## Keyakinan Ayub bahwa Allah Akan Memihaknya

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1"> Kemudian, Ayub menjawab, katanya,</span>
<span className="v" id="v2" data-v="2" data-xref="MAZMUR 64:3; AYUB 18:2; AYUB 27:2"> <span className="pl pl-1">“Berapa lama lagi kamu akan menyiksa batinku,</span><br /><span className="pl pl-2">dan menghancurkan aku berkeping-keping dengan kata-kata?</span></span>
<span className="v" id="v3" data-v="3" data-xref="KEJADIAN 31:7; NEHEMIA 4:12; AYUB 18:4–21"> <span className="pl pl-1">Sudah kesepuluh kalinya kamu menghinaku;</span><br /><span className="pl pl-2">kamu tidak malu menyalahkan aku.</span></span>
<span className="v" id="v4" data-v="4" data-xref="2 KORINTUS 5:10; AMSAL 9:12; YEHEZKIEL 18:4"> <span className="pl pl-1">Kalaupun benar bahwa aku sudah bersalah,</span><br /><span className="pl pl-2">kesalahanku tinggal menjadi urusanku sendiri.</span></span>
<span className="v" id="v5" data-v="5" data-xref="MAZMUR 35:26; MAZMUR 38:16; MAZMUR 55:12"> <span className="pl pl-1">Jika kamu benar-benar ingin menyombongkan diri melawan aku,</span><br /><span className="pl pl-2">dan menggunakan aibku sebagai alasan untuk melawan aku,</span></span>
<span className="v" id="v6" data-v="6" data-xref="AYUB 18:8–10; AYUB 27:2; AYUB 16:11–14"> <span className="pl pl-1">ketahuilah bahwa Allah telah menempatkanku di sisi yang salah,</span><br /><span className="pl pl-2">dan mengurungku dengan jala-Nya.</span></span>
<span className="v" id="v7" data-v="7" data-xref="HABAKUK 1:2–3; RATAPAN 3:8; AYUB 31:35–36"> <span className="pl pl-1">Lihatlah, aku berseru, ‘Ketidakadilan!’ tetapi aku tidak dijawab.</span><br /><span className="pl pl-2">Aku berteriak minta tolong, tetapi tidak ada keadilan.</span></span>
<span className="v" id="v8" data-v="8" data-xref="RATAPAN 3:7; AYUB 3:23; AMSAL 4:19"> <span className="pl pl-1">Dia menutup jalanku sehingga aku tidak bisa lewat,</span><br /><span className="pl pl-2">dan Dia menaruh kegelapan di jalan-jalanku.</span></span>
<span className="v" id="v9" data-v="9" data-xref="MAZMUR 89:44; AYUB 29:7–14; MAZMUR 89:39"> <span className="pl pl-1">Dia melucuti kehormatanku,</span><br /><span className="pl pl-2">dan mengambil mahkota dari kepalaku.</span></span>
<span className="v" id="v10" data-v="10" data-xref="AYUB 24:20; MAZMUR 37:35–36; 2 KORINTUS 4:8–9"> <span className="pl pl-1">Dia meremukkanku dari segala sisi hingga aku pupus;</span><br /><span className="pl pl-2">harapanku dicabut-Nya seperti sebuah pohon.</span></span>
<span className="v" id="v11" data-v="11" data-xref="AYUB 13:24; AYUB 16:9; AYUB 33:10"> <span className="pl pl-1">Dia menyulut kemarahan-Nya terhadapku,</span><br /><span className="pl pl-2">dan Dia menganggapku sebagai musuh-Nya.</span></span>
<span className="v" id="v12" data-v="12" data-xref="AYUB 30:12; AYUB 16:13; YESAYA 51:23"> <span className="pl pl-1">Pasukan-pasukan-Nya datang bersama-sama;</span><br /><span className="pl pl-2">mereka mengepung jalan untuk menyerang aku,</span><br /><span className="pl pl-2">dan mereka berkemah di sekeliling kemahku.</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v13" data-v="13" data-xref="MAZMUR 88:8; MAZMUR 88:18; MAZMUR 69:8"> <span className="pl pl-1">Dia menjauhkanku dari saudara-saudaraku,</span><br /><span className="pl pl-2">dan kenalan-kenalanku benar-benar mengasingkanku.</span></span>
<span className="v" id="v14" data-v="14" data-xref="MAZMUR 38:11; YEREMIA 20:10; 2 SAMUEL 16:23"> <span className="pl pl-1">Kerabat-kerabatku telah meninggalkan aku,</span><br /><span className="pl pl-2">dan teman-temanku telah melupakan aku.</span></span>
<span className="v" id="v15" data-v="15" data-xref="AYUB 31:31–32; MAZMUR 123:3"> <span className="pl pl-1">Tamu-tamu dan pelayan-pelayanku perempuan</span><br /><span className="pl pl-2">menganggapku sebagai orang asing;</span><br /><span className="pl pl-2">aku adalah seorang pendatang menurut pandangan mereka.</span></span>
<span className="v" id="v16" data-v="16" data-xref="AYUB 1:15–17; AYUB 1:19"> <span className="pl pl-1">Aku memanggil pelayanku, tetapi dia tidak menjawab,</span><br /><span className="pl pl-2">walaupun aku harus memohon kepadanya dengan mulutku sendiri.</span></span>
<span className="v" id="v17" data-v="17" data-xref="AYUB 2:9–10; AYUB 17:1"> <span className="pl pl-1">Napasku asing bagi istriku,</span><br /><span className="pl pl-2">dan aku memuakkan saudara-saudara kandungku sendiri.</span></span>
<span className="v" id="v18" data-v="18" data-xref="2 RAJA-RAJA 2:23; AYUB 30:12; AYUB 30:1"> <span className="pl pl-1">Bahkan, anak-anak kecil menghinaku;</span><br /><span className="pl pl-2">ketika aku berdiri, mereka mengataiku.</span></span>
<span className="v" id="v19" data-v="19" data-xref="MAZMUR 41:9; MAZMUR 109:4–5; MAZMUR 55:12–14"> <span className="pl pl-1">Semua sahabat dekatku membenciku,</span><br /><span className="pl pl-2">dan mereka yang aku kasihi berbalik melawan aku.</span></span>
<span className="v" id="v20" data-v="20" data-xref="MAZMUR 102:5; RATAPAN 4:8; AYUB 33:19–22"> <span className="pl pl-1">Tulang-tulangku melekat pada kulit dan dagingku,</span><br /><span className="pl pl-2">dan aku hanya terluput dengan kulit gigiku.</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v21" data-v="21" data-xref="AYUB 1:11; MAZMUR 38:2; AYUB 2:5"> <span className="pl pl-1">Kasihanilah aku, sahabat-sahabatku, kasihanilah aku,</span><br /><span className="pl pl-2">karena tangan Allah telah menyentuhku.</span></span>
<span className="v" id="v22" data-v="22" data-xref="MAZMUR 69:26; AYUB 31:31; AYUB 16:13–14"> <span className="pl pl-1">Mengapa kamu mengejar-ngejar aku seperti Allah?</span><br /><span className="pl pl-2">Apakah kamu belum puas dengan dagingku?</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v23" data-v="23" data-xref="YESAYA 30:8; AYUB 31:35; YESAYA 8:1"> <span className="pl pl-1">Ah, seandainya kata-kataku ditulis.</span><br /><span className="pl pl-2">Ah, seandainya semua itu ditulis dalam sebuah buku.</span></span>
<span className="v" id="v24" data-v="24" data-xref="YEREMIA 17:1; KELUARAN 28:21; KELUARAN 32:16"> <span className="pl pl-1">Seandainya dengan pena besi dan dengan timah,</span><br /><span className="pl pl-2">semua itu dipahat pada gunung batu sampai selama-lamanya!</span></span>
<span className="v" id="v25" data-v="25" data-xref="EFESUS 1:7; YESAYA 54:5; MAZMUR 78:35"> <span className="pl pl-1">Sebab, aku tahu bahwa Penebusku hidup,</span><br /><span className="pl pl-2">dan bahwa pada akhirnya, Dia akan berdiri di atas bumi.</span></span>
<span className="v" id="v26" data-v="26" data-xref="MATIUS 5:8; 1 YOHANES 3:2; MAZMUR 17:15"> <span className="pl pl-1">Bahkan, walau sampai kulitku dihancurkan,</span><br /><span className="pl pl-2">dalam dagingku, aku akan melihat Allah,</span></span>
<span className="v" id="v27" data-v="27" data-xref="MAZMUR 73:26; YESAYA 26:19; BILANGAN 24:17"> <span className="pl pl-1">yang akan aku lihat sendiri,</span><br /><span className="pl pl-2">dengan mataku sendiri, bukan yang lain.</span><br /><span className="pl pl-2">Betapa hatiku merindu dalam diriku.</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v28" data-v="28" data-xref="AYUB 19:22; MAZMUR 69:26; 1 RAJA-RAJA 14:13"> <span className="pl pl-1">Jika kamu berkata, ‘Bagaimana kita dapat mengejarnya?</span><br /><span className="pl pl-2">Sebab, akar masalahnya ada pada dia.’</span></span>
<span className="v" id="v29" data-v="29" data-xref="PENGKHOTBAH 12:14; PENGKHOTBAH 11:9; MAZMUR 58:10–11"> <span className="pl pl-1">Takutlah pada pedang,</span><br /><span className="pl pl-2">karena kemurkaan mendatangkan hukuman dari pedang,</span><br /><span className="pl pl-2">supaya kamu tahu bahwa ada penghakiman.”</span></span>
</div>

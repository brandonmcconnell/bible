## Nyanyian Pujian Daud kepada TUHAN

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="KELUARAN 15:1; HAKIM-HAKIM 5:1; YESAYA 12:1–6"> Daud mengucapkan perkataan nyanyian ini kepada TUHAN pada waktu TUHAN menyelamatkan dia dari tangan semua musuhnya dan dari tangan Saul.</span>
</div>
<div className="bp poetry">
<span className="v" id="v2" data-v="2" data-xref="MAZMUR 18:2–50; MAZMUR 31:3; MAZMUR 71:3"> <span className="pl pl-1">Dia berkata, “TUHAN adalah bukit batuku, benteng pertahananku, dan penyelamatku.</span></span>
<span className="v" id="v3" data-v="3" data-xref="MAZMUR 9:9; YESAYA 12:2; AMSAL 18:10"> <span className="pl pl-2">Allahku, bukit batuku, tempat aku berlindung,</span><br /><span className="pl pl-1">perisaiku, tanduk keselamatanku,</span><br /><span className="pl pl-2">kota bentengku, tempat perlindunganku,</span><br /><span className="pl pl-1">dan Juru Selamatku.</span><br /><span className="pl pl-2">Engkau menyelamatkan aku dari kekerasan.</span></span>

</div>
<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="YUNUS 2:3; MAZMUR 69:14–15; WAHYU 17:15"> <span className="pl pl-1">Sesungguhnya gelora-gelora maut melingkupi aku,</span><br /><span className="pl pl-2">dan arus-arus kejahatan meliputiku.</span></span>

<span className="v" id="v8" data-v="8" data-xref="AYUB 26:11; MAZMUR 97:4; HAKIM-HAKIM 5:4"> <span className="pl pl-1">Lalu, bumi berguncang dan bergetar,</span><br /><span className="pl pl-2">dasar-dasar langit gemetar dan berguncang</span><br /><span className="pl pl-2">karena Dia marah.</span></span>

<span className="v" id="v11" data-v="11" data-xref="MAZMUR 104:3; MAZMUR 18:10; 1 SAMUEL 4:4"> <span className="pl pl-1">Dia mengendarai kerub,</span><br /><span className="pl pl-2">lalu terbang, dan terlihat di atas sayap-sayap angin.</span></span>
<span className="v" id="v12" data-v="12" data-xref="MAZMUR 97:2; 2 SAMUEL 22:10; AYUB 36:29"> <span className="pl pl-1">Dia membuat kegelapan menjadi pondok-pondok-Nya di sekelilingnya,</span><br /><span className="pl pl-2">air yang gelap, dan awan-awan tebal.</span></span>
<span className="v" id="v13" data-v="13" data-xref="2 SAMUEL 22:9"> <span className="pl pl-1">Dari kilauan di hadapan-Nya,</span><br /><span className="pl pl-2">bara api menyala.</span></span>

<span className="v" id="v15" data-v="15" data-xref="ULANGAN 32:23; YOSUA 10:10; HABAKUK 3:11"> <span className="pl pl-1">Dia melepaskan anak-anak panah dan menyerakkan mereka,</span><br /><span className="pl pl-2">kilat-kilat, dan mengacaukan mereka.</span></span>

<div className="bp poetry">

<span className="v" id="v17" data-v="17" data-xref="YESAYA 43:2; MAZMUR 144:7; MAZMUR 18:16"> <span className="pl pl-1">Dia menjangkau dari tempat tinggi,</span><br /><span className="pl pl-2">Dia mengambil aku, Dia menarikku dari limpahan air.</span></span>

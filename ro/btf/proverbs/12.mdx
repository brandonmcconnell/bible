<span className="v" id="v1" data-v="1" data-xref="Proverbe 15:10; Proverbe 9:7–8; Psalmii 119:97–100"> Oricine iubește instruirea iubește cunoașterea, dar cel ce urăște mustrarea este neghiob.</span>
<span className="v" id="v2" data-v="2" data-xref="Proverbe 8:35; Faptele 11:24; Psalmii 112:5"> Un om bun obține favoarea DOMNULUI, dar pe un om al planurilor stricate el îl va condamna.</span>
<span className="v" id="v3" data-v="3" data-xref="Proverbe 10:25; Efeseni 3:17; Proverbe 12:12"> Un om nu va fi întemeiat prin stricăciune, dar rădăcina celor drepți nu va fi mutată.</span>
<span className="v" id="v4" data-v="4" data-xref="Proverbe 14:30; Proverbe 31:10–25; Proverbe 14:1"> O femeie virtuoasă este o coroană pentru soțul ei, dar cea care îl face de rușine este ca putregaiul în oasele lui.</span>
<span className="v" id="v5" data-v="5" data-xref="Psalmii 139:23; Isaia 55:7; Psalmii 140:1–3"> Gândurile celor drepți sunt drepte, dar sfaturile celor stricați sunt înșelăciune.</span>
<span className="v" id="v6" data-v="6" data-xref="Proverbe 14:3; Ieremia 5:26; Proverbe 1:11–19"> Cuvintele celor stricați sunt pentru a pândi pentru sânge, dar gura celor integri îi va elibera.</span>
<span className="v" id="v7" data-v="7" data-xref="Matei 7:24–27; Proverbe 11:21; Proverbe 10:25"> Cei stricați sunt doborâți și nu mai sunt, dar casa celor drepți va sta în picioare.</span>
<span className="v" id="v8" data-v="8" data-xref="2 Corinteni 10:18; 1 Corinteni 4:5; 1 Corinteni 3:10–15"> Un om va fi lăudat după înțelepciunea sa, dar cel cu o inimă perversă va fi disprețuit.</span>
<span className="v" id="v9" data-v="9" data-xref="Luca 14:11; Proverbe 13:7"> Cel ce este disprețuit și are un servitor este mai bun decât cel ce își dă onoare și îi lipsește pâinea.</span>
<span className="v" id="v10" data-v="10" data-xref="Deuteronomul 25:4; Geneză 33:13–14; Numerele 22:28–32"> Un om drept dă atenție vieții animalului său, dar îndurările blânde ale celor stricați sunt crude.</span>
<span className="v" id="v11" data-v="11" data-xref="Proverbe 28:19; Proverbe 14:23; 1 Tesoloniceni 4:11–12"> Cel ce își ară pământul va fi săturat cu pâine, dar cel ce urmează persoane de nimic este lipsit de înțelegere.</span>
<span className="v" id="v12" data-v="12" data-xref="Ieremia 17:7–8; Ioan 15:5; Luca 8:13–15"> Cel stricat dorește prada oamenilor răi, dar rădăcina celor drepți rodește.</span>
<span className="v" id="v13" data-v="13" data-xref="Proverbe 21:23; Proverbe 11:8; Psalmii 64:8"> Cel stricat este prins în capcană prin fărădelegea buzelor sale, dar cel drept va ieși din tulburare.</span>
<span className="v" id="v14" data-v="14" data-xref="Proverbe 18:20–21; Isaia 3:10–11; Proverbe 13:2"> Un om va fi săturat cu bine prin rodul gurii sale, și recompensa mâinilor omului îi va fi restituită.</span>
<span className="v" id="v15" data-v="15" data-xref="Proverbe 3:7; Proverbe 26:12; Proverbe 14:16"> Calea unui nebun este dreaptă în propriii lui ochi, dar cel ce dă ascultare sfatului este înțelept.</span>
<span className="v" id="v16" data-v="16" data-xref="Proverbe 29:11; Iacov 1:19; Proverbe 10:12"> Furia unui nebun este imediat cunoscută, dar un om chibzuit acoperă rușinea.</span>
<span className="v" id="v17" data-v="17" data-xref="Proverbe 14:5; Proverbe 14:25; Proverbe 24:28"> Cel ce spune adevăr declară dreptate, dar un martor fals, înșelăciune.</span>
<span className="v" id="v18" data-v="18" data-xref="Proverbe 16:24; Proverbe 15:4; Psalmii 57:4"> Este unul care vorbește ca străpungerile unei săbii, dar limba celor înțelepți este sănătate.</span>
<span className="v" id="v19" data-v="19" data-xref="Proverbe 19:9; Psalmii 52:4–5; Iov 20:5"> Buza adevărului va fi întemeiată, pentru totdeauna, dar o limbă mincinoasă este numai pentru o clipă.</span>
<span className="v" id="v20" data-v="20" data-xref="Matei 5:9; 1 Petru 3:8–13; Proverbe 12:12"> Înșelăciune este în inima celor ce plănuiesc răul, dar a sfătuitorilor păcii este bucuria.</span>
<span className="v" id="v21" data-v="21" data-xref="1 Petru 3:13; Psalmii 91:10; Romani 8:28"> Niciun rău nu se va întâmpla celui drept, dar cei stricați vor fi umpluți cu ticăloșii.</span>
<span className="v" id="v22" data-v="22" data-xref="Psalmii 5:6; Proverbe 11:20; Apocolipsa 22:15"> Buze mincinoase sunt urâciune pentru DOMNUL, dar cei ce lucrează după adevăr sunt desfătarea lui.</span>
<span className="v" id="v23" data-v="23" data-xref="Proverbe 13:16; Proverbe 11:13; Proverbe 10:19"> Un om chibzuit ascunde cunoaștere, dar inima proștilor vestește nechibzuință.</span>
<span className="v" id="v24" data-v="24" data-xref="Proverbe 12:27; Proverbe 10:4; Proverbe 21:25–26"> Mâna celor harnici va conduce, dar cel leneș va fi sub tribut.</span>
<span className="v" id="v25" data-v="25" data-xref="Proverbe 16:24; Proverbe 15:13; Proverbe 17:22"> Întristarea din inima omului o face să se aplece, dar un cuvânt bun face inima veselă.</span>
<span className="v" id="v26" data-v="26" data-xref="1 Ioan 2:26; Matei 5:46–48; Proverbe 17:27"> Cel drept este nespus mai bun decât vecinul său, dar calea celor stricați îi amăgește.</span>
<span className="v" id="v27" data-v="27" data-xref="Proverbe 13:4; Proverbe 26:15; Proverbe 15:16"> Leneșul nu își frige vânatul, dar averea omului harnic este prețioasă.</span>
<span className="v" id="v28" data-v="28" data-xref="3 Ioan 1:11; Romani 5:21; Ezechiel 18:20–24"> În calea dreptății este viață, și în cărarea ei nu este moarte.</span>

<span className="v" id="v1" data-v="1" data-xref="Proverbe 19:21; Proverbe 16:9; Luca 21:14–15"> Pregătirile inimii în om și răspunsul limbii sunt de la DOMNUL.</span>
<span className="v" id="v2" data-v="2" data-xref="Proverbe 21:2; 1 Samuel 16:7; Luca 16:15"> Toate căile unui om sunt curate în proprii lui ochi, dar DOMNUL cântărește duhurile.</span>
<span className="v" id="v3" data-v="3" data-xref="Psalmii 37:4–5; Proverbe 3:6; Psalmii 55:22"> Încredințează lucrările tale DOMNULUI și gândurile tale vor fi întemeiate.</span>
<span className="v" id="v4" data-v="4" data-xref="2 Petru 2:9; Romani 9:22; Isaia 43:21"> DOMNUL a făcut pentru el însuși toate lucrurile; da, chiar pe cel stricat pentru ziua răului.</span>
<span className="v" id="v5" data-v="5" data-xref="Proverbe 6:16–17; Proverbe 11:21; Proverbe 8:13"> Fiecare om îngâmfat în inimă este urâciune pentru DOMNUL; deși merge mână în mână, el nu va rămâne nepedepsit.</span>
<span className="v" id="v6" data-v="6" data-xref="Proverbe 14:16; Iov 28:28; 2 Corinteni 7:1"> Prin milă și adevăr nelegiuirea este îndepărtată, și prin teama de DOMNUL oamenii se depărtează de rău.</span>
<span className="v" id="v7" data-v="7" data-xref="Romani 8:31; 1 Ioan 3:22; Coloseni 1:10"> Când căile unui om îi plac DOMNULUI, el face chiar pe dușmanii lui să fie în pace cu el.</span>
<span className="v" id="v8" data-v="8" data-xref="Proverbe 15:16; Psalmii 37:16; 1 Timotei 6:6–9"> Mai bine puțin cu dreptate, decât venituri mari fără dreptate.</span>
<span className="v" id="v9" data-v="9" data-xref="Proverbe 19:21; Psalmii 37:23; Proverbe 16:1"> Inima unui om plănuiește calea lui, dar DOMNUL îi conduce pașii.</span>
<span className="v" id="v10" data-v="10" data-xref="Isaia 32:1–2; Geneză 44:5; Geneză 44:15"> O hotărâre divină este pe buzele împăratului; gura lui nu încalcă legea în judecată.</span>
<span className="v" id="v11" data-v="11" data-xref="Proverbe 11:1; Proverbe 20:10; Proverbe 20:23"> O greutate și o balanță dreaptă sunt ale DOMNULUI; toate greutățile din pungă sunt lucrarea lui.</span>
<span className="v" id="v12" data-v="12" data-xref="Proverbe 25:5; Proverbe 29:14; Luca 12:48"> Pentru împărați este urâciune să comită stricăciune, pentru că tronul este întemeiat prin dreptate.</span>
<span className="v" id="v13" data-v="13" data-xref="Proverbe 14:35; Psalmii 101:5–7; Proverbe 22:11"> Buzele drepte sunt desfătarea împăraților și ei iubesc pe acela care vorbește drept.</span>
<span className="v" id="v14" data-v="14" data-xref="Proverbe 20:2; Proverbe 19:12; Eclesiastul 10:4"> Furia unui împărat este ca mesagerii morții, dar un om înțelept o va potoli.</span>
<span className="v" id="v15" data-v="15" data-xref="Psalmii 72:6; Iov 29:23–24; Osea 6:3"> În lumina înfățișării împăratului este viață; și favoarea lui este ca un nor de ploaie de primăvară.</span>
<span className="v" id="v16" data-v="16" data-xref="Proverbe 8:10–11; Matei 16:26; Proverbe 8:19"> Cu cât este mai bine a obține înțelepciune decât aur! Și a obține înțelegere mai de ales decât argint!</span>
<span className="v" id="v17" data-v="17" data-xref="Isaia 35:8; Proverbe 19:16; Proverbe 10:9"> Calea largă a celor integri este să se depărteze de rău; cel ce își păzește calea își păstrează sufletul.</span>
<span className="v" id="v18" data-v="18" data-xref="Proverbe 11:2; Isaia 2:11–12; Proverbe 18:12"> Mândria merge înaintea distrugerii și un duh îngâmfat înaintea căderii.</span>
<span className="v" id="v19" data-v="19" data-xref="Matei 5:3; Isaia 57:15; Psalmii 138:6"> Mai bine să ai un duh umil cu cei de jos, decât să împarți prada cu cei mândri.</span>
<span className="v" id="v20" data-v="20" data-xref="Ieremia 17:7–8; Psalmii 2:12; Isaia 30:18"> Cel ce se comportă cu înțelepciune într-un lucru va găsi binele; și oricine se încrede în DOMNUL este fericit.</span>
<span className="v" id="v21" data-v="21" data-xref="Proverbe 16:23–24; Isaia 50:4; Proverbe 15:7"> Cel înțelept în inimă se va numi chibzuit; și dulceața buzelor adaugă învățătură.</span>
<span className="v" id="v22" data-v="22" data-xref="Proverbe 13:14; Ioan 6:63; Ioan 5:24"> Înțelegerea este un izvor de viață pentru cel ce o are, dar instruirea nechibzuiților este nechibzuință.</span>
<span className="v" id="v23" data-v="23" data-xref="Proverbe 15:28; Matei 12:34–35; Coloseni 3:16"> Inima celui înțelept îi face gura chibzuită și adaugă învățătură buzelor sale.</span>
<span className="v" id="v24" data-v="24" data-xref="Proverbe 12:18; Proverbe 24:13–14; Proverbe 25:11–12"> Cuvintele plăcute sunt ca un fagure de miere, dulci pentru suflet și sănătate pentru oase.</span>
<span className="v" id="v25" data-v="25" data-xref="Proverbe 14:12; Proverbe 12:15; 2 Corinteni 13:5"> Este o cale care i se pare dreaptă unui om, dar sfârșitul ei sunt căile morții.</span>
<span className="v" id="v26" data-v="26" data-xref="Eclesiastul 6:7; Proverbe 14:23; Proverbe 9:12"> Cel ce muncește, muncește pentru el însuși, fiindcă gura lui poftește aceasta de la el.</span>
<span className="v" id="v27" data-v="27" data-xref="Iacov 3:6; Proverbe 6:14; Isaia 5:18"> Un om neevlavios sapă să scoată răul la iveală și pe buzele sale este ca un foc arzător.</span>
<span className="v" id="v28" data-v="28" data-xref="Proverbe 17:9; Proverbe 18:8; Proverbe 15:18"> Un om pervers seamănă ceartă, și un șoptitor desparte prieteni buni.</span>
<span className="v" id="v29" data-v="29" data-xref="Proverbe 2:12–15; Proverbe 12:26; Proverbe 1:10–14"> Un om violent ademenește pe aproapele său și îl conduce pe calea care nu este bună.</span>
<span className="v" id="v30" data-v="30" data-xref="Matei 13:15; Mica 7:3; Matei 14:7–8"> El își închide ochii ca să uneltească lucruri perverse; mișcându-și buzele duce răul la împlinire.</span>
<span className="v" id="v31" data-v="31" data-xref="Proverbe 20:29; Leviticul 19:32; Proverbe 3:1–2"> Capul cărunt este o coroană a gloriei, dacă este găsit pe calea dreptății.</span>
<span className="v" id="v32" data-v="32" data-xref="Iacov 1:19; Proverbe 15:18; Proverbe 25:28"> Cel încet la mânie este mai bun decât cel tare, și cel ce își stăpânește duhul, decât cel ce ia o cetate.</span>
<span className="v" id="v33" data-v="33" data-xref="Proverbe 18:18; Iona 1:7; Faptele 1:26"> Sorțul este aruncat în poală, dar întregul verdict al acestuia este al DOMNULUI.</span>

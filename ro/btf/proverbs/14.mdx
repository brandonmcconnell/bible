<span className="v" id="v1" data-v="1" data-xref="Proverbe 31:10–31; Proverbe 24:3–4; Proverbe 21:9"> Fiecare femeie înțeleaptă își zidește casa, dar nechibzuita o dărâmă cu mâinile ei.</span>
<span className="v" id="v2" data-v="2" data-xref="2 Timotei 3:2–3; Faptele 10:35; Proverbe 28:6"> Cel ce umblă în integritatea lui se teme de DOMNUL, dar cel ce este pervers în căile sale îl disprețuiește.</span>
<span className="v" id="v3" data-v="3" data-xref="Proverbe 12:6; Iacov 3:5–6; Apocolipsa 12:11"> În gura celui nebun este un toiag al mândriei, dar buzele celor înțelepți îi vor păstra.</span>
<span className="v" id="v4" data-v="4" data-xref="1 Corinteni 9:9–11; Proverbe 13:23; Amos 4:6"> Unde nu sunt boi, ieslea este curată; dar mult câștig este prin tăria boului.</span>
<span className="v" id="v5" data-v="5" data-xref="Proverbe 6:19; Proverbe 19:5; Exod 23:1"> Un martor credincios nu minte, dar un martor fals vântură minciuni.</span>
<span className="v" id="v6" data-v="6" data-xref="Iacov 1:5; Matei 13:11–12; Matei 11:25–27"> Un batjocoritor caută înțelepciunea și nu o găsește, dar cunoașterea este ușoară pentru cel ce înțelege.</span>
<span className="v" id="v7" data-v="7" data-xref="Proverbe 13:20; Efeseni 5:11; 1 Corinteni 5:11"> Pleacă din prezența unui om prost, când nu găsești în el buzele cunoașterii.</span>
<span className="v" id="v8" data-v="8" data-xref="Efeseni 5:17; 2 Timotei 3:13; Iacov 3:13"> Înțelepciunea celui chibzuit este să cunoască propria sa cale, dar nechibzuința proștilor este înșelăciune.</span>
<span className="v" id="v9" data-v="9" data-xref="Proverbe 26:18–19; Proverbe 10:23; Romani 14:17–18"> Nebunii iau în râs păcatul, dar printre drepți este favoare.</span>
<span className="v" id="v10" data-v="10" data-xref="Filipeni 4:7; Proverbe 18:14; Proverbe 15:13"> Inima își cunoaște propria ei amărăciune, și un străin nu se amestecă în bucuria ei.</span>
<span className="v" id="v11" data-v="11" data-xref="Proverbe 3:33; Proverbe 12:7; Matei 7:26–27"> Casa celor stricați va fi dărâmată, dar tabernacolul celor integri va înflori.</span>
<span className="v" id="v12" data-v="12" data-xref="Proverbe 16:25; Matei 7:13–14; Proverbe 12:15"> Este o cale care i se pare dreaptă unui om, dar sfârșitul ei sunt căile morții.</span>
<span className="v" id="v13" data-v="13" data-xref="Eclesiastul 2:2; Iacov 4:9; Eclesiastul 2:10–11"> Chiar în râs inima este plină de durere, și sfârșitul acelei veselii este întristare.</span>
<span className="v" id="v14" data-v="14" data-xref="Galateni 6:8; Proverbe 12:14; Evrei 3:12"> Cel care decade în inimă va fi umplut cu propriile sale căi, și un om bun va fi umplut din el însuși.</span>
<span className="v" id="v15" data-v="15" data-xref="Efeseni 5:17; Proverbe 14:8; 1 Ioan 4:1"> Cel simplu crede fiecare cuvânt, dar omul chibzuit se uită bine la umblarea lui.</span>
<span className="v" id="v16" data-v="16" data-xref="Proverbe 22:3; Proverbe 3:7; 1 Tesoloniceni 5:22"> Un om înțelept se teme și se depărtează de rău, dar prostul se înfurie și este încrezător.</span>
<span className="v" id="v17" data-v="17" data-xref="Proverbe 14:29; Iacov 1:19; Eclesiastul 7:9"> Cel care repede se mânie lucrează nechibzuit, și un bărbat al planurilor stricate este urât de alții.</span>
<span className="v" id="v18" data-v="18" data-xref="1 Petru 1:18; 1 Petru 5:4; Ieremia 44:17"> Cei simpli moștenesc nechibzuință, dar cei chibzuiți sunt încoronați cu cunoaștere.</span>
<span className="v" id="v19" data-v="19" data-xref="Geneză 42:6; Maleahi 4:3; Exod 8:8"> Cei răi se apleacă în fața celor buni, și cei stricați la porțile celui drept.</span>
<span className="v" id="v20" data-v="20" data-xref="Proverbe 19:4; Proverbe 10:15; Proverbe 19:6–7"> Cel sărac este urât chiar de aproapele său, dar cel bogat are mulți prieteni.</span>
<span className="v" id="v21" data-v="21" data-xref="Proverbe 19:17; Proverbe 28:27; Proverbe 11:12"> Cel ce disprețuiește pe aproapele său păcătuiește, dar cel ce are milă de săraci, fericit este.</span>
<span className="v" id="v22" data-v="22" data-xref="Proverbe 12:2; Ioan 1:17; Psalmii 61:7"> Nu rătăcesc cei ce plănuiesc răul? Dar milă și adevăr vor fi cu cei ce plănuiesc binele.</span>
<span className="v" id="v23" data-v="23" data-xref="Proverbe 28:19; Proverbe 12:24; 2 Tesaloniceni 3:10–12"> În toată munca este câștig, dar vorbăria buzelor duce numai la lipsă.</span>
<span className="v" id="v24" data-v="24" data-xref="Eclesiastul 7:11–12; Luca 12:19–20; Luca 16:19–25"> Coroana celor înțelepți este bogăția lor, dar nechibzuința proștilor este nechibzuință.</span>
<span className="v" id="v25" data-v="25" data-xref="Proverbe 14:5; Faptele 26:16–20; 2 Petru 3:3"> Un martor adevărat eliberează suflete, dar un martor înșelător vântură minciuni.</span>
<span className="v" id="v26" data-v="26" data-xref="Proverbe 19:23; Ieremia 32:39–40; Psalmii 115:13–14"> În teama de DOMNUL este încredere puternică, și copiii lui vor avea un loc de scăpare.</span>
<span className="v" id="v27" data-v="27" data-xref="Apocolipsa 21:6; Proverbe 13:14; Proverbe 2:10–18"> Teama de DOMNUL este un izvor de viață, ca să depărteze de capcanele morții.</span>
<span className="v" id="v28" data-v="28" data-xref="1 Regii 4:20–21; 2 Regii 13:7; Exod 1:22"> În mulțimea poporului stă onoarea împăratului, dar în lipsa poporului este nimicirea prințului.</span>
<span className="v" id="v29" data-v="29" data-xref="Iacov 1:19; Eclesiastul 7:9; Proverbe 14:17"> Cel încet la furie este omul unei mari înțelegeri, dar cel al unui duh nerăbdător înalță nechibzuință.</span>
<span className="v" id="v30" data-v="30" data-xref="Proverbe 17:22; Proverbe 4:23; Proverbe 3:8"> O inimă sănătoasă este viața cărnii, dar invidia este putregaiul oaselor.</span>
<span className="v" id="v31" data-v="31" data-xref="Proverbe 22:2; Proverbe 17:5; Proverbe 22:16"> Cel ce oprimă pe sărac ocărește pe Făcătorul său, dar cel ce îl onorează are milă de sărac.</span>
<span className="v" id="v32" data-v="32" data-xref="2 Timotei 4:18; 2 Corinteni 5:8; Psalmii 23:4"> Cel stricat este alungat în stricăciunea lui, dar cel drept are speranță în moartea sa.</span>
<span className="v" id="v33" data-v="33" data-xref="Proverbe 12:16; Proverbe 13:16; Proverbe 12:23"> Înțelepciunea se odihnește în inima celui ce are înțelegere, dar ce este în mijlocul proștilor este făcut cunoscut.</span>
<span className="v" id="v34" data-v="34" data-xref="Psalmii 107:34; Deuteronomul 28:1–68; Deuteronomul 29:18–28"> Dreptatea înalță o națiune, dar păcatul este ocară pentru orice popor.</span>
<span className="v" id="v35" data-v="35" data-xref="Matei 24:45–51; Luca 12:42–48; Matei 25:23"> Favoarea împăratului este îndreptată spre un servitor înțelept, dar furia lui este împotriva celui ce aduce rușinea.</span>

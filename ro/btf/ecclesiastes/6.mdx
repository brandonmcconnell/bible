<span className="v" id="v1" data-v="1" data-xref="Eclesiastul 5:13"> Este un rău pe care l-am văzut sub soare și acesta este obișnuit printre oameni:</span>
<span className="v" id="v2" data-v="2" data-xref="Eclesiastul 5:19; Psalmii 17:14; Psalmii 73:7"> Un om căruia Dumnezeu i-a dat bogății, avere și onoare, încât nu îi lipsește nimic pentru sufletul său din tot ce dorește, totuși Dumnezeu nu îi dă putere să mănânce din ele, ci un străin le mănâncă; aceasta este deșertăciune și aceasta este o boală rea.</span>
<span className="v" id="v3" data-v="3" data-xref="Iov 3:16; Ieremia 22:19; Eclesiastul 4:3"> Dacă un om naște o sută de copii și trăiește mulți ani, încât zilele anilor lui sunt multe iar sufletul lui nu s-a săturat cu bine și de asemenea nu are îngropare, eu spun, că un făt lepădat este mai bun decât el.</span>
<span className="v" id="v4" data-v="4" data-xref="Psalmii 109:13"> Pentru că el vine cu deșertăciune și pleacă în întuneric și numele lui va fi acoperit cu întuneric.</span>
<span className="v" id="v5" data-v="5" data-xref="Psalmii 58:8; Iov 14:1; Iov 3:10–13"> Mai mult, el nu a văzut soarele, nici nu a cunoscut vreun lucru; acesta are mai multă odihnă decât celălalt.</span>
<span className="v" id="v6" data-v="6" data-xref="Evrei 9:27; Eclesiastul 3:20; Iov 30:23"> Da, chiar dacă de două ori ar trăi o mie de ani, totuși nu ar vedea niciun bine; nu merg toți în același loc?</span>
<span className="v" id="v7" data-v="7" data-xref="Ioan 6:27; Proverbe 16:26; 1 Timotei 6:6–8"> Toată munca omului este pentru gura lui și totuși pofta nu se satură.</span>
<span className="v" id="v8" data-v="8" data-xref="Proverbe 19:1; Eclesiastul 2:14–16; Psalmii 101:2"> Căci ce are înțeleptul mai mult decât prostul? Ce are săracul, care știe să umble înaintea celor vii?</span>
<span className="v" id="v9" data-v="9" data-xref="Eclesiastul 1:14; Iov 31:7; Eclesiastul 1:2"> Mai bună este vederea ochilor decât rătăcirea dorinței; aceasta este de asemenea deșertăciune și chinuire a duhului.</span>
<span className="v" id="v10" data-v="10" data-xref="Iov 9:32; Isaia 45:9–10; Iov 40:2"> Ceea ce a fost, deja a primit un nume, și se știe că este om; nici nu se va certa cu cel ce este mai tare decât el.</span>
<span className="v" id="v11" data-v="11" data-xref="Eclesiastul 4:16; Eclesiastul 5:7; Eclesiastul 2:3–11"> Văzând că sunt multe lucruri care înmulțesc deșertăciunea, cu ce este omul mai bun?</span>
<span className="v" id="v12" data-v="12" data-xref="Iacov 4:14; Iov 14:2; Eclesiastul 3:22"> Căci cine cunoaște ce este bine pentru om în această viață, în toate zilele vieții sale deșerte pe care el le petrece ca o umbră? Căci cine poate spune unui om ce va fi după el sub soare?</span>

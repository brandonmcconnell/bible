## 八福

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="馬可福音 3:13; 馬太福音 15:29; 馬可福音 4:1"> 耶穌看見大群的人，就上了山，並坐下，門徒走到祂跟前，</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行傳 8:35; 路加福音 6:20–26; 使徒行傳 10:34"> 祂就開口教導他們，說：</span>
<span className="v" id="v3" data-v="3" data-xref="以賽亞書 66:2; 箴言 29:23; 詩篇 34:18"> <span className="pl pl-1">「心靈貧窮的人有福了，</span><br /><span className="pl pl-1">因為天國是他們的。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="啟示錄 21:4; 哥林多後書 7:9–10; 約翰福音 16:20–22"> <span className="pl pl-1">哀慟的人有福了，</span><br /><span className="pl pl-1">因為他們必得安慰。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 37:11; 以賽亞書 29:19; 雅各書 3:13"> <span className="pl pl-1">謙和的人有福了，</span><br /><span className="pl pl-1">因為他們必承受土地。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="約翰福音 4:14; 詩篇 107:9; 約翰福音 6:27"> <span className="pl pl-1">切慕公義如饑似渴的人有福了，</span><br /><span className="pl pl-1">因為他們必得飽足。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="以弗所書 4:32–1; 馬太福音 6:14–15; 撒母耳記下 22:26"> <span className="pl pl-1">心存憐憫的人有福了，</span><br /><span className="pl pl-1">因為他們必蒙憐憫。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 24:4; 詩篇 51:10; 希伯來書 10:22"> <span className="pl pl-1">心靈純潔的人有福了，</span><br /><span className="pl pl-1">因為他們必看見上帝。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="希伯來書 12:14; 雅各書 3:16–18; 羅馬書 12:18"> <span className="pl pl-1">使人和睦的人有福了，</span><br /><span className="pl pl-1">因為他們必被稱為上帝的兒女。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="雅各書 1:12; 彼得前書 3:13–14; 哥林多後書 4:17"> <span className="pl pl-1">為義受迫害的人有福了，</span><br /><span className="pl pl-1">因為天國是他們的。</span></span>
<span className="v" id="v11" data-v="11" data-xref="彼得前書 4:14; 路加福音 21:17; 馬可福音 13:13"> 「人們若因為我的緣故侮辱、迫害、肆意毀謗你們，你們就有福了。</span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 6:23; 雅各書 1:2; 歌羅西書 3:24"> 要歡喜快樂，因為你們在天上有大賞賜。他們也曾這樣迫害以前的先知。</span>
</div>
</div>

## 鹽和光

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="歌羅西書 4:6; 路加福音 14:34–35; 馬可福音 9:49–50"> 「你們是世上的鹽。鹽如果失去鹹味，怎能使它再變鹹呢？它將毫無用處，只會被扔在外面任人踐踏。</span>
<span className="v" id="v14" data-v="14" data-xref="腓立比書 2:15; 約翰福音 8:12; 以弗所書 5:8–14"> 你們是世上的光。建在山上的城無法隱藏。</span>
<span className="v" id="v15" data-v="15" data-xref="路加福音 11:33; 馬可福音 4:21; 路加福音 8:16"> 人點亮燈，不會把它放在斗底下，而是放在燈臺上，好照亮全家。</span>
<span className="v" id="v16" data-v="16" data-xref="彼得前書 2:12; 提多書 2:7; 約翰福音 15:8"> 同樣，你們的光也應當照在人面前，好讓他們看見你們的善行，便讚美你們天上的父。</span>
</div>
</div>

## 成全律法

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="羅馬書 10:4; 路加福音 16:17; 加拉太書 4:4–5"> 「不要以為我是來廢除律法和先知書，我不是來廢除，而是來成全。</span>
<span className="v" id="v18" data-v="18" data-xref="路加福音 16:17; 以賽亞書 40:8; 彼得前書 1:25"> 我實在告訴你們，就是到天地都消失了，律法的一點一劃都不會廢除，全都要成就。</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 12:32; 雅各書 2:10–11; 馬太福音 28:20"> 所以，誰違背這些誡命中最小的一條，並教導別人違背，誰在天國將被稱為最小的。但誰遵守這些誡命，並教導別人遵守，誰在天國將被稱為大的。</span>
<span className="v" id="v20" data-v="20" data-xref="羅馬書 10:2–3; 腓立比書 3:9; 羅馬書 9:30–32"> 我告訴你們，你們的義若不勝過律法教師和法利賽人的義，你們絕不能進天國。</span>
</div>
</div>

## 論仇恨

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="申命記 5:17; 出埃及記 20:13; 民數記 35:30–34"> 「你們聽過吩咐古人的話，『不可殺人，殺人的要受審判。』<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="出埃及記20·13。">a</a></sup></span>
<span className="v" id="v22" data-v="22" data-xref="約翰一書 3:14–15; 約翰一書 4:20–21; 約翰一書 2:9"> 但我告訴你們，凡無緣無故<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有古卷無「無緣無故」。">b</a></sup>向弟兄發怒的，要受審判；凡罵弟兄是白癡的，要受公會<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="「公會」是當時猶太人的最高司法機構，處理宗教、道德和倫理等事務。">c</a></sup>的審判；凡罵弟兄是笨蛋的，難逃地獄的火。</span>
<span className="v" id="v23" data-v="23" data-xref="馬可福音 11:25; 利未記 6:2–6; 馬太福音 5:24"> 「所以，你在祭壇前獻祭的時候，要是想起有弟兄和你有過節，</span>
<span className="v" id="v24" data-v="24" data-xref="雅各書 5:16; 羅馬書 12:17–18; 馬太福音 18:15–17"> 就該把祭物留在祭壇前，先去跟他和好，然後再來獻祭。</span>
<span className="v" id="v25" data-v="25" data-xref="路加福音 12:58–59; 箴言 25:8; 希伯來書 3:13"> 「趁著你和告你的人還在去法庭的路上，你要趕緊與對方和解，以免他把你交給審判官，審判官把你交給差役，把你關進監牢。</span>
<span className="v" id="v26" data-v="26" data-xref="馬太福音 18:34; 路加福音 12:59; 帖撒羅尼迦後書 1:9"> 我實在告訴你，要是有一分錢沒有還清，你絕不能從那裡出來。</span>
</div>
</div>

## 論通姦

<div className="bt">
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="申命記 5:18; 箴言 6:32; 出埃及記 20:14"> 「你們聽過這樣的話，『不可通姦。』<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="出埃及記20·14。">d</a></sup></span>
<span className="v" id="v28" data-v="28" data-xref="約翰一書 2:16; 雅各書 1:14–15; 箴言 6:25"> 但我告訴你們，凡看見婦女就動淫念的，他在心裡已經犯了通姦罪。</span>
<span className="v" id="v29" data-v="29" data-xref="羅馬書 8:13; 馬可福音 9:43–48; 歌羅西書 3:5"> 如果你的右眼使你犯罪，就剜掉它！寧可失去身體的一部分，也比整個人被扔進地獄好。</span>
<span className="v" id="v30" data-v="30" data-xref="馬可福音 9:43; 馬太福音 5:29; 彼得前書 2:8"> 如果你的右手使你犯罪，就砍掉它！寧可失去身體的一部分，也比整個人下地獄好。</span>
</div>
</div>

## 論休妻

<div className="bt">
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="耶利米書 3:1; 申命記 24:1–4; 馬太福音 19:7"> 「還有話說，『人若休妻，必須給她休書』。<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="申命記24·1。">e</a></sup></span>
<span className="v" id="v32" data-v="32" data-xref="羅馬書 7:3; 哥林多前書 7:10–11; 路加福音 16:18"> 但我告訴你們，除非是妻子不貞，否則休妻就是使妻子犯通姦罪，娶被休的女子也是犯通姦罪。</span>
</div>
</div>

## 論起誓

<div className="bt">
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="申命記 23:21; 利未記 19:12; 傳道書 5:4–6"> 「你們也聽過吩咐古人的話，『不可違背誓言，總要向主遵守所起的誓。』</span>
<span className="v" id="v34" data-v="34" data-xref="雅各書 5:12; 以賽亞書 66:1; 申命記 23:21–23"> 但我告訴你們，不可起誓。不可指著天起誓，因為天是上帝的寶座。</span>
<span className="v" id="v35" data-v="35" data-xref="詩篇 48:2; 瑪拉基書 1:14; 歷代志下 6:6"> 不可指著地起誓，因為地是上帝的腳凳。不可指著耶路撒冷起誓，因為那是大君王的城。</span>
<span className="v" id="v36" data-v="36" data-xref="路加福音 12:25; 馬太福音 6:27; 馬太福音 23:16–21"> 也不可指著自己的頭起誓，因為你不能使一根頭髮變白或變黑。</span>
<span className="v" id="v37" data-v="37" data-xref="雅各書 5:12; 歌羅西書 4:6; 歌羅西書 3:9"> 你們說話，是就說是，不是就說不是，多說的便是來自那惡者<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="那惡者即魔鬼，又名撒旦。">f</a></sup>。</span>
</div>
</div>

## 論愛仇敵

<div className="bt">
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="利未記 24:19–20; 申命記 19:21; 出埃及記 21:22–27"> 「你們聽過這樣的話，『以眼還眼，以牙還牙。』<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="出埃及記21·24；利未記24·20；申命記19·21。">g</a></sup></span>
<span className="v" id="v39" data-v="39" data-xref="帖撒羅尼迦前書 5:15; 彼得前書 3:9; 羅馬書 12:17–19"> 但我告訴你們，不要跟惡人作對。有人打你的右臉，連左臉也轉過來讓他打。</span>
<span className="v" id="v40" data-v="40" data-xref="路加福音 6:29; 哥林多前書 6:7"> 有人想控告你，要奪你的內衣，連外衣也給他。</span>
<span className="v" id="v41" data-v="41" data-xref="路加福音 23:26; 馬太福音 27:32; 馬可福音 15:21"> 有人強迫你走一里路，你就跟他走二里路。</span>
<span className="v" id="v42" data-v="42" data-xref="箴言 19:17; 希伯來書 13:16; 路加福音 6:30–36"> 有求你的，就給他；有向你借的，不可拒絕他。</span>
<span className="v" id="v43" data-v="43" data-xref="利未記 19:18; 詩篇 139:21–22; 加拉太書 5:13–14"> 「你們聽過這樣的話，『要愛鄰居，恨仇敵。』<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="利未記19·18。">h</a></sup></span>
<span className="v" id="v44" data-v="44" data-xref="羅馬書 12:14; 彼得前書 3:9; 路加福音 6:27–28"> 但我告訴你們，要愛你們的仇敵，為迫害你們的人禱告。</span>
<span className="v" id="v45" data-v="45" data-xref="詩篇 145:9; 路加福音 6:35; 使徒行傳 14:17"> 這樣，你們才是天父的孩子。因為祂讓陽光照好人也照壞人，降雨給義人也給惡人。</span>
<span className="v" id="v46" data-v="46" data-xref="路加福音 6:32–35; 彼得前書 2:20–23; 馬太福音 9:10–11"> 如果你們只愛那些愛你們的人，有什麼值得嘉獎的呢？就是稅吏也會這樣做。</span>
<span className="v" id="v47" data-v="47" data-xref="馬太福音 5:20; 路加福音 6:32; 彼得前書 2:20"> 如果你們只問候自己的弟兄，有什麼特別呢？就是外族人也會這樣做。</span>
<span className="v" id="v48" data-v="48" data-xref="彼得前書 1:15–16; 雅各書 1:4; 利未記 19:2"> 所以，你們要純全，正如你們的天父是純全的。</span>

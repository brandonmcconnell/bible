## 猶大的下場

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="馬可福音 15:1; 約翰福音 18:28; 彌迦書 2:1"> 到了清晨，眾祭司長和百姓的長老商定要處死耶穌。</span>
<span className="v" id="v2" data-v="2" data-xref="馬太福音 20:19; 使徒行傳 3:13; 提摩太前書 6:13"> 他們把祂綁起來，押送到總督彼拉多那裡。</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多後書 7:10; 路加福音 22:47–48; 約伯記 20:15–29"> 出賣耶穌的猶大看見耶穌被定了罪，感到很後悔，就把那三十塊銀子還給祭司長和長老，說：</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳記上 15:30; 提多書 1:16; 使徒行傳 18:15–17"> 「我出賣了清白無辜的人，我犯罪了！」 他們說：「那是你自己的事，跟我們有什麼關係？」</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行傳 1:18–19; 撒母耳記下 17:23; 列王紀上 16:18"> 猶大把錢扔在聖殿裡，出去上吊自盡了。</span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 6:7–9; 申命記 23:18; 以賽亞書 61:8"> 祭司長們撿起銀子，說：「這是血錢，不可收進聖殿的庫房。」</span>
<span className="v" id="v7" data-v="7"> 他們商議後，決定用這些錢買下陶匠的地作為埋葬異鄉人的墳場。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行傳 1:19; 馬太福音 28:15; 約書亞記 4:9"> 因此，那塊地至今被稱為「血田」。</span>
<span className="v" id="v9" data-v="9" data-xref="撒迦利亞書 11:12–13; 馬太福音 1:22; 利未記 27:2–7"> 這就應驗了耶利米先知的話：「他們用以色列人給祂估定的三十塊銀子，</span>
<span className="v" id="v10" data-v="10" data-xref="撒迦利亞書 11:13"> 買了陶匠的一塊田，正如主指示我的。」<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="撒迦利亞書11·12、13；耶利米書19·1‑13；32·6‑9。">a</a></sup></span>
</div>
</div>

## 耶穌在彼拉多面前受審

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="路加福音 23:2–3; 馬可福音 15:2–5; 馬太福音 26:25"> 耶穌站在總督面前受審。總督問：「你是猶太人的王嗎？」 耶穌說：「如你所言。」</span>
<span className="v" id="v12" data-v="12" data-xref="馬太福音 26:63; 以賽亞書 53:7; 馬太福音 27:14"> 當祭司長和長老控告祂時，祂一句話也不說。</span>
<span className="v" id="v13" data-v="13" data-xref="馬太福音 26:62; 約翰福音 18:35; 使徒行傳 22:24"> 彼拉多就問：「你沒聽見他們對你的諸多控告嗎？」</span>
<span className="v" id="v14" data-v="14" data-xref="以賽亞書 8:18; 詩篇 71:7; 哥林多前書 4:9"> 耶穌仍舊一言不發。彼拉多感到十分驚奇。</span>
<span className="v" id="v15" data-v="15" data-xref="約翰福音 18:38–40; 路加福音 23:16; 約翰福音 19:16"> 每逢逾越節，總督都會照慣例按民眾的意願釋放一個囚犯。</span>
<span className="v" id="v16" data-v="16" data-xref="馬可福音 15:7; 使徒行傳 3:14; 路加福音 23:25"> 那時，有一個惡名昭彰的囚犯名叫巴拉巴。</span>
<span className="v" id="v17" data-v="17" data-xref="約翰福音 19:15; 列王紀上 18:21; 馬可福音 15:9–12"> 百姓聚在一起的時候，彼拉多就問他們：「你們要我給你們釋放誰？巴拉巴還是被稱為基督的耶穌？」</span>
<span className="v" id="v18" data-v="18" data-xref="箴言 27:4; 使徒行傳 5:17; 馬可福音 15:10"> 因為彼拉多知道他們把耶穌押來是出於嫉妒。</span>
<span className="v" id="v19" data-v="19" data-xref="撒迦利亞書 9:9; 箴言 29:1; 馬太福音 27:24"> 彼拉多正坐堂斷案時，他夫人派人來對他說：「你不要插手這個義人的事！我今天在夢中因為這個人受了許多苦。」</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行傳 3:14–15; 約翰福音 19:15–16; 約翰福音 18:40"> 祭司長和長老卻慫恿百姓要求釋放巴拉巴，處死耶穌。</span>
<span className="v" id="v21" data-v="21"> 總督再次問百姓：「這兩個人，你們要我釋放哪一個？」他們說：「巴拉巴！」</span>
<span className="v" id="v22" data-v="22" data-xref="以賽亞書 53:2–3; 以賽亞書 49:7; 使徒行傳 13:38"> 彼拉多問：「那麼，我怎樣處置被稱為基督的耶穌呢？」 他們齊聲說：「把祂釘在十字架上！」</span>
<span className="v" id="v23" data-v="23" data-xref="創世記 37:18–19; 使徒行傳 7:57; 使徒行傳 23:12–15"> 彼拉多問：「為什麼？祂犯了什麼罪？」 他們卻更大聲地喊叫：「把祂釘在十字架上！」</span>
<span className="v" id="v24" data-v="24" data-xref="馬太福音 27:4; 詩篇 26:6; 哥林多後書 5:21"> 彼拉多見再說也無濟於事，反而會引起騷亂，於是取了一些水來，在眾人面前洗手，說：「流這義人的血，罪不在我，你們自己負責。」</span>
<span className="v" id="v25" data-v="25" data-xref="約書亞記 2:19; 使徒行傳 5:28; 使徒行傳 7:52"> 眾人都說：「流祂血的責任由我們和我們的子孫承擔！」</span>
<span className="v" id="v26" data-v="26" data-xref="以賽亞書 53:5; 約翰福音 19:1; 馬可福音 15:15"> 於是，彼拉多為他們釋放了巴拉巴，下令將耶穌鞭打後交出去釘十字架。</span>
</div>
</div>

## 耶穌受辱

<div className="bt">
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="約翰福音 18:28; 約翰福音 18:33; 使徒行傳 10:1"> 總督的士兵把耶穌押進總督府，把全營士兵都集合在祂周圍。</span>
<span className="v" id="v28" data-v="28" data-xref="馬可福音 15:17; 約翰福音 19:2–5; 路加福音 23:11"> 他們剝下耶穌的衣服，給祂披上一件朱紅色長袍，</span>
<span className="v" id="v29" data-v="29" data-xref="以賽亞書 53:3; 馬太福音 20:19; 詩篇 69:19–20"> 用荊棘編成冠冕，戴在祂頭上，又拿一根葦稈放在祂右手裡，跪在祂跟前戲弄祂，說：「猶太人的王萬歲！」</span>
<span className="v" id="v30" data-v="30" data-xref="以賽亞書 50:6; 馬太福音 26:67; 以賽亞書 53:7"> 然後向祂吐唾沫，拿過葦稈打祂的頭。</span>
<span className="v" id="v31" data-v="31" data-xref="以賽亞書 53:7; 列王紀上 21:13; 列王紀上 21:10"> 他們戲弄完了，就脫去祂的袍子，給祂穿上原來的衣服，把祂押出去釘十字架。</span>
</div>
</div>

## 釘十字架

<div className="bt">
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="馬可福音 15:21; 馬太福音 16:24; 路加福音 23:26"> 他們出去的時候，遇見一個叫西門的古利奈人，就強迫他背耶穌的十字架。</span>
<span className="v" id="v33" data-v="33" data-xref="約翰福音 19:17–19; 馬可福音 15:22–32; 馬可福音 15:34"> 來到一個地方，名叫各各他——意思是「髑髏地」，</span>
<span className="v" id="v34" data-v="34" data-xref="詩篇 69:21; 馬可福音 15:23; 馬太福音 27:48"> 士兵給耶穌喝摻了苦膽汁的酒，祂嘗了一口，不肯喝。</span>
<span className="v" id="v35" data-v="35" data-xref="詩篇 22:18; 馬可福音 15:24–32; 路加福音 23:34"> 他們把耶穌釘在十字架上，還抽籤分了祂的衣服，</span>
<span className="v" id="v36" data-v="36" data-xref="馬太福音 27:54; 馬可福音 15:44; 馬可福音 15:39"> 然後坐在那裡看守。</span>
<span className="v" id="v37" data-v="37" data-xref="路加福音 23:38; 約翰福音 19:19–22; 馬可福音 15:26"> 他們在祂頭頂上掛了一個牌子，上面寫著祂的罪狀：「這是猶太人的王耶穌。」</span>
<span className="v" id="v38" data-v="38" data-xref="約翰福音 19:18; 路加福音 23:39–43; 以賽亞書 53:12"> 當時，有兩個強盜也被釘在十字架上，一個在祂右邊，一個在祂左邊。</span>
<span className="v" id="v39" data-v="39" data-xref="詩篇 109:25; 耶利米哀歌 1:12; 詩篇 69:7–12"> 過路的人都嘲笑祂，搖著頭說：</span>
<span className="v" id="v40" data-v="40" data-xref="馬太福音 26:61; 馬太福音 4:6; 馬太福音 4:3"> 「你這要把聖殿拆毀又在三天內重建的人啊，救救自己吧！你要是上帝的兒子，就從十字架上下來吧！」</span>
<span className="v" id="v41" data-v="41" data-xref="詩篇 35:26; 以賽亞書 28:22; 詩篇 22:12–13"> 祭司長、律法教師和長老也同樣嘲諷說：</span>
<span className="v" id="v42" data-v="42" data-xref="約翰福音 1:49; 馬太福音 27:37; 使徒行傳 4:14"> 「祂救了別人，卻救不了自己！祂可是以色列的王啊！現在就從十字架上下來吧！我們就信祂。</span>
<span className="v" id="v43" data-v="43" data-xref="詩篇 22:8; 約翰福音 10:36; 以賽亞書 37:10"> 祂信靠上帝，如果上帝喜悅祂，就讓上帝來救祂吧！因為祂自稱是上帝的兒子。」</span>
<span className="v" id="v44" data-v="44" data-xref="馬太福音 27:38; 馬可福音 15:32; 路加福音 23:39–43"> 跟祂一同被釘十字架的強盜也這樣嘲笑祂。</span>
</div>
</div>

## 耶穌之死

<div className="bt">
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="阿摩司書 8:9; 馬可福音 15:33–34; 路加福音 23:44–45"> 從正午一直到下午三點，黑暗籠罩著整個大地。</span>
<span className="v" id="v46" data-v="46" data-xref="詩篇 22:1; 希伯來書 5:7; 以賽亞書 53:10"> 大約下午三點，耶穌大聲呼喊：「以利，以利，拉馬撒巴各大尼？」<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="詩篇22·1。">b</a></sup>意思是：「我的上帝，我的上帝，你為什麼離棄我？」</span>
<span className="v" id="v47" data-v="47" data-xref="瑪拉基書 4:5; 馬可福音 15:35–36; 馬太福音 11:14"> 有些站在旁邊的人聽見了，就說：「這人在呼叫以利亞。」</span>
<span className="v" id="v48" data-v="48" data-xref="詩篇 69:21; 馬太福音 27:34; 路加福音 23:36"> 其中一人連忙跑去拿了一塊海綿，蘸滿酸酒，綁在葦稈上送給祂喝。</span>
<span className="v" id="v49" data-v="49"> 其他人卻說：「等著吧，我們看看以利亞會不會來救祂。」</span>
<span className="v" id="v50" data-v="50" data-xref="約翰福音 19:30; 以賽亞書 53:9–12; 詩篇 22:14–15"> 耶穌又大喊了一聲，就斷了氣。</span>
<span className="v" id="v51" data-v="51" data-xref="希伯來書 10:19–22; 馬可福音 15:38; 希伯來書 6:19"> 就在那時，聖殿裡的幔子從上到下裂成兩半，大地震動，巖石崩裂，</span>
<span className="v" id="v52" data-v="52" data-xref="以賽亞書 26:19; 帖撒羅尼迦前書 4:14; 哥林多前書 15:20"> 墳墓打開，很多死去聖徒的身體復活過來。</span>
<span className="v" id="v53" data-v="53" data-xref="啟示錄 11:2; 以賽亞書 48:2; 啟示錄 21:2"> 他們在耶穌復活後離開墳墓，進聖城向許多人顯現。</span>
<span className="v" id="v54" data-v="54" data-xref="馬太福音 27:36; 馬可福音 15:39; 馬太福音 27:43"> 看守耶穌的百夫長和士兵看見地震及所發生的一切，都驚恐萬狀，說：「這人真是上帝的兒子啊！」</span>
<span className="v" id="v55" data-v="55" data-xref="路加福音 8:2–3; 路加福音 23:48–49; 約翰福音 19:25–27"> 有好些婦女在遠處觀看，她們從加利利就跟隨了耶穌，服侍祂。</span>
<span className="v" id="v56" data-v="56" data-xref="約翰福音 19:25; 馬可福音 15:47–1; 馬太福音 28:1"> 其中有抹大拉的瑪麗亞、雅各和約西的母親瑪麗亞以及西庇太兩個兒子的母親。</span>
</div>
</div>

## 封石守墓

<div className="bt">
<div className="bp">
<span className="v" id="v57" data-v="57" data-xref="約翰福音 19:38–42; 馬可福音 15:42–47; 路加福音 23:50–56"> 傍晚，從亞利馬太來了一位名叫約瑟的有錢人，他是耶穌的門徒。</span>
<span className="v" id="v58" data-v="58" data-xref="路加福音 23:52–53; 馬可福音 15:44–46"> 他去求見彼拉多，要求領取耶穌的遺體，彼拉多就下令把耶穌的遺體交給他。</span>
<span className="v" id="v59" data-v="59"> 約瑟領了遺體，用乾淨的細麻布裹好，</span>
<span className="v" id="v60" data-v="60" data-xref="以賽亞書 53:9; 馬太福音 28:2; 馬太福音 27:66"> 安放在他為自己在巖壁上鑿出的新墓穴裡，又滾來一塊大石頭堵住墓口，然後離去。</span>
<span className="v" id="v61" data-v="61" data-xref="馬太福音 28:1; 馬太福音 27:56"> 那時，抹大拉的瑪麗亞和另一個瑪麗亞坐在墳墓的對面。</span>
<span className="v" id="v62" data-v="62" data-xref="馬可福音 15:42; 約翰福音 19:14; 約翰福音 19:42"> 第二天，就是預備日之後的那天，祭司長和法利賽人一起來見彼拉多，說：</span>
<span className="v" id="v63" data-v="63" data-xref="路加福音 9:22; 馬太福音 16:21; 約翰福音 2:19"> 「總督大人，我們記得那個騙子生前曾說，『三天之後，我必復活。』</span>
<span className="v" id="v64" data-v="64" data-xref="馬太福音 28:13; 馬太福音 12:45"> 所以請你命人看守墳墓三天，以防祂的門徒偷走祂的屍體，然後對百姓說祂已經從死裡復活。這樣的迷惑會比以前的更厲害！」</span>
<span className="v" id="v65" data-v="65" data-xref="馬太福音 27:66; 馬太福音 28:11–15; 箴言 21:30"> 彼拉多說：「你們帶上衛兵，去那裡嚴加看守。」</span>
<span className="v" id="v66" data-v="66" data-xref="但以理書 6:17; 馬太福音 27:60; 提摩太後書 2:19"> 他們就帶著衛兵去了，在墓口的石頭上貼上封條，派人看守墓穴。</span>
</div>

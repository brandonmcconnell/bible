## 耶穌復活

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="馬可福音 16:1–8; 約翰福音 20:1–10; 馬太福音 27:56"> 安息日剛過，週日黎明時分，抹大拉的瑪麗亞和另一位瑪麗亞一同到墳墓去察看。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行傳 16:26; 約翰福音 20:12–13; 馬可福音 16:3–5"> 突然，大地劇烈地震動，主的天使從天而降，把墓口的石頭滾開，坐在上面。</span>
<span className="v" id="v3" data-v="3" data-xref="馬可福音 9:3; 使徒行傳 1:10; 馬可福音 16:5"> 他的容貌如閃電，衣裳潔白如雪。</span>
<span className="v" id="v4" data-v="4" data-xref="啟示錄 1:17; 但以理書 10:7; 馬太福音 27:65–66"> 看守墓穴的衛兵嚇得渾身發抖，像死人一樣。</span>
<span className="v" id="v5" data-v="5" data-xref="啟示錄 1:17–18; 希伯來書 1:14; 以賽亞書 41:10"> 天使對那兩個女人說：「不要怕，我知道你們是在找那位被釘十字架的耶穌。</span>
<span className="v" id="v6" data-v="6" data-xref="馬可福音 16:6; 馬太福音 12:40; 路加福音 24:6–8"> 祂不在這裡，正如祂所說的，祂已經復活了。你們來看，這是安放祂的地方。</span>
<span className="v" id="v7" data-v="7" data-xref="馬太福音 26:32; 路加福音 24:22–24; 馬太福音 28:10"> 現在你們快去告訴祂的門徒，祂已經從死裡復活，要先你們一步去加利利，你們將在那裡見到祂。記住，我已經告訴你們了。」</span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 2:11; 馬可福音 16:8; 路加福音 24:36–41"> 她們聽了又害怕又欣喜，連忙離開墳墓，跑去告訴門徒。</span>
<span className="v" id="v9" data-v="9" data-xref="馬太福音 28:17; 約翰福音 20:14–17; 馬太福音 14:33"> 忽然，耶穌迎面而來，對她們說：「願你們平安！」她們就上前抱住祂的腳敬拜祂。</span>
<span className="v" id="v10" data-v="10" data-xref="羅馬書 8:29; 約翰福音 20:17; 馬太福音 28:7"> 耶穌對她們說：「不要害怕。你們去告訴我的弟兄，叫他們到加利利去，他們將在那裡見到我。」</span>
</div>
</div>

## 行賄造謠

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="馬太福音 27:65–66; 馬太福音 28:4"> 她們還在趕路的時候，有些守墓的衛兵已經進城把整件事告訴祭司長。</span>
<span className="v" id="v12" data-v="12" data-xref="馬太福音 26:3–4; 使徒行傳 4:5–22; 馬太福音 27:1–2"> 祭司長和長老聚集商議，決定用重金買通守墓的衛兵，</span>
<span className="v" id="v13" data-v="13" data-xref="馬太福音 26:64"> 又吩咐他們：「你們就說，『夜裡我們熟睡的時候，耶穌的門徒來把祂的屍體偷走了。』</span>
<span className="v" id="v14" data-v="14" data-xref="馬太福音 27:2; 使徒行傳 12:19"> 如果這件事傳到總督那裡，我們會跟他解釋，保你們無事。」</span>
<span className="v" id="v15" data-v="15" data-xref="提摩太前書 6:10; 馬太福音 27:8; 馬太福音 26:15"> 守衛收下錢，便依照吩咐去做。於是，這說法在猶太人中一直流傳到今天。</span>
</div>
</div>

## 大使命

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="馬太福音 26:32; 馬太福音 28:10; 馬太福音 28:7"> 十一個門徒趕到加利利，到了耶穌和他們約定的山上，</span>
<span className="v" id="v17" data-v="17" data-xref="詩篇 45:11; 詩篇 2:12; 約翰福音 5:23"> 看到耶穌就敬拜祂，但有些人仍然心存疑惑。</span>
<span className="v" id="v18" data-v="18" data-xref="約翰福音 3:35; 彼得前書 3:22; 馬太福音 11:27"> 耶穌上前對門徒說： 「天上地下所有的權柄都交給我了。</span>
<span className="v" id="v19" data-v="19" data-xref="馬可福音 16:15–16; 使徒行傳 2:38–39; 使徒行傳 1:8"> 所以，你們要去使萬民作我的門徒，奉父、子、聖靈的名給他們施洗，</span>
<span className="v" id="v20" data-v="20" data-xref="以賽亞書 41:10; 約書亞記 1:5; 使徒行傳 18:9–10"> 教導他們遵守我吩咐你們的一切。記住，我必常與你們同在，一直到世界的末了。」</span>
</div>

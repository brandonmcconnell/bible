## 天國裡誰最偉大

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="馬可福音 9:33–37; 路加福音 9:46–48; 馬太福音 20:20–28"> 這時，門徒上前來，問耶穌：「在天國誰最偉大？」</span>
<span className="v" id="v2" data-v="2" data-xref="馬太福音 19:13–14; 馬可福音 9:36–37; 列王紀上 3:7"> 耶穌叫了一個小孩子來站在他們當中，然後說：</span>
<span className="v" id="v3" data-v="3" data-xref="馬可福音 10:14–15; 彼得前書 2:2; 馬太福音 19:14"> 「我實在告訴你們，你們若不回轉，變得像小孩子那樣，絕不能進天國。</span>
<span className="v" id="v4" data-v="4" data-xref="雅各書 4:10; 路加福音 14:11; 馬可福音 10:43"> 所以，凡像這小孩子一樣謙卑的人，在天國才是最偉大的。</span>
<span className="v" id="v5" data-v="5" data-xref="馬太福音 25:40; 馬可福音 9:37; 約翰福音 13:20"> 「誰為了我的名接待這樣一個小孩子，就是接待我。</span>
<span className="v" id="v6" data-v="6" data-xref="馬可福音 9:42; 路加福音 17:1–2; 馬太福音 18:10"> 不論誰使這樣一個小信徒失足犯罪，他的下場比把大磨石拴在他脖子上沉到深海裡還要慘。</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 17:1; 哥林多前書 11:19; 馬太福音 26:24"> 這世界有禍了！因為裡面充滿了引人犯罪的事。這樣的事是免不了的，但引人犯罪的人有禍了！</span>
<span className="v" id="v8" data-v="8" data-xref="馬太福音 5:29–30; 腓立比書 3:8–9; 羅馬書 13:12"> 「如果你的手或腳使你犯罪，就把它砍下來扔掉！肢體殘缺著進入永生，勝過四肢健全卻被扔進永遠不滅的火中。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行傳 14:22; 馬太福音 18:8; 馬太福音 5:29"> 如果你的一隻眼睛使你犯罪，就剜出來丟掉它！獨眼進入永生，勝過雙目健全卻被扔進地獄的火中。</span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 91:11; 詩篇 34:7; 希伯來書 1:14"> 你們切不可輕視任何一位卑微的人。我告訴你們，他們的天使在天上常見我天父的面。</span>
</div>
</div>

## 迷失的羊

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11"> 「人子到世界來是要拯救迷失的人。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古卷無11節。">a</a></sup></span>
<span className="v" id="v12" data-v="12" data-xref="以西結書 34:12; 路加福音 15:4–7; 以西結書 34:16"> 如果一個人有一百隻羊，其中有一隻走迷了路，你們認為他會怎麼辦呢？難道不會把那九十九隻撇在山上，去找那隻迷失的羊嗎？</span>
<span className="v" id="v13" data-v="13" data-xref="西番雅書 3:17; 路加福音 15:5–10; 雅各書 2:13"> 我實在告訴你們，如果找到了，他會非常歡喜，甚至比有那九十九隻沒有迷失的羊還歡喜。</span>
<span className="v" id="v14" data-v="14" data-xref="約翰福音 17:12; 約翰福音 6:39–40; 彼得後書 3:9"> 同樣，你們的天父也不願任何一個卑微的人失喪。</span>
</div>
</div>

## 糾正信徒的過錯

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="利未記 19:17; 路加福音 17:3–4; 加拉太書 6:1"> 「如果你的弟兄得罪了你，你要找個機會跟他單獨在一起，指出他的錯處。如果他肯接受勸告，你就贏得了你的弟兄。</span>
<span className="v" id="v16" data-v="16" data-xref="申命記 19:15; 哥林多後書 13:1; 約翰福音 8:17"> 如果他不聽，你就帶一兩位弟兄去見他，這樣任何事有兩三個證人作證才能定案。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="申命記19·15。">b</a></sup></span>
<span className="v" id="v17" data-v="17" data-xref="帖撒羅尼迦後書 3:6; 哥林多前書 5:9–7; 帖撒羅尼迦後書 3:14–15"> 如果他仍然不聽，你就應當告訴教會。如果他連教會也不聽，你就把他看作異教徒或稅吏<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="「稅吏」即猶太人眼中的「漢奸」，幫助統治猶太人的羅馬政府收稅，常從中牟取暴利。">c</a></sup>。</span>
<span className="v" id="v18" data-v="18" data-xref="馬太福音 16:19; 哥林多後書 2:10; 約翰福音 20:23"> 我實在告訴你們，你們在地上捆綁的，在天上也要捆綁；你們在地上釋放的，在天上也要釋放。</span>
<span className="v" id="v19" data-v="19" data-xref="馬太福音 7:7; 約翰一書 5:14–16; 馬可福音 11:24"> 「況且，我實在告訴你們，如果你們當中有兩個人在地上同心合意地祈求，不論求什麼，我天上的父必為你們成就。</span>
<span className="v" id="v20" data-v="20" data-xref="哥林多前書 5:4; 啟示錄 21:3; 馬太福音 28:20"> 因為哪裡有兩三個人奉我的名聚會，我就在哪裡與他們同在。」</span>
</div>
</div>

## 七十個七次

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="路加福音 17:3–4; 馬太福音 18:15"> 那時，彼得上前問耶穌：「主啊，如果我的弟兄得罪了我，我該饒恕他多少次呢？七次夠了吧？」</span>
<span className="v" id="v22" data-v="22" data-xref="歌羅西書 3:13; 馬可福音 11:25; 馬太福音 6:14–15"> 耶穌回答說：「我告訴你，不是七次，是七十個七次。</span>
<span className="v" id="v23" data-v="23" data-xref="馬太福音 13:24; 羅馬書 14:12; 馬太福音 3:2"> 「因此，天國就像一個王，他要跟奴僕清算債務。</span>
<span className="v" id="v24" data-v="24" data-xref="詩篇 38:4; 詩篇 130:3–4; 路加福音 16:5"> 正開始清算的時候，有人帶著一個欠了六千萬銀幣<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="「六千萬銀幣」希腊文是「一萬他連得」，一他連得相當於當時一個普通工人20年的工錢。">d</a></sup>的人進來。</span>
<span className="v" id="v25" data-v="25" data-xref="列王紀下 4:1; 尼希米記 5:5; 路加福音 7:42"> 因為這個人無法清還債款，主人就下令把他及其妻兒和所有財產全部賣掉還債。</span>
<span className="v" id="v26" data-v="26" data-xref="馬太福音 18:29; 路加福音 7:43; 馬太福音 8:2"> 那奴僕跪在王面前乞求說，『請寬容我，我會把債務全部還清的。』</span>
<span className="v" id="v27" data-v="27" data-xref="詩篇 145:8; 尼希米記 9:17; 詩篇 86:15"> 主人可憐他，不但釋放了他，而且免了他全部的債。</span>
<span className="v" id="v28" data-v="28" data-xref="馬太福音 20:2; 以西結書 45:9; 申命記 15:2"> 「可是，那奴僕出去後，遇見一位欠他一百個銀幣<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="一個銀幣相當於當時普通工人一天的工錢。">e</a></sup>的同伴，就揪住他，掐著他的喉嚨說，『還我錢！』</span>
<span className="v" id="v29" data-v="29" data-xref="馬太福音 18:26; 馬太福音 6:12; 腓利門書 1:18–19"> 同伴跪下哀求道，『請寬容我，我會還你的。』</span>
<span className="v" id="v30" data-v="30" data-xref="列王紀上 22:27; 列王紀上 21:27–29"> 「那奴僕卻不肯，竟把同伴送進監獄，直到他還清債務為止。</span>
<span className="v" id="v31" data-v="31" data-xref="羅馬書 12:15; 希伯來書 13:3; 馬可福音 3:5"> 其他奴僕目睹這一切，都憤憤不平，就去把這件事告訴了主人。</span>
<span className="v" id="v32" data-v="32" data-xref="路加福音 19:22; 馬太福音 25:26; 羅馬書 3:19"> 「於是，主人把那奴僕召來，說，『你這可惡的奴才！你哀求我，我就免了你所有的債。</span>
<span className="v" id="v33" data-v="33" data-xref="歌羅西書 3:13; 馬太福音 6:12; 以弗所書 4:32–2"> 難道你不應該憐憫你的同伴，就像我憐憫你一樣嗎？』</span>
<span className="v" id="v34" data-v="34" data-xref="馬太福音 5:25–26; 雅各書 2:13; 路加福音 12:58–59"> 主人大怒，把他交給獄卒受刑，直到他還清全部的債務。</span>
<span className="v" id="v35" data-v="35" data-xref="馬太福音 6:14–15; 雅各書 2:13; 路加福音 6:37–38"> 如果你們每個人不從心裡饒恕自己的弟兄，我的天父也要這樣對待你們。」</span>
</div>

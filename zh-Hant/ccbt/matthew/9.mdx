## 醫治癱瘓的人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="馬太福音 4:13; 路加福音 8:37; 馬太福音 8:18"> 耶穌坐船回到湖對岸自己住的城鎮。</span>
<span className="v" id="v2" data-v="2" data-xref="馬可福音 2:1–12; 路加福音 5:18–26; 耶利米書 31:33–34"> 有人用擔架把一個癱瘓的人抬到耶穌面前。耶穌看見他們的信心，就對癱瘓的人說：「孩子，放心吧！你的罪得到赦免了。」</span>
<span className="v" id="v3" data-v="3" data-xref="馬太福音 26:65; 路加福音 5:21; 利未記 24:16"> 幾個律法教師聽了，心裡想：「這個人是在褻瀆上帝。」</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 6:8; 馬太福音 12:25; 啟示錄 2:23"> 耶穌知道他們的心思，就說：「你們為什麼心懷惡念呢？</span>
<span className="v" id="v5" data-v="5" data-xref="約翰福音 5:8–14; 馬可福音 2:9–12; 使徒行傳 3:16"> 說『你的罪得到赦免了』容易呢？還是說『你起來行走』容易呢？</span>
<span className="v" id="v6" data-v="6" data-xref="以賽亞書 43:25; 馬太福音 9:5; 約翰福音 20:21–23"> 如今我要讓你們知道人子在世上有赦罪的權柄。」於是祂對癱瘓的人說：「起來！拿上你的擔架回家去吧。」</span>
<span className="v" id="v7" data-v="7"> 那人就站起來，回家去了。</span>
<span className="v" id="v8" data-v="8" data-xref="路加福音 7:16; 馬太福音 15:31; 使徒行傳 4:21"> 看見的人都充滿了敬畏，就讚美把這樣的權柄賜給人的上帝。</span>
</div>
</div>

## 呼召馬太

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="路加福音 5:27–38; 馬可福音 2:14–22; 路加福音 19:2–10"> 耶穌離開那裡往前走，看見一個名叫馬太的人坐在收稅站裡，便對他說：「跟從我！」馬太就站起來跟從了耶穌。</span>
<span className="v" id="v10" data-v="10" data-xref="提摩太前書 1:13–16; 路加福音 5:29–32; 馬可福音 2:15–17"> 耶穌在馬太家裡坐席的時候，很多稅吏和罪人前來跟耶穌和祂的門徒一起坐席。</span>
<span className="v" id="v11" data-v="11" data-xref="馬太福音 11:19; 路加福音 5:30; 馬可福音 2:16"> 法利賽人看見了，就問耶穌的門徒：「你們的老師為何跟稅吏和罪人一起吃飯？」</span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 5:31; 啟示錄 3:17–18; 馬可福音 2:17"> 耶穌聽見後，答道：「健康的人不需要醫生，有病的人才需要。</span>
<span className="v" id="v13" data-v="13" data-xref="馬可福音 2:17; 路加福音 19:10; 何西阿書 6:6"> 聖經上說，『我要的是憐憫，而非祭物』<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="何西阿書6·6。">a</a></sup>，你們去揣摩這句話的意思吧。我來不是召義人，而是召罪人。」</span>
</div>
</div>

## 禁食的問題

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="路加福音 5:33–39; 馬可福音 2:18–22; 馬太福音 6:16"> 那時，約翰的門徒來問耶穌：「我們和法利賽人常常禁食，為什麼你的門徒不禁食呢？」</span>
<span className="v" id="v15" data-v="15" data-xref="啟示錄 19:9; 約翰福音 3:29; 啟示錄 21:2"> 耶穌對他們說：「新郎和賓客還在一起的時候，賓客豈能悲傷？但有一天新郎將被帶走，那時他們就要禁食了。</span>
<span className="v" id="v16" data-v="16" data-xref="哥林多前書 3:1–2; 約翰福音 16:12; 詩篇 125:3"> 「沒有人用新布縫補舊衣，因為新布會把舊衣扯破，破洞會更大。</span>
<span className="v" id="v17" data-v="17" data-xref="約書亞記 9:4; 約伯記 32:19; 詩篇 119:83"> 也沒有人把新酒裝在舊皮囊裡，否則皮囊會脹破，酒也漏了，皮囊也毀了。人們總是把新酒裝在新皮囊裡，以便兩樣都能保住。」</span>
</div>
</div>

## 起死回生

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="路加福音 8:41–56; 馬可福音 5:22–43; 馬太福音 8:2"> 耶穌說話的時候，來了一個會堂主管，跪在祂面前，說：「我的女兒剛剛死了，求你去把手按在她身上，她就會活過來。」</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行傳 10:38; 加拉太書 6:9–10; 馬太福音 8:7"> 耶穌和門徒就起身跟著他去了。</span>
<span className="v" id="v20" data-v="20" data-xref="路加福音 8:43–56; 馬太福音 14:36; 馬可福音 6:56"> 途中，有一個患了十二年血漏病的女人擠到耶穌的背後，摸了祂衣服的穗子，</span>
<span className="v" id="v21" data-v="21" data-xref="馬可福音 5:26–33; 路加福音 8:45–47; 使徒行傳 19:12"> 因為她心想：「我只要摸到祂的衣服，就會痊癒。」</span>
<span className="v" id="v22" data-v="22" data-xref="路加福音 7:50; 馬太福音 15:28; 馬太福音 9:2"> 耶穌轉過頭來，看見她，就說：「女兒，放心吧，你的信心救了你。」就在那一刻，她的頑疾痊癒了。</span>
<span className="v" id="v23" data-v="23" data-xref="歷代志下 35:25; 馬可福音 5:35–40; 路加福音 8:49–51"> 耶穌來到會堂主管的家，看見殯葬的吹樂手和亂嚷嚷的人群，</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行傳 20:10; 約翰福音 11:11–13; 馬太福音 27:39–43"> 就吩咐他們：「你們出去吧，這孩子沒有死，只是睡著了。」他們都譏笑祂。</span>
<span className="v" id="v25" data-v="25" data-xref="馬可福音 9:27; 馬可福音 5:41; 路加福音 8:54"> 耶穌讓眾人都出去，然後進去拉著女孩的手，女孩就起來了。</span>
<span className="v" id="v26" data-v="26" data-xref="馬太福音 4:24; 馬太福音 14:1–2; 馬可福音 1:45"> 這件事傳遍了那一帶。</span>
</div>
</div>

## 醫治瞎眼的和啞巴

<div className="bt">
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="馬太福音 15:22; 馬太福音 20:30–31; 馬可福音 10:46–48"> 耶穌從那裡往前走，有兩個瞎眼的跟著祂，高聲呼叫：「大衛的後裔啊，可憐我們吧！」</span>
<span className="v" id="v28" data-v="28" data-xref="馬可福音 9:23–24; 馬太福音 13:58; 馬太福音 8:2"> 耶穌進了房子，那兩個瞎眼的來到祂面前。耶穌問他們：「你們相信我能做這事嗎？」他們說：「主啊，我們相信。」</span>
<span className="v" id="v29" data-v="29" data-xref="馬太福音 15:28; 馬可福音 10:52; 馬太福音 8:13"> 於是，耶穌摸他們的眼睛，並說：「照你們的信心成全你們吧。」</span>
<span className="v" id="v30" data-v="30" data-xref="馬太福音 8:4; 路加福音 5:14; 馬太福音 17:9"> 他們的眼睛就看見了。耶穌鄭重地叮囑他們：「切不可張揚這件事。」</span>
<span className="v" id="v31" data-v="31" data-xref="馬可福音 7:36; 馬太福音 9:26; 馬可福音 1:44–45"> 但他們出去後把祂所行的事傳遍了那一帶。</span>
<span className="v" id="v32" data-v="32" data-xref="馬太福音 4:24; 馬太福音 12:22–24; 路加福音 11:14"> 他們正要離去，有人帶著一個被鬼附身的啞巴來見耶穌。</span>
<span className="v" id="v33" data-v="33" data-xref="以賽亞書 35:6; 馬可福音 7:32–37; 出埃及記 4:11–12"> 耶穌把鬼趕出去後，啞巴就能說話了。眾人都很驚奇，說：「在以色列從未見過這樣的事。」</span>
<span className="v" id="v34" data-v="34" data-xref="路加福音 11:15; 馬可福音 3:22; 馬太福音 12:23–24"> 法利賽人卻說：「祂是靠鬼王趕鬼。」</span>
</div>
</div>

## 耶穌憐憫眾人

<div className="bt">
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="馬太福音 4:23–24; 使徒行傳 10:38; 馬可福音 6:56"> 耶穌走遍了各城各鄉，在會堂裡教導人，傳講天國的福音，醫治各樣的疾病。</span>
<span className="v" id="v36" data-v="36" data-xref="馬可福音 6:34; 民數記 27:17; 耶利米書 50:6"> 祂看見眾人，心裡憐憫他們，因為他們困苦無助，好像沒有牧人的羊。</span>
<span className="v" id="v37" data-v="37" data-xref="路加福音 10:2; 馬可福音 16:15; 哥林多前書 3:9"> 耶穌對門徒說：「要收割的莊稼很多，工人卻很少。</span>
<span className="v" id="v38" data-v="38" data-xref="路加福音 10:1–2; 耶利米書 3:15; 帖撒羅尼迦後書 3:1"> 因此，你們要祈求莊稼的主人派工人去收割祂的莊稼。」</span>
</div>
</div>

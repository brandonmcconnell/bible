## 耶穌和施洗者約翰

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="以賽亞書 61:1–3; 使徒行傳 10:38; 路加福音 8:1"> 耶穌囑咐完十二個門徒，就離開那裡，到附近的城鎮傳道和教導人。</span>
<span className="v" id="v2" data-v="2" data-xref="馬可福音 6:17; 馬太福音 14:3; 馬太福音 9:14"> 約翰在監獄中聽到基督所做的事，就差門徒去問祂：</span>
<span className="v" id="v3" data-v="3" data-xref="約翰福音 11:27; 瑪拉基書 3:1; 申命記 18:15–18"> 「你就是我們所等候的那位嗎？還是我們要等別人呢？」</span>
<span className="v" id="v4" data-v="4"> 耶穌回答說：「你們回去把所見所聞告訴約翰，</span>
<span className="v" id="v5" data-v="5" data-xref="以賽亞書 35:4–6; 以賽亞書 61:1–3; 路加福音 4:18"> 就是瞎眼的看見，瘸腿的走路，痲瘋病人得潔淨，耳聾的聽見，死人復活，窮人聽到福音。</span>
<span className="v" id="v6" data-v="6" data-xref="以賽亞書 8:14–15; 哥林多前書 2:14; 馬太福音 26:31"> 凡對我篤信不疑的人有福了！」</span>
<span className="v" id="v7" data-v="7" data-xref="雅各書 1:6; 約翰福音 5:35; 馬可福音 1:3–5"> 他們離開後，耶穌對眾人談論約翰，說：「你們從前去曠野要看什麼呢？看隨風搖動的蘆葦嗎？</span>
<span className="v" id="v8" data-v="8" data-xref="馬太福音 3:4; 列王紀下 1:8; 撒迦利亞書 13:4"> 如果不是，你們出去到底想看什麼？是看穿綾羅綢緞的人嗎？那些穿綾羅綢緞的人在王宮裡。</span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 1:76; 馬太福音 14:5; 馬太福音 21:24–26"> 你們出去究竟想看什麼？看先知嗎？是的，我告訴你們，他不只是先知。</span>
<span className="v" id="v10" data-v="10" data-xref="瑪拉基書 3:1; 以賽亞書 40:3; 瑪拉基書 4:5"> 聖經上說，『看啊，我要差遣我的使者在你前面為你預備道路』<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="瑪拉基書3·1。">a</a></sup>，這裡所指的就是約翰。</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 7:28; 以弗所書 3:8; 馬太福音 3:11"> 我實在告訴你們，凡婦人所生的，沒有一個興起來比施洗者約翰大，然而天國裡最微不足道的也比他大。</span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 16:16; 路加福音 13:24; 以弗所書 6:11–13"> 「從施洗者約翰到現在，天國在強勁地擴展著，暴力之徒一直在攻擊它。</span>
<span className="v" id="v13" data-v="13" data-xref="馬太福音 5:17–18; 羅馬書 3:21; 使徒行傳 13:27"> 因為到約翰為止，所有的先知和律法都在預言天國的事。</span>
<span className="v" id="v14" data-v="14" data-xref="瑪拉基書 4:5; 馬太福音 17:10–13; 馬可福音 9:11–13"> 如果你們願意接受，約翰就是那要來的以利亞。</span>
<span className="v" id="v15" data-v="15" data-xref="路加福音 8:8; 馬太福音 13:9; 馬可福音 4:23"> 有耳朵的，都應當聽。</span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 7:31–35; 馬太福音 12:34; 馬太福音 23:36"> 「我用什麼來比擬這個世代的人呢？他們好像一群在街上玩耍的兒童對別的孩子說，</span>
<span className="v" id="v17" data-v="17" data-xref="以賽亞書 28:9–13; 以賽亞書 30:29; 耶利米書 9:17–20"> <span className="pl pl-1">「『我們吹娶親的樂曲，</span><br /><span className="pl pl-1">你們不跳舞；</span><br /><span className="pl pl-1">我們唱送葬的哀歌，</span><br /><span className="pl pl-1">你們不捶胸。』</span></span>
<span className="v" id="v18" data-v="18" data-xref="路加福音 1:15; 馬太福音 3:4; 約翰福音 10:20"> 約翰來了，也不吃也不喝，他們就說他被鬼附身。</span>
<span className="v" id="v19" data-v="19" data-xref="馬太福音 9:10–11; 路加福音 15:1–2; 路加福音 19:7"> 人子來了，又吃又喝，他們就說祂是貪吃好酒之徒，與稅吏和罪人為友。然而智慧通過她的作為顯明為義。」</span>
</div>
</div>

## 不肯悔改的城

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="路加福音 10:13–15; 耶利米書 8:6; 提摩太後書 2:25–26"> 那時，耶穌開始責備一些城鎮，因為祂在那裡行了許多神蹟，當地的居民仍不肯悔改。</span>
<span className="v" id="v21" data-v="21" data-xref="以西結書 3:6–7; 使徒行傳 12:20; 路加福音 9:10"> 祂說：「哥拉汛啊，你有禍了！伯賽大啊，你有禍了！因為如果把在你們當中所行的神蹟行在泰爾和西頓，那裡的人早就身披著麻衣、頭蒙著灰塵悔改了。</span>
<span className="v" id="v22" data-v="22" data-xref="馬太福音 11:24; 馬太福音 10:15; 希伯來書 10:26–31"> 所以我告訴你們，在審判之日，你們將比泰爾和西頓受更重的刑罰！</span>
<span className="v" id="v23" data-v="23" data-xref="以賽亞書 14:13–15; 約翰福音 4:46–54; 創世記 13:13"> 「迦百農啊，你將被提升到天上嗎？不！你將被打落到陰間。因為如果把在你那裡所行的神蹟行在所多瑪，它肯定會存留到今天。</span>
<span className="v" id="v24" data-v="24" data-xref="馬太福音 10:15; 馬太福音 11:22; 馬可福音 6:11"> 所以我告訴你們，在審判之日，你們將比所多瑪受更重的刑罰！」</span>
</div>
</div>

## 勞苦者得安息

<div className="bt">
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="馬太福音 21:16; 詩篇 8:2; 馬太福音 16:17"> 那時，耶穌說：「父啊，天地的主，我頌讚你，因為你把這些事向聰明、有學問的人隱藏起來，卻啟示給像孩童一般的人。</span>
<span className="v" id="v26" data-v="26" data-xref="提摩太後書 1:9; 以弗所書 1:11; 約伯記 33:13"> 父啊，是的，這正是你的美意。</span>
<span className="v" id="v27" data-v="27" data-xref="約翰福音 14:6–9; 馬太福音 28:18; 路加福音 10:22"> 我父將一切交給了我。除了父，沒有人認識子；除了子和受子啟示的人，沒有人認識父。</span>
<span className="v" id="v28" data-v="28" data-xref="馬太福音 11:29; 約翰福音 7:37; 約翰福音 6:37"> 「所有勞苦困乏、背負重擔的人啊，到我這裡來吧！我要賜給你們安息。</span>
<span className="v" id="v29" data-v="29" data-xref="耶利米書 6:16; 約翰一書 2:6; 腓立比書 2:7–8"> 我心柔和謙卑，你們要負我的軛，向我學習，這樣你們的心靈必得享安息。</span>
<span className="v" id="v30" data-v="30" data-xref="約翰一書 5:3; 約翰福音 16:33; 腓立比書 4:13"> 因為我的軛容易負，我的擔子很輕省。」</span>
</div>

## 十個伴娘的比喻

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 12:35–36; 腓立比書 2:15–16; 馬太福音 24:42–51"> 「那時，天國就像十個伴娘提著燈去迎接新郎，</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米書 24:2; 哥林多前書 10:1–5; 馬太福音 13:19–23"> 其中五個是糊塗的，五個是聰明的。</span>
<span className="v" id="v3" data-v="3" data-xref="啟示錄 3:15–16; 提摩太後書 3:5; 以賽亞書 48:1–2"> 五個糊塗的只顧拿著燈，卻不預備油；</span>
<span className="v" id="v4" data-v="4" data-xref="羅馬書 8:9; 約翰一書 2:27; 約翰一書 2:20"> 那些聰明的不但拿著燈，還用器皿預備了油。</span>
<span className="v" id="v5" data-v="5" data-xref="哈巴谷書 2:3; 帖撒羅尼迦前書 5:6–8; 彼得後書 3:4–9"> 新郎遲遲未到，她們等得困倦，便打盹睡著了。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="彼得後書 3:10; 馬太福音 24:31; 馬太福音 24:44"> 「到了半夜，忽然聽見有人喊道，『新郎來了！出來迎接吧！』</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 12:35; 啟示錄 3:19–20; 彼得後書 3:14"> 伴娘們醒來，把燈點亮。</span>
<span className="v" id="v8" data-v="8" data-xref="箴言 13:9; 路加福音 12:35; 希伯來書 4:1"> 糊塗的伴娘對聰明的伴娘說，『請給我們一些油吧，因為我們的燈快要滅了！』</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="詩篇 49:7–9; 啟示錄 3:17–18; 以賽亞書 55:6–7"> 「聰明的伴娘回答說，『不行，我們的油不夠大家用的，不如你們自己去油店買吧！』</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="路加福音 13:25; 馬太福音 24:44; 路加福音 12:36–37"> 「當糊塗的伴娘去買油的時候，新郎來了。那些預備好的伴娘跟他一同進去參加婚宴，門就關了。</span>
<span className="v" id="v11" data-v="11" data-xref="馬太福音 7:21–23; 希伯來書 12:16–17"> 後來，其他伴娘回來了，喊道，『主啊！主啊！給我們開門吧！』</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="哥林多前書 8:3; 提摩太後書 2:19; 約翰福音 10:27"> 「新郎卻說，『我實在告訴你們，我不認識你們。』</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="馬太福音 24:42–44; 啟示錄 16:15; 帖撒羅尼迦前書 5:6"> 「所以，你們要警醒，因為你們不知道我回來的日子和時辰。</span>
</div>
</div>

## 才幹的比喻

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="馬可福音 13:34; 路加福音 19:12–27; 彼得前書 4:9–11"> 「天國就像一個人即將遠行，他召來自己的奴僕，把產業託付給他們，</span>
<span className="v" id="v15" data-v="15" data-xref="馬太福音 18:24; 路加福音 19:13–14; 路加福音 12:48"> 按各人的才幹分別交給一個人五千銀幣，一個人兩千銀幣，一個人一千銀幣，然後便離開了。</span>
<span className="v" id="v16" data-v="16" data-xref="約翰三書 1:5–8; 提摩太前書 6:17–18; 提摩太後書 2:6"> 得到五千銀幣的立刻去做買賣，結果賺了五千。</span>
<span className="v" id="v17" data-v="17" data-xref="箴言 3:9–10; 以弗所書 5:16; 彼得前書 4:10"> 同樣，得到兩千銀幣的也賺了兩千。</span>
<span className="v" id="v18" data-v="18" data-xref="彼得後書 1:8; 哈該書 1:2–4; 瑪拉基書 1:10"> 可是得到一千銀幣的卻挖了一個洞，把主人的錢藏在地裡。</span>
<span className="v" id="v19" data-v="19" data-xref="哥林多前書 3:12–15; 哥林多後書 5:10; 羅馬書 14:7–12"> 過了很久，這些奴僕的主人回來了，要跟他們結帳。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行傳 20:24; 路加福音 19:16–17; 歌羅西書 1:29"> 得到五千銀幣的奴僕帶來了另外的五千，說，『主人，你交給我五千銀幣，請看，我又賺了五千。』</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="馬太福音 25:23; 路加福音 16:10; 約翰福音 12:26"> 「主人說，『做得好！你真是個又良善又忠心的奴僕。既然你在一點事上忠心，我要把更多的事交給你。進來分享你主人的快樂吧！』</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="哥林多後書 8:12; 哥林多後書 8:7–8; 哥林多後書 8:1–3"> 「得到兩千銀幣的奴僕也上前說，『主人，你交給我兩千銀幣，請看，我又賺了兩千。』</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="馬太福音 25:21; 馬可福音 14:8–9; 馬可福音 12:41–44"> 「主人說，『做得好！你真是個又良善又忠心的奴僕，既然你在一點事上忠心，我要把更多的事交給你。進來分享你主人的快樂吧！』</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="路加福音 19:20–22; 路加福音 15:29; 瑪拉基書 3:14–15"> 「得到一千銀幣的奴僕也上前說，『主人，我知道你為人苛刻，沒有播種的地方也要收割，沒有撒種的地方也要收穫。</span>
<span className="v" id="v25" data-v="25" data-xref="提摩太後書 1:6–7; 羅馬書 8:15; 啟示錄 21:8"> 我很害怕，就去把你的錢藏在地裡。請看，這是你的錢。』</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="馬太福音 18:32; 約伯記 15:5–6"> 「主人說，『你這又可惡又懶惰的奴僕！你既然知道我沒有播種的地方也要收割，沒有撒種的地方也要收穫，</span>
<span className="v" id="v27" data-v="27" data-xref="申命記 23:19–20; 羅馬書 3:19; 猶大書 1:15"> 就應該把錢存入錢莊，等我回來可以連本帶利還給我。』</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="路加福音 19:24; 路加福音 10:42"> 「『所以收回他的一千銀幣，給那個有一萬銀幣的奴僕。</span>
<span className="v" id="v29" data-v="29" data-xref="路加福音 8:18; 馬可福音 4:25; 馬太福音 13:12"> 因為凡有的，還要給他更多，讓他豐富有餘；凡沒有的，連他僅有的，也要奪去。</span>
<span className="v" id="v30" data-v="30" data-xref="馬太福音 8:12; 啟示錄 3:15–16; 馬太福音 13:50"> 把這沒用的奴僕扔進外面的黑暗裡，他必在那裡哀哭切齒。』</span>
</div>
</div>

## 末日的審判

<div className="bt">
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="啟示錄 1:7; 帖撒羅尼迦後書 1:7–8; 馬太福音 19:28"> 「當人子在祂的榮耀中與眾天使降臨的時候，祂要坐在祂榮耀的寶座上，</span>
<span className="v" id="v32" data-v="32" data-xref="瑪拉基書 3:18; 馬太福音 13:49; 哥林多後書 5:10"> 萬民要聚集在祂面前。祂要把他們分開，就像牧人把綿羊和山羊分開一樣。</span>
<span className="v" id="v33" data-v="33" data-xref="詩篇 100:3; 約翰福音 10:26–28; 約翰福音 21:15–17"> 祂要把綿羊放在右邊，山羊放在左邊。</span>
<span className="v" id="v34" data-v="34" data-xref="彼得前書 1:19–20; 雅各書 2:5; 啟示錄 21:7"> 那時，王會對右邊的人說，『我父所賜福的人啊，來承受創世以來為你們預備的國度吧。</span>
<span className="v" id="v35" data-v="35" data-xref="約翰一書 3:16–19; 雅各書 2:15–16; 申命記 15:7–11"> 因為我饑餓時，你們給我吃的；我口渴時，你們給我喝的；我身在異鄉時，你們接待我；</span>
<span className="v" id="v36" data-v="36" data-xref="雅各書 1:27; 提摩太後書 1:16–18; 雅各書 5:14–15"> 我赤身露體時，你們給我穿的；我生病時，你們照顧我；我坐牢時，你們來看我。』</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="馬太福音 6:3; 歷代志上 29:14; 彼得前書 5:5–6"> 「那些義人會回答說，『主啊！我們什麼時候見你餓了就給你吃的？見你渴了就給你喝的？</span>
<span className="v" id="v38" data-v="38"> 見你身在異鄉就接待你？見你赤身露體就給你穿的呢？</span>
<span className="v" id="v39" data-v="39"> 我們又什麼時候見你生病或坐牢，就去看你呢？』</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="箴言 19:17; 箴言 14:31; 馬太福音 10:42"> 「王會回答說，『我實在告訴你們，你們這樣對待我最卑微的一個弟兄，就是對待我了。』</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="彼得後書 2:4; 猶大書 1:6–7; 帖撒羅尼迦後書 1:9"> 「王又對左邊的人說，『你們這些被咒詛的人，走開！到專為魔鬼及其使者預備的永遠不滅的火裡去吧！</span>
<span className="v" id="v42" data-v="42" data-xref="雅各書 2:15–24; 約翰福音 5:23; 馬太福音 12:30"> 因為我饑餓時，你們不給我吃的；我口渴時，你們不給我喝的；</span>
<span className="v" id="v43" data-v="43"> 我身在異鄉時，你們不接待我；我赤身露體時，你們不給我衣服；我生病和我坐牢時，你們不來照顧我。』</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="馬太福音 7:22; 路加福音 10:29; 馬太福音 25:24–27"> 「他們會問，『主啊，我們什麼時候見你餓了，或渴了，或身在異鄉，或赤身露體，或病了，或坐牢，卻沒有幫助你呢？』</span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="箴言 21:13; 箴言 17:5; 箴言 14:31"> 「王會回答說，『我實在告訴你們，你們沒有幫助我最卑微的一個弟兄，就是沒有幫助我。』</span>
<span className="v" id="v46" data-v="46" data-xref="但以理書 12:2; 約翰福音 3:36; 約翰福音 5:29"> 這些人要受永遠的刑罰，但義人要得到永遠的生命。」</span>
</div>
</div>

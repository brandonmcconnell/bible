## 安息日的問題

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命記 23:25; 馬可福音 2:23–28; 路加福音 6:1–5"> 安息日的時候，耶穌經過一片麥田。祂的門徒餓了，便掐些麥穗吃。</span>
<span className="v" id="v2" data-v="2" data-xref="馬太福音 12:10; 約翰福音 7:21–24; 路加福音 14:3"> 法利賽人看見後，對耶穌說：「你看，你的門徒做了安息日不准做的事！」</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="撒母耳記上 21:3–6; 路加福音 6:3; 馬可福音 2:25–26"> 耶穌回答說：「你們沒有讀過大衛的事蹟嗎？當時他和隨從餓了，</span>
<span className="v" id="v4" data-v="4" data-xref="利未記 24:5–9; 出埃及記 25:30; 利未記 8:31"> 他進入上帝的殿，他們吃了獻給上帝的供餅。這餅只有祭司才可以吃，大衛和隨從是不准吃的。</span>
<span className="v" id="v5" data-v="5" data-xref="民數記 28:9–10; 約翰福音 7:22–23; 尼希米記 13:17"> 此外律法書又記載，在安息日，祭司在聖殿裡干犯安息日的規條也不算有罪。你們沒有讀過嗎？</span>
<span className="v" id="v6" data-v="6" data-xref="馬太福音 12:41–42; 歷代志下 6:18; 彼得前書 2:4–5"> 我告訴你們，這裡有一位比聖殿更偉大，</span>
<span className="v" id="v7" data-v="7" data-xref="何西阿書 6:6; 馬太福音 9:13; 彌迦書 6:6–8"> 如果你們明白『我要的是憐憫，而非祭物』<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="何西阿書6·6。">a</a></sup>這句經文的意義，就不會冤枉無辜了。</span>
<span className="v" id="v8" data-v="8" data-xref="馬可福音 2:28; 路加福音 6:5; 約翰福音 5:17–23"> 因為人子是安息日的主。」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="馬可福音 3:1–6; 路加福音 6:6–11"> 耶穌離開那裡，走進猶太人的會堂，</span>
<span className="v" id="v10" data-v="10" data-xref="路加福音 13:14; 約翰福音 9:16; 約翰福音 8:6"> 裡面有個人，一隻手是萎縮的。法利賽人企圖控告耶穌，就問祂：「在安息日可以醫病嗎？」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="申命記 22:4; 路加福音 14:5; 路加福音 13:15–17"> 耶穌回答說：「你們如果有一隻羊在安息日掉進坑裡，難道不把牠拉上來嗎？</span>
<span className="v" id="v12" data-v="12" data-xref="馬太福音 6:26; 路加福音 6:9; 馬可福音 3:4"> 人比羊要貴重多了！所以在安息日行善合情合理。」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="路加福音 13:13; 使徒行傳 3:7–8"> 然後，耶穌對那人說：「把手伸出來！」那人一伸手，手就復原了，跟另一隻手一樣健康。</span>
<span className="v" id="v14" data-v="14" data-xref="約翰福音 11:53; 約翰福音 10:39; 馬可福音 3:6"> 法利賽人卻走了出去，策劃怎樣除掉耶穌。</span>
</div>
</div>

## 上帝的僕人

<div className="bt">
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="馬可福音 3:7–12; 馬太福音 10:23; 馬太福音 19:2"> 耶穌知道了，就離開那裡。很多人跟隨祂，耶穌治好了所有患病的人，</span>
<span className="v" id="v16" data-v="16" data-xref="馬太福音 8:4; 馬太福音 9:30; 馬太福音 17:9"> 叮囑他們不要洩露祂的身分。</span>
<span className="v" id="v17" data-v="17" data-xref="以賽亞書 42:1–4; 以賽亞書 42:9; 馬太福音 13:35"> 這是要應驗以賽亞先知的話：</span>
<span className="v" id="v18" data-v="18" data-xref="以賽亞書 42:1; 路加福音 4:18; 使徒行傳 10:38"> <span className="pl pl-1">「看啊！我所揀選、</span><br /><span className="pl pl-1">所眷愛、所喜悅的僕人，</span><br /><span className="pl pl-1">我要將我的靈賜給祂，</span><br /><span className="pl pl-1">祂要向萬邦宣揚正義。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="馬太福音 11:29; 約翰福音 18:36–38; 提摩太後書 2:24–25"> <span className="pl pl-1">祂不爭競，不喧嚷，</span><br /><span className="pl pl-1">街上也聽不見祂的聲音。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="以賽亞書 42:3–4; 以西結書 34:16; 以賽亞書 61:1–3"> <span className="pl pl-1">壓傷的蘆葦，祂不折斷；</span><br /><span className="pl pl-1">將殘的燈火，祂不吹滅；</span><br /><span className="pl pl-1">祂終必使正義得勝。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="以賽亞書 11:10; 羅馬書 15:12–13; 以賽亞書 42:4"> <span className="pl pl-1">普世都要仰望祂的聖名。」</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="以賽亞書42·1‑4。">b</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="路加福音 11:14–15; 馬可福音 7:35–37; 以賽亞書 29:18"> 有人帶一個被鬼附身、又瞎又啞的人來見耶穌，耶穌便醫治他，使他能說能看。</span>
<span className="v" id="v23" data-v="23" data-xref="馬太福音 9:27; 約翰福音 4:29; 馬太福音 22:42–43"> 眾人都很驚奇，就說：「這人會不會是大衛的那個後裔？」</span>
<span className="v" id="v24" data-v="24" data-xref="馬可福音 3:22; 馬太福音 9:34; 路加福音 11:15"> 法利賽人聽見後卻說：「祂不過是靠鬼王別西卜趕鬼罷了。」</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="加拉太書 5:15; 耶利米書 17:10; 馬太福音 9:4"> 耶穌知道他們的心思，就說：「一個國內部自相紛爭，必然滅亡；一座城、一個家內部自相紛爭，必無法堅立。</span>
<span className="v" id="v26" data-v="26" data-xref="歌羅西書 1:13; 啟示錄 20:2–3; 約翰一書 5:19"> 若撒旦驅逐撒旦，就是自相紛爭，牠的國怎能維持呢？</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行傳 19:13–16; 馬可福音 9:38–39; 路加福音 9:49–50"> 我若是靠別西卜趕鬼，你們的子弟又是靠誰趕鬼呢？因此，他們要審判你們。</span>
<span className="v" id="v28" data-v="28" data-xref="路加福音 11:20; 但以理書 7:14; 馬太福音 6:33"> 但我若是靠上帝的靈趕鬼，就是上帝的國已降臨在你們中間了。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="以賽亞書 49:24; 馬可福音 3:27; 路加福音 11:21–22"> 「人如何進入壯漢家裡搶奪他的財物呢？除非先把那壯漢捆綁起來，才能搶劫他的家。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="馬可福音 9:40; 路加福音 11:23; 約書亞記 24:15"> 「誰不與我為友，就是與我為敵；誰不和我一起收聚，就是在拆散。</span>
<span className="v" id="v31" data-v="31" data-xref="路加福音 12:10; 馬可福音 3:28–30; 希伯來書 10:29"> 所以我告訴你們，一切罪和褻瀆的話都可以得到赦免，但褻瀆聖靈的罪必得不到赦免。</span>
<span className="v" id="v32" data-v="32" data-xref="馬可福音 3:29; 希伯來書 10:26–29; 希伯來書 6:4–6"> 說話得罪人子的，還可以得到赦免；但說話冒犯聖靈的，今生永世都得不到赦免。</span>
</div>
</div>

## 樹與果

<div className="bt">
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="路加福音 6:43–44; 馬太福音 7:16–20; 雅各書 4:8"> 「好樹結好果子，壞樹結壞果子，看果子就能知道樹的好壞。</span>
<span className="v" id="v34" data-v="34" data-xref="路加福音 6:45; 馬太福音 15:18; 以弗所書 4:29"> 你們這些毒蛇的後代！你們既然邪惡，又怎能講出好話呢？因為心裡充滿的，口裡自然會說出來。</span>
<span className="v" id="v35" data-v="35" data-xref="箴言 15:4; 歌羅西書 4:6; 箴言 15:28"> 善人心存良善，就從他裡面發出良善；惡人心存邪惡，就從他裡面發出邪惡。</span>
<span className="v" id="v36" data-v="36" data-xref="傳道書 12:14; 羅馬書 2:16; 啟示錄 20:12"> 我告訴你們，在審判之日，人將為自己所說的每一句閒話負責，</span>
<span className="v" id="v37" data-v="37" data-xref="箴言 13:3; 雅各書 2:21–25"> 因為將憑你口中的話來判斷你是否有罪。」</span>
</div>
</div>

## 求神蹟

<div className="bt">
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="哥林多前書 1:22; 馬可福音 8:11–12; 路加福音 11:16"> 當時，有幾個律法教師和法利賽人對耶穌說：「老師，我們想要看你行個神蹟。」</span>
<span className="v" id="v39" data-v="39" data-xref="馬太福音 16:4; 路加福音 11:29–32; 馬可福音 8:38"> 耶穌回答說：「一個邪惡淫亂的世代想看神蹟，但除了約拿先知的神蹟以外，再沒有神蹟給他們看。</span>
<span className="v" id="v40" data-v="40" data-xref="約拿書 1:17; 馬太福音 27:63–64; 馬太福音 16:21"> 約拿在大魚腹中三日三夜，人子也要在地裡三日三夜。</span>
<span className="v" id="v41" data-v="41" data-xref="馬太福音 12:42; 希伯來書 11:7; 馬太福音 12:6"> 在審判的日子，尼尼微人要起來<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="「起來」或作「復活」。">c</a></sup>定這個世代的罪，因為他們聽到約拿的宣告，就悔改了。看啊！這裡有一位比約拿更大。</span>
<span className="v" id="v42" data-v="42" data-xref="列王紀上 10:1–13; 歷代志下 9:1–12; 希伯來書 1:2–4"> 在審判的日子，南方的女王和這世代的人都要起來，她要定這個世代的罪，因為她曾不遠千里來聽所羅門王的智言慧語。看啊！這裡有一位比所羅門王更大。</span>
</div>
</div>

## 乘虛而入

<div className="bt">
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="路加福音 11:24–26; 路加福音 8:28–32; 馬太福音 8:29"> 「有個污鬼離開了牠所附的人，在乾旱無水之地四處遊蕩，尋找安歇之處，卻沒有找到。</span>
<span className="v" id="v44" data-v="44" data-xref="約翰一書 4:4; 啟示錄 13:8–9; 猶大書 1:4–5"> 於是牠說，『我要回到老地方。』牠回去後，看見裡面空著，打掃得又乾淨又整齊，</span>
<span className="v" id="v45" data-v="45" data-xref="路加福音 11:26; 馬可福音 5:9; 希伯來書 6:4–8"> 就去帶來七個比自己更邪惡的鬼一起住在那裡。那人的下場比從前更慘了。這個邪惡的世代也會這樣。」</span>
</div>
</div>

## 真正的親屬

<div className="bt">
<div className="bp">

<span className="v" id="v47" data-v="47"> 有人告訴祂：「你的母親和兄弟站在外面有話要跟你說。」</span>
</div>
<div className="bp">
<span className="v" id="v48" data-v="48" data-xref="馬可福音 3:32–33; 馬太福音 10:37; 路加福音 2:52"> 耶穌說：「誰是我的母親？誰是我的兄弟？」</span>

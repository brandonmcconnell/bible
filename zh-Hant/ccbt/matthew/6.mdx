## 論賙濟窮人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="馬太福音 23:5; 約翰福音 12:43; 希伯來書 6:10"> 「你們要小心，行義的時候不可張揚，故意叫人看見，否則就不能得你們天父的賞賜了。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="馬太福音 6:5; 馬太福音 6:16; 哥林多後書 9:6–15"> 「因此，賙濟窮人的時候，不要大吹大擂，像那些偽君子在會堂和街市上所行的一樣，以博取人們的讚賞。我實在告訴你們，他們得到的賞賜僅此而已。</span>
<span className="v" id="v3" data-v="3" data-xref="約翰福音 7:4; 馬太福音 9:30; 馬可福音 1:44"> 你們賙濟窮人的時候，右手所做的別叫左手知道，</span>
<span className="v" id="v4" data-v="4" data-xref="馬太福音 6:18; 馬太福音 6:6; 耶利米書 17:10"> 要不聲不響地去做。這樣，鑒察隱祕事的天父必賞賜你們。</span>
</div>
</div>

## 論禱告

<div className="bt">
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="路加福音 18:10–11; 馬太福音 6:2; 路加福音 18:13"> 「你們禱告時，不要像偽君子那樣。他們喜歡站在會堂裡和十字路口上公開禱告，故意讓人看見。我實在告訴你們，他們得到的賞賜不過是人的讚賞。</span>
<span className="v" id="v6" data-v="6" data-xref="列王紀下 4:33; 馬太福音 14:23; 以賽亞書 65:24"> 你們禱告的時候，要進入內室，關上門，向你們肉眼看不見的父祈禱，鑒察隱祕事的父必賞賜你們。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="傳道書 5:2–3; 傳道書 5:7; 列王紀上 18:26–29"> 「你們禱告時不可像外族人那樣喋喋不休，他們以為長篇大論，就必蒙垂聽。</span>
<span className="v" id="v8" data-v="8" data-xref="馬太福音 6:32; 路加福音 12:30; 腓立比書 4:6"> 不可像他們那樣，因為在你們祈求以前，你們的父已經知道你們的需要了。</span>
</div>
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="路加福音 11:1–4; 啟示錄 4:11; 羅馬書 8:15"> 「你們應當這樣禱告，<br /><span className="pl pl-1">「『我們天上的父，</span><br /><span className="pl pl-1">願你的聖名被尊崇，</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="希伯來書 10:36; 馬太福音 26:42; 馬太福音 12:50"> <span className="pl pl-1">願你的國度降臨，</span><br /><span className="pl pl-1">願你的旨意在地上成就，就像在天上成就一樣。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="箴言 30:8; 路加福音 11:3; 馬太福音 4:4"> <span className="pl pl-1">求你今天賜給我們日用的飲食。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="以弗所書 4:32; 馬可福音 11:25; 以弗所書 1:7"> <span className="pl pl-1">饒恕我們的罪，</span><br /><span className="pl pl-1">就像我們饒恕了得罪我們的人。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="哥林多前書 10:13; 啟示錄 7:14–17; 馬太福音 26:41"> <span className="pl pl-1">不要讓我們陷入誘惑，</span><br /><span className="pl pl-1">救我們脫離那惡者。</span><br /><span className="pl pl-1">因為國度、權柄、榮耀都是你的，直到永遠。阿們！』</span></span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="以弗所書 4:32; 馬可福音 11:25; 歌羅西書 3:13"> 「如果你們饒恕別人的過犯，你們的天父也必饒恕你們的過犯。</span>
<span className="v" id="v15" data-v="15" data-xref="馬太福音 18:35"> 如果你們不饒恕別人的過犯，你們的天父也不會饒恕你們的過犯。</span>
</div>
</div>

## 論禁食

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="以賽亞書 58:3–5; 馬太福音 9:14–15; 但以理書 9:3"> 「你們禁食的時候，不要像偽君子那樣愁眉苦臉，因為他們故意蓬頭垢面，好讓別人知道他們在禁食。我實在告訴你們，他們得到的賞賜不過是人的讚賞。</span>
<span className="v" id="v17" data-v="17" data-xref="路得記 3:3; 傳道書 9:8; 撒母耳記下 12:20"> 你禁食的時候要梳頭洗臉，</span>
<span className="v" id="v18" data-v="18" data-xref="馬太福音 6:6; 馬太福音 6:4; 哥林多後書 10:18"> 不叫人們看出你在禁食，只讓你肉眼看不見的父知道，鑒察隱祕事的父必賞賜你。</span>
</div>
</div>

## 論積財

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="希伯來書 13:5; 約翰一書 2:15–16; 路加福音 12:21"> 「不要為自己在世上積攢財寶，世上有蟲子咬，會生銹，又有賊闖進來偷。</span>
<span className="v" id="v20" data-v="20" data-xref="路加福音 12:33; 馬太福音 19:21; 雅各書 2:5"> 你們要把財寶積攢在天上，天上沒有蟲子咬，不會生銹，也沒有賊闖進來偷。</span>
<span className="v" id="v21" data-v="21" data-xref="歌羅西書 3:1–3; 路加福音 12:34; 哥林多後書 4:18"> 要知道，你的財寶在哪裡，你的心也在哪裡。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="路加福音 11:34–36; 哥林多後書 11:3; 歌羅西書 3:22"> 「眼睛是身體的燈。你的眼睛若明亮，全身就光明；</span>
<span className="v" id="v23" data-v="23" data-xref="約翰一書 2:11; 馬太福音 6:22; 以賽亞書 5:20–21"> 你的眼睛若昏花<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「昏花」或作「邪惡」。">a</a></sup>，全身就黑暗。如果你裡面的光黑暗了，那黑暗是多麼大啊！</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="約翰一書 2:15–16; 路加福音 16:13; 雅各書 4:4"> 「一個人不能服侍兩位主人，因為他不是恨這位、愛那位，就是重這位、輕那位。你們不能又事奉上帝，又事奉金錢。</span>
</div>
</div>

## 不要憂慮衣食

<div className="bt">
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="腓立比書 4:6; 彼得前書 5:7; 羅馬書 8:32"> 「所以我告訴你們，不要為生活憂慮，比如吃什麼、喝什麼，也不要為身體憂慮，比如穿什麼。難道生命不比飲食重要嗎？身體不比穿著重要嗎？</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="馬太福音 10:29–31; 詩篇 147:9; 路加福音 12:24–32"> 「你們看天上的飛鳥，牠們不種，不收，也不在倉裡積存糧食，你們的天父尚且養活牠們，難道你們還不如飛鳥貴重嗎？</span>
<span className="v" id="v27" data-v="27" data-xref="路加福音 12:25–26; 傳道書 3:14; 詩篇 39:5–6"> 你們誰能用憂慮使自己多活片刻呢？</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="馬太福音 6:25; 腓立比書 4:6; 路加福音 12:27"> 「何必為穿著憂慮呢？你們看看野地的百合花是如何生長的，它們既不勞苦，也不紡織。</span>
<span className="v" id="v29" data-v="29" data-xref="歷代志下 9:20–22; 歷代志下 9:4–6; 彼得前書 3:2–5"> 但我告訴你們，就連所羅門王最顯赫時的穿戴還不如一朵百合花！</span>
<span className="v" id="v30" data-v="30" data-xref="馬太福音 14:31; 路加福音 12:28; 彼得前書 1:24"> 你們的信心太小了！野地的草今天還在，明天就被扔進爐中，上帝還這樣裝扮它們，何況你們呢？</span>
<span className="v" id="v31" data-v="31" data-xref="彼得前書 5:7; 路加福音 12:29; 馬太福音 4:4"> 所以，你們不要憂慮『吃什麼？喝什麼？穿什麼？』</span>
<span className="v" id="v32" data-v="32" data-xref="馬太福音 6:8; 路加福音 12:30; 以弗所書 4:17"> 因為這些都是外族人的追求，你們的天父知道你們的需要。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="路加福音 12:31; 馬太福音 5:6; 約翰福音 6:27"> 「你們要先尋求上帝的國和祂的義，這一切都會賜給你們。</span>
<span className="v" id="v34" data-v="34" data-xref="馬太福音 6:25; 約翰福音 14:27; 希伯來書 13:5–6"> 所以，不要為明天憂慮，因為明天自有明天的憂慮，一天的難處一天擔就夠了。</span>
</div>
</div>

## 撒種的比喻

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 8:4–10; 馬太福音 13:1–15; 馬可福音 4:1–12"> 當天，耶穌離開房子，坐在湖邊。</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 5:3; 馬太福音 4:25; 馬可福音 4:1"> 有一大群人聚集到祂周圍，祂只好上船坐下，眾人都站在岸上。</span>
<span className="v" id="v3" data-v="3" data-xref="馬可福音 4:2–9; 馬可福音 4:13; 詩篇 78:2"> 祂用比喻給他們講許多道理，說：「有一個農夫出去撒種。</span>
<span className="v" id="v4" data-v="4" data-xref="馬太福音 13:18–19"> 撒種的時候，有些種子落在路旁，被飛鳥吃掉了；</span>
<span className="v" id="v5" data-v="5" data-xref="以西結書 11:19; 以西結書 36:26; 撒迦利亞書 7:12"> 有些落在石頭地上，因為泥土不深，種子很快就發芽了，</span>
<span className="v" id="v6" data-v="6" data-xref="馬太福音 13:21; 雅各書 1:11–12; 歌羅西書 1:23"> 然而因為沒有根，被太陽一曬，就枯萎了；</span>
<span className="v" id="v7" data-v="7" data-xref="馬可福音 4:18–19; 耶利米書 4:3–4; 創世記 3:18"> 有些落在荊棘叢中，荊棘長起來便把幼苗擠住了；</span>
<span className="v" id="v8" data-v="8" data-xref="馬太福音 13:23; 路加福音 8:15; 創世記 26:12"> 有些落在沃土裡，就結出果實，有的多達一百倍，有的六十倍，有的三十倍。</span>
<span className="v" id="v9" data-v="9" data-xref="啟示錄 2:11; 馬太福音 11:15; 啟示錄 2:7"> 有耳朵的，都應當聽。」</span>
</div>
</div>

## 用比喻的目的

<div className="bt">
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="馬可福音 4:33–34; 馬可福音 4:10"> 門徒上前問耶穌：「你為什麼要用比喻來教導他們呢？」</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多前書 2:9–10; 哥林多前書 2:14; 馬太福音 19:11"> 耶穌回答說：「天國的奧祕只讓你們知道，不讓他們知道。</span>
<span className="v" id="v12" data-v="12" data-xref="馬太福音 25:29; 馬可福音 4:24–25; 路加福音 8:18"> 因為凡有的，還要給他更多，讓他豐富有餘；凡沒有的，連他僅有的也要奪去。</span>
<span className="v" id="v13" data-v="13" data-xref="以西結書 12:2; 耶利米書 5:21; 以賽亞書 42:18–20"> 我用比喻教導他們是因為他們視而不見，聽而不聞，聞而不悟。</span>
<span className="v" id="v14" data-v="14" data-xref="以賽亞書 6:9–10; 以西結書 12:2; 哥林多後書 3:14"> 以賽亞的預言正應驗在他們身上，<br /><span className="pl pl-1">「『你們聽了又聽，卻不明白；</span><br /><span className="pl pl-1">看了又看，卻不領悟。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="以賽亞書 6:10; 馬可福音 4:12; 撒迦利亞書 7:11"> <span className="pl pl-1">因為這些人心靈麻木，</span><br /><span className="pl pl-1">耳朵發背，眼睛昏花，</span><br /><span className="pl pl-1">以致眼睛看不見，耳朵聽不見，</span><br /><span className="pl pl-1">心裡不明白，無法回心轉意，</span><br /><span className="pl pl-1">得不到我的醫治。』</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="以賽亞書6·9、10。">a</a></sup></span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 10:23–24; 以弗所書 1:17–18; 馬太福音 16:17"> 「但你們的眼睛是有福的，因為看得見；你們的耳朵也是有福的，因為聽得見。</span>
<span className="v" id="v17" data-v="17" data-xref="約翰福音 8:56; 希伯來書 11:13; 彼得前書 1:10–12"> 我實在告訴你們，以前有許多先知和義人曾渴望看見你們所看見的，聽見你們所聽見的，卻未能如願。</span>
</div>
</div>

## 解釋比喻

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="馬太福音 13:11–12; 路加福音 8:11–15; 馬可福音 4:13–20"> 「所以，你們應當留心這撒種的比喻。</span>
<span className="v" id="v19" data-v="19" data-xref="路加福音 8:11–15; 馬太福音 13:38; 希伯來書 2:1"> 種子落在路旁，是指人聽了天國的道理卻不明白，魔鬼乘虛而入，把撒在他心裡的奪走了。</span>
<span className="v" id="v20" data-v="20" data-xref="以西結書 33:31–32; 詩篇 106:12–13; 約翰福音 5:35"> 種子落在石頭地上，是指人聽了道後，立刻歡喜地接受了，</span>
<span className="v" id="v21" data-v="21" data-xref="馬太福音 11:6; 彼得後書 1:8–9; 以弗所書 3:17"> 但他們心裡沒有根基，不過是暫時接受，一旦為道遭受患難或迫害，就立刻放棄了。</span>
<span className="v" id="v22" data-v="22" data-xref="提摩太前書 6:17; 路加福音 8:14; 提摩太前書 6:9–10"> 種子落在荊棘叢中，是指人雖然聽過道，但生活的憂慮和錢財的迷惑把道擠住了，以致不能結出果實。</span>
<span className="v" id="v23" data-v="23" data-xref="腓立比書 1:11; 馬太福音 12:33; 約翰福音 15:16"> 種子落在沃土裡，是指人聽了道，並明白了道，就結出果實，有的多達一百倍，有的六十倍，有的三十倍。」</span>
</div>
</div>

## 毒麥的比喻

<div className="bt">
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="馬太福音 25:1; 馬太福音 13:47; 馬太福音 20:1"> 耶穌又給他們講了一個比喻，說：「天國就像一個人，將好種子撒在田裡。</span>
<span className="v" id="v25" data-v="25" data-xref="彼得前書 5:8; 彼得後書 2:1; 使徒行傳 20:30–31"> 人們睡覺的時候，仇敵過來把毒麥撒在他的麥田裡，就走了。</span>
<span className="v" id="v26" data-v="26" data-xref="馬可福音 4:26–29"> 當麥子長苗吐穗時，毒麥也長起來了。</span>
<span className="v" id="v27" data-v="27" data-xref="羅馬書 16:17; 哥林多後書 6:1; 哥林多後書 5:18–20"> 奴僕看見了就來對主人說，『主人啊！你不是把好種子撒在田裡了嗎？從哪裡來的毒麥呢？』</span>
<span className="v" id="v28" data-v="28" data-xref="哥林多前書 5:3–7; 帖撒羅尼迦前書 5:14; 路加福音 9:49–54"> 「主人回答說，『這是仇敵做的。』奴僕問道，『要我們去拔掉它們嗎？』</span>
<span className="v" id="v29" data-v="29"> 「主人說，『不用了，因為拔毒麥會連麥子一起拔掉。</span>
<span className="v" id="v30" data-v="30" data-xref="馬太福音 3:12; 提摩太前書 5:24; 哥林多前書 4:5"> 讓它們一起生長吧。到收割的時候，我會吩咐收割的工人先把毒麥拔出來，紮成捆，留著燒，然後將麥子存入穀倉。』」</span>
</div>
</div>

## 芥菜種和麵酵的比喻

<div className="bt">
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="路加福音 13:18–19; 馬太福音 17:20; 馬可福音 4:30–32"> 耶穌又給他們講了一個比喻：「天國就像一粒芥菜種，人把它種在田裡。</span>
<span className="v" id="v32" data-v="32" data-xref="以西結書 31:6; 但以理書 4:12; 以西結書 17:23–24"> 它雖然是種子中最小的，長起來之後卻比其他蔬菜都大，並且長成一棵樹，飛鳥也來在它枝頭棲息。」</span>
<span className="v" id="v33" data-v="33" data-xref="加拉太書 5:9; 哥林多前書 5:6–7; 路加福音 13:21"> 祂又給他們講了個比喻：「天國就像麵酵，婦人拿來摻在三斗麵裡，直到整團麵都發起來。」</span>
<span className="v" id="v34" data-v="34" data-xref="馬可福音 4:33–34; 約翰福音 16:25; 馬太福音 13:13"> 耶穌用比喻對眾人講這些事，祂每次對他們講話時都用比喻。</span>
<span className="v" id="v35" data-v="35" data-xref="詩篇 78:2; 以弗所書 3:9; 彼得前書 1:20–21"> 這是要應驗先知的話：「我要開口講比喻，道出創世以來隱藏的事。」<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="詩篇78·2。">b</a></sup></span>
</div>
</div>

## 解釋毒麥的比喻

<div className="bt">
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="約翰福音 16:17–20; 馬太福音 13:11; 馬太福音 9:28"> 後來，耶穌離開人群，進到屋裡。門徒來到祂面前，說：「請給我們解釋田間毒麥的比喻。」</span>
<span className="v" id="v37" data-v="37" data-xref="哥林多前書 3:5–7; 馬太福音 13:41; 路加福音 10:16"> 耶穌說：「那撒下好種子的就是人子，</span>
<span className="v" id="v38" data-v="38" data-xref="約翰福音 8:44; 腓立比書 3:18–19; 使徒行傳 13:10"> 麥田代表世界，那些好種子就是天國的子民。毒麥就是那些屬魔鬼的人，</span>
<span className="v" id="v39" data-v="39" data-xref="馬太福音 13:49; 啟示錄 14:15–19; 馬太福音 25:31"> 撒毒麥的仇敵就是魔鬼。收割的日子便是世界的末日，收割的工人就是天使。</span>
<span className="v" id="v40" data-v="40" data-xref="馬太福音 13:39"> 「毒麥怎樣被拔出來扔進火裡燒，在世界末日的時候也是一樣，</span>
<span className="v" id="v41" data-v="41" data-xref="馬太福音 24:31; 馬太福音 18:7; 彼得後書 2:1–2"> 人子將派天使把一切引人犯罪的和作惡的從祂國裡挑出來，</span>
<span className="v" id="v42" data-v="42" data-xref="馬太福音 13:50; 路加福音 16:23–24; 馬太福音 8:12"> 扔進火爐裡。他們將在那裡哀哭切齒。</span>
<span className="v" id="v43" data-v="43" data-xref="但以理書 12:3; 馬太福音 11:15; 路加福音 12:32"> 那時，義人在他們天父的國度要像太陽一樣發出光輝。有耳朵的，都應當聽。</span>
</div>
</div>

## 寶藏與珍珠的比喻

<div className="bt">
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="箴言 2:2–5; 歌羅西書 2:3; 腓立比書 3:7–9"> 「天國就像藏在地裡的寶貝，有人發現了，就把它埋好，然後歡然變賣他所有的財產去買那塊地。</span>
<span className="v" id="v45" data-v="45" data-xref="箴言 3:13–18; 馬太福音 16:26; 馬太福音 13:24"> 「天國又像一個四處搜購貴重珍珠的商人。</span>
<span className="v" id="v46" data-v="46" data-xref="以弗所書 3:8; 路加福音 18:28–30; 箴言 2:4"> 他找到一顆極貴重的珍珠，就去變賣了一切產業，把它買下來。</span>
</div>
</div>

## 撒網的比喻

<div className="bt">
<div className="bp">
<span className="v" id="v47" data-v="47" data-xref="約翰福音 15:6; 提摩太後書 3:2–5; 馬太福音 22:9–10"> 「天國又像一張漁網，撒在海裡捕到了各種魚。</span>
<span className="v" id="v48" data-v="48" data-xref="馬太福音 13:30; 馬太福音 13:40–43; 馬太福音 3:12"> 網滿了，人們把網拉上岸，然後坐下來挑選，好的就收進筐裡，不好的就丟掉。</span>
<span className="v" id="v49" data-v="49" data-xref="啟示錄 20:12–15; 馬太福音 24:31; 馬太福音 13:39"> 世界末日的時候也是這樣。天使必把惡人從義人中揀出來，</span>
<span className="v" id="v50" data-v="50" data-xref="馬太福音 13:42; 馬太福音 8:12; 啟示錄 14:10–11"> 扔進火爐裡，他們將在那裡哀哭切齒。</span>
<span className="v" id="v51" data-v="51" data-xref="馬太福音 13:19; 馬太福音 13:11; 馬可福音 4:34"> 你們明白這些事了嗎？」 他們回答說：「明白了。」</span>
<span className="v" id="v52" data-v="52" data-xref="約翰一書 2:7–8; 提摩太後書 3:16–17; 提多書 1:9"> 耶穌說：「律法教師成為天國的門徒後，就像一個家主從他的庫房裡拿出新的和舊的東西來。」</span>
</div>
</div>

## 拿撒勒人厭棄耶穌

<div className="bt">
<div className="bp">
<span className="v" id="v53" data-v="53" data-xref="馬太福音 7:28; 馬可福音 4:33–35"> 耶穌講完了這些比喻，就離開那裡，</span>
<span className="v" id="v54" data-v="54" data-xref="馬太福音 7:28; 約翰福音 7:15–16; 馬可福音 6:1–6"> 回到自己的家鄉，在會堂裡教導人。人們很驚奇，說：「這個人從哪裡得到如此的智慧和異能呢？</span>
<span className="v" id="v55" data-v="55" data-xref="約翰福音 6:42; 馬可福音 6:3; 路加福音 3:23"> 這不是那木匠的兒子嗎？祂母親不是瑪麗亞嗎？祂的弟弟不是雅各、約瑟、西門和猶大嗎？</span>
<span className="v" id="v56" data-v="56"> 祂的妹妹們不也都在我們這裡嗎？祂究竟從哪裡得了這些能力呢？」</span>
<span className="v" id="v57" data-v="57" data-xref="約翰福音 4:44; 馬太福音 11:6; 路加福音 4:24"> 他們就對祂很反感。 耶穌對他們說：「先知到處受人尊敬，只有在本鄉本家例外。」</span>
<span className="v" id="v58" data-v="58" data-xref="馬可福音 6:5–6; 羅馬書 11:20; 希伯來書 3:12–19"> 因為他們不信，耶穌就沒有在那裡多行神蹟。</span>
</div>

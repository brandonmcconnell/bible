## 傳統與誡命

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="馬可福音 3:22; 馬太福音 23:2; 路加福音 5:21"> 有幾個法利賽人和律法教師從耶路撒冷來質問耶穌：</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 11:38; 馬可福音 7:2; 歌羅西書 2:20–23"> 「為什麼你的門徒吃飯前不行洗手禮，破壞祖先的傳統呢？」</span>
<span className="v" id="v3" data-v="3" data-xref="歌羅西書 2:23; 提多書 1:14; 歌羅西書 2:8"> 耶穌回答說：「為什麼你們因拘守傳統而違背上帝的誡命呢？</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及記 20:12; 利未記 20:9; 出埃及記 21:17"> 上帝說，『要孝敬父母』<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="出埃及記20·12；申命記5·16。">a</a></sup>，又說，『咒罵父母的，必被處死。』<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="出埃及記21·17；利未記20·9。">b</a></sup></span>
<span className="v" id="v5" data-v="5" data-xref="馬可福音 7:10–13; 使徒行傳 5:29; 馬太福音 23:16–18"> 你們卻說，『人如果宣佈把供養父母的錢奉獻給上帝，</span>
<span className="v" id="v6" data-v="6" data-xref="提摩太前書 5:8; 耶利米書 8:8; 馬可福音 7:13"> 他就不必孝敬父母了。』你們這是用傳統來廢掉上帝的誡命。</span>
<span className="v" id="v7" data-v="7" data-xref="馬可福音 7:6; 馬太福音 23:23–29; 使徒行傳 28:25–27"> 你們這些偽君子，以賽亞針對你們說的預言一點沒錯，</span>
<span className="v" id="v8" data-v="8" data-xref="以賽亞書 29:13; 以西結書 33:31; 使徒行傳 8:21"> <span className="pl pl-1">「『這些人嘴上尊崇我，</span><br /><span className="pl pl-1">心卻遠離我，</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="以賽亞書 29:13; 馬可福音 7:7; 提摩太前書 1:4"> <span className="pl pl-1">他們的教導無非是人的規條，</span><br /><span className="pl pl-1">他們敬拜我也是枉然。』</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="以賽亞書29·13。">c</a></sup><br /><span className="pl pl-1">」</span></span>
<span className="v" id="v10" data-v="10" data-xref="馬可福音 7:14–15; 路加福音 20:45–47; 路加福音 24:45"> 耶穌召集了眾人，對他們說：「你們要聽，也要明白。</span>
<span className="v" id="v11" data-v="11" data-xref="馬可福音 7:15; 馬太福音 15:18–20; 雅各書 3:5–8"> 入口的東西不會使人污穢，從口中出來的才會使人污穢。」</span>
<span className="v" id="v12" data-v="12" data-xref="列王紀上 22:13–14; 哥林多前書 10:32–33; 加拉太書 2:5"> 門徒上前對祂說：「你知道嗎？法利賽人聽見你的話很反感。」</span>
<span className="v" id="v13" data-v="13" data-xref="約翰福音 15:2; 以賽亞書 60:21; 約翰福音 15:6"> 耶穌回答說：「凡不是我天父栽種的都要被連根拔起來。</span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 6:39; 以賽亞書 56:10; 馬太福音 23:16–24"> 隨便他們吧！他們是瞎眼的嚮導。瞎眼的給瞎眼的領路，二人都會掉進坑裡。」</span>
<span className="v" id="v15" data-v="15" data-xref="馬太福音 13:36; 馬可福音 4:34; 約翰福音 16:29"> 彼得對耶穌說：「請給我們解釋一下這個比喻。」</span>
<span className="v" id="v16" data-v="16" data-xref="馬太福音 16:9; 馬可福音 7:18; 馬可福音 9:32"> 耶穌說：「你們也還是這樣糊塗嗎？</span>
<span className="v" id="v17" data-v="17" data-xref="路加福音 6:45; 哥林多前書 6:13; 馬太福音 7:19–20"> 豈不知入口的東西都是進到肚子裡，然後排進廁所嗎？</span>
<span className="v" id="v18" data-v="18" data-xref="箴言 15:28; 馬太福音 12:34; 雅各書 3:6–10"> 可是，從口中出來的乃是發自內心，會使人污穢。</span>
<span className="v" id="v19" data-v="19" data-xref="馬可福音 7:21–23; 加拉太書 5:19–21; 耶利米書 17:9"> 因為從心裡出來的有惡念、謀殺、通姦、淫亂、偷盜、假見證和毀謗，</span>
<span className="v" id="v20" data-v="20" data-xref="馬可福音 7:3–4; 以弗所書 5:3–6; 哥林多前書 6:18–20"> 這些東西才使人污穢。不洗手吃飯並不會使人污穢。」</span>
</div>
</div>

## 迦南婦人的信心

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="馬可福音 7:24–30; 馬太福音 11:21–23; 士師記 1:31"> 耶穌從那裡退到泰爾和西頓境內。</span>
<span className="v" id="v22" data-v="22" data-xref="馬太福音 9:27; 馬可福音 7:25–26; 馬太福音 17:15"> 那地方有個迦南的婦人前來大聲懇求耶穌：「主啊！大衛的後裔啊！可憐我吧！我的女兒被鬼附身，受盡折磨！」</span>
<span className="v" id="v23" data-v="23" data-xref="馬太福音 14:15; 馬可福音 10:47–48; 耶利米哀歌 3:8"> 耶穌卻一言不答。門徒上前求祂說：「請讓她走吧！她老是在我們後面喊叫。」</span>
<span className="v" id="v24" data-v="24" data-xref="馬太福音 10:5–6; 羅馬書 15:8; 耶利米書 50:6–7"> 耶穌說：「我奉差遣只是來尋找以色列家迷失的羊。」</span>
<span className="v" id="v25" data-v="25" data-xref="創世記 32:26; 馬太福音 20:31; 馬太福音 14:33"> 那婦人上前跪下，說：「主啊！求你幫幫我吧！」</span>
<span className="v" id="v26" data-v="26" data-xref="馬可福音 7:27–28; 馬太福音 7:6; 腓立比書 3:2"> 耶穌答道：「把兒女的食物丟給狗吃，不合適。」</span>
<span className="v" id="v27" data-v="27" data-xref="以弗所書 3:8; 路加福音 16:21; 約伯記 40:4–5"> 婦人說：「主啊，不錯，可是狗也吃主人飯桌上掉下來的碎渣呀！」</span>
<span className="v" id="v28" data-v="28" data-xref="馬可福音 9:23–24; 馬太福音 8:13; 詩篇 145:19"> 耶穌說：「婦人，你的信心真大！我答應你的要求。」就在那一刻，她女兒痊癒了。</span>
</div>
</div>

## 耶穌使四千人吃飽

<div className="bt">
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="馬太福音 4:18; 約翰福音 6:1; 馬太福音 5:1"> 耶穌離開那裡，來到加利利湖邊，上了山，在那裡坐下。</span>
<span className="v" id="v30" data-v="30" data-xref="路加福音 6:17–19; 使徒行傳 5:15–16; 馬太福音 14:35–36"> 大群的人把瘸腿的、瞎眼的、殘疾的、啞巴及許多別的病人帶來，放在祂腳前，祂就醫治了他們。</span>
<span className="v" id="v31" data-v="31" data-xref="馬太福音 9:8; 路加福音 18:43; 路加福音 17:15–18"> 眾人看見啞巴說話，殘疾的復原，瘸腿的走路，瞎眼的看見，都很驚奇，就讚美以色列的上帝。</span>
<span className="v" id="v32" data-v="32" data-xref="使徒行傳 27:33; 路加福音 12:29–30; 馬太福音 9:36"> 耶穌把門徒召集過來，對他們說：「我憐憫這些人，他們跟我在一起已經三天，沒有任何吃的。我不願讓他們餓著肚子回去，以免他們在路上體力不支。」</span>
<span className="v" id="v33" data-v="33" data-xref="馬可福音 6:37; 馬太福音 14:15; 馬可福音 8:4–5"> 門徒說：「在這荒郊野外，我們到哪裡找足夠的食物給這麼多人吃呢？」</span>
<span className="v" id="v34" data-v="34" data-xref="馬太福音 16:9–10; 路加福音 24:41–42; 約翰福音 21:9–10"> 耶穌問：「你們有多少餅？」 門徒答道：「七個，還有幾條小魚。」</span>
<span className="v" id="v35" data-v="35" data-xref="路加福音 9:14–16; 馬可福音 6:39–40; 約翰福音 6:10"> 耶穌便吩咐眾人坐在地上。</span>
<span className="v" id="v36" data-v="36" data-xref="路加福音 22:19; 羅馬書 14:6; 約翰福音 6:11"> 祂拿著那七個餅和幾條魚祝謝後，掰開，遞給門徒，門徒再分給眾人。</span>
<span className="v" id="v37" data-v="37" data-xref="馬可福音 8:19–21; 馬太福音 16:9–10; 馬太福音 15:33"> 大家都吃了，並且吃飽了，剩下的零碎裝滿了七個筐子。</span>
<span className="v" id="v38" data-v="38"> 當時吃飯的，除了婦女和小孩，共有四千男人。</span>
<span className="v" id="v39" data-v="39" data-xref="馬可福音 8:10; 馬太福音 14:22"> 耶穌遣散眾人以後，就坐船去了馬加丹地區。</span>
</div>

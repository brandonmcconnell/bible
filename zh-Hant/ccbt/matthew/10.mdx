## 差遣使徒

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 9:1–6; 馬可福音 3:13–15; 馬可福音 6:7–13"> 耶穌叫了十二位門徒來，賜他們權柄，能趕出污鬼、醫治各樣的疾病。</span>
<span className="v" id="v2" data-v="2" data-xref="馬太福音 4:21; 使徒行傳 1:13; 路加福音 5:10"> 以下是這十二位使徒的名字： 首先是西門，又名彼得，還有彼得的兄弟安得烈、西庇太的兒子雅各、雅各的兄弟約翰、</span>
<span className="v" id="v3" data-v="3" data-xref="馬可福音 3:18; 使徒行傳 1:13; 馬可福音 2:14"> 腓力、巴多羅買、多馬、稅吏馬太、亞勒腓的兒子雅各、達太、</span>
<span className="v" id="v4" data-v="4" data-xref="馬太福音 26:14; 馬太福音 26:47; 約翰福音 13:2"> 激進黨人<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「激進黨人」指當時激進的猶太民族主義者，常以行動反抗統治他們的羅馬政府。">a</a></sup>西門和出賣耶穌的加略人猶大。</span>
<span className="v" id="v5" data-v="5" data-xref="約翰福音 4:9; 使徒行傳 22:21–23; 列王紀下 17:24–41"> 耶穌差遣這十二個人出去，囑咐他們：「外族人的地方不要去，撒瑪利亞人的城鎮也不要進，</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米書 50:6; 以西結書 34:6; 以賽亞書 53:6"> 要到以色列人當中尋找迷失的羊。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行傳 28:31; 馬太福音 3:2; 路加福音 9:60"> 「你們要邊走邊傳，『天國臨近了！』</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行傳 3:6; 路加福音 10:9; 使徒行傳 4:30"> 要醫治病人，叫死人復活，使痲瘋病人得潔淨，趕走邪靈。你們白白地得來，也應當白白地給人。</span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 22:35; 路加福音 9:3–5; 路加福音 10:4–12"> 出門時錢袋裡不要帶金、銀、銅幣，</span>
<span className="v" id="v10" data-v="10" data-xref="路加福音 10:7–12; 提摩太前書 5:17–18; 哥林多前書 9:4–14"> 不要帶行李、備用的衣服、鞋或手杖，因為工人理應得到供應。</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 10:7–8; 約伯記 31:32; 士師記 19:16–21"> 你們無論到哪座城、哪個村，要在那裡尋找配接待你們的人，然後住在他家，一直住到離開。</span>
<span className="v" id="v12" data-v="12" data-xref="撒母耳記上 25:6; 路加福音 10:5–6; 使徒行傳 10:36"> 你們進他家的時候，要祝他家平安。</span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 10:6; 詩篇 35:13; 哥林多後書 2:16"> 如果那家配得平安，你們的平安必臨到那家；如果那家不配，平安仍歸給你們。</span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 10:10–11; 使徒行傳 18:6; 尼希米記 5:13"> 如果有人不接待你們，不聽你們傳的道，你們離開那家或那城時，要跺掉腳上的塵土。</span>
<span className="v" id="v15" data-v="15" data-xref="彼得後書 2:6; 約翰一書 4:17; 約翰福音 15:22–24"> 我實在告訴你們，在審判之日，那城將比所多瑪和蛾摩拉受更重的刑罰！</span>
</div>
</div>

## 將臨的迫害

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="路加福音 10:3; 腓立比書 2:15; 哥林多前書 14:20"> 「聽著，我差你們出去，就好像把羊送入狼群。所以，你們要像蛇一樣機靈，像鴿子一樣馴良。</span>
<span className="v" id="v17" data-v="17" data-xref="馬可福音 13:9; 馬太福音 23:34; 使徒行傳 26:11"> 「你們要小心謹慎，因為你們將被送上法庭，並在會堂裡被鞭打。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行傳 5:25–27; 馬太福音 8:4; 詩篇 2:1–6"> 你們要因我的緣故被帶到官長和君王面前，在他們和外族人面前為我作見證。</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及記 4:12; 馬可福音 13:11–13; 提摩太後書 4:17"> 當你們被押去受審時，不要顧慮如何應對，或說什麼話，那時必賜給你們當說的話。</span>
<span className="v" id="v20" data-v="20" data-xref="路加福音 21:15; 使徒行傳 6:10; 路加福音 12:12"> 因為那時候說話的不是你們自己，而是你們父的靈藉著你們說話。</span>
<span className="v" id="v21" data-v="21" data-xref="路加福音 21:16–17; 彌迦書 7:5–6; 馬可福音 13:12–13"> 「那時，人將把自己的弟兄置於死地，父親將把兒子置於死地，兒女將反叛父母，置他們於死地。</span>
<span className="v" id="v22" data-v="22" data-xref="馬太福音 24:13; 雅各書 1:12; 啟示錄 2:10"> 你們將為我的名被眾人憎恨，但堅忍到底的必定得救。</span>
<span className="v" id="v23" data-v="23" data-xref="馬太福音 16:28; 使徒行傳 8:1; 馬可福音 13:26"> 你們如果在一個地方遭迫害，就逃到另一個地方。我實在告訴你們，沒等你們走遍以色列的城鎮，人子就來了。</span>
<span className="v" id="v24" data-v="24" data-xref="約翰福音 15:20; 路加福音 6:40; 約翰福音 13:16"> 「學生不能高過老師，奴僕也不能大過主人。</span>
<span className="v" id="v25" data-v="25" data-xref="路加福音 11:15; 馬太福音 12:24; 馬太福音 9:34"> 學生頂多和老師一樣，奴僕頂多和主人一樣。連家主都被罵成是別西卜<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="「別西卜」是鬼王的名字。">b</a></sup>，更何況祂的家人呢？</span>
<span className="v" id="v26" data-v="26" data-xref="路加福音 8:17; 馬可福音 4:22; 耶利米書 1:8"> 「不要害怕那些迫害你們的人。因為掩蓋的事終會暴露出來，隱藏的秘密終會被人知道。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行傳 5:20; 約翰福音 16:13; 約翰福音 16:1"> 你們要把我暗中告訴你們的公佈於眾，你們要把聽到的耳語在屋頂上傳揚。</span>
<span className="v" id="v28" data-v="28" data-xref="路加福音 12:4–5; 以賽亞書 8:12–13; 啟示錄 2:10"> 那些只能殺害身體，不能毀滅靈魂的，不用怕他們。但要畏懼有權將身體和靈魂一同毀滅在地獄裡的上帝。</span>
<span className="v" id="v29" data-v="29" data-xref="路加福音 12:6–7; 詩篇 104:27–30"> 兩隻麻雀不是只賣一個銅錢嗎？然而沒有天父的許可，一隻也不會掉在地上。</span>
<span className="v" id="v30" data-v="30" data-xref="路加福音 12:7; 撒母耳記上 14:45; 使徒行傳 27:34"> 就連你們的頭髮都被數過了。</span>
<span className="v" id="v31" data-v="31" data-xref="路加福音 12:24; 詩篇 8:5; 馬太福音 6:26"> 所以不要害怕，你們比許多麻雀要貴重！</span>
<span className="v" id="v32" data-v="32" data-xref="啟示錄 3:5; 羅馬書 10:9–10; 路加福音 12:8–9"> 「凡在人面前承認我的，我在天父面前也必承認他；</span>
<span className="v" id="v33" data-v="33" data-xref="提摩太後書 2:12; 路加福音 9:26; 路加福音 12:9"> 凡在人面前否認我的，我在天父面前也必否認他。</span>
</div>
</div>

## 跟從主的代價

<div className="bt">
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="路加福音 12:49–53; 使徒行傳 14:4; 使徒行傳 13:45–50"> 「不要以為我來了會讓天下太平，我不是帶來和平，而是帶來刀劍。</span>
<span className="v" id="v35" data-v="35" data-xref="彌迦書 7:5–6; 馬太福音 10:21; 路加福音 21:16"> 因為我來是要叫兒子與父親作對，女兒與母親作對，媳婦與婆婆作對，</span>
<span className="v" id="v36" data-v="36" data-xref="彌迦書 7:6; 耶利米書 12:6; 詩篇 41:9"> 家人之間反目成仇。<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="彌迦書7·6。">c</a></sup></span>
<span className="v" id="v37" data-v="37" data-xref="路加福音 14:26; 馬太福音 22:37; 腓立比書 3:7–9"> 「愛父母過於愛我的人不配作我的門徒；愛兒女過於愛我的人不配作我的門徒；</span>
<span className="v" id="v38" data-v="38" data-xref="路加福音 14:27; 馬可福音 8:34; 馬太福音 16:24"> 不背起自己的十字架跟從我的，不配作我的門徒。</span>
<span className="v" id="v39" data-v="39" data-xref="約翰福音 12:25; 馬可福音 8:35–36; 路加福音 17:33"> 保全自己生命的，必失去生命；但為了我失去生命的，必得到生命。</span>
</div>
</div>

## 得賞賜

<div className="bt">
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="約翰福音 13:20; 路加福音 9:48; 路加福音 10:16"> 「誰接待你們，就是接待我；誰接待我，就是接待差我來的那位。</span>
<span className="v" id="v41" data-v="41" data-xref="約翰三書 1:5–8; 希伯來書 6:10; 列王紀下 4:16–17"> 因為某人是先知而接待他的，必得到和先知一樣的賞賜；因為某人是義人而接待他的，必得到和義人一樣的賞賜。</span>
<span className="v" id="v42" data-v="42" data-xref="希伯來書 6:10; 馬太福音 25:40; 馬可福音 9:41–42"> 人若接待我門徒中最卑微的人，並因為他是我的門徒而給他一杯涼水喝，我實在告訴你們，那人必得到賞賜。」</span>
</div>

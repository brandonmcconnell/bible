## 譴責律法教師和法利賽人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 12:1; 路加福音 20:45–46; 馬太福音 15:10–20"> 隨後，耶穌對眾人和門徒說：</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 20:46; 馬可福音 12:38; 瑪拉基書 2:7"> 「律法教師和法利賽人坐在摩西的位子上講授律法。</span>
<span className="v" id="v3" data-v="3" data-xref="提摩太後書 3:5; 提多書 1:16; 羅馬書 2:19–24"> 你們要謹遵他們的教導，但不要效法他們的行為，因為他們言行不一。</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 11:46; 使徒行傳 15:10; 加拉太書 6:13"> 他們把難負的重擔捆好，放在別人肩上，而自己連一根指頭也不肯動！</span>
<span className="v" id="v5" data-v="5" data-xref="馬太福音 6:1–16; 約翰福音 12:43; 腓立比書 2:3"> 「他們的所作所為是為了給人看的，他們把額上佩戴的經文盒子加寬了，又將衣服的穗子加長了。</span>
<span className="v" id="v6" data-v="6" data-xref="約翰三書 1:9; 路加福音 11:43–54; 馬可福音 12:38–39"> 他們喜歡宴席中的上座和會堂裡的首位。</span>
<span className="v" id="v7" data-v="7" data-xref="約翰福音 1:38; 約翰福音 1:49; 約翰福音 3:26"> 他們喜歡別人在街市上問候他們，稱呼他們為老師<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「老師」希臘文是「拉比」，特指猶太教的老師。">a</a></sup>。</span>
<span className="v" id="v8" data-v="8" data-xref="雅各書 3:1; 哥林多前書 1:12–13; 彼得前書 5:3"> 但你們不要讓別人稱呼你們為老師，因為你們只有一位老師，你們彼此都是弟兄。</span>
<span className="v" id="v9" data-v="9" data-xref="約翰一書 3:1; 希伯來書 12:9; 瑪拉基書 1:6"> 不要稱呼地上的人為父親，因為你們只有一位父親，祂在天上。</span>
<span className="v" id="v10" data-v="10"> 不要讓人稱你們為導師，因為你們只有一位導師基督。</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多前書 9:19; 加拉太書 5:13; 約翰福音 13:14–15"> 你們當中誰位分最大，誰就要作你們的僕人。</span>
<span className="v" id="v12" data-v="12" data-xref="彼得前書 5:5; 雅各書 4:6; 箴言 29:23"> 自高的人必遭貶抑，謙卑的人必得尊榮。</span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 11:52; 馬太福音 23:29; 馬太福音 23:23"> 「虛偽的律法教師和法利賽人啊，你們有禍了！因為你們當著人們的面關閉天國之門，自己不進去，也不讓別人進去。</span>
<span className="v" id="v14" data-v="14"> 「虛偽的律法教師和法利賽人啊，你們有禍了！因為你們侵吞寡婦的家產，還假意做冗長的禱告。因此，你們會受到更嚴厲的刑罰。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有古卷無14節。">b</a></sup></span>
<span className="v" id="v15" data-v="15" data-xref="以弗所書 2:3; 使徒行傳 13:10; 使徒行傳 13:43"> 「虛偽的律法教師和法利賽人啊，你們有禍了！因為你們走遍海洋和陸地去引人入教，等人入了教，卻使他淪為地獄之子，比你們還壞一倍。</span>
<span className="v" id="v16" data-v="16" data-xref="馬太福音 15:14; 馬太福音 5:33–35; 雅各書 5:12"> 「瞎眼的嚮導啊，你們有禍了！你們說，『指著聖殿發誓，不算數；但是指著聖殿裡的金子發誓，就要遵守誓言。』</span>
<span className="v" id="v17" data-v="17" data-xref="馬太福音 23:19; 民數記 16:38–39; 詩篇 94:8"> 瞎眼的愚昧人啊！金子重要呢？還是使金子神聖的聖殿重要呢？</span>
<span className="v" id="v18" data-v="18"> 你們又說，『指著祭壇發誓不算數，但是指著壇上的供物發誓，就要遵守誓言。』</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及記 29:37; 出埃及記 30:29"> 瞎眼的人啊！供物重要呢？還是使供物神聖的祭壇重要呢？</span>
<span className="v" id="v20" data-v="20"> 其實指著祭壇發誓，就是指著祭壇和壇上的一切東西發誓。</span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 26:8; 列王紀上 8:13; 歷代志下 6:2"> 指著聖殿發誓，就是指著聖殿和住在裡面的上帝發誓。</span>
<span className="v" id="v22" data-v="22" data-xref="馬太福音 5:34; 詩篇 11:4; 以賽亞書 66:1"> 指著天發誓，就是指著上帝的寶座和坐在寶座上的那位發誓。</span>
<span className="v" id="v23" data-v="23" data-xref="路加福音 11:42; 彌迦書 6:8; 何西阿書 6:6"> 「虛偽的律法教師和法利賽人啊，你們有禍了！你們把薄荷、茴香、芹菜獻上十分之一，卻忽略了律法中更重要的事——公正、憐憫、信實。後者是你們本該做的，前者也不可忽略。</span>
<span className="v" id="v24" data-v="24" data-xref="馬太福音 19:24; 馬太福音 27:6–8; 馬太福音 15:2–6"> 瞎眼的嚮導啊！你們濾出蚊蟲，卻吞下駱駝。</span>
<span className="v" id="v25" data-v="25" data-xref="路加福音 11:39–40; 馬太福音 15:19–20; 馬可福音 7:4–13"> 「虛偽的律法教師和法利賽人啊，你們有禍了！你們洗淨杯盤的外面，裡面卻盛滿了貪婪和放縱。</span>
<span className="v" id="v26" data-v="26" data-xref="哥林多後書 7:1; 雅各書 4:8; 希伯來書 10:22"> 瞎眼的法利賽人啊！要先洗淨杯盤的裡面，好讓外面也乾淨。<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="意思是：「裡面的思想先乾淨了，外在的言行才會真正乾淨。」">c</a></sup></span>
<span className="v" id="v27" data-v="27" data-xref="路加福音 11:44; 使徒行傳 23:3; 民數記 19:16"> 「虛偽的律法教師和法利賽人啊，你們有禍了！你們好像粉飾的墳墓，外表好看，裡面卻裝滿了死人的骨頭和各種污穢之物。</span>
<span className="v" id="v28" data-v="28" data-xref="路加福音 16:15; 詩篇 51:6; 馬太福音 23:5"> 所以你們虛有公義的外表，內心卻充滿了虛偽和罪惡。</span>
<span className="v" id="v29" data-v="29" data-xref="路加福音 11:47–48; 使徒行傳 2:29"> 「虛偽的律法教師和法利賽人啊，你們有禍了！你們為先知建墓，為義人修碑，並且說，</span>
<span className="v" id="v30" data-v="30" data-xref="耶利米書 2:30; 馬太福音 23:34–35; 馬太福音 21:35–36"> 『我們如果活在我們祖先的時代，絕不會和他們一起去殺害先知。』</span>
<span className="v" id="v31" data-v="31" data-xref="使徒行傳 7:51–52; 帖撒羅尼迦前書 2:15–16; 約書亞記 24:22"> 這樣，你們自己證明自己是殺害先知之人的後代。</span>
<span className="v" id="v32" data-v="32" data-xref="創世記 15:16; 民數記 32:14; 帖撒羅尼迦前書 2:16"> 去填滿你們祖先的罪惡吧！</span>
<span className="v" id="v33" data-v="33" data-xref="馬太福音 3:7; 馬太福音 12:34; 馬太福音 5:22"> 你們這些蛇，這些毒蛇的後代啊，你們怎能逃脫地獄的刑罰呢？</span>
<span className="v" id="v34" data-v="34" data-xref="馬太福音 10:16–17; 馬太福音 13:52; 歌羅西書 1:28"> 「看啊，我派先知、智者和律法教師到你們當中，有的會遭到你們的殺害，被你們釘在十字架上；有的會在會堂裡被你們鞭打，被你們從這城追到那城。</span>
<span className="v" id="v35" data-v="35" data-xref="歷代志下 24:20–22; 撒迦利亞書 1:1; 希伯來書 11:4"> 因此，所有義人在地上所流的血，就是從義人亞伯的血，直到你們在聖所和祭壇之間所殺的巴拉加的兒子撒迦利亞的血，都要歸到你們身上。</span>
<span className="v" id="v36" data-v="36" data-xref="馬太福音 10:23; 馬太福音 24:34; 馬可福音 13:30–31"> 我實在告訴你們，這一切罪責都要歸到這個世代。</span>
</div>

## 為耶路撒冷哀歎

<div className="bt">
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="路加福音 13:34–35; 路得記 2:12; 詩篇 91:4"> 「耶路撒冷啊！耶路撒冷啊！你常殺害先知，又用石頭打死派到你那裡的使者。我多次想要招聚你的兒女，像母雞把小雞聚集在翅膀底下，可是你們卻不肯。</span>
<span className="v" id="v38" data-v="38" data-xref="耶利米書 22:5; 路加福音 13:35; 路加福音 21:24"> 看啊！你們的家園將一片荒涼。</span>
<span className="v" id="v39" data-v="39" data-xref="詩篇 118:26; 馬太福音 21:9; 羅馬書 11:25"> 我告訴你們，從現在起，直到你們說『奉主名來的當受稱頌』<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="詩篇118·26。">d</a></sup>那天之前，你們再也見不到我了。」</span>

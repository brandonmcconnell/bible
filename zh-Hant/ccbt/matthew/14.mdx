## 施洗者約翰之死

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 3:1; 馬可福音 8:15; 路加福音 9:7–9"> 那時，分封王希律聽見耶穌的名聲，</span>
<span className="v" id="v2" data-v="2" data-xref="馬太福音 16:14; 約翰福音 10:41; 馬可福音 8:28"> 就對臣僕說：「這個人是施洗者約翰！他從死裡復活了，所以能行這些神蹟。」</span>
<span className="v" id="v3" data-v="3" data-xref="馬可福音 6:17; 路加福音 3:19–20; 馬太福音 4:12"> 原來希律為他兄弟腓力的妻子希羅底的緣故，拘捕了約翰，把他捆綁起來關在監牢。</span>
<span className="v" id="v4" data-v="4" data-xref="利未記 20:21; 利未記 18:16; 馬可福音 6:18"> 因為約翰曾多次對他說：「你娶這個婦人不合法。」</span>
<span className="v" id="v5" data-v="5" data-xref="馬太福音 21:26; 馬太福音 11:9; 馬可福音 6:19–20"> 他想殺掉約翰，但怕觸怒百姓，因為他們都認為約翰是先知。</span>
<span className="v" id="v6" data-v="6" data-xref="馬可福音 6:21–23; 創世記 40:20; 何西阿書 1:5–6"> 在希律的生日那天，希羅底的女兒在眾人面前跳舞。希律非常高興，</span>
<span className="v" id="v7" data-v="7" data-xref="以斯帖記 5:3; 以斯帖記 5:6; 以斯帖記 7:2"> 就起誓答應她無論要什麼都可以。</span>
<span className="v" id="v8" data-v="8" data-xref="馬可福音 6:24; 箴言 29:10; 箴言 1:16"> 她受了母親的指使，說：「請把施洗者約翰的頭放在盤子裡送給我。」</span>
<span className="v" id="v9" data-v="9" data-xref="約翰福音 19:12–16; 撒母耳記上 14:28; 馬可福音 6:26"> 希律感到為難，但既然在眾賓客面前起了誓，只好下令給她。</span>
<span className="v" id="v10" data-v="10" data-xref="馬太福音 17:12; 馬太福音 21:35–36; 路加福音 9:9"> 他派人進監牢砍了約翰的頭，</span>
<span className="v" id="v11" data-v="11" data-xref="啟示錄 16:6; 創世記 49:7; 以西結書 16:3–4"> 放在盤子裡送給女孩，她又轉送給她母親。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行傳 8:2; 馬太福音 27:58–61"> 約翰的門徒把屍體領回安葬後，就去告訴耶穌。</span>
</div>
</div>

## 耶穌使五千人吃飽

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="路加福音 9:10–17; 馬太福音 14:1–2; 馬可福音 6:30–44"> 耶穌聽見這個消息，就獨自坐船退到一處荒僻的地方。眾人得知後，就從各城步行來跟隨祂。</span>
<span className="v" id="v14" data-v="14" data-xref="希伯來書 4:15; 馬太福音 9:36; 希伯來書 2:17"> 耶穌上了岸，看見一大群人，心裡憐憫他們，就治好了他們當中的病人。</span>
<span className="v" id="v15" data-v="15" data-xref="馬太福音 15:23; 馬可福音 8:3; 馬可福音 6:35–36"> 黃昏時，門徒過來對耶穌說：「這裡是荒郊野外，天又晚了，請遣散眾人，好讓他們到村莊去自己買些吃的。」</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀下 4:42–44; 哥林多後書 8:2–3; 傳道書 11:2"> 耶穌回答說：「他們不用離開，你們給他們吃的吧。」</span>
<span className="v" id="v17" data-v="17" data-xref="馬太福音 15:33–34; 馬可福音 6:37–38; 路加福音 9:13"> 門徒答道：「我們這裡只有五個餅和兩條魚。」</span>
<span className="v" id="v18" data-v="18"> 耶穌說：「拿來給我。」</span>
<span className="v" id="v19" data-v="19" data-xref="馬可福音 8:6–7; 路加福音 24:30; 撒母耳記上 9:13"> 於是，祂叫眾人坐在草地上，然後拿起那五個餅和兩條魚，舉目望著天祝謝後，掰開餅遞給門徒，讓他們分給眾人。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及記 16:12; 馬可福音 6:42–44; 馬太福音 16:8–10"> 大家都吃飽了，把剩下的零碎收拾起來，裝滿了十二個籃子。</span>
<span className="v" id="v21" data-v="21" data-xref="腓立比書 4:19; 哥林多後書 9:8–11; 使徒行傳 4:4"> 當時吃飯的，除了婦女和小孩，約有五千男人。</span>
</div>
</div>

## 耶穌在水上行走

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="馬可福音 6:45–51; 約翰福音 6:15–21; 馬太福音 15:39"> 隨後，耶穌催門徒上船，叫他們先渡到湖對岸，祂則遣散眾人。</span>
<span className="v" id="v23" data-v="23" data-xref="路加福音 6:12; 馬可福音 6:46; 馬太福音 26:36"> 等眾人都離開了，祂就獨自上山去禱告，在那裡一直待到晚上。</span>
<span className="v" id="v24" data-v="24" data-xref="約翰福音 6:18; 馬可福音 6:48; 馬太福音 8:24"> 那時，門徒的船離岸已遠，遇到逆風，船身被波浪撞擊得搖擺不定。</span>
<span className="v" id="v25" data-v="25" data-xref="約伯記 9:8; 約翰福音 6:19; 馬可福音 6:48"> 天將破曉的時候，耶穌從水面上朝門徒走去。</span>
<span className="v" id="v26" data-v="26" data-xref="馬可福音 6:49–50; 啟示錄 1:17; 路加福音 1:11–12"> 門徒看見祂在湖面上走，都嚇壞了，說：「是幽靈！」他們害怕得又喊又叫。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行傳 23:11; 啟示錄 1:17–18; 約翰福音 16:33"> 耶穌立刻對他們說：「放心吧！是我，不要怕。」</span>
<span className="v" id="v28" data-v="28" data-xref="約翰福音 6:68; 羅馬書 12:3; 馬太福音 26:33–35"> 彼得說：「主啊！如果真的是你，就叫我從水面上走到你那裡。」</span>
<span className="v" id="v29" data-v="29" data-xref="腓立比書 4:13; 馬可福音 9:23; 使徒行傳 3:16"> 耶穌說：「你來吧！」 於是，彼得就從船上下去，走在湖面上，要去耶穌那裡。</span>
<span className="v" id="v30" data-v="30" data-xref="耶利米哀歌 3:54–57; 提摩太後書 4:16–17; 馬可福音 14:38"> 他看到風浪很大，就害怕起來，身體開始往下沉，便大喊：「主啊，救我！」</span>
<span className="v" id="v31" data-v="31" data-xref="雅各書 1:6–8; 詩篇 138:7; 創世記 22:14"> 耶穌馬上伸手拉住他，說：「你信心太小了！為什麼懷疑呢？」</span>
<span className="v" id="v32" data-v="32" data-xref="詩篇 107:29–30; 馬可福音 4:41; 約翰福音 6:21"> 他們上了船，風浪就平靜了。</span>
<span className="v" id="v33" data-v="33" data-xref="約翰福音 11:27; 詩篇 2:7; 羅馬書 1:4"> 船上的人都敬拜祂，說：「你真是上帝的兒子。」</span>
<span className="v" id="v34" data-v="34" data-xref="馬可福音 6:53–56; 路加福音 5:1; 約翰福音 6:24–25"> 他們渡到湖對岸，來到革尼撒勒。</span>
<span className="v" id="v35" data-v="35" data-xref="馬太福音 4:24–25; 馬可福音 6:55; 馬可福音 1:28–34"> 當地的人認出是耶穌，就派人去把附近所有的病人都帶到祂面前，</span>
<span className="v" id="v36" data-v="36" data-xref="路加福音 6:19; 馬可福音 3:10; 出埃及記 28:33–43"> 求耶穌讓他們只摸一摸祂衣服的穗子，所有摸過的病人都好了。</span>
</div>
</div>

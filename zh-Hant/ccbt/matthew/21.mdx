## 光榮進聖城

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="撒迦利亞書 14:4; 馬可福音 11:1–10; 路加福音 21:37"> 耶穌和門徒將近耶路撒冷，來到橄欖山的伯法其。耶穌派了兩個門徒，</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 19:30–32; 馬可福音 11:2–3; 約翰福音 2:5–8"> 並囑咐說：「你們到前面的村莊去，就會看見一頭母驢拴在那裡，旁邊還有一頭驢駒。你們把牠們解開，牽到我這裡。</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多後書 8:1–2; 使徒行傳 17:25; 哥林多後書 8:9"> 要是有人問起，你們就說，『主要用牠們』，那人會立刻讓你們牽來。」</span>
<span className="v" id="v4" data-v="4" data-xref="撒迦利亞書 9:9; 約翰福音 12:15; 馬太福音 1:22"> 這件事發生是要應驗先知的話：</span>
<span className="v" id="v5" data-v="5" data-xref="撒迦利亞書 9:9–10; 以賽亞書 62:11; 以賽亞書 12:6"> 「要對少女錫安說，『看啊，你的君王來了！祂謙卑地騎著驢，騎著一頭驢駒。』<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="撒迦利亞書9·9。">a</a></sup>」</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及記 39:43; 約翰福音 15:14; 出埃及記 40:16"> 兩個門徒照著耶穌的吩咐去了，</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀下 9:13; 馬可福音 11:4–8; 路加福音 19:32–35"> 把母驢和驢駒帶了回來。他們把衣服搭在驢背上，讓耶穌騎上去。</span>
<span className="v" id="v8" data-v="8" data-xref="列王紀下 9:13; 約翰福音 12:13; 利未記 23:40"> 許多人把衣服鋪在路上，還有些人砍下樹枝鋪在路上。</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 118:24–26; 路加福音 2:14; 約翰福音 12:13–15"> 眾人前呼後擁，高喊道：<br /><span className="pl pl-1">「和散那</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="「和散那」原意是「拯救我們」，此處有「讚美」的意思。">b</a></sup><br /><span className="pl pl-1">歸於大衛的後裔！」</span><br /><span className="pl pl-1">「奉主名來的當受稱頌！」</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="詩篇118·26。">c</a></sup><br /><span className="pl pl-1">「和散那歸於至高之處的上帝！」</span></span>
<span className="v" id="v10" data-v="10" data-xref="使徒行傳 9:5; 路得記 1:19; 約翰福音 12:16–19"> 耶穌進耶路撒冷時，全城轟動，說：「這是誰？」</span>
<span className="v" id="v11" data-v="11" data-xref="約翰福音 6:14; 路加福音 7:16; 約翰福音 7:40"> 眾人說：「祂是先知耶穌，來自加利利的拿撒勒。」</span>
</div>
</div>

## 潔淨聖殿

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="約翰福音 2:14–17; 路加福音 19:45–47; 馬可福音 11:15–18"> 耶穌進入聖殿，趕走裡面所有做買賣的人，推翻兌換錢幣之人的桌子和賣鴿子之人的凳子。</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米書 7:11; 以賽亞書 56:7; 路加福音 19:46"> 耶穌斥責他們說：「聖經上說，『我的殿必稱為禱告的殿。』<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="以賽亞書56·7。">d</a></sup>你們竟把它變成了賊窩。<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="耶利米書7·11。">e</a></sup>」</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行傳 3:1–9; 使徒行傳 10:38; 馬太福音 11:4–5"> 殿中瞎眼的和瘸腿的都來到耶穌面前，祂便治好了他們。</span>
<span className="v" id="v15" data-v="15" data-xref="馬太福音 21:9; 路加福音 19:39–40; 以賽亞書 26:11"> 祭司長和律法教師看見祂所行的奇事，又聽見小孩子在聖殿裡高聲喊著：「和散那歸於大衛的後裔！」便十分惱怒。</span>
<span className="v" id="v16" data-v="16" data-xref="詩篇 8:2; 馬太福音 11:25; 路加福音 19:39–40"> 他們責問耶穌說：「你聽見這些人說的了嗎？」<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="詩篇8·2。">f</a></sup>耶穌說：「我聽見了。聖經上說，『你使孩童和嬰兒口中發出頌讚』，你們從未讀過嗎？」</span>
<span className="v" id="v17" data-v="17" data-xref="約翰福音 11:18; 馬可福音 11:11; 路加福音 24:50"> 然後，祂便離開他們，出城前往伯大尼，在那裡住宿。</span>
</div>
</div>

## 咒詛無花果樹

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="馬太福音 4:2; 希伯來書 4:15; 馬太福音 12:1"> 清早，耶穌在回城的路上餓了。</span>
<span className="v" id="v19" data-v="19" data-xref="約翰福音 15:6; 馬可福音 11:14; 提多書 1:16"> 祂看見路旁有一棵無花果樹，便走過去，卻發現除了葉子外什麼也沒有。 祂對那棵樹說：「你永遠不會再結果子！」那棵樹立刻枯萎了。</span>
<span className="v" id="v20" data-v="20" data-xref="以賽亞書 40:6–8; 馬可福音 11:20–21; 雅各書 1:10–11"> 門徒見了就驚奇地問：「這棵樹怎麼一下子枯萎了？」</span>
<span className="v" id="v21" data-v="21" data-xref="雅各書 1:6; 馬太福音 17:20; 馬可福音 11:22–23"> 耶穌回答說：「我實在告訴你們，你們如果有信心、不懷疑，不但能使無花果樹枯萎，就算對這座山說，『從這裡挪開，投進大海裡！』也照樣可以實現。</span>
<span className="v" id="v22" data-v="22" data-xref="馬太福音 7:7; 約翰一書 5:14–15; 馬可福音 11:24"> 所以，只要相信，你們無論禱告求什麼，都必得到。」</span>
</div>
</div>

## 質問耶穌的權柄

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="使徒行傳 4:7; 馬可福音 11:27–33; 歷代志上 24:1–19"> 耶穌進了聖殿，正在教導人的時候，祭司長和百姓的長老上前質問祂：「你憑什麼權柄做這些事？誰授權給你了？」</span>
<span className="v" id="v24" data-v="24" data-xref="路加福音 6:9; 歌羅西書 4:6; 馬太福音 10:16"> 耶穌說：「我也要問你們一個問題，你們回答了，我就告訴你們我憑什麼權柄做這些事。</span>
<span className="v" id="v25" data-v="25" data-xref="約翰一書 3:20; 馬可福音 1:1–11; 約翰福音 3:18"> 約翰的洗禮是從哪裡來的？從天上來的，還是從人間來的？」 他們便彼此議論說：「如果我們說『是從天上來的』，祂一定會問我們，『那你們為什麼不信他？』</span>
<span className="v" id="v26" data-v="26" data-xref="馬可福音 6:20; 馬太福音 14:5; 約翰福音 5:35"> 但如果我們說『是從人間來的』，又怕觸怒百姓，因為他們都相信約翰是先知。」</span>
<span className="v" id="v27" data-v="27" data-xref="羅馬書 1:18–22; 帖撒羅尼迦後書 2:9–10; 路加福音 20:7–8"> 於是，他們回答耶穌說：「我們不知道。」 耶穌說：「我也不告訴你們我憑什麼權柄做這些事。」</span>
</div>
</div>

## 兩個兒子的比喻

<div className="bt">
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="哥林多前書 15:58; 馬太福音 20:1; 哥林多前書 10:15"> 耶穌又說：「你們怎樣看這件事？某人有兩個兒子。他對大兒子說，『孩子，你今天到葡萄園工作吧！』</span>
<span className="v" id="v29" data-v="29" data-xref="以西結書 18:28–32; 馬太福音 3:2–8; 以賽亞書 55:6–7"> 「大兒子回答說，『我不去！』但後來他改變了主意，就去了。</span>
<span className="v" id="v30" data-v="30" data-xref="提多書 1:16; 以西結書 33:31; 馬太福音 23:3"> 「那父親又去對小兒子說同樣的話。小兒子回答說，『好的，父親』，卻沒有去。</span>
<span className="v" id="v31" data-v="31" data-xref="路加福音 7:29; 路加福音 7:37–50; 馬太福音 7:21"> 「這兩個兒子到底哪一個服從父親呢？」 他們回答道：「大兒子。」 耶穌說：「我實在告訴你們，稅吏和娼妓要比你們先進上帝的國。</span>
<span className="v" id="v32" data-v="32" data-xref="路加福音 7:37–50; 撒迦利亞書 7:11–12; 路加福音 7:29–30"> 因為約翰來指示你們當行的正路，你們不信他，但稅吏和娼妓信了。你們親眼看見了這些事，竟然還是執迷不悟，不肯信他。</span>
</div>
</div>

## 惡毒的佃戶

<div className="bt">
<div className="bp poetry">
<span className="v" id="v33" data-v="33" data-xref="以賽亞書 5:1–4; 馬可福音 12:1–12; 路加福音 20:9–19"> 「你們再聽一個比喻。有個園主開墾了一個葡萄園，在園子的四周圍上籬笆，又在園中挖了一個榨酒池，建了一座瞭望臺，然後把葡萄園租給佃戶，就出遠門了。</span>
<span className="v" id="v34" data-v="34" data-xref="路加福音 20:10–19; 以賽亞書 5:4; 撒迦利亞書 1:3–6"> 到了收穫的季節，園主派奴僕去佃戶那裡收取他的那份果實。</span>
<span className="v" id="v35" data-v="35" data-xref="歷代志下 36:15–16; 馬太福音 5:12; 希伯來書 11:36–37"> 佃戶卻抓住他的奴僕，打傷一個，殺死一個，又用石頭打死了一個。</span>
<span className="v" id="v36" data-v="36" data-xref="馬太福音 22:4"> 於是，園主又派去更多奴僕，結果也遭到同樣的對待。</span>
<span className="v" id="v37" data-v="37" data-xref="約翰福音 3:16; 約翰福音 3:35–36; 西番雅書 3:7"> 最後，園主派了自己的兒子去，心想，『他們肯定會尊重我的兒子。』</span>
<span className="v" id="v38" data-v="38" data-xref="路加福音 20:14; 創世記 37:18–20; 馬可福音 12:7–8"> 可是那些佃戶看見園主的兒子，就彼此商量說，『這是產業繼承人。來吧！我們殺掉他，佔了他的產業！』</span>
<span className="v" id="v39" data-v="39" data-xref="使徒行傳 2:23; 雅各書 5:6; 路加福音 22:52–54"> 於是，他們抓住他，把他扔到葡萄園外殺了。</span>
<span className="v" id="v40" data-v="40" data-xref="希伯來書 10:29; 馬可福音 12:9; 路加福音 20:15–16"> 那麼，當園主回來的時候，他會怎樣處置那些佃戶呢？」</span>
<span className="v" id="v41" data-v="41" data-xref="使徒行傳 18:6; 馬太福音 21:43; 使徒行傳 28:28"> 他們說：「他會毫不留情地除掉那些惡人，然後把葡萄園租給其他按時交果子的佃戶。」</span>
<span className="v" id="v42" data-v="42" data-xref="詩篇 118:22–23; 以賽亞書 28:16; 使徒行傳 4:11"> 耶穌說：<br /><span className="pl pl-1">「『工匠丟棄的石頭已成了房角石。</span><br /><span className="pl pl-1">這是主的作為，在我們看來奇妙莫測。』</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="詩篇118·22、23。">g</a></sup>你們從未讀過這段經文嗎？</span>
<span className="v" id="v43" data-v="43" data-xref="馬太福音 21:41; 馬太福音 8:11–12; 彼得前書 2:9"> 所以，我告訴你們，上帝將把祂的國從你們那裡奪去，賜給結果子的人。</span>
<span className="v" id="v44" data-v="44" data-xref="以賽亞書 8:14–15; 彼得前書 2:8; 但以理書 2:34–35"> 凡跌在這石頭上的人，都會粉身碎骨；這石頭落在誰身上，會把誰砸爛。」</span>
<span className="v" id="v45" data-v="45" data-xref="路加福音 20:19; 路加福音 11:45; 馬太福音 12:12"> 祭司長和法利賽人聽了耶穌的比喻，明白祂是針對他們講的。</span>
<span className="v" id="v46" data-v="46" data-xref="馬太福音 21:11; 馬太福音 21:26; 路加福音 7:16"> 他們試圖逮捕耶穌，但又害怕百姓，因為百姓都認為耶穌是先知。</span>
</div>

## 耶穌基督的家譜

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 22:18; 羅馬書 1:3; 加拉太書 3:16"> 耶穌基督是亞伯拉罕的子孫、大衛的後裔，以下是祂的家譜：</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行傳 7:8; 希伯來書 11:17–18; 創世記 46:8–27"> 亞伯拉罕生以撒， 以撒生雅各， 雅各生猶大和他的兄弟，</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 46:12; 創世記 38:29–30; 歷代志上 4:1"> 猶大和她瑪生法勒斯和謝拉， 法勒斯生希斯崙， 希斯崙生蘭<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「蘭」希臘文是「亞蘭」。">a</a></sup>，</span>
<span className="v" id="v4" data-v="4" data-xref="歷代志上 2:10–12; 民數記 7:12; 民數記 2:3"> 蘭生亞米拿達， 亞米拿達生拿順， 拿順生撒門，</span>
<span className="v" id="v5" data-v="5" data-xref="希伯來書 11:31; 路得記 1:16–17; 雅各書 2:25"> 撒門和喇合生波阿斯， 波阿斯和路得生俄備得， 俄備得生耶西，</span>
<span className="v" id="v6" data-v="6" data-xref="列王紀上 15:5; 撒母耳記上 17:12; 撒母耳記下 12:24–25"> 耶西生大衛王。<br />大衛和烏利亞的妻子生所羅門，</span>
<span className="v" id="v7" data-v="7" data-xref="歷代志下 14:1–15; 列王紀上 14:31; 列王紀上 11:43–24"> 所羅門生羅波安， 羅波安生亞比雅， 亞比雅生亞撒，</span>
<span className="v" id="v8" data-v="8" data-xref="歷代志上 3:11; 歷代志下 26:1–23; 列王紀下 8:16"> 亞撒生約沙法， 約沙法生約蘭， 約蘭生烏西雅，</span>
<span className="v" id="v9" data-v="9" data-xref="以賽亞書 7:1–13; 歷代志下 26:21; 歷代志下 27:1–32"> 烏西雅生約坦， 約坦生亞哈斯， 亞哈斯生希西迦，</span>
<span className="v" id="v10" data-v="10" data-xref="歷代志下 32:33–27; 列王紀上 13:2; 歷代志上 3:13–15"> 希西迦生瑪拿西， 瑪拿西生亞們， 亞們生約西亞，</span>
<span className="v" id="v11" data-v="11" data-xref="耶利米書 27:20; 耶利米書 52:28–30; 但以理書 1:2"> 約西亞生耶哥尼雅和他的兄弟， 那時以色列人被擄往巴比倫。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="歷代志上 3:17; 以斯拉記 3:2; 路加福音 3:27"> 被擄到巴比倫以後， 耶哥尼雅生撒拉鐵， 撒拉鐵生所羅巴伯，</span>
<span className="v" id="v13" data-v="13"> 所羅巴伯生亞比玉， 亞比玉生以利亞敬， 以利亞敬生亞所，</span>
<span className="v" id="v14" data-v="14"> 亞所生撒督， 撒督生亞金， 亞金生以律，</span>
<span className="v" id="v15" data-v="15"> 以律生以利亞撒， 以利亞撒生馬但， 馬但生雅各，</span>
<span className="v" id="v16" data-v="16" data-xref="馬太福音 27:17; 約翰福音 4:25; 路加福音 3:23"> 雅各生約瑟。 約瑟就是瑪麗亞的丈夫， 那被稱為基督<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="「基督」意思是「受膏者」。">b</a></sup>的耶穌就是瑪麗亞生的。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="馬太福音 1:11–12; 列王紀下 24:14; 馬太福音 11:2"> 這樣，從亞伯拉罕到大衛共有十四代，從大衛到被擄至巴比倫也是十四代，從被擄至巴比倫到基督降生也是十四代。</span>
</div>
</div>

## 耶穌的降生

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="加拉太書 4:4–5; 路加福音 1:27–38; 約伯記 14:4"> 耶穌基督降生的經過記載如下。<br />耶穌的母親瑪麗亞和約瑟訂了婚，還沒有成親就從聖靈懷了孕。</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 22:21–24; 申命記 24:1–4; 約翰福音 8:4–5"> 她未婚夫約瑟是個義人，不願公開地羞辱她，就想暗中和她解除婚約。</span>
<span className="v" id="v20" data-v="20" data-xref="箴言 3:5–6; 路加福音 1:19; 馬太福音 1:18"> 他正在考慮這事的時候，主的一位天使在夢中向他顯現，說：「大衛的後裔約瑟，不要怕，把瑪麗亞娶過來，因為她所懷的孕是從聖靈來的。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行傳 13:23; 使徒行傳 4:12; 約翰福音 1:29"> 她將生一個兒子，你要給祂取名叫耶穌<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="「耶穌」意思是「救主」。">c</a></sup>，因為祂要把自己的子民從罪惡中救出來。」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="路加福音 24:44; 馬太福音 2:23; 列王紀上 8:15"> 這一切應驗了主藉著先知所說的話：</span>
<span className="v" id="v23" data-v="23" data-xref="以賽亞書 7:14; 以賽亞書 9:6–7; 詩篇 46:11"> 「必有童貞女懷孕生子，祂的名字要叫以馬內利。」<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="以賽亞書7·14。">d</a></sup>以馬內利的意思是「上帝與我們同在」。</span>
<span className="v" id="v24" data-v="24" data-xref="約翰福音 15:14; 雅各書 2:21–26; 約翰福音 2:5–8"> 約瑟醒來，就遵從主的天使所吩咐的娶瑪麗亞為妻，</span>
<span className="v" id="v25" data-v="25" data-xref="路加福音 2:21; 出埃及記 13:2; 馬太福音 1:21"> 只是在她生下孩子之前沒有與她同房。約瑟給孩子取名叫耶穌。</span>
</div>
</div>

## 王宴客的比喻

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="馬太福音 20:1–16; 馬太福音 12:43–45; 路加福音 14:16"> 耶穌又用比喻對他們說：</span>
<span className="v" id="v2" data-v="2" data-xref="啟示錄 19:7–9; 馬太福音 13:24; 以弗所書 5:24–32"> 「天國就像一個王為兒子籌備婚宴。</span>
<span className="v" id="v3" data-v="3" data-xref="啟示錄 22:17; 約翰福音 5:40; 路加福音 14:15–17"> 他派奴僕去請受邀的客人，可是客人都不肯來。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行傳 13:46; 馬太福音 21:36; 約翰福音 6:50–57"> 王再派其他奴僕去，說，『去告訴被邀請的人，我的宴席已經備好，公牛和肥畜都宰了，一切都預備妥當，來赴婚宴吧！』</span>
<span className="v" id="v5" data-v="5" data-xref="希伯來書 2:3; 路加福音 14:18–20; 約翰一書 2:15–16"> 那些人卻毫不理會地走了，一個去種田，一個去做買賣，</span>
<span className="v" id="v6" data-v="6" data-xref="約翰福音 15:19–20; 約翰福音 16:2–3; 使徒行傳 7:51–57"> 其餘的竟然抓住王的奴僕，把他們羞辱一番後殺了。</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 19:27; 彼得前書 4:17–18; 路加福音 21:24"> 王大怒，派軍隊去剿滅兇手，燒毀他們的城。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="帖撒羅尼迦後書 1:5; 使徒行傳 13:46; 啟示錄 3:4"> 「然後，他對奴僕說，『婚宴已預備好了，只是被邀請的人不配。</span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 14:21–24; 箴言 1:20–23; 馬可福音 16:15–16"> 所以你們到街頭巷尾，把所有見到的人都請到宴席上來。』</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多前書 6:9–11; 啟示錄 19:6–9; 哥林多後書 12:21"> 奴僕到街上把遇到的人都請了來，好人壞人都有，婚宴大廳裡滿了客人。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="啟示錄 3:4–5; 啟示錄 19:8; 希伯來書 4:12–13"> 「王出來會見在座的客人，發現有一個人沒有穿禮服，</span>
<span className="v" id="v12" data-v="12" data-xref="撒母耳記上 2:9; 約伯記 5:16; 馬太福音 20:13"> 就問他，『朋友，你來這裡怎麼不穿婚宴的禮服呢？』那人無言以對。</span>
<span className="v" id="v13" data-v="13" data-xref="馬太福音 8:12; 馬太福音 25:30; 馬太福音 24:51"> 王便吩咐侍從，『把他手腳綁起來丟到外面的黑暗裡，讓他在那裡哀哭切齒。』</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="彼得後書 1:10; 路加福音 13:23–24; 馬太福音 7:13–14"> 「因為被邀請的人多，選上的人少。」</span>
</div>
</div>

## 以納稅問題刁難耶穌

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="路加福音 20:20–26; 馬可福音 12:13–17; 詩篇 2:2"> 那時，法利賽人出去策劃怎樣從耶穌的話裡找把柄陷害祂。</span>
<span className="v" id="v16" data-v="16" data-xref="馬可福音 3:6; 馬可福音 8:15; 馬可福音 12:14"> 他們派了自己的門徒跟希律黨人一同去問耶穌：「老師，我們知道你誠實無偽，按真理傳上帝的道，不徇情面，因為你不以貌取人。</span>
<span className="v" id="v17" data-v="17" data-xref="路加福音 2:1; 羅馬書 13:6–7; 馬太福音 17:25"> 那麼請告訴我們，你認為向凱撒納稅對不對呢？」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="約翰福音 8:6; 路加福音 5:22; 約翰福音 2:25"> 耶穌看出了他們的惡意，就說：「你們這些偽君子，為什麼試探我呢？</span>
<span className="v" id="v19" data-v="19" data-xref="馬太福音 20:2; 啟示錄 6:6; 馬太福音 18:28"> 拿一個納稅用的錢幣來給我看。」他們就拿給祂一個銀幣。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="路加福音 20:24"> 耶穌問他們：「上面刻的是誰的像和名號？」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="羅馬書 13:7; 箴言 24:21; 使徒行傳 4:19"> 他們說：「凱撒的。」<br />耶穌說：「那麼，屬於凱撒的東西應該給凱撒，屬於上帝的東西應該給上帝。」</span>
<span className="v" id="v22" data-v="22" data-xref="馬可福音 12:12; 馬太福音 22:46; 路加福音 20:25–26"> 他們聽了很驚奇，只好離開祂走了。</span>
</div>
</div>

## 論復活

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="使徒行傳 4:1; 馬可福音 12:18–27; 使徒行傳 23:6–8"> 同一天，不相信死人會復活的撒都該人也來問耶穌，</span>
<span className="v" id="v24" data-v="24" data-xref="申命記 25:5–10; 路加福音 20:28; 路得記 1:11"> 說：「老師，摩西說，『如果一個人死了，沒有兒女，只留下妻子，他的兄弟就當娶嫂嫂，替哥哥傳宗接代。』</span>
<span className="v" id="v25" data-v="25" data-xref="路加福音 20:29–33; 馬可福音 12:19–23; 希伯來書 9:27"> 從前，我們這裡有弟兄七人，老大結了婚，沒有孩子就死了，把妻子留給了弟弟。</span>
<span className="v" id="v26" data-v="26"> 二弟、三弟一直到七弟都相繼娶了嫂嫂。</span>
<span className="v" id="v27" data-v="27"> 最後，那女人也死了。</span>
<span className="v" id="v28" data-v="28"> 那麼，到復活的時候，她將是誰的妻子呢？因為他們都娶過她。」</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="約翰福音 20:9; 羅馬書 15:4; 路加福音 1:37"> 耶穌說：「你們弄錯了。你們不明白聖經，也不知道上帝的能力。</span>
<span className="v" id="v30" data-v="30" data-xref="路加福音 20:34–36; 馬可福音 12:24–25; 馬太福音 24:38"> 因為到復活的時候，人不娶也不嫁，就像天上的天使一樣。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="馬太福音 12:3; 馬太福音 21:16; 馬太福音 21:42"> 「關於死人復活的事，你們沒有讀過上帝對你們說過的話嗎？</span>
<span className="v" id="v32" data-v="32" data-xref="出埃及記 3:6; 馬可福音 12:26–27; 路加福音 20:37–38"> 祂說，『我是亞伯拉罕的上帝，以撒的上帝，雅各的上帝。』<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="出埃及記3·6。">a</a></sup>上帝不是死人的上帝，而是活人的上帝。」</span>
<span className="v" id="v33" data-v="33" data-xref="馬可福音 12:17; 馬可福音 6:2; 約翰福音 7:46"> 眾人聽到祂的教導都很驚奇。</span>
</div>
</div>

## 最大的誡命

<div className="bt">
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="馬可福音 12:28–31; 馬太福音 25:3–5; 馬太福音 12:14"> 法利賽人聽見耶穌使撒都該人無言以對，就聚集在一起。</span>
<span className="v" id="v35" data-v="35" data-xref="路加福音 7:30; 路加福音 10:25–37; 路加福音 11:52"> 其中有位律法專家試探耶穌說：</span>
<span className="v" id="v36" data-v="36" data-xref="馬可福音 12:28–33; 馬太福音 5:19–20; 路加福音 11:42"> 「老師，請問律法中哪一條誡命最重要呢？」</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="馬可福音 12:29–30; 路加福音 10:27; 申命記 6:5"> 耶穌回答說：「『你要全心、全情、全意愛主你的上帝』<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="申命記6·5。">b</a></sup>，</span>
<span className="v" id="v38" data-v="38"> 這是第一條也是最重要的誡命。</span>
<span className="v" id="v39" data-v="39" data-xref="馬可福音 12:31; 路加福音 10:27–37; 利未記 19:18"> 第二條也相似，就是『要愛鄰如己』<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="利未記19·18。">c</a></sup>。</span>
<span className="v" id="v40" data-v="40" data-xref="羅馬書 13:9; 馬太福音 7:12; 約翰一書 4:19–21"> 律法和先知的全部教導都以這兩條誡命為基礎。」</span>
</div>
</div>

## 基督的身分

<div className="bt">
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="路加福音 20:41–44; 馬可福音 12:35–37; 馬太福音 22:34"> 耶穌趁著法利賽人聚在那裡，就問他們：</span>
<span className="v" id="v42" data-v="42" data-xref="耶利米書 23:5–6; 約翰福音 6:68–69; 馬太福音 16:13–17"> 「你們對基督有何看法？祂是誰的後裔？」他們答道：「大衛的後裔。」</span>
</div>
<div className="bp poetry">
<span className="v" id="v43" data-v="43" data-xref="撒母耳記下 23:2; 啟示錄 4:2; 馬可福音 12:36"> 耶穌說：「那麼，為什麼大衛受聖靈感動，稱祂為主呢？大衛曾說，</span>
<span className="v" id="v44" data-v="44" data-xref="詩篇 110:1; 希伯來書 1:13; 使徒行傳 2:34–35"> <span className="pl pl-1">「『主對我主說，</span><br /><span className="pl pl-1">你坐在我的右邊，</span><br /><span className="pl pl-1">等我把你的仇敵放在你腳下。』</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="詩篇110·1。">d</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="羅馬書 1:3–4; 啟示錄 22:16; 約翰福音 8:58"> 既然大衛稱基督為主，基督又怎麼會是大衛的後裔呢？」</span>
<span className="v" id="v46" data-v="46" data-xref="馬可福音 12:34; 路加福音 20:40; 路加福音 14:6"> 沒人能回答耶穌的問題。此後，再沒人敢用問題刁難耶穌。</span>
</div>
</div>

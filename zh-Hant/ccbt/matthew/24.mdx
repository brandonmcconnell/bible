## 預言聖殿被毀

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="馬可福音 13:1–37; 路加福音 21:5–36; 以西結書 8:6"> 耶穌離開聖殿，正往外走的時候，門徒上前把聖殿建築指給祂看。</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 19:44; 耶利米書 26:18; 彌迦書 3:12"> 耶穌對他們說：「你們看見這殿宇了嗎？我實在告訴你們，將來它要被完全拆毀，找不到兩塊疊在一起的石頭。」</span>

## 世界末日的預兆

<div className="bt">
<div className="bp poetry">
<span className="v" id="v3" data-v="3" data-xref="馬可福音 13:3–4; 使徒行傳 1:7; 帖撒羅尼迦前書 5:1–11"> 耶穌正坐在橄欖山上，門徒私下來問祂：「請告訴我們，這事什麼時候會發生？你再來和世界末日的時候會有什麼預兆？」</span>
<span className="v" id="v4" data-v="4" data-xref="約翰一書 4:1; 耶利米書 29:8; 帖撒羅尼迦後書 2:3"> 耶穌回答說：「你們要小心，免得被人迷惑。</span>
<span className="v" id="v5" data-v="5" data-xref="馬太福音 24:11; 馬太福音 24:24; 耶利米書 14:14"> 因為將來會有許多人冒我的名來，說，『我是基督』，欺騙許多人。</span>
<span className="v" id="v6" data-v="6" data-xref="馬可福音 13:7–8; 路加福音 21:9; 彼得前書 3:14–15"> 你們聽見戰爭爆發、戰訊頻傳時，切不可驚慌，因為這些事必然發生，只是末日還沒有到。</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 21:11; 啟示錄 6:8; 以賽亞書 19:2"> 民族將攻打民族，國家將攻打國家，各處將有饑荒和地震。</span>
<span className="v" id="v8" data-v="8" data-xref="帖撒羅尼迦前書 5:3; 彼得前書 4:17–18; 申命記 28:59"> 這些只是災難<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「災難」希臘文是「生產之痛」。">a</a></sup>的開始。</span>
<span className="v" id="v9" data-v="9" data-xref="約翰福音 16:2; 約翰福音 15:19–20; 路加福音 21:16–17"> 「那時，你們將遭人迫害、殺害，並因我的名而被萬民憎恨。</span>
<span className="v" id="v10" data-v="10" data-xref="彌迦書 7:5–6; 路加福音 21:16; 馬太福音 11:6"> 那時，許多人會放棄信仰，互相出賣，彼此憎恨。</span>
<span className="v" id="v11" data-v="11" data-xref="馬太福音 24:24; 馬太福音 7:15; 馬太福音 24:5"> 許多假先知也會出現，迷惑許多人。</span>
<span className="v" id="v12" data-v="12" data-xref="啟示錄 2:4–5; 雅各書 4:1–4; 啟示錄 3:15"> 由於罪惡氾濫，許多人的愛心逐漸冷淡。</span>
<span className="v" id="v13" data-v="13" data-xref="馬太福音 10:22; 馬可福音 13:13; 啟示錄 2:10"> 但堅忍到底的必定得救。</span>
<span className="v" id="v14" data-v="14" data-xref="啟示錄 14:6; 羅馬書 10:18; 羅馬書 16:25–26"> 這天國的福音將傳遍天下，讓萬民都聽見，然後末日才會來臨。</span>
<span className="v" id="v15" data-v="15" data-xref="但以理書 9:27; 但以理書 12:11; 馬可福音 13:14"> 「當你們看見但以理先知所說的『那帶來毀滅的可憎者』<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="但以理書9·27；11·31；12·11。">b</a></sup>站立在聖地的時候（讀者須會意），</span>
<span className="v" id="v16" data-v="16" data-xref="創世記 19:15–17; 路加福音 21:21–22; 希伯來書 11:7"> 猶太地區的人要逃到山上去，</span>
<span className="v" id="v17" data-v="17" data-xref="路加福音 17:31–33; 馬可福音 13:15–16; 馬太福音 10:27"> 在屋頂上的人不要下來拿屋內的東西，</span>
<span className="v" id="v18" data-v="18"> 在田間的人也不要回家取外衣。</span>
<span className="v" id="v19" data-v="19" data-xref="路加福音 23:29–30; 申命記 28:53–56; 路加福音 21:23"> 那時，孕婦和哺育嬰兒的母親們可就遭殃了！</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及記 16:29; 使徒行傳 1:12"> 你們要祈求上帝，不要讓你們逃難的時候遇上冬天或安息日。</span>
<span className="v" id="v21" data-v="21" data-xref="但以理書 12:1; 約珥書 2:2; 瑪拉基書 4:1"> 因為那時世上將有空前絕後的大災難。</span>
<span className="v" id="v22" data-v="22" data-xref="馬可福音 13:20; 提摩太後書 2:10; 馬太福音 24:31"> 如果不縮短災期，恐怕沒有人能活命。但為了上帝的選民，災期必被縮短。</span>
<span className="v" id="v23" data-v="23" data-xref="路加福音 21:8; 路加福音 17:23–24; 申命記 13:1–3"> 「那時，如果有人對你們說，『看啊，基督在這裡！』或說，『基督在那裡！』你們不要相信。</span>
<span className="v" id="v24" data-v="24" data-xref="帖撒羅尼迦後書 2:9–11; 馬可福音 13:22; 啟示錄 13:13–14"> 因為假基督和假先知將出現，行很大的神蹟奇事來迷惑人，如果可能，甚至要迷惑上帝的選民。</span>
<span className="v" id="v25" data-v="25" data-xref="約翰福音 16:1; 路加福音 21:13; 以賽亞書 48:5–6"> 你們要記住，我已經預先告訴你們了。</span>
<span className="v" id="v26" data-v="26" data-xref="路加福音 3:2–3; 以賽亞書 40:3; 馬太福音 3:1"> 「因此，如果有人對你們說，『看啊，基督在曠野！』你們不要出去；或者說，『看啊！基督在內室』，你們也不要相信。</span>
<span className="v" id="v27" data-v="27" data-xref="路加福音 17:24–37; 撒迦利亞書 9:14; 約伯記 37:3"> 因為人子降臨時的情形就像閃電從東方發出一直照到西方。</span>
<span className="v" id="v28" data-v="28" data-xref="路加福音 17:37; 約伯記 39:27–30; 申命記 28:49"> 屍體在哪裡，禿鷹就會聚集在哪裡。</span>
<span className="v" id="v29" data-v="29" data-xref="阿摩司書 8:9; 約珥書 3:15; 以賽亞書 13:10"> 「當災難的日子一過，<br /><span className="pl pl-1">「『太陽昏暗，</span><br /><span className="pl pl-1">月亮無光，</span><br /><span className="pl pl-1">星宿隕落，</span><br /><span className="pl pl-1">天體震動。』</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="以賽亞書13·10；34·4。">c</a></sup></span>
<span className="v" id="v30" data-v="30" data-xref="啟示錄 1:7; 但以理書 7:13; 路加福音 21:27"> 「那時，天上會出現人子降臨的預兆，地上的萬族都要哀哭，他們將看見人子帶著能力和極大的榮耀駕著天上的雲降臨。</span>
<span className="v" id="v31" data-v="31" data-xref="帖撒羅尼迦前書 4:16; 馬可福音 13:27; 以賽亞書 27:13"> 在響亮的號聲中，祂將差遣天使從四面八方、天涯海角招聚祂揀選的人。</span>
</div>
</div>

## 無花果樹的比喻

<div className="bt">
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="馬可福音 13:28–29; 路加福音 21:29–30"> 「你們可以從無花果樹學個道理。當無花果樹發芽長葉的時候，你們就知道夏天快來了。</span>
<span className="v" id="v33" data-v="33" data-xref="雅各書 5:9; 希伯來書 10:37; 以西結書 7:2–14"> 同樣，當你們看見這一切事發生時，就知道人子快來了，就在門口。</span>
<span className="v" id="v34" data-v="34" data-xref="馬可福音 13:30–31; 路加福音 21:32–33; 馬太福音 16:28"> 我實在告訴你們，這個世代還沒有過去，這一切都要發生。</span>
<span className="v" id="v35" data-v="35" data-xref="以賽亞書 40:8; 彼得前書 1:25; 民數記 23:19"> 天地都要消逝，但我的話永不消逝。</span>
</div>
</div>

## 警醒準備

<div className="bt">
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="馬可福音 13:32; 使徒行傳 1:7; 馬太福音 24:44"> 「但沒有人知道那日子和時辰何時來到，連天上的天使也不知道，人子<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="「人子」希臘文是「子」。">d</a></sup>也不知道，只有天父知道。</span>
<span className="v" id="v37" data-v="37" data-xref="路加福音 17:26–27; 創世記 6:1–7; 彼得後書 2:5"> 人子降臨時的情形將像挪亞的時代。</span>
<span className="v" id="v38" data-v="38" data-xref="路加福音 17:26–28; 羅馬書 13:13–14; 路加福音 14:18–20"> 洪水來臨之前的日子裡，人們吃吃喝喝，男婚女嫁，一直到挪亞進方舟那天；</span>
<span className="v" id="v39" data-v="39" data-xref="約翰福音 3:20; 馬太福音 24:37; 使徒行傳 13:41"> 他們懵然不知，直到洪水來把他們全沖走了。人子降臨時的情形也是這樣。</span>
<span className="v" id="v40" data-v="40" data-xref="路加福音 17:34–37; 彼得後書 2:7–9; 彼得後書 2:5"> 那時，兩個人在田裡，一個將被接去，一個將被撇下；</span>
<span className="v" id="v41" data-v="41" data-xref="出埃及記 11:5; 以賽亞書 47:2; 路加福音 17:35"> 兩個女人推磨，一個將被接去，一個將被撇下。</span>
<span className="v" id="v42" data-v="42" data-xref="路加福音 21:36; 帖撒羅尼迦前書 5:6; 馬太福音 25:13"> 所以，你們要警醒，因為你們不知道你們的主會在哪一天來。</span>
<span className="v" id="v43" data-v="43" data-xref="路加福音 12:39; 馬太福音 24:44; 帖撒羅尼迦前書 5:2–6"> 你們都知道，家主若知道賊會在夜裡幾點來，就必警醒，不讓賊入屋偷竊。</span>
<span className="v" id="v44" data-v="44" data-xref="馬太福音 25:10; 馬太福音 24:42; 馬太福音 25:13"> 同樣，你們也要做好準備，因為在你們意想不到的時候，人子就來了。</span>
</div>
</div>

## 兩種奴僕

<div className="bt">
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="馬太福音 25:21; 馬太福音 25:23; 哥林多前書 4:1–2"> 「那麼，誰是那個受主人委託管理家中大小僕役、按時分糧食給他們、又忠心又精明的奴僕呢？</span>
<span className="v" id="v46" data-v="46" data-xref="啟示錄 16:15; 路加福音 12:43; 路加福音 12:37"> 主人回家時，看見他盡忠職守，他就有福了。</span>
<span className="v" id="v47" data-v="47" data-xref="馬太福音 25:23; 馬太福音 25:21; 路加福音 12:37"> 我實在告訴你們，主人一定會把所有產業都交給他管理。</span>
<span className="v" id="v48" data-v="48" data-xref="馬太福音 18:32; 以賽亞書 32:6; 路加福音 12:45"> 但如果奴僕邪惡，以為主人不會那麼快回來，</span>
<span className="v" id="v49" data-v="49" data-xref="啟示錄 17:6; 啟示錄 16:6; 彌迦書 3:5"> 就動手毆打同伴，跟醉漢一起吃喝玩樂，</span>
<span className="v" id="v50" data-v="50" data-xref="帖撒羅尼迦前書 5:2–3; 啟示錄 3:3; 馬太福音 24:42–44"> 主人會在他想不到的日子、不知道的時辰回來，</span>
<span className="v" id="v51" data-v="51" data-xref="馬太福音 8:12; 馬太福音 22:13; 路加福音 12:46"> 嚴厲地懲罰<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="「嚴厲地懲罰」或作「腰斬」。">e</a></sup>他，判他和偽君子同樣的罪。他必在那裡哀哭切齒。</span>
</div>

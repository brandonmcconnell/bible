## 責人先責己

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 6:37; 羅馬書 2:1–2; 雅各書 4:11–12"> 「不要論斷人，免得你們被論斷。</span>
<span className="v" id="v2" data-v="2" data-xref="雅各書 2:13; 馬可福音 4:24; 路加福音 6:38"> 因為你們怎樣論斷別人，也必照樣被論斷；你們用什麼尺度衡量別人，也要用什麼尺度衡量你們。</span>
<span className="v" id="v3" data-v="3" data-xref="約翰福音 8:7–9; 加拉太書 6:1; 路加福音 6:41–42"> 為什麼你只看見你弟兄眼中的小刺，卻看不見自己眼中的大梁呢？</span>
<span className="v" id="v4" data-v="4"> 既然你自己眼中有大梁，又怎麼能對弟兄說『讓我除去你眼中的小刺』呢？</span>
<span className="v" id="v5" data-v="5" data-xref="路加福音 6:42; 詩篇 51:9–13; 馬太福音 23:13–28"> 你這偽君子啊！要先除掉自己眼中的大梁，才能看得清楚，好清除弟兄眼中的小刺。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="箴言 9:7–8; 箴言 23:9; 馬太福音 10:14–15"> 「不要把聖物給狗，免得狗轉過頭來咬你們；也不要把珍珠扔在豬前，免得豬踐踏珍珠。</span>
</div>
</div>

## 祈求、尋找、叩門

<div className="bt">
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="馬太福音 21:22; 約翰一書 3:22; 約翰福音 15:7"> 「祈求，就會給你們；尋找，就會尋見；叩門，就會給你們開門。</span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 81:10; 詩篇 81:16; 路加福音 23:42–43"> 因為凡祈求的，就得到；尋找的，就尋見；叩門的，就給他開門。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="路加福音 11:11–13"> 「你們誰有兒子求餅，卻給他石頭呢？</span>
<span className="v" id="v10" data-v="10"> 求魚，卻給他蛇呢？</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 11:11–13; 雅各書 1:17; 羅馬書 8:32"> 你們雖然邪惡，尚且知道把好東西給兒女，你們的天父豈不更要把好東西賜給求祂的人嗎？</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="路加福音 6:31; 羅馬書 13:8–10; 加拉太書 5:13–14"> 「所以，無論何事，想要別人怎樣對待你們，你們就要怎樣對待別人，這是律法和先知的教導。</span>
</div>
</div>

## 辨別與抉擇

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="路加福音 13:24–25; 箴言 16:25; 約翰福音 14:6"> 「你們要進窄門，因為通向滅亡的門寬，路闊，進去的人也多；</span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 13:23–30; 馬太福音 22:14; 馬太福音 16:24–25"> 但通向永生的門小，路窄，找到的人也少。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="約翰一書 4:1; 彼得後書 2:1–3; 馬太福音 24:11"> 「你們要提防假先知，他們披著羊皮到你們當中，骨子裡卻是兇殘的狼。</span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 6:43–45; 馬太福音 12:33; 雅各書 3:12"> 你們可以憑他們結的果子認出他們。荊棘怎能結出葡萄呢？蒺藜怎能長出無花果呢？</span>
<span className="v" id="v17" data-v="17" data-xref="馬太福音 12:33–35; 加拉太書 5:22–24; 以弗所書 5:9"> 同樣，好樹結好果子，壞樹結壞果子；</span>
<span className="v" id="v18" data-v="18" data-xref="加拉太書 5:17; 約翰一書 3:9–10"> 好樹結不出壞果子，壞樹也結不出好果子。</span>
<span className="v" id="v19" data-v="19" data-xref="馬太福音 3:10; 希伯來書 6:8; 約翰福音 15:2–6"> 凡不結好果子的樹，都要被砍下來扔進火裡。</span>
<span className="v" id="v20" data-v="20" data-xref="馬太福音 7:16; 使徒行傳 5:38"> 因此，你們可以憑他們結的果子認出他們。</span>
<span className="v" id="v21" data-v="21" data-xref="羅馬書 2:13; 路加福音 6:46; 雅各書 1:22"> 並不是所有稱呼我『主啊，主啊』的人都能進天國，只有遵行我天父旨意的人才能進去。</span>
<span className="v" id="v22" data-v="22" data-xref="路加福音 13:25–27; 哥林多前書 13:1–2; 瑪拉基書 3:17–18"> 在審判那天，很多人會對我說，『主啊，主啊，我們不是奉你的名傳道，奉你的名趕鬼，奉你的名行了許多神蹟嗎？』</span>
<span className="v" id="v23" data-v="23" data-xref="馬太福音 25:41; 詩篇 6:8; 路加福音 13:25"> 我會清楚地告訴他們，『我從來不認識你們，你們這些作惡的人走開！』</span>
</div>
</div>

## 兩種蓋房子的人

<div className="bt">
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="路加福音 6:47–49; 約翰福音 13:17; 哥林多前書 3:10–11"> 「所以，凡聽了我的這些話就去行的人，就像聰明人把房子建在磐石上。</span>
<span className="v" id="v25" data-v="25" data-xref="雅各書 1:12; 詩篇 125:1–2; 彼得前書 1:7"> 遇到風吹雨打、洪水沖擊，房子仍屹立不倒，因為它建基在磐石上。</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米書 8:9; 路加福音 6:49; 雅各書 2:20"> 凡聽了我這些話不去行的，就像愚昧人把房子建在沙土上。</span>
<span className="v" id="v27" data-v="27" data-xref="馬太福音 13:19–22; 彼得後書 2:20–22; 哥林多前書 3:13"> 遇到風吹雨打、洪水沖擊，房子就倒塌了，而且倒塌得很厲害。」</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="路加福音 4:32; 馬可福音 1:22; 約翰福音 7:46"> 耶穌講完這番話後，眾人對祂的教導感到驚奇，</span>
<span className="v" id="v29" data-v="29" data-xref="希伯來書 4:12–13; 路加福音 20:8; 申命記 18:18–19"> 因為祂教導他們時像個有權柄的人，不像他們的律法教師。</span>
</div>
</div>

## 稱讚腓利門

<div className="bt">
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="羅馬書 1:8; 以弗所書 1:16; 帖撒羅尼迦後書 1:3"> 腓利門弟兄，我每次為你們禱告時都會感謝我的上帝，</span>
<span className="v" id="v5" data-v="5" data-xref="歌羅西書 1:4; 以弗所書 1:15; 哥林多前書 16:1"> 因為我聽說了你對眾聖徒的愛心和對主耶穌的信心。</span>
<span className="v" id="v6" data-v="6" data-xref="腓立比書 1:9–11; 彼得後書 1:8; 歌羅西書 1:9"> 我求上帝使你因著有份於信仰而明白我們在基督裡所擁有的一切福分。</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多後書 7:13; 帖撒羅尼迦前書 3:9; 哥林多後書 7:4"> 弟兄啊，你的愛心給我帶來極大的喜樂和安慰，因為你使眾聖徒感到欣慰。</span>
</div>
</div>

## 憑愛心求情

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="帖撒羅尼迦前書 2:6; 哥林多後書 10:8; 哥林多後書 3:12"> 因此，我儘管可以靠著基督吩咐你去做當做的事，</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多後書 5:20; 以弗所書 4:1; 羅馬書 12:1"> 然而我這上了年紀又為基督耶穌的緣故被囚禁的保羅寧願憑愛心求你，</span>
<span className="v" id="v10" data-v="10" data-xref="歌羅西書 4:9; 哥林多前書 4:15; 提摩太前書 1:2"> 就是替阿尼西謀<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「阿尼西謀」這個名字意思是有用、有益處。">a</a></sup>求你。他是我在獄中帶領歸主的屬靈兒子，</span>
<span className="v" id="v11" data-v="11" data-xref="提摩太後書 4:11; 約伯記 30:1–2; 彼得前書 2:10"> 他過去對你沒有什麼益處，但現在對你對我都有益處。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="馬太福音 6:14–15; 耶利米書 31:20; 馬可福音 11:25"> 我現在派我深愛的阿尼西謀回你那裡。</span>
<span className="v" id="v13" data-v="13" data-xref="腓立比書 1:7; 以弗所書 3:1; 哥林多前書 16:17"> 我本想把他留在身邊，讓他在我為傳福音而坐牢期間替你服侍我。</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多後書 9:7; 歷代志上 29:17; 彼得前書 5:2–3"> 不過，未經你同意，我不願這樣做，免得你的善行是出於勉強，而非自願。</span>
<span className="v" id="v15" data-v="15" data-xref="創世記 50:20; 創世記 45:5–8; 以賽亞書 20:6"> 也許他暫時離開你是為了讓你以後永遠得到他。</span>
<span className="v" id="v16" data-v="16" data-xref="歌羅西書 3:22; 馬太福音 23:8; 哥林多前書 7:22"> 你得到的不再是一個奴隸，而是一位遠超過奴隸的親愛弟兄。對我而言，的確如此；從人的角度和主內關係而言，他更是你親愛的弟兄。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="哥林多後書 8:23; 馬太福音 10:40; 腓利門書 1:12"> 你若當我是同伴，就請你像接納我一樣接納他。</span>
<span className="v" id="v18" data-v="18" data-xref="以賽亞書 53:4–7"> 如果他得罪你，或虧欠你什麼，都記在我的賬上吧。</span>
<span className="v" id="v19" data-v="19" data-xref="加拉太書 6:11; 加拉太書 5:2; 哥林多前書 4:15"> 我保羅在此親筆保證，我必償還。其實我不說你也知道，你欠我的是你整個人。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="約翰三書 1:4; 腓利門書 1:7; 腓利門書 1:12"> 弟兄啊，看在主的份上，讓我從你那裡得益處，在基督裡心得安慰吧！</span>
<span className="v" id="v21" data-v="21" data-xref="帖撒羅尼迦後書 3:4; 哥林多後書 2:3; 哥林多後書 7:16"> 我寫信給你，深信你一定會照辦，甚至超過我的要求。</span>
<span className="v" id="v22" data-v="22" data-xref="哥林多後書 1:11; 腓立比書 2:24; 約翰二書 1:12"> 同時，也請你為我預備住處，因為我盼望藉著你們的禱告，我可以蒙恩到你們那裡。</span>
</div>
</div>

## 問候

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="歌羅西書 1:7; 羅馬書 16:7; 歌羅西書 4:12"> 為了基督耶穌的緣故和我一同坐牢的以巴弗問候你。</span>
<span className="v" id="v24" data-v="24" data-xref="提摩太後書 4:10–11; 歌羅西書 4:14; 歌羅西書 4:10"> 此外，我的同工馬可、亞里達古、底馬和路加都問候你。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="提摩太後書 4:22; 羅馬書 16:23; 羅馬書 16:20"> 願我們主耶穌基督的恩典與你們的靈同在。阿們！</span>
</div>
</div>

## 真葡萄樹

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="耶利米書 2:21; 以賽亞書 27:2–3; 哥林多前書 3:9"> 「我是真葡萄樹，我父是栽培的人。</span>
<span className="v" id="v2" data-v="2" data-xref="馬太福音 3:10; 希伯來書 12:10–11; 馬太福音 15:13"> 屬於我的枝子如果不結果子，祂就把它剪掉；如果結果子，祂便修剪它，讓它結更多果子。</span>
<span className="v" id="v3" data-v="3" data-xref="約翰福音 17:17; 以弗所書 5:26; 彼得前書 1:22"> 因著我對你們講的道，你們已經潔淨了。</span>
<span className="v" id="v4" data-v="4" data-xref="約翰一書 2:6; 加拉太書 2:20; 約翰福音 8:31"> 你們要常在我裡面，我就常在你們裡面。枝子若離開葡萄樹，就不能結果子。同樣，你們若不常在我裡面，也不能結果子。</span>
<span className="v" id="v5" data-v="5" data-xref="腓立比書 4:13; 歌羅西書 1:10; 約翰福音 15:16"> 「我是葡萄樹，你們是枝子。常在我裡面的，我也常在他裡面，他就會多結果子，因為你們離了我什麼都不能做。</span>
<span className="v" id="v6" data-v="6" data-xref="馬太福音 7:19; 希伯來書 6:7–8; 馬太福音 13:41"> 不常在我裡面的人就像扔在外面枯乾的枝子，最後只有被人拾起來扔進火裡燒掉。</span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 37:4; 約翰一書 5:14; 約翰福音 14:13"> 你們若常在我裡面，我的話也常在你們裡面，無論你們求什麼，都會得到應允。</span>
<span className="v" id="v8" data-v="8" data-xref="約翰福音 8:31; 馬太福音 5:16; 腓立比書 1:11"> 你們多結果子，證明自己是我的門徒，就會給我父帶來榮耀。</span>
<span className="v" id="v9" data-v="9" data-xref="約翰福音 17:23–24; 約翰福音 17:26; 約翰一書 2:28"> 父怎樣愛我，我也怎樣愛你們。你們要常在我的愛中。</span>
<span className="v" id="v10" data-v="10" data-xref="約翰福音 14:15; 約翰一書 5:3; 約翰一書 3:21–24"> 你們若遵守我的命令，就必常在我的愛中，正如我遵守了父的命令，常在父的愛中一樣。</span>
<span className="v" id="v11" data-v="11" data-xref="約翰福音 17:13; 羅馬書 15:13; 約翰福音 16:24"> 「我把這些事告訴你們，是要叫你們心裡有我的喜樂，讓你們的喜樂滿溢。</span>
<span className="v" id="v12" data-v="12" data-xref="約翰一書 4:21; 彼得前書 4:8; 約翰福音 13:34"> 你們要彼此相愛，像我愛你們一樣，這就是我的命令。</span>
<span className="v" id="v13" data-v="13" data-xref="約翰福音 10:11; 以弗所書 5:2; 羅馬書 5:6–8"> 為朋友捨命是最偉大的愛了。</span>
<span className="v" id="v14" data-v="14" data-xref="馬太福音 12:50; 約翰一書 5:3; 雅各書 2:23"> 你們如果照我的吩咐去做，就是我的朋友。</span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 25:14; 哥林多前書 2:9–12; 馬太福音 13:11"> 我不再稱你們為奴僕，因為奴僕不知道主人的事。我稱你們為朋友，因為我把從父那裡聽見的一切都告訴了你們。</span>
<span className="v" id="v16" data-v="16" data-xref="約翰福音 15:19; 耶利米書 1:5–7; 以弗所書 2:10"> 不是你們揀選了我，而是我揀選了你們，並且派你們出去結長存的果子。這樣，你們奉我的名無論向父求什麼，祂都會賜給你們。</span>
<span className="v" id="v17" data-v="17" data-xref="約翰福音 15:12; 約翰一書 3:14–17; 彼得前書 2:17"> 我把這些事吩咐你們，是要叫你們彼此相愛。</span>
</div>
</div>

## 被世人憎惡

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="約翰一書 3:13; 約翰福音 7:7; 馬可福音 13:13"> 「如果世人恨你們，要知道，他們恨你們以前已經恨我了。</span>
<span className="v" id="v19" data-v="19" data-xref="約翰一書 4:4–5; 約翰福音 17:14–16; 以弗所書 1:4–11"> 如果你們屬於這個世界，世人一定會愛你們。可是你們不屬於這世界，我已經把你們從世上揀選出來，因此世人恨你們。</span>
<span className="v" id="v20" data-v="20" data-xref="提摩太後書 3:12; 約翰福音 13:16; 馬太福音 10:24"> 你們要記住我說的話，『奴僕不能大過主人。』<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="約翰福音13·16。">a</a></sup>他們如果迫害我，也必迫害你們；他們如果遵行我的話，也必遵行你們的話。</span>
<span className="v" id="v21" data-v="21" data-xref="馬太福音 10:22; 約翰福音 16:3; 馬太福音 10:18"> 世人將因為我的名而這樣對待你們，因為他們不認識差我來的那位。</span>
<span className="v" id="v22" data-v="22" data-xref="約翰福音 9:41; 雅各書 4:17; 使徒行傳 17:30"> 我如果沒有來教導他們，他們就沒有罪了，但現在他們的罪無可推諉。</span>
<span className="v" id="v23" data-v="23" data-xref="約翰福音 8:40–42; 約翰二書 1:9; 約翰一書 2:23"> 恨我的，也恨我的父。</span>
<span className="v" id="v24" data-v="24" data-xref="約翰福音 5:36; 約翰福音 14:9; 約翰福音 7:31"> 我如果沒有在他們當中行過空前的神蹟，他們就沒有罪了。然而，他們親眼看見了，卻還是恨我和我的父。</span>
<span className="v" id="v25" data-v="25" data-xref="詩篇 109:3; 詩篇 69:4; 詩篇 35:19"> 這是要應驗他們律法書上的話，『他們無故地恨我。』<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="詩篇35·19；69·4。">b</a></sup></span>
<span className="v" id="v26" data-v="26" data-xref="約翰福音 14:26; 約翰福音 14:16–17; 約翰福音 16:13–15"> 「我要從父那裡為你們差護慰者來，祂就是從父而來的真理之靈。祂來了要為我作見證。</span>
<span className="v" id="v27" data-v="27" data-xref="約翰一書 4:14; 約翰福音 21:24; 使徒行傳 10:39–42"> 你們也要為我作見證，因為你們從開始就與我在一起。</span>
</div>

## 井邊談道

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="約翰福音 3:26; 約翰福音 3:22; 哥林多後書 4:5"> 耶穌得知法利賽人聽見祂比約翰收徒施洗的人數還多，便離開猶太，返回加利利。其實不是耶穌親自施洗，而是祂的門徒施洗。</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 17:11; 路加福音 2:49; 路加福音 9:51–52"> 祂回加利利的路上必須經過撒瑪利亞。</span>
<span className="v" id="v5" data-v="5" data-xref="約書亞記 24:32; 創世記 33:19; 創世記 48:22"> 於是，祂來到撒瑪利亞的一座城，名叫敘加，靠近雅各留給他兒子約瑟的那塊地。</span>
<span className="v" id="v6" data-v="6" data-xref="希伯來書 4:15; 希伯來書 2:17; 馬太福音 8:24"> 雅各井就在那個地方。耶穌走路疲乏，便坐在井旁休息。那時大約是正午。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="馬太福音 10:42; 列王紀上 17:10; 創世記 24:43"> 門徒都進城買食物去了。有一個撒瑪利亞的婦人來打水，耶穌對她說：「請給我一點水喝。」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="使徒行傳 10:28; 馬太福音 10:5; 列王紀下 17:24–41"> 撒瑪利亞婦人說：「你是個猶太人，怎麼向我這撒瑪利亞婦人要水喝？」原來猶太人和撒瑪利亞人互不往來。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="約翰福音 4:14; 啟示錄 7:17; 約翰福音 7:37–39"> 耶穌回答說：「要是你知道上帝的恩賜，又知道向你要水喝的是誰，你早就求祂了，祂也早就把活水給你了。」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="哥林多前書 2:14; 約翰福音 3:4"> 婦人說：「先生，你沒有打水的器具，井又深，你從哪裡得到活水呢？</span>
<span className="v" id="v12" data-v="12" data-xref="約翰福音 4:6; 約翰福音 8:53; 馬太福音 12:42"> 我們的祖先雅各把這口井留給我們，他自己和他的兒女、牲畜都喝這井裡的水，難道你比他更大嗎？」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="約翰福音 6:27; 以賽亞書 65:13–14; 路加福音 16:24"> 耶穌說：「人喝了這井裡的水，還會再渴，</span>
<span className="v" id="v14" data-v="14" data-xref="約翰福音 7:38–39; 約翰福音 6:35; 以賽亞書 49:10"> 但是喝了我所賜的水，永遠不會再渴。我所賜的水要在他裡面成為生命的泉源，湧流不息，直到永生。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="約翰福音 6:34; 羅馬書 8:5; 詩篇 4:6"> 婦人說：「先生，請你把這水賜給我，我就不會再渴了，也用不著來打水了。」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="希伯來書 4:13; 啟示錄 2:23; 約翰福音 4:18"> 耶穌說：「去叫你的丈夫來。」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17"> 婦人說：「我沒有丈夫。」耶穌說：「你說的對，你沒有丈夫，</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米書 3:20; 哥林多前書 7:10–11; 羅馬書 7:3"> 因為你有過五個丈夫了，現在和你在一起的也不是你丈夫。你說的是實話。」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="路加福音 7:39; 約翰福音 6:14; 約翰福音 9:17"> 婦人說：「先生，我看你一定是先知。</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 12:6–7; 申命記 27:12; 申命記 11:29"> 我們的祖先一向都是在這山上敬拜上帝，你們卻說耶路撒冷才是敬拜的地方。」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="提摩太前書 2:8; 瑪拉基書 1:11; 約翰福音 4:23"> 耶穌回答說：「婦人，你要信我。時候快到了，你們將不在這山上或耶路撒冷敬拜父。</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行傳 17:23; 以賽亞書 2:3; 羅馬書 9:4–5"> 你們不知道你們敬拜的是誰，我們知道我們敬拜的是誰，因為救恩是從猶太人出來的。</span>
<span className="v" id="v23" data-v="23" data-xref="腓立比書 3:3; 約翰福音 5:25; 馬太福音 15:7–9"> 時候快到了，現在就是，真正敬拜父的，要用心靈<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「用心靈」或譯「靠聖靈」；24節同。">a</a></sup>、按真理敬拜祂，因為父尋找的正是這樣敬拜祂的人。</span>
<span className="v" id="v24" data-v="24" data-xref="哥林多後書 3:17; 馬太福音 15:8–9; 腓立比書 3:3"> 上帝是靈，所以必須用心靈、按真理敬拜祂。」</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="約翰福音 1:49; 但以理書 9:24–26; 約翰福音 1:41–42"> 婦人說：「我知道那被稱為基督的彌賽亞要來。祂來了，會把一切都告訴我們。」</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="約翰福音 8:24; 馬可福音 14:61–62; 羅馬書 10:20–21"> 耶穌說：「我這位跟你說話的就是。」</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="路加福音 7:39; 約翰福音 4:8–9"> 這時，門徒回來了，看見耶穌和一個婦人談話，感到驚奇，可是沒有人問：「你想要什麼？」或問：「你為什麼和她說話？」</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="約翰福音 4:7; 路加福音 24:33; 馬可福音 16:8–10"> 那婦人撇下水罐，回到城裡，對人們說：</span>
<span className="v" id="v29" data-v="29" data-xref="啟示錄 22:17; 哥林多前書 14:24–25; 約翰福音 4:25"> 「你們快來看啊！有一個人把我做過的事都說了出來。莫非祂就是基督？」</span>
<span className="v" id="v30" data-v="30" data-xref="羅馬書 5:20; 使徒行傳 8:5–8; 路加福音 17:16–18"> 眾人聽了就到城外去見耶穌。</span>
</div>
</div>

## 撒種與收割

<div className="bt">
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="約翰福音 1:38; 創世記 24:33; 使徒行傳 16:30–34"> 其間，門徒對耶穌說：「老師，請吃點東西吧。」</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="約伯記 23:12; 詩篇 119:103; 約翰福音 4:34"> 耶穌說：「我有食物吃，是你們不知道的。」</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="馬太福音 16:6–11; 路加福音 9:45"> 門徒彼此議論說：「難道有人給祂吃的了？」</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="約翰福音 6:38; 約翰福音 5:30; 約伯記 23:12"> 耶穌說：「我的食物就是遵行差我來者的旨意，完成祂的工作。</span>
<span className="v" id="v35" data-v="35" data-xref="路加福音 10:2–3; 馬太福音 9:37–38; 約翰福音 4:30"> 你們不是說還有四個月才到收割的時候嗎？舉目向田觀看吧，莊稼已經熟了，可以收割了。</span>
<span className="v" id="v36" data-v="36" data-xref="雅各書 5:19–20; 羅馬書 1:13; 哥林多前書 3:5–9"> 收割的人可以得到報酬並為永生收穫果實，叫撒種的和收割的一同快樂。</span>
<span className="v" id="v37" data-v="37" data-xref="彌迦書 6:15; 約伯記 31:8; 路加福音 19:21"> 俗語說得好，『那人撒種，這人收割。』</span>
<span className="v" id="v38" data-v="38" data-xref="約翰福音 1:7; 歷代志下 36:15; 使徒行傳 10:42–43"> 我派你們去收割那些你們沒有勞作的莊稼，別人勞苦，你們享受他們勞苦的成果。」</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="約翰福音 4:29; 約翰福音 4:5; 約翰福音 10:41–42"> 那城裡有許多撒瑪利亞人信了耶穌，因為那婦人作見證說：「祂把我做過的事都說了出來。」</span>
<span className="v" id="v40" data-v="40" data-xref="啟示錄 3:20; 使徒行傳 16:15; 路加福音 24:29"> 撒瑪利亞人來見耶穌，懇求祂留下來，祂就在那裡住了兩天。</span>
<span className="v" id="v41" data-v="41" data-xref="哥林多前書 2:4–5; 使徒行傳 1:8; 使徒行傳 8:12"> 因為耶穌傳的道，信的人更多了。</span>
<span className="v" id="v42" data-v="42" data-xref="約翰一書 4:14; 約翰福音 1:29; 約翰一書 5:20"> 他們對那婦人說：「現在我們信，不再是因為你的話，而是我們親耳聽見了，知道祂真是世人的救主。」</span>
</div>
</div>

## 耶穌治好大臣的兒子

<div className="bt">
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="馬太福音 4:13; 羅馬書 15:8; 馬可福音 7:27–28"> 兩天後，耶穌動身前往加利利。</span>
<span className="v" id="v44" data-v="44" data-xref="馬太福音 13:57; 路加福音 4:24; 馬可福音 6:4"> 祂以前說過：「先知在本鄉不受人尊敬。」</span>
<span className="v" id="v45" data-v="45" data-xref="約翰福音 2:23; 約翰福音 2:13–16; 申命記 16:16"> 然而，祂回到加利利卻受到當地人歡迎，因為他們上耶路撒冷過節時，看見了祂的一切作為。</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="約翰福音 2:1–11; 路加福音 7:2; 何西阿書 5:15"> 祂又到了加利利的迦拿，就是祂從前把水變成酒的地方。有一個大臣的兒子在迦百農患了病。</span>
<span className="v" id="v47" data-v="47" data-xref="約翰福音 4:3; 約翰福音 11:21; 約翰福音 11:32"> 大臣聽說耶穌從猶太來到加利利，立刻趕來見祂，求祂去醫治他病危的兒子。</span>
</div>
<div className="bp">
<span className="v" id="v48" data-v="48" data-xref="約翰福音 20:29; 希伯來書 2:4; 哥林多前書 1:22"> 耶穌對他說：「你們不看見神蹟奇事，總不相信。」</span>
</div>
<div className="bp">
<span className="v" id="v49" data-v="49" data-xref="馬可福音 5:23; 詩篇 88:10–12; 詩篇 40:17"> 大臣說：「先生，趁我的孩子還沒死，求你趕快去！」</span>
</div>
<div className="bp">
<span className="v" id="v50" data-v="50" data-xref="馬太福音 8:13; 馬可福音 7:29–30; 羅馬書 4:20–21"> 耶穌說：「回去吧，你的兒子好了。」他相信耶穌的話，就回去了。</span>
</div>
<div className="bp">
<span className="v" id="v51" data-v="51" data-xref="列王紀上 17:23; 約翰福音 4:50; 約翰福音 4:53"> 途中遇見奴僕來報信，說他兒子好了，</span>
<span className="v" id="v52" data-v="52"> 他就問什麼時候好的。僕人說：「昨天下午一點鐘燒就退了。」</span>
</div>
<div className="bp">
<span className="v" id="v53" data-v="53" data-xref="詩篇 107:20; 路加福音 19:9; 使徒行傳 16:34"> 他知道正是那時候耶穌對他說：「你的兒子好了。」他和全家都信了。</span>
</div>
<div className="bp">
<span className="v" id="v54" data-v="54" data-xref="約翰福音 4:45; 約翰福音 2:1–11"> 這是耶穌從猶太回到加利利後行的第二個神蹟。</span>
</div>
</div>

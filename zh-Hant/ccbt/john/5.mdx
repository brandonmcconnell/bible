## 耶穌在畢士大池邊治病

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命記 16:16; 出埃及記 23:14–17; 出埃及記 34:23"> 這事以後，猶太人的一個節期到了，耶穌便上了耶路撒冷。</span>
<span className="v" id="v2" data-v="2" data-xref="尼希米記 12:39; 尼希米記 3:1; 尼希米記 3:32"> 耶路撒冷靠近羊門的地方有一個水池，希伯來話叫畢士大，池邊有五條走廊，</span>
<span className="v" id="v3" data-v="3" data-xref="馬可福音 3:1–4; 路加福音 7:22; 馬太福音 15:30"> 裡面躺著許多瞎眼的、瘸腿的、癱瘓的等病人。</span>
<span className="v" id="v4" data-v="4"> 他們都在等候主的天使偶爾來攪動池水。水動時，第一個下去的，無論患了什麼病都會痊癒。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古卷無4節。">a</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="使徒行傳 3:2; 路加福音 8:43; 馬可福音 9:21"> 那裡有一個人病了三十八年。</span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 18:41; 希伯來書 4:15; 希伯來書 4:13"> 耶穌看他躺著，知道他病了很久，就問他：「你想痊癒嗎？」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="詩篇 72:12; 申命記 32:36; 哥林多前書 9:24"> 那人回答說：「先生，水動的時候，沒有人把我放進池子裡，我要下去的時候，別人總是先我一步。」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="路加福音 5:24; 馬太福音 9:6; 馬可福音 2:11"> 耶穌對他說：「起來，拿上你的墊子走吧！」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="使徒行傳 3:7–8; 約翰福音 9:14; 馬可福音 3:2–4"> 那人立刻痊癒了，拿起墊子開始行走。那天是安息日，</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米書 17:21; 路加福音 6:2; 約翰福音 9:16"> 猶太人便對那人說：「今天是安息日，你不可拿著墊子走路。」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="馬可福音 2:9–11; 約翰福音 9:16"> 他說：「那位醫治我的叫我拿起墊子走。」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="馬太福音 21:23; 士師記 6:29; 羅馬書 10:2"> 他們問他：「叫你拿起墊子走的人是誰？」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="路加福音 4:30; 路加福音 24:31; 約翰福音 8:59"> 那人不知道是誰，因為那裡人多，耶穌已經躲開了。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="約翰福音 8:11; 利未記 26:23–24; 詩篇 118:18"> 後來，耶穌在聖殿裡遇見他，對他說：「你已經完全好了，不要再犯罪了，免得你遭遇更不幸的事。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="約翰福音 9:11–12; 約翰福音 4:29; 約翰福音 9:25"> 那人便去告訴猶太人，醫治他的是耶穌。</span>
<span className="v" id="v16" data-v="16" data-xref="約翰福音 10:39; 約翰福音 7:19–20; 馬可福音 3:6"> 因為耶穌在安息日給人治病，猶太人便開始迫害祂。</span>
<span className="v" id="v17" data-v="17" data-xref="約翰福音 9:4; 約翰福音 14:10; 歌羅西書 1:16"> 耶穌對他們說：「我父至今仍在做工，我也在做工。」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="約翰福音 10:30; 約翰福音 10:33; 約翰福音 19:7"> 猶太人聽了，更想殺祂，因祂不但干犯安息日，還稱上帝為父，把自己看作與上帝平等。</span>
</div>
</div>

## 聖子的權柄

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="約翰福音 12:49; 約翰福音 8:28; 約翰福音 14:10"> 耶穌說：「我實實在在地告訴你們，子憑自己什麼都不能做，唯有看見父做什麼，子才做什麼。無論父做什麼，子也照樣做。</span>
<span className="v" id="v20" data-v="20" data-xref="約翰福音 3:35; 馬太福音 3:17; 約翰福音 17:26"> 父因為愛子，便把自己的一切作為給祂看，而且還要把比這些更大的作為給祂看，叫你們驚奇。</span>
<span className="v" id="v21" data-v="21" data-xref="羅馬書 8:11; 申命記 32:39; 約翰福音 11:25"> 父如何使死人復活並賜生命給他們，子也照樣想賜生命給誰，就賜給誰。</span>
<span className="v" id="v22" data-v="22" data-xref="約翰福音 5:27; 使徒行傳 17:31; 哥林多後書 5:10"> 父不審判人，祂將審判的事全交給子，</span>
<span className="v" id="v23" data-v="23" data-xref="約翰一書 2:23; 路加福音 10:16; 馬太福音 11:27"> 叫人尊敬子如同尊敬父。不尊敬子的，就是不尊敬差子來的父。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="約翰福音 3:36; 約翰福音 6:40; 約翰一書 5:11–13"> 「我實實在在地告訴你們，誰聽從我的話，又信差我來的那位，誰就有永生，不被定罪，已經出死入生了。</span>
<span className="v" id="v25" data-v="25" data-xref="約翰福音 5:28; 以弗所書 5:14; 以弗所書 2:5"> 我實實在在地告訴你們，時候快到了，現在就是，死人將聽見上帝兒子的聲音，聽見的將活過來。</span>
<span className="v" id="v26" data-v="26" data-xref="約翰福音 11:26; 約翰福音 1:4; 出埃及記 3:14"> 因為正如父自己是生命的源頭，祂也同樣讓子作生命的源頭，</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行傳 10:42; 約翰福音 5:22; 使徒行傳 17:31"> 又把審判的權柄交給祂，因為祂是人子。</span>
<span className="v" id="v28" data-v="28" data-xref="啟示錄 20:12; 帖撒羅尼迦前書 4:14–17; 以賽亞書 26:19"> 你們不要驚奇，時候將到，一切在墳墓裡的死人都要聽見上帝兒子的聲音，</span>
<span className="v" id="v29" data-v="29" data-xref="但以理書 12:2–3; 羅馬書 2:6–10; 使徒行傳 24:15"> 他們都要從墳墓裡出來。行善的人復活後得永生，作惡的人復活後被定罪。</span>
</div>
</div>

## 見證耶穌

<div className="bt">
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="約翰福音 6:38; 約翰福音 5:19; 約翰福音 4:34"> 「我憑自己不能做什麼，我按從父聽到的指示審判，我的審判是公平的；因為我不是按自己的旨意行，而是按差我來者的旨意行。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="箴言 27:2; 約翰福音 8:54; 啟示錄 3:14"> 「如果我為自己作見證，我的見證是無效的。</span>
<span className="v" id="v32" data-v="32" data-xref="約翰福音 1:33; 約翰福音 12:28–30; 約翰福音 5:36–37"> 然而，另有一位給我作見證，我知道他為我做的見證是真實的。</span>
<span className="v" id="v33" data-v="33" data-xref="約翰福音 1:29–34; 約翰福音 3:26–36; 約翰福音 1:15–27"> 你們曾派人到約翰那裡，他為真理做過見證。</span>
<span className="v" id="v34" data-v="34" data-xref="路加福音 19:41–42; 約翰福音 20:31; 約翰一書 5:9"> 其實我並不需要人的見證，我之所以提起這些事是為了使你們得救。</span>
<span className="v" id="v35" data-v="35" data-xref="彼得後書 1:19; 約翰福音 1:7–8; 馬太福音 11:11"> 約翰是一盞點亮的明燈，你們情願在他的光中歡樂一時。</span>
<span className="v" id="v36" data-v="36" data-xref="約翰福音 10:25; 約翰福音 10:37–38; 約翰福音 15:24"> 但是我有比約翰更大的見證，因為父交待我去完成的工作，就是我現在所做的工作，證明我是父差來的。</span>
<span className="v" id="v37" data-v="37" data-xref="約翰福音 8:18; 約翰福音 1:18; 馬太福音 3:17"> 差我來的父曾親自為我做過見證。你們從未聽過祂的聲音，從未見過祂，</span>
<span className="v" id="v38" data-v="38" data-xref="約翰一書 2:14; 申命記 6:6–9; 約翰福音 12:44–48"> 心裡也沒有祂的道，因為你們不信祂差來的那位。</span>
<span className="v" id="v39" data-v="39" data-xref="路加福音 24:27; 路加福音 24:44; 彼得後書 1:19–21"> 你們研讀聖經，以為從聖經中可以得到永生。其實為我作見證的正是這聖經，</span>
<span className="v" id="v40" data-v="40" data-xref="約翰福音 3:19; 約翰福音 1:11; 詩篇 81:11"> 但你們卻不肯到我這裡來得生命。</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="約翰福音 7:18; 約翰福音 5:34; 帖撒羅尼迦前書 2:6"> 「我不接受人給的榮耀，</span>
<span className="v" id="v42" data-v="42" data-xref="約翰一書 4:20; 約翰一書 3:17; 約翰福音 2:25"> 我知道你們沒有愛上帝的心。</span>
<span className="v" id="v43" data-v="43" data-xref="約翰福音 10:25; 馬太福音 24:5; 約翰福音 17:4–6"> 我奉我父的名來，你們不接受我；若有人奉自己的名來，你們卻接受他。</span>
<span className="v" id="v44" data-v="44" data-xref="約翰福音 12:43; 羅馬書 2:29; 腓立比書 2:3"> 你們喜歡互相恭維，卻不追求從獨一上帝來的榮耀，怎能信我呢？</span>
<span className="v" id="v45" data-v="45" data-xref="羅馬書 3:19–20; 加拉太書 3:10; 哥林多後書 3:7–11"> 不要以為我會在父面前控告你們，控告你們的是你們所仰賴的摩西。</span>
<span className="v" id="v46" data-v="46" data-xref="申命記 18:15; 申命記 18:18–19; 約翰福音 1:45"> 你們若信摩西，就會信我，因為他的書裡也提到我。</span>
<span className="v" id="v47" data-v="47" data-xref="路加福音 16:31; 路加福音 16:29"> 你們如果連他寫的都不信，又怎麼會信我的話呢？」</span>
</div>
</div>

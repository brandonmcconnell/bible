## 生命之道

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 1:1; 約翰福音 17:5; 啟示錄 19:13"> 太初，道已經存在，道與上帝同在，道就是上帝。</span>
<span className="v" id="v2" data-v="2"> 祂太初就與上帝同在。</span>
<span className="v" id="v3" data-v="3" data-xref="歌羅西書 1:16–17; 哥林多前書 8:6; 啟示錄 4:11"> 萬物都是藉著祂造的<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「造的」或譯「存在」。">a</a></sup>，受造之物沒有一樣不是藉著祂造的。</span>
<span className="v" id="v4" data-v="4" data-xref="約翰福音 8:12; 約翰福音 12:46; 約翰福音 5:26"> 祂裡面有生命，這生命是人類的光。</span>
<span className="v" id="v5" data-v="5" data-xref="約翰福音 3:19–20; 約翰福音 12:36–40; 哥林多前書 2:14"> 光照進黑暗裡，黑暗不能吞滅<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="「吞滅」或譯「接受」或「明白」。">b</a></sup>光。</span>
<span className="v" id="v6" data-v="6" data-xref="瑪拉基書 3:1; 約翰福音 3:28; 以賽亞書 40:3–5"> 有一個上帝差來的人名叫約翰，</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行傳 19:4; 約翰福音 1:36; 約翰福音 5:33–35"> 他作為見證人來為光作見證，叫世人可以藉著他相信。</span>
<span className="v" id="v8" data-v="8" data-xref="約翰福音 1:20; 約翰福音 3:28; 使徒行傳 19:4"> 約翰不是那光，而是那光的見證人。</span>
<span className="v" id="v9" data-v="9" data-xref="約翰福音 12:46; 約翰福音 1:4; 約翰一書 2:8"> 那照亮世人的真光來到了世上。</span>
<span className="v" id="v10" data-v="10" data-xref="約翰福音 17:25; 約翰一書 3:1; 哥林多前書 2:8"> 祂來到世上，藉祂而造的世界卻不認識祂。</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 19:14; 以賽亞書 53:2–3; 約翰福音 3:32"> 祂來到自己的地方，自己人卻不接受祂。</span>
<span className="v" id="v12" data-v="12" data-xref="加拉太書 3:26; 羅馬書 8:14; 約翰一書 3:1"> 但所有接受祂的，就是那些信祂的人，祂就賜給他們權利成為上帝的兒女。</span>
<span className="v" id="v13" data-v="13" data-xref="約翰一書 3:9; 雅各書 1:18; 彼得前書 1:23"> 這些人不是從血緣關係生的，也不是從情慾或人意生的，而是從上帝生的。</span>
<span className="v" id="v14" data-v="14" data-xref="約翰一書 4:9; 提摩太前書 3:16; 以賽亞書 40:5"> 道成為肉身，住在我們中間，充滿了恩典和真理。我們見過祂的榮耀，正是父獨一兒子的榮耀。</span>
<span className="v" id="v15" data-v="15" data-xref="馬太福音 3:11; 歌羅西書 1:17; 路加福音 3:16"> 約翰為祂作見證，高聲喊道：「這就是我以前所說的那位，『祂在我之後來，卻比我位分高，因為祂在我之前已經存在了。』」</span>
<span className="v" id="v16" data-v="16" data-xref="歌羅西書 1:19; 羅馬書 5:2; 以弗所書 2:5–10"> 從祂的豐盛裡，我們一次又一次地領受了恩典。</span>
<span className="v" id="v17" data-v="17" data-xref="羅馬書 6:14; 約翰福音 14:6; 羅馬書 3:19–26"> 因為律法是藉著摩西頒佈的，恩典和真理則是藉著耶穌基督賜下來的。</span>
<span className="v" id="v18" data-v="18" data-xref="歌羅西書 1:15; 約翰福音 6:46; 馬太福音 11:27"> 從來沒有人見過上帝，只有父懷中的獨一上帝<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="「獨一上帝」有古卷作「獨一兒子」。">c</a></sup>把祂顯明出來。</span>
</div>
</div>

## 施洗者約翰的見證

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="路加福音 3:15–18; 約翰福音 10:24; 使徒行傳 19:4"> 以下是約翰的見證。猶太人從耶路撒冷派祭司和利未人來查問約翰是誰。</span>
<span className="v" id="v20" data-v="20" data-xref="馬可福音 1:7–8; 馬太福音 3:11–12; 約翰福音 3:28–36"> 約翰毫不隱瞞地說：「我不是基督。」</span>
<span className="v" id="v21" data-v="21" data-xref="瑪拉基書 4:5; 申命記 18:15–18; 馬太福音 11:14"> 他們問：「那麼，你是誰？是以利亞嗎？」 他說：「不是。」 他們又問：「你是那位先知嗎？」 他說：「不是。」</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳記下 24:13"> 他們又追問：「你到底是誰？你自己說出來吧，我們好回覆差我們來的人。」</span>
<span className="v" id="v23" data-v="23" data-xref="以賽亞書 40:3–5; 馬可福音 1:3; 馬太福音 3:3"> 他就用以賽亞先知的話說：「我就是那個在曠野大聲呼喊『修直主的路』<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="以賽亞書40·3。">d</a></sup>的人。」</span>
<span className="v" id="v24" data-v="24" data-xref="路加福音 11:53; 馬太福音 23:13–15; 路加福音 11:39–44"> 法利賽人派來的那些人問他：</span>
<span className="v" id="v25" data-v="25" data-xref="申命記 18:18; 申命記 18:15; 約翰福音 1:20–22"> 「你既然不是基督，不是以利亞，也不是那位先知，那你為什麼給人施洗呢？」</span>
<span className="v" id="v26" data-v="26" data-xref="約翰福音 1:10–11; 路加福音 3:16; 使徒行傳 1:5"> 約翰答道：「我用水施洗，但在你們中間站著一位你們不認識的，</span>
<span className="v" id="v27" data-v="27" data-xref="約翰福音 1:30; 馬可福音 1:7; 馬太福音 3:11"> 祂在我之後來，我連給祂解鞋帶都不配。」</span>
<span className="v" id="v28" data-v="28" data-xref="約翰福音 10:40; 約翰福音 3:23; 士師記 7:24"> 這事發生在約旦河東岸的伯大尼，就是約翰給人施洗的地方。</span>
</div>
</div>

## 上帝的羔羊

<div className="bt">
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="以賽亞書 53:7; 約翰一書 2:2; 約翰一書 3:5"> 次日，約翰看見耶穌走過來，就說：「看啊！上帝的羔羊，除去世人罪惡的！</span>
<span className="v" id="v30" data-v="30" data-xref="約翰福音 1:27; 約翰福音 1:15; 路加福音 3:16"> 我說過，『有一個人在我之後來，卻比我位分高，因為祂在我之前已經存在了。』這就是我說的那位。</span>
<span className="v" id="v31" data-v="31" data-xref="瑪拉基書 3:1; 路加福音 1:17; 瑪拉基書 4:2–5"> 我以前並不認識祂，現在我用水給人施洗，是要把祂顯明給以色列人。」</span>
<span className="v" id="v32" data-v="32" data-xref="馬可福音 1:10; 路加福音 3:22; 馬太福音 3:16"> 約翰又作見證說：「我看見聖靈好像鴿子一樣從天降下，住在祂身上。</span>
<span className="v" id="v33" data-v="33" data-xref="使徒行傳 1:5; 馬太福音 3:11; 路加福音 3:16"> 我本來不認識祂，但那位差我來用水給人施洗的告訴我，『你看見聖靈降下，住在誰身上，誰就是用聖靈給人施洗的。』</span>
<span className="v" id="v34" data-v="34" data-xref="詩篇 2:7; 約翰福音 1:49; 詩篇 89:26–27"> 我看見了，便作見證：祂就是上帝的兒子。」</span>
</div>
</div>

## 第一批門徒

<div className="bt">
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="約翰福音 3:25–26; 瑪拉基書 3:16"> 再次日，約翰和兩個門徒站在那裡，</span>
<span className="v" id="v36" data-v="36" data-xref="約翰福音 1:29; 彼得前書 1:19–20; 以賽亞書 65:1–2"> 他看見耶穌經過，就說：「看啊！這是上帝的羔羊！」</span>
<span className="v" id="v37" data-v="37" data-xref="羅馬書 10:17; 約翰福音 1:43; 撒迦利亞書 8:21"> 兩個門徒聽見他的話，便跟從了耶穌。</span>
<span className="v" id="v38" data-v="38" data-xref="約翰福音 18:7; 約翰福音 3:2; 約翰福音 1:49"> 耶穌轉過身來，看見他們跟著，便問：「你們想要什麼？」 他們說：「老師<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="「老師」希臘文是「拉比」，特指猶太教的老師，下同。">e</a></sup>，你住在哪裡？」</span>
<span className="v" id="v39" data-v="39" data-xref="路加福音 24:29; 馬太福音 11:28–30; 約翰福音 6:37"> 耶穌說：「你們來看吧。」他們便跟著去看耶穌住的地方。那時大約下午四點，他們就住在耶穌那裡。</span>
<span className="v" id="v40" data-v="40" data-xref="馬可福音 1:16–20; 馬太福音 4:18–22; 約翰福音 1:40–42"> 聽見約翰的話後跟從耶穌的兩個人中，有一個是西門·彼得的弟弟安得烈。</span>
<span className="v" id="v41" data-v="41" data-xref="約翰福音 4:25; 約翰福音 1:45; 詩篇 89:20"> 他首先去找他哥哥西門，說：「我們找到彌賽亞了！」彌賽亞的意思是基督<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="希伯來文的「彌賽亞」和希臘文的「基督」都是「受膏者」的意思。">f</a></sup>。</span>
<span className="v" id="v42" data-v="42" data-xref="約翰福音 21:15–17; 哥林多前書 3:22; 哥林多前書 15:5"> 他帶著西門去見耶穌。 耶穌看著西門，對他說：「你是約翰的兒子西門，你要叫磯法。」磯法的意思是彼得<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="「磯法」和「彼得」分別是亞蘭語和希臘語，都是「磐石」的意思。">g</a></sup>。</span>
<span className="v" id="v43" data-v="43" data-xref="馬太福音 9:9; 約翰福音 14:8; 以賽亞書 65:1"> 又過了一天，耶穌決定去加利利。祂找到腓力，就對他說：「跟從我！」</span>
<span className="v" id="v44" data-v="44" data-xref="約翰福音 12:21; 馬太福音 11:21; 馬可福音 8:22"> 腓力是伯賽大人，與彼得、安得烈是同鄉。</span>
<span className="v" id="v45" data-v="45" data-xref="申命記 18:18–22; 路加福音 24:27; 彌迦書 5:2"> 腓力去找拿但業，對他說：「我們遇見了摩西律法和先知記載的那位！祂是約瑟的兒子，拿撒勒人耶穌。」</span>
<span className="v" id="v46" data-v="46" data-xref="約翰福音 7:52; 約翰福音 7:41–42; 約翰福音 4:29"> 拿但業說：「拿撒勒能出什麼好的？」 腓力說：「你來看看吧！」</span>
<span className="v" id="v47" data-v="47" data-xref="啟示錄 14:5; 詩篇 32:2; 詩篇 73:1"> 耶穌看見拿但業走過來，就指著他說：「看啊，這是個真正的以色列人！他心裡毫無詭詐。」</span>
<span className="v" id="v48" data-v="48" data-xref="以賽亞書 65:24; 約翰福音 2:25; 詩篇 139:1–2"> 拿但業問耶穌：「你怎麼會認識我？」 耶穌答道：「你在無花果樹下，腓力叫你之前，我就看見你了。」</span>
<span className="v" id="v49" data-v="49" data-xref="西番雅書 3:15; 撒迦利亞書 9:9; 馬太福音 27:42"> 拿但業說：「老師，你是上帝的兒子！你是以色列的王！」</span>
<span className="v" id="v50" data-v="50" data-xref="約翰福音 11:40; 約翰福音 20:29; 路加福音 1:45"> 耶穌說：「我說看見你在無花果樹下，你就信我嗎？將來你還要看見比這更大的事。</span>
<span className="v" id="v51" data-v="51" data-xref="創世記 28:12; 使徒行傳 7:56; 路加福音 22:43"> 我實實在在地告訴你們，你們會看見天開了，上帝的天使以人子<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="「人子」是耶穌的自稱，耶穌在這裡自比天梯，背景請參見創世記28·12。">h</a></sup>為梯上上下下。」</span>
</div>

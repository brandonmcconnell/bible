## 變水為酒

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="約翰福音 4:46; 箴言 31:10–12; 約翰福音 21:2"> 第三天，有人在加利利的迦拿舉辦婚宴，耶穌的母親在場。</span>
<span className="v" id="v2" data-v="2" data-xref="約翰福音 1:40–49; 馬太福音 10:40–42; 哥林多前書 7:39"> 耶穌和門徒也應邀赴宴。</span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 104:15; 腓立比書 4:6; 以賽亞書 24:11"> 酒喝完了，耶穌的母親就對祂說：「他們沒有酒了。」</span>
<span className="v" id="v4" data-v="4" data-xref="約翰福音 7:6; 約翰福音 13:1; 約翰福音 7:30"> 耶穌說：「女士，何必把我牽扯進去？我的時候還沒有到。」</span>
<span className="v" id="v5" data-v="5" data-xref="約翰福音 15:14; 創世記 6:22; 希伯來書 11:8"> 祂母親對僕人說：「祂叫你們做什麼，你們就做什麼。」</span>
<span className="v" id="v6" data-v="6" data-xref="約翰福音 3:25; 希伯來書 9:10; 以弗所書 5:26"> 那裡有六口猶太人用來行潔淨禮儀的石缸，每口可以盛約一百升水。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="列王紀下 4:2–6; 約翰福音 2:5; 約翰福音 2:3"> 耶穌對僕人說：「把缸倒滿水！」他們就往缸裡倒水，一直滿到缸口。</span>
<span className="v" id="v8" data-v="8" data-xref="約翰福音 2:9; 箴言 3:5–6; 羅馬書 13:7"> 耶穌又說：「現在舀些出來，送給宴席總管。」他們就送了去。</span>
<span className="v" id="v9" data-v="9" data-xref="約翰福音 4:46; 約翰福音 7:17; 詩篇 119:100"> 那些僕人知道酒是怎麼來的，宴席總管並不知道。他嘗過那水變的酒後，便把新郎叫來，</span>
<span className="v" id="v10" data-v="10" data-xref="啟示錄 7:16–17; 箴言 9:1–6; 路加福音 16:25"> 對他說：「人們都是先拿好酒款待客人，等客人喝夠了，再把次等的拿出來，你卻把好酒留到現在！」</span>
<span className="v" id="v11" data-v="11" data-xref="約翰福音 20:30–31; 約翰福音 1:14; 約翰福音 3:2"> 這是耶穌第一次行神蹟，是在加利利的迦拿行的，彰顯了祂的榮耀，門徒都信了祂。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="馬太福音 12:46; 馬太福音 13:55–56; 馬可福音 6:3"> 這事以後，耶穌和祂的母親、弟弟及門徒一起去迦百農住了幾天。</span>
</div>
</div>

## 潔淨聖殿

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="路加福音 2:41; 約翰福音 11:55; 約翰福音 2:23"> 猶太人的逾越節快到了，耶穌便上耶路撒冷去。</span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 19:45–46; 馬可福音 11:15; 馬可福音 11:17"> 祂看見聖殿外院有人在賣牛羊和鴿子，還有人坐在那裡兌換銀幣，</span>
<span className="v" id="v15" data-v="15" data-xref="約翰福音 18:6; 撒迦利亞書 4:6; 哥林多後書 10:4"> 就用繩子做成鞭子把牛羊趕出去，拋散錢商的銀幣，推翻他們的桌子，</span>
<span className="v" id="v16" data-v="16" data-xref="馬太福音 21:13; 耶利米書 7:11; 馬可福音 11:17"> 又對賣鴿子的說：「把這些東西拿出去！不要把我父的殿當作市場。」</span>
<span className="v" id="v17" data-v="17" data-xref="詩篇 69:9; 詩篇 119:139"> 祂的門徒想起聖經上說：「我為你的殿心急如焚。」<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="詩篇69·9。">a</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="馬太福音 21:23; 馬可福音 8:11; 馬可福音 11:27–28"> 當時，猶太人質問祂：「你能顯什麼神蹟向我們證明你有權柄這樣做？」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="馬可福音 14:58; 馬可福音 15:29; 馬太福音 27:40"> 耶穌回答說：「你們拆毀這座殿，我三天之內就會把它重建起來。」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20"> 他們說：「這座殿用了四十六年才建成，你三天之內就要把它重建起來嗎？」</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多前書 6:19; 哥林多前書 3:16; 以弗所書 2:20–22"> 其實耶穌說的殿是指自己的身體，</span>
<span className="v" id="v22" data-v="22" data-xref="約翰福音 12:16; 約翰福音 16:4; 路加福音 24:7–8"> 等到祂從死裡復活以後，祂的門徒想起這句話，就相信了聖經和耶穌所傳的道。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="約翰福音 7:31; 路加福音 8:13; 約翰福音 6:14"> 耶穌在耶路撒冷過逾越節期間，許多人看見祂行的神蹟，就信了祂。</span>
<span className="v" id="v24" data-v="24" data-xref="約翰福音 6:64; 希伯來書 4:13; 使徒行傳 1:24"> 耶穌卻不信任他們，因為祂洞悉萬人。</span>
<span className="v" id="v25" data-v="25" data-xref="約翰福音 13:11; 馬太福音 9:4; 約翰福音 6:64"> 不用別人告訴祂，祂也深知人的內心。</span>
</div>
</div>

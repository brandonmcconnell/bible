## 好牧人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="馬太福音 7:15; 約翰福音 10:8–10; 羅馬書 16:18"> 「我實實在在地告訴你們，不從門進羊圈而從別處爬進去的人就是賊，是強盜。</span>
<span className="v" id="v2" data-v="2" data-xref="約翰福音 10:14; 使徒行傳 20:28; 彼得前書 5:4"> 從門進去的才是羊的牧人，</span>
<span className="v" id="v3" data-v="3" data-xref="以西結書 34:11–16; 提摩太後書 2:19; 約翰福音 10:4"> 看門的會給他開門，羊也聽他的聲音。他按名字叫自己的羊，把牠們領出來。</span>
<span className="v" id="v4" data-v="4" data-xref="申命記 1:30; 約翰福音 10:16; 約翰福音 12:26"> 領出來之後，自己便走在前面，羊群也跟著他，因為羊認得他的聲音。</span>
<span className="v" id="v5" data-v="5" data-xref="約翰一書 4:5–6; 歌羅西書 2:6–10; 馬可福音 4:24"> 羊從不跟隨陌生人，見了陌生人就逃跑，因為牠們不認得陌生人的聲音。」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="以賽亞書 56:11; 詩篇 82:5; 箴言 28:5"> 耶穌講了這個比喻，但聽的人都不明白祂的意思。</span>
<span className="v" id="v7" data-v="7" data-xref="約翰福音 14:6; 以弗所書 2:18; 約翰福音 10:1"> 於是祂又說：「我實實在在地告訴你們，我就是羊的門。</span>
<span className="v" id="v8" data-v="8" data-xref="以西結書 34:2; 耶利米書 23:1; 約翰福音 10:1"> 在我以前來的，都是賊，是強盜，羊不聽從他們。</span>
<span className="v" id="v9" data-v="9" data-xref="約翰福音 14:6; 以弗所書 2:18; 約翰福音 10:7"> 我就是門，從我進來的必定得救，並且會安然出入，找到草吃。</span>
<span className="v" id="v10" data-v="10" data-xref="路加福音 19:10; 約翰福音 6:51; 約翰福音 12:47"> 盜賊來，無非是要偷竊、殺害、毀壞。但我來是要羊得生命，並且得到豐盛的生命。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="約翰福音 10:14–15; 詩篇 23:1; 約翰福音 15:13"> 「我是好牧人，好牧人為羊捨命。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行傳 20:29; 撒迦利亞書 11:16–17; 以西結書 34:2–6"> 僱工不是牧人，羊也不是他的，他一見狼來了，必撇下羊逃命。狼就會抓住羊，驅散羊群。</span>
<span className="v" id="v13" data-v="13" data-xref="腓立比書 2:20; 約翰福音 12:6; 使徒行傳 18:17"> 他逃走，因為他是僱工，並不在乎羊。</span>
<span className="v" id="v14" data-v="14" data-xref="約翰福音 10:27; 約翰福音 10:11; 提摩太後書 2:19"> 我是好牧人，我認識我的羊，我的羊也認識我，</span>
<span className="v" id="v15" data-v="15" data-xref="加拉太書 1:4; 約翰福音 10:11; 以賽亞書 53:10"> 正如父認識我，我也認識父，並且我為羊捨命。</span>
<span className="v" id="v16" data-v="16" data-xref="以賽亞書 56:8; 約翰福音 11:52; 彼得前書 2:25"> 我還有別的羊不在這羊圈裡，我必須領他們回來，他們也必聽我的聲音。這樣，我所有的羊將要合成一群，由一個牧人來帶領。</span>
<span className="v" id="v17" data-v="17" data-xref="約翰福音 10:18; 約翰福音 10:11; 希伯來書 2:9"> 父愛我，因為我捨棄自己的生命，為了再得回生命。</span>
<span className="v" id="v18" data-v="18" data-xref="希伯來書 2:9; 提多書 2:14; 約翰福音 2:19–21"> 沒有人能奪走我的生命，我是甘心捨棄的。我有權捨棄，也有權得回，這是我從父那裡得到的命令。」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="約翰福音 9:16; 哥林多前書 3:3; 約翰福音 7:40–43"> 猶太人因這番話又起了紛爭。</span>
<span className="v" id="v20" data-v="20" data-xref="約翰福音 7:20; 馬可福音 3:21; 約翰福音 8:47–48"> 他們當中好些人說：「祂被鬼附身了！祂瘋了！何必聽祂的？」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="出埃及記 4:11; 以賽亞書 35:5–6; 詩篇 94:9"> 又有些人說：「被鬼附身的人不會說這種話的，鬼能醫治瞎眼的人嗎？」</span>
</div>
</div>

## 被猶太人棄絕

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22"> 耶路撒冷慶祝修殿節的時候到了，是在冬天。</span>
<span className="v" id="v23" data-v="23" data-xref="使徒行傳 5:12; 使徒行傳 3:11"> 耶穌正在聖殿的所羅門廊行走，</span>
<span className="v" id="v24" data-v="24" data-xref="路加福音 22:67–70; 約翰福音 1:19; 約翰福音 8:25"> 一群猶太人圍著祂說：「你讓我們猜到什麼時候呢？如果你是基督，就清楚地告訴我們吧！」</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="約翰福音 10:38; 約翰福音 8:58; 約翰福音 14:11"> 耶穌回答說：「我已經告訴你們了，你們卻不信。我奉我父的名所行的神蹟也為我作見證，</span>
<span className="v" id="v26" data-v="26" data-xref="約翰福音 8:47; 哥林多後書 4:3–4; 約翰福音 12:37–40"> 只是你們不肯相信，因為你們不是我的羊。</span>
<span className="v" id="v27" data-v="27" data-xref="約翰福音 10:16; 約翰福音 10:14; 啟示錄 3:20"> 我的羊聽我的聲音，我也認識他們，他們也跟隨我。</span>
<span className="v" id="v28" data-v="28" data-xref="約翰福音 6:39–40; 約翰福音 6:37; 約翰福音 3:15–16"> 我要賜他們永生，他們永不滅亡。沒有人能從我的手裡把他們搶走。</span>
<span className="v" id="v29" data-v="29" data-xref="約翰福音 6:37; 約翰福音 17:2; 約翰福音 17:9"> 我父把羊賜給我，祂比萬物都大，沒有人能從祂手中把羊搶走。</span>
<span className="v" id="v30" data-v="30" data-xref="約翰福音 1:1–2; 約翰福音 14:9; 約翰福音 17:21–23"> 我和父本為一。」</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="約翰福音 5:18; 約翰福音 8:59; 撒母耳記上 30:6"> 於是猶太人又拿起石頭要打祂。</span>
<span className="v" id="v32" data-v="32" data-xref="約翰一書 3:12; 約翰福音 5:36; 詩篇 35:12"> 耶穌就問他們：「我將許多從父而來的善行顯給你們看，你們為了哪一件事拿石頭打我呢？」</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="約翰福音 5:18; 利未記 24:16; 約翰福音 10:30"> 猶太人回答說：「我們不是因為你做的善事打你，而是因為你說了褻瀆的話，你是人，卻把自己當作上帝。」</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="詩篇 82:6–7; 出埃及記 7:1; 詩篇 82:1"> 耶穌說：「你們的律法書上不是寫著『我曾說你們都是神』<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="詩篇82·6。">a</a></sup>嗎？</span>
<span className="v" id="v35" data-v="35" data-xref="馬太福音 24:35; 羅馬書 13:1; 路加福音 16:17"> 聖經上的話是不能廢的，既然上帝稱那些承受祂道的人為神，</span>
<span className="v" id="v36" data-v="36" data-xref="約翰福音 5:17–18; 約翰福音 3:17; 耶利米書 1:5"> 而我是父分別出來又差到世上來的，我說自己是上帝的兒子，你們就指控我褻瀆嗎？</span>
<span className="v" id="v37" data-v="37" data-xref="約翰福音 15:24; 約翰福音 10:25; 約翰福音 12:37–40"> 如果我不做我父的事，你們不必信我。</span>
<span className="v" id="v38" data-v="38" data-xref="約翰福音 14:20; 約翰福音 10:25; 約翰福音 10:30"> 但如果我做了，你們縱然不信我，也應該相信我所做的事，這樣你們就會知道並領會父在我裡面，我也在父裡面。」</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="約翰福音 7:30; 約翰福音 8:59; 約翰福音 7:44"> 他們又要抓耶穌，但祂從他們手中逃脫了。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="約翰福音 1:28; 約翰福音 11:54; 約翰福音 7:1"> 後來，耶穌回到約旦河東岸約翰從前施洗的地方，在那裡住下來。</span>
<span className="v" id="v41" data-v="41" data-xref="約翰福音 1:33–34; 約翰福音 1:29–30; 馬可福音 1:37"> 許多人來到祂那裡。他們說：「雖然約翰沒有行過神蹟，可是約翰所說關於這人的事全是真的。」</span>
<span className="v" id="v42" data-v="42" data-xref="約翰福音 4:41; 約翰福音 2:23; 約翰福音 7:31"> 那裡有許多人信了耶穌。</span>
</div>
</div>

## 論重生

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="約翰福音 19:39; 約翰福音 7:47–50; 約翰福音 3:10"> 有一個法利賽人名叫尼哥德慕，是猶太人的官。</span>
<span className="v" id="v2" data-v="2" data-xref="約翰福音 5:36; 使徒行傳 10:38; 使徒行傳 2:22"> 一天晚上，他來見耶穌，說：「老師，我們知道你是上帝差來教導人的，因為如果沒有上帝的同在，沒有人能行你所行的神蹟。」</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多後書 5:17; 約翰福音 3:5–6; 彼得前書 1:23–25"> 耶穌說：「我實實在在地告訴你，人若不重生<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「重生」或譯「生自上面」，7節同。">a</a></sup>，就不能看見上帝的國。」</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多前書 2:14; 哥林多前書 1:18; 約翰福音 3:3"> 尼哥德慕說：「人老了，怎能重生呢？難道要再進母腹生一次嗎？」</span>
<span className="v" id="v5" data-v="5" data-xref="以西結書 36:25–27; 以弗所書 5:26; 使徒行傳 2:38"> 耶穌說：「我實實在在地告訴你，人若不是從水和聖靈生的，就不能進上帝的國。</span>
<span className="v" id="v6" data-v="6" data-xref="加拉太書 5:16–21; 以西結書 36:26–27; 羅馬書 8:4–9"> 從肉體生的還是肉體，從靈生的才是靈。</span>
<span className="v" id="v7" data-v="7" data-xref="約翰福音 3:3; 以弗所書 4:22–24; 羅馬書 12:1–2"> 我說你們必須重生，你不要驚奇。</span>
<span className="v" id="v8" data-v="8" data-xref="傳道書 11:4–5; 哥林多前書 2:11; 使徒行傳 2:2"> 風隨意吹動，你聽見它的聲音，卻不知道它從哪裡來、往哪裡去。凡從靈生的人也是這樣。」</span>
<span className="v" id="v9" data-v="9" data-xref="約翰福音 6:60; 路加福音 1:34; 以賽亞書 42:16"> 尼哥德慕又問：「這怎麼可能呢？」</span>
<span className="v" id="v10" data-v="10" data-xref="馬太福音 22:29; 耶利米書 8:8–9; 以西結書 11:19"> 耶穌說：「你是以色列人的老師，還不明白這事嗎？</span>
<span className="v" id="v11" data-v="11" data-xref="約翰福音 8:38; 約翰一書 5:6–12; 約翰福音 12:49"> 我實實在在地告訴你，我們所說的是自己知道的，所見證的是自己見過的，可是你們不肯接受我們的見證。</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多前書 3:1–2; 哥林多前書 2:7–9; 希伯來書 5:11"> 我對你們說地上的事，你們尚且不信，要是說天上的事，你們怎麼會信呢？</span>
<span className="v" id="v13" data-v="13" data-xref="箴言 30:4; 約翰福音 6:38; 使徒行傳 2:34"> 除了從天上降下來的人子<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="「從天上降下來的人子」有古卷作：「從天降下、仍舊在天的人子」。">b</a></sup>以外，沒有人到過天上。</span>
<span className="v" id="v14" data-v="14" data-xref="民數記 21:7–9; 約翰福音 8:28; 約翰福音 12:32–34"> 摩西在曠野怎樣舉起銅蛇，人子也必照樣被舉起來，</span>
<span className="v" id="v15" data-v="15" data-xref="約翰福音 3:16; 約翰福音 6:40; 約翰福音 12:44–46"> 叫一切信祂的人都得到永生。</span>
<span className="v" id="v16" data-v="16" data-xref="羅馬書 5:8; 約翰一書 4:9–10; 約翰福音 3:15"> 「因為上帝愛世人，甚至將祂獨一的兒子賜給他們，叫一切信祂的人不致滅亡，反得永生。</span>
<span className="v" id="v17" data-v="17" data-xref="約翰一書 4:14; 路加福音 19:10; 約翰福音 12:47–48"> 上帝差祂的兒子到世上來，不是要定世人的罪，而是要藉著祂的兒子拯救世人。</span>
<span className="v" id="v18" data-v="18" data-xref="馬可福音 16:16; 約翰一書 5:10; 羅馬書 8:1"> 信祂的人不會被定罪，不信的人已經被定罪，因為他們不信上帝獨一的兒子。</span>
<span className="v" id="v19" data-v="19" data-xref="約翰福音 8:12; 帖撒羅尼迦後書 2:12; 約翰福音 9:39–41"> 光來到世上，世人因為自己的行為邪惡而不愛光，反愛黑暗，這就是他們被定罪的原因。</span>
<span className="v" id="v20" data-v="20" data-xref="以弗所書 5:11–13; 約翰福音 7:7; 約伯記 24:13–17"> 作惡的人恨光，不肯接近光，恐怕他們的罪行暴露出來。</span>
<span className="v" id="v21" data-v="21" data-xref="約翰一書 1:6; 詩篇 139:23–24; 約翰三書 1:11"> 但遵行真理的人喜歡接近光，好顯明他們所做的是靠上帝做的。」</span>
</div>
</div>

## 施洗者約翰論耶穌

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="約翰福音 4:1–3; 約翰福音 3:26; 約翰福音 2:13"> 這事之後，耶穌和門徒前往猶太地區，在那裡住下，給人施洗。</span>
<span className="v" id="v23" data-v="23" data-xref="馬可福音 1:4–5; 以西結書 43:2; 馬太福音 3:5–6"> 那時約翰還沒有入獄，他在靠近撒冷的哀嫩也給人施洗。那裡水多，眾人都去受洗。</span>
<span className="v" id="v25" data-v="25" data-xref="約翰福音 2:6; 馬太福音 3:11; 希伯來書 6:2"> 約翰的門徒和一個猶太人為了潔淨的禮儀爭辯起來，</span>
<span className="v" id="v26" data-v="26" data-xref="約翰福音 1:7; 約翰福音 1:15; 約翰福音 12:19"> 於是他們來見約翰，說：「老師，你看，以前在約旦河東岸和你在一起、你為祂作見證的那位在給人施洗，眾人都去祂那裡了！」</span>
<span className="v" id="v27" data-v="27" data-xref="雅各書 1:17; 哥林多前書 4:7; 哥林多前書 15:10"> 約翰回答說：「除非是從天上賜的，否則人什麼都得不到。</span>
<span className="v" id="v28" data-v="28" data-xref="約翰福音 1:20; 約翰福音 1:23; 馬太福音 3:11–12"> 你們自己可以為我作見證，我說過我不是基督，我只是奉差遣在祂前面預備道路。</span>
<span className="v" id="v29" data-v="29" data-xref="馬太福音 9:15; 何西阿書 2:19; 以賽亞書 54:5"> 娶新娘的是新郎，伴郎聽見新郎的聲音，就會歡喜快樂。因此，我現在也心滿意足了。</span>
<span className="v" id="v30" data-v="30" data-xref="歌羅西書 1:18; 詩篇 72:17–19; 希伯來書 3:2–6"> 祂必興旺，我必衰微。</span>
<span className="v" id="v31" data-v="31" data-xref="約翰福音 8:23; 馬太福音 28:18; 羅馬書 9:5"> 「從上面來的超越萬物；從地上來的，屬於地，他所談論的也不外乎地上的事。從天上來的超越萬物。</span>
<span className="v" id="v32" data-v="32" data-xref="約翰福音 3:11; 約翰福音 15:15; 約翰福音 1:11"> 祂見證的是自己的所見所聞，只是沒有人接受祂的見證。</span>
<span className="v" id="v33" data-v="33" data-xref="希伯來書 6:17; 以弗所書 1:13; 提多書 1:1–2"> 接受祂見證的人印證了上帝是真實的。</span>
<span className="v" id="v34" data-v="34" data-xref="使徒行傳 10:38; 馬太福音 12:18; 約翰福音 15:26"> 上帝所差來的，說的是上帝的話，因為上帝將聖靈無限量地賜給祂。</span>
<span className="v" id="v35" data-v="35" data-xref="馬太福音 28:18; 約翰福音 5:22; 約翰福音 5:20"> 父愛子，已把萬物交在祂手裡。</span>
<span className="v" id="v36" data-v="36" data-xref="約翰福音 5:24; 約翰福音 1:12; 帖撒羅尼迦前書 5:9"> 信子的人有永生；不信子的人得不到永生，上帝的烈怒常在他身上。」</span>
</div>
</div>

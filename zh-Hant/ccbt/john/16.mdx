## 聖靈的工作

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="彼得前書 2:8; 馬太福音 13:21; 馬太福音 26:31–33"> 「我把這些事告訴你們，以免你們背棄信仰。</span>
<span className="v" id="v2" data-v="2" data-xref="約翰福音 9:22; 使徒行傳 26:9–11; 羅馬書 10:2–3"> 人們將把你們趕出會堂，時候將到，殺害你們的人還以為是在事奉上帝。</span>
<span className="v" id="v3" data-v="3" data-xref="約翰福音 15:21; 約翰福音 17:25; 約翰福音 8:55"> 他們這樣做，是因為他們根本不認識父，也不認識我。</span>
<span className="v" id="v4" data-v="4" data-xref="約翰福音 14:29; 馬可福音 13:23; 約翰福音 17:12–13"> 我把這些事提前告訴你們，是要叫你們到時候可以想起我曾跟你們講過這些事。我以前沒有告訴你們，那是因為我還跟你們在一起。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="約翰福音 13:36; 約翰福音 7:33; 約翰福音 16:28"> 「現在我要去差我來的父那裡，你們沒有人問我去哪裡。</span>
<span className="v" id="v6" data-v="6" data-xref="約翰福音 14:1; 約翰福音 16:20–22; 路加福音 24:17"> 因為我把這些事告訴了你們，你們心裡充滿了憂愁。</span>
<span className="v" id="v7" data-v="7" data-xref="約翰福音 14:26; 約翰福音 14:16–17; 約翰福音 15:26"> 然而，我把實情告訴你們，我去對你們是有益的，因為如果我不去，護慰者就不會來，我去了就會派祂到你們這裡來。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行傳 2:37; 猶大書 1:15; 撒迦利亞書 12:10"> 祂來了，必讓世人在罪、義和審判方面知罪。</span>
<span className="v" id="v9" data-v="9" data-xref="約翰福音 15:22–25; 約翰福音 8:23–24; 約翰福音 12:47–48"> 關於罪，是因為他們不信我；</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多後書 5:21; 彼得前書 3:18; 羅馬書 10:3–4"> 關於義，是因為我要去父那裡，你們再也看不到我了；</span>
<span className="v" id="v11" data-v="11" data-xref="約翰福音 12:31; 約翰一書 3:8; 希伯來書 2:14"> 關於審判，是因為這世界的王受了審判。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="馬可福音 4:33; 約翰福音 15:15; 哥林多前書 3:1–2"> 「我還有許多事情要告訴你們，可是你們現在還不能承受。</span>
<span className="v" id="v13" data-v="13" data-xref="約翰福音 14:26; 哥林多前書 2:10–13; 約翰福音 14:17"> 等到真理之靈來了，祂會引導你們進入一切真理。祂不憑自己說話，而是把祂所聽見的和有關將來的事告訴你們。</span>
<span className="v" id="v14" data-v="14" data-xref="約翰一書 4:13–14; 哥林多後書 3:14–18; 約翰福音 15:26"> 祂也要把從我領受的指示你們，使我得榮耀。</span>
<span className="v" id="v15" data-v="15" data-xref="約翰福音 17:10; 馬太福音 11:27; 約翰福音 3:35"> 父的一切都是我的，所以我才說聖靈要把從我領受的指示你們。</span>
</div>
</div>

## 轉憂為喜

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="約翰福音 7:33; 使徒行傳 1:3; 約翰福音 14:18–24"> 「不久，你們就見不到我了。再過不久，你們還會看見我。」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="約翰福音 16:16; 馬可福音 9:32; 約翰福音 16:5"> 幾個門徒彼此議論說：「祂說，『不久，你們就見不到我了，再過不久，你們還會看見我』，又說，『因為我要去父那裡』，這到底是什麼意思呢？</span>
<span className="v" id="v18" data-v="18" data-xref="路加福音 24:25; 馬太福音 16:9–11; 希伯來書 5:12"> 祂說『不久』是什麼意思呢？我們真不明白祂在說什麼！」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="約翰福音 16:30; 約翰福音 16:16; 約翰福音 14:19"> 耶穌知道他們想問祂，就說：「我說，『不久，你們就見不到我了。再過不久，你們還會看見我。』你們在議論這話是什麼意思嗎？</span>
<span className="v" id="v20" data-v="20" data-xref="雅各書 1:2; 馬太福音 5:4; 詩篇 126:5–6"> 我實實在在地告訴你們，你們將痛哭、哀號，世人卻要歡喜；你們將憂愁，然而你們的憂愁將變為喜樂。</span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 113:9; 以賽亞書 13:8; 帖撒羅尼迦前書 5:3"> 婦人分娩時都會痛苦，但孩子生下來後，她就會因為這世界添了一個新生命而歡喜，忘掉了生產的劇痛。</span>
<span className="v" id="v22" data-v="22" data-xref="彼得前書 1:8; 使徒行傳 13:52; 約翰福音 16:6"> 同樣，現在你們痛苦，但到我再見你們的時候，你們的心必歡喜，而且這份喜樂是誰也奪不去的。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="約翰福音 15:7; 約翰福音 14:13–14; 馬太福音 21:22"> 「到那一天，你們就什麼也不用問我了。我實實在在地告訴你們，你們奉我的名無論向父求什麼，祂都會賜給你們。</span>
<span className="v" id="v24" data-v="24" data-xref="馬太福音 7:7–8; 雅各書 4:2–3; 約翰福音 15:11"> 你們從來沒有奉我的名求過什麼，你們現在求，就必得到，好使你們的喜樂滿溢。</span>
</div>
</div>

## 勝過世界

<div className="bt">
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="約翰福音 16:12; 馬可福音 4:13; 馬太福音 13:34–35"> 「我一直用比喻跟你們講這些事，不久，我就不再用比喻了，而是清楚地把父的事告訴你們。</span>
<span className="v" id="v26" data-v="26" data-xref="羅馬書 8:34; 約翰福音 17:24; 約翰福音 17:19"> 到那天，你們將要奉我的名祈求，我不是說我要為你們向父祈求。</span>
<span className="v" id="v27" data-v="27" data-xref="約翰福音 14:21; 約翰福音 14:23; 約翰福音 17:23"> 父愛你們，因為你們一直愛我，並且相信我來自上帝。</span>
<span className="v" id="v28" data-v="28" data-xref="約翰福音 13:1; 約翰福音 13:3; 約翰福音 8:14"> 我從父那裡來到這個世界，現在我要離開這個世界回到父那裡。」</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="約翰福音 16:25"> 門徒說：「現在你直截了當地告訴我們，不再用比喻了。</span>
<span className="v" id="v30" data-v="30" data-xref="約翰福音 21:17; 約翰福音 17:8; 約翰福音 16:17"> 現在我們知道你無所不知，無需人問你什麼，因此我們相信你來自上帝。」</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="路加福音 9:44–45; 約翰福音 13:38"> 耶穌說：「你們現在相信嗎？</span>
<span className="v" id="v32" data-v="32" data-xref="撒迦利亞書 13:7; 馬太福音 26:31; 約翰福音 8:29"> 看啊！時候快到了，現在就是，你們將要分散，各自回家，只留下我一人。不過，我並非一人，因為父與我在一起。</span>
<span className="v" id="v33" data-v="33" data-xref="約翰福音 14:27; 約翰一書 5:4; 帖撒羅尼迦後書 3:16"> 我把這些事告訴你們，是要叫你們在我裡面有平安。你們在世上會有苦難，但你們要放心，我已經勝過這個世界。」</span>
</div>
</div>

</div>

## 香膏抹腳

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="馬可福音 14:3–8; 約翰福音 11:1; 路加福音 24:50"> 逾越節前六天，耶穌來到伯大尼，就是祂叫拉撒路從死裡復活的那個村子。</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 22:27; 路加福音 10:38–42; 啟示錄 3:20"> 村裡有人為耶穌預備了晚飯，拉撒路也與耶穌同席，瑪大在旁邊伺候。</span>
<span className="v" id="v3" data-v="3" data-xref="馬可福音 14:3–9; 約翰福音 11:2; 路加福音 10:38–39"> 瑪麗亞拿出一瓶<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「一瓶」希臘文是「一羅馬磅」，約325克。">a</a></sup>珍貴的純哪噠香膏來抹耶穌的腳，又用自己的頭髮去擦，屋裡充滿了香氣。</span>
<span className="v" id="v4" data-v="4" data-xref="馬太福音 10:4; 撒母耳記上 17:28–29; 約翰福音 13:2"> 有一個門徒，就是將要出賣耶穌的加略人猶大說：</span>
<span className="v" id="v5" data-v="5" data-xref="路加福音 18:22; 路加福音 12:33; 馬可福音 14:4–5"> 「為什麼不把香膏賣三百個銀幣<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="「三百個銀幣」相當於當時一個人一年的工錢。">b</a></sup>去賙濟窮人呢？」</span>
<span className="v" id="v6" data-v="6" data-xref="約翰福音 13:29; 詩篇 50:16–20; 雅各書 2:6"> 他這樣說不是因為他真的關心窮人，而是因為他是個賊，負責保管錢袋，常從中偷拿財物。</span>
<span className="v" id="v7" data-v="7" data-xref="馬太福音 26:12; 馬可福音 14:6; 馬太福音 27:57–60"> 耶穌說：「由她吧！她這是為我安葬作預備。</span>
<span className="v" id="v8" data-v="8" data-xref="申命記 15:11; 馬可福音 14:7; 馬太福音 26:11"> 因為你們身邊總會有窮人，可是你們身邊不會總有我。」</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行傳 4:14; 約翰福音 11:43–45; 使徒行傳 3:10–11"> 有許多猶太人知道耶穌在那裡，就來看祂，不單是為了看耶穌，也想看看從死裡復活的拉撒路。</span>
<span className="v" id="v10" data-v="10" data-xref="路加福音 16:31; 馬太福音 2:16; 約翰福音 11:47–53"> 於是，祭司長計劃連拉撒路也殺掉，</span>
<span className="v" id="v11" data-v="11" data-xref="約翰福音 11:45; 約翰福音 12:18; 使徒行傳 13:45"> 因為有許多猶太人因為拉撒路的緣故離開他們，去信了耶穌。</span>
</div>
</div>

## 光榮進聖城

<div className="bt">
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="馬可福音 11:7–10; 馬太福音 21:4–9; 路加福音 19:35–38"> 第二天，很多上來過節的人聽見耶穌快到耶路撒冷了，</span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 118:25–26; 啟示錄 15:3; 馬太福音 21:9–11"> 就拿著棕樹枝出去迎接祂，高喊道：<br /><span className="pl pl-1">「和散那！」</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="「和散那」原意是「拯救我們」，此處有「讚美」的意思。">c</a></sup><br /><span className="pl pl-1">「奉主名來的以色列王當受稱頌！」</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="詩篇118·25、26。">d</a></sup></span>
<span className="v" id="v14" data-v="14" data-xref="撒迦利亞書 9:9; 馬可福音 11:1–7; 馬太福音 21:1–7"> 那時，耶穌找到一頭驢駒，就騎上牠，正如聖經記載：</span>
<span className="v" id="v15" data-v="15" data-xref="撒迦利亞書 9:9; 以賽亞書 62:11; 西番雅書 3:16–17"> <span className="pl pl-1">「少女錫安啊，不要害怕！</span><br /><span className="pl pl-1">看啊，你的君王騎著驢駒來了。」</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="撒迦利亞書9·9。">e</a></sup></span>
<span className="v" id="v16" data-v="16" data-xref="約翰福音 2:22; 約翰福音 14:26; 約翰福音 7:39"> 起初門徒不明白這些事，耶穌得了榮耀之後，他們才想起聖經上這些有關耶穌的記載果然在祂身上應驗了。</span>
<span className="v" id="v17" data-v="17" data-xref="啟示錄 1:2; 約翰一書 5:9–12; 約翰福音 19:35"> 那些親眼看見耶穌叫拉撒路復活、走出墳墓的人不斷傳揚這件事。</span>
<span className="v" id="v18" data-v="18" data-xref="約翰福音 12:11"> 眾人因為聽說耶穌行了這神蹟，都去迎接祂。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行傳 17:6; 詩篇 22:27; 約翰一書 2:2"> 法利賽人彼此議論說：「我們真是枉費心思！看啊，整個世界都跟著祂跑了。」</span>
</div>
</div>

## 耶穌預言自己的死

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="約翰福音 7:35; 以賽亞書 11:10; 使徒行傳 17:4"> 有幾個希臘人也在節期上耶路撒冷敬拜。</span>
<span className="v" id="v21" data-v="21" data-xref="馬太福音 2:2; 路加福音 19:2–4; 約翰福音 6:40"> 他們去見加利利的伯賽大人腓力，請求說：「先生，我們想見見耶穌。」</span>
<span className="v" id="v22" data-v="22" data-xref="馬可福音 10:13–14; 路加福音 9:49–50; 約翰福音 1:40–41"> 腓力把這件事告訴安得烈，二人去轉告耶穌。</span>
<span className="v" id="v23" data-v="23" data-xref="約翰福音 13:31–32; 約翰福音 17:1–5; 以賽亞書 60:9"> 耶穌說：「人子得榮耀的時候到了。</span>
<span className="v" id="v24" data-v="24" data-xref="哥林多前書 15:36–38; 以賽亞書 53:10–12; 希伯來書 2:9–10"> 我實實在在地告訴你們，一粒麥子如果不落在地裡死了，仍是一粒，如果死了，就會結出許多麥粒來。</span>
<span className="v" id="v25" data-v="25" data-xref="馬太福音 10:39; 路加福音 9:23–24; 馬可福音 8:35"> 愛惜自己生命的，會失掉生命；憎惡自己今世生命的，必保住生命，直到永生。</span>
<span className="v" id="v26" data-v="26" data-xref="歌羅西書 3:24; 加拉太書 1:10; 撒母耳記上 2:30"> 誰要事奉我，就要跟從我。我在哪裡，事奉我的人也要在哪裡。我父必尊重事奉我的人。</span>
<span className="v" id="v27" data-v="27" data-xref="約翰福音 12:23; 希伯來書 5:7; 馬太福音 26:42"> 「我現在心裡憂傷，說什麼才好呢？求父救我離開這個時刻嗎？然而，我原是為這個時刻來的。</span>
<span className="v" id="v28" data-v="28" data-xref="約翰福音 13:31–32; 馬太福音 26:42; 啟示錄 5:9–14"> 父啊！願你使自己的名得榮耀！」 當時天上有聲音說：「我已使自己的名得了榮耀，並且還要得榮耀。」</span>
<span className="v" id="v29" data-v="29" data-xref="約伯記 37:2–5; 啟示錄 6:1; 啟示錄 14:2"> 站在那裡的人群中有人聽見後，就說：「打雷了！」也有人說：「是天使在跟祂說話。」</span>
<span className="v" id="v30" data-v="30" data-xref="約翰福音 11:42; 約翰福音 11:15; 約翰福音 5:34"> 耶穌說：「這聲音不是為我發出的，是為你們發出的。</span>
<span className="v" id="v31" data-v="31" data-xref="哥林多後書 4:4; 約翰一書 5:19; 約翰一書 3:8"> 現在是這世界受審判的時候，這世界的王<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="「世界的王」指「魔鬼，又名撒旦」，參見路加福音10·18；歌羅西書2·15；約翰一書3·8。">f</a></sup>要被趕出去了。</span>
<span className="v" id="v32" data-v="32" data-xref="約翰福音 3:14; 約翰福音 8:28; 彼得前書 2:24"> 至於我，當我從地上被舉起來時，必吸引萬人歸向我。」</span>
<span className="v" id="v33" data-v="33" data-xref="約翰福音 18:32; 約翰福音 21:19"> 耶穌這句話指的是祂會怎樣死。</span>
<span className="v" id="v34" data-v="34" data-xref="以西結書 37:24–25; 以賽亞書 9:7; 但以理書 7:14"> 眾人問：「我們從律法書上知道，基督是永遠長存的，你怎麼說『人子必須被舉起來』呢？這人子是誰呢？」</span>
<span className="v" id="v35" data-v="35" data-xref="約翰福音 12:46; 約翰福音 16:16; 以弗所書 5:8"> 耶穌對他們說：「光在你們中間照耀的時候不多了，你們要趁著有光的時候走路，免得黑暗臨到你們。走在黑暗裡的人不知道要往哪裡去。</span>
<span className="v" id="v36" data-v="36" data-xref="以弗所書 5:8; 約翰福音 8:59; 使徒行傳 13:47–48"> 所以你們當趁著有光的時候信從光，好成為光明的兒女。」 耶穌說完後，便離開他們，隱藏起來。</span>
</div>
</div>

## 猶太人不信祂

<div className="bt">
<div className="bp poetry">
<span className="v" id="v37" data-v="37" data-xref="路加福音 16:31; 約翰福音 1:11; 約翰福音 15:24"> 耶穌雖然在他們面前行了許多神蹟，他們還是不信祂。</span>
<span className="v" id="v38" data-v="38" data-xref="以賽亞書 53:1; 羅馬書 10:16; 羅馬書 10:20"> 這是要應驗以賽亞先知的話：<br /><span className="pl pl-1">「主啊，誰相信我們所傳的呢？主的臂膀向誰彰顯呢？」</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="以賽亞書53·1。">g</a></sup><br /></span>
<span className="v" id="v39" data-v="39" data-xref="約翰福音 10:38; 約翰福音 5:44; 彼得後書 2:14"> <span className="pl pl-1">接著，以賽亞又說出他們不能信的緣故：</span><br /></span>
<span className="v" id="v40" data-v="40" data-xref="以賽亞書 6:10; 馬太福音 13:13–15; 路加福音 8:10"> <span className="pl pl-1">「主使他們眼瞎、心硬，</span><br /><span className="pl pl-1">免得他們眼睛看見，</span><br /><span className="pl pl-1">心裡明白，回心轉意，</span><br /><span className="pl pl-1">就被我醫治。」</span><sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="以賽亞書6·10。">h</a></sup></span>
<span className="v" id="v41" data-v="41" data-xref="以賽亞書 6:1–5; 以賽亞書 6:9–10; 約翰福音 1:14"> 以賽亞看見了祂的榮耀，所以才這樣說。</span>
<span className="v" id="v42" data-v="42" data-xref="約翰福音 9:22; 約翰福音 7:13; 以賽亞書 51:7"> 雖然這樣，仍有很多猶太的官員信了耶穌，只是在法利賽人面前不敢公開承認，因為害怕會被趕出會堂。</span>
<span className="v" id="v43" data-v="43" data-xref="約翰福音 5:44; 馬太福音 23:5–7; 約翰福音 5:41"> 因為他們愛從世人而來的榮耀，勝過愛從上帝而來的榮耀。</span>
</div>
</div>

## 耶穌的道要審判人

<div className="bt">
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="馬太福音 10:40; 約翰福音 13:20; 約翰福音 5:24"> 耶穌高聲說：「信我的，不只是信我，而是信差我來的那位。</span>
<span className="v" id="v45" data-v="45" data-xref="約翰福音 14:9–10; 哥林多後書 4:6; 歌羅西書 1:15"> 人看見了我，就是看見了差我來的那位。</span>
<span className="v" id="v46" data-v="46" data-xref="約翰福音 8:12; 詩篇 36:9; 約翰福音 9:5"> 我來是要作世界的光，好叫信我的人脫離黑暗。</span>
<span className="v" id="v47" data-v="47" data-xref="約翰福音 3:17; 約翰福音 8:15–16; 約翰福音 12:48"> 聽了我的話卻不遵守的人，我不審判他，因為我來不是要審判世人，而是要拯救世人。</span>
<span className="v" id="v48" data-v="48" data-xref="路加福音 10:16; 希伯來書 9:27–28; 羅馬書 2:16"> 棄絕我、不接受我話的人將受審判，我講過的道在末日要審判他，</span>
<span className="v" id="v49" data-v="49" data-xref="約翰福音 14:10; 約翰福音 8:26; 約翰福音 5:30"> 因為我不是憑自己講的，我說什麼、講什麼都是差我來的父吩咐的。</span>
<span className="v" id="v50" data-v="50" data-xref="約翰福音 17:3; 約翰福音 6:68; 約翰一書 5:20"> 我知道祂的命令能帶來永生。所以祂怎麼告訴我，我就怎麼說。」</span>
</div>
</div>

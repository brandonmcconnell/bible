## 拉撒路病死

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 10:38–42; 約翰福音 12:17; 列王紀下 20:1–12"> 伯大尼村有個名叫拉撒路的人病倒了。伯大尼是瑪麗亞和她姐姐瑪大居住的村莊。</span>
<span className="v" id="v2" data-v="2" data-xref="約翰福音 12:3; 馬可福音 14:3; 馬太福音 26:6–7"> 就是這個瑪麗亞後來用香膏抹主，又用自己的頭髮擦乾祂的腳，患病的拉撒路是她的弟弟。</span>
<span className="v" id="v3" data-v="3" data-xref="約翰福音 11:5; 啟示錄 3:19; 提摩太後書 4:20"> 她們兩姊妹託人去告訴耶穌，說：「主啊，你所愛的人病了！」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="約翰福音 11:40; 約翰福音 9:3; 彼得前書 4:14"> 耶穌聽見後，說：「這病不至於死，而是為了上帝的榮耀，使祂的兒子藉此得到榮耀。」</span>
<span className="v" id="v5" data-v="5" data-xref="約翰福音 15:9–13; 約翰福音 16:27; 約翰福音 17:26"> 耶穌一向愛瑪大、她妹妹和拉撒路，</span>
<span className="v" id="v6" data-v="6" data-xref="以賽亞書 30:18; 以賽亞書 55:8–9; 創世記 45:1–5"> 可是祂聽到拉撒路有病的消息後，仍在原地逗留了兩天，</span>
<span className="v" id="v7" data-v="7" data-xref="約翰福音 10:40–42; 路加福音 9:51; 使徒行傳 20:22–24"> 然後才對門徒說：「我們回猶太吧！」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="約翰福音 10:31; 約翰福音 8:59; 使徒行傳 21:12–13"> 門徒說：「老師，猶太人近來想拿石頭打你，你還要去那裡嗎？」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="約翰福音 9:4; 約翰福音 12:35; 耶利米書 31:9"> 耶穌說：「白天不是有十二個小時嗎？人在白天走路，不會跌倒，因為他看得見這世上的光。</span>
<span className="v" id="v10" data-v="10" data-xref="約翰一書 2:10–11; 箴言 4:18–19; 耶利米書 13:16"> 人在夜間走路，才會跌倒，因為沒有光。」</span>
<span className="v" id="v11" data-v="11" data-xref="但以理書 12:2; 約翰福音 11:13; 約翰福音 11:43–44"> 接著耶穌又說：「我們的朋友拉撒路已經睡了，我去叫醒他。」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12"> 門徒說：「主啊，他如果睡了，肯定會好的。」</span>
<span className="v" id="v13" data-v="13" data-xref="馬太福音 9:24"> 其實耶穌是指他已經死了，門徒卻以為他真的睡了。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="約翰福音 16:25; 約翰福音 16:29; 約翰福音 10:24"> 於是，耶穌清楚地對他們說：「拉撒路死了。</span>
<span className="v" id="v15" data-v="15" data-xref="提摩太後書 2:10; 約翰福音 14:10–11; 以賽亞書 54:15"> 為了你們的緣故，我很高興自己不在那裡，好叫你們信我。現在我們可以去了。」</span>
<span className="v" id="v16" data-v="16" data-xref="約翰福音 13:37; 馬太福音 10:3; 約翰福音 21:2"> 綽號「雙胞胎」的多馬對其他門徒說：「我們也去跟祂一塊兒死吧。」</span>
</div>
</div>

## 拉撒路死而復活

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="約翰福音 11:39; 何西阿書 6:2; 使徒行傳 2:27–31"> 耶穌到了伯大尼，得知拉撒路已經在墳墓裡四天了。</span>
<span className="v" id="v18" data-v="18" data-xref="啟示錄 14:20; 啟示錄 21:16; 約翰福音 6:19"> 伯大尼離耶路撒冷不遠，大約只有三公里的路，</span>
<span className="v" id="v19" data-v="19" data-xref="約伯記 2:11; 約翰福音 11:31; 帖撒羅尼迦前書 5:11"> 很多猶太人來看望瑪大和瑪麗亞，為她們兄弟的事來安慰她們。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="路加福音 10:38–42; 帖撒羅尼迦前書 4:17; 馬太福音 25:1"> 瑪大聽說耶穌來了，就去迎接祂，瑪麗亞卻仍然坐在家裡。</span>
<span className="v" id="v21" data-v="21" data-xref="約翰福音 11:32; 列王紀上 17:18; 馬太福音 9:18"> 瑪大對耶穌說：「主啊，你如果早在這裡，我弟弟就不會死了。</span>
<span className="v" id="v22" data-v="22" data-xref="約翰福音 9:31; 約翰福音 11:41–42; 馬太福音 28:18"> 就是現在我也知道你無論向上帝求什麼，上帝必定賜給你。」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="約翰福音 11:43–44"> 耶穌說：「你弟弟必定復活。」</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="但以理書 12:2–3; 使徒行傳 24:15; 約翰福音 5:28–29"> 瑪大說：「我知道，在末日復活的時候，他必復活。」</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="帖撒羅尼迦前書 4:14; 約翰福音 3:36; 約翰一書 5:11–12"> 耶穌說：「我是復活，我是生命。信我的人雖然死了，也必復活。</span>
<span className="v" id="v26" data-v="26" data-xref="約翰福音 10:28; 約翰福音 5:24; 羅馬書 8:13"> 凡活著信我的人必永遠不死。你相信嗎？」</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="馬太福音 16:16; 約翰福音 6:69; 約翰福音 6:14"> 瑪大說：「主啊，我信！我相信你是來到世界的基督，是上帝的兒子。」</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="約翰福音 11:20; 約翰福音 13:13; 馬可福音 10:49"> 瑪大說完了，就回去悄悄地告訴她妹妹瑪麗亞：「老師來了，祂叫你去。」</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="箴言 15:23; 詩篇 27:8; 雅歌 3:1–4"> 瑪麗亞聽了，急忙起來到耶穌那裡。</span>
<span className="v" id="v30" data-v="30" data-xref="約翰福音 11:20"> 那時，耶穌還沒有進村子，仍在瑪大迎接祂的地方。</span>
<span className="v" id="v31" data-v="31" data-xref="約翰福音 11:19; 創世記 37:35; 撒母耳記下 12:16–18"> 那些在家裡安慰瑪麗亞的猶太人，見她匆匆忙忙地起來出去了，以為她要去墳墓那裡哭，就跟著出去。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="約翰福音 11:21; 路加福音 17:16; 路加福音 5:8"> 瑪麗亞來到耶穌那裡，俯伏在祂腳前說：「主啊，你如果早在這裡，我弟弟就不會死了。」</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="約翰福音 11:38; 約翰福音 12:27; 馬可福音 3:5"> 耶穌看見她和陪她來的猶太人都在哭，心中非常激憤和難過，</span>
<span className="v" id="v34" data-v="34" data-xref="馬可福音 15:47; 馬太福音 28:6; 約翰福音 1:39"> 便問：「你們把他葬在哪裡了？」<br />他們答道：「主啊，你來看。」</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="路加福音 19:41; 希伯來書 4:15; 約翰福音 11:33"> 耶穌哭了。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="約翰福音 11:3; 約翰一書 3:1; 約翰一書 4:9–10"> 猶太人說：「你看！祂多麼愛拉撒路啊！」</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="約翰福音 9:6–7; 約翰福音 11:32; 路加福音 23:39"> 其中也有人說：「祂既然能醫治瞎眼的人，難道不能叫這個人不死嗎？」</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="約翰福音 11:33; 路加福音 24:2; 馬太福音 27:60"> 耶穌又非常激憤地來到墳墓前。那墳墓是個洞，洞口堵著一塊大石頭。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="約翰福音 11:17; 馬可福音 16:3; 詩篇 49:7"> 耶穌說：「把石頭挪開。」<br />死者的姐姐瑪大對祂說：「主啊，他死了四天了，肯定臭了。」</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="約翰福音 11:4; 約翰福音 11:23–26; 羅馬書 4:17–25"> 耶穌說：「我不是跟你說過，只要你信，就會看見上帝的榮耀嗎？」</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="馬太福音 11:25; 約翰福音 17:1; 詩篇 123:1"> 於是，他們把石頭挪開，耶穌望著天說：「父啊，我感謝你，因為你已垂聽了我的禱告，</span>
<span className="v" id="v42" data-v="42" data-xref="約翰福音 3:17; 約翰福音 17:21; 約翰一書 4:14"> 我知道你常常垂聽我的禱告。我這樣說是為了周圍站著的眾人，好叫他們相信是你差我來的。」</span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="列王紀下 4:33–36; 使徒行傳 9:40; 使徒行傳 9:34"> 說完，就大聲呼喊：「拉撒路，出來！」</span>
<span className="v" id="v44" data-v="44" data-xref="約翰福音 5:25; 約翰福音 20:7; 約翰福音 11:25–26"> 那死者就出來了，手腳都纏著布條，臉上也包著布。<br />耶穌對他們說：「給他解開，讓他走！」</span>
</div>
</div>

## 謀害耶穌

<div className="bt">
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="約翰福音 2:23; 約翰福音 11:19; 約翰福音 10:41"> 許多來看望瑪麗亞的猶太人看見耶穌的作為，就信了祂，</span>
<span className="v" id="v46" data-v="46" data-xref="約翰福音 9:13; 使徒行傳 5:25; 約翰福音 12:37"> 但也有些人去見法利賽人，把耶穌所行的事告訴他們。</span>
<span className="v" id="v47" data-v="47" data-xref="馬太福音 26:3; 約翰福音 12:19; 使徒行傳 4:5–6"> 祭司長和法利賽人便召開公會會議，說：「這人行了許多神蹟，我們該怎麼辦呢？</span>
<span className="v" id="v48" data-v="48" data-xref="帖撒羅尼迦前書 2:15–16; 馬太福音 23:35–38; 馬太福音 27:25"> 如果讓祂這樣繼續下去，所有的人都會信祂，那時羅馬人一定會來奪取我們的聖地，擄掠我們的人民。」</span>
</div>
<div className="bp">
<span className="v" id="v49" data-v="49" data-xref="馬太福音 26:3; 約翰福音 11:51; 約翰福音 18:13–14"> 那年擔任大祭司的該亞法對他們說：「你們什麼都不懂！</span>
<span className="v" id="v50" data-v="50" data-xref="約翰福音 18:14; 路加福音 24:46; 羅馬書 3:8"> 你們沒有認識到，對你們而言，與其整個民族滅亡，不如一人替眾人死。」</span>
<span className="v" id="v51" data-v="51" data-xref="但以理書 9:26; 哥林多後書 5:21; 出埃及記 28:30"> 其實這句話不是出於他自己，只因那年他是大祭司，上帝藉著他預言耶穌將要替猶太民族死。</span>
<span className="v" id="v52" data-v="52" data-xref="約翰福音 10:16; 以賽亞書 49:6; 約翰一書 2:2"> 祂不單是要替猶太民族死，也要把散居在各處的上帝的兒女聚集在一起。</span>
</div>
<div className="bp">
<span className="v" id="v53" data-v="53" data-xref="使徒行傳 5:33; 使徒行傳 9:23; 馬可福音 14:1"> 從那天起，他們就計劃要殺害耶穌，</span>
<span className="v" id="v54" data-v="54" data-xref="約翰福音 7:1; 約翰福音 7:4; 歷代志下 13:19"> 所以耶穌不再公開地在猶太人中間露面。祂離開那裡，前往靠近曠野的地方，到了以法蓮城，就和門徒住下來。</span>
</div>
<div className="bp">
<span className="v" id="v55" data-v="55" data-xref="歷代志下 30:17–20; 希伯來書 9:13–14; 約翰福音 6:4"> 猶太人的逾越節快到了，有很多人從鄉下上耶路撒冷，預備在過節前潔淨自己。</span>
<span className="v" id="v56" data-v="56" data-xref="約翰福音 7:11; 約翰福音 11:7–8"> 他們四處尋找耶穌，又彼此在聖殿裡談論：「你們怎麼想？祂不會來過節吧？」</span>
<span className="v" id="v57" data-v="57" data-xref="約翰福音 9:22; 約翰福音 8:59; 約翰福音 5:16–18"> 當時祭司長和法利賽人早已下令，任何人知道耶穌在哪裡，都要報告，他們好去抓祂。</span>
</div>
</div>

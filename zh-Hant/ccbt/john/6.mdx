## 耶穌使五千人吃飽

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="馬可福音 6:31–44; 約翰福音 6:23; 路加福音 5:1"> 事後，耶穌渡過加利利湖，就是提比哩亞湖。</span>
<span className="v" id="v2" data-v="2" data-xref="馬太福音 4:24–25; 馬太福音 12:15; 馬太福音 15:30–31"> 許多人因為見過耶穌治病的神蹟，就跟隨了祂。</span>
<span className="v" id="v3" data-v="3" data-xref="約翰福音 6:15; 路加福音 9:28; 路加福音 6:12–13"> 耶穌到了山上，與門徒一起坐下來。</span>
<span className="v" id="v4" data-v="4" data-xref="約翰福音 2:13; 約翰福音 11:55; 約翰福音 5:1"> 那時，猶太人的逾越節快到了。</span>
<span className="v" id="v5" data-v="5" data-xref="馬太福音 15:33; 路加福音 9:12–13; 馬太福音 14:14–15"> 耶穌舉目看見一大群人向祂走來，就對腓力說：「我們到哪裡去買餅給他們吃呢？」</span>
<span className="v" id="v6" data-v="6" data-xref="創世記 22:1; 申命記 13:3; 歷代志下 32:31"> 祂這樣說是想考驗腓力，其實祂知道怎麼做。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="民數記 11:21–22; 馬可福音 6:37; 約翰福音 12:5"> 腓力回答說：「就算買二百個銀幣<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一個銀幣相當於當時一天的工錢。">a</a></sup>的餅，也不夠他們每人分一點兒啊！」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="約翰福音 1:40–44; 馬太福音 4:18"> 另外一個門徒，西門·彼得的弟弟安得烈對耶穌說：</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀下 4:42–44; 馬太福音 14:17; 馬可福音 6:38"> 「這裡有個小孩子，帶了五個大麥餅和兩條魚。不過，這麼多人，這一點東西實在無濟於事。」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="路加福音 9:14–16; 馬太福音 15:35–36; 馬可福音 6:39–41"> 耶穌說：「你們叫大家坐下。」那地方草很多，眾人便坐下來，當時那裡約有五千男人。</span>
<span className="v" id="v11" data-v="11" data-xref="約翰福音 6:23; 帖撒羅尼迦前書 5:18; 馬太福音 15:36"> 耶穌拿起餅來祝謝後，分給坐著的眾人，然後又照樣分魚，眾人可以隨意吃。</span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 1:53; 尼希米記 9:25; 尼希米記 8:10"> 眾人吃飽後，耶穌對門徒說：「把剩下的零碎收拾起來，免得浪費。」</span>
<span className="v" id="v13" data-v="13" data-xref="箴言 11:24–25; 列王紀下 4:2–7; 哥林多後書 9:8–9"> 他們便把眾人吃剩的那五個大麥餅的零碎收拾起來，裝滿了十二個籃子。</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 18:15–18; 馬太福音 21:11; 使徒行傳 7:37"> 眾人看見耶穌行的這個神蹟，都說：「這人真是那位要來到世上的先知！」</span>
<span className="v" id="v15" data-v="15" data-xref="約翰福音 18:36; 約翰福音 6:15–21; 約翰福音 7:3–4"> 耶穌知道他們想強行立祂作王，便獨自退到山上。</span>
</div>
</div>

## 耶穌在湖面上行走

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16"> 傍晚的時候，門徒來到湖邊，</span>
<span className="v" id="v17" data-v="17" data-xref="馬可福音 6:45; 約翰福音 6:24–25; 約翰福音 2:12"> 上了船，去湖對岸的迦百農。天色已暗，耶穌還沒到他們那裡。</span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 107:25; 詩篇 135:7; 馬太福音 14:24"> 忽然，湖面上狂風大作，波濤洶湧。</span>
<span className="v" id="v19" data-v="19" data-xref="馬可福音 6:47–49; 馬太福音 14:25–26; 約伯記 9:8"> 門徒搖著櫓行了大約五六公里，突然看見耶穌在水面上朝他們的船走來，他們很害怕。</span>
<span className="v" id="v20" data-v="20" data-xref="馬太福音 14:27–31; 以賽亞書 43:1–2; 以賽亞書 44:8"> 耶穌對他們說：「是我，不要怕。」</span>
<span className="v" id="v21" data-v="21" data-xref="馬可福音 6:51; 馬太福音 14:32–33; 啟示錄 3:20"> 於是門徒歡然接祂上船，船立刻到了目的地。</span>
</div>
</div>

## 生命之糧

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="馬可福音 6:45; 馬太福音 14:22; 約翰福音 6:2"> 第二天，留在對岸的眾人發現那裡原來只有一條船，而耶穌沒有和門徒一起坐船離開。</span>
<span className="v" id="v23" data-v="23" data-xref="約翰福音 6:1; 約翰福音 6:11–12"> 後來，從提比哩亞來了幾條小船，停泊在靠近主祝謝後給人吃餅的地方。</span>
<span className="v" id="v24" data-v="24" data-xref="約翰福音 6:17; 路加福音 8:40; 馬可福音 6:53"> 眾人發現耶穌和門徒都不在那裡，就乘船到迦百農去找祂。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="約翰福音 1:38–39; 馬太福音 23:7"> 他們在湖對岸找到了耶穌，對祂說：「老師，你什麼時候到這裡來的？」</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="雅各書 4:3–4; 腓立比書 3:19; 腓立比書 2:21"> 耶穌回答說：「我實實在在地告訴你們，你們找我，並不是因為看見了神蹟，而是因為你們有餅吃，並且吃飽了。</span>
<span className="v" id="v27" data-v="27" data-xref="歌羅西書 3:2; 以賽亞書 55:2; 約翰福音 6:54"> 不要為必壞的食物勞碌，要為那存到永生的食物勞碌，就是人子要賜給你們的食物，因為人子有父上帝的印證。」</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="使徒行傳 16:30; 使徒行傳 9:6; 馬太福音 19:16"> 眾人問祂：「我們該做什麼，才是做上帝的工作呢？」</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="約翰一書 3:23; 使徒行傳 16:31; 約翰福音 3:36"> 耶穌說：「信上帝差來的那位，就是做上帝的工作。」</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="約翰福音 12:37; 約翰福音 10:38; 哥林多前書 1:22"> 他們又問：「那麼，你要行什麼神蹟給我們看，好讓我們信你呢？你要做什麼呢？</span>
<span className="v" id="v31" data-v="31" data-xref="尼希米記 9:15; 詩篇 105:40; 詩篇 78:24–25"> 我們的祖先在曠野有嗎哪吃，正如聖經上說，『祂賜下天糧給他們吃。』<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="出埃及記16·4；尼希米記9·15；詩篇78·24、25。">b</a></sup>」</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="約翰福音 15:1; 約翰福音 6:58; 出埃及記 16:4"> 耶穌對他們說：「我實實在在地告訴你們，不是摩西將天上的糧賜給了你們，而是我父將天上的真糧賜給你們。</span>
<span className="v" id="v33" data-v="33" data-xref="約翰福音 8:42; 約翰福音 17:8; 約翰福音 3:13"> 因為上帝賜的糧就是從天降下、賜生命給世人的那位。」</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="約翰福音 4:15; 約翰福音 6:26; 詩篇 4:6"> 他們說：「先生，求你常常把這種糧食賜給我們吧。」</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="約翰福音 6:48–58; 啟示錄 22:17; 約翰福音 6:41"> 耶穌說：「我就是生命的糧，到我這裡來的人必定不餓，信我的人必永遠不渴。</span>
<span className="v" id="v36" data-v="36" data-xref="彼得前書 1:8–9; 路加福音 16:31; 約翰福音 12:37"> 但我對你們說過，你們雖然親眼看見我，還是不信。</span>
<span className="v" id="v37" data-v="37" data-xref="馬太福音 11:28; 約翰福音 6:39; 約翰福音 17:24"> 凡父賜給我的人，必到我這裡來。到我這裡來的，我決不丟棄他。</span>
<span className="v" id="v38" data-v="38" data-xref="約翰福音 5:30; 約翰福音 4:34; 約翰福音 3:31"> 因為我從天上下來，不是要成就自己的旨意，而是要成就差我來者的旨意。</span>
<span className="v" id="v39" data-v="39" data-xref="約翰福音 17:12; 約翰福音 6:40; 約翰福音 18:9"> 差我來者的旨意是，祂所賜給我的，我一個也不會失掉，在末日我要叫他們復活。</span>
<span className="v" id="v40" data-v="40" data-xref="約翰福音 6:54; 約翰福音 5:24; 羅馬書 6:23"> 因為我父的旨意是要叫一切看見兒子並相信的人得到永生，在末日，我要叫他們復活。」</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="約翰福音 6:51–52; 約翰福音 6:48; 約翰福音 6:33"> 猶太人聽見耶穌說自己是從天上降下來的糧，就嘀嘀咕咕，</span>
<span className="v" id="v42" data-v="42" data-xref="路加福音 4:22; 馬可福音 6:3; 馬太福音 13:55–56"> 說：「這不是約瑟的兒子耶穌嗎？祂的父母，我們都認識，祂現在怎麼能說自己是從天上降下來的呢？」</span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="希伯來書 4:13; 約翰福音 6:64; 馬可福音 9:33"> 耶穌回答他們說：「你們不用嘀嘀咕咕。</span>
<span className="v" id="v44" data-v="44" data-xref="約翰福音 6:65; 約翰福音 6:39–40; 馬太福音 11:25–27"> 如果不是差我來的父吸引人，沒有人能到我這裡來。到我這裡來的，在末日，我要叫他復活。</span>
<span className="v" id="v45" data-v="45" data-xref="以賽亞書 54:13; 耶利米書 31:33–34; 希伯來書 10:16"> 先知書上說，『他們都要受上帝的訓誨。』<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="以賽亞書54·13。">c</a></sup>這裡是指凡聽見父的教導又領會的人，都會到我這裡來。</span>
<span className="v" id="v46" data-v="46" data-xref="約翰福音 1:18; 約翰福音 7:29; 馬太福音 11:27"> 這並不是說有人見過父，唯獨從上帝而來的那位見過父。</span>
<span className="v" id="v47" data-v="47" data-xref="約翰福音 3:36; 歌羅西書 3:3–4; 羅馬書 5:9–10"> 我實實在在地告訴你們，信我的人有永生。</span>
<span className="v" id="v48" data-v="48" data-xref="約翰福音 6:51; 哥林多前書 11:24–25; 哥林多前書 10:16–17"> 我是生命的糧。</span>
<span className="v" id="v49" data-v="49" data-xref="哥林多前書 10:3–5; 猶大書 1:5; 撒迦利亞書 1:5"> 你們的祖先在曠野吃過嗎哪，還是死了。</span>
<span className="v" id="v50" data-v="50" data-xref="約翰福音 6:33; 約翰福音 6:51; 羅馬書 8:10"> 但這是從天上降下來的糧，人吃了就不死。</span>
<span className="v" id="v51" data-v="51" data-xref="路加福音 22:19; 約翰福音 6:33; 希伯來書 10:5–12"> 我就是天上降下來的生命之糧，人吃了這糧，必永遠活著。我將要賜下的糧就是我的肉，是為了讓世人得到生命。」</span>
</div>
<div className="bp">
<span className="v" id="v52" data-v="52" data-xref="約翰福音 9:16; 約翰福音 10:19; 約翰福音 6:41"> 猶太人開始彼此爭論，說：「這個人怎麼能把自己的肉給我們吃呢？」</span>
</div>
<div className="bp">
<span className="v" id="v53" data-v="53" data-xref="約翰一書 5:12; 馬太福音 26:26–28; 約翰福音 6:55"> 耶穌說：「我實實在在地告訴你們，如果你們不吃人子的肉，不喝人子的血，你們裡面就沒有生命。</span>
<span className="v" id="v54" data-v="54" data-xref="約翰福音 6:39–40; 約翰福音 6:27; 腓立比書 3:7–10"> 吃我肉、喝我血的人有永生，在末日，我要叫他復活。</span>
<span className="v" id="v55" data-v="55" data-xref="約翰福音 15:1; 約翰福音 8:31; 約翰福音 6:32"> 因為我的肉是真糧食，我的血是真飲品，</span>
<span className="v" id="v56" data-v="56" data-xref="約翰一書 3:24; 約翰福音 15:4–5; 約翰福音 14:20"> 吃我肉、喝我血的人常在我裡面，我也常在他裡面。</span>
<span className="v" id="v57" data-v="57" data-xref="加拉太書 2:20; 約翰福音 5:26; 約翰福音 17:21"> 永活的父差我來，我靠祂而活。同樣，吃我肉的人也靠我而活。</span>
<span className="v" id="v58" data-v="58" data-xref="約翰福音 3:36; 約翰福音 6:47–51; 約翰福音 6:41"> 我是從天上降下來的真糧，吃這糧的人必永遠活著，不像你們的祖先，雖然吃過嗎哪，最後還是死了。」</span>
</div>
<div className="bp">
<span className="v" id="v59" data-v="59" data-xref="約翰福音 6:24; 箴言 8:1–3; 路加福音 4:31"> 這番話是耶穌在迦百農會堂裡教導人的時候講的。</span>
</div>
</div>

## 永生之道

<div className="bt">
<div className="bp">
<span className="v" id="v60" data-v="60" data-xref="約翰福音 6:66; 約翰福音 8:43; 約翰福音 8:31"> 祂的許多門徒聽了，就議論說：「這話實在難懂，誰能接受呢？」</span>
</div>
<div className="bp">
<span className="v" id="v61" data-v="61" data-xref="約翰福音 2:24–25; 約翰福音 6:64; 約翰福音 21:17"> 耶穌知道門徒在嘀咕，就說：「這話讓你們反感嗎？</span>
<span className="v" id="v62" data-v="62" data-xref="馬可福音 16:19; 約翰福音 3:13; 約翰福音 17:4–5"> 如果你們看見人子升到祂原來所在的地方，會怎麼樣呢？</span>
<span className="v" id="v63" data-v="63" data-xref="加拉太書 5:25; 希伯來書 4:12; 詩篇 119:93"> 叫人活著的是靈，肉體毫無作用。我對你們說的話就是靈，就是生命。</span>
<span className="v" id="v64" data-v="64" data-xref="約翰福音 10:26; 提摩太後書 2:19; 希伯來書 4:13"> 然而，你們中間有些人不信。」因為耶穌一開始就知道誰不信祂、誰會出賣祂。</span>
</div>
<div className="bp">
<span className="v" id="v65" data-v="65" data-xref="約翰福音 6:44–45; 約翰福音 6:37; 約翰福音 3:27"> 祂繼續說：「所以我曾對你們說，如果不是我父賜恩，沒有人能到我這裡來。」</span>
</div>
<div className="bp">
<span className="v" id="v66" data-v="66" data-xref="路加福音 9:62; 約翰一書 2:19; 希伯來書 10:38"> 從此，很多門徒離開了，不再跟從耶穌。</span>
</div>
<div className="bp">
<span className="v" id="v67" data-v="67" data-xref="路得記 1:11–18; 約翰福音 6:70; 路加福音 14:25–33"> 於是耶穌問那十二個門徒：「你們也要離開我嗎？」</span>
</div>
<div className="bp">
<span className="v" id="v68" data-v="68" data-xref="詩篇 73:25; 約翰福音 5:24; 約翰一書 5:11–13"> 西門·彼得答道：「主啊！你有永生之道，我們還跟從誰呢？</span>
<span className="v" id="v69" data-v="69" data-xref="約翰福音 11:27; 路加福音 9:20; 馬可福音 8:29"> 我們已經相信並且知道你是上帝的聖者。」</span>

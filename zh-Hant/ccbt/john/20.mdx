## 耶穌復活

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="馬可福音 16:9; 馬太福音 27:60; 約翰福音 19:25"> 週日清晨，天還未亮，抹大拉的瑪麗亞就來到墳墓前，發現墓口的石頭已經挪開了。</span>
<span className="v" id="v2" data-v="2" data-xref="約翰福音 13:23; 約翰福音 20:13; 約翰福音 21:24"> 她趕快跑去告訴西門·彼得和耶穌所愛的那個門徒，說：「有人把主從墳墓裡搬走了，不知放到哪裡去了。」</span>
<span className="v" id="v3" data-v="3" data-xref="路加福音 24:12"> 彼得和那個門徒聽了就出去，往墳墓那邊跑。</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳記下 18:23; 哥林多後書 8:12; 哥林多前書 9:24"> 兩個人一起跑，但那個門徒比彼得跑得快，所以先到了墳墓。</span>
<span className="v" id="v5" data-v="5" data-xref="約翰福音 19:40; 約翰福音 20:11; 約翰福音 11:44"> 他沒有進去，只是探頭往裡看，看見細麻布還在那裡。</span>
<span className="v" id="v6" data-v="6" data-xref="約翰福音 18:17; 約翰福音 21:7; 馬太福音 16:15–16"> 西門·彼得隨後也來了，他進到裡邊，看到細麻布放在那裡，</span>
<span className="v" id="v7" data-v="7" data-xref="約翰福音 11:44"> 耶穌的裹頭巾則捲著放在另一處，沒有和細麻布放在一起。</span>
<span className="v" id="v8" data-v="8" data-xref="約翰福音 20:25; 約翰福音 20:4; 約翰福音 1:50"> 先到的那個門徒也進來了，看見這種情形就信了。</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 16:10; 以賽亞書 25:8; 以賽亞書 53:10–12"> 因為他們還不明白聖經上有關耶穌必須從死裡復活的話。</span>
<span className="v" id="v10" data-v="10" data-xref="約翰福音 7:53; 約翰福音 16:32"> 然後，他們各自回家去了。</span>
<span className="v" id="v11" data-v="11" data-xref="約翰福音 20:5"> 瑪麗亞卻站在墳墓外面哭泣，邊哭邊往墳墓裡面看，</span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 24:3–7; 啟示錄 3:4; 馬可福音 16:5–6"> 看見兩個穿著白衣的天使，分別坐在原來安放耶穌遺體的頭腳兩端。</span>
<span className="v" id="v13" data-v="13" data-xref="約翰福音 20:15; 約翰福音 2:4; 撒母耳記上 1:8"> 天使對她說：「婦人，你為什麼哭呢？」 她說：「有人把我的主搬走了，我不知道放在什麼地方。」</span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 24:16; 約翰福音 21:4; 馬太福音 28:9"> 說完，她轉過身來，看見耶穌站在那裡，但她不知道是耶穌。</span>
<span className="v" id="v15" data-v="15" data-xref="約翰福音 20:13; 約翰福音 18:7; 約翰福音 1:38"> 耶穌問她：「婦人，你為什麼哭？你在找誰？」 瑪麗亞還以為祂是園丁，就說：「先生，如果是你把祂搬走了，請告訴我放在哪裡了，我好搬回來。」</span>
<span className="v" id="v16" data-v="16" data-xref="約翰福音 10:3; 約翰福音 1:38; 使徒行傳 10:3"> 耶穌說：「瑪麗亞。」 瑪麗亞轉向祂用希伯來話說：「拉波尼！」拉波尼的意思是老師。</span>
<span className="v" id="v17" data-v="17" data-xref="約翰福音 16:28; 以弗所書 4:8–10; 加拉太書 4:6–7"> 耶穌說：「不要拉著我，我還沒有升到父那裡。你先去找我的眾弟兄，告訴他們我要升天去見我的父，也是你們的父；去見我的上帝，也是你們的上帝。」</span>
<span className="v" id="v18" data-v="18" data-xref="路加福音 24:10; 馬太福音 28:10; 約翰福音 20:1"> 抹大拉的瑪麗亞就去向門徒報信，說：「我看見主了！」又把主對她說的話告訴門徒。</span>
</div>
</div>

## 向門徒顯現

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="約翰福音 20:26; 約翰福音 14:27; 約翰福音 20:21"> 當晚，即週日晚上，門徒因為害怕猶太人，把房門都關上了。忽然，耶穌來了，站在他們當中，對他們說：「願你們平安！」</span>
<span className="v" id="v20" data-v="20" data-xref="約翰福音 16:22; 約翰福音 16:20; 約翰福音 20:27"> 說完，祂把手和肋旁給他們看。門徒看見主，十分歡喜。</span>
<span className="v" id="v21" data-v="21" data-xref="約翰福音 17:18–19; 約翰福音 13:20; 約翰福音 3:17"> 耶穌又說：「願你們平安！父怎樣差遣我，我也照樣差遣你們。」</span>
<span className="v" id="v22" data-v="22" data-xref="約伯記 33:4; 創世記 2:7; 使徒行傳 8:15"> 然後祂向他們吹了一口氣，說：「你們領受聖靈吧！</span>
<span className="v" id="v23" data-v="23" data-xref="馬太福音 18:18; 馬太福音 16:19; 馬可福音 2:5–10"> 你們赦免誰的罪，誰的罪就得到赦免；你們不赦免誰的罪，誰的罪就得不到赦免。」</span>
</div>
</div>

## 向多馬顯現

<div className="bt">
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="約翰福音 11:16; 約翰福音 6:66–67; 希伯來書 10:25"> 耶穌顯現的時候，十二個門徒中綽號「雙胞胎」的多馬不在場。</span>
<span className="v" id="v25" data-v="25" data-xref="約翰福音 6:30; 馬可福音 16:11; 希伯來書 3:12"> 其他門徒告訴他：「我們看見主了！」可是多馬說：「除非我親眼看見祂手上的釘痕，用手摸到祂手上的釘痕和祂的肋旁，否則我決不信。」</span>
<span className="v" id="v26" data-v="26" data-xref="約翰福音 20:19; 以賽亞書 54:10; 約翰福音 20:21"> 過了八天，門徒又聚在一起，多馬也在，門都關著。突然耶穌來了，站在他們當中說：「願你們平安！」</span>
<span className="v" id="v27" data-v="27" data-xref="約翰福音 20:25; 約翰一書 1:1–2; 約翰福音 20:20"> 然後對多馬說：「把你的指頭放在我手上摸摸看，伸出手來摸摸我的肋旁。不要懷疑，要相信！」</span>
<span className="v" id="v28" data-v="28" data-xref="約翰福音 1:1; 以賽亞書 9:6; 以賽亞書 7:14"> 多馬回答說：「我的主，我的上帝！」</span>
<span className="v" id="v29" data-v="29" data-xref="彼得前書 1:8; 哥林多後書 5:7; 希伯來書 11:1"> 耶穌說：「你看見我才信，那些沒有看見就信的人有福了。」</span>
<span className="v" id="v30" data-v="30" data-xref="約翰福音 21:25; 提摩太後書 3:15–17; 羅馬書 15:4"> 耶穌在門徒面前還行了許多神蹟，只是沒有記在這本書裡。</span>
<span className="v" id="v31" data-v="31" data-xref="使徒行傳 10:43; 約翰福音 3:15–16; 約翰一書 5:1"> 而記載這些事，是為了使你們相信耶穌就是基督，是上帝的兒子，並且使你們這些信祂的人可以靠祂的名得到生命。</span>
</div>

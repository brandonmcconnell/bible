<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以賽亞書 53:5; 以賽亞書 50:6; 馬太福音 20:19"> 於是彼拉多命人鞭打耶穌。</span>
<span className="v" id="v2" data-v="2" data-xref="馬可福音 15:16–20; 路加福音 23:11; 馬太福音 27:27–31"> 士兵用荊棘編成冠冕戴在祂頭上，又拿紫袍給祂穿上，</span>
<span className="v" id="v3" data-v="3" data-xref="馬太福音 27:29; 馬太福音 26:49; 路加福音 1:28"> 來到祂面前說：「猶太人的王萬歲！」然後又用手掌打祂。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="約翰福音 18:38; 約翰福音 19:6; 路加福音 23:4"> 彼拉多又走到外面對眾人說：「我把祂帶到你們面前，好讓你們知道我查不出祂有什麼罪。」</span>
<span className="v" id="v5" data-v="5" data-xref="約翰福音 19:2; 希伯來書 12:2; 以賽亞書 7:14"> 於是，耶穌戴著荊棘冠冕、穿著紫色長袍走出來。彼拉多對眾人說：「你們看這個人！」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="約翰福音 18:31; 約翰福音 19:4; 使徒行傳 2:23"> 祭司長和差役一看見耶穌，就喊道：「把祂釘在十字架上！把祂釘在十字架上！」<br />彼拉多說：「你們自己把祂帶去釘十字架吧！因為我查不出祂有什麼罪。」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="利未記 24:16; 約翰福音 5:18; 馬太福音 26:63–66"> 猶太人回答說：「我們有律法，按照那律法，祂理當被處死，因為祂自稱是上帝的兒子。」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="約翰福音 19:13; 使徒行傳 14:11–19"> 彼拉多聽了這話，更加害怕，</span>
<span className="v" id="v9" data-v="9" data-xref="約翰福音 18:33; 詩篇 38:13–15; 腓立比書 1:28"> 又將耶穌帶回總督府，問祂：「你到底是從哪裡來的？」但耶穌沒有回答。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="但以理書 5:19; 約翰福音 18:39; 但以理書 3:14–15"> 彼拉多說：「你不回答我嗎？難道你不知道我有權釋放你，也有權把你釘在十字架上嗎？」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="羅馬書 13:1; 約翰福音 3:27; 使徒行傳 2:23"> 耶穌回答說：「若非從天上賜下權柄給你，你根本無權處置我。因此，把我交給你的那人罪更大。」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="使徒行傳 17:6–7; 約翰福音 18:33–36; 馬可福音 6:16–26"> 從那時起，彼拉多想要釋放耶穌，可是猶太人卻一直喊叫：「你如果釋放這個人，就不是凱撒的忠臣<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「忠臣」希臘文是「朋友」。">a</a></sup>。凡自以為王的，就是背叛凱撒。」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="詩篇 82:5–7; 馬太福音 27:19; 阿摩司書 4:7"> 彼拉多聽了這話，就帶著耶穌來到一個地方，名叫「鋪石地」，希伯來話叫厄巴大。彼拉多在那裡開庭審判祂。</span>
<span className="v" id="v14" data-v="14" data-xref="馬太福音 27:62; 約翰福音 19:5; 馬可福音 15:25"> 那天正是逾越節的預備日，大約正午，彼拉多對猶太人說：「看，你們的王！」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="路加福音 23:18; 使徒行傳 21:36; 約翰福音 19:6"> 眾人喊道：「除掉祂！除掉祂！把祂釘在十字架上！」<br />彼拉多說：「我可以把你們的王釘在十字架上嗎？」<br />祭司長答道：「除了凱撒，我們沒有別的王！」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="路加福音 23:24–25; 馬太福音 27:26–31; 馬可福音 15:15–20"> 於是，彼拉多將耶穌交給他們去釘十字架，他們就把耶穌帶走了。</span>
</div>
</div>

## 釘十字架

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="路加福音 23:33; 路加福音 14:27; 路加福音 23:26"> 耶穌背著自己的十字架出來，前往髑髏地<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="可能當地的石灰巖地形看起來像一具骷髏頭，故此得名。">b</a></sup>，那地方希伯來話叫各各他。</span>
<span className="v" id="v18" data-v="18" data-xref="以賽亞書 53:12; 馬可福音 15:24–27; 加拉太書 3:13"> 他們在那裡把耶穌釘在十字架上。同時還釘了兩個人，一邊一個，耶穌在當中。</span>
<span className="v" id="v19" data-v="19" data-xref="馬太福音 27:37; 路加福音 23:38; 馬可福音 15:26"> 彼拉多寫了一個告示，安在十字架上，上面寫著：「猶太人的王，拿撒勒人耶穌。」</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行傳 26:14; 啟示錄 16:16; 使徒行傳 22:2"> 因為耶穌被釘十字架的地方離城不遠，告示上面的字是用希伯來、羅馬、希臘三種文字寫的，所以很多猶太人讀了上面的字。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="約翰福音 19:14; 約翰福音 19:19"> 猶太人的祭司長對彼拉多說：「不要寫『猶太人的王』，應該寫『這人自稱是猶太人的王』。」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="詩篇 76:10; 詩篇 65:7; 箴言 8:29"> 彼拉多說：「我寫了就寫了。」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="路加福音 23:34; 馬可福音 15:24; 馬太福音 27:35"> 士兵把耶穌釘在十字架上，又把祂的衣服分成四份，每人一份。剩下的內衣從上到下是一塊布，沒有縫口。</span>
<span className="v" id="v24" data-v="24" data-xref="詩篇 22:18; 約翰福音 19:28; 約翰福音 19:36–37"> 他們就商量說：「不要撕破它，讓我們抽籤決定給誰吧。」<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="詩篇22·18。">c</a></sup>這件事是要應驗聖經上的話：「他們分了我的外衣，又為我的內衣抽籤。」士兵果然這樣做了。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="路加福音 23:49; 馬太福音 27:55–56; 約翰福音 20:1"> 耶穌的十字架旁邊站著祂母親、祂母親的姊妹、革羅罷的妻子瑪麗亞和抹大拉的瑪麗亞。</span>
<span className="v" id="v26" data-v="26" data-xref="約翰福音 21:24; 約翰福音 20:2; 約翰福音 2:4"> 耶穌看見祂的母親和祂愛的門徒都站在旁邊，就對母親說：「女士，看啊，他是你的兒子。」</span>
<span className="v" id="v27" data-v="27" data-xref="馬太福音 12:48–50; 約翰福音 16:32; 提摩太前書 5:2–4"> 然後對那門徒說：「看啊，她是你的母親。」從那天起，那個門徒就把她接到自己家裡去了。</span>
</div>
</div>

## 耶穌之死

<div className="bt">
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="詩篇 69:21; 詩篇 22:15; 約翰福音 19:30"> 之後，耶穌知道一切都完成了，就說：「我渴了。」這是要應驗聖經上的話。</span>
<span className="v" id="v29" data-v="29" data-xref="民數記 19:18; 路加福音 23:36; 馬可福音 15:36"> 那裡有一個器皿盛滿了酸酒。有人用海綿蘸滿了酸酒，綁在牛膝草上送到祂嘴邊，</span>
<span className="v" id="v30" data-v="30" data-xref="約翰福音 17:4; 腓立比書 2:8; 歌羅西書 2:14–17"> 耶穌喝了那酸酒，然後說：「成了！」就垂下頭來，將靈魂交給了上帝。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="約翰福音 19:14; 約翰福音 19:42; 馬可福音 15:42"> 因為那天是預備日，第二天的安息日是個大日子，為了避免在安息日有屍首留在十字架上，猶太人便求彼拉多叫人打斷他們的腿，把他們搬走。</span>
<span className="v" id="v32" data-v="32" data-xref="約翰福音 19:18; 路加福音 23:39–43"> 於是，士兵上前把與耶穌同釘十字架的兩個人的腿都打斷了。</span>
<span className="v" id="v33" data-v="33"> 但是他們來到耶穌那裡時，發現祂已經死了，就沒有打斷祂的腿，</span>
<span className="v" id="v34" data-v="34" data-xref="約翰一書 5:6; 撒迦利亞書 12:10; 撒迦利亞書 13:1"> 只是有一個士兵用矛刺了一下祂的肋旁，頓時有血和水流了出來。</span>
<span className="v" id="v35" data-v="35" data-xref="約翰福音 21:24; 希伯來書 2:3–4; 約翰一書 1:1–3"> 看見這事的人為此作見證，他的見證是真實的，他知道自己所說的是事實，好讓你們可以相信。</span>
<span className="v" id="v36" data-v="36" data-xref="詩篇 34:20; 民數記 9:12; 出埃及記 12:46"> 這些事的發生是為了應驗聖經上的話：「祂的骨頭一根也不會折斷。」<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="出埃及記12·46；民數記9·12；詩篇34·20。">d</a></sup></span>
<span className="v" id="v37" data-v="37" data-xref="撒迦利亞書 12:10; 啟示錄 1:7; 詩篇 22:16–17"> 還有經文說：「他們必仰望自己所刺的那位。」<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="撒迦利亞書12·10。">e</a></sup></span>
</div>
</div>

## 安葬耶穌

<div className="bt">
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="馬可福音 15:42–47; 馬太福音 27:57–61; 箴言 29:25"> 事後，有一個名叫約瑟的亞利馬太人請求彼拉多讓他為耶穌收屍。他因為畏懼猶太人，只是暗中做耶穌的門徒。彼拉多批准後，他就把耶穌的遺體領去。</span>
<span className="v" id="v39" data-v="39" data-xref="約翰福音 7:50–52; 雅歌 4:14; 約翰福音 3:1–21"> 曾經夜訪耶穌的尼哥德慕也來了，他帶來了沒藥和沉香調成的香料，重約三十四公斤。</span>
<span className="v" id="v40" data-v="40" data-xref="約翰福音 11:44; 約翰福音 20:5–7; 使徒行傳 5:6"> 他們按照猶太人殯葬的習俗，用細麻布加上香料把耶穌的遺體裹好。</span>
<span className="v" id="v41" data-v="41" data-xref="路加福音 23:53; 馬太福音 27:60; 約翰福音 20:15"> 在耶穌被釘十字架的地方有一個園子，裡邊有一座新墳墓，從來沒有安葬過人。</span>
<span className="v" id="v42" data-v="42" data-xref="約翰福音 19:31; 約翰福音 19:14; 以賽亞書 53:9"> 因為那天是猶太人的預備日，這座新墳墓也在附近，他們就把耶穌安放在那裡。</span>
</div>

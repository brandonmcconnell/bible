## 耶穌被捕

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="馬可福音 14:32; 馬太福音 26:36; 撒母耳記下 15:23"> 耶穌禱告完畢，就帶著門徒穿過汲淪溪，進了那裡的一個園子。</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 21:37; 路加福音 22:39; 馬可福音 11:11–12"> 因為耶穌時常帶著門徒到那裡聚會，所以出賣耶穌的猶大也知道那地方。</span>
<span className="v" id="v3" data-v="3" data-xref="約翰福音 18:12; 路加福音 22:47–53; 詩篇 22:12"> 這時，猶大帶著一隊士兵以及祭司長和法利賽人的差役，拿著燈籠、火把和兵器來了。</span>
<span className="v" id="v4" data-v="4" data-xref="約翰福音 13:1; 約翰福音 18:7; 詩篇 27:3"> 耶穌知道將要發生在自己身上的一切事，於是出來問他們：「你們找誰？」</span>
<span className="v" id="v5" data-v="5" data-xref="馬太福音 21:11; 約翰福音 19:19; 馬太福音 2:23"> 他們回答說：「拿撒勒人耶穌！」 耶穌說：「我就是。」那時出賣耶穌的猶大也站在他們當中。</span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 27:2; 詩篇 70:2–3; 列王紀下 1:9–15"> 他們聽到耶穌說「我就是」，便後退跌倒在地上。</span>
<span className="v" id="v7" data-v="7" data-xref="約翰福音 18:4"> 耶穌又問：「你們找誰？」 他們說：「拿撒勒人耶穌。」</span>
<span className="v" id="v8" data-v="8" data-xref="約翰福音 10:28; 馬太福音 26:56; 哥林多後書 12:9"> 耶穌說：「我已經告訴你們我就是。你們既然找我，就讓這些人走吧。」</span>
<span className="v" id="v9" data-v="9" data-xref="約翰福音 17:12"> 這是要應驗祂以前說的：「你賜給我的人一個也沒有失掉。」<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="約翰福音6·39。">a</a></sup></span>
<span className="v" id="v10" data-v="10" data-xref="馬可福音 14:47; 馬太福音 26:51–54; 路加福音 22:49–51"> 西門·彼得帶著一把刀，他拔刀向大祭司的奴僕馬勒古砍去，削掉了他的右耳。</span>
<span className="v" id="v11" data-v="11" data-xref="馬太福音 20:22; 馬太福音 26:39; 約翰福音 20:17"> 耶穌對彼得說：「收刀入鞘吧！我父賜給我的杯，我怎能不喝呢？」</span>
<span className="v" id="v12" data-v="12" data-xref="馬太福音 26:57; 約翰福音 18:3; 使徒行傳 21:37"> 千夫長帶著士兵和猶太人的差役抓住耶穌，把祂捆綁起來。</span>
<span className="v" id="v13" data-v="13" data-xref="約翰福音 18:24; 約翰福音 11:51; 馬太福音 26:3"> 他們押著耶穌先去見亞那，他是那一年的大祭司該亞法的岳父。</span>
<span className="v" id="v14" data-v="14" data-xref="約翰福音 11:49–52"> 這個該亞法以前曾對猶太人建議說：「不如一人替眾人死。」</span>
</div>
</div>

## 彼得不認主

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="路加福音 22:54; 馬可福音 14:54; 馬太福音 26:58–68"> 西門·彼得和另一個門徒跟在耶穌後面。那門徒認識大祭司，就跟著耶穌進了大祭司的院子。</span>
<span className="v" id="v16" data-v="16" data-xref="馬太福音 26:69; 馬可福音 14:66–68; 路加福音 22:55–57"> 彼得留在門外。後來，認識大祭司的那個門徒出來對看門的婢女說了一聲，便把彼得也帶了進去。</span>
<span className="v" id="v17" data-v="17" data-xref="馬太福音 26:69–70; 約翰福音 21:15; 路加福音 22:56–57"> 看門的婢女問彼得：「你不也是這個人的門徒嗎？」 他說：「我不是。」</span>
<span className="v" id="v18" data-v="18" data-xref="馬可福音 14:54; 約翰福音 18:25; 馬可福音 14:67"> 天氣很冷，奴僕和差役生了一堆炭火，站著烤火取暖，彼得也跟他們站在一起烤火取暖。</span>
<span className="v" id="v19" data-v="19" data-xref="馬可福音 14:55–65; 路加福音 20:20; 路加福音 22:63–71"> 那時，大祭司正在盤問耶穌有關祂的門徒和祂的教導之事。</span>
<span className="v" id="v20" data-v="20" data-xref="約翰福音 7:26; 以賽亞書 48:16; 馬太福音 4:23"> 耶穌說：「我是公開對世人講的，我常在猶太人聚集的會堂和聖殿教導人，沒有在背地裡講過什麼。</span>
<span className="v" id="v21" data-v="21" data-xref="馬太福音 26:59–60; 使徒行傳 24:12–13; 路加福音 22:67"> 你何必問我呢？問那些聽過我講的人吧，他們知道我講過什麼。」</span>
<span className="v" id="v22" data-v="22" data-xref="約翰福音 19:3; 馬可福音 14:65; 路加福音 22:63–64"> 耶穌話才說完，站在旁邊的差役就打祂耳光，說：「你敢這樣回答大祭司！」</span>
<span className="v" id="v23" data-v="23" data-xref="彼得前書 2:20–23; 哥林多後書 10:1; 馬太福音 5:39"> 耶穌說：「如果我說錯了，你可以指出我錯在哪裡。如果我說的對，你為什麼打我呢？」</span>
<span className="v" id="v24" data-v="24" data-xref="約翰福音 18:13; 馬太福音 26:57"> 亞那派人把耶穌捆綁著押到大祭司該亞法那裡。</span>
<span className="v" id="v25" data-v="25" data-xref="馬可福音 14:67–72; 約翰福音 18:17–18; 創世記 18:15"> 那時西門·彼得仍然站在那裡烤火，有人問他：「你不也是祂的門徒嗎？」 彼得否認說：「我不是！」</span>
<span className="v" id="v26" data-v="26" data-xref="約翰福音 18:1; 約翰福音 18:10; 馬太福音 26:73"> 大祭司有個奴僕，跟被彼得削掉耳朵的那人是親戚，他說：「我不是看見你和祂一起在園子裡嗎？」</span>
<span className="v" id="v27" data-v="27" data-xref="約翰福音 13:38; 馬可福音 14:71–72; 路加福音 22:60–62"> 彼得再次否認。就在那時，雞叫了。</span>
</div>
</div>

## 彼拉多審問耶穌

<div className="bt">
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="約翰福音 18:33; 約翰福音 19:9; 馬太福音 27:27"> 黎明的時候，眾人從該亞法那裡把耶穌押往總督府，他們自己卻沒有進去，因為怕沾染污穢，不能吃逾越節的晚餐。</span>
<span className="v" id="v29" data-v="29" data-xref="馬太福音 27:23; 馬可福音 15:2–5; 馬太福音 27:11–14"> 彼拉多出來問他們：「你們控告這個人什麼罪？」</span>
<span className="v" id="v30" data-v="30" data-xref="使徒行傳 3:13; 路加福音 20:19–26; 馬可福音 10:33"> 他們回答說：「如果祂沒有為非作歹，我們也不會把祂送到你這裡來。」</span>
<span className="v" id="v31" data-v="31" data-xref="約翰福音 19:6–7; 約翰福音 19:15; 使徒行傳 25:18–20"> 彼拉多說：「你們把祂帶走，按照你們的律法去審理吧。」 猶太人說：「可是我們無權處死人。」</span>
<span className="v" id="v32" data-v="32" data-xref="約翰福音 3:14; 馬太福音 20:19; 馬太福音 26:2"> 這是要應驗耶穌預言自己會怎樣死的話。</span>
<span className="v" id="v33" data-v="33" data-xref="路加福音 23:3–4; 約翰福音 18:37; 約翰福音 19:3"> 彼拉多回到總督府提審耶穌，問道：「你是猶太人的王嗎？」</span>
<span className="v" id="v34" data-v="34"> 耶穌回答說：「你這樣問，是你自己的意思，還是聽別人說的？」</span>
<span className="v" id="v35" data-v="35" data-xref="使徒行傳 18:14–16; 尼希米記 4:2; 羅馬書 3:1–2"> 彼拉多說：「難道我是猶太人嗎？是你們猶太人和祭司長把你送來的。你到底做了什麼？」</span>
<span className="v" id="v36" data-v="36" data-xref="路加福音 17:20–21; 歌羅西書 1:12–14; 羅馬書 14:17"> 耶穌答道：「我的國不屬於這個世界，如果我的國屬於這個世界，我的臣僕早就起來爭戰了，我也不會被交在猶太人的手裡。但現在我的國不屬於這個世界。」</span>
<span className="v" id="v37" data-v="37" data-xref="約翰一書 4:6; 約翰福音 8:47; 約翰福音 8:14"> 於是彼拉多對祂說：「那麼，你是王嗎？」 耶穌說：「你說我是王，我正是為此而生，也為此來到世上為真理作見證，屬於真理的人都聽從我的話。」</span>
<span className="v" id="v38" data-v="38" data-xref="約翰福音 19:4; 路加福音 23:4; 約翰福音 19:6"> 彼拉多說：「真理是什麼？」說完了，又到外面對猶太人說：「我查不出祂有什麼罪。</span>
<span className="v" id="v39" data-v="39" data-xref="馬太福音 27:15–18; 路加福音 23:16–23; 馬可福音 15:6–14"> 不過按照慣例，在逾越節我要給你們釋放一個人。你們要我為你們釋放猶太人的王嗎？」</span>
<span className="v" id="v40" data-v="40" data-xref="路加福音 23:25; 馬可福音 15:15; 馬太福音 27:16"> 眾人又高喊：「不要這個人！我們要巴拉巴！」巴拉巴是個強盜。</span>
</div>

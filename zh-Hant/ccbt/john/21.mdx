## 海邊顯現

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="約翰福音 6:1; 約翰福音 6:23; 馬太福音 28:16"> 後來，耶穌在提比哩亞湖邊又向門徒顯現。當時的情形是這樣：</span>
<span className="v" id="v2" data-v="2" data-xref="馬太福音 4:21–22; 約翰福音 1:45–1; 約翰福音 4:46"> 西門·彼得、綽號「雙胞胎」的多馬、加利利的迦拿人拿但業、西庇太的兩個兒子以及其他兩個門徒都在一起。</span>
<span className="v" id="v3" data-v="3" data-xref="路加福音 5:5; 馬太福音 4:18–20; 帖撒羅尼迦後書 3:7–9"> 西門·彼得對他們說：「我要去打魚！」 眾人說：「我們也跟你去。」於是他們就出去，上了船，但那一夜什麼也沒打到。</span>
<span className="v" id="v4" data-v="4" data-xref="約翰福音 20:14; 路加福音 24:15–16; 路加福音 24:31"> 天將破曉的時候，耶穌站在岸上，但門徒都不知道是耶穌。</span>
<span className="v" id="v5" data-v="5" data-xref="腓立比書 4:19; 腓立比書 4:11–13; 約翰一書 2:13"> 耶穌對他們說：「孩子們，打到魚沒有？」 他們回答說：「沒有！」</span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 5:4–7; 使徒行傳 2:41; 約翰福音 2:5"> 耶穌說：「在船的右邊下網就會打到魚。」於是他們照著祂的話把網撒下去，網到的魚多到連網都拉不動。</span>
<span className="v" id="v7" data-v="7" data-xref="約翰福音 13:23; 約翰福音 20:2; 馬太福音 14:28–29"> 耶穌所愛的那個門徒對彼得說：「是主！」那時西門·彼得赤著身子，一聽見是主，立刻束上外衣，跳進海裡。</span>
<span className="v" id="v8" data-v="8" data-xref="申命記 3:11"> 其他門徒離岸不遠，約有一百米，他們隨後用船把那一網魚拖到岸邊。</span>
<span className="v" id="v9" data-v="9" data-xref="約翰福音 21:13; 列王紀上 19:5–6; 約翰福音 21:10"> 他們上岸後，看見有一堆炭火，上面有魚和餅。</span>
<span className="v" id="v10" data-v="10"> 耶穌說：「拿幾條剛打的魚來。」</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 5:6–8; 使徒行傳 2:41"> 西門·彼得就上船把網拉上岸。網裡一共有一百五十三條大魚！雖然魚這麼多，網卻沒有破。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行傳 10:41; 路加福音 9:45; 約翰福音 16:19"> 耶穌又說：「你們來吃早餐吧！」沒有一個門徒敢問祂是誰，他們都知道祂是主。</span>
<span className="v" id="v13" data-v="13" data-xref="約翰福音 21:9; 使徒行傳 10:41; 路加福音 24:42–43"> 耶穌過來把餅和魚分給他們。</span>
<span className="v" id="v14" data-v="14" data-xref="約翰福音 20:26; 約翰福音 20:19"> 這是耶穌從死裡復活後第三次向門徒顯現。</span>
</div>
</div>

## 耶穌和彼得

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="以賽亞書 40:11; 約翰一書 4:19; 羅馬書 15:1"> 吃過早餐後，耶穌對西門·彼得說：「約翰的兒子西門，你比這些人更愛我嗎？<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「你比這些人更愛我嗎」或譯「你愛我比愛這些更深嗎」。">a</a></sup>」 彼得說：「主啊！是的，你知道我愛你。」 耶穌對他說：「你要餵養我的小羊。」</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行傳 20:28; 彼得前書 5:2; 彼得前書 2:25"> 耶穌第二次問：「約翰的兒子西門，你愛我嗎？」 彼得說：「主啊！是的，你知道我愛你。」 耶穌說：「你要牧養我的羊。」</span>
<span className="v" id="v17" data-v="17" data-xref="約翰福音 13:38; 約翰福音 16:30; 馬可福音 14:72"> 耶穌第三次問：「約翰的兒子西門，你愛我嗎？」 彼得因為耶穌一連三次這樣問他，就難過起來，於是對耶穌說：「主啊！你無所不知，你知道我愛你。」 耶穌說：「你要餵養我的羊。</span>
<span className="v" id="v18" data-v="18" data-xref="約翰福音 13:36; 使徒行傳 12:3–4; 使徒行傳 21:11"> 我實實在在地告訴你，你年輕的時候，自己穿上衣服，想去哪裡就去哪裡。但到你年老的時候，你將伸出手來，別人要把你綁起來帶到你不願意去的地方。」</span>
<span className="v" id="v19" data-v="19" data-xref="彼得後書 1:14; 約翰福音 21:22; 馬太福音 10:38"> 這話是暗示彼得將要怎樣死來使上帝得榮耀。之後，耶穌又對他說：「你跟從我吧！」</span>
<span className="v" id="v20" data-v="20" data-xref="約翰福音 21:7; 約翰福音 20:2; 約翰福音 21:24"> 彼得轉身看見耶穌所愛的那個門徒跟在後面，就是吃最後的晚餐時靠在耶穌身邊問「主啊！是誰要出賣你」的那個門徒。</span>
<span className="v" id="v21" data-v="21" data-xref="路加福音 13:23–24; 使徒行傳 1:6–7; 馬太福音 24:3–4"> 彼得問耶穌：「主啊！他將來會怎樣呢？」</span>
<span className="v" id="v22" data-v="22" data-xref="啟示錄 2:25; 啟示錄 3:11; 馬可福音 9:1"> 耶穌說：「我如果要他活到我再來，與你有什麼關係？你只管跟從我吧！」</span>
<span className="v" id="v23" data-v="23" data-xref="申命記 29:29; 約伯記 33:13; 但以理書 4:35"> 於是在信徒中間就傳說那個門徒不會死。其實耶穌並沒有說他不會死，只是說：「我如果要他活到我再來，與你有什麼關係？」</span>
<span className="v" id="v24" data-v="24" data-xref="約翰福音 19:35; 約翰福音 15:27; 約翰一書 5:6"> 為這些事作見證、記錄這些事的就是那個門徒，我們都知道他的見證是真實的。</span>
<span className="v" id="v25" data-v="25" data-xref="詩篇 40:5; 約翰福音 20:30–31; 詩篇 71:15"> 耶穌還做了許多其他的事，如果都寫成書，我想整個世界也容納不下。</span>
</div>

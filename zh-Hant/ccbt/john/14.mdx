## 耶穌是道路、真理、生命

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以賽亞書 26:3; 約翰福音 16:22–23; 以賽亞書 12:2–3"> 「你們心裡不要憂愁，你們要信上帝，也要信我。</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多後書 5:1; 約翰福音 13:36; 希伯來書 13:14"> 我父的家裡有許多住處，不然我就不會說去為你們預備地方了。</span>
<span className="v" id="v3" data-v="3" data-xref="帖撒羅尼迦前書 4:16–17; 約翰福音 12:26; 提摩太後書 2:12"> 我預備好了以後，必定回來接你們到我那裡。我在哪裡，讓你們也在哪裡。</span>
<span className="v" id="v4" data-v="4" data-xref="約翰福音 10:9; 約翰福音 16:28; 約翰福音 13:3"> 你們知道哪條路通往我去的地方。」</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="約翰福音 11:16; 馬可福音 9:19; 約翰福音 20:25–28"> 多馬說：「主啊，你要去哪裡，我們還不知道，又怎麼會知道路呢？」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="使徒行傳 4:12; 約翰福音 10:9; 以弗所書 2:18"> 耶穌說：「我就是道路、真理、生命，若不藉著我，沒有人能去父那裡。</span>
<span className="v" id="v7" data-v="7" data-xref="歌羅西書 1:15–17; 約翰福音 8:19; 路加福音 10:22"> 你們若認識我，也會認識我的父。從現在起，你們確實認識祂，並且已經看見祂。」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="出埃及記 33:18–23; 啟示錄 22:3–5; 約翰福音 1:43–46"> 腓力說：「主啊！求你讓我們看看父，我們就心滿意足了。」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="歌羅西書 1:15; 約翰福音 12:45; 約翰福音 14:7"> 耶穌說：「腓力，我和你們相處了這麼久，你還不認識我嗎？人看見了我，就看見了父，你怎麼說『讓我們看看父』呢？</span>
<span className="v" id="v10" data-v="10" data-xref="約翰福音 5:19; 約翰福音 10:38; 約翰福音 10:30"> 難道你不相信我在父裡面，父也在我裡面嗎？我這些話不是憑自己講的，而是住在我裡面的父在做祂自己的工作。</span>
<span className="v" id="v11" data-v="11" data-xref="約翰福音 10:38; 約翰福音 10:25; 約翰福音 5:36"> 你們要相信我，我在父裡面，父也在我裡面。你們即使不信，也該因我所做的而信我。</span>
<span className="v" id="v12" data-v="12" data-xref="馬太福音 21:21; 馬可福音 16:17; 路加福音 10:17–19"> 我實實在在地告訴你們，我所做的事，信我的人也要做，而且要做更大的事，因為我要回到父那裡。</span>
<span className="v" id="v13" data-v="13" data-xref="約翰福音 15:7; 馬可福音 11:24; 馬太福音 7:7"> 你們奉我的名無論求什麼，我必應允，好讓父在子身上得榮耀。</span>
<span className="v" id="v14" data-v="14"> 你們若奉我的名向我求什麼，我必應允。</span>
</div>
</div>

## 應許賜下聖靈

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="約翰一書 2:3–5; 約翰一書 5:2–3; 約翰福音 14:21–24"> 「你們若愛我，就必遵守我的命令。</span>
<span className="v" id="v16" data-v="16" data-xref="約翰福音 14:26; 約翰福音 15:26; 約翰福音 16:7–15"> 我會求父另外賜一位護慰者給你們，祂要永遠和你們同在。</span>
<span className="v" id="v17" data-v="17" data-xref="以西結書 36:27; 約翰福音 16:13; 約翰一書 2:27"> 祂是真理的靈，世人不能接受祂，因為他們看不見祂，也不認識祂。但你們認識祂，因祂常與你們同在，並且要住在你們裡面。</span>
<span className="v" id="v18" data-v="18" data-xref="約翰福音 14:3; 詩篇 23:4; 馬太福音 18:20"> 我不會撇下你們為孤兒，我必到你們這裡來。</span>
<span className="v" id="v19" data-v="19" data-xref="約翰福音 16:16; 約翰福音 7:33; 希伯來書 7:25"> 不久，世人就看不見我了，而你們卻能看見我，因為我活著，你們也要活著。</span>
<span className="v" id="v20" data-v="20" data-xref="約翰福音 15:5–7; 加拉太書 2:20; 約翰福音 17:21–23"> 到了那一天，你們就知道我在父裡面，你們在我裡面，我也在你們裡面。</span>
<span className="v" id="v21" data-v="21" data-xref="約翰福音 14:15; 約翰一書 5:3; 約翰一書 2:5"> 接受我的命令又遵行的，就是愛我的人。愛我的，我父必定愛他，我也要愛他，並且要親自向他顯現。」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="使徒行傳 1:13; 路加福音 6:16; 馬太福音 10:3"> 猶大（不是加略人猶大）問耶穌：「主啊，你為什麼只向我們顯現而不向世人顯現呢？」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="約翰福音 14:21; 約翰福音 14:15; 啟示錄 3:20–21"> 耶穌回答說：「愛我的人必遵行我的道，我父也必愛他，並且我們要到他那裡與他同住。</span>
<span className="v" id="v24" data-v="24" data-xref="約翰福音 7:16; 約翰福音 14:10; 約翰福音 8:42"> 不愛我的人不會遵行我的道。你們所聽見的道不是出於我自己，而是出於差我來的父。</span>
<span className="v" id="v25" data-v="25" data-xref="約翰福音 17:6–8; 約翰福音 13:19; 約翰福音 16:12"> 我趁著與你們在一起，將這些事情都告訴了你們。</span>
<span className="v" id="v26" data-v="26" data-xref="約翰福音 15:26; 約翰福音 14:16; 約翰一書 2:27"> 但護慰者，就是父為我的名而差來的聖靈，將教導你們一切的事，並使你們想起我對你們說的一切話。</span>
<span className="v" id="v27" data-v="27" data-xref="腓立比書 4:7; 約翰福音 16:33; 以賽亞書 41:10"> 我把平安留給你們，把我的平安賜給你們，我賜給你們的平安不像世人給的平安。你們心裡不要憂愁，也不要害怕。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="約翰福音 10:29–30; 哥林多前書 15:24–28; 哥林多前書 11:3"> 「我對你們說過，我去了還要再回到你們這裡。你們如果真的愛我，就會為我去父那裡而歡喜快樂，因為父比我大。</span>
<span className="v" id="v29" data-v="29" data-xref="約翰福音 13:19; 約翰福音 16:4–31; 馬太福音 24:24–25"> 現在事情還沒有發生，我便先告訴你們，到了事情發生的時候，你們就會相信。</span>
<span className="v" id="v30" data-v="30" data-xref="約翰一書 5:19; 約翰一書 4:4; 啟示錄 12:9"> 我不再跟你們多談，因為世界的王快要來了。他根本沒有力量勝過我，</span>
<span className="v" id="v31" data-v="31" data-xref="約翰福音 10:18; 腓立比書 2:8; 約翰福音 12:49"> 但為了讓世人知道我愛父，父怎麼吩咐我，我就怎麼做。起來，我們走吧！」</span>
</div>
</div>

</div>

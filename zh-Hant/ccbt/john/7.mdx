## 耶穌的弟弟不信祂

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="約翰福音 5:16–18; 約翰福音 4:3; 馬太福音 21:38"> 之後，耶穌周遊加利利，不願去猶太地區，因為猶太人想要殺祂。</span>
<span className="v" id="v2" data-v="2" data-xref="撒迦利亞書 14:16–19; 申命記 16:13–16; 出埃及記 23:16–17"> 猶太人的住棚節快到了，</span>
<span className="v" id="v3" data-v="3" data-xref="馬太福音 12:46; 約翰福音 7:5; 路加福音 8:19"> 耶穌的弟弟們對祂說：「離開這裡，去猶太過節吧，好讓你的門徒在那裡也看見你所做的啊！</span>
<span className="v" id="v4" data-v="4" data-xref="約翰福音 18:20; 箴言 18:1–2; 馬太福音 23:5"> 因為人想出名，都不會暗地裡行事，你既然可以做這些事，就把自己顯給世人看吧！」</span>
<span className="v" id="v5" data-v="5" data-xref="馬可福音 3:21; 約翰福音 1:11–13; 彌迦書 7:5–6"> 原來連祂的弟弟們也不信祂。</span>
<span className="v" id="v6" data-v="6" data-xref="約翰福音 7:8; 約翰福音 2:4; 約翰福音 7:30"> 耶穌對他們說：「我的時候還沒有到，你們什麼時候都很方便。</span>
<span className="v" id="v7" data-v="7" data-xref="約翰福音 15:18–19; 約翰福音 3:19; 加拉太書 4:16"> 世人不會恨你們，只會恨我，因為我指證他們行為邪惡。</span>
<span className="v" id="v8" data-v="8" data-xref="約翰福音 7:6; 約翰福音 8:20; 約翰福音 7:30"> 你們先去過節吧，我現在還不上去，因為我的時候還沒有到。」</span>
<span className="v" id="v9" data-v="9"> 耶穌說完這些話，仍留在加利利。</span>
</div>
</div>

## 耶穌過住棚節

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="阿摩司書 5:13; 馬太福音 10:16; 以賽亞書 42:2–3"> 他們走了以後，耶穌避開了人們的注意，暗地裡上去過節。</span>
<span className="v" id="v11" data-v="11" data-xref="約翰福音 11:56"> 猶太人在節期查問：「祂在哪裡？」</span>
<span className="v" id="v12" data-v="12" data-xref="約翰福音 7:40–43; 約翰福音 9:16; 約翰福音 7:32"> 眾人對祂議論紛紛，有些人說：「祂是好人。」有些說：「不，祂欺騙民眾。」</span>
<span className="v" id="v13" data-v="13" data-xref="約翰福音 9:22; 約翰福音 19:38; 約翰福音 20:19"> 不過，沒有人敢公開議論祂的事，因為害怕猶太人。</span>
<span className="v" id="v14" data-v="14" data-xref="約翰福音 7:28; 路加福音 19:47; 約翰福音 7:37"> 節期約過了一半，耶穌來到聖殿教導人。</span>
<span className="v" id="v15" data-v="15" data-xref="路加福音 4:22; 馬太福音 7:28–29; 馬太福音 13:54"> 猶太人感到驚奇，說：「這個人沒上過學，怎麼懂得這麼多呢？」</span>
<span className="v" id="v16" data-v="16" data-xref="約翰福音 14:10; 約翰福音 14:24; 約翰福音 17:8"> 耶穌說：「我的教導不是出於我自己，而是出於差我來的那位。</span>
<span className="v" id="v17" data-v="17" data-xref="約翰福音 8:31–32; 約翰福音 8:43; 耶利米書 31:33–34"> 人若願意遵行上帝的旨意，就能分辨這些教導是出於上帝，還是出於我自己。</span>
<span className="v" id="v18" data-v="18" data-xref="約翰福音 5:41; 哥林多前書 10:31–33; 約翰福音 13:31–32"> 憑自己講論的人是要尋求自己的榮耀，但有一位只尋求差祂來者的榮耀，祂真實無偽，毫無不義。</span>
<span className="v" id="v19" data-v="19" data-xref="約翰福音 1:17; 約翰福音 11:53; 馬太福音 12:14"> 摩西不是把律法傳給了你們嗎？你們卻沒有一個人遵守。為什麼想要殺我呢？」</span>
<span className="v" id="v20" data-v="20" data-xref="約翰福音 10:20; 約翰福音 8:48; 約翰福音 8:52"> 眾人回答說：「你一定是被鬼附身了！誰要殺你啊？」</span>
<span className="v" id="v21" data-v="21" data-xref="約翰福音 7:23; 約翰福音 5:2–11"> 耶穌說：「我行了一件神蹟，你們都感到驚奇。</span>
<span className="v" id="v22" data-v="22" data-xref="利未記 12:3; 創世記 17:10–14; 羅馬書 4:9–11"> 摩西把割禮傳給你們，你們也在安息日行割禮。其實割禮不是摩西定的，而是從祖先們的時代就有了。</span>
<span className="v" id="v23" data-v="23" data-xref="馬太福音 12:5; 約翰福音 5:14–16; 馬太福音 12:2"> 為了不違背摩西的律法，行割禮的那一天就算是安息日，你們還是照行割禮。那麼，我在安息日使一個病人完全康復，你們為什麼向我發怒呢？</span>
<span className="v" id="v24" data-v="24" data-xref="以賽亞書 11:3–4; 雅各書 2:9; 約翰福音 8:15"> 不要根據外表來斷定是非，要按公義的原則判斷。」</span>
</div>
</div>

## 耶穌是基督嗎

<div className="bt">
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="約翰福音 7:10–11"> 有些住在耶路撒冷的人說：「這不是他們要殺的那個人嗎？</span>
<span className="v" id="v26" data-v="26" data-xref="提摩太後書 1:7–8; 約翰福音 7:48; 約翰福音 12:42"> 你看祂這樣公開講道，居然沒有人說什麼，難道官長也真的認定祂是基督嗎？</span>
<span className="v" id="v27" data-v="27" data-xref="彌迦書 5:2; 約翰福音 7:41–42; 約翰福音 6:42"> 可是我們知道這人從哪裡來。基督來的時候，沒有人知道祂從哪裡來。」</span>
<span className="v" id="v28" data-v="28" data-xref="約翰福音 8:42; 約翰福音 8:19; 約翰福音 8:26"> 於是，耶穌在聖殿裡高聲教導人說：「你們認識我，也知道我從哪裡來。其實我來不是出於自己的意思，差我來的那位是真實的，你們不認識祂。</span>
<span className="v" id="v29" data-v="29" data-xref="約翰福音 8:55; 馬太福音 11:27; 約翰福音 17:18"> 但我認識祂，因為我是從祂那裡來的，差我來的就是祂。」</span>
<span className="v" id="v30" data-v="30" data-xref="約翰福音 8:20; 約翰福音 10:39; 約翰福音 7:6"> 他們想捉拿耶穌，只是沒有人下手，因為祂的時候還沒有到。</span>
<span className="v" id="v31" data-v="31" data-xref="約翰福音 12:42; 馬太福音 12:23; 約翰福音 10:41–42"> 有許多人信了耶穌，他們說：「基督來的時候所行的神蹟，難道會比這個人行的更多嗎？」</span>
<span className="v" id="v32" data-v="32" data-xref="約翰福音 18:3; 路加福音 22:52–53; 約翰福音 11:47–48"> 法利賽人聽見眾人這樣議論耶穌，就聯合祭司長派差役去抓祂。</span>
<span className="v" id="v33" data-v="33" data-xref="約翰福音 16:5; 約翰福音 13:33; 馬可福音 16:19"> 耶穌對眾人說：「我暫時還會跟你們在一起，不久我要回到差我來的那位那裡。</span>
<span className="v" id="v34" data-v="34" data-xref="箴言 1:24–31; 約翰福音 13:33–36; 約翰福音 14:6"> 那時你們要尋找我卻找不到，你們也不能去我所在的地方。」</span>
<span className="v" id="v35" data-v="35" data-xref="雅各書 1:1; 以賽亞書 11:12; 西番雅書 3:10"> 猶太人彼此議論說：「祂要去哪裡，使我們找不著呢？難道祂要到我們猶太人僑居的希臘各地去教導希臘人嗎？</span>
<span className="v" id="v36" data-v="36" data-xref="約翰福音 3:9; 約翰福音 7:34; 約翰福音 12:34"> 祂說我們找不到祂，又不能去祂所在的地方，是什麼意思？」</span>
</div>
</div>

## 活水的江河

<div className="bt">
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="以賽亞書 55:1; 約翰福音 4:14; 約翰福音 6:35"> 節期最後一天，也是整個節期的高潮，耶穌站起來高聲說：「人若渴了，可以到我這裡來喝。</span>
<span className="v" id="v38" data-v="38" data-xref="約翰福音 4:14; 以賽亞書 44:3; 以賽亞書 58:11"> 信我的人正如聖經所言，『從他裡面要流出活水的江河來。』」</span>
<span className="v" id="v39" data-v="39" data-xref="使徒行傳 2:17; 約珥書 2:28; 約翰福音 14:16–17"> 耶穌這話是指信祂的人要領受聖靈，但當時聖靈還沒有降臨，因為耶穌還沒有得到榮耀。</span>
<span className="v" id="v40" data-v="40" data-xref="馬太福音 21:11; 約翰福音 1:21; 約翰福音 6:14"> 聽見這些話後，有些人說：「祂真是那位先知。」</span>
<span className="v" id="v41" data-v="41" data-xref="約翰福音 7:52; 約翰福音 1:46; 約翰福音 1:49"> 也有些人說：「祂是基督。」還有些人說：「不會吧，基督怎麼會出自加利利呢？</span>
<span className="v" id="v42" data-v="42" data-xref="彌迦書 5:2; 馬太福音 2:5; 路加福音 2:4"> 聖經上不是說基督是大衛的後裔，要降生在大衛的故鄉伯利恆嗎？」</span>
<span className="v" id="v43" data-v="43" data-xref="約翰福音 9:16; 約翰福音 10:19; 約翰福音 7:12"> 眾人因為對耶穌的看法不同，就起了紛爭。</span>
<span className="v" id="v44" data-v="44" data-xref="約翰福音 7:30; 使徒行傳 23:11; 約翰福音 8:20"> 有些人想抓祂，只是沒有人下手。</span>
</div>
</div>

## 猶太官長不信耶穌

<div className="bt">
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="約翰福音 7:32; 使徒行傳 5:21–27"> 祭司長和法利賽人看見差役空手回來，就問：「你們為什麼不把祂帶來呢？」</span>
<span className="v" id="v46" data-v="46" data-xref="馬太福音 7:28–29; 路加福音 4:22; 約翰福音 7:26"> 差役答道：「從未有人像祂那樣說話！」</span>
<span className="v" id="v47" data-v="47" data-xref="約翰福音 7:12; 哥林多後書 6:8; 列王紀下 18:32"> 法利賽人說：「難道你們也被祂迷惑了嗎？</span>
<span className="v" id="v48" data-v="48" data-xref="約翰福音 12:42; 哥林多前書 1:20; 哥林多前書 2:8"> 哪有官長和法利賽人信祂呢？</span>
<span className="v" id="v49" data-v="49" data-xref="哥林多前書 1:20–21; 約翰福音 9:40; 約翰福音 9:34"> 這群不懂律法的人該受咒詛！」</span>
<span className="v" id="v50" data-v="50" data-xref="約翰福音 19:39; 約翰福音 3:1–2"> 曾經夜訪耶穌、屬於他們當中一員的尼哥德慕說：</span>
<span className="v" id="v51" data-v="51" data-xref="箴言 18:13; 申命記 1:17; 申命記 19:15–19"> 「難道不先聽被告申辯並查明真相，我們的律法就定他的罪嗎？」</span>
<span className="v" id="v52" data-v="52" data-xref="約翰福音 7:41; 約翰福音 1:46; 以賽亞書 9:1–2"> 他們回答說：「難道你也是加利利人嗎？你去查查看，就會知道沒有先知是從加利利來的。」</span>
<span className="v" id="v53" data-v="53" data-xref="詩篇 33:10; 約伯記 5:12–13; 詩篇 76:10"> 眾人都回家去了。</span>

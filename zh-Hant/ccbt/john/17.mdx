## 耶穌的禱告

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="約翰福音 13:31–32; 約翰福音 17:4–5; 腓立比書 2:9–11"> 耶穌說完後，就舉目望著天說：「父啊！時候到了，願你使你的兒子得榮耀，好讓你的兒子也使你得榮耀。</span>
<span className="v" id="v2" data-v="2" data-xref="約翰福音 10:28–29; 約翰福音 6:39; 但以理書 7:14"> 因為你把管理世人的權柄賜給了祂，使祂可以將永生賜予你賜給祂的人。</span>
<span className="v" id="v3" data-v="3" data-xref="約翰一書 5:20; 約翰一書 5:11–12; 耶利米書 9:23–24"> 這永生就是，認識你獨一的真神，並且認識你差來的耶穌基督。</span>
<span className="v" id="v4" data-v="4" data-xref="約翰福音 4:34; 使徒行傳 20:24; 提摩太後書 4:7"> 我已經完成你交給我的工作，使你在地上得了榮耀。</span>
<span className="v" id="v5" data-v="5" data-xref="約翰福音 1:1–3; 歌羅西書 1:15–17; 約翰福音 10:30"> 父啊，現在讓我和你同享創世以前我們共有的榮耀吧！</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="約翰福音 17:26; 約翰福音 14:21–24; 約翰一書 5:20"> 「你從世上賜給我的人，我已將你的名顯明給他們。他們本來屬於你，你將他們賜給了我，他們遵守了你的道。</span>
<span className="v" id="v7" data-v="7" data-xref="約翰福音 7:16–17; 約翰福音 16:15; 約翰福音 14:7–10"> 如今他們知道，我所領受的一切都是從你而來的，</span>
<span className="v" id="v8" data-v="8" data-xref="約翰福音 17:14; 約翰福音 15:15; 約翰福音 16:30"> 因為我已經把你賜給我的道賜給他們，他們也接受了，並且確實知道我是從你那裡來的，也相信是你差遣了我。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="希伯來書 9:24; 約翰福音 17:2; 約翰福音 17:6"> 「我不為世人祈求，卻為他們祈求，就是為你賜給我的那些人祈求，因為他們屬於你。</span>
<span className="v" id="v10" data-v="10" data-xref="約翰福音 10:30; 彼得前書 2:9; 啟示錄 5:8–14"> 凡屬於我的都是你的，凡屬於你的也都是我的，並且我從他們身上得了榮耀。</span>
<span className="v" id="v11" data-v="11" data-xref="馬太福音 6:9; 箴言 18:10; 約翰福音 17:12–18"> 現在我要離開這個世界去你那裡了，他們卻仍然留在世上。聖父啊，求你為了自己的名，就是你賜給我的名而保守他們，使他們像我們一樣合而為一。</span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 109:6–19; 約翰福音 10:27–28; 約翰福音 18:9"> 我和他們在一起的時候，靠著你賜給我的名保守他們，護衛他們。除了那個注定滅亡的人以外，他們一個也沒有滅亡，這是為了應驗聖經上的話。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="希伯來書 12:2; 加拉太書 5:22; 約翰福音 15:11"> 「現在我要去你那裡了，我在世上這樣說，是要叫他們心裡充滿我的喜樂。</span>
<span className="v" id="v14" data-v="14" data-xref="約翰福音 17:16; 約翰福音 15:18–21; 約翰一書 5:19–20"> 我已將你的道賜給他們，世人恨他們，因為他們像我一樣不屬於這個世界。</span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 121:7; 約翰一書 5:18; 馬太福音 6:13"> 我不求你帶他們離開這個世界，但求你保守他們脫離那惡者。</span>
<span className="v" id="v16" data-v="16" data-xref="約翰福音 17:14"> 因為他們像我一樣不屬於這個世界。</span>
<span className="v" id="v17" data-v="17" data-xref="約翰福音 15:3; 詩篇 119:160; 以弗所書 5:26"> 求你用真理使他們聖潔。你的道就是真理。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多後書 5:20; 約翰福音 20:21; 約翰福音 17:3"> 你怎樣差我到世上來，我也照樣差他們到世人中間。</span>
<span className="v" id="v19" data-v="19" data-xref="提多書 2:14; 希伯來書 2:11; 約翰福音 17:17"> 為了他們，我獻上自己，使他們藉著真理可以聖潔。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="約翰福音 17:6–11; 使徒行傳 2:41; 使徒行傳 4:4"> 「我不但為這些人祈求，也為那些因他們的話而信我的人祈求，</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多前書 12:12; 歌羅西書 3:11–14; 約翰福音 17:11"> 使他們都合而為一，正如父你在我裡面，我在你裡面一樣，使他們也在我們裡面，好讓世人相信是你差我來的。</span>
<span className="v" id="v22" data-v="22" data-xref="哥林多後書 3:18; 約翰福音 14:20; 馬可福音 16:17–20"> 我又將你賜給我的榮耀賜給他們，使他們像我們一樣合而為一。</span>
<span className="v" id="v23" data-v="23" data-xref="約翰福音 17:21; 約翰福音 16:27; 約翰一書 3:1"> 我在他們裡面，你在我裡面，使他們完完全全地合而為一。這樣，世人便知道我是你差來的，而且知道你像愛我一樣愛他們。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="約翰福音 17:5; 約翰福音 12:26; 約翰福音 14:3"> 「父啊！我在哪裡，願你賜給我的人也在哪裡，好讓他們看見你賜給我的榮耀，因為在創世以前你已經愛我了。</span>
<span className="v" id="v25" data-v="25" data-xref="約翰福音 17:11; 約翰福音 7:29; 約翰福音 17:8"> 公義的父啊！儘管世人不認識你，但我認識你，這些人也知道是你差我來的。</span>
<span className="v" id="v26" data-v="26" data-xref="約翰福音 17:23; 約翰福音 17:6; 約翰福音 15:9"> 我使他們認識了你的名，我還要使他們更認識你的名，好讓你對我的愛存在他們裡面，我也在他們裡面。」</span>
</div>
</div>

## 呼籲公義和憐憫

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="尼希米記 1:1; 以斯拉記 6:14–15; 撒迦利亞書 1:1"> 大流士王執政第四年九月，即基斯流月四日，耶和華的話傳給了撒迦利亞。</span>
<span className="v" id="v2" data-v="2" data-xref="撒迦利亞書 8:21; 耶利米書 26:19; 撒母耳記上 13:12"> 那時，伯特利人差遣沙利色、利堅米勒及其隨從去向耶和華求恩。</span>
<span className="v" id="v3" data-v="3" data-xref="撒迦利亞書 8:19; 雅各書 4:8–10; 瑪拉基書 2:7"> 他們問萬軍之耶和華殿裡的祭司和先知：「我們還要照多年的慣例在五月哀傷、禁食嗎？」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="以賽亞書 10:16"> 萬軍之耶和華對我說：</span>
<span className="v" id="v5" data-v="5" data-xref="撒迦利亞書 1:12; 以賽亞書 58:4–6; 哥林多前書 10:31"> 「你要對境內的民眾和祭司說，『這七十年來，你們在五月和七月禁食、哀傷，難道真的是為了我嗎？</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多前書 11:20–21; 哥林多前書 11:26–29; 何西阿書 8:13"> 你們吃喝，難道不是為自己吃、為自己喝嗎？</span>
<span className="v" id="v7" data-v="7" data-xref="以賽亞書 1:16–20; 耶利米書 17:26; 耶利米書 7:5"> 這些豈不是耶和華藉從前的先知所宣告的嗎？當時耶路撒冷和周圍的城邑人口興盛、繁榮，南地和丘陵都有人居住。』」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8"> 耶和華又對撒迦利亞說：</span>
<span className="v" id="v9" data-v="9" data-xref="彌迦書 6:8; 詩篇 82:2–4; 箴言 21:3"> 「萬軍之耶和華曾對你們的祖先說，『要秉公行義，彼此以慈愛和憐憫相待。</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米書 5:28; 以賽亞書 1:23; 雅各書 5:4"> 不可欺壓寡婦、孤兒、寄居者和窮人，不可設陰謀彼此相害。』</span>
<span className="v" id="v11" data-v="11" data-xref="尼希米記 9:29; 耶利米書 8:5; 何西阿書 4:16"> 他們卻不理會，頑梗地背過身去，充耳不聞，</span>
<span className="v" id="v12" data-v="12" data-xref="以西結書 11:19; 尼希米記 9:29–30; 歷代志下 36:16"> 心如鐵石，不遵從律法，也不遵從萬軍之耶和華藉著祂的靈指示從前的先知所說的話。因此，萬軍之耶和華非常憤怒。</span>
<span className="v" id="v13" data-v="13" data-xref="箴言 1:24–28; 耶利米書 14:12; 以賽亞書 1:15"> 祂說，『我曾呼喚他們，他們不聽；將來他們呼求我，我也不聽。</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 28:33; 申命記 28:64; 耶利米書 23:19"> 我要用旋風把他們吹散到陌生的萬國中，使他們的土地荒涼、杳無人跡，因為他們使美好的土地一片荒涼。』」</span>
</div>

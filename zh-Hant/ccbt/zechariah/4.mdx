## 金燈臺和橄欖樹

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="耶利米書 31:26; 但以理書 8:18; 撒迦利亞書 1:9"> 那位與我說話的天使又來喚醒我，像喚醒睡覺的人一樣。</span>
<span className="v" id="v2" data-v="2" data-xref="啟示錄 4:5; 啟示錄 1:12; 馬太福音 5:14–16"> 他問我：「你看見了什麼？」 我說：「我看見一個純金的燈臺，燈台頂端有一個油碗，燈臺上有七盞燈，每盞燈有七個燈芯。</span>
<span className="v" id="v3" data-v="3" data-xref="啟示錄 11:4; 撒迦利亞書 4:14; 羅馬書 11:17"> 燈臺旁邊有兩棵橄欖樹，左右各一棵。」</span>
<span className="v" id="v4" data-v="4" data-xref="撒迦利亞書 6:4; 撒迦利亞書 1:9; 撒迦利亞書 1:19"> 我問與我說話的天使：「主啊，這是什麼意思？」</span>
<span className="v" id="v5" data-v="5" data-xref="撒迦利亞書 4:13; 撒迦利亞書 1:9; 但以理書 2:30"> 他說：「你不知道嗎？」我說：「主啊，我不知道。」</span>
<span className="v" id="v6" data-v="6" data-xref="歷代志下 32:7–8; 哥林多後書 10:4–5; 哥林多前書 2:4–5"> 他對我說：「這是耶和華對所羅巴伯講的話。萬軍之耶和華說，『不靠權勢，不靠才能，乃靠我的靈。</span>
<span className="v" id="v7" data-v="7" data-xref="耶利米書 51:25; 撒迦利亞書 4:9; 彌迦書 4:1"> 大山啊，你算什麼？你必在所羅巴伯面前化為平地。他必搬出那塊封殿頂的石頭，伴隨著歡呼聲：願恩典、恩典歸於這殿！』」</span>
<span className="v" id="v8" data-v="8"> 耶和華對我說：</span>
<span className="v" id="v9" data-v="9" data-xref="以斯拉記 6:14–15; 撒迦利亞書 6:12–13; 撒迦利亞書 6:15"> 「所羅巴伯的手已經奠立這殿的根基，他的手也必完成這項工程。那時你便知道，是萬軍之耶和華差遣我到你們這裡來的。</span>
<span className="v" id="v10" data-v="10" data-xref="約伯記 8:7; 哥林多前書 1:28–29; 歷代志下 16:9"> 誰敢藐視這微不足道的日子？他們看見所羅巴伯手中拿著線錘時，就必歡喜。這七盞燈是耶和華遍察天下的眼睛。」</span>
<span className="v" id="v11" data-v="11" data-xref="撒迦利亞書 4:3; 啟示錄 11:4"> 我又問天使：「燈臺左右的兩棵橄欖樹是什麼意思？」</span>
<span className="v" id="v12" data-v="12" data-xref="啟示錄 11:4; 馬太福音 20:23; 哈該書 1:1"> 然後我又問道：「流出金色橄欖油的兩個金管旁邊的兩根橄欖枝是什麼意思？」</span>
<span className="v" id="v13" data-v="13" data-xref="撒迦利亞書 4:5; 希伯來書 5:11–12"> 他說：「你不知道嗎？」我說：「主啊，我不知道。」</span>
<span className="v" id="v14" data-v="14" data-xref="啟示錄 11:4; 以賽亞書 61:1–3; 但以理書 9:24–26"> 他說：「這是侍立在天下之主旁邊的兩位受膏者。」</span>

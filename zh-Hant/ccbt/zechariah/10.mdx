## 耶和華應許拯救以色列

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="雅各書 5:16–18; 馬太福音 7:7–8; 以賽亞書 44:3"> <span className="pl pl-1">要在春季向耶和華求雨。</span><br /><span className="pl pl-1">祂造出雷雨，</span><br /><span className="pl pl-1">為世人降下甘霖，</span><br /><span className="pl pl-1">賜人田間的菜蔬。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="馬太福音 9:36; 耶利米書 27:9; 以西結書 34:5"> <span className="pl pl-1">因為神像說的是虛言，</span><br /><span className="pl pl-1">占卜者講的是謊話，</span><br /><span className="pl pl-1">他們訴說的是假夢，</span><br /><span className="pl pl-1">他們的安慰是空話。</span><br /><span className="pl pl-1">所以人們如迷失的羊，</span><br /><span className="pl pl-1">因無牧人而遭受困苦。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v3" data-v="3" data-xref="以西結書 34:2; 以西結書 34:7–10; 耶利米書 23:1–2"> <span className="pl pl-1">「我必向牧人發怒，</span><br /><span className="pl pl-1">我必懲罰這些首領</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「首領」希伯來文作「公山羊」。">a</a></sup><br /><span className="pl pl-1">。</span><br /><span className="pl pl-1">因為萬軍之耶和華必眷顧祂的羊群猶大家，</span><br /><span className="pl pl-1">使他們像戰場上的駿馬。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="撒迦利亞書 9:10; 撒迦利亞書 9:8; 民數記 24:17"> <span className="pl pl-1">房角石、橛子、戰弓，</span><br /><span className="pl pl-1">以及所有掌權者必出自猶大。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="哈該書 2:22; 撒迦利亞書 9:13; 詩篇 20:7"> <span className="pl pl-1">他們必如戰場上的勇士，</span><br /><span className="pl pl-1">將仇敵踐踏在街上的泥土中。</span><br /><span className="pl pl-1">他們必爭戰，</span><br /><span className="pl pl-1">因為耶和華與他們同在。</span><br /><span className="pl pl-1">他們必使敵方的騎兵蒙羞。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="撒迦利亞書 13:9; 撒迦利亞書 10:12; 耶利米書 3:18"> <span className="pl pl-1">「我必使猶大家強盛，</span><br /><span className="pl pl-1">我必拯救約瑟家。</span><br /><span className="pl pl-1">我必帶他們回到故土，</span><br /><span className="pl pl-1">因為我憐憫他們。</span><br /><span className="pl pl-1">他們必好像從未被我拋棄一樣，</span><br /><span className="pl pl-1">因為我是他們的上帝耶和華，</span><br /><span className="pl pl-1">我必應允他們的禱告。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="撒迦利亞書 9:15; 撒迦利亞書 9:17; 撒母耳記上 2:1"> <span className="pl pl-1">以法蓮人必如勇士，</span><br /><span className="pl pl-1">他們必心裡暢快，如同喝了酒，</span><br /><span className="pl pl-1">他們的兒女見狀也必喜樂，</span><br /><span className="pl pl-1">他們必因耶和華而歡欣。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="以賽亞書 5:26; 以賽亞書 7:18; 耶利米書 33:22"> <span className="pl pl-1">「我必吹哨聚集他們，</span><br /><span className="pl pl-1">因為我救贖了他們，</span><br /><span className="pl pl-1">他們必像從前一樣人數眾多。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="以西結書 6:9; 何西阿書 2:23; 以斯帖記 8:17"> <span className="pl pl-1">雖然我把他們分散到列國，</span><br /><span className="pl pl-1">他們必在遠方想起我，</span><br /><span className="pl pl-1">他們及其子女必得以倖存，</span><br /><span className="pl pl-1">並且回到故土。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="何西阿書 11:11; 彌迦書 7:14; 撒迦利亞書 8:7"> <span className="pl pl-1">我必從埃及領他們歸回，</span><br /><span className="pl pl-1">從亞述招聚他們，</span><br /><span className="pl pl-1">領他們到基列和黎巴嫩，</span><br /><span className="pl pl-1">那裡將不夠他們居住。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="以西結書 30:13; 彌迦書 5:5–6; 以賽亞書 43:2"> <span className="pl pl-1">祂必經過苦海，</span><br /><span className="pl pl-1">擊打海浪，</span><br /><span className="pl pl-1">尼羅河必乾涸，</span><br /><span className="pl pl-1">亞述的驕傲必掃地，</span><br /><span className="pl pl-1">埃及的勢力必滅沒。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="以賽亞書 41:10; 以賽亞書 2:5; 撒迦利亞書 10:6"> <span className="pl pl-1">我必讓他們靠耶和華而強盛，</span><br /><span className="pl pl-1">他們必奉祂的名行事。</span><br /><span className="pl pl-1">這是耶和華說的。」</span></span>
</div>

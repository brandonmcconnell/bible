## 耶和華的日子

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以賽亞書 13:9; 以賽亞書 2:12; 以賽亞書 13:6"> 看啊，耶和華的日子快到了，那時你那裡的財物必被搶掠和瓜分。</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 21:20–24; 以賽亞書 13:16; 羅馬書 9:27–29"> 因為我必招聚萬國去攻打耶路撒冷。那時，城必失守，房屋必被洗劫，婦女必被玷污。半城的人必被擄去，剩下的人必不會從城中被剷除。</span>
<span className="v" id="v3" data-v="3" data-xref="撒迦利亞書 12:9; 西番雅書 3:19; 撒迦利亞書 2:8–9"> 那時，耶和華必出來與萬國爭戰，像從前爭戰的日子一樣。</span>
<span className="v" id="v4" data-v="4" data-xref="彌迦書 1:3–4; 以西結書 11:23; 使徒行傳 1:11–12"> 到那天，祂的腳必踏在耶路撒冷東面的橄欖山上，這山必從東至西分成兩半，一半向北移，一半向南移，中間形成極大的山谷。</span>
<span className="v" id="v5" data-v="5" data-xref="猶大書 1:14–15; 阿摩司書 1:1; 馬太福音 25:31"> 你們要從我的山谷逃跑，因為山谷必延伸到亞薩。你們必逃跑，像猶大王烏西雅年間的人躲避大地震一樣。我的上帝耶和華必帶著所有的聖者降臨。</span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 97:10–11; 詩篇 112:4; 約翰福音 12:46"> 到那天，將沒有光、嚴寒和冰霜。</span>
<span className="v" id="v7" data-v="7" data-xref="啟示錄 22:5; 帖撒羅尼迦前書 5:2; 但以理書 12:4"> 那將是奇特的日子，沒有晝夜之分，晚上仍然有光，只有耶和華知道那日何時來臨。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="啟示錄 22:1–2; 約翰福音 7:38; 約翰福音 4:14"> 到那天，必有活水從耶路撒冷湧出，一半流向死海，一半流向地中海，冬夏不變。</span>
<span className="v" id="v9" data-v="9" data-xref="以弗所書 4:5–6; 啟示錄 11:15; 但以理書 7:27"> 耶和華必做普世的王。到那天，必唯祂獨尊，唯祂的名獨尊。</span>
<span className="v" id="v10" data-v="10" data-xref="撒迦利亞書 12:6; 約書亞記 15:32; 列王紀上 15:22"> 從迦巴直到耶路撒冷南邊的臨門，整個地區都要變為平原。從便雅憫門到舊門，再到角門，從哈楠業樓到王的榨酒池，耶路撒冷必仍然矗立在原處。</span>
<span className="v" id="v11" data-v="11" data-xref="啟示錄 22:3; 耶利米書 23:5–6; 阿摩司書 9:15"> 城內必有人居住，不再遭毀滅的咒詛。耶路撒冷必安享太平。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="以西結書 39:17–20; 以賽亞書 66:15–16; 彌迦書 4:11–13"> 耶和華必降瘟疫給攻打耶路撒冷的萬邦，使他們活著的時候皮肉已經腐爛，眼睛爛在眼眶中，舌頭爛在口中。</span>
<span className="v" id="v13" data-v="13" data-xref="撒迦利亞書 12:4; 啟示錄 17:12–17; 士師記 7:22"> 到那天，耶和華必使他們慌亂不堪，彼此揪住，互相毆打。</span>
<span className="v" id="v14" data-v="14" data-xref="以賽亞書 23:18; 撒迦利亞書 12:2; 歷代志下 20:25–27"> 猶大也必在耶路撒冷爭戰，四圍列國的財物，包括大量的金銀和衣服，必被收聚起來。</span>
<span className="v" id="v15" data-v="15" data-xref="撒迦利亞書 14:12"> 同樣的瘟疫也必降在馬匹、騾子、駱駝、驢和營中的其他牲畜身上。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="撒迦利亞書 14:17–19; 以賽亞書 66:23; 以賽亞書 66:18–21"> 前來攻打耶路撒冷的萬國中的倖存者，必每年上來敬拜大君王萬軍之耶和華，並且守住棚節。</span>
<span className="v" id="v17" data-v="17" data-xref="阿摩司書 4:7–8; 以賽亞書 60:12; 耶利米書 14:4"> 地上萬族中若有人不上耶路撒冷敬拜大君王萬軍之耶和華，他們必得不到雨水。</span>
<span className="v" id="v18" data-v="18" data-xref="撒迦利亞書 14:15; 申命記 11:10–11; 撒迦利亞書 14:12"> 埃及人若不上來敬拜，也必得不到雨水，耶和華必使他們和不上來守住棚節的列國一樣遭受瘟疫。</span>
<span className="v" id="v19" data-v="19" data-xref="約翰福音 3:19"> 這將是埃及和不上來守住棚節的萬國所得的懲罰。</span>
<span className="v" id="v20" data-v="20" data-xref="哥林多前書 3:16–17; 出埃及記 39:30; 利未記 8:9"> 到那天，馬鈴上也必刻上「耶和華的聖物」的字樣。耶和華殿內的鍋必像祭壇前的碗一樣聖潔。</span>
<span className="v" id="v21" data-v="21" data-xref="以西結書 44:9; 羅馬書 14:6–7; 哥林多前書 10:31"> 耶路撒冷和猶大的鍋都是萬軍之耶和華的聖物，來獻祭的人都可以用這些鍋煮祭肉。到那天，萬軍之耶和華的殿中必再也沒有商人。</span>
</div>

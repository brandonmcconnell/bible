## 羊群必遭殺戮

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="耶利米書 22:6–7; 耶利米書 22:23; 路加福音 21:23–24"> 黎巴嫩啊，打開你的門吧，<br /><span className="pl pl-1">好讓火焰吞噬你的香柏樹。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="以賽亞書 2:12–17; 以西結書 31:17; 以賽亞書 10:33–34"> <span className="pl pl-1">松樹啊，哀號吧，</span><br /><span className="pl pl-1">因為香柏樹已經倒下，</span><br /><span className="pl pl-1">挺拔的樹木已被毀壞。</span><br /><span className="pl pl-1">巴珊的橡樹啊，哀號吧，</span><br /><span className="pl pl-1">因為茂密的樹林已被砍倒。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="耶利米書 50:44; 耶利米書 25:34–36; 撒迦利亞書 11:8"> <span className="pl pl-1">聽啊，牧人在哀號，</span><br /><span className="pl pl-1">因為他們肥美的草場已被毀壞。</span><br /><span className="pl pl-1">聽啊，獅子在吼叫，</span><br /><span className="pl pl-1">因為約旦河畔的叢林已被毀壞。</span></span>
<span className="v" id="v4" data-v="4" data-xref="撒迦利亞書 11:7; 馬太福音 23:37; 羅馬書 15:8"> 我的上帝耶和華說：「你去牧養這群待宰的羊。</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米書 50:7; 何西阿書 12:8; 提摩太前書 6:5–10"> 買羊的宰羊卻不受懲罰，賣羊的說，『耶和華當受稱頌！我發財了。』牠們的牧人毫不憐憫牠們。</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米書 13:14; 馬太福音 22:7; 以賽亞書 9:19–21"> 我不再憐憫這地方的居民，我要使他們落在鄰人及其君王手中，任這地方被摧毀，必不從敵人手中拯救他們。這是耶和華說的。」</span>
<span className="v" id="v7" data-v="7" data-xref="撒迦利亞書 11:14; 撒迦利亞書 11:4; 以賽亞書 11:4"> 於是，我牧養這群最困苦的待宰之羊。我拿了兩根杖，一根叫「恩惠」，一根叫「聯合」，開始牧養這群羊。</span>
<span className="v" id="v8" data-v="8" data-xref="以賽亞書 49:7; 馬太福音 23:34–36; 約翰福音 15:18"> 我在一個月之內除掉了三個牧人。 我厭煩羊群，他們也厭惡我。</span>
<span className="v" id="v9" data-v="9" data-xref="耶利米書 43:11; 馬太福音 13:10–11; 馬太福音 21:19"> 於是我說：「我不再牧養你們了。要死的就死吧，要亡的就亡吧，讓剩下的互相吞吃吧。」</span>
<span className="v" id="v10" data-v="10" data-xref="撒迦利亞書 11:7; 詩篇 89:39; 希伯來書 8:8–13"> 然後，我拿起那根叫「恩惠」的杖，把它折斷，以廢除我與萬民所立的約。</span>
<span className="v" id="v11" data-v="11" data-xref="西番雅書 3:12; 路加福音 2:38; 申命記 31:21"> 約就在當天廢除了，那些注視著我的困苦羊便知道這是上帝的話。</span>
<span className="v" id="v12" data-v="12" data-xref="馬太福音 26:15; 出埃及記 21:32; 路加福音 22:3–6"> 我對他們說：「你們若認為好，就給我工錢，不然就算了。」於是，他們給了我三十塊銀子作工錢。</span>
<span className="v" id="v13" data-v="13" data-xref="馬太福音 27:3–10; 使徒行傳 1:18–19; 以賽亞書 53:2–3"> 耶和華對我說：「把這一大筆錢丟給窯戶吧，這就是我在他們眼中的價值！」我便把三十塊銀子丟給聖殿中的窯戶。</span>
<span className="v" id="v14" data-v="14" data-xref="以賽亞書 9:21; 以賽亞書 11:13; 使徒行傳 23:7–10"> 我又把那根叫「聯合」的杖折斷，以斷開猶大和以色列之間的手足之情。</span>
<span className="v" id="v15" data-v="15" data-xref="以賽亞書 6:10–12; 路加福音 11:40; 耶利米書 2:26–27"> 耶和華又對我說：「你再拿起愚昧牧人的器具，</span>
<span className="v" id="v16" data-v="16" data-xref="以西結書 34:2–6; 耶利米書 23:2; 馬太福音 23:2–4"> 因為我要使一位牧人在地上興起，他不照顧喪亡的，不尋找失散的，不醫治受傷的，不牧養健壯的，反而吃肥羊的肉，撕掉牠們的蹄子。</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米書 23:1; 以西結書 13:3; 哥林多前書 8:4"> <span className="pl pl-1">「丟棄羊群的無用牧人有禍了！</span><br /><span className="pl pl-1">願刀砍在他的臂膀和右眼上！</span><br /><span className="pl pl-1">願他的臂膀徹底枯槁，</span><br /><span className="pl pl-1">他的右眼完全失明！」</span></span>

## 對耶路撒冷的應許

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 萬軍之耶和華的話傳給了我，說：</span>
<span className="v" id="v2" data-v="2" data-xref="約珥書 2:18; 撒迦利亞書 1:14–16; 以賽亞書 42:13–14"> 「萬軍之耶和華說，『我篤愛錫安，我為錫安而大發烈怒。</span>
<span className="v" id="v3" data-v="3" data-xref="撒迦利亞書 1:16; 撒迦利亞書 2:10–11; 約翰福音 1:14"> 我要回到錫安，住在耶路撒冷。耶路撒冷必被稱為忠信之城，萬軍之耶和華的山必被稱為聖山。這是耶和華說的。</span>
<span className="v" id="v4" data-v="4" data-xref="以賽亞書 65:20–22; 約伯記 5:26; 耶利米哀歌 5:11–15"> 必再次有年紀老邁、手拿拐杖的男女坐在耶路撒冷的街上。這是萬軍之耶和華說的。</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米書 31:13; 馬太福音 11:16–17; 耶利米書 30:19–20"> 街上必到處都是玩耍的男女孩童。』</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米書 32:27; 羅馬書 4:20–21; 民數記 11:22–23"> 萬軍之耶和華說，『那時，這事在這些餘民看來是稀奇的，但在我看來毫不稀奇。這是萬軍之耶和華說的。』</span>
<span className="v" id="v7" data-v="7" data-xref="耶利米書 31:8; 羅馬書 11:25–27; 瑪拉基書 1:11"> 萬軍之耶和華說，『看啊，我要從日出之地和日落之處救出我的子民，</span>
<span className="v" id="v8" data-v="8" data-xref="以西結書 36:28; 以西結書 11:20; 耶利米書 31:33"> 帶他們回到耶路撒冷居住。本著信實和公義，他們要做我的子民，我要做他們的上帝。』</span>
<span className="v" id="v9" data-v="9" data-xref="以賽亞書 35:4; 歷代志上 22:13; 以斯拉記 5:1–2"> 「萬軍之耶和華說，『在奠立萬軍之耶和華殿的根基那天，眾先知都在場。現今聽見這些先知之言的人啊，你們要剛強，以便建造聖殿！</span>
<span className="v" id="v10" data-v="10" data-xref="哈該書 1:6–11; 哈該書 2:16–18; 阿摩司書 3:6"> 那日之前，人和牲畜都得不到工錢。在敵人的威脅下，人們出入沒有平安。因為我使眾人彼此為敵。</span>
<span className="v" id="v11" data-v="11" data-xref="以賽亞書 12:1; 哈該書 2:19; 撒迦利亞書 8:8–9"> 如今我不會像從前那樣對待這些餘民了。這是萬軍之耶和華說的。</span>
<span className="v" id="v12" data-v="12" data-xref="利未記 26:4–5; 申命記 33:13; 創世記 27:28"> 因為他們必平安地撒種，葡萄樹必結果子，土地必出產五穀，天必降下甘霖，我必把這些福氣賜給這些餘民。</span>
<span className="v" id="v13" data-v="13" data-xref="西番雅書 3:20; 撒迦利亞書 8:9; 詩篇 72:17"> 猶大家和以色列家啊，從前你們在列國中是受咒詛的，現在我要拯救你們，使你們成為蒙福的人。你們不要害怕，要剛強。』</span>
<span className="v" id="v14" data-v="14" data-xref="耶利米書 31:28; 以西結書 24:14; 耶利米書 4:28"> 「萬軍之耶和華說，『從前你們的祖先惹我發怒，我決定毫不留情地降禍給他們。這是萬軍之耶和華說的。</span>
<span className="v" id="v15" data-v="15" data-xref="撒迦利亞書 8:13; 彌迦書 7:18–20; 路加福音 12:32"> 現在我決定賜福給耶路撒冷和猶大家。你們不要害怕。</span>
<span className="v" id="v16" data-v="16" data-xref="以弗所書 4:25; 撒迦利亞書 7:9; 詩篇 15:2"> 你們所當做的是：彼此說真話，在城門口秉公斷案，使人和睦。</span>
<span className="v" id="v17" data-v="17" data-xref="箴言 6:16–19; 彌迦書 2:1–3; 耶利米書 44:4"> 不可設陰謀彼此相害，不可貪愛假誓，因為這些都是我所憎惡的。這是耶和華說的。』」</span>
<span className="v" id="v18" data-v="18"> 萬軍之耶和華的話傳給了我，說：</span>
<span className="v" id="v19" data-v="19" data-xref="撒迦利亞書 8:16; 耶利米書 39:2; 撒迦利亞書 7:5"> 「萬軍之耶和華說，『四月、五月、七月、十月的禁食必成為猶大家歡喜快樂的日子和幸福的節期。因此，你們要喜愛真理與和平。</span>
<span className="v" id="v20" data-v="20" data-xref="以賽亞書 2:2–3; 彌迦書 4:1–2; 撒迦利亞書 2:11"> 各族的人和各城的居民都必來這裡。這是萬軍之耶和華說的。</span>
<span className="v" id="v21" data-v="21" data-xref="撒迦利亞書 7:2; 何西阿書 6:3; 詩篇 146:1–2"> 這一城的居民必到那一城，說，我們快去向耶和華求恩，去尋求萬軍之耶和華吧！我自己也去。</span>
<span className="v" id="v22" data-v="22" data-xref="撒迦利亞書 8:21; 以賽亞書 60:3–22; 啟示錄 21:24"> 許多民族和強國必來耶路撒冷尋求萬軍之耶和華，向耶和華求恩。</span>
<span className="v" id="v23" data-v="23" data-xref="以賽亞書 55:5; 哥林多前書 14:25; 以賽亞書 60:3"> 那時，十個來自列國、講不同語言的人必拉住一個猶大人的衣角，說，讓我們跟你們同去吧，因為我們聽說上帝與你們同在。這是萬軍之耶和華說的。』」</span>

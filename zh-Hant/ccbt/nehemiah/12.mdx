## 聖殿供職的班次

<div className="bt">
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="歷代志上 25:1–26; 尼希米記 11:17; 以斯拉記 3:10–11"> 哈沙比雅、示利比和甲篾的兒子耶書亞是利未人的首領。他們的弟兄站在他們對面，照上帝僕人大衛的吩咐一班一班地讚美、稱頌上帝。</span>

## 尼希米奉獻新城牆

<div className="bt">
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="歷代志上 15:16; 歷代志上 15:28; 歷代志下 29:30"> 在耶路撒冷的城牆典禮之際，民眾把各處的利未人請到耶路撒冷，來稱頌、歌唱、敲鈸、鼓瑟、彈琴，歡慶典禮。</span>
<span className="v" id="v28" data-v="28" data-xref="歷代志上 9:16; 歷代志上 2:54; 尼希米記 6:2"> 歌樂手的子孫從耶路撒冷周圍地區、尼陀法人的村莊、</span>
<span className="v" id="v29" data-v="29" data-xref="約書亞記 10:43; 歷代志上 6:60; 以斯拉記 2:24"> 伯·吉甲，以及迦巴和亞斯瑪弗地區被招聚起來，因為歌樂手已在耶路撒冷周圍為自己建立了村莊。</span>
<span className="v" id="v30" data-v="30" data-xref="約伯記 1:5; 出埃及記 19:10; 歷代志下 29:5"> 祭司和利未人自潔，然後潔淨民眾、城門和城牆。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="尼希米記 2:13; 尼希米記 12:38; 歷代志上 13:1"> 我率猶大的首領上到城牆上，使稱頌的歌樂手分成兩大隊，一隊從城牆上向右前往糞廠門，</span>
<span className="v" id="v32" data-v="32"> 跟在他們後面的有何沙雅和半數的猶大首領，</span>
<span className="v" id="v33" data-v="33" data-xref="尼希米記 10:2–7"> 還有亞撒利雅、以斯拉、米書蘭、</span>
<span className="v" id="v34" data-v="34"> 猶大、便雅憫、示瑪雅和耶利米，</span>
<span className="v" id="v35" data-v="35" data-xref="約書亞記 6:4; 民數記 10:2–10; 歷代志下 5:12"> 還有一些吹號的祭司，包括約拿單的兒子撒迦利亞，約拿單是示瑪雅的兒子，示瑪雅是瑪他尼的兒子，瑪他尼是米該亞的兒子，米該亞是撒刻的兒子，撒刻是亞薩的兒子；</span>
<span className="v" id="v36" data-v="36" data-xref="尼希米記 12:24; 歷代志下 8:14; 歷代志上 23:5"> 還有撒迦利亞的弟兄示瑪雅、亞撒利、米拉萊、基拉萊、瑪艾、拿坦業、猶大、哈拿尼，他們都拿著上帝僕人大衛的樂器。隊伍由律法教師以斯拉帶領。</span>
<span className="v" id="v37" data-v="37" data-xref="尼希米記 3:26; 尼希米記 2:14; 尼希米記 8:3"> 他們經過泉門，沿大衛城的臺階，順城牆的地勢而上，經過大衛的宮殿，走到東面的水門。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="尼希米記 3:8; 尼希米記 3:11; 尼希米記 12:31"> 第二隊稱頌的歌樂手向左走，我和半數的民眾在城牆上跟著他們，經過爐樓一直走到寬牆，</span>
<span className="v" id="v39" data-v="39" data-xref="尼希米記 3:1; 尼希米記 3:3; 尼希米記 8:16"> 然後又經過以法蓮門、古門、魚門、哈楠業樓、哈米亞樓，遠至羊門，之後停在護衛門。</span>
<span className="v" id="v40" data-v="40" data-xref="詩篇 42:4; 詩篇 134:1–3; 尼希米記 12:31–32"> 這兩隊稱頌的歌樂手站在上帝的殿裡，我和半數的首領也站在那裡，</span>
<span className="v" id="v41" data-v="41"> 同時還有吹號的祭司以利亞金、瑪西雅、米拿民、米該亞、以利約乃、撒迦利亞和哈楠尼亞，</span>
<span className="v" id="v42" data-v="42" data-xref="詩篇 81:1; 尼希米記 11:14; 詩篇 100:1–2"> 以及瑪西雅、示瑪雅、以利亞撒、烏西、約哈難、瑪基雅、以攔和以謝。歌樂手在伊斯拉希雅的領導下高聲歌唱。</span>
<span className="v" id="v43" data-v="43" data-xref="以斯拉記 3:13; 詩篇 92:4; 耶利米書 31:13"> 那天，眾人獻上許多祭物，滿心歡喜，因為上帝賜給他們極大的喜樂，連婦孺也都歡喜，耶路撒冷的歡聲遠處可聞。</span>
</div>
</div>

## 預備聖殿的需要

<div className="bt">
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="尼希米記 13:12–13; 尼希米記 10:37–39; 歷代志下 31:11–13"> 那天，有人被委派管理庫房，把舉祭、初熟之物和十一奉獻收集在庫房裡。他們要照律法的規定從各城田地收集祭司和利未人當得的份，因為猶大人對祭司和利未人的供職很滿意。</span>
<span className="v" id="v45" data-v="45" data-xref="歷代志上 25:1–26; 歷代志下 23:6; 歷代志上 23:28"> 祭司和利未人遵行上帝的吩咐，遵守潔淨的禮。歌樂手和殿門守衛也遵照大衛和他兒子所羅門的命令行事。</span>
<span className="v" id="v46" data-v="46" data-xref="歷代志下 29:30; 詩篇 73:1; 歷代志上 25:1–31"> 遠在大衛和亞薩的時代就有歌樂手，並有讚美、稱頌上帝的詩歌。</span>
<span className="v" id="v47" data-v="47" data-xref="民數記 18:21–29; 尼希米記 12:26; 尼希米記 13:10–12"> 在所羅巴伯和尼希米的時代，全體以色列人供應歌樂手和殿門守衛的日常需用，並分出一份給利未人，利未人又分出一份給亞倫的子孫。</span>
</div>

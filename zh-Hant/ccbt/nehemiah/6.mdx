## 敵人陰謀阻撓重建

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="尼希米記 2:19; 尼希米記 2:10; 尼希米記 4:1"> 參巴拉、多比雅、阿拉伯人基善和我們其餘的敵人聽說我已修完城牆，沒有留下任何缺口——那時我還沒有為城門安上門扇——</span>
<span className="v" id="v2" data-v="2" data-xref="詩篇 37:12; 歷代志上 8:12; 尼希米記 11:35"> 參巴拉和基善就派人告訴我說：「來，我們在阿挪平原的一個村莊見面吧。」其實他們想要害我。</span>
<span className="v" id="v3" data-v="3" data-xref="約翰福音 9:4; 馬太福音 10:16; 提摩太前書 4:15–16"> 我派使者回覆他們說：「我正在做一件大工程，不能下去見你們。我怎能停止工作下去見你們呢？」</span>
<span className="v" id="v4" data-v="4" data-xref="士師記 16:15–20; 路加福音 18:5; 加拉太書 2:5"> 他們四次派人來告訴我，每次我都這樣拒絕了。</span>
<span className="v" id="v5" data-v="5" data-xref="以弗所書 6:11; 哥林多後書 2:11; 哥林多後書 11:13–15"> 參巴拉第五次派人送來一封未封口的信，</span>
<span className="v" id="v6" data-v="6" data-xref="尼希米記 2:19; 以斯拉記 4:12; 羅馬書 3:8"> 上面寫著：「各國都在謠傳，基善也說，你和猶太人計劃謀反，因而才修建城牆，據說你要做他們的王。</span>
<span className="v" id="v7" data-v="7" data-xref="箴言 26:24–26; 列王紀上 1:7; 列王紀上 1:18"> 你還派先知在耶路撒冷指著你宣講說，『猶大有王了。』如今王必聽到這些傳聞。所以你還是來與我們一同商議吧。」</span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 52:2; 約伯記 13:4; 馬太福音 12:34"> 我就派人答覆他說：「你所說的並非事實，是你心裡捏造的。」</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 138:3; 彼得前書 5:10; 以弗所書 3:16"> 因為他們想恐嚇我們，以為我們會嚇得手發軟，無法完成工程。但上帝啊，求你使我的手有力量！</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米書 36:5; 馬太福音 7:15; 詩篇 37:12"> 我到米希達別的孫子、第來雅的兒子示瑪雅的家中，那時他正閉門不出。他對我說：「我們在上帝的殿裡會面，要關上殿門，因為他們要來殺你，要在夜間殺你。」</span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 11:1–2; 使徒行傳 21:13; 箴言 28:1"> 但我回答說：「像我這樣的人豈能逃跑？豈能進入殿裡保命？我決不進去。」</span>
<span className="v" id="v12" data-v="12" data-xref="以西結書 13:22; 提摩太前書 3:3; 以西結書 13:7"> 我察覺上帝並沒有差派他，他是被多比雅和參巴拉收買才說預言攻擊我的。</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米書 20:10; 哥林多後書 11:12; 提摩太後書 1:7"> 他們收買他是為了恐嚇我，使我依從他去犯罪，好毀壞我的名聲來羞辱我。</span>
<span className="v" id="v14" data-v="14" data-xref="尼希米記 13:29; 提摩太後書 4:14–15; 以賽亞書 9:14–15"> 我的上帝啊，多比雅、參巴拉、女先知挪亞底及其他先知企圖恐嚇我，求你記住他們。</span>
</div>
</div>

## 工程竣工

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="詩篇 1:3; 但以理書 9:25; 尼希米記 4:1–2"> 以祿月<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「以祿月」即希伯來曆的六月，陽曆是八月中旬到九月中旬。">a</a></sup>二十五日城牆竣工，前後用了五十二天。</span>
<span className="v" id="v16" data-v="16" data-xref="詩篇 126:2; 約書亞記 5:1; 尼希米記 4:7"> 我們的敵人和周圍各國聽說後，都感到懼怕和氣餒，因為他們知道這工作是在上帝的幫助下完成的。</span>
<span className="v" id="v17" data-v="17" data-xref="彌迦書 7:1–6; 馬太福音 24:10–12; 尼希米記 3:5"> 在那些日子，多比雅和猶大貴族之間多有書信來往。</span>
<span className="v" id="v18" data-v="18" data-xref="以斯拉記 2:5; 尼希米記 7:10; 尼希米記 3:4"> 在猶大有很多人與多比雅結盟，因為他是亞拉的兒子示迦尼的女婿，他兒子約哈難又娶了比利迦的兒子米書蘭的女兒為妻。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行傳 4:18–21; 尼希米記 6:9; 約翰福音 7:7"> 他們常告訴我有關多比雅的善行，並把我的話告訴他。多比雅不斷寫信恐嚇我。</span>
</div>

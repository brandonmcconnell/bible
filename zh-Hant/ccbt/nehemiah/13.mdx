## 與外族人隔離

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命記 23:3–5; 尼希米記 9:3; 尼希米記 13:23"> 那天，有人給民眾宣讀摩西律法書時，發現書上說亞捫人和摩押人永不可加入上帝的會眾。</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 23:5; 約書亞記 24:9–10; 民數記 23:8–11"> 因為他們沒有用食物和水接待以色列人，還雇巴蘭咒詛他們，但我們的上帝將咒詛變為祝福。</span>
<span className="v" id="v3" data-v="3" data-xref="尼希米記 9:2; 出埃及記 12:38; 民數記 11:4"> 以色列人聽到律法書上的話，便逐出所有外族人。</span>

## 尼希米的改革

<div className="bt">
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="尼希米記 12:44; 尼希米記 6:17–18; 尼希米記 13:28"> 這事之前，被委派負責上帝殿庫房的以利亞實祭司因與多比雅是親戚，</span>
<span className="v" id="v5" data-v="5" data-xref="尼希米記 12:44; 歷代志下 34:11; 民數記 18:21–24"> 就為多比雅預備了一個大房間，這房間從前用來存放素祭、乳香、器皿，還有按律法給利未人、歌樂手、殿門守衛的十分之一五穀、新酒和新油，以及給祭司的舉祭。</span>
<span className="v" id="v6" data-v="6" data-xref="尼希米記 5:14; 尼希米記 2:5–6; 馬太福音 13:25"> 這一切發生的時候，我不在耶路撒冷，因為我已在巴比倫王亞達薛西三十二年回到王那裡。過了一段日子，我向王請假離開。</span>
<span className="v" id="v7" data-v="7" data-xref="尼希米記 13:5; 馬太福音 21:12–13; 耶利米哀歌 1:10"> 我返回耶路撒冷後，才得知以利亞實在上帝殿的院內為多比雅預備房間的惡事。</span>
<span className="v" id="v8" data-v="8" data-xref="馬可福音 11:15–17; 以斯拉記 10:1; 詩篇 69:9"> 我非常憤怒，把多比雅所有的物品扔出房間，</span>
<span className="v" id="v9" data-v="9" data-xref="歷代志下 29:5; 歷代志下 29:15–19; 尼希米記 12:45"> 下令潔淨那些房間，然後搬回上帝殿內的器皿、素祭和乳香。</span>
<span className="v" id="v10" data-v="10" data-xref="尼希米記 10:37; 瑪拉基書 3:8; 瑪拉基書 1:6–14"> 我發現利未人沒有得到應得之份，以致當值的利未人和歌樂手都跑回自己的田地。</span>
<span className="v" id="v11" data-v="11" data-xref="尼希米記 10:39; 尼希米記 13:17; 尼希米記 13:25"> 我斥責眾首領說：「為何忽略上帝的殿？」然後，我招聚利未人，叫他們各歸各職。</span>
<span className="v" id="v12" data-v="12" data-xref="尼希米記 10:37–39; 瑪拉基書 3:10; 尼希米記 12:44"> 猶大人都把他們的五穀、新酒和新油的十分之一送進庫房。</span>
<span className="v" id="v13" data-v="13" data-xref="列王紀下 22:7; 尼希米記 7:2; 尼希米記 12:44"> 我派示利米雅祭司、律法教師撒督及利未人毗大雅管理庫房，並派撒刻的兒子、瑪他尼的孫子哈難做他們的助手。這些人忠誠可靠，他們負責把物品分配給他們的弟兄。</span>
<span className="v" id="v14" data-v="14" data-xref="詩篇 122:6–9; 尼希米記 13:22; 尼希米記 13:31"> 我的上帝啊，求你因這事而記念我，不要塗抹我為上帝的殿和其中的敬拜禮儀所做的善事。</span>
<span className="v" id="v15" data-v="15" data-xref="尼希米記 10:31; 尼希米記 13:21; 出埃及記 34:21"> 那些日子，我在猶大看見有人在安息日榨酒，用驢馱運禾捆，又在安息日把酒、葡萄、無花果和各樣出產帶進耶路撒冷。我就在他們賣食物的那天警告他們。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 23:12; 申命記 5:14"> 一些住在耶路撒冷的泰爾人運來魚和各樣貨物，在安息日賣給耶路撒冷的猶大人。</span>
<span className="v" id="v17" data-v="17" data-xref="尼希米記 13:11; 尼希米記 13:25; 以賽亞書 1:10"> 我斥責猶大的貴族說：「你們為何做這惡事干犯安息日？</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米書 17:21–23; 耶利米書 44:9; 民數記 32:14"> 你們的祖先難道不是犯了這樣的罪，以致我們的上帝使一切災禍臨到我們和這城嗎？如今你們干犯安息日，使上帝的憤怒越發臨到以色列。」</span>
<span className="v" id="v19" data-v="19" data-xref="利未記 23:32; 出埃及記 31:14–17; 耶利米書 17:19–22"> 我下令在安息日之前夜幕來臨時關上耶路撒冷城門，一直到安息日完畢才打開。我又派我的一些僕人把守城門，不准在安息日帶貨物進城。</span>
<span className="v" id="v20" data-v="20"> 有一兩次，商人和販賣各樣貨物的曾在耶路撒冷城外住宿。</span>
<span className="v" id="v21" data-v="21" data-xref="羅馬書 13:3–4; 彼得前書 2:14; 以斯拉記 7:26"> 我警告他們說：「你們為什麼在城牆外面住宿呢？若再這樣，我必拘捕你們。」從此，他們就不再在安息日來了。</span>
<span className="v" id="v22" data-v="22" data-xref="尼希米記 12:30; 尼希米記 13:14; 尼希米記 13:31"> 我吩咐利未人潔淨自己，然後來看守城門，尊安息日為聖日。我的上帝啊，求你因此而眷顧我，按你豐盛的慈愛憐憫我。</span>
<span className="v" id="v23" data-v="23" data-xref="以斯拉記 9:1–2; 以斯拉記 10:10; 尼希米記 10:30"> 那些日子，我見猶大人娶了亞實突、亞捫和摩押的女子為妻。</span>
<span className="v" id="v24" data-v="24" data-xref="西番雅書 3:9"> 他們半數的子女說亞實突話或其他外族人的話，不懂得猶大話。</span>
<span className="v" id="v25" data-v="25" data-xref="申命記 7:3; 尼希米記 13:17; 尼希米記 10:29–30"> 我就斥責他們，咒詛他們，打了他們其中一些人，又扯他們的頭髮，要他們奉上帝的名起誓不再讓自己的子女與外族人通婚，自己也不娶外族女子。</span>
<span className="v" id="v26" data-v="26" data-xref="列王紀上 11:1–8; 列王紀上 3:13; 傳道書 7:26"> 我說：「這豈不是以色列王所羅門所犯的罪嗎？眾國中沒有王可與他相比，他的上帝愛他，立他做全以色列的王。然而，連他也被外族女子引入罪中。</span>
<span className="v" id="v27" data-v="27" data-xref="以斯拉記 10:2; 撒母耳記上 30:24"> 我怎能聽憑你們行這大惡，因娶外族女子而背叛我們的上帝呢？」</span>
<span className="v" id="v28" data-v="28" data-xref="尼希米記 2:19; 尼希米記 3:1; 尼希米記 12:22"> 以利亞實大祭司之子耶何耶大有個兒子娶了和倫人參巴拉的女兒，我就把他趕了出去。</span>
<span className="v" id="v29" data-v="29" data-xref="尼希米記 6:14; 民數記 25:12–13; 瑪拉基書 2:4–8"> 我的上帝啊，求你記住他們，因為他們玷污了祭司的職分，違背了你與祭司和利未人所立的約。</span>
<span className="v" id="v30" data-v="30" data-xref="尼希米記 10:30; 尼希米記 12:1–26; 歷代志上 23:1–26"> 這樣，我清除了他們當中的一切外族之物，並指定祭司和利未人的職分，使他們各盡其職，</span>
<span className="v" id="v31" data-v="31" data-xref="尼希米記 13:14; 尼希米記 13:22; 詩篇 106:4"> 又讓民眾定期供應木柴和初熟的物產。 我的上帝啊，求你眷顧我，施恩於我。</span>
</div>

## 尼希米幫助窮苦人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以賽亞書 5:7; 出埃及記 22:25–27; 哥林多前書 6:6–8"> 那時，民眾和他們的妻子都抱怨他們的猶太同胞。</span>
<span className="v" id="v2" data-v="2" data-xref="瑪拉基書 2:2; 詩篇 128:2–4; 詩篇 127:3–5"> 有的說：「我們和兒女人口眾多，需要糧食來活命。」</span>
<span className="v" id="v3" data-v="3" data-xref="利未記 25:35–39; 瑪拉基書 3:8–11; 創世記 47:15–25"> 有的說：「因為饑荒的緣故，我們要將田地、葡萄園和房屋作抵押來獲取糧食。」</span>
<span className="v" id="v4" data-v="4" data-xref="以斯拉記 4:13; 以斯拉記 4:20; 申命記 28:47–48"> 有的說：「我們要借錢才能繳納王對我們的田地和葡萄園徵收的稅。</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀下 4:1; 利未記 25:39–43; 以賽亞書 58:7"> 我們和他們是同胞，我們的孩子就像他們的孩子。但現在我們的兒女要被迫成為僕婢，甚至我們的女兒有些已經淪為奴婢。我們卻無能為力，因為我們的田地和葡萄園已經歸別人了。」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="出埃及記 11:8; 尼希米記 13:25; 以弗所書 4:26"> 聽到他們的怨聲載道後，我非常憤怒。</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 23:19–20; 利未記 25:36; 出埃及記 22:25"> 經過深思熟慮後，我便斥責貴族和官員，說：「你們竟然向同胞放高利貸！」於是我召開大會處理他們的問題。</span>
<span className="v" id="v8" data-v="8" data-xref="利未記 25:47–49; 哥林多前書 8:11; 馬太福音 25:29"> 我對他們說：「我們在盡力贖回那些被賣到外邦的猶太同胞，你們卻要賣他們為奴，好讓我們再贖回他們嗎？」他們都沉默不語，無言以對。</span>
<span className="v" id="v9" data-v="9" data-xref="利未記 25:36; 撒母耳記下 12:14; 羅馬書 2:24"> 我繼續說：「你們的所作所為實在不對。難道你們不應該敬畏上帝，以免我們的仇敵凌辱我們嗎？</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多後書 6:1; 出埃及記 22:25–27; 以西結書 18:13"> 我和我的兄弟及僕人都借錢、借糧給民眾，現在我們要停止收取利息。</span>
<span className="v" id="v11" data-v="11" data-xref="以賽亞書 58:6; 利未記 6:4–5; 路加福音 3:8"> 你們今天就要歸還他們的田地、葡萄園、橄欖園和房屋，以及你們向他們所收的五穀、新酒和油的利息。」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="以斯拉記 10:5; 耶利米書 34:8–10; 馬太福音 19:21–22"> 他們說：「我們會照你的話去做，把東西還給他們，不再向他們索債。」於是，我召來祭司，讓這些人起誓遵守自己的諾言。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行傳 18:6; 歷代志上 16:36; 馬太福音 10:14"> 我抖著衣服說：「如果你們不守誓言，願上帝也這樣抖掉你們的家園和你們勞碌得來的，使你們一無所有。」全體會眾都說：「阿們！」他們讚美耶和華，民眾都遵照誓言去行。</span>
</div>
</div>

## 尼希米大公無私

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="尼希米記 13:6; 帖撒羅尼迦後書 3:8–9; 哥林多前書 9:4–15"> 從亞達薛西王二十年至三十二年，也就是我奉派為猶大省長的十二年間，我和我的弟兄都沒有吃省長的俸祿。</span>
<span className="v" id="v15" data-v="15" data-xref="尼希米記 5:9; 以賽亞書 50:10; 箴言 16:6"> 在我之前的省長使民眾負擔沉重，天天索取食物、酒及十兩銀子。他們的僕人也欺壓民眾，但我因敬畏上帝就沒有這樣做。</span>
<span className="v" id="v16" data-v="16" data-xref="加拉太書 6:9; 帖撒羅尼迦前書 2:5–6; 哥林多前書 15:58"> 我全心修築城牆，沒有購置田產，我的僕人也都參與修建城牆的工作。</span>
<span className="v" id="v17" data-v="17" data-xref="列王紀上 18:19; 彼得前書 4:9–10; 撒母耳記下 9:7"> 除了從周圍外邦來到我們這裡的人之外，還有一百五十名猶太人和官員與我一同吃飯。</span>
<span className="v" id="v18" data-v="18" data-xref="列王紀上 4:22–23; 詩篇 37:21; 詩篇 37:26"> 我每天需要預備一頭公牛、六隻肥羊和飛禽；每十天還要大量供應各樣酒品。即使這樣，我仍然沒有吃省長的俸祿，因為民眾已經負擔沉重。</span>
<span className="v" id="v19" data-v="19" data-xref="尼希米記 13:31; 詩篇 106:4; 尼希米記 13:14"> 我的上帝啊，求你記念我為這些民眾所做的一切，施恩於我。</span>
</div>
</div>

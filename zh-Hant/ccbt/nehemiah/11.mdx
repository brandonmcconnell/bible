## 住在耶路撒冷的人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以賽亞書 48:2; 以賽亞書 52:1; 尼希米記 11:18"> 民眾的首領住在耶路撒冷。其餘的人用抽籤的方式抽出十分之一的人口住在聖城耶路撒冷，剩下的人則住在其他城邑。</span>
<span className="v" id="v2" data-v="2" data-xref="士師記 5:9; 哥林多後書 8:16–17; 約伯記 29:13"> 眾人為所有自願住在耶路撒冷的人祝福。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="以斯拉記 2:1; 以斯拉記 2:43; 歷代志上 9:1–34"> 以色列人、祭司、利未人、殿役和所羅門僕人的子孫住在猶大各城自己的家園，有些來自猶大和便雅憫的人住在耶路撒冷。以下是住在耶路撒冷的猶大省首領：<br />猶大人中有法勒斯的子孫、烏西雅的兒子亞他雅。烏西雅是撒迦利雅的兒子，撒迦利雅是亞瑪利雅的兒子，亞瑪利雅是示法提雅的兒子，示法提雅是瑪勒列的兒子。</span>
<span className="v" id="v5" data-v="5" data-xref="歷代志上 9:5; 尼希米記 3:15; 民數記 26:20"> 此外還有巴錄的兒子瑪西雅。巴錄是谷何西的兒子，谷何西是哈賽雅的兒子，哈賽雅是亞大雅的兒子，亞大雅是約雅立的兒子，約雅立是撒迦利雅的兒子，撒迦利雅是示羅尼的兒子。</span>
<span className="v" id="v6" data-v="6"> 住在耶路撒冷的法勒斯的子孫共有四百六十八人，都是勇士。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="歷代志上 9:7–9"> 便雅憫人中有米書蘭的兒子撒路。米書蘭是約葉的兒子，約葉是毗大雅的兒子，毗大雅是歌賴雅的兒子，歌賴雅是瑪西雅的兒子，瑪西雅是以鐵的兒子，以鐵是耶篩亞的兒子。</span>
<span className="v" id="v8" data-v="8"> 此外還有迦拜和撒來，共九百二十八人。</span>
<span className="v" id="v9" data-v="9" data-xref="歷代志上 9:7"> 細基利的兒子約珥是他們的監督，哈西努亞的兒子猶大是耶路撒冷的副官。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="歷代志上 9:10; 尼希米記 12:6; 尼希米記 12:19"> 祭司中有雅斤，約雅立的兒子耶大雅，</span>
<span className="v" id="v11" data-v="11" data-xref="歷代志上 9:11; 歷代志上 6:7–14; 民數記 3:32"> 以及管理上帝殿的西萊雅，他是希勒迦的兒子，希勒迦是米書蘭的兒子，米書蘭是撒督的兒子，撒督是米拉約的兒子，米拉約是亞希突的兒子；</span>
<span className="v" id="v12" data-v="12" data-xref="歷代志上 9:12–13"> 還有他們在殿裡供職的弟兄，共八百二十二人；還有耶羅罕的兒子亞大雅，耶羅罕是毗拉利的兒子，毗拉利是暗洗的兒子，暗洗是撒迦利亞的兒子，撒迦利亞是巴施戶珥的兒子，巴施戶珥是瑪基雅的兒子；</span>
<span className="v" id="v13" data-v="13"> 還有他們做族長的弟兄，共二百四十二人；還有亞薩列的兒子亞瑪帥，亞薩列是亞哈賽的兒子，亞哈賽是米實利末的兒子，米實利末是音麥的兒子；</span>
<span className="v" id="v14" data-v="14"> 還有他們英勇的弟兄，共一百二十八人。他們的監督是哈基多琳的兒子撒巴第業。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="歷代志上 9:14; 歷代志上 9:19"> 利未人中有哈述的兒子示瑪雅。哈述是押利甘的兒子，押利甘是哈沙比雅的兒子，哈沙比雅是布尼的兒子。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行傳 6:2–3; 尼希米記 8:7; 以斯拉記 8:33"> 還有利未人的族長沙比太和約撒拔，他們負責上帝殿外面的事務。</span>
<span className="v" id="v17" data-v="17" data-xref="歷代志上 9:15; 歷代志上 25:1–6; 尼希米記 12:8–9"> 還有米迦的兒子瑪他尼，他是帶領禱告和讚美的。米迦是撒底的兒子，撒底是亞薩的兒子。還有他的助手瑪他尼的弟兄八布迦。此外，還有沙姆亞的兒子押大。沙姆亞是加拉的兒子，加拉是耶杜頓的兒子。</span>
<span className="v" id="v18" data-v="18" data-xref="尼希米記 11:1; 啟示錄 21:2; 但以理書 9:24"> 在聖城的利未人共有二百八十四名。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="尼希米記 7:45; 歷代志上 9:17–22; 詩篇 84:10"> 殿門守衛有亞谷和達們，還有他們做殿門守衛的弟兄，共一百七十二人。</span>
<span className="v" id="v20" data-v="20" data-xref="尼希米記 11:3"> 其他以色列人、祭司和利未人住在猶大各城自己的家園。</span>
<span className="v" id="v21" data-v="21" data-xref="尼希米記 3:26; 歷代志下 27:3; 尼希米記 3:31"> 殿役住在俄斐勒，他們的首領是西哈和基斯帕。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="尼希米記 12:42; 歷代志上 25:1–6; 以斯拉記 8:19"> 在耶路撒冷的利未人的監督是巴尼的兒子烏西，巴尼是哈沙比雅的兒子，哈沙比雅是瑪他尼的兒子，瑪他尼是米迦的兒子。烏西是亞薩的子孫，亞薩的子孫是負責聖殿事務的歌樂手。</span>
<span className="v" id="v23" data-v="23" data-xref="以斯拉記 7:20–24; 尼希米記 12:47; 以斯拉記 6:8–9"> 歌樂手每天應盡的責任由王決定。</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 38:30; 歷代志上 18:17; 歷代志上 23:28"> 猶大的兒子謝拉的子孫、米示薩別的兒子毗他希雅幫助王處理民眾的事務。</span>
</div>
</div>

## 住在其他城邑的人

<div className="bt">
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="約書亞記 14:15; 約書亞記 15:21–22"> 至於村莊及其周圍的田地，一些猶大人住在基列·亞巴、底本、葉甲薛和它們周圍的村莊，</span>
<span className="v" id="v26" data-v="26" data-xref="約書亞記 15:26–27; 約書亞記 19:2"> 耶書亞、摩拉大、伯·帕列、</span>
<span className="v" id="v27" data-v="27" data-xref="創世記 26:33; 約書亞記 15:28; 士師記 20:1"> 哈薩·書亞、別示巴和別示巴周圍的村莊，</span>
<span className="v" id="v28" data-v="28" data-xref="撒母耳記上 27:6; 約書亞記 15:31"> 洗革拉、米哥拿和米哥拿周圍的村莊，</span>
<span className="v" id="v29" data-v="29" data-xref="約書亞記 19:41; 約書亞記 15:32–33; 約書亞記 15:35"> 音·臨門、瑣拉、耶末、</span>
<span className="v" id="v30" data-v="30" data-xref="約書亞記 10:3; 約書亞記 15:8; 約書亞記 18:16"> 撒挪亞、亞杜蘭和它們周圍的村莊，拉吉及其周圍的田地，亞西加及其周圍的村莊。他們居住的地方從別示巴一直延伸到欣嫩谷。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="創世記 12:8; 約書亞記 8:9; 約書亞記 18:13"> 便雅憫人住的地方由迦巴起直到密抹、亞雅、伯特利和伯特利周圍的村莊，</span>
<span className="v" id="v32" data-v="32" data-xref="約書亞記 21:18; 以賽亞書 10:30; 撒母耳記上 21:1"> 亞拿突、挪伯、亞南雅、</span>
<span className="v" id="v33" data-v="33" data-xref="撒母耳記下 4:3; 撒母耳記上 7:17; 約書亞記 18:25"> 夏瑣、拉瑪、基他音、</span>
<span className="v" id="v34" data-v="34" data-xref="撒母耳記上 13:18"> 哈第、洗編、尼八拉、</span>
<span className="v" id="v35" data-v="35" data-xref="歷代志上 8:12; 尼希米記 7:37; 歷代志上 4:14"> 羅德、阿挪和匠人之谷。</span>
<span className="v" id="v36" data-v="36" data-xref="約書亞記 21:1–45; 創世記 49:7; 歷代志上 6:54–81"> 一些原本住在猶大的利未人被安頓在便雅憫。</span>
</div>
</div>

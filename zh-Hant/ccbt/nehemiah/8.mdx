## 以斯拉宣讀律法書

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以斯拉記 7:6; 尼希米記 3:26; 歷代志下 34:15"> 全體民眾齊心聚集在水門前的廣場上。他們請律法教師以斯拉帶來耶和華藉摩西頒給以色列人的律法書。</span>
<span className="v" id="v2" data-v="2" data-xref="利未記 23:24; 瑪拉基書 2:7; 民數記 29:1"> 七月一日，以斯拉祭司把律法書帶到能聽懂的男女會眾面前，</span>
<span className="v" id="v3" data-v="3" data-xref="啟示錄 3:22; 啟示錄 2:29; 希伯來書 2:1–3"> 面向水門前的廣場，從清早到正午一直向他們宣讀律法書，民眾都側耳傾聽。</span>
<span className="v" id="v4" data-v="4" data-xref="以斯拉記 10:29; 尼希米記 12:13; 尼希米記 10:20"> 律法教師以斯拉站在為這聚會預備的木臺上，站在他右邊的是瑪他提雅、示瑪、亞奈雅、烏利亞、希勒迦和瑪西雅；站在他左邊的是毗大雅、米沙利、瑪基雅、哈順、哈拔大拿、撒迦利亞和米書蘭。</span>
<span className="v" id="v5" data-v="5" data-xref="士師記 3:20; 列王紀上 8:14; 路加福音 4:16–17"> 以斯拉站在高處，他在全體會眾面前一打開書卷，他們都站了起來。</span>
<span className="v" id="v6" data-v="6" data-xref="提摩太前書 2:8; 耶利米哀歌 3:41; 出埃及記 4:31"> 以斯拉稱頌偉大的上帝耶和華，全體民眾都舉手應聲說：「阿們！阿們！」他們又面伏於地，俯伏敬拜耶和華。</span>
<span className="v" id="v7" data-v="7" data-xref="尼希米記 9:4; 利未記 10:11; 尼希米記 3:23"> 耶書亞、巴尼、示利比、雅憫、亞谷、沙比太、荷第雅、瑪西雅、基利他、亞撒利雅、約撒拔、哈難、毗萊雅和利未人幫助民眾明白律法，當時民眾都站在那裡。</span>
<span className="v" id="v8" data-v="8" data-xref="路加福音 24:45; 使徒行傳 28:23; 路加福音 24:32"> 他們宣讀上帝的律法書，並解釋清楚，使民眾明白所宣讀的。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="尼希米記 7:65; 尼希米記 7:70; 申命記 12:12"> 全體民眾聽到律法書上的話都哭了。尼希米省長、律法教師以斯拉祭司和教導民眾的利未人對他們說：「今天是你們上帝耶和華的聖日，不要悲哀、哭泣。」</span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 28:7–8; 箴言 17:22; 哥林多後書 12:8–9"> 尼希米又說：「你們去吃肥美的肉，喝甘甜的酒，並分些給沒有預備的人，因為今天是我們主的聖日。不要悲傷，因為從耶和華而來的喜樂是你們的力量。」</span>
<span className="v" id="v11" data-v="11" data-xref="民數記 13:30"> 利未人使全體民眾安靜，說：「請安靜，因為今天是聖日。不要悲傷。」</span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 119:174; 詩篇 119:111; 詩篇 119:130"> 於是，全體民眾去吃喝，並分給他人，非常歡喜，因為他們明白了教導給他們的話。</span>
</div>
</div>

## 守住棚節

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="箴言 2:1–6; 箴言 8:33–34; 箴言 12:1"> 第二天，全體民眾的族長、祭司和利未人都到律法教師以斯拉那裡，要深入研究律法上的話。</span>
<span className="v" id="v14" data-v="14" data-xref="利未記 23:34; 申命記 16:13–15; 利未記 23:40–43"> 當時，他們發現耶和華藉摩西吩咐的律法上記載，以色列人要在七月節期期間住在棚子裡，</span>
<span className="v" id="v15" data-v="15" data-xref="利未記 23:40; 申命記 16:16; 利未記 23:4"> 並且要在各城邑和耶路撒冷宣佈和傳揚以下信息：「你們要上山取橄欖樹、野橄欖樹、番石榴樹、棕樹和其他茂密樹木的枝子，照著所規定的搭棚。」</span>
<span className="v" id="v16" data-v="16" data-xref="尼希米記 12:39; 列王紀下 14:13; 尼希米記 12:37"> 於是，民眾都出去取來樹枝，在自家的屋頂上、庭院裡、上帝殿的院子裡、水門的廣場上和以法蓮門的廣場上搭棚。</span>
<span className="v" id="v17" data-v="17" data-xref="歷代志下 8:13; 以斯拉記 3:4; 歷代志下 7:8–10"> 從流亡之地歸回的民眾都搭起棚子，住在裡面。從嫩的兒子約書亞時代直到那天，以色列人從沒有這樣做過。民眾非常歡喜。</span>
<span className="v" id="v18" data-v="18" data-xref="民數記 29:35; 利未記 23:36; 申命記 31:10–13"> 從第一天到最後一天，以斯拉每天都誦讀上帝的律法書。他們守節期七天，第八天根據典章舉行莊嚴的聚會。</span>
</div>
</div>

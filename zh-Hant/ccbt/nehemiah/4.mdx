## 尼希米戰勝阻力

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="尼希米記 2:10; 希伯來書 11:36; 詩篇 35:15–16"> 參巴拉聽說我們正在重建城牆，非常憤怒，就嘲笑猶太人，</span>
<span className="v" id="v2" data-v="2" data-xref="以斯拉記 4:9–10; 哥林多前書 1:27; 以西結書 37:3–13"> 當著他的同僚和撒瑪利亞軍兵的面說：「這群弱小的猶太人在做什麼呢？要重建城牆嗎？要獻祭嗎？要在一日之間建好嗎？要用廢墟中燒過的石頭來建造嗎？」</span>
<span className="v" id="v3" data-v="3" data-xref="尼希米記 2:19; 列王紀上 20:10; 尼希米記 2:10"> 他身旁的亞捫人多比雅說：「他們建的石牆，一隻狐狸上去就能踩倒！」</span>
<span className="v" id="v4" data-v="4" data-xref="詩篇 79:12; 詩篇 123:3–4; 箴言 3:34"> 我禱告說：「我們的上帝啊，求你垂聽，因為我們被人藐視。求你使他們對我們的凌辱歸到他們自己頭上，使他們被擄到外邦。</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 109:14; 耶利米書 18:23; 詩篇 69:27–28"> 不要遮掩他們的惡行，也不要從你面前塗抹他們的罪惡，因為他們在這些建造的人面前惹你發怒。」</span>
<span className="v" id="v6" data-v="6" data-xref="腓立比書 2:13; 尼希米記 6:15; 希伯來書 13:21"> 眾人全心做工，把整個城牆連接起來，高達原來的一半。</span>
<span className="v" id="v7" data-v="7" data-xref="尼希米記 2:10; 尼希米記 4:1; 使徒行傳 5:33"> 參巴拉、多比雅、阿拉伯人、亞捫人和亞實突人聽說耶路撒冷的城牆正在重建、缺口正在填補，非常憤怒，</span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 83:3–11; 以賽亞書 8:9–10; 耶利米書 20:10"> 便一起圖謀襲擊耶路撒冷，使城內混亂。</span>
<span className="v" id="v9" data-v="9" data-xref="彼得前書 5:8; 使徒行傳 4:24–30; 詩篇 50:15"> 但我們向我們的上帝禱告，並設立守衛晝夜防備他們。</span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 11:1–2; 哈該書 1:2; 歷代志下 2:18"> 猶大人說：「工人已經筋疲力盡，還有太多瓦礫有待清理，我們自己無法重建城牆。」</span>
<span className="v" id="v11" data-v="11" data-xref="帖撒羅尼迦前書 5:2; 使徒行傳 23:12; 詩篇 56:6"> 我們的敵人說：「我們要趁他們不知不覺，進入他們中間殺死他們，阻止他們的工作。」</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 31:7; 創世記 31:41; 民數記 14:22"> 靠近敵人居住的猶太人十次來告訴我們，說敵人會從各方來襲擊我們<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="本節希伯來文意義不明。">a</a></sup>。</span>
<span className="v" id="v13" data-v="13" data-xref="尼希米記 4:17–18; 以弗所書 6:11–20; 雅歌 3:7–8"> 於是，我按宗族派人手持刀劍、長矛和弓箭，守衛在城牆後面低窪的空地上。</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳記下 10:12; 民數記 14:9; 以賽亞書 41:10–14"> 我察看形勢後，起來對貴族、官員和其他民眾說：「不要怕他們！要記住，主偉大而可畏。要為你們的兄弟、兒女、妻子和家園而戰。」</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳記下 17:14; 羅馬書 12:11; 約伯記 5:12–13"> 敵人聽說我們知道了他們的陰謀，上帝已破壞他們的詭計，就沒有來。我們回到城牆那裡，繼續各人的工作。</span>
<span className="v" id="v16" data-v="16" data-xref="尼希米記 4:23; 詩篇 101:6; 尼希米記 5:15–16"> 從那時起，我的僕人一半繼續修築城牆，一半身穿盔甲，手持長矛、盾牌和弓箭負責守衛。官長都站在修築城牆的所有猶大人後面。</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多後書 6:7; 提摩太後書 4:7; 提摩太後書 2:3"> 搬運工人一手工作，一手拿兵器。</span>
<span className="v" id="v18" data-v="18" data-xref="民數記 10:9; 歷代志下 13:12–17"> 修築城牆的人工作的時候都腰間佩刀。吹號的人在我旁邊，</span>
<span className="v" id="v19" data-v="19"> 我對貴族、官員和其餘的民眾說：「這工程浩大，範圍廣闊，我們在城牆上相隔很遠。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及記 14:14; 申命記 1:30; 申命記 20:4"> 因此你們無論在哪裡聽見號角聲，都要聚到我們那裡。我們的上帝必為我們爭戰！」</span>
<span className="v" id="v21" data-v="21" data-xref="加拉太書 6:9; 歌羅西書 1:29; 哥林多前書 15:58"> 這樣，從黎明直到星星出現，我們一直工作，有一半手持長矛守衛。</span>
<span className="v" id="v22" data-v="22" data-xref="尼希米記 11:1–2"> 那時，我又吩咐眾人各帶僕人在耶路撒冷住宿。他們夜間可以幫我們守衛，白天幫我們工作。</span>
<span className="v" id="v23" data-v="23" data-xref="士師記 9:48; 尼希米記 7:2; 哥林多前書 15:10"> 我和我的兄弟、僕人及跟從我的守衛都衣不解帶，刀不離身<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="「刀不離身」或譯「出去打水時也帶著刀」。">b</a></sup>。</span>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="何西阿書 5:1; 瑪拉基書 1:6; 耶利米書 13:13"> 祭司們啊，這誡命是傳給你們的。</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 17:18; 啟示錄 14:7; 詩篇 69:22"> 萬軍之耶和華說：「如果你們不聽從我的話，也不從內心尊崇我的名，我必使咒詛臨到你們，把你們的福氣變成咒詛。其實我已經咒詛了你們，因為你們不把我的誡命放在心上。</span>
<span className="v" id="v3" data-v="3" data-xref="那鴻書 3:6; 瑪拉基書 2:9; 約伯記 20:7"> 我必斥責你們的子孫，把你們祭牲的糞便抹在你們臉上，又把你們和糞便一同丟掉，</span>
<span className="v" id="v4" data-v="4" data-xref="民數記 3:12; 以西結書 38:23; 馬太福音 3:12"> 你們便知道我這樣告誡你們，是為了使我與你們祖先利未所立的約堅立。這是萬軍之耶和華說的。</span>
<span className="v" id="v5" data-v="5" data-xref="民數記 25:12–13; 以西結書 34:25; 以西結書 37:26"> 我與他所立的是生命和平安之約，我將生命和平安賜給他，使他心存敬畏。他就尊崇我，敬畏我的名。</span>
<span className="v" id="v6" data-v="6" data-xref="但以理書 12:3; 提摩太後書 2:15–16; 啟示錄 14:5"> 他口中教導真理，嘴裡毫無詭詐。他帶著平安和正直與我同行，並引導許多人遠離罪惡。</span>
<span className="v" id="v7" data-v="7" data-xref="提摩太後書 2:24–25; 利未記 10:11; 申命記 21:5"> 祭司的嘴唇應持守知識，民眾應從他口中尋求訓誨，因為他是萬軍之耶和華的使者。</span>
<span className="v" id="v8" data-v="8" data-xref="尼希米記 13:29; 耶利米書 18:15; 以賽亞書 30:11"> 然而，你們卻偏離正道，你們的教導使許多人跌倒，你們破壞了我和利未所立的約。這是萬軍之耶和華說的。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳記上 2:30; 申命記 1:17; 馬太福音 19:17–18"> 因此，我必使你們在眾人面前被藐視和輕賤。因為你們不遵守我的道，在教導上偏心待人。」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="詩篇 100:3; 瑪拉基書 2:11; 哥林多前書 8:6"> 我們豈不有同一位父親嗎？豈不由同一位上帝所造嗎？為何要彼此欺騙，背棄上帝與我們祖先所立的約呢？</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多後書 6:14–18; 以斯拉記 9:1–2; 尼希米記 13:23–29"> 猶大人不忠貞，在以色列和耶路撒冷做了可憎的事，他們娶信奉外邦神明的女子為妻，褻瀆了耶和華所愛的聖所。</span>
<span className="v" id="v12" data-v="12" data-xref="利未記 18:29; 利未記 20:3; 以西結書 24:21"> 願耶和華從雅各的帳篷中剷除所有做這事並獻供物給萬軍之耶和華的人！</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="以賽亞書 1:11–15; 耶利米書 14:12; 詩篇 78:34–37"> 另外，你們痛哭哀號，眼淚甚至淹沒了耶和華的祭壇，因為耶和華不再理會你們的供物，不再悅納你們所獻的。</span>
<span className="v" id="v14" data-v="14" data-xref="瑪拉基書 2:15; 傳道書 9:9; 以賽亞書 54:6"> 你們還問為什麼。因為耶和華在你和你的髮妻中間作證，她是你的配偶，是你盟約的妻子，你卻對她不忠。</span>
<span className="v" id="v15" data-v="15" data-xref="馬太福音 19:4–6; 瑪拉基書 2:14; 馬可福音 10:6–8"> 上帝不是把你們合為一體，叫你們肉體和心靈都歸祂嗎<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="此句希伯來文語意不清。">a</a></sup>？祂為何這樣做？是為了得敬虔的後裔。所以，你們要小心謹慎，不可對自己的髮妻不忠。</span>
<span className="v" id="v16" data-v="16" data-xref="馬太福音 19:3–9; 馬太福音 5:31–32; 馬可福音 10:2–12"> 以色列的上帝耶和華說：「我憎惡休妻和暴虐待妻的人。所以你們要小心謹慎，不可不忠。」這是萬軍之耶和華說的。</span>
<span className="v" id="v17" data-v="17" data-xref="以賽亞書 43:24; 彼得後書 3:3–4; 傳道書 8:11"> 你們說的話使耶和華厭煩，然而你們還說：「我們哪裡令祂厭煩了？」因為你們說：「耶和華視作惡者皆為好人，並且喜悅他們。」還說：「公義的上帝在哪裡？」</span>
</div>

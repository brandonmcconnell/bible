## 所羅門為民眾祝福

<div className="bt">
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="列王紀上 8:14; 歷代志下 29:29; 列王紀上 8:55–61"> 然後，王轉身為站立在那裡的以色列全體會眾祝福。</span>
<span className="v" id="v4" data-v="4" data-xref="詩篇 72:18–19; 馬太福音 24:35; 詩篇 68:32–35"> 他說：「以色列的上帝耶和華當受稱頌！祂親口給我父大衛的應許，現在祂親手成就了！</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 20:24; 列王紀上 8:16; 撒母耳記上 13:13–14"> 祂曾說，『自從我帶我的子民出埃及以來，我並沒有在以色列各支派中選出一座城來建造殿宇，作為我名所在之地，也沒有選立一人做我以色列子民的君王。</span>
<span className="v" id="v6" data-v="6" data-xref="歷代志上 28:4; 詩篇 132:13; 歷代志下 12:13"> 但如今，我揀選了耶路撒冷作為我名所在之地，又揀選了大衛來治理我的以色列子民。』」</span>
<span className="v" id="v7" data-v="7" data-xref="歷代志上 17:1; 列王紀上 5:3; 歷代志上 22:7"> 所羅門又說：「我父大衛曾想為以色列的上帝耶和華的名建一座殿，</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多後書 8:12; 馬可福音 14:8; 列王紀上 8:18–21"> 但耶和華對我父大衛說，『你想為我的名建造殿宇，這番心意是好的，</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳記下 7:12–13; 歷代志上 17:4; 歷代志上 17:11–12"> 但你不可建，要由你的親生兒子為我的名建殿。』</span>
<span className="v" id="v10" data-v="10" data-xref="傳道書 1:4; 歷代志上 28:5; 歷代志上 17:11"> 現在耶和華已經成就祂的應許。我繼承了我父大衛的王位統治以色列，又為以色列的上帝耶和華的名建了殿。</span>
<span className="v" id="v11" data-v="11" data-xref="歷代志下 5:10; 歷代志下 5:7; 列王紀上 8:21"> 我把約櫃安放在裡面，約櫃裡有耶和華與以色列人所立的約。」</span>
</div>

## 所羅門的禱告

<div className="bt">
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="詩篇 63:4; 以賽亞書 50:10; 約伯記 11:13"> 所羅門當著以色列會眾的面，站在耶和華的壇前，向天伸出雙手。</span>
<span className="v" id="v13" data-v="13" data-xref="列王紀上 8:54; 尼希米記 8:4; 詩篇 95:6"> 他曾造一個長兩米二，寬兩米二，高一米半的銅臺，放在院子中間。他站在臺上，當著以色列會眾的面雙膝跪下，向天伸出雙手，</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及記 15:11; 申命記 7:9; 尼希米記 1:5"> 禱告說：「以色列的上帝耶和華啊，天上地下沒有神明可以與你相比！你向盡心遵行你旨意的僕人守約、施慈愛。</span>
<span className="v" id="v15" data-v="15" data-xref="歷代志上 22:9–10; 撒母耳記下 7:12; 列王紀上 8:24"> 你持守對你僕人——我父大衛的應許，你曾親口應許，你今天親手成就了。</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀上 2:4; 約翰福音 15:14–15; 歷代志下 7:18"> 以色列的上帝耶和華啊，你曾對你僕人——我父大衛說，『若你的子孫像你一樣謹慎行事，遵行我的律法，你的王朝就不會中斷。』求你信守這應許。</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米書 11:5; 以賽亞書 41:17; 歷代志下 6:4"> 以色列的上帝耶和華啊，求你實現你對你僕人大衛的應許。</span>
<span className="v" id="v18" data-v="18" data-xref="歷代志下 2:6; 以賽亞書 66:1; 詩篇 139:7–10"> 「然而，上帝啊，你真會住在人間嗎？看啊，至高的諸天尚且容不下你，更何況我建造的這殿呢？</span>
<span className="v" id="v19" data-v="19" data-xref="列王紀上 8:28; 路加福音 18:1–7; 約翰福音 17:20"> 可是，我的上帝耶和華啊，求你垂顧你僕人的禱告和祈求，垂聽你僕人在你面前的呼求和禱告。</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 34:15; 但以理書 6:10; 詩篇 121:5"> 願你晝夜看顧這殿，就是你應許立你名的地方！你僕人向著這地方禱告的時候，求你垂聽。</span>
<span className="v" id="v21" data-v="21" data-xref="彌迦書 7:18; 但以理書 9:19; 以賽亞書 43:25"> 你僕人和你的以色列子民向這地方祈禱的時候，求你從你天上的居所垂聽，赦免我們的罪。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及記 22:11; 利未記 5:1; 民數記 5:19–22"> 「如果有人得罪鄰舍，被叫到這殿中，在你的壇前起誓，</span>
<span className="v" id="v23" data-v="23" data-xref="以賽亞書 3:10–11; 箴言 17:15; 耶利米書 51:56"> 求你從天上垂聽，在你眾僕人當中施行審判，按他們的行為罰惡賞善。</span>
<span className="v" id="v24" data-v="24" data-xref="利未記 26:17; 列王紀下 17:7–18; 約書亞記 7:8"> 「當你的以色列子民因得罪你而敗在敵人手中時，如果他們回心轉意歸向你，承認你的名，在這殿裡向你祈禱，</span>
<span className="v" id="v25" data-v="25" data-xref="耶利米書 33:6–13; 以斯拉記 1:1–6; 創世記 13:15"> 求你從天上垂聽，赦免他們的罪，帶領他們回到你賜給他們和他們祖先的土地上。</span>
<span className="v" id="v26" data-v="26" data-xref="申命記 28:23; 申命記 11:17; 利未記 26:19"> 「當你的子民得罪你，你懲罰他們，讓天不降雨時，如果他們向著這地方禱告，承認你的名，並離開罪惡，</span>
<span className="v" id="v27" data-v="27" data-xref="列王紀上 8:35–36; 耶利米書 5:24; 撒迦利亞書 10:1"> 求你在天上垂聽，赦免你僕人以色列子民的罪，教導他們走正道，降下甘霖滋潤你賜給你子民作產業的土地。</span>
<span className="v" id="v28" data-v="28" data-xref="啟示錄 9:3–11; 約珥書 2:25; 路得記 1:1"> 「如果國中有饑荒、瘟疫、旱災、黴病、蝗災、蟲災，或是城邑被敵人圍困，無論遭遇什麼災禍疾病，</span>
<span className="v" id="v29" data-v="29" data-xref="詩篇 50:15; 詩篇 32:2–6; 歷代志下 6:12–13"> 只要你的以色列子民，或個人或全體，自知心中痛苦並向著這殿伸手禱告，無論祈求什麼，</span>
<span className="v" id="v30" data-v="30" data-xref="歷代志上 28:9; 撒母耳記上 16:7; 啟示錄 2:23"> 求你從天上的居所垂聽，赦免他們。唯獨你能洞察人心，你必按各人的行為施行賞罰，</span>
<span className="v" id="v31" data-v="31" data-xref="使徒行傳 9:31; 約伯記 28:28; 詩篇 128:1"> 使你的子民在你賜給我們祖先的土地上終生敬畏你，遵行你的道。</span>
<span className="v" id="v32" data-v="32" data-xref="以賽亞書 56:3–7; 列王紀上 8:41–43; 馬太福音 8:10–11"> 「如果遠方有不屬於你以色列子民的外族人聽說你的大能大力，慕名而來，向著這殿禱告，</span>
<span className="v" id="v33" data-v="33" data-xref="歷代志下 7:14; 列王紀上 8:16; 啟示錄 11:15"> 求你從天上的居所垂聽，應允他們的祈求，好叫天下萬民都像你的以色列子民一樣認識你的名、敬畏你，並知道我建造的這殿屬於你的名下。</span>
<span className="v" id="v34" data-v="34" data-xref="歷代志下 20:6–13; 歷代志下 18:31; 歷代志下 20:4"> 「你的子民奉你的命令上陣與敵人作戰，無論他們在哪裡，如果他們向著你選擇的這城和我為你名建造的這殿禱告，</span>
<span className="v" id="v35" data-v="35" data-xref="但以理書 9:17–19; 詩篇 9:3–4; 耶利米書 5:28"> 求你從天上垂聽他們的祈禱，為他們伸張正義。</span>
<span className="v" id="v36" data-v="36" data-xref="傳道書 7:20; 雅各書 3:2; 約翰一書 1:8–10"> 「世上沒有不犯罪的人，如果你的子民得罪你，以致你向他們發怒，讓敵人把他們擄走，不論遠近，</span>
<span className="v" id="v37" data-v="37" data-xref="耶利米書 31:18–20; 但以理書 9:5–11; 以賽亞書 64:6–12"> 若他們在被擄之地回心轉意，向你懇求，承認自己犯罪作惡了；</span>
<span className="v" id="v38" data-v="38" data-xref="歷代志下 33:11–13; 但以理書 6:10; 但以理書 9:3–4"> 若他們全心全意地歸向你，在被擄之地朝著你賜給他們祖先的這片土地、你選擇的這城和我為你建的這殿向你禱告，</span>
<span className="v" id="v39" data-v="39" data-xref="彌迦書 7:18–20; 歷代志下 6:35; 詩篇 25:18"> 求你從天上的居所垂聽他們的祈禱，為他們伸張正義，赦免得罪你的子民。</span>
<span className="v" id="v40" data-v="40" data-xref="歷代志下 7:15; 詩篇 116:2; 尼希米記 1:6"> <span className="pl pl-1">「我的上帝啊，</span><br /><span className="pl pl-1">求你睜眼看、側耳聽在這殿裡獻上的禱告。</span><br /></span>
<span className="v" id="v41" data-v="41" data-xref="以賽亞書 61:10; 歷代志上 28:2; 詩篇 132:8–10"> <span className="pl pl-1">耶和華上帝啊，</span><br /><span className="pl pl-1">求你起來和你大能的約櫃一同進入你的安息之所！</span><br /><span className="pl pl-1">耶和華上帝啊，</span><br /><span className="pl pl-1">願你的祭司披上救恩，</span><br /><span className="pl pl-1">願你忠心的子民蒙福歡樂！</span><br /></span>
<span className="v" id="v42" data-v="42" data-xref="以賽亞書 55:3; 詩篇 132:1; 以賽亞書 61:1"> <span className="pl pl-1">耶和華上帝啊，</span><br /><span className="pl pl-1">求你不要棄絕你所膏立的人，</span><br /><span className="pl pl-1">顧念你曾應許以慈愛待你的僕人大衛。」</span></span>
</div>

## 猶大王約西亞

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="西番雅書 1:1; 耶利米書 1:2; 歷代志下 33:25"> 約西亞八歲登基，在耶路撒冷執政三十一年。</span>
<span className="v" id="v2" data-v="2" data-xref="歷代志下 29:2; 約書亞記 1:7; 列王紀下 22:2"> 他做耶和華視為正的事，效法他祖先大衛，不偏不離。</span>
</div>
</div>

## 約西亞清除偶像

<div className="bt">
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="歷代志下 33:22; 歷代志下 15:2; 箴言 8:17"> 他執政第八年，雖然還年幼，卻開始尋求他祖先大衛的上帝。他執政第十二年，開始清除猶大和耶路撒冷的邱壇、亞舍拉神像、雕刻和鑄造的偶像。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及記 32:20; 利未記 26:30; 列王紀下 23:4–6"> 眾人在他面前拆毀巴力的祭壇，他砍掉上面高高的香壇，又把亞舍拉神像及雕刻和鑄造的偶像打碎並磨成粉末，撒在祭拜它們之人的墳墓上，</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀上 13:2; 耶利米書 3:10; 民數記 35:33"> 把它們祭司的骸骨放在它們的壇上焚燒。這樣，他潔淨了猶大和耶路撒冷。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳記上 13:20–21; 以賽亞書 7:25; 歷代志下 30:1"> 約西亞還在瑪拿西、以法蓮、西緬，遠至拿弗他利的各城邑及其周圍的荒廢之地做了同樣的事情。</span>
<span className="v" id="v7" data-v="7" data-xref="歷代志下 31:1; 申命記 9:21; 歷代志下 34:1"> 他拆毀祭壇和亞舍拉神像，把偶像磨成粉末，砍掉以色列境內所有的香壇，然後回到耶路撒冷。</span>
</div>
</div>

## 發現律法書

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="撒母耳記下 8:16; 歷代志上 18:15; 耶利米書 29:25"> 約西亞執政第十八年，在潔淨國土和聖殿以後，他差遣亞薩利雅的兒子沙番、耶路撒冷的總督瑪西雅和約哈斯作史官的兒子約亞，負責整修他的上帝耶和華的殿。</span>
<span className="v" id="v9" data-v="9" data-xref="歷代志下 30:18; 歷代志下 30:10; 歷代志下 35:8"> 他們到希勒迦大祭司那裡，把獻給上帝殿的銀子交給他。這銀子是守殿門的利未人從瑪拿西人和以法蓮人，所有剩下的以色列人，所有的猶大人和便雅憫人，以及耶路撒冷的居民那裡收來的。</span>
<span className="v" id="v10" data-v="10" data-xref="列王紀下 12:11–12; 以斯拉記 3:7; 列王紀下 22:5–6"> 他們把銀子交給負責修理耶和華殿的督工，由他們付給修理耶和華殿的工人，</span>
<span className="v" id="v11" data-v="11" data-xref="歷代志下 33:4–7; 歷代志下 33:22"> 就是木匠和瓦匠，來購買鑿好的石頭、木架和棟梁，修繕猶大諸王失修的建築。</span>
<span className="v" id="v12" data-v="12" data-xref="列王紀下 12:15; 歷代志上 23:5; 列王紀下 22:7"> 這些人都忠誠地工作。他們的督工是利未人米拉利的子孫雅哈和俄巴底，哥轄的子孫撒迦利亞和米書蘭。其他精通樂器的利未人</span>
<span className="v" id="v13" data-v="13" data-xref="尼希米記 4:10; 歷代志下 2:18; 耶利米書 8:8"> 負責監督搬運工人及做各種工作的人，還有一些利未人做書記、官員和殿門守衛。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="利未記 8:36; 詩篇 1:2; 利未記 10:11"> 他們把奉獻到耶和華殿裡的銀子拿出來的時候，希勒迦祭司發現了摩西所傳的耶和華的律法書。</span>
<span className="v" id="v15" data-v="15"> 希勒迦對沙番書記說：「我在耶和華的殿裡發現了律法書。」希勒迦把書卷交給沙番。</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀下 22:9–10; 耶利米書 36:20–21"> 沙番把書卷帶到王那裡，向王稟告說：「凡交給臣僕辦的事，都在辦理。</span>
<span className="v" id="v17" data-v="17"> 臣僕已經清空耶和華殿裡的銀子，交給督工和工人。」</span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 119:46; 耶利米書 36:20–21; 申命記 17:19"> 沙番書記又對王說：「希勒迦祭司交給我一卷書。」沙番就在王面前誦讀這書。</span>
<span className="v" id="v19" data-v="19" data-xref="約書亞記 7:6; 申命記 28:3–68; 列王紀下 22:19"> 王聽了律法書上的話，就撕裂衣服，</span>
<span className="v" id="v20" data-v="20" data-xref="列王紀下 22:12; 耶利米書 26:24; 耶利米書 40:9"> 吩咐希勒迦、沙番的兒子亞希甘、米迦的兒子亞比頓、沙番書記和王的臣僕亞撒雅：</span>
<span className="v" id="v21" data-v="21" data-xref="耶利米書 21:2; 以西結書 14:1–11; 歷代志下 28:6"> 「你們去為我及以色列和猶大的餘民求問耶和華有關這書卷上的話。耶和華的烈怒已經臨到我們身上，因為我們的祖先沒有遵守耶和華的話，沒有遵行這書卷上的一切吩咐。」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="路加福音 2:36; 出埃及記 15:20; 列王紀下 22:14"> 於是，王派去的人跟著希勒迦去見女先知戶勒妲，她是負責管理禮服的沙龍之妻。沙龍是哈斯拉的孫子、特瓦的兒子。戶勒妲住在耶路撒冷第二區。他們向她說明來意，</span>
<span className="v" id="v23" data-v="23" data-xref="耶利米書 37:7–10; 耶利米書 21:3–7; 列王紀下 22:15–20"> 她對他們說：「以色列的上帝耶和華要你們回去告訴差你們來見我的人，</span>
<span className="v" id="v24" data-v="24" data-xref="歷代志下 36:14–20; 約書亞記 23:16; 申命記 28:15–68"> 耶和華說，『我要照在猶大王面前所讀的那書上的一切咒詛，降災難給這地方及這裡的居民。</span>
<span className="v" id="v25" data-v="25" data-xref="耶利米書 7:20; 馬可福音 9:43–48; 那鴻書 1:6"> 因為他們背棄我，給其他神明燒香，製造偶像惹我發怒，所以我的怒火要傾倒在這地方，絕不止息。』</span>
<span className="v" id="v26" data-v="26" data-xref="歷代志下 34:23; 歷代志下 34:21"> 你們告訴差你們來求問耶和華的猶大王，『至於你所聽見的那些話，以色列的上帝耶和華說，</span>
<span className="v" id="v27" data-v="27" data-xref="歷代志下 32:26; 以西結書 9:4; 詩篇 34:18"> 因為你聽到我對這地方及其居民的警告，便悔改，在我面前謙卑、撕裂衣服，向我哭泣，我才垂聽你的禱告。這是我耶和華說的。</span>
<span className="v" id="v28" data-v="28" data-xref="以賽亞書 39:8; 詩篇 37:37; 列王紀上 21:29"> 我會讓你平安入土到你祖先那裡，你不會看到我要降給這地方及這裡居民的一切災難。』」他們便回去稟告王。</span>
</div>
</div>

## 約西亞立約順服上帝

<div className="bt">
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="列王紀下 23:1–3; 歷代志下 30:2; 馬可福音 14:8"> 於是，王派人召集猶大和耶路撒冷的所有長老。</span>
<span className="v" id="v30" data-v="30" data-xref="出埃及記 24:7; 列王紀下 23:2; 歷代志下 34:15"> 王與猶大人和耶路撒冷的居民、祭司和利未人等全體民眾，不論貴賤，一同上到耶和華的殿。王把在耶和華殿中發現的約書讀給他們聽。</span>
<span className="v" id="v31" data-v="31" data-xref="歷代志下 23:16; 列王紀下 23:3; 列王紀下 11:14"> 王站在自己的位置上，在耶和華面前立約，要全心全意地跟隨耶和華，遵從祂的一切誡命、法度和律例，履行約書上的規定。</span>
<span className="v" id="v32" data-v="32" data-xref="歷代志下 30:12; 耶利米書 3:10; 歷代志下 14:4"> 他使耶路撒冷和便雅憫的人都遵行這約。於是，耶路撒冷的居民都遵行他們祖先的上帝的約。</span>
<span className="v" id="v33" data-v="33" data-xref="歷代志下 34:3–7; 約書亞記 24:31; 列王紀下 23:4–20"> 約西亞除去以色列境內所有的可憎之物，又吩咐所有住在以色列的人都事奉他們的上帝耶和華。約西亞在世時，他們都沒有偏離他們祖先的上帝耶和華。</span>
</div>
</div>

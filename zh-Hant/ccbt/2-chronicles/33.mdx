## 猶大王瑪拿西

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀下 21:1–18; 歷代志上 3:13; 以賽亞書 3:12"> 瑪拿西十二歲登基，在耶路撒冷執政五十五年。</span>
<span className="v" id="v2" data-v="2" data-xref="歷代志下 28:3; 申命記 18:9; 列王紀下 17:11"> 他做耶和華視為惡的事，效法耶和華在以色列人面前趕走的外族人的可憎行徑。</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 16:21; 申命記 17:3; 歷代志下 31:1"> 他重建他父親希西迦拆毀的邱壇，為巴力築造祭壇，製造亞舍拉神像，並祭拜和供奉天上的萬象。</span>
<span className="v" id="v4" data-v="4" data-xref="歷代志下 7:16; 列王紀上 8:29; 申命記 12:11"> 耶和華曾指著祂的殿說：「我的名必永遠在耶路撒冷，」他卻在耶和華的殿內建造異教的祭壇。</span>
<span className="v" id="v5" data-v="5" data-xref="歷代志下 4:9; 耶利米書 32:34–35; 以西結書 8:7–18"> 他在耶和華殿的兩個院子裡為天上萬象建造祭壇。</span>
<span className="v" id="v6" data-v="6" data-xref="利未記 18:21; 利未記 20:6; 歷代志下 28:3"> 他還在欣嫩子谷把自己的兒子燒死，獻作祭物。他行邪術、占卜、觀兆，求問靈媒和巫師，做了許多耶和華視為惡的事，惹耶和華發怒。</span>
<span className="v" id="v7" data-v="7" data-xref="歷代志下 33:4; 歷代志下 7:16; 列王紀上 11:13"> 他雕刻神像，放在上帝的殿中。關於這殿，上帝曾對大衛和他兒子所羅門說：「我從以色列各支派中選擇了這殿和耶路撒冷，我的名要永遠立在這裡。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳記下 7:10; 申命記 5:31–1; 利未記 8:36"> 只要以色列人謹遵我藉著摩西頒給他們的一切法度、律例和典章，我就不再把他們從我賜給他們祖先的土地上趕走。」</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀下 24:3–4; 箴言 29:12; 歷代志下 33:2"> 瑪拿西誘使猶大人和耶路撒冷的居民作惡，比耶和華在以色列人面前所毀滅的各族更嚴重。</span>
</div>
</div>

## 瑪拿西悔改

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="歷代志下 36:15–16; 耶利米書 44:4–5; 撒迦利亞書 1:4"> 耶和華警告瑪拿西和他的百姓，他們卻不肯聽從。</span>
<span className="v" id="v11" data-v="11" data-xref="申命記 28:36; 歷代志下 36:6; 尼希米記 9:32"> 所以，耶和華就差遣亞述王的將領來攻擊他們，他們捉住瑪拿西，把他用鉤子鉤著、用銅鏈鎖著押往巴比倫。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及記 10:3; 詩篇 50:15; 歷代志下 32:26"> 在困苦中，瑪拿西祈求他的上帝耶和華的幫助，並且在他祖先的上帝面前極其謙卑。</span>
<span className="v" id="v13" data-v="13" data-xref="歷代志上 5:20; 但以理書 4:25; 馬太福音 7:7–8"> 耶和華應允他的禱告，垂聽他的懇求，使他返回耶路撒冷繼續做王。瑪拿西這才明白耶和華是上帝。</span>
<span className="v" id="v14" data-v="14" data-xref="歷代志下 27:3; 列王紀上 1:33; 尼希米記 3:3"> 這事以後，瑪拿西重建大衛城的外牆，從谷中基訓泉的西邊直到魚門口，環繞俄斐勒，築高城牆。他又派將領駐紮猶大各堅城。</span>
<span className="v" id="v15" data-v="15" data-xref="歷代志下 33:3–7; 何西阿書 14:1–3; 列王紀下 21:7"> 瑪拿西將偶像和外族人的神像從耶和華的殿中除去，又把他在聖殿山和耶路撒冷築造的一切祭壇全部拆掉，扔在城外。</span>
<span className="v" id="v16" data-v="16" data-xref="歷代志下 14:4; 列王紀上 18:30; 歷代志下 33:9"> 他重建耶和華的祭壇，在上面獻平安祭和感恩祭，又吩咐猶大人事奉以色列的上帝耶和華。</span>
<span className="v" id="v17" data-v="17" data-xref="歷代志下 32:12; 列王紀上 22:43; 列王紀下 15:4"> 然而，眾人仍然在邱壇獻祭，只是獻給他們的上帝耶和華。</span>
</div>
</div>

## 瑪拿西逝世

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="歷代志下 33:19; 歷代志下 33:12–13; 阿摩司書 7:12"> 瑪拿西其他的事、他向上帝的禱告和先見奉以色列的上帝耶和華的名對他說的話，都記在《以色列列王史》上。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行傳 9:11; 約翰一書 1:9; 但以理書 5:22"> 他的禱告，上帝的答覆，他在謙卑下來之前的罪惡和不忠，他在哪裡修築邱壇以及設立亞舍拉神像和其他偶像的事，都記在《先知書》<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="《先知書》或譯《何賽的書》。">a</a></sup>上。</span>
<span className="v" id="v20" data-v="20" data-xref="馬太福音 1:10; 歷代志下 32:33; 列王紀下 21:18–25"> 瑪拿西與祖先同眠後，葬在宮內，他兒子亞們繼位。</span>
</div>
</div>

## 亞們做猶大王

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="雅各書 4:13–15; 路加福音 12:19–20; 歷代志下 33:1"> 亞們二十二歲登基，在耶路撒冷執政兩年。</span>
<span className="v" id="v22" data-v="22" data-xref="列王紀下 21:20; 以西結書 20:18; 列王紀下 21:1–11"> 亞們像他父親瑪拿西一樣做耶和華視為惡的事。他祭拜和供奉他父親瑪拿西製造的一切偶像。</span>
<span className="v" id="v23" data-v="23" data-xref="歷代志下 33:12; 歷代志下 33:19; 耶利米書 7:26"> 可是，亞們沒有像他父親瑪拿西一樣在耶和華面前謙卑下來。相反，他犯的罪越來越多。</span>
<span className="v" id="v24" data-v="24" data-xref="羅馬書 11:22; 歷代志下 25:27–28; 歷代志下 24:25–26"> 他的臣僕謀反，在王宮裡殺了他。</span>
<span className="v" id="v25" data-v="25" data-xref="民數記 35:31; 歷代志下 34:1; 歷代志下 36:1"> 民眾殺死那些背叛亞們王的人，讓他兒子約西亞接續他作王。</span>
</div>
</div>

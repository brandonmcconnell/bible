## 約沙法禱告退敵

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="詩篇 83:5–8; 以賽亞書 16:6; 歷代志下 32:1"> 後來摩押人、亞捫人同一些米烏尼人<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「米烏尼人」出現在古希臘譯本，但希伯來文是「亞捫人」。">a</a></sup>一起來攻打約沙法。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 14:7; 撒母耳記上 23:29; 約書亞記 15:62"> 有人稟告約沙法說：「有一支大軍從死海對岸的以東<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="「以東」希伯來文是「亞蘭」。">b</a></sup>殺來，已經攻到哈洗遜·他瑪。」哈洗遜·他瑪就是隱·基底。</span>
<span className="v" id="v3" data-v="3" data-xref="但以理書 9:3; 歷代志下 19:3; 撒母耳記上 7:6"> 約沙法很害怕，決定尋求耶和華，在整個猶大宣告禁食。</span>
<span className="v" id="v4" data-v="4" data-xref="詩篇 50:15; 詩篇 60:10–12; 詩篇 69:35"> 猶大人聚集起來尋求耶和華。他們從猶大各城前來尋求耶和華。</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀下 19:15–19; 歷代志下 6:12–13; 歷代志下 34:31"> 約沙法站在耶和華殿的新院前，在猶大和耶路撒冷的會眾中，</span>
<span className="v" id="v6" data-v="6" data-xref="申命記 4:39; 歷代志上 29:11–12; 但以理書 4:17"> 說：「我們祖先的上帝耶和華啊，你不是住在天上的上帝嗎？你主宰萬邦萬國，你手中有權柄和能力，無人能抵擋你。</span>
<span className="v" id="v7" data-v="7" data-xref="以賽亞書 41:8; 雅各書 2:23; 詩篇 44:2"> 我們的上帝啊，你不是曾經在你的以色列子民面前驅逐這地方的居民，把這片土地賜給你的朋友亞伯拉罕的後裔永遠作產業嗎？</span>
<span className="v" id="v8" data-v="8" data-xref="歷代志下 6:10; 歷代志下 2:4"> 你的子民在這裡居住，為你的名建造聖所，說，</span>
<span className="v" id="v9" data-v="9" data-xref="歷代志下 6:28–30; 歷代志下 6:20; 列王紀上 8:33"> 『我們若遭遇禍患，無論是戰禍、瘟疫或饑荒，在急難中站在這殿前向你呼求，你必定垂聽，施行拯救，因為你的名在這殿裡。』</span>
<span className="v" id="v10" data-v="10" data-xref="申命記 2:19; 申命記 2:4–5; 申命記 2:9"> 「從前以色列人離開埃及的時候，你不准他們侵犯亞捫人、摩押人和來自西珥山的人，他們就繞道行進，沒有毀滅這些人。</span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 83:3–12; 士師記 11:23–24; 耶利米書 18:20"> 但現在這些人竟以怨報德，要把我們從你賜給我們作產業的地方趕走。</span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 121:1–2; 詩篇 25:15; 詩篇 141:8"> 我們的上帝啊，難道你不懲罰他們嗎？面對前來攻擊的大軍，我們無力抵擋，不知道該怎麼辦，我們只有仰望你。」</span>
<span className="v" id="v13" data-v="13" data-xref="以斯拉記 10:1; 使徒行傳 21:5; 申命記 29:10"> 猶大人都與他們的妻子、兒女和嬰孩站在耶和華面前。</span>
<span className="v" id="v14" data-v="14" data-xref="歷代志下 15:1; 歷代志下 24:20; 使徒行傳 10:31"> 這時，耶和華的靈降在雅哈悉身上。雅哈悉是利未人亞薩的後裔、瑪探雅的玄孫、耶利的曾孫、比拿雅的孫子、撒迦利雅的兒子。</span>
<span className="v" id="v15" data-v="15" data-xref="歷代志下 32:7–8; 申命記 31:6; 出埃及記 14:13–14"> 他說：「全體猶大人、耶路撒冷的居民和約沙法王啊，你們要留心聽！耶和華對你們說，『你們不要因敵軍強大而恐懼驚慌，因為戰爭的勝敗不在於你們，而在於上帝。</span>
<span className="v" id="v16" data-v="16"> 明天你們下去迎敵，敵軍會從洗斯坡上來，你們一定會在耶魯伊勒曠野前面的谷口遇見他們。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及記 14:13–14; 歷代志下 15:2; 以賽亞書 41:10"> 你們不用與他們交戰，只要守住陣勢，站立不動，看耶和華為你們施行拯救。猶大人和耶路撒冷人啊，不要恐懼，不要驚慌，明天只管出去迎敵，耶和華必與你們同在！』」</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及記 4:31; 歷代志下 7:3; 創世記 24:26"> 於是，約沙法面伏於地，所有猶大人和耶路撒冷的居民也都俯伏在耶和華面前敬拜祂。</span>
<span className="v" id="v19" data-v="19" data-xref="歷代志上 15:16–22; 歷代志上 16:42; 歷代志上 16:5"> 哥轄族和可拉族的利未人都站起來，高聲讚美以色列的上帝耶和華。</span>
<span className="v" id="v20" data-v="20" data-xref="羅馬書 8:31; 約翰福音 14:1; 約翰福音 11:40"> 第二天清晨，眾人起來去提哥亞的曠野。他們出發的時候，約沙法站著說：「猶大人和耶路撒冷的居民啊，請聽我說！要信靠你們的上帝耶和華，你們就必堅立；要相信祂的先知，你們就必得勝。」</span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 107:1; 詩篇 106:1; 歷代志下 5:13"> 約沙法與眾人商議後，就派歌樂手穿上聖潔的禮服走在軍隊前面，讚美耶和華，說：「你們要稱謝耶和華，因祂的慈愛永遠長存！」</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳記上 14:20; 以賽亞書 19:2; 以西結書 38:21"> 他們開始唱歌讚美的時候，耶和華就派伏兵擊殺前來攻打猶大的亞捫人、摩押人和來自西珥山的人，打敗了他們。</span>
<span className="v" id="v23" data-v="23" data-xref="士師記 7:22; 撒母耳記上 14:20; 以西結書 35:2–3"> 原來亞捫人和摩押人攻擊來自西珥山的人，消滅了他們，然後亞捫人和摩押人又自相殘殺。</span>
<span className="v" id="v24" data-v="24" data-xref="以賽亞書 37:36; 詩篇 110:6; 歷代志上 5:22"> 猶大人來到曠野的瞭望塔俯瞰那支大軍，發現敵軍屍橫遍野，無一逃脫。</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳記上 30:19–20; 列王紀下 7:9–16; 民數記 31:15"> 約沙法和他的百姓前去拾財物，發現屍體中有許多財物、衣服和貴重物品，多得拿不完。他們拾了三天才拾完。</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及記 17:15; 創世記 32:20; 歷代志下 5:9"> 第四天，他們聚集到一個山谷，一起稱頌耶和華。那裡從此名叫比拉迦<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="「比拉迦」就是稱讚的意思。">c</a></sup>谷，直到今天。</span>
<span className="v" id="v27" data-v="27" data-xref="尼希米記 12:43; 希伯來書 6:20; 詩篇 30:1"> 猶大人和耶路撒冷人在約沙法的帶領下，歡歡喜喜地返回耶路撒冷，因為耶和華使他們戰勝了仇敵。</span>
<span className="v" id="v28" data-v="28" data-xref="啟示錄 14:2–3; 詩篇 57:8; 詩篇 92:3"> 他們一路彈琴、鼓瑟、吹號回到耶路撒冷，進入耶和華的殿。</span>
<span className="v" id="v29" data-v="29" data-xref="歷代志下 17:10; 列王紀下 7:6; 出埃及記 23:27"> 列邦列國聽聞耶和華打敗了以色列的敵人，都很懼怕。</span>
<span className="v" id="v30" data-v="30" data-xref="歷代志下 15:15; 歷代志下 14:6–7; 撒母耳記下 7:1"> 因此，約沙法執政期間國家太平，因為他的上帝賜他四境平安。</span>
</div>

## 約沙法逝世

<div className="bt">
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="列王紀上 22:41–44"> 約沙法三十五歲登基做猶大王，在耶路撒冷執政二十五年。他母親叫阿蘇巴，是示利希的女兒。</span>
<span className="v" id="v32" data-v="32" data-xref="歷代志下 14:2–5; 列王紀上 15:11; 歷代志下 14:11–13"> 約沙法事事效法他父親亞撒，不偏不離，做耶和華視為正的事。</span>
<span className="v" id="v33" data-v="33" data-xref="歷代志下 17:6; 歷代志下 19:3; 歷代志下 12:14"> 但他沒有拆除邱壇，民眾還沒有全心歸向他們祖先的上帝。</span>
<span className="v" id="v34" data-v="34" data-xref="列王紀上 16:1; 歷代志下 19:2; 列王紀上 16:7"> 約沙法其他的事蹟自始至終都記在哈拿尼的兒子耶戶的史記上。耶戶的史記收錄在《以色列列王史》上。</span>
<span className="v" id="v35" data-v="35" data-xref="列王紀上 22:48–49; 列王紀下 1:2–16"> 後來，猶大王約沙法與作惡多端的以色列王亞哈謝聯盟。</span>
<span className="v" id="v36" data-v="36" data-xref="列王紀上 10:22; 歷代志下 9:21; 列王紀上 9:26"> 他們在以旬·迦別造船，要去他施。</span>
<span className="v" id="v37" data-v="37" data-xref="箴言 13:20; 歷代志下 19:2; 歷代志下 9:21"> 瑪利沙人多大瓦的兒子以利以謝向約沙法預言說：「因為你與亞哈謝聯盟，耶和華必破壞你所造的船隻。」那些船隻果然壞了，無法前往他施。</span>

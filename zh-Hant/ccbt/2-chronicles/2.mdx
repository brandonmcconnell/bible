## 預備建聖殿

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀上 5:5; 歷代志上 22:10; 列王紀上 7:1"> 所羅門決定為耶和華的名建造殿宇，也為自己興建王宮。</span>
<span className="v" id="v2" data-v="2" data-xref="歷代志下 2:18; 列王紀上 5:15–16"> 他徵用七萬名搬運工、八萬名在山上鑿石的匠人、三千六百名監工，</span>
<span className="v" id="v3" data-v="3" data-xref="歷代志上 14:1; 撒母耳記下 5:11; 列王紀上 5:1–11"> 並傳信給泰爾王希蘭，說：「你曾運香柏木給我父親建造王宮，請你也照樣幫助我。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及記 30:7; 出埃及記 25:30; 歷代志下 2:1"> 現在，我要為我的上帝耶和華的名建一座殿，我要把殿獻給祂，在祂面前燒芬芳的香，經常獻上供餅，在每天早晚、安息日、朔日<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「朔日」即每月初一。">a</a></sup>，以及我們的上帝耶和華所定的節期獻上燔祭。這是以色列人永遠當守的律例。</span>
<span className="v" id="v5" data-v="5" data-xref="歷代志上 16:25; 出埃及記 15:11; 詩篇 135:5"> 我要建造的殿宇極其宏偉，因為我們的上帝超越一切神明。</span>
<span className="v" id="v6" data-v="6" data-xref="以賽亞書 66:1; 歷代志下 6:18; 列王紀上 8:27"> 諸天尚且容不下祂，誰能為祂建造殿宇呢？我是誰，怎能為祂建造殿宇呢？我不過是建個向祂燒香的地方。</span>
<span className="v" id="v7" data-v="7" data-xref="歷代志下 2:13–14; 歷代志上 22:15–16; 出埃及記 31:3–5"> 現在，請你派一位巧匠來，他要懂得雕刻，會用金銀銅鐵鑄造物品，會編織紫色、朱紅色和藍色的布，好與我父大衛在猶大和耶路撒冷所預備的巧匠一起工作。</span>
<span className="v" id="v8" data-v="8" data-xref="列王紀上 5:6; 列王紀上 10:11; 歷代志下 9:10–11"> 也請你從黎巴嫩運些香柏木、松木和檀香木來，因為我知道你的僕人擅長砍伐黎巴嫩的樹木。我會派人與你的僕人一起工作。</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀上 9:8; 歷代志下 2:5; 歷代志下 7:21"> 我要建的殿宇非常宏偉，所以需要的木料非常多。</span>
<span className="v" id="v10" data-v="10" data-xref="列王紀上 5:11; 以斯拉記 7:22; 羅馬書 13:7–8"> 我會供給你的伐木工人四百四十萬升小麥、四百四十萬升大麥、四十四萬升酒和四十四萬升油。」</span>
<span className="v" id="v11" data-v="11" data-xref="列王紀上 10:9; 歷代志下 9:8; 詩篇 72:17"> 泰爾王希蘭寫信給所羅門說：「耶和華愛祂的子民，所以立你做他們的王。</span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 33:6; 彼得前書 1:3; 啟示錄 4:11"> 創造天地的以色列的上帝耶和華當受稱頌！祂賜給大衛王一個有智慧、謀略和悟性的兒子來為耶和華建殿，也為他自己建造王宮。</span>
<span className="v" id="v13" data-v="13" data-xref="歷代志下 4:16"> 現在，我派聰明能幹的巧匠戶蘭去你那裡。</span>
<span className="v" id="v14" data-v="14" data-xref="歷代志下 2:7; 出埃及記 31:3–4; 列王紀上 7:13–14"> 他的母親是但支派的人，父親是泰爾人。他精於雕刻和設計，善用金銀銅鐵和木石製造物品，又會編織細麻布和紫色、藍色、朱紅色的布。你可以讓他與你的工匠和你父親大衛的工匠一起工作。</span>
<span className="v" id="v15" data-v="15" data-xref="歷代志下 2:10; 列王紀上 5:11"> 現在，請我主把許諾的小麥、大麥、油和酒運給僕人。</span>
<span className="v" id="v16" data-v="16" data-xref="約書亞記 19:46; 列王紀上 5:8–9; 以斯拉記 3:7"> 我們會在黎巴嫩砍伐你需要的木材，紮成木筏，經海道運到約帕，你可以從那裡將木材轉運到耶路撒冷。」</span>
<span className="v" id="v17" data-v="17" data-xref="歷代志上 22:2; 列王紀上 5:13–16; 歷代志下 8:7–8"> 所羅門依照他父親大衛的方法，統計所有寄居在以色列的外族人，共有十五萬三千六百人。</span>
<span className="v" id="v18" data-v="18" data-xref="歷代志下 2:2"> 他指派其中的七萬人做搬運工，八萬人在山上採鑿石頭，三千六百人做監工。</span>

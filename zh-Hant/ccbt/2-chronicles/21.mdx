## 猶大王約蘭

<div className="bt">
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="歷代志下 12:6; 歷代志下 23:2; 歷代志下 24:5"> 亞撒利雅、耶歇、撒迦利雅、亞撒列夫、米迦勒和示法提雅是約蘭的兄弟、猶大王約沙法的兒子。</span>
<span className="v" id="v3" data-v="3" data-xref="歷代志下 11:23; 申命記 21:15–17; 歷代志下 11:5"> 他們的父親賜給他們許多金銀財寶和猶大境內的堅城，但將王位賜給了約蘭，因為他是長子。</span>
<span className="v" id="v4" data-v="4" data-xref="士師記 9:5; 歷代志下 21:17; 創世記 4:8"> 約蘭登基，鞏固了王位後，就用刀殺了他所有的兄弟和一些以色列的首領。</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀下 8:17–22"> 約蘭三十二歲登基，在耶路撒冷執政八年。</span>
<span className="v" id="v6" data-v="6" data-xref="歷代志下 18:1; 列王紀上 12:28–30; 列王紀下 8:18"> 他與亞哈家一樣步以色列諸王的後塵，因為他娶了亞哈的女兒為妻，做耶和華視為惡的事。</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀上 11:36; 詩篇 132:17–18; 撒母耳記下 7:12–17"> 但耶和華不願毀滅大衛家，因為祂曾與大衛立約，應許讓大衛和他的子孫永遠做王。</span>
<span className="v" id="v8" data-v="8" data-xref="歷代志下 21:10; 歷代志下 20:22–23; 創世記 27:40"> 約蘭執政期間，以東人脫離猶大的統治，自己立王。</span>
<span className="v" id="v9" data-v="9"> 約蘭率將領及所有戰車前去討伐，結果被以東人包圍。但他們乘夜突出重圍。</span>
<span className="v" id="v10" data-v="10" data-xref="歷代志下 15:2; 耶利米書 2:13; 歷代志下 13:10"> 以東人至今仍脫離猶大的統治，立拿人也在那時候叛變了，因為約蘭背棄了他祖先的上帝耶和華。</span>
<span className="v" id="v11" data-v="11" data-xref="利未記 20:5; 列王紀上 11:7; 利未記 17:7"> 約蘭在猶大的山上修建邱壇，引誘耶路撒冷的居民與假神苟合，使猶大人步入歧途。</span>
<span className="v" id="v12" data-v="12" data-xref="歷代志下 14:2–5; 歷代志下 17:3–4; 列王紀下 2:1"> 以利亞先知寫信給約蘭說：「你祖先大衛的上帝耶和華說，『你沒有效法你父親約沙法，也沒有效法猶大王亞撒，</span>
<span className="v" id="v13" data-v="13" data-xref="歷代志下 21:4; 歷代志下 21:11; 列王紀上 16:30–33"> 而是重蹈以色列諸王的覆轍，與亞哈家一樣，引誘猶大人和耶路撒冷的居民與假神苟合，還殺了比你好的兄弟。</span>
<span className="v" id="v14" data-v="14" data-xref="利未記 26:21; 出埃及記 20:5; 何西阿書 5:11"> 因此，耶和華要降大災禍給你的人民、兒女、妻妾及一切所有。</span>
<span className="v" id="v15" data-v="15" data-xref="歷代志下 21:18–19; 使徒行傳 1:18; 申命記 28:67"> 你必患嚴重的腸病，並且日益加重，直到你的腸子掉出來。』」</span>
<span className="v" id="v16" data-v="16" data-xref="歷代志下 17:11; 歷代志下 33:11; 列王紀上 11:14"> 耶和華驅使非利士人和古實附近的阿拉伯人攻打約蘭。</span>
<span className="v" id="v17" data-v="17" data-xref="歷代志下 22:1; 歷代志下 22:6; 歷代志下 25:23"> 他們起兵攻打猶大，侵入境內，擄走了王宮裡的所有財物以及約蘭的兒子和妻妾，只留下他最小的兒子約哈斯。</span>
<span className="v" id="v18" data-v="18" data-xref="歷代志下 21:15; 使徒行傳 12:23; 列王紀下 9:29"> 這事以後，耶和華使約蘭患了無法醫治的腸病，</span>
<span className="v" id="v19" data-v="19" data-xref="歷代志下 16:14; 耶利米書 34:5"> 日益加重，兩年後腸子掉了出來，他痛苦地死去。他的百姓沒有像對待他祖先那樣向他焚火致哀。</span>
<span className="v" id="v20" data-v="20" data-xref="耶利米書 22:18; 歷代志下 28:27; 耶利米書 22:28"> 約蘭三十二歲登基，在耶路撒冷執政八年。他死後無人向他致哀。他葬在大衛城，但沒有葬在王陵裡。</span>

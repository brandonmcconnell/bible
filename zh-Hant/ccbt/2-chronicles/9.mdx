## 示巴女王拜訪所羅門

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="馬太福音 12:42; 路加福音 11:31; 列王紀上 10:1–13"> 示巴女王聽聞所羅門的名聲，便來用難題考問他。她率領許多隨從，用駱駝馱著香料、寶石和大量黃金，到耶路撒冷晉見所羅門，與所羅門談論她心中的疑問。</span>
<span className="v" id="v2" data-v="2" data-xref="約翰福音 15:15; 列王紀上 3:12; 馬可福音 4:34"> 所羅門解答了她所有的問題，沒有一樣難得住他。</span>
<span className="v" id="v3" data-v="3" data-xref="歷代志下 3:1–4; 列王紀上 10:3; 列王紀上 6:1–7"> 示巴女王看見所羅門智慧非凡，又看見他建的宮殿、</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 12:37; 列王紀上 4:22–23; 詩篇 143:7"> 席上的美味、入座的群臣、侍立的僕人、酒侍、他們的服裝，以及他在耶和華殿裡獻的燔祭，感到萬分驚奇。</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀上 10:6"> 她對王說：「我在本國聽到的有關你的功業和智慧原來都是真的。</span>
<span className="v" id="v6" data-v="6" data-xref="列王紀上 10:7; 歷代志下 9:5; 列王紀上 4:34"> 若不是親眼目睹，我不會相信。其實我聽到的還不到一半！你的智慧遠超過我聽到的傳聞。</span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 27:4; 箴言 3:14; 箴言 10:21"> 你的百姓真有福氣！你的臣僕經常侍立在你面前聆聽智言慧語，真有福氣！</span>
<span className="v" id="v8" data-v="8" data-xref="歷代志下 2:11; 歷代志上 29:23; 以賽亞書 32:1–2"> 你的上帝耶和華當受稱頌！祂喜愛你，立你坐在祂的寶座上替祂掌權。因為你的上帝愛以色列人，要使他們永遠堅立，所以立你為他們的王，使你秉公行義。」</span>
<span className="v" id="v9" data-v="9" data-xref="歷代志下 9:1; 詩篇 72:10; 詩篇 72:15"> 示巴女王將八萬兩黃金、大量香料和寶石獻給所羅門王。再無人像示巴女王那樣獻給所羅門王那麼多香料。</span>
<span className="v" id="v10" data-v="10" data-xref="歷代志下 8:18; 列王紀上 10:11; 列王紀上 10:22"> 希蘭的僕人和所羅門的僕人從俄斐運來黃金、檀香木和寶石。</span>
<span className="v" id="v11" data-v="11" data-xref="列王紀上 10:12; 歷代志上 23:5; 詩篇 92:1–3"> 所羅門王用這些檀香木建造耶和華的殿和王宮的階梯，又為歌樂手製作琴瑟。在猶大從來沒有見過這樣的物品。</span>
<span className="v" id="v12" data-v="12" data-xref="列王紀上 10:13; 以弗所書 3:20; 詩篇 20:4"> 所羅門王滿足了示巴女王的一切要求，回贈她的禮物超過了她帶來的。之後，女王和隨從就回示巴去了。</span>
</div>
</div>

## 所羅門王的財富

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="詩篇 72:15; 詩篇 68:29; 列王紀上 10:14–28"> 所羅門每年收到的黃金約四十五萬兩，</span>
<span className="v" id="v14" data-v="14" data-xref="詩篇 68:29; 詩篇 72:10"> 此外還有商人、阿拉伯諸王和國中各總督送給他的金銀。</span>
<span className="v" id="v15" data-v="15" data-xref="列王紀上 10:16–17; 歷代志下 12:9–10"> 所羅門王用錘好的金子打造了二百面大盾牌，每面用一百四十兩金子；</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀上 7:2"> 又用錘好的金子打造了三百面小盾牌，每面用七十兩金子，全部放在黎巴嫩林宮。</span>
<span className="v" id="v17" data-v="17" data-xref="列王紀上 10:18–20; 詩篇 45:8; 啟示錄 20:11"> 王又造了一個象牙大寶座，外面用純金包裹。</span>
<span className="v" id="v18" data-v="18" data-xref="民數記 24:9; 啟示錄 5:5; 民數記 23:24"> 這寶座有六級臺階，又有金腳凳與寶座相連，寶座兩旁有扶手，扶手兩邊各站著一頭獅子，</span>
<span className="v" id="v19" data-v="19" data-xref="馬太福音 19:28; 啟示錄 21:12"> 六級臺階上共站著十二頭獅子，每級臺階兩端各站一頭。這寶座舉世無雙。</span>
<span className="v" id="v20" data-v="20" data-xref="列王紀上 10:21; 以斯帖記 1:7; 歷代志下 9:27"> 所羅門王所有的杯子都是金的，黎巴嫩林宮裡所有的器皿都是純金的，沒有一件是用銀子造的，因為所羅門年間銀子不算什麼。</span>
<span className="v" id="v21" data-v="21" data-xref="列王紀上 22:48; 約伯記 39:13; 列王紀上 10:22"> 王有船隊與希蘭的僕人一起出海去他施，每三年就運回金銀、象牙、猿猴和孔雀。</span>
<span className="v" id="v22" data-v="22" data-xref="歷代志下 1:12; 詩篇 89:27; 列王紀上 4:30–31"> 所羅門王的財富和智慧超過天下諸王。</span>
<span className="v" id="v23" data-v="23" data-xref="雅各書 1:5; 雅各書 3:17; 箴言 2:6"> 天下的君王都紛紛來朝見所羅門，聆聽上帝賜給他的智言慧語。</span>
<span className="v" id="v24" data-v="24" data-xref="列王紀上 10:25; 約伯記 42:11; 詩篇 72:10"> 他們年年都帶來禮物，有金銀器皿、衣服、兵器、香料和騾馬。</span>
<span className="v" id="v25" data-v="25" data-xref="列王紀上 4:26; 列王紀上 10:26; 歷代志下 1:14"> 所羅門有四千個安置戰車和馬匹的棚，有一萬二千名騎兵，駐紮在屯車城和他所在的耶路撒冷。</span>
<span className="v" id="v26" data-v="26" data-xref="列王紀上 4:21; 創世記 15:18; 列王紀上 4:24"> 所羅門統管從幼發拉底河到非利士地區，遠至埃及邊境的諸王。</span>
<span className="v" id="v27" data-v="27" data-xref="歷代志下 1:15–17; 以賽亞書 9:10; 列王紀上 10:27–29"> 王使耶路撒冷的銀子多如石頭，使香柏木多如丘陵的桑樹。</span>
<span className="v" id="v28" data-v="28" data-xref="歷代志下 1:16; 列王紀上 10:28; 以賽亞書 31:1"> 所羅門的馬匹都是從埃及和其他國家運來的。</span>
</div>
</div>

## 所羅門逝世

<div className="bt">
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="歷代志上 29:29; 列王紀上 11:41–43; 列王紀上 11:29"> 所羅門其他的事蹟自始至終都記在拿單先知的史記、示羅人亞希雅的《預言書》和易多先見論尼八的兒子耶羅波安的《啟示書》中。</span>
<span className="v" id="v30" data-v="30" data-xref="列王紀上 11:42–43"> 所羅門在耶路撒冷統治整個以色列四十年，</span>
<span className="v" id="v31" data-v="31" data-xref="列王紀上 2:10; 撒母耳記下 7:12; 列王紀上 1:21"> 他與祖先同眠後，葬在他父親大衛的城裡。他兒子羅波安繼位。</span>
</div>

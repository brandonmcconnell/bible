## 建造聖殿

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歷代志上 21:18; 創世記 22:14; 歷代志上 22:1"> 所羅門在耶路撒冷的摩利亞山上動工興建耶和華的殿，殿址在耶布斯人阿珥楠的麥場，就是大衛指定的地方。耶和華曾在那裡向他父親大衛顯現。</span>
<span className="v" id="v2" data-v="2" data-xref="列王紀上 6:1"> 所羅門在執政第四年二月二日動工建殿。</span>
<span className="v" id="v3" data-v="3" data-xref="列王紀上 6:2–3; 歷代志上 28:11–19"> 按照古時的尺度，他建造的上帝殿宇的地基長二十七米，寬九米。</span>
<span className="v" id="v4" data-v="4" data-xref="約翰福音 10:23; 使徒行傳 5:12; 使徒行傳 3:11"> 殿前的門廊長九米，與殿的寬度一樣，高九米<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「高九米」希伯來文是「高五十四米」。">a</a></sup>，裡面都貼上純金。</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀上 6:15–17; 列王紀上 6:21–22"> 大殿裡鑲上松木板，貼上純金，又刻上棕樹和鏈子。</span>
<span className="v" id="v6" data-v="6" data-xref="以賽亞書 54:11–12; 歷代志上 29:8; 啟示錄 21:18–21"> 所羅門用寶石和巴瓦音的純金裝飾聖殿。</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀上 6:20–22; 出埃及記 26:29; 以西結書 7:20"> 殿的棟梁、牆壁、門檻和門扇也都貼上金子；牆上還刻上基路伯天使。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="出埃及記 26:33; 列王紀上 6:19–20; 列王紀上 6:16"> 所羅門又動工建造至聖所，長九米，寬九米，與殿的寬度一樣，裡面共貼了四十二萬兩純金。</span>
<span className="v" id="v9" data-v="9" data-xref="歷代志上 28:11"> 所用的金釘重十二兩。樓房也都貼上了金子。</span>
<span className="v" id="v10" data-v="10" data-xref="列王紀上 6:23–28; 出埃及記 25:18"> 他又在至聖所製造兩個基路伯天使，包上金子。</span>
<span className="v" id="v11" data-v="11"> 兩個基路伯天使的翅膀共九米長，每個翅膀長兩米二。兩個基路伯天使面向殿站立，他們展開的翅膀共九米長，各有一個翅膀觸到殿牆，一個翅膀互相連接。</span>
<span className="v" id="v14" data-v="14" data-xref="希伯來書 9:3; 希伯來書 10:20; 馬太福音 27:51"> 他用細麻和藍色、紫色、朱紅色毛線織成幔子，上面繡上基路伯天使。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="列王紀上 7:15–24; 耶利米書 52:20–23"> 所羅門在殿前造了兩根柱子，每根高八米，上面的柱冠高兩米二。</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀上 7:20; 列王紀上 6:21"> 他造了鏈子<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="「他造了鏈子」希伯來文是「他在聖所內造了鏈子」。">b</a></sup>，裝飾在柱冠上。他又造了一百個石榴，安在鏈子上。</span>
<span className="v" id="v17" data-v="17" data-xref="列王紀上 7:21"> 他把兩根柱子一南一北立在殿前，南邊那根稱為雅斤，北邊那根稱為波阿斯。</span>
</div>
</div>

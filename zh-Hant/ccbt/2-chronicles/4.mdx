## 聖殿的器具

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀上 8:64; 以西結書 43:13–17; 列王紀上 9:25"> 所羅門造了一座銅壇，長九米，寬九米，高四米半。</span>
<span className="v" id="v2" data-v="2" data-xref="提多書 3:5; 撒迦利亞書 13:1; 出埃及記 30:18–21"> 他又鑄了一個圓形銅海，高兩米二，直徑四米半，周長十三米半。</span>
<span className="v" id="v3" data-v="3" data-xref="以西結書 1:10; 以西結書 10:14; 哥林多前書 9:9–10"> 銅海邊緣下面有兩圈牛的圖案，每四十五釐米有十頭牛，是跟銅海一起鑄造的。</span>
<span className="v" id="v4" data-v="4" data-xref="馬太福音 28:19–20; 啟示錄 21:14; 馬可福音 16:15"> 有十二頭銅牛馱著銅海，三頭向北，三頭向西，三頭向南，三頭向東。銅海安在牛上，牛尾向內。</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀上 7:26"> 銅海厚八釐米，邊如杯邊，又如百合花，容量為六萬六千升。</span>
<span className="v" id="v6" data-v="6" data-xref="列王紀上 7:38; 出埃及記 30:18–21; 列王紀上 7:40"> 他又造了十個盆，五個放右邊，五個放左邊，用來清洗獻燔祭所用之物。但銅海只供祭司洗滌使用。</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及記 25:31–40; 列王紀上 7:49; 約翰福音 8:12"> 他照著所定的式樣，造了十個金燈臺放在殿裡，五個在右邊，五個在左邊；</span>
<span className="v" id="v8" data-v="8" data-xref="列王紀上 7:48; 瑪拉基書 1:12; 出埃及記 25:23–30"> 又造了十張桌子放在殿裡，五張在右邊，五張在左邊；還造了一百個金碗。</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀上 6:36; 列王紀下 21:5; 列王紀上 7:12"> 他又建了祭司院、大院及大院的門，門都包上銅。</span>
<span className="v" id="v10" data-v="10" data-xref="列王紀上 7:39"> 銅海放在殿的右邊，就是東南方。</span>
<span className="v" id="v11" data-v="11" data-xref="列王紀上 7:40–51; 列王紀上 7:14"> 戶蘭又造了鍋、鏟和碗。他為所羅門王完成了上帝殿裡的工作。</span>
<span className="v" id="v12" data-v="12" data-xref="列王紀上 7:41; 歷代志下 3:15–17"> 戶蘭所製造的有：兩根柱子，兩個碗狀的柱冠，兩個裝飾柱冠的網子，</span>
<span className="v" id="v13" data-v="13" data-xref="列王紀上 7:20; 列王紀上 7:42; 耶利米書 52:23"> 四百個安在網子上的石榴，每個網子上兩行石榴，用來裝飾碗狀的柱冠；</span>
<span className="v" id="v14" data-v="14" data-xref="列王紀上 7:27–43"> 盆座及盆座上的盆；</span>
<span className="v" id="v15" data-v="15"> 銅海和銅海下面的十二頭銅牛；</span>
<span className="v" id="v16" data-v="16" data-xref="歷代志下 2:13; 列王紀上 7:13–14; 歷代志下 4:11"> 鍋、鏟、肉叉及耶和華殿裡的一切器具。這些都是巧匠戶蘭用磨亮的銅為所羅門王製造的。</span>
<span className="v" id="v17" data-v="17" data-xref="列王紀上 7:46"> 這些都是照王的命令，在疏割和撒利但之間的約旦平原用泥模鑄成的。</span>
<span className="v" id="v18" data-v="18" data-xref="列王紀上 7:47; 耶利米書 52:20; 歷代志上 22:14"> 所羅門製造的器具極多，銅的重量無法統計。</span>
<span className="v" id="v19" data-v="19" data-xref="啟示錄 9:13; 但以理書 5:2–3; 出埃及記 25:23–30"> 所羅門又為上帝的殿造了以下器具：金壇和放供餅的桌子，</span>
<span className="v" id="v20" data-v="20" data-xref="歷代志下 4:7; 出埃及記 25:31–37; 列王紀上 6:5"> 按規定放在內殿前的純金燈臺和燈盞，</span>
<span className="v" id="v21" data-v="21" data-xref="列王紀上 6:29; 出埃及記 37:20; 列王紀上 6:35"> 燈臺上的金花、燈盞、火鉗、</span>
<span className="v" id="v22" data-v="22" data-xref="列王紀下 12:13; 列王紀下 25:14; 耶利米書 52:18"> 燈剪、碗、碟和火鼎。殿門和至聖所的門也是金的。</span>

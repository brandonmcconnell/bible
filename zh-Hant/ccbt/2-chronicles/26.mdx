## 猶大王烏西雅

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歷代志下 22:1; 馬太福音 1:8–9; 歷代志下 33:25"> 全體猶大人立十六歲的烏西雅為王，繼承他父親亞瑪謝的王位。</span>
<span className="v" id="v2" data-v="2" data-xref="列王紀下 16:6; 歷代志下 25:28; 歷代志下 25:23"> 亞瑪謝王與祖先同眠後，烏西雅為猶大收復了以祿城，並重新修建。</span>
<span className="v" id="v3" data-v="3" data-xref="列王紀下 15:2–3; 阿摩司書 1:1; 何西阿書 1:1"> 烏西雅十六歲登基，在耶路撒冷執政五十二年。他母親叫耶可利雅，是耶路撒冷人。</span>
<span className="v" id="v4" data-v="4" data-xref="歷代志下 25:2"> 他事事效法他父親亞瑪謝，做耶和華視為正的事。</span>
<span className="v" id="v5" data-v="5" data-xref="歷代志下 15:2; 歷代志下 24:2; 歷代志上 22:13"> 撒迦利亞在世之日，烏西雅尋求上帝，撒迦利亞教導他敬畏上帝。當他尋求耶和華時，上帝就使他亨通。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="以賽亞書 14:29; 撒母耳記上 5:6; 撒母耳記上 5:1"> 他出兵攻打非利士人，把迦特、雅比尼和亞實突的城牆夷平後，在亞實突境內及非利士人的其他地區興建城邑。</span>
<span className="v" id="v7" data-v="7" data-xref="歷代志下 21:16; 歷代志上 5:20; 歷代志下 14:11"> 上帝幫助他攻打非利士人和住在姑珥·巴力的阿拉伯人及米烏尼人。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳記下 8:2; 歷代志下 17:11; 創世記 19:38"> 亞捫人向他進貢，烏西雅的名聲傳到埃及，因他非常強大。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="尼希米記 3:13; 歷代志下 25:23; 列王紀下 14:13"> 烏西雅在耶路撒冷的角門、谷門和城牆拐角的地方建造城樓，並加固城樓，</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 26:18–21; 以賽亞書 29:17; 列王紀下 3:4"> 又在曠野建造瞭望塔，挖了許多水井，因為他在高原和平原有很多牲畜。他雇人在山區和沃野為他耕種田地和照料葡萄園，因為他喜愛農耕。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="列王紀下 5:2"> 烏西雅有支可以隨時列隊出戰的軍兵，由書記耶利和官長瑪西雅召集，歸王的將軍哈拿尼雅統領。</span>
<span className="v" id="v12" data-v="12"> 率領戰士的族長有兩千六百名，</span>
<span className="v" id="v13" data-v="13" data-xref="歷代志下 25:5; 歷代志下 14:8; 歷代志下 11:1"> 他們手下有三十萬七千五百精兵，幫助王攻打敵人。</span>
<span className="v" id="v14" data-v="14" data-xref="士師記 20:16; 撒母耳記上 17:49"> 烏西雅為全軍備有盾牌、矛槍、頭盔、鎧甲、弓箭和投石器用的石頭，</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及記 31:4; 馬太福音 4:24; 歷代志下 2:7"> 又讓巧匠在耶路撒冷設計和製造兵器，安放在城樓和角樓上，用來發射弓箭和大石頭。烏西雅威名遠揚，因為他得到非常的幫助，極其強盛。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="歷代志下 32:25; 歷代志下 25:19; 箴言 16:18"> 烏西雅強盛後，便心高氣傲，以致走向滅亡。他干犯他的上帝耶和華，擅自進入耶和華的殿在香壇上燒香。</span>
<span className="v" id="v17" data-v="17" data-xref="歷代志上 6:10; 歷代志上 26:6; 歷代志上 12:28"> 祭司亞撒利雅率領八十位耶和華勇敢的祭司跟著進殿，</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及記 30:7–8; 民數記 18:7; 耶利米書 13:18"> 阻止烏西雅王，說：「烏西雅啊，給耶和華燒香不是你可以做的事，而是承受聖職做祭司的亞倫子孫的事。離開聖所吧！你已干犯耶和華上帝，必不能從祂那裡得榮耀。」</span>
<span className="v" id="v19" data-v="19" data-xref="民數記 12:10; 歷代志下 25:16; 列王紀下 5:25–27"> 手拿香爐要燒香的烏西雅大怒，正當他在耶和華殿裡的香壇旁向眾祭司發怒的時候，他額頭上突然患了痲瘋病。</span>
<span className="v" id="v20" data-v="20" data-xref="申命記 28:22; 以斯帖記 6:12; 利未記 14:34"> 亞撒利雅大祭司和眾祭司見狀就催促他出殿，他急忙出去了，因為耶和華降災給他。</span>
<span className="v" id="v21" data-v="21" data-xref="利未記 13:46; 民數記 12:15; 列王紀下 7:3"> 烏西雅王到死一直有痲瘋病。他被隔離在別的宮中，不得進耶和華的殿。他兒子約坦管理王室，治理國家。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="以賽亞書 1:1; 以賽亞書 6:1; 歷代志下 9:29"> 烏西雅其他的事自始至終都是亞摩斯的兒子以賽亞先知記載的。</span>
<span className="v" id="v23" data-v="23" data-xref="歷代志下 28:27; 歷代志下 21:20; 歷代志下 26:18"> 烏西雅與祖先同眠後，葬在他祖墳附近一個王室的墳場，因為他有痲瘋病。他兒子約坦繼位。</span>
</div>
</div>

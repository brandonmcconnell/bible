## 希西迦加強防禦

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀下 18:13–37; 列王紀下 17:6; 歷代志下 20:1–2"> 在希西迦忠心地辦好這些事以後，亞述王西拿基立起兵入侵猶大，圍攻各堅城，企圖攻佔這些城。</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 9:53; 路加福音 9:51; 列王紀下 12:17"> 希西迦見西拿基立決意要攻打耶路撒冷，</span>
<span className="v" id="v3" data-v="3" data-xref="箴言 24:6; 箴言 20:18; 箴言 15:22"> 就與眾官員和將領商議，決定截斷城外的水源，眾人也都贊成。</span>
<span className="v" id="v4" data-v="4" data-xref="歷代志下 32:30; 列王紀下 18:9; 列王紀上 19:21"> 於是，他們召集大批民眾，截斷所有的水源和過境的溪流，不讓亞述王得到充足的水。</span>
<span className="v" id="v5" data-v="5" data-xref="歷代志下 25:23; 列王紀上 9:24; 列王紀下 25:4"> 希西迦發憤圖強，修築所有被毀壞的城牆，在上面建造城樓，在城外加建一道牆，並在大衛城的米羅加強防禦，製造許多兵器和盾牌。</span>
<span className="v" id="v6" data-v="6" data-xref="以賽亞書 40:2; 歷代志下 30:22; 尼希米記 8:16"> 他委任將領管理民眾，將他們全部召集在城門的廣場上，訓勉他們說：</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀下 6:16; 羅馬書 8:31; 以弗所書 6:10"> 「你們要剛強勇敢，不要在亞述王和他的大軍面前恐懼驚慌，因為與我們同在的比與他同在的更有能力。</span>
<span className="v" id="v8" data-v="8" data-xref="耶利米書 17:5; 歷代志下 20:17; 以賽亞書 41:10"> 那與他同在的只是血肉之軀，與我們同在的卻是我們的上帝耶和華，祂必幫助我們，為我們作戰。」眾人因猶大王希西迦的這番話而得到鼓舞。</span>
</div>
</div>

## 亞述恐嚇耶路撒冷

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="列王紀下 18:17; 約書亞記 10:31; 以賽亞書 36:2"> 之後，亞述王西拿基立率領全軍圍攻拉吉，同時派遣臣僕到耶路撒冷城，對猶大王希西迦和城中所有的猶大人說：</span>
<span className="v" id="v10" data-v="10" data-xref="列王紀下 18:19; 以賽亞書 36:4"> 「亞述王西拿基立這樣說，『你們仍然留在被困的耶路撒冷，究竟倚仗什麼呢？</span>
<span className="v" id="v11" data-v="11" data-xref="馬太福音 27:43; 詩篇 11:1–3; 以賽亞書 36:18"> 希西迦說你們的上帝耶和華會從亞述王手中拯救你們，難道他不是哄騙你們，要叫你們餓死渴死嗎？</span>
<span className="v" id="v12" data-v="12" data-xref="歷代志下 31:1; 申命記 12:13–14; 申命記 12:26–27"> 這希西迦不是拆除了耶和華的邱壇和祭壇，吩咐猶大和耶路撒冷的人必須在一個祭壇前敬拜並在上面燒香嗎？</span>
<span className="v" id="v13" data-v="13" data-xref="列王紀下 18:33–35; 以賽亞書 44:8–10; 但以理書 4:30"> 難道你們不知道我和我的祖先怎樣對付列國嗎？列國有哪個神明能從我手中救它的國家呢？</span>
<span className="v" id="v14" data-v="14" data-xref="以賽亞書 10:11–12; 出埃及記 15:9–11; 以賽亞書 42:8"> 我祖先所滅的列國有哪個神明能從我手中救它的國民呢？難道你們的上帝能從我手中救你們嗎？</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及記 5:2; 但以理書 3:15; 以賽亞書 36:18"> 所以，不要讓希西迦欺騙、迷惑你們，也不要相信他！任何民族或國家的神明都不能從我和我祖先手中救它的人民，何況你們的上帝呢？』」</span>
<span className="v" id="v16" data-v="16" data-xref="詩篇 73:9; 約翰福音 15:21; 約伯記 15:25–26"> 亞述王的臣僕還用別的話譭謗耶和華上帝和祂的僕人希西迦。</span>
<span className="v" id="v17" data-v="17" data-xref="以賽亞書 37:14; 列王紀下 19:12; 以賽亞書 37:28–29"> 西拿基立還寫信侮辱以色列的上帝耶和華說：「列邦的神明既然都不能從我手中救自己的人民，希西迦的上帝也不例外。」</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳記上 17:10; 列王紀下 18:26–28; 撒母耳記上 17:26"> 亞述王的臣僕用希伯來語大聲向城牆上的耶路撒冷人喊話，威嚇他們，使他們懼怕，好攻取城。</span>
<span className="v" id="v19" data-v="19" data-xref="列王紀下 19:18; 以賽亞書 2:8; 耶利米書 32:30"> 他把耶路撒冷的上帝與世間人手所造的神像相提並論。</span>
</div>
</div>

## 耶和華拯救耶路撒冷

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="詩篇 91:14–15; 以賽亞書 37:14–20; 歷代志下 14:11"> 於是，希西迦王和亞摩斯的兒子以賽亞先知向天上的上帝呼求禱告。</span>
<span className="v" id="v21" data-v="21" data-xref="以賽亞書 37:36–38; 詩篇 76:5; 詩篇 18:50"> 耶和華就差遣一個天使進入亞述王營中，滅了所有的勇士、官長和將領。西拿基立只好滿臉羞愧地返回自己的國家。一天，他去自己的神廟時，他的幾個親生兒子用刀殺了他。</span>
<span className="v" id="v22" data-v="22" data-xref="以賽亞書 31:4–5; 詩篇 18:48–50; 帖撒羅尼迦後書 3:5"> 這樣，耶和華從亞述王西拿基立及一切仇敵手中拯救了希西迦和耶路撒冷的居民，使他們四境平安。</span>
<span className="v" id="v23" data-v="23" data-xref="歷代志下 17:5; 馬太福音 2:11; 歷代志下 1:1"> 許多人帶著祭物到耶路撒冷獻給耶和華，也帶許多名貴的禮物送給猶大王希西迦。此後，希西迦受到各國的敬重。</span>
</div>
</div>

## 希西迦的疾病和驕傲

<div className="bt">
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="以賽亞書 38:1–8; 列王紀下 20:1–11; 以賽亞書 38:21–22"> 那時，希西迦病危，他向耶和華祈求。耶和華應允了他，賜給他一個徵兆。</span>
<span className="v" id="v25" data-v="25" data-xref="歷代志下 24:18; 歷代志下 26:16; 歷代志下 32:31"> 希西迦卻沒有為他所蒙的恩典而感謝上帝，因為他心中驕傲。因此，上帝的烈怒臨到他、猶大和耶路撒冷。</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米書 26:18–19; 歷代志下 34:27–28; 歷代志下 33:12"> 後來希西迦和耶路撒冷的居民發覺自己心裡驕傲，就謙卑下來。因此，在希西迦有生之年，耶和華的烈怒沒有臨到他們。</span>
</div>
</div>

## 希西迦的財富和尊榮

<div className="bt">
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="歷代志上 27:25–31; 歷代志下 1:12; 箴言 10:22"> 希西迦極有財富和尊榮。他建造庫房來存放他的金、銀、寶石、香料、盾牌和各種珍寶，</span>
<span className="v" id="v28" data-v="28" data-xref="撒母耳記下 7:8; 歷代志下 26:10; 列王紀上 4:26"> 又建造倉庫來貯藏穀物、新酒和新油，並為各類牲畜蓋棚立圈。</span>
<span className="v" id="v29" data-v="29" data-xref="歷代志上 29:12; 箴言 10:22; 撒母耳記上 2:7"> 他為自己建造城邑，並且擁有大批的牛羊，因為上帝賜他極多的財富。</span>
<span className="v" id="v30" data-v="30" data-xref="列王紀上 1:33; 以賽亞書 22:9–11; 詩篇 1:1–3"> 他截斷基訓的上泉，將水引到大衛城的西邊。希西迦凡事亨通。</span>
<span className="v" id="v31" data-v="31" data-xref="申命記 8:2; 箴言 17:3; 創世記 22:1"> 然而，當巴比倫的使者來見他，詢問他有關這地方發生的奇蹟時，上帝就讓希西迦自行處理，為要試驗他，好知道他內心如何。</span>
</div>
</div>

## 希西迦逝世

<div className="bt">
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="以賽亞書 36:1–22; 列王紀下 18:1–20; 歷代志下 31:20–21"> 希西迦其他的事和忠信的作為都記在亞摩斯的兒子以賽亞先知的《啟示書》上和《猶大和以色列列王史》上。</span>
<span className="v" id="v33" data-v="33" data-xref="箴言 10:7; 列王紀上 1:21; 歷代志下 16:14"> 希西迦與祖先同眠後，葬在大衛子孫墓地的高處。所有猶大人和耶路撒冷的居民都向他致哀。他兒子瑪拿西繼位。</span>
</div>
</div>

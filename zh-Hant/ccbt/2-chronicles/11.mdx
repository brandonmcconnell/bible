## 耶和華禁止他們交戰

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀上 12:21–24; 詩篇 33:10; 詩篇 33:16"> 羅波安回到耶路撒冷，從猶大和便雅憫支派召集了十八萬精兵，要攻打以色列，收復全國。</span>
<span className="v" id="v2" data-v="2" data-xref="歷代志下 12:15; 歷代志下 12:5–7; 歷代志下 8:14"> 然而，耶和華上帝對祂的僕人示瑪雅說：</span>
<span className="v" id="v3" data-v="3" data-xref="列王紀下 17:34; 創世記 49:28; 啟示錄 7:4–8"> 「你去告訴所羅門的兒子猶大王羅波安和所有住在猶大和便雅憫的以色列人，</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 50:20; 列王紀上 11:29–38; 歷代志下 10:15–16"> 耶和華這樣說，『你們不要上去與弟兄交戰，都回家吧，因為這事出於我。』」眾人聽從了耶和華的話，沒有去攻打耶羅波安，各自回家去了。</span>
</div>
</div>

## 羅波安加強防禦

<div className="bt">
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="歷代志下 8:2–6; 歷代志下 14:6–7; 以賽亞書 22:8–11"> 羅波安住在耶路撒冷，他在猶大修築城池用來防禦。</span>
<span className="v" id="v6" data-v="6" data-xref="尼希米記 3:5; 阿摩司書 1:1; 歷代志上 4:32"> 他修築的城池有伯利恆、以坦、提哥亞、</span>
<span className="v" id="v7" data-v="7" data-xref="約書亞記 15:35; 撒母耳記上 22:1; 約書亞記 15:58"> 伯·夙、梭哥、亞杜蘭、</span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 54:1; 約書亞記 15:24; 撒母耳記上 23:19"> 迦特、瑪利沙、西弗、</span>
<span className="v" id="v9" data-v="9" data-xref="約書亞記 15:39; 約書亞記 15:35; 約書亞記 10:5"> 亞多萊音、拉吉、亞西加、</span>
<span className="v" id="v10" data-v="10" data-xref="民數記 13:22; 約書亞記 15:33; 約書亞記 14:14"> 瑣拉、亞雅崙、希伯崙，這些都是猶大和便雅憫的堅城。</span>
<span className="v" id="v11" data-v="11" data-xref="歷代志下 17:19; 以賽亞書 22:10–11; 歷代志下 11:23"> 他又在各城池加強防禦，派將領駐守，供給食物、油和酒。</span>
<span className="v" id="v12" data-v="12" data-xref="撒母耳記下 13:22; 歷代志下 26:14–15; 歷代志下 32:5"> 他在城內儲備盾牌和矛槍，使城池非常堅固。猶大和便雅憫都歸屬他。</span>
</div>
</div>

## 祭司和利未人投奔猶大

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13"> 以色列全境的祭司和利未人都從四面八方來投奔羅波安。</span>
<span className="v" id="v14" data-v="14" data-xref="歷代志下 13:9; 民數記 35:2–5; 列王紀上 12:28–33"> 利未人撇下他們的草場和產業，來到猶大和耶路撒冷，因為耶羅波安和他的眾子不准他們做祭司事奉耶和華。</span>
<span className="v" id="v15" data-v="15" data-xref="列王紀上 12:28; 列王紀上 12:31; 列王紀上 13:33"> 耶羅波安卻為邱壇、公山羊像和他造的牛犢像設立他自己的祭司。</span>
<span className="v" id="v16" data-v="16" data-xref="歷代志下 15:9; 使徒行傳 11:23; 詩篇 84:5–7"> 以色列各支派中那些誠心尋求以色列的上帝耶和華的人，都跟隨利未人到耶路撒冷獻祭給他們祖先的上帝耶和華。</span>
<span className="v" id="v17" data-v="17" data-xref="歷代志下 12:1; 歷代志下 1:1–12; 歷代志下 7:17–19"> 他們使猶大國堅固，他們效忠所羅門的兒子羅波安三年之久，並在此期間遵行大衛和所羅門的道。</span>
</div>
</div>

## 羅波安的家室

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="撒母耳記上 16:6; 歷代志上 27:18; 撒母耳記上 17:13"> 羅波安娶了大衛的兒子耶利摩的女兒瑪哈拉為妻，她母親亞比孩是耶西的兒子以利押的女兒。</span>
<span className="v" id="v19" data-v="19"> 瑪哈拉為他生了耶烏施、示瑪利雅、撒罕三個兒子。</span>
<span className="v" id="v20" data-v="20" data-xref="歷代志下 13:2; 歷代志下 11:21; 歷代志下 12:16"> 後來，他又娶了押沙龍的女兒瑪迦<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「押沙龍的女兒瑪迦」或譯「押沙龍的孫女瑪迦」。">a</a></sup>，生了亞比雅、亞太、細撒、示羅密。</span>
<span className="v" id="v21" data-v="21" data-xref="士師記 8:30; 申命記 17:17; 列王紀上 11:3"> 羅波安共有十八個妻子、六十個妾、二十八個兒子、六十個女兒。眾妻妾中押沙龍的女兒瑪迦最得寵愛，</span>
<span className="v" id="v22" data-v="22" data-xref="申命記 21:15–17; 歷代志上 29:1; 歷代志上 5:1–2"> 羅波安就立她所生的兒子亞比雅為太子，以便讓他繼承王位。</span>
<span className="v" id="v23" data-v="23" data-xref="歷代志下 21:3; 創世記 25:6; 路加福音 16:8"> 羅波安精明地把其他王子派駐到猶大和便雅憫境內的各堅城，給他們充足的供應和許多妻妾。</span>
</div>
</div>

## 預備守逾越節

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多前書 5:7–8; 歷代志下 11:13; 何西阿書 5:4"> 希西迦派人通告以色列和猶大全境，又寫信通知以法蓮人和瑪拿西人，叫他們到耶路撒冷耶和華的殿，向以色列的上帝耶和華守逾越節。</span>
<span className="v" id="v2" data-v="2" data-xref="民數記 9:10–11; 歷代志上 13:1–3; 歷代志下 30:13"> 王、眾官員及耶路撒冷的全體會眾決定在二月守逾越節。</span>
<span className="v" id="v3" data-v="3" data-xref="歷代志下 29:34; 出埃及記 12:6; 出埃及記 12:18"> 他們不能在一月守節期，因為潔淨自己的祭司不夠多，民眾也沒有聚集在耶路撒冷。</span>
<span className="v" id="v4" data-v="4" data-xref="歷代志上 13:4"> 王與全體會眾都很贊成這個計劃。</span>
<span className="v" id="v5" data-v="5" data-xref="士師記 20:1; 利未記 23:2; 以斯帖記 8:8–10"> 於是，他們下令通告全以色列，從別示巴直到但，讓人們到耶路撒冷向以色列的上帝耶和華守逾越節，因為人們不常照律例守這節期。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="耶利米書 51:31; 以斯帖記 8:14; 列王紀下 15:19"> 信差遵照王的命令，帶著王和眾官員的信走遍以色列和猶大，宣告說：「以色列人啊，你們應當歸向亞伯拉罕、以撒和以色列的上帝耶和華，好使祂轉向你們這些從亞述王手中逃脫的餘民。</span>
<span className="v" id="v7" data-v="7" data-xref="歷代志下 29:8; 以西結書 20:13–18; 撒迦利亞書 1:3–4"> 不要效法你們的祖先和親族，他們對他們祖先的上帝耶和華不忠，所以耶和華使他們的下場令人驚駭，正如你們所見的。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及記 32:9; 歷代志下 29:10; 申命記 10:16"> 現在，不要像你們的祖先那樣頑固不化；要順服耶和華，進入祂永遠聖潔的聖所，事奉你們的上帝耶和華，好使祂的烈怒轉離你們。</span>
<span className="v" id="v9" data-v="9" data-xref="以賽亞書 55:7; 彌迦書 7:18; 詩篇 86:5"> 你們若歸向祂，你們的弟兄和兒女必蒙擄走他們之人的憐憫，得以回歸此地，因為你們的上帝耶和華有恩典，好憐憫。你們若歸向祂，祂必不會轉臉不顧你們。」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="歷代志下 36:16; 歷代志下 30:6; 尼希米記 2:19"> 信差將這通告逐城傳遍以法蓮和瑪拿西，直到西布倫，可是那些地方的人卻嘲笑、戲弄他們。</span>
<span className="v" id="v11" data-v="11" data-xref="歷代志下 30:18; 歷代志下 30:21; 歷代志下 30:25"> 然而，有些亞設人、瑪拿西人和西布倫人謙卑悔改，來到耶路撒冷。</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米書 32:39; 耶利米書 24:7; 腓立比書 2:13"> 耶和華上帝感動猶大人，使他們一心遵從王與眾官員奉祂的指示所下的命令。</span>
</div>
</div>

## 守逾越節

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="歷代志下 30:2; 詩篇 84:7"> 二月，大群的人聚到耶路撒冷守除酵節。</span>
<span className="v" id="v14" data-v="14" data-xref="歷代志下 28:24; 撒母耳記下 15:23; 歷代志下 15:16"> 他們除去耶路撒冷的祭壇和所有香壇，把它們扔進汲淪溪。</span>
<span className="v" id="v15" data-v="15" data-xref="歷代志下 29:34; 歷代志下 5:11; 出埃及記 19:22"> 二月十四日，他們宰了逾越節的羔羊。祭司和利未人覺得慚愧，就潔淨自己，把燔祭帶到耶和華的殿裡，</span>
<span className="v" id="v16" data-v="16" data-xref="申命記 33:1; 歷代志下 35:15; 列王紀下 11:14"> 然後照上帝的僕人摩西的律法照常供職。祭司從利未人手中接過血，灑在壇上。</span>
<span className="v" id="v17" data-v="17" data-xref="歷代志下 29:34; 歷代志下 35:3–6; 出埃及記 12:6"> 因為會眾中間有許多人沒有潔淨自己，利未人就為所有不潔之人宰逾越節的羔羊獻給耶和華。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前書 11:28; 雅各書 5:15–16; 但以理書 9:19"> 有許多以法蓮人、瑪拿西人、以薩迦人和西布倫人，沒有潔淨自己就吃了逾越節的羊羔，違背了律法的規定。希西迦就為他們禱告說：「凡誠心尋求他祖先的上帝耶和華的人，雖然沒有照聖所的律例潔淨自己，願良善的耶和華赦免他！」</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及記 15:26; 雅各書 5:15–16; 詩篇 103:3"> 耶和華垂聽希西迦的禱告，就赦免<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「赦免」希伯來文是「醫治」。">a</a></sup>了他們。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="出埃及記 12:15; 出埃及記 13:6; 申命記 12:12"> 在耶路撒冷的以色列人非常喜樂地守除酵節七天。利未人和祭司用響亮的樂器天天頌讚耶和華。</span>
<span className="v" id="v22" data-v="22" data-xref="歷代志下 32:6; 尼希米記 9:3; 以賽亞書 40:1–2"> 希西迦慰勞所有善於事奉耶和華的利未人。於是，眾人歡宴過節七天，又獻上平安祭，稱謝他們祖先的上帝耶和華。</span>
</div>
</div>

## 再次守節期

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="列王紀上 8:65; 歷代志下 7:9"> 全體會眾商議要再守節期七天，於是眾人又歡歡喜喜地守節期七天。</span>
<span className="v" id="v24" data-v="24" data-xref="歷代志下 29:34; 歷代志下 35:7–8; 以弗所書 4:8"> 猶大王希西迦送給會眾一千頭公牛和七千隻羊，眾官員也送給會眾一千頭公牛和一萬隻羊，並且很多祭司都已潔淨自己。</span>
<span className="v" id="v25" data-v="25" data-xref="歷代志下 30:11; 歷代志下 30:18; 歷代志上 16:10–11"> 猶大全體會眾、祭司、利未人和從以色列來的全體會眾，以及寄居在以色列和猶大的人盡都歡喜。</span>
<span className="v" id="v26" data-v="26" data-xref="歷代志下 7:8–10"> 全耶路撒冷都喜氣洋洋，因為自以色列王大衛的兒子所羅門時代以來，耶路撒冷從未有過這樣的盛會。</span>
<span className="v" id="v27" data-v="27" data-xref="申命記 26:15; 詩篇 68:5; 民數記 6:23–26"> 利未祭司起來為民眾祝福，他們的禱告得蒙垂聽，達到天上的聖所。</span>
</div>
</div>

## 亞撒王擊敗古實人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歷代志下 9:31; 列王紀上 2:10; 列王紀上 14:31"> 亞比雅與祖先同眠後，葬在大衛城，他兒子亞撒繼位。亞撒執政期間，國中太平十年。</span>
<span className="v" id="v2" data-v="2" data-xref="列王紀上 15:11; 歷代志下 31:20; 列王紀上 15:14"> 亞撒做他的上帝耶和華看為好、視為正的事，</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 7:5; 出埃及記 34:13; 列王紀下 23:14"> 拆除外族的祭壇和邱壇，打碎神柱，砍倒亞舍拉神像，</span>
<span className="v" id="v4" data-v="4" data-xref="歷代志下 30:19; 詩篇 119:10; 詩篇 101:2–8"> 命令猶大人尋求他們祖先的上帝耶和華，遵行祂的律法和誡命。</span>
<span className="v" id="v5" data-v="5" data-xref="歷代志下 34:4; 歷代志下 34:7"> 他除掉猶大各城邑的邱壇和香壇，那時國家在他的治理下太平無事。</span>
<span className="v" id="v6" data-v="6" data-xref="歷代志下 15:15; 歷代志上 22:9; 約伯記 34:29"> 他還在猶大修築堅城，那些年國中太平，沒有戰事，因為耶和華賜他平安。</span>
<span className="v" id="v7" data-v="7" data-xref="彼得前書 3:12; 歷代志下 14:6; 耶利米書 29:12–14"> 他對猶大人說：「我們要修築城邑，在四周建造城牆和望樓，裝置大門和門閂。我們仍擁有這片土地，是因為我們尋求我們的上帝耶和華；我們尋求祂，祂就賜我們四境平安。」於是，他們修築城邑，凡事順利。</span>
<span className="v" id="v8" data-v="8" data-xref="歷代志下 13:3; 歷代志下 17:14–19; 歷代志下 11:1"> 亞撒的軍隊中有三十萬持大盾牌和矛槍的猶大人，二十八萬持小盾牌和弓箭的便雅憫人。他們都是英勇的戰士。</span>
<span className="v" id="v9" data-v="9" data-xref="歷代志下 16:8; 歷代志下 12:2–3; 歷代志下 11:8"> 古實王謝拉率領一百萬大軍和三百輛戰車攻打猶大，到了瑪利沙。</span>
<span className="v" id="v10" data-v="10" data-xref="士師記 1:17; 約書亞記 19:4"> 亞撒出兵迎敵，雙方在瑪利沙的洗法谷擺開陣勢。</span>
<span className="v" id="v11" data-v="11" data-xref="耶利米書 1:19; 哥林多後書 12:9–10; 詩篇 22:5"> 亞撒呼求他的上帝耶和華說：「耶和華啊，唯有你才能幫助弱小的勝過強大的。我們的上帝耶和華啊，求你幫助我們，因為我們依靠你，奉你的名迎戰這大軍。耶和華啊，你是我們的上帝，不要讓人勝過你。」</span>
<span className="v" id="v12" data-v="12" data-xref="歷代志下 13:15; 詩篇 136:17–18; 申命記 28:7"> 於是，耶和華使古實人敗在亞撒和猶大人面前，古實人潰逃。</span>
<span className="v" id="v13" data-v="13" data-xref="創世記 10:19; 創世記 26:1; 創世記 20:1"> 亞撒率領軍隊乘勝追擊，直追到基拉耳。古實人在耶和華和祂的軍兵面前大敗，傷亡慘重，一蹶不振。猶大人擄走了許多財物，</span>
<span className="v" id="v14" data-v="14" data-xref="歷代志下 17:10; 創世記 35:5; 歷代志下 20:29"> 攻陷了基拉耳四周的城邑，因為這些城裡的人都懼怕耶和華。他們洗劫各城，因為城中有大量財物。</span>
<span className="v" id="v15" data-v="15" data-xref="民數記 31:30–47; 民數記 31:9; 撒母耳記上 30:20"> 他們毀壞牲畜的棚圈，搶走許多羊和駱駝，然後返回耶路撒冷。</span>

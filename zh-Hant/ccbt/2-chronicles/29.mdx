## 猶大王希西迦

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀下 18:1–3; 歷代志上 3:13; 歷代志下 26:5"> 希西迦二十五歲登基，在耶路撒冷執政二十九年。他母親叫亞比雅，是撒迦利雅的女兒。</span>
<span className="v" id="v2" data-v="2" data-xref="歷代志下 34:2; 歷代志下 28:1"> 希西迦事事效法他祖先大衛，做耶和華視為正的事。</span>
</div>
</div>

## 潔淨聖殿

<div className="bt">
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="歷代志下 28:24; 歷代志下 29:7; 馬太福音 6:33"> 希西迦元年一月，他開啟耶和華殿的門，重新修理。</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米書 19:2; 尼希米記 3:29; 歷代志下 32:6"> 他把眾祭司和利未人召集在東邊的廣場，</span>
<span className="v" id="v5" data-v="5" data-xref="歷代志下 35:6; 哥林多前書 3:16–17; 歷代志下 34:3–8"> 對他們說：「利未人啊，請聽我說！現在你們要潔淨自己，也要潔淨你們祖先的上帝耶和華的殿，除去聖所中的污穢之物。</span>
<span className="v" id="v6" data-v="6" data-xref="以西結書 8:16; 耶利米書 2:27; 但以理書 9:16"> 我們的祖先行事不忠，做我們的上帝耶和華視為惡的事，背棄祂，轉臉背向祂的居所。</span>
<span className="v" id="v7" data-v="7" data-xref="歷代志下 28:24; 利未記 24:2–8; 歷代志下 29:3"> 他們封鎖殿廊的門，吹滅燈火，不在聖所裡向以色列的上帝燒香、獻燔祭。</span>
<span className="v" id="v8" data-v="8" data-xref="耶利米書 25:9; 耶利米書 25:18; 耶利米書 29:18"> 因此，耶和華的烈怒臨到猶大和耶路撒冷，使他們的遭遇令人恐懼、震驚、嗤笑，正如你們親眼所見的。</span>
<span className="v" id="v9" data-v="9" data-xref="歷代志下 28:17; 歷代志下 28:5–8; 耶利米哀歌 5:7"> 所以我們的祖先死在刀下，我們的妻兒也被擄去。</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米書 50:5; 歷代志下 23:16; 以斯拉記 10:3"> 現在我決心要與以色列的上帝耶和華立約，好使祂的烈怒轉離我們。</span>
<span className="v" id="v11" data-v="11" data-xref="申命記 10:8; 加拉太書 6:7–8; 民數記 8:6–14"> 我的孩子們啊，不要懈怠！因為耶和華揀選你們站在祂面前事奉祂，向祂燒香。」</span>
<span className="v" id="v12" data-v="12" data-xref="民數記 3:19–20; 歷代志上 15:5–7; 民數記 4:2–20"> 於是，利未人開始供職。其中哥轄宗族有亞瑪賽的兒子瑪哈和亞撒利雅的兒子約珥，米拉利宗族有亞伯底的兒子基士和耶哈利勒的兒子亞撒利雅，革順宗族有薪瑪的兒子約亞和約亞的兒子伊甸，</span>
<span className="v" id="v13" data-v="13" data-xref="歷代志上 6:39; 歷代志上 15:8; 歷代志上 15:17"> 以利撒反宗族有申利和耶利，亞薩宗族有撒迦利雅和瑪探雅，</span>
<span className="v" id="v14" data-v="14" data-xref="歷代志上 6:33; 歷代志上 25:1; 歷代志上 25:6"> 希幔宗族有耶歇和示每，耶杜頓宗族有示瑪雅和烏薛。</span>
<span className="v" id="v15" data-v="15" data-xref="歷代志下 30:12; 歷代志上 23:28; 歷代志下 29:5"> 他們召集其他利未人一起潔淨自己，並遵照王的吩咐和耶和華的命令，進去潔淨耶和華的殿。</span>
<span className="v" id="v16" data-v="16" data-xref="歷代志下 15:16; 馬太福音 21:12–13; 馬太福音 23:27"> 祭司們進去潔淨耶和華的殿，把所有污穢之物搬到耶和華殿的院子裡，然後再由利未人運到外面的汲淪溪丟掉。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及記 12:2–8; 歷代志下 3:4; 列王紀上 6:3"> 他們一月一日開始潔淨的工作，到一月八日已經潔淨到耶和華殿的走廊，又用八天潔淨耶和華的殿，一月十六日完成潔淨的工作。</span>
</div>
</div>

## 重新奉獻聖殿

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="歷代志下 4:1; 歷代志下 4:7–8; 歷代志下 13:11"> 然後，他們晉見希西迦王，說：「我們已經潔淨了整個耶和華的殿、燔祭壇以及壇上的一切器皿、供餅的桌子及桌子上的一切器皿。</span>
<span className="v" id="v19" data-v="19" data-xref="歷代志下 28:24"> 我們已備齊亞哈斯王對上帝不忠時所廢棄的器皿，並潔淨了它們，現在都放在耶和華的壇前。」</span>
<span className="v" id="v20" data-v="20" data-xref="約書亞記 6:12; 耶利米書 25:4; 出埃及記 24:4"> 希西迦王清早起來，召集城中官員一同上到耶和華的殿。</span>
<span className="v" id="v21" data-v="21" data-xref="利未記 4:3–14; 約伯記 42:8; 以西結書 45:23"> 他們牽來七頭公牛、七隻公綿羊、七隻羊羔和七隻公山羊，作國家、聖所和猶大人的贖罪祭。王吩咐做祭司的亞倫子孫把這些牲畜獻在耶和華的壇上。</span>
<span className="v" id="v22" data-v="22" data-xref="利未記 4:18; 利未記 8:19; 利未記 8:24"> 他們宰了公牛，祭司取過血來灑在壇上，然後宰了公綿羊並把血灑在壇上，又宰了羊羔並把血灑在壇上。</span>
<span className="v" id="v23" data-v="23" data-xref="利未記 4:15; 利未記 4:24; 利未記 1:4"> 有人把作贖罪祭的公山羊牽到王和會眾面前，他們就將手按在公山羊身上。</span>
<span className="v" id="v24" data-v="24" data-xref="利未記 14:20; 以西結書 45:15; 哥林多後書 5:18–21"> 祭司宰了公山羊，把血灑在壇上作贖罪祭，為所有以色列人贖罪，因為王吩咐要為所有以色列人獻上燔祭和贖罪祭。</span>
<span className="v" id="v25" data-v="25" data-xref="歷代志下 8:14; 歷代志上 23:5; 撒母耳記下 24:11"> 王又分派利未人在耶和華的殿裡敲鈸、鼓瑟、彈琴，正如大衛王、王的先見迦得和先知拿單的指示，就是耶和華藉先知所吩咐的。</span>
<span className="v" id="v26" data-v="26" data-xref="歷代志上 23:5; 歷代志上 15:24; 阿摩司書 6:5"> 利未人拿著大衛的樂器侍立在那裡，祭司拿著號角侍立在那裡。</span>
<span className="v" id="v27" data-v="27" data-xref="歷代志下 23:18; 詩篇 137:3–4; 歷代志下 20:21"> 希西迦下令在壇上獻燔祭。開始獻燔祭時，伴隨著號角聲和以色列王大衛的樂器聲，響起了頌讚耶和華的歌聲。</span>
<span className="v" id="v28" data-v="28" data-xref="啟示錄 5:8–14; 詩篇 89:15; 詩篇 68:24–26"> 全體會眾伴著歌聲和號角聲俯伏敬拜，直到獻完燔祭。</span>
<span className="v" id="v29" data-v="29" data-xref="歷代志下 20:18; 歷代志上 29:20; 腓立比書 2:10–11"> 獻完燔祭後，王和所有在場的人都俯伏敬拜。</span>
<span className="v" id="v30" data-v="30" data-xref="腓立比書 4:4; 詩篇 95:1–2; 歷代志上 16:7–36"> 希西迦王與眾官員又吩咐利未人用大衛和亞薩先見的詩詞頌讚耶和華。他們歡然歌唱，並低頭敬拜。</span>
<span className="v" id="v31" data-v="31" data-xref="歷代志下 13:9; 出埃及記 35:22; 利未記 7:12"> 希西迦說：「你們既然已經把自己獻給了耶和華，現在就把祭物和感恩祭帶到耶和華的殿裡來吧。」於是，會眾就把祭物和感恩祭送來，有些人甘心樂意地送來燔祭。</span>
<span className="v" id="v32" data-v="32" data-xref="以斯拉記 6:17; 列王紀上 3:4; 歷代志上 29:21"> 會眾獻給耶和華作燔祭的有七十頭公牛、一百隻公綿羊、二百隻羊羔，</span>
<span className="v" id="v33" data-v="33"> 獻為聖物的有六百頭公牛、三千隻綿羊。</span>
<span className="v" id="v34" data-v="34" data-xref="歷代志下 35:11; 歷代志下 30:3; 詩篇 94:15"> 但祭司人數太少，剝不完燔祭牲的皮，於是他們的親族利未人就來幫助他們，直到獻完燔祭，並且別的祭司也潔淨了自己，因為利未人比祭司更誠心潔淨自己。</span>
<span className="v" id="v35" data-v="35" data-xref="民數記 15:5–10; 出埃及記 29:13; 歷代志上 16:37–42"> 他們獻上大量燔祭和平安祭祭牲的脂肪，以及與燔祭同獻的奠祭。 從此，耶和華殿裡的事奉恢復了。</span>
<span className="v" id="v36" data-v="36" data-xref="使徒行傳 2:41; 帖撒羅尼迦前書 3:8–9; 歷代志上 29:9"> 希西迦和民眾因上帝為他們做的而歡喜快樂，因為這事很快成就了。</span>

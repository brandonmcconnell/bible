## 亞撒的改革

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歷代志下 24:20; 歷代志下 20:14; 民數記 24:2"> 上帝的靈降在俄德的兒子亞撒利雅身上，</span>
<span className="v" id="v2" data-v="2" data-xref="雅各書 4:8; 歷代志下 24:20; 歷代志下 15:4"> 他便出來迎接亞撒，對他說：「亞撒啊，所有的猶大人和便雅憫人啊，請聽我說！你們若順從耶和華，祂必與你們同在。你們若尋求祂，祂必讓你們尋見。你們若背棄祂，祂必離棄你們。</span>
<span className="v" id="v3" data-v="3" data-xref="尼希米記 8:9; 利未記 10:11; 歷代志下 17:8–9"> 以色列人已經許久沒有真神，沒有祭司教導，也沒有律法。</span>
<span className="v" id="v4" data-v="4" data-xref="以賽亞書 55:6; 申命記 4:29–30; 歷代志下 15:15"> 然而，他們在患難時歸向以色列的上帝耶和華，尋求祂，祂就讓他們尋見。</span>
<span className="v" id="v5" data-v="5" data-xref="士師記 5:6; 詩篇 121:8; 撒母耳記上 13:6"> 那時，人們出入不得平安，因為各地都有動亂。</span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 21:22–24; 馬太福音 24:7; 歷代志下 33:11"> 邦國毀滅邦國、城邑毀滅城邑，因為上帝用各樣災難擾亂他們。</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多前書 15:58; 約書亞記 1:7; 約書亞記 1:9"> 但你們要剛強，不要雙手發軟，因為你們必因所行的得獎賞。」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="歷代志下 8:12; 歷代志下 13:19; 歷代志下 4:1"> 亞撒聽了俄德的兒子亞撒利雅先知的預言，就鼓起勇氣剷除猶大和便雅憫全境及他在以法蓮山區奪取的各城邑中的可憎神像，並在耶和華殿的走廊前重修耶和華的祭壇。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="歷代志下 11:16; 使徒行傳 9:31; 撒迦利亞書 8:21–23"> 當時，有許多以法蓮人、瑪拿西人和西緬人看見亞撒的上帝耶和華與他同在，就從以色列來投奔他，寄居在猶大。亞撒把他們和所有的猶大人與便雅憫人都招聚在一起。</span>
<span className="v" id="v10" data-v="10" data-xref="以斯帖記 8:9"> 亞撒執政第十五年三月，他們聚集在耶路撒冷。</span>
<span className="v" id="v11" data-v="11" data-xref="歷代志下 14:13–15; 民數記 31:28–29; 民數記 31:50"> 當天，他們從擄物中取出七百頭牛和七千隻羊獻祭給耶和華。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行傳 24:14; 歷代志下 23:16; 申命記 10:12"> 他們與他們祖先的上帝耶和華立約，要全心全意地尋求祂。</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及記 22:20; 詩篇 115:13; 列王紀上 18:40"> 凡不尋求以色列的上帝耶和華的，無論男女老幼，一律處死。</span>
<span className="v" id="v14" data-v="14" data-xref="尼希米記 5:13; 詩篇 81:1–4; 尼希米記 10:29"> 他們高聲向耶和華起誓，並吹響號角。</span>
<span className="v" id="v15" data-v="15" data-xref="歷代志下 14:7; 歷代志下 15:12; 以賽亞書 26:8"> 猶大人都為所起的誓而歡喜快樂，因他們誠心起誓、誠意尋求耶和華，耶和華就讓他們尋見，並賜他們四境平安。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="列王紀上 15:13–24; 列王紀上 15:10; 列王紀下 23:15"> 亞撒王還廢除了他祖母瑪迦的太后之位，因為她造了可憎的亞舍拉神像。亞撒把她可憎的神像砍倒、打碎，放在汲淪溪燒掉。</span>
<span className="v" id="v17" data-v="17" data-xref="列王紀下 14:4; 列王紀下 12:3; 列王紀上 11:4"> 他雖然沒有清除以色列的邱壇，但一生忠於耶和華。</span>
<span className="v" id="v18" data-v="18" data-xref="列王紀上 7:51; 歷代志上 26:20–26; 列王紀上 15:14–15"> 他把自己和父親奉獻的金銀及器皿都帶到上帝的殿裡。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="列王紀上 15:31; 列王紀上 15:33; 列王紀上 15:16–17"> 從那時直到亞撒執政第三十五年，國中都沒有戰爭。</span>
</div>
</div>

</div>

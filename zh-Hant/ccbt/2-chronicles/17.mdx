## 猶大王約沙法

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀上 15:24; 以弗所書 6:10; 馬太福音 1:8"> 亞撒的兒子約沙法繼位，他發憤圖強對抗以色列。</span>
<span className="v" id="v2" data-v="2" data-xref="歷代志下 15:8; 歷代志下 11:5; 歷代志下 11:11–12"> 他派兵駐守猶大所有的堅城，又把守備軍安置在猶大和他父親亞撒所征服的以法蓮各城邑。</span>
<span className="v" id="v3" data-v="3" data-xref="列王紀下 22:2; 以賽亞書 41:10; 提摩太後書 4:22"> 耶和華與約沙法同在，因為他效法他祖先大衛起初所行的，沒有尋求巴力，</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀上 12:28; 路加福音 1:6; 帖撒羅尼迦前書 2:12"> 只尋求他父親的上帝，遵行祂的誡命，沒有效法以色列人的行為。</span>
<span className="v" id="v5" data-v="5" data-xref="歷代志下 18:1; 馬太福音 6:33; 詩篇 127:1"> 因此，耶和華鞏固他的王位，所有的猶大人都向他進貢，他極有財富和尊榮。</span>
<span className="v" id="v6" data-v="6" data-xref="何西阿書 14:9; 歷代志下 15:17; 歷代志下 20:33"> 他專心遵行耶和華的道，剷除猶大境內的邱壇和亞舍拉神像。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="歷代志下 35:3; 尼希米記 8:7–8; 傳道書 12:9–10"> 他在執政第三年委派官員便·亥伊勒、俄巴底、撒迦利雅、拿坦業和米該亞到猶大各城教導民眾，</span>
<span className="v" id="v8" data-v="8" data-xref="以斯拉記 7:1–6; 歷代志下 19:8; 瑪拉基書 2:7"> 與他們同去的還有利未人示瑪雅、尼探雅、西巴第雅、亞撒黑、示米拉末、約拿單、亞多尼雅、多比雅和駝·巴多尼雅，還有祭司以利沙瑪和約蘭。</span>
<span className="v" id="v9" data-v="9" data-xref="約翰福音 5:46; 羅馬書 3:2; 使徒行傳 8:40"> 他們帶著耶和華的律法書，走遍猶大各城鎮教導民眾。</span>
<span className="v" id="v10" data-v="10" data-xref="歷代志下 14:14; 出埃及記 15:14–16; 箴言 16:7"> 猶大周圍的列國都懼怕耶和華，不敢與約沙法爭戰。</span>
<span className="v" id="v11" data-v="11" data-xref="歷代志下 26:8; 歷代志下 9:14; 撒母耳記下 8:2"> 一些非利士人向他進貢禮物和銀子，阿拉伯人也給他送來公綿羊和公山羊各七千七百隻。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="歷代志下 8:2–6; 歷代志下 14:6–7; 歷代志下 32:5"> 約沙法日漸強大，在猶大境內修建堡壘和儲貨城，</span>
<span className="v" id="v13" data-v="13" data-xref="歷代志上 27:25–31; 歷代志下 26:10–15"> 在猶大各城儲備大量物資。他又在耶路撒冷屯駐精兵，</span>
<span className="v" id="v14" data-v="14" data-xref="歷代志下 11:1; 創世記 15:5; 民數記 1:18"> 其人數按宗族記在下面。<br />猶大族有千夫長押拿，率領精兵三十萬；</span>
<span className="v" id="v15" data-v="15"> 其次是千夫長約哈難，率領軍兵二十八萬；</span>
<span className="v" id="v16" data-v="16" data-xref="士師記 5:9; 士師記 5:2; 歷代志上 29:9"> 其次是自願事奉耶和華的細基利的兒子亞瑪斯雅，率領精兵二十萬。</span>
<span className="v" id="v17" data-v="17" data-xref="歷代志下 14:8; 撒母耳記下 1:21–22"> 便雅憫族有勇士以利雅大，率領手持弓箭和盾牌的軍兵二十萬；</span>
<span className="v" id="v18" data-v="18"> 其次是約薩拔，率領武裝好的軍兵十八萬。</span>
<span className="v" id="v19" data-v="19" data-xref="歷代志下 17:2; 歷代志下 11:12; 歷代志下 11:23"> 以上都是服侍王的軍兵，不包括王派去駐守猶大各堅城的軍兵。</span>
</div>

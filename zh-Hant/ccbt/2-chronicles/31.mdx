## 希西迦的改革

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀下 18:4; 歷代志下 32:12; 創世記 19:15"> 當一切都辦妥後，所有在場的以色列人就前往猶大各城邑，砸碎神柱，砍倒亞舍拉神像，又拆毀猶大、便雅憫、以法蓮、瑪拿西境內所有的邱壇和祭壇，然後各自返回自己的城邑和家園。</span>
<span className="v" id="v2" data-v="2" data-xref="歷代志上 24:1; 歷代志上 16:4–6; 歷代志下 29:24–26"> 希西迦分派祭司和利未人的班次，使他們各司其職，獻上燔祭和平安祭，在耶和華殿門內事奉，稱謝、頌讚耶和華。</span>
<span className="v" id="v3" data-v="3" data-xref="以西結書 45:17; 歷代志下 35:7; 歌羅西書 2:16–17"> 王又從自己的產業中劃分出一部分作為早晚的燔祭，以及安息日、朔日和耶和華律法規定的其他節期的燔祭。</span>
<span className="v" id="v4" data-v="4" data-xref="瑪拉基書 2:7; 民數記 18:8–21; 尼希米記 13:10–13"> 他又吩咐耶路撒冷的居民將祭司和利未人當得的份交給他們，好使他們專心執行耶和華的律法。</span>
<span className="v" id="v5" data-v="5" data-xref="尼希米記 13:12; 歷代志下 24:10–11; 尼希米記 10:35–39"> 諭旨一出，以色列人就獻出許多初熟的五穀、新酒、新油、蜂蜜、田間的出產等各樣物品的十分之一，數量極多。</span>
<span className="v" id="v6" data-v="6" data-xref="利未記 27:30; 歷代志下 11:16–17; 申命記 14:28"> 住在猶大各城的以色列人和猶大人也送來牛羊的十分之一，以及獻給他們的上帝耶和華的聖物，就是十一奉獻，把它們堆積成堆。</span>
<span className="v" id="v7" data-v="7" data-xref="利未記 23:16–24"> 他們從三月開始堆積，到七月才結束。</span>
<span className="v" id="v8" data-v="8" data-xref="以弗所書 1:3; 創世記 14:19–20; 腓立比書 4:10"> 希西迦與眾官員來了，看見堆積起來的供物，就稱頌耶和華，又為耶和華的以色列子民祝福。</span>
<span className="v" id="v9" data-v="9"> 希西迦向祭司和利未人詢問這些供物的事，</span>
<span className="v" id="v10" data-v="10" data-xref="瑪拉基書 3:10; 歷代志上 6:8; 哥林多後書 9:8–11"> 撒督家族的亞撒利雅大祭司回答說：「自從民眾把這些供物送到耶和華的殿裡以來，我們不但吃得飽，還剩下許多。因為耶和華賜福給祂的子民，所以才有這麼多剩餘。」</span>
<span className="v" id="v11" data-v="11" data-xref="尼希米記 10:38–39; 尼希米記 13:5; 尼希米記 13:12–13"> 於是，希西迦下令在耶和華的殿裡預備庫房。他們預備好後，</span>
<span className="v" id="v12" data-v="12" data-xref="歷代志下 35:9; 列王紀下 12:15; 歷代志上 26:20–26"> 便忠心地把供物、十一奉獻和聖物放進庫房。利未人歌楠雅總管這事，他的兄弟示每做助手。</span>
<span className="v" id="v13" data-v="13" data-xref="歷代志上 24:5; 歷代志下 31:10–11; 歷代志上 9:11"> 耶歇、亞撒細雅、拿哈、亞撒黑、耶利摩、約撒拔、以列、伊斯瑪基雅、瑪哈和比拿雅做監督協助歌楠雅和他兄弟示每，他們都是希西迦王和管理上帝殿的亞撒利雅指派的。</span>
<span className="v" id="v14" data-v="14" data-xref="利未記 23:38; 歷代志上 26:12; 利未記 27:28"> 看守東門的利未人音拿的兒子可利，負責管理民眾自願獻給上帝的禮物，以及分發獻給耶和華的供物和至聖的祭物。</span>
<span className="v" id="v15" data-v="15" data-xref="約書亞記 21:9–19; 歷代志上 9:22; 歷代志下 29:12"> 伊甸、珉雅珉、耶書亞、示瑪雅、亞瑪利雅和示迦尼雅在祭司所在的各城忠心地協助可利，按照班次，不分老幼，將物品分給他們的弟兄。</span>
<span className="v" id="v16" data-v="16" data-xref="以斯拉記 3:4; 利未記 21:22–23; 歷代志上 23:3"> 此外，他們還分給三歲及三歲以上、名字記在家譜上、每天在耶和華的殿中按班次供職的男子，</span>
<span className="v" id="v17" data-v="17" data-xref="歷代志上 23:24; 歷代志上 23:27; 民數記 3:15"> 並分給按宗族登記在家譜上的祭司，按班次和職任分給二十歲及二十歲以上的利未人，</span>
<span className="v" id="v18" data-v="18" data-xref="羅馬書 15:16; 以賽亞書 5:16; 歷代志下 31:15"> 也按照家譜分給他們的妻子兒女，因為他們誠心潔淨自己。</span>
<span className="v" id="v19" data-v="19" data-xref="歷代志下 31:12–15; 利未記 25:34; 民數記 35:2–5"> 至於住在各城郊野做祭司的亞倫子孫，各城都有指定的人把應得之份分給祭司中所有的男子和登記在家譜上的利未人。</span>
<span className="v" id="v20" data-v="20" data-xref="列王紀下 20:3; 列王紀下 22:2; 使徒行傳 24:16"> 希西迦在猶大全境都如此行，做他的上帝耶和華視為良善、正直和忠心的事。</span>
<span className="v" id="v21" data-v="21" data-xref="馬太福音 6:33; 耶利米書 29:13; 約書亞記 1:7–8"> 無論是在上帝的殿中事奉，還是遵行律法和誡命，他都尋求他的上帝，盡心去做。因此，他行事順利。</span>

## 約西亞守逾越節

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及記 12:6; 民數記 9:3; 列王紀下 23:21–23"> 約西亞在耶路撒冷為耶和華守逾越節。一月十四日，眾人宰殺逾越節的羔羊。</span>
<span className="v" id="v2" data-v="2" data-xref="歷代志下 31:2; 歷代志上 22:19; 歷代志下 29:5–11"> 他指派祭司各盡其職，鼓勵他們在耶和華的殿裡事奉，</span>
<span className="v" id="v3" data-v="3" data-xref="歷代志上 23:26; 瑪拉基書 2:7; 申命記 33:10"> 又對將自己獻給耶和華、負責教導以色列人的利未人說：「你們把聖約櫃放在以色列王大衛的兒子所羅門建的殿裡，不用再扛在肩上。現在你們去事奉你們的上帝耶和華和祂的以色列子民吧。</span>
<span className="v" id="v4" data-v="4" data-xref="歷代志下 8:14; 歷代志上 23:1–26; 尼希米記 11:10–20"> 你們要按宗族和班次，依照以色列王大衛和他兒子所羅門所寫的指示，預備自己。</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 134:1; 詩篇 135:2; 以斯拉記 6:18"> 你們要按你們以色列同胞所在宗族的班次，侍立在聖所，每個班次中要有幾個利未宗族的人。</span>
<span className="v" id="v6" data-v="6" data-xref="歷代志下 29:5; 希伯來書 9:13–14; 歷代志下 29:15"> 你們要宰殺逾越節的羔羊，潔淨自己，為你們的同胞做好準備，依照耶和華藉摩西所吩咐的去行。」</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀上 8:63; 歷代志下 30:24; 以賽亞書 32:8"> 約西亞王從自己的產業中，捐出三萬隻綿羊羔和山羊羔，以及三千頭公牛，賜給所有在場的人做逾越節的祭牲。</span>
<span className="v" id="v8" data-v="8" data-xref="歷代志下 29:31–33; 耶利米書 29:25–26; 歷代志上 24:4–5"> 他的眾官員也自願為民眾、祭司和利未人捐獻。管理上帝殿的希勒迦、撒迦利亞和耶歇獻出兩千六百隻羊羔和三百頭牛，給祭司做逾越節的祭牲。</span>
<span className="v" id="v9" data-v="9" data-xref="耶利米書 7:21–28; 耶利米書 3:10; 以賽亞書 1:10–15"> 利未人的首領歌楠雅和他的兩個兄弟示瑪雅和拿坦業，及哈沙比雅、耶利、約撒拔獻出五千隻羊羔和五百頭牛，給利未人做逾越節的祭牲。</span>
<span className="v" id="v10" data-v="10" data-xref="歷代志下 30:16; 以斯拉記 6:18; 歷代志下 35:4–5"> 一切都準備好後，依照王的吩咐，祭司站在自己的地方，利未人按照班次侍立。</span>
<span className="v" id="v11" data-v="11" data-xref="歷代志下 29:34; 希伯來書 9:21–22; 歷代志下 29:22–24"> 利未人宰殺逾越節的羔羊，祭司從他們手中接過血，灑在壇上，利未人又剝去祭牲的皮。</span>
<span className="v" id="v12" data-v="12" data-xref="利未記 3:9–11; 利未記 3:3; 利未記 3:5"> 他們按照家族把燔祭分給眾人，好使他們按照摩西書上所寫的，把祭物獻給耶和華。獻牛也是這樣。</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及記 12:8–9; 撒母耳記上 2:13–15; 申命記 16:7"> 他們按規定用火烤逾越節的羔羊，在鍋裡、罐裡和盆裡煮聖物，然後迅速分給民眾。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行傳 6:2–4"> 之後，利未人為自己和祭司預備祭物，因為做祭司的亞倫子孫要繼續獻燔祭和脂肪一直到晚上。</span>
<span className="v" id="v15" data-v="15" data-xref="歷代志上 25:1–7; 歷代志上 26:12–19; 歷代志上 9:17–19"> 負責歌樂的亞薩子孫依照大衛、亞薩、希幔和王的先見耶杜頓的吩咐，站在自己的崗位上；殿門守衛都看守各門，不必離開工作崗位，因為他們的弟兄利未人為他們預備了祭物。</span>
<span className="v" id="v16" data-v="16"> 當天，一切事奉耶和華的事都辦好了，他們就按約西亞王的命令守逾越節，又在耶和華的壇上獻燔祭。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及記 12:15–20; 歷代志下 30:21–23; 出埃及記 23:15"> 所有在場的以色列人都在那時守逾越節，又守除酵節七天。</span>
<span className="v" id="v18" data-v="18" data-xref="歷代志下 30:5; 列王紀下 23:21–23; 歷代志下 30:26–27"> 自撒母耳先知以來，在以色列從來沒有這樣守過逾越節，以色列從沒有君王像約西亞、祭司、利未人、所有在場的猶大人和以色列人，以及耶路撒冷的居民這樣守過逾越節。</span>
<span className="v" id="v19" data-v="19"> 這次逾越節是在約西亞執政第十八年慶祝的。</span>
</div>

## 約西亞逝世

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="以賽亞書 10:9; 列王紀下 23:29–30; 耶利米書 46:2–12"> 約西亞辦理完殿裡的事後，埃及王尼哥上來，要攻打幼發拉底河附近的迦基米施。約西亞出兵迎戰他。</span>
<span className="v" id="v21" data-v="21" data-xref="歷代志下 25:19; 列王紀下 18:25; 以賽亞書 36:10"> 尼哥派使者對約西亞說：「猶大王啊，我與你沒有恩怨。我今天來不是要攻擊你，而是要攻擊與我作戰的那一家。上帝吩咐我要速速完成，你不要與上帝作對，免得祂毀滅你，因為上帝與我同在。」</span>
<span className="v" id="v22" data-v="22" data-xref="士師記 5:19; 歷代志下 18:29; 列王紀上 22:30"> 約西亞卻不聽上帝藉尼哥說的話。他沒有退兵，反而喬裝上陣，與尼哥會戰於米吉多平原。</span>
<span className="v" id="v23" data-v="23" data-xref="列王紀上 22:34; 列王紀下 9:24; 創世記 49:23"> 約西亞王被弓箭手射中，就對臣僕說：「我受了重傷，帶我離開吧。」</span>
<span className="v" id="v24" data-v="24" data-xref="撒迦利亞書 12:11; 列王紀下 23:30; 詩篇 36:6"> 他的臣僕就扶他下戰車，上另一輛戰車，送他到耶路撒冷。約西亞死在那裡，葬在他祖先的墳墓裡。所有猶大和耶路撒冷的人都為他哀悼。</span>
<span className="v" id="v25" data-v="25" data-xref="耶利米哀歌 4:20; 耶利米書 22:10; 約伯記 3:8"> 耶利米為約西亞作了哀歌，所有的男女歌樂手至今仍用這些哀歌紀念約西亞，成了以色列的傳統。這些哀歌都記在《哀歌書》上。</span>
<span className="v" id="v26" data-v="26" data-xref="歷代志下 31:20; 歷代志下 32:32"> 約西亞其他的事和他怎樣忠心地遵行耶和華的律法，</span>
<span className="v" id="v27" data-v="27" data-xref="歷代志下 26:22; 歷代志下 25:26; 列王紀下 10:34"> 以及他自始至終的作為都記在《以色列和猶大列王史》上。</span>
</div>

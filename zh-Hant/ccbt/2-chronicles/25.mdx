## 猶大王亞瑪謝

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀下 14:1–6"> 亞瑪謝二十五歲登基，在耶路撒冷執政二十九年。他母親叫約耶但，是耶路撒冷人。</span>
<span className="v" id="v2" data-v="2" data-xref="歷代志下 25:14; 雅各書 4:8; 使徒行傳 8:21"> 他做耶和華視為正的事，只是沒有全心去做。</span>
<span className="v" id="v3" data-v="3" data-xref="歷代志下 24:25–26; 列王紀下 14:5–22; 創世記 9:5–6"> 他鞏固王位後，立即處死了殺他父王的臣僕，</span>
<span className="v" id="v4" data-v="4" data-xref="申命記 24:16; 以西結書 18:20; 列王紀下 14:5–6"> 但沒有處死他們的孩子，好遵行耶和華在摩西律法書中的吩咐：「不可因孩子犯罪而處死父親，也不可因父親犯罪而處死孩子。各人要自負罪責。」<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="申命記24·16。">a</a></sup></span>
</div>
</div>

## 與西珥人交戰

<div className="bt">
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="民數記 1:3; 歷代志下 17:14–18; 歷代志下 11:1"> 亞瑪謝召集猶大人，按著猶大和便雅憫宗族設立千夫長和百夫長，並統計二十歲以上、能使用盾牌矛槍且有作戰能力的精兵，共有三十萬人。</span>
<span className="v" id="v6" data-v="6"> 他又用六萬八千兩銀子從以色列雇來十萬精兵。</span>
<span className="v" id="v7" data-v="7" data-xref="歷代志下 19:2; 列王紀上 12:28; 何西阿書 9:13"> 一位上帝的僕人來對他說：「王啊，不要讓以色列的軍隊與你同去，因為耶和華不與以色列，不與以法蓮人同在。</span>
<span className="v" id="v8" data-v="8" data-xref="歷代志下 14:11; 歷代志下 20:6; 腓立比書 4:19"> 你若一定要去，即使你奮勇爭戰，上帝也必使你敗在敵人面前，因為上帝有能力幫助，也有能力傾覆。」</span>
<span className="v" id="v9" data-v="9" data-xref="箴言 10:22; 申命記 8:18"> 亞瑪謝問上帝的僕人：「我付給以色列軍隊的六萬八千兩銀子怎麼辦？」上帝的僕人回答說：「耶和華能賜給你更多銀子。」</span>
<span className="v" id="v10" data-v="10" data-xref="列王紀上 12:24; 撒母耳記下 19:43; 箴言 29:22"> 於是，亞瑪謝解散從以法蓮雇來的軍隊，讓他們回家去。他們非常惱怒猶大人，怒氣沖沖地回家去了。</span>
<span className="v" id="v11" data-v="11" data-xref="列王紀下 14:7; 詩篇 60:1; 撒母耳記下 8:13"> 亞瑪謝鼓起勇氣，率領本國軍隊去鹽谷，殺了一萬西珥人，</span>
<span className="v" id="v12" data-v="12" data-xref="歷代志下 20:10; 歷代志上 20:3; 撒母耳記下 12:31"> 又把生擒的一萬人帶到山崖上推下去摔得粉身碎骨。</span>
<span className="v" id="v13" data-v="13" data-xref="歷代志下 8:5; 列王紀上 16:29; 列王紀上 9:17"> 可是，那些被亞瑪謝遣返、不許一同出征的以色列軍隊侵入從撒瑪利亞到伯·和崙一帶的猶大各城，殺了三千人，搶了大批財物。</span>
<span className="v" id="v14" data-v="14" data-xref="歷代志下 28:23; 申命記 7:25; 申命記 7:5"> 亞瑪謝殺敗以東人<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="以東人又稱西珥人。">b</a></sup>後，帶回了西珥人的神像，立為自己的神明，向它們祭拜燒香。</span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 96:5; 歷代志下 25:11–12; 歷代志下 25:7"> 因此，耶和華向亞瑪謝發怒，祂派一個先知去見他，說：「這些神明既然不能從你手中救自己的人民，你為什麼還要祭拜它們呢？」</span>
<span className="v" id="v16" data-v="16" data-xref="歷代志下 18:20–21; 耶利米書 29:26; 歷代志下 18:25"> 先知正說話的時候，王就說：「住口！我們立你做王的謀士了嗎？你要自取滅亡嗎？」先知便不再說什麼，只說：「我知道上帝已決定要毀滅你，因為你做了這事，不聽我的忠告。」</span>
</div>
</div>

## 與以色列交戰

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="列王紀下 14:8–14; 歷代志下 25:13; 箴言 20:3"> 猶大王亞瑪謝與群臣商議後，就派人對耶戶的孫子、約哈斯的兒子、以色列王約阿施說：「來，我們戰場上見。」</span>
<span className="v" id="v18" data-v="18" data-xref="士師記 9:8–15; 列王紀上 4:33; 詩篇 80:13"> 以色列王約阿施派人回覆猶大王亞瑪謝說：「黎巴嫩的蒺藜派使者去對黎巴嫩的香柏樹說，『將你女兒嫁給我兒子吧。』後來黎巴嫩的一隻野獸經過，把那蒺藜踐踏在腳下。</span>
<span className="v" id="v19" data-v="19" data-xref="歷代志下 26:16; 歷代志下 32:25; 箴言 18:6"> 你打敗了以東人就趾高氣揚。你還是待在家裡吧，何必惹禍上身，使你和猶大一同滅亡呢？」</span>
<span className="v" id="v20" data-v="20" data-xref="歷代志下 22:7; 列王紀上 12:15; 彼得前書 2:8"> 但亞瑪謝不理會他的勸告。原來這事出於上帝，要把他們交在約阿施手中，因為他們求告以東的神明。</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳記上 6:19–20; 撒母耳記上 6:9; 約書亞記 21:16"> 於是，以色列王約阿施起兵攻打猶大王亞瑪謝，兩王會戰於猶大的伯·示麥。</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳記上 4:10; 歷代志下 28:5–6; 列王紀上 22:36"> 猶大人被以色列人打敗，兵將都各自逃回家去了。</span>
<span className="v" id="v23" data-v="23" data-xref="歷代志下 21:17; 尼希米記 8:16; 歷代志下 26:9"> 以色列王約阿施在伯·示麥擒獲約哈斯的孫子、約阿施的兒子猶大王亞瑪謝，把他帶到耶路撒冷，又拆毀從以法蓮門到角門約一百八十米長的耶路撒冷城牆，</span>
<span className="v" id="v24" data-v="24" data-xref="歷代志上 26:15; 歷代志下 12:9; 列王紀下 14:14"> 搶走上帝殿中俄別·以東看守的所有金銀和器皿，以及王宮裡的財寶，並帶著人質返回撒瑪利亞。</span>
<span className="v" id="v25" data-v="25" data-xref="列王紀下 14:17–22"> 約哈斯的兒子以色列王約阿施死後，約阿施的兒子猶大王亞瑪謝又活了十五年。</span>
<span className="v" id="v26" data-v="26" data-xref="歷代志下 20:34; 列王紀下 14:15"> 亞瑪謝其他的事自始至終都記在《猶大與以色列列王史》上。</span>
<span className="v" id="v27" data-v="27" data-xref="歷代志下 24:25; 約書亞記 10:31; 列王紀下 14:19"> 亞瑪謝背棄耶和華後，耶路撒冷有人謀反，他就逃到拉吉，但叛黨派人追到那裡殺了他。</span>
<span className="v" id="v28" data-v="28" data-xref="列王紀下 14:20"> 有人用馬將他的屍體馱回耶路撒冷，葬在猶大城他的祖墳裡。</span>
</div>
</div>

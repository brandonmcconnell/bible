## 約書亞的訣別之言

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="約書亞記 13:1; 約書亞記 21:44; 約書亞記 11:23"> 此後很長時間，耶和華使以色列人四境太平，沒有戰事。約書亞年事已高，</span>
<span className="v" id="v2" data-v="2" data-xref="約書亞記 24:1; 申命記 31:28; 歷代志上 28:1"> 他召來全體以色列人，包括長老、族長、審判官和官長，對他們說：「我已經老了，</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 14:14; 約書亞記 10:42; 約書亞記 10:14"> 你們都親眼看見你們的上帝耶和華怎樣為了你們而對付列邦，親自為你們爭戰。</span>
<span className="v" id="v4" data-v="4" data-xref="約書亞記 13:6–7; 約書亞記 18:10; 約書亞記 13:2"> 從約旦河到西邊地中海的這片土地，無論是已征服的還是沒有征服的，我已經用抽籤的方式分給你們各支派作產業。</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 11:23; 約書亞記 13:6; 出埃及記 33:2"> 你們的上帝耶和華必把列邦從你們面前驅離趕走，讓你們佔據他們的土地，正如你們的上帝耶和華的應許。</span>
<span className="v" id="v6" data-v="6" data-xref="申命記 5:32; 申命記 28:14; 箴言 4:26–27"> 所以，你們要剛強，謹遵摩西律法書上所記載的一切，不可有半點偏離。</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及記 23:13; 詩篇 16:4; 申命記 7:2–3"> 不可與你們中間剩下的異族混雜，不可提他們的神明或憑它們起誓，不可供奉和祭拜他們的神明。</span>
<span className="v" id="v8" data-v="8" data-xref="申命記 10:20; 約書亞記 22:5; 申命記 13:4"> 你們要一如既往地倚靠你們的上帝耶和華，</span>
<span className="v" id="v9" data-v="9" data-xref="約書亞記 1:5; 申命記 11:23; 約書亞記 23:5"> 因為祂為你們趕走了強大的外族人，至今無人敵得過你們。</span>
<span className="v" id="v10" data-v="10" data-xref="申命記 32:30; 利未記 26:8; 申命記 3:22"> 你們一個人能打敗他們一千人，因為你們的上帝耶和華照著祂的應許為你們爭戰。</span>
<span className="v" id="v11" data-v="11" data-xref="約書亞記 22:5; 申命記 6:5–12; 箴言 4:23"> 所以你們要特別謹慎，愛你們的上帝耶和華。</span>
<span className="v" id="v12" data-v="12" data-xref="申命記 7:3; 以西結書 18:24; 西番雅書 1:6"> 如果你們悖逆，跟你們當中剩下的異族人聯合，通婚往來，</span>
<span className="v" id="v13" data-v="13" data-xref="申命記 7:16; 民數記 33:55; 出埃及記 23:33"> 毫無疑問，你們的上帝耶和華必不再為你們趕走他們。相反，他們還要成為設在你們當中的圈套和陷阱，你們的肉中刺、眼中釘，直到你們在你們的上帝耶和華所賜給你們的這塊美好的土地上滅亡。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="路加福音 21:33; 列王紀上 2:2; 利未記 26:3–13"> 「我快要走完人世的路程了。你們深知你們的上帝耶和華賜給你們的一切美好應許，沒有一句落空，都已經應驗了。</span>
<span className="v" id="v15" data-v="15" data-xref="申命記 28:15–68; 利未記 26:14–46; 士師記 3:8"> 正如你們的上帝耶和華已成就祂應許給你們的一切福氣，祂也會照樣降各樣災禍給你們，直到把你們從祂所賜的這美好土地上毀滅。</span>
<span className="v" id="v16" data-v="16" data-xref="申命記 4:25–26; 列王紀下 24:20"> 你們如果違背你們的上帝耶和華吩咐你們遵守的約，去供奉、祭拜其他神明，祂必向你們發怒，使你們在祂所賜的這美好土地上迅速滅亡。」</span>
</div>

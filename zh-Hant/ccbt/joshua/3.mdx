## 走過約旦河

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="約書亞記 2:1; 馬可福音 1:35; 民數記 25:1"> 約書亞清早起來，率領全體以色列人離開什亭，來到約旦河邊安營，等候過河。</span>
<span className="v" id="v2" data-v="2" data-xref="約書亞記 1:10–11"> 過了三天，官長走遍各營，吩咐民眾說：</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 31:9; 撒母耳記下 6:13; 申命記 31:25"> 「你們看見做祭司的利未人抬著你們上帝耶和華的約櫃出發時，就要起身跟在後面。</span>
<span className="v" id="v4" data-v="4" data-xref="詩篇 89:7; 希伯來書 12:28–29; 出埃及記 3:5"> 這樣，你們就會知道路，因為你們從來沒有走過這條路。但你們要跟約櫃保持九百米的距離，不要走近約櫃。」</span>
<span className="v" id="v5" data-v="5" data-xref="約書亞記 7:13; 利未記 20:7; 約珥書 2:16"> 約書亞又對民眾說：「你們要潔淨自己，因為明天耶和華要在你們當中行奇事。」</span>
<span className="v" id="v6" data-v="6" data-xref="約翰福音 14:2–3; 民數記 14:15; 彌迦書 2:13"> 約書亞又對祭司說：「抬起約櫃，率領民眾過河吧！」他們就抬起約櫃，走在民眾前面。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="約書亞記 4:14; 約書亞記 1:5; 歷代志上 29:25"> 耶和華對約書亞說：「從今天開始，我要使你在以色列人面前得到尊榮，讓他們知道我與你同在，正如從前我跟摩西同在一樣。</span>
<span className="v" id="v8" data-v="8" data-xref="約書亞記 3:3; 約書亞記 3:17; 歷代志下 29:15"> 你要吩咐抬約櫃的祭司走到約旦河邊，站在水中。」</span>
<span className="v" id="v9" data-v="9" data-xref="申命記 4:1; 申命記 12:8"> 約書亞對以色列人說：「你們要來聽你們的上帝耶和華的話。</span>
<span className="v" id="v10" data-v="10" data-xref="申命記 7:1; 出埃及記 33:2; 詩篇 44:2–3"> 今天你們會明白永活的上帝就在你們當中，祂必在你們面前趕走迦南人、赫人、希未人、比利洗人、革迦撒人、亞摩利人和耶布斯人。</span>
<span className="v" id="v11" data-v="11" data-xref="撒迦利亞書 6:5; 撒迦利亞書 4:14; 詩篇 24:1"> 看啊，天下之主的約櫃要在你們前面過約旦河。</span>
<span className="v" id="v12" data-v="12" data-xref="約書亞記 4:2; 約書亞記 4:9; 約書亞記 4:4"> 現在，你們要從以色列的十二支派中選出十二個人來，每支派選一人。</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及記 15:8; 詩篇 78:13; 約書亞記 3:15–16"> 當祭司抬著天下之主耶和華的約櫃一踏進約旦河，往下流的河水必止住，形成一道水堤。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="使徒行傳 7:44–45; 約書亞記 6:6; 哥林多前書 1:24–25"> 那時是收割的季節，河水高漲，淹沒兩岸。民眾拔營準備過河，抬約櫃的祭司走在前頭。祭司的腳剛一踏進河水，</span>
<span className="v" id="v16" data-v="16" data-xref="約書亞記 3:13; 列王紀上 4:12; 列王紀上 7:46"> 往下流的水立刻止住了，在很遠的撒拉但附近的亞當城那裡漲成一道水牆。流入亞拉巴海，即鹽海的水完全被截斷了，民眾便走到對面的耶利哥。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及記 14:22; 出埃及記 14:29; 詩篇 66:6"> 以色列人過河的時候，抬耶和華約櫃的祭司站在河中間的乾地上，直到所有人都從乾地上過了約旦河。</span>
</div>
</div>

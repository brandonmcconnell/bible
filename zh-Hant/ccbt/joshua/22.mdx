## 建祭壇之爭

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民數記 32:18–33; 申命記 29:7–8"> 約書亞召來了呂便、迦得和瑪拿西半個支派的人來，</span>
<span className="v" id="v2" data-v="2" data-xref="約書亞記 1:12–18; 申命記 3:16–20; 民數記 32:20–29"> 對他們說：「你們都遵守了耶和華的僕人摩西的一切吩咐，也聽從了我的一切吩咐。</span>
<span className="v" id="v3" data-v="3" data-xref="腓立比書 1:23–27"> 這些日子以來，你們從沒有離棄自己的弟兄，遵守了你們的上帝耶和華的吩咐。</span>
<span className="v" id="v4" data-v="4" data-xref="約書亞記 13:8; 民數記 32:18; 申命記 3:20"> 現在你們的上帝耶和華已經照祂的應許，使你們的弟兄安居，你們可以回到約旦河東，到摩西賜給你們作產業的地方。</span>
<span className="v" id="v5" data-v="5" data-xref="馬太福音 22:37; 出埃及記 20:6; 羅馬書 8:28"> 不過，你們要謹遵耶和華的僕人摩西吩咐你們的誡命和律法，要愛你們的上帝耶和華，遵行祂的旨意，聽從祂的命令，依靠祂，全心全意地事奉祂。」</span>
<span className="v" id="v6" data-v="6" data-xref="約書亞記 14:13; 路加福音 24:50; 創世記 47:7"> 於是，約書亞為他們祝福，送他們回去，他們就各自返回家園去了。</span>
<span className="v" id="v7" data-v="7" data-xref="約書亞記 17:1–12; 民數記 32:33; 約書亞記 13:29–31"> 摩西已經在巴珊把土地分給了瑪拿西半個支派，約書亞把約旦河西的土地分給了瑪拿西另外的半個支派及其他支派。約書亞派他們回家的時候，為他們祝福，</span>
<span className="v" id="v8" data-v="8" data-xref="民數記 31:27; 申命記 8:9–14; 箴言 3:16"> 說：「現在你們帶著大量財物、牲畜、金銀、銅、鐵和衣物返回家園，要把從敵人那裡得來的財物分給你們的弟兄。」</span>
<span className="v" id="v9" data-v="9" data-xref="民數記 32:29; 民數記 32:26; 民數記 32:1"> 於是，呂便、迦得和瑪拿西半個支派的人，便離開在迦南的示羅的以色列人，返回耶和華藉摩西分配給他們的基列。</span>
<span className="v" id="v10" data-v="10" data-xref="約書亞記 24:26–27; 創世記 31:46–52; 約書亞記 4:5–9"> 他們來到約旦河附近的迦南境內，就在約旦河邊築了一座高大的祭壇。</span>
<span className="v" id="v11" data-v="11" data-xref="申命記 13:12–14; 利未記 17:8–9; 約書亞記 2:7"> 以色列人聽見呂便、迦得和瑪拿西半個支派的人，在約旦河西的迦南境內築起了一座祭壇，</span>
<span className="v" id="v12" data-v="12" data-xref="士師記 20:1–11; 申命記 13:15; 加拉太書 4:17–18"> 便全部聚集在示羅，要討伐他們。</span>
<span className="v" id="v13" data-v="13" data-xref="民數記 25:7; 詩篇 106:30–31; 出埃及記 6:25"> 以色列人派祭司以利亞撒的兒子非尼哈去基列見他們，</span>
<span className="v" id="v14" data-v="14" data-xref="民數記 1:4; 出埃及記 18:25"> 又從每支派差遣一位族長，共十位隨行。</span>
<span className="v" id="v15" data-v="15" data-xref="歷代志上 21:3; 撒母耳記上 15:23; 申命記 30:17"> 他們來到基列的呂便、迦得和瑪拿西半個支派的人那裡，對他們說：</span>
<span className="v" id="v16" data-v="16" data-xref="申命記 12:13–14"> 「耶和華的全體會眾問你們，你們怎能這樣背叛以色列的上帝，離棄耶和華，為自己另建祭壇呢？</span>
<span className="v" id="v17" data-v="17" data-xref="民數記 25:1–18; 詩篇 106:28–29; 申命記 4:3–4"> 從前拜毗珥的罪惡不夠大嗎？那一次，瘟疫降到耶和華的會眾身上，直到今日我們還沒有洗淨這罪。</span>
<span className="v" id="v18" data-v="18" data-xref="民數記 16:22; 約書亞記 22:16; 約書亞記 7:11"> 你們今日要離棄耶和華嗎？今日你們背叛耶和華，明日祂必向以色列全體會眾發怒。</span>
<span className="v" id="v19" data-v="19" data-xref="約書亞記 18:1; 歷代志下 11:16–17; 使徒行傳 10:14–15"> 你們如果認為自己的土地不潔淨，可以搬到耶和華的土地上跟我們一起居住，這裡有耶和華的聖幕。只是不可在耶和華的祭壇以外，為自己另築祭壇，以致背叛耶和華，背叛我們。</span>
<span className="v" id="v20" data-v="20" data-xref="約書亞記 7:1; 約書亞記 7:5; 約書亞記 7:18"> 從前謝拉的曾孫亞干私自留下那些耶和華吩咐要毀滅之物，耶和華的烈怒難道沒有臨到以色列全體會眾嗎？因他的罪而死的不只他一個人！」</span>
<span className="v" id="v21" data-v="21" data-xref="雅各書 1:19; 箴言 16:1; 彼得前書 3:15"> 呂便、迦得和瑪拿西半個支派的人便回答這些以色列的族長說：</span>
<span className="v" id="v22" data-v="22" data-xref="列王紀上 8:39; 詩篇 44:21; 申命記 10:17"> 「大能的上帝耶和華，大能的上帝耶和華，祂知道一切！以色列人也當知道！如果我們悖逆或干犯耶和華，願祂今天就不放過我們！</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳記上 20:16; 申命記 18:19; 以西結書 3:18"> 如果我們離棄耶和華，為自己造祭壇，或在壇上獻燔祭、素祭和平安祭，願耶和華親自懲罰我們。</span>
<span className="v" id="v24" data-v="24" data-xref="約書亞記 4:6; 申命記 6:20; 創世記 30:33"> 我們這樣做是怕以後你們的子孫可能會對我們的子孫說，『你們和以色列的上帝耶和華有什麼關係？</span>
<span className="v" id="v25" data-v="25" data-xref="列王紀上 12:16; 以斯拉記 4:2–3; 撒母耳記上 26:19"> 耶和華把約旦河定為我們跟你們呂便人和迦得人的邊界，你們與耶和華一點關係也沒有。』這樣，恐怕你們的子孫會使我們的子孫不再敬畏耶和華。</span>
<span className="v" id="v26" data-v="26"> 因此，我們便商議在這裡築一座祭壇，這壇不是用來獻燔祭或別的祭，</span>
<span className="v" id="v27" data-v="27" data-xref="約書亞記 24:27; 創世記 31:48; 申命記 12:17–18"> 只是在你們和我們之間，也在彼此的後人之間立個證據，證明我們也獻燔祭、平安祭及其他祭事奉耶和華，免得日後你們的子孫對我們的子孫說，『你們與耶和華一點關係也沒有。』</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及記 25:40; 以西結書 43:10–11; 希伯來書 8:5"> 我們商議，萬一你們對我們或我們的子孫這樣說，我們可以回答說，『你們看我們祖先築的這座祭壇跟耶和華的祭壇一模一樣，只是這座壇不是用來獻燔祭或別的祭，而是作為你們和我們之間的證據！』</span>
<span className="v" id="v29" data-v="29" data-xref="約書亞記 24:16; 申命記 12:13–14; 約書亞記 22:23"> 我們根本無意背叛、離棄我們的上帝耶和華，在祂聖幕前的祭壇以外另築祭壇來獻燔祭、素祭和別的祭。」</span>
<span className="v" id="v30" data-v="30" data-xref="約書亞記 22:33; 以斯帖記 1:21; 箴言 15:1"> 祭司非尼哈和以色列會眾的族長聽了他們的解釋，都很滿意。</span>
<span className="v" id="v31" data-v="31" data-xref="歷代志下 15:2; 利未記 26:11–12; 以賽亞書 12:6"> 以利亞撒的兒子祭司非尼哈對他們說：「今日我們知道耶和華在我們當中，因為你們沒有對耶和華不忠，現在你們使以色列人免遭耶和華的懲罰了。」</span>
<span className="v" id="v32" data-v="32" data-xref="約書亞記 22:12–14; 箴言 25:13"> 以利亞撒的兒子非尼哈祭司和眾族長便離開呂便人和迦得人，從基列回到迦南向以色列人報告這事。</span>
<span className="v" id="v33" data-v="33" data-xref="歷代志上 29:20; 路加福音 2:28; 但以理書 2:19"> 眾人聽後，都很滿意，便頌讚耶和華，打消了出兵討伐呂便人和迦得人、毀滅他們家園的念頭。</span>
<span className="v" id="v34" data-v="34" data-xref="約書亞記 22:27; 馬太福音 4:10; 以賽亞書 43:10"> 呂便人和迦得人給那座祭壇取名叫「證壇」，意思是這壇在我們中間證明耶和華是上帝。</span>

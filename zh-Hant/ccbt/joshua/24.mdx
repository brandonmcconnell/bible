## 重申耶和華的約

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="約書亞記 23:2; 撒母耳記上 10:19; 創世記 33:18–19"> 約書亞在示劍招聚以色列各支派，他召來以色列的長老、族長、審判官和官長。他們一同站在上帝面前。</span>
<span className="v" id="v2" data-v="2" data-xref="約書亞記 24:15; 以西結書 16:3; 創世記 31:30"> 約書亞對全體民眾說：「以色列的上帝耶和華這樣說，『從前你們的祖先，包括亞伯拉罕和拿鶴二人的父親他拉，住在幼發拉底河那邊拜其他神明。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 12:1–4; 創世記 21:2–3; 使徒行傳 7:2–3"> 我把你們的祖先亞伯拉罕從幼發拉底河那邊帶出來，領他走遍迦南，使他人丁興旺。我把以撒賜給他，</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 36:8; 申命記 2:5; 創世記 25:24–26"> 把雅各和以掃賜給以撒，把西珥山賜給以掃作產業，雅各和他的子孫則去了埃及。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 3:10; 出埃及記 7:1–12; 詩篇 105:26–36"> 後來，我差遣了摩西和亞倫，並用災禍攻擊埃及人，把你們領出來。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行傳 7:36; 希伯來書 11:29; 以賽亞書 63:12–13"> 我帶你們的祖先出埃及，到達紅海，埃及人帶領戰車騎兵追了上來。</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 4:34; 出埃及記 14:10; 出埃及記 14:20"> 你們的祖先大聲呼求我，我就降下黑暗，把你們和埃及人分開，又用海水淹沒埃及人。你們親眼見過我在埃及的作為。後來，你們在曠野住了很長時間。</span>
<span className="v" id="v8" data-v="8" data-xref="民數記 21:21–35; 詩篇 135:10–11; 尼希米記 9:22"> 我領你們來到約旦河東邊亞摩利人居住的地方。他們跟你們爭戰，我把他們交在你們手中，使你們佔領他們的土地作自己的產業。我把他們從你們面前全部消滅。</span>
<span className="v" id="v9" data-v="9" data-xref="士師記 11:25; 彌迦書 6:5; 民數記 22:2"> 那時，摩押王西撥的兒子巴勒起兵攻打你們，並派人去召比珥的兒子巴蘭來咒詛你們。</span>
<span className="v" id="v10" data-v="10" data-xref="申命記 23:5; 民數記 24:5–10; 以賽亞書 54:17"> 但我不聽巴蘭的話，反而使他為你們連連祝福。這樣，我從巴勒手中救了你們。</span>
<span className="v" id="v11" data-v="11" data-xref="約書亞記 4:10–12; 約書亞記 3:14–17; 詩篇 114:5"> 你們過了約旦河來到耶利哥。耶利哥人、亞摩利人、比利洗人、迦南人、赫人、革迦撒人、希未人和耶布斯人都跟你們交戰，但我把他們交在你們手中。</span>
<span className="v" id="v12" data-v="12" data-xref="申命記 7:20; 出埃及記 23:28; 詩篇 44:3–6"> 我差黃蜂飛在你們前面，把亞摩利的兩個王從你們面前趕走，沒有動用你們一刀一弓。</span>
<span className="v" id="v13" data-v="13" data-xref="申命記 6:10–12; 申命記 8:7; 約書亞記 21:45"> 你們沒有開墾土地，也沒有建造城邑，但我賜給你們土地和城邑，使你們住在其中，享用別人栽種的葡萄園和橄欖園的果子。』</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="撒母耳記上 12:24; 申命記 10:12; 創世記 35:2"> 「所以，你們要敬畏耶和華，誠心誠意地事奉祂，棄絕你們祖先在幼發拉底河那邊和在埃及所拜的神明，專心事奉耶和華。</span>
<span className="v" id="v15" data-v="15" data-xref="列王紀上 18:21; 約翰福音 6:67–68; 路得記 1:15–16"> 你們如果不願事奉耶和華，今天就選擇你們的神明吧，或大河那邊你們祖先事奉的神明，或你們這裡亞摩利人的神明。至於我和我全家，我們必事奉耶和華。」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="希伯來書 10:38–39; 撒母耳記上 12:23; 羅馬書 6:2"> 民眾答道：「我們決不背棄耶和華去事奉其他神明，</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及記 19:4; 以賽亞書 63:7–14; 以賽亞書 46:4"> 因為我們的上帝耶和華曾領我們和我們的祖先脫離埃及人的奴役，在我們眼前行大神蹟，一路保護我們安然經過列邦。</span>
<span className="v" id="v18" data-v="18" data-xref="彌迦書 4:2; 出埃及記 10:2; 詩篇 116:16"> 耶和華把這地方的亞摩利人等外族人從我們面前趕走了，我們必事奉祂，因為祂是我們的上帝。」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="以賽亞書 5:16; 出埃及記 23:21; 詩篇 99:9"> 約書亞說：「你們不能事奉耶和華，祂是聖潔的上帝，祂痛恨不貞，必不赦免你們的過犯和罪惡。</span>
<span className="v" id="v20" data-v="20" data-xref="希伯來書 10:26–27; 以西結書 18:24; 歷代志上 28:9"> 如果你們背棄耶和華，去拜外族的神明，祂雖然恩待了你們，也必轉而降禍給你們，毀滅你們。」</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及記 20:19; 以賽亞書 44:5; 申命記 5:27–28"> 民眾答道：「不，我們一定要事奉耶和華。」</span>
<span className="v" id="v22" data-v="22" data-xref="詩篇 119:173; 詩篇 119:11; 約伯記 15:6"> 約書亞說：「現在你們自己作證，你們已選擇事奉耶和華。」民眾答道：「我們願意自己作證。」</span>
<span className="v" id="v23" data-v="23" data-xref="哥林多後書 6:16–18; 約書亞記 24:14; 希伯來書 12:28–29"> 約書亞說：「這樣，你們現在就要棄絕你們中間的外族神明，專心歸向以色列的上帝耶和華。」</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及記 24:7; 出埃及記 24:3; 申命記 5:27–29"> 民眾答道：「我們必事奉我們的上帝耶和華，聽從祂的話。」</span>
<span className="v" id="v25" data-v="25" data-xref="尼希米記 9:38; 歷代志下 23:16; 出埃及記 15:25"> 當天約書亞與民眾立約，在示劍為他們訂立律例和典章。</span>
<span className="v" id="v26" data-v="26" data-xref="士師記 9:6; 創世記 35:4; 約書亞記 4:20–24"> 約書亞把這些話都寫在上帝的律法書上，又把一塊大石頭豎立在耶和華聖所旁邊的橡樹下。</span>
<span className="v" id="v27" data-v="27" data-xref="路加福音 19:40; 約書亞記 22:34; 約書亞記 22:27–28"> 然後，他對民眾說：「看啊，這塊石頭可以為我們作證，它聽到了耶和華所吩咐我們的話。如果你們背棄上帝，它必作證。」</span>
<span className="v" id="v28" data-v="28" data-xref="士師記 2:6"> 於是，約書亞命民眾各自返回自己的地方。</span>
</div>
</div>

## 約書亞去世

<div className="bt">
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="士師記 2:8; 提摩太後書 4:7–8; 申命記 34:5"> 後來，耶和華的僕人、嫩的兒子約書亞去世了，享年一百一十歲。</span>
<span className="v" id="v30" data-v="30" data-xref="約書亞記 19:50; 士師記 2:9; 撒母耳記下 23:30"> 以色列人把他葬在他的土地上，就是在迦實山北邊、以法蓮山區的亭拿·西拉。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="士師記 2:7; 申命記 31:13; 申命記 11:2"> 約書亞在世的時候，以色列人都事奉耶和華。他死後，在那些經歷過耶和華奇妙作為的長老還健在期間，以色列人仍事奉耶和華。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="創世記 50:25; 創世記 33:19; 出埃及記 13:19"> 以色列人把從埃及帶出來的約瑟的骸骨葬在示劍，在從前雅各用一百塊銀子向哈抹的子孫買的那塊地裡。哈抹是示劍的父親。後來那塊地成了約瑟子孫的產業。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="約書亞記 22:13; 出埃及記 6:25; 以賽亞書 57:1–2"> 亞倫的兒子以利亞撒也死了，他們把他葬在他兒子非尼哈分到的以法蓮山區的基比亞。</span>
</div>
</div>

</div>

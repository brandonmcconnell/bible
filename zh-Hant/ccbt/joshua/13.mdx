## 尚未攻取之地

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="約書亞記 14:10; 申命記 31:3; 約書亞記 24:29"> 約書亞年事已高，耶和華對他說：「你年紀大了，但還有許多地方有待征服，</span>
<span className="v" id="v2" data-v="2" data-xref="約書亞記 13:11; 撒母耳記上 27:8; 約珥書 3:4"> 就是非利士人和基述人的全境，</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 2:23; 士師記 3:3; 耶利米書 2:18"> 即從埃及東面的西曷河直到北面以革倫的邊境，這一帶都算是迦南，是統治迦薩人、亞實突人、亞實基倫人、迦特人、以革倫人的五個非利士王的地方；南方亞衛人的地方；</span>
<span className="v" id="v4" data-v="4" data-xref="約書亞記 19:30; 撒母耳記上 4:1; 士師記 1:34–36"> 整個迦南人的地方，從西頓人的米亞拉直到亞摩利人邊境的亞弗；</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀上 5:18; 約書亞記 12:7; 詩篇 83:7"> 迦巴勒人的地方；東部從黑門山山麓的巴力·迦得直到哈馬口的整個黎巴嫩。</span>
<span className="v" id="v6" data-v="6" data-xref="約書亞記 11:8; 約書亞記 23:13; 士師記 2:21–23"> 我必為以色列人趕走從黎巴嫩到米斯利弗·瑪音一帶山區的所有西頓人。你只管照我的吩咐，把這些土地分給以色列人作產業，</span>
<span className="v" id="v7" data-v="7" data-xref="民數記 26:53–56; 民數記 33:54; 以西結書 48:23–29"> 分給其他九個支派和瑪拿西半個支派作產業。」</span>
</div>
</div>

## 約旦河東土地的分配

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="約書亞記 12:6; 申命記 3:12–17; 約書亞記 22:4"> 瑪拿西半個支派和呂便、迦得兩支派已經得到耶和華的僕人摩西在約旦河東分給他們的產業：</span>
<span className="v" id="v9" data-v="9" data-xref="約書亞記 13:16; 民數記 21:30; 約書亞記 12:2"> 從亞嫩谷旁的亞羅珥起，包括谷中的城，直到底本的整個米底巴平原，</span>
<span className="v" id="v10" data-v="10" data-xref="民數記 21:24–26"> 以及希實本的亞摩利王西宏統治的各城，直到亞捫的邊境。</span>
<span className="v" id="v11" data-v="11" data-xref="歷代志上 2:23; 約書亞記 12:2–5; 申命記 4:47–48"> 此外，還包括基列、基述人和瑪迦人的疆域、整個黑門山和直到撒迦的整個巴珊地，</span>
<span className="v" id="v12" data-v="12" data-xref="約書亞記 12:4; 約書亞記 14:3–4; 民數記 21:23–35"> 以及巴珊王噩的國土。噩曾經在亞斯她錄和以得來做王，是僅存的利乏音人。摩西打敗了這些人，趕走了他們。</span>
<span className="v" id="v13" data-v="13" data-xref="約書亞記 23:12–13; 約書亞記 13:11; 民數記 33:55"> 以色列人卻沒有趕走基述人和瑪迦人，他們到今天還住在以色列人當中。</span>
<span className="v" id="v14" data-v="14" data-xref="民數記 18:20–24; 約書亞記 14:3–4; 申命記 18:1–2"> 摩西並沒有把土地分給利未支派作產業，因為獻給以色列的上帝耶和華的火祭就是他們的產業，正如耶和華對他們的應許。</span>
<span className="v" id="v15" data-v="15"> 以下是摩西按宗族分給呂便支派的產業：</span>
<span className="v" id="v16" data-v="16" data-xref="約書亞記 13:9; 約書亞記 12:2; 以賽亞書 16:7–9"> 從亞嫩谷旁邊的亞羅珥城、谷中的城和米底巴附近的整個平原，</span>
<span className="v" id="v17" data-v="17" data-xref="民數記 22:41; 民數記 32:38; 民數記 21:19"> 到希實本城和希實本平原的所有城邑，即底本、巴末·巴力、伯·巴力·勉、</span>
<span className="v" id="v18" data-v="18" data-xref="民數記 21:23; 約書亞記 21:36–37; 歷代志上 6:78–79"> 雅雜、基底莫、米法押、</span>
<span className="v" id="v19" data-v="19" data-xref="民數記 32:37–38"> 基列亭、西比瑪、谷中山丘上的細列·沙轄、</span>
<span className="v" id="v20" data-v="20" data-xref="約書亞記 12:3; 申命記 4:46; 以西結書 25:9"> 伯毗珥、毗斯迦山坡和伯·耶施末，</span>
<span className="v" id="v21" data-v="21" data-xref="民數記 31:8; 申命記 3:10; 申命記 2:30–36"> 平原的各城邑和亞摩利王西宏的國土。西宏曾在希實本做王，摩西打敗了他和他的米甸首領以未、利金、蘇珥、戶珥和利巴。</span>
<span className="v" id="v22" data-v="22" data-xref="民數記 31:8; 猶大書 1:11; 彼得後書 2:15"> 以色列人用刀所殺的人中有比珥的兒子術士巴蘭。</span>
<span className="v" id="v23" data-v="23"> 呂便支派的土地以約旦河為界。以上是呂便支派按宗族分到的城邑和村莊。</span>
<span className="v" id="v24" data-v="24" data-xref="民數記 32:34–36"> 以下是摩西按宗族分給迦得支派的土地：</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳記下 12:26; 撒母耳記下 11:1; 民數記 32:35"> 雅謝和基列境內所有的城邑；亞捫人的一半領土，直到拉巴附近的亞羅珥；</span>
<span className="v" id="v26" data-v="26" data-xref="撒母耳記下 17:27; 撒母耳記下 2:8; 士師記 10:17"> 從希實本直到拉抹·米斯巴和比多寧，從瑪哈念到底璧的邊境；</span>
<span className="v" id="v27" data-v="27" data-xref="民數記 32:36; 民數記 34:11; 創世記 33:17"> 還有谷中的伯亞蘭、伯·寧拉、疏割、撒分，就是希實本王西宏國中其餘的土地，以約旦河為界，沿東岸直到加利利湖的頂端。</span>
<span className="v" id="v28" data-v="28"> 以上這些城邑、村莊便是迦得支派按宗族所分到的產業。</span>
<span className="v" id="v29" data-v="29"> 以下是摩西按宗族分給瑪拿西半個支派的土地：</span>
<span className="v" id="v30" data-v="30" data-xref="約書亞記 13:26; 申命記 3:13–15; 民數記 32:39–41"> 從瑪哈念開始，包括整個巴珊，就是巴珊王噩的國土及其境內雅珥的六十座城邑，</span>
<span className="v" id="v31" data-v="31" data-xref="約書亞記 12:4; 民數記 32:39–40"> 還有基列的一半和巴珊王噩的兩座城亞斯她錄和以得來。瑪拿西的兒子瑪吉的一半子孫按宗族分到這些土地。</span>
<span className="v" id="v32" data-v="32"> 以上是摩西在耶利哥對面約旦河東的摩押平原分給以色列人的產業。</span>
<span className="v" id="v33" data-v="33" data-xref="約書亞記 18:7; 約書亞記 13:14; 申命記 18:1–2"> 摩西並沒有分給利未支派任何產業，因為以色列的上帝耶和華就是他們的產業，正如耶和華對他們的應許。</span>
</div>
</div>

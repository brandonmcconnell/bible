## 其餘土地的分配

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="約書亞記 19:51; 撒母耳記上 1:3; 約書亞記 21:2"> 征服了這些地方以後，以色列全體會眾都聚集在示羅，把會幕設立在那裡。</span>
<span className="v" id="v2" data-v="2"> 這時，以色列還有七個支派沒有分到產業。</span>
<span className="v" id="v3" data-v="3" data-xref="士師記 18:9; 箴言 13:4; 箴言 10:4"> 約書亞對他們說：「你們等到什麼時候，才去佔領你們祖先的上帝耶和華賜給你們的土地呢？</span>
<span className="v" id="v4" data-v="4" data-xref="約書亞記 18:6; 約書亞記 4:2; 約書亞記 18:3"> 你們每支派要派出三個人，我要差他們走遍那地，按各支派應得的土地繪製地圖，然後回來稟告我。</span>
<span className="v" id="v5" data-v="5" data-xref="約書亞記 16:1–10; 約書亞記 19:1–9; 約書亞記 15:1–12"> 他們要把土地劃分作七份。猶大要留在南部自己的領土上，約瑟家族要留在北部自己的領土上。</span>
<span className="v" id="v6" data-v="6" data-xref="約書亞記 14:2; 約書亞記 18:10; 使徒行傳 13:19"> 你們把這七份土地繪成地圖交給我，我要在我們的上帝耶和華面前為你們抽籤。</span>
<span className="v" id="v7" data-v="7" data-xref="約書亞記 13:33; 約書亞記 13:8–31; 民數記 18:20"> 你們當中的利未人沒有份，因為做耶和華的祭司這職任就是他們的產業。至於迦得支派、呂便支派和瑪拿西半個支派，耶和華的僕人摩西已把約旦河東的土地分給他們了。」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="約書亞記 18:10; 羅馬書 14:19; 撒母耳記上 14:41"> 那些畫地圖的人啟程出發的時候，約書亞囑咐他們說：「你們要走遍那裡，繪製地圖，然後回來稟告我，我要在示羅，在耶和華面前為你們抽籤。」</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行傳 13:19"> 於是，他們走遍那裡，把所有城邑分作七份，繪在冊上，然後回到示羅見約書亞。</span>
<span className="v" id="v10" data-v="10" data-xref="歌羅西書 1:12; 使徒行傳 13:19; 約書亞記 18:6"> 約書亞便在示羅按照以色列的支派，在耶和華面前為他們抽籤分地。</span>
</div>
</div>

## 便雅憫支派分到的土地

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="約書亞記 16:1–10; 約書亞記 15:1–8; 申命記 10:1–22"> 便雅憫支派按宗族抽籤分到的領土，座落在猶大和約瑟支派的領土之間。</span>
<span className="v" id="v12" data-v="12" data-xref="約書亞記 16:1; 約書亞記 7:2; 約書亞記 2:1"> 他們北部的邊界從約旦河起，沿耶利哥北面的山坡直上，往西穿過山區，直到伯·亞文的曠野；</span>
<span className="v" id="v13" data-v="13" data-xref="創世記 28:19; 約書亞記 16:2–3; 約書亞記 10:11"> 從那裡經路斯，即伯特利南面山坡到下伯·和崙南面山區的亞他錄·亞達。</span>
<span className="v" id="v14" data-v="14" data-xref="約書亞記 15:9; 歷代志上 13:5–6; 撒母耳記上 7:1–2"> 西面的邊界自伯·和崙對面山的西側，向南直到猶大人的基列·巴力城，即基列·耶琳。</span>
<span className="v" id="v15" data-v="15" data-xref="約書亞記 15:9"> 南部邊界從基列·耶琳的邊界開始，向西直到尼弗多亞的水泉，</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀下 23:10; 約書亞記 15:7–8; 以賽亞書 30:33"> 又往下到欣嫩子谷對面的山麓，也就是利乏音谷北邊，然後往南，經欣嫩谷到耶布斯的南坡，直到隱·羅結；</span>
<span className="v" id="v17" data-v="17" data-xref="約書亞記 15:6"> 然後，向北先後到隱·示麥，亞都冥山坡對面的基利綠，呂便的兒子波罕所立的大石，</span>
<span className="v" id="v18" data-v="18" data-xref="約書亞記 15:6; 約書亞記 15:61"> 以及亞拉巴的對面，再往北下到亞拉巴；</span>
<span className="v" id="v19" data-v="19" data-xref="創世記 14:3; 約書亞記 15:2; 民數記 34:3"> 又沿著伯·曷拉的北面直到鹽海的北岸，也就是約旦河的南部河口。這是南部的邊界。</span>
<span className="v" id="v20" data-v="20"> 東面以約旦河為界。這是便雅憫人按宗族分到的土地四周的邊界。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="約書亞記 18:12; 約書亞記 6:1; 約書亞記 18:19"> 以下是便雅憫支派按宗族分到的城邑：耶利哥、伯·曷拉、伊麥·基悉、</span>
<span className="v" id="v22" data-v="22" data-xref="約書亞記 15:6; 列王紀上 12:29–32; 約書亞記 18:18"> 伯·亞拉巴、西瑪蓮、伯特利、</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳記上 13:17"> 亞文、巴拉、俄弗拉、</span>
<span className="v" id="v24" data-v="24" data-xref="以斯拉記 2:26; 約書亞記 21:17; 以賽亞書 10:29"> 基法·阿摩尼、俄弗尼、迦巴，共十二座城及其附近的鄉村。</span>
<span className="v" id="v25" data-v="25" data-xref="約書亞記 9:17; 列王紀上 3:4–5; 約書亞記 10:2"> 還有基遍、拉瑪、比錄、</span>
<span className="v" id="v26" data-v="26" data-xref="士師記 10:17; 以斯拉記 2:25; 約書亞記 9:17"> 米斯巴、基非拉、摩撒、</span>
<span className="v" id="v27" data-v="27"> 利堅、伊利毗勒、他拉拉、</span>
<span className="v" id="v28" data-v="28" data-xref="撒母耳記下 21:14; 約書亞記 15:8; 士師記 20:4–5"> 洗拉、以利弗、耶布斯，即耶路撒冷、基比亞、基列，共十四座城及其附近的鄉村。<br />這就是便雅憫各宗族所分到的土地。</span>
</div>
</div>

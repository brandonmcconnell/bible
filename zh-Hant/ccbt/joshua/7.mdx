## 亞干犯罪

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="約書亞記 22:20; 傳道書 9:18; 歷代志上 2:6–7"> 以色列人在當毀滅之物的事上犯了罪。因為猶大支派中謝拉的曾孫、撒底的孫子、迦米的兒子亞干拿了一些本該毀滅之物，耶和華便向以色列人發怒。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="約書亞記 18:12; 何西阿書 4:15; 撒母耳記上 14:23"> 當時，約書亞從耶利哥派人去伯特利東邊靠近伯·亞文的艾城，並吩咐道：「你們去偵察那地方。」那些人便上去偵察艾城。</span>
<span className="v" id="v3" data-v="3" data-xref="希伯來書 6:11–12; 路加福音 13:24; 彼得後書 1:5"> 他們偵察回來後對約書亞說：「那裡的居民很少，我們不必全軍出動，只要派兩三千人上去便可以攻取艾城，不必勞師動眾。」</span>
<span className="v" id="v4" data-v="4" data-xref="申命記 28:25; 利未記 26:17; 申命記 32:30"> 於是，大約有三千以色列人去攻打艾城，不料卻被艾城人擊潰。</span>
<span className="v" id="v5" data-v="5" data-xref="約書亞記 2:11; 約書亞記 2:9; 利未記 26:36"> 艾城的人殺了他們三十六人，從城門前追殺他們，一直到示巴琳，在下坡處殺敗他們。以色列人嚇得心驚膽戰。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="創世記 37:29; 創世記 37:34; 啟示錄 18:19"> 約書亞和以色列的長老便撕裂衣服，把灰撒在頭上，俯伏在耶和華的約櫃面前，直到晚上。</span>
<span className="v" id="v7" data-v="7" data-xref="希伯來書 12:5; 列王紀下 3:10; 馬太福音 17:20"> 約書亞說：「唉！主耶和華啊，你為什麼把我們帶過約旦河，交給亞摩利人毀滅呢？倒不如讓我們住在約旦河東岸！</span>
<span className="v" id="v8" data-v="8" data-xref="羅馬書 3:5–6; 以斯拉記 9:10; 哈巴谷書 2:1"> 主啊，現在以色列人被仇敵打敗，我還有什麼話可說呢？</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及記 32:12; 詩篇 83:4; 以西結書 36:22–23"> 迦南人和這一帶的人聽到這消息以後，必從四面八方來圍攻我們，將我們從地上斬盡殺絕。那時候，你的大名怎麼辦呢？」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="撒母耳記上 15:22; 出埃及記 14:15; 撒母耳記上 16:1"> 耶和華對約書亞說：「起來吧！你為何俯伏在地？</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行傳 5:1–2; 希伯來書 4:13; 約書亞記 6:17–19"> 以色列人犯了罪，違背了我吩咐他們應守的約，拿了本該毀滅之物放在自己的行囊裡，又偷竊又撒謊。</span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 5:4–5; 以賽亞書 59:2; 約書亞記 6:18"> 所以，以色列人無法抵擋敵人，掉頭敗逃，因為他們已成當毀之物。你必須將那些本該毀滅之物從你們中間除掉，不然我就不再與你們同在。</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米哀歌 3:40–41; 約書亞記 3:5; 馬太福音 7:5"> 起來吧！去吩咐民眾潔淨自己，讓他們為明天潔淨自己，因為以色列的上帝耶和華這樣說，『以色列啊！你們中間有當毀之物，你們不除掉它們就無法抵擋敵人。</span>
<span className="v" id="v14" data-v="14" data-xref="箴言 16:33; 約拿書 1:7; 約書亞記 7:17–18"> 明天早上，你們要按支派一個一個前來，耶和華指出哪個支派，哪支派的各宗族便要前來。耶和華指出哪個宗族，哪宗族的各家族便要前來。耶和華指出哪個家族，哪家族的各成員便要前來。</span>
<span className="v" id="v15" data-v="15" data-xref="創世記 34:7; 撒母耳記上 14:38–39; 士師記 20:6"> 哪個人被指出拿了本該毀滅之物，哪個人及其所有的東西就要被火焚燒。因為他違背了耶和華的約，在以色列人中做了可恥的事。』」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="詩篇 119:60; 約書亞記 3:1; 創世記 22:3"> 第二天清早，約書亞按照支派召來以色列人，結果抽中猶大支派；</span>
<span className="v" id="v17" data-v="17" data-xref="民數記 26:20; 歷代志上 2:4–7; 創世記 38:30"> 他讓猶大支派各宗族前來，結果抽中謝拉宗族；他讓謝拉宗族前來，結果抽中撒底家族；</span>
<span className="v" id="v18" data-v="18" data-xref="民數記 32:23; 使徒行傳 5:1–10; 撒母耳記上 14:42"> 他讓撒底家族的人一個一個前來，結果抽中猶大支派中謝拉的曾孫、撒底的孫子、迦米的兒子亞干。</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳記上 6:5; 耶利米書 13:16; 約翰福音 9:24"> 約書亞對亞干說：「孩子啊，我勸你把榮耀歸給以色列的上帝耶和華，向祂認罪，把你所做的事告訴我，不要隱瞞。」</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 38:18; 約伯記 33:27; 創世記 42:21"> 亞干答道：「我的確得罪了以色列的上帝耶和華。事情是這樣的，</span>
<span className="v" id="v21" data-v="21" data-xref="雅各書 1:15; 詩篇 119:37; 約翰一書 2:15–16"> 在奪得的財物中，我看上了一件漂亮的示拿外衣、四十五兩銀子和十兩金子，我一時貪心便拿去了，藏在我帳篷的地底下，銀子就放在衣服下面。」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22"> 約書亞派人跑到他帳篷裡，果然那件外衣藏在他帳篷裡，銀子在衣服下面。</span>
<span className="v" id="v23" data-v="23"> 他們從帳篷裡取出這些東西，將它們帶到約書亞和全體民眾那裡，擺在耶和華面前。</span>
<span className="v" id="v24" data-v="24" data-xref="箴言 15:27; 提摩太前書 6:9–10; 約書亞記 7:26"> 約書亞和全體以色列人把謝拉家族的亞干、那些銀子、衣服和金子及其兒女、牛、驢、羊、帳篷和一切所有都帶到亞割谷。</span>
<span className="v" id="v25" data-v="25" data-xref="約書亞記 6:18; 歷代志上 2:7; 利未記 24:14"> 約書亞對亞干說：「你為什麼給我們惹禍呢？耶和華今天要降禍給你。」於是，以色列人便拿石頭打死了他及其一切，將他們燒毀。</span>
<span className="v" id="v26" data-v="26" data-xref="以賽亞書 65:10; 何西阿書 2:15; 申命記 13:17"> 他們在亞干身上堆起一大堆石頭，那些石頭今天還在。耶和華這才息怒，因此那地方至今還叫亞割<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「亞割」意思是「連累」。">a</a></sup>谷。</span>
</div>
</div>

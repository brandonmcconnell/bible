## 堆石為證

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命記 27:2; 約書亞記 3:17"> 民眾都過河之後，耶和華對約書亞說：</span>
<span className="v" id="v2" data-v="2" data-xref="約書亞記 3:12; 民數記 1:4–15; 列王紀上 18:31"> 「你去從民眾中選出十二個人，每支派選一人，</span>
<span className="v" id="v3" data-v="3" data-xref="約書亞記 4:19–20; 約書亞記 3:13; 約書亞記 4:8"> 吩咐他們從約旦河床祭司站立的地方取十二塊石頭，放在你們今晚住宿的地方。」</span>
<span className="v" id="v4" data-v="4" data-xref="約書亞記 4:2; 馬可福音 3:14–19"> 約書亞便召來他從以色列人中選的十二個人，每支派一人，對他們說：</span>
<span className="v" id="v5" data-v="5"> 「從你們上帝耶和華的約櫃前過去，到約旦河中間，以色列每個支派中有一人扛一塊石頭回來，一共十二塊，</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及記 13:14; 約書亞記 4:21; 詩篇 44:1"> 留在你們中間作記號。以後，倘若你們的子孫問你們，『這些石頭是什麼意思？』</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及記 12:14; 民數記 16:40; 出埃及記 28:12"> 你們就告訴他們，『約旦河水在耶和華的約櫃前曾經被截斷，當約櫃過河的時候，河水被截斷了。這些石頭要在以色列人當中作為永久的紀念。』」</span>
<span className="v" id="v8" data-v="8" data-xref="約書亞記 4:2–5; 約書亞記 1:16–18; 約書亞記 4:20"> 以色列人遵行了約書亞的吩咐。他們按以色列人支派的數目，從約旦河中取了十二塊石頭，搬來放在住宿的地方，正如耶和華對約書亞的吩咐。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳記上 7:12; 士師記 1:26; 歷代志下 5:9"> 約書亞又在約旦河床抬約櫃的祭司站立的地方立了十二塊石頭。石頭至今還在那裡。</span>
<span className="v" id="v10" data-v="10" data-xref="約書亞記 3:13; 詩篇 119:60; 箴言 27:1"> 抬約櫃的祭司站在約旦河中間，一直站到耶和華吩咐約書亞交待民眾做的每一件事都完成了，正如摩西對約書亞的吩咐。民眾迅速過了河。</span>
<span className="v" id="v11" data-v="11" data-xref="約書亞記 3:8; 約書亞記 4:18; 約書亞記 3:17"> 所有人都過河以後，祭司才抬著耶和華的約櫃在民眾注視下過了河。</span>
<span className="v" id="v12" data-v="12" data-xref="民數記 32:20–32; 約書亞記 1:14"> 呂便支派、迦得支派和瑪拿西半個支派的人照摩西從前的囑咐，帶著兵器走在以色列人前面。</span>
<span className="v" id="v13" data-v="13" data-xref="以弗所書 6:11; 耶利米書 39:5; 耶利米書 52:8"> 大約有四萬武裝好的以色列人在耶和華面前過了河，前往耶利哥平原，準備作戰。</span>
<span className="v" id="v14" data-v="14" data-xref="約書亞記 3:7; 歷代志下 30:12; 列王紀上 3:28"> 那一天，耶和華在以色列眾人面前提升約書亞，在他有生之年，他們像敬畏摩西一樣敬畏他。</span>
<span className="v" id="v15" data-v="15"> 耶和華對約書亞說：</span>
<span className="v" id="v16" data-v="16" data-xref="啟示錄 11:19; 出埃及記 25:16–22; 約書亞記 3:3–6"> 「你去吩咐抬約櫃的祭司從約旦河裡上來。」</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 8:16–18; 使徒行傳 16:35–39; 使徒行傳 16:23"> 約書亞便吩咐他們從約旦河裡上來。</span>
<span className="v" id="v18" data-v="18" data-xref="約書亞記 3:15; 歷代志上 12:15; 約書亞記 3:13"> 抬耶和華約櫃的祭司從河床上來，腳剛一踏上岸，約旦河的水立刻恢復原狀，像以往一樣漲過兩岸。</span>
<span className="v" id="v19" data-v="19" data-xref="約書亞記 5:9; 彌迦書 6:5; 出埃及記 12:2–3"> 那天是一月十日。以色列人從約旦河上來後，就在耶利哥東邊的吉甲紮營。</span>
<span className="v" id="v20" data-v="20" data-xref="約書亞記 4:3; 約書亞記 4:8"> 約書亞把從約旦河取來的十二塊石頭立在吉甲，</span>
<span className="v" id="v21" data-v="21" data-xref="約書亞記 4:6; 詩篇 145:4–7; 詩篇 105:2–5"> 並對以色列人說：「以後，你們的子孫問你們這堆石頭是什麼意思，</span>
<span className="v" id="v22" data-v="22" data-xref="約書亞記 3:17; 以賽亞書 51:10; 以賽亞書 44:27"> 你們就告訴他們，『這是代表以色列人曾走乾地穿過約旦河。』</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及記 14:21; 以賽亞書 43:16; 以賽亞書 63:12–14"> 因為你們的上帝耶和華使約旦河成為乾地、讓你們穿過，就像祂從前使紅海成為乾地、讓我們穿過一樣。</span>
<span className="v" id="v24" data-v="24" data-xref="詩篇 106:8; 詩篇 89:13; 列王紀上 8:42–43"> 這是要讓天下萬民都知道耶和華的手大有能力，要讓你們永遠敬畏你們的上帝耶和華。」</span>

## 以色列人被基遍人欺騙

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民數記 34:6; 出埃及記 3:17; 出埃及記 23:23"> 住在約旦河西的山區、丘陵以及地中海沿岸、遠至黎巴嫩的諸王，就是那些赫人、亞摩利人、迦南人、比利洗人、希未人和耶布斯人的王聽說這件事，</span>
<span className="v" id="v2" data-v="2" data-xref="啟示錄 16:14; 約珥書 3:9–13; 詩篇 2:1–2"> 就聯合起來對抗約書亞和以色列人。</span>
<span className="v" id="v3" data-v="3" data-xref="約書亞記 10:2; 約書亞記 9:17; 撒母耳記下 21:1–2"> 基遍的居民聽說約書亞在耶利哥和艾城所做的事，</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 16:8; 馬太福音 10:16; 馬可福音 2:22"> 便想出一個詭計來。他們裝作特使，把舊皮袋和縫補過的酒囊馱在驢背上，</span>
<span className="v" id="v5" data-v="5" data-xref="路加福音 15:22; 申命記 33:25; 申命記 29:5"> 穿著縫補過的舊鞋和破爛衣服，帶著又乾又發黴的餅，</span>
<span className="v" id="v6" data-v="6" data-xref="約書亞記 5:10; 列王紀下 20:14; 約書亞記 9:9"> 到吉甲營去見約書亞。他們對約書亞和以色列人說：「我們從很遠的地方來，求你們跟我們締結盟約。」</span>
<span className="v" id="v7" data-v="7" data-xref="約書亞記 11:19; 士師記 2:2; 出埃及記 34:12"> 以色列人對這些希未人說：「你們也許就住在附近。我們怎麼能跟你們締結盟約呢？」</span>
<span className="v" id="v8" data-v="8" data-xref="申命記 20:11; 列王紀下 10:5; 約書亞記 9:11"> 他們對約書亞說：「我們是你的奴僕。」約書亞說：「你們是什麼人？從哪裡來？」</span>
<span className="v" id="v9" data-v="9" data-xref="申命記 20:15; 約書亞記 9:24; 以賽亞書 55:5"> 他們答道：「僕人們因為你的上帝耶和華的大名，才從很遠的地方來。我們聽說了祂在埃及的一切作為，</span>
<span className="v" id="v10" data-v="10" data-xref="民數記 21:24–35; 申命記 1:4; 約書亞記 12:4"> 以及祂怎樣對付約旦河東的兩個亞摩利王——希實本王西宏和亞斯她錄的巴珊王噩。</span>
<span className="v" id="v11" data-v="11" data-xref="約書亞記 9:8; 以斯帖記 8:17; 約書亞記 1:11"> 我們的長老和民眾就派我們帶著乾糧來迎接你們，甘做你們的僕人，希望跟你們締結盟約。</span>
<span className="v" id="v12" data-v="12" data-xref="約書亞記 9:4–5"> 我們出來的時候帶的餅是熱的，看啊，現在又乾又發黴了。</span>
<span className="v" id="v13" data-v="13"> 這些皮酒囊原來也是新的，但現在已經破了。因為長途跋涉，我們的衣服和鞋也都破舊不堪了。」</span>
<span className="v" id="v14" data-v="14" data-xref="箴言 3:5–6; 民數記 27:21; 歷代志上 10:13–14"> 以色列人接受了他們的食物，卻沒有求問耶和華。</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳記下 21:2; 申命記 20:10–11; 約書亞記 11:19"> 約書亞與他們立了和平盟約，容他們存活，會眾的首領也向他們起誓守約。</span>
<span className="v" id="v16" data-v="16" data-xref="箴言 12:19"> 立約三天後，以色列人才得知他們原來是鄰居，就住在附近。</span>
<span className="v" id="v17" data-v="17" data-xref="以斯拉記 2:25; 約書亞記 18:25–28; 約書亞記 18:14"> 以色列人啟程，走了三天來到他們居住的基遍、基非拉、比錄和基列·耶琳各城。</span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 15:4; 撒母耳記下 21:7; 傳道書 5:6"> 會眾的首領曾憑以色列的上帝耶和華向他們起過誓，所以不能殺他們。全體會眾因此向首領大發怨言。</span>
<span className="v" id="v19" data-v="19" data-xref="傳道書 8:2; 約書亞記 9:20; 傳道書 9:2"> 首領便對全體會眾說：「我們曾憑以色列的上帝耶和華向他們起誓，我們現在不能動他們。</span>
<span className="v" id="v20" data-v="20" data-xref="瑪拉基書 3:5; 箴言 20:25; 提摩太前書 1:10"> 我們要容他們存活，免得我們因違背誓言而惹耶和華發怒。」</span>
<span className="v" id="v21" data-v="21" data-xref="申命記 29:11; 約書亞記 9:27; 約書亞記 9:23"> 首領又說：「就容他們存活吧。」首領就叫他們為全體會眾劈柴挑水。</span>
<span className="v" id="v22" data-v="22" data-xref="約書亞記 9:6; 約書亞記 9:16; 創世記 3:13–14"> 於是，約書亞召來他們，對他們說：「你們為什麼要欺騙我們，說你們住得很遠？其實你們就住在附近。</span>
<span className="v" id="v23" data-v="23" data-xref="約書亞記 9:21; 創世記 9:25–26; 約書亞記 9:27"> 因此，你們是受咒詛的。你們要永遠做奴僕，為我上帝的殿劈柴挑水。」</span>
<span className="v" id="v24" data-v="24" data-xref="申命記 20:15–17; 申命記 7:1–2; 出埃及記 23:31–33"> 他們答道：「僕人們這樣做是因為害怕喪命。我們確實聽說你的上帝耶和華曾經應許祂僕人摩西，要把這整片土地都賜給你們，並從你們面前將這裡的居民殺盡。</span>
<span className="v" id="v25" data-v="25" data-xref="創世記 16:6; 士師記 10:15; 耶利米書 26:14"> 現在我們既然落在你的手中，你們想怎樣對待我們就怎樣對待吧。」</span>
<span className="v" id="v26" data-v="26"> 約書亞不讓以色列人加害他們，因此他們沒有被殺死。</span>
<span className="v" id="v27" data-v="27" data-xref="申命記 12:5"> 那天，約書亞讓他們在耶和華指定的地方，為會眾和耶和華的祭壇劈柴挑水。他們至今仍做這樣的工作。</span>

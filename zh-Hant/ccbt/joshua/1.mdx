## 主對約書亞的吩咐

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命記 34:9; 申命記 1:38; 申命記 31:23"> 耶和華的僕人摩西死了以後，耶和華對摩西的助手——嫩的兒子約書亞說：</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 3:28; 申命記 31:7; 民數記 27:16–21"> 「我的僕人摩西已經死了，你和全體以色列人現在要準備渡過約旦河，到我要賜給你們的地方去。</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 11:24; 約書亞記 14:9; 提多書 1:2"> 我已把你們腳掌將踏之地都賜給了你們，正如我對摩西的應許。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及記 23:31; 創世記 15:18–21; 申命記 3:25"> 從南部的曠野直到北部的黎巴嫩，從東部的幼發拉底大河直到西部的地中海，包括赫人居住的全境，都將是你們的領土。</span>
<span className="v" id="v5" data-v="5" data-xref="羅馬書 8:31; 申命記 31:6–8; 馬太福音 28:20"> 在你有生之年，沒有人能夠抵擋你。過去我怎樣與摩西同在，也必照樣與你同在，我必不離開你，也不丟棄你。</span>
<span className="v" id="v6" data-v="6" data-xref="但以理書 10:19; 以弗所書 6:10; 約書亞記 1:9"> 你要剛強勇敢，因為你要帶領這些人佔領我起誓要賜給他們祖先的土地。</span>
<span className="v" id="v7" data-v="7" data-xref="歷代志上 22:13; 申命記 5:32; 約書亞記 1:8"> 你只要剛強勇敢，謹遵我僕人摩西所吩咐你的一切律法，毫不偏離，就可以無往不利。</span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 119:15; 詩篇 19:14; 歌羅西書 3:16"> 你要常常誦讀這律法書，晝夜不斷地思想，以便謹遵律法書上的一切指示。這樣，你必亨通、順利。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 28:15; 耶利米書 1:7–8; 約書亞記 1:6–7"> 我再次吩咐你，要剛強勇敢！不要驚慌害怕，因為你無論走到哪裡，你的上帝耶和華必與你同在。」</span>
<span className="v" id="v10" data-v="10"> 於是，約書亞吩咐民眾的首領說：</span>
<span className="v" id="v11" data-v="11" data-xref="申命記 9:1; 何西阿書 6:2; 列王紀下 20:5"> 「你們要走遍全營，吩咐民眾預備好食物。因為三天之內，你們就要過約旦河，去佔領你們的上帝耶和華賜給你們的土地。」</span>
<span className="v" id="v12" data-v="12" data-xref="民數記 32:20–22"> 約書亞又對呂便支派、迦得支派和瑪拿西半個支派的人說：</span>
<span className="v" id="v13" data-v="13" data-xref="民數記 32:20–28; 申命記 3:18–20; 約書亞記 22:1–4"> 「你們要牢記耶和華的僕人摩西吩咐你們的話，他說你們的上帝耶和華要把這片土地賜給你們，讓你們安居。</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 20:8; 出埃及記 13:18; 啟示錄 17:4"> 你們的妻子兒女和牲畜可以留在約旦河東岸、摩西分給你們的土地上，但你們當中所有的勇士要帶著兵器先過約旦河，幫助你們的弟兄。</span>
<span className="v" id="v15" data-v="15" data-xref="腓立比書 2:4; 民數記 32:17–22; 哥林多前書 12:26"> 要等到你們的上帝耶和華使你們的弟兄像你們一樣得到祂所賜的土地，安居以後，你們才可以回到約旦河東日出之地，在耶和華的僕人摩西分給你們的土地上定居。」</span>
<span className="v" id="v16" data-v="16" data-xref="提多書 3:1; 申命記 5:27; 彼得前書 2:13–15"> 他們回答約書亞說：「凡你命令我們的，我們一定遵行。無論你派我們去哪裡，我們一定去。</span>
<span className="v" id="v17" data-v="17" data-xref="約書亞記 1:5; 列王紀上 1:37; 約書亞記 1:9"> 我們在一切事上怎樣服從摩西，也必照樣服從你，唯願你的上帝耶和華與你同在，像與摩西同在一樣。</span>
<span className="v" id="v18" data-v="18" data-xref="以弗所書 6:10; 約書亞記 1:9; 以斯拉記 10:4"> 任何人違抗你的命令，不悉數遵行你的吩咐，都要被處死。你要剛強勇敢！」</span>

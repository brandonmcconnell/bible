## 艾城之戰

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="約書亞記 1:9; 申命記 7:18; 申命記 1:21"> 耶和華對約書亞說：「不要驚慌害怕。只管率領全軍去攻打艾城，我已經將艾城的王、他的人民、城池和土地都交在你手裡了。</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 20:14; 約書亞記 6:21; 歷代志下 20:22"> 你怎樣對待耶利哥和耶利哥王，也要照樣對待艾城和艾城的王。不過你們可以拿城中的財物和牲畜。你要在城後設下伏兵。」</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="馬太福音 24:39; 馬太福音 25:6; 帖撒羅尼迦前書 5:2"> 於是，約書亞率領全軍前往艾城。他挑選了三萬精兵，派他們在黑夜出發，</span>
<span className="v" id="v4" data-v="4" data-xref="士師記 20:29; 約書亞記 8:16; 士師記 20:36"> 並吩咐他們說：「你們要在城後埋伏，不可離城太遠，全體保持戒備。</span>
<span className="v" id="v5" data-v="5" data-xref="約書亞記 7:5; 馬太福音 10:16; 士師記 20:31–33"> 我會率領軍隊正面攻城，當敵人像上次那樣出城應戰時，我們便逃跑。</span>
<span className="v" id="v6" data-v="6" data-xref="士師記 20:32; 出埃及記 15:9; 傳道書 8:11"> 他們必定乘勝追擊，我們便引他們離城，因為敵人一定會以為我們又像上次一樣臨陣逃跑。</span>
<span className="v" id="v7" data-v="7" data-xref="箴言 21:30–31; 列王紀下 5:1; 約書亞記 8:1"> 那時，你們便從埋伏的地方衝出來攻佔艾城，你們的上帝耶和華一定會把艾城交在你們手裡。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳記下 13:28; 約書亞記 1:16; 約書亞記 1:9"> 你們攻陷艾城後，要照耶和華的話放火焚城。這是我的命令。」</span>
<span className="v" id="v9" data-v="9" data-xref="約書亞記 7:2; 創世記 12:8; 以斯拉記 2:28"> 於是，約書亞派遣他們出去。他們去埋伏在伯特利和艾城之間，就是艾城的西面。那一夜，約書亞住在民眾當中。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="約書亞記 6:12; 詩篇 119:60; 創世記 22:3"> 清早，約書亞召集民眾，與以色列的眾首領率全軍前往艾城。</span>
<span className="v" id="v11" data-v="11"> 隨他同去的軍隊都向前推進，來到城外，在城的北面紮營，與艾城相隔一個山谷。</span>
<span className="v" id="v12" data-v="12" data-xref="約書亞記 8:2–3"> 約書亞選了五千人，讓他們埋伏在艾城和伯特利之間，就是艾城的西面。</span>
<span className="v" id="v13" data-v="13" data-xref="約書亞記 8:12; 約書亞記 8:8"> 於是，城北的主力軍隊和城西的伏兵都部署好了。當晚，約書亞在山谷裡過夜。</span>
<span className="v" id="v14" data-v="14" data-xref="馬太福音 24:39; 士師記 20:34–36; 申命記 1:1"> 艾城的王見以色列人兵臨城下，清早便急忙和全城的人起來出城迎戰，在亞拉巴谷附近跟以色列軍交鋒，他不知道城後有伏兵。</span>
<span className="v" id="v15" data-v="15" data-xref="約書亞記 18:12; 約書亞記 16:1; 士師記 20:36"> 約書亞帶領以色列軍詐敗，沿著通往曠野的路逃跑。</span>
<span className="v" id="v16" data-v="16" data-xref="士師記 20:31; 士師記 20:36–39; 約書亞記 8:5–6"> 艾城的人都被召去追趕以色列人，他們追擊約書亞，被誘出城來。</span>
<span className="v" id="v17" data-v="17" data-xref="約伯記 5:13; 約書亞記 8:3; 以賽亞書 19:11–13"> 這樣，伯特利和艾城的人傾巢而出，追殺以色列人，他們的城門大開。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="約書亞記 8:26; 約伯記 15:25; 撒母耳記上 17:41"> 耶和華對約書亞說：「把你手中的矛指向艾城，因為我要將這城交在你手裡。」約書亞就把手中的矛指向艾城。</span>
<span className="v" id="v19" data-v="19"> 他一伸手，城後的伏兵立即行動，迅速衝進城去，一舉佔領艾城，隨即放火燒城。</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 76:5; 約伯記 11:20; 創世記 19:28"> 艾城的人回頭發現城內煙氣沖天，卻無路可逃，因為那些逃往曠野的以色列人已掉頭攻擊他們。</span>
<span className="v" id="v21" data-v="21"> 約書亞和以色列全軍見伏兵已經佔領艾城，城中濃煙滾滾，便掉頭攻擊艾城的人。</span>
<span className="v" id="v22" data-v="22" data-xref="申命記 7:2; 約書亞記 10:28; 約書亞記 6:21"> 伏兵也出城追擊艾城的人。以色列軍前後夾攻，把敵人圍困在中間全部殲滅，無一漏網。</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳記上 15:8; 約書亞記 10:17; 啟示錄 19:20"> 他們生擒了艾城的王，將他押到約書亞那裡。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="約書亞記 11:10–14; 約書亞記 10:30–41; 民數記 21:24"> 以色列軍在田間和曠野用刀殺盡了追趕他們的艾城人後，又進城殺了留在城裡的人，</span>
<span className="v" id="v25" data-v="25" data-xref="申命記 20:16–18"> 當天被殺的艾城人男男女女共有一萬二千人。</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及記 17:11–12; 約書亞記 8:18"> 一直到艾城所有的人都被殺光了，約書亞才收回手中的矛。</span>
<span className="v" id="v27" data-v="27" data-xref="約書亞記 8:2; 民數記 31:26; 詩篇 50:10"> 以色列人照耶和華對約書亞的吩咐，只帶走了城中的牲畜和財物。</span>
<span className="v" id="v28" data-v="28" data-xref="申命記 13:16; 耶利米書 49:2; 列王紀下 19:25"> 約書亞燒毀全城，使城永遠成為一堆廢墟，至今仍一片荒涼。</span>
<span className="v" id="v29" data-v="29" data-xref="約書亞記 7:26; 撒母耳記下 18:17; 申命記 21:22–23"> 約書亞又將艾城王的屍體掛在樹上示眾。黃昏時，他才吩咐人把屍體取下來扔在城門口，又在屍體上堆了一大堆石頭。石堆至今還在。</span>
</div>
</div>

## 重申律法

<div className="bt">
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="申命記 27:4–6; 出埃及記 20:24; 創世記 12:7–8"> 約書亞照耶和華的僕人摩西對以色列人的吩咐，在以巴路山上為以色列的上帝耶和華築了一座祭壇。這壇是按照摩西律法書的記載，用未經鐵器鑿過的原石築的。以色列人就在這壇上把燔祭和平安祭獻給耶和華。</span>
<span className="v" id="v32" data-v="32" data-xref="申命記 27:2–3; 申命記 27:8"> 約書亞又在眾人面前，將摩西所寫的律法刻在石頭上。</span>
<span className="v" id="v33" data-v="33" data-xref="申命記 11:29; 申命記 31:12; 申命記 31:9"> 所有以色列人與他們的長老、官員和審判官都站在耶和華的約櫃兩旁，面對著抬約櫃的利未祭司，寄居的外族人和本族人都在場。他們一半人站在基利心山前，一半人站在以巴路山前，正如耶和華的僕人摩西從前祝福他們時所吩咐的。</span>
<span className="v" id="v34" data-v="34" data-xref="尼希米記 8:2–3; 尼希米記 13:1; 申命記 31:10–12"> 隨後，約書亞按照摩西律法書的記載，向民眾宣讀一切祝福和咒詛的話。</span>
<span className="v" id="v35" data-v="35" data-xref="申命記 31:12; 尼希米記 8:2; 耶利米書 26:2"> 他在全體會眾，包括婦女、小孩以及住在他們中間的外族人面前，一字不漏地宣讀摩西的一切吩咐。</span>
</div>
</div>

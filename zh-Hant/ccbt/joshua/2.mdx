## 喇合營救探子

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="希伯來書 11:31; 雅各書 2:25; 馬太福音 1:5"> 嫩的兒子約書亞暗中從什亭派出兩個探子，去偵察那片土地，特別是耶利哥的情況。他們進到一個名叫喇合的妓女家中，就住在那裡。</span>
<span className="v" id="v2" data-v="2" data-xref="以賽亞書 43:13; 但以理書 4:35; 箴言 21:30"> 有人告訴耶利哥王說：「今晚有以色列人來這裡刺探。」</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳記下 10:3; 創世記 42:9–12; 使徒行傳 12:6"> 耶利哥王便派人到喇合那裡，對她說：「把來到你家裡的人交出來，因為他們是來刺探這地方的。」</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀下 6:19; 撒母耳記下 17:19–20; 撒母耳記下 16:18–19"> 但喇合已經把二人藏起來了，她答道：「不錯，他們來過，可是我不知他們是從哪裡來的。</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米書 50:20; 以西結書 47:12; 啟示錄 21:25"> 天黑要關城門的時候，他們就離開了，我不知道他們去哪裡了。你們快去追吧，還可以追上。」</span>
<span className="v" id="v6" data-v="6" data-xref="希伯來書 11:23; 雅各書 2:25; 歌羅西書 3:3"> 其實喇合已經把二人帶到屋頂上，藏在那裡的麻稈堆裡了。</span>
<span className="v" id="v7" data-v="7" data-xref="士師記 3:28; 約書亞記 2:5; 士師記 12:5"> 追捕的人便沿著通往約旦河渡口的路追去，他們一出城，城門便關閉了。</span>
<span className="v" id="v8" data-v="8"> 在兩個探子睡覺前，喇合上到屋頂對他們說：</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及記 23:27; 申命記 2:25; 約書亞記 2:11"> 「我知道耶和華已經把這地方賜給你們，我們對你們充滿恐懼。這裡所有的居民都嚇得膽戰心驚。</span>
<span className="v" id="v10" data-v="10" data-xref="民數記 21:21–35; 出埃及記 15:14–16; 出埃及記 14:21–31"> 因為你們離開埃及過紅海的時候，耶和華怎樣使紅海在你們面前成為乾地，你們怎樣對付約旦河東的兩個亞摩利王西宏和噩，把他們徹底消滅，我們都聽說了。</span>
<span className="v" id="v11" data-v="11" data-xref="申命記 4:39; 約書亞記 5:1; 約書亞記 7:5"> 我們聽了這些事，感到心驚膽戰、勇氣盡失。你們的上帝耶和華是天地萬物的上帝。</span>
<span className="v" id="v12" data-v="12" data-xref="約書亞記 2:18; 約書亞記 9:18–20; 提摩太後書 1:16–18"> 我既然恩待了你們，現在請你們憑耶和華向我起誓，你們同樣會恩待我家，並且給我一個可靠的憑據，</span>
<span className="v" id="v13" data-v="13"> 保證放過我的父母、兄弟、姊妹和他們所有的親人，救我們脫離死亡。」</span>
<span className="v" id="v14" data-v="14" data-xref="馬太福音 5:7; 士師記 1:24–25; 創世記 24:49"> 二人便對她說：「只要你不洩露我們的事，我們願意用性命擔保，當耶和華把這地方賜給我們的時候，我們一定守信善待你。」</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行傳 9:25; 哥林多後書 11:33; 約書亞記 6:20"> 喇合的房子就在城牆邊，她就住在城牆上，於是她用繩子把二人從窗口縋下去，</span>
<span className="v" id="v16" data-v="16" data-xref="雅各書 2:25; 撒母耳記上 23:14; 詩篇 11:1"> 並對他們說：「你們往山上去，免得被追捕的人發現。你們要在那裡躲三天，等追捕的人回城後再走。」</span>
<span className="v" id="v17" data-v="17" data-xref="民數記 30:2; 撒母耳記下 21:7; 創世記 24:3–8"> 二人對她說：「要讓我們信守誓言，你必須這樣做：</span>
<span className="v" id="v18" data-v="18" data-xref="約書亞記 6:23; 約書亞記 2:21; 約書亞記 2:12–13"> 我們來攻佔這座城的時候，你要把這條朱紅色繩子繫在縋我們下去的窗戶上，並且把你的父母、兄弟、姊妹和他們的親人都召集到你家裡。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行傳 27:31; 列王紀上 2:36–42; 出埃及記 12:13"> 倘若有人離開這房子跑到街上遭遇不測，我們不負任何責任。我們一定保證屋內所有人的性命安全。</span>
<span className="v" id="v20" data-v="20" data-xref="箴言 11:13"> 如果你洩露我們的事，你要我們起的誓也就作廢了。」</span>
<span className="v" id="v21" data-v="21" data-xref="約翰福音 2:5; 約書亞記 2:18; 馬太福音 7:24"> 喇合說：「一言為定！」於是她送走他們，把朱紅色的繩子繫在窗戶上。</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳記上 19:10–12; 撒母耳記下 17:20; 詩篇 32:6–7"> 二人到山上躲藏了三天，等追捕的人回去。追捕的人沿途搜索，毫無所獲，便回去了。</span>
<span className="v" id="v23" data-v="23"> 二人便下山，過河回到嫩的兒子約書亞那裡，向他稟告整個經過，</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及記 23:31; 約書亞記 1:8; 約書亞記 2:9–11"> 又說：「耶和華確實將那整片土地交給我們了，那裡的居民聽到我們的消息，都嚇得膽戰心驚。」</span>

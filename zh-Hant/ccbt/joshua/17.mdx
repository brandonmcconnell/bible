<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民數記 26:29; 創世記 41:51; 創世記 50:23"> 以下是約瑟的長子瑪拿西支派分到的土地：瑪拿西的長子、基列的父親瑪吉是個戰士，因此分到了基列和巴珊兩地。</span>
<span className="v" id="v2" data-v="2" data-xref="歷代志上 7:18; 民數記 26:29–32; 士師記 6:11"> 瑪拿西其他子孫也按宗族分到了土地，他們屬於亞比以謝、希勒、亞斯烈、示劍、希弗和示米大宗族。這些男子按宗族都是約瑟的兒子瑪拿西的後代。</span>
<span className="v" id="v3" data-v="3" data-xref="民數記 27:1; 民數記 26:33; 民數記 36:2–11"> 瑪拿西的玄孫、瑪吉的曾孫、基列的孫子、希弗的兒子西羅非哈沒有兒子，只有五個女兒，名叫瑪拉、挪阿、曷拉、密迦、得撒。</span>
<span className="v" id="v4" data-v="4" data-xref="約書亞記 14:1; 民數記 27:5–7; 加拉太書 3:28"> 她們來見祭司以利亞撒、嫩的兒子約書亞和各首領，說：「耶和華曾經吩咐摩西在我們親族中分給我們產業。」約書亞便照耶和華的吩咐，讓她們在叔伯中也分到產業。</span>
<span className="v" id="v5" data-v="5" data-xref="約書亞記 17:2–3; 民數記 32:30–42; 約書亞記 13:29–31"> 除了約旦河東的基列和巴珊兩地以外，瑪拿西人還分到十塊土地，</span>
<span className="v" id="v6" data-v="6"> 因為在瑪拿西的後代中，女性也分到了產業。瑪拿西其他子孫分到基列地區。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="約書亞記 21:21; 約書亞記 20:7; 約書亞記 24:32"> 瑪拿西支派分到的土地從亞設開始，到示劍東面的密米他，再向南到隱·他普亞人居住的地方。</span>
<span className="v" id="v8" data-v="8" data-xref="約書亞記 16:8; 約書亞記 15:34; 約書亞記 12:17"> 他普亞地屬於瑪拿西，但在瑪拿西邊界上的他普亞城屬於以法蓮的子孫。</span>
<span className="v" id="v9" data-v="9" data-xref="約書亞記 16:3; 約書亞記 19:29; 約書亞記 16:8–9"> 邊界繼續向南到加拿河，在河南側瑪拿西境內的城邑都歸以法蓮。瑪拿西的邊界沿著加拿河北側直到地中海。</span>
<span className="v" id="v10" data-v="10"> 這樣，南面歸以法蓮，北面歸瑪拿西，西部邊界是地中海，北接亞設，東鄰以薩迦。</span>
<span className="v" id="v11" data-v="11" data-xref="歷代志上 7:29; 列王紀下 9:27; 士師記 5:19"> 在以薩迦和亞設境內，瑪拿西擁有伯·善、以伯蓮、多珥、隱·多珥、他納和米吉多及其附近的鄉村。</span>
<span className="v" id="v12" data-v="12" data-xref="士師記 1:27–28; 出埃及記 23:29–33; 羅馬書 6:12–14"> 可是，瑪拿西人沒能把這些城邑的迦南人趕走，因為他們執意不肯離開。</span>
<span className="v" id="v13" data-v="13" data-xref="約書亞記 16:10; 腓立比書 4:13; 士師記 1:35"> 以色列人國勢強盛的時候，就讓迦南人服勞役，但始終沒有把他們完全趕走。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="民數記 26:34–37; 創世記 48:19; 創世記 48:22"> 約瑟的子孫對約書亞說：「耶和華賜福給我們，使我們人口眾多，為什麼你只讓我們抽一支籤，分一份產業呢？」</span>
<span className="v" id="v15" data-v="15" data-xref="創世記 13:7; 創世記 14:5; 路加福音 12:48"> 約書亞對他們說：「你們如果人口眾多，認為以法蓮山區窄小，可以到比利洗人和利乏音人居住的地方開闢林區。」</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀上 4:12; 士師記 4:3; 士師記 1:19"> 他們答道：「那些山區不夠我們住，況且住在伯·善一帶和耶斯列平原的迦南人都有鐵戰車。」</span>
<span className="v" id="v17" data-v="17"> 約書亞對約瑟的子孫以法蓮人和瑪拿西人說：「你們人口眾多，勢力強大，不應只得一籤之地，</span>
<span className="v" id="v18" data-v="18" data-xref="希伯來書 13:6; 羅馬書 8:31; 民數記 14:6–9"> 山區也要分給你們，雖然全是森林，但可以開闢土地，使整個地區歸你們。雖然迦南人強盛，有鐵戰車，但你們必能趕走他們。」</span>
</div>

## 分給利未人的城邑

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="約書亞記 14:1; 約書亞記 19:51; 約書亞記 17:4"> 利未人的眾族長到迦南的示羅見祭司以利亞撒、嫩的兒子約書亞和以色列各支派的首領，說：「耶和華藉著摩西曾吩咐你們把一些城邑分給我們住，並把城郊的草場給我們牧養牲畜。」</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 49:7; 申命記 33:8–10; 歷代志上 6:54–81"> 以色列人便按照耶和華的吩咐，從他們的產業中把以下的城邑及其草場分給了利未人。</span>
<span className="v" id="v4" data-v="4" data-xref="歷代志上 6:54–60; 約書亞記 24:33; 約書亞記 21:8–19"> 首先哥轄宗族抽了籤。利未人哥轄宗族中大祭司亞倫的子孫從猶大、西緬和便雅憫支派的產業中抽籤得了十三座城。</span>
<span className="v" id="v5" data-v="5" data-xref="約書亞記 21:20–26; 出埃及記 6:16–25; 歷代志上 6:66–70"> 哥轄宗族中其他人也從以法蓮、但和瑪拿西半個支派的產業中抽籤得了十座城。</span>
<span className="v" id="v6" data-v="6" data-xref="約書亞記 21:27–33; 歷代志上 6:71–76; 出埃及記 6:16–17"> 革順的子孫從以薩迦、亞設、拿弗他利和在巴珊的瑪拿西半個支派的產業中抽籤得了十三座城。</span>
<span className="v" id="v7" data-v="7" data-xref="約書亞記 21:34–40; 歷代志上 6:77–81; 出埃及記 6:19"> 米拉利的子孫按宗族從呂便、迦得和西布倫支派的產業中抽籤得了十二座城。</span>
<span className="v" id="v8" data-v="8" data-xref="約書亞記 21:3; 約書亞記 18:6; 民數記 33:54"> 以色列人照耶和華對摩西的吩咐，把這些城邑及其草場用抽籤的方式分給利未人。</span>
<span className="v" id="v9" data-v="9" data-xref="歷代志上 6:65; 約書亞記 21:13–18"> 因為利未支派哥轄宗族中亞倫的子孫抽到第一籤，以色列人就從猶大和西緬兩支派的產業中點名划出以下城邑分給他們：</span>
<span className="v" id="v11" data-v="11" data-xref="歷代志上 6:55; 路加福音 1:39; 撒母耳記下 5:1–5"> 猶大山區的基列·亞巴及其草場，亞巴原是亞衲人的祖先，基列·亞巴就是希伯崙。</span>
<span className="v" id="v12" data-v="12" data-xref="約書亞記 14:13–15; 歷代志上 6:55–57"> 而城周圍的田地和鄉村已經分給耶孚尼的兒子迦勒作產業。</span>
<span className="v" id="v13" data-v="13" data-xref="約書亞記 15:42; 約書亞記 10:29; 約書亞記 15:54"> 以色列人把避難城希伯崙分給祭司亞倫的子孫，並把立拿、</span>
<span className="v" id="v14" data-v="14" data-xref="約書亞記 15:48; 約書亞記 15:50; 撒母耳記上 30:27–28"> 雅提珥、以實提莫、</span>
<span className="v" id="v15" data-v="15" data-xref="約書亞記 15:49; 約書亞記 15:51; 約書亞記 12:13"> 何崙、底璧、</span>
<span className="v" id="v16" data-v="16" data-xref="約書亞記 15:10; 歷代志上 6:59; 約書亞記 15:55"> 亞因、淤他、伯·示麥共九座城及其草場分給了他們。這都是從猶大和西緬兩支派分出來的。</span>
<span className="v" id="v17" data-v="17" data-xref="約書亞記 18:24–25; 約書亞記 9:3; 歷代志上 6:60"> 從便雅憫支派的產業中分給他們的城有：基遍、迦巴、</span>
<span className="v" id="v18" data-v="18" data-xref="以賽亞書 10:30; 歷代志上 6:60; 耶利米書 1:1"> 亞拿突、亞勒們四座城及其草場。</span>
<span className="v" id="v19" data-v="19"> 做祭司的亞倫子孫共分到十三座城邑及其草場。</span>
<span className="v" id="v20" data-v="20" data-xref="歷代志上 6:66; 約書亞記 21:5"> 利未人哥轄宗族其他子孫從以法蓮支派的產業中抽籤分到的城邑有：</span>
<span className="v" id="v21" data-v="21" data-xref="約書亞記 20:7; 士師記 9:1; 列王紀上 12:1"> 以法蓮山區的避難城示劍、基色、</span>
<span className="v" id="v22" data-v="22" data-xref="歷代志上 6:68; 約書亞記 16:3; 約書亞記 18:13–14"> 基伯先和伯·和崙共四座城及其草場。</span>
<span className="v" id="v23" data-v="23" data-xref="約書亞記 19:44–45"> 從但支派的產業中分給他們的城邑有：伊利提基、基比頓、</span>
<span className="v" id="v24" data-v="24" data-xref="約書亞記 19:42; 約書亞記 10:12; 歷代志上 6:69"> 亞雅崙和迦特·臨門四座城及其草場。</span>
<span className="v" id="v25" data-v="25" data-xref="約書亞記 17:11; 士師記 5:19"> 他們從瑪拿西半個支派的產業中分到他納和迦特·臨門兩座城及其草場。</span>
<span className="v" id="v26" data-v="26"> 以上是哥轄其他子孫所分到的十座城及其草場。</span>
<span className="v" id="v27" data-v="27" data-xref="歷代志上 6:71; 申命記 1:4; 約書亞記 20:8"> 以色列人分給利未支派中革順子孫的城邑有：瑪拿西半個支派中巴珊的哥蘭避難城和比·施提拉兩座城及其草場；</span>
<span className="v" id="v28" data-v="28" data-xref="約書亞記 19:12; 歷代志上 6:72–73"> 以薩迦支派的基善、大比拉、</span>
<span className="v" id="v29" data-v="29" data-xref="約書亞記 10:23; 約書亞記 12:11; 約書亞記 10:3"> 耶末、隱·干寧四座城及其草場；</span>
<span className="v" id="v30" data-v="30" data-xref="歷代志上 6:74–75; 約書亞記 19:25–28"> 亞設支派的米沙勒、押頓、</span>
<span className="v" id="v31" data-v="31" data-xref="士師記 18:21; 歷代志上 6:75; 士師記 1:31"> 黑甲、利合四座城及其草場；</span>
<span className="v" id="v32" data-v="32" data-xref="歷代志上 6:76; 約書亞記 20:7; 約書亞記 19:37"> 拿弗他利支派的哈末·多珥、加珥坦和加利利的避難城基低斯三座城及其草場。</span>
<span className="v" id="v33" data-v="33"> 革順人按宗族共分到十三座城邑及其草場。</span>
<span className="v" id="v34" data-v="34" data-xref="歷代志上 6:77; 約書亞記 19:11; 約書亞記 21:7"> 其餘的利未人，就是米拉利的子孫所分到的城邑有：西布倫支派的約念、加珥他、</span>
<span className="v" id="v35" data-v="35"> 丁拿、拿哈拉四座城及其草場；</span>
<span className="v" id="v36" data-v="36" data-xref="約書亞記 20:8; 申命記 4:43; 民數記 21:23"> 呂便支派的比悉、雅雜、</span>
<span className="v" id="v37" data-v="37"> 基底莫、米法押四座城及其草場；</span>
<span className="v" id="v38" data-v="38" data-xref="創世記 32:2; 列王紀上 22:3; 歷代志上 6:80"> 迦得支派的瑪哈念、基列的避難城拉末、</span>
<span className="v" id="v39" data-v="39" data-xref="以賽亞書 16:8–9; 民數記 32:35; 民數記 32:1"> 希實本、雅謝四座城及其草場。</span>
<span className="v" id="v40" data-v="40"> 利未人中米拉利的子孫按宗族所分到的城邑共有十二座。</span>
<span className="v" id="v41" data-v="41" data-xref="民數記 35:1–8; 申命記 33:10; 創世記 49:7"> 利未人從以色列各支派共分到四十八座城及其草場，</span>
<span className="v" id="v42" data-v="42"> 這些城周圍都有草場，城城如此。</span>
<span className="v" id="v43" data-v="43" data-xref="創世記 13:15; 詩篇 106:42–45; 出埃及記 23:27–31"> 這樣，耶和華把從前起誓要賜給以色列人祖先的整個地區，都賜給了以色列人，以色列人都分到土地，住了下來。</span>
<span className="v" id="v44" data-v="44" data-xref="約書亞記 11:23; 希伯來書 4:9; 申命記 31:3–5"> 耶和華照著給他們祖先的應許，使他們四境安寧，沒有仇敵能抵擋他們。耶和華將所有仇敵都交在了他們手中。</span>
<span className="v" id="v45" data-v="45" data-xref="列王紀上 8:56; 約書亞記 23:14–15; 民數記 23:19"> 耶和華給以色列人的美好應許沒有一句落空，全部實現了。</span>

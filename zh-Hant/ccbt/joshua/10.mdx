## 太陽停止

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="約書亞記 6:21; 希伯來書 7:1; 約書亞記 8:2"> 耶路撒冷王亞多尼·洗德聽說約書亞奪取並毀滅了艾城，像對付耶利哥和耶利哥王一樣對付艾城和艾城的王，又聽說基遍人已經跟以色列人締結盟約，住在他們中間，</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 11:25; 約書亞記 2:24; 出埃及記 15:14–16"> 便大為驚恐。因為基遍是一座大城，宏偉得像座都城，比艾城更大，城中的人都驍勇善戰。</span>
<span className="v" id="v3" data-v="3" data-xref="歷代志下 11:9; 彌迦書 1:13; 約書亞記 10:1"> 耶路撒冷王亞多尼·洗德便派遣使者去見希伯崙王何咸、耶末王毗蘭、拉吉王雅非亞和伊磯倫王底璧，說：</span>
<span className="v" id="v4" data-v="4" data-xref="約書亞記 9:15; 約書亞記 10:1; 以賽亞書 8:9–10"> 「求你們上來幫助我攻打基遍，因為這城已經與約書亞和以色列人締結盟約。」</span>
<span className="v" id="v5" data-v="5" data-xref="以賽亞書 8:9–10; 創世記 15:16; 約書亞記 10:6"> 於是，五位亞摩利王，就是耶路撒冷王、希伯崙王、耶末王、拉吉王和伊磯倫王，便聯合起來，率領他們所有的軍隊在基遍附近紮營，攻打基遍。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="約書亞記 9:6; 約書亞記 5:10; 申命記 1:15"> 基遍人派人去吉甲告訴約書亞說：「住在山區的亞摩利眾王正聯合起來攻打我們，求你趕快來救我們！不要不顧你的僕人。」</span>
<span className="v" id="v7" data-v="7" data-xref="約書亞記 8:1; 以賽亞書 8:12; 以賽亞書 8:14"> 於是，約書亞便率領全軍，包括所有精兵，從吉甲上去。</span>
<span className="v" id="v8" data-v="8" data-xref="羅馬書 8:31; 申命記 3:2; 詩篇 27:1–2"> 耶和華對約書亞說：「不要害怕，我已經把他們交在你手中，他們沒有一人能抵擋你。」</span>
<span className="v" id="v9" data-v="9" data-xref="傳道書 9:10; 提摩太後書 2:3; 箴言 24:11–12"> 約書亞從吉甲出發，連夜趕路，突襲敵人。</span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 18:14; 約書亞記 16:3; 約書亞記 16:5"> 耶和華使亞摩利聯軍陣腳大亂，以色列人就在基遍大敗敵軍，在去伯·和崙的上坡路上追殺他們，一直追到亞西加和瑪基大。</span>
<span className="v" id="v11" data-v="11" data-xref="以賽亞書 28:2; 士師記 5:20; 詩篇 18:12–14"> 敵人在從伯·和崙到亞西加的下坡路上逃竄的時候，耶和華降下大冰雹，被冰雹砸死的人比以色列人用刀殺死的還要多。</span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="哈巴谷書 3:11; 以賽亞書 38:8; 以賽亞書 60:20"> 耶和華將亞摩利人交在以色列人手中，那天約書亞當眾向耶和華禱告：<br /><span className="pl pl-1">「太陽啊，停在基遍！</span><br /><span className="pl pl-1">月亮啊，停在亞雅崙谷！」</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="哈巴谷書 3:11; 以賽亞書 38:8; 約書亞記 10:14"> <span className="pl pl-1">果然太陽停住了，</span><br /><span className="pl pl-1">月亮也不動了，</span><br /><span className="pl pl-1">直到以色列人殺敗敵人。</span><br />《雅煞珥書》記載了這事。約有一天的時間，太陽停留在天空，沒有西沉。</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 1:30; 出埃及記 14:14; 約書亞記 10:42"> 耶和華這樣垂聽一個人的祈求是空前絕後的，這是因為耶和華要為以色列爭戰。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="約書亞記 10:43; 約書亞記 10:6"> 後來，約書亞率領以色列軍返回了吉甲的營地。</span>
</div>
</div>

## 亞摩利五王被殺

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="撒母耳記上 24:8; 阿摩司書 9:2; 詩篇 139:7–10"> 那五王逃進瑪基大的山洞裡，躲藏起來。</span>
<span className="v" id="v17" data-v="17"> 有人告訴約書亞那五個王藏在瑪基大的山洞裡，</span>
<span className="v" id="v18" data-v="18" data-xref="馬太福音 27:66; 約伯記 21:30; 阿摩司書 9:1"> 約書亞便下令說：「滾幾塊大石頭堵住洞口，派人看守。</span>
<span className="v" id="v19" data-v="19" data-xref="詩篇 18:37–41; 耶利米書 8:14; 以賽亞書 9:14–15"> 你們不可停下來，要繼續追殺敵人，不要讓他們逃回城，你們的上帝耶和華已經把他們交在你們手中了。」</span>
<span className="v" id="v20" data-v="20" data-xref="約書亞記 8:24; 撒母耳記下 20:6; 約書亞記 10:10"> 約書亞和以色列人把敵人殺得大敗，幾乎全軍覆沒，一些殘餘都逃進了堅固的城壘。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及記 11:7; 以賽亞書 54:17; 以賽亞書 57:4"> 以色列人都安然無恙地回到約書亞駐紮的瑪基大營。再也沒有人敢威脅以色列人了。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="撒母耳記上 15:32"> 約書亞說：「打開洞口，把裡面的五個王押出來見我。」</span>
<span className="v" id="v23" data-v="23" data-xref="約書亞記 10:1; 約書亞記 10:5; 約書亞記 10:3"> 眾人便把耶路撒冷王、希伯崙王、耶末王、拉吉王、伊磯倫王從洞裡押出來，帶到約書亞面前。</span>
<span className="v" id="v24" data-v="24" data-xref="瑪拉基書 4:3; 羅馬書 16:20; 啟示錄 2:26–27"> 約書亞召來全體以色列人，然後對那些跟他一起出征的將領說：「你們上前來，用腳踏在這些王的脖子上。」各將領便照著約書亞的吩咐做了。</span>
<span className="v" id="v25" data-v="25" data-xref="哥林多後書 1:10; 約書亞記 1:9; 以弗所書 6:10"> 約書亞對他們說：「你們不要驚慌害怕，要剛強勇敢，因為耶和華要使你們攻打的所有仇敵都落此下場。」</span>
<span className="v" id="v26" data-v="26" data-xref="約書亞記 8:29; 撒母耳記下 21:9; 馬太福音 27:25"> 隨後約書亞將這五個王殺死，把屍體分別掛在五棵樹上，直到傍晚。</span>
<span className="v" id="v27" data-v="27" data-xref="約書亞記 8:29; 申命記 21:22–23; 約書亞記 7:26"> 日落時，約書亞才下令把屍體放下，扔在他們先前躲藏的山洞裡，用大石頭堵住洞口，石頭至今還在那裡。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="約書亞記 6:21; 申命記 7:16; 申命記 20:16–17"> 約書亞在當天佔領了瑪基大，把瑪基大王和所有的居民都用刀殺了，一個沒留。他對待瑪基大王跟以前對待耶利哥王一樣。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="約書亞記 21:13; 約書亞記 15:42; 耶利米書 52:1"> 約書亞和以色列軍又從瑪基大出發，去攻打立拿。</span>
<span className="v" id="v30" data-v="30"> 耶和華將立拿城和立拿王交在以色列人手中，他們用刀殺了全城的人，一個沒留。他們對待立拿王跟以前對待耶利哥王一樣。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="約書亞記 10:3; 約書亞記 12:11; 約書亞記 10:5"> 約書亞和以色列軍從立拿前往拉吉，他們在城外紮營，攻打拉吉。</span>
<span className="v" id="v32" data-v="32"> 耶和華將拉吉交在以色列人手中，第二天約書亞便攻佔了拉吉，用刀殺了全城的人，就像在立拿所行的一樣。</span>
<span className="v" id="v33" data-v="33" data-xref="約書亞記 16:10; 士師記 1:29; 約書亞記 16:3"> 基色王何蘭前來支持拉吉，結果也被約書亞殺得一個不剩。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="約書亞記 10:3; 約書亞記 12:12; 約書亞記 15:39"> 約書亞又率領以色列全軍從拉吉前往伊磯倫，在城外紮營，攻打伊磯倫。</span>
<span className="v" id="v35" data-v="35" data-xref="利未記 26:44; 約書亞記 10:37; 約伯記 19:10"> 他們當天就攻陷該城，用刀殺了城內所有的人，就像在拉吉所行的一樣。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="士師記 1:10; 約書亞記 15:13; 約書亞記 14:13–14"> 約書亞和全體以色列人又從伊磯倫去攻打希伯崙。</span>
<span className="v" id="v37" data-v="37"> 他們攻陷該城及其附屬城邑，用刀殺了希伯崙王和城邑中的居民，一個沒留，就像在伊磯倫所行的一樣。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="約書亞記 15:15; 約書亞記 12:13; 約書亞記 15:49"> 然後，約書亞和全體以色列人再回兵攻打底璧，</span>
<span className="v" id="v39" data-v="39" data-xref="俄巴底亞書 1:18; 約書亞記 11:8; 申命記 3:3"> 攻取了該城及其附屬城邑，擒獲底璧王，用刀殺了城中所有的人，一個沒留，就像對待希伯崙、立拿和立拿王一樣。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="申命記 7:2–16; 出埃及記 23:31–33; 約書亞記 8:27"> 這樣，約書亞征服了整個地區，包括山區、南地、丘陵和山坡及那裡的眾王。他按照以色列的上帝耶和華的吩咐，消滅了一切有生命氣息的，一個沒留。</span>
<span className="v" id="v41" data-v="41" data-xref="約書亞記 11:16; 約書亞記 15:51; 申命記 9:23"> 約書亞征服了各地，從加低斯·巴尼亞到迦薩，歌珊全境，直到基遍。</span>
<span className="v" id="v42" data-v="42" data-xref="約書亞記 10:14; 詩篇 46:7; 詩篇 80:3"> 約書亞能一鼓作氣殺敗諸王，征服他們的土地，都是因為有以色列的上帝耶和華為以色列人爭戰。</span>
<span className="v" id="v43" data-v="43" data-xref="約書亞記 10:15; 約書亞記 4:19; 撒母耳記上 11:14"> 之後，約書亞率領以色列人回到吉甲的營地。</span>
</div>
</div>

## 打敗北方諸王

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="約書亞記 11:10; 詩篇 2:1–4; 士師記 4:2"> 夏瑣王耶賓聽見這些消息，就派人去見瑪頓王約巴、伸崙王、押煞王，</span>
<span className="v" id="v2" data-v="2" data-xref="約書亞記 12:3; 士師記 1:27; 約書亞記 17:11"> 還有北方山區、基尼烈南面的亞拉巴、西部丘陵和多珥高原的各王，</span>
<span className="v" id="v3" data-v="3" data-xref="士師記 3:3; 約書亞記 18:26; 創世記 31:49"> 以及東西兩面的迦南人、山區的亞摩利人、赫人、比利洗人、耶布斯人和黑門山麓米斯巴地區的希未人。</span>
<span className="v" id="v4" data-v="4" data-xref="士師記 7:12; 撒母耳記上 13:5; 創世記 32:12"> 這些王便率領自己的軍隊，帶著許多馬匹和戰車傾巢出動，人數多如海邊的沙。</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 118:10–12; 啟示錄 16:14; 以賽亞書 8:9"> 他們在米倫河會師，一同紮營，要跟以色列人交戰。</span>
<span className="v" id="v6" data-v="6" data-xref="約書亞記 10:8; 撒母耳記下 8:4; 士師記 20:28"> 耶和華對約書亞說：「你不要怕他們。明天這個時候，我必把他們全部交給以色列人殺滅，你要砍斷他們馬匹的蹄筋，燒毀他們的戰車。」</span>
<span className="v" id="v7" data-v="7" data-xref="約書亞記 10:9; 帖撒羅尼迦前書 5:2–3"> 於是，約書亞率領所有的軍兵在米倫河邊突襲敵軍。</span>
<span className="v" id="v8" data-v="8" data-xref="約書亞記 13:6; 約書亞記 19:28; 撒迦利亞書 9:2"> 耶和華把敵軍交在以色列人手中，以色列人打敗了他們，追殺他們直到西頓大城、米斯利弗·瑪音和東面的米斯巴谷，全部消滅了他們，一個沒留。</span>
<span className="v" id="v9" data-v="9" data-xref="約書亞記 11:6; 以西結書 39:9–10"> 約書亞照耶和華的吩咐，砍斷他們馬匹的蹄筋，燒毀他們的戰車。</span>
<span className="v" id="v10" data-v="10" data-xref="約書亞記 11:1; 士師記 4:2"> 然後，約書亞回師攻陷夏瑣，用刀殺了夏瑣王。夏瑣曾經在諸國中為首。</span>
<span className="v" id="v11" data-v="11" data-xref="約書亞記 10:40; 申命記 20:16"> 以色列人用刀殺了城內的人，一個沒留。約書亞放火燒了夏瑣。</span>
<span className="v" id="v12" data-v="12" data-xref="申命記 20:16–17; 申命記 7:2; 民數記 33:50–53"> 約書亞攻佔了諸王所有的城池，擒獲諸王。他照耶和華的僕人摩西的吩咐，用刀殺死諸王，毀掉城池。</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米書 30:18"> 以色列人只燒毀了夏瑣，沒有燒建在山丘上的其他城池。</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 20:14; 民數記 31:9; 約書亞記 8:27"> 他們用刀殺掉城內所有的居民，一個沒留，擄掠了城內所有的財物和牲畜。</span>
<span className="v" id="v15" data-v="15" data-xref="約書亞記 1:7; 出埃及記 34:11–13; 使徒行傳 20:20"> 耶和華怎樣吩咐祂的僕人摩西，摩西也怎樣吩咐約書亞，約書亞都一一照辦，沒有遺漏任何耶和華吩咐摩西的事。</span>
<span className="v" id="v16" data-v="16" data-xref="約書亞記 10:41; 約書亞記 11:21; 約書亞記 12:8"> 約書亞佔領了整個地區，包括山區、南地、歌珊全境、丘陵、亞拉巴和以色列山區及平原，</span>
<span className="v" id="v17" data-v="17" data-xref="申命記 7:24; 約書亞記 11:3; 約書亞記 13:5"> 從哈拉山起到西珥，直到黑門山山麓黎巴嫩山谷的巴力·迦得城。約書亞擒獲了各城的王，殺死了他們。</span>
<span className="v" id="v18" data-v="18" data-xref="約書亞記 14:7–10; 約書亞記 11:23"> 約書亞跟這些地區的諸王爭戰了很久。</span>
<span className="v" id="v19" data-v="19" data-xref="約書亞記 9:3–27"> 除了基遍的希未人以外，其他沒有一城向以色列人求和，以色列人全部攻佔這些城。</span>
<span className="v" id="v20" data-v="20" data-xref="羅馬書 9:18; 申命記 20:16–17; 出埃及記 4:21"> 原來耶和華使他們的心剛硬，跟以色列人作戰，好讓他們遭受無情的毀滅，正如耶和華對摩西的吩咐。</span>
<span className="v" id="v21" data-v="21" data-xref="申命記 9:2; 民數記 13:22–23; 約書亞記 15:13–14"> 那時，約書亞又出兵把希伯崙、底璧、亞拿伯、以色列和猶大各山區的亞衲人和他們的城邑全部毀滅。</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳記上 17:4; 歷代志上 18:1; 約書亞記 15:46"> 除了在迦薩、迦特和亞實突有一些殘餘之外，以色列境內沒有亞衲人了。</span>
<span className="v" id="v23" data-v="23" data-xref="約書亞記 21:44–45; 民數記 26:52–55; 約書亞記 14:1–15"> 約書亞照耶和華對摩西的指示，奪取整個地區，把土地按照支派分給以色列人作產業。於是境內國泰民安，沒有戰事了。</span>

## 西緬支派分到的土地

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="約書亞記 19:9; 創世記 49:5–7; 約書亞記 18:6–11"> 西緬支派按宗族得到第二籤，所得的產業在猶大人的疆界內，</span>
<span className="v" id="v2" data-v="2" data-xref="歷代志上 4:28–30; 尼希米記 11:26–30; 創世記 21:31"> 有別示巴，又名示巴、摩拉大、</span>
<span className="v" id="v3" data-v="3" data-xref="約書亞記 15:28–29"> 哈薩·書亞、巴拉、以森、</span>
<span className="v" id="v4" data-v="4" data-xref="約書亞記 15:30; 士師記 1:17"> 伊勒多臘、比土力、何珥瑪、</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳記上 30:1; 歷代志上 4:31; 約書亞記 15:31"> 洗革拉、伯·瑪加博、哈薩·蘇撒、</span>
<span className="v" id="v6" data-v="6" data-xref="約書亞記 15:32"> 伯·利巴勿、沙魯險共十三座城及其附近的鄉村，</span>
<span className="v" id="v7" data-v="7" data-xref="約書亞記 15:42; 約書亞記 15:32; 民數記 33:19–20"> 還有亞因、利門、以帖、亞珊四座城及其村莊，</span>
<span className="v" id="v8" data-v="8" data-xref="歷代志上 4:33; 撒母耳記上 30:27"> 包括周圍所有的村莊，遠至巴拉·比珥，即南地的拉瑪。這些都是西緬支派按宗族所得的產業。</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多後書 8:14–15; 出埃及記 16:18"> 西緬人的產業是從猶大人的產業中撥出來的，因為猶大支派所分到的地區過於廣大，所以要撥出一部分來分給西緬人。</span>
</div>
</div>

## 西布倫支派分到的土地

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="約書亞記 18:11; 約書亞記 18:6; 創世記 49:13"> 西布倫人按宗族得了第三籤，他們分到的土地遠至撒立。</span>
<span className="v" id="v11" data-v="11" data-xref="約書亞記 12:22; 歷代志上 6:68; 列王紀上 4:12"> 從撒立向西到瑪拉拉、大巴設，直到約念東邊的小河；</span>
<span className="v" id="v12" data-v="12" data-xref="士師記 4:6; 歷代志上 6:72; 約書亞記 19:22"> 從撒立向東朝日出方向到吉斯綠·他泊的邊界，經大比拉、直到雅非亞；</span>
<span className="v" id="v13" data-v="13" data-xref="列王紀下 14:25"> 再往東，經迦特·希弗、以特·加汛、臨門，直到尼亞；</span>
<span className="v" id="v14" data-v="14"> 北上轉向哈拿頓，直到伊弗他·伊勒山谷。</span>
<span className="v" id="v15" data-v="15" data-xref="約書亞記 11:1; 路得記 1:19; 撒母耳記下 23:15"> 還有加他、拿哈拉、伸崙、以大拉、伯利恆，共十二座城及其附近的鄉村。</span>
<span className="v" id="v16" data-v="16"> 以上這些城邑和鄉村是西布倫人按宗族所得的產業。</span>
</div>
</div>

## 以薩迦支派分到的土地

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17"> 以薩迦人按宗族得了第四籤，</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳記上 28:4; 列王紀下 4:8; 何西阿書 1:4–5"> 他們的土地包括耶斯列、基蘇律、書念、</span>
<span className="v" id="v19" data-v="19"> 哈弗連、示按、亞拿哈拉、</span>
<span className="v" id="v20" data-v="20"> 拉璧、基善、亞別、</span>
<span className="v" id="v21" data-v="21" data-xref="約書亞記 21:29"> 利篾、隱·干寧、隱·哈大、伯·帕薛、</span>
<span className="v" id="v22" data-v="22" data-xref="士師記 4:6; 歷代志上 6:77; 約書亞記 19:38"> 他泊、沙哈洗瑪、伯·示麥，直到約旦河，共十六座城及其附近的鄉村。</span>
<span className="v" id="v23" data-v="23"> 這些城邑和鄉村都是以薩迦支派按宗族分到的產業。</span>
</div>
</div>

## 亞設支派分到的土地

<div className="bt">
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="路加福音 2:26–38"> 亞設支派按宗族得了第五籤，</span>
<span className="v" id="v25" data-v="25" data-xref="約書亞記 12:20; 約書亞記 11:1; 撒母耳記下 2:16"> 他們得到的土地包括黑甲、哈利、比田、押煞、</span>
<span className="v" id="v26" data-v="26" data-xref="雅歌 7:5; 列王紀上 18:42; 以賽亞書 33:9"> 亞拉米勒、亞末和米沙勒，西至迦密和希曷·立納，</span>
<span className="v" id="v27" data-v="27" data-xref="列王紀上 9:13; 撒母耳記上 5:2"> 然後向東到伯·大袞，挨著西布倫和伊弗他·伊勒谷，經伯·以墨和尼業向北到迦步勒；</span>
<span className="v" id="v28" data-v="28" data-xref="士師記 1:31; 約書亞記 11:8; 以賽亞書 23:12"> 再經義伯崙、利合、哈們、加拿直到西頓大城；</span>
<span className="v" id="v29" data-v="29" data-xref="士師記 1:31; 撒母耳記下 5:11; 彌迦書 1:14"> 再轉到拉瑪、堅固的泰爾城，然後轉到何薩，直到亞革悉一帶的地中海。</span>
<span className="v" id="v30" data-v="30" data-xref="約書亞記 21:31; 列王紀上 20:30; 撒母耳記上 4:1"> 還有烏瑪、亞弗和利合，共二十二座城及其附近的鄉村。</span>
<span className="v" id="v31" data-v="31" data-xref="申命記 33:24–25; 創世記 49:20"> 這些城邑和鄉村都是亞設支派按宗族分到的產業。</span>
</div>
</div>

## 拿弗他利支派分到的土地

<div className="bt">
<div className="bp">
<span className="v" id="v32" data-v="32"> 拿弗他利人按宗族得了第六籤，</span>
<span className="v" id="v33" data-v="33" data-xref="士師記 4:11"> 他們的土地從希利弗、撒拿音的橡樹、亞大米·尼吉和雅比聶到拉共，再到約旦河；</span>
<span className="v" id="v34" data-v="34" data-xref="申命記 33:23; 約書亞記 19:12; 約書亞記 19:22"> 又向西到亞斯納·他泊、戶割，南接西布倫，西接亞設，東接約旦河<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「約旦河」參照《七十士譯本》，希伯來文作「約旦河的猶大」。">a</a></sup>。</span>
<span className="v" id="v35" data-v="35" data-xref="約書亞記 11:2; 列王紀上 8:65; 創世記 10:18"> 還包括以下堅城：西丁、側耳、哈末、拉甲、基尼烈、</span>
<span className="v" id="v36" data-v="36" data-xref="約書亞記 11:1; 約書亞記 11:20; 約書亞記 12:19"> 亞大瑪、拉瑪、夏瑣、</span>
<span className="v" id="v37" data-v="37" data-xref="約書亞記 20:7; 約書亞記 12:22"> 基低斯、以得來、隱·夏瑣、</span>
<span className="v" id="v38" data-v="38"> 以利隱、密大·伊勒、和璉、伯·亞納、伯‧示麥，共十九座城及其附近的鄉村。</span>
<span className="v" id="v39" data-v="39"> 這些城邑和鄉村都是拿弗他利支派按宗族分到的產業。</span>
</div>
</div>

## 但支派分到的土地

<div className="bt">
<div className="bp">
<span className="v" id="v40" data-v="40"> 但支派按宗族得了第七籤，</span>
<span className="v" id="v41" data-v="41" data-xref="歷代志上 2:53; 約書亞記 15:33; 士師記 13:25"> 他們的土地包括瑣拉、以實陶、伊珥·示麥、</span>
<span className="v" id="v42" data-v="42" data-xref="士師記 1:35; 約書亞記 10:12; 約書亞記 21:24"> 沙拉賓、亞雅崙、伊提拉、</span>
<span className="v" id="v43" data-v="43" data-xref="創世記 38:12; 撒母耳記上 5:10; 士師記 14:1–2"> 以倫、亭拿他、以革倫、</span>
<span className="v" id="v44" data-v="44" data-xref="列王紀上 15:27; 列王紀上 16:15; 列王紀上 9:18"> 伊利提基、基比頓、巴拉、</span>
<span className="v" id="v45" data-v="45" data-xref="約書亞記 21:24"> 伊胡得、比尼·比拉、迦特·臨門、</span>
<span className="v" id="v46" data-v="46" data-xref="約拿書 1:3; 使徒行傳 9:36; 歷代志下 2:16"> 美·耶昆、拉昆和約帕對面的一帶。</span>
<span className="v" id="v47" data-v="47" data-xref="士師記 1:34–35; 士師記 18:1–29"> 但支派無法奪取他們的土地，於是就去攻打利善城，用刀殺了城內的居民，佔據了這座城，用他們祖先的名字把城改名為但，</span>
<span className="v" id="v48" data-v="48"> 這些城邑和村莊都是但支派按宗族得到的產業。</span>
</div>
</div>

## 約書亞分得之地

<div className="bt">
<div className="bp">
<span className="v" id="v49" data-v="49" data-xref="以西結書 45:7–8"> 以色列人把地分配完畢以後，又從中劃出土地給嫩的兒子約書亞。</span>
<span className="v" id="v50" data-v="50" data-xref="約書亞記 24:30; 士師記 2:9; 歷代志上 7:24"> 以色列人遵從耶和華的吩咐，把約書亞想要的以法蓮山區的亭拿·西拉城分給他。約書亞重修那城，住在那裡。</span>
<span className="v" id="v51" data-v="51" data-xref="約書亞記 18:10; 約書亞記 14:1; 約書亞記 18:1"> 以上是祭司以利亞撒、嫩的兒子約書亞和以色列各支派的首領，在示羅的會幕門口，在耶和華面前抽籤所分配的土地。至此，他們把地分完了。</span>
</div>

## 猶大支派分到的土地

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民數記 26:55–56; 約書亞記 14:2; 民數記 33:36–37"> 猶大支派按宗族抽籤分到的土地，南到以東的邊界，到最南端的荀曠野。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 14:3; 以西結書 47:8; 以賽亞書 11:15"> 南面的邊界始於鹽海南端的海灣，</span>
<span className="v" id="v3" data-v="3" data-xref="民數記 34:4; 士師記 1:36; 民數記 20:1"> 沿亞克拉濱山坡南面，經荀，北上至加低斯·巴尼亞南面，經過希斯崙到亞達珥，再繞到甲加，</span>
<span className="v" id="v4" data-v="4" data-xref="民數記 34:5; 約書亞記 13:3; 出埃及記 23:31"> 經過押們、順著埃及小河直到地中海。這是猶大支派的南部邊界。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="民數記 34:12; 約書亞記 18:15–19; 民數記 34:10"> 東面以鹽海到約旦河口為邊界。<br />北界從約旦河口的海灣開始，</span>
<span className="v" id="v6" data-v="6" data-xref="約書亞記 18:17; 約書亞記 18:19–21"> 到伯·曷拉，經過伯·亞拉巴北面，直到呂便的兒子波罕所立的大石；</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀上 1:9; 撒母耳記下 17:17; 約書亞記 7:26"> 從亞割谷往北到底璧，到谷南亞都冥隘口對面的吉甲，經隱·示麥泉，直到隱·羅結；</span>
<span className="v" id="v8" data-v="8" data-xref="約書亞記 18:16; 約書亞記 15:63; 約書亞記 18:28"> 然後再沿著欣嫩子谷而上，直到耶布斯，即耶路撒冷的南面，再到欣嫩谷西面、利乏音谷北端的山頂；</span>
<span className="v" id="v9" data-v="9" data-xref="歷代志上 13:6; 約書亞記 18:15; 士師記 18:12"> 從山頂到尼弗多亞泉，到以弗崙山的各城，直到巴拉，即基列·耶琳；</span>
<span className="v" id="v10" data-v="10" data-xref="士師記 14:1; 士師記 14:5; 創世記 38:12–13"> 從巴拉向西繞到西珥山，到耶琳山北坡，即基撒崙，到伯·示麥，經亭拿，</span>
<span className="v" id="v11" data-v="11" data-xref="約書亞記 15:45; 列王紀下 1:2–3; 撒母耳記上 5:10"> 再到以革倫北坡，轉向施基崙，經巴拉山和雅比聶，直到地中海。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="民數記 34:6–7; 約書亞記 15:47; 以西結書 47:20"> 西面的邊界是地中海沿岸。以上是猶大人根據宗族所得地業的四界。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="民數記 13:30; 申命記 1:34–36; 民數記 14:23–24"> 約書亞又照耶和華的吩咐，在猶大支派所分到的土地之中劃出基列·亞巴，即希伯崙，分給耶孚尼的兒子迦勒。亞巴是亞衲人的祖先。</span>
<span className="v" id="v14" data-v="14" data-xref="士師記 1:20; 士師記 1:10; 民數記 13:22–23"> 迦勒趕走了住在那裡的亞衲族的三個族長，即示篩、亞希幔和撻買，</span>
<span className="v" id="v15" data-v="15" data-xref="約書亞記 10:38; 約書亞記 10:3; 士師記 1:11–13"> 再從那裡出兵攻打底璧，底璧從前叫基列·西弗。</span>
<span className="v" id="v16" data-v="16" data-xref="士師記 1:12–13; 士師記 1:6"> 迦勒說：「誰攻取基列·西弗，我就把女兒押撒嫁給他。」</span>
<span className="v" id="v17" data-v="17" data-xref="士師記 3:9; 士師記 1:13; 約書亞記 14:6"> 迦勒的弟弟基納斯的兒子俄陀聶攻取了那城，迦勒便把女兒押撒嫁給他。</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 24:64; 撒母耳記上 25:23"> 押撒出嫁的時候，勸丈夫向她父親要一塊田。她剛下驢，迦勒便問她：「你想要什麼？」</span>
<span className="v" id="v19" data-v="19" data-xref="士師記 1:14–15; 撒母耳記上 25:27; 申命記 33:7"> 押撒答道：「求你賜福給我，你既然把南地賜給我，求你也把水泉賜給我吧。」迦勒就把上泉和下泉都給了她。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="創世記 49:8–12; 申命記 33:7"> 以下是猶大支派按宗族所得的產業：</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 35:21; 尼希米記 11:25"> 在最南面靠近以東的城邑有甲薛、以得、雅姑珥、</span>
<span className="v" id="v22" data-v="22"> 基拿、底摩拿、亞大達、</span>
<span className="v" id="v23" data-v="23" data-xref="約書亞記 12:22; 民數記 33:37; 申命記 1:19"> 基低斯、夏瑣、以提楠、</span>
<span className="v" id="v24" data-v="24" data-xref="撒母耳記上 23:14; 撒母耳記上 23:24; 撒母耳記上 23:19"> 西弗、提鏈、比亞綠、</span>
<span className="v" id="v25" data-v="25"> 夏瑣·哈大他、加略·希斯崙，即夏瑣、</span>
<span className="v" id="v26" data-v="26" data-xref="歷代志上 4:28"> 亞曼、示瑪、摩拉大、</span>
<span className="v" id="v27" data-v="27" data-xref="尼希米記 11:26"> 哈薩·迦大、黑實門、伯·帕列、</span>
<span className="v" id="v28" data-v="28" data-xref="創世記 26:33; 歷代志上 4:28; 創世記 21:31–33"> 哈薩·書亞、別示巴、比斯約他、</span>
<span className="v" id="v29" data-v="29" data-xref="約書亞記 15:9–11; 約書亞記 19:3; 歷代志上 4:29"> 巴拉、以因、以森、</span>
<span className="v" id="v30" data-v="30" data-xref="約書亞記 19:4; 民數記 14:45; 申命記 1:44"> 伊勒多臘、基失、何珥瑪、</span>
<span className="v" id="v31" data-v="31" data-xref="撒母耳記上 27:6; 撒母耳記上 30:1; 歷代志上 12:1"> 洗革拉、麥瑪拿、三撒拿、</span>
<span className="v" id="v32" data-v="32" data-xref="民數記 34:11; 尼希米記 11:29"> 利巴勿、實忻、亞因和臨門，共二十九座城及其附近的鄉村。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="士師記 13:25; 士師記 16:31; 民數記 13:23"> 在丘陵地帶有以實陶、瑣拉、亞實拿、</span>
<span className="v" id="v34" data-v="34" data-xref="約書亞記 12:17; 約書亞記 15:53"> 撒挪亞、隱·干寧、他普亞、以楠、</span>
<span className="v" id="v35" data-v="35" data-xref="撒母耳記上 17:1; 撒母耳記上 22:1; 約書亞記 10:3"> 耶末、亞杜蘭、梭哥、亞西加、</span>
<span className="v" id="v36" data-v="36" data-xref="撒母耳記上 17:52"> 沙拉音、亞底他音、基底拉和基底羅他音，共十四座城及其附近的鄉村。</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37"> 還有洗楠、哈大沙、麥大·迦得、</span>
<span className="v" id="v38" data-v="38" data-xref="列王紀下 14:7; 士師記 20:1; 撒母耳記上 10:17"> 底連、米斯巴、約帖、</span>
<span className="v" id="v39" data-v="39" data-xref="約書亞記 10:3; 列王紀下 22:1; 約書亞記 10:31–32"> 拉吉、波斯加、伊磯倫、</span>
<span className="v" id="v40" data-v="40"> 迦本、拉幔、基提利、</span>
<span className="v" id="v41" data-v="41" data-xref="約書亞記 10:21; 約書亞記 12:16; 約書亞記 10:10"> 基低羅、伯·大袞、拿瑪、瑪基大，共十六座城及其附近的鄉村。</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="約書亞記 10:29; 列王紀下 8:22; 約書亞記 19:7"> 還有立拿、以帖、亞珊、</span>
<span className="v" id="v43" data-v="43"> 益弗他、亞實拿、尼悉、</span>
<span className="v" id="v44" data-v="44" data-xref="創世記 38:5; 彌迦書 1:14–15; 撒母耳記上 23:1–14"> 基伊拉、亞革悉、瑪利沙，共九座城及其附近的鄉村。</span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="約書亞記 13:3; 阿摩司書 1:8; 撒母耳記上 6:17"> 還有以革倫及其附近的城邑和鄉村。</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="歷代志下 26:6; 阿摩司書 1:8; 撒母耳記上 5:1"> 還有以革倫到地中海一帶所有靠近亞實突的城邑和鄉村，</span>
<span className="v" id="v47" data-v="47" data-xref="約書亞記 15:4; 出埃及記 23:31; 阿摩司書 1:6–7"> 亞實突及其附近的城邑和鄉村，迦薩及其附近的城邑和鄉村，直到埃及小河和地中海沿岸。</span>
</div>
<div className="bp">
<span className="v" id="v48" data-v="48" data-xref="約書亞記 21:14"> 在山區有沙密、雅提珥、梭哥、</span>
<span className="v" id="v49" data-v="49" data-xref="約書亞記 15:15; 士師記 1:11"> 達拿、基列·薩拿，即底璧、</span>
<span className="v" id="v50" data-v="50"> 亞拿伯、以實提莫、亞念、</span>
<span className="v" id="v51" data-v="51" data-xref="約書亞記 11:16; 約書亞記 10:41; 撒母耳記下 15:12"> 歌珊、何崙、基羅，共十一座城及其附近的鄉村。</span>
</div>
<div className="bp">
<span className="v" id="v52" data-v="52" data-xref="以賽亞書 21:11"> 還有亞拉、度瑪、以珊、</span>
<span className="v" id="v53" data-v="53"> 雅農、伯·他普亞、亞非加、</span>
<span className="v" id="v54" data-v="54" data-xref="約書亞記 15:13; 創世記 23:2; 約書亞記 14:15"> 宏他、基列·亞巴，即希伯崙、洗珥，共九座城及其附近的鄉村。</span>
</div>
<div className="bp">
<span className="v" id="v55" data-v="55" data-xref="撒母耳記上 25:2; 約書亞記 15:24; 撒母耳記上 23:25"> 還有瑪雲、迦密、西弗、淤他、</span>
<span className="v" id="v56" data-v="56"> 耶斯列、約甸、撒挪亞、</span>
<span className="v" id="v57" data-v="57" data-xref="約書亞記 15:10; 創世記 38:12; 耶利米書 14:1"> 該隱、基比亞、亭拿，共十座城及其附近的鄉村。</span>
</div>
<div className="bp">
<span className="v" id="v58" data-v="58" data-xref="歷代志上 4:39"> 還有哈忽、伯·夙、基突、</span>
<span className="v" id="v59" data-v="59"> 瑪臘、伯·亞諾、伊勒提君，共六座城及其附近的鄉村。</span>
</div>
<div className="bp">
<span className="v" id="v60" data-v="60" data-xref="約書亞記 18:14; 撒母耳記上 7:1"> 還有基列·巴力，即基列·耶琳、拉巴兩座城及其附近的鄉村。</span>
</div>
<div className="bp">
<span className="v" id="v61" data-v="61" data-xref="約書亞記 15:6; 約書亞記 18:18"> 在曠野有伯·亞拉巴、密丁、西迦迦、</span>
<span className="v" id="v62" data-v="62" data-xref="撒母耳記上 23:29; 歷代志下 20:2"> 匿珊、鹽城、隱·基底，共六座城及其附近的鄉村。</span>
</div>
<div className="bp">
<span className="v" id="v63" data-v="63" data-xref="士師記 1:21; 士師記 1:8; 撒母耳記下 5:6–9"> 猶大人沒能把住在耶路撒冷的耶布斯人趕出去，他們至今仍然跟猶大人一同居住。</span>
</div>

## 被擊敗的諸王

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命記 3:8–9; 士師記 11:18; 約書亞記 1:15"> 以色列人在約旦河東岸殺死了兩個王，佔據了他們的領土：自亞嫩谷直到黑門山，包括東面的整個亞拉巴。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 32:22; 士師記 11:22; 詩篇 136:19–20"> 這兩個王一個是住在希實本的亞摩利王西宏。他統轄的地區從亞嫩谷旁的亞羅珥，包括山谷中部和基列的一半，直到亞捫人邊境的雅博河。</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 3:17; 約書亞記 13:20; 約書亞記 11:2"> 他的領土還包括約旦河谷東部：從加利利湖至亞拉巴海，也就是鹽海，到伯·耶施末，直到毗斯迦的山麓。</span>
<span className="v" id="v4" data-v="4" data-xref="申命記 1:4; 申命記 3:10–11; 約書亞記 13:12"> 另一個王是巴珊王噩，他原是利乏音的遺民，住在亞斯她錄和以得來。</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 3:14; 撒母耳記上 27:8; 約書亞記 13:11"> 他所統轄的地區包括黑門山、撒迦、整個巴珊，直到基述人和瑪迦人的邊境，還包括基列的另一半，直到希實本王西宏的國界。</span>
<span className="v" id="v6" data-v="6" data-xref="民數記 32:33; 民數記 32:29; 路加福音 22:29–42"> 耶和華的僕人摩西帶領以色列人征服了這兩個王，並把他們的土地分給呂便支派、迦得支派和瑪拿西半個支派的人作產業。</span>
<span className="v" id="v7" data-v="7" data-xref="約書亞記 11:17; 約書亞記 11:23–1; 約書亞記 1:3–4"> 約書亞帶領以色列人征服了約旦河西的諸王，佔領的土地包括從黎巴嫩谷地的巴力·迦得直到西珥的哈拉山。約書亞按以色列的支派把這些土地分給以色列人。</span>
<span className="v" id="v8" data-v="8" data-xref="約書亞記 11:16; 約書亞記 10:40; 約書亞記 9:1"> 那裡有山區、丘陵、河谷、山坡、曠野和南地，就是赫人、亞摩利人、迦南人、比利洗人、希未人、耶布斯人住的地方。</span>
<span className="v" id="v9" data-v="9" data-xref="約書亞記 8:29–35; 約書亞記 6:2–21; 約書亞記 8:1"> 這些王是耶利哥王、伯特利附近的艾王、</span>
<span className="v" id="v10" data-v="10" data-xref="約書亞記 10:23; 約書亞記 10:36–37; 約書亞記 10:3"> 耶路撒冷王、希伯崙王、</span>
<span className="v" id="v11" data-v="11" data-xref="約書亞記 10:31–32; 約書亞記 10:3–23"> 耶末王、拉吉王、</span>
<span className="v" id="v12" data-v="12" data-xref="約書亞記 10:33; 約書亞記 15:39; 約書亞記 10:3"> 伊磯倫王、基色王、</span>
<span className="v" id="v13" data-v="13" data-xref="約書亞記 10:38; 約書亞記 10:3; 約書亞記 15:36"> 底璧王、基德王、</span>
<span className="v" id="v14" data-v="14" data-xref="民數記 21:1; 民數記 14:45; 民數記 21:3"> 何珥瑪王、亞拉得王、</span>
<span className="v" id="v15" data-v="15" data-xref="約書亞記 10:29–30; 撒母耳記上 22:1"> 立拿王、亞杜蘭王、</span>
<span className="v" id="v16" data-v="16" data-xref="約書亞記 10:28; 士師記 1:22; 約書亞記 8:17"> 瑪基大王、伯特利王、</span>
<span className="v" id="v17" data-v="17" data-xref="列王紀上 4:10; 約書亞記 15:34; 約書亞記 19:13"> 他普亞王、希弗王、</span>
<span className="v" id="v18" data-v="18" data-xref="約書亞記 19:30; 以賽亞書 33:9; 約書亞記 13:4"> 亞弗王、拉沙崙王、</span>
<span className="v" id="v19" data-v="19" data-xref="約書亞記 11:1; 士師記 4:2; 約書亞記 11:10–11"> 瑪頓王、夏瑣王、</span>
<span className="v" id="v20" data-v="20" data-xref="約書亞記 11:1; 約書亞記 19:15; 約書亞記 19:25"> 伸崙·米崙王、押煞王、</span>
<span className="v" id="v21" data-v="21" data-xref="約書亞記 17:11; 列王紀下 23:29–30; 士師記 5:19"> 他納王、米吉多王、</span>
<span className="v" id="v22" data-v="22" data-xref="約書亞記 19:37; 約書亞記 21:32; 約書亞記 15:23"> 基低斯王、迦密附近的約念王、</span>
<span className="v" id="v23" data-v="23" data-xref="約書亞記 11:2; 創世記 14:1–2; 約書亞記 4:19"> 多珥山上的多珥王、吉甲的戈印王、</span>
<span className="v" id="v24" data-v="24" data-xref="列王紀下 15:14; 列王紀上 16:23; 申命記 7:24"> 得撒王，共三十一個王。</span>

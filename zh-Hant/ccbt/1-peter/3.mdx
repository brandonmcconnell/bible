## 夫妻之道

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歌羅西書 3:18; 以弗所書 5:33; 以弗所書 5:22–24"> 照樣，你們作妻子的要順服自己的丈夫。這樣，即使丈夫不信從真道，也會因為看見妻子貞潔和敬虔的品行而被無聲地感化。</span>
<span className="v" id="v3" data-v="3" data-xref="提摩太前書 2:9–10; 羅馬書 12:2; 以賽亞書 3:18–24"> 你們不要注重外表的妝飾，像編頭髮、戴金飾或穿華麗的衣服，</span>
<span className="v" id="v4" data-v="4" data-xref="歌羅西書 3:12; 撒母耳記上 16:7; 羅馬書 2:29"> 要以溫柔、嫺靜這些永不褪色的內在美為妝飾，這是上帝所看重的。</span>
<span className="v" id="v5" data-v="5" data-xref="提多書 2:3–4; 提摩太前書 5:5; 路加福音 2:37"> 從前那些仰賴上帝的聖潔婦女，都以這些來妝飾自己，並順服自己的丈夫，</span>
<span className="v" id="v6" data-v="6" data-xref="創世記 18:12; 羅馬書 9:7–9; 以賽亞書 57:11"> 正如撒拉順服亞伯拉罕，稱他為主人。你們如果做對的事，不怕恐嚇，就是撒拉的女兒。</span>
<span className="v" id="v7" data-v="7" data-xref="歌羅西書 3:19; 創世記 2:23–24; 馬太福音 19:3–9"> 你們作丈夫的也一樣，要按情理<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「按情理」希臘文是「按知識」。">a</a></sup>與妻子共同生活，因為她們比你們軟弱。要敬重她們，因為她們和你們一同承受生命之恩。這樣，你們的禱告就可以暢通無阻了。</span>
</div>
</div>

## 要為義受苦

<div className="bt">
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="羅馬書 12:10; 以弗所書 4:31–2; 彼得前書 1:22"> 總而言之，你們要同心合意，互相關懷，彼此相愛，仁慈謙卑。</span>
<span className="v" id="v9" data-v="9" data-xref="箴言 20:22; 羅馬書 12:17; 羅馬書 12:14"> 不要以惡報惡，以辱罵還辱罵，反要祝福對方，因為這是你們蒙召的目的，好叫你們蒙福。</span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 34:12–16; 雅各書 1:26; 彼得前書 2:1"> 聖經上說：<br /><span className="pl pl-1">「若有人熱愛生命，</span><br /><span className="pl pl-1">渴望幸福，</span><br /><span className="pl pl-1">就要舌頭不出惡言，</span><br /><span className="pl pl-1">嘴唇不說詭詐的話。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="馬太福音 5:9; 詩篇 34:14; 希伯來書 12:14"> <span className="pl pl-1">要棄惡行善，竭力追求和睦。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 34:15–16; 約翰福音 9:31; 箴言 15:29"> <span className="pl pl-1">因為主的眼睛看顧義人，</span><br /><span className="pl pl-1">祂的耳朵垂聽他們的祈求。</span><br /><span className="pl pl-1">但主必嚴懲作惡之人。」</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="詩篇34·12‑16。">b</a></sup></span>
<span className="v" id="v13" data-v="13" data-xref="箴言 16:7; 羅馬書 8:28; 帖撒羅尼迦前書 5:15"> 如果你們熱心行善，有誰會害你們呢？</span>
<span className="v" id="v14" data-v="14" data-xref="馬太福音 10:28; 彼得前書 2:19–20; 馬太福音 5:10–12"> 就算你們為義受苦，也是有福的。不要害怕別人的恐嚇<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="「不要害怕別人的恐嚇」或譯「不要怕別人所怕的」。以賽亞書8·12。">c</a></sup>，也不要驚慌，</span>
<span className="v" id="v15" data-v="15" data-xref="歌羅西書 4:6; 提摩太後書 2:25–26; 路加福音 21:14–15"> 要從心裡尊基督為主。如果有人問起你們心中的盼望，你們要隨時準備答覆，</span>
<span className="v" id="v16" data-v="16" data-xref="彼得前書 2:12; 希伯來書 13:18; 彼得前書 2:15"> 但態度要溫和恭敬，存無愧的良心。這樣，那些對你們在基督裡的好品行妄加誣衊的人會自覺羞愧。</span>
<span className="v" id="v17" data-v="17" data-xref="彼得前書 3:14; 彼得前書 4:19; 馬太福音 26:39"> 如果上帝的旨意是要你們因行善而受苦，也總比你們因作惡而受苦強。</span>
<span className="v" id="v18" data-v="18" data-xref="希伯來書 9:28; 希伯來書 9:26; 哥林多後書 5:21"> 因為基督也曾一次為罪受苦<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="「受苦」有古卷作「受死」。">d</a></sup>，以無罪之身代替不義之人，為要領你們到上帝面前。祂的肉體雖被處死，但祂藉著聖靈復活了。</span>
<span className="v" id="v19" data-v="19" data-xref="彼得前書 4:6; 以賽亞書 61:1; 以賽亞書 42:7"> 祂還藉著聖靈向那些被監禁的靈魂傳道，</span>
<span className="v" id="v20" data-v="20" data-xref="希伯來書 11:7; 彼得後書 2:5; 創世記 6:3"> 就是從前在挪亞造方舟、上帝耐心等候人們悔改的時代中那些不肯信的人。當時進入方舟，從洪水中得救的人很少，只有八個人。</span>
<span className="v" id="v21" data-v="21" data-xref="馬可福音 16:16; 以西結書 36:25–26; 使徒行傳 2:38"> 這水預表的洗禮現在藉著耶穌基督的復活也拯救了你們，這洗禮不是要除掉肉體的污穢，而是求在上帝面前有無愧的良心。</span>
<span className="v" id="v22" data-v="22" data-xref="希伯來書 9:24; 希伯來書 12:2; 希伯來書 10:12"> 基督已經升到天上，坐在上帝的右邊，眾天使、掌權的、有能力的都服從了祂。</span>
</div>
</div>

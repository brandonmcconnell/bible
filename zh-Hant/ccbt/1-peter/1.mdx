<span className="v" id="v2" data-v="2" data-xref="帖撒羅尼迦後書 2:13; 以弗所書 1:4–5; 希伯來書 12:24"> 你們按照父上帝預先定好的旨意蒙了揀選，藉著聖靈得以聖潔，好順服耶穌基督，並靠祂的血得到潔淨。 願上帝多多賜給你們恩典和平安！</span>

## 活潑的盼望

<div className="bt">
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="彼得前書 1:23; 約翰一書 5:4; 羅馬書 15:13"> 願頌讚歸於我們主耶穌基督的父上帝！祂懷著極大的憐憫，透過耶穌基督從死裡復活，使我們獲得重生，有活潑的盼望，</span>
<span className="v" id="v4" data-v="4" data-xref="啟示錄 21:27; 希伯來書 9:15; 彼得前書 5:4"> 可以承受那不會朽壞、不會腐爛、不會衰殘、為你們存留在天上的產業。</span>
<span className="v" id="v5" data-v="5" data-xref="腓立比書 1:6; 以弗所書 2:8; 帖撒羅尼迦後書 2:13–14"> 你們這些因信而蒙上帝用大能保守的人，必能得到那已經預備好、在末世要顯明的救恩。</span>
<span className="v" id="v6" data-v="6" data-xref="雅各書 1:2; 彼得前書 5:10; 羅馬書 12:12"> 為此，即使現今你們必須暫時在百般試煉中忍受痛苦，也要滿懷喜樂。</span>
<span className="v" id="v7" data-v="7" data-xref="約伯記 23:10; 以賽亞書 48:10; 彼得前書 4:12"> 這樣，你們的信心經過考驗後，比那經過火煉仍會壞掉的金子更加寶貴，使你們可以在耶穌基督顯現時得到稱讚、榮耀和尊貴。</span>
<span className="v" id="v8" data-v="8" data-xref="約翰福音 20:29; 哥林多後書 5:7; 羅馬書 15:13"> 你們雖然沒有見過祂，卻愛祂；雖然現在看不見祂，卻信祂，並且有無法形容、充滿榮耀的喜樂。</span>
<span className="v" id="v9" data-v="9" data-xref="羅馬書 6:22; 雅各書 1:21; 希伯來書 11:13"> 因為你們得到了信心帶來的果效，就是你們的靈魂得救。</span>
<span className="v" id="v10" data-v="10" data-xref="馬太福音 13:17; 路加福音 10:24; 路加福音 24:25–27"> 有關這救恩，那些預言恩典要臨到你們的眾先知早已詳細尋求和查考了。</span>
<span className="v" id="v11" data-v="11" data-xref="以賽亞書 52:13–14; 彼得後書 1:21; 路加福音 24:25–27"> 基督的靈曾在他們心中指示他們，預言基督要受苦，然後得榮耀。他們便詳細查考這些事在何時、何境況下發生。</span>
<span className="v" id="v12" data-v="12" data-xref="約翰福音 15:26; 哥林多前書 2:10; 以弗所書 3:10"> 他們得到啟示，知道他們傳講這些事不是為了自己，而是為了你們。現在，那些靠著從天上差來的聖靈向你們傳福音的人，已經將這些事傳給你們了。連天使也渴望把這些事看個明白。</span>
</div>
</div>

## 要聖潔像主

<div className="bt">
<div className="bp poetry">
<span className="v" id="v13" data-v="13" data-xref="彼得前書 5:8; 路加福音 12:35; 彼得前書 4:7"> 所以，要預備好你們的心，謹慎自律，專心盼望耶穌基督顯現時要帶給你們的恩典。</span>
<span className="v" id="v14" data-v="14" data-xref="羅馬書 12:2; 提多書 3:3–5; 彼得前書 4:2–3"> 你們既是順服的兒女，就不要再像從前無知的時候那樣放縱私慾。</span>
<span className="v" id="v15" data-v="15" data-xref="馬太福音 5:48; 哥林多後書 7:1; 希伯來書 12:14"> 那呼召你們的是聖潔的，你們的一切行為也要聖潔。</span>
<span className="v" id="v16" data-v="16" data-xref="利未記 11:44; 利未記 19:2; 利未記 20:7"> 因為聖經上說：「你們要聖潔，因為我是聖潔的。」<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="利未記11·44、45；19·2。">a</a></sup></span>
<span className="v" id="v17" data-v="17" data-xref="使徒行傳 10:34–35; 歷代志下 19:7; 馬太福音 6:9"> 既然你們稱呼那位按各人的行為公正無私地審判人的上帝為父，就應該存著敬畏的心過你們在世上寄居的日子。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前書 6:20; 提多書 2:14; 詩篇 49:7–8"> 要知道，你們從傳統的、沒有意義的生活中被救贖出來，不是靠金銀等會朽壞的東西，</span>
<span className="v" id="v19" data-v="19" data-xref="約翰一書 1:7; 彼得前書 2:22–24; 約翰福音 1:29"> 而是靠無瑕無疵的代罪羔羊基督的寶血。</span>
<span className="v" id="v20" data-v="20" data-xref="以弗所書 1:4; 提摩太後書 1:9–10; 希伯來書 9:26"> 基督是上帝在創世以前預先揀選的，卻在這末世為你們顯現。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行傳 2:24; 希伯來書 2:9; 約翰福音 12:44"> 你們藉著基督信了使祂從死裡復活、賜祂榮耀的上帝，所以，你們的信心和盼望都在於上帝。</span>
<span className="v" id="v22" data-v="22" data-xref="提摩太前書 1:5; 希伯來書 13:1; 羅馬書 12:9–10"> 你們既因順服真理，潔淨了自己的心，能夠真誠地愛弟兄姊妹，就當以清潔的心彼此切實相愛。</span>
<span className="v" id="v23" data-v="23" data-xref="彼得前書 1:3; 希伯來書 4:12; 約翰福音 1:13"> 你們獲得重生，不是藉著會腐爛的種子，而是藉著不會腐爛的種子——上帝活潑永存的道。</span>
<span className="v" id="v24" data-v="24" data-xref="以賽亞書 40:6–8; 詩篇 103:15; 雅各書 4:14"> 因為<br /><span className="pl pl-1">「芸芸眾生盡如草，</span><br /><span className="pl pl-1">榮華紛縟草上花；</span><br /><span className="pl pl-1">草必枯乾花必殘，</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="以賽亞書 40:8; 馬太福音 5:18; 詩篇 119:89"> <span className="pl pl-1">唯有主道永長存。」</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="以賽亞書40·6‑8。">b</a></sup>這道就是傳給你們的福音。</span>
</div>
</div>

## 上帝的兒女

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="約翰福音 1:12; 加拉太書 3:26; 哥林多後書 6:18"> 你們看，父上帝何等愛我們，稱我們為祂的兒女！我們也實在是祂的兒女，世人之所以不認識我們，是因為他們不認識父上帝。</span>
<span className="v" id="v2" data-v="2" data-xref="腓立比書 3:21; 歌羅西書 3:4; 哥林多前書 13:12"> 親愛的弟兄姊妹，我們現在是上帝的兒女，將來如何還未顯明。但我們知道，當基督顯現的時候，我們會像祂，因為我們必見到祂的本相。</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多後書 7:1; 約翰一書 2:6; 彼得後書 3:14"> 凡心存這種盼望的人都會自潔，因為祂是聖潔的。</span>
<span className="v" id="v4" data-v="4" data-xref="約翰一書 5:17; 羅馬書 3:20; 羅馬書 4:15"> 人犯罪就是違背上帝的律法，違背上帝的律法就是犯罪。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多後書 5:21; 希伯來書 9:28; 彼得前書 3:18"> 你們知道，耶穌降世是為了除掉罪，祂裡面毫無罪惡。</span>
<span className="v" id="v6" data-v="6" data-xref="約翰三書 1:11; 約翰一書 2:4; 約翰一書 3:9"> 住在祂裡面的人不會犯罪；不斷犯罪的人既沒見過祂，也不認識祂。</span>
<span className="v" id="v7" data-v="7" data-xref="約翰一書 2:29; 彼得前書 1:15–16; 羅馬書 2:13"> 孩子們，不要受人誘騙，行義的才是義人，正如耶穌是公義的。</span>
<span className="v" id="v8" data-v="8" data-xref="希伯來書 2:14; 約翰福音 8:44; 歌羅西書 2:15"> 一直犯罪的人是屬魔鬼的，因為魔鬼從起初便犯罪，但上帝兒子的顯現是為了摧毀魔鬼的工作。</span>
<span className="v" id="v9" data-v="9" data-xref="約翰一書 5:18; 彼得前書 1:23; 約翰福音 1:13"> 從上帝生的人不會繼續犯罪，因為他裡面有上帝的生命<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「上帝的生命」希臘文是「上帝的種子」。">a</a></sup>。他不能繼續犯罪，因為他是從上帝生的。</span>
<span className="v" id="v10" data-v="10" data-xref="約翰一書 4:8; 約翰三書 1:11; 路加福音 6:35"> 這樣，就可以看出誰是上帝的兒女，誰是魔鬼的兒女。凡不行義、不愛弟兄姊妹的人，都不是上帝的兒女。</span>
</div>
</div>

## 彼此相愛

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="約翰福音 15:12; 約翰二書 1:5; 約翰一書 4:7"> 我們應當彼此相愛，這是你們起初聽見的信息。</span>
<span className="v" id="v12" data-v="12" data-xref="希伯來書 11:4; 創世記 4:4–15; 箴言 29:27"> 不要步該隱的後塵。他屬於那惡者，殺害了自己的弟弟。他為什麼要殺害自己的弟弟呢？因為他行為邪惡，他弟弟卻秉行公義。</span>
<span className="v" id="v13" data-v="13" data-xref="約翰福音 15:18–19; 約翰福音 17:14; 路加福音 21:17"> 弟兄姊妹，世人若恨你們，不要驚奇。</span>
<span className="v" id="v14" data-v="14" data-xref="約翰福音 13:35; 約翰一書 5:2; 約翰一書 4:20–21"> 我們因愛弟兄姊妹，便知道自己已經出死入生了。不愛弟兄姊妹的，仍然陷在死亡中。</span>
<span className="v" id="v15" data-v="15" data-xref="馬太福音 5:21–22; 箴言 26:24–26; 啟示錄 21:8"> 恨弟兄姊妹的就是殺人的，你們知道：殺人者裡面沒有永生。</span>
<span className="v" id="v16" data-v="16" data-xref="約翰一書 4:9–11; 以弗所書 5:2; 約翰福音 13:34"> 耶穌為我們捨命，我們由此便知道什麼是愛，我們也理當為弟兄姊妹捨命。</span>
<span className="v" id="v17" data-v="17" data-xref="希伯來書 13:16; 以賽亞書 58:7–10; 申命記 15:7–11"> 如果一個豐衣足食的人看見貧窮的弟兄姊妹，卻毫無憐憫之心，怎能說他愛上帝呢？</span>
<span className="v" id="v18" data-v="18" data-xref="雅各書 2:15–16; 羅馬書 12:9; 彼得前書 1:22"> 所以，孩子們啊，不要單在言語和口頭上說愛人，總要按真理行出來。</span>
<span className="v" id="v19" data-v="19" data-xref="希伯來書 10:22; 約翰一書 3:21; 希伯來書 6:10–11"> 這樣，我們必知道自己屬於真理，即使我們心中自責，也可以在上帝面前安心，因為上帝比我們的心大，祂洞悉一切。</span>
<span className="v" id="v21" data-v="21" data-xref="約翰一書 2:28; 希伯來書 4:16; 哥林多後書 1:12"> 親愛的弟兄姊妹，我們若能凡事問心無愧，就可以在上帝面前坦然無懼。</span>
<span className="v" id="v22" data-v="22" data-xref="約翰福音 15:7; 約翰福音 9:31; 約翰一書 5:14"> 這樣，我們無論向上帝祈求什麼，都必得到，因為我們遵守祂的命令，做祂喜悅的事。</span>
<span className="v" id="v23" data-v="23" data-xref="約翰福音 6:29; 約翰福音 13:34; 彼得前書 1:22"> 上帝的命令是：我們要信祂兒子耶穌基督的名，遵照祂的命令彼此相愛。</span>
<span className="v" id="v24" data-v="24" data-xref="哥林多前書 3:16; 約翰一書 4:15–16; 約翰一書 4:12–13"> 遵行上帝命令的人就住在上帝裡面，上帝也住在他裡面。我們藉著上帝賜給我們的聖靈知道：祂住在我們裡面。</span>
</div>
</div>

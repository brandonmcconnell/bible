<span className="v" id="v2" data-v="2" data-xref="約翰一書 4:14; 彼得前書 3:18; 約翰一書 4:10"> 祂為我們的罪作了贖罪祭，不只是為我們的罪，也是為天下人的罪。</span>
<span className="v" id="v3" data-v="3" data-xref="約翰福音 14:15; 約翰福音 15:10; 路加福音 6:46"> 我們若遵行上帝的命令，就知道自己確實認識祂。</span>
<span className="v" id="v4" data-v="4" data-xref="約翰一書 1:6; 提多書 1:16; 雅各書 2:14–16"> 若有人說「我認識祂」，卻不遵行祂的命令，這人是說謊的，他裡面沒有真理。</span>
<span className="v" id="v5" data-v="5" data-xref="約翰福音 14:23; 約翰福音 14:21; 約翰一書 4:12–13"> 人若遵行祂的道，就完全活出了祂的愛，我們藉此知道自己是在祂裡面。</span>
<span className="v" id="v6" data-v="6" data-xref="彼得前書 2:21; 約翰福音 13:15; 哥林多前書 11:1"> 所以，自稱住在祂裡面的人，行事為人理當和耶穌一樣。</span>

## 新命令

<div className="bt">
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="約翰一書 3:11; 利未記 19:18; 馬可福音 12:29–34"> 親愛的弟兄姊妹，我寫給你們的並不是一條新命令，而是你們起初接受的舊命令，這舊命令就是你們已經聽過的道。</span>
<span className="v" id="v8" data-v="8" data-xref="以弗所書 5:8; 羅馬書 13:12; 約翰福音 13:34"> 然而，我寫給你們的也是新命令，在基督和你們身上都顯明是真實的，因為黑暗漸漸消逝，真光已經在照耀。</span>
<span className="v" id="v9" data-v="9" data-xref="約翰一書 4:20; 約翰一書 2:11; 約翰一書 3:13–17"> 人若說自己在光明中，卻恨他的弟兄姊妹，他仍然活在黑暗裡。</span>
<span className="v" id="v10" data-v="10" data-xref="約翰一書 3:14; 羅馬書 9:32–33; 羅馬書 14:13"> 愛弟兄姊妹的人住在光明中，沒有什麼可以絆倒他<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「沒有什麼可以絆倒他」或譯「他也不會絆倒別人」。">a</a></sup>。</span>
<span className="v" id="v11" data-v="11" data-xref="約翰福音 12:35; 提多書 3:3; 約翰一書 1:6"> 恨弟兄姊妹的人活在黑暗中，走在黑暗中，不知何去何從，因為黑暗弄瞎了他的眼睛。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行傳 10:43; 使徒行傳 13:38; 以弗所書 1:7"> 孩子們，我寫信給你們，因為靠著祂的名，你們的罪已經得到赦免。</span>
<span className="v" id="v13" data-v="13" data-xref="約翰福音 14:7; 約翰一書 2:14; 路加福音 10:22"> 父老們，我寫信給你們，因為你們已經認識從太初就存在的那位。年輕人，我寫信給你們，因為你們已經戰勝了那惡者。</span>
<span className="v" id="v14" data-v="14" data-xref="詩篇 119:11; 約翰一書 2:13; 歌羅西書 3:16"> 孩子們，我曾寫信給你們，因為你們認識了父。父老們，我曾寫信給你們，因為你們認識了從太初就存在的那位。年輕人，我曾寫信給你們，因為你們剛強，上帝的道常在你們裡面，並且你們戰勝了那惡者。</span>
<span className="v" id="v15" data-v="15" data-xref="雅各書 4:4; 羅馬書 12:2; 馬太福音 6:24"> 不要愛世界和世上的事，因為人若愛世界，就不會再有愛父的心了。</span>
<span className="v" id="v16" data-v="16" data-xref="羅馬書 13:14; 加拉太書 5:17; 詩篇 119:36–37"> 凡屬世界的，如肉體的私慾、眼目的私慾和今生的驕傲都不是從父那裡來的，而是從世界來的。</span>
<span className="v" id="v17" data-v="17" data-xref="馬太福音 24:35; 羅馬書 12:2; 哥林多前書 7:31"> 這世界和其中一切的私慾都在消逝，但遵守上帝旨意的人永遠長存。</span>
</div>
</div>

## 防備敵基督者

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="約翰一書 4:3; 約翰二書 1:7; 馬太福音 24:24"> 孩子們，現在是末世了。你們從前聽說敵基督者要來，其實現在許多敵基督者已經出現了，由此可知，現在是末世了。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行傳 20:30; 哥林多前書 11:19; 路加福音 8:13"> 這些人是從我們中間出去的，但他們不屬於我們。他們如果屬於我們，就會留在我們當中。他們的離去顯明他們都不屬於我們。</span>
<span className="v" id="v20" data-v="20" data-xref="約翰福音 14:26; 約翰一書 2:27; 哥林多後書 1:21–22"> 你們從那位聖者領受了恩膏，所以明白真理。</span>
<span className="v" id="v21" data-v="21" data-xref="彼得後書 1:12; 猶大書 1:5; 箴言 1:5"> 我寫信給你們，不是因為你們不明白真理，而是因為你們明白真理，並且知道真理中毫無謊言。</span>
<span className="v" id="v22" data-v="22" data-xref="約翰二書 1:7; 約翰一書 4:3; 約翰一書 2:18"> 誰是說謊的呢？不就是那否認耶穌是基督的嗎？那不承認父和子的就是敵基督者。</span>
<span className="v" id="v23" data-v="23" data-xref="約翰一書 4:15; 約翰福音 8:19; 約翰福音 5:23"> 凡否認子的，都沒有父；凡承認子的，連父也有了。</span>
<span className="v" id="v24" data-v="24" data-xref="約翰福音 14:23; 約翰福音 15:9–10; 約翰一書 4:13"> 你們務要把起初所聽見的道謹記在心，這樣，你們就必住在子裡面，也必住在父裡面。</span>
<span className="v" id="v25" data-v="25" data-xref="約翰福音 10:28; 提多書 3:7; 猶大書 1:21"> 基督應許給我們的是永生。</span>
<span className="v" id="v26" data-v="26" data-xref="彼得後書 2:1–3; 約翰二書 1:7; 使徒行傳 20:29–30"> 我寫這些話給你們，是針對那些誘騙你們的人。</span>
</div>
</div>

## 順從聖靈

<div className="bt">
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="約翰福音 14:26; 約翰一書 2:20–21; 哥林多前書 2:13"> 既然你們從那位聖者領受的恩膏常在你們裡面，就無需他人指教你們，祂的恩膏必在一切事上指教你們。這恩膏真實無偽，你們要按這恩膏的指教住在基督裡。</span>
<span className="v" id="v28" data-v="28" data-xref="約翰一書 4:17; 馬可福音 8:38; 約翰一書 3:2"> 孩子們，你們要住在基督裡。這樣，當祂顯現的時候，就是祂再來的時候，我們便能坦然無懼，在祂面前不至羞愧。</span>
<span className="v" id="v29" data-v="29" data-xref="約翰福音 3:3–5; 約翰一書 3:7; 約翰一書 5:1"> 你們既然知道祂是公義的，也該知道所有行義的人都是從上帝生的。</span>
</div>

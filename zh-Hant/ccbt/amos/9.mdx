## 耶和華的審判

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="詩篇 68:21; 啟示錄 1:17; 以賽亞書 6:1"> <span className="pl pl-1">我看見主站在祭壇旁，祂說：</span><br /><span className="pl pl-1">「你要擊打柱頂，使殿的根基震動；</span><br /><span className="pl pl-1">要打碎它們，使殿宇坍塌壓死眾人。</span><br /><span className="pl pl-1">僥倖生還的，我要用刀劍殺掉，</span><br /><span className="pl pl-1">無人能逃脫，無人能倖免。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="耶利米書 51:53; 詩篇 139:7–10; 俄巴底亞書 1:4"> <span className="pl pl-1">即使他們挖洞鑽進陰間，</span><br /><span className="pl pl-1">我也要把他們揪出來；</span><br /><span className="pl pl-1">即使他們爬上高天，</span><br /><span className="pl pl-1">我也要把他們拉下來；</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="耶利米書 16:16; 耶利米書 23:23–24; 以賽亞書 27:1"> <span className="pl pl-1">即使他們藏在迦密山的峰頂，</span><br /><span className="pl pl-1">我也要去搜尋，捉住他們；</span><br /><span className="pl pl-1">即使他們潛到海底，</span><br /><span className="pl pl-1">我也要派海蛇去吞咬他們；</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="利未記 26:33; 耶利米書 21:10; 耶利米書 44:11"> <span className="pl pl-1">即使他們被敵人擄去，</span><br /><span className="pl pl-1">我也要命刀劍追殺他們。</span><br /><span className="pl pl-1">我要定睛在他們身上，</span><br /><span className="pl pl-1">不是要賜福而是要降禍。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="阿摩司書 8:8; 詩篇 46:6; 以賽亞書 64:1"> <span className="pl pl-1">主——萬軍之耶和華觸摸大地，</span><br /><span className="pl pl-1">大地就消融，地上的人都要哀號；</span><br /><span className="pl pl-1">大地如埃及的尼羅河漲起退落。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="阿摩司書 5:8; 阿摩司書 4:13; 詩篇 104:3"> <span className="pl pl-1">那位在天上建造樓閣，</span><br /><span className="pl pl-1">在大地之上立定穹蒼，</span><br /><span className="pl pl-1">召來海水澆在大地上的——</span><br /><span className="pl pl-1">祂的名字是耶和華。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="耶利米書 47:4; 申命記 2:23; 列王紀下 16:9"> <span className="pl pl-1">耶和華說：</span><br /><span className="pl pl-1">「以色列人啊，</span><br /><span className="pl pl-1">在我眼中，你們不是和古實人一樣嗎？</span><br /><span className="pl pl-1">我不是領你們出埃及，</span><br /><span className="pl pl-1">領非利士人出迦斐托</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「迦斐托」即克里特島。">a</a></sup><br /><span className="pl pl-1">，</span><br /><span className="pl pl-1">領亞蘭人出吉珥嗎？</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="耶利米書 30:11; 阿摩司書 9:4; 耶利米書 44:27"> <span className="pl pl-1">主耶和華的眼目察看這罪惡的國家，</span><br /><span className="pl pl-1">我要從地上除滅它，</span><br /><span className="pl pl-1">但不會完全毀滅雅各家。</span><br /><span className="pl pl-1">這是耶和華說的。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="路加福音 22:31; 申命記 28:64; 以賽亞書 30:28"> <span className="pl pl-1">「因為我要下令在萬國中篩以色列家，</span><br /><span className="pl pl-1">就像人篩穀物，一粒石子也不會落在地上。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="阿摩司書 6:3; 以賽亞書 33:14; 阿摩司書 6:1"> <span className="pl pl-1">在我的子民中，</span><br /><span className="pl pl-1">所有誇口說『災禍不會追上我們，也不會迎面而來』的罪人，</span><br /><span className="pl pl-1">都要死在刀下。</span></span>
</div>
</div>

## 以色列的復興

<div className="bt">
<div className="bp poetry">
<span className="v" id="v11" data-v="11" data-xref="使徒行傳 15:15–17; 耶利米書 33:14–16; 以賽亞書 16:5"> <span className="pl pl-1">「到那日，</span><br /><span className="pl pl-1">我要重建大衛已傾覆的棚子，</span><br /><span className="pl pl-1">修補它城牆的缺口。</span><br /><span className="pl pl-1">我要從廢墟中重建它，</span><br /><span className="pl pl-1">恢復它往日的榮耀。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="以賽亞書 43:7; 以賽亞書 65:1; 使徒行傳 15:17"> <span className="pl pl-1">這樣，以色列人必擁有以東所剩的和所有屬於我名下的國家。</span><br /><span className="pl pl-1">這是要成就這事的耶和華說的。」</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="約珥書 3:18; 約翰福音 4:35; 利未記 26:5"> <span className="pl pl-1">耶和華說：</span><br /><span className="pl pl-1">「時候將到，</span><br /><span className="pl pl-1">五穀還未收完又該耕種了，</span><br /><span className="pl pl-1">葡萄還未踩完又該栽種了。</span><br /><span className="pl pl-1">甜酒從群山上滴下，在丘嶺間流淌。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="以賽亞書 61:4; 耶利米書 30:3; 耶利米書 30:18"> <span className="pl pl-1">我要使我被擄的以色列子民返鄉，</span><br /><span className="pl pl-1">他們要重建廢城並住在城中，</span><br /><span className="pl pl-1">栽種葡萄園，喝園中釀出的美酒，</span><br /><span className="pl pl-1">整理園圃，吃園中出產的佳果。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="耶利米書 24:6; 以西結書 37:25; 以賽亞書 60:21"> <span className="pl pl-1">我要將以色列人栽種在他們自己的土地上，</span><br /><span className="pl pl-1">他們永不再從我賜給他們的土地上被剷除。」</span><br /><span className="pl pl-1">這是你們的上帝耶和華說的。</span></span>
</div>

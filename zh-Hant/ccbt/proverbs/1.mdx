## 箴言的價值

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="箴言 10:1; 歷代志上 22:9; 歷代志上 28:5"> 這是大衛的兒子以色列王所羅門的箴言。</span>
</div>
<div className="bp poetry">
<span className="v" id="v2" data-v="2" data-xref="箴言 7:4; 申命記 4:5–6; 提摩太後書 3:15–17"> <span className="pl pl-1">為使人認識智慧和教誨，</span><br /><span className="pl pl-2">領悟真知灼見，</span></span>
<span className="v" id="v3" data-v="3" data-xref="箴言 2:1–9; 約伯記 22:22; 箴言 8:10–11"> <span className="pl pl-1">接受精明處事的教誨，</span><br /><span className="pl pl-2">為人處事仁義、公平、正直；</span></span>
<span className="v" id="v4" data-v="4" data-xref="箴言 8:5; 箴言 8:17; 詩篇 119:9"> <span className="pl pl-1">使愚昧人明智，</span><br /><span className="pl pl-2">使年輕人有知識和明辨力；</span></span>
<span className="v" id="v5" data-v="5" data-xref="箴言 12:1; 箴言 9:9; 哥林多前書 10:15"> <span className="pl pl-1">使智者聽了長學問，</span><br /><span className="pl pl-2">明哲聽了得指引；</span></span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 78:2; 馬可福音 4:11; 詩篇 49:4"> <span className="pl pl-1">使人領悟箴言和比喻，</span><br /><span className="pl pl-2">明白智者的話和謎語。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="約伯記 28:28; 詩篇 111:10–1; 傳道書 12:13"> 知識始於敬畏耶和華，<br /><span className="pl pl-2">愚人輕視智慧和教誨。</span></span>
<span className="v" id="v8" data-v="8" data-xref="箴言 6:20; 箴言 30:17; 箴言 5:1–2"> <span className="pl pl-1">孩子啊，</span><br /><span className="pl pl-2">你要聽從父親的教誨，</span><br /><span className="pl pl-2">不可背棄母親的訓誨。</span></span>
<span className="v" id="v9" data-v="9" data-xref="但以理書 5:29; 箴言 4:9; 創世記 41:42"> <span className="pl pl-1">因為這要作你頭上的華冠，</span><br /><span className="pl pl-2">頸上的項鏈。</span></span>
<span className="v" id="v10" data-v="10" data-xref="以弗所書 5:11; 箴言 16:29; 詩篇 1:1"> <span className="pl pl-1">孩子啊，惡人若引誘你，</span><br /><span className="pl pl-2">不要屈從。</span></span>
<span className="v" id="v11" data-v="11" data-xref="耶利米書 5:26; 箴言 1:18; 箴言 12:6"> <span className="pl pl-1">他們若說：「跟我們來吧，</span><br /><span className="pl pl-2">我們去埋伏殺人，</span><br /><span className="pl pl-2">任意暗害無辜者；</span></span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 124:3; 詩篇 28:1; 羅馬書 3:13"> <span className="pl pl-1">我們要像陰間一樣生吞他們，</span><br /><span className="pl pl-2">整個吞沒他們，</span><br /><span className="pl pl-2">使他們如墜入墳墓的人；</span></span>
<span className="v" id="v13" data-v="13" data-xref="提摩太前書 6:9–10; 路加福音 12:15; 約伯記 24:2–3"> <span className="pl pl-1">我們必得到各樣寶物，</span><br /><span className="pl pl-2">把戰利品裝滿我們的房屋。</span></span>
<span className="v" id="v14" data-v="14"> <span className="pl pl-1">跟我們一起幹吧，</span><br /><span className="pl pl-2">大家有福同享！」</span></span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 119:101; 詩篇 1:1; 箴言 4:14–15"> <span className="pl pl-1">孩子啊，</span><br /><span className="pl pl-2">不要走他們的道，</span><br /><span className="pl pl-2">切莫行他們的路。</span></span>
<span className="v" id="v16" data-v="16" data-xref="以賽亞書 59:7; 箴言 6:18; 箴言 4:16"> <span className="pl pl-1">因為他們奔向罪惡，</span><br /><span className="pl pl-2">急速地去殺人流血。</span></span>
<span className="v" id="v17" data-v="17" data-xref="約伯記 35:11; 箴言 7:23; 耶利米書 8:7"> <span className="pl pl-1">在飛鳥眼前設網羅，徒勞無功。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 9:16; 以斯帖記 7:10; 箴言 5:22–23"> <span className="pl pl-1">他們埋伏，卻自流己血；</span><br /><span className="pl pl-2">他們伏擊，卻自害己命。</span></span>
<span className="v" id="v19" data-v="19" data-xref="箴言 15:27; 彼得後書 2:3; 雅各書 5:1–4"> <span className="pl pl-1">這就是貪愛不義之財者的結局，</span><br /><span className="pl pl-2">不義之財終要奪去他們的性命。</span></span>
</div>
</div>

## 智慧的勸誡

<div className="bt">
<div className="bp poetry">
<span className="v" id="v20" data-v="20" data-xref="箴言 9:3; 歌羅西書 2:3; 路加福音 11:49"> <span className="pl pl-1">智慧在大街上高喊，</span><br /><span className="pl pl-2">在廣場上揚聲，</span></span>
<span className="v" id="v21" data-v="21" data-xref="使徒行傳 5:20; 箴言 9:3; 馬太福音 13:2"> <span className="pl pl-1">在熱鬧的街頭宣告，</span><br /><span className="pl pl-2">在城門口發言：</span></span>
<span className="v" id="v22" data-v="22" data-xref="箴言 1:29; 詩篇 1:1; 箴言 5:12"> <span className="pl pl-1">「你們愚昧人喜愛愚昧，</span><br /><span className="pl pl-2">嘲諷者以嘲弄為樂，</span><br /><span className="pl pl-2">無知者厭惡知識，</span><br /><span className="pl pl-2">要到什麼時候呢？</span></span>
<span className="v" id="v23" data-v="23" data-xref="使徒行傳 3:19; 以西結書 33:11; 以西結書 18:27–30"> <span className="pl pl-1">你們若因我的責備而回轉，</span><br /><span className="pl pl-2">我就向你們顯明我的旨意</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「我就向你們顯明我的旨意」希伯來文是「我就將我的靈澆灌你們」。">a</a></sup><br /><span className="pl pl-2">，</span><br /><span className="pl pl-2">叫你們明白我的話語。</span></span>
<span className="v" id="v24" data-v="24" data-xref="以賽亞書 65:12; 羅馬書 10:21; 耶利米書 7:13"> <span className="pl pl-1">我呼喚你們，</span><br /><span className="pl pl-2">你們卻充耳不聞；</span><br /><span className="pl pl-2">我向你們招手，</span><br /><span className="pl pl-2">你們卻視若無睹。</span></span>
<span className="v" id="v25" data-v="25" data-xref="詩篇 81:11; 路加福音 7:30; 箴言 1:30"> <span className="pl pl-1">你們漠視我的勸誡，</span><br /><span className="pl pl-2">不接受我的責備。</span></span>
<span className="v" id="v26" data-v="26" data-xref="詩篇 2:4; 箴言 10:24; 詩篇 37:13"> <span className="pl pl-1">因此，</span><br /><span className="pl pl-2">你們遭遇災難時，</span><br /><span className="pl pl-2">我必發笑；</span><br /><span className="pl pl-2">驚恐臨到你們時，</span><br /><span className="pl pl-2">我必嗤笑。</span></span>
<span className="v" id="v27" data-v="27" data-xref="箴言 3:25–26; 路加福音 21:34–35; 詩篇 58:9"> <span className="pl pl-1">那時，恐懼如風暴襲擊你們，</span><br /><span className="pl pl-2">災難如旋風臨到你們，</span><br /><span className="pl pl-2">憂愁和苦難吞沒你們。</span></span>
<span className="v" id="v28" data-v="28" data-xref="彌迦書 3:4; 雅各書 4:3; 耶利米書 11:11"> <span className="pl pl-1">你們呼求我，</span><br /><span className="pl pl-2">我也不回答；</span><br /><span className="pl pl-2">你們懇切地尋找我，</span><br /><span className="pl pl-2">卻找不到。</span></span>
<span className="v" id="v29" data-v="29" data-xref="箴言 1:22; 約伯記 21:14–15; 箴言 6:23"> <span className="pl pl-1">因為你們厭惡知識，</span><br /><span className="pl pl-2">決定不敬畏耶和華，</span></span>
<span className="v" id="v30" data-v="30" data-xref="詩篇 81:11; 箴言 1:25; 路加福音 14:18–20"> <span className="pl pl-1">不接受我的勸誡，</span><br /><span className="pl pl-2">又藐視我的責備。</span></span>
<span className="v" id="v31" data-v="31" data-xref="箴言 14:14; 耶利米書 6:19; 箴言 22:8"> <span className="pl pl-1">所以，你們必自食其果，</span><br /><span className="pl pl-2">因自己的惡謀而吃盡苦頭。</span></span>
<span className="v" id="v32" data-v="32" data-xref="箴言 8:36; 耶利米書 2:19; 約翰福音 3:36"> <span className="pl pl-1">愚昧人背離正道，</span><br /><span className="pl pl-2">自招滅亡；</span><br /><span className="pl pl-2">愚頑人逍遙自在，</span><br /><span className="pl pl-2">毀掉自己。</span></span>
<span className="v" id="v33" data-v="33" data-xref="詩篇 25:12–13; 詩篇 112:7–8; 以賽亞書 26:3"> <span className="pl pl-1">然而，那聽從我的必安然居住，</span><br /><span className="pl pl-2">得享安寧，</span><br /><span className="pl pl-2">不怕災禍。」</span></span>
</div>
</div>

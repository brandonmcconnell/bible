## 信靠耶和華

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="箴言 4:5; 約翰福音 14:21–24; 申命記 6:6–9"> <span className="pl pl-1">孩子啊，不要忘記我的訓誨，</span><br /><span className="pl pl-2">要把我的誡命存在心裡，</span></span>
<span className="v" id="v2" data-v="2" data-xref="以弗所書 6:1–3; 箴言 4:10; 詩篇 91:16"> <span className="pl pl-1">因為這必使你延年益壽，</span><br /><span className="pl pl-2">幸福平安。</span></span>
<span className="v" id="v3" data-v="3" data-xref="箴言 7:3; 哥林多後書 3:3; 希伯來書 10:16"> <span className="pl pl-1">不要讓慈愛和信實離開你，</span><br /><span className="pl pl-2">要把它們繫在你的頸項上，</span><br /><span className="pl pl-2">刻在你的心坎上。</span></span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 2:52; 撒母耳記上 2:26; 羅馬書 14:18"> <span className="pl pl-1">這樣，你必蒙上帝和世人的喜悅，</span><br /><span className="pl pl-2">享有美譽。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="詩篇 37:5; 耶利米書 17:7–8; 箴言 28:26"> <span className="pl pl-1">你要全心信靠耶和華，</span><br /><span className="pl pl-2">不可倚靠自己的悟性。</span></span>
<span className="v" id="v6" data-v="6" data-xref="箴言 16:3; 詩篇 32:8; 腓立比書 4:6"> <span className="pl pl-1">凡事都要信從祂，</span><br /><span className="pl pl-2">祂必指引你走正路。</span></span>
<span className="v" id="v7" data-v="7" data-xref="約伯記 28:28; 羅馬書 12:16; 箴言 26:12"> <span className="pl pl-1">不要自以為有智慧，</span><br /><span className="pl pl-2">要敬畏耶和華，遠離惡事。</span></span>
<span className="v" id="v8" data-v="8" data-xref="箴言 4:22; 詩篇 147:3; 箴言 16:24"> <span className="pl pl-1">這樣可醫治你的身體，</span><br /><span className="pl pl-2">滋潤你的筋骨。</span></span>
<span className="v" id="v9" data-v="9" data-xref="申命記 26:2–15; 哥林多前書 16:2; 出埃及記 23:19"> <span className="pl pl-1">你要用自己的財富和一切初熟的物產來尊崇耶和華，</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="箴言 19:17; 申命記 28:8; 箴言 22:9"> <span className="pl pl-1">祂必使你五穀滿倉，</span><br /><span className="pl pl-2">榨酒池溢出新釀。</span></span>
<span className="v" id="v11" data-v="11" data-xref="約伯記 5:17; 啟示錄 3:19; 希伯來書 12:5–12"> <span className="pl pl-1">孩子啊，不可輕視耶和華的管教，</span><br /><span className="pl pl-2">也不可厭煩祂的責備。</span></span>
<span className="v" id="v12" data-v="12" data-xref="申命記 8:5; 啟示錄 3:19; 箴言 29:17"> <span className="pl pl-1">因為耶和華管教祂所愛的人，</span><br /><span className="pl pl-2">就像父親管教他所疼愛的孩子。</span></span>
<span className="v" id="v13" data-v="13" data-xref="箴言 8:32–35; 箴言 4:5–9; 傳道書 9:15–18"> <span className="pl pl-1">找到智慧、得到悟性的人有福了，</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="箴言 16:16; 箴言 8:19; 約伯記 28:13–19"> <span className="pl pl-1">因為智慧比銀子更有價值，</span><br /><span className="pl pl-2">比金子更有益處，</span></span>
<span className="v" id="v15" data-v="15" data-xref="箴言 8:11; 約伯記 28:18; 詩篇 73:25–26"> <span className="pl pl-1">比珠寶更珍貴；</span><br /><span className="pl pl-2">你所喜愛的一切都難以相比。</span></span>
<span className="v" id="v16" data-v="16" data-xref="箴言 3:2; 哥林多後書 6:10; 箴言 22:4"> <span className="pl pl-1">智慧的右手有長壽，</span><br /><span className="pl pl-2">左手有富貴和尊榮。</span></span>
<span className="v" id="v17" data-v="17" data-xref="路加福音 1:79; 以賽亞書 26:3; 腓立比書 4:8–9"> <span className="pl pl-1">她的路上有福樂，</span><br /><span className="pl pl-2">她的道上有平安。</span></span>
<span className="v" id="v18" data-v="18" data-xref="箴言 11:30; 啟示錄 2:7; 箴言 15:4"> <span className="pl pl-1">對持守智慧的人來說，</span><br /><span className="pl pl-2">智慧是生命樹，</span><br /><span className="pl pl-2">緊握智慧的人必蒙福。</span></span>
<span className="v" id="v19" data-v="19" data-xref="詩篇 104:24; 耶利米書 10:12; 約翰福音 1:3"> <span className="pl pl-1">耶和華以智慧奠立大地，</span><br /><span className="pl pl-2">以悟性鋪設諸天；</span></span>
<span className="v" id="v20" data-v="20" data-xref="創世記 7:11; 詩篇 65:9–12; 約伯記 36:27–28"> <span className="pl pl-1">祂用知識使深淵裂開，</span><br /><span className="pl pl-2">使天上降下甘露。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v21" data-v="21" data-xref="約書亞記 1:8; 申命記 6:6–9; 申命記 32:46–47"> <span className="pl pl-1">孩子啊，你要守護智慧和明辨力，</span><br /><span className="pl pl-2">別讓她們離開你的視線。</span></span>
<span className="v" id="v22" data-v="22" data-xref="箴言 4:22; 箴言 1:9; 以賽亞書 38:16"> <span className="pl pl-1">她們必給你帶來生命，</span><br /><span className="pl pl-2">作你頸項上華美的裝飾。</span></span>
<span className="v" id="v23" data-v="23" data-xref="箴言 4:12; 箴言 10:9; 詩篇 121:3"> <span className="pl pl-1">如此，你必步履穩健，不致失足；</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="詩篇 3:5; 詩篇 4:8; 箴言 6:22"> <span className="pl pl-1">你必安然躺臥，睡得香甜。</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="以賽亞書 41:10–14; 詩篇 112:7; 彼得前書 3:14"> <span className="pl pl-1">不要怕突來的災禍，</span><br /><span className="pl pl-2">不要怕惡人遭毀滅，</span></span>
<span className="v" id="v26" data-v="26" data-xref="詩篇 91:3; 撒母耳記上 2:9; 箴言 14:26"> <span className="pl pl-1">因為耶和華是你的靠山，</span><br /><span className="pl pl-2">祂使你的腳不陷入網羅。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v27" data-v="27" data-xref="加拉太書 6:10; 雅各書 2:15–16; 羅馬書 13:7"> <span className="pl pl-1">倘若有力量行善，</span><br /><span className="pl pl-2">就當幫助有需要的人，不要推託。</span></span>
<span className="v" id="v28" data-v="28" data-xref="利未記 19:13; 申命記 24:12–15; 哥林多後書 8:11"> <span className="pl pl-1">倘若可以幫忙，</span><br /><span className="pl pl-2">就不可對有求於你的鄰人說：</span><br /><span className="pl pl-2">「回去吧，明天再來，我必給你！」</span></span>
<span className="v" id="v29" data-v="29" data-xref="箴言 6:14; 箴言 16:29–30; 詩篇 55:20"> <span className="pl pl-1">鄰舍在你附近安分居住，</span><br /><span className="pl pl-2">不可謀害他。</span></span>
<span className="v" id="v30" data-v="30" data-xref="提摩太後書 2:24; 箴言 29:22; 羅馬書 12:18–21"> <span className="pl pl-1">別人若沒有害你，</span><br /><span className="pl pl-2">不要無故與他相爭。</span></span>
<span className="v" id="v31" data-v="31" data-xref="箴言 24:1; 詩篇 37:1; 加拉太書 5:21"> <span className="pl pl-1">不要羡慕殘暴之徒，</span><br /><span className="pl pl-2">也不可步其後塵，</span></span>
<span className="v" id="v32" data-v="32" data-xref="詩篇 25:14; 約翰福音 15:15; 箴言 11:20"> <span className="pl pl-1">因為耶和華憎惡邪僻之徒，</span><br /><span className="pl pl-2">喜愛正直的人。</span></span>
<span className="v" id="v33" data-v="33" data-xref="詩篇 37:22; 利未記 26:14–46; 約伯記 8:6–7"> <span className="pl pl-1">耶和華咒詛惡人的家，</span><br /><span className="pl pl-2">賜福義人的家。</span></span>
<span className="v" id="v34" data-v="34" data-xref="雅各書 4:6; 彼得前書 5:5; 詩篇 138:6"> <span className="pl pl-1">耶和華譏笑好譏誚的人，</span><br /><span className="pl pl-2">恩待謙卑的人。</span></span>
<span className="v" id="v35" data-v="35" data-xref="詩篇 132:18; 以賽亞書 65:13–15; 詩篇 73:24"> <span className="pl pl-1">智者得尊榮，</span><br /><span className="pl pl-2">愚人受羞辱。</span></span>
</div>

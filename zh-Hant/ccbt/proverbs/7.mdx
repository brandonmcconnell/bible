## 要遠離淫婦

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="箴言 1:8; 啟示錄 1:3; 路加福音 11:28"> <span className="pl pl-1">孩子啊，你要遵從我的吩咐，</span><br /><span className="pl pl-2">把我的誡命珍藏在心中。</span></span>
<span className="v" id="v2" data-v="2" data-xref="詩篇 17:8; 箴言 4:4; 利未記 18:5"> <span className="pl pl-1">遵守我的誡命，你便存活。</span><br /><span className="pl pl-2">要愛護我的訓誨，</span><br /><span className="pl pl-2">如愛護眼中的瞳人。</span></span>
<span className="v" id="v3" data-v="3" data-xref="申命記 11:18–20; 箴言 3:3; 申命記 6:8–9"> <span className="pl pl-1">要繫在你的指頭上，</span><br /><span className="pl pl-2">刻在你的心版上。</span></span>
<span className="v" id="v4" data-v="4" data-xref="箴言 4:6–8; 箴言 2:2–4; 雅歌 8:1"> <span className="pl pl-1">你要把智慧當作姊妹，</span><br /><span className="pl pl-2">將悟性視為親人。</span></span>
<span className="v" id="v5" data-v="5" data-xref="箴言 2:16; 箴言 6:24; 箴言 5:3"> <span className="pl pl-1">她們能使你遠離淫婦，</span><br /><span className="pl pl-2">遠離妓女的甜言蜜語。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="創世記 26:8; 士師記 5:28; 撒母耳記下 6:16"> <span className="pl pl-1">我曾在家裡的窗前，</span><br /><span className="pl pl-2">透過窗櫺往外觀看，</span></span>
<span className="v" id="v7" data-v="7" data-xref="箴言 6:32; 箴言 1:22; 箴言 1:32"> <span className="pl pl-1">只見在愚昧人中，</span><br /><span className="pl pl-2">有個無知的青年，</span></span>
<span className="v" id="v8" data-v="8" data-xref="箴言 5:8; 箴言 7:12; 士師記 16:1"> <span className="pl pl-1">他穿過靠近淫婦的巷口，</span><br /><span className="pl pl-2">朝她的家門走去，</span></span>
<span className="v" id="v9" data-v="9" data-xref="約伯記 24:13–15; 羅馬書 13:12–14; 以弗所書 5:11"> <span className="pl pl-1">趁著日暮黃昏，</span><br /><span className="pl pl-2">藉著夜色昏暗。</span></span>
<span className="v" id="v10" data-v="10" data-xref="提摩太前書 2:9; 以賽亞書 3:16–24; 哥林多後書 11:2–3"> <span className="pl pl-1">看啊！一個妓女打扮、</span><br /><span className="pl pl-2">心術不正的女子出來迎接他。</span></span>
<span className="v" id="v11" data-v="11" data-xref="箴言 9:13; 提多書 2:5; 箴言 31:10–31"> <span className="pl pl-1">她喧嚷放蕩，不安分守家，</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="箴言 23:28; 箴言 9:14; 啟示錄 18:3"> <span className="pl pl-1">有時在街上，有時在廣場，</span><br /><span className="pl pl-2">或在各巷口守候。</span></span>
<span className="v" id="v13" data-v="13" data-xref="創世記 39:12; 民數記 25:6–8; 創世記 39:7"> <span className="pl pl-1">她纏著那青年，與他親吻，</span><br /><span className="pl pl-2">厚顏無恥地說：</span></span>
<span className="v" id="v14" data-v="14" data-xref="箴言 21:27; 利未記 7:11; 箴言 17:1"> <span className="pl pl-1">「我今天剛獻祭還了願，</span><br /><span className="pl pl-2">家裡有平安祭肉</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="按猶太律法規定，還願之後所得的祭肉要在第二天吃完。參考利未記7·16。">a</a></sup><br /><span className="pl pl-2">，</span></span>
<span className="v" id="v15" data-v="15"> <span className="pl pl-1">因此我出來迎接你，尋找你，</span><br /><span className="pl pl-2">終於找到了你！</span></span>
<span className="v" id="v16" data-v="16" data-xref="以賽亞書 19:9; 以西結書 27:7; 列王紀上 10:28"> <span className="pl pl-1">我已經鋪好了床，</span><br /><span className="pl pl-2">鋪上了埃及的繡花布，</span></span>
<span className="v" id="v17" data-v="17" data-xref="詩篇 45:8; 以賽亞書 57:7–9; 雅歌 4:13–14"> <span className="pl pl-1">又用沒藥、沉香、肉桂薰了床。</span><br /></span>
<span className="v" id="v18" data-v="18"> <span className="pl pl-1">來吧，讓我們通宵暢飲愛情，</span><br /><span className="pl pl-2">讓我們盡情歡愛！</span></span>
<span className="v" id="v19" data-v="19" data-xref="馬太福音 20:11; 路加福音 12:45–46; 路加福音 12:39"> <span className="pl pl-1">因為我丈夫不在家，出遠門了。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="歷代志下 2:4"> <span className="pl pl-1">他帶著錢囊去了，月圓才回來。」</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="箴言 5:3; 箴言 7:5; 列王紀下 4:8"> <span className="pl pl-1">淫婦花言巧語勾引他，</span><br /><span className="pl pl-2">用諂媚的話語誘惑他。</span></span>
<span className="v" id="v22" data-v="22" data-xref="約伯記 13:27; 使徒行傳 16:24; 使徒行傳 14:13"> <span className="pl pl-1">那青年立刻隨她而去，</span><br /><span className="pl pl-2">像走向屠宰場的公牛，</span><br /><span className="pl pl-2">又像掉入陷阱的雄鹿，</span></span>
<span className="v" id="v23" data-v="23" data-xref="傳道書 9:12; 箴言 9:18; 箴言 1:17"> <span className="pl pl-1">直等到利箭射穿他的肝。</span><br /><span className="pl pl-2">他像隻自投網羅的飛鳥，</span><br /><span className="pl pl-2">渾然不知要賠上性命！</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v24" data-v="24" data-xref="箴言 5:7; 箴言 4:1; 約翰一書 2:1"> <span className="pl pl-1">孩子們啊，你們要聽從我的話，</span><br /><span className="pl pl-2">留意我口中的訓言，</span></span>
<span className="v" id="v25" data-v="25" data-xref="箴言 5:8; 以賽亞書 53:6; 箴言 6:25"> <span className="pl pl-1">別讓你的心偏向淫婦的道，</span><br /><span className="pl pl-2">步入她的歧途。</span></span>
<span className="v" id="v26" data-v="26" data-xref="彼得前書 2:11; 尼希米記 13:26; 列王紀上 11:1–2"> <span className="pl pl-1">因為她使許多人喪命，</span><br /><span className="pl pl-2">被她殺害的數目眾多。</span></span>
<span className="v" id="v27" data-v="27" data-xref="箴言 5:5; 箴言 9:18; 箴言 2:18–19"> <span className="pl pl-1">她的家是通往陰間的路，</span><br /><span className="pl pl-2">引人墜入死亡之室。</span></span>

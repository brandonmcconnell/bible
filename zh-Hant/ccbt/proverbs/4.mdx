## 父親的教誨

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="希伯來書 2:1; 詩篇 34:11; 箴言 1:8"> <span className="pl pl-1">孩子們啊，</span><br /><span className="pl pl-2">你們要聽從父親的教誨，</span><br /><span className="pl pl-2">留心學習，以便領悟，</span></span>

<span className="v" id="v3" data-v="3" data-xref="歷代志上 22:5; 歷代志上 29:1; 羅馬書 12:16"> <span className="pl pl-1">我年幼時在父親身邊，</span><br /><span className="pl pl-2">是母親唯一的寵兒。</span></span>

<span className="v" id="v6" data-v="6" data-xref="帖撒羅尼迦後書 2:10; 箴言 4:21–22; 以弗所書 3:17"> <span className="pl pl-1">不可離棄智慧，智慧必護佑你；</span><br /><span className="pl pl-2">你要熱愛智慧，智慧必看顧你。</span></span>
<span className="v" id="v7" data-v="7" data-xref="傳道書 7:12; 傳道書 9:16–18; 箴言 23:23"> <span className="pl pl-1">智慧至上，要求取智慧，</span><br /><span className="pl pl-2">要不惜一切獲取悟性。</span></span>

<span className="v" id="v9" data-v="9" data-xref="箴言 1:9; 彼得前書 5:4; 希伯來書 2:7–9"> <span className="pl pl-1">她必為你戴上華冠，</span><br /><span className="pl pl-2">加上榮冕。」</span></span>
</div>
<div className="bp poetry">

<span className="v" id="v11" data-v="11" data-xref="詩篇 25:4–5; 傳道書 12:9; 箴言 8:9"> <span className="pl pl-1">我已經指示你走智慧之道，</span><br /><span className="pl pl-2">引導你行正確的路。</span></span>
<span className="v" id="v12" data-v="12" data-xref="箴言 3:23; 詩篇 18:36; 彼得前書 2:8"> <span className="pl pl-1">你行走，腳下不受阻礙；</span><br /><span className="pl pl-2">你奔跑，也不會跌倒。</span></span>
<span className="v" id="v13" data-v="13" data-xref="希伯來書 2:1; 箴言 3:18; 箴言 23:23"> <span className="pl pl-1">你要持守教誨，不要鬆懈；</span><br /><span className="pl pl-2">要守護好，因為那是你的生命。</span></span>
<span className="v" id="v14" data-v="14" data-xref="詩篇 1:1; 哥林多前書 15:33; 箴言 1:10"> <span className="pl pl-1">不要涉足惡人的道，</span><br /><span className="pl pl-2">不要行走壞人的路；</span></span>
<span className="v" id="v15" data-v="15" data-xref="以弗所書 5:11; 約伯記 22:23; 帖撒羅尼迦前書 5:22"> <span className="pl pl-1">要避開，不可踏足，</span><br /><span className="pl pl-2">要繞道前行。</span></span>
<span className="v" id="v16" data-v="16" data-xref="詩篇 36:4; 彌迦書 2:1; 以賽亞書 57:20"> <span className="pl pl-1">因為他們不作惡就無法入睡，</span><br /><span className="pl pl-2">不絆倒人就無法安眠；</span></span>
<span className="v" id="v17" data-v="17" data-xref="雅各書 5:4–5; 詩篇 14:4; 彌迦書 6:12"> <span className="pl pl-1">他們吃的是邪惡餅，</span><br /><span className="pl pl-2">喝的是殘暴酒。</span></span>
<span className="v" id="v18" data-v="18" data-xref="約翰福音 8:12; 約伯記 11:17; 但以理書 12:3"> <span className="pl pl-1">義人的道路好像黎明的曙光，</span><br /><span className="pl pl-2">越照越亮，直到正午。</span></span>

</div>
<div className="bp poetry">

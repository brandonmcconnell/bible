<span className="v" id="v6" data-v="6" data-xref="詩篇 141:4; 箴言 23:3; 但以理書 1:8–10"> <span className="pl pl-1">不要吃吝嗇人的飯，</span><br /><span className="pl pl-2">不可貪圖他的美味。</span></span>

</div>
<div className="bp poetry">

<span className="v" id="v10" data-v="10" data-xref="箴言 22:28; 撒迦利亞書 7:10; 申命記 27:17"> <span className="pl pl-1">不可挪移古時的界石，</span><br /><span className="pl pl-2">不可侵佔孤兒的田地。</span></span>
<span className="v" id="v11" data-v="11" data-xref="箴言 22:23; 約伯記 19:25; 耶利米書 51:36"> <span className="pl pl-1">因他們的救贖主強大，</span><br /><span className="pl pl-2">祂必對付你，替他們伸冤。</span></span>
<span className="v" id="v12" data-v="12" data-xref="箴言 5:1–2; 箴言 2:2–6; 箴言 23:19"> <span className="pl pl-1">你要專心接受教誨，</span><br /><span className="pl pl-2">側耳傾聽博學之言。</span></span>
<span className="v" id="v13" data-v="13" data-xref="箴言 13:24; 箴言 19:18; 箴言 29:15"> <span className="pl pl-1">不要疏於管教孩子，</span><br /><span className="pl pl-2">杖責不會使他斃命，</span></span>

<span className="v" id="v15" data-v="15" data-xref="箴言 23:24–25; 約翰二書 1:4; 箴言 29:3"> <span className="pl pl-1">孩子啊，</span><br /><span className="pl pl-2">你若心裡有智慧，</span><br /><span className="pl pl-2">我心裡也會歡喜。</span></span>
<span className="v" id="v16" data-v="16" data-xref="箴言 8:6; 以弗所書 5:4; 雅各書 3:2"> <span className="pl pl-1">你的口若說正直的話，</span><br /><span className="pl pl-2">我的內心也歡暢不已。</span></span>
<span className="v" id="v17" data-v="17" data-xref="箴言 28:14; 哥林多後書 7:1; 彼得前書 1:17"> <span className="pl pl-1">不要心裡羡慕罪人，</span><br /><span className="pl pl-2">要終日敬畏耶和華。</span></span>
<span className="v" id="v18" data-v="18" data-xref="希伯來書 10:35; 耶利米書 29:11; 詩篇 9:18"> <span className="pl pl-1">這樣，你必前途光明，</span><br /><span className="pl pl-2">你的盼望不會幻滅。</span></span>
<span className="v" id="v19" data-v="19" data-xref="箴言 23:26; 箴言 23:12; 箴言 4:10–23"> <span className="pl pl-1">孩子啊，聽我的話，</span><br /><span className="pl pl-2">要有智慧，心守正道。</span></span>
<span className="v" id="v20" data-v="20" data-xref="路加福音 21:34; 以弗所書 5:18; 以賽亞書 5:22"> <span className="pl pl-1">不要結交酒肉朋友，</span><br /></span>

<span className="v" id="v25" data-v="25" data-xref="箴言 17:25; 路加福音 11:27–28; 路加福音 1:58"> <span className="pl pl-1">願你使父母快樂，</span><br /><span className="pl pl-2">叫生你的人歡欣。</span></span>
<span className="v" id="v26" data-v="26" data-xref="詩篇 119:2; 詩篇 119:9–11; 申命記 6:5"> <span className="pl pl-1">孩子啊，把你的心交給我，</span><br /><span className="pl pl-2">雙目要緊盯我的道路。</span></span>
<span className="v" id="v27" data-v="27" data-xref="箴言 22:14"> <span className="pl pl-1">妓女是深坑，淫婦是陷阱；</span><br /></span>
<span className="v" id="v28" data-v="28" data-xref="傳道書 7:26; 箴言 7:12; 箴言 22:14"> <span className="pl pl-1">她像強盜般埋伏，</span><br /><span className="pl pl-2">使世間增添奸徒。</span></span>

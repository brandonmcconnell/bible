## 所羅門的箴言

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="箴言 1:1; 箴言 29:15; 箴言 17:25"> 以下是所羅門的箴言：<br /><span className="pl pl-2">智慧兒使父親快樂，</span><br /><span className="pl pl-2">愚昧兒叫母親憂傷。</span></span>
<span className="v" id="v2" data-v="2" data-xref="箴言 11:4; 箴言 12:28; 詩篇 49:6–10"> <span className="pl pl-1">不義之財毫無益處，</span><br /><span className="pl pl-2">公義救人脫離死亡。</span></span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 37:3; 馬太福音 6:30–33; 詩篇 37:25"> <span className="pl pl-1">耶和華不讓義人挨餓，</span><br /><span className="pl pl-2">祂使惡人的奢望成空。</span></span>
<span className="v" id="v4" data-v="4" data-xref="箴言 21:5; 箴言 20:4; 箴言 19:15"> <span className="pl pl-1">遊手好閒招致貧窮，</span><br /><span className="pl pl-2">勤奮努力帶來富足。</span></span>
<span className="v" id="v5" data-v="5" data-xref="箴言 6:8; 箴言 30:25; 箴言 17:2"> <span className="pl pl-1">精明兒夏季時貯藏，</span><br /><span className="pl pl-2">不肖子收成時酣睡。</span></span>
<span className="v" id="v6" data-v="6" data-xref="申命記 28:2; 箴言 28:20; 約伯記 29:13"> <span className="pl pl-1">祝福臨到義人的頭，</span><br /><span className="pl pl-2">殘暴充滿惡人的口。</span></span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 112:6; 路加福音 1:48; 馬可福音 14:9"> <span className="pl pl-1">義人流芳於世，</span><br /><span className="pl pl-2">惡人名聲敗壞。</span></span>
<span className="v" id="v8" data-v="8" data-xref="馬太福音 7:24–25; 箴言 12:1; 雅各書 3:13"> <span className="pl pl-1">心存智慧的接受誡命；</span><br /><span className="pl pl-2">說話愚昧的自招滅亡。</span></span>
<span className="v" id="v9" data-v="9" data-xref="箴言 28:18; 馬太福音 10:26; 詩篇 26:11–12"> <span className="pl pl-1">行正道者活得安穩，</span><br /><span className="pl pl-2">走歪路者終必敗露。</span></span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 35:19; 箴言 6:13; 約翰三書 1:10"> <span className="pl pl-1">擠眉弄眼，帶來憂傷；</span><br /><span className="pl pl-2">胡言亂語，導致滅亡。</span></span>
<span className="v" id="v11" data-v="11" data-xref="箴言 13:14; 以弗所書 4:29; 箴言 10:6"> <span className="pl pl-1">義人的口是生命之泉，</span><br /><span className="pl pl-2">惡人的口卻充滿殘暴。</span></span>
<span className="v" id="v12" data-v="12" data-xref="彼得前書 4:8; 哥林多前書 13:4–7; 箴言 17:9"> <span className="pl pl-1">恨能挑起紛爭，</span><br /><span className="pl pl-2">愛能遮掩一切過犯。</span></span>
<span className="v" id="v13" data-v="13" data-xref="箴言 26:3; 箴言 6:32; 以賽亞書 50:4"> <span className="pl pl-1">明哲口中有智慧，</span><br /><span className="pl pl-2">無知者背上受鞭打。</span></span>
<span className="v" id="v14" data-v="14" data-xref="箴言 18:7; 箴言 10:8; 箴言 13:3"> <span className="pl pl-1">智者儲藏知識，</span><br /><span className="pl pl-2">愚人口惹禍端。</span></span>
<span className="v" id="v15" data-v="15" data-xref="箴言 18:11; 箴言 19:7; 詩篇 52:7"> <span className="pl pl-1">錢財是富人的堅城，</span><br /><span className="pl pl-2">貧乏帶給窮人毀滅。</span></span>
<span className="v" id="v16" data-v="16" data-xref="羅馬書 6:23; 以賽亞書 3:10–11; 希伯來書 6:10"> <span className="pl pl-1">義人的報酬是生命，</span><br /><span className="pl pl-2">惡人的果子是懲罰。</span></span>
<span className="v" id="v17" data-v="17" data-xref="彼得後書 1:5–11; 路加福音 11:28; 箴言 6:23"> <span className="pl pl-1">聽從教誨的，走生命之路；</span><br /><span className="pl pl-2">拒絕責備的，必步入歧途。</span></span>
<span className="v" id="v18" data-v="18" data-xref="箴言 26:24–26; 詩篇 55:21; 撒母耳記下 3:27"> <span className="pl pl-1">暗藏仇恨的滿口虛謊，</span><br /><span className="pl pl-2">散佈流言的愚不可及。</span></span>
<span className="v" id="v19" data-v="19" data-xref="雅各書 1:19; 雅各書 3:2; 箴言 17:27–28"> <span className="pl pl-1">言多必失，智者慎言。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="耶利米書 17:9; 箴言 12:18; 創世記 6:5"> <span className="pl pl-1">義人之舌似純銀，</span><br /><span className="pl pl-2">惡人之心無價值。</span></span>
<span className="v" id="v21" data-v="21" data-xref="何西阿書 4:6; 箴言 17:16; 箴言 1:29"> <span className="pl pl-1">義人的口滋養眾人，</span><br /><span className="pl pl-2">愚人因無知而死亡。</span></span>
<span className="v" id="v22" data-v="22" data-xref="詩篇 107:38; 創世記 26:12; 撒母耳記上 2:7–8"> <span className="pl pl-1">耶和華的祝福使人富足，</span><br /><span className="pl pl-2">祝福中不加任何憂愁</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「祝福中不加任何憂愁」或譯「勞苦無法使其加增」。">a</a></sup><br /><span className="pl pl-2">。</span></span>
<span className="v" id="v23" data-v="23" data-xref="箴言 15:21; 箴言 2:14; 箴言 14:9"> <span className="pl pl-1">愚人以惡為樂，</span><br /><span className="pl pl-2">哲士喜愛智慧。</span></span>
<span className="v" id="v24" data-v="24" data-xref="詩篇 145:19; 以賽亞書 66:4; 馬太福音 5:6"> <span className="pl pl-1">惡人所怕的必臨到他，</span><br /><span className="pl pl-2">義人的心願必得實現。</span></span>
<span className="v" id="v25" data-v="25" data-xref="詩篇 15:5; 詩篇 58:9; 馬太福音 7:24–27"> <span className="pl pl-1">暴風掃過，</span><br /><span className="pl pl-2">惡人消逝無蹤，</span><br /><span className="pl pl-2">義人永不動搖。</span></span>
<span className="v" id="v26" data-v="26" data-xref="箴言 25:13; 箴言 26:6; 馬太福音 25:26"> <span className="pl pl-1">懶漢讓差他的人難受，</span><br /><span className="pl pl-2">如醋倒牙，如煙薰目。</span></span>
<span className="v" id="v27" data-v="27" data-xref="箴言 9:11; 箴言 3:2; 詩篇 91:16"> <span className="pl pl-1">敬畏耶和華的享長壽，</span><br /><span className="pl pl-2">惡人的壽數必被縮短。</span></span>
<span className="v" id="v28" data-v="28" data-xref="約伯記 8:13; 羅馬書 15:13; 詩篇 73:24–26"> <span className="pl pl-1">義人的憧憬帶來歡樂，</span><br /><span className="pl pl-2">惡人的希望終必破滅。</span></span>
<span className="v" id="v29" data-v="29" data-xref="箴言 21:15; 羅馬書 2:8–9; 腓立比書 4:13"> <span className="pl pl-1">耶和華的道保護正直人，</span><br /><span className="pl pl-2">毀滅作惡之人。</span></span>
<span className="v" id="v30" data-v="30" data-xref="詩篇 37:22; 詩篇 125:1; 詩篇 37:9–10"> <span className="pl pl-1">義人永不動搖，</span><br /><span className="pl pl-2">惡人無處容身。</span></span>
<span className="v" id="v31" data-v="31" data-xref="詩篇 37:30; 箴言 10:13; 箴言 10:20–21"> <span className="pl pl-1">義人的口發出智慧，</span><br /><span className="pl pl-2">詭詐的舌必被割掉。</span></span>
<span className="v" id="v32" data-v="32" data-xref="箴言 15:28; 箴言 12:6; 箴言 11:11"> <span className="pl pl-1">義人說話得體合宜，</span><br /><span className="pl pl-2">惡人口出乖謬之言。</span></span>

<span className="v" id="v3" data-v="3" data-xref="箴言 27:11; 箴言 10:1; 箴言 15:20"> <span className="pl pl-1">愛慕智慧的使父親歡欣，</span><br /><span className="pl pl-2">結交妓女的必耗盡錢財。</span></span>
<span className="v" id="v4" data-v="4" data-xref="箴言 29:14; 箴言 20:8; 但以理書 11:20"> <span className="pl pl-1">君王秉公行義，國家安定；</span><br /><span className="pl pl-2">他若收受賄賂，國必傾倒。</span></span>
<span className="v" id="v5" data-v="5" data-xref="何西阿書 5:1; 約伯記 17:5; 詩篇 5:9"> <span className="pl pl-1">奉承鄰舍，等於設網羅絆他。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="傳道書 9:12; 出埃及記 15:1; 提摩太後書 2:26"> <span className="pl pl-1">惡人被自己的罪纏住，</span><br /><span className="pl pl-2">義人卻常常歡喜歌唱。</span></span>
<span className="v" id="v7" data-v="7" data-xref="約伯記 29:16; 詩篇 41:1; 箴言 21:13"> <span className="pl pl-1">義人關心窮人的冤屈，</span><br /><span className="pl pl-2">惡人對此漠不關心。</span></span>
<span className="v" id="v8" data-v="8" data-xref="箴言 11:11; 耶利米書 15:1; 雅各書 5:15–18"> <span className="pl pl-1">狂徒煽動全城，</span><br /><span className="pl pl-2">智者平息眾怒。</span></span>
<span className="v" id="v9" data-v="9" data-xref="箴言 26:4; 傳道書 10:13; 馬太福音 7:6"> <span className="pl pl-1">智者跟愚人對簿公堂，</span><br /><span className="pl pl-2">愚人會怒罵嬉笑不止。</span></span>
<span className="v" id="v10" data-v="10" data-xref="約翰福音 15:18–19; 約翰一書 3:12–13; 創世記 4:5–8"> <span className="pl pl-1">嗜殺之徒憎惡純全無過的人，</span><br /><span className="pl pl-2">但正直的人保護他們</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「但正直的人保護他們」或譯「索取正直人的性命」。">a</a></sup><br /><span className="pl pl-2">。</span></span>
<span className="v" id="v11" data-v="11" data-xref="箴言 19:11; 箴言 12:16; 彌迦書 7:5"> <span className="pl pl-1">愚人盡情發洩怒氣，</span><br /><span className="pl pl-2">智者默然克制怒氣。</span></span>
<span className="v" id="v12" data-v="12" data-xref="箴言 20:8; 列王紀下 10:6–7; 詩篇 52:2–4"> <span className="pl pl-1">君王若聽讒言，</span><br /><span className="pl pl-2">臣僕必成奸徒。</span></span>
<span className="v" id="v13" data-v="13" data-xref="馬太福音 5:45; 箴言 22:2; 詩篇 13:3"> <span className="pl pl-1">貧窮人和欺壓者有共同點：</span><br /><span className="pl pl-2">他們的眼睛都是耶和華所賜。</span></span>
<span className="v" id="v14" data-v="14" data-xref="箴言 16:12; 以賽亞書 11:4; 詩篇 72:2–4"> <span className="pl pl-1">君王若秉公審判窮人，</span><br /><span className="pl pl-2">他的王位必永遠堅立。</span></span>
<span className="v" id="v15" data-v="15" data-xref="箴言 10:1; 箴言 17:25; 箴言 29:17"> <span className="pl pl-1">管教之杖使孩子得智慧，</span><br /><span className="pl pl-2">放縱的子女讓母親蒙羞。</span></span>
<span className="v" id="v16" data-v="16" data-xref="詩篇 37:36; 詩篇 91:8; 詩篇 58:10"> <span className="pl pl-1">惡人當道，罪惡氾濫；</span><br /><span className="pl pl-2">義人必得見他們敗亡。</span></span>
<span className="v" id="v17" data-v="17" data-xref="箴言 10:1; 箴言 29:15; 箴言 23:13–14"> <span className="pl pl-1">好好管教兒子，</span><br /><span className="pl pl-2">他會帶給你平安，使你心裡喜樂。</span></span>
<span className="v" id="v18" data-v="18" data-xref="雅各書 1:25; 路加福音 11:28; 約翰福音 13:17"> <span className="pl pl-1">百姓無神諭便任意妄為，</span><br /><span className="pl pl-2">但遵守律法的人必蒙福。</span></span>

<span className="v" id="v20" data-v="20" data-xref="雅各書 1:19; 箴言 26:12; 箴言 14:29"> <span className="pl pl-1">言語急躁的人，</span><br /><span className="pl pl-2">還不如愚人有希望。</span></span>
<span className="v" id="v21" data-v="21"> <span className="pl pl-1">從小嬌縱的僕人，</span><br /><span className="pl pl-2">最終必反仆為主。</span></span>
<span className="v" id="v22" data-v="22" data-xref="箴言 15:18; 箴言 17:19; 箴言 26:21"> <span className="pl pl-1">憤怒的人挑起紛爭，</span><br /><span className="pl pl-2">暴躁的人多有過犯。</span></span>

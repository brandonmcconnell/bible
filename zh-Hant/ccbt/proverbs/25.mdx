## 所羅門的箴言（續）

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="箴言 1:1; 列王紀上 4:32; 彌迦書 1:1"> 以下也是所羅門的箴言，由猶大王希西迦的人抄錄。</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 29:29; 羅馬書 11:33–34; 約伯記 11:7–8"> <span className="pl pl-1">將事隱藏是上帝的榮耀，</span><br /><span className="pl pl-2">把事查明是君王的光榮。</span></span>
<span className="v" id="v3" data-v="3" data-xref="以賽亞書 55:9; 詩篇 103:11; 列王紀上 4:29"> <span className="pl pl-1">天之高，地之厚，</span><br /><span className="pl pl-2">君王的心測不透。</span></span>
<span className="v" id="v4" data-v="4" data-xref="提摩太後書 2:20–21; 以西結書 22:18; 箴言 17:3"> <span className="pl pl-1">除掉銀子裡的渣滓，</span><br /><span className="pl pl-2">銀匠就能鑄造器皿。</span></span>
<span className="v" id="v5" data-v="5" data-xref="箴言 16:12; 箴言 20:8; 詩篇 101:7–8"> <span className="pl pl-1">清除君王身邊的惡人，</span><br /><span className="pl pl-2">王位必因公義而鞏固。</span></span>
<span className="v" id="v6" data-v="6" data-xref="箴言 27:2; 箴言 25:27; 箴言 16:19"> <span className="pl pl-1">不可在王面前妄自尊大，</span><br /><span className="pl pl-2">不要佔據大人物的位子。</span></span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 14:7–11; 路加福音 18:14; 彼得前書 5:5"> <span className="pl pl-1">與其在權貴面前被貶低，</span><br /><span className="pl pl-2">不如等人邀請你坐上座。</span></span>
<span className="v" id="v8" data-v="8" data-xref="馬太福音 5:25; 箴言 17:14; 箴言 18:6"> <span className="pl pl-1">不可貿然打官司，</span><br /><span className="pl pl-2">以免被鄰舍羞辱，</span><br /><span className="pl pl-2">無所適從。</span></span>
<span className="v" id="v9" data-v="9" data-xref="馬太福音 18:5–17; 箴言 11:13; 箴言 20:19"> <span className="pl pl-1">遇到跟鄰舍對簿公堂，</span><br /><span className="pl pl-2">不可洩露他人的秘密，</span></span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 119:39"> <span className="pl pl-1">免得聽見的人辱罵你，</span><br /><span className="pl pl-2">你的惡名將永難洗刷。</span></span>
<span className="v" id="v11" data-v="11" data-xref="箴言 15:23; 以賽亞書 50:4; 傳道書 12:10"> <span className="pl pl-1">一句話說得合宜，</span><br /><span className="pl pl-2">就像金蘋果放在銀器裡。</span></span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 141:5; 箴言 15:31–32; 箴言 15:5"> <span className="pl pl-1">對受教者而言，</span><br /><span className="pl pl-2">智者的責備猶如金耳環和金飾物。</span></span>
<span className="v" id="v13" data-v="13" data-xref="箴言 13:17; 箴言 25:25; 腓立比書 2:25–30"> <span className="pl pl-1">忠信的使者叫主人心裡舒暢，</span><br /><span className="pl pl-2">就像夏收之時有冰雪的涼氣。</span></span>
<span className="v" id="v14" data-v="14" data-xref="箴言 20:6; 路加福音 14:11; 彼得後書 2:15–19"> <span className="pl pl-1">誇口送禮物卻食言的人，</span><br /><span className="pl pl-2">就像沒有雨水的風和雲。</span></span>
<span className="v" id="v15" data-v="15" data-xref="箴言 15:1; 傳道書 10:4; 箴言 16:14"> <span className="pl pl-1">堅忍的耐心說服君王，</span><br /><span className="pl pl-2">柔和的舌頭折斷骨頭。</span></span>
<span className="v" id="v16" data-v="16" data-xref="箴言 25:27; 以弗所書 5:18; 箴言 24:13–14"> <span className="pl pl-1">找到蜂蜜要酌量而食，</span><br /><span className="pl pl-2">免得吃多了嘔吐。</span></span>
<span className="v" id="v17" data-v="17" data-xref="創世記 19:2–3; 士師記 19:18–21; 羅馬書 15:24"> <span className="pl pl-1">不要頻頻去鄰舍家，</span><br /><span className="pl pl-2">免得惹人煩、遭人厭。</span></span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 57:4; 箴言 12:18; 雅各書 3:6"> <span className="pl pl-1">作偽證陷害鄰舍的人，</span><br /><span className="pl pl-2">無異於大錘、快刀和利箭。</span></span>
<span className="v" id="v19" data-v="19" data-xref="以賽亞書 36:6; 以西結書 29:6–7; 約伯記 6:14–20"> <span className="pl pl-1">危難時投靠奸詐之人，</span><br /><span className="pl pl-2">形同倚靠壞牙和跛腳。</span></span>
<span className="v" id="v20" data-v="20" data-xref="羅馬書 12:15; 傳道書 3:4; 以賽亞書 58:7"> <span className="pl pl-1">對憂傷的人唱歌，</span><br /><span className="pl pl-2">如同天寒脫衣、傷口撒鹽。</span></span>
<span className="v" id="v21" data-v="21" data-xref="羅馬書 12:20–21; 馬太福音 5:44; 出埃及記 23:4–5"> <span className="pl pl-1">你的仇敵若餓了，</span><br /><span className="pl pl-2">就給他吃的；</span><br /><span className="pl pl-2">若渴了，就給他水喝；</span></span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳記下 16:12; 馬太福音 10:13; 哥林多前書 15:18"> <span className="pl pl-1">因為你這是把炭火堆在他頭上，</span><br /><span className="pl pl-2">耶和華必獎賞你。</span></span>
<span className="v" id="v23" data-v="23" data-xref="約伯記 37:22; 詩篇 15:3; 羅馬書 1:30"> <span className="pl pl-1">北風帶來雨水，</span><br /><span className="pl pl-2">讒言激起憤怒。</span></span>
<span className="v" id="v24" data-v="24" data-xref="箴言 21:19; 箴言 21:9; 箴言 27:15–16"> <span className="pl pl-1">寧願住在屋頂的一角，</span><br /><span className="pl pl-2">也不跟爭鬧之妻同屋。</span></span>
<span className="v" id="v25" data-v="25" data-xref="箴言 15:30; 羅馬書 10:15; 詩篇 63:1"> <span className="pl pl-1">有好消息從遠方傳來，</span><br /><span className="pl pl-2">如涼水滋潤乾渴的人。</span></span>
<span className="v" id="v26" data-v="26" data-xref="以西結書 34:18–19; 撒母耳記上 22:14–18; 帖撒羅尼迦前書 2:15"> <span className="pl pl-1">義人向惡人低頭，</span><br /><span className="pl pl-2">就像清泉被攪渾，</span><br /><span className="pl pl-2">水井受污染。</span></span>
<span className="v" id="v27" data-v="27" data-xref="約翰福音 5:44; 箴言 27:2; 腓立比書 2:3"> <span className="pl pl-1">蜂蜜吃得太多有害無益，</span><br /><span className="pl pl-2">追求自己的榮耀也不光彩。</span></span>
<span className="v" id="v28" data-v="28" data-xref="箴言 16:32; 箴言 22:24; 歷代志下 32:5"> <span className="pl pl-1">無法自制的人就像牆垣被毀之城。</span></span>

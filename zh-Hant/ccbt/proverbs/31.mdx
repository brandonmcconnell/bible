## 利慕伊勒王的箴言

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="箴言 6:20; 箴言 1:8; 提摩太後書 1:5"> 以下是利慕伊勒王的箴言，<br /><span className="pl pl-1">是他母親給他的教誨：</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v2" data-v="2" data-xref="以賽亞書 49:15; 撒母耳記上 1:11; 撒母耳記上 1:28"> <span className="pl pl-1">我兒，我親生的骨肉，</span><br /><span className="pl pl-2">我許願得來的孩子啊，</span><br /><span className="pl pl-2">我該怎樣教導你呢？</span></span>
<span className="v" id="v3" data-v="3" data-xref="申命記 17:17; 尼希米記 13:26; 箴言 7:26–27"> <span className="pl pl-1">不要在女人身上耗費精力，</span><br /><span className="pl pl-2">不要迷戀那些能毀滅王的人。</span></span>
<span className="v" id="v4" data-v="4" data-xref="箴言 20:1; 傳道書 10:17; 以賽亞書 5:22"> <span className="pl pl-1">利慕伊勒啊，</span><br /><span className="pl pl-2">君王不可喝酒，</span><br /><span className="pl pl-2">不可喝酒，</span><br /><span className="pl pl-2">首領不宜喝烈酒，</span></span>
<span className="v" id="v5" data-v="5" data-xref="哈巴谷書 2:5"> <span className="pl pl-1">免得喝酒後忘記律例，</span><br /><span className="pl pl-2">不為困苦人伸張正義。</span></span>
<span className="v" id="v6" data-v="6" data-xref="提摩太前書 5:23; 詩篇 104:15; 撒母耳記上 1:10"> <span className="pl pl-1">把烈酒給行將滅亡的人，</span><br /><span className="pl pl-2">把淡酒給心中憂傷的人，</span></span>
<span className="v" id="v7" data-v="7" data-xref="以弗所書 5:18"> <span className="pl pl-1">讓他們喝了忘掉自己的貧窮，</span><br /><span className="pl pl-2">不再記得自己的痛苦。</span></span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 82:3–4; 箴言 24:11–12; 以斯帖記 4:13–16"> <span className="pl pl-1">要為不能自辯者說話，</span><br /><span className="pl pl-2">為一切不幸的人伸冤。</span></span>
<span className="v" id="v9" data-v="9" data-xref="以賽亞書 1:17; 利未記 19:15; 阿摩司書 5:11–12"> <span className="pl pl-1">你要開口秉公審判，</span><br /><span className="pl pl-2">為貧窮困苦者辯護。</span></span>
</div>
</div>

## 賢德的妻子

<div className="bt">
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="箴言 19:14; 箴言 12:4; 箴言 18:22"> <sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="10-30節是字母詩，每一節依次由一個希伯來字母開頭。">a</a></sup><span className="pl pl-1">誰能找到賢德之妻？</span><br /><span className="pl pl-2">她的價值遠勝過珠寶。</span></span>
<span className="v" id="v11" data-v="11" data-xref="彼得前書 3:1–7; 列王紀下 4:22–23; 列王紀下 4:9–10"> <span className="pl pl-1">她丈夫信賴她，</span><br /><span className="pl pl-2">什麼也不缺乏。</span></span>
<span className="v" id="v12" data-v="12" data-xref="撒母耳記上 25:18–22; 撒母耳記上 25:26–27"> <span className="pl pl-1">她一生對丈夫有益無損。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="提多書 2:5; 提摩太前書 5:10; 帖撒羅尼迦後書 3:10–12"> <span className="pl pl-1">她尋找羊毛和細麻，</span><br /><span className="pl pl-2">愉快地親手做衣。</span></span>
<span className="v" id="v14" data-v="14" data-xref="箴言 31:24; 列王紀上 9:26–28; 以西結書 27:3–36"> <span className="pl pl-1">她好像商船，</span><br /><span className="pl pl-2">從遠方運來糧食。</span></span>
<span className="v" id="v15" data-v="15" data-xref="羅馬書 12:11; 馬可福音 1:35; 路加福音 12:42"> <span className="pl pl-1">天未亮她就起床，</span><br /><span className="pl pl-2">為全家預備食物，</span><br /><span className="pl pl-2">分派婢女做家事。</span></span>
<span className="v" id="v16" data-v="16" data-xref="馬太福音 13:44; 雅歌 8:12; 約書亞記 15:18"> <span className="pl pl-1">她選中田地便買下來，</span><br /><span className="pl pl-2">親手賺錢栽種葡萄園。</span></span>
<span className="v" id="v17" data-v="17" data-xref="約伯記 38:3; 彼得前書 1:13; 以弗所書 6:10"> <span className="pl pl-1">她精力充沛，</span><br /><span className="pl pl-2">雙臂有力。</span></span>
<span className="v" id="v18" data-v="18" data-xref="帖撒羅尼迦前書 2:9; 馬太福音 25:3–10; 詩篇 127:2"> <span className="pl pl-1">她深諳經營之道，</span><br /><span className="pl pl-2">她的燈徹夜不熄。</span></span>
<span className="v" id="v19" data-v="19" data-xref="出埃及記 35:25–26"> <span className="pl pl-1">她手拿捲線桿，</span><br /><span className="pl pl-2">手握紡線錘。</span></span>
<span className="v" id="v20" data-v="20" data-xref="以弗所書 4:28; 希伯來書 13:16; 箴言 22:9"> <span className="pl pl-1">她樂於賙濟窮人，</span><br /><span className="pl pl-2">伸手幫助困苦者。</span></span>
<span className="v" id="v21" data-v="21" data-xref="創世記 45:22; 撒母耳記下 1:24; 箴言 25:20"> <span className="pl pl-1">她不因下雪而為家人擔心，</span><br /><span className="pl pl-2">因為全家都穿著朱紅暖衣。</span></span>
<span className="v" id="v22" data-v="22" data-xref="啟示錄 19:8; 箴言 7:16; 創世記 41:42"> <span className="pl pl-1">她為自己縫製繡花毯，</span><br /><span className="pl pl-2">用細麻和紫布做衣服。</span></span>
<span className="v" id="v23" data-v="23" data-xref="箴言 12:4; 路得記 4:1; 申命記 16:18"> <span className="pl pl-1">她丈夫在城門口與當地長老同坐，</span><br /><span className="pl pl-2">受人尊重。</span></span>
<span className="v" id="v24" data-v="24" data-xref="以西結書 27:16; 路加福音 16:19; 箴言 31:19"> <span className="pl pl-1">她縫製細麻衣裳出售，</span><br /><span className="pl pl-2">又製作腰帶賣給商人。</span></span>
<span className="v" id="v25" data-v="25" data-xref="約伯記 40:10; 羅馬書 13:14; 約伯記 29:14"> <span className="pl pl-1">她充滿力量和尊榮，</span><br /><span className="pl pl-2">她以笑顏迎接未來。</span></span>
<span className="v" id="v26" data-v="26" data-xref="以弗所書 4:29; 箴言 16:24; 箴言 10:31"> <span className="pl pl-1">她說的話帶著智慧，</span><br /><span className="pl pl-2">她的訓言充滿慈愛。</span></span>
<span className="v" id="v27" data-v="27" data-xref="提摩太前書 5:10; 提多書 2:4; 帖撒羅尼迦後書 3:6"> <span className="pl pl-1">她料理一切家務，</span><br /><span className="pl pl-2">從不偷懶吃閒飯。</span></span>
<span className="v" id="v28" data-v="28" data-xref="提摩太後書 3:15–17; 提摩太後書 1:5; 列王紀上 2:19"> <span className="pl pl-1">她的兒女肅立，</span><br /><span className="pl pl-2">為她祝福，</span><br /><span className="pl pl-2">她的丈夫也稱讚她，</span></span>
<span className="v" id="v29" data-v="29" data-xref="雅歌 6:8–9; 以弗所書 5:27"> <span className="pl pl-1">說：「世上賢德的女子很多，</span><br /><span className="pl pl-2">唯有你無與倫比。」</span></span>
<span className="v" id="v30" data-v="30" data-xref="箴言 1:7; 彼得前書 3:4–5; 箴言 11:22"> <span className="pl pl-1">豔麗是虛假的，</span><br /><span className="pl pl-2">美貌是短暫的，</span><br /><span className="pl pl-2">唯有敬畏耶和華的女子配得稱讚。</span></span>
<span className="v" id="v31" data-v="31" data-xref="詩篇 128:2; 希伯來書 6:10; 馬太福音 7:16"> <span className="pl pl-1">願她享受自己的勞動成果，</span><br /><span className="pl pl-2">願她的事蹟使她在城門口受稱讚。</span></span>
</div>

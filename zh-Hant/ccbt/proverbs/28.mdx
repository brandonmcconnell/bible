<span className="v" id="v4" data-v="4" data-xref="羅馬書 1:32; 以弗所書 5:11; 馬太福音 14:4"> <span className="pl pl-1">背棄律法的稱讚惡人，</span><br /><span className="pl pl-2">遵守律法的抗拒惡人。</span></span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 92:6; 雅各書 1:5; 約翰一書 2:27"> <span className="pl pl-1">邪惡之人不明白公義，</span><br /><span className="pl pl-2">尋求耶和華的全然明白。</span></span>
<span className="v" id="v6" data-v="6" data-xref="箴言 19:1; 箴言 28:18; 路加福音 16:19–23"> <span className="pl pl-1">行為正直的窮人，</span><br /><span className="pl pl-2">勝過行事邪僻的富人。</span></span>
<span className="v" id="v7" data-v="7" data-xref="彼得前書 4:3–4; 箴言 29:3; 箴言 3:1–35"> <span className="pl pl-1">遵守律法的是智慧之子，</span><br /><span className="pl pl-2">與貪食者為伍的令父蒙羞。</span></span>
<span className="v" id="v8" data-v="8" data-xref="約伯記 27:16–17; 箴言 13:22; 傳道書 2:26"> <span className="pl pl-1">人放高利貸牟利，</span><br /><span className="pl pl-2">是為濟貧者積財。</span></span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 66:18; 提摩太後書 4:3–4; 撒迦利亞書 7:11–13"> <span className="pl pl-1">人若不聽從律法，</span><br /><span className="pl pl-2">他的禱告也可憎。</span></span>
<span className="v" id="v10" data-v="10" data-xref="箴言 26:27; 詩篇 37:25–26; 加拉太書 2:4"> <span className="pl pl-1">引誘正直人走邪道，</span><br /><span className="pl pl-2">必掉進自己設的陷阱；</span><br /><span className="pl pl-2">但純全無過的人必承受福分。</span></span>
<span className="v" id="v11" data-v="11" data-xref="箴言 18:17; 傳道書 9:15–17; 箴言 26:16"> <span className="pl pl-1">富人自以為有智慧，</span><br /><span className="pl pl-2">卻被明智的窮人看透。</span></span>
<span className="v" id="v12" data-v="12" data-xref="箴言 29:2; 箴言 11:10; 箴言 28:28"> <span className="pl pl-1">義人得勝，眾民歡騰；</span><br /><span className="pl pl-2">惡人當道，人人躲藏。</span></span>
<span className="v" id="v13" data-v="13" data-xref="約翰一書 1:8–10; 詩篇 32:3–5; 約伯記 31:33"> <span className="pl pl-1">自掩其罪，必不亨通；</span><br /><span className="pl pl-2">痛改前非，必蒙憐憫。</span></span>
<span className="v" id="v14" data-v="14" data-xref="箴言 23:17; 詩篇 2:11; 以賽亞書 66:2"> <span className="pl pl-1">常敬畏主的必蒙福，</span><br /><span className="pl pl-2">心裡剛硬的必遭禍。</span></span>
<span className="v" id="v15" data-v="15" data-xref="彼得前書 5:8; 馬太福音 2:16; 箴言 19:12"> <span className="pl pl-1">暴虐的君王轄制窮人，</span><br /><span className="pl pl-2">如咆哮的獅、覓食的熊。</span></span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 18:21; 耶利米書 22:15–17; 傳道書 4:1"> <span className="pl pl-1">昏庸的君王殘暴不仁，</span><br /><span className="pl pl-2">恨不義之財的享長壽。</span></span>
<span className="v" id="v17" data-v="17" data-xref="創世記 9:6; 列王紀上 21:19; 出埃及記 21:14"> <span className="pl pl-1">背負血債者必終生逃亡，</span><br /><span className="pl pl-2">誰也不要幫他。</span></span>
<span className="v" id="v18" data-v="18" data-xref="箴言 10:9; 箴言 28:6; 啟示錄 3:3"> <span className="pl pl-1">純全無過的必蒙拯救，</span><br /><span className="pl pl-2">行為邪僻的轉眼覆滅。</span></span>
<span className="v" id="v19" data-v="19" data-xref="箴言 12:11; 士師記 9:4; 箴言 27:23–27"> <span className="pl pl-1">勤奮耕耘，豐衣足食；</span><br /><span className="pl pl-2">追求虛榮，窮困潦倒。</span></span>
<span className="v" id="v20" data-v="20" data-xref="路加福音 16:10–12; 箴言 13:11; 啟示錄 2:10"> <span className="pl pl-1">忠信的人必大蒙祝福，</span><br /><span className="pl pl-2">急於發財的難免受罰。</span></span>
<span className="v" id="v21" data-v="21" data-xref="箴言 24:23; 箴言 18:5; 以西結書 13:19"> <span className="pl pl-1">徇私偏袒實為不善，</span><br /><span className="pl pl-2">人卻為一點餅而枉法。</span></span>

<span className="v" id="v23" data-v="23" data-xref="箴言 27:5–6; 馬太福音 18:15; 詩篇 141:5"> <span className="pl pl-1">責備人的至終比諂媚者更受愛戴。</span><br /></span>

## 亞古珥的箴言

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="箴言 31:1; 彼得後書 1:19–21"> 以下是雅基的兒子亞古珥的箴言。<br /><span className="pl pl-2">這人說：上帝啊，我很疲倦；</span><br /><span className="pl pl-2">上帝啊，我很疲倦，精疲力盡。</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「這人說」希伯來文或譯「這人對以鐵說，對以鐵和烏甲說」。">a</a></sup></span>
<span className="v" id="v2" data-v="2" data-xref="詩篇 73:22; 哥林多前書 3:18; 以賽亞書 6:5"> <span className="pl pl-1">我比眾人都愚蠢，</span><br /><span className="pl pl-2">不具備人的悟性。</span></span>
<span className="v" id="v3" data-v="3" data-xref="啟示錄 3:7; 以弗所書 3:18–19; 羅馬書 11:33"> <span className="pl pl-1">我從未學到智慧，</span><br /><span className="pl pl-2">也不認識至聖者。</span></span>
<span className="v" id="v4" data-v="4" data-xref="約翰福音 3:13; 以弗所書 4:8–10; 約伯記 26:8"> <span className="pl pl-1">誰升上高天又降下來？</span><br /><span className="pl pl-2">誰將風聚在掌中？</span><br /><span className="pl pl-2">誰將眾水裹在衣服裡？</span><br /><span className="pl pl-2">誰定了地的邊界？</span><br /><span className="pl pl-2">祂叫什麼名字？</span><br /><span className="pl pl-2">祂兒子叫什麼名字？</span><br /><span className="pl pl-2">你知道嗎？</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="詩篇 18:30; 雅各書 3:17; 詩篇 12:6"> <span className="pl pl-1">上帝的話句句千真萬確，</span><br /><span className="pl pl-2">祂作投靠祂之人的盾牌。</span></span>
<span className="v" id="v6" data-v="6" data-xref="申命記 12:32; 申命記 4:2; 啟示錄 22:18–19"> <span className="pl pl-1">你不可對祂的話有所添加，</span><br /><span className="pl pl-2">免得祂責備你，</span><br /><span className="pl pl-2">揭穿你的虛謊。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="路加福音 10:42; 列王紀下 2:9; 詩篇 27:4"> <span className="pl pl-1">上帝啊，我向你求兩件事，</span><br /><span className="pl pl-2">求你在我有生之年賜給我。</span></span>
<span className="v" id="v8" data-v="8" data-xref="提摩太前書 6:6–8; 詩篇 62:9–10; 詩篇 119:37"> <span className="pl pl-1">求你使虛偽和謊言遠離我，</span><br /><span className="pl pl-2">求你讓我不貧窮也不富足，</span><br /><span className="pl pl-2">賜給我需用的飲食，</span></span>
<span className="v" id="v9" data-v="9" data-xref="何西阿書 13:6; 申命記 31:20; 以西結書 16:49–50"> <span className="pl pl-1">免得我因為飽足就不認你，</span><br /><span className="pl pl-2">說：「耶和華是誰呢？」</span><br /><span className="pl pl-2">又恐怕我因窮困而偷竊，</span><br /><span className="pl pl-2">以致辱沒我上帝的名。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="羅馬書 14:4; 傳道書 7:21; 申命記 23:15"> <span className="pl pl-1">別向主人譭謗他的僕人，</span><br /><span className="pl pl-2">免得你受咒詛、擔當罪責。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v11" data-v="11" data-xref="箴言 20:20; 箴言 30:17; 出埃及記 21:17"> <span className="pl pl-1">有一種</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="「種」希伯來文是「世代」，11-14節也相同。">b</a></sup><br /><span className="pl pl-1">人咒詛父親，</span><br /><span className="pl pl-2">不為母親祝福。</span></span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 18:11; 箴言 16:2; 提摩太後書 3:5"> <span className="pl pl-1">有一種人自以為純潔，</span><br /><span className="pl pl-2">卻沒有洗掉自己的污穢。</span></span>
<span className="v" id="v13" data-v="13" data-xref="箴言 6:17; 以賽亞書 2:11; 詩篇 101:5"> <span className="pl pl-1">有一種人趾高氣揚，</span><br /><span className="pl pl-2">目空一切。</span></span>
<span className="v" id="v14" data-v="14" data-xref="詩篇 57:4; 詩篇 3:7; 詩篇 14:4"> <span className="pl pl-1">有一種人牙如劍，</span><br /><span className="pl pl-2">齒如刀，</span><br /><span className="pl pl-2">要吞吃世間的困苦人和貧窮人。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="箴言 30:21; 箴言 30:29; 箴言 6:16"> <span className="pl pl-1">水蛭有兩個女兒，</span><br /><span className="pl pl-2">她們不停地叫：「給我！給我！」</span><br /><span className="pl pl-1">三樣東西從不知足，</span><br /><span className="pl pl-1">永不言「夠」的共有四樣：</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="箴言 27:20; 哈巴谷書 2:5; 創世記 30:1"> <span className="pl pl-1">陰間、不孕的婦人、</span><br /><span className="pl pl-2">乾旱的土地和燒不夠的火焰。</span></span>
<span className="v" id="v17" data-v="17" data-xref="箴言 23:22; 申命記 21:18–21; 箴言 30:11"> <span className="pl pl-1">嘲笑父親、藐視母親教誨的，</span><br /><span className="pl pl-2">眼睛必被谷中的烏鴉啄出，</span><br /><span className="pl pl-2">被禿鷹吃掉。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v18" data-v="18" data-xref="約伯記 42:3; 詩篇 139:6"> <span className="pl pl-1">我測不透的妙事有三樣，</span><br /><span className="pl pl-1">我不明白的事共有四樣：</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="以賽亞書 40:31; 約伯記 39:27; 出埃及記 22:16"> <span className="pl pl-1">鷹在空中飛翔之道，</span><br /><span className="pl pl-2">蛇在石上爬行之道，</span><br /><span className="pl pl-2">船在海中航行之道，</span><br /><span className="pl pl-2">男女相愛之道。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v20" data-v="20" data-xref="箴言 5:6; 箴言 7:13–23; 民數記 5:11–30"> <span className="pl pl-1">淫婦的道是這樣：</span><br /><span className="pl pl-2">她吃完就擦擦嘴，</span><br /><span className="pl pl-2">說，「我沒有做壞事。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v21" data-v="21"> <span className="pl pl-1">使大地震動的事有三樣，</span><br /><span className="pl pl-1">大地無法承受的事共有四樣：</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="箴言 19:10; 傳道書 10:7; 撒母耳記上 25:10–11"> <span className="pl pl-1">奴僕做王，</span><br /><span className="pl pl-2">愚人吃飽，</span></span>
<span className="v" id="v23" data-v="23" data-xref="箴言 21:19; 箴言 27:15; 箴言 29:21"> <span className="pl pl-1">醜惡女子出嫁，</span><br /><span className="pl pl-2">婢女取代主母。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v24" data-v="24" data-xref="約伯記 12:7"> <span className="pl pl-1">地上有四種動物，</span><br /><span className="pl pl-2">身體雖小卻極其聰明：</span></span>
<span className="v" id="v25" data-v="25" data-xref="箴言 6:6–8"> <span className="pl pl-1">螞蟻力量雖小，</span><br /><span className="pl pl-2">卻在夏天儲備糧食；</span></span>
<span className="v" id="v26" data-v="26" data-xref="詩篇 104:18; 利未記 11:5"> <span className="pl pl-1">石獾雖不強壯，</span><br /><span className="pl pl-2">卻在巖石中做窩；</span></span>
<span className="v" id="v27" data-v="27" data-xref="約珥書 2:25; 約珥書 1:6–7; 約珥書 2:7–11"> <span className="pl pl-1">蝗蟲雖無君王，</span><br /><span className="pl pl-2">卻整齊地列隊前進；</span></span>
<span className="v" id="v28" data-v="28"> <span className="pl pl-1">壁虎雖易捕捉，</span><br /><span className="pl pl-2">卻居住在王宮大內。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v29" data-v="29"> <span className="pl pl-1">步履威武的有三樣，</span><br /><span className="pl pl-1">走路雄壯的共有四樣：</span><br /></span>
<span className="v" id="v30" data-v="30" data-xref="民數記 23:24; 士師記 14:18"> <span className="pl pl-1">威震百獸、從不畏縮的獅子，</span><br /></span>
<span className="v" id="v31" data-v="31" data-xref="但以理書 3:15–18; 箴言 20:2; 箴言 16:14"> <span className="pl pl-1">昂首闊步的雄雞，</span><br /><span className="pl pl-2">公山羊和率領軍隊的君王。</span></span>
<span className="v" id="v32" data-v="32" data-xref="約伯記 21:5; 約伯記 40:4; 箴言 26:12"> <span className="pl pl-1">你若行事愚昧、</span><br /><span className="pl pl-2">妄自尊大或圖謀不軌，</span><br /><span className="pl pl-2">就當用手掩口。</span></span>
<span className="v" id="v33" data-v="33" data-xref="箴言 17:14; 箴言 29:22; 箴言 28:25"> <span className="pl pl-1">激起憤怒會引起爭端，</span><br /><span className="pl pl-2">正如攪牛奶會攪出奶油，</span><br /><span className="pl pl-2">擰鼻子會擰出鼻血。</span></span>

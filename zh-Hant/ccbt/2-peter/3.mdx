## 主再來的應許

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="提摩太後書 1:6; 彼得後書 1:12–15; 彼得前書 1:22"> 親愛的弟兄姊妹，我現在寫給你們的是第二封信。這兩封信都是為了提醒你們，激勵你們保持真誠的心，</span>
<span className="v" id="v2" data-v="2" data-xref="猶大書 1:17; 彼得後書 2:21; 路加福音 1:70"> 叫你們記得從前聖先知們說的預言，以及我們的主和救主藉使徒傳給你們的誡命。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="猶大書 1:18; 提摩太前書 4:1–2; 彼得後書 2:10"> 最重要的是，你們要知道，末世必出現冷嘲熱諷、放縱自己邪情私慾的人。他們說：</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米書 17:15; 瑪拉基書 2:17; 耶利米書 5:12–13"> 「主要降臨的應許在哪裡？從我們的祖先長眠地下直到現在，萬物依舊與創世之初一樣。」</span>
<span className="v" id="v5" data-v="5" data-xref="希伯來書 11:3; 創世記 1:9; 詩篇 24:2"> 他們故意忽略：太初，上帝憑口中的話語創造了諸天，並藉著水從水中造出了地；</span>
<span className="v" id="v6" data-v="6" data-xref="馬太福音 24:38–39; 彼得後書 2:5; 路加福音 17:27"> 後來，那個世界被水淹沒而毀滅了。</span>
<span className="v" id="v7" data-v="7" data-xref="彼得後書 3:10; 以賽亞書 51:6; 彼得後書 3:12"> 現在的天地同樣是憑上帝的話語保留到被火焚燒的日子，就是不敬虔的人被審判和毀滅的日子。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="詩篇 90:4; 羅馬書 11:25; 哥林多前書 12:1"> 親愛的弟兄姊妹，有一件事你們不可忽略，就是主看一日如千年，千年如一日。</span>
<span className="v" id="v9" data-v="9" data-xref="提摩太前書 2:4; 羅馬書 2:4; 哈巴谷書 2:3"> 主的應許還未實現，有人以為祂拖延，其實祂不是拖延，而是在寬容你們。祂不願任何人滅亡，願意人人都悔改。</span>
<span className="v" id="v10" data-v="10" data-xref="啟示錄 21:1; 馬太福音 24:35; 彼得後書 3:7"> 不過，主的日子會像賊一樣突然臨到。那日，諸天必在一聲巨響中消失，有形有質的都要被烈火熔化，大地和其中的一切將不復存在。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="彼得前書 1:15; 腓立比書 1:27; 彼得前書 2:12"> 既然一切都要這樣被熔化，你們在熱切等候上帝的日子來臨期間，該過怎樣聖潔、敬虔的生活啊！因為到那日，天要被火焚毀，有形有質的都要被烈火熔化。</span>
<span className="v" id="v13" data-v="13" data-xref="以賽亞書 65:17; 啟示錄 21:1; 以賽亞書 66:22"> 但我們等候的是上帝應許的新天新地，有公義住在其中。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="帖撒羅尼迦前書 5:23; 帖撒羅尼迦前書 3:13; 腓立比書 1:10"> 所以，親愛的弟兄姊妹，你們既然盼望這些事，就當努力使自己在主面前毫無瑕疵，無可指責，安然無懼。</span>
<span className="v" id="v15" data-v="15" data-xref="羅馬書 2:4; 彼得後書 3:9; 提摩太前書 1:16"> 你們要把我們主的寬容看作是讓眾人得救的機會，正如我們親愛的弟兄保羅按著上帝賜給他的智慧寫信告訴你們的。</span>
<span className="v" id="v16" data-v="16" data-xref="馬太福音 15:6; 希伯來書 5:11; 雅各書 1:8"> 他所有的書信都談到這些事。一些不學無術、反覆無常的人曲解了信中一些難懂的地方，就像曲解其他經文一樣，他們是自取滅亡。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="希伯來書 3:14; 歌羅西書 2:8; 哥林多後書 11:13–15"> 因此，親愛的弟兄姊妹，你們既然預先知道了這些事，就應該小心謹慎，不要讓那些不法之徒用錯謬的理論引誘你們，使你們失去原本堅定的立場。</span>
<span className="v" id="v18" data-v="18" data-xref="歌羅西書 1:10; 以弗所書 4:15; 彼得前書 2:2"> 相反，你們要在我們的主和救主耶穌基督的恩典中不斷長進，越來越認識祂。<br />願榮耀歸給祂，從現在直到永遠。阿們！</span>
</div>
</div>

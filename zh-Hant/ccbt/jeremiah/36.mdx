## 耶利米的書卷被焚毀

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="耶利米書 25:1; 歷代志下 36:5; 耶利米書 45:1"> 約西亞的兒子猶大王約雅敬執政第四年，耶和華對耶利米說：</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米書 30:2; 耶利米書 25:3; 耶利米書 1:10"> 「你拿一個卷軸來，把從約西亞執政時期直到現在我告訴你有關以色列、猶大和各國的事都寫在上面。</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米書 18:8; 使徒行傳 3:19; 耶利米書 26:3"> 或許猶大人聽了我打算要降給他們的災禍，便各自改邪歸正，我就赦免他們的過犯和罪惡。」</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米書 32:12; 耶利米書 36:32; 以西結書 2:9"> 耶利米就叫來尼利亞的兒子巴錄。巴錄按耶利米的口述把耶和華吩咐他的話都寫在卷軸上，</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米書 32:2; 耶利米書 33:1; 哥林多後書 11:23"> 耶利米對他說：「我被囚禁，不能進入耶和華的殿，</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米書 36:8–9; 耶利米書 26:2; 耶利米書 22:2"> 所以你要在禁食的日子，去耶和華的殿向百姓宣讀我口授你記錄在卷軸上的耶和華的話。你要向猶大各城來的人宣讀。</span>
<span className="v" id="v7" data-v="7" data-xref="耶利米書 36:3; 耶利米書 21:5; 歷代志下 33:12–13"> 或許他們會懇求耶和華施憐憫，並各自改邪歸正，因為耶和華宣佈要向他們大發怒氣和烈怒。」</span>
<span className="v" id="v8" data-v="8" data-xref="耶利米書 1:17; 哥林多前書 16:10; 路加福音 4:16–30"> 尼利亞的兒子巴錄照耶利米先知的吩咐，在耶和華的殿中宣讀卷軸上耶和華的話。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="歷代志下 20:3; 約拿書 3:5; 以斯帖記 4:16"> 約西亞的兒子猶大王約雅敬執政第五年九月，耶路撒冷和猶大各城的人都在耶和華面前宣告禁食。</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米書 36:11; 耶利米書 26:10; 耶利米書 52:25"> 巴錄來到耶和華殿新門入口處的上院，在沙番的兒子書記基瑪利雅的房間，向眾人宣讀卷軸上耶利米的話。</span>
<span className="v" id="v11" data-v="11" data-xref="耶利米書 36:10; 歷代志下 34:20; 列王紀下 25:22"> 沙番的孫子、基瑪利雅的兒子米該亞聽了卷軸上耶和華的話，</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米書 26:22; 列王紀下 22:12; 耶利米書 36:25"> 就下到王宮，進入書記的房間。房間內坐著所有官長，即書記以利沙瑪、示瑪雅的兒子第萊雅、亞革波的兒子以利拿單、沙番的兒子基瑪利雅和哈拿尼雅的兒子西底迦及其他官長。</span>
<span className="v" id="v13" data-v="13" data-xref="列王紀下 22:10; 歷代志下 34:24; 歷代志下 34:16–18"> 米該亞將巴錄向眾人宣讀的話都告訴了他們。</span>
<span className="v" id="v14" data-v="14" data-xref="耶利米書 36:2; 耶利米書 41:18; 耶利米書 41:1–2"> 眾官長就派古示的曾孫、示利米雅的孫子、尼探雅的兒子猶底去請巴錄把當眾宣讀的卷軸拿來。尼利亞的兒子巴錄拿著卷軸到他們那裡，</span>
<span className="v" id="v15" data-v="15"> 他們請他坐下，把卷軸讀給他們聽。巴錄就讀給他們聽。</span>
<span className="v" id="v16" data-v="16" data-xref="耶利米書 13:18; 耶利米書 36:24; 阿摩司書 7:10–11"> 他們聽後嚇得面面相覷，對巴錄說：「我們必須把這些話稟告王！」</span>
<span className="v" id="v17" data-v="17" data-xref="約翰福音 9:15; 約翰福音 9:10–11; 約翰福音 9:26–27"> 他們問巴錄：「請告訴我們，你是怎麼寫下這些話的？是耶利米口授的嗎？」</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米書 36:4; 耶利米書 36:2; 箴言 26:4–5"> 巴錄說：「都是耶利米口授、我用筆墨記錄在卷軸上的。」</span>
<span className="v" id="v19" data-v="19" data-xref="列王紀上 17:3; 列王紀上 18:10; 耶利米書 26:20–24"> 他們說：「你和耶利米都要藏起來，不可讓人知道你們在哪裡。」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="耶利米書 36:12; 耶利米書 36:21"> 他們把卷軸存放在書記以利沙瑪的房間，然後進宮把整件事稟告王。</span>
<span className="v" id="v21" data-v="21" data-xref="列王紀下 22:10; 歷代志下 34:18; 以西結書 2:4–5"> 王就派猶底去把卷軸取來，猶底便從書記以利沙瑪的房間取來卷軸，讀給王和侍立在王周圍的官長聽。</span>
<span className="v" id="v22" data-v="22" data-xref="阿摩司書 3:15; 耶利米書 22:14–16; 耶利米書 36:9"> 那時正是九月，王坐在冬宮，面前擺著一盆炭火。</span>
<span className="v" id="v23" data-v="23" data-xref="列王紀上 22:8; 箴言 21:30; 列王紀上 22:27"> 王和臣僕聽了這些話，既不懼怕，也沒有撕裂衣服。猶底每讀三四段，王就用書記的小刀把那幾段割下來扔進火盆裡，直到全卷被燒毀。</span>
<span className="v" id="v25" data-v="25" data-xref="創世記 37:22; 耶利米書 36:12; 使徒行傳 5:34–39"> 雖然以利拿單、第萊雅和基瑪利雅懇求王不要把卷軸燒掉，王卻不聽，</span>
<span className="v" id="v26" data-v="26" data-xref="列王紀上 17:3; 列王紀上 19:1–3; 列王紀上 19:14"> 還命令自己的兒子耶拉篾、亞斯列的兒子西萊雅和亞伯德的兒子示利米雅，去拘捕書記巴錄和耶利米先知。但耶和華把他們藏了起來。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="耶利米書 36:4"> 王把耶利米口述、巴錄記錄的卷軸燒掉後，耶和華對耶利米說：</span>
<span className="v" id="v28" data-v="28" data-xref="撒迦利亞書 1:5–6; 約伯記 23:13; 耶利米書 44:28"> 「你再拿一卷軸，把猶大王約雅敬先前燒毀的卷軸上的話寫下來。</span>
<span className="v" id="v29" data-v="29" data-xref="以賽亞書 30:10; 耶利米書 26:9; 申命記 29:19"> 你要告訴猶大王約雅敬，『耶和華說：你把卷軸燒掉，還說為什麼上面寫著巴比倫王必來毀滅這地方和其中的人畜。</span>
<span className="v" id="v30" data-v="30" data-xref="耶利米書 22:30; 列王紀下 24:12–15; 創世記 31:40"> 所以關於猶大王約雅敬，耶和華說：他的子孫沒有一人能登大衛的寶座，他必曝尸荒野，遭受烈日的暴曬和夜霜的侵襲。</span>
<span className="v" id="v31" data-v="31" data-xref="箴言 29:1; 耶利米書 19:15; 耶利米書 35:17"> 我要因他、他後裔和他臣僕的罪惡而懲罰他們。因為他們不聽我的警告，我要給他們以及耶路撒冷和猶大的居民降下我說過的災禍。』」</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="耶利米書 36:4; 耶利米書 36:18; 出埃及記 4:15–16"> 於是，耶利米又拿了一個卷軸，交給尼利亞的兒子書記巴錄，他按耶利米的口述，把猶大王約雅敬燒毀的那卷軸上的話都記下來，還增添了許多類似的話。</span>
</div>
</div>

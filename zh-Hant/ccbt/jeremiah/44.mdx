## 耶和華給流亡埃及之人的信息

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="耶利米書 46:14; 以賽亞書 11:11; 出埃及記 14:2"> 關於住在埃及的密奪、答比匿、挪弗和巴特羅地區的猶大人，耶和華對耶利米說：</span>
<span className="v" id="v2" data-v="2" data-xref="以賽亞書 6:11; 耶利米書 9:11; 耶利米書 34:22"> 「以色列的上帝——萬軍之耶和華說，『你們已看見了我降在耶路撒冷和猶大各城的災禍。如今它們一片荒涼，杳無人跡。</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 29:26; 申命記 13:6; 申命記 32:17"> 這都是因為那裡的居民犯罪作惡，向他們、你們和你們祖先都不認識的神明燒香祭拜，惹我發怒。</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米書 26:5; 耶利米書 7:25; 耶利米書 7:13"> 我屢次差遣我的僕人——眾先知警告他們不要再做讓我深惡痛絕的事，</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米書 11:10; 耶利米書 19:13; 歷代志下 36:16"> 他們卻毫不理會，不肯離棄邪惡，仍向其他神明燒香。</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米書 7:20; 耶利米書 21:5; 以賽亞書 51:17"> 因此，我的怒氣和烈怒在猶大的城邑和耶路撒冷的街上燃燒，使它們淪為荒涼的廢墟，正如今日一樣。』</span>
<span className="v" id="v7" data-v="7" data-xref="哈巴谷書 2:10; 耶利米書 51:22; 以西結書 33:11"> 現在以色列的上帝——萬軍之上帝耶和華說，『你們為什麼自招大禍，使你們當中的男人、女人、孩童和嬰兒都從猶大滅亡，無一倖免呢？</span>
<span className="v" id="v8" data-v="8" data-xref="耶利米書 42:18; 耶利米書 25:6–7; 耶利米書 44:3"> 你們為什麼在所居住的埃及製作偶像，向其他神明燒香，惹我發怒，自招毀滅，成為天下萬國咒詛和羞辱的對象呢？</span>
<span className="v" id="v9" data-v="9" data-xref="耶利米書 7:17–18; 約書亞記 22:17–20; 耶利米書 44:15–19"> 難道你們忘記了你們的祖先、猶大列王及其嬪妃，以及你們自己和妻子在猶大和耶路撒冷街上的惡行嗎？</span>
<span className="v" id="v10" data-v="10" data-xref="箴言 28:14; 彼得前書 5:6; 啟示錄 15:4"> 你們至今既不悔悟也不懼怕，不遵行我給你們和你們祖先設立的律法和誡命。</span>
<span className="v" id="v11" data-v="11" data-xref="耶利米書 21:10; 利未記 26:17; 利未記 20:5–6"> 「『因此，以色列的上帝——萬軍之耶和華說：看啊，我必嚴懲你們，毀滅整個猶大。</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米書 42:15–18; 耶利米書 42:22; 以賽亞書 65:15"> 我要毀滅那些執意去埃及住的猶大餘民。他們都必在埃及滅亡，死於刀劍和饑荒，無論尊卑，無一倖免。他們的下場將很可怕，成了人們責罵、咒詛和羞辱的對象。</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米書 11:22; 耶利米書 43:11; 耶利米書 44:27–28"> 我要像懲罰耶路撒冷一樣用刀劍、饑荒和瘟疫懲罰那些住在埃及的人。</span>
<span className="v" id="v14" data-v="14" data-xref="羅馬書 9:27; 耶利米書 22:26–27; 耶利米書 42:17"> 那些去埃及住的猶大餘民沒有幾個能逃脫，並活著返回他們渴望居住的故鄉猶大，除了少數倖存者外，他們都不得回去。』」</span>
<span className="v" id="v15" data-v="15" data-xref="箴言 11:21; 耶利米書 5:1–5; 創世記 19:4"> 那時，所有知道妻子向其他神明燒香的男人和一大群在場的婦女，以及所有住在埃及的巴特羅地區的人對耶利米說：</span>
<span className="v" id="v16" data-v="16" data-xref="約伯記 21:14–15; 路加福音 19:27; 耶利米書 16:15–17"> 「我們不會聽從你奉耶和華的名對我們說的話。</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米書 7:18; 尼希米記 9:34; 耶利米書 44:21"> 但我們必照所許的願向天后燒香奠酒，正如我們和我們的祖先、君王和官長在猶大各城和耶路撒冷街上所做的一樣。那時，我們食物充足，生活幸福，無災無禍。</span>
<span className="v" id="v18" data-v="18" data-xref="瑪拉基書 3:13–15; 民數記 11:5–6; 約伯記 21:14–15"> 但自從我們停止向天后燒香奠酒後，我們便一無所有，不斷有人死於刀劍和饑荒。」</span>
<span className="v" id="v19" data-v="19" data-xref="耶利米書 7:18; 耶利米書 44:15; 列王紀上 21:25"> 那些燒香的婦女說：「你以為我們的丈夫不知道我們向天后燒香奠酒、照著她的形像做祭餅嗎？」</span>
<span className="v" id="v20" data-v="20"> 於是，耶利米對在場所有答覆他的男女說：</span>
<span className="v" id="v21" data-v="21" data-xref="耶利米書 44:17; 耶利米書 44:9; 耶利米書 11:13"> 「你們和你們的祖先、君王、官長及其他所有百姓在猶大各城和耶路撒冷的街上燒香，耶和華豈不記得，豈能遺忘？</span>
<span className="v" id="v22" data-v="22" data-xref="耶利米書 25:18; 以賽亞書 7:13; 瑪拉基書 2:17"> 你們的可憎惡行令耶和華忍無可忍，以致祂使你們的土地一片荒涼，無人居住，被人咒詛，正如今天的情形。</span>
<span className="v" id="v23" data-v="23" data-xref="列王紀上 9:9; 但以理書 9:11–12; 尼希米記 13:18"> 你們遭遇今天的災禍是因為你們向其他神明燒香得罪耶和華，不聽從祂的話，不遵行祂的律法、誡命和教誨。」</span>
<span className="v" id="v24" data-v="24" data-xref="耶利米書 43:7; 耶利米書 44:15–16; 耶利米書 42:15"> 耶利米又對在場的男女說：「你們住在埃及的猶大人都要聽耶和華的話。</span>
<span className="v" id="v25" data-v="25" data-xref="馬太福音 14:9; 使徒行傳 23:12–15; 以賽亞書 28:15"> 以色列的上帝——萬軍之耶和華說，『你們和你們的妻子曾許願向天后燒香奠酒，並且著手還了所許的願。那麼，就去履行你們的許諾吧！還你們所許的願吧！』</span>
<span className="v" id="v26" data-v="26" data-xref="詩篇 50:16; 以西結書 20:39; 希伯來書 6:13"> 住在埃及的所有猶大人啊，你們都要聽耶和華的話。耶和華說，『看啊，我以自己偉大的名起誓，再沒有一個住在埃及的猶大人會憑永活的主耶和華起誓。</span>
<span className="v" id="v27" data-v="27" data-xref="耶利米書 31:28; 列王紀下 21:14; 耶利米書 1:10"> 看啊，我一定要給你們降下災禍而非祝福，使所有住在埃及的猶大人死於刀劍和饑荒，直到滅絕。</span>
<span className="v" id="v28" data-v="28" data-xref="耶利米書 44:14; 以賽亞書 27:12–13; 以賽亞書 10:19"> 刀下餘生、從埃及返回猶大的人必寥寥無幾。那時，你們這些來埃及住的猶大餘民必知道誰的話會實現，是我的還是你們的。</span>
<span className="v" id="v29" data-v="29" data-xref="箴言 19:21; 馬太福音 24:15–16; 耶利米書 44:30"> 我必在這地方懲罰你們，我要給你們一個預兆，好叫你們知道我言出必行，必降災給你們。這是耶和華說的。</span>
<span className="v" id="v30" data-v="30" data-xref="列王紀下 25:4–7; 耶利米書 43:9–13; 耶利米書 34:21"> 我必把埃及王法老何弗拉交在想殺他的仇敵手中，就像我把猶大王西底迦交在想殺他的仇敵巴比倫王尼布甲尼撒手中一樣。這是耶和華說的。』」</span>

## 腰帶的比喻

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="耶利米書 13:11; 希伯來書 1:1; 耶利米書 27:2"> 耶和華對我說：「你去買一條麻布腰帶束在腰間，不可讓它沾水。」</span>
<span className="v" id="v2" data-v="2" data-xref="以西結書 2:8; 約翰福音 15:14; 箴言 3:5"> 我照耶和華的話買了腰帶，束在腰間。</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米書 13:8"> 耶和華又對我說：</span>
<span className="v" id="v4" data-v="4" data-xref="彌迦書 4:10; 詩篇 137:1; 耶利米書 51:63–64"> 「拿著你買來的腰帶去幼發拉底河邊，把它藏在那裡的巖縫中。」</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 40:16; 出埃及記 39:42–43; 提摩太後書 2:3"> 於是，我照耶和華的吩咐把腰帶藏在那裡。</span>
<span className="v" id="v6" data-v="6"> 多日後，耶和華對我說：「去幼發拉底河邊取回我吩咐你藏在那裡的腰帶。」</span>
<span className="v" id="v7" data-v="7" data-xref="羅馬書 3:12; 以賽亞書 64:6; 耶利米書 13:10"> 我就去幼發拉底河邊把所藏的腰帶挖出來，但腰帶已經腐爛，毫無用處。</span>
<span className="v" id="v8" data-v="8"> 耶和華對我說：</span>
<span className="v" id="v9" data-v="9" data-xref="利未記 26:19; 耶利米書 13:15–17; 西番雅書 3:11"> 「耶和華如此說，『我也要這樣消滅猶大的驕傲和耶路撒冷的狂妄。</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米書 16:12; 耶利米書 9:14; 歷代志下 36:15–16"> 這邪惡的百姓拒絕聽我的話，一意孤行，跟隨、供奉、祭拜其他神明，他們將像這腰帶一樣毫無用處。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及記 19:5–6; 耶利米書 33:9; 詩篇 81:11"> 我本想使以色列人和猶大人緊靠著我，就像腰帶緊貼在人的腰間，讓他們做我的子民，使我聲名遠揚、得到讚美和尊崇，他們卻不肯聽從。這是耶和華說的。』</span>
<span className="v" id="v12" data-v="12" data-xref="以西結書 24:19"> 「因此，你告訴他們，以色列的上帝耶和華說，『每個瓦瓶都要盛滿酒。』若他們說，『難道我們不知道每個瓦瓶都要盛滿酒嗎？』</span>
<span className="v" id="v13" data-v="13" data-xref="以賽亞書 63:6; 詩篇 75:8; 詩篇 60:3"> 你就告訴他們，『耶和華說：我要使這片土地上所有的居民，包括坐在大衛寶座上的君王以及祭司、先知和耶路撒冷人都酩酊大醉；</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 29:20; 詩篇 2:9; 耶利米書 19:9–11"> 我要使他們彼此撞得粉碎，就算父子也要彼此相撞；我要毀滅他們，決不留情，也不心慈手軟。』」</span>
<span className="v" id="v15" data-v="15" data-xref="以賽亞書 28:14–22; 啟示錄 2:29; 使徒行傳 4:19–20"> <span className="pl pl-1">你們要留心聽，</span><br /><span className="pl pl-1">不可傲慢，</span><br /><span className="pl pl-1">因為耶和華已發言。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="以賽亞書 59:9; 以賽亞書 8:22; 以賽亞書 5:30"> <span className="pl pl-1">趁著你們的上帝耶和華還未使黑暗來臨，</span><br /><span className="pl pl-1">你們還未在漆黑的山上絆倒，</span><br /><span className="pl pl-1">要把榮耀歸給祂。</span><br /><span className="pl pl-1">否則，祂必使你們期望的光明變為幽冥和黑暗。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="瑪拉基書 2:2; 耶利米書 9:1; 耶利米書 14:17"> <span className="pl pl-1">如果你們不肯聽，</span><br /><span className="pl pl-1">我的心會為你們的驕傲暗自哭泣，</span><br /><span className="pl pl-1">我雙眼痛哭，淚流滿面，</span><br /><span className="pl pl-1">因為耶和華的羊群將要被擄。</span></span>
</div>

## 耶利米負軛的比喻

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="耶利米書 27:3; 耶利米書 28:1; 耶利米書 27:12"> 約西亞的兒子猶大王約雅敬執政初期，耶和華的話傳給了耶利米。</span>
<span className="v" id="v2" data-v="2" data-xref="阿摩司書 7:1; 阿摩司書 7:4; 耶利米書 27:12"> 耶和華對我說：「你要用皮帶和木頭做個軛，套在自己頸上。</span>
<span className="v" id="v3" data-v="3" data-xref="阿摩司書 1:9–3; 以西結書 25:1–17; 以西結書 17:15–21"> 然後請那些到耶路撒冷朝見猶大王西底迦的使者傳話給他們的主人以東王、摩押王、亞捫王、泰爾王和西頓王，</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米書 51:19; 耶利米書 10:10; 耶利米書 25:27"> 說，『以色列的上帝——萬軍之耶和華說，</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米書 32:17; 耶利米書 51:15; 詩篇 115:15–16"> 我伸出大能的臂膀創造了大地、地上的人類和動物，我想把大地賜給誰就賜給誰。</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米書 28:14; 耶利米書 25:9; 但以理書 2:37–38"> 現在，我要把你們的國家交給我的僕人巴比倫王尼布甲尼撒，連田野的走獸也要歸他管轄。</span>
<span className="v" id="v7" data-v="7" data-xref="耶利米書 52:31; 啟示錄 13:5–10; 但以理書 5:25–31"> 各國都要臣服於他和他的子孫，直到他的國家滅亡。那時，許多國家和強大的君王必奴役他。</span>
<span className="v" id="v8" data-v="8" data-xref="以西結書 14:21; 以西結書 17:19–21; 耶利米書 38:17–19"> 如果哪一邦或哪一國不肯臣服於巴比倫王尼布甲尼撒，不肯負巴比倫王的軛，我必用刀劍、饑荒和瘟疫懲罰他們，直到我藉巴比倫王的手毀滅他們。這是耶和華說的。</span>
<span className="v" id="v9" data-v="9" data-xref="耶利米書 14:14; 瑪拉基書 3:5; 耶利米書 29:8"> 你們不可聽信你們的先知、占卜者、解夢者、巫師和術士的話，他們說你們不會臣服於巴比倫王。</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米書 32:31; 耶利米書 28:16; 耶利米書 23:25"> 他們的預言是騙人的，只會使你們遠離家園。我會趕走你們，使你們滅亡。</span>
<span className="v" id="v11" data-v="11" data-xref="耶利米書 27:8; 耶利米書 27:2; 耶利米書 38:2"> 但如果哪一國肯負巴比倫王的軛，臣服於他，我必使那國的人們留在本國耕種居住。這是耶和華說的。』」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="耶利米書 28:1; 耶利米書 38:17; 歷代志下 36:11–13"> 我同樣對猶大王西底迦說：「你們要負巴比倫王的軛，臣服於他和他的人民，就可存活。</span>
<span className="v" id="v13" data-v="13" data-xref="以西結書 18:31; 耶利米書 27:8; 箴言 8:36"> 你和你的人民何必死於刀劍、饑荒和瘟疫呢？耶和華要降這些災難給不肯臣服於巴比倫王的國家。</span>
<span className="v" id="v14" data-v="14" data-xref="耶利米書 14:14; 哥林多後書 11:13–15; 耶利米書 29:8–9"> 不要聽信那些先知騙人的預言，他們說你們不會臣服於巴比倫王。</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米書 27:10; 歷代志下 25:16; 耶利米書 6:13–15"> 耶和華並沒有派他們，他們卻奉祂的名說假預言。如果你們聽信他們的話，耶和華必把你們和向你們說預言的先知趕走，使你們一同滅亡。」</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀下 24:13; 耶利米書 28:3; 但以理書 1:2"> 我也對祭司和全體民眾說：「耶和華說，『你們不要聽信假先知騙人的預言，他們說耶和華殿裡的器皿很快就要從巴比倫運回來了。</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米書 38:17; 耶利米書 38:23; 耶利米書 7:34"> 你們不可聽信他們的話。你們要臣服於巴比倫王，以便存活。何必使這城淪為廢墟呢？</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳記上 7:8; 耶利米書 18:20; 撒母耳記上 12:19"> 如果他們真的是先知，有耶和華給他們的信息，就讓他們求萬軍之耶和華不要使聖殿中、猶大王宮內和耶路撒冷剩餘的器皿被擄到巴比倫去。』</span>
<span className="v" id="v19" data-v="19" data-xref="列王紀下 25:13; 耶利米書 52:17–23; 列王紀下 25:17"> 巴比倫王尼布甲尼撒把約雅敬的兒子猶大王耶哥尼雅，以及猶大和耶路撒冷的貴族從耶路撒冷擄到巴比倫去的時候，沒有帶走耶和華殿的銅柱、銅海、銅底座及其他器皿。</span>
<span className="v" id="v21" data-v="21"> 關於耶和華殿中、猶大王宮內和耶路撒冷剩下的物件，以色列的上帝——萬軍之耶和華說：</span>
<span className="v" id="v22" data-v="22" data-xref="耶利米書 29:10; 以斯拉記 7:19; 耶利米書 32:5"> 『它們必被擄到巴比倫，留在那裡，一直到我眷顧以色列人的日子，那時我必把它們帶回原處。這是耶和華說的。』」</span>
</div>

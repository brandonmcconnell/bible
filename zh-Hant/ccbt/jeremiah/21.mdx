## 預言耶路撒冷的淪陷

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="耶利米書 29:25; 耶利米書 37:3; 耶利米書 52:24"> 西底迦王派瑪基雅的兒子巴施戶珥和瑪西雅的兒子西番雅祭司來見耶利米的時候，耶和華的話臨到耶利米。當時，他們對耶利米說：</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米書 37:3; 耶利米書 42:4–6; 耶利米書 37:7"> 「請你為我們求問耶和華，因為巴比倫王尼布甲尼撒來攻打我們，或許耶和華會像以往一樣為我們行神蹟，使敵人撤軍。」</span>
<span className="v" id="v3" data-v="3"> 耶利米對他們說：「你們要告訴西底迦，</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米書 32:5; 耶利米書 37:8–10; 以賽亞書 5:5"> 以色列的上帝耶和華說，『看啊，你們與圍城的巴比倫王及迦勒底人作戰，我要把你們的兵器掉轉過來，我要把它們收集在城中心。</span>
<span className="v" id="v5" data-v="5" data-xref="以賽亞書 63:10; 出埃及記 6:6; 以賽亞書 5:25"> 我要在怒氣、義憤和烈怒中伸出大能的臂膀下手擊打你們，</span>
<span className="v" id="v6" data-v="6" data-xref="西番雅書 1:3; 以西結書 14:13; 耶利米書 12:3–4"> 我要擊打這城裡的居民和牲畜，使他們死於大瘟疫。</span>
<span className="v" id="v7" data-v="7" data-xref="耶利米書 37:17; 列王紀下 25:5–7; 哈巴谷書 1:6–10"> 然後，我要把猶大王西底迦及其臣僕以及城中逃過瘟疫、刀劍和饑荒的人都交給巴比倫王尼布甲尼撒，使他們落在尋索其命的仇敵手中。巴比倫王必殘酷無情地殺戮他們。這是耶和華說的。』</span>
<span className="v" id="v8" data-v="8" data-xref="申命記 30:19; 申命記 30:15; 申命記 11:26"> 「耶利米啊，你要告訴百姓，『耶和華說，看啊，我把生命之路和死亡之路擺在你們面前，</span>
<span className="v" id="v9" data-v="9" data-xref="耶利米書 38:2; 耶利米書 45:5; 耶利米書 39:18"> 留在這城裡的必死於刀劍、饑荒和瘟疫，出城向迦勒底人投降的必保全性命、逃過一死。</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米書 44:11; 阿摩司書 9:4; 耶利米書 44:27"> 我必嚴懲這城，向它降禍不降福。它必落在巴比倫王手中，被付之一炬。這是耶和華說的。』</span>
<span className="v" id="v11" data-v="11" data-xref="耶利米書 17:20; 彌迦書 3:1; 耶利米書 13:18"> 「你要對猶大的王室說，『你們要聽耶和華的話。</span>
<span className="v" id="v12" data-v="12" data-xref="以賽亞書 1:17; 箴言 31:8–9; 耶利米書 4:4"> 大衛家啊，耶和華說，<br /><span className="pl pl-1">「『你們要天天秉公行義，</span><br /><span className="pl pl-1">從壓迫者手中解救受剝削的人，</span><br /><span className="pl pl-1">免得你們的惡行激起我的怒火，</span><br /><span className="pl pl-1">如烈焰燃起，無人能滅。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="以西結書 13:8; 耶利米哀歌 4:12; 俄巴底亞書 1:3–4"> <span className="pl pl-1">耶路撒冷啊，</span><br /><span className="pl pl-1">你座落在山谷之上，</span><br /><span className="pl pl-1">如平原的磐石，</span><br /><span className="pl pl-1">自以為無人能攻擊你，</span><br /><span className="pl pl-1">無人能闖入你的住處，</span><br /><span className="pl pl-1">但我要攻擊你，</span><br /><span className="pl pl-1">這是耶和華說的。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="以賽亞書 3:10–11; 耶利米書 32:19; 箴言 1:31"> <span className="pl pl-1">我要照你的所作所為懲罰你；</span><br /><span className="pl pl-1">我要點燃你的樹林，</span><br /><span className="pl pl-1">燒光你周圍的一切。</span><br /><span className="pl pl-1">這是耶和華說的。』」</span></span>

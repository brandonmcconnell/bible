## 耶利米被捕

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歷代志下 36:4–5; 耶利米書 27:1; 列王紀下 23:34–36"> 約西亞的兒子猶大王約雅敬執政初期，耶和華對耶利米說：</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 4:2; 使徒行傳 20:27; 馬太福音 28:20"> 「這是耶和華說的：你要站在我殿的院子裡，把我吩咐你的話一字不漏地告訴從猶大各城前來敬拜的人。</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米書 36:3; 以賽亞書 1:16–19; 耶利米書 18:7–10"> 或許他們都會聽從我的話，改邪歸正，那樣我會施憐憫，取消原本用來懲治他們罪惡的災禍。</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀上 9:6; 耶利米書 44:10; 以賽亞書 1:20"> 你要告訴他們，耶和華這樣說，『如果你們不聽從我的話，不遵行我給你們設立的律法，</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米書 11:7; 列王紀下 9:7; 耶利米書 7:13"> 不聽從我差遣我的僕人——眾先知屢次傳給你們的話，</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米書 24:9; 列王紀下 22:19; 耶利米書 25:18"> 我必使這殿像示羅一樣被毀，使耶路撒冷被萬國咒詛。』」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="耶利米書 5:31; 彌迦書 3:11; 使徒行傳 5:17"> 祭司、先知和民眾都聽見了耶利米在耶和華的殿裡說的這些話。</span>
<span className="v" id="v8" data-v="8" data-xref="耶利米哀歌 4:13–14; 使徒行傳 7:52; 耶利米書 18:18"> 耶利米向民眾傳達完耶和華的話之後，祭司、先知和民眾就抓住他，說：「你真該死！</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行傳 4:17–19; 使徒行傳 19:24–32; 彌迦書 2:6"> 你為什麼奉耶和華的名預言這殿必像示羅一樣被毀，這城必要荒無人煙呢？」於是，他們聚在耶和華的殿裡圍住耶利米。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="耶利米書 36:10; 耶利米書 38:4–6; 耶利米書 37:14–16"> 猶大的官員得知後，就離開王宮，上到耶和華的殿，坐在耶和華殿新門的入口。</span>
<span className="v" id="v11" data-v="11" data-xref="耶利米書 38:4; 馬太福音 26:66; 申命記 18:20"> 祭司和先知對官員和民眾說：「這人該被處死！因為他預言這城要被毀，這是你們親耳聽到的。」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="使徒行傳 5:29; 耶利米書 26:15; 使徒行傳 4:19"> 耶利米對官員和民眾說：「你們剛才聽見了耶和華差我對這殿和這城說的預言。</span>
<span className="v" id="v13" data-v="13" data-xref="約拿書 3:9; 約拿書 4:2; 以賽亞書 1:19"> 你們要改邪歸正，聽從你們上帝耶和華的話，這樣耶和華必施憐憫，取消祂宣佈要降給你們的災禍。</span>
<span className="v" id="v14" data-v="14" data-xref="約書亞記 9:25; 撒母耳記下 15:26; 耶利米書 38:5"> 至於我，我已落在你們手中，你們認為怎樣好就怎樣待我吧！</span>
<span className="v" id="v15" data-v="15" data-xref="民數記 35:33; 箴言 6:17; 馬太福音 26:25"> 不過，你們要確知，如果你們置我於死地，你們和這城及城中的居民必擔當濫殺無辜的罪，因為確實是耶和華派我來告訴你們這些預言的。」</span>
</div>
<div className="bp poetry">
<span className="v" id="v16" data-v="16" data-xref="使徒行傳 5:34–39; 使徒行傳 23:29; 使徒行傳 25:25"> 官員和民眾便對祭司和先知說：「這人不該被處死，因為他是奉我們上帝耶和華的名對我們說話。」</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行傳 5:34; 彌迦書 1:1"> 有幾個長老站起來對聚集的民眾說：</span>
<span className="v" id="v18" data-v="18" data-xref="彌迦書 1:1; 尼希米記 4:2; 撒迦利亞書 8:3"> 「猶大王希西迦執政期間，摩利沙人彌迦對猶大民眾預言說，<br /><span className="pl pl-1">「『萬軍之耶和華說錫安必被夷為平地，</span><br /><span className="pl pl-1">耶路撒冷必淪為廢墟，</span><br /><span className="pl pl-1">聖殿山必成為長滿荒林的高崗。』</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="彌迦書3·12。">a</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="出埃及記 32:14; 撒母耳記下 24:16; 以賽亞書 37:15–20"> 「但猶大王希西迦和猶大眾人並沒有處死他。希西迦敬畏耶和華，求祂開恩，耶和華就施憐憫，沒有把宣佈的災禍降給他們。若處死這人，我們就會大禍臨頭。」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="撒母耳記上 7:2; 約書亞記 9:17; 約書亞記 15:60"> 當時，基列·耶琳人示瑪雅的兒子烏利亞也奉耶和華的名預言這城和這地方將被毀，內容與耶利米說的一樣。</span>
<span className="v" id="v21" data-v="21" data-xref="馬太福音 10:23; 馬太福音 14:5; 耶利米書 36:26"> 約雅敬王及其官長臣僕聽見烏利亞的話，王就想處死他。烏利亞得知後，嚇得逃到埃及去了。</span>
<span className="v" id="v22" data-v="22" data-xref="耶利米書 36:12; 列王紀下 22:12; 列王紀下 22:14"> 約雅敬王便派亞革波的兒子以利拿單率隨從去埃及捉拿他。</span>
<span className="v" id="v23" data-v="23" data-xref="耶利米書 2:30; 啟示錄 11:7; 以西結書 19:6"> 他們把烏利亞從埃及押送到約雅敬王面前，王用刀殺了他，把屍首拋在平民的墳地中。</span>
<span className="v" id="v24" data-v="24" data-xref="耶利米書 40:5–7; 耶利米書 39:14; 耶利米書 1:18–19"> 不過，沙番的兒子亞希甘保護耶利米，他才沒被交給民眾處死。</span>
</div>
</div>

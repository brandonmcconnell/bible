## 聖殿講道

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華對耶利米說：</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米書 26:2; 啟示錄 3:22; 阿摩司書 7:16"> 「你站在耶和華殿的門口這樣宣告，『所有從這些門進殿敬拜耶和華的猶大人啊，你們要聽耶和華的話。</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米書 18:11; 耶利米書 26:13; 以賽亞書 1:16–19"> 以色列的上帝——萬軍之耶和華說，你們改過自新，我便讓你們在這裡安居。</span>
<span className="v" id="v4" data-v="4" data-xref="彌迦書 3:11; 馬太福音 3:9–10; 西番雅書 3:11"> 你們不要相信那些謊言，說這是耶和華的殿，這是耶和華的殿，這是耶和華的殿。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="列王紀上 6:12–13; 以賽亞書 1:19; 耶利米書 7:3"> 「『如果你們真正改過自新，彼此公平相待，</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及記 22:21–24; 撒迦利亞書 7:9–12; 耶利米書 13:10"> 不欺壓異鄉人和孤兒寡婦，不在這地方濫殺無辜，不拜其他神明自取毀滅，</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 4:40; 耶利米書 25:5; 耶利米書 3:18"> 我便讓你們在這塊我永遠賜給你們祖先的土地上安居。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="以賽亞書 28:15; 以西結書 13:6–16; 耶利米書 23:14–16"> 「『然而，你們竟相信那些空洞的謊言。</span>
<span className="v" id="v9" data-v="9" data-xref="耶利米書 7:6; 出埃及記 20:3; 雅各書 4:1–4"> 難道你們偷盜、謀殺、通姦、起假誓、向巴力獻祭、拜不認識的神明，</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米書 32:34; 以西結書 23:37; 以西結書 23:39"> 然後來到這用來敬拜我的殿，站在我面前說自己安全了，就以為可以繼續做可憎之事嗎？</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 19:45–46; 以賽亞書 56:7; 馬太福音 21:13"> 難道這用來敬拜我的殿在你們眼中竟成了賊窩嗎？這些事，我都看在眼裡。這是耶和華說的。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="約書亞記 18:1; 耶利米書 26:6; 撒母耳記上 4:10–11"> 「『你們去我曾選為我名所在之地的示羅，看看我是怎樣因我以色列子民的罪而懲罰那地方的。</span>
<span className="v" id="v13" data-v="13" data-xref="以賽亞書 65:12; 歷代志下 36:15–16; 耶利米書 7:25"> 我對你們的所作所為一再提出警告，你們卻充耳不聞；我呼喚你們，你們卻不回應。這是耶和華說的。</span>
<span className="v" id="v14" data-v="14" data-xref="詩篇 78:60; 列王紀下 25:9; 耶利米書 7:4"> 因此，我要像對待示羅一樣，對待你們所倚靠的這用來敬拜我的殿，對待我賜給你們和你們祖先的地方。</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米書 15:1; 列王紀下 17:23; 耶利米書 52:3"> 我要把你們從我面前趕走，好像從前趕走你們的弟兄以法蓮<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「以法蓮」此處指「北國以色列」。">a</a></sup>人一樣。』</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="耶利米書 11:14; 耶利米書 14:11–12; 耶利米書 15:1"> 「耶利米啊，不要為這些百姓禱告，不要替他們呼求禱告，不要為他們向我祈求，因為我必不聽。</span>
<span className="v" id="v17" data-v="17" data-xref="以西結書 8:6–18; 以西結書 14:23; 耶利米書 6:27"> 你沒有看見他們在猶大各城和耶路撒冷街道上所做的事嗎？</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米書 19:13; 耶利米書 44:17–19; 哥林多前書 10:22"> 孩子拾柴，父親點火，婦人揉麵做餅向天后獻祭，向其他神明奠酒，惹我發怒。</span>
<span className="v" id="v19" data-v="19" data-xref="耶利米書 20:11; 耶利米書 2:19; 但以理書 9:7–8"> 難道他們是在惹我發怒嗎？難道他們不是自害己身，自取羞辱嗎？這是耶和華說的。」</span>
<span className="v" id="v20" data-v="20" data-xref="耶利米書 42:18; 耶利米哀歌 2:3–5; 以賽亞書 42:25"> 因此，主耶和華說：「我要向這地方的人、牲畜、田野的樹木和地裡的出產發怒，發烈怒，如熊熊怒火，無法熄滅。」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="何西阿書 8:13; 耶利米書 6:20; 阿摩司書 5:21–23"> 以色列的上帝——萬軍之耶和華說：「你們把燔祭和其他祭物都拿去吃吧！</span>
<span className="v" id="v22" data-v="22" data-xref="何西阿書 6:6; 撒母耳記上 15:22; 詩篇 51:16–17"> 因為我把你們祖先帶出埃及的時候，並沒有吩咐他們獻燔祭或其他祭物，</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及記 15:26; 申命記 5:33; 出埃及記 19:5–6"> 只吩咐他們一件事，『你們要聽從我的話，我就做你們的上帝，你們做我的子民；你們遵行我的一切吩咐，就必蒙福。』</span>
<span className="v" id="v24" data-v="24" data-xref="詩篇 81:11–12; 耶利米書 8:5; 耶利米書 7:26"> 他們卻掩耳不聽，一意孤行，任意行惡，越來越壞。</span>
<span className="v" id="v25" data-v="25" data-xref="歷代志下 36:15; 耶利米書 25:4; 尼希米記 9:26"> 從你們的祖先離開埃及那天起，一直到今天，我日復一日地差遣我的僕人——眾先知到你們那裡，</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米書 16:12; 歷代志下 30:8; 耶利米書 7:24"> 但你們掩耳不聽，頑固不化，比你們的祖先更邪惡。</span>
</div>
<div className="bp poetry">
<span className="v" id="v27" data-v="27" data-xref="耶利米書 26:2; 耶利米書 1:7; 以賽亞書 65:12"> 「耶利米啊，你將這番話告訴他們，他們也不會聽；你向他們呼籲，他們也不會回應。</span>
<span className="v" id="v28" data-v="28" data-xref="以賽亞書 59:14–15; 箴言 1:7; 以賽亞書 1:4–5"> 你要對他們說，『這就是不聽他們上帝耶和華的話、不肯受管教的國民。忠信喪盡，他們已絕口不提。</span>
<span className="v" id="v29" data-v="29" data-xref="約伯記 1:20; 彌迦書 1:16; 耶利米書 6:30"> <span className="pl pl-1">「『你們要剪去頭髮扔掉，</span><br /><span className="pl pl-1">在光禿的山上唱哀歌，</span><br /><span className="pl pl-1">因為耶和華已棄絕這惹祂發怒的世代。』」</span></span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="耶利米書 32:34; 以西結書 7:20; 但以理書 9:27"> 耶和華說：「猶大人做了我視為邪惡的事，把可憎的偶像放在用來敬拜我的聖殿中，玷污了聖殿。</span>
<span className="v" id="v31" data-v="31" data-xref="列王紀下 23:10; 耶利米書 32:35; 利未記 18:21"> 他們在欣嫩子谷的陀斐特建造邱壇，焚燒自己的兒女。我從未吩咐他們這樣做，連想都沒想過。</span>
<span className="v" id="v32" data-v="32" data-xref="耶利米書 19:11; 耶利米書 19:6; 列王紀下 23:10"> 因此，看啊，時候將到，那地方必不再叫陀斐特或欣嫩子谷，而要叫殺戮谷。他們要在那裡埋葬死人，直到無處可埋。這是耶和華說的。</span>
<span className="v" id="v33" data-v="33" data-xref="耶利米書 12:9; 申命記 28:26; 啟示錄 19:17–18"> 飛禽走獸必吃這百姓的屍體，無人驅趕牠們。</span>
<span className="v" id="v34" data-v="34" data-xref="啟示錄 18:23; 何西阿書 2:11; 以西結書 26:13"> 我要使猶大各城和耶路撒冷街上的歡樂聲、新郎和新娘的歡笑聲全部消失，因為大地必荒涼。」</span>
</div>
</div>

## 呼籲背信的以色列悔改

<div className="bt">
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="列王紀下 17:7–17; 以西結書 16:31; 耶利米書 7:24"> 在約西亞王執政期間，耶和華對我說：「你看見背信的以色列所行的了嗎？她上到高山上、在綠樹下淫亂。</span>
<span className="v" id="v7" data-v="7" data-xref="以西結書 16:46; 何西阿書 6:1–4; 何西阿書 14:1"> 我以為她淫亂之後會回到我身邊，她卻執迷不悟。她不貞的妹妹猶大也看見了這事。</span>
<span className="v" id="v8" data-v="8" data-xref="申命記 24:1; 何西阿書 4:15–17; 以賽亞書 50:1"> 因為背信的以色列淫亂，我給她休書，把她休掉。她不貞的妹妹猶大卻不害怕，竟也去淫亂。</span>
<span className="v" id="v9" data-v="9" data-xref="耶利米書 2:27; 以賽亞書 57:6; 耶利米書 3:2"> 以色列對淫亂不以為然，竟與石頭木頭苟合，玷污了土地。</span>
<span className="v" id="v10" data-v="10" data-xref="何西阿書 7:14; 耶利米書 12:2; 歷代志下 34:33–18"> 儘管如此，她不貞的妹妹猶大只是假裝歸向我，並不誠心。這是耶和華說的。」</span>
</div>
<div className="bp poetry">
<span className="v" id="v11" data-v="11" data-xref="以西結書 23:11; 以西結書 16:51–52; 何西阿書 11:7"> 耶和華對我說：「背信的以色列比不貞的猶大罪過還輕。</span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 86:15; 以西結書 33:11; 申命記 4:29–31"> 你去向北方宣告，<br /><span className="pl pl-1">「『耶和華說，</span><br /><span className="pl pl-1">背信的以色列啊，回轉吧！</span><br /><span className="pl pl-1">我必不向你們發怒，</span><br /><span className="pl pl-1">因為我充滿慈愛，</span><br /><span className="pl pl-1">不會永遠懷怒。』</span><br /><span className="pl pl-1">這是耶和華說的。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="耶利米書 2:25; 耶利米書 3:6; 申命記 12:2"> <span className="pl pl-1">『你必須要承認自己的罪，</span><br /><span className="pl pl-1">承認背叛了你的上帝耶和華，</span><br /><span className="pl pl-1">在綠樹下祭拜各種外邦的神明，</span><br /><span className="pl pl-1">不聽從我的話。』</span><br /><span className="pl pl-1">這是耶和華說的。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="何西阿書 2:19–20; 耶利米書 2:19; 耶利米書 31:32"> <span className="pl pl-1">「『背信的子民啊，回轉吧！</span><br /><span className="pl pl-1">因為我是你們的主人</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「主人」或譯作「丈夫」。">a</a></sup><br /><span className="pl pl-1">。</span><br /><span className="pl pl-1">我要從你們中間選些人帶回錫安，</span><br /><span className="pl pl-1">每座城邑選一人，每個宗族選二人。』</span><br /><span className="pl pl-1">這是耶和華說的。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="耶利米書 23:4; 使徒行傳 20:28; 以弗所書 4:11–12"> 「『我要賜給你們合我心意的牧人，讓他們用知識與智慧牧養你們。</span>
<span className="v" id="v16" data-v="16" data-xref="以賽亞書 65:17; 阿摩司書 9:14–15; 以西結書 37:26"> 你們在地上繁衍昌盛的時候，人們不會再提及耶和華的約櫃，不會再把它放在心上，不會再想起它，不會再感到需要它，也不會再造一個。這是耶和華說的。</span>
<span className="v" id="v17" data-v="17" data-xref="以西結書 43:7; 彌迦書 4:1–5; 耶利米書 17:12"> 那時，耶路撒冷必被稱為「耶和華的寶座」，萬國都要聚集在耶路撒冷尊崇耶和華的名，不再執迷不悟地作惡。</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米書 31:8; 何西阿書 1:11; 阿摩司書 9:15"> 那時，猶大人必與以色列人一同從北方來到我賜給你們祖先作基業的地方。</span>
<span className="v" id="v19" data-v="19" data-xref="耶利米書 3:4; 耶利米書 31:9; 以賽亞書 63:16"> <span className="pl pl-1">「『我曾想，我多麼願意把你們當成我的兒女，</span><br /><span className="pl pl-1">賜給你們萬國中最肥美的土地。</span><br /><span className="pl pl-1">我原以為你們會叫我「父親」，</span><br /><span className="pl pl-1">再不離我而去。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="以賽亞書 48:8; 耶利米書 5:11; 何西阿書 5:7"> <span className="pl pl-1">然而，以色列家啊！</span><br /><span className="pl pl-1">你們竟對我不忠，</span><br /><span className="pl pl-1">就像不貞的妻子離開丈夫。</span><br /><span className="pl pl-1">這是耶和華說的。』」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v21" data-v="21" data-xref="哥林多後書 7:10; 耶利米書 31:9; 耶利米書 2:32"> <span className="pl pl-1">從光禿的山頭傳來聲音，</span><br /><span className="pl pl-1">是以色列子民哭泣呼求的聲音，</span><br /><span className="pl pl-1">因為他們走入歧途，</span><br /><span className="pl pl-1">忘掉了他們的上帝耶和華。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="何西阿書 14:1; 何西阿書 14:4; 撒迦利亞書 13:9"> <span className="pl pl-1">耶和華說：「背信的子民啊，</span><br /><span className="pl pl-1">歸來吧！</span><br /><span className="pl pl-1">我要醫治你們背信的病。」</span><br /><span className="pl pl-1">他們說：「是的，我們要到你面前，</span><br /><span className="pl pl-1">因為你是我們的上帝耶和華。</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="詩篇 121:1–2; 詩篇 3:8; 以賽亞書 12:2"> <span className="pl pl-1">在高山丘陵上狂歡、</span><br /><span className="pl pl-1">拜偶像真是枉然，</span><br /><span className="pl pl-1">唯有我們的上帝耶和華才能拯救以色列。</span></span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="何西阿書 9:10; 以西結書 16:63; 以西結書 16:61"> 「從我們年幼時，那些可恥的神像就吞噬了我們祖先辛苦得來的牛羊和兒女。</span>
<span className="v" id="v25" data-v="25" data-xref="耶利米書 22:21; 箴言 5:13; 以賽亞書 50:11"> 讓我們躺在自己的羞恥中，讓我們的恥辱遮蓋我們吧！因為我們和我們的祖先都得罪了我們的上帝耶和華，我們自幼至今一直沒有順服我們的上帝耶和華。」</span>

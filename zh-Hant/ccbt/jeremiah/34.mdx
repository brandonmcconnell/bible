## 給西底迦的警告

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="耶利米書 1:15; 但以理書 2:37–38; 列王紀下 25:1–9"> 巴比倫王尼布甲尼撒率領他的軍隊和他統治的各邦國攻打耶路撒冷及其周圍城邑時，耶和華對耶利米說：</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米書 21:10; 耶利米書 34:22; 耶利米書 37:8–10"> 「以色列的上帝耶和華這樣說，『你去告訴猶大王西底迦，以色列的上帝耶和華說：看啊，我要把這城交在巴比倫王的手中，他要將城付之一炬。</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米書 32:4; 耶利米書 21:7; 列王紀下 25:4–7"> 你必逃不出巴比倫王的手心，你必被抓，落入他手中。你必和巴比倫王面對面、眼對眼地說話，然後被帶到巴比倫。</span>
<span className="v" id="v4" data-v="4"> 猶大王西底迦啊！你要聽耶和華關於你的話。耶和華說：你必不會死在刀劍之下，</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米書 22:18; 歷代志下 16:14; 列王紀下 22:20"> 你必安然去世。人們必為你燒香，像為你的先王燒香一樣，他們必為你哀悼說，唉，我主啊！』這是我耶和華說的。」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="撒母耳記上 15:16–24; 撒母耳記上 3:18; 列王紀上 21:19"> 耶利米先知就在耶路撒冷把這番話告訴了猶大王西底迦。</span>
<span className="v" id="v7" data-v="7" data-xref="約書亞記 10:3; 耶利米書 4:5; 列王紀下 18:13–14"> 那時，巴比倫王的軍隊正攻打耶路撒冷以及猶大僅存的兩座堅城拉吉和亞西加。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="利未記 25:10; 列王紀下 23:2–3; 列王紀下 11:17"> 耶和華的話傳給耶利米之前，西底迦王與耶路撒冷的居民立約，宣佈釋放自己的奴隸。</span>
<span className="v" id="v9" data-v="9" data-xref="申命記 15:12; 利未記 25:39–46; 出埃及記 3:18"> 各人都要釋放自己的希伯來男女奴隸，誰都不應使自己的希伯來同胞做奴隸。</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米書 26:16; 耶利米書 26:10; 耶利米書 38:4"> 所有立約的首領和人民都答應守約，不再奴役他們。他們按約釋放了自己的男女奴隸。</span>
<span className="v" id="v11" data-v="11" data-xref="彼得後書 2:20–22; 箴言 26:11; 馬太福音 12:43–45"> 但事後他們卻反悔，抓回先前釋放的男女奴隸，再次奴役他們。</span>
<span className="v" id="v12" data-v="12"> 那時，耶和華對耶利米說：</span>
<span className="v" id="v13" data-v="13" data-xref="士師記 6:8; 約書亞記 24:17; 申命記 5:27"> 「以色列的上帝耶和華這樣說，『我曾帶領你們的祖先離開埃及，使他們不再受奴役，那時我與他們立約說，</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 15:12; 列王紀上 9:22; 列王紀下 17:13–14"> 如果你們的希伯來同胞賣身做你們的奴隸，服侍你們六年後，到第七年你們要給他們自由。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="申命記15·12。">a</a></sup>你們的祖先卻掩耳不聽。</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米書 34:8; 列王紀下 23:3; 尼希米記 10:29"> 不久前，你們回心轉意，做我視為正的事，釋放自己的同胞，並且在我的殿中當著我的面立了約。</span>
<span className="v" id="v16" data-v="16" data-xref="利未記 19:12; 出埃及記 20:7; 耶利米書 34:11"> 然而，你們卻反悔，各自抓回先前釋放的男女奴隸，再次奴役他們，褻瀆了我的名。</span>
<span className="v" id="v17" data-v="17" data-xref="馬太福音 7:2; 申命記 28:25; 加拉太書 6:7"> 因此耶和華說，既然你們不聽我的話，不給自己的同胞自由，看啊，我必給你們自由，使你們自由地死於刀劍、瘟疫和饑荒，使你們的遭遇令天下萬國驚懼。這是耶和華說的。</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 15:10; 創世記 15:17–18; 何西阿書 6:7"> 猶大與耶路撒冷的官員、宮廷侍臣、祭司和全體百姓曾把牛犢劈成兩半，從中間走過跟我立約，後來卻又違背跟我立的約，不守在我面前所立之約的規定，所以我必使他們的下場像他們劈開的牛犢一樣。</span>
<span className="v" id="v20" data-v="20" data-xref="耶利米書 7:33; 耶利米書 16:4; 耶利米書 19:7"> 我要把他們交在想殺他們的敵人手中，他們的屍體要成為飛禽走獸的食物。</span>
<span className="v" id="v21" data-v="21" data-xref="耶利米書 52:24–27; 耶利米書 39:6; 耶利米書 52:10"> 我要把猶大王西底迦及其官員交在想殺他們的敵人手中，交在剛撤軍的巴比倫王手中。</span>
<span className="v" id="v22" data-v="22" data-xref="耶利米書 9:11; 耶利米書 39:8; 耶利米書 39:1–2"> 看啊，我要吩咐他們回來攻佔這城，將它付之一炬，我要使猶大的城邑荒無人煙。這是耶和華說的。』」</span>
</div>
</div>

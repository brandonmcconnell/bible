## 兩個異象

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="阿摩司書 7:8; 阿摩司書 8:2; 撒迦利亞書 5:2"> 耶和華又對我說：「耶利米，你看見什麼？」我說：「我看見一根杏樹枝。」</span>
<span className="v" id="v12" data-v="12" data-xref="以西結書 12:28; 以西結書 12:25; 以西結書 12:22–23"> 耶和華說：「你看的不錯。我必實現我說過的話。」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="以西結書 11:3; 以西結書 11:7; 撒迦利亞書 4:2"> 耶和華又對我說：「你看見什麼？」我回答說：「我看見一鍋煮沸的水，從北方傾倒下來。」</span>
<span className="v" id="v14" data-v="14" data-xref="以賽亞書 41:25; 耶利米書 4:6; 耶利米書 10:22"> 耶和華說：「必有災禍要從北方降臨到這地方的一切居民。</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米書 43:10; 耶利米書 25:9; 耶利米書 9:11"> 我要召來北方各國之民，他們要在耶路撒冷的城門口設寶座，攻打耶路撒冷周圍的城牆和猶大各城邑。這是耶和華說的。</span>
<span className="v" id="v16" data-v="16" data-xref="耶利米書 7:9; 耶利米書 19:4; 使徒行傳 7:41"> 我要審判我的子民，因為他們犯罪作惡，背棄我，給其他神明燒香，又祭拜自己製造的神像。</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米書 1:7–8; 列王紀上 18:46; 彼得前書 1:13"> 現在，你要做好準備，去把我吩咐你的話都告訴他們。不要懼怕他們，不然我將使你在他們面前充滿恐懼。</span>
<span className="v" id="v18" data-v="18" data-xref="以賽亞書 50:7; 以西結書 3:8–9; 耶利米書 15:20"> 看啊，今天我已使你成為堅城、鐵柱、銅牆，來對抗整個猶大，對抗猶大的君王、首領、祭司和眾民。</span>
<span className="v" id="v19" data-v="19" data-xref="約書亞記 1:9; 耶利米書 1:8; 耶利米書 20:11"> 他們必攻擊你，但絕不能勝過你，因為我與你同在，我必拯救你。這是耶和華說的。」</span>

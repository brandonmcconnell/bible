## 關於摩押的預言

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="民數記 32:3; 民數記 32:37–38; 耶利米書 48:22–23"> 關於摩押，以色列的上帝——萬軍之耶和華說：<br /><span className="pl pl-1">「尼波大禍臨頭了！</span><br /><span className="pl pl-1">它必被毀滅；</span><br /><span className="pl pl-1">基列亭必蒙羞淪陷，</span><br /><span className="pl pl-1">堡壘必蒙羞被毀。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="民數記 32:37; 耶利米書 31:36; 以賽亞書 16:14"> <span className="pl pl-1">摩押不再受稱讚，</span><br /><span className="pl pl-1">敵人在希實本圖謀害她，說，</span><br /><span className="pl pl-1">『來吧！我們剷除這個國家。』</span><br /><span className="pl pl-1">瑪得緬啊，你也將變得死寂無聲，</span><br /><span className="pl pl-1">刀劍必追殺你。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v3" data-v="3" data-xref="以賽亞書 15:5; 耶利米書 48:34; 耶利米書 48:5"> <span className="pl pl-1">「從何羅念傳來呼喊聲，</span><br /><span className="pl pl-1">『荒涼了！毀滅了！』</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="詩篇 137:9; 民數記 21:27–30; 以斯帖記 8:11"> <span className="pl pl-1">摩押滅亡了，</span><br /><span className="pl pl-1">她的孩童放聲哀哭。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="以賽亞書 15:5"> <span className="pl pl-1">摩押人痛哭著走上魯希坡，</span><br /><span className="pl pl-1">他們在何羅念的下坡聽見悲慘的哀號。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="耶利米書 17:6; 耶利米書 51:6; 約伯記 30:3–7"> <span className="pl pl-1">逃命吧！像灌木一樣藏到曠野去吧！</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="民數記 21:29; 耶利米書 9:23; 詩篇 52:7"> <span className="pl pl-1">摩押啊，你要被攻佔，</span><br /><span className="pl pl-1">因為你倚仗自己的成就和財富。</span><br /><span className="pl pl-1">你的神明基抹及供奉它的祭司和官長都要被擄去。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="耶利米書 6:26; 耶利米書 51:56; 耶利米書 25:9"> <span className="pl pl-1">毀滅者必攻擊每一座城邑，</span><br /><span className="pl pl-1">無一倖免；</span><br /><span className="pl pl-1">山谷遭踐踏，</span><br /><span className="pl pl-1">平原被毀壞，</span><br /><span className="pl pl-1">正如耶和華所說的。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="詩篇 11:1; 耶利米書 48:28; 以賽亞書 16:2"> <span className="pl pl-1">「給摩押翅膀讓她飛走吧</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「給摩押翅膀讓她飛走吧，」或譯作「給摩押豎起墓碑吧，因為她將被毀滅」或「在摩押撒鹽吧，因為她將被毀滅」。">a</a></sup><br /><span className="pl pl-1">，</span><br /><span className="pl pl-1">因為她的城邑將淪為廢墟，</span><br /><span className="pl pl-1">杳無人跡。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳記上 15:3; 列王紀上 20:42; 士師記 5:23"> <span className="pl pl-1">不殷勤地為耶和華做工，</span><br /><span className="pl pl-1">不揮刀斬殺摩押人的必受咒詛。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v11" data-v="11" data-xref="西番雅書 1:12; 撒迦利亞書 1:15; 耶利米書 48:29"> <span className="pl pl-1">「摩押自幼常享安逸，</span><br /><span className="pl pl-1">從未被擄到別處，</span><br /><span className="pl pl-1">好像沉澱的酒沒有被從這缸倒到那缸，</span><br /><span className="pl pl-1">味道依舊，香氣未變。</span></span>
<span className="v" id="v12" data-v="12" data-xref="那鴻書 2:2; 以賽亞書 30:14; 以西結書 25:9–10"> 「不過，看啊，時候將到，我要派倒酒的人去把她倒出來，倒空酒缸，把缸打碎。這是耶和華說的。</span>
<span className="v" id="v13" data-v="13" data-xref="以賽亞書 45:16; 士師記 11:24; 耶利米書 48:39"> 摩押人必因他們的神明基抹而羞愧，就像以色列人因信靠伯特利的神像而羞愧一樣。</span>
<span className="v" id="v14" data-v="14" data-xref="詩篇 33:16; 以賽亞書 10:13; 以賽亞書 10:16"> <span className="pl pl-1">「摩押人啊，</span><br /><span className="pl pl-1">你們怎能自稱為驍勇善戰的英雄呢？</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="耶利米書 50:27; 耶利米書 46:18; 耶利米書 51:57"> <span className="pl pl-1">摩押要滅亡了，</span><br /><span className="pl pl-1">她的城邑要被摧毀，</span><br /><span className="pl pl-1">她最勇敢的青年將被殺戮。</span><br /><span className="pl pl-1">這是名叫萬軍之耶和華的君王說的。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="以賽亞書 13:22; 耶利米書 1:12; 以西結書 12:28"> <span className="pl pl-1">摩押快要被毀滅了，</span><br /><span className="pl pl-1">她的災難就要來臨。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="以賽亞書 9:4; 以賽亞書 14:4–5; 以西結書 19:11–14"> <span className="pl pl-1">她的近鄰和知道她名望的人啊，</span><br /><span className="pl pl-1">你們都要為她哀悼，</span><br /><span className="pl pl-1">『那強大、輝煌的權勢竟然崩潰了！』</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v18" data-v="18" data-xref="民數記 21:30; 以賽亞書 47:1; 以賽亞書 15:2"> <span className="pl pl-1">「底本的居民啊，</span><br /><span className="pl pl-1">你們要從榮耀的位子上下來，</span><br /><span className="pl pl-1">坐在乾旱的地上，</span><br /><span className="pl pl-1">因為毀滅摩押的要來攻擊你們，</span><br /><span className="pl pl-1">摧毀你們的堡壘。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="申命記 2:36; 撒母耳記上 4:16; 撒母耳記上 4:13–14"> <span className="pl pl-1">亞羅珥的居民啊！</span><br /><span className="pl pl-1">你們要站在路旁觀望，</span><br /><span className="pl pl-1">詢問逃難的男女究竟發生了什麼事。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="以賽亞書 16:2; 民數記 21:26–28; 申命記 2:36"> <span className="pl pl-1">你們會得知摩押淪陷了，</span><br /><span className="pl pl-1">她羞愧難當。</span><br /><span className="pl pl-1">你們哀傷痛哭吧！</span><br /><span className="pl pl-1">你們要在亞嫩河邊宣告，</span><br /><span className="pl pl-1">『摩押被毀滅了！』</span></span>
<span className="v" id="v21" data-v="21" data-xref="約書亞記 13:18; 以賽亞書 15:4; 耶利米書 48:8"> 「審判降臨在平原上的何倫、雅雜、米法押、</span>
<span className="v" id="v22" data-v="22" data-xref="耶利米書 48:18; 民數記 33:46; 民數記 32:34"> 底本、尼波、伯·低比拉太音、</span>
<span className="v" id="v23" data-v="23" data-xref="約書亞記 13:17; 耶利米書 48:1; 民數記 32:38"> 基列亭、伯·迦末、伯·米恩、</span>
<span className="v" id="v24" data-v="24" data-xref="阿摩司書 2:2; 耶利米書 48:41; 約書亞記 21:36"> 加略、波斯拉等摩押遠近各地的城邑。</span>
<span className="v" id="v25" data-v="25" data-xref="詩篇 75:10; 詩篇 10:15; 撒迦利亞書 1:19–21"> 摩押的權勢被粉碎了，她的力量被摧毀了。這是耶和華說的。</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米書 48:42; 以賽亞書 29:9; 耶利米書 51:39"> 「你們要灌醉她，因為她藐視耶和華。她必在自己的嘔吐物中打滾，被人恥笑。</span>
<span className="v" id="v27" data-v="27" data-xref="耶利米書 2:26; 彌迦書 7:8–10; 西番雅書 2:8"> 摩押啊，你不是曾經嘲笑以色列嗎？以色列難道是強盜嗎？你每次談到她總是不屑地搖頭。</span>
<span className="v" id="v28" data-v="28" data-xref="詩篇 55:6–7; 士師記 6:2; 雅歌 2:14"> <span className="pl pl-1">「摩押人啊，</span><br /><span className="pl pl-1">你們要離開城邑，住到巖洞裡，</span><br /><span className="pl pl-1">像鴿子在巖縫裡築巢一樣。</span><br /></span>
<span className="v" id="v29" data-v="29" data-xref="以賽亞書 16:6; 詩篇 138:6; 以賽亞書 2:11–12"> <span className="pl pl-1">我們聽說摩押傲氣沖天，</span><br /><span className="pl pl-1">狂妄自大、心中高傲。</span><br /></span>
<span className="v" id="v30" data-v="30" data-xref="耶利米書 50:36; 以賽亞書 16:6; 以賽亞書 37:28–29"> <span className="pl pl-1">我知道摩押的狂傲不過是外強中乾，</span><br /><span className="pl pl-1">她的誇耀不過是虛張聲勢。</span><br /><span className="pl pl-1">這是耶和華說的。</span><br /></span>
<span className="v" id="v31" data-v="31" data-xref="以賽亞書 15:5; 列王紀下 3:25; 耶利米書 48:36"> <span className="pl pl-1">因此，我要為她哀號，</span><br /><span className="pl pl-1">為摩押人痛哭，</span><br /><span className="pl pl-1">為吉珥·哈列設人悲傷。</span><br /></span>
<span className="v" id="v32" data-v="32" data-xref="以賽亞書 16:8–9; 民數記 21:32; 約書亞記 13:19"> <span className="pl pl-1">西比瑪的葡萄樹啊，</span><br /><span className="pl pl-1">我為你比為雅謝人哭得更悲痛！</span><br /><span className="pl pl-1">你的枝條雖然延伸到大海，</span><br /><span className="pl pl-1">一直到雅謝，</span><br /><span className="pl pl-1">但毀滅者已在蹂躪你夏日的果子和葡萄！</span><br /></span>
<span className="v" id="v33" data-v="33" data-xref="以賽亞書 5:10; 哈該書 2:16; 耶利米書 25:9–10"> <span className="pl pl-1">摩押的沃土上再沒有歡喜快樂的聲音。</span><br /><span className="pl pl-1">我使榨酒池不出酒，</span><br /><span className="pl pl-1">再沒有踩踏葡萄的歡呼聲，</span><br /><span className="pl pl-1">歡呼被吶喊取代。</span></span>
<span className="v" id="v34" data-v="34" data-xref="以賽亞書 15:4–6; 民數記 32:3; 申命記 34:3"> 「哀哭聲從希實本傳到以利亞利和雅雜，又從瑣珥傳到何羅念和伊基拉·施利施亞，因為連寧林的水也乾涸了。」</span>
<span className="v" id="v35" data-v="35" data-xref="以賽亞書 15:2; 以賽亞書 16:12; 民數記 28:14"> 耶和華說：「我要滅絕摩押那些在邱壇獻祭和向他們神明燒香的人。</span>
<span className="v" id="v36" data-v="36" data-xref="以賽亞書 15:7; 以賽亞書 16:11; 以賽亞書 15:5"> 我的心為摩押悲鳴，好像淒涼的簫聲；我的心為吉珥·哈列設人悲鳴，好像淒涼的簫聲。他們的一切財富都消失了。</span>
<span className="v" id="v37" data-v="37" data-xref="耶利米書 41:5; 創世記 37:34; 耶利米書 47:5"> 他們都悲哀地剃去髮鬚，割傷雙手，腰束麻布。</span>
<span className="v" id="v38" data-v="38" data-xref="耶利米書 22:28; 耶利米書 25:34; 以賽亞書 22:1"> 在摩押境內的屋頂和街頭巷尾，哀聲處處可聞，因為我已把摩押打得粉碎，好像打碎沒人要的器皿。這是耶和華說的。</span>
<span className="v" id="v39" data-v="39" data-xref="以賽亞書 20:4–6; 耶利米哀歌 4:1; 耶利米哀歌 2:1"> 摩押破碎不堪！她嚎啕痛哭，羞愧難當，令四圍的人嗤笑、驚懼。」</span>
<span className="v" id="v40" data-v="40" data-xref="以賽亞書 8:8; 申命記 28:49; 耶利米書 49:22"> 耶和華說：<br /><span className="pl pl-1">「看啊，敵人必像展翅疾飛的大鷹一樣來攻擊摩押。</span><br /></span>
<span className="v" id="v41" data-v="41" data-xref="以賽亞書 21:3; 以賽亞書 13:8; 彌迦書 4:9–10"> <span className="pl pl-1">他們要攻取城池，佔領堡壘。</span><br /><span className="pl pl-1">那時，摩押的勇士像臨盆的婦人一樣心驚膽戰。</span><br /></span>
<span className="v" id="v42" data-v="42" data-xref="耶利米書 48:2; 以賽亞書 7:8; 以賽亞書 37:23"> <span className="pl pl-1">摩押必被摧毀，最後亡國，</span><br /><span className="pl pl-1">因為她藐視耶和華。</span><br /></span>
<span className="v" id="v43" data-v="43" data-xref="耶利米哀歌 3:47; 以賽亞書 24:17–18; 申命記 32:23–25"> <span className="pl pl-1">摩押人啊！</span><br /><span className="pl pl-1">你們要充滿恐懼，</span><br /><span className="pl pl-1">陷入深坑和網羅。</span><br /><span className="pl pl-1">這是耶和華說的。</span><br /></span>
<span className="v" id="v44" data-v="44" data-xref="耶利米書 11:23; 列王紀上 19:17; 耶利米書 46:21"> <span className="pl pl-1">逃過驚恐的必落入深坑，</span><br /><span className="pl pl-1">爬出深坑的必陷入網羅，</span><br /><span className="pl pl-1">因為我懲罰摩押的時候到了。</span><br /><span className="pl pl-1">這是耶和華說的。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v45" data-v="45" data-xref="民數記 24:17; 民數記 21:28; 撒迦利亞書 10:4"> <span className="pl pl-1">「在希實本的蔭影下，</span><br /><span className="pl pl-1">逃難的人無助地站著，</span><br /><span className="pl pl-1">因為希實本烈焰熊熊，</span><br /><span className="pl pl-1">西宏的城火光沖天，</span><br /><span className="pl pl-1">燒毀了摩押和其中的叛逆之人。</span><br /></span>
<span className="v" id="v46" data-v="46" data-xref="民數記 21:29; 耶利米書 48:7; 士師記 11:24"> <span className="pl pl-1">摩押人啊，你們有禍了！</span><br /><span className="pl pl-1">拜基抹神明的人滅亡了！</span><br /><span className="pl pl-1">你們的兒女都被擄去了。</span><br /></span>

## 耶路撒冷淪陷

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西結書 24:1–2; 耶利米書 52:4–7; 列王紀下 25:1–12"> 猶大王西底迦執政第九年十月，巴比倫王尼布甲尼撒率領全軍包圍耶路撒冷。</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米書 52:6–7; 彌迦書 2:12–13; 列王紀下 25:3–4"> 西底迦執政第十一年四月九日，耶路撒冷淪陷。</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米書 21:4; 耶利米書 38:17; 耶利米書 39:13"> 尼甲·沙利薛、三甲·尼波、撒西金和另一個尼甲·沙利薛等巴比倫王的所有官長都進城坐在中門。</span>
<span className="v" id="v4" data-v="4" data-xref="阿摩司書 2:14; 歷代志下 32:5; 列王紀下 25:4–7"> 猶大王西底迦和所有軍兵見勢不妙，便在夜間穿過御花園，從兩城牆中間的門逃往亞拉巴。</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀下 23:33; 約書亞記 5:10; 耶利米書 52:26–27"> 但迦勒底的軍隊追趕他們，在耶利哥平原追上並擒住西底迦，把他押到哈馬的利比拉去見巴比倫王尼布甲尼撒，在那裡接受王的審判。</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米書 52:10; 耶利米書 34:19–21; 耶利米書 24:8–10"> 巴比倫王在利比拉當著西底迦的面殺了他的眾子和猶大所有的貴族，</span>
<span className="v" id="v7" data-v="7" data-xref="以西結書 12:13; 列王紀下 25:7; 耶利米書 52:11"> 又剜去他的雙眼，把他用銅鏈鎖著押往巴比倫。</span>
<span className="v" id="v8" data-v="8" data-xref="尼希米記 1:3; 耶利米書 38:18; 耶利米書 21:10"> 迦勒底人放火焚燒王宮和民居，拆毀耶路撒冷的城牆。</span>
<span className="v" id="v9" data-v="9" data-xref="耶利米書 40:1; 創世記 37:36; 耶利米書 10:18"> 護衛長尼布撒拉旦把城中的餘民以及投降的人都擄到巴比倫，</span>
<span className="v" id="v10" data-v="10" data-xref="列王紀下 25:12; 耶利米書 40:7; 耶利米書 52:16"> 卻讓那些一貧如洗的窮人留在猶大，將葡萄園和田地分給他們。</span>
</div>
</div>

## 耶利米獲釋

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="使徒行傳 24:23; 耶利米書 15:21; 約伯記 5:19"> 至於耶利米，巴比倫王尼布甲尼撒吩咐護衛長尼布撒拉旦：</span>
<span className="v" id="v12" data-v="12" data-xref="箴言 16:7; 耶利米書 40:4; 箴言 21:1"> 「你把耶利米帶去好好照顧，切不可傷害他。他有什麼要求，你都要滿足。」</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米書 39:3; 耶利米書 39:9"> 於是，護衛長尼布撒拉旦、尼布沙斯班、尼甲·沙利薛等巴比倫王的所有將領，</span>
<span className="v" id="v14" data-v="14" data-xref="耶利米書 38:28; 列王紀下 22:12; 耶利米書 26:24"> 便派人把耶利米從護衛的院子提出來，讓沙番的孫子、亞希甘的兒子基大利帶他回家。從此，耶利米就生活在百姓當中。</span>
<span className="v" id="v15" data-v="15" data-xref="提摩太後書 2:9; 耶利米書 32:1–2; 耶利米書 36:1–5"> 耶利米被監禁在護衛院子裡的時候，耶和華對他說：</span>
<span className="v" id="v16" data-v="16" data-xref="但以理書 9:12; 撒迦利亞書 1:6; 約書亞記 23:14–15"> 「你去告訴古實人以伯·米勒，以色列的上帝——萬軍之耶和華說，『看啊，我必照我說的使這城遭受災禍，得不到祝福。你必親眼看見這一切發生。』</span>
<span className="v" id="v17" data-v="17" data-xref="詩篇 41:1–2; 詩篇 91:14–15; 詩篇 50:15"> 耶和華說，『但那時，我必拯救你，使你不致落在你所懼怕的人手中。</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米書 38:2; 詩篇 34:22; 耶利米書 21:9"> 我必拯救你，使你保全性命，不致喪身刀下，因為你信靠我。這是耶和華說的。』」</span>

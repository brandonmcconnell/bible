## 猶大的罪與罰

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="箴言 3:3; 哥林多後書 3:3; 箴言 7:3"> 「猶大人的罪是用鐵筆記錄的，用鑽石鐫刻的，寫在了他們心坎上和祭壇角上。</span>
<span className="v" id="v2" data-v="2" data-xref="歷代志下 24:18; 耶利米書 2:20; 士師記 3:7"> 他們的兒女念念不忘他們在綠樹下、高崗上和山野間的祭壇和亞舍拉神像。因為他們境內罪惡氾濫，我必使敵人擄掠他們的財寶和邱壇。</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米書 15:14; 耶利米哀歌 5:2; 以賽亞書 5:25"> 他們必失去我賜給他們的產業，被敵人擄到陌生的異鄉做奴隸，因為他們激起了我的怒火，永難熄滅。」</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 118:8–9; 詩篇 146:3–4; 以賽亞書 2:22"> <span className="pl pl-1">耶和華說：</span><br /><span className="pl pl-1">「信靠世人、倚靠血肉之軀、</span><br /><span className="pl pl-1">心中背叛耶和華的人該受咒詛！</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="約伯記 20:17; 申命記 29:23; 詩篇 1:4"> <span className="pl pl-1">這樣的人毫無福樂，</span><br /><span className="pl pl-1">像沙漠中的灌木。</span><br /><span className="pl pl-1">他要住在曠野的乾旱之處，</span><br /><span className="pl pl-1">住在無人的鹽鹼地。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="以賽亞書 26:3–4; 詩篇 34:8; 詩篇 40:4"> <span className="pl pl-1">信靠耶和華、倚靠耶和華的人有福了！</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 1:3; 以賽亞書 58:11; 以西結書 47:12"> <span className="pl pl-1">這樣的人像一棵栽在水邊的樹，</span><br /><span className="pl pl-1">根扎入溪水旁，</span><br /><span className="pl pl-1">不怕炎熱，不怕乾旱，</span><br /><span className="pl pl-1">綠葉如蔭，不斷結果。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="馬可福音 7:21–22; 馬太福音 15:19; 傳道書 9:3"> <span className="pl pl-1">「人心比什麼都詭詐，</span><br /><span className="pl pl-1">無可救藥，</span><br /><span className="pl pl-1">誰能識透呢？</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳記上 16:7; 羅馬書 8:27; 耶利米書 11:20"> <span className="pl pl-1">我耶和華鑒察人心，</span><br /><span className="pl pl-1">察看人的意念，</span><br /><span className="pl pl-1">按照各人的所作所為報應人。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v11" data-v="11" data-xref="箴言 28:20; 箴言 21:6; 耶利米書 22:17"> <span className="pl pl-1">謀取不義之財的人就像孵其他鳥蛋的鷓鴣，</span><br /><span className="pl pl-1">他中年便會失去不義之財，</span><br /><span className="pl pl-1">最後成了愚昧之人。</span></span>

## 遵守安息日

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="耶利米書 7:2; 耶利米書 26:2; 使徒行傳 5:20"> 耶和華對我說：「你去站在猶大君王出入的人民門門口和耶路撒冷的各城門口，</span>
<span className="v" id="v20" data-v="20" data-xref="耶利米書 19:3; 耶利米書 22:2; 詩篇 49:1–2"> 向他們宣告，『從這些城門進出的猶大君王、所有百姓以及耶路撒冷的居民啊，你們都要聽耶和華的話。</span>
<span className="v" id="v21" data-v="21" data-xref="尼希米記 13:15–21; 民數記 15:32–36; 約翰福音 5:9–12"> 耶和華說，如果你們想保住性命，就要小心，不要在安息日帶貨物進耶路撒冷的城門，</span>
<span className="v" id="v22" data-v="22" data-xref="以西結書 20:12; 出埃及記 20:8–10; 以賽亞書 58:13"> 也不要從家中運出貨物，不要在安息日做任何工作。要按照我對你們祖先的吩咐守安息日為聖日。</span>
<span className="v" id="v23" data-v="23" data-xref="箴言 29:1; 耶利米書 11:10; 使徒行傳 7:51"> 然而，他們卻不理不聽，頑固不化，不肯聽從和受教。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="耶利米書 17:21–22; 申命記 11:13; 彼得後書 1:5–10"> 「『耶和華說，你們要留心聽我的話，在安息日不可運貨物進耶路撒冷的城門，不可做任何工作，要守安息日為聖日。</span>
<span className="v" id="v25" data-v="25" data-xref="耶利米書 22:4; 以賽亞書 9:7; 希伯來書 12:22"> 這樣，坐大衛寶座的君王及其官員必乘車騎馬和猶大人以及耶路撒冷的居民進入城門。這城必永遠有人居住。</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米書 33:13; 耶利米書 32:44; 撒迦利亞書 7:7"> 人們必帶著燔祭、平安祭、素祭、乳香和感恩祭從猶大的城邑、耶路撒冷四周、便雅憫地區、丘陵、山區和南地去耶和華的殿。</span>
<span className="v" id="v27" data-v="27" data-xref="列王紀下 25:9; 耶利米書 7:20; 耶利米書 21:14"> 但如果你們不聽我的話，不守安息日為聖日，仍在安息日運貨物進耶路撒冷的城門，我必在各城門點起無法撲滅的大火，燒毀耶路撒冷的宮殿。』」</span>
</div>

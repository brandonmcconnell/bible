## 耶利米陷在枯井裡

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="尼希米記 7:9; 以斯拉記 2:3; 使徒行傳 4:6–10"> 瑪坦的兒子示法提雅、巴施戶珥的兒子基大利、示利米雅的兒子猶甲、瑪基雅的兒子巴施戶珥聽見耶利米對眾人說：</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米書 39:18; 耶利米書 34:17; 耶利米書 45:5"> 「耶和華這樣說，『凡留在這城的，必死於刀劍、饑荒和瘟疫；凡出去向迦勒底人投降的，必保全性命，得以存活。』</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米書 21:10; 耶利米書 32:3–5"> 耶和華說，『這城必落在巴比倫王的軍隊手中，他們必攻佔這城。』」</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米書 26:11; 使徒行傳 16:20; 尼希米記 6:9"> 這幾位官長就對西底迦王說：「求你處死這人！因為他的話令這城的軍民士氣低落。這人不為人民著想，反要害他們。」</span>
<span className="v" id="v5" data-v="5" data-xref="約翰福音 19:12–16; 撒母耳記下 3:39; 撒母耳記下 19:22"> 西底迦王說：「你們可以隨意處置他，我不會阻止你們。」</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米書 37:21; 耶利米書 38:22; 耶利米書 37:16"> 於是，他們拿住耶利米，用繩子把他縋到王子瑪基雅的蓄水池裡。那池子在護衛的院子裡，池中沒有水，只有淤泥。耶利米就陷在淤泥中。</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 21:19; 阿摩司書 5:10; 耶利米書 29:2"> 那時，王正坐在便雅憫門口。宮廷侍臣古實人以伯·米勒聽說他們把耶利米囚在蓄水池裡，</span>
<span className="v" id="v8" data-v="8"> 便離開王宮，去對王說：</span>
<span className="v" id="v9" data-v="9" data-xref="耶利米書 37:21–6; 以斯帖記 7:4–6; 箴言 31:8–9"> 「我主我王啊！這些人對耶利米先知太狠毒了。他們把他扔在蓄水池裡，他必餓死在那裡，因為城中絕糧了。」</span>
<span className="v" id="v10" data-v="10" data-xref="箴言 21:1; 以斯帖記 8:7; 以斯帖記 5:2"> 於是，王吩咐古實人以伯·米勒率領三十人，趁耶利米先知還沒死，把他從池中救出來。</span>
<span className="v" id="v11" data-v="11"> 以伯·米勒帶著他的手下進入王宮，從庫房下面的房間拿了些碎布和破衣，用繩索縋到池底給耶利米，</span>
<span className="v" id="v12" data-v="12" data-xref="羅馬書 12:10; 以弗所書 4:32; 羅馬書 12:15"> 讓他把這些碎布和破衣放在腋下墊繩索。耶利米就照做了。</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米書 37:21; 使徒行傳 28:16; 使徒行傳 23:35"> 他們便用繩索把耶利米從池中拉上來。耶利米仍留在護衛的院子裡。</span>
</div>
</div>

## 西底迦王密會耶利米

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="耶利米書 37:17; 列王紀上 22:16; 耶利米書 21:1–2"> 西底迦王派人把耶利米先知帶到耶和華殿的第三道門那裡與他會面。他對耶利米說：「我要問你一件事，你不可有任何隱瞞。」</span>
<span className="v" id="v15" data-v="15" data-xref="路加福音 22:67–68"> 耶利米說：「我若從實稟告，你一定會殺我。我就是給你建議，你也不會聽。」</span>
<span className="v" id="v16" data-v="16" data-xref="耶利米書 37:17; 耶利米書 38:1–6; 以賽亞書 57:16"> 於是，他私下向耶利米發誓說：「我憑那賜給我們生命的永活的耶和華起誓，我決不殺你，也不把你交在想殺你的人手中。」</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米書 27:12; 耶利米書 27:17; 耶利米書 38:2"> 耶利米說：「以色列的上帝——萬軍之上帝耶和華說，『如果你出去向巴比倫王的將領投降，就可以保住你和你全家的性命，這城也不會被燒毀。</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米書 38:3; 耶利米書 24:8–10; 列王紀下 25:4–10"> 但如果你不出去向巴比倫王的將領投降，這城必落在迦勒底人手裡，被付之一炬，你也逃不掉。』」</span>
<span className="v" id="v19" data-v="19" data-xref="約翰福音 12:42; 耶利米書 38:22; 約翰福音 19:12–13"> 西底迦王說：「我害怕那些已經向迦勒底人投降的猶大人，恐怕迦勒底人會把我交給他們，任由他們羞辱。」</span>
<span className="v" id="v20" data-v="20" data-xref="但以理書 4:27; 以賽亞書 55:3; 耶利米書 26:13"> 耶利米說：「你不會被交給他們的。求你聽從耶和華吩咐我對你說的話，這樣你就可以平安無事，保全性命。</span>
<span className="v" id="v21" data-v="21" data-xref="以西結書 2:7; 以西結書 2:4–5; 耶利米書 26:15"> 如果你不肯投降，耶和華已讓我看到以下景象：</span>
<span className="v" id="v22" data-v="22" data-xref="耶利米書 43:6; 耶利米哀歌 1:2; 耶利米哀歌 5:11"> 所有留在猶大王宮的婦女都必被帶到巴比倫王的將領那裡，她們會對你說，『你被好友欺騙和左右，當你陷入泥潭時，他們就離棄了你。』</span>
<span className="v" id="v23" data-v="23" data-xref="耶利米書 41:10; 耶利米書 39:6; 耶利米書 38:18"> 「你的嬪妃和兒女必被交給迦勒底人，你也逃不掉，必被巴比倫王所擒。這城也要被付之一炬。」</span>
<span className="v" id="v24" data-v="24"> 西底迦說：「不可讓人知道我和你交談，否則你會喪命。</span>
<span className="v" id="v25" data-v="25" data-xref="耶利米書 38:27; 耶利米書 38:4–6"> 如果有官長聽說我和你交談，前來逼你說出我們談話的內容，否則就殺死你，</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米書 37:20; 耶利米書 37:15; 以斯帖記 4:8"> 你可以告訴他們，你是在求我不要把你押回約拿單的房子，以免死在那裡。」</span>
<span className="v" id="v27" data-v="27" data-xref="撒母耳記上 10:15–16; 列王紀下 6:19; 使徒行傳 23:6"> 果然，眾官長前來查問耶利米，他就照王的吩咐回覆他們，他們便不再追問，因為他跟王的談話無人知道。</span>
<span className="v" id="v28" data-v="28" data-xref="耶利米書 37:21; 耶利米書 39:14; 詩篇 23:4"> 耶利米被囚在護衛的院子裡，一直到耶路撒冷淪陷。</span>
</div>
</div>

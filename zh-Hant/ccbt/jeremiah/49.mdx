## 審判亞捫的預言

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="阿摩司書 1:13–15; 西番雅書 2:8–11; 以西結書 25:2–10"> 關於亞捫人，耶和華說：<br /><span className="pl pl-1">「難道以色列沒有子孫？</span><br /><span className="pl pl-1">沒有繼承人嗎？</span><br /><span className="pl pl-1">為什麼祭拜米勒公的人佔據了迦得，住在城邑中？」</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="耶利米書 4:19; 以西結書 21:20; 申命記 3:11"> <span className="pl pl-1">耶和華說：「看啊，時候將到，</span><br /><span className="pl pl-1">我要使亞捫人的拉巴城外響起戰爭的吶喊。</span><br /><span className="pl pl-1">拉巴必淪為廢墟，</span><br /><span className="pl pl-1">它周圍的鄉村都要被焚燒，</span><br /><span className="pl pl-1">以色列人必從侵略者手中收復失地。</span><br /><span className="pl pl-1">這是耶和華說的。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v3" data-v="3" data-xref="耶利米書 48:7; 耶利米書 48:37; 以賽亞書 15:2"> <span className="pl pl-1">「希實本啊，哀哭吧！</span><br /><span className="pl pl-1">因為艾城毀滅了。</span><br /><span className="pl pl-1">拉巴的居民啊，痛哭吧！</span><br /><span className="pl pl-1">披上麻衣悲傷地在城牆內跑來跑去吧！</span><br /><span className="pl pl-1">因為米勒公及其祭司和官長都要被擄走。</span><br /></span>

## 審判以東的預言

<div className="bt">
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="阿摩司書 1:11–12; 耶利米書 25:21; 創世記 36:15"> <span className="pl pl-1">關於以東，萬軍之耶和華說：</span><br /><span className="pl pl-1">「提幔再沒有智慧了嗎？</span><br /><span className="pl pl-1">謀士已無計可施了嗎？</span><br /><span className="pl pl-1">他們都失去智慧了嗎？</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="耶利米書 25:23; 耶利米書 46:21; 耶利米書 49:30"> <span className="pl pl-1">底但的居民啊，</span><br /><span className="pl pl-1">你們要轉身逃命，</span><br /><span className="pl pl-1">藏在深洞裡，</span><br /><span className="pl pl-1">因為我必在所定之時降災禍懲罰以掃。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="俄巴底亞書 1:5–6; 以賽亞書 17:6"> <span className="pl pl-1">人們到你那裡摘葡萄，難道不留下幾串嗎？</span><br /><span className="pl pl-1">盜賊夜間來偷東西，難道不只偷所需要的嗎？</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="以賽亞書 17:14; 瑪拉基書 1:3–4; 以賽亞書 45:3"> <span className="pl pl-1">但我要把以掃洗劫一空，</span><br /><span className="pl pl-1">我要使他無處藏身，無法隱藏。</span><br /><span className="pl pl-1">他及其孩子、弟兄和鄰居必一同滅亡。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 68:5; 何西阿書 14:3; 雅各書 1:27"> <span className="pl pl-1">撇下你的孤兒吧！</span><br /><span className="pl pl-1">我必使他們存活；</span><br /><span className="pl pl-1">你的寡婦也可以倚靠我。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="耶利米書 25:28–29; 俄巴底亞書 1:16; 耶利米書 25:15"> 耶和華說：「看啊，那些本不該喝這杯憤怒的人尚且要喝，更何況你呢？你必難逃懲罰，你一定要喝這杯憤怒。</span>
<span className="v" id="v13" data-v="13" data-xref="創世記 22:16; 以賽亞書 34:6; 創世記 36:33"> 因為我已憑自己起誓，波斯拉必淪為廢墟，令人驚駭，被人嘲笑和咒詛。它周圍的城邑要永遠荒涼。這是耶和華說的。」</span>
<span className="v" id="v14" data-v="14" data-xref="以賽亞書 30:4; 以賽亞書 37:7; 以西結書 7:25–26"> <span className="pl pl-1">我從耶和華那裡聽到消息，</span><br /><span className="pl pl-1">有位使者被派去對列國說：</span><br /><span className="pl pl-1">「聚集起來攻打以東，</span><br /><span className="pl pl-1">準備爭戰吧！」</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="路加福音 1:51; 俄巴底亞書 1:2; 彌迦書 7:10"> <span className="pl pl-1">耶和華說：</span><br /><span className="pl pl-1">「以東啊，我要使你在列國中最弱小，</span><br /><span className="pl pl-1">被世人藐視。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="以賽亞書 49:25; 阿摩司書 9:2; 約伯記 39:27"> <span className="pl pl-1">你這棲身在巖穴中、盤踞在高山上的民族啊，</span><br /><span className="pl pl-1">你令人驚懼、心高氣傲，</span><br /><span className="pl pl-1">其實只是自欺。</span><br /><span className="pl pl-1">儘管你像老鷹在高處搭窩，</span><br /><span className="pl pl-1">我也必把你拉下來。</span><br /><span className="pl pl-1">這是耶和華說的。</span></span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="以西結書 35:7; 耶利米書 50:13; 耶利米書 49:13"> 「以東的下場必令人驚駭，它的滿目瘡痍令所有路人驚駭和嗤笑。</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米書 49:33; 申命記 29:23; 耶利米書 50:40"> 那裡要像所多瑪、蛾摩拉及其周圍的城邑一樣被毀滅，人煙絕跡。這是耶和華說的。</span>
<span className="v" id="v19" data-v="19" data-xref="耶利米書 12:5; 耶利米書 30:21; 耶利米書 50:44–46"> 看啊，我必在瞬間把以東人趕離家園，如約旦河邊叢林中跳出的獅子趕散草場的羊群。我要派我揀選的人統治這地方。誰能與我相比？誰能與我較量？哪位首領能抵擋我？」</span>
<span className="v" id="v20" data-v="20" data-xref="耶利米書 50:45; 瑪拉基書 1:3–4; 耶利米書 49:7"> 因此，你們要聽聽耶和華攻擊以東的策略，聽聽祂攻擊提幔居民的計劃。他們的孩子要被拖走，他們的家園要被毀滅。</span>
<span className="v" id="v21" data-v="21" data-xref="耶利米書 50:46; 以西結書 32:10; 以賽亞書 14:4–15"> 以東傾覆的聲音震動大地，哭喊聲直傳到紅海。</span>
<span className="v" id="v22" data-v="22" data-xref="耶利米書 48:40–41; 何西阿書 8:1; 以賽亞書 13:8"> 看啊，敵人必像展翅飛來的鷹一樣衝下來攻擊波斯拉。到那日，以東的勇士必像臨盆的婦女一樣膽戰心驚。</span>
</div>
</div>

<span className="v" id="v25" data-v="25" data-xref="耶利米書 33:9; 耶利米書 51:41; 以賽亞書 1:26"> <span className="pl pl-1">我所喜悅的名城為何還沒有被撇棄？</span><br /></span>

<span className="v" id="v32" data-v="32" data-xref="耶利米書 9:26; 耶利米書 25:23; 耶利米書 49:36"> <span className="pl pl-1">他們的駱駝必被擄去，</span><br /><span className="pl pl-1">大群的牲畜必成為戰利品。</span><br /><span className="pl pl-1">我要把剃去鬢髮的人驅散到四方，</span><br /><span className="pl pl-1">使災禍從四面八方臨到他們。</span><br /><span className="pl pl-1">這是耶和華說的。</span><br /></span>

## 審判以攔的預言

<div className="bt">
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="創世記 10:22; 但以理書 8:2; 耶利米書 25:25"> 猶大王西底迦執政初期，耶和華告訴了耶利米先知有關以攔的事。</span>
<span className="v" id="v35" data-v="35" data-xref="以賽亞書 22:6; 耶利米書 51:56; 詩篇 46:9"> 萬軍之耶和華說：「看啊，我要摧毀以攔的弓箭手，那是他們的精銳之師。</span>
<span className="v" id="v36" data-v="36" data-xref="耶利米書 49:32; 啟示錄 7:1; 以西結書 5:10"> 我要使敵人從四面八方如風而來，把以攔人驅散到四方，使他們流落到列國。</span>
<span className="v" id="v37" data-v="37" data-xref="耶利米書 9:16; 耶利米書 48:2; 耶利米書 49:22"> 我要使以攔人在想殺他們的仇敵面前驚恐萬分，我要發烈怒降禍給他們，用刀劍追殺他們，直到徹底消滅他們。這是耶和華說的。</span>
<span className="v" id="v38" data-v="38" data-xref="耶利米書 43:10; 但以理書 7:9–14"> 我要在以攔設立我的寶座，消滅那裡的君王和官長。這是耶和華說的。</span>
<span className="v" id="v39" data-v="39" data-xref="耶利米書 48:47; 何西阿書 3:5; 彌迦書 4:1"> 但將來有一天，我要使被擄的以攔人返鄉。這是耶和華說的。」</span>
</div>

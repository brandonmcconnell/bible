## 耶利米警告猶大人勿去埃及

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="耶利米書 41:11; 耶利米書 40:13; 耶利米書 6:13"> 加利亞的兒子約哈難、何沙雅的兒子耶撒尼亞和其他將領及民眾，無論尊卑，都近前來，</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米書 36:7; 利未記 26:22; 使徒行傳 8:24"> 對耶利米先知說：「求你答應我們的懇求，為我們這些餘民向你的上帝耶和華禱告。你親眼看見了，我們本來人數眾多，現在卻寥寥無幾。</span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 86:11; 箴言 3:6; 詩篇 25:4–5"> 願你的上帝耶和華指示我們該去哪裡，該做什麼。」</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳記上 12:23; 撒母耳記上 3:17–18; 出埃及記 8:29"> 耶利米先知說：「好。我必照你們說的向你們的上帝耶和華禱告，並把祂的話毫不隱瞞地告訴你們。」</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 31:50; 士師記 11:10; 瑪拉基書 3:5"> 他們說：「倘若我們不照你的上帝耶和華派你傳給我們的一切話去做，願耶和華作信實可靠的證人指控我們！</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米書 7:23; 申命記 5:29; 羅馬書 8:7"> 我們派你去我們的上帝耶和華那裡，祂的話不論中聽不中聽，我們都願意聽從。我們若聽從祂的話，就必亨通。」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="詩篇 27:14; 以賽亞書 28:16; 哈巴谷書 2:3"> 十天之後，耶和華的話傳給了耶利米。</span>
<span className="v" id="v8" data-v="8" data-xref="耶利米書 42:1; 耶利米書 41:11–16; 耶利米書 43:2–5"> 耶利米便召集加利亞的兒子約哈難和眾將領及民眾，無論尊卑，</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀下 19:4; 耶利米書 42:2; 列王紀下 19:6"> 對他們說：「你們讓我替你們向以色列的上帝耶和華祈求，耶和華這樣說，</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米書 31:28; 以西結書 36:36; 耶利米書 24:6"> 『如果你們留在這地方，我必造就你們，決不毀滅你們；我必栽培你們，決不剷除你們。因為我為降在你們身上的災禍而難過。</span>
<span className="v" id="v11" data-v="11" data-xref="羅馬書 8:31; 耶利米書 1:19; 耶利米書 1:8"> 不要懼怕巴比倫王，不要怕他，因為我必與你們同在，拯救你們脫離他的權勢。這是耶和華說的。</span>
<span className="v" id="v12" data-v="12" data-xref="尼希米記 1:11; 詩篇 106:45–46; 箴言 16:7"> 我必憐憫你們，讓他也憐憫你們，使你們重歸故土。』</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米書 44:16; 出埃及記 5:2; 耶利米書 42:10"> 然而，如果你們不聽你們的上帝耶和華的話，不留在這地方，</span>
<span className="v" id="v14" data-v="14" data-xref="耶利米書 41:17; 耶利米書 4:19; 以賽亞書 31:1"> 非要去埃及住，以為那裡沒有戰爭，聽不見號角聲，也不會忍饑挨餓，</span>
<span className="v" id="v15" data-v="15" data-xref="申命記 17:16; 耶利米書 44:12–14; 耶利米書 42:17"> 那麼，你們這些猶大的餘民就要聽耶和華的話。以色列的上帝——萬軍之耶和華說，『如果你們決意去埃及住，</span>
<span className="v" id="v16" data-v="16" data-xref="耶利米書 44:27; 以西結書 11:8; 阿摩司書 9:1–4"> 你們所害怕的刀劍必追上你們，你們所懼怕的饑荒必緊緊地跟著你們到埃及。你們必死在那裡。</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米書 42:22; 耶利米書 44:28; 耶利米書 44:13–14"> 凡決意去埃及住的人必要死於刀劍、饑荒和瘟疫，無人能逃脫我降的災禍，倖存下來。』</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="耶利米書 7:20; 耶利米書 18:16; 耶利米書 29:18"> 「以色列的上帝——萬軍之耶和華說，『我曾把我的怒氣和烈怒傾倒在耶路撒冷人身上，如果你們去埃及，我也要把我的怒氣傾倒在你們身上。你們的下場將很可怕，被人責罵、咒詛和羞辱，再也見不到故土。』</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 17:16; 以賽亞書 30:1–7; 尼希米記 9:26"> 猶大的餘民啊，耶和華已告訴你們不要去埃及。別忘了我今日給你們的警告，</span>
<span className="v" id="v20" data-v="20" data-xref="以西結書 14:3–4; 以西結書 33:31; 馬太福音 22:15–18"> 你們是在自欺，因為原是你們請我去向你們的上帝耶和華禱告，讓我毫不隱瞞地把祂的話告訴你們，你們答應遵行。</span>
<span className="v" id="v21" data-v="21" data-xref="以西結書 2:7; 撒迦利亞書 7:11–12; 使徒行傳 20:26–27"> 今日，我把你們的上帝耶和華要我傳的話告訴你們，你們卻不聽從。</span>
<span className="v" id="v22" data-v="22" data-xref="耶利米書 42:17; 以西結書 6:11; 何西阿書 9:6"> 因此，你們要清楚知道，在你們想去居住的地方，你們必死於刀劍、饑荒和瘟疫。」</span>
</div>
</div>

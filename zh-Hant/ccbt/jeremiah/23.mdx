## 將來的盼望

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="耶利米書 10:21; 撒迦利亞書 11:15–17; 以西結書 34:2–10"> 耶和華說：「牧養我子民的首領有禍了！因為他們殘害、驅散我草場上的羊群。」</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 32:34; 耶利米書 21:12; 彌迦書 7:4"> 以色列的上帝耶和華這樣斥責那些牧養祂子民的首領：「你們驅散我的羊群，沒有照顧他們。看啊，我必因你們的惡行而懲罰你們。這是耶和華說的。</span>
<span className="v" id="v3" data-v="3" data-xref="阿摩司書 9:14–15; 耶利米書 32:37; 以賽亞書 43:5–6"> 我要把我倖存的子民從我流放他們去的各地召集起來，領他們回到故土，使他們生養眾多，人丁興旺。</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米書 3:14–15; 彼得前書 1:5; 以西結書 34:23–31"> 我要設立首領照顧他們，使他們不再擔驚受怕，也不再迷失。這是耶和華說的。」</span>
<span className="v" id="v5" data-v="5" data-xref="路加福音 1:32–33; 以賽亞書 4:2; 以賽亞書 9:7"> 耶和華說：「看啊，時候將到，我要為大衛興起一個公義的苗裔，使他執掌王權。他必秉公行義，治國有方。</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多前書 1:30; 耶利米書 33:16; 腓立比書 3:9"> 在他掌權的日子，猶大必得拯救，以色列必安享太平並被稱為『耶和華是我們的公義』。」</span>
<span className="v" id="v7" data-v="7" data-xref="耶利米書 16:14–15; 耶利米書 23:3; 以賽亞書 43:18–19"> 耶和華說：「看啊，時候將到，那時人不再憑把以色列人帶出埃及的耶和華起誓，</span>
<span className="v" id="v8" data-v="8" data-xref="以賽亞書 43:5–6; 阿摩司書 9:14–15; 以西結書 34:13"> 而是憑把他們從北方之地和流放的列國領回來的永活耶和華起誓。他們必在自己的國土上安居樂業。」</span>
<span className="v" id="v9" data-v="9" data-xref="哈巴谷書 3:16; 耶利米哀歌 3:15; 詩篇 60:3"> <span className="pl pl-1">談及那些先知，</span><br /><span className="pl pl-1">我的心都碎了，</span><br /><span className="pl pl-1">我的骨頭都顫抖。</span><br /><span className="pl pl-1">因為耶和華和祂聖言的緣故，</span><br /><span className="pl pl-1">我好像不勝酒力的醉漢。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="何西阿書 4:2–3; 詩篇 107:34; 耶利米書 9:2"> <span className="pl pl-1">這裡到處是不忠貞的人，</span><br /><span className="pl pl-1">他們行為邪惡，濫用權力。</span><br /><span className="pl pl-1">大地因受咒詛而悲哀，</span><br /><span className="pl pl-1">曠野的草場都枯乾了。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="西番雅書 3:4; 耶利米書 6:13; 馬太福音 21:12–13"> <span className="pl pl-1">耶和華說：「先知和祭司都不敬虔，</span><br /><span className="pl pl-1">我甚至看見他們在我的聖殿裡行惡。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="耶利米書 13:16; 耶利米書 11:23; 詩篇 35:6"> <span className="pl pl-1">因此，他們必被趕到黑暗中，</span><br /><span className="pl pl-1">在濕滑的路上跌倒，</span><br /><span className="pl pl-1">因為我必在他們受罰的日子降災禍給他們。</span><br /><span className="pl pl-1">這是耶和華說的。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="耶利米書 2:8; 以賽亞書 9:16; 列王紀上 18:18–21"> <span className="pl pl-1">我看見撒瑪利亞的先知行可憎之事，</span><br /><span className="pl pl-1">他們靠巴力說預言，</span><br /><span className="pl pl-1">引誘我的子民以色列走入歧途。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="以賽亞書 1:9–10; 耶利米書 29:23; 以西結書 22:25"> <span className="pl pl-1">我也看見耶路撒冷的先知行為可惡，</span><br /><span className="pl pl-1">他們通姦，謊話連篇，</span><br /><span className="pl pl-1">慫恿惡人，</span><br /><span className="pl pl-1">以致無人悔過自新。</span><br /><span className="pl pl-1">在我眼中，他們就像所多瑪人，耶路撒冷人像蛾摩拉人一樣敗壞。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="耶利米書 8:14; 耶利米書 9:15; 耶利米哀歌 3:5"> <span className="pl pl-1">因此，關於這些先知，萬軍之耶和華說，</span><br /><span className="pl pl-1">『看啊，我要使他們吃苦艾，</span><br /><span className="pl pl-1">喝毒水，因為褻瀆之風從耶路撒冷的先知那裡蔓延，</span><br /><span className="pl pl-1">遍及全境。』」</span></span>
<span className="v" id="v16" data-v="16" data-xref="耶利米書 14:14; 以西結書 13:6; 加拉太書 1:8–9"> 萬軍之耶和華對耶路撒冷人說：「你們不要聽信這些先知的預言，他們使你們充滿虛假的盼望，他們的預言是自己的想象，不是耶和華說的。</span>
<span className="v" id="v17" data-v="17" data-xref="彌迦書 3:11; 耶利米書 13:10; 阿摩司書 9:10"> 他們不斷對藐視我的人說，『耶和華說你們必安享太平。』他們對那些執迷不悟的人說，『災禍不會降到你們身上。』</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米書 23:22; 以賽亞書 40:13–14; 阿摩司書 3:7"> <span className="pl pl-1">「然而，他們誰曾站在耶和華面前看見並聽見祂說話呢？</span><br /><span className="pl pl-1">他們誰曾留心聽祂的話呢？</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="耶利米書 30:23; 耶利米書 25:32; 阿摩司書 1:14"> <span className="pl pl-1">看啊，耶和華的烈怒像暴風一樣襲來，</span><br /><span className="pl pl-1">像旋風一樣吹到惡人頭上。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="耶利米書 30:24; 以賽亞書 55:11; 撒迦利亞書 1:6"> <span className="pl pl-1">耶和華不完成祂心中的計劃決不息怒。</span><br /><span className="pl pl-1">將來你們會清楚地明白這一切。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v21" data-v="21" data-xref="耶利米書 14:14; 耶利米書 27:15; 耶利米書 23:32"> <span className="pl pl-1">「我沒有差遣這些先知，</span><br /><span className="pl pl-1">他們卻妄自行動；</span><br /><span className="pl pl-1">我沒有對他們說話，</span><br /><span className="pl pl-1">他們卻亂發預言。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="耶利米書 23:18; 撒迦利亞書 1:4; 耶利米書 25:5"> <span className="pl pl-1">他們若曾站在我面前聽我說話，</span><br /><span className="pl pl-1">早就向我的子民宣告我的話，</span><br /><span className="pl pl-1">使他們改邪歸正了。」</span></span>
<span className="v" id="v23" data-v="23" data-xref="詩篇 139:1–10; 列王紀上 20:23; 列王紀上 20:28"> 耶和華說：「我難道不是遠近無處不在的上帝？」</span>
<span className="v" id="v24" data-v="24" data-xref="箴言 15:3; 詩篇 139:7; 詩篇 90:8"> 耶和華說：「難道人藏在隱秘處我就看不見了嗎？我豈不是充滿天地嗎？這是耶和華說的。</span>
<span className="v" id="v25" data-v="25" data-xref="耶利米書 23:32; 耶利米書 23:28; 耶利米書 29:8"> 我已聽見這些先知奉我的名所說的假預言，他們說，『我做了個夢！我做了個夢！』</span>
<span className="v" id="v26" data-v="26" data-xref="提摩太前書 4:1–2; 耶利米書 14:14; 帖撒羅尼迦後書 2:9–11"> 這些先知謊話連篇，憑空預言要到何時呢？</span>
<span className="v" id="v27" data-v="27" data-xref="士師記 8:33–34; 士師記 3:7; 使徒行傳 13:8"> 他們彼此傳講所做的夢，想藉此使我的子民忘記我的名，正如他們的祖先因祭拜巴力而忘記了我的名。</span>
<span className="v" id="v28" data-v="28" data-xref="哥林多後書 2:17; 提摩太前書 1:12; 哥林多前書 3:12–13"> 讓做夢的先知儘管宣揚他們的夢吧，但得到我話語的先知要忠心地傳達我的話。糠秕怎能與麥子相比呢！這是耶和華說的。」</span>
<span className="v" id="v29" data-v="29" data-xref="希伯來書 4:12; 耶利米書 5:14; 路加福音 24:32"> 耶和華說：「難道我的話不像火嗎？不像擊碎巖石的鐵錘嗎？」</span>
<span className="v" id="v30" data-v="30" data-xref="申命記 18:20; 以西結書 13:8; 耶利米書 14:14–15"> 耶和華說：「看啊，我要對付那些假先知，他們盜用彼此的話，卻妄稱是我的話。」</span>
<span className="v" id="v31" data-v="31" data-xref="耶利米書 23:17; 歷代志下 18:10–12; 歷代志下 18:5"> 耶和華說：「看啊，我要對付那些假先知，他們妄自說預言，卻謊稱是耶和華的話。」</span>
<span className="v" id="v32" data-v="32" data-xref="以西結書 13:7–18; 西番雅書 3:4; 耶利米哀歌 2:14"> 耶和華說：「看啊，我要對付那些假先知，他們憑虛謊之夢說預言，並四處傳揚，用彌天大謊把我的子民引入歧途。其實我並沒有差遣他們，也沒有委派他們，他們對我的子民毫無益處。這是耶和華說的。」</span>
<span className="v" id="v33" data-v="33" data-xref="瑪拉基書 1:1; 耶利米書 12:7; 哈巴谷書 1:1"> 耶和華說：「耶利米啊，如果有百姓、先知或祭司問你，『耶和華有什麼啟示？』你要對他們說，『你們就是耶和華的重擔<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「重擔」希伯來文也有「啟示」的意思。">a</a></sup>，耶和華說要丟棄你們。』</span>
<span className="v" id="v34" data-v="34" data-xref="撒迦利亞書 13:3; 耶利米哀歌 2:14"> 如果有先知、祭司或百姓宣稱有耶和華的啟示，我必懲罰他和他全家。</span>
<span className="v" id="v35" data-v="35" data-xref="耶利米書 31:34; 耶利米書 42:4; 耶利米書 33:3"> 你們各人要問自己的親友，『耶和華有什麼答覆？』或『耶和華說了什麼？』</span>
<span className="v" id="v36" data-v="36" data-xref="耶利米書 10:10; 彼得後書 3:16; 以賽亞書 3:8"> 你們不可再說有耶和華的啟示，因為你們把自己的話當成祂的啟示，曲解我們永活的上帝——萬軍之耶和華的話。</span>
<span className="v" id="v37" data-v="37"> 耶利米啊，你要這樣問先知，『耶和華有什麼答覆？耶和華說了什麼？』</span>
<span className="v" id="v38" data-v="38" data-xref="歷代志下 11:13–14"> 如果他們說，『這是耶和華的啟示。』你就說，『耶和華說，我警告你們不可宣稱有耶和華的啟示，你們卻偏偏宣稱有我的啟示，</span>
<span className="v" id="v39" data-v="39" data-xref="耶利米書 23:33; 以西結書 8:18; 箴言 13:13"> 我必徹底忘記你們，把你們和我賜給你們及你們祖先的城邑拋棄。</span>
<span className="v" id="v40" data-v="40" data-xref="耶利米書 20:11; 以西結書 5:14–15; 耶利米書 42:18"> 我要使你們永遠蒙羞受辱，難以忘懷。』」</span>

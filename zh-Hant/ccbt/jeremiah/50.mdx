## 審判巴比倫的預言

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="耶利米書 25:26–27; 耶利米書 51:1–14; 以賽亞書 13:1–3"> 關於迦勒底人居住的巴比倫，耶和華對耶利米先知說：</span>
<span className="v" id="v2" data-v="2" data-xref="以賽亞書 46:1; 以賽亞書 21:9; 耶利米書 51:44"> <span className="pl pl-1">「你們要在列國中傳揚和宣告，</span><br /><span className="pl pl-1">要豎起旗幟，毫不隱瞞地宣告，</span><br /><span className="pl pl-1">『巴比倫要淪陷了！</span><br /><span className="pl pl-1">她的神明彼勒必蒙羞，</span><br /><span className="pl pl-1">米羅達必驚慌；</span><br /><span className="pl pl-1">巴比倫的神像都蒙羞，</span><br /><span className="pl pl-1">偶像都必驚慌。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="西番雅書 1:3; 耶利米書 51:11; 耶利米書 51:62"> <span className="pl pl-1">因為有一個來自北方的國家要攻擊它，</span><br /><span className="pl pl-1">使她的土地荒涼、人畜絕跡。』」</span></span>
<span className="v" id="v4" data-v="4" data-xref="耶利米書 31:31; 何西阿書 1:11; 何西阿書 3:5"> 耶和華說：「那時，以色列人要與猶大人一同來，流著淚尋求他們的上帝耶和華。</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米書 32:40; 希伯來書 8:6–10; 以賽亞書 55:3"> 他們必打聽前往錫安的路，朝錫安走去。他們必憑永不被遺忘的約歸附耶和華。</span>
<span className="v" id="v6" data-v="6" data-xref="以賽亞書 53:6; 馬太福音 9:36; 以西結書 34:14"> 我的子民成了一群迷路的羊，他們的牧人使他們步入歧途，在高山丘陵間流浪，忘了自己的安歇之處。</span>
<span className="v" id="v7" data-v="7" data-xref="耶利米書 14:8; 耶利米書 2:3; 撒迦利亞書 11:5"> 遇見他們的人都吞噬他們。他們的敵人說，『我們沒有錯！這是因為他們冒犯了他們真正的安歇之處——耶和華，他們祖先的盼望——耶和華。』</span>
<span className="v" id="v8" data-v="8" data-xref="以賽亞書 48:20; 耶利米書 51:6; 啟示錄 18:4"> 我的子民啊，你們要逃離巴比倫，離開迦勒底人的土地，要像帶領羊群的公山羊一樣離開。</span>
<span className="v" id="v9" data-v="9" data-xref="耶利米書 51:11; 耶利米書 15:14; 撒母耳記下 1:22"> 看啊，我要使來自北方的列強聯合起來攻打巴比倫，他們要列陣攻佔它，他們的勇士箭術高超，從不空手而歸。</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米書 25:12; 以賽亞書 33:23; 以賽亞書 33:4"> 他們要在迦勒底肆意擄掠，直到心滿意足。這是耶和華說的。</span>
<span className="v" id="v11" data-v="11" data-xref="以賽亞書 47:6; 以西結書 25:15–17; 以西結書 26:2–3"> <span className="pl pl-1">「搶奪我產業的巴比倫人啊，</span><br /><span className="pl pl-1">你們歡喜快樂，</span><br /><span className="pl pl-1">像草場上歡跳的母牛犢，</span><br /><span className="pl pl-1">又像嘶鳴的公馬。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="耶利米書 51:43; 耶利米書 49:2; 加拉太書 4:26"> <span className="pl pl-1">但你們的母親巴比倫將羞愧難當，</span><br /><span className="pl pl-1">生養你們的將蒙受恥辱，</span><br /><span className="pl pl-1">她將排在列國之末，</span><br /><span className="pl pl-1">淪為曠野、旱地和荒漠。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="耶利米書 18:16; 耶利米書 49:17; 耶利米哀歌 2:15–16"> <span className="pl pl-1">由於耶和華的憤怒，</span><br /><span className="pl pl-1">巴比倫必無人居住，</span><br /><span className="pl pl-1">荒涼不堪。</span><br /><span className="pl pl-1">她滿目瘡痍，</span><br /><span className="pl pl-1">令路人驚懼、嗤笑。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="耶利米書 50:29; 哈巴谷書 2:17; 撒母耳記上 17:20"> <span className="pl pl-1">弓箭手啊，你們要列陣圍攻巴比倫，</span><br /><span className="pl pl-1">向她猛射，</span><br /><span className="pl pl-1">不要吝嗇箭枝，</span><br /><span className="pl pl-1">因為她得罪了耶和華。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="耶利米書 51:58; 啟示錄 18:6; 耶利米書 46:10"> <span className="pl pl-1">你們要從四面向她吶喊，</span><br /><span className="pl pl-1">她必投降，</span><br /><span className="pl pl-1">她的堡壘將傾倒，</span><br /><span className="pl pl-1">城牆將坍塌，</span><br /><span className="pl pl-1">因為耶和華要報應她。</span><br /><span className="pl pl-1">你們要向她復仇，</span><br /><span className="pl pl-1">她怎樣對待別人，</span><br /><span className="pl pl-1">你們也要怎樣對待她。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="耶利米書 51:9; 耶利米書 46:16; 以賽亞書 13:14"> <span className="pl pl-1">你們要剷除在巴比倫撒種的和收割的。</span><br /><span className="pl pl-1">為躲避敵人的刀劍，</span><br /><span className="pl pl-1">人們各自逃到故土親族那裡。</span></span>
<span className="v" id="v17" data-v="17" data-xref="耶利米書 2:15; 約翰福音 10:10–12; 列王紀下 18:9–13"> 「以色列人是一群被獅子驅散的羊，先被亞述王吞噬，後被巴比倫王尼布甲尼撒咬碎骨頭。」</span>
<span className="v" id="v18" data-v="18" data-xref="以賽亞書 10:12; 西番雅書 2:13–15; 那鴻書 1:1–3"> 因此，以色列的上帝——萬軍之耶和華說：「看啊，我要像懲罰亞述王一樣懲罰巴比倫王和他的國家。</span>
<span className="v" id="v19" data-v="19" data-xref="耶利米書 3:18; 彌迦書 7:14; 耶利米書 30:18"> 我要帶領以色列人返回他們的草場，讓他們在迦密和巴珊吃草，在以法蓮和基列的山上吃得飽足。</span>
<span className="v" id="v20" data-v="20" data-xref="彌迦書 7:19; 耶利米書 31:34; 以賽亞書 1:9"> 那時，在以色列必找不到過犯，在猶大必找不到罪惡，因為我必赦免我保留下來的餘民。這是耶和華說的。</span>
<span className="v" id="v21" data-v="21" data-xref="以西結書 23:23; 撒母耳記上 15:3; 耶利米書 50:3"> <span className="pl pl-1">「你們要去攻打米拉大翁和比割的居民，</span><br /><span className="pl pl-1">照我的命令追殺他們，徹底消滅他們。</span><br /><span className="pl pl-1">這是耶和華說的。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="耶利米書 4:19–21; 耶利米書 51:54–56; 以賽亞書 21:2–4"> <span className="pl pl-1">巴比倫境內傳來戰爭和大毀滅的聲音。</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="耶利米書 51:20–24; 以賽亞書 14:4–6; 啟示錄 18:16"> <span className="pl pl-1">威震天下的錘子巴比倫竟被砍斷、打碎了！</span><br /><span className="pl pl-1">它的下場令列國震驚！</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="約伯記 9:4; 但以理書 5:30–31; 約伯記 40:2"> <span className="pl pl-1">巴比倫啊，我給你設下了陷阱，</span><br /><span className="pl pl-1">你在懵然不知中被捉住，</span><br /><span className="pl pl-1">你因為與耶和華為敵，</span><br /><span className="pl pl-1">才被找到並擒獲。</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="耶利米書 51:55; 耶利米書 51:25; 阿摩司書 3:6"> <span className="pl pl-1">耶和華已打開祂的兵器庫，</span><br /><span className="pl pl-1">取出傾瀉祂烈怒的兵器。</span><br /><span className="pl pl-1">因為主——萬軍之耶和華要懲罰迦勒底人。</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="以賽亞書 14:23; 耶利米書 50:10; 以賽亞書 45:3"> <span className="pl pl-1">你們要從遠方前來攻打巴比倫，</span><br /><span className="pl pl-1">打開她的糧倉，</span><br /><span className="pl pl-1">使她淪為一堆廢墟，</span><br /><span className="pl pl-1">徹底毀滅她，不留一物。</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="耶利米書 46:21; 以賽亞書 34:7; 耶利米書 48:44"> <span className="pl pl-1">你們要殺掉她所有的士兵，</span><br /><span className="pl pl-1">把他們全部屠殺。</span><br /><span className="pl pl-1">他們大禍臨頭了，</span><br /><span className="pl pl-1">懲罰他們的日子到了。</span></span>
<span className="v" id="v28" data-v="28" data-xref="以賽亞書 48:20; 耶利米書 50:15; 耶利米哀歌 1:10"> 「從巴比倫逃出來的人在錫安述說我們的上帝耶和華如何報仇，為祂的聖殿報仇。</span>
<span className="v" id="v29" data-v="29" data-xref="耶利米書 51:56; 以賽亞書 47:10; 但以理書 4:37"> 「要召集所有的弓箭手來攻打巴比倫，在她四圍紮營，不讓一人漏網。要照她的所作所為報應她；她怎樣對待別人，也要怎樣對待她，因為她藐視以色列的聖者耶和華。</span>
<span className="v" id="v30" data-v="30" data-xref="耶利米書 49:26; 耶利米書 18:21; 耶利米書 9:21"> 她的青年要倒斃街頭，那時她所有的戰士都要滅亡。」這是耶和華說的。</span>
<span className="v" id="v31" data-v="31" data-xref="耶利米書 21:13; 耶利米書 50:29; 以西結書 39:1"> <span className="pl pl-1">「主——萬軍之耶和華說，</span><br /><span className="pl pl-1">『狂傲的人啊，我要與你為敵，</span><br /><span className="pl pl-1">我懲罰你的時候到了。</span><br /></span>
<span className="v" id="v32" data-v="32" data-xref="耶利米書 21:14; 耶利米書 49:27; 以賽亞書 10:12–15"> <span className="pl pl-1">狂傲的人要踉踉蹌蹌，</span><br /><span className="pl pl-1">跌倒在地，無人扶起。</span><br /><span className="pl pl-1">我要焚燒她的城邑，</span><br /><span className="pl pl-1">使她周圍的一切化為灰燼。』」</span></span>
<span className="v" id="v33" data-v="33" data-xref="以賽亞書 14:17; 出埃及記 9:2–3; 以賽亞書 58:6"> 萬軍之耶和華說：「以色列人和猶大人要一同受壓迫，擄走他們的人必控制他們，不肯釋放他們。</span>
<span className="v" id="v34" data-v="34" data-xref="以賽亞書 54:5; 耶利米書 15:21; 以賽亞書 41:14"> 但他們的救贖主——萬軍之耶和華大有能力，祂必為他們伸冤，使他們的家園安寧，使巴比倫的居民不得安寧。」</span>
<span className="v" id="v35" data-v="35" data-xref="耶利米書 47:6; 但以理書 5:30; 但以理書 5:7–8"> 耶和華說：<br /><span className="pl pl-1">「敵人要攻擊巴比倫的居民及其首領和謀士；</span><br /></span>
<span className="v" id="v36" data-v="36" data-xref="耶利米書 49:22; 那鴻書 3:13; 以賽亞書 44:25"> <span className="pl pl-1">敵人要攻擊巴比倫的假先知，</span><br /><span className="pl pl-1">使他們顯出愚昧；</span><br /><span className="pl pl-1">敵人要攻擊巴比倫的勇士，</span><br /><span className="pl pl-1">使他們充滿恐懼；</span><br /></span>
<span className="v" id="v37" data-v="37" data-xref="耶利米書 51:30; 那鴻書 3:13; 耶利米書 51:21"> <span className="pl pl-1">敵人要攻擊巴比倫人的戰車戰馬和他們的盟軍，</span><br /><span className="pl pl-1">使他們柔弱得像婦女；</span><br /><span className="pl pl-1">敵人要攻打他們的庫房，</span><br /><span className="pl pl-1">肆意搶奪他們的財寶。</span><br /></span>
<span className="v" id="v38" data-v="38" data-xref="啟示錄 16:12; 以賽亞書 44:27; 耶利米書 50:2"> <span className="pl pl-1">旱災必臨到巴比倫，</span><br /><span className="pl pl-1">使那裡的河流乾涸，</span><br /><span className="pl pl-1">因為那裡神像遍地，</span><br /><span className="pl pl-1">人們都沉迷於祭拜偶像。</span></span>
<span className="v" id="v39" data-v="39" data-xref="以賽亞書 13:20–22; 啟示錄 18:2; 耶利米書 25:12"> 「因此，巴比倫必杳無人煙，永遠荒涼，成為豺狼等野獸出沒之地、鴕鳥的棲身之所。</span>
<span className="v" id="v40" data-v="40" data-xref="創世記 19:24–25; 猶大書 1:7; 以賽亞書 13:19–20"> 上帝要毀滅巴比倫，像毀滅所多瑪、蛾摩拉及其周圍的城邑一樣，使那裡人煙絕跡。這是耶和華說的。</span>
<span className="v" id="v41" data-v="41" data-xref="耶利米書 51:27–28; 耶利米書 6:22–23; 以賽亞書 13:2–5"> <span className="pl pl-1">「看啊，有一個民族要從北方來，</span><br /><span className="pl pl-1">有一個強國及許多君王要從地極發動進攻。</span><br /></span>
<span className="v" id="v42" data-v="42" data-xref="以賽亞書 5:30; 以賽亞書 13:17–18; 以賽亞書 47:6"> <span className="pl pl-1">少女巴比倫啊，他們殘酷無情，</span><br /><span className="pl pl-1">手持弓箭和矛槍，</span><br /><span className="pl pl-1">騎馬奔來，聲勢如怒海狂濤，</span><br /><span className="pl pl-1">列陣攻擊你。</span><br /></span>
<span className="v" id="v43" data-v="43" data-xref="耶利米書 51:31; 耶利米書 49:24; 以賽亞書 21:3–4"> <span className="pl pl-1">巴比倫王聽到風聲，</span><br /><span className="pl pl-1">四肢發軟，痛苦不堪，</span><br /><span className="pl pl-1">如分娩的婦人。</span></span>
<span className="v" id="v44" data-v="44" data-xref="耶利米書 49:19–21; 以賽亞書 46:11; 詩篇 89:6"> 「看啊，我必在瞬間把巴比倫人趕離家園，如約旦河邊叢林中跳出的獅子趕散草場的羊群。我要派我揀選的人統治這地方。誰能與我相比？誰能與我較量？哪位首領能抵擋我？」</span>
<span className="v" id="v45" data-v="45" data-xref="耶利米書 49:20; 耶利米書 51:10–11; 啟示錄 17:16–17"> 因此，你們要聽聽耶和華攻擊巴比倫的策略，聽聽祂攻擊迦勒底人的計劃。他們的孩子要被拖走，他們的家園要被毀滅。</span>
<span className="v" id="v46" data-v="46" data-xref="耶利米書 49:21; 啟示錄 18:9–19; 以西結書 31:16"> 巴比倫被毀滅的消息震動大地，哭喊聲傳到列國。</span>

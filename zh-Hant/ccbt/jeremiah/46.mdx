## 關於埃及的預言

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="耶利米書 1:10; 撒迦利亞書 2:8; 耶利米書 4:7"> 耶和華把有關列國的事告訴了耶利米先知。</span>
<span className="v" id="v2" data-v="2" data-xref="列王紀下 23:29; 耶利米書 46:14; 耶利米書 25:19"> 約西亞的兒子猶大王約雅敬執政第四年，埃及王法老尼哥的軍隊在幼發拉底河邊的迦基米施被巴比倫王尼布甲尼撒擊敗。關於埃及，耶和華說：</span>
<span className="v" id="v3" data-v="3" data-xref="以賽亞書 21:5; 約珥書 3:9; 那鴻書 2:1"> <span className="pl pl-1">「要預備大小盾牌，</span><br /><span className="pl pl-1">衝向戰場。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="以西結書 21:9–11; 耶利米書 51:3; 撒母耳記上 17:5"> <span className="pl pl-1">要套好戰車，</span><br /><span className="pl pl-1">騎上戰馬，</span><br /><span className="pl pl-1">擦亮矛槍，</span><br /><span className="pl pl-1">頂盔貫甲，</span><br /><span className="pl pl-1">準備作戰。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="耶利米書 49:29; 耶利米書 6:25; 耶利米書 46:21"> <span className="pl pl-1">可是，我看見什麼？</span><br /><span className="pl pl-1">他們驚慌後退，</span><br /><span className="pl pl-1">勇士敗逃，不敢回頭，</span><br /><span className="pl pl-1">驚恐不安。</span><br /><span className="pl pl-1">這是耶和華說的。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="但以理書 11:19; 耶利米書 46:12; 詩篇 27:2"> <span className="pl pl-1">善跑者跑不掉，</span><br /><span className="pl pl-1">強壯者逃不了，</span><br /><span className="pl pl-1">他們仆倒在北面的幼發拉底河邊。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="耶利米書 47:2; 以賽亞書 8:7–8; 但以理書 11:22"> <span className="pl pl-1">「那如尼羅河漲溢，</span><br /><span className="pl pl-1">如江水奔騰的是誰呢？</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="以賽亞書 10:13–16; 以西結書 32:2; 以賽亞書 37:24–26"> <span className="pl pl-1">埃及如尼羅河漲溢，</span><br /><span className="pl pl-1">如江水奔騰。</span><br /><span className="pl pl-1">她說，『我要漲溢，淹沒大地，</span><br /><span className="pl pl-1">毀滅城邑和其中的居民。』</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="以賽亞書 66:19; 以西結書 27:10; 那鴻書 3:9"> <span className="pl pl-1">戰馬奔騰吧！</span><br /><span className="pl pl-1">戰車疾駛吧！</span><br /><span className="pl pl-1">勇士啊，就是那些手拿盾牌的古實人和弗人以及箭法嫺熟的呂底亞人啊，出戰吧！</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="申命記 32:42; 約珥書 1:15; 耶利米書 46:2"> <span className="pl pl-1">因為這是主——萬軍之耶和華向敵人報仇的日子。</span><br /><span className="pl pl-1">刀劍必吞噬他們，</span><br /><span className="pl pl-1">痛飲他們的血，</span><br /><span className="pl pl-1">因為要在北方的幼發拉底河邊向主——萬軍之耶和華獻祭。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="耶利米書 8:22; 彌迦書 1:9; 那鴻書 3:19"> <span className="pl pl-1">處女埃及啊，</span><br /><span className="pl pl-1">去基列取乳香吧！</span><br /><span className="pl pl-1">然而，再多的良藥也是徒然，</span><br /><span className="pl pl-1">你們無法得醫治。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="那鴻書 3:8–10; 以賽亞書 19:2; 耶利米書 46:6"> <span className="pl pl-1">你們的恥辱傳遍列國，</span><br /><span className="pl pl-1">你們的哀哭響徹大地，</span><br /><span className="pl pl-1">你們的勇士彼此碰撞，</span><br /><span className="pl pl-1">倒在一起。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v13" data-v="13" data-xref="耶利米書 44:30; 耶利米書 43:10–13; 以賽亞書 19:1–25"> 關於巴比倫王尼布甲尼撒要來攻打埃及的事，耶和華對耶利米先知說：</span>
<span className="v" id="v14" data-v="14" data-xref="耶利米書 46:10; 耶利米書 44:1; 耶利米書 46:3–4"> <span className="pl pl-1">「你們要在埃及宣佈，在密奪、挪弗和答比匿宣告，</span><br /><span className="pl pl-1">『要擺好陣勢，準備作戰，</span><br /><span className="pl pl-1">因為刀劍要吞噬你們周圍的人。』</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="以賽亞書 66:15–16; 詩篇 68:2; 詩篇 18:39"> <span className="pl pl-1">你們的勇士為何仆倒？</span><br /><span className="pl pl-1">他們無法站立，</span><br /><span className="pl pl-1">因為耶和華擊倒了他們，</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="利未記 26:36–37; 耶利米書 51:9; 耶利米書 46:6"> <span className="pl pl-1">使他們跌跌絆絆，紛紛倒下。</span><br /><span className="pl pl-1">他們說，『起來，我們回到同胞那裡，回到故鄉吧，</span><br /><span className="pl pl-1">好躲避敵人的刀劍。』</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="以賽亞書 19:11–16; 出埃及記 15:9; 列王紀上 20:10"> <span className="pl pl-1">他們在那裡喊叫，</span><br /><span className="pl pl-1">『埃及王法老只會虛張聲勢，</span><br /><span className="pl pl-1">他已錯失良機。』」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v18" data-v="18" data-xref="耶利米書 48:15; 士師記 4:6; 約書亞記 19:22"> <span className="pl pl-1">名叫萬軍之耶和華的王說：</span><br /><span className="pl pl-1">「我憑我的永恆起誓，</span><br /><span className="pl pl-1">將有一位要來，</span><br /><span className="pl pl-1">他的氣勢如群山中的他泊山，</span><br /><span className="pl pl-1">又像海邊的迦密山。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="以賽亞書 20:4; 耶利米書 48:18; 以西結書 30:13"> <span className="pl pl-1">住在埃及的人啊，</span><br /><span className="pl pl-1">收拾行裝準備流亡吧！</span><br /><span className="pl pl-1">因為挪弗必荒廢，</span><br /><span className="pl pl-1">淪為廢墟，杳無人跡。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v20" data-v="20" data-xref="何西阿書 10:11; 耶利米書 47:2; 耶利米書 1:14"> <span className="pl pl-1">「埃及像頭肥美的母牛犢，</span><br /><span className="pl pl-1">但從北方卻來了牛虻。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="耶利米書 46:5; 俄巴底亞書 1:13; 列王紀下 7:6"> <span className="pl pl-1">埃及的傭兵好像肥牛犢，</span><br /><span className="pl pl-1">都轉身逃之夭夭，無力抵擋，</span><br /><span className="pl pl-1">因為他們遭難、受罰的日子到了。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v22" data-v="22" data-xref="以賽亞書 14:8; 以賽亞書 29:4; 彌迦書 1:8"> <span className="pl pl-1">「敵軍列隊進攻的時候，</span><br /><span className="pl pl-1">埃及必像蛇一樣嘶嘶地溜走。</span><br /><span className="pl pl-1">敵軍必拿著斧頭蜂擁而來，</span><br /><span className="pl pl-1">像樵夫砍樹一樣攻擊他們。</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="士師記 7:12; 士師記 6:5; 約珥書 2:25"> <span className="pl pl-1">埃及的人口雖然稠密如林，</span><br /><span className="pl pl-1">敵軍必像無數的蝗蟲一樣掃平他們。</span><br /><span className="pl pl-1">這是耶和華說的。</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="耶利米書 1:15; 以西結書 29:1–21; 耶利米書 46:11"> <span className="pl pl-1">埃及人必蒙羞，</span><br /><span className="pl pl-1">落在北方人的手中。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v25" data-v="25" data-xref="西番雅書 2:11; 耶利米書 43:12–13; 以賽亞書 20:5–6"> 以色列的上帝——萬軍之耶和華說：「看啊，我要懲罰底比斯的神明亞捫、埃及的其他神明、法老、首領以及依靠法老的人。</span>
<span className="v" id="v26" data-v="26" data-xref="以西結書 32:11; 耶利米書 44:30; 以西結書 29:8–14"> 我要把他們交在想殺他們的巴比倫王尼布甲尼撒及其官長手中。然而，日後埃及必再有人居住，如往日一樣。這是耶和華說的。</span>
<span className="v" id="v27" data-v="27" data-xref="以賽亞書 43:5; 耶利米書 30:10–11; 以賽亞書 43:1"> <span className="pl pl-1">「我的僕人雅各啊，不要害怕！</span><br /><span className="pl pl-1">以色列啊，不要驚慌！</span><br /><span className="pl pl-1">因為我要從遠方拯救你，</span><br /><span className="pl pl-1">從流亡之地拯救你的後裔。</span><br /><span className="pl pl-1">雅各必重返家園，安享太平，</span><br /><span className="pl pl-1">不受驚嚇。</span><br /></span>
<span className="v" id="v28" data-v="28" data-xref="哥林多前書 11:32; 啟示錄 3:19; 耶利米書 10:24"> <span className="pl pl-1">我的僕人雅各啊，不要害怕，</span><br /><span className="pl pl-1">因為我與你同在。</span><br /><span className="pl pl-1">我曾使你流亡到列國，</span><br /><span className="pl pl-1">我必徹底毀滅列國，</span><br /><span className="pl pl-1">但不會徹底毀滅你，</span><br /><span className="pl pl-1">也不會放過你，</span><br /><span className="pl pl-1">我必公正地懲治你。</span><br /><span className="pl pl-1">這是耶和華說的。」</span></span>
</div>

## 陶器的比喻

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1"> 耶和華對耶利米說：</span>
<span className="v" id="v2" data-v="2" data-xref="希伯來書 1:1; 使徒行傳 9:6; 耶利米書 19:1–2"> 「你去陶匠家，在那裡我有話告訴你。」</span>
<span className="v" id="v3" data-v="3" data-xref="約翰福音 15:14; 約拿書 1:3; 使徒行傳 26:19"> 我便下到陶匠家，見他正用輪盤做器皿。</span>
<span className="v" id="v4" data-v="4" data-xref="羅馬書 9:20–23; 耶利米書 18:6; 以賽亞書 45:9"> 他手中陶造的器皿做壞了，他就用那塊泥做成別的器皿，想怎麼做就怎麼做。</span>
<span className="v" id="v5" data-v="5"> 這時，耶和華對我說：</span>
<span className="v" id="v6" data-v="6" data-xref="以賽亞書 64:8; 羅馬書 9:20–21; 耶利米書 18:4"> 「以色列人啊，難道我不能像陶匠對待陶泥一樣對待你們嗎？以色列人啊，你們在我手中就像陶泥在陶匠手中一樣。這是耶和華說的。</span>
<span className="v" id="v7" data-v="7" data-xref="耶利米書 1:10; 耶利米書 12:14–17; 耶利米書 45:4"> 當我宣佈要剷除、推翻、毀滅哪一邦或哪一國的時候，</span>
<span className="v" id="v8" data-v="8" data-xref="以西結書 18:21; 耶利米書 26:13; 約拿書 3:9–10"> 如果他們悔過自新，我必施憐憫，取消我原本要降給他們的災禍。</span>
<span className="v" id="v9" data-v="9" data-xref="耶利米書 31:28; 阿摩司書 9:11–15; 耶利米書 1:10"> 當我宣佈要建造和栽培哪一邦或哪一國的時候，</span>
<span className="v" id="v10" data-v="10" data-xref="以西結書 33:18; 撒母耳記上 2:30; 以西結書 18:24"> 如果他們做我視為惡的事，不聽從我的話，我必改變心意，取消我原本要賜給他們的福氣。</span>
<span className="v" id="v11" data-v="11" data-xref="列王紀下 17:13; 以賽亞書 55:6–7; 耶利米書 35:15"> 因此，你去告訴猶大人和耶路撒冷的居民，『耶和華說，我正計劃降災禍懲罰你們。你們要離開罪惡，改邪歸正。』</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米書 2:25; 耶利米書 7:24; 申命記 29:19"> 他們卻說，『沒用！我們要隨心所欲，為所欲為。』」</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米書 5:30; 何西阿書 6:10; 耶利米書 23:14"> <span className="pl pl-1">因此耶和華說：</span><br /><span className="pl pl-1">「你們問問列國，</span><br /><span className="pl pl-1">看看誰曾聽過這樣的事？</span><br /><span className="pl pl-1">少女以色列竟做了一件極可怕的事。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="約翰福音 6:68"> <span className="pl pl-1">黎巴嫩山嶺上的積雪會融化嗎？</span><br /><span className="pl pl-1">從遠方流來的冰涼溪水會停止嗎？</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="耶利米書 6:16; 耶利米書 2:32; 何西阿書 11:2"> <span className="pl pl-1">然而，我的子民卻把我忘記，</span><br /><span className="pl pl-1">向虛無的神明燒香，</span><br /><span className="pl pl-1">以致他們跌倒，偏離古道，走入僻陋的小路。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="詩篇 22:7; 耶利米書 25:9; 耶利米書 19:8"> <span className="pl pl-1">因此，他們的土地必荒涼，</span><br /><span className="pl pl-1">永遠遭人嗤笑，</span><br /><span className="pl pl-1">經過此地的人無不驚懼，</span><br /><span className="pl pl-1">搖頭歎息。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="耶利米書 13:24; 耶利米書 2:27; 約伯記 27:21"> <span className="pl pl-1">我要在敵人面前驅散他們，</span><br /><span className="pl pl-1">就像東風吹散塵土一樣。</span><br /><span className="pl pl-1">在他們遭難的時候，</span><br /><span className="pl pl-1">我必以背相向，</span><br /><span className="pl pl-1">不理睬他們。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v18" data-v="18" data-xref="詩篇 52:2; 耶利米書 11:19; 瑪拉基書 2:7"> 他們說：「來！我們設計對付耶利米吧，反正我們一直有祭司教導律法，有智者出謀劃策，有先知傳講預言。來吧！我們抨擊他，不要理會他的話。」</span>
<span className="v" id="v19" data-v="19" data-xref="尼希米記 6:9; 耶利米書 20:12; 詩篇 55:16–17"> <span className="pl pl-1">耶和華啊，求你眷顧我，</span><br /><span className="pl pl-1">聽聽敵人對我的指控。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 35:7; 詩篇 57:6; 詩篇 106:23"> <span className="pl pl-1">人豈能以惡報善？</span><br /><span className="pl pl-1">他們竟設陷阱謀害我，</span><br /><span className="pl pl-1">求你顧念我怎樣站在你面前為他們求情，</span><br /><span className="pl pl-1">怎樣求你不要向他們發烈怒。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 109:9–20; 耶利米哀歌 5:3; 阿摩司書 4:10"> <span className="pl pl-1">因此，求你讓他們喪身刀下，</span><br /><span className="pl pl-1">兒女餓死，</span><br /><span className="pl pl-1">妻子喪夫亡子，</span><br /><span className="pl pl-1">男人被殺，</span><br /><span className="pl pl-1">青年死於戰場！</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="耶利米書 6:26; 詩篇 140:5; 西番雅書 1:10–11"> <span className="pl pl-1">當你使敵軍突襲他們時，</span><br /><span className="pl pl-1">願他們家中傳出哭喊聲，</span><br /><span className="pl pl-1">因為他們挖陷阱要捕捉我，</span><br /><span className="pl pl-1">設圈套要絆我的腳。</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="詩篇 35:4; 詩篇 69:22–28; 尼希米記 4:4–5"> <span className="pl pl-1">耶和華啊，你知道他們害我的各種詭計，</span><br /><span className="pl pl-1">求你不要赦免他們的罪過，</span><br /><span className="pl pl-1">不要從你眼前塗抹他們的罪惡。</span><br /><span className="pl pl-1">求你使他們倒在你面前，</span><br /><span className="pl pl-1">求你在烈怒中懲罰他們。</span></span>

## 警告猶大的王

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="耶利米書 34:2; 路加福音 3:19–20; 撒母耳記下 24:11–12"> 耶和華對我說：「你下到猶大王的宮殿這樣宣告，</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 1:32; 以賽亞書 9:7; 耶利米書 22:4"> 『坐在大衛寶座上的猶大王啊，你和你的臣僕以及經過這些城門的百姓都要聽耶和華的話。</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米書 21:12; 彌迦書 6:8; 耶利米書 22:17"> 耶和華說，你們要秉公行義，要從欺壓者手中解救受剝削的人。不要欺凌、虐待異鄉人和孤兒寡婦，不可在這地方濫殺無辜。</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米書 17:25"> 如果你們謹遵我的命令，坐在大衛寶座上的君王必率領臣民乘車、騎馬進出王宮。</span>
<span className="v" id="v5" data-v="5" data-xref="阿摩司書 6:8; 希伯來書 6:13; 創世記 22:16"> 但如果你們不遵守我的命令，我憑自己起誓，這王宮必淪為廢墟。這是耶和華說的。』」</span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 107:34; 以賽亞書 6:11; 以賽亞書 27:10"> <span className="pl pl-1">關於猶大王的宮殿，耶和華說：</span><br /><span className="pl pl-1">「雖然它在我眼中美如基列，</span><br /><span className="pl pl-1">又像黎巴嫩的山峰，</span><br /><span className="pl pl-1">但我必使它變成不毛之地，</span><br /><span className="pl pl-1">變成荒無人煙的城邑。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="以賽亞書 37:24; 以賽亞書 10:33–34; 耶利米書 4:6–7"> <span className="pl pl-1">我要派人拿著兵器來摧毀它，</span><br /><span className="pl pl-1">他們要砍下它最好的香柏木，</span><br /><span className="pl pl-1">扔進火裡。</span></span>
<span className="v" id="v8" data-v="8" data-xref="列王紀上 9:8–9; 歷代志下 7:20–22; 申命記 29:23–26"> 「各國的人經過這城時都會彼此議論說，『為什麼耶和華這樣對待這座大城？』</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀下 22:17; 歷代志下 34:25; 耶利米書 50:7"> 有人會回答，『因為城裡的人背棄了他們的上帝耶和華的約，供奉、祭拜其他神明。』」</span>
<span className="v" id="v10" data-v="10" data-xref="傳道書 4:2; 耶利米書 22:11; 以賽亞書 57:1"> <span className="pl pl-1">你們不要為死去的王哀哭，</span><br /><span className="pl pl-1">也不要為他悲傷，</span><br /><span className="pl pl-1">但要為被擄走的王切切哀哭，</span><br /><span className="pl pl-1">因為他必一去不返，</span><br /><span className="pl pl-1">永別故土。</span></span>
<span className="v" id="v11" data-v="11" data-xref="歷代志上 3:15; 歷代志下 36:1–4; 列王紀下 23:34"> 因為關於接替父親約西亞做猶大王、後來被擄走的沙龍<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「沙龍」也叫「約哈斯」。">a</a></sup>，耶和華說：「他必一去不返，</span>
<span className="v" id="v12" data-v="12" data-xref="列王紀下 23:34; 耶利米書 22:18"> 客死流亡之地，永別故土。」</span>
</div>
</div>

## 對約雅敬的審判

<div className="bt">
<div className="bp poetry">
<span className="v" id="v13" data-v="13" data-xref="雅各書 5:4; 彌迦書 3:10; 利未記 19:13"> <span className="pl pl-1">耶和華說：</span><br /><span className="pl pl-1">「猶大王約雅敬啊，你有禍了！</span><br /><span className="pl pl-1">你以不公不義的手段建造宮廷殿宇，</span><br /><span className="pl pl-1">使同胞白白做工，</span><br /><span className="pl pl-1">不給他們工錢。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳記下 7:2; 以賽亞書 5:8–9; 哈該書 1:4"> <span className="pl pl-1">你說要為自己建造宏偉的宮殿、寬敞的樓房。</span><br /><span className="pl pl-1">你安上窗戶，</span><br /><span className="pl pl-1">鑲上香柏木板，</span><br /><span className="pl pl-1">塗上紅漆。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="列王紀下 23:25; 以賽亞書 3:10; 傳道書 10:17"> <span className="pl pl-1">難道你大肆使用香柏木就能顯出你做王的氣派嗎？</span><br /><span className="pl pl-1">你父親也吃也喝，</span><br /><span className="pl pl-1">但他秉公行義，</span><br /><span className="pl pl-1">所以他凡事順利；</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="耶利米書 9:24; 以賽亞書 1:17; 約翰一書 2:3–4"> <span className="pl pl-1">他為困苦和貧窮的人伸冤，</span><br /><span className="pl pl-1">所以他凡事順利。</span><br /><span className="pl pl-1">這才是真正認識我。</span><br /><span className="pl pl-1">這是耶和華說的。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="彼得後書 2:14; 列王紀下 24:4; 耶利米書 22:3"> <span className="pl pl-1">可是，你心裡眼裡貪圖不義之財，</span><br /><span className="pl pl-1">只顧濫殺無辜，橫徵暴斂。」</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="列王紀上 13:30; 耶利米書 16:6; 耶利米書 16:4"> <span className="pl pl-1">因此，關於約西亞的兒子猶大王約雅敬，耶和華說：</span><br /><span className="pl pl-1">「沒有人會為他哀悼說，</span><br /><span className="pl pl-1">『唉，我的弟兄啊！</span><br /><span className="pl pl-1">唉，我的姊妹啊！』</span><br /><span className="pl pl-1">沒有人會為他哀悼說，</span><br /><span className="pl pl-1">『唉，主人啊！</span><br /><span className="pl pl-1">唉，他的尊榮！』</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="耶利米書 36:30; 列王紀上 21:23–24; 歷代志下 36:6"> <span className="pl pl-1">他必像死驢一樣被拖出去扔在耶路撒冷的城門外，曝屍荒野。」</span></span>
</div>
</div>

<div className="bt">
<div className="bp poetry">
<span className="v" id="v20" data-v="20" data-xref="民數記 27:12; 以西結書 23:22; 耶利米哀歌 1:2"> <span className="pl pl-1">「耶路撒冷人啊，</span><br /><span className="pl pl-1">你們要上黎巴嫩哭喊，</span><br /><span className="pl pl-1">在巴珊哀號，</span><br /><span className="pl pl-1">在亞巴琳痛哭，</span><br /><span className="pl pl-1">因為你們的盟友被消滅了。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="耶利米書 32:30; 耶利米書 3:25; 耶利米書 7:22–28"> <span className="pl pl-1">在你們興盛的時候，</span><br /><span className="pl pl-1">我曾警告過你們，</span><br /><span className="pl pl-1">你們卻不聽。</span><br /><span className="pl pl-1">你們從小就叛逆，</span><br /><span className="pl pl-1">不聽我的話。</span><br /></span>

</div>

## 對哥尼雅的審判

<div className="bt">
<div className="bp poetry">
<span className="v" id="v24" data-v="24" data-xref="耶利米書 37:1; 雅歌 8:6; 歷代志上 3:16"> 耶和華說：「約雅敬的兒子猶大王哥尼雅<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="「哥尼雅」即「耶哥尼雅」，又叫「約雅斤」。">b</a></sup>啊，我憑我的永恆起誓，即使你是我右手上蓋章的戒指，我也要把你摘下來，</span>
<span className="v" id="v25" data-v="25" data-xref="耶利米書 34:20–21; 耶利米書 21:7; 列王紀下 24:15–16"> 交給那些想殺你的人，交給你所懼怕的巴比倫王尼布甲尼撒和迦勒底軍隊。</span>
<span className="v" id="v26" data-v="26" data-xref="列王紀下 24:15; 耶利米書 15:2–4; 以賽亞書 22:17"> 我要把你和你的生母趕到異鄉，那裡不是你們的出生之地，卻是你們的葬身之處。</span>
<span className="v" id="v27" data-v="27" data-xref="耶利米書 44:14; 列王紀下 25:27–30; 詩篇 86:4"> 你們渴望回到故鄉，卻不能如願以償。」</span>
<span className="v" id="v28" data-v="28" data-xref="詩篇 31:12; 何西阿書 8:8; 耶利米書 48:38"> <span className="pl pl-1">難道哥尼雅這人是被鄙視的破瓶子，是無人要的器皿嗎？</span><br /><span className="pl pl-1">為什麼他和他的子孫被趕到陌生之地？</span><br /></span>
<span className="v" id="v29" data-v="29" data-xref="申命記 32:1; 彌迦書 1:2; 耶利米書 6:19"> <span className="pl pl-1">大地啊，大地啊，大地啊，</span><br /><span className="pl pl-1">要聽耶和華的話！</span><br /></span>
<span className="v" id="v30" data-v="30" data-xref="耶利米書 36:30; 詩篇 94:20; 馬太福音 1:11–16"> <span className="pl pl-1">耶和華說：</span><br /><span className="pl pl-1">「你要把這人作為無兒無女、</span><br /><span className="pl pl-1">一生失敗的人記錄下來，</span><br /><span className="pl pl-1">因為他的後裔中無一人能成功地繼承大衛的寶座，</span><br /><span className="pl pl-1">統治猶大。」</span></span>
</div>

## 上帝應許拯救祂的子民

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="耶利米書 26:15; 耶利米書 1:1–2"> 耶和華對耶利米說：</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米書 36:32; 以賽亞書 30:8; 哈巴谷書 2:2–3"> 「以色列的上帝耶和華這樣說，『你要把我對你說的一切話寫在書卷上。</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米書 29:14; 耶利米書 16:15; 耶利米書 30:18"> 耶和華說：看啊，時候將到，我要使我被擄的以色列和猶大子民返鄉，回到我賜給他們祖先的土地上，恢復他們的地業。這是耶和華說的。』」</span>
<span className="v" id="v4" data-v="4"> <span className="pl pl-1">以下是耶和華談論以色列和猶大的話。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="西番雅書 1:10–11; 阿摩司書 8:10; 以賽亞書 5:30"> <span className="pl pl-1">耶和華說：「我聽見驚恐戰慄的喊叫聲，</span><br /><span className="pl pl-1">沒有平安。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="那鴻書 2:10; 約珥書 2:6; 耶利米書 4:31"> <span className="pl pl-1">你們去問問看，</span><br /><span className="pl pl-1">男人能分娩嗎？</span><br /><span className="pl pl-1">為什麼我看見男人們都雙手捂著肚子，</span><br /><span className="pl pl-1">好像分娩的婦人，</span><br /><span className="pl pl-1">臉色蒼白呢？</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="但以理書 12:1; 撒迦利亞書 14:1–2; 瑪拉基書 4:1"> <span className="pl pl-1">唉！無比可怕的日子快來了，</span><br /><span className="pl pl-1">那將是雅各子孫的苦難之日，</span><br /><span className="pl pl-1">但他們必得拯救。」</span></span>
<span className="v" id="v8" data-v="8" data-xref="那鴻書 1:13; 以西結書 34:27; 以賽亞書 9:4"> 萬軍之耶和華說：「那日，我要折斷他們頸上的軛，砍斷他們的鎖鏈，使他們不再受外族人奴役。</span>
<span className="v" id="v9" data-v="9" data-xref="何西阿書 3:5; 以賽亞書 55:3–5; 路加福音 1:69"> 他們要事奉他們的上帝耶和華，服侍我為他們選立來坐大衛寶座的王。</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米書 46:27–28; 以賽亞書 43:5; 耶利米書 29:14"> <span className="pl pl-1">「我的僕人雅各啊，不要害怕；</span><br /><span className="pl pl-1">以色列啊，不要驚慌。</span><br /><span className="pl pl-1">這是耶和華說的。</span><br /><span className="pl pl-1">因為我必從遠方拯救你，</span><br /><span className="pl pl-1">從流亡之地拯救你的後裔，</span><br /><span className="pl pl-1">使雅各重歸故土，安享太平，</span><br /><span className="pl pl-1">不受驚嚇。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="耶利米書 10:24; 耶利米書 1:19; 以賽亞書 8:10"> <span className="pl pl-1">因為我與你同在，</span><br /><span className="pl pl-1">要拯救你。</span><br /><span className="pl pl-1">這是耶和華說的。</span><br /><span className="pl pl-1">我要徹底毀滅列國，</span><br /><span className="pl pl-1">就是我曾使你流亡的地方。</span><br /><span className="pl pl-1">但我不會徹底毀滅你，</span><br /><span className="pl pl-1">也不會放過你，</span><br /><span className="pl pl-1">我必公正地懲治你。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="耶利米書 15:18; 耶利米書 30:15; 耶利米書 14:17"> <span className="pl pl-1">耶和華說：</span><br /><span className="pl pl-1">「你們的創傷無法醫治，</span><br /><span className="pl pl-1">你們的傷口無法痊癒。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="耶利米書 46:11; 耶利米書 8:22; 耶利米書 30:17"> <span className="pl pl-1">沒有人為你們辯護，</span><br /><span className="pl pl-1">你們的傷處無藥可治，</span><br /><span className="pl pl-1">你們無法痊癒。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="耶利米書 5:6; 約伯記 30:21; 耶利米哀歌 1:2"> <span className="pl pl-1">你們的盟友都忘了你們，</span><br /><span className="pl pl-1">對你們漠不關心。</span><br /><span className="pl pl-1">我要像你們的仇敵一樣擊打你們，</span><br /><span className="pl pl-1">像敵人一樣殘酷地懲罰你們，</span><br /><span className="pl pl-1">因為你們罪大惡極，罪過無數。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="耶利米書 30:14; 耶利米書 30:12; 耶利米書 6:6–7"> <span className="pl pl-1">你們緣何為自己的創傷哭泣？</span><br /><span className="pl pl-1">你們的創傷無法醫治。</span><br /><span className="pl pl-1">因為你們罪大惡極，罪過無數，</span><br /><span className="pl pl-1">我才這樣懲罰你們。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="耶利米書 10:25; 以賽亞書 33:1; 出埃及記 23:22"> <span className="pl pl-1">然而，吞吃你們的必被吞吃，</span><br /><span className="pl pl-1">你們的敵人全被擄走，</span><br /><span className="pl pl-1">擄掠你們的必被擄掠，</span><br /><span className="pl pl-1">搶奪你們的必被搶奪。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="詩篇 107:20; 耶利米書 33:6; 彼得前書 2:24"> <span className="pl pl-1">因為你們被稱為棄兒，</span><br /><span className="pl pl-1">是無人關心的錫安，</span><br /><span className="pl pl-1">我要醫治你們的創傷，</span><br /><span className="pl pl-1">使你們康復。</span><br /><span className="pl pl-1">這是耶和華說的。」</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="哈該書 2:7–9; 詩篇 102:13; 耶利米書 30:3"> <span className="pl pl-1">耶和華說：</span><br /><span className="pl pl-1">「看啊，我要使雅各家被擄的子孫返鄉，</span><br /><span className="pl pl-1">我要憐憫他們的家園，</span><br /><span className="pl pl-1">使他們在廢墟上重建城邑，</span><br /><span className="pl pl-1">在原處重修宮殿。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="耶利米書 33:22; 以賽亞書 51:11; 以賽亞書 60:22"> <span className="pl pl-1">那裡必傳出感謝和歡樂的聲音。</span><br /><span className="pl pl-1">我必使他們人丁興旺，</span><br /><span className="pl pl-1">不再減少；</span><br /><span className="pl pl-1">我必使他們得享尊榮，</span><br /><span className="pl pl-1">不再受歧視。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="耶利米書 32:39; 耶利米書 2:3; 耶利米書 50:33–34"> <span className="pl pl-1">他們的兒女要如往日一樣興旺，</span><br /><span className="pl pl-1">我要使他們的會眾堅立，</span><br /><span className="pl pl-1">我要懲罰所有壓迫他們的人。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="民數記 16:5; 以西結書 34:23–24; 使徒行傳 5:31"> <span className="pl pl-1">他們的首領將是自己的同胞，</span><br /><span className="pl pl-1">他們的元首將出自本族。</span><br /><span className="pl pl-1">我必帶領他近前來，他必到我面前，</span><br /><span className="pl pl-1">因為無人敢貿然來到我面前。</span><br /><span className="pl pl-1">這是耶和華說的。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="啟示錄 21:3; 以西結書 36:28; 耶利米書 31:33"> <span className="pl pl-1">你們要做我的子民，</span><br /><span className="pl pl-1">我要做你們的上帝。」</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="耶利米書 23:19–20; 撒迦利亞書 9:14; 耶利米書 25:32"> <span className="pl pl-1">看啊，耶和華的怒氣必如風暴一樣橫掃過來，</span><br /><span className="pl pl-1">颳到惡人頭上。</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="耶利米書 23:20; 何西阿書 3:5; 彌迦書 4:1"> <span className="pl pl-1">耶和華不完成祂心中的計劃，</span><br /><span className="pl pl-1">祂的烈怒必不止息。</span><br /><span className="pl pl-1">將來有一天，你們會明白。</span></span>

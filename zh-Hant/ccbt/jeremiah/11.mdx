## 猶大毀約

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華對耶利米說：</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米書 11:6; 出埃及記 19:5; 歷代志下 29:10"> 「你要聽這約上的話，把內容告訴猶大人和耶路撒冷的居民。</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 27:26; 申命記 28:15–68; 申命記 29:19–20"> 你要告訴他們，以色列的上帝耶和華說，『不遵守這約的人必受咒詛。</span>
<span className="v" id="v4" data-v="4" data-xref="利未記 26:12; 耶利米書 7:22–23; 申命記 4:20"> 我把你們的祖先從苦難的鐵熔爐埃及帶出來，那時我吩咐他們遵守這約。他們若聽從我的話，遵行我的吩咐，就必做我的子民，我也必做他們的上帝。</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 7:12–13; 詩篇 105:9–11; 耶利米書 28:6"> 這樣，我就實現我向你們祖先起的誓，賜給他們那奶蜜之鄉，正如今日一樣。』」我回答說：「耶和華啊，遵命！」</span>
<span className="v" id="v6" data-v="6" data-xref="雅各書 1:22; 羅馬書 2:13; 耶利米書 7:2"> 耶和華對我說：「你要在猶大各城和耶路撒冷的街頭宣告，呼籲百姓聽從、遵行這約。</span>
<span className="v" id="v7" data-v="7" data-xref="歷代志下 36:15; 以弗所書 4:17; 撒母耳記上 8:9"> 因為自從我帶你們祖先出埃及那天一直到今日，我一再勸誡他們要聽從我的話。</span>
<span className="v" id="v8" data-v="8" data-xref="耶利米書 7:24; 耶利米書 7:26; 耶利米書 35:15"> 然而，他們卻不聽不理，人人憑自己頑固的惡念行事。因此，我要使約中的一切咒詛臨到他們，因為我吩咐他們遵守這約，他們卻不遵守。」</span>
<span className="v" id="v9" data-v="9" data-xref="何西阿書 6:9; 馬太福音 26:3–4; 彌迦書 3:11"> 耶和華對我說：「猶大人和耶路撒冷的居民陰謀背叛我。</span>
<span className="v" id="v10" data-v="10" data-xref="申命記 31:16; 以西結書 16:59; 詩篇 78:8–10"> 他們重蹈祖先的覆轍，不聽從我的話，跟從、祭拜其他神明。以色列和猶大都違背了我與他們祖先立的約。</span>
<span className="v" id="v11" data-v="11" data-xref="以西結書 8:18; 箴言 1:28; 以賽亞書 1:15"> 所以我要使他們災難臨頭，無法逃脫，任他們高聲呼求，我也不聽。這是耶和華說的。</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米書 2:28; 申命記 32:37; 歷代志下 28:22"> 那時，猶大各城和耶路撒冷的居民必去呼求他們燒香供奉的神明，但災難來臨時，那些神明根本救不了他們。</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米書 2:28; 列王紀下 23:13; 以賽亞書 2:8"> 猶大啊，你的神明多如你的城邑，你給可憎的巴力燒香的祭壇多如耶路撒冷的街道。</span>
<span className="v" id="v14" data-v="14" data-xref="耶利米書 7:16; 耶利米書 11:11; 約翰一書 5:16"> 「因此，耶利米啊，你不要為這些人祈禱，不要為他們呼求禱告，因為他們遭難時向我呼求，我必不理會他們。</span>
<span className="v" id="v15" data-v="15" data-xref="箴言 2:14; 提多書 1:15; 耶利米書 3:1–2"> 我所愛的子民既然罪惡滔天，還在我殿裡做什麼？難道祭肉可以為他們消災免禍嗎？他們以作惡為樂。</span>
<span className="v" id="v16" data-v="16" data-xref="羅馬書 11:17–24; 以賽亞書 27:11; 詩篇 52:8"> 耶和華曾稱他們為枝繁葉茂、果實佳美的橄欖樹，但現在祂要在呼嘯的風暴中把它點燃，燒毀它的枝條。</span>
<span className="v" id="v17" data-v="17" data-xref="以賽亞書 5:2; 耶利米書 2:21; 耶利米書 12:2"> 我萬軍之耶和華曾栽培以色列人和猶大人，如今我要降禍給他們，因為他們作惡，向巴力獻祭，惹我發怒。」</span>
</div>
</div>

## 謀害耶利米

<div className="bt">
<div className="bp poetry">
<span className="v" id="v18" data-v="18" data-xref="撒母耳記上 23:11–12; 列王紀下 6:9–10; 以西結書 8:6–18"> 有人想謀害我，耶和華告訴了我，我才知道，那時祂讓我看見他們的所作所為。</span>
<span className="v" id="v19" data-v="19" data-xref="以賽亞書 53:7–8; 耶利米書 20:10; 詩篇 83:4"> 我好像一隻被牽去宰殺的馴良羊羔，不知他們要謀害我。他們說：<br /><span className="pl pl-1">「我們把這棵樹連果子一同毀滅，</span><br /><span className="pl pl-1">我們從世上除掉它，</span><br /><span className="pl pl-1">使它的名字被遺忘吧！」</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="耶利米書 20:12; 耶利米書 17:10; 撒母耳記上 16:7"> <span className="pl pl-1">然而，審判公正、洞察肺腑心腸的萬軍之耶和華啊，</span><br /><span className="pl pl-1">願我能看見你報應他們，</span><br /><span className="pl pl-1">因為我已向你陳明我的冤屈。</span></span>
<span className="v" id="v21" data-v="21" data-xref="耶利米書 20:10; 阿摩司書 2:12; 路加福音 13:33–34"> 亞拿突人想殺我，他們威脅我說：「你不要奉耶和華的名說預言，免得死在我們手上。」因此，萬軍之耶和華說：「看啊，我必懲罰他們。他們的青年必喪身刀下，他們的子女必死於饑荒，</span>
<span className="v" id="v23" data-v="23" data-xref="耶利米書 23:12; 彌迦書 7:4; 何西阿書 9:7"> 一個不留。因為在亞拿突人受罰之年，我必降災難給他們。」</span>

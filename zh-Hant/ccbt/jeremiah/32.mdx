## 耶利米買田

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="耶利米書 39:1–2; 列王紀下 25:1–2; 耶利米書 25:1"> 猶大王西底迦第十年，就是尼布甲尼撒第十八年，耶和華的話傳給了耶利米。</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米書 37:21; 尼希米記 3:25; 耶利米書 33:1"> 那時，巴比倫王的軍隊正圍攻耶路撒冷。耶利米先知被囚禁在猶大王宮中護衛的院子裡。</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米書 34:2–3; 耶利米書 21:4–7; 耶利米書 26:8–9"> 猶大王西底迦囚禁了他，責問他為什麼預言說：「耶和華說，『看啊，我要把這座城交在巴比倫王手中，他必攻佔這座城。</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米書 39:4–7; 列王紀下 25:4–7; 耶利米書 37:17"> 猶大王西底迦逃不出迦勒底人的手心，必落入巴比倫王手中，與他面對面、眼對眼地說話。</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米書 39:7; 以西結書 17:9–10; 以西結書 17:15"> 他必把西底迦帶到巴比倫，西底迦要住在那裡，直到我懲罰他。你們和迦勒底人作戰註定要失敗。這是耶和華說的。』」</span>
<span className="v" id="v6" data-v="6"> 耶利米說：「耶和華對我說，</span>
<span className="v" id="v7" data-v="7" data-xref="耶利米書 1:1; 耶利米書 11:21; 利未記 25:25"> 『看啊，你叔父沙龍的兒子哈拿篾會來找你，讓你買下他在亞拿突的那塊田地，說你是他的近親，理當買下它。』」</span>
<span className="v" id="v8" data-v="8" data-xref="耶利米書 32:7; 耶利米書 32:2; 耶利米書 33:1"> 果然如耶和華所言，我堂兄弟哈拿篾到護衛的院子裡對我說：「我在便雅憫境內的亞拿突有一塊田，求你買下它，因為你有權承接和買贖。求你買下吧！」我知道這是耶和華的旨意。</span>
<span className="v" id="v9" data-v="9" data-xref="撒迦利亞書 11:12–13; 以斯帖記 3:9; 列王紀上 20:39"> 於是，我從堂兄弟哈拿篾手裡買了亞拿突的那塊田。我簽訂了契約，封好，請來證人並稱了四兩銀子給他。</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 2:27; 哥林多前書 11:16; 使徒行傳 26:3"> 我拿著列明條款、一份加了封印和一份沒有加封印的地契，</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米書 32:16; 耶利米書 51:59; 耶利米書 36:4–5"> 當著堂兄弟哈拿篾、在地契上簽名的證人和護衛院子裡所有猶大人的面，把地契交給瑪西雅的孫子、尼利亞的兒子巴錄。</span>
<span className="v" id="v13" data-v="13"> 我當眾對巴錄說：</span>
<span className="v" id="v14" data-v="14"> 「以色列的上帝——萬軍之耶和華吩咐你把封印的和沒有封印的兩份地契放在一個瓦瓶裡，長期保存。</span>
<span className="v" id="v15" data-v="15" data-xref="撒迦利亞書 3:10; 阿摩司書 9:14–15; 耶利米書 30:18"> 因為以色列的上帝——萬軍之耶和華說，將來必有人在這裡重新買房屋、田地和葡萄園。」</span>
<span className="v" id="v16" data-v="16" data-xref="耶利米書 12:1; 創世記 32:9–12; 腓立比書 4:6–7"> 我把地契交給尼利亞的兒子巴錄之後，便向耶和華禱告說：</span>
<span className="v" id="v17" data-v="17" data-xref="路加福音 1:37; 耶利米書 32:27; 創世記 18:14"> 「主耶和華啊，看啊，你伸出臂膀以大能創造天地，你無所不能。</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米書 10:16; 申命記 5:9–10; 出埃及記 34:7"> 你恩待千萬人，也向後世的子孫追討他們祖先所犯的罪。偉大全能的上帝啊！你名叫萬軍之耶和華。</span>
<span className="v" id="v19" data-v="19" data-xref="耶利米書 17:10; 馬太福音 16:27; 詩篇 62:12"> 你有偉大的計劃和大能的作為，你鑒察世人的一舉一動，按照各人的行為施行賞罰。</span>
<span className="v" id="v20" data-v="20" data-xref="尼希米記 9:10; 撒母耳記下 7:23; 出埃及記 10:2"> 你曾在埃及行神蹟奇事，現今仍在以色列和世人中間行神蹟奇事，使自己威名遠揚，正如今日。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及記 6:6; 申命記 26:8; 詩篇 105:43"> 你伸出臂膀用大能的手行神蹟奇事及可畏的事，領你的以色列子民出了埃及。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及記 3:8; 出埃及記 13:5; 耶利米書 11:5"> 你信守對他們祖先的應許，賜給他們這奶蜜之鄉。</span>
<span className="v" id="v23" data-v="23" data-xref="以斯拉記 9:7; 詩篇 78:54–55; 但以理書 9:10–14"> 他們進入並得到這塊土地之後，卻不聽你的話，也不遵行你的律法，對你的吩咐置若罔聞，因此你使他們大禍臨頭。</span>
<span className="v" id="v24" data-v="24" data-xref="耶利米書 32:36; 申命記 4:26; 約書亞記 23:15–16"> 看啊，敵人已經修築高臺要攻打這城，這城要因刀劍、饑荒和瘟疫而落入迦勒底人手中。你所說的都應驗了，你也看見了。</span>
<span className="v" id="v25" data-v="25" data-xref="耶利米書 32:24; 詩篇 97:2; 詩篇 77:19"> 主耶和華啊！雖然這城快要落入迦勒底人手中了，可是你還要我在證人面前買下這塊地。」</span>
<span className="v" id="v26" data-v="26"> 耶和華對耶利米說：</span>
<span className="v" id="v27" data-v="27" data-xref="馬太福音 19:26; 耶利米書 32:17; 以賽亞書 64:8"> 「看啊，我是耶和華，是所有世人的上帝，難道有我做不到的事嗎？</span>
<span className="v" id="v28" data-v="28" data-xref="耶利米書 32:3; 耶利米書 32:24; 耶利米書 19:7–12"> 看啊，我要把這城交在巴比倫王尼布甲尼撒和他率領的迦勒底人手中，讓他們攻取這城。這是耶和華說的。</span>
<span className="v" id="v29" data-v="29" data-xref="耶利米書 21:10; 耶利米書 19:13; 耶利米書 52:13"> 攻城的迦勒底人必放火焚城，把城中的房屋付之一炬，城中的居民曾在房頂上向巴力燒香、向其他神明奠酒，惹我發怒。</span>
<span className="v" id="v30" data-v="30" data-xref="耶利米書 7:22–26; 申命記 9:7–12; 耶利米書 25:7"> 以色列人和猶大人自幼就行我視為惡的事，以色列人的所作所為惹我發怒。這是耶和華說的。</span>
<span className="v" id="v31" data-v="31" data-xref="列王紀下 23:27; 耶利米書 27:10; 列王紀下 21:4–7"> 這城自從建立以來直到如今一直惹我發怒，以致我決意從眼前毀滅它。</span>
<span className="v" id="v32" data-v="32" data-xref="但以理書 9:8; 耶利米書 2:26; 以賽亞書 1:4–6"> 以色列和猶大的君王和官長、祭司和先知、猶大百姓和耶路撒冷居民的惡行讓我憤怒。</span>
<span className="v" id="v33" data-v="33" data-xref="耶利米書 7:13; 耶利米書 2:27; 以西結書 8:16"> 他們不是面向我而是背對我，我不厭其煩地教導他們，他們卻不肯聽，不受教。</span>
<span className="v" id="v34" data-v="34" data-xref="耶利米書 7:30; 以西結書 8:5–16; 列王紀下 21:4–7"> 他們把可憎的神像放在我的殿中，玷污了我的殿；</span>
<span className="v" id="v35" data-v="35" data-xref="耶利米書 7:31; 歷代志下 33:6; 利未記 18:21"> 他們在欣嫩子谷為巴力建邱壇，用自己的兒女作祭物獻給摩洛，使猶大陷入罪中。我從未吩咐他們做如此可憎之事，連想都沒想過。</span>
<span className="v" id="v36" data-v="36" data-xref="耶利米書 32:24; 耶利米書 32:3; 耶利米書 32:28"> 「你們說這座城要因刀劍、饑荒和瘟疫而落入巴比倫王手中，但以色列的上帝耶和華說，</span>
<span className="v" id="v37" data-v="37" data-xref="耶利米書 23:3; 耶利米書 23:6; 以西結書 34:12–14"> 『看啊，我曾在怒氣、義憤和烈怒中把他們驅散到各地，我也必招聚他們，領他們回到故土，使他們安居樂業。</span>
<span className="v" id="v38" data-v="38" data-xref="耶利米書 24:7; 以西結書 11:19–20; 希伯來書 8:10"> 他們要做我的子民，我要做他們的上帝。</span>
<span className="v" id="v39" data-v="39" data-xref="以西結書 11:19–20; 使徒行傳 4:32; 約翰福音 17:21"> 我要使他們同心合意，永遠敬畏我，使他們和子孫得到福樂。</span>
<span className="v" id="v40" data-v="40" data-xref="耶利米書 31:31–33; 以西結書 36:26; 耶利米書 24:7"> 我要與他們立永遠的約，永遠恩待他們，使他們對我心存敬畏，不再背棄我。</span>
<span className="v" id="v41" data-v="41" data-xref="耶利米書 24:6; 西番雅書 3:17; 以賽亞書 62:5"> 我必以恩待他們為樂，全心全意在這地方培育他們。』</span>
<span className="v" id="v42" data-v="42" data-xref="耶利米書 31:28; 約書亞記 23:14–15; 耶利米書 33:10–11"> 「耶和華說，『我曾降下這一切災禍給他們，我也要把我應許的福樂賜給他們。</span>
<span className="v" id="v43" data-v="43" data-xref="以西結書 37:11–14; 耶利米書 32:15; 耶利米書 32:36"> 你們說這地方落在了迦勒底人手中，變得一片荒涼，人畜絕跡。但將來這地方必再有人置買田產。</span>
<span className="v" id="v44" data-v="44" data-xref="耶利米書 17:26; 耶利米書 33:26; 耶利米書 33:11"> 在便雅憫境內，耶路撒冷周圍和猶大的城邑，以及山區、丘陵、南地的城邑中，必有人用銀子置買田地，簽訂地契，蓋封印，請人作證，因為我必使被擄的人回到故土。這是耶和華說的。』」</span>

## 猶大的滅亡

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀下 24:18; 約書亞記 10:29; 歷代志下 36:11"> 西底迦二十一歲登基，在耶路撒冷執政十一年。他母親叫哈慕她，是立拿人耶利米的女兒。</span>
<span className="v" id="v2" data-v="2" data-xref="列王紀上 14:22; 列王紀下 24:19–20; 以西結書 17:16–20"> 西底迦像約雅敬一樣做耶和華視為惡的事。</span>
<span className="v" id="v3" data-v="3" data-xref="以賽亞書 3:4–5; 歷代志下 36:13; 以賽亞書 3:1"> 因此，耶和華向耶路撒冷和猶大的人發怒，最終把他們從祂面前趕走。 後來，西底迦背叛了巴比倫王。</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米書 39:1; 撒迦利亞書 8:19; 以西結書 24:1–2"> 在他執政第九年十月十日，巴比倫王尼布甲尼撒率領全軍攻打耶路撒冷，在城外安營，修築圍城的高臺。</span>
<span className="v" id="v5" data-v="5"> 城一直被圍困到西底迦王執政第十一年。</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米書 39:2; 以賽亞書 3:1; 列王紀下 25:3"> 那年四月九日，城裡饑荒非常嚴重，百姓無糧可吃。</span>
<span className="v" id="v7" data-v="7" data-xref="耶利米書 39:4–7; 耶利米書 51:32; 列王紀下 25:4"> 城被攻破，西底迦和士兵便在夜間從靠近御花園的兩城牆中間的門逃往亞拉巴。當時迦勒底人仍四面包圍著城。</span>
<span className="v" id="v8" data-v="8" data-xref="耶利米書 34:21; 耶利米書 32:4; 耶利米書 38:23"> 迦勒底的軍隊追趕西底迦，在耶利哥平原追上了他。他的軍隊都四散而逃。</span>
<span className="v" id="v9" data-v="9" data-xref="耶利米書 39:5; 民數記 13:21; 列王紀下 25:6"> 迦勒底人擒住西底迦，把他押到哈馬的利比拉去見巴比倫王。巴比倫王在那裡審判他，</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米書 22:30; 列王紀下 25:7; 創世記 21:16"> 當著他的面殺了他的眾子和猶大所有的官員，</span>
<span className="v" id="v11" data-v="11" data-xref="以西結書 12:13; 耶利米書 34:3–5"> 又剜去他的雙眼，把他用銅鏈鎖著押往巴比倫，將他終生囚在牢裡。</span>
<span className="v" id="v12" data-v="12" data-xref="列王紀下 25:8; 耶利米書 39:9; 耶利米書 52:29"> 巴比倫王尼布甲尼撒執政第十九年五月十日，他的臣僕護衛長尼布撒拉旦進入耶路撒冷，</span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 79:1; 彌迦書 3:12; 歷代志下 36:19"> 放火焚燒耶和華的殿、王宮及耶路撒冷所有的房屋。他燒毀了所有重要建築。</span>
<span className="v" id="v14" data-v="14" data-xref="尼希米記 1:3; 列王紀下 25:10"> 他率領的迦勒底軍隊拆毀了耶路撒冷四圍的城牆。</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米書 15:1–2; 撒迦利亞書 14:2"> 護衛長尼布撒拉旦擄去最貧窮的人、城中的餘民、那些投降巴比倫王的人和剩下的技工，</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀下 25:12; 耶利米書 39:9–10; 耶利米書 40:5–7"> 只留下一些最貧窮的人，讓他們照料葡萄園、耕種田地。</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米書 27:19–22; 耶利米書 52:21–23; 歷代志下 4:12–15"> 迦勒底人打碎耶和華殿中的銅柱、銅底座和銅海，把銅運往巴比倫，</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及記 27:3; 民數記 4:14; 列王紀上 7:45"> 並帶走了盆、鏟、燈剪、碗、碟及一切獻祭用的銅器。</span>
<span className="v" id="v19" data-v="19" data-xref="列王紀上 7:49–50; 歷代志下 4:6–22; 利未記 26:12"> 護衛長還帶走了杯、火鼎、碗、盆、燈臺、碟和奠酒的杯等所有金銀器皿。</span>
<span className="v" id="v20" data-v="20" data-xref="列王紀上 7:47; 列王紀下 25:16; 歷代志下 4:18"> 所羅門王為耶和華的殿所造的兩根銅柱、一個銅海、銅海下面的十二頭銅牛，以及一些銅底座，用的銅多得無法計算。</span>
<span className="v" id="v21" data-v="21" data-xref="列王紀下 25:17; 列王紀上 7:15–21; 歷代志下 3:15–17"> 兩根銅柱中空，高八米，周長五米四，銅壁厚四指。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及記 28:25; 列王紀下 25:17; 歷代志下 3:15"> 銅柱有柱冠，柱冠高兩米二，柱冠周圍裝飾著銅網和銅石榴。兩根柱子都一樣。</span>
<span className="v" id="v23" data-v="23" data-xref="列王紀上 7:20"> 每根銅柱周圍裝飾著九十六個石榴，網子四周共有一百個石榴。</span>
<span className="v" id="v24" data-v="24" data-xref="列王紀下 25:18; 耶利米書 29:25; 耶利米書 35:4"> 護衛長擄走祭司長西萊雅、副祭司長西番亞和三名殿門守衛，</span>
<span className="v" id="v25" data-v="25" data-xref="列王紀下 25:19; 以斯帖記 1:14; 馬太福音 18:10"> 又從城中擄走一名統管士兵的將領、王的七個親信、一名負責招兵的書記和城中找到的六十名平民，</span>
<span className="v" id="v26" data-v="26"> 把他們帶到利比拉去見巴比倫王。</span>
<span className="v" id="v27" data-v="27" data-xref="以西結書 33:28; 以賽亞書 32:13–14; 以賽亞書 6:11–12"> 巴比倫王在哈馬地區的利比拉處死了他們。猶大人就這樣被擄去，離開了家園。</span>
<span className="v" id="v28" data-v="28" data-xref="列王紀下 24:12–16; 列王紀下 24:2–3; 但以理書 1:1–3"> 以下是尼布甲尼撒擄去的人數：他執政第七年擄去三千零二十三名猶大人；</span>
<span className="v" id="v29" data-v="29" data-xref="耶利米書 52:12; 創世記 12:5; 列王紀下 25:11"> 他執政第十八年，從耶路撒冷擄去八百三十二人；</span>
<span className="v" id="v30" data-v="30" data-xref="耶利米書 52:15; 耶利米書 6:9"> 他執政第二十三年，他的護衛長尼布撒拉旦擄去七百四十五名猶大人。總共四千六百人。</span>
<span className="v" id="v31" data-v="31" data-xref="列王紀下 25:27–30; 詩篇 3:3; 創世記 40:13"> 猶大王約雅斤被擄後第三十七年，即巴比倫王以未·米羅達元年十二月二十五日，巴比倫王恩待約雅斤，釋放了他，</span>
<span className="v" id="v32" data-v="32" data-xref="箴言 12:25; 但以理書 5:18–19; 但以理書 2:37"> 並好言相待，使他的地位高過被擄到巴比倫的其他各王。</span>
<span className="v" id="v33" data-v="33" data-xref="撒母耳記下 9:7; 列王紀上 2:7; 創世記 41:14"> 約雅斤脫去了囚服，終生與巴比倫王一起吃飯。</span>
<span className="v" id="v34" data-v="34" data-xref="撒母耳記下 9:10; 路加福音 11:3; 馬太福音 6:11"> 在他有生之年，巴比倫王供應他每天的需用，直到他去世。</span>

## 耶路撒冷的罪

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="創世記 18:23–32; 歷代志下 16:9; 以西結書 22:30"> 耶和華說：<br /><span className="pl pl-1">「你們在耶路撒冷街頭四處看看，</span><br /><span className="pl pl-1">在廣場找找，</span><br /><span className="pl pl-1">如果你們能找到一個公正誠實的人，</span><br /><span className="pl pl-1">我就赦免這城。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="提多書 1:16; 耶利米書 4:2; 何西阿書 4:1–2"> <span className="pl pl-1">雖然他們憑永活的耶和華起誓，</span><br /><span className="pl pl-1">卻口是心非。」</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="耶利米書 2:30; 耶利米書 7:28; 以賽亞書 9:13"> <span className="pl pl-1">耶和華啊，你關注的不是誠實嗎？</span><br /><span className="pl pl-1">你責打他們，他們不感到疼痛；</span><br /><span className="pl pl-1">你嚴懲他們，他們仍不受教。</span><br /><span className="pl pl-1">他們拒不悔改，</span><br /><span className="pl pl-1">臉比石頭還硬。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v4" data-v="4" data-xref="耶利米書 8:7; 何西阿書 4:6; 以賽亞書 28:9–13"> <span className="pl pl-1">我想：「他們貧窮、愚昧，</span><br /><span className="pl pl-1">不明白耶和華的道，</span><br /><span className="pl pl-1">也不知道他們上帝的法令。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="耶利米書 2:20; 雅各書 2:5–7; 馬太福音 19:23–26"> <span className="pl pl-1">我要找他們的首領說話，</span><br /><span className="pl pl-1">因為這些首領明白耶和華的道，</span><br /><span className="pl pl-1">知道他們上帝的法令。」</span><br /><span className="pl pl-1">然而，他們卻一致折斷軛，</span><br /><span className="pl pl-1">掙開繩索。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="耶利米書 4:7; 哈巴谷書 1:8; 西番雅書 3:3"> <span className="pl pl-1">因此，林中的獅子必襲擊他們，</span><br /><span className="pl pl-1">荒野的豺狼必殘害他們，</span><br /><span className="pl pl-1">豹子也蹲伏在他們的城外，</span><br /><span className="pl pl-1">伺機撕裂出城的人，</span><br /><span className="pl pl-1">因為他們罪大惡極，屢屢叛道。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="加拉太書 4:8; 約書亞記 23:7; 耶利米書 2:11"> <span className="pl pl-1">耶和華說：</span><br /><span className="pl pl-1">「耶路撒冷啊，我怎能赦免你呢？</span><br /><span className="pl pl-1">你的兒女背棄我，</span><br /><span className="pl pl-1">憑假神起誓。</span><br /><span className="pl pl-1">我供應他們的一切需要，</span><br /><span className="pl pl-1">他們卻縱情淫亂，</span><br /><span className="pl pl-1">湧向娼妓的家。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="耶利米書 13:27; 申命記 5:18; 撒母耳記下 11:2–4"> <span className="pl pl-1">他們像吃得肥壯、發情的公馬，</span><br /><span className="pl pl-1">個個垂涎鄰居的妻子。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="耶利米書 9:9; 耶利米書 5:29; 以賽亞書 1:24"> <span className="pl pl-1">我怎能不懲罰他們呢？</span><br /><span className="pl pl-1">我怎能不親自報應這樣的國民呢？</span><br /><span className="pl pl-1">這是耶和華說的。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="耶利米書 4:27; 馬太福音 22:7; 阿摩司書 9:8"> <span className="pl pl-1">你們要上去毀壞她的葡萄園，</span><br /><span className="pl pl-1">但不可徹底毀壞。</span><br /><span className="pl pl-1">要砍掉枝子，</span><br /><span className="pl pl-1">因為那些枝子不屬於耶和華。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="耶利米書 3:20; 以賽亞書 48:8; 何西阿書 6:7"> <span className="pl pl-1">以色列家和猶大家全然背叛我。</span><br /><span className="pl pl-1">這是耶和華說的。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="歷代志下 36:16; 以西結書 12:22–28; 耶利米書 23:14–17"> <span className="pl pl-1">「他們毀謗耶和華說，</span><br /><span className="pl pl-1">『祂不會管的，災禍不會臨到我們，</span><br /><span className="pl pl-1">我們必不會遇見刀劍和饑荒。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="耶利米書 14:15; 約伯記 8:2; 耶利米書 14:13"> <span className="pl pl-1">先知不過是一陣風，</span><br /><span className="pl pl-1">他們的話並非來自上帝，</span><br /><span className="pl pl-1">他們預言的災禍必降臨到自己身上。』」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="耶利米書 23:29; 耶利米書 1:9; 何西阿書 6:5"> <span className="pl pl-1">因此，萬軍之上帝耶和華對我說：</span><br /><span className="pl pl-1">「因為他們說了這話，</span><br /><span className="pl pl-1">我要使我的話在你口中成為火，</span><br /><span className="pl pl-1">使他們像柴一樣被燒毀。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="申命記 28:49; 耶利米書 4:16; 以賽亞書 33:19"> <span className="pl pl-1">以色列家啊，我要使一個國家，</span><br /><span className="pl pl-1">一個歷久不衰的古國從遠方來攻擊你們，</span><br /><span className="pl pl-1">你們不明白他們的語言，</span><br /><span className="pl pl-1">也聽不懂他們說的話。</span><br /><span className="pl pl-1">這是耶和華說的。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="以賽亞書 5:28; 詩篇 5:9; 羅馬書 3:13"> <span className="pl pl-1">他們都是勇士，</span><br /><span className="pl pl-1">他們的箭袋像敞開的墳墓。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="利未記 26:16; 申命記 28:33; 何西阿書 8:14"> <span className="pl pl-1">他們必吞噬你們的莊稼和糧食，</span><br /><span className="pl pl-1">吞噬你們的兒女，</span><br /><span className="pl pl-1">吞噬你們的牛羊，</span><br /><span className="pl pl-1">吞噬你們的葡萄和無花果，</span><br /><span className="pl pl-1">用刀劍摧毀你們所依靠的堅城。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v18" data-v="18" data-xref="耶利米書 5:10; 羅馬書 11:1–5; 耶利米書 4:27"> 耶和華說：「即使在那時，我也不會徹底毀滅你們。</span>
<span className="v" id="v19" data-v="19" data-xref="列王紀上 9:8–9; 申命記 28:47–48; 耶利米書 22:8–9"> 耶利米啊，如果有人問，『為什麼我們的上帝耶和華這樣待我們？』你可以對他們說，『你們怎樣背棄耶和華，在自己的土地上供奉外族的神明，也要怎樣在異地他鄉服侍外族人。』</span>
<span className="v" id="v20" data-v="20"> <span className="pl pl-1">「要向雅各家宣告，</span><br /><span className="pl pl-1">在猶大傳講，</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="使徒行傳 28:26; 以西結書 12:2; 以賽亞書 6:9–10"> <span className="pl pl-1">『聽著，你們這群愚昧無知的人啊，</span><br /><span className="pl pl-1">你們視而不見，</span><br /><span className="pl pl-1">聽而不聞。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="約伯記 38:10–11; 詩篇 104:9; 約伯記 26:10"> <span className="pl pl-1">難道你們不該敬畏我嗎？</span><br /><span className="pl pl-1">這是耶和華說的。</span><br /><span className="pl pl-1">難道你們在我面前不該顫抖嗎？</span><br /><span className="pl pl-1">我以沙石為海的界限，</span><br /><span className="pl pl-1">使水永遠不能越過它。</span><br /><span className="pl pl-1">洶湧的波濤不能逾越，</span><br /><span className="pl pl-1">澎湃的海浪不能漫過。</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="耶利米書 6:28; 申命記 21:18; 詩篇 95:10"> <span className="pl pl-1">但你們這些人心裡頑固，</span><br /><span className="pl pl-1">悖逆成性。</span><br /><span className="pl pl-1">你們離我而去。</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="詩篇 147:8; 約珥書 2:23; 創世記 8:22"> <span className="pl pl-1">你們心中從不說，</span><br /><span className="pl pl-1">我們要敬畏我們的上帝耶和華，</span><br /><span className="pl pl-1">祂按時降下秋雨和春雨，</span><br /><span className="pl pl-1">讓我們按時收割。</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="以賽亞書 59:2; 詩篇 107:17; 詩篇 107:34"> <span className="pl pl-1">你們的罪過使你們不再風調雨順，</span><br /><span className="pl pl-1">你們的罪惡使你們失去祝福。』</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="箴言 1:11; 詩篇 64:5; 以西結書 22:2–12"> <span className="pl pl-1">我的子民中有惡人，</span><br /><span className="pl pl-1">他們像捕鳥人一樣埋伏等候，</span><br /><span className="pl pl-1">設下網羅陷害人。</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="彌迦書 1:12; 耶利米書 9:6; 何西阿書 12:7–8"> <span className="pl pl-1">他們的家裡充滿了詭詐，</span><br /><span className="pl pl-1">就像籠子裝滿了鳥。</span><br /><span className="pl pl-1">他們變得有財有勢，</span><br /></span>
<span className="v" id="v28" data-v="28" data-xref="以賽亞書 1:23; 申命記 32:15; 耶利米書 7:6"> <span className="pl pl-1">吃得肥胖紅潤，壞事做盡，</span><br /><span className="pl pl-1">不秉公審判，不為孤兒伸冤，</span><br /><span className="pl pl-1">不為窮人主持公道。」</span><br /></span>
<span className="v" id="v29" data-v="29" data-xref="耶利米書 5:9; 瑪拉基書 3:5; 耶利米書 9:9"> <span className="pl pl-1">耶和華說：「我怎能坐視不理呢？</span><br /><span className="pl pl-1">我怎能不懲罰這樣的國家呢？</span><br /></span>
<span className="v" id="v30" data-v="30" data-xref="何西阿書 6:10; 耶利米書 23:14; 以賽亞書 1:2"> <span className="pl pl-1">這地方發生了一件令人震驚、恐懼的事，</span><br /></span>
<span className="v" id="v31" data-v="31" data-xref="以西結書 13:6; 耶利米書 14:14; 彌迦書 2:11"> <span className="pl pl-1">就是先知說假預言，</span><br /><span className="pl pl-1">祭司濫用權力，</span><br /><span className="pl pl-1">我的子民卻以此為樂。</span><br /><span className="pl pl-1">但當最後的結局來臨時，</span><br /><span className="pl pl-1">他們還能做什麼呢？</span></span>

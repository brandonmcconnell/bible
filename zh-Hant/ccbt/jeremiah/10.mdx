## 上帝與偶像

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="何西阿書 4:1; 耶利米書 42:15; 阿摩司書 7:16"> 以色列家啊，聽聽耶和華對你們說的話吧！</span>
<span className="v" id="v2" data-v="2" data-xref="利未記 20:23; 利未記 18:3; 路加福音 21:25–28"> 耶和華說：<br /><span className="pl pl-1">「不要效法列國的行為。</span><br /><span className="pl pl-1">他們被天象嚇倒，</span><br /><span className="pl pl-1">你們卻不要因天象而害怕。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="以賽亞書 44:9–20; 利未記 18:30; 彼得前書 1:18"> <span className="pl pl-1">他們信奉的毫無價值，</span><br /><span className="pl pl-1">他們從林中砍一棵樹，</span><br /><span className="pl pl-1">工匠用鑿子雕刻偶像，</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="以賽亞書 46:7; 以賽亞書 40:19–20; 詩篇 115:4"> <span className="pl pl-1">以金銀作裝飾，</span><br /><span className="pl pl-1">用釘子和錘子釘牢，</span><br /><span className="pl pl-1">以免晃動。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="以賽亞書 46:7; 哥林多前書 12:2; 以賽亞書 41:23–24"> <span className="pl pl-1">它們像瓜園中的稻草人，</span><br /><span className="pl pl-1">不能說話，不能行走，</span><br /><span className="pl pl-1">需要人搬運。</span><br /><span className="pl pl-1">你們不要怕它們，</span><br /><span className="pl pl-1">它們既不能害人，</span><br /><span className="pl pl-1">也不能助人。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="詩篇 96:4; 出埃及記 15:11; 詩篇 48:1"> <span className="pl pl-1">耶和華啊，你無與倫比，</span><br /><span className="pl pl-1">你真偉大，你的名充滿力量！</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="啟示錄 15:4; 詩篇 22:28; 哥林多前書 1:19–20"> <span className="pl pl-1">萬國的王啊，誰不敬畏你？</span><br /><span className="pl pl-1">敬畏你是理所當然的。</span><br /><span className="pl pl-1">因為萬國的智者和君王中無人能與你相比。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="撒迦利亞書 10:2; 耶利米書 10:14; 詩篇 115:8"> <span className="pl pl-1">他們都愚昧無知，</span><br /><span className="pl pl-1">竟從無用的木頭偶像受教！</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 115:4; 但以理書 10:5; 列王紀上 10:22"> <span className="pl pl-1">偶像上的銀片來自他施，</span><br /><span className="pl pl-1">金片來自烏法，</span><br /><span className="pl pl-1">都是木匠和金匠的作品，</span><br /><span className="pl pl-1">這些偶像穿的藍色和紫色衣服都是巧匠製作的。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="申命記 32:4; 以賽亞書 57:15; 那鴻書 1:6"> <span className="pl pl-1">唯有耶和華是真神，</span><br /><span className="pl pl-1">是永活的上帝，</span><br /><span className="pl pl-1">是永恆的君王。</span><br /><span className="pl pl-1">祂一發怒，大地便震動，</span><br /><span className="pl pl-1">列國都無法承受祂的烈怒。</span></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="詩篇 96:5; 以賽亞書 2:18; 耶利米哀歌 3:66"> 你們要這樣對他們說：「那些神明沒有創造天地，它們將從天地間消亡。」</span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="創世記 1:1; 約伯記 9:8; 箴言 3:19"> <span className="pl pl-1">耶和華以大能創造大地，</span><br /><span className="pl pl-1">以智慧建立世界，</span><br /><span className="pl pl-1">以聰明鋪展諸天。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 135:7; 約伯記 38:22; 約伯記 38:34–35"> <span className="pl pl-1">祂一聲令下，天上便大水澎湃；</span><br /><span className="pl pl-1">祂使雲從地極升起，</span><br /><span className="pl pl-1">使閃電在雨中劃過，</span><br /><span className="pl pl-1">使風從祂的倉庫吹出。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="詩篇 135:16–18; 詩篇 115:4–8; 以賽亞書 46:7–8"> <span className="pl pl-1">世人都愚昧無知，</span><br /><span className="pl pl-1">金匠都因所造的偶像而羞愧，</span><br /><span className="pl pl-1">因為神像是騙人的，</span><br /><span className="pl pl-1">它們沒有生命氣息。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="耶利米書 14:22; 以賽亞書 41:24; 耶利米書 51:18"> <span className="pl pl-1">它們毫無價值，</span><br /><span className="pl pl-1">荒唐可笑，</span><br /><span className="pl pl-1">刑罰一到，必被毀滅。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="申命記 32:9; 耶利米書 32:18; 耶利米書 31:35"> <span className="pl pl-1">但雅各的上帝截然不同，</span><br /><span className="pl pl-1">因為祂是萬物的創造者，</span><br /><span className="pl pl-1">以色列子民是祂的產業，</span><br /><span className="pl pl-1">萬軍之耶和華是祂的名字。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="以西結書 12:3–12; 耶利米書 6:1; 馬太福音 24:15"> <span className="pl pl-1">被圍困的居民啊，</span><br /><span className="pl pl-1">收拾行裝離開吧！</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳記上 25:29; 撒迦利亞書 1:6; 申命記 28:63–64"> <span className="pl pl-1">因為耶和華說：</span><br /><span className="pl pl-1">「看啊，這次我要把這地方的居民拋出去，</span><br /><span className="pl pl-1">使他們苦不堪言方肯覺悟。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v19" data-v="19" data-xref="彌迦書 7:9; 耶利米書 4:31; 耶利米書 14:17"> <span className="pl pl-1">我有禍了！因我的創傷難癒。</span><br /><span className="pl pl-1">但我說：「這是疾病，我必須忍受。」</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="耶利米書 4:20; 耶利米書 31:15; 以賽亞書 54:2"> <span className="pl pl-1">我的帳篷已毀，</span><br /><span className="pl pl-1">繩索已斷；</span><br /><span className="pl pl-1">我的兒女都離我而去，蹤影全無，</span><br /><span className="pl pl-1">再沒有人為我支搭帳篷，</span><br /><span className="pl pl-1">掛上幔子。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="以西結書 34:2–10; 耶利米書 12:10; 耶利米書 23:1–2"> <span className="pl pl-1">首領愚昧，</span><br /><span className="pl pl-1">沒有求問耶和華，</span><br /><span className="pl pl-1">因此一敗塗地，</span><br /><span className="pl pl-1">百姓如羊群四散。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v22" data-v="22" data-xref="耶利米書 9:11; 哈巴谷書 1:6–9; 耶利米書 6:22"> <span className="pl pl-1">聽啊，有消息傳來，</span><br /><span className="pl pl-1">喧囂的敵軍從北方衝來，</span><br /><span className="pl pl-1">要使猶大的城邑荒涼，</span><br /><span className="pl pl-1">淪為豺狼的巢穴。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v23" data-v="23" data-xref="箴言 20:24; 箴言 16:1; 詩篇 37:23"> <span className="pl pl-1">耶和華啊，我知道人不能駕馭自己的命運，</span><br /><span className="pl pl-1">不能左右自己的前程。</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="詩篇 38:1; 詩篇 6:1; 耶利米書 30:11"> <span className="pl pl-1">耶和華啊，求你公正地懲罰我，</span><br /><span className="pl pl-1">不要帶著怒氣懲罰我，</span><br /><span className="pl pl-1">免得你使我不復存在。</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="詩篇 79:6–7; 耶利米書 8:16; 約伯記 18:21"> <span className="pl pl-1">求你向不認識你的列國和不求告你名的民族發烈怒，</span><br /><span className="pl pl-1">因為他們吞噬、毀滅雅各，</span><br /><span className="pl pl-1">使他的家園一片荒涼。</span></span>
</div>

## 應許以色列人必復興

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="耶利米書 38:28; 耶利米書 37:21; 耶利米書 32:2–3"> 耶利米仍被囚禁在護衛院子裡的時候，耶和華第二次對他說：</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 6:3; 出埃及記 15:3; 以賽亞書 37:26"> 「耶和華創造大地，使其成形、根基穩固，祂名叫耶和華。祂說，</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米書 29:12; 以賽亞書 65:24; 以弗所書 3:20"> 『你呼求我，我就回應你，並且把你不知道的偉大奧妙之事告訴你。</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米書 32:24; 哈巴谷書 1:10; 以西結書 4:2"> 關於耶路撒冷城中的房屋和猶大王宮被拆毀，用來抵禦攻城台和刀劍一事，以色列的上帝耶和華說：</span>
<span className="v" id="v5" data-v="5" data-xref="以賽亞書 8:17; 耶利米書 21:10; 耶利米書 21:4–7"> 他們與迦勒底人爭戰只會使這些房屋堆滿死屍，因為我要在怒氣和烈怒中殺死他們。他們作惡多端，我必掩面不理這城。</span>
<span className="v" id="v6" data-v="6" data-xref="約翰福音 10:10; 以賽亞書 30:26; 提多書 3:5–6"> 但有一天，我必醫治這城的創傷，恢復我子民的健康，使他們繁榮安定。</span>
<span className="v" id="v7" data-v="7" data-xref="以賽亞書 1:26; 耶利米書 30:3; 阿摩司書 9:14–15"> 我要使被擄的猶大人和以色列人返鄉，使他們重建如初。</span>
<span className="v" id="v8" data-v="8" data-xref="撒迦利亞書 13:1; 彌迦書 7:18–19; 詩篇 51:2"> 我要除去他們干犯我的一切罪惡，赦免他們悖逆我的一切罪過。</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 126:2–3; 以賽亞書 60:5; 西番雅書 3:17–20"> 這城要使我在天下萬國面前得到尊崇、頌讚和榮耀，因為他們必聽見我賜給這城的一切福樂。因為我使這城繁榮安定，他們都必恐懼戰慄。』」</span>
</div>
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="耶利米書 32:43; 耶利米書 32:36; 以西結書 37:11"> 耶和華說：「你們說猶大的城邑和耶路撒冷的街道一片荒涼、人畜絕跡，</span>
<span className="v" id="v11" data-v="11" data-xref="歷代志上 16:34; 詩篇 106:1; 詩篇 107:22"> 但這些地方必傳出歡樂聲、新郎新娘的歡笑聲和在耶和華殿中獻感恩祭者的歌唱聲，<br /><span className="pl pl-1">「『要感謝萬軍之耶和華，</span><br /><span className="pl pl-1">因為耶和華是美善的，</span><br /><span className="pl pl-1">祂的慈愛永遠長存。』</span><br />因為我必使被擄的人返鄉，重建家園。這是耶和華說的。」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="以賽亞書 65:10; 以西結書 34:12–15; 耶利米書 36:29"> 萬軍之耶和華說：「在這一片荒涼、人畜絕跡的地方，在它所有城邑必再有供牧人放羊的草場。</span>
<span className="v" id="v13" data-v="13" data-xref="利未記 27:32; 路加福音 15:4; 耶利米書 17:26"> 在山區、丘陵和南地的城邑，以及便雅憫地區、耶路撒冷周圍和猶大的城邑必再次有人清點羊群。這是耶和華說的。」</span>
<span className="v" id="v14" data-v="14" data-xref="哈該書 2:6–9; 耶利米書 23:5; 歷代志上 17:13–14"> 耶和華說：「看啊，時候將到，我要實現我給以色列人和猶大人的美好應許。</span>
<span className="v" id="v15" data-v="15" data-xref="以賽亞書 11:1–5; 耶利米書 23:5–6; 以賽亞書 4:2"> 那日那時，我要使大衛公義的苗裔興起，他要在地上秉公行義。</span>
<span className="v" id="v16" data-v="16" data-xref="耶利米書 23:6; 哥林多前書 1:30; 以賽亞書 45:17"> 那時，猶大必得拯救，耶路撒冷必安享太平並被稱為『耶和華是我們的義』。</span>
<span className="v" id="v17" data-v="17" data-xref="列王紀上 2:4; 詩篇 89:29–37; 路加福音 1:32–33"> 因為耶和華說，『我應許大衛的後裔必永遠坐在以色列的寶座上，</span>
<span className="v" id="v18" data-v="18" data-xref="以賽亞書 56:7; 啟示錄 1:6; 申命記 18:1"> 利未家的祭司必永遠有人在我面前獻燔祭、素祭及其他祭物。』」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19"> 耶和華對耶利米說：</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 8:22; 詩篇 89:37; 以賽亞書 54:9–10"> 「耶和華這樣說，『除非你們能廢除我與白晝黑夜所立的約，叫白晝黑夜不再按時更替，</span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 89:34; 歷代志下 7:18; 撒母耳記下 23:5"> 才能廢除我與我僕人大衛所立的約，使他的王位後繼無人，也才能廢除我與事奉我的利未祭司所立的約。</span>
<span className="v" id="v22" data-v="22" data-xref="創世記 15:5; 創世記 22:17; 希伯來書 11:12"> 我要使我僕人大衛的後裔和事奉我的利未人，像天上的星和海邊的沙一樣不可勝數。』」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23"> 耶和華對耶利米說：</span>
<span className="v" id="v24" data-v="24" data-xref="尼希米記 4:2–4; 詩篇 83:4; 詩篇 44:13–14"> 「你看到了嗎？人們說，『耶和華已經棄絕了祂所揀選的以色列和猶大兩個國家。』他們藐視我的子民，視他們為亡國之民。</span>
<span className="v" id="v25" data-v="25" data-xref="詩篇 74:16–17; 耶利米書 31:35–36; 詩篇 104:19"> 然而，耶和華說，『正如我決不廢棄我所定的晝夜交替之約和天地運行之律，</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米書 31:37; 以賽亞書 14:1; 何西阿書 2:23"> 我也決不棄絕雅各和我僕人大衛的後裔。我必讓大衛的後裔做王統治亞伯拉罕、以撒和雅各的子孫，因為我必使被擄的人回到故土，也必憐憫他們。』」</span>
</div>

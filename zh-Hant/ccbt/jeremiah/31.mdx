## 以色列人必回歸

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="耶利米書 30:22; 耶利米書 30:24; 撒迦利亞書 13:9"> 耶和華說：「那時，我要做以色列各宗族的上帝，他們必做我的子民。</span>
<span className="v" id="v2" data-v="2" data-xref="民數記 10:33; 詩篇 95:11; 馬太福音 11:28"> <span className="pl pl-1">「逃脫刀兵之災的以色列人必在曠野蒙恩，</span><br /><span className="pl pl-1">找到安息之所。</span><br /><span className="pl pl-1">這是耶和華說的。」</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 103:17; 以賽亞書 54:8–9; 何西阿書 11:4"> <span className="pl pl-1">從前，耶和華向以色列</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「以色列」參照《七十士譯本》，希伯來文作「我」。">a</a></sup><br /><span className="pl pl-1">顯現，說：</span><br /><span className="pl pl-1">「我以永遠的愛愛你，</span><br /><span className="pl pl-1">我以不變的慈愛吸引你。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="耶利米書 33:7; 耶利米書 31:13; 阿摩司書 5:2"> <span className="pl pl-1">少女以色列啊，</span><br /><span className="pl pl-1">我要重建你，你必得到重建，</span><br /><span className="pl pl-1">你要再次拿起鈴鼓與歡樂的人一同跳舞。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="阿摩司書 9:14; 利未記 19:23–25; 申命記 28:30"> <span className="pl pl-1">你將在撒瑪利亞的山上重新栽種葡萄園，</span><br /><span className="pl pl-1">栽種的人必享受園中的果實。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="耶利米書 50:4–5; 彌迦書 4:1–3; 耶利米書 50:19"> <span className="pl pl-1">有一天，守望者要在以法蓮的山上呼喊，</span><br /><span className="pl pl-1">『來，我們上錫安朝見我們的上帝耶和華吧！』」</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 14:7; 詩篇 28:9; 以賽亞書 37:31"> <span className="pl pl-1">耶和華說：</span><br /><span className="pl pl-1">「你們要為雅各歡呼歌唱，</span><br /><span className="pl pl-1">向列國之首喝采。</span><br /><span className="pl pl-1">你們要傳揚頌讚，說，</span><br /><span className="pl pl-1">『耶和華啊，</span><br /><span className="pl pl-1">求你拯救你以色列剩餘的子民！』</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="以西結書 34:16; 以賽亞書 42:16; 耶利米書 23:8"> <span className="pl pl-1">看啊，我要從北方把他們帶回來，</span><br /><span className="pl pl-1">從地極招聚他們，</span><br /><span className="pl pl-1">其中有瞎眼的、瘸腿的、孕婦和產婦，</span><br /><span className="pl pl-1">他們要成群結隊地回到這裡。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="馬太福音 5:4; 耶利米書 3:4; 出埃及記 4:22"> <span className="pl pl-1">我必引領他們回來，</span><br /><span className="pl pl-1">他們必一路含淚禱告。</span><br /><span className="pl pl-1">我要使他們走在溪水邊，</span><br /><span className="pl pl-1">行在平坦的路上，</span><br /><span className="pl pl-1">他們必不會跌倒，</span><br /><span className="pl pl-1">因為我是以色列的父親，</span><br /><span className="pl pl-1">以法蓮是我的長子。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="以賽亞書 40:11; 以西結書 34:12; 申命記 30:4"> <span className="pl pl-1">「列國啊，你們要聽耶和華的話，</span><br /><span className="pl pl-1">要在遠方的海島宣告，</span><br /><span className="pl pl-1">『驅散以色列的那位必聚集他們，</span><br /><span className="pl pl-1">像牧人守護羊群一樣守護他們。』</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="以賽亞書 48:20; 提多書 2:14; 以賽亞書 44:23"> <span className="pl pl-1">因為耶和華必拯救雅各，</span><br /><span className="pl pl-1">必從強敵手中救贖他們。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="以賽亞書 35:10; 以賽亞書 58:11; 約珥書 3:18"> <span className="pl pl-1">他們必來到錫安山上歡呼，</span><br /><span className="pl pl-1">為耶和華所賜的美物——五穀、新酒、</span><br /><span className="pl pl-1">油、羔羊和牛犢而歡欣。</span><br /><span className="pl pl-1">他們就像水源充足的田園，</span><br /><span className="pl pl-1">不再愁苦。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 30:11; 以賽亞書 61:3; 以賽亞書 51:11"> <span className="pl pl-1">那時，少女要歡然起舞，</span><br /><span className="pl pl-1">老人和青年要一起快樂。</span><br /><span className="pl pl-1">我要使他們轉憂為喜，</span><br /><span className="pl pl-1">我要安慰他們，使他們歡喜，</span><br /><span className="pl pl-1">不再愁苦。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="耶利米書 31:25; 彼得前書 2:9; 耶利米書 33:9"> <span className="pl pl-1">我要使祭司有充足的供應，</span><br /><span className="pl pl-1">使我的子民飽享美物。</span><br /><span className="pl pl-1">這是耶和華說的。」</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="馬太福音 2:16–18; 耶利米書 40:1; 詩篇 77:2"> <span className="pl pl-1">耶和華說：</span><br /><span className="pl pl-1">「在拉瑪有痛哭哀號的聲音，</span><br /><span className="pl pl-1">是拉結在為兒女哀慟，</span><br /><span className="pl pl-1">不肯接受安慰，</span><br /><span className="pl pl-1">因為他們都死了。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v16" data-v="16" data-xref="路得記 2:12; 耶利米書 30:3; 希伯來書 6:10"> <span className="pl pl-1">耶和華說：</span><br /><span className="pl pl-1">「不要哭泣，不要流淚，</span><br /><span className="pl pl-1">因為你的勞苦必有回報，</span><br /><span className="pl pl-1">你的兒女必從敵國回來。</span><br /><span className="pl pl-1">這是耶和華說的。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="耶利米哀歌 3:21; 耶利米書 29:11–16; 耶利米哀歌 3:18"> <span className="pl pl-1">你將來必有盼望，</span><br /><span className="pl pl-1">你的兒女必重返家園。</span><br /><span className="pl pl-1">這是耶和華說的。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="耶利米書 31:9; 詩篇 80:3; 約伯記 5:17"> <span className="pl pl-1">我聽見以法蓮</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="「以法蓮」是北國以色列的主要支派，常用來代指北國以色列。">b</a></sup><br /><span className="pl pl-1">在為自己悲歎，</span><br /><span className="pl pl-1">『我們就像未經馴服的牛犢，</span><br /><span className="pl pl-1">你管教我們，使我們順服，</span><br /><span className="pl pl-1">求你使我們回到你身邊，</span><br /><span className="pl pl-1">好恢復我們，</span><br /><span className="pl pl-1">因為你是我們的上帝耶和華。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="以西結書 36:31; 耶利米書 3:25; 以西結書 21:12"> <span className="pl pl-1">我們離開你後就後悔了，</span><br /><span className="pl pl-1">我們醒悟之後捶胸頓足，</span><br /><span className="pl pl-1">因早年的所作所為而羞愧難當。』」</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="以賽亞書 55:7; 彌迦書 7:18–19; 以賽亞書 63:15"> <span className="pl pl-1">耶和華說：「以法蓮不是我的愛子嗎？</span><br /><span className="pl pl-1">他不是我喜悅的孩子嗎？</span><br /><span className="pl pl-1">我雖然常常責備他，</span><br /><span className="pl pl-1">但仍然惦記著他。</span><br /><span className="pl pl-1">我深深地想念他，</span><br /><span className="pl pl-1">我必憐憫他。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v21" data-v="21" data-xref="耶利米書 50:5; 以賽亞書 62:10; 詩篇 84:5"> <span className="pl pl-1">「以色列人啊，</span><br /><span className="pl pl-1">你們要為自己設置路標，</span><br /><span className="pl pl-1">豎起路牌，</span><br /><span className="pl pl-1">牢記你們走過的大道。</span><br /><span className="pl pl-1">以色列人啊，</span><br /><span className="pl pl-1">回來吧！回到你們的城邑吧！</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="耶利米書 49:4; 耶利米書 7:24; 馬太福音 1:21"> <span className="pl pl-1">背信的子民啊！</span><br /><span className="pl pl-1">你們四處流浪要到何時呢？</span><br /><span className="pl pl-1">耶和華在地上開闢了一件新事——女子將要護衛男子。」</span></span>
<span className="v" id="v23" data-v="23" data-xref="撒迦利亞書 8:3; 以賽亞書 1:26; 耶利米書 50:7"> 以色列的上帝——萬軍之耶和華說：「我使被擄的猶大人回到故鄉後，他們要在猶大各城邑再次呼喊，<br /><span className="pl pl-1">「『公義的居所啊，</span><br /><span className="pl pl-1">聖山啊，願耶和華賜福給你！』</span></span>
<span className="v" id="v24" data-v="24" data-xref="撒迦利亞書 8:4–8; 以西結書 36:10; 撒迦利亞書 2:4"> 「農夫和牧人必住在猶大的各城邑。</span>
<span className="v" id="v25" data-v="25" data-xref="馬太福音 5:6; 馬太福音 11:28; 約翰福音 4:14"> 我要使疲乏的人振作起來，使愁苦的人快樂起來。」</span>
<span className="v" id="v26" data-v="26" data-xref="詩篇 127:2; 撒迦利亞書 4:1–2"> 這時，我醒過來，覺得這一覺實在香甜。</span>
<span className="v" id="v27" data-v="27" data-xref="何西阿書 2:23; 撒迦利亞書 10:9; 以西結書 36:9"> 耶和華說：「看啊，時候將到，我要使以色列和猶大人丁興旺，牲畜繁多。</span>
<span className="v" id="v28" data-v="28" data-xref="耶利米書 24:6; 耶利米書 1:10; 耶利米書 18:7–9"> 我曾決意剷除、拆毀、推翻、剿滅他們，降災給他們，將來我必塑造、栽培他們。這是耶和華說的。</span>
<span className="v" id="v29" data-v="29" data-xref="耶利米哀歌 5:7; 以西結書 18:2–3; 耶利米書 31:30"> 那時，人再不會說，<br /><span className="pl pl-1">「『父親吃酸葡萄，</span><br /><span className="pl pl-1">兒子的牙酸倒了。』</span></span>
<span className="v" id="v30" data-v="30" data-xref="以西結書 18:20; 以賽亞書 3:11; 申命記 24:16"> 因為各人都要因自己的罪而死，誰吃酸葡萄，誰的牙酸倒。」</span>
<span className="v" id="v31" data-v="31" data-xref="希伯來書 10:16–17; 以西結書 37:26; 耶利米書 31:31–34"> 耶和華說：「看啊，時候將到，我要與以色列家和猶大家另立新約，</span>
<span className="v" id="v32" data-v="32" data-xref="出埃及記 24:6–8; 申命記 5:3; 出埃及記 19:5"> 這約不同於我與他們祖先所立的約，那是我牽著他們祖先的手領他們離開埃及時立的。雖然我是他們的丈夫，他們卻違背了我的約。這是耶和華說的。」</span>
<span className="v" id="v33" data-v="33" data-xref="哥林多後書 3:3; 希伯來書 10:16; 希伯來書 8:10"> 耶和華說：「那些日子以後，我將與以色列家立這樣的約，我要把我的律法放在他們腦中，寫在他們心上。我要作他們的上帝，他們要作我的子民。</span>
<span className="v" id="v34" data-v="34" data-xref="以賽亞書 43:25; 希伯來書 8:12; 約翰一書 2:27"> 誰都無需再教導自己的鄰居和弟兄，說，『你要認識耶和華』，因為他們無論尊卑都必認識我。我要赦免他們的過犯，忘掉他們的罪惡。這是耶和華說的。」</span>
<span className="v" id="v35" data-v="35" data-xref="耶利米書 10:16; 以賽亞書 51:15; 詩篇 136:7–9"> <span className="pl pl-1">指定太陽白天照耀、</span><br /><span className="pl pl-1">命令星月晚上發光、</span><br /><span className="pl pl-1">攪動大海，使之波濤洶湧的萬軍之耶和華說：</span><br /></span>
<span className="v" id="v36" data-v="36" data-xref="以賽亞書 54:9–10; 耶利米書 33:20–26; 詩篇 89:36–37"> <span className="pl pl-1">「只要天地之律還在，</span><br /><span className="pl pl-1">以色列邦國必永續不斷。</span><br /><span className="pl pl-1">這是耶和華說的。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v37" data-v="37" data-xref="耶利米書 33:24–26; 以賽亞書 40:12; 耶利米書 33:22"> <span className="pl pl-1">耶和華說：</span><br /><span className="pl pl-1">「正如無人能量度高天，</span><br /><span className="pl pl-1">探測大地的根基，</span><br /><span className="pl pl-1">同樣我也決不會因以色列人的所作所為而棄絕他們。</span><br /><span className="pl pl-1">這是耶和華說的。」</span></span>
<span className="v" id="v38" data-v="38" data-xref="撒迦利亞書 14:10; 列王紀下 14:13; 耶利米書 30:18"> 耶和華說：「看啊，時候將到，從哈楠業樓直到角門，整個耶路撒冷城要重建起來歸給耶和華。</span>
<span className="v" id="v39" data-v="39" data-xref="撒迦利亞書 2:1–2; 以西結書 40:8"> 城界要向外延伸到迦立山，再轉到歌亞。</span>

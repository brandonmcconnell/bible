## 預言被擄七十年

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="耶利米書 36:1; 列王紀下 24:1–2; 但以理書 1:1"> 約西亞的兒子猶大王約雅敬執政第四年，即巴比倫王尼布甲尼撒元年，耶和華告訴了耶利米有關猶大百姓的事。</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米書 18:11; 耶利米書 19:14–15; 馬可福音 7:14–15"> 耶利米先知對猶大人和耶路撒冷的所有居民說：</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米書 11:7; 耶利米書 26:5; 耶利米書 1:2"> 「從亞們的兒子猶大王約西亞執政第十三年，到今天已有二十三年。在這期間，我不斷把耶和華對我說的話傳給你們，你們卻充耳不聞。</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米書 25:3; 耶利米書 26:5; 耶利米書 13:10–11"> 耶和華屢次差遣祂的僕人——眾先知警告你們，你們卻充耳不聞，毫不理會。</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米書 7:7; 創世記 17:8; 以賽亞書 55:6–7"> 他們對你們說，『你們人人都要改邪歸正，以便永遠住在耶和華賜給你們和你們祖先的土地上。</span>
<span className="v" id="v6" data-v="6" data-xref="申命記 8:19; 耶利米書 7:6; 耶利米書 35:15"> 不要隨從、供奉、祭拜其他神明，不要製造神像惹耶和華發怒，免得祂懲罰你們。』」</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀下 21:15; 箴言 8:36; 申命記 32:21"> 耶和華說：「然而，你們不聽我的話，製造神像惹我發怒，自招懲罰。」</span>
<span className="v" id="v8" data-v="8"> 因此，萬軍之耶和華說：「由於你們不遵行我的命令，</span>
<span className="v" id="v9" data-v="9" data-xref="以賽亞書 13:3; 耶利米書 18:16; 耶利米書 1:15"> 我要召集北方各族和我的僕人巴比倫王尼布甲尼撒，去攻擊這片土地和其中的居民，以及周圍各國。我要徹底毀滅他們，使他們的下場令人驚駭和嗤笑，土地永遠荒涼。這是耶和華說的。</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米書 7:34; 啟示錄 18:22–23; 以西結書 26:13"> 我要使他們的歡樂聲、新郎新娘的歡笑聲、推磨聲和燈光都消失。</span>
<span className="v" id="v11" data-v="11" data-xref="但以理書 9:2; 撒迦利亞書 1:12; 歷代志下 36:21–22"> 整片土地要變得荒涼可怕，列國要臣服於巴比倫王七十年。</span>
<span className="v" id="v12" data-v="12" data-xref="但以理書 9:2; 以賽亞書 13:19; 耶利米書 29:10"> 七十年後，我要因巴比倫王和他國民迦勒底人的罪而懲罰他們，使他們的土地永遠荒涼。這是耶和華說的。</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米書 1:10; 耶利米書 1:5; 但以理書 5:31"> 我藉耶利米所說有關列國的預言都記在這書上了，我的這些話必應驗在他們的土地上。</span>
<span className="v" id="v14" data-v="14" data-xref="耶利米書 51:6; 耶利米書 27:7; 耶利米書 50:9"> 他們必受許多國家和強大君王的奴役，我要按他們的所作所為報應他們。」</span>
</div>
</div>

## 上帝審判列國

<div className="bt">
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="詩篇 75:8; 以賽亞書 51:17; 啟示錄 14:10"> 以色列的上帝耶和華對我說：「你從我手中接過這盛滿我烈怒的酒杯，到我差遣你去的國家給他們喝。</span>
<span className="v" id="v16" data-v="16" data-xref="那鴻書 3:11; 耶利米書 51:7; 耶利米書 51:39"> 他們喝了之後必東倒西歪、行為瘋狂，因為我要使戰禍臨到他們。」</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米書 1:10; 耶利米書 25:28; 以西結書 43:3"> 於是，我從耶和華手中接過杯，奉祂的差遣到列國去給他們喝。</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米書 24:9; 詩篇 60:3; 耶利米書 44:22"> 我給耶路撒冷和猶大的城邑，以及猶大的君王和官員喝這杯烈怒，使他們的城邑淪為廢墟，令人驚駭，被人嘲笑和咒詛，正如今日一樣。</span>
<span className="v" id="v19" data-v="19" data-xref="耶利米書 46:13–26; 那鴻書 3:8–10; 耶利米書 46:2"> 喝這杯烈怒的還有埃及王法老及其官長臣僕和全體百姓，</span>
<span className="v" id="v20" data-v="20" data-xref="約伯記 1:1; 以西結書 30:5; 以賽亞書 20:1"> 他們當中所有的外族人，烏斯的眾王和統治亞實基倫、迦薩、以革倫以及亞實突餘民的非利士眾王，</span>
<span className="v" id="v21" data-v="21" data-xref="耶利米書 48:1–22; 詩篇 137:7; 耶利米書 9:26"> 以東、摩押和亞捫人，</span>
<span className="v" id="v22" data-v="22" data-xref="耶利米書 47:4; 阿摩司書 1:9–10; 以西結書 28:22–23"> 泰爾的眾王、西頓的眾王和海島上的眾王，</span>
<span className="v" id="v23" data-v="23" data-xref="耶利米書 9:26; 耶利米書 49:32; 耶利米書 49:8"> 底但、提瑪、布斯和所有剃鬢髮的人，</span>
<span className="v" id="v24" data-v="24" data-xref="歷代志下 9:14; 耶利米書 25:20; 以西結書 30:5"> 阿拉伯的眾王和荒野各族的諸王，</span>
<span className="v" id="v25" data-v="25" data-xref="以賽亞書 11:11; 創世記 10:22; 以賽亞書 13:17"> 心利的眾王、以攔的眾王和瑪代的眾王，</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米書 51:41; 耶利米書 25:9; 耶利米書 50:1–46"> 無論遠近的一個個北方的王，以及天下萬國，最後是巴比倫王。</span>
<span className="v" id="v27" data-v="27" data-xref="耶利米書 25:16; 哈巴谷書 2:16; 以西結書 21:4–5"> 耶和華對我說：「你要告訴他們，以色列的上帝——萬軍之耶和華說，『你們要喝這杯烈怒，喝得大醉、嘔吐、倒地不起，因為我要使刀劍臨到你們。』</span>
<span className="v" id="v28" data-v="28" data-xref="約伯記 34:33; 耶利米書 51:29; 以賽亞書 14:24–27"> 如果他們不肯從你手中接過杯來喝，你就告訴他們，萬軍之耶和華說，『你們必須喝！</span>
<span className="v" id="v29" data-v="29" data-xref="以西結書 38:21; 箴言 11:31; 彼得前書 4:17"> 看啊，我開始在屬我的城中降下災禍，難道你們可以逃脫懲罰嗎？你們必逃不過懲罰，因為我要使刀劍臨到天下萬民。』這是萬軍之耶和華說的。</span>
<span className="v" id="v30" data-v="30" data-xref="阿摩司書 1:2; 約珥書 3:16; 以賽亞書 42:13"> 耶利米啊，你要告訴他們這些預言，<br /><span className="pl pl-1">「『耶和華要在高天怒吼，</span><br /><span className="pl pl-1">從祂的聖所發出雷鳴；</span><br /><span className="pl pl-1">祂要向祂的子民怒吼，</span><br /><span className="pl pl-1">向地上的居民吶喊，</span><br /><span className="pl pl-1">好像踩踏葡萄的人一樣。</span><br /></span>
<span className="v" id="v31" data-v="31" data-xref="何西阿書 4:1; 約珥書 3:2; 以賽亞書 66:16"> <span className="pl pl-1">吶喊聲必傳到地極，</span><br /><span className="pl pl-1">因為祂要指控列國，審判世人，</span><br /><span className="pl pl-1">使惡人喪身刀下。</span><br /><span className="pl pl-1">這是耶和華說的。』」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v32" data-v="32" data-xref="耶利米書 23:19; 以賽亞書 34:2; 歷代志下 15:6"> <span className="pl pl-1">萬軍之耶和華說：</span><br /><span className="pl pl-1">「看啊，災難正蔓延到列國，</span><br /><span className="pl pl-1">有大暴風從地極捲起。」</span></span>
<span className="v" id="v33" data-v="33" data-xref="以賽亞書 66:16; 耶利米書 8:2; 詩篇 79:3"> 到那日，遍地都是被耶和華殺戮的人，無人哀悼、收殮和埋葬，他們好像地上的糞便。</span>
<span className="v" id="v34" data-v="34" data-xref="耶利米書 6:26; 耶利米書 50:27; 詩篇 2:9"> <span className="pl pl-1">你們這群牧人啊，要痛哭哀號！</span><br /><span className="pl pl-1">你們這群百姓的首領啊，</span><br /><span className="pl pl-1">要在灰塵中傷心地打滾！</span><br /><span className="pl pl-1">因為你們被宰殺和驅散的時候到了，</span><br /><span className="pl pl-1">你們必跌倒，像精美的器皿一樣被摔碎。</span><br /></span>
<span className="v" id="v35" data-v="35" data-xref="約伯記 11:20; 阿摩司書 2:14; 耶利米書 52:8–11"> <span className="pl pl-1">牧人必無路可逃，</span><br /><span className="pl pl-1">百姓的首領必無處藏身。</span><br /></span>
<span className="v" id="v36" data-v="36" data-xref="耶利米書 4:8; 耶利米書 25:34"> <span className="pl pl-1">聽聽牧人的哭喊，</span><br /><span className="pl pl-1">百姓首領的哀號吧，</span><br /><span className="pl pl-1">因為耶和華正在毀滅他們的家園。</span><br /></span>
<span className="v" id="v37" data-v="37" data-xref="以賽亞書 27:10–11; 以賽亞書 32:14"> <span className="pl pl-1">因為耶和華的震怒，</span><br /><span className="pl pl-1">寧靜的草場變得一片荒涼。</span><br /></span>
<span className="v" id="v38" data-v="38" data-xref="耶利米書 4:7; 耶利米書 5:6; 何西阿書 13:7–8"> <span className="pl pl-1">耶和華離開了祂的居所，</span><br /><span className="pl pl-1">就像獅子離開了洞穴。</span><br /><span className="pl pl-1">他們的土地因強敵的刀劍和耶和華的烈怒而一片荒涼。</span></span>
</div>

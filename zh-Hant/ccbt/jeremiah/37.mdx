## 西底迦求耶利米代禱

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="耶利米書 22:24; 列王紀下 24:17; 列王紀下 24:12"> 巴比倫王尼布甲尼撒立約西亞的兒子西底迦代替約雅敬的兒子哥尼雅做猶大王。</span>
<span className="v" id="v2" data-v="2" data-xref="列王紀下 24:19–20; 箴言 29:12; 歷代志下 36:12–16"> 西底迦和他的臣僕及人民卻沒有聽從耶和華藉耶利米先知說的話。</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米書 21:1–2; 耶利米書 29:25; 耶利米書 42:20"> 西底迦王派示利米雅的兒子猶甲和瑪西雅的兒子祭司西番雅來對耶利米先知說：「求你為我們向我們的上帝耶和華禱告。」</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米書 37:15; 耶利米書 32:2–3"> 當時，耶利米還可以在百姓中自由來往，因為他還沒有被囚在獄中。</span>
<span className="v" id="v5" data-v="5" data-xref="以西結書 17:15; 耶利米書 37:11; 耶利米書 34:21"> 那時，法老的軍隊已從埃及出發，正在圍攻耶路撒冷的迦勒底人聽見消息就退兵了。</span>
<span className="v" id="v6" data-v="6"> 耶和華對耶利米先知說：</span>
<span className="v" id="v7" data-v="7" data-xref="耶利米哀歌 4:17; 列王紀下 22:18; 以西結書 17:17"> 「以色列的上帝耶和華這樣說，『猶大王派你們來求問我，你們告訴他：前來支援你們的法老軍隊必返回本國埃及，</span>
<span className="v" id="v8" data-v="8" data-xref="耶利米書 39:2–8; 耶利米書 38:23; 耶利米書 34:21–22"> 而迦勒底人必捲土重來，攻佔這城，將它付之一炬。</span>
<span className="v" id="v9" data-v="9" data-xref="俄巴底亞書 1:3; 耶利米書 29:8; 加拉太書 6:3"> 耶和華說，你們不要自欺，以為迦勒底人必撤軍。其實他們不會撤軍。</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米書 50:45; 以賽亞書 30:17; 約珥書 2:11"> 即使你們能打敗迦勒底全軍，他們營中受傷的殘兵也必起來燒毀這城。』」</span>
<span className="v" id="v11" data-v="11" data-xref="耶利米書 37:5"> 當迦勒底人因害怕法老的軍隊而從耶路撒冷撤軍的時候，</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米書 1:1; 尼希米記 6:11; 列王紀上 19:3"> 耶利米起身離開耶路撒冷，前往便雅憫境內去接收他在同族中應得的地業。</span>
<span className="v" id="v13" data-v="13" data-xref="撒迦利亞書 14:10; 耶利米書 38:7; 路加福音 23:2"> 當耶利米先知來到便雅憫門時，哈拿尼亞的孫子、示利米雅的兒子守門官伊利雅逮捕了他，說：「你想去投奔迦勒底人！」</span>
<span className="v" id="v14" data-v="14" data-xref="詩篇 52:1–2; 耶利米書 40:4–6; 詩篇 27:12"> 耶利米說：「胡說，我不是去投奔迦勒底人。」但伊利雅不信，就把他抓起來押到眾官長那裡。</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米書 38:26; 耶利米書 20:1–3; 耶利米書 26:16"> 官長們大怒，命人打耶利米，把他囚禁在書記約拿單的房子裡，因為他們已把這房子改作監牢。</span>
<span className="v" id="v16" data-v="16" data-xref="耶利米書 38:6; 耶利米書 38:10–13; 耶利米哀歌 3:53"> 耶利米被囚禁在地牢中許多天。</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米書 21:7; 耶利米書 24:8; 列王紀上 14:1–4"> 後來，西底迦王派人把他帶到自己的宮中，私下問他：「耶和華有什麼話給你嗎？」耶利米說：「有，你要被交在巴比倫王手中。」</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行傳 25:8; 約翰福音 10:32; 但以理書 6:22"> 耶利米又問他：「我在什麼事上得罪了你、你的臣僕或人民，以致你們把我囚在監牢中？</span>
<span className="v" id="v19" data-v="19" data-xref="耶利米書 2:28; 耶利米書 28:10–17; 耶利米書 6:14"> 那些曾向你們預言『巴比倫王絕不會來這裡攻打你們』的先知如今在哪裡呢？</span>
<span className="v" id="v20" data-v="20" data-xref="耶利米書 36:7; 耶利米書 38:6–9; 使徒行傳 28:18–19"> 現在，我主我王啊，請恩准我的懇求！求你不要把我送回書記約拿單的房子，免得我死在那裡。」</span>
<span className="v" id="v21" data-v="21" data-xref="耶利米書 38:13; 耶利米書 38:28; 耶利米書 38:9"> 於是，西底迦王下令把耶利米囚在護衛的院子裡，派人每天從餅鋪取一個餅給他，直到城中絕糧。耶利米就這樣住在護衛的院子裡。</span>

## 預言旱災

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="耶利米書 17:8"> 耶和華告訴耶利米有關旱災的事：</span>
<span className="v" id="v2" data-v="2" data-xref="以賽亞書 3:26; 耶利米書 8:21; 撒母耳記上 5:12"> <span className="pl pl-1">「猶大悲泣，</span><br /><span className="pl pl-1">她的城邑衰敗，</span><br /><span className="pl pl-1">人人坐在地上痛哭，</span><br /><span className="pl pl-1">耶路撒冷哀鳴四起。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳記下 15:30; 詩篇 40:14; 列王紀下 18:31"> <span className="pl pl-1">貴族派僕人去水池打水，</span><br /><span className="pl pl-1">僕人去那裡發現沒有水，</span><br /><span className="pl pl-1">就帶著空瓶垂頭喪氣、</span><br /><span className="pl pl-1">羞愧地抱頭而歸。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="約珥書 1:19–20; 約珥書 1:11; 耶利米書 3:3"> <span className="pl pl-1">天不下雨，</span><br /><span className="pl pl-1">土地乾裂，</span><br /><span className="pl pl-1">農夫沮喪地抱著頭。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 29:9; 約伯記 39:1–4; 以賽亞書 15:6"> <span className="pl pl-1">因為沒有草，</span><br /><span className="pl pl-1">田野的母鹿拋棄了剛生下來的小鹿；</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="耶利米書 2:24; 約伯記 39:5–6; 約珥書 1:18"> <span className="pl pl-1">因為沒有草，</span><br /><span className="pl pl-1">野驢站在光禿的山頭上像豺狼一樣喘氣，雙目無神。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="詩篇 25:11; 何西阿書 5:5; 耶利米書 14:20–21"> <span className="pl pl-1">耶和華啊，雖然我們的罪控告我們，</span><br /><span className="pl pl-1">我們屢屢叛逆得罪你，</span><br /><span className="pl pl-1">求你為了自己的名而拯救我們。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="耶利米書 17:13; 耶利米書 50:7; 以賽亞書 43:3"> <span className="pl pl-1">以色列的盼望和患難時的救主啊，</span><br /><span className="pl pl-1">你為什麼在本地像個異鄉人，</span><br /><span className="pl pl-1">像個只住一夜的客旅呢？</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="以賽亞書 63:19; 以賽亞書 59:1; 耶利米書 15:16"> <span className="pl pl-1">你為什麼像個受驚的人，</span><br /><span className="pl pl-1">像個無力救人的勇士呢？</span><br /><span className="pl pl-1">耶和華啊，你一直都在我們中間，</span><br /><span className="pl pl-1">我們屬於你的名下，</span><br /><span className="pl pl-1">求你不要拋棄我們。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="何西阿書 9:9; 何西阿書 8:13; 詩篇 119:101"> <span className="pl pl-1">關於這些百姓，耶和華說：</span><br /><span className="pl pl-1">「他們喜歡遊蕩，</span><br /><span className="pl pl-1">不約束自己的腳步，</span><br /><span className="pl pl-1">因此耶和華不悅納他們。</span><br /><span className="pl pl-1">現在祂要追憶他們的罪惡，</span><br /><span className="pl pl-1">追討他們的罪。」</span></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="耶利米書 7:16; 耶利米書 11:14; 出埃及記 32:32–34"> 耶和華對我說：「你不要為這百姓求好處。</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米書 11:11; 以西結書 8:18; 箴言 1:28"> 即使他們禁食，我也不會聽他們的呼求；他們獻上燔祭和素祭，我也不會悅納。我要用刀劍、饑荒和瘟疫滅絕他們。」</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米書 6:14; 耶利米書 4:10; 彼得後書 2:1"> 我說：「主耶和華啊！眾先知不停地告訴他們不會有戰爭，也不會遭遇饑荒，說耶和華必在這地方賜給他們永久的平安。」</span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="以西結書 13:6–7; 以西結書 12:24; 耶利米書 29:8–9"> 耶和華對我說：「那些先知奉我的名說假預言，我並沒有差派他們，沒有委任他們，也沒有對他們說話。他們對你們說的預言是假異象，是占卜，是他們心中的妄想。</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米書 5:12–13; 以西結書 14:10; 耶利米書 23:14–15"> 我沒有差派他們，他們卻奉我的名預言這地方必沒有刀劍和饑荒。他們必死於刀劍和饑荒。這是耶和華說的。</span>
<span className="v" id="v16" data-v="16" data-xref="耶利米書 7:33; 箴言 1:31; 耶利米書 15:2–3"> 聽他們說預言的人及其妻子兒女，必因饑荒和戰爭而曝屍耶路撒冷街頭，無人掩埋。因為我要使他們受到應得的報應。</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米書 8:21; 耶利米書 9:1; 耶利米書 13:17"> <span className="pl pl-1">「耶利米，你要對他們說，</span><br /><span className="pl pl-1">『讓我晝夜淚眼汪汪吧，</span><br /><span className="pl pl-1">因為我的處女同胞遭受重創，</span><br /><span className="pl pl-1">傷勢危重。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="以西結書 7:15; 耶利米哀歌 1:20; 耶利米書 8:10"> <span className="pl pl-1">我走到田間，</span><br /><span className="pl pl-1">眼前是死於刀下的屍體；</span><br /><span className="pl pl-1">我進入城裡，</span><br /><span className="pl pl-1">見饑荒肆虐，</span><br /><span className="pl pl-1">先知和祭司也流亡異鄉</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「先知和祭司也流亡異鄉」或譯「連先知和祭司也渾渾噩噩，茫然無措」。">a</a></sup><br /><span className="pl pl-1">。』」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v19" data-v="19" data-xref="耶利米哀歌 5:22; 耶利米書 8:15; 耶利米書 6:30"> <span className="pl pl-1">耶和華啊，你完全丟棄猶大了嗎？</span><br /><span className="pl pl-1">你厭惡錫安嗎？</span><br /><span className="pl pl-1">你為什麼重重地打我們，以致無法醫治？</span><br /><span className="pl pl-1">我們期待平安，卻沒有祥和；</span><br /><span className="pl pl-1">渴望得到醫治，卻飽受驚嚇。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="耶利米書 3:25; 詩篇 32:5; 約翰一書 1:7–9"> <span className="pl pl-1">耶和華啊，我們承認自己和我們祖先的罪，</span><br /><span className="pl pl-1">我們誠然得罪了你。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="耶利米書 14:7; 詩篇 106:45; 耶利米書 3:17"> <span className="pl pl-1">為了你的尊名，</span><br /><span className="pl pl-1">求你不要厭惡我們，</span><br /><span className="pl pl-1">不要讓你榮耀的寶座蒙羞。</span><br /><span className="pl pl-1">求你顧念你與我們立的約，</span><br /><span className="pl pl-1">不要廢除它。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="約珥書 2:23; 耶利米書 5:24; 詩篇 135:7"> <span className="pl pl-1">在列國供奉的偶像中，</span><br /><span className="pl pl-1">誰能賜下雨水呢？</span><br /><span className="pl pl-1">天能自降甘霖嗎？</span><br /><span className="pl pl-1">我們的上帝耶和華啊，</span><br /><span className="pl pl-1">難道不是只有你能行這些事嗎？</span><br /><span className="pl pl-1">是你行了這一切，</span><br /><span className="pl pl-1">所以我們仰望你。</span></span>
</div>

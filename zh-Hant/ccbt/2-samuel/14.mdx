## 押沙龍回耶路撒冷

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳記下 13:39; 撒母耳記下 2:18; 撒母耳記下 18:33"> 洗魯雅的兒子約押知道王想念押沙龍，</span>
<span className="v" id="v2" data-v="2" data-xref="歷代志下 11:6; 阿摩司書 1:1; 路得記 3:3"> 就派人到提哥亞去召來一個聰明的婦人，對她說：「你假扮哀悼的人，穿上喪服，不要用油抹身，要裝成為死者哀悼很久的婦人，</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳記下 14:19; 出埃及記 4:15; 以賽亞書 51:16"> 然後到王那裡，對他這樣這樣說。」約押把應該說的話都告訴婦人。</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳記下 1:2; 列王紀下 6:26–28; 撒母耳記上 25:23"> 提哥亞婦人來到王面前，俯伏在地上說：「王啊，求你救救我吧！」</span>
<span className="v" id="v5" data-v="5" data-xref="士師記 9:8–15; 撒母耳記下 12:1–3"> 王問她：「你有什麼事？」婦人說：「婢女是個寡婦，丈夫死了。</span>
<span className="v" id="v6" data-v="6" data-xref="創世記 4:8; 申命記 22:26–27; 出埃及記 2:13"> 我本來有兩個兒子，有一次他們在田間發生爭執，當時沒有人勸解，其中一個兒子被打死了。</span>
<span className="v" id="v7" data-v="7" data-xref="民數記 35:19; 馬太福音 21:38; 撒母耳記下 12:17"> 現在整個家族都起來反對婢女，說，『把那打死親兄弟的兇手交出來，我們要他以命償命，除掉這個繼承人。』他們要讓我家斷子絕孫，使婢女的丈夫既不能留名，也不能留後。」</span>
<span className="v" id="v8" data-v="8" data-xref="箴言 18:13; 以賽亞書 11:3–4; 約伯記 29:16"> 王說：「你回家去吧！我會為你作主。」</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳記上 25:24; 列王紀上 2:33; 馬太福音 27:25"> 提哥亞婦人說：「我主我王，願罪過<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「罪過」可能指違背摩西律法殺人償命的規定。">a</a></sup>都落在婢女和婢女家族，跟王和王位無關。」</span>
<span className="v" id="v10" data-v="10"> 王說：「若有人為難你，你就把他帶來，他必不敢再找你的麻煩。」</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳記上 14:45; 馬太福音 10:30; 民數記 35:19"> 婦人說：「求王憑你的上帝耶和華起誓，不許報血仇者殺人，留我兒一命。」王說：「我憑永活的耶和華起誓，你的兒子必毫髮無損。」</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 18:27; 撒母耳記上 25:24; 使徒行傳 26:1"> 婦人說：「求我主我王再容婢女說一句。」王說：「說吧！」</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳記下 13:37–38; 撒母耳記下 12:7; 士師記 20:2"> 婦人說：「王怎麼想出這樣的事來針對上帝的子民呢？王剛才所說的話正表明王的不是了，因為王不讓被流放的兒子回來。</span>
<span className="v" id="v14" data-v="14" data-xref="約伯記 30:23; 民數記 35:28; 希伯來書 9:27"> 人都難免一死，就像覆水難收。然而，上帝不是要奪取人的性命，而是要設法使流亡的人重新回來。</span>
<span className="v" id="v15" data-v="15"> 我向我主我王說出這番話，是因為人們恐嚇我。我想，不如向王請命，也許王會成全婢女的心願。</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳記上 26:19"> 有人要害我和我兒子的性命，叫我們不得承受上帝所賜的產業，也許王能從這人手中救我們。</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳記上 29:9; 撒母耳記下 19:27; 撒母耳記下 14:20"> 婢女想，我主我王的話必能安慰我，因為我主我王就像上帝的天使一樣能明辨是非。願王的上帝耶和華常與王同在！」</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米書 38:25; 撒母耳記上 3:17–18; 耶利米書 38:14"> 王對婦人說：「我有一件事要問你，你要實實在在地回答我。」婦人說：「我主我王請說。」</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳記下 14:3; 撒母耳記上 1:26; 撒母耳記上 20:3"> 王說：「這是不是約押的主意？」婦人說：「我憑我主我王的性命起誓，王所說的一點不錯，這些話是你臣僕約押吩咐婢女說的。</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳記下 14:17; 撒母耳記下 19:27; 約伯記 32:21–22"> 他這樣做是希望扭轉局面。我主如上帝的天使一樣有智慧，洞悉天下之事。」</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳記下 14:11; 撒母耳記上 14:39; 馬可福音 6:26"> 於是，王對約押說：「我答應你的請求，你去把年輕的押沙龍帶回來吧。」</span>
<span className="v" id="v22" data-v="22" data-xref="路得記 2:2; 約伯記 31:20; 約伯記 29:11"> 約押俯伏在地，叩謝王恩，說：「今天僕人在我主我王面前蒙了恩，因為王應允了僕人的請求。」</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳記下 3:3; 撒母耳記下 13:37–38"> 約押便到基述把押沙龍接回耶路撒冷。</span>
<span className="v" id="v24" data-v="24" data-xref="啟示錄 22:4; 創世記 43:3; 撒母耳記下 3:13"> 王說：「讓押沙龍回自己的家，不要讓他來見我！」押沙龍便返回自己家中，沒有朝見王。</span>
<span className="v" id="v25" data-v="25" data-xref="以賽亞書 1:6; 申命記 28:35; 約伯記 2:7"> 在整個以色列，沒有人像押沙龍那樣因相貌英俊而為人稱道，他從頭到腳毫無瑕疵。</span>
<span className="v" id="v26" data-v="26" data-xref="以西結書 44:20; 哥林多前書 11:14; 撒母耳記下 18:9"> 他的頭髮濃密，每年年終會很沉重，需要剪髮，剪下的頭髮按王的重量標準約重兩公斤。</span>
<span className="v" id="v27" data-v="27" data-xref="撒母耳記下 18:18; 撒母耳記下 13:1; 以賽亞書 14:22"> 押沙龍有三兒一女，女兒名叫她瑪，長得非常美麗。</span>
<span className="v" id="v28" data-v="28"> 押沙龍在耶路撒冷住了兩年，沒有跟王見過面。</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳記下 14:30–31; 以斯帖記 1:12; 馬太福音 22:3"> 他派人去請約押來，託他去求見王，但約押不肯來。第二次再請，他還是不肯來。</span>
<span className="v" id="v30" data-v="30" data-xref="士師記 15:4–5; 列王紀下 10:6–7; 列王紀下 9:33"> 押沙龍就吩咐僕人：「你們看，約押的田就在我的田旁邊，他種了大麥，你們去放火把它燒了。」押沙龍的僕人便把麥田燒了。</span>
<span className="v" id="v31" data-v="31"> 約押便來到押沙龍家裡，問他：「你為什麼叫僕人放火燒我的田？」</span>
<span className="v" id="v32" data-v="32" data-xref="撒母耳記上 20:8; 出埃及記 14:12; 箴言 28:13"> 押沙龍答道：「我派人請你來，希望你替我去問王，『我為什麼要從基述回來呢？倒不如仍然留在那裡。』現在我要見王，如果我有什麼罪過，就讓他殺了我吧！」</span>
<span className="v" id="v33" data-v="33" data-xref="創世記 33:4; 路加福音 15:20; 創世記 27:26"> 約押就去見王，把押沙龍的話告訴他，王便召見押沙龍。押沙龍來到王面前俯首叩拜，王就親吻他。</span>

## 亞希多弗計謀落空

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以賽亞書 59:7–8; 詩篇 109:2–4; 詩篇 3:3–5"> 亞希多弗對押沙龍說：「請讓我挑選一萬二千人，今夜啟程追趕大衛，</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳記下 16:14; 列王紀上 22:31; 撒迦利亞書 13:7"> 趁他疲憊無力的時候襲擊他，使他驚慌失措，他的隨從必逃命。我只把王一個人殺掉，</span>
<span className="v" id="v3" data-v="3" data-xref="帖撒羅尼迦前書 5:3; 以賽亞書 48:22; 以賽亞書 57:21"> 把他的部下全都帶來歸順你。你尋索的人既然死了，跟隨他的人必然會歸順你。這樣，大家就平安無事了。」</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳記上 18:20–21; 羅馬書 1:32; 歷代志下 30:4"> 押沙龍和以色列的長老都贊成這個提議。</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳記下 15:32–37; 撒母耳記下 16:16–19"> 押沙龍說：「召亞基人戶篩進來，我們也聽聽他的意見。」</span>
<span className="v" id="v6" data-v="6"> 戶篩來了，押沙龍就把亞希多弗的建議告訴他，問他：「我們應該照亞希多弗的提議去做嗎？如果不可行，說說你的看法吧。」</span>
<span className="v" id="v7" data-v="7" data-xref="箴言 31:8"> 戶篩答道：「亞希多弗這次的主意不好！</span>
<span className="v" id="v8" data-v="8" data-xref="何西阿書 13:8; 撒母耳記上 16:18; 希伯來書 11:32–34"> 你知道你父親和他的部下，他們都是勇士，現在他們就像丟了熊崽的母熊一樣兇猛。況且你父親是個身經百戰的人，他一定不會跟部下睡在一處。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳記上 24:3; 撒母耳記上 14:14–15; 士師記 20:32–33"> 他現在可能藏在山洞或某個地方。要是他襲擊我們的人馬，聽見的人會說押沙龍的軍隊慘敗了。</span>
<span className="v" id="v10" data-v="10" data-xref="約書亞記 2:9–11; 出埃及記 15:15; 創世記 49:9"> 那時候，你手下的人再膽量過人，也會膽戰心驚。因為全以色列都知道你父親是英雄，他的部下都是勇士。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 22:17; 士師記 20:1; 詩篇 9:16"> 因此，我認為你應該把從但到別示巴的那多如海沙的以色列人都聚集起來，然後你親自率領他們出征。</span>
<span className="v" id="v12" data-v="12" data-xref="撒母耳記上 23:23; 俄巴底亞書 1:3; 列王紀上 20:10"> 這樣不管在哪裡找到大衛，我們就像露水一樣鋪天蓋地地襲擊他，讓他全軍覆沒。</span>
<span className="v" id="v13" data-v="13" data-xref="馬太福音 24:2; 彌迦書 1:6"> 如果大衛退進一座城裡，我們以色列全軍就拿繩索把那城拉到河谷，連一塊石頭都不留。」</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳記下 15:34; 哥林多前書 1:19–20; 箴言 19:21"> 押沙龍和以色列眾人都說：「亞基人戶篩的主意比亞希多弗的好！」其實是耶和華決定破壞亞希多弗的巧計，好把災禍降在押沙龍身上。</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳記下 15:35–36"> 戶篩把亞希多弗和自己為押沙龍及以色列長老所提的建議告訴祭司撒督和亞比亞他，</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳記下 15:28; 哥林多前書 15:54; 哥林多後書 5:4"> 並說：「你們現在快派人去通知大衛，告訴他今晚不可在曠野的渡口過夜，務必要渡過約旦河，免得他和隨從全軍覆沒。」</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳記下 15:36; 約書亞記 18:16; 撒母耳記下 15:27"> 當時，約拿單和亞希瑪斯待在隱·羅結，不敢進城，怕被人看見。有一個婢女從城中出來給他們報信，他們便去通知大衛王。</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳記下 3:16; 撒母耳記下 16:5; 撒母耳記下 19:16"> 不料，有一個少年發現了他們，就去告訴押沙龍。他們二人急忙逃走，來到巴戶琳的一戶人家，藏到那家院子裡的一口井內，</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及記 1:19; 約書亞記 2:4–24"> 那家的婦人用蓋子蓋上井口，然後在上面撒了一些麥子，沒有人知道這件事。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及記 1:19; 約書亞記 2:22–23; 撒母耳記上 19:12–17"> 押沙龍的部下來到婦人家查問約拿單和亞希瑪斯的下落，婦人說他們已經過河了。押沙龍的部下就去搜索，結果一無所獲，就返回耶路撒冷。</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳記下 17:15–16"> 押沙龍的部下離開後，約拿單和亞希瑪斯便從井裡爬出來，去向大衛王報信，把亞希多弗的計謀告訴他，請他趕快渡過約旦河。</span>
<span className="v" id="v22" data-v="22" data-xref="馬太福音 10:16; 約翰福音 18:9; 箴言 27:12"> 大衛王和部下就動身過約旦河，在黎明之前，所有的人都過去了。</span>
<span className="v" id="v23" data-v="23" data-xref="馬太福音 27:5; 列王紀下 20:1; 撒母耳記下 15:12"> 亞希多弗見自己的提議不被接納，便備上驢，啟程回鄉，安頓好家事以後，就自縊身亡了。他被安葬在他父親的墓穴裡。</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 32:2; 撒母耳記下 2:8; 約書亞記 13:26"> 大衛來到瑪哈念，押沙龍也率領以色列全軍渡過了約旦河。</span>
<span className="v" id="v25" data-v="25" data-xref="歷代志上 2:13; 撒母耳記下 19:13; 撒母耳記下 20:9–12"> 押沙龍任命亞瑪撒為元帥，代替約押的位置。亞瑪撒是以實瑪利人以特拉的兒子，他母親是拿轄的女兒亞比該。亞比該與約押的母親洗魯雅是姊妹。</span>
<span className="v" id="v26" data-v="26" data-xref="約書亞記 17:1; 申命記 3:15; 民數記 32:1–42"> 押沙龍和以色列人在基列地區安營。</span>
<span className="v" id="v27" data-v="27" data-xref="列王紀上 2:7; 撒母耳記下 10:1–2; 撒母耳記下 9:4"> 大衛來到瑪哈念後，得到亞捫族拉巴人拿轄的兒子朔比、羅·底巴人亞米利的兒子瑪吉和基列的羅基琳人巴西萊的款待。</span>
<span className="v" id="v28" data-v="28" data-xref="撒母耳記上 25:18; 俄巴底亞書 1:3; 撒母耳記下 16:1–2"> 他們帶來被褥、碗盆、瓦器、小麥、大麥、麵粉、炒麥、豆子、扁豆、</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳記下 16:2; 以賽亞書 21:14; 撒母耳記下 16:14"> 蜂蜜、奶油、綿羊和乳酪，送給大衛和跟隨他的人，因為他們想：「眾人在曠野一定饑渴疲乏了。」</span>

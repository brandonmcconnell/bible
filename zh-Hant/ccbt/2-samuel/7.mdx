## 上帝對大衛的應許

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="箴言 16:7; 路加福音 1:74–75; 列王紀上 5:4"> 大衛住在王宮裡，耶和華使他安享太平，不受四圍的仇敵侵擾。</span>
<span className="v" id="v2" data-v="2" data-xref="歷代志上 16:1; 撒母耳記下 5:11; 哈該書 1:4"> 一天，王對拿單先知說：「你看，我住在香柏木建的王宮中，上帝的約櫃卻還在帳幕裡。」</span>
<span className="v" id="v3" data-v="3" data-xref="歷代志上 22:7; 列王紀上 8:17–18; 列王紀下 4:27"> 拿單答道：「你有什麼想法，就去做吧，因為耶和華與你同在。」</span>
<span className="v" id="v4" data-v="4" data-xref="歷代志上 17:3; 民數記 12:6; 阿摩司書 3:7"> 當晚耶和華對拿單說：</span>
<span className="v" id="v5" data-v="5" data-xref="歷代志上 23:3–32; 列王紀上 5:3–4; 列王紀上 8:16–19"> 「你去告訴我的僕人大衛，『耶和華說，你要建造殿宇給我居住嗎？</span>
<span className="v" id="v6" data-v="6" data-xref="列王紀上 8:16; 約書亞記 18:1; 出埃及記 40:18–19"> 從我把以色列人帶出埃及那天起，直到今天，我從未住過殿宇，一路上都住在帳幕裡。</span>
<span className="v" id="v7" data-v="7" data-xref="歷代志上 17:6; 撒母耳記下 5:2; 利未記 26:11–12"> 在我與以色列人同行的日子，我從未責問任何我委派牧養我子民的士師，你為何不為我建香柏木的殿宇呢？』</span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 78:70–71; 撒母耳記下 6:21; 撒母耳記下 12:7"> 「現在你要告訴我的僕人大衛，萬軍之耶和華說，『你原本在草場牧羊，我召你來做我以色列子民的首領。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳記下 5:10; 歷代志上 17:8; 撒母耳記上 18:14"> 無論你去哪裡，我都與你同在，為你剷除所有仇敵。現在我要使你聲名遠揚，與世上的偉人齊名。</span>
<span className="v" id="v10" data-v="10" data-xref="阿摩司書 9:15; 歷代志上 17:9; 耶利米書 24:6"> 我必為我的以色列子民預備一個地方，栽培他們，使他們住在自己的家園，不再受驚擾，不會像從前我設立士師治理他們的時候那樣受惡人壓迫。我必使你安定，免受仇敵的侵擾。我耶和華向你宣告，我必為你建立王朝。</span>
<span className="v" id="v12" data-v="12" data-xref="列王紀上 8:20; 使徒行傳 2:30; 使徒行傳 13:36"> 你離世與祖先同眠時，我必興起你親生的後裔接替你，使他的國穩固。</span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 1:31–33; 列王紀上 8:19; 撒母耳記下 7:16"> 他必為我的名建造殿宇，我必使他的國度王位永固。</span>
<span className="v" id="v14" data-v="14" data-xref="希伯來書 1:5; 啟示錄 3:19; 歷代志上 17:13"> 我要作他的父親，他要作我的兒子。如果他犯了罪，我必用人的杖、世人的鞭子來懲治他，</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳記上 15:23; 撒母耳記上 15:28; 詩篇 89:28"> 我的慈愛曾離開從你面前被廢的掃羅，但我的慈愛必不離開他。</span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 1:32–33; 詩篇 89:36–37; 撒母耳記下 7:13"> 你的家和你的國必在我面前永遠堅立，你的王位必永遠穩固。』」</span>
<span className="v" id="v17" data-v="17" data-xref="歷代志上 17:15; 使徒行傳 20:27; 哥林多前書 15:3"> 拿單就把所聽到的啟示全部告訴大衛。</span>
</div>
</div>

## 大衛的禱告

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="詩篇 8:4; 歷代志上 17:16; 撒母耳記上 18:18"> 於是，大衛王進去，在耶和華面前坐下，說：「主耶和華啊，我是誰？我的家算什麼？你竟這樣厚待我。</span>
<span className="v" id="v19" data-v="19" data-xref="以賽亞書 55:8–9; 歷代志上 17:17; 詩篇 36:7"> 主耶和華啊，在你眼中這還不夠，你還說到僕人家的將來。主耶和華啊，你竟這樣恩待世人！</span>
<span className="v" id="v20" data-v="20" data-xref="約翰福音 21:17; 撒母耳記上 16:7; 詩篇 139:1"> 主耶和華啊，大衛還能對你說什麼呢？因為你深知你的僕人。</span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 115:1; 詩篇 138:2; 以弗所書 1:9"> 你讓僕人知道你憑自己的應許、按自己的心意成就這大事。</span>
<span className="v" id="v22" data-v="22" data-xref="詩篇 86:10; 出埃及記 15:11; 詩篇 86:8"> 主耶和華啊，你真偉大！我們從未聽過有誰能與你相比，你是獨一無二的上帝。</span>
<span className="v" id="v23" data-v="23" data-xref="申命記 9:26; 申命記 10:21; 申命記 15:15"> 世上哪個民族比得上你的以色列子民呢？你從埃及救贖他們，讓他們做你的子民，又彰顯你的大名，行偉大而可畏的事，把列國及其神明從你的以色列子民面前趕走。</span>
<span className="v" id="v24" data-v="24" data-xref="申命記 26:18; 彼得前書 2:10; 創世記 17:7"> 你讓以色列人永遠做你的子民，你耶和華做他們的上帝。</span>
<span className="v" id="v25" data-v="25" data-xref="詩篇 119:49; 以西結書 36:37; 創世記 32:12"> 「耶和華上帝啊，求你永遠信守你對僕人和僕人家的應許，求你成就你的應許。</span>
<span className="v" id="v26" data-v="26" data-xref="歷代志上 17:23–24; 詩篇 72:18–19; 馬太福音 6:9"> 這樣，你的名必永遠被尊崇，人們必說，『萬軍之耶和華是以色列的上帝。』你僕人大衛的家必在你面前堅立。</span>
<span className="v" id="v27" data-v="27" data-xref="歷代志上 17:25–26; 詩篇 10:17; 路得記 4:4"> 以色列的上帝——萬軍之耶和華啊，因為你曾啟示僕人，說要為僕人建立王朝，僕人才敢這樣向你祈禱。</span>
<span className="v" id="v28" data-v="28" data-xref="約翰福音 17:17; 出埃及記 34:6; 民數記 23:19"> 主耶和華啊，唯有你是上帝，你的話真實可靠，你給了僕人美好的應許。</span>
<span className="v" id="v29" data-v="29" data-xref="民數記 6:24–26; 歷代志上 17:27; 詩篇 115:12–15"> 現在求你賜福給僕人家，使僕人家在你面前永續不斷。主耶和華啊，這些都是你的應許，願你永遠賜福給僕人家。」</span>
</div>

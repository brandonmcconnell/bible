## 拿單斥責大衛

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀上 20:35–41; 詩篇 51:1–19; 撒母耳記下 11:10–17"> 耶和華派拿單先知去見大衛。拿單對大衛說：「一座城裡有兩個人，一個富有，一個貧窮。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳記下 15:16; 約伯記 1:3; 撒母耳記下 5:13–16"> 富人擁有許多牛羊，</span>
<span className="v" id="v3" data-v="3" data-xref="彌迦書 7:5; 撒母耳記下 11:3; 箴言 5:18–19"> 窮人除了自己買來養活的一隻母羊羔外，什麼也沒有。他讓牠跟自己的兒女一起長大。他吃什麼，羊也吃什麼，他喝什麼，羊也喝什麼，甚至讓牠睡在自己懷裡，就像他女兒一樣。</span>
<span className="v" id="v4" data-v="4" data-xref="雅各書 1:14; 撒母耳記下 11:3–4; 創世記 18:2–7"> 一天，富人家中來了客人，他捨不得拿自己的牛羊款待客人，卻宰了窮人的羊給客人吃。」</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 38:24; 羅馬書 2:1; 撒母耳記上 26:16"> 大衛聽後非常憤怒，對拿單說：「我憑永活的耶和華起誓，做這事的人實在該死！</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及記 22:1; 路加福音 19:8; 箴言 6:31"> 他這樣做真是沒有半點憐憫之心，他必須償還那窮人四倍！」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="馬太福音 14:14; 撒母耳記上 16:13; 撒母耳記下 22:1"> 拿單對大衛說：「那人就是你！以色列的上帝耶和華這樣說，『我膏立你做以色列的王，從掃羅手中救你，</span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 84:11; 羅馬書 8:32; 撒母耳記下 9:7"> 將你主人的家業和妻妾交給你，把以色列和猶大的國權賜給你。倘若還不夠，我會再加倍地賜給你。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳記上 15:19; 詩篇 139:1–2; 撒母耳記上 15:23"> 你為什麼蔑視我的命令，做出我視為可憎的事呢？你藉亞捫人的刀殺了赫人烏利亞，把他的妻子據為己有。</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳記下 18:14–15; 馬太福音 26:52; 羅馬書 2:4"> 因為你藐視我，把赫人烏利亞的妻子據為己有，從今以後，殺戮流血的事必永不離開你的家。』</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳記下 16:21–22; 申命記 28:30; 撒母耳記下 15:10"> 耶和華說，『我要在你家中降下災禍，我要當著你的面把你的妻妾交給你的近臣，他必在光天化日之下與她們行淫。</span>
<span className="v" id="v12" data-v="12" data-xref="撒母耳記下 16:22; 撒母耳記下 11:4–15; 傳道書 12:14"> 你在暗地裡做這惡事，我要讓這樣的惡事當著以色列人的面在光天化日之下臨到你。』」</span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 51:4; 撒母耳記下 24:10; 箴言 28:13"> 大衛對拿單說：「我得罪了耶和華。」拿單說：「耶和華已經赦免了你的罪，使你不致死亡。</span>
<span className="v" id="v14" data-v="14" data-xref="羅馬書 2:24; 以賽亞書 52:5; 詩篇 89:31–33"> 但你做的醜事給了仇敵大肆褻瀆耶和華的機會，所以你這個孩子必定死。」</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳記上 25:38; 詩篇 104:29; 歷代志下 13:20"> 拿單說完，便回家去了。<br />耶和華擊打烏利亞的妻子給大衛生的孩子，使他患重病。</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳記下 13:31; 使徒行傳 9:9; 詩篇 69:10"> 大衛為這孩子向上帝哀求，並且禁食，他進到裡面，整夜躺在地上。</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳記下 3:35; 撒母耳記上 28:23"> 宮裡的老臣在旁邊伺候，想要扶他起來，他卻不肯，也不肯與他們一同吃飯。</span>
<span className="v" id="v18" data-v="18" data-xref="民數記 20:15"> 到了第七日，孩子死了。大衛的臣僕都不敢把這消息告訴他，因為他們心裡想：「孩子還活著的時候，我們勸他，他尚且不聽，若告訴他孩子死了，他會怎樣折磨自己呢？」</span>
<span className="v" id="v19" data-v="19"> 大衛看見他們交頭接耳，知道孩子死了，便問他們：「孩子死了？」他們答道：「是的，他死了。」</span>
<span className="v" id="v20" data-v="20" data-xref="約伯記 1:20; 路得記 3:3; 耶利米哀歌 3:39–41"> 大衛聽後，便從地上起來，沐浴更衣，抹上香膏，然後到耶和華的殿去敬拜。他回宮以後，吩咐人擺上食物，自己開始用膳。</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多前書 2:15"> 他的臣僕詫異地問他：「你這是什麼意思？孩子還活著的時候，你禁食、哀哭。孩子死了，你反倒起來進食。」</span>
<span className="v" id="v22" data-v="22" data-xref="以賽亞書 38:1–3; 以賽亞書 38:5; 約拿書 3:9–10"> 大衛說：「不錯，孩子活著的時候我禁食、哀哭，因為我想也許耶和華會向我開恩，讓他活命。</span>
<span className="v" id="v23" data-v="23" data-xref="創世記 37:35; 約伯記 30:23; 路加福音 23:43"> 但現在他既然死了，我禁食又有什麼用呢？能讓他起死回生嗎？我必去他那裡，他卻不能返回我這裡了。」</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="馬太福音 1:6; 歷代志上 28:5–6; 歷代志上 22:9–10"> 大衛安慰妻子拔示巴，與她同房，她便生了一個兒子。大衛給孩子取名叫所羅門。耶和華喜愛這孩子，</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳記下 7:4; 尼希米記 13:26; 列王紀上 1:11"> 祂差遣拿單先知去賜給他一個名字，叫耶底底亞，意思是耶和華喜愛他。</span>
</div>
</div>

## 大衛打敗亞捫人

<div className="bt">
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="歷代志上 20:1–3; 申命記 3:11; 撒母耳記下 11:25"> 那時，約押正攻打亞捫人的拉巴，佔領了王城。</span>
<span className="v" id="v27" data-v="27" data-xref="以西結書 21:20; 撒母耳記下 11:1; 申命記 3:11"> 他派使者去向大衛稟告說：「我攻打拉巴，已經佔領了城的水源。</span>
<span className="v" id="v28" data-v="28" data-xref="約翰福音 7:18"> 請你趕快帶領其餘的兵馬前來圍攻並佔領這城，免得我攻取這城以後，人們用我的名字為這城命名。」</span>
<span className="v" id="v29" data-v="29"> 於是，大衛便召集了所有的人去攻打拉巴，攻陷了那城，</span>
<span className="v" id="v30" data-v="30" data-xref="歷代志上 20:2"> 奪取了亞捫王頭上的金冠。這金冠重達三十四公斤，上面還鑲著寶石，人們將它戴在大衛頭上。大衛從城裡獲得許多戰利品，</span>
<span className="v" id="v31" data-v="31" data-xref="歷代志上 20:3; 詩篇 21:8–9; 阿摩司書 1:3"> 又把城裡的人帶出來，讓他們從事鋸木、耕田、砍樹的工作，還讓他們製作磚。他用同樣的方式對待亞捫其他城邑的居民。之後，大衛和全軍返回耶路撒冷。</span>
</div>

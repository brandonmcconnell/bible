## 大衛戰勝敵人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歷代志上 18:1–17; 撒母耳記下 7:9; 撒母耳記下 21:15–22"> 後來大衛打敗並征服了非利士人，奪取了他們的都城。</span>
<span className="v" id="v2" data-v="2" data-xref="民數記 24:17; 撒母耳記上 10:27; 撒母耳記下 8:6"> 他又打敗了摩押人，讓他們並排躺在地上，然後用繩子去量，每兩繩之內的人都要被殺掉，第三繩的人留下性命。從此，摩押人臣服於大衛，向他進貢。</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳記上 14:47; 撒母耳記下 10:16; 撒母耳記下 10:19"> 利合的兒子瑣巴王哈大底謝出來，要恢復他在幼發拉底河一帶的勢力，大衛打敗了他，</span>
<span className="v" id="v4" data-v="4" data-xref="約書亞記 11:6; 約書亞記 11:9; 歷代志上 18:4"> 俘獲一千七百名騎兵和兩萬名步兵，砍斷拉戰車的馬匹的蹄筋，只留下夠拉一百輛戰車的馬匹。</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀上 11:23–25; 以賽亞書 7:8; 約伯記 9:13"> 大馬士革的亞蘭人前來支援瑣巴王哈大底謝，大衛殺了他們兩萬二千人，</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳記下 8:14; 撒母耳記下 7:9; 詩篇 18:34–46"> 還在大馬士革的亞蘭境內駐軍，亞蘭人臣服於大衛，向他進貢。耶和華使大衛無往而不勝。</span>
<span className="v" id="v7" data-v="7" data-xref="歷代志下 9:15–16; 列王紀上 14:26–27; 列王紀上 10:16–17"> 大衛奪走哈大底謝侍從的金盾牌，帶回耶路撒冷，</span>
<span className="v" id="v8" data-v="8" data-xref="歷代志上 18:8; 歷代志上 22:16; 以西結書 47:16"> 又從哈大底謝統治的比他和比羅他兩座城中奪走大量的銅。</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀上 8:65; 歷代志下 8:4; 歷代志上 18:9"> 哈馬王陀以聽說大衛打敗哈大底謝全軍，</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳記上 13:10; 歷代志上 18:10; 詩篇 129:8"> 就派兒子約蘭帶著許多金銀銅器去朝見大衛王，向他請安，祝賀他打敗了哈大底謝。因為陀以常常和哈大底謝交戰。</span>
<span className="v" id="v11" data-v="11" data-xref="列王紀上 7:51; 歷代志上 29:2; 歷代志上 22:14–16"> 大衛王把這些器皿和他征服亞蘭人、摩押人、亞捫人、非利士人、亞瑪力人，以及利合的兒子瑣巴王哈大底謝時所得的金銀都分別出來，奉獻給耶和華。</span>
<span className="v" id="v13" data-v="13" data-xref="列王紀下 14:7; 撒母耳記下 7:9; 歷代志上 18:12"> 大衛在鹽谷殺了一萬八千亞蘭人歸來後，聲威大振。</span>
<span className="v" id="v14" data-v="14" data-xref="創世記 27:29; 創世記 25:23; 撒母耳記下 8:6"> 他又在以東全境駐軍，以東人都臣服於他。耶和華使他無往而不勝。</span>
<span className="v" id="v15" data-v="15" data-xref="阿摩司書 5:15; 詩篇 89:14; 詩篇 72:2"> 大衛治理全以色列，對百姓秉公行義。</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀上 4:3; 歷代志上 11:6; 撒母耳記下 19:13"> 那時，洗魯雅的兒子約押做元帥；亞希律的兒子約沙法做史官；</span>
<span className="v" id="v17" data-v="17" data-xref="歷代志上 6:8; 歷代志上 18:16; 歷代志上 24:3–4"> 亞希突的兒子撒督和亞比亞他的兒子亞希米勒做祭司長；西萊雅做書記；</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳記上 30:14; 撒母耳記下 20:7; 撒母耳記下 20:23"> 耶何耶大的兒子比拿雅統管基利提人和比利提人。大衛的眾子都做祭司。</span>

## 大衛的遺言

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="撒母耳記上 16:12–13; 撒母耳記下 7:8–9; 詩篇 89:20"> 耶西的兒子大衛是雅各的上帝膏立的王，他身居高位，在以色列能歌善詠。以下是他的遺言：</span>
<span className="v" id="v2" data-v="2" data-xref="彼得後書 1:21; 馬太福音 22:43; 馬可福音 12:36"> <span className="pl pl-1">「耶和華的靈藉著我說話，</span><br /><span className="pl pl-1">祂的言語在我口中。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳記下 22:32; 申命記 32:4; 出埃及記 18:21"> <span className="pl pl-1">以色列的上帝告訴我，</span><br /><span className="pl pl-1">以色列的磐石對我說，</span><br /><span className="pl pl-1">『以公義治理人民，</span><br /><span className="pl pl-1">敬畏上帝的君王，</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="士師記 5:31; 詩篇 72:6; 何西阿書 6:5"> <span className="pl pl-1">就像旭日的光輝、</span><br /><span className="pl pl-1">晴朗的早晨，</span><br /><span className="pl pl-1">又像雨後的光芒，</span><br /><span className="pl pl-1">使大地長出青草。』</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="以賽亞書 55:3; 撒母耳記下 7:14–16; 以賽亞書 9:6–7"> <span className="pl pl-1">我的家在上帝面前不正是如此嗎？</span><br /><span className="pl pl-1">上帝與我立下永遠的約，</span><br /><span className="pl pl-1">這約穩妥可靠。</span><br /><span className="pl pl-1">祂必拯救我，成全我的願望。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="以西結書 2:6; 以賽亞書 33:12; 申命記 13:13"> <span className="pl pl-1">但惡人要像荊棘一樣被丟棄，</span><br /><span className="pl pl-1">沒人用手拿起他們，</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="希伯來書 6:8; 帖撒羅尼迦後書 2:8; 以賽亞書 27:4"> <span className="pl pl-1">人要拿鐵器和長矛把他們收集起來焚毀。」</span></span>
</div>
</div>

## 大衛的勇士

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="歷代志上 27:2; 歷代志上 11:11–47; 歷代志上 27:32"> 以下是大衛的勇士：他革捫人約設·巴設，又稱伊斯尼人亞底挪，是三勇士之首，曾在一次交戰中殺掉八百敵人。</span>
<span className="v" id="v9" data-v="9" data-xref="歷代志上 27:4; 歷代志上 11:12–14; 撒母耳記上 17:26"> 其次是亞哈希人朵多的兒子以利亞撒，他是三勇士之一。有一次，以色列人和非利士人打仗，他跟隨大衛向非利士人罵陣。以色列人都撤退了，</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳記上 19:5; 撒母耳記上 11:13; 士師記 15:14"> 他卻堅守陣地，奮勇殺敵，直到手臂發麻，握刀的手無法鬆開。那天，耶和華使以色列人大獲全勝。以色列軍隊回到以利亞撒那裡來撿死人的財物。</span>
<span className="v" id="v11" data-v="11" data-xref="歷代志上 11:13–14; 歷代志上 11:27; 撒母耳記下 23:33"> 第三位勇士是哈拉人亞基的兒子沙瑪。有一次非利士人聚集在一塊長滿扁豆的田中和以色列人打仗，以色列人都逃跑了，</span>
<span className="v" id="v12" data-v="12" data-xref="箴言 21:31; 撒母耳記下 23:10; 詩篇 3:8"> 沙瑪卻站在田中間堅守麥田，擊殺非利士人。耶和華使以色列人大獲全勝。</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳記上 22:1; 撒母耳記下 5:18; 約書亞記 12:15"> 在收割的時候，非利士軍隊在利乏音谷紮營，三十位統領中有三位到亞杜蘭洞見大衛。</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳記上 22:4–5; 撒母耳記上 13:4; 撒母耳記上 10:5"> 那時大衛留守在堡壘裡，非利士人的駐軍在伯利恆。</span>
<span className="v" id="v15" data-v="15" data-xref="約翰福音 4:14; 詩篇 42:1–2; 以賽亞書 41:17"> 大衛渴了，說：「但願有人給我打些伯利恆城門旁的井水喝！」</span>
<span className="v" id="v16" data-v="16" data-xref="創世記 35:14; 哥林多後書 5:14; 腓立比書 2:17"> 這三位勇士就衝過非利士人的營地，到伯利恆城門旁的井打水，帶回來給大衛。大衛卻不肯喝，他把水澆奠在耶和華面前，</span>
<span className="v" id="v17" data-v="17" data-xref="利未記 17:10; 馬可福音 14:24; 哥林多前書 15:30"> 說：「耶和華啊！這三人冒死去打水，這些水就像是他們的血，我決不能喝！」因此，大衛不肯喝。這是三勇士的事蹟。</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳記下 10:10; 撒母耳記下 10:14; 歷代志上 11:20–21"> 洗魯雅的兒子、約押的兄弟亞比篩是這三位<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「三位」有些希伯來文抄本作「三十位」。">a</a></sup>勇士的統領，他曾揮矛刺死三百人，在三勇士中出了名，</span>
<span className="v" id="v19" data-v="19" data-xref="馬太福音 13:8; 馬太福音 13:23; 哥林多前書 15:41"> 最有聲望，因此做了他們的統領，只是不及前三位勇士。</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳記下 8:18; 約書亞記 15:21; 撒母耳記下 20:23"> 甲薛人耶何耶大的兒子比拿雅是位勇士，做過非凡的事。他曾殺死摩押的兩個勇猛戰士，也曾在下雪天跳進坑中殺死一頭獅子，</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳記上 17:51; 歷代志上 11:23; 歌羅西書 2:15"> 還殺死了一個埃及勇士。當時埃及人拿著長矛，比拿雅拿著棍子迎戰，他奪了對方的長矛，用那矛刺死了對方。</span>
<span className="v" id="v22" data-v="22"> 這是耶何耶大的兒子比拿雅的事蹟，他像那三位勇士一樣贏得了名聲。</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳記下 20:23; 歷代志上 27:6; 撒母耳記上 22:14"> 他比那三十勇士更有聲望，只是不及前三位勇士。大衛派他作護衛長。</span>
<span className="v" id="v24" data-v="24" data-xref="撒母耳記下 2:18; 歷代志上 27:7; 歷代志上 11:26"> 三十位勇士中有：約押的兄弟亞撒黑、伯利恆人朵多的兒子伊勒哈難、</span>
<span className="v" id="v25" data-v="25" data-xref="士師記 7:1; 歷代志上 11:27–28"> 哈律人沙瑪、哈律人以利加、</span>
<span className="v" id="v26" data-v="26" data-xref="撒母耳記下 14:2; 歷代志上 11:27–28; 歷代志上 27:9–10"> 帕勒提人希利斯、提哥亞人益吉的兒子以拉、</span>
<span className="v" id="v27" data-v="27" data-xref="約書亞記 21:18; 歷代志上 11:19; 歷代志上 11:28"> 亞拿突人亞比以謝、戶沙人米本乃、</span>
<span className="v" id="v28" data-v="28" data-xref="歷代志上 27:13; 列王紀下 25:23; 歷代志上 11:30"> 亞哈希人撒們、尼陀法人瑪哈萊、</span>
<span className="v" id="v29" data-v="29" data-xref="歷代志上 11:30–31; 約書亞記 18:28; 歷代志上 27:15"> 尼陀法人巴拿的兒子希立、便雅憫支派基比亞人利拜的兒子以太、</span>
<span className="v" id="v30" data-v="30" data-xref="士師記 12:15; 歷代志上 27:14; 士師記 12:13"> 比拉頓人比拿雅、迦實溪人希太、</span>
<span className="v" id="v31" data-v="31" data-xref="撒母耳記下 3:16; 歷代志上 11:32–33"> 伯·亞拉巴人亞比亞本、巴魯米人押斯瑪弗、</span>
<span className="v" id="v32" data-v="32" data-xref="歷代志上 11:34"> 沙本人以利雅哈巴、雅善的兒子們、哈拉人沙瑪的兒子約拿單、</span>
<span className="v" id="v33" data-v="33" data-xref="歷代志上 11:27; 撒母耳記下 23:11; 歷代志上 11:35"> 哈拉人沙拉的兒子亞希暗、</span>
<span className="v" id="v34" data-v="34" data-xref="撒母耳記下 11:3; 撒母耳記下 15:12; 撒母耳記下 10:6"> 瑪迦人亞哈拜的兒子以利法列、基羅人亞希多弗的兒子以連、</span>
<span className="v" id="v35" data-v="35" data-xref="歷代志上 11:37; 約書亞記 15:55"> 迦密人希斯萊、亞巴人帕萊、</span>
<span className="v" id="v36" data-v="36" data-xref="撒母耳記下 8:3; 歷代志上 11:38"> 瑣巴人拿單的兒子以甲、迦得人巴尼、</span>
<span className="v" id="v37" data-v="37" data-xref="歷代志上 11:37; 歷代志上 11:39; 撒母耳記下 4:2"> 亞捫人洗勒、為洗魯雅的兒子約押拿兵器的比錄人拿哈萊、</span>
<span className="v" id="v38" data-v="38" data-xref="歷代志上 2:53; 撒母耳記下 20:26; 歷代志上 11:40"> 以帖人以拉、以帖人迦立、</span>
<span className="v" id="v39" data-v="39" data-xref="撒母耳記下 11:3; 馬太福音 1:6; 列王紀上 15:5"> 赫人烏利亞，共三十七名勇士。</span>

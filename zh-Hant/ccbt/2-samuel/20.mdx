## 示巴反叛大衛

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀上 12:16; 歷代志下 10:16; 申命記 13:13"> 有一個無賴名叫示巴，是便雅憫人比基利的兒子，當時剛好在吉甲。他吹響號角，大喊：「我們與大衛毫無關係，耶西兒子的產業沒有我們的份。以色列人啊，各自回家去吧！」</span>
<span className="v" id="v2" data-v="2" data-xref="約翰福音 6:66–68; 使徒行傳 11:23; 撒母耳記下 19:15"> 於是，以色列人都離開了大衛，跟隨了比基利的兒子示巴。但猶大人仍然緊緊跟隨他們的王，從約旦河一直來到耶路撒冷。</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳記下 16:21–22; 撒母耳記下 15:16; 創世記 40:3"> 大衛回到耶路撒冷的宮裡，把從前留下來看守王宮的十個妃嬪關進冷宮，供養她們，卻不再和她們同房。她們像寡婦一樣在軟禁中度過餘生。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="撒母耳記下 19:13; 撒母耳記下 17:25; 歷代志上 2:17"> 王對亞瑪撒說：「你要在三天內招聚猶大人，跟他們一起來見我。」</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳記下 19:13; 撒母耳記上 13:8"> 亞瑪撒就去招聚猶大人，但他超過了王所定的期限。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳記下 21:17; 撒母耳記下 11:11; 列王紀上 1:33"> 大衛對亞比篩說：「現在比基利的兒子示巴給我們帶來的危害恐怕比押沙龍還要大。你帶領我的部下去捉拿他，免得他佔據了堅固的城池，得以逃脫。」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="撒母耳記下 8:18; 列王紀上 1:38; 撒母耳記下 20:23"> 於是，約押的部下和基利提人、比利提人，以及所有的勇士都跟隨亞比篩離開耶路撒冷，去追趕比基利的兒子示巴。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳記下 3:30; 撒母耳記下 2:13; 撒母耳記下 20:4–5"> 他們來到基遍的巨石旁，見亞瑪撒迎面而來。約押當時身穿戰袍，腰間佩刀，他迎上去的時候，刀從鞘中滑落出來。</span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 22:47–48; 馬太福音 26:48–49; 彌迦書 7:2"> 約押對亞瑪撒說：「兄弟，你好嗎？」他用右手抓住亞瑪撒的鬍子，親吻他。</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳記下 2:23; 撒母耳記下 3:27; 士師記 3:21"> 亞瑪撒毫無防備，被約押一刀刺入肚子，肚破腸流而死。然後，約押和他兄弟亞比篩繼續追趕比基利的兒子示巴。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="撒母耳記下 20:13; 撒母耳記下 20:21; 列王紀下 9:32"> 約押的一個部下站在亞瑪撒的屍體旁邊說：「擁護約押和大衛的人來跟隨約押吧！」</span>
<span className="v" id="v12" data-v="12" data-xref="箴言 24:21–22; 詩篇 9:16; 撒母耳記下 17:25"> 亞瑪撒的屍體倒在路中間的血泊中。那人見眾人駐足圍觀，便把屍體從路上拖到田裡，扔了一件衣服蓋上。</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳記上 6:12; 以賽亞書 7:3; 列王紀下 18:17"> 屍體搬走以後，眾人都跟隨約押去追比基利的兒子示巴。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="列王紀下 15:29; 列王紀上 15:20; 歷代志下 16:4"> 示巴走遍以色列各支派，一直到伯·瑪迦的亞比拉城。他的本族比利人都聚集起來跟隨他。</span>
<span className="v" id="v15" data-v="15" data-xref="列王紀下 19:32; 耶利米書 32:24; 列王紀上 15:20"> 約押率大軍來到伯·瑪迦，把示巴圍困在亞比拉城內，他們修築攻城的高臺，撞擊城牆，要摧毀它。</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳記下 14:2; 傳道書 9:14–18; 撒母耳記上 25:32–33"> 有一個聰明的婦人從城上喊：「請聽我說！請聽我說！請約押到這邊來，我有話要對他說。」</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳記下 14:12; 撒母耳記上 25:24"> 約押就走上前去，那婦人問道：「你是約押嗎？」約押答道：「我就是。」婦人說：「請聽婢女說幾句。」約押說：「你說吧！」</span>
<span className="v" id="v18" data-v="18" data-xref="申命記 20:10–11"> 婦人說：「古時候人們常說，『有事到亞比拉去請教，問題都會解決。』</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳記上 26:19; 撒母耳記下 21:3; 撒母耳記下 17:16"> 我們這座城的人在以色列素來熱愛和平、忠心耿耿，你卻要毀滅這座大城。你為什麼要吞掉耶和華的產業？」</span>
<span className="v" id="v20" data-v="20" data-xref="路加福音 10:29; 箴言 28:13; 耶利米書 17:9"> 約押答道：「我根本不想吞掉或毀滅這城。</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳記上 26:9; 士師記 2:9; 撒母耳記下 17:2–3"> 事情不是這樣。以法蓮山區比基利的兒子示巴背叛大衛王，你們只要把他交出來，我就撤退。」那婦人說：「我們一定把他的首級從城上拋下來給你。」</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳記下 20:1; 傳道書 7:19; 撒母耳記下 11:6–21"> 婦人把自己的良策告訴眾人，他們便把比基利的兒子示巴的頭割下來，拋給約押。約押就吹響號角令軍隊各自回家，自己回耶路撒冷見王。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="撒母耳記下 8:16–18; 歷代志上 18:15–17; 列王紀上 4:3–6"> 約押負責統率以色列全軍；耶何耶大的兒子比拿雅統管基利提人和比利提人；</span>
<span className="v" id="v24" data-v="24" data-xref="列王紀上 4:3; 列王紀上 12:18; 列王紀上 4:6"> 亞多蘭管理服勞役的；亞希律的兒子約沙法做史官；</span>
<span className="v" id="v25" data-v="25" data-xref="列王紀上 4:4; 撒母耳記下 8:17; 歷代志上 18:16"> 示法做書記；撒督和亞比亞他做祭司；</span>
<span className="v" id="v26" data-v="26" data-xref="撒母耳記下 23:38; 出埃及記 2:14; 創世記 41:45"> 雅珥人以拉做大衛的祭司。</span>
</div>

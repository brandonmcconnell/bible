## 大衛做猶大王

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳記上 30:31; 撒母耳記上 23:4; 創世記 32:2"> 這事以後，大衛求問耶和華：「我可以回到猶大的城邑嗎？」耶和華說：「可以。」大衛又問：「我應該回到哪一座城呢？」耶和華說：「希伯崙。」</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳記上 25:42–43; 撒母耳記上 30:5; 路加福音 22:28–29"> 大衛就帶著他的兩個妻子耶斯列人亞希暖和迦密人拿八的遺孀亞比該，一起上到希伯崙。</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳記上 30:1; 歷代志上 12:1–7; 撒母耳記上 27:2–3"> 他還把部下和他們的家屬一起帶去，住在希伯崙地區的城邑。</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳記下 5:5; 撒母耳記上 31:11–13; 撒母耳記下 5:3"> 猶大人到希伯崙膏立大衛做猶大支派的王。 大衛聽說是基列·雅比人埋葬了掃羅，</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳記上 23:21; 詩篇 115:15; 路得記 2:20"> 就派使者去告訴他們：「你們這樣厚待你們的主人掃羅，把他安葬，願耶和華賜福給你們！</span>
<span className="v" id="v6" data-v="6" data-xref="箴言 14:22; 出埃及記 34:6; 馬太福音 5:44"> 願耶和華以慈愛和信實待你們，我也會厚待你們，因為你們做了這事。</span>
<span className="v" id="v7" data-v="7" data-xref="以弗所書 6:10; 撒母耳記下 10:12; 創世記 15:1"> 現在你們的主掃羅已經死了，猶大支派已經膏立我做他們的王，你們要剛強勇敢。」</span>
</div>
</div>

## 大衛家與掃羅家爭戰

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="撒母耳記上 14:50; 創世記 32:2; 撒母耳記下 3:7–8"> 那時，掃羅的元帥——尼珥的兒子押尼珥帶著掃羅的兒子伊施·波設過河來到瑪哈念，</span>
<span className="v" id="v9" data-v="9" data-xref="約書亞記 19:18; 約書亞記 13:8–11; 民數記 1:40"> 立他為王統治基列、亞書利、耶斯列、以法蓮、便雅憫和以色列其餘的地方。</span>
<span className="v" id="v10" data-v="10"> 掃羅的兒子伊施·波設四十歲登基，統治以色列兩年。猶大支派則跟隨大衛。</span>
<span className="v" id="v11" data-v="11" data-xref="列王紀上 2:11; 撒母耳記下 5:4–5; 歷代志上 3:4"> 大衛在希伯崙做王統治猶大支派七年半。</span>
<span className="v" id="v12" data-v="12" data-xref="約書亞記 18:25; 約書亞記 10:2; 約書亞記 9:3"> 有一次，尼珥的兒子押尼珥帶領掃羅的兒子伊施·波設的軍隊，從瑪哈念前往基遍。</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳記下 8:16; 歷代志上 2:16; 撒母耳記下 20:23"> 洗魯雅的兒子約押帶領大衛的軍隊出來，在基遍池與他們相遇。一方坐在池這邊，一方坐在池那邊。</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳記下 2:17; 箴言 10:23; 箴言 17:14"> 押尼珥對約押說：「讓雙方的青年起來，在我們面前較量一下吧。」約押說：「好啊。」</span>
<span className="v" id="v15" data-v="15"> 於是，伊施·波設的便雅憫人和大衛的僕人雙方都起身選了十二人出來，</span>
<span className="v" id="v16" data-v="16"> 他們各自抓住對方的頭髮，用刀刺對方的肋旁，同歸於盡。於是基遍的那個地方叫「刀田」。</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳記下 3:1"> 那天，兩軍惡戰，押尼珥和以色列人被大衛的人馬殺敗。</span>
<span className="v" id="v18" data-v="18" data-xref="歷代志上 12:8; 哈巴谷書 3:19; 雅歌 8:14"> 當時，洗魯雅的三個兒子約押、亞比篩和亞撒黑都在場。亞撒黑跑得飛快如田野的鹿，</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳記下 2:21; 約書亞記 1:7; 箴言 4:27"> 他跟在押尼珥後面，不偏不離，窮追不捨。</span>
<span className="v" id="v20" data-v="20"> 押尼珥回頭問道：「你是亞撒黑嗎？」亞撒黑說：「正是。」</span>
<span className="v" id="v21" data-v="21" data-xref="士師記 14:19"> 押尼珥說：「你離開我，去追趕別人，奪取他的兵器吧。」但亞撒黑還是窮追不捨。</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳記下 3:27; 箴言 29:1; 列王紀下 14:10–12"> 押尼珥又對他說：「別追我了，非逼我殺你嗎？我若殺了你，還有何顏面見你哥哥約押呢？」</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳記下 3:27; 撒母耳記下 4:6; 撒母耳記下 5:6"> 但亞撒黑還是不肯甘休。押尼珥就用槍柄刺入他的肚腹，穿透了他的後背，他便倒地身亡。眾人趕到那裡，都停了下來。</span>
<span className="v" id="v24" data-v="24"> 但約押和亞比篩卻繼續追趕押尼珥。太陽落山時，他們追到了基亞附近的亞瑪山，通往基遍曠野的路旁。</span>
<span className="v" id="v25" data-v="25"> 便雅憫人在押尼珥的帶領下聚集在一個山頭上。</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米書 46:14; 耶利米書 46:10; 使徒行傳 7:26"> 押尼珥向約押喊道：「我們非要無休止地殺下去嗎？難道你不知道這樣下去必有苦果嗎？你什麼時候才命令你的人停止追殺自己的同胞呢？」</span>
<span className="v" id="v27" data-v="27" data-xref="箴言 17:14; 撒母耳記下 2:14; 箴言 15:1"> 約押說：「我憑永活的上帝起誓，你要是不這樣說，我們會一直追到天亮。」</span>
<span className="v" id="v28" data-v="28"> 於是，約押吹響號角，所有的人便停止了戰鬥，不再追擊以色列人。</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳記下 2:8; 雅歌 2:17"> 押尼珥和隨從連夜趕路，穿過了亞拉巴，過了約旦河，第二天又馬不停蹄地走了一個上午，回到瑪哈念。</span>
<span className="v" id="v30" data-v="30"> 約押追趕押尼珥回來後細點人數，發現除亞撒黑外大衛的軍隊還損失了十九個人。</span>
<span className="v" id="v31" data-v="31" data-xref="撒母耳記下 3:1; 列王紀上 20:11"> 大衛的軍隊殺了三百六十個跟隨押尼珥的便雅憫人。</span>
<span className="v" id="v32" data-v="32" data-xref="歷代志上 2:13–16; 撒母耳記上 17:58; 歷代志下 21:1"> 約押和他的隨從把亞撒黑送到伯利恆，葬在他父親的墳墓裡。然後，他們整夜趕路，黎明的時候回到了希伯崙。</span>
</div>

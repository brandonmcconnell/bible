## 大衛和洗巴

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳記上 25:18; 撒母耳記下 15:32; 撒母耳記下 9:2–13"> 大衛剛越過了山頂，就看見米非波設的僕人洗巴牽著兩頭驢，驢背上馱著二百個麵餅、一百個葡萄餅、一百個夏天的果餅和一皮袋酒來迎接他。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳記下 17:29; 士師記 10:4; 士師記 5:10"> 王問洗巴說：「你帶這些來做什麼？」洗巴說：「驢是給王的家眷騎的，餅和夏天的水果是給你的隨從吃的，酒是供他們在曠野疲憊時喝的。」</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳記下 9:9–10; 詩篇 15:3; 撒母耳記下 19:24–30"> 王又問他：「你主人的孫子米非波設在哪裡？」洗巴說：「他在耶路撒冷，因為他相信現在以色列人會把他祖父的國歸還給他。」</span>
<span className="v" id="v4" data-v="4" data-xref="箴言 18:13; 箴言 18:17; 箴言 19:2"> 王就對洗巴說：「米非波設的一切現在都歸你了。」洗巴說：「我叩拜我主我王，願我在你面前蒙恩。」</span>
</div>
</div>

## 示每咒詛大衛

<div className="bt">
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="撒母耳記下 3:16; 撒母耳記上 17:43; 出埃及記 22:28"> 大衛王來到巴戶琳時，掃羅家族基拉的兒子示每出來向著大衛邊走邊罵，</span>
<span className="v" id="v6" data-v="6"> 還朝大衛和他的臣僕扔石頭，無視大衛身邊的眾多隨從和勇士。</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 13:13; 撒母耳記上 25:17; 列王紀上 21:10"> 示每罵大衛：「滾吧！滾吧！你這個殺人兇手，你這個敗類！</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳記下 1:16; 撒母耳記下 3:28–29; 列王紀上 2:32–33"> 你殺掃羅的家人，奪他的王位，耶和華報應了你，把江山交給了你兒子押沙龍。你這殺人兇手是自食惡果！」</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及記 22:28; 撒母耳記下 9:8; 撒母耳記上 24:14"> 洗魯雅的兒子亞比篩對王說：「這死狗竟敢咒罵我主我王，讓我過去砍掉他的頭！」</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳記下 19:22; 羅馬書 9:20; 約翰福音 18:11"> 王卻說：「洗魯雅的兒子啊，不要管我的事。如果是耶和華叫他來咒罵我，誰能干涉他呢？」</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳記下 17:1–4; 創世記 45:5; 撒母耳記下 12:11–12"> 大衛對亞比篩和他所有臣僕說：「我的親生兒子尚且要取我的命，何況這個便雅憫人呢？由他去吧！讓他咒罵吧！因為這是耶和華的意思。</span>
<span className="v" id="v12" data-v="12" data-xref="申命記 23:5; 希伯來書 12:10; 詩篇 25:18"> 也許耶和華會體察我的困苦，因我今天所受的咒罵而賜福給我。」</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行傳 23:23; 撒母耳記下 16:5–6"> 於是，大衛和隨從繼續趕路，示每也沿著對面的山坡邊走邊罵，向他們扔石頭，撒灰塵。</span>
<span className="v" id="v14" data-v="14"> 王和眾人來到約旦河邊時，疲憊不堪，便在那裡歇息。</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳記下 15:37; 撒母耳記下 15:12"> 押沙龍和以色列眾人進了耶路撒冷，亞希多弗也和他在一起。</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀下 11:12; 撒母耳記上 10:24; 列王紀上 1:25"> 大衛的朋友亞基人戶篩去見押沙龍，對他說：「願王萬歲！願王萬歲！」</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳記下 19:25; 撒母耳記下 15:32–37; 申命記 32:6"> 押沙龍問戶篩說：「這就是你對朋友的忠誠嗎？你為什麼不跟你的朋友去呢？」</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳記上 16:13; 撒母耳記下 5:1–3"> 戶篩說：「我不去，誰是耶和華和全體以色列人民所揀選的，我就歸屬誰，留在誰那裡。</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳記下 15:34; 詩篇 55:21; 撒母耳記上 28:2"> 再說，我應該服侍誰呢？難道不該服侍王的兒子嗎？我要像服侍你父親一樣服侍你。」</span>
<span className="v" id="v20" data-v="20" data-xref="以賽亞書 8:10; 詩篇 37:12–13; 以賽亞書 29:15"> 押沙龍問亞希多弗下一步應該怎麼辦。</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳記下 20:3; 撒母耳記下 15:16; 撒迦利亞書 8:13"> 亞希多弗說：「你父親留下幾個妃嬪看守宮殿，你要跟她們同寢，叫所有的以色列人知道你與父親誓不兩立，這樣支持你的人會更堅定。」</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳記下 12:11–12; 撒母耳記下 15:16; 撒母耳記下 20:3"> 於是，他們便為押沙龍在殿頂蓋了一座帳篷，他就當著所有以色列人的面與父親的妃嬪同寢。</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳記下 15:12; 撒母耳記下 17:14; 撒母耳記下 17:23"> 那時，亞希多弗出的主意如同是來自上帝的話，大衛曾對他言聽計從，現在押沙龍也是一樣。</span>

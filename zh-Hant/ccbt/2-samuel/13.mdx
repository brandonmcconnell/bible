## 暗嫩玷污她瑪

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歷代志上 3:9; 撒母耳記下 3:2–3; 撒母耳記下 13:15"> 後來，大衛的兒子暗嫩愛上了美麗的她瑪，她瑪是大衛的兒子押沙龍的妹妹。</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多後書 7:10; 列王紀上 21:4; 雅歌 5:8"> 她仍是處女，住在深宮裡，暗嫩無法接近她，相思成病。</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳記上 16:9; 哥林多前書 3:19; 雅各書 3:15"> 暗嫩有一個朋友名叫約拿達，是大衛長兄示米亞的兒子，生性狡猾。</span>
<span className="v" id="v4" data-v="4" data-xref="利未記 20:17; 利未記 18:9; 以斯帖記 5:13–14"> 他問暗嫩：「王子，你為什麼一天比一天消沉？能告訴我嗎？」暗嫩答道：「我愛上了我兄弟押沙龍的妹妹她瑪。」</span>
<span className="v" id="v5" data-v="5" data-xref="馬可福音 6:24–25; 箴言 19:27; 使徒行傳 23:15"> 約拿達說：「你回去躺在床上裝病，你父親來探望你的時候，你就請求他叫你妹妹她瑪來，在你面前預備食物，請她親手遞給你吃。」</span>
<span className="v" id="v6" data-v="6" data-xref="創世記 18:6; 馬太福音 13:33"> 暗嫩就躺在床上裝病。王來看他的時候，他便對王說：「請你叫我妹妹她瑪來這裡，在我面前做兩個餅，請她親自遞給我吃。」</span>
<span className="v" id="v7" data-v="7"> 大衛便派人進宮對她瑪說：「你去你哥哥暗嫩房裡為他預備食物吧。」</span>
<span className="v" id="v8" data-v="8"> 她瑪到了哥哥暗嫩的家，暗嫩正躺在床上裝病。她拿了麵團在他面前揉麵做餅，把餅烤熟了。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 45:1; 約翰福音 3:20; 士師記 3:19"> 她拿著鍋在他面前把餅倒出來，但暗嫩卻不肯吃。暗嫩命令僕人：「你們全都出去吧！」僕人就都退下了。</span>
<span className="v" id="v10" data-v="10"> 暗嫩對她瑪說：「你把食物拿到我的臥房來，親手遞給我吃。」她瑪便拿著餅進了她哥哥暗嫩的臥房裡，</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 39:11–12"> 上前給他吃，暗嫩卻抓住她，說：「妹妹，與我同寢吧！」</span>
<span className="v" id="v12" data-v="12" data-xref="士師記 19:23; 利未記 20:17; 士師記 20:6"> 她瑪說：「哥哥，不要，不要玷污我！在以色列不應當發生這種事，不要做這種惡事。</span>
<span className="v" id="v13" data-v="13" data-xref="士師記 19:24; 創世記 20:12; 創世記 19:8"> 你這樣叫我怎麼見人呢？你在以色列也必遭人唾棄。你可以請求王，他會同意把我許配給你。」</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳記下 12:11; 以斯帖記 7:8; 士師記 20:5"> 暗嫩卻充耳不聞，因為他力氣比她瑪大，就把她強姦了。</span>
<span className="v" id="v15" data-v="15" data-xref="以西結書 23:17"> 事後暗嫩非常憎恨她瑪，對她的恨比以前對她的愛還強烈。他對她瑪說：「你起來走吧！」</span>
<span className="v" id="v16" data-v="16"> 她瑪哀求道：「不要這樣對我！你趕我走是更大的惡行。」暗嫩卻不聽，</span>
<span className="v" id="v17" data-v="17"> 他吩咐隨從：「把這女人趕出去，隨後鎖上門。」</span>
<span className="v" id="v18" data-v="18" data-xref="士師記 5:30; 創世記 37:3; 詩篇 45:13–14"> 他的隨從就把她瑪趕出去，隨後鎖上了門。那時，她瑪穿著彩色的長衣，沒有出嫁的公主都穿這種衣服。</span>
<span className="v" id="v19" data-v="19" data-xref="約書亞記 7:6; 耶利米書 2:37; 撒母耳記下 1:11"> 她瑪把灰塵撒在頭上，撕破身上的彩衣，雙手抱著頭，一面走一面哭。</span>
<span className="v" id="v20" data-v="20" data-xref="羅馬書 12:19; 創世記 46:15; 創世記 34:2"> 她的哥哥押沙龍問她：「是不是你哥哥暗嫩污辱了你？妹妹，不要聲張，他是你哥哥，不要把這件事放在心上。」於是她瑪就憂憂鬱鬱地住在押沙龍家裡。</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 34:7; 撒母耳記下 3:28–29; 撒母耳記上 2:29"> 大衛王聽見了這件事以後，非常生氣。</span>
<span className="v" id="v22" data-v="22" data-xref="利未記 19:17–18; 創世記 31:24; 創世記 24:50"> 押沙龍好話壞話都沒有對暗嫩說一句話，只是心裡暗暗地恨他，因為他玷污了妹妹她瑪。</span>
</div>
</div>

## 押沙龍為妹妹報仇

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="創世記 38:12–13; 撒母耳記上 25:4; 歷代志下 26:10"> 兩年後，押沙龍的工人在以法蓮附近的巴力·夏瑣剪羊毛，押沙龍邀請王的眾子去那裡。</span>
<span className="v" id="v24" data-v="24" data-xref="撒母耳記下 11:8–15; 耶利米書 41:6–7; 詩篇 55:21"> 他去見王，說：「工人正在為僕人剪羊毛，請王和眾臣僕跟僕人一起去吧。」</span>
<span className="v" id="v25" data-v="25" data-xref="路加福音 14:23; 士師記 19:7–10; 撒母耳記下 14:22"> 王說：「我兒，我們不必都去打擾你。」押沙龍再三邀請，王還是推辭了，但他為押沙龍祝福。</span>
<span className="v" id="v26" data-v="26" data-xref="撒母耳記下 20:9; 撒母耳記下 3:27; 撒母耳記下 11:13–15"> 押沙龍說：「王若不去，請讓我兄弟暗嫩跟我們去吧。」大衛說：「何必要他同去呢？」</span>
<span className="v" id="v27" data-v="27" data-xref="箴言 26:24–26"> 但押沙龍再三懇求，王就讓暗嫩和其他王子一同去了。</span>
<span className="v" id="v28" data-v="28" data-xref="士師記 19:6; 士師記 19:22; 士師記 19:9"> 押沙龍吩咐僕人說：「你們要留意，當暗嫩喝得正高興的時候，我叫你們動手，你們就要殺他。不要害怕，要剛強勇敢！因為這是我的命令。」</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳記下 18:9; 列王紀上 1:33; 列王紀下 1:9–12"> 押沙龍的僕人就照命令把暗嫩殺了。王的眾子都起來騎上騾子逃走了。</span>
<span className="v" id="v30" data-v="30"> 他們還在路上的時候，有人稟告大衛說：「押沙龍把王子都殺了，無一倖免！」</span>
<span className="v" id="v31" data-v="31" data-xref="撒母耳記下 1:11; 撒母耳記下 12:16; 約伯記 1:20"> 王便站起來撕裂衣服，躺在地上。眾臣僕也都撕裂衣服，站在旁邊。</span>
<span className="v" id="v32" data-v="32" data-xref="撒母耳記上 16:9; 撒母耳記下 13:3; 創世記 27:41"> 大衛的長兄示米亞的兒子約拿達說：「我主不要以為所有的王子都被殺了，其實只有暗嫩一人死了。自從暗嫩姦污押沙龍的妹妹她瑪以來，押沙龍便決定要報仇了。</span>
<span className="v" id="v33" data-v="33" data-xref="撒母耳記下 19:19"> 所以，我主我王啊，不要相信這消息，不是所有的王子都死了，只有暗嫩一人死了。」</span>
<span className="v" id="v34" data-v="34" data-xref="創世記 4:8–14; 箴言 28:17; 阿摩司書 5:19"> 此時，押沙龍已經逃走了。守望的人舉目瞭望，見有一大群人從西面山坡的路上下來。</span>
<span className="v" id="v35" data-v="35"> 約拿達對王說：「請看，王子們都回來了！正如僕人所言。」</span>
<span className="v" id="v36" data-v="36" data-xref="撒母耳記下 18:33; 撒母耳記下 12:21; 撒母耳記下 13:15"> 話剛說完，眾王子已經來到他們跟前放聲大哭，王和眾臣僕也哀痛不已。</span>
<span className="v" id="v37" data-v="37" data-xref="撒母耳記下 3:3; 撒母耳記下 14:32; 撒母耳記下 13:34"> 押沙龍逃到了亞米忽的兒子基述王達買那裡，在那裡住了三年。大衛王天天為他兒子暗嫩悲傷，</span>
<span className="v" id="v39" data-v="39" data-xref="創世記 24:67; 創世記 38:12; 創世記 37:35"> 後來心情恢復平靜，開始想念押沙龍。</span>
</div>

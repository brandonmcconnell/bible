## 大衛犯罪

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歷代志上 20:1; 列王紀上 20:26; 列王紀上 20:22"> 第二年春天，諸王又要發動戰爭。大衛差遣約押率領眾將領和以色列大軍出征，自己卻留在耶路撒冷。他們打敗了亞捫人之後又圍攻拉巴。</span>
<span className="v" id="v2" data-v="2" data-xref="馬太福音 5:28; 詩篇 119:37; 約伯記 31:1"> 一天黃昏，大衛從床上起來在王宮頂上散步，看見一個長得非常漂亮的女人在沐浴。</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳記下 23:39; 歷代志上 3:5; 雅各書 1:14–15"> 大衛就派人去打聽這個女人是誰，得知她是以連的女兒、赫人烏利亞的妻子拔示巴。</span>
<span className="v" id="v4" data-v="4" data-xref="利未記 18:19; 雅各書 1:14–15; 詩篇 51:1–19"> 大衛派使者把她接來，她來了，大衛就與她同寢，那時她的月經剛潔淨。事後，她便回家去了。</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 22:22; 箴言 6:34"> 拔示巴懷孕了，就派人去告訴大衛。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="箴言 28:13; 創世記 4:7; 撒母耳記上 15:30"> 大衛便傳信給約押，說：「你派赫人烏利亞來見我。」約押就派烏利亞去見大衛。</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 37:14; 撒母耳記上 17:22; 創世記 29:6"> 烏利亞來了，大衛問他有關約押、士兵和戰爭的情況，</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 18:4; 創世記 43:34; 以賽亞書 29:15"> 然後吩咐他回家休息。烏利亞離開王宮後，收到王送的一份禮物。</span>
<span className="v" id="v9" data-v="9" data-xref="箴言 21:30; 約伯記 5:12–14"> 但他跟王的其他僕人一同睡在王宮門口，沒有回家。</span>
<span className="v" id="v10" data-v="10"> 大衛得知烏利亞沒有回家，便對他說：「你遠道而來，為什麼不回家休息呢？」</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳記下 7:2; 撒母耳記下 20:6; 撒母耳記下 7:6"> 烏利亞答道：「約櫃、以色列人和猶大人都在帳篷裡，而我主約押及其軍隊也在田間紮營，我怎麼可以回家吃喝，與妻子同房呢？我以王的性命起誓，我決不做這樣的事！」</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米書 2:37; 耶利米書 2:22–23"> 大衛對烏利亞說：「你再住一天，明天我會派你回去。」於是烏利亞那日就留在耶路撒冷。</span>
<span className="v" id="v13" data-v="13" data-xref="哈巴谷書 2:15; 創世記 19:32–35; 箴言 20:1"> 第二天，大衛邀請他一同吃飯，把他灌醉了。可是到了晚上，烏利亞還是不肯回家，仍然跟王的其他士兵一同住宿。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="耶利米書 17:9; 列王紀上 21:8–10; 詩篇 19:13"> 第二天早上，大衛給約押寫了一封信，要烏利亞帶去。</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳記下 12:9; 詩篇 51:4; 耶利米書 20:13"> 大衛在信上吩咐約押：「你把烏利亞派到前線最險惡的地方，到時其他人都要撤退，好讓敵人殺死他。」</span>
<span className="v" id="v16" data-v="16" data-xref="箴言 29:12; 撒母耳記上 22:17–19; 使徒行傳 5:29"> 於是約押圍攻城池時，便派烏利亞到他知道的最強悍的敵人那裡。</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳記下 12:9; 詩篇 51:14"> 敵人出來迎戰約押，大衛的軍中有幾位陣亡，赫人烏利亞也死了。</span>
<span className="v" id="v18" data-v="18"> 約押就派人去向大衛稟告戰爭的詳情，</span>
<span className="v" id="v19" data-v="19"> 並叮囑信使：「你向王稟告戰情後，</span>
<span className="v" id="v20" data-v="20"> 他若發怒責問你，『為什麼還冒死逼近城池呢？你們難道不知道敵人會從城牆上射箭嗎？</span>
<span className="v" id="v21" data-v="21" data-xref="士師記 7:1; 士師記 9:50–54; 撒母耳記下 3:27"> 難道你們不知道耶路·比設<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「耶路·比設」又名「耶路·巴力」，參見士師記6·32。">a</a></sup>的兒子亞比米勒是誰殺的嗎？一個婦人從城牆上扔下一塊磨石，把他砸死在提備斯。你們為什麼還要逼近城牆呢？』你就對王說，『你的僕人赫人烏利亞也死了。』」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22"> 於是，信使前來見大衛，照約押的吩咐向大衛稟告。</span>
<span className="v" id="v23" data-v="23"> 他說：「敵軍勢力強大，在城外跟我們交戰，但我們把他們追到城門口。</span>
<span className="v" id="v24" data-v="24"> 敵軍的弓箭手從城牆上射死了王的幾個士兵，赫人烏利亞也死了。」</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳記下 12:26; 約書亞記 7:8–9; 傳道書 9:1–3"> 大衛便對信使說：「你去告訴約押不要為這事難過，因為刀劍無情。讓他只管竭力攻陷城池。要這樣勉勵約押。」</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="撒母耳記下 14:2; 創世記 27:41; 撒母耳記下 3:31"> 拔示巴聽到丈夫烏利亞的死訊之後就為他哭喪。</span>
<span className="v" id="v27" data-v="27" data-xref="詩篇 51:4–5; 撒母耳記下 12:9; 申命記 22:29"> 喪期過後，大衛便派人把她接進宮裡，她就做了大衛的妻子，並給他生了個兒子。然而，大衛的所作所為令耶和華十分不悅。</span>
</div>

## 大衛統計人口

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歷代志上 21:1; 歷代志上 27:23–24; 雅各書 1:13–14"> 耶和華又向以色列人發怒，祂促使大衛來對付他們，讓大衛統計以色列和猶大的人口。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳記下 3:10; 士師記 20:1; 撒母耳記下 20:23"> 大衛對統領軍隊的約押說：「你去走遍以色列各支派，從但到別示巴，統計以色列和猶大的人口，讓我知道國民的數目。」</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 1:11; 詩篇 115:14; 箴言 14:28"> 約押說：「我主我王，願你的上帝耶和華使國民的人數比現在增加百倍，讓你親眼看到。但我主我王為什麼要做這事呢？」</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行傳 5:29; 傳道書 8:4; 歷代志上 21:4"> 但大衛不聽約押和其他將領的規勸。他們只好去統計以色列的人數。</span>
<span className="v" id="v5" data-v="5" data-xref="約書亞記 13:9; 申命記 2:36; 約書亞記 13:16"> 他們過了約旦河，在谷中亞羅珥城南面安營，又經過迦得前往雅謝。</span>
<span className="v" id="v6" data-v="6" data-xref="約書亞記 19:28; 創世記 31:47–48; 士師記 18:28–29"> 然後，他們到基列、他停·合示地區、但·雅安，繞到西頓，</span>
<span className="v" id="v7" data-v="7" data-xref="約書亞記 19:29; 約書亞記 11:3; 創世記 21:22–33"> 再去泰爾的堡壘及希未人和迦南人的城邑。最後，他們到了猶大南部的別示巴。</span>
<span className="v" id="v8" data-v="8"> 他們花了九個月零二十天的時間，走遍全國，最後回到耶路撒冷。</span>
<span className="v" id="v9" data-v="9" data-xref="歷代志上 27:23–24; 歷代志上 21:5–6; 民數記 1:44–46"> 約押把統計的人數奏告王：「以色列有八十萬英勇的刀兵，猶大有五十萬。」</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳記下 12:13; 撒母耳記上 13:13; 箴言 28:13"> 大衛統計了人口以後，內心不安，就對耶和華說：「我做這事犯了大罪。耶和華啊，求你赦免僕人的罪，我做了極其愚昧的事。」</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳記上 22:5; 撒母耳記上 9:9; 歷代志上 29:29"> 大衛第二天早上起來，耶和華對大衛的先見迦得先知說：</span>
<span className="v" id="v12" data-v="12" data-xref="希伯來書 12:6–10; 啟示錄 3:19; 箴言 3:12"> 「你去告訴大衛，耶和華說，『我有三樣災禍，你可以選擇讓我降哪一樣給你。』」</span>
<span className="v" id="v13" data-v="13" data-xref="歷代志上 21:12; 利未記 26:25; 撒母耳記下 21:1"> 迦得就來見大衛，對他說：「你願意國內有七年饑荒呢？還是被敵人追殺三個月呢？還是國內發生三天瘟疫呢？請你考慮好後告訴我，我好回覆那差我來的。」</span>
<span className="v" id="v14" data-v="14" data-xref="詩篇 51:1; 詩篇 119:156; 歷代志上 21:13"> 大衛說：「我實在為難！不過我寧願落在耶和華的手中，也不願落在人的手中，因為耶和華有極大的憐憫。」</span>
<span className="v" id="v15" data-v="15" data-xref="歷代志上 21:14; 歷代志上 27:24; 民數記 25:9"> 於是，耶和華在以色列降下瘟疫，從那天早晨一直持續到所定的時間，從但到別示巴共有七萬人死亡。</span>
<span className="v" id="v16" data-v="16" data-xref="約珥書 2:13–14; 創世記 6:6; 出埃及記 12:23"> 當天使準備伸手毀滅耶路撒冷的時候，耶和華心生憐憫，就對滅命天使說：「夠了，住手吧！」當時，耶和華的天使正站在耶布斯人亞勞拿的麥場上。</span>
<span className="v" id="v17" data-v="17" data-xref="詩篇 74:1; 歷代志上 21:16–17; 撒母耳記下 24:10"> 大衛看見滅命天使，就對耶和華說：「是我犯了罪，做了惡事，這些百姓有什麼過錯呢？願你的手懲罰我和我的家族。」</span>
<span className="v" id="v18" data-v="18" data-xref="歷代志上 21:18–30; 撒母耳記下 24:11"> 就在那天，迦得來見大衛，對他說：「你要去耶布斯人亞勞拿的麥場，在那裡為耶和華建一座壇。」</span>
<span className="v" id="v19" data-v="19" data-xref="希伯來書 11:8; 尼希米記 9:26; 歷代志下 36:16"> 大衛就照耶和華藉迦得所說的話去了麥場。</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 18:2; 路得記 2:10; 歷代志上 21:20–21"> 亞勞拿看見王及他的臣僕來了，就上前俯伏在地，向王下拜，</span>
<span className="v" id="v21" data-v="21" data-xref="歷代志上 21:22; 民數記 25:8; 撒母耳記下 21:3–14"> 說：「我主我王到僕人這裡有什麼事？」大衛說：「我要買你的麥場，好在這裡為耶和華築一座壇，使民中的瘟疫止息。」</span>
<span className="v" id="v22" data-v="22" data-xref="列王紀上 19:21; 撒母耳記上 6:14; 歷代志上 21:22"> 亞勞拿說：「我主我王喜歡什麼，就拿去獻祭吧。這裡有牛可以作燔祭，還有打麥的器具和牛軛可以作柴。</span>
<span className="v" id="v23" data-v="23" data-xref="以西結書 20:40–41; 以賽亞書 32:8; 詩篇 20:3–4"> 王啊，僕人亞勞拿願意把這一切都獻給你，願你的上帝耶和華悅納你。」</span>
<span className="v" id="v24" data-v="24" data-xref="歷代志上 21:24–25; 瑪拉基書 1:12–14; 創世記 23:13"> 王卻說：「不可，我一定要出錢買，我不要用白白得來之物作為燔祭獻給我的上帝耶和華。」大衛就用十兩銀子買了亞勞拿的麥場和牛。</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳記下 21:14; 耶利米哀歌 3:32–33; 創世記 8:20"> 大衛在那裡為耶和華建了一座壇，獻上燔祭和平安祭，耶和華垂聽了他的禱告，瘟疫就在以色列止住了。</span>

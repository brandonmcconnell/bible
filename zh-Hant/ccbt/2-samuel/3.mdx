## 押尼珥之死

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀上 14:30; 箴言 4:18–19; 約伯記 8:7"> 掃羅和大衛兩家長期爭戰，大衛家的勢力越來越強，掃羅家卻日益衰微。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="歷代志上 3:1–4; 創世記 49:3–4; 撒母耳記下 13:1–29"> 大衛在希伯崙生的兒子有耶斯列人亞希暖所生的長子暗嫩，</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳記上 27:8; 歷代志上 3:1; 申命記 3:14"> 迦密人拿八的遺孀亞比該所生的次子基利押，基述王達買的女兒瑪迦所生的三子押沙龍，</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀上 2:13–25; 列王紀上 1:5–18"> 哈及所生的四子亞多尼雅，亞比她所生的五子示法提雅，</span>
<span className="v" id="v5" data-v="5"> 大衛的妻子以格拉所生的六子以特念。大衛的這些兒子都是在希伯崙生的。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="撒母耳記下 2:8–9; 歷代志下 25:8; 以賽亞書 8:9–10"> 在掃羅和大衛兩家爭戰期間，押尼珥在掃羅家權勢日增。</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳記下 21:8–11; 列王紀上 2:21–22; 撒母耳記下 12:8"> 他跟掃羅的一個妃嬪、愛亞的女兒利斯巴通姦，伊施·波設問他：「你為什麼睡我父親的妃嬪呢？」</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳記下 9:8; 撒母耳記下 16:9; 馬可福音 6:18–19"> 押尼珥聽了非常憤怒，說：「難道我是猶大的走狗嗎？我至今還這樣厚待你父親掃羅家和他的親戚朋友，沒有把你交給大衛，今天你竟為了這個女人來責備我！</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳記上 15:28; 列王紀上 19:2; 路得記 1:17"> 倘若我不照著耶和華應許大衛的誓言，把掃羅的江山奪過來交給大衛，讓他統治全以色列和猶大，從但到別示巴，願耶和華重重地懲罰我！」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11"> 伊施·波設一句話也不敢答，因為他害怕押尼珥。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="歷代志上 12:38–40; 撒母耳記下 3:21; 路加福音 16:5–8"> 押尼珥派使者送信給大衛，說：「這是誰的土地呢？如果你與我立約，我必幫助你統一以色列。」</span>
<span className="v" id="v13" data-v="13" data-xref="創世記 43:3; 撒母耳記上 19:11–17; 創世記 44:23"> 大衛回答說：「好，我與你立約，但有一個要求：你一定要把掃羅的女兒米甲帶來才能見我。」</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳記上 18:27; 撒母耳記上 18:25; 撒母耳記下 2:10"> 於是，大衛派使者去見掃羅的兒子伊施·波設說：「請把我的妻子米甲送回來，因為她是我用一百個非利士人的包皮作聘禮娶來的。」</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳記上 25:44"> 伊施·波設就派人把米甲從她丈夫、拉億的兒子帕鐵那裡接回來。</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳記下 16:5; 撒母耳記下 19:16; 列王紀上 2:8"> 帕鐵一路跟著米甲，邊走邊哭，一直到巴戶琳。押尼珥對他說：「你回去吧！」他就回去了。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17"> 押尼珥和以色列的長老商量說：「你們以前一直都希望大衛做你們的王，</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳記上 15:28; 詩篇 89:19–23; 撒母耳記上 9:16"> 現在是時候了，因為耶和華曾說要藉著祂僕人大衛的手，從非利士人和其他所有敵人手中拯救祂的以色列子民。」</span>
<span className="v" id="v19" data-v="19" data-xref="歷代志上 12:29; 撒母耳記上 10:20–21; 詩篇 68:27"> 押尼珥也跟便雅憫人商談，然後到希伯崙把以色列人和便雅憫人的願望告訴大衛。</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 31:54; 創世記 26:30; 以斯帖記 1:3"> 當時，他帶了二十個人前往希伯崙見大衛，大衛就設宴款待他們。</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳記下 3:12; 列王紀上 11:37; 撒母耳記下 3:10"> 押尼珥對大衛說：「我要去招聚所有以色列人到我主我王這裡，好跟你立約，你便可以如願以償，統治全以色列。」於是大衛為他送行，他就平安地回去了。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22"> 大衛送押尼珥平安離開後不久，約押就率領大衛的軍隊襲敵歸來，並帶回許多戰利品。</span>
<span className="v" id="v23" data-v="23"> 約押率領全軍回來後，有人告訴他：「尼珥的兒子押尼珥剛才來朝見王，王送他平安地離去了。」</span>
<span className="v" id="v24" data-v="24" data-xref="撒母耳記下 3:8; 撒母耳記下 19:5–7; 約翰福音 18:35"> 約押聽後，就去見王，說：「你這做的是什麼事？押尼珥來見你，你為什麼放他走呢？</span>
<span className="v" id="v25" data-v="25" data-xref="申命記 28:6; 以賽亞書 37:28; 民數記 27:17"> 你要知道，尼珥的兒子押尼珥想來騙你，探聽你的虛實。」</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="箴言 26:23–26; 箴言 27:4–6"> 約押從大衛那裡出來，派使者去追押尼珥，他們在西拉井追上了他，把他帶了回來。大衛對這件事一無所知。</span>
<span className="v" id="v27" data-v="27" data-xref="列王紀上 2:5; 撒母耳記下 20:9–10; 列王紀上 2:32"> 押尼珥回到希伯崙的時候，約押就把他帶到城門的甕洞，裝作與他密談，乘機用短劍刺入他的肚子，把他殺死了，為他兄弟亞撒黑報了仇。</span>
<span className="v" id="v28" data-v="28" data-xref="民數記 35:33; 出埃及記 21:12; 創世記 9:6"> 後來，大衛聽到消息就說：「我和我的國在耶和華面前永遠跟尼珥的兒子押尼珥的死無關。</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳記下 1:16; 詩篇 109:8–19; 利未記 13:44–46"> 約押和他全家要承擔這罪，願他的後代永遠有長瘡的、患皮膚病的、拄拐杖的、被刀劍所殺的或挨餓的。」</span>
<span className="v" id="v30" data-v="30" data-xref="箴言 28:17; 使徒行傳 28:4; 撒母耳記下 2:19–23"> 約押和他兄弟亞比篩之所以殺押尼珥，是因為押尼珥在基遍殺了他們的兄弟亞撒黑。</span>
</div>
<div className="bp poetry">
<span className="v" id="v31" data-v="31" data-xref="創世記 37:34; 撒母耳記下 1:11; 撒母耳記下 1:2"> 大衛對約押和部下說：「你們要撕裂衣服，腰束麻布，在押尼珥棺前哭喪！」大衛王也跟在棺後送葬。</span>
<span className="v" id="v32" data-v="32" data-xref="箴言 24:17; 約伯記 31:28; 撒母耳記上 30:4"> 他們就把押尼珥葬在希伯崙。大衛王和眾人在墓旁大哭一場。</span>
<span className="v" id="v33" data-v="33" data-xref="撒母耳記下 1:17; 歷代志下 35:25; 路加福音 12:19–20"> 大衛王哀悼押尼珥，說：<br /><span className="pl pl-1">「押尼珥啊！</span><br /><span className="pl pl-1">你怎能死得糊里糊塗</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「糊里糊塗」希伯來文是「像愚笨人」。">a</a></sup><br /><span className="pl pl-1">呢？</span><br /></span>
<span className="v" id="v34" data-v="34" data-xref="士師記 16:21; 撒母耳記下 1:12; 約伯記 24:14"> <span className="pl pl-1">你的手沒有被捆，</span><br /><span className="pl pl-1">你的腳沒有被鎖，</span><br /><span className="pl pl-1">你是死在奸惡之人的手裡啊！」</span><br />於是眾人都為押尼珥哀哭。</span>
<span className="v" id="v35" data-v="35" data-xref="撒母耳記下 12:17; 撒母耳記下 1:12; 路得記 1:17"> 大衛整天沒有進食，眾人來勸他吃一點東西，但他起誓說：「我若在日落以前吃任何東西，願上帝重重地懲罰我！」</span>
<span className="v" id="v36" data-v="36" data-xref="馬可福音 7:37; 詩篇 62:9; 馬可福音 15:11–13"> 眾人聽見了，都很喜悅，王做的每一件事都令他們喜悅。</span>
<span className="v" id="v37" data-v="37"> 那天全以色列的人都看出尼珥的兒子押尼珥的死與大衛無關。</span>
<span className="v" id="v38" data-v="38" data-xref="約伯記 32:9; 撒母耳記下 2:8; 撒母耳記下 3:12"> 大衛王對他的隨從說：「你們難道不知道今天以色列損失了一位偉大的將領嗎？</span>
<span className="v" id="v39" data-v="39" data-xref="列王紀上 2:33–34; 詩篇 101:8; 詩篇 28:4"> 今天我雖然是被膏立的王，但仍勢單力薄，無法對付洗魯雅的兩個兒子，願耶和華報應他們的惡行。」</span>
</div>
</div>

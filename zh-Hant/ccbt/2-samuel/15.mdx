## 押沙龍謀反

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀上 1:5; 撒母耳記下 12:11; 撒母耳記上 8:11"> 後來，押沙龍為自己備了車馬，又派五十個人在他前面開道。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 18:14; 路得記 4:1; 約伯記 24:14"> 他常常清早起來，站在城門的通道旁邊。每當有人來找王審理爭訟時，押沙龍便問他是從哪一座城來的，那人就會報上自己所屬的支派。</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳記下 8:15; 以西結書 22:7; 彼得前書 2:17"> 押沙龍會對他說：「你的申訴合情合理，可惜王沒有派人來聽你申訴。」</span>
<span className="v" id="v4" data-v="4" data-xref="士師記 9:29; 士師記 9:1–5; 箴言 27:2"> 他接著會說：「要是我被立為國中的審判官就好了！那樣，任何人有爭訟都可以來找我，我一定會為他主持公道。」</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳記下 14:33; 詩篇 55:21; 箴言 26:25"> 每當有人要向他叩拜，他都伸手扶他，親吻他。</span>
<span className="v" id="v6" data-v="6" data-xref="羅馬書 16:18; 彼得後書 2:3; 箴言 11:9"> 押沙龍這樣對待每一個來向王申訴的以色列人，贏得了民心。</span>
<span className="v" id="v7" data-v="7" data-xref="以賽亞書 58:4; 撒母耳記上 16:13; 撒母耳記上 16:1–2"> 過了四年，押沙龍對王說：「請讓我到希伯崙去還我向耶和華許下的願吧。</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 28:20–21; 撒母耳記下 13:37–38; 撒母耳記上 1:11"> 僕人住在亞蘭的基述時曾許願，如果耶和華帶領我回到耶路撒冷，我必在希伯崙敬拜祂。」</span>
<span className="v" id="v9" data-v="9"> 王說：「你平安地去吧！」押沙龍就去了希伯崙。</span>
<span className="v" id="v10" data-v="10" data-xref="歷代志上 12:38; 撒母耳記下 5:5; 撒母耳記下 3:2–3"> 他派密使通知以色列各支派一聽見號角的響聲，便喊：「押沙龍在希伯崙做王了！」</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳記上 9:13; 撒母耳記上 22:15; 羅馬書 16:18–19"> 有二百人應邀隨同押沙龍一起從耶路撒冷去希伯崙，他們對內情一無所知。</span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 41:9; 撒母耳記下 15:31; 約書亞記 15:51"> 押沙龍獻祭的時候，還派人去把大衛的謀士亞希多弗從他的故鄉基羅請來。反叛的勢力大增，擁護押沙龍的民眾越來越多。</span>
</div>
</div>

## 大衛逃離耶路撒冷

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="士師記 9:3; 馬太福音 27:22; 撒母耳記下 15:6"> 有人來稟告大衛：「以色列的民心都歸向押沙龍了。」</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳記下 19:9; 以西結書 46:18; 詩篇 55:3–11"> 大衛便對在耶路撒冷跟隨他的臣僕說：「我們趕快逃命吧！否則，我們都難逃押沙龍的追捕。我們要馬上離開！免得他趕到殘害我們，屠殺全城。」</span>
<span className="v" id="v15" data-v="15" data-xref="約翰福音 6:66–69; 箴言 18:24; 路加福音 22:28–29"> 臣僕對王說：「臣等謹遵我主我王的決定。」</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳記下 16:21–22; 撒母耳記下 20:3; 詩篇 3:1"> 於是王就帶著全家逃命，只留下十個妃嬪看守宮殿。</span>
<span className="v" id="v17" data-v="17" data-xref="詩篇 3:1–2; 傳道書 10:7; 詩篇 66:12"> 大衛王帶著眾民離開耶路撒冷，走到最後的那座房子時，停了下來。</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳記下 8:18; 撒母耳記上 30:14; 撒母耳記下 20:7"> 他的臣僕都從他身邊過去了，包括基利提人、比利提人以及從迦特來的六百個隨從。</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳記下 18:2; 路得記 1:11–13"> 王問迦特人以太說：「你為什麼要跟我們一起逃難呢？回去留在新王那裡吧！你是流亡到這裡的外族人。</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳記上 23:13; 撒母耳記下 2:6; 約翰福音 1:17"> 你剛來不久，我怎麼可以叫你跟我們一同四處飄流呢？我甚至不知道往何處去。你還是和你的弟兄回去吧，願耶和華以慈愛和信實待你！」</span>
<span className="v" id="v21" data-v="21" data-xref="路得記 1:16–17; 箴言 17:17; 列王紀下 4:30"> 以太卻答道：「我憑永活的耶和華和我主我王的性命起誓，不管我王去哪裡，僕人都要誓死追隨到底！」</span>
<span className="v" id="v22" data-v="22"> 大衛便對以太說：「那就繼續前行吧！」於是，迦特人以太帶著他的人及所有的家眷繼續前行。</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳記下 16:2; 列王紀上 2:37; 約翰福音 18:1"> 眾人離開時，當地的百姓都放聲大哭。王帶著所有的人過了汲淪溪，向曠野走去。</span>
<span className="v" id="v24" data-v="24" data-xref="民數記 4:15; 撒母耳記下 8:17; 撒母耳記下 20:25"> 祭司撒督、亞比亞他和抬上帝約櫃的利未人都來了，他們把約櫃放下，讓城裡出來的人先走過去。</span>
<span className="v" id="v25" data-v="25" data-xref="耶利米書 25:30; 詩篇 26:8; 詩篇 43:3–4"> 王對撒督說：「你把上帝的約櫃抬回城去吧。耶和華若恩待我，必使我重返家園，重見約櫃和會幕；</span>
<span className="v" id="v26" data-v="26" data-xref="撒母耳記上 3:18; 撒母耳記下 22:20; 列王紀上 10:9"> 但我若使祂不悅，也甘願聽憑祂的處置。</span>
<span className="v" id="v27" data-v="27" data-xref="撒母耳記上 9:9; 撒母耳記下 17:17; 撒母耳記下 24:11"> 你是個有先見之明的人，安心帶著你的兒子亞希瑪斯和亞比亞他的兒子約拿單回城吧。</span>
<span className="v" id="v28" data-v="28" data-xref="撒母耳記下 17:16; 撒母耳記下 15:23; 撒母耳記下 17:1"> 我會在曠野渡口那裡等你們的消息。」</span>
<span className="v" id="v29" data-v="29"> 於是，撒督和亞比亞他便把上帝的約櫃抬回耶路撒冷，留了下來。</span>
<span className="v" id="v30" data-v="30" data-xref="以斯帖記 6:12; 撒母耳記下 19:4; 路加福音 19:41"> 大衛蒙著頭，赤著腳登上橄欖山，邊走邊哭，他的隨從也蒙著頭，哭著走上山。</span>
<span className="v" id="v31" data-v="31" data-xref="撒母耳記下 17:14; 撒母耳記下 17:23; 雅各書 3:15"> 有人告訴大衛，亞希多弗也叛變，投奔了押沙龍，大衛就禱告說：「耶和華啊，求你使亞希多弗的謀算都變得愚不可及。」</span>
<span className="v" id="v32" data-v="32" data-xref="約書亞記 16:2; 撒母耳記下 1:2; 詩篇 3:3–5"> 大衛來到山頂敬拜上帝的地方，看見亞基人戶篩撕破了衣服，頭蒙灰塵前來迎接他。</span>
<span className="v" id="v33" data-v="33" data-xref="撒母耳記下 19:35"> 大衛對他說：「你跟我一同逃命，只會給我帶來不便。</span>
<span className="v" id="v34" data-v="34" data-xref="約書亞記 8:2; 撒母耳記下 16:16–19; 馬太福音 10:16"> 你若回到城中，告訴押沙龍你願意做他的臣僕，就像以前做我的臣僕一樣，就可以幫我破壞亞希多弗的計謀。</span>
<span className="v" id="v35" data-v="35" data-xref="撒母耳記下 17:15–16"> 祭司撒督和亞比亞他都在那裡，你在宮內聽到什麼消息就告訴他們。</span>
<span className="v" id="v36" data-v="36" data-xref="撒母耳記下 17:17; 撒母耳記下 15:27; 撒母耳記下 18:19–33"> 撒督的兒子亞希瑪斯和亞比亞他的兒子約拿單也在那裡，你聽到什麼消息，可以派他們傳信給我。」</span>
<span className="v" id="v37" data-v="37" data-xref="撒母耳記下 16:15–16; 歷代志上 27:33"> 於是，大衛的朋友戶篩便回到城裡。那時，押沙龍也進了耶路撒冷。</span>
</div>

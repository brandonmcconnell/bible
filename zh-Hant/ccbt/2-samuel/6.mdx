## 運約櫃到耶路撒冷

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歷代志上 13:1–4; 列王紀上 8:1; 歷代志上 13:6–14"> 大衛又召集了三萬名以色列精兵，</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳記上 4:4; 撒母耳記上 7:1; 詩篇 80:1"> 率領他們到猶大的巴拉去接上帝的約櫃。這約櫃以坐在基路伯天使之間的萬軍之耶和華的名字命名。</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳記上 6:7; 民數記 7:4–9; 民數記 4:5–12"> 他們把上帝的約櫃從座落在山上的亞比拿達家抬出來，放在一輛新車上，由亞比拿達的兩個兒子烏撒和亞希約趕車，</span>
<span className="v" id="v4" data-v="4" data-xref="歷代志上 13:7; 撒母耳記上 7:1–2"> 亞希約走在約櫃前面。</span>
<span className="v" id="v5" data-v="5" data-xref="歷代志上 13:8; 詩篇 150:3–5; 阿摩司書 5:23"> 大衛和全體以色列人在耶和華面前用琴、瑟、鼓、鈸和鑼奏樂，盡情歌舞。</span>
<span className="v" id="v6" data-v="6" data-xref="歷代志上 13:9; 民數記 4:15; 民數記 4:19–20"> 他們走到拿肯的麥場時，拉車的牛失蹄，烏撒就伸手去扶上帝的約櫃。</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳記上 6:19; 歷代志上 15:13; 歷代志上 13:10"> 耶和華上帝便向他發怒，因他的不敬而擊殺了他。他死在了約櫃旁邊。</span>
<span className="v" id="v8" data-v="8" data-xref="約拿書 4:1; 歷代志上 13:11–12; 約拿書 4:9"> 大衛因耶和華擊殺烏撒而煩惱，就稱那地方為毗列斯·烏撒<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「毗列斯·烏撒」意思是「向烏撒發怒」。">a</a></sup>，沿用至今。</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 119:120; 歷代志上 13:11–12; 民數記 17:12–13"> 那天，大衛懼怕耶和華，就說：「耶和華的約櫃怎能運到我這裡？」</span>
<span className="v" id="v10" data-v="10" data-xref="歷代志上 26:4–8; 撒母耳記下 15:19; 歷代志上 15:18"> 他不願把耶和華的約櫃運進大衛城，而是把它運到迦特人俄別·以東家。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 39:5; 創世記 30:27; 箴言 3:9–10"> 耶和華的約櫃在俄別·以東家存放了三個月，耶和華賜福給俄別·以東和他全家。</span>
<span className="v" id="v12" data-v="12" data-xref="歷代志上 15:25–3; 列王紀上 8:1; 馬太福音 10:42"> 大衛聽說耶和華因為約櫃而賜福給俄別·以東全家及其一切所有，就歡歡喜喜地去把上帝的約櫃從俄別·以東家接進大衛城。</span>
<span className="v" id="v13" data-v="13" data-xref="列王紀上 8:5; 歷代志上 15:15; 民數記 4:15"> 這一次，抬耶和華約櫃的人走了六步，大衛就獻上公牛和肥犢為祭。</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳記上 2:18; 出埃及記 15:20; 詩篇 150:4"> 大衛穿著細麻布的以弗得，在耶和華面前盡情跳舞。</span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 68:24–27; 歷代志上 15:28; 歷代志上 15:25"> 大衛和全體以色列人在歡呼聲和號角聲中把耶和華的約櫃迎進大衛城。</span>
<span className="v" id="v16" data-v="16" data-xref="哥林多前書 2:14; 歷代志上 15:29; 詩篇 69:7"> 耶和華的約櫃進大衛城的時候，掃羅的女兒米甲從窗戶往外觀看，見大衛在耶和華面前又跳又舞，心裡就輕視他。</span>
<span className="v" id="v17" data-v="17" data-xref="歷代志上 15:1; 歷代志下 1:4; 列王紀上 8:5"> 眾人把耶和華的約櫃抬進去，安放在大衛所搭的帳幕裡。大衛在耶和華面前獻上燔祭和平安祭，</span>
<span className="v" id="v18" data-v="18" data-xref="列王紀上 8:55; 歷代志上 16:2; 創世記 14:19"> 然後奉萬軍之耶和華的名給民眾祝福，</span>
<span className="v" id="v19" data-v="19" data-xref="尼希米記 8:10; 歷代志下 35:7–8; 歷代志上 16:3"> 還分給所有以色列人，不論男女，每人一個餅、一塊肉和一個葡萄餅。眾人就各自回家去了。</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳記下 6:16; 撒母耳記下 6:14; 士師記 9:4"> 大衛回到家為自己的家人祝福，米甲出來迎接他，說：「今天以色列王好光彩呀！居然像個粗俗之人，在臣僕和婢女面前露體！」</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行傳 13:22; 詩篇 89:19–20; 撒母耳記上 13:14"> 大衛對她說：「我是在耶和華面前跳舞。祂不用你父親和你父親家裡的人，而是選立我來治理祂的以色列子民，所以我要在祂面前歡慶。</span>
<span className="v" id="v22" data-v="22" data-xref="彼得前書 4:14; 希伯來書 12:2; 以賽亞書 51:7"> 我要讓自己更卑微，自視低賤，但你說的那些婢女會尊重我。」</span>
<span className="v" id="v23" data-v="23" data-xref="馬太福音 1:25; 以賽亞書 22:14; 以賽亞書 4:1"> 掃羅的女兒米甲終生都沒有生育。</span>

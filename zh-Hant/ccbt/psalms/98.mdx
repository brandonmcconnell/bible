## 頌揚上帝的拯救

<div className="bt">
<div className="hs">一首詩歌。</div>
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="出埃及記 15:6; 以賽亞書 52:10; 詩篇 33:3"> <span className="pl pl-1">你們要向耶和華唱新歌，</span><br /><span className="pl pl-1">因為祂的作為奇妙，</span><br /><span className="pl pl-1">祂以右手和聖潔的臂膀施行拯救。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="以賽亞書 52:10; 以賽亞書 62:2; 詩篇 22:31"> <span className="pl pl-1">耶和華顯明了祂的拯救之恩，</span><br /><span className="pl pl-1">向列邦彰顯了祂的公義。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 22:27; 使徒行傳 13:47; 申命記 4:31"> <span className="pl pl-1">祂沒有忘記以慈愛和信實對待以色列人，</span><br /><span className="pl pl-1">普天下都看見我們上帝的救恩。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="以賽亞書 44:23; 詩篇 100:1; 詩篇 66:1"> <span className="pl pl-1">普世要向耶和華歡呼，</span><br /><span className="pl pl-1">歡歡喜喜地高聲頌揚。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="以賽亞書 51:3; 啟示錄 5:8; 詩篇 33:2"> <span className="pl pl-1">要彈奏豎琴歌頌耶和華，</span><br /><span className="pl pl-1">伴著琴聲唱詩歌頌祂。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 81:2–4; 啟示錄 19:16; 歷代志下 15:14"> <span className="pl pl-1">要伴隨著號聲和角聲在大君王耶和華面前歡呼。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="以賽亞書 49:13; 詩篇 24:1; 詩篇 96:11–1"> <span className="pl pl-1">大海和海中的一切要頌揚，</span><br /><span className="pl pl-1">大地和地上的一切要歡呼。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="以賽亞書 55:12; 詩篇 89:12; 詩篇 65:12–13"> <span className="pl pl-1">江河要鼓掌，</span><br /><span className="pl pl-1">群山要在耶和華面前齊聲歡唱，</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 96:13; 詩篇 96:10; 使徒行傳 17:31"> <span className="pl pl-1">因為祂要來審判大地，</span><br /><span className="pl pl-1">要公義地審判世界，</span><br /><span className="pl pl-1">公正地審判萬民。</span></span>

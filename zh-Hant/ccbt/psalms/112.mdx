## 敬畏上帝者必蒙福

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="詩篇 128:1; 路加福音 1:50; 以賽亞書 50:10"> <span className="pl pl-1">你們要讚美耶和華！</span><br /><span className="pl pl-1">敬畏耶和華、熱愛祂命令的人有福了！</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="創世記 17:7; 箴言 20:7; 詩篇 37:26"> <span className="pl pl-1">他的子孫在世上必興盛，</span><br /><span className="pl pl-1">正直人的後代必蒙福。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="箴言 15:6; 箴言 3:16; 馬太福音 6:33"> <span className="pl pl-1">他的家財豐厚，</span><br /><span className="pl pl-1">他的公義永遠長存。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="約伯記 11:17; 詩篇 97:11; 歌羅西書 3:12–13"> <span className="pl pl-1">黑暗中必有光照亮正直人，</span><br /><span className="pl pl-1">照亮有恩慈、好憐憫、行公義的人。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 37:21; 箴言 2:20; 以弗所書 5:15"> <span className="pl pl-1">慷慨借貸，</span><br /><span className="pl pl-1">行事公正的人必亨通。</span><br /></span>

<span className="v" id="v7" data-v="7" data-xref="以賽亞書 26:3–4; 箴言 1:33; 詩篇 57:7"> <span className="pl pl-1">他不怕惡訊，</span><br /><span className="pl pl-1">他一心信靠耶和華。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 59:10; 詩篇 31:24; 詩篇 118:7"> <span className="pl pl-1">他心裡篤定，毫不害怕，</span><br /><span className="pl pl-1">他終必戰勝仇敵。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 75:10; 希伯來書 13:16; 雅各書 2:15–16"> <span className="pl pl-1">他慷慨施捨，賙濟窮人；</span><br /><span className="pl pl-1">他的公義永遠長存；</span><br /><span className="pl pl-1">他的角被高舉，得享尊榮。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 58:7–8; 箴言 11:7; 箴言 10:28"> <span className="pl pl-1">惡人見狀惱怒不已，</span><br /><span className="pl pl-1">他咬牙切齒地死去。</span><br /><span className="pl pl-1">惡人的盼望必破滅。</span></span>

## 求上帝擊退仇敵

<div className="bt">
<div className="hs">上聖殿朝聖之詩。</div>
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="詩篇 124:1; 耶利米書 2:2; 何西阿書 11:1"> <span className="pl pl-1">以色列要說：</span><br /><span className="pl pl-1">「我從小就深受仇敵的迫害，</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="詩篇 34:19; 馬太福音 16:18; 哥林多後書 4:8–9"> <span className="pl pl-1">我從小就深受仇敵的迫害，</span><br /><span className="pl pl-1">但他們沒能勝過我。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="以賽亞書 51:23; 詩篇 141:7"> <span className="pl pl-1">他們如同農夫在我背上耕田，</span><br /><span className="pl pl-1">耕出長長的犁溝。」</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="詩篇 119:137; 耶利米哀歌 3:22; 尼希米記 9:33"> <span className="pl pl-1">耶和華是公義的，</span><br /><span className="pl pl-1">祂砍斷了惡人的綁索。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 71:13; 以賽亞書 37:35; 以斯帖記 6:13"> <span className="pl pl-1">願所有憎惡錫安的人抱愧而逃。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 37:2; 詩篇 92:7; 列王紀下 19:26"> <span className="pl pl-1">願他們像房頂的草，</span><br /><span className="pl pl-1">沒長起來就已枯萎，</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="加拉太書 6:8; 以賽亞書 17:10–11; 詩篇 126:6"> <span className="pl pl-1">割下來不滿一把，</span><br /><span className="pl pl-1">紮起來不足一捆。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="路得記 2:4; 詩篇 118:26"> <span className="pl pl-1">沒有一個路過的人說：</span><br /><span className="pl pl-1">「願耶和華賜福給你們！</span><br /><span className="pl pl-1">我們奉耶和華的名祝福你們。」</span></span>

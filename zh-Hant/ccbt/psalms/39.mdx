## 受苦者的呼求

<div className="bt">
<div className="hs">大衛的詩，交給樂長耶杜頓。</div>
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="箴言 21:23; 詩篇 141:3; 雅各書 1:26"> <span className="pl pl-1">我說：「我要謹言慎行，</span><br /><span className="pl pl-1">免犯口舌之罪。</span><br /><span className="pl pl-1">只要身邊有惡人，</span><br /><span className="pl pl-1">我就用嚼環勒住自己的口。」</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="使徒行傳 4:20; 詩篇 38:13–14; 約伯記 32:19–20"> <span className="pl pl-1">然而，我默不作聲，</span><br /><span className="pl pl-1">連好話也不出口時，</span><br /><span className="pl pl-1">內心就更加痛苦。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="路加福音 24:32; 耶利米書 20:9; 以西結書 3:14"> <span className="pl pl-1">我心如火燒，越沉思越煩躁，</span><br /><span className="pl pl-1">便開口呼求：</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="詩篇 90:12; 詩篇 103:14; 約伯記 14:13"> <span className="pl pl-1">「耶和華啊，求你讓我知道我人生的終點和壽數，</span><br /><span className="pl pl-1">明白人生何其短暫。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 90:9–10; 詩篇 144:4; 詩篇 89:47"> <span className="pl pl-1">你使我的生命轉瞬即逝，</span><br /><span className="pl pl-1">我的歲月在你眼中不到片刻。</span><br /><span className="pl pl-1">人的生命不過是一絲氣息，（細拉）</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 12:20–21; 雅各書 4:14; 傳道書 2:26"> <span className="pl pl-1">人生不過是幻影，</span><br /><span className="pl pl-1">勞碌奔波卻一場空，</span><br /><span className="pl pl-1">積蓄財富卻不知誰來享用。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="羅馬書 15:13; 詩篇 38:15; 詩篇 119:81"> <span className="pl pl-1">主啊，如今我等候什麼呢？</span><br /><span className="pl pl-1">你是我的盼望。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 44:13; 詩篇 65:3; 約珥書 2:17"> <span className="pl pl-1">求你救我脫離一切過犯，</span><br /><span className="pl pl-1">不要讓愚昧人嘲笑我。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="約伯記 2:10; 撒母耳記下 16:10; 利未記 10:3"> <span className="pl pl-1">我默然不語，一言不發，</span><br /><span className="pl pl-1">因為我受的責罰是出於你。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="約伯記 9:34; 約伯記 13:21; 詩篇 25:16–17"> <span className="pl pl-1">求你不要再懲罰我，</span><br /><span className="pl pl-1">你的責打使我幾乎喪命。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="約伯記 13:28; 哥林多前書 11:30–32; 以賽亞書 50:9"> <span className="pl pl-1">因為人犯罪，你責罰管教他們，</span><br /><span className="pl pl-1">如同蛀蟲吞噬他們所愛的。</span><br /><span className="pl pl-1">世人不過是一絲氣息。（細拉）</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="彼得前書 2:11; 希伯來書 11:13; 列王紀下 20:5"> <span className="pl pl-1">「耶和華啊，</span><br /><span className="pl pl-1">求你垂聽我的禱告，</span><br /><span className="pl pl-1">傾聽我的呼求，</span><br /><span className="pl pl-1">別對我的眼淚無動於衷。</span><br /><span className="pl pl-1">因為我在你面前只是客旅，</span><br /><span className="pl pl-1">是寄居的，</span><br /><span className="pl pl-1">正如我的祖先。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="約伯記 10:20–21; 約伯記 14:10–12; 約伯記 14:5–6"> <span className="pl pl-1">求你寬恕我，</span><br /><span className="pl pl-1">好讓我在離世之前能重展笑容。」</span></span>
</div>

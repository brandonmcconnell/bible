## 信靠之福

<div className="bt">
<div className="hs">大衛的詩。</div>
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="以賽亞書 26:3–4; 詩篇 56:1; 詩篇 31:23"> <span className="pl pl-1">上帝啊！我投靠你，</span><br /><span className="pl pl-1">求你保護我。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="詩篇 73:25; 詩篇 31:14; 詩篇 89:26"> <span className="pl pl-1">我對耶和華說：「你是我的主，</span><br /><span className="pl pl-1">我的福祉都從你而來。」</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="箴言 12:26; 希伯來書 6:10; 箴言 13:20"> <span className="pl pl-1">世上的聖民極其尊貴，</span><br /><span className="pl pl-1">是我所喜愛的。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="出埃及記 23:13; 約書亞記 23:7; 詩篇 32:10"> <span className="pl pl-1">追隨其他神明的人，其愁苦必有增無減。</span><br /><span className="pl pl-1">我必不向他們的假神澆奠血祭，</span><br /><span className="pl pl-1">口中也不提假神的名號。</span><br /></span>

<span className="v" id="v6" data-v="6" data-xref="耶利米書 3:19; 以弗所書 1:18; 詩篇 21:1–3"> <span className="pl pl-1">你用準繩量給我佳美之地，</span><br /><span className="pl pl-1">我的產業何其美！</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 73:24; 以賽亞書 50:4; 詩篇 77:6"> <span className="pl pl-1">我要稱頌那訓導我的耶和華，</span><br /><span className="pl pl-1">我的良心也在夜間提醒我。</span><br /></span>

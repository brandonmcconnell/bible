## 義人和惡人的結局

<div className="bt">
<div className="hs">大衛的詩。</div>
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="詩篇 37:7; 箴言 23:17; 箴言 24:19"> <span className="pl pl-1">不要因為惡人而煩躁，</span><br /><span className="pl pl-1">也不要羡慕不義之人，</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="詩篇 92:7; 詩篇 90:5–6; 雅各書 1:10–11"> <span className="pl pl-1">因為他們如瞬息枯萎的草芥，</span><br /><span className="pl pl-1">又如轉眼消逝的青草。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v3" data-v="3" data-xref="耶利米書 17:7–8; 馬太福音 6:31–33; 詩篇 62:8"> <span className="pl pl-1">要信靠耶和華，要行善，</span><br /><span className="pl pl-1">要在這片土地上安然度日。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="約翰福音 15:7; 詩篇 145:19; 約翰福音 15:16"> <span className="pl pl-1">要以耶和華為樂，</span><br /><span className="pl pl-1">祂必成全你的心願。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="箴言 16:3; 彼得前書 5:7; 腓立比書 4:6–7"> <span className="pl pl-1">要把你的路交托給耶和華，</span><br /><span className="pl pl-1">信靠祂，祂必幫助你。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="以賽亞書 54:17; 約伯記 11:17; 以賽亞書 58:8"> <span className="pl pl-1">祂使你的公義如晨光照耀，</span><br /><span className="pl pl-1">使你的仁義如日中天。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="雅各書 5:7–11; 詩篇 27:14; 詩篇 62:5"> <span className="pl pl-1">要在耶和華面前安靜，</span><br /><span className="pl pl-1">耐心等候祂，</span><br /><span className="pl pl-1">不要因惡人道路通達、陰謀得逞而煩躁。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="箴言 14:29; 箴言 16:32; 雅各書 1:19–20"> <span className="pl pl-1">你要抑制怒氣，除掉憤怒；</span><br /><span className="pl pl-1">不要煩躁不安，</span><br /><span className="pl pl-1">那會導致你作惡。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="以賽亞書 60:21; 詩篇 25:13; 詩篇 37:29"> <span className="pl pl-1">因為作惡的必被消滅，</span><br /><span className="pl pl-1">但等候耶和華的必承受土地。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="約伯記 24:24; 詩篇 103:16; 詩篇 37:35–36"> <span className="pl pl-1">再過片刻，惡人必不復存在，</span><br /><span className="pl pl-1">雖尋遍其住處，也不見蹤影。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="馬太福音 5:5; 加拉太書 5:22–23; 以賽亞書 26:3"> <span className="pl pl-1">但謙卑人必承受土地，</span><br /><span className="pl pl-1">得享太平昌盛。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="彌迦書 2:1; 詩篇 35:16; 詩篇 31:13"> <span className="pl pl-1">惡人謀害義人，</span><br /><span className="pl pl-1">對他們咬牙切齒。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 2:4; 箴言 1:26; 撒母耳記上 26:10"> <span className="pl pl-1">但主嗤笑邪惡人，</span><br /><span className="pl pl-1">因為祂知道他們末日將臨。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="箴言 29:27; 詩篇 11:2; 約翰一書 3:12"> <span className="pl pl-1">惡人拔劍張弓要消滅窮苦人，</span><br /><span className="pl pl-1">殺戮正直人，</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 7:14–15; 詩篇 35:8; 耶利米書 51:56"> <span className="pl pl-1">但他們的劍必刺穿自己的心，</span><br /><span className="pl pl-1">他們的弓必被折斷。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v16" data-v="16" data-xref="箴言 16:8; 箴言 15:16–17; 提摩太前書 6:6"> <span className="pl pl-1">義人清貧一生強過惡人財富如山。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="以賽亞書 41:10; 詩篇 63:8; 詩篇 145:14"> <span className="pl pl-1">因為惡人的勢力終必瓦解，</span><br /><span className="pl pl-1">耶和華必扶持義人。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 1:6; 羅馬書 6:23; 詩篇 103:17"> <span className="pl pl-1">耶和華看顧純全者的時日，</span><br /><span className="pl pl-1">他們的產業永遠長存。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="詩篇 33:19; 箴言 10:3; 約伯記 5:20–22"> <span className="pl pl-1">他們在災難中不致蒙羞，</span><br /><span className="pl pl-1">在饑荒時仍得飽足。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 68:2; 詩篇 102:3; 路加福音 13:3"> <span className="pl pl-1">但惡人必滅亡，</span><br /><span className="pl pl-1">耶和華的仇敵必像野地的花一樣凋零，</span><br /><span className="pl pl-1">消逝如煙。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v21" data-v="21" data-xref="希伯來書 13:16; 詩篇 112:5; 箴言 22:7"> <span className="pl pl-1">惡人借債不還，</span><br /><span className="pl pl-1">義人慷慨給予。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="箴言 3:33; 哥林多前書 16:22; 加拉太書 3:13"> <span className="pl pl-1">蒙耶和華賜福的人必承受土地，</span><br /><span className="pl pl-1">被耶和華咒詛的人必遭剷除。</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="箴言 16:9; 詩篇 119:133; 箴言 4:26"> <span className="pl pl-1">耶和華鞏固義人的腳步，</span><br /><span className="pl pl-1">喜悅他們所走的路。</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="箴言 24:16; 詩篇 145:14; 詩篇 94:18"> <span className="pl pl-1">他們即使失腳，也不會跌倒，</span><br /><span className="pl pl-1">因為耶和華的手扶持他們。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v25" data-v="25" data-xref="希伯來書 13:5; 詩篇 37:28; 詩篇 112:2"> <span className="pl pl-1">從幼年到老年，</span><br /><span className="pl pl-1">我從未見過義人遭棄，</span><br /><span className="pl pl-1">也未見其後人討飯。</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="詩篇 112:5; 馬太福音 5:7; 詩篇 37:21"> <span className="pl pl-1">他們總是樂善好施，</span><br /><span className="pl pl-1">他們的後代都蒙祝福。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v27" data-v="27" data-xref="詩篇 34:14; 箴言 16:6; 約翰一書 2:16–17"> <span className="pl pl-1">你要離惡行善，</span><br /><span className="pl pl-1">就必永遠安居。</span><br /></span>
<span className="v" id="v28" data-v="28" data-xref="詩篇 11:7; 箴言 2:22; 詩篇 21:10"> <span className="pl pl-1">因為耶和華喜愛公正，</span><br /><span className="pl pl-1">不丟棄信靠祂的人，</span><br /><span className="pl pl-1">永遠保護他們。</span><br /><span className="pl pl-1">惡人的後代必被剷除。</span><br /></span>

</div>
<div className="bp poetry">
<span className="v" id="v30" data-v="30" data-xref="歌羅西書 4:6; 箴言 25:11–13; 以弗所書 4:29"> <span className="pl pl-1">義人口出智慧，訴說正義，</span><br /></span>
<span className="v" id="v31" data-v="31" data-xref="詩篇 40:8; 申命記 6:6; 以賽亞書 51:7"> <span className="pl pl-1">銘記上帝的律法，</span><br /><span className="pl pl-1">從不失腳。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v32" data-v="32" data-xref="路加福音 19:47–48; 詩篇 10:8–10; 詩篇 37:12"> <span className="pl pl-1">惡人窺探義人，</span><br /><span className="pl pl-1">伺機謀害。</span><br /></span>
<span className="v" id="v33" data-v="33" data-xref="詩篇 109:31; 彼得後書 2:9; 羅馬書 8:1"> <span className="pl pl-1">但耶和華不會讓他們落在惡人手中，</span><br /><span className="pl pl-1">也不會讓義人在審判時被定罪。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v34" data-v="34" data-xref="詩篇 27:14; 詩篇 37:9; 箴言 20:22"> <span className="pl pl-1">要等候耶和華，</span><br /><span className="pl pl-1">堅守祂的道，</span><br /><span className="pl pl-1">祂必賜你土地，使你有尊榮。</span><br /><span className="pl pl-1">你必親眼看見惡人被剷除。</span><br /></span>

<span className="v" id="v36" data-v="36" data-xref="詩篇 37:10; 使徒行傳 12:22–23; 以賽亞書 10:16–19"> <span className="pl pl-1">再一看，他已經消失得無影無蹤，</span><br /><span className="pl pl-1">我尋找他，卻找不到。</span><br /></span>

<span className="v" id="v38" data-v="38" data-xref="箴言 14:32; 詩篇 52:5; 詩篇 1:4–6"> <span className="pl pl-1">罪人必同遭毀滅，</span><br /><span className="pl pl-1">惡人必沒有前途。</span><br /></span>
<span className="v" id="v39" data-v="39" data-xref="詩篇 9:9; 詩篇 91:15; 以賽亞書 12:2"> <span className="pl pl-1">耶和華拯救義人，</span><br /><span className="pl pl-1">患難時作他們的庇護所。</span><br /></span>

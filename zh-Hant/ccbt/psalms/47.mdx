## 至高的主宰

<div className="bt">
<div className="hs">可拉後裔的詩，交給樂長。</div>
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="詩篇 98:4; 耶利米書 31:7; 詩篇 106:47"> <span className="pl pl-1">萬民啊，你們要鼓掌，</span><br /><span className="pl pl-1">向上帝高聲歡呼！</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="瑪拉基書 1:14; 詩篇 99:3; 詩篇 95:3"> <span className="pl pl-1">因為至高者耶和華當受敬畏，</span><br /><span className="pl pl-1">祂是掌管天下的大君王。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 18:47; 哥林多前書 15:25; 詩篇 81:14"> <span className="pl pl-1">祂使列國降服於我們，</span><br /><span className="pl pl-1">讓列邦伏在我們腳下。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="彼得前書 1:4; 阿摩司書 6:8; 那鴻書 2:2"> <span className="pl pl-1">祂為我們選定產業，</span><br /><span className="pl pl-1">就是祂所愛的雅各引以為榮的產業。（細拉）</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="詩篇 68:33; 詩篇 24:7–10; 民數記 23:21"> <span className="pl pl-1">上帝在歡呼聲中登上寶座；</span><br /><span className="pl pl-1">耶和華在角聲中登上寶座。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="馬太福音 25:34; 詩篇 68:4; 以賽亞書 33:22"> <span className="pl pl-1">要歌頌，歌頌上帝！</span><br /><span className="pl pl-1">要歌頌，歌頌我們的君王！</span><br /></span>

<span className="v" id="v8" data-v="8" data-xref="歷代志上 16:31; 啟示錄 19:6; 詩篇 99:1"> <span className="pl pl-1">上帝坐在聖潔的寶座上治理列國。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 89:18; 創世記 49:10; 詩篇 72:7–9"> <span className="pl pl-1">列邦的首領聚集在一起，</span><br /><span className="pl pl-1">要做亞伯拉罕之上帝的子民，</span><br /><span className="pl pl-1">因為上帝主宰世上的君王，</span><br /><span className="pl pl-1">祂至高無上。</span></span>

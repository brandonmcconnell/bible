## 求上帝賜福聖殿

<div className="bt">
<div className="hs">上聖殿朝聖之詩。</div>
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="詩篇 120:1; 詩篇 129:1; 耶利米哀歌 5:1"> <span className="pl pl-1">耶和華啊，</span><br /><span className="pl pl-1">求你顧念大衛和他所受的一切苦難。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="創世記 49:24; 詩篇 65:1; 詩篇 119:106"> <span className="pl pl-1">他曾向耶和華起誓，</span><br /><span className="pl pl-1">向雅各的大能者許願說：</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="哈該書 1:4; 傳道書 9:10; 馬太福音 6:33"> <span className="pl pl-1">「我不為耶和華找到居所，</span><br /><span className="pl pl-1">不為雅各的大能者找到安居之處，</span><br /><span className="pl pl-1">必不進家門，</span><br /><span className="pl pl-1">不沾床，不睡覺，不打盹。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="撒母耳記上 17:12; 撒母耳記上 7:1; 彌迦書 5:2"> <span className="pl pl-1">我們在以法他聽到約櫃的消息，</span><br /><span className="pl pl-1">在雅珥的田野找到了它。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 99:5; 詩篇 5:7; 耶利米哀歌 2:1"> <span className="pl pl-1">讓我們進入耶和華的居所，</span><br /><span className="pl pl-1">在祂腳凳前俯伏敬拜。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="歷代志下 6:41–42; 民數記 10:35–36; 詩篇 68:1"> <span className="pl pl-1">耶和華啊，</span><br /><span className="pl pl-1">求你起來和你大能的約櫃一同進入安息之所。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="約伯記 29:14; 啟示錄 19:8; 詩篇 104:1"> <span className="pl pl-1">願你的祭司身披公義，</span><br /><span className="pl pl-1">願你忠心的子民歡唱。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 84:9; 歷代志下 6:42; 列王紀上 11:34"> <span className="pl pl-1">為了你僕人大衛的緣故，</span><br /><span className="pl pl-1">求你不要棄絕你所膏立的人。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v11" data-v="11" data-xref="撒母耳記下 7:12; 使徒行傳 2:30; 詩篇 89:3–4"> <span className="pl pl-1">耶和華曾向大衛起了永不廢棄的誓說：</span><br /><span className="pl pl-1">「我必使你的後代繼承你的王位。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 1:32–33; 使徒行傳 2:30; 以賽亞書 59:21"> <span className="pl pl-1">你的後代若守我的約，</span><br /><span className="pl pl-1">遵行我教導他們的法度，</span><br /><span className="pl pl-1">他們的子孫必永遠坐在你的寶座上。」</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 78:68–69; 希伯來書 12:22; 詩篇 87:2"> <span className="pl pl-1">因為耶和華已經揀選了錫安，</span><br /><span className="pl pl-1">願意將錫安作為祂的居所。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="詩篇 132:8; 列王紀上 8:13; 詩篇 76:2"> <span className="pl pl-1">祂說：「這是我永遠的安息之所；</span><br /><span className="pl pl-1">我要住在這裡，</span><br /><span className="pl pl-1">因為我喜歡這地方。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 147:14; 利未記 26:4–5; 箴言 3:9–10"> <span className="pl pl-1">我要賜福，使她糧食充足，</span><br /><span className="pl pl-1">使她裡面的窮人飲食無憂。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="歷代志下 6:41; 詩篇 132:9; 約翰福音 16:24"> <span className="pl pl-1">我要用救恩作她祭司的衣裳，</span><br /><span className="pl pl-1">她忠心的子民必歡唱。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="路加福音 1:69; 以西結書 29:21; 歷代志下 21:7"> <span className="pl pl-1">我必使大衛的角在那裡興起，</span><br /><span className="pl pl-1">我必為我所膏立的預備明燈。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 35:26; 約伯記 8:22; 詩篇 21:8–9"> <span className="pl pl-1">我必使他的仇敵抱愧蒙羞，</span><br /><span className="pl pl-1">但他頭上的王冠必光芒四射。」</span></span>

## 上帝的慈愛

<div className="bt">
<div className="hs">大衛的詩。</div>
<div className="bp poetry">

<span className="v" id="v2" data-v="2" data-xref="以賽亞書 63:7; 詩篇 116:12; 詩篇 105:5"> <span className="pl pl-1">我的心啊，要稱頌耶和華，</span><br /><span className="pl pl-1">不要忘記祂的一切恩惠。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 15:26; 以賽亞書 53:5; 耶利米書 17:14"> <span className="pl pl-1">祂赦免你一切的罪惡，</span><br /><span className="pl pl-1">醫治你一切的疾病。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="詩篇 56:13; 詩篇 71:23; 詩篇 103:12"> <span className="pl pl-1">祂救贖你的生命脫離死亡，</span><br /><span className="pl pl-1">以慈愛和憐憫環繞你。</span><br /></span>

</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="詩篇 9:9; 詩篇 12:5; 詩篇 72:12"> <span className="pl pl-1">耶和華為一切受欺壓的人伸張正義，主持公道。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="出埃及記 33:13; 詩篇 147:19; 詩篇 78:11"> <span className="pl pl-1">祂讓摩西明白自己的旨意，</span><br /><span className="pl pl-1">向以色列人彰顯自己的作為。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 86:15; 約珥書 2:13; 出埃及記 34:6–7"> <span className="pl pl-1">耶和華好憐憫，有恩典，</span><br /><span className="pl pl-1">不輕易發怒，充滿慈愛。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="以賽亞書 57:16; 詩篇 30:5; 彌迦書 7:18–19"> <span className="pl pl-1">祂不永久責備人，</span><br /><span className="pl pl-1">也不永遠懷怒。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="以斯拉記 9:13; 耶利米哀歌 3:22; 尼希米記 9:31"> <span className="pl pl-1">祂沒有按我們的罪惡對待我們，</span><br /><span className="pl pl-1">也沒有照我們的罪過懲罰我們。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 57:10; 路加福音 1:50; 詩篇 36:5"> <span className="pl pl-1">因為天離地有多高，</span><br /><span className="pl pl-1">祂對敬畏祂之人的愛也多大！</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="以賽亞書 43:25; 約翰一書 1:7; 彌迦書 7:18"> <span className="pl pl-1">東離西有多遠，</span><br /><span className="pl pl-1">祂叫我們的過犯離我們也多遠！</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 11:11–12; 希伯來書 12:5–11; 路加福音 15:21–22"> <span className="pl pl-1">耶和華憐愛敬畏祂的人，</span><br /><span className="pl pl-1">如同慈父憐愛自己的兒女。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="傳道書 12:7; 約伯記 10:9; 詩篇 78:38–39"> <span className="pl pl-1">因為祂知道我們的本源，</span><br /><span className="pl pl-1">顧念我們不過是塵土。</span></span>
</div>
<div className="bp poetry">

</div>

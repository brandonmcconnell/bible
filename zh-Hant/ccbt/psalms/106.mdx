## 上帝恩待祂的子民

<div className="bt">
<div className="bp poetry">

<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="出埃及記 9:16; 以西結書 20:9; 以西結書 20:14"> <span className="pl pl-1">但祂為了自己的名拯救了他們，</span><br /><span className="pl pl-1">以彰顯祂的大能。</span><br /></span>

<span className="v" id="v11" data-v="11" data-xref="出埃及記 15:5; 詩篇 78:53; 出埃及記 14:13"> <span className="pl pl-1">海水淹沒了敵軍，</span><br /><span className="pl pl-1">沒有一人生還。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="出埃及記 14:31–21; 路加福音 8:13; 約翰福音 8:30–31"> <span className="pl pl-1">那時他們才相信祂的話，</span><br /><span className="pl pl-1">歌唱讚美祂。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 78:11; 出埃及記 15:24; 以賽亞書 48:17–18"> <span className="pl pl-1">然而，他們很快忘了祂的作為，</span><br /><span className="pl pl-1">不願等候祂的引導。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="哥林多前書 10:9; 民數記 11:4; 哥林多前書 10:6"> <span className="pl pl-1">他們在曠野大起貪念，</span><br /><span className="pl pl-1">在荒野試探上帝。</span><br /></span>

<span className="v" id="v16" data-v="16" data-xref="民數記 16:1–50; 利未記 21:10–12; 利未記 21:6–8"> <span className="pl pl-1">他們還在營中嫉妒摩西和耶和華的聖僕亞倫。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="申命記 11:6; 民數記 16:29–33; 民數記 26:10"> <span className="pl pl-1">大地裂開吞沒了大坍，</span><br /><span className="pl pl-1">埋葬了亞比蘭一夥人。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="希伯來書 12:29; 民數記 16:35–40; 民數記 16:46"> <span className="pl pl-1">火在他們的黨羽中燒起，</span><br /><span className="pl pl-1">燒滅了這些惡人。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="出埃及記 32:4–8; 出埃及記 32:35; 尼希米記 9:18"> <span className="pl pl-1">他們在何烈山鑄造牛犢，祭拜金屬偶像，</span><br /></span>

<span className="v" id="v24" data-v="24" data-xref="申命記 1:32; 以西結書 20:6; 希伯來書 3:18–19"> <span className="pl pl-1">他們藐視那佳美之地，</span><br /><span className="pl pl-1">不相信祂的應許。</span><br /></span>

## 上帝是至高的君王

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="歷代志上 16:23–33; 詩篇 98:1; 詩篇 149:1"> <span className="pl pl-1">你們要向耶和華唱新歌，</span><br /><span className="pl pl-1">普世都要歌頌耶和華。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="馬可福音 16:15; 詩篇 71:15; 詩篇 103:1–2"> <span className="pl pl-1">要歌頌耶和華，頌讚祂的名，</span><br /><span className="pl pl-1">天天傳揚祂的拯救之恩。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 22:27; 但以理書 4:1–3; 路加福音 24:47"> <span className="pl pl-1">要在列國述說祂的榮耀，</span><br /><span className="pl pl-1">在萬民中述說祂的奇妙作為。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="詩篇 145:3; 詩篇 18:3; 啟示錄 15:4"> <span className="pl pl-1">因為耶和華無比偉大，</span><br /><span className="pl pl-1">當受至高的頌揚；</span><br /><span className="pl pl-1">祂超越一切神明，當受敬畏。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 115:15; 以賽亞書 42:5; 耶利米書 10:11–12"> <span className="pl pl-1">列邦的神明都是假的，</span><br /><span className="pl pl-1">唯獨耶和華創造了諸天。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 63:2–3; 詩篇 104:1; 彼得後書 1:16–17"> <span className="pl pl-1">祂帶著尊貴和威嚴，</span><br /><span className="pl pl-1">祂的聖所充滿能力和榮美。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="啟示錄 19:1; 馬太福音 6:13; 歷代志上 29:11–13"> <span className="pl pl-1">萬族萬民啊，</span><br /><span className="pl pl-1">要把榮耀和能力歸給耶和華，</span><br /><span className="pl pl-1">歸給耶和華！</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 100:4; 羅馬書 12:1; 出埃及記 34:5–9"> <span className="pl pl-1">要將耶和華之名當得的榮耀歸給祂，</span><br /><span className="pl pl-1">要帶著祭物到祂的院宇。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 29:2; 詩篇 114:7; 詩篇 110:3"> <span className="pl pl-1">當敬拜聖潔榮耀的耶和華，</span><br /><span className="pl pl-1">大地要在祂面前顫抖。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 93:1; 詩篇 67:4; 詩篇 9:8"> <span className="pl pl-1">要告訴列國：</span><br /><span className="pl pl-1">「耶和華掌權，</span><br /><span className="pl pl-1">世界堅立不搖，</span><br /><span className="pl pl-1">祂必公正地審判萬民。」</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 69:34; 以賽亞書 49:13; 詩篇 98:7–9"> <span className="pl pl-1">願天歡喜，願地快樂，</span><br /><span className="pl pl-1">願海洋和其中的一切都歡呼。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="以賽亞書 55:12–13; 以賽亞書 35:1; 以賽亞書 42:10–11"> <span className="pl pl-1">願田野和其中的萬物都歡騰，</span><br /><span className="pl pl-1">願林中的樹木都在耶和華面前歡唱。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="啟示錄 19:11; 提摩太後書 4:8; 以賽亞書 25:8–9"> <span className="pl pl-1">因為祂來了，祂來審判天下，</span><br /><span className="pl pl-1">祂要按公義審判世界，</span><br /><span className="pl pl-1">憑祂的信實審判萬民。</span></span>

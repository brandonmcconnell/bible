<span className="v" id="v6" data-v="6" data-xref="列王紀上 6:18; 列王紀上 6:29; 列王紀上 6:35"> <span className="pl pl-1">他們用斧頭、錘子把雕刻的牆板都搗毀了。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="列王紀下 25:9; 詩篇 89:39; 以西結書 24:21"> <span className="pl pl-1">他們縱火焚燒你的聖所，</span><br /><span className="pl pl-1">把它夷為平地，</span><br /><span className="pl pl-1">褻瀆了你的居所。</span><br /></span>

<span className="v" id="v15" data-v="15" data-xref="民數記 20:11; 以賽亞書 48:21; 詩篇 105:41"> <span className="pl pl-1">你曾開闢泉源和溪流，</span><br /><span className="pl pl-1">也曾使滔滔河水枯乾。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="詩篇 136:7–9; 馬太福音 5:45; 詩篇 104:19"> <span className="pl pl-1">白晝和黑夜都屬於你，</span><br /><span className="pl pl-1">你設立了日月。</span><br /></span>

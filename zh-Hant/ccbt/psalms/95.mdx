## 讚美上帝之歌

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="哥林多前書 10:4; 詩篇 81:1; 撒母耳記下 22:47"> <span className="pl pl-1">來吧，讓我們向耶和華歌唱，</span><br /><span className="pl pl-1">向拯救我們的磐石歡呼。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="詩篇 100:4; 以弗所書 5:19; 詩篇 105:2"> <span className="pl pl-1">讓我們懷著感恩的心來到祂面前，</span><br /><span className="pl pl-1">用詩歌頌揚祂。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 96:4; 耶利米書 10:6–7; 詩篇 145:3"> <span className="pl pl-1">因為耶和華是偉大的上帝，</span><br /><span className="pl pl-1">是眾神明之上的大君王。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="詩篇 135:6; 哈巴谷書 3:10; 哈巴谷書 3:6"> <span className="pl pl-1">祂掌管地的深處，</span><br /><span className="pl pl-1">祂擁有山的高峰。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="創世記 1:9–10; 詩篇 146:6; 約伯記 38:10–11"> <span className="pl pl-1">海洋屬於祂，是祂創造的，</span><br /><span className="pl pl-1">陸地也是祂造的。</span><br /></span>

<span className="v" id="v7" data-v="7" data-xref="希伯來書 4:7; 希伯來書 3:15; 啟示錄 3:20"> <span className="pl pl-1">因為祂是我們的上帝，</span><br /><span className="pl pl-1">我們是祂照管的子民，</span><br /><span className="pl pl-1">是祂牧放的羊群。</span><br /><span className="pl pl-1">但願你們今日聽從祂的聲音！</span><br /></span>

## 上帝和祂的子民

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="以賽亞書 12:4; 詩篇 145:11–12; 羅馬書 10:13"> <span className="pl pl-1">你們要稱謝耶和華，呼求祂的名，</span><br /><span className="pl pl-1">在列邦傳揚祂的作為。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="詩篇 119:27; 詩篇 98:5; 以賽亞書 12:5–6"> <span className="pl pl-1">要歌頌、讚美祂，</span><br /><span className="pl pl-1">述說祂一切奇妙的作為。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="耶利米哀歌 3:25; 加拉太書 6:14; 哥林多前書 1:29"> <span className="pl pl-1">要以祂的聖名為榮，</span><br /><span className="pl pl-1">願尋求耶和華的人心中快樂。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="詩篇 27:8; 西番雅書 2:2–3; 歷代志下 6:41"> <span className="pl pl-1">要尋求耶和華和祂的能力，</span><br /><span className="pl pl-1">時常來到祂面前。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 77:11; 詩篇 119:13; 申命記 32:7"> <span className="pl pl-1">祂僕人亞伯拉罕的後裔啊，</span><br /><span className="pl pl-1">祂所揀選的雅各的子孫啊，</span><br /><span className="pl pl-1">要記住祂所行的神蹟奇事和祂口中的判詞。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="以賽亞書 26:9; 申命記 26:17–18; 出埃及記 20:2"> <span className="pl pl-1">祂是我們的上帝耶和華，</span><br /><span className="pl pl-1">祂在普天下施行審判。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="申命記 7:9; 詩篇 106:45; 詩篇 111:5"> <span className="pl pl-1">祂永遠記得祂的約，</span><br /><span className="pl pl-1">歷經千代也不忘祂的應許，</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="創世記 17:2; 創世記 22:16–18; 創世記 26:3"> <span className="pl pl-1">就是祂與亞伯拉罕所立的約，</span><br /><span className="pl pl-1">向以撒所起的誓。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="創世記 17:7–8; 撒母耳記下 23:5; 創世記 28:13–15"> <span className="pl pl-1">祂將這約定為律例賜給雅各，</span><br /><span className="pl pl-1">定為永遠的約賜給以色列。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="創世記 13:15; 創世記 15:18; 詩篇 78:55"> <span className="pl pl-1">祂說：「我必把迦南賜給你，</span><br /><span className="pl pl-1">作為你的產業。」</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="創世記 34:30; 申命記 7:7; 希伯來書 11:9"> <span className="pl pl-1">那時他們人丁稀少，寥寥可數，</span><br /><span className="pl pl-1">在當地寄居。</span><br /></span>
<span className="v" id="v13" data-v="13"> <span className="pl pl-1">他們在異國他鄉流離飄零。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="創世記 35:5; 出埃及記 7:16–17; 創世記 26:14–33"> <span className="pl pl-1">耶和華不容人壓迫他們，</span><br /><span className="pl pl-1">還為他們的緣故責備君王，</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="撒迦利亞書 2:8; 創世記 26:11; 創世記 20:7"> <span className="pl pl-1">說：「不可加害我膏立的人，</span><br /><span className="pl pl-1">也不可傷害我的先知。」</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="以西結書 4:16; 創世記 41:54; 以賽亞書 3:1"> <span className="pl pl-1">祂命饑荒降在那裡，</span><br /><span className="pl pl-1">斷絕一切食物供應。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="使徒行傳 7:9; 創世記 37:36; 創世記 45:4–5"> <span className="pl pl-1">祂派一個人先去，</span><br /><span className="pl pl-1">這人就是被賣為奴隸的約瑟。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="使徒行傳 16:24; 創世記 39:20; 創世記 40:15"> <span className="pl pl-1">他被戴上腳鐐，套上枷鎖，</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="使徒行傳 7:10; 箴言 21:1; 創世記 40:20–21"> <span className="pl pl-1">直到後來他的預言應驗，</span><br /><span className="pl pl-1">耶和華的話試煉了他。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="創世記 41:14"> <span className="pl pl-1">埃及王派人釋放他，</span><br /><span className="pl pl-1">百姓的首領給他自由，</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="創世記 41:40–44; 創世記 45:8; 創世記 41:55"> <span className="pl pl-1">派他執掌朝政，</span><br /><span className="pl pl-1">管理國中的一切，</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="以賽亞書 19:11; 創世記 41:33; 創世記 41:38"> <span className="pl pl-1">有權柄管束王的大臣，</span><br /><span className="pl pl-1">將智慧傳授王的長老。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v23" data-v="23" data-xref="使徒行傳 7:11–15; 使徒行傳 13:17; 詩篇 78:51"> <span className="pl pl-1">以色列來到埃及，</span><br /><span className="pl pl-1">雅各寄居在含地。</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="創世記 46:3; 出埃及記 1:7–9; 使徒行傳 7:17"> <span className="pl pl-1">耶和華使祂的子民生養眾多，</span><br /><span className="pl pl-1">比他們的仇敵還要強盛。</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="使徒行傳 7:19; 創世記 15:13; 出埃及記 9:16"> <span className="pl pl-1">祂使仇敵轉念憎恨祂的子民，</span><br /><span className="pl pl-1">用詭計虐待祂的僕人。</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="出埃及記 3:10; 出埃及記 29:5–46; 出埃及記 28:12"> <span className="pl pl-1">祂派遣祂的僕人摩西和祂揀選的亞倫，</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="詩篇 78:43–51; 尼希米記 9:10–11; 詩篇 105:23"> <span className="pl pl-1">在埃及行神蹟，</span><br /><span className="pl pl-1">在含地行奇事。</span><br /></span>
<span className="v" id="v28" data-v="28" data-xref="詩篇 99:7; 約珥書 2:31; 約珥書 2:2"> <span className="pl pl-1">祂使黑暗降下籠罩那裡；</span><br /><span className="pl pl-1">他們沒有違背祂的話。</span><br /></span>
<span className="v" id="v29" data-v="29" data-xref="出埃及記 7:20–21; 詩篇 78:44; 以賽亞書 50:2"> <span className="pl pl-1">祂使埃及的水變成血，</span><br /><span className="pl pl-1">魚都死去；</span><br /></span>
<span className="v" id="v30" data-v="30" data-xref="啟示錄 16:13–14; 出埃及記 8:3–14; 詩篇 78:45"> <span className="pl pl-1">又使國中到處是青蛙，</span><br /><span className="pl pl-1">王宮禁院也不能倖免。</span><br /></span>
<span className="v" id="v31" data-v="31" data-xref="出埃及記 8:16–18; 出埃及記 8:21–24; 以賽亞書 7:18"> <span className="pl pl-1">祂一發命令，</span><br /><span className="pl pl-1">蒼蠅蜂擁而至，蝨子遍滿全境。</span><br /></span>
<span className="v" id="v32" data-v="32" data-xref="詩篇 78:47–48; 出埃及記 9:18–28; 啟示錄 8:7"> <span className="pl pl-1">祂使雨變成冰雹，</span><br /><span className="pl pl-1">遍地電光閃閃。</span><br /></span>
<span className="v" id="v33" data-v="33" data-xref="詩篇 78:47; 啟示錄 9:4"> <span className="pl pl-1">祂擊倒他們的葡萄樹和無花果樹，</span><br /><span className="pl pl-1">摧毀他們境內的樹木。</span><br /></span>
<span className="v" id="v34" data-v="34" data-xref="出埃及記 10:12–15; 詩篇 78:46; 約珥書 1:4–7"> <span className="pl pl-1">祂一發聲，</span><br /><span className="pl pl-1">就飛來無數蝗蟲和螞蚱，</span><br /></span>
<span className="v" id="v35" data-v="35"> <span className="pl pl-1">吃盡他們土地上的植物，</span><br /><span className="pl pl-1">吃盡他們田間的出產。</span><br /></span>
<span className="v" id="v36" data-v="36" data-xref="創世記 49:3; 出埃及記 12:29–30; 詩篇 78:51"> <span className="pl pl-1">祂又擊殺他們境內所有的長子，</span><br /><span className="pl pl-1">就是他們年輕力壯時生的長子。</span><br /></span>
<span className="v" id="v37" data-v="37" data-xref="出埃及記 12:35–36; 出埃及記 3:22; 使徒行傳 13:17"> <span className="pl pl-1">祂帶領以色列人攜金帶銀地離開埃及，</span><br /><span className="pl pl-1">各支派中無人畏縮。</span><br /></span>
<span className="v" id="v38" data-v="38" data-xref="出埃及記 12:33; 出埃及記 15:16; 創世記 35:5"> <span className="pl pl-1">埃及人懼怕他們，</span><br /><span className="pl pl-1">樂見他們離去。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v39" data-v="39" data-xref="尼希米記 9:12; 詩篇 78:14; 以賽亞書 4:5"> <span className="pl pl-1">祂鋪展雲彩為他們遮蔭，</span><br /><span className="pl pl-1">晚上用火給他們照明。</span><br /></span>
<span className="v" id="v40" data-v="40" data-xref="詩篇 78:18; 民數記 11:31–33; 約書亞記 5:12"> <span className="pl pl-1">他們祈求，</span><br /><span className="pl pl-1">祂就賜下鵪鶉，降下天糧，</span><br /><span className="pl pl-1">叫他們飽足。</span><br /></span>
<span className="v" id="v41" data-v="41" data-xref="民數記 20:11; 哥林多前書 10:4; 出埃及記 17:6"> <span className="pl pl-1">祂使磐石裂開、湧出水來，</span><br /><span className="pl pl-1">在乾旱之地奔流成河。</span><br /></span>
<span className="v" id="v42" data-v="42" data-xref="出埃及記 2:24; 路加福音 1:72–73; 創世記 12:7"> <span className="pl pl-1">因為祂顧念祂賜給僕人亞伯拉罕的神聖應許。</span><br /></span>
<span className="v" id="v43" data-v="43" data-xref="以賽亞書 35:10; 使徒行傳 7:36; 耶利米書 31:11–12"> <span className="pl pl-1">祂帶領祂的子民歡然離去，</span><br /><span className="pl pl-1">祂所揀選的百姓歡呼前行。</span><br /></span>
<span className="v" id="v44" data-v="44" data-xref="申命記 6:10–11; 約書亞記 24:13; 詩篇 78:55"> <span className="pl pl-1">祂把列國的土地賜給他們，</span><br /><span className="pl pl-1">使他們獲得別人的勞動成果。</span><br /></span>
<span className="v" id="v45" data-v="45" data-xref="申命記 4:40; 提多書 2:14; 以弗所書 2:8–10"> <span className="pl pl-1">祂這樣做是要使他們持守祂的命令，</span><br /><span className="pl pl-1">遵行祂的律法。</span><br /><span className="pl pl-1">你們要讚美耶和華！</span></span>
</div>

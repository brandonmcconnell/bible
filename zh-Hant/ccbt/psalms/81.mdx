## 歌頌上帝的恩惠

<div className="bt">
<div className="hs">亞薩的詩，交給樂長，用迦特樂器。</div>
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="耶利米書 31:7; 詩篇 66:1; 詩篇 100:1–2"> <span className="pl pl-1">要歌頌賜我們力量的上帝，</span><br /><span className="pl pl-1">向雅各的上帝歡呼。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="詩篇 149:1–3; 詩篇 92:3; 歌羅西書 3:16"> <span className="pl pl-1">要唱詩，擊鼓，彈奏悅耳的琴瑟。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="民數記 10:1–10; 民數記 15:3; 歷代志下 2:4"> <span className="pl pl-1">要在我們過節的朔日和望日</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「朔日和望日」即每月的初一和十五。">a</a></sup><br /><span className="pl pl-1">吹響號角。</span><br /></span>
<span className="v" id="v4" data-v="4"> <span className="pl pl-1">這是以色列的律例，</span><br /><span className="pl pl-1">是雅各的上帝所定的法令。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 114:1; 申命記 28:49; 哥林多前書 14:21–22"> <span className="pl pl-1">上帝攻擊埃及的時候，</span><br /><span className="pl pl-1">為約瑟立下此法度。</span><br /><span className="pl pl-1">我在那裡聽見陌生的聲音說：</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="以賽亞書 9:4; 以賽亞書 10:27; 出埃及記 6:6"> <span className="pl pl-1">「我卸下了你肩上的重擔，</span><br /><span className="pl pl-1">使你的雙手放下筐子，</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="出埃及記 19:19; 民數記 20:13; 出埃及記 2:23"> <span className="pl pl-1">你在苦難中向我呼求，</span><br /><span className="pl pl-1">我就拯救了你，</span><br /><span className="pl pl-1">從雷聲隆隆的密雲中應允了你。</span><br /><span className="pl pl-1">我在米利巴泉邊考驗你。（細拉）</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 50:7; 約翰福音 3:11; 以賽亞書 1:19"> <span className="pl pl-1">我的子民啊，</span><br /><span className="pl pl-1">要聽我的警告。</span><br /><span className="pl pl-1">以色列人啊，</span><br /><span className="pl pl-1">但願你們聽從我的話。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="以賽亞書 43:12; 申命記 32:12; 申命記 6:14"> <span className="pl pl-1">你們當中不可有別的神明，</span><br /><span className="pl pl-1">也不可向外族的神明下拜，</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="約翰福音 15:7; 詩篇 107:9; 出埃及記 20:2"> <span className="pl pl-1">我是你們的上帝耶和華，</span><br /><span className="pl pl-1">曾帶你們出埃及。</span><br /><span className="pl pl-1">張開你們的口吧，</span><br /><span className="pl pl-1">我必使你們飽足。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="申命記 32:18; 耶利米書 7:23–24; 耶利米書 2:11–13"> <span className="pl pl-1">我的子民卻不肯聽我的話，</span><br /><span className="pl pl-1">以色列不願意順從我。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="羅馬書 1:24; 耶利米書 7:24; 以賽亞書 30:1"> <span className="pl pl-1">因此我就任憑他們頑固不化，</span><br /><span className="pl pl-1">為所欲為。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="以賽亞書 48:18; 申命記 5:29; 申命記 10:12–13"> <span className="pl pl-1">但願我的子民肯聽從我，</span><br /><span className="pl pl-1">以色列人肯遵行我的道。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="阿摩司書 1:8; 士師記 2:20–23; 民數記 14:9"> <span className="pl pl-1">那時，我必迅速制伏他們的敵人，</span><br /><span className="pl pl-1">伸手攻擊他們的仇敵。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="申命記 7:10; 羅馬書 1:30; 出埃及記 20:5"> <span className="pl pl-1">恨耶和華的人要向祂投降，</span><br /><span className="pl pl-1">他們會永遠沉淪。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="申命記 32:13–14; 詩篇 147:14; 撒母耳記上 14:25–26"> <span className="pl pl-1">我要以上好的麥子供養我的子民，</span><br /><span className="pl pl-1">讓他們飽享磐石間的蜂蜜。」</span></span>

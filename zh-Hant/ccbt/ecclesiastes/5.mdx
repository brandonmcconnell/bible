## 敬畏上帝

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="雅各書 1:19; 希伯來書 12:28–29; 箴言 15:8"> 你進入上帝的殿時要小心謹慎，近前傾聽勝過愚人獻祭，因為他們不知道自己是在作惡。</span>
<span className="v" id="v2" data-v="2" data-xref="馬太福音 6:7; 箴言 10:19; 以賽亞書 55:9"> 在上帝面前不要冒失開口，不可急於發言，因為祂在天上，你在地上。所以，你要少言寡語。</span>
<span className="v" id="v3" data-v="3" data-xref="箴言 15:2; 箴言 10:19; 傳道書 10:12–14"> 事務繁雜，夜裡多夢；多言多語，顯出愚昧。</span>
<span className="v" id="v4" data-v="4" data-xref="民數記 30:2; 申命記 23:21–23; 詩篇 76:11"> 你向上帝許願，不可遲遲不還，因為祂不喜歡愚人。要還所許的願。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行傳 5:4; 申命記 23:22; 箴言 20:25"> 與其許了願不還，倒不如不許。</span>
<span className="v" id="v6" data-v="6" data-xref="雅各書 1:26; 約翰二書 1:8; 雅各書 3:2"> 不要在言語上犯罪，也不要在祭司<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「祭司」希伯來文是「使者」。">a</a></sup>面前說許錯了願。為什麼用言語惹上帝發怒，以致祂摧毀你手中的工作呢？</span>
<span className="v" id="v7" data-v="7" data-xref="傳道書 12:13; 馬太福音 12:36; 傳道書 8:12"> 多夢多言都是虛空。你只要敬畏上帝！</span>
</div>
</div>

## 財富虛空

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="詩篇 12:5; 傳道書 4:1; 傳道書 3:16"> 若你在某地看見窮人受欺壓，公平正義被踐踏，不要震驚，因為官上有官，在眾官之上還有更高的官鑒察。</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀上 4:7–23; 詩篇 115:16; 創世記 1:29–30"> 況且，地的出產滋養萬人，就是君王也需要從田地得到供應。</span>
<span className="v" id="v10" data-v="10" data-xref="提摩太前書 6:10; 馬太福音 6:24; 路加福音 12:15"> 貪愛錢財的，金銀不能使他滿足；貪圖富裕的，再多的收益也不能叫他稱心。這也是虛空！</span>
<span className="v" id="v11" data-v="11" data-xref="約翰一書 2:16; 哈巴谷書 2:13; 詩篇 119:36–37"> 財富增加，消費的人也增加，這對財富的主人有什麼益處呢？只是過眼雲煙罷了！</span>
<span className="v" id="v12" data-v="12" data-xref="箴言 3:24; 詩篇 4:8; 耶利米書 31:26"> 勞力的人不管吃多吃少，總是睡得香甜；富人的家財卻害得他不能成眠。</span>
<span className="v" id="v13" data-v="13" data-xref="傳道書 6:1–2; 路加福音 18:22–23; 創世記 19:14"> 我看到日光之下有一件可悲的事：有人積攢財寶，反而害了自己。</span>
<span className="v" id="v14" data-v="14" data-xref="馬太福音 6:19–20; 哈該書 2:16–17; 箴言 23:5"> 經營不善，財富盡失，什麼也不能留給子孫。</span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 49:17; 約伯記 1:21; 提摩太前書 6:7"> 人怎樣從母腹空空而來，也必照樣空空而去；勞碌一生，什麼也不能帶走。</span>
<span className="v" id="v16" data-v="16" data-xref="箴言 11:29; 傳道書 1:3; 約翰福音 6:27"> 這是極大的悲哀！人怎樣來，也要怎樣去，為風勞碌有什麼益處呢？</span>
<span className="v" id="v17" data-v="17" data-xref="詩篇 127:2; 以西結書 4:16–17; 詩篇 90:7–11"> 他一生活在黑暗中，飽受煩惱、病痛和憤怒的困擾。</span>
<span className="v" id="v18" data-v="18" data-xref="傳道書 2:24; 傳道書 3:12–13; 傳道書 3:22"> 我認為人生最美最善的是，在上帝所賜的短暫歲月中盡情吃喝，享受自己在日光之下勞苦得來的成果。因為這是人當得的。</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 8:18; 傳道書 3:13; 傳道書 6:2"> 上帝不單給人財富和產業，也叫他能吃能喝，享用自己所當得的，並在勞碌中得到快樂，這都是上帝的恩賜。</span>
<span className="v" id="v20" data-v="20" data-xref="以賽亞書 65:21–24; 以賽亞書 65:13–14; 詩篇 37:16"> 他不用擔憂自己壽命的長短，因為上帝使他心裡充滿喜樂。</span>
</div>
</div>

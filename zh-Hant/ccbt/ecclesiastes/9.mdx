<span className="v" id="v1" data-v="1" data-xref="申命記 33:3; 約翰福音 10:27–30; 彼得前書 1:5"> 我仔細思想、探究這一切事，就知道義人、智者及他們的行事為人都由上帝掌管，人無法知道前面等待自己的是愛還是恨。</span>
<span className="v" id="v2" data-v="2" data-xref="瑪拉基書 3:18; 傳道書 2:14–16; 瑪拉基書 3:5"> 義人和惡人、好人和壞人、潔淨的和污穢的、獻祭的和不獻祭的、行善的和犯罪的、敢於起誓的和不敢起誓的人，命運都一樣。</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米書 17:9; 傳道書 8:11; 傳道書 1:17"> 在日光之下有一件可悲的事，就是人的命運都一樣。況且，人內心都充滿邪惡，活著的時候行事狂妄，之後都步入死亡。</span>
<span className="v" id="v4" data-v="4" data-xref="約伯記 14:7–12; 以賽亞書 38:18; 路加福音 16:26–29"> 有生命就有希望，一條活狗總比一頭死獅子強。</span>
<span className="v" id="v5" data-v="5" data-xref="以賽亞書 26:14; 傳道書 1:11; 詩篇 6:5"> 因為活著的人還知道自己終有一死，但死了的人什麼都不知道，再也得不到任何賞賜，他們被忘得一乾二淨。</span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 146:3–4; 傳道書 6:12; 約伯記 3:17–18"> 他們的愛、恨和嫉妒早已不復存在，他們再也無法參與日光之下的任何事。</span>
<span className="v" id="v7" data-v="7" data-xref="傳道書 3:12–13; 申命記 12:7; 傳道書 10:19"> 去歡歡喜喜、快快樂樂地吃喝吧！因為上帝已經悅納你所做的。</span>
<span className="v" id="v8" data-v="8" data-xref="啟示錄 19:14; 啟示錄 3:4–5; 啟示錄 19:8"> 你的衣服要經常保持潔白，頭上也不要缺少膏油。</span>
<span className="v" id="v9" data-v="9" data-xref="箴言 5:18–19; 傳道書 2:10; 瑪拉基書 2:15"> 在你虛空的人生中，就是在上帝所賜、日光之下虛空的歲月裡，你要與愛妻快樂度日，因為這是你一生在日光之下的勞碌中所當得的。</span>
<span className="v" id="v10" data-v="10" data-xref="歌羅西書 3:23; 以弗所書 5:16; 羅馬書 12:11"> 凡你的手能做的，都要盡力去做，因為在你要去的陰間沒有工作，沒有計劃，也沒有知識和智慧。</span>
<span className="v" id="v11" data-v="11" data-xref="耶利米書 9:23; 箴言 21:30–31; 耶利米哀歌 3:37–38"> 我又發現，日光之下，跑得快的未必能得獎，強大的未必能得勝，智者未必得溫飽，聰明人未必得財富，博學者未必受愛戴，因為時機和境遇左右眾人。</span>
<span className="v" id="v12" data-v="12" data-xref="帖撒羅尼迦前書 5:3; 路加福音 21:34–36; 傳道書 8:5–7"> 再者，人無法知道何時大難臨頭。禍患突然臨到時，人根本無法擺脫，就像魚落入險惡的網中，又像鳥兒陷入網羅。</span>
<span className="v" id="v13" data-v="13" data-xref="傳道書 8:16; 傳道書 7:15; 傳道書 6:1"> 我看見日光之下有一種智慧，對我來說意義深遠。</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳記下 20:15–22; 列王紀下 6:24–20"> 有一個勢力強大的君王來攻擊一個人口不多的小城，他建造營壘圍困這城。</span>
<span className="v" id="v15" data-v="15" data-xref="傳道書 4:13; 創世記 40:23; 以斯帖記 6:2–3"> 這城裡有一個貧窮的智者，他用智慧拯救了這城，事後卻無人記念他。</span>
<span className="v" id="v16" data-v="16" data-xref="傳道書 7:19; 箴言 24:5; 箴言 21:22"> 我認為智慧勝過武力，然而那位窮人的智慧卻被輕視，他所說的話也無人理會。</span>
<span className="v" id="v17" data-v="17" data-xref="雅各書 3:17–18; 箴言 28:23; 雅各書 1:20"> 聽智者的細語，勝過聽官長在愚人中的喊叫。</span>
<span className="v" id="v18" data-v="18" data-xref="約書亞記 7:11–12; 傳道書 9:16; 約書亞記 7:5"> 智慧勝過兵器，但一個罪人卻能破壞許多善事。</span>

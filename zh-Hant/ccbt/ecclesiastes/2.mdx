<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 12:19; 傳道書 8:15; 雅各書 5:5"> 我心裡想：「來吧，不妨試試享樂，好好享受！」唉！結果這也是虛空。</span>
<span className="v" id="v2" data-v="2" data-xref="箴言 14:13; 傳道書 7:2–6; 彼得前書 4:2–4"> 我說：「歡笑只不過是一陣狂妄，享樂又有什麼用！」</span>
<span className="v" id="v3" data-v="3" data-xref="箴言 20:1; 傳道書 1:17; 箴言 31:4–5"> 於是，我決意用酒使自己快樂，在體驗愚昧的同時仍然保持理智，直到我明白在短暫的人生歲月中做何事才有益。</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀上 7:1–12; 歷代志下 8:11; 歷代志下 26:10"> 我大動工程，為自己建造房屋，栽種葡萄園；</span>
<span className="v" id="v5" data-v="5" data-xref="路加福音 17:27–29; 雅歌 4:12–1; 耶利米書 39:4"> 我為自己開墾花圃園囿，在其中種植各種果樹；</span>
<span className="v" id="v6" data-v="6" data-xref="尼希米記 2:14; 詩篇 1:3; 耶利米書 17:8"> 我為自己開鑿池塘，用來澆灌茂林。</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀下 3:4; 創世記 15:3; 列王紀上 4:23"> 我買了僕婢，又有生在家中的僕婢，擁有的牛羊遠超過歷來在耶路撒冷的任何人。</span>
<span className="v" id="v8" data-v="8" data-xref="列王紀上 10:10; 列王紀上 9:28; 撒母耳記下 19:35"> 我為自己積聚金銀，搜羅列王和各省的奇珍異寶，得到世人所想望的男女歌優及許多妃嬪。</span>
<span className="v" id="v9" data-v="9" data-xref="歷代志上 29:25; 傳道書 1:16; 列王紀上 10:23"> 這樣，我便財勢日增，超過耶路撒冷歷來所有的人。然而，我仍然保持智慧。</span>
<span className="v" id="v10" data-v="10" data-xref="傳道書 9:9; 傳道書 5:18; 傳道書 3:22"> 凡我眼睛愛看的、心裡渴慕的，我都隨心所欲，盡情享受。我的心從勞碌中得到歡樂，這是我勞碌所得的回報。</span>
<span className="v" id="v11" data-v="11" data-xref="傳道書 1:14; 約翰一書 2:16–17; 傳道書 1:3"> 然而，當我回顧雙手成就的一切和所付的辛勞時，唉，卻發現都是虛空，都是捕風；日光之下的一切都毫無益處。</span>
<span className="v" id="v12" data-v="12" data-xref="傳道書 1:17; 傳道書 7:25; 傳道書 1:9–10"> 於是，我轉念思考什麼是智慧、狂妄和愚昧。其實以後接替君王的人除了重演歷史之外，還能做什麼呢？</span>
<span className="v" id="v13" data-v="13" data-xref="以弗所書 5:8; 傳道書 7:11–12; 馬太福音 6:23"> 我領悟到智慧勝過愚昧，如同光明勝過黑暗。</span>
<span className="v" id="v14" data-v="14" data-xref="詩篇 49:10; 箴言 17:24; 傳道書 9:11"> 智者高瞻遠矚，愚人卻在黑暗中摸索。但我知道兩者都有同樣的命運。</span>
<span className="v" id="v15" data-v="15" data-xref="傳道書 6:8; 傳道書 1:14; 傳道書 1:2"> 於是，我想：「既然愚人的命運也將是我的命運，我有智慧又怎麼樣呢？」我只能說：「這也是虛空。」</span>
<span className="v" id="v16" data-v="16" data-xref="傳道書 1:11; 傳道書 9:5; 詩篇 88:12"> 因為智者和愚人一樣，不過被人記得一時，日後都會被遺忘。兩者都難逃死亡。</span>
<span className="v" id="v17" data-v="17" data-xref="傳道書 2:11; 約拿書 4:8; 傳道書 4:2"> 所以，我憎惡生命，因為在日光之下所做的一切都讓我愁煩。唉！這一切都是虛空，都是捕風。</span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 39:6; 詩篇 49:10; 路加福音 16:27–28"> 我憎惡自己在日光之下勞碌得來的一切，因為這些必留給後人。</span>
<span className="v" id="v19" data-v="19" data-xref="雅各書 3:17; 傳道書 3:22; 傳道書 9:13"> 誰知道後人是智者還是愚人呢？他卻要接管我在日光之下用智慧辛勞經營的產業。這也是虛空。</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 43:14; 約伯記 17:11–15; 哥林多後書 1:8–10"> 因此，我對自己在日光之下一切的勞碌感到絕望。</span>
<span className="v" id="v21" data-v="21" data-xref="傳道書 2:17–18; 歷代志下 31:20–21; 歷代志下 34:2"> 因為一個人用智慧、知識和技能所得來的一切，卻要留給不勞而獲的人享用，這也是虛空，是極大的不幸！</span>
<span className="v" id="v22" data-v="22" data-xref="詩篇 127:2; 傳道書 1:3; 腓立比書 4:6"> 世人在日光之下勞心勞力，究竟得到什麼呢？</span>
<span className="v" id="v23" data-v="23" data-xref="約伯記 14:1; 約伯記 5:7; 詩篇 6:6–7"> 他們一生充滿痛苦，勞碌中盡是愁煩，即使夜間心裡也不安寧。這也是虛空。</span>
<span className="v" id="v24" data-v="24" data-xref="傳道書 3:22; 傳道書 8:15; 提摩太前書 6:17"> 對人而言，沒有什麼比吃喝並享受勞碌之樂更好，我看這也是出自上帝的手。</span>
<span className="v" id="v25" data-v="25" data-xref="傳道書 2:1–12; 列王紀上 4:21–24"> 離了上帝，誰還能吃喝享受呢？</span>
<span className="v" id="v26" data-v="26" data-xref="箴言 13:22; 約伯記 27:16–17; 箴言 28:8"> 上帝把智慧、知識和喜樂賜給祂喜悅的人，卻讓罪人忙於積攢財富，然後把他們的財富賜給祂喜悅的人。這也是虛空，也是捕風。</span>

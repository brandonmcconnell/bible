## 萬物有時

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="傳道書 3:17; 馬太福音 16:3; 傳道書 8:5–6"> <span className="pl pl-1">天下萬物都有定期，</span><br /><span className="pl pl-1">凡事都有定時。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="希伯來書 9:27; 約伯記 14:5; 馬太福音 15:13"> <span className="pl pl-1">出生有時，死亡有時；</span><br /><span className="pl pl-1">耕種有時，拔出有時；</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="何西阿書 6:1–2; 撒母耳記上 2:6; 耶利米書 45:4"> <span className="pl pl-1">殺戮有時，醫治有時；</span><br /><span className="pl pl-1">拆毀有時，建造有時；</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="羅馬書 12:15; 詩篇 30:5; 雅各書 4:9"> <span className="pl pl-1">哭泣有時，歡笑有時；</span><br /><span className="pl pl-1">哀傷有時，雀躍有時；</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="列王紀下 3:25; 約書亞記 10:27; 約書亞記 4:3–9"> <span className="pl pl-1">拋石有時，堆石有時</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「拋石有時，堆石有時」意義不明，有猶太拉比說是「同房有時，分房有時」。">a</a></sup><br /><span className="pl pl-1">；</span><br /><span className="pl pl-1">擁抱有時，避開有時；</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="腓立比書 3:7–8; 路加福音 9:24–25; 馬可福音 8:35–37"> <span className="pl pl-1">尋找有時，遺失有時；</span><br /><span className="pl pl-1">保存有時，丟棄有時；</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="阿摩司書 5:13; 彌迦書 7:5; 耶利米哀歌 3:28"> <span className="pl pl-1">撕裂有時，縫合有時；</span><br /><span className="pl pl-1">沉默有時，發言有時；</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="以弗所書 5:25; 以弗所書 5:28–29; 路加福音 14:26"> <span className="pl pl-1">愛慕有時，憎惡有時；</span><br /><span className="pl pl-1">爭戰有時，和好有時。</span></span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="傳道書 1:3; 傳道書 5:16; 箴言 14:23"> 那麼，人勞碌做工有什麼益處呢？</span>
<span className="v" id="v10" data-v="10" data-xref="傳道書 1:13–14; 創世記 3:19; 傳道書 2:26"> 我察覺上帝給世人重擔，使他們忙碌不休。</span>
<span className="v" id="v11" data-v="11" data-xref="羅馬書 11:33; 羅馬書 1:19–20; 約伯記 11:7"> 祂使萬事各按其時變得美好，又把永恆的意識放在人心裡，人卻不能測透上帝從始至終的作為。</span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 37:3; 傳道書 3:22; 提摩太前書 6:18"> 我認識到，人生在世沒有什麼比歡樂、享受更好。</span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 128:2; 傳道書 9:7; 傳道書 2:24"> 人人都該吃喝、享受自己勞苦的成果，這是上帝的恩賜。</span>
<span className="v" id="v14" data-v="14" data-xref="雅各書 1:17; 詩篇 33:11; 羅馬書 11:36"> 我知道，上帝所做的都會存到永遠，誰也不能增減。祂這樣安排是叫人敬畏祂。</span>
<span className="v" id="v15" data-v="15" data-xref="傳道書 1:9–10; 傳道書 6:10"> 現在的事並不是新事，未來的事也早已發生過。上帝使過去的事再次出現。</span>
</div>

## 世間的不公

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="傳道書 4:1; 傳道書 5:8; 詩篇 94:21–22"> 我又看到日光之下，即使在公道和正義之地也有邪惡。</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多後書 5:10; 傳道書 12:14; 馬太福音 16:27"> 我心裡想：「不論義人或惡人，上帝必審判，因為萬事萬務都有定時。」</span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 73:22; 詩篇 49:12; 希伯來書 9:27"> 我又想：「至於世人，上帝試驗他們，是要他們知道自己與獸類無異。</span>
<span className="v" id="v19" data-v="19" data-xref="詩篇 49:12; 詩篇 49:20; 詩篇 89:47–48"> 因為人和獸的際遇並無分別，兩者都難逃一死，活著都靠一口氣。人並不比獸強，一切都是虛空。</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 3:19; 約伯記 34:15; 傳道書 12:7"> 兩者都同歸一處，出於塵土，也歸於塵土。</span>
<span className="v" id="v21" data-v="21" data-xref="傳道書 12:7; 約翰福音 14:3; 哥林多後書 5:1"> 誰知道人的氣息<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="「氣息」或譯「靈」，本節同。">b</a></sup>會向上升，獸的氣息會降到地下呢？」</span>
<span className="v" id="v22" data-v="22" data-xref="傳道書 2:24; 傳道書 3:11–12; 傳道書 10:14"> 因此，我覺得沒有什麼比人享受工作之樂更好，因為這是人當得的。人死後，誰能使他看到世間的事呢？</span>
</div>

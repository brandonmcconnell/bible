<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="使徒行傳 6:15; 申命記 28:50; 彼得後書 1:20"> <span className="pl pl-1">誰像有智慧的人呢？</span><br /><span className="pl pl-1">誰知道事情的原委呢？</span><br /><span className="pl pl-1">智慧能使人容光煥發，</span><br /><span className="pl pl-1">使冷酷的面孔柔和。</span></span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="列王紀上 2:43; 提多書 3:1; 箴言 24:21"> 我勸你遵守王的命令，因為你曾在上帝面前這樣發誓。</span>
<span className="v" id="v3" data-v="3" data-xref="傳道書 10:4; 使徒行傳 5:8–9; 但以理書 4:35"> 不要在王面前魯莽行事，也不要參與惡行，因為王可以隨意行事。</span>
<span className="v" id="v4" data-v="4" data-xref="約伯記 9:12; 羅馬書 13:1–4; 但以理書 4:35"> 況且，王的命令至高無上，誰敢質問他：「你在做什麼？」</span>
<span className="v" id="v5" data-v="5" data-xref="希伯來書 5:14; 彼得前書 3:13–14; 腓立比書 1:9–10"> 遵從王命的必免遭禍患，因為智者心裡懂得做事的時機和方法。</span>
<span className="v" id="v6" data-v="6" data-xref="傳道書 3:1; 傳道書 3:17; 傳道書 3:11"> 儘管人面臨重重困難，但做任何事都有時機和方法。</span>
<span className="v" id="v7" data-v="7" data-xref="傳道書 10:14; 傳道書 9:12; 箴言 24:22"> 無人知道未來的事，誰能告訴人將來的事呢？</span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 89:48; 約伯記 14:5; 希伯來書 9:27"> 無人能掌管生命<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「生命」也可譯作「風」或「氣息」。">a</a></sup>，留住生命，也無人能掌管死期。無人能免於這場爭戰，邪惡也救不了作惡者。</span>
<span className="v" id="v9" data-v="9" data-xref="傳道書 5:8; 傳道書 4:7–8; 傳道書 5:13"> 這一切我都見過了，我用心思考日光之下的一切事。有時人欺壓人，使人受傷害。</span>
<span className="v" id="v10" data-v="10" data-xref="傳道書 9:5; 傳道書 2:16; 箴言 10:7"> 我看見惡人死後被安葬。他們生前出入聖所，還在他們作惡的城中受到稱讚，這也是虛空。</span>
<span className="v" id="v11" data-v="11" data-xref="以賽亞書 26:10; 詩篇 50:21–22; 羅馬書 2:4–5"> 對犯罪者的刑罰不迅速執行，世人便盡情作惡。</span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 37:11; 彼得後書 2:9; 路加福音 1:50"> 雖然罪人作惡多端仍得長壽，我卻認為敬畏上帝的人必亨通，因為他們對上帝心存敬畏。</span>
<span className="v" id="v13" data-v="13" data-xref="傳道書 6:12; 以賽亞書 3:11; 約伯記 14:2"> 然而，惡人得不到祝福，他們必像幻影一樣不能長久，因為他們不敬畏上帝。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="傳道書 7:15; 傳道書 2:14; 瑪拉基書 3:15"> 世上有一件虛空的事，就是義人遭受了惡人當受的報應，惡人卻享受了義人該享的福樂。我認為這也是虛空。</span>
<span className="v" id="v15" data-v="15" data-xref="傳道書 2:24; 傳道書 5:18; 傳道書 3:12–13"> 因此，我便讚賞享樂，因為在日光之下沒有什麼比吃喝快樂更好。這是人在上帝所賜的年日裡，從勞碌中當得的享受。</span>
<span className="v" id="v16" data-v="16" data-xref="傳道書 1:13; 詩篇 127:2; 傳道書 2:23"> 我全心去尋求智慧，觀察世上所發生的事，甚至晝夜不眠，</span>
<span className="v" id="v17" data-v="17" data-xref="傳道書 3:11; 詩篇 73:16; 羅馬書 11:33"> 我看清了上帝的一切作為，便知道人無法理解日光之下所發生的事。儘管人努力不懈地去尋找，也找不到答案；即使智者自以為明白，他其實仍不能參透。</span>
</div>

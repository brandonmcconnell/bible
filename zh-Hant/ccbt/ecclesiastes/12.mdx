<span className="v" id="v1" data-v="1" data-xref="耶利米哀歌 3:27; 傳道書 11:8; 詩篇 71:17–18"> 年輕時要記住你的創造主，不要等到衰老的歲月來臨時才哀歎：「我的日子毫無樂趣。」</span>
<span className="v" id="v2" data-v="2" data-xref="以賽亞書 5:30; 撒母耳記上 4:18; 撒母耳記上 4:15"> 那時，太陽、月亮、星星都暗淡無光，雨後烏雲再現；</span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 90:9–10; 詩篇 102:23; 撒母耳記下 21:15–17"> 守衛家園的手腳顫抖，強壯的身軀變得彎腰駝背；牙齒稀少，無法咀嚼；視力衰退，看不清楚；</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米書 25:10; 撒母耳記下 19:35; 啟示錄 18:22"> 耳朵發背，聽不到推磨聲；小鳥一叫，人就起來；歌聲沙啞，不再美妙；</span>
<span className="v" id="v5" data-v="5" data-xref="約伯記 17:13; 耶利米書 9:17–20; 約伯記 30:23"> 懼怕高處，走路戰戰兢兢；頭髮白如銀杏，精力枯竭，慾望蕩然無存；人都走向永遠的歸宿，弔喪的人往來於街上；</span>
<span className="v" id="v6" data-v="6" data-xref="撒迦利亞書 4:2–3"> 銀鏈斷裂，金碗摔壞，泉旁的瓶子破碎，井口的輪子朽爛。</span>
<span className="v" id="v7" data-v="7" data-xref="但以理書 12:2; 傳道書 3:20–21; 詩篇 146:4"> 那時塵土必歸回大地，靈也要歸回賜靈的上帝。</span>
<span className="v" id="v8" data-v="8" data-xref="傳道書 1:2; 傳道書 8:8; 傳道書 1:14"> 傳道者說：「虛空的虛空，一切都是虛空。」</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀上 4:32; 箴言 1:1; 列王紀上 10:8"> 傳道者不但有智慧，還把知識傳授給眾人。他經過細心推敲和研究之後，編寫了許多警世的箴言。</span>
<span className="v" id="v10" data-v="10" data-xref="歌羅西書 1:5; 提摩太前書 1:15; 箴言 16:21–24"> 傳道者費盡心思尋找金玉良言，所寫的都是正直誠實的道理。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行傳 2:37; 希伯來書 4:12; 以西結書 34:23"> 智者的言語好像趕牛的刺棍，他們收集的箴言像釘牢的釘子，都是一位牧者所賜的。</span>
<span className="v" id="v12" data-v="12" data-xref="傳道書 1:18; 約翰福音 21:25; 彼得後書 1:19–21"> 我親愛的兒子，還有一件事，你要聽我的忠告：著書多，沒有窮盡；讀書多，身體疲勞。</span>
<span className="v" id="v13" data-v="13" data-xref="申命記 10:12; 彌迦書 6:8; 申命記 6:2"> 以上所說的，總而言之，就是要敬畏上帝，遵守祂的誡命，這是人的本分。</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多後書 5:10; 羅馬書 2:16; 馬太福音 12:36"> 因為人一切的行為，無論善惡，包括一切隱秘事，上帝都必審問。</span>

## 萬事虛空

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="傳道書 12:8–10; 傳道書 1:12; 傳道書 7:27"> 以下是在耶路撒冷做王的大衛之子傳道者的話。</span>
<span className="v" id="v2" data-v="2" data-xref="詩篇 144:4; 羅馬書 8:20; 傳道書 5:10"> <span className="pl pl-1">傳道者說：虛空的虛空，</span><br /><span className="pl pl-1">虛空的虛空，一切都是虛空。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="傳道書 3:9; 傳道書 5:16; 傳道書 2:22"> <span className="pl pl-1">人在日光之下的一切勞碌有什麼益處呢？</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="詩篇 104:5; 撒迦利亞書 1:5; 傳道書 6:12"> <span className="pl pl-1">一代過去，一代又來，</span><br /><span className="pl pl-1">大地卻永遠長存。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 19:4–6; 哈巴谷書 3:11; 詩篇 42:1"> <span className="pl pl-1">太陽升起，太陽落下，</span><br /><span className="pl pl-1">匆忙回到升起之地。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="約翰福音 3:8; 傳道書 11:5; 詩篇 107:25"> <span className="pl pl-1">風吹向南，又轉向北，</span><br /><span className="pl pl-1">循環不息，周而復始。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="約伯記 38:10–11; 詩篇 104:6–9"> <span className="pl pl-1">江河湧流入海，海卻不會滿溢；</span><br /><span className="pl pl-1">江河從何處流出，又返回何處。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="箴言 27:20; 馬太福音 11:28; 傳道書 4:8"> <span className="pl pl-1">萬事令人厭煩，人述說不盡。</span><br /><span className="pl pl-1">眼看，看不飽；</span><br /><span className="pl pl-1">耳聽，聽不夠。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="傳道書 3:15; 傳道書 6:10; 傳道書 2:12"> <span className="pl pl-1">以往發生的事，將來還會發生；</span><br /><span className="pl pl-1">先前做過的事，將來也必再做。</span><br /><span className="pl pl-1">日光之下，根本沒有新事。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="使徒行傳 7:51; 路加福音 17:26–30; 馬太福音 23:30–32"> <span className="pl pl-1">人可以指著哪件事說</span><br /><span className="pl pl-1">「看啊，這是新事」？</span><br /><span className="pl pl-1">所謂的新事在我們以前早就有了。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="傳道書 2:16; 詩篇 9:6; 傳道書 9:5"> <span className="pl pl-1">過去的事無人記得，</span><br /><span className="pl pl-1">將來的事後人也不記得。</span></span>
</div>

## 智慧之虛空

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="傳道書 1:1; 列王紀上 4:1–19"> 我傳道者曾在耶路撒冷做以色列的王。</span>
<span className="v" id="v13" data-v="13" data-xref="傳道書 3:10; 創世記 3:19; 提摩太前書 4:15"> 我專心用智慧去研究、探索天下萬事，發現上帝給世人的是極重的苦工。</span>
<span className="v" id="v14" data-v="14" data-xref="傳道書 2:11; 傳道書 2:17; 傳道書 2:26"> 我觀察一切日光之下所做的事，看啊，都是虛空，好像捕風。</span>
<span className="v" id="v15" data-v="15" data-xref="傳道書 7:12–13; 以賽亞書 40:4; 傳道書 3:14"> 彎曲的不能變直，缺少的無法補足<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「補足」希伯來文是「數算」。">a</a></sup>。</span>
<span className="v" id="v16" data-v="16" data-xref="傳道書 2:9; 列王紀上 4:30; 列王紀上 10:7"> 我心裡想：「我獲得極大的智慧，遠超過以前統治耶路撒冷的人。我擁有豐富的智慧和知識。」</span>
<span className="v" id="v17" data-v="17" data-xref="傳道書 2:3; 帖撒羅尼迦前書 5:21; 傳道書 1:13–14"> 我又專心察明智慧和知識、狂妄和愚昧，卻發現這也是捕風。</span>
<span className="v" id="v18" data-v="18" data-xref="約伯記 28:28; 傳道書 12:12–13; 哥林多前書 3:18–20"> 因為智慧越高，愁煩越多；知識越多，痛苦越深。</span>
</div>
</div>

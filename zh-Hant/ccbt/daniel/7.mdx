## 但以理夢見四獸

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="但以理書 1:17; 阿摩司書 3:7; 但以理書 5:1"> 巴比倫王伯沙撒元年，但以理在床上做了一個夢，腦中出現了異象，便把夢記錄下來，講述其中的大意。</span>
<span className="v" id="v2" data-v="2" data-xref="啟示錄 7:1; 啟示錄 17:15"> 但以理說：「我在夜間的異象中看見天上有四股風吹來，攪動大海。</span>
<span className="v" id="v3" data-v="3" data-xref="啟示錄 13:1; 但以理書 7:17; 但以理書 2:32–33"> 接著，四隻巨獸從海中上來，各有不同的形狀。</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米書 4:7; 以賽亞書 14:13–17; 以西結書 17:3"> 第一隻獸像獅子，但有鷹的翅膀。我觀看時，見牠的翅膀被拔掉。牠被扶起來，像人一樣雙腳站在地上，並被賦予人的頭腦。</span>
<span className="v" id="v5" data-v="5" data-xref="但以理書 2:39; 以賽亞書 13:17–18; 箴言 17:12"> 第二隻獸像熊，用兩隻後腿站立，牙齒間叼著三根肋骨，有聲音對牠說，『起來，多吞吃肉吧！』</span>
</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="啟示錄 13:2; 但以理書 8:20–22; 但以理書 8:5–8"> 「此後，我繼續觀看，見還有一隻獸像豹，背上有四個如鳥翼般的翅膀。這獸有四個頭，並被賦予權柄。</span>
<span className="v" id="v7" data-v="7" data-xref="啟示錄 13:1; 啟示錄 12:3; 啟示錄 17:12"> 此後，我在夜間的異象中看見第四隻獸，恐怖可怕，極其強壯，長著大鐵牙吞吃、咬碎獵物，用腳踐踏所剩的。這獸與前三隻獸不同，牠有十個角。</span>
<span className="v" id="v8" data-v="8" data-xref="啟示錄 13:5–6; 啟示錄 13:1; 詩篇 12:3"> 我觀看這些角時，見其中又長出一個小角，先前的角中有三個被連根拔出，由它取而代之。這小角有人的眼睛和說狂言的口。</span>
<span className="v" id="v9" data-v="9" data-xref="啟示錄 1:14; 馬可福音 9:3; 但以理書 7:13"> <span className="pl pl-1">「我看見寶座已設立，</span><br /><span className="pl pl-1">上面坐著亙古長存者，</span><br /><span className="pl pl-1">祂的衣服潔白如雪，</span><br /><span className="pl pl-1">頭髮如純淨的羊毛。</span><br /><span className="pl pl-1">祂的寶座是火焰，</span><br /><span className="pl pl-1">寶座的輪子是烈火。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="以賽亞書 30:27; 申命記 33:2; 啟示錄 20:11–15"> <span className="pl pl-1">從祂面前流出火河，</span><br /><span className="pl pl-1">事奉祂的有千千，</span><br /><span className="pl pl-1">侍立在祂面前的有萬萬。</span><br /><span className="pl pl-1">祂坐下要審判，</span><br /><span className="pl pl-1">案卷已經展開。</span></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="啟示錄 19:20; 啟示錄 20:10; 帖撒羅尼迦後書 2:8"> 「因為小角口出狂言，我便繼續觀看，一直到那獸被殺，身體被毀並被扔進火中。</span>
<span className="v" id="v12" data-v="12" data-xref="但以理書 8:7; 但以理書 7:4–6"> 至於其餘的獸，牠們的權柄都被奪去，但獲准再存活一段時間。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="馬太福音 26:64; 啟示錄 1:7; 路加福音 21:27"> 「我在夜間的異象中看見一位像人子的駕著天上的雲而來，到亙古長存者那裡，被引到祂面前。</span>
<span className="v" id="v14" data-v="14" data-xref="啟示錄 11:15; 但以理書 7:27; 約翰福音 3:35"> 祂得到權柄、榮耀和國度，各國、各邦、各語種的人都要事奉祂。祂的統治直到永遠、沒有窮盡，祂的國度永不滅亡。</span>
</div>
</div>

## 解釋異象

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="但以理書 7:28; 耶利米書 17:16; 創世記 40:7–8"> 「我但以理心靈不安，腦中出現的異象讓我恐懼，</span>
<span className="v" id="v16" data-v="16" data-xref="啟示錄 7:13–14; 撒迦利亞書 2:3; 啟示錄 5:5"> 便走近一位侍立一旁的，問他這些事的意思。他就向我解釋說，</span>
<span className="v" id="v17" data-v="17" data-xref="但以理書 8:19–22; 但以理書 2:37–40; 約翰福音 18:36"> 『這四隻巨獸是指四個將要在世上興起的王。</span>
<span className="v" id="v18" data-v="18" data-xref="但以理書 7:27; 以賽亞書 60:12–14; 啟示錄 5:10"> 但至高者的聖民必承受這國度，並永永遠遠擁有這國度。』</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="但以理書 7:7; 但以理書 2:40–43"> 「那時，我想知道關於第四獸的事，牠與其餘三獸不同，極其可怕，有鐵牙銅爪，吞吃、咬碎獵物，用腳踐踏所剩的。</span>
<span className="v" id="v20" data-v="20" data-xref="但以理書 7:23; 但以理書 7:8; 但以理書 7:11"> 我也想知道有關牠頭上的十角及後來長出的小角的事。有三個角在這小角面前斷落，這角有眼和說狂言的口，看起來比其他角更強大。</span>
<span className="v" id="v21" data-v="21" data-xref="但以理書 12:7; 啟示錄 17:14; 但以理書 8:24"> 我看見這小角與聖民爭戰，並佔了上風。</span>
<span className="v" id="v22" data-v="22" data-xref="但以理書 7:18; 啟示錄 20:4; 啟示錄 5:10"> 後來亙古長存的至高者來為祂的聖民伸冤。聖民擁有國度的時候到了。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="但以理書 2:40; 但以理書 7:7; 路加福音 2:1"> 「那位侍立一旁的說，『第四隻獸是指世上將興起的第四個國，與其他各國不同，牠將吞吃、踐踏、咬碎天下。</span>
<span className="v" id="v24" data-v="24" data-xref="但以理書 7:20; 但以理書 11:36; 啟示錄 13:1"> 十角是指這國中將興起十個王，後來又興起一王，與先前的王不同，他將制伏三個王。</span>
<span className="v" id="v25" data-v="25" data-xref="但以理書 12:7; 啟示錄 12:14; 帖撒羅尼迦後書 2:4"> 他必褻瀆至高者，迫害至高者的聖民，試圖改變節期和律法。聖民將被交在他手中三年半。</span>
<span className="v" id="v26" data-v="26" data-xref="啟示錄 20:10–11; 帖撒羅尼迦後書 2:8; 啟示錄 11:13"> 然而，審判者將坐下來審判，奪去並永遠廢除他的權柄。</span>
<span className="v" id="v27" data-v="27" data-xref="詩篇 72:11; 路加福音 1:33; 啟示錄 11:15"> 那時，國度、權柄和天下萬國的尊榮必賜給至高者的聖民。祂的國度直到永遠，一切掌權者都要事奉祂，順服祂。』</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="路加福音 2:19; 路加福音 2:51; 但以理書 10:8"> 「這就是我的夢。我但以理心中十分害怕，臉色蒼白，但我沒有把這事告訴別人。」</span>
</div>
</div>

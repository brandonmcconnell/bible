## 公綿羊和公山羊的異象

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="但以理書 11:4; 但以理書 9:2; 但以理書 7:28"> 在看見先前的異象之後，我但以理在伯沙撒王執政第三年又看見一個異象。</span>
<span className="v" id="v2" data-v="2" data-xref="以斯帖記 1:2; 尼希米記 1:1; 創世記 10:22"> 我在異象中看見自己在以攔省的書珊城，又看見自己站在烏萊河畔。</span>
<span className="v" id="v3" data-v="3" data-xref="但以理書 8:20; 但以理書 10:5; 撒迦利亞書 6:1"> 我舉目觀看，見河邊站著一隻公綿羊，長著兩個長角，一角比另一角長，較長的角是後長出來的。</span>
<span className="v" id="v4" data-v="4" data-xref="但以理書 11:16; 但以理書 11:36; 但以理書 8:7"> 我看見這公綿羊向西方、北方和南方頂撞，沒有獸能抵擋牠，或逃脫牠的威力。牠隨心所欲，狂妄自大。</span>
<span className="v" id="v5" data-v="5" data-xref="但以理書 8:21; 但以理書 11:3; 但以理書 8:8"> 我正沉思的時候，忽然從西面出現一隻公山羊，穿越大地，腳不沾地奔來。牠雙眼之間有一個醒目的角。</span>
<span className="v" id="v6" data-v="6"> 這公山羊來到我之前看見站在河邊的雙角公綿羊那裡，憤怒地向牠頂去。</span>
<span className="v" id="v7" data-v="7" data-xref="但以理書 7:7; 但以理書 11:11; 約書亞記 8:20"> 我看見公山羊憤怒地頂向公綿羊，攻擊牠，折斷了牠的雙角。公綿羊無力抵擋公山羊，被撞倒在地，踐踏在腳下，無人能救牠脫離公山羊的威力。</span>
<span className="v" id="v8" data-v="8" data-xref="但以理書 7:2; 啟示錄 7:1; 但以理書 5:20"> 公山羊極其狂妄自大。但正值鼎盛之時，牠的大角突然折斷，在原處又長出四個醒目的角，朝著天的四方。</span>
<span className="v" id="v9" data-v="9" data-xref="但以理書 11:16; 以西結書 20:6; 以西結書 20:15"> 其中一個角又長出一個小角，向南方、東方和佳美之地<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「佳美之地」指以色列，下同11·16、41。">a</a></sup>擴張勢力。</span>
<span className="v" id="v10" data-v="10" data-xref="以賽亞書 14:13; 啟示錄 12:4; 但以理書 8:7"> 它長得高及天軍，將一些天軍和星宿拋到地上，用腳踐踏。</span>
<span className="v" id="v11" data-v="11" data-xref="但以理書 12:11; 啟示錄 13:5–7; 但以理書 8:25"> 它狂妄自大，與天軍的統帥比高，它廢除日常獻給祂的祭，毀壞祂的聖所。</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米書 12:1; 以賽亞書 59:14; 但以理書 11:31–36"> 因為反叛的緣故，天軍和日常所獻的祭都交給了它。它將真理拋在地上，它所行的無不順利。</span>
<span className="v" id="v13" data-v="13" data-xref="啟示錄 11:2; 啟示錄 6:10; 路加福音 21:24"> 接著，我聽見一位聖者在說話，另一位聖者問他：「異象中出現的有關日常所獻的祭，毀滅性的反叛和踐踏聖所及天軍的事要持續多久呢？」</span>
<span className="v" id="v14" data-v="14" data-xref="但以理書 12:7; 但以理書 7:25; 啟示錄 11:2–3"> 他對我說：「兩千三百個晝夜。之後，聖所才會潔淨。」</span>
</div>

## 解釋異象

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="但以理書 10:16; 啟示錄 1:13; 彼得前書 1:10–11"> 我但以理看見這異象，正想明白它的意思，忽然有一個外貌像人的站在我面前。</span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 1:19; 路加福音 1:26; 但以理書 8:2"> 我聽見有人聲從烏萊河兩岸之間呼喊：「加百列啊，要讓此人明白這異象。」</span>
<span className="v" id="v17" data-v="17" data-xref="但以理書 8:19; 但以理書 12:4; 哈巴谷書 2:3"> 於是，他朝我站的地方走來，當他走來的時候，我嚇得俯伏在地。他對我說：「人子啊，你要明白，這異象是關於末後的時期。」</span>
<span className="v" id="v18" data-v="18" data-xref="但以理書 10:18; 以西結書 2:2; 但以理書 10:16"> 他和我說話的時候，我伏在地上昏睡過去，他便輕拍我，扶我起來，</span>
<span className="v" id="v19" data-v="19" data-xref="哈巴谷書 2:3; 但以理書 11:27; 啟示錄 17:17"> 對我說：「我要告訴你將來上帝發烈怒的末了所發生的事，因為這異象是關於那定好的末後時期。</span>
<span className="v" id="v20" data-v="20" data-xref="但以理書 8:3; 但以理書 11:1–2"> 你看見的那隻有兩角的公綿羊指瑪代和波斯的諸王。</span>
<span className="v" id="v21" data-v="21" data-xref="但以理書 10:20; 但以理書 11:3; 但以理書 8:5–8"> 公山羊指希臘王，在牠雙眼之間的大角指第一個王。</span>
<span className="v" id="v22" data-v="22" data-xref="但以理書 11:4; 但以理書 8:3; 但以理書 8:8"> 大角折斷後，從原處長出四個角表示四個國必從這國興起，但都不及這國強大。</span>
<span className="v" id="v23" data-v="23" data-xref="啟示錄 13:11–14; 帖撒羅尼迦後書 2:9–11; 啟示錄 19:20"> 在四國的末期，人們惡貫滿盈的時候，必有一個面貌兇惡、詭計多端的王興起。</span>
<span className="v" id="v24" data-v="24" data-xref="但以理書 8:12; 但以理書 11:31–36; 但以理書 7:25"> 他勢力強大，卻不是靠自己的力量。他必帶來可怕的毀滅，而且凡事亨通，他必毀滅強者和聖民。</span>
<span className="v" id="v25" data-v="25" data-xref="但以理書 8:11; 啟示錄 17:14; 約伯記 34:20"> 他靠陰謀詭計得逞，心高氣傲，乘人不備突然毀滅許多人，甚至要攻擊萬君之君，然而他終必被擊垮，但並非被人的手擊垮。</span>
<span className="v" id="v26" data-v="26" data-xref="但以理書 10:1; 但以理書 12:9; 但以理書 12:4"> 有關兩千三百個晝夜的異象是真的。但你要保密，因為這指的是遙遠的將來。」</span>
<span className="v" id="v27" data-v="27" data-xref="但以理書 7:28; 哈巴谷書 3:16; 但以理書 8:7"> 我但以理精疲力盡，病了幾天。後來我起來照常辦理王的事務，但我對這異象感到驚奇不已，不明白它的意思。</span>
</div>

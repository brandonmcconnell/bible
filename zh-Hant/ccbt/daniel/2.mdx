## 尼布甲尼撒的夢

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="但以理書 4:5; 以斯帖記 6:1; 約伯記 33:15–17"> 尼布甲尼撒在執政第二年做了夢，心裡煩亂，無法入睡，</span>
<span className="v" id="v2" data-v="2" data-xref="但以理書 1:20; 但以理書 4:6; 創世記 41:8"> 便派人召來術士、巫師、行法術的和占星家<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「占星家」亞蘭文作「迦勒底人」，同下2·4、5、10節；3·8；4·7；5·7、11。">a</a></sup>，為他解夢。他們都來到王面前。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 40:8; 創世記 41:15; 但以理書 4:5"> 王對他們說：「我做了一個夢，心裡煩亂，想知道夢的意思。」</span>
<span className="v" id="v4" data-v="4" data-xref="但以理書 3:9; 但以理書 5:10; 以斯拉記 4:7"> 占星家用亞蘭話對王說：「願王萬歲！請將夢告訴僕人，僕人好解釋夢的意思。」</span>
<span className="v" id="v5" data-v="5" data-xref="但以理書 3:29; 以斯拉記 6:11; 列王紀下 10:27"> 王對占星家說：「我的旨意已定，你們若不能將夢和夢的意思告訴我，必被碎屍萬段，你們的家必淪為廢墟。</span>
<span className="v" id="v6" data-v="6" data-xref="但以理書 5:7; 但以理書 2:48; 但以理書 5:29"> 你們若能將夢和夢的意思告訴我，我必給你們禮物、賞賜和極大的尊榮。所以你們要將夢和夢的意思告訴我。」</span>
<span className="v" id="v7" data-v="7" data-xref="但以理書 2:4; 但以理書 2:9; 傳道書 10:4"> 他們再次對王說：「請王將夢告訴僕人，僕人好解釋夢的意思。」</span>
<span className="v" id="v8" data-v="8" data-xref="歌羅西書 4:5; 以弗所書 5:16"> 王說：「我敢肯定，你們是在拖延時間，因為你們知道我的旨意已定，</span>
<span className="v" id="v9" data-v="9" data-xref="以賽亞書 41:23; 但以理書 7:25; 以斯帖記 4:11"> 你們若不將夢告訴我，我必懲治你們。你們串通起來在我面前胡言亂語，以拖待變。現在將夢告訴我，我就相信你們能解夢。」</span>
<span className="v" id="v10" data-v="10" data-xref="但以理書 2:27"> 占星家說：「王所要求的，世上無人能做到，因為再偉大、再有權勢的君王，也沒問過術士、巫師或占星家這樣的事。</span>
<span className="v" id="v11" data-v="11" data-xref="但以理書 5:11; 以賽亞書 57:15; 創世記 41:39"> 王問的事太難，除了不在人間居住的神明外，無人能為王解答。」</span>
<span className="v" id="v12" data-v="12" data-xref="但以理書 3:13; 馬太福音 2:16; 但以理書 3:19"> 王大怒，下令處死巴比倫所有的智者。</span>
<span className="v" id="v13" data-v="13" data-xref="但以理書 1:19–20; 以斯帖記 3:12–15; 以賽亞書 10:1"> 於是，處死智者的諭旨發出，有人便搜尋但以理和他的同伴，要處死他們。</span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="但以理書 2:24; 耶利米書 52:12; 撒母耳記下 20:16–22"> 王的護衛長亞略奉命去處死巴比倫的智者，但以理機智、謹慎地應對。</span>
<span className="v" id="v15" data-v="15"> 他問王的護衛長亞略：「王的命令為何這樣緊急？」亞略就把情況告訴他。</span>
<span className="v" id="v16" data-v="16" data-xref="但以理書 1:18–19; 但以理書 2:9–11"> 但以理便進宮求王寬限，以便為王解夢。</span>
<span className="v" id="v17" data-v="17" data-xref="但以理書 1:6–7; 但以理書 3:12; 但以理書 1:11"> 然後，他回到居所將這事告訴同伴哈拿尼雅、米沙利和亞撒利雅，</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米書 33:3; 馬太福音 18:19; 馬太福音 18:12"> 要同伴祈求天上的上帝施憐憫，顯明這奧秘，以免他們和其他巴比倫的智者一起被殺。</span>
<span className="v" id="v19" data-v="19" data-xref="民數記 12:6; 阿摩司書 3:7; 但以理書 7:7"> 這奧秘在夜間的異象中向但以理顯明，他便頌讚天上的上帝，</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 113:2; 詩篇 145:1–2; 啟示錄 5:12"> 說：<br /><span className="pl pl-1">「上帝的名永永遠遠當受稱頌，</span><br /><span className="pl pl-1">因為智慧和能力都屬於祂。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 75:5–7; 詩篇 31:14–15; 詩篇 113:7–8"> <span className="pl pl-1">祂改變時令和季節，廢王立王，</span><br /><span className="pl pl-1">賜智慧給智者，賜知識給哲士。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="約伯記 12:22; 約翰一書 1:5; 耶利米書 23:24"> <span className="pl pl-1">祂顯明深奧隱秘之事，</span><br /><span className="pl pl-1">洞悉暗中的隱情，</span><br /><span className="pl pl-1">有光與祂同住。</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="但以理書 2:18; 出埃及記 3:15; 但以理書 2:29–30"> <span className="pl pl-1">我祖先的上帝啊，我感謝你，讚美你，</span><br /><span className="pl pl-1">因你賜我智慧和能力，</span><br /><span className="pl pl-1">應允我們的祈求，</span><br /><span className="pl pl-1">使我們明白王的夢。」</span></span>
</div>
</div>

## 但以理解夢

<div className="bt">
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="使徒行傳 27:24; 但以理書 2:12–14"> 於是，但以理去見王指派處死巴比倫智者的亞略，對他說：「不要處死巴比倫的智者，請帶我去見王，我要為王解夢。」</span>
<span className="v" id="v25" data-v="25" data-xref="哥林多前書 1:27–28; 但以理書 6:13; 但以理書 5:13"> 亞略急忙帶但以理去見王，對王說：「我在被擄的猶大人中找到一個能為王解夢的。」</span>
<span className="v" id="v26" data-v="26" data-xref="但以理書 1:7; 但以理書 5:16; 但以理書 5:12"> 王就問又名伯提沙撒的但以理：「你能將我做的夢和夢的意思告訴我嗎？」</span>
<span className="v" id="v27" data-v="27" data-xref="以賽亞書 47:12–14; 但以理書 2:2; 以賽亞書 44:25"> 但以理回答說：「沒有智者、術士、巫師或占星家可以解答王所問的奧秘，</span>
<span className="v" id="v28" data-v="28" data-xref="創世記 40:8; 阿摩司書 4:13; 但以理書 10:14"> 但天上的上帝能揭開奧秘，祂已把將來要發生的事告訴了王。王啊，你躺在床上時想到了將來的事，揭開奧秘的上帝已把將來的事指示給你。上帝將王做的夢啟示給我，並非因為我智慧超群，而是要讓王知道夢的意思和王的心思。以下是王在床上做的夢和腦中出現的異象。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="哈巴谷書 1:7; 以西結書 28:7; 但以理書 7:3–17"> 「王啊，你夢見一個高大宏偉、極其明亮的塑像站在你面前，相貌可怕，</span>
<span className="v" id="v32" data-v="32" data-xref="耶利米書 51:7; 但以理書 7:4–6; 啟示錄 17:4"> 有純金的頭、銀的胸和臂、銅的肚腹和大腿、</span>
<span className="v" id="v33" data-v="33" data-xref="但以理書 7:19–26; 但以理書 7:7–8; 但以理書 2:40–43"> 鐵的小腿和半鐵半泥的腳。</span>
<span className="v" id="v34" data-v="34" data-xref="但以理書 2:44–45; 但以理書 8:25; 撒迦利亞書 12:3"> 在你觀看的時候，有一塊非人手鑿出的石頭砸在塑像半鐵半泥的腳上，砸碎了腳。</span>
<span className="v" id="v35" data-v="35" data-xref="以賽亞書 2:2–3; 詩篇 37:10; 啟示錄 20:11"> 鐵、泥、銅、銀、金隨即粉碎，猶如夏天麥場上的糠秕，被風吹得無影無蹤。但打碎這像的石頭變成一座大山，充滿整個大地。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="但以理書 2:23–24"> 「這就是夢的內容。現在我們要為王解夢。</span>
<span className="v" id="v37" data-v="37" data-xref="以西結書 26:7; 耶利米書 27:6–7; 以斯拉記 7:12"> 王啊，你是王中之王，天上的上帝已將國度、權柄、能力和尊榮賜給你，</span>
<span className="v" id="v38" data-v="38" data-xref="但以理書 4:21–22; 詩篇 50:10–11; 耶利米書 27:5–7"> 也將居住在各地的世人、走獸和飛禽都交在你手中，讓你管理。你就是那金頭。</span>
<span className="v" id="v39" data-v="39" data-xref="但以理書 5:28–31; 以賽亞書 44:28–5; 但以理書 2:32"> 在你之後，必有另一國興起，不及你的國強大。之後是將要統治天下的第三個國，是銅的。</span>
<span className="v" id="v40" data-v="40" data-xref="但以理書 7:7; 但以理書 7:19–26; 但以理書 11:36–45"> 接著是堅如鐵的第四國，能擊垮、打碎列國，正如鐵能擊垮、打碎一切。</span>
<span className="v" id="v41" data-v="41" data-xref="啟示錄 17:12; 但以理書 2:33–35; 啟示錄 12:3"> 你看見半鐵半陶泥的腳和腳趾，表示那將是一個分裂的國。正如你看見鐵和泥混雜在一起，它必有鐵一般的力量。</span>
<span className="v" id="v42" data-v="42" data-xref="但以理書 7:24; 啟示錄 13:1"> 半鐵半泥的腳趾表示那國必半強半弱。</span>
<span className="v" id="v43" data-v="43"> 你看見鐵和泥混雜在一起，這表示那國的民族彼此混雜通婚，卻不能團結，正如鐵和泥無法混合。</span>
<span className="v" id="v44" data-v="44" data-xref="馬太福音 28:18; 路加福音 1:32–33; 但以理書 6:26"> 在以上列王統治的時候，天上的上帝必設立一個永不被毀的國，這國必不會落入其他民族手中。它將擊垮、消滅列國，並且永遠長存。</span>
<span className="v" id="v45" data-v="45" data-xref="以賽亞書 28:16; 創世記 41:32; 申命記 10:17"> 你看見那塊非人手從山中鑿出的石頭打碎鐵、銅、泥、銀和金。偉大的上帝已把將來的事告訴了王。這夢是真實的，解釋是可靠的。」</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="使徒行傳 10:25; 使徒行傳 14:13; 以斯拉記 6:10"> 尼布甲尼撒王俯伏在地，向但以理下拜，並下令給他獻供物和香。</span>
<span className="v" id="v47" data-v="47" data-xref="但以理書 2:22; 但以理書 2:28; 阿摩司書 3:7"> 王對但以理說：「你們的上帝真是萬神之神、萬王之主、奧秘的啟示者，因為你能揭開這個奧秘。」</span>
<span className="v" id="v48" data-v="48" data-xref="但以理書 2:6; 但以理書 4:9; 但以理書 5:11"> 王賜但以理高官及許多貴重的禮物，派他治理巴比倫全省，管理巴比倫所有的智者。</span>
<span className="v" id="v49" data-v="49" data-xref="但以理書 1:7; 以斯帖記 2:19; 但以理書 3:12–30"> 王又應允但以理的請求，派沙得拉、米煞和亞伯尼歌負責巴比倫省的事務。但以理仍在朝中供職。</span>
</div>

## 尼布甲尼撒的第二個夢

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="但以理書 6:25; 彼得前書 1:2; 但以理書 3:4"> 尼布甲尼撒王傳諭天下各族、各邦、各語種的人：「願你們大享平安！</span>
<span className="v" id="v2" data-v="2" data-xref="但以理書 3:26; 詩篇 66:16; 詩篇 71:18"> 我樂意向你們述說至高的上帝對我所行的神蹟奇事。</span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 145:13; 以賽亞書 25:1; 但以理書 2:44"> <span className="pl pl-1">「祂的神蹟何其偉大！</span><br /><span className="pl pl-1">祂的奇事何其可畏！</span><br /><span className="pl pl-1">祂的國度永遠長存，</span><br /><span className="pl pl-1">祂的統治直到萬代。</span></span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="以賽亞書 47:7–8; 帖撒羅尼迦前書 5:2–3; 詩篇 30:6–7"> 「我尼布甲尼撒安居在家，在宮中享受榮華。</span>
<span className="v" id="v5" data-v="5" data-xref="但以理書 2:1; 約伯記 7:13–14; 但以理書 2:28–29"> 但我做了一個夢，讓我害怕。我躺在床上的時候，腦中出現的情景和異象使我恐懼。</span>
<span className="v" id="v6" data-v="6" data-xref="但以理書 2:2; 創世記 41:7–8; 以賽亞書 8:19"> 我便召巴比倫所有的智者來為我解夢。</span>
<span className="v" id="v7" data-v="7" data-xref="以賽亞書 44:25; 但以理書 2:7; 創世記 41:8"> 術士、巫師、占星家和占卜者都來了，我將夢告訴他們，他們卻不能給我解夢。</span>
<span className="v" id="v8" data-v="8" data-xref="但以理書 1:7; 但以理書 5:14; 但以理書 4:18"> 最後但以理來到我面前，他又名伯提沙撒，取自我神明的名，他有聖潔神明的靈。我將夢告訴他，說，</span>
<span className="v" id="v9" data-v="9" data-xref="但以理書 2:48; 但以理書 5:11; 但以理書 4:8"> 『術士的首領伯提沙撒啊，我知道你有聖潔神明的靈，任何奧秘都難不倒你。請你為我解釋我夢中所見的異象。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="耶利米書 12:2; 但以理書 4:5; 詩篇 37:35–36"> 「『以下是我躺在床上時腦中出現的異象：我看見大地中央有棵非常高大的樹。</span>
<span className="v" id="v11" data-v="11" data-xref="但以理書 4:21–22; 申命記 9:1; 馬太福音 11:23"> 這樹長得蒼勁有力，高可參天，從地極都能看見。</span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 13:19; 耶利米哀歌 4:20; 以西結書 31:6–7"> 它的葉子美麗，果實纍纍，可作眾生的食物。野獸在它的蔭下躺臥，飛鳥在它的枝頭棲息，一切生命都從它那裡得到食物。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="申命記 33:2; 但以理書 8:13; 但以理書 7:1"> 「『我躺在床上時腦中出現了異象，我看見一位聖潔的守望者從天而降。</span>
<span className="v" id="v14" data-v="14" data-xref="馬太福音 3:10; 但以理書 4:23; 以西結書 31:12–13"> 他大聲說，砍倒那棵樹，削掉它的枝子，剝光它的葉子，拋散它的果子，使野獸逃離樹下，飛鳥離開枝頭。</span>
<span className="v" id="v15" data-v="15" data-xref="約伯記 14:7–9; 但以理書 4:25–27; 以西結書 29:14–15"> 但把樹樁留在地裡，用鐵環和銅環箍住留在野地的青草中，讓他被天上的露水浸濕，與野獸一起住在草中。</span>
<span className="v" id="v16" data-v="16" data-xref="但以理書 4:23; 啟示錄 12:14; 但以理書 4:25"> 要改變他的人心，給他一個獸心，達七年之久。</span>
<span className="v" id="v17" data-v="17" data-xref="但以理書 4:25; 但以理書 2:21; 詩篇 75:6–7"> 這是守望者的命令，是聖者的決定，要讓眾生知道至高者主宰世上萬國，祂要把國賜給誰就賜給誰，即使是最卑微的人。』</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="但以理書 5:15; 創世記 41:8; 但以理書 5:8"> 「這就是我尼布甲尼撒王所做的夢。伯提沙撒啊，你要為我解夢，因為我國中所有的智者都不能為我解夢。但是你能，因為你裡面有聖潔神明的靈。」</span>
</div>
</div>

## 但以理解夢

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="但以理書 8:27; 但以理書 7:28; 但以理書 4:24"> 但以理，又名伯提沙撒，一時非常驚訝，惶恐不安。王說：「伯提沙撒啊，不要因為這夢和夢的意思而惶恐不安。」伯提沙撒回答說：「我主啊，願這夢發生在恨你的人身上，夢的意思應驗在你的仇敵身上。</span>
<span className="v" id="v20" data-v="20" data-xref="但以理書 4:10–12; 以西結書 31:3; 以西結書 31:16"> 你夢見的樹蒼勁高大，高可參天，從地極都能看見。</span>
<span className="v" id="v21" data-v="21"> 它的葉子美麗，果實纍纍，可作眾生的食物。野獸住在它的蔭下，飛鳥宿在它的枝頭。</span>
<span className="v" id="v22" data-v="22" data-xref="但以理書 2:37–38; 撒母耳記下 12:7; 耶利米書 27:6–8"> 王啊，這蒼勁高大的樹就是你，你的威名高達穹蒼，你的權柄延至地極。</span>
<span className="v" id="v23" data-v="23" data-xref="但以理書 5:21; 但以理書 4:13–16"> 王看見聖潔的守望者從天而降，說，『將這樹砍倒、毀滅，但把樹樁用鐵環和銅環箍住留在野地的青草中，讓他被天上的露水浸濕，與野獸一起吃草七年。』</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="詩篇 107:40; 約伯記 40:11–12; 以賽亞書 46:10–11"> 「王啊，以下是夢的意思，是至高者裁定要臨到我主我王的事：</span>
<span className="v" id="v25" data-v="25" data-xref="但以理書 4:17; 耶利米書 27:5; 詩篇 83:18"> 你必從人群中被趕走，與野獸同住，像牛一樣吃草，被天上的露水浸濕，達七年之久，直到你知道至高者主宰世上萬國，祂要把國賜給誰就賜給誰。</span>
<span className="v" id="v26" data-v="26" data-xref="但以理書 4:15; 馬太福音 5:34; 馬太福音 21:20"> 守望者命令留下樹樁，表示等到你承認上天掌權後，你將重掌國權。</span>
<span className="v" id="v27" data-v="27" data-xref="以賽亞書 55:6–7; 約拿書 3:9; 使徒行傳 8:22"> 王啊，請接受我的勸諫，你要秉公行義，以斷絕罪惡；憐憫窮人，以除掉罪過。這樣，你的國運也許可以延續。」</span>
</div>
</div>

## 夢兆應驗

<div className="bt">
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="民數記 23:19; 撒迦利亞書 1:6; 箴言 10:24"> 這一切事果然發生在尼布甲尼撒王身上。</span>
<span className="v" id="v29" data-v="29" data-xref="啟示錄 2:21; 傳道書 8:11; 彼得前書 3:20"> 十二個月後，他在巴比倫王宮的屋頂散步時，</span>
<span className="v" id="v30" data-v="30" data-xref="箴言 16:18; 啟示錄 18:10; 路加福音 14:11"> 說：「這宏偉的巴比倫豈不是我用大能建立為京都，以顯我的威嚴和榮耀嗎？」</span>
<span className="v" id="v31" data-v="31" data-xref="使徒行傳 9:3–5; 啟示錄 16:7; 路加福音 12:20"> 話未說完，天上就有聲音傳來，說：「尼布甲尼撒王啊，你聽著，你已失去王權。</span>
<span className="v" id="v32" data-v="32" data-xref="耶利米書 27:5; 但以理書 5:21; 箴言 8:15–16"> 你必從人群中被趕走，與野獸同住，像牛一樣吃草，達七年之久，直到你知道至高者主宰世上萬國，祂要把國賜給誰就賜給誰。」</span>
<span className="v" id="v33" data-v="33" data-xref="但以理書 4:32; 但以理書 4:25; 但以理書 5:5"> 這話立刻應驗在尼布甲尼撒身上。他從人群中被趕走，像牛一樣吃草，身體被天上的露水浸濕，直到他的頭髮長如鷹毛，指甲長如鳥爪。</span>
</div>
<div className="bp poetry">
<span className="v" id="v34" data-v="34" data-xref="啟示錄 4:10; 耶利米書 10:10; 但以理書 12:7"> 「七年後，我尼布甲尼撒舉目望天，恢復了神智，便稱頌至高者，讚美、尊崇永活者。<br /><span className="pl pl-1">「祂的統治永無窮盡，</span><br /><span className="pl pl-1">祂的國度直到萬代。</span><br /></span>
<span className="v" id="v35" data-v="35" data-xref="約伯記 42:2; 詩篇 135:6; 詩篇 115:3"> <span className="pl pl-1">世人都微不足道，</span><br /><span className="pl pl-1">祂在天軍和世人中獨行其旨，</span><br /><span className="pl pl-1">無人能攔阻祂的手，</span><br /><span className="pl pl-1">或質問祂的作為。</span></span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="但以理書 4:34; 箴言 22:4; 但以理書 4:15–16"> 「那時，我恢復了神智，也恢復了我的威嚴和榮耀，重現我國度的輝煌。我的謀士和大臣都來朝見我，我重掌國權，權勢比以前更大。</span>
<span className="v" id="v37" data-v="37" data-xref="雅各書 4:6–7; 詩篇 33:4–5; 彼得前書 5:5–6"> 現在我尼布甲尼撒頌讚、尊崇、敬奉天上的王，因為祂的作為公正，祂行事公平，能夠貶抑行為驕傲的人。」</span>
</div>
</div>

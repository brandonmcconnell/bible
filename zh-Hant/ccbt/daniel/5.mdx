## 牆上寫字

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以斯帖記 1:3; 馬可福音 6:21–22; 以賽亞書 21:4–5"> 伯沙撒王盛宴款待一千大臣，與他們一同飲酒。</span>
<span className="v" id="v2" data-v="2" data-xref="但以理書 1:2; 列王紀下 24:13; 耶利米書 27:16–22"> 王暢飲的時候，命人將先王尼布甲尼撒從耶路撒冷聖殿中擄來的金銀器皿拿來，供他與大臣、王后和妃嬪用來飲酒。</span>
<span className="v" id="v3" data-v="3"> 於是，他們把從耶路撒冷上帝殿中擄來的金器拿來，王與大臣、王后和妃嬪便用這些器皿飲酒。</span>
<span className="v" id="v4" data-v="4" data-xref="但以理書 5:23; 哈巴谷書 2:19; 詩篇 135:15–18"> 他們一邊飲酒，一邊頌讚金、銀、銅、鐵、木、石所造的神明。</span>
<span className="v" id="v5" data-v="5" data-xref="但以理書 4:31; 但以理書 5:24–28; 約伯記 20:5"> 突然，有人的手指出現，在燈臺對面王宮的粉牆上寫字。王看見那隻手在寫字，</span>
<span className="v" id="v6" data-v="6" data-xref="以西結書 7:17; 但以理書 7:28; 那鴻書 2:10"> 臉色驟變，驚恐萬分，兩腿發軟，雙膝顫抖。</span>
<span className="v" id="v7" data-v="7" data-xref="但以理書 5:29; 但以理書 5:16; 但以理書 2:48"> 他大聲傳令，召來巫師、占星家和占卜者，對這些巴比倫的智者說：「誰能讀牆上的字，把意思告訴我，他必身穿紫袍，頸戴金鏈，在國中位居第三。」</span>
<span className="v" id="v8" data-v="8" data-xref="但以理書 2:27; 但以理書 4:7; 創世記 41:8"> 王所有的智者進來後，竟無人能讀懂或把意思告訴王。</span>
<span className="v" id="v9" data-v="9" data-xref="但以理書 5:6; 但以理書 2:1; 耶利米書 6:24"> 伯沙撒王愈發恐懼，臉色蒼白，他的大臣都不知所措。</span>
<span className="v" id="v10" data-v="10" data-xref="但以理書 3:9; 但以理書 6:6; 但以理書 2:4"> 太后聽到王和大臣的喊聲，便來到宴會廳，對王說：「願王萬歲！不要驚慌失色。</span>
<span className="v" id="v11" data-v="11" data-xref="但以理書 4:8–9; 但以理書 2:47–48; 但以理書 4:18"> 你國中有一個人，他裡面有聖潔神明的靈。先王在世時，曾發現他有神明一樣的灼見、悟性和智慧。先王尼布甲尼撒立他為術士、巫師、占星家和占卜者的首領。</span>
<span className="v" id="v12" data-v="12" data-xref="但以理書 5:14; 但以理書 6:3; 但以理書 1:7"> 他有非凡的心智、知識和悟性，能解夢、釋謎、解惑。他叫但以理，先王給他取名叫伯提沙撒。現在可以把他召來，他必能解釋這些字的意思。」</span>
<span className="v" id="v13" data-v="13" data-xref="但以理書 6:13; 但以理書 5:11; 但以理書 2:25"> 於是，但以理被帶到王面前。王問他：「你就是先王從猶大擄來的但以理嗎？</span>
<span className="v" id="v14" data-v="14" data-xref="但以理書 5:11–12"> 我聽說你有神明的靈，有灼見、悟性和非凡的智慧。</span>
<span className="v" id="v15" data-v="15" data-xref="但以理書 5:7–8; 以賽亞書 47:12; 以賽亞書 29:10–12"> 我召智者和巫師來讀這些字，為我解釋字的意思，但他們都不能解釋。</span>
<span className="v" id="v16" data-v="16" data-xref="但以理書 5:7; 創世記 40:8; 但以理書 5:29"> 我聽說你能釋夢、解惑。你若能讀出牆上的字，把意思告訴我，你必身穿紫袍、頸戴金鏈，在我的國中位居第三。」</span>
<span className="v" id="v17" data-v="17" data-xref="列王紀下 5:16; 創世記 14:23; 列王紀下 5:26"> 但以理回答說：「你的禮物自己留著，你的賞賜可以給別人，不過我會為你讀這些字，解釋意思。</span>
<span className="v" id="v18" data-v="18" data-xref="但以理書 2:37–38; 但以理書 4:17; 但以理書 4:22–25"> 王啊，至高的上帝曾將國位、權力、尊榮、威嚴賜給你的先王尼布甲尼撒，</span>
<span className="v" id="v19" data-v="19" data-xref="但以理書 3:6; 但以理書 2:12–13; 但以理書 3:4"> 因為他有上帝所賜的大權，各族、各邦、各語種的人都在他面前恐懼顫抖。他操生殺大權，可隨意提升、罷黜。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及記 9:17; 耶利米書 13:18; 希伯來書 3:13"> 但他變得心高氣傲、剛愎自用、狂妄自大，因而被革除王位、剝去尊榮。</span>
<span className="v" id="v21" data-v="21" data-xref="但以理書 4:25; 以西結書 17:24; 但以理書 4:35"> 他從人群中被趕走，他的心變成獸心，他與野驢同住，像牛一樣吃草，被天上的露水浸濕，直到他知道至高的上帝主宰世上萬國，祂要把國賜給誰就賜給誰。</span>
<span className="v" id="v22" data-v="22" data-xref="歷代志下 33:23; 出埃及記 10:3; 雅各書 4:17"> 「伯沙撒啊，你是他的後裔，你雖然知道這一切事，仍不謙卑，</span>
<span className="v" id="v23" data-v="23" data-xref="約伯記 12:10; 但以理書 4:37; 耶利米書 10:23"> 竟在天上的主面前自大，命人拿來祂殿裡的器皿，供你和大臣、王后、妃嬪用來飲酒，並頌讚不能看、不能聽、一無所知、用金、銀、銅、鐵、木、石所造的神明，卻不尊崇賜你生命氣息、掌管你一舉一動的上帝。</span>
<span className="v" id="v24" data-v="24" data-xref="但以理書 5:5"> 「因此，上帝使指頭出現，寫下這些字，</span>
<span className="v" id="v25" data-v="25"> 就是『彌尼，彌尼，提客勒，烏法珥新』。</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米書 25:11–12; 以賽亞書 47:1–15; 耶利米書 27:7"> 這些字的意思是這樣，彌尼指上帝已經數算你國度的年日，使之到此為止；</span>
<span className="v" id="v27" data-v="27" data-xref="約伯記 31:6; 哥林多前書 3:13; 詩篇 62:9"> 提客勒指你已經被放在秤上稱了，發現分量不夠；</span>
<span className="v" id="v28" data-v="28" data-xref="以賽亞書 13:17; 但以理書 6:28; 但以理書 5:31"> 烏法珥新<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「烏法珥新」亞蘭文是「毗勒斯」，即「烏法珥新」的單數格式。">a</a></sup>指你的國要分裂，歸給瑪代人和波斯人。」</span>
<span className="v" id="v29" data-v="29" data-xref="但以理書 5:16; 但以理書 5:7"> 於是，伯沙撒下令給但以理穿上紫袍，戴上金項鏈，又宣告他在國中位居第三。</span>
<span className="v" id="v30" data-v="30" data-xref="耶利米書 51:31; 耶利米書 51:57; 耶利米書 51:39"> 當夜，迦勒底王伯沙撒被殺。</span>
<span className="v" id="v31" data-v="31" data-xref="但以理書 9:1; 但以理書 6:1"> 瑪代人大流士奪取了王權，時年六十二歲。</span>

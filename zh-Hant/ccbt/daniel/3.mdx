## 金像和火窯

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哈巴谷書 2:19; 耶利米書 16:20; 以賽亞書 46:6"> 尼布甲尼撒王造了一尊高二十七米、寬兩米七的金像，立在巴比倫省的杜拉平原。</span>
<span className="v" id="v2" data-v="2" data-xref="但以理書 3:27; 箴言 29:12; 列王紀上 12:32"> 他派人召集總督、行政官、省長、謀士、庫房官、審判官、司法官及各省的所有官員，前來參加他所立之像的敬奉禮。</span>
<span className="v" id="v3" data-v="3" data-xref="啟示錄 17:17; 啟示錄 17:13; 啟示錄 13:13–16"> 於是總督、行政官、省長、謀士、庫房官、審判官、司法官及各省的官員，齊來參加尼布甲尼撒王所立之像的敬奉禮，站在那像面前。</span>
<span className="v" id="v4" data-v="4" data-xref="但以理書 4:1; 但以理書 6:25; 彌迦書 6:16"> 傳令官大聲宣佈說：「各族、各邦、各語種的人啊，王有令，</span>
<span className="v" id="v5" data-v="5" data-xref="但以理書 3:15; 但以理書 3:10; 但以理書 3:7"> 『你們一聽見角、笛、弦琴、豎琴、瑟、笙等各種樂器奏響，就要叩拜尼布甲尼撒王所立的金像。</span>
<span className="v" id="v6" data-v="6" data-xref="馬太福音 13:50; 馬太福音 13:42; 耶利米書 29:22"> 不叩拜的人必立刻被拋進烈焰熊熊的火窯。』」</span>
<span className="v" id="v7" data-v="7" data-xref="啟示錄 17:8; 啟示錄 13:3; 啟示錄 13:8"> 於是，各族、各邦、各語種的人一聽見角、笛、弦琴、豎琴、瑟等各種樂器的聲音，就都叩拜尼布甲尼撒王所立的金像。</span>
<span className="v" id="v8" data-v="8" data-xref="以斯拉記 4:12–16; 但以理書 6:12–13; 以斯帖記 3:8–9"> 那時，有幾個占星家前來控告猶大人。</span>
<span className="v" id="v9" data-v="9" data-xref="但以理書 5:10; 但以理書 6:6; 但以理書 6:21"> 他們對尼布甲尼撒王說：「願王萬歲！</span>
<span className="v" id="v10" data-v="10" data-xref="但以理書 3:4–7; 但以理書 6:12; 以斯帖記 3:12–14"> 王啊，你已下令，角、笛、弦琴、豎琴、瑟、笙等各種樂器一奏響，每個人都要叩拜金像。</span>
<span className="v" id="v11" data-v="11"> 不叩拜的人必被扔進烈焰熊熊的火窯。</span>
<span className="v" id="v12" data-v="12" data-xref="但以理書 6:13; 但以理書 2:49; 使徒行傳 17:7"> 然而，王啊，有幾個猶大人，就是王委派負責巴比倫省事務的沙得拉、米煞和亞伯尼歌，卻不理會你的命令，不事奉你的神明，也不祭拜你立的金像。」</span>
<span className="v" id="v13" data-v="13" data-xref="但以理書 3:19; 但以理書 2:12; 以斯帖記 3:5–6"> 尼布甲尼撒王勃然大怒，下令將沙得拉、米煞、亞伯尼歌帶來。於是他們被帶到王面前。</span>
<span className="v" id="v14" data-v="14" data-xref="耶利米書 50:2; 但以理書 3:1; 以賽亞書 46:1"> 尼布甲尼撒問他們：「沙得拉、米煞和亞伯尼歌啊，你們真的不事奉我的神明，不祭拜我立的金像嗎？</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行傳 5:29; 歷代志下 32:15–17; 出埃及記 5:2"> 現在你們準備好，一聽見角、笛、弦琴、豎琴、瑟、笙等各種樂器的聲音，就要叩拜我造的像。不然，必立刻將你們扔進烈焰熊熊的火窯。那時什麼神明能從我手中救你們呢？」</span>
<span className="v" id="v16" data-v="16" data-xref="但以理書 1:7; 但以理書 3:12"> 沙得拉、米煞和亞伯尼歌答道：「尼布甲尼撒啊，我們無需為此事回答你。</span>
<span className="v" id="v17" data-v="17" data-xref="羅馬書 8:31; 路加福音 1:37; 希伯來書 7:25"> 王啊，我們若真被扔進烈焰熊熊的火窯，我們所事奉的上帝必能救我們脫離火窯，祂必從你手中救我們。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行傳 5:29–32; 馬太福音 10:39; 啟示錄 2:10–11"> 即或不然，王啊，你要明白，我們也不會事奉你的神明或祭拜你立的金像。」</span>
<span className="v" id="v19" data-v="19" data-xref="但以理書 3:13; 利未記 26:24; 箴言 21:24"> 尼布甲尼撒怒氣填胸，向沙得拉、米煞和亞伯尼歌大發雷霆，下令將火窯燒得比平時熱七倍，</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行傳 16:23; 使徒行傳 16:25; 但以理書 3:15"> 又命令軍中的勇士將沙得拉、米煞和亞伯尼歌綁起來，扔進烈焰熊熊的火窯。</span>
<span className="v" id="v21" data-v="21"> 這三人穿著外袍、褲子等衣物，戴著頭巾，被綁著扔進烈焰熊熊的火窯。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及記 12:33; 箴言 21:18; 箴言 11:8"> 因為王的命令緊急，窯燒得非常熱，火焰燒死了那些抬沙得拉、米煞和亞伯尼歌的人。</span>
<span className="v" id="v23" data-v="23" data-xref="但以理書 6:16–17; 耶利米書 38:6; 詩篇 34:19"> 沙得拉、米煞和亞伯尼歌三人被綁著落入烈焰熊熊的火窯。</span>
<span className="v" id="v24" data-v="24" data-xref="但以理書 6:7; 但以理書 6:22; 但以理書 3:9–10"> 這時，尼布甲尼撒王驚奇地跳起來，問謀士：「我們綁起來扔進火裡的不是三個人嗎？」他們答道：「王啊，是的。」</span>
<span className="v" id="v25" data-v="25" data-xref="以賽亞書 43:2; 使徒行傳 28:5; 馬可福音 16:18"> 王說：「看啊，我見有四個人在火中走來走去，沒有被綁著，也沒有被燒傷，第四個人的面貌好像神明的兒子。」</span>
<span className="v" id="v26" data-v="26" data-xref="但以理書 3:17; 以賽亞書 52:12; 啟示錄 19:5"> 於是，尼布甲尼撒走近火窯的門，喊道：「至高上帝的僕人沙得拉、米煞和亞伯尼歌啊，出來吧，到這裡來吧。」沙得拉、米煞和亞伯尼歌便從火中出來。</span>
<span className="v" id="v27" data-v="27" data-xref="以賽亞書 43:2; 希伯來書 11:34; 以賽亞書 26:11"> 那些總督、行政官、省長和王的謀士上前圍觀，見火焰沒有燒傷他們的身體，他們的頭髮沒有燒焦，衣服沒有燒壞，身上甚至沒有火燎的氣味。</span>
<span className="v" id="v28" data-v="28" data-xref="羅馬書 14:7–8; 詩篇 34:7–8; 詩篇 84:11–12"> 尼布甲尼撒說：「沙得拉、米煞和亞伯尼歌的上帝當受稱頌！祂差遣天使拯救祂的僕人。他們信靠祂，無視王命，寧肯捨命也不供奉、祭拜其他神明。</span>
<span className="v" id="v29" data-v="29" data-xref="但以理書 2:5; 詩篇 76:10; 申命記 32:31"> 現在我下令，不論何民、何邦、何族，若譭謗沙得拉、米煞和亞伯尼歌的上帝，必被碎屍萬段，他們的家必淪為廢墟，因為沒有別的神明能這樣施行拯救。」</span>
<span className="v" id="v30" data-v="30" data-xref="但以理書 2:49; 撒母耳記上 2:30; 但以理書 3:12"> 於是，王讓沙得拉、米煞、亞伯尼歌在巴比倫省身居高位。</span>

## 但以理為同胞禱告

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="但以理書 11:1; 但以理書 1:21; 但以理書 5:31–1"> 瑪代人亞哈隨魯的兒子大流士被立為迦勒底國王元年，</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米書 29:10; 耶利米書 25:11–12; 歷代志下 36:21"> 就是他統治的第一年，我但以理從經書上得知，按照耶和華給耶利米先知的話，耶路撒冷必荒涼七十年。</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米書 33:3; 耶利米書 29:10–13; 雅各書 5:16–18"> 我便禁食，身披麻衣，頭蒙灰塵，向主上帝禱告祈求。</span>
<span className="v" id="v4" data-v="4" data-xref="羅馬書 8:28; 出埃及記 20:6; 申命記 5:10"> 我向我的上帝耶和華禱告、認罪，說：「主啊，你是偉大而可畏的上帝，你向那些愛你、遵守你誡命的人守約，施慈愛。</span>
<span className="v" id="v5" data-v="5" data-xref="瑪拉基書 3:7; 但以理書 9:11; 但以理書 9:15"> 我們犯罪作惡，行為邪惡叛逆，偏離你的誡命和典章，</span>
<span className="v" id="v6" data-v="6" data-xref="但以理書 9:10; 歷代志下 36:15–16; 路加福音 20:10–12"> 沒有聽從你的僕人——眾先知奉你的名向我們的君王、首領、先祖及國中百姓所說的話。</span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 44:15; 耶利米書 3:25; 耶利米書 2:26–27"> 主啊，你是公義的，我們猶大人和耶路撒冷的居民，以及因對你不忠而被驅散到遠近各地的以色列人都受盡羞辱，正如今日一樣。</span>
<span className="v" id="v8" data-v="8" data-xref="但以理書 9:6–7; 耶利米哀歌 1:7–8; 耶利米哀歌 1:18"> 耶和華啊，我們和我們的君王、首領、先祖因得罪了你而滿臉羞愧。</span>
<span className="v" id="v9" data-v="9" data-xref="以弗所書 1:6–8; 但以理書 9:7; 但以理書 9:5"> 雖然我們背叛了主——我們的上帝，祂卻有憐憫和饒恕之心。</span>
<span className="v" id="v10" data-v="10" data-xref="但以理書 9:6; 列王紀下 18:12; 尼希米記 9:13–17"> 我們沒有聽從我們的上帝耶和華的話，沒有遵行祂藉著祂的僕人——眾先知給我們頒佈的律法。</span>
<span className="v" id="v11" data-v="11" data-xref="耶利米書 8:5–10; 以賽亞書 1:4–6; 申命記 28:15–68"> 以色列人都違背你的律法，偏離正道，不聽從你的話。你僕人摩西的律法書上所記載的咒詛和審判都落在了我們身上，因為我們得罪了你。</span>
<span className="v" id="v12" data-v="12" data-xref="以西結書 5:9; 耶利米哀歌 1:12; 約伯記 12:17"> 你把大災難降在我們身上，應驗了你警告我們和我們官長的話。耶路撒冷遭遇的災禍普天之下從未有過。</span>
<span className="v" id="v13" data-v="13" data-xref="申命記 28:15–68; 以賽亞書 9:13; 但以理書 9:11"> 這一切災禍降在了我們身上，正如摩西律法書的記載。然而，我們的上帝耶和華啊，我們卻沒有離開罪惡，也沒有認識你的真理並懇求你施恩。</span>
<span className="v" id="v14" data-v="14" data-xref="但以理書 9:7; 尼希米記 9:33; 詩篇 51:14"> 所以耶和華決意使災禍降在我們身上，因為我們的上帝耶和華的一切作為都是公義的，我們卻沒有聽從祂的話。</span>
<span className="v" id="v15" data-v="15" data-xref="尼希米記 9:10; 出埃及記 32:11; 尼希米記 1:10"> 「主——我們的上帝啊，你曾用大能的手把你的子民領出埃及，使自己威名遠揚，如同今日。我們卻犯罪作惡。</span>
<span className="v" id="v16" data-v="16" data-xref="撒迦利亞書 8:3; 約珥書 3:17; 詩篇 87:1–3"> 主啊，你一向公義，求你息怒，別再向你的聖山耶路撒冷城發烈怒。由於我們的罪惡和我們祖先的過犯，耶路撒冷和你的子民成了四圍鄰人嘲諷的對象。</span>
<span className="v" id="v17" data-v="17" data-xref="詩篇 80:19; 耶利米哀歌 5:18; 哥林多後書 1:20"> 我們的上帝啊，求你垂聽僕人的禱告祈求，為你自己的緣故，以容光照耀你荒涼的聖所。</span>
<span className="v" id="v18" data-v="18" data-xref="以賽亞書 37:17; 耶利米書 36:7; 列王紀下 19:16"> 我的上帝啊，求你側耳垂聽，睜眼眷顧我們荒涼的土地和屬於你名下的城。我們向你祈求，並非因為我們有什麼義行，而是因為你充滿憐憫。</span>
<span className="v" id="v19" data-v="19" data-xref="但以理書 9:18; 以弗所書 1:12; 阿摩司書 7:2"> 主啊，求你垂聽！主啊，求你赦免！主啊，求你垂聽並行動！我的上帝啊，為你自己的緣故，求你不要耽延，因為這城和這民都屬於你的名下。」</span>
</div>
</div>

## 加百列解釋預言

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="詩篇 145:18; 但以理書 9:3–4; 羅馬書 3:23"> 我繼續禱告，承認我和同胞以色列人的罪，為我上帝耶和華的聖山在祂面前祈求。</span>
<span className="v" id="v21" data-v="21" data-xref="路加福音 1:19; 但以理書 8:16; 列王紀上 18:36"> 我正禱告的時候，約在獻晚祭時，先前在異象中看見的那位加百列奉命疾飛而來。</span>
<span className="v" id="v22" data-v="22" data-xref="但以理書 9:24–27; 但以理書 10:21; 但以理書 8:16"> 他指教我說：「但以理啊，我現在來是要使你有智慧和悟性。</span>
<span className="v" id="v23" data-v="23" data-xref="但以理書 10:19; 馬太福音 24:15; 但以理書 10:11–12"> 你剛開始祈求，就已賜下答覆，我是來告訴你的，因為你倍受眷愛。所以你要留意以下的信息，明白異象的意思。</span>
<span className="v" id="v24" data-v="24" data-xref="希伯來書 9:11–14; 羅馬書 5:10; 耶利米書 23:5–6"> 「已經為你的同胞和聖城定了七十個七，以終結叛逆，除掉罪惡，贖盡過犯，帶來永遠的公義，封住異象和預言，膏抹至聖所<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「至聖所」或譯「至聖者」。">a</a></sup>。</span>
<span className="v" id="v25" data-v="25" data-xref="以斯拉記 4:24; 以賽亞書 9:6; 以賽亞書 55:4"> 你要知道，也要明白，從重建耶路撒冷的命令發出，到受膏的君王來臨，其間有七個七加六十二個七。耶路撒冷城及其廣場和壕溝必得重建，且是在艱難時期。</span>
<span className="v" id="v26" data-v="26" data-xref="以賽亞書 53:8; 那鴻書 1:8; 馬可福音 13:2"> 六十二個七之後，受膏者必被殺害，一無所有。另有一王要興起，他的臣民要毀滅這城和聖所。結局必如洪水沖來，戰爭將持續到末了，到處一片荒涼。這已經命定。</span>
<span className="v" id="v27" data-v="27" data-xref="馬太福音 24:15; 路加福音 21:20; 但以理書 12:11"> 那王必與許多人締結一七之久的盟約。一七之半，他必終止祭牲和供物，並且在聖殿里設立帶來毀滅的可憎之物，直到所定的結局臨到這可憎者。」</span>
</div>

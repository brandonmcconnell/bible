## 但以理被擄到巴比倫

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歷代志下 36:5–7; 列王紀下 24:1–2; 列王紀下 24:13"> 猶大王約雅敬執政第三年，巴比倫王尼布甲尼撒前來圍攻耶路撒冷。</span>
<span className="v" id="v2" data-v="2" data-xref="歷代志下 36:7; 撒迦利亞書 5:11; 耶利米書 27:19–20"> 主將猶大王約雅敬及上帝殿中的部分器具交在他手中。他把器具擄到巴比倫<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「巴比倫」希伯來文是「示拿」，巴比倫的別稱。">a</a></sup>的神廟，放在他神明的庫房裡。</span>
<span className="v" id="v3" data-v="3" data-xref="以賽亞書 39:7; 列王紀下 20:17–18; 列王紀下 24:15"> 王吩咐太監長亞施毗拿從以色列的王室和貴族中選一些人，</span>
<span className="v" id="v4" data-v="4" data-xref="但以理書 5:11; 使徒行傳 7:22; 箴言 22:29"> 即毫無殘疾、相貌英俊、學問淵博、聰慧善學、能在王宮服侍的青年，教他們迦勒底的語言和文字。</span>
<span className="v" id="v5" data-v="5" data-xref="但以理書 1:19; 列王紀上 10:8; 但以理書 1:8"> 王安排他們每日享用御用的膳食和酒。他們要受教養三年，期滿後好在王身邊供職。</span>
<span className="v" id="v6" data-v="6" data-xref="以西結書 14:14; 馬太福音 24:15; 但以理書 2:17"> 被選的人中有猶大人但以理、哈拿尼雅、米沙利和亞撒利雅。</span>
<span className="v" id="v7" data-v="7" data-xref="但以理書 5:12; 但以理書 4:8; 但以理書 2:49"> 太監長給他們起了新名字：稱但以理為伯提沙撒，哈拿尼雅為沙得拉，米沙利為米煞，亞撒利雅為亞伯尼歌。</span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 141:4; 以西結書 4:13–14; 利未記 11:45–47"> 然而，但以理決心不用王的膳食和酒，以免玷污自己。他請求太監長准許他不玷污自己。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 39:21; 箴言 16:7; 詩篇 106:46"> 上帝使但以理得到太監長的恩待和同情。</span>
<span className="v" id="v10" data-v="10" data-xref="馬太福音 6:16–18; 約翰福音 12:42–43; 箴言 29:25"> 不過，太監長對但以理說：「我懼怕我主我王，因為這是他指派給你們的飲食。如果他看見你們面容比同齡的青年憔悴，如何是好？你們會使我在王面前人頭難保。」</span>
<span className="v" id="v11" data-v="11"> 但以理便對太監長派來監管他、哈拿尼雅、米沙利和亞撒利雅的人說：</span>
<span className="v" id="v12" data-v="12" data-xref="羅馬書 14:2; 但以理書 1:16; 創世記 1:29–30"> 「求你試試在十天內只讓僕人們吃素菜、喝清水，</span>
<span className="v" id="v13" data-v="13"> 然後比較一下我們的面容和那些用御膳的青年的面容，看了之後再作決定。」</span>
<span className="v" id="v14" data-v="14"> 監管同意試他們十天。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及記 23:25; 箴言 10:22; 列王紀下 4:42–44"> 十天後，但以理和他三個朋友看起來比那些用御膳的青年更俊美健康。</span>
<span className="v" id="v16" data-v="16" data-xref="但以理書 1:12"> 於是，監管撤去了指派給他們的膳食和酒，只給他們素菜。</span>
<span className="v" id="v17" data-v="17" data-xref="列王紀上 3:12; 雅各書 1:5; 但以理書 2:21"> 上帝使這四個青年精通各種學問和知識。但以理能明白各種異象和夢兆。</span>
<span className="v" id="v18" data-v="18" data-xref="但以理書 1:5"> 到了尼布甲尼撒王規定青年們進宮的日子，太監長便帶他們去見王。</span>
<span className="v" id="v19" data-v="19" data-xref="箴言 22:29; 創世記 41:46; 但以理書 1:5"> 王與他們談話，發現無人比得上但以理、哈拿尼雅、米沙利和亞撒利雅，便把他們留在身邊供職。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及記 8:19; 以賽亞書 47:12–14; 列王紀上 4:29–34"> 王詢問他們各種各樣的事，發現他們的智慧和聰明比全國的術士和巫師高十倍。</span>
<span className="v" id="v21" data-v="21" data-xref="但以理書 6:28; 但以理書 10:1"> 直到塞魯士王元年，但以理仍在宮中供職。</span>
</div>

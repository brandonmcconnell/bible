## 但以理在獅子坑

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="出埃及記 18:21–22; 但以理書 5:31; 以斯帖記 1:1"> 大流士決定設立一百二十個總督治理全國。</span>
<span className="v" id="v2" data-v="2" data-xref="但以理書 2:48–49; 但以理書 5:29; 以斯帖記 7:4"> 總督之上設三個總長，負責管理總督，以維護王的統治，但以理是其中之一。</span>
<span className="v" id="v3" data-v="3" data-xref="但以理書 5:14; 箴言 22:29; 創世記 41:38–41"> 因為但以理有非凡的心智，遠超過其他總長和總督，王便考慮讓他治理全國。</span>
<span className="v" id="v4" data-v="4" data-xref="彼得前書 3:16; 腓立比書 2:15; 彼得前書 2:12"> 於是，其他總長和總督想在但以理的政務中找把柄控告他，卻找不到任何把柄或過失，因為他誠實可靠，毫無過失。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行傳 24:13–16; 以斯帖記 3:8; 使徒行傳 24:20–21"> 最後他們說：「除非我們從但以理上帝的律法下手，否則找不到指控他的把柄。」</span>
<span className="v" id="v6" data-v="6" data-xref="但以理書 2:4; 尼希米記 2:3; 但以理書 6:21"> 於是，這些總長和總督齊來見王，說：「願大流士王萬歲！</span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 59:3; 詩篇 62:4; 但以理書 3:27"> 所有總長、行政官、總督、謀士和省長都認為王應該頒布詔書並實施一道禁令，三十天內，任何人不得向王以外的神明或人禱告，違者必被扔進獅子坑。</span>
<span className="v" id="v8" data-v="8" data-xref="但以理書 6:15; 以斯帖記 1:19; 但以理書 6:12"> 王啊，求你頒佈並簽署這道禁令，使之不可更改，正如瑪代人和波斯人的律令是不可更改的。」</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 146:3; 詩篇 118:9; 詩篇 62:9–10"> 於是大流士王簽署了這道禁令。</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行傳 5:29; 詩篇 55:17; 帖撒羅尼迦前書 5:17–18"> 但以理知道王簽署禁令後，就回到家裡，他樓上房間的窗戶朝向耶路撒冷。他像往常一樣每日三次跪下向上帝禱告、感恩。</span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 37:32–33; 詩篇 10:9; 但以理書 6:6"> 那些官員一同來了，發現但以理向他的上帝禱告、祈求，</span>
<span className="v" id="v12" data-v="12" data-xref="但以理書 6:8; 但以理書 3:8–12; 以斯帖記 1:19"> 便去見王，提及王的禁令，說：「王啊，你不是簽署禁令，三十天內，任何人不得向王以外的神明或人禱告，違者必被扔進獅子坑嗎？」王說：「確有此事，按照瑪代人和波斯人的律令，這禁令不可更改。」</span>
<span className="v" id="v13" data-v="13" data-xref="但以理書 3:12; 使徒行傳 5:29; 但以理書 2:25"> 他們對王說：「王啊，被擄來的猶大人但以理不理會你和你的禁令，仍一日三次向他的上帝祈禱。」</span>
<span className="v" id="v14" data-v="14" data-xref="馬可福音 6:26; 馬太福音 27:17–24; 撒母耳記下 3:28–29"> 王聽了這些話，十分愁煩，一心想救但以理，直到日落都在籌劃解救之道。</span>
<span className="v" id="v15" data-v="15" data-xref="但以理書 6:12; 詩篇 94:20–21; 但以理書 6:8"> 那些人齊來見王，說：「王啊，要知道按照瑪代人和波斯人的律令，王頒佈的禁令和律例是不可更改的。」</span>
<span className="v" id="v16" data-v="16" data-xref="詩篇 37:39–40; 約伯記 5:19; 詩篇 91:14–16"> 王便下令把但以理帶來扔進獅子坑。他對但以理說：「願你一直事奉的上帝拯救你！」</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米哀歌 3:53; 使徒行傳 12:4; 馬太福音 27:60–66"> 有人搬來一塊石頭封住坑口，王用他和大臣的印加封，使懲辦但以理的事不可更改。</span>
<span className="v" id="v18" data-v="18" data-xref="以斯帖記 6:1; 但以理書 2:1; 撒母耳記下 12:16–17"> 王回宮後，整夜禁食，拒絕娛樂，無法入睡。</span>
<span className="v" id="v19" data-v="19" data-xref="帖撒羅尼迦前書 3:5; 馬可福音 16:2; 馬太福音 28:1"> 次日黎明，王起來匆忙趕往獅子坑，</span>
<span className="v" id="v20" data-v="20" data-xref="歷代志上 16:11; 希伯來書 7:25; 但以理書 6:27"> 到了坑邊，淒聲呼喊但以理：「永活上帝的僕人但以理啊，你一直事奉的上帝有沒有救你脫離獅子的口？」</span>
<span className="v" id="v21" data-v="21" data-xref="但以理書 2:4; 但以理書 6:6; 尼希米記 2:3"> 但以理對王說：「願王萬歲！</span>
<span className="v" id="v22" data-v="22" data-xref="提摩太後書 4:17; 希伯來書 11:33; 使徒行傳 12:11"> 我的上帝差遣天使封住了獅子的口，不讓牠們傷害我，因為我在上帝面前是清白的。王啊，我在你面前也沒有過錯。」</span>
<span className="v" id="v23" data-v="23" data-xref="歷代志上 5:20; 馬可福音 9:23; 但以理書 3:27–28"> 王非常高興，便命人把但以理從坑中拉上來。於是，但以理從坑中被拉了上來，他因為信靠他的上帝，身上毫無損傷。</span>
<span className="v" id="v24" data-v="24" data-xref="以賽亞書 38:13; 以斯帖記 7:10; 申命記 24:16"> 王下令把那些惡意控告但以理的人及其兒女妻子都帶來，扔進獅子坑。他們還沒到坑底，獅子便撲上去，咬碎了他們的骨頭。</span>
<span className="v" id="v25" data-v="25" data-xref="但以理書 4:1; 以斯拉記 1:1–2; 以斯帖記 3:12"> 後來，大流士王傳諭境內的各族、各邦、各語種的人，說：「願你們大享平安！</span>
<span className="v" id="v26" data-v="26" data-xref="但以理書 4:34; 路加福音 1:33; 但以理書 3:29"> 我下令，我統治的國民都要敬畏但以理的上帝，<br /><span className="pl pl-1">「因為祂是永活長存的上帝，</span><br /><span className="pl pl-1">祂的國度永不滅亡，</span><br /><span className="pl pl-1">祂的統治直到永遠。</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="但以理書 4:2–3; 詩篇 18:50; 使徒行傳 4:30"> <span className="pl pl-1">祂庇護、拯救，</span><br /><span className="pl pl-1">在天上地下行神蹟奇事，</span><br /><span className="pl pl-1">救但以理脫離獅子的口。」</span></span>
<span className="v" id="v28" data-v="28" data-xref="但以理書 1:21; 歷代志下 36:22–2; 以賽亞書 44:28–1"> 因此，在大流士和波斯人塞魯士執政期間，但以理凡事亨通。</span>

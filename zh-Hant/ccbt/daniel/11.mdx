<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="但以理書 9:1; 但以理書 5:31; 但以理書 10:18"> 「瑪代人大流士元年，我去幫助、護衛米迦勒。</span>
<span className="v" id="v2" data-v="2" data-xref="以斯拉記 4:5–6; 但以理書 8:26; 啟示錄 21:5"> 現在我要把真相告訴你。波斯將再有三位王興起，隨後的第四位王遠比其他王富有。他靠財富強盛後，便會煽動眾民去攻打希臘國。</span>
<span className="v" id="v3" data-v="3" data-xref="但以理書 11:16; 但以理書 11:36; 但以理書 8:21"> 那時必有一位英勇的王興起，執掌大權，隨心所欲。</span>
<span className="v" id="v4" data-v="4" data-xref="但以理書 8:22; 但以理書 8:8; 耶利米書 12:17"> 但他興起後不久，他的國必土崩瓦解，在天下一分為四，既不歸他的後代統治，也不如他掌權時強盛。因為他的國必被連根拔除，歸給外人。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="但以理書 11:14; 但以理書 11:11; 但以理書 11:25"> 「南方王必強盛，他的將領中將有一位比他更強盛，這人執掌王權，勢力強大。</span>
<span className="v" id="v6" data-v="6" data-xref="但以理書 11:13; 但以理書 11:40; 但以理書 11:7"> 若干年後，南方王將與北方王聯盟。南方王的女兒將到北方王那裡締結盟約。但她必保不住自己的勢力，王權也無法長久。她和她的隨從、父親及輔佐者必遭殺害。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="但以理書 11:38–39; 但以理書 11:19–20; 以賽亞書 9:14"> 「她家族中必有一人繼承王位，率軍攻打北方王的軍隊，侵入他的堡壘，擊敗他們，</span>
<span className="v" id="v8" data-v="8" data-xref="以賽亞書 37:19; 以賽亞書 46:1–2; 耶利米書 43:12–13"> 將他們的神像、鑄造的偶像及金銀寶器擄到埃及。此後數年，他不再去攻擊北方王。</span>
<span className="v" id="v9" data-v="9"> 後來，北方王必侵入南方王的國土，但終必撤回本國。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="耶利米書 51:42; 但以理書 11:7; 但以理書 11:26"> 「北方王的兒子們必發動戰爭，召集大軍，如洪水席捲而來，直打到南方王的堡壘。</span>
<span className="v" id="v11" data-v="11" data-xref="但以理書 8:7; 但以理書 11:5; 詩篇 33:16–17"> 南方王必大怒，出來迎戰北方王的大軍，並擊敗他們。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行傳 12:22–23; 列王紀下 14:10; 以賽亞書 10:7–12"> 南方王獲勝後必心高氣傲，殺戮成千上萬的人，但他的勝利不能持久。</span>
<span className="v" id="v13" data-v="13" data-xref="但以理書 4:16; 但以理書 12:7; 但以理書 11:6–7"> 因為北方王必召集更龐大的軍隊，並於數年後帶著大量裝備捲土重來。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="啟示錄 17:17; 使徒行傳 4:25–28"> 「那時，許多人必起來反抗南方王。你同胞中的殘暴之徒也必反叛，從而使異象應驗，但他們必失敗。</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米書 6:6; 以西結書 17:17; 以西結書 4:2"> 北方王必修築高臺攻取南方王的堅城，南方的軍兵必無力抵擋，就是精兵也抵擋不住。</span>
<span className="v" id="v16" data-v="16" data-xref="但以理書 8:9; 但以理書 11:36; 但以理書 11:3"> 北方王必為所欲為，所向無敵。他必侵佔佳美之地，手握毀滅之權。</span>
<span className="v" id="v17" data-v="17" data-xref="列王紀下 12:17; 以西結書 4:3; 以西結書 4:7"> 他決意傾全國之力而來，與南方王建立聯盟，並將自己的女兒嫁給南方王，旨在推翻他的國。但北方王的計劃必然失敗，毫無收益。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="何西阿書 12:14; 耶利米書 31:10; 西番雅書 2:11"> 「後來，他將轉而攻打沿海地區，征服許多地方。但一位將領必終結他的囂張氣焰，使他自取其辱。</span>
<span className="v" id="v19" data-v="19" data-xref="以西結書 26:21; 詩篇 37:36; 約伯記 20:8"> 他將返回本國的堡壘，從此一蹶不振，銷聲匿跡。</span>
<span className="v" id="v20" data-v="20" data-xref="以賽亞書 60:17; 但以理書 11:7; 申命記 15:2–3"> 繼承他王位的人將派稅吏橫徵暴斂，以維持王國的榮耀。但不久他必滅亡，並非死於民怨，也非死於戰爭。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="但以理書 11:34; 但以理書 8:25; 士師記 9:1–20"> 「接著繼位的是一個卑鄙的人。他無權繼位，卻乘人不備用奸計篡位。</span>
<span className="v" id="v22" data-v="22" data-xref="但以理書 8:10–11; 但以理書 11:10; 但以理書 9:26"> 他橫掃千軍，擊潰他們，包括盟國的王。</span>
<span className="v" id="v23" data-v="23" data-xref="但以理書 8:25; 帖撒羅尼迦後書 2:9; 詩篇 52:2"> 他與人結盟後，必行欺詐，藉不多的人掌握大權。</span>
<span className="v" id="v24" data-v="24" data-xref="但以理書 7:25; 箴言 23:7; 馬太福音 9:4"> 他必乘人不備入侵最富庶的地區，行他祖先從未行過的事，將擄掠的財物分給部下，並策劃攻打堡壘，但這都是短暫的。</span>
<span className="v" id="v25" data-v="25" data-xref="箴言 15:18; 但以理書 11:2; 箴言 28:25"> 他集中力量，鼓起勇氣，率領大軍進攻南方王。南方王也率領強大的軍隊迎戰，卻敵不過他，因為有人暗算南方王。</span>
<span className="v" id="v26" data-v="26" data-xref="但以理書 11:10; 但以理書 11:40; 撒母耳記下 4:2–12"> 南方王必遭親信暗算，全軍潰敗，許多人被殺。</span>
<span className="v" id="v27" data-v="27" data-xref="詩篇 12:2; 耶利米書 9:3–5; 哈巴谷書 2:3"> 兩個王心懷叵測，同席而坐，爾虞我詐，但都不成功，因為結局必在所定的時間到來。</span>
<span className="v" id="v28" data-v="28" data-xref="但以理書 11:30–32; 但以理書 8:24; 使徒行傳 3:25"> 北方王必帶著大量財物回國，但他決意反對聖約。他必任意妄為，然後返回本國。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="使徒行傳 17:26; 以賽亞書 14:31; 但以理書 11:25"> 「到了所定的時間，他必再次攻打南方，但結果與上次不同，</span>
<span className="v" id="v30" data-v="30" data-xref="創世記 10:4; 民數記 24:24; 耶利米書 2:10"> 因為基提的戰船必來攻擊他，使他喪膽而回。他必惱恨聖約，任意妄為，回來支持背棄聖約的人。</span>
<span className="v" id="v31" data-v="31" data-xref="但以理書 12:11; 但以理書 9:27; 馬太福音 24:15"> 他的軍隊必褻瀆作聖所的堡壘，廢除日常獻的祭，設立帶來毀滅的可憎之物。</span>
<span className="v" id="v32" data-v="32" data-xref="歷代志上 28:9; 詩篇 9:10; 約翰福音 17:3"> 他必花言巧語籠絡違背聖約的人，但認識上帝的人必奮起反抗。</span>
<span className="v" id="v33" data-v="33" data-xref="馬太福音 24:9; 約翰福音 16:2; 瑪拉基書 2:7"> 那些智者必教導許多民眾，但他們將在一段時間內被刀劍殺戮，或被燒死，或被擄去，或被搶掠。</span>
<span className="v" id="v34" data-v="34" data-xref="馬太福音 7:15; 羅馬書 16:18; 使徒行傳 20:29–30"> 他們倒下時會得到一點援助，許多人並非真心實意地加入他們的行列。</span>
<span className="v" id="v35" data-v="35" data-xref="撒迦利亞書 13:9; 瑪拉基書 3:2–4; 啟示錄 2:10"> 有些智者將被害，但這是為了熬煉、淨化他們，使他們潔白無瑕，一直到末了。因為結局必在所定的時間到來。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="啟示錄 13:5–6; 帖撒羅尼迦後書 2:4; 申命記 10:17"> 「北方王必任意妄為，自高自大，自以為超越一切神明，肆意詆譭萬神之神。他必亨通，一直到上帝發烈怒的日子結束。因為所定的必定成就。</span>
<span className="v" id="v37" data-v="37" data-xref="帖撒羅尼迦後書 2:4; 以賽亞書 14:13; 提摩太前書 4:3"> 他不尊崇他祖先的神明，也不尊崇婦女們愛慕的神明或其他任何神明，因為他自認為超越一切。</span>
<span className="v" id="v38" data-v="38" data-xref="啟示錄 17:1–5; 以賽亞書 44:9; 啟示錄 13:12–17"> 他反倒敬奉他祖先不認識的堡壘之神，向它獻上金銀寶石及貴重的禮物。</span>
<span className="v" id="v39" data-v="39" data-xref="啟示錄 18:9–13"> 他必靠外族神明的幫助攻打堅固的堡壘，將極大的尊榮賜給順從他的人，派他們治理民眾，分給他們土地作獎賞。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="但以理書 11:35; 但以理書 11:10; 以賽亞書 5:28"> 「到了末後，南方王必與北方王交戰。北方王必率領戰車、騎兵和大批戰船攻擊他，又如洪水般橫掃列國。</span>
<span className="v" id="v41" data-v="41" data-xref="耶利米書 48:47; 耶利米書 49:6; 以賽亞書 11:13–15"> 他必侵入佳美之地，殺死成千上萬的人，只有以東、摩押及亞捫人的首領得以逃脫。</span>
<span className="v" id="v42" data-v="42" data-xref="撒迦利亞書 10:10–11; 以西結書 29:14; 啟示錄 11:8"> 他必攻擊列國，埃及也無法逃脫。</span>
<span className="v" id="v43" data-v="43" data-xref="歷代志下 12:3; 那鴻書 3:9; 以西結書 30:4–5"> 他必掌管埃及的金銀財寶，利比亞人和古實人必歸順他。</span>
<span className="v" id="v44" data-v="44" data-xref="啟示錄 19:19–21; 啟示錄 16:12; 啟示錄 17:13"> 但從東方和北方傳來的消息必令他震驚，他必大怒，出兵殺戮、毀滅許多人。</span>
<span className="v" id="v45" data-v="45" data-xref="帖撒羅尼迦後書 2:4; 但以理書 8:25; 啟示錄 19:19–21"> 他必在海和榮美的聖山之間搭起他宮殿般的帳幕。但他必滅亡，無人相助。</span>
</div>
</div>

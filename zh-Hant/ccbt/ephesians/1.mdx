## 基督徒的屬靈恩福

<div className="bt">
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="彼得前書 1:3; 哥林多後書 1:3; 以弗所書 2:6"> 讚美我們主耶穌基督的父上帝！祂在基督裡賜給了我們天上各樣屬靈的恩福。</span>
<span className="v" id="v4" data-v="4" data-xref="提摩太後書 1:9; 羅馬書 8:28–30; 以弗所書 2:10"> 早在創造世界以前，祂已經在基督裡揀選了我們，使我們在祂面前成為聖潔無瑕的人。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="羅馬書 8:29–30; 以弗所書 1:11; 加拉太書 4:5–6"> 上帝因為愛我們，就按照祂自己美好的旨意，預定我們藉著耶穌基督得到作祂兒女的名分。</span>
<span className="v" id="v6" data-v="6" data-xref="羅馬書 3:22–26; 以弗所書 1:12; 歌羅西書 1:13"> 我們讚美祂奇妙無比的恩典，這恩典是上帝藉著祂的愛子賜給我們的。</span>
<span className="v" id="v7" data-v="7" data-xref="彼得前書 2:24; 羅馬書 3:24; 約翰一書 1:7–9"> 我們藉著祂愛子的血蒙救贖，過犯得赦免，這都是出於祂的洪恩。</span>
<span className="v" id="v8" data-v="8" data-xref="啟示錄 5:12; 以弗所書 3:10; 羅馬書 5:15"> 上帝用各種智慧和聰明把這恩典豐豐富富地賜給我們，</span>
<span className="v" id="v9" data-v="9" data-xref="歌羅西書 1:26–28; 羅馬書 16:25–27; 以弗所書 3:3–9"> 照著祂在基督裡所定的美好計劃，叫我們知道祂旨意的奧祕，</span>
<span className="v" id="v10" data-v="10" data-xref="歌羅西書 1:20; 腓立比書 2:9–10; 加拉太書 4:4"> 等所定的時候一到，叫天地萬物一同歸在基督名下。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="羅馬書 8:28; 彼得前書 1:4; 以賽亞書 46:10–11"> 我們也在基督裡被揀選成為祂的子民。這都是按自己旨意行萬事的上帝預先定下的計劃，</span>
<span className="v" id="v12" data-v="12" data-xref="以弗所書 1:6; 耶利米書 17:5–7; 以弗所書 1:13–14"> 好讓我們這些首先在基督裡得到盼望的人都頌讚祂的榮耀。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="哥林多後書 1:22; 以弗所書 4:30; 提摩太後書 2:19"> 你們聽過真理之道，就是那使你們得救的福音，而且也信了基督。你們既然信祂，就領受了上帝應許賜下的聖靈為印記。</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多後書 1:22; 哥林多後書 5:5; 以弗所書 4:30"> 聖靈是我們領受產業的擔保，直到上帝的子民得到救贖，使祂的榮耀得到頌讚。</span>
</div>
</div>

## 保羅的禱告

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="腓利門書 1:5; 歌羅西書 1:3–4; 帖撒羅尼迦後書 1:3"> 我聽到你們對主耶穌的信心和對眾聖徒的愛心後，</span>
<span className="v" id="v16" data-v="16" data-xref="羅馬書 1:8–9; 歌羅西書 1:9; 歌羅西書 1:3"> 不斷為你們感謝上帝，禱告的時候常常提到你們。</span>
<span className="v" id="v17" data-v="17" data-xref="以賽亞書 11:2; 雅各書 3:17–18; 歌羅西書 1:9–10"> 我求我們主耶穌基督的上帝——榮耀的父把賜智慧和啟示的靈給你們，好使你們更深地認識祂。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行傳 26:18; 哥林多後書 4:6; 路加福音 24:45"> 我也求上帝照亮你們心中的眼睛，使你們知道祂的呼召給你們帶來了何等的盼望，祂應許賜給眾聖徒的產業有何等豐盛的榮耀，</span>
<span className="v" id="v19" data-v="19" data-xref="腓立比書 2:13; 以弗所書 3:20; 歌羅西書 2:12"> 祂在我們這些信的人身上所運行的能力是何等浩大。</span>
<span className="v" id="v20" data-v="20" data-xref="希伯來書 10:12; 馬可福音 16:19; 詩篇 110:1"> 上帝曾用這大能使基督從死裡復活，使基督在天上坐在自己右邊，</span>
<span className="v" id="v21" data-v="21" data-xref="腓立比書 2:9–11; 歌羅西書 2:10; 歌羅西書 1:15–16"> 遠遠超越今生永世所有執政的、掌權的、有能力的、作主宰的和一切權勢。</span>
<span className="v" id="v22" data-v="22" data-xref="歌羅西書 1:18; 歌羅西書 2:10; 哥林多前書 15:25–27"> 祂又使萬物降服在基督腳下，使基督為教會作萬物的元首。</span>
<span className="v" id="v23" data-v="23" data-xref="歌羅西書 1:18–19; 約翰福音 1:16; 歌羅西書 2:9–10"> 教會是基督的身體，蘊涵著那無所不在、充滿萬物者的豐盛。</span>
</div>
</div>

## 行事與聖徒的身分相稱

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="約翰一書 4:11; 彼得前書 1:15–16; 以弗所書 4:32"> 因此，你們既然是上帝疼愛的兒女，就要效法上帝。</span>
<span className="v" id="v2" data-v="2" data-xref="約翰福音 13:34; 加拉太書 2:20; 歌羅西書 3:14"> 要以愛心待人，像基督愛我們一樣，祂為我們犧牲自己作為獻給上帝的馨香供物和祭物。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="歌羅西書 3:5; 以弗所書 5:5; 加拉太書 5:19–21"> 一切淫亂、污穢或貪婪的事在你們當中連提都不要提，才合乎聖徒的身分。</span>
<span className="v" id="v4" data-v="4" data-xref="歌羅西書 3:8; 以弗所書 4:29; 帖撒羅尼迦前書 5:18"> 污言穢語、愚昧粗俗的談笑都不合宜，總要說感恩的話才好。</span>
<span className="v" id="v5" data-v="5" data-xref="加拉太書 5:21; 哥林多前書 6:9–10; 以弗所書 5:3"> 因為你們清楚知道，淫亂的人、污穢的人，還有貪婪的人，就是拜偶像的人，在基督和上帝的國裡沒有立足之地。</span>
<span className="v" id="v6" data-v="6" data-xref="羅馬書 1:18; 歌羅西書 2:8; 馬太福音 24:4"> 不要被虛空的道理欺騙，因為上帝的烈怒必臨到做這些事的悖逆之人。</span>
<span className="v" id="v7" data-v="7" data-xref="啟示錄 18:4; 以弗所書 5:11; 提摩太前書 5:22"> 所以，你們不要與他們同流合污。</span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="約翰福音 8:12; 約翰一書 1:7; 使徒行傳 26:18"> 你們從前活在黑暗中，現在既然活在主的光明中，行事為人就該像光明的兒女。</span>
<span className="v" id="v9" data-v="9" data-xref="約翰一書 3:9–10; 加拉太書 5:22–23; 約翰三書 1:11"> 光明總是結出良善、公義和真理的果子。</span>
<span className="v" id="v10" data-v="10" data-xref="羅馬書 12:1–2; 希伯來書 12:28; 詩篇 19:14"> 你們要察驗什麼是主所喜悅的事，</span>
<span className="v" id="v11" data-v="11" data-xref="羅馬書 13:12; 提摩太前書 5:20; 帖撒羅尼迦後書 3:6"> 不可參與那些黑暗無益的事，反而要揭發，</span>
<span className="v" id="v12" data-v="12" data-xref="以弗所書 5:3; 耶利米書 23:24; 傳道書 12:14"> 因為那些人暗地裡做的事就是提起來都覺得可恥。</span>
<span className="v" id="v13" data-v="13" data-xref="約翰福音 3:20–21; 哥林多前書 4:5; 何西阿書 2:10"> 然而，一切事被光一照，都會真相大白，</span>
<span className="v" id="v14" data-v="14" data-xref="以賽亞書 60:1; 羅馬書 13:11–12; 以賽亞書 26:19"> 因為光能使一切顯明出來。因此有人說：<br /><span className="pl pl-1">「沉睡的人啊，醒來吧！</span><br /><span className="pl pl-1">從死人中起來吧，</span><br /><span className="pl pl-1">基督要光照你了！」</span></span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="歌羅西書 4:5; 雅各書 3:13; 腓立比書 1:27"> 因此，你們要注意自己的生活，不要像愚昧人，要像有智慧的人。</span>
<span className="v" id="v16" data-v="16" data-xref="歌羅西書 4:5; 阿摩司書 5:13; 約翰福音 12:35"> 要愛惜光陰，因為現今是個邪惡的世代。</span>
<span className="v" id="v17" data-v="17" data-xref="羅馬書 12:2; 帖撒羅尼迦前書 5:18; 歌羅西書 1:9"> 所以，不要做糊塗人，要明白主的旨意。</span>
<span className="v" id="v18" data-v="18" data-xref="箴言 20:1; 路加福音 1:15; 羅馬書 13:13"> 不要醉酒，醉酒會使人放蕩，要被聖靈充滿。</span>
<span className="v" id="v19" data-v="19" data-xref="歌羅西書 3:16; 哥林多前書 14:26; 詩篇 95:2"> 要用詩篇、聖詩、靈歌互相激勵，從心底唱出讚美主的旋律。</span>
<span className="v" id="v20" data-v="20" data-xref="歌羅西書 3:17; 帖撒羅尼迦前書 5:18; 希伯來書 13:15"> 凡事總要奉我們主耶穌基督的名感謝父上帝。</span>
</div>
</div>

## 夫婦之道

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="腓立比書 2:3; 以弗所書 5:24; 以弗所書 5:22"> 你們要存敬畏基督的心彼此順服。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="歌羅西書 3:18–1; 彼得前書 3:1–6; 提多書 2:5"> 你們作妻子的，要順服丈夫，如同順服主。</span>
<span className="v" id="v23" data-v="23" data-xref="哥林多前書 11:3–10; 歌羅西書 1:18; 以弗所書 1:22–23"> 因為丈夫是妻子的頭，正如基督是祂的身體——教會的頭，又是教會的救主。</span>
<span className="v" id="v24" data-v="24" data-xref="以弗所書 5:33; 歌羅西書 3:20; 提多書 2:7"> 教會怎樣順服基督，妻子也要照樣凡事順服丈夫。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="彼得前書 3:7; 歌羅西書 3:19; 以弗所書 5:28"> 你們作丈夫的，要愛妻子，正如基督愛教會，為教會捨己，</span>
<span className="v" id="v26" data-v="26" data-xref="希伯來書 10:22; 約翰福音 15:3; 以西結書 36:25"> 好藉著道用水洗淨教會，使她聖潔，</span>
<span className="v" id="v27" data-v="27" data-xref="歌羅西書 1:22; 希伯來書 9:14; 彼得前書 1:19"> 以便把聖潔、完美、沒有污點和皺紋等瑕疵的榮耀教會獻給祂自己。</span>
<span className="v" id="v28" data-v="28" data-xref="以弗所書 5:25; 馬太福音 19:5; 創世記 2:21–24"> 同樣，作丈夫的也要愛妻子如同愛自己的身體，愛妻子就是愛自己。</span>
<span className="v" id="v29" data-v="29" data-xref="以西結書 34:14–15; 以弗所書 5:31; 傳道書 4:5"> 從來沒有人會厭惡自己的身體，人會保養和愛惜身體，正如基督對待教會一樣，</span>
<span className="v" id="v30" data-v="30" data-xref="哥林多前書 6:15; 哥林多前書 12:12–27; 羅馬書 12:5"> 因為我們是祂身上的肢體。</span>
<span className="v" id="v31" data-v="31" data-xref="創世記 2:24; 馬太福音 19:5; 馬可福音 10:7–8"> 「因此，人要離開父母，與妻子結合，二人成為一體。」<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="創世記2·24。">a</a></sup></span>
<span className="v" id="v32" data-v="32" data-xref="啟示錄 21:2; 哥林多後書 11:2; 以賽亞書 54:5"> 這是一個極大的奧祕，然而我是指著基督和教會的關係說的。</span>
<span className="v" id="v33" data-v="33" data-xref="彼得前書 3:2–7; 以斯帖記 1:20; 以弗所書 5:25"> 總之，你們作丈夫的都要愛妻子如同愛自己，作妻子的也要敬重丈夫。</span>
</div>
</div>

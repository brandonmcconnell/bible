## 外族人的福音使者

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歌羅西書 1:24; 提摩太後書 1:8; 腓立比書 1:13–16"> 為此，我保羅為了把基督耶穌傳給你們外族人而作了囚犯。</span>
<span className="v" id="v2" data-v="2" data-xref="歌羅西書 1:25–27; 提摩太前書 1:11; 提摩太後書 1:11"> 相信你們已經聽說了，上帝委派我將祂的恩典傳給你們，</span>
<span className="v" id="v3" data-v="3" data-xref="加拉太書 1:12; 羅馬書 16:25; 以弗所書 1:9–11"> 藉著啟示讓我明白福音的奧祕，正如我前面簡要提過的。</span>
<span className="v" id="v4" data-v="4" data-xref="歌羅西書 4:3; 哥林多前書 4:1; 哥林多後書 11:6"> 你們讀過之後，就能明白我深知基督的奧祕。</span>
<span className="v" id="v5" data-v="5" data-xref="彼得前書 1:10–12; 彼得後書 3:2; 提多書 1:1–3"> 自古以來，上帝沒有讓人知道這奧祕，如今祂藉著聖靈將這奧祕啟示給祂的聖使徒和先知。</span>
<span className="v" id="v6" data-v="6" data-xref="加拉太書 3:26–29; 約翰一書 1:3; 約翰一書 2:25"> 這奧祕就是外族人能夠在基督耶穌裡藉著福音與以色列人同作後嗣，同為一體，同享應許。</span>
<span className="v" id="v7" data-v="7" data-xref="以弗所書 1:19; 以弗所書 3:20; 以弗所書 3:2"> 上帝運用大能賜給我恩典，叫我成為這福音的使者。</span>
<span className="v" id="v8" data-v="8" data-xref="歌羅西書 1:27; 哥林多前書 15:9; 以弗所書 2:7"> 我本來比最卑微的聖徒還卑微，卻蒙上帝賜我這恩典，讓我把基督那測不透的豐富傳給外族人，</span>
<span className="v" id="v9" data-v="9" data-xref="歌羅西書 1:26; 馬太福音 13:35; 提摩太後書 1:9"> 讓世人都明白世代隱藏在創造萬物的上帝裡面的奧祕，</span>
<span className="v" id="v10" data-v="10" data-xref="彼得前書 1:12; 以弗所書 6:12; 哥林多前書 2:7"> 目的是為了現在透過教會讓天上的執政者和掌權者認識上帝豐富的智慧。</span>
<span className="v" id="v11" data-v="11" data-xref="提摩太後書 1:9; 以弗所書 1:11; 以弗所書 1:4"> 上帝這樣做是按照祂在我們主基督耶穌裡所成就的永恆計劃。</span>
<span className="v" id="v12" data-v="12" data-xref="以弗所書 2:18; 羅馬書 5:2; 希伯來書 4:14–16"> 我們靠著基督、藉著信祂可以坦然無懼、篤定不疑地來到上帝面前。</span>
<span className="v" id="v13" data-v="13" data-xref="歌羅西書 1:24; 帖撒羅尼迦後書 3:13; 哥林多後書 1:6"> 所以，我請求各位不要因我為你們受苦而沮喪，這其實是你們的榮耀。</span>
</div>
</div>

## 基督的愛

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="詩篇 95:6; 以弗所書 1:16–19; 腓立比書 2:10"> 為此，我跪在創造天地萬物的父面前，</span>
<span className="v" id="v16" data-v="16" data-xref="歌羅西書 1:11; 腓立比書 4:13; 以賽亞書 40:29–31"> 祈求祂按照自己豐盛的榮耀，藉著祂的靈，以大能使你們內在的生命剛強起來，</span>
<span className="v" id="v17" data-v="17" data-xref="歌羅西書 2:7; 約翰一書 4:16; 約翰福音 14:23"> 使基督藉著你們的信心住在你們心裡，使你們在愛中扎根、堅立，</span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 103:11–12; 約伯記 11:7–9; 以弗所書 1:18–23"> 以便能夠與眾聖徒一同領悟基督的愛是多麼長闊高深，</span>
<span className="v" id="v19" data-v="19" data-xref="以弗所書 1:23; 歌羅西書 2:9–10; 歌羅西書 1:10"> 並知道基督的愛遠超越人的認知，好叫上帝無限的豐富充滿你們。</span>
<span className="v" id="v20" data-v="20" data-xref="哥林多後書 9:8; 羅馬書 4:21; 耶利米書 32:27"> 上帝照著運行在我們裡面的大能，能夠豐豐富富地成就一切，超過我們所求所想的。</span>
<span className="v" id="v21" data-v="21" data-xref="猶大書 1:25; 羅馬書 11:36; 彼得後書 3:18"> 願祂在教會中，在基督耶穌裡得到榮耀，直到世世代代，永永遠遠。阿們！</span>
</div>
</div>

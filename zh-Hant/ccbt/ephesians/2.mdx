## 靠恩典、憑信心

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歌羅西書 2:13; 以弗所書 2:5–6; 歌羅西書 3:1–4"> 你們從前死在過犯和罪惡之中。</span>
<span className="v" id="v2" data-v="2" data-xref="以弗所書 6:12; 約翰一書 5:19; 以弗所書 2:3"> 那時，你們隨從今世的風俗，順服在空中掌權的魔鬼，就是如今在一切悖逆上帝之人心中運行的邪靈。</span>
<span className="v" id="v3" data-v="3" data-xref="提多書 3:3; 以弗所書 4:22; 加拉太書 5:16–24"> 我們以前也在他們當中隨從本性的慾望，放縱肉體和心中的私慾，與其他人一樣生來就是惹上帝發怒的人。</span>
<span className="v" id="v4" data-v="4" data-xref="彼得前書 1:3; 以弗所書 1:7; 詩篇 86:15"> 然而上帝有豐富的憐憫，祂深愛我們，</span>
<span className="v" id="v5" data-v="5" data-xref="羅馬書 3:24; 以弗所書 2:8; 羅馬書 5:10"> 儘管我們死在過犯之中，祂仍然使我們與基督一同活了過來。你們得救是因為上帝的恩典。</span>
<span className="v" id="v6" data-v="6" data-xref="歌羅西書 3:1–3; 以弗所書 1:3; 羅馬書 6:4–5"> 在基督耶穌裡，上帝使我們與基督一同復活，一同坐在天上，</span>
<span className="v" id="v7" data-v="7" data-xref="提摩太前書 1:16–17; 提多書 3:4; 以弗所書 2:4"> 好藉著祂在基督耶穌裡向我們所施的恩慈，向後世顯明祂無比豐富的恩典。</span>
<span className="v" id="v8" data-v="8" data-xref="羅馬書 3:22–26; 以弗所書 2:5; 羅馬書 4:16"> 你們得救是靠恩典，憑信心。這不是出於你們自己，而是上帝的禮物；</span>
<span className="v" id="v9" data-v="9" data-xref="提摩太後書 1:9; 羅馬書 11:6; 提多書 3:3–5"> 也不是由於你們的行為，以免有人自誇。</span>
<span className="v" id="v10" data-v="10" data-xref="腓立比書 2:13; 歌羅西書 1:10; 希伯來書 13:21"> 我們是上帝的傑作，是在基督耶穌裡創造的，為要完成上帝預先安排給我們的美好工作。</span>
</div>
</div>

## 在基督裡合而為一

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="歌羅西書 2:11; 歌羅西書 2:13; 歌羅西書 3:11"> 因此，你們要記住，從前按照肉體來說你們是外族人，那些肉體上受過人手所行割禮的以色列人，稱你們為「沒有受過割禮的」。</span>
<span className="v" id="v12" data-v="12" data-xref="加拉太書 4:8; 歌羅西書 1:21; 耶利米書 31:31–34"> 那時，你們與基督無關，也不是以色列人，在上帝應許的諸約上是局外人，你們活在世上沒有盼望，沒有上帝。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行傳 2:39; 歌羅西書 1:20–22; 歌羅西書 1:13–14"> 但你們這些從前遠離上帝的人，如今在基督耶穌裡，靠著祂所流的血已經被帶到上帝面前。</span>
<span className="v" id="v14" data-v="14" data-xref="加拉太書 3:28; 歌羅西書 3:11; 歌羅西書 3:15"> 因為基督耶穌親自給我們帶來了和平，用自己的身體拆毀了以色列人和外族人之間充滿敵意的隔牆，使雙方合而為一，</span>
<span className="v" id="v15" data-v="15" data-xref="歌羅西書 2:14; 加拉太書 3:10; 歌羅西書 1:21–22"> 並廢除了以誡命和規條為內容的律法制度。祂這樣做是為了在自己裡面把雙方造成一個新人，成就和平，</span>
<span className="v" id="v16" data-v="16" data-xref="歌羅西書 1:20–22; 羅馬書 5:10; 哥林多後書 5:18–21"> 並藉著十字架消滅彼此間的敵意，使雙方藉著一個身體與上帝和好。</span>
<span className="v" id="v17" data-v="17" data-xref="以賽亞書 57:19–21; 使徒行傳 10:36; 羅馬書 5:1"> 祂來傳揚這平安的福音給你們這些離上帝很遠的外族人，也給我們這些離上帝很近的以色列人。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前書 12:13; 以弗所書 3:12; 羅馬書 5:2"> 我們雙方都是靠著祂在同一位聖靈的引導下來到父上帝面前。</span>
<span className="v" id="v19" data-v="19" data-xref="腓立比書 3:20; 約翰一書 3:1; 加拉太書 6:10"> 因此，你們不再是外人或過客，你們與眾聖徒一樣是天國的子民，是上帝家裡的人了。</span>
<span className="v" id="v20" data-v="20" data-xref="彼得前書 2:4–5; 以賽亞書 28:16; 彼得前書 2:7–8"> 你們已被建立在眾使徒和先知們的根基上，基督耶穌自己是房角石。</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多前書 3:16–17; 哥林多前書 3:9; 哥林多後書 6:16"> 整座建築的各部分都靠祂連接在一起，逐漸成為主的聖殿。</span>
<span className="v" id="v22" data-v="22" data-xref="彼得前書 2:4–5; 哥林多前書 3:16; 約翰一書 4:16"> 你們也靠著祂被建造在一起，成為上帝藉著聖靈居住的地方。</span>
</div>
</div>

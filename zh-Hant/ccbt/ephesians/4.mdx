## 信徒同屬一體

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="歌羅西書 1:10; 腓立比書 1:27; 帖撒羅尼迦前書 2:12"> 所以，我這為主被囚禁的勸你們，既然蒙了上帝的呼召，就要過與所蒙的呼召相稱的生活。</span>
<span className="v" id="v2" data-v="2" data-xref="歌羅西書 3:12–13; 哥林多前書 13:7; 哥林多前書 13:4–5"> 凡事要謙卑、溫柔、忍耐，用愛心互相寬容，</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多前書 1:10; 歌羅西書 3:13–15; 哥林多前書 12:12–13"> 以和平彼此聯結，竭力持守聖靈所賜的合一。</span>
<span className="v" id="v4" data-v="4" data-xref="以弗所書 2:18; 羅馬書 12:4–5; 哥林多前書 12:4–13"> 正如你們蒙召後同有一個盼望、一個身體、一位聖靈、</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多前書 8:6; 哥林多前書 12:13; 彼得前書 3:21"> 一位主、一個信仰、一種洗禮、</span>
<span className="v" id="v6" data-v="6" data-xref="羅馬書 11:36; 瑪拉基書 2:10; 哥林多前書 8:6"> 一位上帝，就是萬人之父，祂超越萬物，貫穿萬物，且在萬物之中。</span>
<span className="v" id="v7" data-v="7" data-xref="彼得前書 4:10; 羅馬書 12:3; 哥林多前書 12:7–11"> 然而，我們各人都是按照基督所賜之量領受恩典。</span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 68:18; 歌羅西書 2:15; 撒母耳記上 30:26"> 因此聖經上說：<br /><span className="pl pl-1">「祂升上高天時，</span><br /><span className="pl pl-1">帶著許多俘虜，</span><br /><span className="pl pl-1">將恩賜賞給眾人。」</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="詩篇68·18。">a</a></sup></span>
<span className="v" id="v9" data-v="9" data-xref="約翰福音 3:13; 馬太福音 12:40; 箴言 30:4"> 既然說「升上」，豈不表示祂曾經降到地上嗎？</span>
<span className="v" id="v10" data-v="10" data-xref="希伯來書 7:26; 希伯來書 4:14; 以弗所書 1:20–23"> 降下的是祂，升到諸天之上的也是祂，這樣祂可以充滿萬物。</span>
<span className="v" id="v11" data-v="11" data-xref="耶利米書 3:15; 哥林多前書 12:28–29; 以弗所書 2:20"> 祂賜恩讓一些人作使徒，一些人作先知，一些人作傳福音的，一些人作牧師和教師，</span>
<span className="v" id="v12" data-v="12" data-xref="帖撒羅尼迦前書 5:11–14; 以弗所書 4:16; 哥林多前書 12:27"> 為要裝備聖徒，使他們各盡其職，建立基督的身體，</span>
<span className="v" id="v13" data-v="13" data-xref="歌羅西書 1:28; 約翰福音 17:21; 以弗所書 4:5"> 直到我們對上帝的兒子有一致的信仰和認識，逐漸成熟，達到基督那樣完美的生命。</span>
<span className="v" id="v14" data-v="14" data-xref="希伯來書 13:9; 羅馬書 16:17–18; 哥林多前書 14:20"> 這樣，我們就不再像小孩子，被各種異端邪說之風吹得飄來飄去，被人的陰謀詭計欺騙。</span>
<span className="v" id="v15" data-v="15" data-xref="約翰一書 3:18; 以弗所書 4:25; 撒迦利亞書 8:16"> 相反，我們說話要憑愛心堅持真理，在各方面都要追求長進，更像元首基督。</span>
<span className="v" id="v16" data-v="16" data-xref="歌羅西書 2:19; 約翰福音 15:5; 歌羅西書 2:2"> 整個身體靠祂巧妙地結合在一起，筋骨相連，各部位各盡其職，身體便漸漸成長，在愛中建立起來。</span>
</div>
</div>

## 新人新生命

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="羅馬書 1:21; 彼得前書 4:3–4; 帖撒羅尼迦前書 4:1–2"> 因此，我奉主的名鄭重勸告各位，不要再像不信的外族人一樣過著心靈空虛的日子。</span>
<span className="v" id="v18" data-v="18" data-xref="馬太福音 13:15; 以弗所書 2:12; 羅馬書 1:21–23"> 他們因為愚昧無知、心裡剛硬而理智受到蒙蔽，並與上帝所賜的生命隔絕了。</span>
<span className="v" id="v19" data-v="19" data-xref="歌羅西書 3:5; 羅馬書 1:24–26; 提摩太前書 4:2"> 他們麻木不仁，放縱情慾，沉溺於各種污穢的事。</span>
<span className="v" id="v20" data-v="20" data-xref="提多書 2:11–14; 約翰福音 6:45; 馬太福音 11:29"> 但基督並未這樣教導你們。</span>
<span className="v" id="v21" data-v="21" data-xref="約翰一書 5:20; 以弗所書 1:13; 希伯來書 3:7–8"> 你們如果聽過祂的事，領受了祂的教導，就是在祂裡面的真理，</span>
<span className="v" id="v22" data-v="22" data-xref="羅馬書 6:6; 希伯來書 12:1; 雅各書 1:21"> 就應該與從前的生活方式一刀兩斷，脫去因私慾的迷惑而漸漸敗壞的舊人，</span>
<span className="v" id="v23" data-v="23" data-xref="羅馬書 12:2; 羅馬書 8:6; 詩篇 51:10"> 洗心革面，</span>
<span className="v" id="v24" data-v="24" data-xref="歌羅西書 3:10–14; 哥林多後書 5:17; 以弗所書 2:10"> 穿上照著上帝形像所造的新人。這新人有從真理而來的公義和聖潔。</span>
<span className="v" id="v25" data-v="25" data-xref="歌羅西書 3:9; 撒迦利亞書 8:16; 箴言 12:22"> 所以不要再說謊，大家都要彼此說真話，因為我們都是一個身體的肢體。</span>
<span className="v" id="v26" data-v="26" data-xref="雅各書 1:19; 詩篇 4:4; 詩篇 37:8"> 不要因生氣而犯罪，<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="詩篇4·4。">b</a></sup>不要到日落時還怒氣未消，</span>
<span className="v" id="v27" data-v="27" data-xref="雅各書 4:7; 彼得前書 5:8; 以弗所書 6:16"> 不要讓魔鬼有機可乘。</span>
<span className="v" id="v28" data-v="28" data-xref="提摩太前書 6:18; 帖撒羅尼迦前書 4:11–12; 加拉太書 6:10"> 從前偷竊的要改過自新，自食其力，做正當事，以便能夠與有需要的人分享所得。</span>
<span className="v" id="v29" data-v="29" data-xref="歌羅西書 4:6; 帖撒羅尼迦前書 5:11; 傳道書 10:12"> 污言穢語一句都不可出口，要隨時隨地說造就人的好話，使聽的人得益處。</span>
<span className="v" id="v30" data-v="30" data-xref="帖撒羅尼迦前書 5:19; 以賽亞書 63:10; 以弗所書 1:13–14"> 不要讓上帝的靈擔憂，你們已經蓋上了聖靈的印記，將來必蒙救贖。</span>
<span className="v" id="v31" data-v="31" data-xref="歌羅西書 3:8; 傳道書 7:9; 提多書 3:2–3"> 要從你們當中除掉一切苦毒、惱恨、怒氣、爭吵、毀謗和邪惡。</span>
<span className="v" id="v32" data-v="32" data-xref="歌羅西書 3:12–13; 馬太福音 6:14–15; 馬可福音 11:25"> 總要以恩慈、憐憫的心彼此相待，要互相饒恕，正如上帝在基督裡饒恕了你們一樣。</span>
</div>

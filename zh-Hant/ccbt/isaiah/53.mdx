## 受苦的僕人

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="約翰福音 12:38; 羅馬書 10:16–17; 哥林多前書 1:18"> 誰相信我們所傳的呢？<br /><span className="pl pl-1">耶和華的臂膀向誰彰顯呢？</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="腓立比書 2:6–7; 以賽亞書 52:14; 約翰福音 1:10–14"> <span className="pl pl-1">祂像嫩芽一樣在耶和華面前長大，</span><br /><span className="pl pl-1">像生長在旱地裡的根。</span><br /><span className="pl pl-1">祂沒有俊美威榮的外表吸引我們，</span><br /><span className="pl pl-1">也沒有令我們仰慕的容貌。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="馬太福音 26:67; 約翰福音 1:10–11; 以賽亞書 53:10"> <span className="pl pl-1">祂被藐視，遭人厭棄，</span><br /><span className="pl pl-1">飽受痛苦，歷盡憂患。</span><br /><span className="pl pl-1">人們對祂不屑一顧，</span><br /><span className="pl pl-1">我們也不尊重祂。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v4" data-v="4" data-xref="彼得前書 2:24; 馬太福音 8:17; 加拉太書 3:13"> <span className="pl pl-1">其實祂擔當了我們的憂患，</span><br /><span className="pl pl-1">背負了我們的痛苦。</span><br /><span className="pl pl-1">我們卻以為是上帝責罰、</span><br /><span className="pl pl-1">擊打、苦待祂。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="彼得前書 2:24–25; 彼得前書 3:18; 馬太福音 20:28"> <span className="pl pl-1">誰知祂是因我們的過犯而被刺透，</span><br /><span className="pl pl-1">因我們的罪惡而被壓傷。</span><br /><span className="pl pl-1">我們因祂所受的刑罰而得到平安，</span><br /><span className="pl pl-1">因祂所受的鞭傷而得到醫治。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="彼得前書 2:25; 彼得前書 3:18; 詩篇 119:176"> <span className="pl pl-1">我們都像迷路的羊，</span><br /><span className="pl pl-1">各人偏行己路，</span><br /><span className="pl pl-1">但耶和華卻讓祂承擔我們眾人的罪惡。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="使徒行傳 8:32–33; 馬太福音 26:63; 彼得前書 2:23"> <span className="pl pl-1">祂遭欺壓、受痛苦，</span><br /><span className="pl pl-1">卻默然不語，</span><br /><span className="pl pl-1">像被人牽去宰殺的羔羊，</span><br /><span className="pl pl-1">又如在剪毛人手下一聲不吭的綿羊，</span><br /><span className="pl pl-1">祂默然不語。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="彼得前書 3:18; 使徒行傳 8:33; 馬太福音 26:65–66"> <span className="pl pl-1">祂受到欺壓和審判，被押去處死。</span><br /><span className="pl pl-1">祂那個世代的人誰會想到祂受鞭打、</span><br /><span className="pl pl-1">從世上被除去是因為我百姓的過犯呢？</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="馬太福音 27:57–60; 彼得前書 2:22; 約翰一書 3:5"> <span className="pl pl-1">雖然祂沒有做過殘暴之事，</span><br /><span className="pl pl-1">口中也沒有詭詐，</span><br /><span className="pl pl-1">人卻將祂與惡人同葬，</span><br /><span className="pl pl-1">與富人同墓。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="羅馬書 8:32; 哥林多後書 5:21; 加拉太書 3:13"> <span className="pl pl-1">然而，祂被壓傷、</span><br /><span className="pl pl-1">受痛苦是耶和華的旨意；</span><br /><span className="pl pl-1">祂的性命作了贖罪祭</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「祂的性命作了贖罪祭」或譯「耶和華以祂的性命作贖罪祭」。">a</a></sup><br /><span className="pl pl-1">。</span><br /><span className="pl pl-1">祂必看見自己的後裔，</span><br /><span className="pl pl-1">祂必長久活著。</span><br /><span className="pl pl-1">耶和華的旨意必在祂手中成就。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="羅馬書 5:18–19; 彼得前書 2:24; 以賽亞書 53:4–6"> <span className="pl pl-1">祂必看見自己勞苦的成果，</span><br /><span className="pl pl-1">並心滿意足。</span><br /><span className="pl pl-1">耶和華說：「我公義的僕人必憑祂的知識使許多人被算為義人，</span><br /><span className="pl pl-1">祂要擔當他們的罪惡。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 22:37; 希伯來書 9:28; 路加福音 23:32–34"> <span className="pl pl-1">因此，我要使祂與偉人同享尊榮，</span><br /><span className="pl pl-1">跟強者同分戰利品，</span><br /><span className="pl pl-1">因為祂獻出了自己的生命。</span><br /><span className="pl pl-1">祂被列在罪犯中，</span><br /><span className="pl pl-1">卻擔當了許多人的罪，</span><br /><span className="pl pl-1">又為罪犯代求。」</span></span>
</div>

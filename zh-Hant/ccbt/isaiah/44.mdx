## 以色列蒙揀選

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="以賽亞書 41:8; 羅馬書 11:5–6; 耶利米書 30:10"> <span className="pl pl-1">「我的僕人雅各，</span><br /><span className="pl pl-1">我所揀選的以色列啊，</span><br /><span className="pl pl-1">現在你要留心聽。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="耶利米書 1:5; 以賽亞書 43:1; 以賽亞書 46:3–4"> <span className="pl pl-1">造你、使你在母胎中成形、</span><br /><span className="pl pl-1">幫助你的耶和華說，</span><br /><span className="pl pl-1">『我的僕人雅各，</span><br /><span className="pl pl-1">我所揀選的耶書崙</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「耶書崙」是以色列的暱稱。">a</a></sup><br /><span className="pl pl-1">啊，</span><br /><span className="pl pl-1">不要害怕。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="約珥書 2:28; 使徒行傳 2:17; 以賽亞書 59:21"> <span className="pl pl-1">我要用水澆灌乾渴之地，</span><br /><span className="pl pl-1">使河流滋潤乾旱之土。</span><br /><span className="pl pl-1">我要用我的靈澆灌你的後裔，</span><br /><span className="pl pl-1">使我賜的福臨到你的子孫。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="以賽亞書 58:11; 詩篇 1:3; 詩篇 92:13–15"> <span className="pl pl-1">他們要滋長如青草，</span><br /><span className="pl pl-1">又如溪旁楊柳。』</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="哥林多後書 8:5; 撒迦利亞書 13:9; 彼得前書 2:9"> <span className="pl pl-1">這個說，『我屬於耶和華，』</span><br /><span className="pl pl-1">那個說，『我是雅各的子孫，』</span><br /><span className="pl pl-1">還有人手上寫著，『耶和華之民，』</span><br /><span className="pl pl-1">把自己歸在以色列名下。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="以賽亞書 41:4; 以賽亞書 43:10–11; 啟示錄 1:8"> <span className="pl pl-1">「耶和華，以色列的君王和救贖主——</span><br /><span className="pl pl-1">萬軍之耶和華說，</span><br /><span className="pl pl-1">『我是首先的，我是末後的，</span><br /><span className="pl pl-1">除我以外再沒有真神。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="以賽亞書 41:26; 以賽亞書 41:22; 以賽亞書 46:9–10"> <span className="pl pl-1">誰能與我相比？讓他公之於眾。</span><br /><span className="pl pl-1">讓他細說自從我設立這古老民族以來的往事，</span><br /><span className="pl pl-1">讓他宣告未來將要發生的事。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="以賽亞書 43:10; 撒母耳記上 2:2; 申命記 4:35"> <span className="pl pl-1">不要恐懼，不要害怕，</span><br /><span className="pl pl-1">我不是從古時告訴過你們嗎？</span><br /><span className="pl pl-1">你們是我的證人。</span><br /><span className="pl pl-1">除我以外還有真神嗎？</span><br /><span className="pl pl-1">沒有，沒有別的磐石，</span><br /><span className="pl pl-1">一個也沒有。』」</span></span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="以賽亞書 41:24; 耶利米書 10:14–15; 詩篇 97:7"> 製造偶像的真是無用，他們珍愛的偶像毫無價值。拜神像的人目盲眼瞎，愚昧無知，自找羞辱。</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米書 10:5; 哈巴谷書 2:18; 使徒行傳 19:26"> 製造神像、鑄造無益偶像的是誰？</span>
<span className="v" id="v11" data-v="11" data-xref="以賽亞書 42:17; 以賽亞書 45:16; 詩篇 97:7"> 看啊，拜偶像的人必羞愧，製造神像的工匠不過是人。讓他們聚在一起來對質吧，他們必恐懼、羞愧。</span>
<span className="v" id="v12" data-v="12" data-xref="以賽亞書 41:6–7; 以賽亞書 40:19; 以賽亞書 46:6–7"> 鐵匠拿起工具在炭火上工作，用他強壯的臂膀揮動鐵錘打造偶像。他饑餓時就會無力，口渴時就會疲乏。</span>
<span className="v" id="v13" data-v="13" data-xref="士師記 17:4–5; 詩篇 115:5–7; 使徒行傳 17:29"> 木匠拉線測量木料，用筆勾出輪廓，用圓規畫出模樣，用鑿子雕成人的樣子，形態逼真，放在廟宇裡。</span>
<span className="v" id="v14" data-v="14" data-xref="以賽亞書 40:20; 耶利米書 10:3–8; 何西阿書 4:12"> 他砍伐香柏木，或從林中選取柏木和橡木。他栽種松樹，雨水使它長大。</span>
<span className="v" id="v15" data-v="15" data-xref="歷代志下 25:14; 啟示錄 9:20; 士師記 2:19"> 這樹可以用來燒柴，他取一些木料生火取暖、烤餅，又製成神像來祭拜，雕成偶像來叩拜。</span>
<span className="v" id="v16" data-v="16"> 他用一半木頭生火烤肉，飽餐一頓，並用火取暖，說：「啊！我這裡有火，真暖和。」</span>
<span className="v" id="v17" data-v="17" data-xref="以賽亞書 45:20; 列王紀上 18:26; 但以理書 6:27"> 他用另一半木頭造了一個神明，作他的偶像，向它俯伏叩拜、禱告說：「你是我的神明，求你拯救我。」</span>
<span className="v" id="v18" data-v="18" data-xref="以賽亞書 6:9–10; 哥林多後書 4:3–4; 約翰福音 12:39–40"> 他們愚昧無知，因為他們的眼睛被封住以致看不見，他們的心竅被塞住以致不明白。</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 27:15; 列王紀上 11:7; 列王紀上 11:5"> 他們無人思想，無人明白，無人醒悟說：「我用一半木頭生火，在炭上烤餅烤肉吃，我豈能用另一半木頭造可憎的神像？我豈能向一塊木頭叩拜？」</span>
<span className="v" id="v20" data-v="20" data-xref="羅馬書 1:28; 約伯記 15:31; 何西阿書 12:1"> 他們以灰為食，心智迷糊，走入歧途，不能自救，也不會說：「我右手拿的神像豈不是假的嗎？」</span>
</div>
</div>

## 耶和華救贖以色列

<div className="bt">
<div className="bp poetry">
<span className="v" id="v21" data-v="21" data-xref="以賽亞書 44:1–2; 以賽亞書 49:15–16; 以賽亞書 43:15"> <span className="pl pl-1">「雅各啊，以色列啊，</span><br /><span className="pl pl-1">要記住這些事，</span><br /><span className="pl pl-1">因為你是我的僕人。</span><br /><span className="pl pl-1">我造了你，你是我的僕人；</span><br /><span className="pl pl-1">以色列啊，我必不忘記你。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="以賽亞書 43:25; 哥林多前書 6:20; 使徒行傳 3:18–19"> <span className="pl pl-1">我除去了你的過犯和罪惡，</span><br /><span className="pl pl-1">使它們如雲霧消散。</span><br /><span className="pl pl-1">歸向我吧，因為我救贖了你。」</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="以弗所書 1:6–7; 啟示錄 5:8–14; 詩篇 69:34"> <span className="pl pl-1">諸天啊，歌唱吧！</span><br /><span className="pl pl-1">因為耶和華成就了這事。</span><br /><span className="pl pl-1">地的深處啊，歡呼吧！</span><br /><span className="pl pl-1">眾山嶺和林中的樹木啊，</span><br /><span className="pl pl-1">你們都要歌唱！</span><br /><span className="pl pl-1">因為耶和華救贖了雅各，</span><br /><span className="pl pl-1">在以色列彰顯了祂的榮耀。</span><br /></span>

<span className="v" id="v25" data-v="25" data-xref="詩篇 33:10; 約伯記 5:12–14; 耶利米書 50:36"> <span className="pl pl-1">我使假先知的預兆無法應驗，</span><br /><span className="pl pl-1">使占卜者醜態百出；</span><br /><span className="pl pl-1">我顛覆智者的知識，</span><br /><span className="pl pl-1">使之愚不可及。</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="列王紀上 18:36–38; 以賽亞書 42:9; 尼希米記 1:3"> <span className="pl pl-1">我使我僕人的話應驗，</span><br /><span className="pl pl-1">使我使者的計劃成就。</span><br /><span className="pl pl-1">我說耶路撒冷必有人居住，</span><br /><span className="pl pl-1">我說猶大的城邑必重建起來，</span><br /><span className="pl pl-1">從廢墟中重建起來。</span><br /></span>

<span className="v" id="v28" data-v="28" data-xref="歷代志下 36:22–3; 以賽亞書 45:1; 以賽亞書 45:13"> <span className="pl pl-1">我說塞魯士是我的牧人，</span><br /><span className="pl pl-1">他必完成我的旨意，</span><br /><span className="pl pl-1">他會下令重建耶路撒冷，</span><br /><span className="pl pl-1">降旨奠定聖殿的根基。</span></span>

## 以色列必蒙拯救

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="以賽亞書 51:9; 以西結書 29:3; 以賽亞書 66:16"> 到那日，耶和華必用祂無堅不摧的利劍懲罰海怪，那蜿蜒、快速爬行的蛇。祂必殺死那海中的怪物。</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米書 2:21; 路加福音 20:9–18; 以賽亞書 5:1–7"> <span className="pl pl-1">到那日，你們要歌頌那佳美的葡萄園。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="以賽亞書 58:11; 約翰福音 15:1–2; 撒母耳記上 2:9"> <span className="pl pl-1">我耶和華是看守它的，</span><br /><span className="pl pl-1">我勤加澆灌，</span><br /><span className="pl pl-1">晝夜守護，</span><br /><span className="pl pl-1">不讓人毀壞。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="以賽亞書 10:17; 希伯來書 6:8; 馬太福音 3:12"> <span className="pl pl-1">我不再發怒。</span><br /><span className="pl pl-1">若是發現荊棘和蒺藜，</span><br /><span className="pl pl-1">我就對付它們，</span><br /><span className="pl pl-1">把它們燒光，</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="以賽亞書 25:4; 約伯記 22:21; 以弗所書 2:16–17"> <span className="pl pl-1">除非它們尋求我的庇護，</span><br /><span className="pl pl-1">要與我和好，</span><br /><span className="pl pl-1">要與我和好。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="以賽亞書 37:31; 何西阿書 14:5–6; 羅馬書 11:16–26"> <span className="pl pl-1">將來，雅各必扎根生長，</span><br /><span className="pl pl-1">以色列必發芽開花，</span><br /><span className="pl pl-1">果實遍地。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="以賽亞書 37:36–38; 耶利米書 51:24; 以賽亞書 10:20–25"> <span className="pl pl-1">耶和華豈像擊打以色列的敵人那樣擊打以色列人？</span><br /><span className="pl pl-1">祂豈像殺戮以色列的敵人那樣殺戮以色列人？</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="耶利米書 10:24; 耶利米書 4:11; 以西結書 19:12"> <span className="pl pl-1">祂與以色列人為敵，</span><br /><span className="pl pl-1">使他們被擄，</span><br /><span className="pl pl-1">祂驅逐他們離開本地，</span><br /><span className="pl pl-1">在刮東風的日子，用暴風吹散他們。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="羅馬書 11:27; 以賽亞書 48:10; 以賽亞書 17:8"> <span className="pl pl-1">雅各家的罪惡必藉此得到赦免，</span><br /><span className="pl pl-1">他們罪惡被除掉後的碩果是：</span><br /><span className="pl pl-1">把一切祭壇的石頭打得粉碎，如同石灰粉，</span><br /><span className="pl pl-1">推倒亞舍拉神像和香壇。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="以賽亞書 17:2; 耶利米書 26:18; 以賽亞書 32:13–14"> <span className="pl pl-1">堅城荒涼，居所被遺棄，</span><br /><span className="pl pl-1">如同曠野一樣杳無人煙。</span><br /><span className="pl pl-1">牛犢在那裡吃草、躺臥，</span><br /><span className="pl pl-1">吃光樹枝上的葉子。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="耶利米書 8:7; 以賽亞書 1:3; 以賽亞書 43:1"> <span className="pl pl-1">樹枝枯乾斷落，</span><br /><span className="pl pl-1">婦女拿去作柴燒。</span><br /><span className="pl pl-1">因為這是愚昧無知的民族，</span><br /><span className="pl pl-1">所以他們的創造主必不憐憫他們，</span><br /><span className="pl pl-1">也不向他們施恩。</span></span>
</div>

<span className="v" id="v13" data-v="13" data-xref="馬太福音 24:31; 利未記 25:9; 希伯來書 12:22"> 到那日，號角大響後，亞述地將要滅亡的以色列人和流亡到埃及的以色列人，都必來到耶路撒冷的聖山敬拜耶和華。</span>

## 北國必遭審判

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="何西阿書 7:5; 以賽亞書 28:7; 列王紀下 14:25–27"> 以法蓮酒徒引以為榮的華冠有禍了！<br /><span className="pl pl-1">它座落在醉酒者肥美的山谷頂上，</span><br /><span className="pl pl-1">它的榮美如將殘之花。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="以賽亞書 30:30; 那鴻書 1:8; 以西結書 13:11"> <span className="pl pl-1">看啊，主有一位強壯有力的人，</span><br /><span className="pl pl-1">他像冰雹和帶來毀滅的暴風，</span><br /><span className="pl pl-1">又像洶湧氾濫的洪水，</span><br /><span className="pl pl-1">他必把華冠摔在地上。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="以賽亞書 26:6; 希伯來書 10:29; 啟示錄 11:2"> <span className="pl pl-1">以法蓮酒徒引以為榮的華冠必被踐踏在腳下。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="那鴻書 3:12; 彌迦書 7:1; 以賽亞書 28:1"> <span className="pl pl-1">那榮美的將殘之花在肥沃的山谷之巔，</span><br /><span className="pl pl-1">它必像夏季到來之前早熟的無花果，</span><br /><span className="pl pl-1">人一看見它就把它摘下吞掉。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="彼得前書 5:4; 以賽亞書 62:3; 以賽亞書 60:19"> <span className="pl pl-1">到那日，萬軍之耶和華必作祂餘民的榮冠和華冕，</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 18:32–34; 約翰福音 5:30; 約書亞記 1:9"> <span className="pl pl-1">祂必使審判官公正斷案，</span><br /><span className="pl pl-1">賜力量給守城退敵之人。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="以賽亞書 56:10–12; 路加福音 21:34; 以賽亞書 19:14"> <span className="pl pl-1">但祭司和先知也因醉酒而搖搖晃晃，</span><br /><span className="pl pl-1">因烈酒而東倒西歪。</span><br /><span className="pl pl-1">他們因烈酒而搖搖晃晃、</span><br /><span className="pl pl-1">酩酊大醉，東倒西歪，</span><br /><span className="pl pl-1">他們錯解異象，糊塗判案。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="耶利米書 48:26; 箴言 26:11; 哈巴谷書 2:15–16"> <span className="pl pl-1">桌子上到處都是嘔吐之物，</span><br /><span className="pl pl-1">一片狼藉。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 131:2; 耶利米書 6:10; 約翰福音 12:38"> <span className="pl pl-1">他們抱怨說：</span><br /><span className="pl pl-1">「祂想教導誰知識呢？</span><br /><span className="pl pl-1">祂想把信息解釋給誰呢？</span><br /><span className="pl pl-1">是剛剛斷奶、離開母懷的嬰孩嗎？</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="以賽亞書 28:13; 提摩太後書 3:7; 耶利米書 11:7"> <span className="pl pl-1">因為祂的教導只是命命令令、命命令令、律律例例、律律例例、這裡一點、那裡一點。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v11" data-v="11" data-xref="哥林多前書 14:21; 申命記 28:49; 以賽亞書 33:19"> <span className="pl pl-1">因此，耶和華必用外族人的口和陌生的語言來教訓他們。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="馬太福音 11:28–29; 以賽亞書 30:15; 耶利米書 6:16"> <span className="pl pl-1">耶和華曾對他們說：</span><br /><span className="pl pl-1">「這是安歇之地，</span><br /><span className="pl pl-1">讓疲乏的人安歇吧。</span><br /><span className="pl pl-1">這是安歇之地。」</span><br /><span className="pl pl-1">他們卻不肯聽。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="馬太福音 13:14; 以賽亞書 6:9–10; 彼得後書 3:16"> <span className="pl pl-1">所以，對他們來說，</span><br /><span className="pl pl-1">耶和華的話成了命命令令、命命令令、律律例例、律律例例、這裡一點、那裡一點，</span><br /><span className="pl pl-1">以致他們走路時仰面跌倒，摔傷，落網，被捉。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="以賽亞書 28:22; 以賽亞書 29:20; 以賽亞書 1:10"> <span className="pl pl-1">因此，你們這些好譏諷、在耶路撒冷統管百姓的人啊，</span><br /><span className="pl pl-1">要聽耶和華的話。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="以賽亞書 8:7–8; 以西結書 13:22; 阿摩司書 2:4"> <span className="pl pl-1">你們說：</span><br /><span className="pl pl-1">「我們已經和死亡立約，</span><br /><span className="pl pl-1">與陰間結盟。</span><br /><span className="pl pl-1">勢不可擋的災難席捲而來時，</span><br /><span className="pl pl-1">我們會安然無恙，</span><br /><span className="pl pl-1">因為我們以謊言為庇護所，</span><br /><span className="pl pl-1">以詭詐為藏身處。」</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="詩篇 118:22; 使徒行傳 4:11–12; 彼得前書 2:6–8"> <span className="pl pl-1">所以主耶和華說：</span><br /><span className="pl pl-1">「看啊，我要在錫安放一塊基石，</span><br /><span className="pl pl-1">一塊經過考驗的石頭，</span><br /><span className="pl pl-1">一塊根基穩固的寶貴房角石，</span><br /><span className="pl pl-1">信靠的人必不會恐慌。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="列王紀下 21:13; 阿摩司書 7:7–9; 啟示錄 16:21"> <span className="pl pl-1">我必以公平為準繩，</span><br /><span className="pl pl-1">以公義作線錘。</span><br /><span className="pl pl-1">冰雹必砸碎你們虛謊的庇護所，</span><br /><span className="pl pl-1">洪水必淹沒你們的藏身處。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="以賽亞書 7:7; 以賽亞書 8:10; 以賽亞書 28:15"> <span className="pl pl-1">你們和死亡所立的約必被廢棄，</span><br /><span className="pl pl-1">與陰間的結盟必不能長久。</span><br /><span className="pl pl-1">勢不可擋的災難席捲而來時，</span><br /><span className="pl pl-1">你們必遭踐踏。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="哈巴谷書 3:16; 以賽亞書 36:22; 列王紀下 24:2"> <span className="pl pl-1">災難必不分晝夜、日復一日地襲來，</span><br /><span className="pl pl-1">每次襲來都必擄掠你們。」</span><br /><span className="pl pl-1">明白這信息的人都必驚恐萬分。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="以賽亞書 64:6; 哥林多前書 1:18–31; 羅馬書 9:30–32"> <span className="pl pl-1">你們的床太小，不能舒身；</span><br /><span className="pl pl-1">你們的被子太窄，不足裹身。</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="此處的床和被子象徵他們虛假的安全感。">a</a></sup><br /></span>
<span className="v" id="v21" data-v="21" data-xref="歷代志上 14:11; 約書亞記 10:12; 撒母耳記下 5:20"> <span className="pl pl-1">耶和華必像在毗拉心山一樣挺身而出，</span><br /><span className="pl pl-1">像在基遍谷一樣發怒，</span><br /><span className="pl pl-1">要完成祂奇異的作為，</span><br /><span className="pl pl-1">成就祂不尋常的工作。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="以賽亞書 10:22–23; 以賽亞書 24:1–23; 馬太福音 27:44"> <span className="pl pl-1">現在你們不要再譏諷了，</span><br /><span className="pl pl-1">以免你們的捆索更沉重，</span><br /><span className="pl pl-1">因為我已從主——萬軍之耶和華那裡聽到毀滅全國的諭旨。</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="以賽亞書 1:2; 耶利米書 22:29; 啟示錄 2:11"> <span className="pl pl-1">你們要側耳聽我的聲音，</span><br /><span className="pl pl-1">留心聽我的話語。</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="耶利米書 4:3; 何西阿書 10:11–12"> <span className="pl pl-1">難道農夫會一直耕地而不撒種嗎？</span><br /><span className="pl pl-1">難道他會一直犁地、耙地嗎？</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="以西結書 4:9; 馬太福音 23:23; 出埃及記 9:31–32"> <span className="pl pl-1">他整平土地之後，</span><br /><span className="pl pl-1">難道不種小茴香、大茴香，</span><br /><span className="pl pl-1">按行種小麥，</span><br /><span className="pl pl-1">在合適的地方種大麥，</span><br /><span className="pl pl-1">在田邊種粗麥嗎？</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="出埃及記 31:3–6; 出埃及記 36:2; 約伯記 39:17"> <span className="pl pl-1">因為他的上帝指點他，教導他耕種之道。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v27" data-v="27" data-xref="以賽亞書 41:15; 以賽亞書 27:7–8; 耶利米書 46:28"> <span className="pl pl-1">打小茴香不用大槌，用木棍；</span><br /><span className="pl pl-1">打大茴香不用石磙，用木棒。</span><br /></span>
<span className="v" id="v28" data-v="28" data-xref="哥林多前書 9:9–10; 馬太福音 3:12; 約翰福音 12:24"> <span className="pl pl-1">做餅的糧食要磨碎，</span><br /><span className="pl pl-1">沒有人會不停地在場上碾壓糧食。</span><br /><span className="pl pl-1">馬拉著石磙在場上軋過，</span><br /><span className="pl pl-1">也不會把糧食磨碎。</span><br /></span>
<span className="v" id="v29" data-v="29" data-xref="羅馬書 11:33; 耶利米書 32:19; 約伯記 5:9"> <span className="pl pl-1">這些知識都是萬軍之耶和華所賜的，</span><br /><span className="pl pl-1">祂有奇妙的謀略和偉大的智慧。</span></span>
</div>

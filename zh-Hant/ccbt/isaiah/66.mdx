## 耶和華的審判

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="使徒行傳 7:48–50; 使徒行傳 17:24; 馬太福音 5:34–35"> 耶和華說：<br /><span className="pl pl-1">「天是我的寶座，</span><br /><span className="pl pl-1">地是我的腳凳，</span><br /><span className="pl pl-1">你們要為我造怎樣的殿宇？</span><br /><span className="pl pl-1">哪裡可作我的安歇之處？</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="以賽亞書 57:15; 詩篇 34:18; 詩篇 51:17"> <span className="pl pl-1">這一切不都是我親手創造的嗎？</span><br /><span className="pl pl-1">這是耶和華說的。</span><br /><span className="pl pl-1">我看顧謙卑、悔過、</span><br /><span className="pl pl-1">對我的話心存敬畏的人。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v3" data-v="3" data-xref="箴言 15:8; 阿摩司書 5:21–22; 以賽亞書 1:11–15"> <span className="pl pl-1">「至於那些任意妄為、</span><br /><span className="pl pl-1">以行可憎之事為樂的人，</span><br /><span className="pl pl-1">他們宰牛就像殺人、</span><br /><span className="pl pl-1">獻羊羔就像打斷狗頸、</span><br /><span className="pl pl-1">獻穀物就像獻豬血、</span><br /><span className="pl pl-1">燒香就像頌讚偶像，</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="以賽亞書 65:12; 耶利米書 7:13; 箴言 10:24"> <span className="pl pl-1">我必重重地懲罰他們，</span><br /><span className="pl pl-1">使他們遭遇自己害怕的事。</span><br /><span className="pl pl-1">因為我呼喚，無人回應；</span><br /><span className="pl pl-1">我講話，無人聆聽。</span><br /><span className="pl pl-1">他們做我視為惡的事，</span><br /><span className="pl pl-1">專行令我不悅的事。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="約翰福音 15:18–20; 以賽亞書 66:2; 馬太福音 5:10–12"> <span className="pl pl-1">對耶和華的話心存敬畏的人啊，要聽祂的話：</span><br /><span className="pl pl-1">「你們的弟兄憎恨你們，</span><br /><span className="pl pl-1">因為我的名而棄絕你們，</span><br /><span className="pl pl-1">他們譏諷說，</span><br /><span className="pl pl-1">『願耶和華得榮耀，</span><br /><span className="pl pl-1">我們好看看你們的歡樂！』</span><br /><span className="pl pl-1">他們必受羞辱。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="約珥書 3:7–16; 阿摩司書 1:2; 以賽亞書 34:8"> <span className="pl pl-1">城中傳出喧鬧聲，</span><br /><span className="pl pl-1">殿中也傳出聲音，</span><br /><span className="pl pl-1">這是耶和華報應祂仇敵的聲音。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="啟示錄 12:1–5; 以賽亞書 54:1; 加拉太書 4:26"> <span className="pl pl-1">「錫安還沒有陣痛就分娩，</span><br /><span className="pl pl-1">還沒有感到產痛就生下男嬰。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="以賽亞書 64:4; 以賽亞書 49:20–22; 羅馬書 15:18–21"> <span className="pl pl-1">誰曾聽過看過這樣的事？</span><br /><span className="pl pl-1">一個國家能一日而生嗎？</span><br /><span className="pl pl-1">一個民族能在剎那間產生嗎？</span><br /><span className="pl pl-1">然而錫安剛開始陣痛就生下了兒女。」</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="以賽亞書 37:3; 創世記 18:14"> <span className="pl pl-1">耶和華說：「我既使她臨產，</span><br /><span className="pl pl-1">難道不讓她分娩嗎？」</span><br /><span className="pl pl-1">你的上帝說：「我既使她生產，</span><br /><span className="pl pl-1">難道封閉她的胎嗎？</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="詩篇 26:8; 申命記 32:43; 詩篇 137:6"> <span className="pl pl-1">「所有愛耶路撒冷的人啊，</span><br /><span className="pl pl-1">要與她一同歡喜，為她高興。</span><br /><span className="pl pl-1">所有為她悲哀的人啊，</span><br /><span className="pl pl-1">要與她盡情歡樂。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="以賽亞書 60:16; 約珥書 3:18; 以賽亞書 60:5"> <span className="pl pl-1">你們必在她舒適的懷抱裡得到乳養和滿足，</span><br /><span className="pl pl-1">欣然暢飲她充足的奶汁。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="以賽亞書 48:18; 以賽亞書 60:16; 以賽亞書 45:14"> <span className="pl pl-1">耶和華說：</span><br /><span className="pl pl-1">「看啊，我賜給她的平安如濤濤江河，</span><br /><span className="pl pl-1">使萬國的滾滾財富都歸給她。</span><br /><span className="pl pl-1">你們必被她抱在懷中乳養，</span><br /><span className="pl pl-1">搖在膝上。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="哥林多後書 1:4; 以賽亞書 51:3; 以賽亞書 40:1"> <span className="pl pl-1">母親怎樣撫慰孩子，</span><br /><span className="pl pl-1">我也怎樣撫慰你們，</span><br /><span className="pl pl-1">你們必在耶路撒冷得到安慰。」</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="撒迦利亞書 10:7; 以斯拉記 8:31; 以斯拉記 7:9"> <span className="pl pl-1">你們見到這些事，必滿心歡喜，</span><br /><span className="pl pl-1">身體如青草一樣充滿活力。</span><br /><span className="pl pl-1">耶和華必向祂的僕人彰顯大能，</span><br /><span className="pl pl-1">向祂的仇敵發怒。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="以賽亞書 30:33; 帖撒羅尼迦後書 1:6–9; 彼得後書 3:10–12"> <span className="pl pl-1">看啊，耶和華要在火中降臨，</span><br /><span className="pl pl-1">祂的戰車好像旋風。</span><br /><span className="pl pl-1">祂要發烈怒，用火焰懲罰。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="以西結書 38:21–22; 以賽亞書 30:30; 以西結書 39:2–10"> <span className="pl pl-1">因為耶和華要用火和劍審判世人，並殺死許多人。</span></span>
<span className="v" id="v17" data-v="17" data-xref="以賽亞書 65:3–4; 申命記 14:3–8; 以賽亞書 1:28–29"> 耶和華說：「那些人奉獻自己、潔淨自己，一個接一個進園中祭拜偶像，又吃豬肉、老鼠及其他可憎之物，他們必一同滅亡。</span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 86:9; 啟示錄 11:15; 哥林多後書 4:4–6"> 我知道他們的所作所為和所思所想。我要召集萬邦萬民，他們必來瞻仰我的榮耀。</span>
<span className="v" id="v19" data-v="19" data-xref="以賽亞書 52:15; 羅馬書 15:21; 以賽亞書 55:5"> 我要在他們中間行神蹟，我要派一些生還者到他施、普勒、路德、米設、羅施、土巴、雅完各國，以及那些沒有聽過我名聲，也沒有見過我榮耀的遙遠海島。他們必在列國傳揚我的榮耀。</span>
<span className="v" id="v20" data-v="20" data-xref="以賽亞書 60:3–14; 以賽亞書 65:11; 以賽亞書 11:9"> 他們必騎著馬、駕著車、坐著轎、騎著騾子或駱駝，把你們的弟兄從各國帶到我的聖山耶路撒冷，作為供物獻給耶和華，好像以色列人用潔淨的器皿把素祭帶到耶和華的殿中。這是耶和華說的。」</span>
<span className="v" id="v21" data-v="21" data-xref="彼得前書 2:9; 出埃及記 19:6; 啟示錄 1:6"> 耶和華說：「我要在他們中間立一些人做祭司和利未人。」</span>
</div>
<div className="bp poetry">
<span className="v" id="v22" data-v="22" data-xref="以賽亞書 65:17; 彼得後書 3:13; 啟示錄 21:1"> <span className="pl pl-1">耶和華說：「正如我造的新天新地在我面前長存，</span><br /><span className="pl pl-1">你們的名字和後裔也必長存。</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="以西結書 46:1; 詩篇 86:9; 歌羅西書 2:16–17"> <span className="pl pl-1">每逢朔日和安息日，</span><br /><span className="pl pl-1">世人都必來敬拜我。</span><br /><span className="pl pl-1">這是耶和華說的。</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="啟示錄 14:10–11; 以賽亞書 14:11; 帖撒羅尼迦前書 2:15–16"> <span className="pl pl-1">他們必出去觀看那些背叛我之人的屍體，</span><br /><span className="pl pl-1">因為咬他們的蟲不會死，</span><br /><span className="pl pl-1">燒他們的火不會滅，</span><br /><span className="pl pl-1">世人都必厭惡他們。」</span></span>
</div>

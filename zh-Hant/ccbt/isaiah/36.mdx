## 亞述王入侵猶大

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歷代志下 32:1; 列王紀下 18:13; 列王紀下 18:17"> 希西迦王執政第十四年，亞述王西拿基立起兵攻取了猶大所有的堅城。</span>
<span className="v" id="v2" data-v="2" data-xref="歷代志下 32:9–23; 以賽亞書 7:3; 列王紀下 18:17–37"> 然後，亞述王從拉吉差遣將軍率領大軍到耶路撒冷的希西迦王那裡。將軍站在上池的水溝旁、通往漂布場的路上。</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳記下 8:16–17; 以賽亞書 22:15–21; 撒母耳記下 20:24–25"> 希勒迦的兒子宮廷總管以利亞敬、書記舍伯那和亞薩的兒子史官約亞出來見亞述的將軍。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="列王紀下 18:19–37; 猶大書 1:16; 箴言 16:18"> 亞述的將軍對他們說：「你們去告訴希西迦，偉大的亞述王說，『你憑什麼這樣自信呢？</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀下 18:7; 耶利米書 52:3; 箴言 21:30–31"> 你所謂的戰略和軍力不過是空話。你究竟倚靠誰，竟敢背叛我？</span>
<span className="v" id="v6" data-v="6" data-xref="以西結書 29:6–7; 耶利米書 37:5–8; 列王紀下 18:21"> 看啊，你所倚靠的埃及不過是一根破裂的蘆葦杖，倚靠它的必被刺破手。倚靠埃及王法老的下場都是這樣。』</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀下 18:4–5; 詩篇 42:10–11; 詩篇 42:5"> 也許你會說，『我們倚靠我們的上帝耶和華。』希西迦不是拆除了祂的邱壇和祭壇，又吩咐猶大和耶路撒冷的人必須在這座祭壇前敬拜嗎？</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳記上 17:40–43; 列王紀上 20:10; 尼希米記 4:2–5"> 來，跟我主人亞述王打個賭，你若能找到兩千騎士，我就給你兩千匹馬！</span>
<span className="v" id="v9" data-v="9" data-xref="以賽亞書 10:8; 以賽亞書 30:16–17; 以賽亞書 36:6"> 你們即使依靠埃及的戰車和騎兵，又怎能打敗我主人的一個最小的將領呢？</span>
<span className="v" id="v10" data-v="10" data-xref="列王紀下 18:25; 以賽亞書 10:5–7; 列王紀上 13:18"> 更何況我來攻打、毀滅這地方不正是耶和華的意思嗎？耶和華吩咐我攻打、毀滅這地方。」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="以斯拉記 4:7; 但以理書 2:4; 列王紀下 18:26–27"> 以利亞敬、舍伯那和約亞對亞述的將軍說：「求你用亞蘭語跟僕人們說話，我們都聽得懂。求你不要用猶大話跟我們說，免得城牆上的人聽見。」</span>
<span className="v" id="v12" data-v="12" data-xref="列王紀下 18:27; 利未記 26:29; 耶利米哀歌 4:9–10"> 亞述的將軍卻說：「難道我主人派我來只對你們和你們的主人說這些話嗎？不也是對坐在城牆上的人說嗎？他們和你們一樣都要吃自己的糞，喝自己的尿。」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="歷代志下 32:18; 詩篇 73:8–9; 列王紀下 18:28–32"> 於是，他站著用猶大話大喊：「你們要聽偉大的亞述王的話，</span>
<span className="v" id="v14" data-v="14" data-xref="帖撒羅尼迦後書 2:4; 啟示錄 13:5–6; 但以理書 6:20"> 王說，『你們不要被希西迦欺騙，他不能救你們。</span>
<span className="v" id="v15" data-v="15" data-xref="以賽亞書 37:23–24; 馬太福音 27:43; 詩篇 71:9–11"> 不要聽希西迦的話去倚靠耶和華，說什麼耶和華必拯救你們，這城必不會落在亞述王手中。』</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀上 4:25; 撒迦利亞書 3:10; 彌迦書 4:4"> 不要聽希西迦的話。亞述王說，『你們要跟我講和，出來歸順我。這樣，你們就可以吃自己葡萄樹和無花果樹的果子，喝自己井裡的水。</span>
<span className="v" id="v17" data-v="17" data-xref="列王紀下 18:32; 申命記 8:7–9; 約伯記 20:17"> 以後我會來領你們到一個地方，那裡和這裡一樣有五穀和新酒、餅和葡萄園。</span>
<span className="v" id="v18" data-v="18" data-xref="以賽亞書 37:17–18; 以賽亞書 36:15; 以賽亞書 37:10"> 希西迦說耶和華必拯救你們，不要被他哄騙。列國有哪個神明曾從亞述王手中救它的國家呢？</span>
<span className="v" id="v19" data-v="19" data-xref="以賽亞書 10:9–11; 耶利米書 49:23; 撒母耳記下 8:9"> 哈馬和亞珥拔的神明在哪裡呢？西法瓦音的神明在哪裡呢？它們從我手中救撒瑪利亞了嗎？</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 50:21; 歷代志下 32:19; 以賽亞書 37:23–29"> 這些國家有哪個神明從我手中救了它的國家呢？難道耶和華能從我手中救耶路撒冷嗎？』」</span>
<span className="v" id="v21" data-v="21" data-xref="箴言 26:4; 詩篇 38:13–15; 馬太福音 7:6"> 民眾默不作聲，一言不發，因為希西迦王曾吩咐他們不要答話。</span>
<span className="v" id="v22" data-v="22" data-xref="以賽亞書 36:3; 以賽亞書 33:7; 馬太福音 26:65"> 這時，宮廷總管希勒家的兒子以利亞敬、書記舍伯那和亞薩的兒子史官約亞都撕裂衣服去見希西迦，把亞述將軍的話回稟他。</span>
</div>
</div>

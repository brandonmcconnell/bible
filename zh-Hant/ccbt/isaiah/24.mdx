## 主必審判世界

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="那鴻書 2:10; 以賽亞書 2:19; 以賽亞書 42:15"> 看啊，耶和華必摧毀大地，<br /><span className="pl pl-1">使大地荒涼。</span><br /><span className="pl pl-1">祂毀壞地面，驅散萬民。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="何西阿書 4:9; 耶利米哀歌 5:12–14; 以西結書 7:12–13"> <span className="pl pl-1">那時，祭司和百姓，</span><br /><span className="pl pl-1">主人和僕人，</span><br /><span className="pl pl-1">主母和婢女，</span><br /><span className="pl pl-1">買的和賣的，</span><br /><span className="pl pl-1">貸的和借的，</span><br /><span className="pl pl-1">債主和債戶都必遭難。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="以賽亞書 24:1; 以賽亞書 6:11; 申命記 29:23"> <span className="pl pl-1">大地必被完全毀壞，洗劫一空。</span><br /><span className="pl pl-1">這是耶和華說的。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v4" data-v="4" data-xref="何西阿書 4:3; 以賽亞書 33:9; 以賽亞書 3:26"> <span className="pl pl-1">大地枯竭凋零，</span><br /><span className="pl pl-1">世界衰敗沒落，</span><br /><span className="pl pl-1">世上的權貴也敗落。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="希伯來書 13:20; 羅馬書 8:20–21; 但以理書 7:25"> <span className="pl pl-1">大地被世人玷污，</span><br /><span className="pl pl-1">他們干犯律法，</span><br /><span className="pl pl-1">不守律例，背棄永遠的約。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="瑪拉基書 4:1; 馬太福音 7:14; 撒迦利亞書 5:3–4"> <span className="pl pl-1">所以咒詛必吞噬大地，</span><br /><span className="pl pl-1">世人必因罪而受懲罰。</span><br /><span className="pl pl-1">他們必被焚燒，</span><br /><span className="pl pl-1">所剩無幾。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="以賽亞書 16:10; 約珥書 1:10–12; 以賽亞書 16:8"> <span className="pl pl-1">葡萄樹枯萎，新酒枯竭，</span><br /><span className="pl pl-1">歡樂的人都發出悲歎。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="何西阿書 2:11; 啟示錄 18:22; 以西結書 26:13"> <span className="pl pl-1">愉快的鼓聲止息，</span><br /><span className="pl pl-1">悅耳的琴音消失，</span><br /><span className="pl pl-1">宴樂的喧鬧不復聽聞。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="以賽亞書 5:22; 傳道書 9:7; 以賽亞書 5:20"> <span className="pl pl-1">再沒有人對酒高歌，</span><br /><span className="pl pl-1">濃酒變得苦澀。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="啟示錄 18:2; 啟示錄 17:5–6; 以賽亞書 24:12"> <span className="pl pl-1">毀壞的城一片荒涼，</span><br /><span className="pl pl-1">家家房門緊閉，無人能進。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="何西阿書 7:14; 以賽亞書 24:7–9; 耶利米書 48:33"> <span className="pl pl-1">人們因無酒而在街上喊叫；</span><br /><span className="pl pl-1">一切歡樂變作哀愁，</span><br /><span className="pl pl-1">地上喜樂不復存在。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="耶利米書 9:11; 彌迦書 1:12; 耶利米哀歌 5:18"> <span className="pl pl-1">城裡一片荒涼，</span><br /><span className="pl pl-1">城門被撞成碎片。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="以賽亞書 1:9; 以西結書 6:8–11; 以西結書 11:16–20"> <span className="pl pl-1">世上萬民必所剩無幾，</span><br /><span className="pl pl-1">像打過的橄欖樹，</span><br /><span className="pl pl-1">又如摘過的葡萄樹。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="以賽亞書 40:9; 耶利米書 31:12; 以賽亞書 54:1"> <span className="pl pl-1">劫後餘生的人必高聲歡呼，</span><br /><span className="pl pl-1">在西方讚美耶和華的威嚴。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="瑪拉基書 1:11; 以賽亞書 42:4; 以賽亞書 60:9"> <span className="pl pl-1">因此，要在東方尊崇耶和華，</span><br /><span className="pl pl-1">要在眾海島讚美以色列的上帝耶和華的名。</span><br /></span>

</div>
<div className="bp poetry">
<span className="v" id="v17" data-v="17" data-xref="耶利米書 48:43–44; 列王紀上 19:17; 利未記 26:21–22"> <span className="pl pl-1">世人啊！</span><br /><span className="pl pl-1">恐怖、陷阱和網羅要臨到你們。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="創世記 7:11; 詩篇 18:7; 約書亞記 10:10–11"> <span className="pl pl-1">逃避恐怖的必掉進陷阱，</span><br /><span className="pl pl-1">爬出陷阱的必被網羅纏住。</span><br /><span className="pl pl-1">天上的水閘開啟，</span><br /><span className="pl pl-1">大地的根基搖動。</span><br /></span>

<span className="v" id="v20" data-v="20" data-xref="以賽亞書 19:14; 何西阿書 4:1–5; 但以理書 11:19"> <span className="pl pl-1">大地像醉漢東搖西晃，</span><br /><span className="pl pl-1">又像暴風中的茅屋搖來擺去。</span><br /><span className="pl pl-1">它被沉重的罪惡壓垮，</span><br /><span className="pl pl-1">再也無法起來。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v21" data-v="21" data-xref="詩篇 76:12; 以賽亞書 34:2–17; 撒迦利亞書 14:12–19"> <span className="pl pl-1">到那日，耶和華必在天上懲罰天上的眾權能者，</span><br /><span className="pl pl-1">在地上懲罰地上的君王。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="撒迦利亞書 9:11; 以賽亞書 42:22; 耶利米書 38:6–13"> <span className="pl pl-1">他們必像囚犯一樣被聚在一起，</span><br /><span className="pl pl-1">關在牢裡，囚在獄中，</span><br /><span className="pl pl-1">多日之後必受懲罰。</span><br /></span>

</div>

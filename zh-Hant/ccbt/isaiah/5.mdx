## 葡萄園之歌

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="馬可福音 12:1; 路加福音 20:9; 約翰福音 15:1"> 我要為我所愛的歌唱，唱一首有關他葡萄園的歌：<br /><span className="pl pl-1">我所愛的在肥沃的山岡上有一個葡萄園。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="耶利米書 2:21; 申命記 32:32–33; 馬可福音 11:13"> <span className="pl pl-1">他鬆土，清除石頭，</span><br /><span className="pl pl-1">栽種了上好的葡萄樹，</span><br /><span className="pl pl-1">在園中建了一座瞭望塔，</span><br /><span className="pl pl-1">鑿了榨酒池。</span><br /><span className="pl pl-1">他期望收穫好葡萄，</span><br /><span className="pl pl-1">得到的卻是壞葡萄。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v3" data-v="3" data-xref="羅馬書 2:5; 詩篇 51:4; 彌迦書 6:2–3"> <span className="pl pl-1">他說，「耶路撒冷和猶大的居民啊，</span><br /><span className="pl pl-1">請你們在我和我的葡萄園之間裁決。</span><br /></span>

</div>
<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="耶利米哀歌 1:15; 路加福音 21:24; 以賽亞書 28:18"> <span className="pl pl-1">「現在，我告訴你們我會怎樣處理這葡萄園，</span><br /><span className="pl pl-1">我要除去籬笆，任它被毀壞；</span><br /><span className="pl pl-1">我要拆毀圍牆，任它被踐踏。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="以賽亞書 7:23–25; 耶利米書 25:11; 以賽亞書 24:1–3"> <span className="pl pl-1">我不再修剪，不再鋤地，</span><br /><span className="pl pl-1">任由它荒廢，長滿荊棘和蒺藜。</span><br /><span className="pl pl-1">我必禁止雲朵降下雨水。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="詩篇 80:8–11; 耶利米書 12:10; 雅各書 5:4"> <span className="pl pl-1">萬軍之耶和華的葡萄園就是以色列家，</span><br /><span className="pl pl-1">祂所喜愛的葡萄樹就是猶大人。</span><br /><span className="pl pl-1">祂希望看到公平，</span><br /><span className="pl pl-1">卻只看見殺戮；</span><br /><span className="pl pl-1">指望看到公義，</span><br /><span className="pl pl-1">看啊，卻只聽見冤聲。</span></span>
</div>
</div>

## 以色列的罪惡

<div className="bt">
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="彌迦書 2:2; 哈巴谷書 2:9–12; 耶利米書 22:13–17"> <span className="pl pl-1">那些不斷建房置田、佔光土地、</span><br /><span className="pl pl-1">獨居其中的人有禍了！</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="馬太福音 23:38; 以賽亞書 22:14; 阿摩司書 5:11"> <span className="pl pl-1">我親耳聽到萬軍之耶和華說：</span><br /><span className="pl pl-1">「許多房屋必荒廢，</span><br /><span className="pl pl-1">豪華的美宅必無人居住。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="利未記 26:26; 哈該書 2:16; 哈該書 1:6"> <span className="pl pl-1">十畝葡萄園只產一桶酒，</span><br /><span className="pl pl-1">二百升種子只產二十升糧食。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v11" data-v="11" data-xref="箴言 23:29–30; 羅馬書 13:13; 箴言 20:1"> <span className="pl pl-1">那些從清早到深夜貪杯好酒，</span><br /><span className="pl pl-1">喝到酩酊大醉的人有禍了！</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="約伯記 21:11–14; 詩篇 28:5; 阿摩司書 6:4–6"> <span className="pl pl-1">他們在琴、瑟、鼓、笛聲中飲酒作樂，</span><br /><span className="pl pl-1">毫不理會耶和華的作為，</span><br /><span className="pl pl-1">全然漠視祂手中的工作。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v13" data-v="13" data-xref="何西阿書 4:6; 以賽亞書 1:3; 以賽亞書 27:11"> <span className="pl pl-1">所以，我的子民必因無知而被擄。</span><br /><span className="pl pl-1">他們的貴族餓得要死，</span><br /><span className="pl pl-1">民眾渴得要命。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="箴言 30:16; 路加福音 21:34; 哈巴谷書 2:5"> <span className="pl pl-1">陰間必敞開喉嚨，</span><br /><span className="pl pl-1">張開無邊的大口，</span><br /><span className="pl pl-1">耶路撒冷的首領、群眾和宴樂之人都落入其中。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="以賽亞書 2:11; 以賽亞書 2:9; 耶利米書 5:4–5"> <span className="pl pl-1">世人受羞辱，遭貶抑，</span><br /><span className="pl pl-1">狂妄者眼目低垂。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="詩篇 46:10; 以賽亞書 12:4; 歷代志上 29:11"> <span className="pl pl-1">唯有萬軍之耶和華因祂的公正而受尊崇，</span><br /><span className="pl pl-1">至聖的上帝藉公義彰顯自己的聖潔。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="西番雅書 2:6; 西番雅書 2:14; 以賽亞書 7:25"> <span className="pl pl-1">那時，羔羊在那裡吃草，</span><br /><span className="pl pl-1">如在自己的草場，</span><br /><span className="pl pl-1">寄居者在富人的荒場上進食。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v18" data-v="18" data-xref="耶利米書 23:14; 以西結書 13:22; 耶利米書 5:31"> <span className="pl pl-1">那些用虛假作繩子拽來罪惡，</span><br /><span className="pl pl-1">用套繩拉來邪惡的人有禍了！</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="以西結書 12:22; 耶利米書 17:15; 耶利米書 23:36"> <span className="pl pl-1">他們說：「讓上帝快點，快點完成祂的工作，</span><br /><span className="pl pl-1">好讓我們看看；</span><br /><span className="pl pl-1">讓以色列的聖者早點實現祂的計劃，</span><br /><span className="pl pl-1">好讓我們知道。」</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="箴言 17:15; 提摩太後書 3:1–5; 路加福音 16:15"> <span className="pl pl-1">那些善惡不分、黑白顛倒、</span><br /><span className="pl pl-1">甜苦不辨的人有禍了！</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="哥林多前書 3:18–20; 箴言 3:7; 羅馬書 12:16"> <span className="pl pl-1">那些自以為聰明、睿智的人有禍了！</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="以賽亞書 5:11; 哈巴谷書 2:15; 以賽亞書 28:7"> <span className="pl pl-1">那些以豪飲稱霸、善於調酒的人有禍了！</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="以賽亞書 10:2; 雅各書 5:6; 詩篇 94:21"> <span className="pl pl-1">他們收受賄賂，釋放罪人，</span><br /><span className="pl pl-1">不為無辜者主持公道。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v24" data-v="24" data-xref="以賽亞書 30:12; 約伯記 18:16; 約珥書 2:5"> <span className="pl pl-1">他們的根必朽爛，</span><br /><span className="pl pl-1">他們的花朵如飛塵飄落，</span><br /><span className="pl pl-1">就像火焰吞滅禾稭，燒盡乾草，</span><br /><span className="pl pl-1">因為他們厭棄萬軍之耶和華的訓誨，</span><br /><span className="pl pl-1">藐視以色列聖者的言語。</span><br /></span>

<span className="v" id="v26" data-v="26" data-xref="撒迦利亞書 10:8; 申命記 28:49; 以賽亞書 7:18"> <span className="pl pl-1">祂必豎起旗幟召集遠方的國家，</span><br /><span className="pl pl-1">吹哨叫來地極的人。</span><br /><span className="pl pl-1">看啊，他們必飛速而來！</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="約珥書 2:7–8; 約伯記 12:18; 約伯記 12:21"> <span className="pl pl-1">他們無人疲倦，無人踉蹌，</span><br /><span className="pl pl-1">無人打盹，無人睡覺，</span><br /><span className="pl pl-1">都腰帶緊束，鞋帶未斷。</span><br /></span>
<span className="v" id="v28" data-v="28" data-xref="詩篇 45:5; 那鴻書 2:3–4; 以西結書 21:9–11"> <span className="pl pl-1">他們的利箭上弦，引弓待發；</span><br /><span className="pl pl-1">他們的馬蹄堅如巖石，</span><br /><span className="pl pl-1">車輪快如旋風。</span><br /></span>
<span className="v" id="v29" data-v="29" data-xref="以賽亞書 42:22; 撒迦利亞書 11:3; 彌迦書 5:8"> <span className="pl pl-1">他們吼叫如獅子，</span><br /><span className="pl pl-1">吼叫像猛獅，</span><br /><span className="pl pl-1">他們咆哮著捕食，</span><br /><span className="pl pl-1">將獵物叼走，無人能救。</span><br /></span>
<span className="v" id="v30" data-v="30" data-xref="以賽亞書 8:22; 約珥書 2:10; 耶利米書 4:23–28"> <span className="pl pl-1">那日，他們必向以色列咆哮，</span><br /><span className="pl pl-1">如怒海澎湃。</span><br /><span className="pl pl-1">人若觀看大地，</span><br /><span className="pl pl-1">只見黑暗和艱難，</span><br /><span className="pl pl-1">光明被密雲遮蓋。</span></span>

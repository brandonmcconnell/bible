## 關於摩押的預言

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="阿摩司書 2:1–3; 耶利米書 48:1–47; 以賽亞書 11:14"> 以下是關於摩押的預言：<br /><span className="pl pl-1">摩押的亞珥城必在一夜之間被摧毀，淪為廢墟；</span><br /><span className="pl pl-1">摩押的基珥城必在一夜之間被摧毀，淪為廢墟。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="耶利米書 48:1; 利未記 21:5; 以賽亞書 3:24"> <span className="pl pl-1">摩押人上到神廟，</span><br /><span className="pl pl-1">上到底本的邱壇痛哭。</span><br /><span className="pl pl-1">他們都剃光頭髮，刮掉鬍鬚，</span><br /><span className="pl pl-1">為尼波和米底巴城哀號。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="約拿書 3:6–8; 耶利米書 19:13; 申命記 22:8"> <span className="pl pl-1">他們身披麻衣走在街上，</span><br /><span className="pl pl-1">人們在房頂和廣場上號啕大哭。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="耶利米書 48:34; 列王紀上 19:4; 約拿書 4:8"> <span className="pl pl-1">希實本人和以利亞利人都在哭喊，</span><br /><span className="pl pl-1">聲音一直傳到雅雜，</span><br /><span className="pl pl-1">因此摩押的戰士大聲喊叫，</span><br /><span className="pl pl-1">膽戰心驚。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="耶利米書 48:5; 耶利米書 4:20; 路加福音 19:41–44"> <span className="pl pl-1">我的心為摩押哀號。</span><br /><span className="pl pl-1">她的人民逃難到瑣珥和伊基拉·施利施亞。</span><br /><span className="pl pl-1">他們上到魯希斜坡，邊走邊哭，</span><br /><span className="pl pl-1">在去何羅念的路上因自己的毀滅而哀哭。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="約珥書 1:10–12; 以賽亞書 19:5–7; 民數記 32:36"> <span className="pl pl-1">寧林的河道乾涸，</span><br /><span className="pl pl-1">青草枯萎，植被消失，毫無綠色。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="耶利米書 48:36; 那鴻書 2:12–13; 以賽亞書 10:6"> <span className="pl pl-1">因此，摩押人把自己積存的財物都運過柳樹河。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="以西結書 47:10; 以賽亞書 15:2–5; 耶利米書 48:31–34"> <span className="pl pl-1">摩押境內哀聲四起，</span><br /><span className="pl pl-1">號啕聲傳到以基蓮，</span><br /><span className="pl pl-1">傳到比珥·以琳。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="列王紀下 17:25; 利未記 26:28; 利未記 26:24"> <span className="pl pl-1">底門的河裡流的都是血，</span><br /><span className="pl pl-1">但我還要降更多災難給底門：</span><br /><span className="pl pl-1">獅子必吞噬逃出摩押的人和那裡的餘民。</span></span>

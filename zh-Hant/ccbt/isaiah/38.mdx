## 希西迦患病

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="以賽亞書 38:1–8; 歷代志下 32:24; 列王紀下 20:1–11"> 那些日子，希西迦病危，亞摩斯的兒子以賽亞先知前來對他說：「耶和華說，『你要交待後事，因為你要死了，你必無法康復。』」</span>
<span className="v" id="v2" data-v="2" data-xref="馬太福音 6:6; 詩篇 91:15; 列王紀上 8:30"> 希西迦把臉轉向牆，向耶和華禱告，說：</span>
<span className="v" id="v3" data-v="3" data-xref="希伯來書 5:7; 詩篇 18:20–27; 希伯來書 6:10"> 「耶和華啊，求你顧念我怎樣全心、忠誠地事奉你，做你視為善的事。」希西迦痛哭起來。</span>
<span className="v" id="v4" data-v="4"> 耶和華對以賽亞說：</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 34:5–6; 約翰一書 5:14–15; 啟示錄 7:17"> 「你去告訴希西迦，『你祖先大衛的上帝耶和華說，我垂聽了你的禱告，也看見了你的眼淚，我要使你的壽命增加十五年。</span>
<span className="v" id="v6" data-v="6" data-xref="以賽亞書 37:35; 以賽亞書 31:4–5; 以賽亞書 12:6"> 我要從亞述王手中拯救你和這城，我要保護這城。』」</span>
<span className="v" id="v21" data-v="21" data-xref="列王紀下 20:7–8; 馬可福音 7:33; 約翰福音 9:6"> 以賽亞說：「拿一塊無花果餅貼在王的瘡上，他就會痊癒。」</span>
<span className="v" id="v22" data-v="22" data-xref="詩篇 118:18–19; 列王紀下 20:8; 約翰福音 5:14"> 希西迦問：「有什麼兆頭證明我會上耶和華的殿呢？」<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="這兩節在原文抄本是放在本章末尾，不過這可能是在謄抄過程中放錯位置。其實這兩節經文放在6節和7節之間最為自然，就如在列王紀下一樣，參見列王紀下20·7‑8。">a</a></sup></span>
<span className="v" id="v7" data-v="7" data-xref="士師記 6:37–39; 以賽亞書 37:30; 以賽亞書 7:11–14"> 以賽亞說：「耶和華要給你一個預兆，以證明祂言出必行。</span>
<span className="v" id="v8" data-v="8" data-xref="列王紀下 20:9–11; 約書亞記 10:12–14; 馬太福音 16:1"> 祂要使亞哈斯日晷上的日影後退十度。」果然，日影後退了十度。</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 18:1; 出埃及記 15:1–21; 約伯記 5:18"> 猶大王希西迦病癒後，<br /><span className="pl pl-1">寫了一首詩：</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 102:24; 哥林多後書 1:9; 詩篇 107:18"> <span className="pl pl-1">「我以為自己盛年之際，</span><br /><span className="pl pl-1">就要踏入陰間之門，</span><br /><span className="pl pl-1">不能享受餘年。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 27:13; 詩篇 116:8–9; 詩篇 31:22"> <span className="pl pl-1">我以為再也見不到耶和華，</span><br /><span className="pl pl-1">在世間再不能見到祂，</span><br /><span className="pl pl-1">也不能再見到世人。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 73:14; 哥林多後書 5:1; 希伯來書 1:12"> <span className="pl pl-1">我的居所像牧人的帳篷一樣被拆走，</span><br /><span className="pl pl-1">我像織布的捲布一樣捲起自己的生命，</span><br /><span className="pl pl-1">祂從織布機上把我剪斷。</span><br /><span className="pl pl-1">旦夕之間，祂使我的生命戛然而止。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 51:8; 但以理書 6:24; 詩篇 50:22"> <span className="pl pl-1">我整夜哀號，</span><br /><span className="pl pl-1">祂像獅子一樣咬斷我全身的骨頭。</span><br /><span className="pl pl-1">旦夕之間，祂使我的生命戛然而止。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="以賽亞書 59:11; 詩篇 69:3; 詩篇 123:1–4"> <span className="pl pl-1">「我像燕、鶴一樣哀鳴，</span><br /><span className="pl pl-1">像鴿子一樣呻吟；</span><br /><span className="pl pl-1">我舉目望天，雙眼疲倦。</span><br /><span className="pl pl-1">耶和華啊！</span><br /><span className="pl pl-1">我困苦不堪，求你保護我。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="列王紀上 21:27; 約伯記 7:11; 約伯記 10:1"> <span className="pl pl-1">我能說什麼呢？</span><br /><span className="pl pl-1">祂對我說的，祂都親自成就了。</span><br /><span className="pl pl-1">因為心靈的苦痛，我要一生謹慎行事。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v16" data-v="16" data-xref="希伯來書 12:10–11; 哥林多前書 11:32; 詩篇 119:25"> <span className="pl pl-1">「主啊，你的法令使人存活，</span><br /><span className="pl pl-1">使我的心靈存活。</span><br /><span className="pl pl-1">主啊，求你使我身體復原，</span><br /><span className="pl pl-1">讓我存活。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="以賽亞書 43:25; 彌迦書 7:18–19; 約拿書 2:6"> <span className="pl pl-1">其實我受大苦對我有益。</span><br /><span className="pl pl-1">你施慈愛，從死亡的深坑中拯救我的生命，</span><br /><span className="pl pl-1">將我一切罪惡拋在你背後。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="傳道書 9:10; 詩篇 30:9; 詩篇 6:5"> <span className="pl pl-1">誠然，陰間不會稱謝你，</span><br /><span className="pl pl-1">死亡不會讚美你，</span><br /><span className="pl pl-1">下墳墓的人不會仰望你的信實。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="申命記 6:7; 詩篇 119:175; 詩篇 78:3–6"> <span className="pl pl-1">只有活著的人會像我今天這樣稱謝你，</span><br /><span className="pl pl-1">父親會把你的信實告訴子女。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v20" data-v="20" data-xref="詩篇 116:2; 詩篇 150:4; 詩篇 145:2"> <span className="pl pl-1">「耶和華必救我，</span><br /><span className="pl pl-1">我們要一生一世在祂殿中彈琴歌唱。」</span></span>
</div>

## 關於耶路撒冷的預言

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="耶利米書 21:13; 詩篇 125:2; 約珥書 3:12"> 以下是關於異象谷<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「異象谷」指耶路撒冷。">a</a></sup>的預言：<br /><span className="pl pl-1">為什麼你們全都上到房頂呢？</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="以賽亞書 32:13; 以賽亞書 23:7; 耶利米哀歌 2:20"> <span className="pl pl-1">你們這座充滿喧鬧、騷動和歡樂的城啊，</span><br /><span className="pl pl-1">你們中間被殺的人既非喪身刀下，</span><br /><span className="pl pl-1">也非死於戰場。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="列王紀下 25:4–7; 以賽亞書 3:1–8; 耶利米書 39:4–7"> <span className="pl pl-1">你們的官長都一起逃跑，</span><br /><span className="pl pl-1">一箭未發便束手就縛，</span><br /><span className="pl pl-1">逃到遠方的也一同被擒。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="耶利米書 9:1; 馬太福音 2:18; 詩篇 77:2"> <span className="pl pl-1">所以，我說：「你們不要管我，</span><br /><span className="pl pl-1">讓我痛哭吧！</span><br /><span className="pl pl-1">不要安慰我，</span><br /><span className="pl pl-1">我的同胞都被毀滅了。」</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="彌迦書 7:4; 以賽亞書 37:3; 路加福音 23:30"> <span className="pl pl-1">主——萬軍之耶和華已經定了日子，</span><br /><span className="pl pl-1">要使異象谷飽受恐慌、</span><br /><span className="pl pl-1">失敗和混亂，</span><br /><span className="pl pl-1">城牆被攻破，</span><br /><span className="pl pl-1">哭喊聲響徹山間。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="列王紀下 16:9; 以賽亞書 21:2; 阿摩司書 1:5"> <span className="pl pl-1">以攔人帶著箭袋，</span><br /><span className="pl pl-1">率領戰車和騎兵前來，</span><br /><span className="pl pl-1">吉珥人也亮出盾牌。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="以賽亞書 8:7–8; 以賽亞書 10:28–32; 耶利米書 39:1–3"> <span className="pl pl-1">你們佳美的山谷中佈滿戰車，</span><br /><span className="pl pl-1">騎兵在你們的城門前列陣。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="列王紀上 7:2; 列王紀上 10:17; 以賽亞書 36:1–3"> <span className="pl pl-1">主除去了猶大的防衛。</span><br />那時，你們寄望於藏在林宮裡的兵器。</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀下 20:20; 尼希米記 3:16; 歷代志下 32:1–6"> 你們看見大衛城破口纍纍，你們儲存下池的水，</span>
<span className="v" id="v10" data-v="10"> 數點耶路撒冷城的房屋，把房屋拆掉修補城牆。</span>
<span className="v" id="v11" data-v="11" data-xref="彌迦書 7:7; 耶利米書 33:2–3; 以賽亞書 31:1"> 你們又在兩道城牆之間建造新的蓄水池，用來盛舊池的水。耶和華從古時已定了這一切，要使這一切發生，但你們既不仰望祂，也不理會祂。</span>
<span className="v" id="v12" data-v="12" data-xref="約珥書 2:17; 彌迦書 1:16; 約珥書 1:13"> <span className="pl pl-1">那日，主——萬軍之耶和華要你們哭泣哀號，</span><br /><span className="pl pl-1">剃光頭髮，身披麻衣。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="以賽亞書 56:12; 哥林多前書 15:32; 路加福音 17:26–29"> <span className="pl pl-1">但你們卻歡喜作樂，</span><br /><span className="pl pl-1">宰牛殺羊，喝酒吃肉，說：</span><br /><span className="pl pl-1">「讓我們吃喝吧！</span><br /><span className="pl pl-1">因為明天我們就死了。」</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="以西結書 24:13; 撒母耳記上 3:14; 以賽亞書 5:9"> <span className="pl pl-1">萬軍之耶和華啟示我說：</span><br /><span className="pl pl-1">「你們這罪到死也得不到赦免。</span><br /><span className="pl pl-1">這是主——萬軍之耶和華說的。」</span></span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="以賽亞書 36:3; 列王紀下 18:18; 列王紀下 19:2"> 主——萬軍之耶和華吩咐我去見宮廷總管舍伯那，對他說：</span>
<span className="v" id="v16" data-v="16" data-xref="馬太福音 27:60; 歷代志下 16:14; 撒母耳記下 18:18"> 「你在這裡做什麼？你憑什麼在這裡為自己挖墳墓，在高處為自己挖墳墓，在磐石上為自己鑿安息之所？</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米書 14:3; 約伯記 9:24; 以斯帖記 7:8"> 看啊，你這有權有勢的人，耶和華必緊緊抓住你，把你猛力拋出去。</span>
<span className="v" id="v18" data-v="18" data-xref="以賽亞書 17:13; 阿摩司書 7:17"> 祂必把你揉作一團，像球一樣扔到寬闊之地。在那裡，你必死亡，你華美的戰車也必遭毀滅，你是你主人家的羞辱。」</span>
<span className="v" id="v19" data-v="19" data-xref="以西結書 17:24; 詩篇 75:6–7; 約伯記 40:11–12"> 耶和華對舍伯那說：「我必解除你的官職，把你從高位上拉下來。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="以賽亞書 36:3; 列王紀下 18:18; 以賽亞書 37:2"> 「到那日，我必召來希勒迦的兒子——我的僕人以利亞敬，</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 45:8; 以賽亞書 9:6–7; 創世記 41:42–43"> 給他穿上你的朝服，繫上你的腰帶，把你的權柄交給他。他必像父親一樣保護耶路撒冷的居民和猶大人。</span>
<span className="v" id="v22" data-v="22" data-xref="馬太福音 16:18–19; 啟示錄 3:7; 約伯記 12:14"> 我必把大衛家的鑰匙放在他的肩頭。他開啟的，沒有人能關；他關閉的，沒有人能開。</span>
<span className="v" id="v23" data-v="23" data-xref="以斯拉記 9:8; 約伯記 36:7; 撒迦利亞書 10:4"> 我要使他像深嵌在堅固之處的橛子一樣穩固，他必給他的家族帶來尊榮。</span>
<span className="v" id="v24" data-v="24" data-xref="但以理書 6:1–3; 約翰福音 20:21–23; 馬太福音 28:18"> 他的家族及其子孫後代都靠他得榮耀，如同杯子和酒瓶等小器皿掛在一個橛子上。」</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="以賽亞書 46:11; 以斯帖記 9:24–25; 詩篇 146:3"> 萬軍之耶和華說：「到那日，牢牢釘在堅固之處的橛子必鬆動，被砍落在地上，掛在上面的東西必被除掉。這是耶和華說的。」</span>
</div>

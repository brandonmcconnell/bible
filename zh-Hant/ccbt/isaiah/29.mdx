## 耶路撒冷被圍

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="阿摩司書 4:4–5; 撒母耳記下 5:9; 彌迦書 6:6–7"> <span className="pl pl-1">耶和華說：「亞利伊勒</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「亞利伊勒」在此處用來指錫安/耶路撒冷，2節、7節同。">a</a></sup><br /><span className="pl pl-1">，亞利伊勒，</span><br /><span className="pl pl-1">大衛安營的城啊！</span><br /><span className="pl pl-1">你有禍了！</span><br /><span className="pl pl-1">儘管你年復一年地守節期，</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="以賽亞書 5:25–30; 以賽亞書 3:26; 以賽亞書 10:32"> <span className="pl pl-1">我終必叫你受苦。</span><br /><span className="pl pl-1">你必悲傷哀號，</span><br /><span className="pl pl-1">在我面前成為一座祭壇。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="路加福音 19:43–44; 以西結書 21:22; 列王紀下 25:1–4"> <span className="pl pl-1">我必安營把你團團圍住，</span><br /><span className="pl pl-1">屯兵圍困你，</span><br /><span className="pl pl-1">修築高臺攻打你。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="以賽亞書 8:19; 詩篇 44:25; 以賽亞書 3:8"> <span className="pl pl-1">你必一敗塗地，</span><br /><span className="pl pl-1">躺在塵土中說話，</span><br /><span className="pl pl-1">你細微的聲音從土中傳來，</span><br /><span className="pl pl-1">好像地下幽靈的聲音。</span><br /><span className="pl pl-1">你必從塵埃中喃喃細語。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="帖撒羅尼迦前書 5:3; 以賽亞書 17:13–14; 以賽亞書 37:36"> <span className="pl pl-1">但你的眾仇敵必像纖細的塵埃一樣消散，</span><br /><span className="pl pl-1">眾多的殘暴之徒必如被風颳去的糠秕。</span><br /><span className="pl pl-1">突然，刹那之間，</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="馬可福音 13:8; 撒母耳記上 2:10; 馬太福音 24:7"> <span className="pl pl-1">萬軍之耶和華必帶著雷轟、地震、巨響、旋風、暴風和烈火來臨。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="約伯記 20:8; 彌迦書 4:11–12; 撒迦利亞書 12:9"> <span className="pl pl-1">攻打、圍困亞利伊勒及其堡壘的各國軍隊必如夢幻，</span><br /><span className="pl pl-1">如夜間的異象一樣消失。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="以賽亞書 44:12; 詩篇 73:20; 以賽亞書 10:7–16"> <span className="pl pl-1">他們好像饑餓的人夢中吃飯，</span><br /><span className="pl pl-1">醒來仍然饑餓；</span><br /><span className="pl pl-1">像口渴的人夢中喝水，</span><br /><span className="pl pl-1">醒來仍然渴得發昏。</span><br /><span className="pl pl-1">攻打錫安山的各國軍隊都必如此。」</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="以賽亞書 51:21–22; 以賽亞書 19:14; 啟示錄 17:6"> <span className="pl pl-1">你們駐足驚奇吧！</span><br /><span className="pl pl-1">你們自我蒙蔽，繼續瞎眼吧！</span><br /><span className="pl pl-1">你們醉了，但不是因為酒；</span><br /><span className="pl pl-1">你們東倒西歪，但不是因為烈酒。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="羅馬書 11:8; 以賽亞書 44:18; 帖撒羅尼迦後書 2:9–12"> <span className="pl pl-1">因為耶和華把沉睡的靈傾倒在你們身上，</span><br /><span className="pl pl-1">祂封住你們的眼睛，</span><br /><span className="pl pl-1">蓋住你們的頭。</span><br /><span className="pl pl-1">你們的眼睛就是先知，</span><br /><span className="pl pl-1">你們的頭就是先見。</span></span>
<span className="v" id="v11" data-v="11" data-xref="馬太福音 13:11; 但以理書 12:4; 以賽亞書 8:16"> 對你們而言，這整個啟示都好像封了印的書卷。你們把書卷交給識字的人讀，他會說：「我不能讀，這書卷是封著的。」</span>
<span className="v" id="v12" data-v="12" data-xref="約翰福音 7:15–16; 以賽亞書 29:18; 耶利米書 5:4"> 你們把書卷交給不識字的人讀，他會說：「我不識字。」</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米書 12:2; 以西結書 33:31–33; 馬可福音 7:2–13"> <span className="pl pl-1">主說：「這些人嘴上親近我，</span><br /><span className="pl pl-1">他們用嘴唇尊崇我，心卻遠離我。</span><br /><span className="pl pl-1">他們敬拜我不過是遵行人定的規條。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="哈巴谷書 1:5; 哥林多前書 1:19–24; 以賽亞書 28:21"> <span className="pl pl-1">所以，我要再次行奇妙無比的事，使他們震驚。</span><br /><span className="pl pl-1">他們智者的智慧必泯滅，</span><br /><span className="pl pl-1">明哲的聰明必消失。」</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="以西結書 8:12; 以賽亞書 47:10; 以賽亞書 30:1"> <span className="pl pl-1">那些向耶和華深藏計謀的人有禍了！</span><br /><span className="pl pl-1">他們暗中行事，</span><br /><span className="pl pl-1">自以為誰也無從看見和知曉。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="羅馬書 9:19–21; 以賽亞書 64:8; 以賽亞書 45:9–11"> <span className="pl pl-1">他們顛倒是非！</span><br /><span className="pl pl-1">窯匠豈可被看作泥土？</span><br /><span className="pl pl-1">受造者豈可對創造者說</span><br /><span className="pl pl-1">「你沒有造我」？</span><br /><span className="pl pl-1">陶器怎能對陶匠說：</span><br /><span className="pl pl-1">「你什麼也不懂」？</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v17" data-v="17" data-xref="以賽亞書 32:15; 馬太福音 19:30; 希伯來書 10:37"> <span className="pl pl-1">再過不久，黎巴嫩將變成沃野，</span><br /><span className="pl pl-1">沃野上莊稼將茂密如林。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="以賽亞書 35:5; 馬太福音 11:5; 馬可福音 7:37"> <span className="pl pl-1">那時，耳聾的必聽見那書卷上的話，</span><br /><span className="pl pl-1">盲人的眼睛必能看穿黑暗。</span><br /></span>

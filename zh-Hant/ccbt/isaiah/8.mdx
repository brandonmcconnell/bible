## 預言災難降臨

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="以賽亞書 30:8; 約伯記 19:23–24; 哈巴谷書 2:2–3"> 耶和華對我說：「你去拿塊大的寫字板，用通用的文字在上面寫上『瑪黑珥·沙拉勒·哈施·罷斯』<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「瑪黑珥·沙拉勒·哈施·罷斯」意思是「快速擄掠，迅速搶奪」。">a</a></sup>。</span>
<span className="v" id="v2" data-v="2" data-xref="列王紀下 16:10–11; 列王紀下 18:2; 哥林多後書 13:1"> 我會吩咐忠信的祭司烏利亞和耶比利迦的兒子撒迦利亞為這事作見證。」</span>
<span className="v" id="v3" data-v="3" data-xref="何西阿書 1:3–9; 士師記 4:4; 以賽亞書 7:13–14"> 我以賽亞與女先知同房，她就懷孕生了個兒子。耶和華對我說：「給他取名叫瑪黑珥·沙拉勒·哈施·罷斯。</span>
<span className="v" id="v4" data-v="4" data-xref="羅馬書 9:11; 列王紀下 16:9; 申命記 1:39"> 因為這孩子會叫爸爸媽媽之前，亞述王必把大馬士革的財富和撒瑪利亞的戰利品洗劫一空。」</span>
<span className="v" id="v5" data-v="5" data-xref="以賽亞書 7:10"> 耶和華又對我說：</span>
<span className="v" id="v6" data-v="6" data-xref="約翰福音 9:7; 尼希米記 3:15; 以賽亞書 7:6"> 「因為這些百姓厭棄西羅亞的緩緩流水，反倒因利汛和利瑪利的兒子而歡喜。</span>
<span className="v" id="v7" data-v="7" data-xref="以賽亞書 17:12–13; 創世記 6:17; 以賽亞書 7:17"> 因此，我要差來亞述王和他的軍隊，使他們像幼發拉底河的洪流一樣洶湧而來，淹沒一切水道，漫過河岸，</span>
<span className="v" id="v8" data-v="8" data-xref="以賽亞書 7:14; 以賽亞書 30:28; 馬太福音 1:23"> 席捲猶大，使整個猶大幾遭滅頂之災。他必展開雙翼橫掃你的土地。」願上帝與我們同在！</span>
<span className="v" id="v9" data-v="9" data-xref="以賽亞書 14:5–6; 箴言 11:21; 詩篇 37:14–15"> <span className="pl pl-1">列國啊，你們必被打垮、擊潰！</span><br /><span className="pl pl-1">遠方的人啊，你們要側耳聽！</span><br /><span className="pl pl-1">整裝備戰吧，但你們必被擊垮！</span><br /><span className="pl pl-1">整裝備戰吧，但你們必被擊垮！</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="耶利米哀歌 3:37; 羅馬書 8:31; 約伯記 5:12"> <span className="pl pl-1">你們設計謀吧，但休想得逞！</span><br /><span className="pl pl-1">你們定策略吧，但休想成功！</span><br /><span className="pl pl-1">因為上帝與我們同在。</span></span>

## 當敬畏主

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="以西結書 3:14; 箴言 1:15; 耶利米書 15:19"> 耶和華大能的手按在我身上，警告我不可效法這些百姓。祂說：</span>
<span className="v" id="v12" data-v="12" data-xref="彼得前書 3:14–15; 路加福音 21:9; 詩篇 53:5"> 「他們認為是陰謀的，你們不要認為是陰謀。他們所怕的，你們不要怕，也不要畏懼。</span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 12:5; 以賽亞書 26:3–4; 啟示錄 15:4"> 你們當尊萬軍之耶和華為聖，當敬畏祂，懼怕祂。</span>
<span className="v" id="v14" data-v="14" data-xref="彼得前書 2:8; 羅馬書 9:32–33; 以賽亞書 28:16"> 祂必作人的聖所，也要作以色列和猶大兩家的絆腳石和使他們跌倒的磐石，作耶路撒冷居民的陷阱和網羅。</span>
<span className="v" id="v15" data-v="15" data-xref="馬太福音 21:44; 路加福音 20:17–18; 以賽亞書 28:13"> 許多人必被絆倒，摔得粉身碎骨；他們必被網羅纏住，捕獲。」</span>
<span className="v" id="v16" data-v="16" data-xref="但以理書 12:4; 希伯來書 3:5; 馬可福音 4:10–11"> 你們要在我的門徒中間把上帝的訓誨捲起來，用印封好。</span>
<span className="v" id="v17" data-v="17" data-xref="希伯來書 10:36–39; 哈巴谷書 2:3; 耶利米哀歌 3:25–26"> 雖然耶和華掩面不顧雅各家，但我仍要等候祂，冀望於祂。</span>
<span className="v" id="v18" data-v="18" data-xref="希伯來書 2:13–14; 路加福音 2:34; 撒迦利亞書 8:3"> 看啊，我和耶和華賜給我的兒女在以色列是徵兆和跡象。這徵兆和跡象來自住在錫安山的萬軍之耶和華。</span>
<span className="v" id="v19" data-v="19" data-xref="歷代志上 10:13; 利未記 20:6; 歷代志下 33:6"> 有人讓你們去求問那些念念有詞的巫師和術士。難道你們不該去求問你們的上帝嗎？活人的事怎能求問死人呢？</span>
<span className="v" id="v20" data-v="20" data-xref="彼得後書 1:19; 提摩太後書 3:15–17; 以賽亞書 30:8–11"> 人應該遵循耶和華的訓誨和法度。人若不遵循祂的話，必看不到曙光。</span>
<span className="v" id="v21" data-v="21" data-xref="以賽亞書 9:20; 箴言 19:3; 耶利米哀歌 4:4–5"> 他們必困苦，饑餓，到處流浪。他們饑餓時，會怒氣沖沖地揚天咒罵他們的君王，褻瀆上帝。</span>
<span className="v" id="v22" data-v="22" data-xref="以賽亞書 5:30; 馬太福音 22:13; 耶利米書 13:16"> 他們低頭看地，看到的盡是患難、痛苦和黑暗。他們必被扔進黑暗中。</span>
</div>

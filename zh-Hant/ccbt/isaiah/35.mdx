## 聖潔之路

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="以西結書 36:35; 以賽亞書 51:3; 以賽亞書 55:12–13"> 沙漠和乾旱之地必歡喜；<br /><span className="pl pl-1">曠野必快樂，開滿鮮花，</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="以賽亞書 25:9; 以賽亞書 60:13; 阿摩司書 9:13–15"> <span className="pl pl-1">無比繁盛，充滿歡聲笑語，</span><br /><span className="pl pl-1">享有黎巴嫩的榮耀、</span><br /><span className="pl pl-1">迦密和沙崙的榮美。</span><br /><span className="pl pl-1">人們必看見耶和華的榮耀，</span><br /><span className="pl pl-1">我們上帝的榮美。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v3" data-v="3" data-xref="希伯來書 12:12; 約伯記 4:3–4; 路加福音 22:32"> <span className="pl pl-1">你們要使軟弱的人強壯，</span><br /><span className="pl pl-1">使雙膝無力的人站穩。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="雅各書 5:7–9; 以賽亞書 41:10–14; 哈該書 2:4"> <span className="pl pl-1">要對膽怯的人說：</span><br /><span className="pl pl-1">「你們要剛強，不要害怕。</span><br /><span className="pl pl-1">看啊，你們的上帝必來為你們復仇，施行報應，</span><br /><span className="pl pl-1">祂必來拯救你們。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="以賽亞書 42:6–7; 路加福音 7:20–23; 以賽亞書 29:18"> <span className="pl pl-1">那時，瞎眼的必看見，</span><br /><span className="pl pl-1">耳聾的必聽見，</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="約翰福音 5:8–9; 約翰福音 7:37–39; 路加福音 11:14"> <span className="pl pl-1">瘸腿的必跳躍如鹿，</span><br /><span className="pl pl-1">啞巴必歡呼歌唱；</span><br /><span className="pl pl-1">曠野有泉水湧流，</span><br /><span className="pl pl-1">沙漠裡河川奔騰；</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="使徒行傳 26:18; 以賽亞書 49:10; 約翰福音 4:14"> <span className="pl pl-1">炙熱的沙漠變成池塘，</span><br /><span className="pl pl-1">旱地湧出甘泉；</span><br /><span className="pl pl-1">豺狼的巢穴長出青草、</span><br /><span className="pl pl-1">蘆葦和蒲草。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="馬太福音 7:13–14; 以賽亞書 42:16; 約翰福音 14:6"> <span className="pl pl-1">那裡必有一條大路，</span><br /><span className="pl pl-1">被稱為「聖潔之路」，</span><br /><span className="pl pl-1">專供蒙救贖的人行走。</span><br /><span className="pl pl-1">污穢的人都不能走這條路，</span><br /><span className="pl pl-1">愚昧的人也不能信步其上。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="以賽亞書 62:12; 何西阿書 2:18; 利未記 26:6"> <span className="pl pl-1">那裡必沒有獅子，</span><br /><span className="pl pl-1">也沒有惡獸，</span><br /><span className="pl pl-1">沒有牠們的蹤影，</span><br /><span className="pl pl-1">只有蒙救贖的人行走。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="以賽亞書 30:19; 啟示錄 21:4; 以賽亞書 25:8"> <span className="pl pl-1">耶和華救贖的子民必歸回，</span><br /><span className="pl pl-1">歡唱著回到錫安，</span><br /><span className="pl pl-1">永遠的福樂必臨到他們頭上。</span><br /><span className="pl pl-1">他們必歡喜快樂，</span><br /><span className="pl pl-1">再沒有憂愁和歎息。</span></span>
</div>

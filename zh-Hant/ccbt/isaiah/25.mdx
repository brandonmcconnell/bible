## 讚美之歌

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="出埃及記 15:2; 詩篇 118:28; 民數記 23:19"> 耶和華啊！你是我的上帝，我要尊崇你，讚美你的名。你信實無比，<br /><span className="pl pl-1">按你古時定下的計劃行了奇妙的事。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="以賽亞書 17:1; 以賽亞書 13:22; 以賽亞書 25:12"> <span className="pl pl-1">你使城邑淪為廢墟，</span><br /><span className="pl pl-1">使堅壘淪為荒場。</span><br /><span className="pl pl-1">外族人的宮殿不復存在，</span><br /><span className="pl pl-1">永遠不能重建。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="撒迦利亞書 14:9; 以賽亞書 49:23–26; 詩篇 46:10–11"> <span className="pl pl-1">因此，強大的民必頌揚你，</span><br /><span className="pl pl-1">殘暴之邦的城邑必敬畏你。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="西番雅書 3:12; 以賽亞書 32:2; 雅各書 2:5"> <span className="pl pl-1">你是貧窮人的避難所，</span><br /><span className="pl pl-1">是困苦之人患難中的避難所，</span><br /><span className="pl pl-1">你是避風港，</span><br /><span className="pl pl-1">是酷暑中的陰涼處。</span><br /><span className="pl pl-1">殘暴之徒的氣息好像吹襲牆垣的暴風，</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="啟示錄 20:8–9; 以賽亞書 49:10; 詩篇 105:39"> <span className="pl pl-1">又像乾旱之地的熱氣。</span><br /><span className="pl pl-1">你平息外族人的喧嘩，</span><br /><span className="pl pl-1">止息殘暴之徒的歌聲，</span><br /><span className="pl pl-1">好像雲朵消去酷熱。</span></span>
<span className="v" id="v6" data-v="6" data-xref="馬太福音 8:11; 詩篇 63:5; 撒迦利亞書 9:16–17"> 在錫安山上，萬軍之耶和華必為天下萬民擺設豐盛的宴席，有陳年佳釀和精選的美食。</span>
<span className="v" id="v7" data-v="7" data-xref="以弗所書 4:18; 以賽亞書 60:1–3; 馬太福音 27:51"> 在這山上，祂必除去遮蔽萬民的面紗和籠罩萬國的幔子。</span>
<span className="v" id="v8" data-v="8" data-xref="啟示錄 21:4; 啟示錄 7:17; 哥林多前書 15:54"> 祂必永遠吞滅死亡。主耶和華必擦去各人臉上的眼淚，從世上除掉祂子民的羞辱。這是耶和華說的。</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 27:14; 創世記 49:18; 彌迦書 7:7"> 到那日，人們必說：「看啊，這是我們的上帝，我們信靠祂，祂拯救了我們。這是耶和華，我們信靠祂，我們要因祂的救恩而歡喜快樂。」</span>
<span className="v" id="v10" data-v="10" data-xref="以賽亞書 25:6; 以賽亞書 18:4; 西番雅書 2:9"> 耶和華必伸手保護這山，但摩押人必在本地被踐踏，像乾草被踐踏在糞池中。</span>
<span className="v" id="v11" data-v="11" data-xref="以賽亞書 16:14; 以賽亞書 2:11; 以賽亞書 16:6"> 他們必在裡面張開手臂，好像張開手臂游泳的人一樣。耶和華必摧毀他們的驕傲，挫敗他們手中的詭計。</span>
<span className="v" id="v12" data-v="12" data-xref="以賽亞書 26:5; 啟示錄 18:21; 以賽亞書 14:23"> 祂必拆毀他們高大堅固的城牆，將其夷為平地、化為塵土。</span>

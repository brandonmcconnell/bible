<span className="v" id="v2" data-v="2" data-xref="箴言 27:8; 士師記 11:18; 耶利米書 48:20"> <span className="pl pl-1">在亞嫩河渡口，</span><br /><span className="pl pl-1">摩押人</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「摩押人」希伯來文是「摩押的女子」。">a</a></sup><br /><span className="pl pl-1">如同被趕離巢穴的飛鳥。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="以賽亞書 32:2; 列王紀上 18:4; 以賽亞書 25:4"> <span className="pl pl-1">他們對猶大人說：「給我們出個主意，下個決定吧！</span><br /><span className="pl pl-1">請讓你們的影子在正午如黑夜，</span><br /><span className="pl pl-1">掩藏逃難的人，</span><br /><span className="pl pl-1">不要出賣逃亡者。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="以賽亞書 14:4; 以賽亞書 51:13; 以賽亞書 9:4"> <span className="pl pl-1">讓逃難的摩押人住在你們中間，</span><br /><span className="pl pl-1">請掩護他們躲避毀滅者。」</span><br /><span className="pl pl-1">欺壓者必逝去，</span><br /><span className="pl pl-1">毀滅之事必終止，</span><br /><span className="pl pl-1">入侵者必從地上消亡。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="但以理書 7:14; 彌迦書 4:7; 以賽亞書 9:6–7"> <span className="pl pl-1">那時，必有一個寶座在愛中堅立，</span><br /><span className="pl pl-1">大衛家的人必坐在上面以信實治國，</span><br /><span className="pl pl-1">秉公審判，敏行公義。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="阿摩司書 2:1; 俄巴底亞書 1:3–4; 耶利米書 48:29–30"> <span className="pl pl-1">我們聽說摩押人驕橫傲慢、狂妄自大，</span><br /><span className="pl pl-1">然而他們所誇耀的都是虛假的。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="列王紀下 3:25; 歷代志上 16:3; 耶利米書 48:20"> <span className="pl pl-1">因此，他們必為摩押哀哭，</span><br /><span className="pl pl-1">人人都必哀哭，</span><br /><span className="pl pl-1">為失去吉珥·哈列設的美味葡萄餅而哀歎、悲傷。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="以賽亞書 15:4; 民數記 32:38; 耶利米書 48:32"> <span className="pl pl-1">因為希實本的農田荒廢，</span><br /><span className="pl pl-1">西比瑪的葡萄樹枯萎。</span><br /><span className="pl pl-1">各國的君王都來踐踏這些上好的葡萄樹。</span><br /><span className="pl pl-1">它們的枝子曾經伸展到雅謝和曠野，</span><br /><span className="pl pl-1">嫩枝一直蔓延到死海。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="耶利米書 40:12; 以賽亞書 15:4–5; 耶利米書 40:10"> <span className="pl pl-1">因此，我像雅謝人一樣為西比瑪的葡萄樹哀哭。</span><br /><span className="pl pl-1">希實本和以利亞利啊，</span><br /><span className="pl pl-1">我用眼淚來澆灌你們，</span><br /><span className="pl pl-1">因為再無人為你們的果品和莊稼而歡呼了。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="耶利米書 48:33; 士師記 9:27; 阿摩司書 5:17"> <span className="pl pl-1">肥美的田園裡聽不到快樂的聲音，</span><br /><span className="pl pl-1">葡萄園裡也無人歌唱，無人歡呼，</span><br /><span className="pl pl-1">榨酒池裡無人榨酒。</span><br /><span className="pl pl-1">我已經使歡呼聲止息。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="以賽亞書 15:5; 耶利米書 48:36; 何西阿書 11:8"> <span className="pl pl-1">我的內心為摩押，</span><br /><span className="pl pl-1">為吉珥·哈列設哀鳴，</span><br /><span className="pl pl-1">好像淒涼的琴聲。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="以賽亞書 15:2; 列王紀上 18:29; 耶利米書 48:35"> <span className="pl pl-1">摩押人上邱壇祭拜，</span><br /><span className="pl pl-1">卻累得筋疲力盡；</span><br /><span className="pl pl-1">在廟宇裡禱告，</span><br /><span className="pl pl-1">卻毫無用處。</span></span>
<span className="v" id="v13" data-v="13" data-xref="以賽亞書 44:8"> 以上是耶和華所說有關摩押的預言。</span>
<span className="v" id="v14" data-v="14" data-xref="以賽亞書 21:16; 耶利米書 48:46–47; 以賽亞書 23:9"> 現在，耶和華說：「正如一個雇工的工作年限是三年，三年之內，摩押的榮耀必和它的眾民一同消失，殘存的人必寥寥無幾、軟弱無力。」</span>

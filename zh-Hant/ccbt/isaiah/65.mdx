## 懲罰與拯救

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="羅馬書 10:20; 羅馬書 9:24–26; 彼得前書 2:10"> <span className="pl pl-1">耶和華說：「我向沒有求問我的人顯現，</span><br /><span className="pl pl-1">讓沒有尋找我的人尋見，</span><br /><span className="pl pl-1">對沒有求告我名的國家說，</span><br /><span className="pl pl-1">『我在這裡，我在這裡！』</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="羅馬書 10:21; 箴言 1:24; 耶利米書 4:14"> <span className="pl pl-1">我整天伸出雙手招呼那悖逆的子民，</span><br /><span className="pl pl-1">他們卻任意妄為，</span><br /><span className="pl pl-1">不走正路。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="以賽亞書 1:29; 申命記 32:21; 以賽亞書 66:17"> <span className="pl pl-1">他們不斷地當面惹我發怒。</span><br /><span className="pl pl-1">在園中獻祭，</span><br /><span className="pl pl-1">在磚臺上燒香。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="以賽亞書 66:17; 利未記 11:7; 以賽亞書 66:3"> <span className="pl pl-1">他們坐在墳場裡，</span><br /><span className="pl pl-1">宿在隱秘處。</span><br /><span className="pl pl-1">他們吃豬肉，</span><br /><span className="pl pl-1">鍋裡有不潔之物做的湯。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="路加福音 18:9–12; 路加福音 7:39; 箴言 16:5"> <span className="pl pl-1">他們對人說，『站遠點，</span><br /><span className="pl pl-1">別挨近我，因為我比你聖潔！』</span><br /><span className="pl pl-1">我被這些人氣得鼻孔冒煙，</span><br /><span className="pl pl-1">整天怒火難息。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 50:3; 耶利米書 16:18; 詩篇 79:12"> <span className="pl pl-1">看啊，這些都記錄在我面前，</span><br /><span className="pl pl-1">我不會再保持緘默，</span><br /><span className="pl pl-1">我要報應他們，</span><br /><span className="pl pl-1">按他們和他們祖先的罪報應他們。</span><br /><span className="pl pl-1">我必按他們之前的所作所為報應他們，</span><br /><span className="pl pl-1">因為他們在山上燒香，</span><br /><span className="pl pl-1">在丘陵上褻瀆我。</span><br /><span className="pl pl-1">這是耶和華說的。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="羅馬書 9:27–29; 阿摩司書 9:8–9; 羅馬書 11:24–26"> <span className="pl pl-1">耶和華說：「人發現一串葡萄尚可釀造新酒時，</span><br /><span className="pl pl-1">一定會說，『不要毀壞它，</span><br /><span className="pl pl-1">裡面還有好葡萄。』</span><br /><span className="pl pl-1">同樣，因我僕人的緣故，</span><br /><span className="pl pl-1">我也不會把他們全部毀滅。</span></span>
</div>
<div className="bp poetry">

<span className="v" id="v11" data-v="11" data-xref="以賽亞書 2:2; 以賽亞書 1:28; 申命記 32:17"> <span className="pl pl-1">至於你們這些背棄我耶和華、</span><br /><span className="pl pl-1">忘記我的聖山、</span><br /><span className="pl pl-1">擺宴供奉幸運之神、</span><br /><span className="pl pl-1">斟滿調和酒祭奠命運之神的人，</span><br /></span>

</div>
<div className="bp poetry">
<span className="v" id="v13" data-v="13" data-xref="瑪拉基書 3:18; 以賽亞書 66:14; 以賽亞書 61:7"> <span className="pl pl-1">所以主耶和華說：</span><br /><span className="pl pl-1">「看啊，我的僕人必有吃有喝，</span><br /><span className="pl pl-1">你們卻要饑渴交加；</span><br /><span className="pl pl-1">我的僕人必歡喜，</span><br /><span className="pl pl-1">你們卻要受羞辱；</span><br /></span>

</div>
</div>

<div className="bp poetry">

<span className="v" id="v18" data-v="18" data-xref="詩篇 98:1–9; 啟示錄 19:1–6; 以賽亞書 66:10–14"> <span className="pl pl-1">你們要因我的創造而永遠歡喜快樂。</span><br /><span className="pl pl-1">看啊，我要造充滿喜樂的耶路撒冷，</span><br /><span className="pl pl-1">在城中造歡樂的居民。</span><br /></span>

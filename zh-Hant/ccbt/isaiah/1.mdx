## 上帝責備叛逆的子民

<div className="bt">
<div className="bp poetry">
<span className="v" id="v2" data-v="2" data-xref="申命記 32:1; 申命記 30:19; 彌迦書 1:2"> <span className="pl pl-1">諸天啊，請聽！</span><br /><span className="pl pl-1">大地啊，要側耳聽！</span><br /><span className="pl pl-1">耶和華說：</span><br /><span className="pl pl-1">「我把孩子撫育成人，</span><br /><span className="pl pl-1">他們竟然背叛我。</span><br /></span>

</div>
<div className="bp poetry">
<span className="v" id="v4" data-v="4" data-xref="以賽亞書 5:24; 耶利米書 2:17; 耶利米書 2:13"> <span className="pl pl-1">唉！這罪惡的民族，</span><br /><span className="pl pl-1">惡貫滿盈的百姓，</span><br /><span className="pl pl-1">作惡的子孫，</span><br /><span className="pl pl-1">敗壞的兒女！</span><br /><span className="pl pl-1">他們背棄耶和華，</span><br /><span className="pl pl-1">藐視以色列的聖者，</span><br /><span className="pl pl-1">與祂疏遠。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="但以理書 9:8–11; 以西結書 24:13; 耶利米書 5:3"> <span className="pl pl-1">你們為什麼一再叛逆？</span><br /><span className="pl pl-1">你們為什麼還要受責打？</span><br /><span className="pl pl-1">你們已經頭破血流，</span><br /><span className="pl pl-1">身心疲憊不堪。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="耶利米書 6:14; 耶利米書 33:6; 馬太福音 9:12"> <span className="pl pl-1">你們已經體無完膚，</span><br /><span className="pl pl-1">從頭到腳傷痕纍纍，盡是瘀腫和傷口，</span><br /><span className="pl pl-1">沒有清洗，沒有包紮，</span><br /><span className="pl pl-1">也沒有敷藥。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="耶利米哀歌 5:2; 申命記 28:43; 申命記 28:33"> <span className="pl pl-1">你們的土地荒涼，</span><br /><span className="pl pl-1">城邑化為灰燼。</span><br /><span className="pl pl-1">你們親眼目睹自己的田園被外族人侵吞、毀壞、變成不毛之地。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="撒迦利亞書 9:9; 約翰福音 12:15; 撒迦利亞書 2:10"> <span className="pl pl-1">僅存的少女錫安也像葡萄園裡的草棚，</span><br /><span className="pl pl-1">像瓜田中的茅舍，</span><br /><span className="pl pl-1">像被困無援的孤城。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="羅馬書 9:29; 以賽亞書 37:31–32; 創世記 19:24"> <span className="pl pl-1">若不是萬軍之耶和華讓我們一些人存活，</span><br /><span className="pl pl-1">我們早就像所多瑪和蛾摩拉一樣滅亡了。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="啟示錄 11:8; 以西結書 16:49; 阿摩司書 9:7"> <span className="pl pl-1">你們這些所多瑪的首領啊，</span><br /><span className="pl pl-1">要聆聽耶和華的話！</span><br /><span className="pl pl-1">你們這些蛾摩拉的百姓啊，</span><br /><span className="pl pl-1">要側耳聽我們上帝的訓誨！</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳記上 15:22; 阿摩司書 5:21; 耶利米書 6:20"> <span className="pl pl-1">耶和華說：</span><br /><span className="pl pl-1">「你們獻上許多祭物，對我有什麼用呢？</span><br /><span className="pl pl-1">我厭煩公綿羊的燔祭和肥畜的脂肪，</span><br /><span className="pl pl-1">我不喜歡公牛、羊羔和公山羊的血。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="出埃及記 34:23; 出埃及記 23:17; 彌迦書 6:8"> <span className="pl pl-1">「你們來朝見我的時候，</span><br /><span className="pl pl-1">誰要求你們帶著這些來踐踏我的院宇呢？</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="以賽亞書 66:3; 瑪拉基書 1:10; 馬太福音 15:9"> <span className="pl pl-1">不要再帶毫無意義的祭物了。</span><br /><span className="pl pl-1">我憎惡你們燒的香。</span><br /><span className="pl pl-1">我無法容忍你們又作惡又舉行莊嚴的聚會，</span><br /><span className="pl pl-1">就是你們的朔日</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「朔日」即每月初一。">a</a></sup><br /><span className="pl pl-1">、安息日和大會。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="阿摩司書 5:21; 以賽亞書 43:24; 以賽亞書 7:13"> <span className="pl pl-1">我憎惡你們的朔日及各種節期，</span><br /><span className="pl pl-1">它們成了我的重擔，</span><br /><span className="pl pl-1">令我厭倦。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="彌迦書 3:4; 以賽亞書 59:2–3; 箴言 1:28"> <span className="pl pl-1">你們舉手禱告，我必掩面不理。</span><br /><span className="pl pl-1">即使你們禱告再多，</span><br /><span className="pl pl-1">我也不會聽，</span><br /><span className="pl pl-1">因為你們雙手沾滿鮮血。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="彼得前書 3:11; 以賽亞書 55:6–7; 彼得前書 2:1"> <span className="pl pl-1">你們要洗淨自己，</span><br /><span className="pl pl-1">不要讓我再看見你們的惡行，</span><br /><span className="pl pl-1">要停止作惡。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="彌迦書 6:8; 耶利米書 22:3; 詩篇 82:3–4"> <span className="pl pl-1">你們要學習行善，</span><br /><span className="pl pl-1">追求正義，</span><br /><span className="pl pl-1">幫助受欺壓的，</span><br /><span className="pl pl-1">替孤兒辯護，</span><br /><span className="pl pl-1">為寡婦伸冤。」</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="以賽亞書 44:22; 啟示錄 7:14; 詩篇 51:7"> <span className="pl pl-1">耶和華說：</span><br /><span className="pl pl-1">「來吧，我們彼此理論！</span><br /><span className="pl pl-1">你們的罪雖如朱紅，</span><br /><span className="pl pl-1">也必潔白如雪；</span><br /><span className="pl pl-1">你們的罪雖如緋紅，</span><br /><span className="pl pl-1">也必白如羊毛。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="申命記 30:15–16; 以賽亞書 3:10; 約珥書 2:26"> <span className="pl pl-1">如果你們願意聽從，</span><br /><span className="pl pl-1">就必享用這地方的美好出產。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="以賽亞書 65:12; 以賽亞書 58:14; 民數記 23:19"> <span className="pl pl-1">如果你們執意叛逆，</span><br /><span className="pl pl-1">就必喪身刀下。」</span><br /><span className="pl pl-1">這是耶和華親口說的。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="以西結書 22:1–23; 撒迦利亞書 8:3; 西番雅書 3:1–3"> <span className="pl pl-1">忠信的城竟變成了妓女！</span><br /><span className="pl pl-1">從前充滿公平，</span><br /><span className="pl pl-1">是公義之家，</span><br /><span className="pl pl-1">現在卻住著兇手。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="耶利米書 6:28–30; 耶利米哀歌 4:1–2; 何西阿書 4:18"> <span className="pl pl-1">你的銀子變為渣滓；</span><br /><span className="pl pl-1">你的美酒摻了水份。</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="彌迦書 7:3; 出埃及記 23:8; 撒迦利亞書 7:10"> <span className="pl pl-1">你的首領是叛逆之徒，</span><br /><span className="pl pl-1">與盜賊為伍，</span><br /><span className="pl pl-1">個個喜愛賄賂，</span><br /><span className="pl pl-1">貪圖好處，</span><br /><span className="pl pl-1">不為孤兒辯護，</span><br /><span className="pl pl-1">不替寡婦伸冤。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v24" data-v="24" data-xref="以賽亞書 60:16; 以賽亞書 35:4; 申命記 28:63"> <span className="pl pl-1">所以，主——萬軍之耶和華，</span><br /><span className="pl pl-1">以色列的大能者說：</span><br /><span className="pl pl-1">「唉！我要向我的敵人報仇，</span><br /><span className="pl pl-1">向我的仇敵雪恨。</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="瑪拉基書 3:3; 耶利米書 9:7; 以賽亞書 4:4"> <span className="pl pl-1">我必出手攻擊你，</span><br /><span className="pl pl-1">用鹼煉淨你的渣滓，</span><br /><span className="pl pl-1">除盡你的雜質。</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="耶利米書 33:7; 撒迦利亞書 8:3; 以賽亞書 62:1–2"> <span className="pl pl-1">我必像從前一樣恢復你的審判官，</span><br /><span className="pl pl-1">像起初一樣恢復你的謀士。</span><br /><span className="pl pl-1">之後，你必被稱為公義之城，</span><br /><span className="pl pl-1">忠信之邑。」</span></span>
</div>
<div className="bp poetry">

<span className="v" id="v28" data-v="28" data-xref="帖撒羅尼迦後書 1:8–9; 詩篇 1:6; 以賽亞書 30:13"> <span className="pl pl-1">但叛逆之輩和犯罪之徒必同遭毀滅，</span><br /><span className="pl pl-1">背棄耶和華的人必滅亡。</span><br /></span>
<span className="v" id="v29" data-v="29" data-xref="以賽亞書 65:3; 以賽亞書 57:5; 以賽亞書 66:17"> <span className="pl pl-1">你們必因所喜愛的聖橡樹而抱愧，</span><br /><span className="pl pl-1">必因所選擇的偶像園而蒙羞。</span><br /></span>

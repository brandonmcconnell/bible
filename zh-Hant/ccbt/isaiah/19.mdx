## 關於埃及的預言

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="出埃及記 12:12; 啟示錄 1:7; 約書亞記 2:11"> 以下是關於埃及的預言：<br /><span className="pl pl-1">看啊，耶和華駕著疾馳的雲來到埃及。</span><br /><span className="pl pl-1">埃及的偶像在祂面前顫抖，</span><br /><span className="pl pl-1">埃及人膽戰心驚。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="士師記 7:22; 撒母耳記上 14:20; 馬太福音 10:36"> <span className="pl pl-1">「我必使埃及人彼此為敵——手足相殘，</span><br /><span className="pl pl-1">鄰居互鬥，城邑相爭，</span><br /><span className="pl pl-1">邦國互攻。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="以賽亞書 8:19; 但以理書 2:2; 歷代志上 10:13"> <span className="pl pl-1">埃及人必灰心喪志，</span><br /><span className="pl pl-1">我必破壞他們的計謀。</span><br /><span className="pl pl-1">他們必求問偶像、巫師、靈媒和術士。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="以賽亞書 20:4; 耶利米書 46:26; 以西結書 29:19"> <span className="pl pl-1">我必將埃及人交給一位殘忍的主人，</span><br /><span className="pl pl-1">一位暴君必統治他們。」</span><br /><span className="pl pl-1">這是主——萬軍之耶和華說的。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="耶利米書 51:36; 以西結書 30:12; 撒迦利亞書 14:18"> <span className="pl pl-1">海水必枯竭，</span><br /><span className="pl pl-1">河床必乾涸。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="以賽亞書 37:25; 出埃及記 7:18; 列王紀下 19:24"> <span className="pl pl-1">溝渠必發臭，</span><br /><span className="pl pl-1">埃及的河流逐漸枯竭。</span><br /><span className="pl pl-1">蘆葦和燈心草必枯死，</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="以賽亞書 32:20; 約珥書 1:17–18; 以賽亞書 23:3"> <span className="pl pl-1">尼羅河兩岸青草枯黃，</span><br /><span className="pl pl-1">田地龜裂，莊稼被風吹去，</span><br /><span className="pl pl-1">蕩然無存。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="以西結書 47:10; 哈巴谷書 1:15; 民數記 11:5"> <span className="pl pl-1">所有在尼羅河下鉤的漁夫都哀哭悲傷，</span><br /><span className="pl pl-1">在河上撒網的人都傷痛。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="以西結書 27:7; 箴言 7:16; 列王紀上 10:28"> <span className="pl pl-1">紡麻織布的人一籌莫展，</span><br /><span className="pl pl-1">陷入絕望。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="申命記 11:10; 出埃及記 7:19; 出埃及記 8:5"> <span className="pl pl-1">埃及的顯貴萎靡不振</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="死海古卷為「埃及的織布者都崩潰」。">a</a></sup><br /><span className="pl pl-1">，</span><br /><span className="pl pl-1">僱工們都憂心忡忡。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v11" data-v="11" data-xref="民數記 13:22; 使徒行傳 7:22; 列王紀上 4:30"> <span className="pl pl-1">瑣安的官長愚不可及，</span><br /><span className="pl pl-1">法老聰明的謀士盡出下策。</span><br /><span className="pl pl-1">他們怎敢在法老面前自稱是智者之子，古代君王之後？</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="哥林多前書 1:20; 以賽亞書 14:24; 士師記 9:38"> <span className="pl pl-1">法老啊，你的智者在哪裡呢？</span><br /><span className="pl pl-1">讓他們把萬軍之耶和華對付埃及的計劃告訴你吧！</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="以西結書 30:13; 耶利米書 2:16; 耶利米書 46:14"> <span className="pl pl-1">瑣安的首領愚昧，</span><br /><span className="pl pl-1">挪弗的首領糊塗。</span><br /><span className="pl pl-1">他們是埃及各支派的房角石，</span><br /><span className="pl pl-1">卻把埃及人引入歧途。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="帖撒羅尼迦後書 2:11; 列王紀上 22:20–23; 以西結書 14:7–9"> <span className="pl pl-1">耶和華使錯謬的靈進入他們當中，</span><br /><span className="pl pl-1">使他們像又嘔又吐、東倒西歪的醉漢，</span><br /><span className="pl pl-1">做什麼都錯誤百出。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="以賽亞書 9:14–15; 帖撒羅尼迦前書 4:11–12; 箴言 14:23"> <span className="pl pl-1">埃及從頭到尾，</span><br /><span className="pl pl-1">從權貴到草根必一籌莫展。</span></span>
<span className="v" id="v16" data-v="16" data-xref="耶利米書 51:30; 那鴻書 3:13; 以賽亞書 11:15"> 到那日，當萬軍之耶和華揮手懲罰的時候，埃及人必恐懼顫抖，如柔弱的女子。</span>
<span className="v" id="v17" data-v="17" data-xref="以賽亞書 14:24; 但以理書 4:35; 以西結書 29:6–7"> 他們必對猶大充滿恐懼，一聽見猶大的名字就害怕，因為萬軍之耶和華定下計劃要對付他們。</span>
<span className="v" id="v18" data-v="18" data-xref="西番雅書 3:9; 撒迦利亞書 2:11; 以賽亞書 19:21"> 到那日，埃及必有五座城的人講迦南的語言，並起誓效忠萬軍之耶和華，其中有一座必叫滅亡城<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="「滅亡城」有些抄本作「太陽城」。">b</a></sup>。</span>
<span className="v" id="v19" data-v="19" data-xref="創世記 28:18; 約書亞記 22:10; 約書亞記 22:26"> 到那日，埃及境內必有一座為耶和華築的祭壇，邊境必有一根為耶和華立的石柱。</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 50:15; 提多書 2:13; 以賽亞書 45:21–22"> 這是萬軍之耶和華在埃及的記號和憑據。埃及人因受到欺壓就呼求耶和華，祂必差遣一位救主保護、拯救他們。</span>
<span className="v" id="v21" data-v="21" data-xref="以賽亞書 11:9; 瑪拉基書 1:11; 約翰福音 17:3"> 耶和華必向埃及人彰顯自己。到那日，埃及人必認識祂，帶著祭物和供物來敬拜祂，向祂許願還願。</span>
<span className="v" id="v22" data-v="22" data-xref="申命記 32:39; 希伯來書 12:11; 何西阿書 14:1"> 耶和華必擊打他們，也必醫治他們。他們必歸向耶和華，祂必應允他們的禱告，醫治他們。</span>
<span className="v" id="v23" data-v="23" data-xref="以賽亞書 11:16; 以弗所書 2:18–22; 以賽亞書 35:8–10"> 到那日，必有一條大道連接埃及和亞述，兩國人民互相往來，一同敬拜耶和華。</span>
<span className="v" id="v24" data-v="24" data-xref="以賽亞書 65:8; 創世記 12:2; 加拉太書 3:14"> 到那日，以色列必與埃及和亞述一同成為世人的祝福。</span>
<span className="v" id="v25" data-v="25" data-xref="以賽亞書 29:23; 何西阿書 2:23; 羅馬書 9:24–25"> 萬軍之耶和華必賜福給他們，說：「我的子民埃及、我的創作亞述、我的產業以色列都有福了！」</span>
</div>

## 給亞哈斯王的信息

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="列王紀下 15:37; 列王紀下 16:1; 以賽亞書 1:1"> 烏西雅的孫子、約坦的兒子亞哈斯做猶大王時，亞蘭王利汛和利瑪利的兒子以色列王比加來攻打耶路撒冷，卻無法攻破。</span>
<span className="v" id="v2" data-v="2" data-xref="以賽亞書 8:12; 以賽亞書 7:13; 以賽亞書 9:9"> 亞蘭和以色列結盟的消息傳到猶大王那裡，舉國上下都嚇得膽戰心驚，好像林中被風吹動的樹木。</span>
<span className="v" id="v3" data-v="3" data-xref="列王紀下 18:17; 以賽亞書 36:2; 羅馬書 9:27"> 耶和華對以賽亞說：「你帶著兒子施亞雅述出去，到上池水溝的盡頭、在通往漂布場的路上迎見亞哈斯，</span>
<span className="v" id="v4" data-v="4" data-xref="以賽亞書 35:4; 耶利米哀歌 3:26; 申命記 20:3"> 告訴他要謹慎鎮定，不要害怕，不要因亞蘭王利汛和利瑪利的兒子的怒氣而膽怯，他們不過是兩個冒煙的火把頭。</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 83:3–4; 撒迦利亞書 1:15; 詩篇 2:2"> 亞蘭王和以法蓮及利瑪利的兒子陰謀毀滅他，</span>
<span className="v" id="v6" data-v="6"> 企圖攻打並瓜分猶大，改立他比勒的兒子為王。</span>
<span className="v" id="v7" data-v="7" data-xref="以賽亞書 8:10; 耶利米哀歌 3:37; 以賽亞書 46:10–11"> 但主耶和華說，<br /><span className="pl pl-1">「『這陰謀休想得逞，</span><br /><span className="pl pl-1">休想成功。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="以賽亞書 17:1–3; 創世記 14:15; 撒母耳記下 8:6"> <span className="pl pl-1">亞蘭的都城是大馬士革，</span><br /><span className="pl pl-1">大馬士革的首領是利汛。</span><br /><span className="pl pl-1">六十五年之內，</span><br /><span className="pl pl-1">以法蓮必亡國滅族。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="希伯來書 11:6; 羅馬書 11:20; 歷代志下 20:20"> <span className="pl pl-1">以法蓮的都城是撒瑪利亞，</span><br /><span className="pl pl-1">撒瑪利亞的首領是利瑪利的兒子。</span><br /><span className="pl pl-1">你們信心若不堅定，</span><br /><span className="pl pl-1">必無法堅立。』」</span></span>
<span className="v" id="v10" data-v="10" data-xref="以賽亞書 8:5; 以賽亞書 1:5; 以賽亞書 10:20"> 耶和華又對亞哈斯說：</span>
<span className="v" id="v11" data-v="11" data-xref="以賽亞書 37:30; 以賽亞書 38:7–8; 以賽亞書 38:22"> 「向你的上帝耶和華求個徵兆吧，或顯在天上，或顯在陰間。」</span>
<span className="v" id="v12" data-v="12" data-xref="以西結書 33:31; 歷代志下 28:22; 瑪拉基書 3:15"> 但亞哈斯說：「我不求，我不要試探耶和華。」</span>
<span className="v" id="v13" data-v="13" data-xref="以賽亞書 43:24; 以賽亞書 63:10; 以西結書 34:18"> 以賽亞說：「大衛家啊，你們聽著！你們使人厭煩還不夠嗎？還要使我的上帝厭煩嗎？</span>
<span className="v" id="v14" data-v="14" data-xref="馬太福音 1:23; 以賽亞書 9:6; 路加福音 1:31"> 所以，主會親自給你們一個徵兆，必有童貞女<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「童貞女」或譯「女子」。">a</a></sup>懷孕生子並給他取名叫以馬內利<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="「以馬內利」意思是「上帝與我們同在」。">b</a></sup>。</span>
<span className="v" id="v15" data-v="15" data-xref="以賽亞書 7:22; 阿摩司書 5:15; 馬太福音 3:4"> 他將吃乳酪和蜂蜜，一直到他能棄惡擇善之時。</span>
<span className="v" id="v16" data-v="16" data-xref="以賽亞書 8:4; 申命記 1:39; 以賽亞書 9:11"> 因為在他能明辨是非之前，你所懼怕的這二王的國土必荒廢。</span>
<span className="v" id="v17" data-v="17" data-xref="以賽亞書 8:7–8; 以賽亞書 10:5–6; 歷代志下 28:19–21"> 「之後，耶和華必讓亞述王來攻擊你、你的人民和你全家，這是自以法蓮與猶大分裂以來從未有過的日子。</span>
<span className="v" id="v18" data-v="18" data-xref="以賽亞書 5:26; 約書亞記 24:12; 申命記 1:44"> 那時，耶和華必用哨聲從埃及的尼羅河口召來蒼蠅，從亞述召來黃蜂。</span>
<span className="v" id="v19" data-v="19" data-xref="以賽亞書 2:19; 耶利米書 16:16; 以賽亞書 2:21"> 牠們必蜂擁而來，落在險峻的山谷、巖穴、一切荊棘叢和草場。</span>
<span className="v" id="v20" data-v="20" data-xref="以賽亞書 8:7; 以西結書 29:18; 以賽亞書 10:15"> 那時，主必使用從幼發拉底河那邊租來的剃刀，就是亞述王，來剃光你們的頭髮、體毛和鬍鬚。</span>
<span className="v" id="v21" data-v="21" data-xref="以賽亞書 5:17; 耶利米書 39:10; 以賽亞書 37:30"> 那時，一個人將養活一頭小母牛和兩隻羊。</span>
<span className="v" id="v22" data-v="22" data-xref="以賽亞書 7:15; 馬太福音 3:4; 撒母耳記下 17:29"> 因出產的奶豐富，他就有乳酪吃，境內剩下的人都將吃乳酪和蜂蜜。</span>
<span className="v" id="v23" data-v="23" data-xref="以賽亞書 5:6; 雅歌 8:11–12; 馬太福音 21:33"> 那時，本來有千株葡萄、價值千金的各園子都必長滿荊棘和蒺藜，</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 27:3"> 人們必帶著弓箭去那裡打獵，因為遍地長滿了荊棘和蒺藜。</span>
<span className="v" id="v25" data-v="25" data-xref="以賽亞書 7:21–22; 以賽亞書 13:20–22; 以賽亞書 5:17"> 你因懼怕荊棘和蒺藜，將不再去從前用鋤頭開墾的山地，那裡將成為牧放牛羊的地方。」</span>

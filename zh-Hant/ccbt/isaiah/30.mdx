## 依靠埃及徒勞無益

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="以賽亞書 65:2; 以賽亞書 1:2; 何西阿書 7:13"> 耶和華說：<br /><span className="pl pl-1">「我悖逆的兒女有禍了！</span><br /><span className="pl pl-1">他們推行的計劃並非我的心意，</span><br /><span className="pl pl-1">他們與人結盟並非出於我的靈，</span><br /><span className="pl pl-1">以致罪上加罪。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="以賽亞書 36:6; 民數記 27:21; 申命記 28:68"> <span className="pl pl-1">他們不求問我便去埃及，</span><br /><span className="pl pl-1">要得到法老的保護，</span><br /><span className="pl pl-1">尋求埃及的蔭庇。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="以賽亞書 20:5; 羅馬書 10:11; 耶利米書 17:5–6"> <span className="pl pl-1">然而，法老的保護必成為你們的羞愧，</span><br /><span className="pl pl-1">埃及的蔭庇必成為你們的恥辱。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="以賽亞書 19:11; 以賽亞書 57:9; 耶利米書 43:7"> <span className="pl pl-1">雖然他們的官長已在瑣安，</span><br /><span className="pl pl-1">使臣已到哈內斯，</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="耶利米書 2:36; 以賽亞書 30:7; 以賽亞書 30:16"> <span className="pl pl-1">但他們必因無用的埃及人而蒙羞，</span><br /><span className="pl pl-1">那些人帶不來任何助益，</span><br /><span className="pl pl-1">只帶來羞愧和恥辱。」</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="申命記 8:15; 以賽亞書 46:1–2; 耶利米書 11:4"> <span className="pl pl-1">以下是關於南地動物的預言：</span><br /><span className="pl pl-1">他們用驢馱著財物，</span><br /><span className="pl pl-1">用駱駝馱著珍寶，</span><br /><span className="pl pl-1">穿過公獅、母獅、蝮蛇和飛蛇出沒的艱險之地，</span><br /><span className="pl pl-1">前往一個對他們毫無益處的國家。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="以賽亞書 2:22; 以賽亞書 7:4; 詩篇 118:8–9"> <span className="pl pl-1">埃及的幫助是徒然的，</span><br /><span className="pl pl-1">所以我稱她為「沒用的拉哈伯</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「拉哈伯」埃及的別名，也有「海怪」之意。">a</a></sup><br /><span className="pl pl-1">」。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="申命記 31:22; 哈巴谷書 2:2; 以賽亞書 8:1"> <span className="pl pl-1">現在，你去當著他們的面把這些話刻在版上，</span><br /><span className="pl pl-1">記在書卷上，</span><br /><span className="pl pl-1">永遠留給後世作明證。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="以賽亞書 30:1; 使徒行傳 7:51; 撒迦利亞書 1:4–6"> <span className="pl pl-1">因為他們是悖逆的民族，</span><br /><span className="pl pl-1">是說謊的兒女，</span><br /><span className="pl pl-1">不肯聽從耶和華的教導。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="以西結書 13:7–10; 羅馬書 16:18; 阿摩司書 2:12"> <span className="pl pl-1">他們對先見說：</span><br /><span className="pl pl-1">「你們不要再看異象了。」</span><br /><span className="pl pl-1">對先知說：</span><br /><span className="pl pl-1">「不要再教導我們正道。</span><br /><span className="pl pl-1">給我們說些好聽的話，</span><br /><span className="pl pl-1">講些虛幻的事吧。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="羅馬書 8:7; 羅馬書 1:30; 約翰福音 15:23–24"> <span className="pl pl-1">閃開此道！離開此路！</span><br /><span className="pl pl-1">不要再給我們講以色列聖者的事。」</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="以賽亞書 31:1–3; 以賽亞書 5:24; 帖撒羅尼迦前書 4:8"> <span className="pl pl-1">因此，以色列的聖者說：</span><br /><span className="pl pl-1">「因為你們藐視我的話，</span><br /><span className="pl pl-1">依仗欺壓之能和詭詐之術，</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="以賽亞書 29:5; 以西結書 13:10–15; 列王紀上 20:30"> <span className="pl pl-1">你們這罪必像一堵斷裂、凸起的高牆，</span><br /><span className="pl pl-1">搖搖欲墜，瞬間倒塌，</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="詩篇 2:9; 耶利米書 19:10–11; 彼得後書 2:4–5"> <span className="pl pl-1">又像瓦器一樣被無情地摔碎，</span><br /><span className="pl pl-1">找不到一塊可以用來從火爐中取炭或從水池裡舀水的碎片。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="以賽亞書 26:3–4; 以賽亞書 32:17; 耶利米書 3:22–23"> <span className="pl pl-1">主耶和華——以色列的聖者說：</span><br /><span className="pl pl-1">「你們回轉並安息，就必得拯救；</span><br /><span className="pl pl-1">你們安靜並信靠，就必得力量。</span><br /><span className="pl pl-1">但你們卻不肯。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="以賽亞書 31:1; 以賽亞書 31:3; 申命記 28:25"> <span className="pl pl-1">你們說，『不，我們要騎馬奔逃。』</span><br /><span className="pl pl-1">所以你們必奔逃。</span><br /><span className="pl pl-1">你們又說，『我們要騎快馬逃跑。』</span><br /><span className="pl pl-1">所以追趕你們的人必疾馳如飛。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="申命記 28:25; 約書亞記 23:10; 申命記 32:30"> <span className="pl pl-1">他們一人叱喝，</span><br /><span className="pl pl-1">必嚇得你們千人逃跑；</span><br /><span className="pl pl-1">他們五人叱喝，</span><br /><span className="pl pl-1">你們必全部逃跑，</span><br /><span className="pl pl-1">剩下的像山頂上的旗桿、高崗上的旗幟。」</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="耶利米哀歌 3:25–26; 彼得後書 3:9; 箴言 16:20"> <span className="pl pl-1">然而，耶和華正在等候，</span><br /><span className="pl pl-1">準備施恩給你們，</span><br /><span className="pl pl-1">祂必憐憫你們。</span><br /><span className="pl pl-1">因為耶和華是公正的上帝，</span><br /><span className="pl pl-1">等候祂的人有福了！</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="以賽亞書 60:20; 詩篇 50:15; 以賽亞書 65:24"> 住在耶路撒冷的錫安百姓啊，你們必不再哭泣。祂聽到你們的呼求後，必恩待你們；祂聽見後，必應允你們。</span>
<span className="v" id="v20" data-v="20" data-xref="列王紀上 22:27; 詩篇 80:5; 阿摩司書 8:11–12"> 雖然主讓你們吃苦受難、歷盡艱辛，但你們的教師必不再隱藏，你們必親眼看見你們的教師。</span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 32:8; 箴言 3:5–6; 以賽亞書 58:11"> 不管你們向左還是向右，都會聽見背後有聲音說：「這是正路，走在上面吧！」</span>
<span className="v" id="v22" data-v="22" data-xref="士師記 17:3–4; 以賽亞書 31:7; 撒迦利亞書 13:2"> 你們必拋棄自己那些鍍金和包銀的偶像，把它們當作污穢之物丟掉，對它們說：「去吧！」</span>
</div>
<div className="bp poetry">
<span className="v" id="v23" data-v="23" data-xref="撒迦利亞書 8:11–12; 以賽亞書 32:20; 詩篇 65:9–13"> 你們撒種，主必降雨，並使你們五穀豐登。那時，你們的牲畜必在寬闊的草場上吃草；</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 45:6; 申命記 25:4; 撒母耳記上 8:12"> 耕田的牛和驢必吃用叉子和鏟子揚淨、拌上鹽的飼料。</span>
<span className="v" id="v25" data-v="25" data-xref="以賽亞書 43:19–20; 以賽亞書 35:6–7; 以賽亞書 2:14–15"> 在你們的敵人被殺戮、城樓倒塌的日子，你們的高山岡陵上必有溪水奔流。</span>
<span className="v" id="v26" data-v="26" data-xref="以賽亞書 60:19–20; 申命記 32:39; 啟示錄 22:5"> 耶和華包紮祂子民的創傷，醫治他們的傷口時，月亮必發出太陽般的光輝，太陽的光輝必增加七倍，燦爛得好像七個太陽同時發光。</span>
<span className="v" id="v27" data-v="27" data-xref="帖撒羅尼迦後書 2:8; 那鴻書 1:5–6; 詩篇 18:7–9"> <span className="pl pl-1">看啊，耶和華的名從遠方來，</span><br /><span className="pl pl-1">伴著滾滾濃煙，</span><br /><span className="pl pl-1">祂的怒氣如烈火，</span><br /><span className="pl pl-1">祂口中充滿憤怒，舌頭好像烈焰。</span><br /></span>
<span className="v" id="v28" data-v="28" data-xref="以賽亞書 37:29; 以賽亞書 11:4; 帖撒羅尼迦後書 2:8"> <span className="pl pl-1">祂的氣息像淹到人頸項的洪流。</span><br /><span className="pl pl-1">祂必用毀滅的篩子篩淨列國，</span><br /><span className="pl pl-1">並把嚼環放在列邦口中，</span><br /><span className="pl pl-1">引他們走上歧途。</span></span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="詩篇 42:4; 詩篇 95:1–2; 出埃及記 15:1–21"> 但你們必歡唱，好像晚上慶祝節期；你們必充滿喜樂，好像人們吹著笛子登耶和華的山、到以色列的磐石那裡。</span>
<span className="v" id="v30" data-v="30" data-xref="詩篇 18:13–14; 約書亞記 10:11; 以賽亞書 29:6"> 耶和華必使人聽見祂威嚴的聲音，在憤怒、烈焰、暴雨、狂風和冰雹中讓人看見祂降罰的臂膀。</span>
<span className="v" id="v31" data-v="31" data-xref="以賽亞書 11:4; 以賽亞書 9:4; 彌迦書 5:5–6"> 亞述人聽見耶和華的聲音必心驚膽戰，祂必用杖擊打他們。</span>
<span className="v" id="v32" data-v="32" data-xref="以賽亞書 11:15; 以賽亞書 19:16; 以賽亞書 2:19"> 耶和華的刑杖每責打他們一下，必伴隨著擊鼓彈琴的聲音。祂必在戰場上揮手擊打他們。</span>
<span className="v" id="v33" data-v="33" data-xref="列王紀下 23:10; 創世記 19:24; 耶利米書 19:6"> 焚燒之地陀斐特早預備好了，是為亞述王預備的，又寬又深，堆滿了火和木柴，耶和華的氣息必如同一股硫磺火點燃那些木柴。</span>
</div>

## 關於泰爾的預言

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="約珥書 3:4–8; 阿摩司書 1:9–10; 創世記 10:4"> 以下是關於泰爾的預言：<br /><span className="pl pl-1">他施的船隻哀號吧！</span><br /><span className="pl pl-1">因為從基提</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「基提」就是現在的塞浦路斯。">a</a></sup><br /><span className="pl pl-1">傳來消息，</span><br /><span className="pl pl-1">說泰爾已被毀滅，</span><br /><span className="pl pl-1">房屋和港口都蕩然無存。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="以賽亞書 47:5; 以賽亞書 41:1; 以西結書 28:2"> <span className="pl pl-1">海邊的居民，西頓</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="先知在本預言中提到西頓，是因為泰爾和西頓都在同一地區，都屬於腓尼基人。">b</a></sup><br /><span className="pl pl-1">的商賈啊，</span><br /><span className="pl pl-1">要靜默無言。</span><br /><span className="pl pl-1">你們的商人飄洋過海，</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="耶利米書 2:18; 歷代志上 13:5; 以西結書 27:33"> <span className="pl pl-1">從大水之上把西曷的糧食、尼羅河邊的農產都運到泰爾。</span><br /><span className="pl pl-1">泰爾成為列國的商埠。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="啟示錄 18:23; 創世記 10:15; 耶利米書 47:3–4"> <span className="pl pl-1">西頓啊，你要羞愧！</span><br /><span className="pl pl-1">你這海上的堡壘啊，</span><br /><span className="pl pl-1">大海否認你，說：</span><br /><span className="pl pl-1">「我沒有經歷過產痛，</span><br /><span className="pl pl-1">沒有生過孩子，</span><br /><span className="pl pl-1">也未曾養育過兒女。」</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="約書亞記 2:9–11; 出埃及記 15:14–16; 啟示錄 18:17–19"> <span className="pl pl-1">埃及人聽見泰爾的消息，</span><br /><span className="pl pl-1">都感到傷痛。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="以賽亞書 23:12; 以賽亞書 21:15; 以賽亞書 23:10"> <span className="pl pl-1">海邊的居民啊，你們要去他施！</span><br /><span className="pl pl-1">你們要哀號！</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="以賽亞書 22:2; 以賽亞書 32:13; 約書亞記 19:29"> <span className="pl pl-1">這就是你們歷史悠久、</span><br /><span className="pl pl-1">充滿歡樂的城嗎？</span><br /><span className="pl pl-1">她的雙腳曾帶她到遠方居住。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="以賽亞書 10:8; 耶利米書 50:44–45; 申命記 29:24–28"> <span className="pl pl-1">泰爾曾是封王之地，</span><br /><span className="pl pl-1">她的商賈是王侯，</span><br /><span className="pl pl-1">她的商人名聞天下。</span><br /><span className="pl pl-1">但她如今的遭遇是誰定的？</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="雅各書 4:6; 以賽亞書 13:11; 約伯記 40:11–12"> <span className="pl pl-1">是萬軍之耶和華定的，</span><br /><span className="pl pl-1">為要摧毀因榮華而生的驕傲，</span><br /><span className="pl pl-1">羞辱世上的尊貴者。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="約伯記 12:21; 以賽亞書 23:14; 詩篇 18:32"> <span className="pl pl-1">他施的人民啊，</span><br /><span className="pl pl-1">去你們的田地耕作吧，像在尼羅河沿岸一樣，</span><br /><span className="pl pl-1">因為海港已不復存在。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="撒迦利亞書 9:3–4; 出埃及記 14:21; 耶利米書 47:7"> <span className="pl pl-1">耶和華向大海伸手，</span><br /><span className="pl pl-1">祂使列國震動。</span><br /><span className="pl pl-1">祂已下令毀滅迦南的堡壘。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="啟示錄 18:22; 以西結書 26:13–14; 以賽亞書 23:1–2"> <span className="pl pl-1">祂說：「受欺壓的處女西頓啊，</span><br /><span className="pl pl-1">你再也不能歡樂了！</span><br /><span className="pl pl-1">起來，逃到基提吧，</span><br /><span className="pl pl-1">只是在那裡你也得不到安寧。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v13" data-v="13" data-xref="哈巴谷書 1:6; 以賽亞書 10:5; 列王紀下 17:24"> 看看迦勒底人所居之地，這個民族已不復存在！亞述人使它成為野獸出沒之地。他們築起圍城的高臺，摧毀它的宮殿，使它淪為廢墟。</span>
<span className="v" id="v14" data-v="14" data-xref="以賽亞書 23:1; 以賽亞書 23:6; 以西結書 27:25–30"> <span className="pl pl-1">他施的船隻都哀號吧！</span><br /><span className="pl pl-1">因為你們的堡壘已被摧毀。</span></span>
<span className="v" id="v15" data-v="15" data-xref="耶利米書 25:22; 耶利米書 25:9–11; 但以理書 7:14"> 到那日，泰爾必被遺忘七十年，正好一個王的壽數。七十年之後，泰爾必如妓女之歌所描述的：</span>
<span className="v" id="v16" data-v="16" data-xref="耶利米書 30:14; 箴言 7:10–12"> <span className="pl pl-1">「被遺忘的妓女啊，</span><br /><span className="pl pl-1">拿起琴，走遍全城。</span><br /><span className="pl pl-1">要彈得美妙，多多唱歌，</span><br /><span className="pl pl-1">好使人再記起你。」</span></span>
<span className="v" id="v17" data-v="17" data-xref="那鴻書 3:4; 以西結書 27:6–36; 啟示錄 19:2"> 七十年後，耶和華必眷顧泰爾。她必重操舊業，與天下萬國交易。</span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 72:10; 申命記 26:12–14; 腓立比書 4:17–18"> 但她得到的利潤和收入不會被積攢或儲存起來，而是要被獻給耶和華，用來供應那些事奉耶和華的人，使他們吃得飽足，穿得精美。</span>
</div>

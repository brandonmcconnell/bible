## 未來的君王

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="馬太福音 4:15–16; 列王紀下 15:29; 以賽亞書 8:22"> 但那些受過痛苦的人必不再遇見黑暗。從前，耶和華使西布倫人和拿弗他利人住的地方受人藐視，日後必使這些地方，即約旦河東、沿海一帶、外族人居住的加利利得到榮耀。</span>
<span className="v" id="v2" data-v="2" data-xref="馬太福音 4:16; 以弗所書 5:8; 約翰福音 8:12"> <span className="pl pl-1">走在黑暗中的人必看見大光，</span><br /><span className="pl pl-1">活在死蔭之地的人必被光照亮。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="以賽亞書 35:10; 詩篇 119:162; 以賽亞書 26:15"> <span className="pl pl-1">耶和華啊，你必使以色列成為大國，</span><br /><span className="pl pl-1">使他們喜氣洋洋。</span><br /><span className="pl pl-1">他們必在你面前歡喜快樂，</span><br /><span className="pl pl-1">好像豐收時那樣歡喜，</span><br /><span className="pl pl-1">如同瓜分戰利品時那樣快樂。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="耶利米書 30:8; 以賽亞書 14:25; 以賽亞書 10:26–27"> <span className="pl pl-1">因為你必折斷他們負的重軛和欺壓者的棍棒，</span><br /><span className="pl pl-1">好像昔日你毀滅米甸人一樣；</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="帖撒羅尼迦後書 1:8; 詩篇 46:9; 以賽亞書 30:33"> <span className="pl pl-1">勇士爭戰穿的靴子和染血的戰袍都要被扔進火裡燒掉。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 2:11; 馬太福音 28:18; 耶利米書 23:5–6"> <span className="pl pl-1">因為必有一個嬰兒為我們誕生，</span><br /><span className="pl pl-1">有一個兒子要賜給我們，</span><br /><span className="pl pl-1">祂肩頭必擔負王權。</span><br /><span className="pl pl-1">祂被稱為奇妙的策士、大能的上帝、永存的父、和平的君。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 1:32–33; 但以理書 2:44; 但以理書 7:14"> <span className="pl pl-1">祂的國必長治久安。</span><br /><span className="pl pl-1">祂必坐在大衛的寶座上以公平和公義治國興邦，</span><br /><span className="pl pl-1">使國家永固。</span><br /><span className="pl pl-1">萬軍之耶和華必熱切地成就此事。</span></span>
</div>
</div>

## 耶和華要審判以色列

<div className="bt">
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="以賽亞書 8:4–8; 撒迦利亞書 1:6; 撒迦利亞書 5:1–4"> <span className="pl pl-1">主已出言審判雅各家，</span><br /><span className="pl pl-1">他的審判必臨到以色列，</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="以賽亞書 46:12; 彼得前書 5:5; 以西結書 7:27"> <span className="pl pl-1">以法蓮和撒瑪利亞的居民都知道。</span><br /><span className="pl pl-1">他們驕傲自大地說：</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="瑪拉基書 1:4; 列王紀上 10:27; 列王紀上 7:9–12"> <span className="pl pl-1">「磚牆倒塌了，</span><br /><span className="pl pl-1">我們鑿石重建；</span><br /><span className="pl pl-1">桑樹砍倒了，</span><br /><span className="pl pl-1">我們換種香柏樹。」</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="以賽亞書 8:4–7; 以賽亞書 17:1–5; 以賽亞書 7:8"> <span className="pl pl-1">因此耶和華必興起利汛的仇敵，</span><br /><span className="pl pl-1">驅使敵人來攻擊他們。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="以賽亞書 5:25; 歷代志下 28:18; 詩篇 79:7"> <span className="pl pl-1">東有亞蘭人，西有非利士人，</span><br /><span className="pl pl-1">他們必吞噬以色列。</span><br /><span className="pl pl-1">雖然如此，耶和華的怒氣還沒有止息，</span><br /><span className="pl pl-1">祂降罰的手仍沒有收回。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v13" data-v="13" data-xref="何西阿書 7:10; 以賽亞書 31:1; 耶利米書 5:3"> <span className="pl pl-1">但百姓沒有歸向擊打他們的主，</span><br /><span className="pl pl-1">也不尋求萬軍之耶和華。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="以賽亞書 19:15; 啟示錄 18:8; 何西阿書 1:6"> <span className="pl pl-1">因此，耶和華要在一日之間剷除以色列的頭和尾，</span><br /><span className="pl pl-1">棕樹枝和蘆葦。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="以賽亞書 29:10; 馬太福音 24:24; 撒母耳記上 9:6"> <span className="pl pl-1">頭是指他們的長老和首領，</span><br /><span className="pl pl-1">尾是指教人虛謊之事的假先知。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="馬太福音 15:14; 以賽亞書 3:12; 馬太福音 23:16–36"> <span className="pl pl-1">這些帶領者使百姓步入歧途、</span><br /><span className="pl pl-1">走向滅亡。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="耶利米書 18:21; 以賽亞書 10:6; 以賽亞書 5:25"> <span className="pl pl-1">他們都目無上帝，</span><br /><span className="pl pl-1">行事邪惡，口出妄語。</span><br /><span className="pl pl-1">所以，主不喜歡他們的青年，</span><br /><span className="pl pl-1">也不憐憫他們的孤兒寡婦。</span><br /><span className="pl pl-1">雖然如此，耶和華的怒氣還沒有止息，</span><br /><span className="pl pl-1">祂降罰的手仍沒有收回。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 83:14; 瑪拉基書 4:1; 以賽亞書 5:24"> <span className="pl pl-1">邪惡像燃燒的火焰，</span><br /><span className="pl pl-1">焚毀荊棘和蒺藜，點燃密林，</span><br /><span className="pl pl-1">煙柱旋轉上騰。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="彌迦書 7:2; 彌迦書 7:6; 約珥書 2:2"> <span className="pl pl-1">萬軍之耶和華的烈怒必如火燒焦大地，</span><br /><span className="pl pl-1">百姓成為燒火的柴，</span><br /><span className="pl pl-1">弟兄彼此相煎。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="以賽亞書 49:26; 耶利米書 19:9; 耶利米哀歌 4:10"> <span className="pl pl-1">他們左搶右奪，</span><br /><span className="pl pl-1">仍食不果腹，</span><br /><span className="pl pl-1">紛紛吃自己的骨肉</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「骨肉」或譯「臂膀的肉」。">a</a></sup><br /><span className="pl pl-1">。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="以賽亞書 5:25; 加拉太書 5:15; 以賽亞書 9:12"> <span className="pl pl-1">以法蓮和瑪拿西自相殘殺，</span><br /><span className="pl pl-1">又聯合起來攻打猶大。</span><br /><span className="pl pl-1">雖然如此，耶和華的怒氣還沒有止息，</span><br /><span className="pl pl-1">祂降罰的手仍沒有收回。</span></span>
</div>

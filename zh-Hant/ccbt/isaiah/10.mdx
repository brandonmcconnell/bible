## 主要審判亞述

<div className="bt">
<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="耶利米書 51:20–24; 以賽亞書 14:25; 以賽亞書 30:30"> <span className="pl pl-1">耶和華說：「亞述有禍了！</span><br /><span className="pl pl-1">他是我的憤怒之棍，</span><br /><span className="pl pl-1">他手中拿著我發烈怒的杖。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="以賽亞書 9:17; 耶利米書 25:9; 撒迦利亞書 10:5"> <span className="pl pl-1">我派他去攻打一個不虔敬的國家，</span><br /><span className="pl pl-1">我命他去攻擊一個惹我發怒的民族，</span><br /><span className="pl pl-1">去搶奪、擄掠他們的財物，</span><br /><span className="pl pl-1">像踐踏街上的泥土一樣踐踏他們。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="創世記 50:20; 彌迦書 4:11–12; 使徒行傳 2:23"> <span className="pl pl-1">可是他卻不這樣想，</span><br /><span className="pl pl-1">心裡也不這樣盤算，</span><br /><span className="pl pl-1">他只想毀滅和剷除許多國家。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="列王紀下 18:24; 列王紀下 19:10; 以西結書 26:7"> <span className="pl pl-1">他說，『我的臣僕豈不都是王嗎！</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="歷代志下 35:20; 列王紀下 16:9; 創世記 10:10"> <span className="pl pl-1">迦勒挪豈不是和迦基米施一樣嗎？</span><br /><span className="pl pl-1">哈馬豈不是和亞珥拔一樣嗎？</span><br /><span className="pl pl-1">撒瑪利亞豈不是和大馬士革一樣嗎？</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="以賽亞書 10:14; 列王紀下 19:17–19; 列王紀下 18:33–35"> <span className="pl pl-1">這些偶像之國都在我的手中，</span><br /><span className="pl pl-1">他們雕刻的偶像勝過耶路撒冷和撒瑪利亞的偶像。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="以賽亞書 37:10–13; 以賽亞書 2:8; 以賽亞書 36:19–20"> <span className="pl pl-1">我豈不像毀滅撒瑪利亞和它的偶像那樣，</span><br /><span className="pl pl-1">毀滅耶路撒冷和它的偶像嗎？』」</span></span>
<span className="v" id="v12" data-v="12" data-xref="列王紀下 19:31; 以賽亞書 65:7; 耶利米書 50:18"> 主完成在錫安山和耶路撒冷要做的事後，必懲罰心裡狂妄、眼目高傲的亞述王。</span>
<span className="v" id="v13" data-v="13" data-xref="申命記 8:17; 但以理書 4:30; 以西結書 26:2"> <span className="pl pl-1">因為亞述王說：</span><br /><span className="pl pl-1">「我靠自己的力量和智慧成就了此事，</span><br /><span className="pl pl-1">因為我很聰明。</span><br /><span className="pl pl-1">我廢除列國的疆界，</span><br /><span className="pl pl-1">擄掠他們的財物，</span><br /><span className="pl pl-1">像勇士一樣征服他們的君王。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="約伯記 31:25; 箴言 21:6–7; 那鴻書 2:9–1"> <span className="pl pl-1">我奪取列國的財物，</span><br /><span className="pl pl-1">好像探囊取物；</span><br /><span className="pl pl-1">我征服天下，</span><br /><span className="pl pl-1">不過是手到擒來；</span><br /><span className="pl pl-1">無人反抗，無人吭聲。」</span><br /></span>

## 以色列的餘民

<div className="bt">
<div className="bp poetry">
<span className="v" id="v20" data-v="20" data-xref="以賽亞書 37:31–32; 以賽亞書 50:10; 以賽亞書 1:9"> 到那日，以色列的餘民，雅各家的倖存者，將不再倚靠擊打他們的亞述，他們將真心倚靠以色列的聖者耶和華，</span>
<span className="v" id="v21" data-v="21" data-xref="以賽亞書 9:6; 哥林多後書 3:14–16; 何西阿書 7:10"> <span className="pl pl-1">一些餘民必歸回， 雅各的餘民必歸向大能的上帝。</span></span>
<span className="v" id="v22" data-v="22" data-xref="羅馬書 9:27–28; 以賽亞書 6:13; 啟示錄 20:8"> <span className="pl pl-1">以色列啊，你的人民雖多如海沙，將只有剩餘的人歸回。充滿公義的毀滅之事已定。</span></span>
<span className="v" id="v23" data-v="23" data-xref="以賽亞書 28:22; 以賽亞書 24:1–23; 羅馬書 9:28"> <span className="pl pl-1">因為主——萬軍之耶和華必按所定的在整個大地上施行毀滅。</span></span>
<span className="v" id="v24" data-v="24" data-xref="希伯來書 12:22–24; 以賽亞書 37:6; 以賽亞書 61:3"> 因此，主——萬軍之耶和華說：「我錫安的子民啊，雖然亞述人像埃及人一樣揮舞著棍棒毒打你們，你們不要懼怕。</span>
<span className="v" id="v25" data-v="25" data-xref="但以理書 11:36; 列王紀下 19:35; 希伯來書 10:37"> 因為很快我就不再向你們發怒，我要向他們發怒，毀滅他們。」</span>
<span className="v" id="v26" data-v="26" data-xref="以賽亞書 9:4; 士師記 7:25; 列王紀下 19:35"> 萬軍之耶和華要鞭打他們，就像在俄立磐石擊殺米甸人。祂的杖必像在埃及一樣向海伸出，懲罰他們。</span>
<span className="v" id="v27" data-v="27" data-xref="以賽亞書 9:4; 路加福音 4:18; 以賽亞書 14:25"> 到那日，祂必除去亞述人加在你們肩頭的重擔和頸上的軛；那軛必因你們肥壯而折斷。</span>
<span className="v" id="v28" data-v="28" data-xref="撒母耳記上 14:2; 撒母耳記上 13:2; 撒母耳記上 13:5"> <span className="pl pl-1">亞述大軍攻佔了亞葉，</span><br /><span className="pl pl-1">穿過米磯崙，</span><br /><span className="pl pl-1">把輜重存放在密抹。</span><br /></span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳記上 13:23; 撒母耳記上 7:17; 約書亞記 21:17"> <span className="pl pl-1">他們過了關口，</span><br /><span className="pl pl-1">在迦巴宿營。</span><br /><span className="pl pl-1">拉瑪人戰戰兢兢，</span><br /><span className="pl pl-1">掃羅的基比亞鄉親倉皇逃跑。</span><br /></span>
<span className="v" id="v30" data-v="30" data-xref="撒母耳記上 25:44; 耶利米書 1:1; 約書亞記 21:18"> <span className="pl pl-1">迦琳人啊，高聲喊叫吧！</span><br /><span className="pl pl-1">萊煞人啊，可憐的亞拿突人啊，</span><br /><span className="pl pl-1">留心聽吧！</span><br /></span>
<span className="v" id="v31" data-v="31" data-xref="約書亞記 15:31"> <span className="pl pl-1">瑪得米納人逃跑，</span><br /><span className="pl pl-1">基柄的居民躲藏。</span><br /></span>
<span className="v" id="v32" data-v="32" data-xref="撒母耳記上 21:1; 以賽亞書 37:22; 以賽亞書 19:16"> <span className="pl pl-1">那時，亞述王必屯兵挪伯，</span><br /><span className="pl pl-1">向著少女錫安的山嶺，</span><br /><span className="pl pl-1">向著耶路撒冷的山丘摩拳擦掌。</span></span>
</div>

## 希西迦向以賽亞求助

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀下 19:1–37; 以斯拉記 9:5; 以賽亞書 36:22–38"> 希西迦王聽後就撕裂衣服，披上麻衣，進入耶和華的殿。</span>
<span className="v" id="v2" data-v="2" data-xref="以賽亞書 1:1; 列王紀下 18:18; 以賽亞書 36:3"> 他派身披麻衣的宮廷總管以利亞敬、書記舍伯那和祭司中的長者，去見亞摩斯的兒子以賽亞先知，</span>
<span className="v" id="v3" data-v="3" data-xref="以賽亞書 66:9; 何西阿書 13:13; 以賽亞書 26:17–18"> 對他說：「希西迦說，『今天是遭難、蒙羞、受辱的日子，就像嬰兒要出生，產婦卻無力生產一樣。</span>
<span className="v" id="v4" data-v="4" data-xref="以賽亞書 1:9; 以賽亞書 36:20; 以賽亞書 10:22"> 亞述王派他的將軍來辱罵永活的上帝，也許你的上帝耶和華聽見那些話，就會懲罰他。因此，請你為我們這些剩下的人禱告。』」</span>
<span className="v" id="v5" data-v="5"> 希西迦王的臣僕前來見以賽亞，</span>
<span className="v" id="v6" data-v="6" data-xref="以賽亞書 7:4; 以賽亞書 35:4; 馬可福音 5:36"> 以賽亞對他們說：「告訴你們主人，耶和華這樣說，『你不要因為聽到亞述王的僕人那些褻瀆我的話而害怕。</span>
<span className="v" id="v7" data-v="7" data-xref="以賽亞書 31:8–9; 歷代志下 32:21; 以賽亞書 33:10–12"> 我必驚動<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「驚動」希伯來文是「使靈進入」。">a</a></sup>亞述王的心，讓他聽見一些風聲後便返回本國，使他在那裡死於刀下。』」</span>
<span className="v" id="v8" data-v="8" data-xref="約書亞記 10:29; 民數記 33:20–21; 列王紀下 19:8–9"> 亞述的將軍聽說亞述王已經離開拉吉，便回去見王，發現王在攻打立拿。</span>
<span className="v" id="v9" data-v="9" data-xref="以賽亞書 18:1; 以賽亞書 20:5; 以賽亞書 37:7"> 亞述王聽說古實王特哈加來攻打他，就派使者去見希西迦，說：</span>
<span className="v" id="v10" data-v="10" data-xref="以賽亞書 36:15; 列王紀下 18:5; 馬太福音 27:43"> 「不要讓你所倚靠的上帝愚弄你，說什麼耶路撒冷必不會落在亞述王手中。</span>
<span className="v" id="v11" data-v="11" data-xref="以賽亞書 36:18–20; 列王紀下 18:33–35; 以賽亞書 14:17"> 你肯定聽過亞述諸王掃滅列國的事，難道你能倖免嗎？</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 11:31; 列王紀下 17:6; 列王紀下 18:11"> 我先祖毀滅了歌散、哈蘭、利色和提·拉撒的伊甸，這些國家的神明救得了他們嗎？</span>
<span className="v" id="v13" data-v="13" data-xref="列王紀下 19:13; 列王紀下 17:24; 以賽亞書 36:19"> 哈馬王、亞珥拔王、西法瓦音王、希拿王和以瓦王如今在哪裡呢？」</span>
</div>
</div>

## 希西迦的禱告

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="列王紀下 19:14; 詩篇 123:1–4; 約珥書 2:17–20"> 希西迦從使者手中接過信，讀完後上到耶和華的殿，在耶和華面前展開信，</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳記上 7:8–9; 但以理書 9:3–4; 雅各書 5:13"> 向耶和華禱告說：</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 25:22; 詩篇 99:1; 詩篇 86:10"> 「坐在基路伯天使之上、以色列的上帝——萬軍之耶和華啊，唯有你是天下萬國的上帝，你創造了天地。</span>
<span className="v" id="v17" data-v="17" data-xref="歷代志下 6:40; 詩篇 17:6; 以賽亞書 37:4"> 耶和華啊，求你側耳垂聽！耶和華啊，求你睜眼察看！求你聽聽西拿基立派人來辱罵永活上帝的話。</span>
<span className="v" id="v18" data-v="18" data-xref="那鴻書 2:11–12; 列王紀下 15:29; 列王紀下 17:6"> 耶和華啊，亞述諸王確實掃滅列國，使他們的土地荒涼，</span>
<span className="v" id="v19" data-v="19" data-xref="以賽亞書 44:9–10; 耶利米書 10:11; 何西阿書 8:6"> 把他們的神像扔進火中燒毀。因為那些神像只是人用木頭石頭製造的，根本不是神明。</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 46:10; 列王紀上 18:36–37; 詩篇 83:17–18"> 我們的上帝耶和華啊，現在求你從亞述王手中拯救我們，讓天下萬國都知道唯有你是耶和華。」</span>
</div>
</div>

## 預言亞述必敗

<div className="bt">
<div className="bp poetry">
<span className="v" id="v21" data-v="21" data-xref="以賽亞書 58:9; 以賽亞書 38:3–6; 使徒行傳 4:31"> 亞摩斯的兒子以賽亞派人對希西迦說：「以色列的上帝耶和華說，『因為你就亞述王西拿基立的事向我禱告，</span>
<span className="v" id="v22" data-v="22" data-xref="約伯記 16:4; 耶利米哀歌 2:13; 以賽亞書 1:8"> 以下是耶和華對他的判語，<br /><span className="pl pl-1">「『處女錫安藐視你，嘲笑你；</span><br /><span className="pl pl-1">少女耶路撒冷朝你的背影搖頭。</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="以西結書 39:7; 但以理書 5:20–23; 以賽亞書 17:7"> <span className="pl pl-1">你侮辱、褻瀆誰呢？</span><br /><span className="pl pl-1">你高聲謾罵、傲眼蔑視誰呢？</span><br /><span className="pl pl-1">是以色列的聖者！</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="以賽亞書 14:8; 以賽亞書 10:18; 出埃及記 15:9"> <span className="pl pl-1">你藉你的使者辱罵主。</span><br /><span className="pl pl-1">你說你率領許多戰車上到高山，</span><br /><span className="pl pl-1">上到黎巴嫩的頂峰，</span><br /><span className="pl pl-1">砍下最高的香柏樹和上好的松樹，</span><br /><span className="pl pl-1">征服最高的山和最美的樹林。</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="列王紀上 20:10; 以賽亞書 36:12; 列王紀下 19:23–24"> <span className="pl pl-1">你說你已在外邦之地挖井取水，</span><br /><span className="pl pl-1">已用腳掌踏乾埃及所有的河流。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v26" data-v="26" data-xref="使徒行傳 4:27–28; 使徒行傳 2:23; 彼得前書 2:8"> <span className="pl pl-1">「『難道你沒有聽過這是我起初所定、亙古籌劃的嗎？</span><br /><span className="pl pl-1">如今我實現了所定的計劃：</span><br /><span className="pl pl-1">藉著你使堅城淪為廢墟。</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="詩篇 129:6; 詩篇 37:2; 彼得前書 1:24"> <span className="pl pl-1">城中的居民軟弱無力，</span><br /><span className="pl pl-1">驚慌失措，羞愧難當，</span><br /><span className="pl pl-1">脆弱如野草和菜蔬，</span><br /><span className="pl pl-1">又像還未長大就被曬焦的房頂草。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v28" data-v="28" data-xref="啟示錄 2:13; 詩篇 139:1–11; 耶利米書 23:23–24"> <span className="pl pl-1">「『你起你坐，你出你進，</span><br /><span className="pl pl-1">你向我發怒，我都知道。</span><br /></span>
<span className="v" id="v29" data-v="29" data-xref="以西結書 38:4; 以賽亞書 30:28; 以賽亞書 37:34"> <span className="pl pl-1">因為你向我發怒，</span><br /><span className="pl pl-1">你狂傲的話傳到了我耳中，</span><br /><span className="pl pl-1">我要用鉤子鉤住你的鼻子，</span><br /><span className="pl pl-1">把嚼環放在你嘴裡，</span><br /><span className="pl pl-1">使你原路返回。』</span></span>
<span className="v" id="v30" data-v="30" data-xref="列王紀下 19:29; 利未記 25:4–5; 列王紀上 13:3–5"> 「希西迦啊，我要給你一個兆頭。你們今年要吃野生的，明年要吃自然生長的，後年要播種收割，栽種葡萄園，吃園中的果子。</span>
<span className="v" id="v31" data-v="31" data-xref="以賽亞書 27:6; 列王紀下 19:30–31; 詩篇 80:9"> 猶大的倖存者要再次向下扎根，向上結果。</span>
<span className="v" id="v32" data-v="32" data-xref="以賽亞書 9:7; 列王紀下 19:31; 以賽亞書 59:17"> 因為將有餘民從耶路撒冷出來，有倖存者從錫安山出來。萬軍之耶和華必熱切地成就這事。</span>
<span className="v" id="v33" data-v="33" data-xref="以賽亞書 17:12; 以賽亞書 10:32–34; 以賽亞書 17:14"> 至於亞述王，耶和華說，『他必不能進這城或向這裡射一箭，必不能手持盾牌兵臨城下或修築攻城的高臺。</span>
<span className="v" id="v34" data-v="34" data-xref="以賽亞書 37:29; 箴言 21:30"> 他必原路返回，不得進入這城。這是耶和華說的。</span>
<span className="v" id="v35" data-v="35" data-xref="列王紀下 20:6; 以賽亞書 38:6; 以賽亞書 31:5"> 我必為自己和我僕人大衛的緣故而保護、拯救這城。』」</span>
<span className="v" id="v36" data-v="36" data-xref="以賽亞書 10:12; 列王紀下 19:35; 以賽亞書 10:33–34"> 於是，耶和華的天使到亞述營中殺了十八萬五千人。人們清早起來，發現到處都是屍體。</span>
<span className="v" id="v37" data-v="37" data-xref="約拿書 1:2; 約拿書 3:3; 創世記 10:11–12"> 亞述王西拿基立便拔營回國，住在尼尼微。</span>
<span className="v" id="v38" data-v="38" data-xref="創世記 8:4; 耶利米書 51:27; 以斯拉記 4:2"> 一天，他在廟裡祭拜他的神明尼斯洛時，他兒子亞得米勒和沙利色用刀殺了他，逃往亞拉臘。他兒子以撒哈頓繼位。</span>
</div>

<span className="v" id="v3" data-v="3" data-xref="腓立比書 4:7; 約翰福音 16:33; 約翰福音 14:27"> <span className="pl pl-1">你使堅信不移的人全然平安，</span><br /><span className="pl pl-1">因為他們信靠你。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="以賽亞書 12:2; 詩篇 62:8; 詩篇 55:22"> <span className="pl pl-1">要永遠信靠耶和華，</span><br /><span className="pl pl-1">因為耶和華上帝是永遠屹立的磐石。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="耶利米書 51:37; 啟示錄 18:2; 約伯記 40:11–13"> <span className="pl pl-1">祂貶抑高傲的人，</span><br /><span className="pl pl-1">拆毀他們高聳的城邑，</span><br /><span className="pl pl-1">把它們夷為平地、化為塵土，</span><br /></span>

</div>
<div className="bp poetry">

<span className="v" id="v9" data-v="9" data-xref="馬太福音 6:33; 詩篇 63:1; 詩篇 119:62"> <span className="pl pl-1">在夜間，我的心思慕你，</span><br /><span className="pl pl-1">我的靈切切地尋求你。</span><br /><span className="pl pl-1">你在世上施行審判的時候，</span><br /><span className="pl pl-1">世人就學習行義。</span><br /></span>

<span className="v" id="v12" data-v="12" data-xref="以弗所書 2:10; 詩篇 57:2; 詩篇 29:11"> <span className="pl pl-1">耶和華啊，你必賜我們平安，</span><br /><span className="pl pl-1">因為我們所做的事都是你為我們成就的。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="以賽亞書 63:7; 以賽亞書 2:8; 以賽亞書 10:11"> <span className="pl pl-1">我們的上帝耶和華啊！</span><br /><span className="pl pl-1">除你以外曾有別的主人管轄我們，</span><br /><span className="pl pl-1">但我們只尊崇你的名。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="啟示錄 18:2–3; 箴言 10:7; 以賽亞書 51:12–13"> <span className="pl pl-1">他們都已死去，再不能復生，</span><br /><span className="pl pl-1">逝去的靈魂不能再回來。</span><br /><span className="pl pl-1">因此你懲罰他們，毀滅他們，</span><br /><span className="pl pl-1">使他們被人徹底遺忘。</span><br /></span>

</div>

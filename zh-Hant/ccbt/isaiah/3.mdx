## 對耶路撒冷和猶大的審判

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="利未記 26:26; 以西結書 14:13; 以賽亞書 1:24"> 看啊，主——萬軍之耶和華要從耶路撒冷和猶大拿去眾人倚靠的一切：糧食、水、</span>
<span className="v" id="v2" data-v="2" data-xref="以賽亞書 9:14–15; 列王紀下 24:14–16; 耶利米哀歌 5:12–14"> <span className="pl pl-1">英雄、戰士、審判官、先知、</span><br /><span className="pl pl-1">占卜者、長老、</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="士師記 8:18; 申命記 1:15; 出埃及記 18:21"> <span className="pl pl-1">五十夫長、顯貴、謀士、巧匠和巫師。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="傳道書 10:16; 歷代志下 33:1; 列王紀上 3:7–9"> <span className="pl pl-1">主必使少兒做他們的首領，</span><br /><span className="pl pl-1">讓孩童治理他們。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="耶利米書 9:3–8; 瑪拉基書 3:5; 馬太福音 27:28–30"> <span className="pl pl-1">百姓將彼此欺凌，</span><br /><span className="pl pl-1">鄰居互相爭鬥，</span><br /><span className="pl pl-1">少年目無尊長，</span><br /><span className="pl pl-1">卑賤者欺尊犯上。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="以賽亞書 4:1; 約翰福音 6:15; 士師記 11:6–8"> <span className="pl pl-1">那時，人會拉住一位同族的弟兄說：</span><br /><span className="pl pl-1">「你有外衣穿，你做我們的首領吧，</span><br /><span className="pl pl-1">這廢墟之地就交給你了！」</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="何西阿書 5:13; 耶利米哀歌 2:13; 以西結書 34:4"> <span className="pl pl-1">但那人必高聲說：</span><br /><span className="pl pl-1">「我救不了你們。</span><br /><span className="pl pl-1">我家中無衣無食，</span><br /><span className="pl pl-1">不要讓我做百姓的首領。」</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="哥林多前書 10:22; 以西結書 9:9; 瑪拉基書 3:13–15"> <span className="pl pl-1">耶路撒冷崩潰，</span><br /><span className="pl pl-1">猶大敗落，</span><br /><span className="pl pl-1">因為他們的言行冒犯耶和華，</span><br /><span className="pl pl-1">蔑視榮耀的主。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="創世記 13:13; 創世記 18:20–21; 列王紀下 9:30"> <span className="pl pl-1">他們的表情顯出他們心術不正，</span><br /><span className="pl pl-1">他們跟所多瑪人一樣對自己的罪惡津津樂道，</span><br /><span className="pl pl-1">毫不隱瞞。</span><br /><span className="pl pl-1">他們必大禍臨頭，自招災難。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 128:1–2; 希伯來書 6:10; 傳道書 8:12"> <span className="pl pl-1">要告訴義人：他們必有福樂，</span><br /><span className="pl pl-1">因為他們必吃自己行為結出的果子。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="傳道書 8:13; 雅各書 2:13; 詩篇 62:12"> <span className="pl pl-1">惡人有禍了！他們必大禍臨頭，</span><br /><span className="pl pl-1">因惡行而遭報應。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="以賽亞書 3:4; 那鴻書 3:13; 列王紀下 11:1"> <span className="pl pl-1">耶和華說：「我的子民啊！</span><br /><span className="pl pl-1">孩童欺壓你們，</span><br /><span className="pl pl-1">婦女管轄你們。</span><br /><span className="pl pl-1">你們的首領領你們入迷途，</span><br /><span className="pl pl-1">帶你們走歧路。」</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="彌迦書 6:2; 何西阿書 4:1–2; 箴言 22:22–23"> <span className="pl pl-1">耶和華準備就緒，</span><br /><span className="pl pl-1">要起來審判祂的子民。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="約伯記 22:4; 詩篇 143:2; 以賽亞書 3:2–3"> <span className="pl pl-1">祂必審問祂子民中的長老和首領，對他們說：</span><br /><span className="pl pl-1">「就是你們毀壞了我的葡萄園，</span><br /><span className="pl pl-1">家裡堆著從窮人那裡掠奪的東西。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="彌迦書 3:2–3; 詩篇 94:5; 阿摩司書 2:6–7"> <span className="pl pl-1">你們為何壓榨我的子民，</span><br /><span className="pl pl-1">碾磨貧窮人的臉？」</span><br /><span className="pl pl-1">這是主——萬軍之耶和華說的。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="以賽亞書 32:9–11; 以西結書 16:49–50; 以賽亞書 4:4"> <span className="pl pl-1">耶和華又說：</span><br /><span className="pl pl-1">「錫安的女子狂傲，</span><br /><span className="pl pl-1">昂首走路，賣弄媚眼，</span><br /><span className="pl pl-1">俏步徐行，腳鐲叮噹。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="耶利米書 13:22; 彌迦書 1:11; 啟示錄 16:2"> <span className="pl pl-1">所以，我要使她們頭上長瘡，</span><br /><span className="pl pl-1">前額光禿。」</span></span>

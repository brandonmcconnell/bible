## 關於大馬士革的預言

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="以賽亞書 25:2; 撒迦利亞書 9:1; 阿摩司書 1:3–5"> 以下是關於大馬士革的預言：<br /><span className="pl pl-1">「看啊，大馬士革城必不復存在，淪為廢墟。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="以西結書 25:5; 耶利米書 7:33; 民數記 32:34"> <span className="pl pl-1">亞羅珥的眾城邑必被廢棄，</span><br /><span className="pl pl-1">羊群將在那裡棲息，</span><br /><span className="pl pl-1">沒有人驚擾牠們。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="何西阿書 9:11; 以賽亞書 8:4; 以賽亞書 7:16"> <span className="pl pl-1">以法蓮</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="舊約中常用以法蓮代表以色列國。">a</a></sup><br /><span className="pl pl-1">的堡壘必被摧毀，</span><br /><span className="pl pl-1">大馬士革的王權必喪失。</span><br /><span className="pl pl-1">倖存的亞蘭人必像以色列人的榮耀一樣消失。」</span><br /><span className="pl pl-1">這是萬軍之耶和華說的。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v4" data-v="4" data-xref="以賽亞書 10:16; 申命記 32:15–27; 以賽亞書 24:13"> <span className="pl pl-1">「到那日，雅各的榮耀必消失，</span><br /><span className="pl pl-1">他肥胖的身軀必漸漸消瘦。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="馬太福音 13:30; 約珥書 3:13; 耶利米書 51:33"> <span className="pl pl-1">那時就像人收割莊稼，收集麥穗，</span><br /><span className="pl pl-1">又像人在利乏音谷拾取麥穗。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="以賽亞書 24:13; 申命記 4:27; 羅馬書 9:27"> <span className="pl pl-1">倖存者寥寥無幾，就像打過的橄欖樹上剩下的果子，</span><br /><span className="pl pl-1">或兩三個掛在樹梢，</span><br /><span className="pl pl-1">或四五個殘存在枝頭。」</span><br /><span className="pl pl-1">這是以色列的上帝耶和華說的。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="彌迦書 7:7; 何西阿書 6:1; 何西阿書 3:5"> 到那日，人們必仰望他們的創造主，把目光轉向以色列的聖者。</span>
<span className="v" id="v8" data-v="8" data-xref="以賽亞書 30:22; 以賽亞書 27:9; 以賽亞書 2:8"> 那時他們不再仰望自己雙手所造的祭壇，也不再關注自己指頭所造的亞舍拉神像和香壇。</span>
<span className="v" id="v9" data-v="9" data-xref="阿摩司書 3:11–15; 以賽亞書 27:10; 以賽亞書 24:1–12"> 到那日，他們因以色列人而離棄的堅城必如長滿荊棘和雜草的廢地，一片荒涼。</span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 106:21; 申命記 32:18; 以賽亞書 26:4"> <span className="pl pl-1">你們忘記了拯救你們的上帝，</span><br /><span className="pl pl-1">不記念那保護你們的磐石。</span><br /><span className="pl pl-1">所以，你們雖然栽種佳美的秧子，</span><br /><span className="pl pl-1">插上異國的樹苗，</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="約伯記 4:8; 何西阿書 8:7; 加拉太書 6:7–8"> <span className="pl pl-1">使它們在栽種的當天早上就生長開花，</span><br /><span className="pl pl-1">也必一無所獲。</span><br /><span className="pl pl-1">那時只有艱難和無盡的痛苦。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="耶利米書 6:23; 路加福音 21:25; 詩篇 18:4"> <span className="pl pl-1">唉！列國喧囂，如怒海洶湧；</span><br /><span className="pl pl-1">萬民騷動，如洪水滔滔。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 9:5; 詩篇 1:4; 以賽亞書 41:15–16"> <span className="pl pl-1">雖然萬民喧囂如洶湧的洪水，</span><br /><span className="pl pl-1">但上帝一斥責，他們便逃往遠方，</span><br /><span className="pl pl-1">像山頂上被風捲走的糠秕，</span><br /><span className="pl pl-1">又如狂風捲起的塵埃。</span></span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="列王紀下 19:35; 箴言 22:23; 耶利米書 13:25"> 他們晚上令人恐懼，早晨已無影無蹤。這就是擄掠我們之人的下場，搶奪我們之人的報應。</span>
</div>
</div>

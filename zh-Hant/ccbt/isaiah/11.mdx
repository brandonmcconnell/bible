## 大衛的後裔做王

<div className="bt">
<div className="bp poetry">

<span className="v" id="v2" data-v="2" data-xref="以賽亞書 61:1; 約翰福音 16:13; 以弗所書 1:17–18"> <span className="pl pl-1">耶和華的靈必住在祂身上，</span><br /><span className="pl pl-1">使祂有聰明和智慧、謀略和能力，</span><br /><span className="pl pl-1">能認識並敬畏耶和華。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="約翰福音 7:24; 約翰福音 8:15–16; 路加福音 2:52"> <span className="pl pl-1">祂必以敬畏耶和華為樂。</span><br /><span className="pl pl-1">祂不憑眼見施行審判，</span><br /><span className="pl pl-1">不憑耳聞斷定是非，</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="帖撒羅尼迦後書 2:8; 啟示錄 19:15; 瑪拉基書 4:6"> <span className="pl pl-1">而是按公義審判貧窮人，</span><br /><span className="pl pl-1">以公正為受苦者斷案。</span><br /><span className="pl pl-1">祂必用口中的杖擊打世界，</span><br /><span className="pl pl-1">以嘴裡的氣殺戮惡人。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="以弗所書 6:14; 約翰一書 1:9; 哥林多後書 6:7"> <span className="pl pl-1">公義必作祂的腰帶，</span><br /><span className="pl pl-1">信實必作祂肋下的帶子。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="以賽亞書 65:25; 何西阿書 2:18; 以西結書 34:25"> <span className="pl pl-1">那時，豺狼和綿羊羔同住，</span><br /><span className="pl pl-1">豹子和山羊羔同臥，</span><br /><span className="pl pl-1">牛犢和獅子同群，</span><br /><span className="pl pl-1">小孩子必引領牠們。</span><br /></span>
<span className="v" id="v7" data-v="7"> <span className="pl pl-1">牛與熊一起進食，</span><br /><span className="pl pl-1">小牛和小熊一起躺臥，</span><br /><span className="pl pl-1">獅子像牛一樣吃草。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="以賽亞書 59:5; 詩篇 140:3"> <span className="pl pl-1">吃奶的嬰孩必在毒蛇的洞口玩耍，</span><br /><span className="pl pl-1">斷奶的孩子必把手伸進蛇洞。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="哈巴谷書 2:14; 以賽亞書 52:10; 詩篇 98:2–3"> <span className="pl pl-1">在我的整個聖山上，</span><br /><span className="pl pl-1">牠們都不傷人、不害物。</span><br /><span className="pl pl-1">因為大地必充滿對耶和華的認識，</span><br /><span className="pl pl-1">如同海洋被水充滿。</span></span>
<span className="v" id="v10" data-v="10" data-xref="羅馬書 15:9–12; 路加福音 2:32; 以賽亞書 11:1"> 到那日，耶西的根必成為引導萬民的旗幟，列邦都來尋求祂，祂的安歇之處充滿榮耀。</span>
<span className="v" id="v11" data-v="11" data-xref="彌迦書 7:12; 以賽亞書 10:20; 撒迦利亞書 10:8–12"> 到那日，主必再次伸手從亞述、埃及、巴特羅、古實、以攔、示拿、哈馬和眾海島救回祂剩餘的子民。</span>
<span className="v" id="v12" data-v="12" data-xref="以賽亞書 56:8; 以賽亞書 43:6; 西番雅書 3:10"> <span className="pl pl-1">祂必向各國豎立旗幟，</span><br /><span className="pl pl-1">召集被擄的以色列人，</span><br /><span className="pl pl-1">把分散在世界各地的猶大人聚集起來。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="耶利米書 3:18; 何西阿書 1:11; 以西結書 37:16–24"> <span className="pl pl-1">以法蓮必不再嫉妒，</span><br /><span className="pl pl-1">猶大的仇敵必被剷除，</span><br /><span className="pl pl-1">以法蓮必不嫉妒猶大，</span><br /><span className="pl pl-1">猶大必不與以法蓮為敵。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="約珥書 3:19; 以賽亞書 25:10; 耶利米書 49:28"> <span className="pl pl-1">他們必向西突襲非利士。</span><br /><span className="pl pl-1">他們必一起擄掠東方人，</span><br /><span className="pl pl-1">征服以東和摩押，</span><br /><span className="pl pl-1">亞捫人必順從他們。</span><br /></span>

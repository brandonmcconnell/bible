## 錫安蒙主喜悅

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="以賽亞書 62:6–7; 箴言 4:18; 以賽亞書 32:15–17"> 為了錫安我不再緘默，<br /><span className="pl pl-1">為了耶路撒冷我不再沉默，</span><br /><span className="pl pl-1">直到她的公義如明光照耀，</span><br /><span className="pl pl-1">她的救恩如燃燒的火把。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="以賽亞書 62:12; 創世記 17:5; 以賽亞書 66:12"> <span className="pl pl-1">耶路撒冷啊，</span><br /><span className="pl pl-1">列國必看見你的公義，</span><br /><span className="pl pl-1">列王必看見你的榮耀，</span><br /><span className="pl pl-1">耶和華必親口賜你一個新名字。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="以賽亞書 28:5; 帖撒羅尼迦前書 2:19; 撒迦利亞書 9:16"> <span className="pl pl-1">你必成為耶和華手中的華冠，</span><br /><span className="pl pl-1">你上帝手上的榮冕。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="西番雅書 3:17; 何西阿書 2:19–20; 以賽亞書 62:12"> <span className="pl pl-1">你不再被稱為「棄婦」，</span><br /><span className="pl pl-1">你的土地不再被稱為「荒涼之地」。</span><br /><span className="pl pl-1">你要被稱為「主所喜悅的」，</span><br /><span className="pl pl-1">你的土地要被稱為「有夫之婦」，</span><br /><span className="pl pl-1">因為耶和華必喜愛你，</span><br /><span className="pl pl-1">做你土地的丈夫。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="以賽亞書 62:4; 以賽亞書 65:19; 希伯來書 12:2"> <span className="pl pl-1">你的人民必娶你，</span><br /><span className="pl pl-1">好像少男娶少女；</span><br /><span className="pl pl-1">上帝必喜愛你，</span><br /><span className="pl pl-1">如同新郎喜愛新娘。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="以賽亞書 52:8; 以西結書 3:17–21; 詩篇 134:1–2"> <span className="pl pl-1">耶路撒冷啊，</span><br /><span className="pl pl-1">我已在你城牆上設立守望者。</span><br /><span className="pl pl-1">他們晝夜不停地禱告。</span><br /><span className="pl pl-1">呼求耶和華的人啊，</span><br /><span className="pl pl-1">你們不可歇息，</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="耶利米書 33:9; 西番雅書 3:19–20; 以賽亞書 60:18"> <span className="pl pl-1">要常常敦促祂，</span><br /><span className="pl pl-1">直到祂建立耶路撒冷，</span><br /><span className="pl pl-1">使耶路撒冷得到普世的讚美。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="以賽亞書 65:21–23; 士師記 6:3–6; 申命記 28:33"> <span className="pl pl-1">耶和華憑祂的右手，憑祂大能的臂膀起誓說：</span><br /><span className="pl pl-1">「我再也不會把你的五穀給你的仇敵吃，</span><br /><span className="pl pl-1">再也不會讓外族人喝你辛苦釀製的新酒。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="申命記 12:12; 申命記 16:11; 申命記 12:7"> <span className="pl pl-1">收割的人必享受五穀，</span><br /><span className="pl pl-1">讚美耶和華，</span><br /><span className="pl pl-1">摘葡萄的人必在我聖所的院內喝酒。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="以賽亞書 57:14; 以賽亞書 40:3; 希伯來書 12:13"> <span className="pl pl-1">你們要出去，去城外，</span><br /><span className="pl pl-1">為百姓修平道路。</span><br /><span className="pl pl-1">你們要修築，修築大道，</span><br /><span className="pl pl-1">清除石頭，</span><br /><span className="pl pl-1">為萬民豎立旗幟。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="撒迦利亞書 9:9; 馬太福音 21:5; 約翰福音 12:15"> <span className="pl pl-1">看啊，耶和華已經向普世宣告：「要對少女錫安說，</span><br /><span className="pl pl-1">『看啊，你的拯救者帶著獎賞和報酬來了！』」</span><br /></span>

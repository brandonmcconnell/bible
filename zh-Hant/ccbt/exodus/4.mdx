## 上帝賜摩西能力

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及記 3:18; 出埃及記 2:14; 耶利米書 1:6"> 摩西回答說：「他們不會相信我，也不會聽我的話，他們會說，『耶和華根本沒有向你顯現。』」</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 4:17; 出埃及記 4:20; 以賽亞書 11:4"> 耶和華對摩西說：「你手裡拿的是什麼？」摩西說：「是一根手杖。」</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 7:10–15; 阿摩司書 5:19; 出埃及記 4:17"> 耶和華說：「把它扔在地上！」於是，摩西把杖扔在地上，杖變成了一條蛇。摩西連忙跑開。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行傳 28:3–6; 創世記 22:1–2; 詩篇 91:13"> 耶和華說：「你伸手抓住牠的尾巴！」摩西就伸手抓蛇的尾巴，蛇在他手中變回了杖。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 19:9; 創世記 48:3; 出埃及記 3:15"> 耶和華說：「這樣，他們就會相信他們祖先的上帝耶和華，就是亞伯拉罕、以撒和雅各的上帝，曾經向你顯現。」</span>
<span className="v" id="v6" data-v="6" data-xref="列王紀下 5:27; 民數記 12:10"> 耶和華又說：「把手放進懷裡。」摩西把手放進懷裡，手抽出來的時候，竟患了痲瘋病，像雪一樣白。</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀下 5:14; 申命記 32:39; 馬太福音 8:3"> 耶和華說：「再把手放進懷裡。」摩西又把手放進懷裡，這次再抽出來的時候，手已經復原，跟其他地方的皮肉一樣。</span>
<span className="v" id="v8" data-v="8" data-xref="以賽亞書 28:10; 申命記 32:39; 出埃及記 4:30–31"> 耶和華說：「縱然他們不聽你的話，不信第一個神蹟，也必定相信第二個神蹟。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及記 7:19–25; 出埃及記 1:22; 馬太福音 7:2"> 如果他們兩個神蹟都不相信，還是不聽你的話，你就從尼羅河裡取些水來倒在旱地上，那水就會在旱地上變成血。」</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米書 1:6; 出埃及記 6:12; 使徒行傳 7:22"> 摩西對耶和華說：「主啊！我向來不善言辭，即使你對僕人說話以後，我還是不善言辭，因為我是個拙口笨舌的人。」</span>
<span className="v" id="v11" data-v="11" data-xref="阿摩司書 3:6; 詩篇 146:8; 以西結書 3:26–27"> 耶和華對他說：「是誰造人的口舌？是誰使人啞巴或耳聾？是誰使人目明或眼瞎？豈不都是我耶和華嗎？</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米書 1:9; 路加福音 12:11–12; 馬太福音 10:19–20"> 去吧！我必賜給你口才，指示你說什麼話。」</span>
<span className="v" id="v13" data-v="13" data-xref="約拿書 1:3; 出埃及記 4:1; 馬太福音 13:41"> 但是摩西說：「主啊，請派其他人去吧。」</span>
<span className="v" id="v14" data-v="14" data-xref="馬可福音 14:13–15; 出埃及記 4:27; 歷代志上 21:7"> 耶和華向摩西發怒說：「利未人亞倫不是你哥哥嗎？我知道他是個能言善辯的人，正要來迎接你。他見到你一定很歡喜。</span>
<span className="v" id="v15" data-v="15" data-xref="以賽亞書 51:16; 申命記 18:18; 路加福音 21:15"> 你要把該說的話傳給他，我會賜你們口才，教你們如何行事。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 7:1–2; 詩篇 82:6; 約翰福音 10:34–35"> 他要替你向百姓說話，做你的發言人，你對他來說就像上帝一樣。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及記 4:2; 哥林多前書 1:27; 出埃及記 7:9–20"> 你要把手杖帶在身邊，以便行神蹟。」</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及記 3:1; 撒母耳記上 1:17; 提摩太前書 6:1"> 摩西回到家裡，對他的岳父葉特羅說：「求你讓我回埃及去探望我的親人，看看他們是否在世。」葉特羅說：「你平安地去吧。」</span>
<span className="v" id="v19" data-v="19" data-xref="馬太福音 2:20; 出埃及記 2:23; 出埃及記 2:15"> 耶和華在米甸對摩西說：「你只管放心回埃及去，想害你性命的人都已經死了。」</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及記 17:9; 民數記 20:8–9; 出埃及記 18:3–4"> 於是，摩西拿著上帝的杖，帶著妻子和兒子騎驢返回埃及。</span>
<span className="v" id="v21" data-v="21" data-xref="羅馬書 9:18; 以賽亞書 63:17; 出埃及記 14:8"> 耶和華對摩西說：「你到了埃及，務要照我賜給你的能力在法老面前行神蹟。但我要使他的心剛硬，他必不讓百姓離開。</span>
<span className="v" id="v22" data-v="22" data-xref="何西阿書 11:1; 羅馬書 9:4; 耶利米書 31:9"> 那時，你就告訴法老，『耶和華說，以色列是我的長子，</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及記 11:5; 出埃及記 12:29; 詩篇 135:8"> 我對你說過讓我的長子出去事奉我，但你執意不肯。看啊，我要殺你的長子。』」</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 17:14; 民數記 22:22–23; 何西阿書 13:8"> 摩西在途中夜宿的時候，耶和華遇見摩西，想要殺他。</span>
<span className="v" id="v25" data-v="25" data-xref="約書亞記 5:2–3; 創世記 17:14; 撒母耳記下 16:7"> 他的妻子西坡拉拿起鋒利的火石，割下兒子的包皮，用它碰摩西的腳，說：「你真是我的血郎。」</span>
<span className="v" id="v26" data-v="26"> 這樣，耶和華才放過他。當時，西坡拉說「血郎」是指割禮一事。</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及記 3:1; 出埃及記 4:14–16; 列王紀上 19:8"> 耶和華對亞倫說：「你到曠野去迎接摩西。」他就在上帝的山上遇見摩西，並親吻他。</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及記 4:8–9; 出埃及記 4:15–16; 馬太福音 21:29"> 摩西把耶和華吩咐他的以及要他行的神蹟都告訴了亞倫。</span>
<span className="v" id="v29" data-v="29" data-xref="出埃及記 3:16; 出埃及記 24:11; 出埃及記 24:1"> 摩西和亞倫一起回去招聚以色列的眾長老，</span>
<span className="v" id="v30" data-v="30" data-xref="出埃及記 4:16"> 亞倫把耶和華對摩西的吩咐詳細地告訴他們。摩西又在百姓面前行了那些神蹟，</span>
<span className="v" id="v31" data-v="31" data-xref="出埃及記 3:18; 出埃及記 2:25; 詩篇 106:12–13"> 百姓相信了。以色列人聽見耶和華眷顧他們、看到了他們的苦難，都俯伏敬拜祂。</span>

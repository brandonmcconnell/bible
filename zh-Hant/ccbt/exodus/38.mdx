## 祭壇、院子和奉獻的物品

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及記 27:1–8; 以西結書 43:13–17; 出埃及記 40:6"> 比撒列用皂莢木造了方形的燔祭壇，長寬各兩米二，高一米三，</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 27:2; 約伯記 6:12"> 在壇的四角造四個凸起的角，與壇連成一體，壇外面包上銅。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 27:3; 撒母耳記上 2:13"> 他用銅造祭壇用的一切器具，就是鍋、鏟、碗、肉叉、火鼎。</span>
<span className="v" id="v4" data-v="4"> 又造了一個銅網，銅網在祭壇圍邊的下方，向下伸展到祭壇的腰部，</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 27:4"> 在銅網的四角鑄四個銅環，以便穿橫槓。</span>
<span className="v" id="v6" data-v="6" data-xref="申命記 10:3; 出埃及記 25:6"> 他用皂莢木做橫槓，包上銅，</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行傳 9:15; 哥林多前書 2:2; 哥林多前書 1:24"> 把橫槓穿在壇兩旁的銅環裡，以便抬壇。壇是中空的，用木板製作。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳記上 2:22; 路加福音 2:37; 出埃及記 40:7"> 他用在會幕門口服侍的婦女們的銅鏡造銅盆和盆座。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及記 27:9–19; 詩篇 89:7; 列王紀上 6:36"> 他用帷幔圍成院子，院子南面的帷幔用細麻織成，長四十五米。</span>
<span className="v" id="v10" data-v="10"> 帷幔有二十根柱子，二十個帶凹槽的銅底座，柱子上的鉤和箍都是銀的。</span>
<span className="v" id="v11" data-v="11"> 北面的帷幔也是長四十五米，柱子、銅底座、鉤和箍的樣式都與南面的一樣。</span>
<span className="v" id="v12" data-v="12"> 西面的帷幔寬二十二米半，有十根柱子和十個帶凹槽的底座，鉤和箍都是銀的。</span>
<span className="v" id="v13" data-v="13"> 東面的帷幔也是寬二十二米半。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及記 27:14"> 入口兩邊的帷幔都是寬七米，各有三根柱子和三個帶凹槽的底座。</span>
<span className="v" id="v16" data-v="16"> 院子四面的帷幔都用細麻織成。</span>
<span className="v" id="v17" data-v="17"> 柱子帶凹槽的底座是銅的，柱子上面的鉤和箍是銀的，柱頂包銀，院子所有的柱子都有銀箍。</span>
<span className="v" id="v18" data-v="18" data-xref="歷代志下 3:14"> 院子入口的門簾用細麻和藍色、紫色、朱紅色毛線繡製，長九米、高兩米二，與院子帷幔的高度一樣。</span>
<span className="v" id="v19" data-v="19"> 門簾有四根柱子和四個帶凹槽的銅底座，柱子上的鉤和箍都是銀的，柱頂包銀。</span>
<span className="v" id="v20" data-v="20" data-xref="歷代志下 3:9; 出埃及記 27:19; 以弗所書 2:21–22"> 聖幕和院子四圍所有的橛子都是銅的。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行傳 7:44; 民數記 9:15; 歷代志下 24:6"> 以上是安放約櫃的聖幕中所用的物品，是照摩西的吩咐，由亞倫祭司的兒子以他瑪指揮利未人清點的。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及記 35:30–3; 出埃及記 31:1–5; 詩篇 119:6"> 猶大支派戶珥的孫子、烏利的兒子比撒列做好了耶和華吩咐摩西預備的一切物品。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及記 35:34; 出埃及記 31:6"> 他的助手是但支派亞希撒抹的兒子亞何利亞伯，是雕刻家和設計師，並善用細麻和藍色、紫色、朱紅色毛線刺繡。</span>
<span className="v" id="v24" data-v="24" data-xref="民數記 18:16; 民數記 3:47; 利未記 27:25"> 按聖所的秤計算，建造聖所共用了奉獻的金子兩萬兩。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及記 30:12"> 按聖所的秤計算，從登記的人口所收到的銀子是六萬八千四百兩。</span>
<span className="v" id="v26" data-v="26" data-xref="民數記 1:46; 出埃及記 30:13; 出埃及記 12:37"> 這是所有登記的、年齡在二十歲以上的人所繳納的銀子，共有六十萬三千五百五十人，每人交六克銀子，以聖所的秤為準。</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及記 26:19; 出埃及記 26:25; 出埃及記 26:21"> 鑄造聖所帶凹槽的底座和帷幔柱子帶凹槽的底座，共用了六萬八千兩銀子，共鑄造了一百個底座，每個底座用了六百八十兩銀子。</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及記 27:17"> 剩下的四百兩銀子用來製造柱子上的鉤和箍以及包柱頂。</span>
<span className="v" id="v29" data-v="29"> 百姓奉獻的銅共有兩千四百公斤，</span>
<span className="v" id="v30" data-v="30" data-xref="出埃及記 26:37; 出埃及記 27:17; 出埃及記 27:10"> 用來製造會幕入口帶凹槽的底座、祭壇、壇上的銅網及一切器具、</span>
<span className="v" id="v31" data-v="31"> 院子周圍和院子入口帶凹槽的底座以及聖幕、院子周圍所有的橛子。</span>

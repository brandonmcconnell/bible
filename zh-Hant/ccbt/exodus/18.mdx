## 葉特羅看望摩西

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及記 2:16; 詩篇 77:14–15; 出埃及記 3:1"> 摩西的岳父米甸的祭司葉特羅，聽說上帝為摩西和祂的子民以色列人所做的一切事及如何帶他們出埃及後，</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 2:21; 出埃及記 4:25–26"> 就帶著女兒西坡拉和兩個外孫去見摩西。西坡拉是摩西的妻子，摩西曾讓她回娘家暫時居住。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 2:22; 使徒行傳 7:29; 詩篇 39:12"> 摩西的兩個兒子一個叫革舜，因為摩西說：「我成了在異鄉寄居的人」；</span>
<span className="v" id="v4" data-v="4" data-xref="希伯來書 13:6; 提摩太後書 4:17; 哥林多後書 1:8–10"> 一個叫以利以謝，因為摩西說：「我父親的上帝幫助我，從法老的刀下拯救了我。」</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 3:1; 出埃及記 3:12; 出埃及記 24:16–17"> 摩西的岳父葉特羅帶著摩西的妻子和兩個兒子來到上帝的山見摩西，就是摩西在曠野安營的地方。</span>
<span className="v" id="v6" data-v="6"> 葉特羅事先差人，把他帶著摩西的妻子和兩個兒子要來的消息通知摩西。</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 29:13; 創世記 14:17; 撒母耳記下 11:7"> 摩西出去迎接岳父，向他下拜，與他親吻，彼此問安，然後大家都進了帳篷。</span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 145:4–12; 尼希米記 9:9–15; 詩篇 107:2"> 摩西把耶和華為拯救以色列人而向法老和埃及人所行的事，以及怎樣救百姓脫離路上遇見的種種困難，都告訴了葉特羅。</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多前書 12:26; 羅馬書 12:15; 以賽亞書 66:10"> 葉特羅為耶和華恩待以色列人、把他們救出埃及而高興，</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 14:20; 撒母耳記下 18:28; 路加福音 1:68"> 便說：「耶和華當受稱頌，因為祂從埃及人和法老手中拯救了你們，把這百姓從埃及人手中拯救了出來。</span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 95:3; 出埃及記 15:11; 歷代志下 2:5"> 我現在知道，耶和華比一切神明都偉大，因為祂懲治了虐待這些百姓的狂妄之徒。」</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 31:54; 申命記 12:7; 出埃及記 24:11"> 摩西的岳父葉特羅說完，便向上帝獻燔祭及其他祭物。亞倫和以色列的長老都來與他一起在上帝面前吃飯。</span>
<span className="v" id="v13" data-v="13" data-xref="以賽亞書 16:5; 約伯記 29:7; 士師記 5:10"> 第二天，摩西坐著審理百姓的糾紛，百姓從早到晚都站在摩西周圍。</span>
<span className="v" id="v14" data-v="14"> 摩西的岳父葉特羅看見摩西對百姓所行的一切，就對摩西說：「你為什麼這樣處理百姓的事？為什麼你獨自坐著，眾百姓從早到晚都站在你周圍？」</span>
<span className="v" id="v15" data-v="15" data-xref="民數記 15:34; 民數記 27:5; 民數記 9:8"> 摩西對岳父說：「因為他們來我這裡求問上帝。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 24:14; 哥林多前書 6:1; 撒母耳記下 15:3"> 他們有糾紛就來我這裡，我為雙方定奪是非，教他們認識上帝的律例和法度。」</span>
<span className="v" id="v17" data-v="17"> 摩西的岳父葉特羅勸摩西說：「這不是好方法，</span>
<span className="v" id="v18" data-v="18" data-xref="民數記 11:14–17; 使徒行傳 6:1–4; 哥林多後書 12:15"> 你和這些百姓都會疲憊不堪，你一個人無法擔當如此繁重的工作。</span>
<span className="v" id="v19" data-v="19" data-xref="民數記 27:5; 申命記 5:5; 出埃及記 20:19"> 你要聽我的勸告，願上帝與你同在。你要做百姓的代表，把案件奏明上帝，</span>
<span className="v" id="v20" data-v="20" data-xref="申命記 5:1; 詩篇 143:8; 申命記 1:18"> 又要教導他們律例和法度，指示他們當行的道、當做的事。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行傳 6:3; 申命記 1:13–17; 歷代志下 19:5–10"> 此外，你要在民中挑選一些敬畏上帝、有才幹、誠實、正直、憎惡不義之財的人，派他們做千夫長、百夫長、五十夫長和十夫長，管理百姓。</span>
<span className="v" id="v22" data-v="22" data-xref="民數記 11:17; 民數記 27:2; 民數記 15:33"> 讓他們隨時為百姓判案，處理小糾紛，遇到大事才由你審理。有他們分擔你的責任，你會更輕省。</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳記上 8:6–7; 出埃及記 18:18; 撒母耳記上 8:22"> 如果你這樣做，並且上帝也這樣吩咐你，你就能承受得住，百姓也可以平安地回家。」</span>
<span className="v" id="v24" data-v="24" data-xref="以斯拉記 10:2; 出埃及記 18:19; 出埃及記 18:2–5"> 於是，摩西接納了岳父的建議，依言而行，</span>
<span className="v" id="v25" data-v="25" data-xref="申命記 1:15; 出埃及記 18:21; 使徒行傳 6:5"> 從百姓中挑選有才幹的人，委派他們做百姓的領袖，擔任千夫長、百夫長、五十夫長和十夫長。</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及記 18:22; 出埃及記 18:14–15; 申命記 17:8"> 他們負責隨時審理百姓的事，遇到難斷的案件就呈到摩西那裡，自己則審理普通的事。</span>
<span className="v" id="v27" data-v="27" data-xref="民數記 10:29–30; 士師記 19:9; 創世記 31:55"> 之後，摩西為岳父送行，葉特羅就返回了家鄉。</span>

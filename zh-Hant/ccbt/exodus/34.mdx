## 新的約版

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及記 32:19; 出埃及記 31:18; 詩篇 119:89"> 耶和華對摩西說：「你要鑿出兩塊石版，跟你之前摔碎的兩塊一樣，我要把前兩塊石版上的字刻在上面。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 19:20; 申命記 9:25; 出埃及記 19:11"> 明天清早你要預備好，你要上西奈山頂來見我。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 19:12–13; 出埃及記 19:21; 提摩太前書 2:5"> 誰也不可與你同來，整座山上都不可有人，就是牛羊也不得在山前吃草。」</span>
<span className="v" id="v4" data-v="4"> 於是，摩西鑿出兩塊石版，與前兩塊一樣。他清早起來，照著耶和華的吩咐拿著兩塊石版上了西奈山。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 33:19; 民數記 11:25; 路加福音 9:34–35"> 耶和華在雲中降臨和摩西一同站在那裡，宣告祂的名耶和華。</span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 86:15; 約珥書 2:13; 詩篇 103:8–13"> 耶和華在摩西面前經過，並且宣告說：「我是耶和華，我是耶和華，是有憐憫和恩典的上帝，不輕易發怒，充滿慈愛，無比信實，</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及記 20:5–6; 詩篇 103:3; 申命記 5:9–10"> 向千萬代彰顯慈愛，赦免罪愆、過犯和罪惡，但決不免除罪責，必向子孫追討父輩的罪債，直到三四代。」</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及記 4:31; 歷代志下 20:18; 創世記 17:3"> 摩西急忙俯伏在地上敬拜，</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 33:12; 申命記 32:9; 詩篇 94:14"> 說：「主啊，如果我在你面前蒙了恩，求你與我們同行。雖然百姓頑固不化，求你赦免我們的過犯和罪惡，接納我們做你的產業。」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="申命記 10:21; 詩篇 77:14; 以賽亞書 64:3"> 耶和華說：「我要與你立約，我要在你所有的百姓面前行奇事，是天下萬國從未有過的奇事，你周圍的外族人必看見我為你做的可畏之事。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及記 33:2; 出埃及記 3:17; 出埃及記 3:8"> 你要遵行我今天的吩咐。我必從你面前趕走亞摩利人、迦南人、赫人、比利洗人、希未人和耶布斯人。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及記 23:32–33; 約書亞記 23:12–13; 申命記 7:2"> 你要謹慎，到了目的地後，不可與當地的居民立約，免得因此而陷入網羅。</span>
<span className="v" id="v13" data-v="13" data-xref="列王紀下 18:4; 出埃及記 23:24; 申命記 7:25–26"> 相反，要拆掉他們的祭壇，打碎他們的神柱，砍下他們的亞舍拉神像。</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 4:24; 申命記 32:21; 哥林多前書 10:22"> 不可拜別的神明，因為耶和華是痛恨不貞的上帝，祂名為『痛恨不貞』。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="士師記 2:17; 詩篇 106:28; 民數記 25:2"> 「不可與當地的居民立約，免得他們與自己的神明苟合獻祭時邀請你，你就吃他們的祭物，</span>
<span className="v" id="v16" data-v="16" data-xref="申命記 7:3–4; 列王紀上 11:2–4; 以斯拉記 9:2"> 給兒子娶他們的女兒為妻，以致她們與自己的神明苟合時誘使你的兒子犯同樣的罪。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="利未記 19:4; 出埃及記 32:8; 以賽亞書 46:6–7"> 「不可為自己鑄造神像。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="出埃及記 13:4; 利未記 23:6; 出埃及記 13:6–7"> 「要守除酵節，照我的吩咐在亞筆月所定的時間吃七天的無酵餅，因為你是在亞筆月離開埃及的。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="出埃及記 13:2; 出埃及記 22:29; 出埃及記 13:12"> 「凡是頭胎生的都屬於我，包括牲畜中一切頭胎生的公牛和公羊。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及記 13:13; 出埃及記 23:15; 申命記 16:16"> 頭胎生的驢要用羊贖回，如果不用羊贖回，就要打斷牠的脖子。凡頭胎生的男嬰，都要贖回他的性命。誰也不可空手來朝見我。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="出埃及記 23:12; 申命記 21:4; 路加福音 13:14"> 「一週工作六天，第七天要休息，就是耕種和收割時也要休息。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="出埃及記 23:16; 申命記 16:10–15; 約翰福音 7:2"> 「在收割初熟麥子的時候，要守七七收獲節，年底要守收藏節。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及記 23:14; 申命記 16:16; 出埃及記 23:17"> 所有的男子都要每年三次朝見主耶和華——以色列的上帝。</span>
<span className="v" id="v24" data-v="24" data-xref="詩篇 78:55; 出埃及記 33:2; 箴言 16:7"> 我要從你面前趕走外族人，擴張你的領土。你一年三次朝見你的上帝耶和華時，必沒有人貪戀你的土地。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="出埃及記 23:18; 出埃及記 12:10; 哥林多前書 5:7–8"> 「不可把祭牲的血和有酵的餅一起獻給我，也不可把逾越節的祭物留到早晨。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="出埃及記 23:19; 申命記 14:21; 申命記 26:2"> 「要把田中最好的初熟之物送到你們的上帝耶和華的殿中。<br />「不可用母山羊的奶煮牠的小羊羔。」</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="出埃及記 24:4; 申命記 31:9; 申命記 4:13"> 耶和華又對摩西說：「你要把我說的這些話記錄下來，因為我要按這些話跟你和以色列人立約。」</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及記 34:1; 出埃及記 24:18; 申命記 9:18"> 摩西在耶和華那裡待了四十晝夜，不吃也不喝。耶和華把約的內容，就是十條誡命，寫在石版上。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="馬太福音 17:2; 路加福音 9:29; 出埃及記 32:15"> 摩西手裡拿著兩塊約版下西奈山，他不知道自己因為曾與耶和華說話而臉上發光。</span>
<span className="v" id="v30" data-v="30" data-xref="馬可福音 9:3; 路加福音 5:8; 民數記 12:8"> 亞倫和所有的以色列百姓看見摩西臉上發光，都不敢走近他。</span>
<span className="v" id="v31" data-v="31" data-xref="出埃及記 3:15; 出埃及記 24:1–3; 創世記 45:3"> 摩西召他們過來，亞倫和會眾的首領便上前來。摩西與他們說話。</span>
<span className="v" id="v32" data-v="32" data-xref="列王紀上 22:14; 出埃及記 24:3; 馬太福音 28:20"> 之後，所有的以色列人都來到他面前，他就把耶和華在西奈山上的吩咐都告訴他們。</span>
<span className="v" id="v33" data-v="33" data-xref="哥林多後書 4:4–6; 哥林多後書 3:13–18; 羅馬書 10:4"> 說完之後，他就用帕子遮住自己的臉。</span>
<span className="v" id="v34" data-v="34" data-xref="哥林多後書 3:16; 希伯來書 10:19–22; 希伯來書 4:16"> 他每次進到會幕跟耶和華說話時，就揭開帕子，出來後便把耶和華的吩咐告訴以色列百姓。</span>
<span className="v" id="v35" data-v="35" data-xref="出埃及記 34:29–30; 約翰福音 5:35; 但以理書 12:3"> 百姓看到他臉上發光，他就再用帕子遮住臉，直到下次進去與耶和華說話的時候才揭開。</span>
</div>

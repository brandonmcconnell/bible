## 祭司的衣服

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及記 31:10; 出埃及記 35:23; 出埃及記 35:19"> 比撒列等人按照耶和華對摩西的吩咐，用藍色、紫色、朱紅色毛線精工製作在聖所供職時穿的禮服，又為亞倫做聖衣。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 28:6–12; 利未記 8:7; 出埃及記 25:7"> 他們用金線、細麻及藍色、紫色、朱紅色毛線精工製作以弗得，</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 36:8; 出埃及記 26:1"> 把金子打成薄片，剪成細線，與細麻和藍色、紫色、朱紅色毛線巧妙地織在一起。</span>
<span className="v" id="v4" data-v="4"> 他們做了兩條肩帶，固定在以弗得兩邊，用來連接以弗得。</span>
<span className="v" id="v5" data-v="5" data-xref="啟示錄 1:13; 馬太福音 28:20; 以賽亞書 11:5"> 又按耶和華對摩西的吩咐，照以弗得的做法用金線、細麻及藍色、紫色、朱紅色毛線精工製作腰帶，縫在以弗得上。</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及記 28:9; 以西結書 28:13; 約伯記 28:16"> 他們選了兩塊紅瑪瑙，用刻圖章的方法刻上以色列十二個兒子的名字，鑲在兩個金框裡，</span>
<span className="v" id="v7" data-v="7" data-xref="約書亞記 4:7; 出埃及記 28:12; 出埃及記 28:29"> 再縫在以弗得的兩條肩帶上，作以色列人的紀念石。這些都是照耶和華對摩西的吩咐做的。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="出埃及記 28:4; 利未記 8:8–9; 以賽亞書 59:17"> 他們精工製作胸牌，像造以弗得一樣用金線、細麻及藍色、紫色、朱紅色毛線製作。</span>
<span className="v" id="v9" data-v="9"> 胸牌是方形的，疊成兩層，長寬各二十二釐米。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及記 28:21; 出埃及記 28:16–17; 啟示錄 21:19–21"> 上面鑲上四行寶石：第一行是紅寶石、黃玉和翠玉；</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及記 28:18; 以西結書 28:13"> 第二行是綠寶石、藍寶石和金剛石；</span>
<span className="v" id="v12" data-v="12"> 第三行是紫瑪瑙、白瑪瑙和紫晶；</span>
<span className="v" id="v13" data-v="13"> 第四行是水蒼玉、紅瑪瑙和碧玉。這些寶石都鑲在胸牌的金框上。</span>
<span className="v" id="v14" data-v="14" data-xref="啟示錄 21:12"> 他們用刻圖章的方法，在每一顆寶石上刻一個以色列兒子的名字，十二顆寶石代表以色列十二支派。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="約翰福音 10:28; 約翰福音 17:12; 彼得前書 1:5"> 他們用純金擰成兩條像繩子一樣的鏈子，連在胸牌上，</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 25:12"> 又造兩個金框和兩個金環，把金環安在胸牌兩端。</span>
<span className="v" id="v17" data-v="17"> 把兩條金鏈分別繫在胸牌兩端的金環上，</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及記 28:14; 雅歌 1:10"> 又把兩條金鏈的另兩端接在兩個金框上，安在以弗得前面的肩帶上。</span>
<span className="v" id="v19" data-v="19"> 又造了兩個金環，安在靠近以弗得內邊的胸牌下兩端。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及記 26:3"> 又造了兩個金環，安在以弗得前面兩條肩帶下端，靠近精緻的以弗得腰帶上方的接縫處。</span>
<span className="v" id="v21" data-v="21" data-xref="馬太福音 16:24; 哥林多前書 1:25; 哥林多前書 1:27"> 用一條藍色的帶子繫住以弗得和胸牌上面的金環，使胸牌貼在精工織成的以弗得腰帶上，不會從以弗得上鬆脫。這些都是照耶和華對摩西的吩咐做的。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="出埃及記 28:31–35"> 以弗得的外袍用純藍色的線織成，</span>
<span className="v" id="v23" data-v="23"> 上面有領口，領口周圍織領邊，就像鎧甲上的領口，免得領口破裂。</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及記 28:33; 加拉太書 5:22"> 外袍的底邊用細麻和藍色、紫色、朱紅色毛線做成石榴狀的飾物，</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及記 28:33–34; 雅歌 4:13; 詩篇 89:15"> 又造純金的鈴鐺掛在外袍底邊的石榴間，</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及記 28:34; 雅歌 4:13; 雅歌 6:7"> 一個石榴一個金鈴鐺，相間排列，圍在外袍的底邊。這件外袍是祭司供職時穿的，正如耶和華對摩西的吩咐。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="以西結書 44:18; 彼得前書 1:13; 以賽亞書 61:10"> 他們用細麻布為亞倫父子們縫製內袍、</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及記 28:4; 以西結書 44:18; 出埃及記 28:39"> 禮冠、頭巾和褲子，</span>
<span className="v" id="v29" data-v="29" data-xref="出埃及記 28:39"> 還用細麻和藍色、紫色、朱紅色毛線繡製腰帶。這是照耶和華對摩西的吩咐做的。</span>
<span className="v" id="v30" data-v="30" data-xref="啟示錄 5:10; 希伯來書 7:26; 希伯來書 1:3"> 又用純金造了牌子，就是聖冠，上面用刻印章的方法刻上「耶和華的聖物」的字樣，</span>
<span className="v" id="v31" data-v="31"> 然後用一條藍色帶子把它繫在禮冠上。這些都是照耶和華對摩西的吩咐做的。</span>
</div>
</div>

## 聖幕完工

<div className="bt">
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="出埃及記 39:42–43; 馬太福音 28:20; 出埃及記 25:40"> 聖幕，就是會幕的工作就這樣全部完成了，都是以色列人照耶和華對摩西的吩咐做的。</span>
<span className="v" id="v33" data-v="33" data-xref="出埃及記 35:11–19; 出埃及記 31:7–11; 出埃及記 36:1–38"> 他們把聖幕和聖幕的各樣器具都送到摩西那裡，即鉤子、木板、橫閂、柱子和帶凹槽的底座；</span>
<span className="v" id="v34" data-v="34"> 海狗皮頂蓋、遮掩約櫃的幔子、染成紅色的公羊皮蓋；</span>
<span className="v" id="v35" data-v="35" data-xref="希伯來書 9:5; 出埃及記 25:17; 希伯來書 9:8"> 約櫃、抬約櫃的橫槓、施恩座；</span>
<span className="v" id="v36" data-v="36" data-xref="出埃及記 25:30; 列王紀上 7:48"> 桌子、桌上的一切器具和供餅；</span>
<span className="v" id="v37" data-v="37" data-xref="腓立比書 2:15; 出埃及記 27:21; 馬太福音 5:14–16"> 純金的燈臺、燈盞、燈臺的一切器具、燈油；</span>
<span className="v" id="v38" data-v="38" data-xref="出埃及記 30:7; 出埃及記 37:29; 出埃及記 30:3"> 金壇、膏油、芬芳的香；會幕的門簾；</span>
<span className="v" id="v39" data-v="39" data-xref="列王紀上 8:64; 出埃及記 38:30"> 銅祭壇、祭壇的銅網、抬祭壇的橫槓、祭壇用的一切器具、洗濯盆和盆座；</span>
<span className="v" id="v40" data-v="40" data-xref="出埃及記 27:9–16"> 院子的帷幔、柱子、帶凹槽的底座、院子入口的門簾、繩子、橛子和會幕，即聖幕所需的一切器具；</span>
<span className="v" id="v41" data-v="41" data-xref="出埃及記 28:2; 出埃及記 31:10; 出埃及記 39:1"> 在聖所供職時穿的精製禮服、亞倫祭司的聖衣及其眾子供祭司之職時穿的衣服。</span>
<span className="v" id="v42" data-v="42" data-xref="出埃及記 35:10; 出埃及記 23:21–22; 提摩太後書 2:15"> 這一切都是以色列人照耶和華對摩西的吩咐做的。</span>
<span className="v" id="v43" data-v="43" data-xref="民數記 6:23–27; 利未記 9:22–23; 撒母耳記下 6:18"> 摩西察看這一切工作，見他們都是按照耶和華的吩咐做的，就給他們祝福。</span>
</div>
</div>

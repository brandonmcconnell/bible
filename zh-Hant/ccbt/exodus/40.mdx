## 支起會幕

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華對摩西說：</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 26:30; 出埃及記 13:4; 民數記 7:1"> 「你要在一月一日支起聖幕，即會幕，</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 35:12; 民數記 4:5; 啟示錄 11:19"> 把約櫃安置在裡面，用幔子遮掩。</span>
<span className="v" id="v4" data-v="4" data-xref="利未記 24:8; 出埃及記 40:22–25; 出埃及記 37:10–24"> 把桌子搬進去，擺好桌上的器具，再把燈臺搬進去，點上燈，</span>
<span className="v" id="v5" data-v="5" data-xref="希伯來書 10:19–22; 希伯來書 9:24; 約翰一書 2:1–2"> 把燒香的金香壇放在約櫃前面，掛上聖幕入口的簾子。</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及記 40:29; 約翰一書 4:9–10; 希伯來書 13:10"> 要把燔祭壇放在聖幕門口前面，</span>
<span className="v" id="v7" data-v="7" data-xref="撒迦利亞書 13:1; 約翰一書 1:7; 詩篇 26:6"> 洗濯盆放在會幕和祭壇中間，盆裡要有水。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及記 40:33; 以弗所書 4:11–12; 馬太福音 16:18"> 用帷幔在聖幕四周圍成院子，在院子的入口掛上簾子。</span>
<span className="v" id="v9" data-v="9" data-xref="利未記 8:10; 民數記 7:1; 馬太福音 3:16"> 你要用膏油抹聖幕和裡面所有的器具，使它們分別出來，成為聖潔之物。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及記 29:36–37; 路加福音 1:35; 以賽亞書 61:1"> 要抹燔祭壇和壇上所有器具，使燔祭壇分別出來，成為至聖之物。</span>
<span className="v" id="v11" data-v="11"> 要抹洗濯盆和盆座，使它們分別出來，成為聖潔之物。</span>
<span className="v" id="v12" data-v="12" data-xref="利未記 8:1–13; 利未記 9:1–24; 出埃及記 29:1–35"> 要把亞倫父子們叫到會幕入口，用水為他們沐浴，</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及記 28:41; 約翰一書 2:20; 約翰一書 2:27"> 給亞倫穿上聖衣並膏立他，使他分別出來，做聖潔的祭司事奉我。</span>
<span className="v" id="v14" data-v="14" data-xref="以賽亞書 61:10; 羅馬書 8:30; 哥林多前書 1:30"> 也要把他的兒子們叫來，給他們穿上內袍，</span>
<span className="v" id="v15" data-v="15" data-xref="民數記 25:13; 希伯來書 5:1–14; 希伯來書 8:1–10"> 用同樣的儀式膏立他們，使他們做祭司事奉我。他們的受膏將使他們永遠做祭司，世代相傳。」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="申命記 4:1; 出埃及記 40:17–32; 申命記 12:32"> 摩西照耶和華的吩咐把事情都辦好了。</span>
<span className="v" id="v17" data-v="17" data-xref="民數記 7:1; 出埃及記 40:1–2; 民數記 9:1"> 第二年一月一日，聖幕支起來了。</span>
<span className="v" id="v18" data-v="18" data-xref="以西結書 37:27–28; 彼得前書 1:5; 利未記 26:11"> 摩西支起聖幕，裝上帶凹槽的底座，豎起木板，插上橫閂，立起柱子，</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及記 26:1–14; 出埃及記 36:8–19"> 在聖幕上面搭起罩棚，鋪上頂蓋，都遵照耶和華的吩咐。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及記 16:34; 申命記 10:5; 希伯來書 10:19–21"> 摩西把約版放在約櫃裡，橫槓穿在約櫃的兩旁，施恩座放在約櫃上，</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及記 26:33; 出埃及記 40:3; 出埃及記 35:12"> 把約櫃抬進聖幕，掛起幔子遮掩約櫃，都遵照耶和華對他的吩咐。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及記 26:35; 約翰福音 6:53–57; 以弗所書 3:8"> 他把桌子放在會幕內、遮掩約櫃的幔子外面、聖幕的北側，</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及記 25:30; 出埃及記 40:4; 希伯來書 9:2"> 將獻給耶和華的供餅放在桌上，都遵照耶和華的吩咐。</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及記 26:35; 啟示錄 2:5; 約翰福音 1:1"> 他把燈臺放在會幕內的桌子對面，在聖幕的南側，</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及記 40:4; 出埃及記 25:37; 啟示錄 4:5"> 然後在耶和華面前點燈，都遵照耶和華的吩咐。</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及記 40:5; 希伯來書 7:25; 約翰福音 11:42"> 他把金壇放在會幕裡、遮掩約櫃的幔子前面，</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及記 30:7"> 在壇上點燃芬芳的香，都遵照耶和華的吩咐。</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及記 40:5; 希伯來書 10:19–20; 以弗所書 2:18"> 他掛上聖幕入口的簾子，</span>
<span className="v" id="v29" data-v="29" data-xref="出埃及記 40:6; 希伯來書 13:5–6; 希伯來書 13:10"> 在會幕，即聖幕入口前面設立燔祭壇，在壇上獻燔祭和素祭，都遵照耶和華的吩咐。</span>
<span className="v" id="v30" data-v="30" data-xref="出埃及記 40:7; 出埃及記 38:8; 以西結書 36:25"> 他把洗濯盆放在會幕和祭壇之間，盆裡盛水，供洗濯用。</span>
<span className="v" id="v31" data-v="31" data-xref="出埃及記 30:19–20; 詩篇 26:6; 約翰福音 13:10"> 摩西、亞倫及其眾子都在盆裡清洗手腳，</span>
<span className="v" id="v32" data-v="32" data-xref="詩篇 73:19; 出埃及記 30:19–20; 出埃及記 40:19"> 他們進會幕或走近祭壇的時候，都要先清洗，都遵照耶和華的吩咐。</span>
<span className="v" id="v33" data-v="33" data-xref="出埃及記 40:8; 出埃及記 27:9–16; 約翰福音 17:4"> 摩西又在聖幕和祭壇的四周用帷幔圍成院子，然後在院子入口掛上簾子。這樣，摩西完成了工作。</span>
</div>
</div>

## 耶和華的榮光

<div className="bt">
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="啟示錄 15:8; 民數記 9:15–23; 歷代志下 7:2"> 那時，有雲彩遮蓋會幕，耶和華的榮光充滿了聖幕。</span>
<span className="v" id="v35" data-v="35" data-xref="列王紀上 8:11; 利未記 16:2; 歷代志下 7:2"> 摩西不能進會幕，因為雲彩停在上面，耶和華的榮光充滿了聖幕。</span>
<span className="v" id="v36" data-v="36" data-xref="尼希米記 9:19; 民數記 9:17; 出埃及記 13:21–22"> 一路上，雲彩從聖幕上升起，他們就出發。</span>
<span className="v" id="v37" data-v="37" data-xref="民數記 9:19–22; 詩篇 31:15"> 雲彩不升起，他們就不出發，一直等到雲彩升起。</span>
<span className="v" id="v38" data-v="38" data-xref="詩篇 78:14; 民數記 9:15; 出埃及記 13:21"> 一路上，白天有耶和華的雲彩停留在聖幕上面，夜間雲中有火光照在以色列百姓眼前。</span>
</div>

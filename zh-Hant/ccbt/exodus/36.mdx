<span className="v" id="v1" data-v="1" data-xref="出埃及記 28:3; 出埃及記 35:30–35; 出埃及記 31:1–6"> 摩西說：「比撒列、亞何利亞伯以及所有蒙耶和華賜智慧聰明、有技能、懂得如何建造聖所的人，都要按照耶和華的吩咐去做。」</span>
<span className="v" id="v2" data-v="2" data-xref="歌羅西書 4:17; 希伯來書 5:4; 出埃及記 31:6"> 於是，摩西召來比撒列、亞何利亞伯和所有蒙耶和華賜智慧、有技能、願意參與建造的人。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 35:29; 出埃及記 35:27; 出埃及記 35:5–21"> 他們從摩西那裡領取了以色列百姓奉獻出來建造聖所的一切禮物。每天早上，百姓仍然甘心樂意地來奉獻禮物，</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多前書 3:10; 路加福音 12:42; 馬太福音 24:45"> 以致所有建造聖所的能工巧匠都放下自己的工作，</span>
<span className="v" id="v5" data-v="5" data-xref="歷代志下 31:6–10; 哥林多後書 8:2–3; 歷代志下 24:14"> 前來對摩西說：「百姓的奉獻太多了，我們建造耶和華吩咐的聖所用不了。」</span>
<span className="v" id="v6" data-v="6"> 於是，摩西傳令全營：「男女都不用再為聖所奉獻禮物了。」百姓這才停止奉獻。</span>
<span className="v" id="v7" data-v="7" data-xref="歷代志下 31:10"> 因為所獻的材料已經足夠建造聖所，而且綽綽有餘。</span>
<span className="v" id="v8" data-v="8" data-xref="列王紀上 6:23; 出埃及記 26:1–37; 以西結書 1:5–28"> 工人中的能工巧匠用十幅幔子做成了聖幕，幔子用細麻和藍色、紫色、朱紅色毛線織成，上面精工繡製了基路伯天使。</span>
<span className="v" id="v9" data-v="9"> 每幅幔子的尺寸都一樣，長十二米半、寬一米八。</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多前書 12:27; 出埃及記 26:3; 詩篇 122:3"> 又把每五幅幔子連在一起，共連成兩幅大幔子。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及記 26:4"> 然後在每幅大幔子末幅的邊緣釘上了藍色的扣環，</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及記 26:5; 出埃及記 26:10"> 每幅大幔子各釘上五十個扣環，都是兩兩相對。</span>
<span className="v" id="v13" data-v="13" data-xref="彼得前書 2:4–5; 以弗所書 2:20–22; 哥林多前書 12:20"> 又做了五十個金鉤，把兩幅大幔子連在一起，成為一個完整的聖幕。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及記 26:7–13"> 比撒列用山羊毛織成十一幅幔子，作聖幕的罩棚，</span>
<span className="v" id="v15" data-v="15"> 每幅長十三米半、寬一米八。十一幅幔子的尺寸都一樣。</span>
<span className="v" id="v16" data-v="16"> 然後把五幅連成一大幅，其餘六幅連成一大幅。</span>
<span className="v" id="v17" data-v="17"> 又在這兩幅大幔子邊緣各釘上五十個對稱的扣環，</span>
<span className="v" id="v18" data-v="18"> 再用五十個銅鉤，把兩幅大幔子連在一起，成為一個完整的罩棚，</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及記 26:14"> 並在罩棚上面蓋一層染成紅色的公羊皮，再蓋一層海狗皮做頂蓋。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及記 25:5; 民數記 25:1; 出埃及記 40:18–19"> 他用皂莢木做支聖幕的木板，</span>
<span className="v" id="v21" data-v="21"> 每塊木板長四米半，寬七十釐米，</span>
<span className="v" id="v22" data-v="22"> 上面都有兩個接榫，用來銜接。聖幕的所有木板都這樣做。</span>
<span className="v" id="v23" data-v="23"> 聖幕的南面立二十塊木板，</span>
<span className="v" id="v24" data-v="24"> 在這些木板下面又造了四十個帶凹槽的銀底座，每塊木板下面有兩個，套在木板的兩個接榫上。</span>
<span className="v" id="v25" data-v="25"> 聖幕北面也立二十塊木板，</span>
<span className="v" id="v26" data-v="26"> 木板下面同樣有四十個帶凹槽的銀底座，每塊木板下面有兩個銀底座。</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及記 26:22; 出埃及記 26:27"> 聖幕後面，就是西面，立六塊木板，</span>
<span className="v" id="v28" data-v="28"> 聖幕後面的兩個拐角各有一塊木板，</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行傳 4:32; 以弗所書 3:18–19; 哥林多前書 1:10"> 木板的下端連於底座，頂端用一個環固定。兩個拐角都這樣做。</span>
<span className="v" id="v30" data-v="30" data-xref="出埃及記 26:25"> 這樣，後面共有八塊木板，每塊木板下面各有兩個帶凹槽的銀底座，一共有十六個銀底座。</span>
<span className="v" id="v31" data-v="31" data-xref="出埃及記 26:26–29; 出埃及記 25:28; 出埃及記 30:5"> 他用皂莢木做橫閂，聖幕左右兩邊和後面的牆板上各有五根橫閂，</span>
<span className="v" id="v33" data-v="33"> 攔腰固定牆板的那根橫閂從這端貫穿到那端。</span>
<span className="v" id="v34" data-v="34"> 所有的木板和橫閂都包上金，並在木板上造金環，用來穿橫閂。</span>
<span className="v" id="v35" data-v="35" data-xref="馬太福音 27:51; 希伯來書 10:20; 出埃及記 40:21"> 他用細麻和藍色、紫色、朱紅色毛線織成一幅幔子，上面精工繡上基路伯天使，</span>
<span className="v" id="v36" data-v="36" data-xref="耶利米書 1:18"> 把這幅幔子掛在四根包金的皂莢木柱上，木柱上有金鉤，四根柱子下面有四個銀底座。</span>
<span className="v" id="v37" data-v="37" data-xref="出埃及記 26:36–37; 出埃及記 40:28"> 他又用細麻和藍色、紫色、朱紅色毛線繡製聖幕的門簾，</span>
<span className="v" id="v38" data-v="38" data-xref="出埃及記 27:10"> 用皂莢木做五根掛門簾的柱子，上面有金鉤，柱頂和箍包上金。柱子的五個帶凹槽的底座是銅造的。</span>

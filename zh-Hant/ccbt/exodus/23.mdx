## 公義與憐憫

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="詩篇 101:5; 箴言 19:5; 申命記 19:16–21"> 「不可散佈謠言，也不可與惡人聯手作偽證。</span>
<span className="v" id="v2" data-v="2" data-xref="箴言 1:10–11; 箴言 1:15; 路加福音 23:23–24"> 不可隨眾行惡。在法庭作證時不可附和多數人，顛倒是非。</span>
<span className="v" id="v3" data-v="3" data-xref="雅各書 3:17; 利未記 19:15; 詩篇 82:2–3"> 在訴訟的事上不可偏袒窮人。</span>
<span className="v" id="v4" data-v="4" data-xref="申命記 22:1–4; 帖撒羅尼迦前書 5:15; 馬太福音 5:44"> 「倘若看見仇人的牛或驢走迷了路，總要牽回去交給他。</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 22:4"> 倘若遇見仇人的驢被馱的重物壓倒，不可逕自走開，總要幫助仇人抬開重物。</span>
<span className="v" id="v6" data-v="6" data-xref="瑪拉基書 3:5; 耶利米書 5:28; 利未記 19:15"> 「不可在訴訟案中冤枉窮人。</span>
<span className="v" id="v7" data-v="7" data-xref="以弗所書 4:25; 出埃及記 34:7; 出埃及記 23:1"> 不可誣告別人，不可殺害正直無辜的人，因為我必懲罰作惡之人。</span>
<span className="v" id="v8" data-v="8" data-xref="申命記 16:19; 箴言 17:23; 以賽亞書 5:23"> 不可收受賄賂，因為賄賂蒙蔽人的眼目，使人顛倒是非。</span>
<span className="v" id="v9" data-v="9" data-xref="申命記 27:19; 出埃及記 22:21; 申命記 24:14–18"> 不可欺凌在你們中間寄居的人，因為你們也曾經在埃及寄居，知道寄居他鄉的滋味。</span>
</div>
</div>

## 安息年和安息日

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="利未記 25:3–4"> 「六年之內你要耕種收割，</span>
<span className="v" id="v11" data-v="11" data-xref="利未記 26:34–35; 利未記 25:2–7; 利未記 25:11–12"> 第七年要讓土地休息，不耕不種，你們當中的窮人可以吃田中長出來的，剩下的可以留給動物吃。你也要這樣處理葡萄園和橄欖園。</span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 13:14; 出埃及記 34:21; 出埃及記 35:3"> 六天之內，你要工作，但第七天要休息。這樣，牛、驢可以歇息，你家裡的奴僕和寄居的也可以休息。</span>
<span className="v" id="v13" data-v="13" data-xref="約書亞記 23:7; 撒迦利亞書 13:2; 提摩太前書 4:16"> 你們要謹慎遵從我對你們說的話。不可提其他神明的名字，不可從你口中聽到它們的名字。</span>
</div>
</div>

## 三大節期

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="申命記 16:16; 出埃及記 34:22–24; 利未記 23:34"> 「你每年要向我守三個節期。</span>
<span className="v" id="v15" data-v="15" data-xref="路加福音 22:7; 出埃及記 34:20; 民數記 28:16–25"> 要守除酵節，照我的吩咐在每年亞筆月所定的日期連續吃七天的無酵餅，因為你是在這個月離開了埃及。誰也不可空手朝見我。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 34:22; 出埃及記 22:29; 利未記 23:9–21"> 要在耕種後收取初熟之物的時候守收獲節。要在年終從田間收取勞動成果時守收藏節。</span>
<span className="v" id="v17" data-v="17" data-xref="申命記 16:16; 出埃及記 34:23; 出埃及記 23:14"> 所有的男子都要在這三個節期朝見主耶和華。</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及記 34:25; 利未記 2:11; 申命記 16:4"> 「不可把祭牲的血和有酵的餅一起獻給我，也不可把節期祭牲的脂肪留到早晨。</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及記 34:26; 申命記 14:21; 申命記 26:10"> 要把田中最好的初熟之物送到你們的上帝耶和華的殿中。不可用母山羊的奶煮牠的小羊羔。</span>
</div>
</div>

## 應許賜迦南

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="出埃及記 33:14; 詩篇 91:11; 出埃及記 32:34"> 「看啊，我要差遣天使走在你前面，在路上保護你，帶領你到達我所預備的地方。</span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 78:56; 詩篇 78:40; 希伯來書 12:25"> 他是奉我的名來的，你們要謹遵他的話，不可悖逆，不然他必不赦免你們的過犯。</span>
<span className="v" id="v22" data-v="22" data-xref="創世記 12:3; 申命記 30:7; 撒迦利亞書 2:8"> 「你若認真聽從他的吩咐，遵行我的話，我就與你的仇敵為敵，與你的對頭作對。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及記 23:20; 以賽亞書 5:13; 創世記 15:19–21"> 我的天使要走在你前面，帶領你去亞摩利人、赫人、比利洗人、迦南人、希未人和耶布斯人所住的地方，我會把他們全部消滅。</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及記 20:5; 申命記 12:30–31; 民數記 33:52"> 不可叩拜他們的神明，不可供奉它們，也不可效法他們的行為，要徹底拆毀神像，打碎他們的神柱。</span>
<span className="v" id="v25" data-v="25" data-xref="申命記 7:15; 出埃及記 15:26; 約書亞記 22:5"> 你們要事奉你們的上帝耶和華，我必賜給你食物和水，使疾病遠離你們，</span>
<span className="v" id="v26" data-v="26" data-xref="申命記 7:14; 約伯記 5:26; 申命記 28:4"> 在你境內必沒有人流產或不育，我會使你享盡天年。</span>
<span className="v" id="v27" data-v="27" data-xref="申命記 2:25; 創世記 35:5; 申命記 11:25"> 你所到之處，我必使那裡的人惶恐不安，使你一切的仇敵都在你面前轉身逃跑。</span>
<span className="v" id="v28" data-v="28" data-xref="申命記 7:20; 約書亞記 24:11–12"> 我要派黃蜂做你的先鋒，趕走那些希未人、迦南人和赫人。</span>
<span className="v" id="v29" data-v="29" data-xref="申命記 7:22; 約書亞記 17:12–13; 士師記 3:1–4"> 我不會在一年之內把這些人全部趕走，免得土地荒涼，野獸氾濫。</span>
<span className="v" id="v30" data-v="30"> 我會逐漸地趕走他們，直到你們人丁興旺，可以佔據那片土地。</span>
<span className="v" id="v31" data-v="31" data-xref="創世記 15:18; 申命記 11:24; 約書亞記 21:44"> 我給你定下國界，從紅海到非利士海岸，從曠野到幼發拉底河。我要把其中所有的居民都交在你手中，你要把他們全部趕出去。</span>
<span className="v" id="v32" data-v="32" data-xref="申命記 7:2; 出埃及記 34:12; 出埃及記 34:15"> 不可跟這些民族及其神明立約，</span>
<span className="v" id="v33" data-v="33" data-xref="詩篇 106:36; 申命記 7:16; 出埃及記 34:12"> 也不可讓這些民族住在你的土地上，免得他們使你得罪我，你若供奉他們的神明，必因此而陷入網羅。」</span>
</div>
</div>

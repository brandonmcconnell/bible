## 祭司聖衣的規定

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民數記 18:7; 希伯來書 5:1–5; 民數記 17:2–9"> 「你要從以色列民中把你的哥哥亞倫和他四個兒子拿答、亞比戶、以利亞撒和以他瑪帶到你身邊，立他們為祭司事奉我。</span>
<span className="v" id="v2" data-v="2" data-xref="利未記 8:30; 出埃及記 31:10; 啟示錄 19:8"> 你要為你哥哥亞倫做聖衣，顯明他職位的榮耀和尊貴。</span>
<span className="v" id="v3" data-v="3" data-xref="以弗所書 1:17; 哥林多前書 12:7–11; 以賽亞書 11:2"> 你要吩咐所有我賦予智慧的巧手裁縫師為亞倫縫製衣服，使他分別出來，做聖潔的祭司事奉我。</span>
<span className="v" id="v4" data-v="4" data-xref="以弗所書 6:14; 啟示錄 9:17; 以賽亞書 59:17"> 他們要做的聖衣包括胸牌、以弗得、外袍、雜色的內袍、禮冠和腰帶。要為你哥哥亞倫及其眾子做這樣的聖衣，好讓他們做祭司事奉我。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 25:3–4; 出埃及記 39:2–3"> 要用金線、細麻及藍色、紫色、朱紅色毛線製作聖衣。</span>
</div>
</div>

## 以弗得

<div className="bt">
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="出埃及記 39:2–7; 出埃及記 26:1"> 「以弗得要用金線、細麻及藍色、紫色、朱紅色毛線精工製作。</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及記 39:4"> 要在以弗得兩邊用兩條肩帶縫合起來。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及記 28:27–28; 利未記 8:7; 出埃及記 29:5"> 用金線、細麻及藍色、紫色、朱紅色毛線精工製作腰帶，縫在以弗得上，連成一整件。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="以西結書 28:13; 歷代志下 2:7; 以賽亞書 49:16"> 「你要拿兩塊紅瑪瑙，刻上以色列十二個兒子的名字，</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及記 1:1–4; 創世記 43:33"> 按他們的長幼次序，每一塊寶石刻上六個名字。</span>
<span className="v" id="v11" data-v="11" data-xref="提摩太後書 2:19; 啟示錄 7:2; 耶利米書 22:24"> 要用工匠刻圖章的方法將他們的名字刻在兩塊寶石上，把寶石鑲在兩個金框裡。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及記 28:29; 約書亞記 4:7; 出埃及記 39:6–7"> 然後將鑲著金框的寶石縫在以弗得的兩條肩帶上，作以色列人的紀念石。亞倫要把他們的名字帶在肩上，在耶和華面前作紀念。</span>
<span className="v" id="v13" data-v="13"> 要做兩個金框，</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及記 39:15; 出埃及記 39:17–18; 列王紀上 7:17"> 並像搓繩子一樣用純金搓成兩條金鏈，把鏈子連接在鑲寶石的金框上。</span>
</div>
</div>

## 胸牌

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="出埃及記 28:30; 出埃及記 26:1; 出埃及記 28:4"> 「要精工製作一個用來明白上帝旨意的胸牌，製作的方法和造以弗得一樣，用金線、細麻及藍色、紫色、朱紅色毛線製作。</span>
<span className="v" id="v16" data-v="16"> 胸牌是方形的，長寬各二十二釐米，分成上下兩層。</span>
<span className="v" id="v17" data-v="17" data-xref="以西結書 28:13; 出埃及記 39:10–21; 箴言 8:11"> 上面要鑲上四行寶石：第一行是紅寶石、黃玉和翠玉；</span>
<span className="v" id="v18" data-v="18" data-xref="以西結書 27:16; 約伯記 28:6; 雅歌 5:14"> 第二行是綠寶石、藍寶石和金剛石；</span>
<span className="v" id="v19" data-v="19" data-xref="以賽亞書 54:12; 出埃及記 39:12"> 第三行是紫瑪瑙、白瑪瑙和紫晶；</span>
<span className="v" id="v20" data-v="20" data-xref="以西結書 1:16; 啟示錄 4:3; 但以理書 10:6"> 第四行是水蒼玉、紅瑪瑙和碧玉。這些寶石都要鑲在金框上。</span>
<span className="v" id="v21" data-v="21" data-xref="啟示錄 21:12; 啟示錄 7:4–8; 列王紀上 18:31"> 要用刻圖章的方法在每一顆寶石上刻一個以色列兒子的名字，十二顆寶石代表十二支派。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22"> 「要用純金擰成兩條像繩子一樣的鏈子，連在胸牌上，</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及記 25:11–15"> 造兩個金環安在胸牌兩端，</span>
<span className="v" id="v24" data-v="24"> 把兩條金鏈分別繫在胸牌兩端的金環上，</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及記 39:15; 出埃及記 39:4; 出埃及記 28:14"> 再把金鏈的另兩端接在兩個金框上，安在以弗得前面的肩帶上。</span>
<span className="v" id="v26" data-v="26"> 造兩個金環，安在靠近以弗得內邊的胸牌下兩端。</span>
<span className="v" id="v27" data-v="27"> 再造兩個金環，安在以弗得前面兩條肩帶下端，靠近精緻的以弗得腰帶上方的接縫處。</span>
<span className="v" id="v28" data-v="28" data-xref="民數記 15:38; 出埃及記 28:31; 出埃及記 39:30–31"> 再用一條藍色的帶子繫住以弗得和胸牌上面的金環，使胸牌貼在精工織成的以弗得腰帶上，不會從以弗得上鬆脫。</span>
<span className="v" id="v29" data-v="29" data-xref="出埃及記 28:12; 出埃及記 28:30; 耶利米書 30:21"> 亞倫進聖所時，要佩戴這塊刻著以色列眾子名字、用來做判斷的胸牌，在耶和華面前常作紀念。</span>
<span className="v" id="v30" data-v="30" data-xref="尼希米記 7:65; 以斯拉記 2:63; 民數記 27:21"> 又要把烏陵和土明放在胸牌裡面，亞倫到耶和華面前的時候，要佩帶這胸牌，以便明白上帝的旨意，為以色列人做決定。</span>
</div>
</div>

## 外袍

<div className="bt">
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="利未記 8:7; 出埃及記 28:4; 出埃及記 39:22–26"> 「也要縫製一件藍色的以弗得的外袍，</span>
<span className="v" id="v32" data-v="32" data-xref="尼希米記 4:16; 約翰福音 19:23–24; 出埃及記 39:28"> 袍上要留領口，領口周圍要織領邊，就像鎧甲的領口，免得領口破裂。</span>
<span className="v" id="v33" data-v="33" data-xref="出埃及記 39:24–26; 撒迦利亞書 14:20; 列王紀上 7:18"> 外袍的底邊要另外用藍色、紫色、朱紅色毛線做成石榴狀的飾物，石榴間要掛金鈴鐺。</span>
<span className="v" id="v34" data-v="34" data-xref="雅歌 8:2; 約翰福音 15:4–8; 歌羅西書 1:10"> 一個石榴一個金鈴鐺，相間排列，圍在外袍的底邊。</span>
<span className="v" id="v35" data-v="35" data-xref="希伯來書 9:12; 利未記 16:2"> 亞倫事奉的時候，要穿上這外袍，以便他進聖所到耶和華面前和出聖所的時候，鈴鐺會發出響聲，他就不至於死。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="撒迦利亞書 14:20; 利未記 8:9; 出埃及記 39:30"> 「你也要用純金造一塊牌子，以刻印章的方法刻上『耶和華的聖物』的字樣，</span>
<span className="v" id="v37" data-v="37" data-xref="出埃及記 29:6; 出埃及記 28:4; 撒迦利亞書 3:5"> 再拿一條藍色帶子，把它繫在禮冠前面。</span>
<span className="v" id="v38" data-v="38" data-xref="彼得前書 2:24; 民數記 18:1; 利未記 10:17"> 亞倫要把這金牌戴在額上，表示他承擔以色列人獻聖物時的過犯，這聖物是以色列百姓特別獻上的禮物。這金牌要常常留在亞倫的額上，好使百姓蒙耶和華悅納。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="詩篇 45:14"> 「要用細麻布縫製祭司的內袍，用細麻布做禮冠，腰帶上要有刺繡，</span>
<span className="v" id="v40" data-v="40" data-xref="出埃及記 39:41; 出埃及記 28:4; 出埃及記 28:2"> 也要為亞倫的兒子們縫製內袍、腰帶、頭巾，顯明他們職位的榮耀和尊貴。</span>
<span className="v" id="v41" data-v="41" data-xref="出埃及記 29:7; 利未記 8:1–36; 出埃及記 40:15"> 給你哥哥亞倫及其眾子穿上這些衣服後，你要用油膏立他們，使他們分別出來，做聖潔的祭司事奉我。</span>
</div>
</div>

## 褲子

<div className="bt">
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="以西結書 44:18; 利未記 6:10; 利未記 16:4"> 「要用細麻布為他們做褲子，以遮蓋下體，褲子要從腰部到大腿。</span>
<span className="v" id="v43" data-v="43" data-xref="出埃及記 27:21; 出埃及記 20:26; 利未記 5:17"> 亞倫父子們進會幕或走近祭壇到聖所事奉的時候，都要穿上褲子，免得擔負罪責而死亡。這是亞倫及其子孫永遠當守的律例。</span>
</div>
</div>

</div>

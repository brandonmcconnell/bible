## 逾越節

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華在埃及對摩西和亞倫說：</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 13:4; 申命記 16:1; 出埃及記 34:18"> 「你們要以這個月為一月，為一年之首。</span>
<span className="v" id="v3" data-v="3" data-xref="利未記 1:2; 哥林多前書 5:7; 約翰福音 1:29"> 你要向以色列全體會眾宣佈，本月的第十日，每家都要預備一隻羊羔，一家一隻。</span>
<span className="v" id="v4" data-v="4"> 倘若家人太少，吃不了一隻，可以跟最近的鄰居共享一隻，你們要按人數和各人的食量預備羊羔。</span>
<span className="v" id="v5" data-v="5" data-xref="彼得前書 1:18–19; 希伯來書 9:13–14; 瑪拉基書 1:14"> 羊羔必須是毫無殘疾、一歲的公綿羊或公山羊。</span>
<span className="v" id="v6" data-v="6" data-xref="利未記 23:5; 歷代志下 30:15–18; 民數記 28:16"> 以色列全體會眾要把羊留到本月十四日，在黃昏時分宰殺，</span>
<span className="v" id="v7" data-v="7" data-xref="希伯來書 11:28; 出埃及記 12:22–23; 希伯來書 9:22"> 然後取點血塗在房子的門框和門楣上，他們要在房子裡吃羊肉。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及記 34:25; 申命記 16:7; 出埃及記 13:3"> 當晚，你們要用火把羊肉烤熟，與無酵餅和苦菜一起吃。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及記 12:8; 申命記 16:7; 耶利米哀歌 1:13"> 不可吃生羊肉，也不可煮著吃，要把整隻羊，連頭帶腿和內臟一併烤著吃。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及記 23:18; 出埃及記 34:25; 出埃及記 29:34"> 不可把肉留到早晨，留到早晨的肉要燒掉。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及記 12:27; 以弗所書 6:15; 哥林多前書 5:7"> 你們吃的時候，要束腰、穿鞋、手中拿杖，要趕快吃，這是耶和華的逾越節。</span>
<span className="v" id="v12" data-v="12" data-xref="民數記 33:4; 出埃及記 12:23; 詩篇 82:6"> 「因為那一夜我要巡遍埃及，把境內所有長子和頭生的牲畜全都殺掉，也要嚴懲埃及所有的神明。我是耶和華。</span>
<span className="v" id="v13" data-v="13" data-xref="希伯來書 11:28; 出埃及記 12:23; 約翰一書 1:7"> 塗在你們房屋上的血是一個記號，我見到這血就會越過你們。我擊打埃及的時候，那災禍不會落到你們身上。</span>
<span className="v" id="v14" data-v="14" data-xref="列王紀下 23:21; 出埃及記 12:24; 出埃及記 13:9–10"> 你們要記住這一天，守為耶和華的節期，作為世代不變的律例。</span>
</div>
</div>

## 除酵節

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="創世記 17:14; 申命記 16:3; 出埃及記 23:15"> 「七天之內你們都要吃無酵餅。第一天，要清除家中所有的酵。任何人若在這七天當中吃有酵的食物，要將他從以色列人中剷除。</span>
<span className="v" id="v16" data-v="16" data-xref="利未記 23:7–8; 民數記 28:18; 出埃及記 16:23"> 在節期的第一天和第七天，你們都要舉行聖會。這兩天所有人都不得工作，除了預備各人要吃的以外，不可做任何工。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及記 7:5; 出埃及記 13:3; 出埃及記 12:41"> 你們要守這除酵節，因為我在這天把你們的大軍從埃及領了出來。你們要守這節期，作為世代不變的律例。</span>
<span className="v" id="v18" data-v="18" data-xref="利未記 23:5–8; 出埃及記 12:15; 出埃及記 12:1–2"> 從一月十四日傍晚開始，直到二十一日傍晚，你們都要吃無酵餅。</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及記 12:15; 出埃及記 23:15; 申命記 16:3"> 在這七天內，你們屋裡不能有酵。任何人若吃了有酵的東西，不論他是寄居者還是本地人，都要將他從以色列會眾中剷除。</span>
<span className="v" id="v20" data-v="20"> 無論你們住在哪裡都要吃無酵餅，不能吃任何有酵的食物。」</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及記 12:3; 路加福音 22:7–13; 歷代志下 35:5–6"> 於是，摩西召集以色列的眾長老，對他們說：「你們家家戶戶都要挑選羔羊，把這逾越節的羔羊宰了。</span>
<span className="v" id="v22" data-v="22" data-xref="希伯來書 11:28; 民數記 19:18; 詩篇 51:7"> 拿一把牛膝草蘸盆裡的血，把血塗在門楣和兩邊的門框上。天亮前，你們不可踏出門外。</span>
<span className="v" id="v23" data-v="23" data-xref="啟示錄 7:3; 啟示錄 9:4; 希伯來書 11:28"> 因為耶和華要巡行各地，擊殺埃及人，祂看見你們的門框和門楣上有血，就必越過你們的家門，不讓滅命者進你們家殺人。</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及記 12:14; 創世記 17:8–10"> 這是你們及後代永遠當守的律例。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及記 3:17; 出埃及記 3:8; 申命記 12:8–9"> 你們進入耶和華應許給你們的地方以後，要守這逾越節。</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及記 13:14–15; 申命記 32:7; 詩篇 145:4"> 當你們的兒女問你們守這節期的意義時，</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及記 4:31; 出埃及記 12:11; 哥林多前書 5:7"> 你們就說，『這是獻給耶和華逾越節的祭，因為我們從前在埃及時，祂擊殺埃及人，卻越過以色列人所住的房子，救了我們各家。』」百姓聽了摩西這番話，都俯伏敬拜。</span>
<span className="v" id="v28" data-v="28" data-xref="希伯來書 11:28"> 耶和華怎麼吩咐摩西和亞倫，以色列人就照樣遵行。</span>
<span className="v" id="v29" data-v="29" data-xref="詩篇 78:51; 出埃及記 4:23; 詩篇 105:36"> 到了半夜，耶和華把所有埃及人的長子都殺了，包括坐王位的法老的長子、牢中囚犯的長子和一切頭生的牲畜。</span>
<span className="v" id="v30" data-v="30" data-xref="出埃及記 11:6; 阿摩司書 5:17; 箴言 21:13"> 當晚，法老及其臣僕和所有埃及人都驚醒了，到處都是哭號聲，因為沒有一家不死人的。</span>
<span className="v" id="v31" data-v="31" data-xref="出埃及記 6:1; 出埃及記 10:9; 出埃及記 3:19–20"> 法老連夜召見摩西和亞倫，對他們說：「你們和以色列人起來走吧，離開我的人民。就照你們的要求，去事奉耶和華吧！</span>
<span className="v" id="v32" data-v="32" data-xref="出埃及記 10:26; 創世記 27:34; 創世記 27:38"> 照你們的要求，把所有的牛羊都帶走吧！也要為我祝福。」</span>
<span className="v" id="v33" data-v="33" data-xref="詩篇 105:38; 出埃及記 11:1; 創世記 20:3"> 埃及人催促以色列人趕快離開埃及，因為他們說：「我們都要死了。」</span>
<span className="v" id="v34" data-v="34" data-xref="出埃及記 8:3"> 於是，以色列百姓就把沒有酵的麵團放在揉麵盆裡，用衣服包起來扛在肩上，</span>
<span className="v" id="v35" data-v="35" data-xref="出埃及記 3:21–22; 出埃及記 11:2–3; 創世記 15:14"> 又遵照摩西的吩咐向埃及人索取金器、銀器和衣服。</span>
<span className="v" id="v36" data-v="36" data-xref="創世記 15:14; 使徒行傳 7:10; 出埃及記 3:21–22"> 耶和華使埃及人恩待以色列人，他們要什麼，埃及人就給什麼。這樣，以色列人奪取了埃及人的財富。</span>
<span className="v" id="v37" data-v="37" data-xref="民數記 1:46; 出埃及記 38:26; 民數記 33:3"> 以色列百姓從埃及的蘭塞啟行，前往疏割，婦女孩童不算在內，單是步行的男子就有六十萬，</span>
<span className="v" id="v38" data-v="38" data-xref="民數記 11:4; 撒迦利亞書 8:23"> 同行的還有許多外族人和大群的牛羊。</span>
<span className="v" id="v39" data-v="39" data-xref="出埃及記 11:1; 出埃及記 6:1; 出埃及記 12:31–33"> 他們用從埃及帶出來的麵團烤成無酵餅，麵團沒有酵，因為他們被催促離開埃及，沒有時間準備食物。</span>
<span className="v" id="v40" data-v="40" data-xref="創世記 15:13; 使徒行傳 7:6; 使徒行傳 13:17"> 以色列人在埃及共住了四百三十年，</span>
<span className="v" id="v41" data-v="41" data-xref="哈巴谷書 2:3; 約翰福音 7:8; 使徒行傳 1:7"> 正好滿了四百三十年的那一天，耶和華帶領全軍離開了埃及。</span>
<span className="v" id="v42" data-v="42" data-xref="申命記 16:1–6; 出埃及記 12:14; 出埃及記 13:10"> 那天晚上是耶和華把祂的子民帶出埃及之夜，因此以後世世代代的以色列人都要在那日守夜，以尊崇耶和華。</span>
<span className="v" id="v43" data-v="43" data-xref="出埃及記 12:48; 民數記 9:14; 出埃及記 12:11"> 耶和華對摩西和亞倫說：「以下是逾越節的條例。 「所有外族人都不可吃逾越節的羊羔，</span>
<span className="v" id="v44" data-v="44" data-xref="創世記 17:12–13; 創世記 17:23"> 但那些買來的奴隸若接受了割禮，就可以吃。</span>
<span className="v" id="v45" data-v="45" data-xref="利未記 22:10; 以弗所書 2:12"> 寄居的外族人和雇工不可吃。</span>
<span className="v" id="v46" data-v="46" data-xref="民數記 9:12; 約翰福音 19:36; 約翰福音 19:33"> 你們吃的時候，應當在房子裡吃，不得把肉帶到外面去，也不可折斷羊羔的一根骨頭。</span>
<span className="v" id="v47" data-v="47" data-xref="出埃及記 12:6; 民數記 9:13; 出埃及記 12:3"> 以色列全體會眾都要守這節期。</span>
<span className="v" id="v48" data-v="48" data-xref="民數記 9:14; 歌羅西書 3:11; 加拉太書 3:28"> 跟你們住在一起的外族人如果想為耶和華守逾越節，他全家的男子都必須接受割禮，這樣才可以像以色列人一樣守逾越節，但沒有接受割禮的人絕不可吃逾越節的羊羔。</span>
<span className="v" id="v49" data-v="49" data-xref="民數記 15:15–16; 民數記 15:29; 利未記 24:22"> 本地人和在你們中間寄居的外族人都要遵守這規矩。」</span>
<span className="v" id="v50" data-v="50" data-xref="馬太福音 7:24–25; 出埃及記 6:26; 出埃及記 7:4"> 耶和華怎樣吩咐摩西和亞倫，以色列百姓都遵命而行。</span>
<span className="v" id="v51" data-v="51" data-xref="出埃及記 12:41; 出埃及記 6:26"> 就在那一天，耶和華帶領以色列大軍離開了埃及。</span>

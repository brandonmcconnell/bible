## 天糧

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民數記 33:10–12; 出埃及記 15:27; 出埃及記 17:1"> 以色列全體會眾從以琳出發，來到以琳和西奈中間的汛曠野，時值他們離開埃及後的第二個月的十五日。</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多前書 10:10; 出埃及記 15:24; 詩篇 106:25"> 以色列全體會眾在曠野向摩西和亞倫發怨言說：</span>
<span className="v" id="v3" data-v="3" data-xref="民數記 11:4–5; 民數記 20:3–5; 出埃及記 17:3"> 「我們還不如當初在埃及就死在耶和華手中。在那裡，我們至少可以圍在肉鍋旁吃個飽。現在，你把我們帶到曠野來，是要叫全體會眾餓死在這裡嗎？」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="哥林多前書 10:3; 詩篇 78:24–25; 申命記 8:2"> 耶和華對摩西說：「我要從天上降下食物給你們。百姓可以每天出去拾取他們當天所需的分量，這樣我就可以試驗他們是否遵行我的吩咐。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 16:22–23; 出埃及記 35:2–3; 利未記 25:21–22"> 到第六天，他們要比平時多拾取一倍的分量。」</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及記 6:7; 民數記 16:28; 出埃及記 16:12–13"> 摩西和亞倫對以色列百姓說：「今晚你們就知道把你們從埃及領出來的是耶和華。</span>
<span className="v" id="v7" data-v="7" data-xref="以賽亞書 40:5; 民數記 16:11; 約翰福音 11:40"> 早上，你們會看見祂的榮耀，因為祂聽見了你們向祂所發的怨言。我們算什麼，你們竟埋怨我們？」</span>
<span className="v" id="v8" data-v="8" data-xref="羅馬書 13:2; 撒母耳記上 8:7; 帖撒羅尼迦前書 4:8"> 摩西又說：「耶和華聽見你們發的怨言了，晚上祂必給你們肉吃，早晨再給你們餅吃個飽。我們算什麼？你們埋怨的其實不是我們，而是耶和華。」</span>
<span className="v" id="v9" data-v="9" data-xref="民數記 16:16; 出埃及記 16:2; 出埃及記 16:8"> 摩西對亞倫說：「你去叫以色列全體會眾到耶和華面前來，因為祂已聽見他們的怨言。」</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及記 16:7; 民數記 16:19; 民數記 16:42"> 亞倫對以色列全體會眾說話的時候，他們向曠野遠望，果然看見耶和華的榮光在雲彩中顯現。</span>
<span className="v" id="v11" data-v="11"> 耶和華對摩西說：</span>
<span className="v" id="v12" data-v="12" data-xref="約珥書 3:17; 以西結書 39:22; 出埃及記 6:7"> 「我已經聽見以色列人的怨言。你告訴他們，『到了黃昏，你們就會有肉吃，早晨就會有餅可以吃飽，這樣你們就知道我是你們的上帝耶和華。』」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="民數記 11:9; 詩篇 105:40; 詩篇 78:27–28"> 到了傍晚，有許多鵪鶉飛來，把營地都遮蓋了。到了早晨，營區四周的地上佈滿露水，</span>
<span className="v" id="v14" data-v="14" data-xref="民數記 11:7–9; 詩篇 105:40; 詩篇 78:24"> 露水蒸發以後，曠野便出現一層薄薄的、像白霜的東西。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及記 16:4; 約翰福音 6:58; 出埃及記 16:31"> 以色列人見了，不知道是何物，便彼此議論說：「這是什麼？」摩西對他們說：「這就是耶和華給你們的食物。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 16:36; 出埃及記 16:18; 出埃及記 16:32–33"> 耶和華吩咐你們要按自己和家人的食量來拾取，每人拾取兩升。」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17"> 於是，以色列人遵命而行，有人拾的多，有人拾的少。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多後書 8:14–15"> 後來，他們用升斗<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「升斗」原文為「俄梅珥」，一種量器，約兩升。">a</a></sup>量的時候，就發現多拾的沒有剩餘，少拾的也沒有缺乏，剛好是每人所需要的量。</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及記 12:10; 出埃及記 23:18; 馬太福音 6:34"> 摩西又吩咐他們說：「你們所拾取的，不可留到早晨！」</span>
<span className="v" id="v20" data-v="20" data-xref="馬可福音 10:14; 民數記 16:15; 以弗所書 4:26"> 可是，有的人不聽，留了一些。到了早上，食物已腐爛生蟲，發出惡臭，摩西就向他們發怒。</span>
<span className="v" id="v21" data-v="21" data-xref="箴言 6:6–11; 傳道書 12:1; 哥林多後書 6:2"> 百姓每天早晨出營拾取食物，各人按著所需分量拾取，到太陽升起後，食物就融化了。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及記 16:5; 利未記 25:22; 出埃及記 16:16"> 到第六天，他們就拾取雙倍的分量，也就是每人四升。會眾的首領來稟告摩西，</span>
<span className="v" id="v23" data-v="23" data-xref="利未記 23:3; 出埃及記 31:15; 出埃及記 20:8–11"> 摩西對他們說：「耶和華說，『明天是安息日，是向耶和華守的聖安息日。你們要把一切食物預備好，或烤或煮，吃剩的可以留到早晨。』」</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及記 16:20; 出埃及記 16:33"> 百姓就照摩西的吩咐，把吃剩的食物留到早晨，食物沒有發臭生蟲。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及記 16:23; 出埃及記 16:29; 尼希米記 9:14"> 摩西對他們說：「你們今天就吃這些吧，因為今天是耶和華的安息日，你們在野外找不到食物。</span>
<span className="v" id="v26" data-v="26" data-xref="申命記 5:13; 出埃及記 20:9–11; 以西結書 46:1"> 你們有六天可以拾取食物，但第七天是安息日，沒有食物可以拾取。」</span>
<span className="v" id="v27" data-v="27" data-xref="箴言 20:4"> 到了第七天早晨，有些人仍然出去要拾取食物，結果什麼也找不到。</span>
<span className="v" id="v28" data-v="28" data-xref="詩篇 78:10; 詩篇 106:13; 民數記 14:11"> 耶和華對摩西說：「你們到什麼時候才肯遵行我的誡命和吩咐呢？</span>
<span className="v" id="v29" data-v="29" data-xref="出埃及記 31:13; 以賽亞書 58:13–14; 以西結書 20:12"> 要知道，耶和華已將安息日賜給你們，所以第六天我會賜你們雙倍的食物。第七天，人人都要留在營中，不許外出。」</span>
<span className="v" id="v30" data-v="30" data-xref="申命記 5:12–14; 利未記 23:3; 希伯來書 4:9"> 於是，百姓在第七天休息。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="雅歌 2:3; 民數記 11:6–9; 出埃及記 16:15"> 以色列人稱這種食物為嗎哪，它形狀像芫荽的種子，白色，味道像蜜製薄餅。</span>
<span className="v" id="v32" data-v="32" data-xref="詩篇 105:5; 路加福音 22:19; 詩篇 111:4–5"> 摩西說：「以下是耶和華的吩咐，『把兩升的嗎哪保存起來，直到世世代代，以便你們的子子孫孫可以看見上帝帶你們離開埃及時，在曠野賜給你們的食物。』」</span>
<span className="v" id="v33" data-v="33" data-xref="希伯來書 9:4"> 於是，摩西吩咐亞倫：「拿個罐子盛滿兩升的嗎哪，放在耶和華面前，留到世世代代。」</span>
<span className="v" id="v34" data-v="34" data-xref="出埃及記 27:21; 出埃及記 25:21; 出埃及記 25:16"> 亞倫便照耶和華給摩西的吩咐，把嗎哪放在約櫃前保存起來。</span>
<span className="v" id="v35" data-v="35" data-xref="尼希米記 9:20–21; 約書亞記 5:12; 申命記 8:2–3"> 以色列百姓就在曠野吃了四十年的嗎哪，直到他們到達有人煙的地方，到迦南的邊境為止。</span>
<span className="v" id="v36" data-v="36" data-xref="出埃及記 16:16; 出埃及記 16:32–33"> 當時一俄梅珥等於十分之一伊法。</span>
</div>

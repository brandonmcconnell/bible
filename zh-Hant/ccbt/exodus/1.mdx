## 以色列人受欺壓

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歷代志上 2:1–2; 創世記 46:8–26; 創世記 35:23–26"> 以色列的眾子帶著家眷跟雅各<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「雅各」就是「以色列」，上帝為雅各改名以色列，故事參考創世記32·28。">a</a></sup>一起去了埃及，以下是他們的名字：</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 35:22"> 呂便、西緬、利未、猶大、</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 28:20; 創世記 35:23"> 以薩迦、西布倫、便雅憫、</span>
<span className="v" id="v4" data-v="4"> 但、拿弗他利、迦得、亞設。</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 10:22; 創世記 46:26–27; 士師記 8:30"> 雅各的子孫總共有七十人。那時，約瑟已經住在埃及。</span>
<span className="v" id="v6" data-v="6" data-xref="創世記 50:26; 創世記 50:24; 使徒行傳 7:14–16"> 後來，約瑟和他的弟兄以及同輩的人都相繼去世。</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 46:3; 創世記 1:28; 申命記 26:5"> 以色列人生養眾多，人口大增，很快就遍佈埃及，成為一個強大的民族。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行傳 7:18; 傳道書 2:18–19; 傳道書 9:15"> 後來，埃及有一位不認識約瑟的新王登基，</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 105:24–25; 傳道書 4:4; 雅各書 3:14–16"> 對他的百姓說：「你們看，以色列人比我們多，又比我們強。</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行傳 7:19; 詩篇 83:3–4; 箴言 1:11"> 來吧！我們要設法阻止他們人口增多，否則一遇到戰爭，他們便會加入我們敵人的陣營來攻打我們，然後一走了之。」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="創世記 15:13; 創世記 47:11; 出埃及記 3:7"> 於是，埃及人派監工強迫以色列人服勞役，在比東和蘭塞兩地為法老興建儲貨城。</span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 105:24; 出埃及記 1:9; 羅馬書 8:28"> 以色列人越受奴役，人口增長得越快，散居的範圍也越廣，令埃及人感到恐懼。</span>
<span className="v" id="v13" data-v="13" data-xref="申命記 4:20"> 於是，埃及人殘酷地奴役他們，</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行傳 7:19; 民數記 20:15; 出埃及記 2:23"> 強迫他們和泥造磚，並做田間一切的苦工，使他們痛苦不堪。埃及人殘酷地奴役他們做苦工。</span>
<span className="v" id="v15" data-v="15"> 埃及王又命令兩個希伯來的接生婆施弗拉和普阿：</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 1:22; 馬太福音 21:38; 啟示錄 12:4"> 「你們在替希伯來婦女接生的時候，如果看到生下的是男嬰，就把他殺掉；如果是女嬰，就讓她活下來。」</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行傳 5:29; 出埃及記 1:21; 馬太福音 10:28"> 但這兩個接生婆敬畏上帝，沒有執行埃及王的命令，而是保留了男嬰的性命。</span>
<span className="v" id="v18" data-v="18" data-xref="傳道書 8:4; 撒母耳記下 13:28"> 埃及王召見那兩個接生婆，質問她們：「你們為什麼這樣做？為什麼讓男嬰活著？」</span>
<span className="v" id="v19" data-v="19" data-xref="約書亞記 2:4–24; 撒母耳記下 17:19–20; 撒母耳記上 21:2"> 她們回答說：「因為希伯來婦女跟埃及婦女不同。她們身體強壯，我們還沒有趕到，嬰兒就生下來了。」</span>
<span className="v" id="v20" data-v="20" data-xref="以賽亞書 3:10; 傳道書 8:12; 箴言 11:18"> 因此，以色列人口繼續增加，更加繁盛。因為這兩個接生婆敬畏上帝，上帝便賜福給她們，使她們生兒育女。</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行傳 7:19; 箴言 1:16; 出埃及記 1:16"> 後來，法老命令全埃及的人把以色列人生的所有男嬰都拋進尼羅河裡，只讓女嬰活著。</span>
</div>

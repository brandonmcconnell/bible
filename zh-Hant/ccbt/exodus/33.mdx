<span className="v" id="v1" data-v="1" data-xref="創世記 12:7; 出埃及記 32:13; 出埃及記 32:7"> 耶和華對摩西說：「現在你和你從埃及領出來的百姓要離開這裡，去我向亞伯拉罕、以撒和雅各起誓要賜給他們後代的地方。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 32:34; 約書亞記 24:11; 出埃及記 23:27–31"> 我必差遣天使走在你們前面，趕出當地的迦南人、亞摩利人、赫人、比利洗人、希未人和耶布斯人。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 32:9–10; 出埃及記 3:8; 使徒行傳 7:51"> 你們要去那奶蜜之鄉。但我不會跟你們一起去，免得我在途中就把你們滅絕了，因為你們是頑固不化的百姓。」</span>
<span className="v" id="v4" data-v="4" data-xref="民數記 14:39; 民數記 14:1; 以西結書 26:16"> 百姓聽見這壞消息，都非常哀傷，不再佩戴飾物了。</span>
<span className="v" id="v5" data-v="5" data-xref="民數記 16:21; 民數記 16:45–46; 出埃及記 33:3–4"> 耶和華對摩西說：「你去向以色列百姓宣佈，『你們這些頑固不化的人，我就是跟你們在一起待一刻，都恐怕會滅絕你們。現在你們要摘下自己身上的飾物，我再決定怎樣處置你們。』」</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及記 33:4; 出埃及記 32:3; 耶利米書 2:19"> 因此，以色列百姓從何烈山開始就不再佩戴飾物了。</span>
</div>
</div>

## 耶和華的會幕

<div className="bt">
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="以賽亞書 55:6–7; 出埃及記 29:42–43; 箴言 15:29"> 摩西通常把帳幕支搭在營外離百姓較遠的地方，摩西稱帳幕為會幕。凡求問耶和華的，都會去那裡。</span>
<span className="v" id="v8" data-v="8" data-xref="民數記 16:27"> 當摩西離營去會幕的時候，百姓就都一同起來，各人站在自己的帳篷門口目送摩西走進會幕。</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 99:7; 出埃及記 31:18; 出埃及記 13:21–22"> 摩西進入會幕後，便有雲柱降下來，停在會幕門口，耶和華就跟摩西說話。</span>
<span className="v" id="v10" data-v="10" data-xref="列王紀上 8:22; 列王紀上 8:14; 出埃及記 4:31"> 百姓一看見雲柱停在會幕門口，就都站在自己的帳篷門口敬拜。</span>
<span className="v" id="v11" data-v="11" data-xref="民數記 12:8; 申命記 34:10; 出埃及記 24:13"> 耶和華跟摩西面對面說話，好像兩個朋友談話一樣。然後，摩西返回營中，但他的年輕助手、嫩的兒子約書亞仍然留在會幕。</span>
</div>
</div>

## 耶和華的榮耀

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="出埃及記 33:17; 耶利米書 1:5; 約翰福音 10:14–15"> 摩西對耶和華說：「你吩咐我帶領這些百姓，卻沒有告訴我你將要派誰與我同去，只說，『我憑名字認識你，你在我面前蒙了恩。』</span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 119:33; 詩篇 25:4; 詩篇 27:11"> 我若已經在你面前蒙恩，就求你把你的道路指示我，好讓我認識你，繼續在你面前蒙恩。求你顧念這民族是你的子民。」</span>
<span className="v" id="v14" data-v="14" data-xref="約書亞記 21:44; 馬太福音 11:28; 約書亞記 1:5"> 耶和華回答他說：「我必親自與你同去，使你平安穩妥。」</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及記 34:9; 詩篇 4:6; 出埃及記 33:3"> 摩西說：「你若不與我們同去，就不要帶我們離開這裡。</span>
<span className="v" id="v16" data-v="16" data-xref="申命記 4:7; 民數記 14:14; 列王紀上 8:53"> 你若不與我們同去，誰會知道我和你的子民在你面前蒙了恩呢？豈不是因為你的同在，才使我們不同於地上其他民族嗎？」</span>
<span className="v" id="v17" data-v="17" data-xref="以賽亞書 65:24; 約翰一書 5:14–15; 出埃及記 33:12"> 耶和華回答說：「我答應你的請求，因為你在我面前蒙了恩，我憑名字認識你。」</span>
<span className="v" id="v18" data-v="18" data-xref="啟示錄 21:23; 出埃及記 33:20; 提多書 2:13"> 摩西說：「求你向我彰顯你的榮耀。」</span>
<span className="v" id="v19" data-v="19" data-xref="羅馬書 9:15–18; 以弗所書 1:6–8; 耶利米書 31:14"> 耶和華說：「我必叫你看見我一切的美善，我要在你面前宣告我的名耶和華，我要恩待誰就恩待誰，我要憐憫誰就憐憫誰。</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 32:30; 約翰福音 1:18; 提摩太前書 6:16"> 但你不能看我的臉，因為凡看見的人，都不能存活。</span>
<span className="v" id="v21" data-v="21" data-xref="申命記 5:31; 撒迦利亞書 3:7; 約書亞記 20:4"> 你要站在我旁邊的磐石上，</span>
<span className="v" id="v22" data-v="22" data-xref="詩篇 91:1; 以賽亞書 2:21; 詩篇 91:4"> 我的榮耀經過你面前的時候，我會先把你安置在石縫裡，用我的手遮掩你，直到我從你面前走過。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及記 33:20; 約翰福音 1:18; 提摩太前書 6:16"> 然後我會收回我的手，你就可以看見我的背，但看不到我的臉。」</span>
</div>
</div>

## 十誡

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命記 5:22; 申命記 5:4; 申命記 4:36"> 以下是上帝的訓示：</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="申命記 5:6; 何西阿書 13:4; 利未記 26:13"> 「我是你的上帝耶和華，曾把你從受奴役之地埃及領出來。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="申命記 5:7; 馬太福音 4:10; 詩篇 81:9"> 「除我以外，你不可有別的神明。</span>
<span className="v" id="v4" data-v="4" data-xref="申命記 5:8; 利未記 26:1; 申命記 4:15–19"> 不可為自己雕刻神像，不可仿照天上、地上和地底下水中的任何形像造神像，</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 5:9; 民數記 14:18; 申命記 4:24"> 不可跪拜它們，也不可供奉它們，因為我——你的上帝耶和華痛恨不貞，我必追討背棄我之人的罪，從父到子直到三四代。</span>
<span className="v" id="v6" data-v="6" data-xref="申命記 7:9; 約翰福音 14:21; 約翰一書 5:3"> 但那些愛我、遵守我誡命的人，我必以慈愛待他們，直到千代。</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 5:11; 利未記 19:12; 雅各書 5:12"> 不可妄用你上帝耶和華的名，違者必被耶和華定罪。</span>
<span className="v" id="v8" data-v="8" data-xref="利未記 26:2; 利未記 19:3; 出埃及記 31:13–16"> 要謹記安息日，守為聖日。</span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 13:14; 出埃及記 34:21; 出埃及記 23:12"> 你一週可勞碌工作六天，</span>
<span className="v" id="v10" data-v="10" data-xref="申命記 5:14–15; 出埃及記 34:21; 民數記 15:32–36"> 但第七天是你的上帝耶和華的安息日，這一天你和兒女、僕婢、牲畜及你那裡的外族人不可做任何工。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 1:1–2; 創世記 2:2–3; 出埃及記 31:17"> 因為耶和華用六天創造了天地、海洋和其中的萬物，第七天便休息了，所以耶和華賜福安息日，把它定為聖日。</span>
<span className="v" id="v12" data-v="12" data-xref="以弗所書 6:1–3; 歌羅西書 3:20; 申命記 5:16"> 要孝敬父母，以便在你的上帝耶和華要賜給你的土地上享長壽。</span>
<span className="v" id="v13" data-v="13" data-xref="羅馬書 13:9; 申命記 5:17; 創世記 9:5–6"> 不可殺人。</span>
<span className="v" id="v14" data-v="14" data-xref="希伯來書 13:4; 申命記 5:18; 羅馬書 7:2–3"> 不可通姦。</span>
<span className="v" id="v15" data-v="15" data-xref="羅馬書 13:9; 以弗所書 4:28; 利未記 19:11"> 不可偷盜。</span>
<span className="v" id="v16" data-v="16" data-xref="箴言 19:5; 馬太福音 19:18; 詩篇 15:3"> 不可作偽證陷害人。</span>
<span className="v" id="v17" data-v="17" data-xref="羅馬書 13:9; 路加福音 12:15; 希伯來書 13:5"> 不可貪戀別人的房屋，不可貪戀別人的妻子、僕婢、牛驢或其他任何物品。」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="出埃及記 19:16–18; 耶利米書 23:23; 詩篇 139:7–8"> 那時雷電交加，號角嘹亮，山上冒煙，百姓見此情景，都嚇得渾身顫抖，不敢挨近。</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 18:16; 使徒行傳 7:38; 加拉太書 3:19"> 他們對摩西說：「求你跟我們說話，我們必聽從。不要讓上帝直接跟我們說話，恐怕我們會喪命！」</span>
<span className="v" id="v20" data-v="20" data-xref="申命記 13:3; 箴言 3:7; 撒母耳記上 12:20"> 摩西對百姓說：「不要害怕，上帝降臨是要試驗你們，好讓你們時時敬畏祂，不致犯罪。」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="列王紀上 8:12; 詩篇 97:2; 詩篇 18:9"> 百姓都站得遠遠的，摩西獨自走進上帝所在的密雲中。</span>
<span className="v" id="v22" data-v="22" data-xref="尼希米記 9:13; 申命記 4:36; 希伯來書 12:25–26"> 耶和華吩咐摩西對以色列百姓說：「既然你們已經親眼看見我從天上向你們說話，</span>
<span className="v" id="v23" data-v="23" data-xref="以西結書 20:39; 西番雅書 1:5; 列王紀下 17:33"> 你們不可製造神像與我並立，不可為自己製造金銀神像。</span>
<span className="v" id="v24" data-v="24" data-xref="申命記 12:5; 歷代志下 6:6; 詩篇 132:13–14"> 你們要為我築一座土壇，把你們的牛羊獻在壇上作燔祭和平安祭。凡是我使自己的名被尊崇的地方，我會親臨那裡賜福給你們。</span>
<span className="v" id="v25" data-v="25" data-xref="約書亞記 8:31; 申命記 27:5–6"> 你們若為我築石壇，不可用鑿刻的石頭，因為用工具鑿刻的石頭會玷污祭壇。</span>
<span className="v" id="v26" data-v="26" data-xref="彼得前書 1:16; 傳道書 5:1; 利未記 10:3"> 不可踩著臺階登我的祭壇，免得露出你們的下體。</span>
</div>
</div>

## 瘟疫之災

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及記 8:1; 出埃及記 10:3; 出埃及記 8:20"> 耶和華對摩西說：「你去見法老，告訴他，『希伯來人的上帝耶和華說：放我的子民走，他們好事奉我。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 8:2; 出埃及記 4:23; 利未記 26:27–28"> 如果你不讓他們走，繼續扣留他們，</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 7:4; 使徒行傳 13:11; 撒母耳記上 6:9"> 我必出手使你田間所有的牲畜，包括馬、驢、駱駝和牛羊，都染上嚴重的瘟疫。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及記 8:22; 出埃及記 10:23; 瑪拉基書 3:18"> 但我要把埃及和以色列的牲畜分開，以色列人的牲畜必絲毫無損。』」</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 8:23; 出埃及記 10:4; 耶利米書 28:16–17"> 耶和華定了日期，說：「明天耶和華必在此地行這事。」</span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 78:48; 出埃及記 9:25; 詩篇 78:50"> 第二天，耶和華就行了這事，埃及人的牲畜都死了，但以色列人的牲畜一頭也沒死。</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及記 7:14; 出埃及記 8:32; 以賽亞書 48:4"> 法老派人去探查，發現以色列人的牲畜一頭也沒死。可是，他仍然心裡頑固，不肯讓以色列人離開。</span>
</div>
</div>

## 膿瘡之災

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="出埃及記 8:16"> 耶和華對摩西和亞倫說：「你們去取幾把窯裡的灰，摩西要在法老面前把灰拋向空中。</span>
<span className="v" id="v9" data-v="9" data-xref="啟示錄 16:2; 申命記 28:27; 約伯記 2:7"> 這灰要變成塵土，散佈在埃及全境，落在人或牲畜身上，就會起皰長瘡。」</span>
<span className="v" id="v10" data-v="10" data-xref="申命記 28:27"> 摩西和亞倫便取了一些窯裡的灰，站在法老面前，摩西把灰拋向空中，埃及人和牲畜身上就開始起皰長瘡。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及記 7:11–12; 出埃及記 8:18–19; 啟示錄 16:2"> 埃及的巫師無法與摩西對抗，因為他們及所有埃及人身上都長了膿瘡。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及記 4:21; 出埃及記 7:13–14; 詩篇 81:11–12"> 耶和華使法老的心剛硬，他就不聽他們的話，正如耶和華對摩西說的。</span>
</div>
</div>

## 冰雹之災

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="出埃及記 8:20; 出埃及記 7:15; 出埃及記 9:1"> 耶和華對摩西說：「明天一早你再去見法老，對他說，『希伯來人的上帝耶和華這樣說，你要放我的子民走，他們好事奉我。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及記 8:10; 利未記 26:28; 歷代志上 17:20"> 這一次，我要降下大災禍在你及你的臣僕和百姓身上，好叫你知道普天之下我獨一無二。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及記 3:20; 出埃及記 9:3; 出埃及記 9:16"> 我若用瘟疫攻擊你和你的百姓，你們早就滅亡了。</span>
<span className="v" id="v16" data-v="16" data-xref="羅馬書 9:17; 箴言 16:4; 詩篇 83:17–18"> 我讓你活到現在，是為了向你彰顯我的權能，使我的名傳遍天下。</span>
<span className="v" id="v17" data-v="17" data-xref="以賽亞書 37:29; 以賽亞書 10:15; 以賽亞書 37:23–24"> 但你竟然在我的子民面前狂傲自大，不讓他們離開。</span>
<span className="v" id="v18" data-v="18" data-xref="列王紀上 20:6; 詩篇 83:15; 出埃及記 9:22–25"> 明天大約這時候，我要使天上降下大冰雹，是你們埃及立國以來從沒有見過的。</span>
<span className="v" id="v19" data-v="19" data-xref="哈巴谷書 3:2"> 現在，你要叫人到田間把牲畜和屬於你的一切都帶到安全的地方。凡留在田間的人或牲畜都會被冰雹打死。』」</span>
<span className="v" id="v20" data-v="20" data-xref="箴言 13:13; 箴言 22:3; 希伯來書 11:7"> 有些法老的臣僕聽了耶和華的話就很害怕，趕忙把在田間的僕人和牲畜都召回屋裡。</span>
<span className="v" id="v21" data-v="21" data-xref="以西結書 40:4; 約伯記 34:14; 歷代志上 22:19"> 但那些不把耶和華的話放在心上的，仍把他們的奴僕和牲畜留在田間。</span>
<span className="v" id="v22" data-v="22" data-xref="啟示錄 16:21; 出埃及記 7:19; 出埃及記 8:5"> 耶和華對摩西說：「你向天伸杖，天就會降下冰雹，落在埃及的一切人畜身上，摧毀田間的一切農作物。」</span>
<span className="v" id="v23" data-v="23" data-xref="詩篇 18:13; 約書亞記 10:11; 以賽亞書 30:30"> 摩西向天伸出手杖，耶和華就發出雷電和冰雹，火光飛向大地。耶和華在埃及降下冰雹。</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及記 9:23; 馬太福音 24:21; 出埃及記 10:6"> 那時冰雹夾雜著火降下來，極為嚴重，在埃及史無前例。</span>
<span className="v" id="v25" data-v="25" data-xref="詩篇 78:47; 詩篇 105:32–33"> 冰雹摧毀了埃及境內田間的一切人、牲畜和作物，打斷了所有的樹木，</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及記 11:7; 出埃及記 9:4; 出埃及記 10:23"> 只有以色列人所住的歌珊沒有冰雹。</span>
<span className="v" id="v27" data-v="27" data-xref="耶利米哀歌 1:18; 詩篇 129:4; 出埃及記 10:16"> 法老派人召來摩西和亞倫，對他們說：「這次我犯罪了，耶和華是對的，我和我的百姓錯了。</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及記 8:8; 出埃及記 10:17; 出埃及記 8:28"> 請你們向耶和華祈求，我們已經受夠了雷電和冰雹。我准許以色列人出去，你們不必再留在這裡了。」</span>
<span className="v" id="v29" data-v="29" data-xref="哥林多前書 10:26; 列王紀上 8:38; 以賽亞書 1:15"> 摩西回答說：「我一出城，就向耶和華舉手禱告，雷電和冰雹必立刻停止，這樣你就知道普天下都屬於耶和華。</span>
<span className="v" id="v30" data-v="30" data-xref="以賽亞書 26:10; 箴言 16:6; 以賽亞書 63:17"> 但我知道你和你的臣僕還是不敬畏上帝耶和華。」</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="路得記 1:22; 路得記 2:23; 哈巴谷書 3:17"> 這場冰雹打壞了大麥和亞麻，因為正是大麥吐穗和亞麻開花的時候。</span>
<span className="v" id="v32" data-v="32" data-xref="出埃及記 10:22"> 小麥和粗麥尚未長成，沒有被冰雹打壞。</span>
<span className="v" id="v33" data-v="33" data-xref="出埃及記 9:29; 出埃及記 8:12; 雅各書 5:17–18"> 摩西離開法老，走出城外向耶和華舉手禱告，雷和冰雹便停了，雨也不下了。</span>
<span className="v" id="v34" data-v="34" data-xref="出埃及記 7:14; 歷代志下 36:13; 出埃及記 4:21"> 法老看見雨、雷和冰雹停止了，就又犯罪，他和他的臣僕都心裡頑固。</span>
<span className="v" id="v35" data-v="35" data-xref="出埃及記 4:21"> 法老硬著心，不讓以色列人離開，正如耶和華藉摩西所言。</span>
</div>
</div>

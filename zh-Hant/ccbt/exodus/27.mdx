## 造燔祭壇的條例

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及記 38:1–7; 出埃及記 20:24–26; 出埃及記 40:10"> 「要用皂莢木造一個方形的祭壇，長寬各兩米二，高一米三。</span>
<span className="v" id="v2" data-v="2" data-xref="詩篇 118:27; 出埃及記 29:12; 利未記 4:7"> 要在壇的四角造四個凸起的角，與壇連成一體，壇外面要包上銅。</span>
<span className="v" id="v3" data-v="3" data-xref="列王紀上 7:45; 民數記 4:14; 歷代志上 28:17"> 用銅造盛壇灰的盆和其他祭壇用具，即鏟、碗、肉叉、火鼎。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及記 35:16; 出埃及記 25:12; 出埃及記 38:4–5"> 要造一個銅網，在銅網的四角造四個銅環。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 38:4"> 銅網在祭壇圍邊的下方，向下伸展到祭壇的腰部。</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及記 35:13–15; 民數記 4:44; 出埃及記 30:4"> 要用皂莢木為祭壇造兩根橫槓，包上銅。</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及記 25:28; 出埃及記 30:4; 民數記 4:13–14"> 要將兩根橫槓穿在壇兩旁的銅環裡，以便抬壇。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及記 25:40; 出埃及記 25:9; 希伯來書 8:5"> 整座壇都用木板製作，壇是中空的。一切都要照我在山上給你的指示去做。</span>
</div>
</div>

## 聖幕院子的規劃

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="出埃及記 38:9–20; 以西結書 40:32; 以西結書 42:3"> 「要為聖幕圍出一個院子。院子南面的帷幔要用細麻織成，長四十五米，</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及記 26:19–21; 耶利米書 52:21; 出埃及記 36:38"> 帷幔有二十根柱子，二十個帶凹槽的銅底座，柱子上的鉤和箍都是銀的。</span>
<span className="v" id="v11" data-v="11"> 北面的帷幔也是長四十五米，柱子、銅底座、鉤和箍的樣式都與南面的一樣。</span>
<span className="v" id="v12" data-v="12"> 院子西面的帷幔寬二十二米半，有十根柱子和十個帶凹槽的底座。</span>
<span className="v" id="v13" data-v="13"> 院子東面的帷幔也是寬二十二米半。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及記 27:9; 出埃及記 26:36"> 入口兩邊的帷幔都是寬七米，各有三根柱子和三個帶凹槽的底座。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 26:36; 士師記 5:30; 出埃及記 28:39"> 院子的入口要有門簾，長九米，用細麻和藍色、紫色、朱紅色毛線繡製，還有四根柱子和四個帶凹槽的底座。</span>
<span className="v" id="v17" data-v="17"> 院子四圍的柱子都要有銀箍，所有的鉤子都要用銀製作，帶凹槽的底座要用銅製作。</span>
<span className="v" id="v18" data-v="18"> 整個院子長四十五米，寬二十二米半，高兩米二，所有的帷幔都要用細麻精工製作，帶凹槽的底座要用銅製作。</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及記 35:18; 以賽亞書 22:23–25; 民數記 4:32"> 聖幕裡其他一切器具以及聖幕、院子所用的橛子都要用銅製作。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="利未記 24:1–4; 撒迦利亞書 4:11–14; 詩篇 23:5"> 「你要吩咐以色列人把榨的純橄欖油給你拿來點燈，使燈常明。</span>
<span className="v" id="v21" data-v="21" data-xref="民數記 19:21; 民數記 18:23; 撒母耳記上 3:3"> 亞倫和他的子孫要負責照看會幕內遮掩約櫃的幔子外的燈，使燈從晚上到早晨一直在耶和華面前亮著。這是以色列百姓世代當守的永久律例。</span>
</div>

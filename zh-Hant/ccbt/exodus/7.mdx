## 亞倫和摩西面見法老

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及記 4:15–16; 詩篇 82:6; 約翰福音 10:35–36"> 耶和華對摩西說：「我要使你在法老面前像上帝一樣，你哥哥亞倫是你的發言人。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 4:15; 出埃及記 6:29; 申命記 4:2"> 你要傳達我吩咐你的一切話，你哥哥亞倫要求法老讓以色列人離開他的國家。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 4:21; 出埃及記 11:9; 詩篇 105:27–36"> 可是，我要使法老的心剛硬，雖然我在埃及行許多神蹟奇事，</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及記 11:9; 出埃及記 6:6; 出埃及記 12:51"> 他仍無動於衷。那時，我必伸手重重地懲罰埃及，然後領我大隊的以色列子民離開埃及。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 14:18; 出埃及記 7:17; 出埃及記 8:22"> 我伸手攻擊他們，把以色列人帶出埃及之時，埃及人就會知道我是耶和華。」</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及記 7:2; 創世記 6:22; 出埃及記 7:10"> 摩西和亞倫便遵命而行。</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 34:7; 使徒行傳 7:30; 申命記 31:2"> 他們去見法老的時候，摩西八十歲，亞倫八十三歲。</span>
<span className="v" id="v8" data-v="8"> 耶和華對摩西和亞倫說：</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及記 4:2; 約翰福音 2:18; 以賽亞書 7:11"> 「倘若法老要你們行神蹟給他看，你就吩咐亞倫把手杖扔在法老面前，使杖變作蛇。」</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及記 4:3; 路加福音 10:19; 阿摩司書 9:3"> 摩西和亞倫照耶和華的吩咐來到法老面前。亞倫把手杖扔在法老和他的臣僕面前，杖就變作蛇。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及記 7:22; 提摩太後書 3:8; 出埃及記 8:18"> 法老召智者和巫師前來，這些人是埃及的術士，他們也用邪術如法炮製。</span>
<span className="v" id="v12" data-v="12" data-xref="約翰一書 4:4; 出埃及記 9:11; 出埃及記 8:18–19"> 各人將自己的手杖扔在地上，杖就變作蛇，但亞倫的杖吞噬了他們的杖。</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及記 4:21; 出埃及記 8:15; 撒迦利亞書 7:11–12"> 法老卻仍然硬著心，不肯聽從摩西和亞倫，正如耶和華所言。</span>
</div>
</div>

## 水變血之災

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="出埃及記 10:20; 出埃及記 8:15; 出埃及記 10:1"> 耶和華對摩西說：「法老非常頑固，不肯放百姓走。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及記 8:20; 出埃及記 2:5; 出埃及記 7:10"> 明天早晨，法老會去尼羅河邊，你去河邊見他，要拿著曾變成蛇的手杖。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 3:18; 出埃及記 9:1; 出埃及記 9:13"> 你要對他說，『希伯來人的上帝耶和華差遣我來告訴你，要讓祂的子民到曠野去事奉祂，但到如今你還是不肯。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及記 4:9; 出埃及記 5:2; 出埃及記 7:5"> 所以祂說要用手杖擊打尼羅河水，使河水變成血，好叫你知道祂是耶和華。</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及記 7:24; 出埃及記 7:21; 民數記 11:20"> 河裡的魚會死，河水會發臭，埃及人不能再喝尼羅河的水。』」</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及記 14:21; 出埃及記 10:12; 出埃及記 8:5–6"> 耶和華對摩西說：「你告訴亞倫，讓他向埃及境內的各江河、溪流、池塘伸杖，使水變成血。埃及境內，包括木頭和石頭器皿中將到處是血。」</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 78:44; 詩篇 105:29; 出埃及記 7:17–18"> 摩西和亞倫就按著耶和華所吩咐的去做，亞倫在法老和他的眾臣僕面前舉杖擊打尼羅河水，河水都變成了血。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及記 7:18; 啟示錄 8:9"> 河裡的魚都死了，河水臭得不能飲用。埃及遍地都是血。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及記 7:11; 提摩太後書 3:8; 耶利米書 27:18"> 可是，埃及的巫師用邪術同樣使水變成血。法老仍然硬著心，不肯聽從摩西和亞倫的話，正如耶和華所言。</span>
<span className="v" id="v23" data-v="23" data-xref="耶利米書 36:24; 以西結書 40:4; 瑪拉基書 2:2"> 法老若無其事地轉身回宮去了。</span>
<span className="v" id="v24" data-v="24"> 因為河水不能飲用，埃及人就在尼羅河兩岸掘井取水飲用。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及記 10:23; 出埃及記 8:9–10; 撒母耳記下 24:13"> 耶和華擊打河水後，七天過去了。</span>
</div>

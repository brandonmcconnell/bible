## 上帝應許拯救以色列人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及記 12:33; 出埃及記 12:31; 出埃及記 3:19–20"> 耶和華對摩西說：「你就要看見我怎樣用大能的手對付法老，那時他會讓以色列人走，甚至把他們趕出他的國土！」</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米書 9:24; 瑪拉基書 3:6; 使徒行傳 17:24–25"> 上帝又對摩西說：「我是耶和華，</span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 83:18; 詩篇 68:4; 創世記 17:1"> 我曾以全能上帝的身分向亞伯拉罕、以撒和雅各顯現，但沒有讓他們知道我的名字是耶和華。</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 28:4; 創世記 15:18; 創世記 17:7–8"> 我堅守與他們所立的約，要把他們寄居的迦南賜給他們。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 2:24; 詩篇 106:44–45; 以賽亞書 63:9"> 我已聽見以色列人因受埃及人的奴役而發出的哀聲，也顧念我的約。</span>
<span className="v" id="v6" data-v="6" data-xref="申命記 26:8; 歷代志上 17:21; 出埃及記 7:4"> 所以，你要轉告以色列人說，『我是耶和華。我要解救你們脫離埃及人的轄制，脫離他們的奴役，我要伸出臂膀大行審判，以救贖你們。</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 7:6; 申命記 29:13; 申命記 4:20"> 我要接納你們做我的子民，我要做你們的上帝。這樣，你們就知道我是你們的上帝耶和華，曾救你們脫離埃及人的轄制。</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 26:3; 創世記 15:18; 以西結書 20:42"> 我必帶領你們進入我舉手起誓要給亞伯拉罕、以撒和雅各的那片土地，把它賜給你們作產業。我是耶和華。』」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="出埃及記 5:21; 約伯記 21:4; 出埃及記 14:12"> 摩西把這番話轉告百姓，可是他們因為殘酷的勞役無比沮喪，不肯聽他的話。</span>
<span className="v" id="v10" data-v="10"> 耶和華對摩西說：</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及記 6:29; 出埃及記 5:23; 出埃及記 3:10"> 「你去告訴埃及王法老，讓以色列人離開他的土地。」</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及記 4:10; 耶利米書 1:6; 出埃及記 6:30"> 摩西卻說：「以色列人都不聽我的話，法老又怎麼肯聽我這拙口笨舌的人呢？」</span>
<span className="v" id="v13" data-v="13" data-xref="民數記 27:23; 提摩太前書 6:13; 詩篇 91:11"> 耶和華吩咐摩西和亞倫回到以色列人和法老那裡，要他們領以色列人離開埃及。</span>
</div>
</div>

## 摩西和亞倫的族譜

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="創世記 46:9; 歷代志上 5:3; 民數記 26:5–7"> 以下是以色列各家族的族長：<br />以色列長子呂便的兒子是哈諾、法路、希斯倫和迦米。這些是呂便的宗族。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="歷代志上 4:24; 創世記 46:10; 民數記 26:12–13"> 西緬的兒子是耶姆利、雅憫、阿轄、雅斤、瑣轄和掃羅，掃羅的母親是迦南人。這些是西緬的各宗族。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="民數記 3:17; 創世記 46:11; 歷代志上 6:1"> 按照家譜的記載，利未的兒子是革順、哥轄和米拉利，利未享年一百三十七歲。</span>
<span className="v" id="v17" data-v="17" data-xref="歷代志上 6:17; 民數記 3:18; 歷代志上 23:7"> 革順的兒子是立尼和示每，二人各成宗族。</span>
<span className="v" id="v18" data-v="18" data-xref="歷代志上 6:18; 歷代志上 6:2; 民數記 3:19"> 哥轄的兒子是暗蘭、以斯哈、希伯倫和烏薛，哥轄享年一百三十三歲。</span>
<span className="v" id="v19" data-v="19" data-xref="民數記 3:20; 歷代志上 23:21; 歷代志上 6:19"> 米拉利的兒子是抹利和姆示。這些按家譜的記載是利未的各宗族。</span>
<span className="v" id="v20" data-v="20" data-xref="民數記 26:59; 出埃及記 2:1–2; 出埃及記 6:18"> 暗蘭娶了他父親的妹妹約基別，生了亞倫和摩西，暗蘭享年一百三十七歲。</span>
<span className="v" id="v21" data-v="21" data-xref="民數記 16:1; 歷代志上 6:37–38; 民數記 16:32"> 以斯哈的兒子是可拉、尼斐和細基利。</span>
<span className="v" id="v22" data-v="22" data-xref="利未記 10:4; 民數記 3:30; 尼希米記 3:20"> 烏薛的兒子是米沙利、以利撒反和西提利。</span>
<span className="v" id="v23" data-v="23" data-xref="路得記 4:19–20; 民數記 2:3; 民數記 1:7"> 亞倫娶了亞米拿達的女兒、拿順的妹妹以利沙巴，她生了拿答、亞比戶、以利亞撒和以他瑪。</span>
<span className="v" id="v24" data-v="24" data-xref="歷代志上 6:22–23; 民數記 16:1; 撒母耳記上 1:1"> 可拉的兒子是亞惜、以利加拿和亞比亞撒，這些是可拉的各宗族。</span>
<span className="v" id="v25" data-v="25" data-xref="約書亞記 24:33; 民數記 25:7–13; 約書亞記 22:31–32"> 亞倫的兒子以利亞撒與普鐵的一個女兒結婚，生了非尼哈。以上是利未各宗族的族長。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="出埃及記 12:51; 出埃及記 12:17; 出埃及記 7:4"> 正是亞倫和摩西受耶和華之命，要按以色列人的隊伍把他們帶出埃及。</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及記 6:26; 出埃及記 7:10; 詩篇 77:20"> 也是摩西和亞倫要求埃及王法老讓他們把以色列人帶出埃及。</span>
<span className="v" id="v28" data-v="28"> 那時，耶和華曾經在埃及對摩西說：</span>
<span className="v" id="v29" data-v="29" data-xref="出埃及記 6:11; 出埃及記 7:2; 出埃及記 6:2"> 「我是耶和華，你要把我吩咐你的一切話告訴埃及王法老。」</span>
<span className="v" id="v30" data-v="30" data-xref="出埃及記 6:12; 出埃及記 4:10; 哥林多前書 9:16–17"> 摩西卻對耶和華說：「你看，我拙口笨舌，法老怎肯聽我的話？」</span>
</div>
</div>

</div>

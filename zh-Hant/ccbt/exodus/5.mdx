## 摩西和亞倫見法老

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及記 10:9; 使徒行傳 4:29; 馬太福音 10:28"> 之後，摩西和亞倫去見法老，對他說：「以色列的上帝耶和華說，『放我的子民走，讓他們到曠野去為我守節期。』」</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 3:19; 約伯記 21:15; 列王紀下 18:35"> 法老說：「耶和華是誰？我憑什麼要聽從祂，放走以色列人？我不認識祂，也不會讓以色列人離開！」</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 3:18; 撒迦利亞書 14:16–19; 以西結書 6:11"> 摩西和亞倫說：「希伯來人的上帝向我們顯現了。求你容我們走三天的路程，到曠野去向我們的上帝耶和華獻祭，免得祂用瘟疫或刀劍來攻擊我們。」</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及記 1:11; 使徒行傳 24:5; 阿摩司書 7:10"> 埃及王說：「摩西、亞倫，你們為什麼讓百姓停工！快回去服勞役！」</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 1:7–11; 箴言 14:28"> 法老又說：「這地方的以色列人如此多，你竟叫他們停工！」</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及記 5:10; 出埃及記 5:19; 申命記 16:18"> 當天，法老就對埃及監工和以色列人的工頭下令：</span>
<span className="v" id="v7" data-v="7" data-xref="士師記 19:19; 創世記 24:25"> 「不許再供應草給他們製磚，叫他們自己去撿，</span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 106:41"> 但上交的磚的數量要和往常一樣，一塊也不可少。因為他們懶惰，所以才嚷著要去給他們的上帝獻祭。</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀下 18:20; 耶利米書 43:2; 約伯記 16:3"> 你們要加重他們的工作，他們就無暇再聽那些蠱惑人心的話了！」</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及記 1:11; 出埃及記 3:7; 箴言 29:12"> 於是，那些監工和工頭就出來向百姓宣佈：「法老下令不再供應草給你們製磚。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及記 5:13–14"> 你們要自己設法去找，但上交的磚一塊也不能少。」</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及記 15:7; 以賽亞書 5:24; 以賽亞書 47:14"> 百姓只好在埃及各地收集禾稭當草用。</span>
<span className="v" id="v13" data-v="13"> 監工催逼他們說：「你們要完成每天規定的數目，像從前有草時一樣。」</span>
<span className="v" id="v14" data-v="14" data-xref="以賽亞書 10:24"> 法老的監工又鞭打他們委派的以色列工頭，說：「你們這兩天為什麼沒有像從前一樣完成規定的磚數？」</span>
<span className="v" id="v15" data-v="15"> 以色列人的工頭來見法老，向他哀求說：「你為什麼要這樣對待僕人們？</span>
<span className="v" id="v16" data-v="16"> 監工不給僕人們草，卻命令我們製作磚，還打我們，其實是你百姓的錯。」</span>
<span className="v" id="v17" data-v="17" data-xref="馬太福音 26:8; 約翰福音 6:27; 出埃及記 5:8"> 法老說：「你們是懶漢，懶漢！所以才嚷著要去給耶和華獻祭。</span>
<span className="v" id="v18" data-v="18" data-xref="以西結書 18:18; 但以理書 2:9–13"> 回去繼續做工！我不再供應草給你們，但磚要如數交齊。」</span>
<span className="v" id="v19" data-v="19" data-xref="傳道書 5:8; 傳道書 4:1; 申命記 32:36"> 以色列人的工頭聽見每天做的磚數不可減少，就知道情況不妙。</span>
<span className="v" id="v20" data-v="20"> 他們從法老那裡出來的時候，遇見摩西和亞倫站在外面等候，</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 34:30; 撒母耳記上 13:4; 歷代志上 19:6"> 便埋怨二人說：「願耶和華鑒察、懲罰你們！你們使我們在法老和他的臣僕面前有了臭名，無異於把刀遞到他們手中來殺我們。」</span>
<span className="v" id="v22" data-v="22" data-xref="耶利米書 20:7; 列王紀上 19:10; 民數記 11:14–15"> 摩西回到耶和華那裡說：「主啊！你為什麼這樣苦待你的子民呢？為什麼要派我去呢？</span>
<span className="v" id="v23" data-v="23" data-xref="耶利米書 11:21; 希伯來書 10:36–37; 以賽亞書 28:16"> 自從我去法老那裡奉你的名說話後，他更加虐待你的子民，你卻根本沒有拯救他們。」</span>

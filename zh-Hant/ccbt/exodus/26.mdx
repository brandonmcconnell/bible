## 聖幕的做法

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及記 36:8–19; 出埃及記 26:36; 出埃及記 26:31"> 「要用十幅幔子做聖幕，幔子要用細麻和藍色、紫色、朱紅色毛線織成，上面要精工繡製基路伯天使。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳記下 7:2; 民數記 4:25; 歷代志上 17:1"> 每幅幔子的尺寸都一樣，長十二米半、寬一米八。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 36:10; 歌羅西書 2:2; 以弗所書 2:21–22"> 每五幅連在一起，形成兩幅大幔子。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及記 36:11–12; 出埃及記 36:17; 出埃及記 26:10–11"> 要在每幅大幔子末幅的邊緣釘上藍色的扣環，</span>
<span className="v" id="v5" data-v="5"> 每幅大幔子釘五十個，扣環要兩兩相對，</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及記 36:13; 出埃及記 26:11; 出埃及記 26:33"> 再做五十個金鉤，把兩幅大幔子連在一起，成為一個完整的聖幕。</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及記 26:14; 詩篇 45:13; 出埃及記 26:9"> 「要用山羊毛織十一幅幔子作聖幕的罩棚，</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及記 26:13; 出埃及記 26:2"> 每幅長十三米半、寬一米八。十一幅幔子的尺寸都要一樣。</span>
<span className="v" id="v9" data-v="9"> 然後，你們要把五幅連成一大幅，其餘六幅連成一大幅，第六幅要在罩棚前疊起來。</span>
<span className="v" id="v10" data-v="10"> 要在這兩幅大幔子末幅的邊緣各釘上五十個扣環，</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及記 26:3; 出埃及記 26:6"> 再做五十個銅鉤，把這兩幅大幔子扣在一起，成為一個完整的罩棚。</span>
<span className="v" id="v12" data-v="12"> 鋪罩棚所剩下來的半幅幔子要垂到聖幕後面。</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及記 26:2; 出埃及記 26:8"> 兩旁餘下的幔子可垂在聖幕的兩邊，每邊長四十五釐米，蓋著聖幕。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及記 36:19; 出埃及記 25:5; 出埃及記 35:23"> 罩棚上面要蓋一層染成紅色的公羊皮，再蓋一層海狗皮做頂蓋。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及記 36:20–33; 民數記 4:31–32; 出埃及記 40:17–18"> 「要用皂莢木做支聖幕的木板，</span>
<span className="v" id="v16" data-v="16"> 每塊木板長四米半，寬七十釐米。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及記 36:22; 出埃及記 26:19; 出埃及記 36:24"> 每塊木板要有兩個接榫，用來銜接。聖幕的所有木板都要這樣。</span>
<span className="v" id="v18" data-v="18"> 聖幕的南面要有二十塊木板，</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及記 38:27; 出埃及記 38:30–31; 出埃及記 26:37"> 在這些木板下面要造四十個帶凹槽的銀底座，每塊木板下面有兩個，套在木板的兩個接榫上。</span>
<span className="v" id="v20" data-v="20"> 聖幕北面也要有二十塊木板，</span>
<span className="v" id="v21" data-v="21"> 木板下面同樣有四十個帶凹槽的銀底座，每塊木板下面有兩個銀底座。</span>
<span className="v" id="v22" data-v="22"> 聖幕後面，就是西面，要有六塊木板。</span>
<span className="v" id="v23" data-v="23"> 聖幕後面的兩個拐角要各有一塊木板，</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及記 36:29–30; 詩篇 133:1–3; 哥林多前書 1:10"> 木板的下端連於底座<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「連於底座」或譯「是雙層的」。">a</a></sup>，頂端用一個環固定。兩個拐角都要這樣做。</span>
<span className="v" id="v25" data-v="25"> 這樣，後面共有八塊木板，每塊木板下面各有兩個帶凹槽的銀底座，一共有十六個銀底座。</span>
<span className="v" id="v26" data-v="26" data-xref="羅馬書 15:1; 民數記 4:31; 加拉太書 6:1–2"> 「要用皂莢木做橫閂，聖幕左右兩邊和後面的牆板上要各有五根橫閂，</span>
<span className="v" id="v28" data-v="28"> 攔腰固定牆板的那根橫閂要從這端貫穿到那端。</span>
<span className="v" id="v29" data-v="29" data-xref="出埃及記 25:11–12"> 所有的木板和橫閂都要包上金，並要在木板上造金環，用來穿橫閂。</span>
<span className="v" id="v30" data-v="30" data-xref="出埃及記 25:40; 希伯來書 8:5; 出埃及記 25:9"> 要照著我在山上所指示你的樣式，把聖幕支搭起來。</span>
</div>
</div>

## 造至聖所的條例

<div className="bt">
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="馬太福音 27:51; 歷代志下 3:14; 出埃及記 36:35"> 「要用細麻和藍色、紫色、朱紅色毛線織成一幅幔子，上面精工繡上基路伯天使。</span>
<span className="v" id="v32" data-v="32" data-xref="出埃及記 26:37; 出埃及記 36:38; 以斯帖記 1:6"> 要把這幅幔子掛在四根包金的皂莢木柱上，木柱上有金鉤，木柱立在四個帶凹槽的銀底座上面。</span>
<span className="v" id="v33" data-v="33" data-xref="希伯來書 9:2–3; 利未記 16:2; 出埃及記 40:21"> 要把整幅幔子掛在木柱的金鉤上，把約櫃抬進幔子裡。這幔子把聖幕分為兩個部分，幔子裡面是至聖所，外面是聖所。</span>
<span className="v" id="v34" data-v="34" data-xref="出埃及記 40:20; 出埃及記 25:21; 希伯來書 9:5"> 要把施恩座放在至聖所裡面的約櫃上。</span>
<span className="v" id="v35" data-v="35" data-xref="出埃及記 40:24; 出埃及記 40:22; 希伯來書 9:2"> 桌子要放在幔子的外面、聖幕的北面，燈臺放在南面，跟桌子相對。</span>
<span className="v" id="v36" data-v="36" data-xref="出埃及記 36:37; 民數記 9:15; 出埃及記 26:31"> 要用細麻和藍色、紫色、朱紅色毛線繡製聖幕的門簾。</span>
<span className="v" id="v37" data-v="37" data-xref="出埃及記 36:38"> 要用皂莢木做五根掛門簾的柱子，柱子包上金，上面要有金鉤，並要為柱子鑄造五個帶凹槽的銅底座。</span>
</div>

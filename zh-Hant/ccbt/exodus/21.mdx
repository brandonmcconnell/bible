## 如何對待奴僕

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命記 4:14; 申命記 6:20; 出埃及記 24:3–4"> 「你要向百姓頒佈下列法令。</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 15:12–15; 出埃及記 12:44; 申命記 15:18"> 你若買一個希伯來人當奴僕，他必須服侍你六年，到第七年便可以獲得自由，不用支付任何贖金。</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 15:12–14"> 他來的時候若是單身，就可以單身離開。他來的時候若有妻子，就可以帶妻子一起離開。</span>
<span className="v" id="v4" data-v="4"> 倘若主人給他娶了妻，妻子生了兒女，那麼期滿的時候，他只能單獨離開，他的妻兒要歸主人。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多後書 5:14–15; 申命記 15:16–17; 以賽亞書 26:13"> 倘若奴僕說，『我愛我的主人和我的妻子兒女，我不願意離去做自由人。』</span>
<span className="v" id="v6" data-v="6" data-xref="申命記 15:17; 利未記 25:40; 申命記 19:17–18"> 主人就要帶他到審判官面前，讓他靠著門或門框，用錐子為他穿耳洞。這樣，他就要永遠服侍主人。</span>
<span className="v" id="v7" data-v="7" data-xref="尼希米記 5:5; 出埃及記 21:2–3"> 倘若有人把女兒賣為婢女，她不可像男僕那樣離開。</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 28:8; 申命記 20:7; 瑪拉基書 2:11–15"> 倘若買她的主人本想把她留給自己，後來卻不喜歡她，就必須讓她贖身。主人無權把她轉賣給外族人，因為是主人對她不守信用。</span>
<span className="v" id="v9" data-v="9"> 倘若是買來給自己的兒子，就要把她當作自己的女兒一般看待。</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多前書 7:1–6"> 倘若有人娶了婢女為妻，後來又另娶，他還是要照常供給她飯食和衣服，並履行同房的義務。</span>
<span className="v" id="v11" data-v="11"> 倘若主人不履行以上的三個條件，婢女就可以隨時離開，不用繳付任何贖金。</span>
</div>
</div>

## 如何處理人身傷害

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="創世記 9:6; 馬太福音 26:52; 利未記 24:17"> 「打人致死的，必須被處死。</span>
<span className="v" id="v13" data-v="13" data-xref="約書亞記 20:2–9; 撒母耳記上 24:18; 申命記 4:41–43"> 倘若不是故意殺人，而是上帝許可那人死在他手裡，他就可以逃往我指定的地方。</span>
<span className="v" id="v14" data-v="14" data-xref="列王紀上 2:28–34; 希伯來書 10:26; 民數記 15:30–31"> 倘若是蓄意殺人，就算他逃到我的祭壇那裡，也要把他拉出來處死。</span>
<span className="v" id="v15" data-v="15" data-xref="申命記 21:18–21; 箴言 30:17; 提摩太前書 1:9"> 毆打父母的，必須被處死。</span>
<span className="v" id="v16" data-v="16" data-xref="申命記 24:7; 提摩太前書 1:10; 出埃及記 22:4"> 綁架他人販賣或自用的，必須被處死。</span>
<span className="v" id="v17" data-v="17" data-xref="箴言 20:20; 馬可福音 7:10–11; 申命記 27:16"> 咒罵父母的，必須被處死。</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及記 21:20; 申命記 25:11; 撒母耳記下 14:6"> 倘若吵架時一方用拳頭或石塊致另一方受傷、躺臥在床，但不至於死，</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳記下 3:29; 撒迦利亞書 8:4"> 日後能起床扶著拐杖到戶外走，傷人者便不算有罪，但要賠償受傷者停工期間的損失，並要負責治好他。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="箴言 29:19; 申命記 19:21; 民數記 35:19"> 「倘若有人用棍子打他的僕婢，導致僕婢當場死亡，他必須受懲罰。</span>
<span className="v" id="v21" data-v="21" data-xref="利未記 25:44–46"> 倘若傷者過了一兩天才死去，主人就可免刑，因為死者是他的財產。</span>
<span className="v" id="v22" data-v="22" data-xref="申命記 22:18–19; 出埃及記 21:30; 申命記 16:18"> 倘若有人彼此鬥毆，傷了孕婦，導致早產，但未造成其他傷害，傷人者要按她丈夫所要求的金額，經審判官判定以後，如數賠償。</span>
<span className="v" id="v23" data-v="23" data-xref="申命記 19:21; 民數記 35:31; 利未記 24:19"> 倘若還有其他傷害，傷人者就要以命償命，</span>
<span className="v" id="v24" data-v="24" data-xref="申命記 19:21; 馬太福音 5:38–40; 馬太福音 7:2"> 以眼還眼，以牙還牙，以手還手，以腳還腳，</span>
<span className="v" id="v25" data-v="25"> 以燒傷還燒傷，以創傷還創傷，以毆打還毆打。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="出埃及記 21:20; 約伯記 31:13–15; 詩篇 72:12–14"> 「主人若打壞僕婢的一隻眼睛，就要因此讓僕婢自由離去。</span>
<span className="v" id="v27" data-v="27"> 同樣，倘若他打掉了僕婢的一顆牙齒，也要因此而釋放僕婢。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="出埃及記 21:32; 利未記 20:15–16; 創世記 9:5–6"> 「倘若有牛牴死了人，要用石頭打死那頭牛，並且不可吃牠的肉，牛的主人可算無罪。</span>
<span className="v" id="v29" data-v="29" data-xref="申命記 21:1–9"> 但倘若牛常常用角牴人，並且已經有人向牛的主人投訴，他卻不拴好牛，以致牛牴死了人，就要用石塊打死牛，並處死主人。</span>
<span className="v" id="v30" data-v="30" data-xref="出埃及記 21:22; 出埃及記 30:12; 民數記 35:31–33"> 若判他以錢贖命，不論金額多少，他都得照付。</span>
<span className="v" id="v31" data-v="31"> 牛若牴死了別人的兒女，也要照以上的條例辦理。</span>
<span className="v" id="v32" data-v="32" data-xref="馬太福音 26:15; 撒迦利亞書 11:12–13; 馬太福音 27:3–9"> 牛若牴死了別人的僕婢，牛的主人要賠七兩銀子<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="七兩銀子約是當時一個奴僕的身價。">a</a></sup>給那僕婢的主人，並要用石頭打死牛。</span>
<span className="v" id="v33" data-v="33" data-xref="箴言 28:10; 耶利米書 18:20; 傳道書 10:8"> 倘若有人打開井蓋或挖了井後不把井口蓋好，以致有牛或驢掉進井裡，</span>
<span className="v" id="v34" data-v="34" data-xref="出埃及記 22:6; 出埃及記 21:29–30; 出埃及記 22:14"> 井的主人就要賠償牲畜的主人，死牲畜則歸井的主人。</span>
<span className="v" id="v35" data-v="35"> 倘若某人的牛牴死了別人的牛，兩家的主人就要賣掉活牛，平分所得，同時也要平分那頭死掉的牛。</span>
<span className="v" id="v36" data-v="36"> 倘若素知牛好牴，主人卻沒有拴好牠，他就要以牛還牛，死牛則歸他。</span>
</div>
</div>

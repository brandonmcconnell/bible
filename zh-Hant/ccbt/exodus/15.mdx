## 摩西頌讚耶和華

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="啟示錄 15:3; 出埃及記 15:21; 詩篇 106:12"> 那時，摩西和以色列人便歌頌耶和華，說：<br /><span className="pl pl-1">「我要歌頌耶和華，</span><br /><span className="pl pl-1">因祂大獲全勝，</span><br /><span className="pl pl-1">祂把戰馬和騎兵都拋進海中。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="以賽亞書 12:2; 詩篇 118:14; 詩篇 18:46"> <span className="pl pl-1">耶和華是我的力量，我的詩歌，</span><br /><span className="pl pl-1">也成了我的拯救；</span><br /><span className="pl pl-1">祂是我的上帝，我要讚美祂；</span><br /><span className="pl pl-1">祂是我父親的上帝，我要尊崇祂。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 24:8; 出埃及記 14:14; 啟示錄 19:11–21"> <span className="pl pl-1">耶和華是戰士，</span><br /><span className="pl pl-1">祂名叫耶和華。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="出埃及記 14:13–28; 出埃及記 14:6–7"> <span className="pl pl-1">祂把法老的戰車軍兵都拋進海中，</span><br /><span className="pl pl-1">法老的強將都葬身於紅海，</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="尼希米記 9:11; 出埃及記 15:10; 出埃及記 14:28"> <span className="pl pl-1">大水淹沒他們，</span><br /><span className="pl pl-1">他們如同石塊沉入深海。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 118:15–16; 以賽亞書 51:9; 啟示錄 2:27"> <span className="pl pl-1">耶和華啊，你的右手用大能彰顯威榮；</span><br /><span className="pl pl-1">耶和華啊，你的右手擊碎仇敵。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="以賽亞書 5:24; 以賽亞書 47:14; 瑪拉基書 4:1"> <span className="pl pl-1">你大顯威嚴，擊倒那些起來對抗你的人；</span><br /><span className="pl pl-1">你大發雷霆，他們便像枯草遇火，</span><br /><span className="pl pl-1">一燒而盡。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="約伯記 4:9; 詩篇 78:13; 出埃及記 14:21–22"> <span className="pl pl-1">你的鼻孔一呼氣，海水便堆聚起來，</span><br /><span className="pl pl-1">洪濤便堆起水牆，海底深處也都凝固。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="士師記 5:30; 出埃及記 14:5; 以賽亞書 53:12"> <span className="pl pl-1">敵人說，『追啊，追上他們，</span><br /><span className="pl pl-1">瓜分他們的財物，盡情擄掠他們，</span><br /><span className="pl pl-1">拔出刀來把他們斬盡殺絕。』</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="出埃及記 14:21; 申命記 11:4; 出埃及記 15:5"> <span className="pl pl-1">你叫風一吹，海水就淹沒他們，</span><br /><span className="pl pl-1">他們好像鉛塊一樣沉沒在怒海中。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="列王紀上 8:23; 詩篇 89:5–8; 撒母耳記上 2:2"> <span className="pl pl-1">耶和華啊，萬神之中，誰能像你？</span><br /><span className="pl pl-1">誰能像你——威嚴神聖，</span><br /><span className="pl pl-1">可頌可畏，廣行神蹟？</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="出埃及記 15:6"> <span className="pl pl-1">你伸出右手，大地便吞滅他們。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 77:20; 彼得前書 1:5; 詩篇 77:14–15"> <span className="pl pl-1">你以不變的愛引領你所救贖的子民，</span><br /><span className="pl pl-1">以大能帶他們進入你的聖所。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="申命記 2:25; 約書亞記 2:9–10; 詩篇 48:6"> <span className="pl pl-1">各邦聽見這些事就發抖，</span><br /><span className="pl pl-1">非利士人痛苦不堪，</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="約書亞記 5:1; 約書亞記 2:11; 約書亞記 2:9"> <span className="pl pl-1">以東的族長惶恐不安，</span><br /><span className="pl pl-1">摩押的英雄瑟瑟發抖，</span><br /><span className="pl pl-1">迦南的居民膽戰心驚。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="申命記 2:25; 詩篇 74:2; 約書亞記 2:9"> <span className="pl pl-1">驚駭恐懼籠罩著他們。</span><br /><span className="pl pl-1">耶和華啊，</span><br /><span className="pl pl-1">你臂膀的大能嚇得他們僵立如石，</span><br /><span className="pl pl-1">直到你的子民都安然走過，</span><br /><span className="pl pl-1">直到你買贖的子民都安然走過。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="詩篇 44:2; 詩篇 80:8; 詩篇 78:54–55"> <span className="pl pl-1">耶和華啊，</span><br /><span className="pl pl-1">你要帶領他們到你產業的山上安居，</span><br /><span className="pl pl-1">到你為自己所造的住處，</span><br /><span className="pl pl-1">主啊，到你親手建的聖所。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v18" data-v="18" data-xref="詩篇 10:16; 詩篇 29:10; 詩篇 146:10"> <span className="pl pl-1">「耶和華必做王，直到永永遠遠。」</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="出埃及記 14:28–29; 出埃及記 14:22–23; 希伯來書 11:29"> 法老的軍兵車馬追到海中，耶和華使海水回流淹沒他們，以色列人卻踏著乾地走在海中。</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 150:4; 撒母耳記上 18:6; 詩篇 68:25"> 亞倫的姐姐米利暗先知手拿小鼓，帶領眾婦女擊鼓跳舞，</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及記 15:1; 啟示錄 15:3; 啟示錄 7:10–12"> 唱和道：「要歌頌耶和華，因祂大獲全勝，祂把戰馬和騎兵都拋進海中。」</span>
</div>

## 苦水

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="創世記 16:7; 撒母耳記上 15:7; 創世記 25:18"> 摩西帶領以色列人離開紅海，來到書珥曠野，走了三天仍然找不到水喝。</span>
<span className="v" id="v23" data-v="23" data-xref="路得記 1:20; 民數記 33:8"> 到了瑪拉，那裡的水卻是苦的，不能喝。因此那地方叫瑪拉<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「瑪拉」意思是「苦」。">a</a></sup>。</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及記 16:2; 出埃及記 14:11; 民數記 20:2–5"> 百姓就埋怨摩西說：「我們喝什麼呢？」</span>
<span className="v" id="v25" data-v="25" data-xref="申命記 8:2; 詩篇 66:10; 士師記 3:1"> 摩西向耶和華呼求，耶和華就指示他一棵樹，他把樹扔在水中，水就變甘甜了。耶和華又在瑪拉給百姓定下律例和法令，並在那裡試驗他們，</span>
<span className="v" id="v26" data-v="26" data-xref="詩篇 103:3; 申命記 7:15; 出埃及記 23:25"> 說：「你們若留心聽你們上帝耶和華的話，做我視為正的事，聽從我的命令，遵守我的一切律例，我就不把降在埃及的疾病加在你們身上，因為我是醫治你們的耶和華。」</span>
<span className="v" id="v27" data-v="27" data-xref="啟示錄 22:2; 啟示錄 7:17; 民數記 33:9"> 到了以琳，那裡有十二股水泉和七十棵棕樹，他們就在水邊安營。</span>
</div>

## 造香壇的條例

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="啟示錄 8:3; 出埃及記 37:25–28; 出埃及記 40:5"> 「你要用皂莢木造一座燒香用的壇。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 27:2"> 壇是四方形的，長寬各四十五釐米，高九十釐米，壇上面凸起的四角與壇連成一體。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 25:11; 出埃及記 25:24"> 壇頂、壇的四面和壇上凸起的角要包上純金，四周鑲上金邊。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及記 25:27; 出埃及記 26:29; 出埃及記 27:7"> 要在壇兩側的金邊下面安兩個金環，使橫槓穿過金環，以便抬香壇。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 25:13; 出埃及記 25:27"> 要用皂莢木造橫槓，包上金。</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及記 25:21–22; 出埃及記 30:36; 利未記 16:13"> 要把香壇放在約櫃前幔子的外面，對著約櫃上的施恩座，就是我要跟你會面的地方。</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳記上 2:28; 歷代志上 23:13; 出埃及記 27:20–21"> 「亞倫每天早上料理燈臺的時候，要在這壇上燒芬芳的香。</span>
<span className="v" id="v8" data-v="8" data-xref="希伯來書 9:24; 帖撒羅尼迦前書 5:17; 希伯來書 7:25"> 黃昏點燈的時候，他也要在耶和華面前燒香，世世代代都要如此。</span>
<span className="v" id="v9" data-v="9" data-xref="利未記 10:1"> 不可在這香壇上燒別的香料，不可用這壇來獻燔祭或素祭，也不可在上面澆奠祭。</span>
<span className="v" id="v10" data-v="10" data-xref="利未記 16:18; 希伯來書 9:22–23; 利未記 16:29–30"> 亞倫每年要用贖罪祭牲的血在壇的角上行一次贖罪禮，世代如此。這是耶和華至聖的壇。」</span>
</div>
</div>

## 人丁的贖價

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11"> 耶和華對摩西說：</span>
<span className="v" id="v12" data-v="12" data-xref="民數記 31:50; 歷代志上 27:24; 出埃及記 38:25–26"> 「你統計以色列人口的時候，每一個被統計的男子都要繳付贖價給耶和華，贖回自己的性命，免得在統計人口期間發生災禍。</span>
<span className="v" id="v13" data-v="13" data-xref="利未記 27:25; 民數記 3:47; 以西結書 45:12"> 凡被統計的人都要付六克銀子，即十季拉，以聖所的秤為準，作為獻給耶和華的禮物。</span>
<span className="v" id="v14" data-v="14" data-xref="民數記 1:20; 民數記 1:18; 民數記 1:3"> 凡被統計的，年齡在二十歲以上的男子都要獻此禮物給耶和華。</span>
<span className="v" id="v15" data-v="15" data-xref="民數記 31:50; 利未記 17:11; 出埃及記 30:12"> 富有的不用多繳，貧窮的也不可少付，每個人都要獻六克銀子給耶和華，用來贖自己的性命。</span>
<span className="v" id="v16" data-v="16" data-xref="尼希米記 10:32–33; 民數記 16:40; 出埃及記 38:25–31"> 要向以色列人收贖命的款項，供會幕使用，可以使以色列人在耶和華面前蒙眷顧，贖性命。」</span>
</div>
</div>

## 洗濯盆

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17"> 耶和華對摩西說：</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及記 40:7; 出埃及記 38:8; 列王紀上 7:23"> 「你用銅造一個洗濯盆和盆座，放在會幕和祭壇之間，盆裡盛著水，</span>
<span className="v" id="v19" data-v="19" data-xref="以賽亞書 52:11; 出埃及記 40:31–32; 詩篇 26:6"> 供亞倫父子們洗手洗腳，</span>
<span className="v" id="v20" data-v="20" data-xref="利未記 10:1–3; 希伯來書 12:28–29; 歷代志上 13:10"> 他們進會幕或到壇前給耶和華獻火祭之前，一定要用水洗濯才可以供職，免得死亡。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及記 28:43; 出埃及記 27:21"> 他們要洗手洗腳，免得死亡，這是亞倫及其子孫世代當守的永久律例。」</span>
<span className="v" id="v22" data-v="22"> 耶和華對摩西說：</span>
<span className="v" id="v23" data-v="23" data-xref="以西結書 27:19; 雅歌 4:14; 以西結書 27:22"> 「要用上等的香料，就是沒藥汁六公斤、香肉桂和菖蒲各三公斤、</span>
<span className="v" id="v24" data-v="24" data-xref="詩篇 45:8; 出埃及記 29:40; 民數記 3:47"> 肉桂皮六公斤，都按聖所的秤為準，再加上橄欖油四升，</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及記 37:29; 歷代志上 9:30; 出埃及記 40:9"> 按著調製香料的方法製作聖膏油。</span>
<span className="v" id="v26" data-v="26" data-xref="民數記 7:1; 約翰一書 2:20; 以賽亞書 61:1"> 要用這些膏油來抹會幕、約櫃、</span>
<span className="v" id="v27" data-v="27"> 桌子和桌上所有的器具、燈臺和燈臺上的器具、香壇、</span>
<span className="v" id="v28" data-v="28"> 燔祭壇和壇上所有的器具、洗濯盆和盆座。</span>
<span className="v" id="v29" data-v="29" data-xref="馬太福音 23:19; 出埃及記 29:37; 利未記 6:18"> 你要使這一切聖潔，成為至聖之物。凡碰到它們的都會聖潔。</span>
<span className="v" id="v30" data-v="30" data-xref="利未記 8:12; 出埃及記 28:3; 利未記 8:30"> 「你也要用這油來膏亞倫父子們，使他們分別出來，做聖潔的祭司事奉我。</span>
<span className="v" id="v31" data-v="31" data-xref="出埃及記 37:29; 利未記 21:10; 詩篇 89:20"> 你要把我的話告訴以色列百姓，『我要世世代代以這油為聖膏油。</span>
<span className="v" id="v32" data-v="32" data-xref="出埃及記 30:25; 出埃及記 30:37–38; 利未記 21:10"> 不要把這膏油用在普通人身上，也不可仿製，因為這是聖膏油，你們也要視之為聖物。</span>
<span className="v" id="v33" data-v="33" data-xref="出埃及記 30:38; 創世記 17:14; 出埃及記 12:15"> 任何人若仿製或用這油抹祭司以外的人，要將他從民中剷除。』」</span>
<span className="v" id="v34" data-v="34" data-xref="出埃及記 37:29; 出埃及記 25:6; 出埃及記 30:23"> 耶和華對摩西說：「要取各種芬芳的香料，就是蘇合香、香螺、白松香和純乳香，分量相同，</span>
<span className="v" id="v35" data-v="35" data-xref="利未記 2:13; 出埃及記 30:25; 約翰福音 12:3"> 用調製香料的方法調製，加上鹽，做成純淨聖潔的香。</span>
<span className="v" id="v36" data-v="36" data-xref="出埃及記 25:22; 出埃及記 30:6; 出埃及記 16:34"> 你們要把一些香搗成極細的粉末，放在會幕內的約櫃前面，就是我與你會面的地方，你們要視這香為至聖之物。</span>
<span className="v" id="v37" data-v="37" data-xref="利未記 2:3; 出埃及記 29:37; 出埃及記 30:32–33"> 你們不可用同樣的配方為自己做香，要視它為耶和華的聖物。</span>
<span className="v" id="v38" data-v="38" data-xref="出埃及記 30:33"> 任何人若仿製這香，自己拿來私用<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「私用」希伯來文是「聞這香味」。">a</a></sup>，必從民中被剷除。」</span>
</div>
</div>

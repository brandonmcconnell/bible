## 奉獻的條例

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華對摩西說：</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多後書 9:7; 尼希米記 11:2; 以斯拉記 2:68"> 「你去吩咐以色列百姓要獻禮物給我。你們要為我收下所有甘心樂意獻上的禮物。</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 8:9; 約伯記 28:2"> 你們要收的禮物是金、銀、銅，</span>
<span className="v" id="v4" data-v="4" data-xref="啟示錄 19:8; 創世記 41:42; 以西結書 16:10"> 藍色、紫色和朱紅色毛線，細麻，山羊毛，</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 26:37–1; 出埃及記 26:14–15; 出埃及記 36:20"> 染成紅色的公羊皮，海狗皮，皂莢木，</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及記 27:20; 出埃及記 25:37; 出埃及記 40:24–25"> 燈油，製作膏油和香的香料，</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及記 28:4; 出埃及記 28:6–30"> 鑲嵌在以弗得和胸牌上的紅瑪瑙及其他寶石。</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多後書 6:16; 列王紀上 6:13; 啟示錄 21:3"> 他們要為我造一座聖所，我好住在他們中間。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及記 25:40; 希伯來書 8:5; 使徒行傳 7:44"> 你們要完全照我指示的樣式造聖幕和裡面的各樣器具。</span>
</div>
</div>

## 造約櫃的條例

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="希伯來書 9:4; 出埃及記 37:1–3; 申命記 10:1–3"> 「要用皂莢木做一個櫃，長一米一，寬七十釐米，高七十釐米，</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及記 25:24; 出埃及記 30:3; 歷代志下 3:4"> 裡外都要包上純金，要用金子鑲櫃邊。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及記 27:7; 出埃及記 25:26; 出埃及記 25:15"> 再鑄造四個金環，安在櫃的四個腳上，每邊兩個環。</span>
<span className="v" id="v13" data-v="13" data-xref="歷代志上 15:15; 民數記 4:11; 出埃及記 27:6"> 用皂莢木造兩根橫槓，包上金，</span>
<span className="v" id="v14" data-v="14"> 然後把橫槓穿過櫃兩邊的金環，便於抬櫃。</span>
<span className="v" id="v15" data-v="15" data-xref="列王紀上 8:8; 歷代志下 5:9"> 橫槓穿進櫃環以後，不可再抽出來。</span>
<span className="v" id="v16" data-v="16" data-xref="申命記 31:26; 列王紀上 8:9; 希伯來書 9:4"> 把我將要賜給你的兩塊約版放在櫃裡。</span>
<span className="v" id="v17" data-v="17" data-xref="希伯來書 9:5; 出埃及記 37:6; 希伯來書 4:16"> 要用純金造一個施恩<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「施恩」或譯「贖罪」。">a</a></sup>座，長一米一，寬七十釐米。</span>
<span className="v" id="v18" data-v="18" data-xref="以西結書 10:20; 希伯來書 9:5; 列王紀上 8:6–7"> 用金子在施恩座的兩端打造兩個基路伯天使，</span>
<span className="v" id="v19" data-v="19"> 跟施恩座連在一起，一端一個。</span>
<span className="v" id="v20" data-v="20" data-xref="歷代志上 28:18; 列王紀上 8:7; 希伯來書 9:5"> 兩個基路伯天使要面對面朝向施恩座，向上展開翅膀，遮蓋施恩座。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及記 26:34; 羅馬書 10:4; 出埃及記 25:16–17"> 要把施恩座放在櫃上面，把我要賜給你的約版放在櫃裡。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及記 29:42–43; 民數記 7:89; 以賽亞書 37:16"> 我就在那裡跟你會面，從約櫃上面兩個基路伯天使中間的施恩座上，把要傳給以色列百姓的一切誡命告訴你。</span>
</div>
</div>

## 造供桌的條例

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="希伯來書 9:2; 出埃及記 37:10–16; 列王紀上 7:48"> 「要用皂莢木造一張桌子，長九十釐米，寬四十五釐米，高七十釐米。</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及記 25:11; 列王紀上 6:20–22"> 整張桌子都要包上純金，四周鑲上金邊，</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及記 37:2; 出埃及記 30:3"> 在桌子四周造一個八釐米寬的外框，外框鑲上金邊。</span>
<span className="v" id="v26" data-v="26"> 要造四個金環，安在桌子四角的桌腿上，</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及記 25:14; 出埃及記 25:28"> 金環要靠近外框，以便穿橫槓抬桌子。</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及記 25:14; 使徒行傳 9:15; 民數記 10:17"> 兩根橫槓要用皂莢木製作，外面包金，用來抬桌子。</span>
<span className="v" id="v29" data-v="29" data-xref="民數記 4:7; 出埃及記 37:16; 啟示錄 3:20"> 你們要用純金造桌子上的盤、碟和獻酒用的瓶和杯。</span>
<span className="v" id="v30" data-v="30" data-xref="利未記 24:5–9; 馬太福音 12:4; 出埃及記 39:36"> 桌子上要一直擺著供餅，獻在我面前。</span>
</div>
</div>

## 造燈臺的條例

<div className="bt">
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="列王紀上 7:49; 撒迦利亞書 4:2; 出埃及記 37:17–24"> 「要用純金造一個燈臺，燈臺的燈座、燈柱、油杯、花萼和花瓣要用一塊純金打造。</span>
<span className="v" id="v32" data-v="32"> 燈臺兩邊要各伸出三個分枝，共六個分枝。</span>
<span className="v" id="v33" data-v="33" data-xref="民數記 17:4–8; 耶利米書 1:11–12; 撒迦利亞書 4:3"> 每個分枝上要有三個杏花形狀、有花瓣和花萼的杯，六個分枝都是這樣。</span>
<span className="v" id="v34" data-v="34"> 燈臺上要有四個杏花形狀、有花瓣和花萼的杯。</span>
<span className="v" id="v35" data-v="35"> 燈臺上每一對分枝的相連處要有花萼，三對都是這樣。</span>
<span className="v" id="v36" data-v="36" data-xref="出埃及記 25:18; 列王紀上 10:16–17; 歷代志下 9:15"> 整座燈臺，包括花萼和分枝，都要用一塊純金打造。</span>
<span className="v" id="v37" data-v="37" data-xref="民數記 8:2; 啟示錄 1:20–1; 利未記 24:2–4"> 此外，要為燈臺造七個燈盞，放在燈臺上面，照亮前面的地方。</span>
<span className="v" id="v38" data-v="38" data-xref="列王紀下 12:13; 耶利米書 52:18; 列王紀下 25:14"> 燈臺用的燈剪和燈花盤都要用純金造。</span>
<span className="v" id="v39" data-v="39"> 造整座燈臺和燈臺的器具要用六百八十兩純金。</span>
<span className="v" id="v40" data-v="40" data-xref="希伯來書 8:5; 出埃及記 26:30; 使徒行傳 7:44"> 你務要照著在山上指示你的樣式造各樣器具。</span>
</div>
</div>

## 蛙災

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及記 3:18; 出埃及記 3:12; 出埃及記 5:1"> 耶和華對摩西說：「你去告訴法老，『耶和華說，放我的子民離開，他們好事奉我。</span>
<span className="v" id="v2" data-v="2" data-xref="詩篇 78:45; 出埃及記 9:2; 出埃及記 7:14"> 如果你不肯讓他們去，我就使青蛙來毀壞你的全境。</span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 105:30; 出埃及記 12:34"> 尼羅河將充滿青蛙，牠們要跳到你的宮裡、臥室和床鋪上，跳到你的臣僕和百姓家裡，跳到你的爐灶和揉麵盆裡。</span>
<span className="v" id="v4" data-v="4" data-xref="以賽亞書 19:11; 但以理書 4:37; 使徒行傳 12:22–23"> 青蛙還會跳到你和你的百姓及眾臣僕身上。』」</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 7:19"> 耶和華對摩西說：「你叫亞倫向埃及各地的江河、溪流和池塘伸杖，使青蛙遍佈埃及。」</span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 105:30; 詩篇 78:45; 啟示錄 16:13"> 亞倫就向水伸杖，青蛙就遍佈了埃及全境。</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及記 7:11; 出埃及記 7:22; 申命記 13:1–3"> 巫師也行邪術如法炮製，使青蛙遍佈埃及。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及記 10:17; 出埃及記 9:28; 出埃及記 8:25–28"> 法老召摩西和亞倫進宮，對他們說：「你們要祈求耶和華，使這些青蛙離開我和我的百姓，我便讓你們的百姓去獻祭給耶和華。」</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀上 18:25; 以賽亞書 10:15; 士師記 7:2"> 摩西對法老說：「好吧，你要我在什麼時候為你以及你的臣僕和百姓禱告，叫這些青蛙離開你和你的宮殿，只留在河裡呢？」</span>
<span className="v" id="v10" data-v="10" data-xref="以賽亞書 46:9; 詩篇 86:8; 歷代志上 17:20"> 法老說：「明天。」摩西說：「就照你說的，這樣你就知道我們的上帝耶和華獨一無二。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及記 8:3; 出埃及記 8:9"> 青蛙會離開你、你的宮殿、你的臣僕和百姓，只留在河裡。」</span>
<span className="v" id="v12" data-v="12" data-xref="雅各書 5:16–18; 出埃及記 8:30; 出埃及記 10:18"> 摩西和亞倫離開法老後，摩西就為法老所受的蛙災一事向耶和華呼求。</span>
<span className="v" id="v13" data-v="13" data-xref="申命記 34:10–12"> 耶和華答應了摩西的祈求。在房屋內、院子裡和田野中的青蛙都死了。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及記 8:24; 出埃及記 7:21; 約珥書 2:20"> 百姓把青蛙的屍體堆積起來，埃及全境都充滿了死青蛙的腐臭氣味。</span>
<span className="v" id="v15" data-v="15" data-xref="以賽亞書 26:10; 傳道書 8:11; 希伯來書 3:8"> 法老看見災難緩解，便又硬著心，不肯聽從摩西和亞倫的話，正如耶和華所言。</span>
</div>
</div>

## 蝨災

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="出埃及記 8:5; 出埃及記 8:17"> 耶和華對摩西說：「你吩咐亞倫伸出他的杖擊打地上的塵土，使埃及境內的塵土變成蝨子。」</span>
<span className="v" id="v17" data-v="17" data-xref="詩篇 105:31; 以賽亞書 23:9; 使徒行傳 12:23"> 他們就照上帝的吩咐去做，亞倫伸杖擊打地上的塵土，蝨子就跑到人和牲畜身上，全埃及的塵土都變成了蝨子。</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及記 7:11; 出埃及記 9:11; 但以理書 5:8"> 巫師們也試圖用邪術變出蝨子來，卻無法成功。埃及的百姓和牲畜身上長滿了蝨子。</span>
<span className="v" id="v19" data-v="19" data-xref="路加福音 11:20; 詩篇 8:3; 出埃及記 7:5"> 巫師們對法老說：「這是上帝的作為。」法老仍然硬著心，不肯答應摩西和亞倫的要求，正如耶和華所言。</span>
</div>
</div>

## 蒼蠅之災

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="出埃及記 7:15; 出埃及記 9:13; 出埃及記 8:1"> 耶和華對摩西說：「明天清早，你趁法老去河邊時去見他，告訴他，『耶和華說，放我的子民走，他們好事奉我，</span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 78:45; 以賽亞書 7:18; 詩篇 105:31"> 不然我就叫成群的蒼蠅飛到你、你的臣僕和百姓身上，進到你們各自的家中，使埃及遍地佈滿蒼蠅。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及記 9:4; 瑪拉基書 3:18; 出埃及記 10:23"> 但那天，我必把我子民居住的歌珊分別出來，那裡必沒有成群的蒼蠅，這樣你就知道我耶和華主宰天下。</span>
<span className="v" id="v23" data-v="23"> 我要把我的子民跟你的百姓分開，明天我必行這神蹟。』」</span>
<span className="v" id="v24" data-v="24" data-xref="詩篇 105:31; 詩篇 78:45; 出埃及記 8:21"> 耶和華果然這樣行。密密麻麻的蒼蠅飛進法老的王宮和他臣僕的家裡，埃及全國都受到蒼蠅的毀壞。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及記 8:8; 出埃及記 9:27; 出埃及記 10:16"> 法老召見摩西和亞倫，對他們說：「去吧，就在此地給你們的上帝獻祭吧。」</span>
<span className="v" id="v26" data-v="26" data-xref="創世記 43:32; 創世記 46:34; 申命記 7:25–26"> 摩西說：「這怎麼行？我們獻給我們的上帝耶和華的祭物會令埃及人厭惡。如果我們在埃及人面前獻令他們厭惡的祭物，他們豈不會拿石頭打死我們？</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及記 3:18; 出埃及記 3:12; 出埃及記 34:11"> 我們要照我們上帝耶和華的吩咐離開這裡，走三天的路程到曠野去獻祭給祂。」</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及記 8:8; 出埃及記 9:28; 列王紀上 13:6"> 法老說：「我讓你們去曠野獻祭給你們的上帝耶和華，只是不要走得太遠。你們要為我祈求。」</span>
<span className="v" id="v29" data-v="29" data-xref="出埃及記 8:15; 耶利米書 42:20–21; 出埃及記 8:8"> 摩西說：「我離開這裡就去祈求耶和華，使成群的蒼蠅明天就離開你及你的臣僕和百姓，但這次你不可再食言，阻止以色列人去向耶和華獻祭。」</span>
<span className="v" id="v30" data-v="30" data-xref="出埃及記 8:12; 出埃及記 9:33; 雅各書 5:16"> 摩西說完以後，便離開王宮，去祈求耶和華。</span>
<span className="v" id="v31" data-v="31"> 耶和華就照摩西的祈求，使成群的蒼蠅離開法老及其臣僕和百姓，一隻也沒有留下。</span>
<span className="v" id="v32" data-v="32" data-xref="出埃及記 8:15; 出埃及記 4:21; 羅馬書 2:5"> 這一次，法老又硬著心，不肯讓百姓離開埃及。</span>
</div>
</div>

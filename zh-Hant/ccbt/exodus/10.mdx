## 蝗蟲之災

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及記 4:21; 出埃及記 7:13–14; 出埃及記 3:20"> 耶和華對摩西說：「你去見法老，我已使他和他臣僕的心剛硬，好在他們當中行我這些神蹟。</span>
<span className="v" id="v2" data-v="2" data-xref="約珥書 1:3; 申命記 4:9; 申命記 6:20–22"> 這樣，你就可以把我如何嚴懲埃及人以及我在他們當中所行的神蹟告訴你的子孫，好叫你們知道我是耶和華。」</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="彼得前書 5:6; 列王紀上 21:29; 雅各書 4:10"> 摩西和亞倫便去見法老，對他說：「希伯來人的上帝耶和華說，『你要到什麼時候才肯在我面前謙卑下來？放我的子民走，他們好事奉我。</span>
<span className="v" id="v4" data-v="4" data-xref="啟示錄 9:3; 約珥書 2:25; 出埃及記 11:4–5"> 你若再不答應，明天我要使蝗蟲飛入你的國境。</span>
<span className="v" id="v5" data-v="5" data-xref="約珥書 1:4; 出埃及記 9:32; 約珥書 2:25"> 牠們鋪天蓋地，要吃光冰雹過後田間所剩的，包括一切樹木。</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及記 8:21; 出埃及記 8:3; 出埃及記 11:6"> 你的王宮及臣僕和所有埃及人的房屋都要佈滿蝗蟲，這是你祖祖輩輩從未見過的蝗災。』」摩西說完，便轉身離開法老。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="撒母耳記上 18:21; 出埃及記 23:33; 約書亞記 23:13"> 臣僕對法老說：「這個人害我們要到什麼時候呢？讓他們離開去事奉他們的上帝耶和華吧！埃及快被毀滅了，你不知道嗎？」</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及記 10:24; 出埃及記 12:31; 出埃及記 8:8"> 法老便召回摩西和亞倫，對他們說：「你們去事奉你們的上帝耶和華吧！但你們誰要去呢？」</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及記 5:1; 哥林多前書 5:7–8; 申命記 31:12–13"> 摩西回答說：「我們男女老幼都要去，還有我們的牛群和羊群，因為我們要去守耶和華的節期。」</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及記 13:21; 歷代志下 32:15; 出埃及記 12:30–31"> 法老聽後，說：「我若讓你們帶走婦女和孩子，最好耶和華能保護你們！你們真是居心叵測。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及記 10:28; 詩篇 119:69; 出埃及記 5:4"> 不行！只有男子可以去事奉耶和華，這是你們一直要求的。」法老說完，便下令把他們趕出去。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="出埃及記 7:19; 出埃及記 10:4–5"> 耶和華對摩西說：「你向埃及伸杖，使蝗蟲飛來吃盡冰雹過後田野剩下的一切植物。」</span>
<span className="v" id="v13" data-v="13" data-xref="約拿書 1:4; 詩篇 78:26; 詩篇 148:8"> 摩西就向埃及伸杖。耶和華使東風在埃及境內颳了整整一天一夜，到早晨，東風帶來了蝗蟲。</span>
<span className="v" id="v14" data-v="14" data-xref="詩篇 78:46; 約珥書 1:2–4; 詩篇 105:34–35"> 埃及到處都佈滿了蝗蟲，數目之多實在是空前絕後。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及記 10:5; 詩篇 78:46; 約珥書 1:6–7"> 蝗蟲遍佈整個埃及，地上一片黑暗。這些蝗蟲吃盡了冰雹過後剩下的農作物和樹上的果子，沒有留下一點青綠。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 9:27; 撒母耳記下 19:20; 撒母耳記上 15:30"> 法老急忙召見摩西和亞倫，對他們說：「我得罪了你們的上帝耶和華，又得罪了你們。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及記 8:8; 出埃及記 9:28; 列王紀上 13:6"> 現在求你饒恕我的罪，就這一次，為我祈求你們的上帝耶和華撤去這場死亡之災吧！」</span>
<span className="v" id="v18" data-v="18" data-xref="路加福音 6:28; 出埃及記 8:28–30; 出埃及記 8:9"> 摩西就離開法老出去祈求耶和華，</span>
<span className="v" id="v19" data-v="19" data-xref="約珥書 2:20; 出埃及記 13:18; 出埃及記 15:4"> 耶和華就把風向倒轉，變成猛烈的西風，把蝗蟲颳走，吹進紅海。埃及境內一隻蝗蟲也沒留下。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及記 4:21; 出埃及記 11:10; 申命記 2:30"> 可是，耶和華又使法老心硬，他不讓以色列人離開埃及。</span>
</div>
</div>

## 黑暗之災

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="啟示錄 16:10–11; 猶大書 1:6; 路加福音 23:44"> 耶和華對摩西說：「你向天伸杖，使埃及全境漆黑一片，那黑暗濃得甚至可以摸到。」</span>
<span className="v" id="v22" data-v="22" data-xref="詩篇 105:28; 啟示錄 16:10; 出埃及記 20:21"> 摩西向天伸杖，埃及全境便漆黑了三天之久。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及記 8:22; 以賽亞書 42:16; 彼得前書 2:9"> 埃及人彼此看不見，誰也不敢移動半步。可是，以色列人住的地方卻有光。</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及記 10:8–10; 出埃及記 8:28; 創世記 34:23"> 法老把摩西召來，對他說：「去事奉耶和華吧，你們的婦女和孩子也可以去，但你們要把牛羊留下。」</span>
<span className="v" id="v25" data-v="25" data-xref="利未記 9:22; 利未記 16:9; 出埃及記 29:1–46"> 摩西回答說：「你得允許我們有祭物和燔祭牲獻給我們的上帝耶和華。</span>
<span className="v" id="v26" data-v="26" data-xref="以賽亞書 23:18; 使徒行傳 2:44–45; 箴言 3:9"> 我們要帶走所有的牲畜，一隻蹄子也不留下，因為我們要從其中選一些來獻給我們的上帝耶和華。我們抵達目的地前，還不知道把哪些獻給祂。」</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及記 10:20; 出埃及記 4:21; 出埃及記 14:8"> 但耶和華使法老的心剛硬，他不肯讓以色列百姓離開。</span>
<span className="v" id="v28" data-v="28" data-xref="歷代志下 25:16; 歷代志下 16:10; 阿摩司書 7:13"> 法老對摩西說：「給我退下！不要再讓我見到你，因為你再見我面之日必死。」</span>
<span className="v" id="v29" data-v="29" data-xref="希伯來書 11:27; 出埃及記 12:30–31; 出埃及記 11:4–8"> 摩西回答說：「你說得好，我必不再見你的面。」</span>
</div>
</div>

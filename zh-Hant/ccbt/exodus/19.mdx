## 以色列人在西奈山

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及記 16:1; 出埃及記 12:6; 利未記 23:16–18"> 以色列人離開埃及滿三個月的那一天，他們來到西奈曠野。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 3:1; 出埃及記 17:1; 出埃及記 3:12"> 他們離開利非訂，來到西奈曠野，在那裡的山下安營。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="出埃及記 3:4; 使徒行傳 7:38; 出埃及記 20:21"> 摩西上山到上帝那裡，耶和華從山上呼喚他說：「你告訴雅各家，告訴以色列人，</span>
<span className="v" id="v4" data-v="4" data-xref="申命記 32:11–12; 以賽亞書 63:9; 以賽亞書 40:31"> 『我怎樣對付埃及人，怎樣像鷹一樣把你們背在翅膀上帶來歸屬我，你們都看見了。</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 14:2; 申命記 7:6; 申命記 26:18"> 現在，你們若真心聽從我的話，遵守我的約，就必在萬民中做我寶貴的產業，因為普天下都是我的。</span>
<span className="v" id="v6" data-v="6" data-xref="啟示錄 5:10; 彼得前書 2:9; 彼得前書 2:5"> 你們要歸於我，作祭司之國、聖潔之邦。這些話你要告訴以色列人。』」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="出埃及記 4:29–30; 出埃及記 3:16; 哥林多前書 15:1"> 摩西召集以色列的長老，把耶和華對他的一切吩咐都轉告他們。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及記 24:7; 出埃及記 24:3; 約書亞記 24:24"> 百姓都齊聲回答說：「凡耶和華所吩咐的，我們都願意遵從。」<br />摩西便把他們的話回報耶和華。</span>
<span className="v" id="v9" data-v="9" data-xref="申命記 4:36; 出埃及記 19:16; 出埃及記 24:15–16"> 耶和華對摩西說：「我會在密雲中臨到你那裡，使百姓也可以親耳聽見我與你說話的聲音，這樣他們就會永遠信賴你。」摩西把以色列人的話回報耶和華。</span>
<span className="v" id="v10" data-v="10" data-xref="希伯來書 10:22; 創世記 35:2; 利未記 11:44–45"> 耶和華對摩西說：「你現在回到他們那裡，吩咐他們今天和明天要潔淨自己，洗淨衣服，</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及記 19:16; 出埃及記 34:5; 申命記 33:2"> 到後天都要預備好，因為這一天耶和華要在百姓眼前降臨在西奈山上。</span>
<span className="v" id="v12" data-v="12" data-xref="希伯來書 12:20–21; 約書亞記 3:4; 出埃及記 19:21"> 此外，你要在山的四圍劃定界限，吩咐百姓不得上山或觸碰山的邊界，觸碰者必被處死。</span>
<span className="v" id="v13" data-v="13" data-xref="帖撒羅尼迦前書 4:16; 希伯來書 12:20; 出埃及記 19:16"> 你們不可用手碰違例者，要用石頭打死他或用箭射死他，無論人畜，都不可存活。等到角聲長鳴時，百姓才可上山。」</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及記 19:10"> 於是，摩西下山回到百姓那裡，吩咐他們各人潔淨自己，洗淨衣服。</span>
<span className="v" id="v15" data-v="15" data-xref="哥林多前書 7:5; 撒母耳記上 21:4–5; 出埃及記 19:11"> 又吩咐他們說：「到後天一切都要準備好，這期間你們不可親近女人。」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="希伯來書 12:18–19; 詩篇 18:11–14; 希伯來書 12:21"> 到了第三天早晨，山上雷電大作，烏雲密佈，又有嘹亮的號角聲，營中的百姓都膽戰心驚。</span>
<span className="v" id="v17" data-v="17" data-xref="申命記 4:10; 申命記 5:5"> 摩西率領百姓出營迎接上帝，他們都站在山腳下。</span>
<span className="v" id="v18" data-v="18" data-xref="士師記 5:5; 出埃及記 3:2; 詩篇 144:5"> 因為耶和華在火中降臨到西奈山，山上瀰漫著濃煙，滾滾上騰，好像一個大火窯，整座山劇烈震動。</span>
<span className="v" id="v19" data-v="19" data-xref="詩篇 81:7; 出埃及記 19:16; 尼希米記 9:13"> 號角聲越來越嘹亮。摩西說話，上帝用雷鳴回應他。</span>
<span className="v" id="v20" data-v="20" data-xref="尼希米記 9:13; 出埃及記 34:2; 出埃及記 19:11"> 耶和華降臨在西奈山頂，召摩西到山頂，摩西就上去了。</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳記上 6:19; 出埃及記 3:5; 希伯來書 12:28–29"> 耶和華對摩西說：「你下去警告百姓不可闖過界限到我這裡觀看，以免很多人死亡。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及記 24:5; 使徒行傳 5:10; 歷代志上 13:9–11"> 吩咐到我面前來的祭司要潔淨自己，免得我忽然出來擊殺他們。」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="出埃及記 19:12; 約書亞記 3:4–5"> 摩西對耶和華說：「百姓不能上西奈山，因為你已經吩咐我們要在山的四圍劃定界限，使這山聖潔。」</span>
<span className="v" id="v24" data-v="24" data-xref="希伯來書 4:16; 希伯來書 12:18–25; 希伯來書 12:29"> 耶和華對他說：「你下去把亞倫一起帶來，祭司和百姓仍要留在原來的地方，不得亂闖到我面前，免得我忽然出來擊殺他們。」</span>
<span className="v" id="v25" data-v="25"> 摩西就下去，把耶和華的話轉告給百姓。</span>
</div>
</div>

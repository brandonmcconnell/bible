## 奉獻頭胎

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華對摩西說：</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 2:23; 民數記 3:13; 申命記 15:19"> 「要把以色列人中的長子和頭生的牲畜分別出來，使之聖潔，歸給我。他們都是我的。」</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="申命記 24:18; 申命記 5:15; 出埃及記 20:2"> 摩西對百姓說：「你們要記住離開埃及的這一天，因為耶和華用大能的手把你們從受奴役之地解救出來。不可吃帶酵的食物。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及記 34:18; 出埃及記 23:15; 出埃及記 12:2"> 你們是在亞筆月<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="亞筆月是猶太曆的第一個月，約在陽曆三月中旬到四月中旬，相當於中國的春分時節。">a</a></sup>的這一天從埃及出來的，</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 3:8; 約書亞記 24:11; 出埃及記 12:25–26"> 將來耶和華帶領你們進入迦南人、赫人、亞摩利人、希未人和耶布斯人居住的土地以後，你們每逢此月都要為祂守節期。那是耶和華向你們祖先起誓，應許賜給你們那奶蜜之鄉。</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及記 12:15–20; 出埃及記 34:18; 利未記 23:8"> 在七天的節期內，你們要吃無酵餅，到了第七天，你們要為耶和華守節期。</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及記 12:19; 馬太福音 16:6"> 七天之內要吃無酵餅，你們境內不得有酵或是帶酵的東西。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及記 13:14; 出埃及記 12:26–27; 詩篇 44:1"> 那時，要告訴你們的子孫，『這節期是紀念我們出埃及時，耶和華為我們所做的一切。』</span>
<span className="v" id="v9" data-v="9" data-xref="申命記 6:8; 申命記 11:18–19; 民數記 15:39"> 這節期對你們而言，就像你們手上的記號和額上的提醒，叫你們記得耶和華的律法，祂曾經用大能的手帶你們出埃及。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及記 12:14; 出埃及記 12:24–25; 出埃及記 23:15"> 因此，每一年你們都要按時守這節期。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="出埃及記 13:5"> 「耶和華成就祂起誓給你們和你們祖先的應許，領你們進入迦南人的土地，把那裡賜給你們以後，</span>
<span className="v" id="v12" data-v="12" data-xref="民數記 18:15; 利未記 27:26; 出埃及記 34:19"> 你們要把所有長子和頭生的公畜歸給祂。</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及記 34:20; 民數記 18:15–17; 啟示錄 14:4"> 所有頭生的公驢必須用羊羔贖回，不然就要打斷牠們的脖子。要贖回你們所有的長子。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及記 13:3; 約書亞記 4:6; 詩篇 145:4"> 將來你們的子孫問起這件事的意義，你們就回答，『耶和華曾經用大能的手把我們從受奴役之地埃及帶出來。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及記 12:29"> 當時法老硬著心不肯放我們走，所以耶和華就把埃及人的長子和頭生的牲畜全都殺了。因此，我們把所有頭生的公畜當作祭牲獻給耶和華，把所有長子都贖回來。』</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 13:9; 申命記 11:18; 申命記 6:7–9"> 這事就像你們手上的記號和額上的標記，以牢記耶和華曾用大能的手帶我們出埃及。」</span>
</div>
</div>

## 雲柱和火柱

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="出埃及記 14:11–12; 尼希米記 9:17; 民數記 14:1–4"> 法老讓以色列人離開埃及後，上帝沒有帶領他們穿越非利士地區，雖然那是條捷徑。因為上帝說：「如果他們遇上戰爭，就會改變主意，返回埃及。」</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及記 14:2; 申命記 32:10; 民數記 33:6–8"> 所以，上帝領他們繞道前行，走曠野的路，前往紅海<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="「紅海」或譯「蘆葦湖」，確切地點約在今紅海北端蘇伊士運河附近。">b</a></sup>。以色列人離開埃及時都帶著兵器。</span>
<span className="v" id="v19" data-v="19" data-xref="創世記 50:24–25; 約書亞記 24:32; 使徒行傳 7:16"> 摩西把約瑟的骸骨一起帶走，因為約瑟曾叫以色列人鄭重發誓，對他們說：「上帝必眷顧你們，那時你們要把我的骸骨也一起帶走。」<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="創世記50·25。">c</a></sup></span>
<span className="v" id="v20" data-v="20" data-xref="民數記 33:5–6; 出埃及記 12:37"> 以色列人從疏割啟程，來到曠野邊緣的以倘安營。</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多前書 10:1–2; 尼希米記 9:12; 申命記 1:33"> 耶和華走在他們前面，白天用雲柱為他們指示道路，晚上用火柱照亮他們，這樣他們可以日夜趕路。</span>
<span className="v" id="v22" data-v="22" data-xref="詩篇 121:5–8; 啟示錄 10:1"> 白天的雲柱和晚上的火柱總不從他們前面離開。</span>
</div>
</div>

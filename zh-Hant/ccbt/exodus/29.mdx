## 立祭司的條例

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="利未記 4:3; 瑪拉基書 1:13–14; 出埃及記 12:5"> 「你要使亞倫父子們分別出來，做聖潔的祭司事奉我。做法如下：你要選一頭公牛犢和兩隻毫無殘疾的公綿羊，</span>
<span className="v" id="v2" data-v="2" data-xref="民數記 6:15; 利未記 2:15; 利未記 7:12"> 用細麵粉預備無酵餅、調上油的無酵餅和塗上油的無酵薄餅。</span>
<span className="v" id="v3" data-v="3" data-xref="民數記 6:17; 利未記 8:26; 利未記 8:2"> 所有的餅都要用一個籃子盛，連同公牛和綿羊一起帶到會幕那裡。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及記 40:12; 希伯來書 10:22; 出埃及記 26:36"> 你要把亞倫父子們帶到會幕門口，用水洗他們，</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 28:2–8; 利未記 8:7–8"> 然後給亞倫穿上內袍、以弗得和以弗得的外袍，戴上胸牌，束上精緻的以弗得帶子，</span>
<span className="v" id="v6" data-v="6" data-xref="利未記 8:9; 出埃及記 28:36–39"> 戴上禮冠，把聖冠<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「聖冠」應指28章提到的金牌。">a</a></sup>繫在禮冠上。</span>
<span className="v" id="v7" data-v="7" data-xref="民數記 35:25; 利未記 21:10; 約翰福音 3:34"> 之後，把膏油倒在他頭上，立他為祭司。</span>
<span className="v" id="v8" data-v="8" data-xref="利未記 8:13; 出埃及記 28:40"> 接著輪到亞倫的兒子們，要給他們穿上內袍，</span>
<span className="v" id="v9" data-v="9" data-xref="民數記 18:7; 利未記 8:22–28; 申命記 18:5"> 為他們束上腰帶，戴上頭巾，他們就按永遠的律例得到祭司的職分。你要這樣把聖職授予他們。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="利未記 1:4; 利未記 8:14; 出埃及記 29:15"> 「你要把公牛牽到會幕前面，亞倫父子們要把手按在公牛頭上。</span>
<span className="v" id="v11" data-v="11" data-xref="利未記 9:8; 利未記 9:12; 出埃及記 29:4"> 你要在會幕門前，在耶和華面前宰公牛。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及記 27:2; 利未記 9:9; 利未記 8:15"> 要取些公牛的血帶到祭壇那裡，用手指把血抹在祭壇凸起的四角上，再把剩下的血倒在壇腳。</span>
<span className="v" id="v13" data-v="13" data-xref="利未記 3:3–4; 撒母耳記上 2:16; 利未記 9:10"> 再把包裹內臟的脂肪、肝葉、兩個腎臟和腎臟上的脂肪都放在祭壇上燒掉。</span>
<span className="v" id="v14" data-v="14" data-xref="利未記 4:11–12; 利未記 4:21; 出埃及記 30:10"> 但公牛的皮、肉和糞要拿到營外焚燒。這是贖罪祭。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="出埃及記 29:19; 出埃及記 29:3; 利未記 8:18–21"> 「要把一隻公綿羊牽來，亞倫父子們要把手按在羊頭上，</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 29:11–12"> 然後你要宰羊，把血灑在祭壇四周。</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米書 4:14; 利未記 1:13; 利未記 1:9"> 再把羊切成塊狀，用水洗淨所有的內臟和腿，跟肉塊和頭放在一起。</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 8:21; 腓立比書 4:18; 創世記 22:7"> 然後，把整隻羊放在祭壇上焚燒，這是獻給耶和華的燔祭，是蒙耶和華悅納的馨香火祭。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="出埃及記 29:3; 利未記 8:22–29"> 「你要把另一隻公綿羊牽來，亞倫父子們要把手按在羊頭上，</span>
<span className="v" id="v20" data-v="20" data-xref="以賽亞書 50:5; 希伯來書 10:22; 利未記 14:16"> 然後你要宰羊，取一點血塗在亞倫和他兒子們的右耳垂、右手大拇指和右腳大腳趾上，剩下的血就灑在祭壇四周。</span>
<span className="v" id="v21" data-v="21" data-xref="希伯來書 9:22; 出埃及記 29:7; 出埃及記 29:1"> 再從祭壇上取些血，與膏油一起灑在亞倫父子及其衣服上。這樣，他們和他們的衣服就會變得聖潔。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="出埃及記 29:13; 利未記 9:21; 利未記 9:19"> 「你要取出羊的脂肪、肥尾巴、包裹內臟的脂肪、肝葉、兩個腎臟、腎臟上的脂肪和右腿，因為這是授聖職時所獻的羊。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及記 29:2–3; 利未記 8:26"> 再從耶和華面前裝無酵餅的籃子裡取一個餅、一個油餅和一個薄餅。</span>
<span className="v" id="v24" data-v="24" data-xref="利未記 7:30; 利未記 8:27; 利未記 9:21"> 把這些都放在亞倫父子們手中，作為搖祭在耶和華面前搖一搖。</span>
<span className="v" id="v25" data-v="25" data-xref="利未記 8:28; 出埃及記 29:41; 利未記 3:16"> 然後，你要把這些祭物接過來，放在祭壇的燔祭上焚燒獻給耶和華，成為蒙耶和華悅納的馨香火祭。</span>
<span className="v" id="v26" data-v="26" data-xref="利未記 8:29; 利未記 7:31; 利未記 7:34"> 你要拿起亞倫承受聖職時所獻的那只公綿羊的胸肉，作為搖祭在耶和華面前搖一搖。之後，這份祭肉就歸你。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="利未記 10:15; 民數記 18:11; 申命記 18:3"> 「你要將屬於亞倫父子們、授聖職時所獻公綿羊的搖祭胸肉和舉祭腿肉分別出來，使之聖潔。</span>
<span className="v" id="v28" data-v="28" data-xref="民數記 15:19–20; 利未記 7:11–38; 利未記 10:14–15"> 這些祭物要從以色列人所獻的平安祭中取出來，歸給亞倫父子們，作為永遠的定例。這是以色列人當向耶和華獻的祭物。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="民數記 18:8; 出埃及記 28:3–4; 出埃及記 30:30"> 「亞倫的聖衣要留給他的子孫，他們可以穿上這聖衣受膏，承受聖職。</span>
<span className="v" id="v30" data-v="30" data-xref="民數記 20:28; 利未記 13:5; 使徒行傳 20:6–7"> 接替亞倫做祭司的那位後裔，每次進會幕的聖所供職時，都要一連七天穿著聖衣。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="利未記 8:31; 撒母耳記上 2:13; 以西結書 46:20–24"> 「你要在聖潔的地方煮授聖職時所用的公綿羊肉。</span>
<span className="v" id="v32" data-v="32" data-xref="馬太福音 12:4; 出埃及記 29:23; 出埃及記 29:2–3"> 亞倫父子們可以在會幕的門前吃這公綿羊祭肉和籃內的餅。</span>
<span className="v" id="v33" data-v="33" data-xref="民數記 18:4; 利未記 10:13–18; 詩篇 22:26"> 他們要吃這些在授聖職時用來贖罪、使他們聖潔的祭物。但祭司以外的人不能吃，因為這些是聖物。</span>
<span className="v" id="v34" data-v="34" data-xref="出埃及記 12:10; 利未記 8:32; 出埃及記 29:22"> 若有授聖職時所獻的肉或餅留到早晨，就要燒掉，不可再吃，因為這些都是聖物。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="出埃及記 29:30; 利未記 14:8–11; 利未記 8:4–36"> 「你要照我的吩咐，為亞倫父子們舉行授聖職禮，歷時七天。</span>
<span className="v" id="v36" data-v="36" data-xref="希伯來書 10:11; 希伯來書 9:22–23; 出埃及記 30:28–29"> 每天要獻一頭公牛作贖罪祭，來潔淨祭壇，然後用膏油抹祭壇，使祭壇聖潔。</span>
<span className="v" id="v37" data-v="37" data-xref="出埃及記 40:10; 馬太福音 23:19; 出埃及記 30:28–29"> 連續七天都要這樣做，使祭壇完全聖潔，凡是碰到祭壇的都變得聖潔。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="歷代志下 2:4; 歷代志上 16:40; 民數記 28:3–8"> 「你每天要在祭壇上獻兩隻一歲的公羊羔，</span>
<span className="v" id="v39" data-v="39" data-xref="以西結書 46:13–15; 列王紀下 16:15; 詩篇 5:3"> 早晨和黃昏各獻一隻。</span>
<span className="v" id="v40" data-v="40" data-xref="腓立比書 2:17; 以西結書 46:14; 約珥書 2:14"> 要用一公斤細麵粉調一升橄欖油做成素祭，與早晨獻的羊羔一同獻上，再獻上一升酒作奠祭。</span>
<span className="v" id="v41" data-v="41" data-xref="以西結書 46:13–15; 列王紀上 18:29; 詩篇 141:2"> 黃昏獻第二隻羊時，也要跟早晨一樣同時獻上素祭和奠祭，作為蒙耶和華悅納的馨香火祭。</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="出埃及記 25:22"> 「你們世世代代要不斷地在我面前獻上燔祭，祭禮要在會幕門前舉行，這會幕就是我跟你們會面交談的地方。</span>
<span className="v" id="v43" data-v="43" data-xref="列王紀上 8:11; 歷代志下 7:1–3; 瑪拉基書 3:1"> 我要在那裡和以色列人相會，我的榮耀將使會幕聖潔。</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="利未記 21:15; 利未記 22:9; 利未記 22:16"> 「我要使會幕和祭壇聖潔，也要使亞倫父子們聖潔，做祭司事奉我。</span>
<span className="v" id="v45" data-v="45" data-xref="利未記 26:12; 哥林多後書 6:16; 出埃及記 25:8"> 我要住在以色列人中間，做他們的上帝。</span>
<span className="v" id="v46" data-v="46" data-xref="出埃及記 20:2; 耶利米書 31:33; 以西結書 20:5"> 他們必知道我是他們的上帝耶和華。我帶領他們離開埃及，就是為了要住在他們中間。我是他們的上帝耶和華。</span>
</div>
</div>

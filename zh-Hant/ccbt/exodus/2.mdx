## 摩西出生

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民數記 26:59; 歷代志上 23:12–14; 出埃及記 6:16–20"> 有一個利未族的人跟他同族的女子結婚。</span>
<span className="v" id="v2" data-v="2" data-xref="希伯來書 11:23; 使徒行傳 7:20; 詩篇 112:5"> 那女子懷孕，生了一個男嬰。她看見孩子可愛，就把他藏了三個月。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 1:22; 使徒行傳 7:19; 創世記 6:14"> 後來無法再藏下去，她就拿來一個蒲草籃子，外面塗上防水的瀝青和柏油，然後把嬰兒放在裡面，又把籃子放在尼羅河邊的蘆葦叢中。</span>
<span className="v" id="v4" data-v="4" data-xref="民數記 26:59; 出埃及記 15:20; 彌迦書 6:4"> 嬰兒的姐姐遠遠地站著，要看看她的弟弟究竟會怎樣。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行傳 7:21; 詩篇 12:5; 詩篇 9:9"> 這時，法老的女兒來到河邊沐浴，宮女們在河邊行走。公主發現了蘆葦叢中的籃子，便吩咐一個婢女去把它取來。</span>
<span className="v" id="v6" data-v="6" data-xref="列王紀上 8:50; 彼得前書 3:8; 使徒行傳 7:21"> 公主打開一看，原來是一個男嬰。公主看見孩子在哭，就可憐他，說：「他是希伯來人的孩子。」</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及記 2:4; 民數記 26:59; 民數記 12:1"> 嬰兒的姐姐對公主說：「我去找一個希伯來婦女當奶媽，為你哺養他好嗎？」</span>
<span className="v" id="v8" data-v="8" data-xref="以賽亞書 46:3–4; 詩篇 27:10; 出埃及記 6:20"> 公主回答說：「好！」那女孩就跑去把嬰孩的母親帶來。</span>
<span className="v" id="v9" data-v="9"> 公主對那婦女說：「你把孩子抱去，替我哺養他，我會給你工錢。」她便把孩子抱去哺養。</span>
<span className="v" id="v10" data-v="10" data-xref="希伯來書 11:24; 創世記 16:11; 撒母耳記上 1:20"> 孩子漸漸長大，她便把他帶到公主那裡，孩子就做了公主的兒子。公主給孩子取名叫摩西，意思是「我把他從水中拉了上來」。</span>
<span className="v" id="v11" data-v="11" data-xref="希伯來書 11:24–26; 使徒行傳 7:22–24; 出埃及記 1:11"> 後來，摩西長大了，他去看望做苦工的希伯來同胞，看見一個埃及人在毆打他的一個希伯來同胞。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行傳 7:24–26"> 他左右觀望，見四下無人，便下手殺了那埃及人，把屍體埋藏在沙地裡。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行傳 7:26–28; 哥林多前書 6:7–8"> 第二天，他又出去，看見兩個希伯來人在打架，便過去對理虧的人說：「你為什麼打自己的同胞呢？」</span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 12:14; 馬太福音 21:23; 創世記 19:9"> 那人說：「誰立你作我們的首領和審判官？難道你要殺我，像殺那個埃及人一樣嗎？」摩西聽了，害怕起來，心想：「我做的事一定被人知道了。」</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行傳 7:29; 希伯來書 11:27; 創世記 24:11"> 法老聽說這件事後，便想殺死摩西。摩西為了躲避法老，就逃到米甸居住。一天他坐在一口井旁，</span>
<span className="v" id="v16" data-v="16" data-xref="創世記 24:11; 出埃及記 3:1; 撒母耳記上 9:11"> 米甸祭司的七個女兒來打水，要把水倒進槽裡飲她們父親的羊。</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 29:10; 創世記 21:25; 創世記 26:15–22"> 這時，來了另外一群牧人要把她們趕走。摩西便起來幫助她們，打水飲她們的羊群。</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及記 3:1; 民數記 10:29; 出埃及記 4:18"> 她們回到父親流珥<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「流珥」又名「葉特羅」。">a</a></sup>那裡，父親問道：「你們今天怎麼這麼快就回來了？」</span>
<span className="v" id="v19" data-v="19" data-xref="創世記 50:11; 創世記 29:10"> 她們答道：「有一個埃及人救我們免遭牧人的欺負，還幫我們打水飲羊群。」</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 31:54; 創世記 43:25; 希伯來書 13:2"> 他又問女兒們：「現在那人在哪裡？你們怎麼可以丟下他不管呢？去請他來吃點東西。」</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 31:38–40; 希伯來書 13:5; 希伯來書 11:25"> 後來，摩西同意住在那人家裡。那人把女兒西坡拉許配給他。</span>
<span className="v" id="v22" data-v="22" data-xref="希伯來書 11:13–14; 使徒行傳 7:29; 出埃及記 22:21"> 後來，西坡拉生了一個兒子，摩西給他取名叫革舜，意思是「我成了在異鄉寄居的人」。</span>
<span className="v" id="v23" data-v="23" data-xref="創世記 18:20–21; 雅各書 5:4; 出埃及記 3:7–9"> 過了多年，埃及王死了。以色列人受盡奴役，就哀歎呼求，聲音傳到上帝那裡。</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 26:3; 詩篇 105:42; 出埃及記 6:5"> 上帝聽見他們的哀聲，顧念從前跟亞伯拉罕、以撒、雅各所立的約，</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及記 4:31; 詩篇 55:22; 出埃及記 3:7–8"> 就垂顧他們，體恤他們。</span>

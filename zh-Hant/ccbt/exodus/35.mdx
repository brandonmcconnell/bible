## 安息日的條例

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及記 34:32; 出埃及記 31:1–11; 羅馬書 2:13"> 摩西招聚以色列全體會眾，對他們宣佈說：「以下是耶和華吩咐你們遵守的事。</span>
<span className="v" id="v2" data-v="2" data-xref="利未記 23:3; 路加福音 13:14–15; 出埃及記 20:9–10"> 一週可以工作六天，但第七天是你們為耶和華守的聖日，是完全休息的安息日。凡在這一天工作的，必被處死。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 16:23; 民數記 15:32–36; 出埃及記 12:16"> 在安息日，你們的任何住處都不可生火。」</span>
</div>
</div>

## 為造聖幕奉獻

<div className="bt">
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="出埃及記 25:1–2"> 摩西對以色列全體會眾說：「以下是耶和華給你們的吩咐。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="哥林多後書 9:7; 詩篇 110:3; 出埃及記 25:2–7"> 「你們要獻物品給耶和華。凡慷慨樂捐的，都可以把下列物品獻給耶和華為禮物，即金、銀、銅，</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及記 26:7–14; 出埃及記 26:31; 出埃及記 28:15"> 藍色、紫色和朱紅色毛線，細麻，山羊毛，</span>
<span className="v" id="v7" data-v="7"> 染成紅色的公羊皮，海狗皮，皂莢木，</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及記 27:20; 出埃及記 25:1–40; 出埃及記 30:23"> 燈油，製作膏油和香的香料，</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及記 39:6–14; 出埃及記 28:9; 出埃及記 25:5"> 鑲嵌在以弗得和胸牌上的紅瑪瑙及其他寶石。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="出埃及記 31:1–6; 出埃及記 36:1–4"> 「你們當中的能工巧匠都要來建造耶和華所吩咐的物件，</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及記 26:1–37; 出埃及記 36:8–34; 出埃及記 31:7–9"> 即聖幕和聖幕的罩棚、頂蓋、鉤子、木板、橫閂、柱子和帶凹槽的底座；</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及記 25:10–22; 出埃及記 26:31–33; 出埃及記 37:1–9"> 約櫃和抬約櫃的橫槓、施恩座和遮掩約櫃的幔子；</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及記 25:23–30; 利未記 24:5–6; 出埃及記 37:10–16"> 桌子和抬桌子的橫槓、桌上的一切器具和供餅；</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及記 25:31–39; 馬太福音 5:14–15; 出埃及記 37:17–24"> 燈臺和燈臺用的器具、燈盞和燈油；</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及記 30:1–10; 出埃及記 30:22–38; 出埃及記 37:25–28"> 香壇和抬香壇的橫槓、膏油和芬芳的香；聖幕門口的簾子；</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 27:1–8; 出埃及記 30:18–21; 出埃及記 38:1–8"> 燔祭壇、祭壇的銅網、抬祭壇的橫槓、祭壇用的一切器具、洗濯盆和盆座；</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳記下 7:2; 出埃及記 38:9–20; 出埃及記 27:9–19"> 院子的帷幔、懸掛幔子的柱子和底座、院子入口的門簾；</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及記 27:19"> 聖幕及院子用的橛子和繩子；</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及記 31:10; 民數記 4:5–15; 出埃及記 28:1–43"> 在聖所供職時穿的精製禮服、亞倫祭司的聖衣及其眾子供祭司之職時穿的衣服。」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20"> 之後，以色列全體會眾便從摩西面前退去。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及記 25:2; 出埃及記 35:26; 歷代志上 29:14"> 凡心裡有感動又甘願奉獻的，都把禮物拿來獻給耶和華，作會幕、會幕中的一切器具及聖衣之用。</span>
<span className="v" id="v22" data-v="22" data-xref="尼希米記 7:70–72; 馬太福音 2:11; 以斯拉記 2:68–69"> 凡甘心奉獻的，不論男女，都把別針、耳環、戒指、項鏈等各樣金飾拿來獻給耶和華。</span>
<span className="v" id="v23" data-v="23" data-xref="歷代志上 29:8; 出埃及記 25:2–7; 出埃及記 35:6–10"> 凡有藍色、紫色和朱紅色毛線，細麻，山羊毛，染成紅色的公羊皮，海狗皮的，都把它們拿來了。</span>
<span className="v" id="v24" data-v="24" data-xref="哥林多後書 8:12"> 凡奉獻銀器和銅器的，都拿來獻給耶和華。凡有皂莢木的，只要用得上，都拿來奉獻。</span>
<span className="v" id="v25" data-v="25" data-xref="羅馬書 16:12; 路加福音 8:2–3; 箴言 14:1"> 凡善於紡線的婦女，都把親手紡成的細麻和藍色、紫色、朱紅色毛線拿來奉獻。</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及記 35:21; 出埃及記 36:8; 出埃及記 35:29"> 凡心裡受感動又善於紡織的婦女都來紡山羊毛。</span>
<span className="v" id="v27" data-v="27" data-xref="以斯拉記 2:68; 歷代志上 29:6; 出埃及記 35:9"> 眾首領奉獻了紅瑪瑙和其他寶石，用來鑲嵌在以弗得和胸牌上。</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及記 30:23–38; 出埃及記 35:8"> 他們又獻出香料和油，用來做香、點燈、做膏油。</span>
<span className="v" id="v29" data-v="29" data-xref="哥林多後書 9:7; 出埃及記 35:21–22; 出埃及記 35:4"> 以色列人，不論男女、凡是甘心樂意奉獻的，都把禮物帶來獻給耶和華，好完成耶和華藉摩西吩咐他們的一切工作。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="出埃及記 31:1–6; 雅各書 1:17; 哥林多前書 12:11"> 摩西對以色列人說：「看啊，耶和華已經親自在猶大支派中選出戶珥的孫子、烏利的兒子比撒列，</span>
<span className="v" id="v31" data-v="31" data-xref="雅各書 1:17; 以賽亞書 11:2–5; 以賽亞書 61:1–3"> 上帝的靈已經充滿他，使他有聰明智慧，精於各種技能和手藝，</span>
<span className="v" id="v32" data-v="32"> 能用金、銀和銅製造精巧的器具，</span>
<span className="v" id="v33" data-v="33"> 又能雕刻和鑲嵌寶石，精通木工和各種手藝。</span>
<span className="v" id="v34" data-v="34" data-xref="出埃及記 31:6; 歷代志下 2:14; 以斯拉記 7:27"> 耶和華又使他與但支派亞希撒抹的兒子亞何利亞伯有能力教授別人。</span>
<span className="v" id="v35" data-v="35" data-xref="出埃及記 35:31; 列王紀上 7:14; 以賽亞書 28:26"> 耶和華使他們成為能工巧匠，精通各樣技藝，包括雕刻、圖案設計、紡織，以及用細麻和藍色、紫色、朱紅色毛線刺繡。」</span>
</div>
</div>

## 金牛犢

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行傳 7:40; 申命記 9:9; 出埃及記 24:18"> 百姓見摩西遲遲沒有下山，就聚集到亞倫那裡，對他說：「帶我們出埃及的那個摩西不知怎樣了，你給我們造神像來帶領我們吧。」</span>
<span className="v" id="v2" data-v="2" data-xref="士師記 8:24–27; 出埃及記 12:35–36; 以西結書 16:17"> 亞倫對他們說：「你們去摘下妻子、兒女的金耳環，拿來給我。」</span>
<span className="v" id="v3" data-v="3" data-xref="以賽亞書 46:6; 以賽亞書 40:19–20; 耶利米書 10:9"> 百姓就都摘下金耳環交給亞倫。</span>
<span className="v" id="v4" data-v="4" data-xref="尼希米記 9:18; 申命記 9:16; 列王紀上 12:28"> 亞倫接過這些金耳環，用它們鑄造了一頭牛犢。他們說：「以色列人啊，這就是帶你們出埃及的神明。」</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀下 10:20; 利未記 23:2; 利未記 23:37"> 亞倫見狀便在牛犢前面築了一座壇，然後宣告說：「明天是耶和華定的節期。」</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多前書 10:7; 民數記 25:2; 使徒行傳 7:41–42"> 第二天清晨，百姓都上前來獻燔祭和平安祭，獻完祭後就坐下吃喝，起來狂歡。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="出埃及記 32:11; 何西阿書 9:9; 士師記 2:19"> 耶和華對摩西說：「你下山吧，你的百姓，就是你從埃及領出來的那些人已經敗壞了。</span>
<span className="v" id="v8" data-v="8" data-xref="列王紀上 12:28; 出埃及記 20:23; 出埃及記 20:3–4"> 他們這麼快就偏離了我吩咐他們走的道路，為自己造了一頭牛犢來叩拜獻祭，說，『以色列人啊，這就是帶你們出埃及的神明。』」</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行傳 7:51; 申命記 9:13; 以賽亞書 48:4"> 耶和華又說：「我看到了，這些百姓真是頑固不化。</span>
<span className="v" id="v10" data-v="10" data-xref="申命記 9:14; 民數記 14:12; 申命記 9:19"> 你不要阻止我，我要向他們發烈怒，毀滅他們。我要使你成為大國。」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="申命記 9:18–20; 申命記 9:26–29; 詩篇 106:23"> 摩西懇求他的上帝耶和華說：「耶和華啊，你為什麼要向你的子民發烈怒呢？這些子民是你親自用神蹟和大能從埃及領出來的。</span>
<span className="v" id="v12" data-v="12" data-xref="民數記 14:13–16; 申命記 9:28; 約書亞記 7:9"> 難道你要讓埃及人議論說你領他們出來是出於惡意，是為了在山野之間殺掉他們，從地上滅絕他們嗎？求你息怒，施憐憫，不要降禍給你的子民。</span>
<span className="v" id="v13" data-v="13" data-xref="希伯來書 6:13; 創世記 12:7; 創世記 22:16"> 求你顧念你的僕人亞伯拉罕、以撒和以色列，你曾憑自己向他們起誓說，『我必使你們的後代像天上的星星那麼多。我應許給你們後代的這整片土地，我必賜給他們作永遠的產業。』」</span>
<span className="v" id="v14" data-v="14" data-xref="約拿書 3:10; 詩篇 106:45; 耶利米書 26:13"> 耶和華聽了摩西的話，就施憐憫，不把所說的災禍降在百姓身上。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="申命記 9:15; 出埃及記 40:20; 申命記 5:22"> 摩西轉身下山，手裡拿著兩塊約版，約版的正反兩面都有字。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 31:18; 希伯來書 8:10; 申命記 10:1"> 石版是上帝做的，字是上帝刻的。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及記 24:13; 出埃及記 17:9; 約書亞記 6:20"> 約書亞聽見山下百姓嘈雜的喊叫聲，便對摩西說：「營地裡有打仗的聲音。」</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及記 15:1–18; 但以理書 5:4; 但以理書 5:23"> 摩西對他說：「這不是打勝仗的聲音，也不是打敗仗的聲音，而是歌唱的聲音。」</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 9:16–17; 耶利米書 31:32; 耶利米哀歌 5:15"> 摩西走近營地的時候，看見牛犢，又看見百姓在跳舞，心中大怒，便把手上的兩塊石版摔碎在山腳下，</span>
<span className="v" id="v20" data-v="20" data-xref="申命記 9:21; 列王紀下 23:6; 列王紀下 23:15"> 又焚燒他們鑄造的牛犢，把它磨成粉末撒在水面上，叫以色列百姓喝。</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 20:9; 約書亞記 7:19–26; 列王紀上 21:22"> 摩西對亞倫說：「這些百姓對你做了什麼？你竟使他們陷入大罪中！」</span>
<span className="v" id="v22" data-v="22" data-xref="申命記 9:24; 出埃及記 15:24; 出埃及記 16:20"> 亞倫回答說：「求我主不要動怒，你知道這些人專門作惡。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及記 32:1–4; 出埃及記 32:8"> 他們對我說，『為我們造神明來帶領我們吧，因為帶我們出埃及的那個摩西不知怎樣了。』</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及記 32:4; 路加福音 10:29; 羅馬書 3:10"> 於是，我吩咐他們摘下金耳環給我，我把這些金耳環扔進火裡，這頭牛犢就出來了。」</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="以賽亞書 47:3; 彌迦書 1:11; 啟示錄 16:15"> 摩西見百姓放肆，亞倫縱容他們，使他們成為敵人的笑柄，</span>
<span className="v" id="v26" data-v="26" data-xref="列王紀下 9:32; 馬太福音 12:30; 撒母耳記下 20:11"> 便站在營門口對會眾說：「凡跟從耶和華的，都站到我這邊來。」所有的利未人都聚集到摩西身邊。</span>
<span className="v" id="v27" data-v="27" data-xref="民數記 25:5; 路加福音 14:26; 申命記 33:8–9"> 摩西對他們說：「以色列的上帝耶和華這樣說，『你們各人帶著刀，從這個門到那個門，走遍整個營，不論遇見的是兄弟、夥伴還是鄰居，只管殺他們。』」</span>
<span className="v" id="v28" data-v="28" data-xref="申命記 33:9; 瑪拉基書 2:4–6; 哥林多前書 10:8"> 利未人便照摩西的話去做。那一天，約有三千人被殺。</span>
<span className="v" id="v29" data-v="29" data-xref="民數記 25:11–13; 馬太福音 10:37; 撒迦利亞書 13:3"> 摩西對利未人說：「今天你們已經把自己奉獻給耶和華了，因為你們大義滅親，祂今天必賜福給你們。」</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="撒母耳記上 12:20; 民數記 25:13; 列王紀下 17:21"> 第二天，摩西對百姓說：「你們犯了大罪，我現在要到耶和華那裡，也許可以為你們贖罪。」</span>
<span className="v" id="v31" data-v="31" data-xref="出埃及記 20:23; 但以理書 9:11; 但以理書 9:8"> 摩西回到耶和華那裡，說：「唉，百姓犯了大罪，用金子為自己造了神像。</span>
<span className="v" id="v32" data-v="32" data-xref="詩篇 69:28; 羅馬書 9:3; 啟示錄 21:27"> 懇求你赦免他們的罪，不然請你從你的冊子上抹掉我的名字吧。」</span>
<span className="v" id="v33" data-v="33" data-xref="申命記 29:20; 以西結書 18:4; 啟示錄 20:12"> 耶和華對摩西說：「誰得罪我，我就從我的冊子上抹掉誰的名字。</span>
<span className="v" id="v34" data-v="34" data-xref="出埃及記 23:20; 申命記 32:35; 馬太福音 23:35"> 你現在回去帶領這些百姓，往我指示你的地方去，我的天使必在你前面引路。只是到我懲罰的日子，我必因他們的罪懲罰他們。」</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="使徒行傳 7:41; 出埃及記 32:25; 撒母耳記下 12:9–10"> 耶和華擊殺百姓，是因為他們曾與亞倫一起造牛犢。</span>
</div>
</div>

## 過紅海

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及記 12:1; 出埃及記 13:1"> 耶和華對摩西說：</span>
<span className="v" id="v2" data-v="2" data-xref="民數記 33:7–8; 耶利米書 44:1; 出埃及記 13:17–18"> 「你吩咐以色列人改變方向，在比·哈希錄附近的海邊紮營，在紅海和密奪之間，對面是巴力·洗分。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行傳 4:28; 撒母耳記上 23:23; 詩篇 71:11"> 法老必定以為以色列人走迷了路，被困在曠野。</span>
<span className="v" id="v4" data-v="4" data-xref="羅馬書 9:22–23; 出埃及記 7:5; 羅馬書 9:17"> 我要使法老的心剛硬，使他派兵追趕他們。我要在法老和埃及軍兵身上得榮耀，好叫埃及人知道我是耶和華。」於是，以色列人遵命而行。</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 105:25; 出埃及記 12:33; 路加福音 11:24–26"> 有人向埃及王報信，說以色列百姓逃走了。法老和他的臣僕便改變主意，說：「我們怎麼可以讓以色列人就這樣離開我們，不再服侍我們呢？」</span>
<span className="v" id="v6" data-v="6"> 法老便吩咐人預備戰車，他親自領軍，</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及記 15:4; 士師記 4:3; 詩篇 68:17"> 率領埃及所有的戰車，包括六百輛最精銳的戰車，每輛車上都有戰車長。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行傳 13:17; 民數記 33:3; 申命記 26:8"> 耶和華使埃及王法老的心剛硬，法老就追趕毫無懼色地離開埃及的以色列人。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及記 15:9; 約書亞記 24:6; 出埃及記 14:2"> 埃及大軍的戰車騎兵傾巢而出，在巴力·洗分對面、比·哈希錄附近的海邊，追上了安營的以色列人。</span>
<span className="v" id="v10" data-v="10" data-xref="約書亞記 24:7; 詩篇 34:17; 尼希米記 9:9"> 法老漸漸逼近，以色列人抬頭看見埃及人追了上來，非常害怕，便呼求耶和華。</span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 106:7–8; 民數記 14:1–4; 出埃及記 15:23–24"> 他們對摩西說：「難道埃及沒有墳地，要你帶我們出來死在曠野嗎？為什麼要帶我們出埃及呢？</span>
<span className="v" id="v12" data-v="12" data-xref="約拿書 4:3; 出埃及記 6:9; 約拿書 4:8"> 我們在埃及豈不是對你說過，別管我們，就讓我們服侍埃及人嗎？服侍埃及人總比死在曠野好啊！」</span>
<span className="v" id="v13" data-v="13" data-xref="歷代志下 20:17; 歷代志下 20:15; 出埃及記 14:30"> 摩西對百姓說：「你們不要害怕，站穩了，看耶和華今天怎樣解救你們。你們再也看不到你們今天看到的埃及人了。</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 3:22; 申命記 20:4; 歷代志下 20:17"> 耶和華必為你們爭戰，你們要保持安靜。」</span>
<span className="v" id="v15" data-v="15" data-xref="約書亞記 7:10; 以斯拉記 10:4–5; 尼希米記 9:9"> 耶和華對摩西說：「為什麼向我呼求呢？吩咐以色列人往前走吧。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 7:19; 出埃及記 4:20; 出埃及記 4:2"> 你舉手向海伸出手杖，把海水分開，以色列人可以從中間的乾地走過去。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及記 14:8; 出埃及記 14:4; 以西結書 34:11"> 我要使埃及人的心剛硬，他們會尾隨你們下到海中。我要在法老及其大軍、戰車和騎兵身上得榮耀。</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及記 7:5; 出埃及記 14:4; 出埃及記 7:17"> 當我在法老及其戰車和騎兵身上得到榮耀時，埃及人就知道我是耶和華。」</span>
<span className="v" id="v19" data-v="19" data-xref="以賽亞書 63:9; 出埃及記 32:34; 出埃及記 23:20–21"> 這時，在以色列隊伍前面領路的上帝的天使，轉到百姓後面，雲柱也隨著移到後面立住。</span>
<span className="v" id="v20" data-v="20" data-xref="以賽亞書 8:14; 哥林多後書 2:15–16; 箴言 4:18–19"> 雲柱停在埃及隊伍和以色列隊伍的中間，埃及人這邊一片黑暗，以色列人那邊卻有光，彼此整夜都無法接近對方。</span>
<span className="v" id="v21" data-v="21" data-xref="以賽亞書 63:12; 出埃及記 15:8; 詩篇 66:6"> 摩西向海伸出手，耶和華便整夜用強勁的東風吹退海水，將海底變成乾地。海水分開後，</span>
<span className="v" id="v22" data-v="22" data-xref="希伯來書 11:29; 詩篇 66:6; 出埃及記 15:19"> 以色列人踏著乾地走入海中，海水在他們左右形成水牆。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及記 15:19; 出埃及記 14:17; 出埃及記 15:9"> 法老的軍兵車馬緊追不捨，都跟著下到海中。</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及記 13:21; 詩篇 77:16–19; 出埃及記 14:25"> 到了破曉時分，耶和華從雲柱火柱中俯視埃及軍隊，使他們陷入混亂。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及記 14:14; 申命記 3:22; 約伯記 20:24"> 祂使他們戰車的輪子脫落，難以前行。於是，埃及人說：「我們逃命吧，因為耶和華在幫助以色列人攻擊我們！」</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及記 14:16; 出埃及記 8:5; 雅各書 2:13"> 耶和華對摩西說：「你向海伸出手，使海水回流，淹沒埃及人及其戰車和馬兵。」</span>
<span className="v" id="v27" data-v="27" data-xref="約書亞記 4:18; 詩篇 78:53; 希伯來書 11:29"> 天剛亮的時候，摩西向海伸出手，海水便恢復原狀。埃及人紛紛向岸上逃命，耶和華卻使大水把他們捲回海中。</span>
<span className="v" id="v28" data-v="28" data-xref="詩篇 78:53; 詩篇 106:9–11; 哈巴谷書 3:13"> 海水回流，法老的戰車和人馬都淹沒在大海之中，全軍覆沒。</span>
<span className="v" id="v29" data-v="29" data-xref="出埃及記 14:22; 詩篇 77:19–20; 以賽亞書 43:2"> 以色列人卻在乾地上走過紅海，海水在他們左右形成水牆。</span>
<span className="v" id="v30" data-v="30" data-xref="詩篇 106:8; 詩篇 106:10; 詩篇 92:9–11"> 那天，耶和華就這樣從埃及人手中拯救了以色列人。以色列人看見埃及人的屍體橫在海邊。</span>
<span className="v" id="v31" data-v="31" data-xref="約翰福音 2:11; 約翰福音 11:45; 約翰福音 2:23–25"> 以色列百姓親眼看見耶和華怎樣以大能對付埃及人，他們就敬畏耶和華，又信服祂和祂的僕人摩西。</span>

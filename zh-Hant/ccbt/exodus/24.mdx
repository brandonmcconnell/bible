## 在西奈山立約

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民數記 11:16; 出埃及記 6:23; 利未記 10:1–2"> 耶和華又指示摩西說：「你和亞倫、拿答、亞比戶及以色列的七十位長老上我這裡來，遠遠地敬拜我。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 24:15; 出埃及記 24:13; 希伯來書 10:21–22"> 只有你可以靠近我，其他百姓都不得與你一同走近。」</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 19:8; 出埃及記 24:7; 約書亞記 24:22"> 摩西下山把耶和華的話和法令都告訴百姓，百姓齊聲回答：「我們願意遵行耶和華的一切吩咐。」</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 28:18; 申命記 31:9; 約書亞記 4:8–9"> 摩西把耶和華的這些話記錄下來。他清早起來，在山腳築了一座壇，立了十二根柱子，代表以色列的十二支派。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 18:12; 利未記 3:1–17; 出埃及記 19:22"> 他又吩咐以色列的青年去給耶和華獻燔祭，又獻上公牛作平安祭。</span>
<span className="v" id="v6" data-v="6" data-xref="彼得前書 1:19; 出埃及記 24:8; 希伯來書 9:18"> 摩西把祭牲的血一半放在盆裡，一半灑在壇上。</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 31:11–13; 帖撒羅尼迦前書 5:27; 出埃及記 24:3–4"> 他又把約書念給百姓聽，百姓聽了都說：「我們願意遵行耶和華的一切吩咐，我們願意順服。」</span>
<span className="v" id="v8" data-v="8" data-xref="希伯來書 10:4–5; 出埃及記 24:6; 以西結書 36:25"> 摩西便把盆中的血灑在百姓身上，說：「這是立約的血，是耶和華按所說的話與你們立約的憑據。」</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及記 24:1"> 之後，摩西、亞倫、拿答、亞比戶及以色列的七十位長老便上了山。</span>
<span className="v" id="v10" data-v="10" data-xref="約翰福音 1:18; 以西結書 10:1; 創世記 32:30"> 他們都看見了以色列的上帝，祂的腳下好像是一片藍寶石，像天一樣明淨。</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 15:23–24; 出埃及記 18:12; 創世記 31:54"> 上帝沒有伸手殺這些以色列的首領，允許他們看見祂，在祂面前吃喝。</span>
<span className="v" id="v12" data-v="12" data-xref="申命記 5:22; 出埃及記 31:18; 出埃及記 32:15–16"> 耶和華對摩西說：「你上山到我這裡來，留在這裡，我要把寫著律法和誡命的石版賜給你，你可以用來教導百姓。」</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及記 33:11; 民數記 11:28; 出埃及記 3:1"> 於是，摩西帶著他的助手約書亞動身上了上帝的山。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及記 17:10; 出埃及記 17:12; 創世記 22:5"> 離開之前，摩西吩咐長老說：「你們在這裡等候我們回來。亞倫和戶珥跟你們在一起，民中有什麼訴訟的事情，可以去找他們。」</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及記 19:9; 馬太福音 17:5; 出埃及記 19:16"> 摩西上了山，密雲遮蓋著整座山。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 16:10; 民數記 16:42; 以西結書 1:28"> 耶和華的榮耀停留在西奈山上，密雲遮蓋了山六天。第七天，耶和華在雲中召喚摩西。</span>
<span className="v" id="v17" data-v="17" data-xref="希伯來書 12:29; 申命記 4:24; 出埃及記 3:2"> 在以色列人眼中，耶和華的榮耀在山上好像烈火。</span>
<span className="v" id="v18" data-v="18" data-xref="申命記 9:9; 出埃及記 34:28; 申命記 10:10"> 摩西上到山上，走進雲中，在那裡停留了四十晝夜。</span>

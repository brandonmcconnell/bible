## 賠償條例

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 19:8; 撒母耳記下 12:6; 箴言 6:31"> 「倘若有人偷了別人的牛羊，然後宰了或賣了，他要用五頭牛抵償一頭牛，四隻羊抵償一隻羊。</span>
<span className="v" id="v2" data-v="2" data-xref="馬太福音 24:43; 馬太福音 6:19–20; 民數記 35:27"> 倘若有人打死正入屋偷竊的賊，這人不算犯殺人罪。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 21:2; 以賽亞書 50:1; 馬太福音 18:25"> 倘若事情發生在白天，家主就犯了殺人罪。倘若盜賊被擒，他就要賠償家主，若他一無所有，就要把他賣為奴隸作賠償。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及記 22:7; 出埃及記 22:1; 出埃及記 22:9"> 倘若他偷的牲畜如牛、羊或驢在他手上還活著，他要償還失主雙倍。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="出埃及記 22:3; 出埃及記 22:12; 約伯記 20:18"> 「倘若有人在田野或葡萄園裡牧放牲畜，任由牲畜吃別人田裡的農作物或葡萄，他必須拿自己田裡最好的農作物或葡萄作賠償。</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及記 22:9; 出埃及記 21:33–34; 撒母耳記下 14:30–31"> 倘若田間起火，燒著荊棘，以致燒掉了別人的莊稼、禾捆或整個田園，那點火的人就要賠償一切損失。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="出埃及記 22:4; 箴言 6:30–31; 耶利米書 2:26"> 「倘若有人把金錢或物件交給鄰居保管，結果在鄰居家遭盜，盜賊被緝拿歸案後要賠償雙倍；</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及記 22:28; 申命記 16:18; 出埃及記 21:6"> 倘若沒捉到盜賊，鄰居就要到審判官那裡證明自己沒有偷拿。</span>
<span className="v" id="v9" data-v="9" data-xref="申命記 25:1; 出埃及記 22:4; 民數記 5:6–7"> 倘若二人之間有什麼糾紛，無論是為了牛、驢、羊、衣服或任何失物，爭執的雙方要把案件呈報審判官，審判官判誰敗訴，誰就要賠償雙倍。</span>
<span className="v" id="v10" data-v="10" data-xref="路加福音 12:48; 提摩太後書 1:12; 路加福音 16:11"> 倘若有人把驢、牛、羊或別的牲畜交給鄰居看管，牲畜死傷或被人搶走，並且無人看見，</span>
<span className="v" id="v11" data-v="11" data-xref="希伯來書 6:16; 利未記 5:1; 列王紀上 2:42–43"> 看守的人就要在耶和華面前起誓沒有動鄰居的東西，這樣失主就應當作罷，看守的人不用賠償。</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 31:39; 出埃及記 22:7"> 但倘若牲畜是被人偷去的，受託人就要賠償失主。</span>
<span className="v" id="v13" data-v="13" data-xref="那鴻書 2:12; 彌迦書 5:8; 以西結書 4:14"> 倘若牲畜被野獸撕碎，受託人要把殘骸帶來當證據，無需賠償被撕碎的牲畜。</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 23:19–20; 出埃及記 21:34; 申命記 15:2"> 倘若有人向鄰居借牲畜，牲畜受傷或死掉，而當時物主不在場，借的人就要賠償。</span>
<span className="v" id="v15" data-v="15" data-xref="撒迦利亞書 8:10"> 倘若物主當時在場，借的人就不用賠償。倘若牲畜是租來的，租的人只需付租金不用賠償。</span>
</div>
</div>

## 社會條例

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="申命記 22:28–29; 創世記 34:2–4"> 「倘若有人誘姦了尚未許配的處女，他就要交出聘禮，娶她為妻；</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 34:12; 撒母耳記上 18:25; 申命記 22:29"> 倘若女方家長反對婚事，男方要付出與聘禮等額的金錢給女方家長。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="利未記 20:27; 申命記 18:10–11; 撒母耳記上 28:3"> 「凡行邪術的女人，必須被處死。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="利未記 18:23; 申命記 27:21; 利未記 20:15–16"> 「與動物性交的人，必須被處死。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="申命記 17:2–5; 民數記 25:7–8; 申命記 18:20"> 「獻祭給耶和華以外的其他任何神明的人，必須被處死。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="出埃及記 23:9; 申命記 10:19; 利未記 19:33"> 「不可欺壓在你們中間寄居的人，因為你們在埃及也做過寄居的人。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="申命記 24:17; 以賽亞書 1:17; 以賽亞書 1:23"> 「不可虧待寡婦和孤兒，</span>
<span className="v" id="v23" data-v="23" data-xref="詩篇 18:6; 詩篇 10:17–18; 路加福音 18:7"> 倘若你們虧待他們，他們向我呼求，我必聽他們的呼求，</span>
<span className="v" id="v24" data-v="24" data-xref="詩篇 109:9; 耶利米書 15:8; 詩篇 76:7"> 向你們發怒，用刀殺掉你們，使你們的妻子變為寡婦，兒女成為孤兒。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="詩篇 15:5; 利未記 25:35–37; 申命記 23:19–20"> 「倘若有貧苦的同胞向你借錢，你不可像放債的一樣收取利息。</span>
<span className="v" id="v26" data-v="26" data-xref="箴言 20:16; 阿摩司書 2:8; 申命記 24:6"> 倘若你的鄰居把衣服給你作抵押，你要在日落之前把衣服還給他。</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及記 34:6; 歷代志下 30:9; 詩篇 136:10–11"> 因為他只有這件蔽體的衣服，若是沒有，他晚上如何睡覺？他若呼求我，我必垂聽，因為我是仁慈的。</span>
<span className="v" id="v28" data-v="28" data-xref="使徒行傳 23:5; 傳道書 10:20; 出埃及記 22:8–9"> 不可褻瀆上帝，也不可咒詛百姓的官長。</span>
<span className="v" id="v29" data-v="29" data-xref="出埃及記 23:16; 出埃及記 13:2; 雅各書 1:18"> 你們要向我獻上五穀和新酒，不可遲延。要把你們的長子獻給我。</span>
<span className="v" id="v30" data-v="30" data-xref="利未記 22:27; 申命記 15:19; 出埃及記 13:12"> 也要獻上頭生的牛羊，牠們生下來後可以留在母親身邊七天，第八天要獻給我。</span>
<span className="v" id="v31" data-v="31" data-xref="以西結書 4:14; 利未記 19:2; 申命記 14:21"> 你們要做我聖潔的子民，不可吃田野間被野獸咬死的牲畜，要把牠丟給狗吃。</span>
</div>
</div>

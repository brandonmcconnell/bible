## 上帝呼召摩西

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀上 19:8; 出埃及記 17:6; 詩篇 78:70–72"> 摩西為岳父米甸祭司葉特羅放羊。一天他領著羊群穿越曠野，來到上帝的山——何烈山。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行傳 7:30–35; 以賽亞書 43:2; 馬可福音 12:26"> 忽然有耶和華的天使在荊棘的火焰中向他顯現。摩西看見荊棘雖然在燃燒，卻沒有被燒毀。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行傳 7:31; 詩篇 107:8; 約伯記 37:14"> 摩西想：「我要過去看這個奇異的景象，荊棘為什麼沒有被燒掉呢？」</span>
<span className="v" id="v4" data-v="4" data-xref="申命記 33:16; 撒母耳記上 3:6; 使徒行傳 9:4"> 耶和華上帝見他要上前觀看，就從荊棘叢中呼喚他說：「摩西！摩西！」摩西說：「我在這裡。」</span>
<span className="v" id="v5" data-v="5" data-xref="約書亞記 5:15; 使徒行傳 7:33; 出埃及記 19:12"> 上帝說：「別再靠近，脫下你腳上的鞋，因為你所站的地方是聖地。」</span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 20:37; 馬太福音 22:32; 出埃及記 4:5"> 又說：「我是你祖先的上帝，是亞伯拉罕的上帝，以撒的上帝，雅各的上帝。」摩西害怕看上帝，就把臉蒙起來。</span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 145:19; 詩篇 106:44; 出埃及記 2:23–25"> 耶和華說：「我已經看見我子民在埃及所受的苦難，聽見了他們因監工的壓迫而發出的呼求。我知道他們的痛苦。</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 50:24; 創世記 15:18–21; 出埃及記 3:17"> 我下來是要從埃及人手中救他們，帶他們離開那裡，到一個遼闊肥沃的奶蜜之鄉，就是現在迦南人、赫人、亞摩利人、比利洗人、希未人和耶布斯人居住的地方。</span>
<span className="v" id="v9" data-v="9" data-xref="箴言 22:22–23; 出埃及記 2:23; 出埃及記 1:13–14"> 現在，以色列人的呼求傳到我耳中，我也看到了埃及人怎樣壓迫他們。</span>
<span className="v" id="v10" data-v="10" data-xref="彌迦書 6:4; 撒母耳記上 12:6; 詩篇 105:26"> 現在去吧，我要派你到法老那裡，帶我的以色列子民出埃及。」</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳記上 18:18; 哥林多後書 3:5; 出埃及記 6:12"> 但摩西對上帝說：「我是誰啊？怎麼能去見法老，帶以色列人出埃及呢？」</span>
<span className="v" id="v12" data-v="12" data-xref="約書亞記 1:5; 羅馬書 8:31; 以賽亞書 41:10"> 上帝說：「我必與你同在，你帶百姓出埃及後，你們必在這座山上事奉我——這將是我派你去的證據。」</span>
<span className="v" id="v13" data-v="13" data-xref="箴言 30:4; 以賽亞書 9:6; 耶利米書 23:6"> 摩西問上帝：「假如我到以色列人那裡，對他們說，『你們祖先的上帝派我來你們這裡。』他們如果問我，『祂叫什麼名字？』我該怎樣回答他們呢？」</span>
<span className="v" id="v14" data-v="14" data-xref="約翰福音 8:58; 希伯來書 13:8; 啟示錄 1:8"> 上帝對摩西說：「我是自有永有者。你要這樣回答以色列人，『那位自有永有者派我到你們這裡。』」</span>
<span className="v" id="v15" data-v="15" data-xref="創世記 17:7–8; 希伯來書 13:8; 瑪拉基書 3:6"> 上帝又對摩西說：「你要告訴以色列人是我派遣你到他們那裡，我是他們祖先的上帝耶和華，是亞伯拉罕的上帝，以撒的上帝，雅各的上帝。耶和華是我的名字，直到永遠，世世代代的人都要這樣稱呼我。</span>
<span className="v" id="v16" data-v="16" data-xref="詩篇 8:4; 出埃及記 4:31; 出埃及記 4:29"> 你去招聚以色列的長老，對他們說，『你們祖先的上帝耶和華，就是亞伯拉罕、以撒、雅各的上帝向我顯現，說祂關切你們，知道你們在埃及的遭遇。</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 15:13–21; 創世記 50:24; 創世記 46:4"> 祂應許要帶領你們脫離在埃及所受的苦難，到迦南人、赫人、亞摩利人、比利洗人，希未人和耶布斯人住的地方，那裡是奶蜜之鄉。』</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及記 9:1; 出埃及記 7:16; 出埃及記 10:24–26"> 以色列的長老們必定聽從你的話，你就跟他們一起去見埃及王，對他說，『希伯來人的上帝耶和華向我們顯現。現在請你容許我們走三天的路程，到曠野去，向我們的上帝耶和華獻祭。』</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及記 5:2; 出埃及記 6:1; 出埃及記 7:1–14"> 我也知道除非我用大能的手向他施壓，不然埃及王不會讓你們離開。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行傳 7:36; 尼希米記 9:10; 出埃及記 9:15"> 因此，我必伸手行各種神蹟攻擊埃及，之後他必讓你們離開。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及記 12:36; 詩篇 105:37; 出埃及記 11:3"> 我必使埃及人恩待你們，好叫你們不致空手離開埃及。</span>
<span className="v" id="v22" data-v="22" data-xref="以西結書 39:10; 出埃及記 11:2; 出埃及記 12:35–36"> 你們的婦女只管向埃及鄰居及住在鄰居家的婦女索取金器、銀器和衣服，給自己的兒女穿戴，你們必這樣奪取埃及人的財物。」</span>

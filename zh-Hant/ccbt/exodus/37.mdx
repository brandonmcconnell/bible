## 約櫃

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及記 25:10–20; 出埃及記 26:33; 民數記 10:33–36"> 比撒列用皂莢木造了一個櫃，長一米一，寬七十釐米，高七十釐米。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 30:3"> 這櫃子裡外都包上純金，還鑲了一圈金邊。</span>
<span className="v" id="v3" data-v="3"> 他造了四個金環，安在櫃的四個腳上，每邊兩個環，</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行傳 9:15; 彼得前書 1:7; 民數記 4:14–15"> 又用皂莢木造了兩根橫槓，包上金，</span>
<span className="v" id="v5" data-v="5" data-xref="民數記 4:15; 撒母耳記下 6:3–7; 民數記 1:50"> 然後把橫槓穿過櫃兩邊的金環，便於抬櫃。</span>
<span className="v" id="v6" data-v="6" data-xref="希伯來書 9:5; 提多書 2:14; 羅馬書 3:25"> 他用純金造了一個施恩座，長一米一，寬七十釐米。</span>
<span className="v" id="v7" data-v="7" data-xref="以西結書 10:2; 詩篇 104:4; 詩篇 80:1"> 又用金子在施恩座的兩端打造兩個基路伯天使。</span>
<span className="v" id="v8" data-v="8"> 這兩個基路伯天使跟施恩座連在一起，在施恩座的兩端，</span>
<span className="v" id="v9" data-v="9" data-xref="約翰福音 1:51; 希伯來書 1:14; 創世記 28:12"> 面對面朝向施恩座，向上展開翅膀遮蓋施恩座。</span>
</div>
</div>

## 桌子

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="約翰福音 1:14; 以西結書 40:39–42; 瑪拉基書 1:12"> 他用皂莢木造了一張桌子，長九十釐米，寬四十五釐米，高七十釐米。</span>
<span className="v" id="v11" data-v="11"> 整張桌子都包上純金，四周鑲上金邊。</span>
<span className="v" id="v12" data-v="12"> 在桌子四周造一個八釐米寬的外框，外框鑲上金邊。</span>
<span className="v" id="v13" data-v="13"> 他又造四個金環，安在桌子四角的桌腿上，</span>
<span className="v" id="v14" data-v="14"> 金環靠近外框，以便穿橫槓抬桌子。</span>
<span className="v" id="v15" data-v="15"> 他用皂莢木造兩根橫槓，外面包金，用來抬桌子。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 25:29; 列王紀上 7:50; 列王紀下 12:13"> 又用純金造桌子上的器具，就是盤、碟及獻酒用的杯和瓶。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及記 25:31–39; 希伯來書 9:2; 歷代志下 13:11"> 他用純金造了一座燈臺，燈臺的燈座、燈柱、油杯、花瓣和花萼都是用一塊純金打成的。</span>
<span className="v" id="v18" data-v="18"> 燈臺兩邊各伸出三個分枝，共六個分枝。</span>
<span className="v" id="v19" data-v="19"> 每個分枝上都有三個杏花形狀、有花瓣和花萼的杯，六個分枝都是這樣。</span>
<span className="v" id="v20" data-v="20" data-xref="傳道書 12:5; 耶利米書 1:11; 出埃及記 25:33"> 燈臺上有四個杏花形狀、有花瓣和花萼的杯。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及記 25:35"> 燈臺上每一對分枝的相連處有花萼，三對分枝都是這樣。</span>
<span className="v" id="v22" data-v="22" data-xref="歌羅西書 3:5; 出埃及記 25:31; 詩篇 51:17"> 整座燈臺，包括花萼和分枝，都是用一塊純金打成的。</span>
<span className="v" id="v23" data-v="23" data-xref="啟示錄 1:12; 出埃及記 25:37; 啟示錄 1:20–1"> 他又用純金為這座燈臺造了七個燈盞，以及燈剪和燈花盤。</span>
<span className="v" id="v24" data-v="24"> 造整座燈臺和燈臺的器具共用了六百八十兩純金。</span>
</div>
</div>

## 造香壇

<div className="bt">
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="出埃及記 30:1–5; 希伯來書 7:25; 啟示錄 8:3–4"> 他又用皂莢木造了一座方形的香壇，長寬各四十五釐米，高九十釐米，壇上面凸起的四角與壇連成一體，</span>
<span className="v" id="v26" data-v="26"> 壇頂、壇的四面和壇上凸起的角包上純金，四周鑲上金邊。</span>
<span className="v" id="v27" data-v="27"> 他造了兩個金環，安在壇兩側的金邊下面，</span>
<span className="v" id="v28" data-v="28"> 又用皂莢木造橫槓，包上金，穿在兩個環裡，用來抬香壇。</span>
<span className="v" id="v29" data-v="29" data-xref="詩篇 141:2; 希伯來書 7:25; 約翰一書 2:20"> 他又用調製香料的方法製作聖膏油和純淨芬芳的香。</span>
</div>
</div>

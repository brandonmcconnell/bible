## 在彼拉多面前受審

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="馬太福音 27:1–2; 馬太福音 27:11–14; 路加福音 22:66"> 於是，眾人動身把耶穌押到彼拉多那裡，</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行傳 17:6–7; 約翰福音 19:12; 路加福音 23:14"> 開始指控祂說：「這人蠱惑民心，禁止百姓向凱撒納稅，又說自己是基督，是君王。」</span>
<span className="v" id="v3" data-v="3" data-xref="約翰福音 1:49; 提摩太前書 6:13; 路加福音 22:70"> 彼拉多問耶穌：「你是猶太人的王嗎？」 耶穌回答說：「如你所言。」</span>
<span className="v" id="v4" data-v="4" data-xref="約翰福音 18:38; 路加福音 23:14–15; 路加福音 23:22"> 於是彼拉多對祭司長和百姓說：「我查不出這人有什麼罪。」</span>
<span className="v" id="v5" data-v="5" data-xref="馬可福音 1:14; 約翰福音 1:43; 約翰福音 2:11"> 但他們堅持說：「這個人從加利利開始一直到這裡，在猶太地區四處傳道，煽動民心。」</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行傳 5:37; 路加福音 13:1"> 彼拉多聽後，問道：「祂是加利利人嗎？」</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 3:1; 路加福音 13:31; 馬太福音 14:1"> 他得知耶穌來自分封王希律的轄區後，便把耶穌送交希律，那時希律剛巧在耶路撒冷。</span>
</div>
</div>

## 在希律面前受辱

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="路加福音 9:7–9; 馬太福音 14:1; 馬可福音 6:14"> 希律見到耶穌，十分高興，因為他聽過耶穌的事，早就想見祂，希望看祂行神蹟。</span>
<span className="v" id="v9" data-v="9" data-xref="馬太福音 27:14; 馬太福音 7:6; 彼得前書 2:23"> 他問了耶穌許多問題，耶穌卻一言不發。</span>
<span className="v" id="v10" data-v="10" data-xref="路加福音 11:53; 路加福音 23:14–15; 路加福音 23:5"> 祭司長和律法教師站在那裡極力地指控耶穌。</span>
<span className="v" id="v11" data-v="11" data-xref="馬可福音 15:16–20; 馬太福音 27:27–30; 詩篇 69:19–20"> 希律和他的衛兵嘲弄、侮辱耶穌，給祂穿上華麗的袍子，把祂押回彼拉多那裡。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行傳 4:27; 啟示錄 17:13–14; 詩篇 83:4–6"> 希律和彼拉多向來互相敵視，但在那一天竟化敵為友。</span>
</div>
</div>

## 無辜被判死罪

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="馬可福音 15:14; 馬太福音 27:21–23; 約翰福音 18:38"> 彼拉多召來祭司長、官長和百姓，</span>
<span className="v" id="v14" data-v="14" data-xref="但以理書 6:4; 希伯來書 7:26; 路加福音 23:1–2"> 對他們說：「你們帶這個人來，說祂煽動百姓造反。我當著你們的面審問了祂，卻查不出祂有任何你們指控的罪。</span>
<span className="v" id="v15" data-v="15"> 希律也查不出祂有什麼罪，所以把祂送回來了。可見，這人並沒有犯什麼該死的罪。</span>
<span className="v" id="v16" data-v="16" data-xref="馬太福音 27:26; 路加福音 23:22; 馬可福音 15:15"> 因此，我要懲戒祂，然後釋放祂。」</span>
<span className="v" id="v17" data-v="17"> 每逢逾越節，總督必須給他們釋放一個囚犯。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古卷無17節。">a</a></sup></span>
<span className="v" id="v18" data-v="18" data-xref="使徒行傳 21:36; 使徒行傳 3:14; 使徒行傳 22:22"> 這時，眾人齊聲呼喊：「除掉這個人！給我們釋放巴拉巴！」</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行傳 3:14; 路加福音 23:5; 路加福音 23:2"> 巴拉巴是因在城裡叛亂殺人而被下在監牢的。</span>
<span className="v" id="v20" data-v="20" data-xref="馬可福音 15:15; 馬太福音 14:8–9; 馬太福音 27:19"> 彼拉多想釋放耶穌，便再次勸解他們。</span>
<span className="v" id="v21" data-v="21" data-xref="馬太福音 27:22–25; 馬可福音 15:13; 約翰福音 19:15"> 但他們一直喊：「把祂釘在十字架上！把祂釘在十字架上！」</span>
<span className="v" id="v22" data-v="22" data-xref="路加福音 23:14; 路加福音 23:20; 彼得前書 3:18"> 彼拉多第三次問百姓：「為什麼？祂犯了什麼罪？我找不出該處死祂的罪證。因此，我要懲戒祂，然後釋放祂。」</span>
<span className="v" id="v23" data-v="23" data-xref="撒迦利亞書 11:8; 詩篇 57:4; 詩篇 22:12–13"> 眾人卻繼續大聲喊叫，執意要求把耶穌釘在十字架上。最後，他們的聲勢佔了上風。</span>
<span className="v" id="v24" data-v="24" data-xref="馬太福音 27:26; 出埃及記 23:2; 箴言 17:15"> 於是，彼拉多決定答應他們的要求。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行傳 3:14; 馬可福音 15:6–7; 馬可福音 15:15"> 他釋放了叛亂殺人的囚犯巴拉巴，並把耶穌交給他們任意處置。</span>
</div>
</div>

## 釘十字架

<div className="bt">
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="馬太福音 27:32–44; 馬可福音 15:21–32; 使徒行傳 6:9"> 他們帶耶穌出去的時候，抓住從鄉下來的古利奈人西門，讓他背著十字架跟在耶穌後面。</span>
<span className="v" id="v27" data-v="27" data-xref="路加福音 8:52; 路加福音 8:2; 馬可福音 15:40"> 有一大群人跟在耶穌後面，其中有不少婦女為耶穌捶胸痛哭。</span>
<span className="v" id="v28" data-v="28" data-xref="雅歌 8:4; 雅歌 5:8; 雅歌 1:5"> 耶穌轉過身來，對她們說：「耶路撒冷的女兒啊，不要為我哭，為你們自己和你們的兒女哭吧！</span>
<span className="v" id="v29" data-v="29" data-xref="馬太福音 24:19; 路加福音 21:23–24; 馬可福音 13:17–19"> 因為日子快到了，人們將說，『不曾生育、不曾懷孕、不曾哺乳的女子有福了！』</span>
<span className="v" id="v30" data-v="30" data-xref="啟示錄 6:16; 何西阿書 10:8; 以賽亞書 2:19"> 到時候，人們會向大山說，『倒在我們身上吧！』<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="何西阿書10·8。">b</a></sup>又會對小山說，『遮蓋我們吧！』</span>
<span className="v" id="v31" data-v="31" data-xref="彼得前書 4:17–18; 約翰福音 15:6; 箴言 11:31"> 樹木青蔥的時候，他們尚且做這些事，樹木枯乾的時候，又會怎樣呢？<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="此句或譯「他們尚且如此對待青蔥的樹木，將來又會怎樣對待枯乾的樹木呢？」">c</a></sup>」</span>
<span className="v" id="v32" data-v="32" data-xref="馬可福音 15:27; 以賽亞書 53:12; 馬太福音 27:38"> 當時有兩個罪犯和耶穌一同被押去受刑。</span>
<span className="v" id="v33" data-v="33" data-xref="馬可福音 15:22–23; 約翰福音 19:17–18; 約翰福音 18:32"> 他們到了一個叫「髑髏」的地方，便把耶穌釘在十字架上，又將兩個罪犯分別釘在祂左右兩邊。</span>
<span className="v" id="v34" data-v="34" data-xref="馬太福音 5:44; 使徒行傳 7:60; 彼得前書 3:9"> 耶穌說：「父啊，赦免他們！因為他們不知道自己在做什麼。」士兵抽籤分了耶穌的衣裳。</span>
<span className="v" id="v35" data-v="35" data-xref="詩篇 22:17; 以賽亞書 42:1; 彼得前書 2:4"> 百姓站著觀看，官長也嘲笑耶穌說：「祂救了別人，如果祂是上帝所選立的基督，讓祂救自己吧！」</span>
<span className="v" id="v36" data-v="36" data-xref="詩篇 69:21; 馬太福音 27:48; 馬太福音 27:34"> 士兵們也戲弄祂，拿了些酸酒上前給祂喝，</span>
<span className="v" id="v37" data-v="37"> 又說：「如果你是猶太人的王，救救自己呀！」</span>
<span className="v" id="v38" data-v="38" data-xref="馬可福音 15:26; 馬太福音 27:37; 約翰福音 19:19–22"> 耶穌上方有一塊牌子，上面寫著：「這是猶太人的王。」</span>
<span className="v" id="v39" data-v="39" data-xref="馬太福音 27:44; 馬可福音 15:32; 路加福音 23:35"> 跟耶穌同釘十字架的一個罪犯也譏笑耶穌，說：「你不是基督嗎？救你自己和我們呀！」</span>
<span className="v" id="v40" data-v="40" data-xref="以弗所書 5:11; 路加福音 12:5; 啟示錄 15:4"> 另一個罪犯卻責備他說：「你同樣是受刑的，難道不怕上帝嗎？</span>
<span className="v" id="v41" data-v="41" data-xref="利未記 26:40–41; 以斯拉記 9:13; 彼得前書 1:19"> 我們是罪有應得，但這個人沒有任何過犯。」</span>
<span className="v" id="v42" data-v="42" data-xref="羅馬書 10:9–14; 使徒行傳 16:31; 約翰一書 5:11–13"> 他對耶穌說：「耶穌啊，當你來執掌王權的時候，請你記得我。」</span>
<span className="v" id="v43" data-v="43" data-xref="啟示錄 2:7; 詩篇 50:15; 提摩太前書 1:15–16"> 耶穌對他說：「我實在告訴你，今天你要和我一起在樂園裡了。」</span>
</div>
</div>

## 耶穌之死

<div className="bt">
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="馬太福音 27:45; 馬可福音 15:33–34; 阿摩司書 8:9"> 那時大約是正午，黑暗籠罩著整個大地，一直到下午三點，</span>
<span className="v" id="v45" data-v="45" data-xref="希伯來書 10:19–22; 馬太福音 27:51; 希伯來書 9:3–8"> 太陽黯然無光。掛在聖殿裡的幔子從中間裂成兩半。</span>
<span className="v" id="v46" data-v="46" data-xref="詩篇 31:5; 使徒行傳 7:59; 約翰福音 19:30"> 耶穌大聲呼喊：「父啊，我將我的靈魂交在你手中。」<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="詩篇31·5。">d</a></sup>說完，就斷了氣。</span>
<span className="v" id="v47" data-v="47" data-xref="馬太福音 27:54; 馬可福音 15:39; 路加福音 23:41"> 百夫長見此情形，便讚美上帝，說：「這人的確是個義人。」</span>
<span className="v" id="v48" data-v="48" data-xref="路加福音 18:13; 使徒行傳 2:37; 耶利米書 31:19"> 圍觀的人見狀無不捶胸頓足，黯然離去。</span>
<span className="v" id="v49" data-v="49" data-xref="路加福音 8:2; 詩篇 38:11; 路加福音 23:55"> 耶穌熟識的人和從加利利跟著祂來的婦女們都站在遠處觀看。</span>
</div>
</div>

## 耶穌的安葬

<div className="bt">
<div className="bp">
<span className="v" id="v50" data-v="50" data-xref="約翰福音 19:38–42; 使徒行傳 11:24; 使徒行傳 10:22"> 有一位名叫約瑟的公會議員心地善良、為人正直，</span>
<span className="v" id="v51" data-v="51" data-xref="路加福音 2:25; 路加福音 2:38; 以賽亞書 8:12"> 住在猶太地區的亞利馬太城，一直在等候上帝國的降臨。他並不認同公會的決定和行動。</span>
<span className="v" id="v52" data-v="52" data-xref="約翰福音 19:38–42"> 他去求見彼拉多，要求領取耶穌的遺體。</span>
<span className="v" id="v53" data-v="53" data-xref="馬太福音 27:59–60; 以賽亞書 53:9; 馬可福音 15:46"> 他把耶穌的遺體取下來，用細麻布裹好，然後安放在一個在巖壁上鑿出的新墓穴裡。</span>
<span className="v" id="v54" data-v="54" data-xref="馬太福音 27:62; 約翰福音 19:31; 馬可福音 15:42"> 當天是預備日，安息日快到了。</span>
<span className="v" id="v55" data-v="55" data-xref="路加福音 23:49; 馬太福音 27:61; 馬可福音 15:47"> 和耶穌一起從加利利來的婦女跟在約瑟後面，看到了耶穌的墳墓，並且看到祂的遺體被安放好之後，</span>
<span className="v" id="v56" data-v="56" data-xref="路加福音 24:1; 馬可福音 16:1; 申命記 5:14"> 便回去預備香料和膏油。安息日到了，她們按律法的規定休息了一天。</span>
</div>

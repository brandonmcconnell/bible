## 窮寡婦的奉獻

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="馬可福音 12:41–44; 約翰福音 8:20; 馬太福音 27:6"> 耶穌抬頭觀看，見有錢人正把捐項投進奉獻箱裡，</span>
<span className="v" id="v2" data-v="2" data-xref="馬可福音 12:42"> 又見一個窮寡婦投進兩個小銅錢，</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多後書 8:12; 使徒行傳 10:34; 哥林多後書 8:2–3"> 就說：「我實在告訴你們，這位窮寡婦奉獻的比其他人都多。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行傳 2:44–45; 路加福音 15:12; 使徒行傳 4:34"> 因為他們不過奉獻了自己富餘的，但這窮寡婦奉獻了她賴以為生的一切。」</span>

## 預言將來的事

<div className="bt">
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="約翰福音 2:20; 馬太福音 24:1–51; 馬可福音 13:1–37"> 有些人正在談論由精美的石頭和珍貴的供物所裝飾的聖殿，</span>
<span className="v" id="v6" data-v="6" data-xref="馬太福音 24:2; 馬可福音 13:2; 耶利米哀歌 5:18"> 耶穌說：「你們現在所見到的，將來有一天要被完全拆毀，找不到兩塊疊在一起的石頭。」</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行傳 1:6–7; 馬可福音 13:14; 馬可福音 13:3–4"> 他們問：「老師，這些事什麼時候會發生？發生的時候有什麼預兆？」</span>
<span className="v" id="v8" data-v="8" data-xref="約翰一書 4:1; 馬可福音 13:5–6; 以弗所書 5:6"> 耶穌回答說：「你們要小心提防，不要被迷惑。因為將來會有許多人冒我的名來，說，『我是基督』，或說，『時候到了』，你們切勿跟從他們。</span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 21:28; 馬太福音 24:6–8; 馬可福音 13:7–8"> 你們聽見打仗和叛亂的事，不要害怕，因為這些事一定會先發生，但末日將不會立刻來臨。」</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行傳 2:19–20; 馬可福音 13:8; 歷代志下 15:5–6"> 耶穌接著說：「民族將攻打民族，國家將攻打國家，</span>
<span className="v" id="v11" data-v="11" data-xref="馬太福音 24:29–30; 路加福音 21:25–27"> 將有大地震，各處將有饑荒和瘟疫，天上也將出現恐怖的景象和大異兆。</span>
<span className="v" id="v12" data-v="12" data-xref="彼得前書 4:12–14; 使徒行傳 5:40; 使徒行傳 22:30"> 「這些事情出現之前，人們要拘捕你們，迫害你們，把你們押到會堂和監牢，你們將為了我的名被君王和官長審問。</span>
<span className="v" id="v13" data-v="13" data-xref="腓立比書 1:12; 腓立比書 1:28; 帖撒羅尼迦後書 1:5"> 那時，正是你們為我作見證的機會。</span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 12:11–12; 馬可福音 13:11; 馬太福音 10:19–20"> 你們要立定心志，不要先思慮如何申辯，</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米書 1:9; 以弗所書 6:19; 路加福音 12:12"> 因為我會賜給你們口才、智慧，使你們的仇敵全無反駁的餘地。</span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 12:53; 啟示錄 6:9; 彌迦書 7:5–6"> 你們將被父母、弟兄、親戚、朋友出賣，你們有些人會被他們害死。</span>
<span className="v" id="v17" data-v="17" data-xref="約翰福音 15:19; 路加福音 6:22; 約翰福音 15:21"> 你們將為我的名而被眾人憎恨，</span>
<span className="v" id="v18" data-v="18" data-xref="馬太福音 10:30; 撒母耳記上 14:45; 路加福音 12:7"> 但你們連一根頭髮也不會失落。</span>
<span className="v" id="v19" data-v="19" data-xref="希伯來書 10:36; 馬太福音 10:22; 雅各書 1:3"> 你們只要堅忍到底，必能保全自己的靈魂。</span>
<span className="v" id="v20" data-v="20" data-xref="路加福音 19:43; 但以理書 9:27; 馬可福音 13:14"> 「你們看見耶路撒冷被重兵包圍時，就知道它被毀滅的日子快到了。</span>
<span className="v" id="v21" data-v="21" data-xref="耶利米書 6:1; 創世記 19:17; 路加福音 17:31–33"> 那時，猶太地區的人要逃到山上去，城裡的人要跑到城外，鄉村的人不要進城，</span>
<span className="v" id="v22" data-v="22" data-xref="何西阿書 9:7; 以賽亞書 65:12–16; 以賽亞書 63:4"> 因為那是報應的日子，要應驗聖經的全部記載。</span>
<span className="v" id="v23" data-v="23" data-xref="馬可福音 13:17; 馬太福音 24:19; 路加福音 23:29"> 那時，孕婦和哺育嬰兒的母親們可就遭殃了！因為將有大災難降在這地方，烈怒要臨到這些百姓。</span>
<span className="v" id="v24" data-v="24" data-xref="羅馬書 11:25; 啟示錄 11:2; 以賽亞書 63:18"> 他們要喪身刀下，要被擄到列國去。耶路撒冷要被外族人踐踏，直到外族人肆虐的日期滿了為止。</span>
<span className="v" id="v25" data-v="25" data-xref="以賽亞書 13:10; 約珥書 2:30–31; 啟示錄 6:12–14"> 「日月星辰必顯出異兆，怒海洶湧、波濤翻騰，令各國驚恐不安。</span>
<span className="v" id="v26" data-v="26" data-xref="馬太福音 24:29; 申命記 28:65–67; 彼得後書 3:10–12"> 天體必震動，人類想到世界要面臨的事都嚇得魂不附體。</span>
<span className="v" id="v27" data-v="27" data-xref="馬太福音 24:30; 啟示錄 1:7; 馬可福音 13:26"> 那時，他們要看見人子駕著雲、帶著能力和極大的榮耀降臨。</span>
<span className="v" id="v28" data-v="28" data-xref="羅馬書 8:23; 以賽亞書 60:1–2; 以弗所書 4:30"> 當這些事發生時，你們要昂首挺胸，因為你們蒙救贖的日子近了。」</span>
</div>
</div>

## 警醒禱告

<div className="bt">
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="馬太福音 24:32–35; 馬可福音 13:28–30"> 耶穌又講了一個比喻：「你們看無花果樹及其他樹木，</span>
<span className="v" id="v30" data-v="30" data-xref="路加福音 12:57"> 你們看見它們發芽長葉，就知道夏天近了。</span>
<span className="v" id="v31" data-v="31" data-xref="雅各書 5:9; 希伯來書 10:37; 彼得前書 4:7"> 同樣，你們看見這些事情發生時，就知道上帝的國近了。</span>
<span className="v" id="v32" data-v="32" data-xref="馬可福音 13:30; 馬太福音 24:34; 馬太福音 23:36"> 「我實在告訴你們，這個世代還沒有過去，這一切都要發生。</span>
<span className="v" id="v33" data-v="33" data-xref="以賽亞書 40:8; 馬可福音 13:31; 馬太福音 24:35"> 天地都要消逝，但我的話永不消逝。</span>
<span className="v" id="v34" data-v="34" data-xref="馬可福音 4:19; 路加福音 12:45–46; 路加福音 12:40"> 「你們要小心，不要被宴樂、醉酒和人生的掛慮拖累你們的心，免得那日子像網羅般突然臨到你們，</span>
<span className="v" id="v35" data-v="35" data-xref="啟示錄 16:15; 詩篇 11:6; 耶利米書 48:43–44"> 因為那日子將要臨到世上每一個人。</span>
<span className="v" id="v36" data-v="36" data-xref="約翰一書 2:28; 馬太福音 25:13; 彼得前書 5:8"> 你們要時刻警醒，常常禱告，使你們能逃過這一切將要發生的災難，並能站在人子面前。」</span>
<span className="v" id="v37" data-v="37" data-xref="路加福音 22:39; 馬可福音 11:19; 馬太福音 21:17"> 耶穌每天在聖殿裡講道，晚上則到城外的橄欖山上過夜。</span>
<span className="v" id="v38" data-v="38" data-xref="約翰福音 8:1–2"> 百姓一早都趕去聖殿聽祂的教導。</span>
</div>
</div>

## 耶穌降生伯利恆

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 3:1; 馬太福音 24:14; 使徒行傳 25:21"> 那時候，凱撒奧古斯都頒下諭旨，命羅馬帝國的百姓都登記戶口。</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 3:1; 馬太福音 4:24; 使徒行傳 26:30"> 這是第一次戶口登記，正值居里紐任敘利亞總督。</span>
<span className="v" id="v3" data-v="3"> 人們都回到本鄉辦理戶口登記。</span>
<span className="v" id="v4" data-v="4" data-xref="彌迦書 5:2; 約翰福音 7:42; 撒母耳記上 16:1"> 約瑟因為是大衛家族的人，就從加利利的拿撒勒鎮趕到猶太地區大衛的故鄉伯利恆，</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 22:22–27; 馬太福音 1:18–19"> 要和已許配給他、懷著身孕的瑪麗亞一起登記。</span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 33:11; 啟示錄 12:1–5; 彌迦書 5:2"> 他們在那裡的時候，瑪麗亞產期到了，</span>
<span className="v" id="v7" data-v="7" data-xref="加拉太書 4:4; 哥林多後書 8:9; 以賽亞書 53:2–3"> 便生下第一胎，是個兒子。她用布把孩子裹好，放在馬槽裡，因為客房沒有地方了。</span>
</div>
</div>

## 牧羊人和天使

<div className="bt">
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="創世記 31:39–40; 詩篇 78:70–71; 撒母耳記上 17:34–35"> 當晚，伯利恆郊外有一群牧羊人正在看守羊群。</span>
<span className="v" id="v9" data-v="9" data-xref="以賽亞書 60:1; 哥林多後書 3:18; 列王紀上 8:11"> 忽然，主的天使向他們顯現，主的榮光四面照著他們，他們非常害怕。</span>
<span className="v" id="v10" data-v="10" data-xref="以賽亞書 40:9; 以賽亞書 61:1; 以賽亞書 52:7"> 天使對他們說：「不要害怕！我告訴你們一個有關萬民的大喜訊，</span>
<span className="v" id="v11" data-v="11" data-xref="以賽亞書 9:6; 馬太福音 1:21; 使徒行傳 2:36"> 今天在大衛的城裡有一位救主為你們降生了，祂就是主基督！</span>
<span className="v" id="v12" data-v="12" data-xref="以賽亞書 7:14; 以賽亞書 53:1–2; 以賽亞書 7:11"> 你們將看見一個嬰孩包著布躺在馬槽裡，這就是給你們的記號。」</span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 103:20–21; 啟示錄 5:11; 詩篇 148:2"> 忽然，有一大隊天軍出現，與那天使一同讚美上帝說：</span>
<span className="v" id="v14" data-v="14" data-xref="羅馬書 5:1; 路加福音 19:38; 歌羅西書 1:20"> <span className="pl pl-1">「在至高之處榮耀歸於上帝！</span><br /><span className="pl pl-1">在地上平安臨到祂所喜悅的人！」</span></span>
<span className="v" id="v15" data-v="15" data-xref="彼得前書 3:22; 馬太福音 2:1–2; 馬太福音 2:9–11"> 眾天使離開他們升回天上之後，牧羊人便商議說：「我們現在去伯利恆，看看主告訴我們的這件已發生的事吧！」</span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 19:32; 路加福音 2:12; 路加福音 2:7"> 他們就連忙進城，找到了瑪麗亞和約瑟以及躺在馬槽裡的嬰孩。</span>
<span className="v" id="v17" data-v="17" data-xref="詩篇 66:16; 路加福音 8:39; 詩篇 71:17–18"> 他們看過之後，就把天使告訴他們有關這嬰孩的事傳開了。</span>
<span className="v" id="v18" data-v="18" data-xref="路加福音 2:47; 路加福音 4:36; 路加福音 1:65–66"> 聽見的人都對牧羊人的話感到驚訝。</span>
<span className="v" id="v19" data-v="19" data-xref="路加福音 2:51; 路加福音 1:66; 箴言 4:4"> 但瑪麗亞把這些事牢記在心裡，反覆思想。</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 106:48; 以賽亞書 29:19; 使徒行傳 11:18"> 牧羊人就回去了，不住地讚美和歸榮耀給上帝，因為他們的所見所聞跟天使告訴他們的一樣。</span>
</div>
</div>

## 奉獻聖嬰

<div className="bt">
<div className="bp poetry">
<span className="v" id="v21" data-v="21" data-xref="路加福音 1:31; 創世記 17:12; 加拉太書 4:4–5"> 在第八天，嬰孩接受了割禮，祂的名字叫耶穌，是瑪麗亞懷孕前天使取的。</span>
<span className="v" id="v22" data-v="22" data-xref="利未記 12:1–8"> 摩西律法規定的潔淨期滿後，約瑟和瑪麗亞把嬰孩帶到耶路撒冷去獻給主，</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及記 13:2; 出埃及記 22:29; 民數記 3:13"> 因為主的律法規定：必須把長子分別出來獻給主<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="出埃及記13·2、12。">a</a></sup>。</span>
<span className="v" id="v24" data-v="24" data-xref="利未記 12:6–8; 利未記 12:2; 哥林多後書 8:9"> 他們又按照主的律法獻上祭物，即一對斑鳩或兩隻雛鴿<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="利未記12·8。">b</a></sup>。</span>
<span className="v" id="v25" data-v="25" data-xref="以賽亞書 25:9; 路加福音 2:38; 路加福音 1:6"> 耶路撒冷有一位公義敬虔、有聖靈同在的人名叫西緬，他一直期待著以色列的安慰者到來。</span>
<span className="v" id="v26" data-v="26" data-xref="約翰福音 8:51; 希伯來書 11:5; 路加福音 9:27"> 聖靈曾啟示他：他去世前必能親眼看見主所立的基督。</span>
<span className="v" id="v27" data-v="27" data-xref="馬太福音 4:1; 路加福音 2:41; 路加福音 2:51"> 那天，他受聖靈感動進入聖殿，看見約瑟和瑪麗亞抱著嬰孩耶穌進來，要依照律法的規定為祂行禮，</span>
<span className="v" id="v28" data-v="28" data-xref="路加福音 1:64; 路加福音 2:20; 路加福音 2:13–14"> 就把祂抱過來，稱頌上帝說：</span>
<span className="v" id="v29" data-v="29" data-xref="啟示錄 14:13; 創世記 15:15; 腓立比書 1:23"> <span className="pl pl-1">「主啊，現在可以照你的話，</span><br /><span className="pl pl-1">讓奴僕安然離世了，</span><br /></span>
<span className="v" id="v30" data-v="30" data-xref="以賽亞書 49:6; 路加福音 2:10–11; 路加福音 3:6"> <span className="pl pl-1">因為我已親眼看到你的救恩，</span><br /></span>
<span className="v" id="v31" data-v="31" data-xref="以賽亞書 62:1–2; 以賽亞書 42:1–4; 詩篇 98:2–3"> <span className="pl pl-1">就是你為萬民所預備的救恩。</span><br /></span>
<span className="v" id="v32" data-v="32" data-xref="以賽亞書 60:1–3; 以賽亞書 49:6; 使徒行傳 26:23"> <span className="pl pl-1">這救恩是啟示外族人的光，</span><br /><span className="pl pl-1">也是你以色列子民的榮耀。」</span></span>
<span className="v" id="v33" data-v="33" data-xref="路加福音 1:65–66; 以賽亞書 8:18; 路加福音 2:48"> 耶穌的父母聽見關於祂的這番話，感到驚奇。</span>
<span className="v" id="v34" data-v="34" data-xref="哥林多前書 1:23; 彼得前書 2:7–8; 以賽亞書 8:14–15"> 西緬給他們祝福後，就對孩子的母親瑪麗亞說：「看啊，這孩子必使以色列許多人跌倒、許多人興起。祂將成為眾人攻擊的對象，</span>
<span className="v" id="v35" data-v="35" data-xref="申命記 8:2; 哥林多前書 11:19; 馬太福音 12:24–35"> 好叫許多人的心思意念暴露出來，你自己則會心如刀割。」</span>
<span className="v" id="v36" data-v="36" data-xref="出埃及記 15:20; 創世記 30:13; 使徒行傳 21:9"> 亞設支派中有一位八十四歲高齡的女先知名叫亞拿，是法內利的女兒，婚後七年便開始守寡，之後一直住在聖殿裡，禁食禱告，日夜事奉上帝。</span>
<span className="v" id="v38" data-v="38" data-xref="路加福音 2:25; 哥林多後書 9:15; 馬可福音 15:43"> 正在那時，她也前來感謝上帝，並把耶穌的事報告給所有盼望耶路撒冷蒙救贖的人。</span>
<span className="v" id="v39" data-v="39" data-xref="路加福音 2:4; 加拉太書 4:4–5; 申命記 12:32"> 約瑟和瑪麗亞按照主的律法辦完一切事之後，就回到他們的家鄉加利利的拿撒勒。</span>
<span className="v" id="v40" data-v="40" data-xref="路加福音 2:52; 路加福音 1:80; 以賽亞書 11:1–5"> 耶穌漸漸長大，變得強健，充滿智慧，上帝的恩典與祂同在。</span>
</div>
</div>

## 少年耶穌聖殿論道

<div className="bt">
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="出埃及記 12:14; 民數記 28:16; 申命記 12:18"> 耶穌的父母每年都上耶路撒冷去過逾越節。</span>
<span className="v" id="v42" data-v="42"> 耶穌十二歲那年，跟父母照例上去過節。</span>
<span className="v" id="v43" data-v="43" data-xref="歷代志下 30:21–23; 出埃及記 12:15; 歷代志下 25:17"> 節期完了，祂父母便啟程回家，並不知道少年耶穌仍然留在耶路撒冷，</span>
<span className="v" id="v44" data-v="44" data-xref="詩篇 122:1–4; 以賽亞書 2:3; 詩篇 42:4"> 還以為祂跟在同行的人中間。他們走了一天的路後，才開始在親戚朋友中找祂，</span>
<span className="v" id="v45" data-v="45"> 結果沒有找到，只好回到耶路撒冷去找祂。</span>
<span className="v" id="v46" data-v="46" data-xref="路加福音 5:17; 以賽亞書 49:1–2; 以賽亞書 50:4"> 三天後，他們才在聖殿裡找到耶穌，祂正和教師們坐在一起，一邊聽一邊提問題。</span>
<span className="v" id="v47" data-v="47" data-xref="馬太福音 7:28; 路加福音 4:32; 詩篇 119:99"> 祂的聰慧和對答令聽見的人感到驚奇。</span>
<span className="v" id="v48" data-v="48" data-xref="路加福音 2:49; 馬太福音 12:46; 路加福音 3:23"> 約瑟和瑪麗亞看見耶穌在那裡，大為驚奇。 瑪麗亞對祂說：「兒子，你為什麼這樣對我們呢？你看，你父親和我急得到處找你！」</span>
<span className="v" id="v49" data-v="49" data-xref="約翰福音 6:38; 約翰福音 8:29; 瑪拉基書 3:1"> 耶穌對他們說：「你們為什麼找我呢？難道你們不知道我應該在我父的家嗎？」</span>
<span className="v" id="v50" data-v="50" data-xref="路加福音 18:34; 路加福音 9:45; 馬可福音 9:32"> 但他們不明白祂在講什麼。</span>
<span className="v" id="v51" data-v="51" data-xref="路加福音 2:19; 但以理書 7:28; 創世記 37:11"> 於是，耶穌隨父母回到拿撒勒，並順從他們。瑪麗亞把這一切事牢記在心。</span>
<span className="v" id="v52" data-v="52" data-xref="路加福音 2:40; 箴言 3:3–4; 撒母耳記上 2:26"> 耶穌的智慧和身量不斷增長，越來越受上帝和人們的喜愛。</span>
</div>

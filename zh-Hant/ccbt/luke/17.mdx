## 論罪、信心和本分

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="馬太福音 18:7; 羅馬書 14:13; 哥林多前書 11:19"> 耶穌教導門徒說：「引人犯罪的事是免不了的，但引人犯罪的人有禍了。</span>
<span className="v" id="v2" data-v="2" data-xref="馬可福音 9:42; 馬太福音 18:14; 馬太福音 18:3–6"> 誰使一個卑微的人失足犯罪，他的下場比把大磨石拴在他脖子上扔到海裡還要慘。</span>
<span className="v" id="v3" data-v="3" data-xref="利未記 19:17; 馬太福音 18:21; 馬太福音 18:15–17"> 你們要小心謹慎！你的弟兄若犯了罪，要責備他。他若悔改，要饒恕他。</span>
<span className="v" id="v4" data-v="4" data-xref="歌羅西書 3:12–13; 馬太福音 18:21–22; 羅馬書 12:20"> 就算他一天得罪你七次，每次都對你說，『我悔改』，你都要饒恕他。」</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="馬可福音 9:24; 希伯來書 12:2; 腓立比書 4:13"> 使徒對主說：「請你加添我們的信心。」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="馬太福音 17:20; 馬太福音 21:21; 馬可福音 9:23"> 主說：「你們若有芥菜種那麼大的信心，就算叫這棵桑樹連根拔起，栽在大海裡，它也會服從你們。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="馬太福音 12:11; 路加福音 13:15; 路加福音 14:5"> 「你們誰會對種田或放羊回來的奴僕說，『請趕快坐下來吃飯』？</span>
<span className="v" id="v8" data-v="8" data-xref="路加福音 12:37; 創世記 43:16; 撒母耳記下 12:20"> 不都是吩咐他『給我準備晚飯，束上腰帶伺候我，等我吃喝完畢，你才可以吃喝』嗎？</span>
<span className="v" id="v9" data-v="9"> 奴僕照著吩咐去做，主人會謝他嗎？</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多前書 9:16–17; 約伯記 22:2–3; 彼得前書 5:5–6"> 同樣，你們按吩咐把所有事情辦妥後，也該這樣說，『我們是無用的奴僕，所做的不過是分內的事。』」</span>
</div>
</div>

## 十個痲瘋病人

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="路加福音 9:51–52; 約翰福音 4:3–4"> 耶穌繼續前往耶路撒冷，途經撒瑪利亞和加利利的交界處。</span>
<span className="v" id="v12" data-v="12" data-xref="利未記 13:45–46; 路加福音 5:12; 列王紀下 7:3"> 祂進入一個村莊時，十個痲瘋病人迎面而來。他們遠遠地站著，</span>
<span className="v" id="v13" data-v="13" data-xref="馬太福音 15:22; 馬太福音 20:30–31; 馬太福音 9:27"> 高聲呼喊道：「耶穌，老師啊，求你可憐我們吧！」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="路加福音 5:14; 利未記 13:1–46; 列王紀下 5:14"> 耶穌看見他們，就說：「去讓祭司察看你們的身體。」<br />他們去的時候，就潔淨了。</span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 30:11–12; 詩篇 103:1–4; 詩篇 118:18–19"> 其中一個發現自己痊癒了，就跑回來，高聲讚美上帝，</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行傳 8:5–25; 馬太福音 10:5; 啟示錄 19:10"> 又俯伏在耶穌的腳前連連稱謝。這人是撒瑪利亞人。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="羅馬書 1:21; 詩篇 106:13; 創世記 3:9"> 耶穌說：「被潔淨的不是有十個人嗎？其他九個呢？</span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 50:23; 馬太福音 15:24–28; 詩篇 106:13"> 回來讚美稱頌上帝的只有這個外族人嗎？」</span>
<span className="v" id="v19" data-v="19" data-xref="路加福音 7:50; 路加福音 8:48; 馬可福音 10:52"> 於是祂對那人說：「起來回去吧！你的信心救了你。」</span>
</div>
</div>

## 上帝國的降臨

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="約翰福音 18:36; 路加福音 19:11; 但以理書 2:44"> 法利賽人問耶穌：「上帝的國什麼時候降臨？」<br />耶穌回答說：「上帝國的降臨並沒有看得見的徵兆。</span>
<span className="v" id="v21" data-v="21" data-xref="馬太福音 12:28; 羅馬書 14:17; 馬可福音 13:21"> 沒有人能說，『看啊，上帝的國在這裡！』或說，『在那裡！』因為上帝的國就在你們當中<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「在你們當中」或作「在你們裡面」。">a</a></sup>。」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="路加福音 5:35; 馬太福音 9:15; 約翰福音 8:21–24"> 祂又對門徒說：「時候將到，你們將渴望見到人子降臨的日子，可是你們卻見不到。</span>
<span className="v" id="v23" data-v="23" data-xref="路加福音 21:8; 馬太福音 24:23–26; 路加福音 17:21"> 有人將對你們說，『看啊，祂在這裡！』或說，『看啊，祂在那裡！』你們不要出去，也不要追隨他們。</span>
<span className="v" id="v24" data-v="24" data-xref="馬太福音 24:27; 馬太福音 24:30; 瑪拉基書 4:1–2"> 因為人子降臨的時候必如劃過長空的閃電，從天這邊一直照到天那邊。</span>
<span className="v" id="v25" data-v="25" data-xref="馬太福音 16:21; 路加福音 9:22; 馬可福音 8:31"> 但祂必須先受許多苦，被這個世代棄絕。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="馬太福音 24:37–39; 路加福音 17:24; 創世記 7:7–23"> 「人子降臨時的情形將像挪亞的時代，</span>
<span className="v" id="v27" data-v="27" data-xref="路加福音 12:19–20; 帖撒羅尼迦前書 5:1–3; 路加福音 16:19–23"> 人們吃喝嫁娶，一直到挪亞進方舟那天，洪水來了，把他們全毀滅了；</span>
<span className="v" id="v28" data-v="28" data-xref="以西結書 16:49–50; 創世記 18:20–21; 雅各書 5:1–5"> 又像羅得的時代，人們吃喝、買賣、耕地、蓋房。</span>
<span className="v" id="v29" data-v="29" data-xref="彼得後書 2:6; 西番雅書 2:9; 猶大書 1:7"> 在羅得離開所多瑪那天，烈火和硫磺從天而降，把他們全毀滅了。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="哥林多前書 1:7; 帖撒羅尼迦後書 1:7; 啟示錄 1:7"> 「人子顯現之日的情形也是如此。</span>
<span className="v" id="v31" data-v="31" data-xref="路加福音 21:21; 馬可福音 13:14–16; 耶利米書 45:5"> 那天，在屋頂上的，不要下來拿屋內的東西；田間的人也不要回家。</span>
<span className="v" id="v32" data-v="32" data-xref="創世記 19:26; 希伯來書 10:38–39; 彼得後書 2:18–22"> 你們要記住羅得妻子的事。</span>
<span className="v" id="v33" data-v="33" data-xref="馬可福音 8:35–37; 馬太福音 10:39; 約翰福音 12:25"> 凡想保全生命的，必喪失生命；凡喪失生命的，必保全生命。</span>
<span className="v" id="v34" data-v="34" data-xref="馬太福音 24:40–41; 彼得後書 2:9; 瑪拉基書 3:16–18"> 我告訴你們，那天晚上，兩個人睡在一張床上，一個將被接去，一個將被撇下；</span>
<span className="v" id="v35" data-v="35" data-xref="馬太福音 24:41; 出埃及記 11:5; 士師記 16:21"> 兩個女人一起推磨，一個將被接去，一個將被撇下；</span>
<span className="v" id="v36" data-v="36"> 兩個人在田間，一個將被接去，一個將被撇下。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有古卷無36節。">b</a></sup>」</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="馬太福音 24:28; 約伯記 39:29–30; 啟示錄 19:17–18"> 門徒問：「主啊，在哪裡有這事呢？」<br />耶穌回答說：「屍體在哪裡，禿鷹就會聚集在哪裡。」</span>
</div>
</div>

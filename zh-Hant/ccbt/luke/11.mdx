## 教導門徒禱告

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="詩篇 19:14; 路加福音 22:39–45; 羅馬書 8:26–27"> 有一天，耶穌在一個地方禱告完畢，有個門徒對祂說：「主啊，請教導我們禱告，像約翰教他的門徒一樣。」</span>
<span className="v" id="v2" data-v="2" data-xref="馬太福音 6:6–15; 傳道書 5:2; 詩篇 72:18–19"> 耶穌對他們說：「你們應當這樣禱告，<br /><span className="pl pl-1">「『天父，願你的聖名被尊崇，</span><br /><span className="pl pl-1">願你的國度降臨，</span><br /><span className="pl pl-1">願你的旨意在地上成就，</span><br /><span className="pl pl-1">就像在天上成就一樣</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古卷無「願你的旨意在地上成就，就像在天上成就一樣」。">a</a></sup><br /><span className="pl pl-1">。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="馬太福音 6:11; 馬太福音 6:34; 箴言 30:8"> <span className="pl pl-1">願你天天賜給我們日用的飲食。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="馬太福音 6:12–15; 馬太福音 26:41; 以賽亞書 43:25–26"> <span className="pl pl-1">求你饒恕我們的罪，</span><br /><span className="pl pl-1">因為我們也饒恕所有得罪我們的人。</span><br /><span className="pl pl-1">不要讓我們陷入誘惑，</span><br /><span className="pl pl-1">救我們脫離那惡者</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有古卷無「拯救我們脫離那惡者」。">b</a></sup><br /><span className="pl pl-1">。』」</span></span>
<span className="v" id="v5" data-v="5" data-xref="路加福音 18:1–8"> 耶穌又對他們說：「假設你在半夜跑去朋友家請求說，『朋友，請借給我三個餅吧，</span>
<span className="v" id="v6" data-v="6"> 因為有一位朋友遠道而來，我家沒有什麼可以招待他。』</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 13:25; 加拉太書 6:17; 路加福音 7:6"> 那個人在屋裡應聲說，『請別打攪我，門已經鎖上了，我和孩子們也已經上床了，我不能起來給你拿餅。』</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 32:26; 歌羅西書 4:12; 羅馬書 15:30"> 「我告訴你們，那人雖不念朋友之情，但是倘若你不肯甘休，繼續請求，他最終會起來滿足你的願望。</span>
<span className="v" id="v9" data-v="9" data-xref="馬可福音 11:24; 約翰福音 16:23–24; 馬太福音 21:22"> 「我告訴你們，祈求，就會給你們；尋找，就會尋見；叩門，就會給你們開門。</span>
<span className="v" id="v10" data-v="10" data-xref="雅各書 4:3; 耶利米哀歌 3:54–58; 詩篇 31:22"> 因為凡祈求的，就得到；尋找的，就尋見；叩門的，就給他開門。</span>
<span className="v" id="v11" data-v="11" data-xref="馬太福音 7:9; 以賽亞書 49:15"> 「你們做父親的，誰有兒子求餅，卻給他石頭呢？<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="有古卷無「求餅，卻給他石頭呢？」">c</a></sup>求魚，卻給他蛇呢？</span>
<span className="v" id="v12" data-v="12" data-xref="啟示錄 9:10; 路加福音 10:19; 以西結書 2:6"> 求雞蛋，卻給他蠍子呢？</span>
<span className="v" id="v13" data-v="13" data-xref="馬太福音 7:11; 以賽亞書 44:3–4; 羅馬書 8:32"> 你們雖然邪惡，尚且知道把好東西給兒女，天父豈不更要賜聖靈給那些求祂的人嗎？」</span>
</div>

## 耶穌和別西卜

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="馬太福音 12:22–24; 馬太福音 9:32–34; 馬可福音 7:32–37"> 有一次，耶穌趕出一個使人啞巴的鬼。鬼一出去，啞巴就能說話了，眾人都很驚奇。</span>
<span className="v" id="v15" data-v="15" data-xref="馬太福音 9:34; 馬太福音 12:24–30; 約翰福音 8:48"> 有人卻說：「祂是靠鬼王別西卜趕鬼。」</span>
<span className="v" id="v16" data-v="16" data-xref="約翰福音 6:30; 哥林多前書 1:22; 馬可福音 8:11–12"> 還有些人想試探耶穌，要求祂行個天上的神蹟。</span>
<span className="v" id="v17" data-v="17" data-xref="馬可福音 3:23–27; 馬太福音 12:25–29; 以賽亞書 19:2–3"> 耶穌知道他們的心思，就說：「一個國內部自相紛爭，必然滅亡；一個家內部自相紛爭，必然崩潰。</span>
<span className="v" id="v18" data-v="18" data-xref="馬太福音 12:26; 馬太福音 12:31–34; 路加福音 11:15"> 同樣，若撒旦內部自相紛爭，牠的國怎能維持呢？你們說我是靠別西卜趕鬼，</span>
<span className="v" id="v19" data-v="19" data-xref="路加福音 9:49; 約伯記 15:6; 羅馬書 3:19"> 我若是靠別西卜趕鬼，你們的子弟又是靠誰趕鬼呢？因此，他們要審判你們。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及記 8:19; 馬太福音 12:28; 路加福音 10:9"> 但我若是靠上帝的能力趕鬼，就是上帝的國已降臨在你們中間了。</span>
<span className="v" id="v21" data-v="21" data-xref="馬可福音 3:27; 馬太福音 12:29"> 「壯漢全副武裝地看守自己的住宅，他的財物會很安全。</span>
<span className="v" id="v22" data-v="22" data-xref="以賽亞書 49:24–25; 以賽亞書 53:12; 約翰一書 3:8"> 但是，來了一個比他更強壯的人，把他制伏後，奪去他依靠的武裝，並分了他搶的東西。</span>
<span className="v" id="v23" data-v="23" data-xref="馬太福音 12:30; 路加福音 9:50; 馬可福音 9:40"> 誰不與我為友，就是與我為敵；誰不和我一起收聚，就是在拆散。</span>
<span className="v" id="v24" data-v="24" data-xref="馬太福音 12:43–45; 彼得前書 5:8; 約伯記 2:2"> 「有個污鬼離開了牠所附的人，在乾旱無水之地四處遊蕩，尋找安歇之處，卻沒有找到。於是牠說，『我要回到老地方。』</span>
<span className="v" id="v25" data-v="25" data-xref="帖撒羅尼迦後書 2:9–12; 彼得後書 2:10–19; 猶大書 1:8–13"> 牠回去後，看見裡面打掃得又乾淨又整齊，</span>
<span className="v" id="v26" data-v="26" data-xref="約翰福音 5:14; 馬太福音 12:45; 彼得後書 2:20–22"> 就去帶來七個比自己更邪惡的鬼進去住在那裡。那人的下場比從前更慘了。」</span>
</div>
</div>

## 誰更有福

<div className="bt">
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="路加福音 1:42; 路加福音 1:48; 路加福音 23:29"> 耶穌說話的時候，人群中有個婦人高喊：「生你養你的人真有福啊！」</span>
<span className="v" id="v28" data-v="28" data-xref="路加福音 6:47–48; 路加福音 8:21; 詩篇 112:1"> 耶穌回答說：「但那聽了上帝的話又去遵行的人更有福。」</span>

## 可悲的邪惡世代

<div className="bt">
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="路加福音 11:16; 馬可福音 8:11–12; 哥林多前書 1:22"> 這時聚集的人越來越多，耶穌說：「這是一個邪惡的世代，人們只想看神蹟，但除了約拿的神蹟以外，再沒有神蹟給他們看。</span>
<span className="v" id="v30" data-v="30" data-xref="馬太福音 12:40–42; 約拿書 1:17; 約拿書 3:2–10"> 正如約拿成了尼尼微人的神蹟，人子也要成為這世代的神蹟。</span>
<span className="v" id="v31" data-v="31" data-xref="歷代志下 9:1; 列王紀上 10:1–13; 羅馬書 2:27"> 「在審判的日子，南方的女王和這世代的人都要起來<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="「起來」或作「復活」，下同32節。">d</a></sup>，她要定這個世代的罪，因為她曾不遠千里來聽所羅門王的智言慧語。看啊！這裡有一位比所羅門王更大。</span>
<span className="v" id="v32" data-v="32" data-xref="希伯來書 7:26; 路加福音 11:31; 約拿書 3:5–4"> 「在審判的日子，尼尼微人要起來定這個世代的罪，因為他們聽到約拿的宣告，就悔改了。看啊！這裡有一位比約拿更大。</span>
</div>

<span className="v" id="v34" data-v="34" data-xref="馬太福音 6:22–23; 使徒行傳 26:18; 耶利米書 5:21"> 你的眼睛是身體的燈，你的眼睛明亮，全身就光明；你的眼睛昏花，全身就黑暗。</span>

## 譴責法利賽人

<div className="bt">
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="路加福音 7:36; 哥林多前書 9:19–23; 路加福音 14:1"> 耶穌說完這番話後，有一個法利賽人來請祂吃飯，祂便應邀入席。</span>
<span className="v" id="v38" data-v="38" data-xref="馬太福音 15:2–3; 馬可福音 7:2–5; 約翰福音 3:25"> 這位法利賽人看見耶穌飯前沒有行洗手禮，十分詫異。</span>
<span className="v" id="v39" data-v="39" data-xref="提多書 1:15; 箴言 30:12; 創世記 6:5"> 主對他說：「你們法利賽人洗淨杯盤的外面，你們裡面卻盛滿了貪婪和邪惡。</span>
<span className="v" id="v40" data-v="40" data-xref="路加福音 12:20; 哥林多前書 15:36; 馬太福音 23:26"> 愚蠢的人啊，人裡外不都是上帝所創造的嗎？</span>
<span className="v" id="v41" data-v="41" data-xref="路加福音 12:33; 雅各書 1:27; 提多書 1:15"> 只要你們發自內心地去施捨，一切對你們來說都是潔淨的。</span>
<span className="v" id="v42" data-v="42" data-xref="馬太福音 23:23; 路加福音 18:12; 箴言 21:3"> 「法利賽人啊，你們有禍了！因為你們將薄荷、芸香、各樣蔬菜獻上十分之一，卻忽略了上帝的公義和仁愛。後者是你們本該做的，前者也不可忽略。</span>
<span className="v" id="v43" data-v="43" data-xref="路加福音 20:46; 馬可福音 12:38–39; 路加福音 14:7–11"> 「法利賽人啊，你們有禍了！因為你們喜歡在會堂裡坐首位，又喜歡在街市上聽到別人的問候。</span>
<span className="v" id="v44" data-v="44" data-xref="馬太福音 23:27–28; 詩篇 5:9; 使徒行傳 23:3"> 你們有禍了！因為你們就像沒有墓碑的墳墓，人們從上面走過也不知道。」</span>
</div>
</div>

## 譴責律法教師

<div className="bt">
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="約翰福音 9:40; 馬太福音 22:35; 耶利米書 6:10"> 一位律法教師對耶穌說：「老師，你這話把我們也侮辱了！」</span>
<span className="v" id="v46" data-v="46" data-xref="路加福音 11:52; 以賽亞書 10:1; 馬太福音 23:2–4"> 耶穌回答說：「你們這些律法教師也有禍了！因為你們把沉重難負的擔子放在別人肩上，自己卻連一根指頭也不肯動。</span>
<span className="v" id="v47" data-v="47" data-xref="帖撒羅尼迦前書 2:15; 使徒行傳 7:51; 馬太福音 23:29–33"> 「你們有禍了，你們為先知修造墳墓，而他們正是被你們祖先殺害的！</span>
<span className="v" id="v48" data-v="48" data-xref="雅各書 5:10; 馬太福音 23:31; 歷代志下 36:16"> 所以你們是見證人，你們讚同祖先的行為，因為他們殺了先知，你們為先知造墳墓。</span>
<span className="v" id="v49" data-v="49" data-xref="哥林多前書 1:30; 歌羅西書 2:3; 以弗所書 4:11"> 因此，充滿智慧的上帝說，『我要差遣先知和使徒到他們那裡，有些要被殺害，有些要遭迫害』，</span>
<span className="v" id="v50" data-v="50" data-xref="創世記 9:5–6; 啟示錄 18:20–24; 列王紀下 24:4"> 使創世以來，自亞伯一直到在祭壇和聖所之間被殺的撒迦利亞等眾先知的血債，都由這個世代承擔。我實在告訴你們，這些罪責都要由這個世代承擔。</span>
<span className="v" id="v52" data-v="52" data-xref="馬太福音 23:13; 瑪拉基書 2:7; 路加福音 11:45–46"> 「律法教師啊，你們有禍了！因為你們拿走了知識的鑰匙，自己不進去，還阻擋那些正要進去的人。」</span>
<span className="v" id="v53" data-v="53" data-xref="哥林多前書 13:5; 耶利米書 20:10; 路加福音 20:20"> 耶穌離開那裡後，法利賽人和律法教師開始激烈地反對祂，用各種問題刁難祂，</span>
<span className="v" id="v54" data-v="54" data-xref="馬可福音 12:13; 馬太福音 22:15; 馬太福音 22:35"> 伺機找話柄陷害祂。</span>
</div>

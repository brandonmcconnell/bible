## 猶大出賣耶穌

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及記 12:6–23; 馬太福音 26:2–5; 約翰福音 11:55–57"> 除酵節，又名逾越節，快到了。</span>
<span className="v" id="v2" data-v="2" data-xref="約翰福音 11:47–53; 馬太福音 12:14; 路加福音 20:19"> 祭司長和律法教師因為害怕百姓，便密謀如何殺害耶穌。</span>
<span className="v" id="v3" data-v="3" data-xref="約翰福音 13:2; 馬可福音 14:10–11; 約翰福音 13:26–27"> 這時，撒旦進入加略人猶大的心，這人原是十二使徒之一。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行傳 4:1; 使徒行傳 5:24; 路加福音 22:52"> 他去見祭司長和聖殿護衛長，商議如何把耶穌出賣給他們，</span>
<span className="v" id="v5" data-v="5" data-xref="馬太福音 26:15–16; 使徒行傳 1:18; 馬太福音 27:3–5"> 他們喜出望外，答應給猶大酬金。</span>
<span className="v" id="v6" data-v="6" data-xref="馬可福音 14:2; 馬太福音 26:5"> 猶大同意了，便伺機找百姓不在的場合將耶穌交給他們。</span>
</div>
</div>

## 最後的晚餐

<div className="bt">
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="出埃及記 12:18; 馬可福音 14:12–16; 哥林多前書 5:7"> 除酵節到了，那天要宰殺逾越節的羔羊。</span>
<span className="v" id="v8" data-v="8" data-xref="馬可福音 14:13–16; 使徒行傳 4:19; 使徒行傳 4:13"> 耶穌差派彼得和約翰出去，說：「你們去為我們預備逾越節吃的晚餐。」</span>
<span className="v" id="v9" data-v="9"> 他們問：「你想讓我們在哪裡預備呢？」</span>
<span className="v" id="v10" data-v="10" data-xref="約翰福音 16:4; 馬太福音 26:18–19; 使徒行傳 8:26–29"> 耶穌回答說：「你們進城的時候，一個男子會扛著一瓶水迎面走來，你們要跟著他，到他進的房子裡，</span>
<span className="v" id="v11" data-v="11" data-xref="約翰福音 11:28; 啟示錄 3:20; 路加福音 19:34"> 對房子的主人說，『老師問：客房在哪裡？祂要和門徒在裡面吃逾越節的晚餐。』</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行傳 16:14–15; 使徒行傳 1:13; 約翰福音 2:25"> 主人會帶你們看樓上一間佈置整齊的大房間，你們就在那裡預備吧。」</span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 21:33; 路加福音 19:32; 約翰福音 2:5"> 他們進了城，所遇見的果然和耶穌所說的一樣。他們便在那裡預備逾越節的晚餐。</span>
</div>
</div>

## 設立聖餐

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="馬太福音 26:20; 馬可福音 14:17; 申命記 16:6–7"> 時候到了，耶穌和使徒們一同坐席。</span>
<span className="v" id="v15" data-v="15" data-xref="路加福音 12:50; 約翰福音 4:34; 約翰福音 17:1"> 耶穌對他們說：「我一直盼望在受難之前和你們同吃這個逾越節的宴席。</span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 14:15; 啟示錄 19:9; 路加福音 22:30"> 我告訴你們，在這宴席成就在上帝的國之前，我不會再吃這宴席了。」</span>
<span className="v" id="v17" data-v="17" data-xref="路加福音 22:19; 詩篇 116:13; 申命記 8:10"> 祂接過杯來，祝謝後，說：「你們拿去分著喝吧。</span>
<span className="v" id="v18" data-v="18" data-xref="馬太福音 26:29; 路加福音 22:16; 馬可福音 14:25"> 我告訴你們，在上帝的國降臨之前，我不會再喝這葡萄酒。」</span>
<span className="v" id="v19" data-v="19" data-xref="哥林多前書 11:23–29; 哥林多前書 10:16; 馬可福音 14:22–24"> 接著，祂拿起餅來，祝謝後，掰開分給他們，說：「這是我為你們犧牲的身體，你們要這樣做來記念我。」</span>
<span className="v" id="v20" data-v="20" data-xref="馬太福音 26:28; 哥林多前書 11:25; 撒迦利亞書 9:11"> 飯後，祂照樣拿起杯來，說：「這杯是用我的血立的新約，這血是為你們流的。</span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 41:9; 約翰福音 13:26; 約翰福音 13:21–22"> 「但是看啊，那出賣我之人的手和我的手都在桌子上。</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行傳 2:23; 詩篇 109:6–15; 詩篇 55:12–15"> 按照所定的，人子要離世了，但那出賣人子的人有禍了！」</span>
<span className="v" id="v23" data-v="23" data-xref="約翰福音 13:22–25; 馬可福音 14:19; 馬太福音 26:22"> 他們開始彼此追問誰會出賣耶穌。</span>
</div>
</div>

## 誰最偉大

<div className="bt">
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="路加福音 9:46; 馬可福音 9:34; 馬可福音 10:37–41"> 門徒又開始爭論他們當中誰最偉大。</span>
<span className="v" id="v25" data-v="25" data-xref="馬太福音 20:25–28; 馬可福音 10:41–45"> 耶穌對他們說：「外族人有君王統治他們，那些統治者被稱為恩主，</span>
<span className="v" id="v26" data-v="26" data-xref="彼得前書 5:5; 路加福音 9:48; 馬太福音 18:3–5"> 但你們不可這樣。相反，你們中間位分最高的，要像最卑微的；做首領的，要像服侍人的。</span>
<span className="v" id="v27" data-v="27" data-xref="馬太福音 20:28; 路加福音 12:37; 約翰福音 13:5–16"> 坐席的和服侍的哪個位分高呢？難道不是坐席的那個嗎？然而，我在你們當中像是服侍的。</span>
<span className="v" id="v28" data-v="28" data-xref="希伯來書 2:18; 希伯來書 4:15; 使徒行傳 1:25"> 「在我患難之時，你們一直在我身邊，</span>
<span className="v" id="v29" data-v="29" data-xref="馬太福音 25:34; 提摩太後書 2:12; 雅各書 2:5"> 所以，我父怎樣將國賜給我，我也照樣將國賜給你們，</span>
<span className="v" id="v30" data-v="30" data-xref="馬太福音 19:28; 馬太福音 8:11; 啟示錄 2:26–27"> 使你們在我的國中和我同席吃喝，並且坐在寶座上審判以色列的十二個支派。」</span>
</div>
</div>

## 預言彼得不認主

<div className="bt">
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="彼得前書 5:8; 撒迦利亞書 3:1; 約伯記 1:6–12"> 耶穌說：「西門！西門！撒旦已經要求像篩麥子一樣篩你們，</span>
<span className="v" id="v32" data-v="32" data-xref="彼得前書 5:8–10; 約翰福音 21:15–17; 約翰福音 17:9–11"> 但我已經為你禱告了，叫你不至於失去信心。你回頭以後，要讓你的弟兄剛強。」</span>
<span className="v" id="v33" data-v="33" data-xref="馬可福音 14:31; 馬太福音 26:33–35; 馬可福音 14:29"> 西門·彼得說：「主啊，我已準備好和你一起坐牢，一起受死！」</span>
<span className="v" id="v34" data-v="34" data-xref="約翰福音 13:38; 馬太福音 26:34; 馬可福音 14:30"> 耶穌說：「彼得，我告訴你，今早雞叫之前，你會三次不認我。」</span>
<span className="v" id="v35" data-v="35" data-xref="馬太福音 10:9–10; 路加福音 10:4; 詩篇 23:1"> 耶穌又問門徒：「我從前派你們出去，沒有帶錢袋、背包和鞋，你們有任何缺乏嗎？」 他們答道：「沒有。」</span>
<span className="v" id="v36" data-v="36" data-xref="馬太福音 10:22–25; 帖撒羅尼迦前書 3:4; 帖撒羅尼迦前書 2:14–15"> 耶穌說：「但現在如果有錢袋或背包，都要帶著；如果沒有刀，要賣掉衣服買刀。</span>
<span className="v" id="v37" data-v="37" data-xref="以賽亞書 53:12; 路加福音 23:32; 哥林多後書 5:21"> 我告訴你們，『祂被列在罪犯中』<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="以賽亞書53·12。">a</a></sup>這句經文必在我身上應驗，因為聖經上有關我的事情快要實現了。」</span>
<span className="v" id="v38" data-v="38" data-xref="路加福音 22:49; 馬太福音 26:52–54; 約翰福音 18:36"> 他們說：「主啊，請看，這裡有兩把刀。」耶穌說：「夠了。」</span>
</div>
</div>

## 橄欖山上的禱告

<div className="bt">
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="路加福音 21:37; 約翰福音 18:1–2; 馬太福音 21:1"> 耶穌出去，照常前往橄欖山，門徒也跟著祂。</span>
<span className="v" id="v40" data-v="40" data-xref="馬太福音 6:13; 馬太福音 26:36–46; 路加福音 22:46"> 到了地方，祂對門徒說：「你們要禱告，以免陷入誘惑！」</span>
<span className="v" id="v41" data-v="41" data-xref="馬太福音 26:39; 馬可福音 14:35; 路加福音 18:11"> 然後，祂獨自走到離門徒約有扔一塊石頭那麼遠的地方跪下禱告：</span>
<span className="v" id="v42" data-v="42" data-xref="約翰福音 12:27–28; 馬太福音 26:39; 馬太福音 26:42"> 「父啊，若你願意，求你撤去此杯。然而，願你的旨意成就，而非我的意願。」</span>
<span className="v" id="v43" data-v="43" data-xref="馬太福音 4:11; 馬太福音 26:53; 詩篇 91:11–12"> 有一位從天上來的天使向祂顯現，給祂加添力量。</span>
<span className="v" id="v44" data-v="44" data-xref="耶利米哀歌 1:12; 希伯來書 5:7; 詩篇 22:12–21"> 祂心中極其悲痛，禱告更懇切，汗珠如血滴落在地上。</span>
<span className="v" id="v45" data-v="45" data-xref="馬可福音 14:40–41; 馬太福音 26:43; 馬太福音 26:40"> 祂禱告完後，便起身回到門徒那裡，看見他們因憂愁而疲憊地睡著了，</span>
<span className="v" id="v46" data-v="46" data-xref="路加福音 22:40; 約拿書 1:6; 路加福音 21:34–36"> 就說：「你們為什麼睡覺呢？要起來禱告，以免陷入誘惑！」</span>
</div>
</div>

## 耶穌被捕

<div className="bt">
<div className="bp">
<span className="v" id="v47" data-v="47" data-xref="馬可福音 14:41–50; 約翰福音 18:2–11; 路加福音 22:3–6"> 耶穌還在說話的時候，十二使徒中的猶大已帶著一群人趕到，他上前親吻耶穌。</span>
<span className="v" id="v48" data-v="48" data-xref="馬可福音 14:44–46; 撒母耳記下 20:9–10; 箴言 27:6"> 耶穌對他說：「猶大，你用親吻的暗號來出賣人子嗎？」</span>
<span className="v" id="v49" data-v="49" data-xref="路加福音 22:38"> 跟隨耶穌的人見勢不妙，就說：「主啊，我們要揮刀反擊嗎？」</span>
<span className="v" id="v50" data-v="50" data-xref="約翰福音 18:10–11; 馬可福音 14:47; 羅馬書 12:19"> 其中一人揮刀朝大祭司的奴僕砍過去，削掉了他的右耳。</span>
<span className="v" id="v51" data-v="51" data-xref="羅馬書 12:21; 哥林多後書 10:1; 彼得前書 2:21–23"> 耶穌卻說：「住手！夠了！」於是祂摸那奴僕的耳朵，治好了他，</span>
<span className="v" id="v52" data-v="52" data-xref="路加福音 22:4; 馬可福音 14:48–49; 約翰福音 17:12"> 然後對前來抓祂的祭司長、聖殿護衛長和長老說：「你們像對付強盜一樣拿著刀棍來抓我嗎？</span>
<span className="v" id="v53" data-v="53" data-xref="約翰福音 12:27; 以弗所書 6:12; 使徒行傳 26:18"> 我天天和你們一起在聖殿裡，你們沒有抓我。但現在正是黑暗當權、你們得勢的時候了！」</span>
</div>
</div>

## 彼得不認主

<div className="bt">
<div className="bp">
<span className="v" id="v54" data-v="54" data-xref="馬可福音 14:53–54; 馬太福音 26:57–58; 約翰福音 18:12–17"> 他們抓住耶穌，把祂押到大祭司的府第。彼得遠遠地跟在後面。</span>
<span className="v" id="v55" data-v="55" data-xref="詩篇 26:4–5; 哥林多後書 6:15–17; 馬可福音 14:66–72"> 他們在庭院當中生起了火，圍坐一團，彼得也坐在他們中間。</span>
<span className="v" id="v56" data-v="56" data-xref="約翰福音 18:17; 馬可福音 14:6; 馬可福音 14:17"> 有個婢女看見彼得坐在火堆邊，就盯著他看，說：「這人跟耶穌是一夥的！」</span>
<span className="v" id="v57" data-v="57" data-xref="約翰一書 1:9; 約翰福音 18:25; 馬太福音 26:70"> 彼得卻否認說：「你這女子，我不認識祂。」</span>
<span className="v" id="v58" data-v="58" data-xref="約翰福音 18:25; 馬太福音 26:71–72; 馬可福音 14:69–70"> 過了一會兒，又有個人看見了彼得，就說：「你也是他們一夥的！」 彼得說：「你這人，我不是！」</span>
<span className="v" id="v59" data-v="59" data-xref="約翰福音 18:26–27; 馬可福音 14:69–70; 馬太福音 26:73–74"> 大約一小時之後，又有人斷言：「這人肯定跟祂是一夥的，因為他也是加利利人。」</span>
<span className="v" id="v60" data-v="60" data-xref="馬太福音 26:74–75; 路加福音 22:34; 馬可福音 14:71–72"> 彼得說：「你這人，我不知道你在說什麼！」話音未落，雞就叫了。</span>
<span className="v" id="v61" data-v="61" data-xref="路加福音 22:34; 以賽亞書 57:15–18; 耶利米書 31:18–20"> 這時，主轉過頭來望著彼得，彼得想起主對他說的話：「今早雞叫之前，你會三次不認我。」</span>
<span className="v" id="v62" data-v="62" data-xref="馬太福音 26:75; 哥林多前書 10:12; 馬可福音 14:72"> 他就到外面，痛哭起來。</span>
</div>
</div>

## 在公會受審

<div className="bt">
<div className="bp">
<span className="v" id="v63" data-v="63" data-xref="約翰福音 18:22; 馬可福音 14:55–65; 約伯記 16:9–10"> 看守耶穌的人嘲弄祂，毆打祂，</span>
<span className="v" id="v64" data-v="64" data-xref="士師記 16:25; 士師記 16:21"> 蒙住祂的眼睛，對祂說：「說預言吧！是誰在打你？」</span>
<span className="v" id="v65" data-v="65" data-xref="路加福音 12:10; 馬太福音 12:31–32; 馬太福音 27:39"> 還說了許多侮辱祂的話。</span>
<span className="v" id="v66" data-v="66" data-xref="馬太福音 27:1; 馬可福音 15:1; 使徒行傳 22:5"> 天亮後，百姓的長老、祭司長和律法教師聚在一起，把耶穌押到他們的公會，</span>
<span className="v" id="v67" data-v="67" data-xref="馬太福音 11:3–5; 約翰福音 8:43–45; 馬太福音 26:63–68"> 對祂說：「如果你是基督，就告訴我們。」 耶穌說：「即使我告訴你們，你們也不會相信。</span>
<span className="v" id="v68" data-v="68" data-xref="路加福音 20:41–44; 路加福音 20:3–7"> 如果我問你們，你們也不會回答。</span>
<span className="v" id="v69" data-v="69" data-xref="但以理書 7:13–14; 詩篇 110:1; 馬可福音 16:19"> 但從今以後，人子要坐在大能上帝的右邊。」</span>
<span className="v" id="v70" data-v="70" data-xref="路加福音 23:3; 馬太福音 27:11; 馬太福音 26:64"> 他們都問：「那麼，你是上帝的兒子嗎？」耶穌回答說：「你們說我是。」</span>
<span className="v" id="v71" data-v="71" data-xref="馬太福音 26:65–66; 馬可福音 14:63–64"> 他們說：「我們還需要什麼見證呢？我們親耳聽見祂自己說的。」</span>
</div>

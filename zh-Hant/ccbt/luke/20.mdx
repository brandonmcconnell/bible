## 質問耶穌的權柄

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="馬太福音 21:23–27; 路加福音 19:47–48; 使徒行傳 6:12"> 有一天，耶穌正在聖殿裡教導人、傳講福音，祭司長、律法教師和長老上前來，</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 2:14; 馬可福音 11:28–33; 約翰福音 2:18"> 質問祂：「告訴我們，你憑什麼權柄做這些事？誰授權給你了？」</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="馬太福音 15:2–3; 路加福音 22:68; 歌羅西書 4:6"> 耶穌回答說：「我也問你們一個問題。你們告訴我，</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 15:18; 馬太福音 11:7–19; 馬太福音 17:11–12"> 約翰的洗禮是從天上來的，還是從人間來的？」</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="約翰福音 1:34; 約翰福音 1:15–18; 約翰福音 1:30"> 他們彼此議論說：「如果我們說『是從天上來的』，祂一定會問，『那你們為什麼不信他？』</span>
<span className="v" id="v6" data-v="6" data-xref="馬太福音 21:26; 馬太福音 11:9; 約翰福音 10:41"> 如果我們說『是從人間來的』，百姓會拿石頭打死我們，因為他們相信約翰是先知。」</span>
<span className="v" id="v7" data-v="7" data-xref="以賽亞書 29:14; 彼得後書 3:3; 以賽亞書 41:28"> 於是，他們回答說：「我們不知道是從哪裡來的。」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="箴言 26:4–5; 馬太福音 21:27; 馬可福音 11:33"> 耶穌說：「我也不告訴你們我憑什麼權柄做這些事。」</span>
</div>
</div>

## 利慾薰心的佃戶

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="馬太福音 21:33–46; 馬可福音 12:1–12; 以賽亞書 5:1–7"> 接著耶穌對眾人講了個比喻：「有人開墾了一個葡萄園，把園子租給佃戶，就出遠門了。</span>
<span className="v" id="v10" data-v="10" data-xref="歷代志下 36:15–16; 尼希米記 9:26; 馬太福音 21:34–36"> 到了收穫的季節，他派奴僕去葡萄園向佃戶收取他的那份果實，佃戶卻把奴僕打了一頓，使他空手而歸。</span>
<span className="v" id="v11" data-v="11" data-xref="何西阿書 10:1; 希伯來書 11:36–37; 帖撒羅尼迦前書 2:2"> 園主又派另一個奴僕去，他們照樣將他毆打並羞辱一番，使他空手而歸。</span>
<span className="v" id="v12" data-v="12"> 園主又派第三個奴僕去，他們又把他打傷，拋在園外。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="馬太福音 3:17; 約翰福音 3:16–17; 耶利米書 36:7"> 「園主說，『我該怎樣辦呢？不如叫我所疼愛的兒子去吧。他們大概會尊重他。』</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="羅馬書 8:17; 希伯來書 1:2; 使徒行傳 2:23"> 「可是那些佃戶看見園主的兒子，就彼此商量說，『這是產業繼承人，我們殺掉他，產業就歸我們了！』</span>
<span className="v" id="v15" data-v="15" data-xref="希伯來書 13:12; 馬可福音 12:6–9; 馬太福音 21:37–40"> 於是他們把園主的兒子扔到葡萄園外殺了。<br />「那麼，園主會怎樣處置他們呢？</span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 19:27; 使徒行傳 13:46; 馬太福音 21:41"> 他必來殺掉這些佃戶，把葡萄園租給別人。」<br />眾人聽了就說：「但願這種事永遠不會發生！」</span>
</div>
<div className="bp poetry">
<span className="v" id="v17" data-v="17" data-xref="詩篇 118:22; 以賽亞書 28:16; 使徒行傳 4:11"> 耶穌定睛看著他們，問道：「那麼，聖經上說，<br /><span className="pl pl-1">「『工匠丟棄的石頭已成了房角石』</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="詩篇118·22。">a</a></sup><br /><span className="pl pl-1">，</span><br />這句話是什麼意思呢？</span>
<span className="v" id="v18" data-v="18" data-xref="以賽亞書 8:14–15; 撒迦利亞書 12:3; 但以理書 2:44–45"> 凡跌在這石頭上的人，都會粉身碎骨；這石頭落在誰身上，會把誰砸爛。」</span>
</div>
</div>

## 納稅問題

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="路加福音 19:47–48; 路加福音 20:14; 馬太福音 21:45–46"> 律法教師和祭司長聽出這比喻是針對他們說的，便想立刻下手捉拿耶穌，但又害怕百姓。</span>
<span className="v" id="v20" data-v="20" data-xref="路加福音 11:54; 馬太福音 22:15–22; 馬太福音 27:2"> 於是，他們嚴密監視耶穌，又派遣密探假裝好人，想從祂的話裡找把柄，好把祂交給總督處置。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="帖撒羅尼迦前書 2:4–5; 馬太福音 26:49–50; 馬太福音 22:16"> 那些密探問耶穌：「老師，我們知道你所講所傳的道都是正確的，也知道你不徇情面，而是按真理傳上帝的道。</span>
<span className="v" id="v22" data-v="22" data-xref="尼希米記 9:37; 馬可福音 12:14–17; 使徒行傳 5:37"> 那麼，我們向凱撒納稅對不對呢？」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="馬太福音 22:18; 哥林多前書 3:19; 路加福音 5:22"> 耶穌看破他們的陰謀，</span>
<span className="v" id="v24" data-v="24" data-xref="馬太福音 18:28; 使徒行傳 11:28; 使徒行傳 26:32"> 就叫他們拿一個銀幣來，問他們：「上面刻的是誰的像和名號？」他們說：「凱撒的。」</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="羅馬書 13:6–7; 馬可福音 12:17; 彼得前書 2:13–17"> 耶穌說：「屬於凱撒的，要給凱撒；屬於上帝的，要給上帝。」</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="路加福音 20:20; 箴言 26:4–5; 提多書 1:10"> 耶穌的回答令他們驚奇，他們無法當眾找到把柄，只好閉口不言。</span>
</div>
</div>

## 論死人復活

<div className="bt">
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="使徒行傳 4:1–2; 哥林多前書 15:12; 馬可福音 12:18–27"> 撒督該人向來不相信有復活的事。有幾個這一派的人來問耶穌：</span>
<span className="v" id="v28" data-v="28" data-xref="申命記 25:5–10; 創世記 38:8; 創世記 38:11"> 「老師，按摩西為我們寫的律例，如果有人娶妻後沒有孩子就死了，他的兄弟當娶嫂嫂，替哥哥傳宗接代。</span>
<span className="v" id="v29" data-v="29" data-xref="利未記 20:20; 耶利米書 22:30"> 有弟兄七人，老大結了婚，沒有孩子就死了。</span>
<span className="v" id="v30" data-v="30"> 二弟、</span>
<span className="v" id="v31" data-v="31"> 三弟、一直到七弟都相繼娶了嫂嫂，都沒有留下孩子就死了。</span>
<span className="v" id="v32" data-v="32" data-xref="傳道書 1:4; 傳道書 9:5; 希伯來書 9:27"> 最後那女人也死了。</span>
<span className="v" id="v33" data-v="33" data-xref="馬太福音 22:24–28; 馬可福音 12:19–23"> 那麼，到復活的時候，她將是誰的妻子呢？因為七個人都娶過她。」</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="路加福音 16:8; 路加福音 17:27; 希伯來書 13:4"> 耶穌說：「今世的人才有嫁娶，</span>
<span className="v" id="v35" data-v="35" data-xref="帖撒羅尼迦後書 1:5; 約翰福音 5:29; 但以理書 12:2–3"> 但那些配得將來的世界、從死裡復活的人不娶也不嫁，</span>
<span className="v" id="v36" data-v="36" data-xref="啟示錄 21:4; 腓立比書 3:21; 馬太福音 22:30"> 就像天使一樣永遠不會死。他們既然從死裡復活，就是上帝的兒女。</span>
<span className="v" id="v37" data-v="37" data-xref="出埃及記 3:2–6; 馬可福音 12:26–27; 使徒行傳 7:30–32"> 在火中荊棘的記載中，摩西也證實死人會復活，因為他稱主是『亞伯拉罕的上帝，以撒的上帝，雅各的上帝』<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="出埃及記3·6。">b</a></sup>。</span>
<span className="v" id="v38" data-v="38" data-xref="約翰福音 11:25–26; 歌羅西書 3:3–4; 羅馬書 6:10–11"> 上帝不是死人的上帝，而是活人的上帝。因為在祂那裡的人都是活人。」</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="使徒行傳 23:9; 馬可福音 12:28–34; 馬太福音 22:34–40"> 幾位律法教師說：「老師答得好！」</span>
<span className="v" id="v40" data-v="40" data-xref="馬太福音 22:46; 馬可福音 12:34; 箴言 26:5"> 此後，再沒人敢用問題刁難耶穌。</span>
</div>
</div>

## 論基督

<div className="bt">
<div className="bp poetry">
<span className="v" id="v41" data-v="41" data-xref="馬可福音 12:35–37; 馬太福音 1:1; 馬太福音 22:41–45"> 耶穌問他們：「人怎麼說基督是大衛的後裔呢？</span>
<span className="v" id="v42" data-v="42" data-xref="詩篇 110:1; 使徒行傳 2:34–35; 希伯來書 1:13"> 大衛自己曾在詩篇裡說，<br /><span className="pl pl-1">「『主對我主說，</span><br /><span className="pl pl-1">你坐在我的右邊，</span><br /></span>
<span className="v" id="v43" data-v="43" data-xref="路加福音 19:27; 詩篇 110:1; 啟示錄 19:14–21"> <span className="pl pl-1">等我使你的仇敵成為你的腳凳。』</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="詩篇110·1。">c</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="啟示錄 22:16; 路加福音 1:31–35; 馬太福音 1:23"> 既然大衛稱基督為主，基督又怎麼會是大衛的後裔呢？」</span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="馬太福音 15:10; 馬可福音 12:38–39; 馬可福音 8:34"> 大家正聽的時候，耶穌對門徒說：</span>
<span className="v" id="v46" data-v="46" data-xref="路加福音 11:43; 馬可福音 12:38–39; 路加福音 14:7"> 「你們要提防律法教師。他們愛穿著長袍招搖過市，喜歡人們在大街上問候他們，又喜歡會堂裡的上座和宴席中的首位。</span>
<span className="v" id="v47" data-v="47" data-xref="馬可福音 12:40; 雅各書 3:1; 提多書 1:16"> 他們侵吞寡婦的家產，還假意做冗長的禱告。這種人必受到更嚴厲的懲罰！」</span>
</div>
</div>

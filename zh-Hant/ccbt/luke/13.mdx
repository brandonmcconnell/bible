## 不悔改的下場

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="彼得前書 4:17–18; 耶利米哀歌 2:20; 以西結書 9:5–7"> 這時，有人把加利利人被彼拉多屠殺、血濺祭物之事告訴了耶穌。</span>
<span className="v" id="v2" data-v="2" data-xref="約翰福音 9:2; 使徒行傳 28:4; 約伯記 22:5–16"> 耶穌說：「你們以為這些人被殺，是因為他們的罪比其他加利利人的罪更重嗎？</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行傳 3:19; 馬太福音 3:2; 使徒行傳 2:38–40"> 不！我告訴你們，你們若不悔改，也必同樣滅亡。</span>
<span className="v" id="v4" data-v="4" data-xref="尼希米記 3:15; 約伯記 1:19; 約翰福音 9:11"> 西羅亞樓倒塌曾壓死了十八個人。你們以為他們比耶路撒冷其他人更有罪嗎？</span>
<span className="v" id="v5" data-v="5" data-xref="以西結書 18:30; 路加福音 13:3; 以賽亞書 28:10–13"> 不！我告訴你們，你們若不悔改，也必同樣滅亡。」</span>
<span className="v" id="v6" data-v="6" data-xref="約翰福音 15:16; 以賽亞書 5:1–4; 加拉太書 5:22"> 於是，耶穌說了一個比喻：「有人在葡萄園裡種了一棵無花果樹，他去樹那裡找果子，卻找不到。</span>
<span className="v" id="v7" data-v="7" data-xref="馬太福音 7:19; 路加福音 3:9; 約翰福音 15:6"> 他對園丁說，『三年來，我一直盼望它結果子，它卻一個也沒結。把它砍了，免得白佔土地。』</span>
<span className="v" id="v8" data-v="8" data-xref="彼得後書 3:9; 約珥書 2:17; 羅馬書 10:1"> 「園丁說，『主人，再留它一年吧！讓我在它四周鬆土、施肥，</span>
<span className="v" id="v9" data-v="9" data-xref="約翰福音 15:2; 帖撒羅尼迦前書 2:15; 希伯來書 6:8"> 明年如果結了果子就留它，不然再砍掉它。』」</span>
</div>
</div>

## 治好駝背婦人

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="馬太福音 4:23; 路加福音 4:44; 路加福音 4:15–16"> 有個安息日，耶穌在會堂裡教導。</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 8:2; 路加福音 8:27; 路加福音 13:16"> 那裡有個婦人被邪靈纏身十八年，腰彎得很厲害，無法站直。</span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 107:20; 馬太福音 8:16; 路加福音 6:8–10"> 耶穌看見她，便叫她過來，說：「婦人，你的病好了！」</span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 107:20–22; 馬可福音 16:18; 馬可福音 5:23"> 耶穌雙手按在她身上，她的腰立刻直了，便頌讚上帝。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及記 20:9; 馬太福音 12:2; 約翰福音 9:14–16"> 會堂主管看到耶穌在安息日為人治病，十分惱怒，就對眾人說：「一週有六天可以工作，求醫應當在這六天之內，不可在安息日！」</span>
<span className="v" id="v15" data-v="15" data-xref="路加福音 14:5; 約翰福音 7:21–24; 使徒行傳 13:9–10"> 主說：「你們這些偽君子，莫非你們各自在安息日不解開棚裡的牛和驢，帶牠們去喝水嗎？</span>
<span className="v" id="v16" data-v="16" data-xref="馬可福音 2:27; 提摩太後書 2:26; 路加福音 19:9"> 這婦人身為亞伯拉罕的女兒，受撒旦的捆綁十八年，難道不該在安息日為她解開捆索嗎？」</span>
<span className="v" id="v17" data-v="17" data-xref="彼得前書 3:16; 詩篇 132:18; 以賽亞書 45:24"> 反對祂的人聽了這番話後，都非常羞愧，眾人卻為耶穌的奇妙作為高興歡喜。</span>
</div>
</div>

## 上帝國的比喻

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="馬可福音 4:30–34; 路加福音 17:21; 馬太福音 13:31–32"> 耶穌繼續說：「上帝的國好像什麼呢？我該把上帝的國比作什麼呢？</span>
<span className="v" id="v19" data-v="19" data-xref="但以理書 4:12; 但以理書 4:21; 但以理書 2:44–45"> 上帝的國就像一粒芥菜種，有人把它種在園裡，它長成了一棵樹，飛鳥在它枝頭棲息。」</span>
<span className="v" id="v20" data-v="20"> 耶穌又說：「我該把上帝的國比作什麼呢？</span>
<span className="v" id="v21" data-v="21" data-xref="馬太福音 13:33; 哥林多前書 5:6; 帖撒羅尼迦前書 5:23–24"> 上帝的國就像麵酵，婦人拿來摻在三斗麵裡，直到整團麵都發起來。」</span>
</div>
</div>

## 努力進窄門

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="路加福音 9:51; 馬太福音 9:35; 馬可福音 10:32–34"> 耶穌繼續前往耶路撒冷，沿途在各城鎮教導人。</span>
<span className="v" id="v23" data-v="23" data-xref="馬太福音 7:14; 馬太福音 22:14; 約翰福音 21:21–22"> 有人問祂：「主啊，是不是只有很少人得救呢？」耶穌對他們說：</span>
<span className="v" id="v24" data-v="24" data-xref="馬太福音 7:13–14; 彼得後書 1:10; 哥林多前書 9:24–27"> 「你們要努力進窄門，因為我告訴你們，將來有許多人想要進卻進不去。</span>
<span className="v" id="v25" data-v="25" data-xref="馬太福音 25:10–12; 路加福音 13:27; 馬太福音 7:21–23"> 當家主起來把門關閉之後，你們才站在外面叩門哀求，說，『主啊，給我們開門吧！』家主必說，『我不認識你們，不知道你們是哪裡來的。』</span>
<span className="v" id="v26" data-v="26" data-xref="以賽亞書 58:2; 提多書 1:16; 提摩太後書 3:5"> 「那時，你們必說，『我們不是在一起用過餐嗎？你不是在街上教導過我們嗎？』</span>
<span className="v" id="v27" data-v="27" data-xref="詩篇 6:8; 馬太福音 25:41; 馬太福音 7:22–23"> 「家主必說，『我告訴你們，我不認識你們，不知道你們是哪裡來的。你們這些作惡的人，走開！』</span>
<span className="v" id="v28" data-v="28" data-xref="馬太福音 8:11–12; 馬太福音 22:13; 馬太福音 25:30"> 「當你們看見亞伯拉罕、以撒、雅各和眾先知在上帝的國裡，自己卻被扔到門外時，必要在那裡哀哭切齒。</span>
<span className="v" id="v29" data-v="29" data-xref="以賽亞書 43:6; 以賽亞書 66:18–20; 以賽亞書 49:6"> 那時人們會從東西南北來參加上帝國的宴席。</span>
<span className="v" id="v30" data-v="30" data-xref="馬太福音 19:30; 馬可福音 10:31; 馬太福音 20:16"> 看啊，有些殿後的將要為首，有些為首的將要殿後。」</span>
</div>
</div>

## 為耶路撒冷哀傷

<div className="bt">
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="尼希米記 6:9–11; 詩篇 11:1–2; 馬太福音 14:1"> 那時，有幾個法利賽人來告訴耶穌，說：「快離開這裡吧，希律要殺你！」</span>
<span className="v" id="v32" data-v="32" data-xref="希伯來書 2:10; 希伯來書 5:9; 約翰福音 17:4–5"> 耶穌說：「你們去告訴那個狐狸，『今天和明天，我要繼續趕鬼治病，到第三天，我的任務就完成了。』</span>
<span className="v" id="v33" data-v="33" data-xref="路加福音 9:53; 馬太福音 21:11; 使徒行傳 13:27"> 無論如何，今天、明天和後天我必須繼續前行，因為先知不能死在耶路撒冷以外的地方。</span>
<span className="v" id="v34" data-v="34" data-xref="馬太福音 23:37–39; 申命記 32:11–12; 使徒行傳 7:52"> 「耶路撒冷啊，耶路撒冷啊！你常殺害先知，又用石頭打死派到你那裡的使者。我多次想要招聚你的兒女，像母雞把小雞招聚在翅膀底下，可是你們卻不肯。</span>
<span className="v" id="v35" data-v="35" data-xref="詩篇 118:26; 馬可福音 11:9–10; 馬太福音 21:9"> 看啊！你們的家園將一片荒涼。我告訴你們，在你們說『奉主名來的當受稱頌』<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="詩篇118·26。">a</a></sup>之前，你們再也見不到我了。」</span>
</div>
</div>

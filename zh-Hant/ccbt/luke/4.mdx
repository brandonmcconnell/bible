## 耶穌受試探

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="馬太福音 4:1–11; 使徒行傳 10:38; 馬可福音 1:12–13"> 耶穌被聖靈充滿，從約旦河回來後，隨聖靈的引導來到曠野，</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 34:28; 希伯來書 4:15; 申命記 9:9"> 在那裡受魔鬼的試探四十天。那些日子耶穌什麼也沒吃。那段日子過後，祂餓了。</span>
<span className="v" id="v3" data-v="3" data-xref="馬太福音 4:3; 路加福音 3:22"> 魔鬼對祂說：「你如果是上帝的兒子，就叫這塊石頭變成食物吧。」</span>
<span className="v" id="v4" data-v="4" data-xref="申命記 8:3; 馬太福音 4:4; 馬太福音 6:31"> 耶穌回答說：「聖經上說，『人活著不是單靠食物。』<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="申命記8·3。">a</a></sup>」</span>
<span className="v" id="v5" data-v="5" data-xref="約翰一書 2:15–16; 哥林多前書 15:52; 馬太福音 4:8"> 魔鬼又帶祂上到高處，頃刻間把天下萬國展示給祂看，</span>
<span className="v" id="v6" data-v="6" data-xref="約翰福音 12:31; 約翰一書 5:19; 約翰福音 14:30"> 說：「我要把這一切權勢和榮耀都給你，因為這一切全交給我了，我想給誰就給誰。</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 8:28; 詩篇 72:11; 以賽亞書 45:14"> 如果你向我下拜，這一切就是你的了。」</span>
<span className="v" id="v8" data-v="8" data-xref="申命記 6:13; 申命記 10:20; 馬太福音 4:10"> 耶穌回答說：「聖經上說，『要敬拜主你的上帝，單單事奉祂。』<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="申命記6·13。">b</a></sup>」</span>
<span className="v" id="v9" data-v="9" data-xref="馬太福音 4:5–6; 路加福音 4:3; 馬太福音 8:29"> 魔鬼又帶耶穌到耶路撒冷，讓祂站在聖殿的最高處，說：「你如果是上帝的兒子，就從這裡跳下去吧，</span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 91:11–12; 希伯來書 1:14; 哥林多後書 11:14"> 因為聖經上說，『上帝會吩咐祂的天使保護你，</span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 91:12"> 他們會用手托住你，不讓你的腳碰在石頭上。』<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="詩篇91·11、12。">c</a></sup>」</span>
<span className="v" id="v12" data-v="12" data-xref="申命記 6:16; 希伯來書 3:8–9; 哥林多前書 10:9"> 耶穌回答說：「聖經上說，『不可試探主你的上帝。』<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="申命記6·16。">d</a></sup>」</span>
<span className="v" id="v13" data-v="13" data-xref="希伯來書 4:15; 雅各書 4:7; 馬太福音 4:11"> 魔鬼用盡各種試探後，暫時離開了耶穌。</span>
</div>
</div>

## 拿撒勒人厭棄耶穌

<div className="bt">
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="馬太福音 4:23–25; 使徒行傳 10:37; 馬太福音 4:12"> 耶穌帶著聖靈的能力回到加利利，祂的名聲傳遍了周圍地區。</span>
<span className="v" id="v15" data-v="15" data-xref="馬太福音 4:23; 馬太福音 9:8; 馬太福音 9:35"> 祂在各會堂裡教導人，大家都稱讚祂。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行傳 17:2; 使徒行傳 13:14–16; 馬太福音 2:23"> 祂來到自己長大的地方拿撒勒，照常在安息日進會堂，並站起來要誦讀聖經。</span>
<span className="v" id="v17" data-v="17" data-xref="以賽亞書 61:1–3; 使徒行傳 13:15; 使徒行傳 7:42"> 有人把以賽亞先知書遞給祂，祂打開書卷，找到這樣一段經文：</span>
<span className="v" id="v18" data-v="18" data-xref="以賽亞書 61:1; 馬太福音 11:5; 詩篇 146:7–8"> <span className="pl pl-1">「主的靈在我身上，</span><br /><span className="pl pl-1">因為祂膏立了我，</span><br /><span className="pl pl-1">讓我傳福音給貧窮的人，</span><br /><span className="pl pl-1">差遣我宣告被擄的人得釋放、</span><br /><span className="pl pl-1">瞎眼的人得見光明、</span><br /><span className="pl pl-1">受欺壓的人得自由，</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="以賽亞書 61:2; 以賽亞書 63:4; 哥林多後書 6:1"> <span className="pl pl-1">又宣告上帝的恩年。」</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="以賽亞書61·1、2。">e</a></sup></span>
<span className="v" id="v20" data-v="20" data-xref="路加福音 4:17; 約翰福音 8:2; 路加福音 19:48"> 耶穌讀完便收好書卷，還給負責的人，然後坐下。會堂裡的人都把目光集中在祂身上。</span>
<span className="v" id="v21" data-v="21" data-xref="約翰福音 4:25–26; 使徒行傳 3:18; 使徒行傳 2:16–18"> 祂就對他們說：「你們剛才聽見的這段經文今天已經應驗了。」</span>
<span className="v" id="v22" data-v="22" data-xref="馬太福音 13:54–56; 詩篇 45:2; 使徒行傳 6:10"> 大家都稱讚祂，聽見祂那些充滿恩典的話，都感到驚奇，就說：「這不是約瑟的兒子嗎？」</span>
<span className="v" id="v23" data-v="23" data-xref="約翰福音 4:46–53; 馬太福音 11:23–24; 馬可福音 2:1–12"> 耶穌對他們說：「你們肯定會把這句俗話用在我身上，說，『醫生啊，治好你自己吧！你在迦百農所行的一切，我們都聽說了，也在你家鄉行給我們看吧！』</span>
<span className="v" id="v24" data-v="24" data-xref="馬太福音 13:57; 約翰福音 4:44; 馬可福音 6:4–5"> 可是我實在告訴你們，先知在本鄉是不受歡迎的。</span>
<span className="v" id="v25" data-v="25" data-xref="雅各書 5:17; 列王紀上 17:1; 馬太福音 20:15"> 誠然，在以利亞先知的時代，天乾旱無雨達三年半之久，遍地有大饑荒，當時以色列國有許多寡婦，</span>
<span className="v" id="v26" data-v="26" data-xref="列王紀上 17:9–24; 馬太福音 11:21; 俄巴底亞書 1:20"> 但以利亞並沒有奉命去幫助她們任何人，只奉命去幫助住在西頓地區撒勒法的一個寡婦。</span>
<span className="v" id="v27" data-v="27" data-xref="列王紀下 5:1–27; 約翰福音 17:12; 馬太福音 12:4"> 在以利沙先知的時代，以色列國有許多患痲瘋病的人，但沒有一個人得到醫治，反而敘利亞的乃縵得到了醫治。」</span>
<span className="v" id="v28" data-v="28" data-xref="使徒行傳 5:33; 歷代志下 24:20–21; 耶利米書 38:6"> 會堂裡的人聽了這些話都怒火中燒，</span>
<span className="v" id="v29" data-v="29" data-xref="約翰福音 8:59; 使徒行傳 21:28–32; 民數記 15:35"> 就起來把耶穌趕出城外，帶到懸崖邊，要把祂推下去。他們的城就座落在山上。</span>
<span className="v" id="v30" data-v="30" data-xref="約翰福音 10:39; 約翰福音 8:59; 約翰福音 18:6–7"> 耶穌卻從他們中間穿過，離開了那裡。</span>
</div>
</div>

## 加利利趕鬼醫病

<div className="bt">
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="馬可福音 1:21–28; 馬太福音 4:13; 使徒行傳 13:50–2"> 耶穌下到加利利的迦百農鎮，在安息日教導眾人。</span>
<span className="v" id="v32" data-v="32" data-xref="路加福音 4:36; 馬太福音 7:28–29; 約翰福音 6:63"> 聽眾對祂的教導感到驚奇，因為祂的話帶著權柄。</span>
<span className="v" id="v33" data-v="33" data-xref="馬可福音 1:23"> 會堂裡有一個被污鬼附身的人高聲喊叫：</span>
<span className="v" id="v34" data-v="34" data-xref="馬可福音 1:24; 雅各書 2:19; 馬太福音 8:29"> 「唉！拿撒勒的耶穌啊，我們和你有什麼關係？你是來毀滅我們嗎？我知道你是誰，你是上帝的聖者！」</span>
<span className="v" id="v35" data-v="35" data-xref="路加福音 4:41; 路加福音 4:39; 馬太福音 8:26"> 耶穌責備牠說：「住口！從他身上出來！」污鬼當眾把那人摔倒，然後從他身上出來了，絲毫沒有傷害他。</span>
<span className="v" id="v36" data-v="36" data-xref="路加福音 4:32; 彼得前書 3:22; 馬太福音 12:22–23"> 眾人都很驚訝，彼此議論說：「這是怎麼回事？祂的話有權柄和能力，祂一發命令，污鬼就出來了！」</span>
<span className="v" id="v37" data-v="37" data-xref="馬可福音 1:45; 路加福音 4:14; 以賽亞書 52:13"> 耶穌的名聲傳遍了周圍地區。</span>
</div>
</div>

## 耶穌醫治許多人

<div className="bt">
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="馬太福音 8:14–15; 馬可福音 1:29–31; 約翰福音 11:22"> 祂離開會堂，到了西門的家。那時，西門的岳母正在發高燒，眾人就求耶穌醫治她。</span>
<span className="v" id="v39" data-v="39" data-xref="路加福音 4:41; 路加福音 4:35; 路加福音 8:24"> 耶穌站在她旁邊，斥責熱病，熱病就退了，她便立刻起來服侍他們。</span>
<span className="v" id="v40" data-v="40" data-xref="馬可福音 1:32–34; 馬太福音 8:16–17; 馬可福音 5:23"> 到了黃昏，人們把患各種疾病的人帶到耶穌面前。耶穌把手按在病人身上，一一治好他們，</span>
<span className="v" id="v41" data-v="41" data-xref="馬可福音 1:34; 雅各書 2:19; 路加福音 4:34–35"> 並趕出許多附在人身上的鬼。那些鬼喊叫著：「你是上帝的兒子！」耶穌卻斥責牠們，不許牠們說話，因為牠們知道祂是基督。</span>
<span className="v" id="v42" data-v="42" data-xref="路加福音 6:12; 馬可福音 1:35–38; 約翰福音 4:34"> 黎明時，耶穌出去到一處荒僻的地方。眾人四處尋找祂，找到後想留住祂，不讓祂離開。</span>
<span className="v" id="v43" data-v="43" data-xref="馬可福音 1:38–39; 提摩太後書 4:2; 約翰福音 9:4"> 但耶穌對他們說：「我必須把上帝國的福音傳到其他城鎮去，因為我就是為此被差來的。」</span>
<span className="v" id="v44" data-v="44" data-xref="馬太福音 4:23; 馬可福音 1:39; 路加福音 4:15"> 於是耶穌繼續在猶太<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="「猶太」另有抄本作「加利利」。">f</a></sup>各會堂裡傳道。</span>
</div>

## 耶穌死裡復活

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="約翰福音 20:1–2; 馬可福音 16:1–8; 馬太福音 28:1–8"> 週日黎明時分，幾位婦女帶著預備好的香料來到墳前，</span>
<span className="v" id="v2" data-v="2" data-xref="馬可福音 16:3–4; 馬太福音 27:60–66; 馬可福音 15:46–47"> 發現墓口的大石頭已經滾到旁邊，</span>
<span className="v" id="v3" data-v="3" data-xref="路加福音 24:23; 約翰福音 20:6–7; 馬太福音 16:5"> 便進去，卻沒有看見主耶穌的遺體。</span>
<span className="v" id="v4" data-v="4" data-xref="馬可福音 16:5; 約翰福音 20:11–12; 使徒行傳 1:10"> 正在猜疑之間，突然有兩個衣服發光的人站在旁邊，</span>
<span className="v" id="v5" data-v="5" data-xref="馬可福音 16:5–6; 馬太福音 28:3–5; 啟示錄 1:18"> 她們嚇得俯伏在地。那兩個人對她們說：「你們為什麼在死人中找活人呢？</span>
<span className="v" id="v6" data-v="6" data-xref="馬太福音 17:22–23; 路加福音 9:22; 馬可福音 8:31"> 祂不在這裡，已經復活了！記住祂在加利利對你們說的話，</span>
<span className="v" id="v7" data-v="7" data-xref="馬太福音 16:21"> 『人子必須被交在罪人的手中，被釘在十字架上，在第三天復活。』」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="約翰福音 12:16; 約翰福音 14:26; 約翰福音 2:19–22"> 她們這才想起耶穌的話來，</span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 24:22–24; 馬可福音 16:7–8; 馬太福音 28:7–8"> 便離開墳墓，回去把事情的經過告訴十一個使徒和其他人。</span>
<span className="v" id="v10" data-v="10" data-xref="馬太福音 27:56; 約翰福音 20:11–18; 路加福音 8:2–3"> 把這些事告訴使徒的婦女有抹大拉的瑪麗亞、約亞娜、雅各的母親瑪麗亞及其他人。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="約伯記 9:16; 馬可福音 16:11; 創世記 19:14"> 他們聽了都不相信，認為是無稽之談。</span>
<span className="v" id="v12" data-v="12" data-xref="約翰福音 20:3–10"> 彼得卻起身跑到墓地，屈身往墓裡張望，只見細麻布在那裡，便離開了，對發生的事大惑不解。</span>
</div>
</div>

## 耶穌的顯現

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="路加福音 24:18; 馬可福音 16:12–13"> 同一天，有兩個門徒前往離耶路撒冷十一公里的以馬忤斯村，</span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 6:45; 申命記 6:7; 瑪拉基書 3:6"> 一路談論著最近發生的一切事。</span>
<span className="v" id="v15" data-v="15" data-xref="馬太福音 18:20; 約翰福音 14:18–19; 路加福音 24:36"> 正談論的時候，耶穌走過來和他們同行。</span>
<span className="v" id="v16" data-v="16" data-xref="約翰福音 20:14; 約翰福音 21:4; 路加福音 24:31"> 可是，他們認不出耶穌。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="約翰福音 16:20–22; 約翰福音 16:6; 以西結書 9:4–6"> 耶穌問他們：「你們一路上在談論什麼？」<br />他們停下腳步，滿面愁容，</span>
<span className="v" id="v18" data-v="18" data-xref="約翰福音 19:25"> 其中一個叫革流巴的說：「難道在耶路撒冷作客的人中，只有你不知道近日發生在那裡的事嗎？」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="馬太福音 21:11; 使徒行傳 7:22; 約翰福音 4:19"> 耶穌問：「什麼事？」<br />他們說：「就是拿撒勒人耶穌的事。祂本來是個先知，在上帝和百姓面前言談舉止充滿力量。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行傳 3:13–15; 使徒行傳 4:8–10; 路加福音 23:13"> 我們的祭司長和官長卻把祂押去判了死刑，釘在十字架上。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="路加福音 1:68; 彼得前書 1:18–19; 路加福音 2:38"> 「我們一直希望祂就是要救贖以色列的那位。還有，今天是事發後的第三天，</span>
<span className="v" id="v22" data-v="22" data-xref="馬可福音 16:9–10; 馬太福音 28:7–8; 約翰福音 20:1–2"> 我們當中有幾位婦女讓我們驚奇。她們一早到墳墓那裡，</span>
<span className="v" id="v23" data-v="23"> 發現耶穌的遺體不見了，回來說天使曾向她們顯現，並告訴她們耶穌還活著。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="路加福音 24:12; 約翰福音 20:1–10"> 「後來我們有幾個人去墳墓察看，發現果然像她們所說的，不過沒有看見耶穌。」</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="馬可福音 7:18; 馬可福音 9:19; 希伯來書 5:11–12"> 耶穌對他們說：「無知的人啊！為什麼遲遲不肯相信先知的話呢？</span>
<span className="v" id="v26" data-v="26" data-xref="彼得前書 1:11; 以賽亞書 53:1–12; 撒迦利亞書 13:7"> 基督豈不是要先這樣受害，然後進入祂的榮耀嗎？」</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="以賽亞書 7:14; 路加福音 24:44; 申命記 18:15"> 耶穌接著從摩西和眾先知的記載開始，把有關自己的經文都向他們講解明白。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="馬可福音 6:48; 創世記 19:2; 創世記 32:26"> 快到以馬忤斯村時，耶穌好像還要繼續前行。</span>
<span className="v" id="v29" data-v="29" data-xref="列王紀下 4:8; 路加福音 14:23; 創世記 19:3"> 他們極力挽留祂，說：「天快黑了，時候不早了，跟我們一同住宿吧。」耶穌就和他們一起進村住下。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="馬太福音 14:19; 路加福音 24:35; 馬太福音 15:36"> 吃飯的時候，耶穌拿起餅來，祝謝後，掰開遞給他們。</span>
<span className="v" id="v31" data-v="31" data-xref="路加福音 24:16; 約翰福音 8:59; 路加福音 4:30"> 忽然他們眼睛明亮了，認出是耶穌。耶穌就從他們眼前消失了。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="路加福音 24:45; 耶利米書 23:29; 希伯來書 4:12"> 二人彼此議論說：「一路上祂和我們說話、為我們解釋聖經的時候，我們心裡不是很火熱嗎？」</span>
<span className="v" id="v33" data-v="33" data-xref="馬可福音 16:13; 約翰福音 20:19–26; 使徒行傳 1:14"> 二人馬上動身趕回耶路撒冷，看到十一位使徒及其同伴正聚在一起談論：</span>
<span className="v" id="v34" data-v="34" data-xref="哥林多前書 15:5; 馬可福音 16:7; 路加福音 22:54–62"> 「主真的復活了，並向西門顯現了。」</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="馬可福音 16:12–13; 使徒行傳 2:42; 路加福音 24:30–31"> 二人也把路上發生的事以及掰餅時認出主的經過述說了一遍。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="帖撒羅尼迦後書 3:16; 以賽亞書 57:18; 馬可福音 16:14"> 正說的時候，耶穌親自站在他們中間，說：「願你們平安！」</span>
<span className="v" id="v37" data-v="37" data-xref="撒母耳記上 28:13; 馬太福音 14:26–27; 約伯記 4:14–16"> 他們又驚又怕，以為是看見了幽靈。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="耶利米書 4:14; 希伯來書 4:13; 但以理書 4:19"> 耶穌說：「你們為什麼惴惴不安？為什麼心存疑惑呢？</span>
<span className="v" id="v39" data-v="39" data-xref="約翰福音 20:27; 約翰一書 1:1; 傳道書 12:7"> 你們看我的手和腳，就知道真的是我。來摸摸看，幽靈沒有骨和肉，你們看！我有。」</span>
<span className="v" id="v40" data-v="40"> 說完，祂把手和腳給他們看。</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="約翰福音 21:5; 詩篇 126:1–2; 創世記 45:26–28"> 門徒又驚又喜，難以相信。耶穌問：「你們這裡有吃的嗎？」</span>
<span className="v" id="v42" data-v="42"> 他們便給祂一片烤魚，</span>
<span className="v" id="v43" data-v="43" data-xref="使徒行傳 10:41"> 祂接過來在他們面前吃了。</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="撒迦利亞書 12:10; 路加福音 24:26–27; 撒迦利亞書 9:9"> 耶穌對他們說：「我跟你們在一起的時候曾經說過，摩西的律法書、先知的書以及詩篇裡有關我的記載都要應驗。」</span>
<span className="v" id="v45" data-v="45" data-xref="使徒行傳 16:14; 約翰一書 5:20; 詩篇 119:18"> 於是，耶穌開了他們的心竅，使他們明白聖經，</span>
<span className="v" id="v46" data-v="46" data-xref="以賽亞書 53:2–12; 以賽亞書 50:6; 路加福音 24:44"> 又對他們說：「聖經上說，基督必受害，然後在第三天從死裡復活，</span>
<span className="v" id="v47" data-v="47" data-xref="使徒行傳 5:31; 以賽亞書 49:6; 使徒行傳 2:38"> 人們要奉祂的名傳揚悔改、赦罪的福音，從耶路撒冷一直傳遍萬國。</span>
</div>
<div className="bp">
<span className="v" id="v48" data-v="48" data-xref="使徒行傳 1:8; 使徒行傳 2:32; 使徒行傳 13:31"> 「你們是這些事的見證人，</span>
<span className="v" id="v49" data-v="49" data-xref="使徒行傳 1:8; 使徒行傳 1:4; 約珥書 2:28–32"> 我要把我父的應許賜給你們。不過，你們要留在城裡，直到得著天上來的能力。」</span>
</div>
</div>

## 耶穌升天

<div className="bt">
<div className="bp">
<span className="v" id="v50" data-v="50" data-xref="使徒行傳 1:12; 馬太福音 21:17; 馬可福音 11:1"> 耶穌帶著門徒來到伯大尼附近，舉起雙手為他們祝福。</span>
<span className="v" id="v51" data-v="51" data-xref="使徒行傳 1:9; 馬可福音 16:19; 列王紀下 2:11"> 正祝福的時候，祂就離開了他們，被接到天上去了。</span>
<span className="v" id="v52" data-v="52" data-xref="馬太福音 28:9; 約翰福音 16:22; 詩篇 30:11"> 門徒都敬拜祂，然後歡歡喜喜地回到耶路撒冷。</span>
<span className="v" id="v53" data-v="53" data-xref="馬可福音 16:20; 使徒行傳 2:46–47; 使徒行傳 5:41–42"> 他們常在聖殿裡頌讚上帝。</span>
</div>
</div>

</div>

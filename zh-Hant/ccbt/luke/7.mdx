## 百夫長的信心

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="馬太福音 8:5–13; 路加福音 7:1–10; 馬太福音 7:28–29"> 耶穌向眾人講完道後，進了迦百農。</span>
<span className="v" id="v2" data-v="2" data-xref="列王紀下 5:2–3; 創世記 24:27; 約翰福音 4:46–47"> 當時，有一個百夫長很賞識的奴僕病了，生命垂危。</span>
<span className="v" id="v3" data-v="3" data-xref="馬太福音 8:5; 約翰福音 4:47; 路加福音 9:38"> 百夫長聽說耶穌的事，就託幾位猶太人的長老去請耶穌來醫治他的奴僕。</span>
<span className="v" id="v4" data-v="4" data-xref="啟示錄 3:4; 馬太福音 10:11; 路加福音 7:6–7"> 他們便來懇求耶穌，說：「這位百夫長值得你幫助，</span>
<span className="v" id="v5" data-v="5" data-xref="歷代志下 2:11–12; 歷代志上 29:3–9; 列王紀上 5:1"> 因為他愛我們的同胞，為我們建造會堂。」</span>
<span className="v" id="v6" data-v="6" data-xref="馬可福音 5:24; 創世記 32:10; 雅各書 4:6"> 耶穌就跟他們去了。<br />快抵達時，那百夫長又請幾位朋友去見耶穌，對祂說：「主啊，不用勞駕，你親臨舍下，我不敢當。</span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 107:20; 詩篇 33:9; 路加福音 4:36"> 我自認不配去見你的面，只要你說一句話，我僕人就會痊癒。</span>
<span className="v" id="v8" data-v="8" data-xref="歌羅西書 3:22; 使徒行傳 23:17; 使徒行傳 22:25–26"> 因為我有上司，也有部下。我命令這個部下去，他就去；要那個部下來，他就來。我吩咐奴僕做什麼，他就做什麼。」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="馬太福音 15:28; 羅馬書 3:1–3; 馬太福音 8:10"> 耶穌聽了這番話，感到驚奇，轉身對跟隨祂的眾人說：「我告訴你們，就是在以色列，我也從未見過信心這麼大的人。」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="約翰福音 4:50–53; 馬太福音 8:13; 馬太福音 15:28"> 派去的幾位朋友回到百夫長家裡，發現那奴僕已經痊癒了。</span>
</div>
</div>

## 寡婦的獨子起死回生

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="使徒行傳 10:38"> 過了不久<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「過了不久」有古卷作「次日」。">a</a></sup>，耶穌去拿因城，隨行的有門徒和一大群人。</span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 8:42; 路加福音 8:52; 列王紀上 17:9"> 耶穌快到城門口時，從城裡走出一隊送殯的人，死者是一個寡婦的獨子，有許多城中的人陪著她。</span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 103:13; 以賽亞書 63:9; 詩篇 86:15"> 主看見那寡婦，憐憫之心油然而生，就對她說：「不要哭！」</span>
<span className="v" id="v14" data-v="14" data-xref="約翰福音 5:25; 約翰福音 11:43–44; 使徒行傳 9:40–41"> 隨即上前按住棺架，抬的人停了下來。耶穌說：「年輕人，我吩咐你起來！」</span>
<span className="v" id="v15" data-v="15" data-xref="列王紀下 13:21; 列王紀下 4:32–37; 列王紀上 17:23–24"> 那死者就坐了起來，並開口說話。耶穌把他交給他母親。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="馬太福音 9:8; 路加福音 7:39; 路加福音 1:68"> 人們都驚懼萬分，把榮耀歸給上帝，說：「我們中間出了一位大先知！」又說：「上帝眷顧了祂的子民！」</span>
<span className="v" id="v17" data-v="17" data-xref="馬太福音 4:24; 馬可福音 6:14; 馬太福音 9:26"> 有關祂的這消息傳遍了猶太和附近地區。</span>
</div>
</div>

## 施洗者約翰的疑問

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="約翰福音 3:26; 馬太福音 11:2–19"> 約翰從自己的門徒那裡獲悉這些事後，</span>
<span className="v" id="v19" data-v="19" data-xref="以賽亞書 9:6–7; 約翰福音 4:25; 創世記 22:18"> 就叫了兩個門徒來，派他們去問主：「將要來的那位就是你嗎？還是我們要等別人呢？」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="路加福音 7:19"> 他們來到耶穌面前，便問：「施洗者約翰派我們來請教你，『將要來的那位就是你嗎？還是我們要等別人呢？』」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="馬可福音 3:10; 詩篇 90:7–9; 希伯來書 12:6"> 那時，耶穌剛治好了許多患各種疾病和被邪靈附身的人，又使許多瞎眼的能看見。</span>
<span className="v" id="v22" data-v="22" data-xref="以賽亞書 35:5–6; 以賽亞書 61:1–3; 路加福音 4:18"> 耶穌回答說：「你們回去把所見所聞告訴約翰，就是瞎眼的看見，瘸腿的走路，痲瘋病人得潔淨，耳聾的聽見，死人復活，窮人聽到福音。</span>
<span className="v" id="v23" data-v="23" data-xref="馬太福音 11:6; 彼得前書 2:7–8; 羅馬書 9:32–33"> 凡對我篤信不疑的人有福了！」</span>
</div>
</div>

## 耶穌稱讚施洗者約翰

<div className="bt">
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="以弗所書 4:14; 約翰福音 1:23; 路加福音 1:80"> 約翰的門徒離去後，耶穌對眾人談論約翰，說：「你們從前去曠野要看什麼呢？看隨風搖動的蘆葦嗎？</span>
<span className="v" id="v25" data-v="25" data-xref="以賽亞書 59:17; 以斯帖記 8:15; 以斯帖記 1:3"> 如果不是，你們出去到底想看什麼？是看穿綾羅綢緞的人嗎？那些衣著華麗、生活奢侈的人住在王宮裡。</span>
<span className="v" id="v26" data-v="26" data-xref="路加福音 1:76; 約翰福音 5:35; 路加福音 20:6"> 你們出去究竟想看什麼？看先知嗎？是的，我告訴你們，他不只是先知。</span>
<span className="v" id="v27" data-v="27" data-xref="瑪拉基書 3:1; 路加福音 1:76; 馬可福音 1:2"> 聖經上說，『看啊，我要差遣我的使者在你前面為你預備道路。』<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="瑪拉基書3·1。">b</a></sup>這裡所指的就是約翰。</span>
<span className="v" id="v28" data-v="28" data-xref="馬太福音 13:16–17; 馬太福音 11:11; 歌羅西書 1:25–27"> 我告訴你們，凡婦人所生的，沒有一個比約翰大，但上帝國中最微不足道的也比他大。」</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="路加福音 3:12; 路加福音 7:35; 使徒行傳 18:25"> 眾百姓和稅吏聽了這番話，都承認上帝是公義的，因為他們接受了約翰的洗禮。</span>
<span className="v" id="v30" data-v="30" data-xref="路加福音 13:34; 哥林多後書 6:1; 馬太福音 22:35"> 但那些法利賽人和律法教師沒有接受約翰的洗禮，拒絕了上帝為他們所定的旨意。</span>
</div>
<div className="bp poetry">
<span className="v" id="v31" data-v="31" data-xref="馬太福音 11:16–19; 耶利米哀歌 2:13; 馬可福音 4:30"> 主又說：「我用什麼來比擬這個世代的人呢？他們像什麼呢？</span>
<span className="v" id="v32" data-v="32" data-xref="馬太福音 11:16–19; 耶利米書 5:3–5; 箴言 17:16"> 他們就如孩童坐在集市上彼此呼喊，<br /><span className="pl pl-1">「『我們吹娶親的樂曲，</span><br /><span className="pl pl-1">你們不跳舞；</span><br /><span className="pl pl-1">我們唱送葬的哀歌，</span><br /><span className="pl pl-1">你們不哭泣。』</span></span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="路加福音 1:15; 馬可福音 1:6; 約翰福音 8:52"> 施洗者約翰來了，不吃餅，不喝酒，你們就說他被鬼附身；</span>
<span className="v" id="v34" data-v="34" data-xref="路加福音 15:2; 路加福音 7:36; 約翰福音 12:2"> 人子來了，又吃又喝，你們就說，『看啊，祂是個貪吃好酒之徒，與稅吏和罪人為友！』</span>
<span className="v" id="v35" data-v="35" data-xref="箴言 8:32–36; 馬太福音 11:19; 何西阿書 14:9"> 然而，智慧通過所有順從智慧的人顯明為義。」</span>
</div>
</div>

## 罪婦的悔改

<div className="bt">
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="馬可福音 14:3–9; 馬太福音 26:5–6; 路加福音 14:1"> 有一個法利賽人請耶穌到他家裡吃飯，耶穌應邀赴宴。</span>
<span className="v" id="v37" data-v="37" data-xref="馬可福音 14:3–9; 馬太福音 26:6–13; 馬太福音 21:31"> 那城裡住著一個罪惡的女人。她聽說耶穌在那法利賽人家裡吃飯，就帶了一玉瓶香膏進去。</span>
<span className="v" id="v38" data-v="38" data-xref="詩篇 126:5–6; 詩篇 51:17; 創世記 18:4"> 她站在耶穌背後，挨著祂的腳哭，淚水滴濕了祂的腳，就用自己的頭髮擦乾，又連連親祂的腳，並抹上香膏。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="路加福音 7:16; 路加福音 15:2; 馬可福音 7:21"> 邀請耶穌的法利賽人看在眼裡，心想：「這人如果是先知，就該知道摸祂的是誰，是個什麼樣的女人，她是個罪人。」</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="約翰福音 16:19; 路加福音 5:31; 以西結書 33:31"> 耶穌對他說：「西門，我有話跟你說。」<br />西門答道：「老師，請說。」</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="路加福音 7:47; 羅馬書 5:20; 馬太福音 18:28"> 耶穌說：「有一個債主借給一個人五百個銀幣，又借給另一個人五十個銀幣。</span>
<span className="v" id="v42" data-v="42" data-xref="但以理書 9:18–19; 歌羅西書 3:13; 羅馬書 3:24"> 二人都沒有能力還債，這位債主就免了他們的債務。那麼，哪一位會更愛債主呢？」</span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="詩篇 116:16–18; 提摩太前書 1:13–16; 路加福音 7:47"> 西門答道：「我相信是那個被免去更多債的人。」<br />耶穌說：「你判斷得對！」</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="提摩太前書 5:10; 士師記 19:21; 創世記 18:4"> 隨後祂轉向那女人，繼續對西門說：「你看見這女人了嗎？我到你家裡來，你沒有拿水給我洗腳，這女人卻用眼淚濕了我的腳，還用頭髮擦乾。</span>
<span className="v" id="v45" data-v="45" data-xref="撒母耳記下 15:5; 撒母耳記下 19:39; 羅馬書 16:16"> 你沒有親吻我，但我進來以後，這女人卻不停地吻我的腳。</span>
<span className="v" id="v46" data-v="46" data-xref="詩篇 23:5; 傳道書 9:8; 馬太福音 6:17"> 你沒有用油為我抹頭，這女人卻用香膏抹我的腳。</span>
<span className="v" id="v47" data-v="47" data-xref="約翰一書 4:19; 約翰一書 3:18; 以賽亞書 1:18"> 所以我告訴你，她許多的罪都被赦免了，因此她的愛深切；那些獲得赦免少的，他們的愛也少。」</span>
</div>
<div className="bp">
<span className="v" id="v48" data-v="48" data-xref="馬太福音 9:2; 馬可福音 2:5; 路加福音 5:20"> 耶穌對那女人說：「你的罪都被赦免了。」</span>
</div>
<div className="bp">
<span className="v" id="v49" data-v="49" data-xref="路加福音 5:20–21; 馬太福音 9:3; 馬可福音 2:7"> 同席的人彼此議論說：「這人是誰？竟然能赦免人的罪！」</span>
</div>
<div className="bp">
<span className="v" id="v50" data-v="50" data-xref="馬可福音 5:34; 路加福音 8:48; 路加福音 18:42"> 耶穌又對那女人說：「你的信心救了你，平安地走吧！」</span>
</div>
</div>

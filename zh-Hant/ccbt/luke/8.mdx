## 撒種的比喻

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="馬太福音 4:23; 羅馬書 10:15; 馬太福音 9:35"> 此後，耶穌到各城鎮去傳揚上帝國的福音。同行的有十二使徒，</span>
<span className="v" id="v2" data-v="2" data-xref="馬可福音 16:9; 馬太福音 27:55–56; 馬可福音 15:40–41"> 還有幾個曾被邪靈和疾病纏身、現在已被醫治的婦女。其中有抹大拉的瑪麗亞，耶穌曾經從她身上趕出七個鬼，</span>
<span className="v" id="v3" data-v="3" data-xref="約翰福音 4:46–53; 哥林多後書 8:9; 使徒行傳 9:36–39"> 還有希律的管家苦撒的妻子約亞娜，此外還有蘇撒娜等其他婦女。她們用自己的錢財資助耶穌和門徒。</span>
<span className="v" id="v4" data-v="4" data-xref="馬可福音 4:1–9; 馬太福音 13:2–9"> 那時，人群絡繹不絕地從各個城鎮聚集到耶穌面前，耶穌就講了一個比喻：</span>
<span className="v" id="v5" data-v="5" data-xref="希伯來書 2:1; 雅各書 1:23–24; 馬可福音 4:15"> 「有一個農夫出去撒種，有些種子落在路旁，被人踐踏，又被飛鳥吃掉了；</span>
<span className="v" id="v6" data-v="6" data-xref="希伯來書 3:7–8; 路加福音 8:13; 馬可福音 4:5–6"> 有些落在石頭地上，因水分不足，幼苗剛長出來就枯萎了；</span>
<span className="v" id="v7" data-v="7" data-xref="耶利米書 4:3; 路加福音 8:14; 路加福音 21:34"> 有些落在荊棘叢中，荊棘一同長起來便把幼苗擠住了；</span>
<span className="v" id="v8" data-v="8" data-xref="馬太福音 11:15; 啟示錄 2:11; 啟示錄 2:7"> 有些落在沃土裡，發芽生長，結出百倍的果實。」耶穌講完這番話後，高聲說：「有耳可聽的，都應當聽。」</span>
<span className="v" id="v9" data-v="9" data-xref="馬可福音 4:10; 馬太福音 13:10; 馬太福音 13:18"> 門徒請耶穌解釋這比喻的意思，</span>
<span className="v" id="v10" data-v="10" data-xref="以賽亞書 6:9; 馬可福音 4:11; 馬太福音 11:25"> 耶穌便說：「上帝國的奧祕只讓你們知道，對其他人，我就用比喻，使他們看卻看不見，聽卻聽不明白<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="以賽亞書6·9。">a</a></sup>。</span>
<span className="v" id="v11" data-v="11" data-xref="馬太福音 13:19; 馬可福音 4:14–20; 雅各書 1:21"> 這個比喻的意思是這樣，種子就是上帝的道。</span>
<span className="v" id="v12" data-v="12" data-xref="帖撒羅尼迦後書 2:9–14; 啟示錄 12:9; 雅各書 1:23–24"> 種子落在路旁是指人聽了道，隨後魔鬼來把道從他們心裡奪走了，不讓他們相信並得救。</span>
<span className="v" id="v13" data-v="13" data-xref="何西阿書 6:4; 約翰福音 5:35; 箴言 12:12"> 種子落在石頭地上是指人聽了道，便欣然接受，但他們沒有根基，不過是暫時相信，一遇到試煉就放棄了。</span>
<span className="v" id="v14" data-v="14" data-xref="約翰一書 2:15–17; 提摩太前書 6:9–10; 提摩太前書 6:17"> 種子落在荊棘叢中是指人聽了道，後來被生活的憂慮、錢財和享樂纏住了，以致結不出成熟的果實來。</span>
<span className="v" id="v15" data-v="15" data-xref="希伯來書 10:36; 加拉太書 5:22–26; 歌羅西書 1:10"> 種子落在沃土裡則是指人聽了道，用誠實良善的心堅忍持守，最終結出果實。</span>
</div>
</div>

## 點燈的比喻

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="路加福音 11:33; 馬太福音 5:15–16; 馬可福音 4:21–22"> 「沒有人點亮燈，卻用器皿把它蓋起來或放到床底下，而是放在燈臺上，使進來的人能看見光。</span>
<span className="v" id="v17" data-v="17" data-xref="路加福音 12:2–3; 馬太福音 10:26; 馬可福音 4:22"> 掩蓋的事終會暴露出來，隱藏的秘密終會被人知道。</span>
<span className="v" id="v18" data-v="18" data-xref="馬太福音 13:12; 路加福音 19:26; 馬可福音 4:23–25"> 因此，你們要留心聽，因為凡有的，還要給他更多；凡沒有的，連他自以為已經擁有的也要奪去。」</span>
</div>
</div>

## 耶穌的親屬

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="馬太福音 12:46–50; 馬可福音 3:31–35; 馬可福音 3:21"> 這時，耶穌的母親和兄弟來找祂，由於人太多，他們無法靠近耶穌，</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行傳 1:14; 馬可福音 6:3; 馬太福音 13:55–56"> 有人就對祂說：「你的母親和兄弟站在外面想見你。」</span>
<span className="v" id="v21" data-v="21" data-xref="路加福音 11:27–28; 雅各書 1:22; 約翰福音 13:17"> 耶穌卻說：「聽見上帝的話語並遵行的人就是我的母親和我的弟兄。」</span>
</div>
</div>

## 平靜風浪

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="馬太福音 8:23–27; 馬可福音 4:35–41; 馬可福音 6:45"> 有一天，耶穌對門徒說：「我們渡到湖對岸去吧。」於是他們坐船前往對岸。</span>
<span className="v" id="v23" data-v="23" data-xref="詩篇 93:3–4; 詩篇 124:2–4; 詩篇 148:8"> 耶穌途中睡著了。湖面上忽然狂風大作，船灌滿了水，非常危險。</span>
<span className="v" id="v24" data-v="24" data-xref="詩篇 107:25–29; 路加福音 4:39; 詩篇 104:6–9"> 門徒過來喚醒耶穌，說：「老師！老師！我們快淹死了！」 耶穌醒來，就斥責風浪，頓時風平浪靜了。</span>
<span className="v" id="v25" data-v="25" data-xref="馬太福音 8:26; 箴言 30:4; 馬可福音 4:40–41"> 耶穌對他們說：「你們的信心在哪裡呢？」 門徒又驚又怕，彼此議論說：「祂到底是誰？一發命令，連風浪都聽從祂！」</span>
</div>
</div>

## 格拉森趕鬼

<div className="bt">
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="馬可福音 5:1–20; 馬太福音 8:28–34"> 他們渡過加利利湖，到了對岸的格拉森地區。</span>
<span className="v" id="v27" data-v="27" data-xref="馬可福音 5:2–5; 撒母耳記上 19:24; 民數記 19:16"> 耶穌上岸後，迎面遇見當地一個被鬼附身的人。那人長期不穿衣服，不住在房屋裡，而是住在墳墓裡。</span>
<span className="v" id="v28" data-v="28" data-xref="馬太福音 8:29; 彼得後書 2:4; 馬可福音 5:6–8"> 他一見到耶穌，就仆倒在祂面前，高聲喊叫：「至高上帝的兒子耶穌啊，我和你有什麼關係？求求你，不要折磨我！」</span>
<span className="v" id="v29" data-v="29" data-xref="馬可福音 5:3–5; 路加福音 9:39; 提摩太後書 2:25–26"> 這是因為耶穌已命令污鬼離開那人。那人多次被污鬼操縱，人們用鐵鏈腳鐐把他鎖起來看管，他竟把鎖鏈也扯斷，被鬼催逼到荒野。</span>
<span className="v" id="v30" data-v="30" data-xref="馬太福音 26:53; 路加福音 8:2; 馬太福音 8:29"> 耶穌問他：「你叫什麼名字？」 他說：「群。」因為有一大群鬼附在那人身上。</span>
<span className="v" id="v31" data-v="31" data-xref="馬太福音 25:41; 腓立比書 2:10–11; 約伯記 2:5"> 鬼不斷央求耶穌不要叫牠們到無底坑去。</span>
<span className="v" id="v32" data-v="32" data-xref="以賽亞書 65:4; 以賽亞書 66:3; 啟示錄 20:7"> 當時有一大群豬在山坡上吃食，污鬼就央求耶穌准許牠們進入豬群，耶穌答應了。</span>
<span className="v" id="v33" data-v="33" data-xref="彼得前書 5:8; 約翰福音 8:44; 路加福音 8:22–23"> 於是那群鬼便離開那人，進入豬群。那群豬就一路奔下陡坡，衝進湖裡淹死了。</span>
<span className="v" id="v34" data-v="34" data-xref="馬可福音 5:14; 馬太福音 8:33; 馬太福音 28:11"> 放豬的人見狀就逃走了，把這事傳遍了城裡鄉間。</span>
<span className="v" id="v35" data-v="35" data-xref="路加福音 10:39; 使徒行傳 22:3; 約翰一書 3:8"> 人們出來看個究竟，到了耶穌那裡，發現那曾被鬼附身的人衣著整齊、神智清醒地坐在耶穌腳前，他們都很害怕。</span>
<span className="v" id="v36" data-v="36" data-xref="馬太福音 4:24"> 目擊者把被鬼附身的人得救的經過告訴了他們。</span>
<span className="v" id="v37" data-v="37" data-xref="使徒行傳 16:39; 路加福音 8:28; 路加福音 10:10–11"> 格拉森地區的居民都十分害怕，請求耶穌離開那裡，耶穌便乘船回去了。</span>
<span className="v" id="v38" data-v="38" data-xref="使徒行傳 9:13–16; 馬可福音 5:18–20; 詩篇 145:3–12"> 那不再被鬼附身的人懇求耶穌讓他隨行，耶穌卻讓他回去，說：</span>
<span className="v" id="v39" data-v="39" data-xref="路加福音 17:15–18; 提摩太前書 5:8; 申命記 10:21"> 「你回家吧，把上帝為你所行的奇事告訴別人。」他就回去，走遍全城，四處傳揚耶穌為他所行的奇事。</span>
</div>
</div>

## 雅魯求救

<div className="bt">
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="馬太福音 9:1; 馬可福音 5:21; 馬可福音 6:20"> 耶穌回到對岸，在那裡等候的百姓都歡迎祂。</span>
<span className="v" id="v41" data-v="41" data-xref="馬可福音 5:22–43; 路加福音 13:14; 使徒行傳 18:8"> 有個名叫雅魯的會堂主管走過來俯伏在耶穌腳前，求耶穌到他家去，</span>
<span className="v" id="v42" data-v="42" data-xref="路加福音 7:12; 路加福音 8:45; 約伯記 1:18–19"> 因為他有一個大約十二歲的獨生女快要死了。 耶穌前去雅魯家的時候，人群擁擠著祂。</span>
</div>
</div>

## 患血漏病婦人的信心

<div className="bt">
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="馬可福音 5:25–26; 馬太福音 9:20–22; 利未記 15:25–33"> 有一個患了十二年血漏病的婦人耗盡了積蓄，到處求醫，但沒有人能醫治她。</span>
<span className="v" id="v44" data-v="44" data-xref="馬可福音 5:27–28; 申命記 22:12; 使徒行傳 19:12"> 婦人擠到耶穌的背後，摸了祂衣服的穗子，她的血漏立刻止住了。</span>
<span className="v" id="v45" data-v="45" data-xref="馬可福音 5:30–32; 路加福音 9:13; 路加福音 5:5"> 耶穌問：「誰摸我？」沒有人承認。 彼得說：「老師，眾人都在擁擠你。」</span>
<span className="v" id="v46" data-v="46" data-xref="路加福音 6:19; 路加福音 5:17; 彼得前書 2:9"> 耶穌卻說：「一定有人摸了我，因為我感覺有能力從我身上發出。」</span>
<span className="v" id="v47" data-v="47" data-xref="馬可福音 5:33; 路加福音 17:15–16; 哥林多前書 2:3"> 那婦人知道無法隱瞞，就戰戰兢兢地走過來，俯伏在耶穌腳前，把她摸耶穌的原因及怎樣立刻痊癒的經過當眾說了出來。</span>
<span className="v" id="v48" data-v="48" data-xref="路加福音 7:50; 馬太福音 9:22; 希伯來書 4:2"> 耶穌對她說：「女兒，你的信心救了你！安心去吧。」</span>
</div>
</div>

## 雅魯女兒死而復活

<div className="bt">
<div className="bp">
<span className="v" id="v49" data-v="49" data-xref="馬可福音 5:35–43; 以賽亞書 7:12; 路加福音 7:6"> 耶穌還在說話的時候，有人從雅魯家趕來，對雅魯說：「你的女兒已經死了，不用麻煩老師了。」</span>
<span className="v" id="v50" data-v="50" data-xref="約翰福音 11:40; 約翰福音 11:25; 馬可福音 5:36"> 耶穌聽了，就對雅魯說：「不要怕，只要信。你的女兒一定會好的！」</span>
<span className="v" id="v51" data-v="51" data-xref="馬可福音 14:33; 馬太福音 6:5–6; 列王紀上 17:19–23"> 到了雅魯家，耶穌只准彼得、雅各、約翰和女孩的父母跟祂進去。</span>
<span className="v" id="v52" data-v="52" data-xref="路加福音 23:27; 約翰福音 11:4; 撒迦利亞書 12:10"> 人們都在為那女孩哀傷哭泣，耶穌說：「不要哭，她沒有死，只是睡著了。」</span>
<span className="v" id="v53" data-v="53" data-xref="路加福音 16:14; 以賽亞書 53:3; 約翰福音 11:39"> 眾人就譏笑祂，因為他們都知道那女孩死了。</span>
<span className="v" id="v54" data-v="54" data-xref="耶利米書 31:32; 約翰福音 11:43; 馬可福音 1:31"> 耶穌拉著那女孩的手，說：「孩子，起來！」</span>
<span className="v" id="v55" data-v="55" data-xref="約翰福音 11:44; 列王紀上 17:21–23; 馬可福音 5:43"> 她的靈魂就回來了，她立刻起來了。耶穌吩咐人給她東西吃。</span>
<span className="v" id="v56" data-v="56" data-xref="馬太福音 8:4; 馬太福音 9:30; 路加福音 5:14"> 她的父母非常驚訝，耶穌卻囑咐他們不要把這事傳開。</span>
</div>

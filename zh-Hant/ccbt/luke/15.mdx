## 迷失的羊

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="提摩太前書 1:15; 馬太福音 9:10–13; 路加福音 5:29–32"> 許多稅吏和罪人都來聽耶穌講道，</span>
<span className="v" id="v2" data-v="2" data-xref="馬太福音 9:11; 路加福音 19:7; 路加福音 7:39"> 法利賽人和律法教師埋怨說：「這個人竟和罪人來往，還跟他們一起吃飯。」</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3"> 耶穌給他們講了一個比喻：</span>
<span className="v" id="v4" data-v="4" data-xref="以西結書 34:16; 以西結書 34:11–12; 馬太福音 18:12–14"> 「假如你們當中有人有一百隻羊，走失了一隻，難道他不暫時把那九十九隻留在草場上，去找那隻迷失的羊，一直到找著為止嗎？</span>
<span className="v" id="v5" data-v="5" data-xref="希伯來書 12:2; 路加福音 19:9; 以賽亞書 46:3–4"> 他找到後，會歡歡喜喜地把那隻羊扛回家，</span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 15:10; 路加福音 15:24; 彼得前書 2:25"> 並邀來朋友鄰居，說，『我走失的羊找到了，來和我一同慶祝吧！』</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 5:32; 路加福音 15:10; 路加福音 15:32"> 我告訴你們，一個罪人悔改，在天上也要這樣為他歡喜，甚至比有九十九個不用悔改的義人還歡喜。</span>
</div>
</div>

## 丟錢的比喻

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="路加福音 19:10; 以西結書 34:12; 約翰福音 10:16"> 「又比如一個婦人有十塊錢，弄丟了一塊，難道她不點亮燈，打掃房子，仔細尋找一直到找著為止嗎？</span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 15:6–7"> 她找到後，會邀朋友鄰居來，說，『我丟的錢找到了，來和我一同慶祝吧！』</span>
<span className="v" id="v10" data-v="10" data-xref="路加福音 15:7; 哥林多後書 7:10; 以西結書 33:11"> 我告訴你們，一個罪人悔改，上帝的眾天使也會這樣為他歡喜。」</span>
</div>
</div>

## 浪子回頭

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="馬太福音 21:23–31"> 耶穌又說：「某人有兩個兒子。</span>
<span className="v" id="v12" data-v="12" data-xref="申命記 21:16–17; 馬可福音 12:44; 路加福音 15:30"> 小兒子對父親說，『父親，請你把我應得的家產分給我。』父親就把財產分給了兩個兒子。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="箴言 29:3; 耶利米書 2:5; 箴言 21:17"> 「沒過幾天，小兒子帶著他所有的財物出門遠遊去了。他終日在外花天酒地，揮金如土，</span>
<span className="v" id="v14" data-v="14" data-xref="歷代志下 33:11; 阿摩司書 8:9–12; 何西阿書 2:9–14"> 很快囊空如洗，又遇到嚴重的饑荒，就窮困潦倒，</span>
<span className="v" id="v15" data-v="15" data-xref="提多書 3:3; 提摩太後書 2:25–26; 以賽亞書 1:5"> 只好投靠一個當地人。那人派他到田裡去放豬，</span>
<span className="v" id="v16" data-v="16" data-xref="羅馬書 6:19–21; 耶利米哀歌 4:5; 何西阿書 12:1"> 他餓到恨不得拿餵豬的豆莢充饑，可是連這些也沒有人給他。</span>
<span className="v" id="v17" data-v="17" data-xref="以西結書 18:28; 以弗所書 2:4–5; 路加福音 15:18–19"> 最後，他醒悟過來，心想，『我父親家那麼多僱工的口糧都綽綽有餘，我現在卻要在這裡餓死嗎？</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米哀歌 3:40; 約翰一書 1:8–10; 路加福音 15:21"> 我要動身回到我父親身邊，對他說，父親，我得罪了天，也得罪了你，</span>
<span className="v" id="v19" data-v="19" data-xref="約伯記 42:6; 路加福音 5:8; 詩篇 84:10"> 今後，我再也不配作你的兒子，請把我當作僱工看待吧。』</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 103:10–13; 詩篇 86:5; 詩篇 86:15"> 於是他動身回父親那裡。<br />「他父親遠遠地看見他，就動了慈心，跑上前去抱著他連連親吻。</span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 51:4; 路加福音 15:18–19; 耶利米書 3:13"> 小兒子說，『父親，我得罪了天，也得罪了你，今後，我再也不配作你的兒子。』</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="創世記 41:42; 以斯帖記 8:2; 啟示錄 6:11"> 「父親卻對奴僕說，『趕快拿最好的袍子來給他穿上，給他戴上戒指，穿上鞋，</span>
<span className="v" id="v23" data-v="23" data-xref="以賽亞書 25:6; 馬太福音 22:2–14; 詩篇 63:5"> 把那頭肥牛犢牽來宰了，讓我們一同歡宴慶祝！</span>
<span className="v" id="v24" data-v="24" data-xref="以弗所書 2:5; 以西結書 34:16; 路加福音 19:10"> 因我這兒子是死而復活、失而復得的。』於是他們開始歡慶。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="詩篇 150:4; 耶利米書 31:4; 路加福音 15:11–12"> 「那時，大兒子正在田間。他回來還沒到門口，就聽見家裡傳出奏樂跳舞的聲音。</span>
<span className="v" id="v26" data-v="26"> 他叫來一個奴僕問個究竟。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="使徒行傳 9:17; 腓利門書 1:16; 使徒行傳 22:13"> 「奴僕回答說，『你弟弟回來了！你父親因他安然無恙地回來，特地宰了那頭肥牛犢。』</span>
<span className="v" id="v28" data-v="28" data-xref="約拿書 4:9; 撒母耳記上 18:8; 約拿書 4:1–4"> 大兒子很生氣，不肯進去。父親就出來勸他。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="路加福音 18:11–12; 撒迦利亞書 7:3; 以賽亞書 65:5"> 「他對父親說，『你看，我伺候你這麼多年，從來沒有違背過你的命令，可是你沒有給過我一隻羊羔，讓我和朋友一同歡宴。</span>
<span className="v" id="v30" data-v="30" data-xref="箴言 29:3; 路加福音 15:12–13; 路加福音 15:32"> 但你這個兒子在娼妓身上耗盡家財，一回來，你倒為他宰了肥牛犢！』</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="馬可福音 7:27–28; 羅馬書 9:4; 羅馬書 11:1"> 「父親對他說，『孩子啊！你一直在我身邊，我所有的一切都是你的。</span>
<span className="v" id="v32" data-v="32" data-xref="以弗所書 2:1–10; 路加福音 15:24; 以賽亞書 35:10"> 可是你弟弟是死而復活、失而復得的，所以我們應該歡喜快樂。』」</span>
</div>
</div>

## 天使預告施洗者約翰出生

<div className="bt">
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="歷代志上 24:10; 馬太福音 2:1; 尼希米記 12:4"> 猶太王希律執政期間，亞比雅班裡有位祭司名叫撒迦利亞，他妻子伊莉莎白是亞倫的後裔。</span>
<span className="v" id="v6" data-v="6" data-xref="創世記 7:1; 創世記 17:1; 腓立比書 2:15"> 夫妻二人遵行主的一切誡命和條例，無可指責，在上帝眼中是義人。</span>
<span className="v" id="v7" data-v="7" data-xref="希伯來書 11:11; 創世記 18:11; 撒母耳記上 1:2"> 但他們沒有孩子，因為伊莉莎白不能生育，二人又年紀老邁。</span>
<span className="v" id="v8" data-v="8" data-xref="歷代志下 8:14; 歷代志上 24:19; 歷代志下 31:2"> 有一天，輪到撒迦利亞那一班祭司在上帝面前司職，</span>
<span className="v" id="v9" data-v="9" data-xref="歷代志下 29:11; 出埃及記 30:7–8; 歷代志上 23:13"> 他們按照祭司的規矩抽籤，抽中撒迦利亞到主的殿裡去燒香。</span>
<span className="v" id="v10" data-v="10" data-xref="利未記 16:17; 啟示錄 8:3; 希伯來書 4:14"> 他燒香的時候，眾百姓都在外面禱告。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及記 40:26–27; 使徒行傳 10:3–4; 士師記 13:3"> 那時，主的天使站在香壇的右邊向撒迦利亞顯現，</span>
<span className="v" id="v12" data-v="12" data-xref="士師記 13:22; 士師記 6:22; 路加福音 2:9–10"> 撒迦利亞見了，又驚又怕。</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳記上 2:21; 使徒行傳 10:31; 創世記 25:21"> 天使對他說：「撒迦利亞，不要害怕，你的禱告已蒙垂聽。你的妻子伊莉莎白要為你生一個兒子，你要給他取名叫約翰。</span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 1:58; 箴言 23:24; 創世記 21:6"> 你必歡喜快樂，許多人也會因為他的誕生而欣喜雀躍，</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米書 1:5; 民數記 6:2–4; 路加福音 7:33"> 因為他將成為主眼中偉大的僕人。他必滴酒不沾，並且在母腹裡就被聖靈充滿。</span>
<span className="v" id="v16" data-v="16" data-xref="以賽亞書 40:3–5; 馬太福音 21:32; 瑪拉基書 3:1"> 他將使許多以色列人回心轉意，歸順主——他們的上帝。</span>
<span className="v" id="v17" data-v="17" data-xref="瑪拉基書 4:5–6; 馬太福音 11:14; 路加福音 1:76"> 他將以先知以利亞的心志和能力作主的先鋒，使父親的心轉向兒女，使叛逆的人轉向義人的智慧，為主預備合用的子民。」</span>
<span className="v" id="v18" data-v="18" data-xref="以賽亞書 38:22; 創世記 17:17; 路加福音 1:7"> 撒迦利亞對天使說：「我已經老了，我的妻子也上了年紀，我怎麼能確定這件事呢？」</span>
<span className="v" id="v19" data-v="19" data-xref="路加福音 1:26; 馬太福音 18:10; 但以理書 9:21–23"> 天使回答說：「我是侍立在上帝面前的加百列，奉命來向你報這喜訊。</span>
<span className="v" id="v20" data-v="20" data-xref="以西結書 3:26; 以西結書 24:27; 路加福音 1:22"> 我說的這些話到時候必定應驗。但因為你不肯相信我的話，所以這事成就以前，你會變成啞巴，不能說話。」</span>
<span className="v" id="v21" data-v="21" data-xref="民數記 6:23–27"> 人們在等候撒迦利亞，見他在聖殿裡遲遲不出來，都感到奇怪。</span>
<span className="v" id="v22" data-v="22" data-xref="路加福音 1:62; 約翰福音 13:24; 使徒行傳 21:40"> 後來他出來了，卻成了啞巴，不能說話，只能打手勢，人們意識到他在聖殿裡看見了異象。</span>
<span className="v" id="v23" data-v="23" data-xref="歷代志上 9:25; 列王紀下 11:5–7"> 撒迦利亞供職期滿，就回家去了。</span>
<span className="v" id="v24" data-v="24"> 之後，伊莉莎白果然懷了孕，她有五個月閉門不出。</span>
<span className="v" id="v25" data-v="25" data-xref="創世記 30:22–23; 以賽亞書 54:1–4; 創世記 21:1–2"> 她說：「主真是眷顧我，除掉了我在人群中的羞恥。」</span>
</div>
</div>

## 天使預告耶穌降生

<div className="bt">
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="馬太福音 2:23; 路加福音 1:19; 約翰福音 7:41"> 伊莉莎白懷孕六個月的時候，天使加百列又奉上帝的命令到加利利的拿撒勒，</span>
<span className="v" id="v27" data-v="27" data-xref="馬太福音 1:18; 以賽亞書 7:14; 馬太福音 1:16"> 去見一位叫瑪麗亞的童貞女。瑪麗亞已經和大衛的後裔約瑟訂了婚。</span>
<span className="v" id="v28" data-v="28" data-xref="士師記 6:12; 但以理書 10:19; 路加福音 1:30"> 天使到了瑪麗亞那裡，說：「恭喜你，蒙大恩的女子，主與你同在！」</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行傳 10:17; 路加福音 1:12; 使徒行傳 10:4"> 瑪麗亞聽了覺得十分困惑，反覆思想這話的意思。</span>
<span className="v" id="v30" data-v="30" data-xref="路加福音 1:13; 羅馬書 8:31; 路加福音 12:32"> 天使對她說：「瑪麗亞，不要害怕，你在上帝面前已經蒙恩了。</span>
<span className="v" id="v31" data-v="31" data-xref="以賽亞書 7:14; 馬太福音 1:21; 馬太福音 1:25"> 聽著，你要懷孕生子，並給祂取名叫耶穌。</span>
<span className="v" id="v32" data-v="32" data-xref="以賽亞書 9:6–7; 以賽亞書 16:5; 撒母耳記下 7:11–13"> 祂偉大無比，將被稱為至高者的兒子，主上帝要把祂祖先大衛的王位賜給祂。</span>
<span className="v" id="v33" data-v="33" data-xref="但以理書 2:44; 希伯來書 1:8; 但以理書 7:13–14"> 祂要永遠統治雅各家，祂的國度永無窮盡。」</span>
<span className="v" id="v34" data-v="34" data-xref="士師記 13:8–12; 使徒行傳 9:6"> 瑪麗亞對天使說：「這怎麼可能呢？我還是童貞女。」</span>
<span className="v" id="v35" data-v="35" data-xref="馬太福音 1:18; 約翰福音 1:49; 馬太福音 1:20"> 天使回答說：「聖靈要臨到你身上，至高者的能力要蔭庇你，所以你要生的那聖嬰必稱為上帝的兒子。</span>
<span className="v" id="v36" data-v="36"> 看啊，你的親戚伊莉莎白年紀老邁，一向不能生育，現在已經懷男胎六個月了。</span>
<span className="v" id="v37" data-v="37" data-xref="馬太福音 19:26; 耶利米書 32:27; 馬可福音 10:27"> 因為上帝無所不能。」</span>
<span className="v" id="v38" data-v="38" data-xref="羅馬書 4:20–21; 詩篇 119:38; 詩篇 116:16"> 瑪麗亞說：「我是主的婢女，願你所說的話在我身上成就。」於是天使離開了她。</span>
</div>
</div>

## 瑪麗亞看望伊莉莎白

<div className="bt">
<div className="bp poetry">
<span className="v" id="v39" data-v="39" data-xref="路加福音 1:65; 約書亞記 15:48–59; 約書亞記 10:40"> 不久，瑪麗亞便動身趕往猶太山區的一座城，</span>
<span className="v" id="v40" data-v="40"> 進了撒迦利亞的家，向伊莉莎白請安。</span>
<span className="v" id="v41" data-v="41" data-xref="路加福音 1:67; 使徒行傳 4:8; 路加福音 1:44"> 伊莉莎白一聽見瑪麗亞的問安，腹中的胎兒便跳動起來，伊莉莎白被聖靈充滿，</span>
<span className="v" id="v42" data-v="42" data-xref="路加福音 1:28; 士師記 5:24; 創世記 22:18"> 高聲呼喊：「在婦女中你是最蒙福的！你腹中的孩子也是蒙福的！</span>
<span className="v" id="v43" data-v="43" data-xref="約翰福音 20:28; 約翰福音 13:13; 路加福音 2:11"> 我主的母親來探望我，我怎麼敢當呢？</span>
<span className="v" id="v44" data-v="44"> 我一聽到你問安的聲音，腹中的孩子就歡喜跳動。</span>

<span className="v" id="v48" data-v="48" data-xref="詩篇 138:6; 瑪拉基書 3:12; 哥林多前書 1:26–28"> <span className="pl pl-1">因祂眷顧我這卑微的婢女，</span><br /><span className="pl pl-1">從今以後，</span><br /><span className="pl pl-1">世世代代都要稱我是有福的。</span><br /></span>

## 施洗者約翰出生

<div className="bt">
<div className="bp">
<span className="v" id="v57" data-v="57" data-xref="路加福音 1:13; 創世記 21:2–3; 路加福音 2:6–7"> 伊莉莎白的產期到了，生下一個兒子。</span>
<span className="v" id="v58" data-v="58" data-xref="路加福音 1:25; 路加福音 1:14; 羅馬書 12:15"> 親戚和鄰居聽見主向她大施憐憫，都和她一同歡樂。</span>
<span className="v" id="v59" data-v="59" data-xref="創世記 17:12; 利未記 12:3; 腓立比書 3:5"> 到了第八天，他們來給孩子行割禮，想照他父親的名字給他取名叫撒迦利亞。</span>
<span className="v" id="v60" data-v="60" data-xref="路加福音 1:13; 撒母耳記下 12:25; 路加福音 1:63"> 但伊莉莎白說：「不！要叫他約翰。」</span>
<span className="v" id="v61" data-v="61"> 他們說：「你們家族中沒有人用這個名字啊！」</span>
<span className="v" id="v62" data-v="62" data-xref="路加福音 1:22"> 他們便向他父親打手勢，問他要給孩子起什麼名字。</span>

<span className="v" id="v64" data-v="64" data-xref="路加福音 1:20; 出埃及記 4:15–16; 以西結書 33:22"> 突然，撒迦利亞可以開口了，舌頭也靈活了，便開口讚美上帝。</span>

<span className="v" id="v66" data-v="66" data-xref="使徒行傳 11:21; 路加福音 2:19; 路加福音 2:51"> 聽見的人都在想：「這孩子將來會怎樣呢？因為主的能力伴隨著他。」</span>
</div>

## 撒迦利亞的預言

<div className="bt">
<div className="bp poetry">

## 安息日的主

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命記 23:25; 馬可福音 2:23–28; 馬太福音 12:1–8"> 有一個安息日，耶穌和門徒經過一片麥田，門徒掐些麥穗用手搓著吃。</span>
<span className="v" id="v2" data-v="2" data-xref="馬太福音 12:2; 約翰福音 5:16; 約翰福音 5:9–11"> 有些法利賽人說：「你們為什麼做安息日不准做的事？」</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳記上 21:3–6; 馬可福音 2:25–26; 馬太福音 12:3–5"> 耶穌答道：「你們沒有讀過大衛的事蹟嗎？當時大衛和隨從餓了，</span>
<span className="v" id="v4" data-v="4" data-xref="利未記 24:5–9"> 他進入上帝的殿，拿了獻給上帝的供餅。這餅只有祭司才可以吃，大衛不但自己吃了，還分給他的隨從吃。」</span>
<span className="v" id="v5" data-v="5" data-xref="馬可福音 2:27; 啟示錄 1:10; 馬可福音 9:7"> 耶穌又對他們說：「人子是安息日的主。」</span>
<span className="v" id="v6" data-v="6" data-xref="馬可福音 3:1–6; 馬太福音 12:9–14; 路加福音 4:31"> 又有一個安息日，耶穌進入會堂教導人，那裡有一個右手萎縮的人。</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 20:20; 詩篇 38:12; 路加福音 13:14"> 律法教師和法利賽人監視耶穌，看祂會不會在安息日治病，好找藉口控告祂。</span>
<span className="v" id="v8" data-v="8" data-xref="以賽亞書 42:4; 馬太福音 9:4; 路加福音 5:22"> 耶穌知道他們的心思，就對那個右手萎縮的人說：「起來，站在中間！」那人就起來站在那裡。</span>
<span className="v" id="v9" data-v="9" data-xref="馬可福音 3:4; 馬太福音 12:12–13; 路加福音 14:3"> 耶穌問眾人：「我問你們，在安息日應該行善呢，還是作惡呢？救人呢，還是害人呢？」</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及記 4:6–7; 馬可福音 3:5; 約翰福音 5:8"> 祂環視眾人，然後對那人說：「把手伸出來！」那人的手一伸就復原了。</span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 2:1–2; 使徒行傳 5:33; 傳道書 9:3"> 但法利賽人和律法教師卻怒火中燒，開始商議對付耶穌的辦法。</span>
</div>
</div>

## 揀選十二使徒

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="希伯來書 5:7; 馬可福音 6:46; 馬可福音 1:35"> 一天，耶穌出去到山上整夜向上帝禱告。</span>
<span className="v" id="v13" data-v="13" data-xref="馬可福音 3:13–19; 馬太福音 9:36–4; 啟示錄 21:14"> 天明時分，祂召集門徒，從中選出十二人立為使徒。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行傳 1:13; 馬太福音 4:21; 馬太福音 4:18"> 他們是：西門——耶穌給他取名叫彼得、西門的兄弟安得烈、雅各、約翰、腓力、巴多羅買、</span>
<span className="v" id="v15" data-v="15" data-xref="馬太福音 9:9; 馬可福音 3:18; 使徒行傳 1:13"> 馬太、多馬、亞勒腓的兒子雅各、激進黨人<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="當時激進的民族主義者，常以行動反抗統治他們的羅馬政府。">a</a></sup>西門、</span>
<span className="v" id="v16" data-v="16" data-xref="約翰福音 14:22; 約翰福音 6:70–71; 馬可福音 3:18"> 雅各的兒子猶大和出賣耶穌的加略人猶大。</span>
<span className="v" id="v17" data-v="17" data-xref="馬太福音 11:21; 馬太福音 4:23–25; 詩篇 107:17–20"> 耶穌和他們下了山，站在一處平地上，身邊有一大群門徒，還有大批從猶太、耶路撒冷以及泰爾和西頓沿海地區來的人，</span>
<span className="v" id="v18" data-v="18" data-xref="馬太福音 17:15; 馬太福音 15:22; 使徒行傳 5:16"> 要聽祂講道，盼望祂醫治他們的疾病。那些被污鬼纏身的人也得到了醫治。</span>
<span className="v" id="v19" data-v="19" data-xref="馬太福音 14:36; 馬可福音 3:10; 使徒行傳 5:15–16"> 眾人都想去摸祂，因為有能力從祂身上發出來，治好了所有人。</span>
</div>
</div>

## 論四福

<div className="bt">
<div className="bp poetry">
<span className="v" id="v20" data-v="20" data-xref="雅各書 2:5; 路加福音 6:20–24; 哥林多後書 8:9"> 耶穌抬頭望著門徒，對他們說：<br /><span className="pl pl-1">「貧窮的人有福了，</span><br /><span className="pl pl-1">因為上帝的國屬於你們！</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="約翰福音 6:35; 馬太福音 5:6; 雅各書 1:12"> <span className="pl pl-1">現在饑餓的人有福了，</span><br /><span className="pl pl-1">因為你們將得飽足！</span><br /><span className="pl pl-1">現在哀哭的人有福了，</span><br /><span className="pl pl-1">因為你們將要歡笑！</span></span>
<span className="v" id="v22" data-v="22" data-xref="馬太福音 5:10–12; 馬太福音 10:22; 彼得前書 4:12–16"> 你們為人子的緣故遭人憎恨、棄絕、侮辱、毀謗，就有福了！</span>
<span className="v" id="v23" data-v="23" data-xref="使徒行傳 5:41; 啟示錄 21:7; 啟示錄 3:12"> 那時你們要歡喜雀躍，因為你們在天上有大賞賜！他們的祖先也曾這樣惡待以前的先知。</span>
</div>
</div>

## 論四禍

<div className="bt">
<div className="bp poetry">
<span className="v" id="v24" data-v="24" data-xref="馬太福音 6:2; 雅各書 5:1–6; 詩篇 49:6–7"> <span className="pl pl-1">「富有的人有禍了，</span><br /><span className="pl pl-1">因為你們已經享盡了人世間的安逸！</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="以賽亞書 65:13; 雅各書 4:9; 箴言 14:13"> <span className="pl pl-1">現在飽足的人有禍了，</span><br /><span className="pl pl-1">因為你們將要挨餓！</span><br /><span className="pl pl-1">現在歡笑的人有禍了，</span><br /><span className="pl pl-1">因為你們將要哀哭！</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="約翰福音 15:19; 雅各書 4:4; 馬太福音 7:15"> <span className="pl pl-1">人人都誇讚你們的時候，</span><br /><span className="pl pl-1">你們就有禍了，</span><br /><span className="pl pl-1">因為他們的祖先也是這樣誇讚假先知！</span></span>
</div>
</div>

## 論愛仇敵

<div className="bt">
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="帖撒羅尼迦前書 5:15; 路加福音 6:35; 羅馬書 12:17–21"> 「但是，我告訴你們這些聽道的人，要愛你們的仇敵，要善待恨你們的人，</span>
<span className="v" id="v28" data-v="28" data-xref="彼得前書 3:9; 哥林多前書 4:12; 羅馬書 12:14"> 要為咒詛你們的人祝福，要為惡待你們的人禱告。</span>
<span className="v" id="v29" data-v="29" data-xref="希伯來書 10:34; 馬太福音 5:39–42; 哥林多後書 11:20"> 如果有人打你一邊的臉，連另一邊也轉過來讓他打。如果有人奪你的外衣，連內衣也由他拿去。</span>
<span className="v" id="v30" data-v="30" data-xref="申命記 15:7–10; 哥林多後書 9:6–14; 馬太福音 6:12"> 有人向你求什麼，就給他；有人拿了你的東西，不要追討。</span>
<span className="v" id="v31" data-v="31" data-xref="馬太福音 7:12; 加拉太書 5:14; 馬太福音 22:39"> 想要別人怎樣對待你們，你們就要怎樣對待別人。</span>
<span className="v" id="v32" data-v="32" data-xref="馬太福音 5:46–47; 彼得前書 2:19–20"> 如果你們只愛那些愛你們的人，有什麼功勞呢？就是罪人也會這樣做。</span>
<span className="v" id="v33" data-v="33"> 如果你們只善待那些善待你們的人，有什麼功勞呢？就是罪人也會這樣做。</span>
<span className="v" id="v34" data-v="34" data-xref="馬太福音 5:42; 路加福音 14:12–14; 路加福音 6:35"> 如果你們借錢給人，指望收回，有什麼功勞呢？即使罪人也會借給罪人，日後再如數收回。</span>
<span className="v" id="v35" data-v="35" data-xref="馬太福音 5:44–45; 約翰福音 13:35; 箴言 19:17"> 「然而，要愛你們的仇敵，善待他們，借給人什麼不要指望償還。這樣，你們將有大賞賜，並且將成為至高者的兒子，因為祂恩待那些忘恩負義和作惡的人。</span>
<span className="v" id="v36" data-v="36" data-xref="以弗所書 5:1–2; 馬太福音 5:48; 彼得前書 1:15–16"> 你們要憐憫人，像你們的天父憐憫人一樣。</span>
</div>
</div>

## 責人先責己

<div className="bt">
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="以弗所書 4:32; 雅各書 5:9; 馬太福音 7:1–5"> 「不要論斷人，免得你們被論斷；不要定人的罪，免得你們也被定罪。要饒恕人，這樣你們也必蒙饒恕。</span>
<span className="v" id="v38" data-v="38" data-xref="哥林多後書 9:6–8; 申命記 15:10; 馬可福音 4:24"> 你們要給他人，這樣上帝必給你們，並且會用大號升斗搖勻壓實，滿滿地倒給你們，因為你們用什麼量器量給別人，上帝也會用什麼量器量給你們。」</span>
<span className="v" id="v39" data-v="39" data-xref="馬太福音 15:14; 提摩太後書 3:13; 提摩太前書 6:3–5"> 耶穌又給他們講了個比喻，說：「瞎眼的豈能給瞎眼的領路？二人豈不都要掉進坑裡嗎？</span>
<span className="v" id="v40" data-v="40" data-xref="約翰福音 13:16; 馬太福音 10:24–25; 約翰福音 15:20"> 學生不能高過老師，學成之後不過像老師一樣。</span>
<span className="v" id="v41" data-v="41" data-xref="約翰福音 8:7; 雅各書 1:24; 羅馬書 2:1"> 為什麼你只看見你弟兄眼中的小刺，卻看不見自己眼中的大梁呢？</span>
<span className="v" id="v42" data-v="42" data-xref="羅馬書 2:21–29; 帖撒羅尼迦前書 2:10–12; 詩篇 51:9–13"> 你既看不見自己眼中的大梁，又怎能對弟兄說『讓我除去你眼中的小刺』呢？你這偽君子啊！要先除掉自己眼中的大梁，才能看得清楚，好清除弟兄眼中的小刺。</span>
</div>
</div>

## 樹和果子

<div className="bt">
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="耶利米書 2:21; 馬太福音 12:33; 馬太福音 7:16–20"> 「好樹不結壞果子，壞樹也不結好果子。</span>
<span className="v" id="v44" data-v="44" data-xref="馬太福音 12:33; 雅各書 3:12; 加拉太書 5:19–23"> 樹的好壞從果子就可以分辨出來。人不會從荊棘中採集無花果，也不會在蒺藜上摘取葡萄。</span>
<span className="v" id="v45" data-v="45" data-xref="箴言 4:23; 馬太福音 12:34–37; 以弗所書 4:29"> 善人心存良善，就從他裡面發出良善；惡人心存邪惡，就從他裡面發出邪惡。因為心裡充滿的，口裡自然會說出來。</span>
</div>
</div>

## 兩種蓋房子的人

<div className="bt">
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="加拉太書 6:7; 瑪拉基書 1:6; 馬太福音 7:21–23"> 「你們為什麼『主啊，主啊』地稱呼我，卻不遵行我的話呢？</span>
<span className="v" id="v47" data-v="47" data-xref="雅各書 1:22–25; 馬太福音 7:24–27; 路加福音 11:28"> 我要告訴你們那到我這裡來，聽了我的話又去遵行的人是什麼樣。</span>
<span className="v" id="v48" data-v="48" data-xref="哥林多前書 3:10–15; 詩篇 62:2; 馬太福音 7:25–26"> 他好比一個人蓋房子，把地挖深，將根基立在磐石上。當河流氾濫，洪水沖擊那房子時，房子仍屹立不搖，因為它的根基穩固。</span>
<span className="v" id="v49" data-v="49" data-xref="以西結書 33:31; 雅各書 1:22–26; 馬太福音 23:3"> 但聽了我的話卻不遵行的人，好比一個人沒有打根基，便將房子蓋在地面上，洪水一沖，那房子立刻倒塌，完全毀壞了。」</span>
</div>

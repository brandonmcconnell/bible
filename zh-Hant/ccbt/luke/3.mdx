## 施洗者約翰的傳道

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="路加福音 23:24; 創世記 49:10; 路加福音 9:7"> 凱撒提庇留執政第十五年，本丟·彼拉多任猶太總督，希律做加利利的分封王，他的弟弟腓力做以土利亞和特拉可尼兩地的分封王，呂撒聶做亞比利尼的分封王，</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行傳 4:6; 約翰福音 18:24; 路加福音 1:80"> 亞那和該亞法當大祭司。當時，上帝的話臨到曠野中撒迦利亞的兒子約翰。</span>
<span className="v" id="v3" data-v="3" data-xref="路加福音 1:77; 馬太福音 3:5–6; 使徒行傳 13:24"> 他就到約旦河附近宣講悔改就得赦罪的洗禮。</span>
<span className="v" id="v4" data-v="4" data-xref="以賽亞書 40:3–5; 約翰福音 1:23; 路加福音 1:76–79"> 這正應驗了以賽亞先知書上的話：「有人在曠野大聲呼喊，<br /><span className="pl pl-1">「『預備主的道，</span><br /><span className="pl pl-1">修直祂的路。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="以賽亞書 40:4; 以賽亞書 42:16; 以賽亞書 45:2"> <span className="pl pl-1">一切山谷要被填滿，</span><br /><span className="pl pl-1">大山小丘要被削平，</span><br /><span className="pl pl-1">彎曲的道路要變得筆直，</span><br /><span className="pl pl-1">崎嶇的路徑要變得平坦。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="以賽亞書 52:10; 以賽亞書 40:5; 詩篇 98:2–3"> <span className="pl pl-1">世人都要看見上帝的救恩。』</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="以賽亞書40·3‑5。">a</a></sup><br /><span className="pl pl-1">」</span></span>
<span className="v" id="v7" data-v="7" data-xref="馬太福音 23:33; 馬太福音 12:34; 帖撒羅尼迦前書 1:10"> 約翰對前來接受他洗禮的人群說：「你們這些毒蛇的後代！誰指示你們逃避那將臨的烈怒呢？</span>
<span className="v" id="v8" data-v="8" data-xref="以西結書 18:27–31; 使徒行傳 26:20; 以賽亞書 1:16–18"> 你們要結出與悔改相稱的果子。不要心裡說，『我們是亞伯拉罕的子孫。』我告訴你們，上帝可以從這些石頭中興起亞伯拉罕的子孫。</span>
<span className="v" id="v9" data-v="9" data-xref="馬太福音 7:19; 約翰福音 15:6; 路加福音 13:9"> 現在斧頭已經放在樹根上了，凡不結好果子的樹都要被砍下扔進火裡。」</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行傳 2:37; 路加福音 3:14; 使徒行傳 16:30"> 眾人問道：「那麼，我們該怎麼辦呢？」</span>
<span className="v" id="v11" data-v="11" data-xref="以賽亞書 58:7–11; 約翰一書 3:17; 提摩太前書 6:18"> 約翰回答說：「有兩件衣服的，應當分一件給沒有的；食物充足的，應當分些給饑餓的。」</span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 7:29; 路加福音 15:1–2; 路加福音 18:13"> 有些稅吏也來受洗，並問約翰：「老師，我們該怎麼辦呢？」</span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 19:8; 以弗所書 4:28; 哥林多前書 6:10"> 約翰說：「除了規定的稅以外，一分錢也不可多收。」</span>
<span className="v" id="v14" data-v="14" data-xref="希伯來書 13:5–6; 出埃及記 20:16; 出埃及記 23:1"> 有些軍人問：「我們該怎麼辦呢？」約翰說：「不可敲詐勒索，自己有糧餉就當知足。」</span>
<span className="v" id="v15" data-v="15" data-xref="約翰福音 10:24; 約翰福音 3:28–29; 約翰福音 1:19–28"> 當時的百姓正期待著基督的來臨，大家心裡都在猜想，也許約翰就是基督。</span>
<span className="v" id="v16" data-v="16" data-xref="馬太福音 3:11; 使徒行傳 1:5; 使徒行傳 11:15–16"> 約翰對眾人說：「我用水給你們施洗，但有一位比我更有能力的要來，我連給祂解鞋帶都不配。祂要用聖靈和火給你們施洗。</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米書 15:7; 馬太福音 13:30; 彌迦書 4:12"> 祂手裡拿著簸箕，要揚淨祂的麥場，把麥子收進倉庫，用不滅的火把糠秕燒盡。」</span>
<span className="v" id="v18" data-v="18" data-xref="約翰福音 3:29–36; 約翰福音 1:34; 約翰福音 1:29"> 約翰向眾人傳福音，講了許多勸勉的話。</span>
<span className="v" id="v19" data-v="19" data-xref="路加福音 3:1; 馬太福音 11:2; 馬可福音 6:17–18"> 分封王希律娶了自己弟弟的妻子希羅底，又做了許多惡事，因而受到約翰的指責，</span>
<span className="v" id="v20" data-v="20" data-xref="歷代志下 24:17–22; 約翰福音 3:24; 帖撒羅尼迦前書 2:15–16"> 可是他卻惡上加惡：將約翰關進監牢裡。</span>
</div>
</div>

## 耶穌受洗

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="約翰福音 1:32–34; 馬太福音 3:13–17; 約翰福音 12:27–28"> 眾人都受了洗，耶穌也接受了洗禮。祂正在禱告的時候，天開了，</span>
<span className="v" id="v22" data-v="22" data-xref="詩篇 2:7; 彼得後書 1:17–18; 約翰福音 1:32"> 聖靈降在祂身上，形狀像鴿子，又有聲音從天上傳來：「你是我的愛子，我喜悅你。」</span>
</div>
</div>

## 耶穌的家譜

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="路加福音 4:22; 馬太福音 13:55; 民數記 4:3"> 耶穌開始傳道的時候，年紀約三十歲，照人的看法， 祂是約瑟的兒子， 約瑟是希里的兒子，</span>

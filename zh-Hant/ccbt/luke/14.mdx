## 論安息日治病

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="馬可福音 3:2; 路加福音 20:20; 詩篇 62:4"> 有個安息日，耶穌到一位法利賽人的首領家裡作客，人們嚴密監視祂。</span>
<span className="v" id="v2" data-v="2"> 當時有一個患水腫病的人在耶穌面前，</span>
<span className="v" id="v3" data-v="3" data-xref="馬太福音 12:10; 馬可福音 3:4; 路加福音 13:14–16"> 耶穌問法利賽人和律法教師：「在安息日可以醫病嗎？」</span>
<span className="v" id="v4" data-v="4" data-xref="馬太福音 22:46; 馬太福音 21:25–27"> 他們都閉口不言。耶穌便扶著那人把他治好，叫他走了，</span>
<span className="v" id="v5" data-v="5" data-xref="路加福音 13:15; 出埃及記 23:4–5; 馬太福音 12:11–12"> 然後又問他們：「如果你們有驢<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「驢」另有抄本作「兒子」。">a</a></sup>或牛在安息日掉進井裡，難道你們不會立刻把牠拉上來嗎？」</span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 20:40; 路加福音 21:15; 使徒行傳 6:10"> 他們都啞口無言。</span>
</div>
</div>

## 論謙卑

<div className="bt">
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="腓立比書 2:3; 路加福音 11:43; 馬太福音 23:6"> 耶穌在宴席中看見賓客們都挑選首位，就用比喻對他們說：</span>
<span className="v" id="v8" data-v="8" data-xref="箴言 25:6–7"> 「參加婚宴的時候，不要坐在首位，因為也許有比你尊貴的賓客來赴宴，</span>
<span className="v" id="v9" data-v="9" data-xref="箴言 16:18; 箴言 11:2; 箴言 3:35"> 主人會把他帶到你面前，說，『請你把首位讓給他吧！』你就要滿面羞愧地退到末位去了。</span>
<span className="v" id="v10" data-v="10" data-xref="箴言 25:6–7; 箴言 15:33; 撒母耳記上 15:17"> 你去赴宴時，應該坐在末位，這樣主人會對你說，『朋友，請上坐！』那時，你在賓客面前就有光彩了。</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 18:14; 馬太福音 23:12; 箴言 29:23"> 因為自高的人必遭貶抑，謙卑的人必得尊榮。」</span>
</div>
</div>

## 論待客之道

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="馬太福音 5:46; 雅各書 2:1–6; 路加福音 6:32–36"> 耶穌又對主人說：「擺設午宴、晚宴時，不要邀請你的朋友、弟兄、親戚或有錢的鄰居，免得他們回請你，你便得到報答了。</span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 14:21; 以賽亞書 58:10; 箴言 14:31"> 相反，你設宴時，要邀請貧窮的、殘疾的、瘸腿的、瞎眼的，</span>
<span className="v" id="v14" data-v="14" data-xref="箴言 19:17; 使徒行傳 24:15; 約翰福音 5:29"> 這樣你就有福了，因為他們都沒有能力回報你，到了義人復活的時候，上帝一定會賞賜你。」</span>
</div>
</div>

## 大宴席的比喻

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="啟示錄 19:9; 路加福音 22:30; 路加福音 13:29"> 同席的一個客人聽了這番話，就對耶穌說：「能夠在上帝的國坐席的人多麼有福啊！」</span>
<span className="v" id="v16" data-v="16" data-xref="馬太福音 22:2–14; 啟示錄 22:17; 以賽亞書 55:1–7"> 於是，耶穌對他說：「有一個人大擺宴席，邀請了許多客人。</span>
<span className="v" id="v17" data-v="17" data-xref="馬太福音 11:27–29; 馬太福音 10:1–4; 馬太福音 22:3–4"> 要開席的時候，主人就派奴僕去對客人說，『一切都準備好了，來赴宴吧！』</span>
<span className="v" id="v18" data-v="18" data-xref="提摩太前書 6:9–10; 路加福音 17:26–31; 路加福音 18:24"> 可是，他們都找藉口推辭。頭一個說，『我剛買了一塊田，必須去看一看，請恕我不能參加。』</span>
<span className="v" id="v19" data-v="19"> 另一個說，『我新買了五對牛，要去試一試，請恕我不能參加。』</span>
<span className="v" id="v20" data-v="20" data-xref="申命記 24:5; 哥林多前書 7:33; 路加福音 14:26–28"> 還有一個說，『我剛結了婚，所以不能去。』</span>
<span className="v" id="v21" data-v="21" data-xref="路加福音 14:13; 馬太福音 11:5; 路加福音 14:24"> 奴僕回來將這些話告訴主人，家主非常生氣，就對奴僕說，『快出去到城裡的大街小巷把貧窮的、殘疾的、瘸腿的、瞎眼的都請來。』</span>
<span className="v" id="v22" data-v="22" data-xref="約翰福音 14:2; 以弗所書 3:8; 提摩太前書 2:5–6"> 奴僕說，『主人啊，我照你的吩咐辦了，可是還有空位。』</span>
<span className="v" id="v23" data-v="23" data-xref="馬太福音 22:9–10; 歌羅西書 1:28; 使徒行傳 13:47–48"> 主人又說，『出去到大路上、籬笆旁硬把人拉來，讓我家裡座無虛席。</span>
<span className="v" id="v24" data-v="24" data-xref="馬太福音 21:43; 使徒行傳 13:46; 約翰福音 8:24"> 我告訴你們，原來邀請的那些人沒有一個能嘗到我的宴席！』」</span>
</div>
</div>

## 做門徒的代價

<div className="bt">
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="約翰福音 6:24–27; 路加福音 12:1"> 有一大群人跟著耶穌，祂轉身對他們說：</span>
<span className="v" id="v26" data-v="26" data-xref="馬太福音 10:37; 約翰福音 12:25; 腓立比書 3:8"> 「若有人要跟從我，就要愛我勝過愛他的父母、妻子、兒女、弟兄、姊妹，甚至自己的生命，否則就不能作我的門徒。</span>
<span className="v" id="v27" data-v="27" data-xref="馬太福音 10:38; 路加福音 9:23–25; 馬可福音 8:34–37"> 凡不背起自己的十字架跟從我的，都不能作我的門徒。</span>
<span className="v" id="v28" data-v="28" data-xref="箴言 24:27; 馬太福音 10:22; 約書亞記 24:19–24"> 「你們哪有人建樓房不事先坐下來計算成本，看能否建成？</span>
<span className="v" id="v29" data-v="29"> 否則，打好了地基卻不能完工，徒惹別人嘲笑說，</span>
<span className="v" id="v30" data-v="30" data-xref="希伯來書 6:11; 約翰二書 1:8; 哥林多前書 3:11–14"> 『這個人開了工，卻不能完工！』</span>
<span className="v" id="v31" data-v="31" data-xref="箴言 20:18; 箴言 25:8; 列王紀下 18:20–22"> 「哪有王要跟另一個王打仗時，不先坐下來酌量一下自己的一萬人是否敵得過對方的兩萬人？</span>
<span className="v" id="v32" data-v="32" data-xref="使徒行傳 12:20; 雅各書 4:6–10; 路加福音 12:58"> 如果自知不敵，一定趁敵人還遠的時候，就差使者去求和。</span>
<span className="v" id="v33" data-v="33" data-xref="腓立比書 3:7–8; 約翰一書 2:15–16; 路加福音 5:28"> 「同樣，你們若不撇下一切，就不能作我的門徒。</span>
<span className="v" id="v34" data-v="34" data-xref="馬太福音 5:13; 歌羅西書 4:6; 馬可福音 9:49–50"> 鹽本是好的，但如果失去鹹味，怎能使它再變鹹呢？</span>
<span className="v" id="v35" data-v="35" data-xref="馬太福音 11:15; 路加福音 9:44; 啟示錄 2:11"> 沒有味的鹽，既不利於土壤，也不適宜作肥料，只好丟掉。有耳可聽的，都應當聽。」</span>
</div>
</div>

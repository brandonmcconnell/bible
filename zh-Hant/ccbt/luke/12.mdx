## 警戒門徒

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="彼得前書 2:1; 哥林多前書 5:7–8; 雅各書 3:17"> 這時，成千上萬的人聚集在一起，甚至互相踐踏。耶穌先對門徒說：「你們要提防法利賽人的酵，就是他們的偽善。</span>
<span className="v" id="v2" data-v="2" data-xref="馬可福音 4:22; 路加福音 8:17; 哥林多後書 5:10"> 掩蓋的事終會暴露出來，隱藏的秘密終會被人知道。</span>
<span className="v" id="v3" data-v="3" data-xref="馬太福音 10:27; 馬太福音 12:36; 傳道書 10:20"> 你們暗中說的話將被公佈於眾，你們在密室裡的私語將在屋頂上被傳揚。</span>
<span className="v" id="v4" data-v="4" data-xref="馬太福音 10:28; 耶利米書 1:8; 啟示錄 2:10"> 「朋友們，我告訴你們，不要懼怕那些殺害人的身體後再也無計可施的人。</span>
<span className="v" id="v5" data-v="5" data-xref="彼得後書 2:4; 馬太福音 10:28; 啟示錄 14:7"> 我告訴你們應該懼怕誰，要懼怕上帝——祂有權終結人的生命，並把人扔進地獄裡。是的，我告訴你們，要懼怕祂！</span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 12:24; 詩篇 145:15–16; 詩篇 147:9"> 「五隻麻雀不是只賣兩個銅錢嗎？但沒有一隻麻雀會被上帝遺忘。</span>
<span className="v" id="v7" data-v="7" data-xref="馬太福音 10:30–31; 馬太福音 6:26; 以賽亞書 43:3–4"> 其實就連你們的頭髮都被數過了。不要害怕，你們比許多麻雀要貴重！</span>
<span className="v" id="v8" data-v="8" data-xref="馬太福音 10:32–33; 約翰一書 2:23; 羅馬書 10:9–10"> 「我告訴你們，凡在人面前承認我的，人子在上帝的天使面前也必承認他。</span>
<span className="v" id="v9" data-v="9" data-xref="提摩太後書 2:12; 路加福音 9:26; 馬可福音 8:38"> 凡在人面前否認我的，人子在上帝的天使面前也必否認他。</span>
<span className="v" id="v10" data-v="10" data-xref="馬太福音 12:31–32; 約翰一書 5:16; 提摩太前書 1:13"> 凡說話得罪人子的，還可以得到赦免，但褻瀆聖靈的，必得不到赦免！</span>
<span className="v" id="v11" data-v="11" data-xref="馬太福音 10:17–20; 路加福音 21:12–14; 使徒行傳 4:5–7"> 當你們被押到會堂，或到官員和當權者面前時，不要顧慮如何申辯，或說什麼話，</span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 21:15; 馬太福音 10:20; 使徒行傳 4:8"> 因為到時候聖靈必指教你們該說什麼。」</span>
</div>
</div>

## 無知富翁的比喻

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="路加福音 6:45; 提摩太前書 6:5; 以西結書 33:31"> 這時，人群中有人對耶穌說：「老師，請你勸勸我的兄長跟我分家產吧。」</span>
<span className="v" id="v14" data-v="14" data-xref="羅馬書 2:3; 羅馬書 2:1; 羅馬書 9:20"> 耶穌答道：「朋友，誰派我作你們的審判官或仲裁，為你們分家產呢？」</span>
<span className="v" id="v15" data-v="15" data-xref="希伯來書 13:5; 提摩太前書 6:6–10; 詩篇 119:36–37"> 接著，祂對眾人說：「你們要小心防範一切的貪心，因為人的生命並不在於家道富足。」</span>
<span className="v" id="v16" data-v="16" data-xref="創世記 26:12–14; 何西阿書 2:8; 創世記 41:47–49"> 耶穌又講了一個比喻，說：「有一個財主，他的田裡大豐收，</span>
<span className="v" id="v17" data-v="17" data-xref="馬太福音 5:42; 以賽亞書 58:7; 羅馬書 12:13"> 便心裡盤算，『我儲藏農產的地方不夠了，怎麼辦呢？』</span>
<span className="v" id="v18" data-v="18" data-xref="雅各書 3:15; 雅各書 4:15; 路加福音 12:21"> 於是他說，『我有辦法了。我要把我的倉庫拆掉，建幾座更大的，好儲藏我所有的糧食和財物！</span>
<span className="v" id="v19" data-v="19" data-xref="箴言 27:1; 雅各書 4:13–15; 哥林多前書 15:32"> 那時，我就可以對自己說：你存了這麼多財產，能享用多年，現在大可高枕無憂、盡情地吃喝玩樂吧！』</span>
<span className="v" id="v20" data-v="20" data-xref="約伯記 27:8; 耶利米書 17:11; 提摩太前書 6:7"> 但上帝對他說，『無知的人啊，今晚就要取走你的命！你所預備的一切留給誰享用呢？』</span>
<span className="v" id="v21" data-v="21" data-xref="馬太福音 6:19–20; 路加福音 12:33; 雅各書 2:5"> 「這就是那些只顧為自己積財、在上帝面前卻不富足之人的寫照。」</span>
</div>
</div>

## 不要為衣食憂慮

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="馬太福音 6:25–34; 腓立比書 4:6; 希伯來書 13:5"> 耶穌繼續對門徒說：「所以，我告訴你們，不要為生活憂慮，比如吃什麼，也不要為身體憂慮，比如穿什麼。</span>
<span className="v" id="v23" data-v="23" data-xref="約伯記 2:6; 箴言 13:8; 約伯記 2:4"> 因為生命比飲食重要，身體比穿著重要。</span>
<span className="v" id="v24" data-v="24" data-xref="馬太福音 10:31; 詩篇 147:9; 路加福音 12:7"> 你們看，烏鴉不種也不收，沒倉也沒庫，上帝尚且養活牠們，你們比飛鳥不知要貴重多少！</span>
<span className="v" id="v25" data-v="25" data-xref="馬太福音 6:27; 馬太福音 5:36; 路加福音 19:3"> 「你們誰能用憂慮使自己多活片刻呢？</span>
<span className="v" id="v26" data-v="26" data-xref="彼得前書 5:7; 詩篇 39:6; 傳道書 7:13"> 既然你們連這樣的小事都無能為力，又何必為其餘的事憂慮呢？</span>
<span className="v" id="v27" data-v="27" data-xref="馬太福音 6:28–30; 路加福音 12:24; 列王紀上 10:1–13"> 看看百合花如何生長吧，它們既不勞苦，也不紡織，但我告訴你們，就連所羅門王最顯赫時的穿戴還不如一朵百合花！</span>
<span className="v" id="v28" data-v="28" data-xref="馬太福音 14:31; 以賽亞書 40:6; 馬太福音 6:30"> 「野地的草今天還在，明天就被扔進爐中，上帝還這樣裝扮它們，何況你們呢？你們的信心太小了！</span>
<span className="v" id="v29" data-v="29" data-xref="馬太福音 6:31; 路加福音 12:22; 路加福音 22:35"> 你們不要追求吃什麼喝什麼，不要為此憂慮，</span>
<span className="v" id="v30" data-v="30" data-xref="馬太福音 6:32; 馬太福音 6:8; 以弗所書 4:17"> 因為這些都是不信的世人追求的，你們的天父知道你們需要這些。</span>
<span className="v" id="v31" data-v="31" data-xref="馬太福音 6:33; 希伯來書 13:5; 詩篇 34:9"> 你們要尋求祂的國，這些會加給你們。</span>
<span className="v" id="v32" data-v="32" data-xref="希伯來書 12:28; 彼得前書 1:3–5; 啟示錄 1:6"> 「你們這一小群人啊，不要怕！因為你們的天父樂意把祂的國賜給你們。</span>
<span className="v" id="v33" data-v="33" data-xref="馬太福音 19:21; 使徒行傳 4:34–35; 使徒行傳 2:45"> 要變賣你們的家產去賙濟窮人，要為自己預備永不破損的錢袋，在天上積攢取之不盡的財寶，那裡沒有賊偷，也沒有蟲蛀。</span>
<span className="v" id="v34" data-v="34" data-xref="歌羅西書 3:1–3; 馬太福音 6:21; 腓立比書 3:20"> 因為你們的財寶在哪裡，你們的心也在哪裡。</span>
</div>
</div>

## 警醒預備

<div className="bt">
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="彼得前書 1:13; 以弗所書 6:14; 馬太福音 25:4–10"> 「你們要束上腰帶，準備服侍，要點亮燈，</span>
<span className="v" id="v36" data-v="36" data-xref="猶大書 1:20–21; 雅各書 5:7–8; 啟示錄 3:20"> 像奴僕們等候主人從婚宴回來。主人回來一叩門，奴僕就可以立即給他開門。</span>
<span className="v" id="v37" data-v="37" data-xref="彼得後書 3:14; 馬太福音 24:42; 約翰福音 13:4–5"> 主人回來，看見奴僕警醒等候，奴僕就有福了！我實在告訴你們，主人必束上腰帶請他們坐席，並親自服侍他們。</span>
<span className="v" id="v38" data-v="38" data-xref="帖撒羅尼迦前書 5:4–5; 馬太福音 25:6"> 無論主人在深夜或黎明回家，若發現奴僕警醒等候，奴僕就有福了。</span>
<span className="v" id="v39" data-v="39" data-xref="彼得後書 3:10; 啟示錄 3:3; 啟示錄 16:15"> 「你們都知道，家主若知道賊什麼時候來，一定不會讓賊入屋偷竊。</span>
<span className="v" id="v40" data-v="40" data-xref="帖撒羅尼迦前書 5:6; 馬太福音 25:13; 羅馬書 13:11"> 同樣，你們也要做好準備，因為在你們意想不到的時候，人子就來了。」</span>
</div>
</div>

## 忠僕和惡僕

<div className="bt">
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="馬可福音 13:37; 彼得前書 4:7; 彼得前書 5:8"> 彼得問：「主啊！你這比喻是講給我們聽的，還是講給眾人聽的呢？」</span>
<span className="v" id="v42" data-v="42" data-xref="馬太福音 24:45–46; 彼得前書 5:1–4; 希伯來書 13:17"> 主說：「誰是那個受主人委託管理家中大小僕役、按時分糧食給他們、又忠心又精明的管家呢？</span>
<span className="v" id="v43" data-v="43"> 主人回家時，看見他盡忠職守，他就有福了。</span>
<span className="v" id="v44" data-v="44" data-xref="路加福音 22:29–30; 馬太福音 24:47; 路加福音 19:17–19"> 我實在告訴你們，主人一定會把所有產業都交給他管理。</span>
<span className="v" id="v45" data-v="45" data-xref="馬太福音 24:48–50; 啟示錄 18:7–8; 腓立比書 3:18–19"> 但他若以為主人不會那麼快回來，就動手毆打僕婢、吃喝醉酒，</span>
<span className="v" id="v46" data-v="46" data-xref="路加福音 12:40; 馬太福音 24:51; 詩篇 11:5"> 主人會在他想不到的日子、不知道的時辰回來，嚴厲地懲罰<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「嚴厲地懲罰」或作「腰斬」。">a</a></sup>他，使他和不忠不信的人同受嚴刑。</span>
<span className="v" id="v47" data-v="47" data-xref="雅各書 4:17; 約翰福音 9:41; 約翰福音 12:48"> 明知主人的意思卻不準備，也不遵行主人吩咐的僕人，必受更重的責打。</span>
<span className="v" id="v48" data-v="48" data-xref="雅各書 3:1; 利未記 5:17; 路加福音 16:10–12"> 但因不知道而做了該受懲罰之事的僕人，必少受責打。多賜給誰，就向誰多取；多託付誰，就向誰多要。</span>
</div>
</div>

## 家庭分裂

<div className="bt">
<div className="bp">
<span className="v" id="v49" data-v="49" data-xref="瑪拉基書 4:1; 路加福音 12:51–52; 馬太福音 3:10–12"> 「我來是要把火扔在地上，我多麼希望這火已經燃燒起來。</span>
<span className="v" id="v50" data-v="50" data-xref="約翰福音 12:27–28; 約翰福音 19:30; 約翰福音 7:6–8"> 我有要受的『洗禮』，我何等迫切地想完成這『洗禮』啊！</span>
<span className="v" id="v51" data-v="51" data-xref="馬太福音 10:34–36; 路加福音 12:49; 馬太福音 24:7–10"> 你們以為我來是要使天下太平嗎？不！我告訴你們，我來是要使地上起紛爭。</span>
<span className="v" id="v52" data-v="52" data-xref="使徒行傳 14:1–4; 約翰福音 15:18–21; 彌迦書 7:5–6"> 從今以後，一家五口會彼此相爭，三個人反對兩個人，或是兩個人反對三個人，</span>
<span className="v" id="v53" data-v="53" data-xref="彌迦書 7:6; 馬太福音 10:21–22; 馬太福音 24:10"> 父子相爭，母女對立，婆媳反目。」</span>

## 世事洞明

<div className="bt">
<div className="bp">
<span className="v" id="v54" data-v="54" data-xref="馬太福音 16:2–4; 列王紀上 18:44–45"> 然後，祂又對眾人說：「你們看見雲從西方升起，立刻說，『快下雨了！』果然如此。</span>
<span className="v" id="v55" data-v="55" data-xref="約伯記 37:17; 馬太福音 20:12"> 南風一起，你們就說，『天必燥熱』，你們也說對了。</span>
<span className="v" id="v56" data-v="56" data-xref="馬太福音 16:3; 馬太福音 24:32–33; 馬太福音 11:25"> 你們這些偽善的人！既然懂得分辨天地氣象，為什麼不懂得分辨這個世代呢？</span>
<span className="v" id="v57" data-v="57" data-xref="申命記 32:29; 約翰福音 7:24; 使徒行傳 13:26–38"> 你們為什麼不自己明辨是非呢？</span>
<span className="v" id="v58" data-v="58" data-xref="箴言 25:8–9; 馬太福音 5:23–26; 路加福音 13:24–28"> 如果你和告你的人要去對簿公堂，要盡量在路上與對方和解，以免被拉到審判官面前，審判官把你交給差役，差役把你關進監牢。</span>
<span className="v" id="v59" data-v="59" data-xref="馬可福音 12:42; 馬太福音 18:34; 馬太福音 25:46"> 我告訴你，除非你還清所欠的每一分錢，否則休想出來。」</span>
</div>

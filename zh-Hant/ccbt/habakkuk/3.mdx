## 哈巴谷的禱告

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="詩篇 7:1–17; 詩篇 86:1–17; 詩篇 90:1–17"> 以下是哈巴谷先知的禱告，採用流離調<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="流離調是希伯來詩歌的一種曲調。">a</a></sup>。</span>
<span className="v" id="v2" data-v="2" data-xref="詩篇 85:6; 詩篇 90:13–17; 何西阿書 6:2–3"> <span className="pl pl-1">耶和華啊，我聽過你的威名；</span><br /><span className="pl pl-1">耶和華啊，我對你的作為充滿敬畏。</span><br /><span className="pl pl-1">求你如今再次彰顯你的作為，</span><br /><span className="pl pl-1">求你此時再次顯明你的作為，</span><br /><span className="pl pl-1">求你發怒的時候仍以憐憫為念。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v3" data-v="3" data-xref="申命記 33:2; 詩篇 4:4; 俄巴底亞書 1:9"> <span className="pl pl-1">上帝從提幔來，</span><br /><span className="pl pl-1">聖者從巴蘭山來。（細拉）</span><br /><span className="pl pl-1">祂的榮耀遮蔽諸天，</span><br /><span className="pl pl-1">頌讚之聲響徹大地。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="以賽亞書 60:19–20; 馬太福音 17:2; 約伯記 26:14"> <span className="pl pl-1">祂明亮如晨光，</span><br /><span className="pl pl-1">祂的手射出光芒，</span><br /><span className="pl pl-1">其中蘊藏著大能。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 12:29–30; 民數記 16:46–49; 詩篇 78:50–51"> <span className="pl pl-1">瘟疫行在祂前面，</span><br /><span className="pl pl-1">災病跟在祂腳後。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="創世記 49:26; 申命記 33:15; 那鴻書 1:5"> <span className="pl pl-1">祂停下，大地就震動；</span><br /><span className="pl pl-1">祂觀看，萬民就戰慄。</span><br /><span className="pl pl-1">古老的山嶽崩裂，</span><br /><span className="pl pl-1">遠古的丘陵塌陷，</span><br /><span className="pl pl-1">但祂的作為永遠不變。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="出埃及記 15:14–16; 創世記 10:6–7; 創世記 25:1–4"> <span className="pl pl-1">我看見古珊的帳篷遭難，</span><br /><span className="pl pl-1">米甸的幔子顫抖。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 68:17; 申命記 33:26–27; 出埃及記 14:21–22"> <span className="pl pl-1">耶和華啊，你是向江河發怒嗎？</span><br /><span className="pl pl-1">你騎著馬、乘著得勝的戰車而來，</span><br /><span className="pl pl-1">是向江河生氣嗎？</span><br /><span className="pl pl-1">是向海洋發怒嗎？</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 7:12–13; 詩篇 105:41; 詩篇 78:15–16"> <span className="pl pl-1">你張弓搭箭，要射出許多箭羽。（細拉）</span><br /><span className="pl pl-1">你以江河分開大地。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="耶利米書 4:24; 約書亞記 4:23–24; 詩篇 93:3"> <span className="pl pl-1">群山看見你就戰慄，</span><br /><span className="pl pl-1">大水奔騰而過，</span><br /><span className="pl pl-1">深淵鳴響，波浪滔天。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 144:5–6; 詩篇 18:12–14; 約書亞記 10:11–13"> <span className="pl pl-1">你射出的箭閃閃發光，</span><br /><span className="pl pl-1">你的槍熠熠生輝，</span><br /><span className="pl pl-1">以致日月都停在原處。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="耶利米書 51:33; 彌迦書 4:12–13; 民數記 21:23–35"> <span className="pl pl-1">你懷著烈怒走遍大地，</span><br /><span className="pl pl-1">帶著怒火踐踏列國。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 110:6; 詩篇 105:15; 詩篇 68:19–23"> <span className="pl pl-1">你出來是為了拯救你的子民，</span><br /><span className="pl pl-1">拯救你膏立的王。</span><br /><span className="pl pl-1">你打垮邪惡之人的首領，</span><br /><span className="pl pl-1">從頭到腳徹底毀滅他。（細拉）</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="撒迦利亞書 9:14; 但以理書 11:40; 詩篇 118:10–12"> <span className="pl pl-1">你用他的矛刺透其勇士的頭顱。</span><br /><span className="pl pl-1">他們如旋風而至，要驅散我們，</span><br /><span className="pl pl-1">他們喜好暗中吞噬貧民。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 77:19; 哈巴谷書 3:8; 出埃及記 15:8"> <span className="pl pl-1">你騎馬踩踏洶湧的大海。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="耶利米書 23:9; 哈巴谷書 1:5–11; 哈巴谷書 3:2"> <span className="pl pl-1">我聽到這些，</span><br /><span className="pl pl-1">就膽戰心驚，嘴唇哆嗦，</span><br /><span className="pl pl-1">四肢無力，雙腿發抖。</span><br /><span className="pl pl-1">但我仍要靜候災難臨到入侵者的日子。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v17" data-v="17" data-xref="耶利米書 5:17; 約珥書 1:16–18; 申命記 28:15–18"> <span className="pl pl-1">即使無花果樹不發芽，</span><br /><span className="pl pl-1">葡萄樹不結果，</span><br /><span className="pl pl-1">橄欖樹無收成，</span><br /><span className="pl pl-1">田地不產糧，</span><br /><span className="pl pl-1">圈裡沒有羊，</span><br /><span className="pl pl-1">棚裡沒有牛，</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="約伯記 13:15; 腓立比書 4:4; 彌迦書 7:7"> <span className="pl pl-1">我仍要因耶和華而歡欣，</span><br /><span className="pl pl-1">因拯救我的上帝而喜樂。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳記下 22:34; 詩篇 18:33; 腓立比書 4:13"> <span className="pl pl-1">主耶和華是我的力量，</span><br /><span className="pl pl-1">祂使我的腳如母鹿的蹄，</span><br /><span className="pl pl-1">穩行在高處。</span><br /><span className="pl pl-1">這首歌交給樂長，用弦樂器伴奏。</span></span>
</div>

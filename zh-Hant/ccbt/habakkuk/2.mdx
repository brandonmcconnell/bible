<div className="bt">
<div className="bp poetry">
<span className="v" id="v2" data-v="2" data-xref="以賽亞書 30:8; 啟示錄 14:13; 啟示錄 1:18–19"> <span className="pl pl-1">耶和華對我說：</span><br /><span className="pl pl-1">「將我的啟示記下來，</span><br /><span className="pl pl-1">清楚地刻在板上，</span><br /><span className="pl pl-1">便於人們閱讀。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 27:14; 希伯來書 10:36–37; 以西結書 12:25"> <span className="pl pl-1">這啟示還未到實現之時，</span><br /><span className="pl pl-1">它關乎結局，沒有虛假。</span><br /><span className="pl pl-1">即使緩慢，也要等候，</span><br /><span className="pl pl-1">因為這事終必發生，不再遲延。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="羅馬書 1:17; 希伯來書 10:38; 加拉太書 3:11–12"> <span className="pl pl-1">看那驕傲之人，他們心術不正，</span><br /><span className="pl pl-1">但義人必靠信心</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「信心」或譯「忠信」。">a</a></sup><br /><span className="pl pl-1">而活。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="以賽亞書 5:11–12; 箴言 27:20; 箴言 20:1"> <span className="pl pl-1">財富</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="「財富」參照死海古卷，多個希伯來抄本為「酒」。">b</a></sup><br /><span className="pl pl-1">會欺騙驕傲之人，</span><br /><span className="pl pl-1">使他們永不安分，</span><br /><span className="pl pl-1">像陰間一樣貪得無厭，</span><br /><span className="pl pl-1">如死亡一般永不滿足。</span><br /><span className="pl pl-1">因此，他們征服萬國，</span><br /><span className="pl pl-1">擄掠萬民。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="民數記 23:7; 彌迦書 2:4; 耶利米書 50:13"> <span className="pl pl-1">「但萬國萬民必用詩歌和俗語嘲諷他們，說，</span><br /><span className="pl pl-1">『你們有禍了！</span><br /><span className="pl pl-1">你們吞沒別人的財產，</span><br /><span className="pl pl-1">靠剝削別人囤積財富，</span><br /><span className="pl pl-1">要到何時呢？』</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="箴言 29:1; 以賽亞書 47:11; 耶利米書 8:17"> <span className="pl pl-1">你們的債主必突然行動，</span><br /><span className="pl pl-1">使你們戰戰兢兢，</span><br /><span className="pl pl-1">淪為他們的俘虜。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="以賽亞書 33:1; 哈巴谷書 2:17; 耶利米書 27:7"> <span className="pl pl-1">你們從前擄掠許多國家，</span><br /><span className="pl pl-1">殺人流血，</span><br /><span className="pl pl-1">摧毀他們的土地、城市和人民，</span><br /><span className="pl pl-1">所以各國的餘民必掠奪你們。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="耶利米書 49:16; 耶利米書 22:13–19; 以賽亞書 28:15"> <span className="pl pl-1">「為自己的家積蓄不義之財、</span><br /><span className="pl pl-1">在高處搭窩躲避災禍的人啊，</span><br /><span className="pl pl-1">你們有禍了！</span><br /></span>

<span className="v" id="v11" data-v="11" data-xref="路加福音 19:40; 約書亞記 24:27; 約伯記 31:38–40"> <span className="pl pl-1">牆上的石頭必高聲控訴，</span><br /><span className="pl pl-1">房子的梁木必同聲響應。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="彌迦書 3:10; 但以理書 4:27–31; 那鴻書 3:1"> <span className="pl pl-1">「以人血建城邑，</span><br /><span className="pl pl-1">以罪惡造城池的人啊，</span><br /><span className="pl pl-1">你們有禍了！</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="耶利米書 51:58; 以賽亞書 50:11; 箴言 21:30"> <span className="pl pl-1">列邦的勞碌都化為灰燼，</span><br /><span className="pl pl-1">列國的辛勞盡是虛空。</span><br /><span className="pl pl-1">這不都是出於萬軍之耶和華嗎？</span><br /></span>

</div>
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="耶利米書 51:7; 創世記 9:22; 啟示錄 18:3"> <span className="pl pl-1">「讓鄰居喝酒直到灌醉他們，好觀看他們祼體的人啊，</span><br /><span className="pl pl-1">你們有禍了！</span><br /></span>

<span className="v" id="v18" data-v="18" data-xref="耶利米書 10:8; 哥林多前書 12:2; 以賽亞書 44:9–10"> <span className="pl pl-1">「雕刻的偶像有什麼益處？</span><br /><span className="pl pl-1">騙人的鑄像有什麼用處？</span><br /><span className="pl pl-1">製造者竟信靠自己造的啞巴偶像！</span><br /></span>

## 感恩和禱告

<div className="bt">
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="哥林多前書 1:4; 帖撒羅尼迦前書 1:2–3; 腓利門書 1:4–5"> 我每逢想起你們，就感謝我的上帝；</span>
<span className="v" id="v4" data-v="4" data-xref="帖撒羅尼迦前書 1:2; 羅馬書 1:9; 約翰二書 1:4"> 每次為你們眾人禱告，心裡都帶著喜樂。</span>
<span className="v" id="v5" data-v="5" data-xref="腓立比書 4:14–15; 腓立比書 1:7; 希伯來書 3:14"> 因為你們從最初直到現在，始終和我同心合意地傳揚福音。</span>
<span className="v" id="v6" data-v="6" data-xref="帖撒羅尼迦前書 5:23–24; 腓立比書 2:13; 以弗所書 4:12"> 我深信，上帝既然在你們心裡開始了這美好的工作，就必在耶穌基督再來的時候完成這工作。</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多後書 7:3; 腓立比書 1:5; 歌羅西書 4:18"> 我對你們眾人有這樣的感受很自然，因為我常把你們放在心上<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「我常把你們放在心上」或譯「你們常把我放在心上」。">a</a></sup>。不論我是身在獄中，還是為福音辯護和作證的時候，你們都與我同蒙恩典。</span>
<span className="v" id="v8" data-v="8" data-xref="腓立比書 4:1; 羅馬書 1:9; 提摩太後書 1:4"> 上帝可以作證，我是怎樣以基督耶穌的慈心想念你們的。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="帖撒羅尼迦前書 3:12; 歌羅西書 1:9; 彼得後書 1:5–6"> 我所祈求的就是：你們的愛心隨著屬靈知識和辨別力的提高而日益增長，</span>
<span className="v" id="v10" data-v="10" data-xref="羅馬書 12:2; 帖撒羅尼迦前書 3:13; 帖撒羅尼迦前書 5:23"> 使你們能夠擇善而從，做誠實無過的人，一直到基督再來的日子，</span>
<span className="v" id="v11" data-v="11" data-xref="希伯來書 12:11; 約翰福音 15:8; 約翰福音 15:4–5"> 並靠著耶穌基督結滿仁義的果子，使上帝得到榮耀與頌讚。</span>
</div>
</div>

## 為基督而活

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="提摩太後書 2:9; 羅馬書 8:28; 使徒行傳 11:19–21"> 弟兄姊妹，我希望你們知道，我的遭遇反而會使福音傳得更廣，</span>
<span className="v" id="v13" data-v="13" data-xref="提摩太後書 2:9; 以弗所書 3:1; 腓立比書 1:7"> 連所有的皇家衛兵和其他眾人都知道我是為了基督的緣故而受囚禁。</span>
<span className="v" id="v14" data-v="14" data-xref="以弗所書 6:19–20; 帖撒羅尼迦前書 2:2; 路加福音 1:74"> 大多數主內的弟兄姊妹因我被囚的緣故，就信心堅定，更加放膽傳揚上帝的道。</span>
<span className="v" id="v15" data-v="15" data-xref="羅馬書 16:17–18; 腓立比書 2:3; 哥林多後書 11:13"> 當然，有些人宣講基督是出於嫉妒和爭強好勝，也有些人是出於善意。</span>
<span className="v" id="v16" data-v="16" data-xref="哥林多後書 2:17; 哥林多後書 4:1–2; 詩篇 69:26"> 後者是出於愛心，知道我是上帝派來為福音辯護的。</span>
<span className="v" id="v17" data-v="17" data-xref="提摩太後書 1:11–12; 腓立比書 2:3; 腓立比書 1:7"> 前者傳講基督是出於個人野心，動機不純，以為可以增加我在獄中的痛苦。</span>
<span className="v" id="v18" data-v="18" data-xref="路加福音 9:50; 馬可福音 9:38–40; 哥林多前書 15:11"> 那又怎樣呢？無論他們是出於真心還是假意，基督的福音畢竟被傳開了，因此我很歡喜，而且歡喜不已。</span>
<span className="v" id="v19" data-v="19" data-xref="羅馬書 8:28; 使徒行傳 16:7; 哥林多後書 1:11"> 因為我知道，藉著你們的禱告和耶穌基督之靈的幫助，我終必得到釋放。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="彼得前書 4:16; 哥林多前書 6:20; 以賽亞書 54:4"> 我熱切期待和盼望：我不會感到任何羞愧，而是放膽無懼，不管是生是死，都要照常使基督在我身上被尊崇。</span>
<span className="v" id="v21" data-v="21" data-xref="加拉太書 2:20; 哥林多後書 5:8; 哥林多後書 5:1"> 因為對我來說，活著是為了基督，死了也有益處。</span>
<span className="v" id="v22" data-v="22" data-xref="彼得前書 4:2; 加拉太書 2:20; 腓立比書 1:24"> 如果活在世上，我的工作肯定富有成果。我真不知道該怎麼選擇！</span>
<span className="v" id="v23" data-v="23" data-xref="哥林多後書 5:8; 詩篇 17:15; 啟示錄 14:13"> 我處在兩難之間。我情願離開世界，與基督在一起，那實在是再好不過了。</span>
<span className="v" id="v24" data-v="24" data-xref="約翰福音 16:7; 腓立比書 1:22; 腓立比書 1:25–26"> 可是為了你們，我更有必要活在世上。</span>
<span className="v" id="v25" data-v="25" data-xref="腓立比書 2:24; 哥林多後書 1:24; 以弗所書 4:11–13"> 我既然對此深信不疑，就知道自己仍要活下去，繼續跟你們在一起，好使你們在信仰上又長進又充滿喜樂。</span>
<span className="v" id="v26" data-v="26" data-xref="哥林多後書 1:14; 哥林多後書 5:12; 腓立比書 3:3"> 這樣，我再到你們那裡的時候，你們可以因為我的緣故更加以基督耶穌為榮。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="以弗所書 4:1; 哥林多前書 16:13–14; 哥林多前書 1:10"> 最要緊的是：你們行事為人要與基督的福音相稱。這樣，不管是去看你們，還是只聽到你們的消息，我都能知道你們同心合意，堅定不移地一起為福音信仰奮鬥，</span>
<span className="v" id="v28" data-v="28" data-xref="提摩太後書 1:7–8; 帖撒羅尼迦後書 1:5–6; 馬太福音 10:28"> 毫不懼怕敵人的恐嚇。這是出於上帝的記號，表明他們必滅亡，你們必得救。</span>
<span className="v" id="v29" data-v="29" data-xref="雅各書 1:2; 彼得前書 4:13; 使徒行傳 5:41"> 因為上帝為了基督的緣故，賜恩使你們不但信基督，而且為祂受苦，</span>
<span className="v" id="v30" data-v="30" data-xref="帖撒羅尼迦前書 2:2; 使徒行傳 16:19–40; 提摩太後書 4:7"> 經歷你們從前在我身上見過、現在又從我這裡聽到的同樣爭戰。</span>
</div>
</div>

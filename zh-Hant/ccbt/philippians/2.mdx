## 效法基督

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="歌羅西書 3:12; 約翰一書 4:12; 約翰一書 4:7–8"> 所以，你們如果在基督裡受到鼓勵，得到愛的安慰，與聖靈相通，有慈悲和憐憫之心，</span>
<span className="v" id="v2" data-v="2" data-xref="羅馬書 12:16; 彼得前書 3:8–9; 哥林多前書 1:10"> 就要同心合意，彼此相愛，靈裡合一，思想一致，好讓我的喜樂滿溢。</span>
<span className="v" id="v3" data-v="3" data-xref="羅馬書 12:10; 加拉太書 5:26; 以弗所書 5:21"> 凡事不可自私自利、愛慕虛榮，要心存謙卑，看別人比自己強。</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多前書 10:24; 羅馬書 15:1; 雅各書 2:8"> 各人不要只顧自己的事，也要顧別人的事。</span>
<span className="v" id="v5" data-v="5" data-xref="約翰一書 2:6; 馬太福音 11:29; 彼得前書 2:21"> 你們應當有基督耶穌那樣的心意。</span>
<span className="v" id="v6" data-v="6" data-xref="約翰福音 5:18; 哥林多後書 4:4; 希伯來書 1:3"> <span className="pl pl-1">祂雖然本質上是上帝，</span><br /><span className="pl pl-1">卻不緊抓與上帝同等之位，</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="哥林多後書 8:9; 馬太福音 20:28; 約翰福音 1:14"> <span className="pl pl-1">反而甘願放下一切，</span><br /><span className="pl pl-1">取了奴僕的形像，</span><br /><span className="pl pl-1">降生為人的樣子。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="約翰福音 10:18; 希伯來書 12:2; 羅馬書 5:19"> <span className="pl pl-1">祂以人的樣子出現後，</span><br /><span className="pl pl-1">就自願卑微，順服至死，</span><br /><span className="pl pl-1">而且死在十字架上。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="啟示錄 19:16; 馬太福音 28:18; 彼得前書 3:22"> <span className="pl pl-1">因此，上帝將祂升為至尊，</span><br /><span className="pl pl-1">賜給祂超乎萬名之上的名，</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="以賽亞書 45:23–25; 馬太福音 28:18; 啟示錄 5:13–14"> <span className="pl pl-1">使一切天上的、</span><br /><span className="pl pl-1">地上的和地底下的，</span><br /><span className="pl pl-1">無不屈膝跪拜在耶穌的名下，</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="約翰一書 4:15; 羅馬書 14:11; 約翰福音 13:13"> <span className="pl pl-1">無不口稱耶穌基督是主，</span><br /><span className="pl pl-1">將榮耀歸於父上帝。</span></span>
</div>
</div>

## 暗世明燈

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="彼得後書 1:5–10; 路加福音 13:23–24; 哥林多前書 15:58"> 所以，我親愛的弟兄姊妹，你們一向都很順服，不只是當著我的面時才順服，我不在時你們更加順服，要戰戰兢兢地活出你們的救恩。</span>
<span className="v" id="v13" data-v="13" data-xref="希伯來書 13:21; 哥林多後書 3:5; 提摩太後書 1:9"> 因為你們立志和行事都是上帝在你們心中工作，為要成就祂美好的旨意。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="彼得前書 4:9; 哥林多前書 10:10; 腓立比書 2:3"> 無論做什麼事，都不要抱怨，也不要與人爭論，</span>
<span className="v" id="v15" data-v="15" data-xref="馬太福音 5:14–16; 彼得前書 2:12; 馬太福音 5:45"> 好使你們在這個扭曲乖謬的時代中清白無過，作上帝純潔無瑕的兒女，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="申命記32·5。">a</a></sup>如同明光照耀在世上，</span>
<span className="v" id="v16" data-v="16" data-xref="哥林多前書 9:26; 加拉太書 2:2; 約翰一書 1:1"> 堅守生命之道。這樣，到了基督再來的時候，我可以誇口自己沒有空跑一場，也沒有白費功夫。</span>
<span className="v" id="v17" data-v="17" data-xref="提摩太後書 4:6; 羅馬書 15:16; 希伯來書 13:15–16"> 你們的信心就是獻給上帝的祭物，即使在上面澆奠我的生命，我也很喜樂，並且和大家一同喜樂。</span>
<span className="v" id="v18" data-v="18" data-xref="雅各書 1:2–4; 腓立比書 4:4; 腓立比書 3:1"> 同樣，你們也要喜樂，要和我一同喜樂。</span>
</div>
</div>

## 保羅的得力同工

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="哥林多前書 4:17; 帖撒羅尼迦前書 3:6–8; 帖撒羅尼迦前書 3:2"> 靠著主耶穌，我希望儘快派提摩太去你們那裡，好知道你們的近況，使我也感到欣慰。</span>
<span className="v" id="v20" data-v="20" data-xref="腓立比書 2:2; 哥林多前書 16:10; 腓立比書 2:22"> 因為沒有人像他那樣跟我一同真正關心你們的事。</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多前書 10:24; 馬太福音 16:24; 腓立比書 2:4"> 別人都只顧自己的事，不顧耶穌基督的事。</span>
<span className="v" id="v22" data-v="22" data-xref="哥林多前書 4:17; 哥林多後書 2:9; 提摩太後書 1:2"> 但你們知道提摩太的為人，他與我在福音事工上一起服侍，情同父子。</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳記上 22:3; 腓立比書 2:19"> 所以，我的案子一旦明朗了，我會立刻派他去見你們。</span>
<span className="v" id="v24" data-v="24" data-xref="約翰三書 1:14; 腓利門書 1:22; 腓立比書 1:25–26"> 我靠主深信自己很快也會去你們那裡。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="腓立比書 4:18; 腓利門書 1:1–2; 腓立比書 4:3"> 另外，我覺得有必要讓以巴弗提回到你們那裡。他是我的弟兄、同工和戰友，也是你們差遣來服侍我、供應我需用的。</span>
<span className="v" id="v26" data-v="26" data-xref="羅馬書 12:15; 箴言 12:25; 以弗所書 3:13"> 他很想念你們各位，並且感到不安，因為你們聽說了他患病的事。</span>
<span className="v" id="v27" data-v="27" data-xref="詩篇 34:19; 腓立比書 2:30; 詩篇 103:3–4"> 他確實病了，幾乎喪命，但上帝憐憫了他，不但憐憫他，也憐憫了我，沒讓我憂上加憂。</span>
<span className="v" id="v28" data-v="28" data-xref="約翰福音 16:22; 提摩太後書 1:4; 腓立比書 2:26–27"> 所以，我想儘快派他回去與你們相聚，好讓你們喜樂，也可以減少我的掛慮。</span>
<span className="v" id="v29" data-v="29" data-xref="帖撒羅尼迦前書 5:12; 哥林多前書 16:18; 提摩太前書 5:17"> 你們要在主裡歡歡喜喜地接待他，而且要敬重像他這樣的人，</span>
<span className="v" id="v30" data-v="30" data-xref="哥林多前書 16:17; 使徒行傳 20:24; 腓立比書 4:10"> 因為他冒著生命危險彌補你們服侍我的不足之處，為了基督的工作幾乎喪命。</span>
</div>
</div>

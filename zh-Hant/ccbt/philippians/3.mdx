## 認識基督最寶貴

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="羅馬書 5:11; 腓立比書 4:4; 雅各書 1:2"> 此外，弟兄姊妹，你們要靠主喜樂！我再把這些事寫給你們，對我來說並不麻煩，對你們卻是保障。</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多後書 11:13; 提多書 1:16; 啟示錄 22:15"> 你們要提防那些犬類，提防那些作惡的人，提防那些鼓吹必須受割禮<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「割禮」參見創世記17章；希臘文用誇張的字眼描述割禮，有諷刺之意。">a</a></sup>才能得救的人。</span>
<span className="v" id="v3" data-v="3" data-xref="歌羅西書 2:11; 申命記 30:6; 羅馬書 7:6"> 因為真正受割禮的人是我們這些靠著上帝的靈敬拜、以基督耶穌為榮、不倚靠自身條件的人。</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多後書 11:18–22"> 其實我也可以靠自身的條件。如果別人覺得可以靠自身的條件，我更可以。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多後書 11:22; 羅馬書 11:1; 使徒行傳 23:6"> 我出生後第八天就受了割禮，我是以色列人，屬於便雅憫支派，是道道地地的希伯來人。論守律法，我是法利賽人；</span>
<span className="v" id="v6" data-v="6" data-xref="加拉太書 1:13–14; 使徒行傳 8:3; 使徒行傳 26:9–10"> 論熱心，我曾經迫害教會；論律法要求的義，我是無可指責的。</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 14:33; 馬太福音 16:26; 馬太福音 13:44–46"> 但是為了基督，我從前以為有價值的，現在認為毫無價值。</span>
<span className="v" id="v8" data-v="8" data-xref="耶利米書 9:23–24; 羅馬書 8:18; 腓立比書 3:7"> 不但如此，我看萬事都毫無價值，因為認識我主基督耶穌是最寶貴的。我為祂失去了一切，我把失去的一切視為糞土，好得到基督，</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多後書 5:21; 哥林多前書 1:30; 加拉太書 2:16"> 與祂聯合。我並非擁有源於律法的義，而是擁有信靠基督而得的義。這義從上帝而來，以信為基礎。</span>
<span className="v" id="v10" data-v="10" data-xref="加拉太書 2:20; 羅馬書 8:17; 彼得前書 4:1–2"> 我渴望認識基督和祂復活的大能，與祂一同受苦，甚至到死的地步<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="「甚至到死的地步」或譯「效法祂的死」。">b</a></sup>，</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 20:35–36; 啟示錄 20:5; 使徒行傳 23:6"> 這樣我無論如何都可以從死裡復活。</span>
</div>
</div>

## 直奔標竿

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="提摩太前書 6:11–12; 彼得後書 1:5–8; 詩篇 138:8"> 這並不是說我已經得到了或者純全了，我還要竭力追求，或許可以達到基督耶穌要我達到的目標。</span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 9:62; 希伯來書 12:1–2; 腓立比書 3:12"> 弟兄姊妹，我並非以為自己已經得到了，我只專注一件事，就是忘記背後，努力向前，</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多前書 9:24; 彼得前書 5:10; 啟示錄 3:21"> 直奔目標，要贏得上帝藉著基督耶穌從天上呼召我去得的獎賞。</span>
<span className="v" id="v15" data-v="15" data-xref="約翰福音 7:17; 雅各書 1:4–5; 箴言 2:3–6"> 我們中間成熟的基督徒都應該有這樣的看法。即使你們有什麼不同看法，上帝也必讓你們明白。</span>
<span className="v" id="v16" data-v="16" data-xref="歌羅西書 2:6; 啟示錄 3:3; 啟示錄 2:4–5"> 然而，我們長進到什麼程度，就照著什麼程度去行。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="腓立比書 4:9; 哥林多前書 4:16; 彼得前書 5:3"> 弟兄姊妹，你們要一同效法我，也要向那些以我們為榜樣的人學習。</span>
<span className="v" id="v18" data-v="18" data-xref="以弗所書 4:17; 以賽亞書 8:11; 加拉太書 6:12"> 我已經多次告訴你們，現在又流著淚提醒你們：有許多人行事為人與基督的十字架為敵。</span>
<span className="v" id="v19" data-v="19" data-xref="羅馬書 16:18; 羅馬書 8:5–7; 彼得後書 2:3"> 他們的神就是自己的肚腹，他們以自己的羞恥為榮，只想著地上的事，他們的結局是滅亡。</span>
<span className="v" id="v20" data-v="20" data-xref="以弗所書 2:19; 歌羅西書 3:1–3; 哥林多後書 4:18–1"> 我們卻是天上的國民，熱切等候從天降臨的救主，就是主耶穌基督。</span>
<span className="v" id="v21" data-v="21" data-xref="約翰一書 3:2; 歌羅西書 3:4; 哥林多前書 15:42–56"> 那時，祂要以降服萬物的大能將我們這卑賤的軀體改變成像祂那樣榮耀的身體。</span>
</div>
</div>

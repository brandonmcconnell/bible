## 保羅的薦信

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多後書 12:11; 哥林多後書 10:12; 哥林多後書 5:12"> 難道我們又是在稱讚自己嗎？難道我們像別人一樣，需要拿著推薦信去見你們，或拿著你們的推薦信去見別人嗎？</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多前書 9:1–2; 帖撒羅尼迦前書 1:8; 羅馬書 1:8"> 你們自己就是我們的推薦信，寫在了我們心坎上，眾所周知，人人可讀。</span>
<span className="v" id="v3" data-v="3" data-xref="以西結書 11:19; 耶利米書 31:33; 希伯來書 8:10"> 顯然，你們是從基督而來的一封信，是我們工作的成果。這信不是用筆墨寫成的，而是藉著永活上帝的靈寫成的；不是寫在石版上的，而是刻在心版上的。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="腓立比書 1:6; 以弗所書 3:12; 哥林多後書 2:14"> 我們靠著基督在上帝面前有這樣的確信。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多後書 12:9; 腓立比書 4:13; 哥林多前書 15:10"> 我們並不認為自己能夠承擔什麼，我們能夠承擔全是靠上帝。</span>
<span className="v" id="v6" data-v="6" data-xref="約翰福音 6:63; 羅馬書 7:6; 耶利米書 31:31"> 祂使我們能夠擔任新約的執事。這新約不是用律法條文立的，而是聖靈的工作，因為律法條文帶來死亡，但聖靈賜下生命。</span>
</div>
</div>

## 新約的榮耀

<div className="bt">
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="哥林多後書 3:9–11; 羅馬書 10:4; 出埃及記 31:18"> 這帶來死亡、刻在石版上的律法條文事工尚且有榮耀，甚至使摩西的臉上發出榮光，儘管很快就消逝了，以色列人仍然無法定睛看他，</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多前書 3:16; 以弗所書 2:18; 加拉太書 3:14"> 那麼聖靈的事工豈不更有榮耀嗎？</span>
<span className="v" id="v9" data-v="9" data-xref="羅馬書 3:21–22; 希伯來書 12:18–21; 哥林多後書 5:21"> 那定人罪的事工尚且有榮耀，這賜人義的事工豈不更有榮耀嗎？</span>
<span className="v" id="v10" data-v="10" data-xref="彼得後書 1:17; 哈該書 2:7–9; 使徒行傳 26:13"> 其實先前的榮耀和現今的大榮耀相比，就黯然失色了。</span>
<span className="v" id="v11" data-v="11" data-xref="羅馬書 5:20–21; 希伯來書 8:13; 希伯來書 7:21–25"> 那漸漸消逝的尚且有榮耀，這永遠長存的更是榮耀無比。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="哥林多後書 7:4; 使徒行傳 4:13; 腓立比書 1:20"> 我們因為有這極大的盼望，就放膽無懼，</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及記 34:33–35; 希伯來書 10:1–9; 以弗所書 2:14–15"> 不像摩西將帕子蒙在臉上，以免以色列人看見那漸漸消逝的榮光。</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多後書 4:3–4; 使徒行傳 26:18; 羅馬書 11:25"> 但以色列人心裡剛硬，直到今日，他們每逢讀舊約的時候，同樣的帕子還在那裡，沒有揭去。因為只有在基督裡，那帕子才能被除去。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行傳 13:27–29"> 時至今日，每逢他們讀摩西律法的時候，帕子仍然蒙在他們心上。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 34:34; 以賽亞書 29:18; 以賽亞書 25:7"> 然而，他們一旦歸向基督，那帕子就被除去了。</span>
<span className="v" id="v17" data-v="17" data-xref="羅馬書 8:2; 加拉太書 5:13; 約翰福音 8:32"> 主就是那靈，主的靈在哪裡，哪裡就有自由。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多後書 4:6; 以弗所書 4:22–24; 羅馬書 12:2"> 我們這些臉上不再蒙著帕子的人，可以像鏡子一樣反映主的榮光，漸漸變成主的樣子，榮上加榮。這都是主的作為，主就是那靈。</span>
</div>
</div>

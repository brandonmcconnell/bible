## 保羅得到的異象和啟示

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="加拉太書 1:12; 哥林多後書 12:7; 約翰一書 5:20"> 自誇雖然無益，但我不得不繼續誇下去，談談主給我的異象和啟示。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行傳 22:17; 以西結書 8:1–3; 帖撒羅尼迦前書 4:17"> 我知道一位基督徒<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="此人就是保羅本人，他不願誇耀自己的經歷。">a</a></sup>在十四年前曾被提到第三層天上，是在肉身之內還是在肉身之外，我不知道，只有上帝知道。</span>
<span className="v" id="v3" data-v="3"> 我知道這個人曾被提到天上的樂園裡，聽見了人不可言傳的隱祕事，是在肉身之內還是在肉身之外，我不知道，只有上帝知道。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多後書 11:30; 哥林多前書 2:3; 哥林多後書 12:9–10"> 我要為這人誇口。至於我自己，我除了誇耀自己的軟弱以外，別無可誇。</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多後書 11:16; 哥林多後書 11:31; 哥林多後書 12:11"> 就算我誇口，也不是傻瓜，因為我所說的都是實話。只是我不會這樣做，恐怕有人把我看得太高，超過了他對我的所見所聞。</span>
<span className="v" id="v7" data-v="7" data-xref="民數記 33:55; 士師記 2:3; 歷代志下 32:25–26"> 為了使我不至於因所受的啟示太大而自高，有一根刺在我身上，就是有撒旦的爪牙攻擊我，免得我驕傲自大。</span>
<span className="v" id="v8" data-v="8" data-xref="希伯來書 5:7; 馬太福音 26:39–44; 撒母耳記上 15:11"> 我曾三次祈求主叫這根刺離開我，</span>
<span className="v" id="v9" data-v="9" data-xref="腓立比書 4:13; 哥林多後書 12:10; 以賽亞書 40:29–31"> 但祂說：「我的恩典足夠你用，因為我的能力在人的軟弱上更顯得全備。」所以，我更喜歡誇耀自己的軟弱，好讓基督的能力蔭庇我。</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多後書 12:9; 以弗所書 6:10; 羅馬書 5:3"> 因此，為了基督的緣故，我欣然面對軟弱、凌辱、艱難、迫害和困苦，因為我什麼時候軟弱，就什麼時候剛強。</span>
</div>
</div>

## 保羅關懷哥林多人

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="哥林多後書 11:5; 哥林多後書 11:1; 哥林多前書 15:8–10"> 我成了「傻瓜」，是被你們逼的！你們本該稱許我才對。我雖然算不了什麼，卻沒有一點比不上那些「超級使徒」。</span>
<span className="v" id="v12" data-v="12" data-xref="羅馬書 15:18–19; 哥林多後書 11:4; 哥林多後書 4:2"> 我在你們中間百般地忍耐，用神蹟、奇事、異能證明自己是使徒。</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多前書 9:12; 哥林多前書 9:6; 哥林多後書 11:7–9"> 你們什麼地方不及其他教會呢？唯一的區別是我沒有成為你們的負擔！希望各位原諒我的不公道！</span>
<span className="v" id="v14" data-v="14" data-xref="箴言 19:14; 創世記 24:35–36; 哥林多前書 10:33"> 如今我打算第三次到你們那裡去。我不會拖累你們，因為我想得到的是你們，而不是你們的財物。兒女不必為父母積財，父母應當為兒女積財。</span>
<span className="v" id="v15" data-v="15" data-xref="帖撒羅尼迦前書 2:8; 哥林多後書 1:6; 腓立比書 2:17"> 為了你們的靈魂，我甘願付出，包括自己的生命。難道我越愛你們，就越得不到你們的愛嗎？</span>
<span className="v" id="v16" data-v="16" data-xref="帖撒羅尼迦前書 2:5; 哥林多後書 10:2–3; 哥林多後書 12:13"> 算了！我沒有拖累過你們，但竟然有人說我狡猾，用詭計騙你們。</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多後書 9:5; 哥林多前書 4:17; 列王紀下 5:20–27"> 請問，在我派到你們那裡的人當中，我藉著誰佔過你們的便宜呢？</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多後書 8:6; 羅馬書 4:12; 使徒行傳 20:33–35"> 我懇求提多去你們那裡，並派弟兄與他同去。難道提多佔過你們的便宜嗎？我們行事為人豈不是心靈相通，步調一致嗎？</span>
<span className="v" id="v19" data-v="19" data-xref="羅馬書 9:1; 哥林多前書 14:26; 哥林多後書 10:8"> 你們一直以為我們是替自己辯白，其實我們這番話是在基督裡、在上帝面前說的。親愛的弟兄姊妹，這一切都是為了造就你們。</span>
<span className="v" id="v20" data-v="20" data-xref="加拉太書 5:19–21; 彼得前書 2:1; 羅馬書 1:29"> 因為我怕到你們那裡的時候，我對你們的期望會落空，而你們對我也大失所望。我怕你們當中有紛爭、嫉妒、惱怒、仇恨、毀謗、閒話、狂傲和混亂。</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多後書 13:2; 彼得前書 4:2–3; 歌羅西書 3:5"> 我怕再去你們那裡時，我的上帝會使我在你們面前感到羞愧，又怕看到許多從前犯罪、道德敗壞、淫亂放蕩的人仍然不肯悔改，便心裡悲傷。</span>
</div>
</div>

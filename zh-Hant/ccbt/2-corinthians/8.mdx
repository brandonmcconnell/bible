## 鼓勵信徒慷慨捐助

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行傳 16:9; 哥林多後書 9:2; 哥林多後書 9:4"> 弟兄姊妹，我們現在要讓你們知道上帝向馬其頓各教會所施的恩典。</span>
<span className="v" id="v2" data-v="2" data-xref="雅各書 2:5; 箴言 11:25; 哥林多後書 6:10"> 他們雖然遭遇極大的患難，受盡熬煉，卻充滿了喜樂，在極度貧窮的情況下仍然十分慷慨樂捐。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 35:29; 出埃及記 35:5; 出埃及記 35:21–22"> 我可以證明，他們是甘心樂意，盡其所能地捐助，甚至超過了自己的能力。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行傳 24:17; 加拉太書 6:10; 哥林多後書 9:1"> 他們懇求我們准許他們參與供應有需要的聖徒。</span>
<span className="v" id="v5" data-v="5" data-xref="羅馬書 12:1; 羅馬書 14:7–9; 歷代志下 30:12"> 他們這樣做超過了我們的期望，並且他們按照上帝的旨意首先把自己獻給主，然後獻給我們。</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多後書 12:18; 哥林多後書 8:19; 哥林多後書 8:4"> 所以，我們勸提多要繼續完成他早先在你們當中開始的這件善事。</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多後書 9:8; 彼得後書 1:5–8; 帖撒羅尼迦後書 1:3"> 你們既然在信心、口才、知識、熱心和對我們的愛心上都有突出的表現，也要在這件善事上有突出的表現。</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多前書 7:6; 約翰一書 3:17–19; 雅各書 2:14–16"> 我說這話並非命令你們，而是藉著別人的熱心考驗一下你們愛心的真偽。</span>
<span className="v" id="v9" data-v="9" data-xref="羅馬書 8:32; 腓立比書 2:6–8; 馬太福音 20:28"> 因為你們知道我們主耶穌基督的恩典，祂本來富足，卻為你們的緣故變得貧窮，使你們藉著祂的貧窮可以變得富足。</span>
<span className="v" id="v10" data-v="10" data-xref="提摩太前書 6:18–19; 希伯來書 13:16; 哥林多後書 9:2"> 關於捐助的事，我把自己的意見告訴你們：你們一年前開始捐助，並且甘心樂意——這對你們有益。</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多後書 9:2"> 你們要有始有終，既有懇切願意的心，就要量力而行，辦妥這事。</span>
<span className="v" id="v12" data-v="12" data-xref="馬可福音 12:42–44; 哥林多後書 9:7; 路加福音 21:1–4"> 因為人只要按自己的能力甘心樂意地去做，必蒙上帝悅納，上帝不會讓人做力所不逮之事。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行傳 4:34; 羅馬書 15:26–27"> 這不是說要別人脫離困境，要你們陷入困境，而是要均平。</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多後書 9:12; 使徒行傳 4:34"> 現在你們這些富足的人可以幫補那些有需要的人，以便你們有需要的時候，那些富足的人也可以幫補你們，這樣就可以均平了。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及記 16:18; 路加福音 22:35"> 正如聖經上說：「多拾的沒有剩餘，少拾的也沒有缺乏。」<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="出埃及記16·18。">a</a></sup></span>
</div>
</div>

## 託人送捐款

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="啟示錄 17:17; 耶利米書 32:40; 哥林多後書 2:13–14"> 感謝上帝！祂感動了提多的心，使他像我一樣熱誠地關懷你們。</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多後書 8:6; 希伯來書 13:22; 哥林多後書 8:10"> 這固然是他聽了我們的勸告，但也是他自己非常熱誠，自願去你們那裡。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多後書 12:18; 哥林多後書 8:19; 哥林多前書 7:17"> 我們還要派一位弟兄和他同去，這位弟兄在傳福音的事上得到各地教會的讚許。</span>
<span className="v" id="v19" data-v="19" data-xref="哥林多前書 16:3–4; 哥林多後書 4:15; 哥林多後書 9:8"> 此外，他還受各教會的委派與我們同行，把交給我們的捐款送去，使主得榮耀，並表明我們熱誠相助的心。</span>
<span className="v" id="v20" data-v="20" data-xref="帖撒羅尼迦前書 5:22; 羅馬書 14:16; 以弗所書 5:15"> 我們這樣做是為了避免有人挑我們的不是，因我們經手的捐款數目可觀。</span>
<span className="v" id="v21" data-v="21" data-xref="羅馬書 12:17; 彼得前書 2:12; 腓立比書 4:8"> 無論在主面前或在人面前，我們務求行事為人光明磊落。</span>
<span className="v" id="v22" data-v="22" data-xref="腓立比書 2:20–22"> 我們還要再派一位弟兄和他們一同去你們那裡。我們經過多次多方的考驗，證實他很熱心，而且他因為十分信任你們，現在更熱心了。</span>
<span className="v" id="v23" data-v="23" data-xref="腓立比書 2:25; 腓利門書 1:17; 哥林多後書 8:6"> 至於提多，他是我的同伴，與我一同服侍你們。另外兩位弟兄是眾教會的代表，是基督的榮耀。</span>
<span className="v" id="v24" data-v="24" data-xref="哥林多後書 7:14; 哥林多後書 7:4; 哥林多後書 9:2–4"> 所以，你們要在眾教會面前向他們證明你們的愛心，以及我誇耀你們的話並非虛言。</span>
</div>

## 天上的房屋

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="約伯記 19:25–26; 約翰一書 3:2; 彼得後書 1:13–14"> 我們知道，身體是我們在地上住的帳篷，如果毀壞了，我們就從上帝那裡得到一個住處，不是人手造的，而是天上永恆的「房屋」。</span>
<span className="v" id="v2" data-v="2" data-xref="羅馬書 8:23; 哥林多前書 15:53–54; 哥林多後書 5:3–4"> 我們在這地上的「帳篷」裡歎息，渴望早日遷進那天上的「居所」，好像更換新衣。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 3:7–11; 啟示錄 16:15; 啟示錄 3:18"> 我們一旦穿上新衣，就不會赤身露體了。</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多前書 15:53–54; 哥林多後書 5:2; 以賽亞書 25:8"> 我們在這「帳篷」裡勞苦歎息，並非想脫去這地上的身體，而是想穿上那天上的新身體，讓永恆的生命吞滅必朽的身體。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多後書 1:22; 以弗所書 1:13–14; 羅馬書 8:23"> 上帝為此目的預備了我們，並賜給我們聖靈作擔保。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="哥林多後書 5:1; 腓立比書 3:20–21; 希伯來書 11:13"> 所以，我們總是坦然無懼，儘管知道住在身體之內便無法與主在一起。</span>
<span className="v" id="v7" data-v="7" data-xref="希伯來書 11:1–27; 哥林多後書 4:18; 羅馬書 8:24–25"> 因為我們行事為人是憑信心，不是憑眼見。</span>
<span className="v" id="v8" data-v="8" data-xref="腓立比書 1:20–24; 哥林多後書 5:6; 約翰福音 14:3"> 是的，我們坦然無懼，甚至更樂意離開身體，回到天家與主相聚。</span>
<span className="v" id="v9" data-v="9" data-xref="歌羅西書 1:10; 彼得後書 3:14; 羅馬書 14:18"> 因此，我們立定心志，無論是住在身體之內還是離開身體，都要取悅主。</span>
<span className="v" id="v10" data-v="10" data-xref="馬太福音 16:27; 啟示錄 22:12; 以弗所書 6:8"> 因為我們所有的人都要出現在基督的審判台前，好按照各人肉身所行的善惡接受賞罰。</span>
</div>
</div>

## 勸人與上帝和好

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="猶大書 1:23; 希伯來書 10:31; 提摩太後書 2:24–26"> 我們知道主是當受敬畏的，所以勸人歸信祂。我們的內心如何，上帝知道，我盼望你們的良心也知道。</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多後書 3:1; 哥林多後書 1:14; 加拉太書 6:12–14"> 我們不是再次稱讚自己，而是讓你們有機會以我們為榮，叫你們可以反駁那些只貪圖外表虛榮、不注重內在實質的人。</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多後書 11:16–17; 哥林多後書 11:1; 哥林多後書 12:6"> 我們如果瘋狂，那是為了上帝；我們如果清醒，那是為了你們。</span>
<span className="v" id="v14" data-v="14" data-xref="加拉太書 2:20; 羅馬書 14:7–9; 馬太福音 10:37–38"> 因為基督的愛激勵我們，因為我們確信：基督一人既代替眾人死了，眾人就都死了。</span>
<span className="v" id="v15" data-v="15" data-xref="羅馬書 14:7–9; 彼得前書 4:2–4; 彼得前書 1:14–15"> 祂為眾人死，是要叫那些活著的人不再為自己活，而是要為替他們死而復活的基督活。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="歌羅西書 3:11; 腓立比書 3:7–8; 約翰福音 6:63"> 從今以後，我們不再以世人的眼光看人了，雖然我們曾這樣看待基督，現在卻不再這樣看待祂了。</span>
<span className="v" id="v17" data-v="17" data-xref="以西結書 36:26; 以弗所書 4:22–24; 以賽亞書 43:18–19"> 若有人在基督裡，他就是新造的人，舊事已過，看啊，一切都更新了。</span>
<span className="v" id="v18" data-v="18" data-xref="歌羅西書 1:20–21; 哥林多後書 5:19–20; 羅馬書 5:10–11"> 這一切都是上帝的作為，祂藉著基督使我們與祂和好，又把勸人與祂和好的職分賜給了我們。</span>
<span className="v" id="v19" data-v="19" data-xref="以賽亞書 43:25; 以賽亞書 44:22; 約翰一書 2:1–2"> 也就是說，上帝在基督裡使世人與自己和好，不再追究他們的過犯。祂已託付我們去傳揚這和好之道。</span>
<span className="v" id="v20" data-v="20" data-xref="以弗所書 6:20; 路加福音 14:23; 瑪拉基書 2:7"> 所以我們現在是基督的大使，可以說上帝正藉著我們發出呼求。我們替基督懇求你們：要與上帝和好！</span>
<span className="v" id="v21" data-v="21" data-xref="彼得前書 2:22–24; 彼得前書 3:18; 羅馬書 5:19"> 上帝使無罪的基督擔當我們的罪，使我們可以藉著基督成為上帝接納的義人。</span>
</div>
</div>

<span className="v" id="v4" data-v="4" data-xref="羅馬書 15:26; 哥林多後書 11:17; 哥林多後書 8:24"> 因為萬一有馬其頓的人與我同去，發現你們並沒有準備好，別說我們會因如此信任你們而羞愧，你們更會無地自容。</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 33:11; 撒母耳記上 25:27; 腓立比書 4:17"> 因此，我認為有必要請那幾位弟兄先去你們那裡，將你們從前認捐的款項收集妥當，這樣就表明你們的捐贈是出於甘心樂意，而不是出於勉強。</span>

## 甘心樂意地捐助

<div className="bt">
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="箴言 11:24–25; 路加福音 6:38; 箴言 22:9"> 要記住：「少種的少收，多種的多收。」</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多後書 8:12; 使徒行傳 20:35; 歷代志上 29:17"> 各人心裡想捐多少就捐多少，不要勉強，不要為難。因為捐得甘心樂意的人才是上帝所喜愛的。</span>
<span className="v" id="v8" data-v="8" data-xref="以弗所書 3:20; 腓立比書 4:18–19; 箴言 10:22"> 上帝能夠把各樣恩典多多賜給你們，使你們在各方面常常富足有餘，可以多行各種善事。</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 112:9; 詩篇 112:3; 箴言 21:21"> 正如聖經上說：<br /><span className="pl pl-1">「他慷慨施捨、賙濟窮人，</span><br /><span className="pl pl-1">他的公義永遠長存。」</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="詩篇112·9。">a</a></sup></span>
<span className="v" id="v10" data-v="10" data-xref="以賽亞書 55:10; 哥林多後書 9:6; 何西阿書 10:12"> 賜農夫種子又賜人糧食的上帝，必加倍賜給你們種子，使你們收穫更多仁義的果實，</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多後書 4:15; 歷代志上 29:12–14; 提摩太前書 6:17–18"> 叫你們事事豐裕，可以多多施捨。這樣，從我們這裡得到你們幫助的人便會向上帝獻上感恩。</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多後書 8:14–15; 腓利門書 1:4–7; 腓立比書 2:25"> 因為這件善事不單可以幫助經濟困難的聖徒，也使許多人對上帝充滿感恩。</span>
<span className="v" id="v13" data-v="13" data-xref="希伯來書 13:16; 馬太福音 5:16; 哥林多後書 2:12"> 通過這件善事，他們會把榮耀歸給上帝，因為看見你們信服基督的福音，慷慨地幫助他們及眾人。</span>
<span className="v" id="v14" data-v="14" data-xref="提摩太前書 1:14; 腓立比書 4:1; 腓立比書 4:18–19"> 他們也會因上帝賜給你們的豐盛恩典而熱切地為你們禱告。</span>
<span className="v" id="v15" data-v="15" data-xref="哥林多後書 2:14; 以弗所書 5:20; 約翰福音 3:16"> 感謝上帝，祂的恩賜真是無以言表！</span>
</div>

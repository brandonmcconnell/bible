## 保羅與假使徒

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多後書 11:4; 哥林多前書 1:21; 哥林多後書 11:19"> 請你們包容我的這點愚妄吧！我知道你們一定會包容我。</span>
<span className="v" id="v2" data-v="2" data-xref="何西阿書 2:19–20; 以弗所書 5:26–27; 以賽亞書 54:5"> 我以上帝痛恨不貞的愛愛你們。因為我曾把你們當作貞潔的少女許配給一位丈夫——基督。</span>
<span className="v" id="v3" data-v="3" data-xref="歌羅西書 2:8; 加拉太書 1:6; 以弗所書 4:14"> 但我真怕你們會像被狡猾的蛇欺騙的夏娃一樣，思想受迷惑，失去了對基督純真專一的心。</span>
<span className="v" id="v4" data-v="4" data-xref="加拉太書 1:6–8; 哥林多前書 3:11; 提摩太前書 2:5"> 有人來傳另一位耶穌——與我們所傳的不同，或要你們接受另一個靈——與你們所接受的不同，或要你們相信另一種福音——與你們所相信的不同，你們竟欣然容忍。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多後書 12:11–12; 哥林多前書 15:10; 加拉太書 2:6–9"> 我想，我一點也不比那些「超級使徒」差。</span>
<span className="v" id="v6" data-v="6" data-xref="以弗所書 3:4; 哥林多前書 1:17; 哥林多後書 4:2"> 我雖然不善辭令，但我認識真理。這一點，我們在各方面已經向你們證明了。</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多後書 12:13; 帖撒羅尼迦前書 2:9; 哥林多後書 10:1"> 我為了把上帝的福音白白地傳給你們，甘願卑微，以提升你們，我這樣做有罪嗎？</span>
<span className="v" id="v8" data-v="8" data-xref="腓立比書 4:18; 哥林多後書 11:9; 腓立比書 4:14–16"> 我「搶奪」其他教會，拿了他們的資助，來服侍你們。</span>
<span className="v" id="v9" data-v="9" data-xref="帖撒羅尼迦後書 3:8–9; 帖撒羅尼迦前書 2:9; 帖撒羅尼迦前書 2:6"> 我在你們那裡經濟拮据的時候，沒有拖累過你們任何人，因為馬其頓來的弟兄補足了我的缺乏。我沒有在任何方面成為你們的負擔，將來也不會成為你們的負擔。</span>
<span className="v" id="v10" data-v="10" data-xref="羅馬書 9:1; 羅馬書 1:9; 使徒行傳 18:12"> 我憑我心中基督的真理說，亞該亞地區無人會阻止我這樣誇口。</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多後書 12:15; 哥林多後書 6:11–12; 哥林多後書 7:3"> 為什麼呢？難道我不愛你們嗎？上帝知道我愛你們！</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多前書 9:12; 哥林多前書 5:6; 哥林多後書 5:12"> 我現在所做的，將來還會繼續做下去，為了要斷絕那些投機分子的機會，使他們無法在所誇耀的事上被認為與我們一樣。</span>
<span className="v" id="v13" data-v="13" data-xref="加拉太書 1:7; 啟示錄 2:2; 約翰一書 4:1"> 其實這些人是假使徒，為人詭詐，冒充基督的使徒。</span>
<span className="v" id="v14" data-v="14" data-xref="加拉太書 1:8; 哥林多後書 2:11; 哥林多後書 11:3"> 這不足為奇，因為連撒旦都裝成光明的天使，</span>
<span className="v" id="v15" data-v="15" data-xref="腓立比書 3:19; 啟示錄 9:11; 以賽亞書 9:14–15"> 牠的爪牙若冒充公義的僕人，又何足為奇呢？他們最終必得到應得的報應。</span>
</div>
</div>

## 保羅的諸多苦難

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="哥林多後書 11:1; 哥林多後書 12:6; 哥林多後書 12:11"> 我再說，誰也別把我當作傻瓜。你們如果真這麼想，那就把我當傻瓜看待吧！好讓我也能說幾句自誇的話。</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多前書 7:12; 腓立比書 3:3–6; 哥林多後書 9:4"> 我這樣說，並不是主的意思，而是像一個傻瓜一樣誇口。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前書 4:10; 哥林多後書 11:21–23; 哥林多後書 10:12–18"> 既然許多人憑血氣誇口，我當然也可以誇口。</span>
<span className="v" id="v19" data-v="19" data-xref="哥林多前書 4:10; 哥林多前書 10:15; 哥林多前書 8:1"> 因為你們這些聰明人竟然甘願忍受那些傻瓜，</span>
<span className="v" id="v20" data-v="20" data-xref="加拉太書 2:4; 加拉太書 4:3; 加拉太書 5:1"> 就算有人奴役、剝削、利用、侮辱你們，打你們耳光，你們都能逆來順受！</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多後書 10:10; 哥林多後書 11:17; 哥林多後書 10:1–2"> 慚愧得很，我必須說，我們太軟弱了，做不出那樣的事！ 然而，別人敢誇口的，我再講一句傻話，我也敢。</span>
<span className="v" id="v22" data-v="22" data-xref="腓立比書 3:5; 羅馬書 11:1; 羅馬書 9:4"> 他們是希伯來人，我也是。他們是以色列人，我也是。他們是亞伯拉罕的子孫，我也是。</span>
<span className="v" id="v23" data-v="23" data-xref="哥林多後書 6:4–5; 哥林多後書 1:9–10; 哥林多後書 6:9"> 他們自稱是基督的僕人，我說句狂話，我更是！我比他們更辛苦，坐牢更多，身受更重的鞭打，經常出生入死。</span>
<span className="v" id="v24" data-v="24" data-xref="馬可福音 13:9; 申命記 25:2–3; 馬太福音 10:17"> 我被猶太同胞鞭打了五次，每次三十九鞭<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「三十九鞭」希臘文是「四十鞭減一鞭」。">a</a></sup>，</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行傳 14:19; 使徒行傳 16:37; 希伯來書 11:37"> 被人用棍打了三次，用石頭打了一次，遇到船難三次，曾在大海上漂浮了一天一夜。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行傳 14:5; 使徒行傳 17:5; 使徒行傳 13:50"> 我常常四處奔波，遭遇江河的危險、盜賊的威脅、同胞的威脅、外族的威脅、城中的危險、曠野的危險、海上的危險和假信徒的威脅。</span>
<span className="v" id="v27" data-v="27" data-xref="腓立比書 4:12; 哥林多後書 6:5; 帖撒羅尼迦前書 2:9"> 我勞碌困苦，不得安眠，又饑又渴，挨餓受凍，赤身露體。</span>
<span className="v" id="v28" data-v="28" data-xref="哥林多前書 7:17; 羅馬書 15:16; 使徒行傳 20:18–35"> 此外，我還掛慮眾教會的事，天天承受著壓力。</span>
<span className="v" id="v29" data-v="29" data-xref="哥林多前書 8:13; 哥林多前書 9:22; 加拉太書 4:8–20"> 有誰軟弱，我不感同身受呢？有誰失足犯罪，我不心急如焚呢？</span>
<span className="v" id="v30" data-v="30" data-xref="哥林多後書 12:5–11; 箴言 25:27; 哥林多前書 2:3"> 如果一定要誇耀，我情願誇耀自己的軟弱。</span>
<span className="v" id="v31" data-v="31" data-xref="羅馬書 9:5; 以弗所書 1:3; 約翰福音 10:30"> 主耶穌的父上帝永受稱頌，祂知道我不撒謊。</span>
<span className="v" id="v32" data-v="32" data-xref="使徒行傳 9:24–25; 哥林多後書 11:26"> 在大馬士革的時候，亞哩達王手下的總督吩咐人把守城門，要逮捕我。</span>
<span className="v" id="v33" data-v="33" data-xref="使徒行傳 9:25; 撒母耳記上 19:12; 約書亞記 2:18"> 我被人用筐子從城牆上的窗戶縋下去，才逃出他的手掌。</span>
</div>
</div>

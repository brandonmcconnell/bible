## 拿俄米和路得

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 12:10; 創世記 26:1; 以西結書 14:13"> 在士師執政的時代，猶大發生了饑荒。有一個人帶著妻子和兩個兒子從猶大的伯利恆遷到摩押境內寄居。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 35:19; 彌迦書 5:2; 撒母耳記上 17:21"> 這個人名叫以利米勒，妻子叫拿俄米，兩個兒子分別叫瑪倫和基連。他們都是猶大 伯利恆的以法他人。他們來到摩押，就在那裡住了下來。</span>
<span className="v" id="v3" data-v="3" data-xref="希伯來書 12:10–11; 詩篇 34:19; 希伯來書 12:6"> 後來，拿俄米的丈夫以利米勒去世了，留下她和兩個兒子。</span>
<span className="v" id="v4" data-v="4" data-xref="馬太福音 1:5; 列王紀上 11:1–2; 申命記 23:3"> 這兩個兒子都娶了摩押的女子為妻，一個名叫俄珥巴，一個名叫路得。在那裡住了大約十年後，</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 32:39; 詩篇 89:30–32; 以賽亞書 49:21"> 瑪倫和基連二人都去世了，只剩下拿俄米，沒有了丈夫，也沒有了兒子。</span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 132:15; 出埃及記 3:16; 詩篇 111:5"> 後來，拿俄米在摩押聽說耶和華眷顧祂的子民，使他們五穀豐登，就帶著兩個兒媳婦準備回故鄉。</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀下 8:3; 路得記 1:14; 出埃及記 18:27"> 她們離開所居住的地方，動身返回猶大。</span>
<span className="v" id="v8" data-v="8" data-xref="路得記 2:20; 路得記 1:5; 歌羅西書 3:18"> 拿俄米對兩個兒媳婦說：「你們還是各回娘家去吧！願耶和華恩待你們，就好像你們恩待死去的丈夫和我一樣。</span>
<span className="v" id="v9" data-v="9" data-xref="路得記 3:1; 使徒行傳 20:37; 創世記 29:11"> 願耶和華使你們都有機會再嫁，找到好歸宿。」拿俄米說完了，就親吻她們。她們都放聲大哭，</span>
<span className="v" id="v10" data-v="10" data-xref="撒迦利亞書 8:23; 詩篇 16:3; 詩篇 119:63"> 說：「不！我們要跟你一起回你的家鄉。」</span>
<span className="v" id="v11" data-v="11" data-xref="申命記 25:5; 創世記 38:11"> 拿俄米說：「我的女兒啊，回娘家去吧！為什麼要跟我去呢？難道我還能生兒子做你們的丈夫嗎？</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 17:17; 提摩太前書 5:9"> 回去吧！我的女兒啊，走吧！我已經老了，不可能再嫁人了。就算我還有指望，今晚能再結婚生子，</span>
<span className="v" id="v13" data-v="13" data-xref="約伯記 19:21; 士師記 2:15; 詩篇 32:4"> 難道你們能一直不嫁，等到他們長大嗎？不要這樣，我的女兒啊！這樣你們會很苦，我就更苦了，因為耶和華伸手懲罰我。」</span>
<span className="v" id="v14" data-v="14" data-xref="箴言 18:24; 馬太福音 16:24; 馬太福音 10:37"> 她們又放聲大哭，俄珥巴就親吻婆婆，向她道別，但路得卻依依不捨，不肯離去。</span>
<span className="v" id="v15" data-v="15" data-xref="士師記 11:24; 約書亞記 24:15; 西番雅書 1:6"> 拿俄米說：「你看，你嫂嫂已經回她家鄉和她拜的神明那裡去了，你也跟著嫂嫂回去吧！」</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳記下 15:21; 路得記 2:11–12; 列王紀下 2:2–6"> 路得說：「不要逼我撇你而去。你往哪裡去，我也要往哪裡去；你住在哪裡，我也要住在哪裡；你的同胞就是我的同胞，你的上帝就是我的上帝；</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳記上 3:17; 列王紀上 2:23; 列王紀下 6:31"> 你死在哪裡，我也死在哪裡、葬在哪裡。只有死才能把我們分開。否則，願耶和華重重地懲罰我！」</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行傳 21:14; 以弗所書 6:10; 使徒行傳 2:42"> 拿俄米見路得堅決要跟她走，就不再勸阻她了。</span>
<span className="v" id="v19" data-v="19" data-xref="馬太福音 21:10; 以賽亞書 23:7; 耶利米哀歌 2:15"> 於是，二人便一同回到伯利恆。她們進了伯利恆，全城轟動。婦女們問：「這不是拿俄米嗎？」</span>
<span className="v" id="v20" data-v="20" data-xref="約伯記 6:4; 希伯來書 12:11; 詩篇 73:14"> 拿俄米對她們說：「不要再叫我拿俄米<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「拿俄米」意思是「甜」。">a</a></sup>了，叫我瑪拉<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="「瑪拉」意思是「苦」。">b</a></sup>吧！因為全能者叫我過得好苦啊！</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳記上 2:7–8; 約伯記 1:21; 約伯記 16:8"> 我曾滿滿地離開這裡，現在耶和華卻使我空空地回來。既然耶和華叫我受苦，全能者使我遭難，為何還叫我拿俄米呢？」</span>
<span className="v" id="v22" data-v="22" data-xref="路得記 2:23; 撒母耳記下 21:9; 出埃及記 9:31–32"> 拿俄米帶著她的兒媳婦摩押女子路得從摩押回到了伯利恆，那時正是開始收割大麥的季節。</span>
</div>

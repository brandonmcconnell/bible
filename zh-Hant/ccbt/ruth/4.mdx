## 波阿斯娶路得

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命記 25:7; 路得記 3:12; 申命記 16:18"> 波阿斯來到城門口，坐在那裡，恰巧看見他所說的那位至親經過，便招呼他說：「某人啊，請過來坐一坐。」那人便走過來坐下。</span>
<span className="v" id="v2" data-v="2" data-xref="箴言 31:23; 列王紀上 21:8; 使徒行傳 6:12"> 波阿斯又邀請了城裡的十位長老，對他們說：「請過來坐一坐。」他們都坐下以後，</span>
<span className="v" id="v3" data-v="3" data-xref="箴言 13:10; 詩篇 112:5"> 波阿斯便對那位至親說：「拿俄米從摩押回來了，現在要賣我們族兄以利米勒的那塊地，</span>
<span className="v" id="v4" data-v="4" data-xref="利未記 25:25–29; 耶利米書 32:7–12; 羅馬書 12:17"> 我想應該讓你知道這件事。你最有權贖那塊地，其次才是我，此外再沒有別人了。如果你願意贖回那塊地，請你當著在座各位長老的面表明。如果不願意，請你讓我知道。」那人說：「我願意贖。」</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 38:8; 申命記 25:5–6; 馬太福音 22:24"> 波阿斯說：「那麼，你從拿俄米手中買地的那天，也要娶已死之人的妻子摩押女子路得，好讓死者繼續在產業上留名。」</span>
<span className="v" id="v6" data-v="6" data-xref="利未記 25:25; 路得記 3:13"> 那位至親說：「那我就不能贖了，免得損害到我的產業。你來贖吧，我不能贖。」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="申命記 25:7–10"> 從前在以色列，買贖或交易有這樣的規矩：一旦成交，一方要把鞋脫下來交給另一方，以色列人以此為成交的憑據。</span>
<span className="v" id="v8" data-v="8"> 那位至親對波阿斯說：「你自己買吧！」他就把鞋脫了下來。</span>
<span className="v" id="v9" data-v="9" data-xref="耶利米書 32:10–12; 創世記 23:16–18"> 波阿斯向長老和所有在場的人說：「請各位今天為我作證，所有屬於以利米勒、基連和瑪倫的產業，我都從拿俄米手上買了。</span>
<span className="v" id="v10" data-v="10" data-xref="申命記 25:6; 以弗所書 5:25; 創世記 29:27"> 同時，我要娶瑪倫的遺孀摩押女子路得為妻，好使死者繼續在產業上留名，免得他的名在本族本鄉中消失。今天，請各位作證。」</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 29:32–24; 彌迦書 5:2; 馬太福音 2:6"> 聚集在城門口的眾人和長老都說：「我們願意作證。願耶和華使要進你家門的這女子，像建立以色列家的拉結和利亞一樣。願你在以法他家業興隆，在伯利恆聲名遠揚。</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 38:29; 撒母耳記上 2:20; 歷代志上 2:4"> 願耶和華藉著這年輕女子賜你後裔，使你家像先祖猶大和她瑪的兒子法勒斯家一樣。」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="創世記 33:5; 創世記 29:31; 路得記 3:11"> 這樣，波阿斯便娶了路得為妻，與她同房。耶和華使她懷孕生了一個兒子。</span>
<span className="v" id="v14" data-v="14" data-xref="馬太福音 1:5–20; 路加福音 1:58; 創世記 12:2"> 婦女們對拿俄米說：「耶和華當受稱頌！因為今日祂賜給你一位至親，使你後繼有人，願這孩子在以色列得享盛名！</span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 55:22; 以賽亞書 46:4; 創世記 45:11"> 他必讓你的生命重新得力，奉養你，使你安度晚年，因為他是愛你的兒媳婦所生的。有這兒媳婦比有七個兒子還要好！」</span>
<span className="v" id="v16" data-v="16"> 拿俄米接過嬰孩抱在懷中，照顧他。</span>
<span className="v" id="v17" data-v="17" data-xref="路加福音 1:58–63"> 鄰居的婦女們說：「拿俄米有孩子了！」她們給孩子取名叫俄備得，這俄備得就是耶西的父親，耶西是大衛的父親。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="馬太福音 1:3–6; 歷代志上 2:4–8; 路加福音 3:33"> 以下是法勒斯的家譜：法勒斯生希斯崙，</span>
<span className="v" id="v19" data-v="19" data-xref="路加福音 3:33; 歷代志上 2:9–10; 馬太福音 1:4"> 希斯崙生蘭，蘭生亞米拿達，</span>
<span className="v" id="v20" data-v="20" data-xref="民數記 1:7; 路加福音 3:32; 馬太福音 1:4"> 亞米拿達生拿順，拿順生撒門，</span>
<span className="v" id="v21" data-v="21" data-xref="路加福音 3:32; 馬太福音 1:5; 歷代志上 2:11–12"> 撒門生波阿斯，波阿斯生俄備得，</span>
<span className="v" id="v22" data-v="22" data-xref="歷代志上 2:15; 以賽亞書 11:1; 馬太福音 1:6"> 俄備得生耶西，耶西生大衛。</span>
</div>
</div>

## 路得遇見波阿斯

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路得記 4:21; 路得記 3:12; 路得記 3:2"> 拿俄米的丈夫以利米勒有個親戚，名叫波阿斯，是個有名望的財主。</span>
<span className="v" id="v2" data-v="2" data-xref="利未記 23:22; 利未記 19:9; 申命記 24:19–21"> 摩押女子路得對拿俄米說：「讓我到田裡去，跟在那些願意恩待我的人後面，撿些麥穗回來。」拿俄米說：「去吧，我的女兒！」</span>
<span className="v" id="v3" data-v="3" data-xref="帖撒羅尼迦後書 3:12; 馬太福音 10:29; 路加福音 10:31"> 於是，路得便去了。她恰巧來到以利米勒的親戚波阿斯的田裡，跟在收割的人後面撿麥穗。</span>
<span className="v" id="v4" data-v="4" data-xref="詩篇 129:7–8; 士師記 6:12; 路加福音 1:28"> 當時，波阿斯剛好從伯利恆來到田間，向那些收割的工人問安說：「願耶和華與你們同在。」他們回答說：「願耶和華賜福給你。」</span>
<span className="v" id="v5" data-v="5" data-xref="路得記 4:21; 歷代志上 2:11–12"> 波阿斯問負責收割的工頭說：「那是誰家的女子？」</span>
<span className="v" id="v6" data-v="6" data-xref="路得記 1:22; 馬太福音 24:45; 創世記 24:2"> 工頭回答說：「她是摩押女子，跟拿俄米剛從摩押回來。</span>
<span className="v" id="v7" data-v="7" data-xref="箴言 13:4; 箴言 18:23; 箴言 15:33"> 她求我讓她跟在收割的人後面，撿工人紮捆時遺落的麥穗。她一大早就來到這裡，一直撿到現在，除了在涼棚裡稍微坐了一會兒之外，幾乎沒有休息。」</span>
<span className="v" id="v8" data-v="8" data-xref="列王紀下 5:13; 雅歌 1:7–8; 撒母耳記上 3:6"> 波阿斯對路得說：「姑娘<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「姑娘」希伯來文是「女兒」。">a</a></sup>，聽我說，你不用到別人的田裡去拾麥穗了，也不必離開這裡，只管留下來跟我的女工在一起。</span>
<span className="v" id="v9" data-v="9" data-xref="約翰一書 5:18; 創世記 20:6; 箴言 6:29"> 你看我的工人在哪一塊田裡收割，就跟著我的女工去，我已經吩咐工人不可欺負你。要是你渴了，就去水罐那裡喝工人打回來的水。」</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳記上 25:23; 路得記 2:13; 路加福音 1:43"> 路得就俯伏在地叩謝他，說：「我不過是個外族人，你為什麼這樣恩待我、體恤我？」</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 14:33; 路加福音 18:29–30; 路加福音 5:11"> 波阿斯說：「自從你丈夫過世之後，你怎樣善待婆婆，怎樣離開父母和家鄉來到素不相識的人當中，我都聽說了。</span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 36:7; 詩篇 91:4; 詩篇 63:7"> 願耶和華照你所行的獎賞你！你來投靠在以色列的上帝耶和華的翅膀下，願祂厚厚地賞賜你。」</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳記上 1:18; 創世記 34:3; 創世記 33:8"> 路得說：「我主啊！我真是在你面前蒙恩，雖然我連你的婢女都不如，你還好言安慰我。」</span>
<span className="v" id="v14" data-v="14" data-xref="路得記 2:18; 列王紀下 4:43–44; 馬太福音 14:20"> 吃飯的時候，波阿斯對路得說：「來，吃一點餅吧，可以蘸著醋吃。」路得便坐在那些收割工人旁邊。波阿斯遞給她一些烤好的麥穗。她吃飽了，還有剩餘的。</span>
<span className="v" id="v15" data-v="15" data-xref="雅各書 1:5"> 當她起來又要去撿麥穗的時候，波阿斯就吩咐他的工人說：「你們要任由她撿，就算她從麥捆中撿麥穗，你們也不要為難她。</span>
<span className="v" id="v16" data-v="16" data-xref="羅馬書 12:13; 約翰一書 3:17–18; 申命記 24:19–21"> 甚至要從麥捆中抽一些出來讓她撿，不要責罵她。」</span>
<span className="v" id="v17" data-v="17" data-xref="以西結書 45:11–12; 箴言 31:27; 出埃及記 16:36"> 於是，路得便在田間繼續撿麥穗，到了黃昏，她把撿到的麥穗打了，大約有十公斤大麥。</span>
<span className="v" id="v18" data-v="18" data-xref="路得記 2:14; 約翰福音 6:12–13; 提摩太前書 5:4"> 她把撿來的麥子帶回城裡給婆婆拿俄米看，又把剩下來的食物給婆婆。</span>
<span className="v" id="v19" data-v="19" data-xref="路得記 2:10; 詩篇 41:1; 列王紀上 7:21"> 婆婆問她：「你今天在哪裡拾麥穗？在哪裡做工？願那善待你的人蒙福！」她就告訴婆婆說：「今天我在一個名叫波阿斯的人那裡工作。」</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳記下 2:5; 路得記 3:9–10; 利未記 25:25"> 拿俄米說：「願耶和華賜福給他，他對活著的和過世的都是那麼有情有義。」拿俄米又對路得說：「這人是我們的近親，有為我們贖業的責任。」</span>
<span className="v" id="v21" data-v="21" data-xref="雅歌 1:7–8; 路得記 2:7–8; 路得記 2:22"> 摩押女子路得說：「他還對我說，『你可以跟在我的工人後面撿麥穗，直到他們把我的莊稼都收完為止。』」</span>
<span className="v" id="v22" data-v="22" data-xref="雅歌 1:8; 箴言 27:10"> 拿俄米對兒媳路得說：「我的女兒啊，你就跟他的女工一起到田裡去，免得去別人的田裡被欺負。」</span>
<span className="v" id="v23" data-v="23" data-xref="箴言 6:6–8; 申命記 16:9; 以弗所書 6:1–3"> 因此，路得便常跟波阿斯的女工在一起撿麥穗，直到大麥小麥都收割完畢。路得就這樣陪伴婆婆過日子。</span>

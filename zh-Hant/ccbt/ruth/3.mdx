## 路得麥場見波阿斯

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路得記 1:9; 提摩太前書 5:8; 提摩太前書 5:14"> 一天，路得的婆婆拿俄米對她說：「我的女兒啊，我實在應該為你找個好歸宿，使你生活幸福。</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 25:5–10; 路得記 2:20–23; 路得記 2:8"> 波阿斯不是我們的親戚嗎？而且你又常與他的女工在一起。今晚他會在麥場簸大麥。</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳記下 14:2; 提摩太前書 2:9–10; 以斯帖記 5:1"> 你要梳洗打扮、抹上香膏、換件衣服，然後去麥場，但不要讓他認出你是誰。等他吃飽喝足，</span>
<span className="v" id="v4" data-v="4" data-xref="帖撒羅尼迦前書 5:22"> 躺下睡覺的時候，你看準他躺臥的地方，去掀開蓋在他腳上的被，躺在那裡，到時他必定會告訴你該怎樣做。」</span>
<span className="v" id="v5" data-v="5" data-xref="歌羅西書 3:20; 以弗所書 6:1"> 路得說：「好，我一定照你的吩咐去做。」</span>
<span className="v" id="v6" data-v="6" data-xref="箴言 1:8; 約翰福音 2:5; 出埃及記 20:12"> 於是，路得就到麥場去，照她婆婆吩咐的去做。</span>
<span className="v" id="v7" data-v="7" data-xref="士師記 19:6; 以斯帖記 1:10; 撒母耳記下 13:28"> 波阿斯吃過晚飯，心裡舒暢，便躺在麥堆旁邊睡著了。路得悄悄過去掀起蓋在他腳上的被，躺在他腳旁。</span>
<span className="v" id="v8" data-v="8"> 到了半夜，波阿斯忽然驚醒，翻過身來，發現一個女子躺在他的腳旁，</span>
<span className="v" id="v9" data-v="9" data-xref="以西結書 16:8; 路得記 2:20; 路得記 3:12"> 便問道：「你是誰？」她答道：「我是你的婢女路得，請用你的衣襟遮蓋我，因為你是我的近親。」</span>
<span className="v" id="v10" data-v="10" data-xref="路得記 2:20; 哥林多前書 13:4–5; 路得記 1:8"> 波阿斯說：「姑娘，願耶和華賜福給你，因為你一直對婆家情深義重，現在更是如此。你本來可以找一個富有或貧窮的年輕丈夫，然而你卻沒有這樣做。</span>
<span className="v" id="v11" data-v="11" data-xref="箴言 31:29–31; 箴言 31:10; 箴言 12:4"> 姑娘，不要害怕，你所說的一切，我都會去為你安排，城裡所有的人都知道你是個賢德的女子。</span>
<span className="v" id="v12" data-v="12" data-xref="路得記 4:1; 帖撒羅尼迦前書 4:6; 馬太福音 7:12"> 不錯，我是你的近親，可是有一個人比我更近。</span>
<span className="v" id="v13" data-v="13" data-xref="路得記 4:5; 耶利米書 4:2; 路得記 2:20"> 你今晚就留在這裡，明天早上，如果他答應盡親屬的義務，就由他照顧你；如果他不肯，我憑永活的耶和華起誓，我會盡我的本分。現在你只管安心睡到天亮。」</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多後書 8:21; 羅馬書 14:16; 哥林多前書 10:32"> 路得就躺在波阿斯的腳旁。天未亮，還看不清人的時候，路得就起來了。因為波阿斯曾對她說：「不可讓別人知道有女人來過麥場。」</span>
<span className="v" id="v15" data-v="15" data-xref="以賽亞書 32:8; 加拉太書 6:10"> 離開的時候，波阿斯對她說：「把你的外衣拿來鋪開。」路得就照做了。他用路得的外衣包了六簸箕大麥，幫她扛在肩上，她便回城了。</span>
<span className="v" id="v16" data-v="16"> 回到家中，婆婆問她：「女兒啊，怎麼樣了？」路得便將事情的經過都告訴了婆婆。</span>
<span className="v" id="v17" data-v="17"> 她又說：「那個人給了我六簸箕大麥，對我說，『不要空手回去見你婆婆。』」</span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 37:3–5; 以賽亞書 28:16; 以賽亞書 30:7"> 拿俄米說：「女兒啊！你只管安靜等候，看這事怎樣發展，因為那人今天不把事情辦妥，是絕不會休息的。」</span>

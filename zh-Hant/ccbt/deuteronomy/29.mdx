## 在摩押立約

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命記 5:2–3; 希伯來書 8:9; 出埃及記 24:2–8"> 耶和華除了與以色列人在何烈山立約外，還在摩押吩咐摩西與以色列人立以下的約。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 19:4; 出埃及記 8:12; 約書亞記 24:5–6"> 摩西召來所有以色列人，對他們說：「你們曾親眼見過耶和華在埃及怎樣對付法老及其臣僕和國民，</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 4:32–35; 尼希米記 9:9–11; 申命記 7:18–19"> 親眼看見祂怎樣降下巨大的災難，行偉大的神蹟奇事。</span>
<span className="v" id="v4" data-v="4" data-xref="以弗所書 4:18; 以賽亞書 6:9–10; 箴言 20:12"> 但耶和華至今還沒有賜給你們能明白的心、能看見的眼、能聽清的耳。</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 8:4; 尼希米記 9:21; 申命記 8:2"> 四十年來，耶和華領你們走過曠野，你們身上的衣服沒有穿破，腳上的鞋沒有穿壞；</span>
<span className="v" id="v6" data-v="6" data-xref="申命記 8:3; 以弗所書 5:18; 哥林多前書 9:25"> 你們沒有吃餅，也沒有喝淡酒和烈酒。這是為了讓你們知道耶和華是你們的上帝。</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 2:24–17; 民數記 32:33–42; 詩篇 135:10–12"> 我們來到這裡的時候，希實本王西宏和巴珊王噩都出來攻擊我們，我們擊敗了他們，</span>
<span className="v" id="v8" data-v="8" data-xref="申命記 3:12–13; 民數記 32:33"> 並將佔領的土地分給呂便支派、迦得支派和瑪拿西半個支派作產業。</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀上 2:3; 申命記 4:6; 路加福音 11:28"> 所以，你們要謹遵這約上的話，以便凡事順利。</span>
<span className="v" id="v10" data-v="10" data-xref="約珥書 2:16–17; 啟示錄 20:12; 申命記 31:12–13"> 「今天，你們全都站在你們的上帝耶和華面前，包括你們的族長、長老、官員、所有以色列男子、</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及記 12:38; 約書亞記 9:21–27; 出埃及記 12:48–49"> 你們的孩子、妻子和寄居在你們營中為你們砍柴挑水的外族人，</span>
<span className="v" id="v12" data-v="12" data-xref="歷代志下 15:12–15; 列王紀下 11:17; 申命記 5:2–3"> 為要接受你們的上帝耶和華今天與你們立的誓約。</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及記 6:7; 創世記 17:7; 申命記 28:9"> 這樣，祂今天將確立你們作祂的子民、祂作你們的上帝，正如祂對你們的應許和對你們祖先亞伯拉罕、以撒和雅各的誓言。</span>
<span className="v" id="v14" data-v="14" data-xref="耶利米書 31:31–34; 希伯來書 8:7–12"> 耶和華的這誓約不僅是與你們立的，</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行傳 2:39; 哥林多前書 7:14; 耶利米書 50:5"> 也是與今天一同站在我們的上帝耶和華面前的人，以及今天不在這裡的人<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「今天不在這裡的人」或譯「我們將來的子孫」。">a</a></sup>立的。</span>
<span className="v" id="v16" data-v="16" data-xref="申命記 2:19; 申命記 2:9; 申命記 2:4"> 「你們知道我們如何在埃及生活，也知道我們如何穿越列國來到這裡。</span>
<span className="v" id="v17" data-v="17" data-xref="申命記 28:36"> 你們也見過他們可憎的木、石、金、銀偶像。</span>
<span className="v" id="v18" data-v="18" data-xref="希伯來書 12:15; 申命記 11:16–17; 申命記 13:1–15"> 你們中間，不論男人或女人，家族或支派，切不可有人背棄我們的上帝耶和華，去祭拜列國的神明，你們中間切不可有殘根長出苦毒的果實，</span>
<span className="v" id="v19" data-v="19" data-xref="耶利米書 7:24; 民數記 15:30; 民數記 15:39"> 免得有人聽了這誓言後，心存僥倖地說，『即使我一意孤行，連累他人，也必平安無事。』</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 74:1; 詩篇 79:5; 申命記 9:14"> 耶和華絕不會赦免這樣的人，祂必向這樣的人發烈怒和義憤，使記在這書上的一切咒詛臨到他身上，從世上抹去他的名字。</span>
<span className="v" id="v21" data-v="21" data-xref="馬太福音 25:41; 約書亞記 7:1–26; 以西結書 13:9"> 耶和華必把他從以色列各支派中隔離出來，使他按律法書上約中的一切咒詛受懲罰。</span>
<span className="v" id="v22" data-v="22" data-xref="耶利米書 19:8"> 「你們的子孫後代和從遠方來的外族人，必看見耶和華降在這地方的災禍和疾病。</span>
<span className="v" id="v23" data-v="23" data-xref="西番雅書 2:9; 耶利米書 17:6; 以賽亞書 34:9"> 遍地將是硫磺和鹽，無法耕種，寸草不生，如同耶和華盛怒之下毀滅的所多瑪、蛾摩拉、押瑪和洗扁。</span>
<span className="v" id="v24" data-v="24" data-xref="耶利米書 22:8–9; 列王紀上 9:8–9; 羅馬書 2:5"> 萬國必問，『耶和華為什麼要這樣對待這地方？祂為什麼大發烈怒？』</span>
<span className="v" id="v25" data-v="25" data-xref="希伯來書 8:9; 以賽亞書 47:6; 耶利米書 50:7"> 必有人回答說，『因為這地方的人背棄了他們祖先的上帝耶和華領他們出埃及時與他們所立的約，</span>
<span className="v" id="v26" data-v="26" data-xref="申命記 28:64; 士師記 2:12–13; 士師記 5:8"> 去供奉其他神明，祭拜他們不認識、也非耶和華分派給他們的神明。</span>
<span className="v" id="v27" data-v="27" data-xref="但以理書 9:11–14; 申命記 28:15–68; 申命記 27:15–26"> 因此，耶和華向這片土地發怒，把這書上寫的一切咒詛都降在這裡。</span>
<span className="v" id="v28" data-v="28" data-xref="歷代志下 7:20; 列王紀上 14:15; 詩篇 52:5"> 耶和華在怒氣、義憤和烈怒中把他們從這地方連根拔起，扔到別的地方，正如今日的情形。』</span>
<span className="v" id="v29" data-v="29" data-xref="但以理書 2:22; 使徒行傳 1:7; 羅馬書 11:33–34"> 「奧秘的事屬於我們的上帝耶和華，只有顯明的事永遠屬於我們和我們的子孫，以便我們可以遵守這律法上的一切話。」</span>

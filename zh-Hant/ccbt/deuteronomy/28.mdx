## 遵守誡命蒙祝福

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以賽亞書 1:19; 出埃及記 23:22; 利未記 26:3–13"> 「你們若全心順服你們的上帝耶和華，謹遵祂今天藉我吩咐你們的一切誡命，祂必使你們超越天下萬國。</span>
<span className="v" id="v2" data-v="2" data-xref="撒迦利亞書 1:6; 申命記 28:15; 提摩太前書 4:8"> 你們若聽從你們的上帝耶和華的話，以下這些福氣必臨到你們，追隨你們。</span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 144:12–15; 創世記 39:5; 哈該書 2:19"> 「無論你們在城裡還是鄉間，都必蒙福。</span>
<span className="v" id="v4" data-v="4" data-xref="箴言 10:22; 創世記 49:25; 申命記 7:13"> 「你們必子孫昌盛，五穀豐登，牛羊成群。</span>
<span className="v" id="v5" data-v="5"> 「你們的籃子和揉麵盆都必蒙福。</span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 121:8; 民數記 27:17; 歷代志下 1:10"> 「你們出入都必蒙福。</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳記下 22:38–41; 利未記 26:7–8; 詩篇 89:23"> 「耶和華必使來犯之敵敗在你們面前、潰不成軍、四散逃命。</span>
<span className="v" id="v8" data-v="8" data-xref="申命記 15:10; 利未記 26:10; 箴言 3:9–10"> 「耶和華必使你們凡事蒙福、五穀滿倉。你們的上帝耶和華必在祂賜給你們的土地上賜福你們。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及記 19:5–6; 申命記 7:6; 申命記 26:18–19"> 「你們若遵守你們上帝耶和華的誡命，遵行祂的旨意，祂必按自己的誓言立你們作祂聖潔的子民。</span>
<span className="v" id="v10" data-v="10" data-xref="歷代志下 7:14; 申命記 11:25; 耶利米書 33:9"> 天下萬民將看出你們是耶和華名下的子民，並懼怕你們。</span>
<span className="v" id="v11" data-v="11" data-xref="申命記 30:9; 箴言 10:22; 利未記 26:9"> 「在耶和華向你們祖先起誓要賜給你們的土地上，祂必使你們子孫昌盛、牛羊成群、五穀豐登。</span>
<span className="v" id="v12" data-v="12" data-xref="申命記 15:6; 約珥書 2:23–24; 申命記 15:10"> 耶和華要為你們打開天上的寶庫，使你們風調雨順、凡事蒙福。你們必借貸給多國，卻無需向別國借貸。</span>
<span className="v" id="v13" data-v="13" data-xref="申命記 28:1; 申命記 4:6–9; 腓立比書 1:27"> 你們若聽從你們的上帝耶和華藉我今天吩咐你們的誡命，謹慎遵行，毫不偏離，也不隨從、供奉其他神明，祂必使你們做首不做尾，居上不居下。</span>
</div>
</div>

## 違背誡命受咒詛

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="瑪拉基書 2:2; 申命記 28:2; 申命記 29:20"> 「你們若不聽從你們的上帝耶和華，不謹遵祂今天藉我吩咐你們的一切誡命和律例，祂必使以下的咒詛臨到你們，追隨你們。</span>
<span className="v" id="v16" data-v="16" data-xref="瑪拉基書 3:9–12; 箴言 3:33; 約珥書 1:4"> 「無論你們在城裡還是鄉間，都必受咒詛。</span>
<span className="v" id="v17" data-v="17" data-xref="哈該書 1:6; 申命記 28:5; 詩篇 69:22"> 「你們的籃子和揉麵盆都必受咒詛。</span>
<span className="v" id="v18" data-v="18" data-xref="利未記 26:26; 利未記 26:19–20; 約伯記 18:16–19"> 「婦女所生的，土地所產的，牛羊所生的都必受咒詛。</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 28:6; 士師記 5:6–7; 歷代志下 15:5"> 「你們出入都必受咒詛。</span>
<span className="v" id="v20" data-v="20" data-xref="以賽亞書 66:15; 瑪拉基書 2:2; 申命記 4:26"> 「因為你們作惡、背棄耶和華，祂要使你們凡事受咒詛、混亂不堪、飽受責罰，直到你們被毀滅，迅速滅亡。</span>
<span className="v" id="v21" data-v="21" data-xref="利未記 26:25; 耶利米書 24:10; 耶利米書 16:4"> 「耶和華要使瘟疫緊緊跟隨你們，直到你們在將要佔領的土地上被滅絕。</span>
<span className="v" id="v22" data-v="22" data-xref="阿摩司書 4:9; 利未記 26:16; 哈該書 2:17"> 「耶和華要使你們遭受癆病、熱症、炎症、炙熱、刀劍、乾旱和黴爛之災。這些要危害你們，直到你們滅亡。</span>
<span className="v" id="v23" data-v="23" data-xref="利未記 26:19; 耶利米書 14:1–6; 列王紀上 18:2"> 「耶和華要使你們頭頂的天如銅，腳下的地如鐵。</span>
<span className="v" id="v24" data-v="24" data-xref="申命記 28:12; 以賽亞書 5:24; 阿摩司書 4:11"> 「耶和華要使雨水變為塵土，降在你們身上，直到你們滅亡。</span>
<span className="v" id="v25" data-v="25" data-xref="以賽亞書 30:17; 以西結書 23:46; 耶利米書 24:9"> 「耶和華要使你們被敵人擊敗、潰不成軍、四散逃命，下場令天下萬國驚懼。</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米書 34:20; 耶利米書 16:4; 耶利米書 7:33"> 你們的屍體要成為飛禽走獸的食物，必無人趕走牠們。</span>
<span className="v" id="v27" data-v="27" data-xref="撒母耳記上 5:6; 申命記 28:35; 利未記 21:20"> 「耶和華要使你們患埃及的膿瘡、腫瘤和癬疥，無藥可治。</span>
<span className="v" id="v28" data-v="28" data-xref="帖撒羅尼迦後書 2:9–11; 以賽亞書 19:11–17; 以賽亞書 6:9–10"> 「耶和華要使你們發瘋、瞎眼、心智錯亂。</span>
<span className="v" id="v29" data-v="29" data-xref="以賽亞書 59:10; 約伯記 5:14; 士師記 6:1–6"> 「你們必在大白天摸索，就像盲人在黑暗中摸索一樣，你們的道路必不得亨通，你們要終日受人欺壓搶掠，無人搭救。</span>
<span className="v" id="v30" data-v="30" data-xref="阿摩司書 5:11; 耶利米書 8:10; 約伯記 31:10"> 「你們聘了妻子，別人必佔有她們；你們蓋了房屋，必不能住在裡面；你們栽種葡萄園，必吃不到園中的出產。</span>
<span className="v" id="v31" data-v="31" data-xref="約伯記 1:14–15; 士師記 6:1"> 「你們必看著自己的牛被宰殺卻吃不到肉，自己的驢被搶走後一去不還，自己的羊被敵人擄走卻無人搭救，</span>
<span className="v" id="v32" data-v="32" data-xref="約珥書 3:6; 申命記 28:41; 約伯記 17:5"> 自己的兒女被外族人擄走，你們終日望眼欲穿，卻無能為力。</span>
<span className="v" id="v33" data-v="33" data-xref="耶利米書 5:17; 申命記 28:29–30; 以賽亞書 1:7"> 「與你們素不相識的民族必吃光你們土地的出產和勞碌所得，你們必常受欺壓，</span>
<span className="v" id="v34" data-v="34" data-xref="啟示錄 16:10–11; 申命記 28:68; 以賽亞書 33:14"> 以致眼前的一切令你們發瘋。</span>
<span className="v" id="v35" data-v="35" data-xref="申命記 28:27; 以賽亞書 3:24; 以賽亞書 3:17"> 「耶和華要使你們從頭到腳長滿毒瘡，無藥可治。</span>
<span className="v" id="v36" data-v="36" data-xref="耶利米書 16:13; 申命記 4:28; 列王紀下 25:11"> 「耶和華要帶你們和你們立的王，到一個你們和你們祖先都不知道的國家，你們要在那裡供奉木石神像。</span>
<span className="v" id="v37" data-v="37" data-xref="耶利米書 25:9; 列王紀上 9:7–8; 耶利米書 24:9"> 「在耶和華驅逐你們去的列國，你們的下場令人驚駭，被人嘲笑和譏諷。</span>
<span className="v" id="v38" data-v="38" data-xref="哈該書 1:6; 彌迦書 6:15; 約珥書 1:4"> 「你們種的多，卻收的少，因為莊稼必被蝗蟲吃掉。</span>
<span className="v" id="v39" data-v="39" data-xref="以賽亞書 17:10–11; 約珥書 2:2–4; 約拿書 4:7"> 「你們栽種、修剪葡萄園，卻吃不到葡萄，也喝不到葡萄酒，因為葡萄必被蟲子吃掉。</span>
<span className="v" id="v40" data-v="40" data-xref="彌迦書 6:15; 詩篇 23:5; 詩篇 104:15"> 「你們境內長滿橄欖樹，卻沒有橄欖油抹身，因為橄欖必未熟先落。</span>
<span className="v" id="v41" data-v="41" data-xref="申命記 28:32; 耶利米哀歌 1:5; 列王紀下 24:14"> 「你們生兒育女，卻留不住一個，因為他們必被擄走。</span>
<span className="v" id="v42" data-v="42" data-xref="阿摩司書 7:1–2; 申命記 28:38–39"> 「蝗蟲要吃光你們的樹木和地上的出產。</span>
<span className="v" id="v43" data-v="43" data-xref="申命記 28:13; 撒母耳記上 13:19–23; 列王紀下 17:20"> 「你們中間的外族人要日益興旺，你們卻要日漸衰微。</span>
<span className="v" id="v44" data-v="44" data-xref="申命記 28:12–13; 耶利米哀歌 1:5"> 「他們要借貸給你們，你們卻不能借貸給他們。他們要做首，你們要做尾。</span>
<span className="v" id="v45" data-v="45" data-xref="申命記 28:15; 以賽亞書 1:20; 耶利米書 24:9–10"> 「因為你們不聽從你們上帝耶和華的話，不遵守祂吩咐你們的誡命和律例，這些咒詛都必臨到你們、追趕你們，直到毀滅你們。</span>
<span className="v" id="v46" data-v="46" data-xref="以賽亞書 8:18; 申命記 28:37; 以西結書 14:8"> 這些咒詛要永遠作為你們和你們子孫的神蹟奇事。</span>
<span className="v" id="v47" data-v="47" data-xref="申命記 16:11; 申命記 12:7–12; 尼希米記 9:35–37"> 因為你們在富足時不心甘情願地事奉你們的上帝耶和華，</span>
<span className="v" id="v48" data-v="48" data-xref="耶利米書 28:13–14; 耶利米哀歌 5:2–6; 以西結書 4:16–17"> 所以你們必饑餓乾渴、赤身裸體、一無所有地侍奉耶和華派來攻擊你們的敵人。祂要把鐵軛加在你們的頸上，直到消滅你們。</span>
<span className="v" id="v49" data-v="49" data-xref="耶利米哀歌 4:19; 耶利米書 49:22; 耶利米書 48:40"> 「耶和華要使一國從遙遠的地極興起，他們要如鷹飛來襲擊你們。你們不懂他們的語言。</span>
<span className="v" id="v50" data-v="50" data-xref="以賽亞書 47:6; 歷代志下 36:17; 路加福音 21:23–24"> 他們面目猙獰，不尊重年老的，也不憐憫年少的。</span>
<span className="v" id="v51" data-v="51" data-xref="申命記 28:33; 以賽亞書 62:8; 利未記 26:26"> 他們要吃光你們的牛羊、五穀、新酒和油，直到消滅你們。</span>
<span className="v" id="v52" data-v="52" data-xref="耶利米書 52:4–7; 以西結書 4:1–8; 馬太福音 24:15–16"> 在你們的上帝耶和華所賜給你們的整片土地上，他們要把你們圍困在各個城邑中，直到你們所依賴的高大堅固的城牆都倒塌。</span>
<span className="v" id="v53" data-v="53" data-xref="耶利米哀歌 4:10; 耶利米書 19:9; 利未記 26:29"> 「當你們被敵人圍困、陷入絕境時，你們必吃自己的親生骨肉，就是你們的上帝耶和華賜給你們的兒女。</span>
<span className="v" id="v54" data-v="54" data-xref="申命記 15:9; 馬太福音 20:15; 申命記 13:6"> 你們被敵人圍困在各城中，陷入絕境時，連你們中間最溫柔體貼的男人也要獨自吞吃子女的肉，不肯分給自己的兄弟、愛妻和剩下的兒女，因為他別無所有。</span>
<span className="v" id="v56" data-v="56" data-xref="申命記 28:54; 以賽亞書 3:16; 耶利米哀歌 4:3–6"> 你們被敵人困在各城中，陷入絕境時，連你們中間最溫柔、嬌嫩得連腳也不肯踏在地上的婦女，都要偷偷吃掉自己生的嬰兒和胎胞，不肯分給所愛的丈夫和子女。</span>
<span className="v" id="v58" data-v="58" data-xref="以賽亞書 42:8; 耶利米書 7:9–10; 瑪拉基書 1:14"> 「如果你們不謹遵這書上所寫的一切律法，不敬畏你們的上帝耶和華那榮耀、可畏的名，</span>
<span className="v" id="v59" data-v="59" data-xref="馬可福音 13:19; 申命記 28:46; 但以理書 9:12"> 祂必使你們及子孫遭遇嚴重而長久的災難和疾病，</span>
<span className="v" id="v60" data-v="60" data-xref="申命記 7:15; 出埃及記 15:26; 申命記 28:27"> 使你們所懼怕的埃及人的一切疾病都降在你們身上，纏住你們，</span>
<span className="v" id="v61" data-v="61" data-xref="申命記 4:25–26"> 還使各種未記在這律法書上的疾病和災難降在你們身上，直到消滅你們。</span>
<span className="v" id="v62" data-v="62" data-xref="申命記 10:22; 尼希米記 9:23; 申命記 4:27"> 因為你們不聽從你們的上帝耶和華的話，即使你們的人數多如天上的星，也將所剩無幾。</span>
<span className="v" id="v63" data-v="63" data-xref="箴言 1:26; 耶利米書 32:41; 申命記 30:9"> 正如耶和華喜歡賜福你們，使你們人丁興旺，祂也同樣會不惜消滅你們，使你們在將要佔領的土地上被剷除。</span>
<span className="v" id="v64" data-v="64" data-xref="申命記 4:27–28; 利未記 26:33; 耶利米書 16:13"> 「耶和華要把你們分散到天下萬邦，你們要在那裡供奉祖祖輩輩素不認識的木石神像。</span>
<span className="v" id="v65" data-v="65" data-xref="利未記 26:36; 羅馬書 11:10; 阿摩司書 9:4"> 你們在萬邦中將不得安寧，沒有落腳之地，耶和華必使你們膽戰心驚、目光呆滯、精神頹廢。</span>
<span className="v" id="v66" data-v="66" data-xref="耶利米哀歌 1:13; 希伯來書 10:27; 啟示錄 6:15–17"> 你們必惴惴不安，晝夜恐懼，生死難料。</span>
<span className="v" id="v67" data-v="67" data-xref="申命記 28:34; 約伯記 7:3–4; 啟示錄 9:6"> 你們必看見可怕之事，以致心中充滿恐懼，早上盼望天黑，晚上盼望天亮。</span>
<span className="v" id="v68" data-v="68" data-xref="耶利米書 44:12; 耶利米書 43:7; 何西阿書 8:13"> 耶和華必沿著我曾說你們再不會走的路線，用船把你們送回埃及。你們將在那裡賣身做敵人的僕婢，卻無人買。」</span>
</div>

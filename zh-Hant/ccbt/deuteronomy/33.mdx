## 摩西最後的祝福

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="約書亞記 14:6; 詩篇 90:1; 創世記 27:4"> 以下是上帝的僕人摩西臨終時給以色列人的祝福：</span>
<span className="v" id="v2" data-v="2" data-xref="猶大書 1:14; 哈巴谷書 3:3; 啟示錄 5:11"> <span className="pl pl-1">「耶和華從西奈山來，</span><br /><span className="pl pl-1">從西珥山向我們顯現，</span><br /><span className="pl pl-1">祂從巴蘭山發出光輝；</span><br /><span className="pl pl-1">祂帶著千萬聖者來臨，</span><br /><span className="pl pl-1">祂右邊有閃耀的光芒。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="路加福音 10:39; 瑪拉基書 1:2; 申命記 7:6–8"> <span className="pl pl-1">祂深愛自己的子民，</span><br /><span className="pl pl-1">眾聖者都聽命於祂，</span><br /><span className="pl pl-1">伏在祂的腳前，</span><br /><span className="pl pl-1">領受祂的訓誨。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="約翰福音 1:17; 詩篇 119:111; 約翰福音 7:19"> <span className="pl pl-1">摩西將律法頒佈給我們，</span><br /><span className="pl pl-1">作為雅各子孫的產業。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="申命記 32:15; 士師記 17:6; 民數記 23:21"> <span className="pl pl-1">百姓的眾首領齊聚，</span><br /><span className="pl pl-1">以色列各支派集合之時，</span><br /><span className="pl pl-1">耶和華在耶書崙做王。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="創世記 49:8; 民數記 32:31–32; 約書亞記 22:1–9"> <span className="pl pl-1">摩西祝福呂便支派說：</span><br /><span className="pl pl-1">「儘管呂便人數稀少，</span><br /><span className="pl pl-1">願他存活，不致滅沒。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="創世記 49:8–12; 詩篇 20:2; 撒母耳記下 7:9–12"> <span className="pl pl-1">摩西祝福猶大支派說：</span><br /><span className="pl pl-1">「耶和華啊，</span><br /><span className="pl pl-1">求你聽猶大人的呼求，</span><br /><span className="pl pl-1">帶他們回歸本族，</span><br /><span className="pl pl-1">出手為他們爭戰，</span><br /><span className="pl pl-1">幫他們對抗仇敵。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="出埃及記 17:7; 出埃及記 28:30; 民數記 20:13"> <span className="pl pl-1">摩西祝福利未支派說：</span><br /><span className="pl pl-1">「耶和華啊，</span><br /><span className="pl pl-1">求你把土明和烏陵賜給虔誠的利未人，</span><br /><span className="pl pl-1">你曾經在瑪撒試驗他們，</span><br /><span className="pl pl-1">在米利巴泉邊與他們爭論。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="馬太福音 10:37; 出埃及記 32:25–29; 馬太福音 12:48"> <span className="pl pl-1">為了聽從你的話，遵守你的約，</span><br /><span className="pl pl-1">他們不顧父母，</span><br /><span className="pl pl-1">捨棄弟兄，拋下兒女。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="利未記 10:11; 詩篇 51:19; 申命記 17:9–11"> <span className="pl pl-1">他們把你的典章傳授給雅各，</span><br /><span className="pl pl-1">把你的律法傳授給以色列；</span><br /><span className="pl pl-1">他們要把香獻在你面前，</span><br /><span className="pl pl-1">把全牲燔祭獻在你的壇上。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳記下 24:23; 以西結書 43:27; 以西結書 20:40–41"> <span className="pl pl-1">耶和華啊，</span><br /><span className="pl pl-1">求你賜他們力量，</span><br /><span className="pl pl-1">悅納他們的工作，</span><br /><span className="pl pl-1">擊碎仇敵的腰桿，</span><br /><span className="pl pl-1">使敵人一蹶不振。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="歷代志下 15:2; 詩篇 91:4; 馬太福音 23:37"> <span className="pl pl-1">摩西祝福便雅憫支派說：</span><br /><span className="pl pl-1">「耶和華所愛的人，</span><br /><span className="pl pl-1">安居在祂身邊，</span><br /><span className="pl pl-1">安居在祂懷中，</span><br /><span className="pl pl-1">終日蒙祂庇護。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v13" data-v="13" data-xref="創世記 49:22–26; 彌迦書 5:7; 以賽亞書 18:4"> <span className="pl pl-1">摩西祝福約瑟家族說：</span><br /><span className="pl pl-1">「願他們的土地蒙耶和華賜福，</span><br /><span className="pl pl-1">得天上的甘霖，</span><br /><span className="pl pl-1">及地下的泉源；</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="詩篇 104:19; 馬太福音 5:45; 詩篇 8:3"> <span className="pl pl-1">得日月之輝，物產豐美；</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="哈巴谷書 3:6; 創世記 49:26; 雅各書 5:7"> <span className="pl pl-1">得古老群山之精華，</span><br /><span className="pl pl-1">永存丘陵之富饒；</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="使徒行傳 7:35; 詩篇 24:1; 出埃及記 3:2–4"> <span className="pl pl-1">得大地的豐肥，</span><br /><span className="pl pl-1">蒙荊棘火中之上帝的恩寵。</span><br /><span className="pl pl-1">願這些福氣落在約瑟頭上，</span><br /><span className="pl pl-1">臨到弟兄中的王者身上。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="列王紀上 22:11; 民數記 23:22; 詩篇 44:5"> <span className="pl pl-1">約瑟威武如頭生的公牛，</span><br /><span className="pl pl-1">有野牛的角，</span><br /><span className="pl pl-1">他用角牴萬邦，</span><br /><span className="pl pl-1">直到地極。</span><br /><span className="pl pl-1">他的兩角是數以萬計的以法蓮人和數以千計的瑪拿西人。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v18" data-v="18" data-xref="創世記 49:13–15; 約書亞記 19:11; 士師記 5:14"> <span className="pl pl-1">摩西祝福西布倫和以薩迦支派說：</span><br /><span className="pl pl-1">「願西布倫人欣然外出，</span><br /><span className="pl pl-1">願以薩迦人在帳篷中歡喜。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="以賽亞書 60:5; 以賽亞書 2:3; 詩篇 4:5"> <span className="pl pl-1">他們要招聚眾人上山，</span><br /><span className="pl pl-1">一同獻上公義的祭；</span><br /><span className="pl pl-1">他們汲取海裡的財富和沙中的寶藏。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v20" data-v="20" data-xref="創世記 49:19; 創世記 9:26–27; 歷代志上 5:18–21"> <span className="pl pl-1">摩西祝福迦得支派說：</span><br /><span className="pl pl-1">「擴張迦得疆界的那位當受稱頌！</span><br /><span className="pl pl-1">迦得蹲伏如母獅，</span><br /><span className="pl pl-1">撕碎頭顱和臂膀。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="民數記 32:16–42; 士師記 5:11; 士師記 5:2"> <span className="pl pl-1">他為自己選了最好的土地，</span><br /><span className="pl pl-1">是留給首領的那份。</span><br /><span className="pl pl-1">他與眾首領同行，</span><br /><span className="pl pl-1">施行耶和華的公義和祂給以色列的典章。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v22" data-v="22" data-xref="士師記 18:27; 約書亞記 19:47; 士師記 15:8"> <span className="pl pl-1">摩西祝福但支派說：</span><br /><span className="pl pl-1">「但像一隻從巴珊躍出的幼獅。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v23" data-v="23" data-xref="創世記 49:21; 詩篇 36:8; 馬太福音 4:16"> <span className="pl pl-1">摩西祝福拿弗他利支派說：</span><br /><span className="pl pl-1">「拿弗他利人啊，</span><br /><span className="pl pl-1">你們飽嘗耶和華的恩寵，</span><br /><span className="pl pl-1">滿得祂的賜福，</span><br /><span className="pl pl-1">擁有西方和南方的土地。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v24" data-v="24" data-xref="創世記 49:20; 約伯記 29:6; 羅馬書 14:18"> <span className="pl pl-1">摩西祝福亞設支派說：</span><br /><span className="pl pl-1">「願亞設在眾子中最蒙福，</span><br /><span className="pl pl-1">受眾弟兄的恩待，</span><br /><span className="pl pl-1">雙腳沐浴橄欖油，</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="以賽亞書 41:10; 詩篇 138:3; 腓立比書 4:13"> <span className="pl pl-1">城門有銅鎖鐵閂，</span><br /><span className="pl pl-1">一生都充滿力量。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v26" data-v="26" data-xref="出埃及記 15:11; 以賽亞書 43:11–13; 耶利米書 10:6"> <span className="pl pl-1">「耶書崙啊，</span><br /><span className="pl pl-1">上帝獨一無二，</span><br /><span className="pl pl-1">祂馳騁諸天，前來助你，</span><br /><span className="pl pl-1">穿越長空，充滿威嚴。</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="詩篇 18:2; 詩篇 90:1–2; 詩篇 46:1"> <span className="pl pl-1">亙古的上帝是你的庇護，</span><br /><span className="pl pl-1">祂永恆的臂膀是你的依託。</span><br /><span className="pl pl-1">祂趕走你面前的仇敵，</span><br /><span className="pl pl-1">下令毀滅他們。</span><br /></span>
<span className="v" id="v28" data-v="28" data-xref="民數記 23:9; 創世記 27:28; 出埃及記 33:16"> <span className="pl pl-1">以色列安然居住，</span><br /><span className="pl pl-1">雅各獨居一處，</span><br /><span className="pl pl-1">那裡盛產五穀新酒，</span><br /><span className="pl pl-1">有天上的雨露滋潤。</span><br /></span>
<span className="v" id="v29" data-v="29" data-xref="以賽亞書 45:17; 以賽亞書 12:2; 詩篇 115:9–11"> <span className="pl pl-1">以色列啊，你多麼有福！</span><br /><span className="pl pl-1">蒙耶和華拯救之人啊，誰能像你？</span><br /><span className="pl pl-1">祂是你的盾牌，你得勝的寶劍。</span><br /><span className="pl pl-1">敵人要向你屈服，被你踐踏。」</span></span>
</div>
</div>

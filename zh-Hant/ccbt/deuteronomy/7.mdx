## 做上帝的子民

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命記 31:3; 使徒行傳 13:19; 申命記 4:38"> 「你們的上帝耶和華帶領你們進入將要佔領的土地時，必從你們面前趕走赫人、革迦撒人、亞摩利人、迦南人、比利洗人、希未人和耶布斯人這七個比你們強大的民族。</span>
<span className="v" id="v2" data-v="2" data-xref="士師記 2:2; 出埃及記 23:32–33; 申命記 20:16–17"> 當你們的上帝耶和華把他們交在你們手裡、使你們打敗他們後，你們必須徹底毀滅他們。不可與他們立約，不可憐憫他們。</span>
<span className="v" id="v3" data-v="3" data-xref="列王紀上 11:2; 約書亞記 23:12–13; 出埃及記 34:15–16"> 不可與他們通婚，不可讓你們的兒女與他們的兒女通婚，</span>
<span className="v" id="v4" data-v="4" data-xref="申命記 6:15; 士師記 2:11; 申命記 4:26"> 因為他們會讓你們的兒女離棄耶和華去拜其他神明，以致耶和華向你們發怒，迅速毀滅你們。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 23:24; 申命記 12:2–3; 出埃及記 34:13"> 你們要這樣對待他們：拆毀他們的祭壇，打碎他們的神柱，砍下他們的亞舍拉神像，焚燒他們的偶像。</span>
<span className="v" id="v6" data-v="6" data-xref="申命記 14:2; 出埃及記 19:5–6; 彼得前書 2:9"> 因為你們是你們的上帝耶和華的聖民，祂從天下萬族中揀選你們做祂寶貴的子民。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="申命記 10:22; 羅馬書 9:11–15; 羅馬書 11:6"> 「耶和華喜愛你們、揀選你們，不是因為你們的人口比別的民族多——其實你們在萬族中是最小的——</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及記 20:2; 出埃及記 32:13; 以弗所書 2:4–5"> 而是因為祂愛你們，遵守祂向你們祖先所起的誓。因此，祂用大能的手把你們從受奴役之地領出來，從埃及王法老手中救贖了你們。</span>
<span className="v" id="v9" data-v="9" data-xref="希伯來書 10:23; 提摩太後書 2:13; 帖撒羅尼迦後書 3:3"> 所以你們要知道，你們的上帝耶和華是上帝，是信實的上帝，祂向愛祂、遵守祂誡命的人守約、施慈愛直到千代。</span>
<span className="v" id="v10" data-v="10" data-xref="以賽亞書 59:18; 那鴻書 1:2; 羅馬書 12:19"> 但祂必毫不遲延地當面報應、毀滅那些恨祂的人。</span>
<span className="v" id="v11" data-v="11" data-xref="約翰福音 14:15; 申命記 4:1; 申命記 5:32"> 所以，你們要謹遵我今天吩咐你們的誡命、律例和典章。</span>
</div>
</div>

## 遵守誡命必蒙福

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="申命記 28:1–14; 申命記 7:9; 利未記 26:3–13"> 「如果你們聽從並謹遵這些典章，你們的上帝耶和華就會信守祂給你們祖先的誓約，以慈愛待你們。</span>
<span className="v" id="v13" data-v="13" data-xref="約翰福音 14:21; 約翰福音 15:10; 申命記 28:3–5"> 祂會愛你們，賜福給你們，使你們在祂向你們祖先起誓要賜給你們的土地上人丁興旺，牛羊成群，收穫豐富的穀物、新酒和油。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及記 23:26–33; 申命記 28:4; 詩篇 127:3"> 天下萬族之中，你們是最蒙福的，你們的男人、女人和牲畜沒有不能生育的。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及記 15:26; 詩篇 105:36–37; 利未記 26:3–4"> 耶和華要使你們免患疾病，免遭你們在埃及所見的惡疾，祂要把那些惡疾降在一切憎惡你們的人身上。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 23:33; 士師記 8:27; 申命記 13:8"> 你們必須滅絕你們的上帝耶和華交在你們手裡的各族，不可憐憫他們，不可供奉他們的神明，因為那樣會使你們陷入網羅。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="民數記 13:32; 民數記 33:53; 申命記 18:21"> 「也許你們心裡會說，『這些民族都比我們強大，我們怎能趕走他們呢？』</span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 105:5; 申命記 31:6; 申命記 1:29"> 不要怕他們，要牢記你們的上帝耶和華曾如何對付法老和整個埃及，</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 4:34; 尼希米記 9:10–11; 耶利米書 32:20–21"> 你們親眼目睹祂如何降下大災難、行神蹟奇事、伸出臂膀和大能的手領你們離開埃及，祂也要這樣對付你們所懼怕的各族。</span>
<span className="v" id="v20" data-v="20" data-xref="約書亞記 24:12; 出埃及記 23:28–30"> 你們的上帝耶和華還要派黃蜂去攻擊他們，直到躲藏起來的殘存者也全部滅亡。</span>
<span className="v" id="v21" data-v="21" data-xref="尼希米記 1:5; 申命記 10:17; 尼希米記 9:32"> 不要懼怕他們，因為你們的上帝耶和華住在你們當中，祂是偉大而可畏的上帝。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及記 23:29–30; 約書亞記 15:63"> 你們的上帝耶和華將在你們前面逐漸趕走那些民族，你們不可急速地滅盡他們，否則你們周圍的野獸會大增，危害你們。</span>
<span className="v" id="v23" data-v="23" data-xref="申命記 8:20; 申命記 2:15; 耶利米書 17:18"> 你們的上帝耶和華要將他們交給你們，使他們驚恐萬狀，直到被滅絕。</span>
<span className="v" id="v24" data-v="24" data-xref="約書亞記 10:8; 約書亞記 23:9; 約書亞記 1:5"> 祂要將他們的王交在你們手中，無人能抵擋你們，你們要毀滅他們，使他們的名字從世上絕跡。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及記 32:20; 歷代志上 14:12; 申命記 17:1"> 你們要燒毀他們的神像，不可貪圖神像上的金銀，不可將那些金銀據為己有，免得你們因此陷入網羅；因為那是你們的上帝耶和華所憎惡的。</span>
<span className="v" id="v26" data-v="26" data-xref="申命記 13:17; 何西阿書 14:8; 以西結書 11:18"> 不可把可憎之物帶到家裡，否則你們會像它們一樣被毀滅。你們要極其憎惡、厭棄它們，因為它們是當毀滅之物。</span>
</div>
</div>

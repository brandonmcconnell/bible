## 最大的誡命

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命記 4:1; 申命記 12:1; 申命記 4:45"> 「你們的上帝耶和華吩咐我教導你們以下的誡命、律例和典章，以便你們在將要佔領的土地上遵行。</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 4:40; 申命記 13:4; 出埃及記 20:20"> 這樣，你們就會得享長壽，你們及子孫就會終生敬畏你們的上帝耶和華，遵守祂藉我吩咐你們的一切律例和誡命。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 22:17; 出埃及記 3:8; 創世記 26:4"> 以色列人啊，你們要留心聽，謹慎遵行，以便你們在那奶蜜之鄉可以凡事順利、人口極其繁盛，正如你們祖先的上帝耶和華給你們的應許。</span>
<span className="v" id="v4" data-v="4" data-xref="馬可福音 12:29–32; 以賽亞書 44:6; 提摩太前書 2:5"> 聽啊，以色列人，耶和華是我們的上帝，耶和華是獨一的。</span>
<span className="v" id="v5" data-v="5" data-xref="馬可福音 12:30; 馬太福音 22:37; 路加福音 10:27"> 你們要全心、全意、全力愛你們的上帝耶和華。</span>
<span className="v" id="v6" data-v="6" data-xref="歌羅西書 3:16; 箴言 7:3; 耶利米書 31:33"> 要將我今天吩咐你們的話牢記在心，</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 11:19; 以弗所書 6:4; 詩篇 78:4–6"> 並教導你們的兒女，無論坐在家裡或行在路上，或起或臥，都要講論這些律例和誡命。</span>
<span className="v" id="v8" data-v="8" data-xref="箴言 6:21; 箴言 3:3; 申命記 11:18"> 要把它們繫在手上、戴在額上作記號，</span>
<span className="v" id="v9" data-v="9" data-xref="申命記 11:20; 以賽亞書 30:8; 以賽亞書 57:8"> 要寫在城門上和自家的門框上。</span>
<span className="v" id="v10" data-v="10" data-xref="約書亞記 24:13; 詩篇 105:44; 尼希米記 9:25"> 「你們的上帝耶和華將帶你們進入祂向你們祖先亞伯拉罕、以撒和雅各起誓要賜給你們的土地。那裡宏偉壯觀的城邑不是你們建造的，</span>
<span className="v" id="v11" data-v="11" data-xref="申命記 7:12–18; 申命記 8:10–20; 以西結書 16:10–20"> 滿屋的美物不是你們積攢的，井不是你們挖掘的，葡萄園和橄欖樹也不是你們栽種的。你們在那裡吃飽喝足之後，</span>
<span className="v" id="v12" data-v="12"> 要小心，不可忘記把你們從受奴役之地埃及救出來的耶和華。</span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 4:8; 申命記 10:20; 馬太福音 4:10"> 要敬畏你們的上帝耶和華，事奉祂，憑祂的名起誓。</span>
<span className="v" id="v14" data-v="14" data-xref="耶利米書 25:6; 約翰一書 5:21; 申命記 13:7"> 不可隨從周圍各族的神明，</span>
<span className="v" id="v15" data-v="15" data-xref="申命記 4:24; 出埃及記 20:5; 申命記 7:4"> 免得你們的上帝耶和華向你們發怒，把你們從世上消滅；因為祂住在你們當中，祂痛恨不貞。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 17:7; 路加福音 4:12; 馬太福音 4:7"> 「不可像在瑪撒那樣試探你們的上帝耶和華。</span>
<span className="v" id="v17" data-v="17" data-xref="申命記 11:22; 詩篇 119:4; 哥林多前書 15:58"> 要謹遵你們的上帝耶和華吩咐你們的誡命、法度和律例。</span>
<span className="v" id="v18" data-v="18" data-xref="申命記 4:40; 申命記 12:25; 羅馬書 12:2"> 你們要做耶和華視為正與善的事，以便凡事順利，得到耶和華起誓要賜給你們祖先的佳美之地，</span>
<span className="v" id="v19" data-v="19" data-xref="民數記 33:52–53; 出埃及記 23:28–30; 士師記 3:1–4"> 從你們面前趕出所有敵人，正如耶和華所言。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及記 13:14; 出埃及記 12:26; 約書亞記 4:6–7"> 「將來你們的子孫會問，『我們的上帝耶和華給你們頒佈這些法度、律例和典章是什麼意思？』</span>
<span className="v" id="v21" data-v="21" data-xref="羅馬書 6:17–18; 以弗所書 2:11–12; 申命記 15:15"> 你們要告訴他們，『我們曾在埃及做法老的奴隸，耶和華用大能的手帶我們出埃及。</span>
<span className="v" id="v22" data-v="22" data-xref="申命記 4:34; 詩篇 58:10–11; 申命記 7:19"> 我們親眼看見耶和華行偉大而可畏的神蹟奇事，懲罰埃及和法老全家。</span>
<span className="v" id="v23" data-v="23" data-xref="申命記 6:18; 申命記 6:10; 出埃及記 13:5"> 祂帶領我們離開埃及，為要把我們帶進祂起誓要賜給我們祖先的這片土地。</span>
<span className="v" id="v24" data-v="24" data-xref="耶利米書 32:39; 詩篇 41:2; 申命記 10:12–13"> 我們的上帝耶和華吩咐我們遵守這一切律例、敬畏祂，以便我們可以終生受益，生命無憂，正如今日的情形。</span>
<span className="v" id="v25" data-v="25" data-xref="申命記 24:13; 羅馬書 10:3; 利未記 18:5"> 我們若按照我們的上帝耶和華的吩咐，在祂面前謹遵這一切誡命，便被算為義人。』</span>

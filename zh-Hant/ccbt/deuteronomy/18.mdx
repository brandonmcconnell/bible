## 利未人的產業

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民數記 18:8–9; 申命記 10:9; 哥林多前書 9:13–14"> 「利未祭司及其他利未支派的人在以色列不可擁有土地。他們吃的是獻給耶和華的火祭，那是他們的產業。</span>
<span className="v" id="v2" data-v="2" data-xref="啟示錄 1:5–6; 詩篇 84:11; 彼得前書 2:5"> 他們在眾支派中沒有自己的產業，因為耶和華是他們的產業，這是祂的應許。</span>
<span className="v" id="v3" data-v="3" data-xref="利未記 7:30–34; 申命記 12:27"> 眾人所獻的牛羊的前腿、腮頰和胃應歸祭司。</span>
<span className="v" id="v4" data-v="4" data-xref="尼希米記 12:44–47; 民數記 18:12–24; 歷代志下 31:4–10"> 你們要給祭司初收的五穀、新酒、新油和初剪的羊毛。</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 10:8; 民數記 3:10; 出埃及記 28:1–14"> 因為你們的上帝耶和華從各支派中揀選了利未人，讓他們世代奉祂的名侍立供職。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="民數記 35:2–3; 申命記 12:5; 申命記 16:2"> 「以色列境內任何地方的利未人若願意離開自己所住的城，一心要去耶和華選定的地方，</span>
<span className="v" id="v7" data-v="7" data-xref="歷代志下 31:2–4"> 他可以像在耶和華面前事奉的其他利未人一樣，在那裡奉他的上帝耶和華之名事奉。</span>
<span className="v" id="v8" data-v="8" data-xref="尼希米記 12:44; 尼希米記 12:47; 歷代志下 31:4"> 除了變賣產業所得之外，他還可以分到與其他祭司同等分量的祭物。</span>
</div>
</div>

## 不可隨從外族風俗

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="申命記 12:29–31; 利未記 18:26–27; 利未記 18:30"> 「你們進入你們的上帝耶和華將要賜給你們的土地後，不可仿效當地民族的可憎行徑。</span>
<span className="v" id="v10" data-v="10" data-xref="利未記 19:31; 出埃及記 22:18; 利未記 19:26"> 你們當中不可有人焚燒自己的子女作祭物，不可有人占卜、算命、作法、行邪術、</span>
<span className="v" id="v11" data-v="11" data-xref="利未記 19:31; 撒母耳記上 28:11–14"> 念咒、做靈媒、行巫術或求問亡靈。</span>
<span className="v" id="v12" data-v="12" data-xref="利未記 18:24; 申命記 9:4; 利未記 18:27"> 凡做這些事的人都是耶和華所憎惡的。正是因為當地的民族做這些可憎之事，你們的上帝耶和華才要當著你們的面把他們趕走。</span>
<span className="v" id="v13" data-v="13" data-xref="馬太福音 5:48; 創世記 17:1; 創世記 6:9"> 你們要在你們的上帝耶和華面前純全無過。</span>
</div>
</div>

## 耶和華使一位先知興起

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="使徒行傳 14:16; 申命記 18:10; 創世記 20:6"> 「你們將要趕走的那些民族聽信術士和巫師，但你們的上帝耶和華不准你們仿效他們。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行傳 3:22–23; 使徒行傳 7:37; 約翰福音 1:45"> 你們的上帝耶和華要在你們中間興起一位像我一樣的先知，你們要聽從他。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 20:19; 申命記 5:23–28; 申命記 9:10"> 這正是你們在何烈山聚會時向你們的上帝耶和華所求的，當時你們說，『不要讓我們再聽見我們上帝耶和華的聲音，也不要讓我們再看見這烈火，免得我們死亡。』</span>
<span className="v" id="v17" data-v="17" data-xref="申命記 5:28"> 於是，耶和華對我說，『他們說的對。</span>
<span className="v" id="v18" data-v="18" data-xref="申命記 18:15; 約翰福音 8:28; 約翰福音 12:49–50"> 我要在他們當中選立一位像你一樣的先知，我會告訴他該說的話，他要把我的一切吩咐告訴他們。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行傳 3:22–23; 希伯來書 2:3; 希伯來書 10:26"> 如果有人不聽從他奉我的名所說的話，我必親自懲罰那人。</span>
<span className="v" id="v20" data-v="20" data-xref="申命記 13:1–5; 耶利米書 27:15; 耶利米書 23:13–15"> 若有先知冒我的名說我未曾吩咐他的話，或以其他神明的名義說話，必須處死他。』</span>
<span className="v" id="v21" data-v="21" data-xref="約翰一書 4:1–3; 帖撒羅尼迦前書 5:24; 啟示錄 2:2"> 你們也許心裡會問，『我們如何知道是否是耶和華說的話呢？』</span>
<span className="v" id="v22" data-v="22" data-xref="申命記 18:20; 列王紀下 20:1; 耶利米書 28:1–17"> 如果先知奉耶和華的名說的話沒有應驗，他的話就不是耶和華說的。他是妄自說預言，你們不用怕他。</span>
</div>
</div>

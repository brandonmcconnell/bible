## 以色列人的悖逆

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命記 11:31; 申命記 4:38; 申命記 1:28"> 「以色列人啊，你們要聽！今天你們要過約旦河，去趕出那些比你們強大的民族。他們住在城牆高聳入雲的大城裡，</span>
<span className="v" id="v2" data-v="2" data-xref="民數記 13:22; 那鴻書 1:6; 申命記 7:24"> 是長得高大威猛的亞衲人。你們瞭解他們，也聽人說過，『誰能抵擋亞衲人呢？』</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 4:24; 希伯來書 12:29; 羅馬書 8:31"> 但今天你們要知道，你們的上帝耶和華要走在你們前面，像烈火一樣吞噬他們。祂要制伏他們，使你們迅速趕走他們，毀滅他們，正如祂對你們的應許。</span>
<span className="v" id="v4" data-v="4" data-xref="申命記 8:17; 申命記 9:5; 申命記 18:9–14"> 「你們的上帝耶和華從你們面前趕走他們以後，你們心裡不要以為耶和華帶領你們佔領那片土地是因為你們公義，其實是因為那裡的民族邪惡，耶和華才將他們從你們面前趕走。</span>
<span className="v" id="v5" data-v="5" data-xref="提多書 3:5; 創世記 17:8; 創世記 26:4"> 你們能佔領他們的土地並非因為你們公義、行為正直。你們的上帝耶和華從你們面前趕走那些民族，是因為他們邪惡，也是為了實現祂給你們祖先亞伯拉罕、以撒和雅各的誓言。</span>
<span className="v" id="v6" data-v="6" data-xref="申命記 10:16; 使徒行傳 7:51; 申命記 31:27"> 你們要知道，耶和華賜給你們那佳美之地不是因為你們公義。其實你們是頑固不化的人。</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及記 16:2; 出埃及記 14:11; 民數記 21:5"> 「要牢記你們在曠野怎樣觸怒你們的上帝耶和華。從你們離開埃及那天來到這裡，你們屢屢背叛耶和華。</span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 106:19–22; 出埃及記 32:16; 出埃及記 32:7–10"> 在何烈山，你們觸怒了耶和華，以致祂要毀滅你們。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及記 34:28; 出埃及記 24:18; 列王紀上 19:8"> 那時，我上山去接受耶和華與你們立約的石版，在山上待了四十晝夜，沒吃也沒喝。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及記 31:18; 希伯來書 8:10; 申命記 10:4"> 耶和華把兩塊立約的石版交給我，上面刻著那天你們聚會時祂在山上的火焰中對你們說的話，是祂用手指刻上去的。</span>
<span className="v" id="v11" data-v="11" data-xref="申命記 9:9; 民數記 10:33; 希伯來書 8:6–10"> 四十晝夜後，耶和華把那兩塊刻著約的石版交給我，</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及記 32:7–8; 申命記 31:29; 士師記 2:17"> 對我說，『快下山吧，因為你從埃及領出來的百姓已經敗壞了。他們這麼快就偏離了我吩咐他們走的道，為自己鑄造了神像。』</span>
<span className="v" id="v13" data-v="13" data-xref="申命記 9:6; 列王紀下 17:14; 申命記 10:16"> 「耶和華又對我說，『我已看出，這是頑固不化的百姓。</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 29:20; 出埃及記 32:10–13; 詩篇 9:5"> 不要攔我，我要毀滅他們，從世上抹去他們的名字。我要使你成為一個比他們更強大的民族。』</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及記 19:18; 申命記 5:23; 申命記 4:11"> 我雙手拿著那兩塊約版，轉身從烈火熊熊的山上下來，</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 32:19; 使徒行傳 7:40–41"> 看見你們為自己鑄造了牛犢像，得罪了你們的上帝耶和華，這麼快就偏離了耶和華吩咐你們走的道，</span>
<span className="v" id="v17" data-v="17"> 就當著你們的面摔碎了那兩塊石版。</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及記 34:28; 申命記 9:9; 詩篇 106:23"> 「我又俯伏在耶和華面前，四十晝夜不吃不喝，因為你們犯了大罪，做耶和華憎惡的事，惹祂發怒。</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 10:10; 出埃及記 32:14; 雅各書 5:16–17"> 耶和華向你們發烈怒，要毀滅你們，我非常懼怕。但耶和華再次垂聽了我的祈求。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及記 32:35; 出埃及記 32:21; 希伯來書 7:26–28"> 耶和華對亞倫非常憤怒，以致要殺掉他，於是我也為他祈求。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及記 32:20; 以賽亞書 31:7; 以賽亞書 2:18–21"> 我焚燒了你們鑄造的罪惡之物牛犢像，把它打碎、磨成粉末，撒在從山上流下來的溪水中。</span>
<span className="v" id="v22" data-v="22" data-xref="民數記 11:34; 出埃及記 17:7; 民數記 11:1–5"> 「你們在他備拉、瑪撒和基博羅·哈他瓦三番四次地觸怒耶和華。</span>
<span className="v" id="v23" data-v="23" data-xref="詩篇 106:24–25; 希伯來書 4:2; 詩篇 78:22"> 你們的上帝耶和華吩咐你們離開加低斯·巴尼亞，去佔領祂賜給你們的土地，你們卻違背祂的命令，不信靠祂，也不聽從祂。</span>
<span className="v" id="v24" data-v="24" data-xref="申命記 31:27; 使徒行傳 7:51; 申命記 9:6–7"> 自從我認識你們以來，你們就不斷地背叛耶和華。</span>
<span className="v" id="v25" data-v="25" data-xref="申命記 9:18; 申命記 9:16"> 「因為耶和華說要毀滅你們，我就俯伏在耶和華面前四十晝夜，</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及記 32:11–13; 提多書 2:14; 詩篇 107:2"> 向祂祈求說，『主耶和華啊，求你不要毀滅你的子民！他們是你的產業，是你用大能的手從埃及救贖並帶出來的。</span>
<span className="v" id="v27" data-v="27" data-xref="耶利米書 14:21; 彌迦書 7:18–19; 撒母耳記上 25:25"> 求你看在你僕人亞伯拉罕、以撒和雅各的份上，不要計較這個民族的頑固、邪惡和罪過，</span>
<span className="v" id="v28" data-v="28" data-xref="民數記 14:16; 出埃及記 32:12"> 免得你帶領我們離開之地的人說，你不能把他們領到你應許給他們的地方，你憎惡他們，所以把他們帶到曠野殺了。</span>
<span className="v" id="v29" data-v="29" data-xref="尼希米記 1:10; 列王紀上 8:51; 申命記 9:26"> 他們畢竟是你的子民，你的產業，是你伸出大能的臂膀從埃及帶出來的。』</span>

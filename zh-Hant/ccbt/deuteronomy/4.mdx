## 當守律法

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="羅馬書 10:5; 以西結書 20:11; 利未記 18:5"> 「以色列人啊，要聆聽我傳授給你們的律例和典章，要切實遵行，以便你們可以存活，並進去佔據你們祖先的上帝耶和華賜給你們的那片土地。</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 12:32; 箴言 30:6; 啟示錄 22:18–19"> 我吩咐你們的，你們不可做任何增減，你們要遵守你們的上帝耶和華的命令。</span>
<span className="v" id="v3" data-v="3" data-xref="民數記 25:1–9; 詩篇 106:28–29; 約書亞記 22:17"> 你們親眼看見耶和華在巴力·毗珥事件中的作為，你們的上帝耶和華毀滅了你們中間所有拜巴力·毗珥的人，</span>
<span className="v" id="v4" data-v="4" data-xref="申命記 10:20; 約書亞記 23:8; 約翰福音 6:67–69"> 但你們這些信靠你們的上帝耶和華的人至今都還活著。</span>
<span className="v" id="v5" data-v="5" data-xref="馬太福音 28:20; 帖撒羅尼迦前書 4:1–2; 希伯來書 3:5"> 看啊，遵照我的上帝耶和華的吩咐，我把律例和典章傳授給你們，好讓你們在將要進去佔領的土地上遵守。</span>
<span className="v" id="v6" data-v="6" data-xref="約伯記 28:28; 詩篇 111:10; 提摩太後書 3:15"> 你們要謹遵這些律例和典章，因為這樣就會讓外族人看見你們的智慧和聰明。他們聽見這些律例後，必說，『這偉大的民族真有智慧和聰明！』</span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 145:18; 撒母耳記下 7:23; 詩篇 34:18"> 我們的上帝耶和華與我們如此親近，隨時垂聽我們的呼求，有哪個偉大民族的神明能與之相比？</span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 147:19–20; 羅馬書 7:12–14; 詩篇 119:127–128"> 有哪個偉大的民族擁有我今天所傳授給你們的如此公義的律例和典章？</span>
<span className="v" id="v9" data-v="9" data-xref="申命記 6:7; 申命記 11:19; 詩篇 78:3–8"> 「要謹慎、小心，不可忘記親眼所見的事，要一生銘記在心，並且告訴子子孫孫。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及記 19:9; 希伯來書 12:18–19; 出埃及記 19:16"> 那天，你們在何烈山站在你們的上帝耶和華面前，耶和華對我說，『把民眾招聚起來，讓他們聽我的教誨，學習一生敬畏我，並傳授給自己的兒女。』</span>
<span className="v" id="v11" data-v="11" data-xref="申命記 5:23; 出埃及記 19:16–18; 希伯來書 12:18–19"> 你們來到山腳下，站在那裡，山上烈焰沖天、烏雲密佈、極其幽暗。</span>
<span className="v" id="v12" data-v="12" data-xref="申命記 4:15; 申命記 5:4; 申命記 5:22"> 耶和華在火焰中對你們說話，你們只聽見祂的聲音，卻看不見祂的形像。</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及記 34:28; 出埃及記 31:18; 申命記 9:9–11"> 祂向你們宣告祂的約，就是祂吩咐你們遵守的十誡，並寫在兩塊石版上。</span>
<span className="v" id="v14" data-v="14" data-xref="詩篇 105:44–45; 以西結書 21:1–23"> 那時，耶和華吩咐我把律例和典章傳授給你們，好讓你們在將要佔領的土地上遵守。</span>
</div>
</div>

## 不可拜偶像

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="申命記 4:12; 以賽亞書 40:18; 哥林多後書 4:4–6"> 「你們要格外小心，耶和華在何烈山的火焰中對你們說話時，你們沒有看見任何形像，</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行傳 17:29; 申命記 5:8; 出埃及記 20:4–5"> 所以不可墮落，去為自己製造任何形狀的神像——男人、女人、</span>
<span className="v" id="v17" data-v="17" data-xref="羅馬書 1:23"> 飛禽走獸、</span>
<span className="v" id="v18" data-v="18"> 爬蟲或魚類的像。</span>
<span className="v" id="v19" data-v="19" data-xref="羅馬書 1:25; 申命記 17:3; 列王紀下 21:3"> 當你們舉目觀看你們的上帝耶和華賜給天下萬民的日、月、星辰等天上萬象時，不要受誘惑去跪拜、供奉它們。</span>
<span className="v" id="v20" data-v="20" data-xref="列王紀上 8:51; 耶利米書 11:4; 出埃及記 19:5–6"> 耶和華拯救你們脫離埃及那座鐵熔爐，讓你們做祂自己的子民，正如今日的情形。</span>
<span className="v" id="v21" data-v="21" data-xref="申命記 1:37; 民數記 20:12; 詩篇 106:32–33"> 因你們的緣故，耶和華向我發怒，起誓不讓我過約旦河、進入祂賜給你們作產業的那片佳美之地。</span>
<span className="v" id="v22" data-v="22" data-xref="申命記 3:25; 申命記 3:27; 彼得後書 1:13–15"> 我將死在約旦河這邊，過不了約旦河。但你們必過去得到那片佳美之地。</span>
<span className="v" id="v23" data-v="23" data-xref="申命記 4:9; 希伯來書 3:12; 約書亞記 23:16"> 你們要謹慎，不可忘記你們的上帝耶和華與你們所立的約，不可違背你們上帝耶和華的禁令，去製造任何形狀的神像。</span>
<span className="v" id="v24" data-v="24" data-xref="希伯來書 12:29; 那鴻書 1:6; 申命記 9:3"> 因為你們的上帝耶和華是烈火，是痛恨不貞的上帝。</span>
<span className="v" id="v25" data-v="25" data-xref="申命記 4:16; 何西阿書 9:9; 哥林多前書 10:22"> 「將來，即使你們在那裡安頓已久、子孫滿堂，也不可墮落、製造任何形狀的神像，不可做你們的上帝耶和華視為邪惡的事，惹祂發怒。</span>
<span className="v" id="v26" data-v="26" data-xref="申命記 32:1; 彌迦書 6:2; 耶利米書 22:29"> 否則，今天我叫天地作證，你們必很快從約旦河對面將要佔領的土地上滅亡，你們必被徹底消滅，不得在那裡長久居住。</span>
<span className="v" id="v27" data-v="27" data-xref="申命記 28:62–64; 利未記 26:33; 以西結書 12:15"> 耶和華必把你們驅散到列邦，使你們在列邦中的人數所剩無幾。</span>
<span className="v" id="v28" data-v="28" data-xref="申命記 28:64; 耶利米書 16:13; 申命記 28:36"> 你們必在那裡供奉人用木石造的不會看、不會聽、不會吃、不會聞的神像。</span>
<span className="v" id="v29" data-v="29" data-xref="詩篇 119:2; 耶利米書 29:12–14; 歷代志下 15:4"> 但你們若在那裡尋求你們的上帝耶和華，全心全意地尋求祂，就必尋見。</span>
<span className="v" id="v30" data-v="30" data-xref="約珥書 2:12–13; 耶利米書 23:20; 何西阿書 3:5"> 日後，當你們遭遇這些事，受盡苦難的時候，必歸向你們的上帝耶和華，聽從祂。</span>
<span className="v" id="v31" data-v="31" data-xref="申命記 31:8; 詩篇 116:5; 尼希米記 9:31"> 因為你們的上帝耶和華充滿憐憫，祂不會拋棄你們，滅絕你們，也不會忘記祂與你們祖先所立的誓約。</span>
</div>
</div>

## 獨一的上帝

<div className="bt">
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="約伯記 8:8; 馬太福音 24:31; 詩篇 44:1"> 「你們可以查考歷史，自上帝在世上造人以來，這樣的奇事，天地之間何曾有過？誰曾聽聞？</span>
<span className="v" id="v33" data-v="33" data-xref="士師記 6:22; 申命記 5:24; 出埃及記 33:20"> 有哪個民族像你們一樣，聽見了上帝在火中說話，還活了下來？</span>
<span className="v" id="v34" data-v="34" data-xref="申命記 26:8; 申命記 5:15; 出埃及記 6:6"> 有哪個神明像你們的上帝耶和華那樣在埃及當著你們的面降災禍、行神蹟奇事、發起戰爭、伸出臂膀、施展大能的手、以偉大而可畏的作為拯救一族脫離異邦？</span>
<span className="v" id="v35" data-v="35" data-xref="以賽亞書 45:18; 撒母耳記上 2:2; 以賽亞書 45:5"> 耶和華行這樣的事，是要叫你們知道祂是上帝，除祂以外，別無他神。</span>
<span className="v" id="v36" data-v="36" data-xref="出埃及記 19:9; 出埃及記 19:19; 申命記 4:33"> 祂讓你們聽見祂從天上來的聲音，好教導你們，又在地上讓你們看見祂的烈火，並聽見祂在烈火中說的話。</span>
<span className="v" id="v37" data-v="37" data-xref="申命記 10:15; 以賽亞書 63:9; 出埃及記 13:9"> 因為祂愛你們的祖先，所以揀選他們的子孫，親自用大能帶你們出埃及，</span>
<span className="v" id="v38" data-v="38" data-xref="申命記 7:1; 申命記 9:1–5; 出埃及記 23:27–28"> 趕走比你們強大的民族，領你們進入他們的土地，把他們的土地賜給你們作產業，正如今日的情形。</span>
<span className="v" id="v39" data-v="39" data-xref="約書亞記 2:11; 申命記 4:35; 歷代志上 29:11"> 所以，今天你們要知道並謹記，耶和華是天上地下的上帝，此外別無他神。</span>
<span className="v" id="v40" data-v="40" data-xref="申命記 6:3; 以弗所書 6:3; 申命記 12:28"> 我今天將祂的律例和誡命傳授給你們，你們要遵守，以便你們及子孫都蒙福，在你們上帝耶和華所賜的土地上得享長壽。」</span>
</div>
</div>

## 設立避難城

<div className="bt">
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="民數記 35:6; 民數記 35:14–15; 約書亞記 20:2–9"> 那時，摩西在約旦河東劃出三座城作避難城，</span>
<span className="v" id="v42" data-v="42" data-xref="希伯來書 6:18; 申命記 19:1–10; 民數記 35:15–28"> 供素無冤仇卻誤殺他人者逃往避難。</span>
<span className="v" id="v43" data-v="43" data-xref="約書亞記 20:8; 列王紀上 4:13; 約書亞記 21:27"> 三座城分別是供呂便人避難的比悉，在曠野高原；供迦得人避難的拉末，在基列；供瑪拿西人避難的哥蘭，在巴珊。</span>
</div>

## 重申律法

<div className="bt">
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="申命記 27:3; 利未記 27:34; 瑪拉基書 4:4"> 以下是摩西頒佈給以色列人的律法，</span>
<span className="v" id="v45" data-v="45" data-xref="列王紀上 2:3; 申命記 4:1; 詩篇 119:7"> 即在離開埃及後傳授給他們的法度、律例和典章。</span>
<span className="v" id="v46" data-v="46" data-xref="申命記 3:29; 申命記 4:47; 申命記 1:4–5"> 當時他們在約旦河以東伯·毗珥對面的山谷，那裡原屬於希實本的亞摩利王西宏。摩西領以色列人離開埃及後消滅了西宏，</span>
<span className="v" id="v47" data-v="47" data-xref="申命記 3:1–14; 民數記 21:33–35; 申命記 29:7–8"> 佔領了他的土地，還佔領了巴珊王噩的土地。西宏和噩是約旦河東亞摩利人的兩個王，</span>
<span className="v" id="v48" data-v="48" data-xref="申命記 3:9; 申命記 2:36; 申命記 3:12"> 其國土從亞嫩谷邊的亞羅珥一直到西雲山，即黑門山，</span>
<span className="v" id="v49" data-v="49" data-xref="申命記 3:17; 約書亞記 13:20; 申命記 34:1"> 包括約旦河東的整個亞拉巴，遠至毗斯迦山腳的亞拉巴海。</span>
</div>
</div>

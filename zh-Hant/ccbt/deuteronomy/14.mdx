## 做聖潔的子民

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="利未記 21:5; 羅馬書 9:8; 加拉太書 3:26"> 「你們是你們上帝耶和華的兒女，不可為死人割傷自己或剃光前額。</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 7:6; 利未記 20:26; 出埃及記 19:5–6"> 因為你們是你們的上帝耶和華的聖民，祂從天下萬族中揀選你們作祂寶貴的產業。</span>
<span className="v" id="v3" data-v="3" data-xref="以西結書 4:14; 羅馬書 14:14; 利未記 20:25"> 「你們不可吃任何可憎之物。</span>
<span className="v" id="v4" data-v="4" data-xref="利未記 11:2–45; 使徒行傳 10:14; 列王紀上 4:23"> 但你們可以吃牛、綿羊、山羊、</span>
<span className="v" id="v5" data-v="5"> 鹿、羚羊、麅子、野山羊、瞪羚、黃羊和野綿羊。</span>
<span className="v" id="v6" data-v="6" data-xref="箴言 18:1; 哥林多後書 6:17; 詩篇 1:1–2"> 凡蹄子分瓣且反芻的動物，你們都可以吃。</span>
<span className="v" id="v7" data-v="7" data-xref="馬太福音 7:22–23; 提多書 1:16; 提摩太後書 3:5"> 在那些只反芻或只是蹄子分瓣的動物中，你們不可吃駱駝、野兔和石獾，因為牠們雖反芻但蹄子不分瓣，是不潔淨的。</span>
<span className="v" id="v8" data-v="8" data-xref="利未記 11:26–27; 以賽亞書 66:3; 彼得後書 2:22"> 你們也不可吃豬，因為豬雖蹄子分瓣但不反芻，是不潔淨的。你們不可吃這些動物的肉，也不可摸牠們的屍體。</span>
<span className="v" id="v9" data-v="9" data-xref="利未記 11:9–12"> 「水族中，凡有鰭有鱗的，你們都可以吃。</span>
<span className="v" id="v10" data-v="10"> 凡無鰭無鱗的都不潔淨，你們不可吃。</span>
<span className="v" id="v11" data-v="11"> 「你們可以吃潔淨的鳥類。</span>
<span className="v" id="v12" data-v="12" data-xref="利未記 11:13–19"> 不可吃的鳥類有鵰、胡兀鷲、黑禿鷲、</span>
<span className="v" id="v13" data-v="13"> 鳶、隼類、</span>
<span className="v" id="v14" data-v="14"> 烏鴉類、</span>
<span className="v" id="v15" data-v="15" data-xref="約伯記 30:29"> 鴕鳥、夜鷹、海鷗、鷹類、</span>
<span className="v" id="v16" data-v="16"> 小鴞、大鴞、倉鴞、</span>
<span className="v" id="v17" data-v="17"> 鵜鶘、魚鷹、鸕鷀、</span>
<span className="v" id="v18" data-v="18"> 鸛、鷺鳥類、戴鵀和蝙蝠。</span>
<span className="v" id="v19" data-v="19" data-xref="腓立比書 3:19; 利未記 11:20–23"> 「凡有翅膀、會爬的昆蟲都不潔淨，你們不可吃。</span>
<span className="v" id="v20" data-v="20"> 凡有翅膀的潔淨之物，你們都可以吃。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及記 23:19; 出埃及記 34:26; 利未記 22:8"> 「你們不可吃死掉的動物，但可以送給住在你們城裡的外族人吃，或賣給其他外族人。因為你們是你們的上帝耶和華的聖民。你們不可用母山羊的奶煮牠的羊羔。</span>
</div>
</div>

## 十一奉獻

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="尼希米記 10:37; 申命記 12:17; 申命記 26:12–15"> 「你們每年要獻出收成的十分之一；</span>
<span className="v" id="v23" data-v="23" data-xref="申命記 12:5–7; 申命記 4:10; 申命記 12:17–18"> 要在你們的上帝耶和華選定的敬拜場所，在祂面前吃所獻的十分之一的穀物、新酒、油以及頭生的牛羊。這是為了讓你們學習一生敬畏你們的上帝耶和華。</span>
<span className="v" id="v24" data-v="24" data-xref="申命記 12:21; 申命記 12:5; 申命記 11:24"> 如果你們的上帝耶和華賜福你們，使你們豐收，而你們住的地方離祂選定的敬拜場所太遠，以致不能把收成的十分之一送去，</span>
<span className="v" id="v25" data-v="25"> 就可以把那些收成換成銀錢，帶到你們的上帝耶和華選定的場所。</span>
<span className="v" id="v26" data-v="26" data-xref="傳道書 9:7; 申命記 12:7; 馬太福音 21:12"> 在那裡，你們可以隨意買牛、羊、淡酒或烈酒，然後一家人在你們的上帝耶和華面前吃喝快樂。</span>
<span className="v" id="v27" data-v="27" data-xref="民數記 18:20; 申命記 14:29; 申命記 12:12"> 不可忘記住在你們城裡的利未人，因為利未人沒有分到土地作產業。</span>
<span className="v" id="v28" data-v="28" data-xref="申命記 14:22; 阿摩司書 4:4; 申命記 26:12–15"> 「每逢第三年末，你們要把那年所有出產的十分之一拿出來，存放在你們的城裡，</span>
<span className="v" id="v29" data-v="29" data-xref="申命記 15:10; 申命記 14:27; 箴言 19:17"> 讓你們城中沒有土地的利未人、寄居者和孤兒寡婦都可以來吃飽。這樣，你們的上帝耶和華必使你們凡事蒙福。</span>
</div>
</div>

## 設立避難城

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命記 12:29; 申命記 6:10; 申命記 7:1–2"> 「你們的上帝耶和華毀滅那些民族，把他們的土地賜給你們，使你們趕走他們，住進他們的城邑和房屋後，</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 21:13; 約書亞記 20:2–7; 申命記 4:41–43"> 你們要把你們的上帝耶和華賜給你們的土地劃分為三個地區，在每個地區設立一座避難城，修好通往這三座城的道路，以便誤殺人者可以逃往最近的避難城。</span>
<span className="v" id="v4" data-v="4" data-xref="民數記 35:15–24; 申命記 4:42; 以賽亞書 30:33"> 「如果有人無意間殺了素無冤仇的同伴，他可以逃往避難城，以保住性命。</span>
<span className="v" id="v5" data-v="5" data-xref="民數記 35:25; 箴言 27:12; 列王紀下 6:5–7"> 例如，有人和朋友去森林砍樹，砍伐時斧頭脫柄，誤殺了朋友，他就可以逃往其中一座避難城，以保住性命。</span>
<span className="v" id="v6" data-v="6" data-xref="民數記 35:12; 撒母耳記下 14:7; 申命記 21:22"> 否則，如果避難城離誤殺人者太遠，怒火中燒的報血仇者就會追上去殺死他。其實他是不該死的，因為他與被誤殺的人素無冤仇。</span>
<span className="v" id="v7" data-v="7"> 因此，我吩咐你們要設立三座避難城。</span>
<span className="v" id="v8" data-v="8" data-xref="申命記 12:20; 出埃及記 34:24; 出埃及記 23:31"> 「如果你們謹遵我今天吩咐你們的這一切誡命，愛你們的上帝耶和華，一生遵行祂的旨意，祂就會按照祂對你們祖先所起的誓，擴張你們的疆域，把應許給你們祖先的土地都賜給你們。那時，你們要再設三座避難城，</span>
<span className="v" id="v10" data-v="10" data-xref="以賽亞書 59:7; 箴言 6:17; 馬太福音 27:4–5"> 免得無辜人的血流在你們的上帝耶和華賜給你們作產業之地，以致你們擔當枉殺無辜的罪。</span>
<span className="v" id="v11" data-v="11" data-xref="民數記 35:16–21; 申命記 27:24; 創世記 9:6"> 「如果有人因憎恨鄰居而暗中埋伏，攻擊並殺了鄰居，然後逃到其中一座避難城，</span>
<span className="v" id="v12" data-v="12" data-xref="列王紀上 2:28–34; 列王紀上 2:5–6"> 他本城的長老要派人去把他帶回來，交給報血仇的人，將他處死。</span>
<span className="v" id="v13" data-v="13" data-xref="列王紀上 2:31; 申命記 21:9; 申命記 7:16"> 不可憐憫他，要從以色列除掉這種濫殺無辜的罪，這樣你們才會順利。</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 27:17; 箴言 22:28; 箴言 23:10"> 「在你們的上帝耶和華將要賜給你們作產業之地，你們不可挪動鄰居的界石，因為那是先人立的。</span>
<span className="v" id="v15" data-v="15" data-xref="民數記 35:30; 申命記 17:6; 哥林多後書 13:1"> 「無論是什麼罪或過失，不可憑一個證人就定人的罪，必須有兩三個證人作證才能定案。</span>
<span className="v" id="v16" data-v="16" data-xref="詩篇 27:12; 詩篇 35:11; 出埃及記 23:1–7"> 如果有人作偽證誣陷別人，</span>
<span className="v" id="v17" data-v="17" data-xref="申命記 17:9; 申命記 21:5; 瑪拉基書 2:7"> 訴訟雙方要站在耶和華面前，讓當值的祭司和審判官定奪。</span>
<span className="v" id="v18" data-v="18" data-xref="申命記 13:14; 申命記 17:4; 歷代志下 19:6–7"> 審判官要仔細審查案件，如果發現那人作偽證誣陷同胞，</span>
<span className="v" id="v19" data-v="19" data-xref="箴言 19:5; 箴言 19:9; 但以理書 6:24"> 就要按照他企圖加給被誣告者的傷害處罰他。這樣，就從你們當中除掉了罪惡。</span>
<span className="v" id="v20" data-v="20" data-xref="申命記 21:21; 申命記 17:13; 申命記 13:11"> 其他人聽說後，都會害怕，不敢再做這種惡事。</span>
<span className="v" id="v21" data-v="21" data-xref="馬太福音 5:38–39; 出埃及記 21:23–25; 申命記 19:13"> 你們對惡人不可心軟，要以命償命，以眼還眼，以牙還牙，以手還手，以腳還腳。</span>

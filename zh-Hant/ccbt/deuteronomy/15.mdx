## 安息年

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命記 31:10; 出埃及記 23:10–11; 利未記 25:2–4"> 「每逢第七年末，你們要免除他人的債務。</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 7:42; 雅各書 2:13; 路加福音 6:34–38"> 你們要這樣做，所有債主都要免除同胞所欠的債務，不可向他們追討，因為宣佈免除債務的是耶和華。</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 23:20; 馬太福音 17:25–26; 哥林多前書 6:6–7"> 你們可以向外族人討債，但無論同胞欠你什麼債務，都要免除。</span>
<span className="v" id="v4" data-v="4" data-xref="以賽亞書 58:10–11; 箴言 28:27; 箴言 11:24–25"> 只要你們留心聽從你們上帝耶和華的話，謹遵我今天吩咐你們的誡命，祂必使你們在祂賜給你們作產業的土地上蒙福，你們中間不會有窮人。</span>
<span className="v" id="v6" data-v="6" data-xref="申命記 28:12–13; 路加福音 6:35; 尼希米記 9:27"> 你們的上帝耶和華必照祂的應許賜福給你們，你們必借貸給多國，卻不需要向他們借貸。你們必統治多國，卻不被他們統治。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="約翰一書 3:16–17; 申命記 15:9; 箴言 21:13"> 「在進入你們的上帝耶和華將要賜給你們的土地後，如果你們居住的城中有貧窮的同胞，你們不可硬著心腸拒施援手。</span>
<span className="v" id="v8" data-v="8" data-xref="路加福音 6:34; 馬太福音 5:42"> 你們要伸出援手，按他們的所需慷慨地借給他們。</span>
<span className="v" id="v9" data-v="9" data-xref="申命記 24:15; 馬太福音 20:15; 耶利米書 17:10"> 你們要謹慎，不可因為免除債務的第七年將近，就心懷惡念，對貧窮同胞冷眼相待，拒施援手。否則，他們會向耶和華控訴你們，那時你們便有罪了。</span>
<span className="v" id="v10" data-v="10" data-xref="箴言 22:9; 希伯來書 13:16; 以賽亞書 58:10"> 你們要慷慨給予，並且無怨無悔，因為你們的上帝耶和華必在你們所做的一切事上賜福給你們。</span>
<span className="v" id="v11" data-v="11" data-xref="馬可福音 14:7; 馬太福音 26:11; 約翰福音 12:8"> 你們居住的地方總會有窮人，所以我吩咐你們要慷慨地幫助貧窮和有需要的同胞。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="耶利米書 34:14; 利未記 25:39–41; 出埃及記 21:2–6"> 「如果你們的希伯來同胞，不論男女，賣身給你們為奴，他們要服侍你們六年，到第七年，你們要給他們自由。</span>
<span className="v" id="v13" data-v="13" data-xref="瑪拉基書 3:5; 耶利米書 22:13; 箴言 3:27–28"> 你們釋放他們時，不可讓他們空手離去，</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多前書 16:2; 箴言 10:22; 詩篇 68:10"> 要慷慨地把你們的上帝耶和華賜給你們的羊、五穀和酒分給他們。</span>
<span className="v" id="v15" data-v="15" data-xref="申命記 16:12; 馬太福音 18:32–33; 申命記 5:14–15"> 要記住，你們曾在埃及做奴隸，你們的上帝耶和華救贖了你們。所以，我今天吩咐你們這樣做。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 21:5–6; 詩篇 40:8; 詩篇 40:6"> 如果你們的奴僕因為愛你們和你們的家人，與你們相處融洽，不願意離去，</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳記上 1:22; 利未記 25:39–42"> 你們就要讓他靠在門上，用錐子在他耳朵上扎個洞，他便終身成為你們的奴僕。對待婢女也要這樣。</span>
<span className="v" id="v18" data-v="18" data-xref="路加福音 17:7–8; 以賽亞書 16:14; 以賽亞書 21:16"> 你們釋放奴僕時，不要不情願，因為他們服侍你們六年，所做的是普通雇工的兩倍。而且，你們的上帝耶和華也會在你們所做的一切事上賜福給你們。</span>
</div>
</div>

## 頭生的牛羊

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="出埃及記 13:2; 出埃及記 13:12; 利未記 27:26"> 「你們要把頭生的公牛和公羊分別出來，獻給你們的上帝耶和華。不可用頭生的公牛耕田，也不要剪頭生公羊的毛。</span>
<span className="v" id="v20" data-v="20" data-xref="申命記 12:17; 申命記 14:23; 申命記 12:5–7"> 每年，你們全家要去你們的上帝耶和華選定的地方，在祂面前吃這些頭生的牛羊。</span>
<span className="v" id="v21" data-v="21" data-xref="申命記 17:1; 瑪拉基書 1:7–8; 利未記 22:19–25"> 如果這些牛羊有什麼殘疾，如瘸腿、瞎眼或其他缺陷，就不可獻給你們的上帝耶和華。</span>
<span className="v" id="v22" data-v="22" data-xref="申命記 12:21–22; 申命記 12:15–16"> 要在你們的城裡吃這些牛羊。潔淨的人和不潔淨的人都可以吃，就像吃羚羊和鹿一樣。</span>
<span className="v" id="v23" data-v="23" data-xref="申命記 12:16; 利未記 7:26; 申命記 12:23"> 但不可吃牠們的血，要把血倒在地上，像倒水一樣。</span>
</div>
</div>

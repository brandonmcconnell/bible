## 逾越節

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及記 34:18; 出埃及記 12:2–20; 出埃及記 13:4"> 「你們要在亞筆月<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="亞筆月是猶太曆的第一個月，約在陽曆三月中旬到四月中旬，相當於中國的春分時節。">a</a></sup>為你們的上帝耶和華守逾越節，因為祂在這個月的一個晚上帶你們出了埃及。</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 12:5; 申命記 12:26; 路加福音 22:15"> 你們要在你們的上帝耶和華為祂的名選定的居所，把牛羊作為逾越節的祭牲獻給祂。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 12:39; 出埃及記 34:18; 出埃及記 12:19–20"> 吃祭牲的時候，不可吃有酵的餅，七天之內要吃無酵餅，即憶苦餅，以便你們一生謹記離開埃及的日子，因為當時你們離開得很倉促。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及記 34:25; 出埃及記 12:10; 出埃及記 13:7"> 那七天之內，你們境內不可有酵母。第一天傍晚獻的祭肉不可留到早晨。</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 16:2; 申命記 12:5–6"> 在你們的上帝耶和華將要賜給你們的各城中，你們不可獻逾越節的祭牲，</span>
<span className="v" id="v6" data-v="6" data-xref="申命記 12:5; 出埃及記 12:6–9; 民數記 9:11"> 而是要在傍晚日落時分，即你們離開埃及的時候，到你們的上帝耶和華為祂的名選定的居所獻逾越節的祭牲。</span>
<span className="v" id="v7" data-v="7" data-xref="歷代志下 35:13; 出埃及記 12:8–9; 約翰福音 2:23"> 你們要在那裡煮祭肉吃，第二天早晨可以返回自己的帳篷。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及記 13:6–8; 利未記 23:6–8; 利未記 23:36"> 在隨後的六天之內，你們要吃無酵餅。第七天，要舉行莊嚴的聚會，敬拜你們的上帝耶和華。那一天你們不可做工。</span>
</div>
</div>

## 七七收穫節

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="出埃及記 34:22; 出埃及記 23:16; 使徒行傳 2:1"> 「從收割那天開始算起，你們要算出七週的時間。</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多前書 16:2; 利未記 12:8; 瑪拉基書 3:10–11"> 七週後，要為你們的上帝耶和華守七七收穫節<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="「七七收穫節」後稱為五旬節。">b</a></sup>。那時，你們要按照你們的上帝耶和華所賜的福分，甘心樂意地獻上祭物。</span>
<span className="v" id="v11" data-v="11" data-xref="申命記 12:7; 申命記 12:12; 申命記 12:18"> 你們要和兒女、僕婢、同城的利未人、寄居者及孤兒寡婦，在你們的上帝耶和華為祂的名選定的居所，在祂面前一起歡喜快樂。</span>
<span className="v" id="v12" data-v="12" data-xref="申命記 15:15; 耶利米哀歌 3:19–20; 羅馬書 6:17–18"> 你們要記住自己曾在埃及做過奴隸，因此要謹遵這些律例。</span>
</div>
</div>

## 住棚節

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="出埃及記 23:16; 約翰福音 7:2; 歷代志下 5:3"> 「在收藏好穀物和新酒後，你們要守七天的住棚節。</span>
<span className="v" id="v14" data-v="14" data-xref="尼希米記 8:9–12; 申命記 16:11; 以賽亞書 30:29"> 住棚節期間，你們要和兒女、僕婢、同城的利未人、寄居者及孤兒寡婦一起歡慶。</span>
<span className="v" id="v15" data-v="15" data-xref="利未記 23:36–42; 申命記 30:16; 申命記 16:10"> 要在你們的上帝耶和華選定的地方，為祂守住棚節七天；要滿心歡喜，因為你們的上帝耶和華賜福你們，使你們的出產豐富、凡事順利。</span>
<span className="v" id="v16" data-v="16" data-xref="箴言 3:9–10; 詩篇 96:8; 哈該書 1:9"> 「你們所有男子要每年三次，即在除酵節、七七收穫節和住棚節，在你們的上帝耶和華指定的地方朝見祂。你們不可空手朝見耶和華，</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多後書 9:6–7; 哥林多後書 8:12; 申命記 16:10"> 各人要按祂賜的福分，盡自己的能力獻上禮物。</span>
</div>
</div>

## 委任審判官

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="歷代志上 23:4; 出埃及記 18:25–26; 羅馬書 13:1–6"> 「要在你們的上帝耶和華將要賜給你們的各城中，按支派委任審判官及其他官員。官員們要秉公審判，</span>
<span className="v" id="v19" data-v="19" data-xref="利未記 19:15; 出埃及記 23:2; 箴言 17:23"> 不可徇私枉法、偏心待人，收受賄賂，因為賄賂蒙蔽智者的眼睛，使正直人顛倒是非。</span>
<span className="v" id="v20" data-v="20" data-xref="腓立比書 4:8; 以西結書 18:9; 以西結書 18:5"> 你們要追求公正公義，以便存活，承受你們的上帝耶和華賜給你們的土地。</span>
</div>
</div>

## 不可拜偶像

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="歷代志下 33:3; 列王紀下 17:16; 出埃及記 34:13"> 「在為你們的上帝耶和華建造的祭壇旁，你們不可豎立亞舍拉木神像，</span>
<span className="v" id="v22" data-v="22" data-xref="利未記 26:1; 出埃及記 20:4; 撒迦利亞書 8:17"> 也不可豎立神柱，因為這些是你們的上帝耶和華所憎惡的。</span>
</div>
</div>

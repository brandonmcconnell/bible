## 擊敗巴珊王噩

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民數記 21:33–35; 申命記 1:4; 申命記 29:7"> 「之後，我們前往巴珊，巴珊王噩率全軍在以得來迎戰我們。</span>
<span className="v" id="v2" data-v="2" data-xref="啟示錄 2:10; 歷代志下 20:17; 民數記 21:23–25"> 耶和華對我說，『不要怕他，因為我已把他及其眾民和土地交在你手中，你要像從前對付希實本的亞摩利王西宏一樣對付他。』</span>
<span className="v" id="v3" data-v="3" data-xref="民數記 21:35; 約書亞記 13:12; 約書亞記 13:30"> 「我們的上帝耶和華把巴珊王噩及其眾民交在我們手中，我們殺了他們，一個不留。</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀上 4:13; 約書亞記 12:4; 約書亞記 13:30–31"> 我們佔領了亞珥歌伯全境，即巴珊王噩的所有城邑，共六十座。</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 1:28; 民數記 13:28; 希伯來書 11:30"> 這些城邑圍牆高聳，門閂牢固。我們還佔領了許多沒有城牆的鄉村。</span>
<span className="v" id="v6" data-v="6" data-xref="申命記 2:34; 詩篇 135:10–12; 申命記 2:24"> 像對付希實本王西宏一樣，我們將這些城邑夷為平地，城中的男女老幼一個不留，</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 2:35; 約書亞記 8:27; 約書亞記 11:11–14"> 只留下牲畜和財物作戰利品。</span>
<span className="v" id="v8" data-v="8" data-xref="約書亞記 13:9–12; 約書亞記 12:2–6; 民數記 32:33–42"> 於是，我們攻佔了約旦河東兩個亞摩利王的土地，從亞嫩谷一直到黑門山——</span>
<span className="v" id="v9" data-v="9" data-xref="歷代志上 5:23; 詩篇 29:6; 以西結書 27:5"> 西頓人稱黑門山為西連，亞摩利人稱之為示尼珥——</span>
<span className="v" id="v10" data-v="10" data-xref="約書亞記 13:31; 約書亞記 13:11–12; 申命記 4:49"> 我們攻佔了高原的城邑、整個基列和巴珊，遠至巴珊王噩的城邑撒迦和以得來。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 14:5; 耶利米書 49:2; 撒母耳記下 12:26"> 巴珊王噩是最後一個利乏音人。他的床是鐵做的，存放在亞捫人的拉巴城，長四米，寬一米八。</span>
</div>
</div>

## 分配約旦河東之地

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="申命記 2:36; 民數記 32:32–38; 約書亞記 13:8–28"> 「我們佔領了這片土地後，我把亞嫩谷邊的亞羅珥以北地區和基列山區的一半及其城邑，分給呂便支派和迦得支派，</span>
<span className="v" id="v13" data-v="13" data-xref="民數記 32:39–42; 約書亞記 13:29–32; 歷代志上 5:23–26"> 把基列山區的另一半，以及噩的王國巴珊全境——整個亞珥歌伯分給瑪拿西半個支派。巴珊地區又被稱為利乏音人之地。</span>
<span className="v" id="v14" data-v="14" data-xref="民數記 32:41; 約書亞記 13:13; 撒母耳記下 3:3"> 瑪拿西的子孫雅珥得到亞珥歌伯全境，遠至基述人和瑪迦人的邊界。他按自己的名字給巴珊取名叫哈倭特·雅珥，沿用至今。</span>
<span className="v" id="v15" data-v="15" data-xref="民數記 32:39–40; 約書亞記 17:1–3; 約書亞記 22:7"> 我又把基列分給瑪吉，</span>
<span className="v" id="v16" data-v="16" data-xref="民數記 21:24; 申命記 2:37; 撒母耳記下 24:5"> 把從基列到亞嫩谷，以谷中央為界，遠至亞捫人的邊界雅博河地區，分給呂便支派和迦得支派。</span>
<span className="v" id="v17" data-v="17" data-xref="約書亞記 12:3; 創世記 14:3; 約書亞記 3:16"> 我還把亞拉巴，就是以約旦河為界，從基尼烈直到東面毗斯迦山腳的亞拉巴海，即鹽海地區給了他們。</span>
<span className="v" id="v18" data-v="18" data-xref="民數記 32:20–24; 約書亞記 4:12–13; 約書亞記 1:12–15"> 「那時我吩咐他們說，『你們的上帝耶和華已經把這些地方賜給你們，但你們所有的戰士必須帶著兵器過河，做以色列同胞的先鋒。</span>
<span className="v" id="v19" data-v="19"> 我知道你們有許多牲畜，你們的妻子、兒女和牲畜可以留在我分給你們的城邑。</span>
<span className="v" id="v20" data-v="20" data-xref="約書亞記 22:4; 約書亞記 22:8"> 等你們的上帝耶和華使其他以色列人和你們一樣有了安身之所，佔領了耶和華賜給他們的約旦河西之地後，你們才可以返回我分給你們的家園。』</span>
<span className="v" id="v21" data-v="21" data-xref="民數記 27:18–23; 哥林多後書 12:10; 詩篇 9:10"> 那時我吩咐約書亞說，『你們的上帝耶和華怎樣對付那兩個王，你都親眼看見了。耶和華必以同樣的方式對付你將去攻佔的各國。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及記 14:14; 申命記 20:4; 申命記 1:30"> 不要怕他們，因為你的上帝耶和華將為你們爭戰。』</span>
</div>
</div>

## 摩西不得進入迦南

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="哥林多後書 12:8–9"> 「那時，我懇求耶和華，說，</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及記 15:11; 申命記 11:2; 詩篇 71:19"> 『主耶和華啊，你已向僕人彰顯你的偉大和權能，天上地下沒有神明可與你的大能作為相比！</span>
<span className="v" id="v25" data-v="25" data-xref="申命記 4:21–22; 以西結書 20:6; 出埃及記 3:8"> 求你讓我過去看看約旦河那邊的佳美之地，那美好的山區和黎巴嫩。』</span>
<span className="v" id="v26" data-v="26" data-xref="申命記 1:37; 申命記 31:2; 歷代志上 22:7–9"> 但因你們的緣故，耶和華向我發怒，不聽我的懇求，祂對我說，『夠了，不要再跟我提這件事。</span>
<span className="v" id="v27" data-v="27" data-xref="民數記 27:12; 申命記 34:1–4; 創世記 13:14–15"> 你可以上毗斯迦山頂，向東南西北眺望，親眼看看那片土地，因為你不可過約旦河。</span>
<span className="v" id="v28" data-v="28" data-xref="申命記 31:3; 申命記 31:7; 申命記 1:38"> 你要委任約書亞，勉勵他，支持他，因為他必帶領以色列人過河，使他們承受你眺望的那片土地。』</span>
<span className="v" id="v29" data-v="29" data-xref="申命記 34:6; 申命記 4:46; 民數記 25:3"> 當時，我們駐紮在伯·毗珥對面的谷中。</span>
</div>
</div>

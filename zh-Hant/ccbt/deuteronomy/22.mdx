## 有關女子貞操的條例

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="創世記 29:21; 創世記 29:31; 以弗所書 5:28–29"> 「如果有人娶了妻子，與她同房後卻不喜歡她，</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 22:19; 箴言 18:21; 箴言 18:8"> 誹謗她，說，『我娶了她，與她親近時發現她已經不是處女』，</span>
<span className="v" id="v15" data-v="15"> 女方父母就要把憑據拿到城門口的長老們面前，證明女兒的貞潔。</span>
<span className="v" id="v16" data-v="16"> 女方的父親要對他們說，『我把女兒嫁給這個人，現在他不喜歡我女兒，</span>
<span className="v" id="v17" data-v="17"> 誹謗她，聲稱她結婚時已經不是處女，但這裡有我女兒貞潔的憑據。』女方父母要把女兒新婚之夜用過的床單在本城的長老們面前展開。</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及記 18:21"> 長老們就必須抓住那人懲處他，</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 22:29; 馬太福音 19:8–9; 申命記 24:1–4"> 罰他賠償二十兩銀子給女方的父親，因為他誹謗了一個以色列的處女。那女子仍要做他妻子，丈夫終生不可休她。</span>
<span className="v" id="v20" data-v="20"> 「但如果那人的指控屬實，沒有找到那女子貞潔的憑據，</span>
<span className="v" id="v21" data-v="21" data-xref="申命記 13:5; 創世記 34:7; 士師記 20:6"> 就要把她帶到她父親的家門前，由本城的人用石頭打死她。因為她婚前淫亂，在以色列做了可恥的事。你們必須除掉你們中間的罪惡。</span>
<span className="v" id="v22" data-v="22" data-xref="利未記 20:10; 以西結書 23:45–47; 約翰福音 8:4–5"> 「如果有人與有夫之婦通姦，必須處死姦夫和淫婦，這樣就從以色列除掉了罪惡。</span>
<span className="v" id="v23" data-v="23" data-xref="馬太福音 1:18–19; 申命記 20:7"> 「如果有人在城中遇見已經訂婚的女子，與她行淫，</span>
<span className="v" id="v24" data-v="24" data-xref="申命記 22:21–22; 申命記 21:14; 哥林多前書 5:13"> 你們必須把二人帶到城門口，用石頭打死他們。那女子該死，因為她在城中卻沒有高聲呼救；那男子該死，因為他姦污了別人的妻子。你們必須除去你們中間的罪惡。</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳記下 13:14"> 「如果有人在野外遇見已經訂婚的女子，強姦了她，必須處死那男子。</span>
<span className="v" id="v26" data-v="26" data-xref="申命記 21:22"> 但不可處死那女子，因為她沒有犯該死的罪，她像被攻擊、殺害的人一樣是無辜的。</span>
<span className="v" id="v27" data-v="27" data-xref="哥林多前書 13:7"> 因為她是在野外被強姦，即使呼救也無人救她。</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及記 22:16–17"> 「如果有人遇見未訂婚的處女，強姦了她，被發現後，</span>
<span className="v" id="v29" data-v="29" data-xref="申命記 22:19; 申命記 22:24; 申命記 21:14"> 這人要付給女方的父親十兩銀子，並娶她為妻，終生不可休她，因為他姦污了她。</span>
<span className="v" id="v30" data-v="30" data-xref="申命記 27:20; 哥林多前書 5:1; 利未記 18:8"> 「人不可娶他父親的妻妾，因為這是對他父親的羞辱。</span>

## 十誡

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命記 4:1; 馬太福音 23:3; 申命記 29:10"> 摩西把所有的以色列人召來，對他們說：「以色列人啊，要留心聽我今天對你們宣講的律例和典章，要學習並謹慎遵行。</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 4:23; 出埃及記 19:5–8; 出埃及記 24:8"> 我們的上帝耶和華曾在何烈山與我們立約，</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 29:10–15; 創世記 17:21; 創世記 17:7"> 這約不是與我們祖先立的，而是與我們今天還活著的人立的。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及記 19:18–19; 申命記 34:10; 出埃及記 19:9"> 耶和華在山上的烈火中面對面跟你們說話。</span>
<span className="v" id="v5" data-v="5" data-xref="加拉太書 3:19; 出埃及記 19:16; 出埃及記 20:18–21"> 那時，因為你們害怕那烈火，沒有到山上去，我就站在耶和華和你們中間，把耶和華的話傳給你們。耶和華說：</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="出埃及記 20:2–17; 詩篇 81:5–10; 利未記 26:1–2"> 「『我是你的上帝耶和華，曾把你從受奴役之地埃及領出來。</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及記 20:3; 馬太福音 4:10; 約翰一書 5:21"> 除我以外，你不可有別的神明。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及記 20:4; 申命記 4:15–19"> 不可為自己雕刻神像，不可仿照天上、地上和地底下水中的任何形像造神像，</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及記 20:4–6; 出埃及記 34:7; 但以理書 9:4–9"> 不可跪拜它們，也不可供奉它們，因為我——你的上帝耶和華痛恨不貞，我必追討背棄我之人的罪，從父到子直到三四代。</span>
<span className="v" id="v10" data-v="10" data-xref="羅馬書 8:28; 約翰一書 1:7; 耶利米書 32:18"> 但那些愛我、遵守我誡命的人，我必以慈愛待他們，直到千代。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及記 20:7; 利未記 19:12; 申命記 6:13"> 不可妄用你上帝耶和華的名，違者必被耶和華定罪。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及記 20:8–11; 以賽亞書 58:13; 以賽亞書 56:6"> 要遵照你的上帝耶和華的吩咐守安息日為聖日。</span>
<span className="v" id="v13" data-v="13" data-xref="以西結書 20:12; 路加福音 13:14–16; 出埃及記 23:12"> 你一週可勞碌工作六天，</span>
<span className="v" id="v14" data-v="14" data-xref="希伯來書 4:4; 創世記 2:2; 出埃及記 23:12"> 但第七天是你的上帝耶和華的安息日，這一天你和兒女、僕婢、牛驢等牲畜及你那裡的外族人不可做任何工，好讓僕婢和你一樣得到休息。</span>
<span className="v" id="v15" data-v="15" data-xref="申命記 5:6; 申命記 15:15; 申命記 16:12"> 要記住，你曾在埃及做奴隸，你的上帝耶和華伸出臂膀，用大能的手把你從那裡領出來。因此，你的上帝耶和華吩咐你守安息日。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 20:12; 以弗所書 6:1–3; 歌羅西書 3:20"> 要遵照你的上帝耶和華的吩咐孝敬父母，以便在你的上帝耶和華要賜給你的土地上享長壽，蒙祝福。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及記 20:13; 羅馬書 13:9; 馬太福音 5:21–22"> 不可殺人。</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及記 20:14; 路加福音 18:20; 利未記 20:10"> 不可通姦。</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及記 20:15; 羅馬書 13:9; 以弗所書 4:28"> 不可偷盜。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及記 20:16; 出埃及記 23:1; 箴言 19:9"> 不可作偽證陷害人。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及記 20:17; 羅馬書 13:9; 路加福音 12:15"> 不可貪戀別人的妻子，不可貪圖別人的房屋、田地、僕婢、牛驢，或其他任何物品。』</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="出埃及記 24:12; 出埃及記 31:18; 申命記 4:12–15"> 「這是耶和華在山上的烈火、烏雲和幽暗中高聲頒佈給你們全體會眾的誡命。此外，祂沒有說別的。祂把這些話寫在兩塊石版上交給我。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及記 20:18–19; 希伯來書 12:18–21"> 當時，山上燃燒著烈焰，你們聽見聲音從黑暗中傳來。你們各支派的首領和長老都到我跟前，</span>
<span className="v" id="v24" data-v="24" data-xref="申命記 4:33; 出埃及記 19:19; 出埃及記 33:20"> 說，『看啊，我們的上帝耶和華向我們彰顯了祂的榮耀和威嚴，我們聽見了祂從火中發出的聲音。今天我們已經看見，人聽見上帝說話後還能活著。</span>
<span className="v" id="v25" data-v="25" data-xref="申命記 18:16; 加拉太書 3:10; 哥林多後書 3:7–9"> 但我們何必冒死，被這烈火吞噬呢？我們若再次聽到我們的上帝耶和華的聲音，必然喪命。</span>
<span className="v" id="v26" data-v="26" data-xref="申命記 4:33; 羅馬書 3:20; 馬太福音 26:63"> 世上有誰像我們一樣，聽見永活上帝從火中說話後還能活著呢？</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及記 20:19; 希伯來書 12:19"> 你近前聽我們上帝耶和華所說的話，然後回來把祂的話告訴我們，我們必聽從、遵行。』</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="申命記 18:17; 民數記 36:5; 民數記 27:7"> 「耶和華聽見了你們的話，就對我說，『我聽見了民眾對你說的話，他們所說的都對。</span>
<span className="v" id="v29" data-v="29" data-xref="以賽亞書 48:18; 以西結書 33:31–32; 申命記 11:1"> 但願他們常常敬畏我，遵從我的一切誡命，以便他們和他們的子孫世世代代可以蒙福。</span>
<span className="v" id="v30" data-v="30"> 你吩咐他們回到自己的帳篷，</span>
<span className="v" id="v31" data-v="31" data-xref="加拉太書 3:19; 以西結書 20:11; 申命記 5:1"> 但你要留在我這裡，我要把所有的誡命、律例和典章都賜給你，你要把這些傳授給眾人，使他們可以在我要賜給他們的土地上遵行。』</span>
<span className="v" id="v32" data-v="32" data-xref="約書亞記 23:6; 箴言 4:27; 約書亞記 1:7"> 所以，你們要謹遵你們上帝耶和華的吩咐，不可偏離左右。</span>
<span className="v" id="v33" data-v="33" data-xref="耶利米書 7:23; 申命記 4:40; 路加福音 1:6"> 你們要遵行你們上帝耶和華的一切吩咐，就可以在你們將要佔領的土地上存活、亨通、長久。</span>
</div>
</div>

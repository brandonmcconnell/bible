## 立約書亞做摩西的接班人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 摩西繼續對以色列人說：</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 34:7; 民數記 27:17; 列王紀上 3:7"> 「我現在已經一百二十歲了，無法再繼續帶領你們，耶和華曾說我不得過約旦河。</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 9:3; 申命記 31:23; 申命記 3:28"> 你們的上帝耶和華要親自帶領你們過河，在你們面前消滅那裡的各族，使你們佔領他們的土地。約書亞將帶領你們過河，正如耶和華所言。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及記 23:28–31; 申命記 2:33; 申命記 3:3–11"> 耶和華要毀滅那裡的各族，像毀滅亞摩利二王西宏和噩及其國家一樣。</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 7:2; 申命記 20:16–17; 出埃及記 23:32–33"> 耶和華要把他們交給你們，你們要照我的一切吩咐處置他們。</span>
<span className="v" id="v6" data-v="6" data-xref="約書亞記 1:9; 以弗所書 6:10; 詩篇 27:14"> 你們要剛強勇敢，不要懼怕他們，因為你們的上帝耶和華與你們同行，祂不會撇下你們，也不會離棄你們。」</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 3:28; 申命記 31:6; 申命記 1:38"> 摩西把約書亞叫來，當著全體以色列人的面對他說：「你要剛強勇敢！因為你要與百姓一同進入耶和華起誓要賜給他們祖先的土地，把土地分給他們作產業。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及記 33:14; 申命記 31:6; 約書亞記 1:9"> 耶和華必帶領你，與你同在。祂不會撇下你，也不會離棄你。不要驚慌害怕。」</span>
</div>
</div>

## 每七年當眾宣讀律法一次

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="民數記 4:15; 約書亞記 3:3; 申命記 17:18"> 摩西把這律法寫好，交給抬耶和華約櫃的利未祭司和以色列的眾長老。</span>
<span className="v" id="v10" data-v="10" data-xref="利未記 23:34–43; 申命記 15:1–2"> 摩西吩咐他們說：「每逢免除債務的第七年的住棚節，</span>
<span className="v" id="v11" data-v="11" data-xref="列王紀下 23:2; 約書亞記 8:34–35; 申命記 16:16–17"> 所有以色列人到你們的上帝耶和華選定的地方朝見祂時，你們要當眾大聲宣讀這律法。</span>
<span className="v" id="v12" data-v="12" data-xref="申命記 4:10; 詩篇 34:11–14; 申命記 6:6–7"> 要招聚所有男女、孩童以及住在你們中間的外族人，讓他們聆聽這律法，學習敬畏你們的上帝耶和華，謹遵律法上的一切話。</span>
<span className="v" id="v13" data-v="13" data-xref="申命記 11:2; 申命記 6:7; 箴言 22:6"> 這樣，他們那些還不知道這律法的孩子便有機會聽到律法，在你們將要佔領的約旦河西岸的土地上，學習終生敬畏你們的上帝耶和華。」</span>
</div>
</div>

## 上帝對摩西和約書亞的指示

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="民數記 27:13; 申命記 31:23; 約伯記 2:1"> 耶和華對摩西說：「你快要離世了。叫約書亞與你一起到會幕，我要委派他。」摩西和約書亞就來到會幕。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及記 40:38; 詩篇 99:7; 出埃及記 33:9–10"> 有雲柱停在會幕入口的上方，耶和華在雲柱中向他們顯現。</span>
<span className="v" id="v16" data-v="16" data-xref="士師記 10:6; 士師記 10:13; 士師記 2:12"> 耶和華對摩西說：「你快要與祖先同眠了。這些百姓將很快在要佔領的土地上與外族人的神明苟合，背棄我，違背我與他們所立的約。</span>
<span className="v" id="v17" data-v="17" data-xref="民數記 14:42; 以賽亞書 8:17; 詩篇 104:29"> 那時，我要向他們發怒，離棄他們，掩面不理他們。他們將被吞滅，遭遇許多禍患和災難，以致他們會說，『這些禍患臨到我們，豈不是因為上帝不在我們中間了嗎？』</span>
<span className="v" id="v18" data-v="18" data-xref="申命記 31:16–17"> 那時，我必掩面不理他們，因為他們祭拜其他神明，行為邪惡。</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 6:7; 申命記 31:21–22; 申命記 31:26"> 「現在，你要寫一首歌，教導以色列人，讓他們吟唱，作為我指控他們的證據。</span>
<span className="v" id="v20" data-v="20" data-xref="何西阿書 13:6; 申命記 6:10–12; 尼希米記 9:25–26"> 因為當我把他們帶到我起誓應許他們祖先的奶蜜之鄉後，當他們在那裡吃飽喝足後，就會嫌棄我，違背我與他們所立的約，去供奉其他神明。</span>
<span className="v" id="v21" data-v="21" data-xref="何西阿書 5:3; 詩篇 139:2; 約翰福音 2:24–25"> 當許多禍患和災難臨到他們的時候，這首歌就要成為指控他們的證據，因為這首歌要在他們的子孫中世代流傳。雖然我還沒有帶領他們進入我起誓應許之地，我已經知道他們的心思意念。」</span>
<span className="v" id="v22" data-v="22" data-xref="申命記 31:19; 申命記 31:9"> 當天，摩西就寫下這首歌，傳授給以色列人。</span>
<span className="v" id="v23" data-v="23" data-xref="申命記 31:7–8; 申命記 31:14; 使徒行傳 7:45"> 耶和華囑咐嫩的兒子約書亞：「你要剛強勇敢，因為你要帶領以色列人進入我起誓應許他們的土地，我必與你同在。」</span>
<span className="v" id="v24" data-v="24" data-xref="申命記 31:9; 申命記 17:18"> 摩西把這律法都寫在書上以後，</span>
<span className="v" id="v25" data-v="25" data-xref="申命記 31:9"> 就吩咐抬耶和華約櫃的利未人：</span>
<span className="v" id="v26" data-v="26" data-xref="申命記 31:19; 列王紀下 22:8–11; 加拉太書 2:19"> 「把這律法書放在你們的上帝耶和華的約櫃旁，作為指控你們的證據。</span>
<span className="v" id="v27" data-v="27" data-xref="申命記 32:20; 申命記 9:24; 使徒行傳 7:51"> 因為我知道你們悖逆、頑固不化，我還活在你們中間的時候，你們尚且背叛上帝，何況我死後呢？</span>
<span className="v" id="v28" data-v="28" data-xref="申命記 32:1; 申命記 4:26; 申命記 30:19"> 把你們各支派的長老和首領招聚來，我要把這些話告訴他們，叫天地作證來指控他們。</span>
<span className="v" id="v29" data-v="29" data-xref="士師記 2:19; 申命記 32:5; 路加福音 21:24"> 我知道，我死後你們會徹底墮落，偏離我吩咐你們行的道，做耶和華視為惡的事，惹祂發怒，將來禍患必臨到你們。」</span>
<span className="v" id="v30" data-v="30" data-xref="希伯來書 3:2; 申命記 4:5; 約翰福音 12:49"> 然後，摩西把這首詩歌從頭到尾讀給以色列全體會眾聽。</span>
</div>
</div>

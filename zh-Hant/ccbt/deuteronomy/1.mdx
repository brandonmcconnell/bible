## 前言

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳記上 25:1; 約書亞記 22:7; 民數記 33:17–18"> 以下是摩西對以色列人說的話。當時以色列人在約旦河東的曠野、疏弗對面的亞拉巴，即巴蘭、陀弗、拉班、哈洗錄和底撒哈之間。</span>
<span className="v" id="v2" data-v="2" data-xref="民數記 32:8; 民數記 13:26; 申命記 9:23"> 從何烈山取道西珥山到加低斯·巴尼亞，需十一天。</span>
<span className="v" id="v3" data-v="3" data-xref="民數記 33:38; 申命記 4:1–2; 民數記 20:1"> 在離開埃及後第四十年的十一月一日，摩西把耶和華的一切吩咐告訴了以色列人。</span>
<span className="v" id="v4" data-v="4" data-xref="民數記 21:21–35; 約書亞記 12:2–6; 約書亞記 13:10–12"> 那時，他已經打敗了希實本的亞摩利王西宏，以及盤踞在以得來和亞斯她錄的巴珊王噩。</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 4:8; 申命記 32:46; 申命記 31:9"> 摩西在約旦河東的摩押講解律法，說：</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及記 3:1; 民數記 10:11–13; 出埃及記 19:1–2"> 「我們的上帝耶和華在何烈山對我們說，『你們在這山上已經住了足夠時日，</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 11:24; 約書亞記 10:40; 阿摩司書 2:9"> 現在該啟程前往亞摩利人的山區、亞拉巴地區、山地、丘陵、南地、沿海一帶、迦南人之地和黎巴嫩，直到幼發拉底大河。</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 15:18; 創世記 12:7; 創世記 26:3–4"> 看啊，我把那片土地賜給你們了，你們去佔領吧，那是耶和華起誓要賜給你們祖先亞伯拉罕、以撒、雅各和他們後裔的地方。』</span>
</div>
</div>

## 摩西設立首領

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="出埃及記 18:18; 民數記 11:17; 民數記 11:11–14"> 「那時，我對你們說，『我無法獨自承擔管理你們的重任，</span>
<span className="v" id="v10" data-v="10" data-xref="申命記 10:22; 出埃及記 32:13; 創世記 22:17"> 因為你們的上帝耶和華使你們人丁興旺，以致今天人數多如天上的星星。</span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 115:14; 創世記 22:17; 民數記 6:27"> 願你們祖先的上帝耶和華使你們人數更增千倍，照祂的應許賜福給你們。</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多後書 3:5; 列王紀上 3:7–9; 哥林多後書 2:16"> 但我怎能獨自擔當解決你們問題和爭端的重任呢？</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及記 18:21; 使徒行傳 1:21–23; 民數記 11:16–17"> 你們要從各支派中選出有智慧、有見識、受尊重的人，我要立他們做你們的首領。』</span>
<span className="v" id="v14" data-v="14"> 你們都同意這樣的做法。</span>
<span className="v" id="v15" data-v="15" data-xref="申命記 16:18; 出埃及記 18:25–26; 以弗所書 4:11"> 於是，我把各支派中有智慧和受敬重的人立為你們的首領，即千夫長、百夫長、五十夫長、十夫長和其他官長，治理你們。</span>
<span className="v" id="v16" data-v="16" data-xref="約翰福音 7:24; 出埃及記 22:21; 歷代志下 19:6–10"> 我吩咐這些官員要聆聽案件，公正地審理同胞之間，或與外族人之間的訴訟，</span>
<span className="v" id="v17" data-v="17" data-xref="申命記 16:19; 出埃及記 18:26; 雅各書 2:9"> 不可偏私，不分貴賤，不懼情面，因為判決來自上帝。如果案件太難，可以交給我處理。</span>
<span className="v" id="v18" data-v="18" data-xref="申命記 12:32; 申命記 4:5; 使徒行傳 20:20"> 那時，我把一切當行之事都告訴了你們。</span>
</div>
</div>

## 派人打探迦南

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="申命記 1:2; 申命記 8:15; 耶利米書 2:6"> 「我們照我們上帝耶和華的吩咐，從何烈山出發，走過你們所見的那大而可怕的曠野，前往亞摩利山區，來到加低斯·巴尼亞。</span>
<span className="v" id="v20" data-v="20" data-xref="申命記 1:7–8"> 我對你們說，『我們的上帝耶和華賜給我們的亞摩利山區到了。</span>
<span className="v" id="v21" data-v="21" data-xref="約書亞記 1:9; 詩篇 46:1; 民數記 14:8–9"> 看啊，你們祖先的上帝耶和華已把那片土地賜給你們，你們要照著祂的應許去佔領那裡，不要驚慌害怕。』</span>
<span className="v" id="v22" data-v="22" data-xref="民數記 13:1–20"> 你們都來對我說，『我們要先派人去打探那地方，回來好告訴我們當走哪條路，當佔哪些城。』</span>
<span className="v" id="v23" data-v="23" data-xref="民數記 13:3–33"> 我同意你們的建議，便從你們當中選出十二人，每支派選一人。</span>
<span className="v" id="v24" data-v="24" data-xref="民數記 13:21–27; 約書亞記 2:1–2"> 他們前往山區，到了以實各谷，打探那地方。</span>
<span className="v" id="v25" data-v="25"> 他們帶回來一些那裡的果子，稟告說，『我們的上帝耶和華賜給我們的地方很好。』</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="民數記 14:1–4; 使徒行傳 7:51; 詩篇 106:24–25"> 「但你們卻違背你們上帝耶和華的命令，不肯上去。</span>
<span className="v" id="v27" data-v="27" data-xref="申命記 9:28; 詩篇 106:25; 民數記 14:3"> 你們在帳篷中埋怨說，『耶和華憎恨我們，所以才領我們離開埃及，要把我們交在亞摩利人手裡，讓他們消滅我們。</span>
<span className="v" id="v28" data-v="28" data-xref="民數記 13:28–33; 申命記 9:1–2; 約書亞記 15:14"> 我們能上哪里去呢？我們弟兄的報告讓我們膽戰心驚，他們說那裡的人比我們高大，城邑雄偉，城牆高達雲霄，還有亞衲人在那裡。』</span>
<span className="v" id="v29" data-v="29"> 我對你們說，『不要驚慌，不要怕他們。</span>
<span className="v" id="v30" data-v="30" data-xref="出埃及記 14:14; 尼希米記 4:20; 羅馬書 8:31"> 你們的上帝耶和華必帶領你們，為你們爭戰，正如祂當著你們的面在埃及所行的一樣。</span>
<span className="v" id="v31" data-v="31" data-xref="以賽亞書 46:3–4; 使徒行傳 13:18; 何西阿書 11:3–4"> 你們在曠野曾目睹你們的上帝耶和華像父親抱兒子一樣，一路把你們抱到這地方。』</span>
<span className="v" id="v32" data-v="32" data-xref="詩篇 106:24; 猶大書 1:5; 希伯來書 3:18–19"> 祂為你們開路，為你們找安營的地方，夜間用火柱、白天用雲柱為你們引路。儘管如此，你們還是不信靠你們的上帝耶和華。</span>
</div>
</div>

## 懲罰叛逆

<div className="bt">
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="民數記 14:22–30; 詩篇 95:11; 以西結書 20:15"> 「你們的埋怨惹耶和華發怒，祂起誓說，</span>
<span className="v" id="v35" data-v="35" data-xref="詩篇 95:11"> 『這邪惡的一代沒有一人能看見我起誓要賜給他們祖先的佳美之地，</span>
<span className="v" id="v36" data-v="36" data-xref="民數記 14:24; 約書亞記 14:6–14; 民數記 32:12"> 只有耶孚尼的兒子迦勒能看見，我必把他所踏之地賜給他和他的子孫，因為他一心追隨我。』</span>
<span className="v" id="v37" data-v="37" data-xref="民數記 20:12; 申命記 4:21; 申命記 34:4"> 因為你們的緣故，耶和華也向我發怒，說，『你也不能進入那片土地，</span>
<span className="v" id="v38" data-v="38" data-xref="申命記 3:28; 民數記 14:30; 申命記 31:7–8"> 但你的助手、嫩的兒子約書亞可以進入。你要鼓勵他，因為他將帶領以色列承受那片土地。</span>
<span className="v" id="v39" data-v="39" data-xref="以賽亞書 7:15–16; 民數記 14:3; 民數記 14:31"> 你們說你們的子女會被擄去，但這些還不知善惡的孩子都將進入那片土地，我要把那裡賜給他們，他們將佔領那裡。</span>
<span className="v" id="v40" data-v="40" data-xref="民數記 14:25"> 而你們要掉頭，沿紅海的路回到曠野。』</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="民數記 14:39–45; 箴言 19:3; 民數記 22:34"> 「於是，你們對我說，『我們得罪了耶和華，現在我們願意遵從我們的上帝耶和華的吩咐，上去作戰。』你們便各自拿起兵器，以為可以輕易攻佔山區。</span>
<span className="v" id="v42" data-v="42" data-xref="民數記 14:41–43; 約書亞記 7:8–13; 以賽亞書 59:1–2"> 但耶和華讓我告訴你們，『不要上去作戰，以免被敵人打敗，因為我不與你們同在。』</span>
<span className="v" id="v43" data-v="43" data-xref="民數記 14:44; 以賽亞書 63:10; 使徒行傳 7:51"> 我把耶和華的話轉告了你們，但你們不聽，竟違背耶和華的命令，擅自前往山區。</span>
<span className="v" id="v44" data-v="44" data-xref="詩篇 118:12; 民數記 14:45; 民數記 21:3"> 住在山區的亞摩利人蜂擁出擊，打敗了你們，從西珥追殺你們，一直追到何珥瑪。</span>
<span className="v" id="v45" data-v="45" data-xref="希伯來書 12:17; 詩篇 78:34"> 你們回來在耶和華面前哭泣，但耶和華不理會你們的哭聲。</span>
<span className="v" id="v46" data-v="46" data-xref="民數記 20:1; 民數記 20:22; 士師記 11:16–17"> 因此，你們在加低斯住了很久。</span>
</div>
</div>

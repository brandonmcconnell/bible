## 交戰的條例

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歷代志下 32:7–8; 申命記 31:8; 詩篇 20:7"> 「你們和敵人交戰時，面對比你們強大的軍隊及戰車戰馬，不要害怕，因為你們的上帝耶和華與你們同在，祂曾帶你們出埃及。</span>
<span className="v" id="v2" data-v="2" data-xref="民數記 31:6; 歷代志下 13:12; 民數記 10:8–9"> 你們出戰之前，祭司要上前鼓舞士氣，</span>
<span className="v" id="v3" data-v="3" data-xref="希伯來書 13:6; 詩篇 3:6; 啟示錄 2:10"> 說，『以色列人啊，聽著！今天你們要和敵人交戰，不要膽小害怕，也不要驚慌失措。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及記 14:14; 申命記 3:22; 申命記 1:30"> 因為你們的上帝耶和華要與你們同去，為你們爭戰，使你們戰勝仇敵。』</span>
<span className="v" id="v5" data-v="5" data-xref="尼希米記 12:27; 民數記 31:14; 申命記 16:18"> 官長要對士兵說，『你們誰建了新房子還沒有舉行奉獻禮<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「舉行奉獻禮」指入住前舉行的儀式。">a</a></sup>？他可以回家去，以免他陣亡了，別人為他的房子舉行奉獻禮。</span>
<span className="v" id="v6" data-v="6" data-xref="利未記 19:23–25; 申命記 28:1–30; 耶利米書 31:5"> 誰栽種了葡萄園還沒有享受過園中的果子？他可以回家去，以免他陣亡了，別人享受他園中的果子。</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 24:5; 申命記 28:30; 路加福音 14:18–20"> 誰訂了親還沒有迎娶？他可以回家去，以免他陣亡了，別人娶他的未婚妻。』</span>
<span className="v" id="v8" data-v="8" data-xref="士師記 7:3; 申命記 1:28; 啟示錄 21:8"> 官長也要告訴士兵，『有沒有膽怯、害怕的？他可以回家去，免得影響他人士氣。』</span>
<span className="v" id="v9" data-v="9"> 他們講完後，就要委派將領率軍出戰。</span>
</div>
</div>

## 攻城之略

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="路加福音 10:5–6; 哥林多後書 5:18–1; 以弗所書 2:17"> 「你們進攻一座城之前，要先給城中居民求和的機會。</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 19:14; 約書亞記 11:19–20; 約書亞記 16:10"> 如果他們開城求和，城裡所有人都要做你們的奴隸，為你們服勞役。</span>
<span className="v" id="v12" data-v="12"> 如果他們不肯求和，要交戰，你們就要圍攻那城。</span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 2:6–12; 列王紀上 11:15–16; 詩篇 110:1"> 你們的上帝耶和華把城交給你們時，你們要用刀殺光城裡所有的男子，</span>
<span className="v" id="v14" data-v="14" data-xref="約書亞記 8:2; 約書亞記 22:8; 民數記 31:9"> 但可以留下城中的婦女、孩童、牲畜及其他一切作戰利品。你們可以享用仇敵的財物，那是你們的上帝耶和華賜給你們的。</span>
<span className="v" id="v15" data-v="15"> 上述做法只適用於離你們很遙遠的城邑，你們附近各族的城邑除外。</span>
<span className="v" id="v16" data-v="16" data-xref="約書亞記 11:14; 民數記 21:2–3; 民數記 33:52"> 你們的上帝耶和華將把你們附近各族的城邑賜給你們作產業，你們要將裡面有氣息的全部消滅。</span>
<span className="v" id="v17" data-v="17" data-xref="以賽亞書 34:5–6; 耶利米書 50:35–40; 申命記 7:1–2"> 要遵照你們的上帝耶和華的吩咐，徹底滅絕赫人、亞摩利人、迦南人、比利洗人、希未人和耶布斯人，</span>
<span className="v" id="v18" data-v="18" data-xref="申命記 12:30–31; 出埃及記 23:33; 以弗所書 5:11"> 免得他們將祭拜自己神明的可憎習俗傳給你們，以致你們得罪你們的上帝耶和華。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="馬太福音 3:10; 約翰福音 15:2–8; 申命記 26:6"> 「你們圍攻一座城久攻不下時，不可用斧頭砍掉那裡的樹木，因為你們可以吃樹上的果子。田間的樹木豈是人，讓你們圍攻嗎？</span>
<span className="v" id="v20" data-v="20" data-xref="歷代志下 26:15; 耶利米書 33:4; 傳道書 9:14"> 但你們可以砍那些不結果子的樹來建圍城的工事，直到攻陷為止。</span>
</div>
</div>

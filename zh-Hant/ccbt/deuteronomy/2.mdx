## 曠野漂流

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民數記 21:4; 申命記 1:40; 民數記 14:25"> 「之後，我們遵照耶和華的吩咐掉轉頭，沿紅海的路前往曠野，在西珥山區繞行了很久。</span>
<span className="v" id="v2" data-v="2"> 後來，耶和華對我說，</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 1:6; 申命記 2:14; 申命記 2:7"> 『你們在這山區繞行的日子夠了，現在轉向北方吧。</span>
<span className="v" id="v4" data-v="4" data-xref="民數記 20:14–21; 出埃及記 15:15; 申命記 23:7"> 你要吩咐民眾：你們將經過西珥，那裡住著你們的親屬以掃的子孫。他們懼怕你們，所以你們要格外謹慎，</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 36:8; 約書亞記 24:4; 耶利米書 27:5"> 不可挑起戰爭，因為我已把西珥山賜給以掃作產業，他們的土地，我一寸也不會賜給你們。</span>
<span className="v" id="v6" data-v="6" data-xref="馬太福音 7:12; 民數記 20:19; 羅馬書 12:17"> 你們吃的、喝的，都要花錢向他們買。</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 22:35; 尼希米記 9:21; 申命記 8:2–4"> 你們的上帝耶和華使你們凡事蒙福，看顧著你們走過這遼闊的曠野，四十年來與你們同在，使你們一無所缺。』</span>
<span className="v" id="v8" data-v="8" data-xref="列王紀上 9:26; 士師記 11:18; 列王紀下 16:6"> 「於是，我們繞過我們親屬以掃的子孫所住的西珥，沿亞拉巴的路，經過以拉他、以旬·迦別，向摩押曠野走去。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 19:36–37; 民數記 21:15; 民數記 21:28"> 耶和華對我說，『不可騷擾摩押人，不可挑起戰爭，因為我不會把他們的土地賜給你，我已把亞珥賜給羅得的子孫為業。』</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 14:5; 申命記 2:11; 民數記 13:22"> 「從前以米人住在亞珥，他們人數眾多，像亞衲人一樣身材高大。</span>
<span className="v" id="v11" data-v="11" data-xref="申命記 1:28; 民數記 13:28; 創世記 14:5"> 以米人同亞衲人一樣也被稱為利乏音人，但摩押人稱他們為以米人。</span>
<span className="v" id="v12" data-v="12" data-xref="申命記 2:22; 創世記 14:6; 申命記 2:32–11"> 以前，何利人也住在西珥，但以掃的子孫消滅了他們，佔領了他們的土地，住在那裡，正如後來以色列人佔領了耶和華賜給他們的土地。</span>
<span className="v" id="v13" data-v="13" data-xref="民數記 21:12; 民數記 13:23"> 耶和華又說，『現在，你們要動身過撒烈溪。』於是，我們過了撒烈溪。</span>
<span className="v" id="v14" data-v="14" data-xref="民數記 26:64–65; 民數記 14:28–35; 申命記 1:34–35"> 我們從離開加低斯·巴尼亞到穿過撒烈溪，用了三十八年。期間，那一代戰士都死光了，正如耶和華的誓言。</span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 106:26; 以賽亞書 66:14; 詩篇 32:4"> 其實是耶和華的手攻擊他們，直到把他們從營中全部消滅。</span>
<span className="v" id="v16" data-v="16"> 「民中所有的戰士都死後，</span>
<span className="v" id="v17" data-v="17"> 耶和華對我說，</span>
<span className="v" id="v18" data-v="18" data-xref="民數記 21:23; 以賽亞書 15:1; 民數記 21:15"> 『今天你要經過摩押邊境亞珥。</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 2:9; 士師記 11:13–27; 歷代志下 20:10"> 到亞捫人之地後，不可騷擾他們，不可挑起戰爭，因為我不會把他們的土地賜給你們，我已把那裡賜給羅得的子孫作產業。』</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 14:5"> 那裡以前也是利乏音人住的地方，亞捫人稱利乏音人為散送冥，</span>
<span className="v" id="v21" data-v="21" data-xref="耶利米書 27:7–8; 申命記 1:28; 申命記 2:22"> 利乏音族人數眾多，像亞衲人一樣身材高大。耶和華在亞捫人面前消滅了他們，讓亞捫人佔領他們的土地，住在那裡。</span>
<span className="v" id="v22" data-v="22" data-xref="創世記 36:8; 創世記 36:20–30; 申命記 2:12"> 耶和華也曾為以掃的子孫消滅住在西珥的何利人，讓他們佔據何利人的土地，住在那裡，直到今日。</span>
<span className="v" id="v23" data-v="23" data-xref="創世記 10:14; 約書亞記 13:3; 阿摩司書 9:7"> 同樣，來自克里特的迦斐托人消滅了迦薩附近鄉村的亞衛人，住在那裡。</span>
<span className="v" id="v24" data-v="24" data-xref="耶利米書 27:5; 但以理書 4:17; 士師記 11:18–21"> 耶和華說，『起來穿過亞嫩谷。看啊，我已將亞摩利人希實本王西宏和他的土地交在你手中，你要攻打他，佔領他的土地。</span>
<span className="v" id="v25" data-v="25" data-xref="申命記 11:25; 出埃及記 15:14–16; 申命記 28:10"> 從今天起，我要使天下萬民在你面前驚恐萬狀，一聽到你的名字就嚇得發抖。』</span>
</div>
</div>

## 擊敗希實本王

<div className="bt">
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="路加福音 10:5–6; 路加福音 10:10–12; 約書亞記 13:18"> 「於是，我從基底莫曠野派使者去見希實本王西宏，提出和平的建議，說，</span>
<span className="v" id="v27" data-v="27" data-xref="士師記 11:19; 申命記 2:6; 民數記 21:21–23"> 『請允許我們從貴國經過，我們只走大路，不會偏離。</span>
<span className="v" id="v28" data-v="28" data-xref="民數記 20:19"> 我們吃的喝的，都會花錢向你買，只求讓我們步行經過，</span>
<span className="v" id="v29" data-v="29" data-xref="民數記 20:18; 士師記 11:17–18; 申命記 23:3–4"> 就像西珥的以東人和亞珥的摩押人那樣對待我們，直到我們越過約旦河，進入我們的上帝耶和華所賜之地。』</span>
<span className="v" id="v30" data-v="30" data-xref="民數記 21:23; 出埃及記 4:21; 約書亞記 11:19–20"> 希實本王西宏卻拒絕我們的請求，因為我們的上帝耶和華使他心靈剛硬、頑固不化，好讓我們擊敗他，正如今日的情形。</span>
<span className="v" id="v31" data-v="31" data-xref="申命記 1:8; 申命記 2:24"> 耶和華對我說，『看啊，我已把西宏和他的土地交給你了，去佔領他的土地吧。』</span>
<span className="v" id="v32" data-v="32" data-xref="民數記 21:23–30; 士師記 11:20–23; 詩篇 136:19"> 西宏率領全軍在雅雜與我們交戰。</span>
<span className="v" id="v33" data-v="33" data-xref="申命記 7:2; 約書亞記 21:44; 申命記 3:2–3"> 我們的上帝耶和華使西宏父子及其軍隊敗在我們手下，全軍覆沒。</span>
<span className="v" id="v34" data-v="34" data-xref="申命記 7:2; 撒母耳記上 15:3; 申命記 3:6"> 我們攻佔了西宏的所有城邑，將其夷為平地，殺光城中的男女老幼，一個不留，</span>
<span className="v" id="v35" data-v="35" data-xref="約書亞記 8:27; 申命記 20:14; 民數記 31:9–11"> 只留下牲畜和財物作戰利品。</span>
<span className="v" id="v36" data-v="36" data-xref="約書亞記 13:9; 申命記 4:48; 申命記 3:12"> 從亞嫩谷邊的亞羅珥和谷中的城，直到基列的所有城邑全被我們攻克，我們的上帝耶和華把這一切都交給了我們。</span>
<span className="v" id="v37" data-v="37" data-xref="民數記 21:24; 申命記 3:16; 創世記 32:22"> 我們遵照我們的上帝耶和華的吩咐，沒有進犯亞捫人的土地，即雅博河一帶和山區的城邑。</span>
</div>

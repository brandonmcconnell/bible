## 要聽從耶和華

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命記 6:5; 申命記 10:12; 路加福音 1:74–75"> 「你們要愛你們的上帝耶和華，時刻遵守祂的吩咐、律例、典章和誡命。</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 8:2–5; 申命記 29:10; 使徒行傳 26:22"> 要記住，我現在是對你們，而不是對你們的孩子說話。他們沒有親身經歷、親眼見過你們上帝耶和華的管教、威嚴、大能的手和伸出的臂膀；</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 7:19; 申命記 4:34; 詩篇 105:27–45"> 祂怎樣在埃及行神蹟奇事對付埃及王法老及其整個國家；</span>
<span className="v" id="v4" data-v="4" data-xref="詩篇 106:11; 出埃及記 14:23–31; 出埃及記 15:19"> 怎樣使紅海淹沒追趕你們的埃及軍隊和車馬，將他們永遠毀滅；</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 77:20; 詩篇 106:12–48; 詩篇 78:14–72"> 怎樣在曠野一路看顧你們，一直來到這裡；</span>
<span className="v" id="v6" data-v="6" data-xref="民數記 26:9–10; 詩篇 106:17; 民數記 16:1–35"> 怎樣對付呂便人以利押的兒子大坍和亞比蘭，使大地在以色列人當中裂開，吞沒了他們及其家人、帳篷和所有隨從。</span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 145:4–6; 詩篇 145:12; 詩篇 150:2"> 你們親眼目睹了耶和華的這些偉大作為。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="以弗所書 6:10; 約書亞記 1:6–7; 以弗所書 3:16"> 「因此，你們要遵守我今天吩咐你們的誡命，以便有力量過河，攻取你們將要攻取的土地，</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及記 3:8; 申命記 4:40; 申命記 6:2"> 長久居住在耶和華起誓要賜給你們祖先及其後裔的奶蜜之鄉。</span>
<span className="v" id="v10" data-v="10" data-xref="撒迦利亞書 14:18"> 你們將要攻取的那片土地不像你們離開的埃及。在埃及你們撒種後，要像澆菜園一樣辛勤灌溉<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「辛勤灌溉」希伯來文是「用腳灌溉」。">a</a></sup>。</span>
<span className="v" id="v11" data-v="11" data-xref="希伯來書 6:7; 申命記 8:7–9; 詩篇 65:12–13"> 而你們將要佔領的那片土地卻有山有谷，雨水充足，</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米書 24:6; 詩篇 33:18; 列王紀上 9:3"> 你們的上帝耶和華從歲首到年終時時看顧那裡。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="申命記 10:12; 申命記 4:29; 申命記 6:17"> 「如果你們謹遵我今天吩咐你們的誡命，全心全意地愛你們的上帝耶和華，事奉祂，</span>
<span className="v" id="v14" data-v="14" data-xref="雅各書 5:7; 利未記 26:4; 以西結書 34:26"> 祂就會按時給你們的土地降下秋雨和春雨，使你們收穫穀物、新酒和油，</span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 104:14; 申命記 6:11; 約珥書 2:19"> 有草場飼養牲畜，豐衣足食。</span>
<span className="v" id="v16" data-v="16" data-xref="約伯記 31:27; 希伯來書 3:12; 希伯來書 2:1"> 你們要謹慎，免得被迷惑，轉而供奉、祭拜其他神明。</span>
<span className="v" id="v17" data-v="17" data-xref="列王紀上 8:35; 申命記 6:15; 歷代志下 6:26"> 否則，耶和華必向你們發怒，使天不下雨、地無出產，以致你們在祂賜給你們的佳美之地上迅速滅亡。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="歌羅西書 3:16; 申命記 6:6–9; 箴言 3:1"> 「所以，你們要把我的這些吩咐銘記在心，繫在手上，戴在額上作記號；</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 6:7; 以賽亞書 38:19; 申命記 4:9–10"> 要用這些話教導你們的兒女，無論坐在家裡或行在路上，或起或臥，都要講論；</span>
<span className="v" id="v20" data-v="20" data-xref="申命記 6:9"> 也要寫在城門上和自家的門框上。</span>
<span className="v" id="v21" data-v="21" data-xref="箴言 4:10; 箴言 3:2; 箴言 9:11"> 這樣，你們及子孫就可以生活在耶和華起誓要賜給你們祖先的土地上，與天地同長。</span>
<span className="v" id="v22" data-v="22" data-xref="申命記 6:17; 申命記 11:13; 申命記 10:20"> 如果你們謹遵我吩咐你們的這一切誡命——愛你們的上帝耶和華，遵行祂的旨意，依靠祂，</span>
<span className="v" id="v23" data-v="23" data-xref="申命記 4:38; 申命記 9:1; 申命記 7:1–2"> 耶和華就會為你們趕走那些比你們強大的民族，你們也必佔領他們的土地。</span>
<span className="v" id="v24" data-v="24" data-xref="約書亞記 14:9; 出埃及記 23:31; 創世記 15:18–21"> 你們腳掌踏過的地方都要歸你們。你們的疆界南到曠野，北到黎巴嫩，東到幼發拉底大河，西到地中海。</span>
<span className="v" id="v25" data-v="25" data-xref="申命記 7:24; 出埃及記 23:27; 約書亞記 1:5"> 所到之處無人能抵擋你們，因為你們的上帝耶和華會使那些地方的人對你們充滿懼怕，正如祂對你們的應許。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="申命記 30:1; 申命記 30:15–20; 加拉太書 3:10"> 「看啊，我今天把祝福和咒詛擺在你們面前。</span>
<span className="v" id="v27" data-v="27" data-xref="以賽亞書 1:19; 申命記 28:1–14; 以賽亞書 3:10"> 你們若遵行我今天吩咐你們的誡命，就會蒙福。</span>
<span className="v" id="v28" data-v="28" data-xref="申命記 28:15–68; 羅馬書 2:8–9; 加拉太書 3:10"> 你們若不遵行你們的上帝耶和華的誡命，偏離我今天吩咐你們當走的道路，隨從不認識的其他神明，必受咒詛。</span>
<span className="v" id="v29" data-v="29" data-xref="申命記 27:12–26; 約書亞記 8:30–35"> 你們的上帝耶和華帶領你們進入並佔領那片土地時，你們要在基利心山上宣告祝福，在以巴路山上宣告咒詛。</span>
<span className="v" id="v30" data-v="30" data-xref="創世記 12:6; 士師記 7:1; 約書亞記 4:19"> 基利心山和以巴路山屬於住在亞拉巴的迦南人，位於約旦河西岸的日落之處，在吉甲對面，靠近摩利橡樹。</span>
<span className="v" id="v31" data-v="31" data-xref="約書亞記 1:11; 申命記 9:1; 約書亞記 3:13–17"> 你們就要穿過約旦河，佔領耶和華賜給你們的土地了。你們佔領那裡並定居下來以後，</span>
<span className="v" id="v32" data-v="32" data-xref="馬太福音 28:20; 申命記 12:32; 帖撒羅尼迦前書 4:1–2"> 要謹遵我今天頒佈給你們的一切律例和典章。</span>
</div>
</div>

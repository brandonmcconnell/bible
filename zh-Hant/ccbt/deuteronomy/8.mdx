## 不可忘記耶和華

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命記 4:1; 申命記 5:32–3; 帖撒羅尼迦前書 4:1–2"> 「你們要謹遵我今日吩咐你們的一切誡命，以便能夠存活，人丁興旺，進入並得到耶和華起誓要賜給你們祖先的土地。</span>
<span className="v" id="v2" data-v="2" data-xref="雅各書 1:3; 彼得前書 1:7; 申命記 8:16"> 要記住這四十年來，你們的上帝耶和華怎樣在曠野一路引領你們，祂磨煉你們、考驗你們，好知道你們的心意如何、肯不肯遵守祂的誡命。</span>
<span className="v" id="v3" data-v="3" data-xref="馬太福音 4:4; 路加福音 4:4; 希伯來書 13:5–6"> 祂讓你們忍饑挨餓，然後賜給你們祖祖輩輩從未見過的嗎哪吃，為了使你們明白人活著不是單靠食物，而是靠耶和華口中的每一句話。</span>
<span className="v" id="v4" data-v="4" data-xref="尼希米記 9:21; 申命記 29:5; 馬太福音 26:25–30"> 這四十年來，你們的衣服沒有穿破，雙腳也沒有走腫。</span>
<span className="v" id="v5" data-v="5" data-xref="啟示錄 3:19; 箴言 3:12; 撒母耳記下 7:14"> 你們心裡要明白，你們的上帝耶和華管教你們，如同父親管教兒子。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="歷代志下 6:31; 申命記 5:33; 撒母耳記上 12:24"> 「所以，你們要遵守你們的上帝耶和華的誡命，行祂的道，敬畏祂，</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 11:9–12; 出埃及記 3:8; 以西結書 20:6"> 因為祂要帶你們到一個佳美之地。那裡的谷中和山間流淌著條條溪流、股股清泉；</span>
<span className="v" id="v8" data-v="8" data-xref="約翰福音 6:13; 詩篇 147:14; 申命記 32:14"> 那裡盛產大麥、小麥、葡萄、無花果、石榴、橄欖油和蜂蜜；</span>
<span className="v" id="v9" data-v="9" data-xref="歷代志上 22:14; 申命記 33:25; 約書亞記 22:8"> 那裡食物充足，一無所缺；那裡礦產資源豐富，石頭就是鐵，山中可以採銅。</span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 103:2; 羅馬書 14:6; 箴言 3:9"> 你們吃飽喝足後，要讚美你們的上帝耶和華，因為祂賜給你們那佳美之地。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="詩篇 106:21; 何西阿書 2:8–9; 箴言 1:32"> 「你們要謹慎，免得忘記你們的上帝耶和華，不遵守我今天吩咐你們的誡命、典章和律例。</span>
<span className="v" id="v12" data-v="12" data-xref="箴言 30:9; 申命記 28:47; 申命記 32:15"> 否則，當你們豐衣足食、居室華美、</span>
<span className="v" id="v13" data-v="13" data-xref="約伯記 1:3; 創世記 13:1–5; 路加福音 12:13–21"> 牛羊成群、金銀財物增多的時候，</span>
<span className="v" id="v14" data-v="14" data-xref="詩篇 106:21; 哥林多前書 4:7–8; 申命記 8:11"> 切勿心驕氣傲，忘記你們的上帝耶和華。祂把你們從受奴役之地埃及救出來，</span>
<span className="v" id="v15" data-v="15" data-xref="民數記 21:6; 民數記 20:11; 耶利米書 2:6"> 帶領你們走過乾旱、可怕、毒蛇和蠍子出沒的大曠野。祂使堅硬的磐石流出水來給你們喝，</span>
<span className="v" id="v16" data-v="16" data-xref="申命記 8:3; 雅各書 1:12; 出埃及記 16:15"> 在曠野中把你們祖先從未見過的嗎哪賜給你們吃，為要磨煉你們、考驗你們，使你們最終得到益處。</span>
<span className="v" id="v17" data-v="17" data-xref="申命記 9:4; 哥林多前書 4:7; 但以理書 4:30"> 你們切勿以為是憑自己的雙手和能力致富的。</span>
<span className="v" id="v18" data-v="18" data-xref="箴言 10:22; 何西阿書 2:8; 申命記 7:8"> 要記住，是你們的上帝耶和華賜給你們致富的能力，為要堅立祂給你們祖先的誓約，正如今日的情形。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="申命記 4:26; 撒母耳記上 12:25; 西番雅書 1:18"> 「我今天警告你們，如果你們忘記你們的上帝耶和華，去追隨、供奉、祭拜其他神明，你們必滅亡。</span>
<span className="v" id="v20" data-v="20" data-xref="但以理書 9:11–12; 歷代志下 36:16–17"> 如果你們不聽從你們的上帝耶和華，你們必滅亡，正如祂使列國在你們面前滅亡一樣。</span>
</div>
</div>

## 尼尼微的災禍

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="西番雅書 3:1–3; 哈巴谷書 2:12; 何西阿書 4:2"> <span className="pl pl-1">充滿血腥的尼尼微有禍了！</span><br /><span className="pl pl-1">城中充滿詭詐和掠奪，</span><br /><span className="pl pl-1">害人的事從未止息。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="耶利米書 47:3; 那鴻書 2:3–4; 約伯記 39:22–25"> <span className="pl pl-1">鞭聲啪啪，車輪隆隆，</span><br /><span className="pl pl-1">戰馬奔騰，戰車疾馳，</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="哈巴谷書 3:11; 以西結書 39:4; 以賽亞書 34:3"> <span className="pl pl-1">騎士衝鋒，刀光閃閃，矛槍生輝；</span><br /><span className="pl pl-1">被殺者眾多，屍骨成堆，</span><br /><span className="pl pl-1">人們被遍地的屍體絆倒。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="以賽亞書 47:9; 以賽亞書 47:12–13; 啟示錄 17:1–5"> <span className="pl pl-1">這全是因為尼尼微像妖媚的妓女大肆淫亂，</span><br /><span className="pl pl-1">慣行邪術，</span><br /><span className="pl pl-1">以淫行誘惑列國，</span><br /><span className="pl pl-1">靠邪術欺騙各族。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="耶利米書 13:26; 以西結書 23:29; 耶利米書 13:22"> <span className="pl pl-1">萬軍之耶和華說：</span><br /><span className="pl pl-1">「我與你為敵。</span><br /><span className="pl pl-1">我要把你的衣裙掀到你臉上，</span><br /><span className="pl pl-1">使列國看見你的裸體，</span><br /><span className="pl pl-1">使列邦看見你的羞恥。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="瑪拉基書 2:9; 耶利米書 51:37; 約伯記 9:31"> <span className="pl pl-1">我要把可憎之物拋在你身上，</span><br /><span className="pl pl-1">羞辱你，</span><br /><span className="pl pl-1">讓眾人觀看。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="耶利米書 15:5; 以賽亞書 51:19; 啟示錄 18:10"> <span className="pl pl-1">凡看見你的都要逃避，說，</span><br /><span className="pl pl-1">『尼尼微毀滅了！</span><br /><span className="pl pl-1">誰會為她悲傷呢？』</span><br /><span className="pl pl-1">我到哪裡去尋找安慰你的人呢？」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="阿摩司書 6:2; 以西結書 30:14–16; 耶利米書 46:25–26"> <span className="pl pl-1">你能強過底比斯</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「底比斯」希伯來文是「挪亞們」。">a</a></sup><br /><span className="pl pl-1">嗎？</span><br /><span className="pl pl-1">底比斯位於尼羅河上，</span><br /><span className="pl pl-1">四面環水，</span><br /><span className="pl pl-1">水是她的屏障，</span><br /><span className="pl pl-1">又是她的城牆。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="以西結書 30:5; 以西結書 27:10; 以賽亞書 20:5"> <span className="pl pl-1">古實和埃及是她無窮的力量，</span><br /><span className="pl pl-1">弗人和利比亞人是她的幫手。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="以賽亞書 20:4; 約珥書 3:3; 何西阿書 13:16"> <span className="pl pl-1">可是，她卻被擄去，流落他鄉，</span><br /><span className="pl pl-1">她的嬰孩被摔死在各個街頭。</span><br /><span className="pl pl-1">她的官長被抽籤瓜分，</span><br /><span className="pl pl-1">她所有的首領都被鎖鏈鎖著。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="以賽亞書 49:26; 以賽亞書 2:10; 詩篇 75:8"> <span className="pl pl-1">尼尼微啊，</span><br /><span className="pl pl-1">你也必像醉漢一樣，</span><br /><span className="pl pl-1">你必尋找藏身之處躲避敵人。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="啟示錄 6:13; 以賽亞書 28:4; 哈巴谷書 1:10"> <span className="pl pl-1">你所有的堡壘都像無花果樹上的初熟果子，</span><br /><span className="pl pl-1">一搖樹，果子就掉進吃者口中。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="耶利米書 51:30; 以賽亞書 19:16; 耶利米書 50:37"> <span className="pl pl-1">看啊，</span><br /><span className="pl pl-1">你的軍隊就像柔弱的女人，</span><br /><span className="pl pl-1">你境內的關口向敵人敞開，</span><br /><span className="pl pl-1">你的門閂被火燒毀。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="歷代志下 32:3–4; 那鴻書 2:1; 歷代志下 32:11"> <span className="pl pl-1">你要蓄水以防圍困，</span><br /><span className="pl pl-1">要加強防禦！</span><br /><span className="pl pl-1">要走進土坑踩泥，</span><br /><span className="pl pl-1">拿起磚模造磚！</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="約珥書 1:4; 那鴻書 2:13; 那鴻書 3:13"> <span className="pl pl-1">但在那裡，火要吞噬你，</span><br /><span className="pl pl-1">刀劍要殺戮你，</span><br /><span className="pl pl-1">要像蝗蟲吞沒你。</span><br /><span className="pl pl-1">你只管像蝗蟲一樣繁殖，</span><br /><span className="pl pl-1">如蚱蜢一般增多吧！</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="創世記 22:17; 尼希米記 9:23; 耶利米書 33:22"> <span className="pl pl-1">你的商賈多過天上的繁星，</span><br /><span className="pl pl-1">但他們像吃光田地後飛去的蝗蟲。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="耶利米書 51:27; 啟示錄 9:7"> <span className="pl pl-1">你的臣僕像蝗蟲，</span><br /><span className="pl pl-1">你的將領像成群的蚱蜢。</span><br /><span className="pl pl-1">牠們寒日聚集在牆上，</span><br /><span className="pl pl-1">太陽一出來就飛走了，</span><br /><span className="pl pl-1">無人知道牠們的行蹤。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="列王紀上 22:17; 詩篇 76:5–6; 耶利米書 50:18"> <span className="pl pl-1">亞述王啊！</span><br /><span className="pl pl-1">你的牧人沉睡，貴族酣眠，</span><br /><span className="pl pl-1">你的百姓分散在群山上，</span><br /><span className="pl pl-1">無人招聚他們。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="彌迦書 1:9; 耶利米哀歌 2:15; 約伯記 27:23"> <span className="pl pl-1">你的創傷無法救治，</span><br /><span className="pl pl-1">你的傷勢極其嚴重。</span><br /><span className="pl pl-1">聽見這消息的人必鼓掌歡呼，</span><br /><span className="pl pl-1">因為誰沒受過你無休止的暴虐呢？</span></span>
</div>

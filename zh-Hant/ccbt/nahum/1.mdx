## 耶和華向尼尼微發怒

<div className="bt">
<div className="bp poetry">
<span className="v" id="v2" data-v="2" data-xref="撒迦利亞書 8:2; 出埃及記 20:5; 詩篇 94:1"> <span className="pl pl-1">耶和華是痛恨不貞、施行報應的上帝。</span><br /><span className="pl pl-1">耶和華施行報應，充滿烈怒。</span><br /><span className="pl pl-1">耶和華報應祂的仇敵，向他們發烈怒。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 147:5; 出埃及記 34:6–7; 尼希米記 9:17"> <span className="pl pl-1">耶和華不輕易發怒，大有能力。</span><br /><span className="pl pl-1">耶和華斷不以有罪的為無罪。</span><br /><span className="pl pl-1">祂行走在旋風和暴風中，</span><br /><span className="pl pl-1">雲彩是祂腳下的塵土。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="以賽亞書 33:9; 詩篇 106:9; 詩篇 114:5"> <span className="pl pl-1">祂斥責大海，使大海乾涸；</span><br /><span className="pl pl-1">祂使一切河流枯竭。</span><br /><span className="pl pl-1">巴珊和迦密的草木凋零，</span><br /><span className="pl pl-1">黎巴嫩的鮮花衰殘。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="彌迦書 1:4; 撒母耳記下 22:8; 耶利米書 4:24"> <span className="pl pl-1">在祂面前，群山震動，丘陵消融。</span><br /><span className="pl pl-1">在祂面前，大地隆起，</span><br /><span className="pl pl-1">世界和世上的一切都戰慄。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="耶利米書 10:10; 瑪拉基書 3:2; 申命記 32:22–23"> <span className="pl pl-1">祂發怒，誰能站立？</span><br /><span className="pl pl-1">祂發烈怒，誰能承受？</span><br /><span className="pl pl-1">祂的憤怒如火焰噴湧而出，</span><br /><span className="pl pl-1">磐石在祂面前崩裂。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="約翰福音 10:27; 提摩太後書 2:19; 耶利米哀歌 3:25"> <span className="pl pl-1">耶和華是良善的，</span><br /><span className="pl pl-1">是人患難時的避難所；</span><br /><span className="pl pl-1">祂看顧那些信靠祂的人。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="以賽亞書 28:17; 以賽亞書 8:22; 以西結書 13:13"> <span className="pl pl-1">祂必用滔滔洪水毀滅尼尼微，</span><br /><span className="pl pl-1">把祂的敵人驅逐到黑暗中。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="詩篇 21:11; 箴言 21:30; 詩篇 33:10"> <span className="pl pl-1">尼尼微人啊，</span><br /><span className="pl pl-1">你們為何圖謀抵擋耶和華？</span><br /><span className="pl pl-1">祂要徹底毀滅你們，</span><br /><span className="pl pl-1">無需擊打兩次。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="彌迦書 7:4; 以賽亞書 5:24; 以賽亞書 9:18"> <span className="pl pl-1">你們像糾結的荊棘，</span><br /><span className="pl pl-1">又像酩酊大醉的人，</span><br /><span className="pl pl-1">要如乾稭被火燒盡。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="那鴻書 1:9; 歷代志下 13:7; 列王紀下 18:13–14"> <span className="pl pl-1">你們中間出來一人，</span><br /><span className="pl pl-1">一個邪惡的陰謀者，</span><br /><span className="pl pl-1">圖謀抵擋耶和華。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="以賽亞書 30:19; 約珥書 2:19; 以賽亞書 17:14"> <span className="pl pl-1">耶和華說：</span><br /><span className="pl pl-1">「儘管尼尼微勢力強大、人口眾多，</span><br /><span className="pl pl-1">但必被剷除，化為烏有。</span><br /><span className="pl pl-1">我的子民啊，我使你們受了苦，</span><br /><span className="pl pl-1">但必不再使你們受苦。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="以賽亞書 10:27; 以賽亞書 9:4; 耶利米書 2:20"> <span className="pl pl-1">現在我要打碎他們套在你們頸上的軛，</span><br /><span className="pl pl-1">鬆開你們身上的鎖鏈。」</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="詩篇 109:13; 以賽亞書 46:1–2; 彌迦書 5:13"> <span className="pl pl-1">尼尼微啊，</span><br /><span className="pl pl-1">耶和華已發出有關你的命令：</span><br /><span className="pl pl-1">「你的名不會傳於後世。</span><br /><span className="pl pl-1">我要摧毀你神廟中雕刻和鑄造的偶像。</span><br /><span className="pl pl-1">我要為你掘好墳墓，</span><br /><span className="pl pl-1">因為你毫無用處。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="以賽亞書 52:7; 羅馬書 10:15; 以賽亞書 40:9–10"> <span className="pl pl-1">看啊，</span><br /><span className="pl pl-1">傳喜訊、報平安的人穿山越嶺而來。</span><br /><span className="pl pl-1">猶大啊，</span><br /><span className="pl pl-1">慶祝你的節期，</span><br /><span className="pl pl-1">還你許的願吧！</span><br /><span className="pl pl-1">邪惡之人將不再侵擾你，</span><br /><span className="pl pl-1">他們都將被徹底毀滅。</span></span>

## 唯一的救主

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 22:4; 使徒行傳 6:12; 使徒行傳 23:6–9"> 彼得和約翰向百姓講道的時候，祭司、聖殿護衛長和撒都該人趕來了。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行傳 17:18; 帖撒羅尼迦前書 4:13–14; 使徒行傳 24:14–15"> 他們非常惱怒，因為彼得和約翰在教導百姓，並宣講藉著耶穌死人可以復活。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行傳 5:18; 馬太福音 10:16–17; 使徒行傳 16:19–24"> 於是他們下手捉拿二人，因天色已晚，就把他們扣押了一夜。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行傳 2:41; 哥林多後書 2:14–17; 提摩太後書 2:9–10"> 但有許多聽道的人信了，男人的數目約有五千人。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="使徒行傳 4:8; 馬太福音 27:1–2; 路加福音 20:1"> 第二天，官長、長老和律法教師都聚集在耶路撒冷，</span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 3:2; 約翰福音 18:24; 馬太福音 26:3"> 大祭司亞那，以及該亞法、約翰、亞歷山大和大祭司的許多親族都在場。</span>
<span className="v" id="v7" data-v="7" data-xref="馬太福音 21:23; 馬可福音 11:28; 使徒行傳 5:40"> 他們讓使徒站在當中，質問道：「你們憑什麼權柄、奉誰的名這樣做？」</span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="路加福音 12:11–12; 馬太福音 10:19–20; 使徒行傳 2:4"> 那時彼得被聖靈充滿，對他們說：「各位百姓的官長和長老啊，</span>
<span className="v" id="v9" data-v="9" data-xref="彼得前書 3:15–17; 使徒行傳 3:7; 約翰福音 10:32"> 如果因為那殘疾的乞丐得到醫治這件善事，你們今天來查問我們他是如何痊癒的，</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行傳 5:29–32; 使徒行傳 3:6; 使徒行傳 2:36"> 那麼，你們和所有以色列人都應當知道，他能健康地站在你們面前，全是靠拿撒勒人耶穌基督的名！你們把祂釘在十字架上，但上帝使祂從死裡復活了。</span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 118:22–23; 以賽亞書 28:16; 馬可福音 12:10–12"> <span className="pl pl-1">「『祂是你們工匠丟棄的石頭，</span><br /><span className="pl pl-1">已成了房角石。』</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="詩篇118·22。">a</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="約翰福音 14:6; 哥林多前書 3:11; 約翰福音 3:36"> 除祂以外，別無救主，因為普天之下沒有賜給世人別的名讓我們可以靠著得救！」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="哥林多前書 1:27; 約翰福音 7:15; 馬太福音 11:25"> 在場的人看到彼得和約翰的膽量，又知道他們原是沒有學問的平民百姓，都很驚奇。他們認出這些人跟隨過耶穌，</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行傳 19:36; 使徒行傳 3:8–12; 使徒行傳 4:21"> 又見那個被治好的人站在他們旁邊，便無話可說，</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行傳 26:30–32; 使徒行傳 5:34–42; 馬太福音 5:22"> 只好命令他們離開公會，然後彼此商量說：</span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 21:15; 使徒行傳 6:10; 約翰福音 12:18"> 「我們該怎樣處置這兩個人呢？整個耶路撒冷的居民都知道他們行了一個神蹟，我們無法否認。</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行傳 5:28; 羅馬書 15:18–22; 使徒行傳 5:24"> 然而，為了避免這件事在民間傳得更廣，我們必須警告他們以後不許再奉耶穌的名向任何人傳道。」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="使徒行傳 5:40; 路加福音 24:46–48; 使徒行傳 5:20"> 於是，他們又把使徒召來，嚴禁他們再奉耶穌的名講論或教導。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行傳 5:29; 出埃及記 1:17; 哥林多前書 10:15"> 但彼得和約翰答道：「要我們聽從你們而不聽從上帝，這在上帝看來合理嗎？你們自己決定吧。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行傳 22:15; 耶利米書 20:9; 哥林多前書 9:16–17"> 我們耳聞目睹的，不能不說！」</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行傳 5:26; 馬太福音 21:46; 路加福音 22:2"> 官長實在不知道如何懲治使徒，只好再次恐嚇之後把他們放了，因為百姓都為這個神蹟讚美上帝。</span>
<span className="v" id="v22" data-v="22" data-xref="約翰福音 5:5; 使徒行傳 9:33; 路加福音 13:11"> 在這次神蹟中蒙上帝醫治的那個人已經四十多歲了。</span>
</div>
</div>

## 同心禱告

<div className="bt">
<div className="bp poetry">
<span className="v" id="v23" data-v="23" data-xref="哥林多後書 6:14–17; 使徒行傳 12:11–12; 詩篇 119:63"> 彼得和約翰被釋放之後，就回到自己人那裡，把祭司長和長老的話都告訴大家。</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及記 20:11; 耶利米書 32:17; 尼希米記 9:6"> 大家聽後，一同高聲向上帝禱告說：「主啊，你創造了天地、海洋和其中的萬物。</span>
<span className="v" id="v25" data-v="25" data-xref="詩篇 2:1–6; 使徒行傳 1:16; 使徒行傳 2:30"> 你藉著聖靈感動你的僕人——我們的祖先大衛說，<br /><span className="pl pl-1">「『列國為何咆哮？</span><br /><span className="pl pl-1">萬民為何枉費心機？</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="詩篇 2:2; 啟示錄 17:12–14; 但以理書 9:24"> <span className="pl pl-1">世上的君王一同行動，官長聚集起來，</span><br /><span className="pl pl-1">要抵擋主和祂所膏立的王。』</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="詩篇2·1、2。">b</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="馬太福音 27:2; 使徒行傳 4:30; 路加福音 9:22"> 「果然如此，希律和本丟·彼拉多、外族人和以色列人都聚集在這城裡，要對抗你膏立的聖僕耶穌，</span>
<span className="v" id="v28" data-v="28" data-xref="使徒行傳 2:23; 以賽亞書 46:10; 創世記 50:20"> 然而他們只不過是成就你憑自己的大能和旨意所預定的事。</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行傳 4:13; 使徒行傳 14:3; 腓立比書 1:14"> 主啊，你看他們這樣恐嚇我們，求你幫助你的奴僕們坦然無懼地傳你的道。</span>
<span className="v" id="v30" data-v="30" data-xref="使徒行傳 4:27; 使徒行傳 3:6; 使徒行傳 5:12"> 求你伸出手醫治疾病，藉著你聖僕耶穌的名行神蹟奇事。」</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="馬太福音 21:22; 使徒行傳 2:2; 使徒行傳 2:4"> 禱告完後，聚會的地方震動起來，他們都被聖靈充滿，放膽傳揚上帝的道。</span>
</div>
</div>

## 共用一切

<div className="bt">
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="哥林多前書 1:10; 以弗所書 4:2–6; 彼得前書 3:8"> 當時所有信徒都同心合意，共用所有的東西，沒有人說他的財物只屬於自己。</span>
<span className="v" id="v33" data-v="33" data-xref="約翰福音 1:16; 使徒行傳 1:22; 使徒行傳 1:8"> 使徒充滿能力，繼續為主耶穌復活的事作見證，上帝也賜下極大的恩典給眾人。</span>
<span className="v" id="v34" data-v="34" data-xref="使徒行傳 2:45; 路加福音 12:33; 路加福音 16:9"> 信徒都一無所缺，因為大家賣掉房屋田產，把所得的錢拿來，</span>
<span className="v" id="v35" data-v="35" data-xref="使徒行傳 5:2; 使徒行傳 2:45; 哥林多後書 8:20–21"> 放在使徒腳前，按照各人的需要分給大家。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="加拉太書 2:9; 加拉太書 2:13; 加拉太書 2:1"> 有個生在塞浦路斯的利未人名叫約瑟，使徒叫他巴拿巴，意思是勸慰者。</span>
<span className="v" id="v37" data-v="37" data-xref="使徒行傳 5:1–2; 使徒行傳 4:34–35; 馬太福音 19:29"> 他賣掉自己的一塊田，把賣得的錢交給了使徒。</span>
</div>
</div>

## 彼得醫治瘸腿的乞丐

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="詩篇 55:17; 使徒行傳 10:3; 使徒行傳 4:13"> 一天，在下午三點禱告的時間，彼得和約翰去聖殿。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行傳 14:8; 約翰福音 9:8; 路加福音 16:20"> 有一個生來瘸腿的人天天被人抬到聖殿美門的外面，向進殿的人乞討。</span>
<span className="v" id="v3" data-v="3"> 他看見彼得和約翰要進殿，就求他們施捨。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行傳 14:9–10; 約翰福音 11:40; 路加福音 4:20"> 二人定睛看他，彼得說：「看著我們！」</span>
<span className="v" id="v5" data-v="5"> 那人就緊盯著他們，指望得些什麼。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行傳 3:16; 使徒行傳 10:38; 使徒行傳 4:10"> 彼得說：「金子、銀子我都沒有，但是我把我有的給你。我奉拿撒勒人耶穌基督的名，命令你起來行走！」</span>
<span className="v" id="v7" data-v="7" data-xref="馬可福音 1:31; 馬可福音 9:27; 使徒行傳 9:41"> 彼得拉著他的右手扶他起來，那人的雙腳和踝骨立刻變得強壯有力。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行傳 14:10; 以賽亞書 35:6; 詩篇 107:20–22"> 他跳了起來，站穩後開始行走，跟著彼得和約翰進入聖殿，走著跳著讚美上帝。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行傳 4:21; 使徒行傳 4:16; 路加福音 13:17"> 大家看見他一邊走一邊讚美上帝，</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行傳 3:2; 約翰福音 5:20; 約翰福音 9:3"> 認出他就是那個坐在聖殿美門外面的乞丐，都為發生在他身上的事而感到驚奇、詫異。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行傳 5:12; 約翰福音 10:23; 路加福音 8:38"> 那乞丐在所羅門廊下正緊緊拉著彼得和約翰的時候，眾人都跑過來，大為驚奇。</span>
</div>
</div>

## 彼得傳揚基督

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="哥林多後書 3:5; 約翰福音 3:27–28; 但以理書 2:28–30"> 彼得看見這情形，就對大家說：「以色列人啊，何必驚奇呢？為什麼一直盯著我們呢？你們以為我們是憑自己的能力和虔誠叫這人行走嗎？</span>
<span className="v" id="v13" data-v="13" data-xref="馬太福音 22:32; 使徒行傳 7:32; 馬太福音 27:17–25"> 亞伯拉罕的上帝，以撒的上帝，雅各的上帝，就是我們祖先的上帝，已經使祂的僕人耶穌得了榮耀。你們把耶穌交給彼拉多，儘管彼拉多想釋放祂，你們卻在彼拉多面前棄絕祂！</span>
<span className="v" id="v14" data-v="14" data-xref="馬可福音 1:24; 使徒行傳 7:52; 彼得前書 3:18"> 你們棄絕了那聖潔公義者，竟然要求彼拉多給你們釋放一個兇手。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行傳 2:24; 啟示錄 21:6; 使徒行傳 2:32"> 你們殺了生命之主，上帝卻使祂從死裡復活了。我們都是這事的見證人。</span>
<span className="v" id="v16" data-v="16" data-xref="馬太福音 21:21–22; 使徒行傳 4:10; 使徒行傳 14:9"> 你們認識的這個乞丐因為相信耶穌的名，得到了醫治。你們都看見了，他能痊癒是因為他信耶穌。</span>
<span className="v" id="v17" data-v="17" data-xref="路加福音 23:34; 使徒行傳 13:27; 約翰福音 16:3"> 「弟兄們，我知道你們的所作所為是出於無知，你們的官長也是一樣。</span>
<span className="v" id="v18" data-v="18" data-xref="以賽亞書 53:1–12; 使徒行傳 26:22–23; 使徒行傳 2:23"> 但是上帝早已藉眾先知預言基督要受害，這事果然應驗了。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行傳 2:38; 以賽亞書 44:22; 以賽亞書 43:25"> 所以你們要悔改，歸向上帝，祂將除去你們的罪惡，</span>
<span className="v" id="v20" data-v="20" data-xref="馬太福音 24:30–36; 啟示錄 19:11–16; 帖撒羅尼迦後書 2:2"> 賜給你們煥然一新的日子，也將差遣祂預先為你們選立的基督耶穌降臨。</span>
<span className="v" id="v21" data-v="21" data-xref="羅馬書 8:21; 以賽亞書 1:26; 使徒行傳 1:11"> 基督必須留在天上，直到萬物更新的時候，這是上帝自古以來藉聖先知的口說的。</span>
<span className="v" id="v22" data-v="22" data-xref="申命記 18:15–19; 使徒行傳 7:37; 加拉太書 4:4"> 摩西曾經說，『主——你們的上帝要在你們中間興起一位像我一樣的先知。你們要留心聽祂說的一切話，</span>
<span className="v" id="v23" data-v="23" data-xref="申命記 18:19; 約翰福音 12:48; 希伯來書 10:28–30"> 凡不聽的，必從民中被徹底剷除。』<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="申命記18·15、18、19。">a</a></sup></span>
<span className="v" id="v24" data-v="24" data-xref="使徒行傳 3:21; 路加福音 24:27; 撒母耳記上 3:20"> 「從撒母耳到後來的所有先知都宣告過這些日子。</span>
<span className="v" id="v25" data-v="25" data-xref="創世記 22:18; 加拉太書 3:8; 使徒行傳 2:39"> 你們是先知的子孫，也繼承了上帝和你們祖先所立的約。上帝曾對亞伯拉罕說，『天下萬族必因你的後裔而蒙福。』<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="創世記22·18；26·4。">b</a></sup></span>
<span className="v" id="v26" data-v="26" data-xref="馬太福音 1:21; 使徒行傳 3:22; 猶大書 1:24"> 上帝興起祂的僕人，首先差遣祂到你們中間賜福給你們，使你們每個人都脫離罪惡。」</span>
</div>
</div>

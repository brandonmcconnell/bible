## 保羅在以弗所傳道

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行傳 18:23–28; 哥林多前書 16:12; 哥林多前書 1:12"> 當亞波羅在哥林多時，保羅已取道內陸重回以弗所，在那裡遇見幾個門徒。</span>
<span className="v" id="v2" data-v="2" data-xref="約翰福音 7:39; 使徒行傳 11:15–17; 加拉太書 3:5"> 保羅問他們：「你們信的時候有沒有領受聖靈？」 他們說：「沒有！我們甚至都沒有聽過有聖靈。」</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行傳 18:25; 哥林多前書 12:13; 使徒行傳 8:16"> 保羅說：「那麼，你們受的是什麼洗禮呢？」 他們說：「是約翰的洗禮。」</span>
<span className="v" id="v4" data-v="4" data-xref="約翰福音 1:29–34; 使徒行傳 11:16; 使徒行傳 1:5"> 保羅說：「約翰的洗禮是悔改的洗禮，他告訴百姓要信在他以後來的那一位，就是耶穌。」</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行傳 8:12; 使徒行傳 8:16; 羅馬書 6:3–4"> 他們聽後，立刻奉主耶穌的名受了洗。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行傳 6:6; 使徒行傳 2:4; 馬可福音 16:17"> 保羅把手按在他們身上時，聖靈便降在他們身上，他們就說方言，講預言。</span>
<span className="v" id="v7" data-v="7"> 他們約有十二個人。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行傳 28:23; 使徒行傳 1:3; 使徒行傳 9:20–22"> 保羅一連三個月勇敢地在會堂裡傳道，與人辯論上帝國的事，勸導他們。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行傳 19:23; 使徒行傳 9:2; 使徒行傳 18:6–8"> 可是有些人仍然硬著心不信，還當眾毀謗主的道。保羅便帶著門徒離開他們，天天在推喇奴的學堂講論。</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行傳 20:31; 提摩太後書 1:15; 使徒行傳 16:6"> 這樣持續了兩年，亞細亞所有的居民，無論是猶太人還是希臘人，都聽見了主的道。</span>
<span className="v" id="v11" data-v="11" data-xref="馬可福音 16:17–20; 使徒行傳 5:12; 羅馬書 15:18–19"> 上帝又藉著保羅的手行了一些非凡的神蹟，</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行傳 5:15; 列王紀下 13:20–21; 馬可福音 16:17"> 甚至只要將保羅身上的手帕或圍裙放在病人身上，病人就痊癒了，邪靈也會離開所附的人。</span>
<span className="v" id="v13" data-v="13" data-xref="馬太福音 12:27; 馬可福音 9:38; 路加福音 11:19"> 那時，有幾個走江湖的猶太術士也想用耶穌的名趕鬼，他們向那些被邪靈附身的人說：「我奉保羅所傳講的耶穌之名，命令你們出來！」</span>
<span className="v" id="v14" data-v="14"> 做這事的有猶太祭司長士基瓦的七個兒子。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行傳 16:17–18; 路加福音 4:33–35; 馬可福音 1:34"> 邪靈回答說：「耶穌，我認識；保羅，我也知道。但你們是誰？」</span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 8:29; 馬可福音 5:3–4; 馬可福音 5:15"> 被邪靈附身的人隨即撲向他們，攻擊他們，制伏了他們，使他們赤著身子帶著傷從屋裡逃走了。</span>
<span className="v" id="v17" data-v="17" data-xref="帖撒羅尼迦後書 1:12; 使徒行傳 5:5; 腓立比書 2:9–11"> 住在以弗所的猶太人和希臘人知道了這件事，都驚懼不已。主耶穌的名因此大受尊崇。</span>
<span className="v" id="v18" data-v="18" data-xref="羅馬書 10:10; 詩篇 32:5; 馬太福音 3:6"> 許多已經信耶穌的人都前來認罪，公開承認自己的惡行。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行傳 13:8; 出埃及記 32:20; 創世記 35:4"> 又有許多行邪術的人把他們的書堆在一起，當眾焚燒。根據當時的估價，這些書約值五萬銀幣。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行傳 12:24; 使徒行傳 6:7; 以賽亞書 55:11"> 主的道就這樣傳開了，大大興旺起來。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行傳 20:22; 使徒行傳 20:16; 使徒行傳 23:11"> 這些事以後，保羅決定經過馬其頓和亞該亞回到耶路撒冷。他說：「到了那裡之後，我必須去羅馬看看。」</span>
<span className="v" id="v22" data-v="22" data-xref="羅馬書 16:23; 提摩太後書 4:20; 使徒行傳 16:3"> 於是，他派提摩太和以拉都兩位同工先去馬其頓，自己暫時留在亞細亞。</span>
</div>

## 以弗所的騷亂

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="使徒行傳 19:9; 使徒行傳 24:22; 哥林多後書 1:8–10"> 就在這時，由於主的道，以弗所起了很大的騷亂。</span>
<span className="v" id="v24" data-v="24" data-xref="提摩太前書 6:9–10; 使徒行傳 16:16; 使徒行傳 16:19"> 一個名叫底米丟的銀匠以製造亞底米女神銀龕為業，使從事這門生意的工匠獲利豐厚。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行傳 16:19; 何西阿書 12:7–8; 啟示錄 18:11–19"> 他召集了工匠和同行的人，說：「各位都知道我們靠這一行發財，</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行傳 17:29; 哥林多前書 8:4; 以賽亞書 44:10–20"> 可是你們都耳聞目睹了那個保羅在以弗所和亞細亞全境說服、誤導了許多人，說什麼人手所造的不是神。</span>
<span className="v" id="v27" data-v="27" data-xref="西番雅書 2:11; 提摩太前書 6:5; 馬太福音 23:13"> 這樣下去，不但我們的行業會遭人貶抑，連亞底米女神廟也會被人輕看，甚至全亞細亞及普世尊崇的女神也會威嚴掃地！」</span>
<span className="v" id="v28" data-v="28" data-xref="啟示錄 13:4; 啟示錄 17:13; 使徒行傳 16:19–24"> 眾人聽後，怒氣填胸，高聲喊叫：「以弗所人的亞底米真偉大！」</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行傳 20:4; 歌羅西書 4:10; 使徒行傳 27:2"> 全城陷入一片混亂。眾人抓住保羅的兩個同伴馬其頓人該猶和亞里達古，拖著他們衝進戲院。</span>
<span className="v" id="v30" data-v="30" data-xref="使徒行傳 21:39; 撒母耳記下 18:2–3; 使徒行傳 17:22–31"> 保羅想進去，但門徒不許他去。</span>
<span className="v" id="v31" data-v="31" data-xref="使徒行傳 19:10; 使徒行傳 21:12; 使徒行傳 16:6"> 他的好友——亞細亞的幾位官員也派人勸他別冒險進入戲院。</span>
<span className="v" id="v32" data-v="32" data-xref="使徒行傳 21:34; 使徒行傳 19:40; 馬太福音 11:7–9"> 這時，戲院裡面有人這樣喊，有人那樣喊，混亂不堪。其實大部分人根本不知道自己為什麼聚在那裡。</span>
<span className="v" id="v33" data-v="33" data-xref="使徒行傳 12:17; 提摩太後書 4:14; 提摩太前書 1:20"> 這時，人群中的猶太人把亞歷山大推到前面，請他解釋。亞歷山大舉手示意大家安靜，聽他發言。</span>
<span className="v" id="v34" data-v="34" data-xref="使徒行傳 19:28; 馬太福音 6:7; 啟示錄 13:4"> 但眾人認出他是個猶太人，便又開始一起高呼：「以弗所人的亞底米真偉大！」這樣喊了大約兩個小時。</span>
<span className="v" id="v35" data-v="35" data-xref="帖撒羅尼迦後書 2:10–11; 提摩太前書 4:2; 以弗所書 2:12"> 最後，城裡的書記官使民眾安靜下來，說：「各位以弗所市民，誰不知道以弗所城守護著亞底米神廟和從宙斯那裡掉下來的神像呢？</span>
<span className="v" id="v36" data-v="36" data-xref="箴言 14:29; 使徒行傳 5:35–39; 箴言 25:8"> 既然這是無可否認的事實，你們就該安靜，不可魯莽行事。</span>
<span className="v" id="v37" data-v="37" data-xref="哥林多後書 6:3; 羅馬書 2:22; 使徒行傳 25:8"> 你們帶來的這些人既沒有偷廟裡的東西，也沒有褻瀆我們的女神。</span>
<span className="v" id="v38" data-v="38" data-xref="使徒行傳 13:7; 哥林多前書 6:1; 使徒行傳 18:14"> 底米丟和他的同行如果要控告誰，大可到法庭或總督那裡提出訴訟。</span>
<span className="v" id="v39" data-v="39"> 你們若還有其他要求，也可以通過合法的會議解決。</span>
<span className="v" id="v40" data-v="40" data-xref="使徒行傳 17:5–8; 馬太福音 26:5; 使徒行傳 20:1"> 今天的騷亂實在沒有道理，難免會被查問，到時候我們很難交代。」</span>
<span className="v" id="v41" data-v="41" data-xref="傳道書 9:17; 詩篇 65:7; 哥林多後書 1:8–10"> 說完，便叫眾人散去。</span>

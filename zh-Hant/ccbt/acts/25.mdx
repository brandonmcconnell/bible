## 保羅在非斯都面前申辯

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行傳 23:34; 使徒行傳 25:5; 使徒行傳 8:40"> 非斯都上任三天後，便從凱撒利亞啟程上耶路撒冷。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行傳 25:15; 箴言 4:16; 使徒行傳 24:1"> 祭司長和猶太人的首領向他控告保羅，</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行傳 9:24; 使徒行傳 23:12–15; 撒母耳記上 23:19–21"> 懇求他將保羅押回耶路撒冷，他們想在路上埋伏殺害保羅。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行傳 24:23"> 非斯都卻說：「保羅現在關押在凱撒利亞，我很快會回到那裡。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行傳 25:25; 約翰福音 18:29–30; 使徒行傳 25:18–19"> 讓你們的首領跟我一起去吧，如果那人有什麼過犯，可以在那裡告他。」</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行傳 25:17; 使徒行傳 25:10; 馬太福音 27:19"> 非斯都在耶路撒冷只逗留了十天八天，便返回了凱撒利亞。第二天，他開庭審訊，命人將保羅帶上來。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行傳 24:13; 路加福音 23:10; 使徒行傳 25:24"> 保羅被帶來後，那些從耶路撒冷下來的猶太人站在他周圍，控告他犯了許多重罪，但是都沒有證據。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行傳 24:12; 使徒行傳 28:17; 哥林多後書 1:12"> 保羅為自己辯護說：「我從來沒有違背猶太律法、褻瀆聖殿或反叛凱撒！」</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行傳 24:27; 使徒行傳 12:3; 使徒行傳 25:20"> 非斯都為了討好猶太人，就對保羅說：「你是否願意回耶路撒冷接受我的審訊？」</span>
<span className="v" id="v10" data-v="10" data-xref="馬太福音 27:18; 哥林多後書 4:2; 使徒行傳 28:18"> 保羅說：「我此刻正站在凱撒的法庭上，這就是我應該受審的地方。你很清楚，我並沒有做過什麼對不起猶太人的事。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行傳 28:19; 使徒行傳 26:32; 使徒行傳 25:25"> 我如果做錯了，犯了該死的罪，決不逃避！但他們對我的控告毫無根據，誰也不能把我交給他們。我要向凱撒上訴！」</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行傳 19:21; 腓立比書 1:12–14; 腓立比書 1:20"> 非斯都和議會商討後，說：「你說要上訴凱撒，就去見凱撒吧！」</span>
</div>
</div>

## 非斯都請教亞基帕王

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="使徒行傳 8:40; 使徒行傳 26:1; 使徒行傳 26:27–28"> 過了幾天，亞基帕王和百妮姬一起到凱撒利亞問候非斯都。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行傳 24:27"> 他們在那裡住了多日，非斯都對王提起保羅的案子，說：「我這裡有一個囚犯，是腓利斯留下來的。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行傳 25:1–3; 以斯帖記 3:9; 路加福音 18:3–5"> 上次我去耶路撒冷的時候，猶太人的祭司長和長老控告他，要求我定他的罪。</span>
<span className="v" id="v16" data-v="16" data-xref="約翰福音 7:51; 申命記 19:17–18; 使徒行傳 23:30"> 我告訴他們，按照羅馬人的規矩，被告還沒有跟原告對質和自辯之前，不能定他的罪。</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行傳 25:6; 使徒行傳 25:10"> 後來他們跟我一起來到這裡，我沒有耽誤，第二天就開庭，吩咐把那人帶出來審訊。</span>
<span className="v" id="v18" data-v="18"> 他們都站起來當面控告他，但所告的並非我料想的罪行，</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行傳 23:29; 使徒行傳 18:15; 哥林多前書 15:3–4"> 不過是關於他們的宗教和一個叫耶穌的人的一些爭論。耶穌已經死了，保羅卻說他仍然活著。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行傳 25:9"> 我不知如何審理這些事情，就問被告是否願意上耶路撒冷受審。</span>
<span className="v" id="v21" data-v="21" data-xref="提摩太後書 4:16; 路加福音 2:1; 使徒行傳 25:10–11"> 但保羅請求留下來，聽皇帝定奪，所以我下令仍然扣押他，等著送交凱撒。」</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行傳 9:15; 馬太福音 10:18; 以賽亞書 52:15"> 亞基帕對非斯都說：「我想親自聽聽他的申訴。」 非斯都說：「你明天就會聽到。」</span>
<span className="v" id="v23" data-v="23" data-xref="使徒行傳 26:30; 使徒行傳 25:13; 約翰一書 2:16"> 第二天，亞基帕和百妮姬在眾千夫長和城中達官貴人的陪同下，聲勢浩大地進了法庭。非斯都下令把保羅帶上來後，</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行傳 22:22; 使徒行傳 25:7; 使徒行傳 25:2–3"> 說：「亞基帕王和在座的各位，你們看，就是這個人，所有的猶太人，不管是在這裡還是耶路撒冷，都高聲呼籲我處死他。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行傳 23:29; 使徒行傳 25:11–12; 路加福音 23:4"> 但我發現他並沒有犯什麼該死的罪。既然他要向皇帝上訴，我決定把他押去。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行傳 26:2–3"> 只是關於這個人，我沒有確切的事由可以奏明皇帝<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="希臘文是「主上」，用於對羅馬皇帝的尊稱。">a</a></sup>。所以，我把他帶到各位面前，特別是亞基帕王面前，以便在審訊之後，我可以有所陳奏。</span>
<span className="v" id="v27" data-v="27" data-xref="約翰福音 7:51; 箴言 18:13"> 因為在我看來，解送犯人卻不奏明罪狀不合情理。」</span>
</div>
</div>

## 應許聖靈降臨

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 1:3; 路加福音 24:19; 馬太福音 4:23–24"> 提阿非羅啊，在前一封信中，我從耶穌的生平和教導開始，</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行傳 1:9; 約翰福音 20:21; 以賽亞書 59:20–21"> 一直談到祂藉著聖靈吩咐了自己所選立的使徒，然後被接回天上。</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多前書 15:5–7; 使徒行傳 13:31; 約翰福音 20:26"> 祂受難後用許多確據向使徒顯明自己活著，在四十天之內屢次向他們顯現，並談論上帝的國。</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 24:49; 約翰福音 14:16; 約翰福音 15:26"> 有一次，耶穌和他們在一起吃飯的時候，叮囑他們：「你們不要離開耶路撒冷，要在那裡等候我對你們說過的天父的應許。</span>
<span className="v" id="v5" data-v="5" data-xref="馬太福音 3:11; 使徒行傳 11:15–16; 路加福音 3:16"> 因為從前約翰用水施洗，但過不了多少天，你們要受聖靈的洗。」</span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 19:11; 路加福音 17:20; 但以理書 7:27"> 他們跟耶穌在一起的時候問祂：「主啊，你要在這時候復興以色列國嗎？」</span>
<span className="v" id="v7" data-v="7" data-xref="馬太福音 24:36; 帖撒羅尼迦前書 5:1–2; 馬可福音 13:32"> 耶穌回答說：「天父照自己的權柄定下的時間、日期不是你們可以知道的。</span>
<span className="v" id="v8" data-v="8" data-xref="馬太福音 28:19; 馬可福音 16:15; 羅馬書 15:19"> 但聖靈降臨在你們身上後，你們必得到能力，在耶路撒冷、猶太全境和撒瑪利亞，直到地極，作我的見證人。」</span>
<span className="v" id="v9" data-v="9" data-xref="但以理書 7:13; 路加福音 24:50–51; 馬可福音 16:19"> 耶穌說完這些話，就在他們注視下被提升天，被一朵雲彩接去，離開了他們的視線。</span>
<span className="v" id="v10" data-v="10" data-xref="路加福音 24:4; 約翰福音 20:12; 啟示錄 7:14"> 祂上升時，他們都定睛望著天空，忽然有兩個身穿白衣的人站在他們身旁，</span>
<span className="v" id="v11" data-v="11" data-xref="啟示錄 1:7; 帖撒羅尼迦前書 4:16; 馬可福音 13:26"> 說：「加利利人啊！你們為什麼站在這裡望著天空呢？這位離開你們被接到天上的耶穌，你們看見祂怎樣升天，將來祂還要怎樣回來。」</span>
</div>
</div>

## 選立新使徒

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="路加福音 24:52; 馬太福音 21:1; 路加福音 24:50"> 於是，他們從橄欖山回到耶路撒冷。橄欖山距離耶路撒冷不遠，約是安息日允許走的路程<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="按猶太人的傳統，在安息日只能走約一公里遠。">a</a></sup>。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行傳 20:8; 路加福音 22:12; 馬可福音 14:15"> 他們進城後，來到樓上所住的房間。當時有彼得、約翰、雅各、安得烈、腓力、多馬、巴多羅買、馬太、亞勒腓的兒子雅各、激進黨人西門、雅各的兒子猶大。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行傳 6:4; 以弗所書 6:18; 歌羅西書 4:2"> 他們同幾個婦女，以及耶穌的弟弟們和母親瑪麗亞在一起同心合意地恆切禱告。</span>
<span className="v" id="v15" data-v="15" data-xref="哥林多前書 15:6; 使徒行傳 21:20; 啟示錄 3:4"> 那時，約有一百二十人在聚會，彼得從他們當中站起來說：</span>
<span className="v" id="v16" data-v="16" data-xref="詩篇 41:9; 約翰福音 13:18; 詩篇 55:12–15"> 「弟兄們，關於帶人抓耶穌的猶大，聖靈藉著大衛的口早已預言，這經文必須要應驗。</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行傳 1:25; 馬可福音 3:19; 約翰福音 17:12"> 猶大原本是我們中間的一員，與我們同擔使徒的職分。」</span>
<span className="v" id="v18" data-v="18" data-xref="馬太福音 27:3–10; 馬太福音 26:14–15; 詩篇 55:23"> 他用作惡得來的錢買了一塊田，他頭朝下栽倒在地，肚破腸流。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行傳 2:22; 馬太福音 28:15; 使徒行傳 21:40"> 這消息很快傳遍了耶路撒冷，當地人稱那塊田為「亞革大馬」，就是「血田」的意思。</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 69:25; 詩篇 109:8–15; 使徒行傳 1:25"> 彼得繼續說：「詩篇上寫道，『願他的家園一片荒涼，無人居住』<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="詩篇69·25。">b</a></sup>，又說，『願別人取代他的職位。』<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="詩篇109·8。">c</a></sup></span>
<span className="v" id="v21" data-v="21" data-xref="約翰福音 15:27; 路加福音 10:1–2; 民數記 27:17"> 所以，我們必須另選一個人代替猶大，與我們一同為主耶穌的復活作見證。他必須是從主耶穌接受約翰的洗禮起一直到主升天，始終與我們在一起的人。」</span>
<span className="v" id="v23" data-v="23" data-xref="使徒行傳 15:22; 使徒行傳 1:26"> 於是他們推薦兩個人：別號巴撒巴又叫猶士都的約瑟和馬提亞。</span>
<span className="v" id="v24" data-v="24" data-xref="撒母耳記上 16:7; 使徒行傳 15:8; 希伯來書 4:13"> 大家便禱告說：「主啊！你洞悉每個人的內心，求你指明這二人中你選了誰來擔負使徒的職分。猶大丟棄了這職分，去了他該去的地方。」</span>
<span className="v" id="v26" data-v="26" data-xref="利未記 16:8; 約書亞記 18:10; 撒母耳記上 14:41–42"> 然後，他們抽籤，抽中了馬提亞，就把他加到十一位使徒的行列。</span>
</div>
</div>

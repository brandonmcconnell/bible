## 耶路撒冷會議

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="加拉太書 5:6; 使徒行傳 15:5; 利未記 12:3"> 有幾個從猶太下來的人教導弟兄們說：「你們若不照著摩西的規條接受割禮，就不能得救。」</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行傳 15:22–23; 使徒行傳 15:6–7; 加拉太書 2:1–2"> 保羅和巴拿巴為這件事與他們激烈地辯論，最後大家決定派保羅、巴拿巴和幾個當地的信徒上耶路撒冷去跟使徒和長老討論這件事。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行傳 14:27; 使徒行傳 21:5; 哥林多前書 16:11"> 於是教會為他們送行。他們經過腓尼基和撒瑪利亞，沿途詳述外族人悔改信主的消息，使弟兄姊妹大為歡喜。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行傳 14:27; 使徒行傳 15:12; 使徒行傳 15:3"> 他們到了耶路撒冷，受到教會、使徒和長老的接待，並報告了上帝藉他們所做的一切事。</span>
<span className="v" id="v5" data-v="5" data-xref="加拉太書 5:1–3; 腓立比書 3:5–8; 使徒行傳 15:1"> 有幾個信了主的法利賽人站起來說：「外族的信徒必須接受割禮，而且還要遵守摩西的律法。」</span>
<span className="v" id="v6" data-v="6" data-xref="箴言 15:22; 希伯來書 13:7; 希伯來書 13:17"> 使徒和長老們聚集商議這個問題。</span>
<span className="v" id="v7" data-v="7" data-xref="羅馬書 10:17–18; 加拉太書 2:7–9; 歷代志上 28:4–5"> 經過許多辯論之後，彼得站起來對大家說：「弟兄們，你們都知道，上帝早已在你們當中揀選我去向外族人傳道，讓他們也可以聽到福音並信主。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行傳 1:24; 使徒行傳 10:47; 使徒行傳 14:3"> 洞悉人心的上帝把聖靈賜給他們，正如賜給我們一樣，以表明祂也接納外族人。</span>
<span className="v" id="v9" data-v="9" data-xref="以弗所書 3:6; 加拉太書 5:6; 使徒行傳 10:28"> 上帝對他們和我們一視同仁，祂藉著他們的信心潔淨了他們的心靈。</span>
<span className="v" id="v10" data-v="10" data-xref="加拉太書 5:1; 馬太福音 23:4; 加拉太書 4:9"> 現在你們為什麼要試探上帝，把我們祖先和我們不能負的軛強加在這些門徒肩上？</span>
<span className="v" id="v11" data-v="11" data-xref="羅馬書 3:24; 提多書 3:4–7; 提多書 2:11"> 我們相信，他們和我們一樣都是靠主耶穌的恩典得救。」</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行傳 14:27; 使徒行傳 15:4; 使徒行傳 21:19"> 眾人都沉默不語，繼續聽巴拿巴和保羅訴說上帝藉著他們在外族人中所行的神蹟奇事。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行傳 12:17; 加拉太書 2:12; 雅各書 1:1"> 他們報告完了，雅各站起來說：「弟兄們，請聽我說。</span>
<span className="v" id="v14" data-v="14" data-xref="彼得後書 1:1; 使徒行傳 15:7–9; 路加福音 2:31–32"> 剛才西門講述了上帝當初如何眷顧外族人，從他們當中揀選人歸在祂的名下。</span>
<span className="v" id="v15" data-v="15" data-xref="羅馬書 15:8–12; 使徒行傳 13:47"> 這完全與眾先知的話相符，正如聖經上說，</span>
<span className="v" id="v16" data-v="16" data-xref="阿摩司書 9:11–12; 詩篇 89:35–49; 路加福音 1:31–33"> <span className="pl pl-1">「『此後，我要回來重建已傾覆的大衛家，</span><br /><span className="pl pl-1">從廢墟中重建它、恢復它，</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="撒迦利亞書 2:11; 撒迦利亞書 8:20–23; 以賽亞書 65:1"> <span className="pl pl-1">好叫其餘的百姓，</span><br /><span className="pl pl-1">就是凡歸在我名下的外族人都尋求主。』</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="阿摩司書9·11、12。">a</a></sup>這是主說的，</span>
<span className="v" id="v18" data-v="18" data-xref="以弗所書 1:4; 以弗所書 3:9; 以賽亞書 46:9–10"> 祂從亙古就顯明了這事。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行傳 15:28; 加拉太書 1:7–10; 使徒行傳 15:24"> 「所以，我認為不應該為難那些信上帝的外族人。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行傳 15:29; 啟示錄 2:20; 利未記 3:17"> 我們只需寫信吩咐他們遠避被偶像玷污之物，不可淫亂，不可吃勒死的牲畜和血。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行傳 13:15; 使徒行傳 13:27; 哥林多後書 3:14–15"> 因為自古以來，在各城都有人宣講摩西的律法，每逢安息日，都有人在會堂裡誦讀。」</span>
</div>
</div>

## 給外族信徒的信

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="使徒行傳 15:27; 使徒行傳 15:40; 帖撒羅尼迦前書 1:1"> 最後，使徒、長老和全教會都決定從他們當中選派代表，隨保羅和巴拿巴去安提阿。他們選了別號巴撒巴的猶大和西拉，這兩位都是教會的領袖。</span>
<span className="v" id="v23" data-v="23" data-xref="使徒行傳 23:26; 雅各書 1:1; 加拉太書 1:21"> 他們帶去的書信這樣說：「安提阿、敘利亞和基利迦的外族弟兄姊妹，你們的弟兄——眾使徒和長老向你們問安！</span>
<span className="v" id="v24" data-v="24" data-xref="加拉太書 5:12; 加拉太書 5:10; 使徒行傳 15:1"> 「聽說有幾個人從我們這裡去了你們那裡，<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有古卷此處有「教導你們必須接受割禮並遵守摩西的律法。」">b</a></sup>他們的教導使你們困惑不安。其實我們從來沒有授權他們這樣做。</span>
<span className="v" id="v25" data-v="25" data-xref="彼得後書 3:15; 使徒行傳 1:14; 使徒行傳 15:2"> 所以我們一致決定選派代表，隨我們敬愛的巴拿巴和保羅去你們那裡。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行傳 14:19; 使徒行傳 9:23–25; 腓立比書 2:29–30"> 他們二人為我們主耶穌基督的名已將生死置之度外。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行傳 15:22; 使徒行傳 15:32; 約翰三書 1:13"> 我們差派猶大和西拉去向你們報告我們的決定。</span>
<span className="v" id="v28" data-v="28" data-xref="約翰福音 16:13; 啟示錄 2:24; 馬太福音 11:30"> 因為聖靈和我們都認為不應把額外的重擔加在你們身上。但請務必注意以下幾件事：</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行傳 15:20; 使徒行傳 21:25; 啟示錄 2:14"> 要遠避祭拜偶像的事，不可吃血，不可吃勒死的牲畜，不可淫亂。你們一一遵守這些事才好。祝平安！」</span>
<span className="v" id="v30" data-v="30" data-xref="使徒行傳 16:4; 使徒行傳 6:2; 使徒行傳 23:33"> 他們奉命下到安提阿，召集眾人，交付書信。</span>
<span className="v" id="v31" data-v="31" data-xref="加拉太書 2:4–5; 腓立比書 3:3; 加拉太書 5:1"> 眾人讀過這封信之後，都因信中勸勉的話而歡喜。</span>
<span className="v" id="v32" data-v="32" data-xref="使徒行傳 11:23; 使徒行傳 14:22; 使徒行傳 13:1"> 猶大和西拉也是先知，他們講了許多勉勵、堅立弟兄姊妹的話。</span>
<span className="v" id="v33" data-v="33" data-xref="哥林多前書 16:11; 使徒行傳 16:36; 希伯來書 11:31"> 住了些日子後，安提阿的弟兄姊妹以平安的祝福為他們送行，讓他們回耶路撒冷覆命。</span>
<span className="v" id="v34" data-v="34"> 但西拉決定留在那裡。<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="有古卷無34節。">c</a></sup></span>
<span className="v" id="v35" data-v="35" data-xref="提摩太後書 4:2; 歌羅西書 1:28; 使徒行傳 13:1"> 保羅和巴拿巴則繼續留在安提阿，與許多人一起教導、傳揚主的道。</span>
</div>
</div>

## 保羅與巴拿巴分手

<div className="bt">
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="使徒行傳 14:6; 使徒行傳 13:4; 使徒行傳 13:51"> 過了一些日子，保羅對巴拿巴說：「我們回到曾傳過福音的各城鎮去探望弟兄姊妹吧，好知道他們的情況。」</span>
<span className="v" id="v37" data-v="37" data-xref="使徒行傳 12:12; 腓利門書 1:24; 使徒行傳 13:5"> 巴拿巴想要帶約翰·馬可同去，</span>
<span className="v" id="v38" data-v="38" data-xref="使徒行傳 13:13; 箴言 25:19; 路加福音 14:27–34"> 但保羅堅持不帶他同行，因為他在旁非利亞離開過他們，沒有和他們一起做工。</span>
<span className="v" id="v39" data-v="39" data-xref="歌羅西書 4:10; 傳道書 7:20; 使徒行傳 4:36"> 二人起了激烈的爭執，以致分道揚鑣。巴拿巴帶著約翰·馬可一同乘船去塞浦路斯。</span>
<span className="v" id="v40" data-v="40" data-xref="使徒行傳 15:22; 使徒行傳 14:26; 使徒行傳 11:23"> 保羅則選了西拉同行，弟兄姊妹把他們交託在主的恩典中。</span>
<span className="v" id="v41" data-v="41" data-xref="使徒行傳 15:23; 加拉太書 1:21; 使徒行傳 15:32"> 保羅走遍了敘利亞和基利迦，堅固當地的教會。</span>
</div>

## 保羅在帖撒羅尼迦傳道

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="帖撒羅尼迦前書 1:1; 腓立比書 4:16; 使徒行傳 20:4"> 保羅和西拉經過暗非坡里和亞波羅尼亞，到了帖撒羅尼迦。那裡有猶太人的會堂。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行傳 9:20; 使徒行傳 17:17; 使徒行傳 18:4"> 保羅照以往的習慣進入會堂，一連三個安息日引用聖經與他們討論，</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行傳 18:28; 使徒行傳 9:22; 路加福音 24:32"> 解釋、證明基督必須受害，然後從死裡復活，又說：「我向你們宣講的這位耶穌就是基督。」</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行傳 17:12; 使徒行傳 13:43; 使徒行傳 14:4"> 不少人被說服，成為保羅和西拉的同道，其中有許多是敬畏上帝的希臘人和有名望的婦女。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="加拉太書 5:26; 使徒行傳 17:13; 羅馬書 16:21"> 那些不信主的猶太人卻妒火中燒，他們召集了一群市井無賴，在城裡引發騷亂，闖進耶孫的家企圖把保羅和西拉揪出來示眾。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行傳 24:5; 使徒行傳 16:19–21; 使徒行傳 28:22"> 他們找不到二人，就把耶孫和幾個弟兄拉到當地官員面前，高喊：「那些攪亂天下的人到我們這裡來了，</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 23:2; 使徒行傳 16:21; 約翰福音 19:12"> 耶孫接待了他們。他們違抗凱撒的命令，說另有一個王叫耶穌。」</span>
<span className="v" id="v8" data-v="8" data-xref="馬太福音 2:3; 約翰福音 11:48"> 百姓和當地官長聽後，深感不安。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行傳 17:5"> 於是，官長命耶孫等人繳納保釋金，然後釋放了他們。</span>
</div>
</div>

## 庇哩亞人接受福音

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="使徒行傳 17:2; 帖撒羅尼迦前書 2:2; 使徒行傳 17:13–14"> 弟兄姊妹立刻在夜間把保羅和西拉送往庇哩亞。他們二人一到，就進了猶太會堂。</span>
<span className="v" id="v11" data-v="11" data-xref="以賽亞書 34:16; 箴言 2:1–5; 約翰福音 5:39"> 當地的人比帖撒羅尼迦人開明，非常樂意接受真道，還天天查考聖經，看看所聽的道是否合乎聖經。</span>
<span className="v" id="v12" data-v="12" data-xref="以弗所書 5:14; 使徒行傳 14:1; 使徒行傳 13:50"> 結果有很多人信了，包括不少有名望的希臘婦女和男子。</span>
<span className="v" id="v13" data-v="13" data-xref="帖撒羅尼迦前書 2:14–16; 箴言 28:25; 使徒行傳 6:12"> 可是，帖撒羅尼迦的猶太人聽到保羅在庇哩亞宣揚上帝的道，就趕來慫恿、煽動眾人。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行傳 17:10; 馬太福音 10:23; 使徒行傳 9:25"> 庇哩亞的弟兄姊妹立刻送保羅到海邊，西拉和提摩太仍然留在庇哩亞。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行傳 18:5; 帖撒羅尼迦前書 3:1; 使徒行傳 18:1"> 護送保羅的人一直把他送到雅典，然後帶著保羅的口信回庇哩亞，交代西拉和提摩太儘快趕去雅典與保羅會合。</span>
</div>
</div>

## 保羅在雅典傳道

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="詩篇 119:158; 彼得後書 2:7; 詩篇 119:136"> 保羅在雅典等候他們的時候，看見滿城都是偶像，心裡非常著急。</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行傳 13:16; 使徒行傳 14:1–4; 使徒行傳 17:2–4"> 於是，他在會堂跟猶太人和虔誠的外族人辯論，每天在廣場上跟遇見的人辯論。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前書 1:20–21; 歌羅西書 2:8; 路加福音 11:53"> 還有一些伊壁鳩魯和斯多亞學派的哲學家和保羅爭論，有人說：「這人在胡言亂語什麼呀？」還有人說：「他好像在宣揚外國的神明。」他們這樣說是因為保羅在傳講耶穌和祂復活的福音。</span>
<span className="v" id="v19" data-v="19" data-xref="馬可福音 1:27; 使徒行傳 17:22; 使徒行傳 24:24"> 他們帶保羅到亞略·巴古議會，問他：「我們可以知道你所教導的這個新道理嗎？</span>
<span className="v" id="v20" data-v="20" data-xref="哥林多前書 1:23; 何西阿書 8:12; 哥林多前書 2:14"> 你的言論聽起來確實稀奇，我們很想知道個究竟。」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="提摩太後書 2:16–17; 歌羅西書 4:5; 以弗所書 5:16"> 這些雅典人和僑居在那裡的人無所事事，只喜歡談論和打聽一些新鮮事兒。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="使徒行傳 25:19; 使徒行傳 19:35; 使徒行傳 17:16"> 保羅在亞略·巴古議會中站起來說：「各位雅典人，我看得出你們在各方面都非常虔誠。</span>
<span className="v" id="v23" data-v="23" data-xref="約翰福音 4:22; 加拉太書 4:8–9; 約翰福音 17:3"> 、我在街上走的時候，觀察了你們所敬拜的對象，發現一座祭壇上面寫著『獻給未知之神』。這位你們不認識卻在敬拜的神，我現在介紹給你們。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="列王紀上 8:27; 申命記 10:14; 使徒行傳 7:48"> 「這位創造宇宙萬物的上帝是天地的主宰，並不住在人手建造的廟宇裡，</span>
<span className="v" id="v25" data-v="25" data-xref="詩篇 50:8–13; 創世記 2:7; 以賽亞書 42:5"> 也不需要人的侍奉，因為祂一無所缺。祂親自將生命、氣息和萬物賜給世人。</span>
<span className="v" id="v26" data-v="26" data-xref="申命記 32:7–8; 創世記 3:20; 羅馬書 5:12–19"> 祂從一人造出萬族，讓他們散居世界各地，又預先定下他們的期限和居住的疆界，</span>
<span className="v" id="v27" data-v="27" data-xref="耶利米書 23:23–24; 申命記 4:7; 使徒行傳 14:17"> 以便他們尋求祂，或許他們可以摸索著找到祂。祂原本就離我們各人不遠，</span>
<span className="v" id="v28" data-v="28" data-xref="約伯記 12:10; 歌羅西書 1:17; 希伯來書 1:3"> 我們的生活、行動和存在都靠祂，你們的詩人也說過，『我們是祂的子孫。』</span>
<span className="v" id="v29" data-v="29" data-xref="以賽亞書 40:25; 出埃及記 20:4; 詩篇 115:4–8"> 我們既然是上帝的子孫，就不該認為上帝是人憑手藝和想象用金、銀、石頭所雕刻的樣子。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="使徒行傳 14:16; 提多書 2:11–12; 路加福音 24:47"> 「上帝以往不鑒察世人的無知，現在則命令世上所有的人都要悔改。</span>
<span className="v" id="v31" data-v="31" data-xref="馬太福音 25:31–46; 彼得後書 3:7; 羅馬書 2:16"> 因為祂已經定了日子，要藉祂所設立的人按公義審判這個世界。祂叫那人從死裡復活，給了世人可信的憑據。」</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="使徒行傳 17:18; 使徒行傳 26:8; 使徒行傳 25:19"> 聽見保羅提到死人復活的事，有些人就嘲笑他，還有些人說：「我們改天再聽你講這個。」</span>
<span className="v" id="v33" data-v="33"> 於是保羅離開了他們。</span>
<span className="v" id="v34" data-v="34" data-xref="使徒行傳 17:19; 羅馬書 11:5–6; 使徒行傳 13:48"> 不過，也有人跟隨保羅，信了耶穌，其中有亞略·巴古的會員丟尼修和一位名叫戴瑪麗的婦人及其他人。</span>
</div>
</div>

</div>

## 保羅前往羅馬

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行傳 25:25; 使徒行傳 25:12; 使徒行傳 10:1"> 他們決定讓我們坐船去義大利，於是將保羅和其他囚犯都交給一位皇家兵團的百夫長猶流看管。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行傳 19:29; 腓利門書 1:24; 歌羅西書 4:10"> 有一艘亞大米田的船準備沿著亞細亞海岸航行。我們上船啟航，同行的還有帖撒羅尼迦的馬其頓人亞里達古。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行傳 24:23; 使徒行傳 28:16; 使徒行傳 27:43"> 第二天，船停泊在西頓港，猶流寬待保羅，准許他探望當地的朋友，接受他們的照應。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行傳 4:36; 使徒行傳 15:39; 使徒行傳 13:4"> 我們從那裡啟航後，由於遇到逆風，便沿著塞浦路斯的背風岸前行，</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行傳 6:9; 使徒行傳 13:13; 使徒行傳 15:41"> 經過基利迦和旁非利亞附近的海域，來到呂迦的每拉。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行傳 28:11; 使徒行傳 27:1; 使徒行傳 6:9"> 百夫長在那裡找到一艘從亞歷山大駛往義大利的船，他吩咐我們搭乘那艘船。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行傳 27:21; 提多書 1:5; 提多書 1:12"> 一連多日船速十分緩慢，好不容易才駛近革尼土。因為強風船無法前行，我們只好沿著克里特背風岸航行，經過撒摩尼角。</span>
<span className="v" id="v8" data-v="8"> 船沿著海岸行進，幾經艱難才到達拉西亞城附近的佳澳。</span>
<span className="v" id="v9" data-v="9" data-xref="民數記 29:7; 利未記 23:27–29; 利未記 16:29–31"> 我們耽誤了不少日子，由於禁食的節期<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="指猶太人的贖罪日，約在陽曆九月、十月間（參見利未記23·27）。">a</a></sup>已過，航行很危險，保羅就勸告眾人說：</span>
<span className="v" id="v10" data-v="10" data-xref="但以理書 2:30; 使徒行傳 27:20–26; 使徒行傳 27:41–44"> 「各位，照我看來，我們如果繼續航行，不只會損失貨物和船隻，甚至連我們的性命也難保。」</span>
<span className="v" id="v11" data-v="11" data-xref="以西結書 33:4; 希伯來書 11:7; 以西結書 3:17–18"> 但那百夫長只相信船主和舵手的話，不接受保羅的勸告。</span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 107:30; 使徒行傳 27:8"> 由於佳澳港不適宜過冬，大部分人贊成啟航，以為或許可以趕到菲尼基過冬。菲尼基是克里特的一個港口，一面向西南，一面向西北。</span>
</div>
</div>

## 驚濤駭浪

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="路加福音 12:55; 雅歌 4:16; 約伯記 37:17"> 那時，南風徐徐吹來，他們以為能繼續航行，於是起錨沿著克里特行進。</span>
<span className="v" id="v14" data-v="14" data-xref="馬可福音 4:37; 詩篇 107:25–27; 出埃及記 14:21–27"> 可是出發不久，從島上颳來一股猛烈的東北風<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="「猛烈的東北風」希臘文是「友拉革羅颶風」。">b</a></sup>，</span>
<span className="v" id="v15" data-v="15" data-xref="雅各書 3:4; 使徒行傳 27:27"> 船被颳得失去控制，我們只好任船隨風漂流。</span>
<span className="v" id="v16" data-v="16"> 船沿著一個叫高達的小島的背風面前進，大家好不容易才控制住救生船。</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行傳 27:29; 使徒行傳 27:26; 使徒行傳 27:41"> 水手把救生船拉上甲板後，又用繩索加固船身。因為怕船會在賽耳底擱淺，於是收起船帆，任船漂流。</span>
<span className="v" id="v18" data-v="18" data-xref="約拿書 1:5; 使徒行傳 27:38; 馬太福音 16:26"> 第二天，風浪依然猛烈，他們開始把貨物拋進海裡。</span>
<span className="v" id="v19" data-v="19" data-xref="約伯記 2:4; 路加福音 9:24–25; 馬可福音 8:35–37"> 第三天，他們又親手把船上的用具也拋掉了。</span>
<span className="v" id="v20" data-v="20" data-xref="馬太福音 24:29; 馬太福音 8:24–25; 耶利米書 2:25"> 一連好幾天都看不到太陽、星辰，加上風浪肆虐，我們完全放棄了得救的指望。</span>
</div>
</div>

## 保羅安慰眾人

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="創世記 42:22; 詩篇 107:5–6; 使徒行傳 27:7"> 這時大家已經多日沒有進食，保羅站在他們當中說：「各位當初如果肯聽我勸，不離開克里特，就不會遭受這些損失了。</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行傳 27:25; 使徒行傳 27:36; 哥林多後書 4:8–9"> 現在我勸各位放心，你們無人會喪命，只是這艘船保不住了。</span>
<span className="v" id="v23" data-v="23" data-xref="使徒行傳 23:11; 羅馬書 1:9; 提摩太後書 4:17"> 因為昨天晚上，我所歸屬、所事奉的上帝差遣天使站在我身旁，</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行傳 23:11; 提摩太後書 4:16–17; 馬太福音 10:28"> 對我說，『保羅，不用怕，你一定會站在凱撒面前，並且上帝已經賜平安給所有和你同船的人。』</span>
<span className="v" id="v25" data-v="25" data-xref="羅馬書 4:20–21; 路加福音 1:45; 民數記 23:19"> 所以請各位放心，我深信上帝所說的話必然會成就。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行傳 28:1; 使徒行傳 27:17; 使徒行傳 27:29"> 只是我們一定會在某個島上擱淺。」</span>
<span className="v" id="v27" data-v="27" data-xref="約拿書 1:6; 使徒行傳 27:30; 啟示錄 18:17"> 第十四天的晚上，我們在亞得里亞海漂來漂去。到了午夜時分，水手覺得離陸地不遠了，</span>
<span className="v" id="v28" data-v="28"> 就探測水深，結果約三十七米深，過了一會兒再測水深，只有二十七米左右。</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行傳 27:17; 希伯來書 6:19; 申命記 28:67"> 他們怕會觸礁，就從船尾拋下四個錨，期待天亮。</span>
<span className="v" id="v30" data-v="30" data-xref="使徒行傳 27:16; 使徒行傳 27:32"> 水手們想要棄船逃生，假裝要從船頭拋錨，卻偷偷地把救生船放到海裡。</span>
<span className="v" id="v31" data-v="31" data-xref="帖撒羅尼迦後書 2:13–14; 詩篇 91:11–12; 耶利米書 29:11–13"> 保羅對百夫長和士兵們說：「除非他們留在船上，否則你們都活不了！」</span>
<span className="v" id="v32" data-v="32" data-xref="腓立比書 3:7–9; 路加福音 16:8"> 士兵就砍斷繩索，讓救生船漂走。</span>
<span className="v" id="v33" data-v="33"> 到了黎明時分，保羅勸大家吃東西，說：「你們提心吊膽、不思飲食已經十四天了。</span>
<span className="v" id="v34" data-v="34" data-xref="馬太福音 10:30; 列王紀上 1:52; 路加福音 21:18"> 我勸你們吃點東西，好活下去，你們必定毫髮無損。」</span>
<span className="v" id="v35" data-v="35" data-xref="馬太福音 15:36; 哥林多前書 10:30–31; 提摩太前書 4:3–4"> 保羅說完後拿起餅，當眾感謝上帝，然後掰開吃。</span>
<span className="v" id="v36" data-v="36" data-xref="哥林多後書 1:4–6; 使徒行傳 27:22; 詩篇 27:14"> 於是大家都振作起來，吃了些東西。</span>
<span className="v" id="v37" data-v="37" data-xref="使徒行傳 2:41; 羅馬書 13:1; 彼得前書 3:20"> 船上共有二百七十六人。</span>
<span className="v" id="v38" data-v="38" data-xref="約拿書 1:5; 馬太福音 6:25; 使徒行傳 27:18–19"> 吃飽了以後，為了要減輕船的重量，他們把麥子拋進海裡。</span>
</div>
</div>

## 安全登陸

<div className="bt">
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="使徒行傳 28:1"> 天亮的時候，水手發現了一片不認識的陸地，看見一個有沙灘的海灣，便決定盡可能在那裡靠岸。</span>
<span className="v" id="v40" data-v="40" data-xref="以賽亞書 33:23; 使徒行傳 27:29–30"> 於是砍斷錨索，把錨扔進海裡，同時鬆開舵繩，升起前帆，順著風勢駛向那沙灘。</span>
<span className="v" id="v41" data-v="41" data-xref="哥林多後書 11:25–26; 以西結書 27:26; 使徒行傳 27:26–29"> 可是，遇到兩流交匯的水域，船就擱淺了，船頭卡在那裡不能動彈，船尾被大浪撞裂了。</span>
<span className="v" id="v42" data-v="42" data-xref="馬可福音 15:15–20; 傳道書 9:3; 詩篇 74:20"> 士兵們想把囚犯全殺掉，怕有人乘機游泳逃走。</span>
<span className="v" id="v43" data-v="43" data-xref="使徒行傳 27:3; 箴言 16:7; 使徒行傳 27:11"> 但百夫長為了救保羅，不准他們輕舉妄動，下令會游泳的先跳到海裡游上岸。</span>
<span className="v" id="v44" data-v="44" data-xref="使徒行傳 27:22; 詩篇 107:28–30; 約翰福音 6:39–40"> 其餘的人利用木板和船體的碎片游上岸。結果，全船的人都平安上岸。</span>
</div>

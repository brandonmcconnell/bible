## 提摩太加入福音事工

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="提摩太後書 1:5; 提摩太後書 1:2; 哥林多前書 4:17"> 保羅來到特庇，然後又到路司得。那裡有個門徒名叫提摩太，母親是信主的猶太人，父親是希臘人。</span>
<span className="v" id="v2" data-v="2" data-xref="提摩太前書 5:10; 提摩太後書 3:15; 使徒行傳 14:21"> 路司得和以哥念的弟兄姊妹都稱讚提摩太。</span>
<span className="v" id="v3" data-v="3" data-xref="加拉太書 2:3; 哥林多前書 9:20; 加拉太書 5:6"> 保羅打算帶提摩太同行。因為當地的猶太人都知道提摩太的父親是希臘人，保羅就給提摩太行了割禮。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行傳 15:28–29; 使徒行傳 15:2; 使徒行傳 11:30"> 他們走遍各城，把耶路撒冷的使徒和長老所定下的規條教導當地的門徒遵守。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行傳 9:31; 使徒行傳 2:47; 使徒行傳 6:7"> 這樣，眾教會在信仰上得到堅固，人數天天都在增加。</span>
</div>
</div>

## 馬其頓人的呼求

<div className="bt">
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="使徒行傳 18:23; 使徒行傳 16:7; 使徒行傳 13:2–4"> 由於聖靈禁止他們到亞細亞傳福音，他們便經過弗呂迦和加拉太地區，</span>
<span className="v" id="v7" data-v="7" data-xref="羅馬書 8:9; 腓立比書 1:19; 加拉太書 4:6"> 來到每西亞的邊界，正要進入庇推尼地區，耶穌的靈還是不許。</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多後書 2:12; 提摩太後書 4:13; 使徒行傳 16:11"> 他們就越過每西亞，下到特羅亞。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行傳 9:10–12; 使徒行傳 19:21; 使徒行傳 18:5"> 當晚，保羅在異象中看見一個馬其頓人站在那裡懇求他：「請到馬其頓來幫助我們！」</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多後書 2:12–13; 使徒行傳 14:7; 使徒行傳 16:10–17"> 保羅見了這個異象，確定是上帝呼召我們<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="本書作者路加此時加入保羅的行列，故改用第一人稱複數「我們」。">a</a></sup>到馬其頓去傳福音，就立刻準備動身。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行傳 21:1; 使徒行傳 16:8"> 我們從特羅亞啟航，直接駛往撒摩特喇，第二天抵達尼亞坡里，</span>
<span className="v" id="v12" data-v="12" data-xref="帖撒羅尼迦前書 2:2; 腓立比書 1:1; 使徒行傳 20:6"> 再從那裡來到腓立比。腓立比是馬其頓的主要城市，是羅馬的殖民地。我們在那裡住了幾天。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行傳 13:14; 歌羅西書 1:23; 使徒行傳 17:2"> 安息日那天，我們到城外的河邊，知道那裡有一個禱告的地方，就坐下來，向已經聚集的婦女講道。</span>
<span className="v" id="v14" data-v="14" data-xref="以弗所書 1:17–18; 路加福音 24:45; 以賽亞書 50:5"> 聽眾中有個賣紫色布匹的婦人名叫呂底亞，是推雅推喇城的人，向來敬拜上帝。上帝開啟她的心，她便留心聽保羅講道。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行傳 11:14; 希伯來書 13:2; 使徒行傳 16:33"> 呂底亞和家人接受洗禮之後，極力邀請我們，說：「如果你們認為我是真心信主的話，請來我家住。」於是強留我們住下。</span>
</div>
</div>

## 保羅和西拉入獄

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="利未記 19:31; 申命記 18:9–11; 以賽亞書 8:19"> 一天，我們又去河邊那個禱告的地方，途中遇到一個被巫鬼附身的女奴。她用占卜為她的主人們賺了不少錢。</span>
<span className="v" id="v17" data-v="17" data-xref="約翰福音 14:6; 彼得前書 2:16; 馬可福音 5:7"> 她跟著保羅和我們，大喊大叫：「這些人是至高上帝的奴僕，是來向你們宣講得救之道的。」</span>
<span className="v" id="v18" data-v="18" data-xref="馬可福音 16:17; 路加福音 10:17–19; 使徒行傳 3:6"> 一連幾天，她都這樣喊叫。保羅不勝其煩，就轉過身來斥責那鬼：「我奉耶穌基督的名命令你從她身上出來！」那鬼立刻從她身上出去了。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行傳 17:6; 使徒行傳 21:30; 使徒行傳 8:3"> 她的主人們眼見財路斷絕了，就把保羅和西拉揪住，拖到廣場去見官長。</span>
<span className="v" id="v20" data-v="20" data-xref="雅各書 4:4; 約翰福音 15:18–20; 使徒行傳 28:22"> 他們在官長面前控告保羅和西拉，說：「這些是猶太人，竟擾亂我們的城市，</span>
<span className="v" id="v21" data-v="21" data-xref="以斯帖記 3:8; 使徒行傳 26:3; 耶利米書 10:3"> 宣揚我們羅馬人不可接受或實行的風俗。」</span>
<span className="v" id="v22" data-v="22" data-xref="帖撒羅尼迦前書 2:2; 哥林多後書 6:5; 哥林多後書 11:23–25"> 於是，民眾一起攻擊他們，官長下令剝掉他們的衣服，杖打他們。</span>
<span className="v" id="v23" data-v="23" data-xref="啟示錄 2:10; 提摩太後書 2:9; 撒母耳記上 23:22–23"> 他們被毒打一頓，又被關進監獄，官長命獄卒嚴加看守。</span>
<span className="v" id="v24" data-v="24" data-xref="約伯記 13:27; 約伯記 33:11; 耶利米書 29:26"> 獄卒接到命令後把他們關進內牢，雙腳上了枷鎖。</span>
<span className="v" id="v25" data-v="25" data-xref="帖撒羅尼迦前書 5:16–18; 詩篇 119:62; 雅各書 1:2"> 半夜，保羅和西拉禱告、唱聖詩讚美上帝，其他囚犯都側耳傾聽。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行傳 4:31; 使徒行傳 5:19; 使徒行傳 12:10"> 突然間發生大地震，整座監獄的地基都搖動起來，牢門立刻全開了，囚犯的鎖鏈也都鬆開了。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行傳 12:19; 馬太福音 27:5; 士師記 9:54"> 獄卒驚醒後，看見牢門盡開，以為囚犯已經逃走了，就要拔刀自殺。</span>
<span className="v" id="v28" data-v="28" data-xref="帖撒羅尼迦前書 5:15; 路加福音 23:34; 路加福音 6:27–28"> 保羅見狀大聲喝止：「不要傷害自己，我們都在這裡！」</span>
<span className="v" id="v29" data-v="29" data-xref="啟示錄 3:9; 使徒行傳 24:25; 以賽亞書 60:14"> 獄卒叫人拿燈過來，衝進內牢，戰戰兢兢地俯伏在保羅和西拉面前。</span>
<span className="v" id="v30" data-v="30" data-xref="使徒行傳 2:37; 約翰福音 6:27–29; 以賽亞書 58:9"> 獄卒領他們出來後問道：「兩位先生，我該怎樣做才能得救？」</span>
<span className="v" id="v31" data-v="31" data-xref="約翰福音 1:12; 使徒行傳 2:38–39; 約翰福音 3:36"> 他們說：「要信主耶穌，你和你一家就必定得救。」</span>
<span className="v" id="v32" data-v="32" data-xref="羅馬書 1:16; 歌羅西書 1:27–28; 提摩太前書 1:13–16"> 於是保羅和西拉向獄卒和他全家傳講主的道。</span>
<span className="v" id="v33" data-v="33" data-xref="哥林多前書 1:16; 使徒行傳 16:15; 使徒行傳 16:25"> 當晚，獄卒把二人帶去，為他們清洗傷口。他一家老小都接受了洗禮。</span>
<span className="v" id="v34" data-v="34" data-xref="羅馬書 15:13; 使徒行傳 2:46; 羅馬書 5:11"> 他請二人到家裡並為他們擺上飯食，他和全家人充滿了喜樂，因為都信了上帝。</span>
<span className="v" id="v35" data-v="35" data-xref="耶利米書 5:22; 詩篇 76:10; 使徒行傳 5:40"> 第二天早上，官長派差役來，說：「把他們放了。」</span>
<span className="v" id="v36" data-v="36" data-xref="使徒行傳 15:33; 約翰福音 14:27; 撒母耳記上 1:17"> 獄卒轉告保羅說：「官長下令釋放你們，現在你們可以平安地走了。」</span>
<span className="v" id="v37" data-v="37" data-xref="使徒行傳 22:25–29; 詩篇 58:1–2; 馬太福音 10:16"> 保羅卻說：「我們是羅馬公民，他們未經審訊就當眾打我們，又把我們關進牢裡，現在卻想偷偷打發掉我們嗎？這樣不行，叫他們親自來領我們出去！」</span>
<span className="v" id="v38" data-v="38" data-xref="使徒行傳 22:29; 馬太福音 21:46; 馬太福音 14:5"> 差役回報官長。官長得知保羅和西拉都是羅馬公民，非常害怕，</span>
<span className="v" id="v39" data-v="39" data-xref="馬太福音 8:34; 馬可福音 5:17; 但以理書 6:23"> 連忙到獄中向他們道歉，領他們出監，一再央求他們離開腓立比。</span>
<span className="v" id="v40" data-v="40" data-xref="帖撒羅尼迦前書 3:2–3; 使徒行傳 16:14; 使徒行傳 14:22"> 二人離開監獄，來到呂底亞家中，見了弟兄姊妹，勸勉一番之後，便離開了那裡。</span>
</div>
</div>

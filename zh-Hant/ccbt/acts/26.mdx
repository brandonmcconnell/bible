## 保羅在亞基帕王面前申辯

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行傳 9:15; 箴言 1:24; 使徒行傳 26:2"> 亞基帕對保羅說：「准你為自己辯護。」於是保羅伸手示意，然後為自己辯護說：</span>
<span className="v" id="v2" data-v="2"> 「亞基帕王啊，關於猶太人對我的所有控告，我今天很榮幸可以在你面前申辯，</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行傳 6:14; 使徒行傳 26:26; 使徒行傳 26:7"> 尤其是你對猶太習俗和爭議都十分熟悉。因此，求你耐心聽我說。</span>
<span className="v" id="v4" data-v="4" data-xref="加拉太書 1:13; 提摩太後書 3:10; 腓立比書 3:5"> 「我從小在本族和耶路撒冷為人如何，猶太人都知道。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行傳 23:6; 使徒行傳 22:3; 使徒行傳 24:5"> 他們認識我很久了，如果肯作證的話，可以證明我一直屬於猶太教中最嚴格的法利賽派。</span>
<span className="v" id="v6" data-v="6" data-xref="提多書 2:13; 使徒行傳 24:15; 使徒行傳 28:20"> 現在我是因為對上帝給我們祖先的應許充滿盼望，才站在這裡受審的。</span>
<span className="v" id="v7" data-v="7" data-xref="雅各書 1:1; 腓立比書 3:11; 提摩太前書 5:5"> 我們十二支派日夜虔誠地事奉上帝，盼望這應許能夠實現。王啊！我就是因為有這樣的盼望，才被猶太人控告。</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多前書 15:12–20; 使徒行傳 4:2; 使徒行傳 17:31–32"> 上帝叫死人復活，你們為什麼認為不可信呢？</span>
<span className="v" id="v9" data-v="9" data-xref="提摩太前書 1:13; 使徒行傳 22:8; 腓立比書 3:6"> 我自己也曾經認為應該盡一切可能反對拿撒勒人耶穌的名。</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行傳 8:3; 使徒行傳 9:13–14; 使徒行傳 9:21"> 我在耶路撒冷就曾這樣做。我得到祭司長的授權，把許多聖徒<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="保羅在這裡指的是信耶穌的基督徒。">a</a></sup>關進監獄。他們被判死刑，我也表示贊同。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行傳 22:19; 馬太福音 10:17; 使徒行傳 13:45"> 我多次在各會堂懲罰他們，逼他們說褻瀆的話，對他們深惡痛絕，甚至到外族城鎮去追捕、迫害他們。</span>
</div>
</div>

## 保羅信主的經過

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="使徒行傳 26:10; 使徒行傳 22:5–11; 使徒行傳 9:1–8"> 「那時，我帶著祭司長的授權和委託去大馬士革。</span>
<span className="v" id="v13" data-v="13" data-xref="馬太福音 17:2; 啟示錄 21:23; 啟示錄 1:16"> 王啊！大約正午，我在路上看見一道比太陽還亮的光從天上四面照著我和同行的人。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行傳 21:40; 使徒行傳 22:2; 使徒行傳 9:7"> 我們都倒在地上，我聽見有聲音用希伯來話對我說，『掃羅！掃羅！你為什麼迫害我？你用腳踢刺棍自討苦吃。』</span>
<span className="v" id="v15" data-v="15" data-xref="約翰福音 15:20–21; 馬太福音 25:45; 出埃及記 16:8"> 我說，『主啊，你是誰？』主說，『我就是你所迫害的耶穌。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行傳 22:14–15; 以西結書 2:1; 但以理書 10:11"> 你站起來。我向你顯現，是要派你作我的僕人和見證人，把你所看見的和以後我將啟示給你的事告訴世人。</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行傳 9:15; 提摩太前書 2:7; 耶利米書 1:19"> 我將把你從你的同胞和外族人手中救出來。我差遣你到他們那裡，</span>
<span className="v" id="v18" data-v="18" data-xref="彼得前書 2:9; 以弗所書 1:18; 以弗所書 5:8"> 去開啟他們的眼睛，使他們棄暗投明，脫離魔鬼的權勢，歸向上帝，好叫他們的罪得到赦免，與所有因信我而聖潔的人同得基業。』</span>
</div>
</div>

## 保羅放膽傳道

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="以賽亞書 50:5; 加拉太書 1:16; 以西結書 2:7–8"> 「因此，亞基帕王啊！我沒有違背這從天上來的異象。</span>
<span className="v" id="v20" data-v="20" data-xref="馬太福音 3:8; 使徒行傳 3:19; 使徒行傳 2:38"> 我先在大馬士革，然後到耶路撒冷、猶太全境和外族人當中勸人悔改歸向上帝，行事為人要與悔改的心相稱。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行傳 21:30–31; 使徒行傳 21:27; 使徒行傳 25:3"> 就因為這些事，猶太人在聖殿中抓住我，打算殺我。</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行傳 24:14; 約翰福音 5:46; 羅馬書 3:21"> 然而，我靠著上帝的幫助，到今天還能站在這裡向所有尊卑老幼作見證。我講的不外乎眾先知和摩西說過將要發生的事，</span>
<span className="v" id="v23" data-v="23" data-xref="以賽亞書 53:1–12; 路加福音 24:26; 歌羅西書 1:18"> 就是基督必須受害，並首先從死裡復活，將光明帶給猶太人和外族人。」</span>
<span className="v" id="v24" data-v="24" data-xref="哥林多前書 2:13–14; 哥林多前書 1:23; 哥林多前書 4:10"> 這時，非斯都打斷保羅的申辯，大聲說：「保羅，你瘋了！一定是你的學問太大，使你癲狂了！」</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行傳 23:26; 提多書 1:9; 提多書 2:7–8"> 保羅說：「非斯都大人，我沒有瘋。我講的話真實、合理。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行傳 26:2–3; 使徒行傳 2:1–12; 以賽亞書 30:20"> 王瞭解這些事，所以我才敢在王面前直言。我相信這些事沒有一件瞞得過王，因為這些事並非暗地裡做的。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行傳 26:22–23"> 亞基帕王啊，你信先知嗎？我知道你信。」</span>
<span className="v" id="v28" data-v="28" data-xref="使徒行傳 11:26; 馬太福音 10:18; 使徒行傳 26:29"> 亞基帕王對保羅說：「難道你想三言兩語就說服我成為基督徒嗎？」</span>
<span className="v" id="v29" data-v="29" data-xref="以弗所書 6:20; 歌羅西書 1:28; 羅馬書 10:1"> 保羅說：「不論話多話少，我求上帝不僅使你，也使今天在座的各位都能像我一樣，只是不要帶著這些鎖鏈。」</span>
<span className="v" id="v30" data-v="30" data-xref="使徒行傳 18:15; 使徒行傳 28:22; 使徒行傳 25:23"> 亞基帕王、總督、百妮姬及其他在座的人都站起來，</span>
<span className="v" id="v31" data-v="31" data-xref="使徒行傳 23:29; 使徒行傳 23:9; 使徒行傳 28:18"> 走到一邊商量說：「這人沒有做什麼該判死刑或監禁的事。」</span>
<span className="v" id="v32" data-v="32" data-xref="使徒行傳 28:18; 使徒行傳 25:11–12; 使徒行傳 25:25"> 亞基帕王對非斯都說：「這人要是沒有向凱撒上訴，已經可以獲釋了。」</span>
</div>
</div>

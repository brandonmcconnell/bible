## 司提凡的申辯

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="約翰福音 18:19–21; 馬太福音 26:61–62; 使徒行傳 6:13–14"> 大祭司問：「這是真的嗎？」</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行傳 22:1; 創世記 11:31; 詩篇 29:3"> 司提凡說：「各位父老兄弟，請聽我說！我們的祖先亞伯拉罕遷到哈蘭之前，住在美索不達米亞，榮耀的上帝向他顯現，說，</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 12:1; 希伯來書 11:8; 約書亞記 24:3"> 『你要離開家鄉和親族，到我要指示你的地方去。』<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="創世記12·1。">a</a></sup></span>
<span className="v" id="v4" data-v="4" data-xref="創世記 12:4–5; 創世記 11:31–32; 以賽亞書 41:9"> 亞伯拉罕就離開迦勒底人的地方，在哈蘭住了下來。他父親過世以後，上帝又領他到你們現在住的地方。</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 17:8; 創世記 12:7; 創世記 13:15"> 當時在這片土地上，上帝沒有給他任何產業，他甚至連立足之地也沒有。但上帝應許要把這片土地賜給他和他的後裔作產業，儘管那時候亞伯拉罕還沒有兒子。</span>
<span className="v" id="v6" data-v="6" data-xref="創世記 15:13; 出埃及記 12:40–41; 加拉太書 3:17"> 上帝又說，『你的後裔必流落異鄉，被奴役和虐待四百年。</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及記 3:12; 詩篇 105:27–36; 尼希米記 9:9–11"> 但我必懲罰那奴役他們的國家，之後他們必離開那裡，在這片土地上事奉我。』<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="創世記15·13、14。">b</a></sup></span>
<span className="v" id="v8" data-v="8" data-xref="創世記 35:23–26; 創世記 17:9–14; 創世記 21:1–4"> 上帝又賜給亞伯拉罕割禮之約。所以，亞伯拉罕生以撒後第八天為他行了割禮。後來，以撒生了雅各，雅各生了十二位先祖。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 39:2; 詩篇 105:17; 以賽亞書 43:2"> 「先祖們嫉妒自己的弟弟約瑟，把他賣到了埃及。但上帝一直與他同在，</span>
<span className="v" id="v10" data-v="10" data-xref="箴言 3:4; 提摩太後書 4:18; 箴言 2:6"> 救他脫離一切危難，又賜他過人的智慧，使他在埃及法老面前得到恩寵，官拜宰相治理全國，並管理王室。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 41:54–57; 創世記 45:11; 創世記 42:5"> 「後來，埃及和迦南全境遭遇饑荒，災情嚴重，我們的先祖們斷了糧。</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 42:1–24; 創世記 43:2"> 雅各聽說埃及有糧，就派先祖們去那裡買糧，那是我們的先祖初次去埃及。</span>
<span className="v" id="v13" data-v="13" data-xref="創世記 45:1–18; 創世記 46:31–10"> 他們第二次去的時候，約瑟才和弟兄們相認，法老也知道了他的家族。</span>
<span className="v" id="v14" data-v="14" data-xref="創世記 46:26–27; 申命記 10:22; 出埃及記 1:5"> 後來，約瑟派人去把父親雅各和全族七十五人都接到埃及。</span>
<span className="v" id="v15" data-v="15" data-xref="創世記 49:33; 出埃及記 1:6; 創世記 46:3–7"> 雅各和其他先祖們便定居埃及，直到去世。</span>
<span className="v" id="v16" data-v="16" data-xref="約書亞記 24:32; 創世記 23:16; 出埃及記 13:19"> 後來他們的遺體被帶回示劍，安葬在亞伯拉罕買自哈抹子孫的墓地裡。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及記 1:7–12; 使徒行傳 7:6; 使徒行傳 13:17"> 「上帝對亞伯拉罕應許的日子快到的時侯，以色列人在埃及的人口已大大增加。</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及記 1:8"> 後來埃及有一位不認識約瑟的新王登基。<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="出埃及記1·8。">c</a></sup></span>
<span className="v" id="v19" data-v="19" data-xref="詩篇 105:25; 出埃及記 1:9–22; 啟示錄 12:4–5"> 他用毒計苦害我們的同胞，虐待我們的祖先，強令他們把嬰孩拋棄，不讓嬰孩存活。</span>
<span className="v" id="v20" data-v="20" data-xref="希伯來書 11:23; 出埃及記 2:2–10; 撒母耳記上 16:12"> 那時，摩西出生了，長得俊美非凡<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="「長得」或譯「在上帝眼中」。">d</a></sup>。他的父母在家裡偷偷地撫養了他三個月，</span>
<span className="v" id="v21" data-v="21" data-xref="希伯來書 11:24; 出埃及記 2:2–10; 申命記 32:26"> 最後把他放到外面。法老的女兒救了他，收為養子。</span>
<span className="v" id="v22" data-v="22" data-xref="以賽亞書 19:11; 但以理書 1:17–20; 歷代志下 9:22"> 「摩西學會了埃及人一切的學問，成為一個說話辦事很有能力的人。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及記 2:11–12; 箴言 21:1; 希伯來書 11:24–26"> 他四十歲那年決定去探望自己的同胞以色列人。</span>
<span className="v" id="v24" data-v="24" data-xref="約翰福音 18:10–11; 使徒行傳 7:28; 約翰福音 18:25–27"> 他到了他們那裡，看見一個埃及人正在欺負以色列人，就打抱不平，殺了那個埃及人。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行傳 15:7; 馬可福音 9:32; 列王紀下 5:1"> 摩西以為同胞們會明白上帝要藉著他的手拯救他們，可是他們並不明白。</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及記 2:13–15; 箴言 18:19; 約翰一書 3:11–15"> 第二天，他看見兩個以色列人在打架，就上前勸解說，『你們二位是同胞，為什麼互相傷害呢？』</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行傳 7:35; 路加福音 12:14; 使徒行傳 7:54"> 不料那個欺負人的推開摩西說，『誰立你作我們的首領和審判官？</span>
<span className="v" id="v28" data-v="28"> 難道你要殺我，像昨天殺那個埃及人一樣嗎？』<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="出埃及記2·14。">e</a></sup></span>
<span className="v" id="v29" data-v="29" data-xref="出埃及記 18:2–4; 出埃及記 2:14–22; 出埃及記 4:19–20"> 摩西聽了這話，就逃到米甸寄居，在那裡生了兩個兒子。</span>
<span className="v" id="v30" data-v="30" data-xref="出埃及記 3:1–2; 使徒行傳 7:35; 以賽亞書 43:2"> 「過了四十年，在西奈山的曠野，有天使在荊棘的火焰中向摩西顯現。</span>
<span className="v" id="v31" data-v="31" data-xref="出埃及記 3:3–4"> 摩西見狀很驚奇，正要上前看個究竟，就聽見主說，</span>
<span className="v" id="v32" data-v="32" data-xref="出埃及記 3:6; 馬太福音 22:32; 約伯記 4:14"> 『我是你祖先的上帝，是亞伯拉罕、以撒、雅各的上帝。』<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="出埃及記3·6。">f</a></sup>摩西戰戰兢兢，不敢觀看。</span>
<span className="v" id="v33" data-v="33" data-xref="出埃及記 3:5; 約書亞記 5:15; 傳道書 5:1"> 主又說，『脫下你腳上的鞋，因為你所站的地方是聖地。</span>
<span className="v" id="v34" data-v="34" data-xref="出埃及記 3:7–10; 出埃及記 4:31; 詩篇 106:44"> 我已清楚看見我子民在埃及所受的苦難，也聽見了他們的哀歎，我下來要救他們。你來，我要派你回埃及。』<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="出埃及記3·5、7、8、10。">g</a></sup></span>
<span className="v" id="v35" data-v="35" data-xref="詩篇 118:22–23; 路加福音 19:14; 詩篇 113:7–8"> 「百姓曾拒絕這位摩西，說，『誰立你作我們的首領和審判官？』上帝卻藉著在荊棘中顯現的天使親自差遣他，立他為首領和拯救者。</span>
<span className="v" id="v36" data-v="36" data-xref="出埃及記 12:41; 出埃及記 14:21; 出埃及記 33:1"> 摩西帶領以色列人出埃及，過紅海，越曠野，四十年間行了許多神蹟奇事。</span>
<span className="v" id="v37" data-v="37" data-xref="申命記 18:15–19; 使徒行傳 3:22–23; 約翰福音 18:37"> 就是這位摩西曾對以色列人說，『上帝要在你們中間興起一位像我一樣的先知。』<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="申命記18·15。">h</a></sup></span>
<span className="v" id="v38" data-v="38" data-xref="羅馬書 3:2; 希伯來書 5:12; 彼得前書 4:11"> 這位摩西曾在曠野的會眾中與我們祖先在一起，又在西奈山上與向他傳信息的天使在一起，並且領受了生命之道傳給我們。</span>
<span className="v" id="v39" data-v="39" data-xref="民數記 14:3–4; 民數記 11:5; 尼希米記 9:16–17"> 「可是我們的祖先不肯聽從他，甚至棄絕他，心裡對埃及戀戀不捨。</span>
<span className="v" id="v40" data-v="40" data-xref="出埃及記 32:1; 出埃及記 32:23"> 他們對亞倫說，『為我們造一些神像來帶領我們吧！因為帶我們出埃及的那個摩西不知怎樣了。』<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="出埃及記32·1。">i</a></sup></span>
<span className="v" id="v41" data-v="41" data-xref="詩篇 106:19–21; 尼希米記 9:18; 啟示錄 9:20"> 於是，他們造了一個牛犢像，向它獻祭，並為自己所做的事沾沾自喜。</span>
<span className="v" id="v42" data-v="42" data-xref="阿摩司書 5:25–26; 以西結書 20:39; 耶利米書 19:13"> 因此，上帝轉臉不顧他們，任由他們祭拜日月星辰，正如先知書的記載，<br /><span className="pl pl-1">「『以色列家啊，</span><br /><span className="pl pl-1">在曠野的四十年間，</span><br /><span className="pl pl-1">你們向我獻過祭物和供物嗎？</span><br /></span>
<span className="v" id="v43" data-v="43" data-xref="阿摩司書 5:26–27; 出埃及記 20:4–5; 申命記 5:8–9"> <span className="pl pl-1">你們抬著為祭拜而造的神像，</span><br /><span className="pl pl-1">就是摩洛的帳篷和你們理番神明的星，</span><br /><span className="pl pl-1">所以我要把你們流放到比巴比倫還遠的地方。』</span><sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="阿摩司書5·25‑27。">j</a></sup></span>
<span className="v" id="v44" data-v="44" data-xref="出埃及記 25:40; 出埃及記 38:21; 希伯來書 8:5"> 「我們的祖先在曠野的時候，一直帶著安放約櫃的聖幕，這聖幕是上帝吩咐摩西照他所看見的樣式造的。</span>
<span className="v" id="v45" data-v="45" data-xref="詩篇 44:2; 約書亞記 18:1; 約書亞記 23:9"> 後來我們的祖先承受了聖幕。上帝從我們祖先面前趕走外族人，使他們得到了應許之地。他們同約書亞把聖幕帶到那裡，一直到大衛的時代。</span>
<span className="v" id="v46" data-v="46" data-xref="詩篇 132:1–5; 使徒行傳 13:22; 撒母耳記下 7:1–5"> 大衛蒙上帝悅納，祈求為雅各的上帝預備一個居所。</span>
<span className="v" id="v47" data-v="47" data-xref="列王紀上 8:20; 列王紀上 6:37–38; 撒母耳記下 7:13"> 結果是他的兒子所羅門為上帝建成了聖殿。</span>
<span className="v" id="v48" data-v="48" data-xref="使徒行傳 17:24–25; 以賽亞書 66:1–2; 列王紀上 8:27"> 「其實至高的上帝並不住人造的殿，祂曾藉著先知說，</span>
<span className="v" id="v49" data-v="49" data-xref="以賽亞書 66:1; 詩篇 11:4; 約翰福音 4:21"> 主說：『天是我的寶座，地是我的腳凳，你們要為我造怎樣的殿宇？哪裡可作我的安歇之處？</span>
<span className="v" id="v50" data-v="50" data-xref="耶利米書 32:17; 詩篇 33:6–9; 使徒行傳 14:15"> 這一切不都是我親手創造的嗎？』<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="以賽亞書66·1、2。">k</a></sup></span>
<span className="v" id="v51" data-v="51" data-xref="申命記 10:16; 以弗所書 4:30; 以賽亞書 63:10"> 「你們這些頑固不化、心與耳未受割禮的人，經常抗拒聖靈，所作所為和你們祖先如出一轍！</span>
<span className="v" id="v52" data-v="52" data-xref="馬太福音 5:12; 歷代志下 36:16; 列王紀上 19:10"> 哪一位先知沒有被你們祖先迫害？那些預言義者彌賽亞要來的人也被你們的祖先殺害。如今你們竟出賣了那位義者，殺害了祂！</span>
<span className="v" id="v53" data-v="53" data-xref="希伯來書 2:2; 加拉太書 3:19; 使徒行傳 7:38"> 你們接受了上帝藉天使所傳的律法，竟不遵守！」</span>

## 司提凡殉道

<div className="bt">
<div className="bp">
<span className="v" id="v54" data-v="54" data-xref="使徒行傳 5:33; 詩篇 35:16; 馬太福音 25:30"> 眾人聽了這番話，怒火中燒，對司提凡咬牙切齒。</span>
<span className="v" id="v55" data-v="55" data-xref="馬可福音 16:19; 希伯來書 1:3; 哥林多後書 4:6"> 司提凡卻被聖靈充滿，定睛望天，看見上帝的榮耀和站在上帝右邊的耶穌，</span>
<span className="v" id="v56" data-v="56" data-xref="馬太福音 26:64–65; 使徒行傳 10:11; 啟示錄 11:19"> 就說：「看啊！我看見天開了，人子站在上帝的右邊。」</span>
<span className="v" id="v57" data-v="57" data-xref="撒迦利亞書 7:11; 詩篇 58:4; 使徒行傳 23:27"> 眾人大喊大叫，捂著耳朵，一擁而上，</span>
<span className="v" id="v58" data-v="58" data-xref="使徒行傳 22:20; 使徒行傳 8:1; 使徒行傳 6:13"> 把司提凡拉到城外，用石頭打他。指控他的人把他們的衣服交給一個名叫掃羅的青年保管。</span>
<span className="v" id="v59" data-v="59" data-xref="路加福音 23:46; 詩篇 31:5; 使徒行傳 22:16"> 在亂石擊打之下，司提凡呼求說：「主耶穌啊，接收我的靈魂吧！」然後跪下高聲說：</span>
<span className="v" id="v60" data-v="60" data-xref="馬太福音 5:44; 路加福音 23:34; 哥林多前書 15:20"> 「主啊，不要追究他們的罪！」說完後，就斷氣了。</span>

## 保羅前往耶路撒冷

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="帖撒羅尼迦前書 2:17; 路加福音 5:4; 撒母耳記上 20:41–42"> 我們和眾人道別之後，乘船直接駛往哥士，第二天到達羅底，從那裡前往帕大喇，</span>
<span className="v" id="v2" data-v="2" data-xref="約拿書 1:3; 使徒行傳 11:19; 使徒行傳 15:3"> 在帕大喇遇到一艘開往腓尼基的船，就上了船。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行傳 21:16; 使徒行傳 4:36; 馬太福音 4:24"> 塞浦路斯遙遙在望，船從該島的南面繞過，一直駛向敘利亞。因為船要在泰爾卸貨，我們就在那裡上了岸，</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行傳 20:22–23; 使徒行傳 21:10–12; 使徒行傳 20:6–7"> 找到當地的門徒後，便和他們同住了七天。他們受聖靈的感動力勸保羅不要去耶路撒冷。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行傳 20:36; 使徒行傳 9:40; 詩篇 95:6"> 時間到了，我們繼續前行，眾門徒和他們的妻子兒女送我們出城。大家跪在岸邊禱告之後，彼此道別。</span>
<span className="v" id="v6" data-v="6" data-xref="約翰福音 19:27; 約翰福音 1:11; 哥林多後書 2:13"> 我們上了船，眾人也回家去了。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="希伯來書 13:24; 撒母耳記上 10:4; 使徒行傳 28:12"> 我們從泰爾乘船抵達多利買，上岸問候那裡的弟兄姊妹，和他們住了一天。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行傳 6:5; 使徒行傳 8:26–40; 以弗所書 4:11"> 第二天我們離開那裡，來到凱撒利亞，住在傳道人腓利家裡。他是當初選出的七位執事之一。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行傳 2:17; 啟示錄 2:20; 約珥書 2:28"> 腓利有四個未出嫁的女兒，都能說預言。</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行傳 11:28; 使徒行傳 21:4; 使徒行傳 20:16"> 過了幾天，一個名叫亞迦布的先知從猶太下來。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行傳 21:33; 耶利米書 13:1–11; 撒母耳記上 15:27–28"> 他到了我們這裡，拿保羅的腰帶綁住自己的手腳，說：「聖靈說，『耶路撒冷的猶太人也要這樣捆綁這腰帶的主人，把他交給外族人。』」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="馬太福音 16:21–23; 使徒行傳 20:22; 使徒行傳 21:4"> 聽到這話，我們和當地的信徒都苦勸保羅不要去耶路撒冷。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行傳 20:24; 腓立比書 2:17; 腓立比書 1:20–21"> 但保羅說：「你們為什麼這樣哭泣，讓我心碎呢？我為主耶穌的名甘願受捆綁，甚至死在耶路撒冷。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="路加福音 22:42; 馬太福音 26:42; 馬太福音 26:39"> 我們知道再勸也無濟於事，便不再說什麼，只說：「願主的旨意成就。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="使徒行傳 25:1; 使徒行傳 25:6; 使徒行傳 25:9"> 過了幾天，我們準備妥當，啟程上耶路撒冷。</span>
<span className="v" id="v16" data-v="16" data-xref="箴言 16:31; 使徒行傳 21:8; 詩篇 92:14"> 有幾個凱撒利亞的門徒和我們一起去，並帶我們到一個信主已久的塞浦路斯人拿孫家裡住宿。</span>
</div>
</div>

## 保羅會見雅各和眾長老

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="使徒行傳 15:4; 羅馬書 15:7; 希伯來書 13:1–2"> 我們抵達耶路撒冷後，受到弟兄姊妹的熱烈歡迎。</span>
<span className="v" id="v18" data-v="18" data-xref="加拉太書 1:19; 加拉太書 2:9; 使徒行傳 15:13"> 第二天，保羅和我們去見雅各，眾長老都在那裡。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行傳 14:27; 使徒行傳 1:17; 羅馬書 15:18–19"> 保羅向大家問安之後，便一一述說上帝藉著他的服侍在外族人中所成就的事。</span>
<span className="v" id="v20" data-v="20" data-xref="羅馬書 10:2; 加拉太書 1:14; 使徒行傳 22:3"> 大家聽了，都同聲讚美上帝，又對保羅說：「弟兄，你知道數以萬計的猶太人信了主，他們都熱衷於律法。</span>
<span className="v" id="v21" data-v="21" data-xref="加拉太書 6:12–15; 哥林多前書 9:19–21; 加拉太書 5:1–6"> 他們聽見有人說你教導所有住在外族人中的猶太人背棄摩西的律法，不給孩子行割禮，也不遵守猶太人的規矩。</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行傳 15:12; 使徒行傳 15:22; 使徒行傳 19:32"> 他們一定會聽到你來這裡的消息，這該怎麼辦？</span>
<span className="v" id="v23" data-v="23" data-xref="使徒行傳 18:18; 民數記 6:2–7"> 請你聽我們的建議，這裡有四位向上帝許過願的弟兄，</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行傳 21:26; 使徒行傳 24:18; 使徒行傳 18:18"> 你和他們一起去行潔淨禮，並由你替他們付費，讓他們可以剃頭，好叫眾人知道你嚴守律法，循規蹈矩，關於你的傳聞都是假的。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行傳 15:29; 使徒行傳 15:19–20"> 至於那些外族信徒，我們已經寫信吩咐他們，不可吃祭過偶像的食物，不可吃血和勒死的牲畜，不可淫亂。」</span>
</div>
</div>

## 保羅被捕

<div className="bt">
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="使徒行傳 24:18; 使徒行傳 21:24; 民數記 6:13–20"> 於是，保羅和四位弟兄第二天行了潔淨禮，然後上聖殿報告他們潔淨期滿的日子，屆時好讓祭司為他們每個人獻祭物。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行傳 26:21; 使徒行傳 24:18; 使徒行傳 13:50"> 當七日的潔淨期將滿的時候，有些從亞細亞來的猶太人發現保羅在聖殿裡，就煽動眾人並抓住他，</span>
<span className="v" id="v28" data-v="28" data-xref="使徒行傳 24:5–6; 使徒行傳 21:21; 使徒行傳 26:20–21"> 同時高喊：「以色列人快來幫忙！就是這人到處教唆人反對我們的民族、律法和聖殿。他還帶希臘人進聖殿，玷污這聖地。」</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行傳 20:4; 提摩太後書 4:20; 使徒行傳 18:19"> 這是因為他們在城裡見過一個名叫特羅非摩的以弗所人和保羅在一起，以為保羅一定把他帶進聖殿了。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="使徒行傳 26:21; 哥林多後書 11:26; 使徒行傳 16:19–22"> 這時，全城轟動。眾人一擁而上抓住保羅，把他拖出聖殿，隨即關上殿門。</span>
<span className="v" id="v31" data-v="31" data-xref="哥林多後書 11:23–33; 使徒行傳 17:5; 使徒行傳 26:9–10"> 正當他們要殺保羅的時候，有人把耶路撒冷發生騷亂的消息報告給羅馬軍營的千夫長，</span>
<span className="v" id="v32" data-v="32" data-xref="使徒行傳 23:27; 以賽亞書 3:15; 使徒行傳 5:40"> 千夫長馬上帶著軍兵和幾個百夫長趕來了。眾人一見千夫長和軍隊，便停止毆打保羅。</span>
<span className="v" id="v33" data-v="33" data-xref="以弗所書 6:20; 使徒行傳 21:11; 使徒行傳 20:23"> 千夫長上前拿住保羅，命人用兩條鐵鏈把他鎖起來，問他是什麼人、做了什麼事。</span>
<span className="v" id="v34" data-v="34" data-xref="使徒行傳 19:32; 使徒行傳 23:10; 使徒行傳 22:24"> 人群中有人這樣喊，有人那樣喊，千夫長無法瞭解真相，便命人將保羅帶回軍營。</span>
<span className="v" id="v35" data-v="35" data-xref="哈巴谷書 1:2–3; 詩篇 55:9; 詩篇 58:2"> 保羅剛走上臺階，眾人便兇猛地擁擠過來，士兵們只好把他舉起來抬著走。</span>
<span className="v" id="v36" data-v="36" data-xref="約翰福音 19:15; 使徒行傳 22:22; 路加福音 23:18"> 眾人跟在後面高喊：「殺掉他！」</span>
</div>
</div>

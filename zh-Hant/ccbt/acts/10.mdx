## 哥尼流邀請彼得

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行傳 27:1; 馬太福音 8:5–13; 馬太福音 27:27"> 在凱撒利亞有一位隸屬義大利營的百夫長名叫哥尼流。</span>
<span className="v" id="v2" data-v="2" data-xref="馬太福音 7:7–8; 使徒行傳 10:4; 使徒行傳 10:22"> 他和全家都是虔誠敬畏上帝的人，他慷慨賙濟窮人，常常禱告。</span>
<span className="v" id="v3" data-v="3" data-xref="但以理書 9:20–21; 使徒行傳 3:1; 使徒行傳 5:19"> 一天，大約下午三點，他在異象中清楚地看見一位上帝的天使進來呼喚他：「哥尼流！」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="腓立比書 4:6; 希伯來書 6:10; 使徒行傳 10:31"> 哥尼流驚恐地注視著他，問：「主啊，什麼事？」<br />天使回答說：「你的禱告和施捨已經在上帝面前蒙悅納。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行傳 16:9; 使徒行傳 9:38; 使徒行傳 15:7"> 如今你要派人去約帕，請一個叫西門·彼得的人來。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行傳 9:43; 使徒行傳 11:13–14; 羅馬書 10:14–17"> 他住在海邊一個叫西門的皮革匠家裡。」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="腓利門書 1:16; 撒母耳記上 14:6–7; 馬太福音 8:9–10"> 向他說話的天使離開後，哥尼流叫來兩個家僕和自己的一個敬虔侍衛，</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行傳 9:36; 詩篇 119:59–60; 使徒行傳 10:33"> 把剛才的事告訴他們，然後差他們去約帕。</span>
</div>
</div>

## 彼得見異象

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="西番雅書 1:5; 詩篇 55:17; 撒母耳記上 9:25"> 第二天中午，他們快要到達約帕時，彼得上屋頂去禱告。</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行傳 22:17; 啟示錄 4:2–3; 哥林多後書 12:2–4"> 他覺得肚子餓了，想吃東西。那家人正在預備午飯的時候，彼得進入異象，</span>
<span className="v" id="v11" data-v="11" data-xref="以弗所書 3:6; 約翰福音 1:51; 羅馬書 16:25–26"> 看見天開了，有個東西好像一大塊布，四角吊著降到地上，</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 7:8–9; 約翰福音 7:37; 哥林多前書 6:9–11"> 裡面有各種天上的飛禽、地上的爬蟲和四腳走獸。</span>
<span className="v" id="v13" data-v="13" data-xref="約翰福音 4:31–34; 耶利米書 35:2–5; 使徒行傳 10:10"> 然後有聲音對他說：「彼得，起來，宰了吃！」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="利未記 20:25; 以西結書 4:14; 但以理書 1:8"> 彼得卻說：「主啊！這可不行！我從未吃過任何污穢不潔之物。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="哥林多前書 10:25; 馬太福音 15:11; 提多書 1:15"> 那聲音又一次對他說：「上帝已經潔淨的，你不可再稱之為不潔淨。」</span>
<span className="v" id="v16" data-v="16" data-xref="創世記 41:32; 約翰福音 21:17; 哥林多後書 13:1"> 這樣一連三次之後，那塊布就被收回天上去了。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="約翰福音 13:12; 使徒行傳 10:7–19; 使徒行傳 5:24"> 彼得不知所措，正在猜測這異象到底是什麼意思，哥尼流的僕人們打聽到了西門的家，</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行傳 10:5–6; 使徒行傳 11:11"> 正站在門口大聲問西門·彼得是否住在這裡。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="使徒行傳 8:29; 使徒行傳 11:12; 使徒行傳 21:4"> 彼得還在苦苦思索的時候，聖靈對他說：「彼得，有三個人來找你，</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行傳 15:7–9; 撒迦利亞書 2:9–11; 以賽亞書 48:16"> 快下樓跟他們同去，不必多慮，他們是我差來的。」</span>
<span className="v" id="v21" data-v="21" data-xref="約翰福音 1:38–39; 馬可福音 10:51; 使徒行傳 10:29"> 彼得就下去見他們，說：「我就是你們要找的人，有什麼事？」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="使徒行傳 11:14; 使徒行傳 10:2; 使徒行傳 22:12"> 他們說：「哥尼流百夫長是個又正直又敬畏上帝的人，所有猶太人都稱讚他。聖天使指示他請你到他家裡去，好聽你的指教。」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="使徒行傳 10:45; 使徒行傳 11:12; 彼得前書 4:9"> 彼得就留他們住了一夜。第二天，彼得和他們以及幾個約帕的弟兄一同出發了。</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行傳 8:40; 撒迦利亞書 8:20–23; 撒迦利亞書 3:10"> 又過了一天，他們到達凱撒利亞。哥尼流已經叫來親朋好友，在等候他們。</span>
<span className="v" id="v25" data-v="25" data-xref="啟示錄 19:10; 啟示錄 22:8–9; 但以理書 2:46"> 彼得一進來，哥尼流就迎上去俯伏在他腳前拜他。</span>
<span className="v" id="v26" data-v="26" data-xref="啟示錄 19:10; 啟示錄 22:8–9; 使徒行傳 14:14–15"> 彼得連忙把他扶起來，說：「快起來，我也只不過是人。」</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="哥林多後書 2:12; 約翰福音 4:35; 使徒行傳 10:24"> 彼得和他邊走邊談，進屋後，見聚集了許多人，</span>
<span className="v" id="v28" data-v="28" data-xref="約翰福音 4:9; 以弗所書 3:6–7; 加拉太書 2:12–14"> 就對他們說：「你們知道，按照律法，猶太人不可和外族人來往。但上帝已經指示我不可把任何人視為污穢不潔。</span>
<span className="v" id="v29" data-v="29" data-xref="詩篇 119:60; 彼得前書 3:15; 使徒行傳 10:19–20"> 所以，我受到邀請後，毫不猶豫地來了。請問你們為什麼請我來？」</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="使徒行傳 10:3; 但以理書 9:20–21; 尼希米記 9:1–3"> 哥尼流說：「四天前，大約也是下午三點這個時候，我在家裡禱告，忽然有一個身穿明亮衣服的人站在我面前，</span>
<span className="v" id="v31" data-v="31" data-xref="使徒行傳 10:4; 但以理書 9:23; 路加福音 1:13"> 說，『哥尼流，上帝已經垂聽了你的禱告，也記念你的施捨。</span>
<span className="v" id="v32" data-v="32"> 你派人去約帕把那個叫西門·彼得的人請來，他住在海邊一個叫西門的皮革匠家裡。』</span>
<span className="v" id="v33" data-v="33" data-xref="雅各書 1:19; 加拉太書 4:14; 歷代志下 30:12"> 於是我立刻派人去請你。你能來，真是榮幸，現在我們都在上帝面前，想聆聽主吩咐你傳給我們的話。」</span>
</div>
</div>

## 福音臨到外族人

<div className="bt">
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="羅馬書 2:11; 歷代志下 19:7; 申命記 10:17"> 彼得說：「現在我真的明白了，上帝不偏待人。</span>
<span className="v" id="v35" data-v="35" data-xref="約翰一書 2:29; 使徒行傳 10:2; 羅馬書 10:12–13"> 無論哪一個民族，只要敬畏祂，秉公行義，都會蒙祂接納。</span>
<span className="v" id="v36" data-v="36" data-xref="馬太福音 28:18; 使徒行傳 2:36; 啟示錄 17:14"> 上帝藉著萬物的主宰耶穌基督把平安的福音傳給以色列人。</span>
<span className="v" id="v37" data-v="37" data-xref="路加福音 4:14; 使徒行傳 2:22; 使徒行傳 28:22"> 你們都知道，自從約翰宣講洗禮以來，從加利利開始，整個猶太地區發生了什麼事。</span>
<span className="v" id="v38" data-v="38" data-xref="路加福音 4:18; 使徒行傳 2:22; 以賽亞書 61:1–3"> 你們也知道，拿撒勒人耶穌是上帝用聖靈和大能膏立的。祂周遊四方，廣行善事，醫治被魔鬼壓制的人，因為上帝與祂同在。</span>
<span className="v" id="v39" data-v="39" data-xref="路加福音 24:48; 使徒行傳 1:8; 使徒行傳 10:41"> 我們親眼目睹了耶穌在猶太全境和耶路撒冷的一切作為。可是，他們卻把祂釘死在十字架上。</span>
<span className="v" id="v40" data-v="40" data-xref="彼得前書 1:21; 使徒行傳 13:30–31; 哥林多前書 15:3–4"> 但第三天，上帝使祂從死裡復活，並且向人顯現，</span>
<span className="v" id="v41" data-v="41" data-xref="約翰福音 14:22; 使徒行傳 10:39; 約翰福音 21:13"> 不是向所有的人顯現，而是向被上帝預先揀選為祂作見證的人顯現，就是我們這些在祂復活以後與祂一同吃喝過的人。</span>
<span className="v" id="v42" data-v="42" data-xref="哥林多後書 5:10; 提摩太後書 4:1; 彼得前書 4:5"> 祂命令我們向世人傳道，見證祂就是上帝指派來審判活人和死人的那位。</span>
<span className="v" id="v43" data-v="43" data-xref="撒迦利亞書 13:1; 使徒行傳 2:38; 以賽亞書 53:11"> 所有先知也都為祂作見證說，『誰信祂，誰的罪就能藉著祂的名得到赦免。』」</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="使徒行傳 11:15; 使徒行傳 19:6; 使徒行傳 15:8"> 彼得還在說話的時候，聖靈就降臨在每一個聽道的人身上。</span>
<span className="v" id="v45" data-v="45" data-xref="使徒行傳 10:23; 使徒行傳 2:38; 加拉太書 3:13–14"> 跟彼得一起來的那些嚴守割禮的信徒看見聖靈的恩賜也澆灌到外族人身上，都很驚奇。</span>
<span className="v" id="v46" data-v="46" data-xref="使徒行傳 19:6; 使徒行傳 2:4; 馬可福音 16:17"> 因為他們聽見這些人又說方言又讚美上帝。於是彼得說：</span>
<span className="v" id="v47" data-v="47" data-xref="使徒行傳 8:36; 羅馬書 10:12; 使徒行傳 11:15–17"> 「既然這些人已經和我們一樣領受了聖靈，誰能阻止他們接受洗禮呢？」</span>
<span className="v" id="v48" data-v="48" data-xref="使徒行傳 2:38; 使徒行傳 8:16; 加拉太書 3:27"> 彼得吩咐他們奉耶穌基督的名受洗。之後，他們又請彼得住了幾天。</span>
</div>
</div>

<div className="bible-chapter" lang="zh-Hant" dir="ltr" data-lang="zh-Hant" data-translation="ccbt" data-translation-id="cmn_cbt" data-translation-label="當代譯本" data-book="ACT" data-book-slug="acts" data-book-name="使徒行傳" data-chapter="23" data-verses="35">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行傳 24:16; 提摩太後書 1:3; 哥林多後書 1:12"> 保羅注視著公會的人，說：「弟兄們，我在上帝面前行事為人一向問心無愧。」</span>
<span className="v" id="v2" data-v="2" data-xref="約翰福音 18:22; 使徒行傳 24:1; 彌迦書 5:1"> 大祭司亞拿尼亞一聽，就命那些站在旁邊的人打保羅的嘴。</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 25:1–2; 約翰福音 7:51; 馬太福音 23:27–28"> 保羅對亞拿尼亞說：「你這偽君子<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「偽君子」希臘文是「粉飾的牆」。">a</a></sup>，上帝要擊打你！你坐在那裡不是應當照律法審問我嗎？你怎麼違背律法叫人打我？」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4"> 站在旁邊的人說：「你竟敢辱罵上帝的大祭司？」</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 22:28; 傳道書 10:20; 猶大書 1:8–9"> 保羅說：「弟兄們，我不知道他是大祭司。因為聖經記載，『不可咒詛百姓的官長。』<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="出埃及記22·28。">b</a></sup>」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="使徒行傳 24:15; 使徒行傳 24:21; 使徒行傳 26:5–8"> 保羅發現他們一些是法利賽人，一些是撒都該人，就在公會中高聲說：「弟兄們，我是法利賽人，也是法利賽人的子孫。我因為盼望死人復活，才在這裡受審！」</span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 55:9; 約翰福音 7:40–43; 馬太福音 10:34"> 這句話引起法利賽人和撒都該人之間的爭論，公會分成了兩派。</span>
<span className="v" id="v8" data-v="8" data-xref="路加福音 20:27; 馬太福音 22:23; 馬可福音 12:18"> 因為撒都該人認為沒有復活，也沒有天使和靈，而法利賽人認為這些都有。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="使徒行傳 22:7; 使徒行傳 22:17–18; 約翰福音 12:29"> 眾人大聲喧嚷，有幾個法利賽派的律法教師站起來爭辯說：「我們找不出這人有什麼錯處，也許真的有靈或天使跟他說過話呢！」</span>
<span className="v" id="v10" data-v="10" data-xref="雅各書 1:19; 雅各書 3:14–2; 使徒行傳 22:24"> 爭論越來越激烈，千夫長怕保羅會被他們扯碎了，就派士兵把他從人群中硬搶走，帶回軍營。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="使徒行傳 18:9; 使徒行傳 19:21; 提摩太後書 4:17"> 當晚，主站在保羅身旁對他說：「要勇敢！你怎樣在耶路撒冷為我作見證，也必照樣在羅馬為我作見證。」</span>
</div>
</div>

## 陰謀殺害保羅

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="使徒行傳 23:30; 以賽亞書 8:9–10; 使徒行傳 23:21"> 天亮後，猶太人設下陰謀，並起誓說：「不殺保羅，誓不吃喝！」</span>
<span className="v" id="v13" data-v="13" data-xref="約翰福音 16:2; 撒母耳記下 15:31; 撒母耳記下 15:12"> 有四十多人參與了這個陰謀。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行傳 23:12; 耶利米書 8:12; 以賽亞書 3:9"> 他們去見祭司長和長老，說：「我們已經發了誓，不殺保羅就不吃飯。</span>
<span className="v" id="v15" data-v="15" data-xref="以賽亞書 59:7; 詩篇 37:32–33; 箴言 1:16"> 請你們和公會出面通知千夫長，請他把保羅押到你們這裡來，就說要進一步審訊他。我們準備在他到達之前殺掉他！」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="使徒行傳 23:10; 哥林多前書 3:19; 使徒行傳 23:32"> 保羅的外甥聽到這一陰謀，就去軍營通知保羅。</span>
<span className="v" id="v17" data-v="17" data-xref="箴言 22:3; 馬太福音 8:8–9; 馬太福音 10:16"> 保羅請來一位百夫長，說：「請帶這青年去見千夫長，他有要事稟告！」</span>
<span className="v" id="v18" data-v="18" data-xref="以弗所書 3:1; 以弗所書 4:1; 使徒行傳 28:17"> 百夫長領他去見千夫長，說：「那囚犯保羅叫我帶這青年來，說有要事稟告。」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="耶利米書 31:32; 以斯帖記 9:12; 以斯帖記 7:2"> 千夫長就拉著那青年的手走到一旁，私下問他：「你有什麼事要告訴我？」</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行傳 23:14–15; 使徒行傳 23:1; 詩篇 12:2"> 他說：「那些猶太人約好了，要請求你明天帶保羅到公會，假裝要詳細審問他的事。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行傳 23:12–14; 使徒行傳 14:5–6; 哥林多後書 11:26"> 你不要答應他們，因為他們有四十多個人正埋伏在半路，並且還起誓說，『不殺保羅，誓不吃喝。』他們現在已經準備就緒，就等你答應了。」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="馬可福音 1:44; 約書亞記 2:14"> 千夫長聽後，就叫他回去，並叮囑道：「你向我稟告的事，不要告訴別人。」</span>
</div>
</div>

## 保羅被押往凱撒利亞

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="馬太福音 14:25; 使徒行傳 23:33; 路加福音 12:38"> 於是，千夫長召來兩名百夫長，吩咐道：「預備二百名步兵、七十名騎兵、二百名長槍手，今晚九點出發去凱撒利亞。</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行傳 25:14; 使徒行傳 23:26; 使徒行傳 24:10"> 要給保羅預備坐騎，護送他安全抵達腓利斯總督那裡。」</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25"> 千夫長寫了公文給腓利斯總督，內容如下：</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行傳 15:23; 使徒行傳 26:25; 路加福音 1:3"> 「克勞狄·呂西亞敬問腓利斯總督大人安。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行傳 22:25–29; 使徒行傳 21:31–33; 使徒行傳 24:6"> 這人被猶太人抓住，險些被他們殺害。我得知他是羅馬公民，便帶兵去救了他。</span>
<span className="v" id="v28" data-v="28" data-xref="使徒行傳 22:30"> 為了弄清楚他們控告他的緣由，我押他到猶太人的公會受審，</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行傳 26:31; 使徒行傳 25:25; 使徒行傳 18:15"> 發現他是因為他們的律法問題而被控告，他並沒有犯該被監禁或處死的罪。</span>
<span className="v" id="v30" data-v="30" data-xref="使徒行傳 23:35; 使徒行傳 25:16; 使徒行傳 25:5–6"> 我得知有人準備暗殺他，便立即護送他到你那裡，並吩咐他的控告者去你那裡告他。」</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="提摩太後書 2:3–4; 路加福音 7:8; 使徒行傳 23:23–24"> 軍兵奉命行事，連夜護送保羅到安提帕底。</span>
<span className="v" id="v32" data-v="32" data-xref="使徒行傳 23:23; 使徒行傳 23:10"> 第二天，由騎兵繼續護送，其餘軍兵返回軍營。</span>
<span className="v" id="v33" data-v="33" data-xref="使徒行傳 23:26; 使徒行傳 23:23–24; 使徒行傳 28:16"> 他們到了凱撒利亞，將公文呈交總督，把保羅交給他。</span>
<span className="v" id="v34" data-v="34" data-xref="使徒行傳 21:39; 使徒行傳 25:1; 但以理書 2:49"> 總督看過公文，便問保羅是哪省的人，得知保羅是基利迦人，就說：</span>
<span className="v" id="v35" data-v="35" data-xref="使徒行傳 23:30; 使徒行傳 25:16; 馬太福音 27:27"> 「等告你的人來了，我會審理你的案子。」於是下令把保羅關在希律的王府裡。</span>
</div>
</div>

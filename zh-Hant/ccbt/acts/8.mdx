## 教會受迫害

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行傳 22:20; 但以理書 3:16–18; 使徒行傳 5:40"> 當時，掃羅也贊成殺死司提凡。從那天起，耶路撒冷的教會開始遭到極大的迫害。除了使徒之外，門徒都分散到猶太和撒瑪利亞各地。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 50:10–11; 創世記 23:2; 耶利米書 22:18"> 有些虔誠人將司提凡埋葬了，為他大聲痛哭。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="提摩太前書 1:13; 加拉太書 1:13; 哥林多前書 15:9"> 掃羅卻在摧毀教會，他挨家挨戶搜尋，把男女信徒抓進監牢。</span>
</div>
</div>

## 腓利傳揚福音

<div className="bt">
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="馬太福音 10:23; 使徒行傳 11:19; 使徒行傳 8:1"> 但那些分散到各地的信徒走到哪裡，就將福音傳到哪裡。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行傳 6:5; 使徒行傳 21:8; 使徒行傳 8:35–36"> 腓利來到撒瑪利亞城宣講基督。</span>
<span className="v" id="v6" data-v="6" data-xref="約翰福音 4:41–42; 歷代志下 30:12; 馬太福音 20:15–16"> 城裡的人耳聞目睹他所行的神蹟，都聚精會神地聽他講道。</span>
<span className="v" id="v7" data-v="7" data-xref="馬太福音 10:1; 使徒行傳 14:8–10; 馬可福音 16:17–18"> 當時有許多人被污鬼附身，那些污鬼大聲喊叫著被趕了出來。許多癱瘓的和瘸腿的也被治好了。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行傳 13:52; 使徒行傳 13:48; 使徒行傳 8:39"> 城裡歡天喜地。</span>
</div>
</div>

## 術士歸主

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="使徒行傳 13:6; 使徒行傳 5:36; 約翰福音 7:18"> 城中有個名叫西門的術士，向來自命不凡，曾用邪術使撒瑪利亞人驚奇不已。</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米書 31:34; 彼得後書 2:2; 啟示錄 13:3"> 無論尊卑，眾人都聽從他，稱他為「上帝的大能者」。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行傳 8:9; 加拉太書 3:1; 以賽亞書 44:25"> 他們聽從他，因為他長期用邪術迷惑他們。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行傳 2:38; 使徒行傳 1:3; 馬太福音 28:19"> 後來，他們相信了腓利所傳有關上帝國度的福音和耶穌基督的名，男男女女都接受了洗禮。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行傳 8:6–7; 約翰福音 5:20; 使徒行傳 19:11"> 西門本人也信了基督，接受了洗禮，並常常追隨腓利左右。腓利所行的神蹟奇事令他非常驚奇。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="帖撒羅尼迦前書 2:13; 帖撒羅尼迦前書 3:2; 加拉太書 2:9"> 耶路撒冷的使徒聽說撒瑪利亞人接受了上帝的道，就派彼得和約翰去那裡。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行傳 2:38; 約翰福音 16:23–24; 約翰福音 14:13–14"> 二人到了，為那些信徒禱告，好讓他們領受聖靈，</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行傳 2:38; 使徒行傳 19:2; 馬太福音 28:19"> 因為他們只是奉耶穌的名受了洗，聖靈還沒有降在他們身上。</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行傳 19:6; 使徒行傳 6:6; 提摩太後書 1:6"> 使徒為他們按手，他們就領受了聖靈。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="提摩太前書 6:5; 馬太福音 10:8; 列王紀下 8:9"> 西門看見使徒一按手，就有聖靈賜下來，便拿錢給使徒，</span>
<span className="v" id="v19" data-v="19" data-xref="路加福音 14:7–11; 約翰三書 1:9; 約翰福音 5:44"> 說：「請把這能力也給我吧，以便我把手按在誰身上，就使誰領受聖靈。」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="但以理書 5:17; 馬太福音 10:8; 使徒行傳 2:38"> 彼得責備他說：「你和你的錢都一同毀滅吧！因為你以為可以用錢買上帝的恩賜！</span>
<span className="v" id="v21" data-v="21" data-xref="希伯來書 4:13; 詩篇 36:1; 馬太福音 6:22–24"> 你休想在這事工上有份，因為你在上帝面前心術不正。</span>
<span className="v" id="v22" data-v="22" data-xref="提摩太後書 2:25–26; 但以理書 4:27; 希伯來書 4:12"> 你要悔改，離棄邪惡，向主禱告，或許主會赦免你心中的邪念。</span>
<span className="v" id="v23" data-v="23" data-xref="以賽亞書 58:6; 箴言 5:22; 約翰福音 8:34"> 我看得出你充滿苦澀的嫉妒，被罪惡捆綁。」</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="出埃及記 8:8; 民數記 21:7; 約伯記 42:8"> 西門說：「請為我求求主，免得我遭受你們所說的刑罰。」</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="使徒行傳 20:21; 使徒行傳 26:22–23; 使徒行傳 1:8"> 彼得和約翰為主作見證，傳講主的道。之後，他們啟程回耶路撒冷，沿途又在撒瑪利亞各村莊傳揚福音。</span>
</div>
</div>

## 太監歸主

<div className="bt">
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="使徒行傳 5:19; 希伯來書 1:14; 列王紀下 1:3"> 有一天，主的天使對腓利說：「起來，向南走，往耶路撒冷通往迦薩的路去。」那條路很荒涼。</span>
<span className="v" id="v27" data-v="27" data-xref="西番雅書 3:10; 詩篇 68:31; 以賽亞書 56:3–8"> 腓利就動身去那裡，結果在那條路上遇見一個衣索匹亞的太監。他是衣索匹亞女王甘大基手下的重臣，負責管理國庫。他剛從耶路撒冷參加敬拜回來，</span>
<span className="v" id="v28" data-v="28" data-xref="歌羅西書 3:16; 以賽亞書 1:1; 使徒行傳 28:25"> 正坐在車上誦讀以賽亞先知的書。</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行傳 10:19; 使徒行傳 11:12; 使徒行傳 20:22–23"> 聖靈吩咐腓利：「趕上去，貼近那輛馬車！」</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="路加福音 24:44–45; 約翰福音 5:39; 以弗所書 5:17"> 腓利跑上前，聽見太監在誦讀以賽亞先知的書，就問：「你明白所讀的經文嗎？」</span>
</div>
<div className="bp poetry">
<span className="v" id="v31" data-v="31" data-xref="羅馬書 10:14; 詩篇 73:16–17; 以賽亞書 29:18–19"> 他說：「沒有人指點我，我怎能明白呢？」他就請腓利上車和他一起坐。</span>
<span className="v" id="v32" data-v="32" data-xref="以賽亞書 53:7–8; 彼得前書 2:21–24; 耶利米書 51:40"> 他剛才念的那段經文是：<br /><span className="pl pl-1">「祂默然不語，</span><br /><span className="pl pl-1">像被人牽去宰殺的羔羊，</span><br /><span className="pl pl-1">又如在剪毛人手下一聲不吭的綿羊。</span><br /></span>
<span className="v" id="v33" data-v="33" data-xref="以賽亞書 53:12; 以賽亞書 53:8; 撒迦利亞書 13:7"> <span className="pl pl-1">祂忍受恥辱，</span><br /><span className="pl pl-1">無人為祂主持公道，</span><br /><span className="pl pl-1">誰能講述祂的世代呢？</span><br /><span className="pl pl-1">因為祂的生命竟然從世上被奪去。」</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="以賽亞書53·7、8。">a</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="馬太福音 15:15; 馬太福音 13:36; 馬太福音 2:2–4"> 太監問腓利：「請問先知是在說誰？在說他自己還是在說別人？」</span>
<span className="v" id="v35" data-v="35" data-xref="路加福音 24:27; 使徒行傳 18:28; 使徒行傳 28:23"> 腓利就從這段經文入手開口向他傳耶穌的福音。</span>
<span className="v" id="v36" data-v="36" data-xref="使徒行傳 10:47; 約翰福音 3:5; 提多書 3:5–6"> 他們往前走的時候，經過一處有水的地方，太監說：「你看，這裡有水，我可以在這裡接受洗禮嗎？」</span>
<span className="v" id="v37" data-v="37"> 腓利說：「只要你全心相信，當然可以。」太監說：「我相信耶穌基督是上帝的兒子！」<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有古卷無37節。">b</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="約翰福音 4:1; 約翰福音 3:22–23"> 於是，太監吩咐停車，二人一同下到水裡，腓利為他施洗。</span>
<span className="v" id="v39" data-v="39" data-xref="列王紀上 18:12; 列王紀下 2:16; 以西結書 8:3"> 他們從水裡上來時，主的靈把腓利帶走了。太監看不見腓利了，就繼續前行，滿心歡喜。</span>
<span className="v" id="v40" data-v="40" data-xref="使徒行傳 21:8; 使徒行傳 23:23; 使徒行傳 23:33"> 後來，腓利出現在亞鎖都。他走遍那裡，在各城各鄉傳揚福音，直到凱撒利亞。</span>
</div>
</div>

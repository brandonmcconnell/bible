## 在馬爾他島

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行傳 27:26; 使徒行傳 27:44; 使徒行傳 27:39"> 我們安全上岸後，才知道那個島的名字叫馬爾他。</span>
<span className="v" id="v2" data-v="2" data-xref="羅馬書 1:14; 希伯來書 13:2; 歌羅西書 3:11"> 島上的居民對我們非常友善。因為下雨，天氣又冷，他們就生火接待我們。</span>
<span className="v" id="v3" data-v="3" data-xref="馬太福音 23:33; 馬太福音 12:34; 使徒行傳 28:4"> 保羅撿了一捆柴放進火堆裡，不料有一條毒蛇經不住熱鑽了出來，咬住他的手。</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 13:2; 路加福音 13:4; 約翰福音 7:24"> 那裡的居民看見毒蛇吊在保羅手上，就交頭接耳地說：「這人一定是個兇手，雖然僥倖沒有淹死，天理卻不容他活下去。」</span>
<span className="v" id="v5" data-v="5" data-xref="路加福音 10:19; 馬可福音 16:18; 詩篇 91:13"> 可是保羅把蛇甩進火裡，並沒有受傷。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行傳 12:22; 使徒行傳 14:11–13; 馬太福音 21:9"> 他們以為保羅的手一定會腫起來或者他會突然倒斃，但是等了很久，見他還是安然無恙，就改變了想法，說他是個神明。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="馬太福音 10:40–41; 路加福音 19:6–9; 使徒行傳 28:2"> 那個島的首領名叫部百流，他的田產就在附近。他接待我們，熱情款待了我們三天。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行傳 9:40; 馬可福音 6:5; 雅各書 5:14–16"> 當時，部百流的父親患痢疾，正發燒躺在床上。保羅去為他禱告，把手按在他身上治好了他。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行傳 5:12; 馬可福音 6:54–56; 使徒行傳 5:15"> 這事以後，島上其他病人也來了，並得了醫治。</span>
<span className="v" id="v10" data-v="10" data-xref="帖撒羅尼迦前書 2:6; 腓立比書 4:11–12; 馬太福音 6:31–34"> 他們處處尊敬我們，在我們啟航的時候，又贈送我們途中所需用的物品。</span>
</div>
</div>

## 保羅抵達羅馬

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="使徒行傳 27:6; 哥林多前書 8:4; 以賽亞書 45:20"> 三個月後，我們搭乘一艘停在該島過冬的船離開。這船叫「雙神號<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「雙神號」希臘語是「卡斯特與帕勒克」，二者為宙斯的雙生子，是航運之神。">a</a></sup>」，來自亞歷山大。</span>
<span className="v" id="v12" data-v="12"> 我們先到敘拉古港，在那裡停泊三天，</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行傳 27:13"> 然後繼續前行，到達利基翁。第二天，起了南風，第三天我們抵達部丟利，</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行傳 21:4; 使徒行傳 20:6; 使徒行傳 19:1"> 在那裡遇見幾位弟兄姊妹，應邀和他們同住了七天，然後前往羅馬。</span>
<span className="v" id="v15" data-v="15" data-xref="希伯來書 13:3; 羅馬書 15:24; 出埃及記 4:14"> 那裡的弟兄姊妹聽說我們來了，便到亞比烏和三館迎接我們。保羅見到他們後，就感謝上帝，心中受到鼓勵。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行傳 27:3; 使徒行傳 24:23; 使徒行傳 28:30–31"> 我們進了羅馬城後，保羅獲准在衛兵的看守下自己一個人住。</span>
</div>
</div>

## 繼續傳道

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="使徒行傳 25:8; 使徒行傳 6:14; 使徒行傳 25:10"> 三天後，保羅請來當地猶太人的首領，對他們說：「弟兄們，我雖然沒有做過任何對不起同胞或違背祖先規矩的事，卻在耶路撒冷遭囚禁，又被交到羅馬人的手裡。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行傳 26:31–32; 使徒行傳 23:29; 使徒行傳 22:24–25"> 羅馬官員審訊了我，發現我沒有什麼該死的罪，想釋放我，</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行傳 26:32; 使徒行傳 25:21; 使徒行傳 25:10–12"> 猶太人卻反對，我不得已只好上訴凱撒。我並非有什麼事要控告自己的同胞。</span>
<span className="v" id="v20" data-v="20" data-xref="以弗所書 6:20; 提摩太後書 2:9; 使徒行傳 26:6–7"> 為此，我才請你們來當面談，我受捆綁是為了以色列人所盼望的那位。」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="以賽亞書 54:17; 以賽亞書 41:11; 以賽亞書 50:8"> 他們說：「猶太境內的同胞沒有給我們寫信提你的事，也沒有弟兄到這裡說你的壞話。</span>
<span className="v" id="v22" data-v="22" data-xref="彼得前書 2:12; 使徒行傳 24:14; 彼得前書 3:16"> 不過，我們倒很想聽聽你的觀點，因為我們知道你們這一派的人到處受人抨擊。」</span>
</div>
<div className="bp poetry">
<span className="v" id="v23" data-v="23" data-xref="使徒行傳 17:2–3; 使徒行傳 19:8; 使徒行傳 18:28"> 於是，他們和保羅約定了會面的日期。那一天，很多人來到保羅住的地方。從早到晚，保羅向他們講解和見證上帝的國，引用摩西律法和先知書勸他們相信有關耶穌的事。</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行傳 14:4; 使徒行傳 17:4–5; 使徒行傳 19:8–9"> 有些人相信了他的話，有些人不相信，</span>
<span className="v" id="v25" data-v="25" data-xref="馬太福音 15:7; 彼得後書 1:21; 馬可福音 7:6"> 他們彼此意見不一。在他們散去之前，保羅說了一句話：「聖靈藉以賽亞先知對你們祖先所說的話真是一點不錯，</span>
<span className="v" id="v26" data-v="26" data-xref="以賽亞書 6:9–10; 以西結書 12:2; 以賽亞書 42:19–20"> 祂說，<br /><span className="pl pl-1">「『你去告訴百姓，</span><br /><span className="pl pl-1">你們聽了又聽，卻不明白；</span><br /><span className="pl pl-1">看了又看，卻不領悟。</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="以賽亞書 6:10"> <span className="pl pl-1">因為這百姓心靈麻木，</span><br /><span className="pl pl-1">耳朵發背，眼睛昏花，</span><br /><span className="pl pl-1">以致眼睛看不見，</span><br /><span className="pl pl-1">耳朵聽不見，心裡不明白，無法回心轉意，</span><br /><span className="pl pl-1">得不到我的醫治。』</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="以賽亞書6·9、10。">b</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="路加福音 2:30–32; 使徒行傳 26:17–18; 羅馬書 3:29–30"> 所以你們當知道，上帝的救恩已經傳給了外族人，他們也必聽。」</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29"> 聽完保羅的話後，那些猶太人就回去了，他們中間起了激烈的爭論。<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="有古卷無29節。">c</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30"> 後來，保羅自己租了一間房子，在那裡住了整整兩年，接待所有到訪的人。</span>
<span className="v" id="v31" data-v="31" data-xref="使徒行傳 4:29; 以弗所書 6:19–20; 馬太福音 4:23"> 他勇敢地傳講上帝的國，教導有關主耶穌基督的事，沒有受到任何攔阻。</span>
</div>
</div>

</div>

## 在以哥念傳道

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行傳 18:4; 使徒行傳 13:51; 使徒行傳 13:46"> 保羅和巴拿巴一同進入以哥念的猶太會堂講道，許多猶太人和希臘人信了耶穌。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行傳 13:50; 使徒行傳 21:27–30; 使徒行傳 14:19"> 但那些頑梗不信的猶太人卻慫恿外族人敵視信徒。</span>
<span className="v" id="v3" data-v="3" data-xref="希伯來書 2:4; 以弗所書 6:18–20; 使徒行傳 20:32"> 二人在那裡逗留了好些日子，靠著主勇敢地傳道。主賜給他們行神蹟奇事的能力，為祂的恩典之道作見證。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行傳 28:24; 使徒行傳 14:14; 路加福音 11:21–23"> 城裡的居民分成了兩派，有些附和猶太人，有些支持使徒。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行傳 14:19; 提摩太後書 3:11; 使徒行傳 17:5"> 當時，有些外族人、猶太人及其官長企圖惡待使徒，用石頭打他們。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行傳 14:20–21; 馬太福音 10:23; 提摩太後書 3:11"> 保羅和巴拿巴得知後，就逃往呂高尼的路司得和特庇二城並周圍的地區，</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行傳 14:21; 使徒行傳 16:10; 帖撒羅尼迦前書 2:2"> 在那裡繼續傳揚福音。</span>
</div>
</div>

## 在路司得和特庇傳福音

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="使徒行傳 3:2; 約翰福音 9:1–2; 約翰福音 5:3–5"> 路司得城裡坐著一個生來瘸腿的，他雙腳無力，不能走路。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行傳 3:4; 馬太福音 15:28; 馬太福音 9:28–29"> 他在聽保羅講道。保羅定睛看他，見這個人有信心，可以得醫治，</span>
<span className="v" id="v10" data-v="10" data-xref="以賽亞書 35:6; 約翰福音 5:8–9; 約翰福音 14:12"> 就高聲對他說：「起來，兩腳站直！」那人就跳了起來，開始行走。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行傳 28:6; 使徒行傳 8:10; 使徒行傳 12:22"> 周圍的人看見保羅所行的，就用呂高尼話大聲說：「神明化成人形下凡了！」</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行傳 19:35"> 於是，他們稱巴拿巴為宙斯，又因為保羅是主要的發言人，就稱他為希耳米<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="希臘神話中天神宙斯是最大的神，希耳米則是為眾神傳遞信息的使者——「傳諭之神」。">a</a></sup>。</span>
<span className="v" id="v13" data-v="13" data-xref="但以理書 2:46; 使徒行傳 10:25"> 城外宙斯廟的祭司也牽著牛、拿著花環來到城門口，要和眾人一同向使徒獻祭。</span>
<span className="v" id="v14" data-v="14" data-xref="馬太福音 26:65; 哥林多前書 9:5–6; 列王紀下 5:7"> 巴拿巴和保羅二位使徒見此情形，就撕裂衣服，衝進人群中，高喊：</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行傳 10:26; 哥林多前書 8:4; 雅各書 5:17"> 「各位，你們為什麼這樣做？我們和你們一樣只是凡人！我們來這裡是要向你們傳福音，叫你們離棄這些虛妄的事，轉向那創造天地、海洋和其中萬物的永活上帝。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行傳 17:30; 詩篇 81:12; 羅馬書 1:28"> 在以往的世代，祂雖然容許萬國各行其道，</span>
<span className="v" id="v17" data-v="17" data-xref="羅馬書 1:19–20; 約珥書 2:23; 約伯記 5:10"> 卻從未停止顯明自己的存在。祂常施恩惠，降下甘霖，賞賜豐年，又叫你們衣食飽足，滿心喜樂。」</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米書 44:16–17; 創世記 19:9; 創世記 11:6"> 保羅和巴拿巴說了這些話，才勉強制止住人群向他們獻祭。</span>
<span className="v" id="v19" data-v="19" data-xref="哥林多後書 11:25; 提摩太後書 3:11; 使徒行傳 13:50–51"> 有些猶太人從安提阿和以哥念來煽動民眾，他們用石頭打保羅，以為他死了，就把他拖到城外。</span>
<span className="v" id="v20" data-v="20" data-xref="哥林多後書 1:9–10; 哥林多後書 6:9; 使徒行傳 14:6"> 當門徒圍過來看他的時候，他站了起來，走回城裡。第二天，保羅和巴拿巴前往特庇。</span>
</div>
</div>

## 返回安提阿

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="使徒行傳 14:19; 使徒行傳 14:1; 使徒行傳 13:51"> 他們向那裡的人傳福音，有很多人作了門徒。然後，他們又回到路司得、以哥念和安提阿，</span>
<span className="v" id="v22" data-v="22" data-xref="彼得前書 5:10; 提摩太後書 3:12; 約翰福音 16:33"> 堅固各地門徒的心志，鼓勵他們要持守信仰，並且說：「我們在進入上帝國的道路上必經歷許多苦難。」</span>
<span className="v" id="v23" data-v="23" data-xref="提多書 1:5; 使徒行傳 11:30; 雅各書 5:14"> 二人又為每個教會選立長老，禁食禱告，把他們交託給所信靠的主。</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行傳 13:13–14; 使徒行傳 15:38"> 後來，二人又經過彼西底，來到旁非利亞，</span>
<span className="v" id="v25" data-v="25"> 在別加講完道，然後下到亞大利，</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行傳 15:40; 使徒行傳 11:19; 哥林多後書 1:12"> 從那裡乘船回安提阿。當初就是在安提阿，他們被交託在上帝的恩典中去傳道，如今工作已經完成了。</span>
<span className="v" id="v27" data-v="27" data-xref="哥林多前書 16:9; 使徒行傳 15:12; 歌羅西書 4:3"> 他們到達之後，就召集教會的人，報告上帝藉著他們所做的一切事，以及上帝如何給外族人開了信仰之門。</span>
<span className="v" id="v28" data-v="28" data-xref="使徒行傳 11:26; 使徒行傳 15:35"> 之後，二人和門徒同住了很久。</span>
</div>
</div>

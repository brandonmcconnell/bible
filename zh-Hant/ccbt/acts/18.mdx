## 保羅在哥林多傳道

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多前書 1:2; 提摩太後書 4:20; 哥林多後書 1:1"> 這事之後，保羅離開雅典前往哥林多，</span>
<span className="v" id="v2" data-v="2" data-xref="羅馬書 16:3–4; 哥林多前書 16:19; 提摩太後書 4:19"> 在那裡認識了一位在本都出生的猶太人亞居拉。由於克勞狄命令所有的猶太人離開羅馬，他最近和妻子百基拉從義大利來到哥林多。保羅拜訪了他們。</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多前書 4:12; 帖撒羅尼迦前書 2:9; 哥林多後書 11:9"> 他們夫婦跟保羅是同行，都以製造帳篷為業，保羅就留下來和他們同住，一起做工。</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多後書 5:11; 使徒行傳 17:17; 使徒行傳 28:23"> 保羅每個安息日都到會堂與猶太人和希臘人辯論，勸導他們信主。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="哥林多後書 5:14; 使徒行傳 18:28; 使徒行傳 20:21"> 西拉和提摩太從馬其頓來了之後，保羅就把全部時間都用來傳道，向猶太人證明耶穌是基督。</span>
<span className="v" id="v6" data-v="6" data-xref="以西結書 33:4; 撒母耳記下 1:16; 以西結書 33:8–9"> 可是，猶太人反對、毀謗保羅。保羅便抖掉衣服上的灰塵，對他們說：「你們的罪都歸在你們自己頭上，與我無關！從今以後，我要去外族人那裡了。」</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行傳 16:14; 歌羅西書 4:11; 使徒行傳 10:2"> 保羅就離開那裡，來到一個敬畏上帝、名叫提多·猶士都的人家裡，他家就在會堂隔壁。</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多前書 1:13–17; 羅馬書 10:14–17; 馬可福音 16:15–16"> 會堂主管基利司布和他全家都信了主，許多哥林多人聽了道後，也信了主，受了洗。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="使徒行傳 23:11; 以弗所書 6:19–20; 使徒行傳 27:23–25"> 一天晚上，主在異象中對保羅說：「不要怕，只管繼續傳講，不要停！</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多後書 12:9; 出埃及記 4:12; 以賽亞書 41:10"> 因為我與你同在，沒有人能夠傷害你，在這城裡還有許多屬我的子民。」</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行傳 14:3; 使徒行傳 19:10; 使徒行傳 20:31"> 保羅就在那裡住了一年半，向他們傳授上帝的道。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="使徒行傳 13:50; 使徒行傳 18:27; 使徒行傳 13:7"> 迦流出任亞該亞總督時，猶太人聯合起來攻擊保羅，把他拉上法庭，</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行傳 25:8; 使徒行傳 24:5–6; 使徒行傳 6:13"> 說：「這個人教唆百姓不按律法敬拜上帝。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="彼得前書 3:14–15; 使徒行傳 25:11; 馬可福音 9:19"> 保羅剛要開口，迦流就對猶太人說：「你們這些猶太人！如果這事涉及什麼罪行冤情，我當然會處理。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行傳 23:29; 使徒行傳 25:19; 提摩太前書 6:4"> 但如果只是關於字句、名稱和你們猶太律法的爭論，你們自己去解決吧，我不受理！」</span>
<span className="v" id="v16" data-v="16" data-xref="啟示錄 12:16; 詩篇 76:10; 羅馬書 13:3–4"> 迦流隨即把他們趕出了法庭。</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多前書 1:1; 阿摩司書 6:6; 使徒行傳 17:32"> 眾人揪住會堂主管所提尼，當庭把他痛打一頓。迦流卻置之不理。</span>
</div>
</div>

## 保羅回到安提阿

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="使徒行傳 21:24; 民數記 6:18; 民數記 6:5–9"> 保羅繼續在哥林多逗留了許多時日，才向弟兄姊妹道別。他和百基拉、亞居拉乘船前往敘利亞。保羅因為許過願，就在堅革哩剃了頭髮。</span>
<span className="v" id="v19" data-v="19" data-xref="以弗所書 1:1; 提摩太前書 1:3; 提摩太後書 1:18"> 到了以弗所，保羅離開亞居拉夫婦，獨自進入會堂跟猶太人辯論。</span>
<span className="v" id="v20" data-v="20" data-xref="馬可福音 1:37–38; 哥林多前書 16:12; 使徒行傳 20:16"> 眾人請保羅多留幾天，保羅謝絕了。</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多前書 4:19; 雅各書 4:15; 羅馬書 15:32"> 他向眾人道別，說：「如果上帝許可，我還會回來。」然後上船離開了以弗所。</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行傳 8:40; 使徒行傳 15:4; 使徒行傳 23:23"> 他在凱撒利亞登岸後，先上耶路撒冷去問候教會，再下到安提阿。</span>
<span className="v" id="v23" data-v="23" data-xref="使徒行傳 14:22; 使徒行傳 16:6; 使徒行傳 15:41"> 他在安提阿逗留了一些日子，然後離開那裡，走遍加拉太和弗呂迦地區，堅固各地的門徒。</span>
</div>
</div>

## 亞波羅放膽傳道

<div className="bt">
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="哥林多前書 4:6; 提多書 3:13; 哥林多前書 3:5–6"> 那時有一個生於亞歷山大、名叫亞波羅的猶太人來到以弗所。他博學善辯，熟悉聖經。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行傳 19:3; 羅馬書 12:11; 何西阿書 14:9"> 他在主的道上曾受過栽培，心裡火熱，能正確地講解和教導有關耶穌的事，但他只知道約翰的洗禮。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行傳 18:25; 使徒行傳 14:3; 哥林多前書 12:21"> 他開始在會堂裡勇敢地講道。百基拉和亞居拉聽了以後，便請他到家裡，給他更詳細地講解上帝的道。</span>
<span className="v" id="v27" data-v="27" data-xref="帖撒羅尼迦後書 2:13–14; 雅各書 1:16–18; 彼得前書 1:2–3"> 亞波羅有意去亞該亞，以弗所的弟兄姊妹就鼓勵他，並寫信請當地的門徒接待他。亞波羅到了之後，給當地蒙恩信主的人帶來很大幫助。</span>
<span className="v" id="v28" data-v="28" data-xref="使徒行傳 18:5; 哥林多前書 15:3–4; 使徒行傳 9:22"> 他在公眾面前有力地駁倒猶太人，引用聖經證明耶穌就是基督。</span>
</div>
</div>

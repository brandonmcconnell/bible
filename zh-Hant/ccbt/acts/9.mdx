## 掃羅歸主

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行傳 8:3; 提摩太前書 1:13; 加拉太書 1:13"> 掃羅繼續用兇狠的話恐嚇主的門徒。他去見大祭司，</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行傳 19:9; 使徒行傳 19:23; 使徒行傳 24:14"> 要取得授權書到大馬士革的各會堂搜捕信奉這道的人，無論男女，都要把他們綁了押回耶路撒冷。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="使徒行傳 26:12–13; 哥林多前書 15:8; 使徒行傳 22:6"> 當他快到大馬士革的時候，突然有一道光從天上四面照著他。</span>
<span className="v" id="v4" data-v="4" data-xref="撒迦利亞書 2:8; 創世記 22:11; 羅馬書 11:22"> 他倒在地上，聽見有聲音對他說：「掃羅！掃羅！你為什麼迫害我？」</span>
<span className="v" id="v5" data-v="5" data-xref="提摩太前書 1:13; 撒母耳記上 3:4–10; 約伯記 9:4"> 他說：「主啊，你是誰？」那聲音說：「我就是你所迫害的耶穌。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行傳 22:10; 使徒行傳 26:16; 提摩太前書 1:14–16"> 起來！進城去，有人會告訴你該做的事。」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="使徒行傳 22:9; 但以理書 10:7; 使徒行傳 26:13–14"> 同行的人站在那裡只聽見聲音，卻看不見人，嚇得張口結舌。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行傳 22:11; 使徒行傳 9:18; 列王紀下 6:17–20"> 掃羅從地上爬起來，睜大眼睛，卻什麼也看不見，同伴拉著他的手進了大馬士革。</span>
<span className="v" id="v9" data-v="9" data-xref="約拿書 3:6–8; 以斯帖記 4:16; 歷代志下 33:12–13"> 一連三天，掃羅什麼也看不見，也不吃也不喝。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="創世記 22:1; 使徒行傳 10:3; 使徒行傳 22:12"> 這時候，有個叫亞拿尼亞的門徒住在大馬士革，他在異象中聽見主呼喚他的名字，就回答說：「主啊，我在這裡。」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="使徒行傳 21:39; 使徒行傳 22:3; 使徒行傳 9:30"> 主說：「起來，到直街的猶大家去找一個來自大數、名叫掃羅的人，他正在禱告。</span>
<span className="v" id="v12" data-v="12" data-xref="馬可福音 5:23; 使徒行傳 9:10; 使徒行傳 9:17–18"> 他在異象中看見一個名叫亞拿尼亞的人去他那裡，把手按在他身上，使他恢復視力。」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="提摩太前書 1:13–15; 使徒行傳 8:3; 使徒行傳 22:19–20"> 亞拿尼亞回答說：「主啊！我聽見許多人說他對耶路撒冷的聖徒大加迫害。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行傳 9:21; 使徒行傳 7:59; 提摩太後書 2:22"> 他來這裡是得到祭司長的授權，要拘捕所有求告你名的人。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="加拉太書 1:15–16; 以弗所書 3:7–8; 提摩太後書 4:16–17"> 主對亞拿尼亞說：「你放心去吧！他是我揀選的器皿，要向外族人、君王和以色列人宣揚我的名。</span>
<span className="v" id="v16" data-v="16" data-xref="帖撒羅尼迦前書 3:3; 使徒行傳 21:11; 哥林多後書 6:4"> 我會讓他知道，他必為我的名受許多的苦。」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="使徒行傳 8:17; 使徒行傳 6:6; 使徒行傳 2:4"> 亞拿尼亞去了，進了那家，就把手按在掃羅身上，說：「掃羅弟兄，在你來的路上向你顯現的主耶穌派我來使你重見光明、被聖靈充滿。」</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多後書 3:14; 使徒行傳 22:16; 使徒行傳 2:38"> 頓時，掃羅的眼睛上有鱗片似的東西脫落，他就恢復了視力，便起來接受了洗禮。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行傳 26:20; 撒母耳記上 30:12; 加拉太書 1:17"> 他吃過東西之後，體力也恢復了。他和大馬士革的門徒住了幾天之後，</span>
<span className="v" id="v20" data-v="20" data-xref="約翰福音 20:28; 加拉太書 2:20; 約翰一書 4:14–15"> 隨即到各會堂去宣講：「耶穌是上帝的兒子。」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="使徒行傳 9:13–14; 使徒行傳 8:3; 帖撒羅尼迦後書 1:10"> 聽的人都大吃一驚，說：「他不就是那在耶路撒冷迫害信徒的人嗎？他到這裡來不是要把他們綁了押去見祭司長嗎？」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="使徒行傳 18:5; 以賽亞書 40:29; 路加福音 21:15"> 但掃羅越發有能力，他向大馬士革的猶太人證明耶穌是基督，使他們驚慌失措。</span>
</div>
</div>

## 掃羅逃生

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="加拉太書 1:17–18; 帖撒羅尼迦前書 2:15–16; 使徒行傳 14:19"> 過了一段日子，猶太人圖謀殺死掃羅。</span>
<span className="v" id="v24" data-v="24" data-xref="哥林多後書 11:32; 使徒行傳 25:3; 使徒行傳 20:3"> 他們晝夜在城門守候，伺機下手，但這陰謀被掃羅知道了。</span>
<span className="v" id="v25" data-v="25" data-xref="約書亞記 2:15; 哥林多後書 11:33; 撒母耳記上 19:11–12"> 他的門徒趁夜間用筐子把他從城牆上縋下去。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="使徒行傳 26:20; 加拉太書 1:17–19; 使徒行傳 9:19"> 掃羅逃到耶路撒冷後，曾設法與當地的門徒聯絡，可是他們都怕他，不相信他是門徒。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行傳 4:36; 使徒行傳 4:29; 使徒行傳 4:13"> 只有巴拿巴接待他，帶他去見使徒，向他們陳述掃羅如何在路上遇見主，主如何對他說話，他又如何勇敢地在大馬士革奉耶穌的名傳道。</span>
<span className="v" id="v28" data-v="28" data-xref="使徒行傳 1:21; 民數記 27:16–17; 詩篇 121:8"> 於是，掃羅就在耶路撒冷與使徒一起出入來往，奉主的名放膽傳道。</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行傳 6:1; 猶大書 1:9; 使徒行傳 11:20"> 他常常跟那些講希臘話的猶太人辯論，於是他們打算殺掉他。</span>
<span className="v" id="v30" data-v="30" data-xref="使徒行傳 11:25; 使徒行傳 8:40; 使徒行傳 9:11"> 弟兄姊妹知道這消息後，就把掃羅帶到凱撒利亞，然後送他到大數去。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="詩篇 111:10; 約翰福音 14:16–18; 以賽亞書 33:6"> 當時，猶太、加利利、撒瑪利亞各地的教會都很平安，得到了堅固。信徒們非常敬畏主，又得到聖靈的安慰，人數越來越多。</span>
</div>
</div>

## 彼得醫治癱瘓的人

<div className="bt">
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="使徒行傳 9:13; 使徒行傳 8:25; 箴言 2:8"> 彼得四處奔波，來到呂大探訪那裡的聖徒，</span>
<span className="v" id="v33" data-v="33" data-xref="路加福音 13:16; 約翰福音 5:5; 馬可福音 2:3–11"> 遇見一個癱瘓的人名叫以尼雅，已經臥床八年。</span>
<span className="v" id="v34" data-v="34" data-xref="馬太福音 9:6; 使徒行傳 3:12; 使徒行傳 3:6"> 彼得對他說：「以尼雅，耶穌基督醫治你了，起來收拾你的墊子吧！」他應聲而起。</span>
<span className="v" id="v35" data-v="35" data-xref="使徒行傳 11:21; 使徒行傳 9:42; 歷代志上 5:16"> 呂大和沙崙的居民看見他，都歸向了主。</span>
</div>
</div>

## 彼得使死人復活

<div className="bt">
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="提多書 3:8; 提多書 2:7; 歷代志下 2:16"> 在約帕有個樂善好施的女門徒名叫戴碧達，希臘話叫多加<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「多加」意思是「羚羊」。">a</a></sup>。</span>
<span className="v" id="v37" data-v="37" data-xref="使徒行傳 1:13; 使徒行傳 20:8; 約翰福音 11:36–37"> 當時，她患病死了。有人將她的屍體洗乾淨後，停放在樓上。</span>
<span className="v" id="v38" data-v="38" data-xref="使徒行傳 9:36; 使徒行傳 11:26; 使徒行傳 9:32"> 呂大和約帕相距不遠，門徒聽說彼得在呂大，就派兩個人去懇求他，說：「請立刻來我們這裡！」</span>
<span className="v" id="v39" data-v="39" data-xref="箴言 10:7; 箴言 31:30–31; 帖撒羅尼迦前書 1:3"> 彼得便隨他們一同到了那裡，有人領他上樓。眾寡婦都站在彼得周圍哭，並把多加生前縫制的內衣、外衣給他看。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="馬太福音 9:25; 馬可福音 5:40–42; 路加福音 8:54"> 彼得叫她們都出去，自己跪下禱告，然後轉身對死者說：「戴碧達，起來！」她便睜開了眼睛，看見彼得，就坐了起來。</span>
<span className="v" id="v41" data-v="41" data-xref="馬可福音 1:31; 使徒行傳 6:1; 創世記 45:26"> 彼得伸手扶她起來後，叫那些在外面等候的聖徒和寡婦進來，把活過來的多加交給他們。</span>
<span className="v" id="v42" data-v="42" data-xref="約翰福音 12:44; 約翰福音 12:11; 約翰福音 11:45"> 這事傳遍了整個約帕，許多人都信了主。</span>
<span className="v" id="v43" data-v="43" data-xref="使徒行傳 10:6; 使徒行傳 10:32"> 彼得在約帕和一個名叫西門的皮革匠住了好些日子。</span>
</div>
</div>

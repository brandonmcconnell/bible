## 彼得的解釋

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="詩篇 22:27; 瑪拉基書 1:11; 以賽亞書 32:15"> 使徒和猶太全境的弟兄姊妹都聽說外族人接受了上帝的道。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行傳 10:45; 使徒行傳 10:9; 使徒行傳 15:1"> 彼得一回到耶路撒冷，嚴守割禮的信徒就指責他：</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行傳 10:28; 加拉太書 2:12; 路加福音 15:2"> 「你竟然去未受割禮之人的家，還和他們一同吃飯！」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="路加福音 1:3; 使徒行傳 14:27; 約書亞記 22:21–31"> 彼得就把事情的經過一一向他們解釋，說：</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行傳 10:9–32; 使徒行傳 9:10; 使徒行傳 22:17"> 「我在約帕城禱告的時候，看見一個異象，有個東西好像一大塊布，四角吊著從天上降到我面前。</span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 4:20; 使徒行傳 3:4"> 我仔細一看，見裡面有四腳的牲畜、野獸、爬蟲和飛禽。</span>
<span className="v" id="v7" data-v="7"> 接著，我聽見有聲音對我說，『彼得，起來，宰了吃！』</span>
<span className="v" id="v8" data-v="8" data-xref="羅馬書 14:14; 何西阿書 9:3; 哥林多前書 7:14"> 我說，『主啊，這可不行！我從未吃過任何污穢不潔之物！』</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行傳 15:9; 希伯來書 9:13–14; 使徒行傳 10:34–35"> 那從天上來的聲音又說，『上帝已經潔淨的，你不可再稱之為不潔淨。』</span>
<span className="v" id="v10" data-v="10" data-xref="約翰福音 21:17; 民數記 24:10; 哥林多後書 12:8"> 這樣一連三次，然後一切都被收回天上去了。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及記 4:27; 使徒行傳 9:10–12; 出埃及記 4:14"> 就在那時候，有三個從凱撒利亞來的人到我住處的門口來找我。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行傳 8:29; 羅馬書 3:22; 帖撒羅尼迦後書 2:2"> 聖靈吩咐我跟他們同去，不要猶豫。就這樣，我和這六位弟兄一同到了那人的家。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行傳 10:30–32; 使徒行傳 10:3–6; 使徒行傳 9:43"> 他告訴我們天使如何在他家中向他顯現，並對他說，『你派人去約帕，請一個叫西門·彼得的人來。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行傳 16:15; 使徒行傳 10:22; 使徒行傳 16:31–34"> 他有話告訴你，能使你和你的全家得救。』</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="使徒行傳 19:6; 使徒行傳 10:34–46; 使徒行傳 2:2–12"> 「我開口講話時，聖靈降在他們身上，跟當初降在我們身上的情形一模一樣。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行傳 1:5; 馬可福音 1:8; 箴言 1:23"> 我就想起主的話，『約翰用水施洗，但你們要受聖靈的洗。』</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行傳 10:47; 羅馬書 9:20–26; 但以理書 4:35"> 既然上帝賜給他們的恩賜，與賜給我們這些信主耶穌基督之人的一樣，我是誰，怎能攔阻上帝？」</span>
<span className="v" id="v18" data-v="18" data-xref="羅馬書 10:12–13; 哥林多後書 7:10; 以西結書 36:26"> 眾人聽了便安靜下來，轉而歸榮耀給上帝，說：「如此看來，上帝把悔改得永生的機會也賜給了外族人。」</span>
</div>
</div>

## 安提阿的教會

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="使徒行傳 4:36; 使徒行傳 21:2; 使徒行傳 15:3"> 司提凡殉道後，信徒們因受迫害而四散到各處，遠至腓尼基、塞浦路斯和安提阿，他們只向那裡的猶太人傳福音。</span>
<span className="v" id="v20" data-v="20" data-xref="馬太福音 27:32; 使徒行傳 13:1; 哥林多前書 1:23–24"> 不過，有些塞浦路斯和古利奈的信徒到了安提阿之後，也向希臘人傳講主耶穌的福音。</span>
<span className="v" id="v21" data-v="21" data-xref="路加福音 1:66; 使徒行傳 2:47; 使徒行傳 5:14"> 主的能力伴隨著他們，有許多人相信並歸向了主。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="使徒行傳 9:27; 使徒行傳 8:14; 使徒行傳 13:1–3"> 耶路撒冷教會的人聽到這消息後，就派巴拿巴去安提阿。</span>
<span className="v" id="v23" data-v="23" data-xref="哥林多前書 15:58; 使徒行傳 14:22; 使徒行傳 13:43"> 他到了，看見上帝所賜的恩典後很高興，就勸勉他們要全心地忠於主。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="使徒行傳 11:21; 使徒行傳 5:14; 使徒行傳 9:31"> 巴拿巴是個被聖靈充滿、信心堅定的好人。那時信主的人大大增加。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行傳 9:11; 使徒行傳 9:27; 使徒行傳 9:30"> 他又到大數去找掃羅，</span>
<span className="v" id="v26" data-v="26" data-xref="彼得前書 4:16; 使徒行傳 26:28; 彼得前書 4:14"> 找到後，便帶他回安提阿。他們在教會待了一年之久，教導了許多人。門徒被稱為「基督徒」就是從安提阿開始的。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="使徒行傳 13:1; 哥林多前書 12:28; 以弗所書 4:11"> 當時，有幾位先知從耶路撒冷下到安提阿。</span>
<span className="v" id="v28" data-v="28" data-xref="使徒行傳 21:10; 使徒行傳 18:2; 路加福音 3:1"> 其中一位名叫亞迦布，他得到聖靈的啟示，站起來預言天下將有嚴重的饑荒。後來，這事果然在克勞狄執政期間發生了。</span>
<span className="v" id="v29" data-v="29" data-xref="哥林多後書 8:12–14; 加拉太書 2:10; 哥林多後書 8:2–4"> 門徒決定各盡所能，捐款救濟住在猶太境內的弟兄姊妹。</span>
<span className="v" id="v30" data-v="30" data-xref="使徒行傳 14:23; 使徒行傳 12:25; 使徒行傳 15:4"> 他們捐完後，委託巴拿巴和掃羅將款項送交當地教會的長老。</span>
</div>
</div>

</div>

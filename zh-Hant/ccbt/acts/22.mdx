<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行傳 7:2; 使徒行傳 28:17; 使徒行傳 13:26"> 「各位父老兄弟，現在請聽我申辯！」</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行傳 21:40"> 在場的人聽見保羅講的是希伯來話，更加安靜了。保羅說：</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行傳 26:5; 腓立比書 3:5–6; 使徒行傳 9:11"> 「我是猶太人，生於基利迦的大數，在耶路撒冷長大，曾在迦瑪列門下嚴格地按著我們祖先的律法接受教育，像你們今日一樣熱心事奉上帝。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行傳 22:19–20; 提摩太前書 1:13–15; 使徒行傳 26:9–11"> 我曾經把信奉這道的男女信徒抓進監牢，迫害他們，置他們於死地。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行傳 9:1–2; 路加福音 22:66; 使徒行傳 5:21"> 大祭司和眾長老都可以為我作證。我還拿著他們寫給大馬士革的猶太弟兄的信去拘捕那裡的信徒，押回耶路撒冷受刑。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行傳 9:3–8; 使徒行傳 26:12–18; 啟示錄 1:16"> 「當我快到大馬士革的時候，大約正午，突然有一道強光從天上四面照著我。</span>
<span className="v" id="v7" data-v="7" data-xref="耶利米書 2:9; 馬太福音 25:45; 創世記 22:11"> 我就仆倒在地，聽見有聲音對我說，『掃羅！掃羅！你為什麼迫害我？』</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行傳 26:9; 撒母耳記上 8:7; 出埃及記 16:7–8"> 我回答說，『主啊，你是誰？』他說，『我就是你迫害的拿撒勒人耶穌！』</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行傳 9:7; 但以理書 10:7; 使徒行傳 26:13"> 我的同伴雖然也看見那道強光，卻聽不懂那位說話者的聲音。</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行傳 16:30; 使徒行傳 22:12–16; 使徒行傳 2:37"> 接著我又問，『主啊！我該怎麼辦？』主說，『起來，到大馬士革去，那裡會有人將指派給你的事告訴你。』</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行傳 9:8–9; 使徒行傳 13:11; 以賽亞書 42:16"> 「那道耀眼的光照得我雙眼失明，於是同行的人拉著我的手，帶我進了大馬士革。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行傳 10:22; 使徒行傳 6:3; 約翰三書 1:12"> 那裡有一個嚴守律法的虔誠人名叫亞拿尼亞，深受當地所有猶太人稱道。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行傳 9:17–18; 腓利門書 1:16"> 他來探望我，站在我身邊說，『掃羅弟兄，重見光明吧！』就在那一刻，我抬頭看見了他。</span>
<span className="v" id="v14" data-v="14" data-xref="加拉太書 1:12; 哥林多前書 15:8; 哥林多前書 9:1"> 他又說，『我們祖先的上帝揀選了你，要你明白祂的旨意，又讓你親自看見那位公義者、聽到祂的聲音。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行傳 23:11; 使徒行傳 4:20; 約翰福音 15:27"> 因為你將作祂的見證人，把所見所聞告訴萬民。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行傳 2:38; 使徒行傳 2:21; 提多書 3:5"> 現在你還等什麼呢？起來求告祂的名，接受洗禮，洗淨你的罪。』</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多後書 12:1–4; 使徒行傳 10:9–10; 使徒行傳 9:26–28"> 「後來，我回到耶路撒冷，在聖殿裡禱告的時候，進入異象，</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行傳 9:29; 路加福音 21:21; 以西結書 3:6–7"> 看見主對我說，『趕快離開耶路撒冷，因為這裡的人不會接受你為我做的見證。』</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行傳 22:4; 馬太福音 10:17; 使徒行傳 8:3"> 我說，『主啊！他們都知道我從前搜遍各會堂，逮捕和毒打信你的人。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行傳 7:58; 使徒行傳 8:1; 羅馬書 1:32"> 當你的見證人司提凡為你流血殉道時，我自己也站在旁邊贊同殺他的人，還替他們保管衣服。』</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行傳 9:15; 提摩太前書 2:7; 以弗所書 3:6–8"> 主卻對我說，『去吧！我要差遣你到遙遠的外族人那裡。』」</span>
</div>

## 因羅馬公民身分而免刑

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="使徒行傳 25:24; 使徒行傳 21:36; 約翰福音 19:15"> 眾人一聽到這裡，就高喊：「從世上除掉這樣的人！他不配活著！」</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳記下 16:13; 使徒行傳 26:11; 傳道書 10:3"> 他們大喊大叫，扔掉外衣，揚起塵土。</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行傳 21:31–32; 使徒行傳 21:34; 約翰福音 19:1"> 千夫長下令把保羅押回營房，預備鞭打拷問他，要查出眾人向他喊叫的緣由。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行傳 16:37; 使徒行傳 25:16; 使徒行傳 27:43"> 他們把保羅綁起來正要鞭打，保羅問旁邊的百夫長：「未經定罪就拷打羅馬公民合法嗎？」</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行傳 23:27; 使徒行傳 22:29"> 百夫長一聽，就去稟告千夫長說：「你看該怎麼辦？這人是羅馬公民。」</span>
<span className="v" id="v27" data-v="27"> 千夫長就來問保羅：「告訴我，你是羅馬公民嗎？」 保羅說：「是的。」</span>
<span className="v" id="v28" data-v="28"> 千夫長說：「我花了很多錢才當上羅馬公民！」 保羅說：「我生來就是。」</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行傳 21:33; 使徒行傳 22:24–26; 使徒行傳 16:38–39"> 那些準備拷問保羅的士兵立刻退下了。千夫長也害怕起來，因為發現保羅是羅馬公民，他卻下令捆綁了保羅。</span>
</div>
</div>

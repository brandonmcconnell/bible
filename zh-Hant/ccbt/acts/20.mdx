## 保羅再訪馬其頓和希臘

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多後書 7:5; 使徒行傳 19:21; 提摩太前書 1:3"> 這場風波平息後，保羅召集眾門徒勉勵一番後，便辭別他們去了馬其頓。</span>
<span className="v" id="v2" data-v="2" data-xref="帖撒羅尼迦前書 2:3; 帖撒羅尼迦前書 4:1; 歌羅西書 1:28"> 他走遍那一帶，用許多話鼓勵當地的門徒。之後，他又去希臘，</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行傳 20:19; 哥林多後書 11:26; 使徒行傳 9:23–24"> 在那裡逗留了三個月。保羅正要乘船去敘利亞時，聽聞猶太人計劃要害他，就決定經馬其頓回去。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行傳 19:29; 以弗所書 6:21; 提摩太後書 4:20"> 同他到亞細亞去的人有庇哩亞人畢羅斯的兒子所巴特、帖撒羅尼迦人亞里達古和西公都，還有特庇人該猶、提摩太、亞細亞人推基古和特羅非摩。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行傳 16:8; 使徒行傳 16:10–11; 提摩太後書 4:13"> 他們先到特羅亞等候我們。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行傳 12:3; 使徒行傳 16:12; 出埃及記 23:15"> 除酵節過後，我們從腓立比啟航，五天後在特羅亞和他們會合，大家同住了七天。</span>
</div>
</div>

## 猶推古死而復活

<div className="bt">
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="哥林多前書 16:2; 使徒行傳 2:42; 約翰福音 20:19"> 七日的第一日<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="照猶太人的算法，太陽下山後為一日的開始，基督徒又以禮拜天為一周之始，所以七日的第一日很有可能是禮拜六晚上。">a</a></sup>，我們聚會掰餅，保羅因為次日要離開，就向他們講道，直到半夜。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行傳 1:13; 路加福音 22:12"> 我們聚會的樓上燈火通明。</span>
<span className="v" id="v9" data-v="9" data-xref="馬可福音 13:36; 馬太福音 26:40–41; 約拿書 1:5–6"> 有個名叫猶推古的青年坐在窗臺上聽道。保羅講了許久，猶推古不勝困倦睡著了，竟從三樓掉了下去。別人將他抱起來時，他已經死了。</span>
<span className="v" id="v10" data-v="10" data-xref="馬可福音 5:39; 馬太福音 9:23–24; 列王紀上 17:21–22"> 保羅下去伏在他身上，抱著他對眾人說：「不要驚慌，他還活著！」</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行傳 20:7; 使徒行傳 20:9"> 保羅說完就回到樓上，與大家一同掰餅、吃了，又談了很久，直到天亮才離去。</span>
<span className="v" id="v12" data-v="12" data-xref="帖撒羅尼迦後書 2:16; 帖撒羅尼迦前書 5:14; 哥林多後書 1:4"> 大家把活過來的猶推古送回家，都大得安慰。</span>
</div>
</div>

## 保羅告別以弗所的眾長老

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="馬可福音 6:46; 馬可福音 1:35; 馬可福音 6:31–33"> 我們照保羅的吩咐先乘船到亞朔預備在那裡接他，他打算由陸路步行過去。</span>
<span className="v" id="v14" data-v="14"> 他到了亞朔，我們接他上船，一同前往米推利尼。</span>
<span className="v" id="v15" data-v="15" data-xref="提摩太後書 4:20; 使徒行傳 20:17"> 我們從米推利尼啟航，第二天到了基阿附近，第三天到達撒摩，第四天在米利都停泊。</span>
<span className="v" id="v16" data-v="16" data-xref="哥林多前書 16:8; 使徒行傳 2:1; 使徒行傳 19:21"> 保羅急於趕回耶路撒冷，希望在五旬節前趕到，所以決定越過以弗所，免得在亞細亞境內耽誤太久。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="提多書 1:5; 使徒行傳 11:30; 提摩太前書 5:17"> 保羅從米利都派人到以弗所請教會的長老前來與他相會。</span>
<span className="v" id="v18" data-v="18" data-xref="帖撒羅尼迦前書 1:5–6; 使徒行傳 18:19; 使徒行傳 19:1"> 他們都來了，保羅說：「各位，自從我踏進亞細亞那天起，在你們當中為人如何，你們都很清楚。</span>
<span className="v" id="v19" data-v="19" data-xref="歌羅西書 3:24; 哥林多後書 2:4; 羅馬書 12:11"> 我含著眼淚謙卑地事奉主，又遭到猶太人的謀害，歷盡艱辛。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行傳 20:27; 提摩太後書 4:2; 使徒行傳 5:42"> 你們也知道，凡是對你們有益的事，我沒有避而不宣，我總是在公開場合和各人家中教導你們。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行傳 2:38; 使徒行傳 11:18; 約翰一書 5:11–13"> 我勸猶太人和希臘人都要悔改，歸向上帝，信靠主耶穌基督。</span>
<span className="v" id="v22" data-v="22" data-xref="雅各書 4:14; 哥林多後書 5:14; 彼得後書 1:14"> 現在，我在聖靈的催促下前往耶路撒冷，不知道在那裡會發生什麼事，</span>
<span className="v" id="v23" data-v="23" data-xref="使徒行傳 9:16; 帖撒羅尼迦前書 3:3; 使徒行傳 21:4"> 只知道聖靈在各城指示我，前面必有監禁和苦難等著我。</span>
<span className="v" id="v24" data-v="24" data-xref="提摩太後書 4:6–8; 哥林多後書 4:1; 哥林多後書 12:10"> 不過，只要能跑完我當跑的路程，完成主耶穌交託給我的使命——為上帝充滿恩典的福音作見證，就是犧牲性命，我也在所不惜。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="使徒行傳 28:31; 使徒行傳 20:38; 馬太福音 4:23"> 「我一向在你們中間傳揚上帝的國，如今我知道，以後你們再也見不到我的面了。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行傳 18:6; 以西結書 3:18–21; 以西結書 33:2–9"> 所以今天我向你們聲明，將來你們有誰滅亡，與我無關。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行傳 20:20; 帖撒羅尼迦前書 2:4; 加拉太書 1:7–10"> 因為上帝的整個計劃，我沒有向你們避而不宣。</span>
<span className="v" id="v28" data-v="28" data-xref="彼得前書 5:2–3; 提摩太前書 4:16; 以賽亞書 40:11"> 你們要為自己，也要為教會的群羊警醒，因為聖靈已經任命你們做群羊的監督，牧養上帝的教會。教會是祂用自己的血贖回來的。</span>
<span className="v" id="v29" data-v="29" data-xref="馬太福音 7:15; 彼得後書 2:1; 約翰福音 10:12"> 我知道，在我離開以後，一定會有兇惡的豺狼闖進你們中間，殘害羊群。</span>
<span className="v" id="v30" data-v="30" data-xref="提摩太前書 1:19–20; 提摩太後書 4:3–4; 箴言 23:33"> 就是你們中間也會有人起來歪曲真理，引誘門徒跟隨他們。</span>
<span className="v" id="v31" data-v="31" data-xref="使徒行傳 19:8; 使徒行傳 20:19; 使徒行傳 19:10"> 所以你們一定要警醒，牢記這三年來我怎樣晝夜不住地流著淚勸誡你們。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="歌羅西書 1:12; 以弗所書 1:14; 歌羅西書 3:24"> 「現在，我把你們交託給上帝和祂充滿恩典的道，這道能造就你們，使你們與一切得以聖潔的人同得產業。</span>
<span className="v" id="v33" data-v="33" data-xref="哥林多後書 11:9; 哥林多前書 9:12; 哥林多前書 9:18"> 我從未貪圖別人的金銀和衣服，</span>
<span className="v" id="v34" data-v="34" data-xref="使徒行傳 18:3; 哥林多前書 4:12; 帖撒羅尼迦後書 3:8–9"> 你們都知道，我親手做工養活自己和同工。</span>
<span className="v" id="v35" data-v="35" data-xref="希伯來書 13:16; 箴言 19:17; 哥林多後書 9:6–12"> 我凡事以身作則，教導你們勤奮工作，幫助軟弱的人，並牢記主耶穌的話，『施比受更有福。』」</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="使徒行傳 21:5; 路加福音 22:41; 腓立比書 4:6"> 保羅說完這番話，就和大家一同跪下禱告。</span>
<span className="v" id="v37" data-v="37" data-xref="提摩太後書 1:4; 哥林多前書 16:20; 帖撒羅尼迦前書 5:26"> 眾人都哭了，抱著保羅與他親吻，</span>
<span className="v" id="v38" data-v="38" data-xref="使徒行傳 15:3; 哥林多前書 16:11; 使徒行傳 20:25"> 最使他們傷心的就是他說「你們再也見不到我的面了」。隨後，眾人送他上了船。</span>
</div>
</div>

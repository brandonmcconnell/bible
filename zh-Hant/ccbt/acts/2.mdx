## 聖靈降臨

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="羅馬書 15:6; 腓立比書 2:2; 使徒行傳 1:13–15"> 五旬節那天，門徒都聚集在一起。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行傳 4:31; 列王紀上 19:11; 詩篇 18:10"> 忽然，天上發出一陣響聲，好像狂風呼嘯而過，充滿了他們所在的房子，</span>
<span className="v" id="v3" data-v="3" data-xref="馬太福音 3:11; 約翰福音 1:32–33; 耶利米書 23:29"> 又有火焰般的舌頭顯現出來，分別落在各人的頭上。</span>
<span className="v" id="v4" data-v="4" data-xref="馬可福音 16:17; 使徒行傳 13:52; 使徒行傳 4:31"> 大家都被聖靈充滿，靠著聖靈所賜的能力說起別的語言來。</span>
<span className="v" id="v5" data-v="5" data-xref="路加福音 2:25; 使徒行傳 8:2; 歌羅西書 1:23"> 當時耶路撒冷住著從各國回來的虔誠的猶太人。</span>
<span className="v" id="v6" data-v="6" data-xref="馬太福音 2:3; 哥林多前書 16:9; 使徒行傳 2:2"> 眾人聽見這陣響聲便趕過來，聽見門徒在說他們各自的語言，都十分納悶，</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行傳 2:12; 使徒行傳 1:11; 約翰福音 7:52"> 驚詫地說：「看啊！這些說話的不都是加利利人嗎？</span>
<span className="v" id="v8" data-v="8"> 怎麼會說我們各自的家鄉話呢？</span>
<span className="v" id="v9" data-v="9" data-xref="彼得前書 1:1; 使徒行傳 18:2; 啟示錄 1:4"> 我們有帕提亞人、瑪代人、以攔人，以及住在美索不達米亞、猶太、加帕多迦、本都、亞細亞、</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行傳 16:6; 撒迦利亞書 8:23; 撒迦利亞書 8:20"> 弗呂迦、旁非利亞、埃及和靠近古利奈的利比亞地區的人，還有從羅馬來的猶太人和改信猶太教的人、</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多前書 12:10; 出埃及記 15:11; 詩篇 78:4"> 克里特人和阿拉伯人。我們都聽見他們在用我們各自的語言訴說上帝的大能作為！」</span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 15:26; 使徒行傳 17:20; 路加福音 18:36"> 他們都大感驚奇和困惑，彼此議論說：「這到底是怎麼回事？」</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多前書 14:23; 使徒行傳 2:15; 撒母耳記上 1:14"> 有些人就譏笑說：「他們不過是被新酒灌醉了！」</span>
</div>
</div>

## 彼得講道

<div className="bt">
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="以賽亞書 51:7; 以賽亞書 51:1; 申命記 27:9"> 彼得和其他十一位使徒都站起來，他大聲對眾人說：「各位猶太同胞和住在耶路撒冷的人啊，請留心聽！我告訴你們這是怎麼回事。</span>
<span className="v" id="v15" data-v="15" data-xref="帖撒羅尼迦前書 5:5–8; 撒母耳記上 1:15; 馬太福音 20:3"> 你們以為這些人是醉了，其實不是，因為現在才早上九點鐘。</span>
<span className="v" id="v16" data-v="16" data-xref="約珥書 2:28–32"> 你們眼前看見的正是先知約珥所說的，</span>
<span className="v" id="v17" data-v="17" data-xref="約珥書 2:28–32; 以賽亞書 44:3; 提多書 3:4–6"> <span className="pl pl-1">「『上帝說，在末後的日子，</span><br /><span className="pl pl-1">我要將我的靈澆灌所有的人，</span><br /><span className="pl pl-1">你們的兒女要說預言，</span><br /><span className="pl pl-1">青年要見異象，</span><br /><span className="pl pl-1">老人要做異夢。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="加拉太書 3:28; 歌羅西書 3:11; 哥林多前書 7:21–22"> <span className="pl pl-1">那時，我要將我的靈澆灌我的奴僕和婢女，</span><br /><span className="pl pl-1">他們都要說預言。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="約珥書 2:30–31; 西番雅書 1:14–18; 瑪拉基書 4:1–6"> <span className="pl pl-1">我要在天上顯異兆；</span><br /><span className="pl pl-1">我要在地上行神蹟，有血、有火、有濃煙。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="彼得後書 3:10; 阿摩司書 8:9; 馬太福音 24:29"> <span className="pl pl-1">太陽要變得昏暗，</span><br /><span className="pl pl-1">月亮要變得血紅。</span><br /><span className="pl pl-1">這都要發生在主偉大榮耀的日子來臨以前。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="羅馬書 10:12–13; 約珥書 2:32; 詩篇 86:5"> <span className="pl pl-1">那時，凡求告主名的人都必得救。』</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="約珥書2·28‑32。">a</a></sup></span>
<span className="v" id="v22" data-v="22" data-xref="約翰福音 3:2; 約翰福音 14:10–11; 馬太福音 12:28"> 「各位以色列人啊，請聽我說。上帝藉著拿撒勒人耶穌在你們中間行了異能、奇事和神蹟，以證明這人是祂委派的，這是你們自己所知道的。</span>
<span className="v" id="v23" data-v="23" data-xref="路加福音 22:22; 使徒行傳 4:28; 使徒行傳 3:18"> 耶穌按上帝的定旨和先見被交在你們手裡，你們藉著邪惡之人的手把祂釘死在十字架上了。</span>
<span className="v" id="v24" data-v="24" data-xref="哥林多前書 6:14; 彼得前書 1:21; 使徒行傳 2:32"> 但上帝為祂解除了死亡的痛苦，使祂從死裡復活，因為祂不可能被死亡拘禁。</span>
<span className="v" id="v25" data-v="25" data-xref="詩篇 16:8–11; 以賽亞書 41:13; 詩篇 62:6"> 大衛曾這樣談論耶穌，<br /><span className="pl pl-1">「『我看見主常在我面前，</span><br /><span className="pl pl-1">祂在我右邊，我必不動搖。</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="詩篇 16:9; 詩篇 63:5; 詩篇 71:23"> <span className="pl pl-1">因此我的心歡喜，我的口頌讚，</span><br /><span className="pl pl-1">我的身體也要活在盼望中。</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="詩篇 16:10; 使徒行傳 2:31; 啟示錄 1:18"> <span className="pl pl-1">因為你不會把我的靈魂撇在陰間，</span><br /><span className="pl pl-1">也不會讓你的聖者身體朽壞。</span><br /></span>
<span className="v" id="v28" data-v="28" data-xref="詩篇 16:11; 詩篇 25:4; 詩篇 21:6"> <span className="pl pl-1">你已把生命之路指示我，</span><br /><span className="pl pl-1">叫我在你面前充滿喜樂。』</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="詩篇16·8‑11。">b</a></sup></span>
<span className="v" id="v29" data-v="29" data-xref="使徒行傳 13:36; 列王紀上 2:10; 使徒行傳 7:8–9"> 「弟兄們，我肯定地對你們說，先祖大衛死了，埋葬了，他的墳墓至今還在我們這裡。</span>
<span className="v" id="v30" data-v="30" data-xref="詩篇 132:11–18; 詩篇 89:3–4; 耶利米書 33:14–15"> 大衛是先知，知道上帝曾對他起誓——要從他的後裔中選立一人繼承他的王位。</span>
<span className="v" id="v31" data-v="31" data-xref="使徒行傳 2:27; 詩篇 16:10; 使徒行傳 13:35"> 他預先知道這事，講到基督的復活，說，『祂的靈魂不會被撇在陰間，祂的身體也不會朽壞。』</span>
<span className="v" id="v32" data-v="32" data-xref="使徒行傳 3:15; 使徒行傳 1:8; 使徒行傳 1:22"> 上帝已經使這位耶穌復活了！我們都是這件事的見證人。</span>
<span className="v" id="v33" data-v="33" data-xref="使徒行傳 1:4; 使徒行傳 5:31; 使徒行傳 2:17"> 現在祂被提升到上帝的右邊，從天父領受了所應許的聖靈之後，便將聖靈澆灌下來，你們今天也耳聞目睹了。</span>
<span className="v" id="v34" data-v="34" data-xref="詩篇 110:1; 馬太福音 22:42–45; 希伯來書 1:13"> 大衛並沒有升到天上，但他曾說，<br /><span className="pl pl-1">「『主對我主說，</span><br /><span className="pl pl-1">你坐在我的右邊，</span><br /></span>
<span className="v" id="v35" data-v="35" data-xref="啟示錄 19:19–3; 羅馬書 16:20; 以賽亞書 60:14"> <span className="pl pl-1">等我使你的仇敵成為你的腳凳。』</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="詩篇110·1。">c</a></sup></span>
<span className="v" id="v36" data-v="36" data-xref="使徒行傳 5:30–31; 羅馬書 14:8–12; 哥林多後書 5:10"> 「所以，全體以色列人啊！你們應當確實地知道，上帝已經立這位被你們釘在十字架上的耶穌為主，為基督了。」</span>
<span className="v" id="v37" data-v="37" data-xref="路加福音 3:10; 使徒行傳 22:10; 希伯來書 4:12–13"> 他們聽了這番話，覺得扎心，就對彼得和其他使徒說：「弟兄們，我們該怎麼辦呢？」</span>
<span className="v" id="v38" data-v="38" data-xref="使徒行傳 22:16; 馬可福音 16:16; 使徒行傳 8:12"> 彼得說：「你們每一個人都要悔改，奉耶穌基督的名受洗，使你們的罪得到赦免，你們就必領受上帝所賜的聖靈。</span>
<span className="v" id="v39" data-v="39" data-xref="以賽亞書 44:3; 創世記 17:7–8; 羅馬書 8:30"> 因為這應許是給你們和你們的兒女，以及遠方的人，就是所有被主——我們的上帝呼召的人。」</span>
<span className="v" id="v40" data-v="40" data-xref="腓立比書 2:15; 申命記 32:5; 馬太福音 17:17"> 然後，彼得還講了其他許多話警戒、勸勉他們，說：「你們要救自己脫離這邪惡的世代。」</span>
<span className="v" id="v41" data-v="41" data-xref="使徒行傳 4:4; 使徒行傳 2:47; 使徒行傳 16:31–34"> 結果，那天約有三千人相信了他傳的道，接受了洗禮。</span>
<span className="v" id="v42" data-v="42" data-xref="希伯來書 10:25; 使徒行傳 1:14; 約翰一書 1:3"> 他們都一心遵守使徒的教導，一起團契、掰餅、禱告。</span>
<span className="v" id="v43" data-v="43" data-xref="路加福音 7:16; 約翰福音 14:12; 路加福音 8:37"> 大家都滿心敬畏上帝。使徒又行了很多神蹟奇事。</span>
<span className="v" id="v44" data-v="44" data-xref="使徒行傳 4:32; 約翰一書 3:16–18; 哥林多後書 8:14–15"> 信徒聚在一起，共用所有的東西。</span>
<span className="v" id="v45" data-v="45" data-xref="約翰一書 3:17; 提摩太前書 6:18–19; 雅各書 2:14–16"> 他們把田產家業變賣了，按照各人的需要分給大家。</span>
<span className="v" id="v46" data-v="46" data-xref="使徒行傳 5:42; 使徒行傳 20:7; 使徒行傳 2:42"> 他們天天同心合意地聚集在聖殿裡敬拜上帝，又在各人家中擘餅聚會，懷著歡喜和慷慨的心分享食物，</span>
<span className="v" id="v47" data-v="47" data-xref="使徒行傳 16:5; 使徒行傳 5:13–14; 使徒行傳 2:41"> 讚美上帝，受到眾人的喜愛。主使得救的人數與日俱增。</span>

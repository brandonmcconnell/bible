## 欺騙聖靈

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="利未記 10:1–3; 提摩太後書 2:20; 馬太福音 13:47–48"> 一個名叫亞拿尼亞的人與妻子撒非喇也把田產賣了。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行傳 4:37; 彼得後書 2:14–15; 馬太福音 23:5"> 他私自留下一部分錢，然後把其餘的拿去交給使徒，這件事他妻子也知道。</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米書 23:24; 以賽亞書 29:15; 約翰福音 13:2"> 彼得說：「亞拿尼亞，為什麼撒旦充滿了你的心，以致你欺騙聖靈，私自留下一些賣地的錢呢？</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行傳 5:3; 約書亞記 7:25–26; 列王紀下 5:25–27"> 田產沒有賣的時候屬於你，即使賣了，賣地的錢也由你支配。你怎麼想到做這種事呢？你不是欺騙人，你是欺騙上帝！」</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行傳 5:10–11; 使徒行傳 2:43; 使徒行傳 5:13"> 亞拿尼亞聽見這話，當場倒地而死。聽見這件事的人都非常懼怕。</span>
<span className="v" id="v6" data-v="6" data-xref="約翰福音 19:40; 撒母耳記下 18:17; 申命記 21:23"> 有幾個青年上前把他的屍體裹起來，抬出去埋葬了。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7"> 大約過了三個小時，亞拿尼亞的妻子也進來了，她還不知道發生了什麼事。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行傳 5:2"> 彼得問她：「你們賣田地的錢就這麼多嗎？」她說：「是的，就這麼多。」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="哥林多前書 10:9; 使徒行傳 5:3–4; 詩篇 95:8–11"> 彼得說：「你們二人怎麼串通起來試探主的靈呢？埋葬你丈夫的人就到門口了，他們也要把你抬出去。」</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行傳 5:5"> 撒非喇立刻倒在彼得腳前死了。那些青年進來看見她已經死了，便把她抬出去葬在她丈夫的旁邊。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行傳 5:5; 哥林多前書 10:11–12; 使徒行傳 19:17"> 整個教會和聽見這件事的人都非常懼怕。</span>
</div>
</div>

## 神蹟奇事

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="使徒行傳 19:11; 哥林多後書 12:12; 希伯來書 2:4"> 主藉著使徒們在百姓中行了許多神蹟奇事，大家同心合意地在所羅門廊那裡聚會。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行傳 2:47; 使徒行傳 4:21; 約翰福音 12:42"> 其他人不敢接近他們，不過百姓都很敬重他們。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行傳 2:47; 使徒行傳 4:4; 以賽亞書 55:11–13"> 信主的人數不斷增加，男女都很多。</span>
<span className="v" id="v15" data-v="15" data-xref="馬太福音 14:36; 使徒行傳 19:11–12; 約翰福音 14:12"> 人們甚至把病人抬到街上，放在床上或墊子上，希望彼得路過時的影子可以落在病人身上。</span>
<span className="v" id="v16" data-v="16" data-xref="馬可福音 16:17–18; 馬可福音 2:3–4; 馬太福音 15:30–31"> 還有大群的人從耶路撒冷附近的城鎮帶著病人和被污鬼攪擾的人趕來，他們都得了醫治。</span>
</div>
</div>

## 使徒受迫害

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="使徒行傳 13:45; 使徒行傳 7:9; 使徒行傳 17:5"> 大祭司和他的同黨撒都該人看見這情形，妒火中燒，</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行傳 4:3; 路加福音 21:12; 哥林多後書 11:23"> 便把使徒拘捕，關在監牢。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行傳 16:26; 詩篇 34:7; 使徒行傳 12:7–11"> 當晚，有一位主的天使把獄門打開，領他們出來，</span>
<span className="v" id="v20" data-v="20" data-xref="約翰福音 6:63; 約翰福音 6:68; 約翰一書 5:11–12"> 說：「你們到聖殿去，把這生命之道傳給百姓。」</span>
<span className="v" id="v21" data-v="21" data-xref="約翰福音 8:2; 使徒行傳 22:15; 使徒行傳 12:18–19"> 使徒遵從命令，在黎明的時候進入聖殿開始教導眾人。<br />大祭司和他的同黨召集了公會<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="公會是猶太人的最高立法與司法機關。">a</a></sup>的全體以色列長老，然後派人去監獄把使徒押來。</span>
<span className="v" id="v22" data-v="22"> 差役來到監獄時，發現使徒已經不見了，就回去稟告，說：</span>
<span className="v" id="v23" data-v="23" data-xref="詩篇 2:4; 詩篇 33:10; 但以理書 6:22–24"> 「我們看見牢門緊鎖，守衛都站在門外，但打開門一看，裡面卻空無一人！」</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="使徒行傳 4:1; 使徒行傳 5:26; 約翰福音 12:19"> 聖殿護衛長和祭司長聽後，都很困擾，不知道是怎麼回事。</span>
<span className="v" id="v25" data-v="25"> 這時有人來報告說：「你們關押在牢裡的人正在聖殿裡教導人！」</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行傳 5:13; 使徒行傳 4:21; 馬太福音 26:5"> 聖殿護衛長和差役再去把使徒帶來。這次他們不敢動粗，生怕百姓會用石頭打他們。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="馬太福音 5:22; 使徒行傳 4:7; 路加福音 22:66"> 使徒被帶來之後，站在公會前，大祭司盤問他們，說：</span>
<span className="v" id="v28" data-v="28" data-xref="馬太福音 27:25; 使徒行傳 7:52; 使徒行傳 4:10–11"> 「我們不是嚴禁你們奉耶穌的名去教導百姓嗎？你們竟然在耶路撒冷各處傳道，還想把殺那人的血債歸到我們身上！」</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="使徒行傳 4:19; 撒母耳記上 15:24; 馬可福音 7:7–9"> 彼得和其他使徒申辯說：「我們要服從的是上帝，而非人。</span>
<span className="v" id="v30" data-v="30" data-xref="加拉太書 3:13; 彼得前書 2:24; 使徒行傳 10:39"> 你們釘死在十字架上的耶穌，我們祖先的上帝已經使祂復活了。</span>
<span className="v" id="v31" data-v="31" data-xref="路加福音 24:47; 使徒行傳 2:33; 希伯來書 2:10"> 上帝把祂提升到自己的右邊，立祂為君王和救主，好賜給以色列人悔改的機會，使他們的罪得到赦免。</span>
<span className="v" id="v32" data-v="32" data-xref="約翰福音 15:26–27; 希伯來書 2:3–4; 使徒行傳 1:8"> 我們就是這些事的見證人，上帝賜給順服祂之人的聖靈也同樣作見證。」</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="使徒行傳 7:54; 使徒行傳 2:37; 路加福音 4:28–29"> 他們聽了，怒氣衝天，打算殺掉使徒。</span>
<span className="v" id="v34" data-v="34" data-xref="使徒行傳 22:3; 路加福音 2:46; 路加福音 5:17"> 公會中有一位名叫迦瑪列的法利賽人，是個德高望重的律法教師。他站起來，叫人把使徒暫且押到外面，</span>
<span className="v" id="v35" data-v="35" data-xref="使徒行傳 22:26; 耶利米書 26:19; 馬太福音 27:19"> 然後說：「以色列人啊，你們應當慎重處置這些人。</span>
<span className="v" id="v36" data-v="36" data-xref="使徒行傳 8:9; 彼得後書 2:2; 加拉太書 6:3"> 之前，有個名叫杜達的人起來自立山頭，吸引了差不多四百個跟隨者，但他被殺之後，那些跟隨者就各奔東西，銷聲匿跡了。</span>
<span className="v" id="v37" data-v="37" data-xref="路加福音 2:1–2; 詩篇 7:14–15; 馬太福音 26:52"> 後來，又有個加利利人猶大在戶口登記期間鼓動百姓跟隨他造反。他被殺之後，那些跟隨者也煙消雲散了。</span>
<span className="v" id="v38" data-v="38" data-xref="馬太福音 15:13; 耶利米哀歌 3:37; 以賽亞書 8:9–10"> 所以，像現在這種情形，我勸大家還是不要管他們，隨他們去吧。他們的計劃和行為如果是出於人意，終必失敗；</span>
<span className="v" id="v39" data-v="39" data-xref="箴言 21:30; 以賽亞書 46:10; 馬太福音 16:18"> 但如果是出於上帝，你們不但無法阻止他們，恐怕發現自己是在抵擋上帝！」</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="馬太福音 10:17; 使徒行傳 5:28; 使徒行傳 4:17–21"> 公會採納了他的意見，於是把使徒召回來打了一頓，再次警告他們不可奉耶穌的名傳道，才放了他們。</span>
<span className="v" id="v41" data-v="41" data-xref="雅各書 1:2; 彼得前書 4:13–16; 路加福音 6:22"> 使徒歡歡喜喜地離開公會，因為他們在主看來配得上為祂的名受辱。</span>
<span className="v" id="v42" data-v="42" data-xref="使徒行傳 2:46; 使徒行傳 20:20; 路加福音 21:37"> 他們每天在聖殿裡及各家各戶教導人，不斷地傳揚耶穌是基督。</span>
</div>
</div>

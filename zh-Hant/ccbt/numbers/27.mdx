## 女兒的繼承權

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民數記 26:33; 加拉太書 3:28; 歷代志上 7:15"> 西羅非哈是約瑟之子瑪拿西的玄孫、瑪吉的曾孫、基列的孫子、希弗的兒子。他的女兒是瑪拉、挪阿、曷拉、密迦和得撒。她們前來，</span>
<span className="v" id="v2" data-v="2" data-xref="民數記 15:33–34; 申命記 17:8–10; 出埃及記 18:19–26"> 站在會幕門口對摩西、以利亞撒祭司、眾首領和全體會眾說：</span>
<span className="v" id="v3" data-v="3" data-xref="民數記 26:64–65; 以西結書 18:4; 民數記 14:35"> 「我們的父親死在曠野，他並沒有跟可拉一夥一起反叛耶和華，而是因自己的罪而死，沒有留下兒子。</span>
<span className="v" id="v4" data-v="4" data-xref="約書亞記 17:4; 詩篇 109:13; 出埃及記 32:11"> 難道因為他沒有兒子，他的名字就要從族中消失嗎？請讓我們在父親的家族中分一份產業吧。」</span>
<span className="v" id="v5" data-v="5" data-xref="利未記 24:12–13; 約伯記 23:4; 箴言 3:5–6"> 摩西就把她們的請求呈到耶和華面前。</span>
<span className="v" id="v6" data-v="6" data-xref="加拉太書 3:28; 詩篇 68:5–6"> 耶和華對摩西說：</span>
<span className="v" id="v7" data-v="7" data-xref="加拉太書 3:28; 耶利米書 49:11; 約書亞記 17:4"> 「西羅非哈的女兒說得有理。你要從她們父親的家族中分一份產業給她們，讓她們繼承父親的產業。</span>
<span className="v" id="v8" data-v="8"> 你要告訴以色列人，『人死後如果沒有兒子，就由女兒繼承產業；</span>
<span className="v" id="v9" data-v="9"> 如果沒有女兒，就由其兄弟繼承；</span>
<span className="v" id="v10" data-v="10"> 如果沒有兄弟，就由其父的兄弟繼承；</span>
<span className="v" id="v11" data-v="11" data-xref="民數記 35:29; 路得記 4:3–6; 耶利米書 32:8"> 如果其父沒有兄弟，就由其族中最近的親屬繼承。』」這是耶和華吩咐摩西頒佈給以色列人的律例。</span>
</div>
</div>

## 約書亞接替摩西做首領

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="民數記 33:47–48; 申命記 34:1–4; 申命記 3:23–27"> 耶和華對摩西說：「你上這亞巴琳山去看看我賜給以色列人的土地。</span>
<span className="v" id="v13" data-v="13" data-xref="申命記 10:6; 民數記 31:2; 民數記 20:24–28"> 看了以後，你就要像你哥哥亞倫一樣歸到祖先那裡了。</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 1:37; 民數記 20:8–13; 出埃及記 17:7"> 因為會眾在荀曠野反叛我的時候，你們二人違背我的命令，在取水的事上沒有在他們面前尊我為聖。」這是指米利巴泉事件，發生在荀曠野的加低斯。</span>
<span className="v" id="v15" data-v="15"> 摩西對耶和華說：</span>
<span className="v" id="v16" data-v="16" data-xref="民數記 16:22; 耶利米書 3:15; 希伯來書 12:9"> 「耶和華啊，你是賜人生命的上帝，求你立一個人做會眾的首領，</span>
<span className="v" id="v17" data-v="17" data-xref="以西結書 34:5; 馬可福音 6:34; 列王紀上 22:17"> 在前面帶領他們或進或退，免得你的會眾像沒有牧人的羊群。」</span>
<span className="v" id="v18" data-v="18" data-xref="申命記 34:9; 民數記 27:23; 創世記 41:38"> 耶和華對摩西說：「嫩的兒子約書亞心裡有聖靈，你把他召來，把手按在他身上，</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 3:28; 申命記 31:7–8; 申命記 31:23"> 讓他站在以利亞撒祭司和全體會眾面前，當著他們的面任命他做首領，</span>
<span className="v" id="v20" data-v="20" data-xref="約書亞記 1:16–18; 撒母耳記上 10:9; 列王紀下 2:9–10"> 把你的權柄賜給他，使以色列全體會眾都聽從他。</span>
<span className="v" id="v21" data-v="21" data-xref="約書亞記 9:14; 撒母耳記上 28:6; 出埃及記 28:30"> 他要去以利亞撒祭司那裡，讓祭司藉著烏陵為他求問我。他和全體會眾或進或出，都要聽從以利亞撒的指示。」</span>
<span className="v" id="v22" data-v="22"> 摩西遵命而行，把約書亞召來，讓他站在以利亞撒祭司和全體會眾面前，</span>
<span className="v" id="v23" data-v="23" data-xref="申命記 3:28; 民數記 27:19; 申命記 31:7–8"> 然後照耶和華對摩西的吩咐把手按在他頭上，任命他做首領。</span>
</div>
</div>

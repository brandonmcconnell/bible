## 以色列人發怨言

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民數記 21:5; 民數記 16:35; 列王紀下 1:12"> 民眾因為困難而發怨言，傳到耶和華耳中。耶和華聽見後便向他們發怒，使火在他們中間燃燒，燒毀了營地的邊緣部分。</span>
<span className="v" id="v2" data-v="2" data-xref="民數記 21:7; 雅各書 5:16; 民數記 16:45–48"> 民眾呼求摩西，摩西便向耶和華禱告，火就熄了。</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 9:22"> 那地方叫他備拉，因為耶和華的火曾在他們中間燃燒。</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多前書 10:6; 出埃及記 12:38; 詩篇 106:14"> 他們中間有一群烏合之眾貪戀美食，以色列人也哭著說：「要是有肉吃多好啊！</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 16:3; 詩篇 17:14; 腓立比書 3:19"> 還記得在埃及的時候，我們不花錢就可以吃魚，還有黃瓜、西瓜、韭菜、蔥和蒜。</span>
<span className="v" id="v6" data-v="6" data-xref="民數記 21:5; 撒母耳記下 13:4"> 我們現在毫無胃口，眼前除了嗎哪外，什麼都沒有。」</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及記 16:31; 創世記 2:12; 出埃及記 16:14–15"> 嗎哪的形狀像芫荽籽，又像珍珠。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及記 16:31; 出埃及記 16:16–18; 出埃及記 16:23"> 每天晚上露水降在營地上時，嗎哪也隨著降下來。早晨民眾到四周撿嗎哪，把嗎哪用磨磨碎或在臼中搗碎後，放在鍋裡煮，再做成餅，味道就像油餅。</span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 78:21; 民數記 16:27; 民數記 14:1–2"> 摩西感到難過，因為他聽見民眾都在自己帳篷門口哭泣，以致耶和華大發烈怒。</span>
<span className="v" id="v11" data-v="11" data-xref="申命記 1:12; 出埃及記 5:22; 耶利米書 15:10"> 他對耶和華說：「你為什麼苦待僕人？我做了什麼令你不悅的事，你竟把管理這些民眾的重擔放在我身上？</span>
<span className="v" id="v12" data-v="12" data-xref="以賽亞書 49:23; 以賽亞書 40:11; 帖撒羅尼迦前書 2:7"> 難道是我孕育生養了他們嗎？為什麼你要我像父親呵護吃奶的嬰兒一樣，把他們抱到你應許給他們祖先的地方呢？</span>
<span className="v" id="v13" data-v="13" data-xref="馬太福音 15:33; 馬可福音 8:4; 約翰福音 6:5–9"> 他們都哭著向我要肉吃，我去哪裡找肉給他們吃呢？</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及記 18:18; 申命記 1:9–12; 哥林多後書 2:16"> 管理民眾的責任實在是太重了，我一個人擔當不起啊！</span>
<span className="v" id="v15" data-v="15" data-xref="腓立比書 1:20–24; 列王紀上 19:4; 約拿書 4:3"> 你既然這樣對待我，求你施恩殺了我吧，別讓我受苦了！」</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 24:1; 出埃及記 24:9; 申命記 16:18"> 耶和華對摩西說：「你給我招聚七十個以色列人的長老，就是你所瞭解的長老和首領，把他們帶到會幕，讓他們站在你身邊。</span>
<span className="v" id="v17" data-v="17" data-xref="民數記 11:25; 撒母耳記上 10:6; 哥林多前書 12:4–11"> 我要在那裡降臨，對你說話，把降在你身上的靈也賜給他們，讓他們為你分擔管理民眾的責任，免得你獨自承擔。</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及記 19:10; 使徒行傳 7:39; 出埃及記 16:3–7"> 你要叫民眾潔淨自己，明天就會有肉吃。因為我聽見了他們哭著要肉吃、說埃及的日子更好，我必給他們肉吃。</span>
<span className="v" id="v19" data-v="19"> 他們將不止吃一天、兩天、五天、十天或二十天，</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 106:15; 民數記 21:5; 詩篇 78:27–30"> 而是要吃整整一個月，直到肉從他們鼻孔裡噴出來，令他們厭膩。因為他們厭棄住在他們中間的我，在我面前哭訴，後悔離開埃及。」</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及記 12:37; 民數記 1:46; 創世記 12:2"> 摩西說：「和我同行的，僅男子就有六十萬，你還說要讓他們吃整整一個月的肉！</span>
<span className="v" id="v22" data-v="22" data-xref="馬太福音 15:33; 列王紀下 7:2; 約翰福音 6:9"> 就是把牛羊都宰了，夠他們吃嗎？就是把海裡的魚都捕來，夠他們吃嗎？」</span>
<span className="v" id="v23" data-v="23" data-xref="以賽亞書 59:1; 以賽亞書 50:2; 創世記 18:14"> 耶和華說：「難道我的臂膀短小無力嗎？你很快將看見我的話會不會應驗。」</span>
<span className="v" id="v24" data-v="24" data-xref="民數記 11:16; 民數記 11:26"> 摩西就出去把耶和華的話轉告民眾，又召集了七十位長老，叫他們站在會幕周圍。</span>
<span className="v" id="v25" data-v="25" data-xref="民數記 11:17; 約珥書 2:28–29; 撒母耳記上 10:10"> 耶和華在雲中降臨，對摩西說話，把降在摩西身上的靈也賜給七十位長老。靈一降在他們身上，他們就說起預言來，但只說了這一次。</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米書 36:5; 撒母耳記上 20:26; 撒母耳記上 10:22"> 七十位長老中的伊利達和米達沒有到會幕去，但耶和華的靈也降在他們身上，他們就在營中說起預言來。</span>
<span className="v" id="v27" data-v="27"> 有一個青年跑去稟告摩西說：「伊利達和米達正在營中說預言。」</span>
<span className="v" id="v28" data-v="28" data-xref="馬可福音 9:38–40; 路加福音 9:49–50; 約翰福音 3:26"> 摩西揀選的助手嫩的兒子約書亞就說：「我主摩西，請你禁止他們。」</span>
<span className="v" id="v29" data-v="29" data-xref="哥林多前書 14:5; 馬太福音 9:37–38; 路加福音 10:2"> 摩西說：「你是為我的緣故而嫉妒嗎？願耶和華的子民都成為先知！願耶和華把祂的靈降在他們身上！」</span>
<span className="v" id="v30" data-v="30"> 之後，摩西和以色列的長老都返回營中。</span>
</div>
</div>

## 耶和華賜下鵪鶉

<div className="bt">
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="出埃及記 16:13; 詩篇 105:40; 詩篇 78:26–29"> 耶和華颳起一陣風，把鵪鶉從海面颳到營地四周，約一米厚，方圓數公里。</span>
<span className="v" id="v32" data-v="32" data-xref="以西結書 45:11; 出埃及記 16:36"> 民眾花了兩天一夜的時間去捕捉鵪鶉，每人至少捉了一噸半。他們把鵪鶉攤在營地的周圍。</span>
<span className="v" id="v33" data-v="33" data-xref="詩篇 78:30–31; 詩篇 106:14–15; 民數記 25:9"> 他們口中的肉還沒嚼爛，耶和華的怒氣就已向他們發作，降下了大災。</span>
<span className="v" id="v34" data-v="34" data-xref="申命記 9:22; 哥林多前書 10:6; 民數記 33:16"> 因此，那地方叫基博羅·哈他瓦<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「基博羅·哈他瓦」意思是「貪慾之墓」。">a</a></sup>，因為那些貪食之徒埋葬在那裡。</span>
<span className="v" id="v35" data-v="35" data-xref="民數記 33:17; 民數記 12:16; 申命記 1:1"> 民眾從基博羅·哈他瓦前往哈洗錄，在哈洗錄住了下來。</span>

## 第二次人口統計

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民數記 25:9"> 瘟疫過後，耶和華對摩西和亞倫祭司的兒子以利亞撒說：</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 38:25–26; 民數記 1:2–3; 出埃及記 30:11–16"> 「你們要統計以色列全體會眾的人數，按家係登記所有二十歲以上、有作戰能力的男子。」</span>
<span className="v" id="v3" data-v="3" data-xref="民數記 22:1; 民數記 33:48; 民數記 35:1"> 摩西和以利亞撒祭司就在約旦河邊、耶利哥對面的摩押平原對以色列人說：</span>
<span className="v" id="v4" data-v="4" data-xref="民數記 1:1; 歷代志上 21:1"> 「你們要按照耶和華對摩西的吩咐，統計二十歲以上的男子。」<br />以下是從埃及出來的以色列人。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="歷代志上 5:3; 創世記 46:8–9; 出埃及記 6:14"> 以色列的長子是呂便，呂便的子孫有哈諾族、法路族、</span>
<span className="v" id="v6" data-v="6"> 希斯倫族和迦米族。</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 46:9; 民數記 26:21; 民數記 2:11"> 這些是呂便的各宗族，共登記了四萬三千七百三十人。</span>
<span className="v" id="v8" data-v="8"> 法路的兒子是以利押，</span>
<span className="v" id="v9" data-v="9" data-xref="民數記 1:16; 民數記 16:1–35; 詩篇 106:17"> 以利押的兒子是尼姆利、大坍和亞比蘭。大坍、亞比蘭原是會眾所推選的首領，他們與可拉一夥，一起反叛摩西和亞倫，反叛耶和華，</span>
<span className="v" id="v10" data-v="10" data-xref="民數記 16:38; 彼得後書 2:6; 民數記 16:31–35"> 以致大地裂開，將他們全部吞了下去，當時大火還燒滅了二百五十人。他們成了後人的警戒。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及記 6:24; 詩篇 42:1; 民數記 16:33"> 然而，可拉的子孫沒有被滅絕。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="歷代志上 4:24; 創世記 46:10; 出埃及記 6:15"> 按著宗族，西緬的子孫有尼姆利族、雅憫族、雅斤族、</span>
<span className="v" id="v13" data-v="13" data-xref="創世記 46:10"> 謝拉族和掃羅族。</span>
<span className="v" id="v14" data-v="14" data-xref="民數記 1:22–23; 民數記 2:12–13"> 這些是西緬的各宗族，共登記了兩萬二千二百人。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="創世記 46:16; 民數記 2:14"> 按著宗族，迦得的子孫有洗分族、哈基族、書尼族、</span>
<span className="v" id="v16" data-v="16" data-xref="創世記 46:16"> 阿斯尼族、以利族、</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 46:16"> 亞律族和亞列利族。</span>
<span className="v" id="v18" data-v="18" data-xref="民數記 1:24–25; 民數記 2:14–15"> 這些是迦得的各宗族，共登記了四萬零五百人。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="創世記 46:12; 創世記 38:1–10; 歷代志上 2:3–8"> 珥和俄南是猶大的兒子，他們死在了迦南。</span>
<span className="v" id="v20" data-v="20" data-xref="尼希米記 11:24; 創世記 46:12; 路加福音 3:33"> 按著宗族，猶大的子孫有示拉族、法勒斯族、謝拉族。</span>
<span className="v" id="v21" data-v="21"> 法勒斯的子孫有希斯崙族和哈姆勒族。</span>
<span className="v" id="v22" data-v="22" data-xref="民數記 1:26–27; 民數記 2:3–4; 創世記 49:8"> 這些是猶大的各宗族，共登記了七萬六千五百人。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="創世記 46:13; 歷代志上 7:1; 創世記 30:17–18"> 按著宗族，以薩迦的子孫有陀拉族、普瓦族、</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 46:13"> 雅述族和伸崙族。</span>
<span className="v" id="v25" data-v="25" data-xref="民數記 2:5–6; 民數記 1:28–29"> 這些是以薩迦各宗族，共登記了六萬四千三百人。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="創世記 46:14; 創世記 30:19–20"> 按著宗族，西布倫的子孫有西烈族、以倫族和雅利族。</span>
<span className="v" id="v27" data-v="27" data-xref="民數記 1:30–31; 民數記 2:7–8"> 這些是西布倫的各宗族，共登記了六萬零五百人。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="創世記 46:20; 創世記 48:5; 創世記 41:51–52"> 按著宗族，約瑟的兒子有瑪拿西和以法蓮。</span>
<span className="v" id="v29" data-v="29" data-xref="約書亞記 17:1; 民數記 36:1; 歷代志上 7:14–19"> 瑪拿西的子孫有瑪吉族和基列族。基列是瑪吉的兒子。基列族來自基列。</span>
<span className="v" id="v30" data-v="30" data-xref="士師記 6:11; 士師記 6:34; 士師記 6:24"> 基列的子孫有伊以謝族、希勒族、</span>
<span className="v" id="v31" data-v="31"> 亞斯烈族、示劍族、</span>
<span className="v" id="v32" data-v="32"> 示米大族和希弗族。</span>
<span className="v" id="v33" data-v="33" data-xref="民數記 27:1; 民數記 36:10–12"> 希弗的兒子西羅非哈沒有兒子，只有女兒瑪拉、挪阿、曷拉、密迦和得撒。</span>
<span className="v" id="v34" data-v="34" data-xref="民數記 1:34–35; 民數記 2:20–21"> 這些是瑪拿西的各宗族，共登記了五萬二千七百人。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="歷代志上 7:20–21"> 按著宗族，以法蓮的子孫有書提拉族、比結族和他罕族。</span>
<span className="v" id="v36" data-v="36"> 書提拉的子孫有以蘭族。</span>
<span className="v" id="v37" data-v="37" data-xref="民數記 1:32–33; 民數記 2:18–19"> 這些是以法蓮各宗族，共登記了三萬二千五百人，他們按宗族都是約瑟的子孫。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="歷代志上 8:1; 歷代志上 7:6–12; 創世記 46:2"> 按著宗族，便雅憫的子孫有比拉族、亞實別族、亞希蘭族、</span>
<span className="v" id="v39" data-v="39" data-xref="創世記 46:21"> 書反族和戶反族。</span>
<span className="v" id="v40" data-v="40" data-xref="歷代志上 8:3"> 比拉的子孫有亞勒族和乃幔族。</span>
<span className="v" id="v41" data-v="41" data-xref="民數記 2:22–23; 創世記 46:21; 民數記 1:36–37"> 這些是便雅憫的各宗族，共登記了四萬五千六百人。</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="創世記 46:23"> 按著宗族，但的子孫有書含族，書含族來自書含，這些是但的宗族。</span>
<span className="v" id="v43" data-v="43" data-xref="民數記 1:38–39; 民數記 2:25–26"> 書含族共登記了六萬四千四百人。</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="創世記 46:17; 歷代志上 7:30"> 按著宗族，亞設的子孫有音拿族、亦施韋族和比利亞族。</span>
<span className="v" id="v45" data-v="45"> 比利亞的子孫有希別族和瑪結族。</span>
<span className="v" id="v46" data-v="46" data-xref="創世記 46:17"> 亞設的女兒名叫西拉。</span>
<span className="v" id="v47" data-v="47" data-xref="民數記 2:27–28; 民數記 1:40–41"> 這些是亞設的各宗族，共登記了五萬三千四百人。</span>
</div>
<div className="bp">
<span className="v" id="v48" data-v="48" data-xref="創世記 46:24; 歷代志上 7:13"> 按著宗族，拿弗他利的子孫有雅薛族、沽尼族、</span>
<span className="v" id="v49" data-v="49" data-xref="歷代志上 7:13"> 耶色族和示冷族。</span>
<span className="v" id="v50" data-v="50" data-xref="民數記 1:42–43; 民數記 2:29–30"> 這些是拿弗他利的各宗族，共登記了四萬五千四百人。</span>
</div>
<div className="bp">
<span className="v" id="v51" data-v="51" data-xref="民數記 1:46; 民數記 2:32; 出埃及記 12:37"> 登記的以色列男子共有六十萬一千七百三十人。</span>
</div>
<div className="bp">
<span className="v" id="v52" data-v="52"> 耶和華對摩西說：</span>
<span className="v" id="v53" data-v="53" data-xref="約書亞記 11:23; 約書亞記 14:1; 詩篇 105:44"> 「你要按著各支派登記的人數，把土地分給他們作產業；</span>
<span className="v" id="v54" data-v="54" data-xref="民數記 33:54; 民數記 32:3; 民數記 32:5"> 人數多的多分產業，人數少的少分產業，要按登記的人數分配。</span>
<span className="v" id="v55" data-v="55" data-xref="民數記 34:13; 民數記 33:54; 約書亞記 14:2"> 以色列人要按各自的支派抽籤分地，承受產業。</span>
<span className="v" id="v56" data-v="56" data-xref="哥林多前書 12:4; 羅馬書 11:7"> 無論大小支派，都要用抽籤的方法分配產業。」</span>
</div>
<div className="bp">
<span className="v" id="v57" data-v="57" data-xref="創世記 46:11; 歷代志上 6:1; 出埃及記 6:16–19"> 按著宗族，利未的子孫有革順族、哥轄族和米拉利族。</span>
<span className="v" id="v58" data-v="58" data-xref="民數記 16:1; 民數記 3:17–21; 出埃及記 6:20"> 立尼族、希伯倫族、瑪利族、姆示族和可拉族也是利未的子孫。哥轄生暗蘭。</span>
<span className="v" id="v59" data-v="59" data-xref="出埃及記 6:20; 出埃及記 2:1–2; 利未記 18:12"> 暗蘭的妻子叫約基別，是利未女子，出生在埃及。她給暗蘭生了亞倫、摩西和他們的姐姐米利暗。</span>
<span className="v" id="v60" data-v="60" data-xref="民數記 3:2; 民數記 3:8"> 亞倫生拿答、亞比戶、以利亞撒和以他瑪。</span>
<span className="v" id="v61" data-v="61" data-xref="民數記 3:4; 利未記 10:1–2; 歷代志上 24:1–2"> 拿答和亞比戶在用凡火向耶和華獻祭時死去了。</span>
<span className="v" id="v62" data-v="62" data-xref="申命記 10:9; 民數記 35:2–8; 民數記 3:39"> 利未人中一個月以上的男性共登記了兩萬三千人，他們的人數沒有登記在以色列人中，因為他們在以色列人中不分產業。</span>
</div>
<div className="bp">
<span className="v" id="v63" data-v="63" data-xref="民數記 26:3"> 以上是摩西和以利亞撒祭司在約旦河邊、耶利哥對面的摩押平原統計的以色列人數，</span>
<span className="v" id="v64" data-v="64" data-xref="申命記 2:14–15; 申命記 4:3–4; 哥林多前書 10:5"> 其中沒有一個是摩西和祭司亞倫從前在西奈曠野登記的以色列人。</span>
<span className="v" id="v65" data-v="65" data-xref="哥林多前書 10:5–6; 民數記 14:38; 羅馬書 11:22"> 因為耶和華說過，那批人都要死在曠野。所以，除了耶孚尼的兒子迦勒和嫩的兒子約書亞以外，上次登記的人無一存活。</span>
</div>
</div>

## 以色列人發怨言

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命記 1:45; 民數記 11:1–4"> 當晚，全體會眾放聲大哭。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 15:24; 出埃及記 17:3; 民數記 16:41"> 全體以色列會眾埋怨摩西和亞倫說：「我們還不如死在埃及或曠野！</span>
<span className="v" id="v3" data-v="3" data-xref="民數記 14:31–32; 耶利米書 9:3; 詩篇 78:40"> 耶和華為什麼把我們領到這裡來，讓我們死於刀下？我們的妻兒必被擄去。我們還不如返回埃及。」</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行傳 7:39; 尼希米記 9:16–17; 申命記 17:16"> 他們彼此議論說：「我們選一位首領帶我們回埃及吧！」</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="民數記 16:4; 民數記 16:22; 民數記 16:45"> 摩西和亞倫俯伏在以色列全體會眾面前。</span>
<span className="v" id="v6" data-v="6" data-xref="民數記 14:30; 民數記 13:30; 民數記 14:38"> 打探迦南的人中，嫩的兒子約書亞和耶孚尼的兒子迦勒撕裂衣服，</span>
<span className="v" id="v7" data-v="7" data-xref="民數記 13:27; 申命記 1:25; 申命記 8:7–9"> 對以色列全體會眾說：「我們去打探的地方極其美好。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳記下 22:20; 以賽亞書 62:4; 民數記 13:27"> 如果耶和華喜悅我們，祂必把我們帶到那片土地，將那奶蜜之鄉賜給我們。</span>
<span className="v" id="v9" data-v="9" data-xref="申命記 7:18; 羅馬書 8:31; 申命記 31:6"> 你們不要背叛耶和華，也不要害怕那裡的人，他們不過是我們的獵物，他們已失去庇護。耶和華與我們同在，不要怕他們。」</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及記 17:4; 撒母耳記上 30:6; 利未記 9:23"> 但全體會眾威脅要用石頭打死他們二人。這時耶和華的榮光在會幕中向全體以色列人顯現。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="詩篇 78:32; 詩篇 106:24; 詩篇 78:22"> 耶和華對摩西說：「這些人藐視我要到何時呢？我在他們中間行了這麼多神蹟，他們還要不信我到何時呢？</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及記 32:10; 民數記 25:9; 撒母耳記下 24:12–15"> 我要用瘟疫毀滅他們，不讓他們承受那片土地。但我要使你成為大國，比他們更強盛。」</span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 106:23; 以西結書 20:9; 申命記 32:27"> 摩西對耶和華說：「你曾經用大能把以色列人從埃及領出來，埃及人聽說這事後，</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及記 15:14; 出埃及記 33:11; 申命記 5:4"> 一定會告訴迦南的居民。那裡的居民早已聽說你耶和華與以色列人同在，你面對面向他們顯現，你的雲彩停留在他們上面，你白天用雲柱、黑夜用火柱引導他們。</span>
<span className="v" id="v15" data-v="15" data-xref="士師記 6:16"> 如果你把他們全部消滅，那些聽過你威名的列國就會議論說，</span>
<span className="v" id="v16" data-v="16" data-xref="申命記 9:28; 約書亞記 7:9; 約書亞記 7:7"> 『耶和華無法把以色列人領到祂起誓要賜給他們的地方，所以在曠野把他們殺了。』</span>
<span className="v" id="v17" data-v="17" data-xref="馬太福音 9:6; 馬太福音 9:8; 彌迦書 3:8"> 因此，求主彰顯偉大的權能，正如你所宣告的，</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及記 34:6–7; 詩篇 145:8; 出埃及記 20:5"> 『耶和華不輕易發怒，充滿慈愛；祂赦免罪惡和過犯，但決不免除罪責，必向子孫追討父輩的罪債，直到三四代。』</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及記 34:9; 詩篇 78:38; 詩篇 106:45"> 從他們離開埃及直到現在，你一直在饒恕他們，求你以偉大的慈愛再次赦免這些人的罪。」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="彌迦書 7:18–20; 雅各書 5:16; 詩篇 106:23"> 耶和華說：「我聽你的祈求，赦免他們。</span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 72:19; 哈巴谷書 2:14; 以賽亞書 6:3"> 但我憑我的永恆起誓，正如大地充滿我的榮耀一樣確實，</span>
<span className="v" id="v22" data-v="22" data-xref="約伯記 19:3; 創世記 31:7; 出埃及記 32:1"> 他們絕對一個也看不到我起誓要賜給他們祖先的土地，藐視我的人都看不到那片土地。這些人見過我的榮耀，見過我在埃及和曠野所行的神蹟，卻仍然不聽我的話，試探我十次之多。</span>
<span className="v" id="v24" data-v="24" data-xref="民數記 14:6–9; 約書亞記 14:6–14; 以弗所書 6:6"> 但我的僕人迦勒力排眾議，全心跟從我，所以我必帶他進入那片他去過的土地，讓他的子孫擁有那片產業。</span>
<span className="v" id="v25" data-v="25" data-xref="申命記 1:40; 民數記 13:29; 詩篇 81:11–13"> 由於亞瑪力人和迦南人住在山谷中，明天你們要轉回，沿紅海的路前往曠野。」</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26"> 耶和華對摩西和亞倫說：</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及記 16:12; 哥林多前書 10:10; 出埃及記 16:28"> 「這邪惡的會眾向我發怨言要到何時呢？我已聽見以色列人對我的埋怨。</span>
<span className="v" id="v28" data-v="28" data-xref="民數記 14:21; 希伯來書 3:17; 民數記 14:2"> 你們去把我的話告訴他們，『以色列人啊，我憑我的永恆起誓，我必照你們所說的對待你們。</span>
<span className="v" id="v29" data-v="29" data-xref="民數記 1:45; 哥林多前書 10:5; 希伯來書 3:17"> 你們當中凡登記在冊、二十歲以上向我發怨言的人，必倒斃在這曠野中，</span>
<span className="v" id="v30" data-v="30" data-xref="民數記 26:65; 民數記 14:38; 申命記 1:36–38"> 除耶孚尼的兒子迦勒和嫩的兒子約書亞之外，你們無人能進入我向你們起誓應許之地。</span>
<span className="v" id="v31" data-v="31" data-xref="申命記 1:39; 詩篇 106:24; 民數記 26:64"> 你們說你們的兒女會被擄去，但我要把他們帶到那裡，讓他們享有那片你們厭棄的土地。</span>
<span className="v" id="v32" data-v="32" data-xref="哥林多前書 10:5; 民數記 14:29; 希伯來書 3:17"> 而你們必死在這曠野。</span>
<span className="v" id="v33" data-v="33" data-xref="以西結書 23:35; 民數記 32:13; 申命記 2:14"> 你們的兒女要在曠野飄泊四十年，為你們的不忠而受苦，直到你們都死在曠野。</span>
<span className="v" id="v34" data-v="34" data-xref="以西結書 4:6; 民數記 13:25; 耶利米書 18:9–10"> 你們打探了那地方四十天，你們要為自己的罪受苦四十年，一年頂一天。那時，你們就知道與我為敵的後果。』</span>
<span className="v" id="v35" data-v="35" data-xref="民數記 23:19; 哥林多前書 10:5; 希伯來書 3:19"> 我耶和華已經說過，我必這樣對付這群集合起來與我為敵的邪惡會眾。他們必死在曠野，全部喪命。」</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="民數記 13:31–33; 民數記 13:4–16"> 摩西派去打探迦南的人回來以後危言聳聽，以致全體會眾向摩西發怨言。</span>
<span className="v" id="v37" data-v="37" data-xref="哥林多前書 10:10; 民數記 16:49; 希伯來書 3:17"> 這些危言聳聽的人因而染上瘟疫，死在耶和華面前。</span>
<span className="v" id="v38" data-v="38" data-xref="約書亞記 14:6–10; 民數記 26:65"> 前去打探的人中只有嫩的兒子約書亞和耶孚尼的兒子迦勒得以倖存。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="出埃及記 33:4; 馬太福音 8:12; 希伯來書 12:17"> 摩西傳達完耶和華的話後，以色列人非常悲傷。</span>
<span className="v" id="v40" data-v="40" data-xref="申命記 1:41; 馬太福音 7:21–23; 路加福音 13:25"> 他們清早起來上到山頂，說：「我們知罪了，現在我們要去耶和華應許的地方。」</span>
<span className="v" id="v41" data-v="41" data-xref="歷代志下 24:20; 約伯記 4:9; 耶利米書 2:37"> 摩西說：「你們為什麼要違背耶和華的命令？你們不會成功的。</span>
<span className="v" id="v42" data-v="42" data-xref="申命記 1:42; 約書亞記 7:8; 約書亞記 7:12"> 不要上去！因為耶和華不與你們同在，你們會被敵人打敗。</span>
<span className="v" id="v43" data-v="43" data-xref="民數記 13:29; 民數記 14:25; 歷代志下 15:2"> 你們會遇見亞瑪力人和迦南人，並喪身在他們刀下，因為你們離棄耶和華，祂不再與你們同在。」</span>
<span className="v" id="v44" data-v="44" data-xref="申命記 1:43; 撒母耳記上 4:3–11; 民數記 31:6"> 儘管耶和華的約櫃和摩西都沒有出營，他們卻擅自上山頂去。</span>
<span className="v" id="v45" data-v="45" data-xref="民數記 21:3; 士師記 1:17; 申命記 1:44"> 住在山區的亞瑪力人和迦南人下來擊潰了他們，一路追殺他們到何珥瑪。</span>
</div>
</div>

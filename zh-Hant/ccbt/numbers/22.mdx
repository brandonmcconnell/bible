## 摩押王召巴蘭

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命記 34:1; 申命記 3:8; 民數記 21:20"> 以色列人繼續前行，抵達約旦河東岸的摩押平原，在耶利哥對面安營。</span>
<span className="v" id="v2" data-v="2" data-xref="士師記 11:25; 民數記 21:20–35; 民數記 21:3"> 西撥的兒子摩押王巴勒得知以色列人對亞摩利人的所作所為，</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 15:15; 以賽亞書 23:5; 約書亞記 9:24"> 又見他們人多勢眾，就驚恐萬狀。摩押人被以色列人嚇壞了，</span>
<span className="v" id="v4" data-v="4" data-xref="民數記 25:15–18; 民數記 31:8; 民數記 24:17"> 就對米甸的長老說：「這群人將吞掉我們周圍的一切，如同牛吃光田間的草一樣。」那時，西撥的兒子巴勒做摩押王。</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 23:4; 約書亞記 24:9; 彌迦書 6:5"> 他差遣使者去幼發拉底河附近，到比珥的兒子巴蘭的家鄉毗奪，去召巴蘭，說：「有一個民族從埃及鋪天蓋地而來，就住在我對面。</span>
<span className="v" id="v6" data-v="6" data-xref="民數記 24:9; 民數記 23:7–8; 使徒行傳 16:16"> 他們比我強大，求你為我咒詛他們。這樣，我也許就能擊敗他們，把他們趕走。我知道你祝福誰，誰就蒙福；你咒詛誰，誰就遭禍。」</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳記上 9:7–8; 彌迦書 3:11; 羅馬書 16:18"> 摩押和米甸的長老們帶著占卜的禮金去見巴蘭，把巴勒的話轉告他。</span>
<span className="v" id="v8" data-v="8" data-xref="民數記 23:12; 民數記 22:19–20; 耶利米書 12:2"> 巴蘭說：「你們今夜住在這裡，我必照耶和華的旨意回覆你們。」摩押的官長就在巴蘭那裡住下。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 20:3; 民數記 22:20; 創世記 16:8"> 晚上，上帝來問巴蘭：「住在你這裡的是誰？」</span>
<span className="v" id="v10" data-v="10"> 巴蘭回答說：「他們是摩押王西撥的兒子巴勒派來的，</span>
<span className="v" id="v11" data-v="11"> 說，『有一個民族從埃及鋪天蓋地而來。請你來咒詛那民族，這樣我或許能擊敗他們，把他們趕走。』」</span>
<span className="v" id="v12" data-v="12" data-xref="申命記 23:5; 以弗所書 1:3; 創世記 12:2"> 上帝對巴蘭說：「你不可跟他們去，也不可咒詛那民族，因為那民族是蒙福的。」</span>
<span className="v" id="v13" data-v="13" data-xref="申命記 23:5; 民數記 22:14"> 巴蘭清早起來，對巴勒的官長說：「你們回去吧，耶和華不准我跟你們去。」</span>
<span className="v" id="v14" data-v="14" data-xref="民數記 22:37; 民數記 22:13"> 摩押的官長回去對巴勒說：「巴蘭不肯跟我們來。」</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行傳 10:7–8; 民數記 22:7–8"> 巴勒又派去更多、更尊貴的官長。</span>
<span className="v" id="v16" data-v="16"> 他們到了巴蘭那裡，對他說：「西撥的兒子巴勒請你務必去一趟，</span>
<span className="v" id="v17" data-v="17" data-xref="民數記 24:11; 以斯帖記 5:11; 馬太福音 4:8–9"> 他必有重賞。你要什麼都可以，只求你去為他咒詛那民族。」</span>
<span className="v" id="v18" data-v="18" data-xref="民數記 24:13; 列王紀上 22:14; 歷代志下 18:13"> 巴蘭回答說：「巴勒就是把他滿屋的金銀都給我，我也不能在任何事上違背我的上帝耶和華的命令。</span>
<span className="v" id="v19" data-v="19" data-xref="猶大書 1:11; 彼得後書 2:3; 提摩太前書 6:9–10"> 請你們在這裡過夜，我好看看耶和華對我還有什麼吩咐。」</span>
<span className="v" id="v20" data-v="20" data-xref="民數記 23:12; 民數記 24:13; 民數記 23:26"> 當夜，上帝來對巴蘭說：「這些人既然來請你，你就跟他們去吧，但你只可照我說的做。」</span>
<span className="v" id="v21" data-v="21" data-xref="箴言 1:15–16"> 巴蘭清早起來，備好驢，跟摩押的官長去了。</span>
</div>
</div>

## 上帝攔阻巴蘭

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="出埃及記 4:24; 耶利米哀歌 2:4; 民數記 22:32"> 巴蘭這一去，激怒了上帝。巴蘭騎著驢，帶著兩個僕人正走在途中，耶和華的天使攔住他的去路。</span>
<span className="v" id="v23" data-v="23" data-xref="猶大書 1:11; 彼得後書 2:16; 哥林多前書 1:27–29"> 驢看見耶和華的天使拔刀攔在路上，就離開大路，跑進田間。巴蘭打驢，要牠回到路上。</span>
<span className="v" id="v24" data-v="24"> 耶和華的天使又站在葡萄園之間的一條窄路上，兩邊都是牆。</span>
<span className="v" id="v25" data-v="25" data-xref="以賽亞書 47:12; 約伯記 5:13–15"> 驢看見耶和華的天使，就靠著牆邊走，將巴蘭的腳擠在牆上了。巴蘭又打牠。</span>
<span className="v" id="v26" data-v="26" data-xref="何西阿書 2:6; 以賽亞書 26:11"> 耶和華的天使又走到前面，站在狹窄之處，兩邊都無側身通過的餘地。</span>
<span className="v" id="v27" data-v="27" data-xref="箴言 14:16; 雅各書 1:19; 箴言 27:3–4"> 巴蘭身下的驢看見耶和華的天使，就臥在地上，巴蘭大怒，便用杖打牠。</span>
<span className="v" id="v28" data-v="28" data-xref="彼得後書 2:16; 路加福音 1:37; 出埃及記 4:11"> 耶和華使驢開口對巴蘭說：「我做錯了什麼，你竟打我三次？」</span>
<span className="v" id="v29" data-v="29" data-xref="箴言 12:10; 馬太福音 15:19; 箴言 12:16"> 巴蘭說：「因為你戲弄我。如果我手中有刀，早就把你宰了！」</span>
<span className="v" id="v30" data-v="30" data-xref="彼得後書 2:16; 哥林多前書 1:27–28"> 驢對巴蘭說：「我不是你從小就騎的驢嗎？我可曾這樣對你？」巴蘭說：「沒有。」</span>
<span className="v" id="v31" data-v="31" data-xref="創世記 21:19; 路加福音 24:31; 使徒行傳 26:18"> 那時，耶和華開了巴蘭的眼，他才看見耶和華的天使拔刀攔在路上，便俯身下拜。</span>
<span className="v" id="v32" data-v="32" data-xref="箴言 28:18; 使徒行傳 13:10; 民數記 22:22"> 耶和華的天使對他說：「你為何三次打你的驢？我來阻擋你，因為你走的路在我眼中是邪路。</span>
<span className="v" id="v33" data-v="33" data-xref="民數記 16:33–35; 民數記 14:37; 列王紀上 13:24–28"> 你的驢看見我，一連躲避了三次，驢若沒有躲開，我早已殺了你，只放過驢。」</span>
<span className="v" id="v34" data-v="34" data-xref="約伯記 34:31–32; 撒母耳記下 12:13; 撒母耳記上 15:24"> 巴蘭對耶和華的天使說：「我有罪了，我不知道是你攔在路上。現在你如果反對我去，我就回去。」</span>
<span className="v" id="v35" data-v="35" data-xref="帖撒羅尼迦後書 2:9–12; 以賽亞書 37:26–29; 民數記 22:20–21"> 耶和華的天使說：「跟這些人去吧，但你只許按我的指示說話。」於是，巴蘭跟巴勒的官長去了。</span>
<span className="v" id="v36" data-v="36" data-xref="以賽亞書 16:2; 使徒行傳 28:15; 耶利米書 48:20"> 巴勒聽見巴蘭來了，就來到邊界盡頭、亞嫩河邊的摩押城迎接他。</span>
<span className="v" id="v37" data-v="37" data-xref="民數記 24:11; 約翰福音 5:44; 馬太福音 4:8–9"> 巴勒對巴蘭說：「上次派人請你，你為何不肯來？難道我不能給你重賞嗎？」</span>
<span className="v" id="v38" data-v="38" data-xref="民數記 22:18; 箴言 19:21; 民數記 23:16"> 巴蘭對巴勒說：「現在我已經來了，但我不能隨便發言，我只能按上帝的指示說話。」</span>
<span className="v" id="v39" data-v="39"> 巴蘭和巴勒一同來到基列·胡瑣。</span>
<span className="v" id="v40" data-v="40" data-xref="民數記 23:14; 箴言 1:16; 民數記 23:2"> 巴勒宰牛殺羊賞給巴蘭和隨行的官長。</span>
<span className="v" id="v41" data-v="41" data-xref="民數記 23:13; 民數記 25:2–3; 歷代志下 11:15"> 次日清晨，巴勒領巴蘭上到巴末·巴力<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「巴末·巴力」希伯來文是「巴力的高崗」之意。">a</a></sup>，從那裡可以看到一部分以色列人。</span>
</div>

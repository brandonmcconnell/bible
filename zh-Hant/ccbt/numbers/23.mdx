## 巴蘭的預言

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民數記 23:29; 猶大書 1:11; 出埃及記 27:1–8"> 巴蘭對巴勒說：「你在這裡為我築七座祭壇，預備七頭公牛和七隻公綿羊。」</span>
<span className="v" id="v2" data-v="2" data-xref="民數記 23:14; 民數記 23:30"> 巴勒就照巴蘭的話做了。他們二人在每座壇上獻上一頭公牛和一隻公綿羊，</span>
<span className="v" id="v3" data-v="3" data-xref="民數記 23:15; 創世記 8:20; 創世記 22:2"> 巴蘭對巴勒說：「你留在燔祭旁邊，我到前面去，也許耶和華會向我顯現。無論祂有什麼指示，我必告訴你。」巴蘭就上到一處光禿禿的高地。</span>
</div>
<div className="bp poetry">
<span className="v" id="v4" data-v="4" data-xref="民數記 23:16; 以弗所書 2:9; 路加福音 18:12"> 上帝向巴蘭顯現。巴蘭對上帝說：「我已經預備了七座祭壇，每座祭壇上獻了一頭公牛和一隻公綿羊。」</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 18:18; 耶利米書 1:9; 以賽亞書 59:21"> 耶和華告訴他當說的話，命他回去轉告巴勒。</span>
<span className="v" id="v6" data-v="6"> 巴蘭就回到巴勒那裡，看見他和摩押的官長都站在燔祭旁邊。</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 23:4; 民數記 24:3; 民數記 22:5–6"> 巴蘭吟詩預言說：<br /><span className="pl pl-1">「巴勒領我出亞蘭，</span><br /><span className="pl pl-1">摩押王請我出東山，</span><br /><span className="pl pl-1">說，『來為我咒詛雅各，</span><br /><span className="pl pl-1">來斥責以色列！』</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="民數記 23:23; 以賽亞書 44:25; 民數記 23:20"> <span className="pl pl-1">上帝沒有咒詛的，</span><br /><span className="pl pl-1">我怎能咒詛？</span><br /><span className="pl pl-1">耶和華沒有斥責的，</span><br /><span className="pl pl-1">我怎能斥責？</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="申命記 33:28; 申命記 32:8; 出埃及記 33:16"> <span className="pl pl-1">我從峰頂觀看他們，</span><br /><span className="pl pl-1">從高崗眺望他們，</span><br /><span className="pl pl-1">這獨居一方之民，</span><br /><span className="pl pl-1">不與萬國同列。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 37:37; 創世記 13:16; 詩篇 116:15"> <span className="pl pl-1">雅各的子孫多如塵土，</span><br /><span className="pl pl-1">誰能數得清？</span><br /><span className="pl pl-1">誰能數清以色列人的四分之一？</span><br /><span className="pl pl-1">我願像義人一樣死去，</span><br /><span className="pl pl-1">如義人般終此一生。」</span></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="尼希米記 13:2; 民數記 24:10; 民數記 22:17"> 巴勒對巴蘭說：「你這是做什麼？我請你來咒詛我的仇敵，你竟祝福他們！」</span>
<span className="v" id="v12" data-v="12" data-xref="民數記 22:38; 民數記 23:20; 民數記 23:26"> 巴蘭說：「耶和華讓我說的話，我豈能不說？」</span>
</div>
</div>

## 巴蘭第二次預言

<div className="bt">
<div className="bp poetry">
<span className="v" id="v13" data-v="13" data-xref="詩篇 109:17; 雅各書 3:9–10; 民數記 22:41"> 巴勒說：「請你跟我去另一個地方，那裡看不見全部以色列人，只能看見一部分，你要在那裡為我咒詛他們。」</span>
<span className="v" id="v14" data-v="14" data-xref="以賽亞書 46:6; 民數記 23:29; 以賽亞書 1:10–11"> 他領巴蘭上到毗斯迦山頂的瑣腓田，在那裡築了七座祭壇，每座壇上都獻了一頭公牛和一隻公綿羊。</span>
<span className="v" id="v15" data-v="15" data-xref="民數記 23:3; 民數記 22:8"> 巴蘭對巴勒說：「你留在這些燔祭旁邊，我到那邊去見耶和華。」</span>
<span className="v" id="v16" data-v="16" data-xref="民數記 23:5; 民數記 24:1; 民數記 22:35"> 耶和華向巴蘭顯現，告訴他當說的話，讓他轉告巴勒。</span>
<span className="v" id="v17" data-v="17" data-xref="民數記 23:26; 撒母耳記上 3:17; 耶利米書 37:17"> 巴蘭回到巴勒那裡，看見他和摩押的官長都站在燔祭旁邊。巴勒問道：「耶和華說了什麼？」</span>
<span className="v" id="v18" data-v="18" data-xref="士師記 3:20"> 巴蘭吟詩預言說：<br /><span className="pl pl-1">「巴勒啊，要留心聽！</span><br /><span className="pl pl-1">西撥的兒子啊，請聽我言。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳記上 15:29; 雅各書 1:17; 瑪拉基書 3:6"> <span className="pl pl-1">上帝並非世人，祂不撒謊；</span><br /><span className="pl pl-1">上帝不是凡人，祂不反悔。</span><br /><span className="pl pl-1">祂言出必行，信守承諾。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="約翰福音 10:27–29; 民數記 22:12; 創世記 12:2"> <span className="pl pl-1">我奉命祝福，祂已賜福，</span><br /><span className="pl pl-1">我不能改變。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 23:4; 馬太福音 1:23; 耶利米書 50:20"> <span className="pl pl-1">雅各的子孫中未見有罪惡，</span><br /><span className="pl pl-1">以色列人中看不見有禍患。</span><br /><span className="pl pl-1">他們的上帝耶和華與他們同在，</span><br /><span className="pl pl-1">他們向自己的君王歡呼。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="民數記 24:8; 申命記 33:17; 約伯記 39:9–11"> <span className="pl pl-1">上帝帶他們出埃及，</span><br /><span className="pl pl-1">祂</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「祂」有古卷作「他們」。">a</a></sup><br /><span className="pl pl-1">的力量如野牛之角。</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="路加福音 10:18–19; 約書亞記 13:22; 加拉太書 1:23–24"> <span className="pl pl-1">沒有邪術能害雅各，</span><br /><span className="pl pl-1">沒有咒語可傷以色列。</span><br /><span className="pl pl-1">時候一到，人們必談論雅各，</span><br /><span className="pl pl-1">談論以色列，說，『看啊，</span><br /><span className="pl pl-1">上帝的作為何等偉大！』</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="創世記 49:27; 創世記 49:9; 民數記 24:17"> <span className="pl pl-1">看啊，這民族挺身如母獅，</span><br /><span className="pl pl-1">躍起像雄獅，</span><br /><span className="pl pl-1">不吞食獵物、</span><br /><span className="pl pl-1">不喝獵物的血不躺臥。」</span></span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="詩篇 2:1–3"> 巴勒對巴蘭說：「你可以不咒詛他們，但也不該為他們祝福啊！」</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行傳 5:29; 民數記 22:18; 使徒行傳 4:19–20"> 巴蘭回答說：「我不是說過，我必須按耶和華的指示做嗎？」</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="羅馬書 11:29; 箴言 21:30; 民數記 23:19–20"> 巴勒說：「來吧，我帶你去另一個地方，也許上帝會同意你在那裡為我咒詛他們。」</span>
<span className="v" id="v28" data-v="28" data-xref="民數記 21:20; 詩篇 106:28"> 他領著巴蘭登上俯瞰曠野的毗珥山頂。</span>
<span className="v" id="v29" data-v="29" data-xref="民數記 23:1–2"> 巴蘭對巴勒說：「你在這裡為我築七座祭壇，預備七頭公牛和七隻公綿羊。」</span>
<span className="v" id="v30" data-v="30"> 巴勒就照巴蘭的話，在每座祭壇上獻了一頭公牛和一隻公綿羊。</span>
</div>
</div>

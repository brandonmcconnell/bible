## 迦南的疆域

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華對摩西說：</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 17:8; 詩篇 105:11; 申命記 1:7–8"> 「你把以下指示告訴以色列人。<br />「你們進入賜給你們作產業的迦南後，你們四境的疆界如下：</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="創世記 14:3; 以西結書 47:13; 約書亞記 3:16"> 「南部疆界從荀曠野沿著以東邊界延伸，東起死海的盡頭，</span>
<span className="v" id="v4" data-v="4" data-xref="民數記 32:8; 約書亞記 15:3–4; 民數記 13:26"> 往南至亞克拉濱坡南面，經荀直到加低斯·巴尼亞南面，再延伸至哈薩·亞達，經押們，</span>
<span className="v" id="v5" data-v="5" data-xref="約書亞記 15:4; 創世記 15:18; 列王紀上 8:65"> 轉向埃及河，直到地中海。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="約書亞記 1:4; 以西結書 47:20; 以西結書 47:15"> 「西部以地中海為界，這是你們西部的邊界。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="民數記 33:37; 民數記 34:6; 民數記 34:3"> 「北部疆界從地中海開始直到何珥山，</span>
<span className="v" id="v8" data-v="8" data-xref="民數記 13:21; 列王紀下 14:25; 約書亞記 13:5–6"> 從何珥山再到哈馬口，經西達達、</span>
<span className="v" id="v9" data-v="9" data-xref="以西結書 47:17"> 西斐崙直到哈薩·以難。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10"> 「東部疆界從哈薩·以難一直劃到示番，</span>
<span className="v" id="v11" data-v="11" data-xref="列王紀下 23:33; 申命記 3:17; 約書亞記 11:2"> 從示番往南到亞延東面的利比拉，再往南到基尼烈湖東岸。</span>
<span className="v" id="v12" data-v="12" data-xref="民數記 34:3; 創世記 13:10; 創世記 19:24–26"> 然後沿約旦河南下直到死海。這是你們國土四面的疆界。」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="民數記 34:1; 約書亞記 14:1–5"> 摩西又對以色列人說：「這就是耶和華吩咐用抽籤的方式分給你們九個半支派的土地。</span>
<span className="v" id="v14" data-v="14" data-xref="民數記 32:33; 民數記 32:23; 約書亞記 14:2–3"> 呂便支派和迦得支派已經按著家係得到了他們的產業，瑪拿西半個支派也得到了他們的產業。</span>
<span className="v" id="v15" data-v="15" data-xref="民數記 32:32"> 這兩個半支派的產業在耶利哥對面的約旦河東岸。」</span>
</div>
</div>

## 分地的首領

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16"> 耶和華對摩西說：</span>
<span className="v" id="v17" data-v="17" data-xref="約書亞記 14:1; 約書亞記 19:51; 民數記 13:8"> 「負責給你們分地的是以利亞撒祭司和嫩的兒子約書亞。</span>
<span className="v" id="v18" data-v="18" data-xref="民數記 1:4–16"> 每支派要選出一位首領來協助分地。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="民數記 26:65; 民數記 13:30; 民數記 14:24"> 「以下是這些首領的名字： 猶大支派耶孚尼的兒子迦勒，</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 49:5"> 西緬支派亞米忽的兒子示姆利，</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 49:27; 詩篇 68:27"> 便雅憫支派基斯倫的兒子以利達，</span>
<span className="v" id="v22" data-v="22"> 但支派約利的兒子布基，</span>
<span className="v" id="v23" data-v="23"> 約瑟之子瑪拿西支派以弗的兒子漢聶，</span>
<span className="v" id="v24" data-v="24"> 以法蓮支派拾弗但的兒子基姆利，</span>
<span className="v" id="v25" data-v="25"> 西布倫支派帕納的兒子以利撒番，</span>
<span className="v" id="v26" data-v="26"> 以薩迦支派阿散的兒子帕鐵，</span>
<span className="v" id="v27" data-v="27"> 亞設支派示羅米的兒子亞希忽，</span>
<span className="v" id="v28" data-v="28"> 拿弗他利支派亞米忽的兒子比達黑。」</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="約書亞記 19:51; 民數記 34:18"> 這些是奉耶和華之命在迦南給以色列人分產業的首領。</span>
</div>
</div>

</div>

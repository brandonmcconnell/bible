## 日常獻祭的條例

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華對摩西說：</span>
<span className="v" id="v2" data-v="2" data-xref="利未記 3:11; 創世記 8:21; 民數記 9:2–3"> 「你要吩咐以色列人，在規定的時間獻上蒙我悅納的馨香火祭，作為我的食物。</span>
<span className="v" id="v3" data-v="3" data-xref="利未記 6:9; 但以理書 11:31; 約翰福音 1:29"> 以下是他們要獻給耶和華的火祭：每天兩隻毫無殘疾、一歲的公羊羔作日常燔祭，</span>
<span className="v" id="v4" data-v="4" data-xref="但以理書 9:21; 列王紀上 18:36; 出埃及記 12:6"> 早晨和黃昏各獻一隻，</span>
<span className="v" id="v5" data-v="5" data-xref="利未記 2:1; 出埃及記 16:36; 出埃及記 29:38–42"> 同時獻上一公斤細麵粉，並調上一升橄欖油作素祭。</span>
<span className="v" id="v6" data-v="6" data-xref="阿摩司書 5:25; 利未記 6:9; 詩篇 50:8"> 這是在西奈山上規定的日常燔祭，是獻給耶和華的馨香火祭。</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及記 29:42; 民數記 28:14; 以賽亞書 57:6"> 與每隻羊羔一同獻上的還有一升酒，要將酒灑在聖所，作為獻給耶和華的奠祭。</span>
<span className="v" id="v8" data-v="8"> 黃昏獻第二隻羊羔時，也要跟早晨一樣同時獻上素祭和奠祭，作為蒙耶和華悅納的馨香火祭。</span>
</div>
</div>

## 安息日獻的祭

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="以賽亞書 58:13; 詩篇 92:1–4; 啟示錄 1:10"> 「安息日，要獻兩隻毫無殘疾、一歲的公羊羔，同時獻上奠祭以及兩公斤調油的細麵粉作素祭。</span>
<span className="v" id="v10" data-v="10" data-xref="以西結書 46:4–5; 民數記 29:22; 民數記 29:31"> 這是在日常燔祭和奠祭以外安息日所獻的燔祭。</span>
</div>
</div>

## 初一獻的祭

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="民數記 10:10; 以西結書 46:6; 以斯拉記 3:5"> 「在朔日，要給耶和華獻燔祭——兩頭公牛犢、一隻公綿羊和七隻一歲公羊羔，都要毫無殘疾。</span>
<span className="v" id="v12" data-v="12" data-xref="民數記 15:4–12; 以西結書 46:5–7; 民數記 29:10"> 同時要獻上調了油的細麵粉作素祭，每頭公牛需獻三公斤素祭，每隻公綿羊需獻兩公斤素祭，</span>
<span className="v" id="v13" data-v="13"> 每隻公羊羔需獻一公斤素祭。這馨香的燔祭是獻給耶和華的火祭。</span>
<span className="v" id="v14" data-v="14"> 獻燔祭時要同時獻上奠祭，每頭公牛需獻二升奠酒，每隻公綿羊需獻一升半奠酒，每隻羊羔需獻一升奠酒。這是朔日要獻的燔祭，一年之中月月如此。</span>
<span className="v" id="v15" data-v="15" data-xref="民數記 28:3; 民數記 28:22; 民數記 15:24"> 除了日常的燔祭和奠祭以外，還要把一隻公山羊獻給耶和華作贖罪祭。</span>
</div>
</div>

## 逾越節獻的祭

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="申命記 16:1–8; 出埃及記 12:18; 利未記 23:5–8"> 「一月十四日是耶和華的逾越節，</span>
<span className="v" id="v17" data-v="17" data-xref="利未記 23:6; 出埃及記 23:15; 出埃及記 13:6"> 十五日開始節慶，你們要連續七天吃無酵餅。</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及記 12:16; 利未記 23:7–8"> 第一天要舉行聖會，不可做日常工作。</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 15:21; 以西結書 45:21–25; 民數記 29:8"> 你們要把毫無殘疾的兩頭公牛犢、一隻公綿羊和七隻一歲的公羊羔，獻給耶和華作燔祭；</span>
<span className="v" id="v20" data-v="20"> 同時要獻上調了油的細麵粉作素祭，每頭公牛需獻三公斤素祭，每隻公綿羊需獻兩公斤素祭，</span>
<span className="v" id="v21" data-v="21"> 每隻公羊羔需獻一公斤素祭；</span>
<span className="v" id="v22" data-v="22" data-xref="羅馬書 8:3"> 同時還要獻一隻公山羊作贖罪祭，為你們贖罪。</span>
<span className="v" id="v23" data-v="23" data-xref="民數記 28:3; 民數記 28:10"> 除了早晨獻的日常燔祭以外，要獻上這些祭物。</span>
<span className="v" id="v24" data-v="24"> 接連七天，除了日常的燔祭和同獻的奠祭以外，還要照上面的規定給耶和華獻上馨香的火祭。</span>
<span className="v" id="v25" data-v="25" data-xref="利未記 23:8; 民數記 28:18; 出埃及記 13:6"> 第七天，你們要舉行聖會，不可做日常工作。</span>
</div>
</div>

## 七七收穫節獻的祭

<div className="bt">
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="出埃及記 23:16; 出埃及記 34:22; 利未記 23:10"> 「七七收穫節莊稼初熟之日，就是你們把新素祭獻給耶和華的日子，要召開聖會，不可做日常工作。</span>
<span className="v" id="v27" data-v="27" data-xref="利未記 23:18–19; 民數記 28:11; 民數記 28:19"> 你們要把兩頭公牛犢、一隻公綿羊和七隻一歲的公羊羔，獻給耶和華作馨香的燔祭。</span>
<span className="v" id="v28" data-v="28"> 同時要獻上調了油的細麵粉作素祭，每頭公牛需獻三公斤素祭，每隻公綿羊需獻兩公斤素祭，</span>
<span className="v" id="v29" data-v="29"> 每隻公羊羔需獻一公斤素祭。</span>
<span className="v" id="v30" data-v="30" data-xref="民數記 28:15; 民數記 28:22; 彼得前書 2:24"> 此外，還要獻上一隻公山羊作贖罪祭，為你們贖罪。</span>
<span className="v" id="v31" data-v="31" data-xref="民數記 28:19; 民數記 28:3; 瑪拉基書 1:13–14"> 除了日常的燔祭和同獻的素祭以外，還要獻上奠祭。祭牲不可有殘疾。</span>
</div>
</div>

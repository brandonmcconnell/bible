## 打探迦南

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華對摩西說：</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 1:22–25; 民數記 32:8; 民數記 34:18"> 「你要派十二位首領，每個支派一位，去打探我要賜給以色列人的迦南。」</span>
<span className="v" id="v3" data-v="3" data-xref="民數記 12:16; 民數記 32:8; 申命記 1:19"> 摩西就按耶和華的吩咐，從巴蘭曠野派出了以色列人的十二位首領。</span>
<span className="v" id="v4" data-v="4"> 他們的名字如下：呂便支派撒刻的兒子沙姆亞，</span>
<span className="v" id="v5" data-v="5"> 西緬支派何利的兒子沙法，</span>
<span className="v" id="v6" data-v="6" data-xref="民數記 34:19; 民數記 14:6; 民數記 13:30"> 猶大支派耶孚尼的兒子迦勒，</span>
<span className="v" id="v7" data-v="7"> 以薩迦支派約色的兒子以迦，</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及記 24:13; 民數記 11:28; 民數記 13:16"> 以法蓮支派嫩的兒子何西阿，</span>
<span className="v" id="v9" data-v="9"> 便雅憫支派拉孚的兒子帕提，</span>
<span className="v" id="v10" data-v="10"> 西布倫支派梭底的兒子迦疊，</span>
<span className="v" id="v11" data-v="11"> 約瑟的子孫、瑪拿西支派穌西的兒子迦底，</span>
<span className="v" id="v12" data-v="12"> 但支派基瑪利的兒子亞米利，</span>
<span className="v" id="v13" data-v="13"> 亞設支派米迦勒的兒子西帖，</span>
<span className="v" id="v14" data-v="14"> 拿弗他利支派縛西的兒子拿比，</span>
<span className="v" id="v15" data-v="15"> 迦得支派瑪基的兒子臼利。</span>
<span className="v" id="v16" data-v="16" data-xref="民數記 13:8; 出埃及記 17:9; 民數記 14:6"> 以上是摩西派去打探迦南的人，他稱嫩的兒子何西阿為約書亞。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="士師記 1:9; 創世記 12:9; 士師記 1:19"> 摩西派他們去打探迦南，並囑咐說：「你們先去南地，然後再進山區，</span>
<span className="v" id="v18" data-v="18" data-xref="以西結書 34:14; 出埃及記 3:8"> 察看那地方，看看那裡的居民是強是弱，是多是少；</span>
<span className="v" id="v19" data-v="19"> 他們住的地方是好是壞，人們住的是堅固的城池還是不設防的營地；</span>
<span className="v" id="v20" data-v="20" data-xref="申命記 31:23; 申命記 31:6–8; 以西結書 34:14"> 土地是肥沃還是貧瘠，有沒有樹木。儘力帶些當地的果子回來。」當時是葡萄初熟的季節。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="民數記 20:1; 民數記 33:36; 民數記 27:14"> 於是，他們從荀曠野一直打探到哈馬口附近的利合。</span>
<span className="v" id="v22" data-v="22" data-xref="詩篇 78:12; 詩篇 78:43; 以賽亞書 19:11"> 他們經南地到達希伯崙。希伯崙城比埃及的瑣安城還要早建七年，那裡住著亞衲人的子孫亞希幔、示篩和撻買。</span>
<span className="v" id="v23" data-v="23" data-xref="民數記 13:24; 民數記 32:9; 申命記 1:24–25"> 他們來到以實各谷，在那裡砍下一根葡萄枝，上面有一串葡萄，由兩個人用槓子抬著，又採了一些石榴和無花果。</span>
<span className="v" id="v24" data-v="24"> 因為他們在那裡砍了一串葡萄，所以就稱那地方為以實各<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「以實各」意思是「一串」。">a</a></sup>谷。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="出埃及記 34:28; 出埃及記 24:18; 民數記 14:33–34"> 過了四十天，他們打探完畢，返回營地。</span>
<span className="v" id="v26" data-v="26" data-xref="民數記 32:8; 民數記 20:1; 申命記 1:19"> 他們來到巴蘭曠野的加低斯向摩西、亞倫和以色列全體會眾彙報，把當地的果子給大家看。</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及記 3:8; 出埃及記 3:17; 出埃及記 13:5"> 他們對摩西說：「我們到了你派我們去的那地方，果然是奶蜜之鄉，這些都是那裡的果子。</span>
<span className="v" id="v28" data-v="28" data-xref="申命記 9:1–2; 申命記 1:28; 民數記 13:33"> 但那裡的居民很強悍，城邑高大堅固。我們在那裡還見到亞衲人的子孫。</span>
<span className="v" id="v29" data-v="29" data-xref="民數記 14:43; 士師記 6:3; 創世記 15:19–21"> 亞瑪力人住在南地，赫人、耶布斯人和亞摩利人住在山區，迦南人住在海邊和約旦河沿岸。」</span>
<span className="v" id="v30" data-v="30" data-xref="民數記 14:24; 羅馬書 8:31; 腓立比書 4:13"> 迦勒讓站在摩西面前的民眾安靜，然後說：「我們立刻上去佔領那地方吧！我們必能取勝。」</span>
<span className="v" id="v31" data-v="31" data-xref="申命記 1:28; 約書亞記 14:8; 希伯來書 3:19"> 跟他一起去打探的人卻說：「我們不能上去攻打那些人，他們比我們強大。」</span>
<span className="v" id="v32" data-v="32" data-xref="阿摩司書 2:9; 民數記 14:36–37; 以西結書 36:13–14"> 他們還危言聳聽，說：「我們去打探的地方是吞吃居民之地，我們看見的人個個身材高大。</span>
<span className="v" id="v33" data-v="33" data-xref="申命記 1:28; 以賽亞書 40:22; 創世記 6:4"> 我們在那裡看見了亞衲人的子孫，他們是巨人的後裔，我們跟他們相比就像蚱蜢，他們看我們也像蚱蜢。」</span>
</div>
</div>

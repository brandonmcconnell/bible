## 利未人分到的城邑

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民數記 22:1; 民數記 31:12; 民數記 33:50"> 在耶利哥對面、約旦河邊的摩押平原，耶和華對摩西說：</span>
<span className="v" id="v2" data-v="2" data-xref="約書亞記 14:3–4; 以西結書 48:8; 約書亞記 21:2–42"> 「你告訴以色列人，要從分得的產業中把一些城邑及其周圍的草場分給利未人。</span>
<span className="v" id="v3" data-v="3" data-xref="歷代志下 11:14; 約書亞記 21:11; 以西結書 45:2"> 城邑供他們居住，草場供他們牧放牛羊等牲畜。</span>
<span className="v" id="v4" data-v="4"> 劃分給利未人的草場是從城牆往外延伸四百五十米<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「四百五十米」《七十士譯本》作「九百一十米」。">a</a></sup>，</span>
<span className="v" id="v5" data-v="5"> 要以城為中心，東南西北四郊每邊向外量九百米，作利未人的草場。</span>
<span className="v" id="v6" data-v="6" data-xref="約書亞記 21:13; 約書亞記 21:3; 詩篇 9:9"> 要分給利未人四十二座城邑，另外再加六座供誤殺人者逃命的避難城，</span>
<span className="v" id="v7" data-v="7" data-xref="約書亞記 21:3–42; 歷代志上 6:54–81"> 共分給利未人四十八座城邑，包括城周圍的草場。</span>
<span className="v" id="v8" data-v="8" data-xref="民數記 26:54; 民數記 33:54; 約書亞記 21:1–42"> 以色列各支派要按比例從自己承受的產業中分一些城邑給利未人，人多的支派多給，人少的支派少給。」</span>
</div>
</div>

## 避難城

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9"> 耶和華對摩西說：</span>
<span className="v" id="v10" data-v="10" data-xref="申命記 12:9; 申命記 19:1–2; 利未記 14:34"> 「你要告訴以色列人，『你們過了約旦河進入迦南以後，</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及記 21:13; 約書亞記 20:2; 民數記 35:6"> 要選一些城邑作為你們的避難城，供誤殺人者逃去避難，</span>
<span className="v" id="v12" data-v="12" data-xref="約書亞記 20:3–6; 申命記 19:6; 約書亞記 20:9"> 躲避復仇的人，以免誤殺人者未在會眾面前受審，便被殺死。</span>
<span className="v" id="v13" data-v="13"> 你們要選六座城作為避難城，</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 19:8–10; 申命記 4:41–43; 約書亞記 20:7–9"> 三座在約旦河東岸，三座在迦南。</span>
<span className="v" id="v15" data-v="15" data-xref="民數記 15:16; 加拉太書 3:28; 羅馬書 3:29"> 凡誤殺人的，無論是以色列人，還是在他們當中寄居的外族人，都可以逃到這些城避難。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="利未記 24:17; 創世記 9:5–6; 申命記 19:11–13"> 「『倘若有人用鐵器打人致死，他就是故意殺人，殺人犯必須被處死。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及記 21:18"> 倘若有人用足以致命的石頭打人致死，他就是故意殺人，殺人犯必須被處死。</span>
<span className="v" id="v18" data-v="18"> 倘若有人用足以致命的木器打人致死，他就是故意殺人，殺人犯必須被處死。</span>
<span className="v" id="v19" data-v="19" data-xref="約書亞記 20:3; 申命記 19:6; 申命記 19:12"> 報血仇的人要親自處死故意殺人者，一找到他就要處死他。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及記 21:14; 申命記 19:11; 撒母耳記下 3:27"> 倘若有人因仇恨把人推倒致死，或故意扔東西砸人致死，</span>
<span className="v" id="v21" data-v="21"> 或因仇恨徒手傷人致死，他就是故意殺人，殺人犯必須被處死，報血仇的人一找到他就要處死他。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="民數記 35:11; 出埃及記 21:13; 約書亞記 20:3"> 「『倘若有人並非出於懷恨，而是偶然推倒人致死，或無意間扔東西砸人致死，</span>
<span className="v" id="v23" data-v="23"> 或因沒有看見而扔石頭砸人致死，鑒於他與對方並非仇人，也無意加害對方，</span>
<span className="v" id="v24" data-v="24" data-xref="約書亞記 20:6; 民數記 35:12"> 會眾就要照這些律例在誤殺人者與報血仇者之間做出判決。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及記 29:7; 利未記 4:3; 羅馬書 3:24–26"> 會眾要把誤殺人者從報血仇者手裡救出來，讓他回到他原先逃往的避難城。他要住在那裡，一直住到受聖油膏立的大祭司逝世。</span>
<span className="v" id="v26" data-v="26"> 但倘若誤殺人者離開避難城，</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及記 22:2; 申命記 19:10; 申命記 19:6"> 報血仇的人在城外找到他，將他殺死也不用擔血債。</span>
<span className="v" id="v28" data-v="28" data-xref="希伯來書 3:14; 希伯來書 10:26–30; 希伯來書 6:4–8"> 因為誤殺人者必須留在避難城內，等到大祭司逝世之後，才可返回家園。</span>
<span className="v" id="v29" data-v="29" data-xref="民數記 27:11; 民數記 27:1"> 這是你們世世代代無論住在哪裡都要遵守的律例。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="希伯來書 10:28; 申命記 19:15; 馬太福音 18:16"> 「『倘若有人被控謀殺，必須有幾個人作證才可以處死他，不可憑一個人的證詞處死他。</span>
<span className="v" id="v31" data-v="31" data-xref="申命記 19:11–13; 創世記 9:5–6; 詩篇 51:14"> 犯了死罪的殺人犯必須償命，不可讓他付贖金免死。</span>
<span className="v" id="v32" data-v="32" data-xref="使徒行傳 4:12; 加拉太書 3:10–13; 加拉太書 2:21"> 不可收逃進避難城之人的贖金，讓他在大祭司逝世前返回家園。</span>
<span className="v" id="v33" data-v="33" data-xref="路加福音 11:50–51; 詩篇 106:38; 何西阿書 4:2–3"> 這樣，你們就不致玷污你們所居住的土地，因為血會玷污土地。除非用兇手的血作抵償，否則被血玷污的土地無法得到潔淨。</span>
<span className="v" id="v34" data-v="34" data-xref="民數記 5:3; 詩篇 135:21; 啟示錄 21:27"> 不可玷污你們所居住的土地，那也是我居住的地方，因為我耶和華住在以色列人中間。』」</span>
</div>
</div>

</div>

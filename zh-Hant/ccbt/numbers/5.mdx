## 送不潔淨之人出營

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華對摩西說：</span>
<span className="v" id="v2" data-v="2" data-xref="利未記 21:1; 利未記 13:46; 民數記 12:14"> 「你吩咐以色列人把所有患痲瘋病、漏症和因碰過死屍而不潔淨的人，</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 23:14; 利未記 26:11–12; 詩篇 68:18"> 無論男女，都送到營外，免得他們玷污了營地，因為我住在其中。」</span>
<span className="v" id="v4" data-v="4"> 以色列人遵命而行，照耶和華對摩西的吩咐，把這些人送到營外。</span>
</div>
</div>

## 賠償條例

<div className="bt">
<div className="bp">
<span className="v" id="v5" data-v="5"> 耶和華對摩西說：</span>
<span className="v" id="v6" data-v="6" data-xref="利未記 5:1–4; 利未記 5:14–7"> 「你把以下條例告訴以色列人：無論男女，若虧負別人，以致失信於耶和華，就是犯罪。</span>
<span className="v" id="v7" data-v="7" data-xref="利未記 5:5; 利未記 26:40; 約書亞記 7:19"> 那人必須認罪，賠償受害人全部損失，並加賠五分之一。</span>
<span className="v" id="v8" data-v="8" data-xref="利未記 6:6–7; 利未記 7:7; 利未記 25:25–26"> 如果受害人已死，又沒有可以接受賠償的近親，賠償就屬於耶和華，要歸祭司所有。那人還要再獻上一隻公綿羊為自己贖罪。</span>
<span className="v" id="v9" data-v="9" data-xref="申命記 18:3–4; 利未記 7:6–14; 利未記 6:17–18"> 以色列人帶來奉獻的一切聖物都要歸祭司所有。</span>
<span className="v" id="v10" data-v="10" data-xref="利未記 10:13"> 各人奉獻的聖物，無論是什麼，都要歸祭司所有。」</span>
</div>
</div>

## 疑妻不貞

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11"> 耶和華對摩西說：</span>
<span className="v" id="v12" data-v="12" data-xref="民數記 5:19–20; 箴言 2:16–17"> 「你把以下條例告訴以色列人：若有人懷疑妻子出軌，暗中與人通姦，玷污了自己，卻沒有證人，也沒有當場抓住她，在無法確定是自己疑心還是妻子不貞的情況下，</span>
<span className="v" id="v15" data-v="15" data-xref="以西結書 29:16; 列王紀上 17:18; 利未記 5:11"> 他要帶妻子到祭司那裡，同時為妻子帶去一公斤大麥麵粉作為供物。不可在上面澆油或加乳香，因為這是因疑心而獻上的素祭，是讓人回憶過犯的素祭。</span>
<span className="v" id="v16" data-v="16" data-xref="啟示錄 2:22–23; 耶利米書 17:10; 希伯來書 13:4"> 「祭司要把那婦人帶到耶和華面前，</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及記 30:18; 約翰福音 8:6; 民數記 19:2–9"> 用陶器盛一些聖水，從聖幕的地上取一些塵土撒在水中，</span>
<span className="v" id="v18" data-v="18" data-xref="箴言 5:4; 民數記 5:22; 啟示錄 10:9–10"> 然後讓那婦人站在耶和華面前，解開她的頭髮，把回憶過犯的素祭，就是因疑心而獻的素祭放在她手裡。祭司要拿著帶給罪人咒詛的苦水，</span>
<span className="v" id="v19" data-v="19" data-xref="羅馬書 7:2; 民數記 5:12; 馬太福音 26:63"> 叫她發誓。祭司要對她說，『如果你沒有背著丈夫與人通姦，沒有因出軌而玷污自己，就不會被這苦水所害。</span>
<span className="v" id="v20" data-v="20" data-xref="民數記 5:12"> 如果你曾出軌，背著丈夫與人通姦，以致玷污自己，</span>
<span className="v" id="v21" data-v="21" data-xref="約書亞記 6:26; 尼希米記 10:29; 撒母耳記上 14:24"> 願耶和華使你大腿消瘦、肚腹腫脹，使你在同胞中成為咒詛。</span>
<span className="v" id="v22" data-v="22" data-xref="詩篇 109:18; 詩篇 89:52; 約伯記 31:39–40"> 願這可帶來咒詛的苦水進入你體內，使你肚腹腫脹、大腿消瘦。』她要說，『阿們<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「阿們」是「誠然如此」的意思。">a</a></sup>！阿們！』</span>
<span className="v" id="v23" data-v="23" data-xref="使徒行傳 3:19; 詩篇 51:1; 詩篇 51:9"> 祭司要把這咒詛寫在書卷上，再放在苦水裡把字洗掉。</span>
<span className="v" id="v24" data-v="24" data-xref="撒迦利亞書 5:3–4; 瑪拉基書 3:5"> 祭司要讓婦人喝這可帶來咒詛的苦水，不忠的婦人喝下後，肚子會感到劇痛。</span>
<span className="v" id="v25" data-v="25" data-xref="利未記 8:27; 民數記 5:18; 民數記 5:15"> 祭司要從婦人手中接過她丈夫因疑心而獻的素祭，在耶和華面前搖一搖，然後帶到祭壇那裡。</span>
<span className="v" id="v26" data-v="26" data-xref="利未記 2:2; 利未記 2:9; 利未記 5:12"> 他要從素祭中取出一把麵粉，作為象徵放在祭壇上焚燒，然後叫那婦人喝下苦水。</span>
<span className="v" id="v27" data-v="27" data-xref="耶利米書 42:18; 撒迦利亞書 8:13; 耶利米書 29:18"> 如果她曾玷污自己，背叛了丈夫，這可帶來咒詛的苦水進入她體內後，會引起劇痛，使她肚腹腫脹、大腿消瘦，她將在同胞中成為咒詛。</span>
<span className="v" id="v28" data-v="28" data-xref="彌迦書 7:7–10; 哥林多後書 4:17; 詩篇 113:9"> 但如果她是貞潔的，沒有玷污自己，就不會受傷害，仍能生育。</span>
<span className="v" id="v29" data-v="29" data-xref="民數記 5:19; 民數記 5:12; 民數記 5:15"> 「這就是處理丈夫懷疑妻子不貞的條例。遇到妻子背著丈夫與人通姦，</span>
<span className="v" id="v30" data-v="30"> 或是丈夫懷疑妻子不貞，就要讓妻子站在耶和華面前，由祭司對她執行這條例。</span>
<span className="v" id="v31" data-v="31" data-xref="利未記 20:10; 羅馬書 2:8–9; 以西結書 18:4"> 無論結果怎樣，丈夫都無罪，但妻子若有罪，必承擔罪責。」</span>
</div>
</div>

## 攻打米甸人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華對摩西說：</span>
<span className="v" id="v2" data-v="2" data-xref="民數記 27:13; 民數記 25:14–18; 啟示錄 6:10"> 「你要為以色列人向米甸人報仇，之後你將歸到祖先那裡。」</span>
<span className="v" id="v3" data-v="3" data-xref="利未記 26:25; 民數記 25:11; 列王紀下 10:30"> 於是，摩西對民眾說：「你們的人要拿起兵器去攻打米甸，為耶和華報仇。</span>
<span className="v" id="v4" data-v="4" data-xref="利未記 26:8; 撒母耳記上 14:6; 士師記 7:2"> 以色列的每個支派要派一千人出戰。」</span>
<span className="v" id="v5" data-v="5"> 於是，他們從以色列每個支派選出一千人，武裝了一萬二千軍兵。</span>
<span className="v" id="v6" data-v="6" data-xref="民數記 14:44; 民數記 10:8–9; 歷代志下 13:12–15"> 每個支派選出的一千軍兵由摩西派遣出戰，以利亞撒祭司的兒子非尼哈拿著聖所的器具和號角隨行。</span>
<span className="v" id="v7" data-v="7" data-xref="士師記 21:11; 列王紀上 11:15–16; 撒母耳記上 27:9"> 他們照耶和華對摩西的吩咐，去攻打米甸人，殺死了米甸的所有男子，</span>
<span className="v" id="v8" data-v="8" data-xref="約書亞記 13:21–22; 民數記 25:15; 啟示錄 2:14"> 包括以未、利金、蘇珥、戶珥和利巴五個米甸的王，還殺了比珥的兒子巴蘭。</span>
<span className="v" id="v9" data-v="9" data-xref="申命記 20:14; 歷代志下 28:8–10; 歷代志下 28:5"> 以色列人擄獲了米甸的婦女、孩子、所有牛羊和財物，</span>
<span className="v" id="v10" data-v="10" data-xref="以賽亞書 1:7; 撒母耳記上 30:1; 約書亞記 6:24"> 將他們的城邑營寨付之一炬，</span>
<span className="v" id="v11" data-v="11" data-xref="申命記 20:14; 約書亞記 8:2"> 帶走了擄掠的人畜等戰利品。</span>
<span className="v" id="v12" data-v="12" data-xref="民數記 22:1"> 他們來到耶利哥對面、約旦河邊的摩押平原，把戰利品交給摩西、以利亞撒祭司和以色列全體會眾。</span>
<span className="v" id="v13" data-v="13" data-xref="民數記 5:2; 撒母耳記上 30:21; 民數記 31:12"> 摩西、以利亞撒祭司以及所有民眾的首領，都到營外迎接他們。</span>
<span className="v" id="v14" data-v="14" data-xref="列王紀下 13:19; 撒母耳記上 15:13–14; 民數記 31:48"> 摩西對出征回來的千夫長和百夫長等將領發怒，</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳記上 15:3; 耶利米書 48:10; 申命記 2:34"> 說：「你們為什麼讓這些婦女活著？</span>
<span className="v" id="v16" data-v="16" data-xref="民數記 25:1–9; 彼得後書 2:15; 啟示錄 2:14"> 就是她們聽了巴蘭的指使，在毗珥引誘以色列人背叛耶和華，以致瘟疫降在耶和華的會眾身上。</span>
<span className="v" id="v17" data-v="17" data-xref="士師記 21:11–12; 申命記 20:16–18; 申命記 7:2"> 現在，你們要殺掉所有的男孩，以及與男人發生過關係的女子，</span>
<span className="v" id="v18" data-v="18" data-xref="申命記 21:10–14; 歷代志下 28:8–10; 申命記 20:14"> 但可以留下那些處女。</span>
<span className="v" id="v19" data-v="19" data-xref="民數記 19:11–22; 民數記 5:2; 歷代志上 22:8"> 你們凡殺了人和碰過死人的，都要在營外待七天。在第三天和第七天，你們要潔淨自己及擄來的人，</span>
<span className="v" id="v20" data-v="20" data-xref="民數記 19:22; 創世記 35:2; 出埃及記 19:10"> 也要潔淨自己所有的衣服、皮具、山羊毛製品和木器。」</span>
<span className="v" id="v21" data-v="21" data-xref="民數記 30:16"> 以利亞撒祭司對打仗回來的軍兵說：「以下是耶和華藉摩西頒佈的律例。</span>
<span className="v" id="v22" data-v="22"> 金、銀、銅、鐵、錫、鉛，</span>
<span className="v" id="v23" data-v="23" data-xref="民數記 19:9; 民數記 19:17; 哥林多前書 3:13"> 凡耐火之物都要用火來潔淨，還要用除穢水加以潔淨；不耐火之物要用水來潔淨。</span>
<span className="v" id="v24" data-v="24" data-xref="利未記 11:25; 利未記 15:13; 利未記 14:9"> 第七天，你們洗完衣服後就潔淨了，可以回營。」</span>
<span className="v" id="v25" data-v="25"> 耶和華對摩西說：</span>
<span className="v" id="v26" data-v="26"> 「你和以利亞撒祭司以及會眾的各族長，要統計俘虜和牲畜的數目，</span>
<span className="v" id="v27" data-v="27" data-xref="約書亞記 22:8; 詩篇 68:12; 撒母耳記上 30:24–25"> 然後把這些戰利品分成兩份，一份給出征的戰士，一份給其餘會眾。</span>
<span className="v" id="v28" data-v="28" data-xref="民數記 18:26; 民數記 31:30; 民數記 31:47"> 要從戰士分得的俘虜、牛、驢和羊群中抽出五百分之一，獻給耶和華，</span>
<span className="v" id="v29" data-v="29" data-xref="出埃及記 29:27; 申命記 12:19; 申命記 12:12"> 要把那五百分之一交給以利亞撒祭司，獻給耶和華作舉祭。</span>
<span className="v" id="v30" data-v="30" data-xref="民數記 3:31; 民數記 3:7–8; 民數記 3:25"> 要從以色列人分得的俘虜和牛、驢、羊等牲畜中抽出五十分之一，交給在我聖幕司職的利未人。」</span>
<span className="v" id="v31" data-v="31"> 摩西和以利亞撒祭司遵命而行。</span>
<span className="v" id="v32" data-v="32"> 戰士擄獲的戰利品中有六十七萬五千隻羊，</span>
<span className="v" id="v33" data-v="33"> 七萬二千頭牛，</span>
<span className="v" id="v34" data-v="34"> 六萬一千頭驢，</span>
<span className="v" id="v35" data-v="35"> 三萬二千名處女。</span>
<span className="v" id="v36" data-v="36"> 戰士分得的戰利品有三十三萬七千五百隻羊，</span>
<span className="v" id="v37" data-v="37"> 其中六百七十五隻獻給耶和華；</span>
<span className="v" id="v38" data-v="38"> 三萬六千頭牛，其中七十二頭獻給耶和華；</span>
<span className="v" id="v39" data-v="39"> 三萬零五百頭驢，其中六十一頭獻給耶和華；</span>
<span className="v" id="v40" data-v="40"> 一萬六千名處女，其中三十二人獻給耶和華。</span>
<span className="v" id="v41" data-v="41" data-xref="民數記 18:8; 民數記 18:19; 希伯來書 7:9–12"> 摩西照耶和華的吩咐，把獻給耶和華的舉祭交給以利亞撒祭司。</span>
<span className="v" id="v42" data-v="42"> 以色列會眾分得的那一半戰利品，即摩西從出征之人的戰利品中分出來給他們的，</span>
<span className="v" id="v43" data-v="43"> 有三十三萬七千五百隻羊、</span>
<span className="v" id="v44" data-v="44"> 三萬六千頭牛、</span>
<span className="v" id="v45" data-v="45"> 三萬零五百頭驢、</span>
<span className="v" id="v46" data-v="46"> 一萬六千名處女。</span>
<span className="v" id="v47" data-v="47" data-xref="民數記 31:30; 路加福音 10:1–8; 以賽亞書 56:10–11"> 摩西照耶和華的吩咐，從中抽出五十分之一，交給在聖幕裡司職的利未人。</span>
<span className="v" id="v48" data-v="48"> 統領軍隊的千夫長和百夫長來見摩西，</span>
<span className="v" id="v49" data-v="49" data-xref="約翰福音 18:9; 撒母耳記上 30:18–19; 詩篇 72:14"> 說：「僕人們統計了手下出征的戰士，未失一兵一卒。</span>
<span className="v" id="v50" data-v="50" data-xref="出埃及記 30:12; 出埃及記 30:15–16; 詩篇 116:12"> 現在我們把各自擄獲的臂環、鐲子、圖章戒指、耳環、項鏈等金器，都帶來獻給耶和華，在祂面前為我們贖罪。」</span>
<span className="v" id="v51" data-v="51" data-xref="民數記 7:2–6"> 摩西和以利亞撒祭司收了他們所獻的各種金製品。</span>
<span className="v" id="v52" data-v="52"> 千夫長和百夫長獻給耶和華作舉祭的金子共三千八百兩。</span>
<span className="v" id="v53" data-v="53" data-xref="申命記 20:14; 民數記 31:32"> 戰士則保留了自己擄獲的財物。</span>
<span className="v" id="v54" data-v="54" data-xref="出埃及記 30:16; 撒迦利亞書 6:14; 使徒行傳 10:4"> 摩西和以利亞撒祭司就把千夫長和百夫長獻的金子帶進會幕，在耶和華面前作以色列人的紀念。</span>

## 安置七盞燈

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華對摩西說：</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 25:37; 出埃及記 40:25; 利未記 24:1–2"> 「你告訴亞倫，『你安放燈的時候，七盞燈都要照在燈臺前面。』」</span>
<span className="v" id="v3" data-v="3"> 亞倫就照耶和華對摩西的吩咐把燈放好，使燈照亮燈台前面。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及記 25:31–40; 出埃及記 25:9; 出埃及記 25:18"> 整座燈臺，從燈座到花朵，都是照耶和華指示摩西的樣式用金子錘製而成的。</span>
</div>
</div>

## 為利未人行潔淨與奉獻禮

<div className="bt">
<div className="bp">
<span className="v" id="v5" data-v="5"> 耶和華對摩西說：</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多後書 7:1; 雅各書 4:8; 出埃及記 19:15"> 「你要把利未人從其他以色列人中分別出來，潔淨他們。</span>
<span className="v" id="v7" data-v="7" data-xref="民數記 19:13; 民數記 19:7–10; 利未記 8:6"> 要用以下的方法潔淨他們，把潔淨水灑在他們身上，叫他們用剃刀剃淨全身，洗淨衣服，這樣他們就潔淨了。</span>
<span className="v" id="v8" data-v="8" data-xref="利未記 2:1; 出埃及記 29:1; 利未記 16:3"> 然後叫他們帶來一頭公牛犢及作素祭的調了油的細麵粉，你要另獻一頭公牛犢作贖罪祭。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及記 40:12; 利未記 8:3; 出埃及記 29:4–37"> 你要招聚以色列全體會眾，將利未人帶到會幕前，</span>
<span className="v" id="v10" data-v="10" data-xref="利未記 1:4; 使徒行傳 6:6; 提摩太前書 4:14"> 帶到耶和華面前，會眾要把手按在他們身上。</span>
<span className="v" id="v11" data-v="11" data-xref="利未記 7:30; 利未記 8:29; 民數記 1:49–53"> 亞倫要把他們獻給耶和華，作為以色列人獻的搖祭，使他們可以事奉耶和華。</span>
<span className="v" id="v12" data-v="12" data-xref="希伯來書 10:4–10; 出埃及記 29:10; 利未記 1:4"> 利未人要把手按在那兩頭公牛的頭上，然後你要把一頭作為贖罪祭，一頭作為燔祭獻給耶和華，好為利未人贖罪。</span>
<span className="v" id="v13" data-v="13" data-xref="民數記 8:21; 民數記 8:11; 羅馬書 15:16"> 你要讓利未人站在亞倫父子們面前，把他們當作搖祭獻給耶和華。</span>
<span className="v" id="v14" data-v="14" data-xref="民數記 3:45; 瑪拉基書 3:17; 民數記 18:6"> 這樣，你就把利未人從其他以色列人中分別出來，使他們歸給我。</span>
<span className="v" id="v15" data-v="15" data-xref="民數記 8:11; 民數記 8:13; 民數記 3:23–37"> 利未人被潔淨、當作搖祭獻上以後，就可以進會幕司職，</span>
<span className="v" id="v16" data-v="16" data-xref="民數記 3:12; 民數記 3:45; 民數記 3:9"> 因為在以色列人中，他們完全屬於我，我揀選他們歸我所有，以代替以色列人所有的長子。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及記 13:2; 路加福音 2:23; 出埃及記 13:12–15"> 以色列人所有的長子和頭生的牲畜都屬於我。我擊殺埃及人所有的長子和頭生的牲畜那天，已把以色列人所有的長子和頭生的牲畜都分別出來，使之聖潔，歸給我。</span>
<span className="v" id="v18" data-v="18"> 我現在已揀選利未人代替以色列人所有的長子。</span>
<span className="v" id="v19" data-v="19" data-xref="民數記 1:53; 民數記 16:46; 歷代志下 26:16–20"> 我從以色列人中把利未人作為禮物交給亞倫父子們，替以色列人在會幕中司職，為以色列人贖罪，免得以色列人因接近聖所而遭禍。」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20"> 摩西、亞倫和以色列全體會眾，就按照耶和華對摩西的吩咐把利未人獻上。</span>
<span className="v" id="v21" data-v="21" data-xref="民數記 8:7; 民數記 19:19; 民數記 8:15"> 利未人自潔、洗淨衣服後，亞倫把他們當作搖祭獻給耶和華，又為他們贖罪，使他們潔淨。</span>
<span className="v" id="v22" data-v="22" data-xref="歷代志下 31:2; 歷代志下 35:8–15; 民數記 8:15"> 之後，利未人便進入會幕，在亞倫父子們的監督下司職。以色列人照耶和華對摩西的吩咐奉獻了利未人。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23"> 耶和華對摩西說：</span>
<span className="v" id="v24" data-v="24" data-xref="民數記 4:3; 歷代志上 23:3; 民數記 4:23"> 「二十五歲以上的利未人都要到會幕司職，</span>
<span className="v" id="v25" data-v="25" data-xref="民數記 4:23; 提摩太後書 4:7"> 五十歲時退休，不再司職。</span>
<span className="v" id="v26" data-v="26" data-xref="民數記 1:53; 民數記 3:32; 提摩太前書 4:15"> 退休之後，他們可以協助本族弟兄看守會幕，不用再司職。你要這樣給他們分派工作。」</span>
</div>
</div>

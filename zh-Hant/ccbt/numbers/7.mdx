## 各首領的奉獻

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="利未記 8:10–11; 民數記 7:84; 馬太福音 23:19"> 摩西支好聖幕後，便用膏油抹聖幕和其中的所有器具、祭壇和壇上的所有器具，使它們聖潔。</span>
<span className="v" id="v2" data-v="2" data-xref="民數記 1:4–16; 民數記 10:1–36; 民數記 2:1–34"> 然後，以色列各支派的首領，就是負責統計人口的各族長，都來奉獻。</span>
<span className="v" id="v3" data-v="3"> 他們把供物帶到聖幕前獻給耶和華：每兩位首領奉獻一輛篷車，每位首領奉獻一頭公牛，共六輛篷車和十二頭公牛。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4"> 耶和華對摩西說：</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 25:1–11; 以賽亞書 42:1–7; 提多書 3:8"> 「你要收下他們的這些供物，按利未人的工作分配給他們，好用在會幕的工作中。」</span>
<span className="v" id="v6" data-v="6"> 於是，摩西收下車和牛，交給利未人。</span>
<span className="v" id="v7" data-v="7" data-xref="民數記 4:24–28; 民數記 3:25–26"> 他按照革順子孫的工作需要，分給他們兩輛車和四頭牛，</span>
<span className="v" id="v8" data-v="8" data-xref="民數記 4:28–33; 民數記 3:36–37"> 按照米拉利子孫的工作需要，分給他們四輛車和八頭牛。他們都在祭司亞倫的兒子以他瑪的領導下任職。</span>
<span className="v" id="v9" data-v="9" data-xref="民數記 3:31; 歷代志上 15:13; 民數記 4:4–16"> 摩西沒有把供物分給哥轄的子孫，因為他們要用肩扛所負責的聖物。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="歷代志下 7:9; 尼希米記 12:27; 申命記 20:5"> 膏抹祭壇時，各首領都為獻壇之禮帶來供物，獻在祭壇前。</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多前書 14:40; 哥林多前書 14:33; 歌羅西書 2:5"> 耶和華對摩西說：「每天要有一位首領為獻壇之禮獻上供物。」</span>
</div>

<span className="v" id="v12" data-v="12" data-xref="路加福音 3:32; 民數記 2:3; 馬太福音 1:4"> 第一天來獻供物的是猶大支派亞米拿達的兒子拿順。</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及記 30:13; 出埃及記 37:16; 利未記 2:1"> 他的供物是一個重一公斤半的銀盤，一個重八百克的銀碗，重量都以聖所的秤為準，都盛滿作素祭的調了油的細麵粉；</span>

<span className="v" id="v15" data-v="15" data-xref="彼得前書 1:18–19; 以賽亞書 53:4; 民數記 25:1–18"> 作燔祭的一頭公牛犢、一隻公綿羊和一隻一歲的公羊羔；</span>
<span className="v" id="v16" data-v="16" data-xref="利未記 4:23; 利未記 4:25"> 一隻作贖罪祭的公山羊；</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多後書 5:19–21; 利未記 3:1–17"> 作平安祭的兩頭公牛、五隻公綿羊、五隻公山羊和五隻一歲的公羊羔。這是亞米拿達的兒子拿順的供物。</span>

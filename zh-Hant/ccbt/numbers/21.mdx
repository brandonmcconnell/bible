## 擊敗迦南人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士師記 1:16; 民數記 33:40; 約書亞記 12:14"> 住在南地的迦南人亞拉得王聽說以色列人取道亞他林而來，就攻打他們，俘虜了一些人。</span>
<span className="v" id="v2" data-v="2" data-xref="士師記 11:30; 創世記 28:20; 撒母耳記上 1:11"> 以色列人向耶和華許願說：「要是你將這些人交在我們手中，我們必徹底摧毀<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「摧毀」希伯來文有「銷毀，以示奉獻給耶和華」之意。">a</a></sup>他們的城邑。」</span>
<span className="v" id="v3" data-v="3" data-xref="民數記 14:45; 申命記 1:44; 詩篇 10:17"> 耶和華答應了他們的祈求，把迦南人交在他們手中，使他們徹底毀滅了迦南人及其城邑。從此，那地方叫何珥瑪<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="「何珥瑪」意思是「毀滅」。">b</a></sup>。</span>
</div>
</div>

## 銅蛇

<div className="bt">
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="出埃及記 6:9; 士師記 11:18; 民數記 32:7"> 以色列人為了繞過以東，便從何珥山出發，沿通往紅海的路行進。途中，民眾心裡煩躁，</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 78:19; 民數記 16:13–14; 出埃及記 17:2–3"> 埋怨上帝和摩西說：「你們為什麼帶我們出埃及，叫我們死在曠野呢？這裡無糧無水，我們厭惡這難吃的東西！」</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多前書 10:9; 耶利米書 8:17; 申命記 8:15"> 於是，耶和華派毒蛇進入以色列人中，咬死了許多人。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行傳 8:24; 民數記 11:2; 詩篇 78:34"> 他們來找摩西，說：「我們埋怨耶和華和你，犯了罪，求你向耶和華禱告，好叫蛇離開我們。」摩西就為他們禱告。</span>
<span className="v" id="v8" data-v="8" data-xref="約翰福音 3:14; 詩篇 106:43–45; 詩篇 145:8"> 耶和華對摩西說：「你去造一條毒蛇掛在桿子上，凡被咬的一望這蛇，就可活命。」</span>
<span className="v" id="v9" data-v="9" data-xref="約翰福音 3:14–15; 希伯來書 12:2; 約翰福音 6:40"> 摩西就造了一條銅蛇，掛在桿子上。被蛇咬的人一望銅蛇，就保住了性命。</span>
</div>
</div>

## 前往摩押

<div className="bt">
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="民數記 33:43–45"> 以色列人繼續前行，在阿伯安營；</span>
<span className="v" id="v11" data-v="11"> 又從阿伯動身，走到摩押東邊的曠野，在以耶·亞巴琳安營；</span>
<span className="v" id="v12" data-v="12" data-xref="申命記 2:13–14"> 又從那裡前行，走到撒烈谷安營；</span>
<span className="v" id="v13" data-v="13" data-xref="士師記 11:18; 民數記 22:36; 以賽亞書 16:2"> 又從那裡出發，走到亞嫩河北岸的曠野安營。那裡毗鄰亞摩利人的邊境，亞嫩河是摩押和亞摩利人之間的疆界。</span>
<span className="v" id="v14" data-v="14" data-xref="約書亞記 10:13; 撒母耳記下 1:18"> 因此，《耶和華的戰記》上說：「蘇法的哇哈伯，亞嫩河谷，</span>
<span className="v" id="v15" data-v="15" data-xref="民數記 21:28; 申命記 2:18; 申命記 2:9"> 以及靠近摩押邊界並延伸到亞珥城的河谷的斜坡。」</span>
<span className="v" id="v16" data-v="16" data-xref="民數記 20:8; 以賽亞書 12:3; 以賽亞書 41:17–18"> 以色列人又往前走，來到比珥<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="「比珥」意思是「井」。">c</a></sup>。耶和華曾在那裡對摩西說：「把民眾招聚起來，我要給他們水喝。」</span>
<span className="v" id="v17" data-v="17" data-xref="雅各書 5:13; 出埃及記 15:1–2; 詩篇 106:12"> 當時，以色列人唱了這首歌：<br /><span className="pl pl-1">「井啊，湧出水來！</span><br /><span className="pl pl-1">你們要歌唱這口井，</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="以賽亞書 33:22; 提摩太前書 6:17–18; 雅各書 4:12"> <span className="pl pl-1">它是首領挖的，</span><br /><span className="pl pl-1">是民中的貴族掘的，</span><br /><span className="pl pl-1">用令牌和權杖挖掘的。」</span>他們從曠野前往瑪他拿，</span>
<span className="v" id="v19" data-v="19"> 從瑪他拿前往拿哈列，從拿哈列前往巴末，</span>
<span className="v" id="v20" data-v="20" data-xref="民數記 23:28; 民數記 23:14; 申命記 1:5"> 從巴末前往摩押的谷地，從那裡的毗斯迦山頂可以俯視曠野。</span>
</div>
</div>

## 擊敗亞摩利王和巴珊王

<div className="bt">
<div className="bp poetry">
<span className="v" id="v21" data-v="21" data-xref="申命記 2:26–28; 民數記 20:14–19; 士師記 11:19–21"> 以色列人派使者去見亞摩利王西宏，說：</span>
<span className="v" id="v22" data-v="22" data-xref="民數記 20:17"> 「請允許我們從貴國經過，我們只走王的大路，不會踏入田地和葡萄園，也不會喝井裡的水，直到走出貴國的土地。」</span>
<span className="v" id="v23" data-v="23" data-xref="士師記 11:20; 申命記 29:7–8; 以賽亞書 15:4"> 但西宏不讓以色列人經過他的領土，還招聚軍隊到曠野攻擊他們。他們來到雅雜與以色列人交戰。</span>
<span className="v" id="v24" data-v="24" data-xref="阿摩司書 2:9; 約書亞記 24:8; 創世記 32:22"> 以色列人用刀殺了西宏，佔領了他的土地——從亞嫩河到雅博河，遠至防守嚴密的亞捫人邊界。</span>
<span className="v" id="v25" data-v="25" data-xref="民數記 32:33–42; 以賽亞書 16:8–9; 耶利米書 48:2"> 以色列人攻佔了亞摩利人的所有城邑，包括希實本及其周圍的村莊，住在其中。</span>
<span className="v" id="v26" data-v="26"> 希實本是亞摩利王西宏的都城。西宏曾與摩押的先王交戰，佔領了他所有的領土，遠至亞嫩河。</span>
<span className="v" id="v27" data-v="27" data-xref="以賽亞書 14:4; 民數記 21:14; 哈巴谷書 2:6"> 因此有人作詩說：<br /><span className="pl pl-1">「來希實本吧！</span><br /><span className="pl pl-1">願西宏的城被修建起來。</span><br /></span>
<span className="v" id="v28" data-v="28" data-xref="民數記 21:15; 耶利米書 48:45–46; 以賽亞書 15:1–2"> <span className="pl pl-1">希實本烈焰熊熊，</span><br /><span className="pl pl-1">西宏的城火光沖天，</span><br /><span className="pl pl-1">燒毀摩押的亞珥，</span><br /><span className="pl pl-1">吞噬亞嫩河的高崗。</span><br /></span>
<span className="v" id="v29" data-v="29" data-xref="士師記 11:24; 列王紀下 23:13; 耶利米書 48:46"> <span className="pl pl-1">摩押啊，你大禍臨頭了！</span><br /><span className="pl pl-1">拜基抹神明的人啊，</span><br /><span className="pl pl-1">你們要滅亡了！</span><br /><span className="pl pl-1">基抹任由自己的兒子逃亡、</span><br /><span className="pl pl-1">女兒被亞摩利王西宏擄走。</span><br /></span>
<span className="v" id="v30" data-v="30" data-xref="耶利米書 48:18; 以賽亞書 15:2; 耶利米書 48:22"> <span className="pl pl-1">但我們擊潰了亞摩利人，</span><br /><span className="pl pl-1">從希實本一直到底本都被摧毀，</span><br /><span className="pl pl-1">從挪法到米底巴都淪為廢墟。」</span></span>
<span className="v" id="v31" data-v="31" data-xref="約書亞記 13:8–12; 民數記 32:33–42; 申命記 3:16–17"> 於是，以色列人住在亞摩利境內。</span>
<span className="v" id="v32" data-v="32" data-xref="耶利米書 48:32; 民數記 32:1; 民數記 32:35"> 摩西派人去雅謝打探，然後出兵攻佔了雅謝及其周圍的村莊，趕走那裡的亞摩利人。</span>
<span className="v" id="v33" data-v="33" data-xref="約書亞記 13:12; 申命記 1:4; 申命記 29:7"> 以色列人回師前往巴珊，巴珊王噩率全軍出動，在以得來迎戰以色列人。</span>
<span className="v" id="v34" data-v="34" data-xref="詩篇 135:10–11; 約書亞記 8:7; 申命記 3:2–3"> 耶和華對摩西說：「不要怕他，因為我已把他及其眾民和土地交在你手中。你要像從前對付希實本的亞摩利王西宏一樣對付他。」</span>
<span className="v" id="v35" data-v="35" data-xref="申命記 29:7–8; 約書亞記 13:12; 申命記 3:3–17"> 於是，以色列人殺了噩及其兒子和人民，一個不留，並奪取了他的國土。</span>
</div>
</div>

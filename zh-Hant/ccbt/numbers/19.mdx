## 紅母牛的灰

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華對摩西和亞倫說：</span>
<span className="v" id="v2" data-v="2" data-xref="利未記 22:20–25; 申命記 21:3; 撒母耳記上 6:7"> 「要吩咐以色列人遵行我頒佈的以下律法條例。 「以色列人要牽來一頭毫無殘疾、從未負過軛的紅母牛。</span>
<span className="v" id="v3" data-v="3" data-xref="利未記 4:12; 利未記 4:21; 利未記 16:27"> 你們要把牛交給以利亞撒祭司，然後牽到營外，當著他的面把牛宰了。</span>
<span className="v" id="v4" data-v="4" data-xref="利未記 4:17; 利未記 4:6; 利未記 16:14"> 以利亞撒祭司要用指頭蘸牛血，向會幕前面彈七次。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 29:14; 利未記 4:11–12; 詩篇 22:14"> 然後，要當著他的面焚燒紅母牛，牛的皮、肉、血和糞都要燒掉。</span>
<span className="v" id="v6" data-v="6" data-xref="利未記 14:4; 利未記 14:49; 詩篇 51:7"> 祭司要把香柏木、牛膝草、朱紅色線扔進燒牛的火裡。</span>
<span className="v" id="v7" data-v="7" data-xref="利未記 11:25; 利未記 11:40; 民數記 19:8"> 之後，祭司要洗衣沐浴，才能回營，但要等到傍晚才能潔淨。</span>
<span className="v" id="v8" data-v="8"> 負責燒牛的人也要洗衣、沐浴，並且要等到傍晚才能潔淨。</span>
<span className="v" id="v9" data-v="9" data-xref="希伯來書 9:13; 民數記 19:13; 民數記 19:20–21"> 要由一個潔淨的人把紅母牛灰收起來，放在營外潔淨的地方，留給以色列會眾作除穢水，作除罪之用。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及記 12:49; 民數記 19:7–8; 歌羅西書 3:11"> 收起母牛灰的人也要洗淨衣服，等到傍晚才能潔淨。這是以色列人和在他們中間寄居的外族人永遠當守的律例。</span>
<span className="v" id="v11" data-v="11" data-xref="民數記 5:2; 民數記 31:19; 利未記 21:1"> 「碰過屍體的人，七天不潔淨。</span>
<span className="v" id="v12" data-v="12" data-xref="民數記 31:19; 啟示錄 7:14; 利未記 7:17"> 他要在第三天和第七天用除穢水自潔，才能潔淨，否則就不能潔淨。</span>
<span className="v" id="v13" data-v="13" data-xref="利未記 15:31; 利未記 22:3; 利未記 7:20"> 若有人碰過屍體卻不自潔，他就玷污了耶和華的聖幕，要將他從以色列人中剷除，因為除穢水沒有灑在他身上，他不潔淨，污穢還留在他身上。</span>
<span className="v" id="v14" data-v="14"> 若有人死在帳篷裡，就要遵守這樣的條例：當時走進帳篷的或在場的人都七天不潔淨。</span>
<span className="v" id="v15" data-v="15" data-xref="利未記 14:36; 利未記 11:32; 民數記 31:20"> 帳篷裡沒有蓋的敞口器皿都不潔淨。</span>
<span className="v" id="v16" data-v="16" data-xref="民數記 31:19; 馬太福音 23:27; 路加福音 11:44"> 人若在野外碰過被殺或自然死亡之人的屍體，或碰過死人的骸骨或墳墓，就七天不潔淨。</span>
<span className="v" id="v17" data-v="17" data-xref="約翰福音 7:38; 創世記 26:19; 啟示錄 7:17"> 要為不潔淨的人拿些除罪用的紅母牛灰，放在器皿裡，倒上清水，</span>
<span className="v" id="v18" data-v="18" data-xref="以西結書 36:25–27; 希伯來書 9:14; 民數記 19:9"> 然後由一個潔淨的人拿牛膝草蘸這水灑在帳篷及裡面所有人和器具上，也要灑在碰過骸骨、墳墓、被殺者屍體，或自然死亡者屍體的人身上。</span>
<span className="v" id="v19" data-v="19" data-xref="約翰一書 1:7; 希伯來書 10:22; 以西結書 36:25"> 要由潔淨的人在第三天和第七天把水灑在不潔淨的人身上，並在第七天潔淨他們。接受潔淨禮的人要洗衣、沐浴，等到傍晚才能潔淨。</span>
<span className="v" id="v20" data-v="20" data-xref="馬可福音 16:16; 創世記 17:14; 民數記 19:13"> 若有人沾了污穢卻沒有用除穢水自潔，他就不潔淨，要將他從會眾中剷除，因為他玷污了耶和華的聖所。</span>
<span className="v" id="v21" data-v="21" data-xref="希伯來書 9:13–14; 希伯來書 10:4; 希伯來書 9:10"> 這是你們永遠當守的律例。灑除穢水的人要洗淨衣服。碰過除穢水的人要等到傍晚才能潔淨。</span>
<span className="v" id="v22" data-v="22" data-xref="哈該書 2:13; 利未記 7:19; 馬太福音 15:19–20"> 不潔淨的人碰過的東西都不潔淨，碰過這些東西的人傍晚之前都不潔淨。」</span>

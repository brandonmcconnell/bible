## 可拉之亂

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="猶大書 1:11; 申命記 11:6; 出埃及記 6:21"> 可拉是利未的曾孫、哥轄的孫子、以斯哈的兒子。他跟呂便支派以利押的兩個兒子大坍和亞比蘭，以及比勒的兒子安，</span>
<span className="v" id="v2" data-v="2" data-xref="民數記 26:9; 以西結書 23:10; 創世記 6:4"> 聯合二百五十名在以色列會眾中有聲望的首領反叛摩西，</span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 106:16; 民數記 14:14; 出埃及記 19:6"> 一起攻擊摩西和亞倫，說：「你們太過分了！全體會眾都是聖潔的，有耶和華住在他們當中，你們憑什麼將自己置於耶和華的會眾之上？」</span>
<span className="v" id="v4" data-v="4" data-xref="民數記 14:5; 民數記 20:6; 約書亞記 7:6"> 摩西聽了這話，就俯伏在地，</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 65:4; 民數記 17:5; 提摩太後書 2:19"> 對可拉一夥人說：「到了明天早上，耶和華必顯明誰是屬於祂的，誰是聖潔的。祂必讓祂所揀選的人到祂面前。</span>
<span className="v" id="v6" data-v="6" data-xref="利未記 10:1; 民數記 16:46–48; 列王紀上 18:21–23"> 可拉啊，你們要這樣做，你和你的同夥明天帶香爐來，</span>
<span className="v" id="v7" data-v="7" data-xref="民數記 16:3; 以弗所書 1:4; 列王紀上 18:17–18"> 在耶和華面前點火添香。耶和華揀選誰，誰就是聖潔的。你們利未人太過分了！」</span>
<span className="v" id="v8" data-v="8"> 摩西又對可拉說：「利未人啊，你們聽我說！</span>
<span className="v" id="v9" data-v="9" data-xref="以賽亞書 7:13; 申命記 10:8; 以西結書 44:10–11"> 以色列的上帝把你們從以色列會眾中分別出來，使你們可以到祂面前，在祂的聖幕裡司職，替會眾辦事，你們還不滿足嗎？</span>
<span className="v" id="v10" data-v="10" data-xref="箴言 13:10; 約翰三書 1:9; 民數記 18:7"> 可拉啊，耶和華使你和其他利未人事奉祂，你們還要貪求祭司的職分嗎？</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及記 16:7–8; 出埃及記 17:2; 民數記 16:3"> 其實你和你的同夥合謀反叛的是耶和華。亞倫是何人，你們竟埋怨他？」</span>
<span className="v" id="v12" data-v="12" data-xref="彼得前書 2:13–14; 猶大書 1:8; 箴言 29:9"> 摩西派人去召以利押的兒子大坍和亞比蘭，他們卻說：「我們不去！</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行傳 7:35; 出埃及記 2:14; 民數記 11:5"> 你帶我們離開奶蜜之鄉，要讓我們死在曠野，這還不夠嗎？你還想自立為王管轄我們嗎？</span>
<span className="v" id="v14" data-v="14" data-xref="利未記 20:24; 民數記 36:8–10; 民數記 20:5"> 你並沒有領我們到奶蜜之鄉，也沒有給我們田地和葡萄園作產業，你還想繼續矇騙我們嗎？我們不去！」</span>
<span className="v" id="v15" data-v="15" data-xref="創世記 4:4–5; 哥林多後書 7:2; 帖撒羅尼迦前書 2:10"> 摩西非常憤怒，就對耶和華說：「求你不要接納他們的祭物。我沒有取過他們一頭驢，也沒有害過他們任何人。」</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳記上 12:3; 撒母耳記上 12:7; 提摩太後書 2:14"> 摩西對可拉說：「明天你和你的同夥要跟亞倫一起站在耶和華面前。</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳記上 12:7"> 每人要拿自己的香爐，放上香，帶到耶和華面前，共二百五十個。你和亞倫也要各拿自己的香爐。」</span>
<span className="v" id="v18" data-v="18"> 於是，他們都拿著香爐，盛著火和香，跟摩西和亞倫一起站在會幕門口。</span>
<span className="v" id="v19" data-v="19" data-xref="民數記 14:10; 民數記 16:42; 出埃及記 16:7"> 可拉把全體會眾招聚到會幕門口，要對付摩西和亞倫。這時，耶和華的榮光向全體會眾顯現。</span>
<span className="v" id="v20" data-v="20"> 耶和華對摩西和亞倫說：</span>
<span className="v" id="v21" data-v="21" data-xref="民數記 16:45; 出埃及記 32:10; 詩篇 73:19"> 「你們離開這些會眾，我好在頃刻之間消滅他們。」</span>
<span className="v" id="v22" data-v="22" data-xref="民數記 27:16; 撒迦利亞書 12:1; 約伯記 12:10"> 摩西和亞倫就伏在地上說：「上帝啊，賜人生命氣息的上帝啊！一人犯罪，你就要向全體會眾發怒嗎？」</span>
<span className="v" id="v23" data-v="23"> 耶和華對摩西說：</span>
<span className="v" id="v24" data-v="24" data-xref="民數記 16:21"> 「你叫會眾離可拉、大坍和亞比蘭的帳篷遠一點。」</span>
<span className="v" id="v25" data-v="25" data-xref="民數記 11:16–17; 民數記 11:25; 民數記 11:30"> 於是，摩西起來去大坍和亞比蘭那裡，以色列的長老也跟著他。</span>
<span className="v" id="v26" data-v="26" data-xref="以賽亞書 52:11; 哥林多後書 6:17; 啟示錄 18:4"> 他對會眾說：「你們離這些惡人的帳篷遠一點，不要碰他們的任何東西，免得你們因他們的罪而受牽連，同遭毀滅。」</span>
<span className="v" id="v27" data-v="27" data-xref="約伯記 9:4; 以賽亞書 28:14; 約伯記 40:10–11"> 會眾便離開可拉、大坍和亞比蘭的帳篷。大坍和亞比蘭帶著妻小出來，站在自己的帳篷門口。</span>
<span className="v" id="v28" data-v="28" data-xref="約翰福音 6:38; 出埃及記 3:12; 約翰福音 14:11"> 摩西對會眾說：「你們很快就知道，我所做的事都是奉耶和華之命而行，並非出於私意。</span>
<span className="v" id="v29" data-v="29" data-xref="耶利米哀歌 4:22; 列王紀上 22:28; 出埃及記 32:34"> 如果這些人像常人一樣死去，遭遇跟世人無異，我就不是耶和華派來的。</span>
<span className="v" id="v30" data-v="30" data-xref="詩篇 55:15; 民數記 16:33; 約伯記 31:3"> 但如果耶和華做一件前所未有的事，使地裂開，吞下他們和屬於他們的一切，使他們活生生地墜入陰間，你們就知道這些人藐視耶和華了。」</span>
<span className="v" id="v31" data-v="31" data-xref="詩篇 106:17–18; 民數記 27:3; 申命記 11:6"> 摩西的話剛說完，這些人腳下的地就裂開，</span>
<span className="v" id="v32" data-v="32" data-xref="詩篇 106:17; 民數記 26:11; 啟示錄 12:16"> 吞下了他們和他們的家眷，以及所有可拉一夥的人和財物。</span>
<span className="v" id="v33" data-v="33" data-xref="以西結書 32:18; 以賽亞書 14:9; 詩篇 9:15"> 他們和屬於他們的一切，就這樣活活地墜入陰間，地在他們上面合攏起來，他們就從會眾中滅亡了。</span>
<span className="v" id="v34" data-v="34" data-xref="撒迦利亞書 14:5; 以賽亞書 33:3; 啟示錄 6:15–17"> 他們四圍的以色列人聽到他們的喊叫聲，紛紛逃跑，生怕自己也被地吞下去。</span>
<span className="v" id="v35" data-v="35" data-xref="民數記 26:10; 利未記 10:2; 詩篇 106:18"> 耶和華又降下烈火，燒死了那二百五十個獻香的人。</span>
<span className="v" id="v36" data-v="36"> 耶和華對摩西說：</span>
<span className="v" id="v37" data-v="37" data-xref="利未記 27:28; 民數記 16:18; 民數記 16:7"> 「你叫亞倫祭司的兒子以利亞撒，去從火中把香爐撿起來，把炭火撒在遠處，因為那些香爐是聖潔的。</span>
<span className="v" id="v38" data-v="38" data-xref="民數記 26:10; 以西結書 14:8; 彼得後書 2:6"> 要把那些因犯罪而喪命之人的香爐打成薄片，用來包祭壇，因為那些香爐曾被獻在耶和華面前，是聖潔的，並且可讓以色列人引以為戒。」</span>
<span className="v" id="v39" data-v="39"> 於是，以利亞撒祭司取來被燒死之人所獻的銅香爐，叫人打成薄片用來包祭壇，</span>
<span className="v" id="v40" data-v="40" data-xref="民數記 3:10; 民數記 18:4–7; 歷代志下 26:16–21"> 讓以色列人引以為戒，使亞倫子孫以外的人不致到耶和華面前燒香，以免像可拉及其同夥一樣滅亡。這是按照耶和華藉摩西的吩咐做的。</span>
<span className="v" id="v41" data-v="41" data-xref="民數記 16:1–7; 詩篇 106:23; 民數記 14:2"> 第二天，以色列全體會眾都埋怨摩西和亞倫說：「你們害死了耶和華的子民。」</span>
<span className="v" id="v42" data-v="42" data-xref="民數記 16:19; 利未記 9:23; 民數記 20:6"> 會眾聚集起來反對摩西和亞倫，他們向會幕觀看，忽然有雲彩遮蓋了會幕，耶和華的榮光顯現。</span>
<span className="v" id="v43" data-v="43"> 摩西和亞倫來到會幕前，</span>
<span className="v" id="v44" data-v="44"> 耶和華對摩西說：</span>
<span className="v" id="v45" data-v="45" data-xref="民數記 16:21–22; 民數記 16:24; 民數記 20:6"> 「你們離開這些會眾，我好在頃刻之間消滅他們。」他們二人就俯伏在地。</span>
<span className="v" id="v46" data-v="46" data-xref="民數記 8:19; 歷代志上 27:24; 利未記 10:6"> 摩西對亞倫說：「取香爐來，裡面放些祭壇上的火，添上香，趕快帶到會眾那裡為他們贖罪，因為耶和華發怒了，瘟疫已經開始。」</span>
<span className="v" id="v47" data-v="47" data-xref="馬太福音 5:44; 申命記 33:10–11; 詩篇 106:29"> 亞倫就照著摩西的吩咐取來香爐，跑到會眾當中。那時瘟疫已經在人群中蔓延起來。他就在爐中放上香為民眾贖罪。</span>
<span className="v" id="v48" data-v="48" data-xref="撒母耳記下 24:25; 希伯來書 7:24–25; 民數記 16:18"> 他站在活人和死人之間，瘟疫就止住了。</span>
<span className="v" id="v49" data-v="49" data-xref="民數記 25:9; 民數記 16:32–35; 希伯來書 2:1–3"> 除了在可拉事件中死亡的人以外，有一萬四千七百人死於瘟疫。</span>
<span className="v" id="v50" data-v="50" data-xref="歷代志上 21:26–30; 民數記 16:43"> 瘟疫止住後，亞倫便回到在會幕門口的摩西那裡。</span>

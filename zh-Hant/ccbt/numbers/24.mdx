## 巴蘭第三次預言

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="民數記 23:3; 民數記 23:23; 民數記 23:28"> 巴蘭見耶和華樂意賜福給以色列人，就不再像先前兩次那樣去求兆頭，而是轉向曠野。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳記上 19:20; 歷代志下 15:1; 撒母耳記上 19:23"> 他舉目眺望，看見以色列人按支派紮營。上帝的靈降在他身上，</span>
<span className="v" id="v3" data-v="3" data-xref="民數記 22:31; 民數記 24:16; 民數記 23:7"> 他便吟詩預言說：<br /><span className="pl pl-1">「比珥之子巴蘭的預言，</span><br /><span className="pl pl-1">是眼睛明亮者的話，</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="啟示錄 1:17; 啟示錄 1:10; 民數記 12:6"> <span className="pl pl-1">他得聽上帝之言，</span><br /><span className="pl pl-1">俯伏在地，眼目睜開</span><br /><span className="pl pl-1">得見全能者的異象。</span><br /></span>
<span className="v" id="v5" data-v="5"> <span className="pl pl-1">雅各啊，</span><br /><span className="pl pl-1">你的帳篷何等華美！</span><br /><span className="pl pl-1">以色列啊，</span><br /><span className="pl pl-1">你的居所何等佳美！</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 1:3; 以賽亞書 58:11; 詩篇 104:16"> <span className="pl pl-1">像連綿的山谷，</span><br /><span className="pl pl-1">如河畔的園子；</span><br /><span className="pl pl-1">像耶和華栽種的沉香，</span><br /><span className="pl pl-1">如水邊的香柏樹。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳記下 5:12; 歷代志上 14:2; 啟示錄 17:1"> <span className="pl pl-1">他們沐浴充沛的甘霖，</span><br /><span className="pl pl-1">撒種於濕潤的沃土。</span><br /><span className="pl pl-1">他們的君王高過亞甲，</span><br /><span className="pl pl-1">國度名震四方。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 45:5; 詩篇 2:9; 民數記 14:9"> <span className="pl pl-1">上帝帶他們出埃及，</span><br /><span className="pl pl-1">祂</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「祂」或譯「他們」。">a</a></sup><br /><span className="pl pl-1">的力量如野牛之角。</span><br /><span className="pl pl-1">他們要吞滅敵國，</span><br /><span className="pl pl-1">打碎敵人的骨頭，</span><br /><span className="pl pl-1">用利箭射穿仇敵。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="創世記 12:3; 創世記 27:29; 創世記 49:9"> <span className="pl pl-1">他們蹲伏如雄獅，</span><br /><span className="pl pl-1">躺臥如母獅，誰敢招惹？</span><br /><span className="pl pl-1">願祝福他們的人蒙祝福！</span><br /><span className="pl pl-1">願咒詛他們的人受咒詛！」</span></span>
<span className="v" id="v10" data-v="10" data-xref="民數記 23:11; 以西結書 21:14; 以西結書 21:17"> 巴勒聽了大怒，用力擊掌，對巴蘭說：「我請你來咒詛我的仇敵，你竟三次祝福他們。</span>
<span className="v" id="v11" data-v="11" data-xref="民數記 22:17; 民數記 22:37; 希伯來書 11:24–26"> 現在快回家去吧！我說過要給你重賞，但耶和華不讓你得到。」</span>
<span className="v" id="v12" data-v="12" data-xref="民數記 22:18; 民數記 22:38"> 巴蘭說：「我不是對你派來的使臣說過嗎？</span>
<span className="v" id="v13" data-v="13" data-xref="民數記 16:28; 民數記 22:18; 民數記 22:20"> 就是你把滿屋的金銀都給我，我也不能違背耶和華的命令、憑自己的意思行事——無論好事壞事。我只能說耶和華讓我說的話。</span>
<span className="v" id="v14" data-v="14" data-xref="彌迦書 6:5; 啟示錄 2:14; 創世記 49:1"> 現在我要回本族去了。但我要告訴你日後以色列人會怎樣對待你的人民。」</span>
</div>
</div>

## 巴蘭第四次預言

<div className="bt">
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="民數記 24:3–4; 民數記 23:7; 馬太福音 13:35"> 巴蘭吟詩預言說：<br /><span className="pl pl-1">「比珥之子巴蘭的預言，</span><br /><span className="pl pl-1">是眼睛明亮者的話，</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="民數記 24:4; 哥林多前書 8:1; 撒母耳記下 23:1–2"> <span className="pl pl-1">他得聽上帝之言，</span><br /><span className="pl pl-1">明白至高者的旨意，</span><br /><span className="pl pl-1">俯伏在地，眼目睜開，</span><br /><span className="pl pl-1">得見全能者的異象。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="啟示錄 22:16; 路加福音 1:32–33; 創世記 49:10"> <span className="pl pl-1">我所見的尚未發生，</span><br /><span className="pl pl-1">我目睹的關乎將來。</span><br /><span className="pl pl-1">一顆星要從雅各家升起，</span><br /><span className="pl pl-1">一位君王要從以色列興起。</span><br /><span className="pl pl-1">他要打爛摩押的前額，</span><br /><span className="pl pl-1">擊碎塞特人的頭顱。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="阿摩司書 9:12; 創世記 27:29; 撒母耳記下 8:14"> <span className="pl pl-1">他必征服以東，</span><br /><span className="pl pl-1">佔領敵疆西珥，</span><br /><span className="pl pl-1">以色列必勇往直前。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="創世記 49:10; 彌迦書 5:2; 詩篇 2:1–12"> <span className="pl pl-1">雅各的後裔必掌權，</span><br /><span className="pl pl-1">消滅城中的餘民。」</span></span>
</div>
</div>

## 巴蘭最後的預言

<div className="bt">
<div className="bp poetry">
<span className="v" id="v20" data-v="20" data-xref="出埃及記 17:14; 士師記 6:3; 歷代志上 4:43"> 巴蘭觀看亞瑪力人，並以詩歌預言說：<br /><span className="pl pl-1">「亞瑪力原是列國之首，</span><br /><span className="pl pl-1">但他的結局卻是滅亡。」</span></span>
<span className="v" id="v21" data-v="21" data-xref="創世記 15:19; 士師記 1:16; 約伯記 29:18"> 巴蘭又觀看基尼人，並以詩歌預言說：<br /><span className="pl pl-1">「雖然你的居所堅固，</span><br /><span className="pl pl-1">你的巢築在峭壁，</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="詩篇 83:8; 創世記 10:22; 以斯拉記 4:2"> <span className="pl pl-1">但你必遭滅頂，</span><br /><span className="pl pl-1">被亞述擄去。」</span></span>
<span className="v" id="v23" data-v="23" data-xref="民數記 23:23; 瑪拉基書 3:2; 列王紀下 5:1"> 巴蘭又以詩歌預言說：<br /><span className="pl pl-1">「唉！若上帝做這事，</span><br /><span className="pl pl-1">誰能存活呢？</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="創世記 10:4; 民數記 24:20; 但以理書 10:20"> <span className="pl pl-1">船隻從基提駛來，</span><br /><span className="pl pl-1">征服亞述和希伯，</span><br /><span className="pl pl-1">但他也要滅亡。」</span></span>
<span className="v" id="v25" data-v="25" data-xref="民數記 31:8; 約書亞記 13:22; 民數記 24:11"> 說完，巴蘭動身返回家鄉，巴勒也回去了。</span>
</div>

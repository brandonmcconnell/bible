## 銀號

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華對摩西說：</span>
<span className="v" id="v2" data-v="2" data-xref="以賽亞書 1:13; 約珥書 1:14; 詩篇 81:3"> 「你要用銀子打造兩支號，用來招聚會眾和發出拔營的號令。</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米書 4:5; 約珥書 2:15–16"> 吹響兩支號時，全體會眾要在會幕門口聚集到你面前。</span>
<span className="v" id="v4" data-v="4" data-xref="民數記 7:2; 出埃及記 18:21; 民數記 1:4–16"> 如果只吹響一支號，擔任首領的以色列各族長要聚集到你面前。</span>
<span className="v" id="v5" data-v="5" data-xref="民數記 2:3–9; 民數記 10:14; 以賽亞書 58:1"> 如果吹響拔營的號令，在東面紮營的就要啟行；</span>
<span className="v" id="v6" data-v="6" data-xref="民數記 10:18; 民數記 2:10–16"> 第二次吹響拔營號令時，在南面紮營的就要啟行。拔營號令是啟行的信號。</span>
<span className="v" id="v7" data-v="7" data-xref="約珥書 2:1; 民數記 10:3–4"> 但吹號招聚會眾時，不要用拔營號令。</span>
<span className="v" id="v8" data-v="8" data-xref="約書亞記 6:4–16; 民數記 31:6; 歷代志上 15:24"> 做祭司的亞倫子孫要負責吹號，這是你們世代當守的永久律例。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳記上 10:18; 士師記 2:18; 創世記 8:1"> 當你們在自己的土地上跟來犯之敵作戰時，要吹響兩支號，你們的上帝耶和華必眷顧你們，救你們脫離敵人。</span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 81:3; 帖撒羅尼迦前書 4:16; 哥林多前書 11:24–26"> 在節期和朔日<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「朔日」即每月初一。">a</a></sup>這些歡樂的日子獻燔祭和平安祭的時候，你們要吹號，好在你們的上帝面前蒙眷顧。我是你們的上帝耶和華。」</span>
</div>
</div>

## 離開西奈山

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="出埃及記 40:17; 民數記 1:1; 民數記 9:11"> 第二年的二月二十日，雲彩從安放約櫃的聖幕上升起，</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 21:21; 民數記 12:16; 民數記 9:5"> 以色列人就從西奈曠野啟行，直到雲彩停在巴蘭曠野時才停下來。</span>
<span className="v" id="v13" data-v="13" data-xref="申命記 1:6; 民數記 9:23"> 這是他們初次照耶和華藉摩西的吩咐啟行。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="民數記 2:3–9; 民數記 1:7; 民數記 7:12"> 猶大旗下的營隊率先出發，率領猶大支派的是亞米拿達的兒子拿順，</span>
<span className="v" id="v15" data-v="15" data-xref="民數記 7:18; 民數記 1:8"> 率領以薩迦支派的是蘇押的兒子拿坦業，</span>
<span className="v" id="v16" data-v="16" data-xref="民數記 7:24; 民數記 1:9"> 率領西布倫支派的是希倫的兒子以利押。</span>
<span className="v" id="v17" data-v="17" data-xref="民數記 7:6–8; 民數記 1:51; 希伯來書 12:28"> 然後，聖幕被拆卸，革順和米拉利的子孫抬著聖幕出發。</span>
<span className="v" id="v18" data-v="18" data-xref="民數記 2:10–16; 民數記 1:5; 民數記 26:5–18"> 隨後出發的是呂便旗下的營隊，率領呂便支派的是示丟珥的兒子以利蘇，</span>
<span className="v" id="v19" data-v="19" data-xref="民數記 1:6; 民數記 7:36"> 率領西緬支派的是蘇利沙代的兒子示路蔑，</span>
<span className="v" id="v20" data-v="20" data-xref="民數記 1:14; 民數記 2:14; 民數記 7:42"> 率領迦得支派的是丟珥的兒子以利雅薩。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="民數記 10:17; 民數記 7:9; 民數記 4:4–16"> 隨後出發的是哥轄人，他們抬著聖物前行。在他們到達之前，聖幕應已支好。</span>
<span className="v" id="v22" data-v="22" data-xref="民數記 2:18–24; 民數記 1:10; 民數記 26:23–41"> 隨後出發的是以法蓮旗下的營隊，率領以法蓮支派的是亞米忽的兒子以利沙瑪，</span>
<span className="v" id="v23" data-v="23" data-xref="民數記 1:10; 民數記 7:54"> 率領瑪拿西支派的是比大蘇的兒子迦瑪列，</span>
<span className="v" id="v24" data-v="24" data-xref="民數記 1:11; 民數記 7:60"> 率領便雅憫支派的是基多尼的兒子亞比但。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="約書亞記 6:9; 民數記 1:12; 創世記 49:16–17"> 殿後的是但旗下的營隊，率領但支派的是亞米沙代的兒子亞希以謝，</span>
<span className="v" id="v26" data-v="26" data-xref="民數記 1:13; 民數記 7:72"> 率領亞設支派的是俄蘭的兒子帕結，</span>
<span className="v" id="v27" data-v="27" data-xref="民數記 1:15; 民數記 7:78"> 率領拿弗他利支派的是以南的兒子亞希拉。</span>
<span className="v" id="v28" data-v="28" data-xref="民數記 2:34; 民數記 24:4–5; 哥林多前書 14:33"> 這是以色列各營隊拔營前行的次序。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="創世記 12:7; 士師記 4:11; 出埃及記 3:1"> 摩西對岳父米甸人流珥之子何巴說：「我們就要動身前往耶和華應許給我們的地方，祂曾說要把那地方賜給我們。請你跟我們一起去吧，我們必厚待你，耶和華已經應許要賜福給以色列人。」</span>
<span className="v" id="v30" data-v="30" data-xref="路得記 1:15–17; 詩篇 45:10; 馬太福音 21:29"> 何巴說：「我不去了，我要回到我的家鄉和親族那裡。」</span>
<span className="v" id="v31" data-v="31" data-xref="約伯記 29:15; 加拉太書 6:2; 哥林多前書 12:14–21"> 摩西說：「請不要離開我們。你熟悉曠野，可以做我們的嚮導，告訴我們在哪裡紮營。</span>
<span className="v" id="v32" data-v="32" data-xref="士師記 1:16; 申命記 10:18; 約翰一書 1:3"> 如果你跟我們同去，我們一定與你分享耶和華賜給我們的福氣。」</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="申命記 1:33; 出埃及記 3:1; 詩篇 95:11"> 以色列人離開耶和華的山，走了三天的路程，期間耶和華的約櫃一直在隊伍的前頭，為他們尋找安歇之地。</span>
<span className="v" id="v34" data-v="34" data-xref="尼希米記 9:12; 尼希米記 9:19; 詩篇 105:39"> 他們拔營前行的時候，白天總有耶和華的雲彩在他們上面。</span>
<span className="v" id="v35" data-v="35" data-xref="詩篇 68:1–2; 以賽亞書 17:12–14; 詩篇 132:8"> 每當約櫃出發的時候，摩西就說：「耶和華啊，求你興起，擊潰你的仇敵，使恨你的人從你面前逃竄。」</span>
<span className="v" id="v36" data-v="36" data-xref="申命記 1:10; 詩篇 90:13–17; 以賽亞書 63:17"> 約櫃停下來的時候，他就說：「耶和華啊，求你回到以色列的千萬人中。」</span>
</div>
</div>

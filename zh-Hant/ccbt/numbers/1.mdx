## 以色列的第一次人口統計

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及記 25:22; 出埃及記 19:1; 民數記 10:11–12"> 以色列人離開埃及後第二年的二月一日，耶和華在西奈曠野的會幕中對摩西說：</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 38:26; 出埃及記 30:12; 民數記 1:18"> 「你要按以色列人的宗族和家系統計全體會眾，登記所有男子的名字。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 30:14; 民數記 14:29; 民數記 33:1"> 你和亞倫要一隊一隊地統計以色列人中所有二十歲以上、有作戰能力的男子。</span>
<span className="v" id="v4" data-v="4" data-xref="民數記 1:16; 出埃及記 18:25; 民數記 13:2–15"> 每一支派要有一個人來協助你們。他們都是各宗族的族長，</span>
<span className="v" id="v5" data-v="5" data-xref="民數記 7:30; 創世記 30:5–20; 創世記 49:1–33"> 名單如下：<br />「呂便支派示丟珥的兒子以利蘇、</span>
<span className="v" id="v6" data-v="6" data-xref="民數記 7:36; 民數記 2:12"> 西緬支派蘇利沙代的兒子示路蔑、</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 3:32; 民數記 10:14; 馬太福音 1:2–5"> 猶大支派亞米拿達的兒子拿順、</span>
<span className="v" id="v8" data-v="8" data-xref="民數記 7:18; 民數記 10:15; 民數記 2:5"> 以薩迦支派蘇押的兒子拿坦業、</span>
<span className="v" id="v9" data-v="9" data-xref="民數記 7:24; 民數記 10:16; 民數記 2:7"> 西布倫支派希倫的兒子以利押、</span>
<span className="v" id="v10" data-v="10" data-xref="民數記 7:54; 民數記 7:48; 歷代志上 7:26–27"> 約瑟的後裔——以法蓮支派亞米忽的兒子以利沙瑪和瑪拿西支派比大蘇的兒子迦瑪列、</span>
<span className="v" id="v11" data-v="11" data-xref="民數記 7:60; 民數記 10:24; 民數記 2:22"> 便雅憫支派基多尼的兒子亞比但、</span>
<span className="v" id="v12" data-v="12" data-xref="民數記 7:66; 民數記 2:25; 民數記 10:25"> 但支派亞米沙代的兒子亞希以謝、</span>
<span className="v" id="v13" data-v="13" data-xref="民數記 7:72; 民數記 10:26; 民數記 2:27"> 亞設支派俄蘭的兒子帕結、</span>
<span className="v" id="v14" data-v="14" data-xref="民數記 2:14; 民數記 7:42; 民數記 10:20"> 迦得支派丟珥的兒子以利雅薩、</span>
<span className="v" id="v15" data-v="15" data-xref="民數記 7:78; 民數記 10:27; 民數記 2:29"> 拿弗他利支派以南的兒子亞希拉。」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="民數記 7:2; 出埃及記 18:21; 出埃及記 18:25"> 他們都是從會眾中選出來的，是各支派的首領，也是以色列的將領。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="約翰福音 10:3; 啟示錄 7:4–17; 民數記 1:5–15"> 摩西和亞倫帶著這些被點名的人，</span>
<span className="v" id="v18" data-v="18" data-xref="以斯拉記 2:59; 尼希米記 7:61; 希伯來書 7:3"> 在二月一日招聚全體會眾，按照宗族和家系統計人口，一一登記所有二十歲以上的男子。</span>
<span className="v" id="v19" data-v="19" data-xref="民數記 1:2; 民數記 26:1–2; 撒母耳記下 24:1–10"> 摩西照耶和華的吩咐在西奈曠野統計人口。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="民數記 26:5–7; 民數記 2:10–11; 創世記 46:9"> 以色列的長子呂便支派中，二十歲以上、有作戰能力的男子按宗族、家系和名字一一被登記下來，共有四萬六千五百人。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="民數記 26:12–14; 創世記 34:25–30; 民數記 2:12–13"> 西緬支派中，二十歲以上、有作戰能力的男子按宗族、家系和名字一一被登記下來，共有五萬九千三百人。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="民數記 26:15–18; 創世記 46:16; 民數記 2:14–15"> 迦得支派中，二十歲以上、有作戰能力的男子按宗族、家系和名字一一被登記下來，共有四萬五千六百五十人。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="創世記 29:35; 民數記 26:19–22; 撒母耳記下 24:9"> 猶大支派中，二十歲以上、有作戰能力的男子按宗族、家系和名字一一被登記下來，共有七萬四千六百人。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="創世記 46:13; 創世記 49:14–15; 創世記 30:18"> 以薩迦支派中，二十歲以上、有作戰能力的男子按宗族、家系和名字一一被登記下來，共有五萬四千四百人。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="民數記 26:26–27; 創世記 49:13; 創世記 30:20"> 西布倫支派中，二十歲以上、有作戰能力的男子按宗族、家系和名字一一被登記下來，共有五萬七千四百人。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="民數記 26:35–37; 申命記 33:17; 創世記 46:20"> 約瑟的後裔中，以法蓮支派中，二十歲以上、有作戰能力的男子按宗族、家系和名字一一被登記下來，共有四萬零五百人。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="民數記 26:28–34"> 瑪拿西支派中，二十歲以上、有作戰能力的男子按宗族、家系和名字一一被登記下來，共有三萬二千二百人。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="創世記 49:27; 創世記 44:20; 啟示錄 7:8"> 便雅憫支派中，二十歲以上、有作戰能力的男子按宗族、家系和名字一一被登記下來，共有三萬五千四百人。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="創世記 46:23; 創世記 30:5–6; 創世記 49:16–17"> 但支派中，二十歲以上、有作戰能力的男子按宗族、家系和名字一一被登記下來，共有六萬二千七百人。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="創世記 30:12–13; 創世記 46:27; 創世記 49:20"> 亞設支派中，二十歲以上、有作戰能力的男子按宗族、家系和名字一一被登記下來，共有四萬一千五百人。</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="創世記 49:21; 民數記 26:48–50; 創世記 46:24"> 拿弗他利支派中，二十歲以上、有作戰能力的男子按宗族、家系和名字一一被登記下來，共有五萬三千四百人。</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="民數記 26:64; 民數記 1:2–16"> 以上就是摩西、亞倫和各代表自己族系的十二位以色列首領所統計的男子人數。</span>
<span className="v" id="v45" data-v="45"> 這樣，以色列人中二十歲以上、有作戰能力的男子按宗族、家系和名字一一被登記下來，</span>
<span className="v" id="v46" data-v="46" data-xref="出埃及記 12:37; 民數記 26:51; 出埃及記 38:26"> 共有六十萬三千五百五十人。</span>
<span className="v" id="v47" data-v="47" data-xref="民數記 2:33; 民數記 3:1–49; 民數記 26:57–62"> 然而，利未人沒有按祖先的支派列在其中，</span>
<span className="v" id="v48" data-v="48"> 因為耶和華曾經對摩西說：</span>
<span className="v" id="v49" data-v="49" data-xref="民數記 26:62; 民數記 2:33"> 「你不可統計利未支派的人數，不可把他們的人數算在以色列人中。</span>
<span className="v" id="v50" data-v="50" data-xref="出埃及記 38:21; 出埃及記 31:18; 民數記 4:15"> 你要派利未人管理、搬運和照料放約櫃的聖幕及其所有器具和附屬物，他們要在聖幕四圍紮營。</span>
<span className="v" id="v51" data-v="51" data-xref="民數記 3:38; 民數記 3:10; 撒母耳記上 6:19"> 在遷移的時候，利未人要負責拆卸和支搭聖幕。外人若近前來，必被處死。</span>
<span className="v" id="v52" data-v="52" data-xref="民數記 2:2; 民數記 2:34; 民數記 10:1–36"> 以色列人要按照他們的隊伍各自紮營，各歸本旗。</span>
<span className="v" id="v53" data-v="53" data-xref="民數記 16:46; 歷代志上 23:32; 利未記 10:6"> 但利未人要在安放約櫃的聖幕四周紮營，以免以色列人觸怒耶和華。利未人負責看守放約櫃的聖幕。」</span>
<span className="v" id="v54" data-v="54" data-xref="申命記 12:32; 出埃及記 40:16; 出埃及記 39:32"> 以色列人就按耶和華對摩西的吩咐行了。</span>
</div>
</div>

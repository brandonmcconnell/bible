## 拿細耳人的條例

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華對摩西說：</span>
<span className="v" id="v2" data-v="2" data-xref="士師記 13:5; 阿摩司書 2:11–12; 羅馬書 1:1"> 「你把以下條例告訴以色列人：無論男女，如果許願做拿細耳人，把自己獻給耶和華，</span>
<span className="v" id="v3" data-v="3" data-xref="路加福音 1:15; 提摩太前書 5:23; 阿摩司書 2:12"> 就要禁戒淡酒和烈酒、淡酒或烈酒做的醋、葡萄汁、葡萄和葡萄乾。</span>
<span className="v" id="v4" data-v="4" data-xref="民數記 6:5; 民數記 6:21; 民數記 6:8–9"> 在做拿細耳人期間，葡萄樹所結的，包括葡萄核和葡萄皮，都不可吃。</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳記上 1:11; 士師記 16:17; 士師記 13:5"> 在許願做拿細耳人期間，不可用剃刀剃頭，要任由頭髮生長，要保持聖潔，一直到獻給耶和華的日期滿了。</span>
<span className="v" id="v6" data-v="6" data-xref="利未記 21:11; 利未記 19:28; 利未記 21:1–3"> 在獻給耶和華期間，不可挨近死屍，</span>
<span className="v" id="v7" data-v="7" data-xref="民數記 9:6; 利未記 21:1–2; 利未記 21:10–12"> 即使父母或是兄弟姊妹死了，也不可挨近，以免沾染不潔，因為他頭上有將自己奉獻給上帝的記號。</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多後書 6:17–18"> 在做拿細耳人期間，他是奉獻給耶和華的人。</span>
<span className="v" id="v9" data-v="9" data-xref="民數記 6:18; 使徒行傳 18:18; 利未記 14:9"> 如果有人在他身邊暴斃，使他的頭髮沾染不潔，他要在第七天潔淨的日子剃掉頭髮。</span>
<span className="v" id="v10" data-v="10" data-xref="利未記 15:29; 利未記 1:14; 利未記 15:14"> 第八天，他要帶兩隻斑鳩或雛鴿到會幕門口交給祭司。</span>
<span className="v" id="v11" data-v="11" data-xref="利未記 14:30–31; 利未記 5:8–10"> 祭司要獻一隻作贖罪祭，另一隻作燔祭，為他碰過死屍贖罪。他要在當日使頭聖潔，</span>
<span className="v" id="v12" data-v="12" data-xref="利未記 5:6; 馬太福音 24:13; 利未記 14:24"> 重新開始過奉獻給耶和華的日子，還要帶一隻一歲的公羊羔作贖過祭。他以前做拿細耳人的日子無效，因為他沾染了不潔之物。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行傳 21:26"> 「獻給耶和華的日子期滿後，拿細耳人要遵行以下條例。他要被帶到會幕門口，</span>
<span className="v" id="v14" data-v="14" data-xref="利未記 3:6; 利未記 4:32; 利未記 4:2–3"> 在那裡獻給耶和華一隻毫無殘疾、一歲的公羊羔作燔祭，一隻毫無殘疾、一歲母羊羔作贖罪祭，一隻毫無殘疾的公綿羊作平安祭，</span>
<span className="v" id="v15" data-v="15" data-xref="利未記 2:4; 出埃及記 29:2; 民數記 15:10"> 一籃調油的無酵細麵餅和塗油的無酵薄餅，以及素祭和奠祭。</span>
<span className="v" id="v16" data-v="16"> 祭司要把這些祭物帶到耶和華面前，為他獻上贖罪祭和燔祭，</span>
<span className="v" id="v17" data-v="17"> 然後把公綿羊和那籃無酵餅獻給耶和華作平安祭，再獻上素祭和奠祭。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行傳 21:24; 民數記 6:9; 使徒行傳 18:18"> 拿細耳人要在會幕門口剃掉作為奉獻記號的頭髮，把頭髮放在平安祭下面的火裡燒掉。</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳記上 2:15; 利未記 7:30; 出埃及記 29:23–28"> 拿細耳人剃頭以後，祭司要取出一條煮好的公綿羊前腿，再從籃中拿出一塊無酵餅和一塊無酵薄餅，放在拿細耳人手中。</span>
<span className="v" id="v20" data-v="20" data-xref="傳道書 9:7; 出埃及記 29:27–28; 民數記 5:25"> 然後，祭司要把這些祭物作為搖祭，在耶和華面前搖一搖。這些祭物與作搖祭的胸肉和作舉祭的腿肉一樣，都是歸給祭司的聖物。此後，拿細耳人便可以喝酒。</span>
<span className="v" id="v21" data-v="21" data-xref="希伯來書 13:16; 以斯拉記 2:69; 民數記 5:29"> 「以上是許願獻供物給耶和華的拿細耳人當守的條例和當獻的祭物。但如果他額外許願獻上力所能及之物，就必須還所許的願。」</span>
</div>
</div>

## 祭司的祝福

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22"> 耶和華對摩西說：</span>
<span className="v" id="v23" data-v="23" data-xref="申命記 21:5; 歷代志上 23:13; 創世記 48:20"> 「你告訴亞倫父子們要這樣為以色列人祝福，</span>
<span className="v" id="v24" data-v="24" data-xref="帖撒羅尼迦前書 5:23; 詩篇 121:4–7; 腓立比書 4:7"> 『願耶和華賜福給你，保護你；</span>
<span className="v" id="v25" data-v="25" data-xref="詩篇 80:19; 詩篇 119:135; 詩篇 31:16"> 願耶和華以祂的容光照耀你，施恩給你；</span>
<span className="v" id="v26" data-v="26" data-xref="詩篇 4:6; 詩篇 29:11; 帖撒羅尼迦後書 3:16"> 願耶和華笑顏垂顧你，賜你平安。』</span>
<span className="v" id="v27" data-v="27" data-xref="歷代志下 7:14; 但以理書 9:18–19; 申命記 28:10"> 他們要奉我的名為以色列人祝福，我必賜福給他們。」</span>

## 約旦河東的支派

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民數記 21:32; 民數記 32:3; 創世記 13:10–11"> 呂便和迦得的子孫有許多牲畜，他們見雅謝和基列適於放牧，</span>
<span className="v" id="v2" data-v="2"> 就來見摩西、以利亞撒祭司和會眾的首領，說：</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米書 48:34; 以賽亞書 16:8–9; 民數記 32:34–38"> 「亞他錄、底本、雅謝、寧拉、希實本、以利亞利、示班、尼波和比穩——</span>
<span className="v" id="v4" data-v="4" data-xref="民數記 21:34; 申命記 2:24–35; 民數記 21:24"> 這些耶和華為以色列會眾攻取的地方適於放牧，而僕人們有許多牲畜。</span>
<span className="v" id="v5" data-v="5" data-xref="路得記 2:10; 約書亞記 7:7; 耶利米書 31:2"> 如果你們恩待我們，請將這些地方賜給我們作產業，別讓我們過約旦河了。」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="哥林多前書 13:5; 撒母耳記下 11:11; 腓立比書 2:4"> 摩西對他們說：「難道你們的同胞去打仗，你們卻坐在這裡嗎？</span>
<span className="v" id="v7" data-v="7" data-xref="民數記 13:27–4; 民數記 32:9; 申命記 1:28"> 你們為何使以色列人軍心動搖，不敢進入耶和華所賜之地？</span>
<span className="v" id="v8" data-v="8" data-xref="申命記 1:19–25; 民數記 14:2; 民數記 13:2–26"> 從前我在加低斯·巴尼亞派你們的祖先去打探那地方的時候，他們就是這樣。</span>
<span className="v" id="v9" data-v="9" data-xref="民數記 13:23–10; 申命記 1:24–28"> 他們到以實各谷打探那地方，回來後竟動搖軍心，使以色列人不敢進入耶和華所賜之地。</span>
<span className="v" id="v10" data-v="10" data-xref="民數記 14:11; 詩篇 95:11; 以西結書 20:15"> 那天耶和華發怒，起誓說，</span>
<span className="v" id="v11" data-v="11" data-xref="民數記 14:28–30; 民數記 14:24; 民數記 26:2"> 『從埃及出來、二十歲以上的人都看不到我起誓要賜給亞伯拉罕、以撒和雅各的土地，因為他們沒有一心追隨我；</span>
<span className="v" id="v12" data-v="12" data-xref="申命記 1:36; 民數記 14:30; 民數記 14:24"> 只有基尼洗族耶孚尼的兒子迦勒和嫩的兒子約書亞可以看到，因為他們一心追隨我。』</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多前書 10:5; 民數記 14:33–35; 希伯來書 3:16–19"> 耶和華向以色列人發怒，使他們在曠野漂泊了四十年，直到在耶和華面前作惡的那一代都死了。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="路加福音 11:48; 詩篇 78:57; 馬太福音 23:31–33"> 「現在，你們這群罪人的後代竟然重蹈前人的覆轍，加劇耶和華向以色列所發的怒氣。</span>
<span className="v" id="v15" data-v="15" data-xref="哥林多前書 8:11–12; 歷代志下 15:2; 歷代志下 7:19–22"> 如果你們離棄祂，祂必再次把以色列人丟棄在曠野，這樣你們就毀了整個民族。」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="創世記 33:17; 民數記 34:22"> 他們上前對摩西說：「我們要在這裡為牲畜建棚圈，為家小築城邑，</span>
<span className="v" id="v17" data-v="17" data-xref="約書亞記 4:12–13; 民數記 32:29–32; 申命記 3:18–20"> 讓他們留在堅固的城內，免受當地居民的威脅。然後我們必拿起兵器率先上陣，直到幫其他以色列同胞奪取他們的土地。</span>
<span className="v" id="v18" data-v="18" data-xref="約書亞記 22:1–5"> 在其他同胞佔領各自的產業之前，我們決不回家。</span>
<span className="v" id="v19" data-v="19" data-xref="約書亞記 13:8; 約書亞記 12:1–6; 民數記 34:15"> 但我們不會跟他們在約旦河西岸分土地，我們已經得到約旦河東邊作產業。」</span>
<span className="v" id="v20" data-v="20" data-xref="約書亞記 4:12–13; 申命記 3:18–20; 約書亞記 1:13–15"> 摩西說：「如果你們信守承諾，拿起兵器在耶和華面前出戰，</span>
<span className="v" id="v21" data-v="21"> 你們全軍就要在耶和華面前渡過約旦河，直到祂趕走祂面前的仇敵，</span>
<span className="v" id="v22" data-v="22" data-xref="約書亞記 22:9; 約書亞記 22:4; 申命記 3:20"> 征服那地方。之後，你們才可以回家，才算在耶和華和以色列人面前盡了自己的責任，這地方就在耶和華面前歸給你們作產業。</span>
<span className="v" id="v23" data-v="23" data-xref="以賽亞書 59:12; 箴言 13:21; 創世記 44:16"> 但你們如果不這樣做，就是得罪耶和華，必難逃罪責。</span>
<span className="v" id="v24" data-v="24" data-xref="民數記 32:16; 民數記 30:2; 民數記 32:34–42"> 你們現在去為家小築城邑，為牛羊建棚圈吧，但別忘了信守承諾。」</span>
<span className="v" id="v25" data-v="25" data-xref="約書亞記 1:13–14"> 迦得和呂便的子孫對摩西說：「僕人們一定遵命而行。</span>
<span className="v" id="v26" data-v="26" data-xref="約書亞記 1:14"> 我們的妻子、孩子、牛羊等牲畜都會留在基列的各城。</span>
<span className="v" id="v27" data-v="27" data-xref="約書亞記 4:12; 民數記 32:17; 民數記 12:11"> 僕人當中所有能上陣打仗的人都會照你的吩咐在耶和華面前過河作戰。」</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="約書亞記 1:13"> 於是，摩西對以利亞撒祭司、嫩的兒子約書亞和以色列各支派的族長說：</span>
<span className="v" id="v29" data-v="29"> 「如果迦得和呂便子孫中所有能上陣打仗的人，在耶和華面前跟你們一同過河作戰，你們征服那片土地以後，就要把基列給他們作產業。</span>
<span className="v" id="v30" data-v="30" data-xref="約書亞記 22:19"> 如果他們不帶著兵器跟你們一起過河作戰，就只能在迦南與你們同分產業。」</span>
<span className="v" id="v31" data-v="31"> 迦得和呂便的子孫再次說：「凡耶和華所吩咐的，僕人們一定照辦。</span>
<span className="v" id="v32" data-v="32"> 我們一定帶著兵器在耶和華面前過河，進入迦南，但我們要擁有約旦河東邊作產業。」</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="約書亞記 12:6; 申命記 29:8; 申命記 3:12–17"> 摩西就把亞摩利王西宏和巴珊王噩的國土及周圍的城邑，都給了迦得的子孫、呂便的子孫和約瑟兒子瑪拿西的半個支派。</span>
<span className="v" id="v34" data-v="34" data-xref="申命記 2:36; 民數記 32:3; 以賽亞書 17:2"> 迦得的子孫重建了底本、亞他錄、亞羅珥、</span>
<span className="v" id="v35" data-v="35" data-xref="民數記 32:1; 民數記 32:3"> 亞他錄·朔反、雅謝、約比哈、</span>
<span className="v" id="v36" data-v="36" data-xref="民數記 32:3"> 伯·寧拉和伯·哈蘭，使之成為堅固的城池，並建了羊圈。</span>
<span className="v" id="v37" data-v="37" data-xref="民數記 21:27; 民數記 32:3; 以賽亞書 15:4"> 呂便的子孫重建了希實本、以利亞利、基列亭、</span>
<span className="v" id="v38" data-v="38" data-xref="以賽亞書 46:1; 民數記 32:3; 約書亞記 23:7"> 尼波、巴力·免和西比瑪。他們為重建的城邑起了新名字，如尼波和巴力·免。</span>
<span className="v" id="v39" data-v="39" data-xref="創世記 50:23; 約書亞記 17:1; 民數記 26:29"> 瑪拿西之子瑪吉的子孫佔領了基列，趕走了那裡的亞摩利人。</span>
<span className="v" id="v40" data-v="40" data-xref="約書亞記 17:1; 約書亞記 13:29–31; 申命記 3:13–15"> 摩西就把基列賜給瑪拿西的兒子瑪吉，他便住在那裡。</span>
<span className="v" id="v41" data-v="41" data-xref="申命記 3:14; 士師記 10:4; 約書亞記 13:30"> 瑪拿西的子孫雅珥佔領了基列的村莊，將它們改名為哈倭特·雅珥。</span>
<span className="v" id="v42" data-v="42" data-xref="詩篇 49:11; 撒母耳記下 18:18"> 挪巴佔領了基納及其周圍的村莊，就按自己的名字稱基納為挪巴。</span>
</div>
</div>

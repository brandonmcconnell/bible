## 哥轄子孫的職責

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華對摩西和亞倫說：</span>
<span className="v" id="v2" data-v="2" data-xref="民數記 3:27; 民數記 3:19"> 「你要按宗族和家系統計利未人中哥轄子孫的人數，</span>
<span className="v" id="v3" data-v="3" data-xref="民數記 4:23; 歷代志上 23:3–5; 列王紀下 11:4–12"> 登記所有可在會幕司職的三十歲到五十歲的男子。</span>
<span className="v" id="v4" data-v="4" data-xref="民數記 4:19; 馬可福音 13:34; 民數記 4:30"> 他們在會幕裡的職責是照料至聖之物。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="馬太福音 27:51; 希伯來書 9:3; 出埃及記 40:3"> 「拔營出發的時候，亞倫父子們要進會幕解下聖所和至聖所之間的幔子，用它遮蓋約櫃，</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及記 25:13–15; 出埃及記 35:19; 民數記 4:7–8"> 再在上面依次蓋上海狗皮和純藍色的布，然後穿上抬約櫃的橫槓。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="利未記 24:5–8; 出埃及記 37:10–16; 出埃及記 25:23–30"> 「要在擺放供餅的桌子上鋪一塊藍布，把盤、碟及獻酒用的杯和瓶擺在上面。桌上要有常供的餅。</span>
<span className="v" id="v8" data-v="8" data-xref="民數記 4:6–7; 民數記 4:11–13; 民數記 4:9"> 這些東西上面要蓋朱紅色的布，再蓋上海狗皮，然後穿上抬桌子的橫槓。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="出埃及記 25:31–39; 出埃及記 37:17–24; 啟示錄 1:20–1"> 「要用藍布把燈臺、燈盞、燈剪、燈盤和盛油的器皿全遮蓋起來，</span>
<span className="v" id="v10" data-v="10" data-xref="民數記 4:12; 民數記 4:6"> 再在上面蓋上海狗皮，然後放在抬架上。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="出埃及記 40:5; 出埃及記 30:1–19; 出埃及記 40:26–27"> 「金壇上面要蓋藍色布，再蓋上海狗皮，穿上抬金壇的橫槓。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="歷代志上 9:29; 出埃及記 25:9; 歷代志下 4:22"> 「聖所裡面供職用的一切器皿都要用藍色布包好，蓋上海狗皮，放在抬架上。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="利未記 6:12–13; 出埃及記 39:1; 出埃及記 39:41"> 「要清除祭壇上的灰燼，鋪上紫色布，</span>
<span className="v" id="v14" data-v="14" data-xref="歷代志下 4:19; 出埃及記 38:1–7"> 然後把供職用的火鼎、肉叉、鏟、碗等所有的祭壇器具都放在上面，再蓋上海狗皮，穿上抬祭壇的橫槓。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="撒母耳記下 6:6–7; 民數記 7:9; 申命記 31:9"> 「拔營出發時，要等到亞倫父子們把聖所和聖所的所有器具都蓋好後，哥轄的子孫才可以來抬。他們負責抬這些會幕的器具，但不可觸摸這些聖物，免得死亡。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 25:6; 利未記 24:2; 出埃及記 30:23–38"> 亞倫祭司的兒子以利亞撒負責管理整個聖幕，以及裡面的燈油、香料、日常獻的素祭、膏油及一切器具和物品。」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17"> 耶和華對摩西和亞倫說：</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳記下 6:6–7; 民數記 17:10; 民數記 18:5"> 「不可讓哥轄宗族在利未人中滅絕。</span>
<span className="v" id="v19" data-v="19" data-xref="民數記 4:15"> 他們走近至聖之物以前，亞倫父子們要先進去指派他們做什麼、抬什麼，以免他們死亡。</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳記上 6:19; 出埃及記 19:21; 民數記 4:15"> 他們不可進去看聖物，一刻都不可，免得死亡。」</span>
</div>
</div>

## 革順子孫的職責

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21"> 耶和華對摩西說：</span>
<span className="v" id="v22" data-v="22" data-xref="民數記 3:18; 民數記 3:21; 民數記 3:24"> 「你要按宗族和家系統計革順子孫的人數，</span>
<span className="v" id="v23" data-v="23" data-xref="民數記 4:3; 提摩太前書 1:18; 哥林多前書 9:7"> 登記所有可在會幕司職的三十歲到五十歲的男子。</span>
<span className="v" id="v24" data-v="24" data-xref="民數記 4:19; 民數記 4:31–32; 民數記 4:47"> 以下是革順宗族負責的搬運工作及其他事務：</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="民數記 3:25–26; 出埃及記 26:14; 民數記 7:5–7"> 「他們要抬聖幕的幔子、會幕、會幕頂蓋、頂蓋上的海狗皮、會幕門簾、</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及記 35:18; 出埃及記 27:9"> 圍繞聖幕和祭壇的院子的帷幔、院門門簾、繩索及司職用的一切器具，還負責其他相關事務。</span>
<span className="v" id="v27" data-v="27" data-xref="路加福音 1:70; 哥林多前書 11:2"> 你們要把抬的任務分配給革順的子孫，他們要遵照亞倫父子們的吩咐司職。</span>
<span className="v" id="v28" data-v="28" data-xref="民數記 4:33; 哥林多前書 12:5–6"> 這是革順宗族的人在會幕裡的職責，他們要按祭司亞倫的兒子以他瑪的吩咐司職。</span>
</div>
</div>

## 米拉利子孫的職責

<div className="bt">
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="民數記 3:33–35"> 「你要按宗族和家系統計米拉利子孫的人數，</span>
<span className="v" id="v30" data-v="30" data-xref="民數記 4:3; 民數記 4:23; 提摩太後書 2:4"> 登記所有可在會幕司職的三十歲到五十歲的男子。</span>
<span className="v" id="v31" data-v="31" data-xref="民數記 3:36–37; 出埃及記 26:15; 民數記 7:8–9"> 他們在會幕裡負責抬聖幕的木板、橫閂、柱子、帶凹槽的底座，</span>
<span className="v" id="v32" data-v="32" data-xref="出埃及記 38:21; 歷代志上 9:29; 民數記 3:8"> 院子四周的柱子及其帶凹槽的底座、橛子、繩索和其他相關器具。你們要把當抬的物件一一指派給他們。</span>
<span className="v" id="v33" data-v="33" data-xref="民數記 4:28; 約書亞記 3:6; 以賽亞書 3:6"> 這是米拉利宗族的人在會幕的職責，由祭司亞倫的兒子以他瑪監督。」</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34"> 於是，摩西、亞倫和會眾的首領按宗族和家系統計哥轄的子孫，</span>
<span className="v" id="v35" data-v="35" data-xref="歷代志上 23:24; 民數記 4:23; 歷代志上 23:3"> 登記了所有可在會幕司職的三十歲到五十歲的男子，</span>
<span className="v" id="v36" data-v="36"> 共兩千七百五十人。</span>
<span className="v" id="v37" data-v="37"> 這是哥轄宗族在會幕司職的人數，是摩西和亞倫照耶和華的吩咐統計的。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38"> 按宗族和家系統計，革順的子孫中三十歲到五十歲、可在會幕司職的共兩千六百三十人。</span>
<span className="v" id="v41" data-v="41"> 這是革順宗族在會幕司職的人數，是摩西和亞倫照耶和華的吩咐統計的。</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42"> 按宗族和家系統計，米拉利的子孫中三十歲到五十歲、可在會幕司職的共三千二百人。</span>
<span className="v" id="v45" data-v="45" data-xref="民數記 4:29"> 這是米拉利宗族的人數，是摩西和亞倫照耶和華的吩咐統計的。</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46"> 摩西、亞倫和以色列人的首領按宗族和家系統計了利未人的人數，</span>
<span className="v" id="v47" data-v="47" data-xref="哥林多前書 12:4–31; 羅馬書 12:6–8; 民數記 4:3"> 三十歲到五十歲、可司職和搬運會幕器具的利未人，共八千五百八十人。</span>
<span className="v" id="v49" data-v="49" data-xref="民數記 1:54; 民數記 4:31; 民數記 4:15"> 照耶和華對摩西的吩咐，每個人都被統計在內，都有指定的職責和當抬的器具。這樣，照耶和華對摩西的吩咐，人口統計完畢。</span>
</div>
</div>

</div>

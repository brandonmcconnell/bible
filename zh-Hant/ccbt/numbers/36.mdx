## 女子繼承產業的律例

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民數記 27:1; 歷代志上 7:14–16; 約書亞記 17:2–3"> 基列是約瑟之子瑪拿西的孫子，瑪吉的兒子。他宗族中的各族長來見摩西和做以色列人首領的各族長，說：</span>
<span className="v" id="v2" data-v="2" data-xref="約書亞記 17:3–6; 民數記 27:1–7; 民數記 33:54"> 「耶和華曾吩咐我主用抽籤的方式把土地分給以色列人，還吩咐我主將我們兄弟西羅非哈的產業分給他的女兒們。</span>
<span className="v" id="v3" data-v="3"> 但如果她們嫁給以色列其他支派的人，從我們祖業中分給她們的產業就會歸入她們夫家的支派。這樣的話，我們抽籤分到的土地就會減少。</span>
<span className="v" id="v4" data-v="4" data-xref="利未記 25:10–18; 以賽亞書 61:2; 利未記 25:23"> 到了以色列人的禧年，她們所得的產業就會歸給她們丈夫的支派，我們支派的祖業就會失去她們那份產業。」</span>
<span className="v" id="v5" data-v="5" data-xref="民數記 27:7; 申命記 5:28"> 摩西照耶和華的話吩咐以色列人說：「約瑟支派的人說的對。</span>
<span className="v" id="v6" data-v="6" data-xref="民數記 36:12; 哥林多後書 6:14; 創世記 24:3"> 關於西羅非哈的女兒們，耶和華說她們可以自由嫁人，但必須嫁給本支派的人。</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀上 21:3; 民數記 36:9"> 以色列人的產業不可從一個支派轉到另一個支派，各支派必須守住本支派的祖業。</span>
<span className="v" id="v8" data-v="8" data-xref="歷代志上 23:22"> 在以色列各支派中繼承了產業的女子必須嫁給本支派的人，以便以色列人都能守住自己的祖業。</span>
<span className="v" id="v9" data-v="9"> 以色列人的產業不可從一個支派轉到另一個支派，以色列各支派必須守住本支派的產業。」</span>
<span className="v" id="v10" data-v="10" data-xref="歷代志下 30:12; 馬太福音 28:20; 出埃及記 39:42–43"> 於是，西羅非哈的女兒們遵行了耶和華對摩西的吩咐。</span>
<span className="v" id="v11" data-v="11" data-xref="民數記 27:1; 民數記 26:33"> 瑪拉、得撒、曷拉、密迦和挪阿都嫁給了她們叔伯的兒子，</span>
<span className="v" id="v12" data-v="12"> 即約瑟之子瑪拿西支派的人。這樣，她們的產業仍留在本支派中。</span>
<span className="v" id="v13" data-v="13" data-xref="利未記 27:34; 利未記 26:46; 民數記 22:1"> 以上是在耶利哥對面、約旦河邊的摩押平原，耶和華藉摩西頒佈給以色列人的命令和律例。</span>

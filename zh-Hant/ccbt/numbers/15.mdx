## 獻祭的條例

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華對摩西說：</span>
<span className="v" id="v2" data-v="2" data-xref="利未記 23:10; 民數記 15:18; 利未記 25:2"> 「你把以下條例告訴以色列人。 「你們進入耶和華賜給你們的家園後，</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 29:18; 創世記 8:21; 腓立比書 4:18"> 要用牛羊作火祭獻給耶和華，作蒙耶和華悅納的馨香之祭。不管是獻燔祭、還願祭、自願獻的祭還是節期的祭，都當如此。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及記 29:40; 利未記 23:13; 利未記 6:14"> 獻祭者要同時將一公斤細麵粉調上一升油作素祭獻給耶和華。</span>
<span className="v" id="v5" data-v="5" data-xref="民數記 28:7; 民數記 28:14; 士師記 9:13"> 無論燔祭還是別的祭，每獻一隻羊羔，要同時獻上一升酒作奠祭；</span>
<span className="v" id="v6" data-v="6" data-xref="民數記 28:12–14; 民數記 15:4"> 每獻一隻公綿羊，要同時將兩公斤細麵粉調上一升半油作素祭獻上，</span>
<span className="v" id="v7" data-v="7"> 還要獻一升半酒作奠祭。這是蒙耶和華悅納的馨香之祭。</span>
<span className="v" id="v8" data-v="8" data-xref="利未記 3:1; 利未記 7:11–18; 利未記 1:3"> 如果用公牛獻給耶和華作燔祭、還願祭或平安祭，</span>
<span className="v" id="v9" data-v="9" data-xref="民數記 28:14; 民數記 28:12; 利未記 6:14"> 就要將三公斤細麵粉調上兩升油作素祭和公牛一同獻上，</span>
<span className="v" id="v10" data-v="10" data-xref="民數記 15:5; 民數記 6:15"> 還要獻上兩升酒作奠祭。這是蒙耶和華悅納的馨香之祭。</span>
<span className="v" id="v11" data-v="11"> 「獻公牛、公綿羊、綿羊羔或山羊羔時，都要這樣辦理。</span>
<span className="v" id="v12" data-v="12"> 無論獻多少牲畜，每隻都要這樣辦理。</span>
<span className="v" id="v13" data-v="13"> 凡以色列人獻上蒙耶和華悅納的馨香火祭時，都要這樣辦理。</span>
<span className="v" id="v14" data-v="14"> 住在你們中間的外族人，不管是暫住還是世代居住的，若願意獻上蒙耶和華悅納的馨香火祭，也要這樣辦理。</span>
<span className="v" id="v15" data-v="15" data-xref="民數記 9:14; 民數記 15:29; 出埃及記 12:49"> 以色列人和寄居的外族人都要遵守一樣的條例，永世不變。你們在耶和華面前怎樣做，外族人也要怎樣做。</span>
<span className="v" id="v16" data-v="16"> 你們和寄居在你們那裡的外族人要遵行一樣的條例和規定。」</span>
<span className="v" id="v17" data-v="17"> 耶和華對摩西說：</span>
<span className="v" id="v18" data-v="18" data-xref="民數記 15:2; 申命記 26:1–15"> 「你把以下條例告訴以色列人。 「你們到達耶和華領你們去的地方，</span>
<span className="v" id="v19" data-v="19" data-xref="約書亞記 5:11–12"> 吃當地的出產時，要拿出一份作舉祭獻給耶和華。</span>
<span className="v" id="v20" data-v="20" data-xref="利未記 2:14; 出埃及記 34:26; 申命記 26:2–10"> 你們要用初熟的麥子磨麵做餅，當作舉祭獻上，好像獻麥場的舉祭一樣。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及記 29:28; 民數記 18:26"> 你們世世代代都要用初熟的麥子磨麵，當作舉祭獻給耶和華。</span>
<span className="v" id="v22" data-v="22" data-xref="利未記 4:2; 利未記 4:27; 利未記 5:15–17"> 「如果你們無意間違背了耶和華藉摩西吩咐你們遵守的命令，</span>
<span className="v" id="v23" data-v="23"> 就是吩咐你們從祂頒佈之日起，要世世代代遵守的命令，</span>
<span className="v" id="v24" data-v="24" data-xref="利未記 4:23; 利未記 4:13–21; 利未記 5:15"> 如果是因會眾的無知而造成無心之過，全體會眾就要獻上一頭公牛犢作燔祭，作蒙耶和華悅納的馨香之祭，同時按規定獻上素祭和奠祭，外加一隻公山羊作贖罪祭。</span>
<span className="v" id="v25" data-v="25" data-xref="利未記 4:20; 羅馬書 3:25; 希伯來書 2:17"> 祭司要為以色列全體會眾贖罪，這樣他們就得到了赦免，因為是無心之過，並且他們已經向耶和華獻上火祭和贖罪祭。</span>
<span className="v" id="v26" data-v="26" data-xref="民數記 15:24"> 這樣，以色列全體會眾和寄居的外族人都必蒙赦免，因為無心之過牽涉到所有人。</span>
<span className="v" id="v27" data-v="27" data-xref="利未記 4:27–28; 使徒行傳 17:30; 使徒行傳 3:17"> 「倘若是個人無意間犯了罪，他就要獻上一隻一歲的母山羊作贖罪祭。</span>
<span className="v" id="v28" data-v="28" data-xref="利未記 4:35"> 祭司要為這無意間犯罪的人在耶和華面前贖罪，使他獲得赦免。</span>
<span className="v" id="v29" data-v="29" data-xref="民數記 15:15; 利未記 16:29; 利未記 17:15"> 無論是以色列人或是寄居的外族人，凡是犯無心之過的都要按這規條辦理。</span>
<span className="v" id="v30" data-v="30" data-xref="希伯來書 10:26; 詩篇 19:13; 申命記 1:43"> 但不管是以色列人還是外族人，若任意妄為，褻瀆了耶和華，都要從民中被剷除，</span>
<span className="v" id="v31" data-v="31" data-xref="撒母耳記下 12:9; 箴言 13:13; 以西結書 18:20"> 因為他藐視耶和華的話，違背耶和華的命令，必須被剷除，罪責自負。」</span>
</div>
</div>

## 處死干犯安息日者

<div className="bt">
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="出埃及記 35:2–3; 出埃及記 31:14–15; 出埃及記 20:8–10"> 以色列人在曠野的時候，發現有人在安息日撿柴，</span>
<span className="v" id="v33" data-v="33" data-xref="約翰福音 8:3–20"> 他們就把撿柴的人帶到摩西、亞倫和全體會眾那裡，</span>
<span className="v" id="v34" data-v="34" data-xref="利未記 24:12; 民數記 9:8"> 把他關起來，因為不知道如何處置他。</span>
<span className="v" id="v35" data-v="35" data-xref="使徒行傳 7:58; 出埃及記 31:14–15; 列王紀上 21:13"> 耶和華對摩西說：「必須處死那人，全體會眾要在營外用石頭打死他。」</span>
<span className="v" id="v36" data-v="36" data-xref="約書亞記 7:25"> 於是，全體會眾照耶和華對摩西的吩咐，把他拉到營外，用石頭打死了他。</span>
</div>
</div>

## 衣服穗子的條例

<div className="bt">
<div className="bp">
<span className="v" id="v37" data-v="37"> 耶和華對摩西說：</span>
<span className="v" id="v38" data-v="38" data-xref="馬太福音 23:5; 申命記 22:12; 馬太福音 9:20"> 「你要吩咐以色列人世世代代在衣角縫上穗子，穗子上繫一條藍色細帶。</span>
<span className="v" id="v39" data-v="39" data-xref="詩篇 106:39; 箴言 28:26; 詩篇 73:27"> 穗子是用來提醒他們，要遵行我的一切命令，不要隨從自己心中和眼目的情慾而背信棄義。</span>
<span className="v" id="v40" data-v="40" data-xref="羅馬書 12:1; 帖撒羅尼迦前書 4:7; 利未記 11:44–45"> 這樣，你們就會記得遵守我的一切命令，做你們上帝的聖潔之民。</span>
<span className="v" id="v41" data-v="41" data-xref="彼得前書 2:9–10; 以西結書 36:25–27; 希伯來書 11:16"> 我是你們的上帝耶和華，我把你們從埃及領出來，是要做你們的上帝。我是你們的上帝耶和華。」</span>

## 從埃及到約旦河

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="詩篇 77:20; 彌迦書 6:4; 出埃及記 12:51"> 以下是以色列人在摩西和亞倫的領導下離開埃及列隊行軍的路線。</span>
<span className="v" id="v2" data-v="2" data-xref="民數記 9:17–23; 申命記 10:11; 民數記 10:6"> 摩西遵照耶和華的吩咐記錄啟行的地點，以下是他們停留過的地方。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="出埃及記 14:8; 出埃及記 12:37; 出埃及記 13:4"> 一月十五日，即逾越節的第二天，埃及人眼睜睜地看著以色列人昂首挺胸地離開了蘭塞。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及記 12:12; 以賽亞書 19:1; 出埃及記 18:11"> 當時埃及人正埋葬他們的長子，耶和華擊殺了他們當中的長子，並懲罰了他們的眾神明。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 12:37"> 以色列人從蘭塞啟行，至疏割紮營；</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及記 13:20"> 從疏割啟行，至曠野邊界的以倘紮營；</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及記 14:2; 出埃及記 14:9; 民數記 33:8"> 從以倘啟行，又轉到巴力·洗分對面的比哈·希錄，在密奪附近紮營；</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及記 15:22–26; 出埃及記 14:21–31"> 從比哈·希錄啟行，經過紅海到書珥曠野，在伊坦曠野走了三天，至瑪拉紮營；</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及記 15:27"> 從瑪拉啟行，至以琳紮營，那裡有十二股水泉和七十棵棕樹；</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及記 16:1; 出埃及記 17:1"> 從以琳啟行，至紅海岸邊紮營；</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及記 16:1"> 從紅海啟行，至汛曠野紮營；</span>
<span className="v" id="v12" data-v="12"> 從汛曠野啟行，至脫加紮營；</span>
<span className="v" id="v13" data-v="13"> 從脫加啟行，至亞錄紮營；</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及記 17:1–8; 出埃及記 19:2"> 從亞錄啟行，至利非訂紮營，在那裡民眾沒有水喝；</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及記 19:1–2; 出埃及記 16:1"> 從利非訂啟行，至西奈曠野紮營；</span>
<span className="v" id="v16" data-v="16" data-xref="民數記 11:34; 民數記 10:11–13; 民數記 10:33"> 從西奈曠野啟行，至基博羅·哈他瓦紮營；</span>
<span className="v" id="v17" data-v="17" data-xref="民數記 11:35"> 從基博羅·哈他瓦啟行，至哈洗錄紮營；</span>
<span className="v" id="v18" data-v="18" data-xref="民數記 12:16"> 從哈洗錄啟行，至利提瑪紮營；</span>
<span className="v" id="v19" data-v="19"> 從利提瑪啟行，至臨門·帕烈紮營；</span>
<span className="v" id="v20" data-v="20"> 從臨門·帕烈啟行，至立拿紮營；</span>
<span className="v" id="v21" data-v="21" data-xref="申命記 1:1"> 從立拿啟行，至勒撒紮營；</span>
<span className="v" id="v22" data-v="22"> 從勒撒啟行，至基希拉他紮營；</span>
<span className="v" id="v23" data-v="23"> 從基希拉他啟行，至沙斐山紮營；</span>
<span className="v" id="v24" data-v="24"> 從沙斐山啟行，至哈拉大紮營；</span>
<span className="v" id="v25" data-v="25"> 從哈拉大啟行，至瑪吉希錄紮營；</span>
<span className="v" id="v26" data-v="26"> 從瑪吉希錄啟行，至他哈紮營；</span>
<span className="v" id="v27" data-v="27"> 從他哈啟行，至他拉紮營；</span>
<span className="v" id="v28" data-v="28"> 從他拉啟行，至密加紮營；</span>
<span className="v" id="v29" data-v="29"> 從密加啟行，至哈摩拿紮營；</span>
<span className="v" id="v30" data-v="30" data-xref="申命記 10:5–6"> 從哈摩拿啟行，至摩西錄紮營；</span>
<span className="v" id="v31" data-v="31" data-xref="申命記 10:6; 創世記 36:27; 歷代志上 1:43"> 從摩西錄啟行，至比尼·亞干紮營；</span>
<span className="v" id="v32" data-v="32" data-xref="申命記 10:7"> 從比尼·亞干啟行，至曷·哈吉甲紮營；</span>
<span className="v" id="v33" data-v="33" data-xref="申命記 10:7"> 從曷·哈吉甲啟行，至約巴他紮營；</span>
<span className="v" id="v34" data-v="34"> 從約巴他啟行，至阿博拿紮營；</span>
<span className="v" id="v35" data-v="35" data-xref="申命記 2:8; 列王紀上 9:26; 列王紀上 22:48"> 從阿博拿啟行，至以旬·迦別紮營；</span>
<span className="v" id="v36" data-v="36" data-xref="民數記 20:1; 民數記 27:14; 申命記 32:51"> 從以旬·迦別啟行，至荀曠野的加低斯紮營；</span>
<span className="v" id="v37" data-v="37" data-xref="民數記 21:4; 民數記 20:22–23; 民數記 20:16"> 從加低斯啟行，至以東邊界的何珥山紮營。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="申命記 10:6; 申命記 32:50; 民數記 20:24–28"> 以色列人離開埃及後的第四十年五月一日，亞倫祭司遵照耶和華的吩咐上了何珥山，並在那裡離世，</span>
<span className="v" id="v39" data-v="39"> 享年一百二十三歲。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="民數記 21:1–9"> 在南地的迦南人亞拉得王得知了以色列人要來的消息。</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="民數記 21:4"> 以色列人從何珥山啟行，至撒摩拿紮營；</span>
<span className="v" id="v42" data-v="42"> 從撒摩拿啟行，至普嫩紮營；</span>
<span className="v" id="v43" data-v="43" data-xref="民數記 21:10"> 從普嫩啟行，至阿伯紮營；</span>
<span className="v" id="v44" data-v="44" data-xref="民數記 21:11"> 從阿伯啟行，至摩押邊境的以耶·亞巴琳紮營；</span>
<span className="v" id="v45" data-v="45"> 從以耶·亞巴琳啟行，至底本·迦得紮營；</span>
<span className="v" id="v46" data-v="46" data-xref="耶利米書 48:18; 以西結書 6:14; 以賽亞書 15:2"> 從底本·迦得啟行，至亞門·低比拉太音紮營；</span>
<span className="v" id="v47" data-v="47" data-xref="申命記 32:49; 申命記 34:1; 民數記 27:12"> 從亞門·低比拉太音啟行，至尼波對面的亞巴琳山紮營；</span>
<span className="v" id="v48" data-v="48" data-xref="民數記 22:1"> 從亞巴琳山啟行，至耶利哥對面、約旦河邊的摩押平原紮營。</span>
<span className="v" id="v49" data-v="49" data-xref="約書亞記 2:1; 約書亞記 13:20; 民數記 25:1–9"> 他們沿著約旦河在摩押平原紮營，營地從伯·耶施末一直延伸到亞伯·什亭。</span>
</div>
<div className="bp">
<span className="v" id="v50" data-v="50" data-xref="民數記 33:48–49"> 耶和華在耶利哥對面、約旦河邊的摩押平原對摩西說：</span>
<span className="v" id="v51" data-v="51" data-xref="約書亞記 3:17; 申命記 9:1; 申命記 7:1"> 「你告訴以色列人，『你們過約旦河進了迦南以後，</span>
<span className="v" id="v52" data-v="52" data-xref="出埃及記 23:24; 利未記 26:1; 申命記 20:16–18"> 一定要趕走當地的居民，毀掉他們一切的石像和鑄像，拆毀他們所有的邱壇。</span>
<span className="v" id="v53" data-v="53" data-xref="申命記 11:31; 詩篇 115:16; 申命記 32:8"> 你們要佔領那片土地，住在那裡，因為我已經把那裡賜給你們作產業了。</span>
<span className="v" id="v54" data-v="54" data-xref="民數記 26:53–56; 約書亞記 18:11–48; 約書亞記 15:1–12"> 你們要按宗族抽籤分配土地，人口多的多分，人口少的少分，抽到哪塊地就得哪塊地。你們要按照支派分配土地。</span>
<span className="v" id="v55" data-v="55" data-xref="士師記 2:3; 詩篇 106:34–36; 申命記 7:16"> 如果你們不趕走那裡的居民，留下來的人必成為你們眼裡的刺和肋旁的荊棘，在你們所居之地攪擾你們，</span>
<span className="v" id="v56" data-v="56" data-xref="路加福音 21:23–24; 申命記 28:63; 利未記 20:23"> 我也會用預備對付他們的方法來對付你們。』」</span>
</div>
</div>

</div>

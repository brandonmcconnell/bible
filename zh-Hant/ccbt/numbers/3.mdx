## 利未人的職分

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及記 6:20; 創世記 10:1; 出埃及記 6:16"> 以下是耶和華在西奈山與摩西說話期間亞倫和摩西的後代。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="出埃及記 6:23; 民數記 26:60; 出埃及記 28:1"> 亞倫的長子是拿答，其他兒子是亞比戶、以利亞撒和以他瑪。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 28:41; 利未記 8:30; 利未記 8:12"> 亞倫的兒子都是受膏的祭司，由摩西授予他們聖職做祭司。</span>
<span className="v" id="v4" data-v="4" data-xref="利未記 10:1–2; 民數記 26:61"> 拿答和亞比戶在西奈曠野用凡火向耶和華獻祭時死在祂面前，沒有留下兒子，因而只剩下以利亞撒和以他瑪在父親亞倫身邊擔任祭司。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5"> 耶和華對摩西說：</span>
<span className="v" id="v6" data-v="6" data-xref="申命記 10:8; 民數記 2:33; 民數記 1:49–53"> 「你去叫利未支派來協助亞倫祭司。</span>
<span className="v" id="v7" data-v="7" data-xref="民數記 1:50; 民數記 8:15; 民數記 8:11"> 他們要為亞倫和全體會眾在會幕司職，辦理聖幕的事務，</span>
<span className="v" id="v8" data-v="8" data-xref="民數記 4:33; 民數記 10:17; 以賽亞書 52:11"> 也要負責看守會幕裡面的所有器具，為以色列人辦理聖幕的事務。</span>
<span className="v" id="v9" data-v="9" data-xref="民數記 8:19; 民數記 18:6–7; 以弗所書 4:8"> 你要把利未人交給亞倫父子們，因為他們是從以色列人中選出來單單協助亞倫的。</span>
<span className="v" id="v10" data-v="10" data-xref="民數記 1:51; 民數記 3:38; 羅馬書 12:7"> 你要指派亞倫父子們盡祭司的職分，外人若近前來，必被處死。」</span>
<span className="v" id="v11" data-v="11"> 耶和華又對摩西說：</span>
<span className="v" id="v12" data-v="12" data-xref="民數記 3:41; 民數記 8:16; 民數記 18:6"> 「我從以色列人中揀選利未人代替以色列人所有的長子。利未人要屬於我，</span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 2:23; 出埃及記 13:12; 出埃及記 13:2"> 因為所有頭生的都屬於我。我殺死埃及人所有的長子和頭生的牲畜那天，已把以色列人所有的長子和頭生的牲畜都分別出來，使之聖潔，歸給我。我是耶和華。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14"> 耶和華在西奈曠野對摩西說：</span>
<span className="v" id="v15" data-v="15" data-xref="民數記 26:62; 馬可福音 10:14; 提摩太後書 3:15"> 「你要按利未人的宗族和家系統計他們的人口，登記所有年齡在一個月以上的男性。」</span>
<span className="v" id="v16" data-v="16" data-xref="民數記 3:39; 民數記 4:37; 民數記 4:49"> 於是，摩西照耶和華的吩咐統計利未人。</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 46:11; 出埃及記 6:16–19; 民數記 15:5–23"> 利未的兒子是革順、哥轄和米拉利。</span>
<span className="v" id="v18" data-v="18" data-xref="歷代志上 6:17; 歷代志上 26:1–32; 出埃及記 6:17–19"> 按照宗族，革順的兒子是立尼和示每。</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及記 6:18; 歷代志上 6:18; 歷代志上 15:17–21"> 按照宗族，哥轄的兒子是暗蘭、以斯哈、希伯倫和烏薛。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及記 6:19; 歷代志上 6:19; 民數記 3:33"> 按照宗族，米拉利的兒子是抹利和姆示。他們按家系都屬於利未人的宗族。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21"> 革順宗族有立尼和示每兩個家族，</span>
<span className="v" id="v22" data-v="22" data-xref="民數記 4:38–40"> 其中年齡在一個月以上的男性共七千五百人。</span>
<span className="v" id="v23" data-v="23" data-xref="民數記 1:53; 民數記 2:17"> 革順宗族要在聖幕後面，即西面安營，</span>
<span className="v" id="v24" data-v="24"> 家族首領是拉伊勒的兒子以利雅薩。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及記 25:9; 歷代志上 23:32; 歷代志上 9:14–33"> 革順人負責看守會幕，即聖幕、聖幕的罩棚、頂蓋和門簾、</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及記 35:18; 出埃及記 38:9–16; 出埃及記 27:9–16"> 圍繞聖幕和祭壇的院子的帷幔、門簾、繩索及一切相關的物品。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="歷代志上 26:23; 民數記 3:19; 歷代志上 23:12"> 哥轄宗族有暗蘭家族、以斯哈家族、希伯崙家族和烏薛家族，</span>
<span className="v" id="v28" data-v="28" data-xref="民數記 3:31; 民數記 4:35–36; 民數記 3:7"> 其中年齡在一個月以上的男性共有八千六百人，他們負責看守聖所。</span>
<span className="v" id="v29" data-v="29" data-xref="民數記 1:53; 民數記 3:23; 民數記 2:10"> 哥轄宗族要在聖幕南面安營，</span>
<span className="v" id="v30" data-v="30"> 家族首領是烏薛的兒子以利撒反。</span>
<span className="v" id="v31" data-v="31" data-xref="出埃及記 36:35–36; 出埃及記 27:1–8; 出埃及記 26:31–33"> 他們負責照管約櫃、桌子、燈臺、兩座壇、聖所內用的器具、幔子及一切物品。</span>
<span className="v" id="v32" data-v="32" data-xref="民數記 4:27; 民數記 4:16; 民數記 20:25–28"> 亞倫祭司的兒子以利亞撒是利未人的最高首領，負責監督那些照料聖所的人。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="民數記 3:20; 歷代志上 6:19; 歷代志上 23:21"> 米拉利宗族有抹利和姆示兩個家族，</span>
<span className="v" id="v34" data-v="34" data-xref="民數記 2:9; 民數記 2:11; 民數記 1:21"> 其中年齡在一個月以上的男性共六千二百人，</span>
<span className="v" id="v35" data-v="35" data-xref="民數記 1:53; 民數記 2:25; 民數記 3:28–29"> 家族領袖是亞比亥的兒子蘇列。他們要在聖幕的北面安營。</span>
<span className="v" id="v36" data-v="36" data-xref="出埃及記 26:32; 出埃及記 26:37; 出埃及記 26:15–29"> 米拉利人負責照管聖幕的木板、橫閂、柱子、帶凹槽的底座、聖幕的一切器具和所有相關事務，</span>
<span className="v" id="v37" data-v="37"> 還有院子四周的柱子及其帶凹槽的底座、橛子和繩索。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="民數記 3:10; 民數記 1:53; 民數記 2:3"> 摩西、亞倫和亞倫的兒子們要在聖幕東面、朝日出的方向安營，替以色列人在聖所司職。外人若近前來，必被處死。</span>
<span className="v" id="v39" data-v="39" data-xref="民數記 26:62; 馬太福音 7:14; 民數記 4:47–48"> 摩西和亞倫照耶和華的吩咐，按宗族統計利未人，年齡在一個月以上的男性共兩萬二千人。</span>
</div>
</div>

## 利未人代替長子的地位

<div className="bt">
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="民數記 3:15; 路加福音 10:20; 詩篇 87:6"> 耶和華對摩西說：「你要統計以色列人中年齡在一個月以上的長子，登記他們的名字。</span>
<span className="v" id="v41" data-v="41" data-xref="民數記 3:12; 民數記 3:45; 民數記 8:16"> 我是耶和華，你要把利未人歸給我，代替以色列人所有的長子，也要把利未人的牲畜獻給我，代替以色列人所有頭生的牲畜。」</span>
<span className="v" id="v42" data-v="42"> 摩西就照耶和華的吩咐，統計了以色列人的所有長子，</span>
<span className="v" id="v43" data-v="43" data-xref="民數記 3:39"> 年齡在一個月以上的共兩萬二千二百七十三人。</span>
<span className="v" id="v44" data-v="44"> 耶和華又對摩西說：</span>
<span className="v" id="v45" data-v="45" data-xref="民數記 3:12; 民數記 3:40–41"> 「你要用利未人代替以色列人所有的長子，用利未人的牲畜代替以色列人所有頭生的牲畜。利未人是屬於我的，我是耶和華。</span>
<span className="v" id="v46" data-v="46" data-xref="出埃及記 13:13; 民數記 18:15–16"> 以色列人所有長子的人數比利未人總數多二百七十三人，這些多出來的人需要被贖回，</span>
<span className="v" id="v47" data-v="47" data-xref="出埃及記 30:13; 利未記 27:6; 民數記 18:16"> 每人一兩銀子，要以聖所的秤為準，即一舍客勒<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一舍客勒約合十一克。">a</a></sup>是二十季拉。</span>
<span className="v" id="v48" data-v="48"> 要把多出來之人的贖銀交給亞倫父子們。」</span>
<span className="v" id="v49" data-v="49"> 摩西就收取了利未人所贖人數之外那些多出來之人的贖銀，</span>
<span className="v" id="v50" data-v="50" data-xref="民數記 3:46–47; 彼得前書 3:18; 馬太福音 20:28"> 以聖所的秤計算，共從以色列人的長子收取了二百七十三兩銀子。</span>
<span className="v" id="v51" data-v="51" data-xref="民數記 3:48; 民數記 16:15; 撒母耳記上 12:3–4"> 他照耶和華的吩咐，將贖銀交給亞倫父子們。</span>
</div>
</div>

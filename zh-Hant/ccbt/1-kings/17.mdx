## 以利亞預言旱災

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 4:25–26; 雅各書 5:17; 路加福音 1:17"> 基列的提斯比人以利亞對亞哈說：「我憑我事奉的以色列的上帝——永活的耶和華起誓：如果我不禱告，這幾年必沒有雨水和甘露。」</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米書 18:1; 耶利米書 7:1; 何西阿書 1:1–2"> 耶和華對以利亞說：</span>
<span className="v" id="v3" data-v="3" data-xref="啟示錄 12:6; 耶利米書 36:26; 詩篇 83:3"> 「你離開這裡，往東去，到約旦河以東的基立溪旁躲起來。</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀上 17:9; 詩篇 147:9; 約伯記 38:41"> 你可以喝基立溪的水，我已吩咐烏鴉在那裡供應你食物。」</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀上 19:9; 馬太福音 16:24; 約翰福音 15:14"> 以利亞遵從耶和華的話，到約旦河東的基立溪旁住下來。</span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 78:23–24; 馬太福音 6:31–33; 耶利米書 37:21"> 烏鴉每天早晚為他叼來餅和肉，他喝溪裡的水。</span>
</div>
</div>

## 撒勒法的寡婦

<div className="bt">
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="以賽亞書 54:10; 以賽亞書 40:30–31"> 因為天旱無雨，過了些日子，溪水乾了。</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 22:14; 列王紀上 17:2; 希伯來書 13:6"> 耶和華對他說：</span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 4:26; 俄巴底亞書 1:20; 哥林多後書 4:7"> 「你去西頓的撒勒法，住在那裡。我已吩咐那裡的一個寡婦供養你。」</span>
<span className="v" id="v10" data-v="10" data-xref="約翰福音 4:7; 創世記 24:17; 創世記 21:15"> 於是，他起身去了撒勒法，他來到撒勒法的城門口，看見一個寡婦在撿柴，就對她說：「請給我一點水喝。」</span>
<span className="v" id="v11" data-v="11" data-xref="馬太福音 25:35–40; 列王紀上 18:4; 希伯來書 13:2"> 那婦人去拿水的時候，以利亞又說：「請給我拿一點餅。」</span>
<span className="v" id="v12" data-v="12" data-xref="馬太福音 15:33–34; 列王紀上 17:1; 創世記 21:16"> 她說：「我憑你的上帝——永活的耶和華起誓，我沒有餅，我罈裡只有一把麵，瓶裡只有一點油。我來撿柴就是要回去做餅，與兒子吃完後，等死。」</span>
<span className="v" id="v13" data-v="13" data-xref="馬太福音 6:33; 瑪拉基書 3:10; 創世記 22:1–2"> 以利亞說：「不要害怕，你可以照你所說的去做餅，只是你要先做一小塊餅給我，然後再做給你和你兒子。</span>
<span className="v" id="v14" data-v="14" data-xref="馬太福音 15:36–38; 馬太福音 14:17–20; 列王紀下 4:42–44"> 因為以色列的上帝耶和華說，『在耶和華降雨之前，你罈裡的麵和瓶裡的油必不會用完。』」</span>
<span className="v" id="v15" data-v="15" data-xref="希伯來書 11:17; 馬可福音 12:43; 馬太福音 15:28"> 那婦人就照以利亞的話做了。婦人一家和以利亞就這樣吃了許多天，</span>
<span className="v" id="v16" data-v="16" data-xref="馬太福音 9:28–30; 約翰福音 4:50–51; 路加福音 1:37"> 罈裡的麵沒有用完，瓶裡的油也沒有用光，應驗了耶和華藉以利亞說的話。</span>
<span className="v" id="v17" data-v="17" data-xref="彼得前書 1:7; 但以理書 5:23; 約翰福音 11:14"> 後來，婦人的兒子病了，病情越來越重，最後死了。</span>
<span className="v" id="v18" data-v="18" data-xref="路加福音 5:8; 約翰福音 2:4; 列王紀下 3:13"> 婦人對以利亞說：「上帝的僕人啊，我跟你有什麼關係？你到我這裡來是要讓上帝想起我的罪，取我兒子的性命嗎？」</span>
<span className="v" id="v19" data-v="19" data-xref="列王紀下 4:32; 列王紀下 4:10; 使徒行傳 9:37"> 以利亞對婦人說：「把你兒子交給我。」隨後，他從婦人懷中接過孩子，抱到樓上自己的房間，放在床上。</span>
<span className="v" id="v20" data-v="20" data-xref="雅各書 5:15–18; 馬太福音 21:22; 約書亞記 7:8–9"> 他向耶和華呼求道：「我的上帝耶和華啊，我寄居在這寡婦家裡，你為什麼降禍給她，奪去她兒子的性命呢？」</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行傳 20:10; 使徒行傳 9:40; 列王紀下 4:33–35"> 他三次伏在孩子身上，求告耶和華說：「我的上帝耶和華啊，求你讓這孩子活過來吧！」</span>
<span className="v" id="v22" data-v="22" data-xref="申命記 32:39; 啟示錄 11:11; 希伯來書 11:35"> 耶和華聽了以利亞的祈求，孩子就活過來了。</span>
<span className="v" id="v23" data-v="23" data-xref="列王紀下 4:36–37; 使徒行傳 9:41; 路加福音 7:15"> 以利亞將孩子從樓上抱下來，進屋交給他母親，說：「看，你兒子活過來了！」</span>
<span className="v" id="v24" data-v="24" data-xref="約翰福音 16:30; 約翰福音 2:11; 約翰福音 3:2"> 婦人對以利亞說：「現在我知道你是上帝的僕人，耶和華藉你口所說的都是真的。」</span>

## 耶和華再次向所羅門顯現

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歷代志下 7:11–6; 列王紀上 9:19; 列王紀上 7:51"> 所羅門建完耶和華的殿、自己的王宮和所有要建的建築後，</span>
<span className="v" id="v2" data-v="2" data-xref="列王紀上 3:5; 歷代志下 7:12; 列王紀上 11:9"> 耶和華像在基遍一樣再次向他顯現，</span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 10:17; 約翰一書 5:14; 列王紀下 20:5"> 對他說：「我聽了你的禱告和祈求。我已使你建的殿成為聖潔之地，讓我的名永在其中，我必一直眷顧和心繫這殿。</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀上 15:5; 列王紀上 3:14; 列王紀上 11:6"> 如果你像你父親大衛一樣存誠實正直的心事奉我，遵行我的一切吩咐，謹守我的律例和典章，</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀上 2:4; 列王紀上 6:12; 撒母耳記下 7:16"> 我必使你的王位在以色列永遠穩固，正如我曾向你父親大衛應許，要使他的王朝永不中斷。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="撒母耳記下 7:14–16; 歷代志上 28:9; 歷代志下 15:2"> 「然而，如果你們及你們的子孫離棄我，不守我的誡命和律例，去供奉、祭拜其他神明，</span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 44:14; 耶利米書 24:9; 申命記 4:26"> 我必把以色列人從我賜給他們的土地上剷除，並離棄我為自己的名而使之聖潔的這殿，使以色列人在萬民中成為笑柄，被人嘲諷。</span>
<span className="v" id="v8" data-v="8" data-xref="申命記 29:24–26; 耶利米書 22:8–9; 歷代志下 7:21"> 這殿雖然宏偉<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古譯本作「這殿必成為一堆廢墟」。">a</a></sup>，但將來經過的人必驚訝，譏笑說，『耶和華為什麼這樣對待這地方和這殿呢？』</span>
<span className="v" id="v9" data-v="9" data-xref="耶利米書 2:19; 耶利米書 5:19; 申命記 29:25–28"> 人們會回答，『因為他們背棄曾領他們祖先離開埃及的他們的上帝耶和華，去追隨、祭拜、供奉其他神明，所以耶和華把這一切災禍降在他們身上。』」</span>
</div>
</div>

## 所羅門的事蹟

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="列王紀上 6:37–1; 歷代志下 8:1–18; 列王紀上 9:1"> 所羅門用二十年興建了耶和華的殿和自己的王宮。</span>
<span className="v" id="v11" data-v="11" data-xref="歷代志下 8:2; 歷代志下 2:16; 歷代志下 2:8–10"> 泰爾王希蘭供應了所羅門所需要的一切香柏木、松木和黃金，所羅門王就把加利利一帶的二十座城送給他。</span>
<span className="v" id="v12" data-v="12" data-xref="民數記 22:34; 士師記 14:3"> 希蘭從泰爾去視察這些城，然後滿心不悅地對所羅門說：</span>
<span className="v" id="v13" data-v="13" data-xref="約書亞記 19:27; 阿摩司書 1:9; 列王紀上 5:1–2"> 「兄弟啊，你送給我的是什麼城邑呀？」因此，他稱這個地區為迦步勒<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="「迦步勒」希伯來文的意思為「沒有價值」。">b</a></sup>，沿用至今。</span>
<span className="v" id="v14" data-v="14" data-xref="列王紀上 9:11; 列王紀上 10:10; 列王紀上 9:28"> 希蘭供應了所羅門王八萬兩金子。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="約書亞記 17:11; 列王紀上 9:24; 撒母耳記下 5:9"> 所羅門徵召勞役興建耶和華的殿、自己的王宮、米羅堡和耶路撒冷的城牆以及夏瑣、米吉多和基色。</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀上 3:1; 列王紀上 9:24; 列王紀上 7:8"> 從前埃及王法老攻陷基色，火燒全城，殺了城內的迦南人，把基色賜予女兒，即所羅門之妻作嫁妝。</span>
<span className="v" id="v17" data-v="17" data-xref="約書亞記 16:3; 約書亞記 21:22; 歷代志下 8:4–18"> 所羅門現在重建基色、下伯·和崙、</span>
<span className="v" id="v18" data-v="18" data-xref="約書亞記 19:44; 歷代志下 8:4"> 巴拉和境內沙漠地區的達莫。</span>
<span className="v" id="v19" data-v="19" data-xref="列王紀上 9:1; 傳道書 6:9; 出埃及記 1:11"> 他還建造所有的儲貨城、屯車城、養馬城，並在耶路撒冷、黎巴嫩及全國隨意興建城邑。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="出埃及記 23:23; 創世記 15:19–21; 申命記 7:1–3"> 當時國中仍有非以色列人，就是亞摩利人、赫人、比利洗人、希未人和耶布斯人的後裔，</span>
<span className="v" id="v21" data-v="21" data-xref="約書亞記 17:12; 士師記 1:21; 約書亞記 15:63"> 以色列人沒能滅絕這些外族人，所羅門讓他們的後代服勞役，至今如此。</span>
<span className="v" id="v22" data-v="22" data-xref="利未記 25:39; 列王紀上 4:1–27; 撒母耳記上 8:11–12"> 所羅門王沒有讓以色列人服勞役，而是讓他們做戰士、官長、統帥、將領、戰車長和騎兵長。</span>
<span className="v" id="v23" data-v="23" data-xref="列王紀上 5:16; 歷代志下 8:10; 歷代志下 2:18"> 他還任命五百五十名監工負責監管工人。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="列王紀上 7:8; 撒母耳記下 5:9; 歷代志下 32:5"> 法老的女兒從大衛城遷到為她建造的宮殿以後，所羅門動工興建米羅堡。</span>
<span className="v" id="v25" data-v="25" data-xref="歷代志下 8:12–13; 歷代志下 8:16; 出埃及記 23:14–17"> 耶和華的殿落成以後，所羅門每年三次在他為耶和華築的壇上獻燔祭、平安祭，並在耶和華面前燒香。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="列王紀上 22:48; 民數記 33:35; 申命記 2:8"> 所羅門王在以東境內的紅海邊、靠近以祿的以旬·迦別製造船隻。</span>
<span className="v" id="v27" data-v="27" data-xref="列王紀上 10:11; 列王紀上 5:6; 列王紀上 5:9"> 希蘭派懂得航海的僕人與所羅門的僕人一起乘船出海。</span>
<span className="v" id="v28" data-v="28" data-xref="歷代志下 8:18; 歷代志上 29:4; 列王紀上 10:11"> 他們前往俄斐，從那裡運回二十八萬兩黃金給所羅門王。</span>
</div>
</div>

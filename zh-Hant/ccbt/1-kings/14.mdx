## 亞希雅對耶羅波安的預言

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及記 20:5; 列王紀上 13:33–34; 撒母耳記上 31:2"> 那時，耶羅波安的兒子亞比雅病了，</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳記上 28:8; 列王紀上 11:29–38; 撒母耳記下 14:2"> 耶羅波安就吩咐妻子：「你喬裝改扮使人認不出你是我妻子，然後去示羅找那位預言我做王的先知亞希雅。</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳記上 9:7–8; 列王紀上 13:7; 列王紀下 4:42"> 你要帶十個餅、一些薄餅和一瓶蜂蜜去，他將告訴你孩子的病情會怎樣。」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="列王紀上 11:29; 撒母耳記上 3:2; 撒母耳記上 4:15"> 耶羅波安的妻子就照他的話做，前往示羅，來到亞希雅家。那時亞希雅因年紀老邁，眼睛已失明。</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀下 6:8–12; 箴言 21:30; 列王紀下 4:27"> 耶和華預先告訴亞希雅說：「耶羅波安的妻子會喬裝成別的婦人，前來問你有關她兒子的病情，你要如此如此回答她。」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="但以理書 5:17–28; 使徒行傳 5:9–10; 路加福音 20:20–23"> 她剛進門，亞希雅聽見她的腳步聲就說：「耶羅波安的妻子啊，你進來吧，為什麼喬裝改扮呢？我奉命告訴你一個噩耗。</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀上 16:2; 撒母耳記下 12:7–8; 撒母耳記上 15:16"> 你回去告訴耶羅波安，『以色列的上帝耶和華說，我從百姓中提升你，立你做我以色列子民的王。</span>
<span className="v" id="v8" data-v="8" data-xref="列王紀上 15:5; 列王紀上 11:33–38; 歷代志下 28:1"> 我把國從大衛家撕開賜給你，你卻沒有像我僕人大衛那樣遵守我的誡命，全心聽從我，做我視為正的事，</span>
<span className="v" id="v9" data-v="9" data-xref="以西結書 23:35; 尼希米記 9:26; 詩篇 50:17"> 反而比前人行惡更甚，為自己設立其他神明，鑄造神像，惹我發怒，把我拋在腦後。</span>
<span className="v" id="v10" data-v="10" data-xref="申命記 32:36; 列王紀上 21:21; 列王紀下 14:26"> 所以，我要降禍給耶羅波安家，從以色列剷除耶羅波安家所有的男子，不論是奴隸還是自由人。我要像清除糞便一樣，把耶羅波安家焚燒淨盡。</span>
<span className="v" id="v11" data-v="11" data-xref="列王紀上 16:4; 耶利米書 15:3; 列王紀上 21:23–24"> 耶羅波安家人中，死在城中的必被狗吃，死在田野的必被鳥吃。這是耶和華說的。』</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="列王紀上 14:3; 列王紀上 14:16–17; 列王紀下 1:6"> 「現在你回家去吧，你一進城，孩子就會死。</span>
<span className="v" id="v13" data-v="13" data-xref="歷代志下 19:3; 歷代志下 12:12; 約伯記 19:28"> 全以色列會為他哀悼，把他埋葬。耶羅波安家人中只有他將得到安葬，因為以色列的上帝耶和華只在他身上看見了良善。</span>
<span className="v" id="v14" data-v="14" data-xref="列王紀上 15:27–29; 以西結書 7:2–7; 以西結書 12:22–28"> 耶和華必為自己立一位君王統治以色列，他必剷除耶羅波安家。現在就是時候了。</span>
<span className="v" id="v15" data-v="15" data-xref="約書亞記 23:15–16; 詩篇 52:5; 列王紀下 15:29"> 耶和華將擊打以色列人，使他們像水中的蘆葦一樣顫抖不已。耶和華將把以色列人從祂賜給他們祖先的佳美之地連根拔起，拋散到幼發拉底河的彼岸，這都是因為他們製造亞舍拉神像，惹耶和華發怒。</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀上 15:34; 列王紀上 16:2; 列王紀上 13:34"> 因為耶羅波安犯罪作孽，使以色列人陷入罪中，耶和華必拋棄以色列。」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="列王紀上 15:33; 列王紀上 16:15; 列王紀上 16:23"> 耶羅波安的妻子動身回到得撒，剛邁過家門檻，孩子就死了。</span>
<span className="v" id="v18" data-v="18" data-xref="列王紀上 14:13"> 以色列人埋葬了他，為他哀悼，正應驗了耶和華藉祂僕人亞希雅先知說的話。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="歷代志下 13:2–20; 歷代志上 27:24; 列王紀上 16:20"> 耶羅波安其他的事，不論文治武功，都記在《以色列列王史》上。</span>
<span className="v" id="v20" data-v="20" data-xref="約伯記 14:12; 詩篇 3:5; 列王紀上 11:43"> 他做王二十二年，然後與祖先同眠。他兒子拿答繼位。</span>
</div>
</div>

## 羅波安做猶大王

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="歷代志下 12:13; 列王紀上 11:36; 列王紀上 14:31"> 所羅門的兒子羅波安做猶大王。他四十一歲登基，在耶和華從以色列各支派中選來立祂名的耶路撒冷城執政十七年。羅波安的母親是亞捫人拿瑪。</span>
<span className="v" id="v22" data-v="22" data-xref="歷代志下 12:1; 哥林多前書 10:22; 詩篇 78:58"> 猶大人做耶和華視為惡的事，他們的罪行比他們祖先所做的更惹耶和華發義怒。</span>
<span className="v" id="v23" data-v="23" data-xref="申命記 12:2; 以賽亞書 57:5; 列王紀下 17:9–10"> 他們在各高崗上和綠樹下為自己建造邱壇，豎立神柱和亞舍拉神像，</span>
<span className="v" id="v24" data-v="24" data-xref="申命記 23:17; 哥林多前書 6:9; 列王紀上 15:12"> 國中甚至男廟妓充斥。猶大人仿效耶和華在以色列人面前趕走的外族人，行各種可憎之事。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="列王紀上 11:40; 歷代志下 12:2–4; 歷代志下 12:9"> 羅波安王執政第五年，埃及王示撒上來攻打耶路撒冷，</span>
<span className="v" id="v26" data-v="26" data-xref="列王紀上 15:18; 歷代志下 9:15–16; 列王紀上 7:51"> 把耶和華殿裡和王宮裡的財寶擄掠一空，包括所羅門製造的所有金盾牌。</span>
<span className="v" id="v27" data-v="27" data-xref="撒母耳記上 8:11; 撒母耳記上 22:17; 列王紀上 18:46"> 羅波安王就造了銅盾牌代替那些金盾牌，交給看守宮門的護衛長看管。</span>
<span className="v" id="v28" data-v="28" data-xref="歷代志下 12:11"> 每次王進耶和華的殿，護衛就帶上盾牌，用完後放回護衛房。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="列王紀上 22:45; 列王紀上 15:23; 列王紀上 14:19"> 羅波安其他的事及一切所為都記在《猶大列王史》上。</span>
<span className="v" id="v30" data-v="30" data-xref="列王紀上 12:24; 列王紀上 12:21; 列王紀上 15:6–7"> 羅波安和耶羅波安之間常有爭戰。</span>
<span className="v" id="v31" data-v="31" data-xref="歷代志下 12:16; 馬太福音 1:7; 列王紀上 15:3"> 羅波安與祖先同眠後，葬在大衛城的祖墳裡。他母親是亞捫人拿瑪。他兒子亞比央繼位。</span>
</div>
</div>

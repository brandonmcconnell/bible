## 建造聖殿

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歷代志下 3:1–2; 使徒行傳 7:47; 歷代志上 29:19"> 所羅門在做以色列王的第四年二月，即西弗月，開始為耶和華建殿。那時正是以色列人離開埃及後第四百八十年。</span>
<span className="v" id="v2" data-v="2" data-xref="以西結書 40:1–41; 以西結書 41:1–15; 啟示錄 21:16–17"> 所羅門王為耶和華建造的殿長二十七米，寬九米，高十三米半。</span>
<span className="v" id="v3" data-v="3" data-xref="歷代志上 28:11; 歷代志下 3:3–4; 以西結書 41:15"> 殿前的門廊和殿一樣寬九米，進深四米半。</span>
<span className="v" id="v4" data-v="4" data-xref="以西結書 40:16; 以西結書 41:26; 以西結書 41:16"> 殿有格子窗戶。</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀上 6:16; 列王紀上 6:19–21; 列王紀上 6:31"> 靠殿牆、圍著外殿和內殿又造了三層廂房，</span>
<span className="v" id="v6" data-v="6"> 底層寬兩米二，中層寬兩米七，上層寬三米一。廂房的橫梁都搭在殿牆突出的地方，免得插入殿牆。</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 27:5–6; 彼得前書 2:5; 出埃及記 20:25"> 建殿的石頭都在採石場鑿好了，建殿的時候聽不到錘子、斧頭或其他鐵器的響聲。</span>
<span className="v" id="v8" data-v="8" data-xref="以西結書 41:6–7"> 底層廂房的進口在殿的南面，沿著一道螺旋樓梯可以通到第二層和第三層。</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀上 6:14; 列王紀上 6:38"> 殿建成後，殿頂裝上香柏木的梁木和木板。</span>
<span className="v" id="v10" data-v="10"> 靠著殿牆所造的廂房每一層高兩米二，用香柏木的梁木與殿牆接連起來。</span>
</div>
</div>

## 耶和華的約

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11"> 耶和華對所羅門說：</span>
<span className="v" id="v12" data-v="12" data-xref="歷代志上 22:10; 歌羅西書 1:23; 列王紀上 3:14"> 「關於你所建的這殿，若你遵行我的律例，順從我的典章，謹守我的一切誡命，我必實現我對你父親大衛的應許。</span>
<span className="v" id="v13" data-v="13" data-xref="申命記 31:6; 出埃及記 25:8; 利未記 26:11"> 我必住在以色列人當中，不拋棄我的以色列子民。」</span>
<span className="v" id="v14" data-v="14" data-xref="列王紀上 6:9; 列王紀上 6:38; 使徒行傳 7:47–48"> 所羅門建造的殿落成了。</span>
<span className="v" id="v15" data-v="15" data-xref="列王紀上 7:7"> 殿裡的牆壁和天花板都鋪上了香柏木，地面都鋪上了松木板。</span>
<span className="v" id="v16" data-v="16" data-xref="歷代志下 3:8; 列王紀上 8:6; 希伯來書 9:3"> 在殿的後部，從地面至天花板用香柏木板隔出長九米的內殿，就是至聖所。</span>
<span className="v" id="v17" data-v="17"> 在至聖所外面是外殿，長十八米。</span>
<span className="v" id="v18" data-v="18" data-xref="列王紀上 7:24"> 殿內全部鋪上香柏木，不露一點石頭，香柏木上刻著野瓜和花朵的圖案。</span>
<span className="v" id="v19" data-v="19" data-xref="列王紀上 8:6–10; 詩篇 28:2; 列王紀上 6:5"> 殿的至聖所用來安放耶和華的約櫃。</span>
<span className="v" id="v20" data-v="20" data-xref="列王紀上 6:2–3; 列王紀上 6:22; 列王紀上 7:48"> 至聖所長、寬和高都是九米，裡面全貼上純金，香柏木造的祭壇也包上純金。</span>
<span className="v" id="v21" data-v="21" data-xref="歷代志下 3:7–9; 歷代志下 3:14–16; 列王紀上 6:5"> 殿內全部貼上純金，至聖所前面有金鏈攔著，至聖所內也都貼上純金。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及記 30:1; 出埃及記 30:3; 歷代志下 3:7–14"> 殿內都貼上純金，至聖所內的祭壇也都包上純金。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及記 37:7–9; 創世記 3:24; 彼得前書 1:12"> 至聖所裡面放著兩個橄欖木造的基路伯天使，各高四米半，</span>
<span className="v" id="v24" data-v="24"> 各有兩個兩米二長的翅膀，雙翅展開，兩翅尖相距四米半。</span>
<span className="v" id="v25" data-v="25"> 兩個基路伯的大小和形狀一模一樣，</span>
<span className="v" id="v26" data-v="26"> 高度都是四米半。</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及記 37:9; 出埃及記 25:20; 歷代志下 5:8"> 他將兩個基路伯安在至聖所內，兩個基路伯展開翅膀，各有一個翅膀在至聖所的中央相接，另一個翅膀的尖端觸到牆壁。</span>
<span className="v" id="v28" data-v="28"> 這兩個基路伯天使也包上金。</span>
<span className="v" id="v29" data-v="29" data-xref="列王紀上 6:32; 詩篇 92:12–15; 歷代志下 4:2–5"> 內殿和外殿的牆壁都刻上基路伯天使、棕樹和花朵的圖案，</span>
<span className="v" id="v30" data-v="30" data-xref="啟示錄 21:18–21; 以賽亞書 60:17; 以賽亞書 54:11–12"> 地板是鋪金的。</span>
<span className="v" id="v31" data-v="31" data-xref="希伯來書 10:19–20; 以弗所書 3:18; 約翰福音 14:6"> 至聖所的門、門楣和門柱都是橄欖木造的，門柱呈五角形。</span>
<span className="v" id="v32" data-v="32" data-xref="列王紀上 6:18; 列王紀上 6:29"> 兩扇用橄欖木造的門上都刻著基路伯天使、棕樹和花朵的圖案，並包上金。</span>
<span className="v" id="v33" data-v="33"> 外殿的四角形門柱也是用橄欖木造的，</span>
<span className="v" id="v34" data-v="34" data-xref="以西結書 41:23–25; 列王紀上 5:8"> 兩扇門是松木造的，每一扇門都分為可折疊的兩片，</span>
<span className="v" id="v35" data-v="35"> 上面刻著基路伯天使、棕樹和花朵的圖案，並均勻地包上金。</span>
<span className="v" id="v36" data-v="36" data-xref="列王紀上 7:12; 歷代志下 7:7; 出埃及記 27:9–19"> 內院的牆是由三層鑿好的石頭和一層香柏木建的。</span>
<span className="v" id="v37" data-v="37" data-xref="列王紀上 6:1; 歷代志下 3:2"> 耶和華的殿在所羅門執政第四年的西弗月奠基，</span>
<span className="v" id="v38" data-v="38" data-xref="以斯拉記 6:14–15; 列王紀上 7:1; 撒迦利亞書 4:9"> 在他執政的第十一年的布勒月，即八月全部按規格建成，歷經七年。</span>
</div>

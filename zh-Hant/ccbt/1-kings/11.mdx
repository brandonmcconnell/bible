## 所羅門背棄上帝

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命記 17:17; 箴言 6:24; 尼希米記 13:23–27"> 除了埃及公主以外，所羅門王還寵愛許多外邦女子，有摩押人、亞捫人、以東人、西頓人和赫人。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 34:16; 申命記 7:3–4; 約書亞記 23:12–13"> 耶和華曾告訴以色列人不可跟這些外族人通婚，免得受引誘去隨從他們的神明，所羅門卻迷戀這些女子。</span>
<span className="v" id="v3" data-v="3" data-xref="傳道書 7:28; 撒母耳記下 5:13–16; 歷代志下 11:21"> 他娶了七百個公主，還有三百個妃嬪。這些女子使他的心背棄耶和華。</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀上 9:4; 列王紀上 8:61; 列王紀上 11:6"> 所羅門年老的時候，他的嬪妃誘惑他的心去追隨其他神明。他沒有像他父親大衛那樣忠心順服他的上帝耶和華。</span>
<span className="v" id="v5" data-v="5" data-xref="士師記 2:13; 列王紀上 11:7; 列王紀下 23:13"> 所羅門追隨西頓人的女神亞斯她錄和亞捫人的可憎神明米勒公。</span>
<span className="v" id="v6" data-v="6" data-xref="民數記 14:24; 約書亞記 14:8; 約書亞記 14:14"> 他做了耶和華視為惡的事，沒有像他父親大衛那樣一心追隨耶和華。</span>
<span className="v" id="v7" data-v="7" data-xref="民數記 21:29; 士師記 11:24; 使徒行傳 7:43"> 在耶路撒冷東面的山上，所羅門為摩押人可憎的神明基抹和亞捫人可憎的神明摩洛修建邱壇。</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多前書 10:11–12; 列王紀上 11:1; 以西結書 16:22–29"> 他又為所有的外邦妃嬪修建邱壇，供她們向自己的神明燒香獻祭。</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀上 9:2; 列王紀上 3:5; 申命記 7:4"> 所羅門背棄了曾兩次向他顯現的以色列的上帝耶和華，違背耶和華的命令去隨從其他神明。所以，耶和華向他發怒，</span>
<span className="v" id="v11" data-v="11" data-xref="列王紀上 12:15–16; 列王紀上 11:31; 列王紀下 17:21"> 說：「你既然違背我的命令，不遵守我的約和律例，我必撕裂你的國，將它賜給你的一個臣僕。</span>
<span className="v" id="v12" data-v="12" data-xref="列王紀下 20:19; 撒母耳記上 9:4–5; 列王紀下 22:19–20"> 然而，因你父大衛的緣故，我不會在你有生之年這樣做，我要從你兒子手中把國撕裂。</span>
<span className="v" id="v13" data-v="13" data-xref="列王紀上 12:20; 申命記 12:11; 列王紀上 11:32"> 但我不會把國全部撕掉，為了我僕人大衛和我揀選的耶路撒冷，我會留下一個支派給你兒子。」</span>
</div>
</div>

## 所羅門的敵人

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="歷代志上 5:26; 詩篇 89:30–34; 以賽亞書 13:17"> 耶和華使以東王的後裔哈達興起，與所羅門為敵。</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳記下 8:14; 歷代志上 18:12–13; 申命記 20:13"> 從前大衛征討以東，元帥約押前去埋葬陣亡的人，將以東的男子都殺了。</span>
<span className="v" id="v16" data-v="16"> 他率領以色列人在那裡住了六個月，直到殺光了以東的男子。</span>
<span className="v" id="v17" data-v="17" data-xref="馬太福音 2:13–14; 出埃及記 2:1–10; 列王紀下 11:2"> 那時，哈達年紀還小，他和他父親的幾個以東臣僕一起逃往埃及。</span>
<span className="v" id="v18" data-v="18" data-xref="民數記 10:12; 申命記 33:2; 申命記 1:1"> 他們從米甸逃到巴蘭，在那裡招聚了一些人，然後又逃到埃及去見埃及王法老。法老賜他糧食、房屋和田地。</span>
<span className="v" id="v19" data-v="19" data-xref="創世記 39:4; 耶利米書 43:7–9; 創世記 39:21"> 法老非常喜歡哈達，將王后答比妮的妹妹許配給他。</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 21:7; 撒母耳記上 1:24"> 他們生了一個兒子，取名叫基努拔，由王后在宮中撫養，跟王子們在一起。</span>
<span className="v" id="v21" data-v="21" data-xref="列王紀上 2:10; 出埃及記 4:19; 馬太福音 2:20"> 後來，哈達在埃及知道大衛已與祖先同眠，約押元帥也死了，就求法老准他回國。</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳記下 18:22–23; 路加福音 22:35; 馬可福音 14:31"> 法老問他：「你為什麼要回國呢？你在我這裡還缺什麼嗎？」哈達答道：「什麼都不缺，但還是求王准我回國。」</span>
<span className="v" id="v23" data-v="23" data-xref="列王紀上 11:14; 撒母耳記下 8:3; 撒母耳記下 10:15–18"> 上帝又使以利亞大的兒子利遜興起，與所羅門為敵。這人是從他主人瑣巴王哈大底謝身邊逃走的。</span>
<span className="v" id="v24" data-v="24" data-xref="撒母耳記下 10:8; 撒母耳記下 10:18; 列王紀上 20:34"> 在大衛征服瑣巴人之後，利遜招聚了一群匪徒，自己做頭目。利遜又前往大馬士革，在那裡做王。</span>
<span className="v" id="v25" data-v="25" data-xref="歷代志下 15:2; 詩篇 106:40; 列王紀上 5:4"> 所羅門活著的時候，哈達和利遜不斷為患。利遜統治亞蘭，他憎恨以色列人。</span>
</div>
</div>

## 耶羅波安叛變

<div className="bt">
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="歷代志下 13:6; 列王紀上 12:2; 列王紀上 11:28"> 所羅門的一個臣僕耶羅波安也叛變了。他是以法蓮支派洗利達人尼八的兒子，母親洗魯阿是個寡婦。</span>
<span className="v" id="v27" data-v="27" data-xref="列王紀上 9:24; 列王紀上 9:15; 箴言 30:32"> 以下是他反叛所羅門的緣由： 所羅門當年建造米羅堡，修補大衛城的城牆時，</span>
<span className="v" id="v28" data-v="28" data-xref="箴言 22:29; 撒母耳記下 19:20; 士師記 1:22–23"> 發現年輕的耶羅波安勤奮能幹，就提拔他監管約瑟家族的一切工程。</span>
<span className="v" id="v29" data-v="29" data-xref="列王紀上 12:15; 列王紀上 14:2; 歷代志下 9:29"> 有一次，耶羅波安出了耶路撒冷，在路上遇見身披新衣的示羅人亞希雅先知。當時野外只有他們二人。</span>
<span className="v" id="v30" data-v="30" data-xref="撒母耳記上 15:27–28; 撒母耳記上 24:4–5"> 亞希雅將身上的新衣撕作十二片，</span>
<span className="v" id="v31" data-v="31" data-xref="列王紀上 11:11–12"> 對耶羅波安說：「你可以拿十片。以色列的上帝耶和華說，『我必從所羅門手裡撕裂這國，把十個支派賜給你。</span>
<span className="v" id="v32" data-v="32" data-xref="列王紀上 11:13; 列王紀上 12:20–21; 列王紀上 14:21"> 然而，為了我僕人大衛和我在以色列各支派中揀選的耶路撒冷城，我會留下一個支派給所羅門。</span>
<span className="v" id="v33" data-v="33" data-xref="列王紀上 11:9; 列王紀上 11:5–7; 列王紀上 9:5–7"> 所羅門背棄了我，去祭拜西頓人的女神亞斯她錄、摩押的神明基抹、亞捫人的神明米勒公。他沒有遵行我的道，沒有做我視為正的事，也不像他父親大衛那樣遵守我的律例和典章。</span>
<span className="v" id="v34" data-v="34" data-xref="列王紀上 11:12–13; 列王紀上 11:31; 約伯記 11:6"> 然而，我不會奪走他整個國，我會讓他終生為王，因為我所揀選的僕人大衛遵守我的誡命和律法。</span>
<span className="v" id="v35" data-v="35" data-xref="列王紀上 12:20; 列王紀上 11:12; 出埃及記 20:5–6"> 我必從他兒子手中把國奪走，將十個支派賜給你，</span>
<span className="v" id="v36" data-v="36" data-xref="列王紀下 8:19; 列王紀上 11:13; 列王紀上 15:4"> 只給他兒子留下一個支派，好使我僕人大衛在我面前，在我選為居所的耶路撒冷城常有一盞燈。</span>
<span className="v" id="v37" data-v="37" data-xref="申命記 14:26; 列王紀上 11:26; 撒母耳記下 3:21"> 我要讓你做王，使你隨心所願地統治以色列。</span>
<span className="v" id="v38" data-v="38" data-xref="撒母耳記下 7:11; 約書亞記 1:5; 申命記 31:8"> 若你像我僕人大衛一樣聽從我的一切吩咐，遵行我的道，做我視為正的事，遵守我的律例誡命，我就與你同在，鞏固你的王朝，像鞏固大衛的王朝一樣，使你統治以色列。</span>
<span className="v" id="v39" data-v="39" data-xref="路加福音 1:32–33; 路加福音 2:11; 以賽亞書 11:1–10"> 因所羅門的所作所為，我必讓大衛的後裔遭難，但不會永遠如此。』」</span>
<span className="v" id="v40" data-v="40" data-xref="歷代志下 12:2–9; 以賽亞書 14:24–27; 耶利米哀歌 3:37"> 所羅門想殺耶羅波安，他就逃到埃及投奔埃及王示撒，在那裡一直住到所羅門過世。</span>
<span className="v" id="v41" data-v="41" data-xref="歷代志下 9:29–31"> 所羅門其他的事蹟、作為和智慧都記在《所羅門記》上了。</span>
<span className="v" id="v42" data-v="42" data-xref="列王紀上 2:11"> 所羅門在耶路撒冷統治整個以色列四十年，</span>
<span className="v" id="v43" data-v="43" data-xref="列王紀下 21:18; 列王紀上 2:10; 馬太福音 1:7"> 他與祖先同眠後葬在他父親大衛的城裡。他兒子羅波安繼位。</span>
</div>
</div>

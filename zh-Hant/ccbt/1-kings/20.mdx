## 亞蘭王攻打撒瑪利亞城

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀上 15:18; 列王紀上 15:20; 列王紀上 22:31"> 亞蘭王便·哈達率領全軍，聯合三十二個王，帶著車馬圍攻撒瑪利亞。</span>
<span className="v" id="v2" data-v="2" data-xref="以賽亞書 36:2–22; 列王紀下 19:9; 以賽亞書 37:9–10"> 他派遣使者進城對以色列王亞哈說：</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 15:9; 以賽亞書 10:13–14"> 「便·哈達說，『你的金銀和你家中最美的妻妾兒女都是我的。』」</span>
<span className="v" id="v4" data-v="4" data-xref="士師記 15:11–13; 申命記 28:48; 撒母耳記上 13:6–7"> 以色列王說：「我主我王啊，我答應你的要求，我和我的一切都是你的。」</span>
<span className="v" id="v5" data-v="5"> 不久，使者又來對他說：「便·哈達說，『我已派人吩咐你把金銀、妻妾和兒女都給我。</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米書 25:34; 約珥書 3:5; 列王紀下 18:31–32"> 明天約這個時候，我會派屬下搜查你的王宮和你臣僕的家，他們要拿走你珍愛的一切。』」</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀下 5:7; 箴言 6:14; 列王紀上 8:1"> 以色列王亞哈召集國中的長老，說：「你們看，這人是在找麻煩。他之前派人來要我的妻妾、孩子和金銀，我沒有拒絕他。」</span>
<span className="v" id="v8" data-v="8"> 長老和百姓都說：「別聽從他，別答應他。」</span>
<span className="v" id="v9" data-v="9"> 於是，他對使者說：「你們告訴我主我王，他第一次所要的，僕人可以照辦，但這一次所要的，僕人不能從命。」使者就去回覆便·哈達。</span>
<span className="v" id="v10" data-v="10" data-xref="列王紀上 19:2; 出埃及記 11:8; 列王紀下 19:23–24"> 便·哈達又派人去對亞哈說：「若撒瑪利亞的塵土夠我的士兵每人抓一把，願神明重重地懲罰我。」</span>
<span className="v" id="v11" data-v="11" data-xref="箴言 27:1; 以賽亞書 10:15–16; 撒母耳記上 17:44–47"> 以色列王說：「你去告訴便·哈達，叫他別剛穿上盔甲就誇口，打完仗卸下盔甲再誇口吧。」</span>
<span className="v" id="v12" data-v="12" data-xref="列王紀上 16:9; 列王紀上 20:16; 箴言 31:4–5"> 便·哈達和諸王正在營中飲酒，聽見這話，就吩咐屬下準備攻城。</span>
</div>
</div>

## 亞哈打敗便·哈達

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="列王紀上 20:28; 以西結書 20:22; 以賽亞書 7:1–9"> 一位先知來見以色列王亞哈，說：「耶和華說，『你看見這大軍了嗎？今天我必將他們交在你手裡，這樣你就知道我是耶和華。』」</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳記上 17:50; 創世記 14:14–16; 列王紀上 18:44"> 亞哈問：「誰來完成這任務呢？」先知答道：「耶和華說，省長屬下的青年軍。」亞哈問：「誰來做統領呢？」先知答道：「你。」</span>
<span className="v" id="v15" data-v="15" data-xref="士師記 7:16; 撒母耳記上 14:2; 士師記 7:7"> 於是，亞哈召集了省長屬下的青年軍二百三十二人，又召集以色列全軍，共七千人。</span>
<span className="v" id="v16" data-v="16" data-xref="傳道書 10:16–17; 何西阿書 4:11; 列王紀上 16:9"> 中午，便·哈達正跟盟軍的三十二個王在營中狂飲的時候，亞哈率軍出發了。</span>
<span className="v" id="v17" data-v="17" data-xref="列王紀上 20:14–15; 列王紀上 20:19"> 省長屬下的青年軍率先出城。便·哈達派出的巡邏隊稟告他說：「有人從撒瑪利亞城出來了。」</span>
<span className="v" id="v18" data-v="18" data-xref="列王紀下 14:8–12; 撒母耳記上 14:11–12; 箴言 18:12"> 便·哈達說：「不管他們是來求和還是求戰，都要生擒他們！」</span>
<span className="v" id="v19" data-v="19"> 省長屬下的青年軍率先出城，大軍緊隨其後，</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳記上 30:16–17; 列王紀下 19:36; 傳道書 9:11"> 他們見敵人就殺。亞蘭人敗逃，以色列人乘勢追擊。亞蘭王便·哈達騎著馬與一些騎兵落荒而逃。</span>
<span className="v" id="v21" data-v="21" data-xref="列王紀下 3:18; 士師記 3:28; 列王紀下 3:24"> 以色列王出城攻擊敵軍車馬，重創亞蘭人。</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳記下 11:1; 列王紀上 20:26; 列王紀上 20:13"> 先知又來見以色列王，說：「你要加強防衛，做好準備，因為明年春天亞蘭王必捲土重來。」</span>
<span className="v" id="v23" data-v="23" data-xref="列王紀上 14:23; 撒母耳記上 4:8; 詩篇 50:21–22"> 臣僕給亞蘭王獻計說：「以色列人的神明是山神，所以他們佔了上風，我們若在平原上跟他們交戰，一定會取勝。</span>
<span className="v" id="v24" data-v="24" data-xref="列王紀上 22:31; 箴言 21:30; 列王紀上 20:16"> 王應該撤去諸王，委任將領代替他們，</span>
<span className="v" id="v25" data-v="25" data-xref="詩篇 10:3"> 再招募軍兵，補充失去的戰車和人馬，好在平原上跟他們交戰，這樣我們一定會取勝。」王採納了他們的建議。</span>
<span className="v" id="v26" data-v="26" data-xref="列王紀下 13:17; 列王紀上 20:22; 撒母耳記上 4:1"> 第二年春天，便·哈達召集亞蘭人進軍亞弗，攻打以色列人。</span>
<span className="v" id="v27" data-v="27" data-xref="士師記 6:5; 撒母耳記上 13:5–8; 撒母耳記上 14:2"> 以色列人也召集軍隊，準備糧草，迎戰亞蘭人。他們在亞蘭人對面安營，像兩小群山羊，而亞蘭人卻滿山遍野。</span>
<span className="v" id="v28" data-v="28" data-xref="列王紀上 20:13; 列王紀上 17:18; 以西結書 12:16"> 有位上帝的僕人來見以色列王，說：「耶和華說，『亞蘭人以為我耶和華是山神，不是平原的神，所以我必將這大軍交在你手裡，這樣你們就知道我是耶和華。』」</span>
<span className="v" id="v29" data-v="29" data-xref="歷代志下 13:17; 歷代志下 28:6; 詩篇 10:16"> 以色列人和亞蘭人兩軍對峙，一連七天。第七天，兩軍交戰，以色列軍一天殺了十萬亞蘭步兵，</span>
<span className="v" id="v30" data-v="30" data-xref="列王紀上 22:25; 歷代志下 18:24; 列王紀上 20:26"> 殘餘的人都逃進亞弗城，但城牆倒塌壓死了兩萬七千人。便·哈達也逃進城，躲在一間房子的內室裡。</span>
<span className="v" id="v31" data-v="31" data-xref="撒母耳記下 3:31; 創世記 37:34; 列王紀上 20:23"> 臣僕對他說：「我們聽說以色列王很仁慈。現在，我們不如腰束麻布，頭套繩索，向以色列王請降，也許他會饒王一命。」</span>
<span className="v" id="v32" data-v="32" data-xref="列王紀上 20:3–6; 約伯記 12:17–18; 但以理書 5:20–23"> 他們便腰束麻布，頭套繩索，來見以色列王，說：「僕人便·哈達求王開恩饒命啊！」亞哈回答說：「他還活著嗎？他是我的兄弟。」</span>
<span className="v" id="v33" data-v="33" data-xref="路加福音 16:8; 列王紀下 10:15; 箴言 25:13"> 他們聽見亞哈的口氣溫和，連忙附和說：「是啊，便·哈達是王的兄弟。」亞哈便吩咐他們去把便·哈達帶來見他，然後讓便·哈達登上他的戰車。</span>
<span className="v" id="v34" data-v="34" data-xref="列王紀上 15:20; 以賽亞書 26:10; 列王紀上 20:42"> 便·哈達對亞哈說：「我必歸還我父親從你父親那裡奪來的城邑，你可以在大馬士革設立貿易區，就像我父親在撒瑪利亞所設立的一樣。」亞哈回答說：「你依此立個約，我就放你走。」立約之後，亞哈就放便·哈達走了。</span>
</div>
</div>

## 先知責備亞哈

<div className="bt">
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="列王紀下 2:15; 列王紀上 13:17–18; 列王紀下 4:1"> 眾先知中有一位奉耶和華的命令對他的同伴說：「你打我吧！」同伴卻不肯動手。</span>
<span className="v" id="v36" data-v="36" data-xref="列王紀上 13:21–24; 列王紀上 13:26; 撒母耳記上 15:22–23"> 那位先知就對他說：「你既然不聽從耶和華的吩咐，你一離開我，就會被獅子咬死。」那同伴走後，果然遇見獅子，被咬死了。</span>
<span className="v" id="v37" data-v="37" data-xref="出埃及記 21:12; 列王紀上 20:35"> 那先知又找了一個人，叫那人打他，那人就打他，把他打傷了。</span>
<span className="v" id="v38" data-v="38" data-xref="列王紀上 14:2; 馬太福音 6:16; 列王紀上 22:30"> 先知用頭巾蒙著眼睛，喬裝改扮，在路旁等候亞哈王。</span>
<span className="v" id="v39" data-v="39" data-xref="列王紀下 10:24; 約伯記 36:18; 彼得前書 1:18–19"> 亞哈王經過的時候，他向王喊道：「僕人在打仗的時候，有人押來一個俘虜，要我看管，他說如果俘虜跑掉，我就要以性命抵償，或賠償六百八十兩銀子。</span>
<span className="v" id="v40" data-v="40" data-xref="撒母耳記下 12:5–7; 馬太福音 25:24–27; 約伯記 15:6"> 可是那俘虜趁僕人忙亂之際跑掉了。」以色列王說：「這是你自己的過失，你要自負其咎。」</span>
<span className="v" id="v41" data-v="41" data-xref="耶利米書 6:26; 撒母耳記下 13:19; 約伯記 2:8"> 先知立刻拿去蒙眼的頭巾，以色列王認出他是個先知。</span>
<span className="v" id="v42" data-v="42" data-xref="列王紀上 22:31–37; 歷代志下 18:33–34; 列王紀上 20:39"> 他對王說：「耶和華說，『你放走了我決定要毀滅的人，所以你的命要抵他的命，你百姓的命要抵他百姓的命。』」</span>
<span className="v" id="v43" data-v="43" data-xref="列王紀上 21:4; 以斯帖記 5:13; 以斯帖記 6:12–13"> 以色列王悶悶不樂地回撒瑪利亞的王宮去了。</span>
</div>

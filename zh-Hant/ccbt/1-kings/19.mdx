## 以利亞逃亡

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀上 18:40; 列王紀上 21:25; 列王紀上 21:5–7"> 亞哈把以利亞做的一切事，以及他怎樣用刀殺掉所有巴力先知的經過，都告訴了耶洗別，</span>
<span className="v" id="v2" data-v="2" data-xref="路得記 1:17; 列王紀下 6:31; 列王紀上 20:10"> 耶洗別就派使者去告訴以利亞，說：「明天這個時候，我若不使你像那些人一樣喪命，願神明重重地懲罰我。」</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="創世記 21:31; 馬太福音 26:70–74; 馬太福音 26:56"> 以利亞很害怕，連忙逃命，來到猶大的別示巴。他讓僕人留在那裡，</span>
<span className="v" id="v4" data-v="4" data-xref="約拿書 4:3; 民數記 11:15; 約拿書 4:8"> 自己在曠野走了一天的路程，來到一棵羅騰樹下，坐下來禱告求死，說：「耶和華啊，我受夠了，求你取走我的性命吧，我不比我的祖先強。」</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 34:7; 使徒行傳 12:7; 希伯來書 13:5"> 他躺在樹下睡著了。有一位天使拍醒他，說：「起來吃東西吧。」</span>
<span className="v" id="v6" data-v="6" data-xref="列王紀上 17:6; 馬太福音 4:11; 馬太福音 6:32"> 他睜開眼睛，見頭邊有用炭火烤好的餅和一瓶水。他吃喝完畢，又躺下來。</span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 103:13–14; 申命記 33:25"> 耶和華的天使第二次來拍醒他，說：「起來吃東西吧，你還要走很遠的路。」</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及記 34:28; 出埃及記 24:18; 出埃及記 3:1"> 以利亞起來吃喝，靠著食物補充的體力走了四十晝夜，來到上帝的山，就是何烈山。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="列王紀上 19:13; 出埃及記 33:21–22; 耶利米書 2:18"> 他進了一個山洞，在裡面過夜。耶和華就問他：「以利亞，你在這裡做什麼？」</span>
<span className="v" id="v10" data-v="10" data-xref="列王紀上 18:4; 列王紀上 18:22; 出埃及記 34:14"> 以利亞回答說：「我一向對萬軍之上帝耶和華忠貞不渝。但以色列人背棄你的約，拆毀你的祭壇，殘殺你的先知。現在只剩下我一個人，他們還要殺我。」</span>
<span className="v" id="v11" data-v="11" data-xref="以西結書 1:4; 詩篇 50:3; 約伯記 38:1"> 耶和華說：「你出來站在山上，站在我面前。」耶和華從那裡經過時，疾風大作，劈山碎石，但耶和華不在風中。疾風過後又有地震，但耶和華不在其中。</span>
<span className="v" id="v12" data-v="12" data-xref="約伯記 4:16; 撒迦利亞書 4:6; 申命記 4:33"> 地震之後又有火，但耶和華也不在火中。之後，傳來微小的聲音。</span>
<span className="v" id="v13" data-v="13" data-xref="列王紀上 19:9; 以賽亞書 6:2; 創世記 16:8"> 以利亞聽見後，就用外袍蒙著臉出去站在洞口。這時有個聲音問他：「以利亞，你在這裡做什麼？」</span>
<span className="v" id="v14" data-v="14" data-xref="列王紀上 19:9–10; 耶利米書 22:9; 以賽亞書 62:1"> 以利亞回答說：「我一向對萬軍之上帝耶和華忠貞不渝。但以色列人背棄你的約，拆毀你的祭壇，殘殺你的先知。現在只剩下我一個人，他們還要殺我。」</span>
<span className="v" id="v15" data-v="15" data-xref="以賽亞書 45:1; 耶利米書 1:10; 列王紀下 8:7–15"> 耶和華吩咐他說：「你原路返回，前往大馬士革附近的曠野，到了之後要膏立哈薛做亞蘭王。</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀下 9:1–14; 列王紀上 19:19–21; 列王紀下 2:9"> 然後要膏立寧示的孫子耶戶做以色列王，還要膏立亞伯·米何拉人沙法的兒子以利沙做先知來接替你。</span>
<span className="v" id="v17" data-v="17" data-xref="列王紀下 13:22; 列王紀下 8:12; 列王紀下 13:3"> 將來從哈薛刀下逃生的，必被耶戶所殺；從耶戶刀下逃生的，必被以利沙所殺。</span>
<span className="v" id="v18" data-v="18" data-xref="羅馬書 11:4–5; 以賽亞書 1:9; 以賽亞書 10:20–22"> 此外，我在以色列留下七千人，他們都未曾跪拜巴力，也未曾親吻巴力。」</span>
</div>
</div>

## 呼召以利沙

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="列王紀下 2:8; 列王紀下 2:13–14; 撒母耳記上 28:14"> 於是，以利亞離開那裡，找到沙法的兒子以利沙，當時他正在耕田。他前面有十二對牛，他正趕著第十二對。以利亞走過以利沙身邊時，將自己的外袍搭在他身上。</span>
<span className="v" id="v20" data-v="20" data-xref="馬太福音 8:21–22; 路加福音 9:61–62; 使徒行傳 20:37"> 以利沙就撇下牛，追上以利亞說：「請你讓我先回去與父母親吻道別，再跟你走吧。」以利亞說：「你回去吧，別忘了我剛才對你做的事。」</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳記下 24:22; 提摩太後書 4:11; 腓利門書 1:13"> 以利沙就回去了。他宰了兩頭耕牛，用耕具作柴煮肉分給眾人，然後去跟隨以利亞，服侍他。</span>
</div>
</div>

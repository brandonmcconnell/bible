## 米該雅先知警告亞哈王

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀上 20:34"> 亞蘭和以色列之間三年無戰事。</span>
<span className="v" id="v2" data-v="2" data-xref="列王紀上 15:24; 列王紀上 22:1; 列王紀上 22:41"> 第三年，猶大王約沙法來見以色列王亞哈。</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 4:43; 列王紀上 4:13; 約書亞記 21:38"> 以色列王對臣僕說：「你們都知道基列的拉末是我們的領土，我們豈能坐視不理，不從亞蘭王手中奪回來呢？」</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀下 3:7; 以弗所書 5:11; 約翰二書 1:11"> 他問約沙法：「你願意跟我一起去攻打基列的拉末嗎？」約沙法回答說：「你我不分彼此，我的民就是你的民，我的馬就是你的馬。」</span>
<span className="v" id="v5" data-v="5" data-xref="箴言 3:5–6; 歷代志下 18:4–5; 耶利米書 42:2–6"> 約沙法又對以色列王說：「你要先求問耶和華。」</span>
<span className="v" id="v6" data-v="6" data-xref="列王紀上 18:19; 耶利米書 23:14–17; 以西結書 13:7–16"> 於是，以色列王召來約四百名先知，問他們：「我該去攻打基列的拉末嗎？」他們說：「去吧，主必把那城交在王手中。」</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀下 3:11–13; 歷代志下 18:6–7"> 但約沙法問：「這裡沒有耶和華的先知供我們求問嗎？」</span>
<span className="v" id="v8" data-v="8" data-xref="阿摩司書 5:10; 約翰福音 3:19–21; 約翰福音 7:7"> 以色列王回答說：「還有一個人，是音拉的兒子米該雅，我們可以託他求問耶和華。可是我厭惡他，因為他給我的預言都是有兇無吉。」約沙法說：「王不要這樣說。」</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀下 9:32; 以賽亞書 39:7; 列王紀上 22:26–27"> 以色列王召來一名內侍，說：「你快把音拉的兒子米該雅帶來。」</span>
<span className="v" id="v10" data-v="10" data-xref="以斯帖記 5:1; 以斯帖記 6:8–9; 列王紀上 18:29"> 以色列王和猶大王約沙法身穿朝服，坐在撒瑪利亞城門前麥場的寶座上，眾先知都在他們面前說預言。</span>
<span className="v" id="v11" data-v="11" data-xref="撒迦利亞書 1:18–21; 申命記 33:17; 以西結書 22:27–28"> 基拿拿的兒子西底迦造了兩隻鐵角，說：「耶和華這樣說，『你必用這鐵角牴亞蘭人，直到毀滅他們。』」</span>
<span className="v" id="v12" data-v="12" data-xref="歷代志下 35:22; 列王紀上 22:6–15; 列王紀上 22:32–36"> 所有的先知也都預言說：「去攻打基列的拉末吧，一定得勝，耶和華必將那城交在王的手中。」</span>
<span className="v" id="v13" data-v="13" data-xref="彌迦書 2:6–7; 詩篇 11:1; 以賽亞書 30:10–11"> 去召米該雅的使者對米該雅說：「眾先知都異口同聲地向王說吉言，你也像他們一樣說些吉言吧。」</span>
<span className="v" id="v14" data-v="14" data-xref="民數記 24:13; 民數記 22:18; 歷代志下 18:12–13"> 米該雅回答說：「我憑永活的耶和華起誓，耶和華對我說什麼，我就說什麼。」</span>
<span className="v" id="v15" data-v="15" data-xref="列王紀上 18:27; 士師記 10:14; 馬太福音 26:45"> 米該雅來到王面前，王就問他：「米該雅啊，我們該不該去攻打基列的拉末？」米該雅回答說：「上去攻打吧，一定得勝，耶和華必將那城交在王手中。」</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行傳 19:13; 馬太福音 26:63; 約書亞記 6:26"> 王卻說：「我要你起誓多少次，你才肯奉耶和華的名對我說實話呢？」</span>
<span className="v" id="v17" data-v="17" data-xref="民數記 27:17; 馬太福音 9:36; 列王紀上 22:34–36"> 米該雅說：「我看見以色列人都四散在山上，好像沒有牧人的羊群一樣。耶和華說，『這些人沒有主人，讓他們各自平安地回家去吧。』」</span>
<span className="v" id="v18" data-v="18" data-xref="列王紀上 22:8; 箴言 10:24; 路加福音 11:45"> 以色列王對約沙法說：「我不是告訴過你嗎？他給我的預言都是有兇無吉。」</span>
<span className="v" id="v19" data-v="19" data-xref="約伯記 2:1; 約伯記 1:6; 但以理書 7:9–10"> 米該雅說：「你要聽耶和華的話。我看見耶和華坐在寶座上，眾天軍侍立在祂左右。</span>
<span className="v" id="v20" data-v="20" data-xref="以西結書 14:9; 約伯記 12:16; 耶利米書 4:10"> 耶和華說，『誰願意去引誘亞哈到基列的拉末去送死呢？』眾天軍議論紛紛。</span>
<span className="v" id="v21" data-v="21" data-xref="約伯記 2:1; 列王紀上 22:23; 約伯記 1:6–7"> 後來，有一個靈站出來對耶和華說他願意去。</span>
<span className="v" id="v22" data-v="22" data-xref="士師記 9:23; 撒母耳記上 19:9; 撒母耳記上 16:14"> 耶和華問他用什麼方法，他說，『我要去做謊言之靈，進入他眾先知的口中。』耶和華說，『你必成功誘騙他，就這樣做吧。』</span>
<span className="v" id="v23" data-v="23" data-xref="以西結書 14:9; 馬太福音 24:24–25; 以賽亞書 44:20"> 現在，耶和華已經把謊言之靈放進你這些先知口中，耶和華已決意降禍給你。」</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行傳 23:2; 耶利米哀歌 3:30; 彌迦書 5:1"> 基拿拿的兒子西底迦聽了米該雅的話就上前打他的臉，說：「耶和華的靈怎會離開我向你說話呢？」</span>
<span className="v" id="v25" data-v="25" data-xref="列王紀上 20:30; 彼得後書 2:1; 啟示錄 19:20"> 米該雅說：「你躲進密室的那天就知道了。」</span>
<span className="v" id="v26" data-v="26"> 以色列王下令說：「把米該雅交給亞們總督和約阿施王子，</span>
<span className="v" id="v27" data-v="27" data-xref="歷代志下 16:10; 歷代志下 18:25–27; 啟示錄 2:10"> 告訴他們，『王說，要把這人關在監牢，只給他一點餅和水，直到我平安回來。』」</span>
<span className="v" id="v28" data-v="28" data-xref="民數記 16:29; 彌迦書 1:2; 使徒行傳 13:10–11"> 米該雅說：「你若能平安回來，耶和華就沒有藉著我說話。」他又說：「眾民啊，你們都要記住我的話。」</span>
</div>

## 亞哈之死

<div className="bt">
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="歷代志下 18:28; 列王紀上 22:2–9"> 以色列王和猶大王約沙法出兵攻打基列的拉末。</span>
<span className="v" id="v30" data-v="30" data-xref="歷代志下 35:22; 耶利米書 23:24; 撒母耳記上 28:8"> 以色列王對約沙法說：「我要改裝上陣，你就穿王袍吧。」以色列王就改裝上陣。</span>
<span className="v" id="v31" data-v="31" data-xref="列王紀上 20:24; 歷代志下 18:30; 耶利米書 16:6"> 亞蘭王已經吩咐他的三十二名戰車長不要跟對方的大小軍兵交鋒，只攻擊以色列王。</span>
<span className="v" id="v32" data-v="32" data-xref="箴言 13:20; 約拿書 2:1–2; 詩篇 130:1–4"> 戰車長看見約沙法，以為他就是以色列王，便轉過來攻擊他。約沙法高聲喊叫，</span>
<span className="v" id="v33" data-v="33" data-xref="詩篇 76:10; 列王紀上 22:31"> 戰車長見他不是以色列王，便不再追殺他。</span>
<span className="v" id="v34" data-v="34" data-xref="歷代志下 35:23; 彌迦書 6:13; 撒母耳記上 17:49"> 有人隨手放了一箭，射進了以色列王的鎧甲縫中。王對駕車的說：「調轉車頭拉我離開戰場吧，我受了重傷。」</span>
<span className="v" id="v35" data-v="35" data-xref="列王紀上 22:28; 列王紀上 20:42"> 那天的戰事非常激烈，王被人扶著站在車上，迎戰亞蘭人。到了黃昏，王就死了，車上流滿了血。</span>
<span className="v" id="v36" data-v="36" data-xref="列王紀下 14:12; 列王紀上 22:31; 士師記 21:24"> 太陽快要下山的時候，以色列軍中傳出號令，叫人各回本鄉本城。</span>
<span className="v" id="v37" data-v="37"> 王死後，眾人把王的屍體運回撒瑪利亞安葬，</span>
<span className="v" id="v38" data-v="38" data-xref="列王紀上 21:19; 馬太福音 24:35; 耶利米書 44:21–23"> 並在撒瑪利亞妓女洗浴的池邊洗他的戰車，有狗來舔他的血，正如耶和華所言。</span>
<span className="v" id="v39" data-v="39" data-xref="阿摩司書 3:15; 以西結書 27:6; 詩篇 45:8"> 亞哈其他的事及一切所為，包括他建造的象牙宮和各城邑，都記在《以色列列王史》上。</span>
<span className="v" id="v40" data-v="40" data-xref="撒母耳記下 7:12; 列王紀下 1:17; 列王紀下 1:2"> 亞哈與祖先同眠後，他兒子亞哈謝繼位。</span>
</div>
</div>

## 約沙法做猶大王

<div className="bt">
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="歷代志下 20:31; 列王紀上 22:2; 歷代志下 17:1"> 以色列王亞哈執政第四年，亞撒的兒子約沙法登基做猶大王。</span>
<span className="v" id="v42" data-v="42" data-xref="列王紀下 1:17; 列王紀上 15:2; 列王紀上 15:10"> 約沙法三十五歲登基，在耶路撒冷執政二十五年。他母親叫阿蘇巴，是示利希的女兒。</span>
<span className="v" id="v43" data-v="43" data-xref="列王紀上 15:14; 列王紀下 12:3; 箴言 4:27"> 約沙法事事效法他父親亞撒，不偏不離，做耶和華視為正的事。但他沒有拆除邱壇，人們仍在那裡獻祭燒香。</span>
<span className="v" id="v44" data-v="44" data-xref="列王紀上 22:2; 歷代志下 19:2; 列王紀下 8:18"> 約沙法與以色列王修好。</span>
<span className="v" id="v45" data-v="45" data-xref="列王紀上 14:29; 列王紀上 11:41; 歷代志下 20:34"> 約沙法其他的事蹟、功業和戰績都記在《猶大列王史》上。</span>
<span className="v" id="v46" data-v="46" data-xref="列王紀上 15:12; 列王紀上 14:24; 申命記 23:17"> 約沙法從國中除掉了他父親亞撒時代遺留的男廟妓。</span>
<span className="v" id="v47" data-v="47" data-xref="撒母耳記下 8:14; 列王紀下 3:9; 列王紀下 8:20"> 那時以東沒有王，由總督治理。</span>
<span className="v" id="v48" data-v="48" data-xref="列王紀上 9:26; 列王紀上 10:22; 列王紀上 9:28"> 約沙法又建造了一批他施船，要到俄斐去運載黃金，可是沒有成行，因為船隻在以旬·迦別壞了。</span>
<span className="v" id="v49" data-v="49"> 後來，亞哈的兒子亞哈謝請求約沙法讓他的人跟約沙法的人一起出海，但約沙法拒絕了。</span>
<span className="v" id="v50" data-v="50" data-xref="歷代志下 21:1; 列王紀上 22:40; 列王紀上 15:24"> 約沙法與祖先同眠後葬在大衛城他的祖墳裡。他兒子約蘭繼位。</span>
</div>
</div>

## 亞哈謝做以色列王

<div className="bt">
<div className="bp">
<span className="v" id="v51" data-v="51" data-xref="列王紀下 1:17; 列王紀上 22:40; 列王紀上 15:25"> 猶大王約沙法執政第十七年，亞哈的兒子亞哈謝在撒瑪利亞登基做以色列王，執政兩年。</span>
<span className="v" id="v52" data-v="52" data-xref="列王紀上 15:26; 列王紀上 21:25; 啟示錄 3:20"> 他做耶和華視為惡的事，步他父母的後塵，效法尼八之子耶羅波安，使以色列人陷入罪中。</span>
<span className="v" id="v53" data-v="53" data-xref="列王紀上 16:30–32; 以賽亞書 65:3; 列王紀下 3:2"> 他像他父親一樣供奉、祭拜巴力，惹以色列的上帝耶和華發怒。</span>
</div>

## 葡萄園事件

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士師記 6:33; 歷代志下 28:22; 約書亞記 19:18"> 這事以後，又發生了一件事。耶斯列人拿伯在耶斯列有個葡萄園，在撒瑪利亞王亞哈的王宮附近。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳記上 8:14; 雅各書 1:14–15; 提摩太前書 6:9"> 一天，亞哈對拿伯說：「你的葡萄園靠近我的王宮，你把它讓給我作菜園吧。我可以用更好的葡萄園來跟你交換，如果你願意，我也可以按價付你錢。」</span>
<span className="v" id="v3" data-v="3" data-xref="民數記 36:7; 利未記 25:23; 以西結書 46:18"> 拿伯說：「耶和華不准我把祖先的產業讓給你。」</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀上 20:43; 雅各書 1:14; 約拿書 4:9"> 亞哈因為耶斯列人拿伯不肯把祖先的產業讓給他，就悶悶不樂地回到宮中，躺在床上生氣，飯也不吃。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="列王紀上 16:31; 創世記 3:6; 列王紀上 19:2"> 他妻子耶洗別過來問他：「王為什麼煩悶，不思飲食呢？」</span>
<span className="v" id="v6" data-v="6" data-xref="以斯帖記 5:9–14; 雅各書 4:2–7; 提摩太前書 6:9–10"> 亞哈回答說：「我要耶斯列人拿伯將他的葡萄園賣給我，如果他願意，我也可以用別的葡萄園跟他交換，可是他不肯。」</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳記上 8:14; 彌迦書 7:3; 撒母耳記下 13:4"> 耶洗別說：「你不是以色列王嗎？起來吃飯吧，高興點，我必讓你得到耶斯列人拿伯的葡萄園。」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="尼希米記 6:5; 列王紀下 10:11; 以斯拉記 4:7–8"> 於是，耶洗別以亞哈王的名義寫信，並蓋上王印，送給跟拿伯同居一城的長老和貴族。</span>
<span className="v" id="v9" data-v="9" data-xref="以賽亞書 58:4; 馬太福音 23:13; 路加福音 20:47"> 信上說：「你們要宣告禁食，讓拿伯在百姓中坐首位，</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及記 22:28; 使徒行傳 6:11; 利未記 24:15–16"> 叫兩個無賴坐在他對面控告他咒詛上帝和君王，然後把他拉出去用石頭打死。」</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行傳 4:19; 利未記 19:15; 列王紀下 10:6–7"> 與拿伯同居一城的長老和貴族便照信裡的指示行事。</span>
<span className="v" id="v12" data-v="12" data-xref="以賽亞書 58:4; 列王紀上 21:8–10"> 他們宣告禁食，讓拿伯在百姓中坐首位，</span>
<span className="v" id="v13" data-v="13" data-xref="列王紀下 9:26; 申命記 22:24; 傳道書 10:20"> 又叫兩名無賴當眾作證，指控拿伯咒詛上帝和君王。眾人就把拿伯拖出城外，用石頭打死了他。</span>
<span className="v" id="v14" data-v="14" data-xref="傳道書 8:14; 撒母耳記下 11:14–24; 傳道書 5:8"> 然後，他們派人去把拿伯被石頭打死的消息告訴耶洗別。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="箴言 1:10–16; 箴言 4:17; 列王紀上 21:7"> 耶洗別接到消息後，就告訴亞哈說：「耶斯列人拿伯已經死了，你去佔他不肯賣給你的葡萄園吧。」</span>
<span className="v" id="v16" data-v="16" data-xref="俄巴底亞書 1:12–14; 羅馬書 1:32; 撒母耳記下 11:25–27"> 亞哈聽說耶斯列人拿伯死了，就起來，下去霸佔拿伯的葡萄園。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="詩篇 9:12; 以賽亞書 26:21; 列王紀下 5:26"> 耶和華對提斯比人以利亞說：</span>
<span className="v" id="v18" data-v="18" data-xref="列王紀上 13:32; 歷代志下 22:9"> 「你去撒瑪利亞見以色列王亞哈，他正在拿伯的葡萄園，他到那裡要霸佔那葡萄園。</span>
<span className="v" id="v19" data-v="19" data-xref="列王紀上 22:38; 撒母耳記下 12:9; 哈巴谷書 2:9"> 你要對他說，『耶和華說，你殺了人，還要奪他的產業嗎？』然後告訴他，耶和華說，『狗在哪裡舔拿伯的血，也必在哪裡舔你的血。』」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="列王紀下 17:17; 羅馬書 7:14; 列王紀上 21:25"> 亞哈見了以利亞，說：「我的對頭啊，你又來找我了！」以利亞說：「我又來找你了，因為你一心做耶和華視為惡的事。</span>
<span className="v" id="v21" data-v="21" data-xref="列王紀上 14:10; 撒母耳記上 25:34; 列王紀下 10:1–7"> 耶和華說，『我必降禍給你，徹底毀滅你，從以色列剷除你家所有的男子，不管是奴隸還是自由人。</span>
<span className="v" id="v22" data-v="22" data-xref="列王紀上 16:3; 列王紀上 14:16; 列王紀上 16:11"> 我必使你一家的下場像尼八的兒子耶羅波安家和亞希雅的兒子巴沙家一樣，因為你惹我發怒，並且使以色列人陷入罪中。』</span>
<span className="v" id="v23" data-v="23" data-xref="列王紀下 9:10; 列王紀下 9:30–37; 列王紀上 21:25"> 至於耶洗別，耶和華說，『狗必在耶斯列的城牆邊吃耶洗別的肉。</span>
<span className="v" id="v24" data-v="24" data-xref="列王紀上 16:4; 列王紀上 14:11; 耶利米書 15:3"> 凡屬亞哈的人，死在城中的必被狗吃，死在郊野的必被飛鳥吃。』」</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="箴言 22:14; 列王紀上 21:20; 列王紀上 16:30–33"> 從來沒有人像亞哈那樣受妻子耶洗別唆使，一心做耶和華視為惡的事。</span>
<span className="v" id="v26" data-v="26" data-xref="列王紀下 21:11; 創世記 15:16; 利未記 18:25–30"> 他像被耶和華驅逐的亞摩利人一樣祭拜偶像，行為可憎。</span>
<span className="v" id="v27" data-v="27" data-xref="列王紀下 6:30; 創世記 37:34; 撒母耳記下 3:31"> 亞哈聽了以利亞的話，就撕裂衣服，披麻禁食，睡覺也不脫下麻衣，垂頭喪氣地走來走去。</span>
<span className="v" id="v28" data-v="28"> 耶和華對提斯比人以利亞說：</span>
<span className="v" id="v29" data-v="29" data-xref="彼得後書 3:9; 彌迦書 7:18; 詩篇 86:15"> 「你看見亞哈在我面前如何謙卑了嗎？因為他在我面前謙卑，我不會在他有生之日降災，我要等他兒子執政的時候，才降災給他家。」</span>
</div>
</div>

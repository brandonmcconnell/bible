## 所羅門的王宮

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀上 9:10; 歷代志下 8:1; 傳道書 2:4–5"> 所羅門用了十三年的時間為自己興建王宮。</span>
<span className="v" id="v2" data-v="2" data-xref="列王紀上 10:17; 歷代志下 9:16; 列王紀上 10:21"> 他建造的黎巴嫩林宮長四十五米，寬二十二米半，高十三米半，有四行香柏木柱，柱子支撐著香柏木橫梁。</span>
<span className="v" id="v3" data-v="3" data-xref="列王紀上 6:5"> 每一行木柱有十五根，共四十五根。殿頂鋪香柏木板。</span>
<span className="v" id="v4" data-v="4" data-xref="以西結書 40:22; 以西結書 40:16; 列王紀上 6:4"> 宮殿有三排窗戶，窗與窗相對；</span>
<span className="v" id="v5" data-v="5"> 宮殿的門框和窗戶都是方形的，三排窗戶彼此相對。</span>
<span className="v" id="v6" data-v="6" data-xref="列王紀上 7:12; 以西結書 41:25–26"> 他又建了一座有柱子的廊子，長二十二米半，寬十三米半，前面還有帶柱子的門廊和篷子。</span>
<span className="v" id="v7" data-v="7" data-xref="箴言 20:8; 詩篇 122:5; 以賽亞書 9:7"> 此外，他又建造了一個判案的公堂。堂內從地板到天花板都鋪上了香柏木。</span>
<span className="v" id="v8" data-v="8" data-xref="歷代志下 8:11; 列王紀上 3:1; 列王紀上 9:24"> 所羅門的寢宮就在公堂後面的院內，建築樣式和公堂相同。所羅門又為所娶的法老之女造了一座與公堂相同的宮室。</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀上 7:10–11; 列王紀上 5:17"> 這些宮殿，從根基到牆頂，從外院到內殿用的都是上等的石頭，按規格裡外用鋸切割整齊。</span>
<span className="v" id="v10" data-v="10" data-xref="啟示錄 21:19–20; 哥林多前書 3:10–11; 以賽亞書 54:11"> 根基用的是非常珍貴的石頭，它們的體積巨大，有些甚至是長達三米半至四米半的巨石，</span>
<span className="v" id="v11" data-v="11" data-xref="以弗所書 2:20–22; 彼得前書 2:5"> 上面是按照規格鑿好的上等石頭以及香柏木。</span>
<span className="v" id="v12" data-v="12" data-xref="列王紀上 6:36; 列王紀上 7:6; 約翰福音 10:23"> 大院周圍的牆由三層鑿好的石頭和一層香柏木建成，正如耶和華殿的內院和殿廊的牆。</span>
</div>
</div>

## 戶蘭造聖殿的器具

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="歷代志下 4:11; 歷代志下 2:13–14; 列王紀上 7:40"> 所羅門王派人從泰爾把戶蘭召來。</span>
<span className="v" id="v14" data-v="14" data-xref="歷代志下 2:14; 歷代志下 4:16; 出埃及記 31:2–6"> 戶蘭是拿弗他利支派一個寡婦的兒子，父親是泰爾的銅匠。戶蘭聰明伶俐，技術高超，擅長製造各種銅器。他前來朝見所羅門王，領命負責一切銅器工程。</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米書 52:21; 歷代志下 3:15–17; 列王紀上 7:21"> 他鑄造了兩根銅柱，每根高八米，周長五米四，</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 38:19; 歷代志下 4:12–13; 出埃及記 38:17"> 然後用銅鑄造了兩個高兩米二的柱冠，安在柱頂上。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及記 28:14; 出埃及記 28:24–25; 出埃及記 28:22"> 每一個柱冠上裝飾著七條鏈子織成的網，</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及記 28:14; 出埃及記 39:15–18; 出埃及記 28:22"> 網周圍環繞著兩行石榴，用來遮蓋柱冠。</span>
<span className="v" id="v19" data-v="19" data-xref="列王紀上 7:22; 列王紀上 6:32–35; 列王紀上 6:18"> 門廊的柱冠高一米八，形狀像百合花。</span>
<span className="v" id="v20" data-v="20" data-xref="歷代志下 3:16; 歷代志下 4:13; 耶利米書 52:22–23"> 在每個柱冠靠近網子鼓起來的地方圍著兩行石榴，共二百個。</span>
<span className="v" id="v21" data-v="21" data-xref="歷代志下 3:17; 列王紀上 6:3; 列王紀上 7:12"> 他把兩根柱子立在殿廊前，南邊那根稱為雅斤，北邊那根稱為波阿斯。</span>
<span className="v" id="v22" data-v="22"> 柱冠的形狀像百合花。這樣，銅柱就造成了。</span>
<span className="v" id="v23" data-v="23" data-xref="歷代志下 4:2; 列王紀下 25:13; 耶利米書 52:17"> 他又鑄了一個圓形銅海，高兩米二，直徑四米半，周長十三米半。</span>
<span className="v" id="v24" data-v="24" data-xref="列王紀上 6:18; 歷代志下 4:3; 出埃及記 37:17–22"> 銅海邊緣下面有兩圈野瓜圖案，每米有二十個野瓜，是跟銅海一起鑄造的。</span>
<span className="v" id="v25" data-v="25" data-xref="耶利米書 52:20; 歷代志下 4:4–5; 馬太福音 28:19"> 有十二頭銅牛馱著銅海，三頭向北，三頭向西，三頭向南，三頭向東。銅海安在牛上，牛尾向內。</span>
<span className="v" id="v26" data-v="26" data-xref="歷代志下 4:5; 列王紀上 7:38; 列王紀上 6:18"> 銅海厚八釐米，邊如杯邊，又如百合花，容量是四萬四千升。</span>
<span className="v" id="v27" data-v="27" data-xref="歷代志下 4:14; 列王紀下 25:13; 耶利米書 52:17"> 戶蘭用銅造了十個盆座，每個長一米八，寬一米八，高一米三。</span>
<span className="v" id="v28" data-v="28"> 盆座四面裝上鑲板，鑲板固定在框架上。</span>
<span className="v" id="v29" data-v="29" data-xref="何西阿書 5:14; 以西結書 10:14; 出埃及記 37:7"> 鑲板和框架上刻著獅子、牛和基路伯天使，獅子和牛的上面和下面雕刻著花環。</span>
<span className="v" id="v30" data-v="30" data-xref="以西結書 10:10–13; 以西結書 3:13; 以西結書 1:15–21"> 每一個盆座都有四個銅輪和銅軸，盆放在有四個支腳鑄成的盆架上，盆架周圍有花環圖案。</span>
<span className="v" id="v31" data-v="31"> 盆座的開口呈圓形，深四十五釐米，直徑七十釐米，開口周圍有雕刻。鑲板是方形的，不是圓形的，</span>
<span className="v" id="v32" data-v="32"> 下面有四個七十釐米高的輪子，輪軸固定在盆座上。</span>
<span className="v" id="v33" data-v="33" data-xref="以西結書 1:18; 以西結書 1:16"> 輪子的樣式像戰車的輪子，軸、輞、輻、轂都是鑄成的。</span>
<span className="v" id="v34" data-v="34"> 每個盆座的四角都有支腳，支腳和盆座鑄成一體。</span>
<span className="v" id="v35" data-v="35"> 盆座上有一個高二十三釐米的圓架，上面的支架和鑲板與盆座鑄成一體。</span>
<span className="v" id="v36" data-v="36" data-xref="列王紀上 7:29; 列王紀上 6:29; 以西結書 41:18–20"> 支架和鑲板都刻上基路伯天使、獅子和棕樹的圖案，周圍有花環圖案。</span>
<span className="v" id="v37" data-v="37"> 十個盆座的鑄法、大小和形狀相同。</span>
<span className="v" id="v38" data-v="38" data-xref="出埃及記 40:11–12; 撒迦利亞書 13:1; 約翰一書 1:7"> 他又用銅製造了十個盆，盆徑一米八，容量八百八十升。十個銅盆分別放在十個盆座上。</span>
<span className="v" id="v39" data-v="39" data-xref="歷代志下 4:10; 歷代志下 4:6"> 殿門左右各放五個盆座。銅海放在殿的東南角。</span>
<span className="v" id="v40" data-v="40" data-xref="歷代志下 4:11–16; 出埃及記 24:6; 出埃及記 39:32–43"> 戶蘭又造了鍋、鏟和碗。他為所羅門王完成了耶和華殿的一切工作。</span>
<span className="v" id="v41" data-v="41" data-xref="列王紀上 7:15–22; 歷代志下 4:12"> 他所製造的有兩根柱子，兩個碗狀的柱冠，兩個裝飾柱冠的網子，</span>
<span className="v" id="v42" data-v="42" data-xref="列王紀上 7:20"> 四百個安在網子上的石榴，每個網子上兩行石榴，用來裝飾碗狀的柱冠；</span>
<span className="v" id="v43" data-v="43"> 十個盆座及盆座上的十個盆；</span>
<span className="v" id="v44" data-v="44" data-xref="列王紀上 7:23; 列王紀上 7:25"> 銅海和銅海下面的十二頭銅牛；</span>
<span className="v" id="v45" data-v="45" data-xref="出埃及記 27:3; 出埃及記 38:3; 歷代志下 4:16"> 鍋、鏟、碗。這些都是戶蘭給所羅門王用磨亮的銅為耶和華的殿造的器具。</span>
<span className="v" id="v46" data-v="46" data-xref="約書亞記 3:16; 歷代志下 4:17; 創世記 33:17"> 這些都是照王的命令在疏割和撒拉但之間的約旦平原用泥模鑄成的。</span>
<span className="v" id="v47" data-v="47" data-xref="歷代志上 22:14; 歷代志上 22:3; 歷代志下 4:18"> 所羅門沒有稱過這些器具，因為太多，銅的重量無法統計。</span>
<span className="v" id="v48" data-v="48" data-xref="出埃及記 37:10–16; 歷代志下 4:8; 出埃及記 39:36"> 所羅門又為耶和華的殿造了以下器具：金壇和放供餅的金桌；</span>
<span className="v" id="v49" data-v="49" data-xref="歷代志下 4:7; 歷代志下 4:20; 撒迦利亞書 4:11–14"> 至聖所前面的純金燈臺，左右各五個；燈臺上的金花、燈盞和燈剪；</span>
<span className="v" id="v50" data-v="50" data-xref="出埃及記 25:29; 歷代志下 4:21–22; 出埃及記 27:3"> 純金造的杯、燈剪、碗、碟和火鼎，以及至聖所和外殿入口的金門樞。</span>
<span className="v" id="v51" data-v="51" data-xref="歷代志下 5:1; 撒母耳記下 8:7–11; 歷代志上 28:11–18"> 所羅門王完成耶和華殿的一切工作後，就把他父親大衛獻給耶和華的金銀和器具都搬進耶和華殿的庫房。</span>
</div>

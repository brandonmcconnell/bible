## 亞比央做猶大王

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀上 14:31; 歷代志下 13:1–22"> 尼八的兒子耶羅波安王執政第十八年，亞比央登基做猶大王。</span>
<span className="v" id="v2" data-v="2" data-xref="歷代志下 13:2; 歷代志下 11:20–22; 列王紀上 15:13"> 他在耶路撒冷執政三年，母親是押沙龍的女兒瑪迦。</span>
<span className="v" id="v3" data-v="3" data-xref="列王紀上 11:4; 詩篇 119:80; 列王紀上 3:14"> 亞比央和他父親一樣作惡多端，沒有像他祖先大衛一樣忠於他的上帝耶和華。</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀上 11:36; 歷代志下 21:7; 以賽亞書 37:35"> 但他的上帝耶和華因為大衛的緣故，仍然讓他兒子在耶路撒冷繼位，使耶路撒冷堅立。</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀上 14:8; 撒母耳記下 11:15–17; 列王紀上 15:3"> 除了赫人烏利亞事件以外，大衛一生都做耶和華視為正的事，沒有違背耶和華的任何命令。</span>
<span className="v" id="v6" data-v="6" data-xref="列王紀上 14:30"> 羅波安和耶羅波安之間常有戰事，一直延續到亞比央王朝。</span>
<span className="v" id="v7" data-v="7" data-xref="歷代志下 13:2–22; 列王紀上 14:29"> 亞比央和耶羅波安之間也常有戰事。亞比央其他的事及一切所為都記在《猶大列王史》上。</span>
<span className="v" id="v8" data-v="8" data-xref="歷代志下 14:1; 列王紀上 14:31; 馬太福音 1:7–8"> 亞比央與祖先同眠後，葬在大衛城，他兒子亞撒繼位。</span>
</div>
</div>

## 亞撒做猶大王

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9"> 耶羅波安做以色列王第二十年，亞撒登基做猶大王，</span>
<span className="v" id="v10" data-v="10" data-xref="列王紀上 15:2; 列王紀上 15:13; 歷代志下 13:2"> 他在耶路撒冷執政四十一年。他祖母是押沙龍的女兒瑪迦。</span>
<span className="v" id="v11" data-v="11" data-xref="歷代志下 14:2; 歷代志下 15:17; 列王紀上 15:3"> 亞撒效法他祖先大衛，做耶和華視為正的事。</span>
<span className="v" id="v12" data-v="12" data-xref="列王紀上 22:46; 列王紀上 14:23–24; 歷代志下 14:2–5"> 他從國中驅逐了男廟妓，清除了他祖先製造的一切偶像。</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及記 32:20; 申命記 7:5; 撒迦利亞書 13:3"> 亞撒還廢除了他祖母瑪迦的太后之位，因為她造了可憎的亞舍拉神像。亞撒把她的神像砍倒，放在汲淪溪燒掉。</span>
<span className="v" id="v14" data-v="14" data-xref="列王紀上 22:43; 列王紀上 8:61; 列王紀上 15:3"> 他雖然沒有清除邱壇，但一生忠於耶和華。</span>
<span className="v" id="v15" data-v="15" data-xref="列王紀上 7:51; 歷代志下 14:13; 歷代志下 15:18"> 他把自己和父親奉獻的金銀及器皿都帶到耶和華的殿裡。</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀上 15:32; 列王紀上 14:30; 歷代志下 16:1–6"> 亞撒和以色列王巴沙執政期間，雙方常常交戰。</span>
<span className="v" id="v17" data-v="17" data-xref="列王紀上 12:27; 歷代志下 16:1–6; 約書亞記 18:25"> 以色列王巴沙上來攻打猶大，並修築拉瑪，不許任何人進出猶大王亞撒的地界。</span>
<span className="v" id="v18" data-v="18" data-xref="列王紀上 14:26; 列王紀下 12:18; 列王紀上 11:23–24"> 於是，亞撒把耶和華殿裡和王宮庫房裡剩餘的金銀交給臣僕，派他們送給大馬士革的亞蘭王，即他伯利們的兒子、希旬的孫子便·哈達，說：</span>
<span className="v" id="v19" data-v="19" data-xref="羅馬書 1:31; 歷代志下 16:7; 羅馬書 3:8"> 「我們之間應立盟約，像我們的父輩間立約一樣，現在奉上金銀為禮，請你取消與以色列王巴沙的盟約。這樣，他就會從我境內退兵。」</span>
<span className="v" id="v20" data-v="20" data-xref="列王紀下 15:29; 士師記 18:29; 約書亞記 11:2"> 便·哈達接受了亞撒王的提議，派將領攻打以色列的城邑，攻佔了以雲、但、亞伯·伯·瑪迦、基尼烈全境和拿弗他利全境。</span>
<span className="v" id="v21" data-v="21" data-xref="列王紀上 14:17; 列王紀上 16:15–18; 歷代志下 16:5"> 巴沙聞訊，就停止修築拉瑪，退回得撒去了。</span>
<span className="v" id="v22" data-v="22" data-xref="約書亞記 21:17; 約書亞記 18:24; 約書亞記 18:26"> 亞撒王號令全體猶大人出動，任何人不得有誤，將巴沙修築拉瑪的石頭和木材搬走，用它們修建便雅憫的迦巴和米斯巴。</span>
<span className="v" id="v23" data-v="23" data-xref="歷代志下 16:11–14; 列王紀上 14:29–31; 列王紀上 15:7–8"> 亞撒其他的事，包括他的功業和興建城邑的事蹟都記在《猶大列王史》上。亞撒年老的時候，患了腳疾。</span>
<span className="v" id="v24" data-v="24" data-xref="馬太福音 1:8; 列王紀上 22:41–43; 歷代志下 17:1–9"> 他與祖先同眠後，葬在大衛城他的祖墳裡。他兒子約沙法繼位。</span>
</div>
</div>

## 拿答做以色列王

<div className="bt">
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="列王紀上 14:20; 列王紀上 14:12"> 亞撒做猶大王第二年，耶羅波安的兒子拿答登基做以色列王，執政兩年。</span>
<span className="v" id="v26" data-v="26" data-xref="列王紀上 14:16; 列王紀上 15:34; 列王紀上 15:30"> 拿答行耶和華視為惡的事，像他父親一樣作惡多端，使以色列人陷入罪中。</span>
<span className="v" id="v27" data-v="27" data-xref="約書亞記 19:44; 約書亞記 21:23; 列王紀上 14:14"> 亞撒做猶大王第三年，拿答率以色列軍圍攻非利士的基比頓城時，以薩迦支派亞希雅的兒子巴沙叛變，殺了拿答，篡位稱王。</span>
<span className="v" id="v29" data-v="29" data-xref="列王紀上 14:9–16; 列王紀下 19:25; 列王紀下 10:10–11"> 巴沙一做王，立刻誅殺耶羅波安全家，不留一個活口，應驗了耶和華藉祂僕人示羅人亞希雅所說的話。</span>
<span className="v" id="v30" data-v="30" data-xref="列王紀上 15:26; 列王紀上 14:22; 列王紀上 14:9–16"> 這是因為耶羅波安犯罪，並使以色列人陷入罪中，惹以色列的上帝耶和華發怒。</span>
<span className="v" id="v31" data-v="31" data-xref="列王紀上 14:19; 列王紀上 16:20; 列王紀上 16:14"> 拿答其他的事及一切所為都記在《以色列列王史》上。</span>
<span className="v" id="v32" data-v="32" data-xref="列王紀上 15:16"> 亞撒和以色列王巴沙執政期間，雙方常常交戰。</span>
</div>
</div>

## 巴沙做以色列王

<div className="bt">
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="列王紀上 16:8"> 猶大王亞撒執政第三年，亞希雅的兒子巴沙在得撒登基做以色列王，執政二十四年。</span>
<span className="v" id="v34" data-v="34" data-xref="列王紀上 15:26; 列王紀上 14:16; 列王紀上 12:28–29"> 他做耶和華視為惡的事，步耶羅波安的後塵，使以色列人陷入罪中。</span>
</div>
</div>

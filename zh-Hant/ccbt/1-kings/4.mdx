## 所羅門的臣僕

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="傳道書 1:12; 歷代志下 9:30; 列王紀上 12:19–20"> 所羅門王統治以色列，</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 18:21; 哥林多前書 12:28; 撒母耳記下 8:15–18"> 以下是他的眾臣僕：撒督的兒子亞撒利雅做祭司；</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳記下 8:16; 以賽亞書 62:6; 歷代志上 18:15"> 示沙的兒子以利何烈和亞希亞做書記；亞希律的兒子約沙法做史官；</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀上 2:35; 列王紀上 2:26–27"> 耶何耶大的兒子比拿雅做元帥；撒督和亞比亞他做祭司長；</span>
<span className="v" id="v5" data-v="5" data-xref="歷代志上 27:33; 撒母耳記下 15:37; 撒母耳記下 16:16"> 拿單的兒子亞撒利雅掌管吏部；拿單的兒子撒布得祭司做所羅門王的顧問；</span>
<span className="v" id="v6" data-v="6" data-xref="列王紀上 9:15; 撒母耳記下 20:24; 列王紀上 12:18"> 亞希煞總管宮廷事務；亞比大的兒子亞多尼蘭總管做勞役的。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="歷代志上 27:1–15"> 所羅門在以色列全國設立了十二個地方官，負責供給王及王室的需用，每年每人負責一個月。</span>
<span className="v" id="v8" data-v="8" data-xref="約書亞記 24:33; 士師記 19:1; 士師記 17:1"> 這十二個地方官是：便·戶珥，負責以法蓮山區；</span>
<span className="v" id="v9" data-v="9" data-xref="約書亞記 21:16; 撒母耳記上 6:20; 撒母耳記上 6:12"> 便·底甲，負責瑪迦斯、沙賓、伯·示麥、以倫·伯·哈南；</span>
<span className="v" id="v10" data-v="10" data-xref="約書亞記 15:35; 約書亞記 12:17; 約書亞記 17:2"> 便·希悉，負責亞魯泊，包括梭哥和希弗全境；</span>
<span className="v" id="v11" data-v="11" data-xref="約書亞記 11:2; 約書亞記 12:23; 約書亞記 17:11"> 所羅門女兒她法的丈夫便·亞比拿達，負責多珥高原；</span>
<span className="v" id="v12" data-v="12" data-xref="約書亞記 17:11; 士師記 5:19; 約書亞記 3:16"> 亞希律的兒子巴拿，負責他納和米吉多，靠近撒拉他拿、耶斯列下邊的伯·善全境，以及從伯·善到亞伯·米何拉，遠至約緬；</span>
<span className="v" id="v13" data-v="13" data-xref="申命記 3:4; 民數記 32:41; 列王紀上 22:3"> 便·基別，負責基列的拉末和瑪拿西子孫雅珥在基列的城邑，以及巴珊的亞珥歌伯地區有城牆和銅閂的大城六十座；</span>
<span className="v" id="v14" data-v="14" data-xref="約書亞記 13:26; 撒母耳記下 17:24; 撒母耳記下 2:8"> 易多的兒子亞希拿達，負責瑪哈念；</span>
<span className="v" id="v15" data-v="15" data-xref="約書亞記 19:32–39; 撒母耳記下 15:27; 撒母耳記上 18:18"> 所羅門的另一個女兒巴實抹的丈夫亞希瑪斯，負責拿弗他利；</span>
<span className="v" id="v16" data-v="16" data-xref="約書亞記 19:24–31; 撒母耳記下 15:32"> 戶篩的兒子巴拿，負責亞設和亞祿；</span>
<span className="v" id="v17" data-v="17" data-xref="約書亞記 19:17–23"> 帕路亞的兒子約沙法，負責以薩迦；</span>
<span className="v" id="v18" data-v="18" data-xref="列王紀上 1:8; 約書亞記 18:20–28; 撒迦利亞書 12:13"> 以拉的兒子示每，負責便雅憫；</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 2:26–17; 約書亞記 13:9–12; 民數記 21:21–35"> 烏利的兒子基別，獨自負責從前屬亞摩利王西宏和巴珊王噩的基列地區。</span>
</div>
</div>

## 所羅門的財富和智慧

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="創世記 22:17; 列王紀上 3:8; 創世記 32:12"> 猶大人和以色列人多如海沙，豐衣足食，生活幸福。</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 15:18; 約書亞記 1:4; 詩篇 68:29"> 所羅門統管列國，從幼發拉底河至非利士，直到埃及邊界。所羅門在世的日子，列國都年年進貢稱臣。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22"> 所羅門每天的膳食用三千公斤細麵粉、六千公斤粗麵粉、</span>
<span className="v" id="v23" data-v="23" data-xref="尼希米記 5:17–18"> 十頭肥牛、二十頭草場的牛、一百隻羊，此外還有鹿、羚羊、麅子及肥禽。</span>
<span className="v" id="v24" data-v="24" data-xref="歷代志上 22:9; 詩篇 72:11; 詩篇 72:3"> 所羅門統治幼發拉底河西面所有的國家，從提弗薩直到迦薩，四境安寧。</span>
<span className="v" id="v25" data-v="25" data-xref="彌迦書 4:4; 撒迦利亞書 3:10; 士師記 20:1"> 所羅門在世的時候，從但到別示巴的猶大人和以色列人都在自己的葡萄樹和無花果樹下安居。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="歷代志下 1:14; 歷代志下 9:25; 撒母耳記下 8:4"> 所羅門有四萬個安置拉戰車馬匹的馬廄和一萬二千名騎兵。</span>
<span className="v" id="v27" data-v="27"> 十二個地方官按月供給所羅門王及王室的需用，使他們一無所缺。</span>
<span className="v" id="v28" data-v="28" data-xref="以斯帖記 8:10; 以斯帖記 8:14; 彌迦書 1:13"> 他們也各按其份提供餵戰車馬等馬匹用的大麥和乾草。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="列王紀上 3:12; 雅各書 3:17; 列王紀上 4:20"> 上帝賜予所羅門極大的智慧和悟性，以及如海邊的沙一樣浩博的學識。</span>
<span className="v" id="v30" data-v="30" data-xref="但以理書 5:11–12; 創世記 25:6; 但以理書 1:20"> 他的智慧高過東方人和埃及人的一切智慧，</span>
<span className="v" id="v31" data-v="31" data-xref="歷代志上 2:6; 歷代志上 15:19; 列王紀上 3:12"> 無人能比，勝過以斯拉人以探和瑪曷的兒子希幔、甲各、達大的智慧。他名揚四周列國。</span>
<span className="v" id="v32" data-v="32" data-xref="雅歌 1:1–17; 馬太福音 13:35; 箴言 1:1–31"> 所羅門寫下箴言三千句，作詩歌一千零五首。</span>
<span className="v" id="v33" data-v="33" data-xref="列王紀下 19:23; 詩篇 51:7; 詩篇 92:12"> 他對飛禽走獸、草木魚蟲，從黎巴嫩的香柏樹到長在牆上的牛膝草，都無所不知。</span>
<span className="v" id="v34" data-v="34" data-xref="歷代志下 9:23; 列王紀上 10:1; 歷代志下 9:1"> 天下列王風聞所羅門的智慧，都紛紛遣使來求教。</span>
</div>
</div>

</div>

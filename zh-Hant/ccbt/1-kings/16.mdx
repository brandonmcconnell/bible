<span className="v" id="v2" data-v="2" data-xref="列王紀上 15:34; 列王紀上 14:7; 撒母耳記上 2:8"> 「我從塵土中提拔你，立你為我以色列子民的首領，你卻重蹈耶羅波安的覆轍，使我的子民陷入罪中，惹我發怒。</span>
<span className="v" id="v3" data-v="3" data-xref="列王紀上 14:10; 列王紀上 15:29–30; 以賽亞書 66:24"> 所以我必除掉你和你全家，像除掉尼八的兒子耶羅波安家一樣。</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀上 14:11; 列王紀上 21:24"> 你家人中，死在城中的必被狗吃，死在野外的必被鳥吃。」</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀上 14:19; 列王紀上 15:31; 歷代志下 16:1–6"> 巴沙其他的事蹟和功業都記在《以色列列王史》上。</span>
<span className="v" id="v6" data-v="6" data-xref="列王紀上 14:17; 列王紀上 15:21; 列王紀上 16:13–14"> 巴沙與祖先同眠後葬在得撒，他兒子以拉繼位。</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀上 14:14; 何西阿書 1:4; 詩篇 115:4"> 耶和華藉哈拿尼的兒子耶戶先知譴責巴沙和他全家，是因為他像耶羅波安家一樣做耶和華視為惡的事，惹耶和華發怒，也因為他殺了耶羅波安全家。</span>

## 以拉做以色列王

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8"> 猶大王亞撒執政第二十六年，巴沙的兒子以拉在得撒登基做以色列王，執政兩年。</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀上 18:3; 創世記 39:4; 但以理書 5:1–4"> 以拉的一半戰車由部下心利掌管。心利卻背叛他，趁他在得撒宮廷總管亞雜家中喝醉時，</span>
<span className="v" id="v10" data-v="10" data-xref="列王紀下 9:31"> 進去殺了他，篡了位。那一年是亞撒做猶大王第二十七年。</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳記上 25:22; 列王紀上 16:3; 列王紀上 15:29"> 心利一登基做王，就殺了巴沙全家，他親友家的男子也無一倖免。</span>
<span className="v" id="v12" data-v="12" data-xref="列王紀上 16:1; 列王紀上 16:7; 歷代志下 10:15"> 巴沙慘遭滅門之禍，正應驗了耶和華藉耶戶先知譴責他的話。</span>
<span className="v" id="v13" data-v="13" data-xref="申命記 32:21; 列王紀上 15:30; 以賽亞書 41:29"> 這是因為巴沙和以拉父子二人作惡多端，祭拜假神，使以色列人陷入罪中，惹以色列的上帝耶和華發怒。</span>
<span className="v" id="v14" data-v="14"> 以拉其他的事及一切所為都記在《以色列列王史》上。</span>
</div>
</div>

## 心利做以色列王

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="列王紀上 15:27; 約書亞記 19:44; 約伯記 20:5"> 猶大王亞撒執政第二十七年，心利開始在得撒做王，執政僅七天。那時以色列軍正在攻打非利士的基比頓城。</span>
<span className="v" id="v16" data-v="16" data-xref="歷代志下 22:2; 列王紀下 8:26; 彌迦書 6:16"> 他們聽說心利謀反弒君，就在當天擁立軍中元帥暗利做以色列王。</span>
<span className="v" id="v17" data-v="17" data-xref="士師記 9:50; 路加福音 19:43–44; 列王紀下 18:9–12"> 暗利率領以色列軍離開基比頓，上去圍攻得撒。</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳記下 17:23; 撒母耳記上 31:4–5; 約伯記 2:9–10"> 心利見城被攻破，就走進王宮的城堡中放火燒宮，自焚而死。</span>
<span className="v" id="v19" data-v="19" data-xref="列王紀上 15:26; 列王紀上 14:16; 列王紀上 12:28"> 這是因為他犯罪，行耶和華視為惡的事，步耶羅波安的後塵，使以色列人陷入罪中。</span>
<span className="v" id="v20" data-v="20" data-xref="列王紀上 16:14; 列王紀上 16:5; 列王紀上 16:27"> 心利其他的事及其謀反篡位的經過，都記在《以色列列王史》上。</span>
</div>
</div>

## 暗利做以色列王

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="馬太福音 12:25; 以弗所書 4:3–5; 箴言 28:2"> 那時，以色列人分為兩派，一派擁立基納的兒子提比尼做王，另一派支持暗利。</span>
<span className="v" id="v22" data-v="22"> 暗利一派強於提比尼一派。提比尼死後，暗利做了王。</span>
<span className="v" id="v23" data-v="23" data-xref="列王紀上 16:8; 列王紀上 16:29; 歷代志下 22:2"> 猶大王亞撒執政第三十一年，暗利登基做以色列王，執政共十二年，其中六年在得撒。</span>
<span className="v" id="v24" data-v="24" data-xref="列王紀上 13:32; 列王紀上 16:32; 使徒行傳 8:5–8"> 暗利用了一千四百兩銀子向撒瑪買了撒瑪利亞山，在上面建了一座城，按原來主人撒瑪的名字稱之為撒瑪利亞。</span>
<span className="v" id="v25" data-v="25" data-xref="彌迦書 6:16; 列王紀上 16:30–31; 列王紀上 14:9"> 暗利做耶和華視為惡的事，比以前的諸王更壞。</span>
<span className="v" id="v26" data-v="26" data-xref="列王紀上 16:19; 列王紀上 16:13; 列王紀上 12:26–33"> 他步尼八的兒子耶羅波安的後塵，使以色列人陷入罪中，祭拜假神，惹以色列的上帝耶和華發怒。</span>
<span className="v" id="v27" data-v="27" data-xref="列王紀上 16:20; 列王紀上 16:14; 列王紀上 16:5"> 暗利其他的事及一切所為都記在《以色列列王史》上。</span>
<span className="v" id="v28" data-v="28"> 暗利與祖先同眠後葬在撒瑪利亞，他兒子亞哈繼位。</span>
</div>
</div>

## 亞哈做以色列王

<div className="bt">
<div className="bp">
<span className="v" id="v29" data-v="29"> 猶大王亞撒執政第三十八年，暗利的兒子亞哈登基做以色列王，他在撒瑪利亞執政二十二年。</span>
<span className="v" id="v30" data-v="30" data-xref="列王紀上 16:25; 列王紀上 21:25; 列王紀上 14:9"> 暗利的兒子亞哈做耶和華視為惡的事，比以前的諸王更壞。</span>
<span className="v" id="v31" data-v="31" data-xref="列王紀下 17:16; 列王紀下 10:18; 士師記 18:7"> 他不但步尼八的兒子耶羅波安的後塵，還娶了西頓王葉巴力的女兒耶洗別為妻，供奉、祭拜巴力。</span>
<span className="v" id="v32" data-v="32" data-xref="列王紀下 10:21; 列王紀下 10:26–27"> 他在撒瑪利亞為巴力建廟，在廟裡為巴力設立祭壇。</span>
<span className="v" id="v33" data-v="33" data-xref="列王紀下 13:6; 列王紀上 21:25; 列王紀下 21:3"> 他還造了亞舍拉神像，所作所為比先前諸王更惹以色列的上帝耶和華發怒。</span>
<span className="v" id="v34" data-v="34" data-xref="約書亞記 6:26; 約書亞記 23:14–15; 馬太福音 24:35"> 亞哈執政期間，伯特利人希伊勒重建耶利哥城。他立地基的時候，長子亞比蘭死了；安城門的時候，幼子西割死了。這應驗了耶和華藉嫩的兒子約書亞說的話。</span>
</div>

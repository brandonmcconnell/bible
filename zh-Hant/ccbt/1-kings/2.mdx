## 大衛對所羅門的叮囑

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 47:29; 申命記 31:14; 提摩太前書 1:18"> 大衛臨終時，叮囑他兒子所羅門說：</span>
<span className="v" id="v2" data-v="2" data-xref="約書亞記 1:6–7; 約書亞記 23:14; 以弗所書 6:10"> 「我要走世人都必走的那條路了。你要剛強，做大丈夫。</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 29:9; 申命記 17:18–20; 箴言 3:1–4"> 你要遵從你的上帝耶和華的吩咐，遵行祂的道，照摩西的律法遵守上帝的律例、誡命、典章和法度。這樣，你無論做什麼、去哪裡都必亨通，</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀下 20:3; 撒母耳記下 7:25; 列王紀上 8:25"> 耶和華必成就給我的應許，祂對我說，『如果你的子孫謹慎自守，全心全意地在我面前盡忠，你的以色列王朝必世代相傳。』</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳記下 3:27; 撒母耳記下 20:10; 撒母耳記下 18:5"> 「你知道洗魯雅的兒子約押怎樣對我，他殺了以色列的兩名元帥尼珥的兒子押尼珥和益帖的兒子亞瑪撒。他在太平的時候把他們當作戰場的敵手殺害，腰帶和鞋上沾滿了他們的血。</span>
<span className="v" id="v6" data-v="6" data-xref="列王紀上 2:9; 以賽亞書 57:21; 詩篇 37:37"> 你要用智慧處置他，不可讓他安享天年。</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳記下 17:27–29; 撒母耳記下 9:7; 撒母耳記下 19:31–40"> 「你要恩待基列人巴西萊的眾子，讓他們成為你的座上賓，因為我逃避你哥哥押沙龍的時候，他們曾接待我。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳記下 16:5–8; 列王紀上 2:36–46; 撒母耳記下 19:16–23"> 「別放過巴戶琳的便雅憫人基拉的兒子示每。我逃亡到瑪哈念的時候，他曾用惡毒的話咒罵我。後來他到約旦河迎接我的時候，我曾憑耶和華起誓不殺他。</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀上 2:6; 創世記 42:38; 創世記 44:31"> 但你不要放過他。你是個聰明人，知道該怎樣處置他。你要讓他白頭落地，不得善終。」</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行傳 2:29; 使徒行傳 13:36; 列王紀上 1:21"> 大衛與祖先同眠後，葬在大衛城。</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳記下 5:4–5; 歷代志上 29:26–27"> 他統治以色列四十年，他在希伯崙執政七年，在耶路撒冷執政三十三年。</span>
<span className="v" id="v12" data-v="12" data-xref="歷代志下 1:1; 歷代志上 29:23–25; 詩篇 132:12"> 所羅門繼承大衛的王位，江山穩固。</span>
</div>
</div>

## 所羅門鞏固王位

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="撒母耳記上 16:4–5; 列王紀上 1:5–10; 路加福音 10:5–6"> 一天，哈及的兒子亞多尼雅來見所羅門的母親拔示巴，拔示巴問他：「你是為平安而來嗎？」亞多尼雅說：「是為平安而來。」</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳記下 14:12; 路加福音 7:40"> 又說：「我有事稟告。」拔示巴說：「你說吧。」</span>
<span className="v" id="v15" data-v="15" data-xref="歷代志上 22:9–10; 歷代志上 28:5–7; 列王紀上 1:25"> 亞多尼雅說：「你知道，王位本該是我的，整個以色列原指望我做王。不料，王位歸了我兄弟，因為這是上帝的旨意。</span>
<span className="v" id="v16" data-v="16" data-xref="箴言 30:7; 詩篇 132:10"> 現在我有一個請求，請你不要推辭。」拔示巴說：「你說吧。」</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳記下 12:8; 列王紀上 1:2–4; 撒母耳記下 3:7"> 他說：「請你求所羅門王將那書念女子雅比莎賜我為妻，他不會拒絕你。」</span>
<span className="v" id="v18" data-v="18" data-xref="箴言 14:15"> 拔示巴說：「好吧，我會為你向王請求。」</span>
<span className="v" id="v19" data-v="19" data-xref="詩篇 45:9; 列王紀上 15:13; 利未記 19:32"> 拔示巴就為亞多尼雅的事去見所羅門王，王離座迎接，向她下拜，然後坐回位上，命人在自己右邊為她擺設座位。</span>
<span className="v" id="v20" data-v="20" data-xref="馬太福音 7:7–11; 馬太福音 11:24; 約翰福音 2:3–4"> 拔示巴說：「我有一件小事求你，請你不要推辭。」王說：「母親請說，我必不推辭。」</span>
<span className="v" id="v21" data-v="21" data-xref="列王紀上 1:3; 撒母耳記下 16:21–22"> 拔示巴說：「請將書念女子雅比莎賜給你哥哥亞多尼雅為妻。」</span>
<span className="v" id="v22" data-v="22" data-xref="歷代志上 3:2; 歷代志上 3:5; 馬太福音 20:22"> 所羅門王回答說：「為何只為亞多尼雅求書念女子雅比莎呢？你也為他求這國家吧！他是我哥哥，又有亞比亞他祭司和洗魯雅的兒子約押支持。」</span>
<span className="v" id="v23" data-v="23" data-xref="路得記 1:17; 詩篇 140:9; 詩篇 64:8"> 所羅門王就憑耶和華起誓說：「亞多尼雅若不為他這樣的要求付出性命，願上帝重重地懲罰我。</span>
<span className="v" id="v24" data-v="24" data-xref="歷代志上 22:10; 歷代志上 17:10; 歷代志上 17:17"> 耶和華讓我穩穩地坐在父親大衛的寶座上，照祂的應許為我建立了王朝，我憑永活的耶和華起誓，亞多尼雅今天必被處死。」</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳記下 8:18; 列王紀上 2:46; 士師記 8:20–21"> 於是，所羅門王命令耶何耶大的兒子比拿雅殺死亞多尼雅。</span>
<span className="v" id="v26" data-v="26" data-xref="約書亞記 21:18; 撒母耳記上 22:20–23; 耶利米書 1:1"> 王對亞比亞他祭司說：「你回亞拿突的老家去吧。你本是該死的，但我念你在我父大衛面前抬過主耶和華的約櫃，曾經與我父親患難與共，才饒你一命。」</span>
<span className="v" id="v27" data-v="27" data-xref="撒母耳記上 2:27–36; 撒母耳記上 3:12–14; 耶利米書 7:12–14"> 所羅門就罷免了亞比亞他的職位，不許他再做耶和華的祭司。這事應驗了耶和華在示羅所說的有關以利家的預言。</span>
<span className="v" id="v28" data-v="28" data-xref="列王紀上 1:50; 列王紀上 1:7; 撒母耳記下 18:2"> 約押雖然沒有支持押沙龍，但卻支持了亞多尼雅。他聽見風聲，就逃進聖幕，抓住祭壇的角。</span>
<span className="v" id="v29" data-v="29" data-xref="列王紀上 2:25; 出埃及記 21:14; 列王紀上 2:46"> 有人把這消息告訴所羅門王，說約押已經逃進聖幕，躲在祭壇旁邊。所羅門就派耶何耶大的兒子比拿雅去殺他。</span>
<span className="v" id="v30" data-v="30"> 比拿雅來到耶和華的聖幕，對約押說：「王吩咐你出來！」約押卻回答說：「不，我要死在這裡。」比拿雅回去稟告王。</span>
<span className="v" id="v31" data-v="31" data-xref="申命記 21:8–9; 民數記 35:33; 出埃及記 21:14"> 王說：「你就照他的話成全他，埋葬他，把他濫殺無辜的罪從我和我父親家清除。</span>
<span className="v" id="v32" data-v="32" data-xref="士師記 9:24; 士師記 9:57; 詩篇 7:16"> 耶和華要讓他血債血還。因為他背著我父親殺了兩名比他良善正直的人，即尼珥的兒子以色列元帥押尼珥和益帖的兒子猶大元帥亞瑪撒。</span>
<span className="v" id="v33" data-v="33" data-xref="馬太福音 27:25; 列王紀上 2:32; 路加福音 2:14"> 所以，殺這二人的血債必永遠歸到約押和他後代身上。願耶和華的平安永遠伴隨大衛和他的後代、他的家、他的王位。」</span>
<span className="v" id="v34" data-v="34" data-xref="馬太福音 3:1; 約書亞記 15:61; 列王紀上 2:25"> 耶何耶大的兒子比拿雅就去把約押殺死，葬在曠野約押自己的墓地。</span>
<span className="v" id="v35" data-v="35" data-xref="列王紀上 2:27; 歷代志上 24:3; 歷代志上 29:22"> 王委派耶何耶大的兒子比拿雅替代約押為元帥，命撒督祭司代替亞比亞他。</span>
<span className="v" id="v36" data-v="36" data-xref="撒母耳記下 16:5–9; 列王紀上 2:8–9; 箴言 20:26"> 王又派人將示每召來，對他說：「你要在耶路撒冷建屋居住，不得出城去其他地方。</span>
<span className="v" id="v37" data-v="37" data-xref="撒母耳記下 1:16; 撒母耳記下 15:23; 約書亞記 2:19"> 你哪天越過汲淪溪，哪天必死無疑，你的死是咎由自取。」</span>
<span className="v" id="v38" data-v="38" data-xref="列王紀上 20:4; 列王紀下 20:19"> 示每說：「好，僕人必照我主我王說的做。」示每就一直住在耶路撒冷。</span>
<span className="v" id="v39" data-v="39" data-xref="撒母耳記上 21:10; 撒母耳記上 27:2–3"> 過了三年，示每的兩個僕人逃到迦特王瑪迦的兒子亞吉那裡。示每知道後，</span>
<span className="v" id="v40" data-v="40" data-xref="路加福音 12:15; 箴言 15:27; 提摩太前書 6:10"> 就備上驢到迦特的亞吉那裡找他的僕人，並把他們帶了回來。</span>
<span className="v" id="v41" data-v="41"> 所羅門聽說示每從耶路撒冷前往迦特，已經返回，</span>
<span className="v" id="v42" data-v="42" data-xref="詩篇 15:4; 列王紀上 2:36–38; 路加福音 15:22"> 就派人召來示每，問道：「我不是叫你憑耶和華起誓不離開耶路撒冷嗎？我警告過你，你哪天離開這裡，哪天必死無疑。當時你也同意。</span>
<span className="v" id="v43" data-v="43" data-xref="羅馬書 13:5; 歷代志下 30:12; 傳道書 8:2"> 現在你為何不守你向耶和華起的誓，不遵行我的命令？」</span>
<span className="v" id="v44" data-v="44" data-xref="撒母耳記下 16:5–13; 詩篇 7:16; 以西結書 17:19"> 王又說：「你以前如何惡待我父大衛，你自己心裡明白，現在耶和華要追究你的罪行了。</span>
<span className="v" id="v45" data-v="45" data-xref="箴言 25:5; 列王紀上 2:24; 以賽亞書 9:6–7"> 但所羅門王必蒙祝福，大衛的王位必在耶和華面前必永遠穩固。」</span>
<span className="v" id="v46" data-v="46" data-xref="歷代志下 1:1; 列王紀上 2:12; 列王紀上 2:45"> 於是，王命令耶何耶大的兒子比拿雅殺死示每。這樣所羅門的江山得以穩固。</span>
</div>

## 所羅門求智慧

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀上 9:24; 列王紀上 11:1; 列王紀上 6:1–15"> 所羅門娶了埃及法老的女兒，與法老聯姻。他在自己的王宮、耶和華的殿和耶路撒冷的城牆完工之前，讓她一直住在大衛城。</span>
<span className="v" id="v2" data-v="2" data-xref="列王紀上 22:43; 歷代志下 33:17; 申命記 12:2–5"> 那時候，用來尊崇耶和華之名的殿還沒有建成，以色列人仍然在邱壇獻祭。</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多前書 8:3; 詩篇 31:23; 申命記 30:16"> 所羅門愛耶和華，遵行他父親大衛的律例，只是仍然在邱壇獻祭燒香。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="歷代志上 16:39; 歷代志下 1:3; 歷代志下 7:5"> 有一次，所羅門王上基遍獻了一千頭祭牲作燔祭，因為那裡有最重要的邱壇。</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀上 9:2; 雅各書 1:5–6; 民數記 12:6"> 在基遍，耶和華晚上在夢中向所羅門顯現，對他說：「你想要什麼，只管向我求。」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="列王紀上 9:4; 列王紀上 1:48; 哥林多後書 9:11"> 所羅門說：「你的僕人——我父大衛本著誠實、公義、正直的心在你面前行事，你就向他大施恩慈，並且一如既往地以厚恩待他，讓他兒子今天繼承他的王位。</span>
<span className="v" id="v7" data-v="7" data-xref="歷代志上 29:1; 民數記 27:17; 耶利米書 1:6"> 我的上帝耶和華啊，你讓僕人繼承我父大衛的王位，但僕人還年幼無知，不懂得如何治理國家。</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 15:5; 創世記 13:16; 歷代志上 21:2"> 僕人住在你所揀選的子民中，這些子民多得不可勝數。</span>
<span className="v" id="v9" data-v="9" data-xref="雅各書 1:5; 箴言 16:16; 希伯來書 5:14"> 求你賜我智慧治理你的子民，並能辨別是非；不然，誰能治理你這眾多的子民呢？」</span>
<span className="v" id="v10" data-v="10" data-xref="箴言 15:8"> 主喜悅所羅門的祈求，</span>
<span className="v" id="v11" data-v="11" data-xref="羅馬書 8:26; 雅各書 4:2–3; 箴言 16:31"> 對他說：「既然你不為自己求壽、求財富，也不求滅絕仇敵，只求有智慧秉公治理我的子民，</span>
<span className="v" id="v12" data-v="12" data-xref="約翰一書 5:14–15; 傳道書 1:16; 馬太福音 12:42"> 我必應允你，賜給你空前絕後的智慧和悟性。</span>
<span className="v" id="v13" data-v="13" data-xref="以弗所書 3:20; 馬太福音 6:33; 箴言 3:16"> 你沒有求富貴和尊榮，但我會一併賜給你，使你有生之年在列王中無人能比。</span>
<span className="v" id="v14" data-v="14" data-xref="箴言 3:2; 詩篇 91:16; 列王紀上 15:5"> 你若像你父親大衛一樣遵行我的道，遵守我的律例和誡命，我必使你長壽。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="創世記 41:7; 列王紀上 8:65; 以斯帖記 1:3"> 所羅門醒來，發現是做了一個夢。他回到耶路撒冷，站在耶和華的約櫃前獻上燔祭和平安祭，又宴請群臣。</span>
</div>
</div>

## 智斷死嬰案

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="出埃及記 18:16; 士師記 11:1; 民數記 27:2"> 一天，兩個妓女到王面前告狀。</span>
<span className="v" id="v17" data-v="17" data-xref="羅馬書 13:7; 創世記 43:20"> 其中一個說：「我主啊，我跟這女人同住，我生了一個男孩，當時她也在場。</span>
<span className="v" id="v18" data-v="18"> 我生產三天後，她也生了一個男孩。我們住在一起，除了我們二人，屋裡沒有別人。</span>
<span className="v" id="v19" data-v="19"> 一天晚上，她不小心壓死了自己的孩子。</span>
<span className="v" id="v20" data-v="20" data-xref="約翰福音 3:20; 馬太福音 13:25; 詩篇 139:11"> 她半夜起來，趁我熟睡的時候抱走了我身邊的孩子，放在她懷中，把她的死孩子放在我懷中。</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 21:7; 撒母耳記上 1:23; 耶利米哀歌 4:3–4"> 天快亮的時候，我起來給孩子餵奶，發現孩子死了。天亮後，我仔細察看孩子，發現孩子不是我生的。」</span>
<span className="v" id="v22" data-v="22" data-xref="列王紀上 3:23–24"> 另一個女人說：「不對！活孩子是我的，死孩子是你的。」第一個女人說：「不對！死孩子是你的，活孩子是我的。」兩個女人在王面前爭吵起來。</span>
<span className="v" id="v23" data-v="23"> 王見她們二人都說活孩子是自己的，死孩子是對方的，</span>
<span className="v" id="v24" data-v="24"> 就命人拿刀來。侍從把刀拿來後，</span>
<span className="v" id="v25" data-v="25" data-xref="箴言 25:8"> 王下令將那活孩子劈成兩半，讓她們各得一半。</span>
<span className="v" id="v26" data-v="26" data-xref="以賽亞書 49:15; 耶利米書 31:20; 約翰一書 3:17"> 活孩子的母親心疼自己的孩子，就說：「我主啊，把孩子給她吧，千萬不要殺他！」但另一個女人卻說：「孩子不歸我，也不歸你，把他劈開吧！」</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27"> 王說：「不可殺這孩子，把他交給剛才為孩子求情的女人吧！她是孩子的母親。」</span>
<span className="v" id="v28" data-v="28" data-xref="但以理書 2:47; 列王紀上 3:9–12; 歌羅西書 2:3"> 以色列人聽見王這樣斷案，都敬畏他，因為他們知道他有上帝所賜的智慧，能夠秉公斷案。</span>
</div>
</div>

</div>

## 示巴女王拜訪所羅門

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="馬太福音 12:42; 路加福音 11:31; 歷代志下 9:1–12"> 示巴女王聽說所羅門因耶和華而名聲大震，便來用難題考問他。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行傳 25:23; 詩篇 4:4; 約伯記 4:2"> 她率領許多隨從，用駱駝馱著香料、寶石和大量黃金到耶路撒冷晉見所羅門，與所羅門談論她心中的疑問。</span>
<span className="v" id="v3" data-v="3" data-xref="箴言 1:5–6; 馬太福音 13:11; 列王紀上 10:1"> 所羅門解答了她所有的問題，沒有一樣難得住他。</span>
<span className="v" id="v4" data-v="4" data-xref="馬太福音 12:42; 列王紀上 3:28; 歷代志下 9:3–4"> 示巴女王見所羅門智慧非凡，又看見他建的宮殿、</span>
<span className="v" id="v5" data-v="5" data-xref="歷代志上 26:16; 列王紀上 4:22–23; 列王紀下 16:18"> 席上的美味、入座的群臣、侍立的僕人、他們的服裝、酒侍，以及他在耶和華殿裡獻的燔祭，感到萬分驚奇。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="歷代志下 9:5–6"> 她對王說：「我在本國聽到的有關你的功業和智慧原來都是真的。</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多前書 2:9; 約翰福音 20:25–29; 約翰一書 3:2"> 若不是親眼目睹，我不會相信。其實我聽到的還不到一半！你的智慧和財富遠超過我聽到的傳聞。</span>
<span className="v" id="v8" data-v="8" data-xref="箴言 8:34; 箴言 10:21; 路加福音 11:31"> 你的百姓真有福氣！你的臣僕經常侍立在你面前聆聽智言慧語，真有福氣！</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 72:2; 列王紀上 5:7; 撒母耳記下 8:15"> 你的上帝耶和華當受稱頌！祂喜愛你，立你為以色列的王。因為祂永遠愛以色列，所以立你為王，使你秉公行義。」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="列王紀上 10:2; 馬太福音 2:11; 列王紀上 9:14"> 示巴女王將八萬兩黃金、大量香料和寶石獻給所羅門王。此後，再無人像示巴女王那樣獻給所羅門王那麼多香料。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="列王紀上 9:27–28; 歷代志下 8:18; 詩篇 45:9"> 希蘭的船隻從俄斐運來黃金、大量檀香木和寶石。</span>
<span className="v" id="v12" data-v="12" data-xref="歷代志上 25:1–31; 詩篇 150:3–5; 啟示錄 14:2–3"> 所羅門王用這些檀香木為耶和華的殿和王宮造欄桿，又為歌樂手製作琴瑟。此後，再沒有人運來或見過這樣的檀香木。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="詩篇 37:4; 馬太福音 15:28; 詩篇 20:4"> 所羅門王除了厚贈示巴女王禮物以外，還滿足了她的一切要求。之後，女王和隨從就回示巴去了。</span>
</div>
</div>

## 所羅門的財富

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="歷代志下 9:13–28; 列王紀上 9:28"> 所羅門每年收到的黃金約四十五萬兩。</span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 72:10; 歷代志上 9:24; 以賽亞書 21:13"> 此外，還有商人、阿拉伯諸王和國中各總督送來的貢稅。</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀上 14:26–28; 歷代志下 12:9–10; 歷代志下 9:15–16"> 所羅門王用錘好的金子打造了二百面大盾牌，每面用一百四十兩金子；</span>
<span className="v" id="v17" data-v="17" data-xref="列王紀上 7:2; 列王紀上 14:26"> 又用錘好的金子打造了三百面小盾牌，每面用七十兩金子，全部放在黎巴嫩林宮。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="詩篇 45:8; 列王紀上 10:22; 啟示錄 20:11"> 王又造了一個象牙大寶座，外面用純金包裹。</span>
<span className="v" id="v19" data-v="19"> 這寶座有六級臺階，靠背是圓形的，兩旁有扶手，扶手兩邊各站著一頭獅子。</span>
<span className="v" id="v20" data-v="20" data-xref="民數記 24:9; 創世記 49:9; 民數記 23:24"> 六級臺階上共站著十二頭獅子，每級臺階兩端各站一頭。這寶座舉世無雙。</span>
<span className="v" id="v21" data-v="21" data-xref="列王紀上 10:17; 列王紀上 7:2; 歷代志下 9:20–22"> 所羅門王所有的杯子都是金的，黎巴嫩林宮裡所有的器皿都是純金的，沒有一件是用銀子造的，因為所羅門年間銀子不算什麼。</span>
<span className="v" id="v22" data-v="22" data-xref="列王紀上 22:48; 創世記 10:4; 歷代志下 20:36–37"> 王有他施船隊和希蘭的船隊一起出海，每三年就運回金銀、象牙、猿猴和孔雀。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="列王紀上 3:12–13; 歌羅西書 2:2–3; 列王紀上 4:29–34"> 所羅門王的財富和智慧超過天下諸王。</span>
<span className="v" id="v24" data-v="24" data-xref="列王紀上 3:12; 雅各書 1:5; 列王紀上 3:28"> 天下的人都紛紛來朝見他，聆聽上帝賜給他的智言慧語。</span>
<span className="v" id="v25" data-v="25" data-xref="約伯記 42:11; 詩篇 72:10; 詩篇 72:15"> 他們年年都帶來禮物，有金銀器皿、衣服、兵器、香料和騾馬。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="歷代志下 9:25; 列王紀上 4:26; 申命記 17:16"> 所羅門組建了戰車和騎兵，有一千四百輛戰車、一萬二千名騎兵，駐紮在屯車城和他所在的耶路撒冷。</span>
<span className="v" id="v27" data-v="27" data-xref="歷代志下 1:15–17; 申命記 17:17; 歷代志下 9:27"> 王使耶路撒冷的銀子多如石頭，使香柏木多如丘陵的桑樹。</span>
<span className="v" id="v28" data-v="28" data-xref="申命記 17:16; 歷代志下 9:28; 以賽亞書 31:1–3"> 所羅門的馬匹都是由王室商隊從埃及和古厄按市價買來的。</span>
<span className="v" id="v29" data-v="29" data-xref="約書亞記 1:4; 列王紀下 7:6–7; 瑪拉基書 1:1"> 他們從埃及買來車馬，每輛車六百塊銀子，每匹馬一百五十塊銀子，他們也把車馬賣給赫人諸王和亞蘭諸王。</span>
</div>
</div>

</div>

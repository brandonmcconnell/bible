## 上帝的僕人警告耶羅波安

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀上 12:32–33; 列王紀下 23:17; 帖撒羅尼迦前書 4:15"> 有一位上帝的僕人奉耶和華的命令從猶大來到伯特利。那時，耶羅波安正站在祭壇旁燒香。</span>
<span className="v" id="v2" data-v="2" data-xref="以西結書 36:1; 列王紀下 23:15–18; 列王紀下 22:1–2"> 上帝的僕人奉耶和華的命令向祭壇喊道：「祭壇啊，祭壇啊，耶和華說，必有一子在大衛家出生，他名叫約西亞。他要在你上面殺死那些焚香獻祭的邱壇祭司，在你上面焚燒人的骨頭。」</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多前書 1:22; 出埃及記 4:3–5; 士師記 6:17"> 當日，他又說：「耶和華說要給你們一個徵兆，這壇必破裂，壇上的灰必撒出來。」</span>
<span className="v" id="v4" data-v="4" data-xref="啟示錄 11:5; 歷代志下 18:25–27; 路加福音 6:10"> 耶羅波安王聽了他向伯特利的祭壇所發的呼聲，就從壇上伸手指著他說：「給我拿住他！」但王伸出來的手枯乾了，不能收回。</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀上 13:3; 耶利米書 28:16–17; 申命記 18:22"> 這時，祭壇破裂了，壇上的灰也撒了出來，應驗了上帝的僕人奉耶和華之命所說的徵兆。</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及記 9:28; 使徒行傳 8:24; 出埃及記 10:17"> 王對上帝的僕人說：「請你為我禱告，求你的上帝耶和華使我的手復原。」於是，上帝的僕人向耶和華禱告，王的手就復原了。</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀下 5:15; 撒母耳記上 9:7–8; 士師記 13:15"> 王對上帝的僕人說：「請你跟我回宮，吃點東西吧！我要酬謝你。」</span>
<span className="v" id="v8" data-v="8" data-xref="民數記 24:13; 民數記 22:18; 馬可福音 6:23"> 上帝的僕人卻說：「你就是把你一半的家產送給我，我也不跟你去，也不在這地方用飯喝水，</span>
<span className="v" id="v9" data-v="9" data-xref="約翰福音 13:17; 申命記 13:13–18; 羅馬書 16:17"> 因為耶和華吩咐我不可吃飯喝水，也不可原路返回。」</span>
<span className="v" id="v10" data-v="10"> 上帝的僕人就從另一條路回去了，沒有從伯特利原路返回。</span>
<span className="v" id="v11" data-v="11" data-xref="列王紀下 23:18; 列王紀上 13:20–21; 民數記 24:2"> 在伯特利住著一位老先知，他兒子們把上帝的僕人那天所行的事和對王所說的話告訴了他。</span>
<span className="v" id="v12" data-v="12"> 老先知問道：「上帝的僕人走的哪條路？」他的兒子們就把上帝的僕人走的那條路告訴了他。</span>
<span className="v" id="v13" data-v="13" data-xref="士師記 10:4; 撒母耳記下 19:26; 士師記 5:10"> 於是，他囑咐兒子們為他備驢，然後騎驢去追趕上帝的僕人，看見他正坐在一棵橡樹下，便問：「你就是那位從猶大來的上帝的僕人嗎？」他說：「是。」</span>
<span className="v" id="v15" data-v="15"> 老先知說：「請你跟我一起回家吃飯吧！」</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀上 13:8–9; 馬太福音 16:23; 民數記 22:19"> 上帝的僕人說：「我不能跟你去，也不能跟你在這裡吃飯喝水，</span>
<span className="v" id="v17" data-v="17" data-xref="列王紀上 20:35; 帖撒羅尼迦前書 4:15; 列王紀上 13:1"> 因為耶和華吩咐我不可在這裡用飯喝水，也不可原路返回。」</span>
<span className="v" id="v18" data-v="18" data-xref="約翰一書 4:1; 馬太福音 7:15; 民數記 22:35"> 老先知就欺騙他說：「我也是先知，和你一樣。耶和華派天使來吩咐我帶你到我家吃飯喝水。」</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 13:1; 創世記 3:6; 使徒行傳 4:19"> 上帝的僕人就隨他回家吃飯喝水。</span>
<span className="v" id="v20" data-v="20" data-xref="馬太福音 7:22; 民數記 24:4; 民數記 24:16–24"> 席間，耶和華的話臨到老先知，</span>
<span className="v" id="v21" data-v="21" data-xref="列王紀上 13:17; 撒母耳記上 13:13–14; 撒母耳記上 4:18"> 他就對從猶大來的上帝的僕人說：「耶和華說，你違背了你的上帝耶和華的命令，沒有遵從祂的吩咐，</span>
<span className="v" id="v22" data-v="22" data-xref="以賽亞書 14:18–20; 列王紀上 14:13; 耶利米書 22:18–19"> 竟然返回祂禁止你吃喝的地方吃飯喝水，因此你的屍體必不得安葬在你的祖墳裡。」</span>
<span className="v" id="v23" data-v="23"> 吃喝完了，老先知為他帶回家的這位先知備驢，</span>
<span className="v" id="v24" data-v="24" data-xref="列王紀上 20:36; 列王紀下 2:24; 箴言 26:13"> 這位先知在路上遇到一頭獅子，被咬死了，屍體倒在路上，驢和獅子都站在屍體旁邊。</span>
<span className="v" id="v25" data-v="25" data-xref="列王紀上 13:11"> 過路的人看見屍體倒在路上，旁邊還站著一頭獅子，就去老先知住的城報告這事。</span>
<span className="v" id="v26" data-v="26" data-xref="以西結書 9:6; 箴言 11:31; 詩篇 119:120"> 老先知聽到消息，就說：「這是上帝的僕人，他違背了耶和華的命令，所以耶和華讓獅子咬死了他，正應驗了耶和華的話。」</span>
<span className="v" id="v27" data-v="27"> 他吩咐兒子們備好驢，</span>
<span className="v" id="v28" data-v="28" data-xref="列王紀上 17:6; 詩篇 148:7–8; 但以理書 6:22–24"> 去了那裡，看見上帝僕人的屍體倒在路上，驢和獅子站在屍體旁。獅子既沒有吃屍體，也沒有傷害驢。</span>
<span className="v" id="v29" data-v="29"> 老先知把上帝僕人的屍體馱在驢背上，運回城中為他哀悼，</span>
<span className="v" id="v30" data-v="30" data-xref="耶利米書 22:18; 使徒行傳 8:2; 列王紀上 14:13"> 把他葬在自己的墳墓裡，哀悼他說：「唉！我的弟兄啊！」</span>
<span className="v" id="v31" data-v="31" data-xref="列王紀下 23:17–18; 民數記 23:10; 路加福音 16:22–23"> 安葬之後，老先知又對兒子們說：「我死後，你們要把我跟上帝的僕人合葬，讓我們的屍骨在一起。</span>
<span className="v" id="v32" data-v="32" data-xref="列王紀上 16:24; 列王紀上 13:2; 列王紀上 12:31"> 因為他奉耶和華的命令咒詛伯特利的祭壇和撒瑪利亞各城高崗上神廟的話必應驗。」</span>
<span className="v" id="v33" data-v="33" data-xref="歷代志下 11:15; 歷代志下 13:9; 民數記 17:12–13"> 這事以後，耶羅波安沒有改邪歸正，他任命各種人做邱壇的祭司，不管誰想做祭司，他都封立他們。</span>
<span className="v" id="v34" data-v="34" data-xref="列王紀上 14:10; 列王紀上 15:29–30; 列王紀上 12:30"> 這罪使耶羅波安家走向沒落，最終徹底滅亡。</span>

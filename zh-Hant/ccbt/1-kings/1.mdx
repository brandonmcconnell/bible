## 王位之爭

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="約書亞記 23:1–2; 歷代志上 29:27–28; 歷代志上 23:1"> 大衛王年紀老邁，雖然蓋了幾層被子，仍然覺得冷。</span>
<span className="v" id="v2" data-v="2" data-xref="傳道書 4:11; 創世記 16:5; 彌迦書 7:5"> 他的臣僕建議：「不如選一位少女進宮伺候、照顧我主我王，讓她睡在王懷中給王取暖。」</span>
<span className="v" id="v3" data-v="3" data-xref="約書亞記 19:18; 以斯帖記 2:4; 以斯帖記 2:2"> 於是，他們在以色列全國尋找美貌女子，找到了一位名叫雅比莎的書念少女，把她帶到王那裡。</span>
<span className="v" id="v4" data-v="4" data-xref="馬太福音 1:25"> 這女子長得非常美麗，她照顧、伺候王，但王沒有與她同房。</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳記下 15:1; 撒母耳記下 3:4; 申命記 17:15–16"> 那時，哈及的兒子亞多尼雅妄自尊大，說：「我必做王。」他為自己製備了車輛和騎兵，派五十人在前面開路。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳記下 3:3–4; 撒母耳記上 3:13; 希伯來書 12:5–6"> 他父親從不責問他：「你這是做什麼？」他是押沙龍的弟弟，長得英俊非凡。</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳記下 20:25; 列王紀上 2:22; 撒母耳記上 22:20–23"> 亞多尼雅與洗魯雅的兒子約押及祭司亞比亞他商議，二人都答應支持他。</span>
<span className="v" id="v8" data-v="8" data-xref="列王紀上 4:18; 撒母耳記下 23:8–39; 撒母耳記下 20:25"> 不過，撒督祭司、耶何耶大的兒子比拿雅、拿單先知、示每、利以和大衛的勇士卻沒有跟隨他。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳記下 17:17; 撒母耳記下 13:23–27; 撒母耳記下 15:11–12"> 一天，亞多尼雅在隱·羅結附近的瑣希列磐石那裡宰了牛羊和肥牛犢獻祭，並邀請了眾王子和猶大的群臣。</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳記下 12:24; 列王紀上 1:19; 撒母耳記下 12:1–15"> 可是他沒有邀請拿單先知、比拿雅、大衛的勇士和他的兄弟所羅門。</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳記下 3:4; 撒母耳記下 7:12–17; 撒母耳記下 12:24–25"> 拿單對所羅門的母親拔示巴說：「你沒有聽說嗎？哈及的兒子亞多尼雅做王了，我們的主大衛還不知道。</span>
<span className="v" id="v12" data-v="12" data-xref="箴言 11:14; 使徒行傳 27:31; 創世記 19:17"> 事到如今，我有一個主意，可以保住你和你兒子所羅門的性命。</span>
<span className="v" id="v13" data-v="13" data-xref="列王紀上 1:30; 列王紀上 1:17; 詩篇 132:11–12"> 你去見大衛王，對他說，『我主我王啊，你不是起誓說讓臣妾的兒子所羅門繼承王位，坐你的寶座嗎？怎麼現在亞多尼雅做了王呢？』</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多後書 13:1; 列王紀上 1:17–27"> 你跟王還在說話的時候，我會進去證實你的話。」</span>
<span className="v" id="v15" data-v="15" data-xref="列王紀上 1:1"> 拔示巴就進內室去見年邁的王，書念的少女雅比莎正在伺候他。</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳記上 25:23; 撒母耳記上 24:8; 撒母耳記上 20:41"> 拔示巴向王屈身下拜。王問道：「你有什麼事嗎？」</span>
<span className="v" id="v17" data-v="17" data-xref="列王紀上 1:13; 列王紀上 1:30; 彼得前書 3:6"> 拔示巴回答說：「我主啊，你曾經憑你的上帝耶和華起誓說讓臣妾的兒子所羅門繼承你的王位，坐你的寶座。</span>
<span className="v" id="v18" data-v="18" data-xref="列王紀上 1:24; 列王紀上 1:11; 使徒行傳 3:17"> 但現在亞多尼雅已經稱王了，我主我王還不知道。</span>
<span className="v" id="v19" data-v="19" data-xref="列王紀上 1:25; 列王紀上 1:7–10"> 他宰了許多牛羊和肥牛犢獻祭，邀請眾王子、亞比亞他祭司和約押元帥，卻沒有邀請你的僕人所羅門。</span>
<span className="v" id="v20" data-v="20" data-xref="歷代志上 29:1; 詩篇 123:2; 歷代志上 22:8–10"> 我主我王啊！以色列舉國拭目以待，等你來指定誰坐在我主我王的寶座上繼承王位。</span>
<span className="v" id="v21" data-v="21" data-xref="列王紀上 2:10; 申命記 31:16; 創世記 15:15"> 不然，到我主我王與祖先同眠之後，我和我兒所羅門必被定為罪人。」</span>
<span className="v" id="v22" data-v="22" data-xref="約伯記 1:16–18; 創世記 24:15; 但以理書 9:20"> 她與王正說話間，拿單先知進宮來了。</span>
<span className="v" id="v23" data-v="23" data-xref="列王紀上 1:16; 彼得前書 2:17; 羅馬書 13:7"> 有人奏告王，說：「拿單先知來了。」拿單來到王面前，俯伏在地，</span>
<span className="v" id="v24" data-v="24" data-xref="列王紀上 1:17–18; 列王紀上 1:5; 列王紀上 1:13–14"> 說：「我主我王啊，你已經宣佈讓亞多尼雅繼承你的王位，坐你的寶座嗎？</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳記上 10:24; 列王紀上 1:19; 列王紀上 1:9"> 他今天宰了許多牛羊和肥犢獻祭，宴請眾王子、將領和亞比亞他祭司，他們正在他那裡一邊吃喝一邊說，『亞多尼雅王萬歲！』</span>
<span className="v" id="v26" data-v="26" data-xref="列王紀上 1:8; 列王紀上 1:10; 撒母耳記下 7:2"> 但他沒有邀請臣僕我、撒督祭司、耶何耶大的兒子比拿雅和你的僕人所羅門。</span>
<span className="v" id="v27" data-v="27" data-xref="約翰福音 15:15; 列王紀上 1:24; 列王紀下 4:27"> 這是我主我王的旨意嗎？王還沒有對臣僕們說過誰坐在我主我王的寶座上繼承王位。」</span>
<span className="v" id="v28" data-v="28"> 於是，大衛王召見拔示巴。拔示巴立刻晉見，侍立在王面前。</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳記下 4:9; 詩篇 136:24; 撒母耳記上 14:45"> 王起誓說：「我憑救我脫離一切苦難的永活的耶和華起誓，</span>
<span className="v" id="v30" data-v="30" data-xref="列王紀上 1:13; 列王紀上 1:17"> 我今天必實現我憑以色列的上帝耶和華向你起的誓。你的兒子所羅門必繼承王位，坐在我的寶座上。」</span>
<span className="v" id="v31" data-v="31" data-xref="但以理書 2:4; 但以理書 5:10; 但以理書 3:9"> 拔示巴就向王俯伏下拜說：「我主大衛王萬歲！」</span>
<span className="v" id="v32" data-v="32" data-xref="列王紀上 1:8; 列王紀上 1:38; 列王紀上 1:26"> 大衛王又召見撒督祭司、拿單先知和耶何耶大的兒子比拿雅。他們都來到王面前。</span>
<span className="v" id="v33" data-v="33" data-xref="歷代志下 32:30; 列王紀上 1:38; 歷代志下 33:14"> 王囑咐道：「你們要率領我的隨從，讓我兒所羅門騎上我的騾子，護送他下到基訓。</span>
<span className="v" id="v34" data-v="34" data-xref="列王紀上 1:25; 撒母耳記下 15:10; 撒母耳記上 10:1"> 撒督祭司和拿單先知要在那裡膏立他為以色列王。你們要吹響號角，高喊，『所羅門王萬歲！』</span>
<span className="v" id="v35" data-v="35" data-xref="列王紀上 1:17; 詩篇 72:1–2; 列王紀上 1:13"> 然後，你們要隨他回來，他要登基，繼承我的王位。我已立他做以色列和猶大的君王了。」</span>
<span className="v" id="v36" data-v="36" data-xref="耶利米書 28:6; 哥林多前書 14:16; 詩篇 72:19"> 耶何耶大的兒子比拿雅說：「遵命！願我主我王的上帝耶和華成全這事。</span>
<span className="v" id="v37" data-v="37" data-xref="撒母耳記上 20:13; 列王紀上 1:47; 約書亞記 1:17"> 耶和華怎樣與我主我王同在，願祂也照樣與所羅門同在，使他的王權比我主大衛王的更強大。」</span>
<span className="v" id="v38" data-v="38" data-xref="撒母耳記下 8:18; 列王紀上 1:8; 列王紀上 1:33"> 於是，撒督祭司、拿單先知、耶何耶大的兒子比拿雅，以及基利提人和比利提人請所羅門騎上大衛王的騾子，護送他前往基訓。</span>
<span className="v" id="v39" data-v="39" data-xref="詩篇 89:20; 列王紀上 1:34; 歷代志上 29:22"> 撒督祭司從聖幕裡拿來盛膏油的角，膏立所羅門為王。他們吹響號角，民眾高聲歡呼：「所羅門王萬歲！」</span>
<span className="v" id="v40" data-v="40" data-xref="列王紀下 11:14; 撒迦利亞書 9:9; 列王紀下 11:20"> 眾人浩浩蕩蕩地隨著所羅門回京，一路上吹笛歡呼，聲音震動大地。</span>
<span className="v" id="v41" data-v="41" data-xref="約伯記 15:21–22; 路加福音 17:26–29; 使徒行傳 21:31"> 亞多尼雅和他的眾賓客剛剛飲宴完畢，聽見了這聲音。約押聽見號角聲，便問：「城裡為什麼如此喧鬧？」</span>
<span className="v" id="v42" data-v="42" data-xref="撒母耳記下 15:36; 撒母耳記下 17:17; 撒母耳記下 18:27"> 就在這時候，亞比亞他祭司的兒子約拿單來了，亞多尼雅說：「進來！你是個忠勇的人，一定帶來了好消息。」</span>
<span className="v" id="v43" data-v="43"> 約拿單說：「我們的主大衛王已經立所羅門為王了。</span>
<span className="v" id="v44" data-v="44"> 王派撒督祭司、拿單先知、耶何耶大的兒子比拿雅，以及基利提人和比利提人護送所羅門騎上王的騾子。</span>
<span className="v" id="v45" data-v="45" data-xref="列王紀上 1:40; 但以理書 5:26–28; 撒母耳記上 4:5"> 撒督祭司和拿單先知在基訓膏立他為王，他們一路上歡呼著回來了，全城轟動。你們聽到的就是他們的聲音。</span>
<span className="v" id="v46" data-v="46" data-xref="歷代志上 29:23; 詩篇 132:11; 列王紀上 1:13"> 所羅門已經登基掌權，</span>
<span className="v" id="v47" data-v="47" data-xref="創世記 47:31; 列王紀上 1:37; 以斯拉記 6:10"> 王的臣僕也來向我們的主大衛王道喜說，『願你的上帝使所羅門比你名聲更大，使他的王權比你的更強大。』王在床上俯伏敬拜，</span>
<span className="v" id="v48" data-v="48" data-xref="列王紀上 3:6; 詩篇 132:11–12; 詩篇 145:2"> 說，『以色列的上帝耶和華當受稱頌，因為祂讓我親眼看見我的繼承人今天登基。』」</span>
<span className="v" id="v49" data-v="49" data-xref="以賽亞書 21:4–5; 箴言 28:1; 但以理書 5:4–6"> 亞多尼雅的眾賓客聽後，嚇得四散而去。</span>
<span className="v" id="v50" data-v="50" data-xref="列王紀上 2:28; 出埃及記 21:14; 出埃及記 27:2"> 亞多尼雅懼怕所羅門，就去抓住祭壇的角。</span>
<span className="v" id="v51" data-v="51"> 有人告訴所羅門：「亞多尼雅懼怕王，現在正抓住祭壇的角，要王今天起誓不要殺他。」</span>
<span className="v" id="v52" data-v="52" data-xref="撒母耳記上 14:45; 撒母耳記下 14:11; 箴言 13:6"> 所羅門說：「他若作個忠義的人，必毫髮無損；他若作惡，必死無疑。」</span>
<span className="v" id="v53" data-v="53" data-xref="列王紀上 1:16; 撒母耳記下 14:24; 撒母耳記下 1:2"> 於是，所羅門王便派人去把亞多尼雅從祭壇上帶下來。亞多尼雅前來向所羅門王俯伏下拜，所羅門對他說：「你回家去吧。」</span>

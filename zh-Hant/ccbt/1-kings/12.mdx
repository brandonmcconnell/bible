## 北方支派背叛羅波安

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="士師記 9:6; 歷代志下 10:1–19; 士師記 9:1"> 羅波安前往示劍，因為以色列人都去了那裡，要立他為王。</span>
<span className="v" id="v2" data-v="2" data-xref="列王紀上 11:40; 歷代志下 10:2–3; 列王紀上 11:26–31"> 尼八的兒子耶羅波安曾為了躲避所羅門王而逃往埃及，並一直住在那裡。他聽到消息便從埃及返回以色列。</span>
<span className="v" id="v3" data-v="3"> 以色列人派人去請他，他就和以色列會眾去見羅波安，說：</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳記上 8:11–18; 列王紀上 4:7; 馬太福音 11:29–30"> 「你父親使我們負擔沉重，求你減輕我們的勞役和負擔吧，我們一定服侍你。」</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀上 12:12"> 羅波安對他們說：「你們先回去，三天之後再來見我。」眾人就離開了。</span>
<span className="v" id="v6" data-v="6" data-xref="約伯記 12:12; 約伯記 32:7; 撒母耳記下 16:20"> 羅波安王去徵詢曾服侍他父親所羅門的老臣的意見，說：「你們認為我該怎樣回覆這些民眾？」</span>
<span className="v" id="v7" data-v="7" data-xref="箴言 15:1; 歷代志下 10:6–7; 列王紀上 12:13"> 他們回稟說：「現今王若像僕人一樣服侍民眾，對他們好言相待，他們會永遠做王的僕人。」</span>
<span className="v" id="v8" data-v="8" data-xref="箴言 19:20; 傳道書 10:2–3; 歷代志下 10:8"> 羅波安卻沒有採納老臣的意見。他又去徵詢那些和他一起長大的青年臣僚的意見，</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀上 22:6–8; 撒母耳記下 17:5–6; 歷代志下 10:9"> 說：「民眾求我減輕我父親加給他們的重擔。你們認為我該怎樣回覆他們？」</span>
<span className="v" id="v10" data-v="10" data-xref="歷代志下 10:10–11; 箴言 10:14; 以賽亞書 47:6"> 他們說：「民眾說你父親使他們負擔沉重，請求你減輕他們的負擔。你可以這樣回覆他們，『我的小指頭比我父親的腰還粗。</span>
<span className="v" id="v11" data-v="11" data-xref="耶利米書 27:11; 以西結書 2:6; 耶利米書 28:13–14"> 我父親使你們負重擔，我要使你們負更重的擔子；我父親用鞭子打你們，我要用刺鞭打你們。』」</span>
<span className="v" id="v12" data-v="12" data-xref="列王紀上 12:5; 歷代志下 10:12–14"> 過了三天，耶羅波安和民眾遵照羅波安王的話來見他。</span>
<span className="v" id="v13" data-v="13" data-xref="雅各書 3:17; 箴言 13:20; 傳道書 10:12"> 王沒有採納老臣的建議，而是照青年臣僚的建議，疾言厲色地對他們說：「我父親使你們負重擔，我要使你們負更重的擔子！我父親用鞭子打你們，我要用刺鞭打你們！」</span>
<span className="v" id="v15" data-v="15" data-xref="列王紀上 12:24; 申命記 2:30; 士師記 14:4"> 王不聽民眾的請求。這事出於耶和華，為要應驗祂藉示羅人亞希雅先知對尼八的兒子耶羅波安說的話。</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳記下 20:1; 耶利米書 23:5–6; 歷代志下 10:16"> 以色列人見王不聽他們的請求，就說：<br /><span className="pl pl-1">「我們與大衛有何相干？</span><br /><span className="pl pl-1">我們與耶西的兒子沒有關係！</span><br /><span className="pl pl-1">以色列人啊，各自回家吧！</span><br /><span className="pl pl-1">大衛家啊，自己顧自己吧！」</span>於是，以色列人各自回家了。</span>
<span className="v" id="v17" data-v="17" data-xref="列王紀上 11:36; 列王紀上 11:13; 歷代志下 11:13–17"> 但住在猶大城邑的以色列人仍受羅波安統治。</span>
<span className="v" id="v18" data-v="18" data-xref="列王紀上 4:6; 撒母耳記下 20:24; 列王紀上 5:14"> 羅波安王派勞役總管亞多蘭去以色列人那裡，以色列人卻用石頭打死了他，羅波安王連忙上車逃回耶路撒冷。</span>
<span className="v" id="v19" data-v="19" data-xref="列王紀下 17:21; 歷代志下 10:19; 約書亞記 4:9"> 從此，以色列人反叛大衛家，直到今天。</span>
<span className="v" id="v20" data-v="20" data-xref="列王紀上 11:13; 列王紀上 11:32; 何西阿書 8:4"> 以色列人聽說耶羅波安回來了，就請他到會眾面前，擁立他做以色列人的王。只有猶大支派仍然效忠大衛家。</span>
<span className="v" id="v21" data-v="21" data-xref="歷代志下 11:1–3; 歷代志上 21:5; 歷代志下 14:8"> 羅波安回到耶路撒冷，從猶大和便雅憫支派召集了十八萬精兵，要攻打以色列人，收復全國。</span>
<span className="v" id="v22" data-v="22" data-xref="歷代志下 11:2; 歷代志下 12:5–7; 列王紀上 13:1"> 然而，上帝對祂的僕人示瑪雅說：</span>
<span className="v" id="v23" data-v="23" data-xref="列王紀上 12:17"> 「你去告訴所羅門的兒子猶大王羅波安和猶大、便雅憫支派的人以及其他民眾，</span>
<span className="v" id="v24" data-v="24" data-xref="列王紀上 12:15; 歷代志下 25:7–8; 何西阿書 8:4"> 耶和華這樣說，『你們不要上去與以色列弟兄交戰，都回家吧！今日的景況是出於我的旨意。』」眾人聽從了耶和華的話，各自回家去了。</span>
</div>

## 耶羅波安背棄上帝

<div className="bt">
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="士師記 8:17; 士師記 8:8; 士師記 9:45–49"> 耶羅波安在以法蓮山區修建示劍城，住在那裡。他後來又去修建毗努伊勒。</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米書 38:18–21; 以賽亞書 7:9; 馬可福音 2:6–8"> 他心想：「國權恐怕會重歸大衛家。</span>
<span className="v" id="v27" data-v="27" data-xref="申命記 12:5–7; 箴言 29:25; 申命記 12:14"> 若百姓去耶路撒冷，在耶和華的殿獻祭，他們的心必重新歸向他們的主猶大王羅波安。他們會殺了我，然後投奔猶大王羅波安。」</span>
<span className="v" id="v28" data-v="28" data-xref="列王紀下 10:29; 出埃及記 32:8; 列王紀下 17:16"> 他徵詢臣僚的意見後，就鑄造了兩個金牛犢，對民眾說：「以色列人啊，你們上耶路撒冷敬拜太麻煩了。這兩個金牛犢就是帶你們出埃及的神明。」</span>
<span className="v" id="v29" data-v="29" data-xref="創世記 28:19; 士師記 18:27–31; 何西阿書 4:15"> 他把一個金牛犢安置在伯特利，另一個安置在但。</span>
<span className="v" id="v30" data-v="30" data-xref="列王紀下 17:21; 列王紀上 13:34; 列王紀下 10:31"> 這使民眾陷入罪中，因為他們開始到但去拜金牛犢。</span>
<span className="v" id="v31" data-v="31" data-xref="歷代志下 13:9; 列王紀下 17:32; 列王紀上 13:32–33"> 耶羅波安又在高崗上修建神廟，任命各種人做祭司，他們並非利未人。</span>
<span className="v" id="v32" data-v="32" data-xref="列王紀上 8:5; 列王紀上 8:2; 阿摩司書 7:10–13"> 耶羅波安規定每年八月十五日為節期，好像猶大的節期一樣。他自己在伯特利的祭壇上向金牛犢獻祭，又在伯特利為他修建的神廟設立祭司。</span>
<span className="v" id="v33" data-v="33" data-xref="列王紀上 13:1; 民數記 15:39; 馬太福音 15:6"> 在八月十五日，就是他私自為以色列人定為節期的日子，他在伯特利自己修建的祭壇上燒香。</span>

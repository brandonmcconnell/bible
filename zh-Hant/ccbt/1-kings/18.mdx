## 以利亞戰勝巴力的先知

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 4:25; 雅各書 5:17; 申命記 28:12"> 旱災持續了三年。一天，耶和華對以利亞說：「你去見亞哈。我要降雨在地上。」</span>
<span className="v" id="v2" data-v="2" data-xref="列王紀下 6:25; 箴言 28:1; 利未記 26:26"> 以利亞就去見亞哈。當時，撒瑪利亞正遭受嚴重饑荒。</span>
<span className="v" id="v3" data-v="3" data-xref="尼希米記 7:2; 列王紀上 16:9; 馬太福音 10:28"> 亞哈的宮廷總管俄巴底非常敬畏耶和華，耶洗別屠殺耶和華的眾先知時，他救了一百名先知，把他們分別藏在兩個山洞裡，每洞五十人，並供應他們飲食。亞哈召見俄巴底，</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米書 14:5–6; 約珥書 1:18; 約珥書 2:22"> 對他說：「我們去各地的水泉和河谷，也許可以找到草救活騾馬，不致喪失牲畜。」</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米書 14:3"> 於是，亞哈和俄巴底分頭到不同地區尋找。</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀下 1:6–8; 創世記 44:20; 以賽亞書 60:14"> 俄巴底在路上遇見了以利亞，俄巴底認出了他，就俯伏在地上說：「你是我主以利亞嗎？」</span>
<span className="v" id="v8" data-v="8" data-xref="羅馬書 13:7; 列王紀上 18:3; 彼得前書 2:17–18"> 以利亞回答說：「我就是，你去告訴你主人我在這裡。」</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及記 5:21; 列王紀上 18:12; 列王紀上 17:18"> 俄巴底說：「僕人犯了什麼罪，你竟叫我去亞哈那裡送死？</span>
<span className="v" id="v10" data-v="10" data-xref="列王紀上 17:1; 列王紀上 1:29; 列王紀上 18:15"> 我憑你的上帝——永活的耶和華起誓，王派人到各邦各國尋找你，任何邦國若說你不在那裡，王就要他們起誓說真的找不到你。</span>
<span className="v" id="v11" data-v="11" data-xref="列王紀上 18:8; 列王紀上 18:14"> 現在，你叫我去告訴我主人你在這裡，</span>
<span className="v" id="v12" data-v="12" data-xref="列王紀下 2:16; 使徒行傳 8:39; 以西結書 8:3"> 我離開你以後，不知道耶和華的靈會把你帶到哪裡。如果我去告訴亞哈，他來了卻找不到你，必定會殺我。但僕人自幼就敬畏耶和華。</span>
<span className="v" id="v13" data-v="13" data-xref="列王紀上 18:4; 馬太福音 25:35; 詩篇 18:21–24"> 耶洗別屠殺耶和華的眾先知時，我把一百名先知分別藏在兩個山洞裡，每洞五十人，供應他們飲食。我主沒有聽說這事嗎？</span>
<span className="v" id="v14" data-v="14" data-xref="馬太福音 10:28"> 現在，你要我去告訴我主人你在這裡，這是讓我去送死。」</span>
<span className="v" id="v15" data-v="15" data-xref="列王紀上 17:1; 列王紀上 18:10; 路加福音 2:13–14"> 以利亞說：「我事奉的是永活的萬軍之耶和華，我憑祂起誓，我今天必出現在亞哈面前。」</span>
<span className="v" id="v16" data-v="16"> 於是，俄巴底去稟告亞哈，亞哈就來找以利亞，</span>
<span className="v" id="v17" data-v="17" data-xref="約書亞記 7:25; 列王紀上 21:20; 使徒行傳 16:20"> 見到以利亞後，就說：「給以色列帶來災禍的就是你嗎？」</span>
<span className="v" id="v18" data-v="18" data-xref="歷代志下 15:2; 列王紀上 9:9; 耶利米書 2:19"> 以利亞回答說：「給以色列帶來災禍的不是我，而是你和你父親家，因為你們拋棄耶和華的誡命，去隨從巴力。</span>
<span className="v" id="v19" data-v="19" data-xref="約書亞記 19:26; 列王紀上 16:33; 彼得後書 2:1"> 現在，你快派人去召集所有的以色列人到迦密山來見我，把四百五十名巴力的先知和耶洗別所供養的四百名亞舍拉的先知也帶來。」</span>
<span className="v" id="v20" data-v="20" data-xref="列王紀上 22:9"> 亞哈便派人把以色列人和那些先知招聚到迦密山。</span>
<span className="v" id="v21" data-v="21" data-xref="馬太福音 6:24; 約書亞記 24:15; 哥林多前書 10:21–22"> 以利亞走到眾人面前說：「你們三心二意要到什麼時候呢？如果耶和華是上帝，你們當跟從祂；如果巴力是上帝，你們就跟從他吧！」他們都默不作聲。</span>
<span className="v" id="v22" data-v="22" data-xref="列王紀上 19:10; 列王紀上 19:14; 提摩太後書 4:3–4"> 以利亞繼續對眾人說：「耶和華的先知現在只剩下我一人，巴力的先知卻有四百五十人。</span>
<span className="v" id="v23" data-v="23"> 請給我們牽兩頭公牛來，巴力的先知可以選一頭，切成塊放在柴上，但不要點火；我會把另一頭公牛預備好，放在柴上，也不點火。</span>
<span className="v" id="v24" data-v="24" data-xref="列王紀上 18:38; 歷代志上 21:26; 歷代志下 7:1"> 然後，你們求告你們神明的名字，我求告耶和華的名，那聽禱告降下火來的就是上帝。」眾人非常贊同他的主意。</span>
<span className="v" id="v25" data-v="25"> 以利亞對巴力的先知說：「你們人數眾多，可先選一頭公牛預備好，然後呼求你們的神明，但不可點火。」</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米書 10:5; 哥林多前書 8:4; 馬太福音 6:7"> 他們取了公牛預備好，然後從早上到正午不斷地呼求巴力的名：「巴力啊，求你應允我們！」可是毫無動靜。他們又繞著自己築的祭壇跳個不停。</span>
<span className="v" id="v27" data-v="27" data-xref="詩篇 78:65–66; 以賽亞書 41:23; 傳道書 11:9"> 中午時分，以利亞譏諷他們說：「喊大聲點吧，它肯定是神明！也許它在沉思冥想，也許太忙了，也許出遊了，也許睡著了，需要人叫醒它！」</span>
<span className="v" id="v28" data-v="28" data-xref="利未記 19:28; 申命記 14:1; 馬可福音 5:5"> 於是，他們更加大聲呼求，並按自己的風俗用刀槍自割自刺，直到身體流血。</span>
<span className="v" id="v29" data-v="29" data-xref="列王紀上 18:26; 撒母耳記上 18:10; 出埃及記 29:39"> 過了中午，他們仍不斷地狂呼亂叫，直到獻晚祭的時候，仍然毫無動靜，沒有半點反應。</span>
<span className="v" id="v30" data-v="30" data-xref="歷代志下 33:16; 列王紀上 19:14; 列王紀上 19:10"> 以利亞把眾人召集到自己跟前，他重修已遭毀壞的耶和華的祭壇，</span>
<span className="v" id="v31" data-v="31" data-xref="列王紀下 17:34; 創世記 35:10; 創世記 32:28"> 拿了十二塊石頭分別代表雅各子孫的十二支派。耶和華曾經對雅各說：「你的名字要叫以色列。」</span>
<span className="v" id="v32" data-v="32" data-xref="歌羅西書 3:17; 出埃及記 20:24–25; 士師記 21:4"> 以利亞就奉耶和華的名用那些石頭築了一座祭壇，又在壇的周圍挖了一條能盛十五升穀種的溝，</span>
<span className="v" id="v33" data-v="33" data-xref="創世記 22:9; 士師記 6:20; 利未記 1:6–8"> 然後在壇上擺好柴，把公牛切成塊放在柴上，對眾人說：「你們去打四桶水倒在祭物和柴上。」他們照做了。</span>
<span className="v" id="v34" data-v="34" data-xref="哥林多後書 8:21; 哥林多後書 4:2"> 以利亞吩咐他們再倒一次，他們又倒了一次。以利亞又吩咐他們倒第三次，他們就倒了第三次。</span>
<span className="v" id="v35" data-v="35" data-xref="列王紀上 18:32; 列王紀上 18:38"> 水流到壇的四周，溝裡也灌滿了。</span>
<span className="v" id="v36" data-v="36" data-xref="列王紀上 18:29; 列王紀下 19:19; 出埃及記 3:6"> 到了獻晚祭的時候，以利亞先知走到壇前禱告：「亞伯拉罕、以撒、以色列的上帝耶和華啊，求你今天讓這些人知道你是以色列的上帝，我是你的僕人，我是按你的命令做這一切事。</span>
<span className="v" id="v37" data-v="37" data-xref="但以理書 9:17–19; 路加福音 1:16–17; 以西結書 36:25–27"> 耶和華啊，求你應允我，應允我，好讓眾人知道你耶和華是上帝，你要使他們回心轉意。」</span>
<span className="v" id="v38" data-v="38" data-xref="歷代志上 21:26; 利未記 9:24; 歷代志下 7:1"> 於是，耶和華降火燒盡了祭物、木柴、石頭、塵土，甚至燒乾了溝裡的水。</span>
<span className="v" id="v39" data-v="39" data-xref="列王紀上 18:24; 歷代志下 7:3; 列王紀上 18:21"> 眾人看見這情景，都俯伏在地高呼：「耶和華是上帝！耶和華是上帝！」</span>
<span className="v" id="v40" data-v="40" data-xref="申命記 18:20; 士師記 4:7; 申命記 13:5"> 以利亞對他們說：「抓住巴力的先知，別放走一個人！」眾人就抓住他們，以利亞把他們帶到基順河邊，在那裡殺了他們。</span>

## 上帝降雨

<div className="bt">
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="列王紀上 18:1; 傳道書 9:7; 列王紀上 17:1"> 以利亞對亞哈說：「你去吃喝吧，因為已傳來大雨聲。」</span>
<span className="v" id="v42" data-v="42" data-xref="路加福音 6:12; 但以理書 9:7; 約書亞記 7:6"> 亞哈就去吃喝。以利亞上到迦密山頂，跪在地上，臉伏在雙膝之間。</span>
<span className="v" id="v43" data-v="43" data-xref="哈巴谷書 2:3; 路加福音 18:7; 路加福音 18:1"> 他吩咐僕人：「你去向海的方向觀看。」僕人就去觀看，然後說：「什麼也沒有。」以利亞又讓他去觀看，前後共七次。</span>
<span className="v" id="v44" data-v="44" data-xref="路加福音 12:54; 約伯記 8:7; 撒迦利亞書 4:10"> 第七次，僕人說：「我看見一朵手掌那麼大的雲從海裡升起來了。」以利亞便吩咐他：「你去告訴亞哈，叫他套車下山，免得被雨阻擋。」</span>
<span className="v" id="v45" data-v="45" data-xref="列王紀上 18:39–40; 約書亞記 17:16; 列王紀上 21:1"> 霎時間，天上烏雲密佈，狂風大作，下起大雨。亞哈坐著馬車回耶斯列。</span>
<span className="v" id="v46" data-v="46" data-xref="以西結書 3:14; 以西結書 1:3; 列王紀下 9:1"> 耶和華的手按在以利亞身上，他就束上腰帶，飛奔回城，在亞哈之前到達耶斯列的城門。</span>

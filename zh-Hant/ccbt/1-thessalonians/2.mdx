## 保羅在帖撒羅尼迦的工作

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="帖撒羅尼迦後書 3:1; 哥林多前書 15:2; 哥林多前書 15:58"> 弟兄姊妹，你們自己知道，我們那次探望你們並沒有白費。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行傳 16:22–24; 使徒行傳 4:13; 使徒行傳 17:2–9"> 你們也知道，我們之前在腓立比遭受了迫害和凌辱，但仍然不顧強烈的反對，靠著我們的上帝放膽向你們傳揚祂的福音。</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多後書 2:17; 哥林多後書 4:2; 帖撒羅尼迦前書 4:7"> 我們的勸勉並非出於謬誤、不良動機或詭詐。</span>
<span className="v" id="v4" data-v="4" data-xref="加拉太書 1:10; 羅馬書 8:27; 加拉太書 2:7"> 我們得到了上帝的恩准來承擔福音的責任，所以才這樣傳，不是要取悅人，而是要取悅鑒察我們內心的上帝。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="羅馬書 1:9; 哥林多後書 12:17; 使徒行傳 20:33"> 你們知道，我們沒有花言巧語奉承人，也沒有心存貪念，上帝可以為我們作證。</span>
<span className="v" id="v6" data-v="6" data-xref="加拉太書 1:10; 帖撒羅尼迦前書 2:9; 約翰福音 5:41"> 我們不求得到你們或其他任何人的讚揚，</span>
<span className="v" id="v7" data-v="7" data-xref="以賽亞書 66:13; 帖撒羅尼迦前書 2:11; 提摩太後書 2:24–25"> 雖然身為基督的使徒，我們理當受到尊重。我們反而像母親撫育嬰兒一樣溫柔地對待你們。</span>
<span className="v" id="v8" data-v="8" data-xref="約翰一書 3:16; 哥林多後書 12:15; 腓立比書 2:17"> 我們深愛你們，對你們有深厚的感情，不僅樂意把上帝的福音傳給你們，甚至把生命給你們也在所不惜。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="帖撒羅尼迦後書 3:7–9; 哥林多後書 11:9; 使徒行傳 18:3"> 弟兄姊妹，你們一定記得我們的勞苦和艱難。我們一面向你們傳上帝的福音，一面晝夜辛勤工作，免得成為你們任何人的負擔。</span>
<span className="v" id="v10" data-v="10" data-xref="彼得前書 5:3; 帖撒羅尼迦前書 1:5; 哥林多後書 1:12"> 我們怎樣以聖潔、公義、純全的方式對待你們眾信徒，你們自己可以作證，上帝也可以作證。</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多前書 4:14–15; 希伯來書 13:22; 提摩太前書 5:21"> 你們也知道，我們對待你們就像父親對待自己的孩子一樣。</span>
<span className="v" id="v12" data-v="12" data-xref="以弗所書 4:1; 約翰一書 2:6; 約翰一書 1:6–7"> 我們安慰你們，勸勉你們，督促你們，叫你們行事為人對得起上帝，祂呼召你們進入祂的國度和榮耀。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="希伯來書 4:12; 羅馬書 10:17; 彼得前書 1:23"> 我們也不住地感謝上帝，因為你們從我們這裡聽了上帝的道後就接受了，確信這不是人的道理，而是上帝的道。這道正在你們信的人心裡發揮作用。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="帖撒羅尼迦前書 3:4; 希伯來書 10:33–34; 希伯來書 5:7–8"> 弟兄姊妹，你們的遭遇和猶太地區上帝在基督耶穌裡的眾教會的遭遇一樣。你們受到了自己同胞的迫害，他們也受到了猶太人的迫害。</span>
<span className="v" id="v15" data-v="15" data-xref="馬太福音 5:12; 路加福音 11:48–53; 使徒行傳 7:52"> 這些猶太人殺死了主耶穌和眾先知，又迫害我們。他們不但冒犯上帝，還與所有的人為敵，</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行傳 17:13; 使徒行傳 14:19; 馬可福音 16:16"> 阻止我們傳福音給外族人，唯恐他們得救。這些人惡貫滿盈，上帝的烈怒終於臨到了他們頭上。</span>
</div>
</div>

## 保羅渴望去帖撒羅尼迦

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="歌羅西書 2:5; 哥林多前書 5:3; 帖撒羅尼迦前書 3:6"> 弟兄姊妹，我們身體暫時與你們分離，心靈卻與你們在一起。我們非常渴望見到你們，並想方設法與你們會面。</span>
<span className="v" id="v18" data-v="18" data-xref="羅馬書 15:22; 羅馬書 1:13; 啟示錄 2:10"> 我們想去你們那裡，我保羅也一次又一次地想去，只是遭到撒旦的攔阻。</span>
<span className="v" id="v19" data-v="19" data-xref="腓立比書 4:1; 帖撒羅尼迦前書 3:13; 腓立比書 2:16"> 我們主耶穌再來的時候，我們在祂面前的盼望、喜樂和可誇耀的冠冕是什麼呢？不就是你們嗎？</span>
<span className="v" id="v20" data-v="20" data-xref="哥林多後書 1:14; 哥林多前書 11:7; 箴言 17:6"> 因為你們是我們的榮耀和喜樂。</span>
</div>
</div>

## 捐助聖徒

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="羅馬書 12:13; 哥林多後書 8:1–9; 哥林多後書 9:12–15"> 至於捐款幫助聖徒這件事，你們可以照我吩咐加拉太各教會的方法辦理。</span>
<span className="v" id="v2" data-v="2" data-xref="瑪拉基書 3:9–10; 申命記 15:11–14; 申命記 8:18"> 每逢週日，各人應按照自己的收入抽出一部分留起來，免得我到的時候才現湊。</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多後書 8:6; 哥林多前書 11:34; 哥林多前書 4:19–21"> 我到了以後，會差遣你們委託的人帶著推薦信，把你們的捐款送到耶路撒冷。</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多後書 8:4; 哥林多後書 8:19; 羅馬書 15:25"> 如果我也需要去的話，他們可以跟我一起去。</span>
</div>
</div>

## 保羅的計劃

<div className="bt">
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="使徒行傳 19:21; 哥林多前書 4:19; 哥林多後書 1:15–17"> 我正打算從馬其頓經過，過了馬其頓，我就去探望你們。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行傳 15:3; 羅馬書 15:24; 使徒行傳 20:38"> 我也許會和你們住一段時期，甚至在你們那裡過冬。之後，我無論去什麼地方，你們都可以給我送行。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行傳 18:21; 哥林多前書 4:19; 雅各書 4:15"> 我不想只是現在順道探望你們，主若許可，我盼望能夠和你們同住一段時期。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行傳 2:1; 出埃及記 23:16; 使徒行傳 18:19"> 我會在以弗所停留到五旬節，</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多後書 2:12; 使徒行傳 14:27; 歌羅西書 4:3"> 因為大門為我敞開了，工作很有成效，不過反對我的人也很多。</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多前書 15:58; 帖撒羅尼迦前書 3:2; 羅馬書 16:21"> 提摩太到了以後，你們務要好好接待他，讓他在你們那裡安心，因為他和我一樣，都是在為主做工。</span>
<span className="v" id="v11" data-v="11" data-xref="提摩太前書 4:12; 使徒行傳 15:33; 提多書 2:15"> 所以誰也不許輕視他。你們要幫助他平安地回到我這裡，我正在等候他和弟兄們同來。</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多前書 1:12; 哥林多前書 3:5; 提多書 3:4"> 至於亞波羅弟兄，我雖然再三勸他和弟兄們去你們那裡，但他目前還不願去。不過他有機會就會去。</span>
</div>
</div>

## 勸勉與問候

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="約書亞記 1:9; 以弗所書 6:13–18; 以弗所書 6:10"> 你們要警醒，在信仰上堅定不移，做勇敢剛強的人。</span>
<span className="v" id="v14" data-v="14" data-xref="約翰福音 13:34–35; 彼得前書 4:8; 提摩太前書 1:5"> 無論做什麼事，都要有愛心。</span>
<span className="v" id="v15" data-v="15" data-xref="哥林多前書 1:16; 羅馬書 16:5; 羅馬書 16:2"> 弟兄姊妹，你們都知道司提法納一家在亞該亞是最早信主的<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「最早信主的」希臘文是「最早的果子」。">a</a></sup>，也知道他們怎樣盡心竭力地服侍聖徒。</span>
<span className="v" id="v16" data-v="16" data-xref="希伯來書 13:17; 帖撒羅尼迦前書 5:12; 約翰三書 1:8"> 你們要順服這樣的人，也要順服所有同心努力服侍的人。</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多後書 11:9; 腓立比書 2:30; 腓利門書 1:13"> 我很高興司提法納、福徒拿都和亞該古來我這裡，因為你們幫不到我的地方，他們都補足了。</span>
<span className="v" id="v18" data-v="18" data-xref="腓利門書 1:7; 哥林多後書 7:13; 帖撒羅尼迦前書 5:12"> 他們使我和你們心裡都感到十分欣慰，你們要敬重這樣的人。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行傳 18:2; 腓利門書 1:2; 羅馬書 16:3–5"> 亞細亞的各教會問候你們。亞居拉和百基拉夫婦及常在他們家裡聚會的信徒，奉主的名衷心地問候你們。</span>
<span className="v" id="v20" data-v="20" data-xref="羅馬書 16:16; 帖撒羅尼迦前書 5:26; 彼得前書 5:14"> 全體弟兄姊妹都問候你們。你們要以聖潔的吻彼此問候。</span>
<span className="v" id="v21" data-v="21" data-xref="歌羅西書 4:18; 加拉太書 6:11; 帖撒羅尼迦後書 3:17"> 我保羅親筆問候你們。</span>
<span className="v" id="v22" data-v="22" data-xref="以弗所書 6:24; 約翰福音 14:21; 哥林多後書 5:14–15"> 如果有人不愛主，這人可咒可詛！主啊，我願你來！</span>
<span className="v" id="v23" data-v="23" data-xref="羅馬書 16:20; 羅馬書 16:23"> 願主耶穌基督的恩典與你們同在！</span>
<span className="v" id="v24" data-v="24" data-xref="哥林多前書 14:16; 啟示錄 3:19; 哥林多後書 12:15"> 我在基督耶穌裡愛你們眾人。阿們！</span>
</div>
</div>

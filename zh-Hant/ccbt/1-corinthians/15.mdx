## 基督的復活

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="加拉太書 1:6–12; 彼得前書 5:12; 哥林多前書 15:3–11"> 弟兄姊妹，我希望你們記住我傳給你們的福音，就是你們所領受並向來堅持的福音。</span>
<span className="v" id="v2" data-v="2" data-xref="希伯來書 3:6; 希伯來書 2:1; 希伯來書 3:14"> 你們若持守我傳給你們的，必因這福音而得救——除非你們沒有真正相信。</span>
<span className="v" id="v3" data-v="3" data-xref="彼得前書 2:24; 加拉太書 1:4; 以賽亞書 53:1–12"> 我所領受並傳給你們的最重要的信息是：基督照聖經的記載為我們的罪死了，</span>
<span className="v" id="v4" data-v="4" data-xref="何西阿書 6:2; 馬太福音 12:40; 詩篇 16:10–11"> 然後被埋葬了；又照聖經的記載在第三天復活了，</span>
<span className="v" id="v5" data-v="5" data-xref="馬可福音 16:14; 哥林多前書 1:12; 約翰福音 1:42"> 並曾向磯法顯現，又向十二使徒顯現；</span>
<span className="v" id="v6" data-v="6" data-xref="馬太福音 28:10; 馬可福音 16:7; 使徒行傳 13:36"> 後來有一次向五百多位弟兄姊妹顯現，其中有許多至今還健在，也有些已經安息了；</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 24:50; 使徒行傳 1:2–12; 路加福音 24:33"> 隨後，祂向雅各顯現，又向眾使徒顯現；</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多前書 9:1; 使徒行傳 26:16; 使徒行傳 22:18"> 到最後，竟也向我這好像未按產期出生<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="保羅用「未按產期出生」來指自己非比尋常的蒙召經歷。">a</a></sup>的人顯現。</span>
<span className="v" id="v9" data-v="9" data-xref="以弗所書 3:7–8; 提摩太前書 1:13–15; 使徒行傳 8:3"> 在眾使徒中我最微不足道，根本不配稱為使徒，因為我曾迫害上帝的教會。</span>
<span className="v" id="v10" data-v="10" data-xref="腓立比書 4:13; 哥林多後書 3:5; 腓立比書 2:13"> 但靠著上帝的恩典，我成了今天的我，祂賜給我的恩典沒有枉費。我比其他人更加勞苦，不過我不是靠自己，而是上帝的恩典與我同在。</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多前書 15:3–4; 哥林多前書 2:2"> 不論是我傳的還是其他使徒傳的，我們怎樣傳，你們也怎樣相信了。</span>
</div>
</div>

## 死人復活

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="使徒行傳 26:8; 使徒行傳 17:32; 提摩太後書 2:18"> 既然我們一直都在傳揚基督已經從死裡復活，怎麼你們當中卻有人否定死人復活的事呢？</span>
<span className="v" id="v13" data-v="13" data-xref="約翰福音 11:25–26; 羅馬書 8:11; 帖撒羅尼迦前書 4:14"> 要是沒有死人復活的事，基督也就沒有復活。</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多前書 15:17; 帖撒羅尼迦前書 4:14; 加拉太書 2:2"> 如果基督沒有復活，我們所傳的就是虛空，你們所信的也是虛空。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行傳 2:24; 約伯記 13:7–10; 使徒行傳 2:32"> 而且，我們就是在為上帝做假見證，因為我們見證上帝已經使基督復活了。如果沒有死人復活的事，上帝也就沒有叫基督復活。</span>
<span className="v" id="v16" data-v="16"> 如果人死了不會復活，基督也就沒有復活。</span>
<span className="v" id="v17" data-v="17" data-xref="羅馬書 4:25; 彼得前書 1:3; 哥林多前書 15:14"> 如果基督沒有復活，你們的信仰就是虛空，你們依舊沉淪在罪中，</span>
<span className="v" id="v18" data-v="18" data-xref="帖撒羅尼迦前書 4:13–14; 啟示錄 14:13; 帖撒羅尼迦前書 4:16"> 那些在基督裡安息的人也滅亡了。</span>
<span className="v" id="v19" data-v="19" data-xref="彼得前書 1:21; 啟示錄 14:13; 提摩太後書 1:12"> 如果我們對基督的盼望只在今世，我們就是世上最可憐的人。</span>
<span className="v" id="v20" data-v="20" data-xref="哥林多前書 15:23; 使徒行傳 26:23; 啟示錄 1:5"> 然而，基督已經從死裡復活，祂是死人中第一個復活的<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="「是死人中第一個復活的」希臘文是「成為已經睡了之人初熟的果子」。">b</a></sup>。</span>
<span className="v" id="v21" data-v="21" data-xref="約翰福音 11:25; 羅馬書 5:12–17; 哥林多前書 15:22"> 既然死亡的到來是藉著一人，復活的到來也是藉著一人。</span>
<span className="v" id="v22" data-v="22" data-xref="羅馬書 5:12–21; 哥林多前書 15:45–49; 約翰福音 5:21–29"> 因為正如在亞當裡眾人都死了，同樣，在基督裡眾人也都要復活。</span>
<span className="v" id="v23" data-v="23" data-xref="以賽亞書 26:19; 加拉太書 3:29; 哥林多前書 15:52"> 然而，各人要按照先後次序復活。基督最先復活，以後祂再來時，屬祂的人也要復活。</span>
<span className="v" id="v24" data-v="24" data-xref="但以理書 7:27; 但以理書 7:14; 馬太福音 28:18"> 最後末日來臨，那時基督會廢除一切執政的、掌權的、有能力的，將國度交給父上帝。</span>
<span className="v" id="v25" data-v="25" data-xref="希伯來書 10:12–13; 詩篇 110:1; 馬太福音 22:44"> 因為基督必執掌王權，直到上帝將所有的仇敵都放在祂腳下。</span>
<span className="v" id="v26" data-v="26" data-xref="提摩太後書 1:10; 哥林多前書 15:55; 啟示錄 21:4"> 祂最後要毀滅的仇敵就是死亡。</span>
<span className="v" id="v27" data-v="27" data-xref="詩篇 8:6; 希伯來書 2:8; 馬太福音 28:18"> 因為聖經上說：「上帝使萬物降服在祂腳下。」<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="詩篇8·6。">c</a></sup>當然，這裡說的「萬物都降服祂」不包括使萬物降服祂的上帝。</span>
<span className="v" id="v28" data-v="28" data-xref="歌羅西書 3:11; 哥林多前書 3:23; 以弗所書 1:23"> 到了萬物都降服基督以後，聖子基督也要歸服那使萬物降服祂的上帝，使上帝做萬物的主宰。</span>
<span className="v" id="v29" data-v="29" data-xref="羅馬書 6:3–4; 哥林多前書 15:16; 馬太福音 20:22"> 否則，那些人替死人受洗有什麼意義呢？死人如果不會復活，為什麼要替他們受洗呢？</span>
<span className="v" id="v30" data-v="30" data-xref="哥林多後書 6:9; 加拉太書 5:11; 哥林多後書 4:7–12"> 我們又何必時刻身臨險境呢？</span>
<span className="v" id="v31" data-v="31" data-xref="哥林多後書 4:10–11; 羅馬書 8:36; 哥林多前書 4:9–13"> 我天天面對死亡。弟兄姊妹，我這樣說，就跟我在主基督耶穌裡以你們為榮一樣，沒有半點虛假。</span>
<span className="v" id="v32" data-v="32" data-xref="以賽亞書 22:13; 以賽亞書 56:12; 路加福音 12:19"> 從人的角度看，我在以弗所與那些惡獸格鬥對我有什麼益處呢？如果死人不會復活，「讓我們吃喝吧！因為明天我們就死了。」<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="以賽亞書22·13。">d</a></sup></span>
<span className="v" id="v33" data-v="33" data-xref="箴言 13:20; 馬太福音 24:4; 哥林多前書 5:6"> 你們不要上當受騙：「壞朋友會敗壞好品德。」</span>
<span className="v" id="v34" data-v="34" data-xref="哥林多前書 6:5; 羅馬書 13:11; 希伯來書 5:11–12"> 你們該醒悟了！不要繼續犯罪，因為你們當中有些人不認識上帝。我說這話是要叫你們羞愧。</span>
</div>
</div>

## 復活後的身體

<div className="bt">
<div className="bp poetry">
<span className="v" id="v35" data-v="35" data-xref="以西結書 37:3; 哥林多前書 15:38–53; 羅馬書 9:19"> 也許有人會問：「死人怎樣復活呢？復活後會有怎樣的身體呢？」</span>
<span className="v" id="v36" data-v="36" data-xref="約翰福音 12:24; 路加福音 11:40; 以弗所書 5:15"> 無知的人啊！你們種下的種子必須先死，然後才能生長。</span>
<span className="v" id="v37" data-v="37"> 而且，你們種下的並不是那將來要長成的形體，僅僅是種子，或麥種，或其他種子。</span>
<span className="v" id="v38" data-v="38" data-xref="哥林多前書 3:7; 以賽亞書 61:11; 馬可福音 4:26–29"> 上帝按自己的旨意賜給種子形體，每樣種子都有自己的形體。</span>
<span className="v" id="v39" data-v="39" data-xref="創世記 1:20–26"> 血肉之體各不相同，人、獸、鳥、魚都各有不同的形體。</span>
<span className="v" id="v40" data-v="40"> 此外，有天上的形體，也有地上的形體，兩者的榮光各不相同。</span>
<span className="v" id="v41" data-v="41" data-xref="以賽亞書 24:23; 詩篇 148:3–5; 申命記 4:19"> 日有日的榮光，月有月的榮光，星有星的榮光，這顆星和那顆星的榮光也有分別。</span>
<span className="v" id="v42" data-v="42" data-xref="馬太福音 13:43; 但以理書 12:3; 羅馬書 8:21"> 死人復活也是同樣的道理。種下去的會朽壞，復活的不會朽壞；</span>
<span className="v" id="v43" data-v="43" data-xref="哥林多前書 6:14; 歌羅西書 3:4; 腓立比書 3:20–21"> 種下去的是羞恥的，復活的是榮耀的；種下去的是軟弱的，復活的是剛強的；</span>
<span className="v" id="v44" data-v="44" data-xref="哥林多前書 15:50; 路加福音 24:31; 約翰福音 20:19"> 種下去的是血肉之軀，復活的是屬靈的形體。既有血肉之軀，也必有屬靈的形體。</span>
<span className="v" id="v45" data-v="45" data-xref="約翰福音 5:21; 創世記 2:7; 羅馬書 8:2"> 聖經上也說：「第一個人亞當成了有生命的人」<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="創世記2·7。">e</a></sup>，但末後的亞當是賜人生命的靈。</span>
<span className="v" id="v46" data-v="46" data-xref="歌羅西書 3:9–10; 羅馬書 6:6; 以弗所書 4:22–24"> 先有的不是屬靈的形體，而是血肉之軀，以後才有屬靈的形體。</span>
<span className="v" id="v47" data-v="47" data-xref="約翰福音 3:31; 創世記 2:7; 創世記 3:19"> 第一個人亞當來自地上，是用塵土造的，但第二個人基督來自天上。</span>
<span className="v" id="v48" data-v="48" data-xref="創世記 5:3; 羅馬書 5:12–21; 約翰福音 3:6"> 塵土所造的那位是什麼樣，屬地的人也是什麼樣；從天而來的那位是什麼樣，屬天的人也是什麼樣。</span>
<span className="v" id="v49" data-v="49" data-xref="羅馬書 8:29; 哥林多後書 3:18; 創世記 5:3"> 我們既然有屬地的形像，將來也必有屬天的形像。</span>
<span className="v" id="v50" data-v="50" data-xref="約翰福音 3:3–6; 馬太福音 16:17; 以弗所書 4:17"> 弟兄姊妹，我告訴你們，血肉之軀不能承受上帝的國，必朽壞的身體也不能承受永不朽壞的產業。</span>
<span className="v" id="v51" data-v="51" data-xref="帖撒羅尼迦前書 4:14–17; 腓立比書 3:21; 哥林多前書 15:20"> 聽著，我要告訴你們一個奧祕：我們並不是都要死亡<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="「死亡」希臘文是「睡覺」。">f</a></sup>，而是都要改變，</span>
<span className="v" id="v52" data-v="52" data-xref="帖撒羅尼迦前書 4:16–17; 馬太福音 24:31; 約翰福音 5:28"> 就在一剎那，眨眼之間，最後的號角吹響的時候。因為號角一吹響，死人就要復活成為永不朽壞的，我們也要改變。</span>
<span className="v" id="v53" data-v="53" data-xref="哥林多後書 5:2–4; 約翰一書 3:2; 羅馬書 2:7"> 那時，這必朽的身體要變成不朽的，這必死的要變成不死的。</span>
<span className="v" id="v54" data-v="54" data-xref="以賽亞書 25:8; 啟示錄 20:14; 希伯來書 2:14–15"> 當這一切發生的時候，就應驗了聖經上的話：<br /><span className="pl pl-1">「死亡被勝利吞滅了。」</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="以賽亞書25·8。">g</a></sup><br /></span>
<span className="v" id="v55" data-v="55" data-xref="何西阿書 13:14; 詩篇 89:48; 使徒行傳 2:27"> <span className="pl pl-1">「死亡啊！你得勝的權勢在哪裡？</span><br /><span className="pl pl-1">死亡啊！你的毒鉤在哪裡？」</span><sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="何西阿書13·14。">h</a></sup></span>
<span className="v" id="v56" data-v="56" data-xref="羅馬書 4:15; 加拉太書 3:10–13; 羅馬書 7:5–13"> 死亡的毒鉤就是罪，罪的權勢就是律法。</span>
<span className="v" id="v57" data-v="57" data-xref="哥林多後書 2:14; 羅馬書 8:37; 約翰一書 5:4–5"> 但感謝上帝，祂使我們靠著主耶穌基督得勝。</span>
<span className="v" id="v58" data-v="58" data-xref="加拉太書 6:9; 歷代志下 15:7; 希伯來書 6:10"> 所以，我親愛的弟兄姊妹，你們務要堅定不移，總要竭力做主的工作，因為你們知道自己在主裡的辛勤付出不會白費。</span>
</div>

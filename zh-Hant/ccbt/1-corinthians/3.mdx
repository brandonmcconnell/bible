## 同是上帝的僕人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="希伯來書 5:13; 哥林多前書 2:14–15; 以弗所書 4:13–14"> 弟兄姊妹，以前我對你們講話的時候，還不能把你們看作屬靈的人，只能把你們看作屬肉體的人，是在基督裡的嬰孩。</span>
<span className="v" id="v2" data-v="2" data-xref="希伯來書 5:11–14; 約翰福音 16:12; 彼得前書 2:2"> 我只能用奶而不能用飯來餵養你們，因為你們當時不能消化，甚至現在也不能。</span>
<span className="v" id="v3" data-v="3" data-xref="雅各書 3:16; 加拉太書 5:15; 提多書 3:3"> 你們仍是屬肉體的人，因為你們中間有嫉妒、爭鬥。這豈不證明你們是屬肉體的，行事為人和世人一樣嗎？</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多前書 1:12; 哥林多前書 3:3; 哥林多前書 4:6"> 你們有的說：「我是跟隨保羅的」，有的說：「我是跟隨亞波羅的」，這豈不證明你們和世人一樣嗎？</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多後書 6:4; 哥林多後書 6:1; 彼得前書 4:10"> 亞波羅算什麼？保羅算什麼？我們不過是上帝的僕人，各人照著主所賜的才幹引導你們信靠上帝。</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多前書 3:9–10; 箴言 11:25; 哥林多後書 10:14–15"> 我栽種，亞波羅澆灌，但使之生長的是上帝。</span>
<span className="v" id="v7" data-v="7" data-xref="約翰福音 15:5; 加拉太書 6:3; 詩篇 115:1"> 所以栽種的和澆灌的都算不得什麼，一切都在於使之生長的上帝。</span>
<span className="v" id="v8" data-v="8" data-xref="羅馬書 2:6; 馬太福音 16:27; 約翰二書 1:8"> 其實栽種的人和澆灌的人目標都一樣，各人將按照自己的付出得報酬。</span>
<span className="v" id="v9" data-v="9" data-xref="彼得前書 2:5; 以弗所書 2:20–22; 哥林多後書 6:1"> 因為我們是上帝的同工，你們是上帝的園地和建築。</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多前書 3:11; 以弗所書 2:20; 羅馬書 15:20"> 我照著上帝賜給我的恩典，好像一位有智慧的建築師打下了根基，然後讓其他工人在上面建造。但每個人建造的時候要小心，</span>
<span className="v" id="v11" data-v="11" data-xref="以弗所書 2:20; 以賽亞書 28:16; 提摩太後書 2:19"> 因為除了那已經奠定的根基耶穌基督以外，沒有人能另立根基。</span>
<span className="v" id="v12" data-v="12" data-xref="提摩太後書 4:3; 提摩太後書 3:7; 提摩太後書 2:20"> 人們用金、銀、寶石、草、木或禾稭在這根基上建造，</span>
<span className="v" id="v13" data-v="13" data-xref="彼得前書 1:7; 哥林多前書 3:14–15; 啟示錄 20:12"> 每個人的工程將來都會顯明出來，因為到了審判的日子，必用火試驗各人工程的品質。</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多前書 3:8; 馬太福音 25:21–23; 哥林多前書 4:5"> 人在這根基上所建造的工程若經得起考驗，他必獲得獎賞。</span>
<span className="v" id="v15" data-v="15" data-xref="約翰二書 1:8; 哥林多前書 3:12–13; 猶大書 1:23"> 人的工程若被燒毀了，他必遭受損失，自己雖然可以得救，卻像火裡逃生一樣。</span>
<span className="v" id="v16" data-v="16" data-xref="哥林多前書 6:19; 以西結書 36:27; 哥林多後書 6:16"> 豈不知你們就是上帝的殿，上帝的靈住在你們裡面嗎？</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多前書 6:18–20; 以西結書 43:12; 民數記 19:20"> 若有人摧毀上帝的殿，上帝必摧毀那人，因為上帝的殿是神聖的，你們就是這殿。</span>
<span className="v" id="v18" data-v="18" data-xref="箴言 3:5; 以賽亞書 5:21; 加拉太書 6:3"> 你們不要自欺。如果你們有人自以為在世上有智慧，他應當變成愚人，好成為真正的智者。</span>
<span className="v" id="v19" data-v="19" data-xref="約伯記 5:13; 詩篇 141:10; 哥林多前書 1:19–20"> 因為這世上的智慧在上帝的眼中都是愚昧的，正如聖經上說：「上帝使智者中了自己的詭計。」<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="約伯記5·13。">a</a></sup></span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 94:11; 歌羅西書 2:8; 羅馬書 1:21"> 又說：「主知道智者的思想虛妄。」<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="詩篇94·11。">b</a></sup></span>
<span className="v" id="v21" data-v="21" data-xref="羅馬書 8:32; 羅馬書 8:28; 耶利米書 9:23–24"> 因此，誰都不要仗著人誇耀，因為萬物都屬於你們，</span>
<span className="v" id="v22" data-v="22" data-xref="以弗所書 4:11–12; 腓立比書 1:21; 哥林多前書 9:19–22"> 無論是保羅、亞波羅、磯法、世界、生命、死亡、現在的事或將來的事都屬於你們，</span>
<span className="v" id="v23" data-v="23" data-xref="加拉太書 3:29; 哥林多前書 11:3; 約翰福音 17:9–10"> 你們屬於基督，基督屬於上帝。</span>

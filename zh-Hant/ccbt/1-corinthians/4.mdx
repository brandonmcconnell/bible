## 基督的使徒

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="彼得前書 4:10; 提多書 1:7; 提摩太前書 3:9"> 因此，人應該把我們當作是基督的僕人，是上帝奧祕事的管家。</span>
<span className="v" id="v2" data-v="2" data-xref="馬太福音 25:21; 路加福音 12:42; 路加福音 16:10–12"> 對管家的要求是忠心。</span>
<span className="v" id="v3" data-v="3" data-xref="約翰福音 7:24; 哥林多前書 2:15; 撒母耳記上 16:7"> 我對你們或別人給我的評價毫不介意，我也不評價我自己。</span>
<span className="v" id="v4" data-v="4" data-xref="詩篇 143:2; 約翰一書 3:20–21; 詩篇 130:3"> 就算我今日問心無愧，也不能自以為義，因為評價我的是主。</span>
<span className="v" id="v5" data-v="5" data-xref="雅各書 5:7; 哥林多後書 5:10; 哥林多前書 3:13"> 所以，時候未到，不可妄下斷語。到主耶穌再來的時候，祂會曝光暗中的隱情，揭開人心裡的動機。到時候上帝會給各人應得的稱讚。</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多後書 12:6; 哥林多後書 11:4; 哥林多後書 12:19"> 弟兄姊妹，為了你們的益處，我以自己和亞波羅作例子，好讓你們效法我們不越過聖經的準則，免得有人自高自大、厚此薄彼。</span>
<span className="v" id="v7" data-v="7" data-xref="約翰福音 3:27; 彼得前書 4:10; 雅各書 1:17"> 誰使你與眾不同呢？你有哪一樣不是領受的呢？既然一切都是領受的，你為什麼還自誇，好像不是領受的？</span>
<span className="v" id="v8" data-v="8" data-xref="路加福音 6:25; 箴言 13:7; 哥林多前書 5:6"> 你們已經飽足了，富有了，不需要我們，自己已經作王了。我倒希望你們真的作王了，好讓我們也和你們一同作王。</span>
<span className="v" id="v9" data-v="9" data-xref="希伯來書 10:33; 羅馬書 8:36; 哥林多後書 4:8–12"> 我想，上帝把我們使徒排在隊伍的末尾，好像被判死罪的囚犯，讓我們成了一台戲，給宇宙觀看，給天使和世人觀看。</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多前書 2:3; 使徒行傳 26:24; 哥林多前書 3:18"> 我們為基督的緣故成了愚昧人，你們在基督裡倒成了聰明人；我們軟弱，你們倒剛強；你們受人尊敬，我們倒被人藐視。</span>
<span className="v" id="v11" data-v="11" data-xref="羅馬書 8:35; 哥林多後書 11:23–27; 腓立比書 4:12"> 我們至今還是又饑又渴，衣不蔽體，遭受毒打，居無定所，</span>
<span className="v" id="v12" data-v="12" data-xref="彼得前書 3:9; 馬太福音 5:11; 彼得前書 4:12–14"> 還要親手勞作。我們被人咒罵，就為對方祝福；受人迫害，就逆來順受；</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米哀歌 3:45; 使徒行傳 22:22"> 被人毀謗，就好言相勸。人們至今仍將我們看作世上的廢物，萬物中的渣滓。</span>
<span className="v" id="v14" data-v="14" data-xref="帖撒羅尼迦前書 2:11; 哥林多前書 4:15; 約翰三書 1:4"> 我之所以寫這些事，並非叫你們羞愧，而是像勸誡我親愛的兒女一樣勸誡你們。</span>
<span className="v" id="v15" data-v="15" data-xref="加拉太書 4:19; 哥林多前書 3:10; 哥林多前書 9:14"> 你們雖然在基督裡有千萬個導師，卻沒有許多父親，因為我藉著福音在基督耶穌裡成為你們的父親。</span>
<span className="v" id="v16" data-v="16" data-xref="哥林多前書 11:1; 帖撒羅尼迦後書 3:9; 腓立比書 3:17"> 所以，我勸你們效法我。</span>
<span className="v" id="v17" data-v="17" data-xref="提摩太前書 1:2; 哥林多前書 16:10; 哥林多前書 7:17"> 正因如此，我派了提摩太去你們那裡。他在主裡忠心耿耿，是我所愛的孩子。他會提醒你們我在基督裡如何行事為人，在各地、各教會如何教導人。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前書 4:6–8; 哥林多前書 5:2; 哥林多前書 4:21"> 你們當中有些人以為我不會再去你們那裡，就傲慢自大起來。</span>
<span className="v" id="v19" data-v="19" data-xref="哥林多後書 13:1–4; 使徒行傳 18:21; 使徒行傳 19:21"> 但主若許可，我會很快去你們那裡。那時我要看看這些驕傲的人究竟是只會空談，還是真有上帝的權能。</span>
<span className="v" id="v20" data-v="20" data-xref="哥林多前書 2:4; 帖撒羅尼迦前書 1:5; 哥林多後書 10:4–5"> 因為上帝的國不在於空談，而在於權能。</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多後書 13:2; 哥林多後書 13:10; 帖撒羅尼迦前書 2:7"> 到底你們要什麼呢？要我帶著刑杖去呢？還是要我帶著溫柔慈愛的心去呢？</span>

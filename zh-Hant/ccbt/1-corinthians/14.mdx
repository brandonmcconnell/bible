## 論講道和說方言

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多前書 14:39; 提摩太前書 4:14; 哥林多前書 12:1"> 你們要追求愛，也要切慕屬靈的恩賜，尤其是作先知講道的恩賜。</span>
<span className="v" id="v2" data-v="2" data-xref="馬可福音 16:17; 使徒行傳 19:6; 使徒行傳 10:46"> 人說方言，是對上帝說的，並非對人說的，因為沒有人聽得懂，他是在心靈裡<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「在心靈裡」或譯「藉著聖靈」。">a</a></sup>述說各種奧祕。</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多前書 14:12; 提摩太前書 4:13; 猶大書 1:20"> 但先知講道是對人講的，為了要造就、鼓勵、安慰人。</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多前書 14:22; 哥林多前書 14:26; 馬可福音 16:17"> 說方言只是造就自己，但作先知講道是造就教會。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多前書 12:28–30; 哥林多前書 12:10; 馬可福音 16:17"> 我希望你們都能說方言，不過，我更希望你們都能作先知講道。說方言的不如作先知講道的重要，除非把方言翻譯出來，使教會得造就。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="以弗所書 1:17; 羅馬書 6:17; 提摩太後書 3:16"> 弟兄姊妹，我如果到你們那裡只說方言，不講解有關上帝的啟示、知識、預言、教導，對你們有什麼益處呢？</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多前書 14:8; 路加福音 7:32; 哥林多前書 13:1"> 就連沒有生命的簫和琴，如果發出的聲音雜亂無章，誰能知道所吹所彈的是什麼曲子呢？</span>
<span className="v" id="v8" data-v="8" data-xref="民數記 10:9; 以西結書 33:3–6; 耶利米書 4:19"> 如果號聲不清楚，誰會預備打仗呢？</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多前書 9:26"> 同樣，除非你們講出清楚的信息，不然聽見的人怎能明白呢？那豈不等於對空氣說話嗎？</span>
<span className="v" id="v10" data-v="10"> 世上有各種語言，卻沒有一種是毫無意義的。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行傳 28:2; 羅馬書 1:14; 歌羅西書 3:11"> 如果有人對我說話，我卻不明白他的語言，我們就成了彼此語言不通的人。</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多前書 14:26; 哥林多前書 14:3–4; 哥林多前書 14:1"> 你們也是一樣，既然渴慕屬靈的恩賜，就應該多多追求造就教會的恩賜。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="馬可福音 11:24; 哥林多前書 12:30; 約翰福音 14:13–14"> 所以說方言的人應當祈求能把方言翻譯出來。</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多前書 14:2; 哥林多前書 14:15–16; 哥林多前書 14:19"> 如果我用方言禱告，那是我的靈在禱告，但我的悟性沒有發揮作用。</span>
<span className="v" id="v15" data-v="15" data-xref="歌羅西書 3:16; 約翰福音 4:23–24; 以弗所書 6:18"> 那麼，我該怎麼做呢？我要用靈禱告，也要用悟性禱告；我要用靈歌唱，也要用悟性歌唱。</span>
<span className="v" id="v16" data-v="16" data-xref="歷代志上 16:36; 詩篇 106:48; 啟示錄 5:14"> 否則，如果你在聚會中用方言<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="本處「方言」希臘文是「靈」。">b</a></sup>來感恩，在座不懂方言的人不明白你在說些什麼，怎能在你感恩的時候說「阿們」呢？</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多前書 14:4; 哥林多前書 14:6"> 你的感恩表達得固然美好，無奈不能造就別人。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="哥林多前書 1:4–6; 哥林多前書 4:7"> 感謝上帝，我說方言比你們眾人都多。</span>
<span className="v" id="v19" data-v="19" data-xref="哥林多前書 14:21–22; 哥林多前書 14:4"> 但在教會中我寧可用悟性說五句教導人的話，勝過說萬句別人不懂的方言。</span>
</div>
<div className="bp poetry">
<span className="v" id="v20" data-v="20" data-xref="彼得前書 2:2; 哥林多前書 13:11; 羅馬書 16:19"> 弟兄姊妹，你們的思想不要像小孩子，要長大成熟，但在罪惡的事上要像嬰孩。</span>
<span className="v" id="v21" data-v="21" data-xref="以賽亞書 28:11–12; 耶利米書 5:15; 申命記 28:49"> 律法書上記載：<br /><span className="pl pl-1">「主說，『我要藉著講陌生語言的人和外邦人的口向這些子民說話。</span><br /><span className="pl pl-1">雖然如此，</span><br /><span className="pl pl-1">他們仍然不聽從我。』</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="以賽亞書28·11、12。">c</a></sup><br /><span className="pl pl-1">」</span></span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="使徒行傳 2:6–12; 馬可福音 16:17; 哥林多前書 14:1"> 由此可見，講方言不是顯給信徒的標記，而是顯給非信徒的標記；但先知講道是顯給信徒的標記，不是顯給非信徒的標記。</span>
<span className="v" id="v23" data-v="23" data-xref="使徒行傳 2:13; 使徒行傳 26:24; 哥林多前書 11:18"> 所以，如果聚會的時候，整個教會的人都說方言，偶然有不懂方言的人或非信徒進來，他們豈不會說你們全都瘋了嗎？</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行傳 2:37; 哥林多前書 2:15; 希伯來書 4:12–13"> 但如果你們都做先知講道，偶然有非信徒或是不懂方言的人進來，他會因所聽的道而知罪，良心受到譴責，</span>
<span className="v" id="v25" data-v="25" data-xref="以賽亞書 45:14; 撒迦利亞書 8:23; 詩篇 72:11"> 心中的秘密也會顯露出來，便俯伏敬拜上帝，說：「上帝真的在你們當中！」</span>
</div>
</div>

## 聚會的原則

<div className="bt">
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="以弗所書 5:19; 羅馬書 14:19; 哥林多前書 12:7–10"> 那麼，弟兄姊妹，你們該怎麼做呢？你們聚會的時候，不管是唱詩、教導、講啟示、說方言或翻譯方言，都應該是為了造就人。</span>
<span className="v" id="v27" data-v="27" data-xref="哥林多前書 14:26"> 如果有人說方言，應該只限於兩個人，最多三個，要輪流說，而且要有人把它翻譯出來。</span>
<span className="v" id="v28" data-v="28"> 如果沒有人翻譯，說方言的人就當在聚會中閉口不言，只向自己和上帝說。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="哥林多前書 12:10; 帖撒羅尼迦前書 5:19–21; 約翰一書 4:1–3"> 作先知講道的也應該只限於兩三個人，其他人應當慎思明辨。</span>
<span className="v" id="v30" data-v="30" data-xref="帖撒羅尼迦前書 5:19–20; 約伯記 33:31–33; 約伯記 32:11"> 但如果上帝的啟示臨到在座的其他人，正在講的人要停下來，</span>
<span className="v" id="v31" data-v="31" data-xref="帖撒羅尼迦前書 5:14; 哥林多前書 14:3; 帖撒羅尼迦前書 5:11"> 這樣大家都可以輪流講道，人人都可以得到教導和勉勵。</span>
<span className="v" id="v32" data-v="32" data-xref="使徒行傳 4:19–20; 約翰一書 4:1; 撒母耳記上 10:10–13"> 先知的靈受先知控制，</span>
<span className="v" id="v33" data-v="33" data-xref="雅各書 3:17–18; 哥林多前書 14:40; 帖撒羅尼迦後書 3:16"> 因為上帝不是叫人混亂的上帝，而是賜人安寧的上帝。<br />正如聖徒的各教會一樣，</span>
<span className="v" id="v34" data-v="34" data-xref="提摩太前書 2:11–12; 創世記 3:16; 民數記 30:3–13"> 婦女<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="「婦女」也可譯為「妻子」。">d</a></sup>在聚會中要保持安靜，因為她們不可發言，總要順服，正如律法書所說的。</span>
<span className="v" id="v35" data-v="35" data-xref="以弗所書 5:12; 彼得前書 3:7; 以弗所書 5:25–27"> 她們如果想要學什麼，可以在家問自己的丈夫，因為婦女在聚會中發言是可恥的。</span>
<span className="v" id="v36" data-v="36" data-xref="使徒行傳 18:1–17; 撒迦利亞書 14:8; 使徒行傳 17:15"> 難道上帝的道是出自你們嗎？難道上帝的道單單傳給了你們嗎？</span>
<span className="v" id="v37" data-v="37" data-xref="約翰一書 4:6; 哥林多後書 10:7; 彼得後書 3:2"> 如果你們當中有人自認為是先知或屬靈的人，他就應該知道我現在所寫的是主的命令。</span>
<span className="v" id="v38" data-v="38" data-xref="提摩太後書 4:3–4; 何西阿書 4:17; 啟示錄 22:11–12"> 如果有人對此視而不見，不必理會他。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="哥林多前書 12:31; 哥林多前書 14:1; 帖撒羅尼迦前書 5:20"> 所以，我的弟兄姊妹，你們要切慕作先知講道，也不要禁止說方言。</span>
<span className="v" id="v40" data-v="40" data-xref="歌羅西書 2:5; 提多書 1:5; 哥林多前書 14:26–33"> 但無論做什麼事，都要按規矩，有次序。</span>
</div>
</div>

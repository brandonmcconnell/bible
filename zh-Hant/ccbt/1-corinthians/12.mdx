## 聖靈的恩賜

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多前書 12:4–11; 哥林多前書 14:37; 哥林多前書 14:1–18"> 弟兄姊妹，談到聖靈的恩賜，我不希望你們無知。</span>
<span className="v" id="v2" data-v="2" data-xref="彼得前書 4:3; 帖撒羅尼迦前書 1:9; 詩篇 115:5"> 你們知道，自己在信主前曾受到迷惑和引誘去拜不會說話的偶像。</span>
<span className="v" id="v3" data-v="3" data-xref="約翰一書 4:2–3; 馬太福音 16:16–17; 羅馬書 10:9"> 因此我希望你們知道，一個被上帝的靈感動的人絕不會說「耶穌該受咒詛」；若不是受了聖靈的感動，沒有人會說「耶穌是主」。</span>
<span className="v" id="v4" data-v="4" data-xref="彼得前書 4:10; 哥林多前書 12:28; 羅馬書 12:4–6"> 恩賜各有不同，但聖靈是同一位。</span>
<span className="v" id="v5" data-v="5" data-xref="以弗所書 4:11–12; 羅馬書 12:6–8; 羅馬書 14:8–9"> 事奉各有不同，但主是同一位。</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多前書 3:7; 哥林多前書 12:11; 約翰福音 5:17"> 工作各有不同，但上帝是同一位，祂在眾人當中成就萬事。</span>
<span className="v" id="v7" data-v="7" data-xref="彼得前書 4:10–11; 羅馬書 12:6–8; 哥林多前書 14:19"> 聖靈給各人不同的恩賜為要使眾人得益處。</span>
<span className="v" id="v8" data-v="8" data-xref="箴言 2:6; 哥林多前書 2:6–10; 詩篇 143:10"> 這人從聖靈領受智慧的話，那人從聖靈領受知識；</span>
<span className="v" id="v9" data-v="9" data-xref="雅各書 5:14–15; 哥林多後書 4:13; 以弗所書 2:8"> 聖靈賜這人信心，賜那人醫病的恩賜；</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多前書 14:39; 約翰一書 4:1; 馬可福音 16:17"> 聖靈使這人能行神蹟，使那人能作先知講道；使這人能辨別諸靈，使那人能說方言<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「方言」或譯「語言」。">a</a></sup>，又使另一人能翻譯方言。</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多前書 12:4; 希伯來書 2:4; 哥林多後書 10:13"> 這一切都是同一位聖靈所賜的，是祂按自己的旨意分別賜給各人的。</span>
</div>
</div>

## 同屬一個身體

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="羅馬書 12:4–5; 歌羅西書 3:15; 哥林多前書 12:27"> 這如同一個身體有許多肢體，肢體雖多，仍同屬一個身體。基督的身體也是這樣。</span>
<span className="v" id="v13" data-v="13" data-xref="以弗所書 4:5; 歌羅西書 3:11; 加拉太書 3:28"> 不論是猶太人或希臘人，是奴隸或自由人，我們都領受了同一位聖靈的洗禮，歸入了同一個身體，同飲一位聖靈。</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多前書 12:27–28; 哥林多前書 12:12; 以弗所書 4:25"> 人的身體並非只有一個肢體，而是由許多肢體組成的。</span>
<span className="v" id="v15" data-v="15" data-xref="士師記 9:8–15; 列王紀下 14:9"> 如果腳說：「我不是手，所以我不屬於身體」，難道它就因此不屬於身體嗎？</span>
<span className="v" id="v16" data-v="16" data-xref="羅馬書 12:3; 哥林多前書 12:22; 腓立比書 2:3"> 如果耳朵說：「我不是眼睛，所以我不屬於身體，」難道它就因此不屬於身體嗎？</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多前書 12:21; 詩篇 139:13–16; 箴言 20:12"> 如果整個身體是一隻眼睛，哪裡有聽覺呢？如果整個身體是一隻耳朵，哪裡有嗅覺呢？</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前書 12:28; 羅馬書 12:3; 哥林多前書 12:11"> 其實，上帝按自己的旨意將各個肢體安置在身體上了。</span>
<span className="v" id="v19" data-v="19"> 全身如果只有一個肢體，還會是身體嗎？</span>
<span className="v" id="v20" data-v="20" data-xref="哥林多前書 12:14; 哥林多前書 12:12"> 如今肢體雖多，但身體只有一個。</span>
<span className="v" id="v21" data-v="21" data-xref="以斯拉記 10:1–5; 尼希米記 4:16–21; 約伯記 29:11"> 眼睛不能對手說：「我不需要你。」頭也不能對腳說：「我不需要你。」</span>
<span className="v" id="v22" data-v="22" data-xref="箴言 14:28; 傳道書 9:14–15; 傳道書 4:9–12"> 相反，看起來不太重要的肢體其實是不可或缺的。</span>
<span className="v" id="v23" data-v="23" data-xref="創世記 3:21; 創世記 3:7"> 我們認為身體上不體面的肢體，越要加以美化；不雅觀的肢體，越要精心呵護。</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 3:11; 創世記 2:25"> 我們身上體面的肢體用不著美化。上帝把身體的各肢體安排在一起，使那些不體面的肢體更體面，</span>
<span className="v" id="v25" data-v="25" data-xref="哥林多後書 13:11; 哥林多前書 1:10–12; 約翰福音 17:21–26"> 這樣身體各肢體才可以彼此相顧，不會分門別類。</span>
<span className="v" id="v26" data-v="26" data-xref="羅馬書 12:15; 加拉太書 6:2; 希伯來書 13:3"> 如果一個肢體感到痛苦，全身也一同受苦。如果一個肢體得到榮耀，全身也一同喜樂。</span>
<span className="v" id="v27" data-v="27" data-xref="以弗所書 4:12; 歌羅西書 1:24; 以弗所書 5:30"> 你們就是基督的身體，並且各自都是身體的肢體。</span>
<span className="v" id="v28" data-v="28" data-xref="以弗所書 4:11–13; 羅馬書 12:6–8; 哥林多前書 12:18"> 上帝在教會中設立的第一是使徒，第二是先知，第三是教師，其次是行神蹟的，然後是有醫病恩賜的，幫助別人的，管理事務的，說各種方言的。</span>
<span className="v" id="v29" data-v="29" data-xref="哥林多前書 12:4–11; 哥林多前書 12:14–20"> 豈是都作使徒嗎？都作先知嗎？都作教師嗎？都行神蹟嗎？</span>
<span className="v" id="v30" data-v="30" data-xref="哥林多前書 12:10"> 都有醫病的恩賜嗎？都會說方言嗎？都會翻譯方言嗎？</span>
<span className="v" id="v31" data-v="31" data-xref="哥林多前書 13:1; 哥林多前書 14:39; 馬太福音 5:6"> 你們應該熱心追求更大的恩賜。 現在，我要將一條奇妙無比的道路指示你們！</span>
</div>
</div>

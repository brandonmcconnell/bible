## 敬拜的禮儀

<div className="bt">
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="帖撒羅尼迦後書 2:15; 哥林多前書 4:17; 箴言 31:28–31"> 我讚賞你們，因為你們凡事都想到我，並堅守我傳給你們的各種教導。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 3:16; 歌羅西書 1:18; 歌羅西書 3:18"> 我希望你們知道，基督是男人的頭，丈夫是妻子的頭，上帝是基督的頭。</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳記下 15:30; 哥林多前書 12:28; 哥林多前書 12:10"> 男人在禱告和講道時，若蒙著頭，就是羞辱自己的頭。</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 21:12; 路加福音 2:36; 使徒行傳 2:17"> 但婦女在禱告和講道時，若不蒙著頭，就是羞辱自己的頭，因為她就像剃光了頭髮一樣。</span>
<span className="v" id="v6" data-v="6" data-xref="申命記 22:5; 民數記 5:18"> 因此，婦女若不願意把頭蒙起來，就該把頭髮剪掉。她若覺得剪髮或剃頭是羞恥的，就應該蒙頭。</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多前書 11:3; 創世記 5:1; 詩篇 8:6"> 然而，男人不該蒙頭，因為男人是上帝的形像和榮耀，而女人是男人的榮耀。</span>
<span className="v" id="v8" data-v="8" data-xref="提摩太前書 2:13; 創世記 2:21–23"> 因為男人並非出自女人，而女人卻是出自男人。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 2:18; 創世記 2:23–24; 創世記 2:20"> 並且男人不是為女人而造的，女人卻是為男人而造的。</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 24:64–65; 希伯來書 1:14; 馬太福音 18:10"> 因此為了天使的緣故，女人在頭上應該有順服權柄的記號。</span>
<span className="v" id="v11" data-v="11" data-xref="加拉太書 3:28; 哥林多前書 7:10–14; 哥林多前書 12:12–22"> 不過在主裡，女人不可沒有男人，男人不可沒有女人。</span>
<span className="v" id="v12" data-v="12" data-xref="羅馬書 11:36; 哥林多前書 8:6; 希伯來書 1:2–3"> 因為女人從男人而來，男人又是女人生的，但萬物都來自上帝。</span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 12:57; 約翰福音 7:24; 哥林多前書 10:15"> 你們自行斟酌吧，女人向上帝禱告時不蒙頭合適嗎？</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳記下 14:26; 哥林多前書 14:35"> 按著人的天性，難道你們不知道男人留長髮是他的羞辱，</span>
<span className="v" id="v15" data-v="15"> 女人留長髮是她的榮耀嗎？因為頭髮是用來給女人蓋頭的。</span>
<span className="v" id="v16" data-v="16" data-xref="哥林多前書 7:17; 提摩太前書 6:3–4; 帖撒羅尼迦前書 2:14"> 如果有誰想反駁這些話，我只能說，這是我們和上帝的眾教會向來遵守的規矩。</span>
</div>
</div>

## 守聖餐的規矩

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="希伯來書 10:25; 哥林多前書 14:23; 哥林多前書 11:22"> 現在我有話要吩咐你們，不是稱讚你們，因為你們聚會不但無益，反而有害。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前書 3:3; 哥林多前書 1:10–12; 哥林多前書 5:1"> 首先，我聽說你們在聚會的時候製造分裂，我相信這些話有幾分真實。</span>
<span className="v" id="v19" data-v="19" data-xref="約翰一書 2:19; 提多書 3:10; 使徒行傳 20:30"> 你們中間必然會有分裂的事，好顯出誰是經得起考驗的。</span>
<span className="v" id="v20" data-v="20"> 你們聚會的時候，不是在吃主的晚餐。</span>
<span className="v" id="v21" data-v="21" data-xref="彼得後書 2:13; 猶大書 1:12; 哥林多前書 11:23–25"> 因為你們進餐的時候，各人只顧吃自己的，結果有些人挨餓，有些人醉酒。</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行傳 20:28; 箴言 17:5; 雅各書 2:5–6"> 難道你們不能在家裡吃喝嗎？還是你們輕看上帝的教會，存心羞辱那些貧窮的弟兄姊妹呢？我該說什麼呢？稱讚你們嗎？不可能！</span>
<span className="v" id="v23" data-v="23" data-xref="路加福音 22:19–20; 馬太福音 26:26–28; 哥林多前書 11:23–25"> 我把從主領受的傳給了你們，就是：主耶穌被出賣的那天晚上，祂拿起餅來，</span>
<span className="v" id="v24" data-v="24" data-xref="約翰福音 6:53–58; 哥林多前書 11:27–28; 哥林多前書 10:3–4"> 祝謝後掰開，說，「這是我為你們犧牲的身體，你們要這樣做來記念我。」</span>
<span className="v" id="v25" data-v="25" data-xref="路加福音 22:20; 希伯來書 9:15–20; 希伯來書 13:20"> 飯後，祂照樣拿起杯來，說，「這杯是用我的血立的新約。你們每逢喝的時候，要這樣做來記念我。」</span>
<span className="v" id="v26" data-v="26" data-xref="希伯來書 9:28; 啟示錄 1:7; 約翰福音 14:3"> 所以，每當你們吃這餅、喝這杯的時候，就是宣告主的死，一直到主再來。</span>
<span className="v" id="v27" data-v="27" data-xref="約翰福音 6:51; 哥林多前書 10:21; 希伯來書 10:29"> 因此，無論是誰，若以不正確的心態吃主的餅、喝主的杯，就是得罪主的身體和主的血。</span>
<span className="v" id="v28" data-v="28" data-xref="加拉太書 6:4; 哥林多後書 13:5; 耶利米哀歌 3:40"> 所以，人要先自我省察，才可以吃這餅喝這杯。</span>
<span className="v" id="v29" data-v="29" data-xref="哥林多前書 11:27; 哥林多前書 11:30; 哥林多前書 11:32–34"> 因為人若不顧這是主的身體，隨便吃喝，就是自招審判。</span>
<span className="v" id="v30" data-v="30" data-xref="啟示錄 3:19; 民數記 20:12; 阿摩司書 3:2"> 正因如此，你們當中有許多人身體軟弱，疾病纏身，死亡的也不少。</span>
<span className="v" id="v31" data-v="31" data-xref="約翰一書 1:9; 詩篇 32:3–5; 啟示錄 2:5"> 我們若先自我省察，就不會遭受審判了。</span>
<span className="v" id="v32" data-v="32" data-xref="希伯來書 12:5–11; 詩篇 118:18; 箴言 3:11–12"> 主審判我們，是對我們的管教，免得我們和世人一同被定罪。</span>
<span className="v" id="v33" data-v="33"> 因此，我的弟兄姊妹，當你們聚會吃聖餐時，要彼此等候。</span>
<span className="v" id="v34" data-v="34" data-xref="哥林多前書 11:21–22; 哥林多前書 7:17; 哥林多前書 4:19"> 若有人饑餓，可以在家中先吃，免得你們聚會的時候自招審判。至於其餘的事，等我到了以後再安排。</span>
</div>

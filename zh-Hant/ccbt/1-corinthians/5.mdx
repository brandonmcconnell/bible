## 清除淫亂之罪

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="啟示錄 21:8; 啟示錄 2:21; 歌羅西書 3:5"> 我聽說在你們當中竟有人與繼母亂倫。這種淫亂的事，就是連異教徒都做不出來。</span>
<span className="v" id="v2" data-v="2" data-xref="啟示錄 2:20–22; 哥林多後書 7:7–11; 哥林多前書 5:13"> 你們竟然還自高自大！難道你們不該痛心，把做這事的人從你們當中趕出去嗎？</span>
<span className="v" id="v3" data-v="3" data-xref="歌羅西書 2:5; 帖撒羅尼迦前書 2:17; 哥林多後書 13:2"> 現在，我雖然身在遠方，心卻在你們那裡。我已經審判了做這事的人，就像親自在場一樣。</span>
<span className="v" id="v4" data-v="4" data-xref="約翰福音 20:23; 歌羅西書 3:17; 馬太福音 16:19"> 你們奉我們主耶穌的名聚會時，我的心並我們主耶穌的權能也與你們同在。</span>
<span className="v" id="v5" data-v="5" data-xref="提摩太前書 1:20; 帖撒羅尼迦後書 3:14–15; 加拉太書 6:1–2"> 你們要把這人交給撒旦去毀壞他的肉體，好使這人的靈魂在主耶穌再來的日子可以得救。</span>
<span className="v" id="v6" data-v="6" data-xref="加拉太書 5:9; 哥林多前書 15:33; 雅各書 4:16"> 你們自誇不是好事，豈不知一點麵酵能使整團麵發起來嗎？</span>
<span className="v" id="v7" data-v="7" data-xref="彼得前書 1:19–20; 以弗所書 4:22; 歌羅西書 3:5–9"> 你們要把舊酵除掉，好成為真正無酵的新麵團，因為我們逾越節的羔羊基督已經被獻為祭了。</span>
<span className="v" id="v8" data-v="8" data-xref="彼得前書 2:1–2; 申命記 16:3; 出埃及記 12:15"> 所以，我們不可帶著歹毒邪惡的舊酵守這逾越節，而要用純潔真誠的無酵餅。</span>
<span className="v" id="v9" data-v="9" data-xref="以弗所書 5:11; 帖撒羅尼迦後書 3:14; 哥林多後書 6:14"> 我以前曾經寫信吩咐你們，不可與淫亂的人交往。</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多前書 10:27; 約翰福音 17:15–16; 馬太福音 5:14–16"> 我的意思並不是指世上所有淫亂、貪婪、欺詐與祭拜偶像的人。那樣的話，你們將不得不離開這個世界。</span>
<span className="v" id="v11" data-v="11" data-xref="羅馬書 16:17; 帖撒羅尼迦後書 3:14; 帖撒羅尼迦後書 3:6"> 我的意思是，若有人自稱是信徒，卻淫亂、貪婪、祭拜偶像、毀謗、酗酒、欺詐，你們不要和他們交往，甚至不要和他們一起吃飯。</span>
<span className="v" id="v12" data-v="12" data-xref="馬可福音 4:11; 提摩太前書 3:7; 路加福音 12:14"> 審判教會以外的人與我何干？然而，教會裡面的人豈不是該由你們審判嗎？</span>
<span className="v" id="v13" data-v="13" data-xref="申命記 17:7; 申命記 13:5; 申命記 21:21"> 上帝自會審判教會以外的人，你們要把那邪惡的人從你們當中趕出去。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="申命記13·15；17·7；19·19；21·21；22·21、24；24·7。">a</a></sup></span>

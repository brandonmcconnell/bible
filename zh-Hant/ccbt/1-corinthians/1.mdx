## 問候

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="羅馬書 1:1; 以弗所書 1:1; 哥林多後書 1:1"> 我是按上帝旨意蒙召作基督耶穌使徒的保羅，同所提尼弟兄，</span>
<span className="v" id="v2" data-v="2" data-xref="羅馬書 1:7; 哥林多前書 6:9–11; 哥林多前書 1:30"> 寫信給在哥林多的上帝的教會，就是在基督耶穌裡得以聖潔、蒙召做聖徒的，以及各地求告我們主耶穌基督之名的人。基督是他們的主，也是我們的主。</span>
<span className="v" id="v3" data-v="3" data-xref="羅馬書 1:7; 哥林多後書 1:2; 彼得前書 1:2"> 願我們的父上帝和主耶穌基督賜給你們恩典和平安！</span>
</div>
</div>

## 保羅的感恩

<div className="bt">
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="羅馬書 1:8; 約翰福音 14:26; 提摩太前書 1:14"> 我常常為你們感謝我的上帝，因為祂在基督耶穌裡賜給了你們恩典，</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多後書 9:11; 哥林多後書 8:7; 歌羅西書 2:3"> 使你們在基督裡凡事富足，口才與知識兼備。</span>
<span className="v" id="v6" data-v="6" data-xref="啟示錄 1:2; 提摩太後書 1:8; 提摩太前書 2:6"> 這樣，我為基督所做的見證就在你們身上得到了印證。</span>
<span className="v" id="v7" data-v="7" data-xref="腓立比書 3:20; 彼得後書 3:12; 希伯來書 9:28"> 因此，你們在熱切等候我們的主耶穌基督再來期間，並不缺少任何屬靈的恩賜。</span>
<span className="v" id="v8" data-v="8" data-xref="帖撒羅尼迦前書 5:23–24; 帖撒羅尼迦前書 3:13; 歌羅西書 1:22"> 我們的主耶穌基督必扶持你們到底，使你們在祂再來的日子無可指責。</span>
<span className="v" id="v9" data-v="9" data-xref="帖撒羅尼迦後書 3:3; 希伯來書 10:23; 申命記 7:9"> 上帝是信實的，祂呼召你們是要你們與祂的兒子——我們的主耶穌基督相交。</span>
</div>
</div>

## 信徒要同心合意

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="腓立比書 2:1–4; 以弗所書 4:1–7; 哥林多前書 12:25"> 親愛的弟兄姊妹，我奉主耶穌基督的名勸你們，要同心合意，不可結黨紛爭，要團結一致，</span>
<span className="v" id="v11" data-v="11" data-xref="箴言 18:6; 提摩太前書 6:4; 提摩太後書 2:23–25"> 因為革來家的人把各位弟兄姊妹的事情告訴了我，說你們中間有紛爭。</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多前書 3:21–23; 約翰福音 1:42; 馬太福音 23:9–10"> 我的意思是你們有人說：「我是跟隨保羅的」，有人說：「我是跟隨亞波羅的」，有人說：「我是跟隨磯法<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="即「彼得」，下同。">a</a></sup>的」，有人說：「我是跟隨基督的」。</span>
<span className="v" id="v13" data-v="13" data-xref="以弗所書 4:5; 哥林多後書 11:4; 使徒行傳 2:38"> 難道基督是分成幾派的嗎？替你們釘十字架的是保羅嗎？你們是奉保羅的名受洗的嗎？</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行傳 18:8; 羅馬書 16:23; 哥林多前書 1:4"> 感謝上帝，除了基利司布和該猶以外，我沒有為你們任何人施洗，</span>
<span className="v" id="v15" data-v="15" data-xref="哥林多後書 11:2; 約翰福音 3:28–29; 約翰福音 7:18"> 所以沒有人能說是奉我的名受洗的。</span>
<span className="v" id="v16" data-v="16" data-xref="哥林多前書 16:15; 哥林多前書 16:17; 使徒行傳 16:33"> 不錯，我也曾為司提法納的家人施洗，除此以外，我不記得還為誰施洗了。</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多前書 2:1; 哥林多前書 2:13; 彼得後書 1:16"> 基督差遣我不是去為人施洗，而是去傳揚福音，並且不用智言慧語，免得基督十字架的能力被抹煞。</span>
</div>
</div>

## 上帝的智慧

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="哥林多前書 2:14; 羅馬書 1:16; 帖撒羅尼迦後書 2:10"> 因為十字架之道在將要滅亡的人看來是愚昧的，但對我們這些得救的人來說卻是上帝的大能，</span>
<span className="v" id="v19" data-v="19" data-xref="以賽亞書 29:14; 耶利米書 8:9; 哥林多前書 3:19"> 正如聖經上說：「我要摧毀智者的智慧，廢棄明哲的聰明。」<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="以賽亞書29·14。">b</a></sup></span>
<span className="v" id="v20" data-v="20" data-xref="羅馬書 1:22; 約伯記 12:17; 哥林多前書 3:19"> 這個世代所謂的智者、學者、雄辯家在哪裡？上帝豈不是把這世上的智慧都變成愚昧了嗎？</span>
<span className="v" id="v21" data-v="21" data-xref="路加福音 10:21; 羅馬書 1:20–22; 馬太福音 11:25"> 上帝運用自己的智慧不讓世人憑世上的智慧去認識祂，祂樂意採用世人看為愚昧的講道去拯救那些相信的人。</span>
<span className="v" id="v22" data-v="22" data-xref="馬太福音 16:1–4; 馬太福音 12:38–39; 馬可福音 8:11"> 猶太人要看神蹟，希臘人尋求智慧，</span>
<span className="v" id="v23" data-v="23" data-xref="哥林多前書 2:14; 哥林多前書 2:2; 彼得前書 2:8"> 但我們傳講被釘十字架的基督。這對猶太人來說是絆腳石，對外族人來說是愚昧的。</span>
<span className="v" id="v24" data-v="24" data-xref="哥林多前書 1:30; 歌羅西書 2:3; 哥林多前書 1:18"> 但對於蒙召的人來說，無論是猶太人還是希臘人，基督是上帝的能力、上帝的智慧。</span>
<span className="v" id="v25" data-v="25" data-xref="羅馬書 11:33–36; 哥林多前書 1:18; 撒迦利亞書 4:6–7"> 因為上帝的「愚昧」也勝過世人的智慧，上帝的「軟弱」也勝過世人的剛強。</span>
<span className="v" id="v26" data-v="26" data-xref="雅各書 2:5; 哥林多前書 3:18–20; 雅各書 1:9–11"> 弟兄姊妹，想想你們蒙召時的情形。按人的標準來衡量，你們當中稱得上有智慧的不多，有能力的不多，出身名門望族的也不多。</span>
<span className="v" id="v27" data-v="27" data-xref="雅各書 2:5; 馬太福音 11:25; 哥林多前書 1:20"> 但上帝揀選了世上愚昧的，要使智者羞愧；上帝揀選了世上軟弱的，要使強者羞愧；</span>
<span className="v" id="v28" data-v="28" data-xref="約伯記 34:24; 羅馬書 4:17; 以賽亞書 2:11"> 上帝揀選了世上卑賤的、被藐視的和無足輕重的，要使世人看為舉足輕重的變得無足輕重。</span>
<span className="v" id="v29" data-v="29" data-xref="羅馬書 3:27; 耶利米書 9:23; 以弗所書 2:9"> 這樣，誰都不能在上帝面前自誇了。</span>
<span className="v" id="v30" data-v="30" data-xref="以弗所書 1:7; 腓立比書 3:9; 羅馬書 8:1"> 上帝使你們活在基督耶穌裡，祂使基督耶穌成為我們的智慧、公義、聖潔和救贖。</span>
<span className="v" id="v31" data-v="31" data-xref="耶利米書 9:23–24; 哥林多後書 10:17; 腓立比書 3:3"> 所以，正如聖經上說：「要誇耀，就當誇耀主的作為。」<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="耶利米書9·24。">c</a></sup></span>
</div>
</div>

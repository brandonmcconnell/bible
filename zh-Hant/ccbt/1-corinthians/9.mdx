## 使徒的權利

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行傳 9:17; 提摩太前書 2:7; 哥林多前書 9:19"> 我不是自由的嗎？我不是使徒嗎？我不是見過我們的主耶穌嗎？你們不是我在主裡工作的成果嗎？</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多後書 12:12; 約翰福音 6:27; 哥林多後書 3:1–3"> 即使對別人來說我不是使徒，對你們來說我也是使徒，因為你們就是我在主裡作使徒的印證。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="哥林多後書 12:16–19; 哥林多後書 13:3; 哥林多後書 13:10"> 對那些責難我的人，我的答覆是這樣：</span>
<span className="v" id="v4" data-v="4" data-xref="帖撒羅尼迦前書 2:6; 帖撒羅尼迦後書 3:8–9; 路加福音 10:7"> 難道我們沒有權利接受弟兄姊妹供應的飲食嗎？</span>
<span className="v" id="v5" data-v="5" data-xref="約翰福音 1:42; 希伯來書 13:4; 馬太福音 8:14"> 難道我們沒有權利像主的兄弟、磯法和其他使徒一樣，帶著信主的妻子一同出入嗎？</span>
<span className="v" id="v6" data-v="6" data-xref="帖撒羅尼迦後書 3:7–9; 使徒行傳 13:1–2; 使徒行傳 4:36"> 難道只有我和巴拿巴要自食其力嗎？</span>
<span className="v" id="v7" data-v="7" data-xref="箴言 27:18; 申命記 20:6; 提摩太後書 2:3–4"> 有誰當兵要自備糧餉呢？有誰栽種葡萄園，卻不吃園中出產的葡萄呢？有誰牧養牛羊，卻不喝牛羊的奶呢？</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="以賽亞書 8:20; 帖撒羅尼迦前書 4:8; 羅馬書 3:31"> 我這樣說難道只是人的觀點嗎？律法不也是這樣說的嗎？</span>
<span className="v" id="v9" data-v="9" data-xref="申命記 25:4; 提摩太前書 5:18; 詩篇 104:27"> 摩西的律法書上說：「牛在踩穀時，不可籠住牠的嘴。」<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="申命記25·4。">a</a></sup>難道上帝關心的只是牛嗎？</span>
<span className="v" id="v10" data-v="10" data-xref="提摩太後書 2:6; 羅馬書 15:4; 羅馬書 4:23–24"> 祂這樣說難道不是為了我們嗎？這話的確是為我們寫的，因為耕耘的和打穀的農夫都應該存著分享收成的盼望勞作。</span>
<span className="v" id="v11" data-v="11" data-xref="羅馬書 15:27; 加拉太書 6:6; 哥林多後書 11:15"> 我們在你們中間既然撒下了屬靈的種子，難道就不能從你們那裡收穫物質上的供應嗎？</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多前書 9:15; 哥林多前書 9:18; 哥林多後書 11:12"> 如果別人有權要求你們供應他們，我們豈不更有權嗎？可是我們從來沒有用過這權利，反而凡事忍耐，免得妨礙了基督的福音。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="民數記 18:8–20; 民數記 5:9–10; 利未記 6:26"> 你們難道不知道，在聖殿裡事奉的人可以吃聖殿裡的食物，在祭壇前事奉的人可以分享祭壇上的祭物嗎？</span>
<span className="v" id="v14" data-v="14" data-xref="馬太福音 10:10; 提摩太前書 5:17–18; 哥林多前書 9:4"> 同樣，主也曾吩咐：傳福音的人理當藉著福音得到生活的供應。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="帖撒羅尼迦前書 2:9; 帖撒羅尼迦後書 3:8; 哥林多前書 9:12"> 但是，我完全沒有使用這權利，如今我談這些事，並不是要你們這樣待我。因為我寧死也不要讓人抹煞我所誇耀的。</span>
<span className="v" id="v16" data-v="16" data-xref="羅馬書 1:14; 耶利米書 20:9; 歌羅西書 4:17"> 其實我傳福音並沒有什麼可誇的，因為這是託付給我的任務，我不傳福音就有禍了！</span>
<span className="v" id="v17" data-v="17" data-xref="加拉太書 2:7; 哥林多前書 3:8; 歷代志上 28:9"> 我若甘心樂意地傳福音，就可以得獎賞；我若不甘願，責任也已經委託給我了。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多後書 11:7–9; 哥林多前書 8:9; 帖撒羅尼迦前書 2:6"> 那麼，我能得到什麼獎賞呢？就是我可以把福音白白地傳給人，不使用自己因傳福音而應有的權利。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="加拉太書 5:13; 馬太福音 18:15; 雅各書 5:19–20"> 我雖然是自由之身，不受任何人支配，但我甘願成為眾人的奴僕，為了要得到更多的人。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行傳 16:3; 加拉太書 5:18; 使徒行傳 21:20–26"> 面對猶太人我就做猶太人，為了要贏得猶太人。面對守律法的人，我這不受律法束縛的人就守律法，為了要贏得守律法的人。</span>
<span className="v" id="v21" data-v="21" data-xref="羅馬書 2:12; 羅馬書 2:14; 加拉太書 3:2"> 面對沒有律法的人，我就像個沒有律法的人，為了要贏得沒有律法的人。其實我並非在上帝的律法之外，我是在基督的律法之下。</span>
<span className="v" id="v22" data-v="22" data-xref="哥林多前書 10:33; 羅馬書 15:1; 哥林多前書 9:19"> 面對軟弱的人我就做軟弱的人，為了要得軟弱的人。面對什麼人，我就做什麼人，為了要盡可能地救一些人。</span>
<span className="v" id="v23" data-v="23" data-xref="提摩太後書 2:10; 馬可福音 8:35; 哥林多前書 9:25–27"> 我做的一切都是為了福音的緣故，為了要與人分享福音的祝福。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="腓立比書 3:14; 希伯來書 12:1; 提摩太後書 4:7–8"> 你們不知道嗎？在運動場上賽跑的人雖然個個都在跑，但冠軍只有一個。同樣，你們也要努力奔跑，好獲得獎賞。</span>
<span className="v" id="v25" data-v="25" data-xref="提摩太後書 2:5; 啟示錄 2:10; 提摩太後書 4:7–8"> 參加比賽的選手都事事自制，以求贏得桂冠，但這桂冠終必朽壞，我們要贏得的卻是永不朽壞的桂冠。</span>
<span className="v" id="v26" data-v="26" data-xref="彼得後書 1:10; 腓立比書 1:21; 提摩太後書 2:5"> 因此，我奔跑不是漫無目標，我擊拳不是打空氣。</span>
<span className="v" id="v27" data-v="27" data-xref="羅馬書 8:13; 哥林多前書 9:25; 歌羅西書 3:5"> 我制服己身，掌控自己，免得我傳福音給別人，自己卻被淘汰了。</span>
</div>
</div>

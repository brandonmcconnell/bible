## 論婚姻

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多前書 7:8; 哥林多前書 7:26–27; 哥林多前書 7:37–38"> 關於你們信上所寫的事，我認為男人不親近女人是好的。</span>
<span className="v" id="v2" data-v="2" data-xref="以弗所書 5:28; 以弗所書 5:33; 哥林多前書 7:9"> 不過，為了避免發生淫亂的事，男婚女嫁也合情合理。</span>
<span className="v" id="v3" data-v="3" data-xref="彼得前書 3:7; 出埃及記 21:10"> 夫妻雙方都應當盡自己的本分，過正常的夫妻生活。</span>
<span className="v" id="v4" data-v="4" data-xref="何西阿書 3:3; 馬太福音 19:9; 馬可福音 10:11–12"> 妻子無權支配自己的身體，丈夫才有權；丈夫也無權支配自己的身體，妻子才有權。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 19:15; 約珥書 2:16; 撒迦利亞書 12:12–14"> 夫妻不可彼此虧負，除非雙方同意，才可以暫時分房，以便專心祈禱。以後，二人仍要恢復正常的夫妻生活，免得撒旦趁你們情不自禁的時候引誘你們。</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多後書 8:8; 哥林多前書 7:25; 哥林多前書 7:12"> 我這麼說是准許你們這樣做，並非命令你們。</span>
<span className="v" id="v7" data-v="7" data-xref="馬太福音 19:11–12; 羅馬書 12:6; 哥林多前書 9:5"> 雖然我希望人人都像我一樣獨身，但每個人從上帝所領受的恩賜不同，有的是這樣，有的是那樣。</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多前書 7:32; 哥林多前書 7:34–35; 哥林多前書 7:26–27"> 至於那些未婚的和寡居的，他們若能像我一樣就好了。</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多前書 7:2; 提摩太前書 5:14; 提摩太前書 5:11"> 但他們若不能自制，就應該結婚，因為與其慾火攻心還不如結婚為好。</span>
<span className="v" id="v10" data-v="10" data-xref="馬太福音 5:32; 路加福音 16:18; 馬太福音 19:3–9"> 我也吩咐那些已婚的人，其實不是我吩咐，而是主吩咐：妻子不可離開丈夫，</span>
<span className="v" id="v11" data-v="11" data-xref="耶利米書 3:1; 哥林多前書 7:10; 以賽亞書 50:1"> 若是離開了，不可再嫁別人，只能與丈夫復合。丈夫也不可離棄妻子。</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多後書 11:17; 哥林多前書 7:6; 哥林多前書 7:25"> 至於其他人，主沒有吩咐什麼，但我要說，如果某弟兄的妻子不信主，但樂意和他同住，他就不應離棄妻子。</span>
<span className="v" id="v13" data-v="13"> 同樣，如果某姊妹的丈夫不信主，但樂意和她同住，她就不應離棄丈夫。</span>
<span className="v" id="v14" data-v="14" data-xref="瑪拉基書 2:15–16; 提摩太前書 4:5; 提多書 1:15"> 因為不信的丈夫因妻子而得以聖潔了。同樣，不信的妻子也因丈夫而得以聖潔了。否則你們的孩子就是不潔淨的，但如今他們是聖潔的。</span>
<span className="v" id="v15" data-v="15" data-xref="羅馬書 14:19; 哥林多後書 13:11; 雅各書 3:17–18"> 如果不信的一方堅持要離開的話，就遂其所願吧。無論是弟兄或姊妹遇到這樣的事情都不必勉強。上帝呼召我們，原是要我們和睦相處。</span>
<span className="v" id="v16" data-v="16" data-xref="彼得前書 3:1–2; 哥林多前書 9:22; 羅馬書 11:14"> 你這作妻子的，怎麼知道不能救你的丈夫呢？你這作丈夫的，怎麼知道不能救你的妻子呢？</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多前書 4:17; 羅馬書 12:3–8; 哥林多前書 7:24"> 各人應當依照上帝的呼召和安排生活，這是我對各教會的吩咐。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行傳 15:5; 使徒行傳 15:28; 使徒行傳 15:24"> 如果蒙召時已經受了割禮，不必消除割禮；如果蒙召時沒有受割禮，也不必去受割禮。</span>
<span className="v" id="v19" data-v="19" data-xref="加拉太書 6:15; 加拉太書 5:6; 約翰一書 2:3–4"> 受不受割禮都算不得什麼，最要緊的是遵行上帝的誡命。</span>
<span className="v" id="v20" data-v="20" data-xref="哥林多前書 7:17; 帖撒羅尼迦前書 4:11; 帖撒羅尼迦後書 3:12"> 各人應當保持自己蒙召時的身分。</span>
<span className="v" id="v21" data-v="21" data-xref="彼得前書 2:18–24; 歌羅西書 3:11; 路加福音 10:40–41"> 如果你蒙召時是奴隸，不必因此而煩惱。不過如果你可以獲得自由，也不要放過機會。</span>
<span className="v" id="v22" data-v="22" data-xref="彼得前書 2:16; 腓利門書 1:16; 歌羅西書 3:22–24"> 因為，蒙召信主時做奴隸的，現在是主的自由人；蒙召時做自由人的，現在是基督的奴僕。</span>
<span className="v" id="v23" data-v="23" data-xref="哥林多前書 6:20; 彼得前書 1:18–19; 提多書 2:14"> 你們是主用重價買來的，不要做人的奴隸。</span>
<span className="v" id="v24" data-v="24" data-xref="哥林多前書 7:20; 歌羅西書 3:23–24; 哥林多前書 7:17"> 弟兄姊妹，你們要在上帝面前保持自己蒙召時的身分。</span>
<span className="v" id="v25" data-v="25" data-xref="哥林多前書 7:6; 哥林多前書 4:2; 哥林多前書 7:40"> 關於獨身的問題，主並沒有給我任何命令，但我既然深受主恩，成為祂忠心的僕人，就向你們提供一些意見。</span>
<span className="v" id="v26" data-v="26" data-xref="哥林多前書 7:1; 哥林多前書 7:8; 彼得前書 4:17"> 鑒於目前時勢艱難，我認為各人最好是安於現狀。</span>
<span className="v" id="v27" data-v="27" data-xref="哥林多前書 7:20; 哥林多前書 7:12–14"> 已經有妻子的，就不要設法擺脫她；還沒有妻子的，就不要想著結婚。</span>
<span className="v" id="v28" data-v="28" data-xref="希伯來書 13:4; 哥林多前書 7:32–36; 哥林多前書 7:26"> 男婚女嫁並不是犯罪，只是有家室的人總免不了許多人生的苦惱，我是盼望你們能夠免去這些苦惱。</span>
<span className="v" id="v29" data-v="29" data-xref="約翰一書 2:17; 哥林多前書 7:31; 羅馬書 13:11–12"> 弟兄們，我告訴你們，時日不多了，從今以後，那些有妻子的，要像沒有妻子的；</span>
<span className="v" id="v30" data-v="30" data-xref="詩篇 30:5; 路加福音 6:25; 路加福音 6:21"> 哭泣的，要像不哭泣的；歡喜的，要像不歡喜的；置辦家業的，要像一無所有的。</span>
<span className="v" id="v31" data-v="31" data-xref="約翰一書 2:17; 彼得前書 4:7; 雅各書 4:14"> 享用世界之物的，不要沉溺其中。因為現今的世界很快就要過去了。</span>
<span className="v" id="v32" data-v="32" data-xref="馬太福音 6:25–34; 提摩太前書 5:5; 腓立比書 4:6"> 我希望你們無牽無掛。未婚的男子可以關心主的事，想著怎樣討主的喜悅。</span>
<span className="v" id="v33" data-v="33" data-xref="彼得前書 3:7; 歌羅西書 3:19; 以弗所書 5:25–33"> 但已婚的男子關心世上的事，想著如何取悅妻子，</span>
<span className="v" id="v34" data-v="34" data-xref="路加福音 10:40–42; 哥林多前書 6:20; 路加福音 2:36–37"> 難免分心。沒有丈夫的婦女和處女可以關心主的事，叫身體和心靈都聖潔；但已婚的婦女關心世上的事，想著如何取悅丈夫。</span>
<span className="v" id="v35" data-v="35" data-xref="哥林多前書 7:33–34; 哥林多前書 7:36; 路加福音 8:14"> 我這樣說是為了你們的好處，不是要束縛你們，而是要鼓勵你們做合宜的事，好叫你們殷勤、專心事奉主。</span>
<span className="v" id="v36" data-v="36" data-xref="哥林多前書 7:37; 哥林多前書 7:9; 撒母耳記上 2:33"> 若有人覺得對待自己的未婚妻有不合宜之處，自己又情慾難禁，就成全他的心願，讓他們結婚吧！這並不算犯罪。</span>
<span className="v" id="v37" data-v="37"> 如果這人心裡確信自己沒有結婚的需要，又能自己作主，打定主意不結婚，這樣做也好。</span>
<span className="v" id="v38" data-v="38" data-xref="希伯來書 13:4; 哥林多前書 7:1–2; 哥林多前書 7:8"> 所以，與未婚妻完婚是對的，但不結婚則更好。</span>
<span className="v" id="v39" data-v="39" data-xref="羅馬書 7:2–3; 哥林多後書 6:14–16; 哥林多前書 7:10"> 丈夫還活著的時候，妻子必須忠於丈夫。如果丈夫去世了，她就自由了，可以再婚，只是要嫁給信主的弟兄。</span>
<span className="v" id="v40" data-v="40" data-xref="哥林多前書 7:35; 彼得後書 3:15–16; 哥林多前書 7:8"> 然而，照我的意見，她若能不再婚就更有福了。我想自己也是受了上帝的靈感動才說這番話的。</span>

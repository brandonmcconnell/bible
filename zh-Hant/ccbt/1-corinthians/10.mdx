## 前車之鑑

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及記 14:29; 尼希米記 9:11–12; 詩篇 78:13–14"> 弟兄姊妹，我希望你們知道，我們的祖先曾經在雲下，都曾經走過紅海，</span>
<span className="v" id="v2" data-v="2" data-xref="希伯來書 3:2–3; 哥林多前書 1:13–16; 出埃及記 14:31"> 都在雲下、在海中受洗跟從了摩西。</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 8:3; 尼希米記 9:15; 出埃及記 16:35"> 他們都吃過同樣的靈糧，</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及記 17:6; 約翰福音 7:37; 以賽亞書 48:21"> 都喝過同樣的靈水，因為他們從那與他們同行的屬靈磐石中得水喝，那磐石就是基督。</span>
<span className="v" id="v5" data-v="5" data-xref="希伯來書 3:17; 猶大書 1:5; 民數記 14:37"> 儘管如此，他們當中大多數人不討上帝的喜悅，倒斃在曠野。</span>
<span className="v" id="v6" data-v="6" data-xref="猶大書 1:7; 哥林多前書 10:11; 希伯來書 4:11"> 如今這些事正好警戒我們，叫我們不要像他們那樣貪戀罪惡。</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及記 32:6–8; 詩篇 106:19–20; 哥林多前書 6:9"> 也不要祭拜偶像，像他們當中的人那樣，正如聖經上說：「百姓坐下吃喝，起來狂歡。」<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="出埃及記32·6。">a</a></sup></span>
<span className="v" id="v8" data-v="8" data-xref="民數記 25:1–9; 哥林多前書 6:18; 詩篇 106:29"> 我們也不要淫亂，像他們當中的人那樣，結果一天就死了兩萬三千人。</span>
<span className="v" id="v9" data-v="9" data-xref="民數記 21:5–6; 詩篇 78:18; 希伯來書 3:8–11"> 也不要試探主，像他們當中的人那樣，結果被蛇咬死了。</span>
<span className="v" id="v10" data-v="10" data-xref="民數記 14:2; 民數記 16:41; 民數記 14:37"> 也不要發怨言，像他們當中的人那樣，結果被滅命的天使毀滅了。</span>
<span className="v" id="v11" data-v="11" data-xref="羅馬書 15:4; 羅馬書 13:11; 哥林多前書 9:10"> 發生在他們身上的這些事都是鑑戒，之所以記錄下來是為了警戒我們這活在末世的人。</span>
<span className="v" id="v12" data-v="12" data-xref="羅馬書 11:20; 彼得後書 3:17; 箴言 16:18"> 所以，自以為站得穩的人要小心，免得跌倒。</span>
<span className="v" id="v13" data-v="13" data-xref="彼得後書 2:9; 提摩太後書 4:18; 帖撒羅尼迦後書 3:3"> 你們遇見的誘惑無非是人們常見的。上帝是信實的，祂絕不會讓你們遇見無法抵擋的誘惑，祂必為你們開一條出路，使你們經得住誘惑。</span>
</div>
</div>

## 切勿祭拜偶像

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="啟示錄 21:8; 約翰一書 5:21; 彼得前書 2:11"> 所以，我親愛的弟兄姊妹，你們要遠避祭拜偶像的事。</span>
<span className="v" id="v15" data-v="15" data-xref="哥林多前書 8:1; 帖撒羅尼迦前書 5:21; 哥林多前書 11:13"> 你們都是明白事理的人，可以判斷我的話對不對。</span>
<span className="v" id="v16" data-v="16" data-xref="馬太福音 26:26–28; 哥林多前書 11:23–29; 使徒行傳 2:42"> 領聖餐時，我們為那福杯獻上感謝，這不表示我們有份於基督的血嗎？我們吃掰開的餅，這不表示我們有份於基督的身體嗎？</span>
<span className="v" id="v17" data-v="17" data-xref="羅馬書 12:5; 歌羅西書 3:15; 哥林多前書 12:27"> 我們人數雖多，卻同屬一個身體，因為餅只有一個，我們同享一個餅。</span>
<span className="v" id="v18" data-v="18" data-xref="腓立比書 3:3–5; 加拉太書 6:16; 利未記 7:6"> 你們看以色列人<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="「以色列人」希臘文是「從血統上講是以色列人」。">b</a></sup>，那些吃祭物的難道不是有份於祭壇嗎？</span>
<span className="v" id="v19" data-v="19" data-xref="哥林多前書 8:4; 哥林多前書 3:7; 哥林多前書 13:2"> 我這話是什麼意思呢？是說偶像和祭偶像的食物有什麼特別嗎？</span>
<span className="v" id="v20" data-v="20" data-xref="啟示錄 9:20; 詩篇 106:37–39; 申命記 32:16–17"> 當然不是，我的意思是那些異教徒所獻的祭是祭鬼魔的，而不是獻給上帝的。我不願意你們與鬼魔有任何關係。</span>
<span className="v" id="v21" data-v="21" data-xref="馬太福音 6:24; 列王紀上 18:21; 哥林多後書 6:15–17"> 你們不能又喝主的杯又喝鬼魔的杯，不能又吃主的聖餐又吃祭鬼魔的食物。</span>
<span className="v" id="v22" data-v="22" data-xref="申命記 32:21; 申命記 32:16; 希伯來書 10:31"> 我們想惹主嫉妒嗎？難道我們比祂更有能力嗎？</span>
</div>
</div>

## 信徒的自由

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="哥林多前書 6:12; 哥林多前書 8:9; 以弗所書 4:29"> 凡事我都可以做，但並非事事都有益處；凡事我都可以行，但並非事事都造就人。</span>
<span className="v" id="v24" data-v="24" data-xref="羅馬書 15:1–2; 哥林多前書 10:33; 腓立比書 2:4–5"> 無論是誰，不要求自己的好處，要求別人的好處。</span>
<span className="v" id="v25" data-v="25" data-xref="提摩太前書 4:4; 哥林多前書 8:7; 提多書 1:15"> 市場上賣的肉，你們都可以吃，不必為良心的緣故而詢問什麼，</span>
<span className="v" id="v26" data-v="26" data-xref="詩篇 24:1; 出埃及記 19:5; 詩篇 50:12"> 因為大地和其中的萬物都屬於主。<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="詩篇24·1。">c</a></sup></span>
<span className="v" id="v27" data-v="27" data-xref="哥林多前書 10:25; 路加福音 10:7–8; 哥林多前書 5:9–11"> 如果有非信徒邀請你們吃飯，你們又願意去，那麼，只管吃桌上擺的食物，不必為良心的緣故而詢問什麼。</span>
<span className="v" id="v28" data-v="28" data-xref="哥林多前書 8:10–13; 哥林多前書 8:7; 哥林多前書 10:26"> 不過，如果有人告訴你這些是獻給偶像的祭物，你為了那告訴你的人和良心的緣故，就不要吃。</span>
<span className="v" id="v29" data-v="29" data-xref="哥林多前書 9:19; 羅馬書 14:15–21; 哥林多前書 8:9–13"> 不過我指的不是你的良心，而是那人的良心。也許有人說：「我的自由為什麼要受別人的良心限制呢？</span>
<span className="v" id="v30" data-v="30" data-xref="羅馬書 14:6; 提摩太前書 4:3–4"> 我若存感恩的心吃，為什麼還要受譴責呢？」</span>
<span className="v" id="v31" data-v="31" data-xref="歌羅西書 3:17; 歌羅西書 3:23; 彼得前書 4:11"> 所以，你們或吃或喝，無論做什麼，都要為上帝的榮耀而做。</span>
<span className="v" id="v32" data-v="32" data-xref="使徒行傳 20:28; 哥林多前書 10:33; 羅馬書 14:13"> 不要成為猶太人、希臘人或上帝教會的絆腳石，</span>
<span className="v" id="v33" data-v="33" data-xref="哥林多前書 10:24; 加拉太書 1:10; 哥林多前書 9:19–23"> 就像我凡事儘量讓人滿意，不求自己的好處，只求眾人的好處，以便他們可以得救。</span>
</div>

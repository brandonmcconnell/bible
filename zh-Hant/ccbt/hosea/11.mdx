## 耶和華對以色列的愛

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="馬太福音 2:15; 出埃及記 4:22; 何西阿書 13:4"> <span className="pl pl-1">耶和華說：</span><br /><span className="pl pl-1">「以色列年幼時，我就愛他，</span><br /><span className="pl pl-1">視他為兒子，把他從埃及召出來。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="耶利米書 18:15; 何西阿書 2:13; 以賽亞書 65:7"> <span className="pl pl-1">可是，我越召喚他們，他們就跑得越遠，</span><br /><span className="pl pl-1">給巴力獻祭，向偶像燒香。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="耶利米書 30:17; 申命記 1:31; 出埃及記 15:26"> <span className="pl pl-1">是我教以法蓮學步，張開雙臂抱他們，</span><br /><span className="pl pl-1">他們卻不知道是我醫治他們。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="約翰福音 12:32; 利未記 26:13; 哥林多後書 5:14"> <span className="pl pl-1">我用慈繩愛索牽引他們，</span><br /><span className="pl pl-1">解開他們所負的重軛，</span><br /><span className="pl pl-1">彎腰餵養他們。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="何西阿書 7:16; 何西阿書 8:13; 列王紀下 17:13–14"> <span className="pl pl-1">「他們要返回埃及，</span><br /><span className="pl pl-1">亞述要統治他們，</span><br /><span className="pl pl-1">因為他們不肯歸向我。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="何西阿書 13:16; 何西阿書 10:6; 何西阿書 10:14"> <span className="pl pl-1">刀劍之災要臨到他們的城邑，</span><br /><span className="pl pl-1">毀壞他們的城門，將他們吞噬，</span><br /><span className="pl pl-1">因為他們倚仗自己的計謀。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="耶利米書 8:5; 阿摩司書 5:14–15; 何西阿書 7:16"> <span className="pl pl-1">我的子民執意離我而去，</span><br /><span className="pl pl-1">他們雖然求告至高的我，</span><br /><span className="pl pl-1">我也不會救拔他們。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="耶利米書 31:20; 馬太福音 23:37; 何西阿書 6:4"> <span className="pl pl-1">以法蓮啊，我怎能捨棄你？</span><br /><span className="pl pl-1">以色列啊，我怎能棄絕你？</span><br /><span className="pl pl-1">我怎能使你的下場如押瑪？</span><br /><span className="pl pl-1">我怎能對待你如對待洗扁？</span><br /><span className="pl pl-1">我的心意改變，我滿懷憐愛。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="民數記 23:19; 以賽亞書 55:8–9; 彌迦書 7:18–20"> <span className="pl pl-1">我不再發烈怒，</span><br /><span className="pl pl-1">也不再毀滅以法蓮。</span><br /><span className="pl pl-1">因為我是上帝，不是世人，</span><br /><span className="pl pl-1">是住在你們中間的聖者，</span><br /><span className="pl pl-1">我必不帶著烈怒來臨。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="以賽亞書 31:4; 約珥書 3:16; 阿摩司書 1:2"> <span className="pl pl-1">「以色列子民必跟隨耶和華，</span><br /><span className="pl pl-1">祂要像獅子一樣吼叫。</span><br /><span className="pl pl-1">祂吼叫的時候，</span><br /><span className="pl pl-1">他們要戰戰兢兢地從西方來。</span><br /></span>

</div>

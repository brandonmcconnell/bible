## 何西阿宣佈對以色列的懲罰

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="何西阿書 10:5; 何西阿書 4:12; 耶利米書 44:17"> <span className="pl pl-1">以色列啊，</span><br /><span className="pl pl-1">不要歡喜快樂，</span><br /><span className="pl pl-1">不要像外族人那樣歡喜快樂！</span><br /><span className="pl pl-1">因為你對你的上帝不忠不貞，</span><br /><span className="pl pl-1">喜愛在各麥場上接受嫖資。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="何西阿書 2:9; 彌迦書 6:13–16; 約珥書 1:3–7"> <span className="pl pl-1">麥場上的穀物和榨酒池的酒將不夠養活你們，</span><br /><span className="pl pl-1">新酒也必斷絕。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="以西結書 4:13; 何西阿書 8:13; 利未記 25:23"> <span className="pl pl-1">你們將不能再住在耶和華的土地上。</span><br /><span className="pl pl-1">以法蓮要返回埃及，</span><br /><span className="pl pl-1">在亞述吃不潔之物。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="何西阿書 8:13; 申命記 26:14; 耶利米書 6:20"> <span className="pl pl-1">你們將不能再獻奠祭給耶和華，</span><br /><span className="pl pl-1">你們的祭牲也不蒙悅納。</span><br /><span className="pl pl-1">這些祭物如居喪之人的食物，</span><br /><span className="pl pl-1">吃的人都被玷污。</span><br /><span className="pl pl-1">你們的食物只能供自己吃，</span><br /><span className="pl pl-1">不能帶進耶和華的殿。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="以賽亞書 10:3; 耶利米書 5:31; 何西阿書 2:11"> <span className="pl pl-1">在節日，在耶和華所定的節期裡，</span><br /><span className="pl pl-1">你們要做什麼呢？</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="何西阿書 10:8; 以賽亞書 5:6; 以賽亞書 7:23"> <span className="pl pl-1">即使你們逃脫毀滅之災，</span><br /><span className="pl pl-1">埃及人也要把你們聚集起來，</span><br /><span className="pl pl-1">在摩弗埋葬你們。</span><br /><span className="pl pl-1">你們的珍貴銀器要散落在荊棘中，</span><br /><span className="pl pl-1">你們的帳篷中要長滿蒺藜。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="使徒行傳 26:24–25; 彌迦書 7:4; 列王紀下 9:11"> <span className="pl pl-1">以色列人受懲罰的日子近了，</span><br /><span className="pl pl-1">遭報應的時候到了！</span><br /><span className="pl pl-1">你們必知道。</span><br /><span className="pl pl-1">因為你們罪惡深重，充滿憎恨，</span><br /><span className="pl pl-1">先知被當成傻瓜，</span><br /><span className="pl pl-1">被靈感動的人被視為瘋子。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="何西阿書 5:1; 以西結書 3:17; 以賽亞書 62:6"> <span className="pl pl-1">先知為了上帝做以法蓮的守望者，</span><br /><span className="pl pl-1">可是他走的路上佈滿網羅，</span><br /><span className="pl pl-1">在他上帝的家裡遭人憎恨。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="何西阿書 10:9; 士師記 19:16–21; 何西阿書 8:13"> <span className="pl pl-1">你們敗壞至極，</span><br /><span className="pl pl-1">恰如從前在基比亞的日子。</span><br /><span className="pl pl-1">耶和華必記住你們的罪惡，</span><br /><span className="pl pl-1">追討你們的罪債。</span></span>
</div>
<div className="bp poetry">

<span className="v" id="v11" data-v="11" data-xref="申命記 28:18; 何西阿書 9:14; 何西阿書 4:7"> <span className="pl pl-1">以法蓮人的榮耀要如鳥飛逝，</span><br /><span className="pl pl-1">你們將不能受孕，</span><br /><span className="pl pl-1">不能懷胎，</span><br /><span className="pl pl-1">也不能生育。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="何西阿書 7:13; 申命記 32:25; 申命記 31:17"> <span className="pl pl-1">你們縱然把孩子養大，</span><br /><span className="pl pl-1">我也要奪去他們的性命，一個也不留。</span><br /><span className="pl pl-1">我撇棄你們的時候，</span><br /><span className="pl pl-1">你們就有禍了！</span><br /></span>

</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="路加福音 23:29; 哥林多前書 7:26; 馬可福音 13:17"> <span className="pl pl-1">耶和華啊，求你給他們——</span><br /><span className="pl pl-1">你要給他們什麼呢？</span><br /><span className="pl pl-1">求你使他們子宮流產，乳房乾癟。</span></span>

## 對以色列和猶大的審判

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="何西阿書 9:8; 彌迦書 7:2; 彌迦書 3:9"> <span className="pl pl-1">「祭司啊，要聽！</span><br /><span className="pl pl-1">以色列家啊，要留心聽！</span><br /><span className="pl pl-1">王室啊，要側耳聽！</span><br /><span className="pl pl-1">這是對你們的審判，</span><br /><span className="pl pl-1">因為你們像設在米斯巴的圈套，</span><br /><span className="pl pl-1">像鋪在他泊山的網羅。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="何西阿書 9:15; 以賽亞書 29:15; 何西阿書 6:9"> <span className="pl pl-1">你們這些叛逆之徒大肆殺戮，</span><br /><span className="pl pl-1">我要責罰你們所有人。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="阿摩司書 3:2; 希伯來書 4:13; 何西阿書 13:1"> <span className="pl pl-1">我對以法蓮一清二楚，以色列瞞不過我。</span><br /><span className="pl pl-1">以法蓮做了妓女，以色列被玷污了。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v4" data-v="4" data-xref="何西阿書 4:12; 約翰一書 2:3–4; 何西阿書 4:1"> <span className="pl pl-1">他們的惡行阻撓他們歸向自己的上帝，</span><br /><span className="pl pl-1">因為淫亂之靈佔據了他們的心，</span><br /><span className="pl pl-1">以致他們不認識耶和華。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="何西阿書 7:10; 阿摩司書 5:2; 以西結書 23:31–35"> <span className="pl pl-1">以色列被自己的傲慢指控，</span><br /><span className="pl pl-1">以色列和以法蓮要跌倒在自己的罪中，</span><br /><span className="pl pl-1">猶大也要一同跌倒。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="彌迦書 6:6–7; 約翰福音 7:34; 箴言 1:28"> <span className="pl pl-1">他們牽著牛羊去尋求耶和華，</span><br /><span className="pl pl-1">卻尋不到，</span><br /><span className="pl pl-1">因為祂已離他們而去。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="何西阿書 6:7; 以賽亞書 48:8; 耶利米書 3:20"> <span className="pl pl-1">他們對耶和華不忠，</span><br /><span className="pl pl-1">所生的是私生子，</span><br /><span className="pl pl-1">他們和他們的田地必在朔日被吞噬。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="何西阿書 4:15; 何西阿書 9:9; 撒母耳記上 15:34"> <span className="pl pl-1">耶和華說：</span><br /><span className="pl pl-1">「要在基比亞吹角，</span><br /><span className="pl pl-1">在拉瑪鳴號，</span><br /><span className="pl pl-1">在伯·亞文吶喊，</span><br /><span className="pl pl-1">便雅憫啊，敵人就在你身後！</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="撒迦利亞書 1:6; 以賽亞書 46:10; 何西阿書 9:11–17"> <span className="pl pl-1">以法蓮啊，你要在受懲罰的日子淪為廢墟！</span><br /><span className="pl pl-1">我要在以色列各支派中宣告將來必要發生的事！</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="申命記 19:14; 申命記 27:17; 詩篇 93:3–4"> <span className="pl pl-1">猶大的首領如同擅移地界的人，</span><br /><span className="pl pl-1">侵吞以色列的領土，</span><br /><span className="pl pl-1">我要將烈怒如洪水般傾瀉在他們身上。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="申命記 28:33; 彌迦書 6:16; 列王紀上 12:26–33"> <span className="pl pl-1">以法蓮因甘願追隨偶像而受欺壓，</span><br /><span className="pl pl-1">被審判壓碎。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="以賽亞書 51:8; 約伯記 13:28; 以賽亞書 50:9"> <span className="pl pl-1">我要使以法蓮像蟲蛀的衣服，</span><br /><span className="pl pl-1">使猶大家像朽爛的木頭。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v13" data-v="13" data-xref="何西阿書 7:11; 何西阿書 12:1; 何西阿書 10:6"> <span className="pl pl-1">「以法蓮見自己患病，</span><br /><span className="pl pl-1">猶大見自己有傷，</span><br /><span className="pl pl-1">以法蓮便向強大的亞述王</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「強大的亞述王」或譯為「耶雷布王」，同10·6。">a</a></sup><br /><span className="pl pl-1">求救。</span><br /><span className="pl pl-1">亞述王卻不能醫治你們，</span><br /><span className="pl pl-1">也無法為你們療傷。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="詩篇 7:2; 彌迦書 5:8; 何西阿書 13:7–8"> <span className="pl pl-1">我要像獅子一樣對待以法蓮，</span><br /><span className="pl pl-1">如猛獅一樣對待猶大家，</span><br /><span className="pl pl-1">將他們撕碎、拖走，</span><br /><span className="pl pl-1">無人能營救他們。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="以賽亞書 26:16; 耶利米書 29:12–14; 申命記 4:29–31"> <span className="pl pl-1">我要返回我的居所，</span><br /><span className="pl pl-1">直到他們知罪來尋求我。</span><br /><span className="pl pl-1">在苦難的日子裡，</span><br /><span className="pl pl-1">他們必懇切地尋求我。」</span></span>

## 哈曼圖謀滅絕猶太人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民數記 24:7; 以斯帖記 5:11; 但以理書 6:2"> 後來，亞哈隨魯王提拔亞甲人哈米大他的兒子哈曼，使他的權位高過他所有的同僚。</span>
<span className="v" id="v2" data-v="2" data-xref="以斯帖記 3:5; 詩篇 15:4; 以斯帖記 5:9"> 王命令所有在宮門供職的臣僕都要向哈曼跪拜，但末底改不肯跪拜。</span>
<span className="v" id="v3" data-v="3" data-xref="以斯帖記 3:2; 出埃及記 1:17; 以斯帖記 2:19"> 在宮門供職的臣僕問末底改：「你為何違抗王的命令？」</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 39:10; 約拿書 1:9; 但以理書 6:20–28"> 他們天天勸他，他卻不聽。他們便把這件事告訴哈曼，想看看末底改這樣做是否能站得住，因為末底改已告訴他們自己是猶太人。</span>
<span className="v" id="v5" data-v="5" data-xref="但以理書 3:19; 以斯帖記 5:9; 箴言 21:24"> 哈曼見末底改不肯向他跪拜，就怒氣填胸。</span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 83:4; 啟示錄 12:12"> 他得知末底改是猶太人後，便不屑於只害末底改一人，而是要剷除亞哈隨魯王國內所有的猶太人，即末底改的同胞。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="以斯拉記 6:15; 以西結書 21:21–22; 以斯帖記 9:24–26"> 亞哈隨魯王十二年一月，即尼散月，有人在哈曼面前抽普珥，也就是抽籤，來決定哪月哪日下手，結果抽中十二月，即亞達月。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="以斯拉記 4:12–15; 使徒行傳 16:20–21; 申命記 4:27"> 哈曼對亞哈隨魯王說：「有一個民族散居在王境內各省的眾民族中，他們的律例與各族的律例不同，他們不遵守王的律例，所以容忍他們對王不利。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 23:16; 馬太福音 18:24"> 王若願意，就請降旨消滅他們。我願捐六百八十萬兩銀子交給管理國事的人，納入王的庫房。」</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 41:42; 以斯帖記 8:2; 以斯帖記 7:6"> 於是，王摘下手上的戒指，交給猶太人的仇敵——亞甲人哈米大他的兒子哈曼，</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 23:25; 耶利米書 40:4; 耶利米書 26:14"> 對他說：「這些銀子歸你，這個民族也交給你，隨你處置。」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="列王紀上 21:8; 以斯帖記 1:22; 但以理書 6:12"> 一月十三日，王的書記被召來，他們以亞哈隨魯王的名義，照哈曼的吩咐，用各省的文字和各族的語言寫諭旨，用王的戒指蓋印，送交各總督、各省省長和各族首領。</span>
<span className="v" id="v13" data-v="13" data-xref="歷代志下 30:6; 以斯帖記 9:10; 以斯帖記 8:10–14"> 諭旨由信差送到王的各省，限令在一天之內，也就是亞達月十三日，即十二月十三日，把猶太人的男女老少全部剷除、殺光、滅盡，並奪取他們的財物。</span>
<span className="v" id="v14" data-v="14" data-xref="以斯帖記 8:13–14"> 諭旨的抄本作為法令頒佈到各省，通知各族為那天做好準備。</span>
<span className="v" id="v15" data-v="15" data-xref="以斯帖記 8:15; 約翰福音 16:20; 箴言 29:2"> 信差奉王的命令急忙上路，諭旨也在書珊城裡頒佈了。王和哈曼坐下飲酒，書珊城一片慌亂。</span>
</div>
</div>

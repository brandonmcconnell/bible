## 猶太人獲拯救

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以斯帖記 2:7; 以斯帖記 2:15; 箴言 13:22"> 當天，亞哈隨魯王把猶太人的仇敵哈曼的家產賜給以斯帖王后。末底改也來到王面前，因為以斯帖陳明了他們的親屬關係。</span>
<span className="v" id="v2" data-v="2" data-xref="以斯帖記 3:10; 創世記 41:42; 但以理書 2:48"> 王摘下自己的戒指，就是從哈曼手中取回的，賜給末底改。以斯帖派末底改管理哈曼的家產。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="何西阿書 12:4; 以賽亞書 38:2; 列王紀下 4:27"> 以斯帖又俯伏在王的腳前，流淚哀求王廢掉亞甲人哈曼加害猶太人的陰謀。</span>
<span className="v" id="v4" data-v="4" data-xref="以斯帖記 5:2; 以斯帖記 4:11"> 王向以斯帖伸出金杖，以斯帖就起來站在王面前，</span>
<span className="v" id="v5" data-v="5" data-xref="以斯帖記 7:3; 以斯帖記 5:8; 以斯帖記 3:12–13"> 說：「王若願意，我若得到王的恩寵，王若認為好，並且喜悅我，就請王降旨，廢除亞甲人哈米大他的兒子哈曼陰謀滅絕各省猶太人的諭旨。</span>
<span className="v" id="v6" data-v="6" data-xref="以斯帖記 7:4; 羅馬書 10:1; 羅馬書 9:2–3"> 我怎能忍心看我本族的人受害？我怎能忍心看我的親族被殺？」</span>
<span className="v" id="v7" data-v="7" data-xref="以斯帖記 7:10–1; 加拉太書 3:13; 箴言 13:22"> 亞哈隨魯王對以斯帖王后和猶太人末底改說：「我已把哈曼的家產賜給以斯帖，並把他吊在木架上了，因為他想害猶太人。</span>
<span className="v" id="v8" data-v="8" data-xref="以斯帖記 1:19; 以斯帖記 3:12; 以斯帖記 8:5"> 現在，你們盡可奉王的名寫諭旨給猶太人，用王的戒指蓋印，因為奉王的名所寫、用王的戒指蓋印的諭旨是不可廢除的。」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="以斯帖記 1:22; 以斯帖記 1:1; 列王紀下 18:26"> 三月，即西彎月二十三日，王的書記被召來，按照末底改的一切吩咐用各省的文字和各族的語言，包括猶太人的文字和語言寫諭旨，傳給從印度到古實的一百二十七省的猶太人、總督、省長和官員。</span>
<span className="v" id="v10" data-v="10" data-xref="以賽亞書 60:6; 耶利米書 2:23; 以賽亞書 66:20"> 末底改奉亞哈隨魯王的名寫諭旨，用王的戒指蓋印，讓信差騎王室快馬送往各地。</span>
<span className="v" id="v11" data-v="11" data-xref="以斯帖記 3:13; 詩篇 37:14–15; 詩篇 146:6–9"> 諭旨上說，王准許各城的猶太人在十二月，即亞達月十三日，聚集起來自衛，剷除、殺光、滅盡各族各省攻擊他們的軍隊及其兒女、妻子，奪取仇敵的財物。</span>
<span className="v" id="v13" data-v="13" data-xref="啟示錄 6:10; 以斯帖記 3:14; 士師記 16:28"> 諭旨的抄本頒佈到各省，昭告各族，使猶太人在那天預備好向仇敵報仇。</span>
<span className="v" id="v14" data-v="14" data-xref="以斯帖記 3:15; 但以理書 8:2; 以斯帖記 2:3"> 信差接到王的命令，急忙騎上王室快馬上路。在書珊城也頒佈了諭旨。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="路加福音 16:19; 馬太福音 6:29; 以斯帖記 3:15"> 末底改身穿藍色和白色朝服，頭戴大金冠，披著紫色細麻布外袍，從王那裡出來，書珊城的人都歡呼雀躍。</span>
<span className="v" id="v16" data-v="16" data-xref="箴言 11:10; 詩篇 97:11; 詩篇 18:28"> 猶太人高興歡喜，感到快樂光榮。</span>
<span className="v" id="v17" data-v="17" data-xref="以斯帖記 9:19; 撒迦利亞書 8:20–23; 撒母耳記上 25:8"> 各省各城，凡諭旨所到之處，猶太人都歡喜快樂，設宴慶祝。許多當地人因懼怕猶太人而入了猶太籍。</span>
</div>
</div>

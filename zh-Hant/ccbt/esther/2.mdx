## 以斯帖被立為王后

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="但以理書 6:14–18; 以斯帖記 7:10; 以斯帖記 1:12–21"> 這事之後，亞哈隨魯王的怒氣平息下來，就想起瓦實提和她的所作所為，並怎樣降旨懲罰她的事。</span>
<span className="v" id="v2" data-v="2" data-xref="列王紀上 1:2; 創世記 12:14; 以斯帖記 6:14"> 王的侍臣說：「讓人為王物色一些年輕貌美的處女吧。</span>
<span className="v" id="v3" data-v="3" data-xref="以斯帖記 2:12–15; 以斯帖記 2:8–9; 以斯帖記 1:1–2"> 請王在國中各省委派專使把所有年輕漂亮的處女選入書珊城的女宮，交給管理女子的太監希該，供給她們美容用品。</span>
<span className="v" id="v4" data-v="4" data-xref="馬太福音 14:6; 馬太福音 20:16; 以斯帖記 1:21"> 哪個女子討王歡心，便立她為王后，代替瓦實提。」王覺得這個建議很好，就採納了。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="撒母耳記下 16:5; 撒母耳記上 9:1; 以斯帖記 10:3"> 當時，書珊城中有個猶太人，名叫末底改，是便雅憫人基士的曾孫、示每的孫子、雅珥的兒子。</span>
<span className="v" id="v6" data-v="6" data-xref="列王紀下 24:14–15; 歷代志下 36:20; 耶利米書 24:1"> 巴比倫王尼布甲尼撒曾從耶路撒冷擄走猶大王耶哥尼雅和百姓，末底改也在其中。</span>
<span className="v" id="v7" data-v="7" data-xref="以斯帖記 2:15; 以斯帖記 1:11; 哥林多後書 6:18"> 末底改收養了叔叔的女兒哈大沙，又名以斯帖，把她認作自己的女兒，因為她父母雙亡。這女子體態優美，容貌動人。</span>
<span className="v" id="v8" data-v="8" data-xref="以斯帖記 2:3; 以斯帖記 2:15"> 王的諭旨一下，許多年輕的女子被召到書珊城中，交給管理女子的希該照管。以斯帖也被送到王宮中交給希該。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 39:21; 箴言 16:7; 以斯帖記 2:12"> 希該喜歡以斯帖，就恩待她，急忙給她需用的美容用品和膳食，又從王宮為她挑選七名宮女，讓她和她的宮女搬進女宮上好的房屋。</span>
<span className="v" id="v10" data-v="10" data-xref="以斯帖記 2:20; 馬太福音 10:16; 以斯帖記 3:8"> 以斯帖沒有向人透露過自己的種族和身世，因為末底改吩咐她不要透露。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 37:14; 撒母耳記上 17:18; 使徒行傳 15:36"> 末底改天天在女宮的庭院前徘徊，好打聽以斯帖的消息，瞭解她的情況。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="帖撒羅尼迦前書 4:4–5; 箴言 7:17; 以賽亞書 57:9"> 每個女子依次晉見亞哈隨魯王之前，都要照規矩潔淨十二個月：六個月用沒藥油，六個月用香料和潔身用品。</span>
<span className="v" id="v13" data-v="13"> 每個女子從女宮到王宮晉見王時，她所要求的一切都要給她。</span>
<span className="v" id="v14" data-v="14" data-xref="以斯帖記 4:11; 創世記 34:19; 以賽亞書 62:4–5"> 她晚上進去，次日被帶到另一個女宮，交給管理妃嬪的太監沙甲。除非王喜歡她，提名召見她，否則她不會再見到王。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="雅歌 6:9; 以斯帖記 2:3; 以斯帖記 9:29"> 以斯帖是末底改的叔叔亞比孩的女兒，後來被末底改收養。輪到她晉見王時，除了管理女子的太監希該給她的東西外，她沒有別的要求。凡看見她的人都喜歡她。</span>
<span className="v" id="v16" data-v="16" data-xref="以斯帖記 8:9; 以斯帖記 2:3; 以斯帖記 2:1"> 亞哈隨魯王執政第七年十月，即提別月，以斯帖被帶進宮中見王。</span>
<span className="v" id="v17" data-v="17" data-xref="詩篇 113:7–8; 路加福音 1:48–52; 以西結書 17:24"> 王愛以斯帖勝過愛其他所有女子，她比其他處女更得王的恩寵。於是，王把后冠戴在她頭上，立她為王后，代替瓦實提。</span>
<span className="v" id="v18" data-v="18" data-xref="雅歌 3:11; 路加福音 14:8; 士師記 14:10–17"> 王為以斯帖大擺宴席招待文武百官，又宣佈各省休假<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「休假」或譯「免去賦稅」。">a</a></sup>，並厚賜禮物。</span>
</div>
</div>

## 末底改救王的性命

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="以斯帖記 2:21; 以斯帖記 2:3–4; 以斯帖記 5:13"> 第二次召集處女時，末底改已坐在宮門供職。</span>
<span className="v" id="v20" data-v="20" data-xref="以弗所書 6:1–3; 以斯帖記 2:10; 以斯帖記 2:7"> 以斯帖依照末底改的吩咐，沒有向人透露自己的身世和籍貫，因為她像幼年時一樣聽從末底改的話。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="以斯帖記 6:2; 列王紀上 16:9; 列王紀下 21:23"> 一天，末底改正在宮門供職，兩個守門的太監辟探和提列惱恨亞哈隨魯王，想要下手害他。</span>
<span className="v" id="v22" data-v="22" data-xref="以斯帖記 6:1–2; 羅馬書 11:33; 傳道書 10:20"> 末底改知道後，便通知以斯帖王后，以斯帖就以末底改的名義稟告王。</span>
<span className="v" id="v23" data-v="23" data-xref="創世記 40:22; 創世記 40:19; 以斯帖記 10:2"> 王查明確有此事後，便命人把二人吊死在木架上，並將這事當著他的面寫入史書。</span>
</div>
</div>

## 猶太人的反擊

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以斯帖記 3:13; 以斯帖記 8:12; 詩篇 30:11"> 十二月，即亞達月十三日，是執行王諭旨的日子。那天，猶太人的仇敵原本想轄制他們，卻反而被他們轄制。</span>
<span className="v" id="v2" data-v="2" data-xref="以斯帖記 8:17; 以斯帖記 8:11; 詩篇 71:13"> 猶太人在亞哈隨魯王的各省各城聚集起來，攻擊那些要害他們的人，無人能抵擋他們，因為各族都懼怕他們。</span>
<span className="v" id="v3" data-v="3" data-xref="以斯拉記 8:36; 以斯帖記 8:5; 但以理書 6:1–2"> 各省的官員、總督、省長和為王辦事的人因懼怕末底改，就都幫助猶太人。</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳記下 3:1; 歷代志上 11:9; 撒母耳記上 2:30"> 因為末底改已是王宮要員，他的名聲傳遍各省，權勢日盛。</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 18:34–40; 詩篇 20:7–8; 詩篇 149:6–9"> 猶太人用刀擊殺所有敵人，任意消滅恨他們的人。</span>
<span className="v" id="v6" data-v="6" data-xref="以斯帖記 3:15"> 猶太人單在書珊城就殺了五百人。</span>
<span className="v" id="v7" data-v="7"> 他們還殺了巴珊大他、達分、亞斯帕他、</span>
<span className="v" id="v8" data-v="8"> 坡拉他、亞大利雅、亞利大他、</span>
<span className="v" id="v9" data-v="9"> 帕瑪斯他、亞利賽、亞利代和瓦耶撒他。</span>
<span className="v" id="v10" data-v="10" data-xref="以斯帖記 5:11; 以斯帖記 8:11; 創世記 14:23"> 這十人是猶太人的仇敵哈曼的兒子、哈米大他的孫子。但猶太人沒有動他們的財物。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11"> 當天，王獲悉在書珊城被殺的人數，</span>
<span className="v" id="v12" data-v="12" data-xref="以斯帖記 7:2; 以斯帖記 5:6"> 便對以斯帖王后說：「猶太人在書珊城殺了五百人，還殺了哈曼的十個兒子，在其餘各省就更不知怎樣了！現在你要什麼？必賜給你。你還有何要求？必為你成全。」</span>
<span className="v" id="v13" data-v="13" data-xref="以斯帖記 8:11; 申命記 21:23; 以斯帖記 9:15"> 以斯帖回答說：「王若願意，就請恩准書珊城的猶太人明天仍執行今天的諭旨，並把哈曼十個兒子的屍體吊在木架上。」</span>
<span className="v" id="v14" data-v="14"> 王允准了，便在書珊城頒佈諭旨，哈曼十個兒子的屍體便被吊了起來。</span>
<span className="v" id="v15" data-v="15" data-xref="以斯帖記 8:11; 以斯帖記 9:10; 以斯帖記 9:16"> 亞達月十四日，書珊城的猶太人再次聚集起來，在城中殺了三百人，但沒有動他們的財物。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="以斯帖記 8:11; 以斯帖記 9:2; 利未記 26:7–8"> 王其他各省的猶太人也都聚集起來自衛，得以脫離仇敵。他們殺了七萬五千個仇敵，但沒有動他們的財物。</span>
<span className="v" id="v17" data-v="17" data-xref="以斯帖記 9:21; 以斯帖記 9:1; 以斯帖記 8:9"> 這事發生在亞達月十三日。十四日，猶太人休息，並以此日為設宴歡慶的日子。</span>
<span className="v" id="v18" data-v="18" data-xref="以斯帖記 9:21; 以斯帖記 9:1; 以斯帖記 9:15"> 但書珊城的猶太人在十三、十四日聚集殺敵，十五日才休息，並以此日為設宴歡慶的日子。</span>
<span className="v" id="v19" data-v="19" data-xref="以斯帖記 8:17; 啟示錄 11:10; 尼希米記 8:10–12"> 因此，住在鄉村的猶太人都以亞達月十四日為設宴歡慶的節日，並互贈禮物。</span>
</div>
</div>

## 普珥節

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="申命記 31:19–22; 哥林多後書 1:10–11; 詩篇 145:4–12"> 末底改把這些事記錄下來，寫信給亞哈隨魯王國內遠近各省的猶太人，</span>
<span className="v" id="v21" data-v="21"> 吩咐他們每年在亞達月十四、十五日守節期，</span>
<span className="v" id="v22" data-v="22" data-xref="詩篇 30:11; 以賽亞書 14:3; 以斯帖記 9:19"> 設宴歡慶，互贈禮物，賙濟窮人，以記念猶太人在此月此日得以脫離仇敵，化憂為樂，轉悲為喜。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23"> 猶太人接受了末底改寫給他們的信，同意每年慶祝這個節日。</span>
<span className="v" id="v24" data-v="24" data-xref="以斯帖記 3:5–13; 以斯帖記 9:10"> 因為猶太人的仇敵亞甲人哈米大他的兒子哈曼曾經陰謀毀滅猶太人，曾經抽普珥，即抽籤，要殺戮、滅絕他們。</span>
<span className="v" id="v25" data-v="25" data-xref="詩篇 7:16; 詩篇 140:9; 詩篇 141:10"> 但王知道這陰謀後，便降旨使哈曼謀害猶太人的惡計落到他自己頭上，將他及其眾子吊在木架上。</span>
<span className="v" id="v26" data-v="26" data-xref="以斯帖記 9:20; 民數記 16:40; 以西結書 39:11"> 他們借用普珥這個詞，稱這兩天為普珥節。猶太人因這信上的一切話，又因所看見、所經歷的事，</span>
<span className="v" id="v27" data-v="27" data-xref="撒迦利亞書 2:11; 以賽亞書 56:6; 以斯帖記 8:17"> 就為自己、自己的後代和歸屬他們的人定下規矩：每年必按時守這兩天為節日，永不廢棄。</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及記 13:8–9; 約書亞記 4:7; 詩篇 103:2"> 各省各城、家家戶戶、世世代代都要記念、遵守這節日，使猶太人永不中斷過普珥節，他們的後代也不可忘記。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="以斯帖記 9:20; 以斯帖記 2:15; 以斯帖記 8:10"> 亞比孩的女兒以斯帖王后和猶太人末底改以全權寫第二封信，囑咐猶太人守這普珥節，</span>
<span className="v" id="v30" data-v="30" data-xref="以斯帖記 1:1; 以斯帖記 8:9; 撒迦利亞書 8:19"> 用和善、真誠的話寫信給亞哈隨魯王國一百二十七省的所有猶太人，</span>
<span className="v" id="v31" data-v="31" data-xref="以斯帖記 4:3; 以斯帖記 4:16; 約拿書 3:2–9"> 囑咐他們照猶太人末底改和以斯帖王后的指示，按他們為自己和後代所規定的，按時守普珥節，禁食哀哭。</span>
<span className="v" id="v32" data-v="32" data-xref="以斯帖記 9:26"> 以斯帖的命令確定了普珥節，這命令被記載下來。</span>
</div>
</div>

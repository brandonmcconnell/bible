## 務要傳道

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行傳 10:42; 提摩太後書 4:8; 提摩太前書 5:21"> 在上帝和審判活人死人的基督耶穌面前，我憑基督的顯現和祂的國鄭重囑咐你：</span>
<span className="v" id="v2" data-v="2" data-xref="帖撒羅尼迦前書 5:14; 提摩太前書 4:15–16; 提多書 2:15"> 務要傳道，無論時機好壞，都要準備好，以百般的忍耐和教導督責人、警戒人、勉勵人。</span>
<span className="v" id="v3" data-v="3" data-xref="彼得後書 2:1–3; 提摩太後書 3:1–6; 提摩太前書 4:1–3"> 因為有一天，人們會厭倦純正的教導，耳朵發癢，尋找許多迎合他們私慾的老師。</span>
<span className="v" id="v4" data-v="4" data-xref="撒迦利亞書 7:11; 提摩太前書 1:4; 使徒行傳 7:57"> 他們掩耳不聽真理，反而偏向無稽之談。</span>
<span className="v" id="v5" data-v="5" data-xref="提摩太後書 1:8; 彼得前書 1:13; 提摩太後書 2:3"> 然而，你要謹慎行事，不怕吃苦，專心傳道，盡忠職守。</span>
<span className="v" id="v6" data-v="6" data-xref="腓立比書 1:23; 腓立比書 2:17; 彼得後書 1:14–15"> 我的生命如同奉獻在祭壇上的酒正傾倒出來，我離世的日子快要到了。</span>
<span className="v" id="v7" data-v="7" data-xref="提摩太前書 6:12; 哥林多前書 9:24–27; 希伯來書 12:1–2"> 那美好的仗，我打過了；當跑的路，我跑完了；所信的道，我守住了。</span>
<span className="v" id="v8" data-v="8" data-xref="雅各書 1:12; 啟示錄 2:10; 彼得前書 5:4"> 從此，有公義的冠冕為我預備，按公義審判的主會在祂來的那一天把它賜給我，不但會賜給我，也會賜給所有愛慕祂顯現的人。</span>
</div>
</div>

## 最後的囑咐

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="提摩太後書 1:4; 提摩太後書 4:21"> 請你儘快到我這裡來，</span>
<span className="v" id="v10" data-v="10" data-xref="約翰一書 2:15–16; 提摩太後書 1:15; 歌羅西書 4:14–15"> 因為底馬貪愛世界，離棄我跑到帖撒羅尼迦去了。革勒士去了加拉太，提多去了撻馬太，</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行傳 12:12; 腓利門書 1:24; 使徒行傳 12:25"> 只剩下路加一人在我身邊。你要把馬可一起帶來，因為他在傳道的工作上對我很有幫助。</span>
<span className="v" id="v12" data-v="12" data-xref="以弗所書 6:21; 使徒行傳 20:4; 提多書 3:12"> 至於推基古，我派他到以弗所去了。</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多前書 4:11; 哥林多後書 11:27; 使徒行傳 16:11"> 你來的時候，要把我在特羅亞時留給加布的外衣帶來，也要帶來那些書卷，特別是那些羊皮卷。</span>
<span className="v" id="v14" data-v="14" data-xref="提摩太前書 1:20; 帖撒羅尼迦後書 1:6; 詩篇 28:4"> 銅匠亞歷山大做了許多惡事害我，主必按他的所作所為報應他。</span>
<span className="v" id="v15" data-v="15" data-xref="提摩太後書 3:8; 腓立比書 3:2; 馬太福音 10:16–17"> 你也要提防他，因為他極力反對我們所傳的道。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行傳 7:60; 約翰福音 16:32; 馬可福音 14:50"> 我第一次在法庭申辯的時候，沒有人幫助我，眾人都離棄了我，但願他們不會因此而獲罪。</span>
<span className="v" id="v17" data-v="17" data-xref="彼得前書 5:8; 腓立比書 1:12–14; 撒母耳記上 17:37"> 然而主站在我身旁加給我力量，使我可以把福音完整地傳給所有的外族人。主把我從獅子口裡救了出來。</span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 121:7; 帖撒羅尼迦後書 3:3; 猶大書 1:24–25"> 主必救我脫離一切邪惡的攻擊，帶我進入祂的天國。願榮耀歸給主，直到永永遠遠。阿們！</span>
</div>
</div>

## 問候

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="使徒行傳 18:2; 哥林多前書 16:19; 羅馬書 16:3–4"> 請代我問候百基拉和亞居拉，以及阿尼色弗一家。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行傳 20:4; 使徒行傳 19:22; 腓立比書 2:26–27"> 以拉都留在了哥林多，我把生病的特羅非摩留在了米利都。</span>
<span className="v" id="v21" data-v="21" data-xref="提摩太後書 4:9; 腓立比書 4:22; 約翰三書 1:14"> 你要儘快在冬天之前趕到這裡來。友布羅、布田、利奴、革勞底亞和眾弟兄姊妹都問候你。</span>
<span className="v" id="v22" data-v="22" data-xref="腓利門書 1:25; 加拉太書 6:18; 歌羅西書 4:18"> 願主與你的靈同在！願恩典與你們同在！</span>
</div>

## 基督的精兵

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="哥林多後書 12:9–10; 以弗所書 6:10; 提摩太後書 1:7"> 我兒啊！你要靠著基督耶穌的恩典剛強起來。</span>
<span className="v" id="v2" data-v="2" data-xref="提摩太後書 1:13–14; 提摩太前書 4:6; 提摩太前書 6:12"> 以前你在許多見證人面前聽過我的教導，你要把這些教導傳給忠信可靠、能教導他人的人。</span>
<span className="v" id="v3" data-v="3" data-xref="希伯來書 12:2–3; 雅各書 1:12; 提摩太後書 4:5"> 你要作基督耶穌的精兵，與我同受苦難。</span>
<span className="v" id="v4" data-v="4" data-xref="帖撒羅尼迦前書 2:4; 路加福音 8:14; 彼得後書 2:20"> 當兵的若讓其他事務纏身，就不能取悅徵召他的上司。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多前書 9:24–27; 啟示錄 3:11; 提摩太後書 4:7–8"> 同樣，參加比賽的人若不遵守比賽規則，就不可能得獎。</span>
<span className="v" id="v6" data-v="6" data-xref="希伯來書 10:36; 哥林多前書 9:7–11; 哥林多前書 3:6–9"> 辛勞的農夫理當先享受收成。</span>
<span className="v" id="v7" data-v="7" data-xref="雅各書 1:5; 約翰一書 5:20; 路加福音 24:45"> 你要思想我說的話，因為主必使你領悟這一切。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行傳 2:24; 羅馬書 2:16; 哥林多前書 15:11–20"> 你要切記我所傳的福音：耶穌基督是大衛的後裔，祂從死裡復活了。</span>
<span className="v" id="v9" data-v="9" data-xref="腓立比書 1:7; 使徒行傳 28:31; 提摩太後書 1:8"> 我為這福音受苦，甚至像犯人一樣被囚禁，但上帝的道是囚禁不住的。</span>
<span className="v" id="v10" data-v="10" data-xref="彼得前書 5:10; 歌羅西書 1:24; 提摩太後書 2:3"> 我為了上帝的選民忍受一切痛苦，使他們可以獲得在基督耶穌裡的救恩和永遠的榮耀。</span>
<span className="v" id="v11" data-v="11" data-xref="羅馬書 6:8; 歌羅西書 3:3–4; 羅馬書 6:5"> 有真實可信的話說：<br /><span className="pl pl-1">「我們若與基督同死，</span><br /><span className="pl pl-1">就必與祂同活。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="羅馬書 8:17; 馬太福音 10:33; 啟示錄 20:4"> <span className="pl pl-1">我們若忍耐到底，</span><br /><span className="pl pl-1">就必與祂一同作王。</span><br /><span className="pl pl-1">我們若不承認祂，</span><br /><span className="pl pl-1">祂也必不承認我們。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="民數記 23:19; 羅馬書 3:3; 帖撒羅尼迦後書 3:3"> <span className="pl pl-1">我們縱然會失信，</span><br /><span className="pl pl-1">祂仍然信實可靠，</span><br /><span className="pl pl-1">因為祂不能否認自己。」</span></span>
</div>
</div>

## 做無愧的工人

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="提多書 3:9–11; 提摩太後書 2:23; 提摩太後書 4:1"> 你要提醒眾人這些事，在上帝面前囑咐他們：不要為言詞爭辯，因為那對聽見的人有害無益。</span>
<span className="v" id="v15" data-v="15" data-xref="帖撒羅尼迦前書 2:4; 彼得後書 1:10; 提摩太前書 4:6"> 你應當竭力在上帝面前做經得起考驗、問心無愧的工人，正確講解真理之道。</span>
<span className="v" id="v16" data-v="16" data-xref="提多書 3:9; 提摩太前書 6:20; 提摩太後書 2:14"> 要遠避一切世俗的空談，因為好空談的人只會越來越不敬虔。</span>
<span className="v" id="v17" data-v="17" data-xref="提摩太前書 1:20; 那鴻書 3:15; 雅各書 5:3"> 他們講的話像毒瘡越爛越大，許米乃和腓理徒就是例子。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前書 15:12; 提摩太前書 1:19; 希伯來書 3:10"> 他們離經背道，說復活的事已成過去，動搖了一些人的信心。</span>
<span className="v" id="v19" data-v="19" data-xref="約翰福音 10:14; 哥林多前書 8:3; 那鴻書 1:7"> 然而，上帝所立的堅實根基屹立不搖，這根基上刻著：「主認識那些屬於祂的人」<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="民數記16·5。">a</a></sup>，「凡承認主名的人都要離棄罪惡。」</span>
<span className="v" id="v20" data-v="20" data-xref="羅馬書 9:21–23; 彼得前書 2:5; 提摩太前書 3:15"> 大戶人家不但有金器銀器，也有木器瓦器，這些器皿的用途有貴賤之分。</span>
<span className="v" id="v21" data-v="21" data-xref="提摩太後書 3:17; 以弗所書 2:10; 哥林多後書 7:1"> 人若潔身自愛，遠離卑賤的事，就必成為聖潔無瑕的貴重器皿，可以被主用來成就各種善事。</span>
<span className="v" id="v22" data-v="22" data-xref="彼得前書 2:11; 彼得前書 3:11; 哥林多前書 6:18"> 你要逃避年輕人的邪情私慾，要跟那些以清潔的心求告主的人一同追求公義、信心、仁愛、和平。</span>
<span className="v" id="v23" data-v="23" data-xref="提摩太後書 2:14; 提多書 3:9; 提摩太前書 4:7"> 不要參與愚昧無知的辯論，因為你知道這些事只會引起紛爭。</span>
<span className="v" id="v24" data-v="24" data-xref="提多書 3:2; 雅各書 1:19–20; 提摩太前書 3:2–3"> 主的奴僕不可與人爭執，總要溫和待人，善於教導，心存忍耐。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行傳 11:18; 加拉太書 6:1; 提摩太前書 2:4"> 要溫柔地規勸那些反對的人，也許上帝會賜給他們悔改的心，使他們明白真理，</span>
<span className="v" id="v26" data-v="26" data-xref="提摩太前書 3:7; 以賽亞書 49:25–26; 詩篇 124:7"> 讓他們這些被魔鬼擄去、受其擺佈的人能夠醒悟過來，脫離魔鬼的網羅。</span>
</div>
</div>

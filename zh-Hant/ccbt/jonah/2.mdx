## 約拿的禱告

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="耶利米哀歌 3:53–56; 詩篇 130:1–2; 詩篇 91:15"> 約拿在魚腹中向他的上帝耶和華禱告說：</span>
<span className="v" id="v2" data-v="2" data-xref="詩篇 18:4–6; 詩篇 120:1; 詩篇 34:6"> <span className="pl pl-1">「耶和華啊，我遭遇患難的時候向你求告，</span><br /><span className="pl pl-1">你就應允我。</span><br /><span className="pl pl-1">我在陰間的深處呼求你，</span><br /><span className="pl pl-1">你也垂聽我的聲音。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 42:7; 耶利米哀歌 3:54; 詩篇 69:1–2"> <span className="pl pl-1">你把我拋進深海，</span><br /><span className="pl pl-1">拋進大洋的腹地，</span><br /><span className="pl pl-1">洋流圍困我，</span><br /><span className="pl pl-1">你的巨浪洪濤淹沒我。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="詩篇 31:22; 詩篇 5:7; 歷代志下 6:38"> <span className="pl pl-1">我心想，我從你面前被趕走，</span><br /><span className="pl pl-1">但我還要再瞻仰你的聖殿。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 69:1–2; 耶利米哀歌 3:54; 詩篇 40:2"> <span className="pl pl-1">波濤吞噬我，</span><br /><span className="pl pl-1">深海圍困我，</span><br /><span className="pl pl-1">海草纏繞著我的頭。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 30:3; 詩篇 16:10; 以賽亞書 38:17"> <span className="pl pl-1">我下沉到山的根基，</span><br /><span className="pl pl-1">大地的門閂把我永遠關住；</span><br /><span className="pl pl-1">然而，我的上帝耶和華啊，</span><br /><span className="pl pl-1">你卻把我的性命從深坑中拯救出來。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 18:6; 歷代志下 30:27; 詩篇 11:4"> <span className="pl pl-1">我的生命漸漸消逝的時候，</span><br /><span className="pl pl-1">我就想起了耶和華。</span><br /><span className="pl pl-1">我的禱告進入你的聖殿，</span><br /><span className="pl pl-1">達到你面前。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 31:6; 列王紀下 17:15; 耶利米書 2:13"> <span className="pl pl-1">那些信奉虛無神明的人，</span><br /><span className="pl pl-1">背棄了憐愛他們的上帝</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「背棄了憐愛他們的上帝」或譯「背棄了他們對上帝的忠誠」。">a</a></sup><br /><span className="pl pl-1">，</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 3:8; 詩篇 50:14; 傳道書 5:4–5"> <span className="pl pl-1">但我要用感謝的聲音向你獻祭，</span><br /><span className="pl pl-1">我必還我許的願，</span><br /><span className="pl pl-1">因為救恩來自耶和華。」</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="馬太福音 8:26–27; 詩篇 33:9; 創世記 1:3"> <span className="pl pl-1">於是，耶和華命令那條魚，</span><br /><span className="pl pl-1">魚就把約拿吐到陸地上。</span></span>

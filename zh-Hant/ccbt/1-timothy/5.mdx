## 信徒的責任

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="利未記 19:32; 彼得前書 5:5–6; 提多書 2:2"> 不要斥責年長的，要像對待父親一樣勸他們；對待青年男子要情同手足；</span>
<span className="v" id="v2" data-v="2" data-xref="提摩太前書 4:12; 馬太福音 12:50; 腓立比書 4:8"> 對待年長的婦女要情同母親；對待青年女子要心思純正，視她們如姊妹。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="申命記 27:19; 使徒行傳 6:1; 申命記 10:18"> 要敬重和幫助那些真正有需要的寡婦。</span>
<span className="v" id="v4" data-v="4" data-xref="以弗所書 6:1–3; 約翰福音 19:26–27; 馬太福音 15:4–6"> 寡婦如果有兒孫，就要叫她們的兒孫在家中學習盡孝道，奉養她們，以報答養育之恩，這是上帝所悅納的。</span>
<span className="v" id="v5" data-v="5" data-xref="提摩太前書 5:3; 路加福音 2:37; 哥林多前書 7:32"> 真正有需要、無依無靠的寡婦仰賴上帝的幫助，晝夜不住地禱告祈求。</span>
<span className="v" id="v6" data-v="6" data-xref="雅各書 5:5; 啟示錄 18:7; 路加福音 15:24"> 但貪圖享樂的寡婦雖然活著，卻已經死了。</span>
<span className="v" id="v7" data-v="7" data-xref="提摩太前書 4:11; 提多書 2:15; 提摩太後書 4:1"> 你當教導眾人這些事，好叫他們無可指責。</span>
<span className="v" id="v8" data-v="8" data-xref="加拉太書 6:10; 哥林多後書 12:14; 路加福音 11:11–13"> 誰不照顧自己的親屬，尤其是不照顧自己的家人，就是背棄信仰，比不信的人還壞。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="提摩太前書 3:2; 提摩太前書 5:11; 路加福音 2:36–37"> 列入名冊的寡婦必須年滿六十歲，在婚姻上從一而終，</span>
<span className="v" id="v10" data-v="10" data-xref="提摩太前書 6:18; 提多書 3:8; 使徒行傳 9:36"> 並且在善事上有好名聲，如教養兒女、接待外人、服侍聖徒<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="希臘語是「洗聖徒的腳」。">a</a></sup>、救助困苦、竭力做各種善事。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="提摩太前書 5:14; 何西阿書 13:6; 雅各書 5:5"> 不要把年輕的寡婦列入名冊，因為當她們情慾衝動、無法持守對基督的委身時，就想再嫁，</span>
<span className="v" id="v12" data-v="12" data-xref="加拉太書 1:6; 雅各書 3:1; 哥林多前書 11:34"> 以致違背了起初的誓言而受審判。</span>
<span className="v" id="v13" data-v="13" data-xref="箴言 20:19; 帖撒羅尼迦後書 3:6–11; 使徒行傳 20:30"> 況且，她們不僅懶散成性，四處串門，還說長道短，好管閒事，搬弄是非。</span>
<span className="v" id="v14" data-v="14" data-xref="提多書 2:5; 提摩太前書 6:1; 提多書 2:8"> 所以，我建議年輕的寡婦再嫁，生兒育女，料理家務，不要給仇敵毀謗的機會，</span>
<span className="v" id="v15" data-v="15" data-xref="彼得後書 2:2; 猶大書 1:4–5; 彼得後書 2:20–22"> 因為有些人已經偏離正道，去追隨撒旦了。</span>
<span className="v" id="v16" data-v="16" data-xref="提摩太前書 5:3–5; 提摩太前書 5:8"> 女信徒的家裡若有寡婦，就應該自己照顧她們，免得加重教會的負擔，這樣教會才能照顧那些真正無依無靠的寡婦。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="希伯來書 13:17; 帖撒羅尼迦前書 5:12–13; 加拉太書 6:6"> 那些善於管理教會的長老，尤其是那些辛勤傳道和教導人的，理當得到加倍的敬養。</span>
<span className="v" id="v18" data-v="18" data-xref="申命記 25:4; 哥林多前書 9:14; 哥林多前書 9:7–10"> 因為聖經上說：「牛在踩穀時，不可籠住牠的嘴。」<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="申命記25·4。">b</a></sup>又說：「工人理應得到工錢。」<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="路加福音10·7。">c</a></sup></span>
<span className="v" id="v19" data-v="19" data-xref="馬太福音 18:16; 申命記 19:15; 哥林多後書 13:1"> 若有人向你控告長老，必須有兩三個證人，否則不要受理。</span>
<span className="v" id="v20" data-v="20" data-xref="提摩太後書 4:2; 提多書 1:13; 提摩太前書 1:20"> 那些一直犯罪的人，你要當眾責備他們，以警戒眾人。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="彼得後書 2:4; 提摩太後書 4:1; 提摩太前書 6:13"> 我在上帝和基督耶穌及蒙揀選的眾天使面前吩咐你：要遵行這些話，不要有成見，不要偏心。</span>
<span className="v" id="v22" data-v="22" data-xref="以弗所書 5:11; 提摩太前書 3:10; 提摩太前書 3:6"> 為人行按手禮，不要操之過急。不要沾染別人的罪，要潔身自好。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="詩篇 104:15; 箴言 31:4–7; 提摩太前書 4:4"> 你的胃不好，經常生病，不要只喝水，要稍微喝一點酒。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="提摩太後書 4:10; 使徒行傳 8:18; 加拉太書 5:19–21"> 有些人的罪很明顯，自招審判，有些人的罪日後才暴露出來。</span>
<span className="v" id="v25" data-v="25" data-xref="箴言 10:9; 路加福音 11:33; 詩篇 37:5–6"> 同樣，有些善行很明顯，不明顯的也不會被長久埋沒。</span>
</div>
</div>

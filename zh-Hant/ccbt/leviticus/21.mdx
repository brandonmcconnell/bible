## 祭司保持聖潔的條例

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西結書 44:25; 利未記 21:11; 利未記 10:6–7"> 耶和華對摩西說：「你要告訴做祭司的亞倫子孫：祭司不可因接觸死去的族人而使自己不潔淨，</span>
<span className="v" id="v2" data-v="2" data-xref="帖撒羅尼迦前書 4:13; 利未記 18:6"> 但骨肉至親，如父母、兒女、兄弟，</span>
<span className="v" id="v3" data-v="3"> 以及未出嫁仍是處女的姊妹例外。</span>
<span className="v" id="v4" data-v="4" data-xref="以西結書 24:16–17"> 祭司不可因姻親的關係而玷污自己。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或譯「作為民中的首領，祭司不可玷污自己。」">a</a></sup></span>
<span className="v" id="v5" data-v="5" data-xref="申命記 14:1; 以西結書 44:20; 利未記 19:27–28"> 祭司不可剃光頭、修剪鬍鬚或割傷身體。</span>
<span className="v" id="v6" data-v="6" data-xref="利未記 3:11; 利未記 18:21; 彼得前書 2:9"> 他們要做上帝的聖潔之民，不可褻瀆我的名。因為他們負責獻我的火祭，即我的食物，所以要保持聖潔。</span>
<span className="v" id="v7" data-v="7" data-xref="利未記 21:13–14; 以西結書 44:22; 利未記 21:8"> 他們不可娶妓女或被休的女人為妻，因為祭司要向上帝保持聖潔。</span>
<span className="v" id="v8" data-v="8" data-xref="利未記 20:7–8; 利未記 19:2; 利未記 11:44–45"> 要視祭司為聖潔的，因為他們負責獻你們上帝的食物。要視他們為聖潔的，因為使你們聖潔的我耶和華是聖潔的。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 38:24; 利未記 19:29; 以西結書 9:6"> 如果有祭司的女兒做妓女，辱沒自己，她就是辱沒自己的父親，必須燒死她。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="利未記 10:6–7; 利未記 16:32; 馬太福音 26:65"> 「大祭司在眾祭司中職分最高，頭上澆過膏油，已經承受聖職、穿上聖衣，他不可披頭散髮、撕裂衣服。</span>
<span className="v" id="v11" data-v="11" data-xref="民數記 19:14; 利未記 21:1–2; 民數記 6:7"> 他不可接近死者，即使是父母也不可，以免玷污自己。</span>
<span className="v" id="v12" data-v="12" data-xref="利未記 10:7; 出埃及記 29:6–7; 利未記 8:9–12"> 他不可走出他上帝的聖所，以免褻瀆聖所，因為我的膏油已經使他聖潔。我是耶和華。</span>
<span className="v" id="v13" data-v="13" data-xref="利未記 21:7; 哥林多後書 11:2; 啟示錄 14:4"> 他必須娶處女為妻，</span>
<span className="v" id="v14" data-v="14" data-xref="利未記 21:7; 以西結書 44:22"> 不可娶寡婦、被休的女人或被玷污的妓女，只可娶本族中的處女為妻，</span>
<span className="v" id="v15" data-v="15" data-xref="羅馬書 11:16; 哥林多前書 7:14; 尼希米記 13:23–29"> 以免在民中玷污自己的子孫，因為我是使他們聖潔的耶和華。」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16"> 耶和華對摩西說：</span>
<span className="v" id="v17" data-v="17" data-xref="詩篇 65:4; 民數記 16:5; 利未記 10:3"> 「你告訴亞倫：你世世代代的子孫中，任何有殘疾的人都不可前來向他的上帝獻食物。</span>
<span className="v" id="v18" data-v="18" data-xref="提摩太前書 3:2–3; 利未記 22:19–25; 提多書 1:7"> 任何殘疾的人，如瞎眼的、瘸腿的、五官不正的、畸形的、</span>
<span className="v" id="v19" data-v="19"> 四肢傷殘的、</span>
<span className="v" id="v20" data-v="20" data-xref="申命記 23:1; 以賽亞書 56:3"> 駝背的、侏儒、患眼疾的、長疥癬的或睪丸受損的，都不可近前來獻祭。</span>
<span className="v" id="v21" data-v="21" data-xref="利未記 21:6; 利未記 21:8; 利未記 21:17"> 亞倫祭司的子孫中有殘疾的都不可向耶和華獻火祭。他們既然有殘疾，就不可近前來獻耶和華的食物。</span>
<span className="v" id="v22" data-v="22" data-xref="利未記 2:3; 民數記 18:19; 利未記 24:8–9"> 他們可以吃上帝的食物，聖的和至聖的都可以吃。</span>
<span className="v" id="v23" data-v="23" data-xref="利未記 21:12; 以西結書 44:9–14; 出埃及記 30:6–8"> 但他們不可走近幔子或祭壇，因為他們有殘疾。這樣做是為了避免他們褻瀆我的聖所。我是使聖所聖潔的耶和華。」</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="提摩太前書 1:18; 瑪拉基書 2:1–7; 提摩太後書 2:2"> 摩西把這些條例告訴了亞倫父子們和所有的以色列人。</span>
</div>
</div>

## 有關痲瘋病的條例

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華對摩西和亞倫說：</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="申命記 24:8; 利未記 14:56; 利未記 14:3"> 「如果有人皮膚上長腫包、皮疹或白斑，出現痲瘋病<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「痲瘋病」此處為傳統譯法，希伯來文的意思指包括痲瘋病在內的各種嚴重皮膚病。">a</a></sup>症狀，要將他帶到祭司亞倫或亞倫做祭司的子孫那裡。</span>
<span className="v" id="v3" data-v="3" data-xref="羅馬書 3:19–20; 使徒行傳 20:28; 瑪拉基書 2:7"> 祭司要檢查患處，如果病灶深入皮下，患處的毛髮變白，就是痲瘋病。祭司檢查後，要宣佈他是不潔淨的。</span>
<span className="v" id="v4" data-v="4" data-xref="民數記 12:15; 哥林多前書 4:5; 提摩太前書 5:24"> 如果那人的患處有白斑，但病灶沒有深入皮下，患處的毛髮也沒有變白，祭司要把他隔離七天。</span>
<span className="v" id="v5" data-v="5"> 第七天，祭司要再次檢查患處，如果病灶沒有惡化，沒有在皮膚上擴散，祭司要把他再隔離七天。</span>
<span className="v" id="v6" data-v="6" data-xref="利未記 11:25; 利未記 14:8; 申命記 32:5"> 第七天，祭司要再次檢查，如果患處顏色變淡，也沒有擴散，祭司要宣佈他是潔淨的。他患的不過是皮疹，他要洗淨衣物，便會潔淨。</span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 38:3; 利未記 13:35–36; 提摩太後書 2:16–17"> 如果祭司已查看並宣佈他是潔淨的，但皮疹又擴散，他必須再去見祭司。</span>
<span className="v" id="v8" data-v="8" data-xref="馬太福音 15:7–8; 腓立比書 3:18–19; 使徒行傳 8:21"> 祭司檢查時，如果發現皮疹已擴散，就要宣佈他是不潔淨的，患了痲瘋病。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9"> 「如果有人患痲瘋病，必須將他帶到祭司面前。</span>
<span className="v" id="v10" data-v="10" data-xref="列王紀下 5:27; 歷代志下 26:19–20; 利未記 13:14–15"> 祭司檢查時，如果發現他皮膚上有白色腫包，毛髮變白，患處長出新肉，</span>
<span className="v" id="v11" data-v="11"> 他就是患了慢性痲瘋病，祭司要宣佈他是不潔淨的。他無須被隔離，因他已經不潔淨。</span>
<span className="v" id="v12" data-v="12" data-xref="約翰一書 1:8–10; 約伯記 42:6; 羅馬書 7:14"> 如果他的痲瘋病已擴散，頭上腳上到處可見，</span>
<span className="v" id="v13" data-v="13" data-xref="約翰福音 9:41; 以賽亞書 64:6"> 祭司就要檢查。如果發現痲瘋病已擴散到他全身，全身的皮膚變白，祭司就要宣佈他是潔淨的。</span>
<span className="v" id="v14" data-v="14"> 一旦他身上出現新長的肉，他便不潔淨。</span>
<span className="v" id="v15" data-v="15"> 祭司看到他身上新長的肉，就要宣佈他是不潔淨的，因為新長的肉是不潔淨的，表明他患了痲瘋病。</span>
<span className="v" id="v16" data-v="16" data-xref="加拉太書 1:14–16; 羅馬書 7:14–24; 腓立比書 3:6–8"> 如果新長的肉變白了，他就要去見祭司。</span>
<span className="v" id="v17" data-v="17"> 祭司檢查時，若發現患處確已變白，就要宣佈他是潔淨的，他便潔淨了。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="出埃及記 9:9; 以賽亞書 38:21; 詩篇 38:3–7"> 「如果有人皮膚上長瘡，又痊癒了，</span>
<span className="v" id="v19" data-v="19" data-xref="利未記 13:24"> 但原患處出現白色腫包或白裡帶紅的斑，他就要去讓祭司檢查。</span>
<span className="v" id="v20" data-v="20" data-xref="約翰福音 5:14; 利未記 13:3; 彼得後書 2:20"> 祭司檢查時，若發現病灶深入皮下，患處的毛髮變白，就要宣佈他是不潔淨的。這是瘡變成了痲瘋病。</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多前書 5:5"> 但祭司檢查時，若發現患處沒有白毛，病灶也沒有深入皮下，且顏色變淡，就要把他隔離七天。</span>
<span className="v" id="v22" data-v="22"> 隔離期間，若病灶在皮膚上擴散，祭司要宣佈他是不潔淨的，是患了痲瘋病。</span>
<span className="v" id="v23" data-v="23" data-xref="加拉太書 6:1; 約伯記 34:31–32; 馬太福音 26:75"> 如果患處的斑保持原樣，沒有擴散，便是瘡疤，祭司要宣佈他是潔淨的。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="以賽亞書 3:24"> 「如果有人被火燒傷，傷處變白或白中帶紅，</span>
<span className="v" id="v25" data-v="25" data-xref="利未記 13:18–20; 利未記 13:4"> 祭司要檢查他的傷處。如果傷處毛髮變白，且深入皮下，就是燒傷已變成痲瘋病，祭司要宣佈他是不潔淨的，因為他患了痲瘋病。</span>
<span className="v" id="v26" data-v="26" data-xref="利未記 13:23; 利未記 13:4–5"> 祭司檢查時，若發現傷處沒有白毛，也沒有深入皮下，且顏色變淡，就要把他隔離七天。</span>
<span className="v" id="v27" data-v="27"> 第七天，祭司要再次檢查，若發現傷處擴散，就要宣佈他是不潔淨的，因為他患了痲瘋病。</span>
<span className="v" id="v28" data-v="28"> 如果傷處保持原樣，沒有擴散，且顏色變淡，就是燒傷引起的腫包，祭司要宣佈他是潔淨的，因為那不過是燒傷的疤痕。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="以賽亞書 9:15; 馬太福音 13:14–15; 哥林多後書 4:3–4"> 「如果有男女頭上或下巴長瘡，</span>
<span className="v" id="v30" data-v="30" data-xref="利未記 13:34–37; 利未記 14:54"> 祭司要檢查患處，若發現患處病灶深入皮下，上面有黃色細毛，就要宣佈那人是不潔淨的，因為那是疥癬，是痲瘋病。</span>
<span className="v" id="v31" data-v="31"> 祭司檢查時，若發現病灶沒有深入皮下，也沒有黑毛，就要將那人隔離七天。</span>
<span className="v" id="v32" data-v="32" data-xref="利未記 13:30; 馬太福音 23:5; 路加福音 18:9–12"> 第七天，祭司要檢查患處，若發現疥癬沒有擴散，上面沒有黃毛，也沒有深入皮下，</span>
<span className="v" id="v33" data-v="33"> 那人要剃去頭髮和鬍鬚，但不可剃患處的毛髮。祭司要將他再隔離七天。</span>
<span className="v" id="v34" data-v="34" data-xref="猶大書 1:22; 約翰一書 4:1; 啟示錄 2:2"> 第七天，祭司要再次檢查，若發現疥癬沒有在皮膚上擴散，也沒有深入皮下，就要宣佈那人是潔淨的。那人要洗淨衣服，便潔淨了。</span>
<span className="v" id="v35" data-v="35" data-xref="利未記 13:27; 提摩太後書 2:16–17; 利未記 13:7"> 那人潔淨以後，疥癬若再次擴散，</span>
<span className="v" id="v36" data-v="36"> 祭司就要再次檢查。如果疥癬確已擴散，祭司不必再找黃毛，那人是不潔淨的。</span>
<span className="v" id="v37" data-v="37"> 如果祭司看到疥癬原樣未變，患處長出黑毛，那人就已經痊癒，是潔淨的。祭司要宣佈那人是潔淨的。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38"> 「如果有男女身上長白斑，</span>
<span className="v" id="v39" data-v="39" data-xref="羅馬書 7:22–25; 雅各書 3:2; 傳道書 7:20"> 祭司要檢查患處，若發現斑呈灰白色，就是皮疹，那人是潔淨的。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="加拉太書 4:13; 羅馬書 8:10; 雅歌 5:11"> 「如果有人脫髮，成了禿頭，他是潔淨的。</span>
<span className="v" id="v41" data-v="41"> 如果有人前額脫髮，他只是前額光禿，仍是潔淨的。</span>
<span className="v" id="v42" data-v="42"> 如果在光禿的頭上或前額上長出白裡帶紅的瘡，那就是痲瘋病。</span>
<span className="v" id="v43" data-v="43"> 祭司要檢查患處，若發現瘡周圍腫脹、白中帶紅，看起來像痲瘋病，</span>
<span className="v" id="v44" data-v="44" data-xref="彼得後書 2:1–2; 馬太福音 6:23; 以賽亞書 1:5"> 就是得了痲瘋病，那人是不潔淨的。祭司要因那人頭上的瘡而宣佈他是不潔淨的。</span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="彌迦書 3:7; 利未記 10:6; 以西結書 24:17"> 「患痲瘋病的人必須撕裂衣服，披頭散髮，遮住臉的下半部，高喊『不潔淨！不潔淨！』</span>
<span className="v" id="v46" data-v="46" data-xref="列王紀下 7:3; 列王紀下 15:5; 歷代志下 26:21"> 只要病不痊癒，他就不潔淨，要獨自住在營外。</span>
</div>
</div>

## 黴變衣物的條例

<div className="bt">
<div className="bp">
<span className="v" id="v47" data-v="47" data-xref="猶大書 1:23; 羅馬書 13:12; 以西結書 16:16"> 「如果衣物出現黴斑，不論是羊毛衣、細麻衣、</span>
<span className="v" id="v48" data-v="48" data-xref="利未記 13:51; 啟示錄 3:4; 申命記 8:11"> 羊毛織品、細麻織品，還是皮革或皮革製品，</span>
<span className="v" id="v49" data-v="49"> 只要發現黴斑是綠色或紅色的，那就是黴變，要拿給祭司檢查。</span>
<span className="v" id="v50" data-v="50" data-xref="以西結書 44:23"> 祭司檢查後，要把那衣物隔離七天。</span>
<span className="v" id="v51" data-v="51" data-xref="利未記 14:44"> 第七天，祭司要再次檢查，若發現衣物、編織品或皮革上的黴斑蔓延，就是惡性黴變，那衣物就不潔淨。</span>
<span className="v" id="v52" data-v="52" data-xref="利未記 11:35; 利未記 11:33; 利未記 14:44–45"> 不論那是衣服、羊毛或細麻織品，還是皮革製品，祭司都必須把它燒掉，因為那是惡性黴變，必須燒掉黴變的衣物。</span>
<span className="v" id="v53" data-v="53"> 如果祭司發現衣服、編織品或皮革上的黴斑沒有蔓延，</span>
<span className="v" id="v54" data-v="54"> 就要吩咐人洗淨衣物，再隔離七天。</span>
<span className="v" id="v55" data-v="55" data-xref="以西結書 24:13; 希伯來書 6:4–8; 彼得後書 2:20–22"> 之後，祭司要再次檢查洗過的衣物，若發現黴斑原樣未變，即使沒有蔓延，那衣物也是不潔淨的。無論衣物裡面還是外面黴變，都必須把它燒掉。</span>
<span className="v" id="v56" data-v="56"> 如果祭司發現洗過後黴斑退色，就要把黴變的部分從衣服、皮革、編織品上撕下來。</span>
<span className="v" id="v57" data-v="57" data-xref="馬太福音 22:7; 啟示錄 21:8; 馬太福音 3:12"> 以後衣物、編織品或皮革上若再次出現黴斑，便是舊患復發，要把它燒掉。</span>
<span className="v" id="v58" data-v="58" data-xref="列王紀下 5:14; 啟示錄 1:5; 詩篇 51:2"> 如果洗過衣服、編織品或皮革後，黴斑消失了，要再洗一次就潔淨了。</span>
</div>
<div className="bp">
<span className="v" id="v59" data-v="59"> 「羊毛衣、細麻衣、編織品或皮革製品出現黴變時，以上條例可用來鑒定這些衣物是否潔淨。」</span>
</div>

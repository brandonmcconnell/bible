## 吃聖物的條例

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華對摩西說：</span>
<span className="v" id="v2" data-v="2" data-xref="利未記 18:21; 申命記 15:19; 利未記 22:32"> 「你告訴亞倫父子們要謹慎處理以色列人獻給我的聖物，免得褻瀆我的聖名。我是耶和華。</span>
<span className="v" id="v3" data-v="3" data-xref="利未記 7:20–21; 民數記 19:13; 詩篇 16:11"> 「你告訴他們：你們世世代代的子孫中，如果有人不潔淨，卻接近以色列人分別出來獻給我的聖物，必須把他從我面前剷除。我是耶和華。</span>
<span className="v" id="v4" data-v="4" data-xref="利未記 11:39; 利未記 15:2–3; 利未記 15:13–16"> 亞倫的子孫中若有人患了痲瘋病或漏症，在他潔淨之前，不可吃聖物。如果有人遺精，或碰到因接觸屍體而不潔淨之物，</span>
<span className="v" id="v5" data-v="5" data-xref="利未記 11:43–44; 利未記 15:7; 利未記 15:19"> 或碰到不潔淨的爬蟲，或碰到任何使他不潔淨的爬蟲或人，</span>
<span className="v" id="v6" data-v="6" data-xref="利未記 15:5; 希伯來書 10:22; 哈該書 2:13"> 這人就不潔淨，要到傍晚之後才能潔淨。他要沐浴後才可吃聖物。</span>
<span className="v" id="v7" data-v="7" data-xref="利未記 21:22; 申命記 18:3–4; 哥林多前書 9:13–14"> 日落之後，他就潔淨了，可以吃聖物，因為那是他應得的食物。</span>
<span className="v" id="v8" data-v="8" data-xref="利未記 17:15; 出埃及記 22:31; 以西結書 44:31"> 他不可吃自然死亡或被野獸撕裂的動物，免得因此而不潔淨。我是耶和華。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及記 28:43; 民數記 18:22; 民數記 18:32"> 他們要遵守我的命令，免得他們犯罪，因褻瀆我的命令而死亡。我是使他們聖潔的耶和華。</span>
<span className="v" id="v10" data-v="10" data-xref="馬太福音 12:4; 撒母耳記上 21:6; 出埃及記 29:33"> 「祭司家以外的人不可吃聖物，在祭司家中寄居的或做雇工的都不可吃，</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 17:13; 出埃及記 12:44; 民數記 18:11–13"> 但出生在祭司家裡或祭司用錢買來的奴隸都可以吃。</span>
<span className="v" id="v12" data-v="12" data-xref="以賽亞書 40:13; 利未記 21:3"> 如果祭司的女兒嫁給本族以外的人，她便不可再吃聖潔的舉祭。</span>
<span className="v" id="v13" data-v="13" data-xref="利未記 10:14; 創世記 38:11; 民數記 18:11–19"> 如果祭司的女兒守寡或被休，無兒無女，又像年輕時回到父親家居住，便可以吃父親的食物。除此以外，不屬於祭司家的人都不可吃。</span>
<span className="v" id="v14" data-v="14" data-xref="利未記 27:15; 利未記 27:13; 利未記 5:15–19"> 任何人如果誤吃聖物，就要如數償還給祭司，並加賠五分之一。</span>
<span className="v" id="v15" data-v="15" data-xref="民數記 18:32; 利未記 19:8; 以西結書 22:26"> 祭司不可褻瀆以色列民眾獻給耶和華的聖物，</span>
<span className="v" id="v16" data-v="16" data-xref="利未記 22:9; 彼得前書 2:24; 以賽亞書 53:11–12"> 以免因擅自吃聖物而擔罪、受罰。我是使他們聖潔的耶和華。」</span>
</div>
</div>

## 選擇祭牲的條例

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17"> 耶和華對摩西說：</span>
<span className="v" id="v18" data-v="18" data-xref="利未記 1:2; 申命記 12:6; 民數記 15:3"> 「你要告訴亞倫父子們及所有以色列人：任何以色列人或寄居在以色列的外族人，若向耶和華獻燔祭，無論是為了還願還是出於自願，</span>
<span className="v" id="v19" data-v="19" data-xref="利未記 1:10; 利未記 1:3; 以弗所書 5:27"> 都必須獻毫無殘疾的公牛、公綿羊或公山羊才能蒙悅納。</span>
<span className="v" id="v20" data-v="20" data-xref="申命記 17:1; 瑪拉基書 1:8; 申命記 15:21"> 不可獻有殘疾的，因為不蒙悅納。</span>
<span className="v" id="v21" data-v="21" data-xref="民數記 15:8; 民數記 15:3; 利未記 3:6"> 如果有人為了還願或自願獻牛羊作平安祭給耶和華，必須獻毫無殘疾的牛羊才能蒙悅納。</span>
<span className="v" id="v22" data-v="22" data-xref="利未記 22:20; 瑪拉基書 1:8; 利未記 1:9"> 不可獻給耶和華瞎眼的、傷殘的、斷肢的、長疥癬的牲畜，也不可把這些牲畜獻給耶和華作火祭。</span>
<span className="v" id="v23" data-v="23" data-xref="利未記 21:18"> 至於畸形或發育不全的公牛或綿羊羔，可以用作自願獻的祭，但用作還願祭將不蒙悅納。</span>
<span className="v" id="v24" data-v="24" data-xref="利未記 22:20; 申命記 23:1; 利未記 21:20"> 不可獻給耶和華睪丸受損、被壓碎、破裂或被閹割的牲畜。在你們境內不可做這樣的事，</span>
<span className="v" id="v25" data-v="25" data-xref="利未記 21:8; 以斯拉記 6:8–10; 民數記 15:14–16"> 也不可從外族人手中接受這類牲畜，來獻給你們的上帝作食物。因為這些牲畜是畸形的、殘疾的，不蒙悅納。」</span>
<span className="v" id="v26" data-v="26"> 耶和華對摩西說：</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及記 22:30; 利未記 19:23–24; 利未記 22:25"> 「剛出生的牛、綿羊或山羊，前七天要與母親在一起。從第八天起，把牠們獻給我作火祭必蒙悅納。</span>
<span className="v" id="v28" data-v="28" data-xref="申命記 22:6–7; 申命記 14:21; 出埃及記 34:26"> 不可在同一天內宰殺母牛和小牛或母羊和小羊。</span>
<span className="v" id="v29" data-v="29" data-xref="詩篇 116:17; 詩篇 107:22; 阿摩司書 4:5"> 你們獻感恩祭給耶和華時，要使你們所獻的蒙悅納。</span>
<span className="v" id="v30" data-v="30" data-xref="利未記 7:15–18; 出埃及記 16:19–20; 利未記 19:7"> 要當天吃完祭物，不可留到早晨。我是耶和華。</span>
<span className="v" id="v31" data-v="31" data-xref="申命記 4:40; 利未記 19:37; 民數記 15:40"> 你們要遵行我的一切誡命。我是耶和華。</span>
<span className="v" id="v32" data-v="32" data-xref="利未記 18:21; 路加福音 11:2; 馬太福音 6:9"> 不可褻瀆我的聖名，我要在以色列人中被尊為聖，我是使你們聖潔的耶和華。</span>
<span className="v" id="v33" data-v="33" data-xref="利未記 11:45; 出埃及記 6:7; 利未記 25:38"> 我領你們離開埃及，是要做你們的上帝。我是耶和華。」</span>
</div>
</div>

## 贖罪日的條例

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="利未記 10:1–2"> 亞倫的兩個兒子死在耶和華面前以後，</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 30:10; 列王紀上 8:10–12; 希伯來書 10:19–20"> 耶和華對摩西說：「告訴你哥哥亞倫，他不可隨意進入幔子裡面的至聖所，到約櫃上的施恩座前，免得死亡，因為我要在施恩座之上的雲彩中顯現。</span>
<span className="v" id="v3" data-v="3" data-xref="利未記 4:3; 希伯來書 9:24–25; 希伯來書 9:7"> 亞倫進入聖所時，要帶一頭作贖罪祭的公牛犢和一隻作燔祭的公綿羊。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及記 28:39–43; 以西結書 44:17–18; 出埃及記 30:20"> 他要穿上聖潔的細麻內袍和細麻褲子，束上細麻腰帶，戴上細麻禮冠。這些是聖潔的衣物，他必須沐浴後才可穿戴。</span>
<span className="v" id="v5" data-v="5" data-xref="歷代志下 29:21; 利未記 8:2; 以斯拉記 6:17"> 他要從以色列會眾那裡取兩隻公山羊作贖罪祭，一隻公綿羊作燔祭。</span>
<span className="v" id="v6" data-v="6" data-xref="利未記 9:7; 希伯來書 9:7; 希伯來書 7:27"> 亞倫要先獻上那頭公牛犢作贖罪祭，為自己和全家贖罪。</span>
<span className="v" id="v7" data-v="7" data-xref="羅馬書 12:1; 利未記 4:4; 馬太福音 16:21"> 然後，他要把兩隻公山羊帶到會幕門口，放在耶和華面前。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行傳 1:23–26; 約拿書 1:7; 箴言 16:33"> 他要為這兩隻羊抽籤，決定哪隻歸耶和華，哪隻歸阿撒瀉勒<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「阿撒瀉勒」是希伯來文的音譯，意義不確定。">a</a></sup>。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行傳 4:27–28; 使徒行傳 2:23"> 亞倫要獻上那隻歸耶和華的公山羊作贖罪祭，</span>
<span className="v" id="v10" data-v="10" data-xref="約翰一書 2:2; 利未記 16:21–22; 希伯來書 9:23–24"> 要將那隻歸阿撒瀉勒的公山羊活著獻給耶和華，用來贖罪，然後把牠放到曠野歸阿撒瀉勒。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="利未記 16:6; 希伯來書 7:27; 希伯來書 9:7"> 「亞倫要把那頭為他作贖罪祭的公牛犢牽來宰殺，為自己和全家贖罪，</span>
<span className="v" id="v12" data-v="12" data-xref="利未記 10:1; 出埃及記 30:34–38; 啟示錄 8:3–4"> 然後拿一個香爐，盛滿從耶和華面前的祭壇上取的火炭，再拿兩把磨細的香帶進幔子裡。</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及記 25:21; 出埃及記 30:1; 出埃及記 30:7–8"> 他要在耶和華面前燒香，使香的煙籠罩約櫃上的施恩座，免得他死亡。</span>
<span className="v" id="v14" data-v="14" data-xref="希伯來書 9:25; 利未記 4:5–6; 希伯來書 9:13"> 他要取一些公牛的血，用手指彈灑在施恩座的東面，並在施恩座前用手指彈灑七次。</span>
<span className="v" id="v15" data-v="15" data-xref="希伯來書 9:7; 希伯來書 2:17; 希伯來書 9:3"> 然後，亞倫要出去宰殺那隻為民眾作贖罪祭的公山羊，把羊血帶進幔子裡，像灑公牛的血一樣灑在施恩座的上面和前面。</span>
<span className="v" id="v16" data-v="16" data-xref="希伯來書 9:22–23; 利未記 16:18; 以西結書 45:18–19"> 因以色列人的污穢、叛逆和罪惡，他要這樣為至聖所贖罪。他也要同樣為會幕贖罪，因為會幕座落在以色列人中間，處在他們的污穢中。</span>
<span className="v" id="v17" data-v="17" data-xref="以賽亞書 53:6; 路加福音 1:10; 出埃及記 34:3"> 從他進入聖所為自己、家人和以色列全體會眾贖罪開始，直到他贖完罪出來為止，任何人都不可待在會幕裡。</span>
<span className="v" id="v18" data-v="18" data-xref="利未記 4:7; 希伯來書 5:7–8; 利未記 16:16"> 之後，他要來到耶和華面前的祭壇那裡，為祭壇贖罪。他要取一些牛血和羊血，抹在祭壇凸起的四角上，</span>
<span className="v" id="v19" data-v="19" data-xref="撒迦利亞書 13:1; 以西結書 43:18–22"> 然後用手指向祭壇灑血七次，除掉以色列人的污穢，使祭壇聖潔。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="利未記 16:16; 以西結書 45:20; 歌羅西書 1:20"> 「他為至聖所、會幕和祭壇贖罪後，要牽來那隻活山羊，</span>
<span className="v" id="v21" data-v="21" data-xref="以賽亞書 53:6; 哥林多後書 5:21; 以斯拉記 10:1"> 把雙手放在羊頭上，承認以色列人的所有過犯、叛逆和罪惡，將這一切罪歸到公山羊的頭上，然後派人把牠送到曠野。</span>
<span className="v" id="v22" data-v="22" data-xref="希伯來書 9:28; 以賽亞書 53:11–12; 約翰福音 1:29"> 這隻羊要把他們一切的罪過帶到偏遠的地方，那人要把羊留在曠野。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="以西結書 44:19; 以西結書 42:14; 利未記 16:4"> 「亞倫要走進會幕，脫下他進至聖所時穿的細麻衣服，放在會幕裡。</span>
<span className="v" id="v24" data-v="24" data-xref="利未記 16:3–5; 希伯來書 10:19–22; 出埃及記 28:4–14"> 他要在聖潔之處沐浴，穿上平時的衣服出去為自己和民眾獻燔祭，為自己和民眾贖罪。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及記 29:13; 利未記 4:8–10; 利未記 16:6"> 他要將贖罪祭牲的脂肪焚燒在祭壇上。</span>
<span className="v" id="v26" data-v="26" data-xref="利未記 16:10; 希伯來書 7:19; 民數記 19:21"> 把羊送交阿撒瀉勒的人要洗衣、沐浴，然後才可回到營裡。</span>
<span className="v" id="v27" data-v="27" data-xref="利未記 4:21; 利未記 6:30; 利未記 4:11–12"> 作贖罪祭的公牛和公山羊的血被帶進聖所用來贖罪後，要把公牛和公山羊帶到營外，用火焚燒牠們的皮、肉和糞。</span>
<span className="v" id="v28" data-v="28"> 負責焚燒的人要洗衣、沐浴，然後才可回到營裡。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="以賽亞書 58:3; 民數記 29:7; 出埃及記 20:10"> 「每年七月十日，不論是你們，還是寄居在你們中間的外族人，都要禁食，停止所有工作。這是你們永遠當守的律例。</span>
<span className="v" id="v30" data-v="30" data-xref="耶利米書 33:8; 詩篇 51:2; 以弗所書 5:26"> 因為在這一天要為你們贖罪，使你們在耶和華面前潔淨，脫離一切的罪。</span>
<span className="v" id="v31" data-v="31" data-xref="利未記 23:32; 以賽亞書 58:5; 利未記 25:4"> 這天是你們完全休息的安息日，你們要禁食。這是一條永遠不變的律例。</span>
<span className="v" id="v32" data-v="32" data-xref="利未記 16:4; 出埃及記 29:29–30; 利未記 4:5"> 那受膏、接替父親擔任聖職的大祭司要行贖罪禮。他要穿上聖潔的細麻衣，</span>
<span className="v" id="v33" data-v="33" data-xref="利未記 16:16; 利未記 16:24; 利未記 16:6"> 為至聖所、會幕和祭壇贖罪，也要為祭司和全體會眾贖罪。</span>
<span className="v" id="v34" data-v="34" data-xref="希伯來書 9:7; 希伯來書 9:25; 出埃及記 30:10"> 這是你們當守的永久律例：每年一次為以色列人贖罪。」<br />於是，摩西遵行了耶和華的吩咐。</span>
</div>

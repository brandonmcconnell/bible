## 燈和供餅的條例

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華對摩西說：</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多後書 4:6; 以弗所書 5:8–14; 出埃及記 27:20–21"> 「你要吩咐以色列人把榨的純橄欖油給你拿來點燈，使燈常明。</span>
<span className="v" id="v3" data-v="3"> 亞倫要負責照看會幕內遮掩約櫃的幔子外的燈，使燈從晚上到早晨一直在耶和華面前亮著。這是你們世代當守的永久律例。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及記 31:8; 出埃及記 37:17–24; 出埃及記 39:37"> 亞倫要在耶和華面前常常照看這些放在純金燈臺上的燈。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="出埃及記 25:30; 列王紀上 18:31; 出埃及記 40:23"> 「你要用細麵粉烤十二個餅，每個餅用兩公斤細麵粉。</span>
<span className="v" id="v6" data-v="6" data-xref="列王紀上 7:48; 出埃及記 25:23–24; 歷代志下 4:19"> 你要把餅擺成兩行，放在耶和華面前的純金桌子上，每行六個，</span>
<span className="v" id="v7" data-v="7" data-xref="利未記 2:2; 啟示錄 8:3–4; 創世記 9:16"> 每行餅上放一些純乳香，象徵這些餅是獻給耶和華的火祭。</span>
<span className="v" id="v8" data-v="8" data-xref="歷代志下 2:4; 民數記 4:7; 歷代志上 9:32"> 每逢安息日，要定期把餅擺在耶和華面前。這是以色列人要永遠遵守的約。</span>
<span className="v" id="v9" data-v="9" data-xref="利未記 8:31; 路加福音 6:4; 馬可福音 2:26"> 這些餅要歸亞倫及其子孫。他們要在聖潔之處吃，因為在獻給耶和華的火祭中，這是至聖之物，要永遠歸祭司所有。」</span>
</div>
</div>

## 處死褻瀆聖名者

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="民數記 11:4; 出埃及記 12:38"> 有一個人，母親是以色列人，父親是埃及人，他在營中與一個以色列人打起架來。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及記 20:7; 利未記 24:15–16; 出埃及記 3:15"> 他說咒詛的話，褻瀆了上帝的名，他們把他帶到摩西那裡。他母親叫示羅密，是但支派底伯利的女兒。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及記 18:15–16; 民數記 15:34; 民數記 27:5"> 他們把他關押起來，等候耶和華的指示。</span>
<span className="v" id="v13" data-v="13"> 耶和華對摩西說：</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 17:7; 利未記 20:27; 申命記 21:21"> 「把那褻瀆聖名的人帶到營外，所有聽見的人都把手放在他頭上，然後全體會眾要用石頭打死他。</span>
<span className="v" id="v15" data-v="15" data-xref="民數記 9:13; 出埃及記 22:28; 利未記 5:1"> 你要告訴以色列人，誰咒詛上帝，誰就要承擔自己的罪。</span>
<span className="v" id="v16" data-v="16" data-xref="馬太福音 12:31; 雅各書 2:7; 約翰福音 10:33–36"> 凡褻瀆耶和華聖名的，必須被處死，全體會眾要用石頭打死他。不論是外族人還是以色列人，凡褻瀆聖名的，都必須被處死。</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 9:5–6; 申命記 19:11–12; 申命記 27:24"> 凡殺人的，必須被處死。</span>
<span className="v" id="v18" data-v="18" data-xref="利未記 24:21; 出埃及記 21:34–36"> 打死別人牲畜的，必須賠償牲畜，以命還命。</span>
<span className="v" id="v19" data-v="19" data-xref="馬太福音 5:38; 馬太福音 7:2; 申命記 19:21"> 傷害鄰舍的，必須受同樣的傷害，</span>
<span className="v" id="v20" data-v="20" data-xref="申命記 19:21; 馬太福音 5:38; 出埃及記 21:23–25"> 要以傷還傷，以眼還眼，以牙還牙。他怎樣傷害別人，也要怎樣傷害他。</span>
<span className="v" id="v21" data-v="21" data-xref="利未記 24:17–18; 出埃及記 21:33"> 打死別人牲畜的，必須賠償牲畜；殺人的，必須償命。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及記 12:49; 民數記 15:15–16; 民數記 9:14"> 不論是以色列人還是外族人，都要遵守這些律法。我是你們的上帝耶和華。」</span>
<span className="v" id="v23" data-v="23" data-xref="希伯來書 10:28–29; 希伯來書 2:2–3; 民數記 15:35–36"> 於是，摩西把這些話告訴以色列人，他們就按照耶和華對摩西的吩咐，把那褻瀆聖名的人帶到營外，用石頭打死了。</span>
</div>
</div>

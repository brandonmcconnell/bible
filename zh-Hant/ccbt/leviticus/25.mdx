## 安息年的條例

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民數記 1:1; 加拉太書 4:24–25; 出埃及記 19:1"> 耶和華在西奈山上對摩西說：</span>
<span className="v" id="v2" data-v="2" data-xref="歷代志下 36:21; 利未記 26:34–35; 出埃及記 23:10"> 「你要告訴以色列人：你們到了我將要賜給你們的土地後，要讓土地在耶和華面前守安息。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 23:10"> 六年之內，你們可以耕種田地，修整葡萄園，收穫出產。</span>
<span className="v" id="v4" data-v="4" data-xref="歷代志下 36:21; 利未記 25:20–23; 出埃及記 23:10–11"> 但第七年是要向耶和華守的安息年，土地要完全休息。你們不可耕種，不可修整葡萄園。</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀下 19:29; 以賽亞書 37:30"> 不可收割自生自長的莊稼，也不可摘未經修剪而結的葡萄。這一年土地要完全休耕。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行傳 2:44; 出埃及記 23:11; 使徒行傳 4:34–35"> 但安息年間土地裡自生自長的，你們和你們的僕婢、雇工與住在你們中間的外族人都可以吃，</span>
<span className="v" id="v7" data-v="7"> 你們的牲畜和境內的野獸也可以吃。</span>
</div>
</div>

## 禧年的條例

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="利未記 23:15; 創世記 2:2"> 「你們要計算七個安息年，即七個七年，共四十九年。</span>
<span className="v" id="v9" data-v="9" data-xref="利未記 23:24; 利未記 23:27; 帖撒羅尼迦前書 1:8"> 第五十年的七月十日贖罪日那天，你們要在境內各地吹號。</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米書 34:8; 以賽亞書 63:4; 彼得前書 2:16"> 你們要以這一年為聖年，向境內所有居民宣告自由。這一年將成為你們的禧年。你們要各歸祖業，各回本家。</span>
<span className="v" id="v11" data-v="11" data-xref="利未記 27:17; 利未記 25:4–5"> 第五十年是你們的禧年。這一年你們不可耕種，不可收割自生自長的莊稼，也不可摘未經修剪而結的葡萄。</span>
<span className="v" id="v12" data-v="12" data-xref="利未記 25:6–7"> 這是禧年，是你們的聖年，你們可以吃土地裡自生自長的。</span>
<span className="v" id="v13" data-v="13" data-xref="利未記 25:10; 利未記 27:17–24; 民數記 36:4"> 在禧年，各人要回到祖業。</span>
<span className="v" id="v14" data-v="14" data-xref="利未記 19:13; 利未記 25:17; 撒母耳記上 12:3–4"> 因此，你們和同胞買賣田地時，不可彼此虧負。</span>
<span className="v" id="v15" data-v="15" data-xref="利未記 27:18–23; 腓立比書 4:5"> 買賣雙方要按照距下個禧年的年數和收成的年數定價。</span>
<span className="v" id="v16" data-v="16" data-xref="利未記 25:27; 利未記 25:51"> 距下個禧年的年數多，價錢就高；年數少，價錢就低。因為賣的是田地收成的次數。</span>
<span className="v" id="v17" data-v="17" data-xref="利未記 19:14; 利未記 19:32; 利未記 25:43"> 要敬畏你們的上帝，不可彼此虧負。我是你們的上帝耶和華。</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米書 23:6; 申命記 12:10; 箴言 1:33"> 你們要遵行我的律例，持守我的典章，就可以在那片土地上安居。</span>
<span className="v" id="v19" data-v="19" data-xref="約珥書 2:26; 詩篇 85:12; 利未記 26:5"> 土地會出產豐富，使你們豐衣足食、安然居住。</span>
<span className="v" id="v20" data-v="20" data-xref="利未記 25:4; 路加福音 12:29; 民數記 11:4"> 你們可能會問，『第七年不種不收，我們吃什麼？』</span>
<span className="v" id="v21" data-v="21" data-xref="申命記 28:8; 箴言 10:22; 哥林多後書 9:10"> 我要在第六年賜福給你們，使田地的出產夠你們吃三年。</span>
<span className="v" id="v22" data-v="22" data-xref="列王紀下 19:29; 利未記 26:10; 以賽亞書 37:30"> 第八年開始耕種時，你們仍會吃陳糧，一直吃到第九年的收割季節。</span>
</div>
</div>

## 贖回土地的條例

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="彼得前書 2:11; 詩篇 39:12; 以西結書 48:14"> 「你們不可永遠賣掉土地，因為土地是我的，你們只不過是寄居在那片土地上的過客。</span>
<span className="v" id="v24" data-v="24" data-xref="以弗所書 1:7; 利未記 25:51–53; 利未記 25:27"> 你們購買每一塊土地時，都必須讓原主保留贖回的權利。</span>
<span className="v" id="v25" data-v="25" data-xref="路得記 2:20; 耶利米書 32:7–8; 路得記 3:12"> 如果有人因貧窮而賣掉土地，他的近親要把賣掉的土地贖回來。</span>
<span className="v" id="v26" data-v="26" data-xref="利未記 5:7"> 如果無人為他贖回，而他自己漸漸富裕起來，有能力贖回，</span>
<span className="v" id="v27" data-v="27"> 他要計算賣掉土地的年數，退還距下個禧年所剩年數的地價，便可以贖回自己的土地。</span>
<span className="v" id="v28" data-v="28" data-xref="以賽亞書 35:9–10; 利未記 25:10; 彼得前書 1:4–5"> 如果他沒有能力贖回，所賣的土地在禧年之前要屬於買主。到了禧年，買主必須把土地歸還原主。</span>
</div>
</div>

## 贖回房屋的條例

<div className="bt">
<div className="bp">
<span className="v" id="v29" data-v="29"> 「如果有人賣掉自己城裡的房子，要保留一年贖回權。賣掉房子的一年之內，他可以贖回。</span>
<span className="v" id="v30" data-v="30"> 如果一年之內他沒有贖回，房子便永遠歸買主所有，就是到了禧年也不用歸還。</span>
<span className="v" id="v31" data-v="31" data-xref="詩篇 49:7–8"> 如果房子在四圍無牆的鄉村，要視房子為鄉下的土地，原主可以贖回；到了禧年，買主必須將房子歸還。</span>
<span className="v" id="v32" data-v="32" data-xref="約書亞記 21:1–45; 民數記 35:1–8"> 在利未人的城邑裡，利未人永遠有權贖回所賣的房子。</span>
<span className="v" id="v33" data-v="33" data-xref="民數記 18:20–24; 申命記 18:1–2"> 如果他們沒有贖回，到了禧年要把房子歸還他們，因為在利未人的城裡，利未人的房屋是他們在以色列人中所擁有的產業。</span>
<span className="v" id="v34" data-v="34" data-xref="利未記 25:23; 使徒行傳 4:36–37; 民數記 35:2–5"> 但不可出賣利未人城郊的草場，那是他們永遠擁有的產業。</span>
</div>
</div>

## 照顧同胞的條例

<div className="bt">
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="申命記 15:7–8; 使徒行傳 11:29; 利未記 25:25"> 「如果你們的同胞生活日益貧窮，難以維生，你們要像照顧外族人和寄居者一樣照顧他的生活，讓他住在你們當中。</span>
<span className="v" id="v36" data-v="36" data-xref="出埃及記 22:25; 申命記 23:19–20; 以西結書 18:8"> 不可向他放債取利，要敬畏你們的上帝，讓他住在你們當中。</span>
<span className="v" id="v37" data-v="37"> 你們借錢給他，不可收取利息；借糧給他，不可謀利。</span>
<span className="v" id="v38" data-v="38" data-xref="利未記 11:45; 民數記 15:41; 出埃及記 20:2"> 我是你們的上帝耶和華。我曾經帶領你們離開埃及，為要把迦南賜給你們，並做你們的上帝。</span>
</div>
</div>

## 買賣奴隸的條例

<div className="bt">
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="出埃及記 21:2; 列王紀上 9:22; 列王紀下 4:1"> 「如果你們的同胞窮得把自己賣給你們，不可把他當作奴隸，</span>
<span className="v" id="v40" data-v="40" data-xref="出埃及記 21:2–3"> 要待他像雇工和寄居者一樣。他要為你工作到禧年。</span>
<span className="v" id="v41" data-v="41" data-xref="利未記 25:28; 出埃及記 21:3; 約翰福音 8:32"> 到了禧年，他和孩子們便可以離開你們，回到自己的宗族和祖業。</span>
<span className="v" id="v42" data-v="42" data-xref="利未記 25:55; 羅馬書 6:22; 哥林多前書 7:21–23"> 因為以色列人是我的僕人，是我從埃及帶出來的，所以他們不可賣身為奴。</span>
<span className="v" id="v43" data-v="43" data-xref="歌羅西書 4:1; 利未記 25:46; 出埃及記 1:13–14"> 你們也不可苛待他們，要敬畏你們的上帝。</span>
<span className="v" id="v44" data-v="44" data-xref="出埃及記 12:44; 詩篇 2:8–9; 以賽亞書 14:1–2"> 你們可以從鄰國購買奴隸，</span>
<span className="v" id="v45" data-v="45" data-xref="以賽亞書 56:3–6"> 也可以買居住或出生在你們境內的外族人。這些人可以作你們的產業。</span>
<span className="v" id="v46" data-v="46" data-xref="以賽亞書 14:2; 利未記 25:43"> 你們可以將他們作為產業傳給你們的子孫，使他們終身做奴隸。但你們不可苛待自己的同胞。</span>
<span className="v" id="v47" data-v="47" data-xref="雅各書 2:5; 利未記 25:26; 撒母耳記上 2:7–8"> 「如果你們中間的外族人漸漸富裕，你們同胞中卻有人日益貧窮，把自己賣給外族人或他們的族人，</span>
<span className="v" id="v48" data-v="48" data-xref="尼希米記 5:5; 希伯來書 2:11–13; 利未記 25:35"> 他可以保留贖身的權利。他的兄弟、</span>
<span className="v" id="v49" data-v="49" data-xref="利未記 25:26"> 叔伯、堂兄弟或其他近親都可以贖回他。如果他富裕起來，也可以贖回自己。</span>
<span className="v" id="v50" data-v="50" data-xref="以賽亞書 16:14; 以賽亞書 21:16; 利未記 25:53"> 他要和買主計算從自己賣身為奴到下個禧年之間的年數，然後按雇工的工價，照年數計算贖價。</span>
<span className="v" id="v51" data-v="51"> 如果離禧年還有很多年，他就要按年數和當初賣價的比例償還贖價。</span>
<span className="v" id="v52" data-v="52"> 如果離禧年只有不多的幾年，他就要按年數償還贖身費。</span>
<span className="v" id="v53" data-v="53" data-xref="利未記 25:46; 利未記 25:43"> 買主要待他如按年雇用的工人。你們要確保買主不會苛待他。</span>
<span className="v" id="v54" data-v="54" data-xref="出埃及記 21:2–3; 利未記 25:40–41; 以賽亞書 49:9"> 如果禧年來臨前他沒有被贖回，到了禧年他和孩子們都要獲得自由。</span>
<span className="v" id="v55" data-v="55" data-xref="利未記 25:42; 以賽亞書 43:3; 出埃及記 13:3"> 因為以色列人是我的僕人，是我從埃及領出來的僕人。我是你們的上帝耶和華。</span>
</div>
</div>

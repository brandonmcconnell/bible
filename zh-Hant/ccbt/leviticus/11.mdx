## 有關食物的條例

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華對摩西和亞倫說：</span>
<span className="v" id="v2" data-v="2" data-xref="馬太福音 15:11; 利未記 11:11; 希伯來書 9:10"> 「你們把以下條例告訴以色列人。<br />「地上的動物，</span>
<span className="v" id="v3" data-v="3" data-xref="箴言 2:10; 哥林多後書 6:17; 申命記 6:6–7"> 凡蹄子分瓣且反芻的動物，你們都可以吃。</span>
<span className="v" id="v4" data-v="4"> 但你們不可吃只是蹄子分瓣或只反芻的動物。駱駝不潔淨，因為牠雖反芻但蹄子不分瓣；</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 104:18; 箴言 30:26; 馬太福音 7:26"> 石獾不潔淨，因為牠雖反芻但蹄子不分瓣；</span>
<span className="v" id="v6" data-v="6" data-xref="申命記 14:7"> 野兔不潔淨，因為牠雖反芻但蹄子不分瓣；</span>
<span className="v" id="v7" data-v="7" data-xref="以賽亞書 66:17; 以賽亞書 65:4; 以賽亞書 66:3"> 豬不潔淨，因為牠雖蹄子分瓣但不反芻。</span>
<span className="v" id="v8" data-v="8" data-xref="以賽亞書 52:11; 歌羅西書 2:16; 希伯來書 9:10"> 你們不可吃牠們的肉，也不可摸牠們的屍體，因為牠們對你們來說不潔淨。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="加拉太書 5:6; 雅各書 2:18; 使徒行傳 20:21"> 「海洋與河流裡的動物，凡有鰭有鱗的，你們都可以吃。</span>
<span className="v" id="v10" data-v="10" data-xref="箴言 29:27; 利未記 7:18; 詩篇 139:21–22"> 但海洋與河流裡無鰭無鱗的動物，你們要憎惡。</span>
<span className="v" id="v11" data-v="11"> 牠們都是可憎之物，你們不可吃牠們的肉，也不可摸牠們的屍體。</span>
<span className="v" id="v12" data-v="12"> 水中任何無鰭無鱗的動物，你們都要視為可憎之物。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="約伯記 39:27–30; 耶利米書 4:22; 提多書 3:3"> 「你們不可吃以下鳥類，要視為可憎之物。牠們是鵰、胡兀鷲、黑禿鷲、</span>
<span className="v" id="v14" data-v="14"> 鳶、隼類、</span>
<span className="v" id="v15" data-v="15" data-xref="路加福音 12:24; 列王紀上 17:6; 箴言 30:17"> 烏鴉類、</span>
<span className="v" id="v16" data-v="16" data-xref="以賽亞書 34:11–15; 以弗所書 5:7–11; 以弗所書 2:2–3"> 鴕鳥、夜鷹、海鷗、鷹類、</span>
<span className="v" id="v17" data-v="17"> 小鴞、鸕鷀、大鴞、</span>
<span className="v" id="v18" data-v="18"> 倉鴞、鵜鶘、魚鷹、</span>
<span className="v" id="v19" data-v="19"> 鸛、鷺鳥類、戴鵀和蝙蝠。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="提摩太後書 4:10; 腓立比書 3:18–19; 利未記 11:23"> 「你們要憎惡會飛的四足爬行昆蟲，</span>
<span className="v" id="v21" data-v="21"> 但可以吃其中會飛會跳的昆蟲，</span>
<span className="v" id="v22" data-v="22" data-xref="馬太福音 3:4; 馬可福音 1:6; 出埃及記 10:4–5"> 包括蝗蟲類、蟋蟀類和蚱蜢類。</span>
<span className="v" id="v23" data-v="23"> 你們要憎惡所有會飛的四足爬行昆蟲。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="哥林多前書 15:33; 以弗所書 2:1–3; 哥林多後書 6:17"> 「以下的動物會使你們不潔淨。任何人接觸到牠們的屍體，都不潔淨，要等到傍晚才能潔淨。</span>
<span className="v" id="v25" data-v="25" data-xref="利未記 15:5; 利未記 14:8; 民數記 31:24"> 任何人拿牠們的屍體，都必須洗淨所穿的衣服，要等到傍晚才能潔淨。</span>
<span className="v" id="v26" data-v="26"> 蹄子不分瓣或不反芻的動物，你們要視為不潔淨，碰到牠們的人都不潔淨。</span>
<span className="v" id="v27" data-v="27" data-xref="利未記 11:23; 利未記 11:20"> 所有以腳掌走路的四足動物，你們要視為不潔淨，碰到牠們屍體的人都不潔淨，要等到傍晚才能潔淨。</span>
<span className="v" id="v28" data-v="28" data-xref="利未記 11:24–25"> 凡拿牠們屍體的人都必須洗淨所穿的衣服，要等到傍晚才能潔淨。你們要視牠們為不潔淨的動物。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="利未記 11:41–42; 提摩太後書 3:2–5; 詩篇 10:3"> 「地上不潔淨的動物有鼬鼠、老鼠、大蜥蜴類、</span>
<span className="v" id="v30" data-v="30"> 壁虎、巨蜥、小蜥蜴和變色龍。</span>
<span className="v" id="v31" data-v="31" data-xref="利未記 11:24–25; 利未記 11:8"> 這些爬蟲都是不潔淨的。任何人碰到牠們的屍體，都不潔淨，要等到傍晚才能潔淨。</span>
<span className="v" id="v32" data-v="32" data-xref="利未記 15:12; 提多書 3:5; 提多書 2:14"> 如果牠們的屍體掉在什麼東西上，不管是木器、衣物、皮件還是袋子，不管作何用途，都會變得不潔淨。要把那東西放在水中，一直到傍晚才能潔淨。</span>
<span className="v" id="v33" data-v="33" data-xref="利未記 6:28; 利未記 15:12; 利未記 14:45"> 如果牠們的屍體掉在陶器裡，陶器裡盛的東西都不潔淨。你們必須打碎那陶器。</span>
<span className="v" id="v34" data-v="34" data-xref="提多書 1:15; 箴言 21:4; 箴言 21:27"> 陶器裡的水如果滴到食物上，食物就不潔淨；如果滴到盛飲品的器皿裡，飲品也不潔淨。</span>
<span className="v" id="v35" data-v="35" data-xref="利未記 15:12; 利未記 6:28; 利未記 11:33"> 牠們的屍體無論掉在什麼東西上，那東西都不潔淨，無論是爐是鍋都要打碎。它們不潔淨，也理當被你們視為不潔淨。</span>
<span className="v" id="v36" data-v="36" data-xref="撒迦利亞書 13:1; 約翰福音 4:14"> 如果牠們的屍體掉進水泉或儲水池裡，水泉和儲水池仍然是潔淨的，但碰到屍體的人是不潔淨的。</span>
<span className="v" id="v37" data-v="37" data-xref="哥林多前書 15:37; 彼得前書 1:23; 約翰一書 5:18"> 如果牠們的屍體接觸到將要播撒的種子，種子仍是潔淨的。</span>
<span className="v" id="v38" data-v="38"> 但如果牠們的屍體碰到泡過水的種子，種子就不潔淨。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="利未記 11:40; 利未記 11:24; 利未記 15:7"> 「一隻可以食用的動物死後，任何人如果碰到牠的屍體，都不潔淨，要等到傍晚才能潔淨。</span>
<span className="v" id="v40" data-v="40" data-xref="利未記 22:8; 以西結書 44:31; 申命記 14:21"> 任何人如果吃牠的肉，或拿牠的屍體，都必須洗淨衣服，等到傍晚才能潔淨。</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="利未記 11:29; 利未記 11:20; 利未記 11:23"> 「地上所有的爬蟲都是可憎的，你們不可吃。</span>
<span className="v" id="v42" data-v="42" data-xref="提多書 1:12; 以賽亞書 65:25; 哥林多後書 11:3"> 你們不可吃用肚子、四腳或多腳爬行的動物，這些都是可憎的。</span>
<span className="v" id="v43" data-v="43" data-xref="利未記 20:25; 利未記 11:41–42"> 不可讓這些動物使你們成為可憎的，不可因它們而玷污自己，使自己不潔淨。</span>
<span className="v" id="v44" data-v="44" data-xref="出埃及記 20:2; 彼得前書 1:15–16; 利未記 19:2"> 我是你們的上帝耶和華。你們要分別出來做聖潔的人，因為我是聖潔的。不可讓地上的爬蟲玷污你們。</span>
<span className="v" id="v45" data-v="45" data-xref="利未記 11:44; 出埃及記 20:2; 出埃及記 6:7"> 我是耶和華，我帶你們出埃及，為要做你們的上帝。你們要聖潔，因為我是聖潔的。</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="利未記 14:54; 利未記 15:32; 以西結書 43:12"> 「以上是有關飛禽走獸、水族和地上一切爬蟲的條例，</span>
<span className="v" id="v47" data-v="47" data-xref="利未記 10:10; 以西結書 44:23; 羅馬書 14:13–23"> 使你們可以區分什麼是潔淨的、什麼是不潔淨的、什麼是可吃的、什麼是不可吃的。」</span>
</div>
</div>

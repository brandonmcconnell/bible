## 有關聖潔生活的條例

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華對摩西說：</span>
<span className="v" id="v2" data-v="2" data-xref="利未記 11:44–45; 利未記 20:7; 彼得前書 1:15–16"> 「你要告訴以色列全體會眾，『你們要聖潔，因為我——你們的上帝耶和華是聖潔的。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 20:12; 出埃及記 20:8; 希伯來書 12:9"> 你們每個人都必須孝敬父母，遵守我的安息日。我是你們的上帝耶和華。</span>
<span className="v" id="v4" data-v="4" data-xref="利未記 26:1; 出埃及記 20:23; 詩篇 115:4–7"> 不要祭拜虛無的神明，也不要為自己鑄造神像。我是你們的上帝耶和華。</span>
<span className="v" id="v5" data-v="5" data-xref="利未記 22:19; 利未記 22:29; 利未記 7:16"> 你們獻平安祭給我時，要使你們所獻的蒙悅納。</span>
<span className="v" id="v6" data-v="6" data-xref="利未記 7:11–17"> 要在獻祭當天或第二天吃完祭物。如果第三天還有剩餘，都要燒掉。</span>
<span className="v" id="v7" data-v="7" data-xref="利未記 7:18–21; 利未記 22:25; 耶利米書 16:18"> 如果有人第三天還吃那些祭物，祭物就不潔淨，我不會悅納。</span>
<span className="v" id="v8" data-v="8" data-xref="利未記 22:15; 利未記 5:1"> 那人要自擔罪責，因為他褻瀆了我的聖物。要將他從民中剷除。</span>
<span className="v" id="v9" data-v="9" data-xref="利未記 23:22; 申命記 24:19–22; 路得記 2:2"> 「『你們收割的時候，不要割淨田角地邊的莊稼，也不要撿那些掉在田裡的穗子。</span>
<span className="v" id="v10" data-v="10" data-xref="以賽亞書 17:6; 利未記 25:6; 以賽亞書 24:13"> 不要摘淨葡萄園裡的葡萄，也不要撿掉在地上的葡萄。要把這些留給窮人和寄居在你們中間的外族人。我是你們的上帝耶和華。</span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 101:7; 以弗所書 4:25; 歌羅西書 3:9"> 不可偷盜，不可撒謊，不可互相欺騙。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及記 20:7; 申命記 5:11; 利未記 18:21"> 不可奉我的名起假誓，從而褻瀆你們上帝的名。我是耶和華。</span>
<span className="v" id="v13" data-v="13" data-xref="雅各書 5:4; 瑪拉基書 3:5; 申命記 24:14–15"> 不可欺壓鄰居，也不可搶奪他的東西。要當天支付雇工的工錢，不可拖到第二天。</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 27:18; 利未記 19:32; 利未記 25:17"> 不可咒罵耳聾的，也不可把絆腳石放在盲人面前，應當敬畏你們的上帝。我是耶和華。</span>
<span className="v" id="v15" data-v="15" data-xref="申命記 1:17; 箴言 24:23; 申命記 27:19"> 不可徇私枉法，不可偏袒窮人，不可諂媚權貴之人，要秉公審判。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 23:1; 出埃及記 23:7; 箴言 20:19"> 不可到處搬弄是非，不可危害鄰居的生命安全。我是耶和華。</span>
<span className="v" id="v17" data-v="17" data-xref="約翰一書 2:9; 約翰一書 2:11; 路加福音 17:3"> 對同胞不可心中懷恨。同胞有錯，要當面指正，免得自己因他而擔罪。</span>
<span className="v" id="v18" data-v="18" data-xref="羅馬書 13:9; 馬太福音 22:39–40; 馬可福音 12:31–34"> 不可報復，不可埋怨同胞，要愛鄰如己。我是耶和華。</span>
<span className="v" id="v19" data-v="19" data-xref="哥林多後書 6:14–17; 申命記 22:9–11; 馬太福音 9:16–17"> 「『你們要遵守我的律例。不可讓牲畜雜交；不可在同一塊田播撒兩種不同的種子；不可穿兩種材料織成的衣服。</span>
<span className="v" id="v20" data-v="20" data-xref="申命記 22:23–24; 出埃及記 21:20–21"> 「『一個已經許配人的婢女尚未被贖或未獲自由時，如果有人與她同寢，就要受到處罰，但不可處死他們，因為那婢女還未獲自由。</span>
<span className="v" id="v21" data-v="21" data-xref="利未記 6:6–7; 利未記 5:1–6; 利未記 5:15"> 和她同寢的人要把一隻公綿羊牽到會幕門口，作為贖過祭獻給耶和華。</span>
<span className="v" id="v22" data-v="22" data-xref="利未記 4:26; 利未記 4:20"> 祭司要用作贖過祭的公綿羊在耶和華面前為那人贖罪，他犯的罪便得到赦免。</span>
<span className="v" id="v23" data-v="23" data-xref="利未記 22:27; 使徒行傳 7:51; 耶利米書 9:25–26"> 「『你們到了迦南，在那裡栽種各樣果樹後，前三年不可吃樹上的果子，要視它們是不潔淨的<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「不潔淨的」希伯來文是「未受割禮的」。">a</a></sup>。</span>
<span className="v" id="v24" data-v="24" data-xref="箴言 3:9; 申命記 18:4; 民數記 18:12–13"> 第四年，樹上的所有果子都是聖潔的，要獻給耶和華作頌讚之祭。</span>
<span className="v" id="v25" data-v="25" data-xref="哈該書 1:9–11; 瑪拉基書 3:8–10; 利未記 26:3–4"> 第五年，你們可以吃樹上的果子。你們這樣做，果樹會為你們結出更多果子。我是你們的上帝耶和華。</span>
<span className="v" id="v26" data-v="26" data-xref="申命記 18:10–14; 列王紀下 17:17; 歷代志下 33:6"> 「『不可吃帶血的肉，不可占卜或行巫術。</span>
<span className="v" id="v27" data-v="27" data-xref="利未記 21:5; 申命記 14:1; 以西結書 44:20"> 不可修剪鬢角或鬍鬚。</span>
<span className="v" id="v28" data-v="28" data-xref="申命記 14:1; 利未記 21:5; 列王紀上 18:28"> 不可因哀悼死人而割傷身體，也不可紋身。我是耶和華。</span>
<span className="v" id="v29" data-v="29" data-xref="申命記 23:17–18; 利未記 21:7; 何西阿書 4:12–14"> 不可辱沒自己的女兒，使她淪為娼妓，免得你們居住的地方充滿淫亂和邪惡。</span>
<span className="v" id="v30" data-v="30" data-xref="利未記 26:2; 利未記 19:3; 傳道書 5:1"> 要遵守我的安息日，敬畏我的聖所。我是耶和華。</span>
<span className="v" id="v31" data-v="31" data-xref="以賽亞書 8:19; 利未記 20:27; 利未記 20:6–7"> 不可求問靈媒或巫師，玷污自己。我是你們的上帝耶和華。</span>
<span className="v" id="v32" data-v="32" data-xref="提摩太前書 5:1; 耶利米哀歌 5:12; 箴言 16:31"> 「『在年長者面前，要恭敬站立，要敬重年長者。要敬畏你們的上帝。我是耶和華。</span>
<span className="v" id="v33" data-v="33" data-xref="出埃及記 23:9; 出埃及記 22:21; 瑪拉基書 3:5"> 不可欺負住在你們境內的外族人，</span>
<span className="v" id="v34" data-v="34" data-xref="申命記 10:19; 利未記 19:18; 出埃及記 12:48–49"> 要視他們如同胞，愛他們如愛自己，因為你們也曾經寄居埃及。我是你們的上帝耶和華。</span>
<span className="v" id="v35" data-v="35" data-xref="申命記 25:15; 申命記 25:13; 箴言 16:11"> 在稱重和度量時，不可欺詐。</span>
<span className="v" id="v36" data-v="36" data-xref="箴言 11:1; 出埃及記 20:2; 申命記 25:13–15"> 要使用準確的秤、尺子和升斗。我是你們的上帝耶和華，曾帶領你們離開埃及。</span>
<span className="v" id="v37" data-v="37" data-xref="申命記 8:1; 利未記 18:4–5; 申命記 5:1"> 你們要遵行我的一切律例和典章。我是耶和華。』」</span>
</div>

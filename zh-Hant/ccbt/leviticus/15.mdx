## 有關漏症患者的條例

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="阿摩司書 3:7; 利未記 13:1; 利未記 11:1"> 耶和華對摩西和亞倫說：</span>
<span className="v" id="v2" data-v="2" data-xref="民數記 5:2; 撒母耳記下 3:29; 利未記 22:4"> 「你們把以下條例告訴以色列人。<br />「如果有男人患了漏症，他下體的排洩物是不潔淨的。</span>
<span className="v" id="v3" data-v="3" data-xref="以西結書 23:20; 以西結書 16:26; 利未記 12:3"> 不論他下體的排洩物止住與否，他都是不潔淨的。</span>
<span className="v" id="v4" data-v="4" data-xref="提多書 1:15; 以弗所書 5:11; 哥林多前書 15:33"> 他睡過的床或坐過的東西都不潔淨。</span>
<span className="v" id="v5" data-v="5" data-xref="利未記 11:25; 利未記 16:26; 利未記 17:15"> 凡碰到他睡過的床的人都不潔淨，必須洗衣、沐浴，等到傍晚才能潔淨。</span>
<span className="v" id="v6" data-v="6" data-xref="雅各書 4:8; 以賽亞書 1:16"> 凡坐他坐過之物的人都不潔淨，必須洗衣、沐浴，等到傍晚才能潔淨。</span>
<span className="v" id="v7" data-v="7"> 凡碰到他的人都不潔淨，必須洗衣、沐浴，等到傍晚才能潔淨。</span>
<span className="v" id="v8" data-v="8" data-xref="猶大書 1:4; 彼得後書 2:1–3; 以賽亞書 1:16"> 如果他吐唾沫在一個潔淨的人身上，那人便不潔淨，必須洗衣、沐浴，等到傍晚才能潔淨。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 31:34"> 他騎過的鞍子是不潔淨的。</span>
<span className="v" id="v10" data-v="10" data-xref="雅各書 4:8; 詩篇 26:6; 利未記 15:8"> 凡碰到他坐過之物的人都不潔淨，要等到傍晚才能潔淨。碰到這些東西的人都不潔淨，必須洗衣、沐浴，等到傍晚才能潔淨。</span>
<span className="v" id="v11" data-v="11"> 如果他沒有洗手就碰到別人，那人便不潔淨，必須洗衣、沐浴，等到傍晚才能潔淨。</span>
<span className="v" id="v12" data-v="12" data-xref="利未記 6:28; 利未記 11:32–33; 哥林多後書 5:1"> 必須打碎他摸過的陶器，用水清洗他摸過的木器。</span>
<span className="v" id="v13" data-v="13" data-xref="利未記 14:8; 利未記 8:33; 利未記 15:28"> 他病癒後，必須經過七天的潔淨期，要洗淨衣服，用清水沐浴，這樣就潔淨了。</span>
<span className="v" id="v14" data-v="14" data-xref="利未記 12:8; 利未記 12:6; 希伯來書 10:10"> 第八天，他要把兩隻斑鳩或雛鴿帶到會幕門前，在耶和華面前交給祭司獻祭，</span>
<span className="v" id="v15" data-v="15" data-xref="利未記 14:30–31; 利未記 4:26; 馬太福音 3:17"> 一隻作贖罪祭，一隻作燔祭。這樣，祭司便在耶和華面前為他的漏症贖了罪。</span>
</div>
</div>

## 有關遺精的條例

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="申命記 23:10–11; 利未記 22:4; 利未記 15:5"> 「男人若遺精，便不潔淨，必須沐浴全身，等到傍晚才能潔淨。</span>
<span className="v" id="v17" data-v="17"> 沾了精液的衣物或皮革都不潔淨，必須用水清洗，等到傍晚才能潔淨。</span>
<span className="v" id="v18" data-v="18" data-xref="利未記 15:5; 帖撒羅尼迦前書 4:3–5; 哥林多前書 6:12"> 如果男女同房，二人都不潔淨，必須沐浴，等到傍晚才能潔淨。</span>
</div>
</div>

## 有關女人月經的條例

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="利未記 12:2; 馬太福音 15:19; 馬可福音 5:25"> 「女人在月經期間，要不潔淨七天。凡碰到她的人都不潔淨，要等到傍晚才能潔淨。</span>
<span className="v" id="v20" data-v="20" data-xref="利未記 15:4–9; 箴言 2:16–19; 箴言 6:35"> 月經期間，她躺過或坐過的東西都不潔淨。</span>
<span className="v" id="v21" data-v="21" data-xref="啟示錄 7:14; 哥林多後書 7:1; 以賽亞書 22:14"> 凡碰過她床的人都不潔淨，必須洗衣、沐浴，等到傍晚才能潔淨。</span>
<span className="v" id="v22" data-v="22"> 人若碰到她坐過的地方，也不潔淨，必須洗衣、沐浴，等到傍晚才能潔淨。</span>
<span className="v" id="v23" data-v="23"> 不論是她的床，還是她坐的東西，碰到的人都不潔淨，要等到傍晚才能潔淨。</span>
<span className="v" id="v24" data-v="24" data-xref="利未記 20:18; 彼得前書 2:11; 利未記 18:19"> 男人若與她同房，沾染了她的經血，就要不潔淨七天，他躺過的床也不潔淨。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="馬可福音 5:25; 馬太福音 9:20; 路加福音 8:43"> 「女人若在經期以外多日血漏或經期過長，在此期間便不潔淨，像在經期內一樣。</span>
<span className="v" id="v26" data-v="26"> 在血漏期間，她躺的床或坐的東西都不潔淨，像在經期內一樣。</span>
<span className="v" id="v27" data-v="27" data-xref="利未記 15:21; 希伯來書 10:22; 利未記 17:15–16"> 凡碰到這些東西的人都不潔淨，必須洗衣、沐浴，等到傍晚才能潔淨。</span>
<span className="v" id="v28" data-v="28" data-xref="利未記 15:13–15; 加拉太書 3:13; 以弗所書 1:6–7"> 血漏停止後，她要等七天才潔淨。</span>
<span className="v" id="v29" data-v="29"> 第八天，她要把兩隻斑鳩或雛鴿帶到會幕門口，交給祭司獻祭，</span>
<span className="v" id="v30" data-v="30"> 一隻作贖罪祭，一隻作燔祭。這樣，祭司便在耶和華面前為她贖了血漏的不潔之罪。</span>
<span className="v" id="v31" data-v="31" data-xref="民數記 19:20; 民數記 19:13; 以西結書 5:11"> 你們要使以色列人遠離不潔之物，免得他們因不潔而玷污我設在他們中間的聖幕，以致死亡。」</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="利未記 11:46; 利未記 13:59; 民數記 6:13"> 以上條例是為患漏症的人，包括遺精、</span>
<span className="v" id="v33" data-v="33" data-xref="利未記 15:19; 利未記 20:18; 利未記 15:24–25"> 行經的女人、患漏症的男女、與不潔淨女人同房的男人所設立的條例。</span>
</div>
</div>

</div>

## 獻平安祭的條例

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民數記 6:14; 利未記 1:3; 羅馬書 5:1–2"> 「如果有人用牛獻作平安祭，必須在耶和華面前獻上毫無殘疾的公牛或母牛。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 29:10; 利未記 1:4–5; 使徒行傳 2:36–38"> 獻祭者要把手放在祭牲的頭上，在會幕門口宰殺。做祭司的亞倫子孫要把牛血灑在祭壇四周。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 29:13; 利未記 4:8–9; 出埃及記 29:22"> 獻祭者要從平安祭中獻上火祭給耶和華。他要取出包裹內臟的脂肪和內臟上的脂肪、</span>
<span className="v" id="v4" data-v="4" data-xref="利未記 3:10; 利未記 8:25; 出埃及記 29:22"> 兩個腎臟和腎臟上靠近腰部的脂肪以及肝葉。</span>
<span className="v" id="v5" data-v="5" data-xref="利未記 6:12; 出埃及記 29:13; 彼得前書 2:5"> 亞倫的子孫要把這一切放在祭壇燃燒的木柴上和燔祭一起焚燒，作為蒙耶和華悅納的馨香火祭。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="提多書 2:11–12; 加拉太書 3:28; 利未記 1:2"> 「如果用羊作祭物向耶和華獻平安祭，必須獻毫無殘疾的公羊或母羊。</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀上 8:62; 以弗所書 5:12; 利未記 17:8–9"> 如果獻的是綿羊羔，獻祭者要把羊羔帶到耶和華面前，</span>
<span className="v" id="v8" data-v="8" data-xref="利未記 1:5; 以弗所書 3:12; 利未記 3:13"> 將手放在祭牲的頭上，在會幕前宰殺。亞倫的子孫要把羊羔的血灑在祭壇四周。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及記 29:22; 利未記 9:19; 利未記 8:25"> 獻祭者要從平安祭中取出脂肪作為火祭獻給耶和華。他要從靠近脊椎骨處取下整條肥尾巴、包裹內臟的脂肪、內臟上的脂肪、</span>
<span className="v" id="v10" data-v="10" data-xref="利未記 3:4"> 兩個腎臟和腎臟上靠近腰部的脂肪以及肝葉。</span>
<span className="v" id="v11" data-v="11" data-xref="利未記 21:17; 利未記 21:6; 利未記 3:16"> 祭司要把這一切放在祭壇上焚燒，作為獻給耶和華的火祭。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="利未記 9:15; 以賽亞書 53:2; 哥林多後書 5:21"> 「如果獻的是山羊，獻祭者要把山羊帶到耶和華面前，</span>
<span className="v" id="v13" data-v="13" data-xref="利未記 3:8; 羅馬書 5:15–21; 哥林多後書 5:21"> 將手放在羊頭上，在會幕門口宰殺。亞倫的子孫要把羊血灑在祭壇四周。</span>
<span className="v" id="v14" data-v="14" data-xref="馬太福音 26:38; 馬太福音 22:37; 利未記 3:9–11"> 獻祭者要取出包裹內臟的脂肪和內臟上的脂肪、兩個腎臟和腎臟上靠近腰部的脂肪以及肝葉，作為火祭獻給耶和華。</span>
<span className="v" id="v16" data-v="16" data-xref="利未記 7:23–25; 馬太福音 22:37; 以賽亞書 53:10"> 祭司要把這一切放在祭壇上焚燒，作為蒙耶和華悅納的馨香火祭。所有的脂肪都屬於耶和華。</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 9:4; 馬太福音 26:28; 申命記 15:23"> 你們無論住在哪裡，都不可吃脂肪和血，這是你們世代當守的永久律例。」</span>
</div>
</div>

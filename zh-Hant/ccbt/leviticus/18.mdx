## 禁止淫亂的條例

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華對摩西說：</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 6:7; 利未記 11:44; 以西結書 20:5"> 「你要告訴以色列人：我是你們的上帝耶和華。</span>
<span className="v" id="v3" data-v="3" data-xref="利未記 20:23; 出埃及記 23:24; 彼得前書 4:2–4"> 你們曾經住在埃及，但不可效法埃及人的行為。我要把你們帶到迦南，但你們不可效法迦南人的行為，不可隨從他們的風俗。</span>
<span className="v" id="v4" data-v="4" data-xref="利未記 18:2; 利未記 18:26; 以西結書 20:19"> 你們必須遵行我的典章，持守我的律例。我是你們的上帝耶和華。</span>
<span className="v" id="v5" data-v="5" data-xref="羅馬書 10:5; 以西結書 20:11; 加拉太書 3:12"> 你們要遵守我的典章和律例，遵行的人必因此而活。我是耶和華。</span>
<span className="v" id="v6" data-v="6" data-xref="利未記 20:17–21; 利未記 18:7–19; 利未記 20:11–12"> 「你們任何人不可與近親亂倫。我是耶和華。</span>
<span className="v" id="v7" data-v="7" data-xref="利未記 20:11; 以西結書 22:10; 利未記 18:8–16"> 不可與你母親亂倫而羞辱你父親。她是你的母親，不可與她亂倫。</span>
<span className="v" id="v8" data-v="8" data-xref="利未記 20:11; 哥林多前書 5:1; 申命記 27:20"> 不可與你父親的妻妾亂倫，那會羞辱你的父親。</span>
<span className="v" id="v9" data-v="9" data-xref="利未記 20:17; 申命記 27:22; 以西結書 22:11"> 不可與你的姊妹亂倫。不論是同父異母的，還是同母異父的，生長在同一家庭的，還是不同家庭的，都不可與她亂倫。</span>
<span className="v" id="v10" data-v="10"> 不可與孫女或外孫女亂倫，那會自取羞辱。</span>
<span className="v" id="v11" data-v="11"> 不可與你父親妻妾的女兒亂倫。她是你的姊妹，不可與她亂倫。</span>
<span className="v" id="v12" data-v="12" data-xref="利未記 20:19; 出埃及記 6:20"> 不可與姑母亂倫，她是你父親的至親。</span>
<span className="v" id="v13" data-v="13"> 不可與姨母亂倫，她是你母親的至親。</span>
<span className="v" id="v14" data-v="14" data-xref="利未記 20:20"> 不可與伯母或嬸母亂倫而羞辱你伯父或叔父，她是你的伯母或嬸母。</span>
<span className="v" id="v15" data-v="15" data-xref="利未記 20:12; 創世記 38:26; 以西結書 22:11"> 不可與兒媳亂倫。她是你兒子的妻子，不可與她亂倫。</span>
<span className="v" id="v16" data-v="16" data-xref="申命記 25:5; 利未記 20:21; 馬太福音 22:24"> 不可與兄嫂或弟媳亂倫，她是你兄弟的妻子，那會羞辱你的兄弟。</span>
<span className="v" id="v17" data-v="17" data-xref="利未記 20:14; 阿摩司書 2:7; 申命記 27:23"> 「不可與一個女人性交，又與她女兒性交，也不可與她孫女或外孫女性交。她們是她的近親。這都是邪惡行為。</span>
<span className="v" id="v18" data-v="18" data-xref="瑪拉基書 2:15; 創世記 30:15; 創世記 29:28"> 妻子還在世時，不可娶她姊妹並與她性交，使她們彼此作對。</span>
<span className="v" id="v19" data-v="19" data-xref="利未記 20:18; 利未記 15:24; 以西結書 22:10"> 女人在月經期間不潔淨，不可與她性交。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及記 20:14; 哥林多前書 6:9; 希伯來書 13:4"> 不可與鄰居的妻子性交，那會玷污自己。</span>
<span className="v" id="v21" data-v="21" data-xref="申命記 12:31; 利未記 20:2–5; 申命記 18:10"> 不可把兒女當作祭物獻給假神摩洛，不可褻瀆你上帝的名。我是耶和華。</span>
<span className="v" id="v22" data-v="22" data-xref="利未記 20:13; 羅馬書 1:26–27; 哥林多前書 6:9"> 男人不可與男人同寢，像和女人同寢一樣，這是可憎的。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及記 22:19; 利未記 20:15–16; 利未記 20:12"> 不可與獸類交合，玷污自己。女人也不可與獸類交合。這是變態行為。</span>
<span className="v" id="v24" data-v="24" data-xref="申命記 18:12; 利未記 18:30; 利未記 20:22–23"> 「你們不可做這些事玷污自己，因為我要在你們面前趕走的各國，正是因為這些行為而玷污了自己。</span>
<span className="v" id="v25" data-v="25" data-xref="利未記 18:28; 利未記 20:22–23; 耶利米書 2:7"> 他們居住的土地也都被玷污了，所以我因他們的罪惡而懲罰那片土地，我要使那片土地吐出其中的居民。</span>
<span className="v" id="v26" data-v="26" data-xref="利未記 18:5; 利未記 17:10; 利未記 18:30"> 你們必須遵守我的律例和典章。不論你們還是寄居在你們中間的外族人，都不可做這些可憎之事。</span>
<span className="v" id="v27" data-v="27" data-xref="歷代志下 36:14; 利未記 18:24; 申命記 23:18"> 因為在你們之前居住在那裡的人做了這些可憎之事，玷污了那片土地。</span>
<span className="v" id="v28" data-v="28" data-xref="啟示錄 3:16; 利未記 20:22; 利未記 18:25"> 如果你們玷污了那片土地，它也會像吐出從前的居民一樣把你們吐出去。</span>
<span className="v" id="v29" data-v="29" data-xref="利未記 20:6; 出埃及記 12:15; 利未記 17:10"> 凡做這些可憎之事的，要將他從民中剷除。</span>
<span className="v" id="v30" data-v="30" data-xref="利未記 20:23; 申命記 18:9–12; 利未記 22:9"> 你們要遵守我的命令，不要效法那片土地上居民的惡俗，以致玷污自己。我是你們的上帝耶和華。」</span>

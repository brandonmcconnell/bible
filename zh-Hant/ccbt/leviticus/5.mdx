<span className="v" id="v2" data-v="2" data-xref="利未記 5:17; 申命記 14:8; 哈該書 2:13"> 如果有人接觸了不潔淨之物，如不潔淨的野獸的屍體、家畜的屍體或爬蟲的屍體，即使沒有察覺也已不潔淨，是有罪的。</span>
<span className="v" id="v3" data-v="3" data-xref="民數記 19:11–16; 利未記 15:1–33; 利未記 12:1–8"> 如果有人無意中接觸了別人的不潔之物，當他意識到後，就有罪了。</span>
<span className="v" id="v4" data-v="4" data-xref="傳道書 5:2–6; 使徒行傳 23:12; 士師記 11:31"> 如果有人草率起誓，不論出於善意還是惡意，即使當初沒有察覺，後來才意識到，也是有罪的。</span>
<span className="v" id="v5" data-v="5" data-xref="箴言 28:13; 民數記 5:7; 利未記 26:40"> 如果有人意識到自己犯了以上任何一種罪，就必須認罪。</span>
<span className="v" id="v6" data-v="6" data-xref="利未記 4:28; 利未記 4:32; 利未記 4:20"> 為了贖過，他必須獻給耶和華一隻母綿羊或母山羊作贖罪祭。祭司要為他贖罪。</span>
<span className="v" id="v7" data-v="7" data-xref="利未記 12:8; 利未記 14:21–22; 馬太福音 3:16"> 「他若獻不起羊，就要獻給耶和華兩隻斑鳩或兩隻雛鴿，一隻作贖罪祭，一隻作燔祭。</span>
<span className="v" id="v8" data-v="8" data-xref="利未記 1:15; 利未記 1:17; 羅馬書 4:25"> 他要把牠們帶到祭司那裡，祭司要先用一隻鳥獻贖罪祭，要扭斷鳥脖子，但不可扯掉頭。</span>
<span className="v" id="v9" data-v="9" data-xref="利未記 4:30; 利未記 4:34; 利未記 4:18"> 要把一些鳥血灑在祭壇邊，再把剩下的血倒在壇腳。這是贖罪祭。</span>
<span className="v" id="v10" data-v="10" data-xref="利未記 1:14–17; 利未記 4:26; 利未記 4:20"> 祭司要依照獻燔祭的條例獻上另一隻鳥。這樣，祭司為他贖了罪，他就會得到赦免。</span>
<span className="v" id="v11" data-v="11" data-xref="民數記 5:15; 利未記 2:1–2; 出埃及記 16:36"> 「他若獻不起兩隻斑鳩或雛鴿，就要獻一公斤細麵粉作贖罪祭。細麵粉中不可澆油或加乳香，因為這是贖罪祭。</span>
<span className="v" id="v12" data-v="12" data-xref="利未記 4:35; 利未記 2:9; 利未記 2:2"> 他要把細麵粉帶到祭司那裡，祭司要從中取出一把作為象徵放在壇上，與獻給耶和華的火祭一起焚燒。這是贖罪祭。</span>
<span className="v" id="v13" data-v="13" data-xref="利未記 2:3; 利未記 4:26; 哥林多前書 9:13"> 這樣，祭司為他贖了罪，他就會得到赦免。剩下的細麵粉要歸祭司，像獻素祭一樣。」</span>

## 獻贖過祭的條例

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14"> 耶和華對摩西說：</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及記 30:13; 利未記 4:2; 利未記 6:6"> 「如果有人無意中干犯了耶和華聖物的條例，為了贖過，他要從羊群中選一隻毫無殘疾的公綿羊獻給耶和華，或按聖所的秤獻上同等價值的銀子。這是贖過祭。</span>
<span className="v" id="v16" data-v="16" data-xref="利未記 22:14; 民數記 5:7; 利未記 27:27"> 他要賠償所造成的損失，並加賠五分之一，要把這些都交給祭司。祭司要為他獻上公綿羊作贖過祭，為他贖罪，他就會得到赦免。</span>
<span className="v" id="v17" data-v="17" data-xref="利未記 4:27; 利未記 4:13; 利未記 4:2–4"> 「如果有人觸犯耶和華的任何誡命，即使他不知道，也是犯罪，必須擔當罪責。</span>
<span className="v" id="v18" data-v="18" data-xref="利未記 5:15–16; 提摩太前書 2:5–6; 利未記 1:4"> 他要從羊群中選一隻毫無殘疾的公綿羊，或把同等價值的銀子帶到祭司那裡作贖過祭。祭司要為他的無心之過贖罪，他就會得到赦免。</span>
<span className="v" id="v19" data-v="19" data-xref="詩篇 51:4; 瑪拉基書 3:8; 哥林多後書 5:19–21"> 這是贖過祭，因為他在耶和華面前確實有罪。」</span>
</div>
</div>

## 獻贖罪祭的條例

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華對摩西說：</span>
<span className="v" id="v2" data-v="2" data-xref="詩篇 19:12; 希伯來書 9:7; 利未記 4:27"> 「你把以下條例告訴以色列人。 「如果有人無意中犯罪，觸犯耶和華的任何誡命，要按以下方式獻贖罪祭。</span>
<span className="v" id="v3" data-v="3" data-xref="希伯來書 7:27–28; 利未記 4:14; 利未記 9:2"> 「若大祭司犯罪，禍及眾民，他必須獻給耶和華一頭毫無殘疾的公牛犢作贖罪祭。</span>
<span className="v" id="v4" data-v="4" data-xref="利未記 1:3–4; 但以理書 9:26; 以賽亞書 53:6"> 他要把公牛犢牽到會幕門口，將手放在牛頭上，在耶和華面前宰牛。</span>
<span className="v" id="v5" data-v="5" data-xref="利未記 16:14; 民數記 19:4; 利未記 4:16–17"> 他要取一些公牛的血帶進會幕裡，</span>
<span className="v" id="v6" data-v="6" data-xref="利未記 16:14; 利未記 14:18; 利未記 26:28"> 在耶和華面前用手指蘸血向聖所的幔子彈灑七次，</span>
<span className="v" id="v7" data-v="7" data-xref="利未記 8:15; 利未記 9:9; 利未記 16:18"> 也要把一些公牛的血抹在耶和華面前的香壇凸起的四角上，再把剩下的血倒在會幕門口的燔祭壇腳。</span>
<span className="v" id="v8" data-v="8" data-xref="利未記 3:3–5; 利未記 4:26; 利未記 4:31"> 他要取出作贖罪祭的公牛犢的所有脂肪，即包裹內臟的脂肪和內臟上的脂肪、</span>
<span className="v" id="v9" data-v="9" data-xref="利未記 3:4"> 兩個腎臟和腎臟上靠近腰部的脂肪以及肝葉，</span>
<span className="v" id="v10" data-v="10"> 正如取出平安祭牲的脂肪一樣。他要將這一切放在燔祭壇上焚燒。</span>
<span className="v" id="v11" data-v="11" data-xref="民數記 19:5; 出埃及記 29:14; 利未記 9:8–11"> 至於公牛剩下的部分，即皮、所有的肉、頭、腿、內臟和糞便，他要帶到營外潔淨之處，就是倒壇灰的地方，放在柴上焚燒。</span>
<span className="v" id="v13" data-v="13" data-xref="利未記 5:17; 利未記 5:2–5; 何西阿書 5:15"> 「以色列全體會眾若無意中觸犯耶和華的任何誡命，即使沒有意識到，也是犯罪。</span>
<span className="v" id="v14" data-v="14" data-xref="利未記 4:23; 利未記 4:3; 利未記 4:28"> 他們察覺自己犯罪後，必須獻上一頭公牛犢作贖罪祭。要將公牛犢帶到會幕前，</span>
<span className="v" id="v15" data-v="15" data-xref="利未記 1:4; 利未記 16:21; 利未記 8:14"> 會眾的長老要把手放在公牛的頭上，在耶和華面前宰牛。</span>
<span className="v" id="v16" data-v="16" data-xref="利未記 4:5–12; 希伯來書 9:12–14"> 大祭司要帶一些牛血進入會幕，</span>
<span className="v" id="v17" data-v="17" data-xref="利未記 4:6–7"> 在耶和華面前用手指蘸血向幔子彈灑七次，</span>
<span className="v" id="v18" data-v="18" data-xref="利未記 4:7"> 也要把一些血抹在耶和華面前的香壇凸起的四角上，再把剩下的血倒在會幕門前的燔祭壇腳。</span>
<span className="v" id="v19" data-v="19" data-xref="利未記 5:6; 利未記 4:26; 民數記 15:25"> 他要取出公牛犢的所有脂肪，放在祭壇上焚燒，</span>
<span className="v" id="v20" data-v="20" data-xref="民數記 15:25; 希伯來書 10:10–12; 利未記 12:8"> 正如取出贖罪祭牲的脂肪一樣。這樣，祭司為全體會眾贖了罪，他們就會得到赦免。</span>
<span className="v" id="v21" data-v="21" data-xref="利未記 16:15; 馬太福音 20:28; 哥林多後書 5:21"> 他要把這公牛犢剩下的部分拿到營外焚燒，像焚燒前一頭公牛犢一樣。這是為全體會眾所獻的贖罪祭。</span>
<span className="v" id="v22" data-v="22" data-xref="利未記 4:2; 利未記 4:13; 民數記 31:13"> 「首領若無意中觸犯他上帝耶和華的任何誡命，也是犯罪。</span>
<span className="v" id="v23" data-v="23" data-xref="利未記 4:14; 羅馬書 8:3; 民數記 7:22"> 他察覺自己犯罪後，必須獻上一隻毫無殘疾的公山羊作祭物。</span>
<span className="v" id="v24" data-v="24" data-xref="利未記 3:13; 利未記 7:2; 利未記 4:3–35"> 他要把手放在羊頭上，在殺燔祭牲的地方，在耶和華面前宰羊。這是他的贖罪祭。</span>
<span className="v" id="v25" data-v="25" data-xref="利未記 4:7; 利未記 4:18; 利未記 4:30"> 祭司要用手指蘸一些贖罪祭牲的血抹在燔祭壇凸起的四角上，再把剩下的血倒在燔祭壇腳。</span>
<span className="v" id="v26" data-v="26" data-xref="利未記 4:20; 利未記 4:31; 利未記 4:35"> 要像焚燒平安祭牲的脂肪一樣，把羊的所有脂肪都放在壇上焚燒。這樣，祭司為他贖了罪，他就會得到赦免。</span>
<span className="v" id="v27" data-v="27" data-xref="利未記 4:2; 民數記 15:27; 利未記 4:13"> 「平民若無意中觸犯耶和華的任何誡命，也是犯罪。</span>
<span className="v" id="v28" data-v="28" data-xref="利未記 4:23; 利未記 4:3; 利未記 4:32"> 他察覺自己犯罪後，必須獻上一隻毫無殘疾的母山羊作贖罪祭。</span>
<span className="v" id="v29" data-v="29" data-xref="利未記 4:4; 利未記 4:24; 利未記 1:4"> 他要把手放在贖罪祭牲的頭上，在殺燔祭牲的地方宰羊。</span>
<span className="v" id="v30" data-v="30" data-xref="利未記 4:7; 利未記 4:25; 利未記 4:34"> 祭司要用手指蘸一些羊血抹在燔祭壇凸起的四角上，再把剩下的血倒在燔祭壇腳。</span>
<span className="v" id="v31" data-v="31" data-xref="利未記 4:26; 利未記 4:35; 利未記 1:9"> 獻祭者要像取出平安祭牲的脂肪一樣，取出母山羊的所有脂肪。祭司要把這一切放在壇上焚燒，作為蒙耶和華悅納的馨香之祭。這樣，祭司為他贖了罪，他就會得到赦免。</span>
<span className="v" id="v32" data-v="32" data-xref="利未記 4:28; 彼得前書 3:18; 彼得前書 2:22"> 「他若獻綿羊作贖罪祭，必須獻一隻毫無殘疾的母綿羊。</span>
<span className="v" id="v33" data-v="33" data-xref="利未記 4:29–31; 利未記 4:4"> 他要把手放在羊頭上，在殺燔祭牲的地方宰羊。</span>
<span className="v" id="v34" data-v="34" data-xref="利未記 4:30; 利未記 4:25; 利未記 4:7"> 祭司要用手指蘸一些羊血抹在燔祭壇凸起的四角上，再把剩下的血倒在燔祭壇腳。</span>
<span className="v" id="v35" data-v="35" data-xref="利未記 4:26; 利未記 4:20; 利未記 14:18"> 獻祭者要像取出平安祭牲的脂肪一樣，取出母綿羊的所有脂肪。祭司要把這一切放在壇上，與獻給耶和華的祭物一起焚燒。這樣，祭司為他贖了罪，他就會得到赦免。</span>

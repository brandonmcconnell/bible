## 膏立亞倫父子們做祭司

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華對摩西說：</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 28:2–4; 出埃及記 39:41; 希伯來書 7:27"> 「你把亞倫父子們帶來，也要帶聖衣、膏油、一頭作贖罪祭的公牛、兩隻公綿羊和一籃無酵餅，</span>
<span className="v" id="v3" data-v="3" data-xref="歷代志下 30:13; 使徒行傳 2:1; 尼希米記 8:1"> 然後把全體會眾招聚到會幕門前。」</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及記 39:26; 出埃及記 39:7; 出埃及記 39:5"> 摩西按照耶和華的指示行事，會眾都聚集在會幕門前。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="出埃及記 29:4–37"> 摩西告訴會眾：「這是耶和華吩咐我做的事。」</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多前書 6:11; 以弗所書 5:26; 出埃及記 29:4"> 他把亞倫父子們帶來，用水洗他們。</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及記 28:4; 以賽亞書 61:10; 加拉太書 3:27"> 摩西給亞倫穿上內袍，束上腰帶，穿上外袍，套上以弗得，用精巧的帶子把以弗得繫在亞倫身上，</span>
<span className="v" id="v8" data-v="8" data-xref="以斯拉記 2:63; 帖撒羅尼迦前書 5:8; 以賽亞書 59:17"> 然後給他戴上胸牌，把烏陵和土明放在胸牌內，</span>
<span className="v" id="v9" data-v="9" data-xref="腓立比書 2:9–11; 撒迦利亞書 6:11–14; 出埃及記 28:36–38"> 再把禮冠戴在他頭上，在禮冠前繫上金牌，即聖冠，都遵照耶和華的吩咐。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="出埃及記 40:9–11; 利未記 8:2; 出埃及記 30:23–29"> 摩西拿膏油抹聖幕和聖幕裡的一切物件，使它們聖潔；</span>
<span className="v" id="v11" data-v="11" data-xref="提多書 3:6; 出埃及記 30:29; 出埃及記 16:19"> 再用膏油在祭壇上灑七次，又抹祭壇和祭壇上的器具、洗濯盆和盆座，使它們聖潔。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及記 30:30; 詩篇 133:2; 出埃及記 29:7"> 然後，摩西把膏油倒在亞倫頭上膏立他，使他聖潔。</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及記 29:8–9; 啟示錄 5:10; 啟示錄 1:6"> 摩西又把亞倫的兒子們帶來，給他們穿上內袍，束上腰帶，戴上頭巾，都遵照耶和華的吩咐。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="以西結書 43:19; 詩篇 66:15; 彼得前書 3:18"> 摩西牽來那頭作贖罪祭的公牛，亞倫父子們把手按在牛頭上。</span>
<span className="v" id="v15" data-v="15" data-xref="利未記 4:7; 希伯來書 9:18–23; 以西結書 43:19–27"> 摩西宰了牛，用手指蘸一些牛血抹在祭壇凸起的四角上，以潔淨祭壇，再把剩下的血倒在壇腳，使祭壇聖潔，為祭壇贖罪。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 29:13; 利未記 3:3–5; 利未記 4:8–9"> 他取出內臟上的脂肪、肝葉、兩個腎臟和腎臟上的脂肪，放在祭壇上燒掉，</span>
<span className="v" id="v17" data-v="17" data-xref="利未記 4:11–12; 出埃及記 29:14; 利未記 6:30"> 又照耶和華的吩咐，把公牛的皮、肉和糞便帶到營外燒掉。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="利未記 8:2; 利未記 1:4–13; 出埃及記 29:15–18"> 然後，摩西獻上作燔祭的公綿羊，亞倫父子們把手按在羊頭上。</span>
<span className="v" id="v19" data-v="19"> 摩西宰了那隻羊，把血灑在祭壇四周；</span>
<span className="v" id="v20" data-v="20" data-xref="利未記 1:8"> 把羊切成塊，焚燒羊頭、肉塊和脂肪；</span>
<span className="v" id="v21" data-v="21" data-xref="以弗所書 5:2; 出埃及記 29:18; 利未記 1:17"> 用水洗淨羊的內臟和腿，把整隻羊放在祭壇上焚燒，這是燔祭，作蒙耶和華悅納的馨香火祭，都遵照耶和華的吩咐。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="利未記 8:2; 利未記 8:29; 出埃及記 29:19–31"> 摩西獻上另一隻為授聖職而獻的公綿羊。亞倫父子們把手按在羊頭上。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及記 29:20; 利未記 14:14; 羅馬書 12:1"> 摩西宰了羊，將一些羊血抹在亞倫的右耳垂、右手大拇指和右腳大腳趾上。</span>
<span className="v" id="v24" data-v="24" data-xref="希伯來書 9:18–22"> 他又把亞倫的兒子們帶來，將一些血抹在他們的右耳垂、右手大拇指和右腳大腳趾上，然後把剩下的血都灑在祭壇四周。</span>
<span className="v" id="v25" data-v="25" data-xref="利未記 3:9; 利未記 3:3–5; 以賽亞書 53:10"> 他取下羊的脂肪、肥尾巴、內臟上的脂肪、肝葉、兩個腎臟、腎臟上的脂肪和右腿，</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及記 29:23; 提摩太前書 2:5; 使徒行傳 5:12"> 又從放在耶和華面前盛無酵餅的籃子裡取一個無酵餅、一個油餅和一個薄餅，放在羊的右腿和脂肪上。</span>
<span className="v" id="v27" data-v="27" data-xref="耶利米書 30:21; 希伯來書 9:14; 出埃及記 29:24–37"> 他把這些都放在亞倫父子們手中，作為搖祭在耶和華面前搖一搖。</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及記 29:25; 詩篇 22:13–14; 希伯來書 10:14–22"> 隨後，他從他們手上拿過這些祭物，放在祭壇的燔祭上焚燒，作為授聖職時獻的祭。這是蒙耶和華悅納的馨香火祭。</span>
<span className="v" id="v29" data-v="29" data-xref="哥林多前書 10:31; 彼得前書 4:11; 利未記 7:30–34"> 摩西又把公綿羊的胸肉作為搖祭，在耶和華面前搖一搖，這是他授聖職時所應得之份，都遵照耶和華的吩咐。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="出埃及記 29:21; 民數記 3:3; 出埃及記 30:30"> 摩西拿了一些膏油和壇上的血，灑在亞倫和他的衣服上，也灑在他兒子們和他們的衣服上，使亞倫父子們和他們的衣服聖潔。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="出埃及記 29:31–32; 加拉太書 2:20; 撒母耳記上 2:13–17"> 摩西對亞倫父子們說：「你們要照我的吩咐在會幕門口煮祭肉吃，也要吃籃子裡為授聖職而獻的餅。</span>
<span className="v" id="v32" data-v="32" data-xref="出埃及記 29:34; 出埃及記 12:10; 希伯來書 3:13–14"> 吃剩的肉和餅，你們要燒掉。</span>
<span className="v" id="v33" data-v="33" data-xref="出埃及記 29:35; 民數記 19:12; 以西結書 43:25–27"> 你們的授聖職禮歷時七天，這七天之內，你們不可離開會幕門口。</span>
<span className="v" id="v34" data-v="34" data-xref="希伯來書 7:27; 希伯來書 7:16; 希伯來書 10:11–12"> 今天所做的這一切都是耶和華吩咐的，是為你們贖罪。</span>
<span className="v" id="v35" data-v="35" data-xref="民數記 3:7; 申命記 11:1; 列王紀上 2:3"> 七天之內，你們必須日夜待在會幕門口，要遵守耶和華的吩咐，免得你們死亡。這是耶和華對我的吩咐。」</span>
<span className="v" id="v36" data-v="36" data-xref="申命記 12:32; 申命記 4:2; 出埃及記 40:16"> 於是，亞倫父子們遵行了耶和華藉摩西吩咐的一切。</span>
</div>
</div>

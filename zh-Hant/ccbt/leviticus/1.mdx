## 獻燔祭的條例

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及記 19:3; 出埃及記 25:22; 出埃及記 29:42"> 耶和華在會幕裡呼喚摩西，對他說：</span>
<span className="v" id="v2" data-v="2" data-xref="利未記 22:18–19; 羅馬書 12:6; 歷代志上 16:29"> 「你把以下條例告訴以色列人。<br />「如果你們有人獻祭給耶和華，要用牛羊作祭物。</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 15:21; 希伯來書 9:14; 利未記 22:19–24"> 如果用牛作燔祭，必須用毫無殘疾的公牛，在會幕門口獻上，便可蒙耶和華悅納。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及記 29:10; 出埃及記 29:15; 利未記 4:20"> 獻祭者要把手放在燔祭牲的頭上，所獻的燔祭便蒙悅納，為他贖罪。</span>
<span className="v" id="v5" data-v="5" data-xref="利未記 1:11; 利未記 3:8; 利未記 3:2"> 他要在耶和華面前宰牛，然後做祭司的亞倫子孫，要把牛血灑在會幕門口的祭壇四周。</span>
<span className="v" id="v6" data-v="6" data-xref="利未記 7:8; 創世記 3:21"> 獻祭者要剝掉燔祭牲的皮，把它切成塊。</span>
<span className="v" id="v7" data-v="7" data-xref="利未記 6:12–13; 創世記 22:9; 歷代志上 21:26"> 做祭司的亞倫子孫要在祭壇上生火，把木柴擺在火上，</span>
<span className="v" id="v8" data-v="8" data-xref="利未記 9:13–14; 利未記 1:12; 列王紀上 18:33"> 然後將肉塊、頭和脂肪都擺在祭壇燃燒的木柴上。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 8:21; 利未記 1:13; 以弗所書 5:2"> 獻祭者要用水洗淨牛的內臟和腿。祭司要把這一切都放在壇上焚燒。這是燔祭，是蒙耶和華悅納的馨香火祭。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="以賽亞書 53:6–7; 利未記 1:2–3; 創世記 8:20"> 「如果用綿羊或山羊作燔祭，必須用毫無殘疾的公羊。</span>
<span className="v" id="v11" data-v="11" data-xref="利未記 1:5; 出埃及記 40:22; 利未記 7:2"> 獻祭者要在祭壇北面，在耶和華面前宰羊。做祭司的亞倫子孫要把羊血灑在祭壇四周。</span>
<span className="v" id="v12" data-v="12"> 獻祭者將羊切成塊後，祭司要把肉塊、頭和脂肪擺在祭壇燃燒的木柴上。</span>
<span className="v" id="v13" data-v="13" data-xref="利未記 1:9"> 獻祭者要用水洗淨羊的內臟和腿。祭司要把這一切都放在壇上焚燒。這是燔祭，是蒙耶和華悅納的馨香火祭。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="利未記 5:7; 路加福音 2:24; 利未記 12:8"> 「如果有人用鳥作燔祭獻給耶和華，要用斑鳩或雛鴿。</span>
<span className="v" id="v15" data-v="15" data-xref="利未記 5:8–9; 詩篇 22:21; 約翰一書 2:27"> 祭司要把鳥帶到祭壇前，擰下鳥頭，放在祭壇上焚燒；要在祭壇旁放盡鳥血；</span>
<span className="v" id="v16" data-v="16" data-xref="彼得前書 1:2; 路加福音 1:35; 利未記 16:27"> 要除掉鳥的嗉子和羽毛，扔在祭壇東邊倒灰的地方。</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 15:10; 約翰福音 19:30; 利未記 1:9–10"> 祭司要抓著兩個翅膀把鳥撕開，但不可撕斷，然後把鳥放在祭壇燃燒的木柴上焚燒。這是燔祭，是蒙耶和華悅納的馨香火祭。</span>
</div>

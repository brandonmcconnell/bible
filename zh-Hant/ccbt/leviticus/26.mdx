## 遵行誡命蒙祝福

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="利未記 19:4; 申命記 27:15; 民數記 33:52"> 「你們不可為自己製造偶像，不可豎立神像和神柱，也不可在你們境內安放祭拜用的石像。我是你們的上帝耶和華。</span>
<span className="v" id="v2" data-v="2" data-xref="利未記 19:30"> 你們要守我的安息日，敬畏我的聖所。我是耶和華。</span>
<span className="v" id="v3" data-v="3" data-xref="以賽亞書 1:19; 申命記 11:13–15; 申命記 28:1–14"> 如果你們遵行我的律例，謹守我的誡命，</span>
<span className="v" id="v4" data-v="4" data-xref="撒迦利亞書 8:12; 詩篇 67:6; 利未記 25:21"> 我就按時降雨給你們，使土地長出莊稼、田間果樹結出果實。</span>
<span className="v" id="v5" data-v="5" data-xref="阿摩司書 9:13; 約珥書 2:26; 約珥書 2:19"> 你們要打糧食打到摘葡萄的時候，摘葡萄摘到播種的時候。你們必豐衣足食，安然居住。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="以賽亞書 35:9; 西番雅書 3:13; 詩篇 147:14"> 「我要使你們境內太平，安枕無憂。我要除掉你們境內的猛獸，也要使你們免遭刀劍之災。</span>
<span className="v" id="v7" data-v="7"> 你們將追趕仇敵，使他們倒在你們刀下。</span>
<span className="v" id="v8" data-v="8" data-xref="約書亞記 23:10; 申命記 28:7; 申命記 32:30"> 你們五人要追趕一百人，一百人要追趕一萬人，他們必死在你們刀下。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 17:6–7; 尼希米記 9:23; 以西結書 16:62"> 我要眷顧你們，使你們生養眾多，人丁興旺，也要堅守與你們所立的約。</span>
<span className="v" id="v10" data-v="10" data-xref="利未記 25:22; 列王紀下 19:29; 路加福音 12:17"> 你們存糧充足，甚至要搬出陳糧來儲存新糧。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及記 25:8; 啟示錄 21:3; 出埃及記 29:45"> 我要住在你們中間，我必不厭棄你們。</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多後書 6:16; 耶利米書 30:22; 耶利米書 7:23"> 我要走在你們中間。我要做你們的上帝，你們要做我的子民。</span>
<span className="v" id="v13" data-v="13" data-xref="以西結書 34:27; 利未記 25:38; 詩篇 116:16"> 我是你們的上帝耶和華。我曾帶領你們離開埃及，使你們不再做埃及人的奴隸。我打碎了你們身上的重軛，使你們昂首前行。</span>
</div>
</div>

## 違背誡命受懲罰

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="申命記 28:15–68; 利未記 26:18; 耶利米書 17:27"> 「如果你們不聽從我，不遵行我的這一切誡命；</span>
<span className="v" id="v15" data-v="15" data-xref="列王紀下 17:15; 申命記 31:16; 撒迦利亞書 7:11–13"> 如果你們棄絕我的律例，厭棄我的典章，不聽從我的命令，破壞我與你們所立的約，</span>
<span className="v" id="v16" data-v="16" data-xref="約伯記 31:8; 耶利米書 5:17; 彌迦書 6:15"> 我要懲罰你們，使你們陷入恐慌、患癆病和熱症，使你們眼睛昏花、心力衰竭。你們撒種卻一無所獲，因為敵人要吃盡你們所種的。</span>
<span className="v" id="v17" data-v="17" data-xref="利未記 17:10; 箴言 28:1; 詩篇 53:5"> 我要嚴懲你們，使你們敗在敵人手下；你們要被那些恨你們的人統治，即使沒有人追趕，你們也要逃命。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="利未記 26:21; 利未記 26:28; 利未記 26:24"> 「如果你們經歷這些後，仍然不聽從我，我要使你為罪多受七倍的懲罰。</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 28:23; 列王紀上 17:1; 但以理書 4:37"> 我要重挫你們的傲氣，使你們頭上的天如鐵，腳下的地如銅。</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 127:1; 申命記 11:17; 以賽亞書 49:4"> 你們勞作也是徒然，因為你們的土地必不長莊稼，果樹也不結果實。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="利未記 26:18; 利未記 26:27"> 「如果你們仍然與我作對，不肯聽從我，我要用七倍的災難懲治你們的罪。</span>
<span className="v" id="v22" data-v="22" data-xref="以西結書 14:15; 申命記 32:24; 士師記 5:6"> 我要讓野獸攻擊你們，殘害你們的子女，吞噬你們的牲畜，使你們人口銳減，道路荒涼。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="耶利米書 5:3; 耶利米書 2:30; 阿摩司書 4:6–12"> 「如果你們還是不服管教，繼續與我作對，</span>
<span className="v" id="v24" data-v="24" data-xref="詩篇 18:26; 撒母耳記下 22:27; 約伯記 9:4"> 我也要與你們作對，用七倍的災難懲治你們的罪。</span>
<span className="v" id="v25" data-v="25" data-xref="民數記 14:12; 以西結書 5:17; 耶利米書 29:17–18"> 因為你們毀約，我要用戰禍報應你們。你們躲進各城的時候，我要在你們中間降下瘟疫，使你們落在敵人手裡。</span>
<span className="v" id="v26" data-v="26" data-xref="彌迦書 6:14; 以賽亞書 3:1; 詩篇 105:16"> 我要斷絕你們的糧源。那時候，十個婦女將用一個烤爐烤餅，按定量分餅給你們，你們吃卻吃不飽。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="利未記 26:24; 利未記 26:21"> 「如果你們仍然不肯聽從我，繼續與我作對，</span>
<span className="v" id="v28" data-v="28" data-xref="以賽亞書 59:18; 耶利米書 21:5; 以賽亞書 66:15"> 我也要與你們作對，向你們發烈怒，把比先前嚴厲七倍的懲罰加在你們身上。</span>
<span className="v" id="v29" data-v="29" data-xref="以西結書 5:10; 耶利米哀歌 4:10; 馬太福音 24:19"> 你們要吃自己兒女的肉。</span>
<span className="v" id="v30" data-v="30" data-xref="列王紀下 23:20; 以賽亞書 27:9; 以西結書 6:13"> 我要毀滅你們的邱壇，拆掉你們的香壇，把你們的屍體堆在你們的死偶像上。我必厭惡你們。</span>
<span className="v" id="v31" data-v="31" data-xref="尼希米記 2:3; 耶利米哀歌 1:10; 希伯來書 10:26"> 我要使你們的城邑淪為廢墟，使你們的敬拜場所荒涼，也不再悅納你們的馨香之祭。</span>
<span className="v" id="v32" data-v="32" data-xref="耶利米書 9:11; 耶利米書 19:8; 耶利米書 18:16"> 我要使你們的土地荒廢，連佔據那裡的敵人也為此而震驚。</span>
<span className="v" id="v33" data-v="33" data-xref="撒迦利亞書 7:14; 以西結書 20:23; 申命記 28:64–66"> 我要把你們驅散到各國，還要拔刀追殺你們。你們的土地將荒廢，城邑將淪為廢墟。</span>
<span className="v" id="v34" data-v="34" data-xref="歷代志下 36:21; 利未記 26:43; 利未記 25:2–4"> 你們被擄到敵國的時候，你們的土地將荒廢，享受安息。那時土地必休息，享受安息。</span>
<span className="v" id="v35" data-v="35" data-xref="以賽亞書 24:5–6; 羅馬書 8:22"> 你們住在那裡的時候，沒有在安息年讓土地安息，因此土地在荒廢的日子裡將享受安息。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="以西結書 21:7; 以賽亞書 30:17; 利未記 26:17"> 「我要使你們當中的那些倖存者在敵國心驚膽戰，過著風聲鶴唳、惶恐不安的生活。</span>
<span className="v" id="v37" data-v="37" data-xref="約書亞記 7:12–13; 士師記 2:14; 耶利米書 37:10"> 即使無人追趕，他們也將倉皇逃命，互相絆倒，如同躲避刀劍一樣。你們必無力抵擋敵人。</span>
<span className="v" id="v38" data-v="38" data-xref="申命記 28:48; 以賽亞書 27:13; 耶利米書 42:17–18"> 你們將葬身列國，死在敵人的土地上。</span>
<span className="v" id="v39" data-v="39" data-xref="以西結書 4:17; 以西結書 24:23; 以西結書 33:10"> 你們當中的倖存者將因自己的罪和祖先的罪而消亡在敵人的土地上。</span>
</div>
</div>

## 認罪悔改蒙眷顧

<div className="bt">
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="箴言 28:13; 尼希米記 9:2–5; 約翰一書 1:8–10"> 「如果他們承認自己和祖先的罪，就是背叛我、與我作對的惡行，</span>
<span className="v" id="v41" data-v="41" data-xref="以西結書 44:7; 歷代志下 32:26; 歷代志下 12:6–7"> 以致我與他們作對，把他們流放到敵國；如果他們頑固<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「頑固」希伯來文是「未受割禮」。">a</a></sup>的心謙卑下來，甘願為罪受罰，</span>
<span className="v" id="v42" data-v="42" data-xref="詩篇 106:45; 出埃及記 6:5; 以西結書 16:60"> 我便顧念我與亞伯拉罕、以撒和雅各所立的約，眷顧那片土地。</span>
<span className="v" id="v43" data-v="43" data-xref="羅馬書 8:7; 利未記 26:15; 約翰福音 7:7"> 土地被他們離棄，荒無人煙，得享安息。他們卻要因拒絕遵守我的典章、厭棄我的律例而飽受懲罰。</span>
<span className="v" id="v44" data-v="44" data-xref="羅馬書 11:2; 尼希米記 9:31; 申命記 4:29–31"> 然而，他們流落敵國的時候，我不會棄絕他們，不會因厭惡而毀滅他們，也不會違背我與他們所立的約。我是他們的上帝耶和華。</span>
<span className="v" id="v45" data-v="45" data-xref="利未記 25:38; 以西結書 20:22; 以西結書 20:9"> 為了他們的緣故，我必顧念我與他們祖先所立的約。我曾在列國面前帶領他們的祖先離開埃及，為要做他們的上帝。我是耶和華。」</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="利未記 27:34; 申命記 12:1; 申命記 6:1"> 以上是耶和華藉摩西在西奈山上頒佈給以色列人的律例、典章和法度。</span>
</div>
</div>

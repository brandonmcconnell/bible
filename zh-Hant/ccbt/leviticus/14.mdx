## 痲瘋病患者的潔淨條例

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華對摩西說：</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 17:14; 路加福音 5:12–14; 馬可福音 1:40–44"> 「以下是有關痲瘋病患者的潔淨條例。<br />「痲瘋病患者痊癒後，要被帶到祭司那裡。</span>
<span className="v" id="v3" data-v="3" data-xref="利未記 13:46; 路加福音 7:22; 路加福音 17:15–19"> 祭司要到營外去檢查，如果發現他的病已痊癒，</span>
<span className="v" id="v4" data-v="4" data-xref="民數記 19:6; 利未記 14:6; 希伯來書 9:19"> 要吩咐人為他拿來兩隻潔淨的活鳥、香柏木、朱紅色線和牛膝草。</span>
<span className="v" id="v5" data-v="5" data-xref="利未記 14:50; 希伯來書 2:14; 哥林多後書 5:1"> 祭司要吩咐人在一個盛清水的陶器上宰殺一隻鳥，</span>
<span className="v" id="v6" data-v="6" data-xref="啟示錄 1:5; 撒迦利亞書 13:1; 腓立比書 2:9–11"> 然後祭司要把另一隻鳥，連同香柏木、朱紅色線和牛膝草一起蘸在摻了清水的鳥血裡。</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀下 5:14; 以西結書 36:25; 以賽亞書 52:15"> 祭司要用鳥血在他身上灑七次，宣佈他是潔淨的，然後放走那隻活鳥，讓牠飛向田野。</span>
<span className="v" id="v8" data-v="8" data-xref="利未記 11:25; 民數記 8:7; 彼得前書 3:21"> 他要洗淨衣服，剃去所有毛髮，沐浴之後便潔淨了，可以回到營內，但要住在自己的帳篷外七天。</span>
<span className="v" id="v9" data-v="9" data-xref="民數記 6:9; 利未記 14:8; 民數記 8:7"> 第七天，他要再次剃掉頭髮、鬍鬚和眉毛等各處毛髮，並洗衣、沐浴，之後便潔淨了。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="利未記 2:1; 馬太福音 8:4; 路加福音 5:14"> 「第八天，他要帶來兩隻毫無殘疾的公羊羔、一隻毫無殘疾的一歲母羊羔、三公斤作素祭的調油的細麵粉和一杯油。</span>
<span className="v" id="v11" data-v="11" data-xref="以弗所書 5:26–27; 出埃及記 29:1–4; 民數記 8:21"> 主持潔淨禮的祭司要把他及其祭物帶到會幕門口、耶和華面前，</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及記 29:24; 利未記 6:6–7; 利未記 8:27–29"> 並獻上一隻公羊羔和一杯油作贖過祭，作為搖祭在耶和華面前搖一搖。</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及記 29:11; 利未記 1:11; 利未記 4:24"> 他要在殺贖罪祭牲和燔祭牲的聖潔之處宰公羊羔。贖過祭的祭物要歸祭司，像贖罪祭一樣，這是至聖之物。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及記 29:20; 利未記 8:23–24; 哥林多後書 7:1"> 祭司要拿一些贖過祭祭牲的血抹在求潔淨者的右耳垂、右手大拇指和右腳大腳趾上。</span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 45:7; 約翰福音 3:34; 約翰一書 2:20"> 祭司要拿那杯油，倒一些在自己左手掌中，</span>
<span className="v" id="v16" data-v="16" data-xref="利未記 4:17; 哥林多前書 10:31; 利未記 4:6"> 用右手手指蘸左手掌裡的油，在耶和華面前彈灑七次，</span>
<span className="v" id="v17" data-v="17" data-xref="彼得前書 1:2; 以西結書 36:27; 利未記 14:14"> 然後用手掌中剩下的油抹求潔淨者的右耳垂、右手大拇指和右腳大腳趾，就是抹了贖過祭祭牲血的地方。</span>
<span className="v" id="v18" data-v="18" data-xref="利未記 4:26; 哥林多後書 1:21–22; 以弗所書 1:17–18"> 祭司要把手掌裡剩下的油抹在求潔淨者的頭上。這樣，祭司在耶和華面前為他贖了罪。</span>
<span className="v" id="v19" data-v="19" data-xref="利未記 14:12; 利未記 5:1; 利未記 12:6–8"> 祭司要獻上贖罪祭，為求潔淨者贖罪。然後，祭司要宰殺燔祭牲，</span>
<span className="v" id="v20" data-v="20" data-xref="利未記 14:10; 以弗所書 5:2; 利未記 14:8"> 在祭壇上獻燔祭和素祭，為他贖罪，他就潔淨了。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="利未記 5:7; 利未記 12:8; 箴言 17:5"> 「他如果貧窮，獻不起那麼多祭物，可以獻一隻公羊羔作贖過祭，用搖祭的方式贖罪；也要獻一公斤作素祭的調油的細麵粉和一杯油；</span>
<span className="v" id="v22" data-v="22" data-xref="以西結書 7:16; 以賽亞書 59:11; 耶利米書 48:28"> 還要按自己的能力獻兩隻斑鳩或雛鴿，一隻作贖罪祭，一隻作燔祭。</span>
<span className="v" id="v23" data-v="23" data-xref="利未記 14:10–11"> 第八天，他必須把這些祭物帶到會幕門口，在耶和華面前交給祭司，好使自己潔淨。</span>
<span className="v" id="v24" data-v="24" data-xref="利未記 14:12; 利未記 14:10"> 祭司要用作贖過祭的羊羔和一杯油作搖祭，在耶和華面前搖一搖。</span>
<span className="v" id="v25" data-v="25" data-xref="傳道書 5:1; 詩篇 40:6; 利未記 14:14–20"> 接著，祭司要宰殺作贖過祭的羊羔，拿一些羊血抹在求潔淨者的右耳垂、右手大拇指和右腳大腳趾上。</span>
<span className="v" id="v26" data-v="26"> 祭司也要把一些油倒在自己左手掌中，</span>
<span className="v" id="v27" data-v="27"> 用一根右手指蘸左手掌中的油，在耶和華面前彈灑七次，</span>
<span className="v" id="v28" data-v="28"> 然後把手掌中的一些油抹在求潔淨者的右耳垂、右手大拇指和右腳大腳趾上，就是抹了贖過祭祭牲血的地方。</span>
<span className="v" id="v29" data-v="29" data-xref="利未記 14:18; 約翰一書 2:1–2; 出埃及記 30:15–16"> 祭司要把手掌裡剩下的油抹在求潔淨者的頭上，在耶和華面前為他贖罪。</span>
<span className="v" id="v30" data-v="30" data-xref="利未記 14:22; 羅馬書 8:3; 利未記 12:8"> 然後獻上那人按自己能力帶來的兩隻斑鳩或雛鴿，</span>
<span className="v" id="v31" data-v="31" data-xref="利未記 14:18; 利未記 5:7"> 一隻作贖罪祭，一隻作燔祭，和素祭一起獻上。這樣，祭司在耶和華面前為求潔淨者贖了罪。</span>
<span className="v" id="v32" data-v="32" data-xref="利未記 14:10; 利未記 14:21; 馬太福音 11:5"> 這是獻不起潔淨禮所需祭物的痲瘋病患者應當遵守的條例。」</span>
</div>
</div>

## 處理房子發黴的條例

<div className="bt">
<div className="bp">
<span className="v" id="v33" data-v="33"> 耶和華對摩西和亞倫說：</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="申命記 32:49; 創世記 17:8; 民數記 32:22"> 「你們到了我賜給你們作產業的迦南以後，如果我使那裡的房屋中有發黴現象，</span>
<span className="v" id="v35" data-v="35" data-xref="詩篇 91:10; 申命記 7:26; 撒迦利亞書 5:4"> 屋主必須去告訴祭司，『我的房子裡好像有發黴現象。』</span>
<span className="v" id="v36" data-v="36" data-xref="啟示錄 18:4; 希伯來書 12:15; 提摩太後書 2:17–18"> 祭司進去檢查前，要吩咐人把房子騰空，免得房子裡的一切都變得不潔淨。之後，祭司要進去檢查，</span>
<span className="v" id="v37" data-v="37" data-xref="利未記 13:42; 利未記 13:3; 利未記 13:19–20"> 如發現牆壁上出現紅色或綠色黴斑，並且侵入牆中，</span>
<span className="v" id="v38" data-v="38" data-xref="利未記 13:50"> 祭司就要從房門出來，把房子封閉七天。</span>
<span className="v" id="v39" data-v="39" data-xref="利未記 13:36; 利未記 13:27; 利未記 13:22"> 第七天，祭司要回去檢查。若發現牆壁上的黴斑蔓延，</span>
<span className="v" id="v40" data-v="40" data-xref="啟示錄 2:20; 提多書 3:10; 哥林多前書 5:5–6"> 就要下令拆掉有黴斑的石塊，丟到城外不潔淨的地方，</span>
<span className="v" id="v41" data-v="41" data-xref="以賽亞書 65:4; 啟示錄 22:15; 馬太福音 24:51"> 然後命人刮掉屋內牆壁上的灰泥，倒在城外不潔淨的地方。</span>
<span className="v" id="v42" data-v="42" data-xref="提摩太後書 2:2; 提摩太前書 5:21–22; 歷代志下 17:7–9"> 要另找石塊補被拆掉的地方，並用灰泥重新粉刷房子。</span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="耶利米書 6:28–30; 猶大書 1:12; 彼得後書 2:20"> 「如果拆掉石塊、刮掉灰泥、重新粉刷以後，房子再度出現黴斑，</span>
<span className="v" id="v44" data-v="44" data-xref="利未記 13:51–52; 撒迦利亞書 5:4"> 祭司要去檢查，若發現黴斑已蔓延，就是惡性黴變，那房子就不潔淨。</span>
<span className="v" id="v45" data-v="45" data-xref="列王紀下 10:27; 馬太福音 24:2; 列王紀上 9:6–9"> 房主要拆掉房子，把石塊、木料和所有灰泥都丟到城外不潔淨的地方。</span>
<span className="v" id="v46" data-v="46" data-xref="民數記 19:21–22; 利未記 22:6; 利未記 11:28"> 房子封閉期間，任何人進去，都不潔淨，要等到傍晚才能潔淨。</span>
<span className="v" id="v47" data-v="47" data-xref="利未記 14:8–9; 利未記 11:25"> 凡在房內睡覺或吃飯的人，都必須洗淨衣服。</span>
</div>
<div className="bp">
<span className="v" id="v48" data-v="48" data-xref="哥林多前書 6:11; 約伯記 5:18; 馬可福音 5:29"> 「祭司檢查粉刷後的房子，若發現房內沒有再度出現黴斑，就要宣佈房子是潔淨的，因為黴斑已消失。</span>
<span className="v" id="v49" data-v="49" data-xref="利未記 14:4"> 為潔淨房子，祭司要取兩隻鳥、香柏木、朱紅色線和牛膝草，</span>
<span className="v" id="v50" data-v="50"> 在一個盛清水的陶器上宰殺一隻鳥，</span>
<span className="v" id="v51" data-v="51" data-xref="詩篇 51:7"> 然後用香柏木、牛膝草、朱紅色線和另一隻活鳥，蘸摻了清水的鳥血，向房子灑七次。</span>
<span className="v" id="v52" data-v="52"> 祭司用鳥血、清水、活鳥、香柏木、牛膝草和朱紅色線潔淨那房子後，</span>
<span className="v" id="v53" data-v="53" data-xref="利未記 14:20; 利未記 14:7"> 要放走那隻活鳥，讓牠飛到城外的田野。這樣，祭司為那房子贖了罪，房子就潔淨了。」</span>
</div>
<div className="bp">
<span className="v" id="v54" data-v="54" data-xref="利未記 15:32; 利未記 14:32; 利未記 6:9"> 以上條例是有關痲瘋病、疥癬、</span>
<span className="v" id="v55" data-v="55" data-xref="利未記 13:47–59"> 衣物或房子發黴、</span>
<span className="v" id="v56" data-v="56" data-xref="利未記 13:2"> 腫包、皮疹或白斑的條例。</span>
<span className="v" id="v57" data-v="57" data-xref="利未記 10:10; 以西結書 44:23; 耶利米書 15:19"> 根據這些條例，可以分辨有關的人或物何時潔淨、何時不潔淨。</span>
</div>
</div>

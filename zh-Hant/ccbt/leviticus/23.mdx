## 安息日

<div className="bt">
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="利未記 19:3; 出埃及記 23:12; 出埃及記 35:2–3"> 「你們一週可以工作六天，但第七天是完全休息的安息日，你們要舉行聖會。不可做任何工，無論你們住在哪裡，都要守耶和華的安息日。</span>
<span className="v" id="v4" data-v="4" data-xref="利未記 23:2; 出埃及記 23:14; 利未記 23:37"> 「以下是耶和華所定的節期，你們要在這些日子召開聖會。</span>
</div>

## 逾越節和除酵節

<div className="bt">
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="約書亞記 5:10; 申命記 16:1–8; 民數記 28:16–17"> 「從一月十四日傍晚開始是耶和華的逾越節。</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及記 34:18; 申命記 16:8; 出埃及記 12:15–16"> 從一月十五日開始是耶和華的除酵節，你們要連續七天吃無酵餅。</span>
<span className="v" id="v7" data-v="7" data-xref="民數記 28:18–25; 利未記 23:8; 利未記 23:21"> 在除酵節的第一天，你們要舉行聖會，不可做日常工作。</span>
<span className="v" id="v8" data-v="8"> 一連七天你們要獻火祭給耶和華。第七天，你們要舉行聖會，不可做日常工作。」</span>
</div>
</div>

## 初熟節

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9"> 耶和華對摩西說：</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及記 34:26; 出埃及記 23:19; 申命記 16:9"> 「你把以下條例告訴以色列人。 「你們進入耶和華將要賜給你們的那片土地以後，每逢收割莊稼之時，你們要帶一捆初熟的穀物交給祭司。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及記 29:24; 利未記 10:14; 利未記 9:21"> 祭司要在安息日後第一天把那捆穀物在耶和華面前搖一搖，你們所獻的就會得到悅納。</span>
<span className="v" id="v12" data-v="12" data-xref="希伯來書 10:10–12; 彼得前書 1:19; 利未記 1:10"> 在獻穀物那天，你們要獻給耶和華一隻毫無殘疾、一歲的公羊羔作燔祭，</span>
<span className="v" id="v13" data-v="13" data-xref="利未記 2:14–16; 約珥書 1:9; 民數記 28:10"> 同時要把兩公斤調油的細麵粉作素祭，一起獻給耶和華作馨香的火祭，也要獻一升酒作奠祭。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及記 34:26; 創世記 4:4–5; 利未記 3:17"> 你們必須先將這些供物獻給你們的上帝後，才可以吃餅、烘烤的穀物和新鮮穗子。不論住在哪裡，這是你們世代當守的永久律例。</span>
</div>
</div>

## 五旬節

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="利未記 23:10–11; 利未記 25:8; 申命記 16:9–10"> 「從安息日後第一天，即你們獻上搖祭的那天算起，你們要數整整七週，</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行傳 2:1; 民數記 28:26"> 一直數到第七個安息日後的第一天，共五十天。到那天，你們要把新收的穀物作為素祭獻給耶和華。</span>
<span className="v" id="v17" data-v="17" data-xref="利未記 23:10; 出埃及記 34:26; 出埃及記 34:22"> 你們要用兩公斤細麵粉加上酵，烤成兩個餅作搖祭，從你們居住的地方帶來獻給耶和華作初熟之祭。</span>
<span className="v" id="v18" data-v="18" data-xref="民數記 28:27–31; 利未記 23:12–13; 瑪拉基書 1:13–14"> 你們要把七隻毫無殘疾的一歲公羊羔、一頭公牛犢、兩隻公綿羊和那兩個餅，一起獻給耶和華作燔祭。這些一起獻上的燔祭、素祭和奠祭，是蒙耶和華悅納的馨香火祭。</span>
<span className="v" id="v19" data-v="19" data-xref="民數記 28:30; 利未記 4:23–28; 利未記 7:11–18"> 你們也要獻一隻公山羊作贖罪祭，兩隻一歲的公綿羊作平安祭。</span>
<span className="v" id="v20" data-v="20" data-xref="申命記 18:4; 以弗所書 2:14; 民數記 18:8–12"> 祭司要把這兩隻公綿羊和初熟之物做的餅作為搖祭，在耶和華面前搖一搖。這些是獻給耶和華的聖物，歸祭司所有。</span>
<span className="v" id="v21" data-v="21" data-xref="利未記 23:2; 利未記 23:4; 民數記 18:23"> 你們要在那天召開聖會，不可做日常工作。不論住在哪裡，這是你們世代當守的永久律例。</span>
<span className="v" id="v22" data-v="22" data-xref="申命記 24:19–21; 利未記 19:9–10; 以賽亞書 58:10"> 你們收割時，不可割盡田角地邊的莊稼，也不可撿落在地裡的，要把這些留給窮人和外族人。我是你們的上帝耶和華。」</span>
</div>
</div>

<div className="bt">
<div className="bp">

## 贖罪日

<div className="bt">
<div className="bp">
<span className="v" id="v26" data-v="26"> 耶和華對摩西說：</span>
<span className="v" id="v27" data-v="27" data-xref="利未記 16:29–31; 出埃及記 30:10; 利未記 16:24"> 「七月十日是贖罪日，你們要舉行聖會，禁食，獻火祭給耶和華。</span>
<span className="v" id="v28" data-v="28" data-xref="撒迦利亞書 3:9; 利未記 16:34; 希伯來書 10:10"> 那是在你們的上帝耶和華面前為自己贖罪的日子，你們不可工作。</span>
<span className="v" id="v29" data-v="29" data-xref="創世記 17:14; 民數記 5:2; 利未記 23:27"> 那天，凡不禁食的，要將他從民中剷除；</span>
<span className="v" id="v30" data-v="30" data-xref="利未記 20:3; 西番雅書 2:5; 耶利米書 15:7"> 凡在那天工作的，耶和華要毀滅他。</span>
<span className="v" id="v31" data-v="31"> 你們不可做任何工作。不論住在哪裡，這是你們世代當守的永久律例。</span>
<span className="v" id="v32" data-v="32" data-xref="利未記 16:31; 馬太福音 11:28–30; 詩篇 69:10–11"> 那是你們完全休息的安息日。從七月九日傍晚至次日傍晚，你們必須禁食。」</span>
</div>
</div>

## 住棚節

<div className="bt">
<div className="bp">
<span className="v" id="v33" data-v="33"> 耶和華對摩西說：</span>
<span className="v" id="v34" data-v="34" data-xref="約翰福音 7:2; 尼希米記 8:14; 以斯拉記 3:4"> 「你把以下條例告訴以色列人。 「從七月十五日開始，你們要一連七天向耶和華守住棚節。</span>
<span className="v" id="v35" data-v="35" data-xref="利未記 23:24–25; 利未記 23:7–8"> 第一天，你們要舉行聖會，不可做日常工作。</span>
<span className="v" id="v36" data-v="36" data-xref="尼希米記 8:18; 約翰福音 7:37; 歷代志下 7:8–11"> 一連七天你們要獻火祭給耶和華。第八天要舉行聖會，獻火祭給耶和華。這是莊嚴的聚會，你們不可做日常工作。</span>
<span className="v" id="v37" data-v="37" data-xref="利未記 23:2; 利未記 23:4; 傳道書 3:1"> 「以上是耶和華所定的節期。在這些節期裡，你們要召開聖會，按規定的日子獻給耶和華燔祭、素祭、奠祭和其他祭物。</span>
<span className="v" id="v38" data-v="38" data-xref="民數記 29:39; 利未記 19:3; 以斯拉記 2:68–69"> 除了守安息日並向耶和華獻供物、還願祭和自願獻的祭以外，你們還要守這些節期。</span>
<span className="v" id="v39" data-v="39" data-xref="出埃及記 23:16; 申命記 16:13; 利未記 23:34"> 「你們收割完後，從七月十五日起，要一連七天慶祝耶和華的節期，第一天和第八天是完全休息的安息日。</span>
<span className="v" id="v40" data-v="40" data-xref="腓立比書 4:4; 啟示錄 7:9; 申命記 16:14–15"> 第一天，你們要摘下樹上結的上好果子，折下棕樹枝、葉子濃密的樹枝與河邊的柳枝，在你們的上帝耶和華面前歡慶七天。</span>
<span className="v" id="v41" data-v="41" data-xref="民數記 29:12; 尼希米記 8:18"> 在每年七月的這七天，你們要向耶和華守這節期。這是你們世代當守的永久律例。</span>
<span className="v" id="v42" data-v="42" data-xref="尼希米記 8:14–17; 創世記 33:17; 民數記 24:5"> 你們要搭棚居住七天，所有以色列人都要住在棚裡。</span>
<span className="v" id="v43" data-v="43" data-xref="申命記 31:10–13; 詩篇 78:5–6; 出埃及記 13:14"> 這樣，你們的後代就會知道，我帶領以色列人離開埃及後，曾讓他們住在棚裡。我是你們的上帝耶和華。」</span>
<span className="v" id="v44" data-v="44" data-xref="利未記 23:1–2; 馬太福音 18:20; 利未記 21:24"> 於是，摩西向以色列人宣佈了耶和華所定的這些節期。</span>
</div>
</div>

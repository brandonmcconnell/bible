## 各種罪的懲處條例

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華對摩西說：</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 21:21; 利未記 18:21; 利未記 20:27"> 「你要告訴以色列人：在你們或寄居在你們中間的外族人中，如果有人把子女獻給假神摩洛，必須處死他，當地的人要用石頭打死他。</span>
<span className="v" id="v3" data-v="3" data-xref="利未記 18:21; 以西結書 5:11; 以西結書 23:38–39"> 我也必嚴懲那人，將他從民中剷除。因為他把子女獻給摩洛，玷污我的聖所，褻瀆我的聖名。</span>
<span className="v" id="v4" data-v="4" data-xref="申命記 17:2–5; 使徒行傳 17:30; 列王紀上 20:42"> 如果那地方的人對此置之不理，沒有處死那人，</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 106:39; 何西阿書 2:13; 何西阿書 2:5"> 我必嚴懲那人及其家人，從民中剷除他和那些追隨他與摩洛苟合的人。</span>
<span className="v" id="v6" data-v="6" data-xref="利未記 19:31; 以賽亞書 8:19; 利未記 20:27"> 如果有人求問靈媒或巫師，與他們苟合，我必嚴懲，將他從民中剷除。</span>
<span className="v" id="v7" data-v="7" data-xref="利未記 11:44; 利未記 19:2; 彼得前書 1:15–16"> 你們要分別出來，做聖潔的人，因為我是你們的上帝耶和華。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及記 31:13; 雅各書 1:22; 帖撒羅尼迦前書 5:23"> 你們要遵行我的律例。我是使你們聖潔的耶和華。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="出埃及記 21:17; 馬可福音 7:10; 申命記 27:16"> 「咒罵父母的，必被處死。他咒罵父母，罪有應得。</span>
<span className="v" id="v10" data-v="10" data-xref="約翰福音 8:4–5; 申命記 22:22–24; 申命記 5:18"> 如果有人與別人的妻子通姦，姦夫淫婦必須被處死。</span>
<span className="v" id="v11" data-v="11" data-xref="申命記 27:20; 申命記 27:23; 阿摩司書 2:7"> 如果有人與父親的妻妾同寢，就是羞辱他的父親。要把二人處死，他們罪有應得。</span>
<span className="v" id="v12" data-v="12" data-xref="利未記 18:15; 利未記 18:23; 創世記 38:18"> 如果有人與兒媳同寢，二人都必須被處死。他們亂倫，罪有應得。</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多前書 6:9; 利未記 18:22; 猶大書 1:7"> 如果男人與男人同寢，好像男人與女人同寢一樣，他們的行為可憎，必須被處死。他們罪有應得。</span>
<span className="v" id="v14" data-v="14" data-xref="利未記 18:17; 申命記 27:23; 約書亞記 7:15"> 如果有人娶妻，又娶岳母，便是大惡。要把他們三人燒死，使你們杜絕這種敗壞之事。</span>
<span className="v" id="v15" data-v="15" data-xref="利未記 18:23; 申命記 27:21; 出埃及記 22:19"> 如果有男人與獸類交合，他和獸都要被處死。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 21:32; 出埃及記 19:13; 希伯來書 12:20"> 如果有女人與獸類交合，女人和獸都要被處死。他們必須被處死，他們罪有應得。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="利未記 18:9; 申命記 27:22; 以西結書 22:11"> 「如果有人娶了同父異母或同母異父的姊妹，這是可恥之事，必須公開剷除他們。他與自己的姊妹亂倫，羞辱了她，要承擔自己的罪。</span>
<span className="v" id="v18" data-v="18" data-xref="利未記 15:24; 利未記 18:19; 以西結書 18:6"> 如果有人與經期的女人同寢，他就暴露了女人的血泉，女人也自露血泉。要將他們二人從民中剷除。</span>
<span className="v" id="v19" data-v="19" data-xref="利未記 18:6; 利未記 18:12–30; 出埃及記 6:20"> 不可與姨母或姑母亂倫，因為這是羞辱自己的親人。二人要承擔自己的罪。</span>
<span className="v" id="v20" data-v="20" data-xref="利未記 18:14; 約伯記 18:19; 路加福音 23:29"> 如果有人與伯母或嬸母同寢，就是羞辱他的伯父或叔父。二人要承擔自己的罪，必無子女而死。</span>
<span className="v" id="v21" data-v="21" data-xref="利未記 18:16; 馬太福音 14:3–4"> 如果有人娶兄嫂或弟媳，這是污穢行為，羞辱了自己的兄弟。二人必無兒無女。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="利未記 18:25–28; 以西結書 36:27; 利未記 18:4–5"> 「你們要遵行我的一切律例和典章，免得我要帶你們去居住的那片土地把你們吐出去。</span>
<span className="v" id="v23" data-v="23" data-xref="申命記 9:5; 利未記 18:24; 利未記 18:30"> 我要在你們面前趕走那片土地上的各族，你們不要隨從他們的習俗。他們做了以上那些事，所以我厭惡他們。</span>
<span className="v" id="v24" data-v="24" data-xref="申命記 14:2; 出埃及記 6:8; 申命記 7:6"> 我曾說你們必佔據他們的土地，我要把那片奶蜜之鄉賜給你們作產業。我是你們的上帝耶和華，我已經把你們從萬族中分別出來。</span>
<span className="v" id="v25" data-v="25" data-xref="申命記 14:3–21; 利未記 11:1–47; 使徒行傳 10:11–15"> 所以，你們要區分潔淨和不潔淨的獸類與鳥類。不可吃那些我視為不潔淨的飛禽、走獸和爬蟲，以免玷污自己。</span>
<span className="v" id="v26" data-v="26" data-xref="彼得前書 1:15–16; 利未記 20:7; 利未記 20:24"> 你們要聖潔，因為我耶和華是聖潔的。我把你們從萬族中分別出來，使你們做我的子民。</span>
<span className="v" id="v27" data-v="27" data-xref="利未記 19:31; 利未記 20:6; 撒母耳記上 28:7–9"> 如果有人做靈媒或巫師，不論男女，都必須被處死。你們要用石頭打死他們，他們罪有應得。」</span>
</div>
</div>

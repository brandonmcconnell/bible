## 許願的條例

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華對摩西說：</span>
<span className="v" id="v2" data-v="2" data-xref="民數記 6:2; 撒母耳記上 1:28; 士師記 11:30–31"> 「你要告訴以色列人：如果有人許下特別的願，以付身價的方式奉獻一個人給耶和華，就要為被奉獻者估定身價。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 30:13; 利未記 27:25; 民數記 18:16"> 以聖所的秤為準，要為二十至六十歲的男子估價十兩銀子，</span>
<span className="v" id="v4" data-v="4" data-xref="馬太福音 27:9–10; 撒迦利亞書 11:12–13; 馬太福音 26:15"> 女子則估價七兩銀子；</span>
<span className="v" id="v5" data-v="5"> 五至二十歲的男子估價四兩銀子，女子則估價二兩銀子；</span>
<span className="v" id="v6" data-v="6" data-xref="民數記 3:40–43; 民數記 18:14–16"> 滿月至五歲的男子估價一兩銀子，女子則估價半兩多銀子；</span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 90:10"> 六十歲以上的男子估價三兩銀子，女子則估價二兩銀子。</span>
<span className="v" id="v8" data-v="8" data-xref="馬可福音 14:7; 利未記 14:21–22; 路加福音 21:1–4"> 如果許願的人因貧窮而負擔不起，就要把他帶到祭司面前，祭司要按他的能力另行估價。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9"> 「如果有人許願獻牲畜給耶和華作供物，所獻的牲畜就會成為聖物。</span>
<span className="v" id="v10" data-v="10" data-xref="利未記 27:15–33; 雅各書 1:8"> 不可更換所獻的牲畜，不可以壞換好，也不可以好換壞。如果更換，兩頭牲畜都會成為聖物。</span>
<span className="v" id="v11" data-v="11" data-xref="申命記 23:18; 瑪拉基書 1:14"> 如果許願獻的是不潔淨的牲畜，即不能獻給耶和華作供物的牲畜，那人就要把牲畜帶到祭司面前，</span>
<span className="v" id="v12" data-v="12"> 由祭司評定牠的好壞，祭司估價多少就是多少。</span>
<span className="v" id="v13" data-v="13" data-xref="利未記 27:19; 利未記 27:15; 利未記 22:14"> 那人如果有意贖回，必須支付祭司估定的價值，再加付五分之一。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="民數記 18:14; 利未記 25:29–31; 利未記 27:21"> 「如果有人把房子分別出來獻給耶和華，祭司就要評定房子的好壞，祭司估價多少就是多少。</span>
<span className="v" id="v15" data-v="15" data-xref="利未記 27:13"> 那人如果想贖回房子，必須支付祭司估定的價值，再加付五分之一，房子便仍歸他所有。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="以西結書 45:11–14; 何西阿書 3:2; 使徒行傳 4:34–37"> 「如果有人把自己繼承的部分土地分別出來獻給耶和華，祭司就要按照土地的播種量來估價，撒二百升大麥種子的土地值十兩銀子。</span>
<span className="v" id="v17" data-v="17"> 如果有人在禧年奉獻土地，所估的價便是定價。</span>
<span className="v" id="v18" data-v="18" data-xref="利未記 25:15–16; 利未記 25:51–52; 利未記 25:27"> 如果是在禧年以後獻的，祭司要按照距下個禧年的年數來估價，估價要逐年減低。</span>
<span className="v" id="v19" data-v="19" data-xref="利未記 27:13"> 如果那人想贖回所獻的土地，要在估價的基礎上加付五分之一，土地便仍歸他所有。</span>
<span className="v" id="v20" data-v="20"> 他如果沒有贖回土地，而是賣給別人，便再也不能贖回。</span>
<span className="v" id="v21" data-v="21" data-xref="以西結書 44:29; 民數記 18:14; 利未記 25:31"> 到了禧年，那土地要像永遠獻給耶和華的土地一樣歸耶和華，成為祭司的產業。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="利未記 25:10; 利未記 25:25"> 「如果獻給耶和華的土地不是自己的產業，而是買來的，</span>
<span className="v" id="v23" data-v="23" data-xref="利未記 27:18; 利未記 27:12"> 祭司就要按照距下個禧年的年數來估價。那人要當天付清地價，地價歸耶和華。</span>
<span className="v" id="v24" data-v="24" data-xref="利未記 25:28; 利未記 27:20"> 到了禧年，他要把所獻的土地歸還給賣主，就是土地的原主。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及記 30:13; 民數記 18:16; 民數記 3:47"> 所有價銀的稱量要以聖所的秤為準，即二十季拉為一舍客勒<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一舍客勒約合十一克。">a</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="出埃及記 13:2; 出埃及記 13:12–13; 民數記 18:17"> 「潔淨牲畜的頭胎，無論是牛是羊，已經屬於耶和華，任何人不可再把牠獻給耶和華。</span>
<span className="v" id="v27" data-v="27" data-xref="利未記 27:11"> 如果是不潔淨牲畜的頭胎，他可以在祭司的估價基礎上，加付五分之一把牠贖回；如果不贖回，就要按估價把牠賣掉。</span>
<span className="v" id="v28" data-v="28" data-xref="約書亞記 6:17–19; 利未記 27:21; 出埃及記 22:20"> 凡永遠獻上的<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="「永遠獻上的」指完全獻給耶和華、永不可贖回的人或物，一般要被毀滅。此律多適用於戰爭中被攻佔的城邑或戰俘。">b</a></sup>，不論是人、牲畜或是田產，都不可賣掉，也不可贖回，因為這一切都是耶和華的至聖之物。</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳記上 15:18–23; 民數記 21:2–3"> 凡永遠獻上的人不可被贖回，必須被處死。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="馬太福音 23:23; 尼希米記 13:12; 創世記 28:22"> 「土地的所有出產中，不論是穀物還是樹上的果實，十分之一屬於耶和華，是耶和華的聖物。</span>
<span className="v" id="v31" data-v="31"> 如果有人想從那十分之一中贖回一部分，他要加付估價的五分之一。</span>
<span className="v" id="v32" data-v="32" data-xref="耶利米書 33:13; 以西結書 20:37; 彌迦書 7:14"> 至於牛羊，要讓牠們從牧人的杖下經過，每十隻的第十隻要歸耶和華作聖物。</span>
<span className="v" id="v33" data-v="33" data-xref="利未記 27:10"> 不論是好是壞，不可挑揀，不可更換。如果更換，兩隻都要作聖物，不可贖回。」</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="利未記 26:46; 民數記 1:1; 希伯來書 12:18–25"> 以上是耶和華在西奈山上藉摩西向以色列人頒佈的誡命。</span>
</div>
</div>

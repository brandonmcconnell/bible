## 獻素祭的條例

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="利未記 6:14–18; 利未記 9:17; 以賽亞書 66:20"> 「如果有人獻素祭給耶和華，要用細麵粉作祭物。要在細麵粉上澆油、加乳香，</span>
<span className="v" id="v2" data-v="2" data-xref="利未記 5:12; 利未記 6:15; 使徒行傳 10:4"> 帶到做祭司的亞倫子孫那裡。祭司要抓一把澆了油的細麵粉，連同所有乳香放在壇上焚燒，作為象徵。這是蒙耶和華悅納的馨香火祭。</span>
<span className="v" id="v3" data-v="3" data-xref="利未記 10:12–13; 民數記 18:9; 利未記 21:22"> 剩下的素祭要歸亞倫及其子孫，這在獻給耶和華的火祭中是至聖之物。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及記 29:2; 哥林多前書 5:7–8; 詩篇 22:14"> 「如果獻用爐子烤的素祭，要獻調油的無酵細麵餅，或塗油的無酵薄餅。</span>
<span className="v" id="v5" data-v="5" data-xref="利未記 6:21; 利未記 7:9"> 「如果獻用平底鍋烤的素祭，要獻調油的無酵細麵餅。</span>
<span className="v" id="v6" data-v="6" data-xref="約翰福音 18:1–19; 詩篇 22:1–21; 馬可福音 14:1–15"> 要把餅掰成碎塊，澆上油。這是素祭。</span>
<span className="v" id="v7" data-v="7" data-xref="利未記 2:1–2; 利未記 7:9"> 「如果獻用煎鍋煎的素祭，要獻用細麵粉和油做的祭物。</span>
<span className="v" id="v8" data-v="8"> 「要把這樣做好的素祭帶到耶和華面前，交給祭司獻在祭壇上。</span>
<span className="v" id="v9" data-v="9" data-xref="利未記 2:2; 腓立比書 4:18; 利未記 6:15"> 祭司要從中取出一部分，作為象徵放在祭壇上焚燒。這是蒙耶和華悅納的馨香火祭。</span>
<span className="v" id="v10" data-v="10" data-xref="利未記 2:3"> 剩下的素祭要歸亞倫及其子孫。這在獻給耶和華的火祭中是至聖之物。</span>
<span className="v" id="v11" data-v="11" data-xref="加拉太書 5:9; 路加福音 12:1; 出埃及記 23:18"> 「獻給耶和華的任何素祭都不可含酵，因為你們不可把酵或蜜當作火祭獻給耶和華。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及記 23:19; 創世記 23:10–11; 出埃及記 22:29"> 你們可以把酵和蜜作為初熟之祭獻給耶和華，但不可作為馨香之祭獻在祭壇上。</span>
<span className="v" id="v13" data-v="13" data-xref="以西結書 43:24; 馬太福音 5:13; 歌羅西書 4:6"> 所有素祭都要用鹽調味，不可少了你們與上帝立約的鹽。所有祭物中都要放鹽。</span>
<span className="v" id="v14" data-v="14" data-xref="利未記 23:10; 瑪拉基書 1:11; 民數記 28:2"> 「如果將初熟的穀物獻給耶和華作素祭，要用烘好後壓碎的新麥穗，</span>
<span className="v" id="v15" data-v="15"> 加上油和乳香。這是素祭。</span>
<span className="v" id="v16" data-v="16" data-xref="希伯來書 5:7; 羅馬書 8:26–27; 以賽亞書 61:1"> 祭司要將一些壓碎的麥穗、油及所有乳香作為象徵焚燒。這是獻給耶和華的火祭。</span>

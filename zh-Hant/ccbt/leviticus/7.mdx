## 祭司獻贖過祭的條例

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="利未記 6:17; 利未記 5:14–7; 利未記 6:25"> 「以下是獻贖過祭的條例。<br />「贖過祭是至聖的。</span>
<span className="v" id="v2" data-v="2" data-xref="利未記 1:5; 利未記 6:25; 利未記 1:11"> 要在殺燔祭牲的地方宰贖過祭祭牲，祭牲的血要灑在祭壇周圍。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 29:13; 利未記 3:15–16; 詩篇 51:6"> 要獻上祭牲的所有脂肪，包括肥尾巴、包裹內臟的脂肪、</span>
<span className="v" id="v4" data-v="4" data-xref="利未記 3:4"> 兩個腎臟和腎臟上靠近腰部的脂肪以及肝葉。</span>
<span className="v" id="v5" data-v="5" data-xref="利未記 1:13; 加拉太書 5:24; 彼得前書 4:1–2"> 祭司要在壇上焚燒這一切，作為獻給耶和華的火祭。這是贖過祭。</span>
<span className="v" id="v6" data-v="6" data-xref="利未記 6:29; 民數記 18:9–10; 利未記 2:3"> 祭司家的任何男子都可以吃剩下的祭肉，但要在聖潔之處吃，因為這是至聖之物。</span>
<span className="v" id="v7" data-v="7" data-xref="利未記 6:25–26; 利未記 14:13; 哥林多前書 9:13"> 祭物要歸主持祭禮的祭司，這一條例也適用於贖罪祭。</span>
<span className="v" id="v8" data-v="8" data-xref="利未記 4:11; 出埃及記 29:14; 羅馬書 13:14"> 燔祭牲的皮要歸主持祭禮的祭司。</span>
<span className="v" id="v9" data-v="9" data-xref="民數記 18:9; 以西結書 44:29; 利未記 2:10"> 至於素祭，不論是用爐烤的，還是用平底鍋或煎鍋做的，都要歸主持祭禮的祭司。</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多後書 8:14; 出埃及記 16:18"> 但調油的或乾的素祭要歸亞倫的子孫，由他們均分。</span>
</div>
</div>

## 獻平安祭的條例

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="利未記 22:18–21; 以西結書 45:15; 利未記 3:1–17"> 「以下是向耶和華獻平安祭的條例。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="利未記 2:4; 民數記 6:15; 彼得前書 2:5"> 「有人若為感謝耶和華而獻平安祭，除了獻祭牲以外，要一同獻上調油的無酵餅、塗油的無酵薄餅及調油的細麵餅，</span>
<span className="v" id="v13" data-v="13" data-xref="阿摩司書 4:5; 利未記 23:17; 馬太福音 13:33"> 也要一同獻上有酵餅。</span>
<span className="v" id="v14" data-v="14" data-xref="民數記 18:19; 出埃及記 29:27–28; 民數記 18:24–32"> 他要從每種餅中各取一個，作為舉祭獻給耶和華。舉祭歸灑平安祭祭牲血的祭司。</span>
<span className="v" id="v15" data-v="15" data-xref="利未記 22:29–30"> 至於為感恩而獻的平安祭祭肉，要在獻祭的當天吃完，不可留到次日早晨。</span>
<span className="v" id="v16" data-v="16" data-xref="利未記 19:5–8; 申命記 12:6; 詩篇 116:14"> 如果是自願獻的或為了還願而獻的祭物，要在獻祭當天吃祭肉，剩下的可以留到第二天吃。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及記 12:10; 何西阿書 6:2; 哥林多前書 15:4"> 但到第三天，必須燒掉剩下的祭肉。</span>
<span className="v" id="v18" data-v="18" data-xref="利未記 19:7–8; 利未記 11:41; 民數記 18:27"> 如果第三天仍然吃祭肉，所獻的祭便不蒙悅納，毫無價值，是不潔淨的。吃的人要自擔罪責。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="路加福音 11:41; 提多書 1:15; 使徒行傳 10:15–16"> 「祭肉如果接觸到任何不潔之物，都不可吃，要燒掉。潔淨的人都可以吃祭肉。</span>
<span className="v" id="v20" data-v="20" data-xref="利未記 15:2–33; 創世記 17:14; 利未記 22:3–7"> 如果有人不潔淨，卻吃獻給耶和華的平安祭祭肉，要將他從民中剷除。</span>
<span className="v" id="v21" data-v="21" data-xref="利未記 12:1–59; 利未記 11:20; 以西結書 4:14"> 如果有人接觸到人或獸的不潔之物，或任何不潔的可憎之物，又吃獻給耶和華的平安祭祭肉，要將他從民中剷除。」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22"> 耶和華對摩西說：</span>
<span className="v" id="v23" data-v="23" data-xref="利未記 3:16–17; 利未記 17:6; 撒母耳記上 2:15–17"> 「你把以下條例告訴以色列人。<br />「你們不可吃牛、綿羊或山羊的脂肪。</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及記 22:31; 利未記 17:15; 利未記 22:8"> 自然死亡或被野獸咬死的動物的脂肪也不可吃，但可以作其他用途。</span>
<span className="v" id="v25" data-v="25"> 無論誰吃了獻給耶和華的火祭祭牲的脂肪，都要將他從民中剷除。</span>
<span className="v" id="v26" data-v="26" data-xref="創世記 9:4; 利未記 3:17; 使徒行傳 15:20"> 你們無論住在哪裡，都不可吃鳥和獸的血。</span>
<span className="v" id="v27" data-v="27" data-xref="希伯來書 10:29; 利未記 7:20–21; 利未記 7:25"> 凡吃血的，要將他從民中剷除。」</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28"> 耶和華對摩西說：</span>
<span className="v" id="v29" data-v="29" data-xref="歌羅西書 1:20; 約翰一書 1:7; 利未記 3:1–17"> 「你把以下條例告訴以色列人。<br />「凡向耶和華獻平安祭的，都要從平安祭中取出一份獻給耶和華作禮物。</span>
<span className="v" id="v30" data-v="30" data-xref="民數記 6:20; 利未記 3:9; 利未記 3:14"> 他要親手將這獻給耶和華的火祭帶來，將祭牲的脂肪和胸肉帶來，在耶和華面前將胸肉搖一搖，當作搖祭獻上。</span>
<span className="v" id="v31" data-v="31" data-xref="利未記 3:5; 利未記 3:11; 利未記 3:16"> 祭司要把脂肪放在壇上焚燒，胸肉歸亞倫及其子孫。</span>
<span className="v" id="v32" data-v="32" data-xref="民數記 6:20; 利未記 7:34; 利未記 9:21"> 你們要把平安祭牲的右腿獻為舉祭，歸給祭司。</span>
<span className="v" id="v33" data-v="33" data-xref="利未記 26:1–46; 利未記 6:1–30; 利未記 7:3"> 要把右腿歸給亞倫子孫中獻平安祭的血和脂肪的那位祭司。</span>
<span className="v" id="v34" data-v="34" data-xref="民數記 18:18–19; 利未記 10:14–15; 出埃及記 29:9"> 因為耶和華已經從以色列人獻的平安祭中，把作搖祭的胸肉和作舉祭的腿肉，賜給祭司亞倫及其子孫，這是他們在以色列人中永遠當得的份。</span>
<span className="v" id="v35" data-v="35" data-xref="約翰一書 2:20; 約翰一書 2:27; 民數記 18:7–19"> 從亞倫及其子孫受膏為祭司事奉耶和華開始，在獻給耶和華的火祭中，這是他們應得之份。</span>
<span className="v" id="v36" data-v="36" data-xref="利未記 8:12; 利未記 8:30; 出埃及記 40:13–15"> 祭司受膏之日，耶和華就命令以色列人把這部分祭肉分給他們，這是他們世世代代應得之份。」</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="出埃及記 29:1; 利未記 1:1–6; 利未記 6:9–18"> 以上是獻燔祭、素祭、贖罪祭、贖過祭、平安祭和授聖職時所獻之祭的條例。</span>
<span className="v" id="v38" data-v="38" data-xref="利未記 1:1–2"> 這些條例是耶和華在西奈山上吩咐摩西的。當天，摩西命令以色列人在西奈曠野向耶和華獻祭。</span>
</div>

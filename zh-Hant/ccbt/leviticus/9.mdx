## 亞倫獻祭

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="馬太福音 28:1; 以西結書 43:26–27; 利未記 15:14"> 到了第八天，摩西召來亞倫父子們和以色列的眾長老。</span>
<span className="v" id="v2" data-v="2" data-xref="利未記 4:3; 希伯來書 10:10–14; 利未記 8:14"> 他對亞倫說：「你要在耶和華面前獻上一頭公牛犢作贖罪祭、一隻公綿羊作燔祭，這些祭牲都要毫無殘疾。</span>
<span className="v" id="v3" data-v="3" data-xref="以斯拉記 6:17; 啟示錄 5:9; 提多書 2:14"> 然後，你要告訴以色列人，『你們要取一隻公山羊作贖罪祭、毫無殘疾的一頭一歲牛犢和一隻一歲羊羔作燔祭、</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及記 29:43; 以西結書 43:2; 利未記 9:23"> 一頭公牛和一隻公綿羊作平安祭，連同調油的素祭一起獻給耶和華，因為今天耶和華要向你們顯現。』」</span>
<span className="v" id="v5" data-v="5" data-xref="歷代志下 5:2–3; 出埃及記 19:17; 尼希米記 8:1"> 於是，以色列人遵照摩西的吩咐，把祭物帶到會幕前。全體會眾都聚集到那裡，站在耶和華面前。</span>
<span className="v" id="v6" data-v="6" data-xref="利未記 9:23; 以西結書 43:2; 出埃及記 24:16"> 摩西對他們說：「耶和華吩咐你們這樣做，是為了向你們顯出祂的榮耀。」</span>
<span className="v" id="v7" data-v="7" data-xref="希伯來書 5:3; 希伯來書 5:1; 利未記 4:3"> 隨後，摩西對亞倫說：「你要到壇前來，獻上你的贖罪祭和燔祭，為自己和民眾贖罪。也要按照耶和華的吩咐，為百姓獻上他們的祭物，為他們贖罪。」</span>
<span className="v" id="v8" data-v="8" data-xref="利未記 4:1–12; 利未記 1:4–5; 利未記 4:29"> 於是，亞倫走到壇前，宰殺為他作贖罪祭的牛犢。</span>
<span className="v" id="v9" data-v="9" data-xref="利未記 4:6–7; 利未記 8:15; 利未記 4:25"> 他兒子們把牛犢的血遞給他，他用手指蘸血抹在祭壇凸起的四角上，再把剩下的血倒在壇腳。</span>
<span className="v" id="v10" data-v="10" data-xref="利未記 8:16–17; 箴言 23:26; 利未記 3:9–11"> 他照耶和華對摩西的吩咐，在壇上焚燒贖罪祭牲的脂肪、腎臟和肝葉，</span>
<span className="v" id="v11" data-v="11" data-xref="利未記 8:17; 利未記 4:11–12; 利未記 16:27–28"> 把皮和肉帶到營外焚燒。</span>
<span className="v" id="v12" data-v="12" data-xref="以弗所書 5:2; 以弗所書 5:25–27; 利未記 1:1–17"> 亞倫宰了燔祭祭牲，他兒子們把祭牲的血遞給他，他把血灑在祭壇四周。</span>
<span className="v" id="v13" data-v="13"> 他們將祭牲一塊一塊地連頭一起交給亞倫獻在壇上焚燒。</span>
<span className="v" id="v14" data-v="14" data-xref="利未記 8:21"> 亞倫洗淨祭牲的內臟和腿，放在祭壇的燔祭上焚燒。</span>
<span className="v" id="v15" data-v="15" data-xref="利未記 4:27–31; 希伯來書 5:3; 利未記 9:3"> 隨後，亞倫為民眾獻祭。他牽來那隻為民眾作贖罪祭的公山羊，宰殺後，像剛才為自己獻贖罪祭一樣為他們獻上贖罪祭。</span>
<span className="v" id="v16" data-v="16" data-xref="利未記 9:12–14; 利未記 8:18–21; 希伯來書 10:1–22"> 他又牽來燔祭祭牲，依照條例獻上燔祭。</span>
<span className="v" id="v17" data-v="17" data-xref="利未記 2:1–2; 約翰福音 6:53; 利未記 9:1"> 除了早晨的燔祭，亞倫又取來素祭，從中拿了一把獻在壇上焚燒。</span>
<span className="v" id="v18" data-v="18" data-xref="歌羅西書 1:20; 羅馬書 5:1; 以弗所書 2:14–17"> 然後，他宰了公牛和公綿羊，為民眾獻平安祭。他兒子們把祭牲的血遞給他，他把血灑在祭壇四周。</span>
<span className="v" id="v19" data-v="19" data-xref="利未記 3:16; 利未記 9:10; 利未記 3:9"> 他們把公牛和公綿羊的脂肪、肥尾巴、包裹內臟的脂肪、腎臟和肝葉，</span>
<span className="v" id="v20" data-v="20" data-xref="利未記 3:14–17; 利未記 7:29–34"> 放在祭牲的胸脯上，然後亞倫把那些脂肪放在壇上焚燒，</span>
<span className="v" id="v21" data-v="21" data-xref="利未記 7:30–34; 利未記 7:24; 出埃及記 29:24"> 將胸肉和右腿肉作為搖祭在耶和華面前搖一搖，都遵照摩西的吩咐。</span>
<span className="v" id="v22" data-v="22" data-xref="申命記 21:5; 路加福音 24:50; 民數記 6:23–27"> 亞倫舉手為民眾祝福，他獻完贖罪祭、燔祭和平安祭後走下祭壇。</span>
<span className="v" id="v23" data-v="23" data-xref="利未記 9:6; 民數記 16:19; 路加福音 1:21–22"> 之後，摩西和亞倫走進會幕，又出來為民眾祝福。這時，耶和華的榮耀向所有民眾顯現。</span>
<span className="v" id="v24" data-v="24" data-xref="士師記 6:21; 列王紀上 18:38–39; 歷代志上 21:26"> 有火從耶和華那裡降下來，燒盡祭壇上的燔祭和脂肪。民眾看見這景象，都歡呼起來，俯伏在地。</span>

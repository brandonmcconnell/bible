## 請求代禱

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="帖撒羅尼迦前書 5:25; 歌羅西書 4:3; 哥林多前書 16:9"> 弟兄姊妹，最後我還要請你們為我們禱告，好使主的道像在你們那裡一樣迅速傳開、受到尊崇，</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多後書 4:3–4; 羅馬書 15:31; 申命記 32:20"> 並使我們能避開那些邪惡的人，因為不是人人都有信心。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="提摩太後書 4:18; 帖撒羅尼迦前書 5:24; 哥林多前書 10:13"> 主是信實的，祂必使你們剛強，保護你們脫離那惡者。</span>
<span className="v" id="v4" data-v="4" data-xref="腓立比書 1:6; 腓利門書 1:21; 帖撒羅尼迦前書 4:10"> 我們靠著主深信你們正遵行我們的吩咐，而且以後還會繼續遵行。</span>

<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="詩篇 119:36; 歷代志上 29:18; 申命記 30:6"> 願主引導你們的心領悟上帝的愛和基督的堅忍。</span>
</div>
</div>

## 不可遊手好閒

<div className="bt">
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="帖撒羅尼迦後書 3:10–11; 帖撒羅尼迦後書 3:7; 羅馬書 16:17"> 弟兄姊妹，現在我們奉主耶穌基督的名吩咐你們，要遠離那些遊手好閒、不遵守我們教導的信徒。</span>
<span className="v" id="v7" data-v="7" data-xref="帖撒羅尼迦後書 3:6; 帖撒羅尼迦後書 3:9; 哥林多前書 4:16"> 你們自己知道應該怎樣效法我們，因為我們在你們那裡的時候，並沒有懶懶散散，</span>
<span className="v" id="v8" data-v="8" data-xref="馬太福音 6:11; 帖撒羅尼迦前書 2:9; 以弗所書 4:28"> 也沒有白吃誰的飯，而是晝夜辛勤工作，免得成為你們任何人的負擔。</span>
<span className="v" id="v9" data-v="9" data-xref="帖撒羅尼迦後書 3:7; 帖撒羅尼迦前書 2:6; 哥林多前書 9:4–14"> 這並不是因為我們沒有權利接受供應，而是要給你們樹立學習的榜樣。</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 3:19; 箴言 13:4; 箴言 20:4"> 我們在你們那裡的時候，曾吩咐過你們：不肯工作的人沒有資格吃飯。</span>
<span className="v" id="v11" data-v="11" data-xref="提摩太前書 5:13; 帖撒羅尼迦後書 3:6; 帖撒羅尼迦前書 4:11"> 我們聽說在你們當中有些人遊手好閒，無所事事，專管閒事。</span>
<span className="v" id="v12" data-v="12" data-xref="以弗所書 4:28; 帖撒羅尼迦前書 4:11; 帖撒羅尼迦後書 3:8"> 我們奉主耶穌基督的名吩咐並勸誡這些人要安分守己，自食其力。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="加拉太書 6:9–10; 希伯來書 12:3; 哥林多後書 4:1"> 弟兄姊妹，你們要堅持行善，不要灰心。</span>
<span className="v" id="v14" data-v="14" data-xref="提多書 3:10; 帖撒羅尼迦後書 3:6; 哥林多前書 5:11"> 如果有人不聽從這信上的教導，要注意提防他，不要和他來往，好使他羞愧。</span>
<span className="v" id="v15" data-v="15" data-xref="提多書 3:10; 帖撒羅尼迦前書 5:14; 哥林多前書 5:5"> 只是不可把他當作仇人，要像對待弟兄姊妹一樣勸誡他。</span>
</div>
</div>

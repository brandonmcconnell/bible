## 專心行善

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="羅馬書 13:1–7; 彼得前書 2:13–17; 傳道書 10:4"> 你要提醒眾人順服執政掌權者，要服從，隨時準備做各種善事。</span>
<span className="v" id="v2" data-v="2" data-xref="以弗所書 4:31; 提摩太後書 2:24–25; 以弗所書 4:2"> 不要毀謗，不要爭吵，要謙和、恭敬地對待每一個人。</span>
<span className="v" id="v3" data-v="3" data-xref="以弗所書 2:1–3; 羅馬書 6:17; 歌羅西書 1:21"> 從前我們也愚蠢、悖逆、易受迷惑，受各種私慾和享樂驅使，心裡充滿惡念和嫉妒，令人憎惡，也彼此憎恨。</span>
<span className="v" id="v4" data-v="4" data-xref="以弗所書 2:4–10; 提多書 2:10–11; 提摩太前書 4:10"> 但我們的救主上帝向人彰顯了祂的恩慈和仁愛，</span>
<span className="v" id="v5" data-v="5" data-xref="以弗所書 2:8–9; 提摩太後書 1:9; 哥林多前書 6:11"> 藉著重生之洗和聖靈的更新拯救了我們，這並非因為我們有義行，而是因為祂的憐憫。</span>
<span className="v" id="v6" data-v="6" data-xref="約珥書 2:28; 羅馬書 5:5; 使徒行傳 10:45"> 上帝藉著我們的救主耶穌基督把聖靈豐豐富富地澆灌在我們身上。</span>
<span className="v" id="v7" data-v="7" data-xref="羅馬書 8:17; 提多書 2:11; 哥林多前書 6:11"> 這樣，我們既然靠著祂的恩典被稱為義人，就可以成為後嗣，有永生的盼望。</span>
<span className="v" id="v8" data-v="8" data-xref="提多書 3:14; 提多書 1:9; 詩篇 16:2–3"> 以上這些話是可信的，希望你認真強調，使信上帝的人專心行善。這都是造福眾人的美事。</span>
<span className="v" id="v9" data-v="9" data-xref="提摩太後書 2:14; 提摩太後書 2:23; 提摩太前書 4:7"> 要避免愚昧的爭論、有關家譜的辯駁和律法上的爭執，因為這些毫無益處。</span>
<span className="v" id="v10" data-v="10" data-xref="羅馬書 16:17; 約翰二書 1:10; 馬太福音 18:15–17"> 對於製造分裂的人，警告過一兩次後，要和他斷絕來往。</span>
<span className="v" id="v11" data-v="11" data-xref="希伯來書 10:26; 路加福音 19:22; 馬太福音 25:26–28"> 因為你知道這種人已經背道犯罪，自定己罪。</span>
</div>
</div>

## 信末的囑咐與問候

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="提摩太後書 4:9; 提摩太後書 4:12; 哥林多前書 16:8–9"> 我會派亞提馬或者推基古去見你。到時候，你要盡快到尼哥波立來見我，因為我決定在那裡過冬。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行傳 18:24; 馬太福音 22:35; 約翰三書 1:6–8"> 你要為西納律師和亞波羅送行，盡力幫助他們，讓他們路上一無所缺。</span>
<span className="v" id="v14" data-v="14" data-xref="歌羅西書 1:10; 提多書 3:8; 馬太福音 7:19"> 我們的弟兄姊妹也要學習行善，供應有急需的人，免得毫無建樹。</span>
<span className="v" id="v15" data-v="15" data-xref="提摩太前書 1:5; 以弗所書 6:23–24; 約翰二書 1:1–2"> 這裡的弟兄姊妹都問候你，也請你問候那些因信仰而愛我們的人。 願恩典常與你們眾人同在！</span>
</div>
</div>

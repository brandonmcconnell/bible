## 教導純正的教義

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="提摩太後書 1:13; 提摩太前書 6:3; 提多書 2:11–14"> 你的教導要符合純正的教義。</span>
<span className="v" id="v2" data-v="2" data-xref="加拉太書 5:23; 彼得前書 4:7; 帖撒羅尼迦前書 5:8"> 勸年長的男子要節制、莊重、自律，有全備的信心、愛心和耐心。</span>
<span className="v" id="v3" data-v="3" data-xref="提多書 2:4; 提摩太前書 3:11; 彼得前書 3:3–5"> 勸年長的婦女要過敬虔的生活，不說長道短，不做酒的奴隸，要以身作則。</span>
<span className="v" id="v4" data-v="4" data-xref="提摩太前書 5:14; 提摩太前書 5:2; 提摩太前書 5:11"> 這樣，她們就能教導年輕的婦女愛丈夫、愛兒女、</span>
<span className="v" id="v5" data-v="5" data-xref="箴言 31:10–31; 歌羅西書 3:18; 提摩太前書 5:10"> 自制、貞潔、持家、和善、順服丈夫，免得上帝的道被人毀謗。</span>
<span className="v" id="v6" data-v="6" data-xref="傳道書 12:1; 彼得前書 5:5; 約珥書 2:28"> 勸勉年輕的男子要自制。</span>
<span className="v" id="v7" data-v="7" data-xref="彼得前書 5:3; 提摩太前書 4:12; 哥林多後書 4:2"> 你自己要在各樣善行上作眾人的榜樣，在教導上要誠懇、認真、</span>
<span className="v" id="v8" data-v="8" data-xref="彼得前書 2:12; 彼得前書 2:15; 彼得前書 3:16"> 言語純全、無可指責，讓那些反對的人無話可說、自覺羞愧。</span>
<span className="v" id="v9" data-v="9" data-xref="彼得前書 2:18–25; 提摩太前書 6:1–2; 歌羅西書 3:22–25"> 勸勉作奴僕的要凡事順服主人，讓主人滿意，不頂撞主人，</span>
<span className="v" id="v10" data-v="10" data-xref="馬太福音 5:16; 彼得前書 2:12; 約翰二書 1:9"> 不偷拿主人的東西，為人要忠信可靠，好凡事尊崇我們救主上帝的教導。</span>
<span className="v" id="v11" data-v="11" data-xref="以弗所書 2:8; 提摩太前書 2:4; 以賽亞書 45:22"> 因為上帝拯救世人的恩典已經顯明了，</span>
<span className="v" id="v12" data-v="12" data-xref="以西結書 36:27; 馬太福音 16:24; 羅馬書 6:19"> 這恩典教導我們除掉不敬虔的心和世俗的私慾，在今世過自律、公義、敬畏上帝的生活，</span>
<span className="v" id="v13" data-v="13" data-xref="提摩太後書 4:8; 哥林多前書 1:7; 馬太福音 16:27"> 懷著美好的盼望等候我們偉大的上帝和救主耶穌基督的榮耀顯現。</span>
<span className="v" id="v14" data-v="14" data-xref="希伯來書 9:14; 以弗所書 2:10; 彼得前書 2:9"> 主耶穌為我們犧牲自己，要救贖我們脫離一切罪惡，並潔淨我們，使我們作祂熱心行善的子民。</span>
<span className="v" id="v15" data-v="15" data-xref="提摩太後書 4:2; 提摩太前書 4:12–13; 提多書 1:13"> 你要講明這些事，充分運用權柄來勸勉人、責備人，別讓人輕看你。</span>

## 基甸擒殺米甸二王

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳記下 19:41; 士師記 12:1–6; 約伯記 5:2"> 後來，以法蓮人對基甸說：「你攻打米甸人時為什麼不召我們去？你為什麼這樣對待我們？」他們與他激烈地爭論起來。</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多前書 13:4–7; 腓立比書 2:2–3; 雅各書 3:13–18"> 基甸說：「我怎能比得上你們呢？以法蓮人摘剩的葡萄豈不比我們亞比以謝族收穫的葡萄更好嗎？</span>
<span className="v" id="v3" data-v="3" data-xref="箴言 15:1; 士師記 7:24–25; 約翰福音 4:37"> 上帝把兩名米甸人的首領俄立和西伊伯交在了你們手中，我所做的怎能跟你們相比呢？」基甸這麼一說，他們的怒氣就平息了。</span>
<span className="v" id="v4" data-v="4" data-xref="加拉太書 6:9; 哥林多後書 4:16; 撒母耳記上 14:28–29"> 基甸率領他的三百人渡過約旦河，雖然疲憊不堪，仍緊追敵人。</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 33:17; 詩篇 60:6; 撒母耳記上 25:18"> 基甸對疏割的人說：「我們在追趕西巴和撒慕拿兩個米甸王，十分疲憊，請給我的軍隊一些餅吃。」</span>
<span className="v" id="v6" data-v="6" data-xref="列王紀上 20:11; 腓立比書 2:21; 箴言 18:23"> 疏割的首領卻說：「你還沒有抓到西巴和撒慕拿，我們憑什麼給你的軍隊餅吃？」</span>
<span className="v" id="v7" data-v="7" data-xref="士師記 7:15"> 基甸說：「好吧，耶和華把西巴和撒慕拿交在我們手中後，我必回來用荒野的荊棘抽打你們。」</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 32:30–31; 列王紀上 12:25"> 基甸又去毗努伊勒提出同樣的請求，他們的答復跟疏割人一樣。</span>
<span className="v" id="v9" data-v="9" data-xref="士師記 8:17; 列王紀上 22:27–28"> 基甸對那裡的人說：「我平安歸來時，必拆毀你們的這座城樓。」</span>
<span className="v" id="v10" data-v="10" data-xref="士師記 7:12; 士師記 20:25; 士師記 20:2"> 那時，西巴和撒慕拿率領東方各族的殘餘軍隊一萬五千人駐紮在加各，因為已經有十二萬刀兵被殺。</span>
<span className="v" id="v11" data-v="11" data-xref="民數記 32:35; 民數記 32:42; 士師記 18:27"> 基甸取道挪巴和約比哈東邊遊牧者走的路，出其不意地突襲米甸人。</span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 83:11; 阿摩司書 2:14; 約伯記 12:16–21"> 米甸二王西巴和撒慕拿逃跑，基甸追上去擒住他們，擊潰他們全軍。</span>
<span className="v" id="v13" data-v="13"> 約阿施的兒子基甸從戰場返回，經過希列斯山坡時，</span>
<span className="v" id="v14" data-v="14" data-xref="士師記 1:24–25; 撒母耳記上 30:11–15"> 抓住一個疏割的青年，問他疏割的首領和長老是誰，他就寫下疏割七十七位首領和長老的名字。</span>
<span className="v" id="v15" data-v="15" data-xref="士師記 8:6–7"> 基甸到了疏割，對那裡的人說：「你們曾經譏笑我說，『你還沒有抓到西巴和撒慕拿，我們憑什麼給你疲憊的軍隊餅吃？』看！西巴和撒慕拿在這裡！」</span>
<span className="v" id="v16" data-v="16" data-xref="士師記 8:7; 以斯拉記 2:6; 箴言 10:13"> 說完，就捉住城中的長老，用荒野的荊棘抽打他們。</span>
<span className="v" id="v17" data-v="17" data-xref="士師記 8:9; 列王紀上 12:25"> 他又去拆毀毗努伊勒的城樓，殺了城裡的人。</span>
<span className="v" id="v18" data-v="18" data-xref="士師記 4:6; 猶大書 1:16; 詩篇 89:12"> 基甸問西巴和撒慕拿：「你們在他泊山殺的人是什麼樣子？」他們回答說：「他們長得像你，都像王子一樣。」</span>
<span className="v" id="v19" data-v="19"> 基甸說：「他們是我同母所生的兄弟，我憑永活的耶和華起誓，如果你們當初不殺他們，今天我就不殺你們了。」</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 149:9; 撒母耳記上 15:33; 約書亞記 10:24"> 於是，基甸對長子益帖說：「你殺死他們。」但益帖年紀小，心中害怕，不敢動手。</span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 83:11; 士師記 8:26; 以賽亞書 3:18"> 西巴和撒慕拿對基甸說：「你親自動手吧！這是男子漢做的事。」基甸便親手殺了他們，拿走了他們駱駝頸上的月牙飾物。</span>
</div>
</div>

## 基甸造以弗得

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="約翰福音 6:15; 士師記 9:8–15; 撒母耳記上 12:12"> 以色列人對基甸說：「你從米甸人手中救了我們，請你和你的子孫統治我們。」</span>
<span className="v" id="v23" data-v="23" data-xref="以賽亞書 33:22; 撒母耳記上 12:12; 撒母耳記上 10:19"> 基甸回答說：「我和我子孫都不統治你們，統治你們的是耶和華。」</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 25:13; 創世記 37:25; 創世記 37:28"> 他又說道：「我有一個要求，請你們把搶來的耳環都給我。」原來米甸人屬於以實瑪利族，都戴金耳環。</span>
<span className="v" id="v25" data-v="25"> 他們欣然同意，便鋪開一件外衣，各自把搶來的金耳環都放在上面，</span>
<span className="v" id="v26" data-v="26" data-xref="啟示錄 18:16; 約翰福音 19:2; 啟示錄 18:12"> 重約二十公斤。此外，還有米甸王的月牙飾物、耳墜、紫袍以及駱駝頸上的金鏈。</span>
<span className="v" id="v27" data-v="27" data-xref="士師記 17:5; 士師記 18:14; 詩篇 106:39"> 基甸用這些金子造了一件以弗得聖衣，放在自己的家鄉俄弗拉。後來，以色列人拜那件以弗得，玷污自己，使基甸及其全家陷入網羅。</span>
<span className="v" id="v28" data-v="28" data-xref="士師記 5:31; 士師記 3:11; 士師記 3:30"> 這樣，米甸人被以色列人征服了，從此一蹶不振。基甸在世之日，以色列境內安享太平四十年。</span>
</div>
</div>

## 基甸去世

<div className="bt">
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="士師記 6:32; 士師記 7:1; 撒母耳記上 12:11"> 約阿施的兒子耶路·巴力返回家鄉居住。</span>
<span className="v" id="v30" data-v="30" data-xref="士師記 9:5; 士師記 9:2; 列王紀上 11:3"> 他有許多妻子，生了七十個兒子。</span>
<span className="v" id="v31" data-v="31" data-xref="士師記 9:18; 創世記 22:24; 創世記 16:15"> 他的妾住在示劍，也給他生了一個兒子，他給孩子取名叫亞比米勒。</span>
<span className="v" id="v32" data-v="32" data-xref="創世記 25:8; 士師記 6:24; 約伯記 5:26"> 約阿施的兒子基甸年高壽終，葬在亞比以謝族的俄弗拉，在他父親約阿施的墳墓裡。</span>
<span className="v" id="v33" data-v="33" data-xref="士師記 9:46; 士師記 2:19; 士師記 9:4"> 基甸剛去世，以色列人便又與巴力苟合，奉巴力·比利土為他們的神明，</span>
<span className="v" id="v34" data-v="34" data-xref="詩篇 78:42; 詩篇 106:21; 詩篇 78:11"> 忘記了他們的上帝耶和華曾經從四圍的仇敵手中拯救他們，</span>
<span className="v" id="v35" data-v="35" data-xref="傳道書 9:14–15; 士師記 9:5; 士師記 9:16–19"> 也沒有因耶路·巴力，就是基甸的功績而厚待他的家人。</span>
</div>

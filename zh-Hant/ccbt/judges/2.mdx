## 耶和華責備以色列人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及記 20:2; 創世記 17:7–8; 利未記 26:42"> 耶和華的天使從吉甲來到波金，對以色列人說：「我帶你們出埃及，領你們來到我起誓要賜給你們祖先的土地。我說，『我永不廢棄跟你們立的約，</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 7:2–4; 耶利米書 2:36; 以斯拉記 9:1–3"> 你們不可跟這裡的居民立約，要毀掉他們的祭壇。』可是你們為什麼不聽呢？</span>
<span className="v" id="v3" data-v="3" data-xref="約書亞記 23:13; 民數記 33:55; 申命記 7:16"> 因此，我告訴你們，我必不趕走這裡的居民，他們必成為你們肋旁的刺，他們的神明必成為你們的網羅。」</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米書 31:9; 箴言 17:10; 撒迦利亞書 12:10"> 耶和華的天使說完這些話，以色列人放聲大哭，</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳記上 7:9; 創世記 35:8; 約書亞記 7:26"> 他們稱那地方為波金<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「波金」意思是「哭泣」。">a</a></sup>，在那裡向耶和華獻祭。</span>
</div>
</div>

## 約書亞去世

<div className="bt">
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="約書亞記 24:28–31; 約書亞記 22:6"> 約書亞遣散以色列人後，他們便各自去攻佔所分得的土地。</span>
<span className="v" id="v7" data-v="7" data-xref="腓立比書 2:12; 約書亞記 24:31; 歷代志下 24:2"> 約書亞在世的時候，以色列人都事奉耶和華。他死後，那些目睹耶和華為以色列人行大事的長老還在世的時候，以色列人仍事奉耶和華。</span>
<span className="v" id="v8" data-v="8" data-xref="約書亞記 24:29–30"> 耶和華的僕人、嫩的兒子約書亞去世時一百一十歲。</span>
<span className="v" id="v9" data-v="9" data-xref="約書亞記 19:50; 約書亞記 24:30"> 以色列人把他葬在他自己的土地上，在迦實山以北、以法蓮山區的亭拿·希烈。</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳記上 2:12; 提多書 1:16; 出埃及記 5:2"> 那一代人都去世後，新一代不認識耶和華，也不知道耶和華為以色列人所行的事。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="士師記 4:1; 士師記 6:1; 士師記 3:7"> 以色列人做耶和華視為惡的事，祭拜巴力。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及記 20:5; 申命記 13:5; 申命記 6:14–15"> 他們背棄了領他們祖先離開埃及的上帝耶和華，追隨、祭拜鄰邦的各種神明，因而惹耶和華發怒。</span>
<span className="v" id="v13" data-v="13" data-xref="士師記 10:6; 詩篇 106:36; 士師記 3:7"> 他們背棄耶和華，去祭拜巴力和亞斯她錄。</span>
<span className="v" id="v14" data-v="14" data-xref="列王紀下 17:20; 詩篇 106:40–42; 申命記 32:30"> 耶和華向他們發怒，使他們受到掠奪者的攻擊和四周仇敵的壓制，毫無抵抗之力。</span>
<span className="v" id="v15" data-v="15" data-xref="申命記 28:15–68; 約書亞記 23:15–16; 利未記 26:14–46"> 他們每次出戰，耶和華都出手與他們為敵，使他們戰敗，正如祂的誓言。他們苦不堪言。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="使徒行傳 13:20; 詩篇 106:43–45; 撒母耳記上 12:11"> 後來，耶和華使士師<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="「士師」意思是「首領」。">b</a></sup>興起，從掠奪者手中拯救他們。</span>
<span className="v" id="v17" data-v="17" data-xref="加拉太書 1:6; 申命記 9:12; 士師記 2:7"> 但他們不聽從士師的話，與其他神明苟合，祭拜它們，很快偏離他們祖先的道路，沒有像他們的祖先那樣遵行耶和華的命令。</span>
<span className="v" id="v18" data-v="18" data-xref="申命記 32:36; 約書亞記 1:5; 出埃及記 2:24"> 耶和華見他們因敵人的壓迫和苦待而哀號，就憐憫他們，使士師陸續興起，並與每位士師同在。士師在世之日，耶和華從仇敵手中拯救他們。</span>
<span className="v" id="v19" data-v="19" data-xref="士師記 8:33; 士師記 4:1; 馬太福音 23:32"> 士師去世以後，他們又故態復萌，追隨、祭拜其他神明，比他們的祖先更敗壞。他們執迷不悟，怙惡不悛。</span>
<span className="v" id="v20" data-v="20" data-xref="士師記 2:14; 約書亞記 23:16; 出埃及記 32:10–11"> 耶和華向他們發怒，說：「這百姓違背了我跟他們祖先所立的約，不聽從我的話。</span>
<span className="v" id="v21" data-v="21" data-xref="約書亞記 23:13; 士師記 2:3; 士師記 3:3"> 因此，我不再逐出約書亞去世時還沒有趕走的外族人，</span>
<span className="v" id="v22" data-v="22" data-xref="申命記 8:2; 申命記 8:16; 申命記 13:3"> 我要藉此試驗以色列人，看他們是否像他們祖先一樣謹遵我的道。」</span>
<span className="v" id="v23" data-v="23"> 這就是為什麼耶和華留下那些外族人，沒有立刻把他們趕走，也沒有把他們交在約書亞手中。</span>
</div>
</div>

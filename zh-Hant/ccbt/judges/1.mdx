## 猶大支派攻打迦南人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士師記 20:18; 民數記 27:21; 士師記 20:28"> 約書亞去世以後，以色列人求問耶和華：「我們哪一個支派先上去攻打迦南人呢？」</span>
<span className="v" id="v2" data-v="2" data-xref="啟示錄 5:5; 希伯來書 7:14; 民數記 2:3"> 耶和華說：「猶大支派先去，我已把那片土地交在他們手中了。」</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳記下 10:11; 約書亞記 19:1; 士師記 1:17"> 猶大人對同胞西緬人說：「請跟我們一同到我們分得的地方攻打迦南人，我們也會同樣幫助你們。」於是，西緬人便與猶大人同去。</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳記上 11:8; 出埃及記 23:28–29; 約書亞記 11:6–8"> 猶大人上去攻打迦南人和比利洗人，耶和華使他們得勝，在比色殺了一萬敵軍。</span>
<span className="v" id="v5" data-v="5"> 他們又在那裡遇見亞多尼·比色，與他交戰，打敗了他帶領的迦南人和比利洗人。</span>
<span className="v" id="v6" data-v="6"> 亞多尼·比色逃跑，他們追上去擒住他，砍掉他的大拇指和大腳趾。</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳記上 15:33; 啟示錄 13:10; 路加福音 6:37–38"> 亞多尼·比色說：「從前七十個王被我砍掉大拇指和大腳趾，在我桌下撿食物碎屑，現在上帝照我的行為報應我了。」他們把他帶到耶路撒冷，他就死在那裡。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="約書亞記 15:63; 士師記 1:21"> 猶大人攻陷耶路撒冷，用刀殺了城內的所有居民，並放火焚城。</span>
<span className="v" id="v9" data-v="9" data-xref="約書亞記 15:13–20; 約書亞記 11:21; 約書亞記 10:36"> 隨後，他們下去攻打住在山區、南地和丘陵的迦南人，</span>
<span className="v" id="v10" data-v="10" data-xref="民數記 13:22; 約書亞記 14:15; 耶利米書 9:23"> 又進攻住在希伯崙的迦南人，殺了示篩、亞希幔和撻買。希伯崙從前叫基列·亞巴。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="約書亞記 15:15; 約書亞記 10:38–39"> 他們從那裡出兵攻打底璧，底璧從前叫基列·西弗。</span>
<span className="v" id="v12" data-v="12" data-xref="約書亞記 15:16–17; 撒母耳記上 17:25; 撒母耳記上 18:23"> 迦勒說：「誰攻取基列·西弗，我就把女兒押撒嫁給他。」</span>
<span className="v" id="v13" data-v="13" data-xref="士師記 3:9"> 迦勒的弟弟基納斯的兒子俄陀聶攻取了那城，迦勒便把女兒押撒嫁給他。</span>
<span className="v" id="v14" data-v="14" data-xref="約書亞記 15:18–19"> 押撒出嫁的時候，勸丈夫向她父親要一塊田。她剛下驢，迦勒便問她：「你想要什麼？」</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳記上 25:18; 哥林多後書 9:5; 彼得前書 3:9"> 她回答說：「求你賜福給我，你既然把南地賜給我，求你也把水泉給我吧。」迦勒就把上泉和下泉都給了她。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="民數記 10:29–32; 士師記 4:11; 撒母耳記上 15:6"> 摩西岳父的後代基尼人和猶大人一同離開棕樹城<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「棕樹城」即「耶利哥」。">a</a></sup>，到猶大南部曠野的亞拉得附近，跟當地人一起居住。</span>
<span className="v" id="v17" data-v="17" data-xref="民數記 21:3; 士師記 1:3; 約書亞記 19:4"> 之後，猶大人隨同胞西緬人一起攻打洗法城內的迦南人，徹底毀滅了那城。因此那城叫何珥瑪<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="「何珥瑪」意思是「覆滅之城」。">b</a></sup>。</span>
<span className="v" id="v18" data-v="18" data-xref="約書亞記 11:22; 士師記 3:3; 約書亞記 15:45–47"> 猶大人又奪取了迦薩、亞實基倫和以革倫三座城邑及周圍地區。</span>
<span className="v" id="v19" data-v="19" data-xref="以賽亞書 41:10; 士師記 1:2; 詩篇 60:12"> 耶和華與猶大人同在。他們攻佔了山區，卻沒能趕走平原的居民，因為那裡的人有鐵戰車。</span>
<span className="v" id="v20" data-v="20" data-xref="士師記 1:10; 約書亞記 15:13–14; 民數記 14:24"> 照摩西的吩咐，迦勒得到了希伯崙。他把亞衲三族的人從那裡趕走。</span>
<span className="v" id="v21" data-v="21" data-xref="約書亞記 15:63; 士師記 19:10–12; 士師記 1:8"> 便雅憫人沒有趕走居住在耶路撒冷的耶布斯人，耶布斯人至今仍和他們住在一起。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="士師記 1:19; 列王紀下 18:7; 民數記 1:32"> 約瑟家族也上去攻打伯特利，耶和華與他們同在。</span>
<span className="v" id="v23" data-v="23" data-xref="創世記 28:19; 創世記 35:6; 創世記 48:3"> 他們先派人去打探伯特利，那裡從前名叫路斯。</span>
<span className="v" id="v24" data-v="24" data-xref="約書亞記 2:12–14; 撒母耳記上 30:15"> 探子看見一個人從城裡出來，就對他說：「請你告訴我們進城的路，我們必善待你。」</span>
<span className="v" id="v25" data-v="25" data-xref="約書亞記 6:22–25"> 那人便告訴他們進城的路，他們用刀殺了城內所有的居民，只放走了那人及其全家。</span>
<span className="v" id="v26" data-v="26" data-xref="列王紀下 7:6; 歷代志下 1:17"> 後來，那人搬到赫人的地方，築了一座城，稱之為路斯，沿用至今。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="約書亞記 17:11–13; 耶利米書 48:10; 詩篇 106:34–35"> 瑪拿西人沒有趕走伯·善、他納、多珥、以伯蓮和米吉多眾城邑及其周圍村莊的居民，因為這些迦南人執意住在那裡。</span>
<span className="v" id="v28" data-v="28"> 以色列人強盛時，就強迫他們服勞役，卻沒有全部趕走他們。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="約書亞記 16:10; 列王紀上 9:16"> 以法蓮人沒有趕走住在基色的迦南人，這些迦南人仍然住在他們當中。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="約書亞記 19:15"> 西布倫人沒有趕走基倫和拿哈拉的居民，這些迦南人仍然住在他們當中，為他們服勞役。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="約書亞記 19:24–30"> 亞設人沒有趕走亞柯、西頓、亞黑拉、亞革悉、黑巴、亞弗革和利合的居民。</span>
<span className="v" id="v32" data-v="32" data-xref="詩篇 106:34–35"> 亞設人因為沒有趕出當地的迦南人，就住在他們當中。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="約書亞記 19:32–38; 士師記 1:30; 詩篇 18:24"> 拿弗他利人沒有趕走伯·示麥和伯·亞納的居民，於是就住在這些迦南人當中，強迫他們服勞役。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="約書亞記 19:47; 士師記 18:1"> 亞摩利人強迫但人住在山區，不准他們下到平原。</span>
<span className="v" id="v35" data-v="35" data-xref="約書亞記 19:42; 士師記 12:12; 約書亞記 10:12"> 亞摩利人執意住在希烈山、亞雅崙和沙賓，但約瑟家族強盛時，就強迫他們服勞役。</span>
<span className="v" id="v36" data-v="36" data-xref="民數記 34:4; 約書亞記 15:2–3"> 亞摩利人的邊界從亞克拉濱山坡起，一直到西拉以北。</span>
</div>
</div>

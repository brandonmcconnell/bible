## 迦南餘族

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士師記 2:21–22; 申命記 7:22; 箴言 17:3"> 耶和華為了考驗那些沒有經歷過迦南戰事的以色列人，讓他們學習作戰，就留下了以下各族：</span>
<span className="v" id="v3" data-v="3" data-xref="約書亞記 13:3; 約書亞記 13:5; 士師記 10:7"> 五個非利士王、所有的迦南人、西頓人和住在巴力·黑門山到哈馬口一帶的黎巴嫩山區的希未人。</span>
<span className="v" id="v4" data-v="4" data-xref="士師記 3:1; 士師記 2:22; 出埃及記 15:25"> 耶和華留下這幾個外族是要考驗以色列人，看他們是否願意遵從祂藉摩西向他們祖先頒佈的誡命。</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 106:34–38; 創世記 10:15–18; 出埃及記 3:8"> 以色列人住在這些迦南人、赫人、亞摩利人、比利洗人、希未人和耶布斯人當中，</span>
<span className="v" id="v6" data-v="6" data-xref="申命記 7:3–4; 出埃及記 34:16; 列王紀上 11:1–5"> 跟他們通婚，祭拜他們的神明。</span>
</div>
</div>

## 士師俄陀聶

<div className="bt">
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="出埃及記 34:13; 列王紀下 23:6; 列王紀上 18:19"> 以色列人做耶和華視為惡的事，忘記他們的上帝耶和華，祭拜假神巴力和亞舍拉。</span>
<span className="v" id="v8" data-v="8" data-xref="士師記 2:14; 哈巴谷書 3:7; 士師記 4:9"> 耶和華向他們發怒，把他們交在美索不達米亞王古珊·利薩田的手中，受古珊·利薩田統治八年。</span>
<span className="v" id="v9" data-v="9" data-xref="士師記 3:15; 士師記 1:13; 詩篇 22:5"> 他們向耶和華呼求，耶和華就使一位名叫俄陀聶的拯救者興起，他是迦勒弟弟基納斯的兒子。</span>
<span className="v" id="v10" data-v="10" data-xref="士師記 13:25; 撒母耳記上 11:6; 士師記 14:19"> 耶和華的靈降在俄陀聶身上，他就做了以色列的士師，領兵出戰。耶和華將美索不達米亞王古珊·利薩田交在他手中，他便戰勝了古珊·利薩田。</span>
<span className="v" id="v11" data-v="11" data-xref="士師記 5:31; 士師記 8:28; 約書亞記 11:23"> 此後，國內安享太平四十年，直到俄陀聶去世。</span>
</div>
</div>

## 士師以笏

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="撒母耳記上 12:9; 士師記 2:19; 士師記 2:14"> 之後，以色列人又做耶和華視為惡的事，耶和華就使摩押王伊磯倫強盛起來，攻打以色列人。</span>
<span className="v" id="v13" data-v="13" data-xref="士師記 1:16; 申命記 34:3; 士師記 5:14"> 伊磯倫聯合亞捫人和亞瑪力人進攻以色列人，佔據了棕樹城，</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 28:47–48; 申命記 28:40; 利未記 26:23–25"> 以色列人受摩押王伊磯倫統治十八年。</span>
<span className="v" id="v15" data-v="15" data-xref="士師記 3:9; 詩篇 78:34; 以賽亞書 36:16"> 他們呼求耶和華，耶和華就使一位名叫以笏的拯救者興起。他是便雅憫人基拉的兒子，善用左手。以色列人派他去向摩押王伊磯倫進貢。</span>
<span className="v" id="v16" data-v="16" data-xref="雅歌 3:8; 啟示錄 2:12; 詩篇 149:6"> 他造了一把約半米長的兩刃利劍，綁在右腿的衣服裡。</span>
<span className="v" id="v17" data-v="17" data-xref="以西結書 34:20; 約伯記 15:27; 耶利米書 50:11"> 他帶著貢物去見極其肥胖的摩押王伊磯倫。</span>
<span className="v" id="v18" data-v="18"> 以笏獻上了貢物之後，便讓抬貢物的人先回去。</span>
<span className="v" id="v19" data-v="19" data-xref="約書亞記 4:20; 士師記 3:20; 使徒行傳 23:18–19"> 他自己從吉甲附近的石雕神像處折回王宮，對王說：「王啊，我有機密稟告。」王就命左右侍從迴避，眾人便都退去。</span>
<span className="v" id="v20" data-v="20" data-xref="耶利米書 10:7; 阿摩司書 3:15; 詩篇 29:1"> 當時王獨自坐在樓上的房間乘涼，以笏近前說：「我有從上帝而來的訊息要稟告。」王從座位上站起來的時候，</span>
<span className="v" id="v21" data-v="21" data-xref="撒迦利亞書 13:3; 約伯記 20:25; 撒母耳記上 15:33"> 以笏左手拔出藏在右腿上的劍刺進王的肚腹，</span>
<span className="v" id="v22" data-v="22"> 連劍柄也刺了進去，深深嵌入肥肉。以笏沒有拔劍，</span>
<span className="v" id="v23" data-v="23"> 便走出房間，把門都關上，鎖好。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="撒母耳記上 24:3"> 以笏走後，王的僕人過來，見房門緊鎖，以為王在大解。</span>
<span className="v" id="v25" data-v="25"> 等了很久，門還沒開，他們很焦急，就拿鑰匙開門，發現他們的主人已經倒斃在地上。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26"> 他們等待的時候，以笏已經逃走了。他經過石雕神像處，逃往西伊拉。</span>
<span className="v" id="v27" data-v="27" data-xref="士師記 6:34; 撒母耳記上 13:3; 士師記 5:14"> 到了那裡，他就在以法蓮的山區吹響號角，召集以色列人。眾人跟隨以笏下山，</span>
<span className="v" id="v28" data-v="28" data-xref="士師記 12:5; 士師記 7:9; 士師記 7:15"> 以笏對他們說：「跟我來！耶和華已經把仇敵摩押人交在你們手中了。」於是，眾人跟著他下去佔領了通往摩押的約旦河各渡口，不許任何人渡河。</span>
<span className="v" id="v29" data-v="29" data-xref="申命記 32:15; 士師記 3:17; 詩篇 17:10"> 當時他們殺了約一萬名強悍善戰的摩押勇士，沒有一人逃脫。</span>
<span className="v" id="v30" data-v="30" data-xref="士師記 3:11; 士師記 5:31"> 這樣，以色列人征服了摩押人，國中安享太平八十年。</span>
</div>
</div>

## 參孫和大利拉

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="約書亞記 15:47; 以斯拉記 9:1–2; 創世記 38:16–18"> 一天，參孫去迦薩，看見一個妓女，就與她親近。</span>
<span className="v" id="v2" data-v="2" data-xref="詩篇 118:10–12; 撒母耳記上 23:26; 使徒行傳 9:24"> 迦薩人得知參孫來了，便包圍那地方，整夜埋伏在城門口，沒有動手，心想：「等天一亮，我們就殺掉他。」</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行傳 2:24; 詩篇 107:16; 以賽亞書 63:1–5"> 可是，參孫睡到半夜就起來，把城門的門扇連門框和門閂一同拆下，扛到希伯崙對面的山頂上。</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多前書 10:6; 箴言 22:14; 尼希米記 13:26"> 後來，參孫在梭烈谷愛上一位名叫大利拉的女子。</span>
<span className="v" id="v5" data-v="5" data-xref="約書亞記 13:3; 士師記 14:15; 提摩太前書 6:9–10"> 非利士人的首領就上去見這女子，對她說：「請你哄參孫說出他為何有這麼大力氣，我們怎樣才能制伏他，把他綁起來。事後，我們每人會給你一千一百塊銀子。」</span>
<span className="v" id="v6" data-v="6" data-xref="箴言 7:21; 箴言 6:26; 箴言 22:14"> 於是，大利拉問參孫：「求你告訴我，你為什麼有這麼大力氣？用什麼辦法才能把你綁起來制伏你？」</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳記上 21:2–3; 羅馬書 3:8; 撒母耳記上 27:10"> 參孫說：「如果他們用七根還沒乾的青繩子綁住我，我就會像普通人一樣軟弱。」</span>
<span className="v" id="v8" data-v="8" data-xref="傳道書 7:26"> 非利士人的首領便把七根還沒乾的青繩子交給大利拉，她用那些繩子把參孫綁起來。</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 58:9"> 有人已預先埋伏在她的內室，於是她喊道：「參孫，非利士人來捉你了！」但參孫掙斷了繩子，就像掙斷火燒過的麻線一樣。因此，仍然沒有人知道他為何力氣過人。</span>
<span className="v" id="v10" data-v="10" data-xref="士師記 16:13; 路加福音 22:48; 士師記 16:7"> 大利拉對參孫說：「你說謊捉弄我。現在請你告訴我，用什麼方法才能綁住你？」</span>
<span className="v" id="v11" data-v="11" data-xref="箴言 13:5; 以弗所書 4:25; 箴言 13:3"> 參孫回答說：「如果他們用從未用過的新繩子綁住我，我就會像普通人一樣軟弱。」</span>
<span className="v" id="v12" data-v="12"> 於是，大利拉讓人埋伏在內室，她用七根新繩子綁住參孫，然後喊道：「參孫，非利士人來捉你了！」結果，參孫掙斷了手臂上的繩子，就像掙斷一根線一樣。</span>
<span className="v" id="v13" data-v="13"> 大利拉對參孫說：「到現在你還是說謊捉弄我。請你告訴我，用什麼方法才能綁住你？」參孫說：「你把我的七根髮辮和織布機的線編在一起，用梭子扎緊，我就會像普通人一樣軟弱。」</span>
<span className="v" id="v14" data-v="14" data-xref="詩篇 106:43; 以斯拉記 9:13–14"> 於是，大利拉把他的髮辮和織布機的線編在一起，用梭子扎緊，然後喊道：「參孫，非利士人來捉你了！」參孫醒來，掙脫了織布機的梭子和線。</span>
<span className="v" id="v15" data-v="15" data-xref="士師記 14:16; 約翰一書 2:15–16; 約翰福音 14:21–24"> 大利拉對參孫說：「你既然不跟我說真心話，還說什麼愛我！你捉弄了我三次，沒告訴我你為何力氣過人。」</span>
<span className="v" id="v16" data-v="16" data-xref="箴言 7:21–23; 路加福音 18:5; 馬可福音 14:24"> 大利拉天天在他跟前嘮叨不停，以致他煩得要死，</span>
<span className="v" id="v17" data-v="17" data-xref="彌迦書 7:5; 士師記 13:5; 箴言 12:23"> 就把秘密告訴了她。他說：「我從不剃髮，因為我一出生就獻給上帝做拿細耳人了。如果剃掉我的頭髮，我就會失去力氣，像普通人一樣軟弱。」</span>
<span className="v" id="v18" data-v="18" data-xref="馬太福音 26:15; 士師記 16:5; 提摩太前書 6:10"> 大利拉見他說出了心中的秘密，就派人去通知非利士人的首領，說：「你們再來一次吧，他已經把秘密告訴我了。」於是，他們帶著銀子去了。</span>
<span className="v" id="v19" data-v="19" data-xref="箴言 7:26–27; 箴言 7:21–23; 傳道書 7:26"> 大利拉哄參孫枕著她的腿睡覺，然後叫人來剃掉他的七根髮辮，使他力氣盡失，無力反抗。</span>
<span className="v" id="v20" data-v="20" data-xref="民數記 14:42–43; 撒母耳記上 16:14; 約書亞記 7:12"> 她喊道：「參孫，非利士人來捉你了！」參孫醒來，心想：「我要像前幾次一樣掙脫捆綁。」他卻不知道耶和華已經離開他了。</span>
<span className="v" id="v21" data-v="21" data-xref="箴言 2:19; 箴言 14:14; 以賽亞書 47:2"> 非利士人拿住他，剜了他的眼睛，把他帶到迦薩，用銅鏈鎖住他，讓他在監牢裡推磨。</span>
<span className="v" id="v22" data-v="22" data-xref="詩篇 107:13–14; 詩篇 106:44–45; 利未記 26:44"> 後來，他的頭髮又漸漸長出來了。</span>
</div>
</div>

## 參孫之死

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="撒母耳記上 5:2–5; 箴言 24:17; 詩篇 35:15–16"> 非利士人的首領聚在一起向他們的神明大袞獻大祭，歡呼說：「我們的神把仇敵參孫交在我們手中了。」</span>
<span className="v" id="v24" data-v="24" data-xref="但以理書 5:4; 但以理書 5:23; 士師記 15:16"> 眾人看見參孫，就讚美他們的神明，說：「我們的神把仇敵交在我們手中了，他曾毀壞我們的田地，殺死我們許多人。」</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳記下 13:28; 士師記 19:6; 士師記 9:27"> 他們都興高采烈，並喊道：「把參孫帶來讓我們消遣消遣。」於是，有人把參孫從監牢裡提出來供他們消遣，他們讓他站在兩根柱子中間。</span>
<span className="v" id="v26" data-v="26"> 參孫對拉著他手的童僕說：「帶我到支撐這廟宇的柱子那裡，我想靠一靠。」</span>
<span className="v" id="v27" data-v="27" data-xref="申命記 22:8; 撒母耳記下 11:2; 約書亞記 2:8"> 那時，廟裡擠滿了男男女女，非利士人的首領們都在場，房頂上還有三千男女看參孫的熱鬧。</span>
<span className="v" id="v28" data-v="28" data-xref="耶利米書 15:15; 耶利米哀歌 3:31–32; 詩篇 143:12"> 參孫呼求耶和華，說：「主耶和華啊，求你眷顧我！上帝啊，求你再賜給我一次力量，使我向非利士人報剜眼之仇。」</span>
<span className="v" id="v29" data-v="29"> 參孫就抱住廟宇中央的兩根柱子，一手抱一根，</span>
<span className="v" id="v30" data-v="30" data-xref="腓立比書 2:8; 馬太福音 16:25; 馬太福音 24:38–39"> 然後喊道：「我要跟非利士人同歸於盡！」於是，他用盡全力推柱子，廟宇倒塌，壓住裡面的首領和民眾。參孫死時殺的人比他活著時殺的還多。</span>
<span className="v" id="v31" data-v="31" data-xref="士師記 15:20; 士師記 13:25; 士師記 13:2"> 參孫的兄弟和家人取走他的屍體，葬在瑣拉和以實陶之間他父親瑪挪亞的墓地裡。參孫做以色列的士師二十年。</span>

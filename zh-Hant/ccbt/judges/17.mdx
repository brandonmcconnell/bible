## 米迦的神像

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士師記 18:2; 約書亞記 17:14–18; 士師記 10:1"> 以法蓮山區住了一個名叫米迦的人。</span>
<span className="v" id="v2" data-v="2" data-xref="尼希米記 13:25; 路得記 3:10; 撒母耳記上 23:21"> 他對母親說：「你那一千一百塊銀子被拿走了，你因此說了咒詛的話，我都聽見了。看啊，銀子在我這裡，是我拿去的。」他母親說：「我兒啊，願耶和華賜福給你！」</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 20:4; 出埃及記 20:23; 利未記 19:4"> 米迦把一千一百塊銀子還給母親。他母親說：「我要為我兒把這些銀子獻給耶和華，用來雕刻、鑄造神像。我會把銀子交還給你。」</span>
<span className="v" id="v4" data-v="4" data-xref="以賽亞書 46:6–7; 耶利米書 10:9–10"> 米迦把銀子還給母親後，他母親拿出二百塊銀子交給銀匠雕刻、鑄造神像，放在米迦的房子裡。</span>
<span className="v" id="v5" data-v="5" data-xref="士師記 18:14; 士師記 8:27; 創世記 31:19"> 米迦有一個神廟，他製造了一件以弗得和一些家庭神像，並指派他的一個兒子做祭司。</span>
<span className="v" id="v6" data-v="6" data-xref="申命記 12:8; 箴言 14:12; 士師記 21:25"> 那時，以色列沒有王，人人各行其是。</span>
<span className="v" id="v7" data-v="7" data-xref="彌迦書 5:2; 馬太福音 2:1; 路得記 1:1–2"> 猶大的伯利恆住著一個年輕的利未人。</span>
<span className="v" id="v8" data-v="8" data-xref="尼希米記 13:10–11; 士師記 17:11; 約書亞記 24:33"> 他離開伯利恆想到別的地方居住，一路走到以法蓮山區米迦的家。</span>
<span className="v" id="v9" data-v="9"> 米迦問他：「你從哪裡來？」他回答說：「我是從猶大的伯利恆來的利未人，要找一個住的地方。」</span>
<span className="v" id="v10" data-v="10" data-xref="以西結書 13:19; 士師記 18:19–20; 提摩太前書 6:10"> 米迦說：「你就住在我這裡吧，做我的師父和祭司。我每年給你十塊銀子，還為你提供衣服和飲食。」利未人就進了米迦的家，</span>
<span className="v" id="v11" data-v="11"> 住了下來。米迦待他就像待自己的兒子一樣。</span>
<span className="v" id="v12" data-v="12" data-xref="士師記 18:30; 民數記 16:8–10; 民數記 16:5"> 這樣，米迦派他做祭司，讓他住在自己家裡。</span>
<span className="v" id="v13" data-v="13" data-xref="羅馬書 10:2–3; 箴言 14:12; 約翰福音 16:2"> 米迦說：「現在我有一個利未人做我的祭司，我知道耶和華一定會恩待我。」</span>

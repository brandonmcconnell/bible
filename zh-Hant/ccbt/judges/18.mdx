## 米迦和但支派

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士師記 17:6; 士師記 19:1; 士師記 1:34"> 那時以色列沒有王。但支派的人正在尋找可以居住的地方，因為他們在以色列各支派中還沒有得到屬於自己的土地。</span>
<span className="v" id="v2" data-v="2" data-xref="士師記 13:25; 約書亞記 2:1; 士師記 18:11"> 但支派的人從瑣拉和以實陶派本族的五名勇士去打探、察看那個地方，並吩咐說：「你們去察看那個地方。」他們到了以法蓮山區，在米迦家裡借宿。</span>
<span className="v" id="v3" data-v="3" data-xref="士師記 12:6; 創世記 27:22; 馬太福音 26:73"> 他們到了米迦家，聽出那利未青年的口音，就轉身進去問他：「誰帶你來這裡的？你在這裡做什麼？你為什麼在這裡？」</span>
<span className="v" id="v4" data-v="4" data-xref="士師記 17:10; 以西結書 13:19; 箴言 28:21"> 那青年便把米迦聘他做祭司的事告訴了他們。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行傳 8:10; 以賽亞書 30:1; 列王紀上 22:5"> 他們說：「請你求問上帝，看看我們是否一路順利。」</span>
<span className="v" id="v6" data-v="6" data-xref="列王紀上 22:6; 列王紀上 22:15; 詩篇 33:18"> 祭司說：「你們安心去吧，耶和華會一路眷顧你們。」</span>
<span className="v" id="v7" data-v="7" data-xref="約書亞記 19:47; 士師記 18:27–28; 撒母耳記上 3:13"> 五人啟程來到拉億，發現當地人像西頓人一樣無憂無慮，生活安寧，毫無防範，繁榮富足。他們離西頓很遠，與外界沒有來往。</span>
<span className="v" id="v8" data-v="8" data-xref="士師記 18:11; 士師記 18:2; 士師記 13:2"> 五人回到瑣拉和以實陶後，族人問他們：「你們有什麼發現嗎？」</span>
<span className="v" id="v9" data-v="9" data-xref="約書亞記 2:23–24; 民數記 13:30; 約書亞記 18:3"> 他們回答說：「我們前去攻取那地方吧！我們已經打探清楚了，那地方非常好。你們還等什麼？要趕快去佔領那地方。</span>
<span className="v" id="v10" data-v="10" data-xref="士師記 18:27; 士師記 18:7; 申命記 2:29"> 你們到了那裡，會看見當地的居民毫無防範，那裡地大物博，一無所缺。上帝已經把那地方賜給我們了。」</span>
<span className="v" id="v11" data-v="11" data-xref="士師記 18:16"> 但支派便從瑣拉和以實陶派出六百個帶兵器的人。</span>
<span className="v" id="v12" data-v="12" data-xref="士師記 13:25; 約書亞記 15:60; 歷代志下 1:4"> 他們來到猶大的基列·耶琳的西邊安營。因此，那地方至今仍叫瑪哈尼·但<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「瑪哈尼·但」意思是「但的軍營」。">a</a></sup>。</span>
<span className="v" id="v13" data-v="13" data-xref="約書亞記 24:30; 士師記 19:1; 士師記 18:2–3"> 然後，他們去以法蓮山區，來到米迦的家。</span>
<span className="v" id="v14" data-v="14" data-xref="士師記 17:5; 士師記 18:3–4; 撒母耳記上 14:28"> 偵察過拉億的五個人對其餘的人說：「你們知道嗎？這家有以弗得、一些家庭神像、一個雕刻的偶像和一個金屬鑄像。想一想我們該怎麼辦。」</span>
<span className="v" id="v15" data-v="15" data-xref="創世記 43:27; 撒母耳記上 17:22; 約翰福音 14:27"> 那五個人就進入米迦的家裡，到年輕的利未人房間向他問安，</span>
<span className="v" id="v16" data-v="16" data-xref="士師記 18:11"> 隨行的六百人帶著兵器留在門口。</span>
<span className="v" id="v17" data-v="17" data-xref="士師記 18:14; 士師記 17:4–5; 士師記 18:2"> 當時祭司也和那六百個帶兵器的人站在門口。那五個人進去拿走了雕刻的偶像、以弗得、家庭神像及金屬鑄像。</span>
<span className="v" id="v18" data-v="18"> 祭司見那五人進入米迦家拿走雕刻的偶像、以弗得、家庭神像及金屬鑄像，就問他們：「你們在做什麼？」</span>
<span className="v" id="v19" data-v="19" data-xref="約伯記 29:9; 約伯記 21:5; 士師記 17:10"> 他們說：「安靜，別作聲，跟我們來，做我們的師父和祭司吧。做以色列一個支派、一個宗族的祭司難道不比做一家人的祭司更好嗎？」</span>
<span className="v" id="v20" data-v="20" data-xref="以賽亞書 56:11; 以西結書 13:19; 箴言 30:15"> 祭司聽了非常高興，就帶著以弗得、家庭神像及雕刻的偶像跟隨了他們。</span>
<span className="v" id="v21" data-v="21"> 他們轉身離去，兒女、牲畜和財物在隊伍前面。</span>
<span className="v" id="v22" data-v="22"> 他們離開米迦的家一段路後，米迦召集鄰居趕了上來，</span>
<span className="v" id="v23" data-v="23" data-xref="詩篇 114:5; 撒母耳記下 14:5; 撒母耳記上 11:5"> 向他們大喊。但支派的人轉身問米迦：「你們召集這麼多人來做什麼？」</span>
<span className="v" id="v24" data-v="24" data-xref="哈巴谷書 2:18–19; 以賽亞書 44:18–20; 詩篇 115:8"> 米迦說：「你們帶走了我的神像和祭司，把我洗劫一空，還問我想做什麼！」</span>
<span className="v" id="v25" data-v="25" data-xref="約伯記 27:2; 約伯記 3:5; 撒母耳記上 30:6"> 但支派的人說：「別再多說了，不然我們當中性情暴躁的人會攻擊你們，使你全家喪命。」</span>
<span className="v" id="v26" data-v="26"> 但支派的人繼續趕路。米迦見對方人多勢眾，就回家去了。</span>
<span className="v" id="v27" data-v="27" data-xref="約書亞記 19:47; 士師記 18:7; 士師記 18:10"> 但支派的人帶著米迦的神像和他的祭司來到拉億，那裡的人生活安寧，毫無防範。他們用刀殺掉當地的居民，放火燒了城。</span>
<span className="v" id="v28" data-v="28" data-xref="撒母耳記下 10:6; 士師記 18:7; 民數記 13:21"> 拉億離西頓很遠，當地的居民與外界沒有來往，以致孤立無援。這城位於伯·利合附近的山谷中，但支派的人重建該城，住在那裡。</span>
<span className="v" id="v29" data-v="29" data-xref="約書亞記 19:47; 創世記 14:14; 列王紀上 15:20"> 這座城原來叫拉億，他們用祖先以色列的兒子但的名字為該城重新命名。</span>
<span className="v" id="v30" data-v="30" data-xref="撒母耳記上 4:10–11; 士師記 13:1; 士師記 17:5"> 但支派的人把神像豎立起來，又指派摩西的孫子、革舜的兒子約拿單及其子孫做但支派的祭司，直到該地遭受擄掠為止。</span>
<span className="v" id="v31" data-v="31" data-xref="約書亞記 18:1; 撒母耳記上 1:3; 士師記 19:18"> 上帝的會幕設立在示羅期間，米迦的神像一直豎立在但。</span>

## 參孫的出生

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳記上 12:9; 士師記 6:1; 羅馬書 2:6"> 以色列人又做耶和華視為惡的事，耶和華就把他們交在非利士人手中四十年。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="約書亞記 19:41; 路加福音 1:7; 約書亞記 15:33"> 瑣拉城住了一個但支派的人，名叫瑪挪亞。他妻子不能生育，沒有孩子。</span>
<span className="v" id="v3" data-v="3" data-xref="路加福音 1:13; 路加福音 1:11; 士師記 6:11–12"> 耶和華的天使向那婦人顯現，對她說：「你雖然不生育，但不久你必懷孕生一個兒子。</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 1:15; 士師記 13:14; 民數記 6:2–3"> 現在，你要留心，不可喝淡酒和烈酒，不可吃任何不潔之物。</span>
<span className="v" id="v5" data-v="5" data-xref="民數記 6:5; 撒母耳記上 1:11; 歷代志上 18:1"> 你必懷孕生一個兒子，你不可為他剃頭，因為他一出生就要歸給上帝做拿細耳人<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「拿細耳人」參見民數記6·1‑8。">a</a></sup>。他要從非利士人手中拯救以色列人。」</span>
<span className="v" id="v6" data-v="6" data-xref="士師記 13:17–18; 撒母耳記上 9:6; 馬太福音 28:3–4"> 婦人就去對丈夫說：「有一位上帝的僕人向我顯現，他的容貌像上帝的天使，非常可畏。我沒有問他從哪裡來，他也沒有把名字告訴我。</span>
<span className="v" id="v7" data-v="7" data-xref="士師記 13:4"> 他對我說，『你必懷孕生一個兒子，現在不可喝淡酒和烈酒，不可吃任何不潔之物，因為孩子一出生就要獻給耶和華，終生做拿細耳人。』」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="使徒行傳 9:6; 約伯記 34:32; 箴言 3:5–6"> 瑪挪亞向耶和華祈求說：「主啊，求你再派你的僕人到這裡來，教我們怎樣照顧要出生的孩子。」</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 65:2; 馬太福音 7:7–11"> 上帝應允了他的祈求。他妻子正坐在田間的時候，上帝的天使再次向她顯現。當時她丈夫瑪挪亞不在場。</span>
<span className="v" id="v10" data-v="10" data-xref="約翰福音 4:28–29; 約翰福音 1:41–42"> 她趕忙跑去告訴她丈夫說：「那天來的那人又向我顯現了。」</span>
<span className="v" id="v11" data-v="11"> 瑪挪亞起來跟隨妻子來到那人面前，問他：「跟我妻子說話的就是你嗎？」他答道：「是我。」</span>
<span className="v" id="v12" data-v="12" data-xref="箴言 22:6; 以弗所書 6:4; 創世記 18:19"> 瑪挪亞問道：「你的話應驗以後，我們應該怎樣撫養這孩子？他該做什麼？」</span>
<span className="v" id="v13" data-v="13"> 耶和華的天使說：「你的妻子必須謹記我的一切吩咐。</span>
<span className="v" id="v14" data-v="14" data-xref="約翰福音 2:5; 士師記 13:4; 帖撒羅尼迦後書 3:4"> 她不可吃葡萄樹所結的果實，淡酒和烈酒都不可喝，不可吃任何不潔之物。她必須遵行我的一切吩咐。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="士師記 6:18–19; 創世記 18:3–5; 士師記 13:3"> 瑪挪亞說：「請你留下來，我們要預備一隻山羊羔給你吃。」</span>
<span className="v" id="v16" data-v="16" data-xref="士師記 13:23; 士師記 6:20; 士師記 6:26"> 當時，瑪挪亞仍然不知道那人是耶和華的天使。天使說：「我就是留下來也不會吃你預備的食物。你如果預備燔祭，就把它獻給耶和華吧！」</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 32:29"> 瑪挪亞說：「請告訴我你的名字，當一切應驗的時候，我們好向你表達敬意。」</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 32:29; 以賽亞書 9:6; 士師記 13:6"> 耶和華的天使說：「何必問我的名字呢？我的名字奇妙難測。」</span>
<span className="v" id="v19" data-v="19" data-xref="士師記 6:19–21; 列王紀上 18:30–38"> 於是，瑪挪亞就把一隻山羊羔和素祭放在磐石上，獻給耶和華。就在這時候，天使在瑪挪亞夫婦面前行了一件奇妙的事：</span>
<span className="v" id="v20" data-v="20" data-xref="利未記 9:24; 歷代志上 21:16; 列王紀下 2:11"> 火焰從祭壇上升起的時候，耶和華的天使也在祭壇的火焰中升上去了。瑪挪亞夫婦見狀便俯伏在地。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="士師記 6:22; 何西阿書 12:4–5; 士師記 13:16"> 耶和華的天使後來沒再向瑪挪亞夫婦子顯現，瑪挪亞才知道他是耶和華的天使。</span>
<span className="v" id="v22" data-v="22" data-xref="創世記 32:30; 申命記 5:26; 約翰福音 1:18"> 瑪挪亞對妻子說：「我們必死無疑，因為我們看見了上帝。」</span>
<span className="v" id="v23" data-v="23" data-xref="詩篇 25:14; 哥林多前書 12:21; 約翰福音 15:15"> 他妻子卻說：「耶和華如果要殺我們，就不會接受我們的燔祭和素祭了，也不會讓我們看見這些事，更不會這時候跟我們說這些話。」</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="路加福音 1:80; 撒母耳記上 3:19; 希伯來書 11:32"> 後來瑪挪亞的妻子生了個兒子，她給孩子取名叫參孫。這孩子漸漸長大，耶和華賜福給他。</span>
<span className="v" id="v25" data-v="25" data-xref="士師記 3:10; 約書亞記 15:33; 約翰福音 3:34"> 當他在瑣拉和以實陶之間的瑪哈尼·但的時候，耶和華的靈開始感動他。</span>
</div>
</div>

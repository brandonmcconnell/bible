## 討伐基比亞

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士師記 11:11; 撒母耳記上 3:20; 撒母耳記上 10:17"> 於是，從但到別示巴以及基列的全體以色列人齊心來到米斯巴，聚集在耶和華面前。</span>
<span className="v" id="v2" data-v="2" data-xref="士師記 8:10; 士師記 20:17; 士師記 20:15"> 以色列各支派的首領都參加了這次上帝子民的聚會，當時有四十萬持刀的步兵。</span>
<span className="v" id="v3" data-v="3" data-xref="士師記 19:22–27; 路加福音 14:31–32; 路加福音 12:58–59"> 便雅憫人也聽見以色列人聚集在米斯巴的消息。以色列人問那個利未人：「請告訴我們，這件邪惡的事是怎麼發生的？」</span>
<span className="v" id="v4" data-v="4" data-xref="士師記 19:15–28"> 那利未人，就是被害女子的丈夫說：「我和我的妾到便雅憫的基比亞住宿。</span>
<span className="v" id="v5" data-v="5" data-xref="士師記 19:22; 士師記 19:25–26; 創世記 19:4–8"> 那天晚上，基比亞人攻擊我，包圍我們住宿的房子，要殺死我。他們把我的妾蹂躪致死。</span>
<span className="v" id="v6" data-v="6" data-xref="士師記 19:29; 約書亞記 7:15; 士師記 19:23"> 我就把她的屍體切成塊，送到以色列的各個地區，因為基比亞人做了邪惡、無恥的事。</span>
<span className="v" id="v7" data-v="7" data-xref="士師記 19:30; 哥林多前書 5:6; 哥林多前書 5:10–12"> 以色列人啊，你們看該怎麼處理吧！」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="傳道書 9:10; 士師記 20:1; 箴言 21:3"> 眾人起來異口同聲地說：「我們誰也不回帳篷，誰也不回家。</span>
<span className="v" id="v9" data-v="9" data-xref="約拿書 1:7; 尼希米記 11:1; 約書亞記 14:2"> 現在我們要抽籤去攻打基比亞。</span>
<span className="v" id="v10" data-v="10"> 我們要從各支派中抽出十分之一的人負責運糧，等軍隊到達便雅憫的基比亞後，就可以討伐在以色列做出這種卑鄙之事的基比亞人。」</span>
<span className="v" id="v11" data-v="11"> 於是，以色列人團結一致，一起去攻打那城。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="申命記 13:14; 申命記 20:10; 羅馬書 12:18"> 以色列各支派差人去對便雅憫各地的人說：「你們中間怎麼發生了這種邪惡的事！</span>
<span className="v" id="v13" data-v="13" data-xref="申命記 17:12; 申命記 13:13; 士師記 19:22"> 現在把那些基比亞的無賴交出來，我們要處死他們，從以色列剷除罪惡。」便雅憫人卻充耳不聞，</span>
<span className="v" id="v14" data-v="14" data-xref="民數記 20:20; 約伯記 15:25–26; 民數記 21:23"> 還從各城聚集到基比亞，要跟以色列人打仗。</span>
<span className="v" id="v15" data-v="15" data-xref="民數記 26:41; 士師記 20:25; 民數記 1:37"> 便雅憫人從各城召集了兩萬六千刀兵，還從基比亞召集了七百精兵。</span>
<span className="v" id="v16" data-v="16" data-xref="士師記 3:15; 歷代志上 12:2; 撒母耳記上 17:49–50"> 軍中有七百精兵善用左手甩石，毫髮不差。</span>
<span className="v" id="v17" data-v="17" data-xref="民數記 1:46; 歷代志下 17:14–18; 民數記 26:51"> 其他十一個以色列支派則召集了四十萬刀兵，個個善戰。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="士師記 20:23; 士師記 20:26–27; 民數記 27:21"> 以色列人到伯特利去求問上帝，說：「我們當中哪個支派應當先去攻打便雅憫人呢？」耶和華說：「猶大支派。」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="約書亞記 7:16; 約書亞記 3:1; 約書亞記 6:12"> 第二天清早，以色列人起來在基比亞附近安營，</span>
<span className="v" id="v20" data-v="20"> 朝著便雅憫人擺開陣勢，準備攻打他們。</span>
<span className="v" id="v21" data-v="21" data-xref="士師記 20:25; 詩篇 73:18–19; 歷代志下 28:10"> 便雅憫人從基比亞出來，當天殺了以色列軍兩萬二千人。</span>
<span className="v" id="v22" data-v="22" data-xref="詩篇 64:5; 士師記 20:17; 撒母耳記上 30:6"> 以色列人重整士氣，仍在前一天列陣的地方列陣。</span>
<span className="v" id="v23" data-v="23" data-xref="士師記 20:26–27; 詩篇 78:34–36; 約書亞記 7:6"> 列陣之前，他們在耶和華面前一直哀哭到晚上。他們求問耶和華，說：「我們應該再上去攻打我們的同胞便雅憫人嗎？」耶和華說：「要上去攻打他們。」</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24"> 第二天，以色列人前去攻打便雅憫人。</span>
<span className="v" id="v25" data-v="25" data-xref="士師記 20:21; 創世記 18:25; 羅馬書 2:5"> 便雅憫人從基比亞出來迎戰，又殺了以色列軍一萬八千刀兵。</span>
<span className="v" id="v26" data-v="26" data-xref="士師記 20:23; 約珥書 2:12–18; 士師記 20:18"> 以色列全軍來到伯特利，坐在耶和華面前哀哭，那天他們一直禁食到晚上，又在耶和華面前獻上燔祭和平安祭。</span>
<span className="v" id="v27" data-v="27" data-xref="約書亞記 18:1; 士師記 20:18; 撒母耳記上 4:3–4"> 那時，上帝的約櫃就在那裡，亞倫的孫子、以利亞撒的兒子非尼哈任祭司。以色列人求問耶和華，說：「我們應該再去攻打我們的同胞便雅憫人嗎？還是退兵？」耶和華說：「去攻打吧，因為明天我必把他們交在你們手中。」</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="約書亞記 8:4; 撒母耳記下 5:23; 士師記 20:34"> 以色列人在基比亞周圍設下伏兵。</span>
<span className="v" id="v30" data-v="30"> 第三天，以色列人又像前兩次一樣在基比亞列陣，攻打便雅憫人。</span>
<span className="v" id="v31" data-v="31" data-xref="士師記 19:13–14; 約書亞記 7:5; 以賽亞書 10:29"> 便雅憫人前來迎戰，被以色列人誘到城外。他們又像前兩次一樣擊殺以色列人，大約三十名以色列人死在通往基比亞和伯特利的兩條路上。</span>
<span className="v" id="v32" data-v="32" data-xref="約書亞記 8:15–16"> 便雅憫人說：「我們又像以前一樣打敗他們了。」但以色列人已經商議好，用詐敗的方法誘敵離城到大路上來。</span>
<span className="v" id="v33" data-v="33" data-xref="約書亞記 8:18–22"> 以色列全軍在巴力·他瑪列陣反攻，埋伏在基比亞西面的以色列人也衝了出來。</span>
<span className="v" id="v34" data-v="34" data-xref="約書亞記 8:14; 以賽亞書 47:11; 約伯記 21:13"> 有一萬以色列精兵從正面攻打基比亞，戰事非常激烈。便雅憫人大禍臨頭了仍懵然不知。</span>
<span className="v" id="v35" data-v="35" data-xref="約伯記 20:5; 士師記 20:15; 士師記 20:44–46"> 耶和華幫助以色列人戰勝了便雅憫人。那天，以色列人殺了便雅憫兩萬五千一百刀兵。</span>
<span className="v" id="v36" data-v="36" data-xref="約書亞記 8:15–29"> 便雅憫人這才意識到自己戰敗了。<br />原來以色列人在便雅憫人面前詐敗，因為他們仰仗在基比亞附近設下的伏兵。</span>
<span className="v" id="v37" data-v="37" data-xref="約書亞記 8:19; 約書亞記 6:5; 出埃及記 19:13"> 那些伏兵迅速衝進基比亞，用刀殺了全城的人。</span>
<span className="v" id="v38" data-v="38" data-xref="約書亞記 8:20; 創世記 17:21; 列王紀下 4:16"> 以色列人和伏兵已有約定，伏兵在城內點起一股濃煙時，</span>
<span className="v" id="v39" data-v="39" data-xref="士師記 20:32"> 以色列人便轉身殺回。便雅憫人殺了詐敗的以色列軍大約三十人，以為像以前一樣打敗了他們。</span>
<span className="v" id="v40" data-v="40" data-xref="約書亞記 8:20; 啟示錄 19:3; 創世記 19:28"> 這時基比亞城已濃煙滾滾，便雅憫人回頭觀望，只見全城濃煙四起。</span>
<span className="v" id="v41" data-v="41" data-xref="彼得後書 2:12; 路加福音 21:26; 啟示錄 6:15–17"> 以色列人轉身殺了回來，便雅憫人大驚失色，知道大禍臨頭了。</span>
<span className="v" id="v42" data-v="42" data-xref="約書亞記 8:15; 何西阿書 9:9; 耶利米哀歌 1:3"> 他們從以色列人面前轉身逃往曠野，卻無法逃脫。以色列人從各城出來夾攻他們。</span>
<span className="v" id="v43" data-v="43" data-xref="約書亞記 8:20–22"> 以色列人圍攻便雅憫人，一路追殺他們直到基比亞的東邊。</span>
<span className="v" id="v44" data-v="44"> 便雅憫人共死了一萬八千名勇士。</span>
<span className="v" id="v45" data-v="45" data-xref="約書亞記 15:32; 士師記 21:13; 撒迦利亞書 14:10"> 餘下的人都逃往曠野的臨門巖，沿途有五千人被殺。以色列人追殺他們，一直追到基頓，又消滅了他們兩千人。</span>
<span className="v" id="v46" data-v="46" data-xref="士師記 20:35; 士師記 20:15"> 那天，便雅憫人共死了兩萬五千名英勇的刀兵，</span>
<span className="v" id="v47" data-v="47" data-xref="以賽亞書 1:9; 詩篇 103:9–10; 哈巴谷書 3:2"> 只有六百人逃到了臨門巖，在那裡住了四個月。</span>
<span className="v" id="v48" data-v="48" data-xref="申命記 13:15–17; 歷代志下 25:13; 歷代志下 28:6–9"> 以色列人回師便雅憫境內，用刀將各城的男女老少以及牲畜全部殺死，又放火燒毀所有的城邑。</span>
</div>
</div>

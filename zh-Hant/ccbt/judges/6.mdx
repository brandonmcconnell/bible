## 士師基甸

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="尼希米記 9:26–29; 士師記 2:19–20; 士師記 2:13–14"> 後來，以色列人又做耶和華視為惡的事，耶和華就把他們交在米甸人手下七年。</span>
<span className="v" id="v2" data-v="2" data-xref="希伯來書 11:38; 撒母耳記上 13:6; 申命記 28:47–48"> 米甸人勢力強盛，以色列人只好躲進山裡，藏在洞穴和營寨中。</span>
<span className="v" id="v3" data-v="3" data-xref="士師記 6:33; 士師記 3:13; 士師記 7:12"> 每當他們撒種的時候，米甸人、亞瑪力人及東方人就前來進犯，</span>
<span className="v" id="v4" data-v="4" data-xref="利未記 26:16; 申命記 28:51; 彌迦書 6:15"> 在他們境內安營，摧毀他們遠至迦薩一帶的莊稼，不給他們留下任何糧食，也不留下一隻羊、一頭牛或驢。</span>
<span className="v" id="v5" data-v="5" data-xref="士師記 7:12; 士師記 8:10; 耶利米書 46:23"> 入侵者帶著牲畜和帳篷像蝗蟲一樣湧來，人和駱駝不計其數，摧毀了整個地區。</span>
<span className="v" id="v6" data-v="6" data-xref="士師記 3:9; 耶利米書 5:17; 詩篇 50:15"> 以色列人因米甸人的入侵而極其貧乏，就呼求耶和華。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7"> 當以色列人因米甸人的入侵而呼求耶和華的時候，</span>
<span className="v" id="v8" data-v="8" data-xref="以西結書 20:5–32; 以賽亞書 63:9–14; 詩篇 136:10–16"> 耶和華就差遣先知對他們說：「以色列的上帝耶和華說，『我曾把你們從受奴役之地埃及領出來，</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 44:2–3"> 將你們從埃及人及一切欺壓者的手中拯救出來，從你們面前趕走他們，把他們的土地賜給你們。』</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米書 10:2; 列王紀下 17:35–39; 耶利米書 9:13"> 我曾對你們說，『我是你們的上帝耶和華。你們雖然住在亞摩利人的地方，但不可祭拜他們的神明。』你們卻充耳不聞。」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="約書亞記 17:2; 希伯來書 11:32; 士師記 13:3"> 一天，耶和華的天使來到俄弗拉，坐在亞比以謝族人約阿施的橡樹下。約阿施的兒子基甸因為要躲避米甸人，正躲在榨酒池裡打麥子。</span>
<span className="v" id="v12" data-v="12" data-xref="約書亞記 1:5; 路加福音 1:28; 士師記 2:18"> 耶和華的天使向基甸顯現，對他說：「英勇的戰士啊，耶和華與你同在。」</span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 77:7–9; 歷代志下 15:2; 以賽亞書 59:1–2"> 基甸說：「我主啊，如果耶和華與我們同在，我們怎會有這些遭遇？我們的祖先說耶和華曾帶他們出埃及，但如今祂那些奇妙的作為在哪裡呢？現在祂已經丟棄我們，把我們交在米甸人手裡。」</span>
<span className="v" id="v14" data-v="14" data-xref="約書亞記 1:5–9; 希伯來書 11:34; 撒母耳記上 12:11"> 耶和華轉向他，說：「你盡自己的力量去從米甸人手中拯救以色列人吧，我現在派你去。」</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳記上 9:21; 出埃及記 3:11; 出埃及記 4:10"> 基甸說：「主啊，我出身於瑪拿西支派最弱小的家族，在家裡最微不足道，我怎能拯救以色列人呢？」</span>
<span className="v" id="v16" data-v="16" data-xref="約書亞記 1:5; 出埃及記 3:12; 使徒行傳 11:21"> 耶和華說：「我必與你同在，你必如擊打一人一樣擊打米甸人。」</span>
<span className="v" id="v17" data-v="17" data-xref="詩篇 86:17; 出埃及記 33:13; 以賽亞書 7:11"> 基甸說：「如果我在你面前蒙恩，求你給我一個憑據，使我知道與我說話的真是你耶和華。</span>
<span className="v" id="v18" data-v="18" data-xref="士師記 13:15; 創世記 18:3; 創世記 18:5"> 請你在這裡等一等，讓我回去拿禮物獻給你。」耶和華說：「我必等你回來。」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="創世記 18:6–8; 士師記 13:15–19; 利未記 2:4"> 基甸回家預備了一隻山羊羔，用十公斤麵粉做了無酵餅，把肉放進籃子，把湯盛在壺中，然後拿到橡樹下獻上。</span>
<span className="v" id="v20" data-v="20" data-xref="士師記 13:19; 列王紀上 18:33–34"> 上帝的天使對基甸說：「把肉和無酵餅放在這磐石上，把湯倒在上面。」他一一照做。</span>
<span className="v" id="v21" data-v="21" data-xref="利未記 9:24; 列王紀上 18:38; 歷代志下 7:1"> 耶和華的天使伸出手中的杖碰了一下餅和肉，火就從磐石中噴出來燒盡了它們。耶和華的天使也不見了。</span>
<span className="v" id="v22" data-v="22" data-xref="創世記 32:30; 出埃及記 33:20; 申命記 5:26"> 基甸發現他果然是耶和華的天使，便說：「唉！主耶和華啊，不好了，我面對面見了你的天使。」</span>
<span className="v" id="v23" data-v="23" data-xref="但以理書 10:19; 約翰福音 20:26; 創世記 43:23"> 耶和華對他說：「放心吧，不要害怕，你不會死。」</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 22:14; 出埃及記 17:15; 士師記 8:32"> 基甸在那裡為耶和華築了一座壇，稱之為「耶和華賜平安」。這壇如今仍在亞比以謝族的俄弗拉。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="出埃及記 34:13; 士師記 3:7; 使徒行傳 5:29"> 那天晚上，耶和華吩咐基甸：「牽來你父親的第二頭牛，就是那頭七歲的公牛，拆毀你父親為巴力築的祭壇，砍倒壇旁的亞舍拉神像。</span>
<span className="v" id="v26" data-v="26" data-xref="哥林多前書 14:40; 撒母耳記下 24:18; 哥林多前書 14:33"> 然後，在這座山頂上把石頭堆放整齊，為你的上帝耶和華築一座祭壇，用砍倒的亞舍拉神像作柴，把那頭公牛獻作燔祭。」</span>
<span className="v" id="v27" data-v="27" data-xref="帖撒羅尼迦前書 2:4; 約翰福音 2:5; 申命記 4:1"> 於是，基甸帶了十個僕人遵命而行。不過，他因為害怕家人和城中的人，不敢在白天行動，便在夜間行動。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28"> 清早，城裡的人起來後，發現巴力的祭壇已經被人拆毀，壇旁的亞舍拉神像被砍倒，第二頭公牛被獻在新建的祭壇上。</span>
<span className="v" id="v29" data-v="29"> 他們彼此議論說：「這是誰幹的？」他們仔細調查後得知是約阿施的兒子基甸所為，</span>
<span className="v" id="v30" data-v="30" data-xref="使徒行傳 26:9; 腓立比書 3:6; 耶利米書 50:38"> 便對約阿施說：「把你兒子交出來！他拆毀了巴力的祭壇，砍倒了壇旁的亞舍拉神像，我們要處死他！」</span>
<span className="v" id="v31" data-v="31" data-xref="耶利米書 10:11; 哥林多前書 8:4; 以弗所書 5:11"> 約阿施對氣勢洶洶的人群說：「你們這樣做是要為巴力辯護嗎？是要救它嗎？誰為巴力辯護，今天早晨就處死誰。有人拆毀巴力的祭壇，如果它是神明，就讓它為自己辯護吧！」</span>
<span className="v" id="v32" data-v="32" data-xref="撒母耳記上 12:11; 士師記 7:1; 撒母耳記下 11:21"> 因此，那天他們稱基甸為耶路·巴力，意思是「讓巴力為自己辯護」，因為他拆毀了巴力的祭壇。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="約書亞記 17:16; 士師記 6:3; 羅馬書 8:35–39"> 那時，米甸人、亞瑪力人及東方人會合在一起，過了約旦河，在耶斯列的平原安營。</span>
<span className="v" id="v34" data-v="34" data-xref="士師記 3:27; 歷代志下 24:20; 士師記 3:10"> 耶和華的靈降在基甸身上，他就吹響號角，號召亞比以謝族的人跟從他。</span>
<span className="v" id="v35" data-v="35" data-xref="歷代志下 30:6–12; 士師記 4:6"> 他派人走遍瑪拿西、亞設、西布倫和拿弗他利各支派召集軍隊，人們紛紛前來會合。</span>
<span className="v" id="v36" data-v="36" data-xref="士師記 6:14; 馬太福音 16:1; 士師記 6:17–20"> 基甸對上帝說：「若如你所言，你要用我去拯救以色列人，</span>
<span className="v" id="v37" data-v="37" data-xref="何西阿書 14:5; 馬太福音 10:5–6; 馬太福音 15:24"> 求你給個憑據。我把一團羊毛放在麥場上，若明天早晨只是羊毛上有露水，地面卻是乾的，我就知道，如你所言，你要用我去拯救以色列人。」</span>
<span className="v" id="v38" data-v="38" data-xref="以賽亞書 35:7"> 果然如此，基甸一早醒來，從羊毛中擠出滿滿一碗露水。</span>
<span className="v" id="v39" data-v="39" data-xref="創世記 18:32; 以賽亞書 50:2; 詩篇 107:33–35"> 基甸又對上帝說：「求你不要發怒，容許我再試一次，這次讓羊毛是乾的，地面有露水。」</span>
<span className="v" id="v40" data-v="40"> 那天晚上，上帝就照他所求使地面佈滿露水，唯獨羊毛是乾的。</span>
</div>
</div>

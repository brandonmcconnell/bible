## 利未人和他的妾

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士師記 18:1; 士師記 17:8; 瑪拉基書 2:15"> 那時候，以色列沒有王。有一個利未人住在以法蓮山區的偏遠地帶，他娶了猶大的伯利恆的一個女子為妾。</span>
<span className="v" id="v2" data-v="2" data-xref="以西結書 16:28; 申命記 22:21; 利未記 21:9"> 那女子不忠，離開丈夫回到猶大的伯利恆的父親家，住了四個月。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 34:3; 創世記 50:21; 利未記 19:17"> 後來，她丈夫帶著一個僕人和兩頭驢去見她，用好話勸她回去。那女子帶他去見自己的父親。她父親看見女婿來了，便熱情地接待他，</span>
<span className="v" id="v4" data-v="4"> 留他在家裡小住。他便在那裡住了三天，一起吃住。</span>
<span className="v" id="v5" data-v="5" data-xref="士師記 19:8; 創世記 18:5; 詩篇 104:15"> 第四天，他清早起來準備回家，岳父對他說：「吃點東西補充體力後再走吧。」</span>
<span className="v" id="v6" data-v="6" data-xref="士師記 19:9; 士師記 16:25; 路得記 3:7"> 於是，二人坐下來一起吃喝。岳父對他說：「再住一夜，高興高興吧。」</span>
<span className="v" id="v7" data-v="7"> 他不肯答應，起來要走，但岳父一再挽留，他就又住了一夜。</span>
<span className="v" id="v8" data-v="8"> 第五天清早起來，他準備回家，岳父對他說：「吃點東西補充體力，太陽偏西再走吧。」於是，二人一同吃飯。</span>
<span className="v" id="v9" data-v="9" data-xref="箴言 27:1; 路加福音 24:29; 雅各書 4:13–14"> 他帶著妾和僕人起來要走的時候，岳父對他說：「看啊，太陽偏西了，天色已晚，再住一夜高興高興，明天一早再走吧。」</span>
<span className="v" id="v10" data-v="10" data-xref="約書亞記 15:63; 約書亞記 15:8; 士師記 1:8"> 可是，他不願意再留一夜，就備好兩頭驢，帶著他的妾走了，來到耶布斯附近。耶布斯就是耶路撒冷。</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳記下 5:6; 士師記 1:21; 士師記 19:10"> 他們臨近耶布斯時，天快黑了，僕人對主人說：「我們不如就在耶布斯人的城裡住宿吧。」</span>
<span className="v" id="v12" data-v="12"> 主人說：「我們不可在非以色列人的外邦城邑住宿，不如趕到基比亞。」</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳記上 10:26; 何西阿書 5:8; 以賽亞書 10:29"> 他又說：「我們前往基比亞或拉瑪住宿吧。」</span>
<span className="v" id="v14" data-v="14"> 於是，他們繼續前行，到便雅憫境內的基比亞時，天已經黑了。</span>
<span className="v" id="v15" data-v="15" data-xref="士師記 19:18; 馬太福音 25:35; 馬太福音 25:43"> 他們決定在那裡過夜。因為沒有人接待他們，他們只好在城中的廣場露宿。</span>
<span className="v" id="v16" data-v="16" data-xref="士師記 19:1; 詩篇 104:23; 創世記 3:19"> 那時，有一個老人從田間工作回來，經過那裡。他本來是以法蓮山區的人，現在住在便雅憫境內的基比亞。</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 32:17; 創世記 16:8"> 他看見有人在城中的廣場露宿，就問：「你們從哪裡來，要到哪裡去？」</span>
<span className="v" id="v18" data-v="18" data-xref="士師記 18:31; 約翰福音 15:6; 撒母耳記上 1:7"> 利未人回答說：「我們從猶大的伯利恆來，正要回家去。我住在以法蓮山區的偏遠地帶。我現在要去耶和華的殿。這裡沒有人接待我。</span>
<span className="v" id="v19" data-v="19"> 其實我有糧草餵驢，我和我的妾及僕人也有餅和酒，什麼也不缺。」</span>
<span className="v" id="v20" data-v="20" data-xref="士師記 6:23; 雅各書 2:15–16; 希伯來書 13:2"> 那老人說：「歡迎到我家來，我會供應你們的需要，千萬不可在街頭露宿。」</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 43:24; 創世記 18:4; 路加福音 7:44"> 於是，那老人帶他們回家，餵他們的驢。他們洗完腳後，便一起吃喝。</span>
<span className="v" id="v22" data-v="22" data-xref="創世記 19:4–5; 哥林多前書 6:9; 士師記 20:5"> 他們正歡樂的時候，城裡的一群無賴前來圍住房子，連連叩門，對年長的家主說：「把你家裡的客人交出來，我們要跟他交合。」</span>
<span className="v" id="v23" data-v="23" data-xref="創世記 34:7; 撒母耳記下 13:12; 士師記 20:6"> 老人出去對他們說：「弟兄們啊，不要做這種惡事！這人是我的客人，不要幹這種卑鄙的事！</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 19:8; 申命記 21:14; 創世記 34:2"> 我有個女兒，仍是處女，還有這人的妾，我把她們交出來，任你們玩弄，只是不要對這人幹這種卑鄙的事。」</span>
<span className="v" id="v25" data-v="25" data-xref="何西阿書 10:9; 何西阿書 9:9; 何西阿書 7:4–7"> 他們卻不肯聽。利未人就把自己的妾推出去交給他們。他們強暴她，終夜凌辱她，直到天快亮才放她走。</span>
<span className="v" id="v26" data-v="26" data-xref="士師記 19:3; 創世記 18:12; 彼得前書 3:6"> 天亮時她回到丈夫住宿的房子門前，就仆倒在地。</span>
<span className="v" id="v27" data-v="27"> 早晨，她丈夫起來打開房門要上路，發現她倒臥在門前，雙手搭在門檻上，</span>
<span className="v" id="v28" data-v="28" data-xref="士師記 20:5; 列王紀上 18:29"> 就對她說：「起來，我們走吧！」她卻沒有反應。於是，他就把她的屍體放在驢背上啟程回家。</span>
<span className="v" id="v29" data-v="29" data-xref="士師記 20:6–7; 撒母耳記上 11:7; 羅馬書 10:2"> 回到家裡，他用刀把屍體切成十二塊，派人送往以色列全境。</span>
<span className="v" id="v30" data-v="30" data-xref="士師記 20:7; 箴言 13:10; 何西阿書 9:9"> 看見的人都說：「自從以色列人離開埃及以來，這種事從未發生過，也從未見過。我們必須商量一下，看看該怎麼辦。」</span>

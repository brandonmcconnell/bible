## 亞比米勒做王

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士師記 8:31; 詩篇 83:2–4; 撒母耳記下 15:6"> 耶路·巴力的兒子亞比米勒去示劍的舅舅家，對外祖父全家說：</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 29:14; 士師記 8:30; 希伯來書 2:14"> 「請你們去問示劍人，耶路·巴力的七十個兒子統治他們好呢，還是一個人統治他們好呢？別忘記我是你們的骨肉至親。」</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 29:15; 詩篇 10:3; 箴言 1:11–14"> 他們便將他的話轉告示劍人。示劍人因為亞比米勒是他們的親戚，都擁護他，</span>
<span className="v" id="v4" data-v="4" data-xref="士師記 8:33; 使徒行傳 17:5; 歷代志下 13:7"> 從巴力·比利土的廟裡拿了七十塊銀子給他。他用這些錢收買了一班無賴做隨從。</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀下 11:1–2; 歷代志下 21:4; 士師記 6:24"> 他前往俄弗拉，來到他父親家，在一塊磐石上殺死了他七十個同父異母的兄弟，只有耶路·巴力的小兒子約坦躲了起來，倖免於難。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳記下 5:9; 列王紀上 12:20; 列王紀下 12:20"> 示劍和米羅的人都聚集到示劍石柱旁的橡樹下，擁立亞比米勒為王。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="申命記 11:29; 約翰福音 4:20; 申命記 27:12"> 約坦聽見這消息，便上到基利心山頂，高喊：「示劍人啊，你們要聽我說，這樣上帝也會聽你們說。</span>
<span className="v" id="v8" data-v="8" data-xref="士師記 8:22–23; 但以理書 4:10–18; 列王紀下 14:9"> 從前，樹木要選一個王，它們對橄欖樹說，『你來做我們的王。』</span>
<span className="v" id="v9" data-v="9" data-xref="利未記 2:1; 出埃及記 29:7; 使徒行傳 4:27"> 橄欖樹說，『我怎能因為貪圖淩駕於眾樹之上而停止出產用來尊崇神明與人的橄欖油呢？』</span>
<span className="v" id="v10" data-v="10"> 樹木對無花果樹說，『你來做我們的王。』</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 13:6–7"> 無花果樹說，『我怎能因為貪圖淩駕於眾樹之上而停止出產甜美的果子呢？』</span>
<span className="v" id="v12" data-v="12"> 於是，樹木對葡萄樹說，『你來做我們的王。』</span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 104:15; 傳道書 10:19; 民數記 15:5"> 葡萄樹說，『我怎能因為貪圖淩駕於眾樹之上而停止出產令神明和世人都快樂的美酒呢？』</span>
<span className="v" id="v14" data-v="14" data-xref="列王紀下 14:9"> 最後，所有的樹木都對荊棘說，『你來做我們的王。』</span>
<span className="v" id="v15" data-v="15" data-xref="以賽亞書 30:2; 士師記 9:20; 何西阿書 14:7"> 荊棘回答說，『你們如果誠心立我為你們的王，就投靠在我的蔭下吧；不然，願火從荊棘中冒出來吞噬黎巴嫩的香柏樹。』</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="士師記 8:35"> 「現在你們立亞比米勒為王，光明正大嗎？你們有沒有善待耶路·巴力和他一家？有沒有按他的功績對待他？</span>
<span className="v" id="v17" data-v="17" data-xref="羅馬書 16:4; 羅馬書 5:8; 啟示錄 12:11"> 你們想想，從前我父親為你們出生入死，從米甸人手中拯救你們。</span>
<span className="v" id="v18" data-v="18" data-xref="士師記 9:5–6; 士師記 8:30–31; 士師記 9:14"> 現在你們卻背叛我父親家，在一塊磐石上殺死他七十個兒子。因為他婢女的兒子亞比米勒是你們的親戚，你們就立亞比米勒為示劍居民的王。</span>
<span className="v" id="v19" data-v="19" data-xref="以賽亞書 8:6; 雅各書 4:16; 腓立比書 3:3"> 如果你們光明正大地對待了耶路·巴力一家，願你們給亞比米勒帶來快樂，也願亞比米勒給你們帶來快樂。</span>
<span className="v" id="v20" data-v="20" data-xref="士師記 9:15; 士師記 9:56–57; 歷代志下 20:22–23"> 否則，願亞比米勒燒滅你們示劍人和米羅人，也願你們示劍人和米羅人燒滅亞比米勒。」</span>
<span className="v" id="v21" data-v="21" data-xref="民數記 21:16; 撒母耳記下 20:14; 約書亞記 19:8"> 約坦因懼怕他的兄弟亞比米勒，就逃往比珥居住。</span>
</div>
</div>

## 亞比米勒毀滅示劍

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22"> 亞比米勒治理以色列三年後，</span>
<span className="v" id="v23" data-v="23" data-xref="以賽亞書 33:1; 以賽亞書 19:14; 以賽亞書 19:2"> 上帝派遣一個邪靈挑起亞比米勒和示劍人之間的爭端，示劍人用詭詐的手段對待亞比米勒。</span>
<span className="v" id="v24" data-v="24" data-xref="列王紀上 2:32; 詩篇 7:16; 以斯帖記 9:25"> 這是要懲罰亞比米勒和幫他殘殺耶路·巴力七十個兒子的示劍人。</span>
<span className="v" id="v25" data-v="25" data-xref="約書亞記 8:12–13; 箴言 1:11–12; 約書亞記 8:4"> 示劍人在山頂設下埋伏，等候亞比米勒，他們搶劫所有過路的行人。有人把這事告訴了亞比米勒。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="創世記 13:8; 創世記 19:7"> 以別的兒子迦勒和他的弟兄來到示劍，示劍人都信任他們。</span>
<span className="v" id="v27" data-v="27" data-xref="士師記 9:4; 士師記 9:46; 詩篇 109:17"> 示劍人出城到田間採摘葡萄，踩榨葡萄汁，然後在他們的神廟中歡宴，盡情吃喝，咒詛亞比米勒。</span>
<span className="v" id="v28" data-v="28" data-xref="創世記 34:2; 創世記 34:6; 撒母耳記上 25:10"> 以別的兒子迦勒說：「亞比米勒是誰？我們示劍人是誰，竟要服侍他？他不就是耶路·巴力的兒子嗎？他的幫手不就是西布勒嗎？我們為什麼要服侍他？你們要服侍示劍人祖先哈抹的後代。</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳記下 15:4; 撒母耳記下 2:14–17; 以賽亞書 36:8–9"> 要是這百姓歸我領導就好了！我會除掉亞比米勒，我會挑戰他召集全軍來戰<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「我會挑戰他召集全軍來戰」參照《七十士譯本》；希伯來文作「他對亞比米勒說：『召集你的全軍來戰吧！』」">a</a></sup>。」</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30"> 示劍城的官長西布勒聽見以別的兒子迦勒的話，勃然大怒，</span>
<span className="v" id="v31" data-v="31"> 暗中派人對亞比米勒說：「以別的兒子迦勒和他的弟兄已經到了示劍，正在煽動全城反對你。</span>
<span className="v" id="v32" data-v="32" data-xref="羅馬書 3:15; 詩篇 36:4; 箴言 1:11–16"> 請你晚上帶著部下埋伏在田間，</span>
<span className="v" id="v33" data-v="33" data-xref="撒母耳記上 10:7; 傳道書 9:10; 利未記 25:26"> 清晨日出時攻城。迦勒帶著部下出來應戰時，你便可以見機行事。」</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34"> 於是，亞比米勒帶領軍隊夜間出發，兵分四路埋伏在示劍城外。</span>
<span className="v" id="v35" data-v="35"> 早晨，以別的兒子迦勒出來站在城門口時，亞比米勒帶領部下從埋伏的地方衝了出來。</span>
<span className="v" id="v36" data-v="36" data-xref="馬可福音 8:24; 以西結書 7:7"> 迦勒看見他們，便對西布勒說：「看！有人正從山頂下來。」西布勒說：「你把山影看成人了吧。」</span>
<span className="v" id="v37" data-v="37" data-xref="申命記 18:14"> 迦勒說：「看！有人正從山上下來，還有一隊人正從占卜橡樹那邊的路上奔來。」</span>
<span className="v" id="v38" data-v="38" data-xref="士師記 9:28–29; 列王紀下 14:8–14; 撒母耳記下 2:26–27"> 西布勒說：「你的豪氣哪裡去了？你曾說，『亞比米勒是誰，我們竟要服侍他？』這些不就是你譏笑的人嗎？出去迎戰吧！」</span>
<span className="v" id="v39" data-v="39"> 於是，迦勒率領示劍人出城迎戰亞比米勒。</span>
<span className="v" id="v40" data-v="40" data-xref="列王紀上 20:18–21; 列王紀上 20:30"> 迦勒敗逃，亞比米勒緊追不捨，沿途有許多人受傷倒在地上，一直到城門口。</span>
<span className="v" id="v41" data-v="41" data-xref="士師記 9:28; 士師記 9:30"> 之後，亞比米勒住在亞魯瑪，西布勒把迦勒和他的弟兄逐出示劍。</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42"> 第二天，示劍人出城來到田間。亞比米勒得知後，</span>
<span className="v" id="v43" data-v="43"> 把部下兵分三隊，埋伏在田間，等城裡的人出來時，伏擊他們。</span>
<span className="v" id="v44" data-v="44" data-xref="加拉太書 5:15; 士師記 9:15; 士師記 9:20"> 亞比米勒率領一隊人衝到示劍的城門口，截斷示劍人的退路，其他兩隊擊殺田間的示劍人。</span>
<span className="v" id="v45" data-v="45" data-xref="列王紀下 3:25; 申命記 29:23; 雅各書 2:13"> 亞比米勒鏖戰一天，攻陷了示劍城，殺了城內的居民，把整座城夷為平地，還撒上了鹽。</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="士師記 8:33; 士師記 9:4; 列王紀上 8:26"> 示劍樓的人聽到風聲，躲進了伊勒·比利土神廟的內堂。</span>
<span className="v" id="v47" data-v="47"> 亞比米勒得知他們都聚在那裡後，</span>
<span className="v" id="v48" data-v="48" data-xref="詩篇 68:14; 箴言 1:11–12; 士師記 7:17–18"> 便領兵上撒們山用斧頭砍下樹枝，扛在肩上，並命令部下趕緊照做。</span>
<span className="v" id="v49" data-v="49" data-xref="加拉太書 5:15; 雅各書 3:16; 士師記 9:20"> 他們都砍下樹枝，跟著亞比米勒把樹枝堆在神廟內堂的四周，放火燒死了示劍樓裡所有的人，男女約一千人。</span>
</div>
<div className="bp">
<span className="v" id="v50" data-v="50"> 隨後，亞比米勒去圍攻提備斯，佔領了該城。</span>
<span className="v" id="v51" data-v="51"> 全城的人連男帶女都逃進城中一座堅固的城樓內，鎖上大門，爬上樓頂。</span>
<span className="v" id="v52" data-v="52" data-xref="士師記 9:48–49; 列王紀下 14:10; 列王紀下 15:16"> 亞比米勒攻打城樓，走到城樓門口正準備放火時，</span>
<span className="v" id="v53" data-v="53" data-xref="撒母耳記下 11:21; 約伯記 31:3; 耶利米書 49:20"> 有個婦人扔下一塊磨石，砸爛了他的頭。</span>
<span className="v" id="v54" data-v="54" data-xref="撒母耳記上 31:4–5"> 亞比米勒連忙對為他拿兵器的年輕人說：「拔刀殺了我吧，免得人們說，『一位婦人殺了他。』」於是，那年輕人刺死了他。</span>
<span className="v" id="v55" data-v="55" data-xref="撒母耳記下 18:16; 撒母耳記下 20:21–22; 列王紀上 22:35–36"> 以色列人見亞比米勒已死，便各自回家了。</span>
<span className="v" id="v56" data-v="56" data-xref="詩篇 94:23; 士師記 9:24; 箴言 5:22"> 上帝就這樣使亞比米勒得到了報應，因為他殘殺了自己的七十個兄弟，</span>
<span className="v" id="v57" data-v="57" data-xref="士師記 9:20; 約書亞記 6:26; 列王紀上 16:34"> 上帝也讓示劍人因自己的一切惡行而得到了報應。耶路·巴力的兒子約坦的咒詛臨到了他們。</span>
</div>

## 士師底波拉

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="耶利米書 5:3; 士師記 3:12; 士師記 3:7"> 以笏死後，以色列人又做耶和華視為惡的事。</span>
<span className="v" id="v2" data-v="2" data-xref="約書亞記 11:1; 士師記 4:16; 士師記 4:13"> 耶和華把他們交在統治夏瑣的迦南王耶賓手中。耶賓王的將軍叫西西拉，住在夏羅設。</span>
<span className="v" id="v3" data-v="3" data-xref="士師記 1:19; 詩篇 106:42; 士師記 3:9"> 耶賓王擁有九百輛鐵戰車，他殘暴地壓迫以色列人二十年。以色列人向耶和華呼求。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及記 15:20; 路加福音 2:36; 列王紀下 22:14"> 當時做以色列士師的是女先知底波拉，她是拉比多的妻子，</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 18:19; 耶利米書 31:15; 出埃及記 18:26"> 經常坐在以法蓮山區拉瑪和伯特利之間的底波拉棕樹下，審理以色列人的糾紛。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行傳 13:47; 士師記 8:18; 希伯來書 11:32"> 她派人去拿弗他利的基低斯召來亞比挪庵的兒子巴拉，對他說：「以色列的上帝耶和華命你率領一萬拿弗他利人和西布倫人上他泊山。</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀上 18:40; 以西結書 38:10–16; 詩篇 83:9–10"> 祂必使耶賓的將軍西西拉率領全軍和戰車到基順河與你交戰，祂必把西西拉交在你手中。」</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及記 4:10–14; 馬太福音 14:30–31"> 巴拉回答說：「你跟我去，我就去；你不跟我去，我就不去。」</span>
<span className="v" id="v9" data-v="9" data-xref="士師記 2:14; 撒母耳記上 2:30; 士師記 4:17–22"> 底波拉說：「好，我一定與你同去。不過，你這次出征一定得不到榮耀，因為耶和華要把西西拉交在一名婦人手上。」於是，底波拉起身與巴拉一同前往基低斯。</span>
<span className="v" id="v10" data-v="10" data-xref="士師記 5:18; 士師記 5:15; 士師記 4:14"> 巴拉招聚了一萬名拿弗他利人和西布倫人，底波拉與他一起出征。</span>
<span className="v" id="v11" data-v="11" data-xref="士師記 1:16; 約書亞記 19:33; 民數記 10:29"> 摩西的岳父何巴的後人基尼人希百離開自己的族人，在基低斯附近撒拿音的橡樹旁搭帳篷居住。</span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 89:12; 耶利米書 46:18; 約書亞記 19:12"> 西西拉得知亞比挪庵的兒子巴拉已經上了他泊山，</span>
<span className="v" id="v13" data-v="13" data-xref="士師記 4:2–3; 士師記 4:7"> 便召集全軍和九百輛鐵戰車離開夏羅設，向基順河進軍。</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 9:3; 撒母耳記下 5:24; 以賽亞書 52:12"> 底波拉對巴拉說：「出擊吧！今天耶和華要把西西拉交在你手中。看啊，耶和華已經率先出戰了！」於是，巴拉率領一萬人下了他泊山，</span>
<span className="v" id="v15" data-v="15" data-xref="約書亞記 10:10; 詩篇 83:9–10; 士師記 5:20–21"> 進攻西西拉。耶和華使西西拉的戰車和軍隊潰亂，敗在巴拉刀下。西西拉棄車徒步逃跑，</span>
<span className="v" id="v16" data-v="16" data-xref="羅馬書 2:12; 利未記 26:7–8; 雅各書 2:13"> 巴拉追擊他的戰車和軍隊，直到夏羅設。西西拉全軍都死於刀下，無一逃脫。</span>
<span className="v" id="v17" data-v="17" data-xref="詩篇 69:22; 以賽亞書 57:21; 阿摩司書 5:19–20"> 只有西西拉一人徒步逃到基尼人希百的妻子雅億的帳篷，因為夏瑣王耶賓和希百家向來友好。</span>
<span className="v" id="v18" data-v="18" data-xref="列王紀下 6:19"> 雅億出來迎接西西拉，對他說：「我主，請進，不用怕！」西西拉便走進帳篷，雅億為他蓋上毯子。</span>
<span className="v" id="v19" data-v="19" data-xref="士師記 5:25–26; 創世記 24:43; 以賽亞書 41:17"> 西西拉說：「我口渴，請給我一點水吧。」雅億打開皮袋給他奶喝，然後又給他蓋上毯子。</span>
<span className="v" id="v20" data-v="20" data-xref="約書亞記 2:3–5; 撒母耳記下 17:20"> 西西拉又說：「請你守著門口，倘若有人查問，你就說沒人來過這裡。」</span>
<span className="v" id="v21" data-v="21" data-xref="士師記 5:26–27; 哥林多前書 1:27; 士師記 3:21"> 西西拉因疲勞過度，沉沉入睡。雅億乘機拿起錘子和一根帳篷的橛子，悄悄地走到他身旁，把橛子釘進他的太陽穴，直插到地裡。西西拉就這樣死了。</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳記下 17:10–15; 撒母耳記下 17:3"> 巴拉追來了，雅億出來迎接他，對他說：「你找的人在這裡，進來看看吧。」巴拉和她進了帳篷，見西西拉死在那裡，太陽穴上還插著橛子。</span>
<span className="v" id="v23" data-v="23" data-xref="尼希米記 9:24; 詩篇 18:47; 詩篇 18:39"> 那天，上帝使以色列人戰勝了迦南王耶賓。</span>
<span className="v" id="v24" data-v="24" data-xref="撒母耳記上 3:12"> 以色列人越戰越勇，最終消滅了迦南王耶賓。</span>

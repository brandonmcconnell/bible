## 參孫娶非利士女子為妻

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="約書亞記 15:10; 約書亞記 19:43; 約翰一書 2:16"> 參孫下到亭拿，在那裡看中了一個非利士女子。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 34:4; 創世記 21:21; 創世記 24:2–3"> 他回到家裡便對父母說：「我在亭拿看中一個非利士女子，把她給我娶來做妻子吧！」</span>
<span className="v" id="v3" data-v="3" data-xref="士師記 15:18; 撒母耳記上 17:36; 撒母耳記上 14:6"> 他父母說：「難道我們的親族和同胞中沒有合適的女子嗎？你為什麼要娶未受割禮的非利士人的女子呢？」參孫卻說：「我很喜歡她，請給我把她娶過來吧！」</span>
<span className="v" id="v4" data-v="4" data-xref="約書亞記 11:20; 詩篇 115:3; 士師記 13:1"> 他的父母不知道這事是出於耶和華的旨意，祂要找機會對付非利士人。那時，非利士人統治著以色列。</span>
<span className="v" id="v5" data-v="5"> 參孫跟父母一起去亭拿，走到亭拿的葡萄園時，有一頭猛獅吼叫著撲向他。</span>
<span className="v" id="v6" data-v="6" data-xref="士師記 3:10; 士師記 13:25; 撒母耳記上 11:6"> 耶和華的靈突然降在參孫身上，他雖然手無寸鐵，竟撕裂了那頭獅子，就像撕裂一隻山羊羔一樣。他沒有把這事告訴父母。</span>
<span className="v" id="v7" data-v="7"> 到了亭拿，參孫跟那女子交談，很喜歡她。</span>
<span className="v" id="v8" data-v="8" data-xref="馬太福音 1:20; 創世記 29:21"> 過了些日子，參孫下去迎娶她，途中他順便去看那隻死獅子，見死獅子體內有一群蜜蜂和一些蜂蜜，</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳記上 14:25–30; 箴言 25:15"> 就用手取了一些蜜，邊走邊吃。到了父母那裡，他給了他們一些，他們也吃了。但他沒有告訴父母蜂蜜是從死獅子體內取的。</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 29:22; 啟示錄 19:9; 以斯帖記 1:7–22"> 參孫的父親去那女子家，參孫按習俗擺設宴席。</span>
<span className="v" id="v11" data-v="11" data-xref="馬太福音 9:15; 撒母耳記上 16:6; 撒母耳記上 10:23"> 眾人看見參孫，就安排了三十個人陪他。</span>
<span className="v" id="v12" data-v="12" data-xref="列王紀上 10:1; 以西結書 17:2; 創世記 45:22"> 參孫對他們說：「我出一個謎語，如果你們可以在這七天的婚宴期間猜出來，我就送你們三十件細麻衣和三十件外袍。</span>
<span className="v" id="v13" data-v="13"> 如果猜不中，你們就要給我三十件細麻衣和三十件外袍。」他們說：「請你出謎語吧！」</span>
<span className="v" id="v14" data-v="14" data-xref="雅各書 1:2–4; 列王紀上 17:6; 羅馬書 8:37"> 參孫說：<br /><span className="pl pl-1">「食物出自食者，</span><br /><span className="pl pl-1">甜物出自強者。」</span>三天過後，他們仍然猜不出來。</span>
<span className="v" id="v15" data-v="15" data-xref="士師記 16:5; 士師記 15:6; 箴言 6:26"> 到了第四天，他們對參孫的妻子說：「你要哄你的丈夫把謎底說出來，不然我們就把你和你父親一家全燒死。你們邀請我們來，難道是要奪取我們的家產嗎？」</span>
<span className="v" id="v16" data-v="16" data-xref="士師記 16:15; 創世記 2:24"> 於是，參孫的妻子向他哭訴說：「你是恨我，不是愛我。你給我的族人出了謎語，卻沒有告訴我謎底。」參孫回答說：「我連父母都沒有告訴，又怎能告訴你呢？」</span>
<span className="v" id="v17" data-v="17" data-xref="士師記 16:16; 約伯記 2:9; 士師記 16:13"> 在七天的婚宴期間，她一直在丈夫跟前哭哭啼啼。到了第七天，參孫經不住妻子的催逼就把謎底告訴了她。她把謎底告訴了她的族人。</span>
<span className="v" id="v18" data-v="18"> 在第七天日落之前，城裡的人對參孫說：<br /><span className="pl pl-1">「有什麼比蜂蜜更甜？</span><br /><span className="pl pl-1">有什麼比獅子更強？」</span>參孫說：<br /><span className="pl pl-1">「你們若不是利用我的小母牛耕田，</span><br /><span className="pl pl-1">肯定猜不出來。」</span></span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳記上 11:6; 士師記 3:10; 士師記 13:25"> 耶和華的靈突然降在參孫身上，他便去亞實基倫殺了三十個人，取走他們的衣服，交給猜中謎語的那些人，然後怒氣沖沖地回父親家去了。</span>
<span className="v" id="v20" data-v="20" data-xref="士師記 15:2; 約翰福音 3:29; 詩篇 55:12–13"> 參孫的妻子後來歸了他的伴郎。</span>

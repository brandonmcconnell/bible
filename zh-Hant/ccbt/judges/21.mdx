## 為便雅憫支派娶妻

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士師記 20:1; 馬可福音 6:23; 使徒行傳 23:12"> 以色列人曾在米斯巴起誓不把女兒嫁給便雅憫人。</span>
<span className="v" id="v2" data-v="2" data-xref="士師記 20:26; 士師記 20:18; 撒母耳記上 30:4"> 他們來到伯特利，坐在上帝面前放聲痛哭，直到黃昏。</span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 74:1; 約書亞記 7:7–9; 以賽亞書 63:17"> 他們說：「以色列的上帝耶和華啊，以色列現今為何少了一個支派呢？為何發生了這樣的事呢？」</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳記下 24:25; 列王紀上 8:64; 詩篇 78:34–35"> 第二天，眾人清早起來在那裡築了一座祭壇，獻上燔祭和平安祭。</span>
<span className="v" id="v5" data-v="5" data-xref="士師記 5:23; 士師記 21:18; 士師記 21:1"> 他們彼此議論說：「我們到米斯巴聚集在耶和華面前的時候，各支派中誰沒有來呢？」原來，他們曾經起誓說：凡不到米斯巴聚集在耶和華面前的人都要被處死。</span>
<span className="v" id="v6" data-v="6" data-xref="士師記 21:15; 士師記 20:23; 路加福音 19:41–42"> 以色列人為他們的同胞便雅憫人難過，說：「如今以色列絕了一個支派。</span>
<span className="v" id="v7" data-v="7" data-xref="士師記 21:1; 士師記 21:18; 撒母耳記上 14:28–29"> 我們曾經在耶和華面前起誓，決不把女兒嫁給便雅憫人，現在我們應該怎麼辦，才能使他們剩下來的人得到妻子呢？」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="撒母耳記上 31:11–13; 撒母耳記上 11:1–3; 撒母耳記下 2:5–6"> 他們又查問各支派中誰沒有到米斯巴聚集在耶和華面前，結果發現基列·雅比人缺席，</span>
<span className="v" id="v9" data-v="9"> 因為點兵的時候，沒有一個基列·雅比人在場。</span>
<span className="v" id="v10" data-v="10" data-xref="士師記 5:23; 士師記 21:5; 撒母耳記上 11:7"> 於是，會眾派出一萬二千精兵，命令他們用刀殺掉基列·雅比人及其婦女和孩子。</span>
<span className="v" id="v11" data-v="11" data-xref="民數記 31:17–18; 申命記 2:34"> 他們對精兵說：「你們所要做的就是消滅所有的男子和已婚婦女。」</span>
<span className="v" id="v12" data-v="12" data-xref="約書亞記 18:1; 耶利米書 7:12; 詩篇 78:60"> 他們在基列·雅比的居民中找到四百名處女，把她們帶回迦南的示羅營地。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="士師記 20:47; 申命記 20:10; 以弗所書 2:17"> 全體會眾又派人到臨門巖去跟便雅憫人講和。</span>
<span className="v" id="v14" data-v="14" data-xref="士師記 21:12; 哥林多前書 7:2; 士師記 20:47"> 於是，便雅憫人返回了家鄉，以色列人把從基列·雅比居民中留下來的四百個處女給他們做妻子，但還是不夠。</span>
<span className="v" id="v15" data-v="15" data-xref="士師記 21:6; 歷代志上 15:13; 以賽亞書 58:12"> 眾人為便雅憫支派難過，因為耶和華使以色列少了一個支派。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16"> 會眾的長老說：「便雅憫支派的女子都死了，我們應該怎麼辦才能使餘下的人有妻子呢？</span>
<span className="v" id="v17" data-v="17" data-xref="民數記 26:55; 民數記 36:7"> 便雅憫的餘民必須成家立後，以免以色列失去一個支派。</span>
<span className="v" id="v18" data-v="18" data-xref="士師記 21:1; 士師記 11:35"> 可是我們又不能把女兒嫁給他們，因為我們曾經起誓，『把女兒嫁給便雅憫人的必受咒詛。』」</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 16:10; 申命記 16:1; 申命記 16:13"> 有人想起在示羅每年都有耶和華的節期。示羅在利波拿以南、伯特利以北至示劍的大路東面。</span>
<span className="v" id="v20" data-v="20"> 於是，他們對便雅憫人說：「你們去埋伏在葡萄園裡，</span>
<span className="v" id="v21" data-v="21" data-xref="士師記 11:34; 出埃及記 15:20; 傳道書 3:4"> 見到示羅的女子出來跳舞時，就衝出去各自搶一個，帶回便雅憫做妻子。</span>
<span className="v" id="v22" data-v="22" data-xref="士師記 21:1; 士師記 21:18; 士師記 21:14"> 倘若她們的父親或弟兄前來抱怨，我們會說，『求你們看在我們的情面上恩待他們，因為我們從戰場上帶回的女子不夠分給他們做妻子。何況又不是你們把女兒嫁給他們的，所以罪不在你們。』」</span>
<span className="v" id="v23" data-v="23" data-xref="士師記 20:48"> 便雅憫人就依計行事，從跳舞的女子中各自搶了一個，帶回自己的家鄉做妻子。他們重建城邑，住在其中。</span>
<span className="v" id="v24" data-v="24"> 於是，以色列人離開那裡，各回自己的支派、宗族和家園。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="申命記 12:8; 士師記 17:6; 箴言 3:5"> 那時，以色列沒有王，人人各行其是。</span>
</div>

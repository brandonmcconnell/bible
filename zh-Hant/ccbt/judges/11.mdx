## 士師耶弗他

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="希伯來書 11:32; 士師記 6:12; 列王紀下 5:1"> 基列人耶弗他是個英勇的戰士，他父親名叫基列，母親是個妓女。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 12:10; 箴言 2:16; 申命記 23:2"> 基列的妻子還生了幾個兒子，他們長大後，便把耶弗他趕出家門，說：「你是別的女人生的，你休想繼承我們父親的任何產業。」</span>
<span className="v" id="v3" data-v="3" data-xref="士師記 9:4; 撒母耳記上 22:2; 撒母耳記下 10:8"> 耶弗他只好逃走，住在陀伯地區。有一群匪徒聚集到他身邊，跟隨了他。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="士師記 10:9"> 後來，亞捫人攻打以色列，</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 118:22–23; 使徒行傳 7:35–39; 哥林多前書 1:27–29"> 基列的眾長老就去陀伯請耶弗他，</span>
<span className="v" id="v6" data-v="6"> 對他說：「請你回來做統帥帶領我們對抗亞捫人。」</span>
<span className="v" id="v7" data-v="7" data-xref="啟示錄 3:9; 創世記 45:4–5; 以賽亞書 60:14"> 耶弗他說：「從前你們不是厭惡我，把我從父親家趕走的嗎？現在你們遭難，為什麼來找我？」</span>
<span className="v" id="v8" data-v="8" data-xref="士師記 10:18; 列王紀上 13:6; 出埃及記 10:17"> 基列的眾長老說：「我們現在是來請你跟我們一起回去抵抗亞捫人，你可以做所有基列人的首領。」</span>
<span className="v" id="v9" data-v="9" data-xref="民數記 32:20–29"> 耶弗他說：「如果你們請我回去與亞捫人作戰，耶和華讓我打敗他們，我就真的可以做你們的首領嗎？」</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米書 42:5; 創世記 31:50; 耶利米書 29:23"> 基列的首領們說：「我們必聽從你的吩咐，有耶和華為我們作證。」</span>
<span className="v" id="v11" data-v="11" data-xref="士師記 10:17; 撒母耳記上 10:17; 士師記 20:1"> 於是，耶弗他便跟他們一起回去。民眾擁立他做他們的首領和元帥。耶弗他在米斯巴將之前所說的話在耶和華面前重申一遍。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="申命記 2:26; 馬太福音 18:15–16; 箴言 25:8–9"> 然後，他派遣使者去問亞捫王：「你與我有什麼相干？為什麼要攻打我的領土？」</span>
<span className="v" id="v13" data-v="13" data-xref="創世記 32:22; 民數記 21:24–26; 申命記 2:37"> 亞捫王對他的使者說：「因為以色列人從埃及出來的時候佔據了我們的土地，從亞嫩河到雅博河，一直到約旦河。現在你們要和平地歸還我們。」</span>
<span className="v" id="v14" data-v="14" data-xref="彼得前書 3:11; 羅馬書 12:18; 希伯來書 12:14"> 耶弗他再差遣使者去見亞捫王，</span>
<span className="v" id="v15" data-v="15" data-xref="申命記 2:19; 申命記 2:9; 民數記 21:27–30"> 對他說：「以色列人並沒有佔據摩押和亞捫的土地。</span>
<span className="v" id="v16" data-v="16" data-xref="民數記 14:25; 申命記 1:40; 民數記 20:1"> 當年以色列人離開埃及，經曠野渡過紅海來到加低斯，</span>
<span className="v" id="v17" data-v="17" data-xref="民數記 20:14–21; 申命記 2:4–9; 民數記 20:1"> 然後派遣使者去見以東王，說，『求你讓我們經過你的領土。』以東王卻不答應。他們又派遣使者去見摩押王，摩押王也不答應。於是，以色列人就住在加低斯。</span>
<span className="v" id="v18" data-v="18" data-xref="申命記 2:1–8; 民數記 22:36; 民數記 21:4–13"> 後來，他們走過曠野，繞過以東和摩押，到了摩押的東邊，在摩押的邊界亞嫩河東岸紮營，並沒有進入摩押境內。</span>
<span className="v" id="v19" data-v="19" data-xref="民數記 21:21–35; 申命記 2:26–36; 申命記 3:1–17"> 以色列人派遣使者去見希實本的亞摩利王西宏，對他說，『求讓我們經過你的領土前往我們自己的土地。』</span>
<span className="v" id="v20" data-v="20" data-xref="約書亞記 13:15–32; 民數記 21:23–25; 詩篇 136:17–21"> 但西宏不信任以色列人，拒絕了他們的請求，並招聚全軍駐紮在雅雜，攻打他們。</span>
<span className="v" id="v21" data-v="21"> 但以色列的上帝耶和華幫助以色列人戰勝西宏和他的軍隊，佔領了亞摩利人所有的土地，</span>
<span className="v" id="v22" data-v="22" data-xref="申命記 2:36"> 從亞嫩河直到雅博河，從曠野直到約旦河。</span>
<span className="v" id="v23" data-v="23"> 既然是以色列的上帝耶和華為祂的以色列子民趕走了亞摩利人，你憑什麼要奪取這塊土地？</span>
<span className="v" id="v24" data-v="24" data-xref="民數記 21:29; 詩篇 78:55; 彌迦書 4:5"> 你擁有你們的神明基抹給你們的土地，我們也要擁有我們的上帝耶和華賜給我們的土地。</span>
<span className="v" id="v25" data-v="25" data-xref="彌迦書 6:5; 約書亞記 24:9–10; 申命記 23:3–4"> 難道你比摩押王西撥的兒子巴勒更強嗎？他從未挑戰過以色列人，也未和以色列人交過戰。</span>
<span className="v" id="v26" data-v="26" data-xref="申命記 2:36; 約書亞記 12:5; 士師記 10:8"> 三百年來，以色列人一直住在希實本及其周圍的鄉村、亞羅珥及其周圍的鄉村和亞嫩河沿岸一帶的城邑。在這期間，你們為什麼不收回這些土地呢？</span>
<span className="v" id="v27" data-v="27" data-xref="撒母耳記上 24:15; 創世記 16:5; 撒母耳記上 24:12"> 我們沒有得罪你們，你們卻攻打我們。願審判者耶和華今天在以色列人和亞捫人之間主持公道。」</span>
<span className="v" id="v28" data-v="28" data-xref="列王紀下 14:11; 箴言 16:18"> 可是，亞捫王不理會耶弗他派使者所傳的話。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="民數記 11:25; 士師記 3:10; 士師記 13:25"> 那時，耶和華的靈降在耶弗他身上，他便經過基列和瑪拿西，來到基列的米斯巴，然後從那裡去迎戰亞捫人。</span>
<span className="v" id="v30" data-v="30" data-xref="創世記 28:20; 撒母耳記上 1:11; 傳道書 5:1–2"> 他向耶和華許願說：「如果你把亞捫人交在我手中，</span>
<span className="v" id="v31" data-v="31" data-xref="詩篇 66:13–14; 利未記 27:28–29; 撒母耳記上 1:28"> 讓我平安歸來，第一個從我家門出來迎接我的人必歸給你，我必把他獻給你作燔祭。」</span>
<span className="v" id="v32" data-v="32" data-xref="士師記 1:4; 士師記 2:18; 士師記 3:10"> 於是，耶弗他率軍與亞捫人作戰，耶和華把敵人交在他手中，</span>
<span className="v" id="v33" data-v="33" data-xref="以西結書 27:17; 申命記 2:36"> 他大敗敵軍，摧毀了從亞羅珥到米匿、遠至亞備勒·基拉明的二十座城。這樣，以色列人征服了亞捫人。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="耶利米書 31:4; 出埃及記 15:20; 士師記 10:17"> 耶弗他返回自己在米斯巴的家，他的獨生女兒敲著鼓、跳著舞出來迎接他。</span>
<span className="v" id="v35" data-v="35" data-xref="馬太福音 14:7–9; 創世記 37:29–30; 創世記 42:36–38"> 他一見自己的女兒，便撕裂衣服，說：「唉，我的女兒啊，你真讓我傷心欲絕，禍患臨頭！我向耶和華許了願，不能收回了！」</span>
<span className="v" id="v36" data-v="36" data-xref="撒母耳記下 18:19; 腓立比書 2:30; 羅馬書 16:4"> 他女兒說：「父親啊，你既然向耶和華許了願，就照你許的願對待我吧！因為耶和華幫你打敗了敵軍亞捫人，為你報了仇。</span>
<span className="v" id="v37" data-v="37" data-xref="路加福音 1:25; 撒母耳記上 1:6"> 但求你先給我兩個月的時間，讓我和同伴到山上去為我終身未嫁哀哭。」</span>
<span className="v" id="v38" data-v="38"> 耶弗他答應了，給了她兩個月的時間。於是，她便和同伴到山上為自己終身未嫁哀哭。</span>
<span className="v" id="v39" data-v="39" data-xref="以賽亞書 66:3; 士師記 11:31; 利未記 27:28–29"> 兩個月後，她回到父親那裡。她父親履行了自己所許的願。她從未與男人同房。自此以後，在以色列有個習俗：</span>
<span className="v" id="v40" data-v="40" data-xref="列王紀上 9:25; 士師記 5:11"> 每年以色列的女子都去為基列人耶弗他的女兒哀哭四天。</span>
</div>
</div>

## 治好手枯的人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="馬太福音 12:9–14; 路加福音 6:6–11; 馬可福音 1:21"> 耶穌又進了會堂，那裡有個人一隻手是萎縮的。</span>
<span className="v" id="v2" data-v="2" data-xref="詩篇 37:32; 路加福音 14:1; 路加福音 6:7"> 當時有好些人監視耶穌，看祂會不會在安息日醫治這個人，好控告祂。</span>
<span className="v" id="v3" data-v="3" data-xref="腓立比書 1:28–30; 以賽亞書 42:4; 路加福音 6:8"> 耶穌對那一隻手萎縮的人說：「起來，站在中間。」</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 6:9; 馬太福音 12:10–12; 何西阿書 6:6"> 然後問眾人：「在安息日應該行善還是作惡？救人還是害人？」他們都不吭聲。</span>
<span className="v" id="v5" data-v="5" data-xref="路加福音 6:10; 以弗所書 4:18; 羅馬書 11:25"> 耶穌生氣地看著四周這些人，為他們心裡剛硬而深感難過。祂對那人說：「把手伸出來！」那人一伸手，手就復原了。</span>
<span className="v" id="v6" data-v="6" data-xref="馬太福音 22:16; 馬可福音 12:13; 馬太福音 12:14"> 法利賽人立刻出去，跟希律黨的人策劃怎樣除掉耶穌。</span>
</div>
</div>

## 群眾跟隨耶穌

<div className="bt">
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="馬太福音 4:25; 路加福音 6:17; 馬太福音 12:15"> 耶穌和門徒退到湖邊，有一大群人從加利利來跟隨祂。</span>
<span className="v" id="v8" data-v="8" data-xref="以西結書 35:15; 以賽亞書 34:5; 馬太福音 11:21"> 還有很多人聽見耶穌的一切作為，就從猶太、耶路撒冷、以土買、約旦河東，甚至泰爾和西頓一帶來找祂。</span>
<span className="v" id="v9" data-v="9" data-xref="馬可福音 5:30; 約翰福音 6:15"> 耶穌見人多，就吩咐門徒為祂預備一條小船，以免人群擁擠祂。</span>
<span className="v" id="v10" data-v="10" data-xref="馬太福音 14:36; 馬可福音 6:56; 馬太福音 4:23"> 因為祂醫治了很多人，凡有疾病的人都想擠過來摸祂。</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 4:41; 馬可福音 1:23–24; 路加福音 8:28"> 污鬼一看見祂，就俯伏在祂面前，大喊：「你是上帝的兒子！」</span>
<span className="v" id="v12" data-v="12" data-xref="馬太福音 12:16; 馬可福音 1:25; 馬可福音 1:34"> 耶穌卻嚴厲地警告牠們不要洩露祂的身分。</span>
</div>
</div>

## 選立十二使徒

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="路加福音 9:1; 路加福音 6:12–16; 馬太福音 10:1–4"> 耶穌上了山，把自己想要的人召來，他們就來到祂面前。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行傳 1:8; 路加福音 9:1–6; 約翰福音 15:16"> 祂從中選出十二人立為使徒，讓他們跟隨自己，並且差遣他們出去傳道，</span>
<span className="v" id="v15" data-v="15"> 賜他們趕鬼的權柄。</span>
<span className="v" id="v16" data-v="16" data-xref="約翰福音 1:42; 使徒行傳 1:13; 馬太福音 16:16–18"> 祂設立的十二位使徒是：西門——耶穌給他取名叫彼得、</span>
<span className="v" id="v17" data-v="17" data-xref="希伯來書 4:12; 馬可福音 14:33; 耶利米書 23:29"> 西庇太的兒子雅各和雅各的兄弟約翰——耶穌給他們取名叫「半尼其」，就是「雷霆之子」的意思、</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行傳 1:13; 馬可福音 2:14; 馬太福音 9:9"> 安得烈、腓力、巴多羅買、馬太、多馬、亞勒腓的兒子雅各、達太、激進黨人西門，</span>
<span className="v" id="v19" data-v="19" data-xref="約翰福音 6:71; 約翰福音 13:2; 使徒行傳 1:16–25"> 及後來出賣耶穌的加略人猶大。</span>
</div>
</div>

## 耶穌和別西卜

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="馬可福音 6:31; 約翰福音 4:31–34; 馬可福音 9:28"> 耶穌剛進家門，人群又聚集起來，以致祂和門徒都無暇吃飯。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行傳 26:24; 約翰福音 10:20; 馬可福音 3:31"> 祂的親屬聽見這個消息，就出來要制止祂，因為他們說祂瘋了。</span>
<span className="v" id="v22" data-v="22" data-xref="馬太福音 15:1; 馬太福音 10:25; 馬太福音 9:34"> 從耶路撒冷下來的律法教師說：「祂被別西卜附身。」又說：「祂是靠鬼王趕鬼。」</span>
<span className="v" id="v23" data-v="23" data-xref="路加福音 11:17–23; 馬太福音 12:25–30; 馬太福音 13:34"> 耶穌叫他們來，用比喻對他們說：「撒旦怎能驅逐撒旦呢？</span>
<span className="v" id="v24" data-v="24" data-xref="撒迦利亞書 11:14; 以賽亞書 19:2–3; 撒母耳記下 20:6"> 一個國內部自相紛爭，必無法堅立。</span>
<span className="v" id="v25" data-v="25" data-xref="雅各書 3:16; 詩篇 133:1; 加拉太書 5:15"> 一個家內部自相紛爭，必無法堅立。</span>
<span className="v" id="v26" data-v="26"> 同樣，撒旦如果與自己為敵，自相紛爭，就站立不住，必然滅亡。</span>
<span className="v" id="v27" data-v="27" data-xref="以賽亞書 49:24–26; 馬太福音 12:29; 路加福音 11:21–23"> 沒有人能進入壯漢家裡搶奪財物，除非先把那壯漢捆綁起來，才能搶劫他的家。</span>
<span className="v" id="v28" data-v="28" data-xref="路加福音 12:10; 馬太福音 12:31–32; 約翰一書 5:16"> 「我實在告訴你們，世人一切的罪和褻瀆的話都可以得到赦免，</span>
<span className="v" id="v29" data-v="29" data-xref="馬太福音 12:31–32; 路加福音 12:10; 帖撒羅尼迦後書 1:9"> 唯有褻瀆聖靈的人永遠得不到赦免，他們要永遠擔罪。」</span>
<span className="v" id="v30" data-v="30" data-xref="約翰福音 10:20; 馬可福音 3:22"> 耶穌這樣說是因為他們誣衊祂被污鬼附身。</span>
</div>
</div>

## 誰是耶穌的親人

<div className="bt">
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="路加福音 8:19–21; 馬太福音 12:46–50"> 這時候，耶穌的母親和兄弟來了，他們站在外面，託人叫耶穌。</span>
<span className="v" id="v32" data-v="32"> 有許多人圍坐在耶穌身邊，他們告訴祂說：「看啊！你的母親和兄弟在外面找你。」</span>
<span className="v" id="v33" data-v="33" data-xref="馬可福音 3:21; 申命記 33:9; 馬可福音 6:3"> 耶穌說：「誰是我的母親？誰是我的兄弟？」</span>
<span className="v" id="v34" data-v="34" data-xref="馬太福音 12:49–50; 路加福音 11:27–28; 羅馬書 8:29"> 然後祂望著周圍坐著的人說：「看啊，我的母親和我的兄弟！</span>
<span className="v" id="v35" data-v="35" data-xref="約翰一書 2:17; 馬太福音 7:21; 約翰一書 3:22–23"> 凡遵行上帝旨意的人都是我的弟兄、姊妹和母親。」</span>
</div>
</div>

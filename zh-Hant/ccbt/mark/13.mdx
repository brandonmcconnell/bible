## 預言聖殿被毀

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="馬太福音 24:1–51; 以西結書 11:22–23; 以西結書 10:19"> 耶穌走出聖殿的時候，有一個門徒對祂說：「老師，你看！這是多麼大的石頭，多麼宏偉的建築啊！」</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 21:6; 馬太福音 24:2; 列王紀上 9:7–8"> 耶穌說：「你看見這些宏偉的建築了嗎？將來要被完全拆毀，找不到兩塊疊在一起的石頭。」</span>
<span className="v" id="v3" data-v="3" data-xref="馬太福音 21:1; 馬可福音 4:34; 馬可福音 14:33"> 耶穌面向聖殿坐在橄欖山上，彼得、雅各、約翰和安得烈私下來問祂：</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行傳 1:6–7; 馬太福音 24:3; 但以理書 12:6"> 「請告訴我們，這些事什麼時候會發生？有什麼預兆？」</span>
<span className="v" id="v5" data-v="5" data-xref="歌羅西書 2:8; 以弗所書 5:6; 耶利米書 29:8"> 耶穌回答說：「你們要小心，免得被人迷惑。</span>
<span className="v" id="v6" data-v="6" data-xref="馬可福音 13:22; 耶利米書 23:21–25; 約翰福音 8:24"> 將來會有許多人冒我的名來，說，『我是基督』，欺騙許多人。</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 21:9–11; 約翰福音 14:27; 馬太福音 24:6–7"> 「你們聽見戰爭爆發、戰訊頻傳時，不要驚慌，因為這些事必然發生，只是末日還沒有到。</span>
<span className="v" id="v8" data-v="8" data-xref="馬太福音 24:8; 以賽亞書 37:3; 詩篇 48:6"> 「民族將攻打民族，國家將攻打國家，各處將有地震和饑荒。這些只是災難<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「災難」希臘文是「生產之痛」。">a</a></sup>的開始。</span>
<span className="v" id="v9" data-v="9" data-xref="馬太福音 10:17–18; 約翰福音 16:2; 腓立比書 1:29"> 「你們要小心謹慎，因為你們將被送上法庭，並在會堂裡被鞭打，又將為了我的緣故在官長和君王面前作見證。</span>
<span className="v" id="v10" data-v="10" data-xref="馬太福音 24:14; 歌羅西書 1:23; 羅馬書 10:18"> 不過，福音一定要先傳遍天下。</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 21:14–15; 路加福音 12:11–12; 馬太福音 10:19–21"> 當你們被拘捕，押去受審時，不要先擔心該說什麼話，到時候賜給你們什麼話，你們就說什麼話，因為那時候說話的不是你們自己，而是聖靈。</span>
<span className="v" id="v12" data-v="12" data-xref="馬太福音 10:21; 路加福音 12:52–53; 路加福音 21:16"> 「那時，人將把自己的弟兄置於死地，父親將把兒子置於死地，兒女將反叛父母，置他們於死地。</span>
<span className="v" id="v13" data-v="13" data-xref="約翰福音 15:18–19; 馬太福音 10:22; 馬太福音 24:13"> 你們將因我的名而被眾人憎恨，但堅忍到底的必定得救。</span>
</div>
</div>

## 大災難

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="但以理書 9:27; 但以理書 12:11; 但以理書 11:31"> 「當你們看見『那帶來毀滅的可憎者』<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="但以理書9·27；11·31；12·11。">b</a></sup>站在不當站的地方時（讀者須會意），猶太地區的人要逃到山上去；</span>
<span className="v" id="v15" data-v="15" data-xref="路加福音 17:31–33; 希伯來書 11:7; 腓立比書 3:7–8"> 在屋頂上的人不要下來，不要進屋拿東西；</span>
<span className="v" id="v16" data-v="16"> 在田間的人不要回家取外衣。</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米哀歌 4:10; 路加福音 23:29; 何西阿書 9:14"> 那時，孕婦和哺育嬰兒的母親們可就遭殃了！</span>
<span className="v" id="v18" data-v="18"> 你們要祈求上帝使這些事不要在冬天發生，</span>
<span className="v" id="v19" data-v="19" data-xref="但以理書 12:1; 約珥書 2:2; 馬太福音 24:21"> 因為那是上帝創造天地以來空前絕後的大災難。</span>
<span className="v" id="v20" data-v="20" data-xref="馬太福音 24:22; 撒迦利亞書 13:8–9; 以賽亞書 65:8–9"> 如果主不縮短災期，恐怕沒有人能活命，但為了祂的選民，祂已經縮短災期。</span>
<span className="v" id="v21" data-v="21" data-xref="路加福音 21:8; 馬太福音 24:23–25; 馬太福音 24:5"> 那時，如果有人對你們說，『看啊，基督在這裡！』或說，『基督在那裡！』你們不要相信。</span>
<span className="v" id="v22" data-v="22" data-xref="馬太福音 24:24; 帖撒羅尼迦後書 2:8–14; 馬可福音 13:6"> 因為假基督和假先知將出現，行各種神蹟奇事，如果可能，甚至要迷惑上帝的選民。</span>
<span className="v" id="v23" data-v="23" data-xref="彼得後書 3:17; 馬可福音 13:5; 約翰福音 14:29"> 你們要小心，我已經把一切預先告訴你們了。</span>
</div>
</div>

## 人子降臨

<div className="bt">
<div className="bp poetry">
<span className="v" id="v24" data-v="24" data-xref="以賽亞書 13:10; 使徒行傳 2:19–20; 啟示錄 6:12–14"> <span className="pl pl-1">「大災難過後，</span><br /><span className="pl pl-1">『太陽昏暗，</span><br /><span className="pl pl-1">月亮無光，</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="以賽亞書 34:4; 啟示錄 6:13"> <span className="pl pl-1">星宿隕落，</span><br /><span className="pl pl-1">天體震動。』</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="以賽亞書13·10；34·4。">c</a></sup></span>
<span className="v" id="v26" data-v="26" data-xref="啟示錄 1:7; 馬太福音 16:27; 馬太福音 24:30"> 那時，世人必看到人子駕著雲、帶著極大的能力和榮耀降臨。</span>
<span className="v" id="v27" data-v="27" data-xref="撒迦利亞書 2:6; 馬太福音 24:31; 申命記 30:4"> 祂必差遣天使從四面八方、天涯海角招聚祂揀選的人。</span>
<span className="v" id="v28" data-v="28" data-xref="路加福音 21:29–31; 馬太福音 24:32–33"> 「你們可以從無花果樹學個道理。當無花果樹發芽長葉的時候，你們就知道夏天快來了。</span>
<span className="v" id="v29" data-v="29" data-xref="彼得前書 4:17–18; 雅各書 5:9; 以西結書 12:25–28"> 同樣，當你們看見這些事情發生時，就知道人子快來了，就在門口。</span>
<span className="v" id="v30" data-v="30" data-xref="馬太福音 24:34; 路加福音 21:32; 馬太福音 16:28"> 我實在告訴你們，這個世代還沒有過去，這一切都要發生。</span>
<span className="v" id="v31" data-v="31" data-xref="以賽亞書 40:8; 以賽亞書 51:6; 馬太福音 24:35"> 天地都要消逝，但我的話永不消逝。</span>
<span className="v" id="v32" data-v="32" data-xref="使徒行傳 1:7; 馬太福音 24:36–42; 馬太福音 25:13"> 「但沒有人知道那日子和時辰何時來到，連天上的天使也不知道，人子也不知道，只有天父知道。</span>
<span className="v" id="v33" data-v="33" data-xref="以弗所書 6:18; 路加福音 12:40; 羅馬書 13:11–12"> 你們要小心，保持警醒，因為你們不知道那日子何時來到。</span>
<span className="v" id="v34" data-v="34" data-xref="馬太福音 25:14–30; 約翰福音 10:3; 路加福音 12:36–40"> 「這就好像一個人在出遠門之前，把家中的事交給僕人，讓他們各做各的工作，又吩咐守門的人要警醒。</span>
<span className="v" id="v35" data-v="35" data-xref="馬可福音 13:33; 馬太福音 24:42; 馬太福音 24:44"> 所以你們要警醒，因為你們不知道家主什麼時候回來，可能是黃昏，可能是夜半，也可能是黎明或早上。</span>
<span className="v" id="v36" data-v="36" data-xref="帖撒羅尼迦前書 5:6–7; 羅馬書 13:11–14; 馬太福音 24:48–51"> 別讓他突然回來時看到你們在睡覺。</span>
<span className="v" id="v37" data-v="37" data-xref="馬可福音 13:33; 路加福音 12:41–46; 馬可福音 13:35"> 我勸你們，也勸所有的人，要警醒！」</span>
</div>
</div>

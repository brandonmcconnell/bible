## 登山變象

<div className="bt">
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="路加福音 9:28–36; 以賽亞書 33:17; 馬太福音 17:1–8"> 六天後，耶穌帶著彼得、雅各和約翰單獨登上一座高山。耶穌在他們面前改變了形像，</span>
<span className="v" id="v3" data-v="3" data-xref="馬太福音 28:3; 但以理書 7:9; 啟示錄 7:14"> 衣服潔白放光，世上沒有人能把布漂得那麼白。</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 9:30–31; 馬太福音 17:3–4; 使徒行傳 3:21–24"> 這時，以利亞和摩西向他們顯現，他們在跟耶穌談話。</span>
<span className="v" id="v5" data-v="5" data-xref="腓立比書 1:23; 約翰福音 14:8–9; 啟示錄 22:3–4"> 彼得對耶穌說：「老師，我們在這裡真好！我們搭三座帳篷吧，一座給你，一座給摩西，一座給以利亞。」</span>
<span className="v" id="v6" data-v="6" data-xref="啟示錄 1:17; 但以理書 10:15–19; 馬可福音 16:5–8"> 其實彼得不知道說什麼才好，因為他們都很害怕。</span>
<span className="v" id="v7" data-v="7" data-xref="彼得後書 1:17; 馬太福音 3:17; 馬可福音 1:11"> 就在這時候，有一朵雲彩飄來籠罩他們，雲彩中有聲音說：「這是我的愛子，你們要聽從祂。」</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行傳 10:16; 使徒行傳 8:39–40; 路加福音 24:31"> 門徒立刻四處觀看，發現沒有其他人，只有耶穌和他們在那裡。</span>
<span className="v" id="v9" data-v="9" data-xref="馬太福音 12:40; 馬太福音 17:9–13; 馬可福音 5:43"> 下山的時候，耶穌叮囑他們在人子從死裡復活之前，不要把剛才看見的告訴別人。</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行傳 17:18; 路加福音 24:7–8; 路加福音 18:33–34"> 門徒把這話謹記在心，彼此議論「從死裡復活」是什麼意思。</span>
<span className="v" id="v11" data-v="11" data-xref="瑪拉基書 4:5; 瑪拉基書 3:1; 馬太福音 11:14"> 他們問耶穌：「律法教師為什麼說以利亞必須先來？」</span>
<span className="v" id="v12" data-v="12" data-xref="以賽亞書 53:1–12; 以賽亞書 50:6; 以賽亞書 52:14"> 耶穌回答說：「以利亞固然要先來復興一切，但為什麼聖經上說人子一定會飽受痛苦、遭人蔑視呢？</span>
<span className="v" id="v13" data-v="13" data-xref="馬太福音 14:3–11; 馬太福音 17:12–13; 馬太福音 11:14"> 其實我告訴你們，以利亞已經來了，人們卻任意對待他，正如聖經的記載。」</span>
</div>
</div>

## 治好污鬼附身的孩子

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="路加福音 9:37–42; 馬太福音 17:14–20; 路加福音 11:53–54"> 他們與其他門徒會合時，看見一大群人圍住門徒，幾個律法教師正在跟他們辯論。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及記 34:30; 馬可福音 9:2–3"> 眾人一看到耶穌，都十分驚奇，立刻跑上去問候祂。</span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 5:30–32; 馬可福音 8:11"> 耶穌問門徒：「你們跟他們辯論什麼？」</span>
<span className="v" id="v17" data-v="17" data-xref="馬可福音 9:25; 路加福音 11:14; 約翰福音 4:47"> 人群中有一個人答道：「老師，我帶了我的兒子來找你，因為他被啞巴鬼附身。</span>
<span className="v" id="v18" data-v="18" data-xref="馬太福音 17:19–20; 馬可福音 11:23; 馬太福音 17:16"> 每次鬼控制他，把他摔在地上，他就口吐白沫，咬牙切齒，全身僵硬。我請你的門徒把鬼趕出去，但他們無能為力。」</span>
<span className="v" id="v19" data-v="19" data-xref="民數記 14:11; 約翰福音 20:27; 民數記 14:27"> 耶穌說：「唉，這不信的世代啊！我要跟你們在一起待多久，容忍你們多久呢？把他帶到我這裡來吧。」</span>
<span className="v" id="v20" data-v="20" data-xref="馬可福音 1:26; 路加福音 4:35; 約翰福音 8:44"> 他們把那孩子帶到耶穌面前。那鬼一見耶穌，就使孩子抽搐，倒在地上打滾，口吐白沫。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行傳 9:33; 使徒行傳 4:22; 馬可福音 5:25"> 耶穌問孩子的父親：「他這樣子多久了？」孩子的父親回答道：「他從小就這樣，</span>
<span className="v" id="v22" data-v="22" data-xref="馬太福音 15:22–28; 馬可福音 5:19; 馬太福音 20:34"> 鬼常常將他扔進火裡或水裡，要害他的命。如果你能，求你憐憫我們，幫助我們吧！」</span>
<span className="v" id="v23" data-v="23" data-xref="約翰福音 11:40; 希伯來書 11:6; 馬可福音 11:23"> 耶穌說：「如果你能？對於相信的人，凡事都有可能！」</span>
<span className="v" id="v24" data-v="24" data-xref="路加福音 17:5; 希伯來書 12:2; 以弗所書 2:8"> 孩子的父親立刻高喊：「我信！但我信心不足，求你幫助我！」</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行傳 16:18; 路加福音 9:42; 馬可福音 9:15"> 耶穌看見人群都跑了過來，就斥責那污鬼：「你這個聾啞鬼，我命令你從他身上出來，不許再進去！」</span>
<span className="v" id="v26" data-v="26" data-xref="馬可福音 9:20; 馬可福音 1:26; 馬可福音 9:18"> 那鬼大聲喊叫，使孩子劇烈地抽搐了一陣，就出來了。孩子躺在地上一動也不動，很多人都說他死了。</span>
<span className="v" id="v27" data-v="27" data-xref="馬可福音 1:31; 使徒行傳 3:7; 馬可福音 1:41"> 但耶穌拉著他的手扶他起來，他就站了起來。</span>
<span className="v" id="v28" data-v="28" data-xref="馬太福音 17:19–20; 馬可福音 7:17; 馬太福音 15:15"> 耶穌進屋後，門徒私下問祂：「我們為什麼趕不走那鬼呢？」</span>
<span className="v" id="v29" data-v="29" data-xref="雅各書 5:15; 但以理書 9:3; 馬太福音 17:20"> 耶穌說：「要趕走這類鬼只有靠禱告<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「禱告」有古卷作「禱告和禁食」。">a</a></sup>。」</span>
</div>
</div>

## 再次預言受難

<div className="bt">
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="馬太福音 17:22–23; 路加福音 9:43–45; 馬可福音 6:31–32"> 他們離開那裡，途經加利利。耶穌不想任何人知道祂的行蹤，</span>
<span className="v" id="v31" data-v="31" data-xref="馬太福音 16:21; 馬可福音 9:12; 路加福音 24:44–46"> 因為祂在教導門徒。祂說：「人子將被交在人手中，被他們殺害，但三天之後，祂必復活。」</span>
<span className="v" id="v32" data-v="32" data-xref="路加福音 2:50; 路加福音 9:45; 路加福音 18:34"> 門徒卻不明白這句話的意思，又不敢問祂。</span>
</div>
</div>

## 誰最偉大

<div className="bt">
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="馬太福音 18:1–5; 希伯來書 4:13; 路加福音 9:46–48"> 他們回到迦百農的住所，耶穌問門徒：「你們一路上爭論些什麼？」</span>
<span className="v" id="v34" data-v="34" data-xref="馬可福音 9:50; 馬太福音 20:21–24; 馬太福音 18:1–5"> 他們都沉默不語，因為剛才他們在爭論誰最偉大。</span>
<span className="v" id="v35" data-v="35" data-xref="馬太福音 20:25–28; 馬可福音 10:42–45; 路加福音 22:26"> 耶穌坐下，叫十二個門徒過來，對他們說：「誰想為首，就該在眾人中做最小的，作眾人的僕人。」</span>
<span className="v" id="v36" data-v="36" data-xref="馬可福音 10:16; 馬太福音 19:14–15; 馬太福音 18:2"> 祂領了一個小孩子來，叫他站在門徒中間，又抱起他，對他們說：</span>
<span className="v" id="v37" data-v="37" data-xref="馬太福音 18:3–5; 路加福音 10:16; 馬太福音 10:40–42"> 「誰為了我的名接待這樣一個小孩子，就是接待我；誰接待我，就是接待差我來的那位，而非接待我。」</span>
</div>
</div>

## 警戒犯罪

<div className="bt">
<div className="bp poetry">
<span className="v" id="v38" data-v="38" data-xref="路加福音 9:49–50; 民數記 11:26–29; 路加福音 11:19"> 約翰對耶穌說：「老師，我們看見有人奉你的名趕鬼，就阻止他，因為他不是跟從我們的。」</span>
<span className="v" id="v39" data-v="39" data-xref="哥林多前書 12:3; 哥林多前書 13:1–2; 馬太福音 13:28–29"> 耶穌說：「不要阻止他，因為沒有人奉我的名行過神蹟後，會很快毀謗我。</span>
<span className="v" id="v40" data-v="40" data-xref="馬太福音 12:30; 路加福音 11:23"> 不反對我們的，就是支持我們的。</span>
<span className="v" id="v41" data-v="41" data-xref="馬太福音 10:42; 馬太福音 25:40; 哥林多前書 15:23"> 我實在告訴你們，有人若因你們屬於基督而給你們一杯水喝，也必得到賞賜。</span>
<span className="v" id="v42" data-v="42" data-xref="馬太福音 18:6; 路加福音 17:1–2; 馬太福音 18:10"> 「不論誰使這樣一個小信徒失足犯罪，他的下場比把大磨石拴在他脖子上扔到海裡還要慘。</span>
<span className="v" id="v43" data-v="43" data-xref="馬太福音 5:29–30; 馬太福音 18:8–9; 馬太福音 25:41"> 如果你一隻手使你犯罪，就砍掉它！殘廢著進入永生，勝過雙手健全卻落入地獄不滅的火中<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="-44 有古卷加「那裡蟲是不死的，火是不滅的」。">b</a></sup>。</span>
<span className="v" id="v45" data-v="45" data-xref="馬太福音 18:8; 馬太福音 5:22; 馬可福音 9:43"> 如果你一隻腳使你犯罪，就砍掉它！瘸著腿進入永生，勝過雙腳健全卻被扔進地獄<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="-46 有古卷加「那裡蟲是不死的，火是不滅的」。">c</a></sup>。</span>
<span className="v" id="v47" data-v="47" data-xref="馬太福音 18:9; 馬可福音 9:43; 馬太福音 5:22"> 如果你一隻眼睛使你犯罪，就剜掉它！獨眼進上帝的國，勝過雙目健全卻被扔進地獄。</span>
<span className="v" id="v48" data-v="48" data-xref="以賽亞書 66:24; 馬可福音 9:43–45; 馬太福音 25:41"> 在那裡，<br /><span className="pl pl-1">「『蟲不會死，</span><br /><span className="pl pl-1">火不會滅。』</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="以賽亞書66·24。">d</a></sup></span>
<span className="v" id="v49" data-v="49" data-xref="利未記 2:13; 以西結書 43:24"> 「每個人都要被火煉，像被鹽醃一樣。</span>
<span className="v" id="v50" data-v="50" data-xref="歌羅西書 4:6; 羅馬書 12:18; 馬太福音 5:13"> 鹽本是好的，但如果失去鹹味，怎能使它再鹹呢？你們裡面要有鹽，要彼此和睦。」</span>

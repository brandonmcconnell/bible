## 撒種的比喻

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 5:1–3; 馬可福音 2:13; 路加福音 8:4–10"> 耶穌又開始在湖邊教導，周圍聚集了許多人，耶穌只好上到湖邊的船上坐下，眾人都站在岸上。</span>
<span className="v" id="v2" data-v="2" data-xref="馬太福音 13:34–35; 馬可福音 3:23; 馬可福音 4:11"> 耶穌用比喻教導他們許多事，在教導中祂說：</span>
<span className="v" id="v3" data-v="3" data-xref="雅各書 2:5; 馬太福音 13:26; 馬可福音 4:26–29"> 「聽著！有一個農夫出去撒種。</span>
<span className="v" id="v4" data-v="4" data-xref="馬太福音 13:19; 馬可福音 4:15; 馬太福音 13:4"> 撒種的時候，有些種子落在路旁，被飛鳥吃掉了；</span>
<span className="v" id="v5" data-v="5" data-xref="以西結書 36:26; 路加福音 8:6; 路加福音 8:13"> 有些落在石頭地上，因為泥土不深，種子很快就發芽了，</span>
<span className="v" id="v6" data-v="6" data-xref="雅各書 1:11; 耶利米書 17:5–8; 約拿書 4:8"> 然而因為沒有根，被太陽一曬就枯萎了；</span>
<span className="v" id="v7" data-v="7" data-xref="耶利米書 4:3; 路加福音 8:14; 創世記 3:17–18"> 有些落在荊棘叢中，荊棘長起來便把幼苗擠住了，以致不能結出果實；</span>
<span className="v" id="v8" data-v="8" data-xref="約翰福音 15:5; 歌羅西書 1:6; 馬可福音 4:20"> 有些落在沃土裡，就發芽生長，結出果實，收成多達三十倍、六十倍、一百倍！」</span>
<span className="v" id="v9" data-v="9" data-xref="馬太福音 11:15; 馬可福音 4:23–24; 啟示錄 3:22"> 然後祂說：「有耳可聽的，都應當聽。」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="馬太福音 13:10–17; 馬可福音 4:34; 箴言 13:20"> 當耶穌獨自一人的時候，十二使徒和追隨祂的人來請教比喻的意思。</span>
<span className="v" id="v11" data-v="11" data-xref="馬太福音 11:25; 路加福音 8:10; 約翰一書 5:20"> 耶穌說：「上帝國的奧祕只讓你們知道，對於外人，我全部用比喻，</span>
<span className="v" id="v12" data-v="12" data-xref="以賽亞書 6:9–10; 以賽亞書 44:18; 馬太福音 13:14–15"> 使他們『看了又看，卻不領悟；聽了又聽，卻不明白，免得他們回心轉意，得到赦免。』<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="以賽亞書6·9、10。">a</a></sup>」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="啟示錄 3:19; 馬太福音 13:51–52; 馬可福音 7:17–18"> 耶穌又對他們說：「你們不明白這個比喻，又怎能明白其他比喻呢？</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行傳 8:4; 馬太福音 13:19; 馬太福音 13:37"> 農夫撒的是上帝的道。</span>
<span className="v" id="v15" data-v="15" data-xref="彼得前書 5:8; 馬太福音 13:19; 哥林多後書 2:11"> 種子落在路旁，是指人聽了道，撒旦立刻過來奪去了撒在他們心裡的道。</span>
<span className="v" id="v16" data-v="16" data-xref="馬可福音 6:20; 路加福音 8:13; 馬太福音 13:20–21"> 種子落在石頭地上，是指人聽了道後，立刻歡喜地接受了，</span>
<span className="v" id="v17" data-v="17" data-xref="馬太福音 11:6; 帖撒羅尼迦前書 3:3–5; 馬太福音 12:31"> 但他們心裡沒有根基，不過是暫時接受，一旦為道遭受患難或迫害，就立刻放棄了。</span>
<span className="v" id="v18" data-v="18" data-xref="路加福音 8:14; 耶利米書 4:3; 馬太福音 13:22"> 種子落在荊棘叢中，是指人雖然聽過道，</span>
<span className="v" id="v19" data-v="19" data-xref="約翰一書 2:15–17; 提摩太前書 6:9–10; 提摩太前書 6:17"> 但生活的憂慮、錢財的迷惑和其他慾望紛紛進來把道擠住了，以致不能結出果實。</span>
<span className="v" id="v20" data-v="20" data-xref="歌羅西書 1:10; 路加福音 8:15; 約翰福音 15:4–5"> 種子落在沃土裡，是指人聽了道，領受了，又結出果實，收成多達三十倍、六十倍、甚至一百倍。」</span>
</div>
</div>

## 燈的比喻

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="馬太福音 5:15; 路加福音 11:33; 路加福音 8:16"> 耶穌繼續說：「人會把燈拿來放在斗底下或床底下嗎？當然不會，他一定會把它放在燈臺上。</span>
<span className="v" id="v22" data-v="22" data-xref="路加福音 8:17; 傳道書 12:14; 馬太福音 10:26–27"> 因為隱藏的事無不顯露出來，掩蓋的事終會被人知道。</span>
<span className="v" id="v23" data-v="23" data-xref="馬可福音 4:9; 馬太福音 11:15; 啟示錄 2:29"> 有耳可聽的，就應當聽。」</span>
<span className="v" id="v24" data-v="24" data-xref="希伯來書 2:1; 路加福音 8:18; 馬太福音 7:2"> 耶穌又說：「要好好思想你們所聽到的，你們用什麼量器量給人，就用什麼量器量給你們，甚至要多給你們。</span>
<span className="v" id="v25" data-v="25" data-xref="馬太福音 13:12; 路加福音 8:18; 馬太福音 25:28–29"> 因為凡有的，還要給他更多；凡沒有的，連他僅有的也要奪去！」</span>
</div>
</div>

## 種子生長的比喻

<div className="bt">
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="馬太福音 13:24; 哥林多前書 3:6–9; 路加福音 8:11"> 祂又說：「上帝的國就像一個人在地上撒種。</span>
<span className="v" id="v27" data-v="27" data-xref="傳道書 11:5; 帖撒羅尼迦後書 1:3; 哥林多前書 15:37–38"> 他日出而作，日落而息。種子就在他不知不覺中漸漸發芽長大。</span>
<span className="v" id="v28" data-v="28" data-xref="馬可福音 4:31–32; 何西阿書 6:3; 腓立比書 1:9–11"> 大地會使種子生長，先發苗後吐穗，最終結出飽滿的籽粒。</span>
<span className="v" id="v29" data-v="29" data-xref="約珥書 3:13; 馬太福音 13:30; 馬太福音 13:40–43"> 莊稼成熟後，他就拿起鐮刀來收割，因為收成的時候到了。」</span>
</div>
</div>

## 芥菜種的比喻

<div className="bt">
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="馬太福音 13:31–32; 路加福音 13:18–21; 耶利米哀歌 2:13"> 耶穌說：「我們拿什麼比作上帝的國呢？用什麼比喻來解釋呢？</span>
<span className="v" id="v31" data-v="31" data-xref="使徒行傳 19:20; 路加福音 13:18–19; 但以理書 2:44–45"> 上帝的國就像一粒芥菜種。它是世上種子中最小的，</span>
<span className="v" id="v32" data-v="32" data-xref="但以理書 4:20–22; 但以理書 4:10–14; 以西結書 31:3–10"> 但種在地裡，卻能長得比各樣蔬菜都大，有粗大的枝條，可以讓飛鳥在它的樹蔭中棲息。」</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="馬太福音 13:34–35; 約翰福音 16:12; 希伯來書 5:11–14"> 耶穌用了許多類似的比喻，按照眾人所能領悟的給他們講道。</span>
<span className="v" id="v34" data-v="34" data-xref="約翰福音 16:25; 馬可福音 4:10; 馬太福音 15:15–20"> 祂總是用比喻對他們講論，只有單獨和門徒在一起的時候，才把一切解釋清楚。</span>
</div>
</div>

## 平息風浪

<div className="bt">
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="馬太福音 8:18; 路加福音 8:22; 路加福音 8:25"> 那天晚上，耶穌對門徒說：「我們渡到對岸去吧。」</span>
<span className="v" id="v36" data-v="36" data-xref="馬可福音 3:9; 馬可福音 4:1; 馬可福音 5:2"> 他們就離開眾人，上了耶穌乘坐的船，帶祂一起去湖對岸，還有其他船隻跟著去。</span>
<span className="v" id="v37" data-v="37" data-xref="馬太福音 8:23–24; 約伯記 1:19; 路加福音 8:22–23"> 忽然，湖面上狂風大作，波浪撞擊船身，船內幾乎灌滿了水。</span>
<span className="v" id="v38" data-v="38" data-xref="彼得前書 5:7; 希伯來書 4:15; 以賽亞書 54:6–8"> 耶穌卻還在船尾枕著枕頭睡覺。門徒叫醒了祂，說：「老師，我們快淹死了，你怎麼不管呢？」</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="詩篇 107:29; 詩篇 89:9; 詩篇 65:7"> 耶穌起來斥責狂風，對著湖面說：「靜下來！停下來！」頓時風平浪靜了。</span>
<span className="v" id="v40" data-v="40" data-xref="路加福音 8:25; 馬太福音 8:26; 馬太福音 14:31"> 祂對門徒說：「你們為什麼這樣害怕呢？你們還是沒有信心嗎？」</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="路加福音 8:25; 約伯記 38:11; 詩篇 89:7"> 他們極其害怕，彼此議論說：「祂到底是誰？連風浪都聽祂的！」</span>
</div>
</div>

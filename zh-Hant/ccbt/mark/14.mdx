## 耶穌受膏

<div className="bt">
<div className="bp">

<span className="v" id="v4" data-v="4" data-xref="約翰福音 12:4–5; 馬太福音 26:8–9; 瑪拉基書 1:12–13"> 有些人生氣地彼此議論說：「何必這樣浪費香膏？</span>
<span className="v" id="v5" data-v="5" data-xref="約翰福音 13:29; 以弗所書 4:28; 哥林多前書 10:10"> 這瓶香膏能賣三百多個銀幣<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「三百多個銀幣」相當於當時人們一年的工錢。">a</a></sup>來賙濟窮人。」他們就責備那女人。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="提多書 3:14; 希伯來書 10:24; 希伯來書 13:21"> 耶穌說：「隨她吧！何必為難她呢？她在我身上做的是一件美事。</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 15:11; 馬太福音 26:11; 雅各書 2:14–16"> 因為你們身邊總會有窮人，你們隨時都可以幫助他們，可是你們身邊不會總有我。</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多後書 8:12; 約翰福音 12:7; 馬可福音 15:42–1"> 她做了自己能做的。她是為我的安葬做準備，提前用香膏抹了我的身體。</span>
<span className="v" id="v9" data-v="9" data-xref="馬太福音 26:12–13; 馬可福音 16:15; 馬太福音 24:14"> 我實在告訴你們，無論福音傳到世界哪個角落，人們都會傳揚這女人的事蹟，記念她。」</span>
</div>
</div>

## 最後的晚餐

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="出埃及記 12:6; 出埃及記 12:18; 馬太福音 26:17–19"> 除酵節的第一天，就是宰殺逾越節羔羊的那天，門徒問耶穌：「你想讓我們去哪裡為你預備逾越節吃的晚餐呢？」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="路加福音 22:10–13; 馬太福音 26:18–19; 路加福音 19:30–33"> 耶穌就派了兩個門徒，並囑咐他們：「你們進城會看到一個人帶著一瓶水迎面而來，你們就跟著他。</span>
<span className="v" id="v14" data-v="14" data-xref="啟示錄 3:20; 馬可福音 11:3; 約翰福音 13:13"> 他進哪一家，你們就對哪一家的主人說，『老師問：祂的客房在哪裡？祂要和門徒在裡面吃逾越節的晚餐。』</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行傳 1:13; 詩篇 110:3; 箴言 21:1–2"> 主人會帶你們看樓上一間佈置整齊的大房間，你們就在那裡為我們預備吧。」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="約翰福音 16:4; 路加福音 22:13; 路加福音 22:35"> 兩個門徒出去，進了城，所遇見的果然和耶穌所說的一樣。他們就預備了逾越節的晚餐。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="路加福音 22:14; 約翰福音 13:21–26; 馬太福音 26:20–24"> 傍晚，耶穌和十二使徒來了。</span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 41:9; 約翰福音 6:47; 約翰福音 6:70"> 用餐的時候，耶穌說：「我實在告訴你們，你們中間有一個人要出賣我，他正和我同桌吃飯。」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="路加福音 22:21–23; 馬太福音 26:22; 約翰福音 13:22"> 他們感到憂傷，一個一個地問耶穌：「不是我吧？」</span>
<span className="v" id="v20" data-v="20" data-xref="約翰福音 13:26; 馬太福音 26:23; 約翰福音 6:71"> 耶穌說：「是你們十二個人中的一個，他現在正和我一起在碗裡蘸餅吃。</span>
<span className="v" id="v21" data-v="21" data-xref="馬太福音 26:24–25; 以賽亞書 53:1–12; 約翰福音 19:28"> 人子要離世了，正如聖經對祂的記載，但那出賣人子的人有禍了，他還不如不生在這世上！」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="馬太福音 26:26–29; 馬可福音 14:24; 哥林多前書 10:16–17"> 他們吃的時候，耶穌拿起餅來，祝謝後，掰開分給門徒，說：「拿去吃吧！這是我的身體。」</span>
<span className="v" id="v23" data-v="23" data-xref="馬可福音 14:22; 馬太福音 26:27; 哥林多前書 10:16"> 接著祂又拿起杯來，祝謝後，遞給他們，他們都喝了。</span>
<span className="v" id="v24" data-v="24" data-xref="撒迦利亞書 9:11; 出埃及記 24:8; 啟示錄 7:9–17"> 耶穌說：「這是我為萬人所流的立約之血。</span>
<span className="v" id="v25" data-v="25" data-xref="馬太福音 26:29; 詩篇 104:15; 路加福音 22:16–18"> 我實在告訴你們，從今天起，一直到我在上帝的國喝新酒的那天之前，我不會再喝這葡萄酒。」</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="馬太福音 26:30; 路加福音 22:39; 使徒行傳 16:25"> 他們唱完聖詩，就出門去了橄欖山。</span>
</div>
</div>

<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="馬可福音 14:36; 馬可福音 14:39; 詩篇 18:5–6"> 他們到了客西馬尼，耶穌對門徒說：「你們坐在這裡，我要去禱告。」</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="路加福音 22:44; 希伯來書 5:7; 馬可福音 5:37"> 於是耶穌帶著彼得、雅各和約翰一起去。祂極其憂傷和難過，</span>
<span className="v" id="v34" data-v="34" data-xref="約翰福音 12:27; 馬可福音 13:35–37; 彼得前書 5:8"> 說：「我心裡非常憂傷，幾乎要死，你們留在這裡警醒。」</span>
<span className="v" id="v35" data-v="35" data-xref="馬可福音 14:41; 申命記 9:18; 希伯來書 5:7"> 耶穌往前走了不遠，俯伏在地禱告：如果可以的話，不要讓那時刻臨到祂。</span>

## 耶穌被捕

<div className="bt">
<div className="bp">

<span className="v" id="v44" data-v="44" data-xref="馬太福音 26:48–50; 箴言 27:6; 詩篇 55:20–21"> 出賣耶穌的猶大預先和他們定了暗號，說：「我親吻誰，誰就是耶穌，你們把祂抓起來，小心押走。」</span>

<span className="v" id="v50" data-v="50" data-xref="馬可福音 14:27; 約翰福音 16:32; 詩篇 88:18"> 那時，所有門徒都丟下祂逃走了。</span>

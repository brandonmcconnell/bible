## 傳統與誡命

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="馬太福音 15:1–20; 馬可福音 3:22; 路加福音 5:17"> 有法利賽人和一些律法教師從耶路撒冷聚集到耶穌那裡。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行傳 10:28; 馬太福音 7:3–5; 羅馬書 14:14"> 他們看到祂的一些門徒吃飯前沒有照禮儀洗手。</span>
<span className="v" id="v3" data-v="3" data-xref="加拉太書 1:14; 馬可福音 7:13; 歌羅西書 2:8"> 因為法利賽人和所有的猶太人都拘守祖先的傳統，總是先照禮儀洗手之後才吃飯；</span>
<span className="v" id="v4" data-v="4" data-xref="希伯來書 9:10; 馬太福音 23:25; 路加福音 11:38–39"> 從市場回來也要先潔淨自己，然後才吃飯。他們還拘守許多其他規矩，如洗杯、罐、銅器等。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="帖撒羅尼迦後書 3:6; 使徒行傳 21:21; 馬太福音 15:2"> 他們質問耶穌：「為什麼你的門徒違背祖先的傳統，竟用不潔淨的手吃飯呢？」</span>
</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="以賽亞書 29:13; 提多書 1:16; 馬太福音 15:7–9"> 耶穌回答說：「以賽亞針對你們這些偽君子說的預言一點沒錯，正如聖經上說，<br /><span className="pl pl-1">「『這些人嘴上尊崇我，</span><br /><span className="pl pl-1">心卻遠離我。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="以賽亞書 29:13; 馬太福音 15:9; 雅各書 1:26"> <span className="pl pl-1">他們的教導無非是人的規條，</span><br /><span className="pl pl-1">他們敬拜我也是枉然。』</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="以賽亞書29·13。">a</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="馬可福音 7:3–4; 以賽亞書 1:12"> 你們只知拘守人的傳統，卻無視上帝的誡命。」</span>
<span className="v" id="v9" data-v="9" data-xref="耶利米書 44:16–17; 加拉太書 2:21; 以賽亞書 29:13"> 耶穌又對他們說：「你們為了拘守傳統，竟巧妙地廢除了上帝的誡命。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及記 21:17; 出埃及記 20:12; 申命記 5:16"> 摩西說，『要孝敬父母』<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="出埃及記20·12；申命記5·16。">b</a></sup>，又說，『咒罵父母的，必被處死。』<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="出埃及記21·17；利未記20·9。">c</a></sup></span>
<span className="v" id="v11" data-v="11" data-xref="馬太福音 23:18; 提摩太前書 5:4–8; 馬太福音 15:5"> 你們卻認為人若對父母說，『我把供養你們的錢財已經全部奉獻給上帝了』，</span>
<span className="v" id="v12" data-v="12"> 他就可以不再奉養父母。</span>
<span className="v" id="v13" data-v="13" data-xref="馬可福音 7:9; 提多書 1:14; 馬太福音 5:17–20"> 你們就是這樣為了拘守傳統而廢除上帝的道，類似的情形還有很多。」</span>
</div>
</div>

## 內心的污穢

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="馬太福音 15:10; 以賽亞書 6:9; 箴言 8:5"> 耶穌又召集眾人，對他們說：「你們都要聽我說，也要明白，</span>
<span className="v" id="v15" data-v="15" data-xref="箴言 4:23; 利未記 11:42–47; 提多書 1:15"> 從外面進去的不會使人污穢，只有從人裡面發出來的才會使人污穢。</span>
<span className="v" id="v16" data-v="16"> 有耳可聽的，都應當聽！<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="有古卷無16節。">d</a></sup>」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="馬太福音 15:15; 馬太福音 13:36; 馬可福音 9:28"> 耶穌離開眾人，進了屋子，門徒問祂這比喻的意思。</span>
<span className="v" id="v18" data-v="18" data-xref="馬太福音 15:16–17; 希伯來書 5:11; 以賽亞書 28:9–10"> 耶穌說：「你們也這樣糊塗嗎？豈不知從外面進去的，不會使人污穢，</span>
<span className="v" id="v19" data-v="19" data-xref="馬太福音 15:17; 哥林多前書 6:13; 歌羅西書 2:21–22"> 因為不能進入他的心，只能進他的腸胃，最後排進廁所。」言下之意，所有的食物都是潔淨的。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="雅各書 3:6; 雅各書 1:14–15; 雅各書 4:1"> 祂接著說：「從人裡面發出來的才使人污穢，</span>
<span className="v" id="v21" data-v="21" data-xref="耶利米書 17:9; 羅馬書 8:7–8; 雅各書 4:1–3"> 因為從裡面，就是從人的心裡能夠生出惡念、苟合、偷盜、謀殺、</span>
<span className="v" id="v22" data-v="22" data-xref="馬太福音 20:15; 馬太福音 6:23; 彼得前書 2:15"> 通姦、貪婪、邪惡、詭詐、放蕩、嫉妒、毀謗、驕傲、愚妄。</span>
<span className="v" id="v23" data-v="23" data-xref="馬可福音 7:15; 提多書 1:15; 哥林多前書 3:17"> 這一切惡事都是從裡面生出來的，能使人污穢。」</span>
</div>
</div>

## 外族婦人的信心

<div className="bt">
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="馬太福音 15:21–28; 馬太福音 11:21; 以西結書 28:2"> 耶穌從那裡啟程去泰爾和西頓地區。祂進了一戶人家，原本不想讓人知道，卻無法避開人們的注意。</span>
<span className="v" id="v25" data-v="25" data-xref="馬太福音 15:22; 馬可福音 9:17–23; 使徒行傳 10:25–26"> 當時有一個婦人的小女兒被污鬼附身，她聽見耶穌的事，就來俯伏在祂腳前，懇求祂趕出她女兒身上的鬼。這婦人是希臘人，來自敘利亞的腓尼基。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="馬太福音 15:23–28; 馬太福音 7:6; 使徒行傳 22:21"> 耶穌對她說：「要先讓兒女們吃飽，因為把兒女的食物丟給狗吃不合適。」</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="羅馬書 10:12; 羅馬書 3:29; 使徒行傳 11:17–18"> 婦人說：「主啊，你說的對，但桌子下的狗也吃孩子們掉下來的碎渣呀！」</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="以賽亞書 66:2; 馬太福音 5:3; 約翰一書 3:8"> 耶穌說：「因為你這句話，你回去吧，鬼已經離開你的女兒了。」</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="約翰一書 3:8; 約翰福音 4:50–52"> 她回到家裡，見女兒躺在床上，鬼已經離開了。</span>
</div>
</div>

## 醫治聾啞人

<div className="bt">
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="馬可福音 5:20; 馬太福音 15:29–31; 馬太福音 4:25"> 耶穌離開泰爾地區，經過西頓，來到低加坡里地區的加利利湖。</span>
<span className="v" id="v32" data-v="32" data-xref="路加福音 11:14; 馬可福音 5:23; 馬太福音 9:32–33"> 有人帶著一個又聾又啞的人來見耶穌，懇求祂把手按在這個人身上。</span>
<span className="v" id="v33" data-v="33" data-xref="馬可福音 8:23; 約翰福音 9:6–7; 馬可福音 5:40"> 耶穌就帶他離開眾人走到一邊，用指頭伸進他的耳朵，又吐唾沫抹他的舌頭，</span>
<span className="v" id="v34" data-v="34" data-xref="約翰福音 11:41; 馬可福音 5:41; 馬可福音 6:41"> 望天長歎，對他說：「以法大！」意思是「開了吧！」</span>
<span className="v" id="v35" data-v="35" data-xref="以賽亞書 35:5–6; 詩篇 33:9; 馬可福音 2:12"> 他的耳朵立刻開了，舌頭靈活了，說話也清楚了。</span>
<span className="v" id="v36" data-v="36" data-xref="馬太福音 8:4; 馬可福音 8:26; 馬可福音 3:12"> 耶穌吩咐他們不要將這事告訴別人。可是耶穌越是這樣吩咐，他們越是極力宣揚，</span>
<span className="v" id="v37" data-v="37" data-xref="馬可福音 6:51; 馬可福音 5:42; 出埃及記 4:10–11"> 聽見的人都十分驚奇，說：「祂做的一切都很好，甚至叫耳聾的聽見，啞巴說話！」</span>
</div>
</div>

## 騎驢進耶路撒冷

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="馬太福音 21:1–11; 約翰福音 12:14–19; 路加福音 19:29–40"> 耶穌和門徒將近耶路撒冷，來到橄欖山的伯法其和伯大尼。耶穌派了兩個門徒，</span>
<span className="v" id="v2" data-v="2" data-xref="馬太福音 21:2–3; 路加福音 19:30–31"> 並囑咐說：「你們去前面的村莊，一進村就會看見一頭從來沒有人騎過的驢駒拴在那裡，你們把牠解開牽來。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行傳 10:36; 馬可福音 14:15; 詩篇 110:3"> 若有人問你們為什麼這樣做，就說，『主要用牠，很快會把牠送回來。』」</span>
<span className="v" id="v4" data-v="4" data-xref="馬太福音 26:19; 路加福音 19:32–34; 馬太福音 21:6–7"> 他們就去了，果然看見有一頭驢駒拴在街道旁一戶人家的門外，就解開牠。</span>
<span className="v" id="v5" data-v="5"> 旁邊站著的幾個人就問他們：「你們解開驢駒幹什麼？」</span>
<span className="v" id="v6" data-v="6"> 門徒依照耶穌的吩咐回答，那些人就讓他們牽走了。</span>
<span className="v" id="v7" data-v="7" data-xref="撒迦利亞書 9:9; 路加福音 19:35–36; 馬太福音 21:7–8"> 他們把驢駒牽到耶穌那裡，把自己的外衣搭在驢背上，耶穌就騎了上去。</span>
<span className="v" id="v8" data-v="8" data-xref="利未記 23:40"> 許多人把衣服鋪在路上，還有人將田間的樹枝砍下來鋪在路上。</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 118:25–26; 馬太福音 21:9; 馬太福音 23:39"> 眾人前呼後擁，高喊道：<br /><span className="pl pl-1">「和散那！」</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「和散那」原意是「拯救我們」，此處有「讚美」的意思。">a</a></sup><br /><span className="pl pl-1">「奉主名來的當受稱頌！」</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="詩篇118·26。">b</a></sup></span>
</div>
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="以西結書 37:24–25; 路加福音 2:14; 路加福音 19:38–40"> <span className="pl pl-1">「那將要來臨的我祖大衛的國度當受稱頌！」</span><br /><span className="pl pl-1">「和散那歸於至高之處的上帝！」</span></span>
<span className="v" id="v11" data-v="11" data-xref="約翰福音 8:1–2; 路加福音 19:41–45; 路加福音 21:37–38"> 耶穌進了耶路撒冷，來到聖殿，巡視各處。那時天色已晚，耶穌便和十二使徒出城前往伯大尼。</span>
</div>
</div>

## 咒詛無花果樹

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="馬太福音 21:18–22; 馬太福音 4:2; 約翰福音 19:28"> 第二天，他們離開伯大尼後，耶穌餓了。</span>
<span className="v" id="v13" data-v="13" data-xref="馬太福音 21:19; 路加福音 13:6–9; 以賽亞書 5:7"> 祂遠遠看見一棵長滿葉子的無花果樹，就走過去看能否找到果子。到了樹下，卻什麼也找不到，只有葉子，因為當時不是收無花果的季節。</span>
<span className="v" id="v14" data-v="14" data-xref="馬太福音 21:19; 馬太福音 7:19; 馬太福音 3:10"> 祂對那棵樹說：「願今後無人再吃你的果子！」祂的門徒都聽見了這句話。</span>
</div>
</div>

## 潔淨聖殿

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="約翰福音 2:13–17; 馬太福音 21:12–16; 路加福音 19:45–47"> 他們來到耶路撒冷後，耶穌進入聖殿，趕走裡面做買賣的人，推翻兌換錢幣之人的桌子和賣鴿子之人的凳子，</span>
<span className="v" id="v16" data-v="16"> 不准人抬著貨物穿過聖殿。</span>
<span className="v" id="v17" data-v="17" data-xref="以賽亞書 56:7; 耶利米書 7:11; 路加福音 19:46"> 祂教導他們說：「聖經上不是記載『我的殿必稱為萬民禱告的殿』<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="以賽亞書56·7。">c</a></sup>嗎？你們竟把它變成了賊窩。<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="耶利米書7·11。">d</a></sup>」</span>
<span className="v" id="v18" data-v="18" data-xref="馬太福音 7:28; 馬可福音 12:12; 馬可福音 14:1–2"> 祭司長和律法教師聽到這番話後，就策劃如何殺害耶穌，只是害怕祂，因為百姓都對祂的教導感到驚奇。</span>
<span className="v" id="v19" data-v="19" data-xref="路加福音 21:37; 馬可福音 11:11; 約翰福音 12:36"> 到了傍晚，耶穌和門徒去了城外。</span>
</div>
</div>

## 無花果樹的教訓

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="馬太福音 15:13; 馬可福音 11:14; 約翰福音 15:6"> 早上，他們經過那棵無花果樹，看見它連根都枯了。</span>
<span className="v" id="v21" data-v="21" data-xref="箴言 3:33; 馬太福音 23:7; 馬太福音 25:41"> 彼得想起昨天發生的事，就對耶穌說：「老師，你看！你咒詛的無花果樹已經枯了。」</span>
<span className="v" id="v22" data-v="22" data-xref="詩篇 62:8; 約翰福音 14:1; 馬可福音 9:23"> 耶穌說：「你們要對上帝有信心。</span>
<span className="v" id="v23" data-v="23" data-xref="馬太福音 17:20; 約翰福音 15:7; 馬太福音 21:21"> 我實在告訴你們，不論何人，只要有信心，毫不疑惑，就是對這座山說，『從這裡挪開，投進大海裡！』也必定為他成就。</span>
<span className="v" id="v24" data-v="24" data-xref="馬太福音 21:22; 約翰一書 5:14–15; 約翰一書 3:22"> 所以我告訴你們，你們無論禱告求什麼，只要相信已經得到了，就必得到。</span>
<span className="v" id="v25" data-v="25" data-xref="馬太福音 6:14–15; 歌羅西書 3:13; 以弗所書 4:32"> 你們站著禱告的時候，若想起有人得罪了你們，就要饒恕他。這樣，你們天上的父也會饒恕你們的過犯。</span>
<span className="v" id="v26" data-v="26"> 你們如果不饒恕別人，你們天上的父也不會饒恕你們的過犯。<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="有古卷無26節。">e</a></sup>」</span>
</div>
</div>

## 質問耶穌的權柄

<div className="bt">
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="路加福音 20:1–8; 馬太福音 21:23–27; 詩篇 2:1–5"> 他們再次回到耶路撒冷。耶穌在聖殿裡行走的時候，祭司長、律法教師和長老上前質問祂：</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及記 2:14; 使徒行傳 7:38–39; 民數記 16:3"> 「你憑什麼權柄做這些事？誰授權給你了？」</span>
<span className="v" id="v29" data-v="29" data-xref="路加福音 20:3–8; 馬太福音 21:24; 以賽亞書 52:13"> 耶穌說：「我要問你們一個問題，你們回答了，我就告訴你們我憑什麼權柄做這些事。</span>
<span className="v" id="v30" data-v="30" data-xref="路加福音 3:1–20; 約翰福音 3:25–36; 馬可福音 1:1–11"> 約翰的洗禮是從天上來的，還是從人間來的？請回答我！」</span>
<span className="v" id="v31" data-v="31" data-xref="約翰福音 1:29; 約翰福音 1:34; 馬太福音 21:31–32"> 他們彼此議論說：「如果我們說『是從天上來的』，祂一定會問，『那你們為什麼不信他？』</span>
<span className="v" id="v32" data-v="32" data-xref="馬太福音 21:46; 馬可福音 12:12; 馬太福音 14:5"> 但我們如果說『是從人間來的』，又怕觸怒百姓，因為他們都相信約翰真的是先知。」</span>
<span className="v" id="v33" data-v="33" data-xref="以賽亞書 6:9–10; 哥林多後書 4:3–4; 帖撒羅尼迦後書 2:10–12"> 於是，他們回答說：「我們不知道。」耶穌說：「我也不告訴你們我憑什麼權柄做這些事。」</span>
</div>

## 拿撒勒人厭棄耶穌

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 4:16–30; 馬太福音 13:54–58; 馬太福音 2:23"> 耶穌帶著門徒離開那地方，回到自己的家鄉。</span>
<span className="v" id="v2" data-v="2" data-xref="約翰福音 7:15; 約翰福音 6:42; 使徒行傳 4:13–14"> 到了安息日，祂開始在會堂裡教導人，眾人聽了都很驚奇，說：「這個人從哪裡學來這些本領？祂怎麼會有這種智慧？祂怎麼會行這樣的神蹟？</span>
<span className="v" id="v3" data-v="3" data-xref="馬太福音 12:46; 馬太福音 13:55–57; 約翰福音 6:42"> 這不是那個木匠嗎？祂不是瑪麗亞的兒子嗎？祂不是雅各、約西、猶大、西門的大哥嗎？祂的妹妹們不也住在我們這裡嗎？」他們就對祂很反感。</span>
<span className="v" id="v4" data-v="4" data-xref="約翰福音 4:44; 路加福音 4:24; 馬太福音 13:57"> 耶穌對他們說：「先知到處受人尊敬，只有在本鄉、本族、本家例外。」</span>
<span className="v" id="v5" data-v="5" data-xref="馬太福音 13:58; 馬可福音 9:23; 馬可福音 5:23"> 耶穌不能在那裡行任何神蹟，只把手按在幾個病人身上，醫治了他們。</span>
<span className="v" id="v6" data-v="6" data-xref="馬太福音 9:35; 馬太福音 8:10; 路加福音 13:22"> 耶穌對他們的不信感到詫異，就去周圍的村莊繼續教導人。</span>
</div>
</div>

## 差遣十二使徒

<div className="bt">
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="傳道書 4:9–10; 路加福音 10:17–20; 馬太福音 10:1–5"> 耶穌召集了十二個使徒，差遣他們兩個兩個地出去，賜他們制伏污鬼的權柄，</span>
<span className="v" id="v8" data-v="8" data-xref="路加福音 9:3; 馬太福音 10:9–10; 路加福音 10:4"> 又吩咐他們路上除了手杖外什麼都不要帶，不要帶食物和背包，腰袋裡也不要帶錢，</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行傳 12:8; 以弗所書 6:15"> 只穿一雙鞋和一套衣服就夠了。</span>
<span className="v" id="v10" data-v="10" data-xref="路加福音 10:7–8; 路加福音 9:4; 馬太福音 10:11–13"> 祂對他們說：「無論什麼地方，你們進到哪戶人家，就在哪裡住下來，一直到離開那地方。</span>
<span className="v" id="v11" data-v="11" data-xref="馬太福音 10:14–15; 使徒行傳 18:6; 路加福音 10:10–15"> 如果某地方的人不接待你們，不聽你們傳的道，你們離開那裡時要跺掉腳上的塵土，作為對他們的警告！」</span>
<span className="v" id="v12" data-v="12" data-xref="馬太福音 4:17; 路加福音 13:3; 使徒行傳 20:21"> 使徒便出去傳道，勸人悔改，</span>
<span className="v" id="v13" data-v="13" data-xref="雅各書 5:14–15; 馬可福音 6:7; 路加福音 10:17"> 趕出許多鬼，為許多病人抹油，治好他們。</span>
</div>
</div>

## 施洗者約翰遇害

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="路加福音 9:7–9; 馬可福音 6:14–29; 路加福音 23:7–12"> 耶穌聲名遠揚，希律王也聽說了祂的事。有人說：「施洗者約翰從死裡復活了，所以能行這些神蹟。」</span>
<span className="v" id="v15" data-v="15" data-xref="馬太福音 16:14; 瑪拉基書 4:5; 馬太福音 21:11"> 也有人說：「祂是以利亞。」 還有人說：「祂是個先知，就像古代的一位先知。」</span>
<span className="v" id="v16" data-v="16" data-xref="啟示錄 11:10–13; 馬太福音 27:4; 路加福音 9:9"> 希律聽到這些議論，就說：「被我斬首的約翰從死裡復活了！」</span>
<span className="v" id="v17" data-v="17" data-xref="路加福音 3:19–20; 馬太福音 11:2; 路加福音 3:1"> 原來希律娶了他兄弟腓力的妻子希羅底，並為她的緣故而派人逮捕了約翰，把他鎖在監牢裡。</span>
<span className="v" id="v18" data-v="18" data-xref="利未記 20:21; 利未記 18:16; 列王紀上 22:14"> 因為約翰曾對希律說：「你娶弟弟的妻子不合法。」</span>
<span className="v" id="v19" data-v="19" data-xref="傳道書 7:9; 以弗所書 4:26–27; 創世記 39:17–20"> 希羅底對約翰懷恨在心，想要殺掉他，只是不能得逞。</span>
<span className="v" id="v20" data-v="20" data-xref="馬太福音 21:26; 馬太福音 14:5; 歷代志下 24:15–22"> 因為希律知道約翰是個公義聖潔的人，所以敬畏他，並對他加以保護。儘管約翰所講的道理令他困惑不安，他仍然喜歡聽。</span>
<span className="v" id="v21" data-v="21" data-xref="以斯帖記 2:18; 創世記 40:20; 彼得前書 4:3"> 機會終於來了。希律在自己的生日那天設宴招待文武百官和加利利的顯要。</span>
<span className="v" id="v22" data-v="22" data-xref="以斯帖記 1:10–12; 馬太福音 14:6; 但以理書 5:2"> 希羅底的女兒進來跳舞，甚得希律和客人的歡心。王對她說：「你想要什麼，只管說。」</span>
<span className="v" id="v23" data-v="23" data-xref="以斯帖記 7:2; 以斯帖記 5:3; 以斯帖記 5:6"> 王還對她起誓說：「無論你要什麼，哪怕是我的半壁江山，我都會給你。」</span>
<span className="v" id="v24" data-v="24" data-xref="約伯記 31:31; 以西結書 19:2–3; 創世記 27:8–11"> 她便出去問她母親：「我應該要什麼呢？」 她母親說：「要施洗者約翰的頭！」</span>
<span className="v" id="v25" data-v="25" data-xref="羅馬書 3:15; 民數記 7:19–89; 民數記 7:13"> 她馬上回去向王請求說：「願王立刻把施洗者約翰的頭放在盤子裡送給我。」</span>
<span className="v" id="v26" data-v="26" data-xref="馬太福音 27:24–25; 馬太福音 14:9; 馬太福音 27:3–5"> 王聽到這個請求，感到十分為難，但因為在眾賓客面前起了誓，就不好拒絕。</span>
<span className="v" id="v27" data-v="27" data-xref="馬太福音 14:10–11"> 他立刻命令衛兵進監牢砍了約翰的頭，</span>
<span className="v" id="v28" data-v="28"> 放在盤子裡送給女孩，她又轉送給她母親。</span>
<span className="v" id="v29" data-v="29" data-xref="馬太福音 14:12; 歷代志下 24:16; 馬太福音 27:57–60"> 約翰的門徒聽到這個消息，就來把約翰的屍體領回去，安葬在墳墓裡。</span>
</div>
</div>

## 耶穌使五千人吃飽

<div className="bt">
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="路加福音 9:10; 路加福音 10:17; 馬太福音 10:2"> 使徒們聚集在耶穌身邊，向祂報告他們一切的工作和教導。</span>
<span className="v" id="v31" data-v="31" data-xref="馬可福音 3:20; 約翰福音 6:1; 馬可福音 1:45"> 耶穌對他們說：「你們單獨跟我到荒僻的地方去歇一會兒吧。」因為當時來來往往的人很多，他們連吃飯的時間都沒有。</span>
<span className="v" id="v32" data-v="32" data-xref="馬可福音 8:2–9; 馬可福音 6:45; 馬可福音 4:36"> 他們乘船單獨到了一處荒僻的地方。</span>
<span className="v" id="v33" data-v="33" data-xref="約翰福音 6:2; 馬太福音 15:29–31; 馬可福音 6:54–55"> 可是有許多人看見他們離開，認出了他們，便從各城鎮步行趕往那裡，比他們先到達。</span>
<span className="v" id="v34" data-v="34" data-xref="馬太福音 9:36; 路加福音 9:11; 民數記 27:17"> 耶穌一下船，看見這一大群人好像沒有牧人的羊，心裡憐憫他們，於是教導了他們許多道理。</span>
<span className="v" id="v35" data-v="35" data-xref="約翰福音 6:5–15; 路加福音 9:12–17; 馬太福音 14:15–21"> 天色晚了，門徒過來對耶穌說：「時候已經不早了，這裡又是荒郊野外，</span>
<span className="v" id="v36" data-v="36" data-xref="馬太福音 15:23; 馬可福音 3:21; 馬可福音 5:31"> 請遣散眾人，好讓他們到周圍的村莊去自己買些吃的。」</span>
<span className="v" id="v37" data-v="37" data-xref="列王紀下 4:42–44; 馬太福音 15:32–33; 馬可福音 8:2–3"> 耶穌說：「你們給他們吃的吧。」 門徒說：「難道要我們買二百個銀幣的餅給他們吃嗎？」</span>
<span className="v" id="v38" data-v="38" data-xref="馬太福音 15:34; 馬可福音 8:5; 約翰福音 6:9"> 耶穌說：「去看看你們有多少餅。」 他們察看後，說：「有五個餅和兩條魚。」</span>
<span className="v" id="v39" data-v="39" data-xref="哥林多前書 14:40; 哥林多前書 14:33; 馬太福音 15:35"> 耶穌吩咐門徒叫眾人分組坐在草地上。</span>
<span className="v" id="v40" data-v="40" data-xref="路加福音 9:14–15"> 於是眾人坐下，有的五十人一組，有的一百人一組。</span>
<span className="v" id="v41" data-v="41" data-xref="馬太福音 14:19; 馬可福音 7:34; 路加福音 9:16"> 耶穌拿起那五個餅、兩條魚，舉目望著天祝謝後，掰開餅遞給門徒，讓他們分給眾人。祂又照樣把那兩條魚分給眾人。</span>
<span className="v" id="v42" data-v="42" data-xref="路加福音 9:17; 馬可福音 8:8–9; 馬太福音 15:37–38"> 大家都吃了，並且吃飽了。</span>
<span className="v" id="v43" data-v="43" data-xref="馬可福音 8:19–20"> 門徒把剩下的碎餅、碎魚收拾起來，裝滿了十二個籃子。</span>
<span className="v" id="v44" data-v="44"> 當時吃餅的有五千男人。</span>
</div>
</div>

## 耶穌在湖面上行走

<div className="bt">
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="馬太福音 14:22–33; 約翰福音 6:15–21; 馬可福音 6:32"> 耶穌隨即催門徒上船，叫他們先渡到湖對岸的伯賽大，祂則遣散眾人。</span>
<span className="v" id="v46" data-v="46" data-xref="馬可福音 1:35; 馬太福音 6:6; 路加福音 6:12"> 祂辭別了眾人後，就上山去禱告。</span>
<span className="v" id="v47" data-v="47" data-xref="馬太福音 14:23; 約翰福音 6:16–17"> 到了晚上，門徒的船在湖中心，耶穌獨自留在岸上。</span>
<span className="v" id="v48" data-v="48" data-xref="路加福音 24:28; 路加福音 12:38; 約伯記 9:8"> 祂看見門徒在逆風中搖櫓，非常吃力。天將破曉的時候，祂從水面上朝門徒走去，想要從他們旁邊經過。</span>
<span className="v" id="v49" data-v="49" data-xref="馬太福音 14:25–26; 路加福音 24:37; 約伯記 9:8"> 門徒看見祂在湖面上走，以為是幽靈，就驚叫起來。</span>
<span className="v" id="v50" data-v="50" data-xref="馬太福音 14:27; 約翰福音 6:19–20; 以賽亞書 43:2"> 全船的人看見祂，都嚇壞了。耶穌立刻對他們說：「放心吧！是我，不要怕。」</span>
<span className="v" id="v51" data-v="51" data-xref="詩篇 93:3–4; 馬可福音 4:39; 約翰福音 6:21"> 耶穌上船到他們那裡，風便停了。門徒心裡大為驚奇，</span>
<span className="v" id="v52" data-v="52" data-xref="馬可福音 8:17–21; 路加福音 24:25; 以賽亞書 63:17"> 因為他們仍然不明白耶穌分餅的事，心裡還是愚頑。</span>
<span className="v" id="v53" data-v="53" data-xref="馬太福音 14:34–36; 約翰福音 6:24–25; 路加福音 5:1"> 他們渡到湖對岸，來到革尼撒勒，在那裡靠岸，</span>
<span className="v" id="v54" data-v="54" data-xref="詩篇 9:10; 腓立比書 3:10"> 剛一下船，眾人立刻認出了耶穌。</span>
<span className="v" id="v55" data-v="55" data-xref="馬太福音 4:24; 馬可福音 2:1–3; 馬可福音 3:7–11"> 他們跑遍那一帶地方，用墊子把生病的人抬來，聽到耶穌在哪裡，就把病人抬到哪裡。</span>
<span className="v" id="v56" data-v="56" data-xref="馬太福音 9:20; 路加福音 6:19; 民數記 15:38–39"> 耶穌無論到哪一個村莊、城鎮或鄉下，人們總是把病人抬到街市上，求耶穌讓他們摸一摸祂衣服的穗子，所有摸過的病人都好了。</span>

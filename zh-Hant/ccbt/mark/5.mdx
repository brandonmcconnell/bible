## 治好被鬼附身的人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 8:26–39; 馬太福音 8:28–34; 馬可福音 4:35"> 他們來到湖對岸的格拉森地區。</span>
<span className="v" id="v2" data-v="2" data-xref="馬可福音 1:23; 以賽亞書 65:4; 馬可福音 5:8"> 耶穌剛下船，迎面就遇見一個被污鬼附身的人，是從墳墓裡出來的。</span>
<span className="v" id="v3" data-v="3" data-xref="以賽亞書 65:4; 路加福音 8:29; 但以理書 4:32–33"> 那人以墳墓為家，沒有人能把他捆住，就算用鐵鏈也不行。</span>
<span className="v" id="v4" data-v="4" data-xref="雅各書 3:7–8"> 因為有人多次用鐵鏈和腳鐐鎖住他，但他掙斷了鐵鏈，砸碎了腳鐐。沒有人能制伏他。</span>
<span className="v" id="v5" data-v="5" data-xref="約伯記 2:7–8; 列王紀上 18:28; 約翰福音 8:44"> 他晝夜在墳場和山野間大喊大叫，又用石頭砍自己。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="雅各書 2:19; 詩篇 66:3; 路加福音 4:41"> 他遠遠看見耶穌，就跑過去跪下來拜祂，高聲喊道：</span>
<span className="v" id="v7" data-v="7" data-xref="馬太福音 8:29; 使徒行傳 16:17; 馬太福音 26:63"> 「至高上帝的兒子耶穌啊，我和你有什麼關係？看在上帝的份上，求你不要折磨我！」</span>
<span className="v" id="v8" data-v="8" data-xref="馬可福音 1:25; 馬可福音 9:25–26; 使徒行傳 16:18"> 原來，耶穌已經對他身上的鬼說：「污鬼，從這人身上出來！」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="路加福音 8:30; 馬可福音 5:15; 馬太福音 26:53"> 耶穌問：「你叫什麼名字？」<br />他說：「我的名字叫『群』，因為我們是一大群。」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="馬可福音 3:22; 馬可福音 5:13"> 接著污鬼再三哀求耶穌，不要把牠們趕出那個地區。</span>
<span className="v" id="v11" data-v="11" data-xref="利未記 11:7–8; 以賽亞書 65:4; 以賽亞書 66:3"> 當時有一大群豬在附近山坡上吃食。</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多後書 2:11; 約伯記 1:10–12; 路加福音 22:31–32"> 污鬼就央求耶穌說：「讓我們到豬群裡去，附在牠們身上吧！」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="列王紀上 22:22; 彼得前書 3:22; 約伯記 2:6"> 耶穌允許了，污鬼就離開那人，進入豬群。那群豬就一路奔下陡坡，衝進湖裡淹死了，約有兩千頭。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="路加福音 8:34; 馬太福音 8:33"> 放豬的人逃走了，把這事傳遍了城裡鄉間，人們都跑來看個究竟。</span>
<span className="v" id="v15" data-v="15" data-xref="歌羅西書 1:13; 提摩太後書 1:7; 撒母耳記上 6:20–21"> 他們到了耶穌那裡，看見那曾被群鬼附身的人神智清醒、衣著整齊地坐在那裡，都很害怕。</span>
<span className="v" id="v16" data-v="16"> 目擊者把被鬼附身的人和豬群的事告訴了他們，</span>
<span className="v" id="v17" data-v="17" data-xref="馬太福音 8:34; 馬可福音 1:24; 路加福音 8:37"> 他們就請求耶穌離開他們那裡。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="路加福音 8:38–39; 腓立比書 1:23–24; 馬可福音 5:17"> 耶穌上船的時候，那曾被鬼附身的人懇求耶穌讓他隨行。</span>
<span className="v" id="v19" data-v="19" data-xref="詩篇 66:16; 約翰福音 4:29; 以賽亞書 38:9–20"> 耶穌沒有答應，而是對他說：「回去見你的家人，把主為你所行的奇事和祂憐憫你的經過都告訴他們吧！」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="馬可福音 7:31; 馬太福音 4:25"> 這人就回到低加坡里一帶傳揚耶穌為他所行的奇事，人們都很驚奇。</span>
</div>
</div>

## 耶穌醫治有信心的人

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="馬太福音 9:1; 馬可福音 4:1; 路加福音 8:40"> 耶穌再坐船回到對岸，有一大群人在岸邊圍著祂。</span>
<span className="v" id="v22" data-v="22" data-xref="路加福音 13:14; 使徒行傳 18:8; 馬可福音 5:35–36"> 這時來了一個名叫雅魯的會堂主管，他一見到耶穌便俯伏在祂腳前，</span>
<span className="v" id="v23" data-v="23" data-xref="路加福音 13:13; 路加福音 4:40; 馬可福音 16:18"> 迫切懇求說：「我小女兒快要死了，求你去把手按在她身上，醫治她，救她一命。」</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="馬可福音 5:31; 馬可福音 3:20; 路加福音 7:6"> 耶穌和他同去，一大群人跟著祂，擁擠著祂。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="利未記 15:25–27; 路加福音 8:43–44; 馬太福音 9:20–22"> 有一個婦人患血漏病已經十二年，</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米書 30:12–13; 耶利米書 8:22; 詩篇 108:12"> 經過許多醫生的診治，受盡痛苦，耗盡錢財，病情仍沒有好轉，反而更加嚴重。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行傳 19:12; 馬太福音 14:36; 使徒行傳 5:15"> 她聽見耶穌的事，就夾在人群中從耶穌背後摸祂的衣服，</span>
<span className="v" id="v28" data-v="28"> 心想：「我只要摸到祂的衣服，就會痊癒。」</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="馬可福音 5:34; 詩篇 30:2; 馬可福音 3:10"> 她的血漏立刻止住了，她感到自己痊癒了。</span>
<span className="v" id="v30" data-v="30" data-xref="路加福音 6:19; 路加福音 8:46; 路加福音 5:17"> 耶穌馬上知道有能力從自己身上發出，便在人群中轉過身來問：「誰摸了我的衣服？」</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="路加福音 8:45; 路加福音 9:12"> 門徒對祂說：「你看，這麼多人在你周圍擠來擠去，你怎麼問誰摸你呢？」</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32"> 耶穌環視四周，要找出摸祂的人。</span>
<span className="v" id="v33" data-v="33" data-xref="路加福音 8:47; 路加福音 1:29; 路加福音 1:12"> 那婦人害怕得發抖，知道在自己身上發生了什麼，就上前俯伏在耶穌腳前，將實情說了出來。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="路加福音 8:48; 馬太福音 9:22; 路加福音 7:50"> 耶穌說：「女兒，你的信心救了你。安心去吧！你的病好了。」</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="路加福音 8:49; 約翰福音 11:39; 馬可福音 5:22"> 耶穌還在說話的時候，有人從雅魯家趕來，對雅魯說：「你的女兒已經死了，何必再麻煩老師呢？」</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="路加福音 8:50; 馬太福音 9:28–29; 約翰福音 11:40"> 耶穌聽了，就對雅魯說：「不要怕，只要信。」</span>
<span className="v" id="v37" data-v="37" data-xref="使徒行傳 9:40; 馬可福音 14:33; 哥林多後書 13:1"> 於是，祂帶著彼得、雅各和雅各的弟弟約翰去雅魯家，不准其他人跟著。</span>
<span className="v" id="v38" data-v="38" data-xref="馬太福音 9:23–24; 路加福音 8:52–53; 馬可福音 5:22"> 他們到了會堂主管家，耶穌看見在場的人嚎啕大哭，場面混亂。</span>
<span className="v" id="v39" data-v="39" data-xref="使徒行傳 20:10; 帖撒羅尼迦前書 5:10; 帖撒羅尼迦前書 4:13–14"> 耶穌進去問道：「你們為什麼亂哄哄地哭叫呢？這孩子沒有死，只是睡著了。」</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="尼希米記 2:19; 列王紀下 4:33; 馬太福音 9:24–25"> 眾人都譏笑祂。耶穌讓他們全部出去，然後帶著女孩的父母和三個門徒進了孩子的房間。</span>
<span className="v" id="v41" data-v="41" data-xref="馬可福音 1:31; 路加福音 7:14–15; 路加福音 8:54–55"> 祂拉著女孩的手說：「大利大，古米！」意思是：「小女孩，我吩咐你起來！」</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="馬可福音 4:41; 使徒行傳 3:10–13; 馬可福音 7:37"> 女孩應聲而起，開始走動。當時她十二歲。在場的人都驚奇不已。</span>
<span className="v" id="v43" data-v="43" data-xref="馬太福音 8:4; 馬太福音 9:30; 馬可福音 1:43"> 耶穌鄭重叮囑他們不要把這事張揚出去，又吩咐他們給女孩東西吃。</span>
</div>
</div>

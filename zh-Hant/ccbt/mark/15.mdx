## 耶穌在彼拉多面前受審

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="馬太福音 27:1–2; 路加福音 23:1–5; 路加福音 22:66"> 清早，祭司長、長老、律法教師和全公會的人商定後，便把耶穌綁起來押送到彼拉多那裡。</span>
<span className="v" id="v2" data-v="2" data-xref="馬太福音 2:2; 馬太福音 27:11–14; 提摩太前書 6:13"> 彼拉多問耶穌：「你是猶太人的王嗎？」 耶穌回答說：「如你所言。」</span>
<span className="v" id="v3" data-v="3" data-xref="以賽亞書 53:7; 馬可福音 15:5; 約翰福音 18:29–31"> 祭司長控告耶穌許多罪。</span>
<span className="v" id="v4" data-v="4" data-xref="約翰福音 19:10; 馬太福音 27:13; 馬太福音 26:62"> 彼拉多又問道：「你看，他們控告你這麼多，你都不回答嗎？」</span>
<span className="v" id="v5" data-v="5" data-xref="以賽亞書 53:7; 撒迦利亞書 3:8; 詩篇 71:7"> 耶穌仍舊一言不發，彼拉多感到驚奇。</span>
<span className="v" id="v6" data-v="6" data-xref="約翰福音 18:39–40; 使徒行傳 25:9; 使徒行傳 24:27"> 每逢逾越節，彼拉多都會照慣例按民眾的要求釋放一個囚犯。</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 23:18–19; 馬太福音 27:16; 路加福音 23:25"> 那時，有一個囚犯名叫巴拉巴，與其他作亂時殺過人的囚犯關在一起。</span>
<span className="v" id="v8" data-v="8"> 百姓聚來，要求彼拉多照慣例釋放一個囚犯。</span>
<span className="v" id="v9" data-v="9" data-xref="約翰福音 19:14–16; 約翰福音 19:4–5; 約翰福音 18:39"> 彼拉多問：「你們要我為你們釋放猶太人的王嗎？」</span>
<span className="v" id="v10" data-v="10" data-xref="箴言 27:4; 提多書 3:3; 創世記 4:4–6"> 因為他知道祭司長把耶穌押來是出於嫉妒。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行傳 3:14; 約翰福音 18:40; 何西阿書 5:1"> 但祭司長卻煽動百姓，叫他們要求彼拉多釋放巴拉巴。</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米書 23:5–6; 以賽亞書 9:6–7; 撒迦利亞書 9:9"> 彼拉多又問他們：「那麼，這位你們稱為猶太人之王的，我如何處置呢？」</span>
<span className="v" id="v13" data-v="13"> 他們高喊：「把祂釘在十字架上！」</span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 23:41; 路加福音 23:23–24; 以賽亞書 53:3"> 彼拉多問：「為什麼？祂犯了什麼罪？」 他們卻更大聲地喊：「把祂釘在十字架上！」</span>
<span className="v" id="v15" data-v="15" data-xref="約翰福音 19:1; 馬太福音 27:26; 以賽亞書 50:6"> 為了取悅眾人，彼拉多釋放了巴拉巴，下令將耶穌鞭打後交出去釘十字架。</span>
</div>
</div>

## 耶穌受辱

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="約翰福音 19:9; 馬太福音 27:27–31; 約翰福音 18:28"> 於是，士兵把耶穌押進總督府的院子，集合了全營的士兵。</span>
<span className="v" id="v17" data-v="17" data-xref="馬太福音 27:28–30; 約翰福音 19:2–5; 路加福音 23:11"> 他們給祂穿上紫袍，用荊棘編成冠冕戴在祂頭上，</span>
<span className="v" id="v18" data-v="18" data-xref="馬太福音 27:42–43; 馬可福音 15:2; 創世記 37:10"> 向祂行禮，並高呼：「猶太人的王萬歲！」</span>
<span className="v" id="v19" data-v="19" data-xref="馬可福音 14:65; 以賽亞書 53:3–5; 路加福音 23:11"> 他們用葦稈打祂的頭，向祂吐唾沫，跪拜祂。</span>
<span className="v" id="v20" data-v="20" data-xref="約翰福音 19:16; 馬太福音 27:31"> 戲弄完了，就脫去祂的紫袍，給祂穿上原來的衣服，押祂出去釘十字架。</span>
</div>
</div>

## 釘十字架

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="馬太福音 27:32; 路加福音 23:26; 羅馬書 16:13"> 亞歷山大和魯孚的父親古利奈人西門從鄉下來，途經那地方，衛兵就強迫他背耶穌的十字架。</span>
<span className="v" id="v22" data-v="22" data-xref="馬太福音 27:33–44; 約翰福音 19:17–27; 路加福音 23:27–38"> 他們把耶穌帶到各各他——意思是「髑髏地」，</span>
<span className="v" id="v23" data-v="23" data-xref="馬太福音 27:34; 約翰福音 19:28–30; 路加福音 23:36"> 拿沒藥調和的酒給祂喝，但祂不肯喝。</span>
<span className="v" id="v24" data-v="24" data-xref="路加福音 23:34; 約翰福音 19:23–24; 馬太福音 27:35–36"> 他們把耶穌釘在十字架上，還抽籤分祂的衣服。</span>
<span className="v" id="v25" data-v="25" data-xref="約翰福音 19:14; 馬可福音 15:33; 馬太福音 27:45"> 他們釘祂十字架的時間是在上午九點鐘。</span>
<span className="v" id="v26" data-v="26" data-xref="馬太福音 27:37; 馬太福音 2:2; 約翰福音 19:18–22"> 祂的罪狀牌上寫著「猶太人的王」。</span>
<span className="v" id="v27" data-v="27" data-xref="路加福音 23:32–33; 馬太福音 27:38; 約翰福音 19:18"> 他們還把兩個強盜釘在十字架上，一個在祂右邊，一個在祂左邊，</span>
<span className="v" id="v28" data-v="28"> 這應驗了聖經的話：「祂被列在罪犯中。」<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古卷無28節。">a</a></sup></span>
<span className="v" id="v29" data-v="29" data-xref="馬可福音 14:58; 詩篇 109:25; 耶利米哀歌 1:12"> 過路的人都嘲笑祂，搖著頭說：「哈，你這要把聖殿拆毀又在三天內重建的人啊，</span>
<span className="v" id="v30" data-v="30"> 救救你自己，從十字架上下來吧！」</span>
<span className="v" id="v31" data-v="31" data-xref="約翰福音 12:23–24; 馬太福音 27:41–43; 路加福音 23:35–37"> 祭司長和律法教師也同樣嘲諷祂，彼此議論說：「祂救了別人，卻救不了自己！</span>
<span className="v" id="v32" data-v="32" data-xref="馬太福音 27:44; 路加福音 23:39–43; 撒迦利亞書 9:9"> 以色列的王基督，現在從十字架上下來吧！讓我們看看，我們就信了！」與祂同釘十字架的強盜也嘲笑祂。</span>
</div>
</div>

## 耶穌之死

<div className="bt">
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="馬太福音 27:45; 路加福音 23:44–45; 阿摩司書 8:9–10"> 正午時分，黑暗籠罩著整個大地，一直到下午三點。</span>
<span className="v" id="v34" data-v="34" data-xref="詩篇 22:1; 馬太福音 27:46; 希伯來書 5:7"> 大約下午三點，耶穌大聲呼喊：「以羅伊，以羅伊，拉馬撒巴各大尼？」意思是：「我的上帝，我的上帝，你為什麼離棄我？」<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="詩篇22·1。">b</a></sup></span>
<span className="v" id="v35" data-v="35" data-xref="馬太福音 27:47–49; 馬可福音 9:11–13; 馬太福音 17:11–13"> 有些站在旁邊的人聽見了，就說：「聽，祂在呼叫以利亞。」</span>
<span className="v" id="v36" data-v="36" data-xref="詩篇 69:21; 馬可福音 15:23; 約翰福音 19:28–30"> 有人跑去把一塊海綿蘸滿酸酒，綁在葦稈上送給祂喝，說：「等著吧，我們看看以利亞會不會救祂下來。」</span>
<span className="v" id="v37" data-v="37" data-xref="約翰福音 19:30; 路加福音 23:46; 馬太福音 27:50"> 耶穌大叫一聲，就斷了氣。</span>
<span className="v" id="v38" data-v="38" data-xref="希伯來書 10:19–23; 路加福音 23:45; 希伯來書 9:3–12"> 聖殿的幔子從上到下裂成兩半。</span>
<span className="v" id="v39" data-v="39" data-xref="馬太福音 27:54; 路加福音 23:47–48; 馬太福音 27:43"> 站在對面的百夫長看見耶穌喊叫<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="有古卷無「喊叫」二字。">c</a></sup>斷氣的情形，便說：「這人真是上帝的兒子！」</span>
<span className="v" id="v40" data-v="40" data-xref="路加福音 23:49; 路加福音 8:2–3; 馬太福音 27:55–56"> 有些婦女在遠處觀看，其中有抹大拉的瑪麗亞、小雅各和約西的母親瑪麗亞並撒羅米。</span>
<span className="v" id="v41" data-v="41" data-xref="路加福音 8:2–3; 馬太福音 27:55–56"> 耶穌在加利利時，她們就跟隨祂、服侍祂了。此外還有好些跟著祂上耶路撒冷的婦女。</span>
</div>
</div>

## 安葬耶穌

<div className="bt">
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="路加福音 23:50–56; 約翰福音 19:38–42; 約翰福音 19:31"> 那天是猶太人的預備日，也就是安息日的前一天。傍晚，</span>
<span className="v" id="v43" data-v="43" data-xref="路加福音 2:38; 路加福音 2:25; 路加福音 23:51"> 亞利馬太人約瑟鼓起勇氣去見彼拉多，要求領取耶穌的遺體。他是一位德高望重的公會議員，一直在等候上帝的國。</span>
<span className="v" id="v44" data-v="44" data-xref="約翰福音 19:31–37"> 彼拉多聽見耶穌已經死了，十分驚訝，便把百夫長召來問個明白，</span>
<span className="v" id="v45" data-v="45" data-xref="馬太福音 27:58; 約翰福音 19:38; 馬可福音 15:39"> 得知耶穌確實已死，便將耶穌的遺體交給約瑟。</span>
<span className="v" id="v46" data-v="46" data-xref="以賽亞書 53:9; 馬太福音 27:59–60; 以賽亞書 22:16"> 約瑟把耶穌的遺體取下來，用買來的細麻布裹好，安放在一個在巖壁上鑿出的墓穴裡，又滾來一塊大石頭堵住墓口。</span>
<span className="v" id="v47" data-v="47" data-xref="馬可福音 15:40; 馬可福音 16:1; 路加福音 23:55–2"> 抹大拉的瑪麗亞和約西的母親瑪麗亞都看到了安葬耶穌的地方。</span>
</div>

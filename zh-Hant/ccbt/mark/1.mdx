## 施洗者約翰預備道路

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="約翰一書 5:11–12; 馬太福音 4:3; 馬太福音 3:17"> 有關上帝的兒子耶穌基督的福音是這樣開始的，</span>
<span className="v" id="v2" data-v="2" data-xref="瑪拉基書 3:1; 馬太福音 11:10; 路加福音 1:76"> 正如以賽亞先知書上說：<br /><span className="pl pl-1">「看啊，我要差遣我的使者在你前面為你預備道路。</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="瑪拉基書3·1。">a</a></sup><br /></span>
<span className="v" id="v3" data-v="3" data-xref="以賽亞書 40:3–5; 馬太福音 3:3; 路加福音 3:4–6"> <span className="pl pl-1">他在曠野大聲呼喊，</span><br /><span className="pl pl-1">『預備主的道，</span><br /><span className="pl pl-1">修直祂的路。』</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="以賽亞書40·3。">b</a></sup><br /><span className="pl pl-1">」</span></span>
<span className="v" id="v4" data-v="4" data-xref="使徒行傳 19:3–4; 馬太福音 3:6; 使徒行傳 13:24–25"> 果然，施洗者約翰出現了，他在曠野宣講悔改就得赦罪的洗禮。</span>
<span className="v" id="v5" data-v="5" data-xref="利未記 26:40–42; 使徒行傳 19:18; 馬太福音 3:5–6"> 猶太全境和耶路撒冷的居民都到約翰那裡，承認他們的罪，在約旦河裡接受他的洗禮。</span>
<span className="v" id="v6" data-v="6" data-xref="列王紀下 1:8; 利未記 11:22; 馬太福音 3:4"> 約翰身穿駱駝毛的衣服，腰束皮帶，吃的是蝗蟲和野蜜。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行傳 13:25; 路加福音 3:16; 約翰福音 1:27"> 他傳道說：「在我之後，有一位比我更有能力的要來，我連彎腰給祂解鞋帶都不配。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行傳 1:5; 哥林多前書 12:13; 使徒行傳 19:4–6"> 我是用水給你們施洗，但祂要用聖靈給你們施洗。」</span>
</div>
</div>

## 耶穌受洗

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="馬太福音 3:13–17; 馬太福音 2:23; 路加福音 3:21–22"> 那時，耶穌從加利利的拿撒勒來，在約旦河受了約翰的洗禮。</span>
<span className="v" id="v10" data-v="10" data-xref="約翰福音 1:31–34; 路加福音 3:22; 以賽亞書 42:1"> 耶穌從水中一上來，就看見天裂開了，聖靈好像鴿子一樣降在祂身上，</span>
<span className="v" id="v11" data-v="11" data-xref="以賽亞書 42:1; 馬可福音 9:7; 馬太福音 3:17"> 有聲音從天上傳來：「你是我的愛子，我喜悅你。」</span>
</div>
</div>

## 耶穌受試探

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="馬太福音 4:1–11; 路加福音 4:1–13"> 聖靈隨即催促祂到曠野。</span>
<span className="v" id="v13" data-v="13" data-xref="希伯來書 2:17–18; 希伯來書 4:15; 出埃及記 34:28"> 祂在曠野受撒旦的試探四十天。祂與野獸在一起，有天使伺候祂。</span>
</div>
</div>

## 呼召四漁夫

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="馬太福音 4:23; 馬太福音 4:12; 路加福音 8:1"> 約翰被捕後，耶穌來到加利利宣講上帝的福音，說：</span>
<span className="v" id="v15" data-v="15" data-xref="馬太福音 3:2; 使徒行傳 2:36–38; 馬太福音 4:17"> 「時候到了，上帝的國臨近了，你們要悔改，相信福音。」</span>
<span className="v" id="v16" data-v="16" data-xref="馬太福音 4:18–22; 約翰福音 1:40–42; 約翰福音 6:8"> 耶穌沿著加利利湖邊走，看見西門和他弟弟安得烈正在向湖裡撒網。他們是漁夫。</span>
<span className="v" id="v17" data-v="17" data-xref="路加福音 5:10; 馬太福音 4:19–20; 使徒行傳 2:38–41"> 耶穌對他們說：「來跟從我！我要使你們成為得人的漁夫。」</span>
<span className="v" id="v18" data-v="18" data-xref="路加福音 18:28–30; 路加福音 5:11; 馬可福音 10:28–31"> 他們立刻撇下漁網，跟從了耶穌。</span>
<span className="v" id="v19" data-v="19" data-xref="馬可福音 5:37; 使徒行傳 1:13; 馬可福音 10:35"> 耶穌往前走了不遠，又看見西庇太的兩個兒子雅各和約翰正在船上補網，</span>
<span className="v" id="v20" data-v="20" data-xref="馬太福音 10:37; 路加福音 14:26; 馬可福音 10:29"> 便立刻呼召他們。他們就辭別父親西庇太和船上的僱工，跟從了耶穌。</span>
</div>
</div>

## 傳道趕鬼

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="馬可福音 6:2; 馬可福音 1:39; 馬太福音 4:23"> 他們到了迦百農，耶穌在安息日去會堂裡教導人。</span>
<span className="v" id="v22" data-v="22" data-xref="馬太福音 7:28–29; 馬太福音 13:54; 路加福音 4:32"> 那裡的人都很驚奇，因為祂教導他們時像個有權柄的人，不像律法教師。</span>
<span className="v" id="v23" data-v="23" data-xref="馬可福音 9:25; 馬可福音 7:25; 馬可福音 1:34"> 當時會堂裡有一個被污鬼附身的人喊道：</span>
<span className="v" id="v24" data-v="24" data-xref="馬太福音 8:29; 雅各書 2:19; 使徒行傳 3:14"> 「拿撒勒的耶穌啊，我們和你有什麼關係？你是來毀滅我們嗎？我知道你是誰，你是上帝的聖者！」</span>
<span className="v" id="v25" data-v="25" data-xref="馬可福音 1:34; 路加福音 4:41; 使徒行傳 16:17"> 耶穌責備牠說：「住口，從他身上出來！」</span>
<span className="v" id="v26" data-v="26" data-xref="馬可福音 9:26; 馬可福音 9:20; 路加福音 11:22"> 污鬼使那人抽搐了一陣，大叫一聲，就從他身上出來了。</span>
<span className="v" id="v27" data-v="27" data-xref="馬太福音 15:31; 馬可福音 7:37; 路加福音 9:1"> 眾人都很驚訝，彼此議論說：「這是怎麼回事？真是帶著權柄的新教導啊！祂一發命令，污鬼都服從祂。」</span>
<span className="v" id="v28" data-v="28" data-xref="馬太福音 9:31; 路加福音 4:37; 馬可福音 1:45"> 於是，耶穌的名聲立刻傳遍了整個加利利一帶。</span>
</div>
</div>

## 醫病趕鬼

<div className="bt">
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="路加福音 4:38–39; 馬太福音 8:14–15; 馬可福音 1:21"> 耶穌同雅各和約翰離開會堂後，就來到西門和安得烈家。</span>
<span className="v" id="v30" data-v="30" data-xref="哥林多前書 9:5; 馬可福音 5:23; 約翰福音 11:3"> 當時西門的岳母正發燒，躺在床上，他們立刻把這事告訴耶穌。</span>
<span className="v" id="v31" data-v="31" data-xref="使徒行傳 9:41; 詩篇 116:12; 馬可福音 5:41"> 耶穌走到她的床邊，拉著她的手扶她起來，她的燒就退了，她便起來服侍他們。</span>
<span className="v" id="v32" data-v="32" data-xref="馬太福音 8:16; 馬可福音 3:2; 路加福音 4:40"> 傍晚，日落之後，有人把病人和被鬼附身的人都帶來見耶穌。</span>
<span className="v" id="v33" data-v="33" data-xref="馬可福音 1:5; 使徒行傳 13:44"> 全城的人都聚在門前。</span>
<span className="v" id="v34" data-v="34" data-xref="路加福音 4:41; 馬可福音 3:12; 馬太福音 4:23"> 耶穌治好了許多患各種疾病的人，又趕出很多鬼。祂不許鬼說話，因為鬼認識祂。</span>
</div>
</div>

## 在加利利傳道

<div className="bt">
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="路加福音 6:12; 路加福音 5:16; 路加福音 22:39–46"> 第二天清早，天還沒亮，耶穌就起來出門去荒僻的地方禱告。</span>
<span className="v" id="v36" data-v="36"> 西門和同伴們四處尋找耶穌，</span>
<span className="v" id="v37" data-v="37" data-xref="約翰福音 12:19; 馬可福音 1:5; 撒迦利亞書 11:11"> 找到後便對祂說：「大家都在找你呢！」</span>
<span className="v" id="v38" data-v="38" data-xref="路加福音 4:43; 約翰福音 17:8; 以賽亞書 61:1–3"> 耶穌卻回答說：「我們到附近的鄉鎮去吧，我也好在那裡傳道，因為我就是為此而來的。」</span>
<span className="v" id="v39" data-v="39" data-xref="馬太福音 4:23; 馬可福音 1:21; 路加福音 4:43–44"> 於是，耶穌走遍加利利，在各會堂傳道，趕鬼。</span>
</div>
</div>

## 治好痲瘋病人

<div className="bt">
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="路加福音 5:12–14; 馬太福音 8:2–4; 利未記 13:1–14"> 有一次，一個患痲瘋病的人來到耶穌面前，跪下央求：「如果你肯，就能使我潔淨。」</span>
<span className="v" id="v41" data-v="41" data-xref="馬太福音 9:36; 希伯來書 2:17; 希伯來書 4:15"> 耶穌動了慈心，就伸手摸他，說：「我肯，你潔淨了吧！」</span>
<span className="v" id="v42" data-v="42" data-xref="約翰福音 15:3; 馬可福音 5:29; 約翰福音 4:50–53"> 那人的痲瘋病立即消失了，他就潔淨了。</span>
<span className="v" id="v43" data-v="43" data-xref="馬太福音 9:30; 馬可福音 7:36; 路加福音 8:56"> 耶穌隨即讓他回去並鄭重地叮囑：</span>
<span className="v" id="v44" data-v="44" data-xref="利未記 14:1–32; 路加福音 17:14; 馬太福音 8:4"> 「切勿把這事告訴別人，要去讓祭司察看你的身體，並照摩西的規定獻祭，向眾人證明你已經潔淨了。」</span>
<span className="v" id="v45" data-v="45" data-xref="馬可福音 2:13; 馬太福音 9:31; 約翰福音 6:2"> 但那人離開之後，卻到處傳揚這件事，以致耶穌無法再公開進城。祂只能待在城外的曠野，可是人們仍從各處來找祂。</span>
</div>
</div>

## 天上的讚美

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="啟示錄 7:10–12; 歷代志上 29:11; 啟示錄 11:15"> 此後，我聽見天上好像有一大群人在呼喊：「哈利路亞<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「哈利路亞」意思是「要讚美上帝」。">a</a></sup>！救贖、榮耀和權能都歸於我們的上帝！</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 32:43; 啟示錄 6:10; 啟示錄 18:20"> 因為祂的審判真實公義，祂懲罰了那用淫亂敗壞世界的大淫婦，為那些被她殺害的奴僕伸冤。」</span>
<span className="v" id="v3" data-v="3" data-xref="以賽亞書 34:10; 啟示錄 18:18; 啟示錄 14:11"> 他們又歡呼說：「哈利路亞！焚燒大淫婦的煙不斷上騰，直到永永遠遠。」</span>
<span className="v" id="v4" data-v="4" data-xref="啟示錄 5:14; 尼希米記 8:6; 詩篇 106:48"> 那二十四位長老和四個活物也俯伏敬拜坐在寶座上的上帝，說：「阿們！哈利路亞！」</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 134:1; 詩篇 148:11–13; 詩篇 150:6"> 這時從寶座那裡發出聲音，說：「上帝所有的奴僕和一切敬畏祂的人，無論尊卑，都要讚美我們的上帝！」</span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 97:1; 啟示錄 14:2; 詩篇 93:1"> 我聽見有聲音好像一大群人的呼喊聲，又像洪濤，也像雷鳴，說：「哈利路亞！因為我們的主，全能的上帝已經執掌王權了。</span>
<span className="v" id="v7" data-v="7" data-xref="啟示錄 21:9; 啟示錄 21:2; 啟示錄 19:9"> 我們要歡喜快樂，歸榮耀給祂，因為羔羊的婚期到了，祂的新娘已預備妥當，</span>
<span className="v" id="v8" data-v="8" data-xref="以賽亞書 61:10; 啟示錄 7:13–14; 詩篇 132:9"> 獲准穿上光亮潔白的細麻衣。」這細麻衣代表聖徒的義行。</span>
<span className="v" id="v9" data-v="9" data-xref="啟示錄 22:6; 馬太福音 22:2–4; 路加福音 14:15–16"> 天使吩咐我說：「你要寫下來，被邀請參加羔羊婚宴的人有福了！」他又說：「這是上帝說的，千真萬確。」</span>
<span className="v" id="v10" data-v="10" data-xref="啟示錄 22:8–9; 使徒行傳 10:25–26; 約翰福音 5:39"> 我俯伏在他腳前要拜他，他卻說：「千萬不可！我和你並那些為耶穌作見證的弟兄姊妹同是上帝的奴僕。你要敬拜上帝，因為預言的真諦<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="「真諦」或譯「靈」。">b</a></sup>就是為耶穌作見證。」</span>
</div>
</div>

## 白馬騎士

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="詩篇 96:13; 以賽亞書 11:3–5; 詩篇 98:9"> 我看見天開了，有一匹白馬出來，馬上的騎士名叫「誠信真實」，祂憑公義審判和爭戰。</span>
<span className="v" id="v12" data-v="12" data-xref="啟示錄 19:16; 路加福音 10:22; 啟示錄 2:17–18"> 祂雙目如炬，頭上戴了許多冠冕，身上寫著一個只有祂自己才明白的名字。</span>
<span className="v" id="v13" data-v="13" data-xref="約翰福音 1:1; 以賽亞書 63:1–6; 約翰福音 1:14"> 祂穿著被血浸透的衣服，祂的名字是「上帝的道」。</span>
<span className="v" id="v14" data-v="14" data-xref="猶大書 1:14; 啟示錄 7:9; 啟示錄 19:8"> 眾天軍穿著潔白的細麻衣，騎著白馬跟隨祂。</span>
<span className="v" id="v15" data-v="15" data-xref="以賽亞書 63:2–6; 啟示錄 1:16; 啟示錄 2:27"> 祂口中吐出一把利劍，可以攻擊列國。祂必用鐵杖統治他們，<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="詩篇2·9。">c</a></sup>祂必踩踏盛滿全能上帝之烈怒的榨酒池。</span>
<span className="v" id="v16" data-v="16" data-xref="啟示錄 17:14; 提摩太前書 6:15; 但以理書 2:47"> 祂的衣服和大腿上都寫著祂的名號：「萬王之王，萬主之主。」</span>
<span className="v" id="v17" data-v="17" data-xref="啟示錄 19:21; 啟示錄 8:13; 以西結書 39:17–20"> 我又看見一位天使站在太陽裡，對空中飛翔的鳥大聲呼喚：「來吧！一起來參加上帝的盛宴，</span>
<span className="v" id="v18" data-v="18" data-xref="以西結書 39:18–20; 啟示錄 6:15; 撒母耳記上 17:44"> 一同吃君王、將軍、勇士、馬匹、騎士和所有人的肉吧，無論他們是自由人還是奴隸，尊貴還是卑賤。」</span>
<span className="v" id="v19" data-v="19" data-xref="啟示錄 16:16; 啟示錄 16:14; 啟示錄 17:12–14"> 我看見那怪獸、地上的眾王及其軍隊聚集起來，與白馬騎士和祂的軍隊作戰。</span>
<span className="v" id="v20" data-v="20" data-xref="啟示錄 20:10; 啟示錄 21:8; 帖撒羅尼迦後書 2:8–11"> 怪獸被俘虜了，在怪獸面前行奇蹟的假先知也一同被擒了。這假先知曾用奇蹟迷惑那些蓋了獸印、敬拜獸像的人。他和怪獸一同被活活地扔進硫磺火湖裡。</span>
<span className="v" id="v21" data-v="21" data-xref="啟示錄 19:11–15; 啟示錄 1:16; 啟示錄 19:17–19"> 其餘的被白馬騎士口中的利劍所殺，飛鳥飽餐了他們的肉。</span>
</div>
</div>

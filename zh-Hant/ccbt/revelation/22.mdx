<span className="v" id="v4" data-v="4" data-xref="馬太福音 5:8; 啟示錄 14:1; 啟示錄 3:12"> 他們必見上帝的面，上帝的名字必印在他們的額上。</span>

## 基督的再來

<div className="bt">
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="啟示錄 1:1; 啟示錄 21:5; 啟示錄 19:9"> 天使對我說：「這些話真實可靠。賜聖靈感動眾先知的主上帝已差遣祂的天使，將很快必發生的事指示給祂的奴僕們。」</span>
<span className="v" id="v7" data-v="7" data-xref="啟示錄 1:3; 啟示錄 3:11; 啟示錄 22:20"> 「看啊，我快要來了。遵行這書中預言的人有福了！」</span>
<span className="v" id="v8" data-v="8" data-xref="啟示錄 19:10; 啟示錄 1:1; 啟示錄 19:19"> 以上都是我約翰的所見所聞。我耳聞目睹這些事後，就俯伏敬拜讓我看這些事的天使。</span>
<span className="v" id="v9" data-v="9" data-xref="啟示錄 19:10; 歌羅西書 2:18–19; 啟示錄 14:7"> 天使對我說：「千萬不可！我與你、你的眾先知弟兄和那些遵行這書上話語的人同是上帝的奴僕，你要敬拜上帝。」</span>
<span className="v" id="v10" data-v="10" data-xref="但以理書 8:26; 啟示錄 1:3; 彼得前書 4:7"> 他又對我說：「不可封住這卷書上的預言，因為時候快到了。</span>
<span className="v" id="v11" data-v="11" data-xref="但以理書 12:10; 箴言 4:18; 以西結書 3:27"> 不義的，讓他繼續不義；污穢的，讓他繼續污穢；公義的，讓他保持公義；聖潔的，讓他保持聖潔。」</span>
<span className="v" id="v12" data-v="12" data-xref="馬太福音 16:27; 以賽亞書 62:11; 以賽亞書 40:10"> 「看啊，我快要來了，賞罰在我，我要按各人的行為施行賞罰。</span>
<span className="v" id="v13" data-v="13" data-xref="啟示錄 1:8; 啟示錄 21:6; 以賽亞書 44:6"> 我是阿拉法，我是俄梅加；我是首先的，我是末後的；我是開始，我是終結。</span>
<span className="v" id="v14" data-v="14" data-xref="啟示錄 21:27; 約翰一書 5:3; 啟示錄 22:7"> 那些洗淨自己衣裳的人有福了！他們有權得生命樹的果子，也可以從城門進入城中。</span>
<span className="v" id="v15" data-v="15" data-xref="啟示錄 21:8; 加拉太書 5:19–21; 腓立比書 3:2"> 那些如同惡犬的敗類、行邪術的、淫亂的、殺人的、拜偶像的和一切喜歡弄虛作假的，都要被拒之城外。</span>
<span className="v" id="v16" data-v="16" data-xref="啟示錄 5:5; 彼得後書 1:19; 以賽亞書 11:1"> 我耶穌差遣我的天使到眾教會，向你們證明這些事。我是大衛的根，也是大衛的後裔，又是明亮的晨星。」</span>
<span className="v" id="v17" data-v="17" data-xref="約翰福音 4:14; 啟示錄 21:6; 以賽亞書 55:1–3"> 聖靈和新娘都說：「來吧！」聽見的也要說：「來吧！」口渴的，讓他來吧！願意的，讓他白白地享用生命水吧！</span>
</div>
</div>

## 警告

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="申命記 12:32; 申命記 4:2; 箴言 30:6"> 我警告所有聽見這書上預言的人：如果誰在這書上增添什麼，上帝必將這書上所記載的災禍加在他身上；</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 4:2; 路加福音 11:52; 啟示錄 22:2"> 如果有人從這預言書上刪減什麼，上帝必使他無份於這書上所記載的生命樹和聖城。</span>
<span className="v" id="v20" data-v="20" data-xref="啟示錄 22:7; 希伯來書 9:28; 啟示錄 22:12"> 那位證明這些事的說：「是的，我快要來了。」阿們！主耶穌啊，我願你來！</span>
<span className="v" id="v21" data-v="21" data-xref="帖撒羅尼迦後書 3:18; 羅馬書 16:20; 哥林多後書 13:14"> 願主耶穌的恩典與眾聖徒同在。阿們！</span>
</div>
</div>

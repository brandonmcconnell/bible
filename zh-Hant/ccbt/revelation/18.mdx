## 巴比倫的下場

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="以西結書 43:2; 路加福音 17:24; 帖撒羅尼迦後書 2:8"> 此後，我看見另一位執掌大權的天使從天而降，他的榮光照亮了大地。</span>
<span className="v" id="v2" data-v="2" data-xref="啟示錄 14:8; 耶利米書 51:8; 耶利米書 51:37"> 他用強有力的聲音喊道：<br /><span className="pl pl-1">「巴比倫大城倒塌了！倒塌了！</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="以賽亞書21·9。">a</a></sup><br /><span className="pl pl-1">她成了鬼魔的住處，</span><br /><span className="pl pl-1">各樣污穢之靈的巢穴，</span><br /><span className="pl pl-1">各樣污穢之鳥的老巢，</span><br /><span className="pl pl-1">各樣污穢可憎之獸的老窩。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="啟示錄 14:8; 啟示錄 17:2; 啟示錄 18:9"> <span className="pl pl-1">因為列國都喝了她淫亂的烈酒。</span><br /><span className="pl pl-1">地上的君王與她通姦，</span><br /><span className="pl pl-1">地上的商人也因她窮奢極侈的生活而發了財。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v4" data-v="4" data-xref="以賽亞書 52:11; 哥林多後書 6:17; 耶利米書 51:6"> 我聽見天上又有一個聲音說：<br /><span className="pl pl-1">「我的子民啊，離開那城，</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="耶利米書51·45。">b</a></sup><br /><span className="pl pl-1">以免沾染她的罪惡，</span><br /><span className="pl pl-1">受她所受的災禍。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="創世記 18:20–21; 以斯拉記 9:6; 啟示錄 16:19"> <span className="pl pl-1">因為她已經罪惡滔天，</span><br /><span className="pl pl-1">上帝沒有忘記她的不義。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="耶利米書 50:29; 詩篇 137:8; 耶利米書 51:24"> <span className="pl pl-1">她怎樣待人，</span><br /><span className="pl pl-1">也要怎樣待她，</span><br /><span className="pl pl-1">要按她所做的加倍地報應她，</span><br /><span className="pl pl-1">用她調酒的杯加倍地調給她喝。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="以賽亞書 47:7–9; 西番雅書 2:15; 耶利米哀歌 1:1"> <span className="pl pl-1">她過去怎樣自炫自耀、</span><br /><span className="pl pl-1">奢華荒淫，</span><br /><span className="pl pl-1">現在也要讓她怎樣痛苦哀傷。</span><br /><span className="pl pl-1">因為她心裡說，</span><br /><span className="pl pl-1">『我貴為女王，不是寡婦，</span><br /><span className="pl pl-1">絕不會經歷哀傷。』</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="以賽亞書47·7、8。">c</a></sup><br /></span>
<span className="v" id="v8" data-v="8" data-xref="耶利米書 50:34; 耶利米書 50:31; 啟示錄 17:16"> <span className="pl pl-1">所以在一天之內，</span><br /><span className="pl pl-1">她的災禍，就是死亡、</span><br /><span className="pl pl-1">哀傷和饑荒要同時臨到她身上。</span><br /><span className="pl pl-1">她要被火燒盡，</span><br /><span className="pl pl-1">因為審判她的主上帝大有能力。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="啟示錄 19:3; 啟示錄 18:3; 啟示錄 17:2"> 「地上曾與她通姦、一同奢華享樂的君王目睹焚燒她的煙，必為她哭泣哀號。</span>
<span className="v" id="v10" data-v="10" data-xref="啟示錄 18:19; 啟示錄 18:8; 啟示錄 18:15–17"> 他們對她所受的災禍充滿恐懼，就遠遠地站著說，<br /><span className="pl pl-1">「『雄偉堅固的巴比倫城啊，</span><br /><span className="pl pl-1">有禍了！有禍了！</span><br /><span className="pl pl-1">因為審判頃刻間臨到你了。』</span></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="啟示錄 18:3; 啟示錄 18:23; 以西結書 27:27–36"> 「地上的商人也為她痛哭哀傷，因為再也沒有人購買他們的貨物了。</span>
<span className="v" id="v12" data-v="12" data-xref="啟示錄 17:4; 以西結書 27:5–25; 箴言 8:10–11"> 他們的金、銀、寶石、珍珠、細麻布、紫布、絲綢、朱紅色布、各種香木、象牙器具，貴重木材、銅、鐵、大理石製品，</span>
<span className="v" id="v13" data-v="13" data-xref="以西結書 27:13; 阿摩司書 2:6; 彼得後書 2:3"> 以及肉桂、荳蔻、香料、香膏、乳香、酒、油、細麵粉、小麥、牛、羊、馬、車、僕婢和人口都沒有人購買了。</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多前書 10:6; 詩篇 106:14; 路加福音 16:25"> 他們呼喊，『你貪愛的美物已離你而去了，一切珍饈美味和奢華之物都消失殆盡，無影無蹤。』</span>
</div>
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="啟示錄 18:3; 使徒行傳 19:24–27; 以西結書 27:31"> 「靠販賣這些貨物給她而致富的商人對她所受的災禍充滿恐懼，就站在遠處為她哀傷哭號，</span>
<span className="v" id="v16" data-v="16" data-xref="啟示錄 17:4; 路加福音 16:19–31; 啟示錄 18:10–11"> 說，『身穿紫色和朱紅色細麻布衣服，並用黃金、寶石、珍珠為裝飾的大城啊，有禍了！有禍了！</span>
<span className="v" id="v17" data-v="17" data-xref="以西結書 27:27–36; 啟示錄 17:16; 以賽亞書 23:14"> 因為頃刻間你這一切的繁華都化為烏有了。』所有船主、船客、水手及靠海為生的人都遠遠地站著，</span>
<span className="v" id="v18" data-v="18" data-xref="啟示錄 13:4; 以西結書 27:30–32; 啟示錄 18:9–10"> 看見燒她的煙，就高喊，『有哪一座城能與這座大城相比呢？』</span>
<span className="v" id="v19" data-v="19" data-xref="啟示錄 18:10; 約書亞記 7:6; 以西結書 27:30"> 他們又把塵土撒在頭上，哀傷哭泣，高喊，<br /><span className="pl pl-1">「『這大城啊，有禍了！有禍了！</span><br /><span className="pl pl-1">所有經營航運的都因她的奢華而發了財，</span><br /><span className="pl pl-1">可是頃刻間她卻淪為廢墟了！』</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="啟示錄 6:10; 啟示錄 19:1–3; 路加福音 18:7–8"> <span className="pl pl-1">上天啊，</span><br /><span className="pl pl-1">眾聖徒、眾使徒和眾先知啊，</span><br /><span className="pl pl-1">為她的下場歡喜吧！</span><br /><span className="pl pl-1">因為上帝已經對她下了判決，</span><br /><span className="pl pl-1">為你們伸冤了。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v21" data-v="21" data-xref="耶利米書 51:63–64; 以西結書 26:21; 啟示錄 5:2"> 這時，有一位大能天使舉起一塊像大磨石的石頭扔進海裡，說：<br /><span className="pl pl-1">「巴比倫大城也必這樣被用力扔下去，</span><br /><span className="pl pl-1">消失得無影無蹤。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="以西結書 26:13; 耶利米書 25:10; 耶利米書 7:34"> <span className="pl pl-1">在你那裡，</span><br /><span className="pl pl-1">再也聽不見彈琴作樂、</span><br /><span className="pl pl-1">弄笛吹號的聲音了，</span><br /><span className="pl pl-1">再也找不到能工巧匠了，</span><br /><span className="pl pl-1">再也聽不到推磨的聲音了，</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="啟示錄 18:3; 以賽亞書 23:8; 那鴻書 3:4"> <span className="pl pl-1">再也看不到閃耀的燈光了，</span><br /><span className="pl pl-1">再也聽不見新郎新娘的聲音了。</span><br /><span className="pl pl-1">因為你的商人在世上顯赫一時，</span><br /><span className="pl pl-1">萬國都被你的邪術迷惑，</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="啟示錄 17:6; 啟示錄 16:6; 耶利米書 51:49"> <span className="pl pl-1">你的城內流了眾先知、</span><br /><span className="pl pl-1">眾聖徒和地上一切被殺之人的血。」</span></span>
</div>
</div>

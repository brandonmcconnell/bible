## 羔羊與封印的書卷

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西結書 2:9–10; 以賽亞書 29:11; 啟示錄 5:7"> 接著，我看見坐在寶座上的那位右手拿著一卷內外寫著字、用七個印封住的書。</span>
<span className="v" id="v2" data-v="2" data-xref="以賽亞書 29:11–12; 啟示錄 5:5; 啟示錄 10:1"> 我又看見一位大能天使高聲問道：「誰有資格揭開那七個封印，打開書卷？」</span>
<span className="v" id="v3" data-v="3" data-xref="啟示錄 5:13; 以賽亞書 40:13–14; 羅馬書 11:34"> 可是，天上、地上、甚至地底下誰都沒有資格開卷閱讀。</span>
<span className="v" id="v4" data-v="4" data-xref="但以理書 12:8–9; 啟示錄 4:1"> 我見誰都沒有資格開卷閱讀，便放聲大哭。</span>
<span className="v" id="v5" data-v="5" data-xref="以賽亞書 11:1; 耶利米書 23:5–6; 啟示錄 22:16"> 有一位長老對我說：「不要哭！看啊，猶大支派的獅子，大衛的根已經得勝了，祂能揭開那七個封印，打開書卷。」</span>
</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="撒迦利亞書 4:10; 約翰福音 1:29; 啟示錄 5:12"> 我又看到寶座、四個活物和眾長老之間站著一隻好像是被宰殺過的羔羊。祂有七隻角和七隻眼睛，這些是指被派往普天下的上帝的七靈。</span>
<span className="v" id="v7" data-v="7" data-xref="啟示錄 5:1; 啟示錄 4:2–3"> 羔羊走上前去，從坐在寶座上的那位右手中接過書卷。</span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 141:2; 啟示錄 8:3–4; 腓立比書 2:9–11"> 祂拿過書卷後，四個活物和二十四位長老就各拿著豎琴和盛滿了香的金香爐，俯伏在羔羊面前。那些香就是眾聖徒的祈禱。</span>
<span className="v" id="v9" data-v="9" data-xref="彼得前書 1:18–19; 約翰一書 1:7; 馬太福音 26:28"> 他們唱著一首新歌：<br /><span className="pl pl-1">「你配拿書卷並揭開封印，</span><br /><span className="pl pl-1">因你曾被殺，</span><br /><span className="pl pl-1">用你的血從各部落、各語言族群、各民族、各國家，</span><br /><span className="pl pl-1">將人買贖回來歸給上帝。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="啟示錄 1:6; 但以理書 7:27; 啟示錄 20:6"> <span className="pl pl-1">你又使他們成為上帝的國度和祭司，</span><br /><span className="pl pl-1">他們要在地上執掌王權。」</span></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="但以理書 7:10; 希伯來書 12:22; 啟示錄 4:4"> 我又看見寶座、四個活物和眾長老的周圍有千千萬萬的天使，並聽見他們高聲呼喊：</span>
<span className="v" id="v12" data-v="12" data-xref="啟示錄 5:9; 啟示錄 19:1; 啟示錄 4:11"> 「曾被殺的羔羊配得權柄、財富、智慧、能力、尊貴、榮耀和頌讚！」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="腓立比書 2:10; 歷代志上 29:11; 詩篇 148:2–13"> 我又聽到天上、地上、地底下和海洋中一切被造之物同聲說：「願頌讚、尊貴、榮耀和權柄都歸給坐在寶座上的那位和羔羊，直到永永遠遠！」</span>
<span className="v" id="v14" data-v="14" data-xref="啟示錄 19:4; 啟示錄 4:9–11; 啟示錄 5:8"> 四個活物就說：「阿們！」眾長老也俯伏敬拜。</span>
</div>
</div>

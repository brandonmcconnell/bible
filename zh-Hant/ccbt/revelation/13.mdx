## 兩隻怪獸

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="啟示錄 12:3; 啟示錄 17:3; 但以理書 7:23–25"> 我又看見一隻怪獸從海中上來，有七頭十角，每隻角上都戴著一個冠冕，每個頭上都寫著褻瀆上帝的名號。</span>
<span className="v" id="v2" data-v="2" data-xref="但以理書 7:4–7; 彼得前書 5:8; 啟示錄 17:12"> 牠看起來像豹，腳像熊的腳，口像獅子的口。巨龍將自己的能力、王位和大權柄都交給了怪獸。</span>
<span className="v" id="v3" data-v="3" data-xref="啟示錄 17:8; 啟示錄 13:14; 啟示錄 17:17"> 我看見怪獸的一個頭似乎受了致命傷，這傷卻復原了。全世界的人都驚奇地跟從了牠。</span>
<span className="v" id="v4" data-v="4" data-xref="啟示錄 13:2; 啟示錄 18:18; 啟示錄 13:15"> 他們拜巨龍，因為巨龍將自己的權柄給了怪獸。他們又拜怪獸，說：「誰比得上這獸呢？誰能與牠對抗呢？」</span>
<span className="v" id="v5" data-v="5" data-xref="但以理書 7:8; 但以理書 7:25; 但以理書 11:36"> 巨龍又賜給怪獸說狂妄、褻瀆話的口，並給牠權柄可以任意妄為四十二個月。</span>
<span className="v" id="v6" data-v="6" data-xref="馬太福音 12:34; 希伯來書 9:24; 啟示錄 12:12"> 怪獸開口褻瀆上帝、祂的名、祂的居所和一切居住在天上的。</span>
<span className="v" id="v7" data-v="7" data-xref="但以理書 7:21; 啟示錄 11:7; 但以理書 7:25"> 牠又獲准去攻打聖徒，征服他們，並得到權柄制伏各部落、各民族、各語言族群、各國家。</span>
<span className="v" id="v8" data-v="8" data-xref="彼得前書 1:19–20; 以弗所書 1:4; 馬太福音 25:34"> 凡住在地上、自創世以來名字沒有記在被殺羔羊的生命冊上的人，都會拜怪獸。</span>
<span className="v" id="v9" data-v="9" data-xref="啟示錄 2:7; 啟示錄 2:17; 啟示錄 2:11"> <span className="pl pl-1">凡有耳朵的都應當聽。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="耶利米書 15:2; 以賽亞書 33:1; 啟示錄 14:12"> <span className="pl pl-1">該被擄的人必被擄，</span><br /><span className="pl pl-1">該被刀殺的必被刀殺。</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="耶利米書15·2。">a</a></sup><br />因此，聖徒需要堅忍和信心。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="但以理書 7:8; 哥林多後書 11:13–15; 馬太福音 7:15"> 我又看見另一隻怪獸從地裡上來，牠的兩隻角像羔羊的角，說話卻像龍，</span>
<span className="v" id="v12" data-v="12" data-xref="啟示錄 17:10–11; 啟示錄 14:11; 啟示錄 14:9"> 在頭一隻怪獸面前行使頭一隻怪獸的一切權柄。牠使世上的人拜曾受了致命傷但已復原的頭一隻怪獸，</span>
<span className="v" id="v13" data-v="13" data-xref="馬太福音 24:24; 啟示錄 19:20; 帖撒羅尼迦後書 2:9–10"> 又行大奇蹟，當眾叫火從天降到地上。</span>
<span className="v" id="v14" data-v="14" data-xref="啟示錄 12:9; 啟示錄 19:20; 啟示錄 13:8"> 牠獲准在頭一隻怪獸面前行奇蹟，藉此迷惑普世的人，並吩咐他們為受了刀傷卻仍然活著的頭一隻怪獸塑像。</span>
<span className="v" id="v15" data-v="15" data-xref="啟示錄 20:4; 啟示錄 19:20; 但以理書 3:3–6"> 牠又獲准給怪獸的塑像生命氣息，使牠不但能說話，還能使所有不拜那像的人遭害。</span>
<span className="v" id="v16" data-v="16" data-xref="啟示錄 20:4; 啟示錄 19:20; 以西結書 9:4"> 牠又強迫所有的人，不論尊卑、貧富、自由人或奴隸，都在右手或額上接受印記。</span>
<span className="v" id="v17" data-v="17" data-xref="啟示錄 15:2; 啟示錄 13:16; 啟示錄 14:11"> 凡沒有蓋上怪獸印記的，就是沒有怪獸的名字或代號的，都不能買賣。</span>
<span className="v" id="v18" data-v="18" data-xref="啟示錄 15:2; 啟示錄 17:9; 啟示錄 21:17"> 這裡需要智慧：明哲可以計算那怪獸的代號，因為那是一個人的代號，是六百六十六。</span>
</div>

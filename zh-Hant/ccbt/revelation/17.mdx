## 大淫婦的下場

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="啟示錄 19:2; 啟示錄 17:1–17; 耶利米書 51:13"> 拿著七碗的七位天使中有一位前來對我說：「你過來！我要讓你看那坐在眾水之上的大淫婦將要遭受的刑罰。</span>
<span className="v" id="v2" data-v="2" data-xref="啟示錄 14:8; 耶利米書 51:7; 啟示錄 18:3"> 地上的君王與她行淫，地上的居民因喝了她淫亂的酒而酩酊大醉。」</span>
<span className="v" id="v3" data-v="3" data-xref="啟示錄 12:3; 啟示錄 13:1–6; 啟示錄 12:6"> 那時，我被聖靈感動，被天使帶到曠野，在那裡見到一個婦人騎著一隻朱紅色怪獸。怪獸有七頭十角，渾身寫滿褻瀆上帝的名號。</span>
<span className="v" id="v4" data-v="4" data-xref="啟示錄 18:16; 耶利米書 51:7; 啟示錄 19:2"> 那婦人身穿紫色和朱紅色衣服，用黃金、寶石及珍珠裝扮自己。她手中拿著金杯，裡面盛滿了她淫亂可憎的污穢之物。</span>
<span className="v" id="v5" data-v="5" data-xref="啟示錄 14:8; 啟示錄 18:2; 啟示錄 17:7"> 在她額上還寫了一個神秘的名號：「大巴比倫——地上淫婦及可憎事物之母」。</span>
<span className="v" id="v6" data-v="6" data-xref="啟示錄 16:6; 啟示錄 13:15; 啟示錄 2:13"> 我又見她醉了，因她喝了眾聖徒的血，就是為耶穌作見證之人的血。 我看見她的時候，感到非常驚奇。</span>
<span className="v" id="v7" data-v="7" data-xref="啟示錄 17:1–6; 啟示錄 17:8"> 天使對我說：「你為什麼驚奇呢？我要將這婦人和她騎的七頭十角怪獸的奧祕告訴你。</span>
<span className="v" id="v8" data-v="8" data-xref="啟示錄 17:11; 啟示錄 11:7; 啟示錄 3:10"> 你看見的這怪獸以前出現過，現今沒有出現，將來要從無底坑上來，然後走向滅亡。凡住在地上、自創世以來名字沒有記在生命冊上的人，都因見到這只從前出現過、現今沒有出現、將來會再出現的怪獸而感到驚奇。</span>
<span className="v" id="v9" data-v="9" data-xref="啟示錄 13:18; 啟示錄 17:7; 馬太福音 13:11"> 這裡需要智慧才能明白，牠的七個頭是指那婦人坐鎮的七座山，又指七個王。</span>
<span className="v" id="v10" data-v="10"> 其中五個已經衰亡，一個還在，另外一個還未來到，他來後只能短暫存留。</span>
<span className="v" id="v11" data-v="11" data-xref="啟示錄 17:8"> 那從前出現過、現今沒有出現的怪獸是第八個王，他是七個王之一，也要走向滅亡。</span>
<span className="v" id="v12" data-v="12" data-xref="啟示錄 12:3; 啟示錄 13:1; 但以理書 7:24"> 你看見的那十個角是指另外十個還沒有得勢的王，他們將取得王權和那怪獸一同統治短暫的一段時期。</span>
<span className="v" id="v13" data-v="13" data-xref="啟示錄 17:17; 以西結書 38:10; 以賽亞書 10:5–7"> 他們一致同意把自己所有的能力和權柄交給那怪獸。</span>
<span className="v" id="v14" data-v="14" data-xref="羅馬書 8:30; 提摩太前書 6:15; 馬太福音 22:14"> 他們將與羔羊交戰，但羔羊必勝過他們，因為羔羊是萬主之主，萬王之王。那些跟隨羔羊的是被呼召、蒙揀選、忠心耿耿的人。」</span>
<span className="v" id="v15" data-v="15" data-xref="啟示錄 17:1; 耶利米書 51:13; 耶利米書 51:55"> 天使又對我說：「你看見的那淫婦所坐的眾水是指來自各民族、各國家、各語言族群的人。</span>
<span className="v" id="v16" data-v="16" data-xref="啟示錄 18:8; 以西結書 16:37–44; 利未記 21:9"> 怪獸和你看見的十角必憎恨那淫婦，使她赤身露體、景況淒涼。牠們要吃她的肉，最後用火將她燒盡。</span>
<span className="v" id="v17" data-v="17" data-xref="帖撒羅尼迦後書 2:10–12; 箴言 21:1; 啟示錄 10:7"> 眾王同心將政權交給怪獸，直到上帝的話都應驗。因為上帝使他們定意這樣做，好完成祂的旨意。</span>
<span className="v" id="v18" data-v="18" data-xref="啟示錄 16:19; 啟示錄 18:2; 但以理書 7:23"> 你看見的那婦人就是那掌管世上眾王的大城。」</span>

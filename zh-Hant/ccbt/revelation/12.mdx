## 婦人與巨龍

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 21:25; 以弗所書 5:32; 路加福音 21:11"> 天上出現了一個奇異的景象：有一個婦人，身披太陽，腳踏月亮，頭戴有十二顆星的冠冕。</span>
<span className="v" id="v2" data-v="2" data-xref="約翰福音 16:21; 加拉太書 4:19; 啟示錄 12:4"> 她懷孕將產，正因產痛而呼叫。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="啟示錄 17:12; 啟示錄 12:9; 但以理書 7:24"> 這時天上出現了另一個奇異的景象：有一條紅色巨龍出現，牠有七頭十角，每個頭上都戴著冠冕。</span>
<span className="v" id="v4" data-v="4" data-xref="但以理書 8:9–12; 啟示錄 12:9; 約翰福音 8:44"> 牠的尾巴將天上三分之一的星掃落到地上。巨龍站在那正要生產的婦人面前，等著要吃掉她生下來的嬰孩。</span>
<span className="v" id="v5" data-v="5" data-xref="啟示錄 19:15; 啟示錄 2:26–27; 啟示錄 12:2"> 婦人生下一個男嬰，就是將來要用鐵杖治理萬國的。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="詩篇2·9。">a</a></sup>那男嬰被提到了上帝的寶座那裡，</span>
<span className="v" id="v6" data-v="6" data-xref="啟示錄 13:5; 啟示錄 11:2–3; 啟示錄 12:14"> 婦人則逃到曠野，在上帝為她預備的地方被照顧一千二百六十天。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="猶大書 1:9; 但以理書 12:1; 以弗所書 6:12"> 天上起了戰爭，米迦勒和他的天使出戰巨龍，巨龍和牠的天使抵抗。</span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 37:10; 啟示錄 12:11; 猶大書 1:6"> 巨龍落敗，天上再沒有牠們的立足之地，</span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 10:18; 約翰福音 12:31; 啟示錄 20:10"> 牠和牠的天使都一同從天上被摔到地上。巨龍就是那古蛇，又名魔鬼或撒旦，是迷惑天下人的。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="路加福音 22:31; 撒迦利亞書 3:1–2; 啟示錄 11:15"> 我聽見天上有響亮的聲音說：「我們上帝的救贖、權能、國度和祂所立的基督的權柄現在來臨了。因為那晝夜不停地在我們上帝面前控告我們弟兄的，已經被摔到地上了。</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多後書 10:3–5; 約翰福音 16:33; 約翰一書 5:5"> 弟兄們是靠著羔羊的血和自己所見證的道戰勝了牠，他們沒有貪生怕死。</span>
<span className="v" id="v12" data-v="12" data-xref="以賽亞書 49:13; 啟示錄 8:13; 詩篇 96:11–13"> 因此，諸天和其中的居民都要歡欣雀躍！但大地和海洋有禍了，因為魔鬼知道牠的時日不多了，就怒氣沖沖地下到你們那裡。」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="創世記 3:15; 啟示錄 12:3–5; 約翰福音 16:33"> 巨龍見自己被摔到地上，就迫害那先前產下男嬰的婦人。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及記 19:4; 以賽亞書 40:31; 啟示錄 12:6"> 但那婦人得到一對巨鷹的翅膀，使她能飛到曠野，去上帝為她預備的地方避難，在那裡被照顧三年半。</span>
<span className="v" id="v15" data-v="15" data-xref="以賽亞書 8:7; 以賽亞書 59:19; 詩篇 18:4"> 古蛇在婦人身後張口吐出大量的水，如同江河一般，要沖走她，</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀上 17:6; 出埃及記 12:35–36; 列王紀下 8:9"> 大地卻幫助她，張口吞了巨龍口中吐出來的大水。</span>
<span className="v" id="v17" data-v="17" data-xref="啟示錄 14:12; 創世記 3:15; 啟示錄 11:7"> 巨龍大怒，轉而攻擊她的其他兒女，就是那些堅守上帝的命令、為耶穌作見證的人。</span>
<span className="v" id="v18" data-v="18"> 那時巨龍站在海邊的沙地上。</span>
</div>
</div>

</div>

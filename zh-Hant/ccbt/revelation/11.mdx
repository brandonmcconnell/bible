## 兩位見證人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="啟示錄 21:15; 以西結書 42:15–20; 撒迦利亞書 2:1–2"> 有一根像杖一樣的量桿賜給我，並有聲音吩咐我說：「起來，量一量上帝的殿和祭壇，並數點在殿裡敬拜的人。</span>
<span className="v" id="v2" data-v="2" data-xref="啟示錄 12:6; 但以理書 7:25; 路加福音 21:24"> 你不用量聖殿的外院，因為這部分已經給了外族人，他們要踐踏聖城四十二個月。</span>
<span className="v" id="v3" data-v="3" data-xref="啟示錄 12:6; 啟示錄 11:2; 申命記 19:15"> 我要賜權柄給我的兩個見證人，他們將身穿麻衣，傳道一千二百六十天。」</span>
<span className="v" id="v4" data-v="4" data-xref="撒迦利亞書 4:11–14; 撒迦利亞書 4:2–3; 耶利米書 11:16"> 這兩位見證人就是豎立在世界之主面前的那兩棵橄欖樹和兩座燈臺。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="撒迦利亞書4·3、11、14。">a</a></sup></span>
<span className="v" id="v5" data-v="5" data-xref="耶利米書 5:14; 列王紀下 1:10–12; 何西阿書 6:5"> 若有人要傷害他們，他們便從口中噴出火焰，燒滅敵人；若有人企圖加害他們，必定會這樣被殺。</span>
<span className="v" id="v6" data-v="6" data-xref="列王紀上 17:1; 路加福音 4:25; 詩篇 105:26–36"> 他們有權在傳道期間使天關閉無雨，又有權變水為血，並隨時用各種災禍擊打世界。</span>
<span className="v" id="v7" data-v="7" data-xref="啟示錄 13:7; 但以理書 8:23–24; 但以理書 7:25"> 當他們做完見證以後，從無底坑上來的獸要和他們交戰，並戰勝他們，把他們殺掉。</span>
<span className="v" id="v8" data-v="8" data-xref="耶利米書 23:14; 啟示錄 18:10; 啟示錄 18:21"> 他們便陳屍在大城的街上，這大城按寓意名叫所多瑪，又名埃及，是他們的主被釘在十字架上的地方。</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 79:2–3; 啟示錄 17:15; 啟示錄 10:11"> 三天半之久，他們的屍體不得埋葬，各民族、各部落、各語言族群、各國家的人都觀看他們的屍體。</span>
<span className="v" id="v10" data-v="10" data-xref="列王紀上 18:17; 啟示錄 3:10; 使徒行傳 5:33"> 地上萬民都興高采烈，互送禮物，因為這兩位先知曾使地上的人受苦。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 2:7; 羅馬書 8:11; 羅馬書 8:2"> 三天半過後，從上帝而來的生命之氣進入二人裡面，他們便站立起來。看見的人都害怕極了。</span>
<span className="v" id="v12" data-v="12" data-xref="啟示錄 4:1; 列王紀下 2:11; 使徒行傳 1:9"> 接著他們聽見天上有響亮的聲音呼喚他們：「上這裡來！」他們就在敵人的注視下駕雲升上天去。</span>
<span className="v" id="v13" data-v="13" data-xref="啟示錄 14:7; 啟示錄 6:12; 約書亞記 7:19"> 就在那一刻，發生了強烈的地震，那座城的十分之一倒塌了，因地震死亡的共七千人，生還者都在恐懼中將榮耀歸給天上的上帝。</span>
<span className="v" id="v14" data-v="14" data-xref="啟示錄 8:13; 啟示錄 9:12; 啟示錄 15:1"> 第二樣災難過去了，第三樣災難又接踵而來！</span>
</div>
</div>

## 第七位天使吹號

<div className="bt">
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="但以理書 7:14; 啟示錄 12:10; 但以理書 7:27"> 第七位天使吹響了號角，天上有響亮的聲音說：「世上的國度現在已經屬於我們的主和祂所立的基督了。祂要作王，直到永永遠遠。」</span>
<span className="v" id="v16" data-v="16" data-xref="啟示錄 4:4; 啟示錄 4:10; 啟示錄 7:11"> 在上帝面前，坐在自己寶座上的二十四位長老都一同俯伏敬拜上帝，說：</span>
<span className="v" id="v17" data-v="17" data-xref="啟示錄 1:8; 啟示錄 16:5; 啟示錄 4:8–9"> <span className="pl pl-1">「主啊！昔在、今在的全能上帝啊！</span><br /><span className="pl pl-1">我們感謝你，</span><br /><span className="pl pl-1">因你已執掌大權作王了。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="啟示錄 19:5; 啟示錄 20:12; 啟示錄 6:10–11"> <span className="pl pl-1">列國曾充滿憤怒，</span><br /><span className="pl pl-1">現在你發烈怒的時候到了。</span><br /><span className="pl pl-1">時候已到，你要審判死人，</span><br /><span className="pl pl-1">你要賞賜你的奴僕、先知、聖徒</span><br /><span className="pl pl-1">和一切不論尊卑敬畏你名的人，</span><br /><span className="pl pl-1">你要毀滅那些毀壞世界的人。」</span></span>
<span className="v" id="v19" data-v="19" data-xref="啟示錄 16:21; 啟示錄 15:5–8; 以西結書 38:22"> 那時，天上上帝的聖殿敞開了，殿內的約櫃清晰可見，又有閃電、巨響、雷鳴、地震和大冰雹。</span>
</div>

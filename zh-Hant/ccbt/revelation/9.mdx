<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="啟示錄 8:10; 羅馬書 10:7; 啟示錄 9:2"> 第五位天使吹號的時候，我見有一顆星從天上墜落到地上，有無底坑的鑰匙賜給它。</span>
<span className="v" id="v2" data-v="2" data-xref="約珥書 2:10; 創世記 19:28; 約珥書 2:2"> 它打開無底坑時，濃煙從坑裡冒出來，好像大火爐的煙一樣，太陽和天空都變得昏暗了。</span>
<span className="v" id="v3" data-v="3" data-xref="約珥書 1:4; 啟示錄 9:5; 約珥書 2:25"> 有蝗蟲從煙裡飛出來，落到地上，有地上蠍子的能力賜給牠們。</span>
<span className="v" id="v4" data-v="4" data-xref="啟示錄 7:2–4; 以西結書 9:4; 啟示錄 14:1"> 牠們奉命不得毀壞地上的青草、樹木和其他植物，只傷害額上沒有上帝印記的人，</span>
<span className="v" id="v5" data-v="5" data-xref="啟示錄 9:10; 約伯記 2:6; 啟示錄 9:3"> 但不可殺死他們，只折磨他們五個月。他們受的折磨就像被蠍子蟄到一樣。</span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 23:30; 耶利米書 8:3; 啟示錄 6:16"> 那時候，人求死，卻求不到；想死，死卻躲避他們。</span>
<span className="v" id="v7" data-v="7" data-xref="但以理書 7:8; 那鴻書 3:17; 約珥書 2:4–5"> 那些蝗蟲好像預備出征的戰馬一樣，頭上好像戴了金冠，面孔好像人臉，</span>
<span className="v" id="v8" data-v="8" data-xref="約珥書 1:6; 哥林多前書 11:14–15; 彼得前書 3:3"> 毛髮好像女人的頭髮，牙齒好像獅子的牙，</span>
<span className="v" id="v9" data-v="9" data-xref="約珥書 2:5–8; 那鴻書 2:4–5; 約伯記 39:25"> 胸前有甲，如同鐵甲，鼓動翅膀時聲音如同許多戰馬戰車奔赴戰場。</span>
<span className="v" id="v10" data-v="10" data-xref="啟示錄 9:5; 啟示錄 9:3; 啟示錄 9:19"> 牠們像蠍子一樣有帶毒鉤的尾巴，能夠折磨人五個月。</span>
<span className="v" id="v11" data-v="11" data-xref="約伯記 26:6; 啟示錄 9:1–2; 以弗所書 2:2"> 牠們的王是無底坑的天使，希伯來文名叫亞巴頓，希臘文名叫亞玻倫<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="兩個名字的意思都是「毀滅者」。">a</a></sup>。</span>
<span className="v" id="v12" data-v="12" data-xref="啟示錄 11:14; 啟示錄 8:13–2; 啟示錄 9:13–21"> 第一樣災禍過去了，另外兩樣接踵而來。</span>
<span className="v" id="v13" data-v="13" data-xref="啟示錄 8:3–5; 出埃及記 30:2–3; 啟示錄 9:1"> 第六位天使吹號的時候，我聽見從上帝面前的金祭壇的四角傳出一個聲音，</span>
<span className="v" id="v14" data-v="14" data-xref="啟示錄 16:12; 啟示錄 9:15; 撒母耳記下 8:3"> 對剛才吹號的第六位天使說：「釋放那捆綁在幼發拉底大河的四位天使！」</span>
<span className="v" id="v15" data-v="15" data-xref="啟示錄 9:18; 啟示錄 8:7; 啟示錄 8:9"> 那四位天使就被釋放了，他們為了此年、此月、此日、此刻已經預備好了，要殺掉人類的三分之一。</span>
<span className="v" id="v16" data-v="16" data-xref="啟示錄 7:4; 詩篇 68:17; 但以理書 7:10"> 我聽見他們共有二億騎兵。</span>
<span className="v" id="v17" data-v="17" data-xref="啟示錄 9:18; 啟示錄 14:10; 歷代志上 12:8"> 我在異象中看見了馬和騎士。騎士胸甲的顏色像火焰、紫瑪瑙和硫磺。馬的頭像獅子的頭，口中噴出火、煙和硫磺。</span>
<span className="v" id="v18" data-v="18" data-xref="啟示錄 9:17; 啟示錄 9:15"> 馬口中噴出的這三樣災害殺死了世上三分之一的人口。</span>
<span className="v" id="v19" data-v="19" data-xref="以賽亞書 9:15; 啟示錄 9:10; 以弗所書 4:14"> 這些馬的殺傷力不只在口，也在尾巴。牠們的尾巴像蛇，有頭能咬傷人。</span>
<span className="v" id="v20" data-v="20" data-xref="但以理書 5:23; 申命記 31:29; 提摩太前書 4:1"> 其餘沒有被這些災害所殺的人仍怙惡不悛，繼續拜鬼魔和那些用金、銀、銅、石、木所造，不能看、不能聽、不能行走的偶像。</span>
<span className="v" id="v21" data-v="21" data-xref="啟示錄 21:8; 哥林多後書 12:21; 啟示錄 17:5"> 他們也不肯為自己所犯的兇殺、邪術、淫亂和偷盜悔改。</span>

## 新天新地

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以賽亞書 65:17–19; 彼得後書 3:13; 以賽亞書 66:22"> 接著我看見一個新天新地，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="以賽亞書65·17。">a</a></sup>因為以前的天地都消逝了，海洋也不復存在了。</span>
<span className="v" id="v2" data-v="2" data-xref="希伯來書 11:10; 啟示錄 3:12; 啟示錄 21:10"> 我又看見聖城新耶路撒冷從天上的上帝那裡降下，預備好了，像妝飾整齊等候新郎的新娘。</span>
<span className="v" id="v3" data-v="3" data-xref="以西結書 37:27; 哥林多後書 6:16; 約翰福音 14:23"> 我聽見從寶座中傳來響亮的聲音說：「看啊！上帝的居所設立在人間，祂要與人同住。他們要成為祂的子民，上帝要親自與他們同在，作他們的上帝。</span>
<span className="v" id="v4" data-v="4" data-xref="以賽亞書 25:8; 啟示錄 7:17; 哥林多前書 15:26"> 上帝要擦乾他們所有的眼淚，再沒有死亡、憂傷、哭泣和痛苦，因為以前的事都已成過去。」<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="以賽亞書25·8。">b</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="哥林多後書 5:17; 以賽亞書 42:9; 以賽亞書 43:19"> 坐在寶座上的那位說：「看啊！我已經將一切都更新了。你要將這一切記錄下來，因為這些話真實可信。」</span>
<span className="v" id="v6" data-v="6" data-xref="約翰福音 7:37–38; 約翰福音 4:10; 啟示錄 7:17"> 祂又對我說：「一切都成了！我是阿拉法，我是俄梅加；我是開始，我是終結。我要將生命泉的水白白賜給口渴的人。</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多後書 6:18; 希伯來書 8:10; 啟示錄 2:11"> 得勝者必承受這一切福分，我要作他的上帝，他要作我的兒子。</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多前書 6:9–10; 啟示錄 2:11; 以弗所書 5:5–6"> 至於那些膽怯的、不信的、行為可憎的、殺人的、淫亂的、行邪術的、拜偶像的和所有說謊的，他們的結局是被扔進硫磺火湖裡，這就是第二次的死。」</span>
</div>
</div>

## 新耶路撒冷

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="啟示錄 21:2; 啟示錄 19:7; 啟示錄 16:1–17"> 七位天使手裡拿著盛滿最後七災的七個碗，其中有一位來對我說：「你來，我要將新娘，就是羔羊的妻子指給你看。」</span>
<span className="v" id="v10" data-v="10" data-xref="啟示錄 21:2; 以西結書 11:24; 以西結書 40:1–49"> 我被聖靈感動，天使帶著我到一座高大的山上，將從天上的上帝那裡降下的聖城耶路撒冷指給我看。</span>
<span className="v" id="v11" data-v="11" data-xref="啟示錄 4:6; 啟示錄 22:5; 啟示錄 22:1"> 城中充滿上帝的榮光，璀璨如貴重的寶石，晶瑩如碧玉。</span>
<span className="v" id="v12" data-v="12" data-xref="以西結書 48:31–34; 啟示錄 7:4–8; 啟示錄 21:17–21"> 城牆高大，有十二個城門，東、北、南、西每面三個門，每個城門都有一位天使把守，門上寫著以色列十二支派的名字。</span>
<span className="v" id="v14" data-v="14" data-xref="希伯來書 11:10; 以弗所書 2:20; 以賽亞書 54:11"> 城牆共有十二塊基石，基石上有羔羊的十二位使徒的名字。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="撒迦利亞書 2:1; 啟示錄 11:1–2; 以西結書 41:1–5"> 那和我說話的天使拿了一根金量桿要丈量聖城、城牆和城門。</span>
<span className="v" id="v16" data-v="16" data-xref="以西結書 48:35; 以西結書 48:8–20"> 聖城是正方形的，長寬相等。天使用量桿丈量那城，長、寬、高都是兩千二百公里<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="「兩千二百公里」希臘文是「一萬二千司他町」。">c</a></sup>。</span>
<span className="v" id="v17" data-v="17" data-xref="啟示錄 7:4; 申命記 3:11; 啟示錄 13:18"> 他又丈量了城牆，按人的尺寸，也是天使的尺寸來算，是六十五米<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="「六十五米」希臘文是「一百四十四肘」。">d</a></sup>厚。</span>
<span className="v" id="v18" data-v="18" data-xref="啟示錄 21:11; 啟示錄 21:21; 啟示錄 21:19"> 城牆是用碧玉砌成的，城本身是用純金造的，跟玻璃一樣明淨。</span>
<span className="v" id="v19" data-v="19" data-xref="以賽亞書 54:11–12; 出埃及記 28:17–21; 約伯記 28:16–19"> 城牆的基石用各種寶石裝飾：第一塊基石是碧玉，第二塊是藍寶石，第三塊是綠瑪瑙，第四塊是綠寶石，</span>
<span className="v" id="v20" data-v="20" data-xref="啟示錄 4:3"> 第五塊是紅瑪瑙，第六塊是紅寶石，第七塊是橄欖石，第八塊是水蒼玉，第九塊是黃寶石，第十塊是翡翠，第十一塊是紫瑪瑙，第十二塊是紫晶。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="啟示錄 21:18; 啟示錄 17:4; 啟示錄 22:2"> 十二個城門是用十二顆珍珠造的，每一個城門都是一顆珍珠，城中的街道是純金的，好像透明的玻璃一樣。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="約翰福音 4:23; 列王紀上 8:27; 歷代志下 2:6"> 我看見城中沒有聖殿，因為全能的主上帝和羔羊就是聖城的殿。</span>
<span className="v" id="v23" data-v="23" data-xref="以賽亞書 60:19–20; 啟示錄 22:5; 啟示錄 21:11"> 聖城裡不需要太陽和月亮的光照耀，因為有上帝的榮光照耀，羔羊就是聖城的燈。</span>
<span className="v" id="v24" data-v="24" data-xref="啟示錄 21:26; 啟示錄 22:2; 撒迦利亞書 8:22–23"> 萬民要在聖城的光中行走，地上的君王也要將他們的榮耀帶進聖城。</span>
<span className="v" id="v25" data-v="25" data-xref="以賽亞書 60:11; 撒迦利亞書 14:7; 啟示錄 22:5"> 城門整天都開著，那裡沒有黑夜。</span>
<span className="v" id="v26" data-v="26" data-xref="啟示錄 21:24"> 人們將列國的榮耀和尊貴帶進聖城。</span>
<span className="v" id="v27" data-v="27" data-xref="啟示錄 22:14–15; 以賽亞書 52:1; 啟示錄 20:15"> 所有污穢的、做可憎之事的、撒謊的都不得進入聖城。唯有名字記錄在羔羊的生命冊上的人才有資格進去。</span>
</div>
</div>

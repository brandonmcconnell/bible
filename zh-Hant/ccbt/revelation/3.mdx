## 給撒狄教會的信

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="提摩太前書 5:6; 雅各書 2:26; 啟示錄 1:4"> 「你要寫信告訴撒狄教會的天使，有上帝的七靈又有七顆星的主說，『我知道你的行為，你名義上活著，實際上是死的。</span>
<span className="v" id="v2" data-v="2" data-xref="彼得前書 5:8; 提摩太後書 4:1–4; 啟示錄 16:15"> 你要警醒！把所剩無幾、奄奄一息的生命振作起來，因為我發現你的行為在我的上帝面前不純全。</span>
<span className="v" id="v3" data-v="3" data-xref="啟示錄 2:5; 彼得後書 3:10; 帖撒羅尼迦前書 5:2"> 因此，要回想你以前所領受、所聽見的教導，遵守這些教導，並且悔改。你若不警醒，我必在你意想不到的時候，像賊一樣突然臨到。</span>
<span className="v" id="v4" data-v="4" data-xref="啟示錄 3:5; 啟示錄 7:9; 傳道書 9:8"> 不過在撒狄，你還有幾個人未曾玷污自己的衣服，他們要穿白衣與我同行，因為他們配得這樣。</span>
<span className="v" id="v5" data-v="5" data-xref="馬太福音 10:32; 路加福音 12:8; 啟示錄 21:27"> 得勝者必同樣穿上白衣，我絕不會從生命冊上抹去他的名字，我必在我父和眾天使面前承認他的名。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="啟示錄 2:7"> 「『聖靈對各教會所說的話，凡有耳朵的都應當聽。』</span>
</div>
</div>

## 給非拉鐵非教會的信

<div className="bt">
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="以賽亞書 22:22; 馬太福音 16:19; 啟示錄 1:18"> 「你要寫信告訴非拉鐵非教會的天使，那位聖潔、真實、拿著大衛的鑰匙、開了門無人能關、關了門無人能開的主說，</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多前書 16:9; 歌羅西書 4:3; 啟示錄 3:7"> 『我知道你的行為。你力量微小，卻遵守了我的教導，沒有否認我的名。看啊！我在你面前開了一扇無人能關的門。</span>
<span className="v" id="v9" data-v="9" data-xref="以賽亞書 60:14; 啟示錄 2:9; 以賽亞書 49:23"> 看啊！那些撒旦的會眾自稱是猶太人，其實他們不是，而是說謊的，我要使他們在你面前俯伏下拜，並知道你是我所愛的。</span>
<span className="v" id="v10" data-v="10" data-xref="彼得後書 2:9; 啟示錄 14:12; 撒迦利亞書 13:9"> 因為你遵守我有關堅忍的教導，所以當將來的試煉臨到普天下的人時，我必使你免受磨難。</span>
<span className="v" id="v11" data-v="11" data-xref="雅各書 1:12; 啟示錄 22:12; 啟示錄 2:10"> 我很快就要來了！你要持守所擁有的，免得有人奪去你的冠冕。</span>
<span className="v" id="v12" data-v="12" data-xref="啟示錄 22:4; 啟示錄 21:2; 啟示錄 14:1"> 我要使得勝者在我上帝的殿中作棟梁，永不離開。我要將我上帝的名和我上帝聖城的名，就是從天上我上帝那裡降下來的新耶路撒冷和我自己的新名，都寫在他上面。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="啟示錄 2:7"> 「『聖靈對各教會所說的話，凡有耳朵的都應當聽。』</span>
</div>
</div>

## 給老底嘉教會的信

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="歌羅西書 1:15; 啟示錄 1:5; 哥林多後書 1:20"> 「你要寫信告訴老底嘉教會的天使，那位真實<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「真實」希臘文是「阿們」。">a</a></sup>、誠信、無偽的見證人，就是上帝所造萬物的元首說，</span>
<span className="v" id="v15" data-v="15" data-xref="羅馬書 12:11; 馬太福音 6:24; 列王紀上 18:21"> 『我知道你的行為，你不冷也不熱。我情願你或冷或熱！</span>
<span className="v" id="v16" data-v="16" data-xref="啟示錄 2:5; 撒迦利亞書 11:8–9; 耶利米書 14:19"> 你卻像溫水一樣不冷不熱，我必將你從我口中吐出去！</span>
<span className="v" id="v17" data-v="17" data-xref="箴言 13:7; 何西阿書 12:8; 羅馬書 7:24"> 你說，我很富有，已經發了財，什麼都不缺。你卻不知道自己困苦、可憐、貧窮、瞎眼、赤身露體。</span>
<span className="v" id="v18" data-v="18" data-xref="啟示錄 16:15; 彼得前書 1:7; 以賽亞書 55:1"> 我勸你向我買精煉的金子，使你真正富有。你還要向我買白衣穿在身上，好遮蓋你赤身露體的羞辱。你還要向我買眼藥抹眼睛，使你能看見。</span>
<span className="v" id="v19" data-v="19" data-xref="箴言 3:11–12; 哥林多前書 11:32; 希伯來書 12:5–11"> 凡我所愛的，我都會責備、管教。因此，你要熱心起來，也要悔改。</span>
<span className="v" id="v20" data-v="20" data-xref="路加福音 12:36–37; 啟示錄 19:9; 約翰福音 14:21–23"> 看啊！我站在門外敲門，若有誰聞聲開門，我必進去，我與他，他與我，一同坐席。</span>
<span className="v" id="v21" data-v="21" data-xref="提摩太後書 2:12; 馬太福音 19:28; 啟示錄 2:26–27"> 我必讓得勝者與我一同坐在我的寶座上，正如我得勝後與我父一同坐在祂的寶座上一樣。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="啟示錄 2:7; 啟示錄 2:11; 啟示錄 2:17"> 「『聖靈對各教會所說的話，凡有耳朵的都應當聽。』」</span>
</div>
</div>

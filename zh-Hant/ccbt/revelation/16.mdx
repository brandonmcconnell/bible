<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="西番雅書 3:8; 耶利米書 10:25; 啟示錄 15:1"> 我聽見殿中有宏亮的聲音對七位天使說：「去將那盛滿上帝烈怒的七個碗傾倒在地上。」</span>
<span className="v" id="v2" data-v="2" data-xref="啟示錄 8:7; 啟示錄 16:11; 啟示錄 13:15–18"> 第一位天使去將碗倒在了地上，那些有怪獸的印記、敬拜獸像的人身上長出可怕的毒瘡。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 7:17–21; 啟示錄 8:8–9; 啟示錄 11:6"> 第二位天使將碗倒在了海洋裡，海水變得像死人的血，海中的活物都死光了。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及記 7:17–20; 啟示錄 8:10–11; 何西阿書 13:15"> 第三位天使將碗倒在了江河與水泉裡，水就變成了血。</span>
<span className="v" id="v5" data-v="5" data-xref="啟示錄 1:8; 啟示錄 11:17; 啟示錄 1:4"> 我聽見掌管眾水的天使說：<br /><span className="pl pl-1">「昔在今在的聖者啊！</span><br /><span className="pl pl-1">你是公義的，</span><br /><span className="pl pl-1">因為你施行了審判。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="以賽亞書 49:26; 啟示錄 11:18; 啟示錄 6:10–11"> <span className="pl pl-1">他們流了眾聖徒和先知們的血，</span><br /><span className="pl pl-1">所以你使他們喝血，</span><br /><span className="pl pl-1">這正是他們應得的報應。」</span></span>
<span className="v" id="v7" data-v="7" data-xref="啟示錄 19:2; 啟示錄 6:9; 啟示錄 15:3–4"> 我又聽見從祭壇發出的聲音說：<br /><span className="pl pl-1">「是的，全能的主上帝，</span><br /><span className="pl pl-1">你的判決真實公義。」</span></span>
<span className="v" id="v8" data-v="8" data-xref="使徒行傳 2:20; 啟示錄 14:18; 約拿書 4:8"> 第四位天使將碗倒在太陽上，使太陽可以用它的火炙烤世人。</span>
<span className="v" id="v9" data-v="9" data-xref="啟示錄 2:21; 啟示錄 16:21; 啟示錄 11:13"> 世人被高溫炙烤，就褻瀆掌管這些災禍的上帝的名，他們毫無悔意，不肯歸榮耀給上帝。</span>
<span className="v" id="v10" data-v="10" data-xref="啟示錄 9:2; 馬太福音 8:12; 以賽亞書 8:21–22"> 第五位天使將碗倒在怪獸的座位上，牠的國便被黑暗籠罩，牠的國民痛苦不堪，咬自己的舌頭。</span>
<span className="v" id="v11" data-v="11" data-xref="啟示錄 16:9; 啟示錄 16:2; 啟示錄 16:21"> 他們因為痛苦和毒瘡就褻瀆天上的上帝，不肯為自己的所作所為悔改。</span>
<span className="v" id="v12" data-v="12" data-xref="啟示錄 9:14; 耶利米書 51:36; 以賽亞書 44:27"> 第六位天使將碗倒在幼發拉底大河上，河水就乾了，為東方各國的王預備了道路。</span>
<span className="v" id="v13" data-v="13" data-xref="啟示錄 19:20; 帖撒羅尼迦後書 2:9–11; 啟示錄 20:10"> 我又看見三個像青蛙一樣的污鬼分別從巨龍、怪獸和假先知的口裡跳出來。</span>
<span className="v" id="v14" data-v="14" data-xref="啟示錄 17:14; 提摩太前書 4:1; 啟示錄 20:8"> 牠們都是鬼魔的靈，能行奇蹟。牠們到普天下召集各王，預備在全能上帝的大日子爭戰。</span>
<span className="v" id="v15" data-v="15" data-xref="帖撒羅尼迦前書 5:2–3; 馬太福音 24:42–43; 彼得後書 3:10"> 「看啊！我來的時候像賊一樣。那警醒等候，穿好衣裳的人有福了！他們不會赤身行走，在人前蒙羞。」</span>
<span className="v" id="v16" data-v="16" data-xref="撒迦利亞書 12:11; 士師記 5:19; 約珥書 3:9–14"> 三個污鬼把眾王召集到一個希伯來話叫哈米吉多頓的地方。</span>
<span className="v" id="v17" data-v="17" data-xref="約翰福音 19:30; 啟示錄 21:6; 以弗所書 6:12"> 第七位天使將碗倒在空中時，從殿裡的寶座上傳出響亮的聲音說：「成了！」</span>
<span className="v" id="v18" data-v="18" data-xref="但以理書 12:1; 啟示錄 4:5; 啟示錄 11:19"> 隨後雷電交加，伴隨著巨響，還有空前劇烈的大地震。</span>
<span className="v" id="v19" data-v="19" data-xref="啟示錄 18:5; 啟示錄 17:18; 啟示錄 18:21"> 巴比倫大城裂作三段，其他各國的城邑也都倒塌了。上帝並沒有忘記巴比倫大城的罪惡，要把那杯盛滿祂烈怒的酒給她喝。</span>
<span className="v" id="v20" data-v="20" data-xref="啟示錄 6:14; 啟示錄 20:11; 耶利米書 4:23–25"> 海島都沉沒了，山嶺也都不見了，</span>
<span className="v" id="v21" data-v="21" data-xref="啟示錄 11:19; 約書亞記 10:11; 啟示錄 16:9"> 又有四十公斤重的巨型冰雹從天而降，打在世人身上。世人因為可怕的雹災，就褻瀆上帝。</span>

## 大衛營救基伊拉

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="約書亞記 15:44; 彌迦書 6:15; 尼希米記 3:17–18"> 一天，大衛得知非利士人正在攻打基伊拉，搶掠麥場，</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳記上 23:4; 撒母耳記下 5:19; 撒母耳記下 5:23"> 便求問耶和華：「我可以去攻打非利士人嗎？」耶和華答道：「你可以去攻打非利士人，營救基伊拉。」</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米書 12:5; 詩篇 11:1; 撒母耳記上 23:15"> 大衛的部下卻對他說：「我們在猶大這裡尚且膽戰心驚，何況去基伊拉攻打非利士軍隊呢！」</span>
<span className="v" id="v4" data-v="4" data-xref="士師記 7:7; 約書亞記 8:7; 列王紀下 3:18"> 大衛再求問耶和華，耶和華答道：「到基伊拉去吧，我一定把非利士人交在你手裡。」</span>
<span className="v" id="v5" data-v="5"> 於是，大衛和部下到基伊拉去攻打非利士人，大敗敵人，奪取了他們的牲畜，救出基伊拉人。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳記上 22:20; 撒母耳記上 14:3; 撒母耳記上 14:18"> 亞希米勒的兒子祭司亞比亞他到基伊拉投奔大衛時，把以弗得也帶了去。</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳記上 24:4–6; 約伯記 20:5; 撒母耳記上 26:8–9"> 掃羅得知大衛在基伊拉，就說：「這一次是上帝把他交在我手中了，因為他竟然自投網羅，進入有門有閂的城。」</span>
<span className="v" id="v8" data-v="8"> 掃羅召集全軍準備攻打基伊拉，圍困大衛和他的部下。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳記上 30:7; 撒母耳記上 23:6; 民數記 27:21"> 大衛知道了掃羅的計謀，便吩咐祭司亞比亞他把以弗得帶來，</span>
<span className="v" id="v10" data-v="10" data-xref="羅馬書 3:15–16; 撒母耳記上 23:8; 創世記 18:24"> 然後說：「耶和華，以色列的上帝啊，僕人聽說掃羅要來毀滅基伊拉城，因為我在這裡。</span>
<span className="v" id="v11" data-v="11" data-xref="耶利米書 33:3; 詩篇 50:15; 馬太福音 7:7–8"> 基伊拉的人會不會把我交給掃羅呢？掃羅是不是像我聽說的那樣要來這裡呢？耶和華，以色列的上帝啊，求你告訴我。」耶和華說：「掃羅一定會來。」</span>
<span className="v" id="v12" data-v="12" data-xref="撒母耳記上 23:20; 詩篇 31:8; 詩篇 62:1"> 大衛又問耶和華：「基伊拉的人會不會把我和我的部下交給掃羅呢？」耶和華說：「他們一定會。」</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳記上 22:2; 撒母耳記上 25:13; 撒母耳記上 30:9–10"> 於是，大衛率領自己的六百部下離開基伊拉，到處流浪。掃羅得知大衛已經離開基伊拉，就不去了。</span>
<span className="v" id="v14" data-v="14" data-xref="詩篇 54:3–4; 詩篇 32:7; 約書亞記 15:24"> 大衛住在曠野的堡壘或西弗曠野的山區。掃羅天天搜捕大衛，但上帝沒有把大衛交在他的手中。</span>
<span className="v" id="v15" data-v="15"> 大衛在西弗曠野的何利沙得知掃羅要來殺他。</span>
<span className="v" id="v16" data-v="16" data-xref="以賽亞書 35:3–4; 希伯來書 12:12–13; 約伯記 4:3–4"> 掃羅的兒子約拿單去何利沙見大衛，鼓勵大衛堅定地信靠上帝。</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳記上 20:31; 撒母耳記上 24:20; 使徒行傳 28:16"> 他對大衛說：「不要害怕，我父親掃羅害不了你。你將做以色列的王，我將做你的宰相。我父親也明白這一點。」</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳記下 21:7; 撒母耳記上 20:42; 撒母耳記上 18:3"> 二人在耶和華面前立了約。之後，大衛仍留在何利沙，約拿單則回家去了。</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳記上 26:1; 撒母耳記上 26:3; 詩篇 54:1–7"> 西弗人去基比亞見掃羅，說：「大衛就躲在我們那裡，在曠野南面哈基拉山上何利沙的堡壘裡。</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳記上 23:12; 箴言 29:26; 箴言 11:23"> 王啊，你隨時都可以下來，我們一定把他交在王的手裡。」</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳記上 22:8; 以賽亞書 66:5; 彌迦書 3:11"> 掃羅說：「願耶和華賜福給你們！因為你們體恤我。</span>
<span className="v" id="v22" data-v="22" data-xref="約伯記 5:13"> 我聽說他非常狡猾，你們再回去弄清楚他的行蹤及誰在那裡見過他，</span>
<span className="v" id="v23" data-v="23" data-xref="羅馬書 3:15–16; 馬可福音 14:1; 民數記 10:36"> 查明他的藏身之處，回來如實告訴我，然後我會與你們同去。如果他在猶大境內，我要搜遍千家萬戶，找到他。」</span>
<span className="v" id="v24" data-v="24" data-xref="撒母耳記上 25:2; 約書亞記 15:55"> 於是，西弗人先回去了。當時大衛和他的部下在曠野南面的亞拉巴，即瑪雲曠野。</span>
<span className="v" id="v25" data-v="25" data-xref="士師記 15:8; 撒母耳記上 23:28"> 大衛聽說掃羅和手下正在搜尋他，便率領部下前往瑪雲曠野的磐石，住在那裡。掃羅得知後，便去瑪雲曠野追趕大衛。</span>
<span className="v" id="v26" data-v="26" data-xref="詩篇 17:9; 哥林多後書 1:8; 詩篇 140:1–9"> 掃羅在山這邊走，大衛和他的部下在山那邊走，急急忙忙地躲避掃羅。掃羅和他的手下四面包圍過來，眼看就要抓住他們了。</span>
<span className="v" id="v27" data-v="27" data-xref="列王紀下 19:9; 詩篇 116:3; 申命記 32:36"> 這時，掃羅的信使前來稟報，說非利士人前來犯境，請王速回。</span>
<span className="v" id="v28" data-v="28"> 掃羅只好放棄追趕大衛，回師迎戰非利士人。因此，那地方叫「脫險巖」。</span>
<span className="v" id="v29" data-v="29" data-xref="歷代志下 20:2; 約書亞記 15:62; 以西結書 47:10"> 後來，大衛從那裡轉移到隱·基底的堡壘裡。</span>

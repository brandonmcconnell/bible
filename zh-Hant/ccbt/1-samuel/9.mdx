## 掃羅尋驢

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳記上 14:51; 使徒行傳 13:21; 歷代志上 9:36–39"> 有一個便雅憫人名叫基士，很有威望，是亞斐亞的玄孫、比歌拉的曾孫、洗羅的孫子、亞別的兒子。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 6:2; 民數記 13:33; 撒母耳記上 16:7"> 他的兒子掃羅年輕英俊，在以色列人中無人能比，高出其他人一個頭。</span>
<span className="v" id="v3" data-v="3" data-xref="士師記 5:10; 撒母耳記上 10:2; 士師記 10:4"> 一天，基士丟失了幾頭驢，他就對兒子掃羅說：「你帶一個僕人去找驢吧。」</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀下 4:42; 約書亞記 24:33; 約翰福音 3:23"> 他們找遍了以法蓮的山區、沙利沙地區、沙琳地區和便雅憫地區，都找不著。</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳記上 10:2; 撒母耳記上 1:1; 路加福音 12:11"> 最後，他們來到蘇弗，掃羅對僕人說：「我們還是回家去吧，恐怕我父親不再為驢擔心，反而為我們擔心。」</span>
<span className="v" id="v6" data-v="6" data-xref="列王紀上 13:1; 申命記 33:1; 提摩太前書 6:11"> 但僕人答道：「且慢，這城裡有一位上帝的僕人，很受人敬重，他所說的都會應驗。我們去找他吧，也許他會告訴我們該到哪裡去找驢。」</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀上 14:3; 列王紀下 8:8; 列王紀下 4:42"> 掃羅答道：「如果去的話，我們有什麼可以送給他呢？我們袋裡的食物也吃完了，我們還有什麼可以送給上帝的僕人呢？」</span>
<span className="v" id="v8" data-v="8"> 僕人說：「我這裡還有三克銀子，我們可以送給上帝的僕人，請他告訴我們去哪裡找驢。」</span>
<span className="v" id="v9" data-v="9" data-xref="以賽亞書 30:10; 列王紀下 17:13; 阿摩司書 7:12"> 從前在以色列，如果人們要求問上帝，他們會說：「讓我們去找先見吧。」當時「先知」被稱為「先見」。</span>
<span className="v" id="v10" data-v="10" data-xref="列王紀下 5:13–14"> 掃羅說：「好主意，我們去吧。」於是，他們前往上帝僕人住的城。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 24:11; 出埃及記 2:16; 創世記 24:18–20"> 他們走上山坡，正要進城的時候，遇見一些少女出來打水，就問：「先見在這裡嗎？」</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 31:54; 撒母耳記上 16:2; 撒母耳記上 10:5"> 她們答道：「他在這裡，就在你們前面。你們快去吧，他今天剛到城裡來，因為今天人們在邱壇獻祭。</span>
<span className="v" id="v13" data-v="13" data-xref="約翰福音 6:11; 馬太福音 26:26; 路加福音 24:30"> 你們一進城，就會在他上邱壇吃祭物之前遇見他。因為他不來，人們不能吃，他要先為祭物祝謝後，人們才可以吃。你們現在上去吧，一定會遇見他。」</span>
<span className="v" id="v14" data-v="14"> 他們就趕往城內，剛走進城，就看見撒母耳迎面而來，要上邱壇去。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行傳 13:21; 撒母耳記上 15:1; 約伯記 33:16"> 在掃羅來的前一天，耶和華已經啟示撒母耳說：</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳記上 10:1; 詩篇 106:44; 出埃及記 3:7–9"> 「明天這個時候，我會從便雅憫境內差遣一個人到你這裡，你要膏立他做我以色列子民的首領，他會從非利士人手中把我的子民拯救出來，因為我已聽到我子民的呼求，我要施恩給他們。」</span>
<span className="v" id="v17" data-v="17" data-xref="何西阿書 13:11; 撒母耳記上 16:6–12; 尼希米記 13:25"> 撒母耳看見掃羅的時候，耶和華就對他說：「這就是我對你說的那個人，他將統治我的子民。」</span>
<span className="v" id="v18" data-v="18"> 掃羅來到在城門口的撒母耳面前，問道：「請你告訴我先見住在哪裡？」</span>
<span className="v" id="v19" data-v="19" data-xref="哥林多前書 14:25; 約翰福音 4:29"> 撒母耳答道：「我就是先見。你先上邱壇去，今天你要和我一起吃飯。明天早上我會送你上路，並把你想知道的事都告訴你。</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳記上 8:5; 撒母耳記上 12:13; 撒母耳記上 9:3"> 不要再掛念三天前丟失的驢了，已經找到了。以色列人所仰慕的人是誰呢？不是你和你父親全家嗎？」</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳記上 15:17; 士師記 20:46–48; 詩篇 68:27"> 掃羅答道：「我來自以色列最小的便雅憫支派，我的家族在便雅憫支派中最小，你何出此言？」</span>
<span className="v" id="v22" data-v="22" data-xref="創世記 43:32; 路加福音 14:10"> 撒母耳帶著掃羅和他的僕人來到一個大廳，讓他們在請來的三十位客人中坐上座。</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳記上 1:5; 創世記 43:34"> 撒母耳對廚師說：「把我交給你的那份祭肉拿來。」</span>
<span className="v" id="v24" data-v="24" data-xref="以西結書 24:4; 利未記 7:32–33; 出埃及記 29:22"> 廚師就拿來那塊腿肉，擺在掃羅面前。撒母耳說：「這是為你留的，請吃吧。這是我在請客人時特意為你留的。」於是，掃羅和撒母耳一起吃飯。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行傳 10:9; 申命記 22:8; 撒母耳記下 11:2"> 他們從邱壇下來，回到城裡後，撒母耳把掃羅帶到屋頂上談話。</span>
<span className="v" id="v26" data-v="26" data-xref="創世記 44:4; 約書亞記 7:13; 士師記 19:28"> 黎明時分，撒母耳呼喚屋頂上的掃羅：「起來吧，我該送你上路了。」於是掃羅起床後，與撒母耳一起往外走。</span>
<span className="v" id="v27" data-v="27" data-xref="約翰福音 15:14–15; 撒母耳記上 20:38–39; 列王紀下 9:5–6"> 他們來到城邊的時候，撒母耳讓掃羅吩咐僕人先走。僕人離去後，他對掃羅說：「你在這裡留一會兒，我要把上帝的話告訴你。」</span>

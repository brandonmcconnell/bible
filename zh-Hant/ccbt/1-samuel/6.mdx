## 約櫃回歸以色列

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="詩篇 78:61; 撒母耳記上 5:3; 撒母耳記上 5:1"> 耶和華的約櫃在非利士人的地方停留了七個月。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 7:11; 創世記 41:8; 但以理書 5:7"> 非利士人叫來他們的祭司和占卜者，問道：「我們該怎樣處理耶和華的約櫃呢？請告訴我們怎樣把它送回原處？」</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳記上 6:9; 出埃及記 23:15; 申命記 16:16"> 他們答道：「你們若把以色列上帝的約櫃送回去，不可空手送去，一定要向祂獻上賠罪的禮物，這樣你們就可以得到醫治，也可以知道祂為什麼懲罰你們。」</span>
<span className="v" id="v4" data-v="4" data-xref="士師記 3:3; 撒母耳記上 6:17–18; 約書亞記 13:3"> 非利士人問：「我們該送什麼作賠罪的禮物呢？」他們答道：「你們要按非利士首領的數目，送五個金毒瘡和五隻金鼠，因為你們和你們的首領都遭受了同樣的災難。</span>
<span className="v" id="v5" data-v="5" data-xref="約書亞記 7:19; 撒母耳記上 5:6–7; 撒母耳記上 5:11"> 所以，你們要製作金毒瘡和毀壞田地的老鼠的像，尊崇以色列的上帝，也許祂會放過你們、你們的神明及田地。</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及記 8:15; 出埃及記 7:13; 出埃及記 14:17"> 你們為什麼像法老和埃及人那樣心裡頑固呢？當上帝嚴厲地對待他們時，他們豈沒有讓以色列人離開埃及嗎？</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳記下 6:3; 民數記 19:2; 歷代志上 13:7"> 現在，你們快去準備一輛新車，把兩頭還在哺養小牛、從未負過軛的母牛套在車上，然後把小牛帶回牛圈裡。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳記上 6:3–5"> 你們要把耶和華的約櫃放在車上，旁邊放箱子，裡面裝賠罪的金物，然後送這輛車上路。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳記上 6:3; 約書亞記 15:10; 約書亞記 21:16"> 你們要留意觀察，如果車朝以色列邊境的伯·示麥去，這大災難就是耶和華降給我們的。如果不朝那方向走，我們就知道不是祂懲罰我們，是偶然發生的。」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10"> 於是，非利士人一一照做，他們牽來兩頭還在哺養小牛的母牛，把牠們套在車上，把小牛關在圈裡，</span>
<span className="v" id="v11" data-v="11" data-xref="歷代志上 15:13–15; 撒母耳記下 6:3; 歷代志上 13:7"> 然後把耶和華的約櫃和裝金鼠以及金毒瘡的箱子放在車上。</span>
<span className="v" id="v12" data-v="12" data-xref="民數記 20:19"> 母牛邊走邊叫，不偏不離，徑直朝伯·示麥走去。非利士的首領跟著牠們一直來到伯·示麥的邊界。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13"> 當時，伯·示麥人正在山谷裡收割麥子。他們抬頭看見約櫃，非常高興。</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳記下 24:22; 士師記 21:4; 撒母耳記上 11:5"> 車子來到伯·示麥人約書亞的田間，在一塊巨石旁邊停下來。民眾劈開車子，把兩頭母牛獻給耶和華作燔祭。</span>
<span className="v" id="v15" data-v="15" data-xref="約書亞記 3:3"> 利未人抬下耶和華的約櫃和裝著金物的箱子，把它們放在巨石上。那天，伯·示麥人向耶和華獻上了燔祭和其他祭物。</span>
<span className="v" id="v16" data-v="16" data-xref="士師記 3:3; 撒母耳記上 6:4; 約書亞記 13:3"> 那五個非利士首領看見了這一切後，就在當天回以革倫去了。</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳記下 1:20; 耶利米書 25:20; 撒母耳記上 5:10"> 非利士人獻給耶和華的金毒瘡是分別為亞實突、迦薩、亞實基倫、迦特和以革倫賠罪的。</span>
<span className="v" id="v18" data-v="18" data-xref="約書亞記 13:3; 申命記 3:5; 撒母耳記上 6:14–16"> 那五隻金鼠是按著非利士五個首領的堅固城邑和村莊的數目獻上的。那塊安放耶和華約櫃的巨石至今還在伯·示麥人約書亞的田間。</span>
<span className="v" id="v19" data-v="19" data-xref="民數記 4:20; 出埃及記 19:21; 撒母耳記下 6:7"> 那一天，耶和華擊殺了七十個<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「七十個」有古卷作「五萬零七十個」。">a</a></sup>伯·示麥人，因為他們擅自觀看約櫃裡面。民眾為此哀慟不已，</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳記下 6:9; 瑪拉基書 3:2; 啟示錄 6:17"> 伯·示麥人說：「誰能站立在這位聖潔的上帝耶和華面前呢？該把約櫃送到誰那裡呢？」</span>
<span className="v" id="v21" data-v="21" data-xref="歷代志上 13:5–6; 約書亞記 9:17; 約書亞記 18:14"> 後來，他們就派使者到基列·耶琳的居民那裡，說：「非利士人已經把耶和華的約櫃送回來了，你們下來把它接到你們那裡吧。」</span>
</div>

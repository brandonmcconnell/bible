## 非利士人不信任大衛

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳記上 4:1; 約書亞記 19:30; 列王紀上 20:30"> 非利士人把全部軍隊聚集在亞弗，以色列軍則在耶斯列水泉旁紮營。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳記上 28:1–2; 約書亞記 13:3; 撒母耳記上 29:6–7"> 非利士首領統率以百人和千人為單位的士兵向前推進，大衛和他的部下跟著亞吉走在隊伍後面。</span>
<span className="v" id="v3" data-v="3" data-xref="但以理書 6:5; 撒母耳記上 27:7; 約翰福音 19:6"> 非利士人的官長說：「這些希伯來人在這裡做什麼？」亞吉告訴他們說：「這是以色列王掃羅的臣僕大衛，他追隨我有一段日子了，自從他投奔我以來，我沒發現他有什麼過錯。」</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳記上 14:21; 歷代志上 12:19; 路加福音 16:8"> 他們卻生氣地說：「請送這個人回到你安置他的地方，他不可和我們一起去打仗，免得他在戰場上倒戈。他提著我們的腦袋去重投故主豈不是最好的方法嗎？</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳記上 21:11; 撒母耳記上 18:6–7; 箴言 27:14"> 以前婦女們跳舞歌唱『掃羅殺死千千，大衛殺死萬萬』，歌頌的不就是這個大衛嗎？」</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳記下 3:25; 列王紀下 19:27; 撒母耳記上 20:3"> 亞吉便叫大衛過來，對他說：「我憑永活的耶和華起誓，你一向忠心耿耿，自從你投奔我以來，我沒發現你有什麼過錯，我很願意你與我一同作戰，只是眾首領不贊成。</span>
<span className="v" id="v7" data-v="7" data-xref="民數記 22:34"> 你安心地回去吧，免得他們不悅。」</span>
<span className="v" id="v8" data-v="8" data-xref="馬太福音 6:13; 詩篇 34:13–14; 撒母耳記上 28:2"> 大衛說：「我究竟做錯了什麼？自從僕人投奔你以來，你發現僕人有什麼過錯？為什麼不讓我為我主我王殺敵呢？」</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳記下 19:27; 撒母耳記下 14:17; 撒母耳記下 14:20"> 亞吉說：「你在我眼中就像上帝的天使一樣好，只是非利士眾官長反對你與我們一起出戰。</span>
<span className="v" id="v10" data-v="10" data-xref="歷代志上 12:19; 撒母耳記上 30:1–2; 歷代志上 12:22"> 明天一早，你就和從掃羅手下投奔你的人啟程回去吧。」</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳記上 29:1; 撒母耳記下 4:4; 約書亞記 19:18"> 於是，大衛和部下清早起來返回非利士，非利士軍則前往耶斯列。</span>

## 大衛迎戰歌利亞

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="約書亞記 15:35; 歷代志下 28:18; 歷代志上 11:13"> 非利士人在猶大的梭哥招聚軍隊，準備作戰。他們在梭哥和亞西加之間的以弗·大憫紮營。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳記上 21:9; 撒母耳記上 17:19"> 掃羅和以色列人也聚集起來在以拉谷安營，擺好陣勢準備迎戰。</span>
<span className="v" id="v3" data-v="3"> 雙方的軍隊各佔一座山對峙，中間隔著山谷。</span>
<span className="v" id="v4" data-v="4" data-xref="約書亞記 11:22; 撒母耳記下 21:16–22; 歷代志上 20:4–8"> 非利士營中有個名叫歌利亞的巨人出來討戰。他來自迦特，身高三米，</span>
<span className="v" id="v5" data-v="5"> 頭戴銅盔，身穿重達五十七公斤的鎧甲，</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳記上 17:45; 歷代志下 9:15; 列王紀上 10:16"> 腿上有銅護膝，肩背銅戟。</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳記下 21:19; 撒母耳記上 17:41; 歷代志上 11:23"> 戟柄粗如織布機的軸，鐵戟頭重七公斤。有衛士拿著他的盾牌走在前面。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳記上 8:17; 歷代志上 21:3; 撒母耳記上 17:26"> 他站在那裡挑戰以色列人，高喊：「你們為什麼列陣打仗呢？我是非利士人，你們是掃羅的僕人，你們選一個人下來跟我一比高下。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳記上 11:1"> 如果他打得過我，將我殺了，我們就做你們的奴隸。但如果我戰勝他，把他殺了，你們就要做我們的奴隸，服侍我們。</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳記上 17:25–26; 撒母耳記上 17:45; 撒母耳記上 17:36"> 我今天向以色列軍隊罵陣，你們找一個人出來跟我一決高下吧！」</span>
<span className="v" id="v11" data-v="11" data-xref="約書亞記 1:9; 申命記 31:8; 箴言 28:1"> 掃羅和所有以色列人聽了非利士人的這些話，都嚇得驚恐不已。</span>
<span className="v" id="v12" data-v="12" data-xref="撒母耳記上 16:10–11; 創世記 35:19; 撒母耳記上 16:18"> 大衛是以法他人耶西的兒子。掃羅執政期間，耶西已經年紀老邁，住在猶大的伯利恆，有八個兒子。</span>
<span className="v" id="v13" data-v="13" data-xref="歷代志上 2:13; 撒母耳記下 21:21; 撒母耳記上 17:28"> 他的三個兒子已經跟隨掃羅去打仗了，他們是長子以利押、次子亞比拿達和三子沙瑪。</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳記上 16:11; 創世記 25:23"> 大衛年紀最小，他的三個哥哥跟隨掃羅期間，</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳記上 16:11; 撒母耳記上 16:19–23"> 他有時去掃羅的軍營，有時回伯利恆為他父親放羊。</span>
<span className="v" id="v16" data-v="16" data-xref="馬太福音 4:2; 路加福音 4:2"> 這非利士人早晚都出來罵陣，長達四十天。</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳記上 25:18; 撒母耳記下 17:28; 路得記 2:14"> 一天，耶西對大衛說：「你帶上十公斤烤麥和十個餅，趕快到軍營中送給你的哥哥們。</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 37:14; 撒母耳記上 16:20; 撒母耳記下 17:29"> 再帶十塊奶餅送給他們的千夫長，看望一下他們，帶個信兒回來。</span>
<span className="v" id="v19" data-v="19"> 他們跟隨掃羅率領的以色列軍在以拉谷跟非利士人打仗。」</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳記上 26:5; 路加福音 19:43; 以弗所書 6:1–2"> 大衛清早起來把羊交給一個牧人看顧，然後照父親的吩咐帶著食物出發了。他來到軍營的時候，大軍正吶喊著出戰。</span>
<span className="v" id="v21" data-v="21"> 以色列人與非利士人擺好陣勢，兩軍對壘。</span>
<span className="v" id="v22" data-v="22" data-xref="路加福音 10:5–6; 士師記 18:15; 以賽亞書 10:28"> 大衛把帶來的東西交給負責看守的人保管，自己跑到陣中去問候哥哥們。</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳記上 17:8–10"> 他們正在交談的時候，非利士軍中的迦特人歌利亞出來，像往常一樣向以色列軍罵陣，大衛都聽見了。</span>
<span className="v" id="v24" data-v="24" data-xref="撒母耳記上 13:6–7; 利未記 26:36; 以賽亞書 7:2"> 以色列人一看見歌利亞都競相奔逃，極其害怕。</span>
<span className="v" id="v25" data-v="25" data-xref="約書亞記 15:16; 啟示錄 2:7; 啟示錄 3:12"> 以色列人彼此議論說：「看那個人！他是來向以色列軍罵陣的。誰要能殺死他，王必有重賞，還會把女兒嫁給他為妻，並免去他父親家在以色列應繳的賦稅。」</span>
<span className="v" id="v26" data-v="26" data-xref="申命記 5:26; 撒母耳記上 11:2; 撒母耳記上 14:6"> 大衛問站在旁邊的人：「如果有人殺了這非利士人，洗掉以色列人的羞辱，他會得到什麼呢？這個未受割禮的非利士人是誰？竟敢向永活上帝的軍隊罵陣！」</span>
<span className="v" id="v27" data-v="27" data-xref="撒母耳記上 17:25"> 他們就把剛才的話一一告訴大衛。</span>
<span className="v" id="v28" data-v="28" data-xref="馬太福音 10:36; 創世記 37:11; 箴言 18:19"> 大衛的長兄以利押聽見他跟人說話，就憤怒地對他說：「你來這裡做什麼？你把曠野的那幾隻羊交給誰了？我知道你驕傲自大，心懷惡意，你來只是想看打仗。」</span>
<span className="v" id="v29" data-v="29" data-xref="彼得前書 3:9; 哥林多前書 2:15; 箴言 15:1"> 大衛說：「我做錯了什麼？我問一下都不行嗎？」</span>
<span className="v" id="v30" data-v="30" data-xref="撒母耳記上 17:26–27"> 他又去問其他人同樣的問題，得到了同樣的答覆。</span>
<span className="v" id="v31" data-v="31" data-xref="箴言 22:29"> 有人聽見了大衛的話，就去告訴掃羅，掃羅便派人來召大衛。</span>
<span className="v" id="v32" data-v="32" data-xref="撒母耳記上 16:18; 申命記 20:1–3; 詩篇 3:6"> 大衛對掃羅說：「大家不要因這個非利士人而喪膽，讓僕人去戰他。」</span>
<span className="v" id="v33" data-v="33" data-xref="民數記 13:31; 申命記 9:2; 啟示錄 13:4"> 掃羅說：「你不能去，你年紀還小，他卻是一個久經沙場的戰士。」</span>
<span className="v" id="v34" data-v="34"> 大衛說：「我一直替父親放羊，有時候獅子或熊會從羊群中叼走羊，</span>
<span className="v" id="v35" data-v="35" data-xref="阿摩司書 3:12; 提摩太後書 4:17–18; 但以理書 6:22"> 我會去追打牠，把羊從牠口中救出來。如果牠起來攻擊我，我就揪著牠的鬍子把牠打死。</span>
<span className="v" id="v36" data-v="36" data-xref="撒母耳記上 17:10; 使徒行傳 5:38–39; 羅馬書 2:28–29"> 我曾打死過獅子和熊。這未受割禮的非利士人竟敢向永活上帝的軍隊罵陣，他的下場也必像獅子和熊一樣。</span>
<span className="v" id="v37" data-v="37" data-xref="提摩太後書 4:17–18; 詩篇 138:7–8; 哥林多後書 1:9–10"> 耶和華曾經從獅子和熊的利爪下拯救我，祂也必從這非利士人手中拯救我。」掃羅對大衛說：「去吧，願耶和華與你同在。」</span>
<span className="v" id="v38" data-v="38"> 掃羅把自己的戰袍給大衛穿上，又給他戴上自己的頭盔，穿上自己的鎧甲。</span>
<span className="v" id="v39" data-v="39" data-xref="撒迦利亞書 4:6; 哥林多後書 10:4–5; 何西阿書 1:7"> 大衛把刀挎在戰袍上，試著走了幾步，卻不習慣這種裝束，就對掃羅說：「我穿著這些無法走路，因為我不習慣。」他便摘下頭盔，卸下鎧甲，</span>
<span className="v" id="v40" data-v="40" data-xref="哥林多前書 1:27–29; 馬太福音 10:10; 士師記 15:15–16"> 然後拿著杖，在溪裡撿了五塊光滑的石頭放進牧人用的袋子，拿著投石器向歌利亞走去。</span>
<span className="v" id="v41" data-v="41"> 歌利亞也迎著大衛走來，衛士拿著他的盾牌走在前面。</span>
<span className="v" id="v42" data-v="42" data-xref="撒母耳記上 16:12; 撒母耳記上 17:33; 詩篇 123:3–4"> 歌利亞見大衛是個面色紅潤、相貌英俊的少年，就藐視他。</span>
<span className="v" id="v43" data-v="43" data-xref="撒母耳記下 9:8; 撒母耳記下 3:8; 撒母耳記上 24:14"> 他對大衛說：「你拿著棍子來戰我，難道我是一條狗嗎？」他就憑自己的神明咒詛大衛，</span>
<span className="v" id="v44" data-v="44" data-xref="以西結書 28:9–10; 箴言 18:12; 列王紀上 20:10–11"> 又說：「你過來，我要把你的肉丟給天上的飛禽和地上的走獸。」</span>
<span className="v" id="v45" data-v="45" data-xref="哥林多後書 10:4; 歷代志下 32:8; 哥林多後書 3:5"> 大衛答道：「你是靠刀槍劍戟來攻擊我，我是靠萬軍之耶和華的名，就是你所蔑視的以色列軍隊的上帝來迎戰你。</span>
<span className="v" id="v46" data-v="46" data-xref="以賽亞書 52:10; 約書亞記 4:24; 列王紀下 19:19"> 今天，耶和華必把你交在我手中，我必殺死你，砍掉你的頭，用非利士軍兵的屍體餵飛禽走獸，使普天下都知道以色列有上帝。</span>
<span className="v" id="v47" data-v="47" data-xref="詩篇 44:6–7; 撒迦利亞書 4:6; 何西阿書 1:7"> 這裡所有的人都必知道耶和華拯救人不靠刀槍，因為祂掌管戰爭的勝負。祂必把你們交在我們手中。」</span>
<span className="v" id="v48" data-v="48" data-xref="箴言 28:1; 詩篇 27:1"> 歌利亞迎面走來的時候，大衛就飛快地跑上去應戰，</span>
<span className="v" id="v49" data-v="49" data-xref="哥林多前書 1:27–28; 列王紀下 9:24; 列王紀上 22:34"> 他從袋裡拿出一塊石子用投石器猛力拋去，石子擊中歌利亞的額頭，嵌了進去，他迎面栽倒在地。</span>
<span className="v" id="v50" data-v="50" data-xref="士師記 15:15; 撒母耳記上 17:39; 撒母耳記上 23:21"> 大衛就這樣不用刀劍，只用投石器和一塊石子戰勝了那個非利士人，殺死了他。</span>
<span className="v" id="v51" data-v="51" data-xref="希伯來書 11:34; 撒母耳記上 21:9; 撒母耳記下 23:21"> 大衛跑到那非利士人身邊，從他刀鞘裡拔出刀殺了他，並割下他的頭顱。非利士人看見自己的英雄死了，紛紛逃跑。</span>
<span className="v" id="v52" data-v="52" data-xref="約書亞記 15:11; 約書亞記 15:33–36; 約書亞記 15:45–46"> 以色列人和猶大人乘勢吶喊，追殺非利士人，直追到迦特和以革倫的城門。通往迦特和以革倫的沙拉音大道上到處是非利士人的屍體。</span>
<span className="v" id="v53" data-v="53" data-xref="耶利米書 4:20; 列王紀下 7:7–16; 耶利米書 30:16"> 以色列軍隊追殺非利士人回來，又擄掠了他們的營地。</span>
<span className="v" id="v54" data-v="54" data-xref="出埃及記 16:33; 約書亞記 4:7–8; 撒母耳記上 21:9"> 大衛把那非利士人的頭顱帶到耶路撒冷，把那人的兵器存放在自己的帳篷中。</span>
<span className="v" id="v55" data-v="55" data-xref="撒母耳記上 16:21–22; 撒母耳記上 17:58"> 掃羅看見大衛出去迎戰歌利亞，就問押尼珥元帥：「押尼珥啊，那少年是誰的兒子？」押尼珥答道：「王啊，我向你發誓，我真的不知道。」</span>
<span className="v" id="v56" data-v="56"> 掃羅王說：「你去查查他是誰的兒子。」</span>
<span className="v" id="v57" data-v="57" data-xref="撒母耳記上 17:54"> 大衛殺了歌利亞回來，押尼珥就把他帶到掃羅那裡，他手上還拿著那非利士人的頭顱。</span>
<span className="v" id="v58" data-v="58" data-xref="撒母耳記上 17:12; 撒母耳記上 16:18–19"> 掃羅問他：「年輕人，你是誰的兒子？」大衛答道：「我是你僕人伯利恆人耶西的兒子。」</span>

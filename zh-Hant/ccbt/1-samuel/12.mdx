## 撒母耳的臨別警戒

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳記上 10:24; 撒母耳記上 11:14–15; 撒母耳記上 10:1"> 撒母耳對以色列人說：「看啊，我已照你們的要求為你們立了一個王。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳記上 8:5; 撒母耳記上 8:1; 撒母耳記上 8:20"> 你們已經有君王了。我自幼帶領你們，現在已年老髮白，我的兒子也都在你們這裡。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行傳 20:33; 民數記 16:15; 彼得前書 5:2"> 如今我站在這裡，你們只管在耶和華和祂膏立的王面前為我作證，我奪過誰的牛？搶過誰的驢？欺騙過誰？壓迫過誰？收過誰的賄賂而徇私枉法？如果有的話，我一定償還。」</span>
<span className="v" id="v4" data-v="4" data-xref="但以理書 6:4; 詩篇 37:5–6; 約翰三書 1:12"> 他們答道：「你沒有欺騙、壓迫過我們，也沒有拿過任何人的東西。」</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 22:4; 使徒行傳 24:20; 使徒行傳 23:9"> 撒母耳對他們說：「耶和華和祂所膏立的王今天為我作證，我沒有拿過你們任何人的東西。」他們說：「是的，耶和華為證。」</span>
<span className="v" id="v6" data-v="6" data-xref="彌迦書 6:4; 出埃及記 6:26; 詩篇 99:6"> 撒母耳繼續說：「是耶和華派摩西和亞倫帶領你們的祖先離開埃及。</span>
<span className="v" id="v7" data-v="7" data-xref="以賽亞書 1:18; 彌迦書 6:1–5; 使徒行傳 17:3"> 現在，你們都要站在耶和華面前，讓我來提醒你們有關耶和華為你們和你們祖先所行的一切公義之事。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及記 4:14–16; 出埃及記 2:23–24; 詩篇 78:54–55"> 從前，雅各曾遷到埃及，你們的祖先受到埃及人的壓迫，向耶和華呼求，耶和華就差遣摩西和亞倫帶他們出埃及，到這裡居住。</span>
<span className="v" id="v9" data-v="9" data-xref="士師記 13:1; 士師記 10:7; 士師記 3:12"> 他們卻忘記了他們的上帝耶和華，於是耶和華讓他們落入夏瑣的將軍西西拉、非利士人和摩押王的手中，這些人便攻擊他們。</span>
<span className="v" id="v10" data-v="10" data-xref="士師記 10:10; 士師記 2:13; 士師記 3:7"> 他們就向耶和華呼求，『耶和華啊，我們犯了罪，我們背棄了你去供奉巴力和亞斯她錄，現在求你從仇敵手中救我們，我們必事奉你。』</span>
<span className="v" id="v11" data-v="11" data-xref="士師記 6:32; 士師記 4:6; 士師記 8:35"> 耶和華就派耶路·巴力、比但、耶弗他和撒母耳<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「耶路·巴力、比但、耶弗他和撒母耳」有古卷作「基甸、巴拉、耶弗他和參孫」。">a</a></sup>從周圍的敵人手中救你們，使你們安然居住。</span>
<span className="v" id="v12" data-v="12" data-xref="士師記 8:23; 撒母耳記上 8:5–7; 創世記 17:7"> 可是你們看到亞捫王拿轄來攻擊你們，就對我說，『不行，我們要有一個王來統治我們。』其實你們的上帝耶和華就是你們的王。</span>
<span className="v" id="v13" data-v="13" data-xref="何西阿書 13:11; 撒母耳記上 10:24; 撒母耳記上 8:5"> 現在，你們所求所選的王在這裡，耶和華為你們立了一位王。</span>
<span className="v" id="v14" data-v="14" data-xref="約書亞記 24:14; 申命記 28:1–14; 詩篇 81:12–15"> 如果你們敬畏耶和華，事奉祂，聽從祂的吩咐，不違背祂的命令，你們和統治你們的王都願意跟從祂，一切都會順利。</span>
<span className="v" id="v15" data-v="15" data-xref="約書亞記 24:20; 以賽亞書 1:20; 以賽亞書 3:11"> 如果你們不聽從耶和華的話，違背祂的命令，祂就會像從前懲罰你們的祖先一樣出手懲罰你們。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 14:13; 出埃及記 14:31; 撒母耳記上 12:7"> 現在你們站著留心看，耶和華就要在你們面前行一件大事。</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳記上 8:7; 箴言 26:1; 撒母耳記上 7:9–10"> 你們都知道收割麥子的時候不會下雨。現在，我要向耶和華禱告，求祂打雷降雨，好讓你們知道，你們要求立王在耶和華眼中是多麼大的罪。」</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及記 14:31; 以斯拉記 10:9; 詩篇 106:12–13"> 於是，撒母耳向耶和華呼求，耶和華便在當天打雷降雨，民眾非常害怕耶和華和撒母耳。</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及記 9:28; 約翰一書 5:16; 撒母耳記上 12:23"> 他們求撒母耳，說：「求你為僕人們向你的上帝耶和華祈禱，免得我們死亡！因為我們要求立王是罪上加罪。」</span>
<span className="v" id="v20" data-v="20" data-xref="申命記 11:16; 約書亞記 23:6; 彼得前書 3:16"> 撒母耳說：「不要害怕，你們雖然做了這惡事，但不可離開耶和華，要全心全意地事奉祂。</span>
<span className="v" id="v21" data-v="21" data-xref="哈巴谷書 2:18; 耶利米書 10:15; 耶利米書 16:19"> 不要去追求其他虛無的假神，它們對你們毫無益處，也不能拯救你們。</span>
<span className="v" id="v22" data-v="22" data-xref="申命記 7:7–8; 申命記 14:2; 詩篇 106:8"> 耶和華不會丟棄祂的子民，使自己的大名受損，祂樂意使你們做祂的子民。</span>
<span className="v" id="v23" data-v="23" data-xref="歌羅西書 1:9; 羅馬書 1:9; 提摩太後書 1:3"> 至於我，我會不斷地為你們祈禱，免得我得罪耶和華。我會教導你們行善道、走正路。</span>
<span className="v" id="v24" data-v="24" data-xref="申命記 10:21; 箴言 1:7; 以賽亞書 5:12"> 你們要單單敬畏耶和華，全心全意地事奉祂，想想祂為你們做了何等偉大的事。</span>
<span className="v" id="v25" data-v="25" data-xref="約書亞記 24:20; 何西阿書 10:3; 撒母耳記上 31:1–5"> 可是，如果你們仍然繼續行惡，你們和你們的王都必滅亡。」</span>

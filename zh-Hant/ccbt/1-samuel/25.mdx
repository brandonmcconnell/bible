## 大衛與亞比該

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳記上 28:3; 民數記 20:29; 申命記 34:8"> 撒母耳死了，以色列人都聚在一起哀悼他，把他安葬在拉瑪他自己的墳地裡。之後，大衛到了巴蘭的曠野。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 38:13; 撒母耳記上 23:24; 約書亞記 15:55"> 瑪雲有個富翁擁有三千隻綿羊和一千隻山羊，他的產業在迦密。當時他正在迦密剪羊毛。</span>
<span className="v" id="v3" data-v="3" data-xref="箴言 14:1; 箴言 31:10; 以賽亞書 32:5–7"> 他名叫拿八，是迦勒族人，妻子名叫亞比該，既聰慧又漂亮。拿八粗暴兇惡。</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 38:13; 撒母耳記下 13:23"> 大衛在曠野得知拿八正在剪羊毛，</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 43:23; 撒母耳記上 17:22"> 就派十個部下到迦密去見拿八，吩咐他們以他的名義向拿八問安，</span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 10:5; 歷代志上 12:18; 詩篇 122:7"> 對拿八說：「願你和你全家平安，願你一切順利！</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳記上 25:21; 撒母耳記上 25:15–16; 撒母耳記上 22:2"> 我聽說你正在剪羊毛。你的牧人與我們在迦密的時候，我們沒有欺負過他們，他們沒有丟過任何東西。</span>
<span className="v" id="v8" data-v="8" data-xref="以斯帖記 9:19; 尼希米記 8:10–12; 路加福音 14:12–14"> 你問問你的僕人就知道了。請你恩待我的部下，因為今天是好日子，求你隨手賞一點東西給僕人們和晚輩我。」</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀下 2:15; 歷代志下 14:7; 創世記 8:4"> 大衛的部下就去把大衛的話告訴拿八，等候他的答覆。</span>
<span className="v" id="v10" data-v="10" data-xref="士師記 9:28; 以賽亞書 32:7; 撒母耳記上 22:7–8"> 拿八說：「大衛是誰？耶西的兒子是誰？這些日子有很多僕人逃離主人，</span>
<span className="v" id="v11" data-v="11" data-xref="士師記 8:6; 加拉太書 6:10; 哥林多後書 6:9"> 我怎能把餅、水和為剪羊毛者預備的肉分給一群來歷不明的人呢？」</span>
<span className="v" id="v12" data-v="12" data-xref="以賽亞書 36:21–22; 撒母耳記下 24:13; 希伯來書 13:17"> 大衛的部下回去把拿八的話稟告大衛。</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳記上 23:13; 箴言 25:8; 撒母耳記上 24:5–6"> 大衛聽了，就吩咐眾人備刀，他自己也帶了刀去拿八那裡。大衛帶了四百人去，留下二百人看守輜重。</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳記上 13:10; 馬可福音 15:29"> 拿八的一個僕人告訴拿八的妻子亞比該說：「大衛從曠野派人來向我們主人問安，主人卻辱罵他們。</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳記上 25:7; 撒母耳記上 25:21; 腓立比書 2:15"> 那些人對我們很好，從來不欺負我們。我們跟他們一起在田野的時候，從來沒有丟過任何東西。</span>
<span className="v" id="v16" data-v="16" data-xref="約伯記 1:10; 出埃及記 14:22; 撒迦利亞書 2:5"> 我們在他們附近牧羊的時候，他們晝夜不斷地保護我們。</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳記上 20:7; 申命記 13:13; 撒母耳記上 20:9"> 所以，請你趕快想個法子，不然主人和他全家恐怕都會大難臨頭。主人是個兇暴的人，沒有人敢跟他說話。」</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳記下 16:1; 馬太福音 5:25; 箴言 6:4–5"> 亞比該連忙用驢馱上二百塊餅、兩皮袋酒、五隻宰好了的羊、三十七升烤麥、一百塊葡萄餅和二百塊無花果餅，</span>
<span className="v" id="v19" data-v="19" data-xref="創世記 32:20; 創世記 32:16; 箴言 31:11–12"> 又吩咐僕人說：「你們先去吧！我隨後就來。」她沒有把這事告訴丈夫拿八。</span>
<span className="v" id="v20" data-v="20" data-xref="列王紀下 4:24"> 她騎著驢下山的時候，就看見大衛和他的部下迎面而來。</span>
<span className="v" id="v21" data-v="21" data-xref="箴言 17:13; 以弗所書 4:31; 羅馬書 12:21"> 大衛曾說：「我在曠野保護這人的羊群，使牠們不致丟失，真是枉費功夫。他竟以怨報德。</span>
<span className="v" id="v22" data-v="22" data-xref="列王紀上 14:10; 撒母耳記上 20:13; 撒母耳記上 3:17"> 如果我讓他家裡一個男子活到明早，願上帝重重地懲罰我！」</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳記上 20:41; 士師記 1:14; 約書亞記 15:18"> 亞比該看見大衛，連忙下驢俯伏下拜。</span>
<span className="v" id="v24" data-v="24" data-xref="以斯帖記 8:3; 撒母耳記上 25:28; 撒母耳記下 14:9"> 她俯伏在大衛腳前說：「我主啊，我願意承擔一切罪過，請聽婢女說。</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳記上 25:17; 瑪拉基書 2:2; 撒母耳記下 13:33"> 請不要理會拿八那個惡徒，他人如其名<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「拿八」意思是「愚蠢」。">a</a></sup>，是個名符其實的蠢人。當時婢女沒有見到你派來的使者。</span>
<span className="v" id="v26" data-v="26" data-xref="撒母耳記下 18:32; 羅馬書 12:19–20; 創世記 20:6"> 我主啊，既然耶和華阻止你親手殺人報仇，我就憑永活的耶和華和你的性命起誓，願你的仇敵和傷害你的人都像拿八一樣沒有好下場。</span>
<span className="v" id="v27" data-v="27" data-xref="創世記 33:11; 撒母耳記上 30:26; 列王紀下 5:15"> 現在，請把婢女帶來的禮物分給你的部下吧。</span>
<span className="v" id="v28" data-v="28" data-xref="撒母耳記上 18:17; 撒母耳記下 7:11; 撒母耳記上 24:11"> 請饒恕婢女的罪過，耶和華必使你的子孫世代做王，因為你是在為耶和華而戰，願你一生沒有過錯。</span>
<span className="v" id="v29" data-v="29" data-xref="約翰福音 17:21; 馬太福音 10:29–30; 瑪拉基書 3:17"> 你就是被人追殺，也會在你的上帝耶和華的保護下安然無恙。你敵人的性命卻要像石頭一樣被耶和華用投石器拋出去。</span>
<span className="v" id="v30" data-v="30" data-xref="撒母耳記上 13:14; 詩篇 89:20; 撒母耳記上 23:17"> 如果你現在沒有殺人報仇，傷害無辜，到了耶和華照應許賜福給你、立你做以色列王的時候，你就不會心裡不安了。我主啊，耶和華賜福給你的時候，求你不要忘了婢女。」</span>
<span className="v" id="v32" data-v="32" data-xref="路加福音 1:68; 出埃及記 18:10; 詩篇 72:18"> 大衛對亞比該說：「以色列的上帝耶和華當受稱頌！祂今天派你來見我。</span>
<span className="v" id="v33" data-v="33" data-xref="撒母耳記上 25:26; 箴言 28:23; 箴言 9:9"> 你很有見識，你今天攔阻我親手殺人復仇，值得稱讚。</span>
<span className="v" id="v34" data-v="34" data-xref="撒母耳記上 11:11; 撒母耳記上 25:26; 約書亞記 10:6"> 我憑阻止我殺你的以色列的上帝——永活的耶和華起誓，若不是你趕來迎接我，拿八家中不會有一個男子活到明天早上。」</span>
<span className="v" id="v35" data-v="35" data-xref="創世記 19:21; 撒母耳記上 20:42; 列王紀下 5:19"> 大衛接受了亞比該的禮物，對她說：「安心回家吧，我答應你的請求。」</span>
<span className="v" id="v36" data-v="36" data-xref="撒母耳記上 25:19; 撒母耳記下 13:23; 撒母耳記下 13:28"> 她回到家時，拿八正在大擺宴席，排場如御宴。她見拿八心情愉快，喝得酩酊大醉，就什麼也沒告訴他，等第二天早上再說。</span>
<span className="v" id="v37" data-v="37" data-xref="申命記 28:28; 撒母耳記上 25:34; 撒母耳記上 25:22"> 次日清晨，拿八酒醒以後，他妻子把發生的一切告訴他，他嚇得昏死過去，身體僵硬如石。</span>
<span className="v" id="v38" data-v="38" data-xref="撒母耳記上 26:10; 列王紀下 15:5; 撒母耳記上 6:9"> 過了十天，耶和華擊打拿八，他就死了。</span>
<span className="v" id="v39" data-v="39" data-xref="撒母耳記上 25:26; 撒母耳記上 25:34; 箴言 22:23"> 大衛聽見拿八的死訊，就說：「讚美耶和華！拿八羞辱我，祂為我伸了冤，又阻止僕人行惡。祂使拿八得到了報應。」後來，大衛差遣使者去向亞比該求婚。</span>
<span className="v" id="v40" data-v="40" data-xref="創世記 24:51; 創世記 24:37–38"> 他的使者就啟程到迦密去向亞比該傳達大衛的心意。</span>
<span className="v" id="v41" data-v="41" data-xref="提摩太前書 5:10; 約翰福音 13:3–5; 路得記 2:10"> 亞比該聽了，立刻俯伏在地上說：「婢女願意效勞，為我主的僕人洗腳。」</span>
<span className="v" id="v42" data-v="42" data-xref="創世記 24:61–67; 詩篇 45:10–11"> 她連忙騎上驢，帶了五個侍女，跟隨大衛的使者前去，做了大衛的妻子。</span>
<span className="v" id="v43" data-v="43" data-xref="撒母耳記上 30:5; 約書亞記 15:56; 撒母耳記上 27:3"> 大衛已經娶了耶斯列人亞希暖，她們二人就同做大衛的妻子。</span>
<span className="v" id="v44" data-v="44" data-xref="撒母耳記下 3:14; 撒母耳記上 18:27; 撒母耳記上 18:20"> 掃羅已經把自己的女兒、大衛的妻子米甲嫁給了迦琳人拉億的兒子帕提。</span>

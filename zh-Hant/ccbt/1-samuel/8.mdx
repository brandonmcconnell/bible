## 以色列人要求立王

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命記 16:18–19; 提摩太前書 5:21; 尼希米記 7:2"> 撒母耳在年老的時候立了他的兒子做以色列人的士師。</span>
<span className="v" id="v2" data-v="2" data-xref="歷代志上 6:38; 創世記 22:19; 歷代志上 6:28"> 他的長子是約珥，次子是亞比亞，他們在別示巴做士師。</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 16:19; 詩篇 15:5; 提摩太前書 6:10"> 然而，他們沒有效法自己的父親，反而愛慕不義之財，貪贓枉法。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="撒母耳記上 7:17; 撒母耳記下 5:3; 出埃及記 3:16"> 於是，以色列的長老一起到拉瑪去見撒母耳，</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 17:14–15; 何西阿書 13:10–11; 撒母耳記上 8:6–8"> 說：「你年紀大了，你的兒子不效法你。現在求你為我們立一個王治理我們，像其他國家一樣。」</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳記上 15:11; 雅各書 1:5; 撒母耳記上 12:17"> 撒母耳聽到他們要求立一個王治理他們，心中不悅，就向耶和華禱告。</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 10:16; 撒母耳記上 10:19; 出埃及記 16:8"> 耶和華對撒母耳說：「你照他們所說的去做吧，因為他們不是拒絕你，而是拒絕我做他們的王。</span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 106:34–40; 出埃及記 32:1; 士師記 13:1"> 自從我帶他們出埃及那天一直到今日，他們常常背棄我，去供奉其他神明。現在，他們也這樣對待你。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳記上 10:25; 撒母耳記上 8:11–18; 以西結書 46:18"> 你就照他們所求的去做吧！但你要嚴厲地警告他們，讓他們知道將來王會怎樣管轄他們。」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10"> 撒母耳就把耶和華的話轉告給那些請求他立王的民眾，說：</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳記上 14:52; 申命記 17:14–20; 撒母耳記上 10:25"> 「將來管轄你們的王會徵用你們的兒子做他的戰車兵、騎兵，要他們跑在他的戰車前面。</span>
<span className="v" id="v12" data-v="12" data-xref="撒母耳記上 22:7; 列王紀上 4:7; 歷代志上 27:1–22"> 他會派一些人做千夫長、五十夫長，一些人為他耕種田地、收割莊稼，一些人製造兵器和戰車的裝備。</span>
<span className="v" id="v13" data-v="13"> 他會把你們的女兒帶走，要她們給他造香膏、煮飯和烤餅。</span>
<span className="v" id="v14" data-v="14" data-xref="以西結書 46:18; 列王紀上 21:7; 列王紀上 21:19"> 他會奪去你們最好的田地、葡萄園和橄欖園，送給他的臣僕。</span>
<span className="v" id="v15" data-v="15" data-xref="但以理書 1:3; 以賽亞書 39:7; 創世記 37:36"> 他會從你們的糧食和葡萄園的出產中收取十分之一，送給他的官員和臣僕。</span>
<span className="v" id="v16" data-v="16"> 他會徵用你們的僕婢及最好的牛<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「牛」有古卷作「青年」。">a</a></sup>和驢來為他效勞。</span>
<span className="v" id="v17" data-v="17"> 他會拿去你們羊群的十分之一，你們必做他的奴僕。</span>
<span className="v" id="v18" data-v="18" data-xref="彌迦書 3:4; 以賽亞書 1:15; 箴言 1:25–28"> 那時你們會因所選之王的壓迫而呼求耶和華，耶和華卻不會垂聽。」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="耶利米書 44:16; 耶利米書 7:13; 以賽亞書 66:4"> 民眾卻不肯聽從撒母耳的話。他們說：「不，我們想要一個王治理我們，</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳記上 8:5; 詩篇 106:35; 申命記 7:6"> 這樣我們就會像其他國家一樣，有王來統治我們，率領我們，為我們作戰。」</span>
<span className="v" id="v21" data-v="21" data-xref="士師記 11:11"> 撒母耳聽後，就把民眾這些話轉告耶和華。</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳記上 8:7; 何西阿書 13:11"> 耶和華對撒母耳說：「照他們說的去為他們立一個王吧。」於是，撒母耳對以色列人說：「你們各人回自己的城去吧。」</span>
</div>
</div>

## 掃羅犯罪

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及記 12:5; 彌迦書 6:6"> 掃羅四十歲<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="希伯來文無「四十歲」，一些七十士希臘文譯本有此數字。">a</a></sup>登基。他在統治以色列的第二年，</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳記上 10:26; 撒母耳記上 13:5; 撒母耳記上 14:31"> 從以色列人中選出三千人，親自帶領其中的兩千人到密抹和伯特利山，另外一千人和約拿單留在便雅憫境內的基比亞。他把其餘的人遣散回家。</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳記上 10:5; 士師記 3:27; 士師記 6:34"> 約拿單攻打迦巴的非利士駐軍，非利士人聽到了這消息。於是，掃羅在各地吹響號角，通告希伯來人。</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 34:30; 出埃及記 5:21; 撒迦利亞書 11:8"> 以色列眾人聽說掃羅攻打非利士人的駐軍，並聽說非利士人對以色列人恨之入骨，便響應掃羅的號召，聚集在吉甲。</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳記上 14:23; 約書亞記 11:4; 約書亞記 18:12"> 非利士人調兵遣將，要攻打以色列。他們有三萬輛戰車和六千騎兵，步兵多如海邊的沙。大軍來到伯·亞文以東的密抹，駐紮在那裡。</span>
<span className="v" id="v6" data-v="6" data-xref="士師記 6:2; 希伯來書 11:38; 士師記 10:9"> 以色列人看見敵軍壓境，情勢危急，紛紛躲進山洞、叢林、石穴、地洞和坑裡。</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 20:8; 利未記 26:17; 民數記 32:1–5"> 有些希伯來人過了約旦河，逃到迦得和基列。但掃羅仍然留在吉甲，跟隨他的人都害怕得發抖。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="撒母耳記上 10:8"> 掃羅按著撒母耳所定的日期在吉甲等了七天，可是撒母耳還沒有來。掃羅的軍兵開始散去。</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀上 3:4; 箴言 21:27; 箴言 15:8"> 於是，掃羅說：「你們把燔祭和平安祭帶到我這裡來。」他就獻上了燔祭。</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳記上 15:13; 路得記 2:4; 詩篇 129:8"> 掃羅剛把燔祭獻完，撒母耳就來了，掃羅出去迎接他，向他問安。</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳記上 13:23; 撒母耳記上 13:5; 撒母耳記上 13:16"> 撒母耳對掃羅說：「你做的是什麼事？」掃羅答道：「我看見民眾不斷離我而去，你到了約定的時候還沒有來，而且非利士人就聚集在密抹。</span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 66:3; 阿摩司書 8:5; 哥林多後書 9:7"> 我想非利士人就要到吉甲來攻打我了，但我還沒有向耶和華求助，我迫不得已，就獻上燔祭了。」</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳記上 15:22; 歷代志下 16:9; 撒母耳記上 15:28"> 撒母耳說：「你真糊塗！你違背了你的上帝耶和華的命令。祂本來要使你的王位在以色列永遠堅立，</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行傳 13:22; 撒母耳記上 15:28; 詩篇 89:19–37"> 但現在你的王位不能長久了，耶和華已經找到一個合祂心意的人，要立他做百姓的君王。因為你沒有遵守耶和華的命令。」</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳記上 14:2; 撒母耳記上 13:2; 撒母耳記上 13:6–7"> 撒母耳離開吉甲去便雅憫境內的基比亞。掃羅數了一下跟隨他的人，約有六百人。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="撒母耳記上 13:3"> 掃羅和兒子約拿單及隨從留在便雅憫境內的迦巴，非利士人則在密抹紮營。</span>
<span className="v" id="v17" data-v="17" data-xref="約書亞記 18:23; 撒母耳記上 14:15; 約書亞記 19:3"> 非利士人分成三隊施行突襲，一隊前往書亞境內的俄弗拉，</span>
<span className="v" id="v18" data-v="18" data-xref="尼希米記 11:34; 約書亞記 18:13–14; 約書亞記 16:3"> 一隊前往伯·和崙，一隊前往邊境地區，那裡可以俯瞰曠野附近的洗波音谷。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="列王紀下 24:14; 士師記 5:8; 耶利米書 24:1"> 那時，以色列全境找不到一個鐵匠，這是因為非利士人的禁令，防止希伯來人製造刀槍。</span>
<span className="v" id="v20" data-v="20"> 以色列人都要到非利士的鐵匠那裡去磨鋤、犁、斧和鏟。</span>
<span className="v" id="v21" data-v="21"> 磨鋤或犁要花八克銀子，磨三齒叉、斧頭或趕畜棒要花四克銀子。</span>
<span className="v" id="v22" data-v="22" data-xref="士師記 5:8; 撒迦利亞書 4:6; 撒母耳記上 17:50"> 所以在交戰的日子，除了掃羅和約拿單外，其他隨從手上都沒有刀槍。</span>
<span className="v" id="v23" data-v="23" data-xref="以賽亞書 10:28; 撒母耳記上 14:1; 撒母耳記上 14:4–5"> 當時非利士的一隊防兵前往密抹的隘口駐守。</span>
</div>
</div>

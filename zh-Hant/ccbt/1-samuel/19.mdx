## 掃羅試圖殺大衛

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳記上 18:1; 撒母耳記上 18:9"> 掃羅吩咐他兒子約拿單和眾臣僕去殺掉大衛。但約拿單非常喜愛大衛，</span>
<span className="v" id="v2" data-v="2" data-xref="箴言 17:17; 使徒行傳 9:24; 撒母耳記上 18:1–3"> 便告訴他，說：「我父親要殺你，明天早上你要小心，找個僻靜的地方躲起來。</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳記上 20:9; 撒母耳記上 20:13"> 我會出去和父親站在你藏身的田間，跟他提你的事，然後把消息告訴你。」</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米書 18:20; 箴言 31:8–9; 創世記 42:22"> 約拿單就在父親面前替大衛說好話，他說：「王不要傷害大衛，他從來沒有對不起王，他所做的使王大受益處。</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳記上 11:13; 歷代志上 11:14; 士師記 9:17"> 他冒著生命危險去殺非利士人，耶和華使以色列人大獲全勝，當時你看見了，非常歡喜，現在為什麼要犯罪，枉殺無辜的大衛呢？」</span>
<span className="v" id="v6" data-v="6" data-xref="箴言 26:24–25; 耶利米書 5:2; 詩篇 15:4"> 掃羅聽了約拿單的話，就憑永活的耶和華起誓說：「我不殺大衛。」</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳記上 18:2; 撒母耳記上 16:21; 撒母耳記上 18:13"> 約拿單叫來大衛，把經過告訴他，帶他去見掃羅，大衛又像以前一樣伺候掃羅。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="詩篇 27:3; 詩篇 18:32–50"> 後來，戰事再度爆發，大衛領兵與非利士人交戰，大敗敵人，殺得他們四散潰逃。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳記上 16:14; 撒母耳記上 18:10–11; 撒母耳記上 16:16"> 一天，掃羅手裡拿著矛正坐在家中，從耶和華那裡來的邪靈降臨在掃羅身上。大衛正在彈琴，</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳記上 20:33; 撒母耳記上 18:11; 箴言 21:30"> 掃羅想用矛把大衛刺透，釘在牆上，大衛躲開了，矛插在了牆上。大衛當晚逃走了。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="詩篇 59:1–17; 士師記 16:2"> 掃羅派人去監視大衛的家，要在早上殺死他。大衛的妻子米甲警告他說：「你如果今晚不逃命，明早必死無疑。」</span>
<span className="v" id="v12" data-v="12" data-xref="約書亞記 2:15; 使徒行傳 9:24–25; 詩篇 34:19"> 於是，她從窗口把大衛縋下去，讓他逃走了。</span>
<span className="v" id="v13" data-v="13" data-xref="創世記 31:19; 士師記 18:17; 士師記 18:14"> 然後她把家中的神像放在床上，頭枕在山羊毛的枕頭上，蓋上衣服。</span>
<span className="v" id="v14" data-v="14" data-xref="約書亞記 2:5; 撒母耳記下 16:17–19; 撒母耳記下 17:20"> 掃羅派人來捉拿大衛的時候，米甲說他病了。</span>
<span className="v" id="v15" data-v="15" data-xref="箴言 27:3–4; 詩篇 37:12; 約伯記 31:31"> 掃羅又派人去見大衛，並吩咐說：「把他連床一起抬來，我好殺他。」</span>
<span className="v" id="v16" data-v="16"> 眾人進去發現躺在床上的是一個神像，頭枕在山羊毛的枕頭上。</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳記下 2:22; 撒母耳記上 22:17; 出埃及記 1:17–19"> 掃羅問米甲：「你為什麼欺騙我，讓我的敵人逃走？」米甲答道：「他說如果我不讓他逃走，就殺了我。」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="撒母耳記上 7:17; 詩篇 116:11; 撒母耳記上 15:34"> 大衛逃到住在拉瑪的撒母耳那裡，把掃羅的所作所為告訴他。後來，他和撒母耳去拿約住了下來。</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳記上 23:19; 撒母耳記上 22:9–10; 撒母耳記上 26:1"> 掃羅聽說大衛在拉瑪的拿約，</span>
<span className="v" id="v20" data-v="20" data-xref="約珥書 2:28; 約翰福音 7:32; 撒母耳記上 10:5–6"> 就派人去捉拿他。掃羅的人看到一群先知在說預言，撒母耳在當中帶領他們。上帝的靈也臨到掃羅的人，他們也說起預言來。</span>
<span className="v" id="v21" data-v="21" data-xref="箴言 27:22; 耶利米書 13:23; 約珥書 2:28"> 掃羅聽說後又派人去，派去的人也說起預言來。掃羅第三次派人去，派去的人同樣說起預言來。</span>
<span className="v" id="v22" data-v="22"> 最後掃羅親自前往拉瑪，走到西沽的大井，問撒母耳和大衛在哪裡，有人說在拉瑪的拿約。</span>
<span className="v" id="v23" data-v="23" data-xref="箴言 16:9; 撒母耳記上 10:10; 撒母耳記上 19:20"> 掃羅便去拉瑪的拿約。上帝的靈臨到掃羅，他就一邊走一邊說起預言來，一直到拉瑪的拿約。</span>
<span className="v" id="v24" data-v="24" data-xref="撒母耳記下 6:20; 以賽亞書 20:2; 彌迦書 1:8"> 他脫下自己的衣服，在撒母耳面前說起預言來。他赤身躺了一天一夜。因此有句俗語說：「掃羅也在先知當中嗎？」</span>
</div>

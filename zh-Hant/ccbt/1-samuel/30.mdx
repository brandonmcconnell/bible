## 大衛與亞瑪力人交戰

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳記上 15:7; 撒母耳記上 29:11; 撒母耳記上 27:8–10"> 第三天，大衛率領部下回到洗革拉的時候，發現亞瑪力人襲擊了南地和洗革拉，攻破了洗革拉城，把全城燒毀，</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳記上 27:11; 約伯記 38:11; 詩篇 76:10"> 並擄走了城內的婦女及所有老少，沒有殺任何人。</span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 34:19; 彼得前書 1:6–7; 啟示錄 3:9"> 大衛和部下來到洗革拉城，看到城被燒毀，妻子兒女都被擄走了，</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳記上 11:4; 民數記 14:1; 士師記 21:2"> 便放聲大哭，直哭得精疲力盡。</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳記上 25:42–43; 撒母耳記下 2:2; 撒母耳記上 1:2"> 大衛的兩個妻子耶斯列人亞希暖和拿八的遺孀迦密人亞比該也一起被擄走了。</span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 56:3–4; 詩篇 56:11; 詩篇 62:5"> 跟隨大衛的人因自己的兒女被擄去，心裡很痛苦，商議要用石頭打死大衛。大衛深陷困境，但他靠著他的上帝耶和華得到了力量。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="列王紀上 2:26; 撒母耳記上 22:20–21; 撒母耳記上 23:2–9"> 大衛吩咐亞希米勒的兒子亞比亞他祭司把以弗得拿來，亞比亞他就拿給他。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳記上 30:18; 箴言 3:5–6; 撒母耳記上 23:2"> 大衛求問耶和華，說：「我該追趕敵人嗎？我能追上他們嗎？」耶和華答道：「追趕他們吧，你必能追上他們，救回一切。」</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳記上 27:2"> 於是，大衛率領六百名部下前去追趕，到了比梭溪，有二百人因為太累而不能過溪，就留在那裡。大衛率領其餘的四百人繼續追趕。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="羅馬書 12:20–21; 申命記 23:7; 馬太福音 25:35"> 他們在田野遇見一個埃及人，就把他帶到大衛那裡。他們給他餅吃，給他水喝，</span>
<span className="v" id="v12" data-v="12" data-xref="士師記 15:19; 撒母耳記上 14:27; 撒母耳記上 30:13"> 還給他一塊無花果餅和兩個葡萄餅。他吃完後，恢復了體力，因為這人已經三天三夜沒吃沒喝了。</span>
<span className="v" id="v13" data-v="13" data-xref="雅各書 2:13; 箴言 12:10; 約伯記 31:13–15"> 大衛問他：「你是誰的僕人？你從哪裡來？」他答道：「我是埃及人，是亞瑪力人的奴僕。三天前，主人因為我患病把我撇棄了。</span>
<span className="v" id="v14" data-v="14" data-xref="列王紀上 1:38; 撒母耳記下 8:18; 列王紀上 1:44"> 我們襲擊了基利提的南方，猶大地區和迦勒南部，還燒毀了洗革拉。」</span>
<span className="v" id="v15" data-v="15" data-xref="約書亞記 2:12; 約書亞記 9:19–20; 以西結書 17:16"> 大衛又問他：「你可以領我去這些襲擊者那裡嗎？」他答道：「你先憑上帝向我起誓，你不殺我，也不把我交給我的主人，我就帶你去。」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="啟示錄 11:10–13; 撒母耳記下 13:28; 士師記 16:23–30"> 他帶著大衛找到那裡，見亞瑪力人正散佈在各處吃喝狂歡，因為他們從非利士和猶大搶奪了很多財物。</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳記上 11:11; 詩篇 18:42; 撒母耳記上 15:3"> 大衛率領部下從黎明攻打他們，直到次日黃昏。除了四百個青年騎駱駝逃脫外，亞瑪力人全軍覆沒。</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 14:16"> 大衛奪回亞瑪力人擄去的一切，包括他的兩個妻子。</span>
<span className="v" id="v19" data-v="19" data-xref="詩篇 91:9–10; 撒母耳記上 30:8; 約伯記 1:10"> 他盡數奪回了被擄去的男女老少和財物，</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳記上 30:26; 民數記 31:9–12; 歷代志下 20:25"> 也奪了所有的牛羊。他的部下把這些牛羊趕到自己的牲畜前面，說：「這是大衛的戰利品。」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="希伯來書 13:1; 撒母耳記上 30:10; 士師記 8:15"> 大衛回到留在比梭溪的那二百名因為太疲乏而沒有同去的人那裡，他們出來迎接大衛和眾隨從，大衛也上前問候他們。</span>
<span className="v" id="v22" data-v="22" data-xref="馬太福音 7:12; 申命記 13:13; 列王紀上 21:10"> 大衛隨從中那些惡徒和無賴說：「他們沒有跟我們一起去打仗，我們搶回來的東西不應分給他們，只讓他們帶走自己的妻子和兒女就好了。」</span>
<span className="v" id="v23" data-v="23" data-xref="申命記 8:18; 詩篇 44:2–7; 使徒行傳 7:2"> 大衛說：「弟兄們，這一切是耶和華賜給我們的，我們不可不分給他們，因為是耶和華保護我們，把敵人交在了我們手裡。</span>
<span className="v" id="v24" data-v="24" data-xref="約書亞記 22:8; 民數記 31:27; 詩篇 68:12"> 誰能接受你們的說法呢？上陣打仗的和看守裝備的應該得到一樣的待遇。」</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳記上 16:13"> 從那天開始，大衛就把這原則定為以色列的律例和典章，沿用至今。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="撒母耳記上 25:27; 創世記 33:11; 以賽亞書 32:8"> 大衛來到洗革拉，把部分戰利品送給他的朋友猶大的長老們，說：「這些禮物是從耶和華的敵人那裡奪來送給你們的。」</span>
<span className="v" id="v27" data-v="27" data-xref="約書亞記 15:48; 約書亞記 19:8; 士師記 1:22–23"> 大衛把禮物送給住在伯特利、南地的拉末、雅提珥、</span>
<span className="v" id="v28" data-v="28" data-xref="約書亞記 13:16; 約書亞記 15:50; 約書亞記 21:14"> 亞羅珥、息末、以實提莫、</span>
<span className="v" id="v29" data-v="29" data-xref="士師記 1:16; 撒母耳記上 27:10; 撒母耳記上 15:6"> 拉哈勒、耶拉篾和基尼各城、</span>
<span className="v" id="v30" data-v="30" data-xref="士師記 1:17; 約書亞記 19:4; 約書亞記 15:42"> 何珥瑪、歌拉珊、亞撻、</span>
<span className="v" id="v31" data-v="31" data-xref="撒母耳記下 2:1; 撒母耳記下 15:10; 撒母耳記下 4:1"> 希伯崙以及他和部下所到之處的人。</span>
</div>
</div>

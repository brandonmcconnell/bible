## 大衛不殺掃羅

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳記上 23:28–29; 以西結書 22:9; 撒母耳記上 23:19"> 掃羅追擊非利士人回來，得知大衛在隱·基底的曠野，</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳記上 26:2; 詩篇 104:18; 詩篇 37:32"> 就率領三千以色列精兵去野羊巖附近搜索大衛和他的部下。</span>
<span className="v" id="v3" data-v="3" data-xref="士師記 3:24; 詩篇 57:1–11; 詩篇 142:1–7"> 他們來到路旁的一處羊圈，那裡有一個山洞，掃羅進去大解。大衛和他的部下就躲在洞的深處。</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳記上 26:8–11; 撒母耳記上 24:10; 撒母耳記上 26:23"> 大衛的部下對大衛說：「耶和華說過要把你的仇敵交在你手中，任你處置，今天機會來了。」大衛就爬過去，偷偷割了掃羅外袍的一角。</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳記下 24:10; 列王紀下 22:19; 約翰一書 3:20–21"> 事後，大衛心裡不安，</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳記下 1:14; 約伯記 31:29–30; 撒母耳記上 26:9–11"> 他對部下說：「我不該做這樣的事，我主是耶和華所膏立的王，我絕不出手傷害他，因為他是耶和華所膏立的。」</span>
<span className="v" id="v7" data-v="7" data-xref="馬太福音 5:44; 詩篇 7:4; 羅馬書 12:17–21"> 大衛用這些話攔住他的部下，不讓他們殺掃羅。<br />掃羅起來離開山洞走了，</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳記上 25:23–24; 羅馬書 13:7; 出埃及記 20:12"> 大衛隨後也來到洞外，在後面喊掃羅：「我主我王啊！」掃羅回頭一看，見大衛俯伏在地，向他下拜。</span>
<span className="v" id="v9" data-v="9" data-xref="傳道書 7:21–22; 箴言 29:12; 箴言 16:28"> 大衛對掃羅說：「你為什麼聽信讒言，認為我要謀害你呢？</span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 105:15; 撒母耳記上 24:4; 撒母耳記上 26:8–9"> 你現在親眼看見了，剛才在山洞裡，耶和華把你交在我手中，有人叫我殺你，我卻不肯，因為你是耶和華所膏立的王，我不會動手傷害你。</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳記上 26:20; 撒母耳記上 23:14; 撒母耳記上 23:23"> 我父請看，你的這塊袍子在我手中。我割下了你的袍角，沒有殺你，現在你應該明白我並未圖謀背叛你。我沒有對不起你，你卻要置我於死地。</span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 43:1; 士師記 11:27; 詩篇 35:1"> 願耶和華在你我之間判定是非，替我伸冤，我卻不會動手傷害你。</span>
<span className="v" id="v13" data-v="13" data-xref="馬太福音 7:20; 馬太福音 7:16–18; 馬太福音 12:33–34"> 俗語說，『惡事出於惡人』，所以我不會動手傷害你。</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳記上 26:20; 撒母耳記上 17:43; 撒母耳記下 9:8"> 以色列王出來要捉拿誰呢？一條死狗嗎？一隻跳蚤嗎？</span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 43:1; 詩篇 35:1; 詩篇 119:154"> 願耶和華做我們的審判官，在你我之間判定是非。願耶和華鑒察，為我伸冤，從你手中拯救我。」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="撒母耳記上 26:17; 創世記 33:4; 路加福音 21:15"> 大衛說完了，掃羅問道：「我兒大衛啊！是你嗎？」便放聲大哭起來。</span>
<span className="v" id="v17" data-v="17" data-xref="馬太福音 5:44; 撒母耳記上 26:21; 創世記 38:26"> 掃羅對大衛說：「你比我公義，因為你善待我，我卻惡待你。</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳記上 26:23; 詩篇 31:8; 撒母耳記上 23:12"> 你今天使我明白你善待了我，耶和華把我交在你手中，你卻沒有下手殺我。</span>
<span className="v" id="v19" data-v="19" data-xref="詩篇 18:20; 撒母耳記上 23:21; 箴言 25:21–22"> 有誰會讓自己手中的仇敵平安離去呢？願耶和華因你今日善待我而賜福你。</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳記上 23:17; 馬太福音 2:3–6; 撒母耳記下 3:17–18"> 我知道你必做王，以色列國必在你手中得到堅固。</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 21:23; 撒母耳記下 21:6–8; 撒母耳記上 20:14–17"> 現在請你憑耶和華向我起誓，你不會殺害我的子孫，滅絕我的後代。」</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳記上 23:29; 約翰福音 2:24; 馬太福音 10:16–17"> 大衛便向掃羅起誓。之後，掃羅回家了，大衛和部下也回堡壘去了。</span>
</div>

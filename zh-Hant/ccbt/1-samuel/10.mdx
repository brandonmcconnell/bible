## 立掃羅為王

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳記上 16:13; 詩篇 78:71; 撒母耳記上 9:16"> 撒母耳把一瓶膏油倒在掃羅的頭上，親吻他，說：「耶和華已經膏立你做祂子民的首領。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳記上 9:3–5; 創世記 35:19–20; 約書亞記 18:28"> 你今天離開我以後，會在便雅憫境內的謝撒、靠近拉結的墓旁遇見兩個人。他們會告訴你，你要找的驢已經找到，現在你父親不再為驢擔心，反為你擔心，說，『我該怎樣找到我的兒子呢？』</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 35:3; 創世記 35:1; 創世記 28:22"> 你繼續往前走，會在他泊的橡樹那裡遇見三個人。他們要到伯特利去敬拜上帝，一個牽著三隻山羊羔，一個帶著三個餅，一個拿著一皮袋酒。</span>
<span className="v" id="v4" data-v="4" data-xref="士師記 18:15"> 他們會問候你，送你兩個餅，你要把餅收下。</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀下 3:15; 撒母耳記上 13:3; 撒母耳記上 19:20"> 此後，你會去上帝的山，那裡有非利士人的駐軍。你一進城，就會遇見一群先知從邱壇下來，前面有人鼓瑟、敲鼓、吹笛、彈琴，先知們會說預言。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳記上 10:10; 撒母耳記上 19:23–24; 民數記 11:25"> 耶和華的靈會突然降在你身上，你就會跟他們一起說預言，那時，你會變成另一個人。</span>
<span className="v" id="v7" data-v="7" data-xref="士師記 6:12; 約書亞記 1:5; 以賽亞書 7:14"> 這些兆頭臨到你的時候，你就要見機行事，因為上帝與你同在。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳記上 11:14–15; 撒母耳記上 13:4; 撒母耳記上 13:8–15"> 你先到吉甲去，在那裡等我七天，我會到那裡獻燔祭和平安祭。我到了以後會告訴你怎麼做。」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="以賽亞書 38:7–8; 撒母耳記上 10:2–6; 士師記 7:11"> 掃羅轉身離開撒母耳，上帝使他心靈煥然一新。撒母耳所說的兆頭那天都應驗了。</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳記上 10:5–6; 撒母耳記上 19:20–24"> 掃羅和他的僕人來到上帝的山，遇見了一群先知。上帝的靈突然降在掃羅身上，他就在他們中間說起預言來。</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳記上 19:24; 約翰福音 7:15; 馬太福音 13:54–55"> 以前認識掃羅的人看見他跟先知一起說預言，就議論說：「基士的兒子怎麼了？掃羅也做了先知嗎？」</span>
<span className="v" id="v12" data-v="12" data-xref="以賽亞書 54:13; 約翰福音 6:45; 雅各書 1:17"> 當地的一個人說：「他們的父親是誰？」自此以後，「掃羅也做了先知嗎」就成為一句諺語。</span>
<span className="v" id="v13" data-v="13"> 掃羅說完預言以後，就去了邱壇。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="撒母耳記上 14:50; 列王紀下 5:25; 撒母耳記上 9:3–10"> 掃羅的叔叔問他和他的僕人：「你們到哪裡去了？」掃羅答道：「我們去找驢，沒找著，就去見撒母耳。」</span>
<span className="v" id="v15" data-v="15"> 掃羅的叔叔說：「請把撒母耳對你們說的話告訴我。」</span>
<span className="v" id="v16" data-v="16" data-xref="箴言 29:11; 士師記 14:6; 撒母耳記上 9:20"> 掃羅答道：「他肯定地告訴我們驢已經找到了。」但掃羅沒有把撒母耳提到的立王之事告訴叔叔。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="士師記 20:1; 撒母耳記上 7:5–6"> 撒母耳把以色列人招聚到米斯巴耶和華那裡，</span>
<span className="v" id="v18" data-v="18" data-xref="士師記 6:8–9; 尼希米記 9:27–28; 士師記 2:1"> 對他們說：「以色列的上帝耶和華這樣說，『我帶你們出開埃及，從埃及人和壓迫你們的各國之人手中救出你們。』</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳記上 12:12; 撒母耳記上 8:19; 約書亞記 24:1"> 但你們現在卻背棄了拯救你們脫離一切災難和困苦的上帝，竟然對祂說，『我們要你立一位王來統治我們。』所以你們現在就按著支派宗族站在耶和華面前吧！」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="約書亞記 7:16–18; 使徒行傳 1:24–26; 撒母耳記上 14:41"> 撒母耳讓以色列各支派來抽籤，結果抽中了便雅憫支派。</span>
<span className="v" id="v21" data-v="21"> 然後撒母耳讓便雅憫支派的各宗族來抽，結果抽中了瑪特利家族，最後又抽中了基士的兒子掃羅。眾人找掃羅，卻找不到他。</span>
<span className="v" id="v22" data-v="22" data-xref="民數記 27:21; 士師記 20:18; 撒母耳記上 23:2–4"> 他們便求問耶和華，說：「這人來了嗎？」耶和華說：「他來了，躲在物品堆中。」</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳記上 9:2; 撒母耳記上 16:7; 撒母耳記上 17:4"> 他們就跑去把掃羅請來。掃羅站在百姓當中，高出眾人一頭。</span>
<span className="v" id="v24" data-v="24" data-xref="列王紀上 1:25; 列王紀上 1:39; 撒母耳記下 21:6"> 撒母耳對百姓說：「這就是耶和華為你們選的人。在以色列沒有人能比得上他。」眾人高呼：「願王萬歲！」</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="撒母耳記上 8:11–18; 申命記 17:14–20; 羅馬書 13:1–7"> 撒母耳向百姓說明做君王的權利和責任，又把這些都記在冊子上，放在耶和華面前，然後讓百姓各自回家。</span>
<span className="v" id="v26" data-v="26" data-xref="撒母耳記上 11:4; 約書亞記 18:28; 撒母耳記上 15:34"> 掃羅返回基比亞自己的家時，有一群被上帝感動的勇士跟隨他。</span>
<span className="v" id="v27" data-v="27" data-xref="申命記 13:13; 歷代志下 17:5; 列王紀上 10:25"> 但有一些市井之徒說：「這人怎能救我們？」就鄙視他，沒有送禮物給他，但掃羅沒有說什麼。</span>
</div>

## 掃羅王被廢

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="撒母耳記上 9:16; 撒母耳記上 12:14; 詩篇 2:10–11"> 一天，撒母耳對掃羅說：「耶和華差遣我膏立你做祂以色列子民的王，所以你要聽從祂的話。</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 25:17–19; 出埃及記 17:8–16; 民數記 24:20"> 萬軍之耶和華說，『我要懲罰亞瑪力人，因為在以色列人離開埃及的時候，他們與以色列人為敵。</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 20:16–18; 民數記 24:20; 民數記 31:17"> 你現在要去攻打他們，徹底消滅他們和他們擁有的一切，把男女老幼、牛羊駱駝和驢全部殺掉，一個不留。』」</span>
<span className="v" id="v4" data-v="4" data-xref="約書亞記 15:24; 撒母耳記上 11:8; 撒母耳記上 13:15"> 於是，掃羅在提拉因召集了二十萬步兵，另有從猶大來的一萬人。</span>
<span className="v" id="v5" data-v="5"> 掃羅來到亞瑪力的城池，在山谷裡埋伏起來。</span>
<span className="v" id="v6" data-v="6" data-xref="士師記 1:16; 民數記 10:29–32; 出埃及記 18:19"> 他對基尼人說：「你們離開亞瑪力人吧，免得我把你們也一起消滅，因為在以色列人離開埃及的時候，你們曾善待他們。」於是，基尼人離開了亞瑪力人。</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 16:7; 創世記 25:18; 撒母耳記上 14:48"> 掃羅攻打亞瑪力人，從哈腓拉直打到埃及東面的書珥，</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳記上 30:1; 以斯帖記 3:1; 民數記 24:7"> 生擒了亞瑪力王亞甲，用刀殺盡了亞瑪力人。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳記上 15:15; 撒母耳記上 15:19; 撒母耳記上 15:3"> 掃羅和他的士兵卻留下了亞甲和那些上好的牛羊、肥壯的牛犢和羊羔及一切美物，只毀滅了那些瘦弱無用的牲畜。</span>
<span className="v" id="v10" data-v="10"> 那時，耶和華對撒母耳說：</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳記上 13:13; 創世記 6:6; 撒母耳記下 24:16"> 「我後悔立掃羅為王，因為他離棄了我，不遵守我的命令。」撒母耳很氣憤，整夜呼求耶和華。</span>
<span className="v" id="v12" data-v="12" data-xref="約書亞記 15:55; 撒母耳記下 18:18; 撒母耳記上 25:2"> 清早，撒母耳起來去見掃羅，有人告訴他掃羅已前往迦密山，在那裡為自己立了紀念碑，然後去了吉甲。</span>
<span className="v" id="v13" data-v="13" data-xref="士師記 17:2; 路得記 3:10; 箴言 31:31"> 撒母耳到了掃羅那裡後，掃羅說：「願耶和華賜福給你，我已經遵守了耶和華的命令。」</span>
<span className="v" id="v14" data-v="14" data-xref="瑪拉基書 3:13–15; 耶利米書 2:18–19; 耶利米書 2:34–37"> 撒母耳說：「那麼，我現在聽見的牛羊叫聲是從哪裡來的？」</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳記上 15:21; 撒母耳記上 15:9; 出埃及記 32:22–23"> 掃羅答道：「這是眾人從亞瑪力人那裡帶回來的，他們留下了這些上好的牛羊要獻給你的上帝耶和華，我們毀滅了其餘的一切。」</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳記上 9:27; 列王紀上 22:16; 撒母耳記上 12:7"> 撒母耳對掃羅說：「住口！讓我告訴你耶和華昨天晚上對我說的話。」掃羅答道：「請說。」</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳記上 10:22; 撒母耳記上 9:21; 撒母耳記上 15:1–3"> 撒母耳說：「你雖然從前覺得自己微不足道，但現在卻做了以色列各支派的首領。耶和華膏立你做以色列的王。</span>
<span className="v" id="v18" data-v="18" data-xref="箴言 10:29; 創世記 13:13; 創世記 15:16"> 祂差遣你去攻打那些罪惡的亞瑪力人，命你把他們全部消滅。</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳記上 14:32; 歷代志下 33:6; 歷代志下 36:12"> 你為何不聽從祂的命令？你為何急於掠奪財物，做耶和華視為邪惡的事呢？」</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳記上 15:13; 馬太福音 19:20; 羅馬書 10:3"> 掃羅答道：「我的確服從了耶和華的命令，照著耶和華的吩咐做了。我把亞瑪力王亞甲帶了回來，殺盡了其餘的亞瑪力人。</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳記上 15:15; 出埃及記 32:22–23; 創世記 3:13"> 士兵們卻從本該毀滅的戰利品中取了上好的牛羊，準備在吉甲奉獻給你的上帝耶和華。」</span>
<span className="v" id="v22" data-v="22" data-xref="何西阿書 6:6; 詩篇 51:16–17; 箴言 21:3"> 撒母耳說：<br /><span className="pl pl-1">「耶和華喜歡燔祭和其他祭物，</span><br /><span className="pl pl-1">豈如喜歡人們聽從祂的話？</span><br /><span className="pl pl-1">順服勝於獻祭，</span><br /><span className="pl pl-1">聽從耶和華勝過向祂獻上公羊的脂肪。</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="耶利米書 28:16; 撒母耳記上 13:14; 利未記 20:6"> <span className="pl pl-1">叛逆不亞於行巫術的罪，</span><br /><span className="pl pl-1">頑固不化無異於拜偶像。</span><br /><span className="pl pl-1">你拒絕耶和華的命令，</span><br /><span className="pl pl-1">祂也拒絕你做王。」</span></span>
<span className="v" id="v24" data-v="24" data-xref="撒母耳記下 12:13; 以賽亞書 51:12–13; 民數記 22:34"> 掃羅對撒母耳說：「我犯罪了！我違背了耶和華的命令和你的指示。我因懼怕百姓，就聽從了他們。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及記 10:17"> 現在求你赦免我的罪，跟我一起回去，我好敬拜耶和華。」</span>
<span className="v" id="v26" data-v="26" data-xref="何西阿書 4:6; 撒母耳記上 13:14; 撒母耳記上 16:1"> 但撒母耳說：「我不會跟你回去，你既然拒絕遵行耶和華的命令，祂也拒絕你做以色列的王。」</span>
<span className="v" id="v27" data-v="27" data-xref="列王紀上 11:30–31"> 撒母耳轉身離去，掃羅就抓住他外袍的衣邊，結果衣邊被撕下來了。</span>
<span className="v" id="v28" data-v="28" data-xref="撒母耳記上 28:17–18; 使徒行傳 13:22; 但以理書 4:32"> 撒母耳對他說：「耶和華今天已經從你身上撕下以色列國，賜給了一個比你好的人。</span>
<span className="v" id="v29" data-v="29" data-xref="以西結書 24:14; 民數記 23:19; 提多書 1:2"> 以色列榮耀的上帝不說謊、也不改變心意，因為祂不是反復無常的世人。」</span>
<span className="v" id="v30" data-v="30" data-xref="約翰福音 5:44; 約翰福音 12:43; 以賽亞書 29:13"> 掃羅說：「我犯了罪，但求你在以色列的長老和百姓面前尊重我，求你跟我回去，我好敬拜你的上帝耶和華。」</span>
<span className="v" id="v31" data-v="31"> 於是，撒母耳跟掃羅一起回去，掃羅就敬拜耶和華。</span>
<span className="v" id="v32" data-v="32" data-xref="啟示錄 18:7; 帖撒羅尼迦前書 5:3; 耶利米書 48:44"> 撒母耳說：「把亞瑪力王亞甲帶到我這裡來。」亞甲若無其事地來到他面前，心想自己一定逃過一死了。</span>
<span className="v" id="v33" data-v="33" data-xref="士師記 1:7; 創世記 9:6; 馬太福音 7:2"> 但撒母耳對他說：「你的刀怎樣使婦人失去兒女，你的母親也要怎樣失去她的兒子。」於是，撒母耳就在吉甲，在耶和華面前把亞甲殺死了。</span>
<span className="v" id="v34" data-v="34" data-xref="撒母耳記上 11:4; 撒母耳記上 7:17"> 事後，撒母耳回到拉瑪，掃羅也返回基比亞自己的家。</span>
<span className="v" id="v35" data-v="35" data-xref="撒母耳記上 15:11; 撒母耳記上 19:24; 撒母耳記上 16:1"> 撒母耳一直到死沒有再見掃羅，但他為掃羅哀傷。耶和華後悔立掃羅做以色列王。</span>

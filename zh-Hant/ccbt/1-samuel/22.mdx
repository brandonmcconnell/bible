## 掃羅殘殺祭司

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="詩篇 57:1–11; 詩篇 142:1–7; 歷代志上 11:15"> 大衛離開迦特，逃到亞杜蘭洞。他的兄弟和親屬知道後，都來到他那裡，</span>
<span className="v" id="v2" data-v="2" data-xref="馬太福音 11:28; 撒母耳記上 30:22–24; 詩篇 72:12–14"> 所有受壓迫的、負債的和心懷不滿的人都紛紛來投奔他。大衛就做了他們的首領，跟隨他的約有四百人。</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳記上 3:18; 撒母耳記下 15:25–26; 士師記 11:29"> 後來，大衛到摩押的米斯巴去，請求摩押王收留他的父母，直到他明白上帝給他的安排為止。</span>
<span className="v" id="v4" data-v="4" data-xref="詩篇 11:1; 歷代志上 12:16; 歷代志上 29:29"> 大衛把父母留在了摩押王那裡。在大衛住堡壘期間，他的父母一直住在摩押。</span>
<span className="v" id="v5" data-v="5" data-xref="歷代志下 29:25; 歷代志上 21:9; 歷代志上 29:29"> 迦得先知吩咐大衛離開堡壘回猶大去，大衛就動身前往哈列的樹林。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="撒母耳記上 19:9; 撒母耳記上 18:10; 撒母耳記上 20:33"> 當時，掃羅正在基比亞的拉瑪，坐在柳樹下，手中拿著矛，臣僕侍立在左右。他得知大衛一行人的行蹤後，</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀上 12:16; 撒母耳記上 8:14–15; 撒母耳記上 22:13"> 就對左右的臣僕說：「便雅憫人啊，你們聽著！難道耶西的兒子會給你們田地和葡萄園嗎？他能立你們做千夫長和百夫長嗎？</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳記上 18:3; 撒母耳記上 23:21; 撒母耳記上 20:13–17"> 為什麼你們一同謀害我？我的兒子跟耶西的兒子立約，沒有人告訴我。就是今天我的兒子鼓動我的臣僕來謀害我，也沒有人關心我，告訴我。」</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 52:1–9; 撒母耳記上 14:3; 以西結書 22:9"> 以東人多益正站在掃羅的臣僕中，他說：「我在挪伯親眼看見耶西的兒子到了亞希突的兒子亞希米勒那裡。</span>
<span className="v" id="v10" data-v="10" data-xref="民數記 27:21; 撒母耳記上 30:8; 撒母耳記上 23:4"> 亞希米勒為他求問耶和華，給他食物，還把非利士人歌利亞的刀給了他。」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="羅馬書 3:15"> 於是，掃羅派人把挪伯的祭司——亞希突的兒子亞希米勒及其家人都召來。他們都來到王面前。</span>
<span className="v" id="v12" data-v="12" data-xref="撒母耳記下 9:6; 撒母耳記上 22:7; 以賽亞書 65:1"> 掃羅說：「亞希突的兒子，聽著！」亞希米勒答道：「我主啊，我在這裡。」</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳記上 22:8; 路加福音 23:2–5; 阿摩司書 7:10"> 掃羅說：「你為什麼和耶西的兒子一同謀害我？你為什麼把食物和刀給他，又為他求問耶和華，使他像今天這樣背叛我，伺機害我呢？」</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳記上 20:32; 撒母耳記上 19:4–5; 撒母耳記上 22:13"> 亞希米勒答道：「王的臣僕中有誰像大衛那樣忠心呢？他是王的女婿，又是王的護衛長，在王室中受尊重。</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳記上 25:36; 彼得前書 3:16–17; 哥林多後書 1:12"> 那也不是我第一次為他求問耶和華，求王不要因這事加罪於我或我的家人，因為僕人我對這事一無所知。」</span>
<span className="v" id="v16" data-v="16" data-xref="箴言 28:15; 但以理書 3:19–20; 列王紀上 19:2"> 王卻說：「亞希米勒啊，你和你全家都必死無疑！」</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及記 1:17; 撒母耳記上 14:45; 列王紀下 1:13–14"> 他就命令身旁的護衛，說：「把這些耶和華的祭司殺掉，因為他們跟大衛同謀，明知道大衛在潛逃，卻不來告訴我。」掃羅的臣僕不願意下手殺害耶和華的祭司。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行傳 26:10–11; 何西阿書 7:3; 撒母耳記上 2:18"> 掃羅就對多益說：「你去把祭司殺掉！」以東人多益就殺了他們。那天，他下手殺了八十五個穿細麻布以弗得的祭司。</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳記上 15:3; 何西阿書 10:14; 撒母耳記上 21:1"> 他又把祭司城挪伯的男女老少、牛羊和驢全部用刀殺掉。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="撒母耳記上 23:6; 撒母耳記上 30:7; 列王紀上 2:26–27"> 但是，亞希突之子亞希米勒有個兒子亞比亞他逃出去，投奔了大衛。</span>
<span className="v" id="v21" data-v="21"> 亞比亞他把掃羅屠殺耶和華祭司的事告訴了大衛，</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳記上 21:1–9; 詩篇 44:22"> 大衛說：「那天我見以東人多益在那裡，就知道他一定會告訴掃羅。是我連累了你父親一家。</span>
<span className="v" id="v23" data-v="23" data-xref="列王紀上 2:26; 希伯來書 12:1–3; 約翰福音 10:28–30"> 你就放心留在我這裡，不要害怕，想殺你的人，也想要殺我。你在我這裡很安全。」</span>
</div>
</div>

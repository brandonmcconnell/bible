## 掃羅求問巫婆

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳記上 17:1; 撒母耳記上 29:1–3; 撒母耳記上 7:7"> 非利士人召集大軍與以色列人交戰。亞吉對大衛說：「你應該明白，你和部下要隨我一起出戰。」</span>
<span className="v" id="v2" data-v="2" data-xref="羅馬書 12:9; 撒母耳記下 16:16–19; 撒母耳記上 27:10"> 大衛答道：「僕人願意效勞。」亞吉說：「很好！你就終生做我的護衛吧。」</span>
<span className="v" id="v3" data-v="3" data-xref="利未記 19:31; 撒母耳記上 25:1; 利未記 20:27"> 那時撒母耳已經死了，以色列舉國都為他哀悼，把他葬在他的家鄉拉瑪。當時，掃羅已把所有占卜和行巫術的都逐出了以色列。</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳記上 31:1; 約書亞記 19:18; 列王紀下 4:8"> 非利士人集合起來，在書念紮營，掃羅率領以色列軍隊在基利波紮營。</span>
<span className="v" id="v5" data-v="5" data-xref="以賽亞書 57:20–21; 但以理書 5:6; 以賽亞書 21:3–4"> 掃羅看見非利士軍隊聲勢浩大，嚇得膽戰心驚，</span>
<span className="v" id="v6" data-v="6" data-xref="民數記 12:6; 撒母耳記上 14:37; 耶利米哀歌 2:9"> 就求問耶和華，但耶和華沒有藉著夢、烏陵或先知回答他。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行傳 16:16; 約書亞記 17:11; 歷代志上 10:13"> 於是，掃羅命令臣僕找一個巫婆來，好求問她。臣僕在隱·多珥找到一個巫婆。</span>
<span className="v" id="v8" data-v="8" data-xref="以賽亞書 8:19; 歷代志上 10:13; 列王紀上 22:30"> 掃羅喬裝打扮，由兩個人陪同乘夜趕到那婦人家裡，說：「請你用法術把我要求問的亡靈招上來吧。」</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳記上 28:3; 列王紀下 5:7; 撒母耳記下 18:13"> 婦人對他說：「你知道掃羅剷除了國內占卜的和行巫術的，你為何來陷害我，置我於死地？」</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳記下 14:11; 撒母耳記上 19:6; 申命記 18:10–12"> 掃羅憑耶和華向婦人起誓，說：「我憑永活的耶和華起誓，你必不會因為此事而受到懲罰。」</span>
<span className="v" id="v11" data-v="11"> 婦人問道：「你想讓我招誰上來呢？」掃羅答道：「招撒母耳上來。」</span>
<span className="v" id="v12" data-v="12" data-xref="撒母耳記上 28:3; 列王紀上 14:5"> 婦人看見了撒母耳，就驚叫起來，對掃羅說：「你是掃羅，你為什麼騙我呢？」</span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 82:6–7; 約翰福音 10:34–35; 出埃及記 22:28"> 掃羅王對她說：「不要害怕，你看見什麼了？」婦人說：「我看見一個靈從地裡上來。」</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳記上 15:27; 列王紀下 2:8; 撒母耳記上 24:8"> 掃羅說：「他是什麼模樣？」婦人說：「是個身披長袍的老人。」掃羅知道是撒母耳，便俯伏在地，向他下拜。</span>
<span className="v" id="v15" data-v="15" data-xref="路加福音 16:23–26; 撒母耳記上 28:6; 撒母耳記上 18:12"> 撒母耳對掃羅說：「你為什麼打擾我，招我上來呢？」掃羅答道：「我深陷困境，非利士人與我們交戰，上帝也撇棄了我，不再藉著先知或夢來回答我。因此，我只好招你上來，好告訴我該怎麼辦。」</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀下 6:27; 耶利米哀歌 2:5; 詩篇 68:1–3"> 撒母耳說：「既然耶和華已經離棄了你，與你為敵，你為什麼還來問我？</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳記上 15:27–29; 撒母耳記上 16:13; 撒母耳記上 13:13–14"> 耶和華應驗了祂藉著我所說的預言，祂已把你的國權奪去，交給了你的同胞大衛。</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳記上 15:9; 列王紀上 20:42; 詩篇 50:21–22"> 耶和華今天這樣對待你，是因為你沒有聽從祂的吩咐，沒有把祂憎惡的亞瑪力人滅絕。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行傳 5:5; 耶利米書 28:16–17; 列王紀上 22:20"> 耶和華必把你和以色列人交在非利士人手裡，明天你和你的兒子們必跟我在一起了。耶和華必把以色列的軍隊交在非利士人手裡。」</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳記上 28:5; 約伯記 26:2; 約伯記 15:20–24"> 掃羅聽了撒母耳的話，頓時嚇得渾身僵直，倒在地上。他因一天一夜沒有進食，已經毫無力氣。</span>
<span className="v" id="v21" data-v="21" data-xref="士師記 12:3; 約伯記 13:14; 撒母耳記上 19:5"> 婦人到掃羅跟前，看見他驚恐萬分，就對他說：「婢女冒著生命危險服從你的命令，照你的吩咐做了。</span>
<span className="v" id="v22" data-v="22"> 現在，請你聽婢女的話，讓我給你一些食物吃，你好有體力趕路。」</span>
<span className="v" id="v23" data-v="23" data-xref="列王紀上 21:4; 路加福音 24:29; 路加福音 14:23"> 掃羅不肯，說：「我不吃。」他的隨從和婦人再三勸告，他才同意了，從地上起來坐到床上。</span>
<span className="v" id="v24" data-v="24" data-xref="路加福音 15:23; 創世記 18:7–8"> 婦人連忙宰了家中一隻小肥牛，又和麵烤了無酵餅，</span>
<span className="v" id="v25" data-v="25"> 擺在掃羅和他的隨從面前，他們吃完後，當晚就離開了。</span>

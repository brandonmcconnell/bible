## 約拿單攻打非利士人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士師記 6:27; 彌迦書 7:5; 撒母耳記下 1:25–26"> 一天，掃羅的兒子約拿單對為他拿兵器的年輕人說：「來吧，我們去非利士的駐軍那裡。」但他沒有告訴父親。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳記上 13:15–16; 以賽亞書 10:28–29"> 那時掃羅正待在基比亞邊界米磯崙的石榴樹下，跟隨他的大約有六百人，</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳記上 22:20; 撒母耳記上 2:28; 撒母耳記上 4:21"> 其中有穿著以弗得的祭司亞希亞，即亞希突的兒子。亞希突是示羅耶和華祭司以利的孫子，非尼哈的兒子，以迦博的哥哥。沒有人留意到約拿單出去了。</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳記上 13:23"> 約拿單到非利士駐軍那裡需要經過一個隘口，隘口兩邊的山峰一個叫播薛，一個叫西尼，</span>
<span className="v" id="v5" data-v="5"> 北面的山峰面對密抹，南面的山峰面對迦巴。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="馬太福音 19:26; 羅馬書 8:31; 撒迦利亞書 4:6"> 約拿單對拿兵器的年輕人說：「我們去那些未受割禮之人的軍營，也許耶和華會幫助我們。祂使人得勝不在於人數多少。」</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳記下 7:3; 撒迦利亞書 8:23; 撒母耳記上 10:7"> 拿兵器的人答道：「就照你的意思，我會一心追隨你。」</span>
<span className="v" id="v8" data-v="8" data-xref="士師記 7:9–14"> 約拿單說：「我們去他們那邊，故意讓他們發現。</span>
<span className="v" id="v9" data-v="9" data-xref="士師記 6:36–40; 創世記 24:13–14"> 如果他們說，『站住，等我們去你們那裡！』我們就待在原地，不去他們那裡。</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 24:14; 撒母耳記上 10:7; 士師記 7:11"> 但如果他們說，『你們來我們這裡！』我們就去，因為那表示耶和華已經把他們交在我們手裡了。」</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳記上 13:6; 撒母耳記上 14:22; 士師記 6:2"> 非利士的駐軍看見二人走近，就說：「看！希伯來人從躲藏的洞裡爬出來了！」</span>
<span className="v" id="v12" data-v="12" data-xref="撒母耳記上 17:43–44; 撒母耳記下 5:24; 士師記 7:15"> 駐軍對約拿單和拿兵器的人大喊：「上來，我們要教訓教訓你們。」約拿單就對拿兵器的人說：「跟著我爬上去，耶和華已經把他們交在以色列人手裡了。」</span>
<span className="v" id="v13" data-v="13" data-xref="羅馬書 8:31; 約書亞記 23:10; 利未記 26:7–8"> 於是，約拿單就爬上去擊殺非利士人，拿兵器的人緊隨其後，一同擊殺非利士人。</span>
<span className="v" id="v14" data-v="14"> 他們首次出擊，在半畝大小的區域殺了約二十個非利士人。</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳記上 13:17; 創世記 35:5; 撒母耳記下 5:24"> 營房、田野的所有非利士人，包括駐軍和突擊隊都非常恐慌。大地震動，眾人恐懼萬分。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="歷代志下 20:22–25; 以賽亞書 19:2; 士師記 7:22"> 掃羅在便雅憫境內基比亞的哨兵看見非利士軍隊四散奔逃，潰不成軍。</span>
<span className="v" id="v17" data-v="17"> 掃羅對跟隨他的人說：「你們查一查，看誰離開了軍營？」結果發現約拿單和為他拿兵器的人不見了。</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳記上 30:7–8; 撒母耳記上 5:2; 士師記 20:23"> 掃羅對亞希亞說：「把上帝的約櫃抬來。」那時上帝的約櫃在以色列人那裡。</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳記上 14:24; 民數記 27:21; 約書亞記 9:14"> 掃羅和祭司說話的時候，非利士人營裡越來越混亂。掃羅對祭司說：「停手吧。」</span>
<span className="v" id="v20" data-v="20" data-xref="士師記 7:22; 歷代志下 20:23; 撒母耳記上 14:16"> 他和跟隨他的人聚集起來，衝入戰場，發現非利士人正互相殘殺，亂作一團。</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳記上 29:4; 士師記 7:23"> 從前加入非利士軍隊的希伯來人，現在也倒戈加入掃羅和約拿單的以色列軍隊。</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳記上 13:6; 撒母耳記上 31:7"> 那些躲在以法蓮山區的以色列人聽說非利士人潰逃，都出來緊緊地追殺他們。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及記 14:30; 撒母耳記上 13:5; 詩篇 44:6–8"> 耶和華在那天拯救了以色列人，戰事一直蔓延到伯·亞文。</span>
</div>
</div>

## 約拿單誤違父命

<div className="bt">
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="約書亞記 6:26; 羅馬書 10:2; 士師記 1:28"> 那一天，以色列人很困乏，因為掃羅叫他們起誓：「誰在黃昏前，就是在向敵人報完仇以前吃任何東西，誰就要受咒詛。」於是，以色列人整天都沒有進食。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及記 3:8; 民數記 13:27; 申命記 9:28"> 眾人進入樹林，見地上有蜂蜜。</span>
<span className="v" id="v26" data-v="26" data-xref="傳道書 9:2"> 他們在樹林中雖然看見有蜂蜜正在滴落，但沒有人敢伸手取蜂蜜吃，因為他們都怕違背誓言。</span>
<span className="v" id="v27" data-v="27" data-xref="撒母耳記上 14:29; 撒母耳記上 14:43; 撒母耳記上 30:12"> 約拿單沒有聽見他父親叫以色列人起誓，他伸出手中的杖蘸蜂房的蜜吃，立刻精神大振。</span>
<span className="v" id="v28" data-v="28" data-xref="撒母耳記上 14:43; 撒母耳記上 14:24"> 有個士兵告訴約拿單，說：「你父親曾叫眾人鄭重起誓，『今天吃東西的人必受咒詛。』所以眾人很疲憊。」</span>
<span className="v" id="v29" data-v="29" data-xref="列王紀上 18:18; 約書亞記 7:25"> 約拿單說：「我父親使大家受苦了。你們看，我只吃了少許蜂蜜，就精神大振，</span>
<span className="v" id="v30" data-v="30" data-xref="傳道書 9:18"> 如果大家吃了從敵人那裡奪來的食物，我們就會殲滅更多非利士人。」</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="約書亞記 10:12; 約書亞記 19:42"> 那天，以色列人追殺非利士人，從密抹一直追殺到亞雅崙，眾人疲憊不堪。</span>
<span className="v" id="v32" data-v="32" data-xref="撒母耳記上 15:19; 利未記 3:17; 利未記 17:10–14"> 他們匆匆把奪來的牛、羊和牛犢在地上宰了，肉還帶血就吃了。</span>
<span className="v" id="v33" data-v="33" data-xref="羅馬書 2:1; 馬太福音 7:5"> 有人告訴掃羅，說：「眾人吃了帶血的肉，得罪耶和華了。」掃羅說：「你們犯罪了！現在把一塊大石頭滾到我這裡來，</span>
<span className="v" id="v34" data-v="34"> 再去吩咐大家把牛羊都帶到這裡來宰了吃，不可吃帶血的肉得罪耶和華。」當晚，眾人都把自己的牛羊帶到那裡宰殺。</span>
<span className="v" id="v35" data-v="35" data-xref="撒母耳記上 7:17; 撒母耳記上 7:12; 提摩太後書 3:5"> 掃羅為耶和華築了一座祭壇，這是他第一次為耶和華築壇。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="以賽亞書 48:1–2; 詩篇 73:28; 瑪拉基書 2:7"> 他對以色列人說：「讓我們連夜追趕非利士人，搶奪他們的財物，直到天亮，把他們全部殲滅。」眾人答道：「就照你的意思。」但祭司說：「讓我們先來求問上帝吧。」</span>
<span className="v" id="v37" data-v="37" data-xref="撒母耳記上 28:6; 撒母耳記上 30:7–8; 撒母耳記上 23:9–12"> 於是，掃羅求問上帝，說：「我可以去追殺非利士人嗎？你會把他們交在以色列人手裡嗎？」但耶和華那日沒有回答他。</span>
<span className="v" id="v38" data-v="38" data-xref="士師記 20:2; 約書亞記 7:14–26; 民數記 24:17"> 掃羅說：「你們這些百姓的首領到這裡來，我們要查出今天究竟誰犯了罪，</span>
<span className="v" id="v39" data-v="39" data-xref="撒母耳記上 14:44; 撒母耳記下 12:5; 撒母耳記上 14:24"> 我憑拯救以色列的永活的耶和華起誓，就是我兒子約拿單犯了罪，他也要死！」眾人都默不作聲。</span>
<span className="v" id="v40" data-v="40" data-xref="撒母耳記下 15:15; 撒母耳記上 14:7; 撒母耳記上 14:36"> 掃羅對以色列眾人說：「你們站在這邊，我和我的兒子約拿單站在那邊。」眾人答道：「就照你的意思。」</span>
<span className="v" id="v41" data-v="41" data-xref="使徒行傳 1:24; 約書亞記 7:16–18; 撒母耳記上 10:20–21"> 掃羅向以色列的上帝耶和華禱告說：「請你把實情告訴我吧。」抽籤的結果是約拿單和掃羅犯了罪，民眾都是無辜的。</span>
<span className="v" id="v42" data-v="42"> 掃羅和約拿單二人再抽籤，結果抽出了約拿單。</span>
<span className="v" id="v43" data-v="43" data-xref="約書亞記 7:19; 撒母耳記上 14:27; 約拿書 1:7–10"> 掃羅對約拿單說：「告訴我，你做了什麼事？」約拿單說：「我確實用手中的杖蘸了一點蜂蜜吃，這樣我就要死嗎？」</span>
<span className="v" id="v44" data-v="44" data-xref="撒母耳記上 14:39; 路得記 1:17; 撒母耳記上 25:22"> 掃羅說：「約拿單啊，你必須死。否則，願上帝重重地懲罰我。」</span>
<span className="v" id="v45" data-v="45" data-xref="路加福音 21:18; 使徒行傳 27:34; 撒母耳記下 14:11"> 但眾人對掃羅說：「今天約拿單給以色列人帶來這麼大的勝利，難道要他死嗎？絕不可以！我們憑永活的耶和華起誓，絕不可動他一根頭髮，因為他今天的行動有上帝的幫助。」眾人就這樣救了約拿單的性命。</span>
<span className="v" id="v46" data-v="46"> 掃羅便停止了追擊，非利士人也回本地去了。</span>
</div>
<div className="bp">
<span className="v" id="v47" data-v="47" data-xref="撒母耳記下 10:6; 撒母耳記上 14:52; 撒母耳記下 8:3"> 掃羅統治以色列後，常常攻打四圍的摩押人、亞捫人、以東人、瑣巴的諸王和非利士人等仇敵，無往而不勝。</span>
<span className="v" id="v48" data-v="48" data-xref="出埃及記 17:14; 撒母耳記上 15:3–7; 申命記 25:19"> 他奮勇殺敵，打敗了亞瑪力人，從掠奪者手中救出以色列人。</span>
</div>
<div className="bp">
<span className="v" id="v49" data-v="49" data-xref="歷代志上 8:33; 撒母耳記上 31:2; 撒母耳記下 6:20–23"> 他的兒子是約拿單、亦施韋和麥基舒亞，長女叫米拉，次女叫米甲。</span>
<span className="v" id="v50" data-v="50" data-xref="撒母耳記下 2:8; 撒母耳記上 17:55; 撒母耳記下 3:27"> 他的妻子名叫亞希暖，是亞希瑪斯的女兒。掃羅軍隊的元帥叫押尼珥，是他叔叔尼珥的兒子。</span>
<span className="v" id="v51" data-v="51" data-xref="撒母耳記上 9:1; 撒母耳記上 9:21"> 掃羅的父親基士和押尼珥的父親尼珥都是亞別的兒子。</span>
<span className="v" id="v52" data-v="52" data-xref="撒母耳記上 8:11; 撒母耳記上 8:1"> 掃羅一生常和非利士人激烈交戰。他遇見英勇的壯士，都會徵募到自己麾下。</span>
</div>
</div>

## 撒母耳膏立大衛做王

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀下 9:1; 撒母耳記上 15:23; 詩篇 78:68–71"> 耶和華對撒母耳說：「我已經拒絕讓掃羅做以色列王了，你還要為他哀傷多久呢？把你的角盛滿膏油，我要差遣你到伯利恆的耶西那裡，我已選了他的一個兒子做王。」</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳記上 9:12; 撒母耳記上 20:29; 馬太福音 10:16"> 撒母耳說：「我怎麼可以去呢？掃羅知道了，一定會殺掉我。」耶和華說：「你帶一頭牛犢去，就說，『我是來向耶和華獻祭的。』</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳記上 9:16; 撒母耳記上 16:12–13; 撒母耳記下 15:11"> 你要請耶西參加獻祭，我會告訴你怎麼做，我把誰指示給你，你就要為我膏立誰。」</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀上 2:13; 歷代志上 12:17–18; 撒母耳記上 21:1"> 撒母耳遵行耶和華的吩咐，他來到伯利恆，那城的長老都戰戰兢兢地出來迎接他，問道：「你是為平安而來嗎？」</span>
<span className="v" id="v5" data-v="5" data-xref="約書亞記 3:5; 利未記 20:7–8; 出埃及記 19:10"> 撒母耳答道：「是的，為平安而來，我是來向耶和華獻祭的。你們要潔淨自己，然後來和我一起獻祭。」撒母耳為耶西及其眾子行過潔淨禮後，便邀請他們參加獻祭。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳記上 17:13; 歷代志上 2:13; 撒母耳記上 17:22"> 耶西及其眾子來了，撒母耳看見以利押，心裡想：「這位肯定是耶和華要膏立的人。」</span>
<span className="v" id="v7" data-v="7" data-xref="約翰福音 7:24; 耶利米書 17:10; 路加福音 16:15"> 但耶和華對撒母耳說：「不要看他相貌堂堂、身材高大，我要選的不是他。耶和華不像世人那樣看人，人看外表，耶和華看內心。」</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳記上 17:13; 歷代志上 2:13"> 耶西吩咐他的兒子亞比拿達從撒母耳面前走過，但撒母耳說：「這也不是耶和華揀選的人。」</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳記上 17:13; 歷代志上 2:13; 撒母耳記下 13:3"> 耶西又叫沙瑪從撒母耳面前走過，但撒母耳說：「這也不是耶和華揀選的人。」</span>
<span className="v" id="v10" data-v="10" data-xref="歷代志上 2:13–15"> 耶西叫七個兒子一個一個從撒母耳面前走過，但撒母耳說他們都不是耶和華揀選的人。</span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 78:70–71; 撒母耳記下 7:8; 撒母耳記下 13:3"> 撒母耳問耶西：「你的兒子全都到齊了嗎？」耶西答道：「還有一個最小的，他正在田間放羊。」撒母耳對耶西說：「派人叫他回來，他不來，我們就不入座。」</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米哀歌 4:7; 詩篇 89:19–20; 雅歌 5:10"> 耶西就派人去叫他回來。他面色紅潤，眉清目秀，相貌英俊。耶和華說：「就是他，起來膏立他吧。」</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳記上 10:6; 希伯來書 1:9; 約翰福音 3:34"> 撒母耳就拿出盛膏油的角，當著他哥哥們的面膏立他。從那天起，耶和華的靈突然降在大衛身上。事後，撒母耳回拉瑪去了。</span>
</div>
</div>

## 大衛服侍掃羅

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="詩篇 51:11; 撒母耳記上 18:12; 士師記 9:23"> 耶和華的靈離開了掃羅，有個邪靈從耶和華那裡來折磨他。</span>
<span className="v" id="v15" data-v="15"> 掃羅的臣僕對他說：「現在有個邪靈從上帝那裡來折磨你，</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀下 3:15; 列王紀上 10:8; 撒母耳記上 19:9"> 你<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「你」希伯來文是「我們的主」。">a</a></sup>可以吩咐跟前的臣僕去找一個善於彈琴的人來。邪靈從上帝那裡來到你身上的時候，他為你彈琴，你就舒暢了。」</span>
<span className="v" id="v17" data-v="17"> 掃羅說：「你們就為我找一個善於彈琴的人，帶他到我這裡來。」</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳記上 3:19; 創世記 39:23; 創世記 39:2"> 其中有一個僕人說：「我見過伯利恆的耶西的一個兒子，他善於彈琴，英勇善戰，談吐合宜，相貌英俊，並且耶和華與他同在。」</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳記上 16:11; 撒母耳記上 17:15; 詩篇 78:70–72"> 掃羅便差遣使者去見耶西，說：「請讓你放羊的兒子大衛到我這裡來。」</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳記上 10:27; 箴言 18:16; 撒母耳記上 17:18"> 耶西就把一些餅、一皮袋酒和一隻山羊羔馱在驢背上，讓兒子大衛帶去送給掃羅。</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 41:46; 箴言 22:29; 詩篇 146:3"> 大衛到了掃羅那裡，做了他身邊的侍臣。掃羅非常喜歡大衛，讓大衛為他拿兵器。</span>
<span className="v" id="v22" data-v="22"> 掃羅派人去見耶西，說：「你就讓大衛留在我的身邊吧，因為我喜歡他。」</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳記上 16:14–16; 撒母耳記上 18:10–11; 路加福音 11:24–26"> 每當有邪靈從上帝那裡來到掃羅身上的時候，大衛就為他彈琴，掃羅便覺得舒暢，邪靈也離開了他。</span>
</div>

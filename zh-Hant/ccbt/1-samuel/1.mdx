## 撒母耳的出生

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歷代志上 6:34; 歷代志上 6:25–27; 撒母耳記上 1:19"> 有一個以法蓮人名叫以利加拿，住在以法蓮山區的拉瑪·瑣非城。他是蘇弗的玄孫、托戶的曾孫、以利戶的孫子、耶羅罕的兒子。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 16:1–2; 士師記 13:2; 創世記 29:23–29"> 他有兩個妻子，一個叫哈娜，一個叫毗尼娜。毗尼娜有兒有女，哈娜卻無兒無女。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="路加福音 2:41; 約書亞記 18:1; 申命記 12:5–7"> 以利加拿每年都從家鄉到示羅去敬拜萬軍之耶和華，獻上祭物。當時以利的兩個兒子何弗尼和非尼哈在那裡做耶和華的祭司。</span>
<span className="v" id="v4" data-v="4" data-xref="申命記 12:17–18; 申命記 16:11; 申命記 12:5–7"> 每逢獻祭的日子，以利加拿就會把祭肉分給毗尼娜和她的兒女。</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 30:2; 創世記 29:30–31; 創世記 45:22"> 但他會給哈娜雙份祭肉，因為他愛哈娜，雖然耶和華使她不能生育。</span>
<span className="v" id="v6" data-v="6" data-xref="約伯記 6:14; 約伯記 24:21; 利未記 18:18"> 毗尼娜見耶和華使她不能生育，便常常刺激她、氣她。</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳記上 2:19"> 年復一年都是這樣。每年來到耶和華的殿時，毗尼娜總是惹她傷心哭泣，以致她吃不下飯。</span>
<span className="v" id="v8" data-v="8" data-xref="路得記 4:15; 約伯記 6:14; 以賽亞書 54:6"> 她的丈夫以利加拿對她說：「哈娜，你為什麼哭？為什麼不吃飯？為什麼心裡難過？有我不是比有十個兒子更好嗎？」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="撒母耳記上 3:3; 詩篇 27:4; 詩篇 5:7"> 一天，他們在示羅吃完飯後，哈娜站起來。當時，祭司以利正坐在耶和華殿門口的座位上。</span>
<span className="v" id="v10" data-v="10" data-xref="約伯記 7:11; 路加福音 22:44; 約伯記 10:1"> 哈娜心中愁苦，一邊向耶和華禱告一邊傷心地哭泣。</span>
<span className="v" id="v11" data-v="11" data-xref="士師記 13:5; 民數記 6:5; 創世記 29:32"> 她向上帝許願說：「萬軍之耶和華啊，如果你眷顧婢女的痛苦，不忘記婢女，賜給婢女一個兒子，我必讓他終生事奉你，永不剃他的頭<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="參見民數記6章。">a</a></sup>。」</span>
<span className="v" id="v12" data-v="12" data-xref="帖撒羅尼迦前書 5:17; 雅各書 5:16; 路加福音 18:1"> 哈娜在耶和華面前不住地禱告，以利注視著她的嘴唇。</span>
<span className="v" id="v13" data-v="13" data-xref="羅馬書 8:26; 使徒行傳 2:13; 創世記 24:42–45"> 哈娜在心中默禱，只動嘴唇，不出聲音，以利以為她喝醉了，</span>
<span className="v" id="v14" data-v="14" data-xref="以弗所書 4:25; 約伯記 8:2; 箴言 6:9"> 便對她說：「你要醉到什麼時候呢？醒醒酒吧！」</span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 62:8; 耶利米哀歌 2:19; 詩篇 42:4"> 哈娜答道：「我主啊，我沒有喝醉，我淡酒和烈酒都沒有喝。我是心裡非常愁苦，在耶和華面前傾訴心事。</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳記上 2:12; 約伯記 6:2–3; 馬太福音 12:34–35"> 請不要以為我是墮落的女人，我充滿悲傷和痛苦，所以一直在禱告。」</span>
<span className="v" id="v17" data-v="17" data-xref="馬可福音 5:34; 士師記 18:6; 詩篇 20:3–5"> 以利說：「你安心地回去吧，願以色列的上帝答應你的祈求。」</span>
<span className="v" id="v18" data-v="18" data-xref="路得記 2:13; 羅馬書 15:13; 傳道書 9:7"> 哈娜說：「願婢女在你面前蒙恩。」於是，她就去吃飯，不再愁容滿面了。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="創世記 21:1; 創世記 30:22; 撒母耳記上 1:11"> 第二天，以利加拿一家清早起來敬拜耶和華，然後回到自己的家鄉拉瑪。以利加拿與哈娜同房，耶和華顧念哈娜，</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 41:51–52; 馬太福音 1:21; 出埃及記 2:10"> 使她懷孕。她後來生了一個兒子，給孩子取名叫撒母耳，因為她說：「他是我向耶和華求來的。」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="撒母耳記上 1:3; 申命記 12:11; 約書亞記 24:15"> 第二年，以利加拿帶全家人前往示羅，向耶和華獻年祭並還所許的願。</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳記上 1:28; 撒母耳記上 1:11; 路加福音 2:22"> 哈娜沒有跟他們同去，她告訴丈夫說：「孩子斷奶以後，我會把他帶去獻給耶和華，讓他永遠住在那裡。」</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳記下 7:25; 路加福音 11:27; 創世記 21:7–8"> 以利加拿說：「就依你的意思吧。可以等孩子斷了奶再去。願耶和華成就祂的應許。」於是，她就留在家中哺養孩子，直到孩子斷奶。</span>
<span className="v" id="v24" data-v="24" data-xref="民數記 15:9–10; 約書亞記 18:1; 撒母耳記上 4:3–4"> 孩子斷奶以後，她就把年幼的孩子帶到示羅耶和華的殿，並帶去三頭公牛、十公斤麵粉和一袋酒。</span>
<span className="v" id="v25" data-v="25" data-xref="路加福音 18:15–16; 路加福音 2:22"> 他們宰了一頭公牛後，就把孩子帶到以利面前。</span>
<span className="v" id="v26" data-v="26" data-xref="列王紀下 4:30; 列王紀下 2:4; 列王紀下 2:6"> 哈娜說：「我主啊，我敢在你面前起誓，我就是那一次站在你這裡向耶和華祈求的婦人。</span>
<span className="v" id="v27" data-v="27" data-xref="約翰一書 5:15; 詩篇 118:5; 馬太福音 7:7"> 我求耶和華賜給我這個孩子，祂應允了我的祈求。</span>
<span className="v" id="v28" data-v="28" data-xref="創世記 24:26; 創世記 24:52; 提摩太後書 3:15"> 現在，我將他獻給耶和華，讓他終身事奉耶和華。」<br />他便在那裡敬拜耶和華。</span>
</div>
</div>

## 大衛與約拿單

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="彼得後書 2:9; 哥林多後書 1:12; 約翰一書 3:21"> 大衛從拉瑪的拿約逃出來去見約拿單，問他：「我做了什麼？犯了什麼罪？我什麼地方對不起你父親，他竟追殺我？」</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳記上 9:15; 約翰福音 17:8; 約翰福音 15:15"> 約拿單答道：「絕無此事，你不會死的！我父親事無大小都會告訴我的，他不會瞞著我這件事，不會的。」</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳記上 25:26; 申命記 6:13; 列王紀下 2:6"> 大衛發誓說：「你父親深知你恩待我，他為了不使你傷心，才瞞著你。但我憑永活的耶和華和你的性命起誓，我離死亡僅一步之遙！」</span>
<span className="v" id="v4" data-v="4"> 約拿單說：「你有什麼需要？我一定相助。」</span>
<span className="v" id="v5" data-v="5" data-xref="民數記 10:10; 撒母耳記上 19:2; 民數記 28:11"> 大衛答道：「明天是初一，我本該跟王一起用餐，請讓我躲到田間，直到第三天晚上。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳記上 17:58; 撒母耳記上 9:12; 申命記 12:5"> 如果你父親問起我，你就說我懇求你允許我回到故鄉伯利恆，因為我全家正在那裡獻年祭。</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳記上 25:17; 以斯帖記 7:7; 申命記 1:23"> 如果你父親說『好吧』，僕人就平安無事了。如果他發怒，就表示他決意要殺我。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳記下 14:32; 撒母耳記上 18:3; 撒母耳記上 23:18"> 請你善待僕人，因你與我在耶和華面前立了盟約。如果我有罪，就請你親手殺了我，何必把我交給你父親呢？」</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳記上 20:42; 撒母耳記上 19:2; 撒母耳記上 20:38"> 約拿單答道：「我決不會這樣做。我如果知道父親決意要殺你，怎能不通知你呢？」</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳記上 25:14; 撒母耳記上 25:17; 創世記 42:30"> 大衛說：「你父親如果向你發怒，誰來告訴我呢？」</span>
<span className="v" id="v11" data-v="11"> 約拿單說：「我們一起到田野去吧。」於是，二人一起去了田野。</span>
<span className="v" id="v12" data-v="12" data-xref="約書亞記 22:22; 約伯記 31:4; 箴言 25:2–3"> 約拿單對大衛說：「願以色列的上帝耶和華作證，明天或後天這個時侯我就會打探到我父親的意思，如果他善意待你，我會派人通知你。</span>
<span className="v" id="v13" data-v="13" data-xref="路得記 1:17; 歷代志上 22:11; 約書亞記 1:5"> 如果他有意殺你，而我卻不告訴你讓你安然逃走，願耶和華重重地懲罰我。願耶和華與你同在，像從前與我父親同在一樣。</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳記下 9:3; 以弗所書 5:1–2"> 在我有生之年，請你照耶和華的慈愛恩待我，免我一死。</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳記下 21:7; 撒母耳記上 24:21; 撒母耳記下 9:1–7"> 在我死後，即使耶和華把你所有的仇敵都毀滅了，請你仍舊恩待我的後人。」</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳記上 25:22; 撒母耳記上 18:3; 撒母耳記下 21:8"> 於是，約拿單與大衛家立下盟約，說：「如果大衛不守盟約，願耶和華藉著仇敵懲罰他。」</span>
<span className="v" id="v17" data-v="17" data-xref="箴言 18:24; 撒母耳記上 18:1; 撒母耳記上 18:3"> 約拿單因為像愛自己一樣愛大衛，便叫他再次起誓。</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳記上 20:25; 撒母耳記上 20:5"> 約拿單說：「明天是初一，人們會注意到你缺席。</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳記上 19:2; 撒母耳記上 20:5"> 到了後天，你要趕快去上次出事時躲藏的以色磐石那裡。</span>
<span className="v" id="v20" data-v="20"> 我會朝磐石的旁邊射三箭，好像射靶子。</span>
<span className="v" id="v21" data-v="21" data-xref="耶利米書 5:2; 阿摩司書 8:14; 耶利米書 12:16"> 然後，我會叫一個少年把箭拾回來。如果你聽到我對他說，『箭就在你旁邊，把箭拾回來。』那就表示你可以回來了，我憑永活的耶和華起誓，你必平安無事。</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳記上 20:37"> 但如果我對少年說，『箭就在你前面。』你就要離開，因為是耶和華要你離開。</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳記上 20:14–15; 撒母耳記上 20:42; 創世記 31:50"> 至於我們之間所立的約，耶和華永遠為我們作證。」</span>
<span className="v" id="v24" data-v="24" data-xref="箴言 4:17; 以賽亞書 1:11–15; 箴言 21:3"> 於是，大衛就躲到田野。初一到了，掃羅王入席吃飯，</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳記上 20:18; 士師記 16:20"> 他照常坐在靠牆的位置，約拿單坐在對面，押尼珥坐在王的身邊，大衛的位子空著。</span>
<span className="v" id="v26" data-v="26" data-xref="利未記 15:5; 利未記 11:24; 利未記 11:27"> 那一天，掃羅並沒有說什麼，他以為大衛可能遇到了使自己不潔淨的事，不能赴宴。</span>
<span className="v" id="v27" data-v="27" data-xref="彼得前書 2:4; 撒母耳記上 19:15; 撒母耳記上 18:11"> 可是到了第二天，就是初二，大衛的座位還是空的，掃羅就問兒子約拿單：「耶西的兒子為什麼這兩天都不來赴宴呢？」</span>
<span className="v" id="v28" data-v="28" data-xref="撒母耳記上 20:6"> 約拿單答道：「大衛懇求我讓他回到伯利恆，</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳記上 17:28"> 因為他家要在城中獻祭，他的哥哥要他去。他求我恩准他去見他的哥哥們。所以，他沒有來參加王的宴席。」</span>
<span className="v" id="v30" data-v="30" data-xref="箴言 21:24; 雅各書 1:19–20; 箴言 25:28"> 掃羅向約拿單發怒，對他說：「你這邪逆婦人養的！難道我不知道你是站在耶西的兒子那邊嗎？你這樣做不但自取其辱，也使你母親蒙羞。</span>
<span className="v" id="v31" data-v="31" data-xref="撒母耳記上 19:6; 撒母耳記上 20:8; 撒母耳記上 19:11–15"> 只要耶西的兒子活在世上，你和你的王位就不得安穩。你派人把他抓到我這裡，他非死不可。」</span>
<span className="v" id="v32" data-v="32" data-xref="馬太福音 27:23; 撒母耳記上 19:5; 路加福音 23:22"> 約拿單問：「為什麼要殺他？他做了什麼？」</span>
<span className="v" id="v33" data-v="33" data-xref="撒母耳記上 20:7; 撒母耳記上 18:11; 撒母耳記上 19:10"> 掃羅氣得把矛擲向約拿單，想要殺他。約拿單知道父親決意要殺大衛。</span>
<span className="v" id="v34" data-v="34" data-xref="以弗所書 4:26; 馬可福音 3:5; 傳道書 7:20"> 他怒氣沖沖地離席，整天不肯進食，因為他看見父親如此卑劣地對待大衛，心裡非常難過。</span>
<span className="v" id="v35" data-v="35" data-xref="撒母耳記下 20:5; 撒母耳記上 20:19"> 第二天早晨，約拿單按照和大衛的約定帶著一個少年來到田野。</span>
<span className="v" id="v36" data-v="36" data-xref="撒母耳記上 20:20–22"> 約拿單對少年說：「你跑去把我射的箭拾回來。」少年就向前跑去，約拿單把箭射在他前面。</span>
<span className="v" id="v37" data-v="37" data-xref="撒母耳記上 20:22"> 少年跑到落箭之處的時候，約拿單就大聲叫道：「箭不是在你前面嗎？</span>
<span className="v" id="v38" data-v="38" data-xref="詩篇 55:6–9; 箴言 6:4–5; 馬可福音 13:14–16"> 快快去，不要耽延。」少年連忙把箭拾起來，回到主人那裡。</span>
<span className="v" id="v39" data-v="39"> 他不知道主人的用意，只有約拿單和大衛知道。</span>
<span className="v" id="v40" data-v="40"> 約拿單把弓箭交給那少年，吩咐他帶回城中。</span>
<span className="v" id="v41" data-v="41" data-xref="創世記 29:11; 撒母耳記上 18:3; 撒母耳記下 9:6"> 少年離開以後，大衛就從磐石南面出來，伏地拜了三拜。二人彼此親吻，抱頭痛哭，大衛更是泣不成聲。</span>
<span className="v" id="v42" data-v="42" data-xref="撒母耳記上 1:17; 撒母耳記上 23:18; 撒母耳記上 20:22–23"> 約拿單說：「我們已憑耶和華的名起誓，有耶和華在你我和你我的子孫之間永遠為我們的盟約作證，你就安心去吧。」大衛便起身離開，約拿單也回城去了。</span>

## 大衛再次放過掃羅

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳記上 23:19; 詩篇 54:1–7; 約書亞記 15:24"> 西弗人到基比亞見掃羅，說：「大衛正躲在曠野附近的哈基拉山中。」</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳記上 24:2; 撒母耳記上 13:2; 詩篇 140:4–9"> 掃羅就帶領三千以色列精兵到西弗的曠野去追捕大衛。</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳記上 23:19; 撒母耳記上 26:1"> 他們在曠野附近路邊的哈基拉山上紮營。大衛在曠野聽說掃羅追來了，</span>
<span className="v" id="v4" data-v="4" data-xref="馬太福音 10:16; 約書亞記 2:1"> 就派人去打探消息，得知掃羅的追兵果然已到。</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳記上 17:55; 撒母耳記上 17:20; 撒母耳記上 14:50–51"> 大衛來到掃羅的營地，看見了他和他的元帥尼珥的兒子押尼珥睡覺的地方，他睡在軍營中間，其他人圍繞著他紮營。</span>
<span className="v" id="v6" data-v="6" data-xref="士師記 7:10–11; 撒母耳記下 2:18; 創世記 15:20"> 大衛問赫人亞希米勒和洗魯雅的兒子約押的兄弟亞比篩：「誰願意跟我到掃羅的營裡？」亞比篩答道：「我願意。」</span>
<span className="v" id="v7" data-v="7" data-xref="帖撒羅尼迦前書 5:2–3"> 大衛和亞比篩就趁夜間走進掃羅的軍營，發現掃羅正在熟睡，他的矛插在地上，靠近他的頭，押尼珥和其他人睡在他周圍。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳記上 24:4; 撒母耳記上 26:23; 申命記 32:30"> 亞比篩對大衛說：「現在上帝把你的敵人交在你手中了，讓我一矛把他釘在地上，決不用刺第二下。」</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳記下 1:14; 詩篇 105:15; 撒母耳記下 1:16"> 大衛卻說：「不要殺他，誰殺害耶和華所膏立的王，都難逃罪責。</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 47:29; 申命記 31:14; 詩篇 37:13"> 我憑永活的耶和華起誓，耶和華必親手擊殺他。他要麼壽終而死，要麼命喪沙場。</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳記上 24:6; 撒母耳記上 24:12; 撒母耳記下 1:14"> 我在耶和華面前絕不敢出手傷害祂所膏立的王。我們拿走他旁邊的矛和水瓶吧。」</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 2:21; 創世記 15:12; 以賽亞書 29:10"> 大衛拿上掃羅的矛和水瓶便同亞比篩離開了，沒有人看見，沒有人知道，他們都在沉睡，沒有人醒來，因為耶和華使他們都熟睡了。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="撒母耳記上 24:8; 士師記 9:7"> 大衛爬上營地對面的山坡，遠遠地站在山頂上，與他們相距很遠。</span>
<span className="v" id="v14" data-v="14"> 他呼喊掃羅的士兵和尼珥的兒子押尼珥：「押尼珥，你回答我！」押尼珥問道：「你是誰，竟敢在王面前喊叫？」</span>
<span className="v" id="v15" data-v="15"> 大衛說：「你不是勇士嗎？在以色列有誰比得上你呢？有人來刺殺你的王你的主，你為何沒有保護他呢？</span>
<span className="v" id="v16" data-v="16" data-xref="詩篇 79:11; 撒母耳記下 12:5; 撒母耳記上 26:9"> 你失職了。我憑永活的耶和華起誓，你們都該死。因為你們沒有保護你們的主——耶和華所膏立的王。你看看王頭旁的矛和水瓶在哪裡？」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="撒母耳記上 24:16; 撒母耳記上 24:8"> 掃羅聽出是大衛的聲音，就說：「我兒大衛！是你嗎？」大衛答道：「我主我王啊，是我。</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳記上 24:9; 撒母耳記上 24:11–14; 約翰福音 10:32"> 我主為什麼又要追殺僕人呢？我做錯了什麼，犯了什麼罪？</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳記下 14:16; 撒母耳記下 16:11; 撒母耳記下 20:19"> 我主我王，請聽僕人說，如果是耶和華使你與我作對，願祂悅納我獻上的祭物；如果這是出於人的主意，願他們在耶和華面前受咒詛。因為他們趕我離開耶和華所賜的產業，叫我去供奉其他神明。</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳記上 24:14; 馬太福音 26:55; 撒母耳記上 25:29"> 求你不要讓我死在遠離耶和華的異鄉！以色列王為何要像在山上獵殺鷓鴣一樣追捕一隻跳蚤呢？」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="撒母耳記上 15:24; 撒母耳記上 24:17; 出埃及記 9:27"> 掃羅說：「我犯罪了。我兒大衛，你回來吧，我不會再傷害你，因為你今日保存了我的性命。我真是糊塗，犯了大錯。」</span>
<span className="v" id="v22" data-v="22"> 大衛答道：「王的矛在這裡，請派一個人來拿回去吧。</span>
<span className="v" id="v23" data-v="23" data-xref="詩篇 62:12; 撒母耳記上 24:6–7; 詩篇 18:20–26"> 耶和華獎賞公義、信實的人。今天耶和華把你交在我手中，但我不願下手傷害耶和華所膏立的王。</span>
<span className="v" id="v24" data-v="24" data-xref="馬太福音 5:7; 哥林多後書 1:9–10; 詩篇 54:7"> 我今天保存了你的性命，願耶和華也保存我的性命，救我脫離一切患難。」</span>
<span className="v" id="v25" data-v="25" data-xref="民數記 24:9–10; 箴言 26:25; 撒母耳記上 24:19"> 掃羅對大衛說：「我兒大衛，願你蒙福。你一定能建功立業，戰勝仇敵。」於是，大衛起身離開，掃羅也回家去了。</span>
</div>

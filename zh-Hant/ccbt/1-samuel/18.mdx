## 掃羅嫉妒大衛

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳記上 20:17; 箴言 18:24; 撒母耳記上 18:3"> 大衛與掃羅說完話後，約拿單與大衛情投意合，他像愛自己一樣愛大衛。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳記上 17:15; 撒母耳記上 16:21–23"> 從那天起，掃羅把大衛留在身邊，不讓他再回父親那裡。</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳記上 20:8–17; 撒母耳記上 20:42; 撒母耳記下 21:7"> 約拿單像愛自己一樣愛大衛，他與大衛立了盟約，</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 41:42; 路加福音 15:22; 以斯帖記 6:8–9"> 並把身上的外袍、戰衣、刀、弓和腰帶都送給大衛。</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳記上 18:30; 撒母耳記上 18:14–15; 歌羅西書 4:5"> 無論掃羅派大衛辦什麼事，他都表現出色。掃羅派他做軍隊的將領，民眾和掃羅的臣僕都非常滿意。</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及記 15:20; 士師記 11:34; 詩篇 68:25"> 大衛殺死了非利士人歌利亞，與眾人歸來時，婦女們擊鼓彈琴、載歌載舞地從以色列各城出來迎接掃羅王。</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳記上 21:11; 撒母耳記上 29:5; 出埃及記 15:21"> 她們跳舞歌唱：「掃羅殺死千千，大衛殺死萬萬。」</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳記上 15:28; 箴言 13:10; 雅各書 4:5"> 掃羅聽了非常憤怒，對這話很反感，就說：「她們將萬萬歸功給大衛，將千千歸功給我，只剩我的王位沒有給他了！」</span>
<span className="v" id="v9" data-v="9" data-xref="馬可福音 7:22; 創世記 31:2; 馬太福音 20:15"> 掃羅從此對大衛起了嫉妒之心。</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳記上 19:9; 帖撒羅尼迦後書 2:11; 列王紀上 18:29"> 第二天，從上帝那裡來的邪靈突然降在掃羅身上，他就在屋子裡叫鬧不停，大衛照常為他彈琴。掃羅當時手上拿著矛，</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳記上 20:33; 以賽亞書 54:17; 路加福音 4:30"> 他突然把矛投向大衛，心想：「我要把他刺透，釘在牆上。」他投了兩次，大衛都躲過了。</span>
<span className="v" id="v12" data-v="12" data-xref="撒母耳記上 18:15; 撒母耳記上 18:29; 撒母耳記上 16:13–14"> 耶和華離開了掃羅與大衛同在，所以掃羅忌憚大衛。</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳記下 5:2; 詩篇 121:8; 撒母耳記上 18:16–17"> 他把大衛調離自己身邊，立為千夫長，讓他領兵作戰。</span>
<span className="v" id="v14" data-v="14" data-xref="創世記 39:23; 馬太福音 28:20; 撒母耳記上 16:18"> 耶和華與大衛同在，因此他事事成功。</span>
<span className="v" id="v15" data-v="15" data-xref="雅各書 3:17; 歌羅西書 4:5; 雅各書 1:5"> 掃羅看見大衛做事精明，就忌憚他。</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳記上 18:5; 民數記 27:17; 列王紀上 3:7"> 以色列人和猶大人都愛戴他，因為他帶領他們作戰。</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳記上 17:25; 撒母耳記上 25:28; 撒母耳記上 18:25"> 掃羅對大衛說：「我要把大女兒米拉嫁給你，但你要英勇作戰，效忠於我，為耶和華爭戰。」掃羅心裡想：「我不要親自動手，我要藉非利士人的手殺他。」</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳記下 7:18; 撒母耳記上 9:21; 撒母耳記上 18:23"> 大衛說：「我算什麼？我的家族在以色列那麼卑微，我怎麼配做王的女婿呢？」</span>
<span className="v" id="v19" data-v="19" data-xref="士師記 7:22; 撒母耳記下 21:8; 士師記 14:20"> 到了與大衛成婚的日子，掃羅卻把米拉嫁給了米何拉人亞得列。</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳記上 18:28"> 掃羅的次女米甲愛上了大衛，掃羅知道了非常高興。</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳記上 18:17; 出埃及記 10:7; 耶利米書 9:8"> 他心裡想：「我把這個女兒給大衛，讓他中圈套，好藉非利士人的手殺掉他。」於是，他對大衛說：「你現在還有一次機會做我的女婿。」</span>
<span className="v" id="v22" data-v="22" data-xref="詩篇 36:1–3; 詩篇 55:21; 撒母耳記下 13:28–29"> 他又吩咐臣僕，說：「你們私底下告訴大衛，說王很欣賞他，群臣都愛戴他，勸他做王的女婿。」</span>
<span className="v" id="v23" data-v="23" data-xref="詩篇 119:141; 箴言 14:20; 傳道書 9:15–16"> 掃羅的臣僕把這話告訴了大衛，大衛卻說：「做王的女婿豈是一件小事呢？我不過是個貧窮卑微的人。」</span>
<span className="v" id="v24" data-v="24"> 臣僕把大衛這番話回報掃羅，</span>
<span className="v" id="v25" data-v="25" data-xref="創世記 34:12; 撒母耳記上 18:17; 撒母耳記上 14:24"> 掃羅說：「你們去告訴大衛，就說王只需要一百個非利士人的包皮作聘禮，好向他的敵人報仇。」掃羅想讓大衛死在非利士人的手上。</span>
<span className="v" id="v26" data-v="26" data-xref="撒母耳記上 18:21"> 臣僕把這番話告訴了大衛，大衛欣然答應做王的女婿。期限到來之前，</span>
<span className="v" id="v27" data-v="27" data-xref="撒母耳記下 3:14; 士師記 14:19; 撒母耳記上 18:13"> 大衛和部下出去殺了二百個非利士人，把他們的包皮全部獻給掃羅，好做王的女婿。掃羅便把女兒米甲嫁給了大衛。</span>
<span className="v" id="v28" data-v="28" data-xref="撒母耳記上 24:20; 撒母耳記上 26:25; 創世記 37:8–11"> 掃羅知道耶和華與大衛同在，自己的女兒米甲也愛他，</span>
<span className="v" id="v29" data-v="29" data-xref="傳道書 4:4; 約翰福音 11:53; 雅各書 2:19"> 就更加忌憚大衛，終生與大衛為敵。</span>
<span className="v" id="v30" data-v="30" data-xref="撒母耳記上 18:5; 撒母耳記下 11:1; 彼得前書 2:4"> 非利士人的將領常來進犯，大衛每次作戰總比掃羅的其他臣僕出色，因而倍受尊重。</span>

## 主呼召撒母耳

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="阿摩司書 8:11–12; 詩篇 74:9; 撒母耳記上 3:21"> 小撒母耳跟著以利事奉耶和華。那時候，耶和華的話語稀少，異象也不多。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳記上 4:15; 詩篇 90:10; 創世記 27:1"> 一天晚上，老眼昏花的以利正睡在自己的房裡。</span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 27:4; 利未記 24:2–4; 出埃及記 27:20–21"> 上帝的燈還沒有熄滅，撒母耳睡在耶和華的殿內，那裡有上帝的約櫃。</span>
<span className="v" id="v4" data-v="4" data-xref="以賽亞書 6:8; 哥林多前書 12:6–11; 出埃及記 3:4"> 耶和華呼喚撒母耳，撒母耳答道：「我在這裡！」</span>
<span className="v" id="v5" data-v="5"> 他跑到以利跟前，說：「我來了，你叫我嗎？」以利說：「我沒有叫你，你去睡吧。」於是，他就回去睡覺。</span>
<span className="v" id="v6" data-v="6" data-xref="馬太福音 9:2; 撒母耳記上 4:16; 撒母耳記下 18:22"> 耶和華又呼喚撒母耳，撒母耳起來到以利跟前，說：「我來了，你叫我嗎？」以利答道：「孩子，我沒有叫你，回去睡吧。」</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行傳 19:2; 耶利米書 9:24"> 那時，撒母耳還不認識耶和華，耶和華的話還沒有向他顯明。</span>
<span className="v" id="v8" data-v="8" data-xref="約伯記 33:14–15; 哥林多前書 13:11–12"> 耶和華第三次呼喚他，撒母耳起來，到以利面前，說：「我來了，你叫我嗎？」這時候，以利才明白原來是耶和華在呼喚這孩子。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及記 20:19; 以賽亞書 6:8; 詩篇 85:8"> 他就吩咐撒母耳說：「你回去睡吧，要是再呼喚你，你就說，『耶和華啊，請吩咐，僕人恭聽。』」於是，撒母耳就回去睡下。</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳記上 3:8; 撒母耳記上 3:4–6"> 耶和華來站在那裡，再次像剛才一樣呼喚：「撒母耳！撒母耳！」撒母耳答道：「請吩咐，僕人恭聽。」</span>
<span className="v" id="v11" data-v="11" data-xref="哈巴谷書 1:5; 耶利米書 19:3; 列王紀下 21:12"> 耶和華對撒母耳說：「我要在以色列做一件令人震驚的事。</span>
<span className="v" id="v12" data-v="12" data-xref="撒母耳記上 2:27–36; 撒迦利亞書 1:6; 約書亞記 23:15"> 到時候，我要應驗我說的有關以利家的一切預言。</span>
<span className="v" id="v13" data-v="13" data-xref="箴言 19:18; 馬太福音 10:37; 撒母耳記上 2:12"> 我對以利說過我要永遠懲罰他家，因為他知道自己的兒子褻瀆我，卻沒有約束他們。</span>
<span className="v" id="v14" data-v="14" data-xref="以賽亞書 22:14; 撒母耳記上 2:25; 耶利米書 15:1"> 所以，我向以利家起誓說，『靠祭物或禮物絕不能贖去以利家的罪惡。』」</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米書 1:6–8; 瑪拉基書 1:10; 撒母耳記上 1:9"> 撒母耳在床上躺到天亮，然後起來打開耶和華的殿門。他不敢把異象告訴以利。</span>
<span className="v" id="v16" data-v="16"> 以利叫他：「撒母耳，我的孩子。」撒母耳答道：「我在這裡。」</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳記下 3:35; 路得記 1:17; 詩篇 141:5"> 以利說：「耶和華對你說了什麼？你不要向我隱瞞。如果你隱瞞一句，願上帝重重地懲罰你。」</span>
<span className="v" id="v18" data-v="18" data-xref="約伯記 2:10; 以賽亞書 39:8; 士師記 10:15"> 撒母耳就一五一十地告訴了他。以利說：「祂是耶和華，祂看怎樣好，就怎樣行吧。」</span>
<span className="v" id="v19" data-v="19" data-xref="創世記 39:2; 撒母耳記上 9:6; 列王紀上 8:56"> 撒母耳漸漸長大，耶和華與他同在，使他所說的話沒有一句落空。</span>
<span className="v" id="v20" data-v="20" data-xref="士師記 20:1; 撒母耳記下 3:10; 提摩太前書 1:12"> 從但到別示巴，全以色列的人都知道撒母耳被立為耶和華的先知。</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳記上 3:1; 創世記 12:7; 撒母耳記上 3:4"> 耶和華繼續在示羅顯現，用自己的話啟示撒母耳。</span>

## 哈娜的禱告

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="路加福音 1:46–56; 詩篇 13:5; 以賽亞書 12:2–3"> 哈娜禱告說：<br /><span className="pl pl-1">「我的心因耶和華而歡喜，</span><br /><span className="pl pl-1">我的角因耶和華而高舉，</span><br /><span className="pl pl-1">我的口向敵人誇耀，</span><br /><span className="pl pl-1">我因耶和華的拯救而快樂。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v2" data-v="2" data-xref="撒母耳記下 22:32; 以賽亞書 44:6; 詩篇 86:8"> <span className="pl pl-1">「耶和華聖潔無比，</span><br /><span className="pl pl-1">獨一無二，</span><br /><span className="pl pl-1">沒有磐石像我們的上帝。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="箴言 8:13; 列王紀上 8:39; 箴言 24:12"> <span className="pl pl-1">不要再驕橫傲慢、口出狂言，</span><br /><span className="pl pl-1">因為耶和華是無所不知的上帝，</span><br /><span className="pl pl-1">祂衡量人的一切行為。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="詩篇 76:3; 詩篇 37:15; 詩篇 46:9"> <span className="pl pl-1">勇士的弓被折斷，</span><br /><span className="pl pl-1">軟弱的卻有力量。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="耶利米書 15:9; 路加福音 1:53; 詩篇 113:9"> <span className="pl pl-1">素來豐衣足食的為糊口而當雇工，</span><br /><span className="pl pl-1">本來食不果腹的卻不再挨餓。</span><br /><span className="pl pl-1">不育的婦人現在生了七個孩子，</span><br /><span className="pl pl-1">兒女成群的婦人卻孤獨憔悴。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="申命記 32:39; 以賽亞書 26:19; 啟示錄 1:18"> <span className="pl pl-1">耶和華掌管生死，</span><br /><span className="pl pl-1">祂使人下到陰間，也使人起死回生。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 75:7; 約伯記 5:11; 申命記 8:17–18"> <span className="pl pl-1">貧窮富足在於祂，</span><br /><span className="pl pl-1">卑微高貴也在於祂。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 113:7–8; 但以理書 2:48; 雅各書 2:5"> <span className="pl pl-1">祂從灰塵中提拔窮苦的人，</span><br /><span className="pl pl-1">從糞堆裡提升貧賤的人，</span><br /><span className="pl pl-1">使他們與王子同坐，</span><br /><span className="pl pl-1">得享尊榮。</span><br /><span className="pl pl-1">大地的根基屬於耶和華，</span><br /><span className="pl pl-1">祂在上面建立了世界。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 121:3; 詩篇 91:11–12; 詩篇 33:16–17"> <span className="pl pl-1">祂看顧祂聖民的腳步，</span><br /><span className="pl pl-1">使惡人在黑暗中滅亡，</span><br /><span className="pl pl-1">因為得勝不是靠人的勇力。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 2:9; 詩篇 89:24; 詩篇 18:13–14"> <span className="pl pl-1">跟耶和華對抗的人必被擊潰，</span><br /><span className="pl pl-1">祂必從天上用雷擊打他。</span><br /><span className="pl pl-1">祂必審判天下，</span><br /><span className="pl pl-1">賜力量給祂所立的君王，</span><br /><span className="pl pl-1">使受膏者的角高舉。」</span></span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳記上 3:1; 撒母耳記上 2:18; 撒母耳記上 1:28"> 以利加拿返回了拉瑪，小撒母耳卻留在了示羅，在祭司以利的帶領下事奉耶和華。</span>
</div>
</div>

## 以利的惡子

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="羅馬書 1:28–30; 耶利米書 2:8; 士師記 2:10"> 以利的兩個兒子為人邪惡，不認識耶和華，</span>
<span className="v" id="v13" data-v="13" data-xref="利未記 7:29–34"> 對民眾不守自己做祭司的職分。每當民眾來獻祭，還在煮祭肉的時候，他們的僕人便拿著三齒叉來，</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及記 29:27–28; 以賽亞書 56:11; 撒母耳記上 2:29"> 從罐裡、鼎裡、釜裡或鍋裡插肉，把插上來的祭肉據為己有。他們這樣對待所有到示羅來的以色列人。</span>
<span className="v" id="v15" data-v="15" data-xref="利未記 3:16; 利未記 3:3–5; 羅馬書 16:18"> 甚至在焚燒脂肪之前，祭司的僕人就來對獻祭的人說：「把肉給祭司烤吧！他不要煮過的，只要生的。」</span>
<span className="v" id="v16" data-v="16" data-xref="利未記 7:23–25; 利未記 3:16; 彼得前書 5:2–3"> 如果獻祭的人答道：「要先焚燒脂肪，之後你可以隨便拿，」僕人便會說：「不，你現在就給我，不然我就要搶了。」</span>
<span className="v" id="v17" data-v="17" data-xref="瑪拉基書 2:7–9; 創世記 13:13; 瑪拉基書 2:13"> 在耶和華的眼中，這兩個青年罪惡深重，因為他們輕視獻給耶和華的祭物。</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳記上 3:1; 出埃及記 28:4; 撒母耳記上 2:11"> 那時年少的撒母耳穿著細麻布的以弗得，在耶和華面前事奉。</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳記上 1:3; 撒母耳記上 1:21; 出埃及記 23:14"> 他母親每年都為他縫一件小外衣，在她和丈夫來獻年祭時帶給他。</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳記上 1:27–28; 路加福音 2:34; 路得記 4:11"> 以利祝福以利加拿和他妻子，對他說：「願耶和華讓你妻子再給你生兒育女，代替她求來並獻給耶和華的孩子。」他們就回家去了。</span>
<span className="v" id="v21" data-v="21" data-xref="路加福音 2:40; 撒母耳記上 3:19; 創世記 21:1"> 耶和華眷顧哈娜，她又生了三個兒子和兩個女兒。年少的撒母耳在耶和華面前漸漸長大。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及記 38:8; 撒母耳記上 2:13–17; 耶利米書 7:9–10"> 以利年事已高，他聽說兩個兒子對待以色列人的惡行，以及他們與在會幕門口服侍的婦女行淫的事後，</span>
<span className="v" id="v23" data-v="23" data-xref="耶利米書 8:12; 腓立比書 3:19; 使徒行傳 9:4"> 就對他們說：「你們為什麼做這樣的事？我從百姓口中聽說了有關你們的惡行。</span>
<span className="v" id="v24" data-v="24" data-xref="瑪拉基書 2:8; 提摩太前書 3:7; 使徒行傳 6:3"> 我兒啊，不可這樣，我聽到在耶和華的子民中流傳著你們的壞名聲。</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳記上 3:14; 約書亞記 11:20; 希伯來書 10:26"> 人若得罪了別人，有上帝為他調解。但人若得罪了耶和華，誰能為他求情呢？」然而，他們不肯聽從父親的話，因為耶和華決意要殺他們。</span>
<span className="v" id="v26" data-v="26" data-xref="路加福音 2:52; 路加福音 2:40; 使徒行傳 2:47"> 小撒母耳漸漸長大，日益受到耶和華和民眾的喜愛。</span>
</div>
</div>

## 預言以利家的遭禍

<div className="bt">
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="申命記 33:1; 出埃及記 4:27; 出埃及記 4:14–16"> 有一個上帝的僕人來見以利，對他說：「耶和華說，『你的祖先在埃及被法老奴役的時候，我向他們顯現。</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及記 28:1; 利未記 8:7–8; 民數記 18:19"> 我在以色列各支派中選出你的祖先做我的祭司，在我的祭壇上獻祭燒香，穿著以弗得事奉我。我把以色列人獻的所有火祭都賜給你祖先家。</span>
<span className="v" id="v29" data-v="29" data-xref="馬太福音 10:37; 申命記 32:15; 撒母耳記上 2:13–17"> 你們為什麼蔑視獻給我的祭物和供物？你為什麼把你的兒子看得比我還重要，拿我以色列子民所獻的上好祭物來養肥自己？』</span>
<span className="v" id="v30" data-v="30" data-xref="約翰福音 12:26; 耶利米書 18:9–10; 箴言 3:9–10"> 「所以，以色列的上帝耶和華宣告說，『我曾經應許讓你家族永遠做我的祭司。』但現在耶和華宣佈，『這絕不可能了。尊重我的，我必尊重他；藐視我的，必遭藐視。</span>
<span className="v" id="v31" data-v="31" data-xref="撒母耳記上 22:17–20; 列王紀上 2:26–27; 詩篇 37:17"> 看啊，時候將到，我要切斷你和你家族的力量，你家族必沒有一個老人。</span>
<span className="v" id="v32" data-v="32" data-xref="撒迦利亞書 8:4; 撒母耳記上 4:11; 詩篇 78:59–64"> 你在困苦中必以羨慕的眼光看著我賜福以色列人，你家中卻永遠沒有一個老人。</span>
<span className="v" id="v33" data-v="33" data-xref="列王紀上 2:26–27; 列王紀上 1:7; 撒母耳記上 22:21–23"> 我不會把你家中的人從我壇前滅絕，但留下來的人必使你哭瞎雙眼、傷心欲絕。你的子孫必盛年早逝。</span>
<span className="v" id="v34" data-v="34" data-xref="撒母耳記上 4:11; 列王紀上 13:3; 撒母耳記上 4:17"> 你的兩個兒子何弗尼和非尼哈必死在同一天，這就是我言出必行的記號。</span>
<span className="v" id="v35" data-v="35" data-xref="撒母耳記下 7:27; 撒母耳記下 7:11; 列王紀上 11:38"> 我要為自己立一位忠心的祭司，他必照我的心意行事。我要使他的家族堅立，他必永遠服侍我膏立的王。</span>
<span className="v" id="v36" data-v="36" data-xref="列王紀上 2:27; 瑪拉基書 1:13; 以西結書 44:10–12"> 那時，你家存留下來的人要在他面前下拜，乞討銀子和餅，並懇求說，請給我一個祭司的職位以便糊口！』」</span>
</div>
</div>

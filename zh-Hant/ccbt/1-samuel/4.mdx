## 約櫃被擄

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳記上 29:1; 撒母耳記上 7:12; 撒母耳記上 5:1"> 撒母耳把耶和華的話傳遍了以色列。 那時，以色列人去迎戰非利士人，他們在以便以謝紮營，非利士人在亞弗紮營。</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米哀歌 3:40; 撒母耳記上 17:8; 約書亞記 7:5–8"> 非利士人列陣與以色列人交戰，大敗以色列人，殺了他們約四千人。</span>
<span className="v" id="v3" data-v="3" data-xref="提摩太後書 3:5; 民數記 10:35; 哥林多前書 10:1–5"> 軍隊回營後，以色列的長老說：「耶和華今天為什麼使我們敗在非利士人手下？我們從示羅把耶和華的約櫃抬來吧，讓它<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「它」或作「祂」。">a</a></sup>與我們同去，好從仇敵手中救我們。」</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳記下 6:2; 民數記 7:89; 詩篇 80:1"> 於是，他們派人去示羅，把那坐在基路伯天使上的萬軍之耶和華的約櫃抬來。以利的兩個兒子何弗尼和非尼哈也隨上帝的約櫃同來。</span>
<span className="v" id="v5" data-v="5" data-xref="約書亞記 6:5; 約伯記 20:5; 阿摩司書 6:3"> 以色列人看見耶和華的約櫃到了營中，就高聲歡呼，聲音震動大地。</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及記 32:17–18"> 非利士人聽見了歡呼聲就說：「希伯來人在營中歡呼什麼？」後來他們知道是耶和華的約櫃到了營中，</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 32:30; 出埃及記 14:25; 出埃及記 15:14–16"> 就害怕起來，說：「有神明到了他們營中，我們大禍臨頭了，我們從來沒有遇過這種事情！</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及記 9:14; 出埃及記 7:5; 詩篇 78:43–51"> 我們大禍臨頭了！誰能從這些大能的神明手中救我們？在曠野用各種災禍毀滅埃及人的就是這些神明。</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多前書 16:13; 士師記 13:1; 撒母耳記下 10:12"> 非利士人啊，要剛強，做大丈夫。不然，我們就會成為希伯來人的奴隸，像他們做我們的奴隸一樣。我們要做大丈夫，奮力征戰。」</span>
<span className="v" id="v10" data-v="10" data-xref="利未記 26:17; 列王紀下 14:12; 申命記 28:25"> 非利士人和以色列人交戰，以色列人落敗，紛紛逃回家中。他們傷亡慘重，損失了三萬步兵。</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳記上 2:34; 詩篇 78:64; 撒母耳記上 2:32"> 上帝的約櫃被擄走了，以利的兩個兒子何弗尼和非尼哈被殺身亡。</span>
</div>
</div>

## 以利之死

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="約書亞記 7:6; 尼希米記 9:1; 撒母耳記下 15:32"> 當天有一個便雅憫人逃出了戰場，他撕裂衣服，頭蒙灰塵，來到示羅。</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳記上 1:9; 撒母耳記上 4:18; 約書亞記 7:9"> 以利正坐在路旁的座位上觀望，因為他心裡為上帝的約櫃擔憂。那個從戰場回來的人進城報信後，全城的人都放聲大哭。</span>
<span className="v" id="v14" data-v="14"> 以利聽見哭喊聲，就問：「人們為何喊叫？」那人趕忙告訴他。</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳記上 3:2; 詩篇 90:10; 列王紀上 14:4"> 那時，以利已經九十八歲，眼睛因為年老而失明。</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳記下 1:4; 撒母耳記上 3:6; 約書亞記 7:19"> 報信的人對以利說：「我今天是從戰場逃回來的。」以利問：「我的孩子，情況怎麼樣？」</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳記上 3:11; 撒母耳記上 4:10–11"> 報信的答道：「以色列人被非利士人擊潰，傷亡慘重，你的兩個兒子何弗尼和非尼哈都死了，上帝的約櫃也被擄走了。」</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳記上 4:21–22; 彼得前書 4:17–18; 詩篇 69:9"> 以利年老體胖，聽到上帝的約櫃被擄去，就從門邊的座位上向後跌倒，頸斷身亡。他做以色列的士師四十年。</span>
<span className="v" id="v19" data-v="19"> 以利的兒媳婦、非尼哈的妻子當時懷孕在身，接近產期。她聽說上帝的約櫃被擄、公公和丈夫都死了，就突然陣痛，生下了孩子。</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 35:17–18; 詩篇 77:2; 約翰福音 16:21"> 在她彌留之際，身旁的婦人對她說：「不要怕，你生了一個男孩。」但她既不理會，也不回答。</span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 26:8; 耶利米書 2:11; 詩篇 78:61"> 她給孩子取名叫以迦博，意思是：「榮耀離開以色列了。」這是因為上帝的約櫃被擄走，她的公公和丈夫都死了。</span>
<span className="v" id="v22" data-v="22" data-xref="詩篇 137:5–6; 約翰福音 2:17"> 她說：「榮耀離開了以色列，因為上帝的約櫃已經被擄走了。」</span>
</div>

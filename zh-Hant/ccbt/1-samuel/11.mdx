## 掃羅打敗亞捫人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳記上 12:12; 列王紀上 20:34; 以西結書 17:13"> 亞捫人拿轄率軍上來圍困基列·雅比，城內的居民對拿轄說：「你與我們立約吧！我們願意服侍你。」</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳記上 17:26; 創世記 34:14; 民數記 16:14"> 亞捫人拿轄說：「好，但有一個條件，我要挖去你們每一個人的右眼，作為對全體以色列人的羞辱。」</span>
<span className="v" id="v3" data-v="3"> 雅比的長老說：「請寬限我們七天，我們好派遣使者去以色列全境。要是沒有人來營救我們，我們就向你投降。」</span>
<span className="v" id="v4" data-v="4" data-xref="士師記 2:4; 撒母耳記上 10:26; 撒母耳記上 15:34"> 雅比的使者來到掃羅的家鄉基比亞，把他們的情況告訴眾人，眾人聽了放聲大哭。</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀上 19:19; 士師記 18:23; 創世記 21:17"> 那時掃羅剛好趕著牛從田間回來，便問道：「發生了什麼事？為什麼眾人都在哭？」百姓把雅比的情況告訴了他。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳記上 10:10; 撒母耳記上 16:13; 士師記 6:34"> 掃羅聽後，上帝的靈便突然降在他身上，他勃然大怒，</span>
<span className="v" id="v7" data-v="7" data-xref="士師記 19:29; 士師記 20:1; 士師記 21:5–11"> 牽來兩頭牛，把牠們切成碎塊，然後派使者把碎塊分發到以色列全境，並且宣佈：「誰拒絕跟隨掃羅和撒母耳出戰，他的牛就要被砍成這樣。」耶和華使百姓充滿恐懼，他們都同心合意地響應。</span>
<span className="v" id="v8" data-v="8" data-xref="士師記 1:4–5; 撒母耳記下 24:9; 歷代志下 17:12–19"> 掃羅在比色統計以色列人，共有三十萬，從猶大來的有三萬。</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 18:17"> 他們讓雅比的使者回去告訴基列·雅比人，說：「明天中午，你們必得拯救。」使者回去告訴雅比人，他們非常歡喜，</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳記上 11:2–3"> 便對亞捫人說：「明天我們會出來歸順你們，你們怎樣對待我們都可以。」</span>
<span className="v" id="v11" data-v="11" data-xref="士師記 7:16; 雅各書 2:13; 出埃及記 14:24"> 第二天，掃羅把以色列人分成三隊，在黎明時分突襲亞捫人的軍營，把他們殺得大敗，直到中午才收兵。亞捫人的殘兵四散奔逃，沒有二人在一處的。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="撒母耳記上 10:27; 路加福音 19:27; 詩篇 21:8"> 以色列人對撒母耳說：「是誰說掃羅不該做王？把他們帶來，我們要處死他們。」</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳記下 19:22; 撒母耳記上 19:5; 出埃及記 14:13"> 掃羅卻說：「今天不可殺人，因為今天耶和華拯救了以色列。」</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳記上 10:8; 撒母耳記上 7:16; 歷代志上 12:38–39"> 撒母耳對民眾說：「來吧，我們到吉甲去，在那裡重新立國。」</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳記上 10:8; 撒母耳記上 10:17; 歷代志上 29:21–24"> 於是，他們來到吉甲，在耶和華面前立掃羅為王，又向耶和華獻上平安祭。掃羅和全體以色列人都非常歡喜。</span>
</div>

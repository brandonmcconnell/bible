## 欺壓者的命運

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="詩篇 36:4; 以賽亞書 32:7; 詩篇 7:14–16"> <span className="pl pl-1">躺在床上圖謀不軌、</span><br /><span className="pl pl-1">盤算作惡的人有禍了！</span><br /><span className="pl pl-1">天一亮，他們就依仗手中的權勢行惡。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="以賽亞書 5:8; 耶利米書 22:17; 阿摩司書 8:4"> <span className="pl pl-1">他們貪圖田地，就去霸佔；</span><br /><span className="pl pl-1">想要房屋，就去搶奪。</span><br /><span className="pl pl-1">他們欺壓人的全家，</span><br /><span className="pl pl-1">詐取別人的產業。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="耶利米書 8:3; 阿摩司書 5:13; 以賽亞書 2:11–12"> <span className="pl pl-1">所以，耶和華說：</span><br /><span className="pl pl-1">「我正計劃降災懲罰你們這族，</span><br /><span className="pl pl-1">你們無法逃脫，</span><br /><span className="pl pl-1">再也不能趾高氣揚，</span><br /><span className="pl pl-1">因為這是你們災禍臨頭的日子。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="哈巴谷書 2:6; 耶利米書 9:10; 耶利米書 9:17–21"> <span className="pl pl-1">到那日，人們要唱悲戚的哀歌譏諷你們說，</span><br /><span className="pl pl-1">『我們徹底完了，</span><br /><span className="pl pl-1">耶和華把我們的產業轉給別人。</span><br /><span className="pl pl-1">祂竟拿走我們的產業，</span><br /><span className="pl pl-1">把田地分給擄掠我們的人。』」</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="申命記 32:8; 約書亞記 18:4; 約書亞記 18:10"> <span className="pl pl-1">因此，他們在耶和華的會眾中將無人抽籤分地。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="阿摩司書 2:12; 以賽亞書 30:10; 使徒行傳 5:40"> <span className="pl pl-1">他們的先知說：</span><br /><span className="pl pl-1">「不要說預言了，</span><br /><span className="pl pl-1">不要預言這種事，</span><br /><span className="pl pl-1">我們不會蒙受羞辱。」</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 84:11; 詩篇 15:2; 耶利米書 15:16"> <span className="pl pl-1">雅各家啊，你們怎能說：</span><br /><span className="pl pl-1">「耶和華已經不耐煩了嗎？</span><br /><span className="pl pl-1">祂會做這些事嗎？」</span><br /><span className="pl pl-1">耶和華說：「我的話豈不有益於行為正直的人嗎？</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 120:6–7; 撒母耳記下 20:19; 以賽亞書 9:21"> <span className="pl pl-1">近來，你們像仇敵一樣起來攻擊我的子民</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「你們像仇敵一樣起來攻擊我的子民」或譯「我的子民如仇敵一樣興起來」。">a</a></sup><br /><span className="pl pl-1">。</span><br /><span className="pl pl-1">你們剝去那些如從戰場歸來一樣毫無戒備的過路人的外衣。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="哈巴谷書 2:14; 以西結書 39:21; 哥林多後書 4:6"> <span className="pl pl-1">你們把我子民中的婦女從她們的幸福家園趕走，</span><br /><span className="pl pl-1">又從她們的子女身上永遠地奪去我的尊榮。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="申命記 12:9; 詩篇 106:38; 列王紀下 17:6"> <span className="pl pl-1">你們起來走吧！</span><br /><span className="pl pl-1">這裡不再是你們的安居之地！</span><br /><span className="pl pl-1">因為這裡已遭玷污，</span><br /><span className="pl pl-1">被徹底毀壞。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="耶利米書 5:31; 以賽亞書 30:10–11; 哥林多後書 11:13–15"> <span className="pl pl-1">倘若有騙子撒謊說，</span><br /><span className="pl pl-1">『我預言你們會有美酒佳釀。』</span><br /><span className="pl pl-1">他就會成為這個民族的先知。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="彌迦書 4:6–7; 彌迦書 7:18; 何西阿書 1:11"> <span className="pl pl-1">「雅各家啊，</span><br /><span className="pl pl-1">我必把你們都聚集起來，</span><br /><span className="pl pl-1">我必把以色列的餘民集合起來。</span><br /><span className="pl pl-1">我要將他們安頓在一起，</span><br /><span className="pl pl-1">好像羊圈裡的羊，</span><br /><span className="pl pl-1">又如草場上的羊群；</span><br /><span className="pl pl-1">那裡必人聲鼎沸。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="以賽亞書 52:12; 撒迦利亞書 9:14–15; 以賽亞書 45:1–2"> <span className="pl pl-1">開路者要走在他們前面，</span><br /><span className="pl pl-1">帶領他們衝出敵人的城門。</span><br /><span className="pl pl-1">他們的王走在前面，</span><br /><span className="pl pl-1">耶和華親自引導他們。」</span></span>

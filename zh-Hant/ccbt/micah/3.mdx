## 斥責以色列的領袖

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="以賽亞書 1:10; 耶利米書 5:4–5; 詩篇 82:1–5"> <span className="pl pl-1">我說：「雅各的首領，以色列家的統治者啊！</span><br /><span className="pl pl-1">你們要聽！</span><br /><span className="pl pl-1">難道你們不知正義嗎？</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="以西結書 22:27; 箴言 28:4; 詩篇 53:4"> <span className="pl pl-1">然而，你們憎惡良善，</span><br /><span className="pl pl-1">喜愛邪惡，</span><br /><span className="pl pl-1">剝下我百姓的皮，</span><br /><span className="pl pl-1">從他們的骨頭上剔肉。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 14:4; 以西結書 11:6–7; 以西結書 11:3"> <span className="pl pl-1">你們吃我百姓的肉，</span><br /><span className="pl pl-1">剝我百姓的皮，</span><br /><span className="pl pl-1">打碎他們的骨頭，</span><br /><span className="pl pl-1">把他們切成塊，</span><br /><span className="pl pl-1">如同下在鍋裡、放進釜中的肉。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="箴言 1:28; 以賽亞書 1:15; 以西結書 8:18"> <span className="pl pl-1">你們遭難的時候，</span><br /><span className="pl pl-1">向耶和華呼求，</span><br /><span className="pl pl-1">祂必不應允你們。</span><br /><span className="pl pl-1">因你們的惡行，</span><br /><span className="pl pl-1">祂必掩面不顧你們。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="耶利米書 6:14; 耶利米書 14:14–15; 以西結書 22:25–29"> <span className="pl pl-1">耶和華說：</span><br /><span className="pl pl-1">「使我的子民步入歧途的先知啊，</span><br /><span className="pl pl-1">你們向供養你們的人報平安，</span><br /><span className="pl pl-1">出言攻擊那不供養你們的人。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="以賽亞書 8:20–22; 阿摩司書 8:9–10; 以賽亞書 29:10"> <span className="pl pl-1">因此，黑夜必籠罩你們，</span><br /><span className="pl pl-1">使你們看不見異象；</span><br /><span className="pl pl-1">幽暗必臨到你們，</span><br /><span className="pl pl-1">使你們無法占卜。</span><br /><span className="pl pl-1">太陽要為先知沉落，</span><br /><span className="pl pl-1">白晝變為黑夜。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="撒迦利亞書 13:4; 以賽亞書 44:25; 撒母耳記上 28:6"> <span className="pl pl-1">先見必抱愧，</span><br /><span className="pl pl-1">占卜者必蒙羞。</span><br /><span className="pl pl-1">因得不到上帝的答覆，</span><br /><span className="pl pl-1">你們都必羞愧地捂著臉。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="以賽亞書 58:1; 哥林多前書 2:12–13; 哥林多前書 2:4"> <span className="pl pl-1">至於我，</span><br /><span className="pl pl-1">因有耶和華的靈，</span><br /><span className="pl pl-1">我充滿權能、正義和力量，</span><br /><span className="pl pl-1">能向雅各宣告他的過犯，</span><br /><span className="pl pl-1">向以色列宣告他的罪惡。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="以賽亞書 1:23; 詩篇 58:1–2; 箴言 17:15"> <span className="pl pl-1">雅各家的首領，以色列家的統治者啊，</span><br /><span className="pl pl-1">你們要聽！</span><br /><span className="pl pl-1">你們厭惡正義，顛倒是非；</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="哈巴谷書 2:9–12; 耶利米書 22:13–17; 馬太福音 27:25"> <span className="pl pl-1">以血腥建立錫安，</span><br /><span className="pl pl-1">以罪惡建造耶路撒冷。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="耶利米書 6:13; 以賽亞書 1:23; 彌迦書 3:5"> <span className="pl pl-1">城裡的首領為貪贓而枉法，</span><br /><span className="pl pl-1">祭司為銀子而施教，</span><br /><span className="pl pl-1">先知為錢財而占卜。</span><br /><span className="pl pl-1">他們卻宣稱倚靠耶和華，說：</span><br /><span className="pl pl-1">「耶和華不是在我們當中嗎？</span><br /><span className="pl pl-1">災禍不會臨到我們。」</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="耶利米書 26:18; 詩篇 79:1; 彌迦書 4:1–2"> <span className="pl pl-1">所以，因你們的緣故，</span><br /><span className="pl pl-1">錫安必被夷為平地，</span><br /><span className="pl pl-1">耶路撒冷必淪為廢墟，</span><br /><span className="pl pl-1">聖殿山必成為長滿荒林的高崗。</span></span>
</div>

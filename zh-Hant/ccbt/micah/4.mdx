## 耶路撒冷的將來

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="以賽亞書 2:1–4; 耶利米書 3:17; 使徒行傳 2:17"> <span className="pl pl-1">在末後的日子，</span><br /><span className="pl pl-1">耶和華殿所在的山必聳立，</span><br /><span className="pl pl-1">高過群山，超過萬嶺，</span><br /><span className="pl pl-1">萬民都要湧向它。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="以賽亞書 2:3; 耶利米書 31:6; 使徒行傳 1:8"> <span className="pl pl-1">列國都必來，說：</span><br /><span className="pl pl-1">「來吧，讓我們登耶和華的山，</span><br /><span className="pl pl-1">去雅各之上帝的殿。</span><br /><span className="pl pl-1">祂必教導我們行祂的道，</span><br /><span className="pl pl-1">讓我們走祂的路。」</span><br /><span className="pl pl-1">因為訓誨必出於錫安，</span><br /><span className="pl pl-1">耶和華的話語必來自耶路撒冷。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="以賽亞書 2:4; 約珥書 3:9–16; 馬太福音 25:31–32"> <span className="pl pl-1">祂必在列邦施行審判，</span><br /><span className="pl pl-1">為遠方的強國平息紛爭。</span><br /><span className="pl pl-1">他們必把刀劍打成犁頭，</span><br /><span className="pl pl-1">將矛槍打成鐮刀。</span><br /><span className="pl pl-1">國與國不再刀兵相見，</span><br /><span className="pl pl-1">人們也不再學習戰事。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="撒迦利亞書 3:10; 列王紀上 4:25; 以西結書 39:26"> <span className="pl pl-1">人人都安然坐在自己的葡萄樹和無花果樹下，</span><br /><span className="pl pl-1">不再擔驚受怕。</span><br /><span className="pl pl-1">這是萬軍之耶和華親口說的。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="撒迦利亞書 10:12; 約書亞記 24:15; 歌羅西書 3:17"> <span className="pl pl-1">萬民都遵從自己神明的名，</span><br /><span className="pl pl-1">但我們要永遠遵從我們的上帝耶和華的名。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="西番雅書 3:19; 以西結書 34:12–17; 以賽亞書 35:3–6"> <span className="pl pl-1">耶和華說：</span><br /><span className="pl pl-1">「到那日，我要聚集瘸腿的，</span><br /><span className="pl pl-1">招聚被擄的和被我懲罰的。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="但以理書 7:14; 以賽亞書 24:23; 彌迦書 2:12"> <span className="pl pl-1">我要使瘸腿的成為餘民，</span><br /><span className="pl pl-1">讓被擄的成為強國。</span><br /><span className="pl pl-1">耶和華要在錫安山做王治理他們，</span><br /><span className="pl pl-1">從那時直到永遠。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="以賽亞書 1:26; 啟示錄 22:5; 撒迦利亞書 9:10"> <span className="pl pl-1">「你這羊群的瞭望塔，</span><br /><span className="pl pl-1">少女錫安的堅壘啊！</span><br /><span className="pl pl-1">你從前的國權必得恢復，</span><br /><span className="pl pl-1">少女耶路撒冷的王位必歸你。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="耶利米書 8:19; 以賽亞書 3:1–7; 耶利米哀歌 4:20"> <span className="pl pl-1">現在你為何大聲哭喊？</span><br /><span className="pl pl-1">是因為你沒有王嗎？</span><br /><span className="pl pl-1">難道你的謀士都死了嗎，</span><br /><span className="pl pl-1">以致你像分娩的婦人一樣痛苦不堪？</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="以賽亞書 48:20; 以賽亞書 52:9–12; 列王紀下 20:18"> <span className="pl pl-1">少女錫安啊，</span><br /><span className="pl pl-1">你要像分娩的婦人一樣輾轉呻吟，</span><br /><span className="pl pl-1">因為你現在要離開這城，</span><br /><span className="pl pl-1">住在荒野，被擄到巴比倫。</span><br /><span className="pl pl-1">在那裡，你將得到解救；</span><br /><span className="pl pl-1">在那裡，耶和華必從敵人手中救贖你。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v11" data-v="11" data-xref="俄巴底亞書 1:12; 以賽亞書 5:25–30; 彌迦書 7:10"> <span className="pl pl-1">現在許多國家一起來攻擊你，說：</span><br /><span className="pl pl-1">「願錫安遭蹂躪，</span><br /><span className="pl pl-1">我們要看著錫安被毀滅。」</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="以賽亞書 55:8; 耶利米書 29:11; 羅馬書 11:33–34"> <span className="pl pl-1">他們卻不知道耶和華的心意，</span><br /><span className="pl pl-1">也不明白祂的計劃。</span><br /><span className="pl pl-1">祂聚集他們，</span><br /><span className="pl pl-1">像把禾捆堆積在麥場一樣。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="以賽亞書 41:15–16; 但以理書 2:44; 撒迦利亞書 9:13–15"> <span className="pl pl-1">耶和華說：</span><br /><span className="pl pl-1">「少女錫安啊，</span><br /><span className="pl pl-1">起來打穀吧！</span><br /><span className="pl pl-1">我要給你鐵角，</span><br /><span className="pl pl-1">我要給你銅蹄。</span><br /><span className="pl pl-1">你要打碎列國，</span><br /><span className="pl pl-1">將他們的不義之財獻給耶和華，</span><br /><span className="pl pl-1">把他們的財富獻給普天下的主。」</span></span>
</div>

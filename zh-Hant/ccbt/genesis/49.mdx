## 雅各的預言

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="民數記 24:14; 耶利米書 23:20; 但以理書 10:14"> 雅各把他的兒子們都叫來，對他們說：「你們到我身邊來，我要把你們將來的遭遇告訴你們。</span>
<span className="v" id="v2" data-v="2" data-xref="詩篇 34:11; 箴言 7:1; 箴言 23:22"> <span className="pl pl-1">「雅各的兒子們啊，</span><br /><span className="pl pl-1">你們要聚在一起聽，</span><br /><span className="pl pl-1">聽你們父親以色列的話。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="申命記 21:17; 詩篇 78:51; 詩篇 105:36"> <span className="pl pl-1">呂便啊，你是我的長子，</span><br /><span className="pl pl-1">是我年輕力壯時生的，</span><br /><span className="pl pl-1">卓有尊榮和力量。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="創世記 35:22; 歷代志上 5:1; 申命記 27:20"> <span className="pl pl-1">可是，你必不再居首位，</span><br /><span className="pl pl-1">因為你放縱情慾，</span><br /><span className="pl pl-1">如沸騰不止的水，</span><br /><span className="pl pl-1">你上了你父親的床，</span><br /><span className="pl pl-1">玷污了我的榻。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="創世記 34:25–31; 創世記 46:10–11; 創世記 29:33–34"> <span className="pl pl-1">「西緬和利未是兄弟，</span><br /><span className="pl pl-1">他們依仗刀劍，殘暴不仁。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="創世記 34:30; 詩篇 26:9; 詩篇 16:9"> <span className="pl pl-1">我的靈不可與他們同謀。</span><br /><span className="pl pl-1">我的心不可與他們聯合。</span><br /><span className="pl pl-1">他們洩憤殺人，</span><br /><span className="pl pl-1">隨意砍斷牛腿的筋。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="約書亞記 19:1–9; 歷代志上 4:24–31; 歷代志上 6:65"> <span className="pl pl-1">他們狂怒兇殘，該受咒詛！</span><br /><span className="pl pl-1">我要使他們分散在雅各的子孫中，</span><br /><span className="pl pl-1">散居在以色列各地。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="希伯來書 7:14; 創世記 27:29; 歷代志上 5:2"> <span className="pl pl-1">「猶大啊，你的兄弟們必讚美你，</span><br /><span className="pl pl-1">你的手必掐住仇敵的頸項，</span><br /><span className="pl pl-1">你父親的兒子必向你下拜。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="民數記 24:9; 民數記 23:24; 啟示錄 5:5"> <span className="pl pl-1">我兒猶大是頭小獅子，</span><br /><span className="pl pl-1">他獵食回來，躺臥如雄獅，</span><br /><span className="pl pl-1">蹲伏如母獅，誰敢驚擾他？</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="路加福音 1:32–33; 民數記 24:17; 以賽亞書 9:6"> <span className="pl pl-1">權杖必不離猶大，</span><br /><span className="pl pl-1">御杖必伴他左右，</span><br /><span className="pl pl-1">直到執掌王權的那位來到，</span><br /><span className="pl pl-1">萬民都必歸順他。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v11" data-v="11" data-xref="以賽亞書 63:1–3; 約珥書 3:18; 啟示錄 7:14"> <span className="pl pl-1">「他把小驢拴在葡萄樹旁，</span><br /><span className="pl pl-1">把驢駒拴在上好的葡萄樹旁；</span><br /><span className="pl pl-1">他在葡萄酒中洗衣服，</span><br /><span className="pl pl-1">在葡萄汁中洗外袍。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="箴言 23:29"> <span className="pl pl-1">他的眼睛比酒烏潤，</span><br /><span className="pl pl-1">他的牙齒比奶潔白。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v13" data-v="13" data-xref="申命記 33:18–19; 創世記 30:20; 約書亞記 19:10–16"> <span className="pl pl-1">「西布倫必安居在海濱，</span><br /><span className="pl pl-1">成為泊船的港口，</span><br /><span className="pl pl-1">他的疆界必伸展到西頓。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="歷代志上 12:32; 創世記 30:18; 申命記 33:18"> <span className="pl pl-1">「以薩迦是頭壯驢，</span><br /><span className="pl pl-1">臥在羊圈中。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 81:6; 馬太福音 23:4; 約書亞記 14:15"> <span className="pl pl-1">他見那地方好作安身之處，</span><br /><span className="pl pl-1">地土肥美，就垂下肩頭，</span><br /><span className="pl pl-1">做了苦役。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v16" data-v="16" data-xref="創世記 30:6; 申命記 33:22; 士師記 18:26–27"> <span className="pl pl-1">「但必治理他的人民，</span><br /><span className="pl pl-1">作以色列的一個支派。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="歷代志上 12:35; 士師記 18:22–31; 士師記 14:1–15"> <span className="pl pl-1">他必成為路邊的蛇，</span><br /><span className="pl pl-1">道旁的毒蛇，</span><br /><span className="pl pl-1">咬傷馬蹄，使騎馬的人墜落。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v18" data-v="18" data-xref="詩篇 119:174; 詩篇 119:166; 彌迦書 7:7"> <span className="pl pl-1">「耶和華啊，</span><br /><span className="pl pl-1">我切切等候你的拯救。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v19" data-v="19" data-xref="創世記 30:11; 歷代志上 5:11–22; 申命記 33:20–21"> <span className="pl pl-1">「迦得必被強盜劫掠，</span><br /><span className="pl pl-1">他卻要反敗為勝追趕他們。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v20" data-v="20" data-xref="申命記 33:24–25; 創世記 30:13; 創世記 46:17"> <span className="pl pl-1">「亞設必有豐美的出產和供君王享用的美味。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v21" data-v="21" data-xref="申命記 33:23; 創世記 30:8; 約書亞記 19:32–39"> <span className="pl pl-1">「拿弗他利是頭自由的母鹿，</span><br /><span className="pl pl-1">養育美麗的小鹿</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「養育美麗的小鹿」或譯「口出佳美之言」。">a</a></sup><br /><span className="pl pl-1">。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v22" data-v="22" data-xref="創世記 41:52; 詩篇 128:3; 詩篇 1:1–3"> <span className="pl pl-1">「約瑟是多結果子的枝條，</span><br /><span className="pl pl-1">長在水泉旁，</span><br /><span className="pl pl-1">他的枝條探出牆外。</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="創世記 37:24; 詩篇 64:3; 詩篇 118:13"> <span className="pl pl-1">弓箭手兇猛地攻擊他，</span><br /><span className="pl pl-1">惡狠狠地射他。</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="詩篇 132:2; 以賽亞書 28:16; 詩篇 132:5"> <span className="pl pl-1">但他手持強弓，</span><br /><span className="pl pl-1">雙臂穩健有力，</span><br /><span className="pl pl-1">因為雅各的大能者出手相助，</span><br /><span className="pl pl-1">祂是以色列的牧者和磐石。</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="創世記 28:13; 創世記 35:11; 腓立比書 4:19"> <span className="pl pl-1">你父親的上帝必幫助你，</span><br /><span className="pl pl-1">全能者必賜你天上的福氣、</span><br /><span className="pl pl-1">地下深淵蘊藏的福氣，</span><br /><span className="pl pl-1">使你子孫興旺、牛羊滿圈。</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="申命記 33:15–16; 哈巴谷書 3:6; 以賽亞書 66:5"> <span className="pl pl-1">你父親的祝福高過亙古的峰巒，</span><br /><span className="pl pl-1">多如永存的群山，</span><br /><span className="pl pl-1">願這一切祝福都臨到約瑟頭上，</span><br /><span className="pl pl-1">臨到這超越眾弟兄的人身上。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v27" data-v="27" data-xref="士師記 20:25; 創世記 35:18; 以西結書 22:27"> <span className="pl pl-1">「便雅憫是匹貪婪的狼，</span><br /><span className="pl pl-1">早晨吞吃獵物，</span><br /><span className="pl pl-1">晚上瓜分戰利品。」</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="啟示錄 7:4; 以斯帖記 8:11; 列王紀上 18:31"> 以上是以色列的十二支派，他們的父親按著他們不同的福分給他們祝福。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="創世記 47:30; 創世記 50:13; 創世記 15:15"> 雅各又囑咐他們說：「我要離世了，你們要把我葬在赫人以弗崙田間的洞裡，讓我與祖先在一起。</span>
<span className="v" id="v30" data-v="30" data-xref="創世記 23:20; 創世記 23:16–18; 創世記 23:8–9"> 那洞穴在迦南的幔利附近的麥比拉田間，是亞伯拉罕向赫人以弗崙買來作墳地的。</span>
<span className="v" id="v31" data-v="31" data-xref="創世記 25:9; 創世記 35:29; 創世記 50:13"> 亞伯拉罕和他的妻子撒拉，以撒和他的妻子利百加都葬在那裡，我把利亞也葬在了那裡。</span>
<span className="v" id="v32" data-v="32" data-xref="創世記 23:17–20"> 那塊田和田間的洞穴是向赫人買的。」</span>
<span className="v" id="v33" data-v="33" data-xref="創世記 49:29; 創世記 25:8; 創世記 35:29"> 雅各囑咐完眾子，把腳收到床上，嚥了氣，歸到他祖先那裡。</span>
</div>

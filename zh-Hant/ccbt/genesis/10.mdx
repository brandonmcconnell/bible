## 挪亞三個兒子的後代

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 2:4; 創世記 9:7; 創世記 5:1"> 洪水以後，挪亞的兒子閃、含和雅弗都生了兒子，以下是他們的後代。</span>
<span className="v" id="v2" data-v="2" data-xref="以西結書 38:2; 以西結書 38:6; 啟示錄 20:8"> 雅弗的兒子是歌篾、瑪各、瑪代、雅完、土巴、米設、提拉。</span>
<span className="v" id="v3" data-v="3" data-xref="以西結書 27:14; 耶利米書 51:27"> 歌篾的兒子是亞實基拿、利法、陀迦瑪。</span>
<span className="v" id="v4" data-v="4" data-xref="但以理書 11:30; 以賽亞書 23:12; 民數記 24:24"> 雅完的兒子是以利沙、他施、基提、多單。</span>
<span className="v" id="v5" data-v="5" data-xref="西番雅書 2:11; 以賽亞書 42:4; 耶利米書 2:10"> 雅弗的這些後代各按宗族、語言和民族分散在沿海自己的國土上。</span>
<span className="v" id="v6" data-v="6" data-xref="歷代志上 1:8–16; 以西結書 27:10; 詩篇 105:23"> 含的兒子是古實、麥西<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「麥西」希伯來文是Mizraim，就是「埃及」，13節亦同。">a</a></sup>、弗、迦南。</span>
<span className="v" id="v7" data-v="7" data-xref="以西結書 27:22; 以西結書 27:15; 以賽亞書 21:13"> 古實的兒子是西巴、哈腓拉、撒弗他、拉瑪、撒弗提迦。拉瑪的兒子是示巴和底但。</span>
<span className="v" id="v8" data-v="8" data-xref="彌迦書 5:6"> 古實也是寧錄之父，寧錄是世上第一位勇士，</span>
<span className="v" id="v9" data-v="9" data-xref="歷代志下 28:22; 創世記 6:11; 創世記 25:27"> 在耶和華眼中是個孔武有力的獵人，因此有俗話說：「要像寧錄那樣在耶和華眼中是個孔武有力的獵人。」</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 11:9; 創世記 11:2; 創世記 14:1"> 他首先在示拿地區的巴別、以力、亞甲、甲尼各地建國，</span>
<span className="v" id="v11" data-v="11" data-xref="彌迦書 5:6; 詩篇 83:8; 那鴻書 1:1"> 後來擴展到亞述，在那裡建立了尼尼微、利河伯、迦拉，</span>
<span className="v" id="v12" data-v="12"> 以及尼尼微與迦拉之間的利鮮大城。</span>
<span className="v" id="v13" data-v="13" data-xref="歷代志上 1:11–12; 耶利米書 46:9; 以西結書 30:5"> 麥西的後代有路低人、亞拿米人、利哈比人、拿弗土希人、</span>
<span className="v" id="v14" data-v="14" data-xref="耶利米書 47:4; 歷代志上 1:12; 申命記 2:23"> 帕斯魯細人、迦斯路希人和迦斐托人。非利士人是迦斐托人的後代。</span>
<span className="v" id="v15" data-v="15" data-xref="民數記 34:2–15; 出埃及記 34:11; 創世記 23:3"> 迦南生長子西頓和次子赫，</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳記下 24:18; 士師記 1:21; 撒迦利亞書 9:7"> 他的後代還有耶布斯人、亞摩利人、革迦撒人、</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 34:2"> 希未人、亞基人、西尼人、</span>
<span className="v" id="v18" data-v="18" data-xref="約書亞記 18:22; 撒母耳記下 8:9; 以西結書 27:8"> 亞瓦底人、洗瑪利人和哈馬人。後來迦南各宗族散居在各地。</span>
<span className="v" id="v19" data-v="19" data-xref="創世記 14:2; 創世記 19:24–25; 約書亞記 12:7–8"> 迦南的疆域從西頓向基拉耳延伸，遠至迦薩，再向所多瑪、蛾摩拉、押瑪、洗扁延伸，遠至拉沙。</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 10:6; 創世記 11:1–9"> 以上記載的都是含的子孫，他們根據自己的宗族、語言、國土和民族散居各處。</span>
<span className="v" id="v21" data-v="21" data-xref="民數記 24:24; 創世記 11:10–26"> 雅弗的哥哥閃是希伯子孫的祖先，他也生了兒子。</span>
<span className="v" id="v22" data-v="22" data-xref="以賽亞書 66:19; 耶利米書 25:25; 創世記 14:1–9"> 閃的兒子是以攔、亞述、亞法撒、路德、亞蘭。</span>
<span className="v" id="v23" data-v="23" data-xref="約伯記 1:1; 耶利米書 25:20"> 亞蘭的兒子是烏斯、戶勒、基帖、瑪施。</span>
<span className="v" id="v24" data-v="24" data-xref="路加福音 3:35; 創世記 11:12–15"> 亞法撒生沙拉，沙拉生希伯，</span>
<span className="v" id="v25" data-v="25" data-xref="歷代志上 1:19; 創世記 10:32; 申命記 32:8"> 希伯有兩個兒子，一個名叫法勒<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="「法勒」意思是「分開」。">b</a></sup>，因為那時人們分地而居。法勒的兄弟叫約坍。</span>
<span className="v" id="v26" data-v="26" data-xref="歷代志上 1:20–28"> 約坍生亞摩答、沙列、哈薩瑪非、耶拉、</span>
<span className="v" id="v27" data-v="27" data-xref="歷代志上 1:20–28"> 哈多蘭、烏薩、德拉、</span>
<span className="v" id="v28" data-v="28" data-xref="歷代志上 1:20–28; 列王紀上 10:1; 創世記 25:3"> 俄巴路、亞比瑪利、示巴、</span>
<span className="v" id="v29" data-v="29" data-xref="列王紀上 9:28; 歷代志上 9:13; 創世記 2:11"> 阿斐、哈腓拉、約巴。這些都是約坍的兒子。</span>
<span className="v" id="v30" data-v="30" data-xref="民數記 23:7"> 他們居住的地方，從米沙直到東邊的西發山區。</span>
<span className="v" id="v31" data-v="31" data-xref="創世記 10:5; 創世記 10:20; 使徒行傳 17:26"> 以上記載的都是閃的子孫，他們按著自己的宗族、語言、國土和民族散居各處。</span>
<span className="v" id="v32" data-v="32" data-xref="創世記 9:19; 使徒行傳 17:26; 創世記 10:1"> 這些人都是洪水以後挪亞三個兒子所生的子孫，他們按著自己的民族和家系散居在各地，繁衍出地上各個民族。</span>

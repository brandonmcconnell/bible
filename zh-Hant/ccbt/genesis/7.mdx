## 洪水氾濫

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="馬太福音 24:37–39; 彼得後書 2:5–9; 創世記 6:9"> 耶和華對挪亞說：「你和你全家都進入方舟，因為這個世代只有你在我眼中是義人。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 8:20; 利未記 10:10; 利未記 11:1–47"> 潔淨的動物，你要每樣帶七公七母，不潔淨的動物每樣帶一公一母，</span>
<span className="v" id="v3" data-v="3"> 飛鳥每樣帶七公七母，叫牠們以後可以在地上繁衍後代。</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 6:13; 創世記 7:12; 創世記 7:17"> 因為七天之後，我要在地上降雨四十晝夜，從地上毀滅我所造的一切活物。」</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 6:22; 路加福音 8:21; 出埃及記 39:32"> 凡耶和華所吩咐的，挪亞都照辦了。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="創世記 5:32; 創世記 8:13"> 洪水在大地上氾濫那年，挪亞六百歲了。</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 17:27; 創世記 6:18; 馬太福音 24:38"> 挪亞與妻子、兒子們和兒媳們都進了方舟，躲避洪水。</span>
<span className="v" id="v8" data-v="8"> 潔淨的動物、不潔淨的動物、飛禽和地上的一切爬蟲，</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 7:16; 創世記 2:19; 耶利米書 8:7"> 都一公一母成對地到挪亞那裡，進了方舟，正如上帝對挪亞的吩咐。</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 6:17; 創世記 7:4; 路加福音 17:27"> 七天過後，洪水在地上氾濫起來。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="創世記 8:2; 瑪拉基書 3:10; 箴言 8:28–29"> 挪亞六百歲那年的二月<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「二月」按猶太曆計算，本卷書所用月份都是按猶太曆計算。">a</a></sup>十七日，所有深淵的泉源都裂開了，天上的水閘也打開了，</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 7:4; 馬太福音 4:2; 創世記 7:17"> 地上大雨降了四十晝夜。</span>
<span className="v" id="v13" data-v="13" data-xref="創世記 6:18; 創世記 7:1; 創世記 6:10"> 就在那天，挪亞與他的兒子閃、含和雅弗，還有挪亞的妻子和三個兒媳婦都進了方舟。</span>
<span className="v" id="v14" data-v="14" data-xref="創世記 7:8–9; 創世記 7:2–3"> 所有的野獸、牲畜、地上的爬蟲和飛鳥，都按種類進入方舟。</span>
<span className="v" id="v15" data-v="15" data-xref="創世記 6:19–20; 以賽亞書 11:6"> 一切有生命氣息的活物都成對地到挪亞那裡，進入方舟。</span>
<span className="v" id="v16" data-v="16" data-xref="馬太福音 25:10; 路加福音 13:25; 詩篇 91:1–10"> 所有進入方舟的動物都是一公一母，正如上帝對挪亞的吩咐。然後，耶和華關上了方舟的門。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="創世記 7:4; 創世記 7:12"> 洪水在地上氾濫了四十天，水不斷往上漲，把方舟漂了起來。</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及記 14:28; 詩篇 69:15; 約伯記 22:16"> 洪水來勢洶洶，淹沒大地，方舟漂浮在水面上。</span>
<span className="v" id="v19" data-v="19" data-xref="詩篇 104:6–9; 詩篇 46:2–3; 彼得後書 3:6"> 水勢越來越大，把天下各處的高山都淹沒了。</span>
<span className="v" id="v20" data-v="20" data-xref="耶利米書 3:23; 詩篇 104:6"> 水淹沒了群山，高出群山七米。</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 6:13; 創世記 7:4; 創世記 6:17"> 地上所有的飛禽、走獸、牲畜、爬蟲等動物和人類都死了。</span>
<span className="v" id="v22" data-v="22" data-xref="創世記 2:7; 創世記 6:17"> 陸地上所有鼻孔有生命氣息的活物都死了。</span>
<span className="v" id="v23" data-v="23" data-xref="彼得後書 2:5; 彼得前書 3:20; 希伯來書 11:7"> 地上的人類、飛禽走獸和爬蟲等一切活物都被毀滅了，只剩下挪亞和跟他同在方舟裡的。</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 8:3–4"> 洪水淹沒大地一百五十天。</span>
</div>
</div>

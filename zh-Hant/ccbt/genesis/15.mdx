## 上帝與亞伯蘭立約

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以賽亞書 41:10; 詩篇 119:114; 詩篇 84:11"> 這些事以後，耶和華在異象中對亞伯蘭說：「亞伯蘭，你不要害怕，我是你的盾牌，我要大大賞賜你。」</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 25:21; 使徒行傳 7:5; 創世記 12:1–3"> 亞伯蘭說：「主耶和華啊，你要賜我什麼呢？我沒有兒子，繼承我家業的人是大馬士革人以利以謝。」</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 14:14; 箴言 29:21; 傳道書 2:7"> 亞伯蘭又說：「你沒有賜我後裔，我家中的僕人將繼承我的產業。」</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 17:16; 加拉太書 4:28; 撒母耳記下 7:12"> 耶和華對他說：「這人不會成為你的繼承人，你親生的兒子才是你的繼承人。」</span>
<span className="v" id="v5" data-v="5" data-xref="希伯來書 11:12; 羅馬書 4:18; 申命記 1:10"> 耶和華把亞伯蘭帶到外面，對他說：「你抬頭看看天空，數數繁星，你能數得盡嗎？」接著又對他說：「你的後裔必這麼多。」</span>
<span className="v" id="v6" data-v="6" data-xref="雅各書 2:23; 加拉太書 3:6–14; 羅馬書 4:9"> 亞伯蘭信耶和華，耶和華便算他為義人。</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 12:1; 使徒行傳 7:2–4; 羅馬書 4:13"> 耶和華又對他說：「我是耶和華，我帶你離開了迦勒底的吾珥，為要把這片土地賜給你作產業。」</span>
<span className="v" id="v8" data-v="8" data-xref="路加福音 1:18; 路加福音 1:34; 以賽亞書 7:11"> 亞伯蘭說：「主耶和華啊，我怎麼知道我會得到這片土地呢？」</span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 2:24; 利未記 14:30; 利未記 14:22"> 耶和華說：「你要給我預備三歲的母牛、母山羊和公綿羊各一頭，斑鳩和雛鴿各一隻。」</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米書 34:18–19; 利未記 1:17; 創世記 15:17"> 亞伯蘭一一照辦，把牲畜都劈成兩半，一半對著一半地擺列，但沒有劈開鳥。</span>
<span className="v" id="v11" data-v="11" data-xref="馬太福音 13:4; 詩篇 119:13; 以西結書 17:3"> 有鷙鳥飛到那些屍體上，亞伯蘭趕走了牠們。</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 2:21; 約伯記 33:15; 但以理書 10:8–9"> 太陽下山的時候，亞伯蘭睡得很沉，忽然有可怕的黑暗籠罩著他。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行傳 7:6–7; 出埃及記 1:11; 出埃及記 12:40–41"> 耶和華對他說：「你要清楚知道，你的後裔必流落異鄉，被奴役和虐待四百年。</span>
<span className="v" id="v14" data-v="14" data-xref="尼希米記 9:9–11; 出埃及記 6:5–6; 出埃及記 12:32–38"> 但我必懲罰那奴役他們的國家，之後他們必帶著大量財物離開那裡。</span>
<span className="v" id="v15" data-v="15" data-xref="約伯記 5:26; 創世記 25:7–9; 歷代志下 34:28"> 而你必享長壽，得到安葬，歸到列祖那裡。</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀上 21:26; 但以理書 8:23; 出埃及記 12:40"> 到了第四代<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「代」希伯來文可能指人一生的年日。">a</a></sup>，你的子孫必重回此地，因為亞摩利人現在還沒有惡貫滿盈。」</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米書 34:18–19; 士師記 6:21; 耶利米書 11:4"> 太陽下山，夜幕降臨，突然有冒煙的火爐和點著的火炬在肉塊中經過。</span>
<span className="v" id="v18" data-v="18" data-xref="約書亞記 1:3–4; 創世記 12:7; 創世記 24:7"> 就在那天，耶和華跟亞伯蘭立約，說：「我必將這片土地賜給你的後裔，從埃及河一直延伸到幼發拉底大河，</span>
<span className="v" id="v19" data-v="19" data-xref="民數記 24:21–22"> 就是基尼人、基尼洗人、甲摩尼人、</span>
<span className="v" id="v20" data-v="20" data-xref="以賽亞書 17:5; 創世記 14:5"> 赫人、比利洗人、利乏音人、</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 10:15–19; 出埃及記 23:23–28; 申命記 7:1"> 亞摩利人、迦南人、革迦撒人和耶布斯人的土地。」</span>
</div>

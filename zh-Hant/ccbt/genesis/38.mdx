## 猶大與她瑪

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳記上 22:1; 列王紀下 4:8; 箴言 13:20"> 那時，猶大離開了他的兄弟們，到亞杜蘭人希拉的家裡住。</span>
<span className="v" id="v2" data-v="2" data-xref="歷代志上 2:3; 創世記 24:3; 創世記 6:2"> 他在那裡遇見了迦南人書亞的女兒，就娶她為妻，與她同房。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 46:12; 民數記 26:19"> 她懷孕生了一個兒子，猶大給他取名叫珥。</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 46:12; 民數記 26:19"> 她又懷孕生了一個兒子，給他取名叫俄南。</span>
<span className="v" id="v5" data-v="5" data-xref="民數記 26:20; 創世記 38:26; 創世記 46:12"> 她再次懷孕生了一個兒子，給他取名叫示拉。示拉是在基悉出生的。</span>
<span className="v" id="v6" data-v="6" data-xref="創世記 24:3; 創世記 21:21; 馬太福音 1:3"> 猶大給長子珥娶了她瑪為妻。</span>
<span className="v" id="v7" data-v="7" data-xref="歷代志上 2:3; 創世記 46:12; 民數記 26:19"> 耶和華見猶大的長子珥邪惡，就取走了他的性命。</span>
<span className="v" id="v8" data-v="8" data-xref="申命記 25:5–10; 馬太福音 22:23–27; 路得記 4:5–11"> 猶大對俄南說：「你要與嫂子她瑪同房，向她盡娶寡嫂的本分，好替你哥哥傳宗接代。」</span>
<span className="v" id="v9" data-v="9" data-xref="提多書 3:3; 申命記 25:6; 雅各書 3:16"> 俄南知道生了兒子也不歸自己，所以每次與她瑪同房都把精液遺在地上，以免給哥哥留後。</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 46:12; 民數記 11:1; 歷代志上 21:7"> 耶和華見俄南行為邪惡，就取走了他的性命。</span>
<span className="v" id="v11" data-v="11" data-xref="利未記 22:13; 路得記 1:11–13"> 猶大恐怕示拉會像他的兩個哥哥一樣死去，就對兒媳她瑪說：「示拉還沒有長大，你先回娘家守寡吧。」她瑪就回娘家去住了。</span>
<span className="v" id="v12" data-v="12" data-xref="約書亞記 15:10; 撒母耳記下 13:39; 士師記 14:1"> 多年後，猶大的妻子，即書亞的女兒死了。喪期過後，猶大就和他的朋友亞杜蘭人希拉去亭拿，到給他剪羊毛的人那裡。</span>
<span className="v" id="v13" data-v="13"> 有人告訴她瑪說：「你公公上亭拿去剪羊毛了。」</span>
<span className="v" id="v14" data-v="14" data-xref="創世記 38:26; 創世記 38:11–13; 耶利米書 3:2"> 她瑪見示拉已經長大，卻仍然沒有娶她，就脫下寡婦的衣服，用帕子蒙上臉，換了裝束，坐在去亭拿路上的伊拿印城門口。</span>
<span className="v" id="v15" data-v="15"> 猶大看見她蒙著臉，以為她是妓女，</span>
<span className="v" id="v16" data-v="16" data-xref="提摩太前書 6:10; 馬太福音 26:15; 撒母耳記下 13:11"> 就走到路邊去找她，說：「你來陪我睡覺吧。」猶大不知道她是自己的兒媳婦。她瑪問道：「我陪你睡覺，你給我什麼呢？」</span>
<span className="v" id="v17" data-v="17" data-xref="以西結書 16:33; 創世記 38:20; 箴言 20:16"> 猶大回答說：「我會從羊群中取一隻山羊羔送給你。」她瑪問道：「羊還沒有送來以前，你給我什麼作抵押呢？」</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 38:25–26; 何西阿書 4:11; 耶利米書 22:24"> 猶大問：「你要什麼作抵押呢？」她瑪說：「我要你的印、印帶和你的手杖。」猶大給了她，然後跟她睡覺。她瑪就懷了孕。</span>
<span className="v" id="v19" data-v="19" data-xref="創世記 38:14; 撒母耳記下 14:5; 撒母耳記下 14:2"> 事後，她瑪起來走了。她拿掉蒙臉的帕子，仍舊穿上寡婦的裝束。</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 20:9; 利未記 19:17; 撒母耳記下 13:3"> 猶大託他的朋友亞杜蘭人送去一隻山羊羔，要從那女人手中換回抵押物，卻找不到她。</span>
<span className="v" id="v21" data-v="21"> 他的朋友就問當地的人：「伊拿印路旁的廟妓在哪裡？」他們回答說：「這裡沒有廟妓。」</span>
<span className="v" id="v22" data-v="22"> 他的朋友只好回去對猶大說：「我找不著她，當地人說那裡沒有廟妓。」</span>
<span className="v" id="v23" data-v="23" data-xref="以弗所書 5:12; 箴言 6:33; 啟示錄 16:15"> 猶大說：「讓她留著我的東西吧，免得我們成為笑柄。反正我把羊送過去了，只是你找不到她。」</span>
<span className="v" id="v24" data-v="24" data-xref="利未記 21:9; 以西結書 23:19; 士師記 19:2"> 大約過了三個月，有人告訴猶大說：「你的兒媳婦她瑪不守婦道，並且懷孕了。」猶大說：「把她拉出來燒死！」</span>
<span className="v" id="v25" data-v="25" data-xref="創世記 37:32; 創世記 38:18; 哥林多前書 4:5"> 他們正要把她拉出來，她請人傳信給她公公，說：「這些東西的主人使我懷了孕，請你看看這印、印帶和杖是誰的？」</span>
<span className="v" id="v26" data-v="26" data-xref="撒母耳記上 24:17; 約翰福音 8:9; 提多書 2:11–12"> 猶大認出是自己的東西，就說：「她比我更有理，因為我沒有讓兒子示拉娶她。」猶大沒有再與她睡覺。</span>
<span className="v" id="v27" data-v="27" data-xref="創世記 25:24"> 她瑪臨產的時候，才知道腹中是一對雙胞胎。</span>
<span className="v" id="v28" data-v="28"> 生產的時候，一個嬰兒先伸出手來，接生婆就把一條紅線繫在他的手上，說：「他是先出生的。」</span>
<span className="v" id="v29" data-v="29" data-xref="歷代志上 2:4; 馬太福音 1:3; 創世記 46:12"> 可是那嬰兒隨後卻把手縮回去，他的胞兄先出生了，接生婆說：「你怎麼衝出來了！」因此，他的名字叫法勒斯<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「法勒斯」意思是「衝出來」。">a</a></sup>。</span>
<span className="v" id="v30" data-v="30" data-xref="歷代志上 9:6; 歷代志上 2:4; 馬太福音 1:3"> 後來，那個手上繫有紅線的孩子也出生了，給他取名叫謝拉<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="「謝拉」意思是「紅色」或「光明」。">b</a></sup>。</span>
</div>

## 上帝與挪亞立約

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 9:7; 創世記 1:28; 創世記 8:17"> 上帝賜福給挪亞和他的兒子們，對他們說：「你們要生養眾多，遍佈地面。</span>
<span className="v" id="v2" data-v="2" data-xref="詩篇 8:4–8; 創世記 1:28; 雅各書 3:7"> 所有地上的走獸和爬蟲、空中的飛鳥及海裡的魚，都必懼怕你們，牠們都歸你們管理。</span>
<span className="v" id="v3" data-v="3" data-xref="羅馬書 14:14; 歌羅西書 2:21–22; 哥林多前書 10:31"> 凡是活的動物都可作你們的食物，就像綠色菜蔬一樣，我把一切都賜給你們了。</span>
<span className="v" id="v4" data-v="4" data-xref="申命記 12:23; 申命記 15:23; 申命記 12:16"> 只是你們不可吃帶血的肉，因為血就是生命。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 21:28–29; 出埃及記 21:12; 創世記 4:9–10"> 凡是殺害你們的，無論人或獸，我必向他們追討血債。凡殺人的，我必追討他的血債。</span>
<span className="v" id="v6" data-v="6" data-xref="利未記 24:17; 馬太福音 26:52; 啟示錄 13:10"> 凡殺害人的，也必被人殺害，因為人是上帝照著自己的形像造的。</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 1:28; 創世記 9:1; 創世記 9:19"> 你們要生養眾多，使地上人口興旺。」</span>
<span className="v" id="v8" data-v="8"> 上帝又對挪亞和他身邊的兒子們說：</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 6:18; 以賽亞書 54:9–10; 羅馬書 1:3"> 「我要跟你們和你們的後代立約，</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 8:1; 創世記 9:15–16; 詩篇 36:5–6"> 包括所有和你們在一起的生物，就是那些和你們一起從方舟出來的飛禽走獸和牲畜。</span>
<span className="v" id="v11" data-v="11" data-xref="以賽亞書 54:9; 創世記 8:21–22; 創世記 7:21–23"> 我與你們立約，不再讓洪水滅絕一切生命，也不再讓洪水毀滅大地。」</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 17:11; 馬太福音 26:26–28; 出埃及記 12:13"> 上帝說：「我與你們及所有和你們在一起的生物立世代永存的約，這是我立約的記號。</span>
<span className="v" id="v13" data-v="13" data-xref="以西結書 1:28; 啟示錄 4:3; 啟示錄 10:1"> 我把彩虹放在雲中，作為我跟大地立約的記號。</span>
<span className="v" id="v14" data-v="14"> 我使雲彩覆蓋大地的時候，會有彩虹在雲中出現。</span>
<span className="v" id="v15" data-v="15" data-xref="申命記 7:9; 以西結書 16:60; 以賽亞書 54:8–10"> 這樣我會顧念我與你們及一切有血氣的生物所立的約，水就不會再氾濫、毀滅所有生命。</span>
<span className="v" id="v16" data-v="16" data-xref="以賽亞書 54:8–10; 耶利米書 32:40; 撒母耳記下 23:5"> 當我看見彩虹在雲中出現的時候，就會顧念我與地上一切活物立的永遠之約。」</span>
<span className="v" id="v17" data-v="17"> 上帝對挪亞說：「這是我與地上一切生命立約的記號。」</span>
</div>
</div>

## 挪亞和他的兒子

<div className="bt">
<div className="bp poetry">
<span className="v" id="v18" data-v="18" data-xref="創世記 10:1; 創世記 10:6; 創世記 9:25–27"> 與挪亞一起出方舟的有他的兒子閃、含、雅弗。含是迦南的父親。</span>
<span className="v" id="v19" data-v="19" data-xref="歷代志上 1:4–28; 創世記 8:17; 創世記 5:32"> 這是挪亞的三個兒子，他們的後代遍佈天下。</span>
<span className="v" id="v20" data-v="20" data-xref="申命記 20:6; 箴言 10:11; 以賽亞書 28:24–26"> 挪亞做了農夫，他是第一個栽種葡萄園的人。</span>
<span className="v" id="v21" data-v="21" data-xref="箴言 20:1; 哈巴谷書 2:15–16; 箴言 23:31–32"> 一天，他喝葡萄酒喝醉了，赤裸著身體躺在帳篷裡。</span>
<span className="v" id="v22" data-v="22" data-xref="箴言 30:17; 加拉太書 6:1; 馬太福音 18:15"> 迦南的父親含看見父親赤身露體，便去告訴外面的兩個弟兄。</span>
<span className="v" id="v23" data-v="23" data-xref="加拉太書 6:1; 出埃及記 20:12; 提摩太前書 5:17"> 於是，閃和雅弗拿了一件衣服搭在肩上，倒退著走進帳篷，把衣服蓋在父親身上，他們背著臉不看父親赤裸的身體。</span>
<span className="v" id="v24" data-v="24"> 挪亞酒醒後，知道了小兒子做的事，</span>
<span className="v" id="v25" data-v="25" data-xref="約書亞記 9:23; 申命記 27:16; 士師記 1:28–30"> 就說：<br /><span className="pl pl-1">「迦南該受咒詛，</span><br /><span className="pl pl-1">必做他弟兄的僕人的僕人。」</span></span>
<span className="v" id="v26" data-v="26" data-xref="詩篇 144:15; 創世記 12:1–3; 路加福音 3:23–36"> 又說：<br /><span className="pl pl-1">「閃的上帝耶和華當受稱頌！</span><br /><span className="pl pl-1">願迦南做閃的僕人。</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="羅馬書 11:12; 羅馬書 15:12; 希伯來書 11:9–10"> <span className="pl pl-1">願上帝擴張雅弗的疆界，</span><br /><span className="pl pl-1">願他住在閃的帳篷裡，</span><br /><span className="pl pl-1">願迦南做他的僕人。」</span></span>
<span className="v" id="v28" data-v="28"> 洪水以後，挪亞又活了三百五十年，</span>
<span className="v" id="v29" data-v="29" data-xref="創世記 5:27; 詩篇 90:10; 創世記 5:32"> 共活了九百五十歲才去世。</span>

## 以撒為兒子祝福

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳記上 3:2; 創世記 48:10; 創世記 25:23–25"> 以撒年老的時候，眼睛昏花，幾乎看不見。他把大兒子以掃叫來，說：「我兒啊！」以掃說：「我在這裡。」</span>
<span className="v" id="v2" data-v="2" data-xref="雅各書 4:14; 傳道書 9:10; 箴言 27:1"> 以撒說：「我年老了，不知道還能活多久。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 25:27–28; 創世記 10:9; 哥林多前書 6:12"> 現在，帶著你的弓箭去田野為我打些野味來，</span>
<span className="v" id="v4" data-v="4" data-xref="希伯來書 11:20; 創世記 48:9; 創世記 49:28"> 照我喜歡的口味，做成美食給我吃，以便我在死前給你祝福。」</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5"> 利百加聽見了以撒跟兒子以掃說的話。以掃出去打獵後，</span>
<span className="v" id="v6" data-v="6" data-xref="創世記 25:28"> 利百加就對她兒子雅各說：「我聽見你父親對你哥哥以掃說，</span>
<span className="v" id="v7" data-v="7" data-xref="約書亞記 6:26; 撒母耳記上 24:19; 申命記 33:1"> 『你去打些野味回來，做成美食給我吃，以便我死之前在耶和華面前給你祝福。』</span>
<span className="v" id="v8" data-v="8" data-xref="以弗所書 6:1; 創世記 27:13; 使徒行傳 5:29"> 現在，我兒，你要聽我的話，照我的吩咐去做。</span>
<span className="v" id="v9" data-v="9" data-xref="士師記 13:15; 撒母耳記上 16:20"> 你到羊群裡牽兩隻上好的山羊羔給我，我好照你父親喜愛的口味做成美食，</span>
<span className="v" id="v10" data-v="10"> 由你拿去給他吃，讓他死前為你祝福。」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="創世記 25:25"> 雅各對母親利百加說：「哥哥以掃渾身是毛，我的皮膚光滑。</span>
<span className="v" id="v12" data-v="12" data-xref="申命記 27:18; 創世記 25:27; 瑪拉基書 1:14"> 如果父親用手摸我，一定會發覺我騙他，那時候我不但得不到祝福，反會招來咒詛。」</span>
<span className="v" id="v13" data-v="13" data-xref="馬太福音 27:25; 撒母耳記上 25:24; 撒母耳記下 14:9"> 他母親利百加對他說：「我兒啊，有咒詛，我來承擔。你只管聽我的話，把羊羔牽來。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="創世記 27:9; 箴言 23:2–3; 創世記 25:28"> 於是，雅各把羊牽來交給母親，他母親就照他父親喜愛的口味做成美食。</span>
<span className="v" id="v15" data-v="15" data-xref="創世記 27:27; 路加福音 20:46; 路加福音 15:22"> 利百加又拿了大兒子以掃留在家裡的最好的衣服，給小兒子雅各穿上，</span>
<span className="v" id="v16" data-v="16"> 再用山羊皮把雅各的手和脖子的光滑處都包起來，</span>
<span className="v" id="v17" data-v="17"> 然後把做好的美味和餅交給兒子雅各。</span>
</div>
<div className="bp poetry">
<span className="v" id="v18" data-v="18"> 雅各來到父親跟前，叫了一聲：「父親。」以撒回答說：「我在這裡，兒子，你是哪一個？」</span>
<span className="v" id="v19" data-v="19" data-xref="以賽亞書 28:15; 馬太福音 26:70–74; 撒迦利亞書 13:3–4"> 雅各對父親說：「我是你的大兒子以掃，你吩咐我的事，我已經辦好了。請你坐起來，吃我打的野味，然後給我祝福。」</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及記 20:7; 約伯記 13:7; 創世記 24:12"> 以撒對他說：「我兒，你怎麼這麼快就打到野味了？」雅各回答說：「因為你的上帝耶和華讓我碰見好機會。」</span>
<span className="v" id="v21" data-v="21" data-xref="雅各書 4:8; 以賽亞書 57:19; 創世記 27:12"> 以撒對雅各說：「我兒，過來，讓我摸摸看你是不是我兒以掃。」</span>
<span className="v" id="v22" data-v="22"> 雅各挨到父親跟前，以撒摸著他說：「聲音是雅各的聲音，手卻是以掃的手。」</span>
<span className="v" id="v23" data-v="23" data-xref="創世記 27:16; 希伯來書 11:20; 羅馬書 9:11–12"> 因為雅各手上有毛，與他哥哥以掃的手一樣，以撒分辨不出來，就給他祝福。</span>
<span className="v" id="v24" data-v="24" data-xref="歌羅西書 3:9; 以弗所書 4:25; 箴言 12:22"> 以撒又問：「你真是我的兒子以掃嗎？」雅各回答說：「我是。」</span>
<span className="v" id="v25" data-v="25" data-xref="創世記 27:4"> 以撒便說：「把你打的野味拿給我，我吃了好為你祝福。」雅各遞上野味，以撒吃了；雅各又拿酒給他喝，他也喝了。</span>
<span className="v" id="v26" data-v="26"> 父親以撒對他說：「我兒，你過來親吻我。」</span>
<span className="v" id="v27" data-v="27" data-xref="希伯來書 6:7; 詩篇 65:10; 希伯來書 11:20"> 雅各就挨上前去親了父親。以撒聞到他衣服上的香氣，就祝福他說：<br /><span className="pl pl-1">「我兒子的香氣就像蒙耶和華賜福之田地的香氣。</span><br /></span>
<span className="v" id="v28" data-v="28" data-xref="申命記 33:28; 申命記 33:13; 詩篇 133:3"> <span className="pl pl-1">願上帝賜你天上的甘露、肥沃的土地並豐富的五穀和新酒。</span><br /></span>
<span className="v" id="v29" data-v="29" data-xref="創世記 12:3; 民數記 24:9; 以賽亞書 49:23"> <span className="pl pl-1">願萬民都侍奉你，</span><br /><span className="pl pl-1">萬國都向你下拜。</span><br /><span className="pl pl-1">願你成為你弟兄的主人，</span><br /><span className="pl pl-1">願你母親的兒子向你下拜。</span><br /><span className="pl pl-1">咒詛你的，願他受咒詛；</span><br /><span className="pl pl-1">祝福你的，願他蒙祝福。」</span></span>
</div>
</div>

## 以掃求父親祝福

<div className="bt">
<div className="bp">
<span className="v" id="v30" data-v="30"> 雅各接受了以撒的祝福才剛離開，他的哥哥以掃就打獵回來了。</span>
<span className="v" id="v31" data-v="31" data-xref="創世記 27:4"> 以掃也作好美味，拿到父親跟前，說：「父親，請起來吃你兒子打的野味，好給我祝福。」</span>
<span className="v" id="v32" data-v="32" data-xref="創世記 27:18"> 他父親以撒問道：「你是誰？」以掃回答說：「我是你的兒子，你的長子以掃。」</span>
<span className="v" id="v33" data-v="33" data-xref="創世記 28:3–4; 羅馬書 11:29; 以弗所書 1:3"> 以撒驚得劇烈顫抖，說：「在你來之前拿野味給我吃的是誰呢？我已經吃了，也給那人祝福了，他將來必蒙祝福。」</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="希伯來書 12:17; 箴言 1:31; 撒母耳記上 30:4"> 以掃聽了放聲痛哭，說：「父親啊，求你也為我祝福！」</span>
<span className="v" id="v35" data-v="35" data-xref="帖撒羅尼迦前書 4:6; 約伯記 13:7; 瑪拉基書 2:10"> 以撒說：「你弟弟已經用詭計把你的福分奪去了。」</span>
<span className="v" id="v36" data-v="36" data-xref="創世記 25:26; 約翰福音 1:47; 創世記 32:28"> 以掃說：「怪不得他叫雅各，他已經騙了我兩次，先前把我長子的名分奪去，現在又奪去我的福分！」接著他對父親說：「難道你沒有留下別的祝福可以給我嗎？」</span>
</div>
<div className="bp poetry">
<span className="v" id="v37" data-v="37" data-xref="撒母耳記下 8:14; 創世記 27:28–29; 創世記 25:23"> 以撒對以掃說：「我已經立他做你的主人，使他的眾弟兄做他的僕人，並給他五穀和新酒。我兒啊，我還能為你做什麼呢？」</span>
<span className="v" id="v38" data-v="38" data-xref="希伯來書 12:17; 創世記 27:34; 以賽亞書 65:14"> 以掃對父親說：「父親啊，你只有一個祝福嗎？父親啊，求你也為我祝福！」以掃又放聲大哭。</span>
<span className="v" id="v39" data-v="39" data-xref="創世記 27:28; 希伯來書 11:20; 約書亞記 24:4"> 以撒對他說：<br /><span className="pl pl-1">「你住的地方必遠離肥沃的土地，</span><br /><span className="pl pl-1">也不會有天上的甘霖。</span><br /></span>
<span className="v" id="v40" data-v="40" data-xref="列王紀下 8:20–22; 創世記 25:23; 歷代志下 25:11–12"> <span className="pl pl-1">你必倚靠刀劍生活，</span><br /><span className="pl pl-1">又必服侍你的弟弟。</span><br /><span className="pl pl-1">到你無法忍受的時候，</span><br /><span className="pl pl-1">必掙脫他放在你頸上的軛。」</span></span>
</div>
</div>

## 雅各逃往舅父家

<div className="bt">
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="約翰一書 3:12–15; 創世記 37:4; 創世記 50:3–4"> 以掃因為父親把祝福給了雅各，就對雅各懷恨在心，暗自思量說：「父親已經不久人世，我服完喪就把我弟弟雅各殺掉！」</span>
<span className="v" id="v42" data-v="42" data-xref="創世記 37:18–20; 撒母耳記上 30:5; 創世記 42:21–22"> 大兒子以掃的計謀傳到利百加耳中。她就派人把小兒子雅各叫來，對他說：「你哥哥以掃想要殺你洩憤！</span>
<span className="v" id="v43" data-v="43" data-xref="創世記 27:8; 創世記 11:31; 創世記 27:13"> 我兒，聽我的話，現在就逃到哈蘭我哥哥拉班那裡，</span>
<span className="v" id="v44" data-v="44" data-xref="創世記 31:38; 創世記 31:41"> 與他住些日子，一直住到你哥哥的氣消了。</span>
<span className="v" id="v45" data-v="45" data-xref="箴言 19:21; 創世記 4:8–16; 創世記 9:5–6"> 等他對你的氣消了，忘了你對他所做的事，我會派人接你回來。我何必在一天之內失去你們兩個呢？」</span>
<span className="v" id="v46" data-v="46" data-xref="創世記 24:3; 創世記 26:34–35; 創世記 28:8"> 利百加對以撒說：「我被這些赫人女子煩死了。如果雅各也娶那些赫人女子為妻，我活著還有什麼意思呢？」</span>
</div>
</div>

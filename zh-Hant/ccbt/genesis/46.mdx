## 以色列全家下埃及

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 28:13; 創世記 26:22–25; 創世記 28:10"> 以色列帶著他所有的一切來到別示巴，向他父親以撒的上帝獻祭。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 15:1; 約伯記 33:14–15; 約伯記 4:13"> 晚上，上帝在異象中對他說：「雅各！雅各！」他說：「我在這裡。」</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 12:2; 申命記 26:5; 以賽亞書 43:1–2"> 上帝說：「我是上帝，是你父親的上帝，不要害怕下到埃及，因為我要使你在那裡成為大族。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及記 3:8; 創世記 28:15; 創世記 48:21"> 我必跟你一起下到埃及，也必帶領你回來，約瑟必為你送終。」</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 45:21; 創世記 45:19; 創世記 45:27"> 於是，雅各從別示巴啟程。以色列的兒子們帶著父親和妻兒，乘坐法老派來的車，</span>
<span className="v" id="v6" data-v="6" data-xref="約書亞記 24:4; 以賽亞書 52:4; 使徒行傳 7:15"> 帶著在迦南獲得的牲畜和財物前往埃及。這樣，雅各帶著他所有的子孫，</span>
<span className="v" id="v7" data-v="7"> 就是他的兒子、孫子、女兒和孫女一起去了埃及。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及記 1:1–5; 申命記 33:6; 歷代志上 2:1–55"> 以下是去埃及的以色列人，即雅各和他後代的名字。 雅各的長子是呂便，</span>
<span className="v" id="v9" data-v="9"> 呂便的兒子是哈諾、法路、希斯倫和迦米。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及記 6:15; 創世記 29:33; 創世記 28:1"> 西緬的兒子是耶姆利、雅憫、阿轄、雅斤、瑣轄和迦南女子生的掃羅。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 29:34; 歷代志上 6:16; 民數記 8:1–26"> 利未的兒子是革順、哥轄和米拉利。</span>
<span className="v" id="v12" data-v="12" data-xref="歷代志上 4:21; 創世記 38:10; 創世記 29:35"> 猶大的兒子是珥、俄南、示拉、法勒斯和謝拉，珥和俄南死在了迦南，法勒斯的兒子是希斯崙和哈姆勒。</span>
<span className="v" id="v13" data-v="13" data-xref="歷代志上 12:32; 創世記 35:23; 創世記 30:14–18"> 以薩迦的兒子是陀拉、普瓦、約伯和伸崙。</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 33:18–19; 民數記 26:26–27; 民數記 1:30–31"> 西布倫的兒子是西烈、以倫和雅利。</span>
<span className="v" id="v15" data-v="15" data-xref="創世記 29:32–35; 創世記 30:17–21; 創世記 34:1–31"> 這些都是利亞在巴旦·亞蘭給雅各生的兒孫，加上女兒底娜共有三十三人。</span>
<span className="v" id="v16" data-v="16" data-xref="民數記 26:15–17; 創世記 30:11; 民數記 1:24–25"> 迦得的兒子是洗非芸、哈基、書尼、以斯本、以利、亞羅底和亞列利。</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 49:20; 創世記 30:13; 民數記 1:13"> 亞設的兒子是音拿、亦施瓦、亦施韋、比利亞和他們的妹妹西拉，比利亞的兒子是希別和瑪結。</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 29:24; 創世記 35:26; 創世記 30:9–13"> 這些是悉帕給雅各生的兒孫，共有十六人，悉帕是拉班給女兒利亞的婢女。</span>
<span className="v" id="v19" data-v="19" data-xref="創世記 44:27; 創世記 29:18; 創世記 35:24"> 雅各的妻子拉結生的兒子是約瑟和便雅憫。</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 41:50–52; 創世記 41:45; 申命記 33:13–17"> 約瑟在埃及生的兒子是瑪拿西和以法蓮，他們的母親是安城祭司波提非拉的女兒亞西納。</span>
<span className="v" id="v21" data-v="21" data-xref="歷代志上 7:6–12; 歷代志上 8:1–7; 民數記 26:38–40"> 便雅憫的兒子是比拉、比結、亞實別、基拉、乃幔、以希、羅實、姆平、戶平和亞勒。</span>
<span className="v" id="v22" data-v="22"> 這些是拉結給雅各生的兒孫，共有十四人。</span>
<span className="v" id="v23" data-v="23" data-xref="民數記 1:38–39; 創世記 49:16–17; 民數記 1:12"> 但的兒子是戶伸。</span>
<span className="v" id="v24" data-v="24" data-xref="歷代志上 7:13; 民數記 1:42–43; 創世記 35:25"> 拿弗他利的兒子是雅薛、沽尼、耶色和示冷。</span>
<span className="v" id="v25" data-v="25" data-xref="創世記 29:29; 創世記 35:25; 創世記 30:3–8"> 這些是辟拉給雅各生的兒孫，共有七人，辟拉是拉班給女兒拉結的婢女。</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及記 1:5; 創世記 35:11; 士師記 8:30"> 跟雅各一同到埃及去的兒孫共有六十六人，他的兒媳婦不算在內。</span>
<span className="v" id="v27" data-v="27" data-xref="申命記 10:22; 使徒行傳 7:14; 出埃及記 1:5"> 加上約瑟在埃及生的兩個兒子，雅各一家來到埃及的共有七十人。</span>
<span className="v" id="v28" data-v="28" data-xref="創世記 45:10; 創世記 44:16–34; 創世記 49:8"> 雅各派猶大先去見約瑟，請他派人引路到歌珊去。他們來到歌珊，</span>
<span className="v" id="v29" data-v="29" data-xref="路加福音 15:20; 創世記 45:14–15; 創世記 33:4"> 約瑟備好車前去迎接父親以色列。父子重逢，約瑟抱住父親哭了很久。</span>
<span className="v" id="v30" data-v="30" data-xref="路加福音 2:29–30; 創世記 45:28"> 以色列對約瑟說：「我現在看到你還活著，就是死也安心了。」</span>
<span className="v" id="v31" data-v="31" data-xref="創世記 47:1–3; 希伯來書 2:11; 使徒行傳 18:3"> 約瑟對他的弟兄們和其他家人說：「我要上奏法老，『我在迦南的弟兄和父親全家已經來到我這裡。</span>
<span className="v" id="v32" data-v="32" data-xref="創世記 47:3; 列王紀上 9:27; 列王紀上 18:5–6"> 他們是牧人，以畜牧為業，已經把羊群、牛群和所有的一切都帶來了。』</span>
<span className="v" id="v33" data-v="33" data-xref="創世記 46:32; 創世記 47:2–4; 約拿書 1:8"> 等法老召見你們，問你們以什麼為業，</span>
<span className="v" id="v34" data-v="34" data-xref="出埃及記 8:26; 創世記 43:32; 創世記 46:32"> 你們要說，『僕人們跟我們的祖先一樣，從小以畜牧為業。』這樣，你們就可以住在歌珊，因為埃及人厭惡牧羊的。」</span>

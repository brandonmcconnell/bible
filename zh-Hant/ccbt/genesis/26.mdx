## 以撒寄居基拉耳

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 12:10; 創世記 25:11; 創世記 21:22–32"> 亞伯拉罕在世的時候，那地方鬧過一次饑荒，這時又遭遇饑荒。以撒就遷到基拉耳的非利士王亞比米勒那裡。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 12:7; 詩篇 37:3; 創世記 17:1"> 耶和華向以撒顯現說：「不要下埃及去，要住在我指示你住的地方。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 28:15; 詩篇 105:9; 創世記 17:8"> 你寄居在這裡，我必與你同在，賜福給你，因為我必把這些土地賜給你和你的後代，堅立我對你父親亞伯拉罕的誓約。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行傳 3:25; 創世記 15:5; 創世記 22:17–18"> 我必使你的後代多如天上的繁星，將這些土地都賜給他們，天下萬國必因你的後裔而蒙福。</span>
<span className="v" id="v5" data-v="5" data-xref="馬太福音 7:24; 創世記 22:18; 創世記 22:16"> 因為亞伯拉罕聽從我的話，遵守我的吩咐、命令、典章和律法。」</span>
</div>
</div>

## 亞比米勒斥責以撒

<div className="bt">
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="創世記 20:1"> 於是，以撒就在基拉耳住下來。</span>
<span className="v" id="v7" data-v="7" data-xref="箴言 29:25; 創世記 12:13; 創世記 20:2"> 那裡的人問起他的妻子時，他便說：「她是我妹妹。」他不敢說：「她是我妻子。」他擔心當地的人會因為利百加而殺害他，因為利百加長得非常美麗。</span>
<span className="v" id="v8" data-v="8" data-xref="以賽亞書 62:5; 箴言 5:18–19; 箴言 7:6"> 以撒在那裡住了許久。一天，非利士王亞比米勒從窗口看見以撒在愛撫利百加，</span>
<span className="v" id="v9" data-v="9"> 便召見以撒，問他：「她明明是你妻子，為什麼你說她是你妹妹呢？」以撒回答說：「我擔心別人為了她而殺害我！」</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 20:9–10; 創世記 12:18–19"> 亞比米勒說：「你怎麼可以這樣對我們呢？萬一百姓中有人佔有了她，你就使我們陷入罪中了。」</span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 105:15; 創世記 20:6; 箴言 6:29"> 於是，亞比米勒下令全國：「凡傷害他們二人的，必被處死。」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="馬可福音 4:8; 創世記 24:1; 創世記 26:3"> 以撒在那裡耕種，耶和華賜福給他，那一年他得了百倍的收成。</span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 112:3; 箴言 10:22; 創世記 24:35"> 他的財富越來越多，成了大富戶。</span>
<span className="v" id="v14" data-v="14" data-xref="創世記 37:11; 創世記 13:2; 箴言 27:4"> 他擁有很多的牛羊和僕婢，非利士人嫉妒他。</span>
<span className="v" id="v15" data-v="15" data-xref="創世記 21:30; 創世記 21:25"> 他父親亞伯拉罕生前派人挖的那些水井，全被非利士人用土塞住了。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 1:9"> 亞比米勒對以撒說：「請你離開我們吧，因為你太強盛了。」</span>
<span className="v" id="v17" data-v="17"> 以撒就離開那裡，把帳篷遷往基拉耳谷居住。</span>
<span className="v" id="v18" data-v="18" data-xref="撒迦利亞書 13:2; 何西阿書 2:17; 民數記 32:38"> 他的父親亞伯拉罕生前挖的水井都被非利士人塞住了，以撒便重新挖開，並沿用父親生前給那些水井起的名字。</span>
<span className="v" id="v19" data-v="19" data-xref="約翰福音 4:10–11; 約翰福音 7:38; 雅歌 4:15"> 以撒的牧人在谷中挖得一口活水井，</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 21:25"> 基拉耳的牧人與以撒的牧人爭吵起來，都說：「這口井是我們的。」於是，以撒便稱那口井為埃色<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「埃色」意思是「相爭」。">a</a></sup>，因為他們與他相爭。</span>
<span className="v" id="v21" data-v="21" data-xref="以斯拉記 4:6"> 後來，以撒的僕人又挖了一口井，他們雙方又為那口井發生爭執，以撒便稱那口井為西提拿<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="「西提拿」意思是「敵對」。">b</a></sup>。</span>
<span className="v" id="v22" data-v="22" data-xref="創世記 17:6; 出埃及記 1:7; 詩篇 118:5"> 以撒離開那裡，又挖了一口水井。這次，他們沒有為那口井爭吵。所以，以撒稱那口井為利河伯<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="「利河伯」意思是「寬闊之地」。">c</a></sup>。以撒說：「如今耶和華給了我們一個寬闊的地方，我們可以在這裡繁榮興旺。」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="士師記 20:1; 創世記 21:31; 創世記 46:1"> 以撒從那裡上別示巴去。</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 15:1; 出埃及記 3:6; 以賽亞書 43:1–2"> 當晚，耶和華向他顯現說：「我是你父親亞伯拉罕的上帝。你不要害怕，因為我與你同在。為了我僕人亞伯拉罕的緣故，我必賜福給你，使你人丁興旺。」</span>
<span className="v" id="v25" data-v="25" data-xref="創世記 13:18; 詩篇 116:17; 創世記 12:7–8"> 以撒在那裡築了一座壇求告耶和華的名，並且在那裡搭起帳篷住下來。他的僕人又在那裡挖了一口井。</span>
</div>
</div>

## 以撒和亞比米勒起誓立約

<div className="bt">
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="創世記 21:22–32; 創世記 20:3"> 一天，亞比米勒帶著他的參謀亞戶撒、將領非各從基拉耳來見以撒。</span>
<span className="v" id="v27" data-v="27" data-xref="創世記 26:16; 士師記 11:7; 使徒行傳 7:14"> 以撒說：「你們既然憎恨我，把我趕走，為什麼又來找我？」</span>
<span className="v" id="v28" data-v="28" data-xref="創世記 21:22–23; 以賽亞書 45:14; 以賽亞書 61:9"> 他們回答說：「我們清楚知道耶和華與你同在，我們雙方應該訂立誓約。我們要跟你立約，</span>
<span className="v" id="v29" data-v="29" data-xref="創世記 24:31; 創世記 21:22; 創世記 22:17"> 使你不傷害我們，就像我們沒有侵犯你，總是善待你，讓你平安地離開一樣。你是蒙耶和華賜福的人。」</span>
<span className="v" id="v30" data-v="30" data-xref="創世記 19:3; 羅馬書 12:18; 希伯來書 12:14"> 於是，以撒為他們擺設宴席，一同吃喝。</span>
<span className="v" id="v31" data-v="31" data-xref="撒母耳記上 20:16–17; 希伯來書 6:16; 創世記 25:33"> 第二天早晨，以撒和他們互相起誓之後，送他們平安地離去。</span>
<span className="v" id="v32" data-v="32" data-xref="箴言 10:4; 箴言 13:4; 箴言 2:4–5"> 當天，以撒的僕人將挖井的事告訴他，說：「我們找到水了。」</span>
<span className="v" id="v33" data-v="33" data-xref="創世記 21:31; 創世記 26:28"> 以撒便稱那口井為示巴<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="「示巴」意思是「誓約」。">d</a></sup>，因此那城叫別示巴，沿用至今。</span>
</div>
</div>

## 以掃娶妻

<div className="bt">
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="創世記 36:2; 創世記 36:13; 出埃及記 34:16"> 以掃四十歲時，娶了赫人比利的女兒猶蒂與赫人以倫的女兒巴實抹。</span>
<span className="v" id="v35" data-v="35" data-xref="創世記 27:46–2; 創世記 28:8; 創世記 6:2"> 她們二人常使以撒和利百加傷心。</span>
</div>

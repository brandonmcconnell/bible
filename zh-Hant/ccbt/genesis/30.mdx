<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="約伯記 5:2; 創世記 29:31; 創世記 37:11"> 拉結見自己沒有給雅各生孩子，就嫉妒姐姐。她對雅各說：「你給我孩子，不然我還不如死了！」</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 16:2; 詩篇 127:3; 列王紀下 5:7"> 雅各氣憤地說：「使你不能生育的是上帝，難道我能代替上帝嗎？」</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 50:23; 約伯記 3:12; 路得記 4:11"> 拉結說：「你去跟我的婢女辟拉同房吧，讓她替我生孩子，我也可以藉她留後。」</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 35:22; 創世記 21:10; 撒母耳記下 12:11"> 於是拉結把婢女辟拉給丈夫做妾，雅各和辟拉同房。</span>
<span className="v" id="v5" data-v="5"> 辟拉懷了孕，為雅各生下一個兒子。</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米哀歌 3:59; 詩篇 35:24; 詩篇 43:1"> 拉結說：「上帝為我伸冤，也聽了我的懇求，賜給我一個兒子。」拉結就給孩子取名叫但<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「但」意思是「伸冤」。">a</a></sup>。</span>
<span className="v" id="v7" data-v="7"> 拉結的婢女辟拉又懷孕，為雅各生了第二個兒子。</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 32:24–25; 創世記 23:6; 創世記 49:21"> 拉結說：「我跟姐姐激烈相爭，我得勝了。」她就給這孩子取名叫拿弗他利<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="「拿弗他利」意思是「相爭」。">b</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="創世記 30:4; 創世記 30:17; 創世記 29:35"> 利亞見自己不再生育，就把婢女悉帕給雅各做妾。</span>
<span className="v" id="v10" data-v="10"> 利亞的婢女悉帕給雅各生了一個兒子。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 49:19; 以賽亞書 65:11; 創世記 35:26"> 利亞說：「真幸運！」她便給孩子取名叫迦得<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="「迦得」意思是「幸運」。">c</a></sup>。</span>
<span className="v" id="v12" data-v="12"> 利亞的婢女悉帕又給雅各生了第二個兒子，</span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 1:48; 箴言 31:28; 雅歌 6:9"> 利亞說：「我真有福啊！婦女們會說我有福！」她就為孩子取名叫亞設<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="「亞設」意思是「有福」。">d</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="雅歌 7:13; 創世記 25:30"> 在收麥子的季節，呂便在田間找到一些風茄，拿回家給母親利亞。拉結對利亞說：「請給我一些你兒子找到的風茄。」</span>
<span className="v" id="v15" data-v="15" data-xref="民數記 16:13; 哥林多前書 4:3; 民數記 16:9–10"> 利亞說：「你搶了我丈夫還不夠嗎？現在還要搶我兒子的風茄嗎？」拉結回答說：「你給我風茄，今夜雅各就跟你同房。」</span>
<span className="v" id="v16" data-v="16"> 那天晚上，雅各從田間回來，利亞就出來迎接他說：「你要來跟我同房，因為我已經用兒子的風茄把你雇下來了。」於是，那天晚上雅各便跟利亞同房。</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 30:6; 創世記 30:22; 出埃及記 3:7"> 上帝答應利亞的祈求，使她懷孕，為雅各生了第五個兒子。</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 49:14–15; 申命記 33:18; 創世記 46:13"> 利亞說：「我把婢女送給丈夫，現在上帝給我報酬了。」因此，她就為孩子取名叫以薩迦<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="「以薩迦」意思是「報酬」。">e</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19"> 後來，利亞又懷孕，給雅各生下第六個兒子。</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 35:23; 馬太福音 4:13; 創世記 49:13"> 她說：「上帝賜給我珍貴的禮物，現在我丈夫會尊重我，因為我給他生了六個兒子。」於是，她就給這個兒子取名叫西布倫<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="「西布倫」意思是「尊重」。">f</a></sup>。</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 34:1–3; 創世記 34:26; 創世記 46:15"> 後來，利亞又生了一個女兒，給她取名叫底娜。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="創世記 29:31; 詩篇 113:9; 詩篇 127:3"> 上帝眷顧拉結，聽了她的禱告，使她可以生育。</span>
<span className="v" id="v23" data-v="23" data-xref="路加福音 1:25; 創世記 29:31; 路加福音 1:27"> 她就懷孕，生了一個兒子，說：「上帝除去了我的羞辱。」</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 49:22–26; 創世記 35:24; 創世記 37:2"> 她給孩子取名叫約瑟<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="「約瑟」意思是「增添」。">g</a></sup>，說：「願上帝再給我添一個兒子！」</span>
</div>
</div>

## 雅各與拉班的協議

<div className="bt">
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="創世記 24:54; 創世記 24:56; 創世記 28:15"> 拉結生約瑟以後，雅各對拉班說：「請讓我走吧！我好回故鄉，</span>
<span className="v" id="v26" data-v="26" data-xref="創世記 29:30; 何西阿書 12:12; 創世記 31:26"> 請把我的妻兒給我，我好離開。她們都是我替你工作得來的，你知道我怎樣努力為你工作。」</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="路得記 2:13; 使徒行傳 7:10; 以賽亞書 61:9"> 拉班卻挽留他，說：「如果你肯賞光，請你留下來！因為我占卜得知上帝為了你的緣故才賜福給我。</span>
<span className="v" id="v28" data-v="28" data-xref="創世記 29:15; 創世記 29:19"> 你要多少酬勞，只管說出來，我一定會給你。」</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="創世記 31:6; 創世記 31:38–40; 彼得前書 2:18"> 雅各回答說：「你知道我怎樣努力地服侍你，照顧你的牲畜。</span>
<span className="v" id="v30" data-v="30" data-xref="提摩太前書 5:8; 哥林多後書 12:14; 申命記 11:10"> 我來以前，你的財產很少。耶和華因為我的到來而賜福給你，使你財產大增。但我自己什麼時候才能興家立業呢？」</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="撒母耳記下 21:4–6; 希伯來書 13:5; 詩篇 118:8"> 拉班問：「我該給你什麼呢？」雅各說：「你不用給我什麼，只要你答應一件事，我就繼續照料你的羊群。</span>
<span className="v" id="v32" data-v="32" data-xref="創世記 31:8; 創世記 31:10; 創世記 30:35"> 今天讓我走遍你的羊群，從中挑出有斑點的綿羊、黑色的小羊和有斑點的山羊作為我的薪酬。</span>
<span className="v" id="v33" data-v="33" data-xref="出埃及記 13:14; 撒母耳記下 22:21; 撒母耳記上 26:23"> 以後，如果你在給我作薪酬的羊群中查出沒有斑點的山羊或非黑色的綿羊，就算是我偷的。這樣你可以知道我是否誠實。」</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="哥林多前書 7:7; 民數記 22:29; 哥林多前書 14:5"> 拉班說：「好，就照你的話做！」</span>
<span className="v" id="v35" data-v="35" data-xref="創世記 31:9"> 當天，拉班把有條紋或斑點的公山羊以及有斑點或夾雜白紋的母山羊，連同黑色的綿羊都挑出來，交給自己的兒子們看管。</span>
<span className="v" id="v36" data-v="36"> 然後，他離開雅各，彼此相隔三天的路程。雅各繼續為他照料其餘的羊。</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="創世記 31:9–13; 以西結書 31:8"> 雅各折下一些楊樹、杏樹和楓樹的嫩枝，削掉部分樹皮，露出白色的條紋，</span>
<span className="v" id="v38" data-v="38"> 然後把這些嫩枝插在羊喝水的水槽和水溝裡。羊群來喝水時互相交配。</span>
<span className="v" id="v39" data-v="39" data-xref="出埃及記 12:35–36; 創世記 31:9–12; 創世記 31:40"> 牠們對著這些樹枝交配，就生下有條紋和有斑點的羊羔。</span>
<span className="v" id="v40" data-v="40"> 雅各把這些羊羔分出來，又讓羊群對著拉班那些有條紋和黑色的羊。他把自己的羊安置在一處，不與拉班的羊摻雜在一起。</span>
<span className="v" id="v41" data-v="41"> 每當肥壯的羊交配時，雅各就把有條紋的枝子插在水溝裡，使羊對著樹枝交配。</span>
<span className="v" id="v42" data-v="42"> 但如果交配的羊是瘦弱的，他就不插枝子。這樣，瘦弱的羊歸拉班，肥壯的羊歸雅各。</span>
<span className="v" id="v43" data-v="43" data-xref="創世記 24:35; 創世記 30:30; 創世記 26:13–14"> 因此，雅各變得極其富有，擁有很多羊、駱駝、驢和僕婢。</span>
</div>
</div>

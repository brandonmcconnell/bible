## 約瑟為法老解夢

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 20:3; 創世記 29:14; 出埃及記 4:9"> 兩年後，法老做了個夢，夢見自己站在尼羅河邊，</span>
<span className="v" id="v2" data-v="2" data-xref="以賽亞書 19:6"> 有七頭肥美、健壯的母牛從河裡上來，在蘆葦叢中吃草。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 41:20–21; 創世記 41:4"> 隨後又有七頭醜陋、瘦弱的母牛從河裡上來，與那七頭母牛一同站在河邊。</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀上 3:15"> 後來，七頭醜陋、瘦弱的母牛吃掉了七頭肥美、健壯的母牛。這時，法老醒了過來。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="申命記 32:14"> 之後，他又睡著了，又做了個夢。他夢見一株麥子上長了七個飽滿的穗子。</span>
<span className="v" id="v6" data-v="6" data-xref="以西結書 17:10; 何西阿書 13:15; 以西結書 19:12"> 後來這株麥子上面又長了七個乾癟的穗子，它們被東風吹焦了。</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 37:5; 創世記 20:3"> 七個乾癟的穗子吞食了七個飽滿的穗子。法老醒過來，原來是一場夢。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="但以理書 4:7; 出埃及記 7:22; 馬太福音 2:1"> 早上法老心中不安，就派人召來埃及所有的術士和智者，把夢告訴他們，可是沒有一個人能為他解夢。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="創世記 40:14; 創世記 40:23; 創世記 40:1–3"> 這時酒侍對法老說：「我今天才想起我的罪過。</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 39:20; 創世記 40:2–3; 創世記 37:36"> 我從前和膳司惹法老生氣，被他囚禁在護衛長府內的牢裡。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 40:5–8"> 一天晚上，我倆都做了夢，我們的夢各有不同的意思。</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 40:12–19; 創世記 37:36; 創世記 39:1"> 當時有一個希伯來青年跟我們一起被囚在牢裡，他是護衛長的僕人。我們把夢告訴他，他就分別為我們解夢。</span>
<span className="v" id="v13" data-v="13" data-xref="以西結書 43:3; 創世記 40:20–22; 創世記 40:12"> 後來，他為我們解的夢都應驗了，我恢復了原職，膳司被掛在木頭上處死了。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="但以理書 2:25; 詩篇 113:7–8; 詩篇 105:19–22"> 於是，法老派人去召約瑟，他們急忙從牢裡釋放約瑟。約瑟剃頭刮臉，更換衣服，去見法老。</span>
<span className="v" id="v15" data-v="15" data-xref="但以理書 5:16; 但以理書 5:12; 詩篇 25:14"> 法老對約瑟說：「我做了一個夢，沒有人能為我解夢。我聽說你能解夢。」</span>
<span className="v" id="v16" data-v="16" data-xref="哥林多後書 3:5; 創世記 40:8; 但以理書 2:47"> 約瑟回答說：「我自己不會解夢，但上帝卻能給王圓滿的解釋。」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17"> 法老對約瑟說：「我夢見自己站在尼羅河邊，</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米書 24:8; 耶利米書 24:1–3; 耶利米書 24:5"> 有七頭肥美、健壯的母牛從河裡上來，在蘆葦叢中吃草。</span>
<span className="v" id="v19" data-v="19"> 隨後又有七頭醜陋、瘦弱的母牛從河裡上來，我在全埃及從來沒有見過有這麼醜陋的牛。</span>
<span className="v" id="v20" data-v="20"> 這些醜陋、瘦弱的母牛吃掉先前的七頭肥母牛。</span>
<span className="v" id="v21" data-v="21" data-xref="以西結書 3:3; 詩篇 37:19; 啟示錄 10:9–10"> 可是，牠們吃了以後就像沒吃一樣，仍然和以前一樣醜陋。這時，我就醒了。</span>
<span className="v" id="v22" data-v="22"> 後來我又夢見一株麥子，上面長了七個飽滿的穗子，</span>
<span className="v" id="v23" data-v="23" data-xref="詩篇 129:6–7; 何西阿書 13:15; 列王紀下 19:26"> 接著又長出七個被東風吹焦的乾癟穗子，</span>
<span className="v" id="v24" data-v="24" data-xref="但以理書 4:7; 創世記 41:8; 出埃及記 8:19"> 這些乾癟的穗子吞了那七個飽滿的穗子。我把夢告訴了術士，卻沒有人能為我解夢。」</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="但以理書 2:45; 啟示錄 4:1; 以弗所書 1:17"> 約瑟對法老說：「王的夢都是同一個意思，上帝已經藉著夢把祂將要做的事指示王了。</span>
<span className="v" id="v26" data-v="26" data-xref="創世記 41:47; 創世記 41:2; 創世記 41:53"> 七頭肥美的母牛和七個飽滿的穗子都代表七年，是同樣的意思。</span>
<span className="v" id="v27" data-v="27" data-xref="列王紀下 8:1; 撒母耳記下 24:19"> 隨後上來的七頭瘦弱、醜陋的母牛和七個乾癟、被東風吹焦的穗子也代表七年，是七年饑荒。</span>
<span className="v" id="v28" data-v="28" data-xref="創世記 41:25; 創世記 41:16"> 正如我剛才說的，上帝已經把祂將要做的事向王顯明了。</span>
<span className="v" id="v29" data-v="29" data-xref="創世記 41:26; 創世記 41:46–47; 創世記 41:49"> 埃及全境很快會有七年大豐收，</span>
<span className="v" id="v30" data-v="30" data-xref="創世記 47:13; 創世記 41:54; 雅各書 5:17"> 隨後是七年饑荒肆虐全國，之前的豐收將被忘記。</span>
<span className="v" id="v31" data-v="31" data-xref="以賽亞書 24:20; 撒母耳記上 5:6"> 饑荒將非常嚴重，之前的豐收將蕩然無存。</span>
<span className="v" id="v32" data-v="32" data-xref="民數記 23:19; 以賽亞書 46:10–11; 以賽亞書 14:24–27"> 王的夢出現了兩次，表示上帝的心意已定，上帝必很快成就這事。</span>
<span className="v" id="v33" data-v="33" data-xref="創世記 41:39; 使徒行傳 6:3; 申命記 1:13"> 王應該選一個精明聰慧的人，派他治理埃及。</span>
<span className="v" id="v34" data-v="34" data-xref="箴言 22:3; 路加福音 16:5; 箴言 6:6–8"> 王也應該在各地委派官員，在七年豐收期內徵收全國出產的五分之一，</span>
<span className="v" id="v35" data-v="35" data-xref="創世記 45:6–7; 創世記 41:56; 出埃及記 4:13"> 把在豐年收集的糧食儲存在各城，歸王管理。</span>
<span className="v" id="v36" data-v="36" data-xref="創世記 47:13–25"> 這些糧食要留到埃及七年饑荒時用，免得這片土地被饑荒毀滅。」</span>
</div>
</div>

## 約瑟做埃及宰相

<div className="bt">
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="使徒行傳 7:10; 列王紀上 21:2; 撒母耳記下 3:36"> 法老和他所有的臣僕都贊同約瑟的建議。</span>
<span className="v" id="v38" data-v="38" data-xref="約伯記 32:8; 但以理書 5:14; 民數記 27:18"> 法老對臣僕說：「我們哪裡找像這樣有上帝的靈同在的人呢？」</span>
<span className="v" id="v39" data-v="39" data-xref="創世記 41:33; 創世記 41:28; 創世記 41:25"> 法老對約瑟說：「上帝既然把夢的意思指示給你，可見沒人有你這樣的見識和智慧。</span>
<span className="v" id="v40" data-v="40" data-xref="箴言 22:29; 使徒行傳 7:10; 詩篇 105:21–22"> 你要管理我家，我的人民都要遵從你的命令，只有我權力比你大。」</span>
<span className="v" id="v41" data-v="41" data-xref="馬太福音 28:18; 腓立比書 2:9–11; 創世記 42:6"> 法老又說：「我現在派你治理埃及全國。」</span>
<span className="v" id="v42" data-v="42" data-xref="但以理書 5:29; 但以理書 5:7; 以斯帖記 3:10"> 於是，法老摘下手上用來蓋印的戒指，戴在約瑟的手上，給他穿上細麻袍，把金鏈戴在他頸上，</span>
<span className="v" id="v43" data-v="43" data-xref="使徒行傳 7:10; 創世記 45:8; 創世記 45:26"> 讓他坐在自己的第二輛御車上，並有人在御車前高呼：「跪下！」這樣，法老派約瑟治理整個埃及。</span>
<span className="v" id="v44" data-v="44" data-xref="詩篇 105:22; 出埃及記 11:7"> 法老對約瑟說：「我是法老，但沒有你的命令，埃及的任何人都不得擅自行事。」</span>
<span className="v" id="v45" data-v="45" data-xref="創世記 46:20; 以西結書 30:17; 出埃及記 2:16"> 法老賜給約瑟一個名字，叫撒發那忒·巴內亞，又把安城祭司波提非拉的女兒亞西納賜給他為妻。約瑟巡視了整個埃及。</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="但以理書 1:19; 列王紀上 12:6; 撒母耳記上 16:21"> 約瑟三十歲開始為法老效勞，他離開法老去巡視埃及各地。</span>
<span className="v" id="v47" data-v="47" data-xref="創世記 26:12; 詩篇 72:16"> 七個豐年之內，埃及糧食大豐收，</span>
<span className="v" id="v48" data-v="48" data-xref="創世記 41:34–36; 創世記 47:21"> 約瑟收集埃及七個豐年出產的所有糧食，儲藏進各城，每一座城附近出產的糧食都存放在本城。</span>
<span className="v" id="v49" data-v="49" data-xref="詩篇 78:27; 士師記 6:5; 創世記 22:17"> 約瑟積存了大量五穀，多如海沙，不可勝數。</span>
</div>
<div className="bp">
<span className="v" id="v50" data-v="50" data-xref="創世記 46:20; 創世記 48:5; 撒母耳記下 8:18"> 荒年到來前，安城祭司波提非拉的女兒亞西納給約瑟生了兩個兒子。</span>
<span className="v" id="v51" data-v="51" data-xref="詩篇 30:5; 箴言 31:7; 申命記 33:17"> 約瑟給長子取名叫瑪拿西，因為他說：「上帝使我忘記一切困苦和父親全家。」</span>
<span className="v" id="v52" data-v="52" data-xref="創世記 49:22; 創世記 50:23; 創世記 17:6"> 約瑟給次子取名叫以法蓮，因為他說：「上帝使我在受苦之地昌盛。」</span>
</div>
<div className="bp">
<span className="v" id="v53" data-v="53" data-xref="創世記 41:29–31; 詩篇 73:20; 路加福音 16:25"> 七個豐年結束後，</span>
<span className="v" id="v54" data-v="54" data-xref="創世記 45:11; 使徒行傳 7:11; 詩篇 105:16"> 七個荒年接踵而至，正如約瑟所言。各地都有饑荒，只有埃及全國有糧食。</span>
<span className="v" id="v55" data-v="55" data-xref="馬太福音 17:5; 馬太福音 3:17; 耶利米書 14:1–6"> 後來，埃及全國也遭遇饑荒，百姓就向法老求糧，法老對他們說：「你們去找約瑟吧，要照他的吩咐做。」</span>
</div>
<div className="bp">
<span className="v" id="v56" data-v="56" data-xref="創世記 42:6; 撒迦利亞書 5:3; 路加福音 21:35"> 饑荒蔓延到整個埃及時，約瑟便開倉賣糧給埃及人。那時，埃及的饑荒非常嚴重。</span>
<span className="v" id="v57" data-v="57" data-xref="創世記 41:54; 創世記 42:5; 創世記 41:56"> 各地的人都到埃及來向約瑟買糧，因為天下到處都是大饑荒。</span>
</div>
</div>

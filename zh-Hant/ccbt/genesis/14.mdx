## 亞伯蘭救回羅得

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 10:10; 創世記 10:22; 以賽亞書 37:12"> 那時，示拿王暗拉非、以拉撒王亞略、以攔王基大老瑪和戈印王提達聯合攻打以下五王：所多瑪王比拉、蛾摩拉王比沙、押瑪王示納、洗扁王善以別和比拉王，即瑣珥王。</span>
<span className="v" id="v3" data-v="3" data-xref="約書亞記 3:16; 申命記 3:17; 民數記 34:12"> 五王會師西訂谷，即鹽海。</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 9:25–26; 以西結書 17:15"> 他們受基大老瑪統治十二年，在第十三年叛變了。</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 3:11; 創世記 15:20; 申命記 1:4"> 第十四年，基大老瑪聯合其他王在亞特律·加寧打敗利乏音人，在哈麥打敗蘇西人，在沙微·基列亭打敗以米人，</span>
<span className="v" id="v6" data-v="6" data-xref="申命記 2:22; 申命記 2:12; 創世記 21:21"> 在西珥山打敗住在那裡的何利人，直殺到靠近曠野的伊勒·巴蘭。</span>
<span className="v" id="v7" data-v="7" data-xref="歷代志下 20:2; 創世記 16:14; 創世記 20:1"> 然後，他們返回安·密巴，即加低斯，征服了亞瑪力全境以及住在哈洗遜·他瑪的亞摩利人。</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 19:22; 創世記 13:10; 創世記 19:20"> 那時，所多瑪王、蛾摩拉王、押瑪王、洗扁王和比拉王，即瑣珥王出戰，在西訂谷擺開陣勢，</span>
<span className="v" id="v9" data-v="9"> 抵抗以攔王基大老瑪、戈印王提達、示拿王暗拉非和以拉撒王亞略：四王跟五王交戰。</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 19:17; 創世記 19:30; 以賽亞書 24:18"> 西訂谷佈滿柏油坑，所多瑪王和蛾摩拉王敗走的時候，有些人掉進坑裡，其他人都往山上逃命。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 14:21; 創世記 14:16; 申命記 28:31"> 四王把所多瑪和蛾摩拉所有的財物和糧食洗劫一空，揚長而去，</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 12:5; 創世記 11:27; 啟示錄 3:19"> 並劫走亞伯蘭的侄兒羅得和他的財物，那時羅得正住在所多瑪。</span>
<span className="v" id="v13" data-v="13" data-xref="創世記 13:18; 創世記 14:24; 創世記 40:15"> 有一個逃出來的人把這件事情告訴了希伯來人亞伯蘭。那時，亞伯蘭住在亞摩利人幔利的橡樹那裡。幔利是以實各和亞乃的兄弟，三人都是亞伯蘭的盟友。</span>
<span className="v" id="v14" data-v="14" data-xref="士師記 18:29; 創世記 15:3; 創世記 17:27"> 亞伯蘭聽見侄兒被擄的消息，便率領家中三百一十八名訓練有素的壯丁去追趕他們，一直追到但。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行傳 9:2; 詩篇 112:5; 列王紀上 15:18"> 夜裡，亞伯蘭和他的隨從分頭出擊，大敗他們，一直追殺到大馬士革北面的何巴，</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳記上 30:18–19; 撒母耳記上 30:8; 創世記 12:2"> 奪回所有被劫的財物，並救出他侄兒羅得及其財物、婦女和其他人。</span>
</div>
</div>

## 麥基洗德祝福亞伯蘭

<div className="bt">
<div className="bp poetry">
<span className="v" id="v17" data-v="17" data-xref="撒母耳記下 18:18; 箴言 19:4; 希伯來書 7:1"> 亞伯蘭大敗基大老瑪及其盟軍各王凱旋的時候，所多瑪王到沙微谷來迎接。沙微谷即王谷。</span>
<span className="v" id="v18" data-v="18" data-xref="希伯來書 6:20–3; 詩篇 110:4; 希伯來書 5:6"> 撒冷王麥基洗德也帶著餅和酒出來相迎，他是至高上帝的祭司。</span>
<span className="v" id="v19" data-v="19" data-xref="希伯來書 7:6–7; 創世記 14:22; 詩篇 24:1"> 他祝福亞伯蘭說：<br /><span className="pl pl-1">「願創造天地的主、至高的上帝賜福給亞伯蘭！</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="創世記 28:22; 希伯來書 7:4–9; 瑪拉基書 3:10"> <span className="pl pl-1">將敵人交在你手中的至高上帝當受稱頌！」</span>於是，亞伯蘭把所得財物的十分之一給了他。</span>
<span className="v" id="v21" data-v="21"> 所多瑪王對亞伯蘭說：「請把我的人民交還給我，你可以把財物拿去。」</span>
<span className="v" id="v22" data-v="22" data-xref="但以理書 12:7; 但以理書 4:34; 申命記 32:40"> 亞伯蘭對他說：「我向創造天地的主、至高的上帝耶和華舉手起誓，</span>
<span className="v" id="v23" data-v="23" data-xref="列王紀下 5:16; 哥林多後書 11:9–12; 以斯帖記 9:15–16"> 凡是你的東西，就是一根線、一條鞋帶，我都不會拿，免得你說，『我使亞伯蘭發了財！』</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 14:13; 箴言 3:27; 馬太福音 7:12"> 除了我的隨從已經吃用的以外，我什麼也不要。至於我的盟友亞乃、以實各和幔利所當得之份，請讓他們拿去。」</span>
</div>

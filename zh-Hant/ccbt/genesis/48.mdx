## 雅各祝福以法蓮和瑪拿西

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 41:50–52; 創世記 46:20; 詩篇 128:6"> 後來，有人來通知約瑟，說他父親病了，約瑟就帶著兩個兒子瑪拿西和以法蓮去探望父親。</span>
<span className="v" id="v2" data-v="2" data-xref="以弗所書 6:10; 撒母耳記上 23:16; 申命記 3:28"> 雅各聽說他兒子約瑟來了，就強撐著從床上坐起來，</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 35:9–12; 出埃及記 6:3; 創世記 28:3"> 對約瑟說：「全能的上帝曾經在迦南的路斯向我顯現，賜福給我。</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 17:8; 創世記 35:11; 創世記 26:4"> 祂對我說，『我必使你生養眾多，人丁興旺，並把迦南賜給你的子孫永遠作產業。』</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 41:50–52; 約書亞記 14:4; 創世記 46:20"> 「我來之前，你在埃及生的兩個兒子以法蓮和瑪拿西都算我的，他們跟呂便和西緬一樣是我的。</span>
<span className="v" id="v6" data-v="6" data-xref="約書亞記 14:4"> 除了他們以外，你其他子女仍然歸你，這些子女可以在他們弟兄的名下繼承產業。</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 35:16–19; 馬太福音 2:18; 創世記 35:9"> 我從巴旦回來的路上，拉結死在了迦南，那地方離以法他還有一段路程，我把她葬在通往以法他的路旁。」以法他就是伯利恆。</span>
<span className="v" id="v8" data-v="8"> 以色列看見約瑟的兩個兒子，就問：「他們是誰？」</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 27:4; 創世記 33:5; 希伯來書 11:21"> 約瑟說：「是上帝在這裡賜給我的兒子。」以色列說：「把他們帶過來，我要祝福他們。」</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 27:1; 創世記 27:27; 撒母耳記上 3:2"> 以色列年紀老邁，眼睛昏花，看不清楚。約瑟把兒子帶到他面前，他就親吻他們、擁抱他們。</span>
<span className="v" id="v11" data-v="11" data-xref="以弗所書 3:20; 創世記 45:26; 創世記 42:36"> 以色列對約瑟說：「我以為再也見不到你了，上帝竟然還讓我見到了你的兒子！」</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 42:6; 利未記 19:32; 創世記 19:1"> 約瑟把兩個兒子從以色列的膝上領開，自己向父親俯伏下拜，</span>
<span className="v" id="v13" data-v="13"> 隨後左手牽著瑪拿西，右手牽著以法蓮，把他們分別領到以色列的右邊和左邊。</span>
<span className="v" id="v14" data-v="14" data-xref="創世記 41:51; 詩篇 118:16; 馬太福音 19:15"> 但以色列卻兩手交叉，把右手放在約瑟次子以法蓮的頭上，左手放在約瑟長子瑪拿西的頭上。</span>
<span className="v" id="v15" data-v="15" data-xref="創世記 17:1; 歌羅西書 2:6; 以賽亞書 33:16"> 他祝福約瑟說：「願我祖先亞伯拉罕和以撒敬拜的上帝，就是牧養我一生直到今天的上帝，</span>
<span className="v" id="v16" data-v="16" data-xref="詩篇 34:22; 創世記 49:22; 創世記 48:5"> 救我脫離一切患難的天使，賜福這兩個孩子。願我和我祖先亞伯拉罕及以撒的名字藉著他們流傳。願他們在地上子孫興旺。」</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 48:14; 羅馬書 9:7–8; 歷代志上 21:7"> 約瑟見父親把右手放在以法蓮的頭上，感到不悅，就把父親的右手從以法蓮的頭上挪到瑪拿西頭上，</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 19:18; 創世記 29:26; 創世記 43:33"> 對父親說：「父親，你弄錯了，這才是長子，你應該把右手按在他的頭上。」</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 33:17; 民數記 1:33–35; 創世記 25:28"> 他父親卻不同意，說：「我兒啊，我知道，我知道。他必發展成一個強大的民族，但他弟弟將比他更強大，他弟弟的後裔必成為多個民族。」</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 24:60; 路得記 4:11–12; 創世記 28:3"> 雅各那天祝福他們，說：「以色列人必引用你們的名祝福人，說，『願上帝使你們像以法蓮和瑪拿西一樣！』」他把以法蓮排在瑪拿西前面。</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 50:24; 創世記 46:4; 創世記 28:15"> 以色列對約瑟說：「我快死了，但上帝必與你們同在，帶你們回到你們祖先的土地。</span>
<span className="v" id="v22" data-v="22" data-xref="約翰福音 4:5; 約書亞記 24:32; 歷代志上 5:2"> 我要把我用刀和弓從亞摩利人手上奪來的那塊地留給你，讓你比其他弟兄多得一份。」</span>

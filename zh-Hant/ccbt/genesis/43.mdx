## 約瑟的哥哥們再下埃及

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 12:10; 使徒行傳 7:11–13; 耶利米哀歌 5:10"> 那地方的饑荒仍然非常嚴重，</span>
<span className="v" id="v2" data-v="2" data-xref="提摩太前書 6:6–8; 箴言 16:18; 箴言 15:16"> 他們從埃及帶回來的糧食吃完了，他們的父親對他們說：「你們再去買些糧食吧。」</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 44:23; 創世記 43:5; 撒母耳記下 3:13"> 猶大說：「那人嚴厲地警告我們，『不把你們的弟弟帶來，你們就不要再來見我。』</span>
<span className="v" id="v4" data-v="4"> 你若讓弟弟跟我們同去，我們就去給你買糧。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 20:12; 創世記 44:26; 創世記 42:38"> 你若不讓他跟我們同去，我們就不去給你買糧。因為那人說，『你們不把弟弟帶來，就不要再來見我。』」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6"> 以色列說：「你們為什麼這樣害我，告訴他你們還有一個弟弟呢？」</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 43:3; 創世記 42:13; 創世記 43:27"> 他們回答說：「那人詳細詢問我們和我們家人的情況，問我們的父親是否在世，還有沒有弟兄。我們如實回答，怎會想到他非要我們把弟弟帶去呢？」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="創世記 42:2; 申命記 33:6; 創世記 45:19"> 猶大對父親以色列說：「你就讓這孩子跟我同去吧，我們好立刻動身，這樣我們一家老小才能保住性命，不致餓死。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 42:37; 腓利門書 1:18–19; 希伯來書 7:22"> 我親自擔保他的安全，你可以向我要人。我若不把他帶回來見你，情願一生擔罪。</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 19:16"> 我們若是沒有耽擱的話，現在已經往返兩趟了。」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="創世記 37:25; 耶利米書 8:22; 以西結書 27:17"> 他們的父親以色列說：「事到如今，只好這樣了。你們袋子裡帶一些上好的乳香、蜂蜜、香料、沒藥、榧子和杏仁等土產，去送給那人作禮物吧。</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 42:25; 創世記 42:35; 帖撒羅尼迦前書 4:6"> 你們還要帶雙倍的錢，好歸還上次留在你們口袋中的錢，那次可能是弄錯了。</span>
<span className="v" id="v13" data-v="13" data-xref="創世記 42:38"> 帶你們的弟弟去見那人吧！</span>
<span className="v" id="v14" data-v="14" data-xref="以斯帖記 4:16; 創世記 17:1; 使徒行傳 21:14"> 願全能的上帝叫那人憐憫你們，讓西緬和便雅憫回來。我若喪子就喪子吧！」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15"> 於是，他們就帶著便雅憫、禮物和雙倍的錢去埃及見約瑟。</span>
<span className="v" id="v16" data-v="16" data-xref="創世記 44:1; 創世記 43:19; 創世記 24:2–10"> 約瑟看見便雅憫和他們同來，就對管家說：「你帶他們到我家裡去，宰殺牲畜，預備宴席，中午他們要跟我一起吃飯。」</span>
<span className="v" id="v17" data-v="17"> 管家照約瑟的吩咐，帶他們到約瑟家裡。</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 42:35; 羅馬書 7:8; 創世記 42:21"> 他們被帶到約瑟家後非常害怕，說：「他把我們帶到這裡來，是因為上次放回我們口袋的錢。他想害我們，強迫我們做他的奴僕，搶我們的驢。」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19"> 他們走到約瑟的管家跟前，在房門口對他說：</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 42:3; 創世記 42:10; 創世記 42:27"> 「主啊，我們上次曾來這裡買糧。</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 43:12; 創世記 42:27–35; 羅馬書 13:8"> 但在回家的途中住宿時，我們打開口袋，發現我們帶來買糧的錢分毫不少地放在那裡。我們把這些錢帶回來了，</span>
<span className="v" id="v22" data-v="22"> 又另外帶了一些錢來買糧。我們不知道誰把買糧的錢放進了我們的口袋。」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="約翰福音 20:26; 創世記 42:24; 約翰福音 14:27"> 管家說：「你們放心，不要害怕，你們口袋裡的錢財是你們的上帝，你們父親的上帝賜給你們的。我已經收了你們買糧的錢。」他就把西緬帶出來見他們，</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 18:4; 創世記 24:32; 路加福音 7:44"> 接著帶他們進約瑟的家，給他們水洗腳，給他們的驢餵草料。</span>
<span className="v" id="v25" data-v="25" data-xref="創世記 43:11; 創世記 43:16"> 他們知道要在那裡吃午餐，就預備好禮物，等約瑟中午回來。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="腓立比書 2:10–11; 創世記 27:29; 創世記 42:6"> 約瑟回到家裡後，他們就把帶來的禮物獻給他，向他俯伏下拜。</span>
<span className="v" id="v27" data-v="27" data-xref="創世記 42:13; 撒母耳記上 25:5; 撒母耳記上 17:22"> 約瑟向他們問好，然後說：「你們提起過你們的老父親，他安康嗎？還健在嗎？」</span>
<span className="v" id="v28" data-v="28" data-xref="創世記 37:7; 創世記 43:26; 撒母耳記下 14:4"> 他們回答說：「你僕人——我們的父親仍然健在，安康。」說完了，又向他下拜。</span>
<span className="v" id="v29" data-v="29" data-xref="創世記 42:13; 民數記 6:25; 創世記 30:22–24"> 約瑟抬眼看見了自己的同胞弟弟便雅憫，就問道：「這就是你們所說那位最小的弟弟嗎？」他又對便雅憫說：「孩子，願上帝施恩給你。」</span>
<span className="v" id="v30" data-v="30" data-xref="創世記 42:24; 耶利米書 31:20; 列王紀上 3:26"> 約瑟愛弟之心油然而生，急忙出去找哭的地方。他到自己的房間裡哭了一場。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="創世記 45:1; 彼得前書 3:10; 以賽亞書 42:14"> 他洗過臉出來，控制著自己的感情，吩咐人擺飯。</span>
<span className="v" id="v32" data-v="32" data-xref="創世記 46:34; 出埃及記 8:26; 創世記 43:16"> 約瑟自己一桌，他的弟兄們一桌，那些和他們一起吃飯的埃及人一桌，因為埃及人厭惡希伯來人，不與他們同席。</span>
<span className="v" id="v33" data-v="33"> 約瑟讓他的弟兄們按照長幼次序在他對面坐，他們面面相覷，非常驚訝。</span>
<span className="v" id="v34" data-v="34" data-xref="創世記 45:22; 撒母耳記下 11:8; 撒母耳記上 1:5"> 約瑟吩咐人把自己面前的菜餚分給他們，便雅憫得的那份比其他弟兄多五倍。他們盡情地和約瑟一同吃喝。</span>
</div>
</div>

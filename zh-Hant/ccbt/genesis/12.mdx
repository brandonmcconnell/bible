## 上帝呼召亞伯蘭

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="希伯來書 11:8; 尼希米記 9:7; 使徒行傳 7:2–6"> 耶和華對亞伯蘭說：「你要離開家鄉、親族和父親的家，到我要指示你的地方去。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳記下 7:9; 創世記 18:18; 加拉太書 3:14"> 我必使你成為大國，我必賜福給你，使你聲名遠揚。你必成為別人的祝福。</span>
<span className="v" id="v3" data-v="3" data-xref="加拉太書 3:8; 創世記 22:18; 創世記 27:29"> 我必賜福給那些祝福你的人，咒詛那些咒詛你的人。世上萬族必因你而蒙福。」</span>
<span className="v" id="v4" data-v="4" data-xref="希伯來書 11:8; 創世記 11:31; 創世記 11:27"> 亞伯蘭就照耶和華的吩咐離開哈蘭，侄兒羅得與他同行。那時亞伯蘭七十五歲。</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 14:14; 創世記 11:31; 希伯來書 11:8–9"> 亞伯蘭帶著妻子撒萊、侄兒羅得以及在哈蘭積攢的財物和所得的奴僕，啟程來到迦南。到了迦南以後，</span>
<span className="v" id="v6" data-v="6" data-xref="希伯來書 11:9; 申命記 11:30; 創世記 35:4"> 亞伯蘭繼續前行，來到示劍的摩利橡樹<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「橡樹」希伯來文是「大樹」，也可能指靈樹或聖樹，下同13·18；14·13；18·1；35·4；35·8。">a</a></sup>那裡。當時迦南人住在那地方。</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 17:8; 創世記 18:1; 創世記 13:15"> 耶和華向亞伯蘭顯現，對他說：「我要把這片土地賜給你的後裔。」亞伯蘭就在那裡為向他顯現的耶和華築了一座壇。</span>
<span className="v" id="v8" data-v="8" data-xref="尼希米記 11:31; 創世記 4:26; 創世記 21:33"> 然後，他們又啟程前往伯特利東面的山區，在那裡搭起帳篷。他們的西面是伯特利，東面是艾。亞伯蘭又在那裡築了一座壇，求告耶和華的名。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 13:3; 創世記 24:62; 創世記 13:1"> 之後，亞伯蘭繼續前往南地。</span>
</div>
</div>

## 亞伯蘭逃荒到埃及

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="創世記 43:1; 創世記 26:1–3; 列王紀上 17:1–18"> 那地方遭遇饑荒，災情非常嚴重，亞伯蘭便下到埃及暫住。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 26:7; 創世記 29:17; 創世記 12:14"> 快要到埃及的時候，他對妻子撒萊說：「我知道你是個美貌的女子，</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 20:11; 創世記 26:7; 約翰一書 1:8–10"> 埃及人看見你，一定會因為你是我的妻子而殺了我，讓你活著。</span>
<span className="v" id="v13" data-v="13" data-xref="創世記 26:7; 創世記 20:12–13; 創世記 20:2"> 所以，請你說你是我的妹妹，這樣他們會因為你而善待我，留我一命。」</span>
<span className="v" id="v14" data-v="14" data-xref="創世記 6:2; 馬太福音 5:28; 創世記 39:7"> 亞伯蘭一行到了埃及，撒萊的美貌引起了埃及人的注意。</span>
<span className="v" id="v15" data-v="15" data-xref="創世記 20:2; 創世記 41:1; 列王紀下 18:21"> 法老的官員見了撒萊，就在法老面前稱讚她的美貌，她便被帶進法老的王宮。</span>
<span className="v" id="v16" data-v="16" data-xref="創世記 20:14; 創世記 13:2; 創世記 24:35"> 因為撒萊的緣故，法老厚待亞伯蘭，賞給他許多牛、羊、驢、駱駝和僕婢。</span>
<span className="v" id="v17" data-v="17" data-xref="歷代志上 16:21; 創世記 20:18; 詩篇 105:14–15"> 耶和華因亞伯蘭妻子撒萊的緣故，使法老和他全家患重病。</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 20:9–10; 創世記 26:9–11; 撒母耳記上 14:43"> 法老便召見亞伯蘭，說：「你對我做的是什麼事？為什麼不告訴我她是你妻子？</span>
<span className="v" id="v19" data-v="19"> 為什麼說她是你妹妹，以致我要娶她為妻呢？現在你妻子在這裡，帶她走吧！」</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 105:14–15; 箴言 21:1; 出埃及記 18:27"> 法老就吩咐人把亞伯蘭、他妻子以及他所有的一切都送走了。</span>
</div>

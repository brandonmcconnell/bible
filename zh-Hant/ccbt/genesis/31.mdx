## 雅各逃離拉班

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="傳道書 4:4; 詩篇 49:16–17; 約伯記 31:31"> 雅各聽見拉班的兒子們說：「雅各奪去了我們父親的一切！他的財富都是從我們父親那裡得來的。」</span>
<span className="v" id="v2" data-v="2" data-xref="但以理書 3:19; 撒母耳記上 18:9–11; 創世記 4:5"> 雅各發覺拉班對他的態度不如從前了。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 28:15; 創世記 32:9; 希伯來書 13:5"> 這時，耶和華對雅各說：「回到你的家鄉和親族那裡吧！我必與你同在。」</span>
<span className="v" id="v4" data-v="4"> 於是，雅各就派人把拉結和利亞叫到放羊的地方，</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 31:2–3; 創世記 31:53; 創世記 48:15"> 對她們說：「我感到你們父親對我不如從前了，但我父親的上帝常與我同在。</span>
<span className="v" id="v6" data-v="6" data-xref="創世記 30:29; 以弗所書 6:5–8; 提多書 2:9–10"> 你們知道我是怎樣盡心盡力地替你們父親工作，</span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 37:28; 創世記 31:29; 民數記 14:22"> 他卻欺騙我，把我的工酬更改了十次。然而，上帝不讓他苦待我。</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 30:32"> 如果他說把有斑點的羊給我當酬勞，羊群生的就都是有斑點的；如果他說把有條紋的給我，羊群生的就都是有條紋的。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 31:1; 創世記 31:16; 箴言 13:22"> 上帝就這樣把你們父親的牲畜奪過來給了我。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="申命記 13:1; 創世記 30:39; 創世記 20:6"> 「在羊群交配的季節，我在夢中抬頭看見和母羊交配的公羊都是有條紋或有斑點的。</span>
<span className="v" id="v11" data-v="11" data-xref="以賽亞書 58:9; 創世記 31:13; 撒母耳記上 3:6"> 在夢中，上帝的天使叫我，我說，『我在這裡。』</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及記 3:7; 申命記 24:15; 創世記 31:42"> 他說，『拉班對你的所作所為，我都看見了。現在你抬頭看看，與母羊交配的公羊都是有條紋或有斑點的。</span>
<span className="v" id="v13" data-v="13" data-xref="創世記 31:3; 創世記 32:9; 創世記 28:12–22"> 我就是你在伯特利遇見的上帝。你在那裡用油澆過柱子，向我許過願。現在，你馬上離開這裡，回到你的家鄉。』」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="路得記 4:11; 創世記 2:24; 創世記 29:24"> 拉結和利亞說：「父親的家產沒有我們的份兒，</span>
<span className="v" id="v15" data-v="15" data-xref="創世記 29:15–20; 創世記 31:41; 創世記 29:27–30"> 我們早就被當作外人了，他賣了我們，把我們的身價全部吞了。</span>
<span className="v" id="v16" data-v="16" data-xref="創世記 30:35–1; 創世記 31:9; 詩篇 45:10"> 上帝從我們父親那裡奪過來的一切財產，理當屬於我們和我們的兒女。現在你只管照上帝的吩咐做吧！」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="撒母耳記上 30:17; 創世記 24:61; 創世記 24:10"> 雅各便起來讓兒女和妻子都騎上駱駝，</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 27:1–2; 創世記 27:41; 創世記 35:27–29"> 帶著他在巴旦·亞蘭得到的所有牲畜和財物，啟程去迦南他父親以撒那裡。</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳記上 19:13; 創世記 31:30; 何西阿書 3:4"> 那時拉班正在外面剪羊毛，拉結偷了父親家中的神像。</span>
<span className="v" id="v20" data-v="20"> 雅各不辭而別，背著亞蘭人拉班偷偷地跑了。</span>
<span className="v" id="v21" data-v="21" data-xref="列王紀下 12:17; 創世記 37:25; 創世記 46:28"> 他帶著所有的一切渡過幼發拉底河，逃往基列山區。</span>
</div>
</div>

## 拉班追趕雅各

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="約伯記 5:12–13; 創世記 30:36; 出埃及記 14:5–31"> 到了第三天，拉班才得知雅各逃走了。</span>
<span className="v" id="v23" data-v="23" data-xref="創世記 13:8; 創世記 24:27; 出埃及記 2:11"> 於是，他帶著族人去追趕，追了七天，在基列山區追上了雅各。</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 24:50; 創世記 31:29; 創世記 20:3"> 當晚，上帝在夢中對亞蘭人拉班說：「你要當心，不可對雅各多說什麼。」</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="創世記 12:8; 創世記 33:18; 希伯來書 11:9"> 拉班追上了雅各，那時雅各在基列山搭起帳篷，拉班和他的族人也在那裡搭起帳篷。</span>
<span className="v" id="v26" data-v="26" data-xref="撒母耳記上 30:2; 創世記 12:18; 創世記 20:9–10"> 拉班對雅各說：「你做的是什麼？你欺瞞我，把我的女兒像戰俘一樣帶走。</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及記 15:20; 箴言 26:23–26; 創世記 31:3–5"> 你為什麼要偷偷地逃跑？你為什麼不告訴我，我好擊鼓、彈琴、唱歌歡送你？</span>
<span className="v" id="v28" data-v="28" data-xref="創世記 31:55; 路得記 1:14; 使徒行傳 20:37"> 你甚至不讓我親吻外孫和女兒，與他們道別，你這樣做真愚蠢。</span>
<span className="v" id="v29" data-v="29" data-xref="創世記 31:53; 創世記 31:42; 創世記 31:24"> 我有能力傷害你，但你父親的上帝昨夜對我說，『你要小心，不可對雅各多說什麼。』</span>
<span className="v" id="v30" data-v="30" data-xref="耶利米書 10:11; 創世記 31:19; 士師記 18:24"> 你思家心切，一定要走，但你為什麼要偷走我的神像呢？」</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="箴言 29:25; 創世記 31:26–27; 創世記 20:11"> 雅各對拉班說：「我逃跑是因為害怕，我以為你會從我身邊奪走你的女兒。</span>
<span className="v" id="v32" data-v="32" data-xref="撒母耳記上 12:3–5; 創世記 31:30; 創世記 31:19"> 至於你的神像，你在誰身上搜出來，誰就是該死的。你可以當著眾弟兄的面察看，如果在我這裡有什麼物件是你的，你只管拿走。」雅各不知道拉結偷走了神像。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="創世記 24:67; 創世記 24:28"> 拉班進入雅各、利亞和兩個婢女的帳篷搜查，卻搜不出什麼。拉班離開利亞的帳篷進入拉結的帳篷，</span>
<span className="v" id="v34" data-v="34" data-xref="創世記 31:19; 創世記 31:17"> 那時拉結已經把神像藏在駱駝的鞍座裡，自己坐在上面。拉班搜遍了整個帳篷，什麼也找不到。</span>
<span className="v" id="v35" data-v="35" data-xref="利未記 19:32; 出埃及記 20:12; 彼得前書 2:18"> 拉結對父親說：「請我主別生氣，我有月事在身，不能起身。」結果，拉班搜來搜去找不到神像。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="以弗所書 4:26; 創世記 49:7; 民數記 16:15"> 雅各發怒，斥責拉班說：「我做錯了什麼、犯了什麼罪，以致你對我窮追不捨？</span>
<span className="v" id="v37" data-v="37" data-xref="彼得前書 2:12; 哥林多前書 6:4–5; 撒母耳記上 12:3–4"> 你搜遍我所有的東西，搜到了什麼？現在就當著眾弟兄的面拿出來，讓他們評評理吧！</span>
<span className="v" id="v38" data-v="38" data-xref="創世記 30:27; 申命記 28:4; 以西結書 34:2–4"> 我在你家這二十年，你的母綿羊、母山羊沒有掉過胎，我也沒有吃過你公羊的肉。</span>
<span className="v" id="v39" data-v="39" data-xref="出埃及記 22:31; 出埃及記 22:10–13; 利未記 22:8"> 我沒有把被野獸撕裂的羊帶來給你，而是自己賠上。無論在白晝或黑夜被偷去的，你都要我賠償。</span>
<span className="v" id="v40" data-v="40" data-xref="路加福音 2:8; 出埃及記 2:19–22; 彼得前書 5:2–4"> 我白天受盡烈日煎熬，晚上飽嘗夜露寒霜，不得好睡。</span>
<span className="v" id="v41" data-v="41" data-xref="創世記 31:7; 哥林多前書 15:10; 哥林多後書 11:26"> 這二十年來，我為了你的兩個女兒，替你工作了十四年，又用了六年才從你那裡得到這些羊，你把我的工錢更改了十次。</span>
<span className="v" id="v42" data-v="42" data-xref="詩篇 31:7; 創世記 31:53; 以賽亞書 8:13"> 如果不是我父親以撒敬畏的上帝，就是亞伯拉罕的上帝與我同在，你肯定會讓我兩手空空地回家。但上帝看見了我的難處和勞苦，所以在昨夜責備了你。」</span>
</div>
</div>

## 雅各和拉班立約

<div className="bt">
<div className="bp">
<span className="v" id="v43" data-v="43"> 拉班回答說：「女兒是我的，孩子是我的，羊群也是我的，你的一切都是我的，我又怎會傷害我的女兒和她們的孩子呢？</span>
<span className="v" id="v44" data-v="44" data-xref="創世記 31:52; 約書亞記 24:25–27; 約書亞記 22:27"> 來吧，你我立約為證。」</span>
<span className="v" id="v45" data-v="45" data-xref="創世記 28:18–22"> 於是，雅各拿來一塊石頭，立作柱子，</span>
<span className="v" id="v46" data-v="46" data-xref="傳道書 3:5; 創世記 31:23; 創世記 31:54"> 又吩咐眾弟兄去收集石頭。他們把石頭堆成一堆，在旁邊吃喝。</span>
<span className="v" id="v47" data-v="47" data-xref="希伯來書 12:1"> 拉班稱那石堆為伊迦爾·撒哈杜他<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「伊迦爾·撒哈杜他」意思是「作見證的石堆」。">a</a></sup>，雅各卻稱那石堆為迦累得<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="「迦累得」意思是「以石堆為證」。">b</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v48" data-v="48" data-xref="約書亞記 24:27; 約書亞記 13:8–9; 創世記 31:23"> 拉班說：「今日，這石堆是你我之間的憑證。」因此，那地方名叫迦累得，</span>
<span className="v" id="v49" data-v="49" data-xref="士師記 11:29; 士師記 10:17; 撒母耳記上 7:5–6"> 又叫米斯巴，因為拉班說：「我們分手以後，願上帝親自鑒察我們。</span>
<span className="v" id="v50" data-v="50" data-xref="耶利米書 42:5; 耶利米書 29:23; 彌迦書 1:2"> 倘若你虐待我的女兒，或在她們以外另娶妻子，即使沒人知道，也有上帝在你我之間作見證。」</span>
</div>
<div className="bp">
<span className="v" id="v51" data-v="51"> 拉班又說：「看我在你我之間立的這石堆和石柱。</span>
<span className="v" id="v52" data-v="52" data-xref="創世記 31:48; 創世記 31:44–45"> 這石堆和石柱都是憑證，我不會越過石堆去害你，你也不可越過石堆和石柱來害我。</span>
<span className="v" id="v53" data-v="53" data-xref="創世記 31:42; 創世記 16:5; 約書亞記 24:2"> 願亞伯拉罕的上帝和拿鶴的上帝，就是他們父親的上帝，在你我之間判斷是非。」雅各便憑他父親以撒敬畏的上帝起誓，</span>
<span className="v" id="v54" data-v="54" data-xref="出埃及記 18:12; 創世記 37:25; 創世記 26:30"> 又在山上獻祭，請眾弟兄吃飯。飯後，他們一同在山上過夜。</span>
</div>
<div className="bp">
<span className="v" id="v55" data-v="55" data-xref="創世記 31:28; 申命記 23:5; 創世記 18:33"> 拉班清早起來，親吻外孫和女兒，給他們祝福，然後回家去了。</span>
</div>
</div>

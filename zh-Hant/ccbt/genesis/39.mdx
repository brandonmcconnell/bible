## 約瑟遭陷害

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 37:28; 詩篇 105:17; 創世記 37:36"> 約瑟被以實瑪利商人帶到埃及，賣給了一個埃及人，他是法老的內臣護衛長波提乏。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳記上 18:14; 詩篇 91:15; 耶利米書 15:20"> 約瑟住在他的埃及主人家中，耶和華與他同在，使他凡事亨通。</span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 1:3; 創世記 30:27; 馬太福音 5:16"> 他主人看出耶和華與他同在，使他凡事亨通，</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 39:21–22; 箴言 27:18; 創世記 19:19"> 就賞識他，讓他服侍自己，派他管理自己的家務及其一切所有。</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 30:27; 撒母耳記下 6:11–12; 使徒行傳 27:24"> 自從埃及人波提乏派約瑟管理自己家中一切事務以後，耶和華因為約瑟的緣故而賜福埃及人的家，使他家裡和田間的一切都蒙福。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳記上 16:12; 路加福音 19:17; 箴言 31:11"> 於是，波提乏把一切事都交給約瑟管理，除了自己要吃的食物以外，什麼也不管。<br />約瑟體格健壯，相貌英俊。</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳記下 13:11; 以西結書 16:34; 彼得後書 2:14"> 後來，他主人的妻子看中了約瑟，向他眉目傳情，要引誘他上床。</span>
<span className="v" id="v8" data-v="8" data-xref="箴言 23:26–28; 箴言 22:14; 箴言 9:13–18"> 約瑟拒絕了她，說：「我主人信任我，家裡一切事務概不過問，都交給我管理。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳記下 12:13; 創世記 20:6; 創世記 42:18"> 在這家裡，沒有人比我權力更大了，我主人把一切都交給了我，唯獨你除外，因為你是他的妻子。我怎能做如此惡事得罪上帝呢？」</span>
<span className="v" id="v10" data-v="10" data-xref="彼得前書 2:11; 創世記 39:8; 帖撒羅尼迦前書 5:22"> 但她還是每天勾引約瑟，約瑟不從，並儘量避開她。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="以弗所書 5:12; 以弗所書 5:3; 瑪拉基書 3:5"> 一天，約瑟進屋裡辦事，那時屋裡沒有其他人。</span>
<span className="v" id="v12" data-v="12" data-xref="提摩太後書 2:22; 箴言 7:13–27; 傳道書 7:26"> 她抓住約瑟的外衣，硬要與他上床。約瑟丟下外衣，逃了出去。</span>
<span className="v" id="v13" data-v="13"> 她見約瑟丟下外衣逃了出去，</span>
<span className="v" id="v14" data-v="14" data-xref="創世記 10:21; 彼得前書 2:20; 詩篇 35:11"> 就叫來家裡的人，對他們說：「你們看，我丈夫帶回家的這個希伯來人戲弄我們！他進來要與我上床，我就大聲呼喊，</span>
<span className="v" id="v15" data-v="15"> 他聽見我大聲喊叫，就把衣服丟在我這裡，逃了出去。」</span>
<span className="v" id="v16" data-v="16" data-xref="詩篇 37:32; 耶利米書 4:22; 耶利米書 9:3–5"> 她把約瑟的外衣留在身邊，等她丈夫回來後，</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及記 23:1; 列王紀上 18:17; 詩篇 37:14"> 就對他說：「你帶回來的那個希伯來奴隸進來要調戲我，</span>
<span className="v" id="v18" data-v="18"> 我大聲喊叫，他就把衣服丟在我這裡，逃了出去。」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="創世記 4:5–6; 箴言 18:17; 箴言 6:34–35"> 波提乏聽了妻子講述約瑟如何對待她之後，勃然大怒，</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 40:15; 提摩太後書 2:9; 詩篇 105:18–19"> 把約瑟關進王囚禁犯人的監牢。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及記 3:21; 以賽亞書 41:10; 彼得前書 3:17"> 約瑟坐牢的時候，耶和華與他同在，恩待他，使監獄長賞識他。</span>
<span className="v" id="v22" data-v="22" data-xref="創世記 40:3–4; 創世記 39:4; 撒母耳記上 2:30"> 監獄長把獄中所有囚犯及一切事務都交給約瑟管理。</span>
<span className="v" id="v23" data-v="23" data-xref="以賽亞書 43:2; 創世記 39:2–3; 詩篇 1:3"> 凡交到約瑟手中的事情，監獄長都很放心，因為耶和華與約瑟同在，使他凡事亨通。</span>
</div>
</div>

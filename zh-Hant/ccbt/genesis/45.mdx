## 約瑟與弟兄相認

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="馬太福音 18:15; 使徒行傳 10:41; 創世記 43:30–31"> 約瑟在侍從面前再也控制不住自己，於是令所有侍從都出去。這樣，約瑟跟弟兄們相認時，沒有外人在場。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 46:29; 使徒行傳 20:37; 民數記 14:1"> 約瑟放聲大哭，埃及人聽見了他的哭聲，法老家也聽到了消息。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行傳 7:13; 使徒行傳 9:5; 撒迦利亞書 12:10"> 約瑟對他的弟兄們說：「我是約瑟！我的父親還健在嗎？」他的弟兄們嚇得說不出話來。</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 37:28; 馬太福音 14:27; 創世記 50:18"> 約瑟叫他們走近一點，等他們靠近了，便說：「我是被你們賣到埃及的弟弟約瑟！</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 50:20; 使徒行傳 7:9–15; 創世記 45:7–8"> 現在，你們不要因為把我賣到這裡而自怨自責。上帝差我先來這裡，是為了保住大家的性命。</span>
<span className="v" id="v6" data-v="6" data-xref="創世記 47:23; 創世記 41:54; 創世記 41:56"> 地上的饑荒已經兩年了，我們還有五年不能種、不能收。</span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 44:4; 使徒行傳 7:35; 詩篇 18:50"> 上帝差我先來，是要為你們保留後代，又要大施拯救，保住你們的性命。</span>
<span className="v" id="v8" data-v="8" data-xref="約翰福音 15:16; 羅馬書 9:16; 約翰福音 19:11"> 這樣看來，不是你們，是上帝把我送到這裡的。祂使我成為法老的宰相，管理他的家和整個埃及。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 45:19–20; 創世記 45:13"> 你們快回去告訴我父親，他兒子約瑟說，『上帝已經使我管理整個埃及，請你立刻來我這裡。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及記 9:26; 出埃及記 8:22; 創世記 46:34–6"> 你可以帶著你的子孫、牛羊及一切所有住在歌珊。那裡離我很近，</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 47:12; 創世記 47:6; 馬太福音 15:5–6"> 我可以奉養你，以免你和全家老少及僕婢牲畜都陷入絕境，因為還有五年的饑荒。』</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 42:23; 路加福音 24:39; 約翰福音 20:27"> 你們和我弟弟便雅憫都親眼看見了，這是我親口對你們說的。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行傳 7:14; 啟示錄 21:23; 彼得前書 1:10–12"> 你們要把我在埃及享有的尊榮和你們見到的一切都告訴父親，儘快把他接來。」</span>
<span className="v" id="v14" data-v="14" data-xref="創世記 33:4; 創世記 29:11; 創世記 46:29"> 約瑟和弟弟便雅憫抱頭痛哭，</span>
<span className="v" id="v15" data-v="15" data-xref="路加福音 15:20; 撒母耳記上 10:1; 詩篇 77:4"> 又親吻其他哥哥，抱著他們痛哭，然後弟兄們跟他交談起來。</span>
<span className="v" id="v16" data-v="16" data-xref="創世記 41:33; 以斯帖記 1:21; 創世記 20:15"> 約瑟的弟兄們到來的消息傳到法老的王宮，法老和他的臣僕都感到高興。</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 42:25–26; 創世記 44:1–2"> 法老對約瑟說：「你去吩咐你的弟兄給牲畜馱上貨物，返回迦南，</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 27:28; 民數記 18:12; 創世記 47:6"> 把你們的父親和家眷都接到我這裡。我要把埃及最好的土地賜給他們，讓他們享受這裡肥美的物產。</span>
<span className="v" id="v19" data-v="19" data-xref="創世記 46:5; 創世記 45:27; 創世記 31:17–18"> 吩咐你的弟兄從埃及帶著車去把他們的妻子、兒女和你們的父親接來。</span>
<span className="v" id="v20" data-v="20" data-xref="以賽亞書 1:19; 路加福音 17:31; 申命記 7:16"> 不要捨不得你們在迦南的財產，因為埃及全國的美物都是你們的。」</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 45:19; 以西結書 23:24; 耶利米哀歌 1:18"> 以色列的兒子們就這樣做了。約瑟遵照法老的吩咐，為他的弟兄們預備好車輛和路上需用的糧食，</span>
<span className="v" id="v22" data-v="22" data-xref="創世記 43:34; 列王紀下 5:5; 士師記 14:12"> 又給他們每人一套新衣服，但給了便雅憫五套新衣服和三百塊銀子。</span>
<span className="v" id="v23" data-v="23" data-xref="創世記 24:10; 出埃及記 16:3; 創世記 43:11"> 約瑟送給父親十頭公驢，馱著埃及的美物，還送了十頭母驢，馱著糧食、餅和其他食物，讓父親路上用。</span>
<span className="v" id="v24" data-v="24" data-xref="帖撒羅尼迦前書 5:13; 詩篇 133:1–3; 創世記 42:21–22"> 約瑟送弟兄們回去，臨行前囑咐他們路上不要爭吵。</span>
<span className="v" id="v25" data-v="25"> 於是，他們離開埃及，回到迦南的父親雅各那裡，</span>
<span className="v" id="v26" data-v="26" data-xref="創世記 44:28; 創世記 37:35; 路加福音 24:34"> 對父親說：「約瑟還活著，並且做了埃及的宰相。」雅各驚呆了，不敢相信他們的話。</span>
<span className="v" id="v27" data-v="27" data-xref="詩篇 85:6; 以賽亞書 57:15; 創世記 45:19"> 雅各聽了他們轉述約瑟的話，又看見約瑟派來接他的車，才回過神來。</span>
<span className="v" id="v28" data-v="28" data-xref="路加福音 2:28–30; 約翰福音 16:21–22; 創世記 46:30"> 以色列說：「我信了！我兒約瑟還活著，我要在死之前去見他。」</span>

## 夏甲與以實瑪利

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="加拉太書 4:24; 創世記 12:16; 創世記 15:2–3"> 亞伯蘭的妻子撒萊沒有給他生孩子。撒萊有個婢女名叫夏甲，是埃及人。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 21:4; 創世記 18:10; 創世記 3:17"> 撒萊對亞伯蘭說：「耶和華不讓我生育，請你與我的婢女同房，也許我可以藉著她得子立後。」亞伯蘭同意了撒萊的話。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 16:5; 創世記 12:4–5; 撒母耳記下 5:13"> 於是，撒萊把埃及婢女夏甲給亞伯蘭做妾。那時亞伯蘭已經在迦南住了十年。</span>
<span className="v" id="v4" data-v="4" data-xref="箴言 30:23; 撒母耳記下 6:16; 哥林多前書 13:4–5"> 亞伯蘭與夏甲同房，她就懷了孕。夏甲知道自己懷了孕，就輕視女主人撒萊。</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 31:53; 出埃及記 5:21; 詩篇 7:8"> 撒萊對亞伯蘭說：「我受氣都是因為你。我把婢女放在你懷裡，她仗著自己懷了孕就輕視我，願耶和華在你我之間主持公道。」</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米書 38:5; 箴言 14:29; 彼得前書 3:7"> 亞伯蘭對撒萊說：「婢女在你手中，隨你處置。」於是，撒萊苦待夏甲，夏甲就逃走了。</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 25:18; 出埃及記 15:22; 創世記 21:17"> 耶和華的天使在曠野中，通往書珥之路的水泉旁找到了夏甲，</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 3:9; 創世記 4:10; 傳道書 10:4"> 便問她：「撒萊的婢女夏甲，你從哪裡來？要到哪裡去？」她回答說：「我是從女主人撒萊那裡逃出來的。」</span>
<span className="v" id="v9" data-v="9" data-xref="彼得前書 5:5–6; 傳道書 10:4; 提多書 2:9"> 耶和華的天使對她說：「你要回到女主人那裡順服她。」</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 17:20; 詩篇 83:6–7; 創世記 25:12–18"> 又說：「我必使你的後裔多得不可勝數。」</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及記 2:23–24; 出埃及記 3:7; 以賽亞書 7:14"> 接著又說：「你現在懷了孕，將來會生一個男孩，你要給他取名叫以實瑪利<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「以實瑪利」意思是「上帝聽見了」。">a</a></sup>，因為耶和華已經聽見你痛苦的哀聲。</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 25:18; 創世記 21:20; 約伯記 39:5–8"> 這孩子性情必像野驢，他要跟人作對，人也要跟他作對。他必與他所有的弟兄為敵。」</span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 139:1–12; 創世記 32:30; 箴言 5:21"> 夏甲稱對她說話的耶和華為「看顧人的上帝」，她說：「我竟然在這裡看見了那位看顧我的。」</span>
<span className="v" id="v14" data-v="14" data-xref="創世記 24:62; 創世記 25:11; 創世記 21:31"> 因此，那口井被稱為庇耳·拉海·萊<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="「庇耳·拉海·萊」意思是「看顧我的永恆上帝之井」。">b</a></sup>，位於加低斯和巴列之間。</span>
<span className="v" id="v15" data-v="15" data-xref="創世記 25:12; 創世記 21:9–21; 創世記 17:25–26"> 後來夏甲為亞伯蘭生了一個兒子，亞伯蘭給他取名叫以實瑪利。</span>
<span className="v" id="v16" data-v="16"> 夏甲生以實瑪利時，亞伯蘭八十六歲。</span>
</div>

## 該隱和亞伯

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="約翰一書 3:12; 創世記 3:15; 創世記 4:25"> 亞當和他妻子夏娃同房，夏娃便懷孕，生了該隱。她說：「耶和華讓我得了一個男孩。」</span>
<span className="v" id="v2" data-v="2" data-xref="約翰一書 3:15; 約翰一書 3:12; 路加福音 11:51"> 後來，夏娃又生了該隱的弟弟亞伯。亞伯做了牧羊人，該隱做了農夫。</span>
<span className="v" id="v3" data-v="3" data-xref="民數記 18:12; 利未記 2:1–11; 列王紀上 17:7"> 過了些日子，該隱把地裡的出產當祭物獻給耶和華，</span>
<span className="v" id="v4" data-v="4" data-xref="希伯來書 11:4; 箴言 3:9; 出埃及記 13:12"> 亞伯也把羊群中頭生的羊及其最肥美的部分獻給耶和華。耶和華悅納亞伯和他的祭物，</span>
<span className="v" id="v5" data-v="5" data-xref="希伯來書 11:4; 約伯記 5:2; 路加福音 15:28–30"> 卻不悅納該隱和他的祭物。該隱便非常惱火，面色陰沉。</span>
<span className="v" id="v6" data-v="6" data-xref="以賽亞書 1:18; 約伯記 5:2; 路加福音 15:31–32"> 耶和華問該隱：「你為什麼惱火？為什麼面色陰沉？</span>
<span className="v" id="v7" data-v="7" data-xref="雅各書 1:15; 羅馬書 2:6–10; 以賽亞書 3:10–11"> 如果你做得對，難道不會蒙悅納嗎？如果你做得不對，罪就蹲伏在你的門口，要控制你，但你必須制伏罪。」</span>
<span className="v" id="v8" data-v="8" data-xref="馬太福音 23:35; 約翰一書 3:12–15; 猶大書 1:11"> 該隱對弟弟亞伯說：「我們去田間吧！」<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「我們去田間吧！」參照《七十士譯本》，希伯來文無此句。">a</a></sup>他們在田間的時候，該隱動手打亞伯，把他殺了。</span>
<span className="v" id="v9" data-v="9" data-xref="箴言 28:13; 約翰福音 8:44; 詩篇 9:12"> 後來，耶和華問該隱：「你弟弟亞伯在哪裡？」他說：「我不知道！難道我是我弟弟的看護人嗎？」</span>
<span className="v" id="v10" data-v="10" data-xref="希伯來書 12:24; 詩篇 72:14; 希伯來書 11:4"> 耶和華說：「你做了什麼事？你弟弟的血從地裡向我哭訴。</span>
<span className="v" id="v11" data-v="11" data-xref="加拉太書 3:10; 約伯記 16:18; 創世記 3:14"> 地張開口從你手上接受了你弟弟的血，現在你在地上必受咒詛。</span>
<span className="v" id="v12" data-v="12" data-xref="何西阿書 9:17; 利未記 26:36; 利未記 26:20"> 你種地，地卻不會再為你效力，你必在地上四處漂泊。」</span>
<span className="v" id="v13" data-v="13" data-xref="約伯記 15:22; 啟示錄 16:9; 啟示錄 16:11"> 該隱對耶和華說：「這懲罰太重！我承受不了。</span>
<span className="v" id="v14" data-v="14" data-xref="民數記 35:19; 詩篇 143:7; 約伯記 15:20–24"> 今天你把我從此地趕出去，使我不能再見你的面。我在地上四處漂泊，見到我的人都會殺我。」</span>
<span className="v" id="v15" data-v="15" data-xref="以西結書 9:4; 詩篇 79:12; 創世記 4:24"> 耶和華對他說：「不會的，因為凡殺你的，必遭受七倍的報應。」於是，耶和華在該隱身上留下一個記號，免得見到他的人殺他。</span>
<span className="v" id="v16" data-v="16" data-xref="耶利米書 23:39; 約伯記 2:7; 創世記 4:14"> 該隱離開耶和華，來到伊甸東邊的挪得住下來。</span>
</div>
</div>

## 該隱的後代

<div className="bt">
<div className="bp poetry">
<span className="v" id="v17" data-v="17" data-xref="詩篇 49:11; 傳道書 2:4–11; 但以理書 4:30"> 該隱和妻子同房，他的妻子就懷孕，生了以諾。該隱建了一座城，用他兒子的名字給這城取名叫以諾。</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 36:2; 創世記 5:21"> 以諾生以拿，以拿生米戶雅利，米戶雅利生瑪土撒利，瑪土撒利生拉麥。</span>
<span className="v" id="v19" data-v="19" data-xref="創世記 2:24; 馬太福音 19:8; 創世記 2:18"> 拉麥娶了兩個妻子，一個叫亞大，另一個叫洗拉。</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 4:2; 耶利米書 35:9–10; 約翰福音 8:44"> 亞大生了雅八，雅八是遊牧民族的祖先，</span>
<span className="v" id="v21" data-v="21" data-xref="約伯記 21:12; 以賽亞書 5:12; 創世記 31:27"> 雅八的弟弟叫猶八，他是彈琴吹笛之人的鼻祖。</span>
<span className="v" id="v22" data-v="22" data-xref="申命記 33:25; 申命記 8:9; 歷代志下 2:7"> 洗拉生了土八·該隱，他是打造各種銅鐵器具的匠人<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="「他是打造各種銅鐵器具的匠人」或譯「他是銅匠、鐵匠的祖先」。">b</a></sup>，他的妹妹叫拿瑪。</span>
<span className="v" id="v23" data-v="23" data-xref="民數記 23:18; 出埃及記 20:13; 利未記 19:18"> 拉麥對他的兩個妻子說：<br /><span className="pl pl-1">「亞大，洗拉，你們聽我的聲音；</span><br /><span className="pl pl-1">拉麥的妻子啊，側耳聽我的話，</span><br /><span className="pl pl-1">有人傷我，我殺了他，</span><br /><span className="pl pl-1">青年打我，我宰了他。</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="馬太福音 18:22; 創世記 4:15"> <span className="pl pl-1">殺該隱的遭受七倍的報應，</span><br /><span className="pl pl-1">殺拉麥的遭受七十七倍的報應。」</span></span>
</div>
</div>

## 塞特和以挪士

<div className="bt">
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="創世記 4:8; 創世記 4:10–11; 歷代志上 1:1"> 亞當又與妻子夏娃同房，夏娃生了一個兒子，取名叫塞特，因為她說：「上帝賜我另一個兒子來代替亞伯，因為該隱殺了他。」</span>
<span className="v" id="v26" data-v="26" data-xref="詩篇 116:17; 列王紀上 18:24; 約珥書 2:32"> 塞特生了一個兒子，給他取名叫以挪士。那時候，人開始求告耶和華的名。</span>
</div>

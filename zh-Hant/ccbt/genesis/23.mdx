## 亞伯拉罕買地葬撒拉

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 17:17"> 撒拉享年一百二十七歲。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 23:19; 創世記 13:18; 歷代志上 6:57"> 她在迦南境內的基列·亞巴，即希伯崙去世。亞伯拉罕在那裡痛哭，哀悼她。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 10:15; 創世記 23:7; 撒母耳記上 26:6"> 他從亡妻旁邊站起來對赫人說：</span>
<span className="v" id="v4" data-v="4" data-xref="歷代志上 29:15; 希伯來書 11:9; 創世記 17:8"> 「我在你們中間是異鄉客旅，請你們給我一塊墳地，我好埋葬我的亡妻。」</span>
<span className="v" id="v5" data-v="5"> 赫人答道：</span>
<span className="v" id="v6" data-v="6" data-xref="創世記 24:35; 創世記 14:14; 出埃及記 32:22"> 「我主，請聽我們說，你在我們中間是一位尊貴的王子，你可以選我們這裡最好的墳地，沒有人會反對你使用他的墳地埋葬你的妻子。」</span>
<span className="v" id="v7" data-v="7" data-xref="希伯來書 12:14; 創世記 19:1; 箴言 18:24"> 亞伯拉罕就起身向當地的赫人下拜，說：</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 25:9; 約翰一書 2:1–2; 列王紀上 2:17"> 「如果你們願意讓我安葬亡妻，就請答應我，代我求瑣轄的兒子以弗崙，</span>
<span className="v" id="v9" data-v="9" data-xref="羅馬書 13:8; 羅馬書 12:17"> 把他地頭的麥比拉洞賣給我。請他當著你們的面按實價賣給我作墳地。」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="創世記 34:20; 創世記 34:24; 創世記 23:18"> 當時以弗崙正坐在赫人當中，於是他當著所有出入城門口的赫人答覆亞伯拉罕說：</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 19:24; 以賽亞書 32:8; 申命記 19:15"> 「不可！我主，請聽我說，我當著族人的面，把那塊地和其中的山洞送給你。去安葬你的死者吧！」</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 23:7; 創世記 18:2; 創世記 19:1"> 亞伯拉罕向當地的人下拜，</span>
<span className="v" id="v13" data-v="13" data-xref="羅馬書 13:8; 撒母耳記下 24:24; 創世記 14:22–23"> 當眾對以弗崙說：「你若願意，請聽我說，我要把地錢給你，請你收下，好讓我在那裡安葬我的妻子。」</span>
<span className="v" id="v14" data-v="14"> 以弗崙回答說：</span>
<span className="v" id="v15" data-v="15" data-xref="以西結書 45:12; 出埃及記 30:13; 出埃及記 30:15"> 「我主，請聽我說，九十兩銀子的地對你我來說算什麼呢？去安葬你的妻子吧！」</span>
<span className="v" id="v16" data-v="16" data-xref="撒迦利亞書 11:12; 耶利米書 32:9; 出埃及記 30:13"> 於是，亞伯拉罕聽了以弗崙的意思，就照當眾提出的價錢，按市價稱了九十兩銀子給他。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="創世記 25:9; 創世記 50:13; 創世記 23:20"> 這樣，以弗崙在麥比拉、靠近幔利的那塊地和山洞及地界內所有的樹木，</span>
<span className="v" id="v18" data-v="18" data-xref="路得記 4:1; 耶利米書 32:12; 創世記 34:20"> 都歸了亞伯拉罕。這是在城門口的赫人面前買下的。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="創世記 50:13; 傳道書 12:7; 傳道書 12:5"> 之後，亞伯拉罕把妻子撒拉安葬在迦南的幔利附近、麥比拉田間的洞裡。幔利就是希伯崙。</span>
<span className="v" id="v20" data-v="20" data-xref="耶利米書 32:10–14; 路得記 4:7–10; 創世記 49:31–32"> 這塊赫人的地和其中的山洞從此成了亞伯拉罕家的墳地。</span>
</div>
</div>

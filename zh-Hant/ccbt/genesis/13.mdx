## 亞伯蘭與羅得分道揚鑣

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 12:9–20; 約書亞記 10:40; 撒母耳記下 24:7"> 亞伯蘭帶著妻子、侄兒羅得和所有的一切，離開埃及去南地。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 24:35; 詩篇 112:1–3; 創世記 26:12–13"> 那時亞伯蘭已經擁有很多牲畜和金銀。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 12:8–9; 創世記 12:6"> 他從南地漸漸遷移到伯特利，到了他從前在伯特利和艾中間搭帳篷和築壇的地方。他又在那裡求告耶和華的名。</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米書 49:29; 創世記 25:27; 創世記 4:20"> 和亞伯蘭同行的羅得也有牛群、羊群和帳篷。</span>
<span className="v" id="v6" data-v="6" data-xref="創世記 36:6–7; 傳道書 5:10–11; 提摩太前書 6:9"> 他們的牲畜很多，那地方容納不下，他們無法住在一起。</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 26:20; 創世記 12:6; 雅各書 3:16"> 亞伯蘭的牧人和羅得的牧人之間起了紛爭。那時，迦南人和比利洗人也住在那裡。</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多前書 6:6–7; 使徒行傳 7:26; 詩篇 133:1"> 亞伯蘭對羅得說：「我們之間不該有紛爭，我們的牧人之間也不該有紛爭，因為我們是骨肉至親。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 20:15; 創世記 34:10; 彼得前書 3:8–12"> 整片土地不就在你面前嗎？我們分開吧。如果你往左邊去，我就往右邊走；如果你往右邊去，我就往左邊走。」</span>
<span className="v" id="v10" data-v="10" data-xref="申命記 34:3; 以賽亞書 51:3; 創世記 14:8"> 羅得舉目眺望，看見整個約旦河平原，遠至瑣珥，水源充足。在耶和華毀滅所多瑪和蛾摩拉之前，那地方就好像耶和華的園子，又像埃及。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 13:9; 彼得前書 2:17; 希伯來書 10:25"> 於是，羅得選了整個約旦河平原，向東遷移，他們便分開了。</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 19:29; 創世記 14:12; 創世記 19:1"> 亞伯蘭住在迦南，羅得則住在平原的城邑裡，並漸漸把帳篷遷移到所多瑪附近。</span>
<span className="v" id="v13" data-v="13" data-xref="彼得後書 2:10; 彼得後書 2:6–8; 猶大書 1:7"> 所多瑪人極其邪惡，在耶和華眼中罪惡滔天。</span>
<span className="v" id="v14" data-v="14" data-xref="以賽亞書 49:18; 申命記 3:27; 創世記 28:14"> 羅得離開後，耶和華對亞伯蘭說：「從你站的地方向東西南北眺望，</span>
<span className="v" id="v15" data-v="15" data-xref="歷代志下 20:7; 創世記 35:12; 創世記 15:18"> 你所能看見的地方，我都要賜給你和你的後裔，直到永遠。</span>
<span className="v" id="v16" data-v="16" data-xref="創世記 28:14; 民數記 23:10; 創世記 32:12"> 我要使你的後裔多如地上的塵土，人若能數算地上的塵土，才能數算你的後裔。</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 13:15; 民數記 13:17–24"> 你起來走遍這片土地，因為我要把這片土地賜給你。」</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 18:1; 創世記 8:20; 創世記 35:27"> 亞伯蘭就把帳篷遷移到希伯崙，在幔利的橡樹附近居住，在那裡為耶和華築了一座祭壇。</span>

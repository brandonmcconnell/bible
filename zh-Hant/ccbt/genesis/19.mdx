## 上帝毀滅所多瑪和蛾摩拉

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 18:22; 創世記 18:1–5; 希伯來書 13:2"> 那兩個天使在黃昏的時候來到所多瑪，羅得正坐在城門口，看見他們，便起來迎接，俯伏在地上說：</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 18:4; 路加福音 24:28–29; 希伯來書 13:2"> 「我主啊，請到僕人家洗洗腳，住一夜，早上再繼續趕路吧！」他們說：「不，我們要在街上過夜。」</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 18:6–8; 士師記 6:19; 撒母耳記上 28:24"> 羅得執意邀請他們，他們便跟著進了他家。羅得設宴款待他們，烤了無酵餅，他們就吃了。</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 13:13; 箴言 4:16; 出埃及記 23:2"> 他們正準備就寢的時候，所多瑪城的男人從老到少全都出來，團團圍住羅得的房子，</span>
<span className="v" id="v5" data-v="5" data-xref="士師記 19:22; 以賽亞書 3:9; 猶大書 1:7"> 對羅得大喊大叫：「今晚到你家中作客的人在哪裡？把他們交出來，我們要跟他們交合！」</span>
<span className="v" id="v6" data-v="6" data-xref="士師記 19:23"> 羅得走出來，隨手關上門，到眾人面前，</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多前書 6:9–11; 士師記 19:23; 利未記 20:13"> 對他們說：「各位弟兄，請不要做這種邪惡的事！</span>
<span className="v" id="v8" data-v="8" data-xref="士師記 19:24; 創世記 19:31–38; 士師記 9:15"> 我有兩個女兒，還是處女，我把她們交出來，任憑你們處置，只是請你們不要動這兩個人，因為他們到我舍下做客。」</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及記 2:14; 彼得後書 2:7–8; 創世記 13:12"> 他們對羅得說：「走開！」又說：「這個寄居的人竟當起審判官來啦！現在我們要用更狠的手段對付你。」眾人便推擠羅得，想要破門而入。</span>
<span className="v" id="v10" data-v="10"> 那兩位天使伸手把羅得拉進屋裡，關上了門，</span>
<span className="v" id="v11" data-v="11" data-xref="列王紀下 6:18; 使徒行傳 13:11; 申命記 28:28–29"> 並讓門外的人，不論老少都眼目昏迷，摸來摸去也找不著羅得家的門。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="創世記 7:1; 彼得後書 2:7; 啟示錄 18:4"> 天使對羅得說：「你這裡還有什麼人嗎？你要帶兒女、女婿和城裡其他親人離開這裡，</span>
<span className="v" id="v13" data-v="13" data-xref="創世記 18:20; 馬太福音 13:49–50; 猶大書 1:7"> 因為我們就要毀滅這城了。耶和華已經聽見對城中百姓的極大控訴，祂差遣我們來毀滅這城。」</span>
<span className="v" id="v14" data-v="14" data-xref="民數記 16:21; 耶利米書 51:6; 民數記 16:45"> 羅得聽了就去通知他女兒的未婚夫說：「趕快離開這地方！耶和華要毀滅這城了！」可是他們卻以為他是在開玩笑。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="民數記 16:24–27; 啟示錄 18:4; 創世記 19:22"> 天剛亮的時候，天使便催促羅得說：「趕快帶著你的妻子和這裡的兩個女兒離開，免得所多瑪城因罪惡受懲罰的時候，你也一起被毀滅。」</span>
<span className="v" id="v16" data-v="16" data-xref="羅馬書 9:15–16; 提多書 3:5; 約翰福音 6:44"> 羅得卻猶豫不決，天使便拉著羅得及其妻子和兩個女兒的手出去，將他們帶出去，安置在城外，因為耶和華憐憫他們。</span>
<span className="v" id="v17" data-v="17" data-xref="馬太福音 24:16–18; 路加福音 9:62; 腓立比書 3:13–14"> 帶他們到了城外之後，其中一位說：「趕快逃命！不要回頭看，也不要留在平原，要往山上逃，免得你們被毀滅。」</span>
<span className="v" id="v18" data-v="18" data-xref="約翰福音 13:6–8; 使徒行傳 10:14; 創世記 32:26"> 羅得說：「我主啊，請不要這樣。</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳記上 27:1; 詩篇 103:1–22; 提摩太前書 1:14–16"> 僕人蒙你厚愛、施恩相救，但我無法逃到山上，要是這災難追上我，我就沒命了！</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 119:175; 箴言 3:5–7; 創世記 19:30"> 請看，那座城離這裡不遠，容易跑到，又是座小城，請讓我逃到那座小城活命吧！」</span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 145:19; 詩篇 34:15; 詩篇 102:17"> 天使回答說：「好吧，我也答應你，不毀滅你說的那座城。</span>
<span className="v" id="v22" data-v="22" data-xref="創世記 13:10; 創世記 14:2; 創世記 32:25–28"> 你趕快逃去那裡吧，因為你到達那裡之前，我不能動手。」因此那城便叫瑣珥<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「瑣珥」意思是「小」。">a</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23"> 羅得到達瑣珥的時候，太陽已經出來了。</span>
<span className="v" id="v24" data-v="24" data-xref="申命記 29:23; 以賽亞書 13:19; 阿摩司書 4:11"> 耶和華親自從天上把燃燒的硫磺降在所多瑪和蛾摩拉兩地，</span>
<span className="v" id="v25" data-v="25" data-xref="詩篇 107:34; 創世記 14:3; 創世記 13:10"> 毀滅了這些城和其中的居民，包括整個平原和地上的植物。</span>
<span className="v" id="v26" data-v="26" data-xref="路加福音 17:31–32; 創世記 19:17; 箴言 14:14"> 羅得的妻子跟在他後面，她回頭一望，就變成了一根鹽柱。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="哈巴谷書 2:1; 詩篇 5:3; 希伯來書 2:1"> 亞伯拉罕清早起來，到他從前站在耶和華面前的地方，</span>
<span className="v" id="v28" data-v="28" data-xref="啟示錄 18:9; 啟示錄 9:2; 啟示錄 21:8"> 向所多瑪、蛾摩拉和整個平原眺望，只見那裡濃煙滾滾，好像火窯的煙一樣。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="創世記 8:1; 申命記 9:5; 創世記 18:23–33"> 這樣，上帝顧念亞伯拉罕，在毀滅平原各城的時候，讓羅得逃離所住的城市，免遭毀滅。</span>
</div>
</div>

## 羅得與他的女兒

<div className="bt">
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="創世記 19:19; 以賽亞書 15:5; 雅各書 1:8"> 羅得不敢住在瑣珥，便帶著兩個女兒來到山上，住在一個洞裡。</span>
<span className="v" id="v31" data-v="31" data-xref="申命記 25:5; 以賽亞書 4:1; 創世記 16:2"> 他的大女兒對小女兒說：「我們的父親年紀大了，這裡又沒有男子可以照著世上的習俗娶我們。</span>
<span className="v" id="v32" data-v="32" data-xref="利未記 18:6–7; 創世記 11:3; 創世記 9:21"> 來，我們灌醉父親，然後跟他睡覺，藉著他傳宗接代吧。」</span>
<span className="v" id="v33" data-v="33" data-xref="哈巴谷書 2:15–16; 箴言 23:29–35; 箴言 20:1"> 於是，那晚她們灌醉了父親，大女兒進去和父親睡。她什麼時候躺下，什麼時候起來，羅得完全不知道。</span>
<span className="v" id="v34" data-v="34" data-xref="耶利米書 8:12; 耶利米書 6:15; 以賽亞書 3:9"> 第二天，大女兒對妹妹說：「昨晚我已經和父親睡了，今晚我們再灌醉他，然後你進去和他睡。這樣，我們就可以藉著父親傳宗接代。」</span>
<span className="v" id="v35" data-v="35" data-xref="箴言 24:16; 詩篇 8:4; 彼得前書 4:7"> 當晚，她們又灌醉了父親，小女兒進去與他睡。她什麼時候躺下，什麼時候起來，羅得完全不知道。</span>
<span className="v" id="v36" data-v="36" data-xref="哈巴谷書 2:15; 士師記 1:7; 馬太福音 7:2"> 這樣，羅得的兩個女兒都從父親懷了孕。</span>
<span className="v" id="v37" data-v="37" data-xref="申命記 2:9; 列王紀下 3:1–27; 民數記 21:29"> 大女兒生了一個兒子，給他取名叫摩押<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="「摩押」意思是「出自父親」。">b</a></sup>，他是今天摩押人的祖先。</span>
<span className="v" id="v38" data-v="38" data-xref="申命記 2:19; 士師記 10:6–40; 詩篇 83:4–8"> 小女兒也生了一個兒子，給他取名叫便·亞米<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="「便·亞米」意思是「親人的兒子」。">c</a></sup>，他是今天亞捫人的祖先。</span>
</div>

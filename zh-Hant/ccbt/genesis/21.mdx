## 以撒出生

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="詩篇 12:6; 創世記 18:10; 創世記 18:14"> 耶和華按著自己說過的話眷顧撒拉，成就給她的應許。</span>
<span className="v" id="v2" data-v="2" data-xref="加拉太書 4:22; 希伯來書 11:11; 創世記 18:10"> 亞伯拉罕年老的時候，撒拉懷了孕，在上帝指定的日期為他生了一個兒子。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 17:19; 羅馬書 9:7; 創世記 21:6"> 亞伯拉罕為撒拉所生的兒子取名叫以撒。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行傳 7:8; 申命記 12:32; 約翰福音 7:22–23"> 以撒出生後第八天，亞伯拉罕就照著上帝的吩咐為他行了割禮。</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 17:17; 羅馬書 4:19; 創世記 17:1"> 以撒出生時亞伯拉罕已經一百歲。</span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 126:2; 以賽亞書 54:1; 創世記 17:17"> 撒拉說：「上帝使我歡笑，凡聽見這事的人也必跟我一同歡笑。</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 18:11–12; 以賽亞書 66:8; 帖撒羅尼迦後書 1:10"> 誰會對亞伯拉罕說撒拉要哺養孩子呢？我竟然在他年老的時候給他生了兒子。」</span>
</div>
</div>

## 夏甲和以實瑪利被逐

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="撒母耳記上 1:22; 何西阿書 1:8; 創世記 40:20"> 以撒漸漸長大，亞伯拉罕在他斷奶的那天大擺宴席。</span>
<span className="v" id="v9" data-v="9" data-xref="加拉太書 4:29; 創世記 16:15; 加拉太書 4:22"> 撒拉見埃及人夏甲給亞伯拉罕生的兒子以實瑪利嘲笑以撒，</span>
<span className="v" id="v10" data-v="10" data-xref="約翰福音 8:35; 約翰一書 2:19; 加拉太書 4:22–31"> 就對亞伯拉罕說：「趕走這婢女和她的兒子，因為這婢女的兒子不可和我的兒子以撒一同承受產業。」</span>
<span className="v" id="v11" data-v="11" data-xref="希伯來書 12:11; 創世記 17:18; 馬太福音 10:37"> 亞伯拉罕因兒子以實瑪利的事非常苦惱。</span>
<span className="v" id="v12" data-v="12" data-xref="希伯來書 11:18; 羅馬書 9:7–8; 創世記 17:19"> 上帝對亞伯拉罕說：「你不要再為這孩子和你的婢女苦惱，只管照撒拉的話做，因為以撒生的才可算為你的後裔。</span>
<span className="v" id="v13" data-v="13" data-xref="創世記 16:10; 創世記 17:20; 創世記 21:18"> 至於婢女的兒子以實瑪利，我也會使他自成一國，因為他也是你的後裔。」</span>
<span className="v" id="v14" data-v="14" data-xref="傳道書 9:10; 詩篇 119:60; 創世記 16:7"> 第二天，亞伯拉罕清早起來，把食物和一皮袋水給了夏甲，放在她肩上，讓她和孩子離開。夏甲就走了，在別示巴的曠野流浪。</span>
<span className="v" id="v15" data-v="15" data-xref="列王紀下 3:9; 詩篇 63:1; 耶利米書 14:3"> 皮袋的水喝光了，夏甲把兒子留在一叢灌木下，</span>
<span className="v" id="v16" data-v="16" data-xref="以賽亞書 49:15; 創世記 29:11; 撒母耳記上 24:16"> 自己走到離孩子約一箭之遠的地方，對著孩子坐下，說：「我不忍心看著他死啊！」夏甲坐在那裡放聲大哭起來。</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 16:11; 詩篇 50:15; 出埃及記 3:7"> 上帝聽見孩子的哭聲，就差遣天使從天上安慰夏甲說：「夏甲，你怎麼了？不要害怕，上帝已經聽見孩子的哭聲了。</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 21:13; 創世記 16:10; 創世記 17:20"> 你去扶他起來，用手攙著他，我必使他成為大國。」</span>
<span className="v" id="v19" data-v="19" data-xref="民數記 22:31; 列王紀下 6:17–20; 以賽亞書 35:5–6"> 上帝開了夏甲的眼睛，讓她看見一口水井，她就上前把皮袋裝滿水拿給兒子喝。</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 28:15; 創世記 39:21; 創世記 16:12"> 在上帝的看顧下，孩子漸漸長大。他住在曠野，成為一個射箭能手。</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 26:34–35; 創世記 24:3–4; 民數記 12:16"> 他住在巴蘭曠野，他母親為他娶了一個埃及女子。</span>
</div>
</div>

## 亞伯拉罕與亞比米勒立約

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="約書亞記 3:7; 創世記 26:26; 創世記 26:28"> 那時，亞比米勒和他的將領非各對亞伯拉罕說：「你做的一切都有上帝保佑。</span>
<span className="v" id="v23" data-v="23" data-xref="約書亞記 2:12; 創世記 20:14; 希伯來書 6:16"> 現在請你在這裡當著上帝的面向我起誓，你不會欺騙我和我的子孫後代。我怎樣善待你，請你也同樣善待我以及你所寄居之地的百姓。」</span>
<span className="v" id="v24" data-v="24" data-xref="希伯來書 6:16; 創世記 14:13; 羅馬書 12:18"> 亞伯拉罕說：「我願起誓。」</span>
<span className="v" id="v25" data-v="25" data-xref="創世記 26:15–22; 創世記 29:8; 箴言 25:9"> 由於亞比米勒的僕人霸佔了一口水井，亞伯拉罕就指責亞比米勒。</span>
<span className="v" id="v26" data-v="26" data-xref="創世記 13:7; 列王紀下 5:20–24"> 亞比米勒說：「我不知道是誰做的，你以前沒有告訴我，我今天才聽說這事。」</span>
<span className="v" id="v27" data-v="27" data-xref="創世記 14:22–23; 以賽亞書 32:8; 羅馬書 1:31"> 亞伯拉罕把牛羊送給亞比米勒，他們二人立了約。</span>
<span className="v" id="v28" data-v="28"> 亞伯拉罕又從羊群中分出七隻母羊羔。</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳記上 15:14; 創世記 33:8; 出埃及記 12:26"> 亞比米勒問亞伯拉罕：「你分出七隻母羊羔是什麼意思？」</span>
<span className="v" id="v30" data-v="30" data-xref="創世記 31:52; 約書亞記 24:27; 約書亞記 22:27–28"> 亞伯拉罕回答說：「你要從我手中接受這七隻母羊羔，以證明這口井是我挖的。」</span>
<span className="v" id="v31" data-v="31" data-xref="創世記 26:33; 創世記 21:14; 列王紀上 4:25"> 所以，那地方被稱為別示巴<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「別示巴」意思是「盟誓之井」。">a</a></sup>，因為他們二人在那裡起了誓。</span>
<span className="v" id="v32" data-v="32" data-xref="出埃及記 13:17; 創世記 21:27; 士師記 13:1"> 他們在別示巴立約以後，亞比米勒和他的將領非各便回非利士去了。</span>
<span className="v" id="v33" data-v="33" data-xref="提摩太前書 1:17; 以賽亞書 40:28; 詩篇 90:2"> 亞伯拉罕在別示巴栽了一棵柳樹，又在那裡呼求永恆上帝耶和華的名。</span>
<span className="v" id="v34" data-v="34" data-xref="歷代志上 29:15; 彼得前書 2:11; 希伯來書 11:9"> 亞伯拉罕在非利士人那裡住了很長時間。</span>
</div>
</div>

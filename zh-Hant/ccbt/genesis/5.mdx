## 亞當的後代

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以弗所書 4:24; 歌羅西書 3:10; 創世記 1:26–27"> 以下是關於亞當後代的記載。 上帝造人的時候，是照祂自己的樣式造的。</span>
<span className="v" id="v2" data-v="2" data-xref="馬太福音 19:4; 馬可福音 10:6; 創世記 2:23"> 祂造了男人和女人，又賜福給他們，並在造他們的那日稱他們為「人」。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 4:25; 約伯記 25:4; 詩篇 51:5"> 亞當一百三十歲時生了一子，樣式和形像與自己相似，就給他取名叫塞特。</span>
<span className="v" id="v4" data-v="4" data-xref="歷代志上 1:1–3; 路加福音 3:36–38; 創世記 5:26"> 亞當生了塞特以後，又活了八百年，生兒育女，</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 5:8; 創世記 5:11; 創世記 3:19"> 共活了九百三十歲才去世。</span>
<span className="v" id="v6" data-v="6" data-xref="創世記 4:26"> 塞特一百零五歲時生以挪士，</span>
<span className="v" id="v7" data-v="7"> 之後又活了八百零七年，生兒育女，</span>
<span className="v" id="v8" data-v="8"> 共活了九百一十二歲才去世。</span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 3:37; 歷代志上 1:2"> 以挪士九十歲時生該南，</span>
<span className="v" id="v10" data-v="10"> 之後又活了八百一十五年，生兒育女，</span>
<span className="v" id="v11" data-v="11"> 共活了九百零五歲才去世。</span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 3:37"> 該南七十歲時生瑪勒列，</span>
<span className="v" id="v13" data-v="13"> 之後又活了八百四十年，生兒育女，</span>
<span className="v" id="v14" data-v="14"> 共活了九百一十歲才去世。</span>
<span className="v" id="v15" data-v="15" data-xref="歷代志上 1:2"> 瑪勒列六十五歲時生雅列，</span>
<span className="v" id="v16" data-v="16"> 之後又活了八百三十年，生兒育女，</span>
<span className="v" id="v17" data-v="17"> 共活了八百九十五歲才去世。</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 4:17; 歷代志上 1:3; 猶大書 1:14–15"> 雅列一百六十二歲時生以諾，</span>
<span className="v" id="v19" data-v="19"> 之後又活了八百年，生兒育女，</span>
<span className="v" id="v20" data-v="20"> 共活了九百六十二歲才去世。</span>
<span className="v" id="v21" data-v="21" data-xref="路加福音 3:37"> 以諾六十五歲時生瑪土撒拉，</span>
<span className="v" id="v22" data-v="22" data-xref="帖撒羅尼迦前書 2:12; 創世記 17:1; 創世記 6:9"> 之後與上帝親密同行三百年，生兒育女，</span>
<span className="v" id="v23" data-v="23"> 共活了三百六十五歲。</span>
<span className="v" id="v24" data-v="24" data-xref="希伯來書 11:5–6; 約翰一書 1:7; 創世記 5:22"> 以諾與上帝親密同行，後來被上帝接去，不在世上了。</span>
<span className="v" id="v25" data-v="25" data-xref="創世記 4:18"> 瑪土撒拉一百八十七歲時生拉麥，</span>
<span className="v" id="v26" data-v="26"> 之後又活了七百八十二年，生兒育女，</span>
<span className="v" id="v27" data-v="27"> 共活了九百六十九歲才去世。</span>
<span className="v" id="v28" data-v="28"> 拉麥一百八十二歲時生了一個兒子，</span>
<span className="v" id="v29" data-v="29" data-xref="彼得後書 2:5; 希伯來書 11:7; 馬太福音 24:37"> 取名叫挪亞<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="希伯來文中「挪亞」與「安慰」諧音。">a</a></sup>，他說：「耶和華咒詛了大地，這孩子必使我們從艱辛勞苦中得安慰。」</span>
<span className="v" id="v30" data-v="30"> 拉麥生挪亞之後，又活了五百九十五年，生兒育女，</span>
<span className="v" id="v31" data-v="31"> 共活了七百七十七歲才去世。</span>
<span className="v" id="v32" data-v="32" data-xref="創世記 6:10; 創世記 10:21; 創世記 9:18–19"> 挪亞五百歲後生閃、含和雅弗。</span>
</div>

<span className="v" id="v1" data-v="1" data-xref="出埃及記 31:17; 出埃及記 20:11; 詩篇 33:6"> 天地萬物都造好了。</span>
<span className="v" id="v2" data-v="2" data-xref="希伯來書 4:4; 出埃及記 31:17; 申命記 5:14"> 第七日，上帝完成了祂的創造之工，就在第七日歇了一切的工。</span>
<span className="v" id="v3" data-v="3" data-xref="以西結書 20:12; 馬可福音 2:27; 利未記 23:3"> 上帝賜福給第七日，將其定為聖日，因為祂在這一日歇了祂一切的創造之工。</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 5:1; 啟示錄 1:8; 創世記 1:4"> 這是有關創造天地的記載。 上帝造亞當和夏娃 耶和華上帝創造天地的時候，</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 3:23; 希伯來書 6:7; 約伯記 5:10"> 地上還沒有草木，也沒有長出菜蔬，因為耶和華上帝還沒有降雨在地上，土地也沒有人耕作，</span>
<span className="v" id="v6" data-v="6"> 但有水從地裡湧出，澆灌大地。</span>
<span className="v" id="v7" data-v="7" data-xref="傳道書 12:7; 約伯記 33:4; 哥林多前書 15:45"> 耶和華上帝用地上的塵土造人，把生命的氣息吹進他的鼻孔裡，他就成了有生命的人。</span>
<span className="v" id="v8" data-v="8" data-xref="以西結書 28:13; 創世記 3:24; 創世記 13:10"> 耶和華上帝在東方的伊甸開闢了一個園子，把祂所造的人安置在裡面。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 3:22; 啟示錄 2:7; 啟示錄 22:14"> 耶和華上帝使地裡長出各種樹木，它們既好看又有好吃的果子。在園子的中間有生命樹和分別善惡的樹。</span>
<span className="v" id="v10" data-v="10" data-xref="啟示錄 22:1; 詩篇 46:4"> 有一條河從伊甸流出來灌溉那園子，又從那裡分成四條河流。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 25:18; 創世記 10:29; 撒母耳記上 15:7"> 第一條支流叫比遜河，它環繞著哈腓拉全境，那裡有金子，</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及記 28:20; 民數記 11:7; 以西結書 28:13"> 且是上好的金子，還有珍珠和紅瑪瑙。</span>
<span className="v" id="v13" data-v="13" data-xref="創世記 10:6; 以賽亞書 11:11"> 第二條支流叫基訓河，它環繞著古實全境。</span>
<span className="v" id="v14" data-v="14" data-xref="但以理書 10:4; 創世記 15:18; 申命記 1:7"> 第三條支流叫底格里斯河，它流經亞述的東邊。第四條支流叫幼發拉底河。</span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 128:2; 創世記 2:8; 以弗所書 4:28"> 耶和華上帝把那人安置在伊甸的園子裡，讓他在那裡耕種、看管園子。</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳記上 15:22; 提摩太前書 4:4; 提摩太前書 6:17"> 耶和華上帝吩咐那人說：「你可以隨意吃園中各種樹上的果子，</span>
<span className="v" id="v17" data-v="17" data-xref="羅馬書 6:23; 雅各書 1:15; 創世記 3:19"> 只是不可吃那棵分別善惡樹的果子，因為你吃的日子必定死。」</span>
<span className="v" id="v18" data-v="18" data-xref="傳道書 4:9–12; 哥林多前書 11:7–12; 箴言 18:22"> 耶和華上帝說：「那人獨自一人不好，我要為他造一個相配的幫手。」</span>
<span className="v" id="v19" data-v="19" data-xref="詩篇 8:4–8; 創世記 1:28; 創世記 9:2"> 耶和華上帝用塵土造了各種田野的走獸和空中的飛鳥，把牠們帶到那人跟前，看他怎麼叫牠們。他叫這些動物什麼，牠們的名字就是什麼。</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 2:18"> 那人給所有的牲畜及空中的飛鳥和田野的走獸都起了名字。可是他找不到一個跟自己相配的幫手。</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 15:12; 約伯記 4:13; 撒母耳記上 26:12"> 耶和華上帝使那人沉睡，然後在他沉睡的時候從他身上取出一根肋骨，再把肉合起來。</span>
<span className="v" id="v22" data-v="22" data-xref="哥林多前書 11:8–9; 提摩太前書 2:13; 希伯來書 13:4"> 耶和華上帝用那根肋骨造了一個女人，把她帶到那人跟前。</span>
<span className="v" id="v23" data-v="23" data-xref="以弗所書 5:28–30; 哥林多前書 11:8–9; 撒母耳記下 5:1"> 那人說：<br /><span className="pl pl-1">「這才是我骨中的骨，</span><br /><span className="pl pl-1">肉中的肉，</span><br /><span className="pl pl-1">要稱她為女人，</span><br /><span className="pl pl-1">因為她是從男人身上取出來的。」</span></span>
<span className="v" id="v24" data-v="24" data-xref="馬太福音 19:3–9; 以弗所書 5:28–31; 馬可福音 10:6–12"> 因此，人要離開父母，與妻子結合，二人成為一體。</span>
<span className="v" id="v25" data-v="25" data-xref="創世記 3:7; 創世記 3:10–11; 羅馬書 10:11"> 當時，他們夫婦二人都赤身露體，並不覺得羞恥。</span>

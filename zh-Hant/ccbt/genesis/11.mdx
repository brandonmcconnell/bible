## 巴別塔

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行傳 2:6; 西番雅書 3:9; 以賽亞書 19:18"> 那時，天下人都用同一種語言，講同一種話。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 10:10; 但以理書 1:2; 創世記 14:1"> 人們向東遷移時，在示拿地區找到一處平原，定居下來。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 14:10; 出埃及記 1:14; 出埃及記 2:3"> 他們彼此商量說：「來呀，我們製作磚，把磚燒透吧。」他們用磚作石塊，用柏油作灰泥來造塔，</span>
<span className="v" id="v4" data-v="4" data-xref="申命記 1:28; 約翰福音 5:44; 路加福音 1:51"> 說：「來吧，讓我們造一座城和一座高聳入雲的塔，這樣我們可以為自己揚名，不致分散在普天之下。」</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 18:21; 詩篇 33:13–14; 約翰福音 3:13"> 耶和華下來察看人建造的城和塔。</span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 2:1–4; 創世記 3:22; 創世記 11:1"> 耶和華說：「看啊，他們同屬一個民族，都用同一種語言，現在就開始做這樣的事，如果繼續下去，他們會為所欲為。</span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 33:10; 詩篇 55:9; 約伯記 5:12–13"> 來吧，我們下去變亂他們的語言，使他們彼此言語不通。」</span>
<span className="v" id="v8" data-v="8" data-xref="路加福音 1:51; 申命記 32:8; 創世記 10:25"> 於是，耶和華把他們從那裡分散到普天之下，他們便停止建城了。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 10:10; 創世記 10:5; 創世記 10:20"> 因此，人稱那城為巴別，因為耶和華在那裡變亂了世人的語言，把他們分散到普天之下。</span>
</div>
</div>

## 閃的後代

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="歷代志上 1:17–27; 創世記 10:21–22; 路加福音 3:34–36"> 以下是閃的後代。 洪水過後兩年，閃一百歲時生亞法撒，</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 9:7; 詩篇 144:12; 創世記 1:28"> 之後又活了五百年，生兒育女。</span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 3:36"> 亞法撒三十五歲時生沙拉，</span>
<span className="v" id="v13" data-v="13"> 之後又活了四百零三年，生兒育女。</span>
<span className="v" id="v14" data-v="14"> 沙拉三十歲時生希伯，</span>
<span className="v" id="v15" data-v="15"> 之後又活了四百零三年，生兒育女。</span>
<span className="v" id="v16" data-v="16" data-xref="創世記 10:21; 歷代志上 1:19; 民數記 24:24"> 希伯三十四歲時生法勒，</span>
<span className="v" id="v17" data-v="17"> 之後又活了四百三十年，生兒育女。</span>
<span className="v" id="v18" data-v="18" data-xref="路加福音 3:35"> 法勒三十歲時生拉吳，</span>
<span className="v" id="v19" data-v="19"> 之後又活了二百零九年，生兒育女。</span>
<span className="v" id="v20" data-v="20" data-xref="路加福音 3:35"> 拉吳三十二歲時生西鹿，</span>
<span className="v" id="v21" data-v="21"> 之後又活了二百零七年，生兒育女。</span>
<span className="v" id="v22" data-v="22" data-xref="約書亞記 24:2"> 西鹿三十歲時生拿鶴，</span>
<span className="v" id="v23" data-v="23"> 之後又活了二百年，生兒育女。</span>
<span className="v" id="v24" data-v="24" data-xref="路加福音 3:34; 約書亞記 24:2"> 拿鶴二十九歲時生他拉，</span>
<span className="v" id="v25" data-v="25"> 之後又活了一百一十九年，生兒育女。</span>
<span className="v" id="v26" data-v="26" data-xref="約書亞記 24:2; 歷代志上 1:26–27; 創世記 22:20–24"> 他拉七十歲後，生了亞伯蘭、拿鶴和哈蘭。</span>
</div>
</div>

## 他拉的後代

<div className="bt">
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="創世記 12:4; 創世記 14:12; 創世記 11:31"> 以下是他拉的後代。 他拉生亞伯蘭、拿鶴和哈蘭，哈蘭生羅得。</span>
<span className="v" id="v28" data-v="28" data-xref="創世記 15:7; 尼希米記 9:7; 使徒行傳 7:2–4"> 哈蘭比他父親他拉先去世，他死在自己的家鄉迦勒底的吾珥。</span>
<span className="v" id="v29" data-v="29" data-xref="創世記 17:15; 創世記 22:20; 創世記 24:15"> 亞伯蘭和拿鶴都娶了妻子，亞伯蘭的妻子名叫撒萊，拿鶴的妻子名叫密迦，是哈蘭的女兒。哈蘭是密迦和亦迦的父親。</span>
<span className="v" id="v30" data-v="30" data-xref="創世記 29:31; 創世記 21:1–2; 路加福音 1:7"> 撒萊不能生育，沒有孩子。</span>
<span className="v" id="v31" data-v="31" data-xref="尼希米記 9:7; 使徒行傳 7:2–4; 創世記 24:10"> 他拉帶著兒子亞伯蘭、孫子——哈蘭的兒子羅得、兒媳婦——亞伯蘭的妻子撒萊，離開迦勒底的吾珥前往迦南，他們來到哈蘭，在那裡定居下來。</span>
<span className="v" id="v32" data-v="32"> 他拉在那裡去世，享年二百零五歲<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「二百零五歲」有古卷作「一百四十五歲」。">a</a></sup>。</span>
</div>
</div>

## 上帝創造天地

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="約翰福音 1:1–3; 希伯來書 11:3; 以賽亞書 45:18"> 太初，上帝創造了天地。</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米書 4:23; 詩篇 104:30; 以賽亞書 45:18"> 那時，大地空虛混沌，黑暗籠罩著深淵，上帝的靈運行在水面上。</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多後書 4:6; 約翰福音 1:5; 以賽亞書 45:7"> 上帝說：「要有光！」就有了光。</span>
<span className="v" id="v4" data-v="4" data-xref="傳道書 2:13; 創世記 1:18; 傳道書 11:7"> 上帝看光是好的，就把光和黑暗分開。</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 74:16; 以賽亞書 45:7; 帖撒羅尼迦前書 5:5"> 上帝稱光為晝，稱黑暗為夜。晚上過去，早晨到來，這是第一日<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「這是第一日」或譯「這是一日」。">a</a></sup>。</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米書 51:15; 詩篇 33:6; 約伯記 37:18"> 上帝說：「水與水之間要有穹蒼，把水分開。」</span>
<span className="v" id="v7" data-v="7" data-xref="箴言 8:28–29; 詩篇 148:4; 馬太福音 8:27"> 果然如此。上帝造了穹蒼，將穹蒼之下的水和穹蒼之上的水分開。</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 1:5; 創世記 1:19; 創世記 1:10"> 上帝稱穹蒼為天空。晚上過去，早晨到來，這是第二日。</span>
<span className="v" id="v9" data-v="9" data-xref="彼得後書 3:5; 約拿書 1:9; 耶利米書 5:22"> 上帝說：「天空下面的水要聚在一處，使乾地露出來。」果然如此。</span>
<span className="v" id="v10" data-v="10" data-xref="申命記 32:4; 詩篇 104:31; 創世記 1:4"> 上帝稱乾地為陸地，稱匯聚的水為海洋。上帝看了，覺得美好。</span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 104:14–17; 希伯來書 6:7; 詩篇 147:8"> 上帝說：「陸地要長出植物——各類結種子的菜蔬和結果子的樹木，果子內都有籽。」果然如此，</span>
<span className="v" id="v12" data-v="12" data-xref="馬可福音 4:28; 以賽亞書 55:10–11; 馬太福音 13:24–26"> 陸地長出了植物——各類結種子的菜蔬和結果子的樹木，果子內都有籽。上帝看了，覺得美好。</span>
<span className="v" id="v13" data-v="13"> 晚上過去，早晨到來，這是第三日。</span>
<span className="v" id="v14" data-v="14" data-xref="詩篇 104:19–20; 申命記 4:19; 耶利米書 31:35"> 上帝說：「天空要有光體，以區分晝夜，作記號，定節令，計算年日，</span>
<span className="v" id="v15" data-v="15"> 在天空發光，普照大地。」果然如此。</span>
<span className="v" id="v16" data-v="16" data-xref="詩篇 136:7–9; 申命記 4:19; 詩篇 8:3"> 上帝造了兩個大光體，大的管晝，小的管夜，又造了星辰。</span>
<span className="v" id="v17" data-v="17" data-xref="詩篇 8:3; 詩篇 8:1; 約伯記 38:12"> 上帝把這些光體擺列在天空，讓它們發光普照大地，</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米書 31:35; 詩篇 19:6"> 管理晝夜，分開光和黑暗。上帝看了，覺得美好。</span>
<span className="v" id="v19" data-v="19"> 晚上過去，早晨到來，這是第四日。</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 2:19; 詩篇 104:24–25; 列王紀上 4:33"> 上帝說：「水中要充滿各種動物，空中要有禽鳥飛翔。」</span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 104:24–26; 創世記 1:25; 創世記 8:19"> 上帝就創造了海中的大魚等各類水族和各類禽鳥。上帝看了，覺得美好。</span>
<span className="v" id="v22" data-v="22" data-xref="約伯記 40:15; 創世記 8:17; 詩篇 107:38"> 上帝賜福給這一切生物，說：「水族要多多地生養繁衍，充滿海洋，禽鳥也要在地上多多地繁衍。」</span>
<span className="v" id="v23" data-v="23"> 晚上過去，早晨到來，這是第五日。</span>
<span className="v" id="v24" data-v="24" data-xref="詩篇 50:9–10; 創世記 6:20; 創世記 8:19"> 上帝說：「大地要繁衍各類動物——各類的牲畜、爬蟲和野獸。」果然如此。</span>
<span className="v" id="v25" data-v="25" data-xref="耶利米書 27:5; 約伯記 12:8–10; 創世記 2:19–20"> 上帝造了地上的各類野獸、牲畜和爬蟲。上帝看了，覺得美好。</span>
</div>
</div>

## 上帝照自己的形像造人

<div className="bt">
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="歌羅西書 3:10; 以弗所書 4:24; 詩篇 8:4–8"> 上帝說：「我們要照著我們的形像，按著我們的樣式造人，讓他們管理海裡的魚、空中的鳥和地上的牲畜及一切爬蟲。」</span>
<span className="v" id="v27" data-v="27" data-xref="馬太福音 19:4; 以弗所書 2:10; 創世記 5:1–2"> 上帝就照著自己的形像造了人，祂照著自己的形像造了男人和女人。</span>
<span className="v" id="v28" data-v="28" data-xref="創世記 9:1; 創世記 9:7; 利未記 26:9"> 上帝賜福給他們，對他們說：「你們要生養眾多，遍滿地面，治理大地，管理海裡的魚、空中的鳥以及地上的各種動物。」</span>
<span className="v" id="v29" data-v="29" data-xref="創世記 9:3; 詩篇 104:14–15; 詩篇 145:15–16"> 上帝說：「看啊，我把地上所有結種子的穀蔬和所有樹上有籽的果子，都賜給你們作食物。</span>
<span className="v" id="v30" data-v="30" data-xref="詩篇 104:14; 詩篇 145:15–16; 詩篇 147:9"> 我把綠色植物賜給所有地上的走獸、空中的飛鳥，及地上的爬蟲等有氣息的動物作食物。」果然如此。</span>
<span className="v" id="v31" data-v="31" data-xref="提摩太前書 4:4; 詩篇 104:24; 詩篇 19:1–2"> 上帝看了祂所造的一切，覺得非常美好。晚上過去，早晨到來，這是第六日。</span>
</div>

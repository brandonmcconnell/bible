## 底娜受辱

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 30:21; 耶利米書 2:36; 創世記 30:13"> 一天，利亞給雅各所生的女兒底娜到外面去見當地的女子。</span>
<span className="v" id="v2" data-v="2" data-xref="馬太福音 5:28; 約伯記 31:1; 約伯記 31:9"> 當地首領希未人哈抹的兒子示劍看到她，就抓住她，強行玷污了她。</span>
<span className="v" id="v3" data-v="3" data-xref="何西阿書 2:14; 以賽亞書 40:2; 歷代志下 30:22"> 他戀慕雅各的女兒底娜，愛上了這個少女，就用甜言蜜語討她歡心。</span>
<span className="v" id="v4" data-v="4" data-xref="士師記 14:2; 撒母耳記下 13:13; 創世記 21:21"> 他求父親哈抹為他說親，把底娜娶過來。</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳記下 13:22; 利未記 10:3; 撒母耳記上 10:27"> 底娜被玷污的消息傳到雅各耳中時，他的兒子們正在田野放牧。他只好忍氣吞聲，等兒子們回來再作打算。</span>
<span className="v" id="v6" data-v="6"> 示劍的父親哈抹來和雅各商議。</span>
<span className="v" id="v7" data-v="7" data-xref="約書亞記 7:15; 士師記 20:6; 申命記 22:21"> 雅各的兒子們一聽說這事，就從田野趕回來。大家都非常憤怒，因為示劍玷污了雅各的女兒，對以色列家做了不該做的醜事。</span>
<span className="v" id="v8" data-v="8" data-xref="列王紀上 11:2; 詩篇 119:20; 詩篇 84:2"> 哈抹跟他們商議說：「我兒子示劍愛慕你們家的女兒，請你們把女兒嫁給他吧！</span>
<span className="v" id="v9" data-v="9" data-xref="申命記 7:3; 創世記 26:34–35; 創世記 19:14"> 我們可以互相通婚，你們可以把女兒嫁給我們的兒子，也可以娶我們的女兒為妻。</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 20:15; 創世記 47:27; 創世記 42:34"> 你們可以在我們這裡安頓下來，這片土地就在你們面前，住在這裡做買賣、置產業吧。」</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 33:15; 創世記 18:3"> 示劍對底娜的父親和她的弟兄們說：「請你們恩待我，你們要什麼，我都給你們。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及記 22:16–17; 申命記 22:28–29; 撒母耳記上 18:25–27"> 只要你們把這少女嫁給我，無論你們要多少聘金和禮物，我必如數奉上。」</span>
</div>
</div>

## 雅各之子計殺示劍人

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="創世記 25:27–34; 以賽亞書 59:13; 約伯記 13:4"> 雅各的兒子們因為示劍玷污了他們的妹妹底娜，就假意對示劍和他的父親哈抹說：</span>
<span className="v" id="v14" data-v="14" data-xref="馬太福音 23:1–39; 撒母耳記下 15:7; 創世記 17:11"> 「我們不能把妹妹嫁給沒有受過割禮的人，這對我們是一種羞辱。</span>
<span className="v" id="v15" data-v="15" data-xref="加拉太書 4:12"> 除非你們所有的男子都跟我們一樣受割禮，我們才會答應你們，</span>
<span className="v" id="v16" data-v="16"> 我們才會和你們通婚，共同生活，結成一個民族。</span>
<span className="v" id="v17" data-v="17"> 如果你們不肯這樣做，我們就把妹妹帶走。」</span>
<span className="v" id="v18" data-v="18"> 哈抹父子欣然答應。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行傳 17:12; 使徒行傳 13:50; 撒母耳記上 22:14"> 示劍毫不遲延地照辦，因為他熱戀底娜。在哈抹家族中，他最受人尊重。</span>
<span className="v" id="v20" data-v="20" data-xref="路得記 4:1; 箴言 31:23; 阿摩司書 5:12"> 哈抹父子來到城門口，對那城的居民說：</span>
<span className="v" id="v21" data-v="21"> 「這些人跟我們相處和睦，就讓他們在這裡定居、做買賣吧。我們這裡有足夠的地方可以容納他們，我們可以和他們通婚。</span>
<span className="v" id="v22" data-v="22"> 可是，他們有一個條件，就是要我們所有的男子和他們一樣接受割禮，他們才答應和我們一起生活，結成一個民族。</span>
<span className="v" id="v23" data-v="23" data-xref="箴言 1:12–13; 約翰福音 6:26–27; 約翰福音 2:16"> 到時候，他們的財產和牛羊等所有牲畜不全歸我們了嗎？我們同意他們吧，這樣他們就會在我們這裡定居。」</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 23:10; 哥林多前書 7:19; 以賽亞書 1:10–16"> 在城門進出的人聽了哈抹父子的話，都表示贊同。於是，城裡的男子都接受了割禮。</span>
<span className="v" id="v25" data-v="25" data-xref="創世記 49:5–7; 創世記 29:33–34; 民數記 31:7"> 到了第三天，他們傷口正疼痛的時候，雅各的兩個兒子——底娜的哥哥西緬和利未拿著利劍，乘眾人沒有防備，進城殺掉了所有的男子，</span>
<span className="v" id="v26" data-v="26" data-xref="撒母耳記下 2:26; 申命記 32:42; 以賽亞書 31:8"> 包括哈抹和示劍，從示劍家裡帶走了底娜。</span>
<span className="v" id="v27" data-v="27" data-xref="約書亞記 7:13; 約書亞記 7:21; 出埃及記 2:14"> 雅各的眾子又到被殺之人的城裡擄掠，因為他們的妹妹在那裡被人玷污。</span>
<span className="v" id="v28" data-v="28" data-xref="約伯記 1:15–16; 申命記 8:17–18; 約伯記 20:5"> 他們搶走牛群、羊群、驢群和城裡城外所有的東西，</span>
<span className="v" id="v29" data-v="29"> 並帶走所有財物、婦孺以及房屋裡的一切。</span>
<span className="v" id="v30" data-v="30" data-xref="詩篇 105:12; 約書亞記 7:25; 出埃及記 5:21"> 雅各責備西緬和利未說：「你們為什麼要給我惹麻煩，使我在當地的迦南人和比利洗人中留下臭名呢？我們人數很少，要是他們聯手來攻擊我們，我們全家必遭滅門之禍。」</span>
<span className="v" id="v31" data-v="31" data-xref="箴言 6:34; 創世記 34:13; 創世記 49:7"> 他們說：「他怎麼能把我們的妹妹當妓女對待？」</span>
</div>

## 始祖犯罪

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多後書 11:3; 哥林多後書 11:14; 啟示錄 12:9"> 在耶和華上帝所造的田野的各種動物中，蛇最狡猾。蛇對女人說：「上帝真的說過『你們不可吃園中任何樹上的果子』嗎？」</span>
<span className="v" id="v2" data-v="2" data-xref="詩篇 58:4"> 女人回答說：「我們可以吃園中樹上的果子，</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 2:16–17; 哥林多後書 6:17; 出埃及記 19:12–13"> 只是上帝說過，『你們不可吃園子中間那棵樹的果子，也不可摸，免得死亡。』」</span>
<span className="v" id="v4" data-v="4" data-xref="約翰福音 8:44; 哥林多後書 11:3; 提摩太前書 2:14"> 蛇對女人說：「你們一定不會死！</span>
<span className="v" id="v5" data-v="5" data-xref="以西結書 28:2; 帖撒羅尼迦後書 2:4; 哥林多後書 11:13–15"> 上帝那樣說是因為祂知道，你們吃了那樹的果子以後，眼睛就會打開，像上帝一樣懂得分辨善惡。」</span>
<span className="v" id="v6" data-v="6" data-xref="約翰一書 2:16; 雅各書 1:14–15; 提摩太前書 2:14"> 女人見那棵樹上的果子可口，悅人眼目，可使人有智慧，就摘下來吃了。她又把果子給跟她在一起的丈夫，他也吃了。</span>
<span className="v" id="v7" data-v="7" data-xref="以賽亞書 59:6; 創世記 2:25; 創世記 3:5"> 二人的眼睛就打開了，發覺自己原來赤身露體，便編起無花果樹的葉子來遮體。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="耶利米書 23:24; 箴言 15:3; 希伯來書 4:13"> 天起涼風時，那人和他妻子聽見耶和華上帝在園中行走的聲音，就藏在園子的樹叢中，想躲避耶和華上帝。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 4:9; 創世記 16:8; 創世記 18:20–21"> 耶和華上帝呼喚那人說：「你在哪裡？」</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 2:25; 詩篇 119:120; 以賽亞書 47:3"> 那人說：「我在園中聽見你的聲音，就害怕得躲了起來，因為我赤身露體！」</span>
<span className="v" id="v11" data-v="11" data-xref="羅馬書 3:20; 創世記 4:10; 詩篇 50:21"> 耶和華上帝問：「誰告訴你，說你赤身露體？難道你吃了我吩咐你不可吃的果子嗎？」</span>
<span className="v" id="v12" data-v="12" data-xref="箴言 28:13; 雅各書 1:13–15; 約伯記 31:33"> 那人說：「你賜給我作伴的女人把那樹上的果子給我，我就吃了。」</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多後書 11:3; 提摩太前書 2:14; 創世記 4:10–12"> 耶和華上帝對女人說：「你這是做的什麼事？」女人說：「是蛇誘騙我，我才吃的。」</span>
</div>
</div>

## 上帝的審判

<div className="bt">
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="彌迦書 7:17; 以賽亞書 65:25; 詩篇 72:9"> 耶和華上帝對蛇說：<br /><span className="pl pl-1">「你既然做了這事，</span><br /><span className="pl pl-1">你要比一切牲畜和野獸受更重的咒詛，</span><br /><span className="pl pl-1">你要用肚子爬行，</span><br /><span className="pl pl-1">一生都要吃塵土。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="羅馬書 16:20; 約翰一書 3:8; 啟示錄 12:17"> <span className="pl pl-1">我要使你和女人結仇，</span><br /><span className="pl pl-1">你的後裔和女人的後裔也要彼此為仇，</span><br /><span className="pl pl-1">女人的後裔必傷你的頭，</span><br /><span className="pl pl-1">你必傷他的腳跟。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v16" data-v="16" data-xref="提多書 2:5; 歌羅西書 3:18; 哥林多前書 11:3"> 耶和華上帝對女人說：<br /><span className="pl pl-1">「我必大大加重你懷孕的痛苦，</span><br /><span className="pl pl-1">你分娩時必受痛苦。</span><br /><span className="pl pl-1">你必戀慕</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「戀慕」或譯「想控制」。">a</a></sup><br /><span className="pl pl-1">自己的丈夫，</span><br /><span className="pl pl-1">你的丈夫必管轄你。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v17" data-v="17" data-xref="羅馬書 8:20–22; 創世記 5:29; 以賽亞書 24:5–6"> 耶和華上帝又對亞當說：<br /><span className="pl pl-1">「因為你聽從妻子的話，</span><br /><span className="pl pl-1">吃了我吩咐你不可吃的那樹上的果子，</span><br /><span className="pl pl-1">地必因你而受咒詛。</span><br /><span className="pl pl-1">你必終生艱辛勞苦，</span><br /><span className="pl pl-1">才能吃到地裡出產的食物。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="馬太福音 13:7; 約伯記 5:5; 以賽亞書 7:23"> <span className="pl pl-1">地必給你長出荊棘和蒺藜，</span><br /><span className="pl pl-1">你要吃田間長出來的菜蔬。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="傳道書 12:7; 約伯記 34:15; 詩篇 104:29"> <span className="pl pl-1">你必汗流滿面，才有飯吃，</span><br /><span className="pl pl-1">一直到你歸回土地。</span><br /><span className="pl pl-1">因為那是你的本源。</span><br /><span className="pl pl-1">你本是塵土，也必歸回塵土。」</span></span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="創世記 2:23; 馬太福音 1:23; 創世記 5:29"> 亞當給他的妻子取名叫夏娃，因為她是眾生之母。</span>
<span className="v" id="v21" data-v="21" data-xref="以賽亞書 61:10; 哥林多後書 5:21; 哥林多後書 5:2–3"> 耶和華上帝做了皮衣給他們夫婦穿上。</span>
<span className="v" id="v22" data-v="22" data-xref="啟示錄 2:7; 啟示錄 22:14; 箴言 3:18"> 耶和華上帝說：「看啊，那人已經與我們相似，能分辨善惡。現在，恐怕他會伸手去摘生命樹的果子吃，就永遠活著。」</span>
<span className="v" id="v23" data-v="23" data-xref="創世記 4:2; 創世記 3:19; 創世記 4:12"> 因此，耶和華上帝就把亞當趕出伊甸園，讓他去開墾土地——那是他的本源。</span>
<span className="v" id="v24" data-v="24" data-xref="希伯來書 1:7; 詩篇 104:4; 出埃及記 25:18–22"> 祂趕走了亞當以後，在伊甸園東邊安排基路伯天使和一把旋轉的火劍，守住通往生命樹的路。</span>
</div>
</div>

## 上帝考驗亞伯拉罕

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="希伯來書 11:17; 雅各書 2:21; 申命記 8:2"> 這些事以後，上帝要考驗亞伯拉罕，就呼喚他：「亞伯拉罕！」他回答說：「我在這裡。」</span>
<span className="v" id="v2" data-v="2" data-xref="約翰福音 3:16; 羅馬書 8:32; 希伯來書 11:17"> 上帝說：「帶著你的兒子，你的獨生子，你疼愛的以撒前往摩利亞，在我指示你的山上把他獻為燔祭。」</span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 119:60; 馬太福音 10:37; 路加福音 14:26"> 亞伯拉罕清早起來，準備好驢，劈好獻燔祭用的柴，帶著兩個僕人和兒子以撒動身前往上帝指示他的地方。</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 13:32; 馬太福音 17:23; 何西阿書 6:2"> 到了第三天，亞伯拉罕抬頭遠遠看見那地方，</span>
<span className="v" id="v5" data-v="5" data-xref="希伯來書 11:19; 希伯來書 12:1"> 就對僕人說：「你們和驢在這裡等著，我和孩子到那邊敬拜上帝，然後便回來。」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="約翰福音 19:17; 彼得前書 2:24; 以賽亞書 53:6"> 亞伯拉罕把獻燔祭用的柴放在兒子以撒肩上，自己手裡拿著火種和刀。父子二人一同向前走。</span>
<span className="v" id="v7" data-v="7" data-xref="羅馬書 8:15; 馬太福音 26:39; 創世記 8:20"> 以撒說：「父親。」亞伯拉罕說：「兒子，什麼事？」以撒說：「你看，火種和柴都有了，但獻燔祭用的羊羔在哪裡呢？」</span>
<span className="v" id="v8" data-v="8" data-xref="約翰福音 1:36; 約翰福音 1:29; 啟示錄 5:12"> 亞伯拉罕說：「兒子，上帝會親自預備獻燔祭的羊羔。」二人就一同向前走。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="雅各書 2:21; 希伯來書 11:17–19; 腓立比書 2:7–8"> 他們到了上帝指示的地方，亞伯拉罕就築起祭壇，把柴擺在上面，然後把以撒捆起來放在祭壇上面的柴上。</span>
<span className="v" id="v10" data-v="10" data-xref="雅各書 2:21–23; 希伯來書 11:17–19; 以賽亞書 53:6–12"> 亞伯拉罕伸手拿起刀來，要殺他的兒子。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 21:17; 出埃及記 3:4; 創世記 16:9–10"> 耶和華的天使從天上呼喚他說：「亞伯拉罕！亞伯拉罕！」他回答說：「我在這裡。」</span>
<span className="v" id="v12" data-v="12" data-xref="雅各書 2:21–22; 雅各書 2:18; 撒母耳記上 15:22"> 天使說：「不可動孩子，不可傷害他！現在我知道你敬畏上帝，因為你不惜把你的兒子，你的獨生子獻給我。」</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多前書 10:13; 詩篇 40:6–8; 哥林多後書 1:9–10"> 這時亞伯拉罕抬頭一看，見有一隻公綿羊兩角卡在稠密的樹叢中，於是把羊取來代替他的兒子獻為燔祭。</span>
<span className="v" id="v14" data-v="14" data-xref="創世記 22:13; 出埃及記 17:15; 創世記 22:8"> 亞伯拉罕稱那地方為「耶和華以勒」<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「耶和華以勒」或譯「耶和華必預備」。">a</a></sup>。直到今天人們還說：「在耶和華的山上必有預備。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15"> 耶和華的天使再次從天上呼喚亞伯拉罕，</span>
<span className="v" id="v16" data-v="16" data-xref="希伯來書 6:13–14; 路加福音 1:73; 詩篇 105:9"> 對他說：「耶和華說，『你既然不惜獻上你的兒子，你的獨生子，我憑自己起誓，</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 15:5; 創世記 24:60; 耶利米書 33:22"> 我必賜福給你，使你的後裔多如天上的星和海邊的沙。你的後裔必奪取仇敵的城池，</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行傳 3:25; 創世記 12:3; 加拉太書 3:16"> 天下萬國必因你的後裔而蒙福，因為你聽從了我的話。』」</span>
<span className="v" id="v19" data-v="19" data-xref="創世記 21:31; 士師記 20:1; 約書亞記 15:28"> 於是，亞伯拉罕回到僕人那裡，他們一同返回亞伯拉罕居住的別示巴。</span>
</div>
</div>

## 拿鶴的後代

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="創世記 11:29; 創世記 24:24; 箴言 25:25"> 過了些日子，有人告訴亞伯拉罕：「密迦為你兄弟拿鶴生了幾個兒子，</span>
<span className="v" id="v21" data-v="21" data-xref="約伯記 1:1; 約伯記 32:2; 詩篇 60:1–12"> 長子烏斯、烏斯的弟弟布斯、亞蘭的父親基姆利、</span>
<span className="v" id="v22" data-v="22"> 基薛、哈瑣、必達、益拉和彼土利。」</span>
<span className="v" id="v23" data-v="23" data-xref="創世記 24:15; 創世記 28:5; 創世記 24:51"> 彼土利是利百加的父親。密迦為亞伯拉罕的兄弟拿鶴生了這八個兒子。</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 16:3; 創世記 25:6; 箴言 15:25"> 拿鶴的妾流瑪生了提八、迦含、他轄和瑪迦。</span>
</div>

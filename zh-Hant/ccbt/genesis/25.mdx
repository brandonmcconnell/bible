## 亞伯拉罕的其他後代

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歷代志上 1:32–33; 創世記 23:1–2; 創世記 28:1"> 亞伯拉罕又娶了基土拉為妻。</span>
<span className="v" id="v2" data-v="2" data-xref="歷代志上 1:32–33; 民數記 25:17–18; 約伯記 2:11"> 基土拉為亞伯拉罕生了心蘭、約珊、米但、米甸、伊施巴和書亞。</span>
<span className="v" id="v3" data-v="3" data-xref="以西結書 25:13; 耶利米書 49:8; 以西結書 27:20"> 約珊生了示巴和底但，底但的子孫是亞書利族、利都示族和利烏米族。</span>
<span className="v" id="v4" data-v="4" data-xref="以賽亞書 60:6"> 米甸的兒子是以法、以弗、哈諾、亞比大和以勒大。這些都是基土拉的子孫。</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 24:36; 希伯來書 1:2; 加拉太書 3:29"> 亞伯拉罕把所有的財產都給了以撒。</span>
<span className="v" id="v6" data-v="6" data-xref="創世記 21:14; 士師記 6:3; 使徒行傳 14:17"> 他趁自己還在世的時候，把一些財物送給他的妾所生的兒子們，讓他們離開他的兒子以撒到東方去。</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 12:4"> 亞伯拉罕活了一百七十五歲，</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 35:28–29; 創世記 15:15; 歷代志上 29:28"> 享盡天年，壽終正寢，歸到他祖先那裡。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 50:13; 創世記 35:29; 創世記 49:29–30"> 他的兩個兒子以撒和以實瑪利把他安葬在麥比拉洞，那山洞在幔利附近、赫人瑣轄的兒子以弗崙的地裡。</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 23:16; 創世記 49:31"> 那塊地是亞伯拉罕向赫人買的，他和妻子撒拉都葬在那裡。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 22:17; 創世記 16:14; 創世記 24:62"> 亞伯拉罕去世以後，上帝賜福給他的兒子以撒。以撒住在庇耳·拉海·萊附近。</span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 83:6; 創世記 17:20; 創世記 21:13"> 以實瑪利是亞伯拉罕和撒拉的婢女埃及人夏甲所生的兒子，以下是以實瑪利的後代。</span>
<span className="v" id="v13" data-v="13" data-xref="歷代志上 1:29–31; 以賽亞書 60:7; 雅歌 1:5"> 以實瑪利的兒子按出生的次序名字如下：長子尼拜約，然後是基達、亞德別、米比衫、</span>
<span className="v" id="v14" data-v="14" data-xref="以賽亞書 21:11; 以賽亞書 21:16"> 米施瑪、度瑪、瑪撒、</span>
<span className="v" id="v15" data-v="15" data-xref="歷代志上 5:19; 約伯記 2:11"> 哈大、提瑪、伊突、拿非施、基底瑪。</span>
<span className="v" id="v16" data-v="16" data-xref="創世記 17:20; 創世記 17:23"> 這些都是以實瑪利的兒子，他們按照其村莊和營寨分別作了十二個族的族長。</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 15:15; 創世記 25:7–8"> 以實瑪利活了一百三十七歲，壽終正寢，歸到他祖先那裡。</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 16:12; 創世記 20:1; 列王紀下 23:29"> 他子孫居住的地方從哈腓拉一直延伸到埃及東面、通往亞述方向的書珥，他們與其他親屬作對<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「與其他親屬作對」或譯「住在其他親屬的東面」。">a</a></sup>。</span>
</div>
</div>

## 利百加生以掃和雅各

<div className="bt">
<div className="bp poetry">
<span className="v" id="v19" data-v="19" data-xref="馬太福音 1:2; 路加福音 3:34; 使徒行傳 7:8"> 以下是關於亞伯拉罕的兒子以撒的記載。 亞伯拉罕生以撒。</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 24:29; 創世記 24:67; 創世記 22:23"> 以撒四十歲娶利百加，利百加是巴旦·亞蘭的亞蘭人彼土利的女兒、拉班的妹妹。</span>
<span className="v" id="v21" data-v="21" data-xref="路加福音 1:13; 以賽亞書 58:9; 以斯拉記 8:23"> 以撒因為利百加不生育，就為她祈求耶和華。耶和華應允了他的祈求，利百加就懷了孕。</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳記上 9:9; 撒母耳記上 28:6; 撒母耳記上 30:8"> 兩個胎兒在她腹中彼此相爭，她說：「怎麼會這樣？」於是，她去求問耶和華。</span>
<span className="v" id="v23" data-v="23" data-xref="羅馬書 9:10–13; 創世記 27:40; 創世記 27:29"> 耶和華對她說：<br /><span className="pl pl-1">「你腹中有兩個國家，</span><br /><span className="pl pl-1">兩族從你裡面分出，</span><br /><span className="pl pl-1">一族要比另一族強大，</span><br /><span className="pl pl-1">將來大的要服侍小的。」</span></span>
<span className="v" id="v24" data-v="24"> 到了生產的時候，利百加果然生下雙胞胎。</span>
<span className="v" id="v25" data-v="25" data-xref="創世記 27:11; 創世記 27:16; 創世記 27:23"> 先出生的嬰兒身體通紅，渾身長毛，好像穿了皮衣，因此給他取名叫以掃<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="「以掃」意思是「有毛」。">b</a></sup>。</span>
<span className="v" id="v26" data-v="26" data-xref="創世記 27:36; 何西阿書 12:3; 創世記 38:28–30"> 隨後出生的弟弟手抓著以掃的腳跟，因此給他取名叫雅各<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="「雅各」意思是「抓住」。">c</a></sup>。那時以撒六十歲。</span>
</div>
</div>

## 以掃出賣長子名分

<div className="bt">
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="希伯來書 11:9; 創世記 21:20; 創世記 10:9"> 孩子們漸漸長大，以掃擅長狩獵，常在田野活動；雅各性情安靜，喜歡待在家裡。</span>
<span className="v" id="v28" data-v="28" data-xref="創世記 27:19; 創世記 27:31; 創世記 27:4"> 以撒疼愛以掃，因為他喜歡吃以掃打的野味，利百加卻疼愛雅各。</span>
<span className="v" id="v29" data-v="29" data-xref="箴言 13:25; 以賽亞書 40:30–31; 撒母耳記上 14:28"> 一天，雅各正在熬湯，以掃筋疲力盡地從田野回來。</span>
<span className="v" id="v30" data-v="30" data-xref="創世記 36:1; 出埃及記 15:15; 創世記 36:9"> 以掃對雅各說：「我要累死了，給我一些紅湯喝吧！」因此，以掃又叫以東<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="「以東」意思是「紅色」。">d</a></sup>。</span>
<span className="v" id="v31" data-v="31"> 雅各回答說：「你今天把長子的名分賣給我吧！」</span>
<span className="v" id="v32" data-v="32" data-xref="瑪拉基書 3:14; 約伯記 21:15; 約伯記 22:17"> 以掃說：「我都快死了，長子的名分對我有什麼用呢？」</span>
<span className="v" id="v33" data-v="33" data-xref="希伯來書 12:16; 創世記 27:36; 希伯來書 6:16"> 雅各說：「你現在向我起誓保證吧！」於是，以掃就起誓把長子的名分賣給了雅各。</span>
<span className="v" id="v34" data-v="34" data-xref="腓立比書 3:18–19; 希伯來書 12:16–17; 哥林多前書 15:32"> 雅各把餅和豆湯給以掃，以掃吃完喝完便起身走了。以掃就這樣輕看自己長子的名分。</span>
</div>

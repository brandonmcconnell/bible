## 雅各全家定居埃及

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 45:10; 創世記 46:31; 創世記 46:28"> 約瑟來到法老面前，對他說：「我父親和我的弟兄們已經帶著他們的羊群、牛群和所有的一切從迦南來了，現在就在歌珊。」</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行傳 7:13; 歌羅西書 1:28; 猶大書 1:24"> 約瑟從弟兄中帶了五個人去見法老。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 46:33–34; 帖撒羅尼迦後書 3:10; 創世記 4:2"> 法老問他們：「你們做什麼工作？」他們回答說：「僕人們祖祖輩輩都是牧羊的。</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 46:34; 創世記 15:13; 申命記 26:5"> 迦南的饑荒很嚴重，羊群沒有草吃，所以我們到這裡來寄居，求你准許僕人們住在歌珊。」</span>
<span className="v" id="v5" data-v="5"> 法老對約瑟說：「你父親和弟兄們都來了，</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及記 18:21; 箴言 22:29; 創世記 47:11"> 整個埃及就在你面前，儘管安排他們住在國中最好的地方。他們可以住在歌珊。如果你知道他們中間有能幹的人，可以派他們看管我的牲畜。」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="創世記 47:10; 撒母耳記下 8:10; 撒母耳記上 2:20"> 約瑟又帶父親雅各去見法老，雅各就為法老祝福。</span>
<span className="v" id="v8" data-v="8"> 法老問雅各：「你多大歲數了？」</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 39:12; 詩篇 39:5; 約伯記 14:1"> 雅各回答說：「我在世上寄居一百三十年了，我的日子又苦又短，不像我祖先當年那樣高壽。」</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 47:7; 詩篇 129:8; 希伯來書 7:7"> 雅各為法老祝福後，就告退了。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 47:6; 出埃及記 1:11; 出埃及記 12:37"> 約瑟遵照法老之命把埃及最好的地方蘭塞境內的土地給他父親和弟兄們居住，作他們的產業。</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 45:11; 提摩太前書 5:8; 創世記 47:1"> 約瑟按各家人口供應糧食給父親、弟兄及其他家人。</span>
</div>
</div>

## 饑荒

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="使徒行傳 7:11; 列王紀上 18:5; 耶利米哀歌 4:9"> 饑荒很嚴重，到處都缺糧，埃及和迦南都飽受饑荒之苦。</span>
<span className="v" id="v14" data-v="14" data-xref="創世記 41:56; 路加福音 16:10–12; 路加福音 16:1–2"> 約瑟把埃及人和迦南人向他買糧的銀子收集起來，存放在法老的庫房裡。</span>
<span className="v" id="v15" data-v="15" data-xref="士師記 8:8; 詩篇 37:3; 馬太福音 6:11"> 埃及人和迦南人的銀子都用光了，埃及人就來見約瑟，對他說：「我們的錢財都用光了，求你給我們糧食，免得我們餓死在你面前。」</span>
<span className="v" id="v16" data-v="16" data-xref="歌羅西書 4:5; 但以理書 6:5–7; 哥林多前書 10:32"> 約瑟說：「你們的錢財如果用盡了，可以用你們的牲畜來交換糧食。」</span>
<span className="v" id="v17" data-v="17" data-xref="約伯記 2:4; 出埃及記 9:3; 以賽亞書 31:1"> 於是，他們把牲畜趕到約瑟那裡，用他們的牛、羊、驢和馬跟約瑟換糧食。那一年，他們就依靠換來的糧食生活。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="列王紀下 6:26; 耶利米書 38:9"> 到了第二年，他們又來見約瑟，對他說：「不瞞我主，我們的錢都用光了，牲畜也給我主了，除了我們自己和田地以外，我們一無所有。</span>
<span className="v" id="v19" data-v="19" data-xref="尼希米記 5:2–3; 約伯記 2:4; 耶利米哀歌 1:11"> 求你不要讓我們人死地荒。我們願意用自己和我們的田地來換糧食，我們和我們的田地都歸法老。求你給我們種子，我們好活下去，不致餓死，土地也不致荒廢。」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20"> 埃及人為饑荒所迫，紛紛賣掉自己的田地。約瑟替法老收購了埃及全國的田地，最後，所有的田地都歸法老了。</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 41:48"> 約瑟使埃及全境的人都成為法老的奴僕。</span>
<span className="v" id="v22" data-v="22" data-xref="以斯拉記 7:24; 尼希米記 13:10; 帖撒羅尼迦後書 3:10"> 約瑟唯獨沒有買祭司的田地，因為祭司吃法老的俸祿，有足夠的供給，不用賣地。</span>
<span className="v" id="v23" data-v="23" data-xref="詩篇 112:5; 詩篇 41:1; 傳道書 11:6"> 約瑟對百姓說：「我為法老買了你們和你們的土地，這裡有種子，你們可以拿去耕種。</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 41:34; 詩篇 41:1; 詩篇 112:5"> 但是你們在收成時要把五分之一給法老，其餘的，你們可以留下來作種子和全家人的口糧。」</span>
<span className="v" id="v25" data-v="25" data-xref="創世記 33:15; 箴言 11:26–27; 創世記 18:3"> 他們說：「你救了我們的命，願你恩待我們，我們願做法老的奴僕。」</span>
<span className="v" id="v26" data-v="26" data-xref="創世記 47:22; 以西結書 7:24"> 於是，約瑟立下一條關於埃及土地的法令，到今天還有效，就是埃及出產的五分之一歸給法老。只有祭司的田地不歸法老。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="創世記 46:3; 出埃及記 1:7; 使徒行傳 7:17"> 以色列人住在埃及的歌珊，在那裡獲得了產業，人口興旺。</span>
<span className="v" id="v28" data-v="28" data-xref="詩篇 90:10; 創世記 47:8–9; 創世記 37:2"> 雅各在埃及住了十七年，享年一百四十七歲。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="申命記 31:14; 創世記 24:49; 創世記 24:2"> 以色列快要離世的時候，把兒子約瑟叫來，說：「你如果恩待我，請把手放在我大腿底下起誓，你會以慈愛和信實待我，不把我葬在埃及。</span>
<span className="v" id="v30" data-v="30" data-xref="創世記 49:29–32; 創世記 23:19; 創世記 25:9"> 我與祖先同眠後，你要把我帶出埃及，安葬在我祖先的墓地。」約瑟說：「我必照你說的做。」</span>
<span className="v" id="v31" data-v="31" data-xref="列王紀上 1:47; 希伯來書 11:21; 創世記 24:3"> 他要約瑟起誓，約瑟就向他起誓。於是，以色列在床頭<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「在床頭」或譯「拄著拐杖」。">a</a></sup>敬拜上帝。</span>
</div>
</div>

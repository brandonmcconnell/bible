## 安葬雅各

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 46:4; 申命記 6:7–8; 使徒行傳 8:2"> 約瑟伏在父親身上痛哭，親吻他，</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 50:26; 歷代志下 16:14; 約翰福音 19:39–40"> 然後吩咐醫生用香料保存父親的遺體。醫生遵命而行，</span>
<span className="v" id="v3" data-v="3" data-xref="民數記 20:29; 申命記 34:8; 創世記 50:10"> 按照常例花了四十天用香料處理遺體。埃及人為他哀悼七十天。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="創世記 18:3; 以斯帖記 4:2"> 哀悼的日子完了，約瑟對法老宮中的人說：「如果你們恩待我，</span>
<span className="v" id="v5" data-v="5" data-xref="歷代志下 16:14; 以賽亞書 22:16; 馬太福音 27:60"> 請告訴法老，我父親死前要我起誓把他葬在迦南他自己預備好的墳地。請准許我到迦南去安葬我父親，我辦完喪事就回來。」</span>
<span className="v" id="v6" data-v="6" data-xref="創世記 48:21"> 法老說：「去按照你的誓言埋葬你父親吧。」</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 14:16"> 於是，約瑟啟程去埋葬他的父親，隨行的有法老所有的臣僕和埃及所有的達官顯貴，</span>
<span className="v" id="v8" data-v="8" data-xref="民數記 32:24–27; 出埃及記 10:26; 出埃及記 10:8–9"> 以及約瑟全家、他的眾弟兄和雅各的家眷，只有他們的孩子和牛羊仍然留在歌珊。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及記 14:28; 列王紀下 18:24; 雅歌 1:9"> 隨行的還有大隊車輛和騎兵，人數眾多。</span>
<span className="v" id="v10" data-v="10" data-xref="約伯記 2:13; 使徒行傳 8:2; 撒母耳記下 1:17"> 他們來到約旦河附近的亞達麥場，在那裡痛哭哀悼。約瑟為父親哭喪七天。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 10:15–19; 創世記 24:6; 申命記 11:30"> 迦南人看見他們在亞達麥場痛哭，就說：「埃及人在痛哭哀悼。」因此，約旦河附近的那個地方叫亞伯·麥西<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「亞伯·麥西」意思是「埃及人在哀哭」。">a</a></sup>。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行傳 7:16; 創世記 49:29–32; 以弗所書 6:1"> 雅各的兒子們遵照父親的遺言，</span>
<span className="v" id="v13" data-v="13" data-xref="創世記 49:29–31; 創世記 23:16–18; 使徒行傳 7:16"> 把父親的遺體帶回迦南，安葬在幔利附近、麥比拉田間的洞裡。洞和田地都是亞伯拉罕向赫人以弗崙買來作墳地的。</span>
<span className="v" id="v14" data-v="14"> 葬禮之後，約瑟就跟眾弟兄和一切隨行的人返回埃及。</span>
</div>
</div>

## 上帝的美好旨意

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="箴言 28:1; 創世記 42:21–22; 詩篇 53:5"> 約瑟的哥哥們見父親死了，就說：「約瑟會不會懷恨在心，因我們以前惡待他而報復我們呢？」</span>
<span className="v" id="v16" data-v="16" data-xref="箴言 29:25"> 於是，他們派人去對約瑟說：「你父親臨終時交待這樣的話給你，</span>
<span className="v" id="v17" data-v="17" data-xref="以弗所書 4:32; 馬太福音 6:14–15; 創世記 45:8"> 『從前你哥哥們惡待你，求你饒恕他們的罪惡和過犯。』我們是你父親的上帝的僕人，求你饒恕我們的罪惡。」約瑟聽見這些話，就哭了。</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 37:7–11; 創世記 42:6; 創世記 45:3"> 約瑟的哥哥們來見他，俯伏在他面前，說：「我們是你的奴僕。」</span>
<span className="v" id="v19" data-v="19" data-xref="羅馬書 12:19; 創世記 45:5; 創世記 30:2"> 約瑟對他們說：「你們不要害怕，我豈能代替上帝？</span>
<span className="v" id="v20" data-v="20" data-xref="羅馬書 8:28; 詩篇 119:71; 創世記 45:5–8"> 從前你們是要加害於我，但上帝有祂的美意，祂藉此保全許多人的性命，正如今日的光景。</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 47:12; 彼得前書 3:9; 創世記 45:10–11"> 因此，你們不要害怕，我會照顧你們和你們的兒女。」約瑟好言好語地寬慰他們。</span>
</div>
</div>

## 約瑟去世

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22"> 約瑟和他父親全家住在埃及。約瑟享年一百一十歲。</span>
<span className="v" id="v23" data-v="23" data-xref="民數記 32:39; 創世記 30:3; 約伯記 42:16"> 他看到了以法蓮的孫子，也曾把瑪拿西的兒子瑪吉剛出生的孩子抱在膝上。</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及記 3:16–17; 創世記 35:12; 創世記 26:3"> 一天，約瑟對他的弟兄們說：「我快要死了，但上帝必看顧你們，帶你們離開這裡，回到祂起誓應許給亞伯拉罕、以撒和雅各的地方。」</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及記 13:19; 約書亞記 24:32; 創世記 47:29–31"> 約瑟讓以色列的子孫起了誓，並說：「上帝必看顧你們，你們要把我的骸骨帶回迦南。」</span>
<span className="v" id="v26" data-v="26" data-xref="創世記 50:2–3; 創世記 47:9; 約書亞記 24:29"> 約瑟享年一百一十歲。他們把他的遺體用香料保存好，放在棺材裡，停放在埃及。</span>
</div>
</div>

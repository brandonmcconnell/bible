## 人類的邪惡

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 1:28"> 當時，人類在地上開始逐漸增多，生了女兒。</span>
<span className="v" id="v2" data-v="2" data-xref="詩篇 82:6–7; 約翰一書 2:16; 彼得後書 2:14"> 上帝的兒子們<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「上帝的兒子們」可能指塞特的後代，天使或有權勢的人。">a</a></sup>看見人的女兒漂亮，就隨意選來做妻子。</span>
<span className="v" id="v3" data-v="3" data-xref="尼希米記 9:30; 以賽亞書 63:10; 耶利米書 11:11"> 耶和華說：「人既然是血肉之軀，我的靈不會永遠住在人的裡面，然而人還可以活一百二十年。」</span>
<span className="v" id="v4" data-v="4" data-xref="民數記 13:33; 撒母耳記下 21:15–22; 撒母耳記上 17:4"> 從上帝的兒子和人的女兒交合生子起，地上出現了巨人，他們是上古英武有名的人。</span>
<span className="v" id="v5" data-v="5" data-xref="馬太福音 15:19; 羅馬書 1:28–31; 馬可福音 7:21–23"> 耶和華看見人在地上罪惡深重，心裡終日思想的都是惡事，</span>
<span className="v" id="v6" data-v="6" data-xref="以賽亞書 63:10; 撒母耳記上 15:11; 以弗所書 4:30"> 就後悔在地上造了人，心裡傷痛，</span>
<span className="v" id="v7" data-v="7" data-xref="西番雅書 1:3; 詩篇 37:20; 耶利米書 12:3–4"> 說：「我要把所造的人，連同一切飛禽走獸和爬蟲從地上都毀滅，因為我後悔造了他們。」</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 19:19; 希伯來書 4:16; 路加福音 1:30"> 只有挪亞在耶和華面前蒙恩。</span>
</div>
</div>

## 上帝命挪亞造方舟

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="路加福音 1:6; 希伯來書 11:7; 彼得後書 2:5"> 以下是有關挪亞的記載。 挪亞是個義人，在當時的世代是個純全無過的人，他與上帝同行。</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 5:32"> 挪亞生了三個兒子：閃、含和雅弗。</span>
<span className="v" id="v11" data-v="11" data-xref="以西結書 8:17; 何西阿書 4:1–2; 哈巴谷書 2:8"> 那時大地在上帝眼中敗壞了，充滿了暴行。</span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 53:2–3; 箴言 15:3; 詩篇 14:1–3"> 上帝看見大地敗壞了，因為世人都行為敗壞。</span>
<span className="v" id="v13" data-v="13" data-xref="何西阿書 4:1–2; 彼得前書 4:7; 以西結書 7:2–6"> 祂對挪亞說：「我決定消滅世人，因為他們使大地充滿暴行。我要把他們和大地一起毀滅。</span>
<span className="v" id="v14" data-v="14" data-xref="彼得前書 3:20; 路加福音 17:27; 馬太福音 24:38"> 你要為自己用歌斐木建造一艘方舟，裡面要有艙房，內外都要塗上柏油。</span>
<span className="v" id="v15" data-v="15" data-xref="申命記 3:11; 創世記 7:20"> 你建造的方舟要長一百三十五米，寬二十二米半，高十三米半。</span>
<span className="v" id="v16" data-v="16" data-xref="創世記 8:6; 創世記 7:16; 以西結書 41:16"> 舟頂要有四十五釐米高的透光口，門開在方舟的側面，整艘方舟要分為上、中、下三層。</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 7:4; 彼得後書 2:5; 創世記 7:21–23"> 看啊，我要使洪水在地上氾濫，毀滅天下一切有生命氣息的活物，地上的一切都要滅亡。</span>
<span className="v" id="v18" data-v="18" data-xref="希伯來書 11:7; 創世記 7:7; 創世記 17:7"> 但我要和你立約，你與妻子、兒子和兒媳都可以進方舟。</span>
<span className="v" id="v19" data-v="19" data-xref="創世記 7:15–16; 創世記 7:8–9; 創世記 8:17"> 每樣動物你要帶兩隻進方舟，雌雄各一隻，好保存牠們的生命。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行傳 10:11–12; 創世記 2:19; 創世記 7:8–16"> 各類飛禽走獸和爬蟲每樣一對都要到你那裡，好保全生命。</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 1:29–30; 詩篇 145:16; 詩篇 136:25"> 你要為自己和這些動物預備各種食物，貯存起來。」</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及記 40:16; 約翰福音 15:14; 馬太福音 7:24–27"> 挪亞就照著上帝的吩咐把事情都辦好了。</span>
</div>
</div>

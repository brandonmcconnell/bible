## 約瑟的哥哥們到埃及買糧

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行傳 7:12; 約書亞記 7:10; 列王紀下 8:3–4"> 雅各得知埃及有糧食，就對兒子們說：「你們為什麼還在這兒互相觀望呢？</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 43:8; 創世記 45:9; 創世記 43:2"> 我聽說埃及有糧食，你們快到埃及去買些糧食回來吧，我們好活命，不致餓死。」</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 42:5; 創世記 42:13"> 於是，約瑟的十個哥哥下到埃及買糧。</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 42:38; 創世記 43:29; 創世記 11:4"> 雅各沒有讓約瑟的弟弟便雅憫與他們同去，恐怕他會遭害。</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 41:57; 使徒行傳 7:11; 創世記 12:10"> 以色列的兒子們加入了買糧的行列，因為迦南也遭遇饑荒。</span>
<span className="v" id="v6" data-v="6" data-xref="啟示錄 3:9; 創世記 37:7–10; 創世記 41:40–41"> 那時，約瑟治理埃及，負責賣糧給百姓。約瑟的哥哥們來到他面前，向他俯伏下拜。</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 42:30; 創世記 42:14–17; 馬太福音 15:23–26"> 約瑟一眼就認出了他們，卻不動聲色。他疾言厲色地問道：「你們從哪裡來？」他們回答說：「我們是從迦南來買糧食的。」</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 37:2; 約翰福音 20:14; 路加福音 24:16"> 約瑟認得他哥哥們，但他哥哥們卻認不出他來。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 37:5–9; 出埃及記 32:35; 約書亞記 2:1"> 約瑟想起了自己從前做的兩個夢，就對他們說：「你們是奸細，是來探聽我們虛實的！」</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 37:8; 撒母耳記上 26:17; 創世記 27:37"> 他們說：「我主啊，不是的！僕人們是來買糧的。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 42:19; 哥林多後書 6:4; 約翰福音 7:18"> 僕人們都是一個父親所生，是誠實人，不是奸細。」</span>
<span className="v" id="v12" data-v="12"> 約瑟說：「不對，你們是來探聽我們虛實的。」</span>
<span className="v" id="v13" data-v="13" data-xref="創世記 37:30; 創世記 42:32; 創世記 44:20"> 他們說：「僕人們共有弟兄十二人，父親住在迦南，最小的弟弟在父親身邊，還有一個已經去世。」</span>
<span className="v" id="v14" data-v="14" data-xref="馬太福音 15:21–28; 約伯記 13:24; 創世記 42:9–11"> 約瑟說：「我說你們是奸細一點不錯。</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳記上 17:55; 耶利米書 5:7; 創世記 42:16"> 我以法老的性命起誓，你們最小的弟弟不來這裡，你們都不能走，這是對你們的驗證。</span>
<span className="v" id="v16" data-v="16" data-xref="創世記 42:11"> 你們派一個人回去把你們的弟弟帶來，其他人都要被囚禁在這裡，我要看看你們說的是真還是假。要是你們說的是假話，我以法老的性命起誓，你們一定是奸細。」</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 40:4; 希伯來書 12:10; 創世記 40:7"> 於是，約瑟把他們囚禁了三天。</span>
<span className="v" id="v18" data-v="18" data-xref="利未記 25:43; 尼希米記 5:15; 路加福音 18:2"> 到了第三天，約瑟對他們說：「我是敬畏上帝的人，你們照我的話做就能活命。</span>
<span className="v" id="v19" data-v="19" data-xref="創世記 45:23; 以賽亞書 42:7; 創世記 40:3"> 如果你們是誠實人，就把一個人留在監牢，其他人帶糧食回去接濟你們的家人。</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 44:23; 創世記 43:5; 創世記 42:34"> 但你們一定要帶你們最小的弟弟回來，以證實你們說的是實話，這樣你們就不會死。」他們同意了，</span>
<span className="v" id="v21" data-v="21" data-xref="何西阿書 5:15; 馬可福音 9:43–45; 創世記 37:23–28"> 彼此議論說：「我們一定是在遭報應。從前我們的弟弟苦苦地哀求我們，我們卻不理會，現在這場痛苦臨到我們了。」</span>
<span className="v" id="v22" data-v="22" data-xref="歷代志下 24:22; 詩篇 9:12; 列王紀上 2:32"> 呂便說：「我不是勸你們不要犯罪害那孩子嗎？你們不聽，現在我們必須償還血債了。」</span>
<span className="v" id="v23" data-v="23" data-xref="哥林多後書 5:20; 約翰福音 16:13–14"> 他們不知道約瑟聽得懂他們的話，因為約瑟是通過翻譯跟他們談話。</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 43:30; 猶大書 1:22–23; 希伯來書 4:15"> 約瑟聽後轉身出去哭了，然後又回來跟他們談話，從他們中間選了西緬，當著他們的面把西緬捆綁起來。</span>
<span className="v" id="v25" data-v="25" data-xref="彼得前書 3:9; 羅馬書 12:17–21; 創世記 45:21"> 約瑟又吩咐人把他們的袋子裝滿糧食，把各人買糧的錢放在他們的口袋中，還為他們預備了路上的食物。僕人一一辦妥了。</span>
<span className="v" id="v26" data-v="26"> 約瑟的哥哥們把糧食馱在驢上，啟程離去。</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及記 4:24; 路加福音 2:7; 路加福音 10:34"> 他們來到一處住宿的地方，其中一人打開口袋拿飼料餵驢，卻發現自己的錢在裡面，</span>
<span className="v" id="v28" data-v="28" data-xref="以賽亞書 45:7; 耶利米哀歌 3:37; 創世記 42:36"> 就對其他弟兄說：「你們看，我的錢被退回來了，在我的口袋裡！」他們心驚膽戰地彼此議論說：「上帝這樣對待我們是什麼意思呢？」</span>
<span className="v" id="v29" data-v="29"> 他們回到他們在迦南的父親雅各那裡，把事情的經過告訴了他，</span>
<span className="v" id="v30" data-v="30" data-xref="創世記 42:7"> 說：「埃及的宰相對我們說話很兇，還把我們當成去那裡打探的奸細。</span>
<span className="v" id="v31" data-v="31" data-xref="創世記 42:11"> 我們對他說，『我們是誠實人，不是奸細。</span>
<span className="v" id="v32" data-v="32"> 我們是一個父親所生的十二兄弟，其中有一個已經去世，年紀最小的跟父親留在迦南。』</span>
<span className="v" id="v33" data-v="33" data-xref="創世記 42:19–20; 創世記 42:15"> 那地的宰相卻對我們說，『我要看看你們是不是誠實人，你們把一個弟兄留在我這裡，其他人帶糧食回去接濟家人吧。</span>
<span className="v" id="v34" data-v="34" data-xref="創世記 34:10; 創世記 34:21; 列王紀上 10:15"> 但你們要把最小的弟弟帶來見我，這樣我便知道你們不是奸細，是誠實人。我就會釋放你們的弟兄，你們也可以在這裡自由地買賣。』」</span>
<span className="v" id="v35" data-v="35" data-xref="創世記 43:21; 創世記 43:12; 創世記 43:15"> 後來他們倒口袋時，發現每個人買糧的錢袋都在自己的口袋裡，他們和父親看見錢袋，都害怕起來。</span>
<span className="v" id="v36" data-v="36" data-xref="創世記 43:14; 羅馬書 8:31; 以賽亞書 27:9"> 他們的父親雅各說：「你們使我連連失去兒子，約瑟沒了，西緬沒了，你們還要帶走便雅憫！災禍都落在了我頭上！」</span>
<span className="v" id="v37" data-v="37" data-xref="創世記 46:9; 彌迦書 6:7; 創世記 43:9"> 呂便對父親說：「要是我不把便雅憫帶回你身邊，你就殺了我的兩個兒子！請你把便雅憫交給我，我一定會把他帶回你身邊。」</span>
<span className="v" id="v38" data-v="38" data-xref="創世記 37:35; 創世記 42:4; 創世記 37:33"> 雅各說：「我的兒子不可跟你們去。他哥哥已經死了，現在只剩下他。要是他在路上遇到什麼意外，你們會使我這白髮蒼蒼的老人淒淒慘慘地下陰間。」</span>

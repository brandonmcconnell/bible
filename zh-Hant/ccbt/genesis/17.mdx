## 上帝再次與亞伯蘭立約

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="腓立比書 4:13; 以弗所書 3:20; 路加福音 1:6"> 亞伯蘭九十九歲那年，耶和華向他顯現說：「我是全能的上帝。你要遵行我的旨意，做純全無過的人。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 17:4–6; 創世記 12:2; 詩篇 105:8–11"> 我要與你立約，我要使你子孫極其繁盛。」</span>
<span className="v" id="v3" data-v="3" data-xref="士師記 13:20; 創世記 17:17; 民數記 16:45"> 亞伯蘭就俯伏在地，上帝又對他說：</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 35:11; 加拉太書 3:28–29; 創世記 12:2"> 「我要與你立約，你必成為萬族之父。</span>
<span className="v" id="v5" data-v="5" data-xref="馬太福音 1:21–23; 尼希米記 9:7; 創世記 17:15"> 以後你的名字不再叫亞伯蘭，要改為亞伯拉罕<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「亞伯拉罕」意思是「萬族之父」。">a</a></sup>，因為我已立你為萬族之父。</span>
<span className="v" id="v6" data-v="6" data-xref="創世記 17:4; 馬太福音 1:6–17; 創世記 35:11"> 我要使你生養眾多，民族必由你而生，君王必從你而出。</span>
<span className="v" id="v7" data-v="7" data-xref="羅馬書 9:7–9; 使徒行傳 2:39; 創世記 26:24"> 我要和你並你的子子孫孫立永遠的約，我要做你和你子孫的上帝。</span>
<span className="v" id="v8" data-v="8" data-xref="利未記 26:12; 詩篇 105:11; 出埃及記 6:7"> 我要把你現在寄居的整個迦南，賜給你和你的子孫永遠作產業，我也必做他們的上帝。」</span>
<span className="v" id="v9" data-v="9" data-xref="以賽亞書 56:4–5; 詩篇 25:10; 詩篇 103:18"> 上帝又對亞伯拉罕說：「你和你的子孫世世代代都要遵守我的約。</span>
<span className="v" id="v10" data-v="10" data-xref="歌羅西書 2:11–12; 羅馬書 4:9–11; 使徒行傳 7:8"> 你們所有的男子都要受割禮，這是我與你和你的子孫所立的約，你們要遵守。</span>
<span className="v" id="v11" data-v="11" data-xref="羅馬書 4:11; 使徒行傳 7:8; 申命記 10:16"> 你們都要割包皮，作為我與你們立約的記號。</span>
<span className="v" id="v12" data-v="12" data-xref="利未記 12:3; 路加福音 2:21; 出埃及記 12:48–49"> 你們世世代代的男子，在出生後的第八日都要接受割禮，包括在你家裡出生的和用錢從外族人那裡買來的奴僕。</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及記 12:44; 創世記 37:36; 尼希米記 5:8"> 不論是在你家裡生的，還是你用錢買來的男子，都要接受割禮，這樣我的約就在你們的肉體上成為永遠的約。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及記 4:24–26; 民數記 15:30–31; 出埃及記 12:19"> 任何沒有接受割禮的男子，要將他從民中剷除，因為他違背了我的約。」</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳記下 12:25; 創世記 32:28; 創世記 17:5"> 上帝對亞伯拉罕說：「你的妻子撒萊以後不要叫撒萊，她的名字要叫撒拉。</span>
<span className="v" id="v16" data-v="16" data-xref="創世記 35:11; 創世記 17:6; 以賽亞書 49:23"> 我必賜福給她，讓她為你生一個兒子。我必賜福給她，讓她成為列國之母，列邦的君王必從她而出。」</span>
<span className="v" id="v17" data-v="17" data-xref="啟示錄 11:16; 創世記 21:6; 創世記 18:12"> 亞伯拉罕就俯伏在地，笑了起來，心想：「一百歲的人還能有孩子嗎？撒拉已經九十歲了，還能生育嗎？」</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行傳 2:39; 詩篇 41:12; 詩篇 4:6"> 亞伯拉罕對上帝說：「願以實瑪利蒙你賜福。」</span>
<span className="v" id="v19" data-v="19" data-xref="路加福音 1:13–20; 創世記 21:2–3; 列王紀下 4:16–17"> 上帝說：「不，你妻子撒拉必為你生一個兒子，你要給他取名叫以撒，我必與他堅立我的約，作為他後代永遠的約。</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 21:18; 創世記 21:13; 創世記 25:12–18"> 至於以實瑪利，我已聽見你的祈求，我必賜福給他，使他生養眾多、子孫極其繁盛。他必做十二個族長的父親，我必使他成為大國。</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 21:2–3; 創世記 26:2–5; 加拉太書 3:29"> 撒拉必在明年這時候給你生以撒，我必向他堅守我的約。」</span>
<span className="v" id="v22" data-v="22" data-xref="創世記 18:33; 創世記 35:9–15; 士師記 6:21"> 上帝說完以後，便離開亞伯拉罕上升而去。</span>
<span className="v" id="v23" data-v="23" data-xref="詩篇 119:60; 創世記 18:19; 創世記 17:10–14"> 亞伯拉罕就在那天照著上帝的吩咐，為兒子以實瑪利和家中所有的男子，不論是在家中出生的，還是買回來的，都行了割禮。</span>
<span className="v" id="v24" data-v="24" data-xref="羅馬書 4:11; 創世記 17:17; 羅馬書 4:19–20"> 亞伯拉罕接受割禮的時候九十九歲。</span>
<span className="v" id="v25" data-v="25"> 他的兒子以實瑪利接受割禮的時候十三歲。</span>
<span className="v" id="v26" data-v="26" data-xref="詩篇 119:60; 創世記 22:3–4; 創世記 12:4"> 他們父子二人就在那天接受了割禮。</span>
<span className="v" id="v27" data-v="27" data-xref="創世記 18:19"> 亞伯拉罕家裡所有的男子，包括家中出生的和買回來的，都一起接受了割禮。</span>

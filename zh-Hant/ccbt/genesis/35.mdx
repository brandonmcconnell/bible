## 雅各遷往伯特利

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 31:13; 何西阿書 12:4; 詩篇 91:15"> 上帝對雅各說：「你到伯特利去住，你要在那裡為上帝築一座壇，祂在你逃避你哥哥以掃時曾向你顯現。」</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 19:14; 出埃及記 19:10; 以西結書 18:31"> 於是，雅各吩咐家人和所有的隨從：「你們要除掉你們當中的外族神像，潔淨自己，更換衣服。</span>
<span className="v" id="v3" data-v="3" data-xref="以賽亞書 43:2; 創世記 32:7; 創世記 31:3"> 我們要上伯特利去，在那裡為上帝築一座壇，祂在我遭遇患難時聽了我的禱告，一路都與我同在。」</span>
<span className="v" id="v4" data-v="4" data-xref="士師記 9:6; 申命記 7:25; 出埃及記 32:20"> 他們把所有外族的神像和自己的耳環都交給雅各，雅各把這些東西埋在示劍的橡樹下。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 23:27; 歷代志下 17:10; 約書亞記 5:1"> 他們就出發了，上帝使恐懼籠罩周圍的城邑，沒有人敢追趕他們。</span>
<span className="v" id="v6" data-v="6" data-xref="創世記 28:19; 創世記 28:22; 創世記 12:8"> 雅各和所有的隨從來到迦南的路斯，也就是伯特利。</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 35:3; 創世記 35:1; 創世記 28:13"> 他在那裡建造了一座壇，稱那地方為伊勒·伯特利<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「伊勒·伯特利」意思是「伯特利的上帝」。">a</a></sup>，因為在他逃避哥哥的時候，上帝曾在那裡向他顯現。</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 24:59; 撒母耳記上 31:13; 士師記 2:5"> 後來利百加的奶媽底波拉死了，葬在伯特利下面的橡樹下，那棵樹叫亞倫·巴古<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="「亞倫·巴古」意思是「哭泣的橡樹」。">b</a></sup>。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 35:1; 創世記 18:1; 創世記 26:2"> 雅各從巴旦·亞蘭回來後，上帝又向他顯現，賜福給他。</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 17:5; 創世記 32:27–28; 創世記 17:15"> 上帝對他說：「你叫雅各，但從今以後不要再叫雅各了，你要改名叫以色列。」這樣雅各改名為以色列。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 17:1; 創世記 9:1; 創世記 22:17"> 上帝又說：「我是全能的上帝，你要生養眾多，人丁興旺，一國，甚至多國必從你而出，許多君王必出自你的子孫。</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 12:7; 創世記 28:13; 創世記 26:3–4"> 我要把賜給亞伯拉罕和以撒的土地賜給你和你的後代。」</span>
<span className="v" id="v13" data-v="13" data-xref="創世記 17:22; 創世記 18:33; 士師記 6:21"> 上帝說完就離開雅各升上天去。</span>
<span className="v" id="v14" data-v="14" data-xref="創世記 28:18–19; 撒母耳記上 7:12; 出埃及記 17:15"> 雅各在上帝跟他說話的地方立了一根石柱，又在柱子上奠酒、澆油，</span>
<span className="v" id="v15" data-v="15" data-xref="創世記 28:19"> 稱那地方為伯特利。</span>
</div>
</div>

## 拉結和以撒去世

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="彌迦書 5:2; 創世記 48:7; 列王紀下 5:19"> 他們從伯特利繼續前行，離以法他還有一段路時，拉結要分娩，出現難產。</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 30:24; 撒母耳記上 4:19–21"> 接生婆對難產的她說：「不要害怕，你又添了一個兒子！」</span>
<span className="v" id="v18" data-v="18" data-xref="路加福音 12:20; 使徒行傳 7:59; 路加福音 23:46"> 拉結嚥氣前給兒子取名叫便·俄尼<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="「便·俄尼」意思是「我在苦難中生的兒子」。">c</a></sup>，雅各卻叫他便雅憫<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="「便雅憫」意思是「右手之子」，「右手」希伯來文有幸運或力量的意思。">d</a></sup>。</span>
<span className="v" id="v19" data-v="19" data-xref="彌迦書 5:2; 創世記 48:7; 路得記 4:11"> 拉結死後就葬在通往以法他的路旁，以法他即伯利恆。</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳記上 10:2; 創世記 35:14; 撒母耳記下 18:17–18"> 雅各在她的墳上立了石碑，這碑至今還在。</span>
<span className="v" id="v21" data-v="21" data-xref="彌迦書 4:8; 路加福音 2:8"> 以色列繼續前行，在以得塔附近搭起了帳篷。</span>
<span className="v" id="v22" data-v="22" data-xref="歷代志上 5:1; 利未記 18:8; 撒母耳記下 20:3"> 以色列在那裡居住時，呂便和父親的妾辟拉通姦，以色列也知道這件事。 雅各有十二個兒子。</span>
<span className="v" id="v23" data-v="23" data-xref="創世記 30:18–20; 創世記 46:8–15; 創世記 29:32–35"> 利亞生了雅各的長子呂便，還有西緬、利未、猶大、以薩迦和西布倫。</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 30:22–24; 創世記 46:19–22; 創世記 35:16–18"> 拉結生了約瑟和便雅憫。</span>
<span className="v" id="v25" data-v="25" data-xref="創世記 46:23–25; 創世記 37:2; 創世記 30:4–8"> 拉結的婢女辟拉生了但和拿弗他利。</span>
<span className="v" id="v26" data-v="26" data-xref="創世記 30:9–13; 創世記 46:16–18; 創世記 25:20"> 利亞的婢女悉帕生了迦得和亞設。他們都是雅各的兒子，是在巴旦·亞蘭出生的。</span>
<span className="v" id="v27" data-v="27" data-xref="創世記 13:18; 創世記 23:19; 創世記 18:1"> 雅各來到他父親以撒住的幔利，即基列·亞巴，也就是亞伯拉罕和以撒寄居的地方。基列·亞巴就是希伯崙。</span>
<span className="v" id="v28" data-v="28" data-xref="創世記 25:7; 創世記 50:26; 創世記 47:28"> 以撒享年一百八十歲，</span>
<span className="v" id="v29" data-v="29" data-xref="創世記 15:15; 創世記 49:33; 創世記 49:31"> 年紀老邁，壽終正寢，歸到他祖先那裡。他的兒子以掃和雅各把他安葬了。</span>
</div>

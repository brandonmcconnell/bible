## 約瑟試驗弟兄

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 42:25; 創世記 43:16; 創世記 24:2"> 約瑟吩咐管家說：「給他們的口袋裝滿糧食，他們能帶多少就裝多少，把各人的錢放回他們的口袋中，</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多後書 8:8; 創世記 42:20; 申命記 8:16"> 再把我的銀杯和買糧的錢一起放在最小的兄弟的口袋中。」管家遵命而行。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3"> 清早，他們就牽著驢被送走了。</span>
<span className="v" id="v4" data-v="4" data-xref="約翰福音 10:32; 詩篇 35:12; 箴言 17:13"> 他們出城不久，約瑟對管家說：「你快去追他們，追上了就對他們說，『你們為什麼以惡報善？</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 30:27; 利未記 19:26; 列王紀下 21:6"> 為什麼偷我主人用來喝酒和占卜的銀杯？你們這是作惡！』」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6"> 於是，管家追上他們，按約瑟的話問他們。</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 38:16–18; 創世記 37:18–32; 列王紀下 8:13"> 他們回答說：「我主為什麼這樣說？我們絕不會做這種事。</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 43:12; 創世記 42:35; 羅馬書 13:9"> 你看，我們把上次在口袋裡發現的錢都從迦南帶回來還你了，又怎麼會偷你主人家的金銀呢？</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 31:32; 詩篇 7:3–5; 約伯記 31:38–40"> 你若在僕人中任何人身上搜到銀杯，他就要死！我們也要做我主的奴僕。」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="出埃及記 22:3; 創世記 44:17; 創世記 44:33"> 管家說：「好，就照你們的話做吧！銀杯從誰那裡搜出來，誰就做我的奴僕，其他人都沒有罪。」</span>
<span className="v" id="v11" data-v="11"> 於是，他們急忙把各自的口袋卸到地上打開。</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 44:26–32; 創世記 42:36–38; 創世記 43:14"> 管家就從最年長的開始搜查，結果在最年幼的便雅憫口袋裡搜出了銀杯。</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳記下 1:11; 創世記 37:29–34; 撒母耳記下 1:2"> 他們傷心地撕裂衣服，把東西放回驢背上，返回城裡。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="創世記 50:18; 創世記 43:25; 創世記 43:16"> 猶大和他兄弟們回到約瑟家時，約瑟還在那裡，他們就俯伏在他面前。</span>
<span className="v" id="v15" data-v="15" data-xref="創世記 4:10; 創世記 21:26; 創世記 3:13"> 約瑟對他們說：「你們做的是什麼事？難道你們不知道像我這樣的人是懂得占卜的嗎？」</span>
<span className="v" id="v16" data-v="16" data-xref="創世記 44:9; 但以理書 9:7; 民數記 32:23"> 猶大說：「我們能對我主說什麼呢？我們還有什麼話可說呢？我們如何洗脫罪名呢？上帝既然查出你僕人們的罪，我們跟那個手上被發現有銀杯的一起做我主的奴僕吧！」</span>
<span className="v" id="v17" data-v="17" data-xref="箴言 17:15; 撒母耳記下 23:3; 創世記 18:25"> 約瑟回答說：「不！我決不會這樣做。從誰那裡搜出了銀杯，誰就做我的奴僕，其他人平安地回去見你們的父親吧。」</span>
</div>
</div>

## 猶大求情

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="出埃及記 32:22; 創世記 41:40; 創世記 18:30"> 猶大近前來對他說：「我主啊，你就像法老一樣，求你容僕人說一句話，不要向僕人發怒。</span>
<span className="v" id="v19" data-v="19" data-xref="創世記 43:7; 創世記 43:29; 創世記 42:7–10"> 我主曾經問僕人們是否有父親和弟兄，</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 37:3; 創世記 42:38; 路加福音 7:12"> 我們對我主說，『我們有年邁的老父，他在晚年得了一個兒子，這孩子的哥哥已經死了，他母親只剩下他這一個兒子，他父親很疼愛他。』</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 42:15; 創世記 42:20; 阿摩司書 9:4"> 你吩咐僕人們把弟弟帶來給你親眼看看，</span>
<span className="v" id="v22" data-v="22" data-xref="創世記 44:30; 創世記 42:38"> 我們對我主說，『這孩子不能離開他父親，他若離開，他父親一定會死。』</span>
<span className="v" id="v23" data-v="23" data-xref="創世記 43:5; 創世記 43:3; 創世記 42:15–20"> 可是，你說如果僕人們不把最小的弟弟帶來，就不得再見你的面。</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 42:29–34"> 我們回到你僕人——我們的父親那裡，把我主的話告訴了他。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="創世記 43:2; 創世記 43:5"> 「後來，他又吩咐僕人們回來買些糧，</span>
<span className="v" id="v26" data-v="26" data-xref="路加福音 11:7; 創世記 43:4–5"> 我們告訴他，我們不能來，只有我們最小的弟弟同來，我們才能來。否則，我們不能見你的面。</span>
<span className="v" id="v27" data-v="27" data-xref="創世記 46:19; 創世記 35:16–18; 創世記 30:22–25"> 你僕人——我的父親就對我們說，『你們知道，我妻子給我生了兩個兒子。</span>
<span className="v" id="v28" data-v="28" data-xref="創世記 37:33; 創世記 37:13–14; 創世記 42:36"> 其中一個離我而去，我想他一定被野獸撕碎了，我再沒有見過他。</span>
<span className="v" id="v29" data-v="29" data-xref="創世記 42:38; 創世記 43:14; 申命記 31:17"> 要是你們把這個也帶走，遇上什麼意外的話，你們會使我這白髮蒼蒼的老人淒淒慘慘地下陰間。』</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="撒母耳記上 18:1; 撒母耳記下 18:33; 創世記 44:31"> 「我們父親的命與這孩子的命緊密相連，倘若我沒有把這孩子帶回到你僕人——我的父親身邊，</span>
<span className="v" id="v31" data-v="31" data-xref="創世記 44:29; 創世記 37:35; 哥林多後書 7:10"> 他一看這孩子不在，一定會死。僕人們會使自己白髮蒼蒼的父親淒淒慘慘地下陰間。</span>
<span className="v" id="v32" data-v="32" data-xref="創世記 43:8–9; 創世記 43:16"> 僕人曾經向父親擔保這孩子的安全，說我若不把這孩子帶回他身邊，情願一生擔罪。</span>
<span className="v" id="v33" data-v="33" data-xref="約翰一書 3:16; 出埃及記 32:32; 希伯來書 7:22"> 現在請准許僕人代替這孩子做我主的奴僕，讓他跟他哥哥們回去吧。</span>
<span className="v" id="v34" data-v="34" data-xref="以斯帖記 8:6; 詩篇 116:3; 詩篇 119:143"> 這孩子若不和我一同回去，我如何見我父親呢？我不願看到災難臨到我父親。」</span>
</div>
</div>

</div>

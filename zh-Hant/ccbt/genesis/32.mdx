## 雅各預備見以掃

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="詩篇 91:11; 詩篇 34:7; 希伯來書 1:4"> 雅各繼續前行，上帝的天使遇見了他。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳記下 2:8; 約書亞記 5:14; 約書亞記 21:38"> 雅各看見他們，就說：「這是上帝的軍隊！」於是稱那地方為瑪哈念<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「瑪哈念」意思是「兩營軍隊」。">a</a></sup>。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 25:30; 約書亞記 24:4; 申命記 2:5"> 雅各先派使者到西珥，就是以東地區，去見他哥哥以掃，</span>
<span className="v" id="v4" data-v="4" data-xref="彼得前書 3:6; 路加福音 14:11; 創世記 33:8"> 並吩咐他們：「你們要這樣對我主以掃說，『你僕人雅各說他一直寄居在拉班家裡，</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 33:8; 創世記 33:15; 創世記 33:11"> 現在他帶了牛羊、驢和僕婢回來見我主，派我們來報信，希望在你面前蒙恩。』」</span>
<span className="v" id="v6" data-v="6" data-xref="創世記 33:1; 創世記 32:8; 創世記 32:11"> 報信的人回到雅各那裡，說：「我們到了你哥哥以掃那裡，他正帶著四百人前來見你。」</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 35:3; 哥林多後書 1:8–10; 出埃及記 14:10"> 雅各聽了非常害怕，憂心忡忡，便把隨從、牛群、羊群和駱駝分成兩隊，</span>
<span className="v" id="v8" data-v="8" data-xref="馬太福音 10:16; 創世記 33:1–3"> 心想：「如果以掃來攻擊一隊，另一隊還可以逃生。」</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 31:42; 詩篇 34:4–6; 創世記 31:3"> 他禱告說：「耶和華，我祖父亞伯拉罕和我父親以撒的上帝啊！你吩咐我回到家鄉和親族那裡，答應厚待我。</span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 18:35; 創世記 24:27; 撒母耳記下 7:18"> 我不配蒙你以慈愛和信實相待，我先前過約旦河的時候，手上只有一根杖，現在卻有兩隊人畜。</span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 59:1–2; 箴言 18:19; 馬太福音 6:13"> 求你救我脫離我哥哥以掃的手，我怕他會來殺我和我的妻兒。</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 28:13–15; 希伯來書 6:17; 提多書 1:2"> 然而，你曾說，『我必厚待你，使你的後代多如海沙，不可勝數。』」</span>
<span className="v" id="v13" data-v="13" data-xref="箴言 18:16; 創世記 43:11; 箴言 19:6"> 那天晚上，雅各就在那裡過夜，又從產業中挑選牲畜送給哥哥以掃作禮物：</span>
<span className="v" id="v14" data-v="14" data-xref="約伯記 1:3; 申命記 8:18; 約伯記 42:12"> 母山羊二百隻、公山羊二十隻、母綿羊二百隻、公綿羊二十隻、</span>
<span className="v" id="v15" data-v="15"> 哺乳的駱駝三十頭及其小駱駝、母牛四十頭、公牛十頭、母驢二十頭、公驢十頭。</span>
<span className="v" id="v16" data-v="16" data-xref="創世記 33:8–9; 創世記 32:20; 箴言 2:11"> 雅各把牲畜每類分成一群，交給僕人看管，對他們說：「你們走在前頭，每群牲畜之間要保持一段距離！」</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 33:3"> 又吩咐走在最前面的僕人說：「我哥哥以掃遇到你的時候，如果問你是誰家的人？要到哪裡去？你前頭這些牲畜是誰的？</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 32:4–5"> 你就說，『是你僕人雅各的，是送給他主人以掃的禮物，他自己就在後面。』」</span>
<span className="v" id="v19" data-v="19"> 雅各又吩咐趕第二群、第三群及其餘牲畜的僕人遇見以掃時也要這樣回答，</span>
<span className="v" id="v20" data-v="20" data-xref="約伯記 42:8–9; 箴言 21:14; 創世記 43:11"> 並且一定要說：「你僕人雅各就在後面。」雅各想先用禮物去化解以掃的怨恨，也許見面時以掃會善待他。</span>
<span className="v" id="v21" data-v="21"> 於是，他派人先把禮物送過去，自己則留在營裡過夜。</span>
</div>
</div>

## 雅各遇見上帝

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="申命記 3:16; 申命記 2:37; 提摩太前書 5:8"> 當夜，雅各起來帶著兩個妻子、兩個婢女和十一個兒子渡過雅博渡口。</span>
<span className="v" id="v23" data-v="23"> 雅各把他們連同一切所有都送過河以後，</span>
<span className="v" id="v24" data-v="24" data-xref="何西阿書 12:3–5; 以弗所書 6:12; 路加福音 13:24"> 自己獨自留下。有一個人來和他摔跤，直到黎明。</span>
<span className="v" id="v25" data-v="25" data-xref="哥林多後書 12:7–9; 何西阿書 12:3–4; 馬太福音 26:41"> 那人見勝不過雅各，就在他的大腿窩摸了一下，他大腿的關節就脫臼了。</span>
<span className="v" id="v26" data-v="26" data-xref="何西阿書 12:4; 詩篇 115:12–13; 哥林多後書 12:8–9"> 那人說：「天亮了，讓我走吧！」但雅各說：「你不祝福我，我就不讓你走。」</span>
<span className="v" id="v27" data-v="27"> 那人問道：「你叫什麼名字？」他說：「我叫雅各。」</span>
<span className="v" id="v28" data-v="28" data-xref="啟示錄 2:17; 創世記 35:10; 以賽亞書 62:2–4"> 那人說：「你以後不要再叫雅各了，你要叫以色列，因為你跟上帝和人角力都得勝了。」</span>
<span className="v" id="v29" data-v="29" data-xref="以賽亞書 9:6; 士師記 13:16–18; 約伯記 11:7"> 雅各說：「請你告訴我你的名字。」那人說：「你為什麼問我的名字？」他就在那裡給雅各祝福。</span>
<span className="v" id="v30" data-v="30" data-xref="出埃及記 24:10–11; 民數記 12:8; 以賽亞書 6:5"> 雅各稱那地方為毗努伊勒，因為他說：「我面對面見過上帝，竟能活命。」</span>
<span className="v" id="v31" data-v="31" data-xref="哥林多後書 12:7; 創世記 19:15; 士師記 8:8"> 雅各經過毗努伊勒的時候，太陽出來了，那時他的大腿瘸了。</span>
<span className="v" id="v32" data-v="32" data-xref="撒母耳記上 5:5"> 以色列人至今都不吃大腿窩的筋，因為那人摸過雅各大腿窩的筋。</span>
</div>

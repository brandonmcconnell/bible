## 上帝應許撒拉生子

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 14:13; 創世記 48:3; 創世記 13:18"> 耶和華在幔利的橡樹那裡向亞伯拉罕顯現。那時天氣很熱，亞伯拉罕坐在帳篷口，</span>
<span className="v" id="v2" data-v="2" data-xref="希伯來書 13:2; 創世記 18:22; 創世記 19:1"> 抬頭看見三個人站在對面，就從帳篷口跑去迎接他們，俯伏在地，</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 32:5"> 說：「我主，若我在你面前蒙恩，請不要從僕人這裡走過去。</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 24:32; 創世記 19:2; 創世記 43:24"> 我讓人拿點水來，你們洗洗腳，在樹下歇一會兒。</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 104:15; 士師記 13:15; 士師記 6:18"> 你們既然路過僕人這裡，我拿點餅來，你們補充一下體力再上路吧。」他們說：「好，就照你說的做吧！」</span>
<span className="v" id="v6" data-v="6" data-xref="馬太福音 13:33; 希伯來書 13:2; 使徒行傳 16:15"> 於是，亞伯拉罕連忙進帳篷對撒拉說：「快準備三斗<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「三斗」希伯來文是「三細亞」，大約是十公斤。">a</a></sup>細麵粉，和麵烤餅。」</span>
<span className="v" id="v7" data-v="7" data-xref="瑪拉基書 1:14; 路加福音 15:27; 路加福音 15:30"> 亞伯拉罕又跑到牛群中牽了一頭肥嫩的小牛，交給僕人趕快去準備。</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 19:3; 士師記 13:15; 啟示錄 3:20"> 亞伯拉罕把奶、乳酪和準備好的牛肉擺在他們面前，自己在樹蔭下侍立一旁，伺候他們用餐。</span>
<span className="v" id="v9" data-v="9" data-xref="提多書 2:5; 創世記 24:67; 創世記 4:9"> 他們問亞伯拉罕：「你妻子撒拉在哪裡？」亞伯拉罕回答說：「在帳篷裡。」</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 21:2; 創世記 17:21; 羅馬書 9:8–9"> 其中一人說：「明年這時候，我必回到你這裡，撒拉必生一個兒子。」撒拉在那人後面的帳篷口聽見了。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 17:17; 希伯來書 11:11–12; 路加福音 1:36"> 亞伯拉罕和撒拉已經年紀老邁，撒拉早已絕經。</span>
<span className="v" id="v12" data-v="12" data-xref="彼得前書 3:6; 創世記 17:17; 路加福音 1:18–20"> 撒拉暗自發笑，心想：「我已經老了，還會有這種福氣嗎？況且我的丈夫也老了。」</span>
<span className="v" id="v13" data-v="13" data-xref="約翰福音 2:25"> 耶和華問亞伯拉罕：「撒拉為什麼偷笑說，『我這把年紀還會有孩子嗎？』</span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 1:37; 馬太福音 19:26; 馬可福音 10:27"> 什麼事能難得了耶和華呢？明年這時候，我必回到你這裡，撒拉必生一個兒子。」</span>
<span className="v" id="v15" data-v="15" data-xref="約翰一書 1:8; 箴言 28:13; 以弗所書 4:23"> 撒拉聽見後非常害怕，連忙否認說：「我沒有笑！」但耶和華說：「不，你確實笑了。」</span>
</div>
</div>

## 亞伯拉罕為所多瑪求情

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="使徒行傳 15:3; 使徒行傳 21:5; 使徒行傳 20:38"> 那三個人起身朝所多瑪眺望，亞伯拉罕與他們同行，要送他們一程。</span>
<span className="v" id="v17" data-v="17" data-xref="阿摩司書 3:7; 詩篇 25:14; 約翰福音 15:15"> 耶和華說：「我要做的事怎麼可以瞞著亞伯拉罕呢？</span>
<span className="v" id="v18" data-v="18" data-xref="加拉太書 3:8; 創世記 26:4; 加拉太書 3:14"> 亞伯拉罕必成為強盛的大國，天下萬國必因他而蒙福。</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 6:6–7; 申命記 4:9–10; 提摩太前書 3:4–5"> 我揀選了他，是要他教導自己的子孫後代持守我的道、秉公行義。這樣，我必實現對他的應許。」</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 19:13; 以西結書 16:49–50; 以賽亞書 3:9"> 耶和華說：「所多瑪和蛾摩拉罪惡深重，人們怨聲載道。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及記 3:8; 創世記 11:5; 西番雅書 1:12"> 我現在要下去看看他們的惡行是否如我聽到的控訴一樣，如果不是，我也會知道。」</span>
<span className="v" id="v22" data-v="22" data-xref="創世記 19:1; 使徒行傳 7:55; 以西結書 22:30"> 其中二人轉身向所多瑪走去，亞伯拉罕卻仍舊站在耶和華面前。</span>
<span className="v" id="v23" data-v="23" data-xref="民數記 16:22; 撒母耳記下 24:17; 創世記 20:4"> 亞伯拉罕上前說：「你要把義人和惡人一同毀滅嗎？</span>
<span className="v" id="v24" data-v="24" data-xref="耶利米書 5:1; 以賽亞書 1:9; 馬太福音 7:13–14"> 倘若城中有五十個義人，你還要毀滅那城嗎？你會不會為了五十個義人而饒恕那座城呢？</span>
<span className="v" id="v25" data-v="25" data-xref="約伯記 8:3; 以賽亞書 3:10–11; 約伯記 8:20"> 你絕不會黑白不分，把義人和惡人一同毀滅。你絕不會這麼做！你是普天下的審判者，難道不秉公行事嗎？」</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米書 5:1; 馬太福音 24:22; 以賽亞書 65:8"> 耶和華回答說：「我若在所多瑪城中找到五十個義人，就因他們的緣故饒恕全城。」</span>
<span className="v" id="v27" data-v="27" data-xref="創世記 3:19; 以賽亞書 6:5; 哥林多前書 15:47–48"> 亞伯拉罕說：「主啊，我雖然渺小如灰塵，還斗膽問你，</span>
<span className="v" id="v28" data-v="28" data-xref="創世記 18:29; 列王紀上 20:32–33; 創世記 18:26"> 倘若只有四十五個義人，你會因為少了五個義人而毀滅全城嗎？」耶和華說：「我若在城裡找到四十五個義人，也不會毀滅那城。」</span>
<span className="v" id="v29" data-v="29" data-xref="以弗所書 6:18; 希伯來書 4:16"> 亞伯拉罕又說：「倘若在那裡找到四十個義人呢？」耶和華說：「為了那四十個人的緣故，我不會毀滅那城。」</span>
<span className="v" id="v30" data-v="30" data-xref="詩篇 89:7; 詩篇 9:12; 以斯帖記 4:11–16"> 亞伯拉罕說：「求主不要發怒，容許我再問一次，倘若在那裡只找到三十個義人呢？」耶和華說：「倘若在那裡只找到三十個，我也不會毀滅那城。」</span>
<span className="v" id="v31" data-v="31" data-xref="路加福音 11:8; 創世記 18:27; 路加福音 18:1"> 亞伯拉罕說：「我大膽再問一次，倘若在那裡只找到二十個義人呢？」耶和華說：「為了那二十個人的緣故，我也不會毀滅那城。」</span>
<span className="v" id="v32" data-v="32" data-xref="雅各書 5:15–17; 士師記 6:39; 馬太福音 7:7"> 亞伯拉罕又說：「求主不要發怒，讓我問最後一次，倘若在那裡只找到十個義人呢？」耶和華說：「為了那十個人的緣故，我也不會毀滅那城。」</span>
<span className="v" id="v33" data-v="33" data-xref="創世記 18:22; 創世記 32:26; 創世記 31:55"> 耶和華跟亞伯拉罕說完話便離開了，亞伯拉罕也回家去了。</span>

## 約瑟的夢

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 17:8; 創世記 23:4; 創世記 36:7"> 雅各住在他父親寄居的迦南，</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 35:25–26; 創世記 35:22; 撒母耳記上 2:22–24"> 以下是有關雅各一家的記載。 十七歲的少年約瑟跟哥哥們，就是他父親雅各的妾辟拉和悉帕生的兒子們一同放羊。他向父親報告哥哥們做的壞事。</span>
<span className="v" id="v3" data-v="3" data-xref="約翰福音 3:35; 創世記 37:32; 撒母耳記下 13:18"> 約瑟是以色列年老時生的，眾子中以色列最愛他，為他做了一件彩衣。</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 27:41; 約翰一書 3:12; 約翰一書 4:20"> 約瑟的哥哥們見父親偏愛他，就懷恨在心，對他惡言相向。</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 28:12; 創世記 42:9; 約翰福音 17:14"> 約瑟做了一個夢，並告訴了哥哥們，他們更恨他了。</span>
<span className="v" id="v6" data-v="6" data-xref="創世記 44:18; 士師記 9:7"> 約瑟對哥哥們說：「你們聽聽我做的夢：</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 44:14; 創世記 42:6; 創世記 43:26"> 我們在田裡捆莊稼，我捆的莊稼站立起來，你們捆的莊稼都圍著我捆的莊稼下拜。」</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳記上 10:27; 使徒行傳 7:35; 希伯來書 10:29"> 他的哥哥們回答說：「難道你真要做我們的王嗎？真要統治我們嗎？」因為約瑟的夢和他說的話，他們就更加恨他。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行傳 7:9–14; 創世記 37:7; 但以理書 8:10"> 後來，約瑟又做了一個夢，他又去對哥哥們說：「你們聽聽我做的另一個夢，我夢見太陽、月亮和十一顆星星都向我下拜。」</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 27:29; 腓立比書 2:10–11; 以賽亞書 60:14"> 約瑟把夢告訴了父親和哥哥們，他父親就責備他說：「你做的是什麼夢！難道你的父母弟兄真的都要來向你俯伏下拜嗎？」</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行傳 7:9; 路加福音 2:19; 路加福音 2:51"> 約瑟的哥哥們嫉恨他，他父親卻把這些話記在心裡。</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 37:1; 創世記 33:18; 創世記 34:25–31"> 約瑟的哥哥們到示劍放父親的羊。</span>
<span className="v" id="v13" data-v="13" data-xref="以弗所書 6:1–3; 撒母耳記上 3:8; 撒母耳記上 3:16"> 以色列對約瑟說：「你哥哥們在示劍放羊，我要派你去他們那裡。」約瑟說：「好的。」</span>
<span className="v" id="v14" data-v="14" data-xref="創世記 35:27; 路加福音 19:42; 詩篇 125:5"> 以色列說：「你去看看你哥哥們以及羊群是否平安，然後回來告訴我。」於是，他派約瑟從希伯崙谷出發，前往示劍。</span>
<span className="v" id="v15" data-v="15" data-xref="約翰福音 4:27; 士師記 4:22; 創世記 21:14"> 有人見約瑟在田野走迷了路，就問他：「你在找什麼？」</span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 19:10; 雅歌 1:7"> 約瑟回答說：「我在找我哥哥們，你知道他們在哪裡放羊嗎？」</span>
<span className="v" id="v17" data-v="17" data-xref="列王紀下 6:13"> 那人說：「他們已經走了，我聽他們說要到多坍去。」約瑟就趕往多坍，在那裡找到了他們。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行傳 23:12; 詩篇 37:12; 詩篇 37:32"> 約瑟的哥哥們遠遠看見他走來，趁他還沒有到跟前，就合謀要殺死他。</span>
<span className="v" id="v19" data-v="19" data-xref="創世記 28:12; 創世記 37:11; 創世記 37:5"> 他們彼此商量說：「看！做夢的來了。</span>
<span className="v" id="v20" data-v="20" data-xref="提多書 3:3; 箴言 27:4; 馬太福音 2:2–16"> 來吧！我們殺了他，把他扔在井裡，就說有野獸把他吃掉了，看他的夢怎麼實現。」</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 42:22; 創世記 35:22; 約書亞記 10:28"> 呂便聽後想救約瑟的性命，就說：「我們不要害他性命。」</span>
<span className="v" id="v22" data-v="22" data-xref="創世記 22:12; 申命記 13:9; 創世記 42:22"> 他又說：「不要殺人流血，把他扔在這曠野的井裡吧，不要下手害他。」呂便想從他們手上救下約瑟，把他交回給父親。</span>
<span className="v" id="v23" data-v="23" data-xref="創世記 37:3; 馬太福音 27:28; 創世記 42:21"> 這時候，約瑟來到哥哥們那裡，他們就剝去他身上的彩衣，</span>
<span className="v" id="v24" data-v="24" data-xref="耶利米書 38:6; 詩篇 130:1–2; 撒迦利亞書 9:11"> 抓住他把他扔到井裡。當時，那口井是乾的，沒有水。</span>
<span className="v" id="v25" data-v="25" data-xref="創世記 37:28; 創世記 43:11; 耶利米書 8:22"> 他們坐下來吃飯的時候，抬頭看見一支從基列來的以實瑪利商隊用駱駝馱著香料、乳香、沒藥去埃及。</span>
<span className="v" id="v26" data-v="26" data-xref="創世記 37:20; 創世記 4:10; 創世記 25:32"> 猶大對他的眾弟兄說：「我們殺死弟弟、掩蓋他的血跡有什麼益處呢？</span>
<span className="v" id="v27" data-v="27" data-xref="馬太福音 16:26; 創世記 42:21; 撒母耳記上 18:17"> 不如把他賣給以實瑪利人，不要下手害他，他畢竟是我們的弟弟，我們的骨肉啊！」其他弟兄都贊成他的意見。</span>
<span className="v" id="v28" data-v="28" data-xref="使徒行傳 7:9; 詩篇 105:17; 創世記 45:4–5"> 於是，那些米甸商人經過的時候，他們就把約瑟從井裡拉上來，以四兩銀子的價錢把他賣給了以實瑪利人。這些商人把他帶到埃及去了。</span>
<span className="v" id="v29" data-v="29" data-xref="約伯記 1:20; 創世記 37:34; 創世記 44:13"> 呂便回到井邊發現約瑟不見了，就傷心地撕裂了身上的衣服，</span>
<span className="v" id="v30" data-v="30" data-xref="創世記 42:13; 耶利米書 31:15; 創世記 42:32"> 回到弟兄們那裡說：「那少年不見了，我現在怎麼辦？」</span>
<span className="v" id="v31" data-v="31" data-xref="創世記 37:23; 箴言 28:13; 創世記 37:3"> 他們宰了一隻公山羊，把約瑟的彩衣拿來沾上血，</span>
<span className="v" id="v32" data-v="32" data-xref="路加福音 15:30; 創世記 37:3; 創世記 44:20–23"> 拿去給父親，說：「我們撿到這件衣服，你看看是不是你兒子的？」</span>
<span className="v" id="v33" data-v="33" data-xref="創世記 37:20; 創世記 44:28; 約翰福音 13:7"> 雅各認出那件彩衣，說：「這是我兒子的衣服，一定是野獸把他吃了，約瑟一定被撕碎了！」</span>
<span className="v" id="v34" data-v="34" data-xref="創世記 37:29; 撒母耳記下 3:31; 詩篇 69:11"> 雅各撕裂自己的衣服，腰間束上麻布，為約瑟哀傷了好多天。</span>
<span className="v" id="v35" data-v="35" data-xref="創世記 42:38; 約伯記 2:11; 撒母耳記下 12:17"> 他的兒女都來安慰他，他卻不肯接受他們的安慰，說：「我一定會悲悲傷傷地下到陰間，去我兒子那裡。」約瑟的父親為他哀哭。</span>
<span className="v" id="v36" data-v="36" data-xref="創世記 40:4; 創世記 37:28; 列王紀下 25:8"> 那些米甸人把約瑟帶到埃及後，賣給了法老的內臣護衛長波提乏。</span>

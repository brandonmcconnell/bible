## 洪水消退

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 30:22; 創世記 19:29; 詩篇 136:23"> 上帝眷顧挪亞及方舟裡的野獸和牲畜，就使風吹在大地上，水便開始消退。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 7:11; 馬太福音 8:26–27; 箴言 8:28"> 深淵的泉源和天上的水閘都關閉了，大雨也停了。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 7:24; 創世記 7:11"> 地上的洪水慢慢消退，過了一百五十天，水退下去了。</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀下 19:37; 耶利米書 51:27; 以賽亞書 37:38"> 七月十七日，方舟停在亞拉臘山上。</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 7:11"> 水繼續消退一直到十月，到十月一日，山頂都露出來了。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="創世記 6:16; 但以理書 6:10"> 又過了四十天，挪亞打開他在方舟上所造的窗戶，</span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 147:9; 列王紀上 17:6; 列王紀上 17:4"> 放出一隻烏鴉。牠一直在空中飛來飛去，直到地上的水都乾了。</span>
<span className="v" id="v8" data-v="8" data-xref="雅歌 2:14; 雅歌 1:15; 馬太福音 10:16"> 然後，挪亞放出一隻鴿子，以便瞭解地面的水是否已經消退。</span>
<span className="v" id="v9" data-v="9" data-xref="馬太福音 11:28; 詩篇 116:7; 申命記 28:65"> 但遍地都是水，鴿子找不到歇腳的地方，就飛回了方舟，挪亞伸手把鴿子接進方舟裡。</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 7:4; 創世記 7:10; 創世記 8:12"> 挪亞又等了七天，再把鴿子放出去。</span>
<span className="v" id="v11" data-v="11" data-xref="尼希米記 8:15; 撒迦利亞書 4:12–14; 羅馬書 10:15"> 到了黃昏，鴿子飛回來，嘴裡啣著一片新擰下來的橄欖葉，挪亞便知道地上的水已經退了。</span>
<span className="v" id="v12" data-v="12" data-xref="以賽亞書 25:9; 以賽亞書 30:18; 創世記 8:10"> 他又等了七天，再放出鴿子，這次鴿子沒有回來。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="創世記 7:11"> 挪亞六百零一歲那年的一月一日，地上的水乾了。挪亞打開方舟的蓋觀望，看見地面都乾了。</span>
<span className="v" id="v14" data-v="14" data-xref="創世記 7:13–14; 創世記 7:11"> 到了二月二十七日，大地完全乾了。</span>
<span className="v" id="v15" data-v="15"> 上帝對挪亞說：</span>
<span className="v" id="v16" data-v="16" data-xref="創世記 7:13; 詩篇 121:8; 詩篇 91:11"> 「你與妻子、兒子和兒媳都要出方舟。</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 1:22; 創世記 9:1; 耶利米書 31:27–28"> 你要把方舟裡的飛禽走獸及爬蟲等所有動物都帶出來，讓牠們在地上多多滋長，生養繁衍。」</span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 121:8"> 於是，挪亞與妻子、兒子和兒媳都出了方舟。</span>
<span className="v" id="v19" data-v="19"> 方舟裡的飛禽走獸和爬蟲等所有地上的動物，都按種類出了方舟。</span>
</div>
</div>

## 挪亞獻祭

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="希伯來書 13:15–16; 羅馬書 12:1; 創世記 22:9"> 挪亞為耶和華築了一座壇，在上面焚燒各種潔淨的牲畜和飛鳥作為燔祭。</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多後書 2:15; 以弗所書 5:2; 以賽亞書 54:9–10"> 耶和華聞到這燔祭的馨香，心想：「雖然人從小就心存惡念，但我再不會因為人的緣故而咒詛大地，再不會像這次一樣毀滅一切活物了。</span>
<span className="v" id="v22" data-v="22" data-xref="雅各書 5:7; 詩篇 74:16–17; 耶利米書 5:24"> 只要大地尚存，播種收割、夏熱冬寒、白晝黑夜必不停息。」</span>
</div>
</div>

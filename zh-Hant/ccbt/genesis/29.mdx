## 雅各到達舅父家

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士師記 6:3; 士師記 6:33; 何西阿書 12:12"> 雅各繼續前行，來到東方人住的地方，</span>
<span className="v" id="v2" data-v="2" data-xref="約翰福音 4:14; 以賽亞書 49:10; 約翰福音 4:6"> 看見田間有一口井，有三群羊臥在井邊，因為當地人用那口井的水飲羊。井口封著一塊大石頭。</span>
<span className="v" id="v3" data-v="3"> 羊群聚集在井旁的時候，牧人就把井口的石頭滾開飲羊，隨後再把石頭放回原處。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="創世記 28:10; 創世記 27:43; 使徒行傳 7:2"> 雅各問牧人：「弟兄們，你們是從哪裡來的？」他們說：「我們是從哈蘭來的。」</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 24:24; 創世記 24:29; 創世記 31:53"> 雅各問道：「你們認識拿鶴的孫子拉班嗎？」他們說：「我們認識。」</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳記下 20:9; 創世記 37:14; 出埃及記 18:7"> 雅各又問：「他好嗎？」他們回答說：「很好。你看，他的女兒拉結帶著羊群來了。」</span>
<span className="v" id="v7" data-v="7" data-xref="以弗所書 5:16; 加拉太書 6:9–10"> 雅各對他們說：「太陽還高，不到把羊關起來的時候，你們飲了羊，再放牠們去吃草吧！」</span>
<span className="v" id="v8" data-v="8" data-xref="馬可福音 16:3; 路加福音 24:2; 創世記 34:14"> 他們說：「不行，要等所有的羊群到齊，把井口的石頭滾開後，才能飲羊。」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="出埃及記 2:21; 雅歌 1:7–8; 出埃及記 2:15–16"> 雅各還在跟他們說話的時候，拉結就帶著她父親的羊群來到井邊，她是個牧羊女。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及記 2:17"> 雅各看見表妹拉結和舅父拉班的羊群來了，就上前把井口的石頭滾開，飲他舅父的羊。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 33:4; 創世記 45:14–15; 創世記 45:2"> 他親吻拉結，並放聲大哭。</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 24:28; 創世記 13:8; 創世記 14:14–16"> 雅各告訴拉結自己是她父親的外甥，是利百加的兒子。拉結便跑去告訴她父親。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="創世記 24:29; 使徒行傳 20:37; 羅馬書 16:16"> 拉班聽見外甥雅各來了，就跑去迎接他，擁抱他，親吻他，然後把他接到自己家裡。雅各把事情的經過告訴他。</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳記下 19:12–13; 創世記 2:23; 士師記 9:2"> 拉班說：「你真是我的骨肉至親啊！」雅各在拉班家裡住了一個月。</span>
</div>
</div>

## 雅各娶妻

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="創世記 30:28; 創世記 31:7"> 一天，拉班對他說：「雖然我們是親戚，也不能讓你白白地替我工作。告訴我，你希望得到什麼報酬？」</span>
<span className="v" id="v16" data-v="16" data-xref="路得記 4:11; 創世記 49:31; 創世記 31:4"> 拉班有兩個女兒，大的叫利亞，小的叫拉結。</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 12:11; 創世記 46:19–22; 創世記 24:16"> 利亞兩眼無神<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「兩眼無神」或譯「兩眼很美麗」。">a</a></sup>，而拉結長得美麗多姿。</span>
<span className="v" id="v18" data-v="18" data-xref="何西阿書 12:12; 出埃及記 22:16–17; 創世記 34:12"> 雅各愛上了拉結，於是對拉班說：「我願意為你工作七年，請把你小女兒拉結許配給我。」</span>
<span className="v" id="v19" data-v="19" data-xref="以賽亞書 6:11; 以賽亞書 6:5; 詩篇 12:2"> 拉班說：「把她嫁給你比嫁給外人好，你就留下來吧！」</span>
<span className="v" id="v20" data-v="20" data-xref="哥林多前書 13:7; 以弗所書 5:2; 何西阿書 12:12"> 雅各為了拉結給拉班工作了七年。因為他深愛拉結，所以這七年在他眼中就像短短的幾天。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="士師記 15:1; 創世記 29:20; 創世記 4:1"> 一天，雅各對拉班說：「期限已經滿了，現在請把我妻子給我，我好和她同房。」</span>
<span className="v" id="v22" data-v="22" data-xref="啟示錄 19:9; 路得記 4:10–13; 士師記 14:10–18"> 於是，拉班就擺設宴席款待當地的人。</span>
<span className="v" id="v23" data-v="23" data-xref="彌迦書 7:5; 創世記 38:14–15; 創世記 24:65"> 到了晚上，拉班卻把女兒利亞交給雅各，雅各和她同房。</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 16:1; 創世記 30:9–12; 創世記 46:18"> 拉班又把自己的婢女悉帕送給女兒利亞做婢女。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="馬太福音 7:2; 箴言 11:31; 哥林多前書 3:13"> 早上，雅各才發現娶的是利亞，就對拉班說：「你對我做的是什麼事啊！我服侍你不就是為了拉結嗎？你為什麼騙我？」</span>
<span className="v" id="v26" data-v="26"> 拉班說：「依照本地的習俗，妹妹不能比姐姐先出嫁。</span>
<span className="v" id="v27" data-v="27" data-xref="利未記 18:18; 士師記 14:12; 創世記 2:2–3"> 等這女兒七天的婚期過了，我就把那個女兒也許配給你，你再替我工作七年。」</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28"> 雅各同意了。過了七天，拉班把女兒拉結嫁給雅各，</span>
<span className="v" id="v29" data-v="29" data-xref="創世記 35:22; 創世記 29:24; 創世記 30:3–8"> 又把自己的婢女辟拉送給拉結。</span>
<span className="v" id="v30" data-v="30" data-xref="創世記 31:41; 創世記 29:20; 創世記 31:15"> 雅各也和拉結同房，他深愛拉結勝過愛利亞。他又替拉班工作了七年。</span>
</div>
</div>

## 雅各的兒女

<div className="bt">
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="撒母耳記上 2:21; 馬太福音 10:37; 申命記 21:15"> 耶和華看見利亞失寵，就使利亞生育，但拉結卻不生育。</span>
<span className="v" id="v32" data-v="32" data-xref="申命記 26:7; 出埃及記 4:31; 出埃及記 3:7"> 利亞懷孕生了一個兒子，給孩子取名叫呂便<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="「呂便」意思是「看，一個兒子」，此詞發音像希伯來文「他看見了我的痛苦」一詞的發音。">b</a></sup>。她說：「耶和華看見了我的痛苦，現在我丈夫一定會愛我。」</span>
<span className="v" id="v33" data-v="33" data-xref="創世記 34:25; 創世記 49:5–6; 創世記 34:30"> 她又懷孕生了一個兒子，就說：「耶和華聽見我失寵，所以又給我這個兒子。」於是，她給孩子取名叫西緬<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="「西緬」意思是「聽見」。">c</a></sup>。</span>
<span className="v" id="v34" data-v="34" data-xref="出埃及記 32:26–29; 創世記 49:5–7; 創世記 46:11"> 她又再度懷孕，生了一個兒子，就說：「這次我丈夫一定會依戀我，因為我給他生了三個兒子。」於是，他給孩子取名叫利未<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="「利未」意思是「聯合」。">d</a></sup>。</span>
<span className="v" id="v35" data-v="35" data-xref="馬太福音 1:2; 歷代志上 5:2; 創世記 49:8–12"> 後來，利亞再次懷孕，生了一個兒子，她說：「這次我要讚美耶和華！」於是，她給孩子取名叫猶大<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="「猶大」意思是「讚美」。">e</a></sup>。之後，利亞停止了生育。</span>
</div>
</div>

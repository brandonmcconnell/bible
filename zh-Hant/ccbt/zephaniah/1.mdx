## 耶和華審判的日子

<div className="bt">
<div className="bp poetry">
<span className="v" id="v2" data-v="2" data-xref="彌迦書 7:13; 列王紀下 22:16–17; 以西結書 33:27–29"> <span className="pl pl-1">耶和華說：</span><br /><span className="pl pl-1">「我必毀滅地上的一切。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="何西阿書 4:3; 以西結書 7:19; 耶利米書 12:4"> <span className="pl pl-1">我必毀滅人類、獸類、</span><br /><span className="pl pl-1">天上的鳥和海裡的魚。</span><br /><span className="pl pl-1">我必使惡人倒斃，</span><br /><span className="pl pl-1">我必剷除地上的人類。</span><br /><span className="pl pl-1">這是耶和華說的。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v4" data-v="4" data-xref="何西阿書 10:5; 彌迦書 5:13; 列王紀下 23:4–5"> <span className="pl pl-1">「我必伸手攻擊猶大，</span><br /><span className="pl pl-1">攻擊耶路撒冷的所有居民，</span><br /><span className="pl pl-1">清除巴力的殘跡及拜偶像之祭司的名號。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="耶利米書 19:13; 列王紀上 11:33; 列王紀下 17:33"> <span className="pl pl-1">我必剷除那些在屋頂祭拜天上萬象的人，</span><br /><span className="pl pl-1">剷除敬拜耶和華並憑祂起誓又憑米勒公起誓的人，</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="以賽亞書 1:4; 耶利米書 2:13; 耶利米書 15:6"> <span className="pl pl-1">剷除離棄耶和華、不尋求祂、不求問祂的人。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="哈巴谷書 2:20; 撒迦利亞書 2:13; 西番雅書 1:14"> <span className="pl pl-1">要在主耶和華面前肅靜，</span><br /><span className="pl pl-1">因為耶和華的日子近了。</span><br /><span className="pl pl-1">耶和華已準備好祭物，</span><br /><span className="pl pl-1">潔淨了祂邀請的人。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="以賽亞書 24:21; 以賽亞書 3:18–24; 耶利米書 22:24–30"> <span className="pl pl-1">耶和華說：「在給耶和華獻祭之日，</span><br /><span className="pl pl-1">我必懲罰首領和王子，</span><br /><span className="pl pl-1">以及所有穿外族服裝的人。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳記上 5:5; 阿摩司書 3:10; 撒母耳記上 2:15–16"> <span className="pl pl-1">到那日，我必懲罰所有跳過門檻</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「跳過門檻……的人」指祭拜偶像的人，參見撒母耳記上5·5。">a</a></sup><br /><span className="pl pl-1">、</span><br /><span className="pl pl-1">使主人的家充滿暴力和欺詐的人。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="歷代志下 33:14; 阿摩司書 8:3; 列王紀下 22:14"> <span className="pl pl-1">到那日，魚門必傳出哭喊聲，</span><br /><span className="pl pl-1">新區必響起哀號聲，</span><br /><span className="pl pl-1">山陵必發出崩裂的巨響。</span><br /><span className="pl pl-1">這是耶和華說的。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="雅各書 5:1; 耶利米書 25:34; 何西阿書 12:7–8"> <span className="pl pl-1">市場區的居民啊，哀哭吧！</span><br /><span className="pl pl-1">因為所有的商人必滅亡，</span><br /><span className="pl pl-1">所有做買賣的必被剷除。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="阿摩司書 6:1; 耶利米書 48:11; 以西結書 8:12"> <span className="pl pl-1">那時，我必提著燈巡察耶路撒冷，</span><br /><span className="pl pl-1">懲罰那些安於罪中的人。</span><br /><span className="pl pl-1">他們心想，『耶和華不賜福也不降禍。』</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="阿摩司書 5:11; 彌迦書 6:15; 申命記 28:30"> <span className="pl pl-1">他們的財物必遭搶掠，</span><br /><span className="pl pl-1">家園必淪為廢墟。</span><br /><span className="pl pl-1">他們建造房屋，卻不能住在裡面；</span><br /><span className="pl pl-1">栽種葡萄園，卻喝不到葡萄酒。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="瑪拉基書 4:5; 以西結書 30:3; 西番雅書 1:7"> <span className="pl pl-1">「耶和華的大日子近了，</span><br /><span className="pl pl-1">近了，很快就到了。</span><br /><span className="pl pl-1">那將是痛苦的日子，</span><br /><span className="pl pl-1">勇士也必淒聲哀號。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="約珥書 2:2; 以賽亞書 22:5; 啟示錄 6:17"> <span className="pl pl-1">那是降烈怒的日子，</span><br /><span className="pl pl-1">是困苦艱難的日子，</span><br /><span className="pl pl-1">是摧殘毀壞的日子，</span><br /><span className="pl pl-1">是黑暗幽冥的日子，</span><br /><span className="pl pl-1">是陰霾密佈的日子，</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="何西阿書 8:1; 阿摩司書 3:6; 以賽亞書 32:14"> <span className="pl pl-1">是吹號吶喊、</span><br /><span className="pl pl-1">攻打堅城高壘的日子。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v17" data-v="17" data-xref="啟示錄 3:17; 詩篇 83:10; 耶利米書 2:17"> <span className="pl pl-1">「我要使災難臨到人類，</span><br /><span className="pl pl-1">以致他們行路像瞎眼的，</span><br /><span className="pl pl-1">因為他們得罪了耶和華。</span><br /><span className="pl pl-1">他們的血必如灰塵般被倒出，</span><br /><span className="pl pl-1">他們的屍體必如糞便般被丟棄。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="西番雅書 3:8; 以西結書 7:19; 箴言 11:4"> <span className="pl pl-1">在耶和華發怒的日子，</span><br /><span className="pl pl-1">他們的金銀救不了他們。</span><br /><span className="pl pl-1">祂的怒火必吞噬大地，</span><br /><span className="pl pl-1">祂必驟然毀滅一切世人。」</span></span>
</div>

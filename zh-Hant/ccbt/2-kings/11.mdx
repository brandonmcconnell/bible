## 耶何耶大立約阿施為王

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="耶利米書 41:1; 列王紀下 25:25; 歷代志下 22:10–12"> 亞哈謝的母親亞她利雅見兒子死了，便動手除掉整個王室。</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米書 33:26; 耶利米書 35:2; 以賽亞書 7:6–7"> 但約蘭王的女兒、亞哈謝的妹妹約示巴把亞哈謝的兒子約阿施從將要被殺的王子中偷出來，把他和他的乳母藏在一間臥室裡，才躲過亞她利雅的殺戮。</span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 12:8; 歷代志下 22:12; 瑪拉基書 3:15"> 約阿施和他的乳母在耶和華的殿裡藏了六年，那時亞她利雅當政。</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀下 11:19; 列王紀下 11:9; 列王紀下 11:17"> 第七年，耶何耶大派人召迦利人<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「迦利人」指雇來保護王的外族衛兵。">a</a></sup>和衛兵的百夫長們到耶和華的殿裡，與他們立約，讓他們在耶和華的殿裡起誓，然後把約阿施王子帶到他們面前。</span>
<span className="v" id="v5" data-v="5" data-xref="歷代志上 9:25; 以西結書 44:2–3; 歷代志上 23:32"> 耶何耶大吩咐他們說：「你們在安息日值班的，三分之一的人要守衛王宮，</span>
<span className="v" id="v6" data-v="6" data-xref="歷代志下 23:4–5; 歷代志上 26:13–19"> 三分之一的人要守衛蘇珥門，三分之一的人要守住衛兵院後門。你們要輪流守衛。</span>
<span className="v" id="v7" data-v="7" data-xref="歷代志下 23:6; 列王紀下 11:5"> 安息日不值班的兩隊要在耶和華的殿裡保護王，</span>
<span className="v" id="v8" data-v="8" data-xref="民數記 27:17; 歷代志下 23:7; 列王紀上 2:28–31"> 各人要手持兵器護衛在王周圍。凡擅自闖入者，一律處死。無論王去哪裡，你們都要緊隨左右。」</span>
<span className="v" id="v9" data-v="9" data-xref="歷代志下 23:8; 列王紀下 11:4; 歷代志上 26:26"> 眾百夫長遵令而行，各自帶著在安息日值班和休班的屬下來見耶何耶大。</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳記下 8:7; 歷代志上 18:7; 歷代志下 5:1"> 耶何耶大祭司把耶和華殿中大衛王的矛槍和盾牌交給百夫長。</span>
<span className="v" id="v11" data-v="11" data-xref="列王紀下 11:8; 以西結書 8:16; 列王紀下 11:10"> 衛兵都手持兵器，從殿右到殿左，在祭壇和殿周圍護衛王。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及記 25:16; 撒母耳記上 10:24; 列王紀上 1:39"> 耶何耶大領王子出來，給他戴上王冠，把約書交給他，膏立他為王。眾人都鼓掌高呼：「願王萬歲！」</span>
<span className="v" id="v13" data-v="13" data-xref="歷代志下 23:12–15"> 亞她利雅聽見衛兵和眾人的歡呼聲，便走進耶和華的殿，眾人都聚集在那裡。</span>
<span className="v" id="v14" data-v="14" data-xref="歷代志下 34:31; 列王紀下 23:3; 列王紀下 9:23"> 她看見王照例站在柱旁，百夫長和吹號的人侍立在王左右，眾人都歡呼吹號，便撕裂衣服喊道：「反了！反了！」</span>
<span className="v" id="v15" data-v="15" data-xref="以西結書 9:7; 歷代志下 23:14; 歷代志下 23:9"> 耶何耶大祭司認為不可在耶和華的殿裡處死亞她利雅，便命令帶兵的百夫長：「把她帶出去並用刀殺死所有跟隨她的人。」</span>
<span className="v" id="v16" data-v="16" data-xref="創世記 9:6; 歷代志下 23:15; 馬太福音 7:2"> 他們抓住她，把她帶到馬匹進出王宮的入口，在那裡殺了她。</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳記下 5:3; 歷代志下 15:12–14; 歷代志下 34:31"> 耶何耶大讓王和民眾與耶和華立約，做耶和華的子民，也讓王與民眾立約。</span>
<span className="v" id="v18" data-v="18" data-xref="申命記 12:3; 列王紀下 10:26; 列王紀上 18:40"> 於是，民眾出去拆毀了巴力廟，砸碎祭壇和偶像，在壇前殺了巴力的祭司瑪坦。耶何耶大派守衛保護耶和華的殿，</span>
<span className="v" id="v19" data-v="19" data-xref="耶利米書 17:25; 耶利米書 22:4; 歷代志下 23:19"> 然後率領百夫長、迦利人、衛兵和全體民眾，護送王從耶和華的殿下來，經過衛兵院的門進入王宮。這樣，約阿施坐上了王位。</span>
<span className="v" id="v20" data-v="20" data-xref="箴言 11:10; 箴言 29:2; 列王紀下 11:14"> 民眾都歡喜快樂，城裡安定，因為亞她利雅已在王宮那裡被處死。</span>
<span className="v" id="v21" data-v="21" data-xref="歷代志下 24:1–14; 列王紀下 22:1; 列王紀下 11:4"> 約阿施七歲登基。</span>
</div>

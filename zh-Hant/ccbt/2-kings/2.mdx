## 以利亞被接到天上

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 5:24; 希伯來書 11:5; 列王紀上 19:16–21"> 耶和華用旋風接以利亞升天之前，以利亞和以利沙正離開吉甲。</span>
<span className="v" id="v2" data-v="2" data-xref="列王紀下 2:6; 路得記 1:15–18; 列王紀下 4:30"> 以利亞對以利沙說：「你留在這裡吧，耶和華差遣我去伯特利。」以利沙說：「我憑永活的耶和華和你的性命起誓，我決不離開你。」於是二人前往伯特利。</span>
<span className="v" id="v3" data-v="3" data-xref="列王紀下 4:1; 列王紀下 4:38; 列王紀下 9:1"> 伯特利的眾先知出來見以利沙，問他：「你知道耶和華今天要接走你師傅嗎？」他說：「我知道，請不要作聲。」</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀下 2:2; 約書亞記 6:26; 列王紀上 16:34"> 以利亞對以利沙說：「你留在這裡吧，耶和華差遣我去耶利哥。」以利沙說：「我憑永活的耶和華和你的性命起誓，我決不離開你。」於是二人前往耶利哥。</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀下 2:3; 約書亞記 1:1–2; 使徒行傳 1:11"> 耶利哥的眾先知來見以利沙，問他：「你知道耶和華今天要接走你師傅嗎？」他說：「我知道，請不要作聲。」</span>
<span className="v" id="v6" data-v="6" data-xref="列王紀下 2:2; 約書亞記 3:15"> 以利亞對以利沙說：「你留在這裡吧，耶和華差遣我去約旦河。」以利沙說：「我憑永活的耶和華和你的性命起誓，我決不離開你。」於是二人繼續前行。</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀上 18:13; 列王紀下 2:17; 列王紀上 18:4"> 先知中有五十人跟他們來到約旦河，遠遠地站著，他們二人則站在河邊。</span>
<span className="v" id="v8" data-v="8" data-xref="列王紀上 19:19; 出埃及記 14:21–22; 約書亞記 3:14–17"> 以利亞脫下外衣捲起來，用它擊打河水，水立即左右分開，二人腳踏乾地而過。</span>
<span className="v" id="v9" data-v="9" data-xref="民數記 11:17; 申命記 21:17; 約翰福音 16:7"> 到對岸後，以利亞對以利沙說：「在我被接走之前，你要我為你做什麼？」以利沙說：「請將你的靈加倍給我。」</span>
<span className="v" id="v10" data-v="10" data-xref="馬可福音 11:22–24; 列王紀下 2:12; 約翰福音 16:24"> 以利亞說：「這是個很難的要求。不過，我被接走的時候，你若看得見我，就可以得到，否則就得不到。」</span>
<span className="v" id="v11" data-v="11" data-xref="列王紀下 6:17; 詩篇 104:3–4; 希伯來書 1:14"> 他們邊走邊談，忽然有火馬拉的火車把他們二人隔開，以利亞乘著旋風升上了天。</span>
<span className="v" id="v12" data-v="12" data-xref="列王紀下 13:14; 以賽亞書 37:21; 馬可福音 16:19"> 以利沙見此情景，便喊道：「我父啊！我父啊！以色列的戰車和騎兵啊！」以利沙見以利亞消失在天空中，就悲傷地把自己的衣服撕成兩半。</span>
<span className="v" id="v13" data-v="13" data-xref="列王紀上 19:19; 列王紀下 2:8; 列王紀上 9:26"> 他拿起以利亞身上掉下來的外衣，回到約旦河邊，</span>
<span className="v" id="v14" data-v="14" data-xref="約翰福音 14:12; 詩篇 42:10; 詩篇 115:2"> 用它擊打河水，說：「以利亞的上帝耶和華在哪裡呢？」河水就左右分開，以利沙便過了河。</span>
<span className="v" id="v15" data-v="15" data-xref="彼得前書 4:14; 使徒行傳 1:8; 約書亞記 3:7"> 耶利哥的先知們從遠處看見他，就說：「以利亞的靈降在以利沙身上了。」他們就上前迎接，俯伏在他面前，</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀上 18:12; 使徒行傳 8:39; 哥林多後書 12:2–3"> 說：「僕人們這裡有五十個壯士，請讓他們去尋找你師傅吧，也許耶和華的靈把他提走，放在某座山上或某個山谷裡了。」以利沙說：「你們不要派人去找了。」</span>
<span className="v" id="v17" data-v="17" data-xref="列王紀下 8:11; 希伯來書 11:5; 羅馬書 10:2"> 他們再三懇求，以利沙難以推辭，就讓他們派人去了。他們派去了五十人，找了三天也沒有找到。</span>
<span className="v" id="v18" data-v="18"> 他們回來的時候，以利沙仍在耶利哥。他對他們說：「我不是早就告訴你們不要去嗎？」</span>
</div>
</div>

## 以利沙行神蹟

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="出埃及記 23:26; 申命記 28:2–4; 申命記 28:11"> 耶利哥城的人對以利沙說：「我主，你看這城地勢很好，只是水不好，地裡長不出莊稼。」</span>
<span className="v" id="v20" data-v="20" data-xref="士師記 9:45; 西番雅書 2:9; 以西結書 47:11"> 以利沙說：「拿一個新碗裝些鹽給我。」他們就去照辦。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及記 15:25–26; 列王紀下 4:41; 利未記 2:13"> 以利沙走到水源那裡，把鹽倒在水中說：「耶和華說，『我潔淨了這水，從此它不會再使人死亡，也不會再使土地貧瘠。』」</span>
<span className="v" id="v22" data-v="22"> 果然如以利沙所說，那裡的水變好了，直到如今。</span>
<span className="v" id="v23" data-v="23" data-xref="歷代志下 36:16; 約伯記 19:18; 約伯記 30:1"> 以利沙從那裡去伯特利，正在趕路的時候，從城裡出來一群少年譏笑他說：「禿頭，上去吧！禿頭，上去吧！」</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行傳 13:9–11; 使徒行傳 5:5; 何西阿書 13:8"> 以利沙轉身看著他們，奉耶和華的名咒詛他們。林中隨即走出來兩隻母熊，咬死了其中的四十二個少年。</span>
<span className="v" id="v25" data-v="25" data-xref="列王紀下 4:25; 列王紀上 18:19–20; 列王紀上 18:42"> 以利沙從伯特利上了迦密山，又從迦密山回到撒瑪利亞。</span>
</div>

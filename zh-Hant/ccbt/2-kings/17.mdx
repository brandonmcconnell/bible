## 何細亞做以色列王

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀下 15:30"> 猶大王亞哈斯執政第十二年，以拉的兒子何細亞在撒瑪利亞登基做以色列王，執政九年。</span>
<span className="v" id="v2" data-v="2" data-xref="列王紀下 3:2; 列王紀下 13:11; 歷代志下 30:5–11"> 他做耶和華視為惡的事，不過沒有他之前的以色列諸王那麼敗壞。</span>
<span className="v" id="v3" data-v="3" data-xref="何西阿書 10:14; 列王紀下 15:19; 列王紀下 19:36–37"> 亞述王撒縵以色攻打以色列，何細亞納貢稱臣。</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀下 18:21; 列王紀下 24:20; 以西結書 17:13–19"> 然而，何細亞差遣使者向埃及王梭求援，不再像往年那樣向亞述王進貢。亞述王發現後，把他抓起來囚在獄中。</span>
<span className="v" id="v5" data-v="5" data-xref="何西阿書 13:16; 列王紀下 25:1–3; 列王紀下 18:9"> 亞述王攻打以色列全境，並圍困撒瑪利亞三年。</span>
<span className="v" id="v6" data-v="6" data-xref="歷代志上 5:26; 何西阿書 13:16; 申命記 28:64"> 何細亞執政第九年，撒瑪利亞淪陷。亞述王把以色列人擄到亞述，安置在哈臘、歌散的哈博河一帶以及瑪代人的各城。</span>
</div>
</div>

## 以色列人的罪惡史

<div className="bt">
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="約書亞記 23:16; 詩篇 106:35–41; 尼希米記 9:26"> 以色列人之所以有如此下場，是因為他們的上帝耶和華帶他們出埃及，從埃及王法老手中救出他們，他們卻犯罪得罪祂。他們祭拜其他神明，</span>
<span className="v" id="v8" data-v="8" data-xref="利未記 18:3; 列王紀下 16:3; 申命記 18:9"> 效法耶和華在他們面前趕走的外族人的風俗和以色列諸王奉行的習俗。</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀下 18:8; 約伯記 31:27; 申命記 13:6"> 以色列人暗中做不義之事，冒犯他們的上帝耶和華。從瞭望塔到堅城，他們在各地建邱壇，</span>
<span className="v" id="v10" data-v="10" data-xref="列王紀上 14:23; 彌迦書 5:14; 出埃及記 34:13"> 在各高崗上、綠樹下立神柱和亞舍拉神像，</span>
<span className="v" id="v11" data-v="11" data-xref="歷代志下 28:25; 列王紀下 21:6; 耶利米書 44:17"> 在各邱壇燒香，如同耶和華在他們面前趕走的外族人一樣。他們邪惡的行為激怒了耶和華。</span>
<span className="v" id="v12" data-v="12" data-xref="申命記 12:4; 出埃及記 20:3–5; 申命記 4:23–25"> 儘管耶和華警告他們不可祭拜偶像，他們仍然執迷不悟。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="參出埃及記20·4‑5。">a</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="耶利米書 35:15; 撒母耳記上 9:9; 耶利米書 18:11"> 耶和華藉著祂的眾先知和先見警告以色列人和猶大人說：「你們要離開惡道，按照我吩咐你們祖先的一切律法遵守我的誡命和律例，這律法是藉著我的僕人——眾先知傳給你們的。」</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 31:27; 使徒行傳 7:51; 詩篇 106:24"> 但他們充耳不聞，像他們祖先一樣頑固不化，不信靠他們的上帝耶和華，</span>
<span className="v" id="v15" data-v="15" data-xref="申命記 12:30–31; 申命記 32:21; 羅馬書 1:21–23"> 拒絕遵守祂的律例和祂與他們祖先所立的約，無視祂的警告。他們隨從虛無的偶像，自己也變得虛無。他們違背耶和華的命令，效法周圍的外族人。</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀上 14:23; 列王紀上 16:31; 列王紀上 14:15"> 他們棄絕他們的上帝耶和華的誡命，鑄造了兩個金牛犢，還造了亞舍拉神像。他們祭拜巴力和天上的萬象，</span>
<span className="v" id="v17" data-v="17" data-xref="列王紀下 21:6; 列王紀下 16:3; 申命記 18:10–12"> 把自己的兒女燒死獻作祭物。他們占卜，行邪術，出賣自己去做耶和華視為惡的事，惹祂發怒。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="列王紀上 12:20; 列王紀上 11:13; 何西阿書 11:12"> 因此，耶和華非常憤怒，從祂面前趕走以色列人，只留下猶大一個支派。</span>
<span className="v" id="v19" data-v="19" data-xref="列王紀下 16:3; 列王紀上 14:22–23; 以西結書 16:51–52"> 但猶大人也不遵守他們的上帝耶和華的誡命，反而效法以色列人的習俗。</span>
<span className="v" id="v20" data-v="20" data-xref="列王紀下 15:29; 耶利米書 6:30; 列王紀下 13:3"> 於是，耶和華棄絕了以色列全族，使他們飽嘗痛苦，任人宰割，直至把他們從自己眼前趕走。</span>
<span className="v" id="v21" data-v="21" data-xref="列王紀上 11:11; 列王紀上 11:31; 列王紀上 14:16"> 祂使以色列從大衛家分裂出來，以色列人便擁立尼八的兒子耶羅波安為王。耶羅波安誘使以色列人遠離耶和華，使他們犯了大罪。</span>
<span className="v" id="v22" data-v="22" data-xref="列王紀下 3:3; 列王紀下 13:6; 列王紀下 13:11"> 以色列人沉溺於耶羅波安所犯的一切罪中，始終不肯回頭，</span>
<span className="v" id="v23" data-v="23" data-xref="列王紀下 17:6; 列王紀下 17:13; 列王紀下 17:20"> 直到耶和華把他們從自己眼前趕走，正如祂藉著自己的僕人——眾先知對他們的警告。這樣，以色列人被擄到亞述，至今仍住在那裡。</span>
</div>
</div>

## 外族人移居撒瑪利亞

<div className="bt">
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="列王紀下 18:34; 列王紀下 17:30–31; 馬太福音 10:5"> 亞述王把巴比倫、古他、亞瓦、哈馬、西法瓦音等地的一些居民遷移到撒瑪利亞各城，代替以色列人佔據各城，住在其中。</span>
<span className="v" id="v25" data-v="25" data-xref="列王紀下 17:32; 列王紀下 17:34; 列王紀下 17:41"> 剛遷居到那裡的時候，他們不敬畏耶和華，所以耶和華差遣獅子闖入他們當中，咬死了一些人。</span>
<span className="v" id="v26" data-v="26" data-xref="列王紀下 17:27; 撒母耳記上 8:9; 阿摩司書 8:14"> 有人稟告亞述王說：「你遷移到撒瑪利亞各城的那些人不知道當地神明的規矩，所以神明就差遣獅子闖入他們當中，咬死了一些人。」</span>
<span className="v" id="v27" data-v="27" data-xref="士師記 17:13; 列王紀上 12:31; 列王紀上 13:2"> 亞述王便下令：「派一位被擄來的祭司回去，讓他住在那裡，把當地神明的規矩教導給他們。」</span>
<span className="v" id="v28" data-v="28" data-xref="列王紀上 12:29–32; 以賽亞書 29:13; 馬太福音 15:14"> 於是，有一位從撒瑪利亞被擄走的祭司回去住在伯特利，教導他們怎樣敬拜耶和華。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="列王紀上 12:31; 彌迦書 4:5; 列王紀上 13:32"> 可是，這些從各地遷來的民族都在所住的各城為自己製造神像，供奉在撒瑪利亞人在高崗上建造的神廟中。</span>
<span className="v" id="v30" data-v="30" data-xref="列王紀下 17:24"> 巴比倫人造疏割·比訥神像，古他人造匿甲神像，哈馬人造亞示瑪神像，</span>
<span className="v" id="v31" data-v="31" data-xref="列王紀下 17:24; 列王紀下 17:17; 列王紀下 19:37"> 亞瓦人造匿哈和他珥他神像，西法瓦音人焚燒兒女向他們的神明亞得米勒和亞拿米勒獻祭。</span>
<span className="v" id="v32" data-v="32" data-xref="列王紀上 12:31; 列王紀下 17:29; 列王紀上 13:33"> 他們也敬畏耶和華，卻委任各種人做祭司，在高崗上的神廟為他們獻祭。</span>
<span className="v" id="v33" data-v="33" data-xref="列王紀下 17:41; 路加福音 16:13; 馬太福音 6:24"> 他們就這樣既敬畏耶和華，又各按各的風俗供奉自己的神明。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="創世記 32:28; 創世記 35:10; 列王紀下 17:27–28"> 直到現在，他們依然持守舊俗，不敬畏耶和華，也不遵行耶和華賜給雅各子孫的律例、典章、法度和誡命。耶和華曾給雅各取名叫以色列，</span>
<span className="v" id="v35" data-v="35" data-xref="士師記 6:10; 約書亞記 23:16; 約書亞記 23:7"> 與他的子孫立約，吩咐他們：「不可敬奉其他神明，不可跪拜和供奉它們，也不可向他們獻祭。</span>
<span className="v" id="v36" data-v="36" data-xref="出埃及記 6:6; 申命記 6:13; 利未記 19:32"> 耶和華伸出大能的臂膀把你們領出埃及，你們要敬畏祂，要向祂跪拜、獻祭。</span>
<span className="v" id="v37" data-v="37" data-xref="利未記 19:37; 申命記 5:31–2; 申命記 4:44–45"> 你們要永遠謹遵祂所定的律例、典章、法度和誡命，不可敬奉其他神明。</span>
<span className="v" id="v38" data-v="38" data-xref="申命記 4:23; 申命記 6:12; 申命記 8:14–18"> 不可忘記我與你們立的約，不可敬奉其他神明。</span>
<span className="v" id="v39" data-v="39" data-xref="路加福音 1:74–75; 撒母耳記上 12:24; 馬太福音 10:28"> 我是你們的上帝耶和華，你們要敬畏我，我必從一切仇敵手中救你們。」</span>
<span className="v" id="v40" data-v="40" data-xref="申命記 4:28; 列王紀下 17:8; 耶利米書 13:23"> 但是他們沒有聽從，依然持守舊俗。</span>
<span className="v" id="v41" data-v="41" data-xref="馬太福音 6:24; 西番雅書 1:5; 列王紀上 18:21"> 那些移民到撒瑪利亞各城的外族人既敬畏耶和華，又供奉自己的偶像。直到今日，他們的子孫仍是這樣。</span>
</div>
</div>

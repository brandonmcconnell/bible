## 以利沙幫助窮寡婦

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="馬太福音 18:25; 列王紀下 2:3; 尼希米記 5:2–5"> 有一個先知的妻子哀求以利沙說：「你僕人——我丈夫怎樣敬畏耶和華，你是知道的。如今他去世了，債主來要把我的兩個孩子帶去做奴隸。」</span>
<span className="v" id="v2" data-v="2" data-xref="列王紀上 17:12; 雅各書 2:5; 列王紀下 6:26–27"> 以利沙問她：「我該怎樣幫你呢？告訴我，你家裡有什麼？」婦人答道：「婢女家什麼也沒有，只有一瓶油。」</span>
<span className="v" id="v3" data-v="3" data-xref="約翰福音 2:7; 詩篇 81:10; 約翰福音 16:24"> 以利沙說：「你去向所有鄰居借空器皿，要儘量多借一些。</span>
<span className="v" id="v4" data-v="4" data-xref="馬可福音 8:5–9; 馬太福音 6:6; 以弗所書 3:20"> 然後回家關上門，你和你兒子在屋裡把那瓶油倒在所有借來的器皿中，裝滿的放在一邊。」</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀下 5:11; 希伯來書 11:7–8; 列王紀上 17:15–16"> 於是，婦人辭別以利沙，回去後把自己和兒子關在屋裡，兒子遞給她器皿，她就倒油。</span>
<span className="v" id="v6" data-v="6" data-xref="馬太福音 14:20; 列王紀下 13:19; 路加福音 6:19"> 器皿都裝滿了，她對兒子說：「再拿個器皿給我。」兒子說：「已經沒有了。」這時，油止住了。</span>
<span className="v" id="v7" data-v="7" data-xref="帖撒羅尼迦後書 3:7–12; 列王紀上 12:22; 羅馬書 12:17"> 婦人將經過告訴上帝的僕人，上帝的僕人對她說：「你去把油賣了還債，你們母子可以用剩下的錢度日。」</span>
</div>
</div>

## 以利沙和書念婦人

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="約書亞記 19:18; 創世記 19:3; 列王紀下 4:11–12"> 一天，以利沙路過書念，那裡一位富有的婦人挽留他吃飯。此後以利沙每次路過那裡，總到她家裡吃飯。</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀上 17:24; 箴言 31:10–11; 列王紀下 4:7"> 那婦人對丈夫說：「我看常路過我們這裡的這位是上帝聖潔的僕人。</span>
<span className="v" id="v10" data-v="10" data-xref="羅馬書 12:13; 馬太福音 10:41–42; 馬太福音 25:40"> 不如我們在房頂上給他蓋一間小屋，裡面放床、桌子、椅子和燈。這樣，他來我們家時，可以在那裡休息。」</span>
<span className="v" id="v11" data-v="11"> 一天，以利沙又到了那裡，便在那間小屋裡休息。</span>
<span className="v" id="v12" data-v="12" data-xref="列王紀下 8:4–5; 列王紀下 3:11; 列王紀下 4:29–31"> 以利沙吩咐僕人基哈西去請書念的婦人。他就請來婦人，婦人站在以利沙面前。</span>
<span className="v" id="v13" data-v="13" data-xref="提摩太後書 1:16–18; 腓立比書 4:18–19; 希伯來書 6:10"> 以利沙吩咐基哈西說：「你對她說，『你為我們費了不少心，我們該為你做些什麼呢？要不要我們在王或元帥面前為你說些好話呢？』」她答道：「我在本族中安居無事。」</span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 1:7; 創世記 15:2–3; 撒母耳記上 1:8"> 以利沙問基哈西：「我們能為她做什麼呢？」基哈西說：「她沒有兒子，丈夫也已經老了。」</span>
<span className="v" id="v15" data-v="15"> 以利沙說：「你再去請她來。」她來了，站在門口。</span>
<span className="v" id="v16" data-v="16" data-xref="創世記 18:10; 路加福音 1:13; 列王紀下 4:28"> 以利沙對她說：「明年這時候，你必抱一個兒子。」她說：「上帝的僕人，我主啊，不要騙婢女。」</span>
<span className="v" id="v17" data-v="17" data-xref="詩篇 113:9; 路加福音 1:36; 創世記 21:1"> 那婦人果然懷了孕，在第二年的那時候生了一個兒子，應驗了以利沙對她說的話。</span>
<span className="v" id="v18" data-v="18" data-xref="路得記 2:4"> 孩子漸漸長大。一天，他到收割的人那裡找他父親。</span>
<span className="v" id="v19" data-v="19" data-xref="約伯記 14:1–2; 耶利米書 4:19"> 突然，他對他父親喊道：「我的頭啊！我的頭啊！」他父親見狀立刻吩咐僕人抱他到他母親那裡。</span>
<span className="v" id="v20" data-v="20" data-xref="路加福音 7:12; 約翰福音 11:3; 約翰福音 11:14"> 僕人把他抱起來，送到他母親那裡。孩子坐在母親的膝上，到中午就死了。</span>
<span className="v" id="v21" data-v="21" data-xref="列王紀下 4:32; 列王紀下 4:10; 列王紀下 4:7"> 他母親上樓把他放在上帝僕人的床上，關上門出來。</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行傳 9:38; 列王紀下 4:26; 約翰福音 11:3"> 她叫來丈夫，對他說：「請你預備一個僕人和一頭驢，我好趕快去見上帝的僕人，然後返回來。」</span>
<span className="v" id="v23" data-v="23" data-xref="民數記 10:10; 民數記 28:11; 歷代志上 23:31"> 她丈夫說：「今天不是朔日<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「朔日」即每月初一。">a</a></sup>，也不是安息日，你為什麼要去見他？」婦人說：「放心吧。」</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及記 4:20; 列王紀上 13:13; 撒母耳記上 25:19–20"> 她騎上驢，對僕人說：「快走吧！我不吩咐你，就不要慢下來。」</span>
<span className="v" id="v25" data-v="25" data-xref="列王紀下 2:25; 以賽亞書 35:2; 列王紀上 18:19"> 她就去迦密山見上帝的僕人。上帝的僕人遠遠望見她，就對僕人基哈西說：「你看，書念的婦人來了！</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行傳 15:36; 列王紀下 4:23; 撒母耳記上 17:18"> 你跑去迎接她，問問她和她的丈夫與孩子都好嗎。」 婦人對以利沙的僕人說：「一切都好。」</span>
<span className="v" id="v27" data-v="27" data-xref="撒母耳記下 7:3; 創世記 18:17; 阿摩司書 3:7"> 可是，她上山見到上帝的僕人後，就抱住他的腳。基哈西想要推開她，但上帝的僕人說：「由她吧！因為她心裡非常痛苦。耶和華沒有告訴我發生了什麼事。」</span>
<span className="v" id="v28" data-v="28" data-xref="創世記 30:1; 列王紀下 4:16"> 婦人說：「我何嘗向我主求過兒子呢？我不是對你說不要騙我嗎？」</span>
<span className="v" id="v29" data-v="29" data-xref="列王紀下 2:14; 列王紀上 18:46; 出埃及記 14:16"> 以利沙吩咐基哈西：「你要束上腰帶，拿著我的杖去她家。路上不論遇見誰，都不要問候他。有人問候你，也不要作答。去把我的杖放在孩子臉上。」</span>
<span className="v" id="v30" data-v="30" data-xref="路得記 1:16–18; 列王紀下 2:2; 出埃及記 33:12–16"> 孩子的母親說：「我憑永活的耶和華和你的性命起誓，你若不同去，我決不離開你。」於是，以利沙跟她同去。</span>
<span className="v" id="v31" data-v="31" data-xref="約翰福音 11:11; 馬可福音 5:39; 馬可福音 9:19–29"> 基哈西先趕到，把杖放在孩子臉上，可是孩子一點動靜也沒有。他就回去找以利沙，路上碰見他，便說：「孩子還沒醒過來。」</span>
<span className="v" id="v32" data-v="32" data-xref="路加福音 8:52–53; 約翰福音 11:17; 列王紀上 17:17"> 以利沙進了屋子，看見孩子死了，躺在床上，</span>
<span className="v" id="v33" data-v="33" data-xref="馬太福音 6:6; 列王紀下 4:4; 使徒行傳 9:40"> 就關上門，向耶和華祈禱。</span>
<span className="v" id="v34" data-v="34" data-xref="列王紀上 17:21; 使徒行傳 20:10"> 禱告後，他上床伏在孩子身上，口對口，眼對眼，手對手，孩子的身體漸漸變暖了。</span>
<span className="v" id="v35" data-v="35" data-xref="列王紀下 8:5; 列王紀下 13:21; 列王紀上 17:22"> 然後，以利沙起來在房內來回走了一趟，又上床伏在孩子身上。孩子打了七個噴嚏，便睜開了眼睛。</span>
<span className="v" id="v36" data-v="36" data-xref="希伯來書 11:35; 列王紀上 17:23; 路加福音 7:15"> 以利沙叫基哈西請那婦人來。他便請來婦人，以利沙對婦人說：「把你兒子抱走吧。」</span>
<span className="v" id="v37" data-v="37" data-xref="希伯來書 11:35; 列王紀下 2:15; 列王紀上 17:24"> 婦人進來，在以利沙腳前下拜，然後抱起兒子出去了。</span>
</div>
</div>

## 用麵粉解毒

<div className="bt">
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="列王紀下 8:1; 列王紀下 2:3; 列王紀下 2:1"> 以利沙回到吉甲，那裡正遭遇饑荒。一群先知坐在他面前，他吩咐僕人把一口大鍋放在火上給他們煮湯。</span>
<span className="v" id="v39" data-v="39" data-xref="耶利米書 2:21; 以賽亞書 5:4; 馬太福音 15:13"> 有個先知到田間摘野菜，看見一棵野瓜藤，便摘了一兜野瓜回來，切碎了放進鍋裡，卻不知道那是什麼瓜。</span>
<span className="v" id="v40" data-v="40" data-xref="馬可福音 16:18; 出埃及記 15:23; 出埃及記 10:17"> 湯煮好後倒出來給眾人喝，他們剛喝了一點，就叫道：「上帝的僕人啊，鍋裡有劇毒！」他們都不敢喝了。</span>
<span className="v" id="v41" data-v="41" data-xref="列王紀下 2:21; 出埃及記 15:25; 哥林多前書 1:25"> 以利沙說：「拿點麵粉來。」他把麵粉撒在鍋裡，說：「倒出來給眾人喝吧。」於是，鍋裡沒有毒了。</span>
</div>
</div>

## 用二十個餅餵飽百人

<div className="bt">
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="撒母耳記上 9:7; 約翰福音 6:9; 馬太福音 14:16–21"> 從巴力·沙利沙來了一個人，他帶了二十個用初熟大麥做的餅和一些麥穗送給上帝的僕人。上帝的僕人說：「分給眾人吃吧。」</span>
<span className="v" id="v43" data-v="43" data-xref="路加福音 9:13; 馬太福音 14:20; 約翰福音 6:9"> 僕人說：「這怎麼夠一百人吃呢？」以利沙說：「你只管分給眾人吃。因為耶和華說，『眾人都能吃飽，並且還會剩下。』」</span>
<span className="v" id="v44" data-v="44"> 於是，僕人將食物擺在眾人面前，他們都吃飽了，果然還有剩餘，正如耶和華所言。</span>
</div>

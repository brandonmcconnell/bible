## 希西迦的病危與康復

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以賽亞書 38:1–22; 歷代志下 32:24–26; 腓立比書 2:27"> 那些日子，希西迦病危，亞摩斯的兒子以賽亞先知前來對他說：「耶和華說，『你要交待後事，因為你要死了，你必無法康復。』」</span>
<span className="v" id="v2" data-v="2" data-xref="詩篇 50:15; 馬太福音 6:6; 以賽亞書 38:2–3"> 希西迦把臉轉向牆，向耶和華禱告，說：</span>
<span className="v" id="v3" data-v="3" data-xref="尼希米記 13:14; 尼希米記 13:22; 尼希米記 5:19"> 「耶和華啊，求你顧念我怎樣全心、忠誠地事奉你，做你視為善的事。」希西迦痛哭起來。</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀下 22:14; 列王紀上 7:8"> 當時，以賽亞還沒有走出中院，耶和華對他說：</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 66:19–20; 以賽亞書 38:5; 撒母耳記上 9:16"> 「回去告訴我子民的首領希西迦，『你祖先大衛的上帝耶和華說，我垂聽了你的禱告，也看見了你的眼淚。我要醫治你，第三天你就可以上耶和華的殿。</span>
<span className="v" id="v6" data-v="6" data-xref="列王紀下 19:34; 使徒行傳 27:24; 以賽亞書 10:24"> 我要使你的壽命增加十五年，我要從亞述王手中拯救你和這城。我要為自己和我僕人大衛的緣故保護這城。』」</span>
<span className="v" id="v7" data-v="7" data-xref="以賽亞書 38:21; 列王紀下 2:20–22; 列王紀下 4:41"> 以賽亞說：「拿一塊無花果餅來。」他們就拿來貼在王的瘡上，他就痊癒了。</span>
<span className="v" id="v8" data-v="8" data-xref="士師記 6:17; 以賽亞書 7:11; 列王紀下 19:29"> 希西迦問以賽亞：「有什麼兆頭證明耶和華要醫治我，第三天我可以上耶和華的殿呢？」</span>
<span className="v" id="v9" data-v="9" data-xref="以賽亞書 38:7–8; 馬可福音 8:11–12; 馬太福音 16:1–4"> 以賽亞說：「耶和華要給你一個兆頭，證明祂言出必行。你要日影前進十度還是後退十度呢？」</span>
<span className="v" id="v10" data-v="10" data-xref="列王紀下 3:18; 列王紀下 2:10; 約翰福音 14:12"> 希西迦說：「日影前進十度容易，讓日影後退十度吧。」</span>
<span className="v" id="v11" data-v="11" data-xref="以賽亞書 38:8; 約書亞記 10:12–14; 歷代志下 32:24"> 以賽亞先知向耶和華祈求，耶和華就使亞哈斯日晷上的日影後退了十度。</span>
</div>
</div>

## 巴比倫的使者來訪

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="以賽亞書 39:1–8; 歷代志下 32:31; 以賽亞書 13:1"> 那時，巴拉但的兒子巴比倫王米羅達·巴拉但聽說希西迦病了，便派人送來書信和禮物。</span>
<span className="v" id="v13" data-v="13" data-xref="以賽亞書 39:2; 歷代志下 32:25–27; 列王紀上 10:15"> 希西迦接見使者，讓他們觀看國庫裡的金銀、香料、珍貴膏油、所有兵器和一切寶物。希西迦把宮中及國內的一切悉數給他們看。</span>
<span className="v" id="v14" data-v="14" data-xref="以賽亞書 13:5; 撒母耳記下 12:7–15; 列王紀下 5:25–26"> 以賽亞先知來見希西迦王，問他：「這些人說了些什麼？他們從哪裡來？」希西迦答道：「他們來自遙遠的巴比倫。」</span>
<span className="v" id="v15" data-v="15" data-xref="約伯記 31:33; 約書亞記 7:19; 列王紀下 20:13"> 以賽亞問：「他們在你宮裡看到了什麼？」希西迦答道：「他們看到了我宮中的一切。我把國庫裡的一切悉數給他們看了。」</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀上 22:19; 列王紀下 7:1; 以賽亞書 1:10"> 以賽亞對希西迦說：「你要聽耶和華的話，</span>
<span className="v" id="v17" data-v="17" data-xref="列王紀下 24:13; 歷代志下 36:10; 耶利米書 52:17–19"> 『看啊，時候快到了，你宮中的一切和你祖先積攢到現在的一切必被擄到巴比倫，一件不留。這是耶和華說的。</span>
<span className="v" id="v18" data-v="18" data-xref="歷代志下 33:11; 列王紀下 24:12; 但以理書 1:3"> 你自己親生的子孫中必有人被擄去，在巴比倫王的宮中做太監。』」</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳記上 3:18; 撒迦利亞書 8:19; 路加福音 2:10"> 希西迦對以賽亞說：「耶和華藉你說的話很好。」因為他想：「至少我有生之年將平安穩妥。」</span>
<span className="v" id="v20" data-v="20" data-xref="尼希米記 3:16; 歷代志下 32:32; 歷代志下 32:4"> 希西迦其他的事和功業，包括他建造水池和挖溝引水入城的事蹟，都記在《猶大列王史》上。</span>
<span className="v" id="v21" data-v="21" data-xref="歷代志下 32:33; 列王紀上 14:31; 歷代志下 26:23"> 希西迦與祖先同眠後，他兒子瑪拿西繼位。</span>
</div>
</div>

## 亞哈斯做猶大王

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以賽亞書 1:1; 以賽亞書 7:1; 列王紀下 15:38"> 利瑪利的兒子比加執政第十七年，猶大王約坦的兒子亞哈斯登基。</span>
<span className="v" id="v2" data-v="2" data-xref="歷代志下 28:1–4; 列王紀下 15:34; 列王紀上 11:4–8"> 他二十歲登基，在耶路撒冷執政十六年。他沒有效法他祖先大衛做耶和華視為正的事，</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 12:31; 利未記 18:21; 列王紀下 21:2"> 反而步以色列諸王的後塵，效法耶和華在以色列人面前趕走的外族人的可憎行徑，把自己的兒子焚燒獻作祭物。</span>
<span className="v" id="v4" data-v="4" data-xref="申命記 12:2; 列王紀上 14:23; 耶利米書 17:2"> 他還在邱壇、山岡和綠樹下獻祭燒香。</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀下 15:37; 以賽亞書 9:6–7; 以賽亞書 8:9–10"> 亞蘭王利汛和利瑪利的兒子以色列王比加前來攻打耶路撒冷，圍住亞哈斯，但屢攻不下。</span>
<span className="v" id="v6" data-v="6" data-xref="列王紀下 14:22; 申命記 2:8; 列王紀上 9:26"> 當時，亞蘭王利汛收復以拉他，趕走城內的猶大人。亞蘭<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「亞蘭」有古卷作「以東」。">a</a></sup>人至今居住在那裡。</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀下 15:29; 耶利米哀歌 4:17; 何西阿書 14:3"> 亞哈斯差遣使者去見亞述王提革拉·毗列色，對他說：「我是你的僕人、你的兒子，現在亞蘭王和以色列王攻打我，求你從他們手中拯救我。」</span>
<span className="v" id="v8" data-v="8" data-xref="列王紀下 12:17–18; 歷代志下 28:20–21; 歷代志下 16:2"> 亞哈斯把耶和華殿裡和王宮庫房裡所有的金銀送給亞述王。</span>
<span className="v" id="v9" data-v="9" data-xref="阿摩司書 9:7; 以賽亞書 22:6; 阿摩司書 1:3–5"> 亞述王答應了他，起兵攻陷大馬士革，殺了利汛，把城中的居民擄到吉珥。</span>
<span className="v" id="v10" data-v="10" data-xref="羅馬書 12:2; 以西結書 23:16–17; 以賽亞書 8:2"> 亞哈斯王在大馬士革見亞述王提革拉·毗列色的時候，看到一座壇，便派人將壇的模型和詳細的製造方法送到烏利亞祭司那裡。</span>
<span className="v" id="v11" data-v="11" data-xref="何西阿書 4:6; 歷代志下 26:17–18; 何西阿書 5:11"> 烏利亞祭司按照送來的模型，在亞哈斯王從大馬士革返回之前建造了一座壇。</span>
<span className="v" id="v12" data-v="12" data-xref="歷代志下 26:16–19; 歷代志下 28:25; 列王紀上 13:1"> 王從大馬士革回來，看見那座壇，就到上面獻祭。</span>
<span className="v" id="v13" data-v="13" data-xref="利未記 1:1–3"> 他在上面獻上燔祭、素祭和奠祭，又將平安祭祭牲的血灑在壇上。</span>
<span className="v" id="v14" data-v="14" data-xref="歷代志下 4:1; 出埃及記 40:6; 出埃及記 40:29"> 他把獻給耶和華的銅壇從耶和華的殿前搬到新壇的北邊，銅壇原來放在殿和新壇之間。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及記 29:39–41; 列王紀上 8:64; 歷代志下 29:21–24"> 他吩咐烏利亞祭司：「要在這座大壇上獻早晨的燔祭、晚上的素祭，王的燔祭、素祭，國中民眾的燔祭、素祭和奠祭，燔祭牲和平安祭牲的血也要灑在上面，但銅壇要供我個人求問之用。」</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行傳 4:19; 使徒行傳 5:29; 猶大書 1:11"> 烏利亞祭司遵命而行。</span>
<span className="v" id="v17" data-v="17" data-xref="歷代志下 4:14–15; 耶利米書 52:20; 歷代志下 28:24"> 亞哈斯王拆掉盆座的鑲板，搬走盆，將銅海從銅牛背上搬下來，放在鋪石的地上。</span>
<span className="v" id="v18" data-v="18" data-xref="列王紀下 11:5; 列王紀上 10:5; 以西結書 46:2"> 為討好亞述王，他挪走耶和華殿裡為安息日而蓋的走廊，封閉了王從外面進耶和華殿的入口。</span>
<span className="v" id="v19" data-v="19" data-xref="列王紀下 15:36; 歷代志下 28:26; 列王紀下 20:20–21"> 亞哈斯其他的事都記在《猶大列王史》上。</span>
<span className="v" id="v20" data-v="20" data-xref="馬太福音 1:9; 以賽亞書 1:1; 歷代志上 3:13"> 亞哈斯與祖先同眠後，葬在大衛城他的祖墳裡。他兒子希西迦繼位。</span>
</div>

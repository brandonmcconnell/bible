## 亞瑪謝做猶大王

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀下 13:10; 歷代志下 25:1–4; 列王紀下 14:15"> 約哈斯的兒以色列王子約阿施執政第二年，猶大王約阿施的兒子亞瑪謝登基。</span>
<span className="v" id="v2" data-v="2"> 他二十五歲登基，在耶路撒冷執政二十九年。他母親叫約耶但，是耶路撒冷人。</span>
<span className="v" id="v3" data-v="3" data-xref="歷代志下 25:2–3; 撒迦利亞書 1:4–6; 列王紀上 11:4"> 亞瑪謝做耶和華視為正的事，雖不如他祖先大衛，但事事效法他父親約阿施。</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀下 12:3; 列王紀下 16:4; 列王紀下 15:35"> 然而，他沒有拆除邱壇，人們仍在那裡獻祭燒香。</span>
<span className="v" id="v5" data-v="5" data-xref="歷代志下 25:3–4; 列王紀下 12:20–21; 民數記 35:33"> 他鞏固王位後，立即處死了殺他父王的臣僕，</span>
<span className="v" id="v6" data-v="6" data-xref="申命記 24:16; 以西結書 18:20; 以西結書 18:4"> 但沒有處死他們的孩子，好遵行耶和華在摩西律法書中的吩咐：「不可因孩子犯罪而處死父親，也不可因父親犯罪而處死孩子。各人要自負罪責。」<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="申命記24·16。">a</a></sup></span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳記下 8:13; 歷代志上 18:12; 約書亞記 15:38"> 亞瑪謝曾在鹽谷殺了一萬以東人，攻佔了西拉，把西拉改名為約帖，沿用至今。</span>
<span className="v" id="v8" data-v="8" data-xref="歷代志下 25:17–24; 撒母耳記下 2:14–17; 列王紀下 14:11"> 後來，亞瑪謝差遣使者對耶戶的孫子、約哈斯的兒子、以色列王約阿施說：「來，我們戰場上見。」</span>
<span className="v" id="v9" data-v="9" data-xref="士師記 9:8–15; 列王紀上 4:33; 歷代志下 33:11"> 以色列王約阿施派人回覆猶大王亞瑪謝說：「黎巴嫩的蒺藜派使者去對黎巴嫩的香柏樹說，『將你女兒嫁給我兒子吧。』後來黎巴嫩的一隻野獸經過，把那蒺藜踐踏在腳下。</span>
<span className="v" id="v10" data-v="10" data-xref="歷代志下 26:16; 申命記 8:14; 歷代志下 32:25"> 你打敗了以東人就趾高氣揚，還是待在家裡慶祝勝利吧，何必惹禍上身，使你和猶大一同滅亡呢？」</span>
<span className="v" id="v11" data-v="11" data-xref="約書亞記 19:38; 歷代志下 25:16; 約書亞記 15:10"> 但亞瑪謝不理會他的勸告。於是，以色列王約阿施起兵攻打猶大王亞瑪謝，兩王會戰於猶大的伯·示麥。</span>
<span className="v" id="v12" data-v="12" data-xref="撒母耳記下 18:17; 撒母耳記上 4:10; 列王紀上 22:36"> 猶大人被以色列人打敗，兵將都各自逃回家去了。</span>
<span className="v" id="v13" data-v="13" data-xref="尼希米記 8:16; 尼希米記 12:39; 撒迦利亞書 14:10"> 以色列王約阿施在伯·示麥擒獲亞哈謝的孫子、約阿施的兒子猶大王亞瑪謝，然後前往耶路撒冷，拆毀從以法蓮門到角門約一百八十米長的耶路撒冷城牆，</span>
<span className="v" id="v14" data-v="14" data-xref="列王紀上 14:26; 列王紀上 7:51; 列王紀上 15:18"> 搶走耶和華殿裡和王宮庫房裡的所有金銀和器皿，並帶著人質返回撒瑪利亞。</span>
<span className="v" id="v15" data-v="15" data-xref="列王紀下 13:12–13; 列王紀上 14:19–20; 列王紀下 10:34–35"> 約阿施其他的事和功業，包括他英勇對抗猶大王亞瑪謝的事蹟，都記在《以色列列王史》上。</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀下 13:9; 列王紀下 13:13; 列王紀上 1:21"> 約阿施與祖先同眠後，葬在撒瑪利亞的以色列王陵。他兒子耶羅波安繼位。</span>
<span className="v" id="v17" data-v="17" data-xref="歷代志下 25:25–28; 列王紀下 13:10; 列王紀下 14:23"> 約哈斯的兒子以色列王約阿施死後，猶大王約阿施的兒子亞瑪謝又活了十五年。</span>
<span className="v" id="v18" data-v="18" data-xref="列王紀上 11:41; 列王紀上 14:29; 列王紀下 13:8"> 亞瑪謝其他的事都記在《猶大列王史》上。</span>
<span className="v" id="v19" data-v="19" data-xref="約書亞記 10:31; 列王紀下 15:25; 列王紀下 12:20–21"> 耶路撒冷有人謀反，亞瑪謝就逃到拉吉，但叛黨派人追到那裡殺了他。</span>
<span className="v" id="v20" data-v="20" data-xref="列王紀下 9:28; 列王紀下 12:21; 歷代志下 33:20"> 有人用馬將他的屍體馱回耶路撒冷，葬在大衛城他的祖墳裡。</span>
<span className="v" id="v21" data-v="21" data-xref="列王紀下 21:24; 馬太福音 1:8–9; 列王紀下 15:13"> 猶大民眾擁立亞瑪謝十六歲的兒子亞撒利雅<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="「亞撒利雅」即烏西雅。">b</a></sup>為王。</span>
<span className="v" id="v22" data-v="22" data-xref="列王紀下 16:6; 列王紀上 9:26; 申命記 2:8"> 亞瑪謝與祖先同眠後，亞撒利雅為猶大收回了以拉他，並重新修建。</span>
</div>

## 耶羅波安二世

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="何西阿書 1:1; 阿摩司書 7:9–11; 阿摩司書 1:1"> 約阿施的兒子猶大王亞瑪謝執政第十五年，以色列王約阿施的兒子耶羅波安在撒瑪利亞登基，執政四十一年。</span>
<span className="v" id="v24" data-v="24" data-xref="列王紀下 13:6; 列王紀下 13:11; 創世記 38:7"> 他做耶和華視為惡的事，沒有離開尼八的兒子耶羅波安使以色列人犯的那些罪。</span>
<span className="v" id="v25" data-v="25" data-xref="申命記 3:17; 馬太福音 12:39–40; 約書亞記 19:13"> 他收復了從哈馬口到死海<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="「死海」希伯來文是「亞拉巴海」。">c</a></sup>一帶的以色列邊境，正如以色列的上帝耶和華藉祂僕人迦特希弗人亞米太的兒子約拿先知所言。</span>
<span className="v" id="v26" data-v="26" data-xref="申命記 32:36; 出埃及記 3:7; 列王紀下 13:4"> 因為耶和華看見以色列人，無論自由人還是奴隸都十分痛苦，沒有人幫助他們。</span>
<span className="v" id="v27" data-v="27" data-xref="列王紀下 13:23; 列王紀下 13:5; 羅馬書 11:2–12"> 耶和華沒有說要從世上抹去以色列的名，因此祂藉著約阿施的兒子耶羅波安拯救他們。</span>
<span className="v" id="v28" data-v="28" data-xref="列王紀上 11:24; 歷代志上 18:5–6; 撒母耳記下 8:6"> 耶羅波安其他的事及一切所為和功業，包括他英勇收復大馬士革和一度屬猶大國的哈馬的事蹟，都記在《以色列列王史》上。</span>
<span className="v" id="v29" data-v="29" data-xref="列王紀下 15:8"> 耶羅波安與祖先——以色列的先王們同眠後，他兒子撒迦利雅繼位。</span>
</div>

## 書念婦人得回產業

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哈該書 1:11; 列王紀下 4:31–35; 路得記 1:1"> 以利沙曾經救活了一位書念婦人的兒子。他對那婦人說：「你和家人要離開這裡去別處寄居，因為耶和華已決定使這裡遭受七年饑荒。」</span>
<span className="v" id="v2" data-v="2" data-xref="提摩太前書 5:8; 士師記 3:3; 撒母耳記上 27:1–3"> 那婦人遵照上帝僕人的話，舉家遷往非利士，在那裡寄居了七年。</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米書 22:16; 路加福音 18:3–5; 列王紀下 4:13"> 七年後，她從非利士返回，去向王請求收回自己的房屋和田地。</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀下 5:20–27; 列王紀下 2:14; 列王紀下 6:32"> 那時，王正與上帝僕人的侍者基哈西談話，讓基哈西把以利沙所做的一切大事講給他聽。</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀下 4:35; 馬太福音 10:29–30; 列王紀下 6:26"> 基哈西正在向王講述以利沙如何使死人復活的時候，以利沙救活的孩子的母親剛好進宮為自己的房屋和田地來求王，基哈西便說：「我主我王，這就是那婦人，這是她那個被以利沙救活的兒子。」</span>
<span className="v" id="v6" data-v="6" data-xref="箴言 16:7; 箴言 21:1; 撒母耳記下 9:7"> 王問那婦人，她便如實稟告王。王委派一位臣僕處理她的事情，並吩咐說：「凡屬於這婦人的東西，包括從她離開本地直到今天她田地的所有出產，要全部還給她。」</span>
</div>
</div>

## 以利沙對哈薛的預言

<div className="bt">
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="列王紀上 11:24; 列王紀下 6:24; 列王紀上 20:1"> 一天，以利沙到了大馬士革。當時亞蘭王便·哈達正在生病，他得知上帝的僕人來了，</span>
<span className="v" id="v8" data-v="8" data-xref="列王紀上 19:15; 列王紀下 1:2; 撒母耳記上 9:7"> 便對哈薛說：「你帶著禮物去見上帝的僕人，請他求問耶和華，看看我這病能否痊癒。」</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀下 5:13; 列王紀下 13:14; 列王紀上 19:15"> 哈薛用四十頭駱駝馱著大馬士革的各種美物前去拜見以利沙。到了那裡，他站在以利沙面前說：「你兒子亞蘭王便·哈達派我來問你，他的病能否痊癒？」</span>
<span className="v" id="v10" data-v="10" data-xref="阿摩司書 7:7; 創世記 2:17; 阿摩司書 7:1"> 以利沙對哈薛說：「你去告訴他，他一定會痊癒。不過，耶和華告訴我他必死。」</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 19:41; 羅馬書 9:2; 耶利米書 9:18"> 他目不轉睛地盯著哈薛，盯得他很不安。然後，上帝的僕人哭了。</span>
<span className="v" id="v12" data-v="12" data-xref="何西阿書 13:16; 那鴻書 3:10; 列王紀下 15:16"> 哈薛問：「我主為什麼哭呢？」以利沙說：「因為我知道你會加害以色列人。你會放火燒他們的堡壘，用刀殺戮他們的壯丁，摔死他們的孩童，剖開他們的孕婦。」</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳記上 17:43; 列王紀上 19:15; 撒母耳記下 9:8"> 哈薛說：「你僕人算什麼，不過是一條狗，怎能做這樣的大事呢？」以利沙說：「耶和華告訴我，你要做亞蘭王。」</span>
<span className="v" id="v14" data-v="14" data-xref="列王紀下 8:10; 馬太福音 26:16; 列王紀下 5:25"> 哈薛辭別以利沙回到他主人那裡。王問他：「以利沙對你說什麼？」他答道：「以利沙告訴我，你一定會痊癒。」</span>
<span className="v" id="v15" data-v="15" data-xref="列王紀下 8:13; 列王紀上 15:28; 列王紀上 11:26–37"> 第二天，哈薛拿了一床浸透水的被子，蒙在王的臉上，王窒息而死。於是哈薛篡位。</span>
</div>
</div>

## 約蘭做猶大王

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="列王紀下 1:17; 列王紀下 3:1; 歷代志下 21:1–20"> 亞哈的兒子以色列王約蘭執政第五年，猶大王約沙法讓位給兒子約蘭。</span>
<span className="v" id="v17" data-v="17" data-xref="歷代志下 21:5–10"> 約蘭三十二歲登基，在耶路撒冷執政八年。</span>
<span className="v" id="v18" data-v="18" data-xref="列王紀下 8:26; 列王紀上 11:1–5; 歷代志下 21:13"> 他與亞哈家一樣步以色列諸王的後塵，因為他娶了亞哈的女兒為妻，做耶和華視為惡的事。</span>
<span className="v" id="v19" data-v="19" data-xref="列王紀上 11:36; 撒母耳記下 7:12–13; 路加福音 1:32–33"> 但耶和華因祂僕人大衛的緣故而不願毀滅猶大，因為祂曾應許讓大衛和他的子孫永遠做王。</span>
<span className="v" id="v20" data-v="20" data-xref="列王紀上 22:47; 列王紀下 3:9; 列王紀下 8:22"> 約蘭執政期間，以東人脫離猶大的統治，自己立王。</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳記下 18:17"> 約蘭率領所有戰車前往撒益，他和戰車長們被以東人包圍。他們乘夜出擊，突出重圍，各自逃回家去。</span>
<span className="v" id="v22" data-v="22" data-xref="列王紀下 19:8; 約書亞記 21:13; 創世記 27:40"> 以東人至今仍脫離猶大的統治。立拿人也在那時候叛變了。</span>
<span className="v" id="v23" data-v="23" data-xref="列王紀下 15:36; 列王紀上 11:41; 歷代志下 21:11–20"> 約蘭其他的事及一切所為都記在《猶大列王史》上。</span>
<span className="v" id="v24" data-v="24" data-xref="歷代志下 22:6; 歷代志下 25:23; 歷代志下 21:1"> 約蘭與祖先同眠後，葬在大衛城他的祖墳裡。他兒子亞哈謝繼位。</span>
</div>
</div>

## 亞哈謝做猶大王

<div className="bt">
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="列王紀下 9:29; 列王紀下 8:16–17; 歷代志下 21:20–6"> 亞哈的兒子以色列王約蘭執政第十二年，猶大王約蘭的兒子亞哈謝登基。</span>
<span className="v" id="v26" data-v="26" data-xref="歷代志下 22:2; 列王紀下 9:21–27; 列王紀下 11:1"> 他二十二歲登基，在耶路撒冷執政一年。他母親叫亞她利雅，是以色列王暗利的孫女。</span>
<span className="v" id="v27" data-v="27" data-xref="歷代志下 22:3–4; 哥林多後書 6:14–17; 傳道書 7:26"> 亞哈謝是亞哈家的女婿，他步亞哈家的後塵，做耶和華視為惡的事。</span>
<span className="v" id="v28" data-v="28" data-xref="歷代志下 22:5; 列王紀上 4:13; 歷代志下 19:2"> 他聯合亞哈的兒子約蘭到基列的拉末與亞蘭王哈薛交戰。約蘭受了傷，</span>
<span className="v" id="v29" data-v="29" data-xref="列王紀下 9:15–16; 列王紀下 8:28; 歷代志下 22:5–7"> 便回到耶斯列養傷。約蘭的兒子猶大王亞哈謝下到耶斯列探望他，因為他病了。</span>
</div>
</div>

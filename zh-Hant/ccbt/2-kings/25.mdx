<span className="v" id="v1" data-v="1" data-xref="耶利米書 52:4–11; 歷代志上 6:15; 耶利米書 34:1–6"> 西底迦執政第九年十月十日，巴比倫王尼布甲尼撒率領全軍攻打耶路撒冷，在城外安營，修築圍城的高臺。</span>
<span className="v" id="v2" data-v="2"> 城一直被圍困到西底迦王執政第十一年。</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米書 52:6; 以西結書 5:12; 耶利米書 38:2"> 那年四月九日，城裡饑荒非常嚴重，百姓無糧可吃。</span>
<span className="v" id="v4" data-v="4" data-xref="以西結書 33:21; 列王紀下 25:5; 耶利米書 39:2–7"> 城被攻破，城裡的所有士兵便在夜間從兩城牆中間、靠近御花園的門逃往亞拉巴。當時迦勒底人仍四面包圍著城。</span>
<span className="v" id="v5" data-v="5" data-xref="以賽亞書 30:16; 耶利米書 39:5; 阿摩司書 2:14–16"> 迦勒底軍隊追趕西底迦，在耶利哥平原追上了他，他的軍隊都四散而逃。</span>
<span className="v" id="v6" data-v="6" data-xref="列王紀下 23:33; 耶利米書 34:21–22; 耶利米書 21:7"> 迦勒底人擒住西底迦，把他押到利比拉見巴比倫王，在那裡審判他。</span>
<span className="v" id="v7" data-v="7" data-xref="耶利米書 32:4–5; 士師記 16:21; 耶利米書 39:6–7"> 巴比倫王當著西底迦的面殺了他的眾子，又剜去他的雙眼，把他用銅鏈鎖著押往巴比倫。</span>

## 聖殿被毀

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="耶利米書 52:12–16; 耶利米書 40:1–4; 耶利米哀歌 4:12"> 巴比倫王尼布甲尼撒執政第十九年五月七日，他的臣僕護衛長尼布撒拉旦來到耶路撒冷，</span>
<span className="v" id="v9" data-v="9" data-xref="阿摩司書 2:5; 詩篇 74:3–7; 列王紀上 9:8"> 放火焚燒耶和華的殿、王宮及耶路撒冷所有的房屋。他燒毀了所有重要建築。</span>
<span className="v" id="v10" data-v="10" data-xref="尼希米記 1:3; 耶利米書 39:8; 耶利米書 52:14–23"> 他率領的迦勒底軍隊拆毀了耶路撒冷四圍的城牆。</span>
<span className="v" id="v11" data-v="11" data-xref="以西結書 5:2; 耶利米書 15:1–2; 耶利米書 39:9"> 護衛長尼布撒拉旦擄去城裡剩下的百姓、投降巴比倫王的人以及其他人，</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米書 40:7; 列王紀下 24:14; 以西結書 33:24"> 只留下一些最貧窮的人，讓他們照料葡萄園、耕種田地。</span>
<span className="v" id="v13" data-v="13" data-xref="歷代志下 36:18; 耶利米哀歌 1:10; 列王紀下 20:17"> 迦勒底人打碎耶和華殿中的銅柱、銅底座和銅海，把銅運往巴比倫，</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及記 27:3; 列王紀上 7:47–50; 出埃及記 38:3"> 並帶走了盆、鏟、燈剪、碟子及一切獻祭用的銅器。</span>
<span className="v" id="v15" data-v="15" data-xref="但以理書 5:2–3; 民數記 7:13–14; 列王紀上 7:48–51"> 護衛長還帶走了火鼎、碗等一切金銀器具。</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀上 7:47"> 所羅門為耶和華的殿所造的兩根銅柱、一個銅海和一些銅底座，用的銅多得無法計算。</span>
<span className="v" id="v17" data-v="17" data-xref="列王紀上 7:15–22; 耶利米書 52:21–23"> 銅柱高八米，銅柱有柱冠，高一米半。柱冠周圍裝飾著銅網和銅石榴。兩根柱子都一樣。</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米書 29:25; 以斯拉記 7:1; 耶利米書 21:1"> 護衛長尼布撒拉旦擄走祭司長西萊雅、副祭司長西番亞和三名殿門守衛，</span>
<span className="v" id="v19" data-v="19" data-xref="以斯帖記 1:14"> 還從城中擄走一名統管士兵的將領、王的五個親信、一名負責招兵的書記和六十名平民。</span>
<span className="v" id="v20" data-v="20" data-xref="耶利米哀歌 4:16; 耶利米書 52:26–27; 列王紀下 23:33"> 護衛長尼布撒拉旦把他們帶到利比拉去見巴比倫王，</span>
<span className="v" id="v21" data-v="21" data-xref="申命記 28:64; 列王紀下 23:27; 申命記 4:26"> 巴比倫王在那裡處死了他們。猶大人就這樣被擄去，離開了家園。</span>
</div>
</div>

## 基大利做猶大省長

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="耶利米書 39:14; 列王紀下 22:12; 耶利米書 41:2"> 巴比倫王尼布甲尼撒委任沙番的孫子、亞希甘的兒子基大利治理猶大的餘民。</span>
<span className="v" id="v23" data-v="23" data-xref="耶利米書 40:7–9; 耶利米書 40:11–12; 約書亞記 18:26"> 猶大眾將領和他們的下屬聽到巴比倫王委任基大利治理猶大的消息後，便來到米斯巴見基大利。他們是尼探雅的兒子以實瑪利、加利亞的兒子約哈難、尼陀法人單戶篾的兒子西萊雅、瑪迦人雅撒尼亞。</span>
<span className="v" id="v24" data-v="24" data-xref="耶利米書 40:9–10; 耶利米書 43:6; 撒母耳記下 19:23"> 基大利對他們和他們的下屬起誓說：「你們不要害怕那些迦勒底官員，只管住在此地臣服於巴比倫王，你們會平安無事。」</span>
<span className="v" id="v25" data-v="25" data-xref="撒迦利亞書 7:5; 撒迦利亞書 8:19; 耶利米書 40:15"> 七月，王室後裔以利沙瑪的孫子、尼探雅的兒子以實瑪利帶著十個人在米斯巴刺殺了基大利以及跟他一起的猶大人和迦勒底人。</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米書 43:4–7; 耶利米書 41:16–18; 耶利米書 42:14–22"> 因為害怕迦勒底人報復，猶大眾人不論貴賤，都和眾將領一起逃往埃及。</span>
</div>
</div>

## 約雅斤獲釋

<div className="bt">
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="耶利米書 52:31–34; 創世記 40:20; 創世記 40:13"> 巴比倫王以未·米羅達在他執政的元年十二月二十七日，即猶大王約雅斤被擄後第三十七年，施恩釋放了約雅斤，</span>
<span className="v" id="v28" data-v="28" data-xref="但以理書 2:37; 耶利米書 27:6–11; 但以理書 5:18–19"> 並好言相待，使他的地位高過被擄到巴比倫的其他各王。</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳記下 9:7; 以賽亞書 61:3; 創世記 41:42"> 約雅斤脫去了囚服，終生與巴比倫王一起吃飯。</span>
<span className="v" id="v30" data-v="30" data-xref="路加福音 11:3; 馬太福音 6:11; 尼希米記 11:23"> 在他有生之年，巴比倫王供應他每天的需用。</span>
</div>

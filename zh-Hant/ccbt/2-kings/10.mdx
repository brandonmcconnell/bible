## 耶戶剷除亞哈家

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士師記 8:30; 列王紀上 13:32; 列王紀上 21:8–14"> 亞哈在撒瑪利亞有七十個子孫。耶戶寫信並送到撒瑪利亞，交給耶斯列的首領、長老以及亞哈子孫的監護人，說：</span>
<span className="v" id="v2" data-v="2" data-xref="列王紀下 5:6"> 「既然你們主人的子孫和你們在一起，你們也擁有車馬、堅城和兵器，你們接到這封信後，</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳記下 2:8–9; 列王紀上 12:20–21; 撒母耳記下 2:12–17"> 就可以從你們主人的子孫中選立一個最好的繼承王位，為你們主人家而戰。」</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀下 9:24; 列王紀下 9:27; 以賽亞書 27:4"> 他們都十分害怕，便說：「兩位王都不能抵擋他，我們怎能抵擋呢？」</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀上 20:32; 列王紀上 20:4; 約書亞記 9:11"> 宮廷總管、總督、長老和眾監護人便派人送信給耶戶，說：「我們是你的僕人，你怎樣吩咐，我們就怎樣做。我們不會立任何人為王，你認為怎樣好，就怎樣辦吧。」</span>
<span className="v" id="v6" data-v="6" data-xref="啟示錄 2:20–23; 申命記 5:9; 民數記 25:4"> 耶戶又寫了一封信，說：「你們如果歸順我，願意聽從我，明天這個時候，帶著你們主人子孫的首級來耶斯列見我。」當時亞哈的七十個子孫都養在城中顯貴的府中。</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀上 21:21; 列王紀下 11:1; 列王紀下 10:9"> 這些顯貴們接到信後，便殺了亞哈的七十個子孫，把他們的首級放在籃子裡，送到耶斯列的耶戶那裡。</span>
<span className="v" id="v8" data-v="8" data-xref="申命記 21:23; 撒母耳記下 11:18–21; 馬可福音 6:28"> 使者告訴耶戶：「他們將王眾子孫的首級送來了。」耶戶下令：「把首級分成兩堆，放在城門口，一直放到明天早上。」</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀下 9:14–24; 以賽亞書 5:3; 何西阿書 1:4"> 第二天早晨，耶戶出去站在城門口，對眾人說：「你們都沒有罪，是我背叛我主人，把他殺了。可是，是誰殺了這些人呢？</span>
<span className="v" id="v10" data-v="10" data-xref="列王紀上 21:29; 列王紀上 21:19; 列王紀下 9:7–10"> 由此可知，耶和華對亞哈家的預言一句也沒有落空。耶和華藉祂僕人以利亞所說的一切都應驗了。」</span>
<span className="v" id="v11" data-v="11" data-xref="約伯記 18:19; 列王紀上 18:19; 列王紀上 22:6"> 耶戶殺了亞哈家留在耶斯列的親屬、大臣、朋友和祭司，一個不留。</span>
<span className="v" id="v12" data-v="12"> 耶戶動身去撒瑪利亞，經過牧人剪羊毛的地方時，</span>
<span className="v" id="v13" data-v="13" data-xref="列王紀下 8:29; 列王紀下 8:24; 歷代志下 21:17"> 遇見猶大王亞哈謝的親屬，就問：「你們是誰？」他們答道：「我們是亞哈謝的親屬，現在去問候王和太后一家。」</span>
<span className="v" id="v14" data-v="14" data-xref="歷代志下 22:10; 列王紀下 10:6; 列王紀下 10:10–11"> 耶戶下令活捉他們，他的手下便捉住他們，在伯‧艾克特的井旁全部殺掉，共四十二人，一個不留。</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米書 35:14–19; 以斯拉記 10:19; 以西結書 17:18"> 耶戶繼續前行，遇見前來迎接他的利甲的兒子約拿達。耶戶問候他，並說：「我對你忠誠，你對我也一樣忠誠嗎？」約拿達答道：「當然！」耶戶說：「既然如此，把手伸給我。」他伸出手來，耶戶把他拉上車，</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀上 19:10; 馬太福音 6:5; 列王紀下 10:31"> 說：「跟我來，看我怎樣熱心為耶和華工作。」於是耶戶讓他坐在車上。</span>
<span className="v" id="v17" data-v="17" data-xref="列王紀下 9:8; 歷代志下 22:8; 瑪拉基書 4:1"> 到了撒瑪利亞，他把亞哈家在撒瑪利亞剩下的人全部殺光，一個不留，應驗了耶和華對以利亞說的話。</span>
</div>
</div>

## 耶戶計殺拜巴力之人

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="列王紀上 16:31–32; 列王紀下 3:2; 羅馬書 3:8"> 耶戶召集了所有的人，對他們說：「亞哈供奉巴力還不夠熱心，我耶戶要更熱心地供奉他。</span>
<span className="v" id="v19" data-v="19" data-xref="列王紀上 22:6; 列王紀上 18:19; 哥林多後書 11:3"> 我要向巴力獻大祭，你們去把巴力的先知和祭司及所有拜巴力的人一個不漏地召來。凡不來的人休想活命。」耶戶這樣做，是想用計殺盡拜巴力的人。</span>
<span className="v" id="v20" data-v="20" data-xref="約珥書 1:14; 出埃及記 32:5; 列王紀上 18:19–20"> 耶戶下令召開祭拜巴力的莊嚴聚會，於是他們發出通告。</span>
<span className="v" id="v21" data-v="21" data-xref="列王紀上 16:32; 列王紀下 11:18; 約珥書 3:2"> 耶戶派人送信到以色列各地，凡拜巴力的人全都來了，沒有一個缺席。他們把整個巴力廟塞得滿滿的。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及記 28:2; 馬太福音 22:11–12"> 耶戶吩咐掌管禮服的人拿出禮服給拜巴力的人穿上，他就拿出禮服給他們穿上。</span>
<span className="v" id="v23" data-v="23" data-xref="馬太福音 13:30; 馬太福音 25:32–33; 馬太福音 13:41"> 然後他和利甲的兒子約拿達進廟向他們宣佈說：「你們仔細察看，這裡不可有事奉耶和華的人，只允許拜巴力的人在這裡。」</span>
<span className="v" id="v24" data-v="24" data-xref="列王紀上 20:30–42"> 耶戶和約拿達在廟裡獻上祭物和燔祭。此前，他預先派了八十人在廟外守著，並下令：「我把這些人交在你們手中，誰放走一個，誰就要以命抵償。」</span>
<span className="v" id="v25" data-v="25" data-xref="啟示錄 16:6–7; 以西結書 22:21–22; 列王紀上 18:40"> 耶戶獻完燔祭出來，便命令衛兵和將領說：「進去殺死他們，不要放走一人。」衛兵和將領揮刀殺了他們，把屍首拋出去後，走入巴力廟的內殿，</span>
<span className="v" id="v26" data-v="26" data-xref="列王紀上 14:23; 列王紀下 3:2; 列王紀下 19:18"> 將巴力神柱搬出去燒了。</span>
<span className="v" id="v27" data-v="27" data-xref="但以理書 3:29; 以斯拉記 6:11; 但以理書 2:5"> 他們摧毀了巴力的神柱和廟，把廟當作廁所，至今未變。</span>
<span className="v" id="v28" data-v="28"> 這樣，耶戶從以色列掃除了巴力。</span>
<span className="v" id="v29" data-v="29" data-xref="列王紀上 12:28–30; 列王紀上 14:16; 列王紀上 13:33–34"> 可是，他重蹈尼八的兒子耶羅波安的覆轍，拜伯特利和但兩地的金牛犢，使以色列人陷入罪中。</span>
<span className="v" id="v30" data-v="30" data-xref="列王紀下 10:35; 列王紀下 13:1; 列王紀下 13:10"> 耶和華對耶戶說：「你已經做了我視為正的事，照我的意思除掉了亞哈一家，因此你的子孫必做以色列王，直到第四代。」</span>
<span className="v" id="v31" data-v="31" data-xref="列王紀下 10:29; 箴言 4:23; 希伯來書 2:1"> 但耶戶沒有全心全意地遵守以色列的上帝耶和華的律法，卻重蹈耶羅波安的覆轍，使以色列人陷入罪中。</span>
</div>
</div>

## 耶戶去世

<div className="bt">
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="列王紀下 8:12; 列王紀上 19:17; 列王紀下 13:22"> 那時，耶和華開始削減以色列的領土。哈薛攻打以色列各處，</span>
<span className="v" id="v33" data-v="33" data-xref="阿摩司書 1:3–4; 申命記 2:36; 約書亞記 13:9–12"> 侵佔了約旦河以東的土地，包括基列全境，即迦得人、呂便人和瑪拿西人住的地方，從亞嫩谷附近的亞羅珥起，直到基列和巴珊。</span>
<span className="v" id="v34" data-v="34" data-xref="列王紀上 11:41; 列王紀上 14:29; 列王紀上 14:19"> 耶戶其他的事及一切所為和功業都記在《以色列列王史》上。</span>
<span className="v" id="v35" data-v="35" data-xref="列王紀上 14:20; 列王紀上 14:31; 列王紀上 1:21"> 他與祖先同眠後葬在撒瑪利亞，他兒子約哈斯繼位。</span>
<span className="v" id="v36" data-v="36"> 耶戶在撒瑪利亞統治以色列二十八年。</span>
</div>

## 以利沙找回斧頭

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀下 2:3; 列王紀下 4:1; 約書亞記 17:14"> 一群先知對以利沙說：「你看，我們住的地方實在太小了。</span>
<span className="v" id="v2" data-v="2" data-xref="約翰福音 21:3; 使徒行傳 18:3; 帖撒羅尼迦前書 2:9"> 請讓我們去約旦河吧，我們每人都可以從那裡砍一根木頭蓋房子居住。」以利沙說：「你們去吧。」</span>
<span className="v" id="v3" data-v="3" data-xref="約伯記 6:28; 士師記 19:6; 列王紀下 5:23"> 其中一人請以利沙一起去，以利沙答應了，</span>
<span className="v" id="v4" data-v="4" data-xref="申命記 19:5; 申命記 29:11"> 便和他們一起去約旦河砍伐樹木。</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 37:21; 傳道書 10:10; 列王紀下 6:15"> 有個人砍樹的時候，斧頭掉進了水裡。他大喊：「唉！師傅，這把斧頭是借來的。」</span>
<span className="v" id="v6" data-v="6" data-xref="列王紀下 2:21; 馬可福音 8:23–25; 列王紀下 4:41"> 上帝的僕人問：「斧頭掉在哪裡了？」他就指給以利沙看。以利沙砍了一根樹枝拋進水裡，斧頭便浮了上來。</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀下 4:36; 出埃及記 4:4; 列王紀下 4:7"> 以利沙說：「你去拿上來吧！」他便伸手拿起了斧頭。</span>
</div>
</div>

## 以利沙使亞蘭軍敗退

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="列王紀下 6:24; 箴言 21:30; 箴言 20:18"> 亞蘭王與以色列人交戰，他和臣僕商議要在某處安營。</span>
<span className="v" id="v9" data-v="9" data-xref="阿摩司書 3:7; 啟示錄 1:1; 列王紀下 6:12"> 上帝的僕人傳信給以色列王，說：「你要小心，不要經過那個地方，因為亞蘭人埋伏在那裡。」</span>
<span className="v" id="v10" data-v="10" data-xref="列王紀下 13:14; 列王紀下 5:14; 使徒行傳 27:24"> 以色列王派人到上帝的僕人所說的地方，警告那裡的人要小心防備。這樣的事情發生了好幾次。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="約伯記 18:7–11; 以賽亞書 57:20–21; 馬太福音 2:3–12"> 亞蘭王因此十分惱怒，召來臣僕質問他們：「你們當中誰向以色列王洩露了我們的計劃？」</span>
<span className="v" id="v12" data-v="12" data-xref="但以理書 2:28–30; 阿摩司書 3:7; 列王紀下 6:9–10"> 一位臣僕說：「我主我王啊，沒有人洩露。是以色列的先知以利沙將王在寢宮所談的事告訴了以色列王。」</span>
<span className="v" id="v13" data-v="13" data-xref="創世記 37:17; 約翰福音 11:47–53; 撒母耳記上 23:22–23"> 王說：「去找出他在哪裡，我派人去捉拿他。」王得知以利沙在多坍後，</span>
<span className="v" id="v14" data-v="14" data-xref="列王紀下 18:17; 撒母耳記上 24:2; 撒母耳記上 23:26"> 便派出大隊人馬和戰車前往那裡，他們在夜間抵達多坍，把城圍住。</span>
<span className="v" id="v15" data-v="15" data-xref="馬太福音 8:26; 歷代志下 20:12; 詩篇 53:5"> 上帝僕人的侍者清早起來，走到外面，看見城被軍隊、車馬包圍，就對上帝的僕人說：「唉！我主啊，我們該怎麼辦呢？」</span>
<span className="v" id="v16" data-v="16" data-xref="以賽亞書 41:10–14; 羅馬書 8:31; 約翰一書 4:4"> 上帝的僕人說：「不要害怕！我們的兵馬比他們的還要多。」</span>
<span className="v" id="v17" data-v="17" data-xref="詩篇 68:17; 詩篇 34:7; 撒迦利亞書 6:1–7"> 他隨後禱告：「耶和華啊，求你開他的眼睛，讓他看見。」於是，耶和華開那個侍者的眼睛，他就看見山上到處都是火車火馬圍繞著以利沙。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行傳 13:11; 約翰福音 12:40; 創世記 19:11"> 亞蘭人向以利沙衝來，以利沙祈求耶和華說：「求你使他們瞎眼。」耶和華聽了以利沙的禱告，使他們瞎了眼。</span>
<span className="v" id="v19" data-v="19" data-xref="路加福音 24:16; 撒母耳記下 16:18–19; 路加福音 9:23"> 以利沙對他們說：「不是這條路，也不是這座城。跟我來，我帶你們到你們要找的人那裡。」以利沙把他們領到撒瑪利亞。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="列王紀下 6:17; 路加福音 24:31; 路加福音 16:23"> 他們進城後，以利沙禱告：「耶和華啊，求你開他們的眼睛，讓他們看見。」耶和華開了他們的眼睛，他們就看見了，發現自己在撒瑪利亞城中。</span>
<span className="v" id="v21" data-v="21" data-xref="列王紀下 5:13; 列王紀下 8:9; 列王紀下 2:12"> 以色列王看見他們，問以利沙說：「我父啊，我可以殺他們嗎？」</span>
<span className="v" id="v22" data-v="22" data-xref="羅馬書 12:20–21; 創世記 48:22; 何西阿書 2:18"> 以利沙答道：「不可殺他們。豈可殺用刀和弓抓來的俘虜呢？給他們吃的喝的，讓他們吃喝完了回自己主人那裡吧。」</span>
<span className="v" id="v23" data-v="23" data-xref="列王紀下 5:2; 列王紀下 24:2; 路加福音 6:35"> 於是，以色列王為他們大擺宴席，等他們吃喝完畢，便放他們回自己主人那裡。之後，亞蘭人不再侵犯以色列。</span>
</div>
</div>

## 撒瑪利亞城被圍困

<div className="bt">
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="列王紀上 20:1; 列王紀上 22:31; 傳道書 9:14"> 後來，亞蘭王便·哈達召集全軍圍困撒瑪利亞。</span>
<span className="v" id="v25" data-v="25" data-xref="列王紀下 6:28–29; 耶利米書 14:18; 耶利米書 14:13–15"> 撒瑪利亞被困後，城裡陷入嚴重饑荒，以致一個驢頭可賣二十兩銀子，二百克鴿子糞可賣一兩銀子。</span>
<span className="v" id="v26" data-v="26" data-xref="撒母耳記下 14:4; 以賽亞書 10:3; 路加福音 18:3"> 一天，以色列王從城牆上走過，一個婦人向他呼喊：「我主我王啊，求你幫幫我！」</span>
<span className="v" id="v27" data-v="27" data-xref="詩篇 118:8–9; 詩篇 124:1–3; 詩篇 60:11"> 王說：「如果耶和華不幫助你，我怎能幫助你呢？我豈有麥子和酒？</span>
<span className="v" id="v28" data-v="28" data-xref="撒母耳記下 14:5; 士師記 18:23; 耶利米哀歌 4:10"> 你有什麼難處呢？」婦人說：「這個女人對我說，『我們今天吃你兒子，明天再吃我兒子。』</span>
<span className="v" id="v29" data-v="29" data-xref="利未記 26:29; 申命記 28:53; 申命記 28:57"> 於是我們把我兒子煮了吃。第二天我叫她把她兒子交出來，她卻把兒子藏了起來。」</span>
<span className="v" id="v30" data-v="30" data-xref="列王紀上 21:27; 列王紀下 5:7; 列王紀下 19:1"> 王聽了婦人的話，就撕裂衣服。王走在城牆上，人們都看見他貼身穿著麻衣。</span>
<span className="v" id="v31" data-v="31" data-xref="路得記 1:17; 列王紀上 19:2; 約翰福音 11:50"> 王說：「如果今天沙法的兒子以利沙的頭顱還留在他頸項上，願上帝重重地懲罰我！」</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="以西結書 20:1; 列王紀上 18:4; 以西結書 8:1"> 王派使者去以利沙那裡。那時，以利沙正與長老們坐在他家中。使者到達之前，以利沙對長老說：「你們看，這兇手派人來斬我的頭。使者到達時，你們要把他關在門外。他後面不就是他主人的腳步聲嗎？」</span>
<span className="v" id="v33" data-v="33" data-xref="約伯記 2:9; 以賽亞書 8:21; 創世記 4:13"> 話音未落，使者已經到了，說：「既然這禍是從耶和華來的，我何必再仰望祂呢？」</span>
</div>
</div>

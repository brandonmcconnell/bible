## 希西迦做猶大王

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歷代志下 28:27–1; 馬太福音 1:9–10; 歷代志上 3:13"> 以拉的兒子以色列王何細亞執政第三年，猶大王亞哈斯的兒子希西迦登基。</span>
<span className="v" id="v2" data-v="2" data-xref="歷代志下 29:1–2"> 他二十五歲登基，在耶路撒冷執政二十九年。他母親叫亞比雅<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「亞比雅」此處的希伯來文為亞比，是亞比雅的變體。">a</a></sup>，是撒迦利雅的女兒。</span>
<span className="v" id="v3" data-v="3" data-xref="列王紀下 20:3; 列王紀上 11:4; 歷代志下 31:20–21"> 希西迦事事效法他祖先大衛，做耶和華視為正的事。</span>
<span className="v" id="v4" data-v="4" data-xref="歷代志下 31:1; 民數記 21:8–9; 列王紀下 18:22"> 他拆除邱壇，砸碎神柱，砍倒亞舍拉神像，打碎摩西造的銅蛇，因為當時以色列人仍向銅蛇燒香，稱之為尼忽士旦<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="「尼忽士旦」可能是「蛇」和「銅」的組合詞。">b</a></sup>。</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀下 23:25; 列王紀下 19:10; 馬太福音 27:43"> 希西迦信靠以色列的上帝耶和華，在他前後的猶大諸王沒有一個可與他相比。</span>
<span className="v" id="v6" data-v="6" data-xref="約書亞記 23:8; 申命記 10:20; 約翰福音 14:15"> 他對耶和華忠心不渝，遵守耶和華頒給摩西的誡命。</span>
<span className="v" id="v7" data-v="7" data-xref="羅馬書 8:31; 創世記 39:2–3; 列王紀下 16:7"> 耶和華與他同在，他凡事順利。他反抗亞述王的統治，不再臣服於他。</span>
<span className="v" id="v8" data-v="8" data-xref="以賽亞書 14:29; 列王紀下 17:9; 歷代志下 28:18"> 他擊敗非利士人，從他們的瞭望塔到堅城，一直打到迦薩及其四境。</span>
<span className="v" id="v9" data-v="9" data-xref="何西阿書 10:14; 列王紀下 17:3–23; 列王紀下 18:1"> 希西迦執政第四年，即以拉的兒子以色列王何細亞執政第七年，亞述王撒縵以色起兵攻打撒瑪利亞，將城包圍。</span>
<span className="v" id="v10" data-v="10" data-xref="阿摩司書 6:7; 阿摩司書 9:1–4; 彌迦書 1:6–9"> 三年之後，就是希西迦執政第六年，以色列王何細亞執政第九年，撒瑪利亞失陷。</span>
<span className="v" id="v11" data-v="11" data-xref="歷代志上 5:26; 列王紀下 17:6; 以賽亞書 37:12"> 亞述王把以色列人擄到亞述，將他們安置在哈臘、歌散的哈博河一帶以及瑪代人的城邑裡。</span>
<span className="v" id="v12" data-v="12" data-xref="彼得前書 4:17; 彼得前書 2:8; 彌迦書 3:4"> 這都是因為以色列人沒有聽從他們的上帝耶和華，違背了祂的約，不遵行祂僕人摩西所吩咐的一切。</span>
</div>
</div>

## 亞述人攻打耶路撒冷

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="以賽亞書 36:1–22; 歷代志下 32:1–23; 以賽亞書 7:17–25"> 希西迦王執政第十四年，亞述王西拿基立起兵攻取了猶大所有的堅城。</span>
<span className="v" id="v14" data-v="14" data-xref="列王紀下 18:7; 路加福音 14:32; 列王紀上 20:4"> 猶大王希西迦差遣使者去拉吉見亞述王說：「我錯了，求你退兵！我願意滿足你的任何要求。」亞述王向希西迦索要二十萬兩銀子和兩萬兩金子。</span>
<span className="v" id="v15" data-v="15" data-xref="列王紀下 16:8; 列王紀上 15:18–19; 列王紀下 12:18"> 希西迦將耶和華殿裡和王宮庫房裡的所有銀子都給了他，</span>
<span className="v" id="v16" data-v="16" data-xref="歷代志下 29:3; 列王紀上 6:31–35"> 又刮下他包在耶和華殿門和門柱上的金子，一併送給亞述王。</span>
<span className="v" id="v17" data-v="17" data-xref="以賽亞書 20:1; 列王紀下 20:20; 以賽亞書 7:3"> 但亞述王派他的元帥、都統和將軍從拉吉率領大軍到耶路撒冷的希西迦王那裡。到了耶路撒冷後，他們駐紮在上池的水溝旁、通往漂布場的路上。</span>
<span className="v" id="v18" data-v="18" data-xref="列王紀下 19:2; 以賽亞書 36:3; 撒母耳記下 8:16–17"> 他們要求見王。希勒迦的兒子宮廷總管以利亞敬、書記舍伯那和亞薩的兒子史官約亞出來見他們。</span>
<span className="v" id="v19" data-v="19" data-xref="以賽亞書 36:4; 列王紀下 19:10; 以賽亞書 10:8–14"> 亞述的將軍對他們說：「你們去告訴希西迦，偉大的亞述王說，『你憑什麼這樣自信呢？</span>
<span className="v" id="v20" data-v="20" data-xref="箴言 21:30–31"> 你所謂的戰略和軍力不過是空話。你究竟倚靠誰，竟敢背叛我？</span>
<span className="v" id="v21" data-v="21" data-xref="以賽亞書 30:7; 以西結書 29:6–7; 以賽亞書 30:2–3"> 看啊，你所倚靠的埃及不過是一根破裂的蘆葦杖，倚靠它的必被刺破手。倚靠埃及王法老的下場都是這樣。』</span>
<span className="v" id="v22" data-v="22" data-xref="歷代志下 31:1; 列王紀下 18:4–5; 馬太福音 27:43"> 也許你們會說，『我們倚靠我們的上帝耶和華。』希西迦不是拆除了祂的邱壇和祭壇，又吩咐猶大和耶路撒冷的人必須在耶路撒冷的這座祭壇前敬拜嗎？</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳記上 17:42; 列王紀上 20:10; 尼希米記 4:2–5"> 來，跟我主人亞述王打個賭，你若能找到兩千騎士，我就給你兩千匹馬！</span>
<span className="v" id="v24" data-v="24" data-xref="以賽亞書 10:8; 申命記 17:16; 以賽亞書 36:6"> 你們即使依靠埃及的戰車和騎兵，又怎能打敗我主人的一個最小的將領呢？</span>
<span className="v" id="v25" data-v="25" data-xref="列王紀下 19:6; 以賽亞書 10:5–6; 列王紀下 19:22–37"> 更何況我來攻打、毀滅這地方，不正是耶和華的意思嗎？耶和華吩咐我攻打、毀滅這地方。」</span>
<span className="v" id="v26" data-v="26" data-xref="以斯拉記 4:7; 但以理書 2:4; 以賽亞書 36:11–12"> 以利亞敬、舍伯那和約亞對亞述的將軍說：「求你用亞蘭語跟僕人們說話，我們都聽得懂。求你不要用猶大話跟我們說話，免得城牆上的人聽見。」</span>
<span className="v" id="v27" data-v="27" data-xref="詩篇 73:8; 耶利米哀歌 4:5; 以西結書 4:15"> 亞述的將軍卻說：「難道我主人派我來只對你們和你們的主人說這些話嗎？不也是對坐在城牆上的人說嗎？他們和你們一樣都要吃自己的糞，喝自己的尿。」</span>
<span className="v" id="v28" data-v="28" data-xref="以賽亞書 36:13–18; 以賽亞書 10:8–13; 以西結書 29:3"> 於是，他站著用猶大話大喊：「你們要聽偉大的亞述王的話。</span>
<span className="v" id="v29" data-v="29" data-xref="歷代志下 32:15; 帖撒羅尼迦後書 2:8; 歷代志下 32:11"> 王說，『你們不要被希西迦欺騙，他不能從我手中救你們。</span>
<span className="v" id="v30" data-v="30" data-xref="詩篇 125:1–2; 路加福音 23:35; 列王紀下 19:32–34"> 不要聽希西迦的話去倚靠耶和華，說什麼耶和華必拯救你們，這城必不會落在亞述王手中。』</span>
<span className="v" id="v31" data-v="31" data-xref="列王紀上 4:25; 列王紀上 4:20; 撒迦利亞書 3:10"> 不要聽希西迦的話。亞述王說，『你們要跟我講和，出來歸順我，這樣就可以吃自己葡萄樹和無花果樹的果子，喝自己井裡的水。</span>
<span className="v" id="v32" data-v="32" data-xref="申命記 8:7–9; 出埃及記 3:8; 申命記 11:12"> 以後我會來領你們到一個地方，那裡和這裡一樣有五穀和新酒、餅和葡萄園、橄欖樹和蜂蜜，好讓你們存活，不至於死。希西迦說耶和華必拯救你們，不要聽信他的話，他在哄騙你們。</span>
<span className="v" id="v33" data-v="33" data-xref="以賽亞書 10:10–11; 列王紀下 19:12–13; 歷代志下 32:19"> 列國有哪個神明從亞述王手中救了它的國家呢？</span>
<span className="v" id="v34" data-v="34" data-xref="以賽亞書 10:9; 列王紀下 17:23–33; 耶利米書 49:23"> 哈馬和亞珥拔的神明在哪裡呢？西法瓦音、希拿和以瓦的神明在哪裡呢？它們從我手中救撒瑪利亞了嗎？</span>
<span className="v" id="v35" data-v="35" data-xref="但以理書 3:15; 以賽亞書 10:15; 出埃及記 5:2"> 這些國家有哪個神明從我手中救了它的國家呢？難道耶和華能從我手中救耶路撒冷嗎？』」</span>
<span className="v" id="v36" data-v="36" data-xref="阿摩司書 5:13; 箴言 9:7; 馬太福音 7:6"> 民眾默不作聲，一言不發，因為希西迦王曾吩咐他們不要答話。</span>
<span className="v" id="v37" data-v="37" data-xref="列王紀下 22:11; 創世記 37:29; 列王紀下 5:7"> 這時，希勒家的兒子宮廷總管以利亞敬、書記舍伯那和亞薩的兒子史官約亞都撕裂衣服去見希西迦，把亞述將軍的話回稟他。</span>

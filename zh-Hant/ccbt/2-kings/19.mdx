## 希西迦向以賽亞求助

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀上 21:27; 列王紀下 18:37; 歷代志下 32:20–22"> 希西迦王聽後就撕裂衣服，披上麻衣，進入耶和華的殿。</span>
<span className="v" id="v2" data-v="2" data-xref="以賽亞書 1:1; 以賽亞書 2:1; 馬太福音 4:14"> 他派身披麻衣的宮廷總管以利亞敬、書記舍伯那和祭司中的長者，去見亞摩斯的兒子以賽亞先知，</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米書 30:5–7; 以賽亞書 66:9; 何西阿書 13:13"> 對他說：「希西迦說，『今天是遭難、蒙羞、受辱的日子，就像嬰兒要出生，產婦卻無力生產一樣。</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳記下 16:12; 羅馬書 9:27; 約書亞記 14:12"> 亞述王派他的將軍來辱罵永活的上帝，也許你的上帝耶和華聽見那些話，就會懲罰他。因此，請你為我們這些剩下的人禱告。』」</span>
<span className="v" id="v5" data-v="5"> 希西迦王的臣僕前來見以賽亞，</span>
<span className="v" id="v6" data-v="6" data-xref="列王紀下 18:35; 列王紀下 18:17; 以賽亞書 37:6–38"> 以賽亞對他們說：「告訴你們主人，耶和華這樣說，『你不要因為聽到亞述王的僕人那些褻瀆我的話而害怕。</span>
<span className="v" id="v7" data-v="7" data-xref="俄巴底亞書 1:1; 列王紀下 7:6; 詩篇 18:14–15"> 我必驚動<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「驚動」希伯來文是「使靈進入」。">a</a></sup>亞述王的心，讓他聽見一些風聲後便返回本國，使他在那裡死於刀下。』」</span>
</div>
</div>

## 希西迦向上帝禱告

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="列王紀下 18:14; 約書亞記 10:29; 約書亞記 12:11"> 亞述的將軍聽說亞述王已經離開拉吉，便回去見王，發現王在攻打立拿。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳記上 23:27; 以賽亞書 37:9; 列王紀下 18:17"> 亞述王聽說古實王特哈加來攻打他，便再次派使者去見希西迦，說：</span>
<span className="v" id="v10" data-v="10" data-xref="列王紀下 18:5; 列王紀下 18:29–30; 歷代志下 32:15–19"> 「不要讓你所倚靠的上帝愚弄你，說什麼耶路撒冷必不會落在亞述王手中。</span>
<span className="v" id="v11" data-v="11" data-xref="以賽亞書 10:8–11; 歷代志下 32:13–14; 列王紀下 19:17–18"> 你肯定聽過亞述諸王掃滅列國的事，難道你能倖免嗎？</span>
<span className="v" id="v12" data-v="12" data-xref="列王紀下 17:6; 創世記 11:31; 以西結書 27:23"> 我先祖毀滅了歌散、哈蘭、利色和提·拉撒的伊甸，這些國家的神明救得了他們嗎？</span>
<span className="v" id="v13" data-v="13" data-xref="列王紀下 18:34; 列王紀下 17:24; 以賽亞書 11:11"> 哈馬王、亞珥拔王、西法瓦音王、希拿王和以瓦王如今在哪裡呢？」</span>
<span className="v" id="v14" data-v="14" data-xref="以賽亞書 37:14; 詩篇 91:1–2; 詩篇 123:1–4"> 希西迦從使者手中接過信，讀完後上到耶和華的殿，在耶和華面前展開信，</span>
<span className="v" id="v15" data-v="15" data-xref="以賽亞書 44:6; 列王紀下 5:15; 但以理書 4:34–35"> 禱告說：「坐在基路伯天使之上、以色列的上帝耶和華啊，唯有你是天下萬國的上帝，你創造了天地。</span>
<span className="v" id="v16" data-v="16" data-xref="歷代志下 6:40; 詩篇 31:2; 列王紀下 19:4"> 耶和華啊，求你側耳垂聽！耶和華啊，求你睜眼察看！求你聽聽西拿基立派人來辱罵永活上帝的話。</span>
<span className="v" id="v17" data-v="17" data-xref="歷代志上 5:26; 約伯記 9:2; 哥林多前書 14:25"> 耶和華啊，亞述諸王確實掃滅列國，使他們的土地荒涼，</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行傳 17:29; 以賽亞書 44:9–20; 耶利米書 10:3–9"> 把他們的神像扔進火中燒毀。因為那些神像只是人用木頭石頭製造的，根本不是神明。</span>
<span className="v" id="v19" data-v="19" data-xref="詩篇 83:18; 列王紀上 8:43; 詩篇 67:1–2"> 我們的上帝耶和華啊，現在求你從亞述王手中拯救我們，讓天下萬國都知道唯有你耶和華是上帝。」</span>
</div>
</div>

## 以賽亞給希西迦的信息

<div className="bt">
<div className="bp poetry">
<span className="v" id="v20" data-v="20" data-xref="列王紀下 20:5; 歷代志下 32:20–21; 耶利米書 33:3"> 亞摩斯的兒子以賽亞派人對希西迦說：「以色列的上帝耶和華說，『我已經聽見你關於亞述王西拿基立的禱告。</span>
<span className="v" id="v21" data-v="21" data-xref="耶利米哀歌 2:13; 約伯記 16:4; 耶利米書 14:17"> 以下是耶和華對他的判語，<br /><span className="pl pl-1">「『處女錫安藐視你，嘲笑你；</span><br /><span className="pl pl-1">少女耶路撒冷朝你的背影搖頭。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="以賽亞書 5:24; 詩篇 71:22; 以賽亞書 30:11–12"> <span className="pl pl-1">你侮辱、褻瀆誰呢？</span><br /><span className="pl pl-1">你高聲謾罵、傲眼蔑視誰呢？</span><br /><span className="pl pl-1">是以色列的聖者！</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="列王紀下 18:17; 詩篇 20:7; 以賽亞書 10:18"> <span className="pl pl-1">你藉你的使者辱罵主，</span><br /><span className="pl pl-1">你說你率領許多戰車上到高山，</span><br /><span className="pl pl-1">上到黎巴嫩的頂峰，</span><br /><span className="pl pl-1">砍下最高的香柏樹和上好的松樹，</span><br /><span className="pl pl-1">征服最高的山和最美的樹林。</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="以賽亞書 19:6; 出埃及記 15:9; 撒母耳記下 17:13"> <span className="pl pl-1">你說你已在外邦之地挖井取水，</span><br /><span className="pl pl-1">已用腳掌踏乾埃及所有的河流。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v25" data-v="25" data-xref="以賽亞書 45:7; 以賽亞書 10:5–6; 以賽亞書 37:26–27"> <span className="pl pl-1">「『難道你沒有聽過這是我起初所定、</span><br /><span className="pl pl-1">亙古籌劃的嗎？</span><br /><span className="pl pl-1">如今我實現了所定的計劃：</span><br /><span className="pl pl-1">藉著你使堅城淪為廢墟。</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="耶利米書 51:30; 詩篇 102:11; 耶利米書 51:32"> <span className="pl pl-1">城中的居民軟弱無力，</span><br /><span className="pl pl-1">驚慌失措，羞愧難當，</span><br /><span className="pl pl-1">脆弱如野草和菜蔬，</span><br /><span className="pl pl-1">又像還未長大就被曬焦的房頂草。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v27" data-v="27" data-xref="以賽亞書 37:28–29; 耶利米書 23:23–24; 詩篇 139:1–11"> <span className="pl pl-1">「『你起你坐，你出你進，</span><br /><span className="pl pl-1">你向我發怒，我都知道。</span><br /></span>
<span className="v" id="v28" data-v="28" data-xref="以西結書 29:4; 以西結書 38:4; 列王紀下 19:33"> <span className="pl pl-1">因為你向我發怒，</span><br /><span className="pl pl-1">你狂傲的話傳到了我耳中，</span><br /><span className="pl pl-1">我要用鉤子鉤住你的鼻子，</span><br /><span className="pl pl-1">把嚼環放在你嘴裡，</span><br /><span className="pl pl-1">使你原路返回。』</span></span>
<span className="v" id="v29" data-v="29" data-xref="利未記 25:20–22; 列王紀下 20:8–9; 出埃及記 3:12"> 「希西迦啊，我要給你一個兆頭，你們今年要吃野生的，明年要吃自然生長的，後年要播種收割，栽種葡萄園，吃園中的果子。</span>
<span className="v" id="v30" data-v="30" data-xref="列王紀下 19:4; 以賽亞書 27:6; 歷代志下 32:22–23"> 猶大的倖存者要再次向下扎根，向上結果。</span>
<span className="v" id="v31" data-v="31" data-xref="以賽亞書 9:7; 羅馬書 11:5; 羅馬書 9:27"> 因為將有餘民從耶路撒冷出來，有倖存者從錫安山出來。萬軍之耶和華必熱切地成就這事。</span>
<span className="v" id="v32" data-v="32" data-xref="以賽亞書 8:7–10; 撒母耳記下 20:15; 以賽亞書 37:33–35"> 「至於亞述王，耶和華說，『他必不能進這城或向這裡射一箭，必不能手持盾牌兵臨城下或修築攻城的高臺。</span>
<span className="v" id="v33" data-v="33" data-xref="列王紀下 19:28; 列王紀下 19:36"> 他必原路返回，不得進入這城。這是耶和華說的。</span>
<span className="v" id="v34" data-v="34" data-xref="列王紀上 11:12–13; 列王紀下 20:6; 列王紀上 15:4"> 我必為自己和我僕人大衛的緣故而保護、拯救這城。』」</span>
<span className="v" id="v35" data-v="35" data-xref="歷代志下 32:21–22; 撒母耳記下 24:16; 出埃及記 12:29–30"> 當晚，耶和華的天使到亞述營中殺了十八萬五千人。人們清早起來，發現到處都是屍體。</span>
<span className="v" id="v36" data-v="36" data-xref="約拿書 1:2; 列王紀下 19:7; 列王紀下 19:33"> 亞述王西拿基立便拔營回國，住在尼尼微。</span>
<span className="v" id="v37" data-v="37" data-xref="以斯拉記 4:2; 創世記 8:4; 列王紀下 19:7"> 一天，亞述王在廟裡祭拜他的神明尼斯洛時，他兒子亞得米勒和沙利色用刀殺了他，逃往亞拉臘。他兒子以撒哈頓繼位。</span>
</div>

## 亞撒利雅做猶大王

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歷代志下 26:3–4; 列王紀下 14:21; 歷代志下 26:1"> 以色列王耶羅波安執政第二十七年，猶大王亞瑪謝的兒子亞撒利雅登基。</span>
<span className="v" id="v2" data-v="2" data-xref="歷代志下 26:3–4"> 他十六歲登基，在耶路撒冷執政五十二年。他母親叫耶可利雅，是耶路撒冷人。</span>
<span className="v" id="v3" data-v="3" data-xref="列王紀下 14:3–4; 列王紀下 12:2–3; 歷代志下 26:4"> 他事事效法他父親亞瑪謝，做耶和華視為正的事。</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀下 15:35; 列王紀下 14:4; 列王紀下 12:3"> 但他沒有拆除邱壇，人們仍在那裡獻祭燒香。</span>
<span className="v" id="v5" data-v="5" data-xref="利未記 13:46; 民數記 12:14; 列王紀下 7:3"> 耶和華降災給他，使他患了痲瘋病，一直到死。他被隔離在別的宮中，他兒子約坦管理王室，治理國家。</span>
<span className="v" id="v6" data-v="6" data-xref="歷代志下 26:5–15; 列王紀下 14:18"> 亞撒利雅其他的事及一切所為都記在《猶大列王史》上。</span>
<span className="v" id="v7" data-v="7" data-xref="歷代志下 26:23; 以賽亞書 6:1"> 亞撒利雅與祖先同眠後，葬在大衛城他的祖墳裡。他兒子約坦繼位。</span>
</div>
</div>

## 撒迦利雅做以色列王

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="列王紀下 14:16–17; 列王紀下 14:29–1; 列王紀下 14:21"> 猶大王亞撒利雅執政第三十八年，耶羅波安的兒子撒迦利雅在撒瑪利亞登基做以色列王，執政六個月。</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀下 14:24; 列王紀下 13:2; 列王紀下 13:11"> 他做耶和華視為惡的事，重蹈祖先的覆轍，沒有離開尼八的兒子耶羅波安使以色列人犯的那些罪。</span>
<span className="v" id="v10" data-v="10" data-xref="列王紀上 15:28; 列王紀下 15:14; 列王紀下 9:24"> 雅比的兒子沙龍謀反，當眾殺了撒迦利雅，篡位做了以色列王。</span>
<span className="v" id="v11" data-v="11" data-xref="列王紀下 14:28"> 撒迦利雅其他的事都記在《以色列列王史》上。</span>
<span className="v" id="v12" data-v="12" data-xref="列王紀下 10:30; 馬可福音 13:31; 列王紀下 13:13"> 這件事應驗了從前耶和華對耶戶的應許：「你的子孫必做以色列王，直到第四代。」<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="參列王紀下10·30。">a</a></sup></span>
</div>
</div>

## 沙龍做以色列王

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="列王紀下 15:1; 馬太福音 1:8–9; 列王紀下 15:8"> 猶大王烏西雅執政第三十九年，雅比的兒子沙龍登基，在撒瑪利亞執政一個月。</span>
<span className="v" id="v14" data-v="14" data-xref="列王紀上 14:17; 列王紀上 16:17; 列王紀上 16:15"> 迦底的兒子米拿現從得撒去撒瑪利亞殺了雅比的兒子沙龍，篡位做了以色列王。</span>
<span className="v" id="v15" data-v="15" data-xref="列王紀上 14:19; 列王紀上 14:29; 列王紀下 15:11"> 沙龍其他的事及其謀反的經過都記在《以色列列王史》上。</span>
</div>
</div>

## 米拿現做以色列王

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="列王紀下 8:12; 列王紀上 4:24; 何西阿書 13:16"> 那時，米拿現從得撒起兵攻打提斐薩及其四境。因為城中的居民不肯打開城門投降，他就殺光他們，剖開所有孕婦的肚腹。</span>
<span className="v" id="v17" data-v="17"> 猶大王亞撒利雅執政第三十九年，迦底的兒子米拿現在撒瑪利亞登基做以色列王，執政十年。</span>
<span className="v" id="v18" data-v="18"> 他做耶和華視為惡的事，一生沒有離開尼八的兒子耶羅波安使以色列人犯的那些罪。</span>
<span className="v" id="v19" data-v="19" data-xref="列王紀下 14:5; 歷代志上 5:25–26; 列王紀下 18:16"> 亞述王普勒犯境，米拿現獻給他六十八萬兩銀子，以獲得他的支持並鞏固自己的王位。</span>
<span className="v" id="v20" data-v="20" data-xref="列王紀下 18:14–17; 列王紀下 23:35; 列王紀下 17:3–4"> 這些銀子是米拿現向以色列的所有富戶徵收來的，每人十兩。於是亞述王從以色列境內退兵回國。</span>
<span className="v" id="v21" data-v="21"> 米拿現其他的事及一切所為都記在《以色列列王史》上。</span>
<span className="v" id="v22" data-v="22"> 米拿現與祖先同眠後，他兒子比加轄繼位。</span>
</div>
</div>

## 比加轄做以色列王

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="列王紀上 15:25; 列王紀上 22:51; 約伯記 20:5"> 猶大王亞撒利雅執政第五十年，米拿現的兒子比加轄在撒瑪利亞登基做以色列王，執政兩年。</span>
<span className="v" id="v24" data-v="24" data-xref="列王紀下 15:9; 列王紀下 15:18"> 他做耶和華視為惡的事，沒有離開尼八的兒子耶羅波安使以色列人犯的那些罪。</span>
<span className="v" id="v25" data-v="25" data-xref="歷代志下 28:6; 列王紀下 9:14; 列王紀上 16:9"> 比加轄的一名將軍、利瑪利的兒子比加謀反，率領五十名基列人在撒瑪利亞王宮裡刺殺了比加轄、亞珥歌伯和亞利耶。比加篡位做了以色列王。</span>
<span className="v" id="v26" data-v="26"> 比加轄其他的事及一切所為都記在《以色列列王史》上。</span>
</div>
</div>

## 比加做以色列王

<div className="bt">
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="以賽亞書 7:4; 以賽亞書 7:1; 列王紀下 15:23"> 猶大王亞撒利雅執政第五十二年，利瑪利的兒子比加在撒瑪利亞登基做以色列王，執政二十年。</span>
<span className="v" id="v28" data-v="28" data-xref="列王紀下 15:18; 列王紀下 13:6; 列王紀下 15:9"> 他做耶和華視為惡的事，沒有離開尼八的兒子耶羅波安使以色列人犯的那些罪。</span>
<span className="v" id="v29" data-v="29" data-xref="歷代志上 5:26; 列王紀下 17:6; 列王紀下 16:7"> 以色列王比加執政期間，亞述王提革拉·毗列色來犯，奪取了以雲、亞伯·伯·瑪迦、亞挪、基低斯、夏瑣、基列、加利利及拿弗他利全境，把那裡的居民擄往亞述。</span>
<span className="v" id="v30" data-v="30" data-xref="列王紀下 17:1; 歷代志下 28:4–6; 列王紀下 16:1"> 烏西雅的兒子約坦執政第二十年，以拉的兒子何細亞謀反，殺了利瑪利的兒子比加，篡位做了以色列王。</span>
<span className="v" id="v31" data-v="31"> 比加其他的事及一切所為都記在《以色列列王史》上。</span>
</div>
</div>

## 約坦做猶大王

<div className="bt">
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="歷代志上 3:12; 列王紀下 15:7; 歷代志下 27:1–9"> 利瑪利的兒子以色列王比加執政第二年，猶大王烏西雅的兒子約坦登基。</span>
<span className="v" id="v33" data-v="33" data-xref="歷代志下 27:1"> 他二十五歲登基，在耶路撒冷執政十六年。他母親叫耶路莎，是撒督的女兒。</span>
<span className="v" id="v34" data-v="34" data-xref="歷代志下 26:4–5; 列王紀下 15:3–4; 歷代志下 27:2"> 約坦事事效法他父親烏西雅，做耶和華視為正的事，</span>
<span className="v" id="v35" data-v="35" data-xref="列王紀下 12:3; 歷代志下 23:20; 歷代志下 27:3–9"> 但他沒有拆除邱壇，人們仍在那裡獻祭燒香。他執政期間，曾建造耶和華殿的上門。</span>
<span className="v" id="v36" data-v="36" data-xref="歷代志下 27:4–9; 列王紀下 15:6–7"> 約坦其他的事及一切所為都記在《猶大列王史》上。</span>
<span className="v" id="v37" data-v="37" data-xref="列王紀下 16:5; 以賽亞書 7:1; 路加福音 21:28"> 那時，耶和華差遣亞蘭王利汛和利瑪利的兒子比加攻打猶大。</span>
<span className="v" id="v38" data-v="38" data-xref="列王紀上 14:20; 列王紀上 14:31; 列王紀下 16:1"> 約坦與祖先同眠後，葬在大衛城他的祖墳裡。他兒子亞哈斯繼位。</span>
</div>
</div>

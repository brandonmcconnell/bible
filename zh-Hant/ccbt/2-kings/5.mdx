## 以利沙醫治乃縵

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 4:27; 羅馬書 15:18; 箴言 21:31"> 乃縵是亞蘭王的元帥，甚得亞蘭王器重，因為耶和華藉他使亞蘭人打了許多勝仗。他是英勇的戰士，只是患了痲瘋病。</span>
<span className="v" id="v2" data-v="2" data-xref="列王紀下 6:23; 列王紀下 13:20; 撒母耳記上 13:17–18"> 亞蘭人襲擊以色列時，曾擄回一個以色列少女，這少女做了乃縵妻子的婢女。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行傳 26:29; 路加福音 17:12–14; 民數記 11:29"> 有一天，她對主母說：「要是我主人去見撒瑪利亞的那位先知就好了！他一定能治好我主人的痲瘋病。」</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多前書 1:26–27; 約翰福音 4:28–29; 約翰福音 1:42–46"> 乃縵把這以色列少女的話告訴亞蘭王。</span>
<span className="v" id="v5" data-v="5" data-xref="士師記 14:12; 列王紀下 8:8–9; 民數記 22:17–18"> 亞蘭王說：「你去吧。我會寫信給以色列王。」於是，乃縵帶了六千八百兩銀子、一千四百兩金子和十套衣服，啟程前往以色列。</span>
<span className="v" id="v6" data-v="6"> 他帶給以色列王的信上寫著：「謹以此信介紹我的臣僕乃縵到你那裡，你要治好他的痲瘋病。」</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳記上 2:6; 列王紀上 20:7; 創世記 30:2"> 以色列王讀完信後，就撕裂衣服說：「難道我是上帝嗎？我能操縱人的生死嗎？這人竟叫我治好一個人的痲瘋病！他只是想找藉口攻打我。」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="列王紀上 18:36–37; 何西阿書 12:13; 以西結書 2:5"> 上帝的僕人以利沙聽說以色列王撕裂了衣服，便派人去對王說：「你為什麼撕裂衣服呢？讓那人到我這裡來，我要讓他知道以色列有先知。」</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行傳 16:37–39; 列王紀下 6:32; 以賽亞書 60:14"> 乃縵帶領車輛和馬匹到了以利沙的家，站在門口。</span>
<span className="v" id="v10" data-v="10" data-xref="約翰福音 9:7; 哥林多前書 6:11; 利未記 14:7"> 以利沙派使者出去對乃縵說：「你到約旦河裡洗七次，你的皮膚就會復原，並得到潔淨。」</span>
<span className="v" id="v11" data-v="11" data-xref="馬太福音 15:27; 路加福音 14:11; 馬太福音 8:8"> 乃縵卻怒沖沖地走了。他說：「我以為他一定會出來見我，為我站著求告他的上帝耶和華的名，用手在我的患處晃一晃，治好我的痲瘋病。</span>
<span className="v" id="v12" data-v="12" data-xref="馬可福音 1:9; 列王紀下 5:17; 列王紀下 2:14"> 大馬士革的亞巴拿河和法珥法河不比以色列所有的河都好嗎？難道我在那裡洗就不能得到潔淨嗎？」於是，他怒沖沖地轉身走了。</span>
<span className="v" id="v13" data-v="13" data-xref="列王紀下 6:21; 列王紀下 13:14; 列王紀下 2:12"> 他的僕人上前對他說：「我父啊，先知若吩咐你做一件大事，難道你不去做嗎？何況他只是說你去洗洗就可以潔淨！」</span>
<span className="v" id="v14" data-v="14" data-xref="約伯記 33:25; 路加福音 4:27; 路加福音 5:13"> 乃縵就去約旦河，照上帝僕人的話在河裡洗了七次，他的皮膚復原，像小孩子的一樣，他便潔淨了。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="但以理書 2:47; 但以理書 6:26–27; 約書亞記 2:9–11"> 乃縵率領全體隨從回到上帝的僕人那裡，站在他面前說：「我如今才知道，除了以色列，普天下沒有上帝。請你收下僕人的禮物。」</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀下 5:26; 列王紀下 5:20; 列王紀下 3:14"> 以利沙說：「我憑我事奉的永活的耶和華起誓，我決不接受。」乃縵再三請求，他仍不肯接受。</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行傳 26:18; 列王紀下 5:12; 羅馬書 14:1"> 乃縵說：「你如果不肯接受禮物，請容許僕人用兩頭騾子馱些泥土回去。從此以後，我不再獻燔祭或平安祭給其他神明，只獻給耶和華。</span>
<span className="v" id="v18" data-v="18" data-xref="列王紀下 7:2; 列王紀下 7:17; 列王紀下 17:35"> 但有一件事，願耶和華饒恕僕人。我主人進入臨門廟祭拜時，他會扶著我的手，這樣我也得隨著他彎腰。如果我在臨門廟裡彎腰，願耶和華饒恕我。」</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳記上 1:17; 馬可福音 5:34; 出埃及記 4:18"> 以利沙對他說：「你安心走吧。」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="列王紀下 4:12; 列王紀下 4:31; 列王紀下 6:31"> 乃縵剛走不遠，上帝僕人以利沙的侍者基哈西心想：「我主人沒有收亞蘭人乃縵帶來的禮物就讓他走了。我憑永活的耶和華起誓，我一定要追上去，向他要點東西。」</span>
<span className="v" id="v21" data-v="21" data-xref="路加福音 7:6–7; 列王紀下 9:17–22; 列王紀下 4:26"> 他便去追趕乃縵。乃縵見後面有人趕來，就下車迎接他，問他：「一切都好嗎？」</span>
<span className="v" id="v22" data-v="22" data-xref="列王紀下 5:5; 以賽亞書 59:3; 使徒行傳 5:3–4"> 基哈西答道：「一切都好。我主人派我來告訴你，剛才有兩位年輕的先知從以法蓮山區來見他，請你賜給他們七百兩銀子和兩套衣服。」</span>
<span className="v" id="v23" data-v="23" data-xref="列王紀下 12:10; 列王紀上 20:7; 列王紀下 2:17"> 乃縵說：「請你拿走一千四百兩銀子吧！」並再三請基哈西接受，然後把一千四百兩銀子裝進兩個袋子，連同兩套衣服，交給他的兩個僕人抬走，基哈西跟在他們後面。</span>
<span className="v" id="v24" data-v="24" data-xref="列王紀上 21:16; 約書亞記 7:11–12; 約書亞記 7:1"> 到了山岡，基哈西接過銀子和衣服，放進屋裡，便讓他們回去了。</span>
<span className="v" id="v25" data-v="25" data-xref="列王紀下 5:22; 創世記 16:8; 箴言 30:20"> 基哈西進去侍立在他主人以利沙面前，以利沙問他：「基哈西，你剛才去哪裡了？」基哈西答道：「僕人哪裡也沒去。」</span>
<span className="v" id="v26" data-v="26" data-xref="歌羅西書 2:5; 哥林多前書 5:3; 列王紀下 6:12"> 以利沙對他說：「那人下車回頭迎接你的時候，我的心不也在那裡嗎？現在豈是接受人家銀子、衣服、橄欖園、葡萄園、牛羊和僕婢的時候？</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及記 4:6; 民數記 12:10; 列王紀下 15:5"> 因此，你和你的後代會永遠沾染乃縵的痲瘋病。」基哈西離開以利沙時，患了痲瘋病，皮膚像雪一樣白。</span>
</div>

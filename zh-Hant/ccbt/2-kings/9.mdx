## 耶戶被立為以色列王

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳記上 10:1; 列王紀下 4:29; 列王紀上 1:39"> 以利沙先知叫來一個先知，吩咐他：「你要束上腰帶，拿著這瓶膏油去基列的拉末。</span>
<span className="v" id="v2" data-v="2" data-xref="列王紀下 9:5; 列王紀上 19:16–17; 列王紀下 9:11"> 到了以後，你去找寧示的孫子、約沙法的兒子耶戶，帶他離開同僚，進入密室，</span>
<span className="v" id="v3" data-v="3" data-xref="列王紀上 19:16; 出埃及記 29:7; 撒母耳記上 16:2"> 把這瓶膏油倒在他頭上，告訴他，『耶和華說，我膏立你為以色列王。』然後，你要馬上開門逃走，不可遲延。」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4"> 於是，那位年輕的先知啟程前往基列的拉末。</span>
<span className="v" id="v5" data-v="5" data-xref="士師記 3:19"> 到了那裡，他看見眾將領正坐在一起，便說：「將軍，我有話對你說。」耶戶說：「你想對我們哪一個說話？」他說：「將軍啊，我有話對你說。」</span>
<span className="v" id="v6" data-v="6" data-xref="歷代志下 22:7; 列王紀上 19:16; 列王紀下 9:3"> 耶戶便站起來，進入屋裡。他將膏油倒在耶戶頭上，說：「以色列的上帝耶和華說，『我膏立你做我以色列子民的王。</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀上 21:15; 列王紀上 18:4; 申命記 32:43"> 你要殺你主人亞哈的全家，這樣我就可以為我的僕人——眾先知及其他僕人報仇，他們被耶洗別殺害。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳記上 25:22; 申命記 32:36; 列王紀下 14:26"> 亞哈全家必滅亡，我要從以色列剷除他家所有的男子，不論奴隸還是自由人，</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀上 15:29; 列王紀上 21:22; 列王紀上 14:10–11"> 使他家像尼八的兒子耶羅波安家和亞希雅的兒子巴沙家一樣。</span>
<span className="v" id="v10" data-v="10" data-xref="列王紀上 21:23; 列王紀下 9:35–36; 列王紀下 9:3"> 耶洗別的屍體必在耶斯列的田間被狗吃，無人埋葬。』」說完這話，那位年輕的先知便開門逃跑了。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="耶利米書 29:26; 使徒行傳 26:24; 何西阿書 9:7"> 耶戶出來回到同僚那裡，一個人問他：「沒事吧？那瘋子為什麼來找你？」耶戶答道：「你們認得他，也知道他會說什麼。」</span>
<span className="v" id="v12" data-v="12"> 他們說：「我們不知道，你告訴我們吧！」耶戶說：「他告訴我，耶和華說膏立我做以色列王。」</span>
<span className="v" id="v13" data-v="13" data-xref="馬可福音 11:7–8; 列王紀上 1:39; 列王紀上 1:34"> 他們連忙將自己的衣服鋪在耶戶腳下的臺階上，吹響號角，高喊：「耶戶做王了！」</span>
</div>
</div>

## 以色列王約蘭被殺

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="列王紀下 8:28; 列王紀上 22:3; 列王紀上 16:16"> 寧示的孫子、約沙法的兒子耶戶背叛了約蘭。當時，約蘭率領全體以色列人在基列的拉末防禦亞蘭王哈薛，</span>
<span className="v" id="v15" data-v="15" data-xref="列王紀下 8:29; 撒母耳記上 27:9–11; 歷代志下 22:6"> 他與哈薛交戰受傷後，回到耶斯列養傷。耶戶對屬下說：「你們如果要我做王，就不要讓任何人逃出城去耶斯列報信。」</span>
<span className="v" id="v16" data-v="16" data-xref="歷代志下 22:6–7; 列王紀下 8:28–29"> 於是，耶戶駕車去了耶斯列，因為約蘭在耶斯列養傷，猶大王亞哈謝也在那裡探望他。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="撒母耳記上 16:4; 以西結書 33:2–9; 列王紀下 7:14"> 耶斯列城樓上的守望者看見耶戶的人馬朝耶斯列奔來，就報信說：「我見到一隊人馬！」約蘭下令：「派一個騎兵去看看他們是否為平安而來。」</span>
<span className="v" id="v18" data-v="18" data-xref="列王紀下 9:19; 列王紀下 9:22; 耶利米書 16:5"> 騎兵出去迎接耶戶，對他說：「王問你是否為平安而來。」耶戶說：「這與你何干？你跟在我後面。」守望者稟告說：「使者到了那裡，卻沒有回來。」</span>
<span className="v" id="v19" data-v="19"> 王又派一個騎兵到耶戶那裡，對他說：「王問你是否為平安而來。」耶戶說：「這與你何干？你跟在我後面。」</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳記下 18:27; 列王紀上 19:17; 傳道書 9:10"> 守望者又稟告說：「他到了那裡，也沒有回來。那人駕車很猛，像是寧示的孫子耶戶。」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="列王紀上 21:1–7; 歷代志下 22:7; 彌迦書 1:13"> 約蘭下令備車。以色列王約蘭和猶大王亞哈謝各乘自己的戰車去見耶戶。他們和耶戶在耶斯列人拿伯的田裡相遇。</span>
<span className="v" id="v22" data-v="22" data-xref="歷代志下 21:13; 那鴻書 3:4; 列王紀上 16:30–33"> 約蘭問他：「耶戶，你為平安而來嗎？」耶戶答道：「國中到處都是你母親耶洗別的偶像和邪術，怎能平安呢？」</span>
<span className="v" id="v23" data-v="23" data-xref="列王紀下 11:14; 歷代志下 23:13"> 約蘭調轉車頭逃跑，向亞哈謝大喊：「亞哈謝，他反了！」</span>
<span className="v" id="v24" data-v="24" data-xref="列王紀上 22:34; 箴言 21:30; 帖撒羅尼迦前書 5:3"> 耶戶張弓搭箭，射中約蘭的後背，箭穿透他的心臟，他倒斃在車上。</span>
<span className="v" id="v25" data-v="25" data-xref="列王紀上 21:19; 列王紀上 21:24–29; 以賽亞書 13:1"> 耶戶對將領畢甲說：「你去把他扔在耶斯列人拿伯的田裡。你該記得，你我一起駕車跟隨他父親亞哈的時候，耶和華曾預言亞哈的事說，</span>
<span className="v" id="v26" data-v="26" data-xref="列王紀上 21:19; 申命記 5:9; 歷代志下 25:4"> 『我昨天看見拿伯和他兒子們被殺，我必使你在這塊田裡受到報應，這是耶和華說的。』現在你照耶和華的話，把他扔在這塊田裡吧。」</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="士師記 1:27; 約書亞記 17:11; 列王紀下 8:29"> 猶大王亞哈謝見狀就沿著通往伯哈干的道路逃跑。耶戶在後面追，並大喊：「也把他射死！」他們在以伯蓮附近的姑珥坡把亞哈謝射傷在車上。他逃到米吉多後，傷重身亡。</span>
<span className="v" id="v28" data-v="28" data-xref="歷代志下 35:24; 列王紀下 23:30; 列王紀下 12:21"> 他的臣僕用車把他的屍體運回耶路撒冷，安葬在大衛城他的祖墳裡。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="歷代志下 21:18–19; 歷代志下 22:1–2; 列王紀下 8:24–25"> 亞哈的兒子約蘭執政第十一年，亞哈謝登基做猶大王。</span>
</div>
</div>

## 耶洗別被殺

<div className="bt">
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="耶利米書 4:30; 以西結書 23:40; 以西結書 24:17"> 耶戶去了耶斯列。耶洗別聞訊，便梳頭描眉，向窗外眺望。</span>
<span className="v" id="v31" data-v="31" data-xref="列王紀上 16:9–20"> 耶戶進城時，耶洗別高聲喊道：「謀殺主人的心利啊，平安嗎？」</span>
<span className="v" id="v32" data-v="32" data-xref="以斯帖記 2:15; 出埃及記 32:26; 歷代志下 11:12"> 耶戶抬頭望著窗口，喊道：「誰擁護我？誰？」有兩三個太監從窗口往外看他。</span>
<span className="v" id="v33" data-v="33" data-xref="彌迦書 7:10; 耶利米哀歌 1:15; 以賽亞書 25:10"> 耶戶說：「把她扔下來！」那幾個太監便把耶洗別扔下去，血濺在牆壁上和馬匹身上。耶戶駕車軋過她的身體，</span>
<span className="v" id="v34" data-v="34" data-xref="列王紀上 16:31; 列王紀上 21:25; 以賽亞書 65:15"> 他進入王宮，吃喝完畢，然後吩咐部下說：「處理掉那受咒詛的婦人，把她埋了，她畢竟是王的女兒。」</span>
<span className="v" id="v35" data-v="35" data-xref="使徒行傳 12:23; 以賽亞書 14:18–20; 約伯記 31:3"> 他們出去埋葬她，卻只找到她的頭骨、手掌和腳，</span>
<span className="v" id="v36" data-v="36" data-xref="列王紀上 21:23; 利未記 8:36; 列王紀下 14:25"> 便回去稟告耶戶。耶戶說：「這正應驗耶和華藉祂僕人提斯比人以利亞說的話，『狗必在耶斯列的田間吃耶洗別的肉，</span>
<span className="v" id="v37" data-v="37" data-xref="耶利米書 8:2; 詩篇 83:10; 耶利米書 16:4"> 耶洗別的屍體必像耶斯列田間的糞便，無人能認出那是耶洗別。』」</span>
</div>
</div>

</div>

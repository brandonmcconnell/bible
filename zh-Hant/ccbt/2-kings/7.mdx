## 撒瑪利亞城獲救

<div className="bt">
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="利未記 13:45–46; 民數記 5:2–4; 列王紀下 7:4"> 城門口有四個痲瘋病人，他們商量說：「我們為什麼坐在這裡等死呢？</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米書 14:18; 路加福音 15:17–19; 撒母耳記下 14:14"> 如果我們進城，城裡正遭遇饑荒，我們會餓死；但我們坐在這裡也是死，不如去投靠亞蘭軍。如果他們不殺我們，我們就能活命；不然的話，死就死吧！」</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 28:7; 申命記 32:25; 撒母耳記上 30:17"> 傍晚時分，他們動身去亞蘭人的營地，到了營地外邊，卻發現人影全無。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳記下 5:24; 以賽亞書 31:1; 列王紀上 10:29"> 原來，主使亞蘭人聽見大隊人馬和戰車的聲音。他們以為以色列王雇用了赫人的諸王和埃及人的諸王來攻營，</span>
<span className="v" id="v7" data-v="7" data-xref="箴言 28:1; 詩篇 48:4–6; 希伯來書 6:18"> 便在傍晚時分撇下帳篷、馬和驢，棄營而逃。</span>
<span className="v" id="v8" data-v="8" data-xref="馬太福音 13:44; 約書亞記 7:21; 馬太福音 25:18"> 那幾個痲瘋病人到了營地，走進一個帳篷，又吃又喝，把那裡的金銀和衣服拿走收藏起來，再回來進入另一個帳篷，把財物拿走收藏起來。</span>
<span className="v" id="v9" data-v="9" data-xref="以賽亞書 52:7; 腓立比書 2:4; 那鴻書 1:15"> 後來，他們彼此說：「我們這樣做不對。今天是個報好消息的日子，我們卻不作聲。如果等到天亮，我們會受懲罰的。走，我們給王報信去！」</span>
<span className="v" id="v10" data-v="10" data-xref="列王紀下 7:11; 馬可福音 13:34–35; 詩篇 127:1"> 他們就去喊城門守衛，對他們說：「我們到了亞蘭人的營中，裡面不見人影也沒有人聲，只有拴著的馬和驢，帳篷仍在那裡。」</span>
<span className="v" id="v11" data-v="11"> 城門守衛就高聲宣告消息，有人去稟告王。</span>
<span className="v" id="v12" data-v="12" data-xref="列王紀下 6:25–29; 約書亞記 8:4"> 王連夜起來，對臣僕說：「我告訴你們是怎麼回事。亞蘭人知道我們正遭遇饑荒，就故意離開軍營，埋伏在田野，等我們以色列人出城後，好活捉我們，並攻入城中。」</span>
<span className="v" id="v13" data-v="13" data-xref="列王紀下 7:4; 耶利米哀歌 4:9; 列王紀下 5:13"> 一個臣僕說：「不如派人騎著城中僅存的五匹馬出去打探一下。反正他們和城中剩下的以色列人一樣快要死了。」</span>
<span className="v" id="v14" data-v="14"> 他們預備了兩輛馬車，王便命人出去追蹤亞蘭軍，查明實情。</span>
<span className="v" id="v15" data-v="15" data-xref="以賽亞書 22:24; 馬太福音 24:16–18; 希伯來書 12:1"> 探子一路追到約旦河，沿路看見到處都是亞蘭軍倉皇逃走時丟棄的衣服和裝備，便回去稟告王。</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀下 7:1; 以賽亞書 33:4; 以賽亞書 33:23"> 於是，民眾出城搶掠亞蘭人的營地。那時，三公斤細麵粉只賣一兩銀子，六公斤大麥也只賣一兩銀子，正如耶和華所言。</span>
<span className="v" id="v17" data-v="17" data-xref="列王紀下 7:2; 列王紀下 6:32; 士師記 20:43"> 王派那位攙扶他的將領守在城門口維持秩序，那將領卻被湧出的人群踩死，應驗了上帝的僕人在王去見他時所說的話。</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 18:14; 列王紀下 7:1–2; 列王紀下 6:32"> 上帝的僕人曾對王說：「明天約這時候，在撒瑪利亞城門口，三公斤細麵粉只賣一兩銀子，六公斤大麥也只賣一兩銀子。」</span>
<span className="v" id="v19" data-v="19" data-xref="列王紀下 7:2"> 但那將領對上帝的僕人說：「即使耶和華打開天上的窗戶，也不可能發生這樣的事！」上帝的僕人說：「你必親眼看見，卻吃不到。」</span>
<span className="v" id="v20" data-v="20" data-xref="耶利米書 17:5–6; 歷代志下 20:20; 約伯記 20:23"> 這話果然應驗在他身上，他被人群踩死在城門口。</span>

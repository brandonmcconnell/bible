## 瑪拿西做猶大王

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以賽亞書 62:4; 歷代志下 32:33–9; 馬太福音 1:10"> 瑪拿西十二歲登基，在耶路撒冷執政五十五年。他母親叫謝西巴。</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 12:31; 歷代志下 36:14; 歷代志下 33:2–4"> 他做耶和華視為惡的事，效法耶和華在以色列人面前趕走的外族人的可憎行徑。</span>
<span className="v" id="v3" data-v="3" data-xref="列王紀下 18:4; 列王紀下 17:16; 申命記 17:3"> 他重建他父親希西迦拆毀的邱壇，效法以色列王亞哈為巴力築造祭壇，製造亞舍拉神像，並祭拜和供奉天上的萬象。</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀上 8:29; 撒母耳記下 7:13; 耶利米書 32:34"> 耶和華曾指著祂的殿說：「我的名必立在耶路撒冷，」他卻在耶和華的殿內建造異教的祭壇。</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀上 7:12; 列王紀下 23:4; 列王紀下 23:12"> 他在耶和華殿的兩個院子裡為天上萬象建造祭壇；</span>
<span className="v" id="v6" data-v="6" data-xref="列王紀下 17:17; 利未記 19:31; 利未記 18:21"> 他燒死自己的兒子，獻作祭物；他行邪術，占卜，求問靈媒和巫師，做了許多耶和華視為惡的事，惹耶和華發怒。</span>
<span className="v" id="v7" data-v="7" data-xref="歷代志下 7:16; 列王紀上 9:3; 撒母耳記下 7:13"> 他雕刻亞舍拉神像，放在耶和華的殿中。關於這殿，耶和華曾對大衛和他兒子所羅門說：「我從以色列各支派中選擇了這殿和耶路撒冷，我的名要永遠立在這裡。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳記下 7:10; 申命記 5:28–29; 詩篇 81:11–16"> 只要以色列人謹遵我對他們的一切吩咐和我僕人摩西交給他們的律法，我就不再把他們從我賜給他們祖先的土地上趕走。」</span>
<span className="v" id="v9" data-v="9" data-xref="箴言 29:12; 尼希米記 9:26; 列王紀上 14:16"> 可是他們不肯聽從。瑪拿西誘使他們作惡，比耶和華在以色列人面前所毀滅的各族更嚴重。</span>
<span className="v" id="v10" data-v="10" data-xref="馬太福音 23:34–37; 歷代志下 33:10; 歷代志下 36:15"> 於是，耶和華藉著祂的僕人——眾先知宣告：</span>
<span className="v" id="v11" data-v="11" data-xref="列王紀下 24:3–4; 列王紀上 21:26; 列王紀下 21:9"> 「瑪拿西王做的這些可憎之事，比以前住在這裡的亞摩利人更嚴重，使猶大人祭拜偶像，陷入罪中。</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米書 19:3; 撒母耳記上 3:11; 但以理書 9:12"> 所以，以色列的上帝耶和華說，『我要在耶路撒冷和猶大降下大災難，凡聽見這事的人都必耳鳴。</span>
<span className="v" id="v13" data-v="13" data-xref="阿摩司書 7:7–8; 耶利米哀歌 2:8; 以賽亞書 34:11"> 我要像懲罰撒瑪利亞和亞哈家一樣懲罰耶路撒冷。我要潔淨耶路撒冷，就像人擦淨盤子後倒扣過來。</span>
<span className="v" id="v14" data-v="14" data-xref="耶利米書 23:33; 列王紀下 19:4; 詩篇 89:38–45"> 我要撇棄我剩餘的子民，把他們交給敵人，任其擄掠。</span>
<span className="v" id="v15" data-v="15" data-xref="以西結書 20:30; 申命記 31:27; 以西結書 20:21"> 因為從他們祖先離開埃及那天起直到今天，他們一直做我視為惡的事，惹我發怒。』」</span>
<span className="v" id="v16" data-v="16" data-xref="民數記 35:33; 歷代志下 33:9; 列王紀下 21:11"> 瑪拿西不僅使猶大人犯罪，做耶和華視為惡的事，還濫殺無辜，使耶路撒冷血流遍地。</span>
<span className="v" id="v17" data-v="17" data-xref="列王紀下 20:20–21; 歷代志下 33:1–20"> 瑪拿西其他的事及一切所為，包括他犯的罪，都記在《猶大列王史》上。</span>
<span className="v" id="v18" data-v="18" data-xref="歷代志下 33:20; 列王紀下 21:26; 歷代志下 32:33"> 他與祖先同眠後，葬在他王宮的花園，即烏撒花園。他兒子亞們繼位。</span>
</div>
</div>

## 亞們做猶大王

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="歷代志下 33:21–23; 列王紀上 22:51; 歷代志上 3:14"> 亞們二十二歲登基，在耶路撒冷執政兩年。他母親叫米舒利密，是約提巴人哈魯斯的女兒。</span>
<span className="v" id="v20" data-v="20" data-xref="馬太福音 23:32; 列王紀下 21:11; 使徒行傳 7:51"> 他像他父親瑪拿西一樣做耶和華視為惡的事，</span>
<span className="v" id="v21" data-v="21"> 步他父親的後塵，祭拜和供奉同樣的偶像。</span>
<span className="v" id="v22" data-v="22" data-xref="列王紀下 22:17; 列王紀上 11:33; 歷代志上 28:9"> 他背棄他祖先的上帝耶和華，沒有遵行耶和華的教導。</span>
<span className="v" id="v23" data-v="23" data-xref="列王紀下 12:20; 列王紀下 14:19; 歷代志下 33:24–25"> 他的臣僕謀反，在王宮裡殺了他。</span>
<span className="v" id="v24" data-v="24" data-xref="列王紀下 14:5; 列王紀下 11:17; 列王紀下 14:21"> 民眾殺死那些背叛亞們王的人，讓他兒子約西亞接續他做王。</span>
<span className="v" id="v25" data-v="25" data-xref="列王紀下 20:20; 列王紀下 21:17"> 亞們其他的事都記在《猶大列王史》上。</span>
<span className="v" id="v26" data-v="26" data-xref="列王紀下 21:18; 馬太福音 1:10; 列王紀上 13:5"> 他葬在烏撒花園內他的墳墓裡，他兒子約西亞繼位。</span>
</div>

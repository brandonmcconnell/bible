## 以色列與摩押爭戰

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀下 1:17; 列王紀上 22:51; 列王紀下 8:16"> 猶大王約沙法執政第十八年，亞哈的兒子約蘭在撒瑪利亞登基做以色列王，執政十二年。</span>
<span className="v" id="v2" data-v="2" data-xref="列王紀下 10:18; 列王紀下 10:26–28; 列王紀上 21:25"> 他做耶和華視為惡的事，不過沒有他父母那麼敗壞，因為他除掉了他父親立的巴力神柱。</span>
<span className="v" id="v3" data-v="3" data-xref="列王紀上 14:16; 列王紀上 15:34; 列王紀下 15:18"> 可是他沉溺於尼八的兒子耶羅波安所犯的罪惡，使以色列人陷入罪中。</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳記下 8:2; 創世記 26:13–14; 約伯記 1:3"> 摩押王米沙以牧羊為業，每年向以色列王進貢十萬隻公綿羊的羊毛和十萬隻羊羔。</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀下 1:1; 列王紀下 8:20; 歷代志下 21:8–10"> 亞哈死後，米沙背叛了以色列王。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳記下 24:1–25; 撒母耳記上 11:8; 撒母耳記上 15:4"> 那時，約蘭王從撒瑪利亞出發，召集以色列全軍。</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀上 22:4; 歷代志下 22:10–12; 歷代志下 18:3"> 他還傳信給猶大王約沙法，說：「摩押王背叛了我，你願意和我一起去攻打摩押嗎？」約沙法回覆說：「我願意去。你我不分彼此，我的民就是你的民，我的馬就是你的馬。</span>
<span className="v" id="v8" data-v="8" data-xref="瑪拉基書 1:2–3; 民數記 21:4"> 我們從哪一條路進攻呢？」約蘭答道：「從以東的曠野。」</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀上 22:47; 民數記 20:2; 出埃及記 17:1"> 於是，以色列王跟猶大王和以東王聯合出兵。他們繞道行了七天，軍隊和隨行的牲畜都沒有水喝了。</span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 78:34–36; 以賽亞書 51:20; 以賽亞書 8:21"> 以色列王叫道：「唉！怎麼辦呢？耶和華招聚我們三王，是要把我們交給摩押王！」</span>
<span className="v" id="v11" data-v="11" data-xref="列王紀上 22:7; 列王紀上 19:21; 列王紀下 3:3"> 約沙法說：「這裡有沒有耶和華的先知？我們可以託他求問耶和華。」以色列王的一個臣僕答道：「沙法的兒子以利沙在這裡，以前他是以利亞的助手。」</span>
<span className="v" id="v12" data-v="12" data-xref="列王紀下 5:15; 列王紀下 2:21; 以賽亞書 60:14"> 約沙法說：「耶和華會藉他說話。」於是以色列王、約沙法和 以東王一起去見以利沙。</span>
<span className="v" id="v13" data-v="13" data-xref="列王紀上 22:6; 列王紀上 18:19; 列王紀上 22:10–11"> 以利沙對以色列王說：「我與你有什麼關係？你去問你父母的先知吧！」以色列王說：「不要這樣說，耶和華招聚我們三王，是要把我們交給摩押王！」</span>
<span className="v" id="v14" data-v="14" data-xref="列王紀下 5:16; 列王紀上 17:1; 歷代志下 19:3–4"> 以利沙說：「我事奉的是永活的萬軍之耶和華，我憑祂起誓，若不是看猶大王約沙法的情面，我決不理你，也不會見你。</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳記上 16:23; 以弗所書 5:18–19; 以西結書 1:3"> 現在你們給我找一個琴師來。」琴師彈琴的時候，耶和華的手按在以利沙身上，</span>
<span className="v" id="v16" data-v="16" data-xref="民數記 2:16–18; 列王紀下 4:3"> 他就說：「耶和華吩咐你們要在這山谷中到處挖溝，</span>
<span className="v" id="v17" data-v="17" data-xref="詩篇 107:35; 以賽亞書 41:17–18; 以賽亞書 48:21"> 因為耶和華說，『你們雖不見風，也不見雨，但這谷中必到處有水，人畜都會有水喝。』</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米書 32:27; 路加福音 1:37; 耶利米書 32:17"> 這對耶和華來說是微不足道的事，祂還要把摩押人交在你們手中。</span>
<span className="v" id="v19" data-v="19" data-xref="列王紀下 13:17; 申命記 20:19–20; 士師記 6:16"> 你們必攻陷所有的堅城重鎮，砍倒各種佳美的樹木，堵塞所有水泉，用石頭毀壞一切良田。」</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及記 29:39–40; 但以理書 9:21; 列王紀上 18:36"> 次日早晨，約在獻祭的時候，水從以東流來，遍地都是水。</span>
<span className="v" id="v21" data-v="21" data-xref="以弗所書 6:14; 列王紀上 20:11"> 摩押人聽說三王聯軍進攻他們，於是把凡能打仗的，不論老少都聚集起來，把守在邊界上。</span>
<span className="v" id="v22" data-v="22"> 第二天早晨，日光照在水面上，摩押人起來後，看見對面的水像血一樣紅，</span>
<span className="v" id="v23" data-v="23" data-xref="士師記 5:30; 出埃及記 15:9; 以賽亞書 10:14"> 便說：「那是血啊！一定是三王內訌，自相殘殺。摩押人啊，我們去搶財物吧！」</span>
<span className="v" id="v24" data-v="24" data-xref="帖撒羅尼迦前書 5:3–4; 約書亞記 8:20–22; 士師記 20:40–46"> 他們到了以色列營，以色列人奮起迎戰，殺得他們轉身逃跑。以色列人乘勝追擊，殺入摩押境內，擊殺摩押人，</span>
<span className="v" id="v25" data-v="25" data-xref="以賽亞書 16:7; 耶利米書 48:36; 耶利米書 48:31"> 摧毀城邑，人人拋擲石頭填滿所有良田，堵塞一切水泉，砍倒各種佳美樹木。摩押境內僅剩的吉珥·哈列設城也遭到甩石的士兵圍攻。</span>
<span className="v" id="v26" data-v="26" data-xref="列王紀下 3:9; 阿摩司書 2:1"> 摩押王見戰事不利，就率領七百名刀兵，企圖從以東王那邊突圍，但沒有成功。</span>
<span className="v" id="v27" data-v="27" data-xref="彌迦書 6:7; 申命記 12:31; 士師記 11:31"> 於是，他在城上將本應繼承自己王位的長子殺掉，獻為燔祭。有怒火向以色列人發作，他們便退兵回國了。</span>

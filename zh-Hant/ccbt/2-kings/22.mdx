## 約西亞做猶大王

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="約書亞記 15:39; 歷代志下 34:1–33; 耶利米書 1:2"> 約西亞八歲登基，在耶路撒冷執政三十一年。他母親叫耶底大，是波斯加人亞大雅的女兒。</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 5:32; 約書亞記 1:7; 列王紀下 18:3"> 約西亞做耶和華視為正的事，事事效法他祖先大衛，不偏不離。</span>
</div>
</div>

## 發現律法書

<div className="bt">
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="歷代志下 34:3–33"> 約西亞執政第十八年，他派米書蘭的孫子、亞薩利雅的兒子沙番書記去耶和華的殿，並吩咐他說：</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀下 12:4; 馬可福音 12:41–42; 歷代志下 34:9–18"> 「你去見大祭司希勒迦，讓他清點奉獻到耶和華殿中的銀子，那些銀子是殿門守衛從民眾收集來的。</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀下 12:11–14; 列王紀下 12:5; 歷代志下 24:12–13"> 然後把銀子交給負責修理耶和華殿的督工，由他們付給修理耶和華殿的工人，</span>
<span className="v" id="v6" data-v="6"> 就是木匠、瓦匠、石匠，並購買修理用的木料和鑿好的石頭。</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀下 12:15; 哥林多前書 4:2; 尼希米記 7:2"> 不用查核他們的賬目，因為他們都是忠誠可靠的人。」</span>
<span className="v" id="v8" data-v="8" data-xref="申命記 31:24–26; 歷代志下 34:14–28"> 大祭司希勒迦對書記沙番說：「我在耶和華的殿裡發現了律法書。」希勒迦把書卷交給沙番，他就讀了此書。</span>
<span className="v" id="v9" data-v="9" data-xref="以西結書 8:11; 列王紀下 25:22; 列王紀下 18:18"> 沙番書記稟告王說：「你的臣僕已經清空殿裡的銀子，交給殿裡的督工和工人。」</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米書 36:21; 耶利米書 13:18; 申命記 17:18–20"> 他又告訴王：「希勒迦祭司給了我一卷書。」沙番就在王面前誦讀這書。</span>
<span className="v" id="v11" data-v="11" data-xref="歷代志下 34:19; 約珥書 2:13; 列王紀下 22:19"> 王聽了律法書上的話，就撕裂衣服，</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米書 26:24; 列王紀下 25:22; 列王紀下 19:2–3"> 吩咐希勒迦祭司、沙番的兒子亞希甘、米該亞的兒子亞革波、書記沙番和王的臣僕亞撒雅：</span>
<span className="v" id="v13" data-v="13" data-xref="申命記 29:23–28; 申命記 31:17–18; 耶利米書 37:17"> 「你們去為我及民眾和整個猶大求問耶和華有關這書卷上的話。耶和華的烈怒已經臨到我們身上，因為我們的祖先沒有遵守這書卷上的話，沒有遵行這書卷上的吩咐。」</span>
</div>
</div>

## 戶勒妲的預言

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="士師記 4:4; 歷代志下 34:22; 彌迦書 6:4"> 於是，希勒迦祭司、亞希甘、亞革波、沙番和亞撒雅去見女先知戶勒妲。她是負責管理禮服的沙龍之妻，沙龍是哈珥哈斯的孫子、特瓦的兒子。戶勒妲住在耶路撒冷第二區。他們向她說明來意。</span>
<span className="v" id="v15" data-v="15" data-xref="列王紀下 1:6; 列王紀下 1:16; 耶利米書 23:28"> 她對他們說：「以色列的上帝耶和華要你們回去告訴差你們來見我的人，</span>
<span className="v" id="v16" data-v="16" data-xref="但以理書 9:11–14; 約書亞記 23:15; 申命記 29:27"> 耶和華說，『我要照猶大王所讀的那書上的一切話，降災難給這地方及這裡的居民。</span>
<span className="v" id="v17" data-v="17" data-xref="列王紀下 21:22; 耶利米書 7:20; 申命記 29:24–28"> 因為他們背棄我，給其他神明燒香，製造偶像惹我發怒，所以我的怒火要在這地方燃燒，絕不止息。</span>
<span className="v" id="v18" data-v="18" data-xref="歷代志下 34:26–28; 瑪拉基書 3:16–17; 以賽亞書 3:10"> 你們告訴差你們來求問耶和華的猶大王，至於你所聽見的那些話，以色列的上帝耶和華說，</span>
<span className="v" id="v19" data-v="19" data-xref="詩篇 51:17; 列王紀上 21:29; 以賽亞書 57:15"> 因為你聽到我對這地方及其居民的警告，知道這地方要受咒詛、淪為荒場，便悔改，在我面前謙卑，撕裂衣服，向我哭泣，我才垂聽你的禱告。這是我耶和華說的。</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 37:37; 以賽亞書 57:1–2; 歷代志上 17:11"> 我會讓你平安入土到你祖先那裡，你不會看到我要降給這地方的一切災難。』」他們便回去稟告王。</span>
</div>
</div>

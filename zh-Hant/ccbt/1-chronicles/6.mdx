## 利未的後裔

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 46:11; 出埃及記 6:16; 民數記 26:57"> 利未的兒子是革順、哥轄和米拉利。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 6:18; 出埃及記 6:21–24; 歷代志上 23:12"> 哥轄的兒子是暗蘭、以斯哈、希伯倫和烏薛。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 6:20; 利未記 10:1; 利未記 10:12"> 暗蘭的兒子是亞倫和摩西，女兒是米利暗。亞倫的兒子是拿答、亞比戶、以利亞撒和以他瑪。</span>
<span className="v" id="v4" data-v="4" data-xref="歷代志上 6:50; 出埃及記 6:25; 以斯拉記 7:1–5"> 以利亞撒生非尼哈，非尼哈生亞比書，</span>
<span className="v" id="v5" data-v="5"> 亞比書生布基，布基生烏西，</span>
<span className="v" id="v6" data-v="6"> 烏西生西拉希雅，西拉希雅生米拉約，</span>
<span className="v" id="v7" data-v="7"> 米拉約生亞瑪利雅，亞瑪利雅生亞希突，</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳記下 8:17; 撒母耳記下 15:27; 列王紀上 1:44"> 亞希突生撒督，撒督生亞希瑪斯，</span>
<span className="v" id="v9" data-v="9"> 亞希瑪斯生亞撒利雅，亞撒利雅生約哈難，</span>
<span className="v" id="v10" data-v="10" data-xref="歷代志下 3:4; 歷代志下 3:1; 列王紀上 6:1–7"> 約哈難生亞撒利雅，亞撒利雅在耶路撒冷、所羅門建的聖殿裡任祭司。</span>
<span className="v" id="v11" data-v="11" data-xref="以斯拉記 7:3"> 亞撒利雅生亞瑪利雅，亞瑪利雅生亞希突，</span>
<span className="v" id="v12" data-v="12" data-xref="尼希米記 11:11; 歷代志上 9:11"> 亞希突生撒督，撒督生沙龍，</span>
<span className="v" id="v13" data-v="13" data-xref="歷代志下 35:8; 列王紀下 22:12–14; 列王紀下 22:4"> 沙龍生希勒迦，希勒迦生亞撒利雅，</span>
<span className="v" id="v14" data-v="14" data-xref="列王紀下 25:18; 尼希米記 11:11; 撒迦利亞書 6:11"> 亞撒利雅生西萊雅，西萊雅生約薩答。</span>
<span className="v" id="v15" data-v="15" data-xref="哈該書 2:2; 列王紀下 25:18; 哈該書 1:1"> 在耶和華藉尼布甲尼撒擄掠猶大和耶路撒冷人的時候，約薩答也一起被擄去了。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="出埃及記 6:16; 歷代志上 6:1"> 利未的兒子是革順、哥轄和米拉利。</span>
<span className="v" id="v17" data-v="17" data-xref="歷代志上 23:7; 民數記 3:18; 民數記 3:21"> 革順的兒子一個叫立尼，一個叫示每。</span>
<span className="v" id="v18" data-v="18" data-xref="歷代志上 23:12; 歷代志上 6:2–3"> 哥轄的兒子是暗蘭、以斯哈、希伯倫、烏薛。</span>
<span className="v" id="v19" data-v="19" data-xref="歷代志上 23:21; 歷代志上 24:26; 出埃及記 6:19"> 米拉利的兒子是抹利和姆示。以上是利未人按宗族分的各家族。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="歷代志上 6:43"> 革順的兒子是立尼，立尼的兒子是雅哈，雅哈的兒子是薪瑪，</span>
<span className="v" id="v21" data-v="21"> 薪瑪的兒子是約亞，約亞的兒子是易多，易多的兒子是謝拉，謝拉的兒子是耶特賴。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="出埃及記 6:24; 歷代志上 6:18; 歷代志上 6:2"> 哥轄的兒子是亞米拿達，亞米拿達的兒子是可拉，可拉的兒子是亞惜，</span>
<span className="v" id="v23" data-v="23"> 亞惜的兒子是以利加拿，以利加拿的兒子是以比雅撒，以比雅撒的兒子是亞惜，</span>
<span className="v" id="v24" data-v="24"> 亞惜的兒子是他哈，他哈的兒子是烏列，烏列的兒子是烏西雅，烏西雅的兒子是少羅。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及記 6:24; 歷代志上 6:35–36"> 以利加拿的兒子是亞瑪賽和亞希摩。</span>
<span className="v" id="v26" data-v="26" data-xref="撒母耳記上 1:1; 歷代志上 6:35"> 亞希摩的兒子是以利加拿，以利加拿的兒子是瑣菲，瑣菲的兒子是拿哈，</span>
<span className="v" id="v27" data-v="27" data-xref="撒母耳記上 1:1; 撒母耳記上 1:19–20"> 拿哈的兒子是以利押，以利押的兒子是耶羅罕，耶羅罕的兒子是以利加拿，以利加拿的兒子是撒母耳。</span>
<span className="v" id="v28" data-v="28" data-xref="歷代志上 6:33; 撒母耳記上 8:2"> 撒母耳的長子是約珥，次子是亞比亞。</span>
<span className="v" id="v29" data-v="29" data-xref="歷代志上 6:19; 民數記 3:33"> 米拉利的兒子是抹利，抹利的兒子是立尼，立尼的兒子是示每，示每的兒子是烏撒，</span>
<span className="v" id="v30" data-v="30"> 烏撒的兒子是示米亞，示米亞的兒子是哈基雅，哈基雅的兒子是亞帥雅。</span>
</div>
</div>

## 聖殿的歌樂手

<div className="bt">
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="撒母耳記下 6:17; 歷代志上 15:25–1; 歷代志上 15:16–22"> 約櫃安放在耶和華的殿中之後，大衛便派人在那裡負責歌樂。</span>
<span className="v" id="v32" data-v="32" data-xref="詩篇 135:1–3; 列王紀上 8:6–13; 以斯拉記 6:18"> 他們按班次供職，在會幕歌唱，一直到所羅門在耶路撒冷建造了耶和華的殿。</span>
<span className="v" id="v33" data-v="33" data-xref="歷代志上 6:28; 歷代志上 15:17; 歷代志上 25:1–5"> 以下是負責歌樂的人及其後代：<br />哥轄的後代有希幔。希幔是約珥的兒子，約珥是撒母耳的兒子，</span>
<span className="v" id="v34" data-v="34"> 撒母耳是以利加拿的兒子，以利加拿是耶羅罕的兒子，耶羅罕是以利業的兒子，以利業是陀亞的兒子，</span>
<span className="v" id="v35" data-v="35"> 陀亞是蘇弗的兒子，蘇弗是以利加拿的兒子，以利加拿是瑪哈的兒子，瑪哈是亞瑪賽的兒子，</span>
<span className="v" id="v36" data-v="36"> 亞瑪賽是以利加拿的兒子，以利加拿是約珥的兒子，約珥是亞撒利雅的兒子，亞撒利雅是西番雅的兒子，</span>
<span className="v" id="v37" data-v="37" data-xref="詩篇 45:1; 民數記 26:10–11; 出埃及記 6:21–24"> 西番雅是他哈的兒子，他哈是亞惜的兒子，亞惜是以比雅撒的兒子，以比雅撒是可拉的兒子，</span>
<span className="v" id="v38" data-v="38" data-xref="民數記 3:19; 歷代志上 16:1"> 可拉是以斯哈的兒子，以斯哈是哥轄的兒子，哥轄是利未的兒子，利未是以色列的兒子。</span>
<span className="v" id="v39" data-v="39" data-xref="尼希米記 7:44; 以斯拉記 2:41; 詩篇 75:1"> 希幔的族兄和助手亞薩是比利迦的兒子，比利迦是示米亞的兒子，</span>
<span className="v" id="v40" data-v="40"> 示米亞是米迦勒的兒子，米迦勒是巴西雅的兒子，巴西雅是瑪基雅的兒子，</span>
<span className="v" id="v41" data-v="41"> 瑪基雅是伊特尼的兒子，伊特尼是謝拉的兒子，謝拉是亞大雅的兒子，</span>
<span className="v" id="v42" data-v="42"> 亞大雅是以探的兒子，以探是薪瑪的兒子，薪瑪是示每的兒子，</span>
<span className="v" id="v43" data-v="43" data-xref="出埃及記 6:16; 歷代志上 6:16–17; 創世記 46:11"> 示每是雅哈的兒子，雅哈是革順的兒子，革順是利未的兒子。</span>
<span className="v" id="v44" data-v="44" data-xref="詩篇 89:1; 歷代志上 15:17; 歷代志上 25:1"> 希幔和亞薩的族兄和助手有米拉利的後代以探。以探是基示的兒子，基示是亞伯底的兒子，亞伯底是瑪鹿的兒子，</span>
<span className="v" id="v45" data-v="45"> 瑪鹿是哈沙比雅的兒子，哈沙比雅是亞瑪謝的兒子，亞瑪謝是希勒迦的兒子，</span>
<span className="v" id="v46" data-v="46"> 希勒迦是暗西的兒子，暗西是巴尼的兒子，巴尼是沙麥的兒子，</span>
<span className="v" id="v47" data-v="47" data-xref="約書亞記 21:7; 出埃及記 6:19; 歷代志上 23:21"> 沙麥是末力的兒子，末力是姆示的兒子，姆示是米拉利的兒子，米拉利是利未的兒子。</span>
<span className="v" id="v48" data-v="48" data-xref="歷代志上 23:2; 民數記 3:1–4; 民數記 18:1–32"> 希幔和亞薩的同族弟兄利未人都被派到上帝殿的會幕擔任各種職務。</span>
</div>
<div className="bp">
<span className="v" id="v49" data-v="49" data-xref="利未記 4:20; 出埃及記 27:1–8; 出埃及記 30:1–7"> 亞倫和他的後代在祭壇和香壇上獻祭燒香，負責至聖所裡的各種工作，為以色列人贖罪，正如上帝的僕人摩西的吩咐。</span>
<span className="v" id="v50" data-v="50" data-xref="利未記 10:16; 歷代志上 24:1; 民數記 20:26–28"> 以下是亞倫的後代：以利亞撒、非尼哈、亞比書、</span>
<span className="v" id="v51" data-v="51"> 布基、烏西、西拉希雅、</span>
<span className="v" id="v52" data-v="52"> 米拉約、亞瑪利雅、亞希突、</span>
<span className="v" id="v53" data-v="53" data-xref="撒母耳記下 8:17; 以西結書 44:15; 撒母耳記下 15:35–36"> 撒督、亞希瑪斯。</span>
</div>
</div>

## 利未人住的地方

<div className="bt">
<div className="bp">
<span className="v" id="v54" data-v="54" data-xref="創世記 25:16; 約書亞記 21:10; 約書亞記 21:3–8"> 以下是亞倫的後代哥轄族人分到的地方：<br />他們抽中第一籤，</span>
<span className="v" id="v55" data-v="55" data-xref="約書亞記 14:13; 約書亞記 21:11–13; 約書亞記 15:13"> 得到了猶大境內的希伯崙城及其周圍的草場，</span>
<span className="v" id="v56" data-v="56" data-xref="約書亞記 15:13; 約書亞記 14:13"> 但城外的田地和村莊分給了耶孚尼的兒子迦勒。</span>
<span className="v" id="v57" data-v="57" data-xref="約書亞記 21:13–14; 約書亞記 15:48; 約書亞記 10:29"> 亞倫的子孫得到避難城希伯崙、立拿及其周圍的草場、雅提珥、以實提莫及其周圍的草場、</span>
<span className="v" id="v58" data-v="58" data-xref="約書亞記 10:3; 約書亞記 15:49; 約書亞記 12:13"> 希崙、底璧、</span>
<span className="v" id="v59" data-v="59" data-xref="約書亞記 21:16; 約書亞記 15:42; 撒母耳記上 6:12–19"> 亞珊、伯·示麥及這些城邑周圍的草場。</span>
<span className="v" id="v60" data-v="60" data-xref="耶利米書 1:1; 列王紀上 2:26; 耶利米書 11:23"> 他們還得到了便雅憫支派的迦巴、阿勒篾、亞拿突及這些城邑周圍的草場。他們各宗族所得的城邑共十三座。</span>
</div>
<div className="bp">
<span className="v" id="v61" data-v="61" data-xref="約書亞記 21:4–5; 歷代志上 6:18; 約書亞記 21:20–26"> 哥轄族其餘的人從瑪拿西半個支派中抽籤分到了十座城。</span>
<span className="v" id="v62" data-v="62" data-xref="約書亞記 21:27–33; 歷代志上 6:71–76; 出埃及記 2:22"> 革順各宗族的人從以薩迦、亞設和拿弗他利各支派，以及瑪拿西支派的巴珊地區分到了十三座城。</span>
<span className="v" id="v63" data-v="63" data-xref="約書亞記 21:7; 約書亞記 21:34–40; 民數記 3:20"> 米拉利各宗族的人從呂便、迦得和西布倫各支派抽籤分到十二座城。</span>
<span className="v" id="v64" data-v="64" data-xref="約書亞記 21:41–42; 約書亞記 21:3; 民數記 35:1–8"> 以色列人把這些城邑及其周圍的草場分給了利未人。</span>
<span className="v" id="v65" data-v="65" data-xref="歷代志上 6:57–60"> 以上提到的猶大、西緬和便雅憫各支派的城邑也是用抽籤的方式分給他們的。</span>
<span className="v" id="v66" data-v="66" data-xref="約書亞記 21:20–26"> 哥轄的一些宗族從以法蓮支派分到城邑，</span>
<span className="v" id="v67" data-v="67" data-xref="約書亞記 21:21; 創世記 33:18; 創世記 35:4"> 其中有以法蓮山區的避難城示劍及其周圍的草場，還有基色、</span>
<span className="v" id="v68" data-v="68" data-xref="約書亞記 21:22; 約書亞記 16:5; 撒母耳記上 13:18"> 約緬、伯·和崙、</span>
<span className="v" id="v69" data-v="69" data-xref="約書亞記 10:12; 約書亞記 21:24–25"> 亞雅崙和迦特·臨門及這些城邑周圍的草場。</span>
<span className="v" id="v70" data-v="70" data-xref="約書亞記 21:25; 約書亞記 17:11"> 哥轄族其餘的人從瑪拿西半個支派中得到了亞乃、比連城及其周圍的草場。</span>
<span className="v" id="v71" data-v="71" data-xref="約書亞記 21:27; 約書亞記 9:10; 約書亞記 20:8"> 革順族從瑪拿西半個支派中得到了巴珊的哥蘭及其周圍的草場，亞斯她錄及其周圍的草場。</span>
<span className="v" id="v72" data-v="72" data-xref="約書亞記 21:28–29; 約書亞記 21:32; 約書亞記 19:37"> 他們從以薩迦支派得到了基低斯、大比拉、</span>
<span className="v" id="v73" data-v="73"> 拉末、亞年及這些城邑周圍的草場。</span>
<span className="v" id="v74" data-v="74" data-xref="約書亞記 19:26; 約書亞記 21:30"> 他們從亞設支派得到了瑪沙、押頓、</span>
<span className="v" id="v75" data-v="75" data-xref="約書亞記 21:31"> 戶割、利合及這些城邑周圍的草場。</span>
<span className="v" id="v76" data-v="76" data-xref="約書亞記 21:32; 約書亞記 19:37; 士師記 4:6"> 他們從拿弗他利支派得到了加利利的基低斯、哈們、基列亭及這些城邑周圍的草場。</span>
<span className="v" id="v77" data-v="77" data-xref="約書亞記 21:34–35"> 米拉利族的人從西布倫支派得到了臨摩挪和他泊城及其周圍的草場；</span>
<span className="v" id="v78" data-v="78" data-xref="約書亞記 20:8; 約書亞記 21:36–37; 申命記 4:41–43"> 從約旦河東岸、耶利哥對面的呂便支派得到了曠野中的比悉、雅雜、</span>
<span className="v" id="v79" data-v="79"> 基底莫、米法押及這些城邑的草場；</span>
<span className="v" id="v80" data-v="80" data-xref="創世記 32:2; 列王紀下 9:1; 約書亞記 21:38–39"> 從迦得支派得到了基列的拉末、瑪哈念、</span>
<span className="v" id="v81" data-v="81" data-xref="約書亞記 21:39; 民數記 21:32; 民數記 32:3"> 希實本、雅謝及這些城邑周圍的草場。</span>
</div>

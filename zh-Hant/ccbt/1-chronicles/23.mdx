## 利未人的職務

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歷代志上 29:28; 歷代志上 28:5; 列王紀上 1:33–39"> 大衛年紀老邁，壽數將盡，就立他兒子所羅門為以色列王。</span>
<span className="v" id="v2" data-v="2" data-xref="約書亞記 24:1; 歷代志下 34:29–30; 歷代志上 13:1"> 他召集了以色列的眾首領、祭司和利未人。</span>
<span className="v" id="v3" data-v="3" data-xref="歷代志上 23:24; 民數記 4:2–49"> 凡三十歲以上的利未人都在統計之列，共有三萬八千男子，</span>
<span className="v" id="v4" data-v="4" data-xref="歷代志下 19:8; 申命記 16:18; 歷代志上 26:29–31"> 其中有兩萬四千人在耶和華的殿裡司職，六千人做官長和審判官，</span>
<span className="v" id="v5" data-v="5" data-xref="歷代志下 29:25–26; 歷代志下 8:14; 詩篇 87:7"> 四千人守門，四千人用大衛提供的樂器頌讚耶和華。</span>
<span className="v" id="v6" data-v="6" data-xref="歷代志下 8:14; 歷代志上 6:1; 歷代志上 6:16"> 大衛將利未人革順、哥轄和米拉利的子孫分成班次。</span>
<span className="v" id="v7" data-v="7" data-xref="歷代志上 26:21; 出埃及記 6:17; 歷代志上 6:17–20"> 革順的兒子有拉但和示每。</span>
<span className="v" id="v8" data-v="8" data-xref="歷代志上 6:33–34; 歷代志上 15:20–21; 歷代志上 15:7"> 拉但有長子耶歇，還有西坦和約珥，共三個兒子，</span>
<span className="v" id="v9" data-v="9"> 都是拉但族的族長。示每的兒子有示羅密、哈薛和哈蘭三人。</span>
<span className="v" id="v10" data-v="10"> 示每的兒子還有雅哈、細撒、耶烏施和比利亞四人。</span>
<span className="v" id="v11" data-v="11"> 雅哈是長子，細撒是次子。耶烏施和比利亞的子孫不多，所以合為一族。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及記 6:18; 民數記 3:27; 民數記 26:58"> 哥轄有暗蘭、以斯哈、希伯倫、烏薛四個兒子。</span>
<span className="v" id="v13" data-v="13" data-xref="申命記 21:5; 出埃及記 6:20; 撒母耳記上 2:28"> 暗蘭的兒子是亞倫和摩西。亞倫和他的子孫永遠被分別出來事奉耶和華，向祂獻至聖之物，在祂面前燒香，奉祂的名祝福，直到永遠。</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 33:1; 詩篇 90:1; 歷代志上 26:23–25"> 上帝的僕人摩西的子孫歸在利未支派的名下。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及記 18:3–4; 出埃及記 2:22; 出埃及記 4:20"> 摩西的兒子是革舜和以利以謝。</span>
<span className="v" id="v16" data-v="16" data-xref="歷代志上 26:24; 歷代志上 25:20; 歷代志上 24:20"> 革舜的長子是細布業。</span>
<span className="v" id="v17" data-v="17" data-xref="歷代志上 26:25"> 以利以謝只有一個兒子利哈比雅，但利哈比雅子孫眾多。</span>
<span className="v" id="v18" data-v="18" data-xref="歷代志上 26:26; 歷代志上 24:22"> 以斯哈的長子是示羅密。</span>
<span className="v" id="v19" data-v="19" data-xref="歷代志上 24:23; 歷代志上 15:9; 歷代志上 23:12"> 希伯倫的長子是耶利雅，次子是亞瑪利亞，三子是雅哈悉，四子是耶加緬。</span>
<span className="v" id="v20" data-v="20"> 烏薛的長子是米迦，次子是耶西雅。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及記 6:19; 歷代志上 6:20; 歷代志上 24:26–30"> 米拉利的兒子是抹利和姆示。抹利的兒子是以利亞撒和基士。</span>
<span className="v" id="v22" data-v="22" data-xref="歷代志上 24:28; 民數記 36:6–8"> 以利亞撒終生沒有兒子，只有女兒，同族人基士的兒子娶了她們為妻。</span>
<span className="v" id="v23" data-v="23" data-xref="歷代志上 24:30"> 姆示的三個兒子是末力、以得和耶利摩。</span>
<span className="v" id="v24" data-v="24" data-xref="民數記 10:17; 民數記 10:21; 歷代志上 23:3"> 以上是利未各宗族的子孫，他們登記在各自族長的名下，凡二十歲以上的男子都在耶和華的殿裡任職。</span>
<span className="v" id="v25" data-v="25" data-xref="詩篇 132:13–14; 歷代志上 22:18; 撒母耳記下 7:11"> 大衛說：「以色列的上帝耶和華已使祂的子民安享太平，祂永遠住在耶路撒冷。</span>
<span className="v" id="v26" data-v="26" data-xref="民數記 4:5; 民數記 7:9; 民數記 4:15"> 利未人再不用抬聖幕和其中的器皿了。」</span>
<span className="v" id="v27" data-v="27" data-xref="歷代志上 23:24; 詩篇 72:20; 撒母耳記下 23:1"> 按照大衛臨終時的囑咐，二十歲以上的利未人都在統計之列。</span>
<span className="v" id="v28" data-v="28" data-xref="歷代志下 35:3–6; 歷代志下 31:11; 歷代志下 35:11–14"> 他們的任務是幫助亞倫的子孫在耶和華的殿裡司職，管理殿的院子和廂房，負責潔淨聖物等事務。</span>
<span className="v" id="v29" data-v="29" data-xref="利未記 19:35–36; 出埃及記 25:30; 利未記 6:20–23"> 他們還負責供餅、做素祭的細麵粉、無酵薄餅的調和、烤製、分量和尺寸。</span>
<span className="v" id="v30" data-v="30" data-xref="詩篇 92:1–3; 以斯拉記 3:10–11; 歷代志上 9:33"> 他們每天早晚要肅立、頌讚耶和華，</span>
<span className="v" id="v31" data-v="31" data-xref="以賽亞書 1:13–14; 民數記 28:1–29; 民數記 10:10"> 每逢安息日、朔日<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「朔日」即每月初一。">a</a></sup>或其他節期，他們要按照規定的數目將燔祭獻給耶和華。</span>
<span className="v" id="v32" data-v="32" data-xref="民數記 1:53; 民數記 3:38; 民數記 3:6–9"> 他們負責看守會幕和聖所，幫助他們的親族亞倫的子孫在耶和華的殿裡供職。</span>

## 大衛做以色列人的王

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳記下 5:1–16; 歷代志上 12:23–40; 士師記 9:2"> 以色列人都聚集到希伯崙來見大衛，對他說：「看啊，我們是你的骨肉同胞。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳記下 5:2; 約翰福音 10:4; 詩篇 78:71"> 從前，掃羅做王的時候，率領以色列人出征打仗的是你。你的上帝耶和華也曾應許讓你做祂以色列子民的牧者和首領。」</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳記上 16:12–13; 撒母耳記上 16:1; 撒母耳記下 5:3"> 以色列的長老都到希伯崙見大衛王，大衛與他們在耶和華面前立約，他們膏立大衛做以色列的王，這應驗了耶和華藉撒母耳所說的話。</span>
<span className="v" id="v4" data-v="4" data-xref="士師記 1:21; 創世記 15:21; 約書亞記 15:8"> 大衛和以色列眾人來到耶路撒冷，即耶布斯。那時耶布斯人住在那裡。</span>
<span className="v" id="v5" data-v="5" data-xref="歷代志下 5:2; 列王紀上 8:1; 詩篇 87:2"> 耶布斯人對大衛說：「你攻不進來。」然而，大衛攻取了錫安的堡壘，即後來的大衛城。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳記下 8:16; 撒母耳記下 20:23; 撒母耳記下 3:27"> 大衛說：「誰先攻打耶布斯人，誰就做元帥。」洗魯雅的兒子約押首先進攻，於是就做了元帥。</span>
<span className="v" id="v7" data-v="7" data-xref="歷代志上 11:5; 撒母耳記下 5:7; 詩篇 2:6"> 大衛住在堡壘裡，因此那堡壘就叫大衛城。</span>
<span className="v" id="v8" data-v="8" data-xref="士師記 9:6; 列王紀上 11:27; 列王紀下 12:20"> 大衛又從米羅開始，在四圍修建城牆，其餘的部分由約押修建。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳記下 3:1; 以賽亞書 41:10; 歷代志上 9:20"> 大衛日漸強盛，因為萬軍之耶和華與他同在。</span>
</div>
</div>

## 大衛的勇士

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="歷代志上 11:3; 撒母耳記上 16:1; 歷代志上 12:38"> 以下是大衛手下眾勇士的統領，他們和以色列百姓竭力擁護大衛做王，正如耶和華對以色列的應許。</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳記下 23:8; 歷代志上 27:2; 歷代志上 12:18"> 大衛的勇士有哈革摩尼人雅朔班，他是三勇士之首，曾在一次交戰中揮矛刺死了三百人。</span>
<span className="v" id="v12" data-v="12" data-xref="歷代志上 27:4; 撒母耳記下 23:17–19; 撒母耳記下 23:23"> 其次是亞哈希人朵多的兒子以利亞撒，他是三勇士之一。</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳記下 23:11–12; 撒母耳記上 17:1"> 他曾在巴斯·大閔與大衛抵抗非利士人。那裡有一塊大麥田，以色列人戰敗逃跑，</span>
<span className="v" id="v14" data-v="14" data-xref="詩篇 144:10; 列王紀下 5:1; 撒母耳記上 14:23"> 他們卻站在田中間堅守麥田，擊殺非利士人。耶和華使以色列人大獲全勝。</span>
<span className="v" id="v15" data-v="15" data-xref="歷代志上 14:9; 撒母耳記下 5:18; 以賽亞書 17:5"> 一次，三十位統領中有三位到亞杜蘭洞附近的磐石那裡見大衛，當時非利士軍隊在利乏音谷紮營。</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳記上 10:5; 撒母耳記上 13:4; 撒母耳記上 13:23"> 那時大衛留守在堡壘裡，非利士人的駐軍在伯利恆。</span>
<span className="v" id="v17" data-v="17" data-xref="約翰福音 4:14; 以賽亞書 12:3; 撒母耳記下 23:15–16"> 大衛渴了，說：「但願有人給我打些伯利恆城門旁的井水喝！」</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行傳 21:13; 撒母耳記上 19:5; 使徒行傳 20:24"> 這三位勇士就衝過非利士人的營地，到伯利恆城門旁的井打水，帶回來給大衛。大衛卻不肯喝，他把水澆奠在耶和華面前，</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳記下 23:17; 詩篇 72:14; 士師記 9:17"> 說：「我的上帝啊！這三人冒死去打水，這些水就像是他們的血，我決不能喝。」因此，大衛不肯喝。這是三勇士的事蹟。</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳記上 26:6; 歷代志上 2:16; 撒母耳記下 20:6"> 約押的兄弟亞比篩是這三位勇士的統領，他曾揮矛刺死三百人，在三勇士中出了名，</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多前書 15:41; 馬太福音 13:8"> 最有聲望，因此做了他們的統領，只是不及前三位勇士。</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳記下 23:20–23; 撒母耳記下 8:18; 約書亞記 15:21"> 甲薛人耶何耶大的兒子比拿雅是位勇士，做過非凡的事。他曾殺死摩押的兩個勇猛戰士，也曾在下雪天跳進坑中殺死一頭獅子，</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳記上 17:7; 撒母耳記上 17:4; 申命記 3:11"> 還殺死一個兩米多高的埃及巨人。當時埃及人拿著織布機軸般粗的長矛，比拿雅拿著棍子迎戰，他奪了對方的長矛，用那矛刺死了對方。</span>
<span className="v" id="v24" data-v="24"> 這是耶何耶大的兒子比拿雅的事蹟，他像那三位勇士一樣贏得了名聲。</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳記下 20:23"> 他比那三十勇士更有聲望，只是不及前三位勇士。大衛派他作護衛長。</span>
<span className="v" id="v26" data-v="26" data-xref="歷代志上 27:7; 撒母耳記下 21:19; 撒母耳記下 2:18–23"> 其他勇士有：約押的兄弟亞撒黑、伯利恆人朵多的兒子伊勒哈難、</span>
<span className="v" id="v27" data-v="27" data-xref="撒母耳記下 23:25–26"> 哈律人沙瑪、比倫人希利斯、</span>
<span className="v" id="v28" data-v="28" data-xref="歷代志上 27:12; 歷代志上 27:9; 撒母耳記下 23:27"> 提哥亞人益吉的兒子以拉、亞拿突人亞比以謝、</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳記下 23:27–28; 歷代志上 27:11"> 戶沙人西比該、亞哈希人以萊、</span>
<span className="v" id="v30" data-v="30" data-xref="歷代志上 27:13; 歷代志上 27:15; 撒母耳記下 23:29"> 尼陀法人瑪哈萊、尼陀法人巴拿的兒子希立、</span>
<span className="v" id="v31" data-v="31" data-xref="撒母耳記下 23:29"> 便雅憫支派基比亞人利拜的兒子以太、比拉頓人比拿雅、</span>
<span className="v" id="v32" data-v="32" data-xref="撒母耳記下 23:30–31"> 迦實溪人戶萊、亞拉巴人亞比、</span>
<span className="v" id="v33" data-v="33"> 巴路米人押斯瑪弗、沙本人以利雅哈巴、</span>
<span className="v" id="v34" data-v="34" data-xref="撒母耳記下 23:32–33"> 基孫人哈深的眾子、哈拉人沙基的兒子約拿單、</span>
<span className="v" id="v35" data-v="35" data-xref="撒母耳記下 23:33–34"> 哈拉人沙甲的兒子亞希暗、吾珥的兒子以利法勒、</span>
<span className="v" id="v36" data-v="36"> 米基拉人希弗、比倫人亞希雅、</span>
<span className="v" id="v37" data-v="37" data-xref="撒母耳記下 23:35"> 迦密人希斯羅、伊斯拜的兒子拿萊、</span>
<span className="v" id="v38" data-v="38" data-xref="撒母耳記下 23:36"> 拿單的兄弟約珥、哈基利的兒子彌伯哈、</span>
<span className="v" id="v39" data-v="39"> 亞捫人洗勒、為洗魯雅的兒子約押拿兵器的比錄人拿哈萊、</span>
<span className="v" id="v40" data-v="40" data-xref="撒母耳記下 20:26"> 以帖人以拉、以帖人迦立、</span>
<span className="v" id="v41" data-v="41" data-xref="歷代志上 2:36; 撒母耳記下 23:39; 撒母耳記下 11:6–27"> 赫人烏利亞、亞萊的兒子撒拔、</span>
<span className="v" id="v42" data-v="42"> 示撒的兒子亞第拿——呂便支派中率領三十人的首領、</span>
<span className="v" id="v43" data-v="43"> 瑪迦的兒子哈難、彌特尼人約沙法、</span>
<span className="v" id="v44" data-v="44"> 亞施他拉人烏西亞、亞羅珥人何坦的兒子沙瑪和耶利、</span>
<span className="v" id="v45" data-v="45"> 提洗人申利的兒子耶疊和他的兄弟約哈、</span>
<span className="v" id="v46" data-v="46"> 瑪哈未人以利業、伊利拿安的兒子耶利拜和約沙未雅、摩押人伊特瑪、</span>
<span className="v" id="v47" data-v="47"> 以利業、俄備得和米瑣巴人雅西業。</span>

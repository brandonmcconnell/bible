## 祭司的職務

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歷代志上 23:6; 出埃及記 6:23; 民數記 26:60"> 下面是亞倫子孫的班次。亞倫的兒子是拿答、亞比戶、以利亞撒、以他瑪。</span>
<span className="v" id="v2" data-v="2" data-xref="利未記 10:2; 民數記 3:4; 民數記 26:61"> 拿答和亞比戶比父親先死，而且沒有留下兒子，因此以利亞撒和以他瑪做了祭司。</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳記下 8:17; 歷代志上 24:31; 撒母耳記上 21:1"> 在以利亞撒的子孫撒督和以他瑪的子孫亞希米勒的協助下，大衛將亞倫的子孫分成班次，讓他們各司其職。</span>
<span className="v" id="v4" data-v="4" data-xref="歷代志上 23:24; 民數記 25:11–13; 歷代志上 15:6–12"> 以利亞撒的子孫中做首領的比以他瑪的子孫中做首領的多，他們被分成班次：以利亞撒的子孫中有十六個族長，以他瑪的子孫中有八個族長。</span>
<span className="v" id="v5" data-v="5" data-xref="歷代志上 24:31; 約書亞記 18:10; 使徒行傳 4:1"> 因為以利亞撒和以他瑪的子孫中都有人在聖所做首領事奉上帝，他們便用抽籤的方法公平地分班。</span>
<span className="v" id="v6" data-v="6" data-xref="歷代志上 18:16; 馬太福音 8:19; 尼希米記 8:1"> 利未人拿坦業的兒子示瑪雅是書記。他在君王、首領、撒督祭司、亞比亞他的兒子亞希米勒、眾祭司和利未人的族長面前把抽出的名字記錄下來。他們從以利亞撒的子孫中抽出一族，從以他瑪的子孫中抽出一族。</span>
<span className="v" id="v7" data-v="7" data-xref="以斯拉記 2:36; 尼希米記 11:10; 尼希米記 12:19"> 第一籤抽出來的是耶何雅立，第二籤是耶大雅，</span>
<span className="v" id="v8" data-v="8" data-xref="以斯拉記 2:39; 尼希米記 7:35; 尼希米記 12:15"> 第三籤是哈琳，第四籤是梭琳，</span>
<span className="v" id="v9" data-v="9" data-xref="尼希米記 12:17"> 第五籤是瑪基雅，第六籤是米雅民，</span>
<span className="v" id="v10" data-v="10" data-xref="路加福音 1:5; 尼希米記 12:4; 尼希米記 12:17"> 第七籤是哈歌斯，第八籤是亞比雅，</span>
<span className="v" id="v11" data-v="11" data-xref="以斯拉記 2:36; 尼希米記 12:10; 尼希米記 7:39"> 第九籤是耶書亞，第十籤是示迦尼，</span>
<span className="v" id="v12" data-v="12" data-xref="尼希米記 12:10"> 第十一籤是以利亞實，第十二籤是雅金，</span>
<span className="v" id="v13" data-v="13"> 第十三籤是胡巴，第十四籤是耶是比押，</span>
<span className="v" id="v14" data-v="14" data-xref="尼希米記 7:40; 以斯拉記 2:37; 以斯拉記 10:20"> 第十五籤是璧迦，第十六籤是音麥，</span>
<span className="v" id="v15" data-v="15"> 第十七籤是希悉，第十八籤是哈辟悉，</span>
<span className="v" id="v16" data-v="16"> 第十九籤是毗他希雅，第二十籤是以西結，</span>
<span className="v" id="v17" data-v="17"> 第二十一籤是雅斤，第二十二籤是迦末，</span>
<span className="v" id="v18" data-v="18"> 第二十三籤是第來雅，第二十四籤是瑪西亞。</span>
<span className="v" id="v19" data-v="19" data-xref="歷代志上 9:25; 哥林多前書 14:40; 希伯來書 7:11"> 他們照這班次，按以色列的上帝耶和華藉他們的祖先亞倫所定的條例，在耶和華的殿裡司職。</span>
<span className="v" id="v20" data-v="20" data-xref="歷代志上 26:24; 歷代志上 23:16; 歷代志上 6:18"> 其他利未人還有暗蘭的後代書巴業，書巴業的後裔耶希底亞，</span>
<span className="v" id="v21" data-v="21" data-xref="歷代志上 23:17; 歷代志上 26:25"> 利哈比雅的長子伊示雅，</span>
<span className="v" id="v22" data-v="22" data-xref="歷代志上 23:18; 民數記 3:27; 民數記 3:19"> 以斯哈的後代示羅摩，示羅摩的後代雅哈，</span>
<span className="v" id="v23" data-v="23" data-xref="歷代志上 23:19; 歷代志上 26:31"> 希伯倫的長子耶利雅、次子亞瑪利亞、三子雅哈悉、四子耶加緬，</span>
<span className="v" id="v24" data-v="24" data-xref="歷代志上 23:20"> 烏薛的後代米迦，米迦的後代沙密，</span>
<span className="v" id="v25" data-v="25" data-xref="歷代志上 15:20; 歷代志上 15:18; 歷代志上 23:20"> 米迦的弟兄伊示雅，伊示雅的後代撒迦利雅，</span>
<span className="v" id="v26" data-v="26" data-xref="歷代志上 23:21"> 米拉利的兒子抹利、姆示、雅西雅，雅西雅的兒子比挪，</span>
<span className="v" id="v27" data-v="27" data-xref="民數記 3:20; 歷代志上 23:21; 歷代志上 6:19"> 米拉利的後代雅西雅的兒子比挪、朔含、撒刻、伊比利，</span>
<span className="v" id="v28" data-v="28" data-xref="歷代志上 23:22"> 抹利的兒子以利亞撒，以利亞撒沒有兒子，</span>
<span className="v" id="v29" data-v="29"> 基士的後代耶拉篾，</span>
<span className="v" id="v30" data-v="30" data-xref="歷代志上 23:23; 歷代志上 6:47"> 姆示的兒子末力、以得、耶利摩。這些按宗族都是利未人的後代。</span>
<span className="v" id="v31" data-v="31" data-xref="歷代志上 24:5–6; 歷代志上 26:13; 歷代志上 25:8"> 他們也在大衛王、撒督、亞希米勒、眾祭司和利未人的族長面前抽籤，不分長幼，正如他們的親族亞倫的後代所做的一樣。</span>

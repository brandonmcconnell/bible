## 以色列的後裔

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 32:28; 創世記 35:22–26; 啟示錄 7:5–8"> 以色列的兒子是呂便、西緬、利未、猶大、以薩迦、西布倫、</span>
<span className="v" id="v2" data-v="2"> 但、約瑟、便雅憫、拿弗他利、迦得和亞設。</span>
</div>

## 猶大的後裔

<div className="bt">
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="創世記 38:2–10; 創世記 46:12; 民數記 26:19"> 猶大的兒子是珥、俄南和示拉。這三人是迦南人書亞的女兒生的。猶大的長子珥在耶和華眼中是個邪惡的人，因而被耶和華擊殺了。</span>
<span className="v" id="v4" data-v="4" data-xref="馬太福音 1:3; 創世記 38:13–30; 尼希米記 11:4"> 猶大的兒媳她瑪給猶大生了法勒斯和謝拉。猶大共有五個兒子。</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 46:12; 路得記 4:18; 民數記 26:21"> 法勒斯的兒子是希斯崙和哈姆勒。</span>
<span className="v" id="v6" data-v="6" data-xref="列王紀上 4:31; 約書亞記 7:17–18; 約書亞記 7:1"> 謝拉的五個兒子是心利、以探、希幔、甲各、大拉。</span>
<span className="v" id="v7" data-v="7" data-xref="約書亞記 6:18; 申命記 7:26; 約書亞記 7:25"> 迦米的兒子是亞干，這亞干私藏本該毀滅之物，連累了以色列人。</span>
<span className="v" id="v8" data-v="8"> 以探的兒子是亞撒利雅。</span>
<span className="v" id="v9" data-v="9" data-xref="歷代志上 2:42; 馬太福音 1:3; 路得記 4:19"> 希斯崙的兒子是耶拉篾、蘭和迦勒<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「迦勒」希伯來文是「基路拜」，「迦勒」的另一種拼法。">a</a></sup>。</span>
<span className="v" id="v10" data-v="10" data-xref="馬太福音 1:4; 民數記 1:7; 民數記 2:3"> 蘭生亞米拿達，亞米拿達生拿順，拿順是猶大人的首領。</span>
<span className="v" id="v11" data-v="11" data-xref="路得記 4:21; 馬太福音 1:4–5; 路加福音 3:32"> 拿順生撒門，撒門生波阿斯，</span>
<span className="v" id="v12" data-v="12" data-xref="羅馬書 15:12; 歷代志上 10:14; 以賽亞書 11:10"> 波阿斯生俄備得，俄備得生耶西。</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳記上 17:13; 撒母耳記上 17:28; 歷代志上 20:7"> 耶西生長子以利押、次子亞比拿達、三子示米亞、</span>
<span className="v" id="v14" data-v="14"> 四子拿坦業、五子拉代、</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳記上 16:10–11; 撒母耳記上 17:12–14"> 六子阿鮮、七子大衛。</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳記上 26:6; 撒母耳記下 3:39; 撒母耳記下 2:18–23"> 他們的姊妹是洗魯雅和亞比該。洗魯雅的三個兒子是亞比篩、約押和亞撒黑。</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳記下 17:25; 列王紀上 2:32; 撒母耳記下 20:4–12"> 亞比該生亞瑪撒，亞瑪撒的父親是以實瑪利人益帖。</span>
</div>
</div>

## 希斯崙的後裔

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18"> 希斯崙的兒子迦勒和妻子阿蘇巴生了兒子，他也和耶略生了兒子。阿蘇巴的兒子是耶設、朔罷和押墩。</span>
<span className="v" id="v19" data-v="19" data-xref="歷代志上 2:50; 歷代志上 2:24; 歷代志上 4:4"> 阿蘇巴死後，迦勒又娶了以法她，生了戶珥。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及記 31:2; 出埃及記 36:1–2; 出埃及記 37:1"> 戶珥生烏利，烏利生比撒列。</span>
<span className="v" id="v21" data-v="21" data-xref="民數記 27:1; 申命記 3:15; 民數記 26:29"> 希斯崙六十歲娶瑪吉的女兒，與她生了西割。瑪吉是基列的父親。</span>
<span className="v" id="v22" data-v="22" data-xref="約書亞記 13:30; 申命記 3:14; 民數記 32:41"> 西割生雅珥，雅珥在基列有二十三座城邑。</span>
<span className="v" id="v23" data-v="23" data-xref="約書亞記 13:30; 申命記 3:14; 民數記 32:41–42"> 後來基述人和亞蘭人奪取了雅珥的城邑，包括基納及其附近的六十個村落。這些人都是基列的父親瑪吉的後代。</span>
<span className="v" id="v24" data-v="24" data-xref="歷代志上 4:5; 歷代志上 2:9; 撒母耳記上 30:14"> 希斯崙死在迦勒·以法他後，他的妻子亞比雅給他生了亞施戶。亞施戶是提哥亞的父親。</span>
</div>
</div>

## 耶拉篾的後裔

<div className="bt">
<div className="bp">
<span className="v" id="v25" data-v="25"> 希斯崙的長子耶拉篾生了長子蘭，又生了布拿、阿連、阿鮮、亞希雅。</span>
<span className="v" id="v26" data-v="26"> 耶拉篾的另一個妻子名叫亞她拉，是阿南的母親。</span>
<span className="v" id="v27" data-v="27"> 耶拉篾的長子蘭的兒子是瑪斯、雅憫和以結。</span>
<span className="v" id="v28" data-v="28"> 阿南的兒子是沙邁和雅大。沙邁的兒子是拿答和亞比述。</span>
<span className="v" id="v29" data-v="29"> 亞比述的妻子名叫亞比孩，她給丈夫生了亞班和摩利。</span>
<span className="v" id="v30" data-v="30"> 拿答的兒子是西列和亞遍。西列死後沒有留下兒子。</span>
<span className="v" id="v31" data-v="31" data-xref="歷代志上 2:34–35"> 亞遍的兒子是以示，以示的兒子是示珊，示珊的兒子是亞來。</span>
<span className="v" id="v32" data-v="32"> 沙邁的兄弟雅大的兒子是益帖和約拿單。益帖死後沒有留下兒子。</span>
<span className="v" id="v33" data-v="33"> 約拿單的兒子是比勒和撒薩。這些人都是耶拉篾的子孫。</span>
<span className="v" id="v34" data-v="34"> 示珊沒有兒子，只有女兒，還有一個名叫耶哈的埃及僕人。</span>
<span className="v" id="v35" data-v="35"> 示珊把女兒嫁給僕人耶哈，她給丈夫生了亞太。</span>
<span className="v" id="v36" data-v="36" data-xref="歷代志上 11:41"> 亞太生拿單，拿單生撒拔，</span>
<span className="v" id="v37" data-v="37"> 撒拔生以弗拉，以弗拉生俄備得，</span>
<span className="v" id="v38" data-v="38"> 俄備得生耶戶，耶戶生亞撒利雅，</span>
<span className="v" id="v39" data-v="39"> 亞撒利雅生希利斯，希利斯生以利亞薩，</span>
<span className="v" id="v40" data-v="40"> 以利亞薩生西斯邁，西斯邁生沙龍，</span>
<span className="v" id="v41" data-v="41"> 沙龍生耶加米雅，耶加米雅生以利沙瑪。</span>
</div>
</div>

## 迦勒的後裔

<div className="bt">
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="歷代志上 2:23–24; 希伯來書 12:23; 羅馬書 8:29"> 耶拉篾的兄弟迦勒的長子是西弗的父親米沙，希伯倫的父親瑪利沙也是迦勒的兒子。</span>
<span className="v" id="v43" data-v="43"> 希伯倫的兒子是可拉、他普亞、利肯、示瑪。</span>
<span className="v" id="v44" data-v="44"> 示瑪生拉含，拉含是約干的父親。利肯生沙邁，</span>
<span className="v" id="v45" data-v="45" data-xref="約書亞記 15:58"> 沙邁的兒子是瑪雲，瑪雲是伯·夙的父親。</span>
<span className="v" id="v46" data-v="46" data-xref="歷代志上 2:18–19; 歷代志上 2:48"> 迦勒的妾以法生哈蘭、摩撒和迦謝。哈蘭生迦諧。</span>
<span className="v" id="v47" data-v="47"> 雅代的兒子是利健、約坦、基珊、毗力、以法、沙亞弗。</span>
<span className="v" id="v48" data-v="48" data-xref="創世記 25:5–6; 歷代志上 2:46"> 迦勒的妾瑪迦生示別、特哈拿、</span>
<span className="v" id="v49" data-v="49" data-xref="約書亞記 15:31; 歷代志上 2:42; 以賽亞書 10:31"> 麥瑪拿的父親沙亞弗、抹比拿和基比亞的父親示法。迦勒的女兒是押撒。</span>
<span className="v" id="v50" data-v="50" data-xref="撒母耳記上 7:1; 約書亞記 15:60; 歷代志上 2:53"> 這些人都是迦勒的子孫。以法她的長子戶珥生基列·耶琳的父親朔巴、</span>
<span className="v" id="v51" data-v="51" data-xref="歷代志上 4:4; 約翰福音 7:42; 馬太福音 2:6"> 伯利恆的父親薩瑪、伯迦得的父親哈勒。</span>
<span className="v" id="v52" data-v="52" data-xref="歷代志上 4:2"> 基列·耶琳的父親朔巴的子孫是哈羅以和半數米努·哈人。</span>
<span className="v" id="v53" data-v="53" data-xref="撒母耳記下 23:38; 士師記 13:25; 士師記 13:2"> 基列·耶琳的各宗族是以帖人、布特人、舒瑪人、密來人，從這些宗族中又衍生出瑣拉人和以實陶人。</span>
<span className="v" id="v54" data-v="54" data-xref="尼希米記 7:26; 以斯拉記 2:22; 尼希米記 12:28"> 薩瑪的後代是伯利恆人、尼陀法人、亞他綠·伯·約押人、半數瑪拿哈人、瑣利人，</span>
<span className="v" id="v55" data-v="55" data-xref="列王紀下 10:15; 士師記 1:16; 耶利米書 35:19"> 以及住在雅比斯的文書世家特拉人、示米押人和蘇甲人。這些都是基尼人，是利甲家族的祖先哈末的後代。</span>
</div>

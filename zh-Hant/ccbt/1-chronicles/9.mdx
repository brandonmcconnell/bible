<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="尼希米記 7:64; 歷代志上 5:25–26; 耶利米書 52:14–15"> 所有以色列人都按照譜系記在《以色列列王史》上。 歸回的被擄之民<br />猶大人因為對上帝不忠而被擄到了巴比倫。</span>
<span className="v" id="v2" data-v="2" data-xref="尼希米記 7:73; 以斯拉記 2:58; 以斯拉記 2:70"> 首先從巴比倫回到自己城邑和地業居住的有祭司、利未人、殿役和其他以色列人。</span>
<span className="v" id="v3" data-v="3" data-xref="尼希米記 11:1; 歷代志下 11:16; 尼希米記 11:4–9"> 一些猶大人、便雅憫人、以法蓮人和瑪拿西人住在耶路撒冷，</span>
<span className="v" id="v4" data-v="4" data-xref="歷代志上 2:5; 創世記 46:12; 民數記 26:20"> 其中有猶大的兒子法勒斯的後代烏太。烏太是亞米忽的兒子，亞米忽是暗利的兒子，暗利是音利的兒子，音利是巴尼的兒子。</span>
<span className="v" id="v5" data-v="5" data-xref="民數記 26:20; 尼希米記 11:5"> 示羅的子孫中包括長子亞帥雅及其眾子，</span>
<span className="v" id="v6" data-v="6" data-xref="民數記 26:20; 歷代志上 2:6; 創世記 38:30"> 謝拉的後代耶烏利及其親族共六百九十人。</span>
<span className="v" id="v7" data-v="7" data-xref="尼希米記 10:20; 尼希米記 11:7; 尼希米記 8:4"> 便雅憫人有哈西努的曾孫、何達威雅的孫子、米書蘭的兒子撒路，</span>
<span className="v" id="v8" data-v="8"> 耶羅罕的兒子伊比尼雅，米基立的孫子、烏西的兒子以拉，伊比尼雅的曾孫、流珥的孫子、示法提雅的兒子米書蘭，</span>
<span className="v" id="v9" data-v="9" data-xref="尼希米記 11:8"> 以及他們的親族，按照家譜的記載共有九百五十六人。以上這些人都是各家的族長。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="尼希米記 12:19; 尼希米記 11:10–24"> 回來的祭司有耶大雅、耶何雅立和雅斤，</span>
<span className="v" id="v11" data-v="11" data-xref="尼希米記 11:11; 列王紀下 25:18; 民數記 4:33"> 還有管理上帝殿的亞薩利雅。亞撒利雅是希勒迦的兒子，希勒迦是米書蘭的兒子，米書蘭是撒督的兒子，撒督是米拉約的兒子，米拉約是亞希突的兒子。</span>
<span className="v" id="v12" data-v="12" data-xref="尼希米記 7:40; 以斯拉記 2:37; 尼希米記 11:12–13"> 回來的祭司還有瑪基雅的曾孫、巴施戶珥的孫子、耶羅罕的兒子亞大雅，以及亞第業的兒子瑪賽。亞第業是雅希細拉的兒子，雅希細拉是米書蘭的兒子，米書蘭是米實利密的兒子，米實利密是音麥的兒子。</span>
<span className="v" id="v13" data-v="13" data-xref="尼希米記 11:14; 歷代志上 26:30; 歷代志上 26:32"> 回來的祭司共一千七百六十人，全是族長，善於辦理上帝殿的事務。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="民數記 26:57; 尼希米記 10:11; 歷代志上 6:29"> 回來的利未人有米拉利的後代哈沙比雅的曾孫、押利甘的孫子、哈述的兒子示瑪雅，</span>
<span className="v" id="v15" data-v="15" data-xref="尼希米記 11:22; 尼希米記 11:17; 歷代志上 11:17"> 拔巴甲、黑勒施、加拉和亞薩的曾孫、細基利的孫子、米迦的兒子瑪探雅，</span>
<span className="v" id="v16" data-v="16" data-xref="歷代志上 25:1; 歷代志下 35:15; 歷代志上 12:25"> 耶杜頓的曾孫、迦拉的孫子、示瑪雅的兒子俄巴底，以利加拿的孫子、亞撒的兒子比利迦。他們都住在尼陀法人的村莊裡。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="歷代志上 26:1–32; 歷代志上 23:5; 尼希米記 11:19"> 負責守門的是沙龍、亞谷、達們、亞希幔和他們的親族，沙龍是他們的首領，</span>
<span className="v" id="v18" data-v="18" data-xref="以西結書 46:1–2; 以西結書 44:2–3; 列王紀上 10:5"> 在朝東的王門任職至今；他們曾是利未營中的守門人。</span>
<span className="v" id="v19" data-v="19" data-xref="民數記 26:9–11; 詩篇 44:1; 列王紀下 11:15"> 可拉的曾孫、以比雅撒的孫子、可利的兒子沙龍和其他可拉族人負責看守會幕的門，他們的祖先曾負責看守耶和華居所的門。</span>
<span className="v" id="v20" data-v="20" data-xref="民數記 31:6; 民數記 3:32; 民數記 4:33"> 以利亞撒的兒子非尼哈曾做他們的首領，耶和華也與他同在。</span>
<span className="v" id="v21" data-v="21" data-xref="歷代志上 26:14; 歷代志上 26:2"> 米施利米雅的兒子撒迦利雅是在會幕守門的。</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳記上 9:9; 歷代志上 28:13; 歷代志上 23:1–32"> 被選來守門的共有二百一十二人，都按各自所住的村莊載入家譜。大衛和撒母耳先見委派他們擔此重任。</span>
<span className="v" id="v23" data-v="23" data-xref="以西結書 44:14; 歷代志下 23:19; 以西結書 44:10–11"> 他們及其子孫負責看守耶和華的殿門，也就是會幕的門。</span>
<span className="v" id="v24" data-v="24" data-xref="歷代志上 26:14–18"> 東西南北四面都有守衛。</span>
<span className="v" id="v25" data-v="25" data-xref="列王紀下 11:5; 歷代志下 23:8; 列王紀下 11:7"> 他們村莊的同族弟兄每隔七天就來換班。</span>
<span className="v" id="v26" data-v="26" data-xref="尼希米記 13:5; 尼希米記 10:38–39; 歷代志上 26:20–27"> 四個殿門守衛長都是利未人，負責看守上帝殿的房間和庫房。</span>
<span className="v" id="v27" data-v="27" data-xref="歷代志上 23:30–32; 瑪拉基書 1:10; 撒母耳記上 3:15"> 他們住在殿周圍負責看殿，每天早晨開門。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="尼希米記 13:4–5; 尼希米記 12:44; 歷代志上 26:22–26"> 有些利未人負責管理敬拜時用的器皿，每次取出或送回，他們都要統計清楚。</span>
<span className="v" id="v29" data-v="29" data-xref="歷代志上 23:29; 出埃及記 30:23–38; 出埃及記 27:20"> 還有一些人負責管理聖所的其他器具，以及細麵粉、酒、油、乳香和香料。</span>
<span className="v" id="v30" data-v="30" data-xref="出埃及記 30:23–25; 出埃及記 37:29; 出埃及記 30:35–38"> 有些祭司負責配製香料。</span>
<span className="v" id="v31" data-v="31" data-xref="歷代志上 9:19; 歷代志上 9:22; 利未記 6:21"> 利未人瑪他提雅是可拉族沙龍的長子，他負責烤祭餅。</span>
<span className="v" id="v32" data-v="32" data-xref="利未記 24:5–8; 歷代志上 6:33–48; 出埃及記 25:30"> 哥轄宗族中還有些人負責預備每個安息日需用的供餅。</span>
<span className="v" id="v33" data-v="33" data-xref="歷代志上 6:31–33; 詩篇 134:1–2; 歷代志上 16:4–6"> 利未各宗族的族長負責歌樂，他們住在聖殿的房間裡，晝夜專做這項工作，不做別的事。</span>
<span className="v" id="v34" data-v="34" data-xref="尼希米記 11:1–15; 歷代志上 9:13"> 按照家譜的記載，以上都是利未人的各族長，他們住在耶路撒冷。</span>
</div>
</div>

## 掃羅王的族譜

<div className="bt">
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="歷代志上 2:23–24; 歷代志上 2:50–52; 歷代志上 8:29–40"> 耶利建立了基遍城，定居在那裡，他妻子名叫瑪迦。</span>
<span className="v" id="v36" data-v="36" data-xref="歷代志上 9:39; 歷代志上 8:33"> 他的長子是亞伯頓，其他兒子還有蘇珥、基士、巴力、尼珥、拿答、</span>
<span className="v" id="v37" data-v="37" data-xref="歷代志上 8:31"> 基多、亞希約、撒迦利雅和米基羅。</span>
<span className="v" id="v38" data-v="38" data-xref="歷代志上 8:32"> 米基羅是示米暗的父親。這些人也住在耶路撒冷，與他們的親族為鄰。</span>
<span className="v" id="v39" data-v="39" data-xref="撒母耳記上 13:22; 歷代志上 8:33–38; 歷代志上 10:2"> 尼珥生基士，基士生掃羅，掃羅生約拿單、麥基舒亞、亞比拿達和伊施·巴力。</span>
<span className="v" id="v40" data-v="40" data-xref="撒母耳記下 4:4; 歷代志上 8:34–36"> 約拿單生米力·巴力，米力·巴力生米迦，</span>
<span className="v" id="v41" data-v="41" data-xref="歷代志上 8:35"> 米迦生毗敦、米勒、他利亞、亞哈斯，</span>
<span className="v" id="v42" data-v="42" data-xref="歷代志上 8:36"> 亞哈斯生雅拉，雅拉生亞拉篾、亞斯瑪威和心利，心利生摩撒，</span>
<span className="v" id="v43" data-v="43" data-xref="歷代志上 8:37"> 摩撒生比尼亞，比尼亞生利法雅，利法雅生以利亞薩，以利亞薩生亞悉。</span>
<span className="v" id="v44" data-v="44"> 亞悉有六個兒子，他們是亞斯利干、波基路、以實瑪利、示亞利雅、俄巴底雅和哈難。這些都是亞悉的兒子。</span>
</div>

## 復述猶大的後裔

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 46:12; 創世記 38:29; 民數記 26:20–21"> 猶大的後代是法勒斯、希斯崙、迦米、戶珥、朔巴。</span>
<span className="v" id="v2" data-v="2" data-xref="士師記 13:25; 歷代志上 2:52–54; 約書亞記 15:33"> 朔巴的兒子利亞雅生雅哈，雅哈生亞戶買和拉哈。他們都屬於瑣拉人的宗族。</span>
<span className="v" id="v3" data-v="3" data-xref="士師記 15:11; 歷代志下 11:6"> 以坦的兒子<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「兒子」希伯來文是「父親」。">a</a></sup>是耶斯列、伊施瑪和伊得巴，女兒名叫哈悉勒玻尼。</span>
<span className="v" id="v4" data-v="4" data-xref="歷代志上 4:18; 歷代志上 2:50; 歷代志上 4:39"> 基多的父親是毗努伊勒，戶沙的父親是以謝珥。這些人都是伯利恆的父親、以法她的長子戶珥的後代。</span>
<span className="v" id="v5" data-v="5" data-xref="歷代志上 2:24"> 提哥亞的父親亞施戶有兩個妻子，一個名叫希拉，一個名叫拿拉。</span>
<span className="v" id="v6" data-v="6"> 拿拉給他生了亞戶撒、希弗、提米尼和哈轄斯他利。這些都是拿拉的兒子。</span>
<span className="v" id="v7" data-v="7"> 希拉的兒子是洗列、瑣轄和伊提南。</span>
<span className="v" id="v8" data-v="8"> 哥斯生亞諾和瑣比巴，他也是哈倫的兒子亞哈黑宗族的祖先。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳記上 4:21; 歷代志上 7:23; 創世記 35:18"> 雅比斯比他的眾弟兄尊貴，他母親給他取名叫雅比斯，意思是：「我生他時非常痛苦。」</span>
<span className="v" id="v10" data-v="10" data-xref="馬太福音 7:7–11; 詩篇 116:1–4; 箴言 10:22"> 雅比斯向以色列的上帝禱告說：「願你賜福給我，擴展我的疆域，願你的手扶持我，使我遠離患難、免受痛苦。」上帝答應了他的祈求。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11"> 書哈的弟兄基綠生米黑，米黑是伊施屯的父親。</span>
<span className="v" id="v12" data-v="12"> 伊施屯生伯‧拉巴、巴西亞和提欣拿，提欣拿是珥拿轄的父親。這些都是利迦人。</span>
<span className="v" id="v13" data-v="13" data-xref="約書亞記 15:17; 士師記 1:13; 士師記 3:9–11"> 基納斯的兒子是俄陀聶和西萊雅。俄陀聶的兒子是哈塔、憫挪太。</span>
<span className="v" id="v14" data-v="14" data-xref="尼希米記 11:35; 列王紀下 24:14"> 憫挪太生俄弗拉。西萊雅生革·夏納欣人的祖先約押。他們都是工匠。</span>
<span className="v" id="v15" data-v="15" data-xref="民數記 13:6; 民數記 14:6–10; 約書亞記 15:13–20"> 耶孚尼的兒子是迦勒，迦勒的兒子是以路、以拉和拿安，以拉的兒子是基納斯。</span>
<span className="v" id="v16" data-v="16"> 耶哈利勒的兒子是西弗、西法、提利和亞撒列。</span>
<span className="v" id="v17" data-v="17" data-xref="歷代志上 4:19; 歷代志上 6:57; 約書亞記 15:50"> 以斯拉的兒子是益帖、米列、以弗和雅倫。米列娶了法老的女兒比提雅為妻，她給米列生了米利暗、沙邁和以實提摩的父親益巴。</span>
<span className="v" id="v18" data-v="18" data-xref="歷代志上 2:42; 歷代志上 4:39; 約書亞記 15:58"> 米列還娶了一個猶大人為妻，她生了基多的父親雅列、梭哥的父親希伯和撒挪亞的父親耶古鐵。</span>
<span className="v" id="v19" data-v="19" data-xref="約書亞記 15:44; 撒母耳記上 23:1–13"> 荷第雅的妻子是拿含的妹妹，她的兒子們是迦米人基伊拉和瑪迦人以實提摩的父親。</span>
<span className="v" id="v20" data-v="20"> 示門的兒子是暗嫩、林拿、便·哈南和提倫。以示的兒子是梭黑和便·梭黑。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="創世記 38:5; 歷代志上 2:3; 民數記 26:20"> 猶大有個兒子名叫示拉。示拉的後代是利迦的父親珥、瑪利沙的父親拉大、在伯‧亞實比織細麻布的各家族、</span>
<span className="v" id="v22" data-v="22"> 約敬、哥西巴人、約阿施以及統治摩押和雅叔比利恆的薩拉。這都是古代的記錄。</span>
<span className="v" id="v23" data-v="23" data-xref="詩篇 81:6; 歷代志上 4:14"> 他們都是住在尼他英和基低拉的陶匠，他們在那裡為王效力。</span>
</div>
</div>

## 西緬的後裔

<div className="bt">
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="創世記 46:10; 出埃及記 6:15; 民數記 26:12–14"> 西緬的兒子是尼姆利、雅憫、雅立、謝拉和掃羅。</span>
<span className="v" id="v25" data-v="25"> 掃羅的兒子是沙龍，沙龍的兒子是米比衫，米比衫的兒子是米施瑪，</span>
<span className="v" id="v26" data-v="26"> 米施瑪的兒子是哈姆利，哈姆利的兒子是撒刻，撒刻的兒子是示每。</span>
<span className="v" id="v27" data-v="27" data-xref="民數記 26:14; 民數記 26:22; 民數記 2:13"> 示每有十六個兒子和六個女兒，他弟兄的兒女不多。他們整個宗族的人不如猶大宗族的人多。</span>
<span className="v" id="v28" data-v="28" data-xref="約書亞記 19:2–3; 約書亞記 15:28–29; 約書亞記 19:9"> 西緬人住在別示巴、摩拉大、哈薩·書亞、</span>
<span className="v" id="v29" data-v="29" data-xref="約書亞記 19:3–4"> 辟拉、以森、陀臘、</span>
<span className="v" id="v30" data-v="30" data-xref="尼希米記 11:28; 約書亞記 19:4–5; 撒母耳記上 30:1"> 彼土利、何珥瑪、洗革拉、</span>
<span className="v" id="v31" data-v="31" data-xref="約書亞記 19:5–6"> 伯·瑪加博、哈薩·蘇撒、伯·比利、沙拉音。在大衛做王以前，這些都是西緬人的城邑。</span>
<span className="v" id="v32" data-v="32" data-xref="約書亞記 19:7"> 他們還有五座城邑：以坦、亞因、臨門、陀健、亞珊，</span>
<span className="v" id="v33" data-v="33" data-xref="約書亞記 19:8"> 以及這些城附近的村莊，遠至巴力。這些都是他們的住處。他們有自己的家譜。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34"> 西緬的後代還有米所巴、雅米勒、亞瑪謝的兒子約沙、</span>
<span className="v" id="v35" data-v="35"> 約珥、約示比的兒子耶戶。約示比是西萊雅的兒子，西萊雅是亞薛的兒子。</span>
<span className="v" id="v36" data-v="36"> 西緬的後代還有以利約乃、雅哥巴、約朔海、亞帥雅、亞底業、耶西篾、比拿雅、</span>
<span className="v" id="v37" data-v="37"> 示非的兒子細撒。示非是亞龍的兒子，亞龍是耶大雅的兒子，耶大雅是申利的兒子，申利是示瑪雅的兒子。</span>
<span className="v" id="v38" data-v="38" data-xref="歷代志上 5:24; 創世記 6:4"> 以上所提的這些人都是族長，各宗族都人丁興旺。</span>
<span className="v" id="v39" data-v="39" data-xref="歷代志上 4:4; 歷代志上 4:18; 約書亞記 15:58"> 他們前往平原東邊的基多谷尋找牧羊的草場，</span>
<span className="v" id="v40" data-v="40" data-xref="士師記 18:7–10; 詩篇 105:23; 詩篇 78:51"> 找到了一片肥沃的草場，又遼闊又安靜。從前含族人在那裡居住。</span>
<span className="v" id="v41" data-v="41" data-xref="以賽亞書 14:28–32; 列王紀下 18:8–12; 歷代志上 4:34–38"> 在猶大王希西迦執政期間，以上這些西緬人的族長來攻打含族人的駐地和那裡所有的米烏尼人，消滅了他們，佔據了那裡，一直住到今天，因為那裡有可以牧羊的草場。</span>
<span className="v" id="v42" data-v="42" data-xref="創世記 36:8–9; 申命記 1:2"> 有五百個西緬人在以示的兒子毗拉提、尼利雅、利法雅和烏薛的帶領下前往西珥山，</span>
<span className="v" id="v43" data-v="43" data-xref="撒母耳記上 30:17; 撒母耳記上 15:7–8; 撒母耳記下 8:12"> 剷除了殘餘的亞瑪力人，從此定居在那裡，直到今日。</span>
</div>
</div>

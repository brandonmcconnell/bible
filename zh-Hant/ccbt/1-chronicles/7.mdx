## 以薩迦的後裔

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 46:13; 民數記 26:23–24"> 以薩迦的四個兒子是陀拉、普瓦、雅述和伸崙。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳記下 24:1–9; 歷代志上 27:23–24; 歷代志上 27:1"> 陀拉的兒子是烏西、利法雅、耶勒、雅買、易伯散和示姆利，他們都是陀拉宗族的族長。在大衛執政年間，陀拉家共有兩萬二千六百個英勇的戰士。</span>
<span className="v" id="v3" data-v="3"> 烏西的兒子是伊斯拉希。伊斯拉希的兒子是米迦勒、俄巴底亞、約珥、伊示雅，他們五人都是族長。</span>
<span className="v" id="v4" data-v="4" data-xref="歷代志上 12:32"> 他們妻兒眾多，因此各宗族中可以出征作戰的共有三萬六千人。</span>
<span className="v" id="v5" data-v="5"> 按照家譜的記載，以薩迦支派的各族中共有八萬七千個英勇的戰士。</span>
</div>
</div>

## 便雅憫的後裔

<div className="bt">
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="創世記 46:21; 歷代志上 8:1–40; 歷代志上 7:10–11"> 便雅憫的三個兒子是比拉、比結和耶疊。</span>
<span className="v" id="v7" data-v="7" data-xref="歷代志下 17:17–18; 歷代志上 21:1–5"> 比拉的五個兒子是以斯本、烏西、烏薛、耶利摩和以利，他們都是族長，是英勇的戰士。按家譜記載，他們宗族共有兩萬二千零三十四個戰士。</span>
<span className="v" id="v8" data-v="8"> 比結的兒子是細米拉、約阿施、以利以謝、以利約乃、暗利、耶利末、亞比雅、亞拿突和亞拉篾。</span>
<span className="v" id="v9" data-v="9"> 比結的兒子都是族長。按家譜的記載，他們宗族共有兩萬零二百個英勇的戰士。</span>
<span className="v" id="v10" data-v="10" data-xref="士師記 3:15–30"> 耶疊的兒子是比勒罕，比勒罕的兒子是耶烏施、便雅憫、以笏、基拿拿、細坦、他施和亞希沙哈。</span>
<span className="v" id="v11" data-v="11" data-xref="歷代志下 17:13–19"> 這些耶疊的兒子都是族長，宗族中可以英勇作戰的共一萬七千二百人。</span>
<span className="v" id="v12" data-v="12" data-xref="民數記 26:38–39; 創世記 46:21; 歷代志上 7:15"> 以珥的兒子是書品和戶品，亞黑的兒子是戶伸。</span>
</div>
</div>

## 拿弗他利的後裔

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="民數記 26:48–49; 創世記 30:3–8; 創世記 35:22"> 拿弗他利的兒子是雅薛、沽尼、耶色和沙龍。他們都是辟拉的後代。</span>
</div>
</div>

## 瑪拿西的後裔

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="民數記 32:30–42; 士師記 5:14; 申命記 3:13–15"> 瑪拿西的妾是亞蘭人，她給瑪拿西生的兒子是亞斯烈，另外還生了基列的父親瑪吉。</span>
<span className="v" id="v15" data-v="15" data-xref="民數記 26:33; 民數記 36:1–12; 民數記 27:1–11"> 瑪吉娶了戶品和書品的妹妹瑪迦。瑪拿西另一個後代名叫西羅非哈，西羅非哈只有幾個女兒。</span>
<span className="v" id="v16" data-v="16"> 瑪吉的妻子瑪迦生了一個兒子，給他取名叫毗利施。毗利施的兄弟名叫示利施，示利施的兒子是烏蘭和利金。</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳記上 12:11"> 烏蘭的兒子是比但。這些都是基列的子孫。基列是瑪吉的兒子，瑪吉是瑪拿西的兒子。</span>
<span className="v" id="v18" data-v="18" data-xref="士師記 6:24; 士師記 6:11; 士師記 8:2"> 基列的妹妹哈摩利吉生了伊施荷、亞比以謝和瑪拉。</span>
<span className="v" id="v19" data-v="19"> 示米大的兒子是亞現、示劍、利克希和阿尼安。</span>
</div>
</div>

## 以法蓮的後裔

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="民數記 26:35–36"> 以法蓮的後代有書提拉，書提拉的兒子是比列，比列的兒子是他哈，他哈的兒子是以拉大，以拉大的兒子是他哈，</span>
<span className="v" id="v21" data-v="21"> 他哈的兒子是撒拔，撒拔的兒子是書提拉。以法蓮的另外兩個兒子以謝和以列下去奪迦特人的牲畜，被當地人所殺。</span>
<span className="v" id="v22" data-v="22" data-xref="約伯記 2:11; 創世記 37:34"> 他們的父親以法蓮為他們悲傷了多日，弟兄們都來安慰他。</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳記下 23:5"> 後來，以法蓮與妻子同房，妻子懷孕，生了一個兒子。以法蓮因家裡遭遇不幸，就給孩子取名叫比利亞<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「比利亞」意思是「不幸」。">a</a></sup>。</span>
<span className="v" id="v24" data-v="24" data-xref="約書亞記 16:3; 約書亞記 16:5; 歷代志下 8:5"> 以法蓮有一個女兒叫舍伊拉，她建造了上伯·和崙、下伯·和崙和烏羨·舍伊拉。</span>
<span className="v" id="v25" data-v="25"> 比利亞的兒子是利法和利悉，利悉的兒子是他拉，他拉的兒子是他罕，</span>
<span className="v" id="v26" data-v="26"> 他罕的兒子是拉但，拉但的兒子是亞米忽，亞米忽的兒子是以利沙瑪，</span>
<span className="v" id="v27" data-v="27" data-xref="民數記 13:8; 民數記 13:16; 出埃及記 17:9–14"> 以利沙瑪的兒子是嫩，嫩的兒子是約書亞。</span>
<span className="v" id="v28" data-v="28" data-xref="創世記 28:19; 約書亞記 16:2–3; 歷代志上 6:66–67"> 以法蓮人的地業和住處包括伯特利及其四圍的村莊、東部的拿蘭、西部的基色及其四圍的村莊、示劍及其四圍的村莊，遠至艾雅及其四圍的村莊。</span>
<span className="v" id="v29" data-v="29" data-xref="士師記 1:22–29; 撒迦利亞書 12:11; 列王紀下 9:27"> 瑪拿西人的地業包括伯·善、他納、米吉多、多珥以及它們四圍的村莊。這些是以色列之子約瑟的後代居住的地方。</span>
</div>
</div>

## 亞設的後裔

<div className="bt">
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="創世記 46:17; 民數記 26:44–46"> 亞設的兒子是音拿、亦施瓦、亦施韋、比利亞，女兒是西拉。</span>
<span className="v" id="v31" data-v="31"> 比利亞的兒子是希別和瑪結，瑪結的兒子是比撒威。</span>
<span className="v" id="v32" data-v="32"> 希別的兒子是雅弗勒、朔默、何坦，女兒是書雅。</span>
<span className="v" id="v33" data-v="33"> 雅弗勒的兒子是巴薩、賓哈和亞施法。這三人是雅弗勒的兒子。</span>
<span className="v" id="v34" data-v="34"> 朔默的兒子是亞希、羅迦、耶戶巴和亞蘭。</span>
<span className="v" id="v35" data-v="35"> 朔默的兄弟希連的兒子是瑣法、音那、示利斯和亞抹。</span>
<span className="v" id="v36" data-v="36"> 瑣法的兒子是書亞、哈尼弗、書阿勒、比利、音拉、</span>
<span className="v" id="v37" data-v="37"> 比悉、河得、珊瑪、施沙、益蘭、比拉。</span>
<span className="v" id="v38" data-v="38"> 益帖的兒子是耶孚尼、毗斯巴、亞拉。</span>
<span className="v" id="v39" data-v="39"> 烏拉的兒子是亞拉、漢尼業和利謝。</span>
<span className="v" id="v40" data-v="40" data-xref="歷代志上 21:1–5; 撒母耳記下 24:1–9"> 這些都是亞設的後代。他們都是族長，是英勇的戰士和傑出的首領。按照家譜的記載，他們宗族中可以出征作戰的共有兩萬六千人。</span>
</div>
</div>

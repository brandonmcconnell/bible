## 聖殿的守衛

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歷代志下 23:19; 民數記 26:9–11; 詩篇 44:1"> 以下是殿門守衛的班次： 可拉族亞薩的後代有可利的兒子米施利米雅。</span>
<span className="v" id="v2" data-v="2" data-xref="歷代志上 9:21"> 米施利米雅的長子是撒迦利亞，次子是耶疊，三子是西巴第雅，四子是耶提聶，</span>
<span className="v" id="v3" data-v="3"> 五子是以攔，六子是約哈難，七子是以利約乃。</span>
<span className="v" id="v4" data-v="4" data-xref="歷代志上 16:38; 歷代志上 15:24; 歷代志上 15:18"> 俄別·以東的長子是示瑪雅，次子是約薩拔，三子是約亞，四子是沙甲，五子是拿坦業，</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 128:1"> 六子是亞米利，七子是以薩迦，八子是毗烏利太，因為上帝賜福俄別·以東。</span>
<span className="v" id="v6" data-v="6" data-xref="歷代志上 12:28; 提摩太前書 6:12; 士師記 6:12"> 他兒子示瑪雅有幾個兒子都很能幹，在各自的家族中做首領。</span>
<span className="v" id="v7" data-v="7"> 他們是俄得尼、利法益、俄備得、以利薩巴。他們的親族以利戶和西瑪迦也很能幹。</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多後書 3:6; 彼得前書 4:11; 哥林多前書 12:4–11"> 這些都是俄別·以東的子孫，他們和他們的兒子及親族共有六十二人，都是能幹稱職的人。</span>
<span className="v" id="v9" data-v="9" data-xref="歷代志上 26:14; 歷代志上 26:1"> 米施利米雅的兒子及親族共十八人，都很能幹。</span>
<span className="v" id="v10" data-v="10" data-xref="歷代志上 16:38; 歷代志上 5:1–2"> 米拉利的後代何薩的長子是申利，他本來不是長子，是被他父親立為長子的。</span>
<span className="v" id="v11" data-v="11"> 次子是希勒迦，三子是底巴利雅，四子是撒迦利亞。何薩的兒子及親族共十三人。</span>
<span className="v" id="v12" data-v="12" data-xref="歷代志上 25:8"> 這些按族長分成小組的殿門守衛在耶和華的殿裡按班次供職，與他們的親族一樣。</span>
<span className="v" id="v13" data-v="13" data-xref="歷代志上 25:8; 歷代志上 24:31; 歷代志上 24:5"> 他們無論大小，都按照族系抽籤，以決定看守哪個門。</span>
<span className="v" id="v14" data-v="14"> 示利米雅抽中東門，他兒子撒迦利亞是個精明的謀士，抽中北門。</span>
<span className="v" id="v15" data-v="15" data-xref="歷代志下 25:24; 歷代志上 26:17"> 俄別·以東抽中南門，他兒子抽中庫房。</span>
<span className="v" id="v16" data-v="16" data-xref="尼希米記 12:24; 歷代志上 26:10–12; 列王紀上 10:5"> 書聘和何薩抽中西門和上行之路的沙利基門，守衛與守衛相對而立。</span>
<span className="v" id="v17" data-v="17" data-xref="歷代志下 8:14; 歷代志上 9:24"> 每天有六個利未人守東門，四人守北門，四人守南門，守庫房的二人一組。</span>
<span className="v" id="v18" data-v="18" data-xref="列王紀下 23:11"> 至於西面的走廊，守衛街道的有四人，守衛走廊的有二人。</span>
<span className="v" id="v19" data-v="19" data-xref="民數記 16:11"> 以上是可拉的子孫和米拉利的子孫守門的班次。</span>
</div>
</div>

## 聖殿裡的其他職務

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="歷代志上 26:22; 歷代志上 28:12–19; 歷代志上 22:14–16"> 利未人亞希雅負責掌管上帝殿裡的庫房和放聖物的庫房。</span>
<span className="v" id="v21" data-v="21" data-xref="歷代志上 23:7; 歷代志上 6:17; 歷代志上 29:8"> 革順族拉但的子孫中做族長的有耶希伊利。</span>
<span className="v" id="v22" data-v="22" data-xref="歷代志上 23:8; 尼希米記 10:38; 歷代志上 26:20"> 耶希伊利的兩個兒子西坦和約珥負責管理耶和華殿裡的庫房。</span>
<span className="v" id="v23" data-v="23" data-xref="民數記 3:27; 歷代志上 23:12; 民數記 3:19"> 暗蘭族、以斯哈族、希伯倫族、烏薛族也各有其職。</span>
<span className="v" id="v24" data-v="24" data-xref="歷代志上 24:20; 歷代志上 23:15–16"> 摩西的孫子、革舜的兒子細布業是庫房的主管。</span>
<span className="v" id="v25" data-v="25" data-xref="歷代志上 23:17–18; 歷代志上 23:15; 出埃及記 18:4"> 細布業的親族有以利以謝，以利以謝的兒子是利哈比雅，利哈比雅的兒子是耶篩亞，耶篩亞的兒子是約蘭，約蘭的兒子是細基利，細基利的兒子是示羅密。</span>
<span className="v" id="v26" data-v="26" data-xref="撒母耳記下 8:11; 歷代志上 29:2–9; 歷代志上 22:14"> 示羅密及其親族負責管理庫房中的聖物，這些物品是大衛王、眾族長、千夫長、百夫長和將領獻給上帝的聖物。</span>
<span className="v" id="v27" data-v="27" data-xref="列王紀下 12:14; 約書亞記 6:19; 尼希米記 10:32–34"> 他們把戰爭中擄掠的財物獻出來，以備修繕耶和華的殿。</span>
<span className="v" id="v28" data-v="28" data-xref="撒母耳記上 9:9; 撒母耳記上 17:55; 撒母耳記下 10:9–14"> 撒母耳先見、基士的兒子掃羅、尼珥的兒子押尼珥、洗魯雅的兒子約押及其他人奉獻的聖物都由示羅密及其親族管理。</span>
<span className="v" id="v29" data-v="29" data-xref="歷代志上 23:4; 尼希米記 11:16; 歷代志下 34:13"> 以斯哈族的基拿尼雅及其眾子做官長和審判官，為以色列管理聖殿以外的事務。</span>
<span className="v" id="v30" data-v="30" data-xref="歷代志上 27:17; 歷代志上 23:19; 歷代志上 23:12"> 希伯倫族的哈沙比雅及其親族一千七百人都很能幹，他們在以色列的約旦河以西辦理耶和華和王的事務。</span>
<span className="v" id="v31" data-v="31" data-xref="歷代志上 23:19; 約書亞記 21:39; 歷代志上 29:27"> 按家譜記載，希伯崙宗族的族長是耶利雅。大衛執政第四十年，經過調查，在基列的雅謝從希伯倫族中找到一些能幹的人。</span>
<span className="v" id="v32" data-v="32" data-xref="歷代志下 19:11; 歷代志上 12:37; 歷代志上 23:24"> 耶利雅的親族有兩千七百人，都是能幹的族長。大衛王派他們在呂便支派、迦得支派和瑪拿西半個支派中辦理一切有關上帝和王的事務。</span>
</div>

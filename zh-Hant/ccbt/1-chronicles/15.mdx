## 約櫃被運到耶路撒冷

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歷代志上 16:1; 歷代志上 17:1–5; 詩篇 132:5"> 大衛在大衛城為自己建造宮殿，並為上帝的約櫃預備地方，支搭帳幕。</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 10:8; 申命記 31:9; 民數記 18:1–8"> 大衛說：「除了利未人以外，誰也不可抬上帝的約櫃，因為耶和華只揀選他們抬上帝的約櫃，永遠事奉祂。」</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="列王紀上 8:1; 歷代志上 13:5; 歷代志上 15:1"> 大衛召集以色列人到耶路撒冷，要把耶和華的約櫃抬到他所預備的地方。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及記 6:16–22; 歷代志上 12:26–28; 歷代志上 6:16–30"> 大衛又召集了亞倫的子孫和利未人：</span>
<span className="v" id="v5" data-v="5" data-xref="歷代志上 6:22–24"> 哥轄的後代烏列族長和他的一百二十個族人；</span>
<span className="v" id="v6" data-v="6" data-xref="歷代志上 6:29–30"> 米拉利的後代亞帥雅族長和他的二百二十個族人；</span>
<span className="v" id="v7" data-v="7" data-xref="歷代志上 15:11; 歷代志上 23:8"> 革順的後代約珥族長和他的一百三十個族人；</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及記 6:22"> 以利撒反的後代示瑪雅族長和他的二百個族人；</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及記 6:18; 歷代志上 23:19; 歷代志上 26:30–31"> 希伯倫的後代以利業族長和他的八十個族人；</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及記 6:18; 歷代志上 6:18; 歷代志上 23:12"> 烏薛的後代亞米拿達族長和他的一百一十二個族人。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="歷代志上 12:28; 列王紀上 2:35; 撒母耳記上 22:20–23"> 大衛召來撒督和亞比亞他兩位祭司以及利未人烏列、亞帥雅、約珥、示瑪雅、以利業、亞米拿達，</span>
<span className="v" id="v12" data-v="12" data-xref="歷代志下 35:6; 出埃及記 19:14–15; 歷代志上 15:14"> 對他們說：「你們是利未人的族長，你們和你們的族人都要潔淨自己，好將以色列的上帝耶和華的約櫃抬到我所預備的地方。</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳記下 6:3; 哥林多前書 14:40; 約翰一書 1:8–10"> 先前你們沒有抬約櫃，我們也沒有按規矩求問我們的上帝耶和華，以致祂向我們發怒。」</span>
<span className="v" id="v14" data-v="14" data-xref="歷代志下 29:15; 約珥書 2:16–17; 歷代志下 29:34"> 於是祭司和利未人就潔淨自己，好將以色列的上帝耶和華的約櫃抬上來。</span>
<span className="v" id="v15" data-v="15" data-xref="民數記 4:15; 民數記 7:9; 歷代志下 5:9"> 利未人按照耶和華藉摩西頒佈的命令，用槓把上帝的約櫃抬在肩上。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="歷代志上 13:8; 歷代志下 5:13; 歷代志上 16:42"> 大衛又吩咐利未人的族長去派他們的族人做歌樂手，伴著琴瑟和鈸的樂聲歡唱。</span>
<span className="v" id="v17" data-v="17" data-xref="歷代志上 6:39; 歷代志上 6:44; 歷代志上 6:33"> 於是，利未人指派約珥的兒子希幔和他的親族比利迦的兒子亞薩，以及他的親族米拉利的後代古沙雅的兒子以探。</span>
<span className="v" id="v18" data-v="18" data-xref="歷代志上 26:4; 歷代志上 26:8; 歷代志上 13:14"> 協助他們的親族有撒迦利雅、雅薛、示米拉末、耶歇、烏尼、以利押、比拿雅、瑪西雅、瑪他提雅、以利斐利戶、彌克尼雅，以及守門的俄別·以東和耶利。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="歷代志上 25:6; 歷代志上 16:5; 歷代志上 13:8"> 歌樂手希幔、亞薩和以探負責敲銅鈸，</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 46:1–11"> 撒迦利雅、雅薛、示米拉末、耶歇、烏尼、以利押、瑪西雅、比拿雅負責鼓瑟，調用高音。</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳記上 10:5; 歷代志上 25:6–7; 詩篇 81:1–2"> 瑪他提雅、以利斐利戶、彌克尼雅、俄別·以東、耶利、亞撒西雅負責帶領彈琴，調用低音。</span>
<span className="v" id="v22" data-v="22" data-xref="歷代志上 15:27; 歷代志上 15:16; 歷代志上 25:7–8"> 利未人的族長基拿尼雅善於歌唱，是歌樂手的領班。</span>
<span className="v" id="v23" data-v="23" data-xref="詩篇 84:10; 列王紀下 22:4; 歷代志上 9:21–23"> 比利迦和以利加拿負責看守約櫃。</span>
<span className="v" id="v24" data-v="24" data-xref="歷代志上 16:6; 民數記 10:8; 歷代志上 15:28"> 祭司示巴尼、約沙法、拿坦業、亞瑪賽、撒迦利雅、比拿亞和以利以謝負責在上帝的約櫃前吹號，俄別·以東和耶希亞也負責看守約櫃。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="撒母耳記下 6:12–23; 彌迦書 5:2; 腓立比書 3:3"> 大衛和以色列的長老以及千夫長去俄別·以東家，歡歡喜喜地把耶和華的約櫃抬上來。</span>
<span className="v" id="v26" data-v="26" data-xref="民數記 23:29; 歷代志上 29:14; 詩篇 66:13–15"> 耶和華上帝恩待抬約櫃的利未人，他們就獻上七頭公牛和七隻公羊為祭物。</span>
<span className="v" id="v27" data-v="27" data-xref="撒母耳記上 2:18; 撒母耳記下 6:14"> 大衛和抬約櫃的利未人、歌樂手及其領班基拿尼雅都穿上細麻布外袍，大衛也穿上細麻布的以弗得。</span>
<span className="v" id="v28" data-v="28" data-xref="歷代志上 13:8; 歷代志上 15:16; 歷代志下 5:12–13"> 以色列人把耶和華的約櫃抬了上來，一路上歡呼、吹角、鳴號、敲鈸、鼓瑟、彈琴，大聲奏樂。</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳記下 6:20–23; 撒母耳記下 6:16; 申命記 31:26"> 耶和華的約櫃進大衛城的時候，掃羅的女兒米甲從窗戶往外觀看，見大衛王在興高采烈地跳舞，心裡就輕視他。</span>
</div>
</div>

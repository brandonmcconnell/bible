## 大衛對所羅門的囑咐

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歷代志上 23:2; 歷代志上 11:10–47; 歷代志上 27:1–34"> 大衛召以色列的眾首領到耶路撒冷。於是，各支派的首領、王手下的各班將領、千夫長、百夫長、負責王和王子的財產及牲畜的官員、宮廷侍臣、勇士和能征善戰者都來了，</span>
<span className="v" id="v2" data-v="2" data-xref="詩篇 99:5; 以賽亞書 66:1; 歷代志上 17:1–2"> 大衛王站起來說：「我的弟兄，我的人民啊，請聽我說。我本想建造一座殿宇安放耶和華的約櫃，作我們上帝的腳凳，我已準備好建造的材料。</span>
<span className="v" id="v3" data-v="3" data-xref="歷代志上 22:8; 歷代志上 17:4; 歷代志下 6:8–9"> 但上帝對我說，『你不可為我的名建造殿宇，因為你是個戰士，曾流過人的血。』</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳記上 16:1; 歷代志上 5:2; 撒母耳記上 16:6–13"> 以色列的上帝耶和華從我父家永遠揀選我做以色列的王。因為祂揀選了猶大支派做首領；在猶大支派中，祂揀選了我父親家；在我父親的眾子中，祂喜悅我，立我做以色列的王。</span>
<span className="v" id="v5" data-v="5" data-xref="歷代志上 3:1–9; 歷代志上 23:1; 歷代志上 22:9–10"> 耶和華賜給我許多兒子，祂在我眾子中揀選了所羅門，讓他坐耶和華國的王位，治理以色列。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳記下 7:13–14; 歷代志上 22:9–10; 希伯來書 3:6"> 耶和華對我說，『你兒子所羅門必建造我的殿宇和庭院，因為我揀選他做我的兒子，我也必做他的父親。</span>
<span className="v" id="v7" data-v="7" data-xref="歷代志上 22:13; 列王紀上 8:61; 列王紀上 6:12–13"> 倘若他像今天一樣繼續堅守我的誡命和典章，我必使他的國永遠穩固。』</span>
<span className="v" id="v8" data-v="8" data-xref="申命記 4:1; 申命記 5:32–3; 箴言 2:1–5"> 現在，當著耶和華的會眾——全體以色列人的面，趁著我們的上帝在垂聽，你們要謹遵你們的上帝耶和華的一切誡命，以便你們可以擁有這片佳美之地，並且把它傳給你們的子孫作永遠的產業。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="耶利米書 29:13; 雅各書 4:8–11; 馬太福音 7:7–8"> 「我兒所羅門啊，你要認識你父親的上帝耶和華，誠心樂意地事奉祂，因為祂洞察人心，知道人一切的心思意念。倘若你尋求祂，祂必讓你尋見；倘若你背棄祂，祂必永遠丟棄你。</span>
<span className="v" id="v10" data-v="10" data-xref="歷代志上 28:6; 提摩太前書 4:16; 歷代志上 22:16–19"> 現在你要謹慎，因為耶和華揀選你來建造殿宇作聖所。你要堅定不移地去做。」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="歷代志上 28:19; 列王紀上 6:3; 出埃及記 25:40"> 大衛將殿的走廊、房舍、庫房、樓房、內室和安放施恩座的聖所的圖樣都交給他兒子所羅門，</span>
<span className="v" id="v12" data-v="12" data-xref="歷代志上 26:20; 列王紀上 14:26; 出埃及記 25:40"> 又將心裡構想的耶和華殿的院子、四周的房屋、殿的庫房和聖物庫房的圖樣都交給他。</span>
<span className="v" id="v13" data-v="13" data-xref="歷代志上 9:29; 歷代志上 25:1–31; 列王紀上 7:1–51"> 大衛還讓他知道祭司和利未人的班次、耶和華殿裡各樣的工作及一切所需的器皿，</span>
<span className="v" id="v14" data-v="14"> 製造聖殿中各種金器銀器所需金銀的分量，</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及記 25:31–39; 撒迦利亞書 4:11–14; 啟示錄 1:12–13"> 就是金燈臺和金燈的分量，銀燈臺和銀燈的分量，按每座燈臺和燈的分量及每座燈臺的用途酌定金銀的分量，</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀上 7:48; 歷代志下 4:8; 出埃及記 25:23–30"> 每張放供餅的金桌子的分量，銀桌子的分量，</span>
<span className="v" id="v17" data-v="17" data-xref="列王紀上 10:21; 歷代志下 4:20–22; 民數記 7:13–14"> 純金的叉子、碗、瓶的分量，每個金碗和銀碗的分量，</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及記 25:18–22; 出埃及記 30:1–10; 詩篇 80:1"> 純金香壇的分量，以及在施恩車座上展開翅膀遮蓋耶和華約櫃的基路伯天使的樣式。</span>
<span className="v" id="v19" data-v="19" data-xref="歷代志上 28:11–12; 出埃及記 25:40; 以西結書 3:14"> 大衛說：「以上這一切都是耶和華親手指示我的，讓我明白工作的細節。」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="歷代志上 22:13; 約書亞記 1:5–9; 以賽亞書 41:10"> 大衛又對兒子所羅門說：「你要堅定勇敢地去做！不要驚慌害怕，因為我的上帝耶和華必不撇下你，也不丟棄你，祂必與你同在，直到聖殿的一切工作完畢。</span>
<span className="v" id="v21" data-v="21" data-xref="歷代志上 24:1–26; 歷代志上 22:17–18; 出埃及記 31:3"> 你看，在上帝殿裡司職的各班祭司和利未人已準備就緒，又有各種能工巧匠樂意在各種工作上幫你，眾官長和百姓都聽你調遣。」</span>
</div>
</div>

## 大衛擊敗亞捫人和亞蘭人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳記上 11:1–2; 撒母耳記下 10:1–19; 撒母耳記上 12:12"> 後來，亞捫王拿轄死了，他兒子繼位。</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 23:3–6; 撒母耳記上 30:26; 創世記 19:37–38"> 大衛說：「我要恩待拿轄的兒子哈嫩，因為他父親曾經恩待我。」他便派使臣去安慰喪父的哈嫩。大衛的臣僕來到亞捫境內要安慰哈嫩，</span>
<span className="v" id="v3" data-v="3" data-xref="士師記 1:23–24; 哥林多前書 13:5–7; 列王紀上 12:8–11"> 亞捫的官長卻對哈嫩說：「大衛派人來安慰你，你以為他是來弔唁你父親嗎？他的臣僕來見你，不過是要探聽虛實，想摧毀這地方。」</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳記下 10:4–5; 以賽亞書 15:2; 馬可福音 12:4"> 哈嫩便把大衛的臣僕抓起來，剃去他們的鬍鬚，從臀部割去他們下半身的衣服，然後放走他們。</span>
<span className="v" id="v5" data-v="5" data-xref="約書亞記 6:24–26; 馬太福音 18:31; 列王紀上 16:34"> 消息傳到大衛那裡，他就派人去迎接他們，因為他們倍受羞辱。王告訴他們留在耶利哥，等鬍鬚長好了再回來。</span>
<span className="v" id="v6" data-v="6" data-xref="歷代志上 18:5; 創世記 34:30; 歷代志上 18:9"> 哈嫩及其他亞捫人知道得罪了大衛，就派人用六十八萬兩銀子從美索不達米亞、亞蘭瑪迦和瑣巴招兵買馬，</span>
<span className="v" id="v7" data-v="7" data-xref="民數記 21:30; 約書亞記 13:9; 約書亞記 13:16"> 雇了三萬二千輛戰車和瑪迦王及其軍隊。他們在米底巴附近紮營，亞捫人也從各城出來匯集在一起，準備作戰。</span>
<span className="v" id="v8" data-v="8" data-xref="歷代志上 11:6; 歷代志上 11:10–47; 撒母耳記下 23:8–39"> 大衛聽見消息後，就派約押率領全體勇士出戰。</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀上 20:1; 列王紀上 20:24; 以賽亞書 28:6"> 亞捫人在城門前列陣，來助戰的諸王在郊野列陣。</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳記下 10:9–14; 士師記 20:42–43; 約書亞記 8:22"> 約押見自己腹背受敵，就從以色列軍中挑選一些精兵列陣迎戰亞蘭人，</span>
<span className="v" id="v11" data-v="11" data-xref="歷代志上 18:12; 歷代志上 11:20; 歷代志上 19:9"> 把餘下的軍兵交給他的兄弟亞比篩帶領，列陣迎戰亞捫人。</span>
<span className="v" id="v12" data-v="12" data-xref="腓立比書 1:27–28; 尼希米記 4:20; 傳道書 4:9–12"> 他對亞比篩說：「倘若我勝不過亞蘭人，你便過來支援我；倘若你勝不過亞捫人，我便過去支援你。</span>
<span className="v" id="v13" data-v="13" data-xref="尼希米記 4:14; 詩篇 27:14; 撒母耳記下 10:12"> 你要剛強，我們要為我們的人民和我們上帝的城邑奮勇作戰。願耶和華成全祂自己的旨意！」</span>
<span className="v" id="v14" data-v="14" data-xref="列王紀上 20:19–21; 歷代志下 13:5–16; 耶利米書 46:15–16"> 於是，約押率領軍兵進攻亞蘭人，亞蘭人敗逃。</span>
<span className="v" id="v15" data-v="15" data-xref="羅馬書 8:31; 利未記 26:7"> 亞捫人見亞蘭人敗逃，便也從亞比篩面前逃回城去。約押便回師耶路撒冷。</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳記下 10:16; 撒迦利亞書 14:1–3; 彌迦書 4:11–12"> 亞蘭人見自己敗給以色列人，就派使者調來幼發拉底河那邊的亞蘭人，由哈大底謝的將軍朔法率領。</span>
<span className="v" id="v17" data-v="17" data-xref="以賽亞書 22:6–7; 歷代志上 19:9"> 大衛聽到消息後，就召集以色列全軍，渡過約旦河，去攻打亞蘭人，列陣與他們交戰。</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳記下 10:18; 詩篇 33:16; 詩篇 18:32"> 亞蘭人在以色列人面前敗逃，大衛殺了他們七千名戰車兵、四萬步兵，還殺了他們的將軍朔法。</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳記下 10:19; 約書亞記 9:9–11; 列王紀上 20:1"> 哈大底謝的屬下見自己敗給以色列人，便向大衛求和，臣服於他。從此，亞蘭人不願再支援亞捫人了。</span>

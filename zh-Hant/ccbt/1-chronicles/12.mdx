## 投奔大衛的人

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="撒母耳記上 27:2–6; 歷代志上 11:24–25; 歷代志上 8:33"> 大衛在洗革拉躲避基士的兒子掃羅的時候，有些勇士來投奔他，幫助他作戰。</span>
<span className="v" id="v2" data-v="2" data-xref="士師記 3:15; 士師記 20:16; 撒母耳記上 17:49"> 他們是弓箭手，左右手都能甩石射箭，來自便雅憫支派，與掃羅同族。</span>
<span className="v" id="v3" data-v="3" data-xref="歷代志上 11:28; 撒母耳記下 21:6; 歷代志上 11:33"> 他們的首領是亞希以謝，其次是約阿施，都是基比亞人示瑪的兒子，還有亞斯瑪威的兒子耶薛和毗力，以及比拉迦、亞拿突人耶戶，</span>
<span className="v" id="v4" data-v="4" data-xref="約書亞記 9:3; 約書亞記 15:36; 歷代志上 11:15"> 統領三十位勇士的傑出戰士基遍人以實買雅，他在三十人中是勇士，另有耶利米、雅哈悉、約哈難、基得拉人約撒拔、</span>
<span className="v" id="v5" data-v="5"> 伊利烏賽、耶利摩、比亞利雅、示瑪利雅、哈律弗人示法提雅、</span>
<span className="v" id="v6" data-v="6"> 可拉人以利加拿、耶西亞、亞薩列、約以謝、雅朔班、</span>
<span className="v" id="v7" data-v="7" data-xref="約書亞記 15:58; 歷代志上 4:18; 歷代志上 4:39"> 基多人耶羅罕的兒子猶拉和西巴第雅。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳記下 2:18; 撒母耳記下 17:10; 撒母耳記下 23:20"> 有些迦得支派的人到曠野的堡壘投奔大衛，他們是能征慣戰的勇士，善用盾和矛，貌似雄獅，快如山鹿。</span>
<span className="v" id="v9" data-v="9"> 他們為首的是以薛，其次是俄巴底雅，第三是以利押，</span>
<span className="v" id="v10" data-v="10"> 第四是彌施瑪拿，第五是耶利米，</span>
<span className="v" id="v11" data-v="11"> 第六是亞太，第七是以利業，</span>
<span className="v" id="v12" data-v="12"> 第八是約哈難，第九是以利薩巴，</span>
<span className="v" id="v13" data-v="13"> 第十是耶利米，第十一是末巴奈。</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 32:30; 利未記 26:8"> 這些迦得人都是將領，級別最低的統領一百人，最高的統領一千人。</span>
<span className="v" id="v15" data-v="15" data-xref="約書亞記 3:15; 約書亞記 4:18; 耶利米書 49:19"> 一月，約旦河水漲過兩岸的時候，他們渡到河對岸，把住在平原的人打得東奔西逃。</span>
<span className="v" id="v16" data-v="16"> 便雅憫支派和猶大支派中也有人到堡壘投奔大衛，</span>
<span className="v" id="v17" data-v="17" data-xref="彼得前書 2:23; 猶大書 1:9; 哥林多後書 13:11"> 大衛出去迎接他們，說：「如果你們是好心來幫助我的，我就與你們結盟，但如果你們把我這無罪之人出賣給敵人，願我們祖先的上帝鑒察、懲罰你們。」</span>
<span className="v" id="v18" data-v="18" data-xref="士師記 6:34; 士師記 3:10; 撒母耳記下 17:25"> 當時，上帝的靈感動那三十位勇士的首領亞瑪撒，他就說：<br /><span className="pl pl-1">「大衛啊，我們是你的人！</span><br /><span className="pl pl-1">耶西的兒子啊，我們擁護你！</span><br /><span className="pl pl-1">願你無比昌盛！</span><br /><span className="pl pl-1">願幫助你的人也都昌盛！</span><br /><span className="pl pl-1">因為你的上帝幫助你。」</span>大衛便收留他們，派他們統領他的隊伍。</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳記上 29:2–9"> 從前，大衛和非利士人一同去攻打掃羅的時候，有些瑪拿西人來投奔大衛。但大衛及其部下沒有幫助非利士人作戰，因為非利士人的首領商議後，害怕大衛拿著非利士人的頭顱去歸順他的主人掃羅，便讓他們走了。</span>
<span className="v" id="v20" data-v="20" data-xref="申命記 33:17; 申命記 1:15; 撒母耳記上 29:11"> 大衛回洗革拉的時候，瑪拿西支派的千夫長押拿、約撒拔、耶疊、米迦勒、約撒拔、以利戶、洗勒太都來投奔他。</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳記上 30:1–17; 歷代志上 12:20; 歷代志上 5:24"> 他們都是作戰英勇的將領，幫助大衛抗擊匪徒。</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳記下 3:1; 約伯記 17:9; 創世記 32:2"> 那時天天有人來投效大衛，以致形成一支大軍，好像上帝的軍隊。</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳記下 2:3–4; 歷代志上 11:10; 撒母耳記上 16:1"> 有些武裝好的軍兵也到希伯崙投奔大衛，要把掃羅的國權交給大衛，正如耶和華的應許。以下是這些人的數目：</span>
<span className="v" id="v24" data-v="24"> 從猶大支派來了手持盾牌和長矛的六千八百名戰士；</span>
<span className="v" id="v25" data-v="25"> 從西緬支派來了七千一百名英勇的戰士；</span>
<span className="v" id="v26" data-v="26"> 從利未支派來了四千六百人；</span>
<span className="v" id="v27" data-v="27" data-xref="列王紀下 11:9; 列王紀下 25:18; 歷代志上 6:49–57"> 亞倫家族中的首領耶何耶大和他的三千七百個隨從；</span>
<span className="v" id="v28" data-v="28" data-xref="撒母耳記下 8:17; 歷代志上 6:8; 歷代志上 6:53"> 年輕、英勇的撒督和他家族的二十二個將領；</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳記下 2:8–9; 歷代志上 12:2; 創世記 31:23"> 掃羅的親族、便雅憫支派中有三千人，大部分便雅憫人仍然效忠掃羅家；</span>
<span className="v" id="v30" data-v="30" data-xref="創世記 6:4"> 來自以法蓮支派、在本族中有名望的兩萬零八百個英勇的戰士；</span>
<span className="v" id="v31" data-v="31" data-xref="約書亞記 17:1–18"> 來自瑪拿西半個支派、被點名選出來擁立大衛做王的一萬八千人；</span>
<span className="v" id="v32" data-v="32" data-xref="以弗所書 5:17; 路加福音 12:56–57; 以斯帖記 1:13"> 來自以薩迦支派、洞悉時事且深明以色列當行之道、統領族人的二百位族長；</span>
<span className="v" id="v33" data-v="33" data-xref="詩篇 12:2; 約翰福音 1:47"> 來自西布倫支派、能征善戰、擁有各種兵器、訓練有素、忠心耿耿的五萬人；</span>
<span className="v" id="v34" data-v="34"> 來自拿弗他利支派的一千名將領和三萬七千名手持盾牌和長矛的隨從；</span>
<span className="v" id="v35" data-v="35"> 來自但支派的兩萬八千六百名能征善戰的人；</span>
<span className="v" id="v36" data-v="36" data-xref="歷代志上 12:33; 約珥書 2:7"> 來自亞設支派的四萬名能征善戰的精兵；</span>
<span className="v" id="v37" data-v="37" data-xref="約書亞記 14:3; 申命記 3:12–16; 約書亞記 13:7–32"> 來自約旦河東邊的呂便支派、迦得支派和瑪拿西半個支派的十二萬擁有各種兵器的人。</span>
<span className="v" id="v38" data-v="38" data-xref="創世記 49:8–10; 列王紀上 8:61; 詩篇 101:2"> 以上這些人都是訓練有素的勇士，他們誠心誠意到希伯崙擁立大衛做以色列王，其餘的以色列人也都齊心要立大衛做王。</span>
<span className="v" id="v39" data-v="39" data-xref="創世記 31:54; 撒母耳記下 19:42; 創世記 26:30"> 他們在那裡與大衛一起吃喝了三天，因為他們的親族為他們預備了食物。</span>
<span className="v" id="v40" data-v="40" data-xref="撒母耳記上 25:18; 撒母耳記下 16:1; 耶利米書 23:5–6"> 他們周圍的人，遠至以薩迦、西布倫和拿弗他利各支派的人，都用驢、駱駝、騾子和牛馱來麵餅、無花果餅、葡萄乾、酒和油，又牽來許多牛和羊，以色列充滿了歡樂。</span>

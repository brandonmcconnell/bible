## 呂便的後裔

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 35:22; 創世記 29:32; 創世記 48:15–22"> 以色列的長子原是呂便，但因為他玷污了父親的床<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="指跟父親的妾通姦一事，參見創世記35·22。">a</a></sup>，他長子的名分就給了他弟弟約瑟的後代。因此，按家譜他不是長子。</span>
<span className="v" id="v2" data-v="2" data-xref="馬太福音 2:6; 彌迦書 5:2; 希伯來書 7:14"> 猶大雖然在眾弟兄中最強大，君王也是出自他的後裔，長子的名分卻屬於約瑟。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 46:9; 出埃及記 6:14; 民數記 26:5–9"> 以色列長子呂便的兒子是哈諾、法路、希斯倫和迦米。</span>
<span className="v" id="v4" data-v="4"> 約珥的兒子是示瑪雅，示瑪雅的兒子是歌革，歌革的兒子是示每，</span>
<span className="v" id="v5" data-v="5"> 示每的兒子是米迦，米迦的兒子是利亞雅，利亞雅的兒子是巴力，</span>
<span className="v" id="v6" data-v="6" data-xref="歷代志上 5:26; 列王紀下 15:29; 歷代志下 28:20"> 巴力的兒子是備拉。備·拉是呂便支派的首領，被亞述王提革拉·毗尼色擄去。</span>
<span className="v" id="v7" data-v="7" data-xref="歷代志上 5:17"> 按家譜記載，他做族長的親族是耶利、撒迦利雅和比拉。</span>
<span className="v" id="v8" data-v="8" data-xref="歷代志上 5:4; 民數記 32:34; 民數記 32:38"> 比拉是亞撒的兒子，亞撒是示瑪的兒子，示瑪是約珥的兒子。約珥住在亞羅珥至尼波和巴力·免一帶。</span>
<span className="v" id="v9" data-v="9" data-xref="約書亞記 22:8–9"> 他們的牲畜在基列增多，便又向東遷移到幼發拉底河西邊的曠野。</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 21:9; 歷代志上 5:18–21; 詩篇 83:6"> 掃羅執政期間，呂便人與夏甲人交戰，打敗了夏甲人，佔領了他們在基列東邊的整片土地。</span>
</div>
</div>

## 迦得的後裔

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="約書亞記 13:11; 約書亞記 13:24–28; 申命記 3:10–17"> 迦得的後代住在毗鄰呂便支派的巴珊，向東遠至撒迦。</span>
<span className="v" id="v12" data-v="12"> 在巴珊做首領的有族長約珥、副族長沙番以及雅乃和沙法。</span>
<span className="v" id="v13" data-v="13"> 他們同族的弟兄有米迦勒、米書蘭、示巴、約賴、雅干、細亞和希伯，共七人。</span>
<span className="v" id="v14" data-v="14"> 這些都是亞比孩的兒子。亞比孩是戶利的兒子，戶利是耶羅亞的兒子，耶羅亞是基列的兒子，基列是米迦勒的兒子，米迦勒是耶示篩的兒子，耶示篩是耶哈多的兒子，耶哈多是布斯的兒子。</span>
<span className="v" id="v15" data-v="15"> 古尼的孫子、押比碟的兒子亞希是他們家族的族長。</span>
<span className="v" id="v16" data-v="16" data-xref="歷代志上 27:29; 雅歌 2:1; 以賽亞書 35:2"> 他們住在基列、巴珊和巴珊附近的鄉村以及沙崙所有的草原，直到四圍的邊界地帶。</span>
<span className="v" id="v17" data-v="17" data-xref="列王紀下 14:16; 列王紀下 14:28; 列王紀下 15:32"> 這些人是在猶大王約坦和以色列王耶羅波安執政期間被記錄在族譜裡的。</span>
<span className="v" id="v18" data-v="18" data-xref="民數記 1:3; 約書亞記 4:12–13"> 呂便支派、迦得支派和瑪拿西半個支派中善用盾牌、刀劍、弓箭、能征善戰的勇士共有四萬四千七百六十人。</span>
<span className="v" id="v19" data-v="19" data-xref="創世記 25:15; 歷代志上 1:31; 歷代志上 5:10"> 他們與夏甲人、伊突人、拿非施人和挪答人打仗，</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 22:4–5; 詩篇 9:10; 歷代志下 18:31"> 擊敗了夏甲人及其盟軍，因為他們信靠上帝，在作戰的時候向上帝求助，上帝應允了他們的祈求。</span>
<span className="v" id="v21" data-v="21" data-xref="啟示錄 18:13; 民數記 31:35"> 他們從敵人那裡擄走了五萬隻駱駝、二十五萬隻羊、兩千頭驢和十萬人口。</span>
<span className="v" id="v22" data-v="22" data-xref="歷代志下 32:8; 羅馬書 8:31; 約書亞記 23:10"> 敵人傷亡慘重，因為他們有上帝相助。他們佔據敵人的土地，一直到被擄的時候。</span>
</div>
</div>

## 瑪拿西的半個支派

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="申命記 3:8–9; 雅歌 4:8; 詩篇 133:3"> 瑪拿西半個支派的人住在從巴珊到巴力·黑門、示尼珥和黑門山一帶，他們人數眾多。</span>
<span className="v" id="v24" data-v="24" data-xref="歷代志上 4:38"> 他們的族長以弗、以示、以利業、亞斯列、耶利米、何達威雅、雅疊都是英勇的戰士，是著名的人物和各家族的首領。</span>
<span className="v" id="v25" data-v="25" data-xref="啟示錄 17:5; 詩篇 106:34–39; 出埃及記 34:15"> 可是，他們卻背棄他們祖先的上帝，與當地居民的神明苟合。上帝曾在他們面前毀滅那些居民。</span>
<span className="v" id="v26" data-v="26" data-xref="列王紀下 15:19; 列王紀下 17:6; 列王紀下 15:29"> 因此，以色列的上帝驅使亞述王普勒，即提革拉·毗尼色，把呂便人、迦得人、瑪拿西半個支派的人擄到哈臘、哈博、哈拉和歌散河邊，他們至今還在那裡。</span>
</div>
</div>

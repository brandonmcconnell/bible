## 上帝對大衛的應許

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歷代志下 6:7–9; 歷代志上 15:1; 歷代志上 17:5"> 大衛住進宮殿後，對拿單先知說：「你看，我住在香柏木建的王宮中，耶和華的約櫃卻還在帳幕裡。」</span>
<span className="v" id="v2" data-v="2" data-xref="歷代志上 28:2; 哥林多前書 13:9; 撒迦利亞書 8:23"> 拿單對大衛說：「你有什麼想法，就去做吧！因為上帝與你同在。」</span>
<span className="v" id="v3" data-v="3" data-xref="阿摩司書 3:7; 民數記 12:6; 以賽亞書 30:21"> 當晚，上帝對拿單說：</span>
<span className="v" id="v4" data-v="4" data-xref="歷代志上 28:2–3; 以賽亞書 55:8–9; 歷代志下 6:8–9"> 「你去告訴我的僕人大衛，『耶和華說，你不可建造殿宇給我居住。』</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳記下 7:6; 出埃及記 40:2–3; 列王紀上 8:16"> 從我把以色列人帶出埃及那天起，直到今天，我從未住過殿宇，都住在四處遷移的帳幕裡。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳記下 7:7; 民數記 10:33–36; 哥林多後書 6:16"> 在我與以色列人同行的日子，我從未責問任何我委派牧養我子民的士師，『你為何不為我建香柏木的殿宇呢？』</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳記下 6:21; 出埃及記 3:1–10; 撒母耳記上 17:15"> 「現在你要告訴我的僕人大衛，『萬軍之耶和華說：你原本在草場牧羊，我召你來做我以色列子民的首領。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳記上 18:14; 歷代志上 17:2; 詩篇 113:7–8"> 無論你去哪裡，我都與你同在，為你剷除所有仇敵。現在我要使你聲名遠揚，與世上的偉人齊名。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及記 2:23; 以西結書 28:4; 以弗所書 5:6"> 我必為我的以色列子民預備一個地方，栽培他們，使他們住在自己的家園，不再受驚擾，不會像從前我設立士師治理他們的時候那樣受惡人壓迫。我必使你安定，免受仇敵的侵擾，我耶和華向你宣告，我必為你建立王朝。</span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 132:11; 列王紀上 1:21; 歷代志上 28:5"> 你離世歸祖時，我必興起你親生的後裔接替你，使他的國穩固。</span>
<span className="v" id="v12" data-v="12" data-xref="列王紀上 5:5; 但以理書 2:44; 以賽亞書 9:7"> 他要為我建造殿宇，我必堅立他的王位，直到永遠。</span>
<span className="v" id="v13" data-v="13" data-xref="希伯來書 1:5; 以賽亞書 55:3; 歷代志上 17:12"> 我要做他的父親，他要做我的兒子。我的慈愛曾離開在你之前的那位，但我的慈愛必不離開他。</span>
<span className="v" id="v14" data-v="14" data-xref="詩篇 89:36; 路加福音 1:32–33; 詩篇 72:17"> 我要使他永遠治理我的家和我的國。他的王位必永遠穩固。』」</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米書 23:28; 使徒行傳 20:27; 撒母耳記下 7:17"> 拿單就把所聽到的啟示全部告訴大衛。</span>
</div>
</div>

## 大衛的禱告

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="撒母耳記下 7:18; 創世記 32:10; 以弗所書 3:8"> 於是，大衛王進去，在耶和華面前坐下，說：「耶和華上帝啊，我是誰？我的家算什麼？你竟這樣厚待我。</span>
<span className="v" id="v17" data-v="17" data-xref="歷代志上 17:11–15; 腓立比書 2:8–11; 以賽亞書 49:6"> 上帝啊，在你眼中這還不夠，你還說到僕人家的將來。耶和華上帝啊，你視我為尊貴的人。</span>
<span className="v" id="v18" data-v="18" data-xref="約翰福音 21:17; 撒母耳記上 2:30; 撒母耳記下 7:20–24"> 你將尊榮加於僕人，大衛還能對你說什麼呢？因為你深知你的僕人。</span>
<span className="v" id="v19" data-v="19" data-xref="以賽亞書 37:35; 撒母耳記下 7:21; 但以理書 9:17"> 耶和華啊，你按照自己的心意為僕人成就這大事，以顯明這一切偉大之事。</span>
<span className="v" id="v20" data-v="20" data-xref="以賽亞書 44:6; 耶利米書 10:6–7; 以弗所書 3:20"> 耶和華啊，我們從未聽過有誰能與你相比，你是獨一無二的上帝。</span>
<span className="v" id="v21" data-v="21" data-xref="以西結書 20:9–10; 以賽亞書 63:9; 以賽亞書 48:9"> 世上哪個民族比得上你的以色列子民呢？你從埃及救贖他們，讓他們做你的子民，行偉大而可畏的事，把外族人從他們面前趕走，以彰顯你的大名。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及記 19:5–6; 彼得前書 2:9; 羅馬書 11:1–12"> 你讓以色列人永遠做你的子民，你耶和華做他們的上帝。</span>
<span className="v" id="v23" data-v="23" data-xref="詩篇 119:49; 耶利米書 11:5; 路加福音 1:38"> 「耶和華啊，求你永遠信守你對僕人和僕人家的應許，求你成就你的應許。</span>
<span className="v" id="v24" data-v="24" data-xref="馬太福音 6:13; 耶利米書 31:1; 啟示錄 21:3"> 這樣，你的名必永遠堅立，被尊崇，人們必說，『以色列的上帝——萬軍之耶和華是以色列的上帝』，你僕人大衛的家必在你面前堅立。</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳記上 9:15; 以西結書 36:37; 詩篇 10:17"> 我的上帝啊，因為你曾啟示僕人，說要為僕人建立王朝，僕人才敢這樣向你祈禱。</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及記 34:6–7; 希伯來書 6:18; 提多書 1:2"> 耶和華啊，唯有你是上帝，你應許要將這福氣賜給僕人。</span>
<span className="v" id="v27" data-v="27" data-xref="以弗所書 1:3; 羅馬書 11:29; 詩篇 72:17"> 願你賜福給僕人家，使僕人家在你面前永續不斷。耶和華啊，你已賜下祝福，你的祝福是永遠的！」</span>
</div>
</div>

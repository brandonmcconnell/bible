## 大衛的頌歌

<div className="bt">
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="撒母耳記下 22:1; 詩篇 18:1; 撒母耳記下 23:1–2"> 那一天，大衛初次指派亞薩和他的親族唱詩歌頌耶和華，說：</span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 105:1–15; 以賽亞書 12:4; 列王紀下 19:19"> <span className="pl pl-1">「你們要稱謝耶和華，</span><br /><span className="pl pl-1">呼求祂的名，</span><br /><span className="pl pl-1">在列邦傳揚祂的作為。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="歌羅西書 3:16; 詩篇 96:1–3; 詩篇 98:1–4"> <span className="pl pl-1">要歌頌、讚美祂，</span><br /><span className="pl pl-1">述說祂一切奇妙的作為。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="馬太福音 7:7–8; 耶利米書 29:13; 詩篇 34:2"> <span className="pl pl-1">要以祂的聖名為榮，</span><br /><span className="pl pl-1">願尋求耶和華的人心中快樂。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 27:8–9; 西番雅書 2:2–3; 詩篇 68:35"> <span className="pl pl-1">要尋求耶和華和祂的能力，</span><br /><span className="pl pl-1">時常來到祂面前。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 111:4; 詩篇 119:20; 詩篇 103:2"> <span className="pl pl-1">祂僕人以色列的後裔啊，</span><br /><span className="pl pl-1">祂所揀選的雅各的子孫啊，</span><br /><span className="pl pl-1">要記住祂所行的神蹟奇事和祂口中的判詞。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="詩篇 48:10–11; 以賽亞書 26:9; 出埃及記 15:2"> <span className="pl pl-1">「祂是我們的上帝耶和華，</span><br /><span className="pl pl-1">祂在普天下施行審判。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 105:8; 瑪拉基書 4:4; 申命記 7:9"> <span className="pl pl-1">要永遠銘記祂的約，</span><br /><span className="pl pl-1">歷經千代也不可忘記祂的應許，</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="創世記 26:3; 創世記 17:2; 創世記 35:11"> <span className="pl pl-1">就是祂與亞伯拉罕所立的約，</span><br /><span className="pl pl-1">向以撒所起的誓。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="創世記 17:7–8; 創世記 35:11–12; 約書亞記 24:11–13"> <span className="pl pl-1">祂將這約定為律例賜給雅各，</span><br /><span className="pl pl-1">定為永遠的約賜給以色列。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="創世記 13:15; 彌迦書 2:5; 創世記 17:8"> <span className="pl pl-1">祂說，『我必把迦南賜給你，</span><br /><span className="pl pl-1">作為你的產業。』</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v19" data-v="19" data-xref="創世記 34:30; 申命記 7:7; 使徒行傳 7:5"> <span className="pl pl-1">「那時他們人丁稀少，</span><br /><span className="pl pl-1">寥寥可數，在當地寄居，</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="創世記 46:6; 創世記 20:1; 創世記 46:3"> <span className="pl pl-1">他們在異國他鄉流離飄零。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="創世記 12:17; 創世記 20:3; 出埃及記 7:15–18"> <span className="pl pl-1">耶和華不容人壓迫他們，</span><br /><span className="pl pl-1">還為他們的緣故責備君王，</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="創世記 20:7; 詩篇 105:15; 創世記 49:8–10"> <span className="pl pl-1">說，『不可加害我膏立的人，</span><br /><span className="pl pl-1">也不可傷害我的先知。』</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v23" data-v="23" data-xref="詩篇 96:1–13; 詩篇 71:15; 以賽亞書 51:6–8"> <span className="pl pl-1">「普世都要歌頌耶和華，</span><br /><span className="pl pl-1">天天傳揚祂的救恩；</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="以賽亞書 12:2–6; 但以理書 4:1–3; 詩篇 22:27"> <span className="pl pl-1">要在列國述說祂的榮耀，</span><br /><span className="pl pl-1">在萬民中述說祂的奇妙作為。</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="詩篇 89:7; 詩篇 76:7; 詩篇 66:3–5"> <span className="pl pl-1">因為耶和華無比偉大，</span><br /><span className="pl pl-1">當受至高的頌揚；</span><br /><span className="pl pl-1">祂超越一切神明，</span><br /><span className="pl pl-1">當受敬畏。</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="詩篇 102:25; 利未記 19:4; 以賽亞書 42:5"> <span className="pl pl-1">列邦的神明都是假的，</span><br /><span className="pl pl-1">唯獨耶和華創造了諸天。</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="詩篇 16:11; 詩篇 96:6; 詩篇 28:7–8"> <span className="pl pl-1">祂帶著尊貴和威嚴，</span><br /><span className="pl pl-1">祂的聖所充滿能力和喜樂。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v28" data-v="28" data-xref="哥林多前書 15:10; 腓立比書 4:13; 詩篇 100:1–2"> <span className="pl pl-1">「萬族萬民啊，</span><br /><span className="pl pl-1">要把榮耀和能力歸給耶和華，</span><br /><span className="pl pl-1">歸給耶和華！</span><br /></span>
<span className="v" id="v29" data-v="29" data-xref="詩篇 100:4; 詩篇 96:9; 以賽亞書 6:3"> <span className="pl pl-1">要將耶和華之名當得的榮耀歸給祂，</span><br /><span className="pl pl-1">要將供物獻給祂，</span><br /><span className="pl pl-1">要穿聖衣敬拜耶和華</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或譯「要敬拜聖潔榮耀的耶和華」。">a</a></sup><br /><span className="pl pl-1">。</span><br /></span>
<span className="v" id="v30" data-v="30" data-xref="詩篇 33:9; 詩篇 148:5–6; 希伯來書 1:3"> <span className="pl pl-1">大地要在祂面前顫抖；</span><br /><span className="pl pl-1">世界堅立不搖。</span><br /></span>
<span className="v" id="v31" data-v="31" data-xref="詩篇 96:10; 啟示錄 19:6; 詩篇 97:1"> <span className="pl pl-1">願天歡喜，願地快樂；</span><br /><span className="pl pl-1">願他們在列國宣告，</span><br /><span className="pl pl-1">『耶和華執掌王權！』</span><br /></span>
<span className="v" id="v32" data-v="32" data-xref="詩篇 148:9–10; 以賽亞書 44:23; 詩篇 98:7–8"> <span className="pl pl-1">願海洋和其中的萬物都歡呼，</span><br /><span className="pl pl-1">願田野和其中的一切都歡騰！</span><br /></span>
<span className="v" id="v33" data-v="33" data-xref="詩篇 98:9; 詩篇 96:12–13; 啟示錄 11:17–18"> <span className="pl pl-1">那時，林中的樹木都要在耶和華面前歡唱，</span><br /><span className="pl pl-1">因為祂要來審判天下。</span><br /></span>
<span className="v" id="v34" data-v="34" data-xref="詩篇 106:1; 歷代志下 7:3; 詩篇 107:1"> <span className="pl pl-1">你們要稱謝耶和華，</span><br /><span className="pl pl-1">因為祂是美善的，</span><br /><span className="pl pl-1">祂的慈愛永遠長存！</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v35" data-v="35" data-xref="詩篇 106:47–48; 彼得前書 2:9; 詩篇 14:7"> <span className="pl pl-1">「要說，『拯救我們的上帝啊，</span><br /><span className="pl pl-1">求你拯救我們，招聚我們，</span><br /><span className="pl pl-1">把我們從列國中救出來，</span><br /><span className="pl pl-1">我們好稱謝你的聖名，</span><br /><span className="pl pl-1">以讚美你為榮。』</span><br /></span>
<span className="v" id="v36" data-v="36" data-xref="列王紀上 8:15; 詩篇 72:18–19; 列王紀上 8:56"> <span className="pl pl-1">以色列的上帝耶和華永永遠遠當受稱頌！」</span><br /><span className="pl pl-1">眾民都說：「阿們！」</span><br /><span className="pl pl-1">並讚美耶和華。</span></span>
</div>

## 分派事奉的人員

<div className="bt">
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="歷代志下 8:14; 以斯拉記 3:4; 歷代志上 16:4–6"> 大衛派亞薩及其親族天天在約櫃前事奉耶和華，盡當盡的職分；</span>
<span className="v" id="v38" data-v="38" data-xref="歷代志上 26:10; 歷代志上 13:14; 歷代志上 25:3"> 又派俄別·以東及其六十八位親族、何薩和耶杜頓的兒子俄別·以東守門；</span>
<span className="v" id="v39" data-v="39" data-xref="列王紀上 3:4; 歷代志上 15:11; 歷代志下 1:3–4"> 並派祭司撒督及其他祭司在基遍邱壇的耶和華的聖幕前供職，</span>
<span className="v" id="v40" data-v="40" data-xref="民數記 28:3–8; 出埃及記 29:38–42; 歷代志下 31:3"> 按照耶和華在律法書上對以色列人的吩咐，每日早晚在祭壇上獻燔祭給耶和華。</span>
<span className="v" id="v41" data-v="41" data-xref="歷代志下 5:13; 歷代志上 25:1–6; 歷代志下 20:21"> 與他們一同供職的有希幔、耶杜頓和其他人，他們被特別選出來稱謝上帝，因為祂的慈愛永遠長存。</span>
<span className="v" id="v42" data-v="42" data-xref="詩篇 150:3–6; 歷代志上 25:6–7; 歷代志下 29:25–28"> 希幔和耶杜頓負責用號、鈸及其他樂器伴奏歌頌上帝。耶杜頓的子孫負責守門。</span>
<span className="v" id="v43" data-v="43" data-xref="撒母耳記下 6:19–20; 創世記 18:19; 詩篇 101:2"> 於是，眾民各自回家，大衛也回去為家人祝福。</span>

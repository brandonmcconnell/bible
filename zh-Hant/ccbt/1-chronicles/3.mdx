## 大衛的子孫

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳記下 3:2–5; 約書亞記 15:56; 撒母耳記下 13:1"> 以下是大衛在希伯崙生的兒子：長子暗嫩，由耶斯列人亞希暖所生；次子但以利，由迦密人亞比該所生；</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳記下 19:4–10; 撒母耳記下 3:4; 列王紀上 2:24–25"> 三子押沙龍，由基述王達買的女兒瑪迦所生；四子亞多尼雅，由哈及所生；</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳記下 3:5"> 五子示法提雅，由亞比她所生；六子以特念，由大衛的妻子以格拉所生。</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳記下 2:11; 撒母耳記下 5:4–5; 列王紀上 2:11"> 以上六人都是大衛在希伯崙生的。大衛在希伯崙做王七年零六個月，在耶路撒冷做王三十三年。</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳記下 11:3; 撒母耳記下 12:24–25; 撒母耳記下 12:1–15"> 大衛在耶路撒冷生的兒子有示米亞、朔罷、拿單和所羅門，這四人的母親是亞米利的女兒拔示巴。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳記下 5:15; 歷代志上 14:5; 撒母耳記上 14:5"> 大衛的兒子還有益轄、以利沙瑪、以利法列、</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳記下 5:15–16"> 挪迦、尼斐、雅非亞、</span>
<span className="v" id="v8" data-v="8" data-xref="歷代志上 14:7; 撒母耳記下 5:14–16"> 以利沙瑪、以利雅大和以利法列，共九人。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳記下 13:1–20; 撒母耳記下 5:13"> 這些都是大衛的兒子，不包括嬪妃生的兒子。大衛還有個女兒，名叫她瑪。</span>
</div>
</div>

## 所羅門的後裔

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="列王紀上 11:43; 列王紀上 14:31–1; 列王紀上 15:24"> 所羅門的兒子是羅波安，羅波安的兒子是亞比雅，亞比雅的兒子是亞撒，亞撒的兒子是約沙法，</span>
<span className="v" id="v11" data-v="11" data-xref="列王紀下 8:24; 歷代志下 21:17; 列王紀下 11:21"> 約沙法的兒子是約蘭，約蘭的兒子是亞哈謝，亞哈謝的兒子是約阿施，</span>
<span className="v" id="v12" data-v="12" data-xref="歷代志下 25:1; 列王紀下 14:21; 列王紀下 14:1"> 約阿施的兒子是亞瑪謝，亞瑪謝的兒子是亞撒利雅，亞撒利雅的兒子是約坦，</span>
<span className="v" id="v13" data-v="13" data-xref="列王紀下 18:1; 列王紀下 16:1; 歷代志下 29:1"> 約坦的兒子是亞哈斯，亞哈斯的兒子是希西迦，希西迦的兒子是瑪拿西，</span>
<span className="v" id="v14" data-v="14" data-xref="列王紀下 23:30; 歷代志下 34:1; 列王紀下 21:19"> 瑪拿西的兒子是亞們，亞們的兒子是約西亞。</span>
<span className="v" id="v15" data-v="15" data-xref="列王紀下 23:34"> 約西亞的兒子有長子約哈難、次子約雅敬、三子西底迦、四子沙龍。</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀下 24:6; 馬太福音 1:11; 列王紀下 24:17"> 約雅敬的兒子是耶哥尼雅和西底迦。</span>
</div>
</div>

## 耶哥尼雅的後裔

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="以斯拉記 3:2; 以斯拉記 5:2; 馬太福音 1:12"> 被擄的耶哥尼雅的兒子是撒拉鐵、</span>
<span className="v" id="v18" data-v="18"> 瑪基蘭、毗大雅、示拿薩、耶加米、何沙瑪、尼達比雅。</span>
<span className="v" id="v19" data-v="19" data-xref="以斯拉記 2:2; 以斯拉記 3:2; 哈該書 2:2"> 毗大雅的兒子是所羅巴伯和示每。所羅巴伯的兒子是米書蘭和哈拿尼雅，女兒是示羅密，</span>
<span className="v" id="v20" data-v="20"> 他還有五個兒子：哈舒巴、阿黑、比利迦、哈撒底、於沙·希悉。</span>
<span className="v" id="v21" data-v="21" data-xref="尼希米記 10:22"> 哈拿尼雅的兒子是毗拉提和耶篩亞。耶篩亞生利法雅，利法雅生亞珥南，亞珥南生俄巴底亞，俄巴底亞生示迦尼，</span>
<span className="v" id="v22" data-v="22" data-xref="以斯拉記 8:2"> 示迦尼的兒子是示瑪雅，示瑪雅的兒子是哈突、以甲、巴利亞、尼利雅、沙法。</span>
<span className="v" id="v23" data-v="23"> 尼利雅的三個兒子是以利約乃、希西迦和亞斯利干。</span>
<span className="v" id="v24" data-v="24"> 以利約乃的七個兒子是何大雅、以利亞實、毗萊雅、阿谷、約哈難、第萊雅和阿拿尼。</span>

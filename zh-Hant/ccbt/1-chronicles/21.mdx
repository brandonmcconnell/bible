## 大衛統計人口

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳記下 24:1–25; 撒迦利亞書 3:1; 約伯記 2:4–6"> 撒旦起來攻擊以色列，挑動大衛統計以色列人的數目。</span>
<span className="v" id="v2" data-v="2" data-xref="歷代志上 27:23–24; 撒母耳記下 3:10; 撒母耳記下 24:15"> 大衛對約押和其他軍中的首領說：「你們要去，從別示巴一直到但，統計以色列的人口，然後回來稟告我，我好知道他們的數目。」</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 1:11; 以賽亞書 26:15; 歷代志上 19:13"> 約押說：「願耶和華使祂子民的人數比現在增加百倍。但我主我王啊，他們不都是你的僕人嗎？我主為什麼要這樣做？為什麼使以色列人陷於罪中呢？」</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行傳 5:29; 出埃及記 1:17; 但以理書 3:18"> 但王不聽約押的規勸。約押只好出去，走遍以色列，然後回到耶路撒冷，</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳記下 24:9; 歷代志上 27:23"> 將人數奏告大衛：全以色列有一百一十萬刀兵，猶大有四十七萬。</span>
<span className="v" id="v6" data-v="6" data-xref="歷代志上 27:24; 民數記 1:47–49; 撒母耳記下 20:9–10"> 約押沒有把利未人和便雅憫人算在其中，因為他厭惡王的這個命令。</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀上 15:5; 約書亞記 7:5; 撒母耳記下 21:14"> 上帝也不喜悅這事，便降災給以色列人。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳記下 12:13; 約翰一書 1:9; 創世記 34:7"> 大衛對上帝說：「我做這事犯了大罪。求你赦免僕人的罪，我做了極其愚昧的事。」</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳記上 9:9; 撒母耳記下 24:11; 歷代志上 29:29"> 耶和華對大衛的先見迦得說：</span>
<span className="v" id="v10" data-v="10" data-xref="列王紀上 13:21–22; 啟示錄 3:19; 箴言 1:29–31"> 「你去告訴大衛，我有三樣災禍，他可以選擇讓我降哪一樣給他。」</span>
<span className="v" id="v11" data-v="11" data-xref="箴言 19:20"> 迦得就來見大衛，對他說：「耶和華說，『你可以任選一樣：</span>
<span className="v" id="v12" data-v="12" data-xref="申命記 28:27; 使徒行傳 12:23; 以西結書 14:19–21"> 或三年的饑荒，或被敵人的刀擊敗並追殺三個月，或國中被耶和華的刀懲罰，就是三天的瘟疫，讓耶和華的天使在以色列全境施行毀滅。請你考慮好後告訴我，我好回覆那差我來的。』」</span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 130:7; 以賽亞書 55:7; 腓立比書 1:23"> 大衛說：「我實在為難！不過我寧願落在耶和華的手中，也不願落在人的手中，因為耶和華有極大的憐憫。」</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及記 12:30; 歷代志上 27:24; 列王紀下 19:35"> 於是，耶和華在以色列降下瘟疫，有七萬人死亡。</span>
<span className="v" id="v15" data-v="15" data-xref="創世記 6:6; 出埃及記 32:14; 耶利米書 26:18"> 上帝差遣天使去毀滅耶路撒冷。天使正要毀滅的時候，耶和華見了就心生憐憫，對施行毀滅的天使說：「夠了，住手吧！」當時，耶和華的天使正站在耶布斯人阿珥楠的麥場上。</span>
<span className="v" id="v16" data-v="16" data-xref="民數記 14:5; 列王紀上 21:27; 列王紀下 6:17"> 大衛舉目看見耶和華的天使站在天地之間，手握著已出鞘的刀，指向耶路撒冷。大衛和眾長老都身披麻衣，臉伏於地。</span>
<span className="v" id="v17" data-v="17" data-xref="以西結書 16:63; 撒母耳記下 24:17; 約翰福音 10:11–12"> 大衛對上帝說：「吩咐統計人民數目的不是我嗎？是我犯了罪，做了惡事，這些百姓有什麼過錯呢？我的上帝耶和華啊，願你的手懲罰我和我的家族，不要把瘟疫降在你的子民身上。」</span>
<span className="v" id="v18" data-v="18" data-xref="歷代志下 3:1; 撒母耳記下 24:18; 歷代志上 21:11"> 耶和華的天使吩咐迦得去告訴大衛，他要在耶布斯人阿珥楠的麥場上為耶和華建一座壇。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行傳 9:6; 約翰福音 2:5; 列王紀下 5:10–14"> 大衛照迦得奉耶和華之名所說的話去了麥場。</span>
<span className="v" id="v20" data-v="20" data-xref="士師記 6:11"> 那時，阿珥楠正在打麥子，他轉身看見了天使，跟他在一起的四個兒子都躲了起來。</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳記上 25:23; 撒母耳記下 24:18–20"> 阿珥楠看見大衛來了，就從麥場出來，俯伏在地，向大衛下拜。</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳記下 24:21; 列王紀上 21:2; 民數記 25:8"> 大衛對他說：「請你將這塊麥場賣給我，我要在這裡為耶和華築一座壇，使民中的瘟疫止息。你全價賣給我吧。」</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳記下 24:22–23; 撒母耳記上 6:14; 創世記 23:4–6"> 阿珥楠說：「我主我王只管用我的麥場！我願獻出牛作燔祭，打麥的器具作柴，麥子作素祭，我願獻出這一切。」</span>
<span className="v" id="v24" data-v="24" data-xref="申命記 16:16–17; 創世記 14:23; 創世記 23:13"> 大衛王對他說：「不可，我一定要付你全價，我不要拿你的東西獻給耶和華，也不要把白白得來的獻作燔祭。」</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳記下 24:24–25"> 於是，大衛就用一百四十兩金子買了阿珥楠的麥場。</span>
<span className="v" id="v26" data-v="26" data-xref="利未記 9:24; 士師記 6:21; 箴言 15:8"> 大衛在那裡為耶和華建了一座壇，獻上燔祭和平安祭，並求告耶和華。耶和華垂聽了他的禱告，從天上降火在祭壇上，</span>
<span className="v" id="v27" data-v="27" data-xref="約翰福音 18:11; 詩篇 103:20; 歷代志上 21:15–16"> 又命令天使收刀入鞘。</span>
<span className="v" id="v28" data-v="28"> 大衛見耶和華在耶布斯人阿珥楠的麥場上應允了他的禱告，就在那裡獻祭。</span>
<span className="v" id="v29" data-v="29" data-xref="歷代志上 16:39; 歷代志下 1:3; 歷代志下 1:13"> 那時候，摩西在曠野為耶和華所造的聖幕和燔祭壇都在基遍的邱壇。</span>
<span className="v" id="v30" data-v="30" data-xref="啟示錄 1:17; 希伯來書 12:28–29; 啟示錄 15:4"> 但大衛因為懼怕耶和華天使的刀，不敢去那裡求問上帝。</span>

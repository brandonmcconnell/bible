## 大衛籌備建殿

<div className="bt">
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="歷代志下 2:17; 列王紀上 9:20–21; 列王紀上 5:17–18"> 大衛下令召集住在以色列的外族人，派他們當中的石匠採鑿建上帝殿用的石頭。</span>
<span className="v" id="v3" data-v="3" data-xref="歷代志上 22:14; 歷代志上 29:2; 列王紀上 7:47"> 大衛預備了大量的鐵，用來做門扇的釘子和鉤子，又預備了不計其數的銅。</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀上 5:6–10; 以斯拉記 3:7; 歷代志下 2:3"> 他還預備了無數的香柏木，都是西頓人和泰爾人給他運來的。</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀上 3:7; 歷代志上 29:1; 約翰福音 3:30"> 大衛說：「為耶和華建造的殿宇必須宏偉輝煌，聞名於世，而我的兒子所羅門年紀還輕、閱歷尚淺，所以我要為這殿預備材料。」因此，大衛在去世前為建殿預備了許多材料。</span>
<span className="v" id="v6" data-v="6" data-xref="民數記 27:23; 使徒行傳 20:25–31; 使徒行傳 1:2"> 大衛召來兒子所羅門，囑咐他要為以色列的上帝耶和華建造殿宇。</span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 132:5; 列王紀上 8:16–20; 歷代志下 6:7–9"> 他對所羅門說：「兒啊，我本想為我的上帝耶和華的名建造一座殿宇。</span>
<span className="v" id="v8" data-v="8" data-xref="列王紀上 5:3; 歷代志上 28:3; 歷代志上 17:4–10"> 但耶和華對我說，『你殺了許多人，打了很多仗，在我眼前使許多人血灑大地，因此你不可為我的名建造殿宇。</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀上 4:25; 列王紀上 5:4; 列王紀上 4:20"> 你將生一個兒子，我必使他安享太平，不受四圍的仇敵侵擾。他的名字要叫所羅門，他執政期間，我必使以色列太平安寧。</span>
<span className="v" id="v10" data-v="10" data-xref="希伯來書 1:5; 撒母耳記下 7:13–14; 歷代志上 17:12–14"> 他將為我的名建造殿宇，他要做我的兒子，我要做他的父親，我要使他在以色列的王位永固。』</span>
<span className="v" id="v11" data-v="11" data-xref="歷代志上 22:16; 歷代志上 28:20; 提摩太後書 4:22"> 「兒啊，願耶和華與你同在，使你亨通，照你的上帝耶和華的吩咐去建造祂的殿。</span>
<span className="v" id="v12" data-v="12" data-xref="雅各書 1:5; 箴言 14:8; 列王紀上 3:9–12"> 你的上帝耶和華賜你權柄治理以色列時，願祂賜你聰明和智慧，以便你遵行祂的律法。</span>
<span className="v" id="v13" data-v="13" data-xref="約書亞記 1:6–9; 歷代志上 28:20; 歷代志上 28:7"> 你若謹遵耶和華藉摩西吩咐以色列的律例和典章，就必亨通。你要剛強勇敢，不要驚慌害怕。</span>
<span className="v" id="v14" data-v="14" data-xref="歷代志上 22:3; 列王紀下 25:16; 歷代志上 29:4–7"> 看啊，我歷盡艱辛，為耶和華的殿預備了六千八百萬兩金子、六億八千萬兩銀子和不計其數的銅和鐵。我還預備了木料和石頭。你還要多加預備。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及記 28:6; 出埃及記 35:32; 列王紀上 7:14"> 你有許多工匠，如鑿石匠、砌石匠、木匠等各種能工巧匠，</span>
<span className="v" id="v16" data-v="16" data-xref="歷代志上 22:11; 腓立比書 4:13; 以弗所書 5:14"> 還有不計其數的金匠、銀匠、銅匠和鐵匠。現在動工吧，願耶和華與你同在。」</span>
<span className="v" id="v17" data-v="17" data-xref="歷代志上 28:1–6; 約翰三書 1:8; 歷代志上 29:6"> 大衛又吩咐以色列的眾首領幫助他兒子所羅門，</span>
<span className="v" id="v18" data-v="18" data-xref="歷代志上 22:9; 歷代志上 23:25; 撒母耳記下 7:1"> 他說：「你們的上帝耶和華與你們同在，使你們四境平安。祂將這地方的居民交在我手中，使這地方歸順祂和祂的子民。</span>
<span className="v" id="v19" data-v="19" data-xref="歷代志上 28:9; 申命記 4:29; 歷代志上 16:11"> 現在，你們要全心全意地尋求你們的上帝耶和華，去建造耶和華上帝的聖所，好將祂的約櫃和聖潔器皿都放在裡面。」</span>

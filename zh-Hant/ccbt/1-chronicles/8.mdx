## 便雅憫的後裔

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 46:21; 歷代志上 7:6–12; 民數記 26:38"> 便雅憫的長子是比拉，次子是亞實別，三子是亞哈拉，</span>
<span className="v" id="v2" data-v="2"> 四子是挪哈，五子是拉法。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 46:21; 民數記 26:40"> 比拉的兒子是亞大、基拉、亞比忽、</span>
<span className="v" id="v4" data-v="4"> 亞比書、乃幔、亞何亞、</span>
<span className="v" id="v5" data-v="5" data-xref="歷代志上 7:12; 民數記 26:39; 士師記 3:15"> 基拉、示孚汛、戶蘭。</span>
<span className="v" id="v6" data-v="6" data-xref="歷代志上 2:54; 士師記 3:20–30; 歷代志上 7:10"> 以忽的兒子是乃幔、亞希亞和基拉，他們是迦巴居民的族長，後來被擄到了瑪拿轄。基拉是烏撒和亞希忽的父親。</span>
<span className="v" id="v8" data-v="8" data-xref="路得記 1:1; 創世記 25:6"> 沙哈連休了妻子戶伸和巴拉，後來在摩押與妻子賀得生了約巴、洗比雅、米沙、瑪拉干、</span>
<span className="v" id="v10" data-v="10"> 耶烏斯、沙迦、米瑪。這些兒子都是族長。</span>
<span className="v" id="v11" data-v="11"> 戶伸給沙哈連生的兒子是亞比突和以利巴力。</span>
<span className="v" id="v12" data-v="12" data-xref="以斯拉記 2:33; 尼希米記 7:37; 尼希米記 6:2"> 以利巴力的兒子是希伯、米珊和沙麥。沙麥建立了阿挪和羅德兩座城及其周圍的村莊。</span>
<span className="v" id="v13" data-v="13" data-xref="歷代志上 2:52; 約書亞記 19:42; 歷代志上 4:4"> 以利巴力另外的兩個兒子比利亞和示瑪是亞雅崙居民的族長，他們趕走了迦特人。</span>
<span className="v" id="v14" data-v="14"> 亞希約、沙煞、耶利末、</span>
<span className="v" id="v15" data-v="15"> 西巴第雅、亞拉得、亞得、</span>
<span className="v" id="v16" data-v="16"> 米迦勒、伊施巴和約哈都是比利亞的兒子。</span>
<span className="v" id="v17" data-v="17"> 西巴第雅、米書蘭、希西基、希伯、</span>
<span className="v" id="v18" data-v="18"> 伊施米萊、伊斯利亞和約巴都是以利巴力的兒子。</span>
<span className="v" id="v19" data-v="19"> 雅金、細基利、撒底、</span>
<span className="v" id="v20" data-v="20"> 以利乃、洗勒太、以利業、</span>
<span className="v" id="v21" data-v="21"> 亞大雅、比拉雅和申拉都是示每的兒子。</span>
<span className="v" id="v22" data-v="22"> 伊施班、希伯、以利業、</span>
<span className="v" id="v23" data-v="23"> 亞伯頓、細基利、哈難、</span>
<span className="v" id="v24" data-v="24"> 哈拿尼雅、以攔、安陀提雅、</span>
<span className="v" id="v25" data-v="25"> 伊弗底雅和毗努伊勒都是沙煞的兒子。</span>
<span className="v" id="v26" data-v="26"> 珊示萊、示哈利、亞他利雅、</span>
<span className="v" id="v27" data-v="27"> 雅利西、以利亞和細基利都是耶羅罕的兒子。</span>
<span className="v" id="v28" data-v="28" data-xref="士師記 1:21; 約書亞記 15:63; 尼希米記 11:1"> 按照家譜記載，以上這些人都是族長，住在耶路撒冷。</span>
<span className="v" id="v29" data-v="29" data-xref="歷代志上 9:35–38"> 耶利建立了基遍城<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「耶利建立了基遍城」或譯「基遍之父耶利」。">a</a></sup>，定居在那裡，他妻子名叫瑪迦。</span>
<span className="v" id="v30" data-v="30" data-xref="歷代志上 9:36–37"> 他的長子是亞伯頓，其他兒子還有蘇珥、基士、巴力、拿答、</span>
<span className="v" id="v31" data-v="31" data-xref="歷代志上 9:37"> 基多、亞希約、撒迦和米基羅。</span>
<span className="v" id="v32" data-v="32" data-xref="歷代志上 9:38"> 米基羅是示米暗的父親。這些人也住在耶路撒冷，與他們的親族為鄰。</span>
<span className="v" id="v33" data-v="33" data-xref="撒母耳記上 9:1; 撒母耳記下 2:8; 撒母耳記上 31:2"> 尼珥生基士，基士生掃羅，掃羅生約拿單、麥基舒亞、亞比拿達和伊施·巴力。</span>
<span className="v" id="v34" data-v="34" data-xref="撒母耳記下 4:4; 撒母耳記下 9:12; 撒母耳記下 9:10"> 約拿單生米力·巴力，米力·巴力生米迦，</span>
<span className="v" id="v35" data-v="35" data-xref="歷代志上 9:41"> 米迦生毗敦、米勒、他利亞、亞哈斯，</span>
<span className="v" id="v36" data-v="36" data-xref="歷代志上 9:42"> 亞哈斯生耶何阿達，耶何阿達生亞拉篾、亞斯瑪威和心利，心利生摩撒，</span>
<span className="v" id="v37" data-v="37" data-xref="歷代志上 9:43"> 摩撒生比尼亞，比尼亞生拉法，拉法生以利亞薩，以利亞薩生亞悉。</span>
<span className="v" id="v38" data-v="38"> 亞悉有六個兒子，他們是亞斯利干、波基路、以實瑪利、示亞利雅、俄巴底雅和哈難。這些都是亞悉的兒子。</span>
<span className="v" id="v39" data-v="39"> 亞悉的兄弟以設的兒子有長子烏蘭，次子耶烏施，三子以利法列。</span>
<span className="v" id="v40" data-v="40" data-xref="詩篇 128:3–6; 歷代志下 14:8; 歷代志上 12:2"> 烏蘭的兒子都是善射的英勇戰士。他們子孫昌盛，共有一百五十人。以上都是便雅憫支派的人。</span>

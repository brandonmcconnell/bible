## 以色列的軍隊

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀上 4:27; 歷代志下 26:11–13; 申命記 1:15"> 以色列人的族長、千夫長、百夫長及其他官長都分定班次，每班兩萬四千人，每年按月輪流服侍王。</span>
<span className="v" id="v2" data-v="2" data-xref="歷代志上 11:11; 撒母耳記下 23:8"> 撒巴第業的兒子雅朔班負責第一班，在一月當值，他班內有兩萬四千人。</span>
<span className="v" id="v3" data-v="3" data-xref="民數記 26:20; 民數記 10:14; 創世記 49:8–10"> 他是法勒斯的後代，統管一月當值的所有將領。</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳記下 23:9; 歷代志上 11:12"> 亞哈希人朵代負責二月的班次，他的副官是密基羅，他班內有兩萬四千人。</span>
<span className="v" id="v5" data-v="5" data-xref="歷代志上 18:17; 列王紀上 4:4–5"> 祭司耶何耶大的兒子比拿雅負責第三班，在三月當值，他班內有兩萬四千人。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳記下 23:20–23; 歷代志上 11:22–25; 撒母耳記下 22:20–23"> 比拿雅是當時的三十位勇士之一，也是三十位勇士之首。他兒子暗米薩拔在他班內做統領。</span>
<span className="v" id="v7" data-v="7" data-xref="歷代志上 11:26; 撒母耳記下 23:24; 撒母耳記下 2:18–23"> 約押的兄弟亞撒黑負責第四班，在四月當值，他班內有兩萬四千人，他兒子西巴第雅後來接替了他。</span>
<span className="v" id="v8" data-v="8" data-xref="歷代志上 11:27; 撒母耳記下 23:25; 歷代志上 26:29"> 伊斯拉人珊合負責第五班，在五月當值，他班內有兩萬四千人。</span>
<span className="v" id="v9" data-v="9" data-xref="歷代志上 11:28; 撒母耳記下 23:26"> 提哥亞人益吉的兒子以拉負責第六班，在六月當值，他班內有兩萬四千人。</span>
<span className="v" id="v10" data-v="10" data-xref="歷代志上 11:27; 撒母耳記下 23:26"> 以法蓮的子孫比倫人希利斯負責第七班，在七月當值，他班內有兩萬四千人。</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳記下 21:18; 歷代志上 11:29; 民數記 26:20"> 謝拉族的戶沙人西比該負責第八班，在八月當值，他班內有兩萬四千人。</span>
<span className="v" id="v12" data-v="12" data-xref="歷代志上 11:28; 撒母耳記下 23:27"> 便雅憫的子孫亞拿突人亞比以謝負責第九班，在九月當值，他班內有兩萬四千人。</span>
<span className="v" id="v13" data-v="13" data-xref="歷代志上 11:30; 撒母耳記下 23:28"> 謝拉族的尼陀法人瑪哈萊負責第十班，在十月當值，他班內有兩萬四千人。</span>
<span className="v" id="v14" data-v="14" data-xref="歷代志上 11:31; 撒母耳記下 23:30"> 以法蓮的子孫比拉頓人比拿雅負責第十一班，在十一月當值，他班內有兩萬四千人。</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳記下 23:29; 歷代志上 4:13; 士師記 3:9"> 俄陀聶族的尼陀法人黑玳負責第十二班，在十二月當值，他班內有兩萬四千人。</span>
</div>

## 以色列各支派的官長

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16"> 以下是以色列各支派的首領：呂便支派的首領是細基利的兒子以利以謝；西緬支派的首領是瑪迦的兒子示法提雅；</span>
<span className="v" id="v17" data-v="17" data-xref="歷代志上 26:30; 歷代志上 24:31; 歷代志上 12:27–28"> 利未支派的首領是基姆利的兒子哈沙比雅；亞倫子孫的首領是撒督；</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳記上 16:6; 撒母耳記上 17:29; 撒母耳記上 17:13"> 猶大支派的首領是大衛的哥哥以利戶；以薩迦支派的首領是米迦勒的兒子暗利；</span>
<span className="v" id="v19" data-v="19"> 西布倫支派的首領是俄巴第雅的兒子伊施瑪雅；拿弗他利支派的首領是亞斯列的兒子耶利摩；</span>
<span className="v" id="v20" data-v="20"> 以法蓮支派的首領是阿撒細雅的兒子何細亞；瑪拿西半個支派的首領是毗大雅的兒子約珥；</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳記下 3:27; 撒母耳記上 14:50–51; 撒母耳記下 3:37"> 基列的瑪拿西另半個支派的首領是撒迦利亞的兒子易多；便雅憫支派的首領是押尼珥的兒子雅西業；</span>
<span className="v" id="v22" data-v="22" data-xref="歷代志上 28:1"> 但支派的首領是耶羅罕的兒子亞薩列。以上這些人是以色列各支派的首領。</span>
<span className="v" id="v23" data-v="23" data-xref="創世記 15:5; 歷代志上 21:2–5; 希伯來書 11:12"> 大衛沒有統計二十歲以下的以色列人，因為耶和華曾經應許要使以色列的人數像天上的星那樣多。</span>
<span className="v" id="v24" data-v="24" data-xref="歷代志上 21:1–17; 撒母耳記下 24:1–15"> 洗魯雅的兒子約押開始統計人數，但沒有完成，因為耶和華因此事而向以色列人發烈怒，因此統計的數目沒有收錄在《大衛王記》上。</span>
</div>
</div>

## 王室產業的主管

<div className="bt">
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="歷代志下 16:2; 出埃及記 1:11; 歷代志下 26:10"> 亞疊的兒子押斯馬威管理王室的庫房。烏西雅的兒子約拿單管理鄉間、城邑、村莊和堡壘的庫房。</span>
<span className="v" id="v26" data-v="26"> 基綠的兒子以斯利管理耕田種地的人。</span>
<span className="v" id="v27" data-v="27"> 拉瑪人示每管理葡萄園。實弗米人撒巴底管理葡萄園的酒窖。</span>
<span className="v" id="v28" data-v="28" data-xref="列王紀上 10:27; 歷代志下 1:15; 列王紀上 4:7"> 基第利人巴勒·哈南管理丘陵的橄欖樹和桑樹。約阿施管理油倉。</span>
<span className="v" id="v29" data-v="29" data-xref="歷代志上 5:16; 以賽亞書 65:10"> 沙崙人施提萊管理沙崙的牛群。亞第萊的兒子沙法管理山谷中的牛群。</span>
<span className="v" id="v30" data-v="30" data-xref="創世記 47:6; 約伯記 1:3"> 以實瑪利人阿比勒管理駱駝群。米崙人耶希底亞管理驢群。</span>
<span className="v" id="v31" data-v="31" data-xref="歷代志上 5:10"> 夏甲人雅悉管理羊群。以上這些人都是替大衛王管理產業的。</span>
<span className="v" id="v32" data-v="32" data-xref="撒母耳記下 21:21; 撒母耳記下 13:3; 歷代志上 11:11"> 大衛的叔叔約拿單很精明，任謀士和書記。哈摩尼的兒子耶歇做眾王子的老師。</span>
<span className="v" id="v33" data-v="33" data-xref="撒母耳記下 15:12; 撒母耳記下 15:37; 撒母耳記下 15:32"> 亞希多弗也是王的謀士。亞基人戶篩是王的朋友。</span>
<span className="v" id="v34" data-v="34" data-xref="歷代志上 11:6; 列王紀上 1:7; 歷代志上 27:5"> 後來，比拿雅的兒子耶何耶大和亞比亞他接替亞希多弗做謀士。約押在王的軍隊中做元帥。</span>
</div>
</div>

## 為建殿而獻的禮物

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歷代志上 22:5; 列王紀上 3:7; 歷代志下 13:7"> 大衛王又對全體會眾說：「我兒所羅門是上帝特別揀選的，但他還年輕，缺乏經驗。建殿的工程浩大，因為這殿不是為人造的，而是為耶和華上帝造的。</span>
<span className="v" id="v2" data-v="2" data-xref="歷代志上 22:3–5; 哥林多後書 8:3; 以賽亞書 54:11–12"> 我已竭盡所能為我上帝的殿預備了製作金器、銀器、銅器、鐵器和木器所需的金銀銅鐵及木頭，還有大量瑪瑙、鑲嵌用的寶石、彩石、大理石及其他貴重的石頭。</span>
<span className="v" id="v3" data-v="3" data-xref="歷代志上 21:24; 詩篇 27:4; 詩篇 26:8"> 而且，我因為愛慕我上帝的殿，除了預備以上物品外，還把自己珍藏的金銀獻上，用來建造我上帝的殿。</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀上 9:28; 歷代志上 22:14; 約伯記 28:16"> 我獻上兩百萬兩俄斐金、四百八十萬兩純銀，用來貼殿牆，</span>
<span className="v" id="v5" data-v="5" data-xref="民數記 7:2–3; 出埃及記 35:5–9; 以斯拉記 7:15–16"> 供匠人製作金器銀器。今天，有誰樂意向耶和華奉獻？」</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多後書 9:7; 歷代志上 27:25–1; 以賽亞書 60:3–10"> 結果，各族長、以色列各支派的首領、千夫長、百夫長和負責王室事務的官員都樂意奉獻，</span>
<span className="v" id="v7" data-v="7" data-xref="尼希米記 7:70–71; 以斯拉記 2:69"> 他們為上帝的殿奉獻了三百四十萬兩金子，六百八十萬兩銀子，六百二十噸銅，三千四百噸鐵。</span>
<span className="v" id="v8" data-v="8" data-xref="歷代志上 23:8; 歷代志上 26:21–22"> 有寶石的人都把寶石交到耶和華殿的庫房，由革順人耶歇保管。</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多後書 9:7–8; 哥林多後書 8:3; 列王紀上 8:61"> 因為他們誠心誠意地把東西獻給耶和華，百姓歡喜不已，大衛王也非常歡喜。</span>
</div>
</div>

## 大衛頌讚耶和華

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="以弗所書 1:3; 彼得前書 1:3; 羅馬書 1:7"> 大衛在會眾面前頌讚耶和華，說：「我們先祖以色列的上帝耶和華啊，你永永遠遠當受頌讚！</span>
<span className="v" id="v11" data-v="11" data-xref="希伯來書 1:3; 但以理書 4:34–35; 提摩太前書 1:17"> 耶和華啊，偉大、權能、榮耀、尊貴和威嚴都是你的，天上地下的一切都是你的。耶和華啊，國度是你的，你是萬有的至高主宰。</span>
<span className="v" id="v12" data-v="12" data-xref="以弗所書 3:16; 歷代志下 20:6; 申命記 8:18"> 富貴和尊榮都從你而來，你掌管一切，你手中有權柄和能力，能使人尊大、強盛。</span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 106:1; 哥林多後書 9:15; 哥林多後書 8:16"> 我們的上帝啊，我們稱頌你，讚美你榮耀的名。</span>
<span className="v" id="v14" data-v="14" data-xref="雅各書 1:17; 哥林多後書 3:5; 羅馬書 11:36"> 「我算什麼，我的人民算什麼，怎麼能向你奉獻？因為萬物都從你而來，我們只是把從你那裡得來的獻給你。</span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 144:4; 利未記 25:23; 詩篇 102:11"> 我們在你面前只是客旅，是寄居的，像我們祖先一樣；我們在世的日子就像影子一樣轉瞬即逝。</span>
<span className="v" id="v16" data-v="16" data-xref="歷代志上 29:14; 詩篇 24:1; 歷代志下 31:10"> 我們的上帝耶和華啊，我們為你的聖名建造殿宇所預備的這一切財物，都是從你那裡來的，都屬於你。</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米書 17:10; 箴言 11:20; 歷代志上 28:9"> 我的上帝啊，我知道你洞察人心，喜愛正直的人。我懷著正直的心甘願獻上這一切，我也看見你這裡的子民甘心樂意地將財物獻給你。</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米書 32:39; 耶利米書 10:23; 希伯來書 13:21"> 我們祖先亞伯拉罕、以撒、以色列的上帝耶和華啊！求你使你的子民常存這樣的心志，使他們的心忠於你。</span>
<span className="v" id="v19" data-v="19" data-xref="詩篇 72:1; 歷代志上 28:9; 雅各書 1:17"> 求你賜給我兒所羅門忠誠的心，以遵行你的誡命、法度和律例，用我預備的材料建造殿宇。」</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 95:6; 出埃及記 4:31; 詩篇 135:19–21"> 大衛對全體會眾說：「你們要頌讚你們的上帝耶和華。」於是，全體會眾頌讚他們祖先的上帝耶和華，向耶和華和王俯伏下拜。</span>
</div>
</div>

## 所羅門被立為王

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="歷代志下 7:4–9; 民數記 15:7; 以斯拉記 6:17"> 次日，他們向耶和華獻平安祭和燔祭。他們代表全以色列獻上一千頭公牛、一千隻公綿羊、一千隻羊羔，同時還獻上奠祭及許多其他祭。</span>
<span className="v" id="v22" data-v="22" data-xref="列王紀上 2:35; 歷代志上 23:1; 出埃及記 24:11"> 那一天，他們在耶和華面前歡歡喜喜地吃喝。 他們再次擁立大衛的兒子所羅門做王，在耶和華面前膏立他做首領，又膏立撒督做祭司。</span>
<span className="v" id="v23" data-v="23" data-xref="列王紀上 2:12; 歷代志上 28:5; 羅馬書 13:1"> 於是，所羅門登上了耶和華所賜的王位，接替他父親大衛做王。他凡事亨通，以色列眾人都服從他，</span>
<span className="v" id="v24" data-v="24" data-xref="歷代志上 2:3–9; 以西結書 17:18; 創世記 24:2"> 眾首領、勇士和大衛王的眾子都效忠於他。</span>
<span className="v" id="v25" data-v="25" data-xref="歷代志下 1:12; 歷代志下 1:1; 傳道書 2:9"> 耶和華使所羅門倍受以色列人尊崇，賜他君王的威嚴，超過在他之前的所有以色列王。</span>
</div>
</div>

## 大衛去世

<div className="bt">
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="歷代志上 18:14; 詩篇 78:71–72"> 耶西的兒子大衛是全以色列的王，</span>
<span className="v" id="v27" data-v="27" data-xref="列王紀上 2:11; 撒母耳記下 5:4–5; 歷代志上 3:4"> 他統治以色列四十年，他在希伯崙執政七年，在耶路撒冷執政三十三年。</span>
<span className="v" id="v28" data-v="28" data-xref="創世記 15:15; 使徒行傳 13:36; 歷代志上 23:1"> 大衛年紀老邁，享盡富貴尊榮後，壽終正寢。他兒子所羅門繼位。</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳記上 9:9; 撒母耳記下 12:1–7; 歷代志上 21:9–11"> 大衛王的事蹟自始至終都記在撒母耳先見、拿單先知和迦得先見的史記上。</span>
<span className="v" id="v30" data-v="30" data-xref="但以理書 4:25; 但以理書 4:23; 但以理書 2:21"> 書中記述了他的政績和英勇事蹟，還有他和以色列及列國所遭遇的事。</span>
</div>
</div>

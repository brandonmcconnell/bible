## 基督徒的自由

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多後書 3:17; 加拉太書 5:13; 彼得前書 2:16"> 基督釋放了我們，好讓我們得自由。所以，要站穩了，不要再被奴僕的軛轄制。</span>
<span className="v" id="v2" data-v="2" data-xref="加拉太書 5:6; 使徒行傳 15:1; 羅馬書 9:31–32"> 聽著！我保羅鄭重地告訴你們，如果你們接受割禮，基督對你們就毫無益處。</span>
<span className="v" id="v3" data-v="3" data-xref="加拉太書 3:10; 羅馬書 2:25; 雅各書 2:10–11"> 我再次警告所有接受割禮的人，他們必須遵守全部的律法。</span>
<span className="v" id="v4" data-v="4" data-xref="羅馬書 9:31–32; 彼得後書 2:20–22; 羅馬書 11:6"> 你們若想靠遵行律法被稱為義人，就與基督隔絕了，並且離開了上帝的恩典。</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 130:5; 帖撒羅尼迦前書 1:10; 詩篇 62:5"> 但我們要靠著聖靈，憑信心熱切等候所盼望的義。</span>
<span className="v" id="v6" data-v="6" data-xref="加拉太書 6:15; 哥林多前書 7:19; 雅各書 2:14–26"> 因為在基督耶穌裡，受不受割禮根本無關緊要，藉著愛表現出來的信心才至關重要。</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多前書 9:24; 加拉太書 3:1; 希伯來書 12:1"> 你們本來在信心的路上一直跑得很好。現在是誰攔阻了你們，叫你們不再信從真理呢？</span>
<span className="v" id="v8" data-v="8" data-xref="加拉太書 1:6; 羅馬書 8:28"> 這種勸導當然不是出於呼召你們的上帝！</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多前書 15:33; 哥林多前書 5:6–7; 馬可福音 8:15"> 「一點麵酵能使整團麵發起來。」</span>
<span className="v" id="v10" data-v="10" data-xref="加拉太書 5:12; 哥林多後書 2:3; 加拉太書 1:7"> 我在主裡深信你們不會有二心，但無論誰攪擾你們，都必受懲罰。</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多前書 1:23; 加拉太書 6:12; 加拉太書 4:29"> 弟兄姊妹，我如果仍舊主張行割禮，怎麼還會受迫害呢？如果是那樣，十字架冒犯人的地方就被消除了。</span>
<span className="v" id="v12" data-v="12" data-xref="加拉太書 5:10; 哥林多前書 5:13; 提多書 3:10"> 我恨不得那些攪擾你們的人把自己閹了<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「把自己閹了」或作「與你們隔離」。">a</a></sup>！</span>
<span className="v" id="v13" data-v="13" data-xref="彼得前書 2:16; 哥林多前書 9:19; 哥林多前書 8:9"> 弟兄姊妹，你們蒙召得了自由，但不要以自由為藉口來放縱本性，要本著愛心互相服侍，</span>
<span className="v" id="v14" data-v="14" data-xref="馬太福音 7:12; 利未記 19:18; 加拉太書 6:2"> 因為全部的律法可以總結成一句話：「要愛鄰如己。」<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="利未記19·18。">b</a></sup></span>
<span className="v" id="v15" data-v="15" data-xref="哥林多前書 3:3; 雅各書 3:14–3; 加拉太書 5:26"> 你們要謹慎，如果你們相咬相吞，恐怕會同歸於盡。</span>
</div>
</div>

## 順從聖靈

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="加拉太書 5:24–25; 羅馬書 8:12–14; 加拉太書 6:8"> 因此，我勸你們行事為人要順從聖靈的引導，這樣就不會放縱本性的私慾。</span>
<span className="v" id="v17" data-v="17" data-xref="羅馬書 8:13; 約翰福音 3:6; 羅馬書 8:5–8"> 因為人本性的私慾與聖靈作對，聖靈也與人本性的私慾作對，兩者勢不兩立，使你們不能做自己想做的事。</span>
<span className="v" id="v18" data-v="18" data-xref="羅馬書 8:14; 羅馬書 6:14–15; 加拉太書 5:25"> 但你們如果順從聖靈的引導，就不在律法之下。</span>
<span className="v" id="v19" data-v="19" data-xref="哥林多前書 6:9–10; 歌羅西書 3:5–8; 馬太福音 15:18–19"> 順從本性去做的事顯而易見，如淫亂、污穢、邪蕩、</span>
<span className="v" id="v20" data-v="20" data-xref="提多書 3:10; 哥林多前書 11:19; 啟示錄 21:8"> 拜偶像、行邪術、仇恨、爭鬥、忌恨、惱怒、紛爭、衝突、分裂<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="「分裂」或譯「異端」。">c</a></sup>、</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多前書 6:9–10; 羅馬書 8:13; 羅馬書 13:13"> 嫉妒、兇殺、醉酒和荒宴無度等。我從前警告過你們，現在再一次警告你們：行這些事的人必不能承受上帝的國。</span>
<span className="v" id="v22" data-v="22" data-xref="歌羅西書 3:12–17; 哥林多前書 13:4–7; 約翰福音 15:5"> 但聖靈所結的果子是仁愛、喜樂、和平、忍耐、恩慈、良善、信實、</span>
<span className="v" id="v23" data-v="23" data-xref="提摩太前書 1:9; 使徒行傳 24:25; 提多書 2:2"> 溫柔、自制。沒有律法會禁止這些事。</span>
<span className="v" id="v24" data-v="24" data-xref="羅馬書 6:6; 羅馬書 13:14; 羅馬書 8:13"> 那些屬基督耶穌的人，已經把本性及其邪情私慾都釘在十字架上了。</span>
<span className="v" id="v25" data-v="25" data-xref="加拉太書 5:16; 羅馬書 8:4–5; 羅馬書 8:2"> 我們如果是靠聖靈生活，就當凡事順從聖靈的引導。</span>
<span className="v" id="v26" data-v="26" data-xref="雅各書 3:14–16; 腓立比書 2:1–3; 雅各書 4:16"> 我們不要自高自大，彼此惹氣，互相嫉妒。</span>
</div>
</div>

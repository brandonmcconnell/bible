## 兒子與奴僕

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="加拉太書 4:23; 加拉太書 4:29; 創世記 24:2–3"> 然而，繼承人還年幼時，雖然身為產業的主人，實際上和奴僕沒有分別。</span>
<span className="v" id="v2" data-v="2"> 他一樣要受監護人和管家的約束，一直到他父親指定他繼承產業的日子為止。</span>
<span className="v" id="v3" data-v="3" data-xref="歌羅西書 2:20; 歌羅西書 2:8; 加拉太書 4:9"> 我們也一樣，在孩童時期受世界基本規條的轄制。</span>
<span className="v" id="v4" data-v="4" data-xref="以賽亞書 7:14; 約翰福音 1:14; 羅馬書 1:3"> 然而，時候一到，上帝就差遣自己的兒子藉著一位女子降生，並受律法的約束，</span>
<span className="v" id="v5" data-v="5" data-xref="希伯來書 9:15; 以弗所書 1:5; 彼得前書 1:18–20"> 為要救贖一切受律法約束的人，使我們成為祂的兒女。</span>
<span className="v" id="v6" data-v="6" data-xref="羅馬書 8:15–17; 羅馬書 5:5; 羅馬書 8:9"> 我們<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「我們」希臘文是「你們」。">a</a></sup>既然成為兒女，上帝就差遣祂兒子的靈進入我們的心裡，呼求：「阿爸，父啊！」</span>
<span className="v" id="v7" data-v="7" data-xref="羅馬書 8:16–17; 加拉太書 3:29–2; 加拉太書 3:26"> 由此可見，你們從今以後不再是奴僕，而是兒女。既然身為兒女，就可以靠著上帝成為產業繼承人。</span>
</div>
</div>

## 保羅對加拉太人的關懷

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="哥林多前書 8:4; 以弗所書 2:11–12; 帖撒羅尼迦後書 1:8"> 從前，你們不認識上帝，做那些假神的奴隸。</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多前書 8:3; 加拉太書 3:3; 羅馬書 8:3"> 現在，你們既然認識了上帝，或者更應該說是上帝認識了你們，為什麼還要回到那些脆弱無用的基本規條之下，甘願再做它們的奴隸呢？</span>
<span className="v" id="v10" data-v="10" data-xref="歌羅西書 2:16–17; 羅馬書 14:5; 利未記 23:1–44"> 你們竟然還在拘守什麼日子、月份、節期和年份！</span>
<span className="v" id="v11" data-v="11" data-xref="帖撒羅尼迦前書 3:5; 腓立比書 2:16; 加拉太書 2:2"> 我真擔心我在你們身上的一番心血都枉費了。</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多後書 2:5; 列王紀上 22:4; 創世記 34:15"> 弟兄姊妹，我勸你們現在要像我一樣，因為我已經像你們一樣。你們向來沒有虧待過我。</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多前書 2:3; 哥林多後書 12:7–10; 哥林多後書 11:30"> 你們知道，當初是因為我生病才有機會首次向你們傳福音。</span>
<span className="v" id="v14" data-v="14" data-xref="馬太福音 10:40; 帖撒羅尼迦前書 2:13; 希伯來書 13:2"> 那時，你們雖然因為我生病而受累，卻沒有輕視我、嫌棄我，反而接待我，就像接待上帝的天使，接待基督耶穌一樣。</span>
<span className="v" id="v15" data-v="15" data-xref="羅馬書 5:2; 約翰一書 3:16–18; 歌羅西書 4:13"> 我可以為你們作證，如果可能的話，你們那時就是把眼睛剜出來給我，也心甘情願。你們當初的善意哪裡去了？</span>
<span className="v" id="v16" data-v="16" data-xref="阿摩司書 5:10; 箴言 9:8; 約翰福音 8:45"> 現在我因為告訴你們真理，就成了你們的仇人嗎？</span>
<span className="v" id="v17" data-v="17" data-xref="羅馬書 16:18; 哥林多後書 11:13–15; 彼得後書 2:3"> 那些人非常熱心地對待你們，其實他們心懷不軌，想要離間你們和我們的關係，使你們熱心地對待他們。</span>
<span className="v" id="v18" data-v="18" data-xref="腓立比書 2:12; 啟示錄 3:19; 腓立比書 1:27"> 有人熱心待你們當然很好，但總要動機純正、始終如一，不應該只是我和你們在一起時才熱心待你們。</span>
<span className="v" id="v19" data-v="19" data-xref="以弗所書 4:13; 羅馬書 8:29; 羅馬書 13:14"> 孩子們，為了你們，我像一位母親再次經歷生產的劇痛，一直到基督的生命在你們裡面成形。</span>
<span className="v" id="v20" data-v="20" data-xref="帖撒羅尼迦前書 2:17–18; 哥林多前書 4:19–21; 帖撒羅尼迦前書 3:9"> 我恨不得立刻趕到你們身邊，換種口氣說話，因為我為你們困惑不安。</span>
</div>
</div>

## 夏甲與撒拉的例子

<div className="bt">
<div className="bp poetry">
<span className="v" id="v21" data-v="21" data-xref="加拉太書 3:10; 加拉太書 3:23–24; 羅馬書 7:5–6"> 你們這些甘願在律法之下的人啊！告訴我，你們沒聽過律法怎麼說嗎？</span>
<span className="v" id="v22" data-v="22" data-xref="創世記 16:15; 創世記 21:10; 創世記 21:1–2"> 律法書上說：亞伯拉罕有兩個兒子，一個是婢女生的，一個是主母生的。</span>
<span className="v" id="v23" data-v="23" data-xref="希伯來書 11:11; 羅馬書 9:7–8; 加拉太書 4:28–29"> 婢女的兒子是按著人的意願生的，主母的兒子是按著上帝的應許生的。</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 21:9–13; 希伯來書 10:15–18; 創世記 16:8"> 這些事都有寓意，兩個婦人代表兩個約。夏甲代表頒佈於西奈山的約，她生的孩子是奴僕。</span>
<span className="v" id="v25" data-v="25" data-xref="路加福音 19:44; 使徒行傳 1:11; 加拉太書 1:17"> 這夏甲代表阿拉伯的西奈山，相當於現今的耶路撒冷，她和她的兒女都是奴僕。</span>
<span className="v" id="v26" data-v="26" data-xref="希伯來書 12:22; 腓立比書 3:20; 彌迦書 4:1–2"> 那天上的耶路撒冷則是自由的，是我們的母親。</span>
<span className="v" id="v27" data-v="27" data-xref="以賽亞書 54:1–5; 詩篇 113:9; 路得記 4:14–16"> 因為聖經上說：<br /><span className="pl pl-1">「不生育、未生養的婦人啊，</span><br /><span className="pl pl-1">要快樂；</span><br /><span className="pl pl-1">未曾生產的女子啊，</span><br /><span className="pl pl-1">要高聲歡呼，</span><br /><span className="pl pl-1">因為沒有丈夫的比有丈夫的兒女更多。」</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="以賽亞書54·1。">b</a></sup></span>
<span className="v" id="v28" data-v="28" data-xref="加拉太書 4:23; 羅馬書 9:8–9; 羅馬書 4:13–18"> 弟兄姊妹，你們都像以撒一樣是照著上帝的應許出生的。</span>
<span className="v" id="v29" data-v="29" data-xref="創世記 21:9; 羅馬書 8:13; 加拉太書 5:11"> 當時，那按著人的意願生的兒子迫害那靠著聖靈生的兒子，現在的情況也和當時一樣。</span>
<span className="v" id="v30" data-v="30" data-xref="創世記 21:10–12; 約翰福音 8:35; 羅馬書 8:15–17"> 但聖經上怎麼說呢？聖經上說：「趕走婢女和她的兒子，因為婢女的兒子不能與主母的兒子一同承受產業。」<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="創世記21·10。">c</a></sup></span>
<span className="v" id="v31" data-v="31" data-xref="約翰福音 8:36; 約翰福音 1:12–13; 加拉太書 5:1"> 弟兄姊妹，這樣看來，我們不是婢女的兒女，而是主母的兒女。</span>
</div>
</div>

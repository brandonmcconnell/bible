## 行律法與信基督

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="加拉太書 5:7–8; 哥林多後書 11:3; 加拉太書 1:6"> 無知的加拉太人啊！誰又蠱惑了你們呢？耶穌基督被釘在十字架上的事，早就像一幅畫一樣展現在你們眼前了。</span>
<span className="v" id="v2" data-v="2" data-xref="羅馬書 10:16–17; 加拉太書 3:14; 使徒行傳 15:8"> 我只想問，你們領受了聖靈是靠遵行律法呢，還是因為相信所聽見的福音呢？</span>
<span className="v" id="v3" data-v="3" data-xref="加拉太書 5:4–8; 加拉太書 4:7–10; 希伯來書 7:16–19"> 你們既然靠聖靈開始了基督徒的生活，現在卻想靠肉體達到純全嗎？你們就這麼無知嗎？</span>
<span className="v" id="v4" data-v="4" data-xref="約翰二書 1:8; 哥林多前書 15:2; 希伯來書 10:32–39"> 你們受了許多苦，難道都是徒然的嗎？真白受了嗎？</span>
<span className="v" id="v5" data-v="5" data-xref="加拉太書 3:2; 使徒行傳 14:9–10; 使徒行傳 19:11–12"> 上帝將聖靈賜給你們，又在你們中間行神蹟，是因為你們遵行律法呢，還是因為你們相信所聽到的福音呢？</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="創世記 15:6; 羅馬書 4:21–22; 雅各書 2:23"> 聖經上說：「亞伯拉罕信上帝，就被算為義人。」<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="創世記15·6。">a</a></sup></span>
<span className="v" id="v7" data-v="7" data-xref="羅馬書 9:7–8; 加拉太書 3:9; 加拉太書 3:26–29"> 因此，你們要明白，那些信的人才是亞伯拉罕的子孫。</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 12:3; 創世記 22:18; 創世記 28:14"> 聖經早就指明，上帝要叫外族人因信被稱為義人，祂預先將福音傳給亞伯拉罕，說：「萬國必因你而蒙福。」<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="創世記12·3；18·18；22·18。">b</a></sup></span>
<span className="v" id="v9" data-v="9" data-xref="羅馬書 4:16; 加拉太書 3:29; 羅馬書 4:24"> 所以那些信的人必和有信心的亞伯拉罕一同蒙福。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="申命記 27:26; 羅馬書 8:7; 羅馬書 3:19–20"> 凡以遵行律法為本的人都在咒詛之下，因為聖經上說：「凡不遵行律法書上一切命令的人必受咒詛。」<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="申命記27·26。">c</a></sup></span>
<span className="v" id="v11" data-v="11" data-xref="哈巴谷書 2:4; 羅馬書 1:17; 希伯來書 10:38"> 非常明顯，沒有人能靠遵行律法在上帝面前被稱為義人，因為聖經上說：「義人必靠信心而活。」<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="哈巴谷書2·4。">d</a></sup></span>
<span className="v" id="v12" data-v="12" data-xref="利未記 18:5; 羅馬書 10:5–6; 尼希米記 9:29"> 律法並非以信心為本，而是說：「遵行律法的人必因此而活。」<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="利未記18·5。">e</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="彼得前書 2:24; 申命記 21:23; 希伯來書 9:12"> 但基督替我們受了咒詛，從而救贖我們脫離了律法的咒詛，因為聖經上說：「凡掛在木頭上的人都是受咒詛的。」<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="申命記21·23。">f</a></sup></span>
<span className="v" id="v14" data-v="14" data-xref="加拉太書 3:28–29; 哥林多前書 12:13; 以西結書 36:26–27"> 這樣，賜給亞伯拉罕的福氣可以藉著基督耶穌臨到外族人，使我們也可以藉著信得到上帝應許賜給我們的聖靈。</span>
</div>
</div>

## 律法與應許

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="希伯來書 9:17; 羅馬書 6:19; 羅馬書 3:5"> 弟兄姊妹，我舉個日常生活中的例子。世人的合約一經雙方簽訂之後，就不能作廢，也不能加添。</span>
<span className="v" id="v16" data-v="16" data-xref="創世記 17:7–8; 羅馬書 4:13; 路加福音 1:55"> 上帝曾向亞伯拉罕和他的後裔賜下應許，不過這裡沒有說「後裔們」<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="創世記12·7；13·15；24·7。">g</a></sup>——指許多人，而是說「你的後裔」——指一個人，就是基督。</span>
<span className="v" id="v17" data-v="17" data-xref="希伯來書 11:39–40; 創世記 15:13; 羅馬書 4:13–14"> 我的意思是：四百三十年後頒佈的律法不會廢除上帝先前立下的約，以致應許落空。</span>
<span className="v" id="v18" data-v="18" data-xref="希伯來書 6:12–15; 加拉太書 2:21; 羅馬書 4:13–16"> 我們如果是靠遵行律法去承受產業，就不是倚靠上帝的應許。但上帝是憑應許把產業賜給了亞伯拉罕。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="使徒行傳 7:53; 羅馬書 7:7–13; 希伯來書 2:2"> 那麼，為什麼會有律法呢？律法是為了使人知罪而增設的，一直存到那位承受應許的後裔來臨。律法是通過天使交給一位中保頒佈的。</span>
<span className="v" id="v20" data-v="20" data-xref="提摩太前書 2:5; 申命記 6:4; 約伯記 9:33"> 中保代表雙方，但上帝則單方面賜下應許。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="加拉太書 2:21; 羅馬書 9:31; 羅馬書 3:20–22"> 這樣看來，上帝的律法和上帝的應許是否互相矛盾呢？當然不是！如果頒布的律法能帶給人生命，人就可以靠律法得到義了。</span>
<span className="v" id="v22" data-v="22" data-xref="羅馬書 11:32; 希伯來書 9:15; 加拉太書 3:23"> 但聖經說萬物都困在罪的權勢下，為要使那些信的人因為信耶穌基督而得到應許<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="「因為相信耶穌基督而得到應許」或譯「因為耶穌基督的信實而得到應許」。">h</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="加拉太書 5:18; 加拉太書 3:24–25; 加拉太書 3:19"> 信耶穌的時代<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="「信耶穌的時代」希臘文是「信心」，下同25節。">i</a></sup>來臨以前，律法暫時監管我們。等到信耶穌之道顯明出來後，律法就不再監管了。</span>
<span className="v" id="v24" data-v="24" data-xref="羅馬書 10:4; 使徒行傳 13:38–39; 羅馬書 7:24–25"> 因此，律法是我們的監護人，負責引領我們歸向基督，使我們可以因信被稱為義人。</span>
<span className="v" id="v25" data-v="25" data-xref="羅馬書 6:14; 羅馬書 7:4; 希伯來書 10:15–18"> 現在信耶穌的時代已經來臨，我們不再受律法監管。</span>
<span className="v" id="v26" data-v="26" data-xref="以弗所書 1:5; 哥林多後書 6:18; 約翰福音 1:12–13"> 你們都藉著信基督耶穌而成為上帝的兒女，</span>
<span className="v" id="v27" data-v="27" data-xref="羅馬書 13:14; 哥林多前書 12:13; 羅馬書 6:3–4"> 因為你們受洗歸入基督就是披戴基督<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="「披戴基督」是個隱喻，主要的意思是「像基督」，象徵有基督的生命與品格。">j</a></sup>。</span>
<span className="v" id="v28" data-v="28" data-xref="哥林多前書 12:12–13; 歌羅西書 3:11; 羅馬書 3:29–30"> 從此不再分猶太人和希臘人，自由人和奴隸，男人和女人，因為你們都在基督耶穌裡合而為一了。</span>
<span className="v" id="v29" data-v="29" data-xref="以弗所書 3:6; 羅馬書 9:7–8; 加拉太書 3:7"> 你們若屬於基督，就是亞伯拉罕的子孫，並且按照上帝的應許是產業繼承人。</span>
</div>
</div>

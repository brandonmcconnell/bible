## 建殿工作受阻

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歷代志上 22:9–10; 以斯拉記 1:11; 以斯拉記 10:16"> 猶大和便雅憫的敵人聽說流亡歸來的人為以色列的上帝耶和華建殿，</span>
<span className="v" id="v2" data-v="2" data-xref="列王紀下 19:37; 列王紀下 17:24; 加拉太書 2:4"> 就去見所羅巴伯和以色列的族長，對他們說：「請讓我們與你們一同建造，因為我們像你們一樣也尋求你們的上帝。自從亞述王以撒哈頓帶我們到這裡以後，我們就一直獻祭給上帝。」</span>
<span className="v" id="v3" data-v="3" data-xref="尼希米記 2:20; 馬太福音 10:16; 歷代志下 36:22–3"> 所羅巴伯、耶書亞和以色列其餘的族長回答說：「你們不能參與建殿。遵照波斯王塞魯士的吩咐，我們要自己為以色列的上帝耶和華建殿。」</span>
<span className="v" id="v4" data-v="4" data-xref="以斯拉記 3:3; 尼希米記 6:9; 耶利米書 38:4"> 於是，當地人阻撓猶大人，使他們不敢建殿，</span>
<span className="v" id="v5" data-v="5" data-xref="那鴻書 1:11; 以斯拉記 5:5–18; 詩篇 2:1–2"> 從波斯王塞魯士統治年間，一直到波斯王大流士統治期間，當地人收買謀士，破壞他們的計劃。</span>
</div>
</div>

## 阻擾重建耶路撒冷

<div className="bt">
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="以斯帖記 1:1; 但以理書 9:1; 使徒行傳 24:5–9"> 亞哈隨魯統治初期，他們寫信控告猶大和耶路撒冷的居民。</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀下 18:26; 但以理書 2:4; 以賽亞書 36:11"> 波斯王亞達薛西統治年間，比施蘭、米特利達、他別及其同黨上奏亞達薛西。奏章是用亞蘭文寫的，經過翻譯後呈上。</span>
<span className="v" id="v8" data-v="8" data-xref="以斯拉記 4:9; 撒母耳記下 8:17; 撒母耳記下 20:25"> 利宏省長和伸帥書記也寫了奏本給亞達薛西王，控告耶路撒冷人，內容如下：</span>
<span className="v" id="v9" data-v="9" data-xref="以斯拉記 5:6; 以斯拉記 6:6; 列王紀下 17:24"> 「利宏省長、伸帥書記和我們的同僚底拿人、亞法薩提迦人、他毗拉人、亞法撒人、亞基衛人、巴比倫人、書珊迦人、底亥人、以攔人，</span>
<span className="v" id="v10" data-v="10" data-xref="以斯拉記 4:17; 以斯拉記 4:11; 以斯拉記 7:12"> 以及偉大尊貴的亞斯那巴遷來並安置在撒瑪利亞各城與幼發拉底河西一帶的人民，</span>
<span className="v" id="v11" data-v="11"> 上奏亞達薛西王， 「『幼發拉底河西的臣民奏告亞達薛西王，</span>
<span className="v" id="v12" data-v="12" data-xref="以斯拉記 5:9; 歷代志下 36:13; 以斯拉記 5:3"> 王該知道，從王那裡到我們這裡來的猶太人已經去了耶路撒冷，如今正在重建這座叛逆、罪惡之城，正在重建地基，修復城牆。</span>
<span className="v" id="v13" data-v="13" data-xref="以斯拉記 7:24; 羅馬書 13:6–7; 尼希米記 5:4"> 王該知道，如果這城建好，城牆完工，他們將不再進貢、交賦、納稅，王的稅收必受虧損。</span>
<span className="v" id="v14" data-v="14" data-xref="約翰福音 19:12–15; 以西結書 33:31; 約翰福音 12:5–6"> 我們既食王祿，就不能坐視王遭受損失，因此上奏於王。</span>
<span className="v" id="v15" data-v="15" data-xref="以斯拉記 4:12; 以斯帖記 3:5–8; 列王紀下 24:20–1"> 請王查看先王的記錄，必從中獲悉這城是叛逆之城，危害列王和各省。自古以來，城中叛亂不斷，因此才被毀滅。</span>
<span className="v" id="v16" data-v="16" data-xref="以斯拉記 4:20; 列王紀上 4:24; 撒母耳記下 8:3"> 我們願王知道，這城一旦建好，城牆完工，幼發拉底河西之地就不再為王所有了。』」</span>
<span className="v" id="v17" data-v="17" data-xref="羅馬書 1:7; 以斯拉記 5:7; 以斯拉記 4:9–11"> 王回覆利宏省長、伸帥書記及其住在撒瑪利亞與幼發拉底河西一帶的同僚，說：「願你們平安！</span>
<span className="v" id="v18" data-v="18" data-xref="尼希米記 8:8"> 你們呈上的奏章，經過翻譯已奏報給我。</span>
<span className="v" id="v19" data-v="19" data-xref="列王紀下 18:7; 箴言 25:2; 申命記 13:14"> 我已命人查考，發現這城自古以來屢屢背叛列王，是悖逆和叛亂之地。</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 15:18; 列王紀上 4:21; 歷代志上 18:3"> 強大的君王曾經統管耶路撒冷和幼發拉底河西全境，並向人們徵收貢物和賦稅。</span>
<span className="v" id="v21" data-v="21"> 現在你們要下令讓這些人停止建造這城，等候我的諭旨。</span>
<span className="v" id="v22" data-v="22" data-xref="以斯帖記 7:3–4; 以斯帖記 3:8–9; 以斯拉記 4:13"> 要認真辦理這事，不可遲延，何必讓事情惡化，使王受虧損呢？」</span>
<span className="v" id="v23" data-v="23" data-xref="羅馬書 3:15; 彌迦書 2:1; 以斯拉記 4:17"> 利宏、伸帥書記及其同僚接到亞達薛西王的諭旨後，急忙趕往耶路撒冷，用武力強迫猶太人停工。</span>
<span className="v" id="v24" data-v="24" data-xref="哈該書 1:15; 尼希米記 6:9; 以斯拉記 5:5"> 於是，耶路撒冷上帝殿的重建工程停止了，一直停到波斯王大流士第二年。</span>
</div>
</div>

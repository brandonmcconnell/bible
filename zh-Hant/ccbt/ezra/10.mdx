## 終止雜婚

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="但以理書 9:20; 詩篇 119:136; 羅馬書 9:2"> 以斯拉禱告、認罪、哭泣、俯伏在上帝的殿前時，一大群以色列人，包括男女和孩子，都聚集到他那裡，與他一起痛哭。</span>
<span className="v" id="v2" data-v="2" data-xref="尼希米記 13:27; 以斯拉記 9:2; 耶利米書 3:12–13"> 以攔的後裔耶歇的兒子示迦尼對以斯拉說：「我們對我們的上帝不忠，娶這地方的外族女子為妻，但以色列還有希望。</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 7:2–3; 以斯拉記 9:4; 約書亞記 23:12–13"> 現在，我們來與我們的上帝立約，聽從你和那些敬畏我們上帝誡命之人的指示，遵照律法行事，送走這些妻子和她們的兒女。</span>
<span className="v" id="v4" data-v="4" data-xref="歷代志上 28:10; 傳道書 9:10; 希伯來書 12:12–13"> 起來吧！這事由你處理，我們支持你，放膽去做吧！」</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="尼希米記 13:25; 尼希米記 5:12; 箴言 9:9"> 於是，以斯拉起來，要祭司長、利未人和所有以色列人起誓照這話去做，他們就都起了誓。</span>
<span className="v" id="v6" data-v="6" data-xref="申命記 9:18; 尼希米記 3:1; 尼希米記 12:22"> 以斯拉從上帝的殿前起來，進了以利亞實的兒子約哈難的房間。他在那裡不吃不喝，為流亡歸來者的不忠而憂傷。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="以斯拉記 1:1; 歷代志下 30:5"> 他們在猶大和耶路撒冷發出通告，要求所有流亡歸來的人在耶路撒冷集合。</span>
<span className="v" id="v8" data-v="8" data-xref="以斯拉記 7:26; 約翰福音 9:22; 士師記 21:5"> 按照眾首領和長老的決定，三天之內未到者，其財產會被沒收，還要把他本人從流亡歸來的會眾中逐出。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="撒母耳記上 12:17–18; 耶利米書 10:13; 以斯拉記 7:8–9"> 三天內，所有的猶大人和便雅憫人都聚集在耶路撒冷。九月二十日，民眾都坐在上帝的殿前面的廣場上。因為這事，加上當時下大雨，眾人都戰戰兢兢。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="以斯拉記 9:6; 民數記 32:14; 馬太福音 23:32"> 以斯拉祭司站起來對他們說：「你們對上帝不忠，娶外族的女子為妻，加重了以色列的罪惡。</span>
<span className="v" id="v11" data-v="11" data-xref="羅馬書 12:2; 以斯拉記 10:3; 以賽亞書 1:16–18"> 現在，你們要向你們祖先的上帝耶和華認罪，遵行祂的旨意，與這地方的人和你們的外族妻子斷絕關係。」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="尼希米記 13:23; 詩篇 78:57; 以斯拉記 10:3–4"> 會眾都高聲回答說：「你說的對，我們必照你的話做。</span>
<span className="v" id="v13" data-v="13" data-xref="以斯拉記 10:18–44; 馬太福音 7:13–14"> 可是，人這麼多，又逢雨季，我們不能總站在外面，並且這事一兩天也解決不了，因為我們在這事上犯了大罪。</span>
<span className="v" id="v14" data-v="14" data-xref="歷代志下 29:10; 歷代志下 30:8; 民數記 25:4"> 不如讓我們的首領為全體會眾處理這事，讓那些娶了外族女子為妻的人在指定的時間，與本城的長老和審判官一起來找首領解決，直到我們的上帝因這事而發的烈怒離開我們。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="尼希米記 11:16; 尼希米記 10:20; 尼希米記 12:33"> 只有亞撒黑的兒子約拿單和特瓦的兒子雅哈謝反對這事，支持他們的還有米書蘭和利未人沙比太。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="約伯記 29:16; 申命記 13:14; 約翰福音 7:51"> 流亡歸來的人都遵命而行。以斯拉祭司按家族選出各族長，都是點名指定的。他們從十月一日開始著手查辦這事，</span>
<span className="v" id="v17" data-v="17"> 到次年一月一日才查清娶外族女子為妻的人。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="以斯拉記 5:2; 以斯拉記 3:2; 撒迦利亞書 3:1"> 祭司中娶外族女子為妻的有耶書亞的子孫約薩達的兒子及其弟兄瑪西雅、以利以謝、雅立和基大利。</span>
<span className="v" id="v19" data-v="19" data-xref="利未記 6:6; 列王紀下 10:15; 歷代志下 30:8"> 他們起誓答應休掉自己的妻子，並從羊群中獻上一隻公綿羊為自己贖罪。</span>
<span className="v" id="v20" data-v="20" data-xref="以斯拉記 2:37; 歷代志上 24:14; 尼希米記 7:40"> 音麥的子孫中有哈拿尼和西巴第雅。</span>
<span className="v" id="v21" data-v="21" data-xref="歷代志上 24:8; 以斯拉記 2:39; 尼希米記 7:42"> 哈琳的子孫中有瑪西雅、以利雅、示瑪雅、耶歇和烏西雅。</span>
<span className="v" id="v22" data-v="22" data-xref="歷代志上 9:12; 尼希米記 7:41; 以斯拉記 2:38"> 巴施戶珥的子孫中有以利約乃、瑪西雅、以實瑪利、拿坦業、約撒拔和以利亞撒。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="尼希米記 10:10; 尼希米記 11:16; 以斯拉記 8:33"> 利未人中有約撒拔、示每、基拉雅——又名基利他、毗他希雅、猶大和以利以謝。</span>
<span className="v" id="v24" data-v="24"> 歌樂手中有以利亞實。殿門守衛中有沙龍、提聯、烏利。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="以斯拉記 2:3; 尼希米記 7:8"> 其他以色列人中有巴錄的子孫拉米、耶西雅、瑪基雅、米雅民、以利亞撒、瑪基雅和比拿雅。</span>
<span className="v" id="v26" data-v="26" data-xref="以斯拉記 10:2; 以斯拉記 2:31; 尼希米記 7:12"> 以攔的子孫中有瑪他尼、撒迦利亞、耶歇、押底、耶利末和以利雅。</span>
<span className="v" id="v27" data-v="27" data-xref="尼希米記 7:13; 以斯拉記 2:8"> 薩土的子孫中有以利約乃、以利亞實、瑪他尼、耶利末、撒拔和亞西撒。</span>
<span className="v" id="v28" data-v="28" data-xref="以斯拉記 8:11; 以斯拉記 2:11; 尼希米記 7:16"> 比拜的子孫中有約哈難、哈拿尼雅、薩拜和亞勒。</span>
<span className="v" id="v29" data-v="29" data-xref="尼希米記 7:15; 尼希米記 10:4; 以斯拉記 2:10"> 巴尼的子孫中有米書蘭、瑪鹿、亞大雅、雅述、示押和耶利末。</span>
<span className="v" id="v30" data-v="30" data-xref="以斯拉記 8:4; 尼希米記 7:11; 以斯拉記 2:6"> 巴哈·摩押的子孫中有阿底拿、基拉、比拿雅、瑪西雅、瑪他尼、比撒列、賓內和瑪拿西。</span>
<span className="v" id="v31" data-v="31" data-xref="尼希米記 3:11; 尼希米記 7:35; 以斯拉記 2:32"> 哈琳的子孫中有以利以謝、伊示雅、瑪基雅、示瑪雅、西緬、</span>
<span className="v" id="v32" data-v="32"> 便雅憫、瑪鹿、示瑪利雅。</span>
<span className="v" id="v33" data-v="33" data-xref="以斯拉記 2:19; 尼希米記 7:22"> 哈順的子孫中有瑪特乃、瑪達他、撒拔、以利法列、耶利買、瑪拿西和示每。</span>
<span className="v" id="v34" data-v="34"> 巴尼的子孫中有瑪玳、暗蘭、烏益、</span>
<span className="v" id="v35" data-v="35"> 比拿雅、比底雅、基祿、</span>
<span className="v" id="v36" data-v="36"> 瓦尼雅、米利末、以利亞實、</span>
<span className="v" id="v37" data-v="37"> 瑪他尼、瑪特乃和雅掃。</span>
<span className="v" id="v38" data-v="38"> 賓內的子孫中有示每、</span>
<span className="v" id="v39" data-v="39"> 示利米雅、拿單、亞大雅、</span>
<span className="v" id="v40" data-v="40"> 瑪拿底拜、沙賽、沙賴、</span>
<span className="v" id="v41" data-v="41"> 亞薩利、示利米雅、示瑪利雅、</span>
<span className="v" id="v42" data-v="42"> 沙龍、亞瑪利雅和約瑟。</span>
<span className="v" id="v43" data-v="43" data-xref="以斯拉記 2:29; 尼希米記 7:33"> 尼波的子孫中有耶利、瑪他提雅、撒拔、西比拿、雅玳、約珥和比拿雅。</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="箴言 5:20; 以斯拉記 10:3; 箴言 2:16"> 以上這些人都娶了外族女子為妻，其中有些還生了子女。</span>
</div>
</div>

## 以斯拉到達耶路撒冷

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="尼希米記 2:1; 歷代志上 6:4–14; 以斯拉記 7:21"> 這些事以後，波斯王亞達薛西年間，以斯拉從巴比倫上到耶路撒冷。以斯拉是西萊雅的兒子，西萊雅是亞撒利雅的兒子，亞撒利雅是希勒迦的兒子，</span>
<span className="v" id="v2" data-v="2" data-xref="列王紀上 2:35; 撒母耳記下 8:17"> 希勒迦是沙龍的兒子，沙龍是撒督的兒子，撒督是亞希突的兒子，</span>
<span className="v" id="v3" data-v="3"> 亞希突是亞瑪利雅的兒子，亞瑪利雅是亞撒利雅的兒子，亞撒利雅是米拉約的兒子，</span>
<span className="v" id="v4" data-v="4"> 米拉約是西拉希雅的兒子，西拉希雅是烏西的兒子，烏西是布基的兒子，</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 6:25; 歷代志下 26:20; 歷代志上 6:4"> 布基是亞比書的兒子，亞比書是非尼哈的兒子，非尼哈是以利亞撒的兒子，以利亞撒是大祭司亞倫的兒子。</span>
<span className="v" id="v6" data-v="6" data-xref="以斯拉記 8:22; 以斯拉記 7:28; 以斯拉記 8:31"> 這以斯拉是位從巴比倫上來的律法教師，精通以色列的上帝耶和華賜下的摩西律法。他的上帝耶和華出手幫助他，使王批准他的一切要求。</span>
<span className="v" id="v7" data-v="7" data-xref="以斯拉記 8:1–20; 歷代志上 6:31–48; 歷代志上 9:17–27"> 亞達薛西王第七年，一些以色列人、祭司、利未人、歌樂手、殿門守衛和殿役來到耶路撒冷。</span>
<span className="v" id="v8" data-v="8"> 這年一月一日，以斯拉從巴比倫啟程去耶路撒冷，五月一日就到達那裡，因為他的上帝施恩幫助他。</span>
<span className="v" id="v10" data-v="10" data-xref="瑪拉基書 2:7; 提摩太後書 4:2; 馬太福音 7:24"> 以斯拉專心研讀、遵行耶和華的律法，並在以色列教導律例和典章。</span>
</div>
</div>

## 亞達薛西王給以斯拉的諭旨

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="以斯拉記 5:6; 以斯拉記 7:6; 馬太福音 23:2"> 以斯拉是祭司和律法教師，精通耶和華賜給以色列的誡命和律例。亞達薛西王降旨給以斯拉，內容如下：</span>
<span className="v" id="v12" data-v="12" data-xref="但以理書 2:37; 以西結書 26:7; 以斯拉記 4:17"> 「王中之王亞達薛西降旨給精通天上上帝律法的教師以斯拉祭司，願你平安！</span>
<span className="v" id="v13" data-v="13" data-xref="以斯拉記 6:1; 詩篇 148:6; 歷代志下 30:5"> 「我現在降旨，我國中的以色列人、祭司和利未人，凡願意上耶路撒冷的都可以與你同去。</span>
<span className="v" id="v14" data-v="14" data-xref="以斯帖記 1:14; 以斯拉記 7:25–26; 以斯拉記 7:28"> 我和七位謀士派你去按照你手中上帝的律法察看猶大和耶路撒冷的情況，</span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 135:21; 歷代志下 6:2; 以斯拉記 6:12"> 並帶去我和謀士們自願獻的金銀，獻給住在耶路撒冷的以色列的上帝，</span>
<span className="v" id="v16" data-v="16" data-xref="歷代志上 29:6; 以斯拉記 1:4; 歷代志上 29:9"> 還要帶去你在巴比倫省得到的金銀，以及民眾和祭司為耶路撒冷的上帝之殿自願奉獻的祭物。</span>
<span className="v" id="v17" data-v="17" data-xref="申命記 12:5–11; 民數記 15:4–13; 以斯拉記 6:9–10"> 你一定要用這些金銀購買公牛、公綿羊和綿羊羔，以及素祭和奠祭用品，把這一切獻在耶路撒冷你們上帝殿的祭壇上。</span>
<span className="v" id="v18" data-v="18" data-xref="列王紀下 22:7; 以弗所書 5:17; 列王紀下 12:15"> 至於餘下的金銀，你和你的弟兄可以按你們上帝的心意妥善使用。</span>
<span className="v" id="v19" data-v="19" data-xref="耶利米書 3:17; 以斯拉記 8:33–34; 歷代志下 32:19"> 那些交托給你、用來在你上帝的殿裡敬拜的器皿，你要帶到耶路撒冷的上帝面前。</span>
<span className="v" id="v20" data-v="20" data-xref="以斯拉記 6:4; 以斯拉記 6:8–18"> 如果你們上帝的殿還需要你供應什麼，你可以從國庫支取費用。</span>
<span className="v" id="v21" data-v="21" data-xref="以斯拉記 4:16; 以斯拉記 7:6; 以斯拉記 7:10–13"> 「我亞達薛西王降旨給河西所有的財政大臣，精通天上上帝律法的律法教師以斯拉祭司無論向你們要什麼，都要速速辦理，</span>
<span className="v" id="v22" data-v="22" data-xref="路加福音 16:6–7; 利未記 2:13; 以西結書 45:14"> 可以給他六萬八千兩銀子、兩萬兩千升麥子、兩千二百升酒、兩千二百升油，鹽可以隨意取用。</span>
<span className="v" id="v23" data-v="23" data-xref="詩篇 119:4; 以斯拉記 7:18; 以斯拉記 6:10–12"> 不論天上的上帝為祂的殿有何要求，都要認真辦理，以免祂的烈怒臨到王及眾王子的國。</span>
<span className="v" id="v24" data-v="24" data-xref="以斯拉記 7:7; 以斯拉記 4:13; 以斯拉記 2:36–55"> 我們也通知你們不可向這座上帝殿的祭司、利未人、歌樂手、殿門守衛、殿役或其他工人徵收賦稅。</span>
<span className="v" id="v25" data-v="25" data-xref="以斯拉記 7:10; 申命記 16:18; 雅各書 1:5"> 「你以斯拉要運用上帝賜給你的智慧委派官員和審判官，讓他們治理河西省的人民，就是所有明白你上帝律法的人。你要教導那些不明白你上帝律法的人。</span>
<span className="v" id="v26" data-v="26" data-xref="以斯拉記 6:11; 申命記 13:1–18; 利未記 20:1–27"> 凡不遵行你上帝的律法和王法的，要對他嚴加治罪，或處死，或發配，或抄家，或監禁。」</span>
</div>
</div>

## 以斯拉讚美上帝

<div className="bt">
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="以斯拉記 6:22; 啟示錄 17:17; 以賽亞書 60:13"> 以斯拉說： 「我們祖先的上帝耶和華當受讚美！因為祂使王有這樣的心意尊崇耶路撒冷耶和華的殿。</span>
<span className="v" id="v28" data-v="28" data-xref="提摩太後書 4:17–18; 以斯拉記 5:5; 創世記 32:28"> 祂又在王及其謀士和所有權貴面前施恩於我。因為我的上帝耶和華出手幫助我，我便有勇氣召集以色列的首領與我一同上去。」</span>
</div>
</div>

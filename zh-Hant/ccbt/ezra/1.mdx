## 塞魯士下令猶太人回國

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="耶利米書 29:10; 歷代志下 36:22–23; 耶利米書 25:12–14"> 波斯王塞魯士元年，耶和華為應驗祂藉耶利米所說的話，就感動波斯王塞魯士，使他下詔通告全國：</span>
<span className="v" id="v2" data-v="2" data-xref="以賽亞書 45:12–13; 以賽亞書 44:26–1; 但以理書 5:23"> 「波斯王塞魯士如此說，『天上的上帝耶和華已把天下萬國都賜給我，祂委派我在猶大的耶路撒冷為祂建造殿宇。</span>
<span className="v" id="v3" data-v="3" data-xref="但以理書 6:26; 耶利米書 10:10; 以賽亞書 45:5"> 你們當中凡屬耶和華的子民，都可以去猶大的耶路撒冷，為住在耶路撒冷的以色列的上帝耶和華建殿，願上帝與他們同在！</span>
<span className="v" id="v4" data-v="4" data-xref="歷代志上 29:3; 以斯拉記 7:16–18; 以斯拉記 2:68–70"> 所有餘民無論寄居在哪裡，當地的人都要用金銀、財物和牲畜幫助他們，還要為耶路撒冷的上帝之殿自願獻上禮物。』」</span>
<span className="v" id="v5" data-v="5" data-xref="以斯拉記 1:1; 歷代志下 36:22; 腓立比書 2:13"> 於是，猶大和便雅憫的族長、祭司和利未人等所有被上帝感動的人，都準備上耶路撒冷重建耶和華的殿。</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多後書 9:7; 以斯拉記 1:4; 以斯拉記 8:33"> 他們周圍的人除了獻上自願獻的禮物外，還拿出銀器、金子、財物、牲畜和珍寶來支持他們。</span>
<span className="v" id="v7" data-v="7" data-xref="歷代志下 36:7; 以斯拉記 5:14; 列王紀下 24:13"> 巴比倫王尼布甲尼撒曾從耶路撒冷耶和華的殿裡帶回器皿，放在自己的神廟裡。波斯王塞魯士將這些器皿取出來，</span>
<span className="v" id="v8" data-v="8" data-xref="以斯拉記 5:14; 撒迦利亞書 4:6–10; 以斯拉記 1:11"> 派財政大臣米提利達如數交給猶大的首領設巴薩：</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀上 7:50; 民數記 7:19–89; 歷代志下 4:8"> 三十個金盤、一千個銀盤、二十九把刀、</span>
<span className="v" id="v10" data-v="10"> 三十個金碗、四百一十個次等銀碗及一千件其他器皿，</span>
<span className="v" id="v11" data-v="11" data-xref="提摩太後書 2:19–21; 羅馬書 9:23; 馬太福音 1:11–12"> 共有五千四百件金銀器皿。被擄者從巴比倫上耶路撒冷時，設巴薩把這些器皿一併帶去。</span>

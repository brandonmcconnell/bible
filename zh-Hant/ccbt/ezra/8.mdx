## 歸回之人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以斯拉記 7:7; 以斯拉記 2:62; 歷代志上 9:1"> 亞達薛西王年間，與我一起從巴比倫上到耶路撒冷之人的族長和家譜如下：</span>
<span className="v" id="v2" data-v="2" data-xref="歷代志上 3:22; 歷代志上 3:1; 歷代志上 6:3–15"> 非尼哈的子孫有革順；以他瑪的子孫有但以理；大衛的子孫有哈突；</span>
<span className="v" id="v3" data-v="3" data-xref="以斯拉記 2:3; 尼希米記 10:14; 尼希米記 7:8"> 巴錄的後裔、示迦尼的子孫有撒迦利亞及一百五十名與他一同記入族譜的男子；</span>
<span className="v" id="v4" data-v="4" data-xref="以斯拉記 2:6; 尼希米記 10:14; 尼希米記 7:11"> 巴哈·摩押的子孫有西拉希雅的兒子以利約乃及二百名男子；</span>
<span className="v" id="v5" data-v="5"> 薩土<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「薩土」參照《七十士譯本》，希伯來文無此字。">a</a></sup>的子孫有雅哈悉的兒子示迦尼及三百名男子；</span>
<span className="v" id="v6" data-v="6" data-xref="以斯拉記 2:15; 尼希米記 10:16; 尼希米記 7:20"> 亞丁的子孫有約拿單的兒子以別及五十名男子；</span>
<span className="v" id="v7" data-v="7" data-xref="以斯拉記 2:31; 尼希米記 7:34; 以斯拉記 2:7"> 以攔的子孫有亞他利雅的兒子耶篩亞及七十名男子；</span>
<span className="v" id="v8" data-v="8" data-xref="尼希米記 11:4; 以斯拉記 2:4; 尼希米記 7:9"> 示法提雅的子孫有米迦勒的兒子西巴第雅及八十名男子；</span>
<span className="v" id="v9" data-v="9" data-xref="尼希米記 7:11; 以斯拉記 2:6"> 約押的子孫有耶歇的兒子俄巴底亞及二百一十八名男子；</span>
<span className="v" id="v10" data-v="10"> 巴尼<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="「巴尼」參照《七十士譯本》，希伯來文無此字。">b</a></sup>的子孫有約細斐的兒子示羅密及一百六十名男子；</span>
<span className="v" id="v11" data-v="11" data-xref="以斯拉記 10:28; 尼希米記 7:16; 以斯拉記 2:11"> 比拜的子孫有比拜的兒子撒迦利亞及二十八名男子；</span>
<span className="v" id="v12" data-v="12" data-xref="以斯拉記 2:12; 尼希米記 7:17"> 押甲的子孫有哈加坦的兒子約哈難及一百一十名男子；</span>
<span className="v" id="v13" data-v="13" data-xref="以斯拉記 2:13; 尼希米記 7:18"> 稍後歸回的亞多尼干的子孫有以利法列、耶利、示瑪雅及六十名男子；</span>
<span className="v" id="v14" data-v="14" data-xref="尼希米記 10:12; 以斯拉記 2:14; 尼希米記 7:19"> 比革瓦伊的子孫有烏太、撒刻及七十名男子。</span>
</div>
</div>

## 以斯拉為聖殿召集利未人

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="以斯拉記 8:21; 以斯拉記 8:31; 以斯拉記 7:7"> 我把他們召集在流往亞哈瓦的河邊，我們在那裡紮營三天。我察看民眾和祭司，發現他們當中沒有利未人。</span>
<span className="v" id="v16" data-v="16" data-xref="箴言 2:6; 以斯拉記 8:18; 以斯拉記 10:39"> 於是，我派人把首領以利以謝、亞列、示瑪雅、以利拿單、雅立、以利拿單、拿單、撒迦利亞、米書蘭及兩位教師約雅立和以利拿單叫來。</span>
<span className="v" id="v17" data-v="17" data-xref="以斯拉記 2:43; 出埃及記 4:15; 民數記 8:22–26"> 我派他們去見迦西斐雅的首領易多，請他們告訴易多及其做殿役的親族帶一些人來我們上帝的殿裡事奉。</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米書 3:15; 以斯拉記 7:28; 尼希米記 2:8"> 我們的上帝施恩幫助我們，他們給我們帶來一位能幹的人示利比及其弟兄和兒子共十八人。示利比是以色列的兒子利未的後裔抹利的子孫。</span>
<span className="v" id="v19" data-v="19" data-xref="歷代志上 6:1; 歷代志上 6:16; 尼希米記 10:11"> 他們還帶來哈沙比雅和米拉利的子孫耶篩亞，以及哈沙比雅的弟兄和兒子共二十人。</span>
<span className="v" id="v20" data-v="20" data-xref="以斯拉記 2:43; 以斯拉記 7:7; 歷代志上 9:2"> 此外還有二百二十名殿役，他們都是被點名指派的。從前大衛和眾官員曾指派殿役服侍利未人。</span>
</div>
</div>

## 以斯拉帶領百姓禁食

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="歷代志下 20:3; 約珥書 1:14; 撒母耳記上 7:6"> 然後，我在亞哈瓦河邊宣佈禁食，為要在我們的上帝面前謙卑下來，祈求祂保護我們、我們的兒女及財物一路平安。</span>
<span className="v" id="v22" data-v="22" data-xref="彼得前書 3:12; 詩篇 33:18–19; 歷代志下 16:9"> 我羞於求王派步兵和騎兵沿途幫助我們禦敵，因為我們曾經告訴王：「我們的上帝會施恩幫助尋求祂的人，但會向背棄祂的人發烈怒。」</span>
<span className="v" id="v23" data-v="23" data-xref="耶利米書 29:12–13; 馬太福音 7:7–8; 以斯拉記 8:31"> 因此，我們為這事禁食、尋求我們的上帝，祂應允了我們。</span>
</div>
</div>

## 獻給聖殿的禮物

<div className="bt">
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="以斯拉記 8:18–19"> 我選出十二位祭司長：示利比、哈沙比雅和他們的十個弟兄。</span>
<span className="v" id="v25" data-v="25" data-xref="以斯拉記 8:33; 以斯拉記 7:14–16; 以斯拉記 1:8"> 王及其謀士和將領，以及所有在場的以色列人獻給我們上帝殿的金銀和器皿，我都稱了交給他們。</span>
<span className="v" id="v26" data-v="26" data-xref="以斯拉記 1:9–11"> 我交給他們的有四十四萬兩銀子、價值六萬八千兩銀子的器皿、六萬八千兩金子、</span>
<span className="v" id="v27" data-v="27" data-xref="耶利米哀歌 4:2"> 共重八公斤半的二十個金碗和兩件貴重如金子的上等精銅器皿。</span>
<span className="v" id="v28" data-v="28" data-xref="利未記 22:2–3; 利未記 21:6–8; 歷代志上 23:28"> 我對他們說：「你們和這些器皿是獻給耶和華的，金銀是自願獻給你們祖先的上帝耶和華的禮物。</span>
<span className="v" id="v29" data-v="29" data-xref="以斯拉記 8:33–34; 馬可福音 13:34–35; 歷代志上 26:20–26"> 你們要好好保管，護送到耶路撒冷耶和華殿的庫房裡，要在祭司長、利未人和以色列的各族長面前過秤。」</span>
<span className="v" id="v30" data-v="30" data-xref="以斯拉記 8:22; 歷代志上 29:2–3; 以賽亞書 60:13"> 於是，祭司和利未人接過這些稱過的金、銀和器皿，要帶去耶路撒冷我們上帝的殿裡。</span>
</div>
</div>

## 返回耶路撒冷

<div className="bt">
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="以斯拉記 8:21–22; 以斯拉記 7:9; 以斯拉記 8:15"> 一月十二日，我們從亞哈瓦河邊出發上耶路撒冷。我們的上帝施恩幫助我們，救我們脫離仇敵和路上埋伏之人的攻擊。</span>
<span className="v" id="v32" data-v="32" data-xref="尼希米記 2:11; 以斯拉記 7:8–9"> 到耶路撒冷後，我們休息了三天。</span>
<span className="v" id="v33" data-v="33" data-xref="尼希米記 3:4; 尼希米記 3:21; 以斯拉記 8:30"> 第四天，我們在上帝的殿裡把金銀和器皿過秤，交給烏利亞的兒子米利末祭司。在場的還有非尼哈的兒子以利亞撒，利未人耶書亞的兒子約撒拔和賓內的兒子挪亞底。</span>
<span className="v" id="v34" data-v="34"> 每樣東西都被數過、稱過，其重量都被記錄下來。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="以斯拉記 6:17; 歷代志下 29:31–32; 詩篇 66:10–15"> 從流亡之地歸回的人又獻燔祭給以色列的上帝，為全體以色列人獻上十二頭公牛、九十六隻公綿羊和七十七隻綿羊羔，並獻上十二隻公山羊作贖罪祭。這些都是獻給耶和華的燔祭。</span>
<span className="v" id="v36" data-v="36" data-xref="以斯拉記 7:21–24; 以斯拉記 4:7–23; 以斯拉記 6:13"> 他們將王的諭旨交給王的總督和幼發拉底河西的省長，眾官員都為民眾和上帝殿的工作提供幫助。</span>
</div>
</div>

## 比勒達發言

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="約伯記 2:11"> 書亞人比勒達回答說：</span>
<span className="v" id="v2" data-v="2" data-xref="約伯記 6:26; 約伯記 15:2; 列王紀上 19:11"> <span className="pl pl-1">「你要這樣絮叨到何時？</span><br /><span className="pl pl-1">你的話猶如陣陣狂風。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="申命記 32:4; 歷代志下 19:7; 創世記 18:25"> <span className="pl pl-1">上帝豈會歪曲正義？</span><br /><span className="pl pl-1">全能者豈會顛倒是非？</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="約伯記 1:5; 約伯記 1:18–19; 約伯記 5:4"> <span className="pl pl-1">如果你的兒女得罪了祂，</span><br /><span className="pl pl-1">祂會給他們應有的懲罰。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="雅各書 4:7–10; 希伯來書 3:7–8; 約伯記 11:13"> <span className="pl pl-1">但你若尋求上帝，</span><br /><span className="pl pl-1">向全能者懇求；</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="以賽亞書 51:9; 以賽亞書 3:10; 箴言 15:8"> <span className="pl pl-1">你若純潔、正直，</span><br /><span className="pl pl-1">祂必起身相助，</span><br /><span className="pl pl-1">恢復你公義的家園。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="約伯記 42:12–13; 馬太福音 13:31–32; 箴言 19:20"> <span className="pl pl-1">你起初雖然卑微，</span><br /><span className="pl pl-1">日後必興旺發達。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="申命記 32:7; 申命記 4:32; 約伯記 15:18"> <span className="pl pl-1">「你要請教先輩，</span><br /><span className="pl pl-1">探究祖先的經驗。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="歷代志上 29:15; 詩篇 144:4; 約伯記 14:2"> <span className="pl pl-1">因為我們昨天才出生，一無所知，</span><br /><span className="pl pl-1">我們在世的日子如同掠影。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="箴言 18:15; 馬太福音 12:35; 約伯記 12:7–8"> <span className="pl pl-1">先輩必給你教誨和指點，</span><br /><span className="pl pl-1">向你道出明智之言。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v11" data-v="11" data-xref="出埃及記 2:3; 以賽亞書 19:5–7"> <span className="pl pl-1">「蒲草無泥豈可長高？</span><br /><span className="pl pl-1">蘆葦無水豈可茂盛？</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="耶利米書 17:6; 詩篇 129:6–7; 馬太福音 13:20"> <span className="pl pl-1">它們還在生長、尚未割下，</span><br /><span className="pl pl-1">已比百草先枯萎。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 9:17; 約伯記 11:20; 約伯記 13:16"> <span className="pl pl-1">忘記上帝的人，結局也是如此；</span><br /><span className="pl pl-1">不信上帝的人，盼望終必破滅。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="以賽亞書 59:5–6"> <span className="pl pl-1">他所仰仗的虛若游絲，</span><br /><span className="pl pl-1">他所倚靠的誠如蛛網。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="約伯記 27:18; 路加福音 6:47–49; 馬太福音 7:24–27"> <span className="pl pl-1">他倚靠它，它卻支撐不住；</span><br /><span className="pl pl-1">他抓緊它，它卻脆弱不穩。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="詩篇 80:11; 約伯記 21:7–15; 約伯記 5:3"> <span className="pl pl-1">他像陽光下生機勃勃的植物，</span><br /><span className="pl pl-1">枝條爬滿了園囿，</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="以賽亞書 5:24; 馬可福音 11:20; 猶大書 1:12"> <span className="pl pl-1">根莖盤繞石堆，</span><br /><span className="pl pl-1">深深扎入石縫。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="約伯記 7:10; 詩篇 37:36; 約伯記 7:8"> <span className="pl pl-1">一旦他被連根拔起，</span><br /><span className="pl pl-1">原處必否認見過他。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="約伯記 20:5; 詩篇 113:7; 撒母耳記上 2:8"> <span className="pl pl-1">他的生命就這樣消逝</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「他的生命就這樣消逝」或譯「這就是他一生的樂趣」。">a</a></sup><br /><span className="pl pl-1">，</span><br /><span className="pl pl-1">地上會興起其他人。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v20" data-v="20" data-xref="約伯記 4:7; 詩篇 37:37; 詩篇 37:24"> <span className="pl pl-1">「上帝絕不會拋棄純全的人，</span><br /><span className="pl pl-1">也不會扶持邪惡的人。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 126:2; 創世記 21:6; 詩篇 126:6"> <span className="pl pl-1">祂要使你笑口常開，</span><br /><span className="pl pl-1">歡聲不斷。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="詩篇 132:18; 詩篇 109:29; 詩篇 35:26"> <span className="pl pl-1">憎恨你的人必抱愧蒙羞，</span><br /><span className="pl pl-1">惡人的帳篷必不復存在。」</span></span>

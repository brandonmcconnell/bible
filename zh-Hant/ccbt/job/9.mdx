## 約伯的回應

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1"> 約伯回答說：</span>
<span className="v" id="v2" data-v="2" data-xref="約伯記 4:17; 羅馬書 3:20; 約伯記 25:4"> <span className="pl pl-1">「不錯，我知道你所言不虛，</span><br /><span className="pl pl-1">但人怎能在上帝面前算為義人？</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="約伯記 10:2; 約伯記 40:2; 以賽亞書 57:15–16"> <span className="pl pl-1">人若想與祂辯駁，</span><br /><span className="pl pl-1">千次也不能勝一次。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="約伯記 36:5; 羅馬書 11:33; 以弗所書 3:20"> <span className="pl pl-1">祂充滿智慧，能力無比，</span><br /><span className="pl pl-1">誰能抗拒祂還能平安無恙？</span><br /></span>

<span className="v" id="v8" data-v="8" data-xref="以賽亞書 44:24; 以賽亞書 40:22; 詩篇 104:2–3"> <span className="pl pl-1">祂獨自鋪展穹蒼，</span><br /><span className="pl pl-1">步行在海浪之上。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="阿摩司書 5:8; 創世記 1:16; 約伯記 38:31–41"> <span className="pl pl-1">祂創造了北斗星、參星、昴星及南天的星座。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="約伯記 5:9; 詩篇 72:18; 以弗所書 3:20"> <span className="pl pl-1">祂行的奇事不可測度，</span><br /><span className="pl pl-1">奇蹟不可勝數。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="約伯記 23:8–9; 約伯記 35:14; 詩篇 77:19"> <span className="pl pl-1">祂經過我身旁，我卻看不見；</span><br /><span className="pl pl-1">祂從旁邊掠過，我也無法察覺。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="以賽亞書 45:9; 約伯記 11:10; 約伯記 23:13"> <span className="pl pl-1">祂若奪取，誰能阻擋？</span><br /><span className="pl pl-1">誰敢問祂，『你做什麼？』</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 89:10; 約伯記 26:12; 以賽亞書 30:7"> <span className="pl pl-1">上帝不會忍怒不發，</span><br /><span className="pl pl-1">海怪</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「海怪」希伯來文是「拉哈伯」，下同26·12。">a</a></sup><br /><span className="pl pl-1">的幫手必屈膝在祂腳前。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="列王紀上 8:27; 約伯記 9:3; 約伯記 4:19"> <span className="pl pl-1">「因此，我怎敢與祂辯駁？</span><br /><span className="pl pl-1">怎敢措辭與祂理論？</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="約伯記 10:15; 約伯記 8:5; 約伯記 10:2"> <span className="pl pl-1">我縱然無辜，也無法申訴，</span><br /><span className="pl pl-1">只能乞求我的審判者施恩。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="約伯記 29:24; 出埃及記 6:9; 詩篇 66:18–20"> <span className="pl pl-1">即使我呼喚祂的時候，祂回應我，</span><br /><span className="pl pl-1">我仍不相信祂會垂聽我的聲音。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="約伯記 16:14; 約伯記 2:3; 約伯記 34:6"> <span className="pl pl-1">祂用暴風摧毀我，</span><br /><span className="pl pl-1">無故地使我飽受創傷。</span><br /></span>

<span className="v" id="v19" data-v="19" data-xref="約伯記 9:32–33; 約伯記 9:4; 哥林多前書 1:25"> <span className="pl pl-1">若論力量，祂甚強大；</span><br /><span className="pl pl-1">若上公堂，誰敢傳祂？</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="約伯記 15:5–6; 腓立比書 3:12–15; 詩篇 143:2"> <span className="pl pl-1">即使我清白無辜，我的口也會認罪；</span><br /><span className="pl pl-1">即使我純全無過，祂也會判我有罪。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="約伯記 1:1; 詩篇 139:23–24; 箴言 28:26"> <span className="pl pl-1">我雖純全無過，也已毫不在乎自己，</span><br /><span className="pl pl-1">我厭惡我的生命。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="傳道書 9:1–3; 路加福音 13:2–4; 約伯記 10:8"> <span className="pl pl-1">因為，我認為都是一樣，</span><br /><span className="pl pl-1">純全無過的人和惡人都會被祂毀滅。</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="約伯記 24:12; 約伯記 1:13–19; 約伯記 4:7"> <span className="pl pl-1">災禍突然奪走人命時，</span><br /><span className="pl pl-1">祂嘲笑無辜者的遭遇。</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="約伯記 10:3; 耶利米書 12:1–2; 詩篇 73:3–7"> <span className="pl pl-1">大地落入惡人手中，</span><br /><span className="pl pl-1">蒙蔽審判官眼睛的不是祂是誰？</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v25" data-v="25" data-xref="約伯記 7:6–7; 雅各書 4:14; 詩篇 90:9–10"> <span className="pl pl-1">「我的年日比信差還快，</span><br /><span className="pl pl-1">匆匆而過，不見幸福。</span><br /></span>

<span className="v" id="v30" data-v="30" data-xref="耶利米書 2:22; 詩篇 26:6; 約翰一書 1:8"> <span className="pl pl-1">即使我用雪水淨身，</span><br /><span className="pl pl-1">用鹼水洗手，</span><br /></span>

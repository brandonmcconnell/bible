## 以利戶的回答

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="約伯記 10:7; 約伯記 33:9; 約伯記 10:2"> 三人見約伯自以為義，便不再回答他。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 22:21; 約伯記 40:8; 約伯記 27:2"> 那時，蘭族的布西人巴拉迦的兒子以利戶對約伯很惱火，因為約伯自以為義，不承認上帝的公義。</span>
<span className="v" id="v3" data-v="3" data-xref="約伯記 8:6; 約伯記 24:25; 約伯記 22:5–30"> 他對約伯的三個朋友也很惱火，因為他們說約伯有罪，卻無法回答約伯的質問<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「因為他們說約伯有罪，卻無法回答約伯的質問」有古卷作「因為他們無法回答約伯的質問，因而置上帝於不公」。">a</a></sup>。</span>
<span className="v" id="v4" data-v="4" data-xref="約伯記 32:11–12; 箴言 18:13"> 由於不及他們年長，以利戶便等他們說完才向約伯發言。</span>
<span className="v" id="v5" data-v="5" data-xref="約伯記 32:2; 出埃及記 32:19"> 他見三人無法回答約伯，很惱火。</span>
<span className="v" id="v6" data-v="6" data-xref="約伯記 15:10; 提摩太前書 5:1; 提多書 2:6"> 於是，布西人巴拉迦的兒子以利戶說：<br /><span className="pl pl-1">「我年紀輕，你們是長輩，</span><br /><span className="pl pl-1">所以我畏懼，不敢向你們陳明觀點。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="箴言 16:31; 約伯記 12:12; 希伯來書 5:12"> <span className="pl pl-1">我想，前輩當先發言，</span><br /><span className="pl pl-1">長者當傳授智慧。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="約伯記 38:36; 約伯記 33:4; 提摩太後書 3:16"> <span className="pl pl-1">但只有人裡面的靈——</span><br /><span className="pl pl-1">全能者的氣息賜人悟性。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="馬太福音 11:25; 約伯記 12:20; 傳道書 4:13"> <span className="pl pl-1">長者不一定有智慧，</span><br /><span className="pl pl-1">年老不一定明白是非。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="哥林多前書 7:25; 哥林多前書 7:40"> <span className="pl pl-1">因此，請聽我說，</span><br /><span className="pl pl-1">我也要陳明觀點。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="約伯記 29:21; 約伯記 5:27; 箴言 28:11"> <span className="pl pl-1">看啊，我一直等候你們發言，</span><br /><span className="pl pl-1">傾聽你們的高見，</span><br /><span className="pl pl-1">等你們斟詞酌句。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="約伯記 32:3; 提摩太前書 1:7"> <span className="pl pl-1">我仔細聆聽，</span><br /><span className="pl pl-1">發現你們無人能駁倒約伯，</span><br /><span className="pl pl-1">無人能答覆他。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="耶利米書 9:23; 哥林多前書 1:27–29; 哥林多前書 3:18"> <span className="pl pl-1">你們不要說，『我們找到了智慧，</span><br /><span className="pl pl-1">使他折服的是上帝而非人。』</span><br /></span>
<span className="v" id="v14" data-v="14"> <span className="pl pl-1">約伯沒有與我辯論，</span><br /><span className="pl pl-1">我也不會用你們的理論答覆他。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="約伯記 6:24–25; 馬太福音 22:46; 約伯記 29:22"> <span className="pl pl-1">「他們驚慌失措，無言以對，</span><br /><span className="pl pl-1">再也說不出話來。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="雅各書 1:19; 約伯記 13:5; 阿摩司書 5:13"> <span className="pl pl-1">難道他們不說話，站在那裡無言以對，</span><br /><span className="pl pl-1">我就要等下去嗎？</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="約伯記 35:3–4; 約伯記 33:12; 約伯記 32:10"> <span className="pl pl-1">我也要作出答覆，</span><br /><span className="pl pl-1">陳明我的觀點。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 39:3; 使徒行傳 4:20; 哥林多後書 5:13–14"> <span className="pl pl-1">因為我心裡積滿了話，</span><br /><span className="pl pl-1">我裡面的靈催促我說出來。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="馬太福音 9:17"> <span className="pl pl-1">我裡面像盛滿了酒，卻沒有出口，</span><br /><span className="pl pl-1">又如將要破裂的新酒袋。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="箴言 8:6–7; 約伯記 21:3; 約伯記 13:13"> <span className="pl pl-1">我要一吐為快，</span><br /><span className="pl pl-1">我要開口答覆。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="利未記 19:15; 約伯記 13:8; 馬太福音 22:16"> <span className="pl pl-1">我不看人的情面，</span><br /><span className="pl pl-1">也不奉承人。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="詩篇 12:2–3; 帖撒羅尼迦前書 2:5; 箴言 29:5"> <span className="pl pl-1">我不懂奉承，</span><br /><span className="pl pl-1">否則，造物主會很快把我除掉。</span></span>
</div>

## 約伯咒詛自己

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="耶利米書 20:14–15; 詩篇 106:33; 詩篇 39:2–3"> 後來，約伯開口咒詛自己的生日，</span>
<span className="v" id="v2" data-v="2" data-xref="士師記 18:14"> 說：</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米書 20:14–18; 耶利米書 15:10; 約伯記 10:18–19"> <span className="pl pl-1">「願我出生的那日和懷我的那夜都滅沒。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="使徒行傳 27:20; 出埃及記 10:22–23; 約珥書 2:2"> <span className="pl pl-1">願那日一片黑暗，</span><br /><span className="pl pl-1">被天上的上帝遺忘，</span><br /><span className="pl pl-1">沒有陽光照耀。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="約伯記 10:21–22; 詩篇 23:4; 約伯記 28:3"> <span className="pl pl-1">願那日被幽暗和濃濃的黑影籠罩，</span><br /><span className="pl pl-1">被密雲覆蓋，</span><br /><span className="pl pl-1">被陰暗淹沒。</span><br /></span>
<span className="v" id="v6" data-v="6"> <span className="pl pl-1">願那夜被幽暗吞噬，</span><br /><span className="pl pl-1">不列在年日中，</span><br /><span className="pl pl-1">不算在歲月裡。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="以賽亞書 24:8; 耶利米書 7:34; 啟示錄 18:22–23"> <span className="pl pl-1">願那夜無人生育，</span><br /><span className="pl pl-1">毫無快樂之聲。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="約伯記 41:1; 約伯記 41:10; 馬可福音 5:38"> <span className="pl pl-1">願那些咒詛白日、</span><br /><span className="pl pl-1">能惹動海怪的人，</span><br /><span className="pl pl-1">咒詛那夜。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="約伯記 41:18; 耶利米書 13:16; 約伯記 30:26"> <span className="pl pl-1">願那夜的晨星昏暗，</span><br /><span className="pl pl-1">等不到晨光的出現，</span><br /><span className="pl pl-1">看不見黎明的眼簾。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="耶利米書 20:17; 傳道書 6:3–5; 創世記 20:18"> <span className="pl pl-1">因為那夜沒有關閉我母胎的門，</span><br /><span className="pl pl-1">也沒有遮住我眼前的患難。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v11" data-v="11" data-xref="約伯記 10:18–19; 以賽亞書 46:3; 詩篇 71:6"> <span className="pl pl-1">「為何我不出生時就夭折，</span><br /><span className="pl pl-1">出母胎時就斷氣？</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="以賽亞書 66:12; 創世記 30:3; 創世記 50:23"> <span className="pl pl-1">為何要把我抱在膝上，</span><br /><span className="pl pl-1">用乳汁哺育我？</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="傳道書 9:10; 約伯記 21:13; 約伯記 14:10–12"> <span className="pl pl-1">不然我早已安然躺臥、長眠安息，</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="約伯記 15:28; 詩篇 89:48; 詩篇 49:14"> <span className="pl pl-1">與世上的君王和謀臣作伴——他們為自己建造的宮殿已荒廢，</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="列王紀上 10:27; 約伯記 22:25; 西番雅書 1:18"> <span className="pl pl-1">與房屋堆滿金銀的王侯同眠。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="詩篇 58:8; 傳道書 6:3; 哥林多前書 15:8"> <span className="pl pl-1">為何我沒有像未見天日就流產的嬰兒一樣消逝？</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="啟示錄 14:13; 約伯記 17:16; 希伯來書 4:11"> <span className="pl pl-1">那裡，惡人不再攪擾，</span><br /><span className="pl pl-1">疲憊者得到安息，</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="約伯記 39:7; 以賽亞書 14:3–4; 出埃及記 5:6–8"> <span className="pl pl-1">被囚者得到安寧，</span><br /><span className="pl pl-1">聽不見監工的斥責。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="傳道書 8:8; 約伯記 30:23; 傳道書 12:7"> <span className="pl pl-1">尊貴與卑賤的人都在那裡，</span><br /><span className="pl pl-1">奴僕不再受主人的轄制。</span></span>
</div>
<div className="bp poetry">

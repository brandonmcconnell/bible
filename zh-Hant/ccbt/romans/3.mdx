<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="羅馬書 2:25–29; 創世記 25:32; 傳道書 6:11"> 那麼，猶太人有什麼長處呢？割禮有什麼價值呢？</span>
<span className="v" id="v2" data-v="2" data-xref="羅馬書 9:4; 使徒行傳 7:38; 哥林多前書 9:17"> 其實在各方面有很多好處！首先，上帝的聖言託付給了猶太人。</span>
<span className="v" id="v3" data-v="3" data-xref="提摩太後書 2:13; 希伯來書 4:2; 羅馬書 9:6"> 雖然有些人不信，但那有什麼關係呢？難道上帝的信實可靠會因他們的不信而化為無有嗎？</span>
<span className="v" id="v4" data-v="4" data-xref="詩篇 51:4; 詩篇 116:11; 加拉太書 2:17"> 當然不會！縱然人人都撒謊，上帝仍然真實可靠。正如聖經上說：<br /><span className="pl pl-1">「你的判語證明你是公義的；</span><br /><span className="pl pl-1">你雖被人控告，卻終必得勝。」</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="詩篇51·4。">a</a></sup></span>
<span className="v" id="v5" data-v="5" data-xref="羅馬書 6:19; 加拉太書 3:15; 羅馬書 9:18–20"> 我姑且用人的觀點說：「如果我們的不義反襯出上帝的公義，我們該怎麼說呢？上帝向我們發怒是祂不公正嗎？」</span>
<span className="v" id="v6" data-v="6" data-xref="創世記 18:25; 使徒行傳 17:31; 約伯記 8:3"> 當然不是！若是這樣，上帝怎麼能審判這世界呢？</span>
<span className="v" id="v7" data-v="7" data-xref="羅馬書 3:4; 羅馬書 9:19–20; 使徒行傳 13:27–29"> 也許有人說：「如果我們的虛謊凸顯出上帝的真實，增加祂的榮耀，為什麼祂還要把我們當作罪人審判呢？」</span>
<span className="v" id="v8" data-v="8" data-xref="羅馬書 6:1; 羅馬書 6:15; 羅馬書 5:20"> 為什麼不乾脆說「我們作惡吧，好成就善事」？有人毀謗我們，說我們傳這種道理。這些人受審判是罪有應得！</span>
</div>
</div>

## 沒有義人

<div className="bt">
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="加拉太書 3:22; 羅馬書 6:15; 以賽亞書 65:5"> 那麼，我們猶太人比別人優越嗎？絕對不是！我們已經說過，無論是猶太人還是希臘人，所有的人都在罪的權勢之下。</span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 53:1–3; 詩篇 14:1–3; 羅馬書 3:23"> 正如聖經上說：<br /><span className="pl pl-1">「沒有義人，連一個也沒有，</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 14:2–4; 詩篇 53:2; 提多書 3:3"> <span className="pl pl-1">沒有人明白，沒有人尋求上帝。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 14:3; 傳道書 7:20; 以賽亞書 64:6"> <span className="pl pl-1">人人偏離正道，變得毫無價值。</span><br /><span className="pl pl-1">無人行善，連一個也沒有。</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="詩篇14·1‑3；53·1‑3；傳道書7·20。">b</a></sup><br /></span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 5:9; 詩篇 140:3; 馬太福音 23:27–28"> <span className="pl pl-1">他們的喉嚨是敞開的墳墓，</span><br /><span className="pl pl-1">舌頭上盡是詭詐，</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="詩篇5·9。">c</a></sup><br /><span className="pl pl-1">嘴唇有蛇的毒液，</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="詩篇140·3。">d</a></sup><br /></span>
<span className="v" id="v14" data-v="14" data-xref="詩篇 10:7; 詩篇 109:17–18; 詩篇 59:12"> <span className="pl pl-1">滿口咒詛，言語惡毒；</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="詩篇10·7。">e</a></sup><br /></span>
<span className="v" id="v15" data-v="15" data-xref="以賽亞書 59:7–8; 箴言 1:16; 箴言 6:18"> <span className="pl pl-1">殺人流血，腳步飛快；</span><br /></span>
<span className="v" id="v16" data-v="16"> <span className="pl pl-1">所到之處，大肆毀滅；</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="以賽亞書 59:8; 羅馬書 5:1; 路加福音 1:79"> <span className="pl pl-1">他們不知道平安之路；</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="以賽亞書59·7、8。">f</a></sup><br /></span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 36:1; 箴言 23:17; 箴言 16:6"> <span className="pl pl-1">他們眼中對上帝毫無畏懼。」</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="詩篇36·1。">g</a></sup></span>
<span className="v" id="v19" data-v="19" data-xref="加拉太書 3:10; 加拉太書 3:22–23; 羅馬書 2:12–18"> 我們知道律法所講的都是針對律法之下的人，好叫所有的人都無話可說，使全世界都伏在上帝的審判之下。</span>
<span className="v" id="v20" data-v="20" data-xref="加拉太書 2:16; 使徒行傳 13:39; 羅馬書 3:28"> 因為無人能夠靠遵行律法被上帝稱為義人，律法的本意是要使人知罪。</span>
</div>
</div>

## 因信稱義

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="使徒行傳 10:43; 耶利米書 33:16; 腓立比書 3:9"> 但如今，上帝的義在律法以外顯明出來，有律法和眾先知作見證。</span>
<span className="v" id="v22" data-v="22" data-xref="羅馬書 10:12; 加拉太書 3:28; 羅馬書 8:1"> 人只要信耶穌基督，就可以被上帝稱為義人，沒有一個人例外。</span>
<span className="v" id="v23" data-v="23" data-xref="傳道書 7:20; 約翰一書 1:8–10; 羅馬書 3:9"> 因為世人都犯了罪，虧缺上帝的榮耀，</span>
<span className="v" id="v24" data-v="24" data-xref="彼得前書 1:18–19; 提多書 3:5–7; 歌羅西書 1:14"> 但蒙上帝的恩典，靠著基督耶穌的救贖，就被無條件地稱為義人。</span>
<span className="v" id="v25" data-v="25" data-xref="羅馬書 3:23–24; 彼得前書 1:18–20; 約翰一書 4:10"> 上帝藉基督耶穌所流的血使祂成為贖罪祭，讓人憑信心領受。這是為了顯明上帝的義，因為祂用忍耐的心寬容人過去的罪，</span>
<span className="v" id="v26" data-v="26" data-xref="申命記 32:4; 羅馬書 4:5; 羅馬書 3:30"> 好在現今顯明祂的義，使人知道祂是公義的，祂也稱信耶穌的為義人。</span>
<span className="v" id="v27" data-v="27" data-xref="羅馬書 4:2; 羅馬書 2:23; 哥林多前書 1:29–31"> 既然如此，我們哪裡能誇口呢？當然沒有可誇的。靠什麼方法讓人不能誇口呢？靠遵行律法嗎？不是！是靠信主的方法。</span>
<span className="v" id="v28" data-v="28" data-xref="加拉太書 2:16; 加拉太書 3:8; 提多書 3:7"> 因為我們堅信人被稱為義人是藉著信，不是靠遵行律法。</span>
<span className="v" id="v29" data-v="29" data-xref="歌羅西書 3:11; 以弗所書 3:6; 撒迦利亞書 2:11"> 難道上帝只是猶太人的上帝嗎？祂不也是外族人的上帝嗎？祂當然也是外族人的上帝。</span>
<span className="v" id="v30" data-v="30" data-xref="加拉太書 3:8; 加拉太書 3:20; 腓立比書 3:3"> 因為上帝只有一位，祂本著信稱受割禮的人為義人，也本著信稱未受割禮的人為義人。</span>
<span className="v" id="v31" data-v="31" data-xref="加拉太書 2:21; 馬太福音 5:17; 羅馬書 13:8–10"> 這麼說來，我們是藉著信廢掉上帝的律法嗎？當然不是！我們反倒是鞏固律法。</span>
</div>
</div>

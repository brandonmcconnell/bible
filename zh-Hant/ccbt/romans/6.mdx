## 與基督同死同活

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="彼得前書 2:16; 加拉太書 5:13; 羅馬書 6:15"> 那麼，我們該怎麼說呢？我們可以繼續犯罪，使恩典更豐富嗎？</span>
<span className="v" id="v2" data-v="2" data-xref="約翰一書 3:9; 歌羅西書 3:3; 羅馬書 7:4"> 當然不可！我們既然向罪死了，豈可繼續活在罪中？</span>
<span className="v" id="v3" data-v="3" data-xref="加拉太書 3:27; 加拉太書 2:20–21; 羅馬書 6:8"> 難道你們不知道，我們受洗歸屬基督耶穌是和祂一同死嗎？</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多後書 5:17; 歌羅西書 3:10; 以弗所書 4:22–24"> 所以，我們藉著洗禮和祂同死同埋葬了，為要行事為人有新生命的樣式，正如基督藉著父的榮耀從死裡復活一樣。</span>
<span className="v" id="v5" data-v="5" data-xref="腓立比書 3:10–11; 哥林多後書 4:10; 歌羅西書 2:12"> 我們如果已經在基督的死亡上與祂聯合，也必在祂的復活上與祂聯合。</span>
<span className="v" id="v6" data-v="6" data-xref="加拉太書 2:20; 以弗所書 4:22; 加拉太書 5:24"> 我們知道，我們的舊人已經和祂一同被釘在十字架上，使轄制我們身體的罪失去力量，使我們不再做罪的奴隸。</span>
<span className="v" id="v7" data-v="7" data-xref="彼得前書 4:1; 歌羅西書 3:1–3; 羅馬書 7:4"> 因為死去的人已經脫離了罪。</span>
<span className="v" id="v8" data-v="8" data-xref="提摩太後書 2:11–12; 歌羅西書 3:3–4; 哥林多後書 4:10–14"> 我們如果已經與基督同死，相信也必與祂同活。</span>
<span className="v" id="v9" data-v="9" data-xref="羅馬書 6:14; 啟示錄 1:18; 使徒行傳 2:24–28"> 因為我們知道，基督既然從死裡復活了，就不會再死，死亡也不能再控制祂。</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多後書 5:21; 彼得前書 4:6; 彼得前書 3:18"> 祂死，是向罪死，只死一次；祂活，卻是向上帝活著。</span>
<span className="v" id="v11" data-v="11" data-xref="歌羅西書 3:3–5; 哥林多前書 6:20; 羅馬書 6:2"> 同樣，你們在基督耶穌裡應當看自己是向罪死了，向上帝活著。</span>
<span className="v" id="v12" data-v="12" data-xref="加拉太書 5:16; 羅馬書 6:16; 羅馬書 8:13"> 所以，不要讓罪轄制你們必死的身體，使你們順從身體的私慾。</span>
<span className="v" id="v13" data-v="13" data-xref="羅馬書 12:1; 羅馬書 6:16; 歌羅西書 3:5"> 也不要將你們的肢體獻給罪作不義的工具，而是要像一個從死裡復活的人將自己獻給上帝，把你們的肢體獻給上帝作義的工具。</span>
<span className="v" id="v14" data-v="14" data-xref="加拉太書 5:18; 羅馬書 8:2; 羅馬書 7:4–11"> 罪不能再主宰你們，因為你們已經不在律法之下，而是在恩典之中。</span>
</div>
</div>

## 做義的奴僕

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="提多書 2:11–14; 以弗所書 2:8–10; 羅馬書 6:1–2"> 那麼，我們在恩典之中，不在律法之下，就可以任意犯罪嗎？當然不可！</span>
<span className="v" id="v16" data-v="16" data-xref="約翰福音 8:34; 馬太福音 6:24; 約書亞記 24:15"> 你們難道不明白嗎？你們獻身為奴服從誰，就是誰的奴隸。做罪的奴隸，結局是死亡；作上帝的奴僕，就被稱為義人。</span>
<span className="v" id="v17" data-v="17" data-xref="彼得前書 2:9; 提摩太後書 1:13; 羅馬書 1:8"> 感謝上帝！你們從前雖然做過罪的奴隸，現在卻衷心服從了所傳給你們的教導，</span>
<span className="v" id="v18" data-v="18" data-xref="羅馬書 6:22; 羅馬書 8:2; 加拉太書 5:1"> 從罪中得到釋放，成為義的奴僕。</span>
<span className="v" id="v19" data-v="19" data-xref="羅馬書 6:13; 彼得前書 4:2–4; 歌羅西書 3:5–7"> 因為你們有人性的軟弱，我就用簡單的話向你們解釋。以前你們將肢體獻給骯髒不法的事，任其奴役，助長不法。現在你們要將肢體獻給義，為義效勞，成為聖潔的人。</span>
<span className="v" id="v20" data-v="20" data-xref="羅馬書 6:16–17; 約翰福音 8:34"> 你們做罪的奴隸時，不受義的約束，</span>
<span className="v" id="v21" data-v="21" data-xref="羅馬書 1:32; 羅馬書 7:5; 羅馬書 6:23"> 做了現在引以為恥的事，得到什麼益處呢？那些事只能導致死亡！</span>
<span className="v" id="v22" data-v="22" data-xref="彼得前書 2:16; 羅馬書 6:18; 羅馬書 8:2"> 但現在你們已從罪中得到釋放，作了上帝的奴僕，結果使你們聖潔，最終得到永生。</span>
<span className="v" id="v23" data-v="23" data-xref="約翰福音 3:36; 羅馬書 5:12; 雅各書 1:15"> 因為罪的代價就是死亡，而上帝藉著我們的主基督耶穌賜下的禮物則是永生。</span>
</div>
</div>

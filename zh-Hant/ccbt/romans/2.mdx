## 上帝公義的審判

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 6:37; 羅馬書 2:3; 約翰福音 8:7–9"> 因此，你這論斷人的啊，不管你是誰，都難逃罪責。你在什麼事上論斷別人，就在什麼事上定了自己的罪，因為你論斷別人，自己卻在做同樣的事。</span>
<span className="v" id="v2" data-v="2" data-xref="詩篇 9:7–8; 西番雅書 3:5; 詩篇 145:17"> 我們都知道，上帝必按真理審判做這些事的人。</span>
<span className="v" id="v3" data-v="3" data-xref="箴言 16:5; 路加福音 12:14; 羅馬書 1:32–1"> 你這人啊，你論斷別人，自己卻做同樣的事，你以為自己能逃脫上帝的審判嗎？</span>
<span className="v" id="v4" data-v="4" data-xref="彼得後書 3:9; 以賽亞書 30:18; 出埃及記 34:6"> 還是你藐視祂深厚的慈愛、寬容和忍耐，不知道祂的慈愛是要引導你悔改嗎？</span>
<span className="v" id="v5" data-v="5" data-xref="傳道書 12:14; 羅馬書 1:18; 羅馬書 2:2–3"> 你這樣硬著心不肯悔改，等於是在為自己積蓄烈怒，上帝的烈怒必在祂施行公義審判的日子臨到你。</span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 62:12; 耶利米書 32:19; 馬太福音 16:27"> 上帝必照各人的行為施行賞罰。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="詩篇62·12；箴言24·12。">a</a></sup></span>
<span className="v" id="v7" data-v="7" data-xref="提摩太後書 4:7–8; 路加福音 8:15; 提摩太後書 1:10"> 凡是恆心行善、尋求榮耀、尊貴和永恆福分的人，祂要把永生賜給他們；</span>
<span className="v" id="v8" data-v="8" data-xref="約翰福音 3:18–21; 帖撒羅尼迦後書 1:8; 提摩太前書 6:3–4"> 凡是自私自利、違背真理、行為不義的人，祂的烈怒和怒氣要降在他們身上。</span>
<span className="v" id="v9" data-v="9" data-xref="彼得前書 4:17; 以西結書 18:4; 羅馬書 1:16"> 一切作惡之人必受患難和痛苦，先是猶太人，然後是希臘人。</span>
<span className="v" id="v10" data-v="10" data-xref="以賽亞書 32:17; 以賽亞書 26:12; 民數記 6:26"> 一切行善之人必享榮耀、尊貴和平安，先是猶太人，然後是希臘人。</span>
<span className="v" id="v11" data-v="11" data-xref="申命記 10:17; 使徒行傳 10:34; 歷代志下 19:7"> 因為上帝不偏待人。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="哥林多前書 9:21; 加拉太書 3:10; 加拉太書 2:16–19"> 沒有上帝律法的人若犯罪，雖然不按律法受審判，仍要滅亡；有上帝律法的人若犯罪，必按律法受審判。</span>
<span className="v" id="v13" data-v="13" data-xref="雅各書 1:22–25; 約翰一書 3:7; 雅各書 2:21–25"> 因為在上帝面前，不是僅僅聽到律法的人是義人，而是遵行律法的人才能被稱為義人。</span>
<span className="v" id="v14" data-v="14" data-xref="羅馬書 2:12; 羅馬書 1:19–20; 羅馬書 2:27"> 沒有律法的外族人若順著天性做合乎律法的事，他們雖然沒有律法，自己就是自己的律法。</span>
<span className="v" id="v15" data-v="15" data-xref="哥林多後書 5:11; 哥林多後書 1:12; 羅馬書 1:18–19"> 這表明律法的要求刻在他們心裡，他們的良心也可以作見證，並且他們的思想有時指控他們，有時為他們辯護。</span>
<span className="v" id="v16" data-v="16" data-xref="傳道書 12:14; 哥林多前書 4:5; 使徒行傳 17:31"> 按照我所傳的福音，到了審判之日，上帝要藉著耶穌基督審判人一切隱祕的事。</span>
</div>
</div>

## 猶太人與律法

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="羅馬書 2:23; 彌迦書 3:11; 以賽亞書 48:1–2"> 你自稱是猶太人，倚仗上帝所賜的律法，自誇與上帝有特別的關係；</span>
<span className="v" id="v18" data-v="18" data-xref="帖撒羅尼迦前書 5:21; 申命記 4:8; 雅各書 4:17"> 你受過律法的教導，知道上帝的旨意，能明辨是非；</span>
<span className="v" id="v19" data-v="19" data-xref="啟示錄 3:17–18; 馬太福音 15:14; 以賽亞書 49:6"> 你自信可以做盲人的嚮導、黑暗中的人的光、</span>
<span className="v" id="v20" data-v="20" data-xref="提摩太後書 3:5; 提多書 1:16; 提摩太後書 1:13"> 愚昧人的師傅、小孩子的老師，因為你從律法中得到了知識和真理。</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多前書 9:27; 馬太福音 23:3–28; 路加福音 12:47"> 那麼，你這教導別人的，為什麼不教導自己呢？你教導人不可偷盜，自己卻偷盜嗎？</span>
<span className="v" id="v22" data-v="22" data-xref="瑪拉基書 3:8; 馬太福音 12:39; 馬可福音 11:17"> 你告訴他人不可通姦，自己卻通姦嗎？你憎惡偶像，自己卻去偷廟裡的東西嗎？</span>
<span className="v" id="v23" data-v="23" data-xref="雅各書 4:16–17; 羅馬書 2:17; 羅馬書 3:2"> 你以律法自誇，自己卻違背律法羞辱上帝嗎？</span>
<span className="v" id="v24" data-v="24" data-xref="以西結書 36:20–23; 以賽亞書 52:5; 彼得後書 2:2"> 正如聖經上說：「因你們的緣故，上帝的名在外族人中受到褻瀆！」<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="以賽亞書52·5；以西結書36·22。">b</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="耶利米書 4:4; 加拉太書 5:3–6; 使徒行傳 7:51"> 如果你遵行律法，割禮才有價值；如果你違背律法，受了割禮也如同未受割禮。</span>
<span className="v" id="v26" data-v="26" data-xref="歌羅西書 2:11; 哥林多前書 7:18–19; 羅馬書 8:4"> 如果未受割禮的人遵行律法的教導，他豈不算是受了割禮嗎？</span>
<span className="v" id="v27" data-v="27" data-xref="馬太福音 12:41–42; 羅馬書 2:29; 哥林多後書 3:6"> 身體未受割禮卻遵行律法的人，必審判你這有律法條文、受了割禮卻違背律法的人。</span>
<span className="v" id="v28" data-v="28" data-xref="加拉太書 6:15; 馬太福音 3:9; 羅馬書 9:6–8"> 因為徒具外表的猶太人不是真正的猶太人，身體上的割禮也不是真正的割禮。</span>
<span className="v" id="v29" data-v="29" data-xref="申命記 30:6; 腓立比書 3:3; 申命記 10:16"> 唯有從心裡做猶太人的才是真猶太人，真割禮是藉著聖靈在心裡受的割禮，不在於律法條文。這樣的人得到的稱讚不是從人來的，而是從上帝來的。</span>
</div>
</div>

## 問候

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行傳 9:15; 羅馬書 15:16; 哥林多前書 1:1"> 我是基督耶穌的奴僕保羅，蒙召作使徒，特為傳上帝的福音。</span>
<span className="v" id="v2" data-v="2" data-xref="提多書 1:2; 路加福音 1:70; 羅馬書 3:21"> 這福音是上帝從前藉著眾先知在聖經中應許的，</span>
<span className="v" id="v3" data-v="3" data-xref="馬太福音 1:1; 加拉太書 4:4; 耶利米書 23:5–6"> 講的是上帝的兒子——我們主耶穌基督的事。從肉身來看，祂是大衛的後裔；</span>
<span className="v" id="v4" data-v="4" data-xref="希伯來書 9:14; 希伯來書 5:5–6; 以弗所書 1:19–23"> 從聖潔的靈來看，祂從死裡復活，用大能顯明自己是上帝的兒子。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行傳 9:15; 羅馬書 16:26; 使徒行傳 6:7"> 我們從祂領受了恩典並成為使徒，要帶領萬族的人信從祂，使祂的名得榮耀。</span>
<span className="v" id="v6" data-v="6" data-xref="彼得前書 2:9; 啟示錄 17:14; 彼得後書 1:10"> 你們也是其中蒙召信從耶穌基督的人。</span>
<span className="v" id="v7" data-v="7" data-xref="歌羅西書 1:2; 猶大書 1:1–2; 以弗所書 1:2"> 我問候所有住在羅馬、上帝所愛、蒙召做聖徒的人。願我們的父上帝和主耶穌基督賜給你們恩典和平安！</span>
</div>
</div>

## 保羅渴望去羅馬

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="羅馬書 16:19; 哥林多前書 1:4; 帖撒羅尼迦前書 1:8–9"> 首先，我藉著耶穌基督為各位感謝我的上帝，因為你們的信心正在傳遍天下。</span>
<span className="v" id="v9" data-v="9" data-xref="以弗所書 6:18; 提摩太後書 1:3; 以弗所書 1:16–19"> 我在祂兒子的福音事工上全心事奉的上帝可以為我作見證：我如何在禱告中常常想到你們，並求上帝讓我照祂的旨意最終能去你們那裡。</span>
<span className="v" id="v11" data-v="11" data-xref="彼得後書 1:12; 羅馬書 16:25; 羅馬書 15:29"> 因為我實在想見你們，好將一些屬靈的恩賜分給你們，使你們堅固，</span>
<span className="v" id="v12" data-v="12" data-xref="帖撒羅尼迦前書 3:7–10; 約翰三書 1:3–4; 哥林多後書 7:13"> 也可以說是藉著我們彼此的信心互相激勵。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行傳 19:21; 腓立比書 4:17; 提摩太後書 4:17"> 弟兄姊妹，我希望你們知道，我曾多次計劃去你們那裡，要在你們中間收穫一些福音的果子，像在其他外族人中一樣，只是至今仍有攔阻。</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多前書 9:16–23; 使徒行傳 9:15; 歌羅西書 3:11"> 不論是希臘人和非希臘人<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「非希臘人」希臘文是「未開化的人」，指在希臘、羅馬文化影響圈之外的人。">a</a></sup>、智者和愚人，我對他們都有義務。</span>
<span className="v" id="v15" data-v="15" data-xref="羅馬書 15:20; 以賽亞書 6:8; 哥林多前書 9:17"> 所以，我也切望能將福音傳給你們在羅馬的人。</span>
<span className="v" id="v16" data-v="16" data-xref="馬可福音 8:38; 提摩太後書 1:8; 彼得前書 4:16"> 我不以福音為恥，因為這福音是上帝的大能，要拯救一切相信的人，先是猶太人，然後是希臘人。</span>
<span className="v" id="v17" data-v="17" data-xref="哈巴谷書 2:4; 加拉太書 3:11; 希伯來書 10:38"> 這福音顯明了上帝的義，這義始於信，終於信，正如聖經上說：「義人必靠信心而活。」<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="哈巴谷書2·4。">b</a></sup></span>
</div>
</div>

## 人類的罪惡

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="以弗所書 5:6; 提摩太前書 4:1–2; 羅馬書 1:32"> 上帝的烈怒從天上降下，要懲罰一切心中無神、行為不義的人，就是以不義壓制真理的人。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行傳 14:16–17; 詩篇 19:1–6; 羅馬書 1:20"> 有關上帝的事情，可以讓人類知道的都已經顯而易見，因為上帝已經向人類顯明了。</span>
<span className="v" id="v20" data-v="20" data-xref="羅馬書 1:19; 以賽亞書 40:26; 詩篇 19:1–6"> 自從創造天地以來，上帝永恆的大能和神性是明明可知的，雖然肉眼看不見，但透過受造之物就可以領悟，使人無法推諉。</span>
<span className="v" id="v21" data-v="21" data-xref="以弗所書 4:17–18; 列王紀下 17:15; 耶利米書 2:5"> 他們雖然明知有上帝，卻不把祂當作上帝來榮耀歸祂，也不感謝祂。他們的思想因此變得荒謬無用，無知的心也變得昏暗不明。</span>
<span className="v" id="v22" data-v="22" data-xref="哥林多前書 1:19–21; 羅馬書 11:25; 箴言 26:12"> 他們自以為聰明，其實愚不可及，</span>
<span className="v" id="v23" data-v="23" data-xref="詩篇 106:20; 耶利米書 2:11; 使徒行傳 17:29"> 以必朽的人、飛禽、走獸和爬蟲的形像來取代永恆上帝的榮耀。</span>
<span className="v" id="v24" data-v="24" data-xref="詩篇 81:11–12; 使徒行傳 7:42; 使徒行傳 14:16"> 因此，上帝任憑他們隨從內心的情慾行污穢的事，玷污彼此的身體。</span>
<span className="v" id="v25" data-v="25" data-xref="哈巴谷書 2:18; 耶利米書 13:25; 約翰一書 2:15–16"> 他們把上帝的真理當作謊言，祭拜、供奉受造之物，卻不敬拜、事奉造物主。主是永遠值得稱頌的。阿們！</span>
<span className="v" id="v26" data-v="26" data-xref="猶大書 1:7; 提摩太前書 1:10; 羅馬書 1:24"> 因此，上帝任憑他們放縱可恥的情慾。女人放棄正常的兩性關係，做出變態反常的事。</span>
<span className="v" id="v27" data-v="27" data-xref="利未記 20:13; 利未記 18:22; 羅馬書 1:23–24"> 同樣，男人也背棄了和女人正常的兩性關係，男與男彼此慾火焚燒，做出羞恥不堪的事。他們必因變態而遭受應得的報應。</span>
<span className="v" id="v28" data-v="28" data-xref="帖撒羅尼迦後書 2:10–12; 羅馬書 1:21; 提多書 1:16"> 既然他們故意不認識上帝，上帝就任憑他們心思敗壞，做不當做的事。</span>
<span className="v" id="v29" data-v="29" data-xref="哥林多後書 12:20; 箴言 16:28; 詩篇 41:7"> 他們心裡塞滿了各種不義、邪惡、貪婪、陰險、嫉妒、兇殺、紛爭、詭詐和惡毒，他們說長道短、</span>
<span className="v" id="v30" data-v="30" data-xref="提摩太後書 3:2; 猶大書 1:16; 彼得後書 2:18"> 造謠中傷、怨恨上帝、欺侮別人、心驕氣傲、自高自大、無惡不作、違背父母、</span>
<span className="v" id="v31" data-v="31" data-xref="提摩太後書 3:3; 箴言 18:2; 羅馬書 3:11"> 愚鈍無知、言而無信、無情無義、毫無憐憫。</span>
<span className="v" id="v32" data-v="32" data-xref="羅馬書 2:1–5; 羅馬書 1:21; 羅馬書 6:21"> 他們明明知道，按上帝公義的法則，做這些事的人該死，不但執迷不悟，還喜歡別人跟他們同流合污。</span>
</div>
</div>

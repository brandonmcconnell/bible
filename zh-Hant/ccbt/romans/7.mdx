## 婚姻關係的例子

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="羅馬書 6:14; 羅馬書 7:6; 羅馬書 6:3"> 弟兄姊妹，我現在對那些熟悉律法的人說：你們難道不知道律法只在人活著的時候管轄人嗎？</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 2:23–24; 哥林多前書 7:39; 哥林多前書 7:4"> 比方說，一個婦人結了婚，只要丈夫還在世，她就受律法的約束要與丈夫在一起。如果丈夫死了，她就脫離了與丈夫的婚姻關係。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 20:14; 馬太福音 5:32; 馬可福音 10:6–12"> 丈夫還活著的時候，她若與別的男人通姦，便被稱為淫婦。丈夫若死了，她就脫離了與丈夫的婚姻關係，即使改嫁，也不是淫婦。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="彼得前書 2:24; 加拉太書 5:22–23; 以賽亞書 54:5"> 我的弟兄姊妹，同樣，你們藉著基督的身體向著律法也死了，使你們可以歸於另一位，就是從死裡復活的基督，好為上帝結果子。</span>
<span className="v" id="v5" data-v="5" data-xref="以弗所書 2:3; 加拉太書 5:16–17; 加拉太書 5:24"> 從前我們受自己本性<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「本性」希臘文是「肉體」，以下皆用相同譯法。">a</a></sup>的控制，因律法而激發的罪惡慾望在我們體內發作，以致結出死亡的果子。</span>
<span className="v" id="v6" data-v="6" data-xref="加拉太書 3:23–25; 哥林多後書 3:6; 羅馬書 7:4"> 但現在，我們既然向著一度捆綁我們的律法死了，就脫離了律法的控制，能夠以聖靈所賜的新樣式，而不是按律法條文的舊樣式事奉上帝。</span>
</div>
</div>

## 律法使人知罪

<div className="bt">
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="羅馬書 3:20; 羅馬書 4:15; 哥林多前書 15:56"> 那麼，我們該怎麼說呢？律法是罪嗎？當然不是！要是沒有律法，我就不知道什麼是罪。律法若不說「不可貪心」<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="出埃及記20·17；申命記5·21。">b</a></sup>，我就不知道什麼是貪心。</span>
<span className="v" id="v8" data-v="8" data-xref="羅馬書 7:11; 哥林多前書 15:56; 羅馬書 4:15"> 然而，罪卻趁機利用誡命在我裡面生出各種貪念，因為沒有律法，罪是死的。</span>
<span className="v" id="v9" data-v="9" data-xref="加拉太書 3:10; 羅馬書 8:7; 雅各書 2:10–11"> 從前沒有律法的時候，我是活的，但誡命來了之後，罪就活了，而我卻死了。</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多後書 3:7; 羅馬書 10:5; 利未記 18:5"> 我發現那本來要使人活的誡命反而叫我死，</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 3:13; 羅馬書 7:8; 希伯來書 3:13"> 因為罪利用誡命趁機誘騙我，而且藉著誡命殺了我。</span>
<span className="v" id="v12" data-v="12" data-xref="提摩太前書 1:8; 詩篇 119:137; 詩篇 19:7–12"> 可見律法是聖潔的，誡命也是聖潔、公義、良善的。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="雅各書 1:13–15; 加拉太書 3:21; 羅馬書 8:3"> 既然如此，難道是良善的誡命叫我死嗎？當然不是！是罪藉著良善的誡命叫我死，好讓我們認識罪的真面目，並且罪藉著誡命更顯得邪惡至極！</span>
</div>
</div>

## 善惡相爭

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="列王紀上 21:25; 列王紀下 17:17; 羅馬書 7:18"> 我們知道律法是屬靈的，我卻屬乎肉體，已經賣給罪做奴隸了。</span>
<span className="v" id="v15" data-v="15" data-xref="加拉太書 5:17; 羅馬書 7:19–20; 傳道書 7:20"> 我不明白自己的所作所為，因為我想做的，我不去做；而我憎恨的，我偏偏去做！</span>
<span className="v" id="v16" data-v="16" data-xref="羅馬書 7:12; 羅馬書 7:14; 提摩太前書 1:8"> 如果我做我不想做的，我就承認律法是好的。</span>
<span className="v" id="v17" data-v="17" data-xref="羅馬書 7:20; 腓立比書 3:8–9; 羅馬書 7:18"> 其實不再是我在做，而是住在我裡面的罪在做。</span>
<span className="v" id="v18" data-v="18" data-xref="約翰福音 3:6; 詩篇 51:5; 加拉太書 5:17"> 我也知道，在我裡面，就是我的本性裡面毫無良善，我有行善的心願，卻沒有行善的力量。</span>
<span className="v" id="v19" data-v="19" data-xref="羅馬書 7:15"> 我想行善，卻不去行；我不想作惡，反倒去作。</span>
<span className="v" id="v20" data-v="20" data-xref="羅馬書 7:17"> 如果我做我不想做的，就不再是我在做，而是住在我裡面的罪在做。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="羅馬書 6:14; 羅馬書 7:23; 詩篇 119:133"> 因此，我發現一個律：我想行善的時候，惡就不放過我。</span>
<span className="v" id="v22" data-v="22" data-xref="詩篇 1:2; 詩篇 40:8; 詩篇 119:35"> 按著我裡面的意思<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="「裡面的意思」希臘文是「裡面的人」。">c</a></sup>，我喜愛上帝的律。</span>
<span className="v" id="v23" data-v="23" data-xref="加拉太書 5:17; 雅各書 4:1; 羅馬書 8:2"> 然而，我發覺在我身體內另有一個律和我心中的律作戰，將我俘虜，使我服從身體內犯罪的律。</span>
<span className="v" id="v24" data-v="24" data-xref="羅馬書 6:6; 提摩太後書 4:18; 提多書 2:14"> 我真是苦啊！誰能救我脫離這個被死亡控制的身體呢？</span>
<span className="v" id="v25" data-v="25" data-xref="加拉太書 5:17–24; 歌羅西書 3:17; 哥林多後書 12:9–10"> 感謝上帝，祂藉著我們的主耶穌基督救了我！這樣看來，我的內心服從上帝的律法，但我的本性卻服從犯罪的律。</span>
</div>
</div>

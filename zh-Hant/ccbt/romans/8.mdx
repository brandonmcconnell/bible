## 隨從聖靈而活

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="約翰福音 3:18–19; 哥林多後書 5:17; 加拉太書 3:13"> 因此，如今那些在基督耶穌裡的人不被定罪，</span>
<span className="v" id="v2" data-v="2" data-xref="羅馬書 6:14; 哥林多後書 3:17; 羅馬書 6:18"> 因為賜人生命之聖靈的律，已經在基督耶穌裡使我獲得自由，脫離了罪與死的律。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行傳 13:39; 加拉太書 4:4–5; 希伯來書 7:18–19"> 律法因為人性軟弱而無法成就的事，上帝親自成就了。祂差遣自己的兒子成為和罪人一樣有血有肉的人，作了贖罪祭，廢掉了罪的權勢，</span>
<span className="v" id="v4" data-v="4" data-xref="加拉太書 5:16; 加拉太書 5:22–25; 歌羅西書 1:22"> 使律法公義的要求實現在我們這些不隨從本性、只隨從聖靈而活的人身上。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="哥林多前書 2:14; 加拉太書 5:19–25; 約翰福音 3:6"> 隨從本性的人思想本性的事，隨從聖靈的人思想聖靈的事。</span>
<span className="v" id="v6" data-v="6" data-xref="加拉太書 6:8; 羅馬書 8:7; 羅馬書 8:13"> 受本性支配的思想會導致死亡，受聖靈支配的思想會帶來生命和平安。</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多前書 2:14; 約翰一書 2:15–16; 雅各書 4:4"> 因為受本性支配的思想與上帝為敵，不服從上帝的律法，也無力服從。</span>
<span className="v" id="v8" data-v="8" data-xref="約翰福音 3:5–6; 希伯來書 11:5–6; 羅馬書 8:9"> 所以受本性控制的人不能讓上帝喜悅。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="加拉太書 4:6; 哥林多前書 3:16; 提摩太後書 1:14"> 但如果上帝的靈住在你們裡面，你們就不再受本性控制，而是受聖靈管理。人若沒有基督的靈，就不屬於基督。</span>
<span className="v" id="v10" data-v="10" data-xref="以弗所書 3:17; 加拉太書 2:20; 哥林多後書 5:21"> 如果基督在你們裡面，你們的身體雖然因罪而死亡，靈魂卻因義而活著<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「靈魂卻因義而活著」或譯「聖靈必因義而賜下生命」。">a</a></sup>。</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多後書 4:14; 羅馬書 6:4–5; 哥林多後書 4:11"> 如果使耶穌復活之上帝的靈住在你們裡面，叫基督耶穌從死裡復活的上帝，也必藉著住在你們裡面的聖靈，使你們終有一死的身體活過來。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="羅馬書 6:2–15; 哥林多前書 6:19–20; 彼得前書 4:2–3"> 弟兄姊妹，這樣看來，我們不必隨從本性活著。</span>
<span className="v" id="v13" data-v="13" data-xref="加拉太書 6:8; 彼得前書 2:11; 哥林多前書 9:27"> 你們若隨從本性活著，必定死亡；若靠著聖靈除去身體的惡行，就必活著。</span>
<span className="v" id="v14" data-v="14" data-xref="加拉太書 5:18; 約翰福音 1:12; 加拉太書 3:26"> 因為凡有上帝的靈引導的人都是上帝的兒女。</span>
<span className="v" id="v15" data-v="15" data-xref="加拉太書 4:5–7; 提摩太後書 1:7; 哥林多前書 2:12"> 你們接受的聖靈不是使你們做奴隸，仍舊害怕，而是使你們做兒子，可以稱上帝為「阿爸，父親」。</span>
<span className="v" id="v16" data-v="16" data-xref="約翰一書 4:13; 哥林多後書 1:22; 哥林多後書 5:5"> 聖靈親自與我們的心一同見證我們是上帝的兒女。</span>
<span className="v" id="v17" data-v="17" data-xref="加拉太書 4:7; 加拉太書 3:29; 以弗所書 3:6"> 我們既然是兒女，就是繼承人，是上帝的繼承人，並且與基督同作繼承人。所以，我們現在若和基督一同受苦，將來也必和祂一同得榮耀。</span>
</div>
</div>

## 將來的榮耀

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="哥林多後書 4:17–18; 彼得前書 4:13; 彼得前書 1:5–7"> 我認為，與將來要顯給我們的榮耀相比，現在所受的痛苦簡直微不足道。</span>
<span className="v" id="v19" data-v="19" data-xref="瑪拉基書 3:17–18; 羅馬書 8:23; 約翰一書 3:2"> 受造之物正熱切等候上帝眾子的顯現，</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 3:17–19; 創世記 5:29; 羅馬書 8:22"> 因為受造之物處在虛空之下並非出於情願，而是出於上帝的旨意。</span>
<span className="v" id="v21" data-v="21" data-xref="啟示錄 22:3–5; 使徒行傳 3:21; 彼得後書 3:13"> 不過，受造之物仍然盼望脫離衰亡的束縛，享受上帝兒女榮耀的自由。</span>
<span className="v" id="v22" data-v="22" data-xref="耶利米書 12:4; 耶利米書 12:11; 約翰福音 16:21"> 我們知道一切受造之物至今都在呻吟，如同經歷分娩之痛。</span>
<span className="v" id="v23" data-v="23" data-xref="腓立比書 3:20–21; 哥林多後書 5:2–5; 希伯來書 9:28"> 不但如此，就是我們這些首先得到聖靈的人也在心裡歎息，熱切等候得到兒子的名分<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="「兒子的名分」指被收養為義子，可以享受和親生兒子一樣的權利。">b</a></sup>，就是我們的身體得到救贖。</span>
<span className="v" id="v24" data-v="24" data-xref="哥林多後書 5:7; 希伯來書 11:1; 哥林多後書 4:18"> 我們得救的人有這個盼望。不過，看得見的盼望不算盼望，誰會盼望已經看見的呢？</span>
<span className="v" id="v25" data-v="25" data-xref="羅馬書 12:12; 希伯來書 10:36; 詩篇 27:14"> 但我們若盼望那尚未看見的，就會忍耐等候。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="馬太福音 10:20; 以弗所書 6:18; 加拉太書 4:6"> 況且，我們軟弱的時候，有聖靈幫助我們。我們不知道該怎樣禱告，但聖靈親自用說不出來的歎息替我們祈禱。</span>
<span className="v" id="v27" data-v="27" data-xref="耶利米書 17:10; 約翰一書 5:14–15; 以弗所書 2:18"> 洞悉人心的上帝知道聖靈的意思，因為聖靈是照著上帝的旨意替聖徒祈禱。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="彼得前書 5:10; 雅各書 1:12; 創世記 50:20"> 我們知道，上帝使萬事互相效力<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="「上帝使萬事互相效力」或譯「萬事都互相效力」。">c</a></sup>，使那些愛上帝的人，就是上帝按自己的旨意呼召的人得益處。</span>
<span className="v" id="v29" data-v="29" data-xref="以弗所書 1:4–5; 耶利米書 1:5; 以弗所書 1:11"> 因為上帝預先知道誰是屬祂的人，並預定這些人要被塑造成祂兒子的形像，使祂的兒子在許多弟兄中成為長子。</span>
<span className="v" id="v30" data-v="30" data-xref="啟示錄 17:14; 羅馬書 8:28; 以弗所書 1:11"> 祂所預定的人，祂也呼召他們；祂所呼召的人，祂也稱他們為義人；祂稱之為義人的，祂也使他們得榮耀。</span>
</div>
</div>

## 上帝的愛

<div className="bt">
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="詩篇 118:6; 耶利米書 1:19; 詩篇 56:11"> 對於這些事，我們還可以說什麼呢？上帝若幫助我們，誰能與我們對抗？</span>
<span className="v" id="v32" data-v="32" data-xref="約翰福音 3:16; 羅馬書 8:28; 詩篇 84:11"> 上帝既然連自己的兒子也不顧惜，讓祂為我們犧牲，豈不也把萬物和祂一同白白地賜給我們嗎？</span>
<span className="v" id="v33" data-v="33" data-xref="啟示錄 12:10–11; 以賽亞書 50:8–9; 以賽亞書 54:17"> 誰能指控上帝揀選的人呢？是上帝稱我們為義人。</span>
<span className="v" id="v34" data-v="34" data-xref="希伯來書 7:25; 羅馬書 8:27; 希伯來書 9:24"> 誰能定我們有罪呢？基督耶穌已經替我們死了，而且從死裡復活了，如今在上帝的右邊正替我們祈禱。</span>
<span className="v" id="v35" data-v="35" data-xref="約翰福音 10:28; 詩篇 103:17; 約翰福音 16:33"> 誰能使我們與基督的愛分離呢？難道是患難嗎？困苦嗎？迫害嗎？饑餓嗎？赤身露體嗎？危險嗎？刀劍嗎？</span>
<span className="v" id="v36" data-v="36" data-xref="詩篇 44:22; 以賽亞書 53:7; 哥林多前書 15:30"> 正如聖經上說：「為了你，我們終日出生入死，被視為待宰的羊。」<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="詩篇44·22。">d</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="哥林多前書 15:57; 約翰一書 4:4; 哥林多後書 2:14"> 然而，靠著愛我們的主，我們在這一切事上已經得勝有餘了。</span>
<span className="v" id="v38" data-v="38" data-xref="約翰福音 10:28; 羅馬書 14:8; 提摩太後書 1:12"> 因為我深信無論是死、是生，是天使、是鬼魔，是現在的事、是將來的事，</span>
<span className="v" id="v39" data-v="39" data-xref="約翰福音 10:28–30; 羅馬書 8:35; 羅馬書 5:8"> 是高天之上的、是大地深處的或是其他受造之物，都不能使我們與上帝在主基督耶穌裡賜下的愛分離。</span>
</div>
</div>

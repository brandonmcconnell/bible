## 上帝的選民

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="提摩太前書 2:7; 羅馬書 1:9; 加拉太書 1:20"> 我在基督裡說真話，絕無謊言。我被聖靈感動的良心可以作證，</span>
<span className="v" id="v2" data-v="2" data-xref="腓立比書 3:18; 詩篇 119:136; 耶利米書 13:17"> 我心裡極為憂愁，痛苦不堪！</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 32:32; 以斯帖記 8:6; 羅馬書 11:14"> 為了我的弟兄——我的同胞以色列人，即使我自己被咒詛、與基督隔絕，我也願意！</span>
<span className="v" id="v4" data-v="4" data-xref="以弗所書 2:12; 詩篇 147:19; 羅馬書 9:6"> 身為以色列人，他們擁有上帝兒子的名分、上帝的榮耀、諸約、律法、敬拜禮儀和各種應許。</span>
<span className="v" id="v5" data-v="5" data-xref="約翰福音 10:30; 約翰福音 1:1–3; 歌羅西書 1:16–19"> 蒙揀選的族長是他們的先祖，基督降世為人也是做以色列人。祂是至大至尊，永遠當受稱頌的上帝。阿們！</span>
<span className="v" id="v6" data-v="6" data-xref="羅馬書 2:28–29; 加拉太書 6:16; 羅馬書 11:1–2"> 當然，這並不表示上帝的話落了空，因為從以色列生的，並不都是以色列人，</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 21:12; 希伯來書 11:18; 約翰福音 8:37–39"> 亞伯拉罕的後裔並不都是亞伯拉罕的兒女，聖經上說：「以撒生的才可算為你的後裔。」<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="創世記21·12。">a</a></sup></span>
<span className="v" id="v8" data-v="8" data-xref="約翰福音 1:13; 羅馬書 4:11–16; 加拉太書 3:26–29"> 這話的意思是：憑血氣所生的兒女並不是上帝的兒女，只有憑應許所生的才算是後裔。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 18:10; 創世記 18:14; 創世記 17:21"> 因為上帝曾這樣應許他：「明年這時候，我會再來，撒拉必生一個兒子。」<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="創世記18·10、14。">b</a></sup></span>
<span className="v" id="v10" data-v="10" data-xref="創世記 25:21–23; 路加福音 16:26; 羅馬書 5:11"> 後來，利百加和我們的先祖以撒結婚，懷了雙胞胎。</span>
<span className="v" id="v11" data-v="11" data-xref="提摩太後書 1:9; 以弗所書 1:4–5; 彼得後書 1:10"> 在這對孩子還未出生，還沒有顯出誰善誰惡之時，上帝為了顯明自己揀選人並不是按人的行為，而是按祂自己的旨意，</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 25:22–23; 撒母耳記下 8:14; 列王紀上 22:47"> 便對利百加說：「將來大的要服侍小的。」<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="創世記25·23。">c</a></sup></span>
<span className="v" id="v13" data-v="13" data-xref="瑪拉基書 1:2–3; 申命記 21:15; 創世記 29:33"> 正如聖經上說：「我愛雅各，厭惡以掃。」<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="瑪拉基書1·2、3。">d</a></sup></span>
<span className="v" id="v14" data-v="14" data-xref="歷代志下 19:7; 詩篇 145:17; 申命記 32:4"> 這樣看來，我們該怎麼說呢？難道上帝不公平嗎？當然不是！</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及記 33:19; 羅馬書 9:16; 彌迦書 7:18"> 祂曾對摩西說：<br /><span className="pl pl-1">「我要憐憫誰就憐憫誰，</span><br /><span className="pl pl-1">要恩待誰就恩待誰。」</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="出埃及記33·19。">e</a></sup></span>
<span className="v" id="v16" data-v="16" data-xref="以弗所書 2:8; 馬太福音 11:25–26; 彼得前書 2:9–10"> 可見這並不在於人的意志和努力，而在於祂的憐憫。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及記 9:16; 箴言 16:4; 出埃及記 14:17–18"> 聖經記載著上帝對法老說的話：「我使你興起是為了在你身上彰顯我的權能，使我的名傳遍天下。」<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="出埃及記9·16。">f</a></sup></span>
<span className="v" id="v18" data-v="18" data-xref="約書亞記 11:20; 出埃及記 4:21; 羅馬書 9:15–16"> 總之，上帝要憐憫誰，就憐憫誰；要叫誰頑固，就叫誰頑固。</span>
</div>
</div>

## 上帝的烈怒和憐憫

<div className="bt">
<div className="bp poetry">
<span className="v" id="v19" data-v="19" data-xref="但以理書 4:35; 歷代志下 20:6; 哥林多前書 15:12"> 這樣，你肯定會對我說：「為什麼上帝還指責人呢？誰能抗拒祂的旨意呢？」</span>
<span className="v" id="v20" data-v="20" data-xref="以賽亞書 29:16; 以賽亞書 45:9–11; 以賽亞書 64:8"> 你這個人啊！你是誰啊？竟敢頂撞上帝！受造之物怎能對造物的說：「你為什麼把我造成這樣？」<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="以賽亞書29·16；45·9。">g</a></sup></span>
<span className="v" id="v21" data-v="21" data-xref="以賽亞書 64:8; 箴言 16:4; 提摩太後書 2:20–21"> 陶匠難道不可從一團泥中拿一部分造貴重的器皿，又拿一部分造平凡的器皿嗎？</span>
<span className="v" id="v22" data-v="22" data-xref="箴言 16:4; 猶大書 1:4; 羅馬書 9:21"> 倘若上帝想要顯示祂的烈怒和權能，就儘量容忍祂預備要發烈怒來毀滅的器皿，</span>
<span className="v" id="v23" data-v="23" data-xref="羅馬書 2:4; 彼得前書 1:2–5; 歌羅西書 1:27"> 以便在祂預備施憐憫、賜榮耀的器皿上彰顯祂豐盛的榮耀，又有何不可？</span>
<span className="v" id="v24" data-v="24" data-xref="歌羅西書 3:11; 使徒行傳 13:47–48; 以弗所書 3:6–8"> 那些蒙祂憐憫的器皿就是我們這些從猶太人和外族人中被上帝呼召的人。</span>
<span className="v" id="v25" data-v="25" data-xref="何西阿書 2:23; 彼得前書 2:10; 約翰福音 16:27"> 正如上帝在《何西阿書》上說：<br /><span className="pl pl-1">「本來不是我子民的，</span><br /><span className="pl pl-1">我要稱他們為『我的子民』</span><sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="何西阿書2·23。">h</a></sup><br /><span className="pl pl-1">；</span><br /><span className="pl pl-1">本來不是我所愛的，</span><br /><span className="pl pl-1">我要稱他們為『我所愛的』。</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="何西阿書 1:9–10; 約翰一書 3:1–3; 加拉太書 3:26"> <span className="pl pl-1">從前我在什麼地方對他們說，</span><br /><span className="pl pl-1">『你們不是我的子民。』</span><br /><span className="pl pl-1">將來也要在那裡對他們說，</span><br /><span className="pl pl-1">『你們是永活上帝的兒女。』」</span><sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="何西阿書1·10。">i</a></sup></span>
<span className="v" id="v27" data-v="27" data-xref="以賽亞書 10:20–23; 羅馬書 11:4–6; 以賽亞書 1:9"> 關於以色列人，以賽亞先知曾疾呼：<br /><span className="pl pl-1">「以色列人雖多如海沙，</span><br /><span className="pl pl-1">但得救的只是剩餘的人，</span><br /></span>
<span className="v" id="v28" data-v="28" data-xref="以賽亞書 10:23; 啟示錄 19:11; 使徒行傳 17:31"> <span className="pl pl-1">因為上帝要在世上迅速、</span><br /><span className="pl pl-1">徹底地執行祂的判決。」</span><sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="以賽亞書10·22、23。">j</a></sup></span>
<span className="v" id="v29" data-v="29" data-xref="以賽亞書 1:9; 以賽亞書 13:19; 阿摩司書 4:11"> 正如以賽亞先前所言：<br /><span className="pl pl-1">「若不是萬軍之主給我們存留後裔，</span><br /><span className="pl pl-1">我們早就像所多瑪和蛾摩拉一樣滅亡了。」</span><sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="以賽亞書1·9。">k</a></sup></span>
</div>
</div>

## 以色列人和福音

<div className="bt">
<div className="bp poetry">
<span className="v" id="v30" data-v="30" data-xref="腓立比書 3:9; 希伯來書 11:7; 加拉太書 2:16"> 這樣看來，我們該怎麼說呢？本來不追求義的外族人卻得到了義，就是因信而得的義。</span>
<span className="v" id="v31" data-v="31" data-xref="羅馬書 11:7; 羅馬書 3:20; 雅各書 2:10–11"> 以色列人靠遵行律法追求義，卻徒勞無功。</span>
<span className="v" id="v32" data-v="32" data-xref="哥林多前書 1:23; 彼得前書 2:8; 路加福音 7:23"> 為什麼會這樣呢？因為他們不憑信心、只靠自己的行為去追求義，結果被那塊絆腳石絆倒了，</span>
<span className="v" id="v33" data-v="33" data-xref="以賽亞書 28:16; 以賽亞書 8:14–15; 羅馬書 10:11"> 正如聖經上說：<br /><span className="pl pl-1">「看啊！我在錫安放了一塊絆腳石，</span><br /><span className="pl pl-1">一塊使人跌倒的磐石。</span><br /><span className="pl pl-1">但信靠祂的人必不會蒙羞。」</span><sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="以賽亞書8·14；28·16。">l</a></sup></span>
</div>

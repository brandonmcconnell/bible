## 上帝不放棄以色列人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多後書 11:22; 撒母耳記上 12:22; 腓立比書 3:5"> 這樣，我要問，難道上帝放棄了祂的子民嗎？當然沒有！因我自己也是以色列人，是亞伯拉罕的後裔，屬於便雅憫支派。</span>
<span className="v" id="v2" data-v="2" data-xref="詩篇 94:14; 羅馬書 8:29–30; 出埃及記 32:1"> 上帝並沒有放棄祂預先揀選的子民。你們不知道聖經上有關以利亞先知的記載嗎？他在上帝面前控告以色列人，說：</span>
<span className="v" id="v3" data-v="3" data-xref="列王紀上 19:10–18; 列王紀上 18:13; 尼希米記 9:26"> 「主啊！他們殘殺你的先知，拆毀你的祭壇，只剩下我一個人，他們還要殺我。」<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="列王紀上19·10、14。">a</a></sup></span>
<span className="v" id="v4" data-v="4" data-xref="列王紀上 19:18; 民數記 25:3; 西番雅書 1:4"> 上帝怎樣回答呢？祂說：「我為自己留下七千人，他們都未曾跪拜巴力。」<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="列王紀上19·18。">b</a></sup></span>
</div>
<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="羅馬書 9:27; 以弗所書 1:5–6; 羅馬書 9:11"> 現在的情況也是一樣，上帝按照揀選的恩典留下了少數人。</span>
<span className="v" id="v6" data-v="6" data-xref="加拉太書 2:21; 羅馬書 4:4–5; 提摩太後書 1:9"> 既然說是出於恩典，就不再基於行為，不然恩典就不再是恩典了。</span>
<span className="v" id="v7" data-v="7" data-xref="羅馬書 9:18; 羅馬書 11:5; 哥林多後書 4:4"> 這該怎麼說呢？以色列人努力追求，卻一無所得，只有蒙揀選的人得到了，其他人都變得頑固不化。</span>
<span className="v" id="v8" data-v="8" data-xref="申命記 29:4; 以賽亞書 29:10; 以西結書 12:2"> 正如聖經上說：<br /><span className="pl pl-1">「上帝使他們至今心智昏迷，</span><br /><span className="pl pl-1">眼睛看不見，耳朵聽不到。」</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="申命記29·4；以賽亞書29·10。">c</a></sup></span>
</div>
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="詩篇 69:22–23; 路加福音 12:20; 詩篇 28:4"> 大衛也說：<br /><span className="pl pl-1">「願他們的宴席變為他們的網羅、</span><br /><span className="pl pl-1">陷阱、絆腳石和報應；</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 69:23; 申命記 28:64–68; 彼得後書 2:4"> <span className="pl pl-1">願他們眼目昏暗，</span><br /><span className="pl pl-1">無法看見，</span><br /><span className="pl pl-1">永遠彎腰駝背。」</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="詩篇69·22、23。">d</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="使徒行傳 13:46–48; 羅馬書 11:31; 羅馬書 10:19"> 那麼，我再問，以色列人一失足就再也爬不起來了嗎？當然不是！恰好相反，因為他們的過犯，救恩臨到了外族人，好使他們心生嫉妒。</span>
<span className="v" id="v12" data-v="12" data-xref="羅馬書 11:25; 歌羅西書 1:27; 羅馬書 11:15"> 如果他們的過犯給世界帶來富足，他們的失敗給外族人帶來富足，那麼，他們完全恢復時又將帶來怎樣的祝福呢！</span>
</div>
</div>

## 外族人得救

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="使徒行傳 9:15; 提摩太後書 1:11–12; 以弗所書 3:8"> 現在我有話要對你們外族人說。因為我是外族人的使徒，我尊重自己的職分，</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多前書 7:16; 提摩太前書 4:16; 羅馬書 9:3"> 希望使我的骨肉同胞心生嫉妒，從而拯救他們當中的一些人。</span>
<span className="v" id="v15" data-v="15" data-xref="以弗所書 1:10; 羅馬書 5:10–11; 歌羅西書 1:20–21"> 如果他們的被棄意味著人類與上帝和好，那麼，他們被接納時豈不意味著死而復生嗎？</span>
<span className="v" id="v16" data-v="16" data-xref="以西結書 44:30; 雅各書 1:18; 箴言 3:9"> 首先用來獻祭的那部分麵團如果聖潔，整團麵也聖潔；樹根如果聖潔，樹枝也聖潔。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="以弗所書 2:11–13; 以弗所書 3:6; 馬太福音 21:43"> 如果橄欖樹上有些枝子被折下來，你這野橄欖枝被接上去，得以汲取橄欖樹根供應的汁漿，</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前書 10:12; 羅馬書 11:20; 以弗所書 2:19–20"> 你就不可向折下來的枝子誇口。你若誇口，就該知道：不是你托住樹根，而是樹根托住你。</span>
<span className="v" id="v19" data-v="19" data-xref="羅馬書 11:17; 羅馬書 11:11–12; 羅馬書 11:23–24"> 你也許會說：「原來的枝子被折下來，是為了把我接上去。」</span>
<span className="v" id="v20" data-v="20" data-xref="羅馬書 12:16; 哥林多後書 1:24; 哥林多前書 10:12"> 不錯，他們因為不信才被折下來，你因為信才被接上去，但不要自高，要心存敬畏。</span>
<span className="v" id="v21" data-v="21" data-xref="彼得後書 2:4–9; 耶利米書 25:29; 耶利米書 49:12"> 上帝既然沒有寬容原來的枝子，也不會寬容你。</span>
<span className="v" id="v22" data-v="22" data-xref="希伯來書 3:14; 希伯來書 3:6; 哥林多前書 15:2"> 可見，上帝既慈愛又嚴厲。祂對墮落的人是嚴厲的，但只要你一直活在祂的愛中，祂會以慈愛對待你，不然你也會被砍下來。</span>
<span className="v" id="v23" data-v="23" data-xref="哥林多後書 3:16; 撒迦利亞書 12:10; 馬太福音 23:39"> 況且，以色列人如果不再頑固不信，必重新被接上去，因為上帝能把他們重新接上。</span>
<span className="v" id="v24" data-v="24" data-xref="羅馬書 11:17–18; 羅馬書 11:30"> 你這從野生的橄欖樹上砍下來的枝子，尚且可以違反自然，被接到好橄欖樹上，何況原來的枝子被接回到原來的樹上呢？</span>
</div>
</div>

## 全以色列都要得救

<div className="bt">
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="路加福音 21:24; 哥林多後書 3:14–16; 羅馬書 16:25"> 弟兄姊妹，我不願意你們對以下這奧祕一無所知，免得你們自以為聰明。這奧祕就是：雖然有些以色列人的心剛硬，但等到外族人得救的數目滿了以後，</span>
<span className="v" id="v26" data-v="26" data-xref="以賽亞書 59:20; 耶利米書 31:31–37; 詩篇 14:7"> 全以色列都要得救。正如聖經上說：「救主必從錫安出來，祂將除去雅各子孫的罪惡。</span>
<span className="v" id="v27" data-v="27" data-xref="耶利米書 31:31–34; 以賽亞書 59:21; 以西結書 36:25–29"> 這是我與他們所立的約，那時我要除去他們的罪。」<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="以賽亞書59·20、21；27·9；耶利米書31·33、34。">e</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="申命記 10:15; 申命記 7:7–8; 馬太福音 21:43"> 就福音而論，他們為你們的緣故而成為上帝的仇敵；就上帝的揀選而論，他們因祖先的緣故仍被上帝所愛。</span>
<span className="v" id="v29" data-v="29" data-xref="希伯來書 7:21; 民數記 23:19; 瑪拉基書 3:6"> 因為上帝的恩賜和呼召絕不會收回。</span>
<span className="v" id="v30" data-v="30" data-xref="歌羅西書 3:7; 以弗所書 2:1–2; 哥林多前書 7:25"> 你們從前不順服上帝，然而因為他們的不順服，你們現在反蒙了憐憫。</span>
<span className="v" id="v31" data-v="31" data-xref="羅馬書 11:15; 羅馬書 10:16; 羅馬書 11:25"> 同樣，他們現在不順服，是為了通過你們所蒙的憐憫，使他們現在也蒙憐憫。</span>
<span className="v" id="v32" data-v="32" data-xref="加拉太書 3:22; 羅馬書 3:9; 提摩太前書 2:4–6"> 因為上帝把世人都歸在不順服之列，是為了要憐憫世人。</span>
</div>
</div>

## 頌讚上帝

<div className="bt">
<div className="bp poetry">
<span className="v" id="v33" data-v="33" data-xref="約伯記 5:9; 約伯記 11:7–9; 詩篇 92:5"> <span className="pl pl-1">啊，上帝的智慧和知識多麼博大精深！</span><br /><span className="pl pl-1">祂的判斷多麼難測！</span><br /><span className="pl pl-1">祂的蹤跡多麼難尋！</span><br /></span>
<span className="v" id="v34" data-v="34" data-xref="以賽亞書 40:13; 哥林多前書 2:16; 約伯記 15:8"> <span className="pl pl-1">誰曾知道主的心意？</span><br /><span className="pl pl-1">誰曾做過祂的謀士？</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="以賽亞書40·13。">f</a></sup><br /></span>
<span className="v" id="v35" data-v="35" data-xref="約伯記 41:11; 約伯記 35:7; 哥林多前書 4:7"> <span className="pl pl-1">誰給過祂什麼，</span><br /><span className="pl pl-1">要祂償還呢？</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="約伯記41·11。">g</a></sup><br /></span>
<span className="v" id="v36" data-v="36" data-xref="歌羅西書 1:15–17; 哥林多前書 8:6; 希伯來書 2:10"> <span className="pl pl-1">因為萬物都源於祂，</span><br /><span className="pl pl-1">倚靠祂，歸於祂。</span><br /><span className="pl pl-1">願榮耀歸給祂，</span><br /><span className="pl pl-1">直到永遠。阿們！</span></span>
</div>

## 與上帝和好

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以賽亞書 32:17; 羅馬書 15:13; 約翰福音 16:33"> 我們既然因信被稱為義人，就藉著我們的主耶穌基督與上帝和好了。</span>
<span className="v" id="v2" data-v="2" data-xref="以弗所書 2:18; 以弗所書 3:12; 羅馬書 12:12"> 我們又靠著祂，藉著信進入現在所站的這恩典中，歡歡喜喜地盼望分享上帝的榮耀。</span>
<span className="v" id="v3" data-v="3" data-xref="雅各書 1:2–3; 雅各書 1:12; 彼得前書 3:14"> 不但如此，我們在苦難中也歡喜，因為知道苦難使人生忍耐，</span>
<span className="v" id="v4" data-v="4" data-xref="彼得前書 5:10; 雅各書 1:12; 哥林多後書 4:8–12"> 忍耐生品格，品格生盼望。</span>
<span className="v" id="v5" data-v="5" data-xref="加拉太書 4:6; 以弗所書 3:16–19; 腓立比書 1:20"> 這種盼望不會落空，因為上帝的愛藉著所賜給我們的聖靈已傾注在我們心中。</span>
<span className="v" id="v6" data-v="6" data-xref="以弗所書 2:1–5; 羅馬書 5:8; 歌羅西書 2:13"> 當我們還軟弱無助的時候，基督就在所定的日期為罪人死了。</span>
<span className="v" id="v7" data-v="7" data-xref="約翰福音 15:13; 約翰一書 3:16; 羅馬書 16:4"> 為義人死，是罕見的；為好人死，也許有敢做的；</span>
<span className="v" id="v8" data-v="8" data-xref="約翰福音 15:13; 約翰福音 3:16; 羅馬書 5:6"> 但基督卻在我們還做罪人的時候為我們死！上帝的愛就這樣顯明了。</span>
<span className="v" id="v9" data-v="9" data-xref="帖撒羅尼迦前書 1:10; 羅馬書 8:1; 以弗所書 2:13"> 現在，我們既然因基督所流的血被稱為義人，豈不更要靠著祂免受上帝的烈怒嗎？</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多後書 5:18–19; 哥林多後書 4:10–11; 羅馬書 8:32"> 我們如果還與上帝為敵的時候，尚且可以藉著祂兒子的死亡與祂和好，和好之後豈不更要藉著祂兒子的生命得到拯救嗎？</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多後書 5:18–19; 羅馬書 5:10; 以賽亞書 61:10"> 不但如此，我們藉著主耶穌基督與上帝和好之後，還要藉著祂以上帝為樂。</span>
</div>
</div>

## 亞當與基督

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="哥林多前書 15:21–22; 羅馬書 5:19; 羅馬書 6:23"> 因此，罪怎樣從一個人進入世界並帶來死亡，死亡也怎樣臨到世人，因為世人都犯了罪。</span>
<span className="v" id="v13" data-v="13" data-xref="羅馬書 4:15; 哥林多前書 15:56; 約翰一書 3:4"> 沒有律法之前，罪已經在世上；但沒有律法，罪也不算為罪。</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多前書 15:45; 羅馬書 5:17; 希伯來書 9:27"> 其實，從亞當到摩西的時代，死亡一直轄制著人類，甚至連那些不與亞當犯同樣罪的人也不能倖免。亞當是將要來的那位的預表。</span>
<span className="v" id="v15" data-v="15" data-xref="羅馬書 6:23; 以弗所書 2:8; 羅馬書 5:12"> 然而，上帝的洪恩遠超過亞當的過犯。若因這一人的過犯，眾人都要死亡，那麼上帝的恩典，也就是通過耶穌基督一人所賜的恩典，豈不要更豐富地臨到眾人嗎？</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行傳 13:38–39; 以賽亞書 1:18; 以賽亞書 44:22"> 再者，上帝的恩賜不同於一人犯罪的後果。因為隨一人犯罪而來的審判使人被定罪，隨累累過犯而來的恩賜使人被稱為義人。</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多前書 15:21–22; 哥林多前書 15:49; 羅馬書 5:12"> 若因一人的過犯，死亡就藉著這人作了王，那麼接受上帝洪恩又得到祂所賜之義的人，豈不更要藉著耶穌基督一人在生命中作王嗎？</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前書 15:22; 羅馬書 5:12; 羅馬書 5:15"> 如此說來，因為一次過犯，眾人都被定罪；照樣，因為一次義行，眾人都被稱為義人，得到生命。</span>
<span className="v" id="v19" data-v="19" data-xref="羅馬書 5:18; 哥林多後書 5:21; 腓立比書 2:8"> 因為一人的悖逆，眾人成為罪人；照樣，因為一人的順服，眾人將被稱為義人。</span>
<span className="v" id="v20" data-v="20" data-xref="羅馬書 6:1; 提多書 3:3–7; 羅馬書 6:14"> 律法的頒佈，使過犯更多地顯出來，只是哪裡的罪越多，哪裡的恩典就越豐富。</span>
<span className="v" id="v21" data-v="21" data-xref="提多書 2:11; 羅馬書 5:14; 羅馬書 8:10"> 所以，罪怎樣掌權帶來死亡<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「罪怎樣掌權帶來死亡」或譯「罪怎樣藉著死亡掌權」。">a</a></sup>，恩典也照樣藉著義掌權，為要藉著我們主耶穌基督帶來永生。</span>
</div>

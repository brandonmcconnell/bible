## 介紹菲比

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行傳 18:18; 彼得前書 1:22–23; 提摩太前書 5:9–10"> 現在我給你們推薦我們的姊妹菲比，她是堅革哩教會的女執事。</span>
<span className="v" id="v2" data-v="2" data-xref="腓立比書 2:29; 腓立比書 1:27; 馬太福音 10:40–42"> 請你們在主裡照著做聖徒的本分接待她。無論她有什麼需要，請你們幫助她，因為她幫助過許多人，也幫助過我。</span>

## 問候聖徒

<div className="bt">
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="哥林多前書 16:19; 提摩太後書 4:19; 使徒行傳 18:26"> 請代我問候百基拉和亞居拉夫婦，他們是我在基督耶穌裡的同工，</span>
<span className="v" id="v4" data-v="4" data-xref="腓立比書 2:30; 約翰一書 3:16; 哥林多前書 16:1"> 為了救我將生死置之度外。不但我感謝他們，就是外族人的教會也感謝他們。</span>
<span className="v" id="v5" data-v="5" data-xref="歌羅西書 4:15; 腓利門書 1:2; 哥林多前書 16:19"> 請問候在他們家中聚會的教會。請問候我所愛的以拜尼土，在亞細亞他第一個信從基督。</span>
<span className="v" id="v6" data-v="6" data-xref="羅馬書 16:12; 馬太福音 27:55; 提摩太前書 5:10"> 請問候瑪麗亞。她為你們多受勞苦。</span>
<span className="v" id="v7" data-v="7" data-xref="羅馬書 16:11; 羅馬書 16:21; 腓利門書 1:23"> 請問候安多尼古和猶尼亞，他們是我的親人，曾與我一同坐牢，在使徒中很有名望，比我先信基督。</span>
<span className="v" id="v8" data-v="8" data-xref="腓立比書 4:1; 約翰一書 3:14; 羅馬書 16:5"> 請問候我在主裡所愛的暗伯利。</span>
<span className="v" id="v9" data-v="9" data-xref="羅馬書 16:2–3; 羅馬書 16:21"> 請問候在基督裡與我同工的耳巴奴和我所愛的士大古。</span>
<span className="v" id="v10" data-v="10" data-xref="羅馬書 14:18; 彼得前書 1:7; 申命記 8:2"> 請問候亞比利，他在基督裡曾受過考驗。請問候亞利多布家裡的人。</span>
<span className="v" id="v11" data-v="11" data-xref="羅馬書 16:21; 羅馬書 16:7"> 請問候我的親人希羅天。請問候拿其數家中的信徒。</span>
<span className="v" id="v12" data-v="12" data-xref="帖撒羅尼迦前書 5:12–13; 希伯來書 6:10–11; 哥林多前書 15:58"> 請問候土非娜和土富撒，她們都為主勞苦。請問候我所愛的彼息，她為主多受勞苦。</span>
<span className="v" id="v13" data-v="13" data-xref="馬可福音 15:21; 提摩太前書 5:2; 約翰二書 1:1"> 請問候主所揀選的魯孚，也問候他的母親，他的母親就是我的母親。</span>
<span className="v" id="v14" data-v="14" data-xref="歌羅西書 1:2; 羅馬書 8:29; 希伯來書 3:1"> 請問候亞遜其土、弗勒干、黑米、八羅巴、黑馬和他們當中的其他弟兄姊妹。</span>
<span className="v" id="v15" data-v="15" data-xref="羅馬書 16:2; 羅馬書 1:7; 羅馬書 16:14"> 請問候非羅羅古、猶利亞、尼利亞和他的妹妹、阿林巴和他們那裡的眾聖徒。</span>
<span className="v" id="v16" data-v="16" data-xref="帖撒羅尼迦前書 5:26; 哥林多前書 16:20; 哥林多後書 13:12"> 你們要以聖潔的吻彼此問候。基督的眾教會都問候你們。</span>
</div>
</div>

## 提防悖逆者

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="猶大書 1:19; 帖撒羅尼迦後書 3:6; 提摩太前書 6:3–5"> 弟兄姊妹，我勸你們要留意那些製造分裂和障礙、背離你們所學之道的人，你們要避開他們。</span>
<span className="v" id="v18" data-v="18" data-xref="歌羅西書 2:4; 馬太福音 7:15; 提摩太前書 6:5"> 他們並不是在事奉我們的主基督，只是為了滿足自己的慾望，用花言巧語欺騙單純幼稚的人。</span>
<span className="v" id="v19" data-v="19" data-xref="馬太福音 10:16; 哥林多前書 14:20; 腓立比書 2:15"> 你們對主的順服已人人皆知，我為你們高興，我希望你們在好事上聰明，在壞事上無知。</span>
<span className="v" id="v20" data-v="20" data-xref="路加福音 10:19; 約翰一書 3:8; 創世記 3:15"> 賜平安的上帝快要把撒旦踐踏在你們腳下了。願我們主耶穌的恩典與你們同在！</span>
</div>
</div>

<div className="bp">

<span className="v" id="v22" data-v="22" data-xref="加拉太書 6:11; 哥林多前書 16:21; 羅馬書 16:8"> 我這代筆寫信的德特在主裡問候你們。</span>

<span className="v" id="v24" data-v="24"> 願我們的主耶穌基督賜恩典給你們眾人！阿們。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古卷無24節。">a</a></sup></span>

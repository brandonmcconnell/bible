## 為事奉上帝而活

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="彼得前書 2:5; 羅馬書 6:13; 希伯來書 13:15–16"> 所以，弟兄姊妹，我憑上帝的憐憫勸你們獻上自己的身體，作聖潔、蒙上帝悅納的活祭。你們理當這樣事奉。</span>
<span className="v" id="v2" data-v="2" data-xref="彼得前書 1:14; 以弗所書 4:22–24; 哥林多後書 5:17"> 你們不可追隨這世界的潮流，要隨著思想的不斷更新而改變，這樣就能明辨上帝的旨意，知道什麼是良善、純全、蒙祂悅納的。</span>
<span className="v" id="v3" data-v="3" data-xref="加拉太書 6:3; 腓立比書 2:3–8; 箴言 26:12"> 我憑上帝賜給我的恩典勸告各位，不要自視過高，要照著上帝賜給各人的信心中肯地看待自己。</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多前書 12:27; 哥林多前書 12:12–14; 以弗所書 4:15–16"> 就像我們每個身體有許多肢體，各肢體功能不同，</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多前書 12:20; 哥林多前書 10:17; 哥林多前書 12:27–28"> 我們雖然人多，但在基督裡組成一個身體，彼此聯結，互為肢體。</span>
<span className="v" id="v6" data-v="6" data-xref="彼得前書 4:10–11; 哥林多前書 7:7; 哥林多前書 12:28–31"> 我們照所得的恩典各有不同的恩賜。說預言的，要按著信心的程度說預言；</span>
<span className="v" id="v7" data-v="7" data-xref="以弗所書 4:11; 提摩太後書 4:2; 使徒行傳 13:1"> 服侍的，要專心服侍；教導的，要專心教導；</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多後書 9:7; 提摩太前書 5:17; 哥林多前書 12:28"> 勸勉的，要專心勸勉；施捨的，要慷慨施捨；治理的，要殷勤治理；憐憫的，要甘心憐憫。</span>
</div>
</div>

## 相愛相顧

<div className="bt">
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="詩篇 34:14; 彼得前書 4:8; 提摩太前書 1:5"> 愛必須真誠。要痛恨邪惡，一心向善。</span>
<span className="v" id="v10" data-v="10" data-xref="腓立比書 2:3; 約翰福音 13:34–35; 希伯來書 13:1"> 要彼此相愛如同手足，互相尊重，彼此謙讓。</span>
<span className="v" id="v11" data-v="11" data-xref="希伯來書 6:10–11; 使徒行傳 18:25; 啟示錄 3:15–16"> 要殷勤，不可懶惰，要常常火熱地事奉主。</span>
<span className="v" id="v12" data-v="12" data-xref="羅馬書 15:13; 希伯來書 10:36; 詩篇 62:8"> 盼望中要有喜樂，患難中要堅忍，禱告要恆切。</span>
<span className="v" id="v13" data-v="13" data-xref="希伯來書 13:16; 哥林多後書 9:12; 約翰一書 3:17"> 聖徒有缺乏，要慷慨幫助；客人來訪，要熱誠款待。</span>
<span className="v" id="v14" data-v="14" data-xref="彼得前書 3:9; 馬太福音 5:44; 帖撒羅尼迦前書 5:15"> 迫害你們的，要為他們祝福；要祝福，不可咒詛。</span>
<span className="v" id="v15" data-v="15" data-xref="哥林多前書 12:26; 希伯來書 13:3; 詩篇 35:13–14"> 要與喜樂的人同樂，與哀哭的人同哭。</span>
<span className="v" id="v16" data-v="16" data-xref="彼得前書 3:8; 箴言 3:7; 雅各書 3:13–17"> 要彼此和睦。不可心高氣傲，反要俯就卑微的人。不可自以為聰明。</span>
<span className="v" id="v17" data-v="17" data-xref="箴言 20:22; 帖撒羅尼迦前書 5:15; 馬太福音 5:39"> 不要以惡報惡，要留心去做眾人看為好的事。</span>
<span className="v" id="v18" data-v="18" data-xref="希伯來書 12:14; 馬太福音 5:9; 羅馬書 14:19"> 如果可能，總要盡力與人和睦相處。</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 32:35; 希伯來書 10:30; 箴言 24:29"> 親愛的弟兄姊妹，不要私自報復，要交給發烈怒的上帝，因為聖經上說：<br /><span className="pl pl-1">「主說，『伸冤在我，我必報應。』</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="申命記32·35。">a</a></sup><br /><span className="pl pl-1">」</span></span>
<span className="v" id="v20" data-v="20" data-xref="箴言 25:21–22; 馬太福音 5:44; 路加福音 6:27"> 相反，<br /><span className="pl pl-1">「你的仇敵若餓了，就給他吃的；</span><br /><span className="pl pl-1">若渴了，就給他喝的；</span><br /><span className="pl pl-1">你這樣做是把炭火堆在他頭上。」</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="箴言25·21、22。">b</a></sup></span>
<span className="v" id="v21" data-v="21" data-xref="彼得前書 3:9; 路加福音 6:27–30; 箴言 16:32"> 你不可被惡所勝，反要以善勝惡。</span>
</div>
</div>

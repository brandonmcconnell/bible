## 亞伯拉罕的榜樣

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以賽亞書 51:2; 羅馬書 4:16; 哥林多後書 11:22"> 那麼，從我們的先祖亞伯拉罕身上，我們學到什麼呢？</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多前書 1:31; 哥林多後書 11:30; 腓立比書 3:9"> 亞伯拉罕如果是因行為而被稱為義人，就可以誇口了，但他在上帝面前沒有可誇的。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 15:6; 雅各書 2:23; 加拉太書 3:6–8"> 聖經上不是說「亞伯拉罕信上帝，就被算為義人」<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="創世記15·6。">a</a></sup>嗎？</span>
<span className="v" id="v4" data-v="4" data-xref="羅馬書 11:6; 羅馬書 9:32; 羅馬書 11:35"> 人工作得來的工錢不算是恩典，是應得的。</span>
<span className="v" id="v5" data-v="5" data-xref="腓立比書 3:9; 羅馬書 3:22; 提多書 3:3–7"> 但人不靠行為，只信稱不敬虔之人為義人的上帝，他就因信而被算為義人。</span>
<span className="v" id="v6" data-v="6" data-xref="提摩太後書 1:9; 腓立比書 3:9; 哥林多前書 1:30"> 大衛也說不靠行為被上帝算為義人的人有福了，他說：</span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 32:1–2; 詩篇 130:3–4; 路加福音 7:47–50"> 「過犯得到赦免、罪惡被遮蓋的人有福了。</span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 32:2; 彼得前書 2:24; 哥林多後書 5:19–20"> 不被主算為有罪的人有福了。」<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="詩篇32·1、2。">b</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="加拉太書 3:14; 歌羅西書 3:11; 加拉太書 3:26–28"> 那麼，這種福分只給受割禮的人嗎？還是也給沒有受割禮的人呢？因為我們說，亞伯拉罕信上帝，就被算為義人。</span>
<span className="v" id="v10" data-v="10" data-xref="加拉太書 6:15; 加拉太書 5:6; 創世記 17:10"> 他究竟是怎麼被算為義人的呢？是他受割禮以前呢？還是以後呢？不是以後，而是以前。</span>
<span className="v" id="v11" data-v="11" data-xref="羅馬書 3:22; 路加福音 19:9; 哥林多後書 1:22"> 他後來受割禮只不過是一個記號，表明他在受割禮前已經因信被稱為義人了。他因此成為一切未受割禮的信徒之父，使這些信徒也可以被算為義人。</span>
<span className="v" id="v12" data-v="12" data-xref="雅歌 1:8; 約翰福音 8:39–40; 箴言 2:20"> 他也做了受割禮之人的父，這些人不只是受了割禮，還跟隨我們先祖亞伯拉罕的腳步，效法他在未受割禮時的信心。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="加拉太書 3:29; 創世記 22:17–18; 創世記 28:14"> 上帝應許將世界賜給亞伯拉罕和他的子孫，不是因為亞伯拉罕遵行了律法，而是因為他因信被稱為義人。</span>
<span className="v" id="v14" data-v="14" data-xref="加拉太書 3:18–24; 腓立比書 3:9; 羅馬書 4:16"> 如果只有遵行律法的人才可以承受應許，信心就沒有價值，上帝的應許也就落了空。</span>
<span className="v" id="v15" data-v="15" data-xref="羅馬書 5:13; 加拉太書 3:10; 羅馬書 3:19–20"> 因為有律法，就有刑罰；哪裡沒有律法，哪裡就沒有違法的事。</span>
<span className="v" id="v16" data-v="16" data-xref="羅馬書 3:24–26; 以弗所書 2:8; 加拉太書 3:22"> 所以，上帝的應許是藉著人的信心賜下的，好叫這一切都是出於上帝的恩典，確保應許歸給所有亞伯拉罕的子孫，不單是律法之下的人，也包括一切效法亞伯拉罕信心的人。</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多前書 1:28; 創世記 17:4–5; 約翰福音 5:21"> 亞伯拉罕在上帝面前是我們所有人的父，正如聖經上說：「我已立你為萬族之父。」<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="創世記17·5。">c</a></sup>他所信的上帝是能夠使死人復活、使無變有的上帝。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="羅馬書 8:24; 創世記 15:5–6; 使徒行傳 27:25"> 他在毫無指望的情況下仍然滿懷盼望地相信上帝的應許，因而成為「萬族之父」<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="創世記15·5。">d</a></sup>，正如上帝的應許：「你的後裔必這麼多。」</span>
<span className="v" id="v19" data-v="19" data-xref="希伯來書 11:11–19; 羅馬書 4:20–21; 創世記 17:17"> 那時他將近百歲，知道自己的身體如同已死，撒拉也已經不能生育，但他的信心仍然沒有動搖。</span>
<span className="v" id="v20" data-v="20" data-xref="路加福音 1:45; 哥林多前書 16:13; 但以理書 10:19"> 他沒有因不信而懷疑上帝的應許，反倒信心更加堅定，將榮耀歸給上帝，</span>
<span className="v" id="v21" data-v="21" data-xref="路加福音 1:37; 耶利米書 32:27; 創世記 18:14"> 完全相信上帝必能實現祂的應許。</span>
<span className="v" id="v22" data-v="22" data-xref="羅馬書 4:6; 羅馬書 4:3"> 所以，他因信被算為義人。</span>
<span className="v" id="v23" data-v="23" data-xref="哥林多前書 10:11; 羅馬書 15:4; 哥林多前書 10:6"> 「他被算為義人」這句話不單單是寫給他的，</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行傳 2:24; 彼得前書 1:21; 使徒行傳 13:30"> 也是寫給我們的。我們相信使我們主耶穌從死裡復活的上帝，所以必被算為義人。</span>
<span className="v" id="v25" data-v="25" data-xref="約翰一書 4:9–10; 以賽亞書 53:5–6; 哥林多後書 5:21"> 耶穌受害而死是為了我們的過犯，祂復活是為了使我們被稱為義人。</span>
</div>

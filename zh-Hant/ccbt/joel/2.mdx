## 耶和華審判的日子

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="約珥書 2:15; 約珥書 1:15; 彼得前書 4:7"> 你們要在錫安吹響號角，<br /><span className="pl pl-1">在我的聖山上發出警訊，</span><br /><span className="pl pl-1">此地的居民都要顫抖，</span><br /><span className="pl pl-1">因為耶和華的日子將要來臨，</span><br /><span className="pl pl-1">已經近了。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="約珥書 1:6; 西番雅書 1:14–15; 約珥書 2:10–11"> <span className="pl pl-1">那是昏暗陰沉的日子，</span><br /><span className="pl pl-1">是烏雲密佈的日子。</span><br /><span className="pl pl-1">來了一支空前絕後、強盛無比的大軍，</span><br /><span className="pl pl-1">牠們像曙光一樣佈滿山嶺。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v3" data-v="3" data-xref="以賽亞書 51:3; 約珥書 1:19–20; 創世記 2:8"> <span className="pl pl-1">牠們前面有燎原之火，</span><br /><span className="pl pl-1">後面有熊熊烈焰。</span><br /><span className="pl pl-1">牠們到來之前，</span><br /><span className="pl pl-1">大地就像伊甸園；</span><br /><span className="pl pl-1">牠們過去之後，</span><br /><span className="pl pl-1">大地變成荒涼的曠野。</span><br /><span className="pl pl-1">地上的一切都逃不過這一場浩劫。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v4" data-v="4" data-xref="啟示錄 9:7"> <span className="pl pl-1">牠們的形狀像馬，</span><br /><span className="pl pl-1">疾馳如戰馬，</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="啟示錄 9:9; 以賽亞書 5:24; 以賽亞書 30:30"> <span className="pl pl-1">在山嶺上跳躍奔騰，</span><br /><span className="pl pl-1">如隆隆戰車，</span><br /><span className="pl pl-1">好像烈火吞噬乾草的聲音，</span><br /><span className="pl pl-1">又如大軍列陣備戰。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="那鴻書 2:10; 以賽亞書 13:8; 耶利米書 30:6"> <span className="pl pl-1">百姓一看到牠們，就驚慌失措，</span><br /><span className="pl pl-1">面如死灰。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="箴言 30:27; 撒母耳記下 1:23; 撒母耳記下 2:18–19"> <span className="pl pl-1">牠們快速奔跑像勇士，</span><br /><span className="pl pl-1">攀登城牆如戰士，</span><br /><span className="pl pl-1">有條不紊地前進。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="歷代志下 23:10; 約伯記 33:18; 歷代志下 32:5"> <span className="pl pl-1">隊伍整齊，各行其道，</span><br /><span className="pl pl-1">長驅直入，勢不可擋。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="耶利米書 9:21; 約翰福音 10:1; 出埃及記 10:6"> <span className="pl pl-1">牠們衝向城邑，躥上城牆，</span><br /><span className="pl pl-1">爬進房屋，</span><br /><span className="pl pl-1">如盜賊般破窗而入。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="馬太福音 24:29; 以賽亞書 13:10; 約珥書 3:15–16"> <span className="pl pl-1">所到之處，</span><br /><span className="pl pl-1">天搖地動，</span><br /><span className="pl pl-1">日月昏暗，</span><br /><span className="pl pl-1">星辰無光。</span><br /></span>

</div>
</div>

## 上帝要審判萬國

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="西番雅書 3:19–20; 耶利米書 30:3; 以西結書 39:25"> 「到那日，我要使猶大和耶路撒冷被擄的人返鄉。</span>
<span className="v" id="v2" data-v="2" data-xref="撒迦利亞書 14:2–4; 以賽亞書 66:16; 西番雅書 3:8"> 那時，我要聚集萬國，帶他們下到約沙法<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「約沙法」意思是「耶和華審判」。">a</a></sup>谷，在那裡審判他們，因為他們把我的子民，就是我的產業以色列，分散到各國，並瓜分我的土地。</span>
<span className="v" id="v3" data-v="3" data-xref="那鴻書 3:10; 俄巴底亞書 1:11; 阿摩司書 2:6"> 他們抽籤分了我的子民，將男童換妓女，賣女童買酒喝。</span>
<span className="v" id="v4" data-v="4" data-xref="阿摩司書 1:6–10; 耶利米書 47:4; 以賽亞書 59:18"> 「泰爾、西頓和非利士境內所有的人啊，你們為什麼這樣對我？你們要報復我嗎？如果你們是報復我，我必速速使你們遭報應。</span>
<span className="v" id="v5" data-v="5" data-xref="歷代志下 21:16–17; 列王紀下 18:15–16; 列王紀下 12:18"> 你們奪去我的金銀，搶走我的珍寶，拿去放在你們的廟中，</span>
<span className="v" id="v6" data-v="6" data-xref="以西結書 27:13; 約珥書 3:3; 申命記 28:68"> 並把猶大和耶路撒冷的居民賣給希臘人，使他們遠離家鄉。</span>
<span className="v" id="v7" data-v="7" data-xref="以賽亞書 43:5–6; 耶利米書 23:8; 帖撒羅尼迦後書 1:6"> 然而，他們被賣到哪裡，我要促使他們從哪裡離開，並要使你們得到報應，</span>
<span className="v" id="v8" data-v="8" data-xref="以賽亞書 60:14; 約伯記 1:15; 以賽亞書 14:1–2"> 我必把你們的兒女賣給猶大人，猶大人必把他們賣給遠方的示巴人。這是耶和華說的。」</span>
<span className="v" id="v9" data-v="9" data-xref="耶利米書 46:3–4; 以賽亞書 8:9–10; 以西結書 38:7"> <span className="pl pl-1">你們去向列國宣告：</span><br /><span className="pl pl-1">「要召集勇士，徵調軍隊，</span><br /><span className="pl pl-1">前去打仗！</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="撒迦利亞書 12:8; 彌迦書 4:3; 歷代志下 25:8"> <span className="pl pl-1">要將犁頭打成刀劍，</span><br /><span className="pl pl-1">把鐮刀鑄成矛頭，</span><br /><span className="pl pl-1">弱者要說自己是勇士！</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="以賽亞書 13:3; 西番雅書 3:8; 以西結書 38:9–18"> <span className="pl pl-1">四圍的列國啊，</span><br /><span className="pl pl-1">你們快快聚集到那裡吧！」</span><br /><span className="pl pl-1">耶和華啊，</span><br /><span className="pl pl-1">求你差遣大能的勇士降臨。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="約珥書 3:2; 以賽亞書 2:4; 詩篇 96:13"> <span className="pl pl-1">「列國都要起來，</span><br /><span className="pl pl-1">上到約沙法谷，</span><br /><span className="pl pl-1">因為我要坐在那裡審判周邊列國。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="啟示錄 14:15–20; 馬可福音 4:29; 何西阿書 6:11"> <span className="pl pl-1">開鐮吧，因為莊稼熟了；</span><br /><span className="pl pl-1">踩踏吧，因為榨酒池的葡萄滿了。</span><br /><span className="pl pl-1">酒池滿溢，因為他們惡貫滿盈。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="約珥書 3:2; 腓立比書 3:2; 以賽亞書 34:2–8"> <span className="pl pl-1">千千萬萬的人聚集在審判谷，</span><br /><span className="pl pl-1">因為耶和華的日子要臨到那裡。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="約珥書 2:10; 馬太福音 24:29; 約珥書 2:31"> <span className="pl pl-1">日月昏暗，</span><br /><span className="pl pl-1">星辰無光。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="阿摩司書 1:2; 約珥書 2:10–11; 哈該書 2:6"> <span className="pl pl-1">耶和華從錫安發出怒吼，</span><br /><span className="pl pl-1">從耶路撒冷發出雷聲，</span><br /><span className="pl pl-1">天地為之震動。</span><br /><span className="pl pl-1">但耶和華卻是祂子民的避難所，</span><br /><span className="pl pl-1">是以色列人的堡壘。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v17" data-v="17" data-xref="約珥書 2:27; 那鴻書 1:15; 以賽亞書 52:1"> <span className="pl pl-1">「這樣，你們就知道我是你們的上帝耶和華，</span><br /><span className="pl pl-1">我住在我的聖山錫安。</span><br /><span className="pl pl-1">耶路撒冷必為聖城，</span><br /><span className="pl pl-1">外族人必不再侵犯它。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v18" data-v="18" data-xref="以西結書 47:1–12; 撒迦利亞書 14:8; 啟示錄 22:1–2"> <span className="pl pl-1">「到那日，群山要滴下甜酒，</span><br /><span className="pl pl-1">丘陵要流出乳汁。</span><br /><span className="pl pl-1">猶大的溪澗碧水常流，</span><br /><span className="pl pl-1">必有清泉從耶和華的殿中流出，</span><br /><span className="pl pl-1">澆灌什亭谷。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="以賽亞書 19:1–15; 耶利米書 51:35; 撒迦利亞書 14:18–19"> <span className="pl pl-1">埃及必一片荒涼，</span><br /><span className="pl pl-1">以東必成為荒涼的曠野，</span><br /><span className="pl pl-1">因為他們曾殘暴地對待猶大人，</span><br /><span className="pl pl-1">在猶大濫殺無辜。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="以西結書 37:25; 阿摩司書 9:15; 以賽亞書 33:20"> <span className="pl pl-1">但猶大必常有人住，</span><br /><span className="pl pl-1">耶路撒冷必存到萬代。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="以賽亞書 4:4; 啟示錄 21:3; 以西結書 36:25"> <span className="pl pl-1">我必追討</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="「追討」希伯來文是「洗淨」。">b</a></sup><br /><span className="pl pl-1">尚未追討的血債，</span><br /><span className="pl pl-1">因為耶和華住在錫安。」</span></span>
</div>

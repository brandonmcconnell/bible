## 邪惡的舌頭

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 12:47–48; 提摩太前書 1:7; 彼得前書 5:3"> 我的弟兄姊妹，不要個個當教師，因為你們知道，我們為人師表的將受到更嚴格的評判。</span>
<span className="v" id="v2" data-v="2" data-xref="雅各書 1:26; 箴言 13:3; 彼得前書 3:10"> 因為我們在許多方面難免有過失。如果誰在言語上沒有過失，他就是純全的人，也能在各方面保持自制。</span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 32:9; 詩篇 39:1; 雅各書 1:26"> 我們如果把嚼環放在馬嘴裡，便可以馴服牠，駕馭牠。</span>
<span className="v" id="v4" data-v="4" data-xref="詩篇 107:25–27; 馬太福音 8:24; 使徒行傳 27:14–38"> 一艘大船被強風吹襲時，船身雖然龐大，但舵手只要操縱一個小小的舵，就能隨意駕駛它。</span>
<span className="v" id="v5" data-v="5" data-xref="箴言 18:21; 耶利米書 9:3–8; 箴言 12:18"> 同樣，人的舌頭雖然很小，卻能說誇大的話。 看啊，小火星能點燃大森林。</span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 120:2–3; 箴言 16:27; 馬可福音 7:15"> 舌頭就是火，是我們身體上的一個充滿邪惡的世界，能玷污人的全身，足以燒毀人的一生，它是從地獄點燃的火。</span>
<span className="v" id="v7" data-v="7" data-xref="馬可福音 5:4"> 自然界中的各類走獸、飛禽、爬蟲、水族都可以被馴服，也已經被人類馴服了，</span>
<span className="v" id="v8" data-v="8" data-xref="羅馬書 3:13; 詩篇 140:3; 詩篇 55:21"> 但無人能馴服自己的舌頭，因為舌頭是個蠢蠢欲動的邪惡之物，充滿了致命的毒氣。</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 10:7; 創世記 1:26–27; 詩篇 62:4"> 我們用舌頭來讚美我們的主和天父，也用舌頭來咒詛照著上帝的形像被造的人。</span>
<span className="v" id="v10" data-v="10" data-xref="羅馬書 12:14; 彼得前書 3:9; 哥林多前書 3:3"> 讚美和咒詛竟然從同一張嘴裡發出來。我的弟兄姊妹，這是不應該的！</span>
<span className="v" id="v11" data-v="11"> 同一個泉源能湧出甜苦兩樣水嗎？</span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 6:43–44; 馬太福音 12:33; 馬太福音 7:16–20"> 我的弟兄姊妹，無花果樹能結出橄欖嗎？葡萄樹能結出無花果嗎？一個鹹水泉必流不出甜水來。</span>
</div>
</div>

## 天上的智慧

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="加拉太書 5:23; 雅各書 3:17; 馬太福音 5:5"> 你們當中誰是有智慧、有見識的呢？請他帶著從智慧而來的謙和在善行上表現出來。</span>
<span className="v" id="v14" data-v="14" data-xref="雅各書 3:16; 哥林多前書 13:4; 腓立比書 2:3"> 但如果你們心懷苦澀的嫉妒和自私的野心，就不要自誇，也不要違背真理去撒謊。</span>
<span className="v" id="v15" data-v="15" data-xref="雅各書 3:17; 雅各書 1:17; 哥林多前書 3:19"> 這種智慧並非來自天上，而是從世俗、私慾和魔鬼來的。</span>
<span className="v" id="v16" data-v="16" data-xref="雅各書 3:14; 哥林多前書 3:3; 哥林多前書 14:33"> 哪裡有嫉妒和自私的野心，哪裡就會有混亂和各種惡事。</span>
<span className="v" id="v17" data-v="17" data-xref="加拉太書 5:22–23; 箴言 2:6; 哥林多前書 13:4–7"> 但從天上來的智慧首先是純潔，然後是愛好和平、溫良柔順、充滿憐憫、多結善果、不存偏見、沒有虛偽。</span>
<span className="v" id="v18" data-v="18" data-xref="馬太福音 5:9; 何西阿書 10:12; 腓立比書 1:11"> 使人和睦的人撒下和平的種子，必收穫仁義的果實。</span>
</div>
</div>

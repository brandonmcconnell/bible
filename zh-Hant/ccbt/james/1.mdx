## 信心和忍耐

<div className="bt">
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="彼得前書 1:6–8; 雅各書 1:12; 哥林多後書 12:9–10"> 我的弟兄姊妹，當你們遭遇各種試煉的時候，都要認為是喜樂的事。</span>
<span className="v" id="v3" data-v="3" data-xref="羅馬書 5:3–4; 希伯來書 10:36; 歌羅西書 1:11"> 要知道你們的信心經過考驗會產生忍耐。</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 21:19; 彼得前書 5:10; 馬太福音 5:48"> 你們要忍耐到底，使你們純全、完備、毫無缺欠。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="箴言 2:3–6; 約翰福音 15:7; 箴言 3:5–7"> 如果你們誰缺少智慧，就當求慷慨施恩、不責備人的上帝，上帝必賜給他智慧。</span>
<span className="v" id="v6" data-v="6" data-xref="馬太福音 21:21–22; 希伯來書 11:6; 馬可福音 11:22–24"> 但他要憑信心毫不疑惑地祈求，因為疑惑的人就像海上隨風翻騰的波濤，起伏不定。</span>
<span className="v" id="v7" data-v="7" data-xref="雅各書 4:3; 以賽亞書 58:3–4; 箴言 21:27"> 這種人別想從主那裡得到什麼。</span>
<span className="v" id="v8" data-v="8" data-xref="列王紀上 18:21; 馬太福音 6:24; 雅各書 4:8"> 他們三心二意，行事為人沒有定見。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="耶利米書 9:23–24; 雅各書 2:5–6; 箴言 19:1"> 卑微的弟兄高升，應當快樂。</span>
<span className="v" id="v10" data-v="10" data-xref="彼得前書 1:24; 約翰一書 2:17; 約伯記 14:2"> 富有的弟兄降卑，也要快樂，因為他會像花草一樣衰殘。</span>
<span className="v" id="v11" data-v="11" data-xref="以賽亞書 40:7–8; 詩篇 37:35–36; 詩篇 49:6–14"> 驕陽升起，草就乾枯，花也凋謝，美麗隨之消失。富有的人在忙碌追求中也會如此衰殘。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="彼得前書 5:10; 彼得前書 1:6–8; 啟示錄 2:10"> 在試煉中能夠忍耐到底的人有福了，因為他若經得起考驗，就必得到主應許賜給愛祂之人的生命冠冕。</span>
<span className="v" id="v13" data-v="13" data-xref="哈巴谷書 2:12–13; 雅各書 1:12; 羅馬書 9:19–20"> 當人受到誘惑時，不可說：「是上帝在誘惑我。」因為上帝不受邪惡的誘惑，也不誘惑人。</span>
<span className="v" id="v14" data-v="14" data-xref="馬可福音 7:21–22; 以弗所書 4:22; 馬太福音 15:18"> 其實每個受到誘惑的人都是受自己的私慾慫恿和誘惑。</span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 7:14; 約伯記 15:35; 羅馬書 5:12–21"> 私慾懷了胎，便生出罪，罪一旦長成，便帶來死亡。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="加拉太書 6:7; 雅各書 1:19; 腓立比書 2:12"> 我親愛的弟兄姊妹，不要上當受騙。</span>
<span className="v" id="v17" data-v="17" data-xref="約翰福音 3:27; 馬太福音 7:11; 希伯來書 13:8"> 一切良善的施予和完美的恩賜都是從天上，從眾光之父那裡來的。祂不像轉動的影子變幻無常。</span>
<span className="v" id="v18" data-v="18" data-xref="羅馬書 8:29–31; 彼得前書 1:23; 約翰福音 3:3–5"> 祂按照自己的旨意，藉著真道重生了我們，使我們在祂所造的萬物中作初熟的果實。</span>
</div>
</div>

## 聽道與行道

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="箴言 17:27; 箴言 21:23; 箴言 14:29"> 我親愛的弟兄姊妹，請記住：每個人都要快快地聽，慢慢地說，慢慢地動怒。</span>
<span className="v" id="v20" data-v="20" data-xref="提摩太後書 2:24–25; 以弗所書 4:26; 雅各書 3:17–18"> 因為人的憤怒不能成就上帝的公義。</span>
<span className="v" id="v21" data-v="21" data-xref="以弗所書 4:22; 以弗所書 1:13; 彼得前書 2:11"> 所以你們要除去一切污穢和惡習，謙卑地領受那已經栽種在你們心裡、能救你們靈魂的真道。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="羅馬書 2:13; 路加福音 6:46–48; 約翰福音 13:17"> 你們要行道，不要只是聽道，自己欺騙自己。</span>
<span className="v" id="v23" data-v="23" data-xref="馬太福音 7:26–27; 以西結書 33:31–32; 雅各書 2:14–26"> 因為人聽道而不行道，就像照鏡子一樣，</span>
<span className="v" id="v24" data-v="24" data-xref="彼得後書 3:11; 路加福音 1:66; 路加福音 7:39"> 照過後就走了，隨即忘記了自己的容貌。</span>
<span className="v" id="v25" data-v="25" data-xref="路加福音 11:28; 約翰福音 13:17; 哥林多後書 3:17–18"> 但詳細查考那帶來自由的全備律法並持之以恆的人，不是聽了就忘，而是身體力行，這樣的人必在他所行的事上蒙福。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="以弗所書 4:29; 詩篇 141:3; 彼得前書 3:10"> 如果有人自以為虔誠，卻不勒住自己的舌頭，就是在自己欺騙自己，他的所謂虔誠也毫無價值。</span>
<span className="v" id="v27" data-v="27" data-xref="以賽亞書 1:16–17; 約翰一書 3:17–19; 加拉太書 6:9–10"> 在父上帝看來，純潔無瑕的虔誠是指照顧患難中的孤兒寡婦，並且不讓自己被世俗玷污。</span>
</div>
</div>

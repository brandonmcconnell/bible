## 不可以貌取人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="箴言 24:23; 雅各書 2:9; 利未記 19:15"> 我的弟兄姊妹，你們既然信了我們榮耀的主耶穌基督，就不可以貌取人。</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 15:22; 以斯帖記 3:10; 以斯帖記 8:2"> 比方說，一個手戴金飾、衣著華麗的人來參加你們的聚會，一個衣衫襤褸的人也來參加，</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多後書 8:9; 雅各書 2:6; 路加福音 7:44–46"> 你們就看重那衣著華麗的，對他說：「請上座。」卻對那窮人說：「你站在那邊。」或「坐在我的腳凳邊。」</span>
<span className="v" id="v4" data-v="4" data-xref="約翰福音 7:24; 約伯記 34:19; 馬太福音 7:1–5"> 你們這樣做難道不是偏心待人，心懷惡意地判斷人嗎？</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="馬太福音 5:3; 路加福音 6:20; 啟示錄 2:9"> 我親愛的弟兄姊妹，請聽我說，上帝不是揀選了世上的窮人，使他們在信心上富足，並承受祂應許賜給那些愛祂之人的國度嗎？</span>
<span className="v" id="v6" data-v="6" data-xref="箴言 17:5; 哥林多前書 11:22; 箴言 14:31"> 你們反倒侮辱窮人。難道欺壓你們、抓你們上法庭的不是那些有錢人嗎？</span>
<span className="v" id="v7" data-v="7" data-xref="腓立比書 2:9–11; 啟示錄 13:5–6; 提摩太前書 1:13"> 不正是他們褻瀆你們所敬奉的尊名嗎？</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="利未記 19:18; 加拉太書 5:14; 馬太福音 22:39"> 你們如果能切實行出聖經中「要愛鄰如己」<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="利未記19·18。">a</a></sup>這條至尊的律法，就對了。</span>
<span className="v" id="v9" data-v="9" data-xref="利未記 19:15; 雅各書 2:1–4; 約翰一書 3:4"> 你們如果以貌取人，便是犯罪，被律法定為違法者。</span>
<span className="v" id="v10" data-v="10" data-xref="加拉太書 3:10; 馬太福音 5:18–19; 申命記 27:26"> 人遵守律法，就要全部遵守，他只要觸犯律法中的一條，就等於干犯了全部，</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及記 20:13–14; 馬太福音 5:21–28; 申命記 5:17–18"> 因為那位說「不可通姦」<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="出埃及記20·14；申命記5·18。">b</a></sup>的，也說過「不可殺人」<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="出埃及記20·13；申命記5·17。">c</a></sup>。如果你沒有犯通姦罪，卻殺了人，你仍違背了律法。</span>
<span className="v" id="v12" data-v="12" data-xref="雅各書 1:25; 雅各書 2:8; 彼得後書 1:4–8"> 既然你們要按使人自由的律法受審判，就應該按律法行事為人。</span>
<span className="v" id="v13" data-v="13" data-xref="馬太福音 5:7; 馬太福音 6:15; 箴言 21:13"> 因為不憐憫人的會受到無情的審判，但憐憫勝過審判。</span>
</div>
</div>

## 信心和行為

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="馬太福音 7:26–27; 馬太福音 7:21–23; 雅各書 1:22–25"> 我的弟兄姊妹，如果有人自稱有信心，卻沒有行為，有什麼用呢？這種信心能夠救他嗎？</span>
<span className="v" id="v15" data-v="15" data-xref="路加福音 3:11; 馬太福音 25:35–40; 以賽亞書 58:7"> 如果有弟兄姊妹缺衣少食，</span>
<span className="v" id="v16" data-v="16" data-xref="箴言 3:27–28; 約翰一書 3:16–18; 馬太福音 25:42–45"> 你們只是對他們說：「安心走吧，願你們穿得暖，吃得飽」，卻不幫助他們解決實際困難，這有什麼用呢？</span>
<span className="v" id="v17" data-v="17" data-xref="雅各書 2:26; 彼得後書 1:5–9; 雅各書 2:19–20"> 因此，信心若沒有行為，就是死的。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="雅各書 3:13; 雅各書 2:14; 加拉太書 5:6"> 必有人說：「你有信心，我有行為。」請把你沒有行為的信心指給我看，我就用行為把我的信心顯給你看。</span>
<span className="v" id="v19" data-v="19" data-xref="路加福音 4:34; 馬可福音 1:24; 馬太福音 8:29"> 你相信上帝只有一位，你信得沒錯，鬼魔也相信，而且恐懼顫抖。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="雅各書 2:17; 雅各書 2:26; 箴言 12:11"> 愚蠢的人啊，你們不知道沒有行為的信心毫無用處嗎？</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 22:16–18; 創世記 22:9–12; 約翰福音 8:39"> 我們的祖先亞伯拉罕把兒子以撒獻在祭壇上的時候，難道不是因行為被稱為義人嗎？</span>
<span className="v" id="v22" data-v="22" data-xref="帖撒羅尼迦前書 1:3; 希伯來書 11:17–19; 加拉太書 5:6"> 可見他的信心和行為相稱，而且信心要有行為才是完全的。</span>
<span className="v" id="v23" data-v="23" data-xref="創世記 15:6; 以賽亞書 41:8; 歷代志下 20:7"> 這正應驗了聖經的記載：「亞伯拉罕信上帝，就被算為義人」<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="創世記15·6。">d</a></sup>，並且被稱為「上帝的朋友」。</span>
<span className="v" id="v24" data-v="24" data-xref="雅各書 2:21–22; 雅各書 2:15–18; 詩篇 60:12"> 可見人被稱為義人是因行為，並非單因信心。</span>
<span className="v" id="v25" data-v="25" data-xref="希伯來書 11:31; 約書亞記 6:22–25; 約書亞記 2:19–21"> 還有妓女喇合，她收留使者，把他們藏在家裡，又送他們從別的路逃生，不也是因行為被稱為義人嗎？</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="雅各書 2:20; 雅各書 2:17; 雅各書 2:14"> 身體沒有靈魂是死的，同樣，信心沒有行為也是死的。</span>
</div>
</div>

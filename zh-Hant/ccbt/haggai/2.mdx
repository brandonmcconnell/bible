## 對新殿的應許

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哈該書 1:1; 哈該書 2:20; 哈該書 2:10"> 七月二十一日，耶和華藉先知哈該說：</span>
<span className="v" id="v2" data-v="2" data-xref="哈該書 1:1; 尼希米記 8:9; 以斯拉記 2:63"> 「你去告訴撒拉鐵的兒子猶大省長所羅巴伯、約撒答的兒子大祭司約書亞和所有的餘民，</span>
<span className="v" id="v3" data-v="3" data-xref="以斯拉記 3:12; 哈該書 2:9; 以西結書 7:20"> 『你們倖存的人當中有誰見過這殿昔日的榮耀呢？現在你們看這殿如何？看上去豈不是無足輕重嗎？</span>
<span className="v" id="v4" data-v="4" data-xref="歷代志上 28:20; 約書亞記 1:9; 撒迦利亞書 8:9"> 所羅巴伯啊，你要剛強，這是耶和華說的。約撒答的兒子大祭司約書亞啊，你要剛強；這地方的所有百姓啊，你們要剛強。這是耶和華說的。你們要動工，因為我與你們同在。這是萬軍之耶和華說的。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 34:10; 出埃及記 29:45–46; 以賽亞書 41:13"> 這是你們出埃及時我與你們立的約。不要懼怕，我的靈仍住在你們當中。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="希伯來書 12:26–28; 以賽亞書 10:25; 馬可福音 13:24–26"> 「『萬軍之耶和華說，不久，我要再次震動天地、海洋和旱地。</span>
<span className="v" id="v7" data-v="7" data-xref="瑪拉基書 3:1; 列王紀上 8:11; 約翰福音 7:37–39"> 萬軍之耶和華說，我要震動萬國，萬國的珍寶都要送到這殿，我要使這殿充滿榮耀。</span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 50:10–12; 詩篇 24:1; 以賽亞書 60:17"> 萬軍之耶和華說，金子是我的，銀子也是我的。</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 85:8–9; 哥林多後書 3:9–10; 歌羅西書 1:19–21"> 萬軍之耶和華說，這殿後來的榮耀必大過從前的榮耀。萬軍之耶和華說，我要在這地方賜下平安。』」</span>
</div>
</div>

## 指出百姓的罪

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="哈該書 2:20; 哈該書 1:1; 哈該書 1:15–1"> 大流士王執政第二年九月二十四日，耶和華對先知哈該說：</span>
<span className="v" id="v11" data-v="11" data-xref="利未記 10:10–11; 瑪拉基書 2:7; 申命記 33:10"> 「萬軍之耶和華說，『你去問祭司律法怎麼說，</span>
<span className="v" id="v12" data-v="12" data-xref="利未記 6:27; 馬太福音 23:19; 利未記 7:6"> 如果有人用衣服兜著祭肉，而衣服碰到餅、湯、酒、油或其他食物，這些被衣服碰到的食物會成為聖潔之物嗎？』」祭司們答道：「不會。」</span>
<span className="v" id="v13" data-v="13" data-xref="民數記 5:2–3; 民數記 19:11–22; 利未記 22:4–6"> 哈該又說：「如果因碰過屍體而變得不潔淨的人接觸這些食物，這些食物會變得不潔淨嗎？」祭司答道：「會變得不潔淨。」</span>
<span className="v" id="v14" data-v="14" data-xref="箴言 28:9; 提多書 1:15; 以賽亞書 1:11–15"> 於是哈該說：「耶和華說，『這百姓和這國家在我面前也是如此。他們手中的各樣工作和他們在那裡所獻的都不潔淨。』</span>
</div>
</div>

## 耶和華應許賜福

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="哈該書 1:5; 以斯拉記 3:10; 以斯拉記 4:24"> 「『你們現在要回想重建耶和華殿之前的光景。</span>
<span className="v" id="v16" data-v="16" data-xref="哈該書 1:6; 瑪拉基書 2:2; 箴言 3:9–10"> 那時，有人盼望得到二十斗穀物，卻只有十斗。有人盼望得到五十桶酒，榨酒池中卻只有二十桶。</span>
<span className="v" id="v17" data-v="17" data-xref="申命記 28:22; 哈該書 1:11; 哈該書 1:9"> 我曾用蟲災、黴災和冰雹毀滅你們的作物，你們仍沒有歸向我。這是耶和華說的。</span>
<span className="v" id="v18" data-v="18" data-xref="撒迦利亞書 8:9; 哈該書 2:15; 以斯拉記 5:1–2"> 從今以後，也就是從九月二十四日起，你們要思想耶和華的殿奠基的日子，要認真思想。</span>
<span className="v" id="v19" data-v="19" data-xref="瑪拉基書 3:10; 哈巴谷書 3:17–18; 箴言 3:9–10"> 雖然糧倉裡沒有種子，葡萄樹、無花果樹、石榴樹和橄欖樹沒結果子，但從今以後，我要賜福給你們。』」</span>
</div>
</div>

## 揀選所羅巴伯

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20"> 同一天，耶和華第二次對哈該說：</span>
<span className="v" id="v21" data-v="21" data-xref="撒迦利亞書 4:6–10; 哈該書 2:6–7; 哈該書 1:1"> 「你告訴猶大省長所羅巴伯，『我必震動天地，</span>
<span className="v" id="v22" data-v="22" data-xref="彌迦書 5:10; 士師記 7:22; 西番雅書 3:8"> 推翻君王的寶座，消滅列國的勢力，掀翻他們的戰車和駕車的人，使戰馬跌倒、騎士自相殘殺。</span>
<span className="v" id="v23" data-v="23" data-xref="以賽亞書 43:10; 以賽亞書 42:1; 雅歌 8:6"> 萬軍之耶和華說，我的僕人——撒拉鐵的兒子所羅巴伯啊，到那日，我必使你作我蓋印的戒指，因為我揀選了你。這是萬軍之耶和華說的。』」</span>
</div>
</div>

## 耶和華命令百姓重建聖殿

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以斯拉記 2:2; 以斯拉記 3:8; 以斯拉記 3:2"> 大流士王執政第二年六月一日，耶和華藉著先知哈該對撒拉鐵的兒子猶大省長所羅巴伯和約撒答的兒子大祭司約書亞說：</span>
<span className="v" id="v2" data-v="2" data-xref="以斯拉記 4:23–2; 尼希米記 4:10; 傳道書 11:4"> 「萬軍之耶和華說，『這些百姓說，重建耶和華殿的時候還沒到。』」</span>
<span className="v" id="v3" data-v="3" data-xref="以斯拉記 5:1; 撒迦利亞書 1:1"> 因此，耶和華藉先知哈該說：</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳記下 7:2; 詩篇 132:3–5; 腓立比書 2:21"> 「這殿還荒廢時，你們卻住在華麗的房子裡嗎？</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米哀歌 3:40; 哥林多後書 13:5; 哈該書 1:7"> 萬軍之耶和華說，你們要認真反省自己的行為。</span>
<span className="v" id="v6" data-v="6" data-xref="哈該書 1:9; 申命記 28:38–40; 何西阿書 4:10"> 你們種多收少，吃不飽，喝不足，穿不暖，掙來的工錢卻放在破漏口袋中。」</span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 119:59–60; 哈該書 1:5; 腓立比書 3:1"> 萬軍之耶和華說：「你們要認真反省自己的行為。</span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 132:13–14; 歷代志下 7:16; 哈該書 2:7"> 你們要上山伐木，重建這殿，好讓我歡喜並得到尊崇。這是耶和華說的。</span>
<span className="v" id="v9" data-v="9" data-xref="哈該書 1:4; 哈該書 2:16–17; 哈該書 1:6"> 你們盼望豐收，結果收的很少；你們把收成帶回家，我卻把它們吹走。這是什麼緣故？萬軍之耶和華告訴你們，『因為你們都忙於建自家的房子，任由我的殿荒廢。</span>
<span className="v" id="v10" data-v="10" data-xref="列王紀上 8:35; 利未記 26:19; 申命記 28:23–24"> 所以，天不降露，地無出產。</span>
<span className="v" id="v11" data-v="11" data-xref="哈該書 2:17; 申命記 28:22; 列王紀下 8:1"> 我讓旱災臨到大地、群山、五穀、葡萄、橄欖等地裡的出產和人畜，以及你們所勞碌的一切。』」</span>
<span className="v" id="v12" data-v="12" data-xref="以賽亞書 50:10; 以斯拉記 5:2; 哈該書 1:14"> 撒拉鐵的兒子猶大省長所羅巴伯、約撒答的兒子大祭司約書亞和所有的餘民<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「餘民」指「從流亡之地歸回的人」。">a</a></sup>，聽到他們的上帝耶和華派先知哈該所講的話，都順服耶和華的話。百姓都敬畏耶和華。</span>
<span className="v" id="v13" data-v="13" data-xref="以賽亞書 43:2; 馬太福音 28:20; 瑪拉基書 3:1"> 耶和華的使者哈該向百姓傳達耶和華的話，說：「耶和華說，『我與你們同在。』」</span>
<span className="v" id="v14" data-v="14" data-xref="歷代志下 36:22; 希伯來書 13:21; 哈該書 2:21"> 耶和華感動撒拉鐵的兒子猶大省長所羅巴伯、約撒答的兒子大祭司約書亞和所有的餘民，他們就動工建造他們的上帝——萬軍之耶和華的殿，</span>
<span className="v" id="v15" data-v="15" data-xref="哈該書 1:1; 哈該書 2:20; 哈該書 2:1"> 時值大流士王執政第二年六月二十四日。</span>
</div>

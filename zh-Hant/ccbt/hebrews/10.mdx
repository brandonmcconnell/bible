## 永遠的贖罪祭

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="希伯來書 8:5; 希伯來書 9:11; 歌羅西書 2:17"> 律法只是將來美事的一個投影，並非本體的真像，所以年復一年地獻同樣的祭物，絕不能使前來敬拜的人純全，</span>
<span className="v" id="v2" data-v="2" data-xref="以賽亞書 43:25; 彌迦書 7:19; 詩篇 103:12"> 否則，獻祭的事早已終止了。因為敬拜的人若獻一次祭就能徹底得到潔淨，早就不會再覺得有罪了。</span>
<span className="v" id="v3" data-v="3" data-xref="希伯來書 9:7; 出埃及記 30:10; 利未記 23:27–28"> 然而，每年獻祭，都會使人想起自己的罪來，</span>
<span className="v" id="v4" data-v="4" data-xref="希伯來書 10:11; 以賽亞書 1:11–15; 彌迦書 6:6–8"> 因為公牛和山羊的血根本不能除去人的罪。</span>
</div>
<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="詩篇 40:6–8; 以賽亞書 1:11; 以賽亞書 7:14"> 所以，基督來到世上時曾說：<br /><span className="pl pl-1">「上帝啊，祭物和供物非你所悅，</span><br /><span className="pl pl-1">你為我預備了身體。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="瑪拉基書 1:10; 馬太福音 3:17; 詩篇 147:11"> <span className="pl pl-1">燔祭和贖罪祭非你所愛。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 40:7–8; 約翰福音 4:34; 約翰福音 6:38"> <span className="pl pl-1">於是我說，</span><br /><span className="pl pl-1">『上帝啊，我來是要遵行你的旨意，</span><br /><span className="pl pl-1">我的事都記在聖經上了。』</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="詩篇40·6‑8。">a</a></sup><br /><span className="pl pl-1">」</span></span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="希伯來書 10:5; 馬可福音 12:33"> 基督首先說：「祭物、供物、燔祭和贖罪祭都不是你想要的，也不是你喜愛的。」這些都是依照律法獻上的。</span>
<span className="v" id="v9" data-v="9" data-xref="希伯來書 7:18–19; 希伯來書 12:27–28; 希伯來書 10:7"> 然後祂又說：「看啊，我來是要遵行你的旨意。」可見祂為了設立後者，廢除了前者。</span>
<span className="v" id="v10" data-v="10" data-xref="希伯來書 10:14; 希伯來書 10:12; 哥林多前書 6:11"> 靠著上帝的旨意，耶穌基督只一次獻上自己的身體，便使我們永遠聖潔了。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="希伯來書 5:1; 民數記 28:3; 希伯來書 10:4"> 祭司都要天天站著供職，一次次地獻上同樣的祭物，只是這些祭物根本不能除罪。</span>
<span className="v" id="v12" data-v="12" data-xref="希伯來書 1:3; 歌羅西書 3:1; 羅馬書 8:34"> 而基督一次獻上自己成為永遠的贖罪祭後，就坐在上帝的右邊，</span>
<span className="v" id="v13" data-v="13" data-xref="希伯來書 1:13; 詩篇 110:1; 路加福音 20:43"> 等待祂的仇敵成為祂的腳凳。</span>
<span className="v" id="v14" data-v="14" data-xref="希伯來書 7:25; 希伯來書 10:1; 希伯來書 9:14"> 祂憑一次犧牲，使那些得以聖潔的人永遠純全。</span>
</div>
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="希伯來書 3:7; 啟示錄 2:11; 啟示錄 3:6"> 聖靈也向我們作見證，說：</span>
<span className="v" id="v16" data-v="16" data-xref="耶利米書 31:33–34; 希伯來書 8:8–12; 羅馬書 11:27"> <span className="pl pl-1">「主說：『那些日子以後，</span><br /><span className="pl pl-1">我將與他們立這樣的約，</span><br /><span className="pl pl-1">我要把我的律法放在他們心上，</span><br /><span className="pl pl-1">寫在他們腦中。</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="耶利米書31·33。">b</a></sup><br /></span>
<span className="v" id="v17" data-v="17" data-xref="耶利米書 31:34; 希伯來書 8:12"> <span className="pl pl-1">我要忘掉他們的罪惡和過犯。』</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="耶利米書31·34。">c</a></sup><br /><span className="pl pl-1">」</span></span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="希伯來書 10:2; 希伯來書 10:14"> 既然過犯和罪惡已經得到赦免，就不需要再為罪獻祭了。</span>
</div>
</div>

## 堅忍到底

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="以弗所書 2:18; 希伯來書 9:12; 希伯來書 4:16"> 弟兄姊妹，耶穌為我們開闢了一條又新又活的路，使我們可以靠著祂的血穿過幔子，就是祂的身體，坦然進入至聖所。</span>
<span className="v" id="v21" data-v="21" data-xref="希伯來書 2:17; 希伯來書 4:14–16; 希伯來書 8:1"> 並且，我們有一位大祭司管理上帝的家，</span>
<span className="v" id="v22" data-v="22" data-xref="以西結書 36:25; 約翰福音 3:5; 以弗所書 5:26"> 祂潔淨了我們被罪困擾的良心，用清水洗淨了我們的身體。因此，我們要信心十足、真誠地到上帝面前。</span>
<span className="v" id="v23" data-v="23" data-xref="帖撒羅尼迦前書 5:24; 哥林多前書 1:9; 帖撒羅尼迦後書 3:3"> 我們要堅定不移地持守我們所認定的盼望，因為賜應許的那位是信實的。</span>
<span className="v" id="v24" data-v="24" data-xref="帖撒羅尼迦前書 5:11; 約翰一書 3:18; 希伯來書 13:1"> 我們要想辦法彼此相顧，激發愛心，勉勵行善。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行傳 2:42; 帖撒羅尼迦前書 5:11; 馬太福音 18:20"> 不要像那些停止慣了的人一樣停止聚會，要互相鼓勵，既然知道主再來的日子近了，更要如此。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="彼得後書 2:20–22; 希伯來書 6:4–6; 約翰福音 9:41"> 因為我們知道了真理以後，若仍然故意犯罪，就再沒有贖罪祭了，</span>
<span className="v" id="v27" data-v="27" data-xref="以賽亞書 26:11; 希伯來書 2:3; 西番雅書 1:18"> 只有可怕的審判和燒滅敵對者的烈火等候我們。</span>
<span className="v" id="v28" data-v="28" data-xref="希伯來書 2:2; 申命記 19:15; 申命記 17:2–13"> 人違背摩西的律法，經兩三個人指證後，尚且被毫不留情地處死，</span>
<span className="v" id="v29" data-v="29" data-xref="希伯來書 6:6; 以弗所書 4:30; 以賽亞書 63:10"> 更何況人踐踏上帝的兒子，輕看那使人聖潔的立約之血，又藐視賜人恩典的聖靈？這等人該受多麼重的刑罰啊！</span>
<span className="v" id="v30" data-v="30" data-xref="申命記 32:35–36; 羅馬書 12:19; 那鴻書 1:2"> 我們知道上帝說過：「伸冤在我，我必報應。」<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="申命記32·35。">d</a></sup>祂又說：「主要審判祂的子民。」<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="申命記32·36；詩篇135·14。">e</a></sup></span>
<span className="v" id="v31" data-v="31" data-xref="馬太福音 10:28; 路加福音 12:5; 希伯來書 12:29"> 落在永活上帝的手中是可怕的！</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="希伯來書 6:4; 希伯來書 12:4; 提摩太後書 2:3–13"> 你們要回想當初的日子，那時你們蒙了光照以後，忍受了各種苦難的煎熬。</span>
<span className="v" id="v33" data-v="33" data-xref="哥林多前書 4:9; 腓立比書 4:14; 希伯來書 11:36"> 有時候，你們在眾目睽睽之下被辱罵，受迫害；有時候，你們和遭受這樣苦難的人相依為伴。</span>
<span className="v" id="v34" data-v="34" data-xref="彼得前書 1:4; 提摩太後書 1:16; 馬太福音 5:11–12"> 你們體恤那些坐牢的人，即使你們的家業被搶奪，仍然甘心忍受，因為你們知道自己有更美的、永遠長存的家業。</span>
<span className="v" id="v35" data-v="35" data-xref="哥林多前書 15:58; 加拉太書 6:8–10; 希伯來書 3:6"> 所以切勿失去勇敢的心，因為勇敢的心會給你們帶來大賞賜。</span>
<span className="v" id="v36" data-v="36" data-xref="希伯來書 12:1; 詩篇 37:7; 雅各書 5:7–11"> 你們需要堅忍到底，這樣你們遵行了上帝的旨意後，便可以得到祂的應許。</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="雅各書 5:7–9; 哈巴谷書 2:3–4; 路加福音 18:8"> 因為「將要來臨的那位很快要來了，絕不遲延。<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="以賽亞書26·20；哈巴谷書2·3、4。">f</a></sup></span>
<span className="v" id="v38" data-v="38" data-xref="加拉太書 3:11; 哈巴谷書 2:4; 羅馬書 1:17"> 屬我的義人必靠信心而活。他若畏縮退後，我必不喜悅他。」<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="哈巴谷書2·3、4。">g</a></sup></span>
<span className="v" id="v39" data-v="39" data-xref="約翰一書 5:5; 彼得前書 1:5; 馬可福音 16:16"> 但我們都不是退後走向滅亡的人，而是因為有信心而靈魂得救的人。</span>
</div>
</div>

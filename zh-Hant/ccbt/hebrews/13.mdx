## 做上帝喜悅的事

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="約翰一書 4:20–1; 彼得前書 3:8; 彼得前書 1:22"> 你們要繼續彼此相愛，情同手足。</span>
<span className="v" id="v2" data-v="2" data-xref="馬太福音 25:35; 創世記 18:1–3; 彼得前書 4:9"> 不要忘記款待客旅，因為曾經有人接待客旅時不知不覺接待了天使。</span>
<span className="v" id="v3" data-v="3" data-xref="馬太福音 25:36; 希伯來書 10:34; 羅馬書 12:15"> 要設身處地地顧念那些被囚禁的人，要感同身受地顧念那些被惡待的人。</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 2:24; 箴言 5:15–23; 加拉太書 5:19"> 人人都要尊重婚姻，不可玷污婚床，因為上帝必審判淫亂和通姦的人。</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 31:8; 約書亞記 1:5; 申命記 31:6"> 不要貪愛錢財，要對自己擁有的知足，因為上帝說過：<br /><span className="pl pl-1">「我永不撇下你，也不離棄你。」</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="申命記31·6。">a</a></sup></span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 118:6–9; 以賽亞書 41:10; 羅馬書 8:31"> 這樣，我們可以放膽地說：<br /><span className="pl pl-1">「主是我的幫助，</span><br /><span className="pl pl-1">我必不懼怕，</span><br /><span className="pl pl-1">人能把我怎麼樣？」</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="詩篇118·6、7。">b</a></sup></span>
<span className="v" id="v7" data-v="7" data-xref="帖撒羅尼迦前書 5:12–13; 希伯來書 13:17; 腓立比書 3:17"> 你們要記住從前帶領你們、把上帝的道傳給你們的人，留心觀察他們行事為人的結果，效法他們的信心。</span>
<span className="v" id="v8" data-v="8" data-xref="瑪拉基書 3:6; 雅各書 1:17; 啟示錄 1:8"> 耶穌基督昨日、今日、直到永遠都不改變。</span>
<span className="v" id="v9" data-v="9" data-xref="以弗所書 4:14; 提摩太前書 6:3–5; 以弗所書 5:6"> 你們不要被五花八門的異端邪說勾引了去，因為心中得到力量是靠上帝的恩典，而不是靠飲食上的規條，這些規條從未使遵守的人受益。</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多前書 5:7–8; 哥林多前書 10:20; 哥林多前書 9:13"> 我們有一座祭壇，壇上的祭物是那些在聖幕裡供職的人沒有權利吃的。</span>
<span className="v" id="v11" data-v="11" data-xref="利未記 16:27; 出埃及記 29:14; 利未記 9:11"> 大祭司把祭牲的血帶進至聖所作贖罪祭，而祭牲的身體則在營外燒掉。</span>
<span className="v" id="v12" data-v="12" data-xref="希伯來書 9:12–14; 約翰福音 19:17–18; 使徒行傳 7:58"> 同樣，耶穌為了用自己的血使祂的子民聖潔，也在城門外受難。</span>
<span className="v" id="v13" data-v="13" data-xref="希伯來書 11:26; 彼得前書 4:14–16; 使徒行傳 5:41"> 因此，讓我們也走出營外到祂那裡，忍受祂所忍受的凌辱吧！</span>
<span className="v" id="v14" data-v="14" data-xref="腓立比書 3:20; 歌羅西書 3:1–3; 希伯來書 11:12–16"> 我們在地上沒有永遠的城，我們尋求的是那將來的城。</span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 107:21–22; 詩篇 50:14; 羅馬書 12:1"> 讓我們靠著耶穌，常常開口以頌讚為祭獻給上帝，這是承認主名的人<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="「承認主名的人」希臘文是「承認主名的嘴唇」。">c</a></sup>所結的果子。</span>
<span className="v" id="v16" data-v="16" data-xref="帖撒羅尼迦後書 3:13; 加拉太書 6:10; 羅馬書 12:13"> 不可忘記行善和幫補別人，因為這樣的祭是上帝所喜悅的。</span>
<span className="v" id="v17" data-v="17" data-xref="帖撒羅尼迦前書 5:12–13; 提摩太前書 5:17; 希伯來書 13:7"> 要順服和聽從引導你們的人，因為他們為你們的靈魂時刻警醒，將來要向上帝交賬。你們要讓他們懷著喜樂盡此職責，而非充滿憂愁，那樣對你們毫無益處。</span>
<span className="v" id="v18" data-v="18" data-xref="帖撒羅尼迦前書 5:25; 帖撒羅尼迦後書 3:1; 歌羅西書 4:3"> 請為我們禱告，因為我們自信良心無愧，凡事都願意遵行正道。</span>
<span className="v" id="v19" data-v="19" data-xref="腓利門書 1:22; 羅馬書 1:10–12; 羅馬書 15:31–32"> 也請你們特別為我禱告，使我能夠早日回到你們那裡。</span>
</div>
</div>

## 祝福與問安

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="約翰福音 10:11; 希伯來書 10:22; 詩篇 23:1"> 願賜平安的上帝，就是那位憑著立永恆之約的血使群羊的大牧人我主耶穌從死裡復活的上帝，</span>
<span className="v" id="v21" data-v="21" data-xref="腓立比書 2:13; 帖撒羅尼迦後書 2:17; 腓立比書 4:13"> 在各樣善事上成全你們，好使你們遵行祂的旨意，並藉著耶穌基督在你們心中動工，使你們做祂喜悅的事！願榮耀歸給上帝，直到永永遠遠。阿們！</span>
<span className="v" id="v22" data-v="22" data-xref="希伯來書 3:1; 彼得前書 5:12; 哥林多後書 6:1"> 弟兄姊妹，我簡短地寫信給你們，希望你們聽我勸勉的話。</span>
<span className="v" id="v23" data-v="23" data-xref="腓利門書 1:1; 帖撒羅尼迦前書 3:2; 提摩太後書 1:8"> 你們知道，我們的弟兄提摩太已經被釋放了。如果他很快來到，我會與他一起去看你們。</span>
<span className="v" id="v24" data-v="24" data-xref="希伯來書 13:7; 希伯來書 13:17; 使徒行傳 18:2"> 請問候所有帶領你們的人以及眾聖徒。從義大利來的人也問候你們。</span>
<span className="v" id="v25" data-v="25" data-xref="歌羅西書 4:18; 提摩太後書 4:22; 提多書 3:15"> 願恩典與你們眾人同在！</span>
</div>
</div>

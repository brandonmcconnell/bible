<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="希伯來書 5:12–14; 哥林多後書 7:1; 希伯來書 9:14"> 所以我們要離開有關基督的初級道理，努力邁向成熟，而不是再次打基礎：教導為致死的行為悔改、信靠上帝、</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多前書 15:13–57; 使徒行傳 17:31–32; 羅馬書 6:3–5"> 各種洗禮、按手禮、死人復活、永遠的審判等道理。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行傳 18:21; 哥林多前書 16:7; 哥林多前書 4:19"> 上帝若許可，我們會這樣做。</span>
<span className="v" id="v4" data-v="4" data-xref="希伯來書 10:26–29; 彼得後書 2:20–22; 馬太福音 5:13"> 有些人曾蒙上帝光照，嘗過天賜恩典的滋味，有份於聖靈，</span>
<span className="v" id="v5" data-v="5" data-xref="彼得前書 2:3; 路加福音 8:13; 馬太福音 13:20–21"> 嘗過上帝之道的甘美，領悟到永世的權能，</span>
<span className="v" id="v6" data-v="6" data-xref="彼得後書 2:21; 希伯來書 10:29; 希伯來書 6:4"> 卻背棄了真道，讓他們重新悔改是不可能的。因為他們是把上帝的兒子重新釘在十字架上，使祂公開受辱，結果自招損害。</span>
<span className="v" id="v7" data-v="7" data-xref="何西阿書 10:12; 以賽亞書 44:3; 詩篇 65:9–13"> 一塊經常受到雨水滋潤的田地若為耕種的人長出莊稼來，就蒙上帝賜福；</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 3:17–18; 約翰福音 15:6; 路加福音 13:7–9"> 若長出來的盡是荊棘和蒺藜，就毫無價值，會面臨被咒詛的危險，最後必遭焚燒。</span>
<span className="v" id="v9" data-v="9" data-xref="希伯來書 10:39; 哥林多後書 7:10; 希伯來書 6:4–6"> 親愛的弟兄姊妹，雖然我們這樣說，卻深信你們的光景比這強，有得救的表現。</span>
<span className="v" id="v10" data-v="10" data-xref="馬太福音 10:42; 希伯來書 13:16; 加拉太書 6:10"> 因為上帝並非不公義，以致忘記你們為祂所做的工作，以及你們過去和現在服侍聖徒所表現的愛心。</span>
<span className="v" id="v11" data-v="11" data-xref="彼得後書 1:5–8; 希伯來書 3:6; 羅馬書 5:2–5"> 願你們各人從始至終表現出同樣的殷勤，以便對所盼望的有完全的把握。</span>
<span className="v" id="v12" data-v="12" data-xref="希伯來書 13:7; 希伯來書 10:36; 約翰一書 2:25"> 這樣，你們就不致懶散，可以效法那些憑信心和忍耐承受應許的人。</span>

## 上帝的應許可靠

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="創世記 22:15–18; 路加福音 1:73; 耶利米書 22:5"> 當初，上帝賜給亞伯拉罕應許的時候，因為沒有比自己更大的可以憑著起誓，就憑自己起誓說：</span>
<span className="v" id="v14" data-v="14" data-xref="創世記 22:17; 申命記 1:10; 尼希米記 9:23"> 「我必賜福給你，使你子孫繁盛。」<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="創世記22·17。">a</a></sup></span>
<span className="v" id="v15" data-v="15" data-xref="創世記 12:2–3; 羅馬書 4:17–25; 出埃及記 1:7"> 亞伯拉罕經過耐心的等待，得到了上帝的應許。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 22:11; 希伯來書 6:13; 創世記 31:53"> 人總是指著比自己更大的起誓，並用誓言作保證來了結各種爭論。</span>
<span className="v" id="v17" data-v="17" data-xref="希伯來書 6:18; 箴言 19:21; 以賽亞書 55:11"> 同樣，上帝為要向承受應許的人顯明祂的旨意絕不更改，就用誓言向他們保證。</span>
<span className="v" id="v18" data-v="18" data-xref="民數記 23:19; 提多書 1:2; 撒母耳記上 15:29"> 上帝絕不說謊，祂賜下永不改變的應許和誓言，使我們這些尋找避難所的人大得鼓勵，持定擺在前面的盼望。</span>
<span className="v" id="v19" data-v="19" data-xref="詩篇 43:5; 羅馬書 5:5–10; 希伯來書 9:7"> 我們有這盼望作我們靈魂的錨，既安穩又可靠，一直通往幔子後面的至聖所。</span>
<span className="v" id="v20" data-v="20" data-xref="希伯來書 4:14; 希伯來書 3:1; 希伯來書 5:6"> 耶穌照麥基洗德的模式成了永遠的大祭司，祂是先行者，已經替我們進入了至聖所。</span>
</div>

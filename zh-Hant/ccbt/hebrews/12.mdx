## 仰望耶穌

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="提摩太後書 4:7; 哥林多前書 9:24–27; 腓立比書 2:16"> 既然有這麼多見證人像雲彩一般圍繞著我們，我們就要放下一切重擔，擺脫容易纏累我們的罪，以堅忍的心奔跑我們前面的賽程，</span>
<span className="v" id="v2" data-v="2" data-xref="彌迦書 7:7; 彼得前書 3:18; 彼得前書 2:23–24"> 定睛仰望為我們的信心創始成終的耶穌。祂為了擺在前面的喜樂，就輕看羞辱，忍受了十字架的痛苦，如今已坐在上帝寶座的右邊。</span>
<span className="v" id="v3" data-v="3" data-xref="加拉太書 6:9; 哥林多後書 4:16; 啟示錄 2:3"> 你們要思想這位忍受罪人如此頂撞的主，免得疲倦灰心。</span>
</div>
</div>

## 愛的管教

<div className="bt">
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="哥林多前書 10:13; 啟示錄 2:13; 希伯來書 10:32–34"> 其實你們與罪惡搏鬥，還沒有抵擋到流血的地步。</span>
<span className="v" id="v5" data-v="5" data-xref="箴言 3:11–12; 約伯記 5:17–18; 啟示錄 3:19"> 你們難道忘了那像勸勉兒子一樣勸勉你們的話嗎？「孩子啊，不可輕視主的管教，被祂責備的時候也不要灰心。</span>
<span className="v" id="v6" data-v="6" data-xref="啟示錄 3:19; 箴言 3:12; 詩篇 119:75"> 因為主管教祂所愛的人，責罰<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「責罰」希臘文是「鞭打」之意。">a</a></sup>祂所收納的兒子。」<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="箴言3·11、12。">b</a></sup></span>
<span className="v" id="v7" data-v="7" data-xref="箴言 19:18; 申命記 8:5; 箴言 13:24"> 你們要忍受管教，上帝對待你們如同對待自己的兒女。哪有兒女不受父親管教的呢？</span>
<span className="v" id="v8" data-v="8" data-xref="希伯來書 12:6; 彼得前書 5:9–10; 詩篇 73:1"> 做兒女的都會受管教，如果沒人管教你們，那你們就是私生子，不是兒女。</span>
<span className="v" id="v9" data-v="9" data-xref="民數記 16:22; 民數記 27:16; 以賽亞書 42:5"> 再者，我們的生身父親管教我們，我們尚且敬重他們，何況是萬靈之父上帝管教我們，我們豈不更要順服祂並得到生命嗎？</span>
<span className="v" id="v10" data-v="10" data-xref="彼得後書 1:4; 利未記 11:44–45; 提多書 2:14"> 我們的生身父親是按自己以為好的標準暫時管教我們，但上帝是為了我們的益處而管教我們，使我們可以在祂的聖潔上有份。</span>
<span className="v" id="v11" data-v="11" data-xref="羅馬書 5:3–5; 哥林多後書 4:17; 希伯來書 12:5–6"> 被管教的滋味絕不好受，當時都很痛苦，但事後那些從管教中得到歷練的人會收穫公義和平安的果子。</span>
<span className="v" id="v12" data-v="12" data-xref="以賽亞書 35:3; 希伯來書 12:3; 帖撒羅尼迦前書 5:14"> 所以，你們要舉起下垂的手，挺直發痠的腿，</span>
<span className="v" id="v13" data-v="13" data-xref="箴言 4:26–27; 以賽亞書 35:3; 加拉太書 6:1"> 修直腳下的路，<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="箴言4·26。">c</a></sup>使瘸腿的人不致扭傷腳，反得痊癒。</span>
</div>
</div>

## 切勿違背上帝

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="哥林多後書 7:1; 彼得前書 1:15–16; 帖撒羅尼迦前書 4:7"> 你們要盡力與大家和睦相處，並要追求聖潔的生活，因為不聖潔的人不能見主。</span>
<span className="v" id="v15" data-v="15" data-xref="希伯來書 3:12; 申命記 29:18; 加拉太書 5:4"> 你們要謹慎，免得有人失去上帝的恩典，也免得有人長出苦毒的根擾亂你們，玷污眾人。</span>
<span className="v" id="v16" data-v="16" data-xref="創世記 25:31–34; 哥林多前書 6:15–20; 啟示錄 22:15"> 你們要謹慎，免得有人像以掃那樣淫亂、不敬虔。他為了一時的口腹之慾，賣了自己長子的名分。</span>
<span className="v" id="v17" data-v="17" data-xref="箴言 1:24–31; 馬太福音 25:11–12; 馬太福音 7:23"> 你們知道，他後來想要承受父親對長子的祝福，卻遭到拒絕，雖然聲淚俱下，終無法使父親回心轉意。</span>
<span className="v" id="v18" data-v="18" data-xref="申命記 4:11; 出埃及記 24:17; 出埃及記 20:18"> 你們並非來到那座摸得到，有火焰、烏雲、黑暗、狂風、</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 18:16; 哥林多前書 15:52; 申命記 4:12"> 號角聲和說話聲的西奈山。聽見這些聲音的人都哀求不要再向他們說話了，</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及記 19:12–13; 出埃及記 19:16; 加拉太書 3:10"> 因為他們承擔不了上帝的命令：「即便是動物靠近這山，也要用石頭打死牠！」<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="出埃及記19·12、13。">d</a></sup></span>
<span className="v" id="v21" data-v="21" data-xref="出埃及記 19:16; 申命記 9:19; 以賽亞書 6:3–5"> 那情景實在可怕，就連摩西也說：「我嚇得發抖。」<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="申命記9·19。">e</a></sup></span>
<span className="v" id="v22" data-v="22" data-xref="加拉太書 4:26; 腓立比書 3:20; 啟示錄 14:1"> 但你們是來到了錫安山，永活上帝的城邑，天上的耶路撒冷，千萬天使歡聚的地方。</span>
<span className="v" id="v23" data-v="23" data-xref="雅各書 1:18; 希伯來書 11:40; 路加福音 10:20"> 這裡有名字記錄在天上的眾長子的教會，有審判眾人的上帝和已達到純全的義人的靈魂，</span>
<span className="v" id="v24" data-v="24" data-xref="希伯來書 9:15; 希伯來書 11:28; 希伯來書 11:4"> 還有新約的中保耶穌和祂所灑的血。這血比亞伯的血發出更美的信息。</span>
<span className="v" id="v25" data-v="25" data-xref="希伯來書 8:5; 申命記 30:17; 希伯來書 2:1–3"> 你們要謹慎，切勿拒絕對你們說話的上帝。因為以色列人違背了在地上警戒他們的人，尚且逃脫不了懲罰，何況我們違背從天上警戒我們的上帝呢？</span>
<span className="v" id="v26" data-v="26" data-xref="哈該書 2:6–7; 以賽亞書 13:13; 出埃及記 19:18"> 那時上帝的聲音震動了大地，但現在祂應許說：「再一次，我不單要震動地，還要震動天。」<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="哈該書2·6。">f</a></sup></span>
<span className="v" id="v27" data-v="27" data-xref="哥林多前書 7:31; 馬太福音 24:35; 彼得後書 3:10–11"> 「再一次」這句話是指上帝要挪去可以被震動的受造之物，使不能被震動的可以長存。</span>
<span className="v" id="v28" data-v="28" data-xref="羅馬書 12:1–2; 希伯來書 13:15; 但以理書 2:44"> 那麼，既然我們承受的是一個不能被震動的國度，就要感恩，用虔誠和敬畏的心事奉上帝，討祂喜悅。</span>
<span className="v" id="v29" data-v="29" data-xref="申命記 4:24; 申命記 9:3; 希伯來書 10:27"> 因為我們的上帝是烈火。<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="申命記4·24。">g</a></sup></span>
</div>
</div>

## 大祭司麥基洗德

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 14:18–20; 詩篇 57:2; 希伯來書 6:20"> 這位麥基洗德是撒冷王，也是至高上帝的祭司。當年亞伯拉罕殺敗眾王凱旋的時候，麥基洗德迎上去為他祝福，</span>
<span className="v" id="v2" data-v="2" data-xref="民數記 18:21; 詩篇 85:10–11; 撒母耳記上 8:17"> 亞伯拉罕把所得財物的十分之一給了他。麥基洗德這名字的原意是「公義之王」，後來他又被稱為撒冷王，意思是「和平之王」。</span>
<span className="v" id="v3" data-v="3" data-xref="希伯來書 7:17; 希伯來書 7:23–28; 出埃及記 6:20–27"> 他沒有父母，沒有族譜，生命無始無終，他跟上帝的兒子相似，永遠擔任祭司的職分。</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 14:20; 使徒行傳 2:29; 使徒行傳 7:8–9"> 試想，連我們的祖先亞伯拉罕都將戰利品的十分之一給了他，可見他是何等的尊貴！</span>
<span className="v" id="v5" data-v="5" data-xref="利未記 27:30–33; 歷代志下 31:4–6; 民數記 18:21–32"> 按照摩西律法，那些做祭司的利未後裔可以照例向百姓，就是自己的同胞收取十分之一，儘管他們也是亞伯拉罕的後裔。</span>
<span className="v" id="v6" data-v="6" data-xref="羅馬書 4:13; 希伯來書 7:3–4; 創世記 13:14–17"> 但這位與他們並非同族的麥基洗德，不單接受了亞伯拉罕給他的十分之一，還為承受應許的亞伯拉罕祝福。</span>
<span className="v" id="v7" data-v="7" data-xref="歷代志下 30:27; 創世記 48:15–20; 提摩太前書 3:16"> 毫無疑問，那為人祝福的總比領受祝福的位分大。</span>
<span className="v" id="v8" data-v="8" data-xref="希伯來書 6:20; 希伯來書 5:6; 啟示錄 1:18"> 那些收取十分之一的利未祭司都是會死的人，但那位收取十分之一的麥基洗德被證明仍然活著。</span>
<span className="v" id="v9" data-v="9" data-xref="羅馬書 5:12; 創世記 14:20; 希伯來書 7:4"> 也可以說，連接受十分之一奉獻的利未也透過亞伯拉罕向麥基洗德納了十分之一。</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 35:11; 希伯來書 7:5; 創世記 46:26"> 因為亞伯拉罕遇見麥基洗德時，利未還在他祖先的身體裡。</span>
</div>
</div>

## 大祭司耶穌

<div className="bt">
<div className="bp poetry">
<span className="v" id="v11" data-v="11" data-xref="希伯來書 8:7; 加拉太書 2:21; 加拉太書 4:9"> 以色列人在利未祭司制度的基礎上承受律法，如果通過這個祭司制度可以達到純全，又何必照麥基洗德的模式而不是亞倫的模式，另外興起一位祭司呢？</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米書 31:31–34; 以賽亞書 66:21; 以西結書 16:61"> 既然這祭司制度更改了，律法也必須更改。</span>
<span className="v" id="v13" data-v="13" data-xref="希伯來書 7:11; 希伯來書 7:14; 民數記 17:5"> 因為這裡所說的這位祭司屬於別的支派，那支派裡從來沒有在祭壇前供職的祭司。</span>
<span className="v" id="v14" data-v="14" data-xref="彌迦書 5:2; 以賽亞書 11:1; 路加福音 3:33"> 顯然，我們的主屬於猶大支派，摩西從來沒有說這個支派會出祭司。</span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 110:4; 希伯來書 7:17–21; 希伯來書 7:3"> 如果照麥基洗德的模式另外興起一位祭司，祂做祭司不是照律法要求的血統關係，而是照不能朽壞之生命的大能，事情就更加清楚了。</span>
<span className="v" id="v17" data-v="17" data-xref="詩篇 110:4; 希伯來書 5:6; 希伯來書 7:21"> 因為有一處經文為祂作見證說：「你照麥基洗德的模式永遠做祭司。」<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="詩篇110·4。">a</a></sup></span>
<span className="v" id="v18" data-v="18" data-xref="羅馬書 8:3; 使徒行傳 13:39; 加拉太書 4:9"> 以前的條例由於本身的弱點和無用被廢除了，</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行傳 13:39; 希伯來書 4:16; 希伯來書 9:9"> 因為律法並沒有使什麼變得純全。但如今有了一個更美好的盼望，我們憑這個盼望來到上帝面前。</span>
<span className="v" id="v20" data-v="20" data-xref="民數記 18:7; 希伯來書 5:6; 詩篇 110:4"> 此外，耶穌做祭司還有誓言作保證，其他人做祭司卻沒有誓言作保證。</span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 110:4; 希伯來書 7:17; 希伯來書 6:16–18"> 上帝起誓立耶穌為祭司，說：<br /><span className="pl pl-1">「主起了誓，絕不反悔，</span><br /><span className="pl pl-1">你永遠做祭司。」</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="詩篇110·4。">b</a></sup></span>
<span className="v" id="v22" data-v="22" data-xref="哥林多前書 11:25; 創世記 44:32; 希伯來書 8:6–12"> 這誓言使耶穌成了更美之約的保證人。</span>
<span className="v" id="v23" data-v="23" data-xref="尼希米記 12:10–11; 歷代志上 6:3–14; 希伯來書 7:8"> 以前做祭司的人數極多，但因為受死亡的限制，都不能長久擔任聖職。</span>
<span className="v" id="v24" data-v="24" data-xref="約翰福音 12:34; 希伯來書 7:28; 以賽亞書 9:6–7"> 然而，耶穌永遠活著，祂的祭司職位也永不更改。</span>
<span className="v" id="v25" data-v="25" data-xref="羅馬書 8:34; 約翰一書 2:1–2; 提摩太前書 2:5"> 所以祂能完全拯救那些靠著祂來到上帝面前的人，因為祂永遠活著，為他們祈求。</span>
<span className="v" id="v26" data-v="26" data-xref="哥林多後書 5:21; 希伯來書 4:14–15; 彼得前書 2:22"> 我們所需要的，正是這樣一位聖潔無瑕、純全無過、遠離罪惡、超越諸天的大祭司。</span>
<span className="v" id="v27" data-v="27" data-xref="希伯來書 9:28; 希伯來書 9:12; 希伯來書 9:14"> 祂無需像其他大祭司那樣每天先為自己的罪獻祭，然後為百姓的罪獻祭，因為祂一次獻上自己的生命，便永遠完成了贖罪的工作。</span>
<span className="v" id="v28" data-v="28" data-xref="希伯來書 2:10; 希伯來書 7:21; 希伯來書 1:2"> 根據律法所立的大祭司都有人的軟弱，但律法之後憑誓言所立的大祭司聖子永遠純全。</span>
</div>

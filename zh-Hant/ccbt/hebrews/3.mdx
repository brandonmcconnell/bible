## 耶穌超越摩西

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="提摩太後書 1:9; 腓立比書 3:14; 希伯來書 4:14–15"> 因此，同蒙天召的聖潔弟兄姊妹，你們應當仔細思想那位我們公認為特使和大祭司的耶穌。</span>
<span className="v" id="v2" data-v="2" data-xref="民數記 12:7; 提摩太前書 3:15; 以弗所書 2:22"> 祂向委任祂的上帝盡忠，就好像摩西向上帝的全家盡忠一樣。</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多前書 3:9; 彼得前書 2:5–7; 撒迦利亞書 6:12–13"> 然而祂卻比摩西配得更大的榮耀，就好像建造房子的人比房子更尊貴一樣。</span>
<span className="v" id="v4" data-v="4" data-xref="希伯來書 3:3; 希伯來書 1:2; 以斯帖記 2:10"> 因為房子都是人建造的，但建造萬物的是上帝。</span>
<span className="v" id="v5" data-v="5" data-xref="民數記 12:7; 希伯來書 3:2; 出埃及記 14:31"> 摩西以僕人的身分向上帝的全家盡忠，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="民數記12·7。">a</a></sup>為將來要宣告的事作見證。</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多後書 6:16; 哥林多前書 3:16; 希伯來書 10:35"> 但基督是以兒子的身分忠心治理上帝的家。我們若持定信念和引以為榮的盼望，就是祂的家了。</span>
</div>
</div>

## 不可存剛硬的心

<div className="bt">
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="詩篇 95:7–11; 希伯來書 3:15; 以賽亞書 55:3"> 因此，正如聖靈說：<br /><span className="pl pl-1">「你們今日若聽見祂的聲音，</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="箴言 28:14; 出埃及記 17:7; 撒迦利亞書 7:11–12"> <span className="pl pl-1">不可心裡頑固，</span><br /><span className="pl pl-1">像從前在曠野試探祂、悖逆祂一樣。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="使徒行傳 7:36; 申命記 4:9; 出埃及記 19:4"> <span className="pl pl-1">你們的祖先雖然在那裡觀看我的作為四十年之久，</span><br /><span className="pl pl-1">卻仍然試我、探我。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 95:10; 帖撒羅尼迦後書 2:10–12; 詩篇 67:2"> <span className="pl pl-1">所以，我向那世代的人發怒，</span><br /><span className="pl pl-1">說：『他們心向歧途，</span><br /><span className="pl pl-1">不認識我的道路。』</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="申命記 1:34–35; 希伯來書 4:3; 民數記 32:10–13"> <span className="pl pl-1">因此我憤然起誓說，</span><br /><span className="pl pl-1">『他們絕不可進入我的安息。』</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="詩篇95·7‑11。">b</a></sup><br /><span className="pl pl-1">」</span></span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="耶利米書 17:5; 耶利米書 7:24; 耶利米書 17:9"> 弟兄姊妹，要謹慎，免得你們當中有人心存惡念，不肯相信，背棄了永活的上帝。</span>
<span className="v" id="v13" data-v="13" data-xref="帖撒羅尼迦前書 5:11; 希伯來書 10:24–25; 提摩太後書 4:2"> 趁著還有今日，要天天互相勸勉，免得有人被罪迷惑，心裡變得剛硬。</span>
<span className="v" id="v14" data-v="14" data-xref="希伯來書 3:6; 希伯來書 6:11; 希伯來書 12:10"> 如果我們將起初的信念堅持到底，便在基督裡有份了。</span>
</div>
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="希伯來書 3:7–8; 詩篇 95:7; 希伯來書 10:38"> 聖經上說：<br /><span className="pl pl-1">「你們今日若聽見祂的聲音，</span><br /><span className="pl pl-1">不可心裡頑固，像從前悖逆祂一樣。」</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="詩篇95·7、8。">c</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="民數記 14:2; 民數記 14:30; 民數記 26:65"> 聽見祂的聲音卻又悖逆祂的是誰呢？不就是摩西從埃及領出來的那些人嗎？</span>
<span className="v" id="v17" data-v="17" data-xref="民數記 14:29; 民數記 26:64–65; 民數記 14:32–33"> 四十年之久惹上帝發怒的是誰呢？不就是那些犯罪作惡並倒斃在曠野的人嗎？</span>
<span className="v" id="v18" data-v="18" data-xref="民數記 14:30; 希伯來書 4:6; 申命記 1:34–35"> 上帝起誓不准誰進入祂的安息呢？不就是那些不肯順從的人嗎？</span>
<span className="v" id="v19" data-v="19" data-xref="猶大書 1:5; 約翰福音 3:36; 馬可福音 16:16"> 可見，他們不能進入上帝的安息是因為不信的緣故。</span>
</div>
</div>

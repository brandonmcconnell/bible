## 劃時代的啟示

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="彼得後書 1:20–21; 約珥書 2:28; 民數記 12:6–8"> 在古代，上帝曾藉著先知多次多方向我們的祖先說話，</span>
<span className="v" id="v2" data-v="2" data-xref="約翰福音 1:3; 哥林多前書 8:6; 歌羅西書 1:16–18"> 在這世界的末期，祂又藉著自己的兒子向我們說話。上帝早已立祂承受萬物，並藉著祂創造了宇宙萬物。</span>
<span className="v" id="v3" data-v="3" data-xref="歌羅西書 1:15–17; 啟示錄 4:11; 約翰福音 14:9–10"> 祂是上帝榮耀的光輝，是上帝本體的真像。祂用自己充滿能力的話語維繫萬物。祂洗淨了世人的罪之後，便坐在天上至高上帝的右邊。</span>
<span className="v" id="v4" data-v="4" data-xref="以弗所書 1:21; 腓立比書 2:9–11; 彼得前書 3:22"> 祂既承受了比天使更高的名，就遠超越天使。</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 2:7; 使徒行傳 13:33; 希伯來書 5:5"> 上帝從未對任何一個天使說：<br /><span className="pl pl-1">「你是我的兒子，我今日成為你父親。」</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="詩篇2·7。">a</a></sup>或說：<br /><span className="pl pl-1">「我要作祂的父親，祂要作我的兒子。」</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="撒母耳記下7·14；歷代志上17·13。">b</a></sup></span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 97:7; 歌羅西書 1:18; 申命記 32:43"> 上帝差遣祂的長子到世上來時，卻說：<br /><span className="pl pl-1">「上帝的天使都要敬拜祂。」</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="申命記32·43。">c</a></sup></span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 104:4; 希伯來書 1:14; 列王紀下 6:17"> 上帝提到天使的時候，只是說：<br /><span className="pl pl-1">「祂以風為使者，以火焰為僕役。」</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="詩篇104·4。">d</a></sup></span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 45:6–7; 以賽亞書 9:6–7; 耶利米書 23:5–6"> 關於這兒子，祂卻說：<br /><span className="pl pl-1">「上帝啊，你的寶座永遠長存，</span><br /><span className="pl pl-1">你以公義的杖執掌王權。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 45:7; 詩篇 23:5; 以賽亞書 61:3"> <span className="pl pl-1">你喜愛公義，憎惡邪惡。</span><br /><span className="pl pl-1">所以上帝，你的上帝，</span><br /><span className="pl pl-1">用喜樂之油膏你，使你超過同伴。」</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="詩篇45·6、7。">e</a></sup></span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 102:25–27; 創世記 1:1; 約翰福音 1:1–3"> 此外又說：<br /><span className="pl pl-1">「主啊，太初你奠立大地的根基，</span><br /><span className="pl pl-1">親手創造諸天。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="以賽亞書 51:6; 馬可福音 13:31; 路加福音 21:33"> <span className="pl pl-1">天地都要消亡，但你永遠長存。</span><br /><span className="pl pl-1">天地都會像外衣漸漸破舊，</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 102:26–27; 希伯來書 13:8; 約翰福音 8:58"> <span className="pl pl-1">你要把天地像外衣一樣捲起來。</span><br /><span className="pl pl-1">天地將如衣服一樣被更換，</span><br /><span className="pl pl-1">但你永遠不變，</span><br /><span className="pl pl-1">你的年日永無窮盡。」</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="詩篇102·25‑27。">f</a></sup></span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 110:1; 馬可福音 12:36; 馬太福音 22:44"> 上帝從未對任何一個天使說：<br /><span className="pl pl-1">「你坐在我的右邊，</span><br /><span className="pl pl-1">等我使你的仇敵成為你的腳凳。」</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="詩篇110·1。">g</a></sup></span>
<span className="v" id="v14" data-v="14" data-xref="詩篇 34:7; 詩篇 103:20–21; 詩篇 91:11–12"> 天使豈不都是服侍的靈，奉差遣為那些將要承受救恩的人服務嗎？</span>
</div>

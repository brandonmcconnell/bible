## 持守真道

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 8:15; 彼得後書 1:12–13; 箴言 7:1–2"> 因此，我們必須更加重視所聽的道，以免隨流漂去。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行傳 7:53; 加拉太書 3:19; 希伯來書 10:28"> 既然藉天使傳下來的話確鑿無誤，凡干犯、違背的人都受到了應有的報應，</span>
<span className="v" id="v3" data-v="3" data-xref="希伯來書 10:28–29; 希伯來書 12:25; 希伯來書 5:9"> 我們若忽略這麼大的救恩，怎能逃避懲罰呢？這救恩首先由主親口宣講出來，後來由聽見的人向我們證實了。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行傳 14:3; 以弗所書 1:5; 馬可福音 16:20"> 同時，上帝按自己的旨意，用神蹟、奇事、各樣的異能和聖靈的恩賜與他們一同作見證。</span>
</div>
</div>

## 救恩的元帥

<div className="bt">
<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="啟示錄 11:15; 彼得後書 3:13; 希伯來書 6:5"> 上帝並沒有把我們所談論的未來世界交給天使掌管。</span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 8:4–8; 詩篇 144:3; 約伯記 7:17–18"> 相反，有人在聖經中作見證說：<br /><span className="pl pl-1">「人算什麼，你竟顧念他？</span><br /><span className="pl pl-1">世人算什麼，你竟眷顧他？</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 8:5; 腓立比書 2:6–7"> <span className="pl pl-1">你使他暫時比天使低微一點，</span><br /><span className="pl pl-1">賜他榮耀和尊貴作冠冕，</span><br /><span className="pl pl-1">派他管理你所造的萬物，</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="約翰福音 13:3; 哥林多前書 15:27; 詩篇 8:6"> <span className="pl pl-1">使萬物降服在他腳下。」</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="詩篇8·4‑6。">a</a></sup>既然說了叫萬物都降服在人的管理之下，就沒有一樣例外。不過，我們到現在還沒有看到萬物都降服在人的管理之下，</span>
<span className="v" id="v9" data-v="9" data-xref="腓立比書 2:7–9; 啟示錄 5:9; 約翰一書 4:9–10"> 只看見耶穌暫時比天使低微一點，好靠著上帝的恩典為世人親嘗死亡的滋味。祂因為經歷死亡的痛苦而得到了尊貴和榮耀作冠冕。</span>
<span className="v" id="v10" data-v="10" data-xref="羅馬書 11:36; 使徒行傳 5:31; 路加福音 24:46"> 作為萬物的歸宿和本源的上帝，叫救恩的元帥耶穌經歷苦難而得以純全，以便帶領許多的兒女進入榮耀，這樣的安排是恰當的。</span>
<span className="v" id="v11" data-v="11" data-xref="希伯來書 10:10; 希伯來書 13:12; 希伯來書 10:14"> 因為使人聖潔的耶穌和那些得以聖潔的人都出自同一位父親，所以耶穌不以稱呼他們弟兄姊妹為恥。</span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 22:22; 詩篇 40:10; 約翰福音 18:20"> 祂說：<br /><span className="pl pl-1">「我要向眾弟兄傳揚你的名，</span><br /><span className="pl pl-1">在會眾當中歌頌你。」</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="詩篇22·22。">b</a></sup></span>
<span className="v" id="v13" data-v="13" data-xref="以賽亞書 8:17–18; 以賽亞書 12:2; 詩篇 91:2"> 又說：<br /><span className="pl pl-1">「我要倚靠祂。」</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="以賽亞書8·17。">c</a></sup>還說：<br /><span className="pl pl-1">「看啊，我和上帝賜給我的兒女都在這裡。」</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="以賽亞書8·18。">d</a></sup></span>
<span className="v" id="v14" data-v="14" data-xref="提摩太後書 1:10; 羅馬書 8:3; 歌羅西書 2:15"> 因為眾兒女都是血肉之軀，所以祂也同樣成為血肉之軀，以便親身經歷死亡，藉此摧毀掌握死亡權勢的魔鬼，</span>
<span className="v" id="v15" data-v="15" data-xref="羅馬書 8:15; 提摩太後書 1:7; 路加福音 1:74–75"> 釋放那些因怕死而一生做奴隸的人。</span>
<span className="v" id="v16" data-v="16" data-xref="加拉太書 3:29; 加拉太書 3:16; 羅馬書 4:16–25"> 很明顯，祂要救助的不是天使，而是亞伯拉罕的後裔。</span>
<span className="v" id="v17" data-v="17" data-xref="希伯來書 4:14–2; 腓立比書 2:7–8; 希伯來書 2:14"> 所以祂必須在每一方面都與祂的弟兄姊妹相同，以便在事奉上帝的事上成為一位仁慈忠信的大祭司，替眾人獻上贖罪祭。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前書 10:13; 希伯來書 4:15–16; 猶大書 1:24"> 祂經歷過受試探的痛苦，所以能幫助受試探的人。</span>
</div>

## 論信心

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多後書 5:7; 哥林多後書 4:18; 羅馬書 8:24–25"> 信心是對盼望的事有把握，對還沒看見的事很確定。</span>
<span className="v" id="v2" data-v="2" data-xref="希伯來書 11:39; 希伯來書 11:4"> 古人憑這樣的信心得到了讚許。</span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 33:6; 彼得後書 3:5; 約翰福音 1:3"> 因為信心，我們知道宇宙是藉著上帝的話造成的，所以看得見的是從看不見的造出來的。</span>
<span className="v" id="v4" data-v="4" data-xref="希伯來書 12:24; 創世記 4:3–5; 約翰一書 3:11–12"> 因為信心，亞伯向上帝獻的祭比該隱所獻的更美，他因此蒙了上帝的悅納，被稱為義人。他雖然死了，卻仍然藉著信心說話。</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 5:21–24; 猶大書 1:14; 希伯來書 11:6"> 因為信心，以諾被接到天上，沒有經歷死亡。世人找不到他，因為上帝已經把他接走了。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="創世記5·24。">a</a></sup>其實他在被接之前，已經被肯定為上帝喜悅的人。</span>
<span className="v" id="v6" data-v="6" data-xref="箴言 8:17; 耶利米書 29:13–14; 馬太福音 6:33"> 沒有信心的人得不到上帝的喜悅，因為來到上帝面前的人必須相信上帝存在，並相信祂會賞賜一切尋求祂的人。</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 6:13–1; 彼得前書 3:20; 以西結書 14:14"> 因為信心，挪亞在上帝指示他未來要發生的事之後，就懷著敬畏的心建造方舟挽救全家。他藉著信心定了那個世代的罪，並承受了因信而來的義。</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 12:1–4; 使徒行傳 7:2–4; 馬太福音 7:24–25"> 因為信心，亞伯拉罕聽到上帝的呼召後，就遵命前往他將要承受為產業的地方，但他出發的時候還不知道自己要去哪裡。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 12:8; 創世記 13:18; 創世記 13:3"> 因為信心，他像異鄉客旅一樣寄居在上帝應許給他的地方。他住在帳篷裡，與同受一個應許的以撒和雅各一樣。</span>
<span className="v" id="v10" data-v="10" data-xref="希伯來書 13:14; 腓立比書 3:20; 希伯來書 12:22"> 因為他盼望的是一座有根基的城，是由上帝設計、建造的。</span>
<span className="v" id="v11" data-v="11" data-xref="羅馬書 4:20–21; 希伯來書 10:23; 創世記 18:11–14"> 因為信心，撒拉過了生育年齡後仍然得到了孕育後代的能力，因為她認定賜她應許的上帝言出必行。</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 22:17; 創世記 32:12; 創世記 15:5"> 所以，從一個垂暮之年的人生出許多子孫，好像天上的星、海邊的沙那麼多。</span>
<span className="v" id="v13" data-v="13" data-xref="創世記 23:4; 詩篇 39:12; 希伯來書 11:27"> 這些人到死都滿懷信心。他們雖然沒有得到上帝所應許的，卻從遠處望見了，就歡然接受，承認自己在世上不過是異鄉客旅。</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多後書 4:18–7; 希伯來書 11:16; 希伯來書 13:14"> 他們抱這樣的態度，表明他們正在尋找一個家鄉。</span>
<span className="v" id="v15" data-v="15" data-xref="創世記 24:6–8; 創世記 12:10; 創世記 32:9–11"> 如果他們想念的是自己離開的家鄉，早就找機會回去了。</span>
<span className="v" id="v16" data-v="16" data-xref="希伯來書 13:14; 希伯來書 11:10; 腓立比書 3:20"> 然而，他們渴慕的是天上更美的家鄉。所以，上帝不以被他們稱為上帝為恥，因為祂已經為他們預備了一座城。</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 22:16; 創世記 22:1–12; 雅各書 2:21–24"> 因為信心，亞伯拉罕被試驗時，把以撒獻為祭物，承受應許的亞伯拉罕當時獻上了自己的獨生子。</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 21:12; 羅馬書 9:7; 創世記 17:19"> 關於這兒子，上帝曾說：「以撒生的才可算為你的後裔。」<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="創世記21·12。">b</a></sup></span>
<span className="v" id="v19" data-v="19" data-xref="羅馬書 4:17–21; 馬太福音 9:28; 以弗所書 3:20"> 他認定上帝能使死人復活，從象徵意義上說，他也確實從死亡中得回了以撒。</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 27:27–40; 創世記 28:2–3"> 因為信心，以撒指著將來的事為雅各和以掃祝福。</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 47:31–1; 創世記 48:5–22"> 因為信心，雅各在臨終之時分別為約瑟的兩個兒子祝福，並拄著拐杖敬拜上帝。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及記 13:19; 創世記 50:24–25; 約書亞記 24:32"> 因為信心，約瑟臨終之時提到以色列人將來要離開埃及，並交代要如何處理自己的骸骨。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及記 1:22; 出埃及記 1:16; 希伯來書 13:6"> 因為信心，摩西的父母在他出生後，見他長得俊美，就把他藏了三個月，不怕違抗王的命令。</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及記 2:10–11; 使徒行傳 7:21–24"> 因為信心，摩西長大成人後，拒絕做法老之女的兒子，</span>
<span className="v" id="v25" data-v="25" data-xref="詩篇 84:10; 提摩太後書 2:3–10; 約伯記 36:21"> 寧願與上帝的子民一同受苦，也不願享受一時的罪中之樂。</span>
<span className="v" id="v26" data-v="26" data-xref="希伯來書 10:35; 希伯來書 11:6; 彼得前書 4:14"> 在他眼中，為基督所受的凌辱遠比埃及的財富更有價值，因為他盼望的是將來的賞賜。</span>
<span className="v" id="v27" data-v="27" data-xref="哥林多後書 4:18; 希伯來書 11:13; 希伯來書 11:1"> 因為信心，他離開埃及，不怕王的憤怒。他堅忍不拔，好像看見了肉眼不能看見的主。</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及記 12:21–30; 希伯來書 9:19; 希伯來書 12:24"> 因為信心，他守逾越節，行灑血的禮，免得那位殺長子的傷害以色列人。</span>
<span className="v" id="v29" data-v="29" data-xref="出埃及記 14:13–21; 詩篇 106:9–11; 詩篇 78:13"> 因為信心，以色列人渡過紅海，如履乾地，埃及人試圖過去，卻被海水淹沒。</span>
<span className="v" id="v30" data-v="30" data-xref="約書亞記 6:3–20; 哥林多後書 10:4–5"> 因為信心，以色列人繞著耶利哥城走了七天，城牆就倒塌了。</span>
<span className="v" id="v31" data-v="31" data-xref="雅各書 2:25; 約書亞記 6:22–25; 馬太福音 1:5"> 因為信心，妓女喇合善待以色列的探子，所以沒有與那些不順服的人一同滅亡。</span>
<span className="v" id="v32" data-v="32" data-xref="撒母耳記上 16:1; 撒母耳記上 1:20; 撒母耳記上 16:13"> 我還要再說下去嗎？我沒有時間一一細說基甸、巴拉、參孫、耶弗他、大衛、撒母耳和眾先知的事了。</span>
<span className="v" id="v33" data-v="33" data-xref="詩篇 144:1–2; 希伯來書 6:12–15; 希伯來書 10:36"> 他們憑信心戰勝了敵國，行了公義，得到了應許，堵住了獅子的口，</span>
<span className="v" id="v34" data-v="34" data-xref="列王紀下 6:16–18; 哥林多後書 12:9–10; 撒母耳記上 17:51–52"> 熄滅了猛烈的火焰，刀下逃生，由軟弱變為剛強，作戰勇猛，擊退外敵。</span>
<span className="v" id="v35" data-v="35" data-xref="列王紀下 4:27–37; 列王紀上 17:22–24; 腓立比書 3:11"> 有些婦女得回了從死裡復活的親人。有些人受盡嚴刑拷打，仍不肯苟且偷生，為要得到一個復活後更美好的生命。</span>
<span className="v" id="v36" data-v="36" data-xref="耶利米書 20:2; 創世記 39:20; 耶利米書 37:15–21"> 有些人遭受戲弄、鞭打、捆鎖和囚禁。</span>
<span className="v" id="v37" data-v="37" data-xref="歷代志下 24:21; 耶利米書 26:23; 列王紀上 19:10"> 他們被人用石頭打死，受威逼利誘<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="有聖經抄本在此處無「受威逼利誘」。">c</a></sup>，被鋸成兩截，喪生刀下，披著綿羊和山羊的皮四處奔跑，受盡貧乏、迫害和虐待，</span>
<span className="v" id="v38" data-v="38" data-xref="列王紀上 18:4; 撒母耳記上 22:1; 列王紀上 19:9"> 在曠野、群山、山洞和地穴中漂泊不定。他們是世界不配有的！</span>
<span className="v" id="v39" data-v="39" data-xref="路加福音 10:23–24; 希伯來書 11:13; 希伯來書 11:2"> 這些人都因信心而獲得讚許，但他們並未得到上帝所應許的，</span>
<span className="v" id="v40" data-v="40" data-xref="啟示錄 6:11; 希伯來書 8:6; 希伯來書 10:11–14"> 因為上帝為我們預備了更美的，要叫他們與我們一同得到才算完美。</span>

## 更美之約的大祭司

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="希伯來書 1:3; 歌羅西書 3:1; 啟示錄 3:21"> 我們所講的要點是：我們有這樣一位大祭司，祂現在已經坐在天上至高上帝的寶座右邊，</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 33:7; 哥林多後書 5:1; 希伯來書 9:23–24"> 並在聖所裡供職。這聖所就是真正的聖幕，不是人建立的，而是主親手建立的。</span>
<span className="v" id="v3" data-v="3" data-xref="以弗所書 5:2; 希伯來書 5:1; 希伯來書 9:14"> 所有的大祭司都是為了向上帝獻禮物和祭物而設立的，因此我們這位大祭司也必須有所獻上。</span>
<span className="v" id="v4" data-v="4" data-xref="希伯來書 7:11–15; 希伯來書 5:1; 民數記 17:12–13"> 祂如果是在地上，根本不會做祭司，因為地上已經有照律法向上帝獻禮物的祭司了。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 25:40; 歌羅西書 2:17; 希伯來書 10:1"> 這些祭司的事奉都是仿效和反映天上的事，正如摩西建聖幕的時候，上帝警告他說：<br /><span className="pl pl-1">「你務要照著在山上指示你的樣式造各樣器具。」</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="出埃及記25·40。">a</a></sup></span>
<span className="v" id="v6" data-v="6" data-xref="希伯來書 7:22; 加拉太書 3:16–21; 希伯來書 12:24"> 但如今，耶穌得到了一個更超越的職任，正如祂擔任了更美之約的中保，這約是根據更美的應許所立的。</span>
<span className="v" id="v7" data-v="7" data-xref="希伯來書 7:11; 加拉太書 3:21; 希伯來書 7:18"> 因為如果第一個約沒有缺點，就不必另立新約了。</span>
<span className="v" id="v8" data-v="8" data-xref="耶利米書 31:31–34; 希伯來書 10:16–17; 希伯來書 12:24"> 然而，上帝指責祂的子民，說：<br /><span className="pl pl-1">「主說，看啊，時候將到，</span><br /><span className="pl pl-1">我要與以色列家和猶大家另立新約，</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="耶利米書 31:32; 加拉太書 4:24; 馬可福音 8:23"> <span className="pl pl-1">這約不同於我與他們祖先所立的約，</span><br /><span className="pl pl-1">那是我牽著他們祖先的手領他們離開埃及時所立的。</span><br /><span className="pl pl-1">因為他們不持守我的約，</span><br /><span className="pl pl-1">所以我不再理會他們。</span><br /><span className="pl pl-1">這是主說的。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="以西結書 36:26–28; 耶利米書 31:33; 以西結書 11:19–20"> <span className="pl pl-1">主又說，那些日子以後，</span><br /><span className="pl pl-1">我將與以色列家立這樣的約，</span><br /><span className="pl pl-1">我要把我的律法放在他們腦中，</span><br /><span className="pl pl-1">寫在他們心上。</span><br /><span className="pl pl-1">我要作他們的上帝，</span><br /><span className="pl pl-1">他們要作我的子民。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="耶利米書 31:34; 以賽亞書 54:13; 約翰福音 6:45"> <span className="pl pl-1">誰都無需再教導自己的鄰居和弟兄，</span><br /><span className="pl pl-1">說，『你要認識主。』</span><br /><span className="pl pl-1">因為他們無論尊卑都必認識我。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="希伯來書 10:16–17; 以賽亞書 43:25; 羅馬書 11:27"> <span className="pl pl-1">我要赦免他們的過犯，</span><br /><span className="pl pl-1">忘掉他們的罪惡。」</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="耶利米書31·31‑34。">b</a></sup></span>
<span className="v" id="v13" data-v="13" data-xref="哥林多後書 5:17; 希伯來書 7:18–19; 希伯來書 7:11–12"> 上帝既然說要立新約，就是把第一個約當作舊的了，那漸漸陳舊過時的很快就會消失。</span>
</div>

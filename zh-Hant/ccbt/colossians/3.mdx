## 追求屬天的事

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="羅馬書 8:6; 馬太福音 6:33; 哥林多後書 4:18"> 你們既然和基督一同復活了，就應當追求天上的事，那裡有坐在上帝右邊的基督。</span>
<span className="v" id="v2" data-v="2" data-xref="約翰一書 2:15–17; 歷代志上 22:19; 歌羅西書 3:1"> 你們要思想天上的事，而不是地上的事，</span>
<span className="v" id="v3" data-v="3" data-xref="加拉太書 2:20; 羅馬書 6:2; 歌羅西書 2:20"> 因為你們的舊生命已經死了，你們的新生命與基督一同藏在上帝裡面。</span>
<span className="v" id="v4" data-v="4" data-xref="約翰福音 11:25; 約翰一書 3:2; 加拉太書 2:20"> 基督就是你們的新生命，祂顯現的時候，你們也必和祂一起在榮耀中顯現。</span>
<span className="v" id="v5" data-v="5" data-xref="羅馬書 8:13; 加拉太書 5:19–21; 加拉太書 5:24"> 所以，你們要治死身上屬世的罪惡，如淫亂、污穢、邪情、惡慾和貪心，貪心就是拜偶像，</span>
<span className="v" id="v6" data-v="6" data-xref="以弗所書 5:6; 羅馬書 1:18; 彼得前書 1:14"> 因為上帝的烈怒必臨到做這些事的悖逆之人。</span>
<span className="v" id="v7" data-v="7" data-xref="以弗所書 2:2; 彼得前書 4:3–4; 羅馬書 6:19–20"> 你們過去也過著罪惡的生活，</span>
<span className="v" id="v8" data-v="8" data-xref="以弗所書 4:29; 以弗所書 4:22; 雅各書 1:20–21"> 但現在必須杜絕怒氣、憤恨、惡毒、毀謗和污言穢語等惡事。</span>
<span className="v" id="v9" data-v="9" data-xref="以弗所書 4:22; 以弗所書 4:25; 利未記 19:11"> 不要彼此說謊，因為你們已經脫去了舊人和舊人的行為，</span>
<span className="v" id="v10" data-v="10" data-xref="以弗所書 4:23–24; 羅馬書 12:2; 以弗所書 2:10"> 穿上了新人。這新人在知識上不斷更新，更像他的造物主。</span>
<span className="v" id="v11" data-v="11" data-xref="加拉太書 3:28–29; 哥林多前書 12:13; 羅馬書 10:12"> 從此，不再分希臘人、猶太人，受割禮的、未受割禮的，野蠻人、未開化的人<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「未開化的人」希臘文是「西古提人」。">a</a></sup>，奴隸和自由人，基督就是一切，並且在一切之中。</span>
<span className="v" id="v12" data-v="12" data-xref="以弗所書 4:32; 以弗所書 4:2; 約翰一書 4:19"> 所以，你們既然是上帝所揀選的，是聖潔、蒙愛的人，就要心存憐憫、恩慈、謙卑、溫柔和忍耐。</span>
<span className="v" id="v13" data-v="13" data-xref="以弗所書 4:32; 馬可福音 11:25; 雅各書 2:13"> 倘若彼此之間有怨言，總要互相寬容，彼此饒恕，主怎樣饒恕你們，你們也要照樣饒恕他人。</span>
<span className="v" id="v14" data-v="14" data-xref="彼得前書 4:8; 以弗所書 5:2; 哥林多前書 13:1–13"> 最重要的是要有愛，愛能把一切完美地聯合在一起。</span>
<span className="v" id="v15" data-v="15" data-xref="腓立比書 4:6–7; 約翰福音 14:27; 以賽亞書 26:3"> 要讓基督的平安掌管你們的心，你們就是為此而蒙召成為一個身體。要常存感恩的心。</span>
<span className="v" id="v16" data-v="16" data-xref="詩篇 119:11; 以弗所書 5:19; 約翰福音 15:7"> 要將基督的話豐豐富富地存在心裡，用一切智慧彼此教導，互相勸誡，以感恩的心用詩篇、聖詩、靈歌頌讚上帝。</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多前書 10:31; 歌羅西書 3:23; 箴言 3:6"> 你們無論說什麼和做什麼，都要奉主耶穌的名來說和做，並藉著祂感謝父上帝。</span>
</div>
</div>

## 和諧家庭

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="以弗所書 5:22–9; 提多書 2:4–5; 哥林多前書 11:3"> 你們作妻子的，要順服丈夫，信主的人應當這樣做。</span>
<span className="v" id="v19" data-v="19" data-xref="彼得前書 3:7; 創世記 2:23–24; 歌羅西書 3:21"> 你們作丈夫的，要愛妻子，不可惡待她們。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及記 20:12; 以弗所書 6:1–3; 箴言 6:20"> 你們作兒女的，凡事要聽從父母，因為這是主所喜悅的。</span>
<span className="v" id="v21" data-v="21" data-xref="箴言 4:1–4; 以弗所書 6:4; 詩篇 103:13"> 你們作父親的，不要激怒兒女，免得他們灰心喪志。</span>
<span className="v" id="v22" data-v="22" data-xref="以弗所書 6:5–7; 提摩太前書 6:1–2; 加拉太書 1:10"> 你們作奴僕的，凡事要聽從你們世上的主人，不要只做討好人的表面工夫，要以敬畏主的心真誠服侍。</span>
<span className="v" id="v23" data-v="23" data-xref="歌羅西書 3:17; 以弗所書 6:6–7; 羅馬書 14:8"> 無論做什麼事，都要發自內心，像是為主做的，而不是為人做的，</span>
<span className="v" id="v24" data-v="24" data-xref="以弗所書 6:8; 加拉太書 1:10; 使徒行傳 20:32"> 因為你們知道自己一定會從主那裡得到基業為獎賞。你們事奉的是主基督，</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行傳 10:34; 羅馬書 2:11; 哥林多後書 5:10"> 凡作惡的人終必自食惡果，因為上帝不偏待人。</span>
</div>

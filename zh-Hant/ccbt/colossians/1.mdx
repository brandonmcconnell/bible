## 感恩與禱告

<div className="bt">
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="帖撒羅尼迦前書 1:2; 歌羅西書 1:9; 提摩太後書 1:3"> 我們聽說了你們對基督耶穌的信心和對眾聖徒的愛心，為你們禱告的時候，常常感謝我們主耶穌基督的父上帝。</span>
<span className="v" id="v5" data-v="5" data-xref="彼得前書 1:3–4; 以弗所書 1:13; 提摩太後書 4:8"> 你們能有這樣的信心和愛心是因為那為你們存在天上的盼望，就是你們之前從福音真道中聽到的盼望。</span>
<span className="v" id="v6" data-v="6" data-xref="約翰福音 15:16; 腓立比書 1:11; 歌羅西書 1:23"> 這福音不但傳到了你們那裡，也傳到了世界各地，不斷結出果實並發展壯大，正如你們當初聽了福音並真正明白上帝恩典後的情形。</span>
<span className="v" id="v7" data-v="7" data-xref="歌羅西書 4:12; 腓利門書 1:23; 歌羅西書 4:7"> 這福音是你們從我們親愛的同工以巴弗那裡學到的。他代表我們<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「我們」有古卷作「你們」。">a</a></sup>作基督的忠僕，</span>
<span className="v" id="v8" data-v="8" data-xref="羅馬書 15:30; 提摩太後書 1:7; 加拉太書 5:22"> 並把聖靈賜給你們的愛心告訴了我們。</span>
<span className="v" id="v9" data-v="9" data-xref="雅各書 3:17; 腓立比書 1:9–11; 雅各書 1:5"> 因此，從聽到你們的消息那天起，我們便不斷地為你們禱告，求上帝使你們在一切屬靈的智慧和悟性上完全明白祂的旨意，</span>
<span className="v" id="v10" data-v="10" data-xref="以弗所書 4:1; 希伯來書 13:21; 彼得後書 1:2–3"> 以便你們行事為人對得起主，凡事蒙祂喜悅，在一切善事上結出果實，對上帝的認識不斷增加。</span>
<span className="v" id="v11" data-v="11" data-xref="以弗所書 3:16; 腓立比書 4:13; 以弗所書 4:2"> 願上帝用祂榮耀的權能使你們剛強，無論遇到什麼事都能長久忍耐，</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行傳 20:32; 以弗所書 1:11; 以弗所書 1:18"> 歡喜地感謝天父，因祂使你們有資格跟眾聖徒在光明中同享基業。</span>
<span className="v" id="v13" data-v="13" data-xref="以弗所書 5:8; 使徒行傳 26:18; 彼得前書 2:9"> 祂把我們從黑暗的權勢下拯救出來，遷入祂愛子的國度裡。</span>
<span className="v" id="v14" data-v="14" data-xref="以弗所書 1:7; 羅馬書 3:24–25; 彼得前書 1:19–20"> 我們藉著祂的愛子蒙救贖，罪得到赦免。</span>
</div>
</div>

## 基督超越一切

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="希伯來書 1:3; 約翰福音 14:9; 約翰福音 1:1"> 愛子是那不能看見之上帝的真像，超越<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="「超越」或譯「先存於」，希臘文是「長子」，常用來指地位上的優越或時間上的優先。">b</a></sup>一切受造之物。</span>
<span className="v" id="v16" data-v="16" data-xref="羅馬書 11:36; 約翰福音 1:3; 哥林多前書 8:6"> 因為萬物都是藉著祂創造的，天上的、地上的、有形的、無形的、作王的、統治的、執政的、掌權的，一切都是藉著祂也是為了祂而創造的。</span>
<span className="v" id="v17" data-v="17" data-xref="希伯來書 1:3; 哥林多前書 8:6; 使徒行傳 17:28"> 祂存在於萬物之先，萬物都靠祂維繫。</span>
<span className="v" id="v18" data-v="18" data-xref="以弗所書 1:22–23; 啟示錄 1:5; 以弗所書 4:15–16"> 祂是教會的頭，教會是祂的身體；祂是開始，是首先從死裡復活的，好在一切事上居首位。</span>
<span className="v" id="v19" data-v="19" data-xref="歌羅西書 2:9; 約翰福音 1:16; 以弗所書 1:23"> 因為上帝樂意讓一切的豐盛住在祂裡面，</span>
<span className="v" id="v20" data-v="20" data-xref="哥林多後書 5:18–21; 以弗所書 1:10; 約翰一書 4:9–10"> 又藉著祂在十字架上所流的血成就了和平，使天地萬物藉著祂與上帝和好。</span>
<span className="v" id="v21" data-v="21" data-xref="以弗所書 2:12; 提多書 3:3–7; 以弗所書 2:1–3"> 你們從前與上帝隔絕，行事邪惡，心思意念與祂為敵；</span>
<span className="v" id="v22" data-v="22" data-xref="以弗所書 5:27; 猶大書 1:24; 以弗所書 1:4"> 但現在上帝藉著基督肉身的死使你們與祂和好了，讓你們在祂面前成為聖潔無瑕、無可指責的人。</span>
<span className="v" id="v23" data-v="23" data-xref="希伯來書 3:14; 希伯來書 3:6; 馬太福音 24:13–14"> 只是你們必須恆心持守所信的道，根基穩固，堅定不移，不要失去你們聽到福音後所得到的盼望。這福音傳給了天下萬民。我保羅也作了這福音的使者。</span>
</div>
</div>

## 保羅為教會受苦

<div className="bt">
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="羅馬書 5:3; 提摩太後書 1:8; 哥林多後書 1:5–8"> 我現在因著能為你們受苦而歡喜，並且我是為基督的身體——教會的緣故，在自己身上補滿基督未受盡的苦難。</span>
<span className="v" id="v25" data-v="25" data-xref="以弗所書 3:2; 歌羅西書 1:23; 加拉太書 2:7–8"> 我受上帝的委派成為教會的僕人，要把上帝的道完整地傳給你們。</span>
<span className="v" id="v26" data-v="26" data-xref="路加福音 8:10; 羅馬書 16:25–26; 以弗所書 3:3–10"> 這道是歷世歷代一直隱藏的奧祕，現在已經向祂的眾聖徒顯明了。</span>
<span className="v" id="v27" data-v="27" data-xref="約翰福音 14:20; 羅馬書 8:10; 以弗所書 3:16–17"> 上帝要他們知道這奧祕在外族人中有何等豐盛的榮耀，這奧祕就是：基督在你們裡面，使你們有榮耀的盼望。</span>
<span className="v" id="v28" data-v="28" data-xref="以弗所書 5:27; 耶利米書 3:15; 以弗所書 4:11–13"> 我們傳揚基督，用一切智慧勸誡、教導眾人，使他們在基督裡長大成熟，好把他們交給上帝。</span>
<span className="v" id="v29" data-v="29" data-xref="哥林多前書 15:10; 以弗所書 1:19; 哥林多前書 9:25–27"> 為此，我按著祂在我身上運行的大能盡心竭力，不辭勞苦。</span>
</div>
</div>

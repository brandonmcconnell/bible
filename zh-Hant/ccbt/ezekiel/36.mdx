## 預言賜福以色列

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西結書 37:4; 以西結書 34:14; 以西結書 37:22"> 「人子啊，你要向以色列的山嶺預言說，『以色列的山嶺啊，你們要聽耶和華的話！</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 32:13; 以西結書 25:3; 以西結書 35:10"> 主耶和華這樣說：仇敵說，「哈哈，這古老的山峰歸我們了！」』</span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 44:13–14; 耶利米哀歌 2:15–16; 耶利米書 18:16"> 所以你要說預言，宣告主耶和華這樣說：他們四面蹂躪、摧毀你們，使你們歸列國所有，成了外族人的話柄和笑談。</span>
<span className="v" id="v4" data-v="4" data-xref="以西結書 34:28; 申命記 11:11; 以西結書 36:6"> 因此，以色列的山嶺啊，你們要聽主耶和華的話。以下是主耶和華對高山和丘陵，溪流和河谷，荒涼的廢墟，以及被周圍列國擄掠和譏笑的廢棄城邑所說的話。</span>
<span className="v" id="v5" data-v="5" data-xref="彌迦書 7:8; 以西結書 36:3; 詩篇 137:7"> 主耶和華說：我要在怒火中斥責列國和以東，他們幸災樂禍，滿腹憤恨地把我的土地據為己有，侵佔其中的草場。</span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 123:3–4; 以西結書 34:29; 詩篇 74:23"> 所以你要對以色列說預言，告訴以色列的高山、丘陵、溪流和河谷，主耶和華這樣說：因為你們遭到列國的羞辱，我懷著義憤和烈怒發言。</span>
<span className="v" id="v7" data-v="7" data-xref="以西結書 20:5; 阿摩司書 1:1–15; 以西結書 20:15"> 我起誓要讓你們四圍的列國也受羞辱。這是主耶和華說的。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="以賽亞書 27:6; 希伯來書 10:37; 以西結書 34:26–29"> 「『以色列的山嶺啊，你們要為我的以色列子民長出枝葉，結出果子，因為他們快要回來了。</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 46:11; 何西阿書 2:21–23; 以西結書 36:34"> 看啊，我要幫助你們，垂顧你們，使你們被耕種。</span>
<span className="v" id="v10" data-v="10" data-xref="以西結書 36:33; 耶利米書 33:12; 以西結書 36:37"> 我要使你們那裡的以色列人增加，使城邑有人居住，廢墟得以重建。</span>
<span className="v" id="v11" data-v="11" data-xref="耶利米書 33:12; 耶利米書 23:5–8; 耶利米書 31:27"> 我要使你們那裡的人畜興旺，生養眾多，我要使人們居住在你們那裡，好像以前一樣，讓你們比以前更興盛。這樣，你們就知道我是耶和華。</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米書 15:7; 以西結書 36:13; 耶利米書 32:44"> 我要引領我的以色列子民在你們那裡出入，使你們成為他們的產業，不再奪走他們的兒女。</span>
<span className="v" id="v13" data-v="13" data-xref="民數記 13:32"> 主耶和華說：雖然人們說你們吞吃以色列人、奪走他們的兒女，</span>
<span className="v" id="v14" data-v="14" data-xref="以西結書 37:25–28; 阿摩司書 9:15; 以賽亞書 60:21"> 但你們今後必不再吞吃以色列人，不再奪走他們的兒女。這是主耶和華說的。</span>
<span className="v" id="v15" data-v="15" data-xref="以西結書 34:29; 詩篇 89:50; 以西結書 36:6"> 我必不再使你們聽見列國的辱罵，你們必不再遭受列邦的嘲笑，也不再使你們的國民喪失兒女。這是主耶和華說的。』」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16"> 耶和華對我說：</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米書 2:7; 民數記 35:33–34; 彌迦書 2:10"> 「人子啊，當以色列人住在本土時，他們的惡行玷污了那裡，他們的行為在我眼中就像經期的婦女一樣污穢。</span>
<span className="v" id="v18" data-v="18" data-xref="歷代志下 34:21; 以西結書 7:8; 耶利米哀歌 2:4"> 他們殺人流血，祭拜偶像，玷污了那地方，所以我要把我的烈怒傾倒在他們身上，</span>
<span className="v" id="v19" data-v="19" data-xref="以西結書 39:24; 申命記 28:64; 以西結書 5:12"> 把他們驅散到列國，分散到列邦，照他們的行為報應他們。</span>
<span className="v" id="v20" data-v="20" data-xref="羅馬書 2:24; 以賽亞書 52:5; 耶利米書 33:24"> 他們無論分散到何處，都使我的聖名受到褻瀆，因為外族人都談論他們說，『這些人是耶和華的子民，卻不得不離開耶和華的土地。』</span>
<span className="v" id="v21" data-v="21" data-xref="以賽亞書 48:9; 詩篇 74:18; 以西結書 20:9"> 我顧惜我的聖名，就是以色列人在所去的列國褻瀆的聖名。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="詩篇 106:8; 以西結書 36:32; 詩篇 115:1–2"> 「因此，你要告訴以色列人，主耶和華這樣說，『以色列人啊，我要行這事並非因為你們的緣故，而是因為我聖名的緣故，就是你們在所去列國褻瀆的聖名。</span>
<span className="v" id="v23" data-v="23" data-xref="以西結書 20:41; 以賽亞書 5:16; 以西結書 39:7"> 我要使我偉大的名，就是你們在列國中所褻瀆的名，彰顯它的聖潔。我要當著列國的面在你們身上彰顯我的聖潔，那時他們就知道我是耶和華。這是主耶和華說的。</span>
<span className="v" id="v24" data-v="24" data-xref="以西結書 37:21; 以西結書 34:13; 阿摩司書 9:14–15"> 我要把你們從列國領出來，從列邦招聚你們，帶你們返回故土。</span>
<span className="v" id="v25" data-v="25" data-xref="希伯來書 10:22; 約翰福音 3:5; 耶利米書 33:8"> 我要在你們身上灑清水潔淨你們，洗淨你們所有的污穢，除掉你們一切的偶像。</span>
<span className="v" id="v26" data-v="26" data-xref="以西結書 11:19–20; 詩篇 51:10; 哥林多後書 5:17"> 我要賜你們一顆新心，把新的靈放在你們裡面。我要除去你們的石心，賜給你們一顆肉心。</span>
<span className="v" id="v27" data-v="27" data-xref="提多書 3:3–6; 希伯來書 13:21; 哥林多前書 3:16"> 我要把我的靈放在你們裡面，使你們恪守我的律例、謹遵我的典章。</span>
<span className="v" id="v28" data-v="28" data-xref="耶利米書 31:33; 耶利米書 32:38; 以西結書 37:27"> 這樣，你們必安居在我賜給你們祖先的土地上，你們要做我的子民，我要做你們的上帝。</span>
<span className="v" id="v29" data-v="29" data-xref="約翰福音 1:7–9; 馬太福音 1:21; 何西阿書 2:21–23"> 我要拯救你們脫離一切污穢之事。我要使你們五穀豐登，不讓饑荒侵害你們。</span>
<span className="v" id="v30" data-v="30" data-xref="以西結書 34:27; 約珥書 2:26; 申命記 29:23–28"> 我要使樹木碩果纍纍，田間出產豐盛，免得你們因饑荒再被外族人譏笑。</span>
<span className="v" id="v31" data-v="31" data-xref="以西結書 6:9; 以西結書 20:43; 尼希米記 9:26–35"> 那時，你們便會想起自己邪惡的行徑，並因自己的罪惡和可憎行為而厭惡自己。</span>
<span className="v" id="v32" data-v="32" data-xref="申命記 9:5; 以西結書 36:22; 提摩太後書 1:9"> 主耶和華說：你們要知道，我這樣做並不是為了你們。以色列人啊，你們應當為自己的行為抱愧蒙羞。』</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="以賽亞書 58:12; 以西結書 36:10; 耶利米書 33:10"> 「主耶和華說，『在我洗淨你們一切罪惡的日子，我要使你們的城邑有人居住，廢墟得以重建。</span>
<span className="v" id="v34" data-v="34" data-xref="以西結書 6:14; 耶利米書 25:9–11; 歷代志下 36:21"> 荒涼之地必有人耕種，路人再也看不見荒地。</span>
<span className="v" id="v35" data-v="35" data-xref="以賽亞書 51:3; 約珥書 2:3; 耶利米書 33:9"> 他們會說：以前的荒涼之地如今竟變得像伊甸園，被毀壞廢棄的荒涼城邑已經設防，有人居住。</span>
<span className="v" id="v36" data-v="36" data-xref="馬太福音 24:35; 民數記 23:19; 以西結書 17:24"> 這樣，你們四周其餘的列國便知道我耶和華已重建毀壞之處，重新耕種荒廢之地。我耶和華言出必行。』</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="約翰一書 5:14; 希伯來書 10:21–22; 以西結書 14:3"> 「主耶和華說，『我要再次答應以色列人的懇求，使他們的人口增加，多如羊群。</span>
<span className="v" id="v38" data-v="38" data-xref="列王紀上 8:63; 使徒行傳 2:5–11; 約翰福音 10:16"> 我要使毀壞的城邑住滿人，多如耶路撒冷在節期所獻上的羊群。這樣，他們就知道我是耶和華。』」</span>
</div>
</div>

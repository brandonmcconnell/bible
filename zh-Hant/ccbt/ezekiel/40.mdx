## 新聖殿的異象

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西結書 33:21; 以西結書 1:2–3; 以西結書 3:14"> 在我們被擄的第二十五年，就是耶路撒冷淪陷的第十四年一月十日，耶和華的手按在我身上，祂帶我到了那裡。</span>
<span className="v" id="v2" data-v="2" data-xref="以西結書 1:1; 但以理書 7:1; 但以理書 7:7"> 在異象中上帝把我帶到以色列的一座高山上，山的南面彷彿有一座城。</span>
<span className="v" id="v3" data-v="3" data-xref="以西結書 47:3; 啟示錄 11:1; 但以理書 10:5–6"> 祂把我帶到那裡。城的入口站著一個面色如銅的人，手中拿著一條麻繩和一根量竿。</span>
<span className="v" id="v4" data-v="4" data-xref="以西結書 44:5; 馬太福音 10:27; 以西結書 2:7–8"> 那人對我說：「人子啊，你要留心用眼看，專心用耳聽，注意我要指示你的一切，因為我帶你來這裡正是為了要指示你。你要把所見到的一切告訴以色列人。」</span>
</div>
</div>

## 外院的門

<div className="bt">
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="以西結書 42:20; 以賽亞書 26:1; 啟示錄 21:12"> 我看見殿的四周有牆，那人拿了一根三米長的量竿量這牆，量出牆厚一竿，高一竿。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="以西結書 43:1; 以西結書 8:16; 以西結書 11:1"> 然後，他帶我到殿的東門，走上台階，量了門洞，深一竿。</span>
<span className="v" id="v7" data-v="7" data-xref="以西結書 40:36; 以西結書 40:33; 歷代志上 23:28"> 門內有守衛室，長度和寬度都是一竿。室與室之間相距兩米半，挨著通往聖殿門廊的門洞深一竿。</span>
<span className="v" id="v8" data-v="8"> 他量了通往聖殿的門廊，寬度也是一竿，</span>
<span className="v" id="v9" data-v="9" data-xref="以西結書 45:19"> 連牆柱在內共四米寬，牆柱寬一米。</span>
<span className="v" id="v10" data-v="10"> 東門內共有六間守衛室，每邊三間，大小面積都是一樣，兩邊的牆柱尺寸也相同。</span>
<span className="v" id="v11" data-v="11"> 他量了門的入口，寬五米，長六米半。</span>
<span className="v" id="v12" data-v="12"> 兩邊守衛室前面的矮牆高五十釐米，守衛室都是邊長三米的正方形。</span>
<span className="v" id="v13" data-v="13"> 他又量門的寬度，即這邊守衛室的屋頂到對面守衛室的屋頂，是十二米半。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及記 27:9; 以賽亞書 62:9; 以西結書 42:1"> 他從門口的牆柱量到外院的牆柱，是三十米。</span>
<span className="v" id="v15" data-v="15"> 由門口到通道盡頭的內廊共二十五米，</span>
<span className="v" id="v16" data-v="16" data-xref="歷代志下 3:5; 列王紀上 6:4; 以西結書 41:26"> 守衛室、牆柱上和門廊周圍都有格子窗，牆柱上刻著棕樹。</span>
</div>
</div>

## 外院

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="啟示錄 11:2; 以西結書 42:1; 歷代志上 23:28"> 他帶我到外院，外院靠牆的四周是鋪石地，沿著鋪石地共有三十間廂房。</span>
<span className="v" id="v18" data-v="18"> 鋪石地在門口的兩邊，比內院低，寬度與入口的長度一樣。</span>
<span className="v" id="v19" data-v="19" data-xref="以西結書 40:23; 以西結書 40:27; 以西結書 46:1–2"> 他從外院的內門口量到內院的外門口，東側和北側距離都是五十米。</span>
</div>
</div>

## 北門

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="以西結書 40:6"> 他又量了外院的北門的長和寬，</span>
<span className="v" id="v21" data-v="21" data-xref="以西結書 40:29–30; 以西結書 40:25–26; 以西結書 40:10–16"> 通道兩邊各有三間守衛室，牆柱和門廊的長度和寬度跟東門一樣，分別是二十五米和十二米半。</span>
<span className="v" id="v22" data-v="22" data-xref="以西結書 40:31; 以西結書 40:37; 以西結書 40:6"> 它的窗戶、門廊、牆柱上雕刻的棕樹都和東門的尺寸相同。登上七級石階便到達門口，通道的盡頭是門廊。</span>
<span className="v" id="v23" data-v="23" data-xref="以西結書 40:19; 以西結書 40:27–28; 出埃及記 38:9–12"> 內院的北門與外院的北門相對，正如它的東門和外院的東門相對，他量了相對兩門之間的距離，是五十米。</span>
</div>
</div>

## 南門

<div className="bt">
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="以西結書 46:9; 以西結書 40:6; 以西結書 40:20–21"> 他又帶我到南門，量了牆柱和門廊，都與其他門的尺寸相同，</span>
<span className="v" id="v25" data-v="25" data-xref="以西結書 40:33; 以西結書 40:16; 以西結書 40:21–22"> 通道與門廊四周都有窗戶，和其他的窗戶一樣，通道長二十五米，寬十二米半。</span>
<span className="v" id="v26" data-v="26" data-xref="以西結書 40:22; 以西結書 40:16; 以西結書 40:6"> 登上七級石階便到達門口，通道盡頭是門廊，兩邊的牆柱也同樣刻著棕樹。</span>
<span className="v" id="v27" data-v="27" data-xref="以西結書 40:23; 以西結書 40:32; 以西結書 40:19"> 內院也有南門，他量了與外院南門之間的距離，是五十米。</span>
</div>
</div>

## 內院的門

<div className="bt">
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="以西結書 40:35; 以西結書 40:32"> 他帶我從南門走進內院，量了南門，跟其他門的尺寸一樣。</span>
<span className="v" id="v29" data-v="29" data-xref="以西結書 40:25; 以西結書 40:16; 以西結書 40:7"> 守衛室、牆柱，門廊都和其他的尺寸一樣，通道與門廊四周有窗戶，通道長二十五米，寬十二米半。</span>
<span className="v" id="v30" data-v="30" data-xref="以西結書 40:21; 以西結書 40:36; 以西結書 40:25"> 內院周圍的門廊都是長十三米，寬二米半。</span>
<span className="v" id="v31" data-v="31" data-xref="以西結書 40:26; 以西結書 40:34; 以西結書 40:22"> 這些門廊對著外院，兩邊的牆柱刻著棕樹，上去的石階共有八級。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="以西結書 40:35; 以西結書 40:28–31"> 他又帶我從東門進入內院，量了東門，跟其他門的尺寸一樣，</span>
<span className="v" id="v33" data-v="33" data-xref="以西結書 40:21; 以西結書 40:36; 以西結書 40:25"> 守衛室、牆柱、門廊都和其他的尺寸一樣，通道與門廊四周有窗戶，通道長二十五米，寬十二米半。</span>
<span className="v" id="v34" data-v="34" data-xref="以西結書 40:22; 以西結書 40:31; 以西結書 40:37"> 門廊對著外院，兩邊的牆柱刻著棕樹，那裡的石階共有八級。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="以西結書 47:2; 以西結書 40:32; 以西結書 44:4"> 他又帶我到北門，量了北門，跟其他門的尺寸一樣。</span>
<span className="v" id="v36" data-v="36" data-xref="以西結書 40:29; 以西結書 40:21; 以西結書 40:16"> 守衛室、牆柱、門廊和其他門的尺寸一樣，通道長二十五米，寬十二米半，四周有窗戶。</span>
<span className="v" id="v37" data-v="37" data-xref="以西結書 40:34; 以西結書 40:31"> 門廊對著外院，兩邊的牆柱刻著棕樹，那裡的石階共有八級。</span>
</div>
</div>

## 廂房

<div className="bt">
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="歷代志下 4:6; 以西結書 40:17; 利未記 8:21"> 門口的牆柱旁邊有一個帶門的房間，是洗燔祭牲的地方。</span>
<span className="v" id="v39" data-v="39" data-xref="以西結書 46:2; 利未記 1:3–17; 利未記 4:2–3"> 門廊兩邊各有兩張用來屠宰燔祭牲、贖罪祭牲和贖過祭牲的桌子。</span>
<span className="v" id="v40" data-v="40"> 內院北門的門廊外牆邊有兩張桌子，門廊的另一邊也有兩張桌子。</span>
<span className="v" id="v41" data-v="41" data-xref="以西結書 40:39–40"> 大門兩側各有四張桌子，共八張，供祭司屠宰祭牲之用。</span>
<span className="v" id="v42" data-v="42" data-xref="以西結書 40:39; 出埃及記 20:25"> 另有四張用石頭鑿成的桌子用來預備燔祭牲，屠宰燔祭牲及其他祭牲的器具都放在桌上。桌子長寬各七十五釐米，高五十釐米。</span>
<span className="v" id="v43" data-v="43" data-xref="利未記 1:8; 利未記 1:6; 利未記 8:20"> 廊內四周掛著八釐米長的雙鉤。桌上放著祭肉。</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="歷代志上 6:31–32; 歷代志上 16:41–43; 以西結書 40:27"> 在內院的內門旁有兩間歌樂手用的廂房，一間向南，在北門旁，一間向北，在南門旁。</span>
<span className="v" id="v45" data-v="45" data-xref="歷代志上 9:23; 詩篇 134:1; 利未記 8:35"> 他對我說：「向南的廂房是給殿內供職的祭司用的，</span>
<span className="v" id="v46" data-v="46" data-xref="以西結書 44:15; 以西結書 43:19; 列王紀上 2:35"> 向北的廂房是給壇前供職的祭司用的。他們都是撒督的子孫，利未人中唯有他們可以到耶和華面前事奉。」</span>
<span className="v" id="v47" data-v="47" data-xref="以西結書 40:19; 以西結書 40:23; 以西結書 40:27"> 他量了殿前的院子，是邊長五十米的正方形，祭壇在殿前面。</span>
</div>
</div>

## 聖殿

<div className="bt">
<div className="bp">
<span className="v" id="v48" data-v="48" data-xref="歷代志下 3:4; 列王紀上 6:3"> 他帶我來到殿前通往聖所的門廊，量了兩旁的牆柱，各兩米半寬，門寬七米，門兩邊的牆各一米半厚，</span>
<span className="v" id="v49" data-v="49" data-xref="列王紀上 7:15–21; 以西結書 40:34; 歷代志下 3:17"> 門廊長十米，寬六米。有一排台階上到門廊，牆柱兩旁各有一根柱子。</span>
</div>
</div>

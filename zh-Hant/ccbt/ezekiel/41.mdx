<span className="v" id="v1" data-v="1" data-xref="以西結書 40:2–3; 以西結書 40:17; 以西結書 41:23"> 那人帶我進入殿堂，量兩邊的牆柱，各三米寬。</span>
<span className="v" id="v2" data-v="2" data-xref="列王紀上 6:17; 歷代志下 3:3; 列王紀上 6:2"> 殿的入口寬五米，兩邊的牆各寬兩米半。殿堂長二十米，寬十米。</span>
<span className="v" id="v3" data-v="3" data-xref="以西結書 40:16"> 他到內殿的入口，量兩邊的牆柱，各一米寬，門寬三米，兩邊的牆各寬三米半。</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀上 6:20; 希伯來書 9:3–8; 出埃及記 26:33–34"> 他量了內殿，長寬各十米。他對我說：「這是至聖所。」</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀上 6:5–6; 以西結書 42:3–14; 以西結書 41:6–9"> 他又量殿牆，厚三米，殿的外圍有廂房，每間寬二米。</span>
<span className="v" id="v6" data-v="6" data-xref="列王紀上 6:10; 列王紀上 6:5–6; 以西結書 40:17"> 廂房是一層疊一層的，共有三層，每層有三十個房間。殿牆外圍有支撐廂房梁木的牆坎，以免梁木插入殿牆中。</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀上 6:8; 希伯來書 6:1; 馬太福音 13:32"> 這些廂房的設計是越往上層越寬，殿周圍的建築是層層向上建的，所以越往上層，房間越寬，有樓梯自下層經過中層到上層。</span>
<span className="v" id="v8" data-v="8" data-xref="以西結書 40:5; 啟示錄 21:16"> 我看見殿的周圍有突出的平臺，高一竿，構成廂房的根基。</span>
<span className="v" id="v9" data-v="9" data-xref="以西結書 41:11; 以西結書 42:4; 以西結書 42:1"> 廂房外牆厚二米半，廂房與祭司房之間是一塊圍繞著殿的空地，寬十米。</span>
<span className="v" id="v11" data-v="11" data-xref="以西結書 41:9; 以西結書 42:4"> 廂房有兩個門口朝著空地，一南一北。廂房周圍與空地相連的平臺寬兩米半。</span>
<span className="v" id="v12" data-v="12" data-xref="以西結書 42:1; 以西結書 42:13; 以西結書 41:13–15"> 在殿前空地向西的地方有一棟建築物，寬三十五米，長四十五米，牆厚兩米半。</span>
<span className="v" id="v13" data-v="13" data-xref="以西結書 40:47"> 他量了殿，長五十米。殿的院子，那棟建築物和牆共長五十米。</span>
<span className="v" id="v14" data-v="14"> 殿東邊的空地寬五十米。</span>
<span className="v" id="v15" data-v="15" data-xref="以西結書 42:3; 以西結書 42:1; 以西結書 41:12"> 他量了殿後面、空地對面的那棟建築物，及其兩邊走廊的長度，共長五十米。 聖所、至聖所、院子的門廊，</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀上 6:4; 以西結書 40:25; 以西結書 40:16"> 它們周圍的門檻、格子窗和走廊從地面到窗沿都鑲有木板。</span>
<span className="v" id="v17" data-v="17" data-xref="以西結書 42:15"> 殿的入口和內殿裡外四周的牆也按尺寸鑲著木板。</span>
<span className="v" id="v18" data-v="18" data-xref="列王紀上 7:36; 以西結書 40:16; 以西結書 40:22"> 木板上刻著基路伯天使和棕樹，兩者彼此相間排列。每個基路伯天使有兩個面孔：</span>
<span className="v" id="v19" data-v="19" data-xref="以西結書 10:14; 以西結書 1:10"> 一個是人的臉，面向一邊的棕樹；一個是獅子的臉，面向另一邊的棕樹。整個殿四圍都刻著基路伯天使和棕樹。</span>
<span className="v" id="v20" data-v="20" data-xref="以西結書 41:18"> 從地板到門以上殿內牆壁上都刻著基路伯天使和棕樹。</span>
<span className="v" id="v21" data-v="21" data-xref="以西結書 41:1; 列王紀上 6:33; 以西結書 40:14"> 聖所的門框是方形的，至聖所前的門框也一樣。</span>
<span className="v" id="v22" data-v="22" data-xref="瑪拉基書 1:12; 以西結書 23:41; 瑪拉基書 1:7"> 聖所裡面有一座木頭做的祭壇，高一米半，長寬各一米，壇的四角、底及四面都是木造的。他對我說：「這是耶和華面前的桌子。」</span>
<span className="v" id="v23" data-v="23" data-xref="列王紀上 6:31–35; 歷代志下 4:22; 以西結書 41:1"> 聖所和至聖所各有一道雙扇的門，</span>
<span className="v" id="v24" data-v="24" data-xref="列王紀上 6:34; 以西結書 40:48"> 每扇都是可以折疊的雙頁門，</span>
<span className="v" id="v25" data-v="25" data-xref="以西結書 41:18"> 聖所的門上也刻有基路伯天使和棕樹，與牆上所刻的一樣。門廊上有木造的廊簷。</span>
<span className="v" id="v26" data-v="26" data-xref="以西結書 41:16; 以西結書 40:16; 以西結書 41:5"> 聖殿門廊兩側的牆壁上有格子窗和棕樹雕刻，廂房都有房簷。</span>

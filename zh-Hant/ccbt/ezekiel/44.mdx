## 君王，利未人和祭司

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西結書 43:1; 以西結書 40:17; 以西結書 42:14"> 那人又把我帶到聖所外院的東門，門關閉著。</span>
<span className="v" id="v2" data-v="2" data-xref="以西結書 43:2–4; 出埃及記 24:10; 以賽亞書 6:1–5"> 耶和華對我說：「這門必須關閉，不可打開。人不可從這門進入，因為以色列的上帝耶和華已從這門進入，所以這門必須關閉。</span>
<span className="v" id="v3" data-v="3" data-xref="以西結書 46:2; 以西結書 34:24; 以西結書 37:25"> 只有君王可以坐在裡面，在耶和華面前進食。他要從門廊進入，也要從原路出去。」</span>
<span className="v" id="v4" data-v="4" data-xref="以西結書 1:28; 啟示錄 1:17; 以西結書 3:23"> 他帶我從北門來到殿前，我看見耶和華的榮光充滿了祂的殿，我就俯伏在地。</span>
<span className="v" id="v5" data-v="5" data-xref="以西結書 40:4; 以西結書 43:10–11; 申命記 12:32"> 耶和華對我說：「人子啊，你要認真看，仔細聽我講有關耶和華聖殿的一切規矩和法則，記住所有的出入口。</span>
<span className="v" id="v6" data-v="6" data-xref="以西結書 3:9; 以西結書 45:9; 彼得前書 4:3"> 然後告訴那些叛逆的以色列人，主耶和華這樣說，『以色列人啊，你們行可憎的事，該夠了吧！</span>
<span className="v" id="v7" data-v="7" data-xref="利未記 22:25; 耶利米書 9:26; 以西結書 44:9"> 你們獻上食物、脂肪和血的同時，竟將那些身心未受割禮的外族人領進我的聖所，褻瀆我的殿，破壞我的約，使你們罪上加罪。</span>
<span className="v" id="v8" data-v="8" data-xref="以西結書 44:14; 民數記 18:3–5; 以西結書 40:45–46"> 你們自己不管理我的聖物，卻把我的聖所給外人治理。</span>
<span className="v" id="v9" data-v="9" data-xref="約珥書 3:17; 以西結書 44:7; 撒迦利亞書 14:21"> 「『因此，主耶和華說：以色列人中身心未受割禮的外族人不可進入我的聖所。</span>
<span className="v" id="v10" data-v="10" data-xref="以西結書 22:26; 以西結書 48:11; 列王紀下 23:8–9"> 「『以色列人走入歧途時，有些利未人也遠離我、追隨偶像，他們必須承擔自己犯罪的後果。</span>
<span className="v" id="v11" data-v="11" data-xref="民數記 16:9; 歷代志下 29:34; 歷代志下 30:17"> 然而，他們仍可以在我的聖殿供職，看管殿門，為百姓屠宰燔祭牲和其他祭牲，服侍他們。</span>
<span className="v" id="v12" data-v="12" data-xref="列王紀下 16:10–16; 詩篇 106:26; 以西結書 14:3–4"> 因為利未人帶動以色列人拜偶像，使以色列人陷入罪中，所以我起誓，他們必承擔自己犯罪的後果。這是主耶和華說的。</span>
<span className="v" id="v13" data-v="13" data-xref="民數記 18:3; 列王紀下 23:9; 以西結書 16:61"> 他們不得走近我，不可做我的祭司，也不得走近我的聖物或至聖之物，他們必因自己的可憎行徑蒙羞。</span>
<span className="v" id="v14" data-v="14" data-xref="歷代志上 23:28–32; 民數記 18:4"> 然而，我要委派他們管理聖殿，辦理殿中所有的事務。</span>
<span className="v" id="v15" data-v="15" data-xref="申命記 10:8; 以西結書 48:11; 以西結書 44:7"> 「『以色列人走入歧途時，利未祭司——撒督的子孫仍然在我的聖所盡忠職守，因此他們可以接近我、事奉我，侍立在我面前，獻上祭牲的脂肪和血。這是主耶和華說的。</span>
<span className="v" id="v16" data-v="16" data-xref="以西結書 41:22; 瑪拉基書 1:12; 民數記 18:7–8"> 只有他們可以進入我的聖所，在我的桌前事奉我，遵行我的吩咐。</span>
<span className="v" id="v17" data-v="17" data-xref="啟示錄 19:8; 出埃及記 28:43; 出埃及記 39:27–29"> 他們從內院的門進入殿內供職的時候，要穿細麻布衣服，不可穿羊毛衣服。</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及記 39:28; 哥林多前書 11:4–10; 以賽亞書 3:20"> 他們要戴細麻布頭巾，穿細麻布褲子，不可穿使人容易出汗的衣服。</span>
<span className="v" id="v19" data-v="19" data-xref="以西結書 46:20; 利未記 6:27; 利未記 6:10–11"> 他們出去外院見百姓的時候，必須脫下供職時穿的衣服，放在聖屋，穿上普通的衣服後再出去，免得通過聖衣把聖潔帶到百姓身上。</span>
<span className="v" id="v20" data-v="20" data-xref="哥林多前書 11:14; 民數記 6:5; 利未記 21:5–24"> 他們不可剃光頭，也不可留長頭髮，只可修剪頭髮。</span>
<span className="v" id="v21" data-v="21" data-xref="利未記 10:9; 提多書 1:7–8; 提摩太前書 5:23"> 祭司進入內院時，不可喝酒。</span>
<span className="v" id="v22" data-v="22" data-xref="利未記 21:7; 利未記 21:13–14; 提摩太前書 3:2"> 他們不可娶寡婦或被休的婦女為妻，只能娶以色列的處女或祭司的遺孀。</span>
<span className="v" id="v23" data-v="23" data-xref="以西結書 22:26; 利未記 10:10–11; 提摩太後書 2:24–25"> 他們要教導我的子民辨別聖與俗，潔淨與不潔淨。</span>
<span className="v" id="v24" data-v="24" data-xref="歷代志上 23:4; 以西結書 22:26; 歷代志下 19:8–10"> 他們要審理訴訟之事，按我的律例斷是非。他們必須按我定的律例和法度遵守一切節期，守安息日為聖日。</span>
<span className="v" id="v25" data-v="25" data-xref="哥林多後書 5:16; 利未記 22:4; 馬太福音 8:21–22"> 他們不可走近死屍，免得玷污自己，除非死者是自己的父母、子女、弟兄或未出嫁的姊妹。</span>
<span className="v" id="v26" data-v="26" data-xref="希伯來書 9:13–14; 民數記 19:11–14; 民數記 6:10–21"> 祭司得到潔淨後，必須再等七天。</span>
<span className="v" id="v27" data-v="27" data-xref="民數記 6:9–11; 以西結書 44:17; 利未記 4:3–35"> 他進入內院的聖所事奉時，要為自己獻上贖罪祭，這是主耶和華說的。</span>
<span className="v" id="v28" data-v="28" data-xref="約書亞記 13:33; 民數記 18:20; 申命記 18:1–2"> 「『我是祭司的產業。祭司不可在以色列擁有自己的產業，因為我就是他們的產業。</span>
<span className="v" id="v29" data-v="29" data-xref="民數記 18:14; 利未記 27:21; 利未記 27:28"> 他們的食物是以色列人獻上的素祭、贖罪祭和贖過祭。凡以色列人獻給耶和華的都歸他們，</span>
<span className="v" id="v30" data-v="30" data-xref="尼希米記 10:35–37; 歷代志下 31:10; 申命記 18:4"> 各種初熟的出產和各種供物中上好的部分都要歸給祭司。你們將初熟的麥子磨成麵給祭司，福氣就必臨到你們的家。</span>
<span className="v" id="v31" data-v="31" data-xref="利未記 22:8; 出埃及記 22:31; 申命記 14:21"> 無論是自然死亡的，還是被其他野獸咬死的禽獸，祭司都不可吃。</span>

## 耶路撒冷的不忠

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華對我說：</span>
<span className="v" id="v2" data-v="2" data-xref="以西結書 22:2; 以西結書 20:4; 以賽亞書 58:1"> 「人子啊，你要使耶路撒冷知道她的可憎行徑。</span>
<span className="v" id="v3" data-v="3" data-xref="以西結書 16:45; 以賽亞書 51:1–2; 申命記 20:17"> 你要告訴她，主耶和華這樣對她說，『你祖居迦南，生於迦南。你的父親是亞摩利人，母親是赫人。</span>
<span className="v" id="v4" data-v="4" data-xref="何西阿書 2:3; 創世記 15:13; 出埃及記 5:16–21"> 你出生之日沒人剪斷你的臍帶，沒人用水洗你的身體，沒人用鹽擦淨你，沒人用布包裹你。</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 32:10; 創世記 21:10; 出埃及記 1:22"> 沒有人可憐你，同情你，為你做以上的事。你生下來便遭人厭惡，被扔在野外。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="以弗所書 2:4–5; 約翰福音 5:25; 提多書 3:3–7"> 「『我從你旁邊經過，見你在血泊中掙扎，便對血泊中的你說，活下去！</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 1:10; 出埃及記 1:7; 以賽亞書 62:3"> 我使你像田間的植物一樣茁壯生長。你漸漸發育成熟，長得亭亭玉立，雙乳豐滿，秀髮垂肩，但仍然赤身露體。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="路得記 3:9; 耶利米書 2:2–3; 羅馬書 5:8"> 「『後來我又從你旁邊經過，見你正值少女懷春，我便用我的衣襟遮蓋你赤露的身體，向你起誓，與你定下婚約，你便屬於我。這是主耶和華說的。</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 23:5; 路得記 3:3; 約翰一書 2:27"> 我用水清洗你，洗淨你身上的血污，給你塗上馨香的油，</span>
<span className="v" id="v10" data-v="10" data-xref="以西結書 16:18; 以西結書 16:13; 以賽亞書 61:10"> 給你穿上錦繡的衣裳和海狗皮的鞋，披上細麻衣和絲綢外袍。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 24:22; 以賽亞書 3:19; 創世記 41:42"> 我用首飾來裝扮你，給你戴上手鐲、項鏈、</span>
<span className="v" id="v12" data-v="12" data-xref="以賽亞書 3:21; 以賽亞書 28:5; 耶利米書 13:18"> 鼻環、耳環和華冠。</span>
<span className="v" id="v13" data-v="13" data-xref="申命記 32:13–14; 詩篇 50:2; 列王紀上 4:21"> 這樣，你戴的是金銀首飾，穿的是綾羅綢緞，吃的是細麵粉、蜂蜜和油。你變得美豔絕倫，晉升為王后。</span>
<span className="v" id="v14" data-v="14" data-xref="列王紀上 10:24; 耶利米哀歌 2:15; 哥林多前書 4:7"> 你的美貌名揚列國，因為我給你的華貴使你美貌無比。這是主耶和華說的。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="以賽亞書 57:8; 耶利米書 2:20; 以西結書 16:25"> 「『你卻仗著自己的美貌和名聲縱情淫亂，與所有過路的人縱情苟合。</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀下 23:7; 以西結書 7:20; 歷代志下 28:24"> 你用自己的衣服在拜偶像的邱壇結彩，在那裡行淫。這樣的事真是空前絕後！</span>
<span className="v" id="v17" data-v="17" data-xref="以西結書 23:14–21; 耶利米書 3:9; 以西結書 16:11"> 你用我給你的金銀首飾為自己製造男人的像，與它們苟合。</span>
<span className="v" id="v18" data-v="18"> 你給它們穿上錦繡衣服，把我給你的膏油和香料供奉它們。</span>
<span className="v" id="v19" data-v="19" data-xref="以西結書 16:13; 何西阿書 2:8–13; 創世記 8:21"> 你把我賜你吃的細麵粉、油和蜂蜜作為馨香的供物奉獻在它們面前。這是主耶和華說的。</span>
<span className="v" id="v20" data-v="20" data-xref="以西結書 23:37; 以西結書 20:31; 耶利米書 7:31"> 你還把你給我生的兒女獻給偶像作食物。難道你淫亂還不夠嗎？</span>
<span className="v" id="v21" data-v="21" data-xref="列王紀下 17:17; 利未記 18:21; 申命記 18:10"> 你竟屠殺我的兒女，把他們焚燒獻給偶像。</span>
<span className="v" id="v22" data-v="22" data-xref="耶利米書 2:2; 何西阿書 11:1; 以西結書 16:43"> 你做這一切可憎、淫亂的事，忘記了你幼年赤身露體在血泊中掙扎的日子。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="啟示錄 12:12; 以西結書 2:10; 以西結書 24:6"> 「『主耶和華說，你有禍了！你有禍了！你不但做了這些惡事，</span>
<span className="v" id="v24" data-v="24" data-xref="詩篇 78:58; 以西結書 16:39; 以西結書 16:31"> 還為自己築祭壇，在各廣場建高高的神廟。</span>
<span className="v" id="v25" data-v="25" data-xref="以西結書 16:31; 耶利米書 3:2; 創世記 38:21"> 你在街頭巷尾建高高的神廟，糟蹋自己的美貌。你向每一個過路的人投懷送抱，縱情淫亂。</span>
<span className="v" id="v26" data-v="26" data-xref="以西結書 23:19–21; 以西結書 20:7–8; 以西結書 8:10"> 你還與放縱情慾的鄰邦埃及人苟合，縱情淫亂，激起我的憤怒。</span>
<span className="v" id="v27" data-v="27" data-xref="以賽亞書 9:12; 以西結書 16:57; 以西結書 16:37"> 看啊，我要伸手攻擊你，削減你的口糧，把你交給憎恨你的非利士人，任他們宰割。他們都為你的淫蕩行為感到羞恥。</span>
<span className="v" id="v28" data-v="28" data-xref="列王紀下 16:7; 何西阿書 10:6; 列王紀下 16:10–18"> 你慾海難填，又跟亞述人行淫，但你仍不滿足，</span>
<span className="v" id="v29" data-v="29" data-xref="列王紀下 21:9; 士師記 2:12–19; 以西結書 13:14–23"> 於是又跟那商賈之地的迦勒底人縱情淫亂，但你仍不滿足。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="耶利米書 3:3; 以賽亞書 1:3; 以賽亞書 3:9"> 「『主耶和華說，你的心敗壞至極，所作所為簡直就像不知羞恥的娼妓。</span>
<span className="v" id="v31" data-v="31" data-xref="以西結書 16:33–34; 以賽亞書 52:3; 以西結書 16:39"> 你在街頭巷尾築祭壇，在廣場建高高的神廟，甚至不屑於收嫖資，實在連妓女都不如。</span>
<span className="v" id="v32" data-v="32" data-xref="耶利米書 2:28; 以西結書 23:37; 耶利米書 2:25"> 你這蕩婦，寧願跟外人淫亂，也不愛自己的丈夫！</span>
<span className="v" id="v33" data-v="33" data-xref="以賽亞書 57:9; 何西阿書 8:9–10; 以西結書 16:41"> 妓女接受嫖資，你卻送禮物給所有的情人，引誘他們從四方前來跟你淫亂。</span>
<span className="v" id="v34" data-v="34"> 你賣淫不同於別的妓女，沒有人找你買春，沒有人給你嫖資，你倒貼錢給人，你真是與眾不同。</span>
</div>
</div>

## 主對耶路撒冷的審判和應許

<div className="bt">
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="約翰福音 4:18; 列王紀上 22:19; 約翰福音 4:10"> 「『你這淫婦，要聽耶和華的話。</span>
<span className="v" id="v36" data-v="36" data-xref="以西結書 23:10; 以西結書 24:13; 西番雅書 3:1"> 主耶和華說，你放縱情慾，赤身露體地與眾情人苟合。你祭拜一切可憎的偶像，把自己兒女的血獻給它們。</span>
<span className="v" id="v37" data-v="37" data-xref="何西阿書 2:10; 耶利米書 13:22; 何西阿書 2:3"> 因此，我要把你所愛和所恨的情人都聚集起來。我要聚集他們從四方攻擊你，讓你赤裸裸地暴露在他們面前，讓他們看到你赤身露體。</span>
<span className="v" id="v38" data-v="38" data-xref="利未記 20:10; 創世記 9:6; 西番雅書 1:17"> 我要懲罰你，像懲罰淫亂和殺人的婦女一樣。我要把烈怒和義憤倒在你身上，報應你殺人流血的罪。</span>
<span className="v" id="v39" data-v="39" data-xref="以西結書 23:26; 何西阿書 2:3; 以西結書 16:24–25"> 我要把你交在你的情人手裡。他們必拆毀你的祭壇，夷平你高高的神廟，剝去你的衣裳，奪走你的珠寶，留下你赤身露體。</span>
<span className="v" id="v40" data-v="40" data-xref="以西結書 23:47; 哈巴谷書 1:6–10; 約翰福音 8:5–7"> 他們要聚眾攻擊你，用石頭打你，用刀劍砍碎你，</span>
<span className="v" id="v41" data-v="41" data-xref="以西結書 23:48; 耶利米書 52:13; 耶利米書 39:8"> 燒毀你的房屋，在眾婦女面前審判你。我要阻止你的淫亂行為，使你不再倒貼錢給情人。</span>
<span className="v" id="v42" data-v="42" data-xref="以西結書 5:13; 以西結書 21:17; 以賽亞書 40:1–2"> 這樣，我的烈怒才會平息，我的義憤才會消除，我才會平靜下來，不再發怒。</span>
<span className="v" id="v43" data-v="43" data-xref="以西結書 16:22; 以西結書 11:21; 詩篇 78:42"> 因為你忘記了幼年的日子，做這些事來惹我發怒，我要照你的所作所為報應你。因為你不僅行一切可憎的事，還放蕩淫亂。這是主耶和華說的。</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="以西結書 18:2–3; 詩篇 106:35–38; 撒母耳記上 24:13"> 「『看啊，好說俗語的人都會譏諷你說，有其母必有其女。</span>
<span className="v" id="v45" data-v="45" data-xref="撒迦利亞書 11:8; 以賽亞書 1:4; 以西結書 23:37–39"> 你和你母親及姊妹如出一轍，都厭棄自己的丈夫和兒女。你母親是赫人，你父親是亞摩利人。</span>
<span className="v" id="v46" data-v="46" data-xref="以西結書 23:4; 以西結書 16:48–49; 以西結書 16:53–56"> 你姐姐是撒瑪利亞，她和她的女兒們住在你的北面。你妹妹是所多瑪，她和她的女兒們住在你的南面。</span>
<span className="v" id="v47" data-v="47" data-xref="列王紀下 21:9; 以西結書 16:51; 以西結書 5:6–7"> 你不僅追隨和效法她們可憎的行徑，還很快超過了她們。</span>
<span className="v" id="v48" data-v="48" data-xref="馬太福音 10:15; 路加福音 10:12; 使徒行傳 7:52"> 我憑我的永恆起誓，與你妹妹所多瑪和她女兒們相比，你和你女兒們的行徑有過之而無不及。這是主耶和華說的。</span>
<span className="v" id="v49" data-v="49" data-xref="詩篇 138:6; 以西結書 28:2; 創世記 13:10"> 看啊，你妹妹所多瑪和她的女兒們狂妄自大，安逸飽足，對窮困的人漠不關心。這就是你妹妹所多瑪的罪過。</span>
<span className="v" id="v50" data-v="50" data-xref="創世記 19:24; 創世記 18:20; 創世記 19:5"> 她們心驕氣傲，在我面前做可憎的事，我看見後便除掉了她們。</span>
<span className="v" id="v51" data-v="51" data-xref="耶利米書 3:8–11; 路加福音 12:47–48; 羅馬書 3:9–20"> 撒瑪利亞的罪還不及你的一半，你比她們做了更多可憎之事，以致與你的可憎行徑相比，你的姊妹倒顯得公義了。</span>
<span className="v" id="v52" data-v="52" data-xref="馬太福音 7:1–5; 以西結書 36:15; 以西結書 16:56"> 既然你幫了你的姊妹，使她們顯得公義，你就蒙受羞辱吧！因為你犯的罪比你姊妹犯的罪更可憎，以致她們顯得比你更公義。因此，你就自取其辱，抱愧蒙羞吧！</span>
</div>
<div className="bp">
<span className="v" id="v53" data-v="53" data-xref="以西結書 29:14; 耶利米書 12:16; 以西結書 39:25"> 「『然而，我要使所多瑪、撒瑪利亞及她們的女兒們復興，並使你一同復興，</span>
<span className="v" id="v54" data-v="54" data-xref="以西結書 14:22–23; 耶利米書 2:26; 以西結書 36:31–32"> 讓你自取其辱，深感羞愧，因為你的一切惡行使她們反得安慰。</span>
<span className="v" id="v55" data-v="55" data-xref="以西結書 36:11; 瑪拉基書 3:4; 以西結書 16:53"> 你姊妹所多瑪、撒瑪利亞和她們的眾女兒，以及你和你的眾女兒必恢復起初的光景。</span>
<span className="v" id="v56" data-v="56" data-xref="以賽亞書 65:5; 路加福音 15:28–30; 西番雅書 3:11"> 在你驕傲的日子，你的惡行還沒有被揭露的時候，你覺得妹妹所多瑪不屑一提。但現在，你卻成為以東的眾女兒和她四鄰非利士的眾女兒的笑柄。你周圍的人都鄙視你。</span>
<span className="v" id="v58" data-v="58" data-xref="以西結書 23:49; 耶利米哀歌 5:7; 創世記 4:13"> 你要承擔淫蕩和可憎行徑帶來的懲罰。這是耶和華說的。</span>
</div>
<div className="bp">
<span className="v" id="v59" data-v="59" data-xref="以賽亞書 24:5; 以西結書 17:19; 申命記 29:25"> 「『主耶和華說，你背誓毀約，我必照你的所作所為報應你。</span>
<span className="v" id="v60" data-v="60" data-xref="何西阿書 2:19–20; 希伯來書 12:24; 以西結書 16:8"> 然而，我顧念在你幼年時與你所立的約，我要與你立一個永遠的約。</span>
<span className="v" id="v61" data-v="61" data-xref="希伯來書 8:13; 加拉太書 4:26–31; 以賽亞書 66:7–12"> 你接納你姊妹的時候，會想起自己的所作所為並自覺羞愧。我要將你姊妹賜給你作女兒，我這樣做並不是出於我與你所立的約。</span>
<span className="v" id="v62" data-v="62" data-xref="耶利米書 24:7; 以西結書 6:7; 以西結書 39:22"> 我要和你立約，使你知道我是耶和華。</span>
<span className="v" id="v63" data-v="63" data-xref="詩篇 39:9; 羅馬書 3:19; 以西結書 36:31–32"> 我要赦免你所有的罪，那時你想起這事會羞愧難當，不敢再開口。這是主耶和華說的。』」</span>
</div>
</div>

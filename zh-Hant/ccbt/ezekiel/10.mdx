## 耶和華的榮耀離開聖殿

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及記 24:10; 啟示錄 4:2–3; 啟示錄 1:13"> 我觀看，只見基路伯天使頭頂上的穹蒼之中好像有一個藍寶石寶座。</span>
<span className="v" id="v2" data-v="2" data-xref="啟示錄 8:5; 以西結書 10:16; 以西結書 1:13"> 耶和華對那穿細麻衣的人說：「你到基路伯天使下邊旋轉的輪子中間，雙手捧滿火炭，撒在城上。」我見他進去了。</span>
<span className="v" id="v3" data-v="3" data-xref="以西結書 43:4; 以西結書 9:3; 以西結書 8:16"> 當他進去的時候，基路伯天使站在殿的南邊，內院充滿了雲彩。</span>
<span className="v" id="v4" data-v="4" data-xref="以西結書 1:28; 以西結書 9:3; 出埃及記 40:35"> 耶和華的榮耀從基路伯天使的上面升起，停在殿的門口，殿裡充滿了雲彩，院子也充滿了耶和華榮耀的光輝。</span>
<span className="v" id="v5" data-v="5" data-xref="以西結書 1:24; 約伯記 40:9; 出埃及記 19:16"> 基路伯天使展翅的響聲好像全能上帝說話的聲音，在外院也可以聽見。</span>
<span className="v" id="v6" data-v="6" data-xref="以西結書 10:2; 詩篇 99:1; 詩篇 80:1"> 祂對那穿細麻衣的人說：「你要從基路伯天使下面旋轉的輪子中取火。」那人便進去，站在一個輪子旁邊。</span>
<span className="v" id="v7" data-v="7" data-xref="馬太福音 13:41–42; 以西結書 1:13; 以西結書 41:23–26"> 有一個基路伯天使伸手到他們中間的火裡，取了些火放在那穿細麻衣的人手裡，那人就拿了出去。</span>
<span className="v" id="v8" data-v="8" data-xref="以西結書 1:8; 以西結書 10:21; 以賽亞書 6:6"> 基路伯天使的翅膀下彷彿有人的手。</span>
<span className="v" id="v9" data-v="9" data-xref="以西結書 1:15–17; 但以理書 10:6; 啟示錄 21:20"> 我又看見四個基路伯天使旁各有一個閃耀如綠寶石的輪子。</span>
<span className="v" id="v10" data-v="10" data-xref="以西結書 1:16; 詩篇 36:6; 詩篇 104:24"> 四個輪子結構一樣，好像輪套輪。</span>
<span className="v" id="v11" data-v="11" data-xref="以西結書 1:17; 以西結書 10:22; 以西結書 1:20"> 基路伯天使移動時，不必轉身就可以向四方移動。前輪朝哪個方向移動，其他輪子也朝哪個方向移動，不必轉向。</span>
<span className="v" id="v12" data-v="12" data-xref="以西結書 1:18; 啟示錄 4:8; 啟示錄 4:6"> 這四個基路伯天使的手、背、翅膀及全身都佈滿了眼睛，包括他們的四個輪子。</span>
<span className="v" id="v13" data-v="13"> 我聽見他們稱這些輪子為「旋轉輪」。</span>
<span className="v" id="v14" data-v="14" data-xref="啟示錄 4:7; 以西結書 10:21; 列王紀上 7:36"> 每一個基路伯天使都有四張臉：第一張是基路伯天使的臉，第二張是人的臉，第三張是獅子的臉，第四張是鷹的臉。</span>
<span className="v" id="v15" data-v="15" data-xref="以西結書 1:5; 何西阿書 9:12; 以西結書 11:22"> 然後，這些基路伯天使都向上升去，他們就是我在迦巴魯河邊所見的活物。</span>
<span className="v" id="v16" data-v="16" data-xref="以西結書 1:19–21"> 基路伯天使移動，輪子也隨之移動；基路伯天使展翅飛離地面，輪子也隨之離開地面，不離他們旁邊；</span>
<span className="v" id="v17" data-v="17" data-xref="以西結書 1:20–21; 羅馬書 8:2; 以西結書 1:12"> 基路伯天使停住，輪子也隨之停住；基路伯天使上升，輪子也隨之上升。因為活物的靈在輪子中。</span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 18:10; 馬太福音 23:37–39; 詩篇 78:60–61"> 那時，耶和華的榮耀離開了殿的門口，停在基路伯天使上面。</span>
<span className="v" id="v19" data-v="19" data-xref="以西結書 8:16; 以西結書 1:17–21; 以西結書 1:26–28"> 我正觀看時，基路伯天使展翅飛離地面，他們旁邊的輪子也隨之飛離。他們停在耶和華殿的東門口，以色列上帝的榮耀在他們上面。</span>
<span className="v" id="v20" data-v="20" data-xref="以西結書 1:1; 以西結書 10:15; 列王紀上 7:36"> 這些是我在迦巴魯河邊所看見的活物，他們在以色列上帝的下面。我知道他們是基路伯天使。</span>
<span className="v" id="v21" data-v="21" data-xref="以西結書 1:6; 以西結書 41:18–19; 以西結書 10:14"> 他們各有四張臉，兩對翅膀，翅膀下彷彿有人的手，</span>
<span className="v" id="v22" data-v="22" data-xref="以西結書 10:11; 以西結書 1:10; 以西結書 1:12"> 他們的面貌和我在迦巴魯河邊所見的一樣，每一個都向前直走。</span>

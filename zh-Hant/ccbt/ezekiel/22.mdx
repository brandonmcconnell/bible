## 耶路撒冷的罪惡

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華對我說：</span>
<span className="v" id="v2" data-v="2" data-xref="以賽亞書 58:1; 以西結書 24:6; 以西結書 24:9"> 「人子啊，你要審判這殺人流血的城嗎？你要審判她？那就使她知道自己一切可憎的行為。</span>
<span className="v" id="v3" data-v="3" data-xref="以西結書 22:27; 羅馬書 2:5; 彼得後書 2:3"> 你要向她宣告主耶和華的話，說，『唉，你這殺人流血、製造偶像玷污自己的城啊，你的末日到了。</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀下 21:16; 詩篇 44:13–14; 以西結書 22:2"> 你既犯罪殺人，製造偶像玷污自己，使你滅亡的日子近了，你的大限到了，我要使你成為列國列邦侮辱和譏諷的對象。</span>
<span className="v" id="v5" data-v="5" data-xref="以賽亞書 22:2; 耶利米書 15:2–3"> 你這聲名狼藉、混亂不堪的城將要受到遠近各國的恥笑。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="以西結書 22:27; 以賽亞書 1:23; 撒迦利亞書 3:3"> 「『看啊，在你城中的以色列首領各逞權勢，殺人流血。</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 27:16; 出埃及記 22:21–22; 利未記 20:9"> 他們輕慢父母，壓迫寄居者，欺負孤兒寡婦。</span>
<span className="v" id="v8" data-v="8" data-xref="以西結書 23:38–39; 以西結書 22:26; 以西結書 20:13"> 你藐視我的聖物，褻瀆我的安息日。</span>
<span className="v" id="v9" data-v="9" data-xref="何西阿書 4:14; 利未記 19:16; 何西阿書 4:10"> 在你這城中，有人好誹謗、殺人流血，有人在山上吃祭物，有人淫亂，</span>
<span className="v" id="v10" data-v="10" data-xref="利未記 18:19; 利未記 18:7–8; 以西結書 18:6"> 有人與繼母通姦，羞辱父親，有人姦污經期不潔的婦女，</span>
<span className="v" id="v11" data-v="11" data-xref="利未記 18:15; 撒母耳記下 13:14; 利未記 20:17"> 有人與鄰居的妻子幹出可憎之事，有人玷污自己的兒媳婦，有人姦污自己的同父姊妹。</span>
<span className="v" id="v12" data-v="12" data-xref="申命記 27:25; 以西結書 23:35; 詩篇 106:21"> 在你這城中，他們受賄殺人，放債取利，壓榨鄰居，早把我忘了。這是主耶和華說的。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="以西結書 21:17; 以賽亞書 33:15; 阿摩司書 2:6–8"> 「『我見你謀財害命，就擊掌歎息。</span>
<span className="v" id="v14" data-v="14" data-xref="以西結書 21:7; 以西結書 17:24; 以西結書 24:14"> 在我懲罰你的日子，你還有勇氣和力量嗎？我耶和華言出必行，</span>
<span className="v" id="v15" data-v="15" data-xref="尼希米記 1:8; 以西結書 22:22; 申命記 4:27"> 我要把你驅散到列國，分散到列邦，我要除掉你的污穢。</span>
<span className="v" id="v16" data-v="16" data-xref="以西結書 6:7; 詩篇 83:18; 以西結書 7:24"> 你必在列國面前受凌辱，你便知道我是耶和華。』」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17"> 耶和華對我說：</span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 119:119; 以賽亞書 1:22; 耶利米書 6:28–30"> 「人子啊，在我看來，以色列人已經變成了渣滓。他們是爐中的銅、錫、鐵、鉛，都是銀渣滓。</span>
<span className="v" id="v19" data-v="19" data-xref="馬太福音 13:30; 以西結書 24:3–6; 彌迦書 4:12"> 所以主耶和華說，『你們既都是渣滓，我要把你們聚集在耶路撒冷城。</span>
<span className="v" id="v20" data-v="20" data-xref="耶利米書 4:11–12; 以賽亞書 54:16; 以西結書 24:13"> 我要在義憤和烈怒中把你們聚集在城裡熔化，就像人把銀、銅、鐵、鉛、錫聚在爐中，吹旺爐火熔化一樣。</span>
<span className="v" id="v21" data-v="21" data-xref="以賽亞書 64:7; 那鴻書 1:6; 詩篇 50:3"> 我要聚集你們，把我的怒火倒在你們身上，你們必在城中熔化。</span>
<span className="v" id="v22" data-v="22" data-xref="以西結書 20:8; 以西結書 20:33; 何西阿書 5:10"> 你們要在城中熔化，就像銀在煉爐中熔化。你們就知道我耶和華已將我的烈怒傾倒在你們身上。』」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23"> 耶和華對我說：</span>
<span className="v" id="v24" data-v="24" data-xref="歷代志下 36:14–16; 耶利米書 2:30; 歷代志下 28:22"> 「人子啊，你要對以色列說，『在我發怒的日子，將沒有雨水滋潤你這不潔之地。』</span>
<span className="v" id="v25" data-v="25" data-xref="何西阿書 6:9; 耶利米書 2:34; 以西結書 13:19"> 你的首領圖謀惡事，好像咆哮著撕碎獵物的獅子，他們草菅人命，搶奪財寶，使多人變成寡婦。</span>
<span className="v" id="v26" data-v="26" data-xref="利未記 10:10; 以西結書 44:23; 以西結書 22:8"> 你的祭司強解我的律法，褻瀆我的聖物。他們聖俗不分，也不教導人分辨潔淨的和不潔淨的。他們藐視我的安息日，以致我在他們當中被褻瀆。</span>
<span className="v" id="v27" data-v="27" data-xref="以西結書 22:13; 以賽亞書 1:23; 以西結書 22:6"> 你的首領好像撕碎獵物的豺狼，殺人流血，謀取不義之財。</span>
<span className="v" id="v28" data-v="28" data-xref="以西結書 13:6–7; 以西結書 13:10–16; 耶利米書 23:25–32"> 你的先知粉飾他們的罪惡，對他們說虛假的異象和謊話連篇的占卜，謊稱『耶和華說』，其實耶和華沒有說。</span>
<span className="v" id="v29" data-v="29" data-xref="以西結書 22:7; 出埃及記 23:9; 出埃及記 22:21"> 你的居民強取豪奪，欺壓貧困的，虐待寄居的，無法無天。</span>
<span className="v" id="v30" data-v="30" data-xref="以賽亞書 59:16; 耶利米書 5:1; 詩篇 106:23"> 我想在他們中間尋找一位重修城牆的人，站在我面前為這地方堵住缺口，免得我毀滅這裡。可是，我一個也找不到。</span>
<span className="v" id="v31" data-v="31" data-xref="以西結書 16:43; 以西結書 7:8–9; 以西結書 9:10"> 因此，我要向他們傾倒我的烈怒，用怒火滅盡他們，照他們的所作所為報應他們。這是主耶和華說的。」</span>
</div>
</div>

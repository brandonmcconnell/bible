## 斥責假先知

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華對我說：</span>
<span className="v" id="v2" data-v="2" data-xref="以西結書 13:17; 耶利米書 37:19; 以西結書 22:28"> 「人子啊，你要說預言斥責以色列那些說預言的先知，告訴那些私自說預言的人，『你們要聽耶和華的話。</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米哀歌 2:14; 耶利米書 23:28–32; 何西阿書 9:7"> 主耶和華說，愚頑的先知有禍了！他們沒有看到異象，卻私自說預言。</span>
<span className="v" id="v4" data-v="4" data-xref="啟示錄 19:20; 彌迦書 2:11; 帖撒羅尼迦後書 2:9–10"> 以色列人啊，你們的先知像廢墟中的狐狸，</span>
<span className="v" id="v5" data-v="5" data-xref="以西結書 22:30; 詩篇 106:23; 以賽亞書 58:12"> 你們沒有上去堵住缺口，也沒有重建以色列的圍牆，使以色列在耶和華的日子來臨時的爭戰中堅立。</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米書 29:8; 以西結書 22:28; 耶利米書 28:15"> 他們看見的異象是虛假的，他們的占卜謊話連篇。他們口口聲聲說是傳達耶和華的話，其實耶和華並沒有差遣他們。他們竟然指望自己的謊言能夠應驗。</span>
<span className="v" id="v7" data-v="7" data-xref="以西結書 13:6; 馬太福音 24:23–24; 以西結書 13:2–3"> 你們說這是耶和華說的，其實我並沒有說。你們豈不是見了虛假的異象，說了欺詐的占卜嗎？』」</span>
<span className="v" id="v8" data-v="8" data-xref="以西結書 5:8; 以西結書 21:3; 以西結書 28:22"> 所以主耶和華說：「因為你們的假異象和謊言，我要攻擊你們。這是主耶和華說的。</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 87:6; 詩篇 69:28; 以西結書 20:38"> 我必動手攻擊那些見虛假異象、說欺詐占卜的先知。他們必從我的子民當中被剔除，不被收錄在以色列人的名冊上，也不能進入以色列的土地。這樣，你們就知道我是主耶和華。</span>
<span className="v" id="v10" data-v="10" data-xref="以西結書 22:28; 以西結書 13:16; 耶利米書 6:14"> 因為他們欺騙我的子民說，『平安！』其實並沒有平安，就像有人築了一道薄牆，用白灰加以粉飾。</span>
<span className="v" id="v11" data-v="11" data-xref="以西結書 38:22; 以賽亞書 28:2; 那鴻書 1:7–8"> 所以，你要警告那些粉刷白灰的人，說，『牆必倒塌，暴雨要來臨，冰雹勢必降下，狂風也必大作。』</span>
<span className="v" id="v12" data-v="12" data-xref="列王紀下 3:13; 耶利米哀歌 2:14–15; 士師記 9:38"> 牆倒塌之後，一定會有人問，『你們粉飾的白灰在哪裡呢？』</span>
<span className="v" id="v13" data-v="13" data-xref="以賽亞書 30:30; 啟示錄 16:21; 詩篇 148:8"> 因此，主耶和華說，『我必在烈怒中用狂風暴雨和冰雹來摧毀這牆，</span>
<span className="v" id="v14" data-v="14" data-xref="彌迦書 1:6; 耶利米書 14:15; 耶利米書 6:15"> 我必把你們粉飾的牆夷為平地，使其露出根基。牆倒塌的時候，你們必葬身其中。這樣，你們就知道我是耶和華。</span>
<span className="v" id="v15" data-v="15" data-xref="以賽亞書 30:13; 詩篇 62:3; 尼希米記 4:3"> 我要向這牆和粉飾這牆的人發烈怒，懲罰他們。我告訴你們，這牆完了！粉飾這牆的人也完了！</span>
<span className="v" id="v16" data-v="16" data-xref="以西結書 13:10; 耶利米書 6:14; 耶利米書 8:11"> 他們就是那些向耶路撒冷說假預言，在這城沒有平安的時候宣稱看到了平安異象的以色列先知。這是主耶和華說的。』</span>
<span className="v" id="v17" data-v="17" data-xref="以西結書 13:2; 列王紀下 22:14; 士師記 4:4"> 「人子啊，你要說預言斥責你同胞中私自說預言的女子，</span>
<span className="v" id="v18" data-v="18" data-xref="彼得後書 2:14; 以西結書 13:20; 提摩太後書 4:3"> 告訴她們主耶和華這樣說，『你們這些婦女有禍了！你們為了獵取人命，給人縫製戴在手腕上的符咒和各種尺寸的頭巾。你們獵取我子民的性命，還想保住自己的性命嗎？</span>
<span className="v" id="v19" data-v="19" data-xref="彌迦書 3:5; 箴言 28:21; 耶利米書 23:17"> 你們為了幾把大麥和幾塊餅，在我的子民中褻瀆我，向那些肯聽謊言的說謊，殺死那些不該死的，救活那些不該活的。』</span>
<span className="v" id="v20" data-v="20" data-xref="以西結書 13:18; 提摩太後書 3:8–9; 以西結書 13:8–9"> 「所以主耶和華說，『你們用符咒獵取人命如同捕鳥，我要除去你們的符咒，從你們手臂上扯掉它們，釋放你們像捕鳥一樣獵取的人。</span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 91:3"> 我還要撕去你們的頭巾，把我的子民從你們手中拯救出來，使他們不再做你們手中的獵物。這樣，你們就知道我是耶和華。</span>
<span className="v" id="v22" data-v="22" data-xref="耶利米書 23:14; 耶利米書 14:13–17; 彼得後書 2:18–19"> 我沒有使義人傷心，你們卻以謊言叫他們灰心。你們慫恿惡人不要改邪歸正，以致他們喪命。</span>
<span className="v" id="v23" data-v="23" data-xref="以西結書 13:21; 以西結書 12:24; 彌迦書 3:6"> 因此，你們必不再見假異象，也不再占卜。我必從你們手中拯救我的子民。這樣，你們就知道我是耶和華。』」</span>

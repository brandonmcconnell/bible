## 耶和華立以西結為守望者

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華對我說：</span>
<span className="v" id="v2" data-v="2" data-xref="以西結書 33:30; 以西結書 33:17; 以西結書 3:11"> 「人子啊，你要告訴你的同胞，『如果我使戰爭降臨某地，那地方的百姓就應從他們中間選一人做守望者。</span>
<span className="v" id="v3" data-v="3" data-xref="何西阿書 8:1; 尼希米記 4:20; 尼希米記 4:18"> 守望者若發現敵人來攻打，便吹號警告百姓。</span>
<span className="v" id="v4" data-v="4" data-xref="以西結書 18:13; 使徒行傳 18:6; 耶利米書 6:17"> 凡聽見號聲而不接受警告的，敵人來把他殺了，這流血的罪就要由他自己承擔。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 9:19–21; 希伯來書 11:7; 約翰福音 8:39"> 因為他聽見號聲，卻不接受警告，他的死是咎由自取。他若接受警告，就保全了自己的性命。</span>
<span className="v" id="v6" data-v="6" data-xref="以西結書 3:18–20; 以西結書 33:8–9; 創世記 42:22"> 但如果守望者看見敵人來攻打卻不吹號警告百姓，以致有人被敵人殺了，那人固然是因自己的罪惡而被殺，我卻要向守望者追討那人被殺的血債。』</span>
<span className="v" id="v7" data-v="7" data-xref="以西結書 3:17–21; 耶利米書 26:2; 以西結書 2:7–8"> 「人子啊，我立你為以色列人的守望者，你要聽我口中的話並替我告誡他們。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行傳 20:26–27; 以西結書 33:6; 以西結書 33:14"> 如果我說惡人必定死，你卻不告誡他改邪歸正，他必因自己的罪而死，我卻要向你追討他的血債。</span>
<span className="v" id="v9" data-v="9" data-xref="以西結書 3:19; 使徒行傳 20:26; 箴言 15:10"> 如果你告誡惡人要改邪歸正，他卻不肯，他必因自己的罪而死，而你必保全性命。</span>
<span className="v" id="v10" data-v="10" data-xref="以賽亞書 49:14; 以西結書 37:11; 以西結書 24:23"> 「人子啊，你要對以色列人說，『你們說：我們背負過犯和罪惡，正因此而滅亡。我們怎能存活下去呢？</span>
<span className="v" id="v11" data-v="11" data-xref="提摩太前書 2:4; 以西結書 18:23; 彼得後書 3:9"> 你要告訴他們，主耶和華說：我憑我的永恆起誓，我絕不喜歡惡人死亡，我更願意惡人改邪歸正，得以存活。以色列人啊，回頭吧！改邪歸正吧！何必自取滅亡呢？』</span>
<span className="v" id="v12" data-v="12" data-xref="歷代志下 7:14; 以西結書 33:18–19; 羅馬書 3:25"> 人子啊，你要對你的同胞說，『當義人犯罪時，他以往的義救不了他；當惡人悔改時，他以往的惡不會使他滅沒。義人若犯罪，他以往的義不能使他存活。』</span>
<span className="v" id="v13" data-v="13" data-xref="以西結書 18:24; 希伯來書 10:38; 以西結書 18:4"> 我雖對義人說他必能存活，但如果他仗著自己的義而作惡，他從前的義行不會被記念，他必因自己的惡行而死亡。</span>
<span className="v" id="v14" data-v="14" data-xref="以西結書 18:27; 耶利米書 18:7–8; 何西阿書 14:1"> 我雖對惡人說他必定要死，但他若改邪歸正，秉公行義，</span>
<span className="v" id="v15" data-v="15" data-xref="以西結書 20:11; 路加福音 19:8; 出埃及記 22:1–4"> 償還抵押，歸還贓物，遵行生命之律例，不再犯罪，就必活著，不致死亡。</span>
<span className="v" id="v16" data-v="16" data-xref="以賽亞書 43:25; 以西結書 18:22; 彌迦書 7:18–19"> 他犯的罪不會被追究，他必因秉公行義而活著。</span>
<span className="v" id="v17" data-v="17" data-xref="馬太福音 25:24–26; 以西結書 18:25; 以西結書 18:29"> 「你的同胞卻說：主行事不公平。其實是他們自己行事不公。</span>
<span className="v" id="v18" data-v="18" data-xref="以西結書 33:12–13; 彼得後書 2:20–22; 希伯來書 10:38"> 義人若離義行惡，必因惡行而死。</span>
<span className="v" id="v19" data-v="19" data-xref="以西結書 18:27–28; 以西結書 33:14"> 惡人若改邪歸正、秉公行義，必因此而活。</span>
<span className="v" id="v20" data-v="20" data-xref="馬太福音 16:27; 以西結書 18:25; 以西結書 33:17"> 可是你們卻說，主行事不公平。以色列人啊，我必按你們各人的行為審判你們。」</span>
<span className="v" id="v21" data-v="21" data-xref="以西結書 1:2; 耶利米書 39:1–8; 列王紀下 25:4"> 在我們被擄後第十二年十月五日，有人從耶路撒冷逃出來對我說：「城已經淪陷了。」</span>
<span className="v" id="v22" data-v="22" data-xref="以西結書 1:3; 以西結書 3:26–27; 以西結書 24:26–27"> 逃難的人來的前一晚，耶和華的手一直按在我身上，開了我的口。那人早上來到我這裡時，耶和華已經開了我的口。於是我就開口說話，不再沉默。</span>
<span className="v" id="v23" data-v="23"> 耶和華對我說：</span>
<span className="v" id="v24" data-v="24" data-xref="以西結書 33:27; 以賽亞書 51:2; 使徒行傳 7:5"> 「人子啊，那些住在以色列廢墟中的人說，『亞伯拉罕一人尚且能擁有這片土地，我們這麼多人更能擁有這片土地為業。』</span>
<span className="v" id="v25" data-v="25" data-xref="申命記 12:16; 耶利米書 7:9–10; 創世記 9:4"> 因此，你要告訴他們，主耶和華這樣說，『你們吃帶血的肉，仰賴偶像，又殺人流血，怎能擁有這片土地呢？</span>
<span className="v" id="v26" data-v="26" data-xref="創世記 27:40; 彌迦書 2:1–2; 西番雅書 3:3"> 你們靠刀劍行可憎之事，個個玷污別人的妻子，你們怎能擁有這片土地呢？』</span>
<span className="v" id="v27" data-v="27" data-xref="撒母耳記上 13:6; 耶利米書 42:22; 以西結書 39:4"> 你要告訴他們，主耶和華這樣說，『我憑我的永恆起誓，那些住在廢墟中的必死於刀下，逃到田野的必被野獸吞吃，躲進堡壘和洞穴的必死於瘟疫。</span>
<span className="v" id="v28" data-v="28" data-xref="以西結書 7:24; 耶利米書 44:2; 耶利米書 44:6"> 我要使這片土地荒涼不堪，使她所誇耀的勢力消逝。以色列的山必荒涼，杳無人跡。</span>
<span className="v" id="v29" data-v="29" data-xref="以西結書 6:7; 以西結書 36:17–18; 以西結書 22:2–15"> 因為他們所行的一切可憎之事，我必使這地方荒涼不堪，那時他們就知道我是耶和華。』</span>
<span className="v" id="v30" data-v="30" data-xref="馬太福音 22:16–17; 耶利米書 23:35; 以賽亞書 29:13"> 「人子啊，你的同胞在牆邊和門口彼此議論你說，『來，聽聽從耶和華而來的信息。』</span>
<span className="v" id="v31" data-v="31" data-xref="馬太福音 13:22; 詩篇 78:36–37; 雅各書 1:22–24"> 他們蜂擁而來，坐在你面前聆聽你的話，儼然是我的子民。但他們不付諸實行，嘴裡說的是甜言蜜語，心中卻追求不義之財。</span>
<span className="v" id="v32" data-v="32" data-xref="馬可福音 6:20; 馬可福音 4:16–17; 約翰福音 5:35"> 他們只聽不做，你在他們眼中只不過是嗓音優美、善唱情歌、長於奏樂的人。</span>
<span className="v" id="v33" data-v="33" data-xref="耶利米書 28:9; 撒母耳記上 3:19–20; 以西結書 2:5"> 看吧，你所說的必定應驗。當一切應驗的時候，他們就知道有先知在他們當中。」</span>

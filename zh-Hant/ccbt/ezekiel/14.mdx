## 斥責拜偶像的以色列人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西結書 8:1; 以西結書 20:1; 列王紀下 6:32"> 那時，幾位以色列的長老到我這裡來，坐在我面前。</span>
<span className="v" id="v2" data-v="2" data-xref="阿摩司書 3:7; 列王紀上 14:4"> 耶和華對我說：</span>
<span className="v" id="v3" data-v="3" data-xref="以西結書 14:7; 以西結書 7:19; 以西結書 20:3"> 「人子啊，這些人在心裡立起偶像，把導致犯罪的絆腳石放在自己面前，我豈能讓他們來求問？</span>
<span className="v" id="v4" data-v="4" data-xref="以賽亞書 66:4; 以西結書 14:7; 以賽亞書 3:11"> 你告訴他們，主耶和華這樣說，『任何以色列人若在心裡立起偶像，把導致犯罪的絆腳石放在自己面前，又來求問先知，我耶和華必按他心中偶像的數目親自用懲罰回答他，</span>
<span className="v" id="v5" data-v="5" data-xref="以賽亞書 1:4; 撒迦利亞書 11:8; 羅馬書 1:28"> 好奪回以色列人的心，他們都因為拜偶像而遠離我。』</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="以西結書 18:30; 以賽亞書 30:22; 以西結書 36:31–32"> 「因此，你要告訴以色列人，主耶和華這樣說，『你們要悔改，離棄你們的偶像，離棄一切可憎之事。</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及記 12:48; 以賽亞書 58:1–2; 利未記 24:22"> 因為任何以色列人或是在以色列定居的外族人若背棄我，在心中樹立偶像，把導致犯罪的絆腳石放在自己面前，又來向先知求問我的旨意，我耶和華必親自用懲罰回答他。</span>
<span className="v" id="v8" data-v="8" data-xref="以西結書 15:7; 耶利米書 44:11; 以西結書 5:15"> 我必嚴懲他，使他成為眾人的鑒戒和笑柄。我必將他從我的子民中剷除。這樣，你們就知道我是耶和華。</span>
<span className="v" id="v9" data-v="9" data-xref="以西結書 20:25; 耶利米書 4:10; 詩篇 81:11–12"> 如果先知受迷惑說預言，那是我耶和華任他受迷惑，我必伸手懲治他，把他從我的以色列百姓中除滅。</span>
<span className="v" id="v10" data-v="10" data-xref="以西結書 23:49; 以西結書 14:4; 耶利米書 8:11–12"> 他們必擔當自己的罪過，假先知與求問的人要擔當同樣的罪過。</span>
<span className="v" id="v11" data-v="11" data-xref="以西結書 37:23; 以西結書 44:10; 啟示錄 21:7"> 這樣，以色列人便不再偏離我，不再犯罪玷污自己。他們要做我的子民，我要做他們的上帝。這是主耶和華說的。』」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12"> 耶和華對我說：</span>
<span className="v" id="v13" data-v="13" data-xref="利未記 26:26; 以西結書 4:16; 以賽亞書 24:20"> 「人子啊，若有國家犯罪背叛我，我必伸手斷絕他們的糧源，使饑荒遍地，毀滅人和牲畜。</span>
<span className="v" id="v14" data-v="14" data-xref="以西結書 14:20; 耶利米書 15:1; 以西結書 28:3"> 即使挪亞、但以理和約伯三人在那裡，他們也只能因義行而自己得救。這是主耶和華說的。</span>
<span className="v" id="v15" data-v="15" data-xref="以西結書 5:17; 利未記 26:22; 耶利米書 15:3"> 倘若我使猛獸在那裡橫行、肆虐，以致那裡荒涼、人蹤絕跡，</span>
<span className="v" id="v16" data-v="16" data-xref="創世記 19:29; 雅各書 5:16; 以西結書 33:11"> 縱然這三個義人在那裡，我憑我的永恆起誓，他們也不能救自己的兒女，只能自己得救，那裡卻要荒涼。這是主耶和華說的。</span>
<span className="v" id="v17" data-v="17" data-xref="利未記 26:25; 以西結書 21:3–4; 西番雅書 1:3"> 倘若我使刀劍臨到那裡，讓刀劍橫掃那裡，毀滅人和牲畜，</span>
<span className="v" id="v18" data-v="18"> 縱然這三個義人在那裡，我憑我的永恆起誓，他們也不能救自己的兒女，只能自己得救。這是主耶和華說的。</span>
<span className="v" id="v19" data-v="19" data-xref="以西結書 38:22; 以西結書 5:12; 耶利米書 14:12"> 倘若我叫瘟疫在那裡肆虐，在殺戮中傾倒我的烈怒，毀滅那裡的人和牲畜，</span>
<span className="v" id="v20" data-v="20" data-xref="以西結書 14:14; 約翰一書 2:29; 以賽亞書 3:10"> 縱然挪亞、但以理和約伯在那裡，我憑我的永恆起誓，他們也不能救自己的兒女，只能因義行而自己得救。這是主耶和華說的。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="以西結書 33:27; 以西結書 5:17; 以西結書 14:13"> 「主耶和華說，『我要把刀劍、饑荒、猛獸和瘟疫這四大刑罰降在耶路撒冷，毀滅人和牲畜。</span>
<span className="v" id="v22" data-v="22" data-xref="以西結書 12:16; 以西結書 20:43; 希伯來書 12:6–11"> 然而，其中仍有倖免的人帶著兒女逃出來。他們會逃到你們這裡，你們看見他們的所作所為，便會對我在耶路撒冷所降的一切災難感到欣慰。</span>
<span className="v" id="v23" data-v="23" data-xref="耶利米書 22:8–9; 啟示錄 15:4; 申命記 8:2"> 你們看見他們的所作所為，就知道我不是無緣無故地懲罰耶路撒冷。』這是主耶和華說的。」</span>
</div>
</div>

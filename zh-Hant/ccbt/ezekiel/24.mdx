## 鏽鍋的比喻

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="以西結書 8:1; 以西結書 20:1; 以西結書 29:17"> 第九年十月十日，耶和華對我說：</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米書 39:1; 耶利米書 52:4; 列王紀下 25:1"> 「人子啊，今天是巴比倫王圍攻耶路撒冷的日子，你要記下今天這日子。</span>
<span className="v" id="v3" data-v="3" data-xref="以西結書 11:3; 以西結書 17:2; 以西結書 20:49"> 你要向叛逆的以色列人說比喻，告訴他們，主耶和華這樣說，<br /><span className="pl pl-1">「『把鍋放在火上，</span><br /><span className="pl pl-1">裡面倒上水，</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="彌迦書 3:2–3; 以西結書 22:18–22; 馬太福音 7:2"> <span className="pl pl-1">把羊腿、羊肩等上好的肉塊放進鍋裡，</span><br /><span className="pl pl-1">讓鍋裡盛滿精選的骨頭。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="耶利米書 52:24–27; 耶利米書 52:10; 耶利米書 39:6"> <span className="pl pl-1">要從羊群中選一頭上好的羊，</span><br /><span className="pl pl-1">把柴堆在鍋下，</span><br /><span className="pl pl-1">燒開鍋煮裡面的骨頭。』」</span></span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="以西結書 22:2; 那鴻書 3:1; 俄巴底亞書 1:11"> 因此，主耶和華說：「這像鏽鍋一樣充滿血腥的城有禍了！要把肉從這鏽跡斑斑的鍋中一塊塊地取出來，無需挑選。</span>
<span className="v" id="v7" data-v="7" data-xref="利未記 17:13; 申命記 12:16; 約伯記 16:18"> 這城沾滿血腥，任憑受害者的血流在光禿禿的磐石上，而不是流在地上用土掩蓋。</span>
<span className="v" id="v8" data-v="8" data-xref="申命記 32:21–22; 啟示錄 18:5–10; 以西結書 22:30–31"> 我任憑這城把受害者的血灑在光禿禿的磐石上，不加掩蓋，好激起我的烈怒，使她受報應。</span>
<span className="v" id="v9" data-v="9" data-xref="以西結書 24:6; 哈巴谷書 2:12; 以賽亞書 31:9"> 所以主耶和華說，『血腥的城啊，你有禍了！我要預備大堆木柴。</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米哀歌 2:16; 耶利米書 17:3; 耶利米哀歌 1:10"> 要添柴點火，把肉煮爛，加入香料，燒焦骨頭。</span>
<span className="v" id="v11" data-v="11" data-xref="耶利米書 21:10; 瑪拉基書 4:1; 以賽亞書 1:25"> 然後，把倒空的鍋放在炭火上燒熱，把銅燒紅，好熔化它的雜質，除淨鏽垢，</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米書 9:5; 耶利米書 2:13; 耶利米書 5:3"> 卻徒勞無功，因為鏽垢太厚，就是用火也不能清除。</span>
<span className="v" id="v13" data-v="13" data-xref="以西結書 22:24; 以西結書 5:13; 西番雅書 3:2"> 耶路撒冷啊，淫蕩使你污穢不堪，我本想潔淨你，你卻不願被潔淨。所以，除非我向你傾盡一切憤怒，否則你的污穢必不得清除。</span>
<span className="v" id="v14" data-v="14" data-xref="馬太福音 16:27; 以西結書 18:30; 以賽亞書 3:11"> 我耶和華言出必行，決不退縮，也不寬容，也不留情，我必照你的所作所為來審判你。』這是主耶和華說的。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15"> 耶和華對我說：</span>
<span className="v" id="v16" data-v="16" data-xref="耶利米書 22:10; 耶利米書 13:17; 雅歌 7:10"> 「人子啊，我要擊打你，奪去你心愛的人，你不可悲傷，也不可流淚哭泣。</span>
<span className="v" id="v17" data-v="17" data-xref="何西阿書 9:4; 撒母耳記下 15:30; 利未記 10:6"> 你要默然哀歎，不可為死人辦喪事，仍要纏著頭巾，穿著鞋，不可蒙著臉，也不可吃喪家的飯。」</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前書 7:29–30"> 早晨我把這事告訴百姓，晚上我的妻子便死了。次日早晨，我便遵照耶和華的吩咐行。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="以西結書 12:9; 以西結書 37:18; 瑪拉基書 3:7–8"> 百姓問我：「你可以告訴我們，你這樣做跟我們有什麼關係嗎？」</span>
<span className="v" id="v20" data-v="20"> 我告訴他們：「耶和華對我說，</span>
<span className="v" id="v21" data-v="21" data-xref="以西結書 23:47; 以西結書 23:25; 詩篇 27:4"> 『你告訴以色列人，主耶和華說：我要使我的聖所，就是你們引以為傲、眼中所愛、心裡所慕的受到褻瀆。你們留下的兒女必死於刀下。</span>
<span className="v" id="v22" data-v="22" data-xref="詩篇 78:64; 耶利米書 16:4–7; 以西結書 24:16–17"> 那時，你們將像我的僕人一樣不蒙臉，不吃喪家的飯。</span>
<span className="v" id="v23" data-v="23" data-xref="以西結書 33:10; 以西結書 4:17; 利未記 26:39"> 你們仍將裹著頭巾，穿著鞋，不哭泣，也不悲傷。你們必因自己的罪惡而默然歎息，逐漸滅亡。</span>
<span className="v" id="v24" data-v="24" data-xref="以西結書 4:3; 以賽亞書 20:3; 路加福音 11:29–30"> 以西結做的事都是你們的預兆，你們也將做他做的。當這事發生時，你們就知道我是主耶和華。』</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="以西結書 24:21; 詩篇 48:2; 耶利米書 11:22"> 「人子啊，有一天我要奪去他們所喜悅、所誇耀、眼中所愛、心裡所慕的堡壘，也要奪去他們的兒女。</span>
<span className="v" id="v26" data-v="26" data-xref="約伯記 1:15–19; 以西結書 33:21–22; 撒母耳記上 4:12–18"> 那日，倖存的人必來告訴你這個消息。</span>
<span className="v" id="v27" data-v="27" data-xref="以西結書 33:22; 以西結書 29:21; 路加福音 21:15"> 那時，你必開口向那人說話，不再沉默。你必成為他們的預兆，他們就知道我是耶和華。」</span>
</div>
</div>

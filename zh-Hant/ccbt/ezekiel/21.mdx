## 耶和華審判的刀

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華對我說：</span>
<span className="v" id="v2" data-v="2" data-xref="以西結書 20:46; 以西結書 4:7; 以西結書 25:2"> 「人子啊，你要面向耶路撒冷，開口斥責聖所，說預言斥責以色列，</span>
<span className="v" id="v3" data-v="3" data-xref="約伯記 9:22; 耶利米書 21:13; 以西結書 5:8"> 告訴以色列，耶和華這樣說，『看啊，我要與你為敵，我要拔刀出鞘，將你那裡的義人和惡人一同消滅。</span>
<span className="v" id="v4" data-v="4" data-xref="以西結書 20:47; 以西結書 7:2; 以西結書 6:11–14"> 由於我要將你那裡的義人和惡人一同消滅，我的刀必出鞘從南到北殺向所有的人，</span>
<span className="v" id="v5" data-v="5" data-xref="以西結書 21:30; 那鴻書 1:9; 撒母耳記上 3:12"> 使世人都知道我耶和華已拔刀出鞘，不再收回。』</span>
<span className="v" id="v6" data-v="6" data-xref="以賽亞書 22:4; 以西結書 6:11; 耶利米書 19:10"> 人子啊，你要在他們面前哀歎，要傷心欲絕地哀歎。</span>
<span className="v" id="v7" data-v="7" data-xref="以西結書 7:17; 以西結書 7:26; 以賽亞書 13:7"> 如果他們問你為什麼哀歎，你就說因為有噩耗傳來，聽見的人都膽戰心驚、兩手發軟、精神萎靡、膝弱如水。災難來了，必很快發生。這是主耶和華說的。」</span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8"> 耶和華對我說：</span>
<span className="v" id="v9" data-v="9" data-xref="以賽亞書 34:5–6; 以西結書 21:28; 以西結書 21:3"> 「人子啊，你要說預言，告訴他們，主這樣說，<br /><span className="pl pl-1">「『有一把刀，</span><br /><span className="pl pl-1">有一把刀磨快擦亮了，</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 110:5–6; 以西結書 20:47; 以西結書 21:25–27"> <span className="pl pl-1">磨利以行殺戮，</span><br /><span className="pl pl-1">擦得亮如閃電。</span><br />我們豈能因我兒的權杖而快樂？這刀鄙視一切權杖。</span>
<span className="v" id="v11" data-v="11" data-xref="以西結書 21:19; 耶利米書 25:33; 耶利米書 51:20–23"> 這刀已交給人去擦亮，好握在手中，這刀已磨快擦亮，預備交給屠殺的人。</span>
<span className="v" id="v12" data-v="12" data-xref="以西結書 21:6; 約珥書 1:13; 以西結書 21:14"> 人子啊，號啕大哭吧，因為這刀要攻擊我的子民和所有以色列的首領，他們都要死於刀下。所以你要捶胸頓足。</span>
<span className="v" id="v13" data-v="13" data-xref="以西結書 21:10; 哥林多後書 8:2; 以西結書 21:25"> 這刀必試驗他們，這刀所鄙視的權杖若不復存在，又怎麼辦呢？這是主耶和華說的。』</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="列王紀下 24:1; 民數記 24:10; 利未記 26:24"> 「人子啊，你要拍掌對他們說預言，你要拿刀揮舞兩三次，預示這刀要從四面八方大肆殺戮，</span>
<span className="v" id="v15" data-v="15" data-xref="以西結書 21:10; 耶利米書 17:27; 以西結書 21:22"> 使他們嚇得肝膽俱裂，許多人倒在家門口。我已賜下這亮如閃電的刀，用來殺戮。</span>
<span className="v" id="v16" data-v="16" data-xref="以西結書 21:20; 以西結書 21:4; 以西結書 14:17"> 刀啊，你要左砍右劈，橫掃四方。</span>
<span className="v" id="v17" data-v="17" data-xref="以西結書 5:13; 以西結書 21:14; 撒迦利亞書 6:8"> 我也要拍掌，我的烈怒要平息。這是我耶和華說的。」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18"> 耶和華對我說：</span>
<span className="v" id="v19" data-v="19" data-xref="以西結書 4:1–3; 耶利米書 1:10; 以西結書 5:1–17"> 「人子啊，你要為巴比倫王的刀畫出兩條進攻之路，兩條路要從一個地方出發，要在通往城邑的路口設路標。</span>
<span className="v" id="v20" data-v="20" data-xref="阿摩司書 1:14; 耶利米書 49:2; 以西結書 25:5"> 為刀畫一條路進攻亞捫的拉巴城，再畫一條路進攻猶大的堅城耶路撒冷。</span>
<span className="v" id="v21" data-v="21" data-xref="士師記 18:20; 箴言 16:33; 士師記 17:5"> 巴比倫王會站在兩條路的岔口占卜，搖籤求問他的神像，察看祭牲的肝。</span>
<span className="v" id="v22" data-v="22" data-xref="以西結書 4:2; 以西結書 26:9; 耶利米書 51:14"> 他右手拿到的是攻打耶路撒冷的籤，於是他架起撞城錘，號令殺戮，高聲吶喊，用撞城錘攻打城門，建壘築臺圍攻城池。</span>
<span className="v" id="v23" data-v="23" data-xref="民數記 5:15; 以西結書 21:24; 以西結書 29:16"> 猶大人必認為這是虛假的占卜。他們曾向巴比倫王宣誓效忠，但巴比倫王要使他們想起自己的罪，並擄走他們。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="何西阿書 4:2; 彌迦書 3:10–12; 耶利米書 3:2"> 「所以，主耶和華說，『因為你們的過犯昭然若揭，使人想起你們的罪惡，你們的所作所為都顯出你們的罪過。因此，你們必遭擄掠。</span>
<span className="v" id="v25" data-v="25" data-xref="以西結書 35:5; 以西結書 21:29; 以西結書 17:19"> 你這邪惡敗壞的以色列首領啊！你的結局到了，最終審判的日子來了。』</span>
<span className="v" id="v26" data-v="26" data-xref="以西結書 17:24; 詩篇 75:7; 耶利米書 13:18"> 主耶和華說，『取下你的禮帽，摘下你的冠冕吧，時局轉變了。要提拔卑微的，貶抑高貴的。</span>
<span className="v" id="v27" data-v="27" data-xref="彌迦書 5:2; 耶利米書 23:5–6; 撒迦利亞書 9:9"> 毀滅，毀滅，我要毀滅這國，使它蕩然無存，直到那應得的人來到，我要把這國交給他。』</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="以西結書 21:20; 以西結書 21:9–10; 西番雅書 2:8–10"> 「人子啊，你要說有關亞捫人及其恥辱的預言，告訴他們，主耶和華說，『有刀，有刀已出鞘，為要殺戮；它亮如閃電，要行毀滅。</span>
<span className="v" id="v29" data-v="29" data-xref="以西結書 21:25; 以西結書 22:28; 詩篇 37:13"> 他們為你們看的異象是虛假的，所做的占卜謊話連篇，你們將與褻瀆的惡人一同被殺，因為他們的結局到了，最終審判的日子來了。</span>
<span className="v" id="v30" data-v="30" data-xref="以西結書 16:38; 創世記 15:14; 耶利米書 47:6–7"> 你們要收刀入鞘，我要在你們的受造之處，在你們的出生之地審判你們，</span>
<span className="v" id="v31" data-v="31" data-xref="那鴻書 1:6; 耶利米書 6:22–23; 以西結書 14:19"> 我要把烈怒倒在你們身上，將我的怒火噴在你們身上，把你們交在嗜殺成性的惡徒手中，</span>
<span className="v" id="v32" data-v="32" data-xref="以西結書 25:10; 瑪拉基書 4:1; 以西結書 20:47–48"> 你們必被當作柴焚燒，你們的血必流在自己的土地上，無人再記得你們。因為這是我耶和華說的。』」</span>
</div>
</div>

## 審判以色列的首領

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西結書 3:14; 以西結書 11:24; 以西結書 11:13"> 那時，耶和華的靈將我舉起，帶我到耶和華殿的東門，我見門口那裡有二十五個人，當中有百姓的首領押朔的兒子雅撒尼亞和比拿雅的兒子毗拉提。</span>
<span className="v" id="v2" data-v="2" data-xref="以賽亞書 30:1; 耶利米書 5:5; 詩篇 2:1–2"> 耶和華對我說：「人子啊，這些人在這城裡專給人出毒計，設惡謀。</span>
<span className="v" id="v3" data-v="3" data-xref="以西結書 12:27; 以西結書 12:22; 以西結書 11:7–11"> 他們說，『建造房屋的時候還沒有到。我們的城像鐵鍋一樣堅固，我們像在鍋裡的肉一樣得到保護。』</span>
<span className="v" id="v4" data-v="4" data-xref="以西結書 20:46–47; 以西結書 21:2; 以西結書 3:2–15"> 人子啊，你要說預言，說預言斥責他們。」</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米書 17:10; 耶利米書 16:17; 啟示錄 2:23"> 耶和華的靈降在我身上，並吩咐我說：「耶和華這樣說，『以色列人啊，我知道你們口中在說什麼，心裡在想什麼。</span>
<span className="v" id="v6" data-v="6" data-xref="以西結書 7:23; 以西結書 22:27; 以西結書 22:12"> 你們在城中大肆屠殺，大街小巷遍地屍體。</span>
<span className="v" id="v7" data-v="7" data-xref="以西結書 24:3–13; 彌迦書 3:2–3; 列王紀下 25:18–22"> 所以，主耶和華說，你們在城中殺死的人就是肉，這城就是鍋，但我必把你們從鍋中拉出來。</span>
<span className="v" id="v8" data-v="8" data-xref="箴言 10:24; 以賽亞書 24:17–18; 約伯記 3:25"> 你們懼怕刀劍，我必使刀劍臨到你們。這是主耶和華說的。</span>
<span className="v" id="v9" data-v="9" data-xref="以西結書 5:8; 詩篇 106:41; 申命記 28:36"> 我必把你們從城中趕出去，交給外族人。我必審判你們，</span>
<span className="v" id="v10" data-v="10" data-xref="列王紀下 14:25; 耶利米書 52:9–10; 列王紀下 25:19–21"> 使你們死於刀下。我要審判整個以色列，這樣你們就知道我是耶和華。</span>
<span className="v" id="v11" data-v="11" data-xref="以西結書 11:3; 以西結書 11:7–10"> 這城必不是你們的鍋，你們也必不是其中的肉，我必在以色列全境施行審判。</span>
<span className="v" id="v12" data-v="12" data-xref="以西結書 8:10; 以西結書 8:16; 以西結書 8:14"> 這樣你們就知道我是耶和華。因為你們沒有遵行我的律例，沒有順從我的典章，卻效法你們四鄰外族的規矩。』」</span>
<span className="v" id="v13" data-v="13" data-xref="以西結書 11:1; 以西結書 9:8; 使徒行傳 5:5"> 我正在說預言的時候，比拿雅的兒子毗拉提就死了。我便俯伏在地大喊：「唉，主耶和華啊，你要滅絕以色列的餘民嗎？」</span>
<span className="v" id="v14" data-v="14"> 耶和華對我說：</span>
<span className="v" id="v15" data-v="15" data-xref="以西結書 33:24; 以賽亞書 65:5; 約翰福音 16:2"> 「人子啊，留在耶路撒冷的居民會這樣談論你、你的親人和一切被擄的以色列人，說，『他們遠離了耶和華，這地方已經給了我們。』</span>
<span className="v" id="v16" data-v="16" data-xref="以賽亞書 8:14; 申命記 30:3–4; 詩篇 90:1"> 因此，你要說，『主耶和華這樣說，我雖然把以色列人趕到遠方各國，分散在列邦，卻要在他們所去的國家暫作他們的聖所。』</span>
<span className="v" id="v17" data-v="17" data-xref="以西結書 28:25; 耶利米書 3:18; 以西結書 34:13"> 「你要說，『主耶和華這樣說，我必從各國召集你們，從你們被驅散到的列邦中聚集你們，將以色列的土地再賜給你們。』</span>
<span className="v" id="v18" data-v="18" data-xref="以西結書 37:23; 以西結書 5:11; 以西結書 42:7–8"> 他們回來後，必除掉此地一切醜惡可憎的事。</span>
<span className="v" id="v19" data-v="19" data-xref="以西結書 36:26–27; 耶利米書 31:33; 詩篇 51:10"> 我必賜給他們一顆專一的心，將新靈放在他們裡面，除去他們的石心，賜給他們肉心，</span>
<span className="v" id="v20" data-v="20" data-xref="以西結書 14:11; 詩篇 105:45; 耶利米書 30:22"> 使他們恪守我的律例，謹遵我的典章。他們要做我的子民，我要做他們的上帝。</span>
<span className="v" id="v21" data-v="21" data-xref="以西結書 9:10; 傳道書 11:9; 耶利米書 1:16"> 至於那些心裡戀慕醜惡可憎之物的人，我必按他們所行的報應他們。這是主耶和華說的。」</span>
<span className="v" id="v22" data-v="22" data-xref="以西結書 10:19; 以西結書 1:19–20"> 於是，基路伯天使展開翅膀，輪子跟在他們旁邊，在他們上面有以色列上帝的榮耀。</span>
<span className="v" id="v23" data-v="23" data-xref="撒迦利亞書 14:4; 以西結書 8:4; 以西結書 10:4"> 耶和華的榮耀從城中升起，停在城東的山上。</span>
<span className="v" id="v24" data-v="24" data-xref="以西結書 3:12; 以西結書 8:3; 以西結書 11:1"> 上帝的靈將我舉起，在祂所賜的異象中把我帶到迦勒底被擄的人那裡，我所見的異象從我面前上升消失了。</span>
<span className="v" id="v25" data-v="25" data-xref="以西結書 3:4; 以西結書 3:27; 以西結書 3:17"> 我把耶和華讓我看到的一切都告訴了那些被擄的人。</span>

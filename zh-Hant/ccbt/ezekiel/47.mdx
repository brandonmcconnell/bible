## 從聖殿流出的水

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="啟示錄 22:1; 撒迦利亞書 14:8; 約珥書 3:18"> 他又領我回到聖殿門口，我看見有水從聖殿的門檻下往東流去。殿的正面朝東，這水從殿的南側經祭壇的南邊往下流。</span>
<span className="v" id="v2" data-v="2" data-xref="以西結書 44:4; 以西結書 44:2"> 隨後他領我由北門出來，從外面繞到外院的東門，我見水從東門的南面涓涓流出。</span>
<span className="v" id="v3" data-v="3" data-xref="以西結書 40:3; 使徒行傳 10:45–46; 使徒行傳 11:16–18"> 那人手拿量繩向東量了五百米，然後領我涉水前行，水深及踝。</span>
<span className="v" id="v4" data-v="4" data-xref="歌羅西書 1:6; 羅馬書 15:19; 使徒行傳 19:10–20"> 他又量了五百米，領我涉水前行，水深及膝。他又量了五百米，領我涉水前行，水深及腰。</span>
<span className="v" id="v5" data-v="5" data-xref="以賽亞書 11:9; 哈巴谷書 2:14; 馬太福音 13:31–32"> 他又量了五百米，水已高漲成河，足可游泳，無法再涉水穿過。</span>
<span className="v" id="v6" data-v="6" data-xref="以西結書 44:5; 以西結書 40:4; 撒迦利亞書 4:2"> 他問我：「人子啊，你看見了嗎？」 然後，他帶我回到河邊，</span>
<span className="v" id="v7" data-v="7" data-xref="以西結書 47:12; 啟示錄 22:2; 列王紀下 2:13"> 我發現河的兩岸長滿了樹木。</span>
<span className="v" id="v8" data-v="8" data-xref="約書亞記 3:16; 申命記 3:17; 列王紀下 2:19–22"> 他對我說：「這水向東流，經過亞拉巴流到鹽海，使那裡的鹹水變為淡水。</span>
<span className="v" id="v9" data-v="9" data-xref="約翰福音 7:37–38; 約翰福音 6:63; 約翰福音 4:14"> 河水流經的地方，萬物滋長，魚產豐盛，因為河水使那裡的鹹水變成淡水了，所以河水流經之處萬物滋長。</span>
<span className="v" id="v10" data-v="10" data-xref="馬太福音 4:19; 詩篇 104:25; 民數記 34:6"> 漁夫要站在岸邊捕魚，從隱·基底到隱·以革蓮都是曬網的地方。那裡的魚就像大海的魚一樣種類繁多。</span>
<span className="v" id="v11" data-v="11" data-xref="申命記 29:23; 啟示錄 22:11; 耶利米書 17:6"> 但沼澤和濕窪之地卻不會變淡，留作產鹽之地。</span>
<span className="v" id="v12" data-v="12" data-xref="啟示錄 22:2; 詩篇 1:3; 耶利米書 17:8"> 沿河兩岸長著各種果樹，樹的葉子不會枯乾，果實也不會斷絕。樹必月月結出新果，不但果實可吃，葉子還可作藥用，因為這水是從聖所流出來的。」</span>
</div>
</div>

## 地界

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="以西結書 48:4–6; 耶利米書 3:18; 民數記 34:2–12"> 主耶和華說：「你們要按照我劃定的地界，把土地分給以色列的十二支派作產業，約瑟支派<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「約瑟支派」就是以法蓮和瑪拿西兩支派。">a</a></sup>要得兩份地業。</span>
<span className="v" id="v14" data-v="14" data-xref="以西結書 20:5–6; 創世記 12:7; 以西結書 48:29"> 其他各支派都要均分，因為我曾起誓將這地方賜給你們祖先。這地方必成為你們的產業。</span>
<span className="v" id="v15" data-v="15" data-xref="民數記 34:8; 以西結書 48:1"> 「以下是這地方的地界：北界從地中海岸經希特倫到哈馬口、西達達、</span>
<span className="v" id="v16" data-v="16" data-xref="以西結書 48:1; 民數記 13:21; 撒母耳記下 8:8"> 比羅他和大馬士革與哈馬邊界中間的西伯蓮，一直到浩蘭邊界的哈撒·哈提幹。</span>
<span className="v" id="v17" data-v="17" data-xref="以西結書 48:1; 民數記 34:9"> 這樣，疆界是從地中海岸一直到大馬士革邊界的哈薩·以難，北面以哈馬為界。 這是北界。</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 13:10; 創世記 31:23; 創世記 31:47"> 「東界是從北界南下經浩蘭和大馬士革之間，沿著基列和以色列中間的約旦河為界，一直伸展到東部的海。這是東界。</span>
<span className="v" id="v19" data-v="19" data-xref="以西結書 48:28; 申命記 32:51; 民數記 34:5"> 「南界從他瑪延伸到米利巴·加低斯泉，沿埃及小河直到地中海。 這是南界。</span>
<span className="v" id="v20" data-v="20" data-xref="民數記 34:6; 以西結書 48:1"> 「西界從南界沿地中海的海岸到北界哈馬口對面的地方。 這是西界。</span>
<span className="v" id="v21" data-v="21"> 「你們要按照以色列的各支派分這塊地，</span>
<span className="v" id="v22" data-v="22" data-xref="歌羅西書 3:11; 以弗所書 3:6; 使徒行傳 11:18"> 用抽籤的方法來分產業，也要分給在你們中間居住、生兒育女的外族人。你們要視他們如同以色列人，要讓他們在以色列各支派中與你們同分產業。</span>
<span className="v" id="v23" data-v="23"> 他們居住在哪一支派，就要在哪一支派中分產業給他們。這是主耶和華說的。」</span>
</div>

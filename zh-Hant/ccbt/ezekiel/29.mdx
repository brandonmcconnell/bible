## 預言審判埃及

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="以西結書 29:17; 以西結書 26:1; 以西結書 20:1"> 第十年十月十二日，耶和華對我說：</span>
<span className="v" id="v2" data-v="2" data-xref="以西結書 6:2; 耶利米書 44:30; 耶利米書 46:2–16"> 「人子啊，你要面向埃及王法老，說預言斥責他和整個埃及，</span>
<span className="v" id="v3" data-v="3" data-xref="以西結書 32:2; 以賽亞書 27:1; 耶利米書 44:30"> 你要告訴他，主耶和華這樣說，<br /><span className="pl pl-1">「『埃及王法老啊，</span><br /><span className="pl pl-1">你這躺臥在自己河中的大怪物，</span><br /><span className="pl pl-1">我要與你為敵。</span><br /><span className="pl pl-1">你說這尼羅河屬於你，</span><br /><span className="pl pl-1">是你為自己造的。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="列王紀下 19:28; 以西結書 38:4; 阿摩司書 4:2"> <span className="pl pl-1">但我要鉤住你的腮，</span><br /><span className="pl pl-1">使河中的魚貼在你的鱗甲上，</span><br /><span className="pl pl-1">把你連同貼在你鱗甲上的魚一起從河中拉上來，</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="耶利米書 34:20; 以西結書 32:4–6; 耶利米書 8:2"> <span className="pl pl-1">把你和你河中的魚都丟棄在曠野。</span><br /><span className="pl pl-1">你必曝屍野外，無人收殮。</span><br /><span className="pl pl-1">我要讓你成為走獸飛禽的食物。</span></span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="列王紀下 18:21; 以賽亞書 36:6; 出埃及記 9:14"> 「『這樣，所有的埃及人就知道我是耶和華，因為你不過是一根以色列人無法依靠的蘆葦杖。</span>
<span className="v" id="v7" data-v="7" data-xref="以賽亞書 36:6; 以西結書 17:15–17; 耶利米書 17:5–6"> 當他們用手握住你的時候，你就斷裂，刺傷了他們的肩；當他們倚靠你的時候，你就折斷，閃了他們的腰。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="以西結書 14:17; 以西結書 30:10; 以西結書 29:19–20"> 「『因此，主耶和華說，看啊，我要使刀劍臨到你，消滅你的人畜，</span>
<span className="v" id="v9" data-v="9" data-xref="以西結書 29:3; 箴言 16:18; 以西結書 29:10–12"> 使埃及一片荒涼。這樣，他們就知道我是耶和華。因為你說這尼羅河屬於你，是你造的。</span>
<span className="v" id="v10" data-v="10" data-xref="以西結書 30:12; 以西結書 30:6–9; 出埃及記 14:2"> 因此，我要攻擊你和你的河流，使埃及從密奪到色弗尼，一直到古實的邊界全都荒廢。</span>
<span className="v" id="v11" data-v="11" data-xref="以西結書 32:13; 耶利米書 43:11–12; 以西結書 30:10–13"> 四十年之內，這裡必無人居住，人畜蹤跡滅絕。</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米書 46:19; 以西結書 30:7; 以西結書 30:23"> 我必使埃及成為荒地中的荒地，讓埃及的城邑淪為廢墟中的廢墟四十年。我要將埃及人驅趕到列國，分散到列邦。』</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="耶利米書 46:26; 以賽亞書 19:22"> 「主耶和華說，『四十年之後，我要把分散的埃及人從各國聚集起來。</span>
<span className="v" id="v14" data-v="14" data-xref="以西結書 30:14; 以賽亞書 11:11; 耶利米書 44:1"> 我要讓被擄的埃及人返鄉，使他們回到本土巴特羅，成為一個卑微的國家，</span>
<span className="v" id="v15" data-v="15" data-xref="撒迦利亞書 10:11; 以西結書 30:13; 以西結書 17:14"> 在列國中最衰微，再也不能雄居列國之上。我要使埃及國勢衰弱，再也不能統治列國。</span>
<span className="v" id="v16" data-v="16" data-xref="何西阿書 8:13; 以賽亞書 20:5; 以西結書 29:6–7"> 埃及必不再是以色列人的指望，反而會使以色列人想起自己投靠埃及的罪。這樣，他們便知道我是主耶和華。』」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="以西結書 29:1; 以西結書 1:2; 以西結書 24:1"> 第二十七年一月一日，耶和華對我說：</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米書 27:6; 耶利米書 25:9; 以西結書 26:7–12"> 「人子啊，巴比倫王尼布甲尼撒派兵苦攻泰爾，以致士兵的頭都禿了，肩也破了，卻是徒勞無功。</span>
<span className="v" id="v19" data-v="19" data-xref="以西結書 30:24–25; 耶利米書 43:10–13; 以西結書 32:11"> 所以主耶和華說，『我要把埃及賜給巴比倫王尼布甲尼撒，他必把埃及的財富洗劫一空，用來犒賞自己的軍隊。</span>
<span className="v" id="v20" data-v="20" data-xref="耶利米書 25:9; 以賽亞書 10:6–7; 以賽亞書 45:1–3"> 他和他的軍隊為我效力，所以我把埃及賜給他作為酬勞。』這是主耶和華說的。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="撒母耳記上 2:10; 路加福音 21:15; 詩篇 132:17"> 「到那天，我必復興以色列<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「我必復興以色列」希伯來文是「我必使一隻角從以色列興起」。">a</a></sup>，使你以西結在他們當中開口說話，這樣他們就知道我是耶和華。」</span>
</div>

## 劃分聖地

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西結書 48:29; 撒迦利亞書 14:20–21; 民數記 34:13"> 「『當你們抽籤把土地分給以色列各支派作產業的時候，要分出一塊獻給耶和華作聖地。聖地要長十二公里半，寬十公里，整塊地都要聖潔。</span>
<span className="v" id="v2" data-v="2" data-xref="以西結書 42:16–20; 以西結書 27:28"> 你們要在其中分出一塊長寬各二百五十米的地建聖所。聖所的周圍要有二十五米寬的空地。</span>
<span className="v" id="v3" data-v="3" data-xref="以西結書 48:10"> 聖地當中要量一塊長十二公里半、寬五公里的地，其中要有聖所，是至聖的地方。</span>
<span className="v" id="v4" data-v="4" data-xref="以西結書 43:19; 民數記 16:5; 以西結書 40:45"> 這塊聖地應歸那些在聖所供職並事奉耶和華的祭司，作為他們的居所和建聖所之用。</span>
<span className="v" id="v5" data-v="5" data-xref="以西結書 48:13; 尼希米記 10:38–39; 以西結書 48:20"> 另一塊十二公里半長、五公里寬的土地給那些在聖殿工作的利未人建城居住，作他們的產業<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「作他們的產業」或譯作「有二十間房作他們的產業」。">a</a></sup>。</span>
<span className="v" id="v6" data-v="6" data-xref="以西結書 48:15–18; 以西結書 48:30–35"> 「『在聖地旁邊要分出一塊十二公里半長、兩公里半寬的地建城，歸給所有以色列人。</span>
<span className="v" id="v7" data-v="7" data-xref="以西結書 48:21; 以西結書 34:24; 以西結書 46:16–18"> 「『在聖地和城的東西兩邊是給君王的土地，西邊延伸至西邊的邊境，東邊延伸至東邊的邊境，從西到東長度與各支派分得的土地一樣。</span>
<span className="v" id="v8" data-v="8" data-xref="以賽亞書 11:3–5; 以西結書 46:18; 以西結書 22:27"> 這地方要作君王在以色列的產業。我的君王必不再欺壓我的子民，而是按支派把地分給他們。</span>
<span className="v" id="v9" data-v="9" data-xref="撒迦利亞書 8:16; 耶利米書 22:3; 以西結書 44:6"> 「『主耶和華說，你們這些以色列的君王啊，夠了！你們應當放棄暴行和搶掠，按公平和正義行事，不要再向我的子民橫徵暴斂了！這是主耶和華說的。</span>
<span className="v" id="v10" data-v="10" data-xref="彌迦書 6:10–11; 阿摩司書 8:4–6; 箴言 16:11"> 你們要用公道的天平、伊法和罷特。</span>
<span className="v" id="v11" data-v="11" data-xref="以賽亞書 5:10"> 伊法和罷特容量要相同，量固體的伊法是十分之一賀梅珥<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="一賀梅珥相當於一百五十公斤或二百升。">b</a></sup>，量液體的罷特也是十分之一賀梅珥，賀梅珥是標準的容量單位。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及記 30:13; 民數記 3:47; 利未記 27:25"> 舍客勒<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="一舍客勒約合十一克。">c</a></sup>是標準的重量單位，一舍客勒是二十季拉。六十舍客勒等於一彌那。</span>
<span className="v" id="v13" data-v="13"> 「『以下是你們應當獻的供物，每一賀梅珥小麥要獻上六分之一伊法，每一賀梅珥大麥也要獻上六分之一伊法。</span>
<span className="v" id="v14" data-v="14"> 獻橄欖油要按規定以罷特計量，每一柯珥的油要獻十分之一罷特，一柯珥等於十罷特或一賀梅珥，因為一賀梅珥等於十罷特。</span>
<span className="v" id="v15" data-v="15" data-xref="利未記 1:4; 利未記 6:30; 歌羅西書 1:21"> 在以色列肥美的草場上，每二百隻羊便要獻上一隻。這些供物用來作素祭、燔祭和平安祭，為以色列人贖罪。這是主耶和華說的。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 30:14–15; 以賽亞書 16:1"> 所有的以色列人都要這樣拿供物來獻給君王。</span>
<span className="v" id="v17" data-v="17" data-xref="以西結書 46:4–12; 歷代志下 31:3; 以賽亞書 66:23"> 君王要在節期、朔日<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="「朔日」即每月初一。">d</a></sup>、安息日等以色列人一切的節期獻上燔祭、素祭和奠祭。他要預備贖罪祭、素祭、燔祭和平安祭的祭物，為以色列人贖罪。</span>
<span className="v" id="v18" data-v="18" data-xref="利未記 16:16; 出埃及記 12:2; 以西結書 43:22"> 「『主耶和華說，一月初一，你要獻一隻毫無殘疾的公牛犢，潔淨聖所。</span>
<span className="v" id="v19" data-v="19" data-xref="以西結書 43:20; 以西結書 43:14; 利未記 16:18–20"> 祭司要取些贖罪祭牲的血抹在聖殿的門柱、祭台的四角和內院門口的柱子上。</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 19:12; 利未記 4:27–35; 以西結書 45:15"> 到了一月七日，要同樣為一切在無意和無知中犯罪的人贖罪，使聖殿潔淨。</span>
<span className="v" id="v21" data-v="21" data-xref="利未記 23:5–8; 哥林多前書 5:7–8; 民數記 9:2–14"> 「『一月十四日開始，你們要守逾越節七天，節期間要吃無酵餅。</span>
<span className="v" id="v22" data-v="22" data-xref="利未記 4:14; 哥林多後書 5:21; 馬太福音 20:28"> 在逾越節當天，君王要預備一頭公牛為自己和全體百姓作贖罪祭。</span>
<span className="v" id="v23" data-v="23" data-xref="約伯記 42:8; 利未記 23:8; 民數記 23:1–2"> 在七天的節期間，他要每天預備毫無殘疾的公牛七頭、公綿羊七隻作燔祭獻給耶和華，公山羊一隻作贖罪祭。</span>
<span className="v" id="v24" data-v="24" data-xref="以西結書 46:5–7; 民數記 28:12–15"> 他要預備細麵粉和油作素祭與牛羊一同獻上。每頭公牛或公綿羊要同獻十公斤細麵粉和四升油。</span>
<span className="v" id="v25" data-v="25" data-xref="利未記 23:33–43; 民數記 29:12–38; 歷代志下 5:3"> 在七月十五日開始一連七天的住棚節期間，君王也要供應同樣的贖罪祭、燔祭、素祭和油。』</span>
</div>

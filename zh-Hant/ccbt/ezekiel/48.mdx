## 分地

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西結書 47:15–17; 約書亞記 19:40–47; 啟示錄 7:4–8"> 「以下是各支派分得的土地： 「但的地業在北部：從希特倫經哈馬口到大馬士革邊界的哈薩·以難，北面靠近哈馬，橫跨東西兩地。</span>
<span className="v" id="v2" data-v="2" data-xref="約書亞記 19:24–31; 創世記 30:12–13"> 亞設的地業從東到西與但的地業接壤。</span>
<span className="v" id="v3" data-v="3" data-xref="約書亞記 19:32–39; 創世記 30:7–8"> 拿弗他利的地業從東到西與亞設的地業接壤。</span>
<span className="v" id="v4" data-v="4" data-xref="約書亞記 17:1–11; 約書亞記 13:29–31; 創世記 48:14–20"> 瑪拿西的地業從東到西與拿弗他利的地業接壤。</span>
<span className="v" id="v5" data-v="5" data-xref="約書亞記 17:8–10; 約書亞記 17:14–18; 約書亞記 16:1–10"> 以法蓮的地業從東到西與瑪拿西的地業接壤。</span>
<span className="v" id="v6" data-v="6" data-xref="約書亞記 13:15–21; 創世記 29:32; 創世記 49:3–4"> 呂便的地業從東到西與以法蓮的地業接壤。</span>
<span className="v" id="v7" data-v="7" data-xref="約書亞記 15:1–63; 約書亞記 19:9; 創世記 29:35"> 猶大的地業從東到西與呂便的地業接壤。</span>
<span className="v" id="v8" data-v="8" data-xref="以西結書 45:1–6; 以賽亞書 12:6; 以賽亞書 33:20–22"> 「猶大邊界以南將是你們劃分出來的那塊地，寬十二公里半，由東至西的長度與其他各支派的地相同，聖殿在那塊地的中央。</span>
<span className="v" id="v9" data-v="9"> 你們獻給耶和華的聖地長十二公里半、寬五公里，</span>
<span className="v" id="v10" data-v="10" data-xref="以西結書 45:4; 以西結書 44:28; 馬太福音 10:10"> 南北面各長十二公里半，東西面各寬五公里。耶和華的聖所在這塊地的中央。</span>
<span className="v" id="v11" data-v="11" data-xref="以西結書 40:46; 以西結書 44:10; 馬太福音 24:45–46"> 這塊地要歸給忠心事奉我的聖潔祭司撒督的子孫。當以色列人步入歧途時，他們沒有與利未人同流合污。</span>
<span className="v" id="v12" data-v="12" data-xref="利未記 27:21; 以西結書 45:4"> 這塊從聖地中劃出的至聖之地要歸給他們，它與利未人所得的地業相鄰。</span>
<span className="v" id="v13" data-v="13" data-xref="以西結書 45:3; 申命記 12:19; 以西結書 45:5"> 利未人的地與祭司的地並排挨著，長十二公里半，寬五公里。</span>
<span className="v" id="v14" data-v="14" data-xref="利未記 27:28; 利未記 27:9–10; 出埃及記 22:29"> 他們不可把這塊地出賣或交換，不可把這塊最好的地轉讓給他人，因為它是歸給耶和華的聖地。</span>
<span className="v" id="v15" data-v="15" data-xref="以西結書 42:20; 以西結書 45:6; 以西結書 44:23"> 「剩下的十二公里半長、兩公里半寬的地方作公共用地，用來建城邑、房屋和草場，城要建在這地方的中央。</span>
<span className="v" id="v16" data-v="16" data-xref="啟示錄 21:16"> 城是正方形的，東、西、南、北各長兩公里半。</span>
<span className="v" id="v17" data-v="17"> 城四周要有郊野，東西南北各長一百二十五米，</span>
<span className="v" id="v18" data-v="18" data-xref="約書亞記 9:27; 以斯拉記 2:43–58; 以西結書 45:6"> 與聖地相鄰，城外東西兩側剩下的地各長五公里，地裡的出產要作城內工人的食物。</span>
<span className="v" id="v19" data-v="19" data-xref="以西結書 45:6; 列王紀上 4:7–23; 尼希米記 11:1–36"> 所有在這城裡做工的以色列各支派的人都要耕種這片土地。</span>
<span className="v" id="v20" data-v="20" data-xref="啟示錄 21:16; 希伯來書 12:17"> 你們所獻的這塊聖地和城區是方形的，四面各長十二公里半。</span>
<span className="v" id="v21" data-v="21" data-xref="以西結書 48:22; 以西結書 37:24; 以西結書 48:8"> 「聖地和城區東西兩邊的餘地要歸君王。兩邊的餘地從聖地十二公里半寬的東西邊界開始，沿各支派所分的地，分別向東向西延伸到以色列的東界和西界。聖地和聖殿在地的中央。</span>
<span className="v" id="v22" data-v="22"> 利未人的產業和城區在君王土地的中央，君王的土地在猶大和便雅憫支派之間。</span>
<span className="v" id="v23" data-v="23" data-xref="約書亞記 18:21–28; 以西結書 48:1–7; 創世記 35:16–19"> 「以下是其他各支派所分的地業： 「便雅憫的一份地業從東跨到西。</span>
<span className="v" id="v24" data-v="24" data-xref="約書亞記 19:1–9; 創世記 29:33; 創世記 49:5–7"> 西緬的一份地業從東到西與便雅憫的地業接壤。</span>
<span className="v" id="v25" data-v="25" data-xref="約書亞記 19:17–23; 創世記 30:14–18"> 以薩迦的一份地業從東到西與西緬的地業接壤。</span>
<span className="v" id="v26" data-v="26" data-xref="約書亞記 19:10–16; 創世記 30:19–20"> 西布倫的一份地業從東到西與以薩迦的地業接壤。</span>
<span className="v" id="v27" data-v="27" data-xref="約書亞記 13:24–28; 創世記 30:10–11"> 迦得的一份地業從東到西與西布倫的地業接壤。</span>
<span className="v" id="v28" data-v="28" data-xref="以西結書 47:15; 歷代志下 20:2; 以西結書 47:19–20"> 迦得的南界是從他瑪延伸到米利巴·加低斯泉，沿埃及小河，一直到地中海。</span>
<span className="v" id="v29" data-v="29" data-xref="約書亞記 13:1–21; 民數記 34:2; 民數記 34:13"> 這就是你們要抽籤分給以色列各支派的土地，作為他們的產業。這是主耶和華說的。</span>
<span className="v" id="v30" data-v="30" data-xref="以西結書 48:16; 啟示錄 21:16; 以西結書 48:32–35"> 「以下是城的各個出口。北面的牆是兩公里半長，</span>
<span className="v" id="v31" data-v="31" data-xref="啟示錄 21:12–13; 以賽亞書 26:1–2; 啟示錄 21:21"> 有三道門，按以色列的各支派命名，分別是呂便門、猶大門和利未門。</span>
<span className="v" id="v32" data-v="32"> 東面的牆是兩公里半長，有三道門，分別是約瑟門、便雅憫門和但門。</span>
<span className="v" id="v33" data-v="33"> 南面的牆是兩公里半長，有三道門，分別是西緬門、以薩迦門和西布倫門。</span>
<span className="v" id="v34" data-v="34"> 西面的牆是兩公里半長，有三道門，分別是迦得門、亞設門和拿弗他利門。</span>
<span className="v" id="v35" data-v="35" data-xref="啟示錄 21:3; 撒迦利亞書 2:10; 啟示錄 22:3"> 城的四周共長九公里半，從那時起，這城必叫『耶和華的所在』。」</span>

## 耶和華的榮光充滿聖殿

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西結書 44:1; 以西結書 42:15; 以西結書 46:1"> 後來，那人帶我來到東門，</span>
<span className="v" id="v2" data-v="2" data-xref="啟示錄 18:1; 以西結書 11:23; 以賽亞書 6:3"> 只見以色列上帝的榮光從東方而來，祂的聲音如澎湃的洪濤，大地也因祂的榮耀而發出光芒。</span>
<span className="v" id="v3" data-v="3" data-xref="以西結書 9:5; 以西結書 9:1; 耶利米書 1:10"> 這異象如同我從前在祂毀滅耶路撒冷時看見的異象，也像我在迦巴魯河邊看見的異象，我便俯伏在地。</span>
<span className="v" id="v4" data-v="4" data-xref="以西結書 10:18–19; 以西結書 44:2; 以西結書 43:2"> 耶和華的榮光從東門進入聖殿。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多後書 12:2–4; 列王紀上 8:10–11; 以西結書 8:3"> 上帝的靈把我舉起，帶我進入內院，只見耶和華的榮光充滿聖殿。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="以西結書 40:3; 以賽亞書 66:6; 啟示錄 16:1"> 那人仍然站在我身旁，我聽見有一位從殿中對我說：</span>
<span className="v" id="v7" data-v="7" data-xref="以西結書 43:9; 詩篇 47:8; 利未記 26:30"> 「人子啊，這裡是我的寶座，是我踏腳的地方，我要在這裡永遠住在以色列人當中。以色列的君民必不再因不忠貞，或在邱壇為他們死去的君王立碑而玷污我的聖名。</span>
<span className="v" id="v8" data-v="8" data-xref="以西結書 5:11; 以西結書 8:3–16; 歷代志下 33:7"> 他們不再在我聖殿旁邊建廟宇，使它們的門檻和門柱緊挨著我的門檻和門柱，以致我與它們只有一牆之隔。他們行可憎的事，玷污了我的聖名，所以我發怒消滅他們。</span>
<span className="v" id="v9" data-v="9" data-xref="以西結書 43:7; 以西結書 37:26–28; 以西結書 18:30–31"> 現在，他們要從我面前遠遠地除去他們的不忠貞和先王的碑，我就永遠住在他們當中。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="以西結書 40:4; 以西結書 16:61; 以西結書 16:63"> 「人子啊，你要向以色列人描述所看見的聖殿，讓他們思考聖殿的設計，使他們為自己的罪惡而羞愧。</span>
<span className="v" id="v11" data-v="11" data-xref="以西結書 36:27; 以西結書 11:20; 馬太福音 28:20"> 他們若為自己的行為感到羞愧，你就把殿的構造、出入口等整個設計，以及殿中的一切律例和法則告訴他們，並且當著他們的面寫下來，讓他們忠於設計，遵行殿的一切律例。</span>
<span className="v" id="v12" data-v="12" data-xref="以西結書 40:2; 啟示錄 21:27; 詩篇 93:5"> 殿所在的山頂周圍都是至聖之地，這是有關殿的法則。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="以西結書 40:5; 出埃及記 27:1–8; 以西結書 41:8"> 「以下是祭壇的尺寸，底槽深五十釐米，寬五十釐米，周圍環繞著一條二十五釐米高的邊框。</span>
<span className="v" id="v14" data-v="14"> 從底座到下層臺座高一米，邊寬五十釐米，下層臺座到上一層高二米，邊寬五十釐米。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及記 27:2; 詩篇 118:27; 利未記 9:9"> 最高一層是祭台，高二米，祭台上的四角向上突起。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 27:1; 歷代志下 4:1; 出埃及記 38:1–2"> 祭台是方形的，長寬各六米，</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及記 20:26; 以西結書 40:6; 出埃及記 25:25"> 下面的臺座也是方形的，長寬各七米，周圍環繞著一條二十五釐米高的邊框。底座四圍的邊寬五十釐米，上祭台的石階在東面。」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="出埃及記 40:29; 希伯來書 10:4–12; 以西結書 2:1"> 祂對我說：「人子啊，主耶和華這樣說，『祭壇建成後，要按以下的規矩在上面獻燔祭和灑血。</span>
<span className="v" id="v19" data-v="19" data-xref="以西結書 40:46; 以西結書 44:15; 民數記 16:40"> 你要將一頭公牛犢作為贖罪祭給撒督後裔中的利未祭司，他們可以前來事奉我。這是主耶和華說的。</span>
<span className="v" id="v20" data-v="20" data-xref="利未記 16:19; 利未記 8:15; 出埃及記 29:12"> 取些公牛犢的血抹在祭壇的四角、臺座的四角和四邊，使祭壇潔淨，為祭壇贖罪，</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及記 29:14; 利未記 4:12; 利未記 8:17"> 並把贖罪用的公牛犢拿到聖所外指定的聖殿區焚燒。</span>
<span className="v" id="v22" data-v="22" data-xref="以西結書 43:25–26; 以西結書 43:20; 彼得前書 1:19"> 第二天，你要獻上一頭毫無殘疾的公山羊作贖罪祭，就像獻公牛一樣，使祭壇潔淨。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及記 29:1"> 祭壇潔淨後，你要取來一頭毫無殘疾的公牛犢和一隻毫無殘疾的公綿羊，</span>
<span className="v" id="v24" data-v="24" data-xref="利未記 2:13; 馬可福音 9:49–50; 民數記 18:19"> 祭司要把鹽撒在祭牲上，作為燔祭獻在耶和華面前。</span>
<span className="v" id="v25" data-v="25" data-xref="利未記 8:33; 出埃及記 29:35–37; 利未記 8:35"> 一連七天，每天都要獻上一隻公山羊、一頭公牛犢和一隻公綿羊作贖罪祭，都不可有殘疾。</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及記 29:24; 利未記 8:34; 出埃及記 32:29"> 在這七天之內，他們要為祭壇贖罪，使壇潔淨，成為聖壇。</span>
<span className="v" id="v27" data-v="27" data-xref="利未記 9:1; 以西結書 20:40–41; 彼得前書 2:5"> 七天結束後，從第八天開始，祭司要在祭壇上獻你們的燔祭和平安祭，我必悅納你們。這是主耶和華說的。』」</span>
</div>
</div>

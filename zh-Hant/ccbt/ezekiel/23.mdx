## 兩個淫婦的比喻

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1"> 耶和華對我說：</span>
<span className="v" id="v2" data-v="2" data-xref="以西結書 16:44–46; 耶利米書 3:7–10"> 「人子啊，有一對同胞姊妹，</span>
<span className="v" id="v3" data-v="3" data-xref="利未記 17:7; 以西結書 16:22; 約書亞記 24:14"> 她們在埃及做娼妓，年輕時就淫亂，任人撫摸她們的胸，玩弄她們處女的乳。</span>
<span className="v" id="v4" data-v="4" data-xref="以西結書 16:8; 詩篇 76:2; 耶利米書 2:2–3"> 姐姐名叫阿荷拉，妹妹名叫阿荷利巴。後來她們都歸屬了我，並且生兒育女。阿荷拉即撒瑪利亞，阿荷利巴即耶路撒冷。</span>
<span className="v" id="v5" data-v="5" data-xref="何西阿書 5:13; 列王紀下 17:3; 列王紀下 16:7"> 「阿荷拉歸屬我後仍然淫亂，貪戀她的情人亞述戰士。</span>
<span className="v" id="v6" data-v="6" data-xref="以西結書 23:23"> 他們都是身穿紫衣的省長和總督，都是英俊的年輕騎士。</span>
<span className="v" id="v7" data-v="7" data-xref="何西阿書 5:3; 何西阿書 6:10; 以西結書 22:3–4"> 她便與這些亞述的精英放縱情慾，拜他們的偶像，玷污自己。</span>
<span className="v" id="v8" data-v="8" data-xref="以西結書 23:19; 以西結書 23:3; 出埃及記 32:4"> 她沒有放棄在埃及的淫蕩行為，她年輕的時候，就有人與她同寢，玩弄她處女的乳、發洩情慾。</span>
<span className="v" id="v9" data-v="9" data-xref="何西阿書 11:5; 列王紀下 15:29; 列王紀下 17:23"> 因此，我把她交在她所戀慕的亞述人手裡。</span>
<span className="v" id="v10" data-v="10" data-xref="以西結書 23:29; 何西阿書 2:10; 耶利米書 22:8–9"> 他們扒光她的衣服，奪去她的兒女，用刀殺了她。她受了報應，成了婦女口中的笑柄。</span>
<span className="v" id="v11" data-v="11" data-xref="耶利米書 3:8–11; 以西結書 16:47–51; 以西結書 23:4"> 「她妹妹阿荷利巴看見這一切，不但沒有引以為戒，反而比姐姐更加放蕩淫亂。</span>
<span className="v" id="v12" data-v="12" data-xref="列王紀下 16:7–15; 以西結書 23:23; 歷代志下 28:16–23"> 她貪戀亞述的省長和總督，那些衣著華麗、英俊的年輕騎士。</span>
<span className="v" id="v13" data-v="13" data-xref="何西阿書 12:1–2; 列王紀下 17:18–19; 以西結書 23:31"> 我看見她玷污了自己，與姐姐的行徑如出一轍。</span>
<span className="v" id="v14" data-v="14" data-xref="以西結書 8:10; 耶利米書 22:14; 耶利米書 50:2"> 她還變本加厲地放蕩淫亂，看見牆上用朱砂畫著迦勒底人的像，</span>
<span className="v" id="v15" data-v="15" data-xref="士師記 8:18; 撒母耳記上 18:4; 以賽亞書 22:21"> 腰間束帶，頭巾飄揚，都像是來自迦勒底的巴比倫人的將領，</span>
<span className="v" id="v16" data-v="16" data-xref="以西結書 16:29; 馬太福音 5:28; 約伯記 31:1"> 便戀上了他們，差遣使者到他們那裡。</span>
<span className="v" id="v17" data-v="17" data-xref="以西結書 23:28; 以西結書 23:22; 創世記 10:10"> 巴比倫人便來上她的床，放縱情慾玷污了她。之後，她便厭棄他們。</span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 78:59; 詩篇 106:40; 耶利米書 12:8"> 她繼續公開地淫亂，在眾人面前赤身露體，我厭棄她，像厭棄她姐姐一樣。</span>
<span className="v" id="v19" data-v="19" data-xref="以西結書 23:3; 以西結書 20:7; 以西結書 16:51"> 她卻更加淫亂，懷念自己年輕時在埃及為娼的日子，</span>
<span className="v" id="v20" data-v="20" data-xref="以西結書 17:15; 以西結書 16:26; 耶利米書 5:8"> 貪戀那些體壯精足、如驢似馬的情人，</span>
<span className="v" id="v21" data-v="21"> 渴望重溫早年的淫行，任埃及人摸胸弄乳的日子。</span>
<span className="v" id="v22" data-v="22" data-xref="以西結書 16:37; 啟示錄 17:16; 耶利米書 6:22–23"> 「因此，主耶和華說，『阿荷利巴啊，我要促使那些你始亂終棄的情人從四面八方來攻擊你。</span>
<span className="v" id="v23" data-v="23" data-xref="耶利米書 50:21; 列王紀下 24:2; 列王紀下 20:14–17"> 他們是巴比倫人，還有從比割、書亞和哥亞來的所有迦勒底人以及亞述人，都是騎馬的英俊青年，有省長、總督及有名將領。</span>
<span className="v" id="v24" data-v="24" data-xref="撒母耳記下 24:14; 以西結書 26:10; 以西結書 23:45"> 他們率領大隊人馬，帶著兵器、戰車和軍需車來攻擊你。他們頂盔貫甲，手拿盾牌從四面八方進攻你。我要讓他們懲罰你，他們會按自己的律例來審判你。</span>
<span className="v" id="v25" data-v="25" data-xref="以西結書 23:47; 以西結書 8:1–18; 以西結書 15:6–7"> 我要藉著他們向你傾倒我的義憤，他們要在憤怒中對付你，割去你的鼻子和耳朵，擄去你的兒女，城中剩下的人都要死於刀下，被火吞噬。</span>
<span className="v" id="v26" data-v="26" data-xref="以西結書 16:39; 耶利米書 13:22; 以西結書 23:29"> 他們要剝下你的衣服，奪去你的珠寶。</span>
<span className="v" id="v27" data-v="27" data-xref="以西結書 16:41; 以西結書 23:3; 以西結書 23:19"> 我要藉此制止你從埃及染上的淫亂和放蕩，使你不再嚮往和留戀埃及。』</span>
<span className="v" id="v28" data-v="28" data-xref="以西結書 23:22; 以西結書 23:17; 耶利米書 34:20"> 「主耶和華說，『我要把你交在你憎惡的人手中，交在那些你始亂終棄的人手中，</span>
<span className="v" id="v29" data-v="29" data-xref="以西結書 16:39; 以西結書 23:25–26; 以西結書 23:45–47"> 他們必滿懷仇恨地對付你，奪去你努力得來的一切，留下你赤身露體，使你淫蕩的醜惡公佈於眾。</span>
<span className="v" id="v30" data-v="30" data-xref="以西結書 6:9; 詩篇 106:35–38; 耶利米書 2:18–20"> 因為你與各國苟合，被他們的偶像玷污，這些事必臨到你身上。</span>
<span className="v" id="v31" data-v="31" data-xref="列王紀下 21:13; 耶利米書 7:14–15; 以西結書 16:47–51"> 你既然步你姐姐的後塵，我要讓你喝她喝的那杯。』</span>
<span className="v" id="v32" data-v="32" data-xref="以賽亞書 51:17; 詩篇 60:3; 以西結書 22:4–5"> 「主耶和華說，<br /><span className="pl pl-1">「『你必喝你姐姐那又大又深的杯，</span><br /><span className="pl pl-1">你必遭人恥笑和辱罵，</span><br /><span className="pl pl-1">因為那杯能盛很多。</span><br /></span>
<span className="v" id="v33" data-v="33" data-xref="以賽亞書 51:17; 耶利米書 25:27; 耶利米書 25:15–16"> <span className="pl pl-1">你姐姐撒瑪利亞的杯盛滿了恐懼和淒涼。</span><br /><span className="pl pl-1">你喝了後必酩酊大醉，</span><br /><span className="pl pl-1">滿心憂愁。</span><br /></span>
<span className="v" id="v34" data-v="34" data-xref="詩篇 75:8; 以賽亞書 51:17; 啟示錄 18:7"> <span className="pl pl-1">你必把它喝光，一滴不剩，</span><br /><span className="pl pl-1">然後把杯摔成碎片，</span><br /><span className="pl pl-1">抓破自己的胸脯，</span><br /><span className="pl pl-1">因為我已經宣告。</span><br /><span className="pl pl-1">這是主耶和華說的。』</span></span>
<span className="v" id="v35" data-v="35" data-xref="列王紀上 14:9; 以賽亞書 17:10; 耶利米書 32:33"> 「主耶和華說，『你既忘記我，把我拋在腦後，就要受自己放蕩淫亂的報應。』」</span>
<span className="v" id="v36" data-v="36" data-xref="以西結書 22:2; 以賽亞書 58:1; 以西結書 16:2"> 耶和華又對我說：「人子啊，你要審判阿荷拉和阿荷利巴，指出她們的醜行。</span>
<span className="v" id="v37" data-v="37" data-xref="以西結書 16:36; 耶利米書 32:35; 耶利米書 7:31"> 她們淫蕩，手上沾滿血腥，與偶像淫亂，把為我所生的兒女燒死獻給偶像。</span>
<span className="v" id="v38" data-v="38" data-xref="以西結書 20:13; 列王紀下 21:7; 以西結書 7:20"> 同時，她們還這樣在同一天玷污我的聖所，褻瀆我的安息日，</span>
<span className="v" id="v39" data-v="39" data-xref="列王紀下 21:4; 以西結書 44:7; 耶利米書 23:11"> 她們焚燒自己的兒女獻祭給偶像，並在當天進入我的聖所，褻瀆聖所。這就是她們在我聖所裡的惡行。</span>
<span className="v" id="v40" data-v="40" data-xref="列王紀下 9:30; 耶利米書 4:30; 以西結書 16:13–16"> 「她們甚至派使者去請遠方的人，請來之後，就沐浴洗身，描眉畫眼，佩戴首飾，</span>
<span className="v" id="v41" data-v="41" data-xref="以斯帖記 1:6; 耶利米書 44:17; 以賽亞書 65:11"> 坐在華麗的床上，面前的桌子上擺設著我的香料和膏油。</span>
<span className="v" id="v42" data-v="42" data-xref="以西結書 16:11–12; 啟示錄 12:3; 出埃及記 32:18–19"> 她們身邊傳出一群人的作樂聲，從曠野來的酒徒和粗漢把鐲子戴在這對姊妹的手腕上，把華冠戴在她們的頭上。</span>
<span className="v" id="v43" data-v="43" data-xref="以西結書 23:3; 耶利米書 13:23; 以斯拉記 9:7"> 關於這因縱慾而色衰的婦人，我說，『這些人會繼續與她淫亂。</span>
<span className="v" id="v44" data-v="44" data-xref="以西結書 23:9–13; 以西結書 23:3"> 他們與這對淫婦阿荷拉和阿荷利巴淫亂，好像與娼妓淫亂一樣。</span>
<span className="v" id="v45" data-v="45" data-xref="何西阿書 6:5; 利未記 20:10; 以西結書 23:36–39"> 她們是雙手沾滿血腥的淫婦，必有義人按她們應得的報應審判她們。』</span>
<span className="v" id="v46" data-v="46" data-xref="以西結書 16:40; 耶利米書 15:4; 耶利米書 24:9"> 「主耶和華說，『我要使許多人起來攻擊、搶掠她們，叫她們膽戰心驚。</span>
<span className="v" id="v47" data-v="47" data-xref="以西結書 16:40–41; 耶利米書 39:8; 以西結書 24:21"> 這些人要用石頭打死她們，用刀殺戮她們，並殺死她們的兒女，用火燒毀她們的房屋。</span>
<span className="v" id="v48" data-v="48" data-xref="以西結書 6:6; 以西結書 23:27; 以西結書 16:41"> 這樣，我便清除了這地方的淫亂，所有的婦女都引以為戒，不敢效法她們。</span>
<span className="v" id="v49" data-v="49" data-xref="以西結書 9:10; 以西結書 7:4; 以西結書 6:7"> 她們淫亂，必得報應；她們拜偶像，必受懲罰。這樣，她們就知道我是主耶和華。』」</span>

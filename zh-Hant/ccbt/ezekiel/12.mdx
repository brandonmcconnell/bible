## 被擄的預兆

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華對我說：</span>
<span className="v" id="v2" data-v="2" data-xref="馬可福音 4:12; 耶利米書 5:21; 詩篇 78:40"> 「人子啊，你住在叛逆的人當中。他們有眼睛卻視而不見，有耳朵卻聽而不聞，因為他們是叛逆的人。</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米書 36:3; 提摩太後書 2:25; 耶利米書 26:3"> 所以，人子啊，你要準備流亡的行裝，在白天出去流亡。你要像流亡者一樣，當著他們的面從你住的地方搬到別處。他們雖然叛逆，或許還會明白其中的意思。</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米書 39:4; 以西結書 12:12; 列王紀下 25:4"> 你要在白天當著他們的面把預備流亡的行裝拿出來，你要在晚上當著他們的面像流亡的人一樣出去。</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀下 25:4; 耶利米書 39:2–4"> 你要當著他們的面在牆上挖一個洞，帶著行裝鑽出去。</span>
<span className="v" id="v6" data-v="6" data-xref="以西結書 4:3; 以賽亞書 8:18; 以西結書 24:24"> 你要在天黑時當著他們的面背著行裝出發。你要蒙著臉使自己看不見地，因為我要使你成為以色列人的預兆。」</span>
<span className="v" id="v7" data-v="7" data-xref="以西結書 24:18; 以西結書 37:10; 以西結書 37:7"> 於是，我遵命而行。白天我把預備流亡的行裝拿出來，晚上用手挖通了牆，當著他們的面背著行裝在天黑時出發。</span>
<span className="v" id="v8" data-v="8"> 第二天早晨，耶和華對我說：</span>
<span className="v" id="v9" data-v="9" data-xref="以西結書 24:19; 以西結書 17:12; 以西結書 20:49"> 「人子啊，那些叛逆的以色列人不是問你在做什麼嗎？</span>
<span className="v" id="v10" data-v="10" data-xref="列王紀下 9:25; 以賽亞書 13:1; 耶利米書 24:8"> 你要告訴他們，『主耶和華說：這是關於耶路撒冷的首領和城中以色列人的預兆。』</span>
<span className="v" id="v11" data-v="11" data-xref="耶利米書 52:15; 耶利米書 15:2; 耶利米書 52:28–30"> 你要說，『我就是給你們的預兆，我所做的必發生在你們身上，你們必被擄流亡。』</span>
<span className="v" id="v12" data-v="12" data-xref="列王紀下 25:4; 耶利米書 39:4; 以西結書 12:6"> 他們當中的首領必在天黑時背著行裝出發，在牆上挖洞鑽出去，而且必蒙著臉，看不見地。</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米書 39:7; 何西阿書 7:12; 以西結書 17:20"> 我必撒開網羅捕捉他，把他帶到迦勒底人的巴比倫。他必看不見那地方，卻要死在那裡。</span>
<span className="v" id="v14" data-v="14" data-xref="以西結書 5:2; 列王紀下 25:4–5; 以西結書 17:21"> 我要把他周圍的隨從和所有軍隊驅散到四方，並且拔刀追殺他們。</span>
<span className="v" id="v15" data-v="15" data-xref="以西結書 6:7; 以西結書 12:16; 以西結書 12:20"> 當我把他們驅趕到各國，分散到列邦時，他們就知道我是耶和華。</span>
<span className="v" id="v16" data-v="16" data-xref="耶利米書 22:8–9; 以西結書 14:22–23; 以西結書 6:8–10"> 然而，我要使他們當中一些人免遭刀劍、饑荒和瘟疫，使他們可以在所去的各國供述自己的一切可憎行為。他們就知道我是耶和華。」</span>
<span className="v" id="v17" data-v="17"> 耶和華對我說：</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米哀歌 5:9; 詩篇 80:5; 約伯記 3:24"> 「人子啊，你要戰戰兢兢地吃飯，惶惶恐恐地喝水，</span>
<span className="v" id="v19" data-v="19" data-xref="撒迦利亞書 7:14; 以西結書 6:6–7; 以西結書 6:14"> 然後對這地方的人說，『關於耶路撒冷和以色列的居民，主耶和華這樣說，他們必焦慮不安地吃飯，惶恐不已地喝水，他們的土地必因其中居民的暴行而荒無人煙。</span>
<span className="v" id="v20" data-v="20" data-xref="耶利米書 4:7; 以賽亞書 7:23–24; 耶利米書 25:9"> 他們居住的城邑必淪為廢墟，土地必一片荒涼，他們就知道我是耶和華。』」</span>
<span className="v" id="v21" data-v="21"> 耶和華對我說：</span>
<span className="v" id="v22" data-v="22" data-xref="以西結書 18:2–3; 以西結書 11:3; 以西結書 12:27"> 「人子啊，你們以色列有一句俗語，『光陰流逝，異象都落空。』</span>
<span className="v" id="v23" data-v="23" data-xref="約珥書 2:1; 以西結書 7:5–7; 西番雅書 1:14"> 現在你要告訴他們，主耶和華這樣宣告：我要廢掉這句俗語，使它從以色列人的口中消失。你要對他們說，『日子已近，異象都要應驗。』</span>
<span className="v" id="v24" data-v="24" data-xref="耶利米書 14:13–16; 以西結書 13:23; 撒迦利亞書 13:2–4"> 在以色列人中必不再有虛假的異象和諂媚的預言。</span>
<span className="v" id="v25" data-v="25" data-xref="哈巴谷書 1:5; 以西結書 12:28; 以賽亞書 55:11"> 我是耶和華，我的話都必實現，決不遲延。你們這叛逆的人啊，我說的話必在你們有生之年應驗！」這是主耶和華說的。</span>
<span className="v" id="v26" data-v="26"> 耶和華對我說：</span>
<span className="v" id="v27" data-v="27" data-xref="但以理書 10:14; 以西結書 12:22; 彼得後書 3:4"> 「人子啊，你看，以色列人在說，『他見的異象是關乎多年後的事，他說的預言是針對遙遠的未來。』</span>
<span className="v" id="v28" data-v="28" data-xref="以西結書 12:23–25; 馬可福音 13:32–37; 帖撒羅尼迦前書 5:2–3"> 因此，你要對他們說，『主耶和華這樣說：我的話必應驗，不再遲延。』這是主耶和華說的。」</span>

## 鷹和葡萄樹的比喻

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華對我說：</span>
<span className="v" id="v2" data-v="2" data-xref="以西結書 20:49; 馬太福音 13:35; 哥林多前書 13:12"> 「人子啊，你要向以色列人出謎語，講比喻，</span>
<span className="v" id="v3" data-v="3" data-xref="何西阿書 8:1; 耶利米書 48:40; 以西結書 17:7"> 告訴他們，主耶和華說，『有一隻大鷹翅膀寬大，羽毛豐滿，色彩繽紛。這隻鷹飛到黎巴嫩的香柏樹上，折去樹梢，</span>
<span className="v" id="v4" data-v="4" data-xref="以賽亞書 43:14; 以賽亞書 47:15; 啟示錄 18:11–19"> 掐下樹梢的嫩枝，叼到一個商賈雲集的城市，栽在那裡。</span>
<span className="v" id="v5" data-v="5" data-xref="以賽亞書 44:4; 申命記 8:7–9; 耶利米書 37:1"> 牠又把以色列的樹苗像栽柳樹一樣，栽在水源豐沛的沃土裡。</span>
<span className="v" id="v6" data-v="6" data-xref="以西結書 17:14; 箴言 16:18–19"> 樹苗發了芽，成為向四面蔓延的矮小葡萄樹，它向下扎根，長出枝幹，枝子向著鷹伸展。</span>
<span className="v" id="v7" data-v="7" data-xref="以西結書 31:4; 以西結書 17:15; 列王紀下 24:20"> 「『又有一隻大鷹，翅膀寬大，羽毛豐滿。這葡萄樹把根和枝子從園圃中轉向這隻鷹，好得到牠的澆灌。</span>
<span className="v" id="v8" data-v="8" data-xref="以西結書 17:5–6"> 但這樹已栽在水源豐沛的沃土裡，可以生枝結果，成為美好的葡萄樹。』</span>
<span className="v" id="v9" data-v="9" data-xref="以西結書 17:10; 耶利米書 32:5; 以賽亞書 30:1–7"> 「你要告訴他們，主耶和華這樣說，『這樹能長得茂盛嗎？難道那鷹不把它連根拔起，摘掉它的果子，使樹和嫩葉全部枯萎嗎？不必費多大力氣，也不需要多少人就可以把它連根拔起。</span>
<span className="v" id="v10" data-v="10" data-xref="何西阿書 13:15; 約翰福音 15:6; 馬太福音 21:19"> 這樹雖然被栽種了，又豈能長得茂盛呢？東風一吹，它豈不在園圃中完全枯萎嗎？』」</span>
<span className="v" id="v11" data-v="11"> 耶和華對我說：</span>
<span className="v" id="v12" data-v="12" data-xref="以西結書 24:19; 以西結書 17:3; 以西結書 1:2"> 「你要對這些悖逆的人說，『你們不明白這比喻的意思嗎？』要告訴他們，巴比倫王攻取了耶路撒冷，把其中的君王和大臣擄到巴比倫，</span>
<span className="v" id="v13" data-v="13" data-xref="歷代志下 36:13; 列王紀下 24:15–17; 以西結書 17:5"> 並從猶大王室中選出一人與他立約，要他宣誓效忠。巴比倫王也擄去猶大國的重臣，</span>
<span className="v" id="v14" data-v="14" data-xref="以西結書 29:14; 申命記 28:43; 撒母耳記上 2:30"> 使猶大國臣服於他，無法圖強，只能遵守盟約，以求生存。</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米書 52:3; 耶利米書 38:18; 以西結書 17:7"> 後來，猶大王背叛了巴比倫王，派使者到埃及請求支援軍隊馬匹。他能成功嗎？他這樣做怎能逃脫懲罰呢？他這樣背約怎能逃脫懲罰呢？</span>
<span className="v" id="v16" data-v="16" data-xref="以西結書 12:13; 耶利米書 52:11; 以西結書 17:18–19"> 「主耶和華說，『我憑我的永恆起誓，巴比倫王立他做王，他卻藐視所起的誓，背棄所立的約，他必死在巴比倫。</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米書 37:7; 以西結書 4:2; 以西結書 29:6–7"> 敵人築起圍攻的土壘和高臺大肆殺戮的時候，法老雖然兵強馬壯，人多勢眾，仍無法幫他抗敵。</span>
<span className="v" id="v18" data-v="18" data-xref="歷代志上 29:24; 歷代志下 30:8; 耶利米哀歌 5:6"> 他起誓降服，卻棄約背誓，出爾反爾，所以絕不能逃避後果。</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 5:11; 耶利米書 5:9; 耶利米書 5:2"> 「『因此，主耶和華說：我憑我的永恆起誓，他既藐視我的誓言，背棄我的約，我必懲罰他。</span>
<span className="v" id="v20" data-v="20" data-xref="以西結書 12:13; 以西結書 32:3; 耶利米書 2:35"> 我要撒開網羅抓住他，把他帶到巴比倫，審判他對我不忠的罪。</span>
<span className="v" id="v21" data-v="21" data-xref="列王紀下 25:5; 列王紀下 25:11; 以西結書 12:14"> 他所有的精兵都要喪身刀下，餘下的也要四散逃竄。這樣，你們就知道這是我耶和華說的。</span>
<span className="v" id="v22" data-v="22" data-xref="以賽亞書 53:2; 撒迦利亞書 6:12–13; 以賽亞書 11:1–5"> 「『主耶和華說：我要從香柏樹高高的樹梢上折下一根細枝栽上，我要從樹的頂端折下嫩枝栽在巍峨的高山上。</span>
<span className="v" id="v23" data-v="23" data-xref="馬太福音 13:32; 以西結書 31:6; 以賽亞書 2:2"> 我要把它栽在以色列的高山上，使它生枝結果，成為一棵美麗的香柏樹，各類飛鳥都要棲息在樹上，棲息在枝頭的樹蔭裡。</span>
<span className="v" id="v24" data-v="24" data-xref="阿摩司書 9:11; 哥林多前書 1:27–28; 以西結書 24:14"> 田野所有的樹都會知道我耶和華使高樹倒下、矮樹長高、青樹枯萎、枯樹發榮。我耶和華言出必行。』」</span>

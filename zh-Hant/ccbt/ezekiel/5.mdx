<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以賽亞書 7:20; 以西結書 44:20; 利未記 21:5"> 「人子啊，去拿一把快刀當作剃頭刀，剃掉你的頭髮和鬍鬚，然後用天平把鬚髮平均分成三份。</span>
<span className="v" id="v2" data-v="2" data-xref="以西結書 5:12; 利未記 26:33; 以西結書 4:1–8"> 圍城期滿後，你要把三分之一的鬚髮焚燒在城中，三分之一在城的四周用刀砍斷，三分之一要揚在風中吹散，因為我要拔刀追殺它們。</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米書 52:16; 耶利米書 40:6; 耶利米書 39:10"> 你要從鬚髮中取出幾縷用衣服包上，</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米書 4:4; 耶利米書 41:1–18; 列王紀下 25:25"> 再從中取出幾根扔進火裡焚燒，必有火從這裡燃起，蔓延到整個以色列。」</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="以西結書 4:1; 申命記 4:6; 耶利米書 6:6"> 主耶和華說：「這就是耶路撒冷！我把她安置在萬邦的中央，使列國環繞著她。</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米書 11:10; 以西結書 16:47–48; 尼希米記 9:16–17"> 但她違背我的典章，作惡甚於列邦，觸犯我的律例甚於她周圍的列國。他們拒絕我的典章，不遵守我的律例。」</span>
<span className="v" id="v7" data-v="7" data-xref="耶利米書 2:10–11; 歷代志下 33:9; 列王紀下 21:9–11"> 所以主耶和華說：「你們比周圍的國家更混亂不堪，你們沒有遵行我的律例，不謹守我的典章，連周圍的國家都不如。」</span>
<span className="v" id="v8" data-v="8" data-xref="以西結書 15:7; 耶利米書 24:9; 以西結書 21:3"> 因此主耶和華這樣說：「看啊，我要親自對付你們，我必在列國面前審判你們。</span>
<span className="v" id="v9" data-v="9" data-xref="馬太福音 24:21; 但以理書 9:12; 阿摩司書 3:2"> 因為你們一切的惡行，我必向你們施行空前絕後的懲罰。</span>
<span className="v" id="v10" data-v="10" data-xref="撒迦利亞書 2:6; 申命記 28:64; 以西結書 12:14"> 在你們中間，父親要吃自己的兒子，兒子要吃自己的父親。我必懲罰你們，把你們餘下的人分散到各地各方。」</span>
<span className="v" id="v11" data-v="11" data-xref="以西結書 7:20; 以西結書 7:9; 以西結書 11:18"> 主耶和華說：「因為你們用一切可憎的偶像和惡行玷污我的聖所，我憑我的永恆起誓，我必毫不留情地剷除你們。</span>
<span className="v" id="v12" data-v="12" data-xref="以西結書 5:2; 耶利米書 15:2; 耶利米書 43:10–11"> 你們三分之一的人要死於瘟疫和饑荒，三分之一的人要死於刀下，我必把其餘的三分之一分散到各地各方，並拔刀追殺他們。</span>
<span className="v" id="v13" data-v="13" data-xref="以賽亞書 1:24; 以西結書 36:5–6; 以西結書 21:17"> 這樣，我的怒氣才會發完，我對你們的怒火才會盡消，我才會息怒。我把烈怒傾倒在你們身上的時候，你們就會知道我耶和華說這話是出於痛恨不貞。</span>
<span className="v" id="v14" data-v="14" data-xref="以西結書 22:4; 尼希米記 2:17; 詩篇 79:1–4"> 我必使你們的家園荒涼，使你們在周圍的列國中，在路人眼前飽受羞辱。</span>
<span className="v" id="v15" data-v="15" data-xref="以西結書 25:17; 耶利米書 22:8–9; 列王紀上 9:7"> 當我在怒氣，義憤和烈怒中嚴厲地審判你們時，你們在各國必受羞辱和嘲諷，成為警戒，下場可怕。這是我耶和華說的。</span>
<span className="v" id="v16" data-v="16" data-xref="以西結書 4:16; 申命記 32:23–24; 以西結書 14:13"> 我要向你們射出饑荒的毒箭，破壞和毀滅你們，並且使饑荒越來越嚴重，斷絕你們的糧源。</span>
<span className="v" id="v17" data-v="17" data-xref="以西結書 38:22; 以西結書 14:21; 利未記 26:22"> 我必讓饑荒和猛獸來侵害你們，奪走你們的兒女，使你們飽受瘟疫、暴行和刀劍之災，這是我耶和華說的。」</span>
</div>

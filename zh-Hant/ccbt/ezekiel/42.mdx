## 祭司用的廂房

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西結書 40:20; 以西結書 40:17; 以西結書 42:13"> 那人帶我出了聖殿，向北來到外院的廂房，一排在空地對面，一排在北邊的建築物對面。</span>
<span className="v" id="v2" data-v="2" data-xref="以西結書 41:13"> 廂房長五十米，寬二十五米，有北門。</span>
<span className="v" id="v3" data-v="3" data-xref="以西結書 41:15–16; 以西結書 41:10; 雅歌 7:5"> 內院十米寬的空地對面和外院的鋪石地對面有三層走廊，彼此相對。</span>
<span className="v" id="v4" data-v="4" data-xref="以西結書 46:19; 路加福音 13:24; 馬太福音 7:14"> 在兩排廂房之間有一條五米寬、五十米長的通道，廂房的門都向北。</span>
<span className="v" id="v5" data-v="5" data-xref="以西結書 41:7"> 上層的廂房比下層和中層的窄，因為上層走廊佔去較大的面積。</span>
<span className="v" id="v6" data-v="6" data-xref="以西結書 41:6; 列王紀上 6:8"> 這建築物不像外院那樣有柱子，所以上層比中層和下層窄。</span>
<span className="v" id="v7" data-v="7" data-xref="以西結書 42:12; 以西結書 42:10"> 廂房旁邊有道外牆與廂房及外院平行，長二十五米。</span>
<span className="v" id="v8" data-v="8" data-xref="以西結書 41:13–14"> 靠近外院的廂房長二十五米，靠近聖殿的廂房則長五十米。</span>
<span className="v" id="v9" data-v="9" data-xref="以西結書 46:19; 以西結書 44:5"> 下層廂房的東面有一道門，可以從外院進入。</span>
<span className="v" id="v10" data-v="10" data-xref="以西結書 42:1; 以西結書 42:13; 以西結書 41:12–15"> 南面<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「南面」希伯來文是「東面」。">a</a></sup>的院牆有兩排廂房，一排在空地對面，一排在南面的建築物對面，</span>
<span className="v" id="v11" data-v="11" data-xref="以西結書 42:4"> 廂房前面有通道。這些廂房與北面的廂房一樣，長寬相同，出入口和結構也一樣。</span>
<span className="v" id="v12" data-v="12"> 南廂房的門也和北面的一樣，廂房東面通道的前端有一道門可以進入。</span>
<span className="v" id="v13" data-v="13" data-xref="利未記 10:17; 利未記 7:6; 以西結書 40:46"> 他對我說：「這些在南北兩面對著聖殿空地的廂房都是聖潔的，供事奉耶和華的祭司在那裡吃至聖的祭物，並放置素祭、贖罪祭和贖過祭等至聖的祭物，因為這是聖潔的地方。</span>
<span className="v" id="v14" data-v="14" data-xref="以西結書 44:19; 利未記 8:7; 出埃及記 29:4–9"> 祭司在聖所供職後，不可直接到外院，要先在這些廂房裡脫下供職時所穿的聖衣，換上普通衣服，才可以到外面的百姓那裡。」</span>
<span className="v" id="v15" data-v="15" data-xref="以西結書 43:1; 以西結書 41:15; 以西結書 40:6–16"> 他量完聖殿裡面，便帶我出了東門，量聖殿外圍。</span>
<span className="v" id="v16" data-v="16" data-xref="以西結書 40:3; 啟示錄 11:1–2; 撒迦利亞書 2:1"> 他用量竿量了東面，長二百五十米；</span>
<span className="v" id="v17" data-v="17"> 又量了北面，長二百五十米；</span>
<span className="v" id="v18" data-v="18"> 又量了南面，長二百五十米；</span>
<span className="v" id="v19" data-v="19"> 然後又去量西面，長二百五十米。</span>
<span className="v" id="v20" data-v="20" data-xref="以西結書 45:2; 以西結書 22:26; 以西結書 40:5"> 他量了聖殿的四圍，四圍有一道牆，長寬都是二百五十米，這牆是為了把聖地和俗地隔開。</span>
</div>

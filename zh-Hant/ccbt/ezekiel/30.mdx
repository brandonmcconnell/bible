## 為埃及唱哀歌

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1"> 耶和華對我說：</span>
<span className="v" id="v2" data-v="2" data-xref="以賽亞書 13:6; 以西結書 21:12; 約珥書 1:11"> 「人子啊，你要說預言，宣告主耶和華這樣說，<br /><span className="pl pl-1">「『哀號吧！你們要為那日悲傷。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="俄巴底亞書 1:15; 約珥書 2:1–2; 約珥書 1:15"> <span className="pl pl-1">因為日子近了，耶和華的日子近了，</span><br /><span className="pl pl-1">那將是烏雲密佈的日子，</span><br /><span className="pl pl-1">是列國淪亡的時候。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="以西結書 29:19; 以西結書 29:8; 以賽亞書 16:7"> <span className="pl pl-1">必有刀劍攻擊埃及，</span><br /><span className="pl pl-1">埃及必屍橫遍野，</span><br /><span className="pl pl-1">古實必痛苦不堪。</span><br /><span className="pl pl-1">敵人要擄掠埃及的財富，</span><br /><span className="pl pl-1">摧毀她的根基。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="耶利米書 25:20; 以西結書 27:10; 耶利米書 25:24"> <span className="pl pl-1">古實、弗、路德、阿拉伯和利比亞及其他盟友都必與她一同死於刀下。』</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="以西結書 29:10; 以賽亞書 20:3–6; 以賽亞書 31:3"> <span className="pl pl-1">「耶和華說，</span><br /><span className="pl pl-1">『埃及的盟友都要覆滅，</span><br /><span className="pl pl-1">埃及的傲氣必蕩然無存，</span><br /><span className="pl pl-1">從密奪到色弗尼的居民都要喪身刀下。</span><br /><span className="pl pl-1">這是主耶和華說的。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="以西結書 29:12; 耶利米書 25:18–26; 以西結書 32:18–32"> <span className="pl pl-1">埃及要變成荒地中的荒地，</span><br /><span className="pl pl-1">她的城邑要淪為廢墟中的廢墟。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="以西結書 29:6; 以西結書 29:16; 阿摩司書 1:7"> <span className="pl pl-1">我要點火燒埃及，</span><br /><span className="pl pl-1">埃及的所有盟友都要滅亡。</span><br /><span className="pl pl-1">那時，他們就知道我是耶和華。</span></span>
<span className="v" id="v9" data-v="9" data-xref="以賽亞書 18:1–2; 以賽亞書 23:5; 以西結書 32:9–10"> 「『在那日，我要差遣使者乘船出去驚嚇安逸的古實人，在埃及遭難的日子，他們必痛苦不堪。看啊，這日子快到了。』</span>
<span className="v" id="v10" data-v="10" data-xref="以西結書 29:19; 以西結書 32:11–16; 以西結書 29:4–5"> 「主耶和華說，<br /><span className="pl pl-1">「『我要藉巴比倫王尼布甲尼撒的手消滅埃及的百姓。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="以西結書 28:7; 以西結書 32:12; 以西結書 39:11–20"> <span className="pl pl-1">他和追隨他的都是萬民中最殘暴的人。</span><br /><span className="pl pl-1">他們去毀滅埃及，</span><br /><span className="pl pl-1">拔刀攻擊那裡，</span><br /><span className="pl pl-1">使埃及屍骨遍野。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="以西結書 29:3; 那鴻書 1:4; 啟示錄 16:12"> <span className="pl pl-1">我要使尼羅河乾涸，</span><br /><span className="pl pl-1">把土地賣給惡人，</span><br /><span className="pl pl-1">我要藉外族人的手使埃及及其境內的一切都荒廢，</span><br /><span className="pl pl-1">這是我耶和華說的。』</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v13" data-v="13" data-xref="撒迦利亞書 10:11; 耶利米書 46:14; 耶利米書 2:16"> <span className="pl pl-1">「主耶和華說，</span><br /><span className="pl pl-1">『我要毀滅偶像，</span><br /><span className="pl pl-1">剷除挪弗的神像。</span><br /><span className="pl pl-1">埃及再沒有君王，</span><br /><span className="pl pl-1">我要使埃及境內充滿恐懼。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="以西結書 29:14; 耶利米書 46:25; 詩篇 78:43"> <span className="pl pl-1">我要使巴特羅荒廢，</span><br /><span className="pl pl-1">放火焚燒瑣安，</span><br /><span className="pl pl-1">審判底比斯。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="啟示錄 16:1; 那鴻書 1:6; 詩篇 11:6"> <span className="pl pl-1">我要把我的烈怒傾倒在埃及的訓堡壘，</span><br /><span className="pl pl-1">消滅底比斯的百姓。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="以西結書 30:8–9; 以西結書 28:18"> <span className="pl pl-1">我要放火燒埃及，</span><br /><span className="pl pl-1">訓必受極大的痛苦，</span><br /><span className="pl pl-1">底比斯要被攻破，</span><br /><span className="pl pl-1">挪弗終日困苦不已，</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="創世記 41:45"> <span className="pl pl-1">亞文和比伯實的壯丁必死於刀下，</span><br /><span className="pl pl-1">眾城都要遭受擄掠。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="以西結書 30:3; 以西結書 29:15; 以賽亞書 10:27"> <span className="pl pl-1">我粉碎埃及勢力的那天，</span><br /><span className="pl pl-1">答比匿必日月無光，</span><br /><span className="pl pl-1">她的銳氣全消。</span><br /><span className="pl pl-1">烏雲必籠罩她，</span><br /><span className="pl pl-1">她城邑的居民必被擄去。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="以西結書 30:14; 啟示錄 17:1; 以西結書 5:8"> <span className="pl pl-1">我必這樣審判埃及，</span><br /><span className="pl pl-1">他們就知道我是耶和華。』」</span></span>
<span className="v" id="v20" data-v="20" data-xref="以西結書 29:17; 以西結書 26:1; 以西結書 29:1"> 第十一年一月七日，耶和華對我說：</span>
<span className="v" id="v21" data-v="21" data-xref="耶利米書 30:13; 耶利米書 46:11; 詩篇 37:17"> 「人子啊，我打斷了埃及王法老的一隻臂膀，沒有人替他敷藥包紮，以致他無力拿刀。</span>
<span className="v" id="v22" data-v="22" data-xref="詩篇 37:17; 耶利米書 37:7; 列王紀下 24:7"> 因此，主耶和華說，『我要與埃及王法老為敵，我要把他那強壯的臂膀和曾經受傷的臂膀一起打斷，使刀從他手中掉落。</span>
<span className="v" id="v23" data-v="23" data-xref="以西結書 30:26; 以西結書 30:17–18; 以西結書 29:12–13"> 我要把埃及人驅散到列國，分散到列邦。</span>
<span className="v" id="v24" data-v="24" data-xref="以西結書 30:25; 西番雅書 2:12; 以賽亞書 45:5"> 我要使巴比倫王的臂膀強壯有力，把我的刀交在他手中。我要打斷法老的臂膀，使法老在他面前像受了致命傷的人一樣呻吟。</span>
<span className="v" id="v25" data-v="25" data-xref="以西結書 29:21; 以西結書 32:15; 以西結書 29:16"> 我要使巴比倫王的臂膀強壯有力，而法老的雙臂必軟弱無力。我要把我的刀交在巴比倫王手中，讓他揮刀攻擊埃及。那時他們就知道我是耶和華。</span>
<span className="v" id="v26" data-v="26" data-xref="但以理書 11:42; 以西結書 29:12; 以西結書 30:23"> 我要把埃及人驅散到列國，分散到列邦，這樣他們就知道我是耶和華。』」</span>

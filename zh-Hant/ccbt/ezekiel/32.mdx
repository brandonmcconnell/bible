## 為法老唱哀歌

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="以西結書 30:20; 以西結書 32:17; 以西結書 31:1"> 第十二年十二月一日，耶和華對我說：</span>
<span className="v" id="v2" data-v="2" data-xref="以西結書 29:3; 那鴻書 2:11–13; 以西結書 27:2"> 「人子啊，你要為埃及王法老唱哀歌，對他說，<br /><span className="pl pl-1">「『你自認為是列邦中的雄獅，</span><br /><span className="pl pl-1">其實你像激蕩江河、</span><br /><span className="pl pl-1">用腳把江河攪渾的海怪。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="以西結書 12:13; 耶利米書 16:16; 傳道書 9:12"> <span className="pl pl-1">主耶和華說：</span><br /><span className="pl pl-1">我要藉多國聯軍把我的網撒在你身上，</span><br /><span className="pl pl-1">他們要用我的網把你拉上來。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="以賽亞書 18:6; 以西結書 29:5; 以西結書 31:12–13"> <span className="pl pl-1">我要把你拋在地上，扔在田野，</span><br /><span className="pl pl-1">讓天上的飛鳥落在你身上，</span><br /><span className="pl pl-1">讓地上的走獸吞吃你。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="以西結書 31:12"> <span className="pl pl-1">我要把你的肉撒在山間，</span><br /><span className="pl pl-1">把你的屍首填滿山谷，</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="以賽亞書 34:3; 以賽亞書 34:7; 啟示錄 14:20"> <span className="pl pl-1">用你的血澆灌大地，</span><br /><span className="pl pl-1">漫過群山，溢滿溝壑。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="馬太福音 24:29; 約珥書 2:31; 以賽亞書 13:10"> <span className="pl pl-1">當我消滅你的時候，</span><br /><span className="pl pl-1">我要遮蔽天空，使星辰昏暗；</span><br /><span className="pl pl-1">我要用雲遮蔽太陽，使月亮無光。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="創世記 1:14; 箴言 20:20"> <span className="pl pl-1">我要遮蔽天上所有的光，</span><br /><span className="pl pl-1">使黑暗籠罩你的四境。</span><br /><span className="pl pl-1">這是主耶和華說的。</span></span>
<span className="v" id="v9" data-v="9" data-xref="啟示錄 18:10–15; 以西結書 30:26; 耶利米書 25:15–25"> 「『我把你滅亡的消息帶到你不認識的列國時，必使列邦惶恐不安。</span>
<span className="v" id="v10" data-v="10" data-xref="以西結書 26:16; 以西結書 27:35; 列王紀上 9:8"> 我在他們面前揮刀攻擊你的時候，各國的人都必因你而驚駭，他們的君王必膽戰心驚。在你傾覆那天，他們都必時刻為自己的性命戰戰兢兢。』</span>
<span className="v" id="v11" data-v="11" data-xref="耶利米書 43:10; 以西結書 26:7; 以西結書 30:22–25"> 「主耶和華這樣說，『巴比倫王的刀必來攻擊你。</span>
<span className="v" id="v12" data-v="12" data-xref="以西結書 28:7; 以西結書 29:19; 以西結書 31:11"> 我要使你的人民喪身在各國中最殘暴的勇士刀下。<br /><span className="pl pl-1">「『他們必摧毀埃及的驕傲，</span><br /><span className="pl pl-1">消滅她的人民。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="以西結書 29:11; 以西結書 29:8; 以西結書 30:12"> <span className="pl pl-1">我要殺盡她河邊的牲畜，</span><br /><span className="pl pl-1">使人足獸蹄不再攪渾河水。</span><br /></span>
<span className="v" id="v14" data-v="14"> <span className="pl pl-1">我要使埃及的河流清澈見底，</span><br /><span className="pl pl-1">像油一樣緩緩流淌。</span><br /><span className="pl pl-1">這是主耶和華說的。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="以西結書 6:7; 出埃及記 7:5; 出埃及記 14:4"> <span className="pl pl-1">我要使埃及的土地荒涼，</span><br /><span className="pl pl-1">毀滅其中的一切，</span><br /><span className="pl pl-1">擊殺其中的所有居民，</span><br /><span className="pl pl-1">那時他們就知道我是耶和華。</span></span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳記下 1:17; 歷代志下 35:25; 以西結書 26:17"> 「『這是列國為埃及唱的哀歌，各國的婦女要為埃及和她的人民唱這哀歌。這是主耶和華說的。』」</span>
<span className="v" id="v17" data-v="17" data-xref="以西結書 32:1; 以西結書 33:21; 以西結書 1:2"> 第十二年十二月十五日，耶和華對我說：</span>
<span className="v" id="v18" data-v="18" data-xref="以西結書 31:14; 以西結書 32:2; 耶利米書 1:10"> 「人子啊，為埃及的眾民哀哭吧！我要把她與各強國的人民一同送入陰間，與墜入墳墓的人在一起。</span>
<span className="v" id="v19" data-v="19" data-xref="以西結書 31:18; 以西結書 32:29–30; 耶利米書 9:25–26"> <span className="pl pl-1">「埃及啊，你比誰更美呢？</span><br /><span className="pl pl-1">你下去跟未受割禮的人躺在一起吧！</span></span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 28:3; 以西結書 32:23–26; 以西結書 32:29–30"> 「埃及人要倒斃在喪身刀下的人當中。刀已出鞘，她和她的國民要被拖走。</span>
<span className="v" id="v21" data-v="21" data-xref="以賽亞書 14:9–10; 以西結書 32:27; 以西結書 32:19"> 英勇的統領要在陰間談論埃及王及其盟友說，『這些喪身刀下、未受割禮的人下來長眠了。』</span>
<span className="v" id="v22" data-v="22" data-xref="以西結書 32:26; 以西結書 32:29–30; 以西結書 32:24"> 「亞述和她的大軍都在那裡，她周圍是她大軍的墳墓。他們都是喪身刀下的人。</span>
<span className="v" id="v23" data-v="23" data-xref="以西結書 26:20; 以西結書 32:24–27; 詩篇 27:13"> 他們的墳墓在陰間的最深處，她的大軍躺臥在她墳墓的周圍。他們生前曾使人恐懼，如今卻喪身刀下。</span>
<span className="v" id="v24" data-v="24" data-xref="以西結書 32:18; 以西結書 26:20; 耶利米書 49:34–39"> 以攔在那裡，她的百姓在她墳墓的周圍。他們都未受割禮，喪身刀下，下到了陰間。他們生前曾使人恐懼，如今卻和下墳墓的人一同抱愧蒙羞。</span>
<span className="v" id="v25" data-v="25" data-xref="詩篇 139:8; 歷代志上 10:4; 撒母耳記下 1:20"> 以攔躺臥在被殺的人當中，周圍是她百姓的墳墓。他們都未受割禮、喪身刀下。他們生前曾使人恐懼，如今卻和下墳墓的人一同抱愧蒙羞，躺臥在被殺的人當中。</span>
<span className="v" id="v26" data-v="26" data-xref="以西結書 27:13; 創世記 10:2; 以西結書 38:2–3"> 「米設和土巴都在那裡，周圍是她們百姓的墳墓。他們都未受割禮，生前曾使人恐懼，如今卻喪身刀下。</span>
<span className="v" id="v27" data-v="27" data-xref="以賽亞書 14:18–19; 約伯記 3:13–15; 以西結書 32:21"> 他們沒有古代<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「古代」有古卷作「未受割禮的」。">a</a></sup>勇士的榮耀葬禮，那些勇士帶著兵器下到陰間，頭枕著刀，屍骨上蓋著盾，他們生前曾使人恐懼。</span>
<span className="v" id="v28" data-v="28" data-xref="但以理書 2:34–35"> 「法老啊，你要被毀滅，跟那些未受割禮、喪身刀下的人躺在一起。</span>
<span className="v" id="v29" data-v="29" data-xref="耶利米書 49:7–22; 瑪拉基書 1:3–4; 俄巴底亞書 1:1–9"> 「以東也在那裡，她的君王和官長儘管力量強大，卻和喪身刀下的人在一起，與那些未受割禮、下墳墓的人躺在一起。</span>
<span className="v" id="v30" data-v="30" data-xref="以西結書 38:6; 以西結書 39:2; 以西結書 28:21"> 「北方的諸王和所有的西頓人也在那裡，雖然他們力量強大，令人恐懼，卻羞辱地與被殺的人下到了陰間。他們未受割禮，與喪身刀下的人躺在一起，與下墳墓的人一同蒙羞。</span>
<span className="v" id="v31" data-v="31" data-xref="以西結書 31:16; 以西結書 14:22; 耶利米哀歌 2:13"> 「法老看見他們，便為他大群喪身刀下的民眾和全軍感到欣慰。這是主耶和華說的。</span>
<span className="v" id="v32" data-v="32" data-xref="以西結書 32:27; 創世記 35:5; 哥林多後書 5:11"> 我曾使法老給世人帶來恐懼，但他和他的民眾最後還是要躺臥在未受割禮、喪身刀下的人當中。這是主耶和華說的。」</span>

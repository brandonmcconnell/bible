## 以西結的異象

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="馬太福音 3:16; 以西結書 11:24; 使徒行傳 7:56"> 第三十年四月五日，我正在迦巴魯河畔被擄的人當中，那時天開了，我看見了上帝的異象。</span>
<span className="v" id="v2" data-v="2" data-xref="列王紀下 24:12–15; 以西結書 8:1; 以西結書 20:1"> 那是約雅斤王被擄第五年的四月五日，</span>
<span className="v" id="v3" data-v="3" data-xref="以西結書 3:14; 以西結書 3:22; 列王紀下 3:15"> 就在迦勒底人境內的迦巴魯河畔，耶和華的話傳給了布西的兒子以西結祭司，耶和華的手按在他身上。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="以西結書 1:27; 以西結書 8:2; 耶利米書 23:19"> 在異象中，我看見一陣狂風從北方颳來，有一大朵雲閃耀著火光，四周環繞著燦爛的光芒，火的中心像發光的金屬。</span>
<span className="v" id="v5" data-v="5" data-xref="啟示錄 4:6–8; 以西結書 1:26; 啟示錄 6:6"> 火中有四個像人形的活物，</span>
<span className="v" id="v6" data-v="6" data-xref="以西結書 10:14; 啟示錄 4:7–8; 以西結書 1:15"> 每個活物有四張臉和四個翅膀。</span>
<span className="v" id="v7" data-v="7" data-xref="啟示錄 1:15; 但以理書 10:6; 詩篇 104:4"> 他們的腿是直的，腳如同牛犢的蹄，都亮如磨光的銅。</span>
<span className="v" id="v8" data-v="8" data-xref="以西結書 10:21; 以西結書 10:11; 以賽亞書 6:6"> 四面的翅膀下都有人的手，四個活物都有臉和翅膀，</span>
<span className="v" id="v9" data-v="9" data-xref="以西結書 10:22; 以西結書 10:11; 以西結書 1:11–12"> 翅膀彼此相連。他們移動時不必轉身，各朝前面移動。</span>
<span className="v" id="v10" data-v="10" data-xref="以西結書 10:14; 啟示錄 4:7; 哥林多前書 9:9–10"> 四個活物的臉是這樣的：正面是人的臉，右面是獅子的臉，左面是牛的臉，後面是鷹的臉。</span>
<span className="v" id="v11" data-v="11" data-xref="以賽亞書 6:2; 以西結書 1:23; 以西結書 10:19"> 他們的翅膀向上展開，每個活物的一對翅膀與兩側活物的翅膀相連，另外一對翅膀遮蔽身體。</span>
<span className="v" id="v12" data-v="12" data-xref="以西結書 1:9; 以西結書 10:22; 希伯來書 1:14"> 每個活物都往前直行，耶和華的靈往哪裡去，他們也往哪裡去，移動時不用轉身。</span>
<span className="v" id="v13" data-v="13" data-xref="啟示錄 4:5; 詩篇 104:4; 馬太福音 28:3"> 四個活物的形像如燃燒的火炭，又像火把。活物之間有火上下移動，非常明亮，從火中發出閃電。</span>
<span className="v" id="v14" data-v="14" data-xref="馬太福音 24:27; 撒迦利亞書 4:10; 馬可福音 13:27"> 這些活物像閃電一樣往來飛馳。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="但以理書 7:9; 以西結書 10:9; 以西結書 1:19–21"> 當我觀看這些活物的時候，發現每個活物旁邊的地上都有一個輪子。</span>
<span className="v" id="v16" data-v="16" data-xref="但以理書 10:6; 以西結書 10:9–11; 出埃及記 39:13"> 四個輪子的形狀和結構都一樣，好像輪套輪，如同閃耀的綠寶石。</span>
<span className="v" id="v17" data-v="17" data-xref="以西結書 1:9; 以西結書 1:12; 以賽亞書 55:11"> 他們可以向四面移動，移動時輪子不必轉向。</span>
<span className="v" id="v18" data-v="18" data-xref="以西結書 10:12; 啟示錄 4:6; 啟示錄 4:8"> 輪圈高而可畏，周圍佈滿了眼睛。</span>
<span className="v" id="v19" data-v="19" data-xref="以西結書 10:16; 以西結書 10:19; 詩篇 103:20"> 活物行走，輪子也在旁邊行走；活物上升，輪子也上升。</span>
<span className="v" id="v20" data-v="20" data-xref="以西結書 1:12; 以西結書 10:17; 哥林多前書 14:32"> 靈往哪裡去，活物也往哪裡去，輪子也跟著往哪裡去，因為活物的靈在輪子裡。</span>
<span className="v" id="v21" data-v="21" data-xref="以西結書 10:17; 以西結書 1:19–20; 羅馬書 8:2"> 活物行走，輪子也行走；活物站立不動，輪子也站立不動；活物上升，輪子也跟著上升，因為活物的靈在輪子裡。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="以西結書 10:1; 以西結書 1:26; 啟示錄 4:6"> 活物的頭上好像鋪展著茫茫的穹蒼，如同頂著耀眼的水晶。</span>
<span className="v" id="v23" data-v="23" data-xref="約伯記 4:18; 以西結書 1:11–12; 詩篇 89:7"> 穹蒼下四個活物伸展翅膀，彼此相對，各用另兩個翅膀遮蔽身體。</span>
<span className="v" id="v24" data-v="24" data-xref="以西結書 43:2; 但以理書 10:6; 啟示錄 1:15"> 他們移動時，我聽見他們翅膀發出的響聲如洪濤之聲，既像全能者的聲音，又像軍隊的吶喊。活物站住的時候，便將翅膀垂下。</span>
<span className="v" id="v25" data-v="25" data-xref="以西結書 1:22"> 他們站立垂下翅膀時，有聲音從他們頭頂的穹蒼之上傳來。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="以西結書 10:1; 出埃及記 24:10; 啟示錄 1:13"> 在他們頭頂的穹蒼之上彷彿有藍寶石的寶座，有一位形狀像人的高坐在寶座上。</span>
<span className="v" id="v27" data-v="27" data-xref="以西結書 1:4; 以西結書 8:2; 希伯來書 12:29"> 我看到祂的腰部以上好像燒紅發亮的金屬，好像有火四面環繞。腰部以下如同火焰。祂周圍有耀眼的光輝，</span>
<span className="v" id="v28" data-v="28" data-xref="啟示錄 10:1; 啟示錄 4:3; 創世記 17:3"> 彷彿雨天雲中的彩虹。<br />這是耶和華榮耀的形像。我一看見，便俯伏在地，隨後聽見有說話的聲音。</span>
</div>
</div>

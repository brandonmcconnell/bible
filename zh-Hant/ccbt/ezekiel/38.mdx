## 對歌革的預言

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華對我說：</span>
<span className="v" id="v2" data-v="2" data-xref="以西結書 39:1; 以西結書 27:13; 以西結書 38:3"> 「人子啊，你要面向瑪各地區的歌革，就是米設和土巴的首領，說預言斥責他，</span>
<span className="v" id="v3" data-v="3" data-xref="以西結書 13:8; 以西結書 39:1–10; 以西結書 29:3"> 告訴他，主耶和華這樣說，『米設和土巴的首領歌革啊，我要與你為敵。</span>
<span className="v" id="v4" data-v="4" data-xref="以西結書 29:4; 但以理書 11:40; 以西結書 38:15"> 我要把你調轉過來，用鉤子鉤住你的腮，把你和你那些全副武裝、拿著大小盾牌、揮動刀劍的軍隊、馬匹和騎兵都拖出來。</span>
<span className="v" id="v5" data-v="5" data-xref="以西結書 27:10; 創世記 10:6; 以西結書 30:5"> 你的軍隊中有拿著盾牌、戴著頭盔的波斯人、古實人和弗人，</span>
<span className="v" id="v6" data-v="6" data-xref="以西結書 27:14; 創世記 10:2–3; 歷代志上 1:5–6"> 還有歌篾及其全軍和從遙遠的北方來的陀迦瑪及其全軍。許多國家的軍隊都與你在一起。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="歷代志下 25:8; 約珥書 3:9–12; 以賽亞書 37:22"> 「『你和聚集到你那裡的聯軍都要時刻預備好，你要做他們的統帥。</span>
<span className="v" id="v8" data-v="8" data-xref="以西結書 38:16; 以賽亞書 24:22; 以西結書 38:11–12"> 再過多日，你必被徵召出戰。在以後的歲月，你將去攻打一片已從戰爭中恢復的土地，以色列久已荒涼的山上有從各國招聚回來的百姓。他們從列國中被領回來，如今都在那裡安然居住。</span>
<span className="v" id="v9" data-v="9" data-xref="以賽亞書 28:2; 耶利米書 4:13; 約珥書 2:2"> 你和你的軍隊以及各國的聯軍一起上來，如暴風來臨，又如密雲覆蓋大地。』</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="詩篇 36:4; 彌迦書 2:1; 詩篇 83:3–4"> 「『主耶和華說：那時你必心起歹念，籌劃惡謀。</span>
<span className="v" id="v11" data-v="11" data-xref="撒迦利亞書 2:4–5; 箴言 3:29–30; 耶利米書 49:31–32"> 你必說，我要攻打那沒有圍牆保護的鄉村，毀滅那毫無戒備、在無牆無門無閂之地安然居住的百姓。</span>
<span className="v" id="v12" data-v="12" data-xref="以賽亞書 10:6; 以西結書 38:8; 以西結書 29:19"> 我要搶掠他們的財物，下手攻擊那曾是廢墟的城邑和從列國歸來的百姓。他們住在世界的中心，牲畜貨物甚多。</span>
<span className="v" id="v13" data-v="13" data-xref="以西結書 27:15; 以西結書 27:22–23; 以西結書 32:2"> 示巴人、底但人以及他施的客商和首領都必問：你是來搶掠嗎？你聚集軍隊是來搶奪金銀財寶，擄掠牲畜和貨物嗎？』</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="以西結書 38:8; 撒迦利亞書 2:5; 耶利米書 23:6"> 「因此，人子啊，你要說預言告訴歌革，主耶和華這樣說，『當我的以色列子民安然居住的時候，難道你會不知道嗎？</span>
<span className="v" id="v15" data-v="15" data-xref="以西結書 39:2; 以西結書 38:6; 啟示錄 20:8"> 你召集各國聯軍，組成龐大的軍隊，騎著馬從遙遠的北方來。</span>
<span className="v" id="v16" data-v="16" data-xref="以西結書 39:21; 以西結書 38:23; 何西阿書 3:5"> 歌革啊，你必如密雲一樣遮天蔽日，前來攻擊我的以色列子民。將來，我要領你來攻擊我的土地，我要在列國面前藉著你彰顯我的聖潔，使他們認識我。』</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="但以理書 11:40–45; 以賽亞書 63:1–6; 約珥書 3:9–14"> 「主耶和華說，『歌革啊，我從前藉我的僕人——以色列的先知所預言的那位就是你，那時他們曾多年預言我要領你上來攻擊以色列。</span>
<span className="v" id="v18" data-v="18" data-xref="以西結書 36:5–6; 希伯來書 12:29; 詩篇 89:46"> 當歌革上來攻擊以色列的時候，我必發烈怒。這是主耶和華說的。</span>
<span className="v" id="v19" data-v="19" data-xref="哈該書 2:6–7; 啟示錄 11:13; 啟示錄 16:20"> 我要在義憤和烈怒中宣告，那天在以色列必有大地震。</span>
<span className="v" id="v20" data-v="20" data-xref="何西阿書 4:3; 那鴻書 1:4–6; 啟示錄 6:12–13"> 海裡的魚，空中的鳥，田野的走獸，地上的一切爬蟲和人類都要在我面前戰慄。山嶺必倒塌，懸崖必崩裂，牆垣必坍塌。</span>
<span className="v" id="v21" data-v="21" data-xref="哈該書 2:22; 士師記 7:22; 以西結書 14:17"> 我要在我的山嶺上叫刀劍攻擊歌革人，使他們自相殘殺。這是主耶和華說的。</span>
<span className="v" id="v22" data-v="22" data-xref="以賽亞書 66:16; 詩篇 11:6; 啟示錄 16:21"> 我要用瘟疫和殺戮懲罰他，將暴雨、冰雹、烈火和硫磺傾倒在他及其軍隊和隨從的列邦身上。</span>
<span className="v" id="v23" data-v="23" data-xref="詩篇 9:16; 啟示錄 19:1–6; 以西結書 38:16"> 我要彰顯我的偉大和聖潔，使列國的人都認識我。這樣他們就知道我是耶和華。』</span>
</div>
</div>

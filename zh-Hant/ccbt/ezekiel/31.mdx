## 香柏樹的比喻

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="以西結書 30:20; 耶利米書 52:5–6; 以西結書 1:2"> 第十一年三月一日，耶和華對我說：</span>
<span className="v" id="v2" data-v="2" data-xref="以西結書 29:19; 以西結書 30:10; 以西結書 31:18"> 「人子啊，你要對埃及王法老和他的百姓說，<br /><span className="pl pl-1">「『誰能比你強大呢？</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="以賽亞書 10:33–34; 但以理書 4:10; 但以理書 4:20–23"> <span className="pl pl-1">看啊，亞述曾是黎巴嫩的一棵香柏樹，</span><br /><span className="pl pl-1">枝繁葉茂，遮天蔽日，</span><br /><span className="pl pl-1">高聳入雲。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="啟示錄 17:15; 箴言 14:28; 以西結書 17:5"> <span className="pl pl-1">水源滋潤它，</span><br /><span className="pl pl-1">深泉使它茁壯成長，</span><br /><span className="pl pl-1">溪流四圍環繞它，</span><br /><span className="pl pl-1">澆灌著林間的樹木。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="但以理書 4:11; 以西結書 17:5; 詩篇 1:3"> <span className="pl pl-1">豐沛的水源使它高過田間所有的樹木，</span><br /><span className="pl pl-1">枝子長得又粗又長。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="以西結書 17:23; 馬太福音 13:32; 但以理書 4:12"> <span className="pl pl-1">空中的飛鳥都在它的枝頭上搭窩，</span><br /><span className="pl pl-1">田間的野獸都在它的枝條下生產，</span><br /><span className="pl pl-1">所有的大國都住在它的蔭下。</span><br /></span>
<span className="v" id="v7" data-v="7"> <span className="pl pl-1">它高大美麗，枝幹修長，</span><br /><span className="pl pl-1">因為樹根深入豐沛的水源，</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="以西結書 28:13; 創世記 13:10; 以賽亞書 51:3"> <span className="pl pl-1">連上帝園中的香柏樹也不能與它相比。</span><br /><span className="pl pl-1">松樹不能與它的枝幹相比，</span><br /><span className="pl pl-1">楓樹不能與它的枝條相比，</span><br /><span className="pl pl-1">上帝園中的樹木沒有一棵能與它媲美。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="以西結書 28:13; 但以理書 2:37–38; 創世記 13:10"> <span className="pl pl-1">我使它枝繁葉茂，美麗無比，</span><br /><span className="pl pl-1">以致上帝伊甸園裡的樹木都羡慕它。』</span></span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="以西結書 28:17; 但以理書 5:20; 歷代志下 32:25"> 「因此，主耶和華說，『因為它樹幹高大，樹梢高聳入雲，心高氣傲，</span>
<span className="v" id="v11" data-v="11" data-xref="以西結書 32:11–12; 那鴻書 3:18; 但以理書 5:18–19"> 我要把它交在列國的首領手裡，他必按照它的邪惡懲治它。我丟棄了它。</span>
<span className="v" id="v12" data-v="12" data-xref="以西結書 28:7; 以西結書 35:8; 以西結書 30:11"> 列邦中最殘暴的人要把它砍倒，丟棄在那裡，它折斷的枝幹散落在山間和河谷中。世上各族都離開它的蔭下，棄他而去，</span>
<span className="v" id="v13" data-v="13" data-xref="以西結書 32:4; 以西結書 29:5; 以賽亞書 18:6"> 天上的飛禽要棲身在那折斷的樹幹上，地上的走獸要躺臥在它的枝條中。</span>
<span className="v" id="v14" data-v="14" data-xref="詩篇 63:9–10; 尼希米記 13:18; 彼得後書 2:6"> 故此，水邊的樹木都不再傲然矗立，高聳入雲，水源充足的大樹也不再如此高大，因為它們都註定要與下墳墓的人一同死亡，落到陰間的深處。』</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="瑪拉基書 3:4; 那鴻書 2:8–10; 啟示錄 18:9–11"> 「主耶和華說，『它下到陰間的那天，我要使哀聲響起，使深淵閉塞，江河止息，洪水停滯。我要使黎巴嫩為它哀哭，田野的樹木都因它而枯萎。</span>
<span className="v" id="v16" data-v="16" data-xref="以賽亞書 14:15; 以賽亞書 14:8; 以西結書 26:15"> 我將它與下墳墓的人一同拋到陰間時，列國聽見它墜落的響聲，都恐懼顫抖。伊甸園中的樹木和黎巴嫩水源充足的上好樹木都在陰間得到安慰。</span>
<span className="v" id="v17" data-v="17" data-xref="詩篇 9:17; 以西結書 31:6; 以西結書 31:3"> 列國中活在它蔭庇下的爪牙都與它一同墜入陰間，到喪身刀下的人那裡。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="以西結書 32:19; 以西結書 32:21; 以西結書 28:10"> 「『伊甸園的樹木中，誰能與你的威榮相比呢？然而你必與伊甸園的樹木一同下到陰間，躺臥在未受割禮的人當中，與喪身刀下的人在一起。<br />「『這就是法老和他百姓的結局。這是主耶和華說的。』」</span>
</div>

## 耶路撒冷被困的預兆

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="何西阿書 1:2–9; 阿摩司書 3:2; 以西結書 12:3–16"> 「人子啊，你去拿一塊磚放在自己面前，把耶路撒冷城畫在上面。</span>
<span className="v" id="v2" data-v="2" data-xref="以西結書 21:22; 耶利米書 6:6; 路加福音 19:42–44"> 然後圍困這城，建壘築臺，紮營圍攻，四面架起撞城錘。</span>
<span className="v" id="v3" data-v="3" data-xref="以西結書 12:6; 以賽亞書 8:18; 以賽亞書 20:3"> 拿一個鐵盤當作鐵牆放在你和城中間。你要面向這城，圍困攻擊這城。這是給以色列人的一個徵兆。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="利未記 16:22; 利未記 10:17; 民數記 18:1"> 「你要向左側臥，擔當以色列人的罪惡。要用你向左側臥的天數擔當以色列人的罪惡。</span>
<span className="v" id="v5" data-v="5" data-xref="民數記 14:34; 以賽亞書 53:6"> 他們犯罪多少年，我要讓你側臥多少天。你要擔當以色列人的罪惡三百九十天。</span>
<span className="v" id="v6" data-v="6" data-xref="民數記 14:34; 但以理書 12:11–12; 但以理書 9:24–26"> 然後，你再向右側臥，擔當猶大的罪惡四十天。你側臥的天數代表他們犯罪的年數。</span>
<span className="v" id="v7" data-v="7" data-xref="以賽亞書 52:10; 以西結書 21:2; 以西結書 6:2"> 你要面向被圍困的耶路撒冷，光著臂膀說預言斥責這城。</span>
<span className="v" id="v8" data-v="8" data-xref="以西結書 3:25"> 我要用繩索捆綁你，使你不能翻身，直到你圍城的日子期滿。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="以西結書 4:13; 以賽亞書 28:25; 以西結書 4:16"> 「你要拿小麥、大麥、豆、扁豆、小米和粗麥，裝在一個器皿中用來為自己做餅。你在三百九十天側臥期間要吃這餅。</span>
<span className="v" id="v10" data-v="10" data-xref="利未記 26:26; 以西結書 45:12; 申命記 28:51–68"> 你每天要按時按量吃二百克，</span>
<span className="v" id="v11" data-v="11" data-xref="以賽亞書 5:13; 約翰福音 3:34; 以西結書 4:16"> 每天要按時按量喝六百毫升水。</span>
<span className="v" id="v12" data-v="12" data-xref="以賽亞書 36:12; 創世記 18:6"> 你要像吃大麥餅一樣吃這些餅，要在眾人面前用人糞來烤餅。」</span>
<span className="v" id="v13" data-v="13" data-xref="但以理書 1:8; 何西阿書 9:3–4"> 耶和華說：「我把以色列人驅逐到各國的時候，他們也要這樣在那裡吃不潔淨的食物。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="使徒行傳 10:14; 以西結書 20:49; 以西結書 9:8"> 我說：「唉，主耶和華啊！我從來沒有玷污過自己，我自幼至今從未吃過自然死去的或被野獸撕碎的動物，不潔淨的肉從未入過我的口。」</span>
<span className="v" id="v15" data-v="15"> 於是祂對我說：「好吧，我容許你用牛糞代替人糞來烤餅。」</span>
<span className="v" id="v16" data-v="16" data-xref="以西結書 5:16; 以賽亞書 3:1; 利未記 26:26"> 祂又說：「人子啊，我要斷絕耶路撒冷的糧源，叫他們懷著焦慮限量吃餅，懷著恐懼限量喝水。</span>
<span className="v" id="v17" data-v="17" data-xref="以西結書 24:23; 利未記 26:39; 以西結書 33:10"> 他們必缺糧少水，絕望地面面相覷，因自己的罪惡而滅亡。」</span>
</div>
</div>

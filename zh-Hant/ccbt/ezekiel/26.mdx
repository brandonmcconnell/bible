## 預言泰爾遭審判

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西結書 20:1; 以西結書 1:2; 耶利米書 39:2"> 第十一年十一月一日，耶和華對我說：</span>
<span className="v" id="v2" data-v="2" data-xref="以賽亞書 23:1–18; 以西結書 36:2; 約珥書 3:4"> 「人子啊，泰爾譏笑耶路撒冷說，『哈哈！那通往列國的門戶已遭破壞，城門向我大開，她已荒涼，我必興盛。』</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米書 51:42; 以賽亞書 5:30; 彌迦書 4:11"> 所以主耶和華說，『泰爾啊，我要跟你作對，我要激起多國來攻擊你，就像大海掀起波浪一樣。</span>
<span className="v" id="v4" data-v="4" data-xref="以賽亞書 23:11; 阿摩司書 1:10; 以西結書 26:9"> 他們要破壞你的牆垣，拆毀你的城樓。我要鏟淨你的瓦礫，使你成為光禿禿的磐石。</span>
<span className="v" id="v5" data-v="5" data-xref="以西結書 29:19; 以西結書 27:32; 以西結書 25:7"> 你必在海中做曬網的地方，因為我已經宣告，這是主耶和華說的。你必被列國擄掠，</span>
<span className="v" id="v6" data-v="6" data-xref="以西結書 16:46; 以西結書 26:8; 耶利米書 49:2"> 你陸地上的居民必死於刀下，這樣你就知道我是耶和華。』</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="以斯拉記 7:12; 但以理書 2:37; 以西結書 23:24"> 「主耶和華說，『我要使那王中之王的巴比倫王尼布甲尼撒率領大隊人馬、戰車和騎兵從北方來攻打泰爾。</span>
<span className="v" id="v8" data-v="8" data-xref="以西結書 21:22; 耶利米書 52:4; 耶利米書 32:24"> 他必用刀劍殺戮你陸地上的居民，建壘築臺圍困你，舉著盾牌攻擊你。</span>
<span className="v" id="v9" data-v="9" data-xref="歷代志下 26:15"> 他必用撞城錘擊破你的城牆，用鐵錘搗毀你的城樓。</span>
<span className="v" id="v10" data-v="10" data-xref="以西結書 26:15; 以西結書 27:28; 耶利米書 47:3"> 他人馬眾多，揚起的塵土足以遮蓋你。他要像攻破城池一樣進入你的城門，他的騎兵、軍需車和戰車的響聲要震動你的城牆。</span>
<span className="v" id="v11" data-v="11" data-xref="以賽亞書 5:28; 以賽亞書 26:5; 哈巴谷書 1:8"> 他戰馬的鐵蹄必踏遍你的街道。他必揮刀屠殺你的居民，推倒你堅固的神柱，</span>
<span className="v" id="v12" data-v="12" data-xref="以賽亞書 23:8; 歷代志下 32:27; 撒迦利亞書 9:3–4"> 掠奪你的財富，洗劫你的貨物，摧毀你的城牆，夷平你華麗的房屋，把你的石頭、木頭和瓦礫拋到海裡。</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米書 7:34; 以賽亞書 23:16; 以賽亞書 14:11"> 我必使你的歌聲消逝，琴音斷絕。</span>
<span className="v" id="v14" data-v="14" data-xref="瑪拉基書 1:4; 約伯記 12:14; 民數記 23:19"> 我要使你成為光禿禿的磐石，做曬網的地方，你必不得重建，因為我耶和華已經宣告。這是主耶和華說的。』</span>
</div>
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="以西結書 27:35; 耶利米書 49:21; 以西結書 26:18"> 「主耶和華對泰爾這樣說，『你傾覆的聲音，伴隨著你裡面的殺戮聲和受傷之人的慘叫聲豈不震動沿海地區嗎？</span>
<span className="v" id="v16" data-v="16" data-xref="以西結書 32:10; 約拿書 3:6; 約伯記 8:22"> 沿海諸王都嚇得渾身發抖，從寶座上下來，除去王袍，脫掉錦衣，坐在地上抖個不停，因你而驚懼不已。</span>
<span className="v" id="v17" data-v="17" data-xref="以賽亞書 14:12; 以西結書 19:1; 撒母耳記下 1:25–27"> 他們必為你唱哀歌說，<br /><span className="pl pl-1">「『赫赫名城啊，你曾是海上眾民的居所，</span><br /><span className="pl pl-1">向來稱雄海上，威震鄰邦，</span><br /><span className="pl pl-1">現在怎麼被毀滅了呢？</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="以西結書 26:15; 以賽亞書 23:5–7; 以西結書 27:35"> <span className="pl pl-1">你傾覆的日子，</span><br /><span className="pl pl-1">沿海各國都戰戰兢兢，</span><br /><span className="pl pl-1">眾海島看見你被毀滅，</span><br /><span className="pl pl-1">都心驚膽戰。』</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="以賽亞書 8:7–8; 以西結書 26:3; 但以理書 11:40"> 「主耶和華說，『我要使你成為荒無人煙的城邑，我要使海水上升淹沒你。</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 27:13; 路加福音 10:15; 撒迦利亞書 2:8"> 那時，我要使你與那些墮入陰間的人一同下到作古之人那裡，使你與那些墮入陰間的人一同住在大地深處久已荒涼的地方，好讓你荒無人煙，在活人之地毫無尊榮。</span>
<span className="v" id="v21" data-v="21" data-xref="以西結書 27:36; 以西結書 28:19; 啟示錄 18:21"> 我要使你遭受可怕的災難，你便不復存在，就是有人尋找你，也永遠找不到，這是主耶和華說的。』」</span>
</div>

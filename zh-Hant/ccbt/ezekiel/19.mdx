## 以色列的哀歌

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="以西結書 27:2; 以西結書 26:17; 列王紀下 24:6"> 「你要為以色列的首領唱哀歌，</span>
<span className="v" id="v2" data-v="2" data-xref="撒迦利亞書 11:3; 以賽亞書 5:29; 約伯記 4:11"> 說，<br /><span className="pl pl-1">「『你的母親像什麼？</span><br /><span className="pl pl-1">她就像獅群中的母獅，</span><br /><span className="pl pl-1">臥在雄壯的獅子中養育幼獅。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="以西結書 22:25; 列王紀下 23:31–32; 歷代志下 36:1–2"> <span className="pl pl-1">母獅養大一頭幼獅，</span><br /><span className="pl pl-1">使牠成為一頭猛獅。</span><br /><span className="pl pl-1">牠學會了捕獵和吃人。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="歷代志下 36:4; 列王紀下 23:33–34; 歷代志下 36:6"> <span className="pl pl-1">列國的人知道後，</span><br /><span className="pl pl-1">便設陷阱捉住牠，</span><br /><span className="pl pl-1">用鉤子拉到埃及。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="以西結書 19:3; 列王紀下 23:34–37"> <span className="pl pl-1">母獅盼著牠回來，</span><br /><span className="pl pl-1">眼見指望落空，</span><br /><span className="pl pl-1">便又養育一頭幼獅，</span><br /><span className="pl pl-1">使牠成為一頭猛獅。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="歷代志下 36:5; 歷代志下 36:9; 耶利米書 26:1–24"> <span className="pl pl-1">牠出入獅群，</span><br /><span className="pl pl-1">長成一頭猛獅，</span><br /><span className="pl pl-1">學會了捕食和吃人。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="以西結書 30:12; 以西結書 12:19; 彌迦書 1:2"> <span className="pl pl-1">牠夷平列國的堡壘，</span><br /><span className="pl pl-1">使他們的城邑淪為廢墟，</span><br /><span className="pl pl-1">遍地都因牠的咆哮而震驚。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="耶利米哀歌 4:20; 以西結書 19:4; 以西結書 12:13"> <span className="pl pl-1">於是，列國便從四面圍攻牠，</span><br /><span className="pl pl-1">設網羅捕捉牠。</span><br /><span className="pl pl-1">牠落入他們的陷阱。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="歷代志下 36:6; 以西結書 6:2; 耶利米書 36:30–31"> <span className="pl pl-1">他們用鉤子鉤住牠，把牠關進籠裡，</span><br /><span className="pl pl-1">解送到巴比倫王那裡囚禁起來。</span><br /><span className="pl pl-1">於是，在以色列的山嶺上再也聽不見牠的吼聲。</span></span>
</div>
<div className="bp poetry">

<span className="v" id="v11" data-v="11" data-xref="以西結書 31:3; 詩篇 80:15; 但以理書 4:11"> <span className="pl pl-1">它的枝子粗壯，可作王的杖。</span><br /><span className="pl pl-1">它的樹幹高大，直插雲霄，</span><br /><span className="pl pl-1">枝葉茂密，遠遠可見。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="以西結書 17:10; 何西阿書 13:15; 以賽亞書 27:11"> <span className="pl pl-1">但它被憤怒地連根拔起，</span><br /><span className="pl pl-1">拋在地上。</span><br /><span className="pl pl-1">東風吹乾了它的果實，</span><br /><span className="pl pl-1">粗壯的枝幹折斷枯乾，</span><br /><span className="pl pl-1">被火焚燒。</span><br /></span>

<span className="v" id="v14" data-v="14" data-xref="詩篇 80:15–16; 以西結書 19:11; 列王紀下 24:20"> <span className="pl pl-1">火從枝幹蔓延，</span><br /><span className="pl pl-1">燒毀了它的果實，</span><br /><span className="pl pl-1">沒有留下一根粗壯的枝幹可作王的杖。』</span><br /><span className="pl pl-1">「這是一首哀歌，可作哀悼之用。」</span></span>

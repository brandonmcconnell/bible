## 以色列的牧人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華對我說：</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米書 23:1; 耶利米書 3:15; 以賽亞書 40:11"> 「人子啊，你要這樣說預言斥責以色列的牧人，『主耶和華說：以色列的牧人啊，你們有禍了！你們只顧餵養自己，牧人豈不應該餵養羊群嗎？</span>
<span className="v" id="v3" data-v="3" data-xref="撒迦利亞書 11:16; 耶利米書 2:30; 以西結書 33:25–26"> 但你們只顧吃羊的脂肪，穿羊毛衣，宰殺肥羊，卻不餵養羊群。</span>
<span className="v" id="v4" data-v="4" data-xref="馬太福音 18:12–13; 馬太福音 9:36; 以西結書 34:16"> 你們沒有養壯瘦弱的，沒有醫治生病的，沒有包紮受傷的，沒有領回走散的，沒有尋找迷失的。你們反用暴力轄製他們。</span>
<span className="v" id="v5" data-v="5" data-xref="馬太福音 9:36; 歷代志下 18:16; 耶利米書 23:2"> 因為沒有牧人，羊群便流離失散，成了所有野獸的食物。</span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 142:4; 彼得前書 2:25; 約翰福音 10:16"> 我的羊在群山和高崗上遊蕩，分散在各地，沒有人尋找他們。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="耶利米書 22:2–3; 彌迦書 3:8–9; 詩篇 82:1–7"> 「『所以，你們這些牧人啊，要聽耶和華的話。</span>
<span className="v" id="v8" data-v="8" data-xref="彼得後書 2:13; 使徒行傳 20:33; 以西結書 34:5–6"> 主耶和華說：我憑我的永恆起誓，我的羊因為沒有牧人而成了獵物，淪為所有野獸的食物。我的牧人不去尋找我的羊，他們只餵養自己，不餵養我的羊，</span>
<span className="v" id="v9" data-v="9"> 所以你們這些牧人啊，要聽耶和華的話。</span>
<span className="v" id="v10" data-v="10" data-xref="以西結書 34:2; 撒迦利亞書 10:3; 以西結書 13:8"> 主耶和華說：我要攻擊這些牧人，從他們手中要回我的羊，不再讓他們餵養羊群，使他們無法再餵養自己。我要從他們口中救回我的羊，不再讓羊成為他們的食物。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="約翰福音 10:16; 路加福音 19:10; 耶利米書 23:3"> 「『主耶和華說：看啊，我要親自尋找我的羊，找到他們。</span>
<span className="v" id="v12" data-v="12" data-xref="以賽亞書 40:11; 約翰福音 10:11–12; 路加福音 19:10"> 牧人怎樣尋找他四散的羊，我也照樣尋找我的羊，他們在密雲幽暗的日子失散到各地，我要把他們從那裡救回來。</span>
<span className="v" id="v13" data-v="13" data-xref="以西結書 28:25–26; 以西結書 11:17; 以賽亞書 11:11–16"> 我要把他們從列邦領出來，從列國招聚他們，帶他們回到自己的故土，我要在以色列的山嶺上、溪水旁和境內可居之地牧養他們。</span>
<span className="v" id="v14" data-v="14" data-xref="約翰福音 10:9; 耶利米書 31:25; 詩篇 31:8–10"> 我要在佳美的草場上牧養他們，以色列的山嶺必成為他們的草場。他們要在佳美的草場上安臥，在以色列山嶺的肥美草場上吃草。</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米書 3:15; 詩篇 23:1–2; 約翰福音 21:15"> 我要親自餵養我的羊，讓他們得到安歇。這是主耶和華說的。</span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 19:10; 以西結書 34:4; 以西結書 34:11"> 我要尋找迷失的，領回失散的，包紮受傷的，醫治患病的，但我要消滅肥壯的。我要秉公牧養他們。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="以西結書 34:20–22; 馬太福音 25:32–33; 撒迦利亞書 10:3"> 「『我的羊群啊！至於你們，主耶和華這樣說：我要在你們中間施行審判，在公綿羊和公山羊之間進行審判。</span>
<span className="v" id="v18" data-v="18" data-xref="馬太福音 23:13; 路加福音 11:52; 民數記 16:13"> 你們肥壯的羊在茂盛的草場上吃還不夠嗎？你們非要用蹄子踐踏吃剩的草嗎？你們喝清水還不夠嗎？你們非要用蹄子攪渾剩下的水嗎？</span>
<span className="v" id="v19" data-v="19"> 我其餘的羊只得吃你們踐踏的草，喝你們攪渾的水。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="馬太福音 25:31–46; 以西結書 34:10; 詩篇 22:12–16"> 「『因此，主耶和華對他們說：看啊，我要親自在肥羊和瘦羊之間施行審判。</span>
<span className="v" id="v21" data-v="21" data-xref="撒迦利亞書 11:5; 申命記 33:17; 路加福音 13:14–16"> 你們肥羊用脅和肩拱，用角牴瘦弱的，使他們四散。</span>
<span className="v" id="v22" data-v="22" data-xref="耶利米書 23:2–3; 詩篇 72:12–14; 以西結書 34:10"> 因此我要拯救我的羊，使他們不再成為獵物，我要在羊與羊之間施行審判。</span>
<span className="v" id="v23" data-v="23" data-xref="以西結書 37:24–25; 耶利米書 30:9; 以賽亞書 40:11"> 我要立我的僕人大衛做他們的牧人，他將牧養他們，做他們的牧人。</span>
<span className="v" id="v24" data-v="24" data-xref="耶利米書 31:33; 以西結書 36:28; 耶利米書 23:5–6"> 我耶和華要做他們的上帝，我的僕人大衛要在他們當中做王，這是耶和華說的。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="以賽亞書 11:6–9; 以西結書 37:26; 利未記 26:6"> 「『我要跟他們立平安的約，除去地上的惡獸，讓他們在曠野安居，在叢林安睡。</span>
<span className="v" id="v26" data-v="26" data-xref="申命記 28:12; 以賽亞書 44:3; 利未記 26:4"> 我要賜福他們，也要賜福我聖山的周圍，我要按季節降雨給他們，使恩福如雨降下。</span>
<span className="v" id="v27" data-v="27" data-xref="耶利米書 30:8; 利未記 26:4; 利未記 26:13"> 田間的樹木必結果子，土地必長出莊稼，他們要在故鄉安居。我要折斷他們所負的軛，從奴役他們的人手中把他們拯救出來，那時他們便知道我是耶和華。</span>
<span className="v" id="v28" data-v="28" data-xref="耶利米書 46:27; 耶利米書 30:10; 以西結書 39:26"> 他們必不再成為列國的獵物，也不會被地上的野獸吞吃。他們必安居樂業，不再受人驚嚇。</span>
<span className="v" id="v29" data-v="29" data-xref="以西結書 36:29; 以賽亞書 4:2; 以西結書 34:26–27"> 我要把沃土賜給他們，使他們不再被境內的饑荒吞噬，也不再受各國的侮辱。</span>
<span className="v" id="v30" data-v="30" data-xref="以西結書 37:27; 以西結書 34:24; 詩篇 46:11"> 這樣，以色列人就知道我耶和華——他們的上帝與他們同在，他們以色列人是我的子民，這是主耶和華說的。</span>
<span className="v" id="v31" data-v="31" data-xref="詩篇 100:3; 約翰福音 10:16; 詩篇 78:52"> 你們是我草場上的羊，你們是我的子民，我是你們的上帝。這是主耶和華說的。』」</span>
</div>
</div>

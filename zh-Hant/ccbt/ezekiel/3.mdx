<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="啟示錄 10:9–10; 以西結書 3:17–21; 以西結書 2:8–9"> 祂對我說：「人子啊，要把你得到的吃下去，要吃下這書卷，然後去向以色列人傳講。」</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米書 25:17; 使徒行傳 26:19"> 我張開口，祂就給我吃那書卷，</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米書 15:16; 啟示錄 10:9–10; 詩篇 119:103"> 並對我說：「人子啊，吃下我賜你的這書卷，讓它充滿你的肚腹。」我便吃了，書卷在我嘴裡甘甜如蜜。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="馬太福音 10:5–6; 使徒行傳 1:8; 以西結書 2:3"> 祂又對我說：「人子啊，現在你要到以色列人那裡，把我的話傳給他們。</span>
<span className="v" id="v5" data-v="5" data-xref="約拿書 1:2; 以賽亞書 33:19; 約拿書 3:2–4"> 你不是奉命去語言陌生、難懂的民族那裡，而是到以色列人當中。</span>
<span className="v" id="v6" data-v="6" data-xref="馬太福音 11:20–24; 羅馬書 9:30–33; 約拿書 3:5–10"> 我不是派你到那些語言陌生、艱澀難懂的民族中。我若果真派你到他們那裡，他們一定會聽你的話。</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 10:16; 以西結書 2:4; 撒母耳記上 8:7"> 然而以色列人卻不肯聽從你，因為他們額頭剛硬，心裡頑固，不肯聽從我。</span>
<span className="v" id="v8" data-v="8" data-xref="耶利米書 1:18; 使徒行傳 7:51–56; 彌迦書 3:8"> 不過，我要使你的臉像他們的臉一樣剛硬，使你的額頭像他們的額頭一樣剛硬。</span>
<span className="v" id="v9" data-v="9" data-xref="以西結書 2:6; 耶利米書 1:8; 以賽亞書 50:7"> 我要使你的額頭比火石更硬，如同金剛石。他們雖然是一群叛逆的人，你不要害怕，也不要因為他們的臉色而驚慌。」</span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 119:11; 約伯記 22:22; 以西結書 3:1–3"> 祂又說：「人子啊，你要留心聽我說的一切話，牢記在心。</span>
<span className="v" id="v11" data-v="11" data-xref="以西結書 2:7; 以西結書 3:27; 以西結書 33:30"> 你要到你那些被擄的同胞那裡，不論他們聽不聽，你都要向他們宣告，『主耶和華這樣說。』」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="以西結書 8:3; 使徒行傳 8:39; 以西結書 11:1"> 那時，耶和華的靈把我舉起，我聽見後面有隆隆的聲音說：「耶和華的榮耀在祂所在之地當受稱頌！」</span>
<span className="v" id="v13" data-v="13" data-xref="以西結書 1:24; 以西結書 10:16–17; 以西結書 10:5"> 我聽見活物的翅膀相碰的聲音，以及他們旁邊的輪子發出的隆隆聲。</span>
<span className="v" id="v14" data-v="14" data-xref="以西結書 37:1; 耶利米書 20:7–9; 列王紀下 3:15"> 耶和華的靈把我舉起帶走了。我心裡苦悶，充滿憤怒，耶和華大能的手按在我身上。</span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 137:1; 約伯記 2:13; 創世記 50:10"> 我來到住在提勒·亞畢的被擄的人中，他們在迦巴魯河邊。我感到無比震驚，在他們中間坐了七天。</span>
</div>
</div>

## 告誡以色列人

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="耶利米書 42:7"> 過了七天，耶和華對我說：</span>
<span className="v" id="v17" data-v="17" data-xref="以賽亞書 52:8; 希伯來書 13:17; 歷代志下 19:10"> 「人子啊，我立你為以色列人的守望者，你要聽我口中的話並替我告誡他們。</span>
<span className="v" id="v18" data-v="18" data-xref="以西結書 33:6; 雅各書 5:19–20; 以西結書 3:20"> 如果我說惡人必定死，你卻不告誡他，勸誡他改邪歸正，好保全性命，他必因自己的罪而死，我卻要向你追討他的血債。</span>
<span className="v" id="v19" data-v="19" data-xref="以西結書 33:9; 以西結書 14:20; 提摩太前書 4:16"> 如果你告誡惡人，他卻不肯改邪歸正、停止作惡，他必因自己的罪而死，而你必保全性命。</span>
<span className="v" id="v20" data-v="20" data-xref="以西結書 18:24; 以西結書 18:26; 以西結書 33:12–13"> 如果一個義人偏離正道、犯罪作惡，我會使他絆倒，他必死亡。如果你不告誡他，他必死在罪惡之中，他以前的義行也不會被記念，而我要追究你的責任。</span>
<span className="v" id="v21" data-v="21" data-xref="提摩太前書 4:16; 箴言 9:9; 提多書 2:15"> 如果你告誡他不要犯罪，他聽了你的告誡不再犯罪，他必存活，你也必保住性命。」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="使徒行傳 9:6; 以西結書 37:1; 以西結書 8:4"> 在那裡，耶和華的手按在我身上，對我說：「你起來前往平原，我要在那裡對你說話。」</span>
<span className="v" id="v23" data-v="23" data-xref="以西結書 1:28; 使徒行傳 7:55; 啟示錄 1:17"> 我就起來，到了平原，看見耶和華的榮耀停在那裡，那榮耀和我在迦巴魯河邊所見的一樣，我就俯伏在地。</span>
<span className="v" id="v24" data-v="24" data-xref="以西結書 2:2; 但以理書 10:19; 但以理書 10:8–10"> 這時耶和華的靈進入我裡面，使我站立起來。耶和華對我說：「你要把自己關在房子裡。</span>
<span className="v" id="v25" data-v="25" data-xref="以西結書 4:8; 使徒行傳 9:16; 馬可福音 3:21"> 人子啊，他們必把你捆綁起來，使你不能到百姓當中。</span>
<span className="v" id="v26" data-v="26" data-xref="以西結書 24:27; 彌迦書 3:6–7; 阿摩司書 8:11–12"> 同時，我要使你的舌頭緊貼上膛，使你不能開口責備他們，因為他們是一群叛逆的人。</span>
<span className="v" id="v27" data-v="27" data-xref="以西結書 12:2–3; 以西結書 24:27; 以西結書 3:11"> 但當我對你說話的時候，我必開啟你的口，你要向他們宣告，『主耶和華這樣說。』肯聽的就讓他聽，不肯聽的就由他不聽，因為他們是一群叛逆的人。」</span>
</div>
</div>

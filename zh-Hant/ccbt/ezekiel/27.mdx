## 為泰爾唱哀歌

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1"> 耶和華對我說：</span>
<span className="v" id="v2" data-v="2" data-xref="以西結書 19:1; 耶利米書 9:10; 以西結書 28:12"> 「人子啊，你要為泰爾唱哀歌，</span>
<span className="v" id="v3" data-v="3" data-xref="以西結書 27:4; 以賽亞書 23:11; 以賽亞書 23:2–3"> 告訴位於海口、跟沿海各民族通商的泰爾，主耶和華這樣說，<br /><span className="pl pl-1">「『泰爾啊，</span><br /><span className="pl pl-1">你曾誇耀自己完美無瑕。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="以西結書 26:5"> <span className="pl pl-1">你的疆域在大海上，</span><br /><span className="pl pl-1">你的建造者把你造得完美無瑕。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="申命記 3:9; 以賽亞書 14:8; 雅歌 4:8"> <span className="pl pl-1">他們用示尼珥的松木做你的船板，</span><br /><span className="pl pl-1">用黎巴嫩的香柏木做桅桿，</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="創世記 10:4; 以賽亞書 2:13; 撒迦利亞書 11:2"> <span className="pl pl-1">用巴珊的橡木做你的槳，</span><br /><span className="pl pl-1">把象牙鑲嵌在基提沿岸的黃楊木上做甲板，</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="耶利米書 10:9; 出埃及記 25:4; 創世記 10:4"> <span className="pl pl-1">用埃及來的繡花細麻布做你的帆，</span><br /><span className="pl pl-1">作為你的旗號，</span><br /><span className="pl pl-1">用以利沙島來的藍布和紫布做船篷。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="創世記 10:18; 列王紀上 9:27; 以西結書 27:11"> <span className="pl pl-1">西頓和亞發的居民是你的船夫，</span><br /><span className="pl pl-1">你的智者在船上為你掌舵。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="列王紀上 5:18; 約書亞記 13:5; 詩篇 83:7"> <span className="pl pl-1">迦巴勒的老手和巧匠在船上為你修補船篷，</span><br /><span className="pl pl-1">所有海船和水手都來與你做生意。</span></span>
<span className="v" id="v10" data-v="10" data-xref="以西結書 38:5; 以西結書 30:5; 以賽亞書 66:19"> 「『你軍隊中的戰士有波斯人、路德人、弗人，他們在你的牆上掛起盾牌和頭盔，展示你的光彩。</span>
<span className="v" id="v11" data-v="11" data-xref="以西結書 27:3–4"> 亞發人和你的軍隊都守衛在你的城牆上，歌瑪底人把守你的城樓，他們在你四圍的牆上掛滿盾牌，使你完美無瑕。</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 10:4; 以賽亞書 23:10; 以西結書 38:13"> 「『他施人因你有豐富的貨物，就拿銀、鐵、錫、鉛來跟你交易。</span>
<span className="v" id="v13" data-v="13" data-xref="創世記 10:2; 以賽亞書 66:19; 以西結書 39:1"> 雅完人、土巴人、米設人也跟你通商，用奴隸和銅器來換取你的貨物。</span>
<span className="v" id="v14" data-v="14" data-xref="創世記 10:3; 以西結書 38:6; 歷代志上 1:6"> 陀迦瑪人用馬匹、戰馬和騾子來跟你交易。</span>
<span className="v" id="v15" data-v="15" data-xref="創世記 10:7; 啟示錄 18:12; 列王紀上 10:22"> 底但人也是你的客商，你的市場遠及沿海一帶，他們拿象牙、烏木來跟你交易。</span>
<span className="v" id="v16" data-v="16" data-xref="士師記 10:6; 以西結書 28:13; 撒母耳記下 10:6"> 因為你的貨物豐富，亞蘭人也成了你的客戶，他們用綠寶石、紫布、刺繡、細麻布、珊瑚和紅寶石與你交換貨物。</span>
<span className="v" id="v17" data-v="17" data-xref="士師記 11:33; 列王紀上 5:9; 耶利米書 8:22"> 猶大和以色列也是你的客商，他們用米匿的麥、餅、蜜、油和香料與你交換貨物。</span>
<span className="v" id="v18" data-v="18" data-xref="以賽亞書 7:8; 創世記 15:2; 以西結書 47:16–18"> 大馬士革見你的貨物豐富，就用黑本的酒和沙哈的羊毛來跟你交易。</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及記 30:23–24; 詩篇 45:8; 雅歌 4:13–14"> 從烏薩來的威但人和雅完人用熟鐵、肉桂、菖蒲與你交換貨物。</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 25:3; 以西結書 27:15"> 底但人用馬鞍墊來跟你交易。</span>
<span className="v" id="v21" data-v="21" data-xref="以賽亞書 60:7; 創世記 25:13; 列王紀上 10:15"> 阿拉伯人和基達的所有首領都來做你的客商，他們用羊羔、綿羊和山羊來跟你交易。</span>
<span className="v" id="v22" data-v="22" data-xref="創世記 10:7; 以賽亞書 60:6; 詩篇 72:10"> 示巴和拉瑪的商人用各類上等香料、寶石和黃金交換你的貨物。</span>
<span className="v" id="v23" data-v="23" data-xref="列王紀下 19:12; 以賽亞書 37:12; 阿摩司書 1:5"> 哈蘭、干尼、伊甸、示巴、亞述和基抹的商人都來跟你交易，</span>
<span className="v" id="v24" data-v="24" data-xref="列王紀下 2:8"> 他們把華麗衣服、藍布、刺繡和彩色地毯捆紮結實，拿來跟你交易。</span>
<span className="v" id="v25" data-v="25" data-xref="以賽亞書 2:16; 詩篇 48:7; 以賽亞書 23:14"> <span className="pl pl-1">「『他施的船隻替你運貨，</span><br /><span className="pl pl-1">你在海上載滿沉甸甸的貨物。</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="詩篇 48:7; 以西結書 26:19; 使徒行傳 27:14"> <span className="pl pl-1">船夫把你搖到汪洋之中，</span><br /><span className="pl pl-1">但東風要把你擊碎在海中。</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="箴言 11:4; 以西結書 27:24; 以西結書 27:12"> <span className="pl pl-1">你的財富、貨物、商品、</span><br /><span className="pl pl-1">水手、舵手、修補匠、客商、</span><br /><span className="pl pl-1">戰士和人民在你傾覆的日子都要沉到深海裡。</span><br /></span>
<span className="v" id="v28" data-v="28" data-xref="以西結書 26:10; 出埃及記 15:14; 以西結書 31:16"> <span className="pl pl-1">你舵手的哀號聲必震動海岸，</span><br /></span>
<span className="v" id="v29" data-v="29" data-xref="以西結書 26:16; 以西結書 32:10; 啟示錄 18:17–24"> <span className="pl pl-1">所有的船夫、水手、舵手都必棄船登岸，</span><br /></span>
<span className="v" id="v30" data-v="30" data-xref="耶利米書 6:26; 撒母耳記下 1:2; 耶利米哀歌 2:10"> <span className="pl pl-1">為你放聲痛哭，</span><br /><span className="pl pl-1">把塵埃撒在頭上，</span><br /><span className="pl pl-1">在灰中打滾，</span><br /></span>
<span className="v" id="v31" data-v="31" data-xref="以西結書 7:18; 以賽亞書 22:12; 以賽亞書 15:2"> <span className="pl pl-1">又為你剃光頭發，腰束麻布，</span><br /><span className="pl pl-1">並為你傷心哭泣，痛苦哀號。</span><br /></span>
<span className="v" id="v32" data-v="32" data-xref="以西結書 26:17; 啟示錄 18:18; 以西結書 27:2"> <span className="pl pl-1">他們在痛哭中為你唱起哀歌，</span><br /><span className="pl pl-1">哀悼你說，</span><br /><span className="pl pl-1">有哪一座城像泰爾一樣在深海中銷聲匿跡呢？</span><br /></span>
<span className="v" id="v33" data-v="33" data-xref="啟示錄 18:19; 以西結書 27:3; 以西結書 28:16"> <span className="pl pl-1">你的貨物由海上運出，</span><br /><span className="pl pl-1">滿足了許多國家；</span><br /><span className="pl pl-1">你的資財和貨物使地上的君王富裕。</span><br /></span>
<span className="v" id="v34" data-v="34" data-xref="以西結書 27:26–27; 撒迦利亞書 9:3–4; 以西結書 26:19–21"> <span className="pl pl-1">如今你在汪洋中被海浪擊碎，</span><br /><span className="pl pl-1">你的貨物和人民都一同沉沒了。</span><br /></span>
<span className="v" id="v35" data-v="35" data-xref="以西結書 32:10; 以賽亞書 23:6; 以西結書 26:15–18"> <span className="pl pl-1">沿海的居民因你而驚駭，</span><br /><span className="pl pl-1">君王都嚇得面容失色。</span><br /></span>
<span className="v" id="v36" data-v="36" data-xref="耶利米書 18:16; 詩篇 37:10; 西番雅書 2:15"> <span className="pl pl-1">各國商人都嗤笑你，</span><br /><span className="pl pl-1">你那可怕的末日來臨了，</span><br /><span className="pl pl-1">你將永遠不復存在。』」</span></span>

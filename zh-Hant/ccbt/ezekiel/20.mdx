## 以色列人的悖逆

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西結書 8:1; 以西結書 30:20; 以西結書 24:1"> 第七年五月十日，有幾個以色列的長老來求問耶和華，他們坐在我面前。</span>
<span className="v" id="v2" data-v="2"> 耶和華對我說：</span>
<span className="v" id="v3" data-v="3" data-xref="箴言 28:9; 馬太福音 15:8–9; 詩篇 50:15–21"> 「人子啊，你要告訴他們，主耶和華這樣說，『你們是來求問我嗎？我憑我的永恆起誓，我決不讓你們求問。』這是主耶和華說的。</span>
<span className="v" id="v4" data-v="4" data-xref="以西結書 22:2; 以西結書 23:36; 以西結書 14:20"> 人子啊，你要審判他們嗎？你要審判他們嗎？要使他們知道他們祖先所做的可憎之事。</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 7:6; 以西結書 20:15; 出埃及記 3:8"> 你要告訴他們，主耶和華這樣說，『我揀選以色列那日，曾向雅各家的後裔起誓，又在埃及讓他們認識我，告訴他們我是他們的上帝耶和華。</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及記 3:8; 耶利米書 32:22; 以西結書 20:15"> 那日我向他們起誓，要帶領他們離開埃及，到我為他們選定的奶蜜之鄉，世上最佳美的地方。</span>
<span className="v" id="v7" data-v="7" data-xref="利未記 18:3; 以西結書 20:8; 利未記 11:44"> 我告訴他們要除掉他們祭拜的可憎之物，不可讓埃及的偶像玷污自己，因為我是他們的上帝耶和華。</span>
<span className="v" id="v8" data-v="8" data-xref="以西結書 20:7; 以賽亞書 63:10; 以西結書 20:21"> 「『然而，他們卻背叛我，不聽我的話，沒有除去他們戀慕的可憎之物，也沒有棄絕埃及的偶像。我本想在埃及向他們發烈怒，傾倒我的怒火，</span>
<span className="v" id="v9" data-v="9" data-xref="以西結書 39:7; 以西結書 20:22; 出埃及記 32:12"> 但我沒有這樣做，以免我的名在他們寄居的列邦面前被褻瀆。因為我曾在列邦眼前讓以色列人認識我，把他們帶出埃及。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及記 15:22; 出埃及記 13:17–18; 出埃及記 14:17–22"> 於是，我帶他們離開埃及，進入曠野，</span>
<span className="v" id="v11" data-v="11" data-xref="羅馬書 10:5; 利未記 18:5; 申命記 4:8"> 向他們頒佈我的律例並顯明我的典章，遵行的人必因此而活。</span>
<span className="v" id="v12" data-v="12" data-xref="以西結書 20:20; 以西結書 37:28; 利未記 21:23"> 我又讓他們遵守我的安息日，作為我與他們之間的記號，好叫他們知道是我耶和華使他們成為聖潔之民。</span>
<span className="v" id="v13" data-v="13" data-xref="以西結書 20:21; 以西結書 20:8; 以賽亞書 56:6"> 「『可是，以色列人卻在曠野背叛我，不遵行我的律例，還棄絕我的典章，而遵行的人必因此而活。他們大肆褻瀆我的安息日。我本想在曠野向他們發烈怒，滅絕他們。</span>
<span className="v" id="v14" data-v="14" data-xref="以西結書 20:9; 以西結書 36:22–23; 以西結書 20:22"> 但我沒有這樣做，以免我的名在周圍列邦面前被褻瀆，因為我在列邦眼前把以色列人帶出埃及。</span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 95:11; 詩篇 106:26; 希伯來書 3:18"> 而且，我在曠野曾向他們發誓，不帶他們進入我賜給他們的那奶蜜之鄉，那世上最佳美的地方，</span>
<span className="v" id="v16" data-v="16" data-xref="民數記 15:39; 以西結書 20:8; 以西結書 14:3–4"> 因為他們棄絕我的典章，不順從我的律例，褻瀆我的安息日，心戀偶像。</span>
<span className="v" id="v17" data-v="17" data-xref="以西結書 11:13; 耶利米書 4:27; 耶利米書 5:18"> 但我憐憫他們，沒有毀滅他們，沒有在曠野把他們全部滅絕。</span>
<span className="v" id="v18" data-v="18" data-xref="撒迦利亞書 1:2–4; 詩篇 78:6–8; 彼得前書 1:18"> 「『我在曠野曾對他們的子孫說，不要效法你們祖先的律例，不要遵守他們的規條，不要拜他們的偶像，以致玷污自己。</span>
<span className="v" id="v19" data-v="19" data-xref="以西結書 36:27; 申命記 5:32–8; 以西結書 37:24"> 我是你們的上帝耶和華，你們要恪守我的律例，謹遵我的典章，</span>
<span className="v" id="v20" data-v="20" data-xref="以賽亞書 58:13; 耶利米書 17:22; 出埃及記 31:13–17"> 尊我定的安息日為聖日，作為我與你們之間的記號，使你們知道我是你們的上帝耶和華。</span>
<span className="v" id="v21" data-v="21" data-xref="以西結書 20:13; 民數記 21:5; 以西結書 20:8"> 「『可是，他們的子孫卻背叛我，不恪守我的律例，不謹遵我的典章，而遵行的人必因此而活。他們褻瀆我的安息日。我本想在曠野向他們發烈怒，傾倒我的怒氣，</span>
<span className="v" id="v22" data-v="22" data-xref="以西結書 20:14; 以西結書 20:9; 耶利米書 14:21"> 但我沒有這樣做，以免我的名在周圍列邦面前被褻瀆，因為我在列邦眼前把以色列人帶出埃及。</span>
<span className="v" id="v23" data-v="23" data-xref="利未記 26:33; 申命記 28:64–68; 申命記 32:26–27"> 而且，我在曠野起誓要把他們驅散到列國，分散到列邦，</span>
<span className="v" id="v24" data-v="24" data-xref="以西結書 20:16; 以西結書 6:9; 阿摩司書 2:4"> 因為他們不遵行我的典章，棄絕我的律例，褻瀆我的安息日，眼睛戀慕他們祖先的偶像。</span>
<span className="v" id="v25" data-v="25" data-xref="詩篇 81:12; 以賽亞書 66:4; 以西結書 20:39"> 所以，我任由他們遵行無用的律例，遵守無法使人活著的規條，</span>
<span className="v" id="v26" data-v="26" data-xref="以西結書 6:7; 利未記 18:21; 以西結書 20:31"> 任由他們把自己的長子燒作祭物獻給偶像，以致玷污自己，好使他們充滿恐懼，這樣他們便知道我是耶和華。』</span>
<span className="v" id="v27" data-v="27" data-xref="羅馬書 2:24; 以西結書 2:7; 以西結書 3:11"> 「人子啊，你要告訴以色列人，主耶和華這樣說，『你們的祖先還背信棄義，褻瀆了我。</span>
<span className="v" id="v28" data-v="28" data-xref="以西結書 6:13; 尼希米記 9:22–26; 耶利米書 3:6"> 當我引領他們進入我曾起誓要賜給他們的土地時，他們在所見的每一處高山或茂密的樹下獻祭，獻上惹我發怒的供物，焚燒馨香的祭，向偶像奠酒。</span>
<span className="v" id="v29" data-v="29" data-xref="以西結書 16:24–25; 以西結書 16:31"> 我問他們，你們所去的高處是什麼地方？』從此，那高處一直叫巴麻<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「巴麻」即「高處」的意思。">a</a></sup>。</span>
<span className="v" id="v30" data-v="30" data-xref="耶利米書 16:12; 耶利米書 7:26; 士師記 2:19"> 「所以，你要告訴以色列人，主耶和華這樣說，『你們仍像你們祖先一樣玷污自己，與可憎的偶像苟合嗎？</span>
<span className="v" id="v31" data-v="31" data-xref="以西結書 20:26; 詩篇 106:37–39; 耶利米書 7:31"> 你們至今仍焚燒自己的兒子獻為祭物，用你們的一切偶像玷污自己。以色列人啊，我會讓你們求問我嗎？主耶和華說，我憑我的永恆起誓，我決不讓你們求問。</span>
<span className="v" id="v32" data-v="32" data-xref="以西結書 11:5; 耶利米書 44:17; 詩篇 139:2"> 「『你們說要像列邦列族一樣去供奉木頭石頭，你們的想法絕不能實現！』</span>
<span className="v" id="v33" data-v="33" data-xref="耶利米書 21:5; 以西結書 8:18; 耶利米書 44:6"> 「主耶和華說，『我憑我的永恆起誓，我要發烈怒，伸出臂膀用大能的手治理你們。</span>
<span className="v" id="v34" data-v="34" data-xref="以西結書 20:38; 阿摩司書 9:9–10; 以西結書 34:16"> 我要發烈怒，伸出臂膀用大能的手把你們從列國中領出來，從你們散居的列邦聚集你們，</span>
<span className="v" id="v35" data-v="35" data-xref="何西阿書 2:14; 耶利米書 2:35; 以西結書 17:20"> 領你們進入列國的曠野，面對面地審判你們。</span>
<span className="v" id="v36" data-v="36" data-xref="哥林多前書 10:5–10; 民數記 11:1–35; 以西結書 20:13"> 我從前在埃及的曠野怎樣審判你們的祖先，也必怎樣審判你們。這是主耶和華說的。</span>
<span className="v" id="v37" data-v="37" data-xref="耶利米書 33:13; 利未記 27:32; 馬太福音 25:32–33"> 我要對你們嚴加管教<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="「對你們嚴加管教」希伯來文是「讓你們在杖下經過」。">b</a></sup>，使你們遵守我的約。</span>
<span className="v" id="v38" data-v="38" data-xref="以西結書 13:9; 阿摩司書 9:9–10; 詩篇 95:11"> 我要剷除你們中間叛逆和犯罪的人。雖然我要領他們離開寄居之地，他們卻不能回以色列。這樣，你們就知道我是耶和華。』</span>
<span className="v" id="v39" data-v="39" data-xref="何西阿書 4:17; 以賽亞書 1:13–15; 以西結書 43:7"> 「主耶和華說，『你們以色列人若不聽我的話，就去供奉你們的偶像吧！但將來你們必不再向偶像獻祭物褻瀆我的聖名！』</span>
<span className="v" id="v40" data-v="40" data-xref="以賽亞書 56:7; 瑪拉基書 3:4; 以賽亞書 60:7"> 「主耶和華說，『在我的聖山，就是以色列的高山上，所有的以色列人都要事奉我，我要在那裡悅納你們，要求你們獻上供物、最好的禮物和一切聖物。</span>
<span className="v" id="v41" data-v="41" data-xref="以西結書 28:25; 以西結書 11:17; 以西結書 38:23"> 當我把你們從列國領出來，從你們散居的列邦聚集起來時，你們必如馨香之祭一樣蒙我悅納，我必當著列國的面在你們中間彰顯我的聖潔。</span>
<span className="v" id="v42" data-v="42" data-xref="以西結書 34:13; 以西結書 38:23; 以西結書 36:23–24"> 我要把你們帶回我起誓要賜給你們祖先的以色列，這樣你們就知道我是耶和華。</span>
<span className="v" id="v43" data-v="43" data-xref="以西結書 6:9; 何西阿書 5:15; 耶利米書 31:18"> 你們在那裡會想起以往玷污自己的行徑，並因自己的一切惡行而憎惡自己。』</span>
<span className="v" id="v44" data-v="44" data-xref="以西結書 24:24; 詩篇 115:1; 以西結書 20:9"> 主耶和華說，『以色列人啊，我為了自己的名，沒有照你們邪惡敗壞的行徑懲罰你們，這樣你們便知道我是耶和華。』」</span>
<span className="v" id="v45" data-v="45"> 耶和華對我說：</span>
<span className="v" id="v46" data-v="46" data-xref="阿摩司書 7:16; 以西結書 21:2; 耶利米書 13:19"> 「人子啊，你要面向南方，開口斥責南方，說預言斥責南地的樹林。</span>
<span className="v" id="v47" data-v="47" data-xref="耶利米書 21:14; 以賽亞書 24:1–6; 以西結書 17:24"> 你要對南地的樹林說，『你要聽耶和華的話。主耶和華說，我要在你那裡燃起火來，燒毀你所有的青樹和枯樹。這不熄的烈火要從南到北燒焦一切。</span>
<span className="v" id="v48" data-v="48" data-xref="耶利米書 40:2–3; 耶利米書 7:20; 申命記 29:24–28"> 這樣，世人便知道這烈火是我耶和華點燃的，它絕不會熄滅。』」</span>
<span className="v" id="v49" data-v="49" data-xref="約翰福音 16:25; 使徒行傳 17:18; 以西結書 17:2"> 於是我說：「唉，主耶和華啊，他們在議論我說，『他豈不是在說比喻嗎？』」</span>

## 預言審判泰爾王

<div className="bt">
<div className="bp poetry">

<span className="v" id="v2" data-v="2" data-xref="以西結書 28:9; 帖撒羅尼迦後書 2:4; 以賽亞書 14:13–14"> 「人子啊，你去告訴泰爾王，主耶和華這樣說，<br /><span className="pl pl-1">「『你心裡高傲，說，我是神明，</span><br /><span className="pl pl-1">我坐在海中神明的寶座上。</span><br /><span className="pl pl-1">你雖然自以為像神明，</span><br /><span className="pl pl-1">但你不過是人，並非神明。</span><br /></span>

## 泰爾王的終局

<div className="bt">
<div className="bp poetry">
<span className="v" id="v11" data-v="11"> 耶和華對我說：</span>
<span className="v" id="v12" data-v="12" data-xref="以西結書 19:1; 以西結書 26:17; 哥林多後書 1:22"> 「人子啊，你要為泰爾王唱哀歌，告訴他，主耶和華這樣說，<br /><span className="pl pl-1">「『你曾經是完美的典範，</span><br /><span className="pl pl-1">充滿智慧，美麗無瑕。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="以西結書 28:15; 創世記 2:8; 以西結書 27:16"> <span className="pl pl-1">你曾在上帝的伊甸園中，</span><br /><span className="pl pl-1">你曾佩戴各種寶石，</span><br /><span className="pl pl-1">有紅寶石、黃玉、鑽石、</span><br /><span className="pl pl-1">綠寶石、紅瑪瑙、碧玉、</span><br /><span className="pl pl-1">藍寶石、綠松石、翡翠，</span><br /><span className="pl pl-1">底座鑲嵌著精美的黃金，</span><br /><span className="pl pl-1">這些在你受造的那天都已經預備妥當。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="以賽亞書 14:12–15; 出埃及記 30:26; 以西結書 28:13"> <span className="pl pl-1">我膏立你為看守約櫃的基路伯天使。</span><br /><span className="pl pl-1">我把你安置在上帝的聖山上，</span><br /><span className="pl pl-1">在閃閃發光的寶石中行走。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="彼得後書 2:4; 以西結書 28:17–18; 羅馬書 7:9"> <span className="pl pl-1">你從受造那天開始所行的純全無過，</span><br /><span className="pl pl-1">但後來在你那裡查出不義。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="提摩太前書 6:9–10; 哈巴谷書 2:8; 哈巴谷書 2:17"> <span className="pl pl-1">因為貿易發達，</span><br /><span className="pl pl-1">你便充滿暴力，犯罪作惡。</span><br /><span className="pl pl-1">因此，看守約櫃的基路伯天使啊，</span><br /><span className="pl pl-1">我把你當作污穢之物逐出上帝的山，</span><br /><span className="pl pl-1">從閃閃發光的寶石中除掉你。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="以西結書 28:5; 以西結書 31:10; 雅各書 4:6"> <span className="pl pl-1">你因俊美而心高氣傲，</span><br /><span className="pl pl-1">因輝煌而心智敗壞，</span><br /><span className="pl pl-1">所以我把你扔到地上，</span><br /><span className="pl pl-1">讓你在列國的君王面前出醜。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="瑪拉基書 4:3; 啟示錄 18:8; 阿摩司書 1:9–10"> <span className="pl pl-1">你多行不義，</span><br /><span className="pl pl-1">交易不公，</span><br /><span className="pl pl-1">褻瀆了你的聖所，</span><br /><span className="pl pl-1">因此我使火在你那裡燃起，吞噬你，</span><br /><span className="pl pl-1">在眾目睽睽之下把你燒成地上的灰燼。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="以西結書 26:21; 啟示錄 18:21; 啟示錄 18:15–19"> <span className="pl pl-1">所有認識你的民族都因你而驚駭，</span><br /><span className="pl pl-1">你落得可怕的下場，</span><br /><span className="pl pl-1">你將永遠不復存在。』」</span></span>
</div>
</div>

## 預言歌革被滅

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西結書 38:2–3; 以西結書 35:3; 那鴻書 3:5"> 「人子啊，你要說預言斥責歌革，告訴他，主耶和華這樣說，『米設和土巴的首領歌革啊，我要與你為敵。</span>
<span className="v" id="v2" data-v="2" data-xref="詩篇 40:14; 以西結書 38:15; 以賽亞書 37:29"> 我要把你調轉過來，使你從遙遠的北方來到以色列的山中。</span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 76:3; 何西阿書 1:5; 耶利米書 21:4–5"> 我要打掉你左手的弓，擊落你右手的箭。</span>
<span className="v" id="v4" data-v="4" data-xref="以西結書 39:17–20; 以西結書 33:27; 以西結書 38:21"> 你和你的軍隊，以及與你同來的各國聯軍都要倒斃在以色列的山嶺上，我要把你們的屍體給各種猛禽野獸作食物。</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米書 22:19; 以西結書 32:4; 耶利米書 8:2"> 你必倒斃在田野之間，因為我已經宣告。這是主耶和華說的。</span>
<span className="v" id="v6" data-v="6" data-xref="以西結書 30:16; 阿摩司書 1:4; 以西結書 30:8"> 我要火燒瑪各和安居在海島的人，他們就知道我是耶和華。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="以西結書 38:16; 以西結書 38:23; 出埃及記 20:7"> 「『我要讓我的以色列子民知道我的聖名，不再讓我的聖名被褻瀆。這樣列國就知道我是以色列的聖者耶和華。</span>
<span className="v" id="v8" data-v="8" data-xref="以西結書 38:17; 啟示錄 16:17; 以西結書 7:2–10"> 我所說的日子將要來臨，一切必然實現。這是主耶和華說的。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="詩篇 46:9; 以賽亞書 66:24; 瑪拉基書 1:5"> 「『以色列各城邑的居民都要出去撿兵器當柴燒，其中包括大小的盾牌、弓箭、矛槍等，足夠用七年。</span>
<span className="v" id="v10" data-v="10" data-xref="以賽亞書 33:1; 以賽亞書 14:2; 彌迦書 5:8"> 他們不必到田間拾柴，或到林中伐木，因為有兵器當柴燒。他們要搶奪那些搶奪過他們的人，擄掠那些擄掠過他們的人。這是主耶和華說的。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="以西結書 47:18; 民數記 34:11; 以西結書 38:2"> 「『那一天，我要把以色列境內通往鹽海東邊的旅客谷作為歌革的墳地，埋葬他和他的軍隊。這墳地將截斷行人的去路，因此人稱那地方為哈們·歌革谷。</span>
<span className="v" id="v12" data-v="12" data-xref="申命記 21:23; 以西結書 39:14; 以西結書 39:16"> 以色列人要用七個月來埋葬他們，使那地方潔淨。</span>
<span className="v" id="v13" data-v="13" data-xref="以西結書 28:22; 西番雅書 3:19–20; 耶利米書 33:9"> 以色列人都要來埋葬他們。我彰顯榮耀的那天將是以色列人名聲大振的日子。這是主耶和華說的。</span>
<span className="v" id="v14" data-v="14" data-xref="以西結書 39:12; 民數記 19:11–19"> 七個月之久，他們會派人不斷巡視那裡，埋葬遺留在地面上的屍體，使那裡潔淨。</span>
<span className="v" id="v15" data-v="15" data-xref="路加福音 11:44"> 如果巡視的人發現了骸骨，便在旁邊立一個標記，等待負責埋葬的人將骸骨埋葬在哈們·歌革谷，</span>
<span className="v" id="v16" data-v="16"> 他們要這樣使那地方潔淨。那裡有一座城叫哈摩那<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「哈摩那」意思是「大群」。">a</a></sup>。』</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="西番雅書 1:7; 啟示錄 19:17–18; 以賽亞書 34:6"> 「人子啊，主耶和華說，『你要召喚各類飛鳥和野獸，讓牠們聚集起來，從四面八方來赴我為牠們預備的祭宴，就是以色列山嶺上的大祭宴，在那裡吃肉飲血。</span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 22:12; 耶利米書 51:40; 啟示錄 19:17–18"> 牠們將吃到勇士的肉，喝到君王的血，好像吃公綿羊、羊羔、公山羊、公牛這些巴珊的肥畜。</span>
<span className="v" id="v19" data-v="19"> 牠們要在我為牠們設的祭宴中任意吃肉飲血，直到吃飽喝醉為止。</span>
<span className="v" id="v20" data-v="20" data-xref="啟示錄 19:18; 哈該書 2:22; 詩篇 76:5–6"> 牠們在我的宴席上要飽餐戰馬、騎兵、勇士和所有軍人的肉。這是主耶和華說的。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="以西結書 38:16; 以西結書 38:23; 以賽亞書 37:20"> 「『我要在列國中彰顯我的榮耀，萬國必看見我用大能在他們身上施行的審判。</span>
<span className="v" id="v22" data-v="22" data-xref="耶利米書 24:7; 以西結書 28:26; 以西結書 39:28"> 從那天起，以色列必知道我是他們的上帝耶和華。</span>
<span className="v" id="v23" data-v="23" data-xref="耶利米書 22:8–9; 以賽亞書 1:15; 以賽亞書 59:2"> 列國必知道以色列人被擄走是因為他們犯罪背叛我，以致我掩面不顧他們，把他們交在敵人手中，讓他們喪身刀下。</span>
<span className="v" id="v24" data-v="24" data-xref="以西結書 36:19; 耶利米書 2:17; 耶利米書 4:18"> 我照他們的污穢和罪惡報應他們，掩面不顧他們。』</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="以西結書 34:13; 以賽亞書 27:12–13; 何西阿書 1:11"> 「因此，主耶和華說，『我要使雅各被擄的人返鄉，我要憐憫全體以色列人，熱心維護我的聖名。</span>
<span className="v" id="v26" data-v="26" data-xref="彌迦書 4:4; 列王紀上 4:25; 以西結書 16:63"> 當他們在故土安居，沒有人來威脅他們的時候，他們就會忘記自己所有的羞辱和得罪我的惡事。</span>
<span className="v" id="v27" data-v="27" data-xref="以西結書 38:16; 以西結書 38:23; 以西結書 36:23–24"> 我從列國把他們領回，從敵國把他們召回來的時候，我要藉著他們向列國彰顯我的聖潔。</span>
<span className="v" id="v28" data-v="28" data-xref="以西結書 39:22; 阿摩司書 9:9; 以賽亞書 27:12"> 我讓他們被擄到列國，將來必召集他們返回故土，不撇下一人。這樣，他們便知道我是他們的上帝耶和華。</span>
<span className="v" id="v29" data-v="29" data-xref="約珥書 2:28; 約翰一書 3:24; 以賽亞書 32:15"> 我不再掩面不顧以色列人，因為我要把我的靈澆灌在他們身上。這是主耶和華說的。』」</span>
</div>
</div>

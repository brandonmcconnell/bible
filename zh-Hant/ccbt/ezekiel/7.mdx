## 以色列的結局近了

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華對我說：</span>
<span className="v" id="v2" data-v="2" data-xref="阿摩司書 8:2; 彼得前書 4:7; 以西結書 7:3"> 「人子啊，主耶和華對以色列這樣說，『結局到了，以色列全境的結局到了！</span>
<span className="v" id="v3" data-v="3" data-xref="以西結書 18:30; 以西結書 5:13; 以西結書 33:20"> 以色列，你的結局到了，我的怒氣必傾倒在你身上，我必按你的行為審判你，照你一切的可憎之事報應你。</span>
<span className="v" id="v4" data-v="4" data-xref="以西結書 6:7; 以西結書 11:21; 以西結書 5:11"> 我必不顧惜你，也不憐憫你，我必按你的所作所為和可憎之事報應你。這樣，你必知道我是耶和華。』」</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="那鴻書 1:9; 列王紀下 21:12–13; 以西結書 5:9"> 主耶和華說：「看啊，災禍來了，一場空前的災禍來了！</span>
<span className="v" id="v6" data-v="6" data-xref="撒迦利亞書 13:7; 以西結書 7:3; 彼得後書 2:5"> 結局到了，結局到了！你的結局到了。看啊，結局到了！</span>
<span className="v" id="v7" data-v="7" data-xref="以西結書 12:28; 以西結書 7:12; 以賽亞書 22:5"> 以色列境內的居民啊，災難降臨了！時候已到，日子已近，山上一片恐慌，歡樂蕩然無存。</span>
<span className="v" id="v8" data-v="8" data-xref="以西結書 9:8; 以西結書 14:19; 以西結書 20:8"> 我快要向你傾倒我的烈怒，發出我的怒氣。我必按你的所作所為審判你，照你一切的可憎之事報應你。</span>
<span className="v" id="v9" data-v="9" data-xref="啟示錄 20:13; 彌迦書 6:9; 以賽亞書 9:13"> 我必不顧惜你，也不憐憫你，我必按你的惡行報應你。這樣，你就知道擊打你的是我耶和華。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="以賽亞書 10:5; 雅各書 4:6; 帖撒羅尼迦前書 5:3"> 「看啊，那日子！看啊，那日到了，災禍臨頭了！杖已經發芽，傲慢已經開花。</span>
<span className="v" id="v11" data-v="11" data-xref="西番雅書 1:18; 以西結書 7:23; 以賽亞書 59:6–8"> 暴行成了懲罰邪惡的杖，以色列人必沒有一個能夠存留，他們的財富和尊榮必不復存在。</span>
<span className="v" id="v12" data-v="12" data-xref="以賽亞書 5:13–14; 哥林多前書 7:29–31; 以西結書 7:5–7"> 時候到了，日子近了，買主不要歡樂，賣主也不要憂愁，因為烈怒臨到了所有的人。</span>
<span className="v" id="v13" data-v="13" data-xref="利未記 25:24–28; 利未記 25:31; 約伯記 15:25"> 即使賣主活著，也無法贖回他所賣的，因為關乎每一個人的異象必然應驗，他們因為罪惡，無人能保存性命。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="耶利米書 4:5; 耶利米書 7:20; 耶利米書 51:27"> 「他們吹響了號角，做好了一切準備，卻無人出戰，因為我的烈怒臨到了他們所有的人。</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米書 14:18; 以西結書 5:12; 耶利米哀歌 1:20"> 城外有刀劍，城內有饑荒瘟疫；城外的必喪身刀下，城內的必死於饑荒瘟疫。</span>
<span className="v" id="v16" data-v="16" data-xref="以賽亞書 59:11; 以賽亞書 38:14; 以斯拉記 9:15"> 僥倖逃到山上的，都必像谷中哀鳴的鴿子，為自己的罪惡哀鳴。</span>
<span className="v" id="v17" data-v="17" data-xref="以西結書 21:7; 希伯來書 12:12; 耶利米書 6:24"> 他們必嚇得兩手發軟，雙腿顫抖。</span>
<span className="v" id="v18" data-v="18" data-xref="阿摩司書 8:10; 以賽亞書 15:2–3; 以賽亞書 3:24"> 他們必身披麻衣，戰慄發抖。他們必剃光頭髮，滿臉盡是恥辱。</span>
<span className="v" id="v19" data-v="19" data-xref="箴言 11:4; 西番雅書 1:18; 路加福音 12:19–20"> 他們必把銀子拋在街上，視金子為污穢之物。在耶和華發烈怒的日子，金銀不能拯救他們，也不能填飽他們的肚腹或滿足他們的胃口，因為金銀使他們跌入罪惡中。</span>
<span className="v" id="v20" data-v="20" data-xref="以西結書 24:21; 耶利米書 7:30; 以西結書 8:15–16"> 他們以華美的飾物為驕傲，並用它製造醜惡可憎的神像，因此，我必使這一切變成他們眼中的污穢之物。</span>
<span className="v" id="v21" data-v="21" data-xref="列王紀下 24:13; 詩篇 74:2–8; 歷代志下 36:18–19"> 我必使這一切成為外族人手中的獵物，惡人手中的戰利品，被任意糟蹋。</span>
<span className="v" id="v22" data-v="22" data-xref="耶利米書 18:17; 詩篇 74:18–23; 詩篇 74:10–11"> 我必轉臉不看他們，任由外族人褻瀆我的殿，強盜必進入殿裡大肆褻瀆。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="以西結書 9:9; 耶利米書 27:2; 以西結書 11:6"> 「你要預備鎖鏈，因為這地方充滿了血腥的罪惡，城裡充斥著暴行。</span>
<span className="v" id="v24" data-v="24" data-xref="以西結書 28:7; 詩篇 106:41; 以西結書 21:31"> 我必讓最兇惡的外族人侵佔他們的房屋。我必挫敗強悍之人的傲氣，使他們的聖所遭受褻瀆。</span>
<span className="v" id="v25" data-v="25" data-xref="耶利米書 8:15–16; 以賽亞書 57:21; 耶利米哀歌 4:17–18"> 恐怖的日子來臨了，他們想尋求平安，卻得不到平安。</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米書 4:20; 以西結書 14:1; 彌迦書 3:6"> 災禍接踵而至，噩耗不斷傳來。那時，他們必求問先知，但祭司的教導必消逝，長老們必無計可施。</span>
<span className="v" id="v27" data-v="27" data-xref="以西結書 18:30; 以西結書 7:4–8; 以西結書 26:16"> 君王必悲哀，首領必驚恐，百姓的手都必顫抖。我必按他們的惡行對付他們，使他們受到應得的審判。這樣，他們就知道我是耶和華。」</span>
</div>
</div>

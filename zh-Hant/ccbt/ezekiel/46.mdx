## 君王與節期

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以賽亞書 66:23; 以西結書 44:1–2; 出埃及記 20:9"> 「主耶和華說，『聖殿內院的東門在平時工作的六日內都要關閉，只在安息日和朔日才打開。</span>
<span className="v" id="v2" data-v="2" data-xref="以西結書 44:3; 以西結書 46:8; 歷代志上 29:10–12"> 在這些日子，君王要從東門穿過門廊通道進入內院，站在門框旁邊。祭司要為他獻燔祭和平安祭。他在入口的門檻那裡敬拜，然後離去。這門要到晚上才關閉。</span>
<span className="v" id="v3" data-v="3" data-xref="路加福音 1:10; 約翰福音 10:9; 希伯來書 10:19–22"> 在安息日和朔日，以色列人要站在這門口敬拜耶和華。</span>
<span className="v" id="v4" data-v="4" data-xref="以西結書 45:17; 民數記 28:9–10"> 君王在安息日獻給耶和華的燔祭應是羊羔六隻、公綿羊一隻，都要毫無殘疾。</span>
<span className="v" id="v5" data-v="5" data-xref="以西結書 45:24; 以西結書 46:7; 申命記 16:17"> 至於同獻的素祭，一隻公綿羊要同獻十公斤細麵粉，與羊羔同獻的素祭則可隨意奉獻。每十公斤細麵粉要加四升油。</span>
<span className="v" id="v6" data-v="6" data-xref="以西結書 46:1"> 要在朔日獻公牛犢一頭、羊羔六隻、公綿羊一隻，都要毫無殘疾。</span>
<span className="v" id="v7" data-v="7" data-xref="以西結書 46:5"> 他也要預備素祭，每一頭公牛犢要同獻十公斤細麵粉，公綿羊也是一樣。與羊羔同獻的素祭則可隨意奉獻。每十公斤細麵粉要加四升油。</span>
<span className="v" id="v8" data-v="8" data-xref="以西結書 46:2; 以西結書 44:1–3; 歌羅西書 1:18"> 君王從門廊進去，也要從原路出來。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="申命記 16:16; 出埃及記 23:14–17; 彼得後書 2:20–21"> 「『以色列人在節期進去敬拜耶和華的時候，從北門進去的要從南門出來，從南門進去的要從北門出來。誰都不可回頭從進去的門出來，必須從對面的門出來。</span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 42:4; 歷代志上 29:20; 歷代志上 29:22"> 在這些節期君王應和百姓一同進殿敬拜，百姓離開的時候，君王也要一同離開。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="以西結書 46:5; 以西結書 46:7; 民數記 15:1–41"> 「『每逢節期和特定的聖會，要有與祭牲同獻的素祭，每頭公牛獻十公斤細麵粉，公綿羊也是一樣，與羊羔同獻的素祭則可以隨意奉獻。每十公斤細麵粉要加四升油。</span>
<span className="v" id="v12" data-v="12" data-xref="以西結書 46:1–2; 以西結書 45:17; 以西結書 44:3"> 倘若君王自願向耶和華獻燔祭或平安祭，便要為他打開東門。他獻的燔祭或平安祭要與安息日所獻的一樣。他獻完後就從東門出去，門也跟著關閉。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="以賽亞書 50:4; 約翰福音 1:29; 出埃及記 12:5"> 「『每天早晨，你們要獻給耶和華一隻毫無殘疾的一歲羊羔為燔祭，</span>
<span className="v" id="v14" data-v="14" data-xref="民數記 28:5"> 同獻的素祭是三公斤細麵粉，調上一升油。獻給耶和華的這種素祭是永久不變的律例。</span>
<span className="v" id="v15" data-v="15" data-xref="希伯來書 10:1–10; 民數記 28:6; 出埃及記 29:42"> 所以，每天早晨都要預備羊羔、素祭和油，作為日常獻的燔祭。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="歷代志下 21:3; 加拉太書 4:7; 創世記 25:5–6"> 「『主耶和華說，如果君王把一部分產業作為禮物賜給他兒子，這產業便歸了他兒子，由他兒子的後代繼承。</span>
<span className="v" id="v17" data-v="17" data-xref="利未記 25:10; 路加福音 19:25–26; 加拉太書 4:30–31"> 如果君王把一部分產業作為禮物賜給他的僕人，他的僕人在得到自由之前可以擁有這產業，到他自由的那年<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「自由的那年」即「禧年」，參見利未記25·8‑17。">a</a></sup>，這份產業仍要歸還給君王，因為君王的產業只能由他的後代繼承。</span>
<span className="v" id="v18" data-v="18" data-xref="以西結書 45:8; 列王紀上 21:19; 以西結書 22:27"> 君王不可驅逐百姓離開他們的土地，強奪他們的產業。他必須把自己擁有的產業賜給兒子，免得我的子民從自己的土地上被驅散。』」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="以西結書 42:9; 以西結書 44:4–5; 以西結書 40:44–46"> 然後，那人領我從大門旁邊的入口來到聖所北面的祭司聖屋，讓我看聖屋西邊的地方。</span>
<span className="v" id="v20" data-v="20" data-xref="歷代志下 35:13; 以西結書 44:29; 以西結書 44:19"> 他對我說：「這是祭司煮贖過祭牲、贖罪祭牲和烤素祭的地方。他們在這裡烤煮，免得把聖肉帶到外院，以致把聖潔傳到百姓身上。」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21"> 他又領我到外院，巡察外院的四個角落。我看見院中每個角落都有一個小庭院，</span>
<span className="v" id="v22" data-v="22"> 每個庭院的四周都有圍牆，長二十米，寬十五米，四角的庭院大小都一樣。</span>
<span className="v" id="v23" data-v="23"> 每個庭院的牆周圍都有一排石屋，屋裡有爐灶。</span>
<span className="v" id="v24" data-v="24" data-xref="以西結書 46:20; 約翰福音 21:15–17; 彼得前書 5:2"> 他對我說：「這是聖殿的僕役替百姓煮祭物的地方。」</span>
</div>
</div>

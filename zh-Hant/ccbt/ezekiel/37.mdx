## 枯骨復活

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西結書 3:22; 以西結書 1:3; 使徒行傳 8:39"> 耶和華的手按在我身上，耶和華藉祂的靈把我帶到一個山谷，那裡遍地都是骸骨。</span>
<span className="v" id="v2" data-v="2" data-xref="詩篇 141:7; 以西結書 37:11; 申命記 11:30"> 祂領我在骸骨間走了一圈，我看到谷中的骸骨相當多，都是枯骨。</span>
<span className="v" id="v3" data-v="3" data-xref="約翰福音 11:25–26; 約翰福音 5:21; 申命記 32:39"> 祂對我說：「人子啊，這些骸骨能復活嗎？」我說：「主耶和華啊，只有你知道。」</span>
<span className="v" id="v4" data-v="4" data-xref="約翰福音 5:25; 約翰福音 5:28–29; 馬太福音 21:21"> 祂又對我說：「你對這些骸骨說預言，『枯骨啊，你們要聽耶和華說的話！</span>
<span className="v" id="v5" data-v="5" data-xref="以西結書 37:14; 詩篇 104:29–30; 創世記 2:7"> 主耶和華對這些骸骨說：我要使氣息進入你們裡面，你們就必復活過來。</span>
<span className="v" id="v6" data-v="6" data-xref="約珥書 2:27; 以賽亞書 49:23; 約珥書 3:17"> 我必給你們加上筋，使你們長出肉，再包上皮，將氣息放在你們裡面，你們就復活了。這樣，你們就知道我是耶和華。』」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="使徒行傳 2:2; 列王紀上 19:11–13; 耶利米書 13:5–7"> 於是，我便按耶和華的吩咐向枯骨說預言，我正說預言的時候，忽然有響聲，是震動的聲音，骨頭便彼此連在了一起。</span>
<span className="v" id="v8" data-v="8"> 我又看見骨頭上有了筋，長了肉，包上了皮，只是還沒有氣息。</span>
<span className="v" id="v9" data-v="9" data-xref="約翰福音 3:8; 雅歌 4:16; 詩篇 104:30"> 耶和華對我說：「人子啊，你要向氣息<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「氣息」希伯來文又作「靈」，「風」。">a</a></sup>說預言，告訴氣息，主耶和華這樣說，『氣息啊，從四方吹來，吹在這些被殺的人身上，使他們復活。』」</span>
<span className="v" id="v10" data-v="10" data-xref="啟示錄 11:11; 詩篇 104:30; 啟示錄 20:4–5"> 於是，我便按耶和華的吩咐說預言，氣息就進入他們裡面，他們便復活了，並且站立起來，成為一支大軍。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="以弗所書 2:1; 詩篇 77:7–9; 以西結書 39:25"> 耶和華對我說：「人子啊，這些骸骨就是所有的以色列人。他們說，『我們骨頭枯乾，希望幻滅，徹底完了。』</span>
<span className="v" id="v12" data-v="12" data-xref="以賽亞書 26:19; 何西阿書 13:14; 帖撒羅尼迦前書 4:16"> 因此，你要說預言，告訴他們，『主耶和華說：我的子民啊，我要打開你們的墳墓，領你們出來，我要領你們返回以色列。</span>
<span className="v" id="v13" data-v="13" data-xref="以西結書 37:6; 以西結書 16:62; 詩篇 126:2–3"> 我的子民啊，當我這樣做的時候，你們就知道我是耶和華。</span>
<span className="v" id="v14" data-v="14" data-xref="以西結書 36:27; 約珥書 2:28–29; 以西結書 36:36"> 我要把我的靈放在你們裡面，使你們復活，安居在自己的土地上，那時你們就知道我耶和華言出必行。這是耶和華說的。』」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15"> 耶和華對我說：</span>
<span className="v" id="v16" data-v="16" data-xref="歷代志下 15:9; 歷代志下 10:19; 歷代志下 10:17"> 「人子啊，你拿一根杖來，寫上『猶大和他的以色列同伴』，然後再拿另一根杖，寫上『約瑟，即以法蓮，與他的以色列同伴』。</span>
<span className="v" id="v17" data-v="17" data-xref="何西阿書 1:11; 耶利米書 50:4; 以賽亞書 11:13"> 然後把這兩根杖連成一根，拿在手中。</span>
<span className="v" id="v18" data-v="18" data-xref="以西結書 24:19; 以西結書 12:9; 以西結書 17:12"> 當你的同胞問你這是什麼意思時，</span>
<span className="v" id="v19" data-v="19" data-xref="撒迦利亞書 10:6; 以西結書 37:16–17; 以弗所書 2:13–14"> 你就告訴他們，主耶和華這樣說，『我要把約瑟和他的以色列同伴的杖，就是以法蓮手中的杖，與猶大的杖連接在一起，在我手中成為一根。』</span>
<span className="v" id="v20" data-v="20" data-xref="以西結書 12:3; 民數記 17:6–9; 何西阿書 12:10"> 你要拿著這兩根寫著字的杖讓他們看，</span>
<span className="v" id="v21" data-v="21" data-xref="以西結書 36:24; 耶利米書 29:14; 耶利米書 23:8"> 告訴他們，主耶和華這樣說，『我要把以色列人從他們流亡的列國領出來，從四圍招聚他們，帶他們回歸故土。</span>
<span className="v" id="v22" data-v="22" data-xref="以西結書 37:24; 以西結書 34:23–24; 耶利米書 3:18"> 我要使他們在以色列的土地和群山上成為一國，只有一位王統治他們，不再是兩個國家，不再分為兩個王國。</span>
<span className="v" id="v23" data-v="23" data-xref="啟示錄 21:3–4; 以西結書 36:28–29; 約翰一書 1:9"> 他們不會再因偶像、可憎之物或任何過犯而玷污自己，我要從他們犯罪的地方把他們救出來，洗淨他們的罪。他們要做我的子民，我要做他們的上帝。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="以西結書 34:23–24; 何西阿書 3:5; 以西結書 37:25"> 「『我的僕人大衛要做王治理他們，成為他們唯一的牧人。他們必恪守我的典章，謹遵我的律例。</span>
<span className="v" id="v25" data-v="25" data-xref="阿摩司書 9:15; 以西結書 37:24; 以西結書 28:25"> 他們要安居在我賜給我僕人雅各的土地上，就是你們祖先居住的地方。他們世世代代都要永遠居住在那裡，我僕人大衛要永遠做他們的王。</span>
<span className="v" id="v26" data-v="26" data-xref="以賽亞書 55:3; 耶利米書 30:19; 以西結書 34:25"> 我要與他們訂立平安之約，是永遠的約，使他們安居，人丁興旺，並且我的聖所要永遠設立在他們當中。</span>
<span className="v" id="v27" data-v="27" data-xref="啟示錄 21:3; 約翰福音 1:14; 以西結書 37:23"> 我要住在他們中間。我要做他們的上帝，他們要做我的子民。</span>
<span className="v" id="v28" data-v="28" data-xref="約翰福音 17:17–19; 以西結書 20:12; 出埃及記 31:13"> 我的聖所永遠設立在他們當中之時，列國便會知道我耶和華使以色列聖潔。』」</span>
</div>
</div>

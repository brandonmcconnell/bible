## 犯罪者必滅亡

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華對我說：</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米書 31:29–30; 耶利米哀歌 5:7; 以西結書 37:11"> 「你們談論以色列地時為什麼說『父親吃了酸葡萄，兒子的牙酸倒了』這句俗語呢？</span>
<span className="v" id="v3" data-v="3" data-xref="以西結書 18:19–20; 以西結書 33:11–20; 以西結書 18:30"> 主耶和華說，我憑我的永恆起誓，你們在以色列必不再用這句俗語。</span>
<span className="v" id="v4" data-v="4" data-xref="以西結書 18:20; 羅馬書 6:23; 民數記 16:22"> 因為所有的生命都屬於我，父和子都屬於我。誰犯罪，誰死亡。</span>
<span className="v" id="v5" data-v="5" data-xref="以西結書 33:14; 約翰一書 3:7; 箴言 21:3"> 「倘若有義人秉公行義，</span>
<span className="v" id="v6" data-v="6" data-xref="以西結書 18:15; 申命記 4:19; 以西結書 6:13"> 不在山上的廟宇裡吃祭物，不拜以色列人的偶像，不玷污別人的妻子，不親近經期中的婦女；</span>
<span className="v" id="v7" data-v="7" data-xref="以西結書 18:16; 出埃及記 22:26; 以西結書 18:12"> 不欺壓人，反而退還債戶的抵押品；不搶奪財物，反而給饑餓的人食物吃，給赤身露體的人衣服穿；</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及記 22:25; 撒迦利亞書 8:16; 申命記 23:19–20"> 不放債取利，不犯罪作惡，反而公平待人，</span>
<span className="v" id="v9" data-v="9" data-xref="以西結書 20:11; 哈巴谷書 2:4; 阿摩司書 5:4"> 遵守我的律例，切實遵行我的典章——這樣的人是義人，必能活著。這是主耶和華說的。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及記 21:12; 約翰一書 3:12; 約翰福音 18:40"> 「倘若這人生的兒子兇殘暴戾，嗜殺成性，無惡不作，</span>
<span className="v" id="v11" data-v="11" data-xref="啟示錄 22:14; 馬太福音 7:21–27; 列王紀上 13:8"> 常在山上的廟宇吃祭偶像之物，玷污別人的妻子，</span>
<span className="v" id="v12" data-v="12" data-xref="以西結書 8:17; 以西結書 8:6; 列王紀下 21:11"> 欺壓貧窮困苦的人，搶奪財物，扣留債戶的抵押品，祭拜偶像，行可憎之事，</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及記 22:25; 利未記 20:9; 以西結書 3:18"> 放債取利，這樣的人還能活著嗎？他必不能活。他多行可憎之事，必自取滅亡，自害己命。</span>
<span className="v" id="v14" data-v="14" data-xref="歷代志下 34:21; 箴言 23:24; 耶利米書 8:6"> 「倘若這不肖子有一個好兒子，他看見父親的所作所為，不願步父親的後塵。</span>
<span className="v" id="v15" data-v="15" data-xref="以西結書 18:6–7; 以西結書 18:11–13"> 他不在山上吃祭偶像之物，不拜以色列人的偶像，不玷污別人的妻子，</span>
<span className="v" id="v16" data-v="16" data-xref="以西結書 18:7; 以賽亞書 58:7–10; 約伯記 22:7"> 不欺壓他人，不扣留抵押品，不搶奪財物，反而給饑餓的人食物吃，給赤身露體的人衣服穿，</span>
<span className="v" id="v17" data-v="17" data-xref="以西結書 18:8–9; 馬太福音 18:27–35; 以西結書 18:13"> 不壓榨貧窮的人，不放債取利，反而遵守我的典章，順從我的律例，這人必不因父親的罪惡而死亡，他必活著。</span>
<span className="v" id="v18" data-v="18" data-xref="以西結書 3:18; 以西結書 18:26; 以西結書 18:24"> 他父親因肆意欺詐，掠奪同胞，多行不義，必死於自己的罪惡。</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及記 20:5; 撒迦利亞書 1:3–6; 申命記 5:9"> 「你們會問，『兒子為什麼不用承擔父親的罪惡呢？』這是因為兒子秉公行義，謹遵我的律例，所以他必活著。</span>
<span className="v" id="v20" data-v="20" data-xref="申命記 24:16; 列王紀下 14:6; 以西結書 18:4"> 誰犯罪，誰死亡，兒子不用承擔父親的罪惡，父親也不用承擔兒子的罪惡。義人的義必歸自己，惡人的惡也必歸自己。</span>
<span className="v" id="v21" data-v="21" data-xref="以西結書 18:27–28; 提多書 2:11–14; 以西結書 33:19"> 「惡人若肯改邪歸正，遵守我的律例，秉公行義，就必活著，不致死亡。</span>
<span className="v" id="v22" data-v="22" data-xref="彌迦書 7:19; 以西結書 33:16; 以賽亞書 43:25"> 他犯的一切罪過不會被追究，他必因行事正直而活著。</span>
<span className="v" id="v23" data-v="23" data-xref="以西結書 33:11; 提摩太前書 2:4; 彼得後書 3:9"> 主耶和華說，我難道喜歡惡人死亡嗎？我豈不是更願他們改邪歸正並活著嗎？</span>
<span className="v" id="v24" data-v="24" data-xref="以西結書 33:18; 箴言 21:16; 約翰二書 1:8"> 義人若棄善行惡，與惡人同流合污，這人豈能活著？他從前的義行不會被記念，他必因自己的背信和罪惡而死亡。</span>
<span className="v" id="v25" data-v="25" data-xref="以西結書 33:17; 瑪拉基書 3:13–15; 瑪拉基書 2:17"> 「你們說，『主行事不公平。』以色列人啊，你們聽著，是我行事不公平呢？還是你們行事不公平呢？</span>
<span className="v" id="v26" data-v="26"> 義人若離義行惡，必因惡行而死。</span>
<span className="v" id="v27" data-v="27" data-xref="以西結書 18:21; 以賽亞書 1:18; 以賽亞書 55:7"> 惡人若改邪歸正、秉公行義，必保全性命。</span>
<span className="v" id="v28" data-v="28" data-xref="申命記 32:29; 路加福音 15:17–18; 雅各書 2:10–12"> 因為他醒悟過來，改邪歸正，必能活著，不致死亡。</span>
<span className="v" id="v29" data-v="29" data-xref="以西結書 18:25; 箴言 19:3; 以西結書 18:2"> 以色列人卻說，『主行事不公平！』以色列人啊，是我行事不公平呢？還是你們行事不公平呢？</span>
<span className="v" id="v30" data-v="30" data-xref="以西結書 18:21; 馬太福音 16:27; 馬太福音 3:2"> 「所以主耶和華說，『以色列人啊，我必按你們各人的行為審判你們。你們要悔改，改邪歸正，免得死在罪中。</span>
<span className="v" id="v31" data-v="31" data-xref="詩篇 51:10; 以西結書 36:26; 以西結書 11:19"> 你們要離棄從前所有的罪惡，洗心革面。以色列人啊！你們何必走向滅亡呢？』</span>
<span className="v" id="v32" data-v="32" data-xref="彼得後書 3:9; 以西結書 18:23; 以西結書 33:11"> 主耶和華說，『我斷不喜歡任何人死亡，你們要悔改，便得存活。』」</span>

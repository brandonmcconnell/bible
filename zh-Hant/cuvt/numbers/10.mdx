## 製銀號

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華曉諭摩西說：</span>
<span className="v" id="v2" data-v="2" data-xref="以賽亞書 1:13; 約珥書 1:14; 詩篇 81:3"> 「你要用銀子做兩枝號，都要錘出來的，用以招聚會眾，並叫眾營起行。</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米書 4:5; 約珥書 2:15–16"> 吹這號的時候，全會眾要到你那裏，聚集在會幕門口。</span>
<span className="v" id="v4" data-v="4" data-xref="民數記 7:2; 出埃及記 18:21; 民數記 1:4–16"> 若單吹一枝，眾首領，就是以色列軍中的統領，要聚集到你那裏。</span>
<span className="v" id="v5" data-v="5" data-xref="民數記 2:3–9; 民數記 10:14; 以賽亞書 58:1"> 吹出大聲的時候，東邊安的營都要起行。</span>
<span className="v" id="v6" data-v="6" data-xref="民數記 10:18; 民數記 2:10–16"> 二次吹出大聲的時候，南邊安的營都要起行。他們將起行，必吹出大聲。</span>
<span className="v" id="v7" data-v="7" data-xref="約珥書 2:1; 民數記 10:3–4"> 但招聚會眾的時候，你們要吹號，卻不要吹出大聲。</span>
<span className="v" id="v8" data-v="8" data-xref="約書亞記 6:4–16; 民數記 31:6; 歷代志上 15:24"> 亞倫子孫作祭司的要吹這號；這要作你們世世代代永遠的定例。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳記上 10:18; 士師記 2:18; 創世記 8:1"> 你們在自己的地，與欺壓你們的敵人打仗，就要用號吹出大聲，便在耶和華－你們的上帝面前得蒙紀念，也蒙拯救脫離仇敵。</span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 81:3; 帖撒羅尼迦前書 4:16; 哥林多前書 11:24–26"> 在你們快樂的日子和節期，並月朔，獻燔祭和平安祭，也要吹號，這都要在你們的上帝面前作為紀念。我是耶和華－你們的上帝。」</span>
</div>
</div>

## 離開西奈山

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="出埃及記 40:17; 民數記 1:1; 民數記 9:11"> 第二年二月二十日，雲彩從法櫃的帳幕收上去。</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 21:21; 民數記 12:16; 民數記 9:5"> 以色列人就按站往前行，離開西奈的曠野，雲彩停住在巴蘭的曠野。</span>
<span className="v" id="v13" data-v="13" data-xref="申命記 1:6; 民數記 9:23"> 這是他們照耶和華藉摩西所吩咐的，初次往前行。</span>
<span className="v" id="v14" data-v="14" data-xref="民數記 2:3–9; 民數記 1:7; 民數記 7:12"> 按着軍隊首先往前行的是猶大營的纛。統領軍隊的是亞米拿達的兒子拿順。</span>
<span className="v" id="v15" data-v="15" data-xref="民數記 7:18; 民數記 1:8"> 統領以薩迦支派軍隊的是蘇押的兒子拿坦業。</span>
<span className="v" id="v16" data-v="16" data-xref="民數記 7:24; 民數記 1:9"> 統領西布倫支派軍隊的是希倫的兒子以利押。</span>
<span className="v" id="v17" data-v="17" data-xref="民數記 7:6–8; 民數記 1:51; 希伯來書 12:28"> 帳幕拆卸，革順的子孫和米拉利的子孫就抬着帳幕先往前行。</span>
<span className="v" id="v18" data-v="18" data-xref="民數記 2:10–16; 民數記 1:5; 民數記 26:5–18"> 按着軍隊往前行的是呂便營的纛。統領軍隊的是示丟珥的兒子以利蓿。</span>
<span className="v" id="v19" data-v="19" data-xref="民數記 1:6; 民數記 7:36"> 統領西緬支派軍隊的是蘇利沙代的兒子示路蔑。</span>
<span className="v" id="v20" data-v="20" data-xref="民數記 1:14; 民數記 2:14; 民數記 7:42"> 統領迦得支派軍隊的是丟珥的兒子以利雅薩。</span>
<span className="v" id="v21" data-v="21" data-xref="民數記 10:17; 民數記 7:9; 民數記 4:4–16"> 哥轄人抬着聖物先往前行。他們未到以前，抬帳幕的已經把帳幕支好。</span>
<span className="v" id="v22" data-v="22" data-xref="民數記 2:18–24; 民數記 1:10; 民數記 26:23–41"> 按着軍隊往前行的是以法蓮營的纛，統領軍隊的是亞米忽的兒子以利沙瑪。</span>
<span className="v" id="v23" data-v="23" data-xref="民數記 1:10; 民數記 7:54"> 統領瑪拿西支派軍隊的是比大蓿的兒子迦瑪列。</span>
<span className="v" id="v24" data-v="24" data-xref="民數記 1:11; 民數記 7:60"> 統領便雅憫支派軍隊的是基多尼的兒子亞比但。</span>
<span className="v" id="v25" data-v="25" data-xref="約書亞記 6:9; 民數記 1:12; 創世記 49:16–17"> 在諸營末後的是但營的纛，按着軍隊往前行。統領軍隊的是亞米沙代的兒子亞希以謝。</span>
<span className="v" id="v26" data-v="26" data-xref="民數記 1:13; 民數記 7:72"> 統領亞設支派軍隊的是俄蘭的兒子帕結。</span>
<span className="v" id="v27" data-v="27" data-xref="民數記 1:15; 民數記 7:78"> 統領拿弗他利支派軍隊的是以南的兒子亞希拉。</span>
<span className="v" id="v28" data-v="28" data-xref="民數記 2:34; 民數記 24:4–5; 哥林多前書 14:33"> 以色列人按着軍隊往前行，就是這樣。</span>
<span className="v" id="v29" data-v="29" data-xref="創世記 12:7; 士師記 4:11; 出埃及記 3:1"> 摩西對他岳父<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或譯：內兄">a</a></sup>－米甸人流珥的兒子何巴－說：「我們要行路，往耶和華所應許之地去；他曾說：『我要將這地賜給你們。』現在求你和我們同去，我們必厚待你，因為耶和華指着以色列人已經應許給好處。」</span>
<span className="v" id="v30" data-v="30" data-xref="路得記 1:15–17; 詩篇 45:10; 馬太福音 21:29"> 何巴回答說：「我不去；我要回本地本族那裏去。」</span>
<span className="v" id="v31" data-v="31" data-xref="約伯記 29:15; 加拉太書 6:2; 哥林多前書 12:14–21"> 摩西說：「求你不要離開我們；因為你知道我們要在曠野安營，你可以當作我們的眼目。</span>
<span className="v" id="v32" data-v="32" data-xref="士師記 1:16; 申命記 10:18; 約翰一書 1:3"> 你若和我們同去，將來耶和華有甚麼好處待我們，我們也必以甚麼好處待你。」</span>
</div>
</div>

## 眾民和約櫃往前行

<div className="bt">
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="申命記 1:33; 出埃及記 3:1; 詩篇 95:11"> 以色列人離開耶和華的山，往前行了三天的路程；耶和華的約櫃在前頭行了三天的路程，為他們尋找安歇的地方。</span>
<span className="v" id="v34" data-v="34" data-xref="尼希米記 9:12; 尼希米記 9:19; 詩篇 105:39"> 他們拔營往前行，日間有耶和華的雲彩在他們以上。</span>
<span className="v" id="v35" data-v="35" data-xref="詩篇 68:1–2; 以賽亞書 17:12–14; 詩篇 132:8"> 約櫃往前行的時候，摩西就說：「耶和華啊，求你興起！願你的仇敵四散！願恨你的人從你面前逃跑！」</span>
<span className="v" id="v36" data-v="36" data-xref="申命記 1:10; 詩篇 90:13–17; 以賽亞書 63:17"> 約櫃停住的時候，他就說：「耶和華啊，求你回到以色列的千萬人中！」</span>
</div>

## 在他備拉發怨言

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民數記 21:5; 民數記 16:35; 列王紀下 1:12"> 眾百姓發怨言，他們的惡語達到耶和華的耳中。耶和華聽見了就怒氣發作，使火在他們中間焚燒，直燒到營的邊界。</span>
<span className="v" id="v2" data-v="2" data-xref="民數記 21:7; 雅各書 5:16; 民數記 16:45–48"> 百姓向摩西哀求，摩西祈求耶和華，火就熄了。</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 9:22"> 那地方便叫做他備拉，因為耶和華的火燒在他們中間。</span>
</div>
</div>

## 摩西選立七十個長老

<div className="bt">
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="哥林多前書 10:6; 出埃及記 12:38; 詩篇 106:14"> 他們中間的閒雜人大起貪慾的心；以色列人又哭號說：「誰給我們肉吃呢？</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 16:3; 詩篇 17:14; 腓立比書 3:19"> 我們記得，在埃及的時候不花錢就吃魚，也記得有黃瓜、西瓜、韭菜、誄、蒜。</span>
<span className="v" id="v6" data-v="6" data-xref="民數記 21:5; 撒母耳記下 13:4"> 現在我們的心血枯竭了，除這嗎哪以外，在我們眼前並沒有別的東西。」</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及記 16:31; 創世記 2:12; 出埃及記 16:14–15"> 這嗎哪彷彿芫荽子，又好像珍珠。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及記 16:31; 出埃及記 16:16–18; 出埃及記 16:23"> 百姓周圍行走，把嗎哪收起來，或用磨推，或用臼搗，煮在鍋中，又做成餅，滋味好像新油。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及記 16:13–14; 詩篇 78:23–25; 申命記 32:2"> 夜間露水降在營中，嗎哪也隨着降下。）</span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 78:21; 民數記 16:27; 民數記 14:1–2"> 摩西聽見百姓各在各家的帳棚門口哭號。耶和華的怒氣便大發作，摩西就不喜悅。</span>
<span className="v" id="v11" data-v="11" data-xref="申命記 1:12; 出埃及記 5:22; 耶利米書 15:10"> 摩西對耶和華說：「你為何苦待僕人？我為何不在你眼前蒙恩，竟把這管理百姓的重任加在我身上呢？</span>
<span className="v" id="v12" data-v="12" data-xref="以賽亞書 49:23; 以賽亞書 40:11; 帖撒羅尼迦前書 2:7"> 這百姓豈是我懷的胎，豈是我生下來的呢？你竟對我說：『把他們抱在懷裏，如養育之父抱吃奶的孩子，直抱到你起誓應許給他們祖宗的地去。』</span>
<span className="v" id="v13" data-v="13" data-xref="馬太福音 15:33; 馬可福音 8:4; 約翰福音 6:5–9"> 我從哪裏得肉給這百姓吃呢？他們都向我哭號說：『你給我們肉吃吧！』</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及記 18:18; 申命記 1:9–12; 哥林多後書 2:16"> 管理這百姓的責任太重了，我獨自擔當不起。</span>
<span className="v" id="v15" data-v="15" data-xref="腓立比書 1:20–24; 列王紀上 19:4; 約拿書 4:3"> 你這樣待我，我若在你眼前蒙恩，求你立時將我殺了，不叫我見自己的苦情。」</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 24:1; 出埃及記 24:9; 申命記 16:18"> 耶和華對摩西說：「你從以色列的長老中招聚七十個人，就是你所知道作百姓的長老和官長的，到我這裏來，領他們到會幕前，使他們和你一同站立。</span>
<span className="v" id="v17" data-v="17" data-xref="民數記 11:25; 撒母耳記上 10:6; 哥林多前書 12:4–11"> 我要在那裏降臨，與你說話，也要把降於你身上的靈分賜他們，他們就和你同當這管百姓的重任，免得你獨自擔當。</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及記 19:10; 使徒行傳 7:39; 出埃及記 16:3–7"> 又要對百姓說：『你們應當自潔，預備明天吃肉，因為你們哭號說：誰給我們肉吃！我們在埃及很好。這聲音達到了耶和華的耳中，所以他必給你們肉吃。</span>
<span className="v" id="v19" data-v="19"> 你們不止吃一天、兩天、五天、十天、二十天，</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 106:15; 民數記 21:5; 詩篇 78:27–30"> 要吃一個整月，甚至肉從你們鼻孔裏噴出來，使你們厭惡了，因為你們厭棄住在你們中間的耶和華，在他面前哭號說：我們為何出了埃及呢！』」</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及記 12:37; 民數記 1:46; 創世記 12:2"> 摩西對耶和華說：「這與我同住的百姓、步行的男人有六十萬，你還說：『我要把肉給他們，使他們可以吃一個整月。』</span>
<span className="v" id="v22" data-v="22" data-xref="馬太福音 15:33; 列王紀下 7:2; 約翰福音 6:9"> 難道給他們宰了羊群牛群，或是把海中所有的魚都聚了來，就夠他們吃嗎？」</span>
<span className="v" id="v23" data-v="23" data-xref="以賽亞書 59:1; 以賽亞書 50:2; 創世記 18:14"> 耶和華對摩西說：「耶和華的膀臂豈是縮短了嗎？現在要看我的話向你應驗不應驗。」</span>
<span className="v" id="v24" data-v="24" data-xref="民數記 11:16; 民數記 11:26"> 摩西出去，將耶和華的話告訴百姓，又招聚百姓的長老中七十個人來，使他們站在會幕的四圍。</span>
<span className="v" id="v25" data-v="25" data-xref="民數記 11:17; 約珥書 2:28–29; 撒母耳記上 10:10"> 耶和華在雲中降臨，對摩西說話，把降與他身上的靈分賜那七十個長老。靈停在他們身上的時候，他們就受感說話，以後卻沒有再說。</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米書 36:5; 撒母耳記上 20:26; 撒母耳記上 10:22"> 但有兩個人仍在營裏，一個名叫伊利達，一個名叫米達。他們本是在那些被錄的人中，卻沒有到會幕那裏去。靈停在他們身上，他們就在營裏說預言。</span>
<span className="v" id="v27" data-v="27"> 有個少年人跑來告訴摩西說：「伊利達、米達在營裏說預言。」</span>
<span className="v" id="v28" data-v="28" data-xref="馬可福音 9:38–40; 路加福音 9:49–50; 約翰福音 3:26"> 摩西的幫手，嫩的兒子約書亞，就是摩西所揀選的一個人，說：「請我主摩西禁止他們。」</span>
<span className="v" id="v29" data-v="29" data-xref="哥林多前書 14:5; 馬太福音 9:37–38; 路加福音 10:2"> 摩西對他說：「你為我的緣故嫉妒人嗎？惟願耶和華的百姓都受感說話！願耶和華把他的靈降在他們身上！」</span>
<span className="v" id="v30" data-v="30"> 於是，摩西和以色列的長老都回到營裏去。</span>
</div>
</div>

## 上帝賜鵪鶉為食物

<div className="bt">
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="出埃及記 16:13; 詩篇 105:40; 詩篇 78:26–29"> 有風從耶和華那裏颳起，把鵪鶉由海面颳來，飛散在營邊和營的四圍；這邊約有一天的路程，那邊約有一天的路程，離地面約有二肘。</span>
<span className="v" id="v32" data-v="32" data-xref="以西結書 45:11; 出埃及記 16:36"> 百姓起來，終日終夜，並次日一整天，捕取鵪鶉；至少的也取了十賀梅珥，為自己擺列在營的四圍。</span>
<span className="v" id="v33" data-v="33" data-xref="詩篇 78:30–31; 詩篇 106:14–15; 民數記 25:9"> 肉在他們牙齒之間尚未嚼爛，耶和華的怒氣就向他們發作，用最重的災殃擊殺了他們。</span>
<span className="v" id="v34" data-v="34" data-xref="申命記 9:22; 哥林多前書 10:6; 民數記 33:16"> 那地方便叫做基博羅‧哈他瓦<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="就是貪慾之人的墳墓">a</a></sup>，因為他們在那裏葬埋那起貪慾之心的人。</span>
<span className="v" id="v35" data-v="35" data-xref="民數記 33:17; 民數記 12:16; 申命記 1:1"> 百姓從基博羅‧哈他瓦走到哈洗錄，就住在哈洗錄。</span>
</div>

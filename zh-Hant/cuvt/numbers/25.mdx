## 以色列人在毗珥

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多前書 10:8; 民數記 33:49; 約書亞記 2:1"> 以色列人住在什亭，百姓與摩押女子行起淫亂。</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多前書 10:20; 出埃及記 20:5; 出埃及記 34:15–16"> 因為這女子叫百姓來，一同給她們的神獻祭，百姓就吃她們的祭物，跪拜她們的神。</span>
<span className="v" id="v3" data-v="3" data-xref="約書亞記 22:17; 詩篇 106:28–29; 何西阿書 9:10"> 以色列人與巴力‧毗珥連合，耶和華的怒氣就向以色列人發作。</span>
<span className="v" id="v4" data-v="4" data-xref="申命記 13:17; 申命記 4:3; 申命記 21:23"> 耶和華吩咐摩西說：「將百姓中所有的族長在我面前對着日頭懸掛，使我向以色列人所發的怒氣可以消了。」</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 18:21; 列王紀上 18:40; 申命記 13:9"> 於是摩西吩咐以色列的審判官說：「凡屬你們的人，有與巴力‧毗珥連合的，你們各人要把他們殺了。」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="約珥書 2:17; 民數記 22:4; 耶利米書 36:23"> 摩西和以色列全會眾正在會幕門前哭泣的時候，誰知，有以色列中的一個人，當他們眼前，帶着一個米甸女人到他弟兄那裏去。</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及記 6:25; 詩篇 106:30; 約書亞記 22:30–31"> 祭司亞倫的孫子，以利亞撒的兒子非尼哈看見了，就從會中起來，手裏拿着槍，</span>
<span className="v" id="v8" data-v="8" data-xref="民數記 16:46–48; 詩篇 106:29–31; 歷代志上 21:22"> 跟隨那以色列人進亭子裏去，便將以色列人和那女人由腹中刺透。這樣，在以色列人中瘟疫就止息了。</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多前書 10:8; 申命記 4:3–4; 民數記 25:4–5"> 那時遭瘟疫死的，有二萬四千人。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10"> 耶和華曉諭摩西說：</span>
<span className="v" id="v11" data-v="11" data-xref="申命記 32:21; 詩篇 78:58; 申命記 32:16"> 「祭司亞倫的孫子，以利亞撒的兒子非尼哈，使我向以色列人所發的怒消了；因他在他們中間，以我的忌邪為心，使我不在忌邪中把他們除滅。</span>
<span className="v" id="v12" data-v="12" data-xref="瑪拉基書 2:4–5; 瑪拉基書 3:1; 以賽亞書 54:10"> 因此，你要說：『我將我平安的約賜給他。</span>
<span className="v" id="v13" data-v="13" data-xref="希伯來書 2:17; 羅馬書 10:2–4; 耶利米書 33:22"> 這約要給他和他的後裔，作為永遠當祭司職任的約；因他為上帝有忌邪的心，為以色列人贖罪。』」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="民數記 1:23; 民數記 26:14; 歷代志下 19:7"> 那與米甸女人一同被殺的以色列人，名叫心利，是撒路的兒子，是西緬一個宗族的首領。</span>
<span className="v" id="v15" data-v="15" data-xref="民數記 31:8; 約書亞記 13:21; 民數記 25:18"> 那被殺的米甸女人，名叫哥斯比，是蘇珥的女兒；這蘇珥是米甸一個宗族的首領。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16"> 耶和華曉諭摩西說：</span>
<span className="v" id="v17" data-v="17" data-xref="民數記 31:1–3; 啟示錄 18:6"> 「你要擾害米甸人，擊殺他們；</span>
<span className="v" id="v18" data-v="18" data-xref="啟示錄 2:14; 出埃及記 32:35; 哥林多後書 11:3"> 因為他們用詭計擾害你們，在毗珥的事上和他們的姊妹、米甸首領的女兒哥斯比的事上，用這詭計誘惑了你們；這哥斯比，當瘟疫流行的日子，因毗珥的事被殺了。」</span>
</div>
</div>

## 各支派在營地的位置

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華曉諭摩西、亞倫說：</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多前書 14:40; 民數記 10:22; 民數記 1:50"> 「以色列人要各歸自己的纛下，在本族的旗號那裏，對着會幕的四圍安營。</span>
<span className="v" id="v3" data-v="3" data-xref="歷代志上 2:10; 路得記 4:20; 路加福音 3:32–33"> 在東邊，向日出之地，照着軍隊安營的是猶大營的纛。有亞米拿達的兒子拿順作猶大人的首領。</span>
<span className="v" id="v4" data-v="4" data-xref="民數記 26:22; 民數記 1:27"> 他軍隊被數的，共有七萬四千六百名。</span>
<span className="v" id="v5" data-v="5" data-xref="民數記 1:8; 民數記 7:18; 民數記 7:23"> 挨着他安營的是以薩迦支派。有蘇押的兒子拿坦業作以薩迦人的首領。</span>
<span className="v" id="v6" data-v="6" data-xref="民數記 26:25; 民數記 1:29"> 他軍隊被數的，共有五萬四千四百名。</span>
<span className="v" id="v7" data-v="7" data-xref="民數記 1:9; 民數記 7:24; 民數記 10:16"> 又有西布倫支派。希倫的兒子以利押作西布倫人的首領。</span>
<span className="v" id="v8" data-v="8" data-xref="民數記 26:26–27; 民數記 1:31"> 他軍隊被數的，共有五萬七千四百名。</span>
<span className="v" id="v9" data-v="9" data-xref="民數記 10:14"> 凡屬猶大營、按着軍隊被數的，共有十八萬六千四百名，要作第一隊往前行。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="民數記 1:5; 創世記 49:3–4; 民數記 7:35"> 「在南邊，按着軍隊是呂便營的纛。有示丟珥的兒子以利蓿作呂便人的首領。</span>
<span className="v" id="v11" data-v="11" data-xref="民數記 26:7; 民數記 1:21"> 他軍隊被數的，共有四萬六千五百名。</span>
<span className="v" id="v12" data-v="12" data-xref="民數記 1:6; 民數記 10:19; 民數記 7:41"> 挨着他安營的是西緬支派。蘇利沙代的兒子示路蔑作西緬人的首領。</span>
<span className="v" id="v13" data-v="13" data-xref="民數記 26:14; 民數記 1:23"> 他軍隊被數的，共有五萬九千三百名。</span>
<span className="v" id="v14" data-v="14" data-xref="民數記 1:14; 民數記 7:42; 民數記 7:47"> 又有迦得支派。丟珥的兒子以利雅薩作迦得人的首領。</span>
<span className="v" id="v15" data-v="15" data-xref="民數記 26:18; 民數記 1:25"> 他軍隊被數的，共有四萬五千六百五十名，</span>
<span className="v" id="v16" data-v="16" data-xref="民數記 10:18; 民數記 2:9; 民數記 2:24"> 凡屬呂便營、按着軍隊被數的，共有十五萬一千四百五十名，要作第二隊往前行。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="民數記 10:21; 民數記 10:17; 民數記 3:38"> 「隨後，會幕要往前行，有利未營在諸營中間。他們怎樣安營就怎樣往前行，各按本位，各歸本纛。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="民數記 1:10; 民數記 10:22; 創世記 48:14–20"> 「在西邊，按着軍隊是以法蓮營的纛。亞米忽的兒子以利沙瑪作以法蓮人的首領。</span>
<span className="v" id="v19" data-v="19" data-xref="民數記 1:33; 民數記 26:37"> 他軍隊被數的，共有四萬零五百名。</span>
<span className="v" id="v20" data-v="20" data-xref="民數記 1:10; 民數記 7:54; 民數記 10:23"> 挨着他的是瑪拿西支派。比大蓿的兒子迦瑪列作瑪拿西人的首領。</span>
<span className="v" id="v21" data-v="21" data-xref="民數記 26:34; 民數記 1:35"> 他軍隊被數的，共有三萬二千二百名。</span>
<span className="v" id="v22" data-v="22" data-xref="民數記 1:11; 民數記 7:60; 民數記 10:24"> 又有便雅憫支派。基多尼的兒子亞比但作便雅憫人的首領。</span>
<span className="v" id="v23" data-v="23" data-xref="民數記 1:37; 民數記 26:41"> 他軍隊被數的，共有三萬五千四百名。</span>
<span className="v" id="v24" data-v="24" data-xref="民數記 10:22; 民數記 2:31; 詩篇 80:2"> 凡屬以法蓮營、按着軍隊被數的，共有十萬零八千一百名，要作第三隊往前行。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="民數記 1:12; 民數記 7:66; 民數記 10:25"> 「在北邊，按着軍隊是但營的纛。亞米沙代的兒子亞希以謝作但人的首領。</span>
<span className="v" id="v26" data-v="26" data-xref="民數記 26:43; 民數記 1:39"> 他軍隊被數的，共有六萬二千七百名。</span>
<span className="v" id="v27" data-v="27" data-xref="民數記 1:13; 民數記 7:77; 民數記 7:72"> 挨着他安營的是亞設支派。俄蘭的兒子帕結作亞設人的首領。</span>
<span className="v" id="v28" data-v="28" data-xref="民數記 1:41; 民數記 26:47"> 他軍隊被數的，共有四萬一千五百名。</span>
<span className="v" id="v29" data-v="29" data-xref="民數記 1:15; 民數記 10:27; 民數記 26:48–50"> 又有拿弗他利支派。以南的兒子亞希拉作拿弗他利人的首領。</span>
<span className="v" id="v30" data-v="30" data-xref="民數記 1:42–43; 民數記 26:50"> 他軍隊被數的，共有五萬三千四百名。</span>
<span className="v" id="v31" data-v="31" data-xref="民數記 10:25; 民數記 2:16; 民數記 2:9"> 凡但營被數的，共有十五萬七千六百名，要歸本纛作末隊往前行。」</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="民數記 1:46; 出埃及記 38:26; 民數記 2:9"> 這些以色列人，照他們的宗族，按他們的軍隊，在諸營中被數的，共有六十萬零三千五百五十名。</span>
<span className="v" id="v33" data-v="33" data-xref="民數記 26:57–62; 民數記 1:47–49"> 惟獨利未人沒有數在以色列人中，是照耶和華所吩咐摩西的。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="詩篇 119:6; 民數記 24:2; 民數記 24:5–6"> 以色列人就這樣行，各人照他們的家室、宗族歸於本纛，安營起行，都是照耶和華所吩咐摩西的。</span>
</div>
</div>

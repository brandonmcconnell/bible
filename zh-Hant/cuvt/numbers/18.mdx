## 祭司和利未人的職責

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及記 28:38; 希伯來書 13:17; 彼得前書 2:24"> 耶和華對亞倫說：「你和你的兒子，並你本族的人，要一同擔當干犯聖所的罪孽。你和你的兒子也要一同擔當干犯祭司職任的罪孽。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 29:34; 民數記 18:4; 以西結書 44:15"> 你要帶你弟兄利未人，就是你祖宗支派的人前來，使他們與你聯合，服事你，只是你和你的兒子，要一同在法櫃的帳幕前供職。</span>
<span className="v" id="v3" data-v="3" data-xref="民數記 4:15; 民數記 16:40; 民數記 4:19–20"> 他們要守所吩咐你的，並守全帳幕，只是不可挨近聖所的器具和壇，免得他們和你們都死亡。</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳記上 6:19; 民數記 1:51; 民數記 3:10"> 他們要與你聯合，也要看守會幕，辦理帳幕一切的事，只是外人不可挨近你們。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 27:21; 利未記 24:3; 民數記 16:46"> 你們要看守聖所和壇，免得忿怒再臨到以色列人。</span>
<span className="v" id="v6" data-v="6" data-xref="民數記 3:9; 民數記 3:12; 民數記 3:45"> 我已將你們的弟兄利未人從以色列人中揀選出來歸耶和華，是給你們為賞賜的，為要辦理會幕的事。</span>
<span className="v" id="v7" data-v="7" data-xref="羅馬書 15:15–16; 約翰福音 3:27; 民數記 3:10"> 你和你的兒子要為一切屬壇和幔子內的事一同守祭司的職任。你們要這樣供職；我將祭司的職任給你們當作賞賜事奉我。凡挨近的外人必被治死。」</span>
</div>
</div>

## 祭司當得之物

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="利未記 6:16; 利未記 7:6; 出埃及記 29:29"> 耶和華曉諭亞倫說：「我已將歸我的舉祭，就是以色列人一切分別為聖的物，交給你經管；因你受過膏，把這些都賜給你和你的子孫，當作永得的分。</span>
<span className="v" id="v9" data-v="9" data-xref="利未記 7:7; 利未記 14:13; 利未記 6:25–26"> 以色列人歸給我至聖的供物，就是一切的素祭、贖罪祭、贖愆祭，其中所有存留不經火的，都為至聖之物，要歸給你和你的子孫。</span>
<span className="v" id="v10" data-v="10" data-xref="利未記 7:6; 利未記 6:29; 利未記 6:16"> 你要拿這些當至聖物吃；凡男丁都可以吃。你當以此物為聖。</span>
<span className="v" id="v11" data-v="11" data-xref="申命記 18:3; 出埃及記 29:27–28; 利未記 10:14"> 以色列人所獻的舉祭並搖祭都是你的；我已賜給你和你的兒女，當作永得的分；凡在你家中的潔淨人都可以吃。</span>
<span className="v" id="v12" data-v="12" data-xref="申命記 18:4; 出埃及記 23:19; 出埃及記 34:26"> 凡油中、新酒中、五穀中至好的，就是以色列人所獻給耶和華初熟之物，我都賜給你。</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及記 22:29; 出埃及記 23:19; 彌迦書 7:1"> 凡從他們地上所帶來給耶和華初熟之物也都要歸與你。你家中的潔淨人都可以吃。</span>
<span className="v" id="v14" data-v="14" data-xref="利未記 27:28; 以西結書 44:29"> 以色列中一切永獻的都必歸與你。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及記 34:20; 出埃及記 13:2; 出埃及記 13:12–13"> 他們所有奉給耶和華的，連人帶牲畜，凡頭生的，都要歸給你；只是人頭生的，總要贖出來；不潔淨牲畜頭生的，也要贖出來。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 30:13; 民數記 3:47; 利未記 27:2–7"> 其中在一月之外所當贖的，要照你所估定的價，按聖所的平，用銀子五舍客勒贖出來（一舍客勒是二十季拉）。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及記 29:16; 申命記 15:19–22; 利未記 3:2–5"> 只是頭生的牛，或是頭生的綿羊和山羊，必不可贖，都是聖的，要把牠的血灑在壇上，把牠的脂油焚燒，當作馨香的火祭獻給耶和華。</span>
<span className="v" id="v18" data-v="18" data-xref="利未記 7:31–34; 出埃及記 29:26–28"> 牠的肉必歸你，像被搖的胸、被舉的右腿歸你一樣。</span>
<span className="v" id="v19" data-v="19" data-xref="歷代志下 13:5; 利未記 2:13; 民數記 18:11"> 凡以色列人所獻給耶和華聖物中的舉祭，我都賜給你和你的兒女，當作永得的分。這是給你和你的後裔、在耶和華面前作為永遠的鹽約<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="鹽就是不廢壞的意思">a</a></sup>。」</span>
<span className="v" id="v20" data-v="20" data-xref="以西結書 44:28; 申命記 10:9; 約書亞記 13:33"> 耶和華對亞倫說：「你在以色列人的境內不可有產業，在他們中間也不可有分。我就是你的分，是你的產業。」</span>
</div>
</div>

## 利未人的分

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="尼希米記 12:44; 申命記 14:22–29; 尼希米記 10:37"> 「凡以色列中出產的十分之一，我已賜給利未的子孫為業；因他們所辦的是會幕的事，所以賜給他們為酬他們的勞。</span>
<span className="v" id="v22" data-v="22" data-xref="利未記 22:9; 民數記 1:51–52; 民數記 3:38"> 從今以後，以色列人不可挨近會幕，免得他們擔罪而死。</span>
<span className="v" id="v23" data-v="23" data-xref="民數記 3:7; 民數記 18:20; 民數記 18:1"> 惟獨利未人要辦會幕的事，擔當罪孽；這要作你們世世代代永遠的定例。他們在以色列人中不可有產業；</span>
<span className="v" id="v24" data-v="24" data-xref="民數記 18:26; 瑪拉基書 3:8–10"> 因為以色列人中出產的十分之一，就是獻給耶和華為舉祭的，我已賜給利未人為業。所以我對他們說：『在以色列人中不可有產業。』」</span>
</div>
</div>

## 利未人的十分之一奉獻

<div className="bt">
<div className="bp">
<span className="v" id="v25" data-v="25"> 耶和華吩咐摩西說：</span>
<span className="v" id="v26" data-v="26" data-xref="尼希米記 10:38; 民數記 18:21"> 「你曉諭利未人說：你們從以色列人中所取的十分之一，就是我給你們為業的，要再從那十分之一中取十分之一作為舉祭獻給耶和華，</span>
<span className="v" id="v27" data-v="27" data-xref="民數記 18:30; 申命記 15:14; 列王紀下 6:27"> 這舉祭要算為你們場上的穀，又如滿酒醡的酒。</span>
<span className="v" id="v28" data-v="28" data-xref="希伯來書 6:20–10; 創世記 14:18"> 這樣，你們從以色列人中所得的十分之一也要作舉祭獻給耶和華，從這十分之一中，將所獻給耶和華的舉祭歸給祭司亞倫。</span>
<span className="v" id="v29" data-v="29"> 奉給你們的一切禮物，要從其中將至好的，就是分別為聖的，獻給耶和華為舉祭。</span>
<span className="v" id="v30" data-v="30" data-xref="箴言 3:9–10; 創世記 43:11; 馬太福音 6:33"> 所以你要對利未人說：你們從其中將至好的舉起，這就算為你們場上的糧，又如酒醡的酒。</span>
<span className="v" id="v31" data-v="31" data-xref="哥林多前書 9:10–14; 提摩太前書 5:17–18; 路加福音 10:7"> 你們和你們家屬隨處可以吃；這原是你們的賞賜，是酬你們在會幕裏辦事的勞。</span>
<span className="v" id="v32" data-v="32" data-xref="利未記 19:8; 利未記 22:2; 瑪拉基書 1:7"> 你們從其中將至好的舉起，就不致因這物擔罪。你們不可褻瀆以色列人的聖物，免得死亡。」</span>
</div>
</div>

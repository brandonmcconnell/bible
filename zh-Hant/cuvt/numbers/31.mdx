## 跟米甸人打仗

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華吩咐摩西說：</span>
<span className="v" id="v2" data-v="2" data-xref="民數記 27:13; 民數記 25:14–18; 啟示錄 6:10"> 「你要在米甸人身上報以色列人的仇，後來要歸到你列祖<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是本民">a</a></sup>那裏。」</span>
<span className="v" id="v3" data-v="3" data-xref="利未記 26:25; 民數記 25:11; 列王紀下 10:30"> 摩西吩咐百姓說：「要從你們中間叫人帶兵器出去攻擊米甸，好在米甸人身上為耶和華報仇。</span>
<span className="v" id="v4" data-v="4" data-xref="利未記 26:8; 撒母耳記上 14:6; 士師記 7:2"> 從以色列眾支派中，每支派要打發一千人去打仗。」</span>
<span className="v" id="v5" data-v="5"> 於是從以色列千萬人中，每支派交出一千人，共一萬二千人，帶着兵器預備打仗。</span>
<span className="v" id="v6" data-v="6" data-xref="民數記 14:44; 民數記 10:8–9; 歷代志下 13:12–15"> 摩西就打發每支派的一千人去打仗，並打發祭司以利亞撒的兒子非尼哈同去；非尼哈手裏拿着聖所的器皿和吹大聲的號筒。</span>
<span className="v" id="v7" data-v="7" data-xref="士師記 21:11; 列王紀上 11:15–16; 撒母耳記上 27:9"> 他們就照耶和華所吩咐摩西的，與米甸人打仗，殺了所有的男丁。</span>
<span className="v" id="v8" data-v="8" data-xref="約書亞記 13:21–22; 民數記 25:15; 啟示錄 2:14"> 在所殺的人中，殺了米甸的五王，就是以未、利金、蘇珥、戶珥、利巴，又用刀殺了比珥的兒子巴蘭。</span>
<span className="v" id="v9" data-v="9" data-xref="申命記 20:14; 歷代志下 28:8–10; 歷代志下 28:5"> 以色列人擄了米甸人的婦女孩子，並將他們的牲畜、羊群，和所有的財物都奪了來，當作擄物，</span>
<span className="v" id="v10" data-v="10" data-xref="以賽亞書 1:7; 撒母耳記上 30:1; 約書亞記 6:24"> 又用火焚燒他們所住的城邑和所有的營寨，</span>
<span className="v" id="v11" data-v="11" data-xref="申命記 20:14; 約書亞記 8:2"> 把一切所奪的、所擄的，連人帶牲畜都帶了去，</span>
<span className="v" id="v12" data-v="12" data-xref="民數記 22:1"> 將所擄的人，所奪的牲畜、財物，都帶到摩押平原，在約旦河邊與耶利哥相對的營盤，交給摩西和祭司以利亞撒，並以色列的會眾。</span>
</div>
</div>

## 打仗回來

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="民數記 5:2; 撒母耳記上 30:21; 民數記 31:12"> 摩西和祭司以利亞撒，並會眾一切的首領，都出到營外迎接他們。</span>
<span className="v" id="v14" data-v="14" data-xref="列王紀下 13:19; 撒母耳記上 15:13–14; 民數記 31:48"> 摩西向打仗回來的軍長，就是千夫長、百夫長，發怒，</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳記上 15:3; 耶利米書 48:10; 申命記 2:34"> 對他們說：「你們要存留這一切婦女的活命嗎？</span>
<span className="v" id="v16" data-v="16" data-xref="民數記 25:1–9; 彼得後書 2:15; 啟示錄 2:14"> 這些婦女因巴蘭的計謀，叫以色列人在毗珥的事上得罪耶和華，以致耶和華的會眾遭遇瘟疫。</span>
<span className="v" id="v17" data-v="17" data-xref="士師記 21:11–12; 申命記 20:16–18; 申命記 7:2"> 所以，你們要把一切的男孩和所有已嫁的女子都殺了。</span>
<span className="v" id="v18" data-v="18" data-xref="申命記 21:10–14; 歷代志下 28:8–10; 申命記 20:14"> 但女孩子中，凡沒有出嫁的，你們都可以存留她的活命。</span>
<span className="v" id="v19" data-v="19" data-xref="民數記 19:11–22; 民數記 5:2; 歷代志上 22:8"> 你們要在營外駐紮七日；凡殺了人的，和一切摸了被殺的，並你們所擄來的人口，第三日，第七日，都要潔淨自己，</span>
<span className="v" id="v20" data-v="20" data-xref="民數記 19:22; 創世記 35:2; 出埃及記 19:10"> 也要因一切的衣服、皮物、山羊毛織的物，和各樣的木器，潔淨自己。」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="民數記 30:16"> 祭司以利亞撒對打仗回來的兵丁說：「耶和華所吩咐摩西律法中的條例乃是這樣：</span>
<span className="v" id="v22" data-v="22"> 金、銀、銅、鐵、錫、鉛，</span>
<span className="v" id="v23" data-v="23" data-xref="民數記 19:9; 民數記 19:17; 哥林多前書 3:13"> 凡能見火的，你們要叫它經火就為潔淨，然而還要用除污穢的水潔淨它；凡不能見火的，你們要叫它過水。</span>
<span className="v" id="v24" data-v="24" data-xref="利未記 11:25; 利未記 15:13; 利未記 14:9"> 第七日，你們要洗衣服，就為潔淨，然後可以進營。」</span>
</div>
</div>

## 分戰利品

<div className="bt">
<div className="bp">
<span className="v" id="v25" data-v="25"> 耶和華曉諭摩西說：</span>
<span className="v" id="v26" data-v="26"> 「你和祭司以利亞撒，並會眾的各族長，要計算所擄來的人口和牲畜的總數。</span>
<span className="v" id="v27" data-v="27" data-xref="約書亞記 22:8; 詩篇 68:12; 撒母耳記上 30:24–25"> 把所擄來的分作兩半：一半歸與出去打仗的精兵，一半歸與全會眾。</span>
<span className="v" id="v28" data-v="28" data-xref="民數記 18:26; 民數記 31:30; 民數記 31:47"> 又要從出去打仗所得的人口、牛、驢、羊群中，每五百取一，作為貢物奉給耶和華。</span>
<span className="v" id="v29" data-v="29" data-xref="出埃及記 29:27; 申命記 12:19; 申命記 12:12"> 從他們一半之中，要取出來交給祭司以利亞撒，作為耶和華的舉祭。</span>
<span className="v" id="v30" data-v="30" data-xref="民數記 3:31; 民數記 3:7–8; 民數記 3:25"> 從以色列人的一半之中，就是從人口、牛、驢、羊群、各樣牲畜中，每五十取一，交給看守耶和華帳幕的利未人。」</span>
<span className="v" id="v31" data-v="31"> 於是摩西和祭司以利亞撒照耶和華所吩咐摩西的行了。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32"> 除了兵丁所奪的財物以外，所擄來的：羊六十七萬五千隻；</span>
<span className="v" id="v33" data-v="33"> 牛七萬二千隻；</span>
<span className="v" id="v34" data-v="34"> 驢六萬一千匹；</span>
<span className="v" id="v35" data-v="35"> 女人共三萬二千口，都是沒有出嫁的。</span>
<span className="v" id="v36" data-v="36"> 出去打仗之人的分，就是他們所得的那一半，共計羊三十三萬七千五百隻，</span>
<span className="v" id="v37" data-v="37"> 從其中歸耶和華為貢物的，有六百七十五隻；</span>
<span className="v" id="v38" data-v="38"> 牛三萬六千隻，從其中歸耶和華為貢物的，有七十二隻；</span>
<span className="v" id="v39" data-v="39"> 驢三萬零五百匹，從其中歸耶和華為貢物的，有六十一匹；</span>
<span className="v" id="v40" data-v="40"> 人一萬六千口，從其中歸耶和華的，有三十二口。</span>
<span className="v" id="v41" data-v="41" data-xref="民數記 18:8; 民數記 18:19; 希伯來書 7:9–12"> 摩西把貢物，就是歸與耶和華的舉祭，交給祭司以利亞撒，是照耶和華所吩咐摩西的。</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42"> 以色列人所得的那一半，就是摩西從打仗的人取來分給他們的。（</span>
<span className="v" id="v43" data-v="43"> 會眾的那一半有：羊三十三萬七千五百隻；</span>
<span className="v" id="v44" data-v="44"> 牛三萬六千隻；</span>
<span className="v" id="v45" data-v="45"> 驢三萬零五百匹；</span>
<span className="v" id="v46" data-v="46"> 人一萬六千口。）</span>
<span className="v" id="v47" data-v="47" data-xref="民數記 31:30; 路加福音 10:1–8; 以賽亞書 56:10–11"> 無論是人口是牲畜，摩西每五十取一，交給看守耶和華帳幕的利未人，是照耶和華所吩咐摩西的。</span>
</div>
<div className="bp">
<span className="v" id="v48" data-v="48"> 帶領千軍的各軍長，就是千夫長、百夫長，都近前來見摩西，</span>
<span className="v" id="v49" data-v="49" data-xref="約翰福音 18:9; 撒母耳記上 30:18–19; 詩篇 72:14"> 對他說：「僕人權下的兵已經計算總數，並不短少一人。</span>
<span className="v" id="v50" data-v="50" data-xref="出埃及記 30:12; 出埃及記 30:15–16; 詩篇 116:12"> 如今我們將各人所得的金器，就是腳鍊子、鐲子、打印的戒指、耳環、手釧，都送來為耶和華的供物，好在耶和華面前為我們的生命贖罪。」</span>
<span className="v" id="v51" data-v="51" data-xref="民數記 7:2–6"> 摩西和祭司以利亞撒就收了他們的金子，都是打成的器皿。</span>
<span className="v" id="v52" data-v="52"> 千夫長、百夫長所獻給耶和華為舉祭的金子共有一萬六千七百五十舍客勒。</span>
<span className="v" id="v53" data-v="53" data-xref="申命記 20:14; 民數記 31:32"> 各兵丁都為自己奪了財物。</span>
<span className="v" id="v54" data-v="54" data-xref="出埃及記 30:16; 撒迦利亞書 6:14; 使徒行傳 10:4"> 摩西和祭司以利亞撒收了千夫長、百夫長的金子，就帶進會幕，在耶和華面前作為以色列人的紀念。</span>
</div>
</div>

## 第二個逾越節

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民數記 1:1; 出埃及記 40:2"> 以色列人出埃及地以後，第二年正月，耶和華在西奈的曠野吩咐摩西說：</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 16:1–2; 哥林多前書 5:7–8; 歷代志下 35:1"> 「以色列人應當在所定的日期守逾越節，</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 12:6–11; 利未記 23:5; 歷代志下 30:2"> 就是本月十四日黃昏的時候，你們要在所定的日期守這節，要按這節的律例典章而守。」</span>
<span className="v" id="v4" data-v="4"> 於是摩西吩咐以色列人守逾越節。</span>
<span className="v" id="v5" data-v="5" data-xref="約書亞記 5:10; 馬太福音 28:20; 出埃及記 12:1–13"> 他們就在西奈的曠野，正月十四日黃昏的時候，守逾越節。凡耶和華所吩咐摩西的，以色列人都照樣行了。</span>
<span className="v" id="v6" data-v="6" data-xref="民數記 27:2; 出埃及記 18:15; 民數記 5:2"> 有幾個人因死屍而不潔淨，不能在那日守逾越節。當日他們到摩西、亞倫面前，</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 16:2; 哥林多前書 5:7–8; 出埃及記 12:27"> 說：「我們雖因死屍而不潔淨，為何被阻止、不得同以色列人在所定的日期獻耶和華的供物呢？」</span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 85:8; 民數記 27:5; 哥林多前書 4:4"> 摩西對他們說：「你們暫且等候，我可以去聽耶和華指着你們是怎樣吩咐的。」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9"> 耶和華對摩西說：</span>
<span className="v" id="v10" data-v="10" data-xref="以弗所書 2:1–2; 以弗所書 2:12–13; 哥林多前書 11:28"> 「你曉諭以色列人說：你們和你們後代中，若有人因死屍而不潔淨，或在遠方行路，還要向耶和華守逾越節。</span>
<span className="v" id="v11" data-v="11" data-xref="歷代志下 30:2–15; 出埃及記 12:43–49; 約翰福音 19:36"> 他們要在二月十四日黃昏的時候，守逾越節。要用無酵餅與苦菜，和逾越節的羊羔同吃。</span>
<span className="v" id="v12" data-v="12" data-xref="約翰福音 19:36; 出埃及記 12:46; 出埃及記 12:10"> 一點不可留到早晨；羊羔的骨頭一根也不可折斷。他們要照逾越節的一切律例而守。</span>
<span className="v" id="v13" data-v="13" data-xref="創世記 17:14; 出埃及記 12:15; 民數記 9:7"> 那潔淨而不行路的人若推辭不守逾越節，那人要從民中剪除；因為他在所定的日期不獻耶和華的供物，應該擔當他的罪。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及記 12:48–49; 利未記 24:22; 以賽亞書 56:3–7"> 若有外人寄居在你們中間，願意向耶和華守逾越節，他要照逾越節的律例典章行，不管是寄居的是本地人，同歸一例。」</span>
</div>
</div>

## 雲彩遮蓋帳幕

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="出埃及記 13:21; 出埃及記 40:34; 尼希米記 9:19"> 立起帳幕的那日，有雲彩遮蓋帳幕，就是法櫃的帳幕；從晚上到早晨，雲彩在其上，形狀如火。</span>
<span className="v" id="v16" data-v="16" data-xref="尼希米記 9:12; 出埃及記 40:38; 哥林多前書 10:1"> 常是這樣，雲彩遮蓋帳幕，夜間形狀如火。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及記 40:36–38; 詩篇 32:8; 約翰福音 10:9"> 雲彩幾時從帳幕收上去，以色列人就幾時起行；雲彩在哪裏停住，以色列人就在那裏安營。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前書 10:1; 約翰二書 1:6; 出埃及記 17:1"> 以色列人遵耶和華的吩咐起行，也遵耶和華的吩咐安營。雲彩在帳幕上停住幾時，他們就住營幾時。</span>
<span className="v" id="v19" data-v="19" data-xref="撒迦利亞書 3:7; 民數記 1:52–53; 民數記 3:8"> 雲彩在帳幕上停留許多日子，以色列人就守耶和華所吩咐的不起行。</span>
<span className="v" id="v20" data-v="20"> 有時雲彩在帳幕上幾天，他們就照耶和華的吩咐住營，也照耶和華的吩咐起行。</span>
<span className="v" id="v21" data-v="21" data-xref="尼希米記 9:19; 尼希米記 9:12"> 有時從晚上到早晨，有這雲彩在帳幕上；早晨雲彩收上去，他們就起行。有時晝夜雲彩停在帳幕上，收上去的時候，他們就起行。</span>
<span className="v" id="v22" data-v="22" data-xref="詩篇 32:8; 出埃及記 40:36–37; 出埃及記 40:16"> 雲彩停留在帳幕上，無論是兩天，是一月，是一年，以色列人就住營不起行；但雲彩收上去，他們就起行。</span>
<span className="v" id="v23" data-v="23" data-xref="約書亞記 22:3; 民數記 9:19; 創世記 26:5"> 他們遵耶和華的吩咐安營，也遵耶和華的吩咐起行。他們守耶和華所吩咐的，都是憑耶和華吩咐摩西的。</span>
</div>
</div>

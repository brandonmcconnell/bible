<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="民數記 23:29; 猶大書 1:11; 出埃及記 27:1–8"> 巴蘭對巴勒說：「你在這裏給我築七座壇，為我預備七隻公牛，七隻公羊。」</span>
<span className="v" id="v2" data-v="2" data-xref="民數記 23:14; 民數記 23:30"> 巴勒照巴蘭的話行了。巴勒和巴蘭在每座壇上獻一隻公牛，一隻公羊。</span>
<span className="v" id="v3" data-v="3" data-xref="民數記 23:15; 創世記 8:20; 創世記 22:2"> 巴蘭對巴勒說：「你站在你的燔祭旁邊，我且往前去，或者耶和華來迎見我。他指示我甚麼，我必告訴你。」於是巴蘭上一淨光的高處。</span>
<span className="v" id="v4" data-v="4" data-xref="民數記 23:16; 以弗所書 2:9; 路加福音 18:12"> 上帝迎見巴蘭；巴蘭說：「我預備了七座壇，在每座壇上獻了一隻公牛，一隻公羊。」</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 18:18; 耶利米書 1:9; 以賽亞書 59:21"> 耶和華將話傳給巴蘭，又說：「你回到巴勒那裏，要如此如此說。」</span>
<span className="v" id="v6" data-v="6"> 他就回到巴勒那裏，見他同摩押的使臣都站在燔祭旁邊。</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 23:4; 民數記 24:3; 民數記 22:5–6"> 巴蘭便題起詩歌說：<br /><span className="pl pl-1">巴勒引我出亞蘭，</span><br /><span className="pl pl-1">摩押王引我出東山，說：</span><br /><span className="pl pl-1">來啊，為我咒詛雅各；</span><br /><span className="pl pl-1">來啊，怒罵以色列。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="民數記 23:23; 以賽亞書 44:25; 民數記 23:20"> <span className="pl pl-1">上帝沒有咒詛的，我焉能咒詛？</span><br /><span className="pl pl-1">耶和華沒有怒罵的，我焉能怒罵？</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="申命記 33:28; 申命記 32:8; 出埃及記 33:16"> <span className="pl pl-1">我從高峰看他，從小山望他；</span><br /><span className="pl pl-1">這是獨居的民，不列在萬民中。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 37:37; 創世記 13:16; 詩篇 116:15"> <span className="pl pl-1">誰能數點雅各的塵土？</span><br /><span className="pl pl-1">誰能計算以色列的四分之一？</span><br /><span className="pl pl-1">我願如義人之死而死；</span><br /><span className="pl pl-1">我願如義人之終而終。</span></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="尼希米記 13:2; 民數記 24:10; 民數記 22:17"> 巴勒對巴蘭說：「你向我做的是甚麼事呢？我領你來咒詛我的仇敵，不料，你竟為他們祝福。」</span>
<span className="v" id="v12" data-v="12" data-xref="民數記 22:38; 民數記 23:20; 民數記 23:26"> 他回答說：「耶和華傳給我的話，我能不謹慎傳說嗎？」</span>
</div>
</div>

## 巴蘭第二次預言

<div className="bt">
<div className="bp poetry">
<span className="v" id="v13" data-v="13" data-xref="詩篇 109:17; 雅各書 3:9–10; 民數記 22:41"> 巴勒說：「求你同我往別處去，在那裏可以看見他們；你不能全看見，只能看見他們邊界上的人。在那裏要為我咒詛他們。」</span>
<span className="v" id="v14" data-v="14" data-xref="以賽亞書 46:6; 民數記 23:29; 以賽亞書 1:10–11"> 於是領巴蘭到了瑣腓田，上了毗斯迦山頂，築了七座壇；每座壇上獻一隻公牛，一隻公羊。</span>
<span className="v" id="v15" data-v="15" data-xref="民數記 23:3; 民數記 22:8"> 巴蘭對巴勒說：「你站在這燔祭旁邊，等我往那邊去迎見耶和華。」</span>
<span className="v" id="v16" data-v="16" data-xref="民數記 23:5; 民數記 24:1; 民數記 22:35"> 耶和華臨到巴蘭那裏，將話傳給他；又說：「你回到巴勒那裏，要如此如此說。」</span>
<span className="v" id="v17" data-v="17" data-xref="民數記 23:26; 撒母耳記上 3:17; 耶利米書 37:17"> 他就回到巴勒那裏，見他站在燔祭旁邊；摩押的使臣也和他在一處。巴勒問他說：「耶和華說了甚麼話呢？」</span>
<span className="v" id="v18" data-v="18" data-xref="士師記 3:20"> 巴蘭就題詩歌說：<br /><span className="pl pl-1">巴勒，你起來聽；</span><br /><span className="pl pl-1">西撥的兒子，你聽我言。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳記上 15:29; 雅各書 1:17; 瑪拉基書 3:6"> <span className="pl pl-1">上帝非人，必不致說謊，</span><br /><span className="pl pl-1">也非人子，必不致後悔。</span><br /><span className="pl pl-1">他說話豈不照着行呢？</span><br /><span className="pl pl-1">他發言豈不要成就呢？</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="約翰福音 10:27–29; 民數記 22:12; 創世記 12:2"> <span className="pl pl-1">我奉命祝福；</span><br /><span className="pl pl-1">上帝也曾賜福，此事我不能翻轉。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 23:4; 馬太福音 1:23; 耶利米書 50:20"> <span className="pl pl-1">他未見雅各中有罪孽，</span><br /><span className="pl pl-1">也未見以色列中有奸惡。</span><br /><span className="pl pl-1">耶和華－他的上帝和他同在；</span><br /><span className="pl pl-1">有歡呼王的聲音在他們中間。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="民數記 24:8; 申命記 33:17; 約伯記 39:9–11"> <span className="pl pl-1">上帝領他們出埃及；</span><br /><span className="pl pl-1">他們似乎有野牛之力。</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="路加福音 10:18–19; 約書亞記 13:22; 加拉太書 1:23–24"> <span className="pl pl-1">斷沒有法術可以害雅各，</span><br /><span className="pl pl-1">也沒有占卜可以害以色列。</span><br /><span className="pl pl-1">現在必有人論及雅各，就是論及以色列說：</span><br /><span className="pl pl-1">上帝為他行了何等的大事！</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="創世記 49:27; 創世記 49:9; 民數記 24:17"> <span className="pl pl-1">這民起來，彷彿母獅，</span><br /><span className="pl pl-1">挺身，好像公獅，</span><br /><span className="pl pl-1">未曾吃野食，</span><br /><span className="pl pl-1">未曾喝被傷者之血，決不躺臥。</span></span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="詩篇 2:1–3"> 巴勒對巴蘭說：「你一點不要咒詛他們，也不要為他們祝福。」</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行傳 5:29; 民數記 22:18; 使徒行傳 4:19–20"> 巴蘭回答巴勒說：「我豈不是告訴你說『凡耶和華所說的，我必須遵行』嗎？」</span>
</div>
</div>

## 巴蘭第三次預言

<div className="bt">
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="羅馬書 11:29; 箴言 21:30; 民數記 23:19–20"> 巴勒對巴蘭說：「來吧，我領你往別處去，或者上帝喜歡你在那裏為我咒詛他們。」</span>
<span className="v" id="v28" data-v="28" data-xref="民數記 21:20; 詩篇 106:28"> 巴勒就領巴蘭到那下望曠野的毗珥山頂上。</span>
<span className="v" id="v29" data-v="29" data-xref="民數記 23:1–2"> 巴蘭對巴勒說：「你在這裏為我築七座壇，又在這裏為我預備七隻公牛，七隻公羊。」</span>
<span className="v" id="v30" data-v="30"> 巴勒就照巴蘭的話行，在每座壇上獻一隻公牛，一隻公羊。</span>
</div>

## 以色列的第一次人口普查

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及記 25:22; 出埃及記 19:1; 民數記 10:11–12"> 以色列人出埃及地後，第二年二月初一日，耶和華在西奈的曠野、會幕中曉諭摩西說：</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 38:26; 出埃及記 30:12; 民數記 1:18"> 「你要按以色列全會眾的家室、宗族、人名的數目計算所有的男丁。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 30:14; 民數記 14:29; 民數記 33:1"> 凡以色列中，從二十歲以外，能出去打仗的，你和亞倫要照他們的軍隊數點。</span>
<span className="v" id="v4" data-v="4" data-xref="民數記 1:16; 出埃及記 18:25; 民數記 13:2–15"> 每支派中必有一人作本支派的族長，幫助你們。</span>
<span className="v" id="v5" data-v="5" data-xref="民數記 7:30; 創世記 30:5–20; 創世記 49:1–33"> 他們的名字：屬呂便的，有示丟珥的兒子以利蓿；</span>
<span className="v" id="v6" data-v="6" data-xref="民數記 7:36; 民數記 2:12"> 屬西緬的，有蘇利沙代的兒子示路蔑；</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 3:32; 民數記 10:14; 馬太福音 1:2–5"> 屬猶大的，有亞米拿達的兒子拿順；</span>
<span className="v" id="v8" data-v="8" data-xref="民數記 7:18; 民數記 10:15; 民數記 2:5"> 屬以薩迦的，有蘇押的兒子拿坦業；</span>
<span className="v" id="v9" data-v="9" data-xref="民數記 7:24; 民數記 10:16; 民數記 2:7"> 屬西布倫的，有希倫的兒子以利押；</span>
<span className="v" id="v10" data-v="10" data-xref="民數記 7:54; 民數記 7:48; 歷代志上 7:26–27"> 約瑟子孫、屬以法蓮的，有亞米忽的兒子以利沙瑪；屬瑪拿西的，有比大蓿的兒子迦瑪列；</span>
<span className="v" id="v11" data-v="11" data-xref="民數記 7:60; 民數記 10:24; 民數記 2:22"> 屬便雅憫的，有基多尼的兒子亞比但；</span>
<span className="v" id="v12" data-v="12" data-xref="民數記 7:66; 民數記 2:25; 民數記 10:25"> 屬但的，有亞米沙代的兒子亞希以謝；</span>
<span className="v" id="v13" data-v="13" data-xref="民數記 7:72; 民數記 10:26; 民數記 2:27"> 屬亞設的，有俄蘭的兒子帕結；</span>
<span className="v" id="v14" data-v="14" data-xref="民數記 2:14; 民數記 7:42; 民數記 10:20"> 屬迦得的，有丟珥的兒子以利雅薩；</span>
<span className="v" id="v15" data-v="15" data-xref="民數記 7:78; 民數記 10:27; 民數記 2:29"> 屬拿弗他利的，有以南的兒子亞希拉。</span>
<span className="v" id="v16" data-v="16" data-xref="民數記 7:2; 出埃及記 18:21; 出埃及記 18:25"> 這都是從會中選召的，各作本支派的首領，都是以色列軍中的統領。」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="約翰福音 10:3; 啟示錄 7:4–17; 民數記 1:5–15"> 於是，摩西、亞倫帶着這些按名指定的人，</span>
<span className="v" id="v18" data-v="18" data-xref="以斯拉記 2:59; 尼希米記 7:61; 希伯來書 7:3"> 當二月初一日招聚全會眾。會眾就照他們的家室、宗族、人名的數目，從二十歲以外的，都述說自己的家譜。</span>
<span className="v" id="v19" data-v="19" data-xref="民數記 1:2; 民數記 26:1–2; 撒母耳記下 24:1–10"> 耶和華怎樣吩咐摩西，他就怎樣在西奈的曠野數點他們。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="民數記 26:5–7; 民數記 2:10–11; 創世記 46:9"> 以色列的長子，呂便子孫的後代，照着家室、宗族、人名的數目，從二十歲以外，凡能出去打仗、被數的男丁，共有四萬六千五百名。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="民數記 26:12–14; 創世記 34:25–30; 民數記 2:12–13"> 西緬子孫的後代，照着家室、宗族、人名的數目，從二十歲以外，凡能出去打仗、被數的男丁，共有五萬九千三百名。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="民數記 26:15–18; 創世記 46:16; 民數記 2:14–15"> 迦得子孫的後代，照着家室、宗族、人名的數目，從二十歲以外，凡能出去打仗、被數的，共有四萬五千六百五十名。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="創世記 29:35; 民數記 26:19–22; 撒母耳記下 24:9"> 猶大子孫的後代，照着家室、宗族、人名的數目，從二十歲以外，凡能出去打仗、被數的，共有七萬四千六百名。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="創世記 46:13; 創世記 49:14–15; 創世記 30:18"> 以薩迦子孫的後代，照着家室、宗族、人名的數目，從二十歲以外，凡能出去打仗、被數的，共有五萬四千四百名。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="民數記 26:26–27; 創世記 49:13; 創世記 30:20"> 西布倫子孫的後代，照着家室、宗族、人名的數目，從二十歲以外，凡能出去打仗、被數的，共有五萬七千四百名。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="民數記 26:35–37; 申命記 33:17; 創世記 46:20"> 約瑟子孫屬以法蓮子孫的後代，照着家室、宗族、人名的數目，從二十歲以外，凡能出去打仗、被數的，共有四萬零五百名。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="民數記 26:28–34"> 瑪拿西子孫的後代，照着家室、宗族、人名的數目，從二十歲以外，凡能出去打仗、被數的，共有三萬二千二百名。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="創世記 49:27; 創世記 44:20; 啟示錄 7:8"> 便雅憫子孫的後代，照着家室、宗族、人名的數目，從二十歲以外，凡能出去打仗、被數的，共有三萬五千四百名。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="創世記 46:23; 創世記 30:5–6; 創世記 49:16–17"> 但子孫的後代，照着家室、宗族、人名的數目，從二十歲以外，凡能出去打仗、被數的，共有六萬二千七百名。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="創世記 30:12–13; 創世記 46:27; 創世記 49:20"> 亞設子孫的後代，照着家室、宗族、人名的數目，從二十歲以外，凡能出去打仗、被數的，共有四萬一千五百名。</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="創世記 49:21; 民數記 26:48–50; 創世記 46:24"> 拿弗他利子孫的後代，照着家室、宗族、人名的數目，從二十歲以外，凡能出去打仗、被數的，共有五萬三千四百名。</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="民數記 26:64; 民數記 1:2–16"> 這些就是被數點的，是摩西、亞倫，和以色列中十二個首領所數點的；這十二個人各作各宗族的代表。</span>
<span className="v" id="v45" data-v="45"> 這樣，凡以色列人中被數的，照着宗族，從二十歲以外，能出去打仗、被數的，共有六十萬零三千五百五十名。</span>
</div>
<div className="bp">
<span className="v" id="v47" data-v="47" data-xref="民數記 2:33; 民數記 3:1–49; 民數記 26:57–62"> 利未人卻沒有按着支派數在其中，</span>
<span className="v" id="v48" data-v="48"> 因為耶和華曉諭摩西說：</span>
<span className="v" id="v49" data-v="49" data-xref="民數記 26:62; 民數記 2:33"> 「惟獨利未支派你不可數點，也不可在以色列人中計算他們的總數。</span>
<span className="v" id="v50" data-v="50" data-xref="出埃及記 38:21; 出埃及記 31:18; 民數記 4:15"> 只要派利未人管法櫃的帳幕和其中的器具，並屬乎帳幕的；他們要抬<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或譯：搬運">a</a></sup>帳幕和其中的器具，並要辦理帳幕的事，在帳幕的四圍安營。</span>
<span className="v" id="v51" data-v="51" data-xref="民數記 3:38; 民數記 3:10; 撒母耳記上 6:19"> 帳幕將往前行的時候，利未人要拆卸；將支搭的時候，利未人要豎起。近前來的外人必被治死。</span>
<span className="v" id="v52" data-v="52" data-xref="民數記 2:2; 民數記 2:34; 民數記 10:1–36"> 以色列人支搭帳棚，要照他們的軍隊，各歸本營，各歸本纛。</span>
<span className="v" id="v53" data-v="53" data-xref="民數記 16:46; 歷代志上 23:32; 利未記 10:6"> 但利未人要在法櫃帳幕的四圍安營，免得忿怒臨到以色列會眾；利未人並要謹守法櫃的帳幕。」</span>
<span className="v" id="v54" data-v="54" data-xref="申命記 12:32; 出埃及記 40:16; 出埃及記 39:32"> 以色列人就這樣行。凡耶和華所吩咐摩西的，他們就照樣行了。</span>
</div>
</div>

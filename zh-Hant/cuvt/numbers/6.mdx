## 拿細耳人的條例

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華對摩西說：</span>
<span className="v" id="v2" data-v="2" data-xref="士師記 13:5; 阿摩司書 2:11–12; 羅馬書 1:1"> 「你曉諭以色列人說：無論男女許了特別的願，就是拿細耳人的願<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="拿細耳就是歸主的意思；下同">a</a></sup>，要離俗歸耶和華。</span>
<span className="v" id="v3" data-v="3" data-xref="路加福音 1:15; 提摩太前書 5:23; 阿摩司書 2:12"> 他就要遠離清酒濃酒，也不可喝甚麼清酒濃酒做的醋；不可喝甚麼葡萄汁，也不可吃鮮葡萄和乾葡萄。</span>
<span className="v" id="v4" data-v="4" data-xref="民數記 6:5; 民數記 6:21; 民數記 6:8–9"> 在一切離俗的日子，凡葡萄樹上結的，自核至皮所做的物，都不可吃。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="撒母耳記上 1:11; 士師記 16:17; 士師記 13:5"> 「在他一切許願離俗的日子，不可用剃頭刀剃頭，要由髮綹長長了。他要聖潔，直到離俗歸耶和華的日子滿了。</span>
<span className="v" id="v6" data-v="6" data-xref="利未記 21:11; 利未記 19:28; 利未記 21:1–3"> 在他離俗歸耶和華的一切日子，不可挨近死屍。</span>
<span className="v" id="v7" data-v="7" data-xref="民數記 9:6; 利未記 21:1–2; 利未記 21:10–12"> 他的父母或是弟兄姊妹死了的時候，他不可因他們使自己不潔淨，因為那離俗歸上帝的憑據是在他頭上。</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多後書 6:17–18"> 在他一切離俗的日子是歸耶和華為聖。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="民數記 6:18; 使徒行傳 18:18; 利未記 14:9"> 「若在他旁邊忽然有人死了，以致沾染了他離俗的頭，他要在第七日，得潔淨的時候，剃頭。</span>
<span className="v" id="v10" data-v="10" data-xref="利未記 15:29; 利未記 1:14; 利未記 15:14"> 第八日，他要把兩隻斑鳩或兩隻雛鴿帶到會幕門口，交給祭司。</span>
<span className="v" id="v11" data-v="11" data-xref="利未記 14:30–31; 利未記 5:8–10"> 祭司要獻一隻作贖罪祭，一隻作燔祭，為他贖那因死屍而有的罪，並要當日使他的頭成為聖潔。</span>
<span className="v" id="v12" data-v="12" data-xref="利未記 5:6; 馬太福音 24:13; 利未記 14:24"> 他要另選離俗歸耶和華的日子，又要牽一隻一歲的公羊羔來作贖愆祭；但先前的日子要歸徒然，因為他在離俗之間被玷污了。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="使徒行傳 21:26"> 「拿細耳人滿了離俗的日子乃有這條例：人要領他到會幕門口，</span>
<span className="v" id="v14" data-v="14" data-xref="利未記 3:6; 利未記 4:32; 利未記 4:2–3"> 他要將供物奉給耶和華，就是一隻沒有殘疾、一歲的公羊羔作燔祭，一隻沒有殘疾、一歲的母羊羔作贖罪祭，和一隻沒有殘疾的公綿羊作平安祭，</span>
<span className="v" id="v15" data-v="15" data-xref="利未記 2:4; 出埃及記 29:2; 民數記 15:10"> 並一筐子無酵調油的細麵餅，與抹油的無酵薄餅，並同獻的素祭和奠祭。</span>
<span className="v" id="v16" data-v="16"> 祭司要在耶和華面前獻那人的贖罪祭和燔祭；</span>
<span className="v" id="v17" data-v="17"> 也要把那隻公羊和那筐無酵餅獻給耶和華作平安祭，又要將同獻的素祭和奠祭獻上。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行傳 21:24; 民數記 6:9; 使徒行傳 18:18"> 拿細耳人要在會幕門口剃離俗的頭，把離俗頭上的髮放在平安祭下的火上。</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳記上 2:15; 利未記 7:30; 出埃及記 29:23–28"> 他剃了以後，祭司就要取那已煮的公羊一條前腿，又從筐子裏取一個無酵餅和一個無酵薄餅，都放在他手上。</span>
<span className="v" id="v20" data-v="20" data-xref="傳道書 9:7; 出埃及記 29:27–28; 民數記 5:25"> 祭司要拿這些作為搖祭，在耶和華面前搖一搖；這與所搖的胸、所舉的腿同為聖物，歸給祭司。然後拿細耳人可以喝酒。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="希伯來書 13:16; 以斯拉記 2:69; 民數記 5:29"> 「許願的拿細耳人為離俗所獻的供物，和他以外所能得的獻給耶和華，就有這條例。他怎樣許願就當照離俗的條例行。」</span>
</div>
</div>

## 祭司的祝福

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22"> 耶和華曉諭摩西說：</span>
<span className="v" id="v23" data-v="23" data-xref="申命記 21:5; 歷代志上 23:13; 創世記 48:20"> 「你告訴亞倫和他兒子說：你們要這樣為以色列人祝福，說：</span>
<span className="v" id="v24" data-v="24" data-xref="帖撒羅尼迦前書 5:23; 詩篇 121:4–7; 腓立比書 4:7"> 『願耶和華賜福給你，保護你。</span>
<span className="v" id="v25" data-v="25" data-xref="詩篇 80:19; 詩篇 119:135; 詩篇 31:16"> 願耶和華使他的臉光照你，賜恩給你。</span>
<span className="v" id="v26" data-v="26" data-xref="詩篇 4:6; 詩篇 29:11; 帖撒羅尼迦後書 3:16"> 願耶和華向你仰臉，賜你平安。』</span>
<span className="v" id="v27" data-v="27" data-xref="歷代志下 7:14; 但以理書 9:18–19; 申命記 28:10"> 他們要如此奉我的名為以色列人祝福；我也要賜福給他們。」</span>
</div>

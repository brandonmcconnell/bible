## 每天例常的祭

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華曉諭摩西說：</span>
<span className="v" id="v2" data-v="2" data-xref="利未記 3:11; 創世記 8:21; 民數記 9:2–3"> 「你要吩咐以色列人說：『獻給我的供物，就是獻給我作馨香火祭的食物，你們要按日期獻給我』；</span>
<span className="v" id="v3" data-v="3" data-xref="利未記 6:9; 但以理書 11:31; 約翰福音 1:29"> 又要對他們說：你們要獻給耶和華的火祭，就是沒有殘疾、一歲的公羊羔，每日兩隻，作為常獻的燔祭。</span>
<span className="v" id="v4" data-v="4" data-xref="但以理書 9:21; 列王紀上 18:36; 出埃及記 12:6"> 早晨要獻一隻，黃昏的時候要獻一隻；</span>
<span className="v" id="v5" data-v="5" data-xref="利未記 2:1; 出埃及記 16:36; 出埃及記 29:38–42"> 又用細麵伊法十分之一，並搗成的油一欣四分之一，調和作為素祭。</span>
<span className="v" id="v6" data-v="6" data-xref="阿摩司書 5:25; 利未記 6:9; 詩篇 50:8"> 這是西奈山所命定為常獻的燔祭，是獻給耶和華為馨香的火祭。</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及記 29:42; 民數記 28:14; 以賽亞書 57:6"> 為這一隻羊羔，要同獻奠祭的酒一欣四分之一。在聖所中，你要將醇酒奉給耶和華為奠祭。</span>
<span className="v" id="v8" data-v="8"> 晚上，你要獻那一隻羊羔，必照早晨的素祭和同獻的奠祭獻上，作為馨香的火祭，獻給耶和華。」</span>
</div>
</div>

## 安息日獻的祭

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="以賽亞書 58:13; 詩篇 92:1–4; 啟示錄 1:10"> 「當安息日，要獻兩隻沒有殘疾、一歲的公羊羔，並用調油的細麵伊法十分之二為素祭，又將同獻的奠祭獻上。</span>
<span className="v" id="v10" data-v="10" data-xref="以西結書 46:4–5; 民數記 29:22; 民數記 29:31"> 這是每安息日獻的燔祭；那常獻的燔祭和同獻的奠祭在外。」</span>
</div>
</div>

## 月初獻的祭

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="民數記 10:10; 以西結書 46:6; 以斯拉記 3:5"> 「每月朔，你們要將兩隻公牛犢，一隻公綿羊，七隻沒有殘疾、一歲的公羊羔，獻給耶和華為燔祭。</span>
<span className="v" id="v12" data-v="12" data-xref="民數記 15:4–12; 以西結書 46:5–7; 民數記 29:10"> 每隻公牛要用調油的細麵伊法十分之三作為素祭；那隻公羊也用調油的細麵伊法十分之二作為素祭；</span>
<span className="v" id="v13" data-v="13"> 每隻羊羔要用調油的細麵伊法十分之一作為素祭和馨香的燔祭，是獻給耶和華的火祭。</span>
<span className="v" id="v14" data-v="14"> 一隻公牛要奠酒半欣，一隻公羊要奠酒一欣三分之一，一隻羊羔也奠酒一欣四分之一。這是每月的燔祭，一年之中要月月如此。</span>
<span className="v" id="v15" data-v="15" data-xref="民數記 28:3; 民數記 28:22; 民數記 15:24"> 又要將一隻公山羊為贖罪祭，獻給耶和華；要獻在常獻的燔祭和同獻的奠祭以外。」</span>
</div>
</div>

## 除酵節獻的祭

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="申命記 16:1–8; 出埃及記 12:18; 利未記 23:5–8"> 「正月十四日是耶和華的逾越節。</span>
<span className="v" id="v17" data-v="17" data-xref="利未記 23:6; 出埃及記 23:15; 出埃及記 13:6"> 這月十五日是節期，要吃無酵餅七日。</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及記 12:16; 利未記 23:7–8"> 第一日當有聖會；甚麼勞碌的工都不可做。</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 15:21; 以西結書 45:21–25; 民數記 29:8"> 當將公牛犢兩隻，公綿羊一隻，一歲的公羊羔七隻，都要沒有殘疾的，用火獻給耶和華為燔祭。</span>
<span className="v" id="v20" data-v="20"> 同獻的素祭用調油的細麵；為一隻公牛要獻伊法十分之三；為一隻公羊要獻伊法十分之二；</span>
<span className="v" id="v21" data-v="21"> 為那七隻羊羔，每隻要獻伊法十分之一。</span>
<span className="v" id="v22" data-v="22" data-xref="羅馬書 8:3"> 並獻一隻公山羊作贖罪祭，為你們贖罪。</span>
<span className="v" id="v23" data-v="23" data-xref="民數記 28:3; 民數記 28:10"> 你們獻這些，要在早晨常獻的燔祭以外。</span>
<span className="v" id="v24" data-v="24"> 一連七日，每日要照這例把馨香火祭的食物獻給耶和華，是在常獻的燔祭和同獻的奠祭以外。</span>
<span className="v" id="v25" data-v="25" data-xref="利未記 23:8; 民數記 28:18; 出埃及記 13:6"> 第七日當有聖會，甚麼勞碌的工都不可做。」</span>
</div>
</div>

## 七七收穫節獻的祭

<div className="bt">
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="出埃及記 23:16; 出埃及記 34:22; 利未記 23:10"> 「七七節莊稼初熟，你們獻新素祭給耶和華的日子，當有聖會；甚麼勞碌的工都不可做。</span>
<span className="v" id="v27" data-v="27" data-xref="利未記 23:18–19; 民數記 28:11; 民數記 28:19"> 只要將公牛犢兩隻，公綿羊一隻，一歲的公羊羔七隻，作為馨香的燔祭獻給耶和華。</span>
<span className="v" id="v28" data-v="28"> 同獻的素祭用調油的細麵；為每隻公牛要獻伊法十分之三；為一隻公羊要獻伊法十分之二；</span>
<span className="v" id="v29" data-v="29"> 為那七隻羊羔，每隻要獻伊法十分之一。</span>
<span className="v" id="v30" data-v="30" data-xref="民數記 28:15; 民數記 28:22; 彼得前書 2:24"> 並獻一隻公山羊為你們贖罪。</span>
<span className="v" id="v31" data-v="31" data-xref="民數記 28:19; 民數記 28:3; 瑪拉基書 1:13–14"> 這些，你們要獻在常獻的燔祭和同獻的素祭並同獻的奠祭以外，都要沒有殘疾的。」</span>
</div>

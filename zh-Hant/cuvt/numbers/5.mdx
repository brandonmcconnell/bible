## 不潔的人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華曉諭摩西說：</span>
<span className="v" id="v2" data-v="2" data-xref="利未記 21:1; 利未記 13:46; 民數記 12:14"> 「你吩咐以色列人，使一切長大痲瘋的，患漏症的，並因死屍不潔淨的，都出營外去。</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 23:14; 利未記 26:11–12; 詩篇 68:18"> 無論男女都要使他們出到營外，免得污穢他們的營；這營是我所住的。」</span>
<span className="v" id="v4" data-v="4"> 以色列人就這樣行，使他們出到營外。耶和華怎樣吩咐摩西，以色列人就怎樣行了。</span>
</div>
</div>

## 賠償虧負

<div className="bt">
<div className="bp">
<span className="v" id="v5" data-v="5"> 耶和華對摩西說：</span>
<span className="v" id="v6" data-v="6" data-xref="利未記 5:1–4; 利未記 5:14–7"> 「你曉諭以色列人說：無論男女，若犯了人所常犯的罪，以致干犯耶和華，那人就有了罪。</span>
<span className="v" id="v7" data-v="7" data-xref="利未記 5:5; 利未記 26:40; 約書亞記 7:19"> 他要承認所犯的罪，將所虧負人的，如數賠還，另外加上五分之一，也歸與所虧負的人。</span>
<span className="v" id="v8" data-v="8" data-xref="利未記 6:6–7; 利未記 7:7; 利未記 25:25–26"> 那人若沒有親屬可受所賠還的，那所賠還的就要歸與服事耶和華的祭司；至於那為他贖罪的公羊是在外。</span>
<span className="v" id="v9" data-v="9" data-xref="申命記 18:3–4; 利未記 7:6–14; 利未記 6:17–18"> 以色列人一切的聖物中，所奉給祭司的舉祭都要歸與祭司。</span>
<span className="v" id="v10" data-v="10" data-xref="利未記 10:13"> 各人所分別為聖的物，無論是甚麼，都要歸給祭司。」</span>
</div>
</div>

## 疑妻不貞的案件

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11"> 耶和華對摩西說：</span>
<span className="v" id="v12" data-v="12" data-xref="民數記 5:19–20; 箴言 2:16–17"> 「你曉諭以色列人說：人的妻若有邪行，得罪她丈夫，</span>
<span className="v" id="v13" data-v="13" data-xref="利未記 18:20; 利未記 20:10; 箴言 7:18–19"> 有人與她行淫，事情嚴密，瞞過她丈夫，而且她被玷污，沒有作見證的人，當她行淫的時候也沒有被捉住，</span>
<span className="v" id="v14" data-v="14" data-xref="雅歌 8:6; 箴言 6:34; 西番雅書 3:8"> 她丈夫生了疑恨的心，疑恨她，她是被玷污，或是她丈夫生了疑恨的心，疑恨她，她並沒有被玷污，</span>
<span className="v" id="v15" data-v="15" data-xref="以西結書 29:16; 列王紀上 17:18; 利未記 5:11"> 這人就要將妻送到祭司那裏，又為她帶着大麥麵伊法十分之一作供物，不可澆上油，也不可加上乳香；因為這是疑恨的素祭，是思念的素祭，使人思念罪孽。</span>
<span className="v" id="v16" data-v="16" data-xref="啟示錄 2:22–23; 耶利米書 17:10; 希伯來書 13:4"> 「祭司要使那婦人近前來，站在耶和華面前。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及記 30:18; 約翰福音 8:6; 民數記 19:2–9"> 祭司要把聖水盛在瓦器裏，又從帳幕的地上取點塵土，放在水中。</span>
<span className="v" id="v18" data-v="18" data-xref="箴言 5:4; 民數記 5:22; 啟示錄 10:9–10"> 祭司要叫那婦人蓬頭散髮，站在耶和華面前，把思念的素祭，就是疑恨的素祭，放在她手中。祭司手裏拿着致咒詛的苦水，</span>
<span className="v" id="v19" data-v="19" data-xref="羅馬書 7:2; 民數記 5:12; 馬太福音 26:63"> 要叫婦人起誓，對她說：『若沒有人與你行淫，也未曾背着丈夫做污穢的事，你就免受這致咒詛苦水的災。</span>
<span className="v" id="v20" data-v="20" data-xref="民數記 5:12"> 你若背着丈夫行了污穢的事，在你丈夫以外有人與你行淫，</span>
<span className="v" id="v21" data-v="21" data-xref="約書亞記 6:26; 尼希米記 10:29; 撒母耳記上 14:24"> （祭司叫婦人發咒起誓），願耶和華叫你大腿消瘦，肚腹發脹，使你在你民中被人咒詛，成了誓語；</span>
<span className="v" id="v22" data-v="22" data-xref="詩篇 109:18; 詩篇 89:52; 約伯記 31:39–40"> 並且這致咒詛的水入你的腸中，要叫你的肚腹發脹，大腿消瘦。』婦人要回答說：『阿們，阿們。』</span>
<span className="v" id="v23" data-v="23" data-xref="使徒行傳 3:19; 詩篇 51:1; 詩篇 51:9"> 「祭司要寫這咒詛的話，將所寫的字抹在苦水裏，</span>
<span className="v" id="v24" data-v="24" data-xref="撒迦利亞書 5:3–4; 瑪拉基書 3:5"> 又叫婦人喝這致咒詛的苦水；這水要進入她裏面變苦了。</span>
<span className="v" id="v25" data-v="25" data-xref="利未記 8:27; 民數記 5:18; 民數記 5:15"> 祭司要從婦人的手中取那疑恨的素祭，在耶和華面前搖一搖，拿到壇前；</span>
<span className="v" id="v26" data-v="26" data-xref="利未記 2:2; 利未記 2:9; 利未記 5:12"> 又要從素祭中取出一把，作為這事的紀念，燒在壇上，然後叫婦人喝這水。</span>
<span className="v" id="v27" data-v="27" data-xref="耶利米書 42:18; 撒迦利亞書 8:13; 耶利米書 29:18"> 叫她喝了以後，她若被玷污，得罪了丈夫，這致咒詛的水必進入她裏面變苦了，她的肚腹就要發脹，大腿就要消瘦，那婦人便要在他民中被人咒詛。</span>
<span className="v" id="v28" data-v="28" data-xref="彌迦書 7:7–10; 哥林多後書 4:17; 詩篇 113:9"> 若婦人沒有被玷污，卻是清潔的，就要免受這災，且要懷孕。</span>
<span className="v" id="v29" data-v="29" data-xref="民數記 5:19; 民數記 5:12; 民數記 5:15"> 「妻子背着丈夫行了污穢的事，</span>
<span className="v" id="v30" data-v="30"> 或是人生了疑恨的心，疑恨他的妻，就有這疑恨的條例。那時他要叫婦人站在耶和華面前，祭司要在她身上照這條例而行。</span>
<span className="v" id="v31" data-v="31" data-xref="利未記 20:10; 羅馬書 2:8–9; 以西結書 18:4"> 男人就為無罪，婦人必擔當自己的罪孽。」</span>
</div>
</div>

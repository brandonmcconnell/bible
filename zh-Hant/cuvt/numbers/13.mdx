## 十二個探子

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華曉諭摩西說：</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 1:22–25; 民數記 32:8; 民數記 34:18"> 「你打發人去窺探我所賜給以色列人的迦南地，他們每支派中要打發一個人，都要作首領的。」</span>
<span className="v" id="v3" data-v="3" data-xref="民數記 12:16; 民數記 32:8; 申命記 1:19"> 摩西就照耶和華的吩咐從巴蘭的曠野打發他們去；他們都是以色列人的族長。</span>
<span className="v" id="v4" data-v="4"> 他們的名字：屬呂便支派的有撒刻的兒子沙母亞。</span>
<span className="v" id="v5" data-v="5"> 屬西緬支派的有何利的兒子沙法。</span>
<span className="v" id="v6" data-v="6" data-xref="民數記 34:19; 民數記 14:6; 民數記 13:30"> 屬猶大支派的有耶孚尼的兒子迦勒。</span>
<span className="v" id="v7" data-v="7"> 屬以薩迦支派的有約色的兒子以迦。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及記 24:13; 民數記 11:28; 民數記 13:16"> 屬以法蓮支派的有嫩的兒子何希阿。</span>
<span className="v" id="v9" data-v="9"> 屬便雅憫支派的有拉孚的兒子帕提。</span>
<span className="v" id="v10" data-v="10"> 屬西布倫支派的有梭底的兒子迦疊。</span>
<span className="v" id="v11" data-v="11"> 約瑟的子孫，屬瑪拿西支派的有穌西的兒子迦底。</span>
<span className="v" id="v12" data-v="12"> 屬但支派的有基瑪利的兒子亞米利。</span>
<span className="v" id="v13" data-v="13"> 屬亞設支派的有米迦勒的兒子西帖。</span>
<span className="v" id="v14" data-v="14"> 屬拿弗他利支派的有縛西的兒子拿比。</span>
<span className="v" id="v15" data-v="15"> 屬迦得支派的有瑪基的兒子臼利。</span>
<span className="v" id="v16" data-v="16" data-xref="民數記 13:8; 出埃及記 17:9; 民數記 14:6"> 這就是摩西所打發、窺探那地之人的名字。摩西就稱嫩的兒子何希阿為約書亞。</span>
<span className="v" id="v17" data-v="17" data-xref="士師記 1:9; 創世記 12:9; 士師記 1:19"> 摩西打發他們去窺探迦南地，說：「你們從南地上山地去，</span>
<span className="v" id="v18" data-v="18" data-xref="以西結書 34:14; 出埃及記 3:8"> 看那地如何，其中所住的民是強是弱，是多是少，</span>
<span className="v" id="v19" data-v="19"> 所住之地是好是歹，所住之處是營盤是堅城。</span>
<span className="v" id="v20" data-v="20" data-xref="申命記 31:23; 申命記 31:6–8; 以西結書 34:14"> 又看那地土是肥美是瘠薄，其中有樹木沒有。你們要放開膽量，把那地的果子帶些來。」（那時正是葡萄初熟的時候。）</span>
<span className="v" id="v21" data-v="21" data-xref="民數記 20:1; 民數記 33:36; 民數記 27:14"> 他們上去窺探那地，從尋的曠野到利合，直到哈馬口。</span>
<span className="v" id="v22" data-v="22" data-xref="詩篇 78:12; 詩篇 78:43; 以賽亞書 19:11"> 他們從南地上去，到了希伯崙；在那裏有亞衲族人亞希幔、示篩、撻買。（原來希伯崙城被建造比埃及的鎖安城早七年。）</span>
<span className="v" id="v23" data-v="23" data-xref="民數記 13:24; 民數記 32:9; 申命記 1:24–25"> 他們到了以實各谷，從那裏砍了葡萄樹的一枝，上頭有一掛葡萄，兩個人用槓抬着，又帶了些石榴和無花果來。（</span>
<span className="v" id="v24" data-v="24"> 因為以色列人從那裏砍來的那掛葡萄，所以那地方叫做以實各谷。）</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及記 34:28; 出埃及記 24:18; 民數記 14:33–34"> 過了四十天，他們窺探那地才回來，</span>
<span className="v" id="v26" data-v="26" data-xref="民數記 32:8; 民數記 20:1; 申命記 1:19"> 到了巴蘭曠野的加低斯，見摩西、亞倫，並以色列的全會眾，回報摩西、亞倫，並全會眾，又把那地的果子給他們看；</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及記 3:8; 出埃及記 3:17; 出埃及記 13:5"> 又告訴摩西說：「我們到了你所打發我們去的那地，果然是流奶與蜜之地；這就是那地的果子。</span>
<span className="v" id="v28" data-v="28" data-xref="申命記 9:1–2; 申命記 1:28; 民數記 13:33"> 然而住那地的民強壯，城邑也堅固寬大，並且我們在那裏看見了亞衲族的人。</span>
<span className="v" id="v29" data-v="29" data-xref="民數記 14:43; 士師記 6:3; 創世記 15:19–21"> 亞瑪力人住在南地；赫人、耶布斯人、亞摩利人住在山地；迦南人住在海邊並約旦河旁。」</span>
<span className="v" id="v30" data-v="30" data-xref="民數記 14:24; 羅馬書 8:31; 腓立比書 4:13"> 迦勒在摩西面前安撫百姓，說：「我們立刻上去得那地吧！我們足能得勝。」</span>
<span className="v" id="v31" data-v="31" data-xref="申命記 1:28; 約書亞記 14:8; 希伯來書 3:19"> 但那些和他同去的人說：「我們不能上去攻擊那民，因為他們比我們強壯。」</span>
<span className="v" id="v32" data-v="32" data-xref="阿摩司書 2:9; 民數記 14:36–37; 以西結書 36:13–14"> 探子中有人論到所窺探之地，向以色列人報惡信，說：「我們所窺探、經過之地是吞吃居民之地，我們在那裏所看見的人民都身量高大。</span>
<span className="v" id="v33" data-v="33" data-xref="申命記 1:28; 以賽亞書 40:22; 創世記 6:4"> 我們在那裏看見亞衲族人，就是偉人；他們是偉人的後裔。據我們看，自己就如蚱蜢一樣；據他們看，我們也是如此。」</span>

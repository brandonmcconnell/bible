## 哥轄子孫的職責

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華曉諭摩西、亞倫說：</span>
<span className="v" id="v2" data-v="2" data-xref="民數記 3:27; 民數記 3:19"> 「你從利未人中，將哥轄子孫的總數，照他們的家室、宗族，</span>
<span className="v" id="v3" data-v="3" data-xref="民數記 4:23; 歷代志上 23:3–5; 列王紀下 11:4–12"> 從三十歲直到五十歲，凡前來任職、在會幕裏辦事的，全都計算。</span>
<span className="v" id="v4" data-v="4" data-xref="民數記 4:19; 馬可福音 13:34; 民數記 4:30"> 哥轄子孫在會幕搬運至聖之物，所辦的事乃是這樣：</span>
<span className="v" id="v5" data-v="5" data-xref="馬太福音 27:51; 希伯來書 9:3; 出埃及記 40:3"> 起營的時候，亞倫和他兒子要進去摘下遮掩櫃的幔子，用以蒙蓋法櫃，</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及記 25:13–15; 出埃及記 35:19; 民數記 4:7–8"> 又用海狗皮蓋在上頭，再蒙上純藍色的毯子，把槓穿上。</span>
<span className="v" id="v7" data-v="7" data-xref="利未記 24:5–8; 出埃及記 37:10–16; 出埃及記 25:23–30"> 又用藍色毯子鋪在陳設餅的桌子上，將盤子、調羹、奠酒的爵，和杯擺在上頭。桌子上也必有常設的餅。</span>
<span className="v" id="v8" data-v="8" data-xref="民數記 4:6–7; 民數記 4:11–13; 民數記 4:9"> 在其上又要蒙朱紅色的毯子，再蒙上海狗皮，把槓穿上。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及記 25:31–39; 出埃及記 37:17–24; 啟示錄 1:20–1"> 要拿藍色毯子，把燈臺和燈臺上所用的燈盞、剪子、蠟花盤，並一切盛油的器皿，全都遮蓋。</span>
<span className="v" id="v10" data-v="10" data-xref="民數記 4:12; 民數記 4:6"> 又要把燈臺和燈臺的一切器具包在海狗皮裏，放在抬架上。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及記 40:5; 出埃及記 30:1–19; 出埃及記 40:26–27"> 在金壇上要鋪藍色毯子，蒙上海狗皮，把槓穿上。</span>
<span className="v" id="v12" data-v="12" data-xref="歷代志上 9:29; 出埃及記 25:9; 歷代志下 4:22"> 又要把聖所用的一切器具包在藍色毯子裏，用海狗皮蒙上，放在抬架上。</span>
<span className="v" id="v13" data-v="13" data-xref="利未記 6:12–13; 出埃及記 39:1; 出埃及記 39:41"> 要收去壇上的灰，把紫色毯子鋪在壇上；</span>
<span className="v" id="v14" data-v="14" data-xref="歷代志下 4:19; 出埃及記 38:1–7"> 又要把所用的一切器具，就是火鼎、肉鍤子、鏟子、盤子，一切屬壇的器具都擺在壇上，又蒙上海狗皮，把槓穿上。</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳記下 6:6–7; 民數記 7:9; 申命記 31:9"> 將要起營的時候，亞倫和他兒子把聖所和聖所的一切器具遮蓋完了，哥轄的子孫就要來抬，只是不可摸聖物，免得他們死亡。會幕裏這些物件是哥轄子孫所當抬的。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="出埃及記 25:6; 利未記 24:2; 出埃及記 30:23–38"> 「祭司亞倫的兒子以利亞撒所要看守的是點燈的油與香料，並當獻的素祭和膏油，也要看守全帳幕與其中所有的，並聖所和聖所的器具。」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17"> 耶和華曉諭摩西、亞倫說：</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳記下 6:6–7; 民數記 17:10; 民數記 18:5"> 「你們不可將哥轄人的支派從利未人中剪除。</span>
<span className="v" id="v19" data-v="19" data-xref="民數記 4:15"> 他們挨近至聖物的時候，亞倫和他兒子要進去派他們各人所當辦的，所當抬的。這樣待他們，好使他們活着，不致死亡。</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳記上 6:19; 出埃及記 19:21; 民數記 4:15"> 只是他們連片時不可進去觀看聖所，免得他們死亡。」</span>
</div>
</div>

## 革順子孫的職責

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21"> 耶和華曉諭摩西說：</span>
<span className="v" id="v22" data-v="22" data-xref="民數記 3:18; 民數記 3:21; 民數記 3:24"> 「你要將革順子孫的總數，照着宗族、家室，</span>
<span className="v" id="v23" data-v="23" data-xref="民數記 4:3; 提摩太前書 1:18; 哥林多前書 9:7"> 從三十歲直到五十歲，凡前來任職、在會幕裏辦事的，全都數點。</span>
<span className="v" id="v24" data-v="24" data-xref="民數記 4:19; 民數記 4:31–32; 民數記 4:47"> 革順人各族所辦的事、所抬的物乃是這樣：</span>
<span className="v" id="v25" data-v="25" data-xref="民數記 3:25–26; 出埃及記 26:14; 民數記 7:5–7"> 他們要抬帳幕的幔子和會幕，並會幕的蓋與其上的海狗皮，和會幕的門簾，</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及記 35:18; 出埃及記 27:9"> 院子的帷子和門簾（院子是圍帳幕和壇的）、繩子，並所用的器具，不論是做甚麼用的，他們都要經理。</span>
<span className="v" id="v27" data-v="27" data-xref="路加福音 1:70; 哥林多前書 11:2"> 革順的子孫在一切抬物辦事之上都要憑亞倫和他兒子的吩咐；他們所當抬的，要派他們看守。</span>
<span className="v" id="v28" data-v="28" data-xref="民數記 4:33; 哥林多前書 12:5–6"> 這是革順子孫的各族在會幕裏所辦的事；他們所看守的，必在祭司亞倫兒子以他瑪的手下。」</span>
</div>
</div>

## 米拉利子孫的職責

<div className="bt">
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="民數記 3:33–35"> 「至於米拉利的子孫，你要照着家室、宗族把他們數點。</span>
<span className="v" id="v30" data-v="30" data-xref="民數記 4:3; 民數記 4:23; 提摩太後書 2:4"> 從三十歲直到五十歲，凡前來任職、在會幕裏辦事的，你都要數點。</span>
<span className="v" id="v31" data-v="31" data-xref="民數記 3:36–37; 出埃及記 26:15; 民數記 7:8–9"> 他們辦理會幕的事，就是抬帳幕的板、閂、柱子，和帶卯的座，</span>
<span className="v" id="v32" data-v="32" data-xref="出埃及記 38:21; 歷代志上 9:29; 民數記 3:8"> 院子四圍的柱子和其上帶卯的座、橛子、繩子，並一切使用的器具。他們所抬的器具，你們要按名指定。</span>
<span className="v" id="v33" data-v="33" data-xref="民數記 4:28; 約書亞記 3:6; 以賽亞書 3:6"> 這是米拉利子孫各族在會幕裏所辦的事，都在祭司亞倫兒子以他瑪的手下。」</span>
</div>
</div>

## 利未支派男丁的統計

<div className="bt">
<div className="bp">
<span className="v" id="v34" data-v="34"> 摩西、亞倫與會眾的諸首領將哥轄的子孫，照着家室、宗族，</span>
<span className="v" id="v35" data-v="35" data-xref="歷代志上 23:24; 民數記 4:23; 歷代志上 23:3"> 從三十歲直到五十歲，凡前來任職、在會幕裏辦事的，都數點了。</span>
<span className="v" id="v36" data-v="36"> 被數的共有二千七百五十名。</span>
<span className="v" id="v37" data-v="37"> 這是哥轄各族中被數的，是在會幕裏辦事的，就是摩西、亞倫照耶和華藉摩西所吩咐數點的。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38"> 革順子孫被數的，照着家室、宗族，</span>
<span className="v" id="v39" data-v="39"> 從三十歲直到五十歲，凡前來任職、在會幕裏辦事的，共有二千六百三十名。</span>
<span className="v" id="v41" data-v="41"> 這是革順子孫各族中被數的，是在會幕裏辦事的，就是摩西、亞倫照耶和華藉摩西所吩咐數點的。</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42"> 米拉利子孫中各族被數的，照着家室、宗族，</span>
<span className="v" id="v43" data-v="43"> 從三十歲直到五十歲，凡前來任職、在會幕裏辦事的，共有三千二百名。</span>
<span className="v" id="v45" data-v="45" data-xref="民數記 4:29"> 這是米拉利子孫各族中被數的，就是摩西、亞倫照耶和華藉摩西所吩咐數點的。</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46"> 凡被數的利未人，就是摩西、亞倫並以色列眾首領，照着家室、宗族所數點的，</span>
<span className="v" id="v47" data-v="47" data-xref="哥林多前書 12:4–31; 羅馬書 12:6–8; 民數記 4:3"> 從三十歲直到五十歲，凡前來任職、在會幕裏做抬物之工的，共有八千五百八十名。</span>
<span className="v" id="v49" data-v="49" data-xref="民數記 1:54; 民數記 4:31; 民數記 4:15"> 摩西按他們所辦的事、所抬的物，憑耶和華的吩咐數點他們；他們這樣被摩西數點，正如耶和華所吩咐他的。</span>
</div>
</div>

</div>

## 摩押王召巴蘭

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命記 34:1; 申命記 3:8; 民數記 21:20"> 以色列人起行，在摩押平原、約旦河東，對着耶利哥安營。</span>
<span className="v" id="v2" data-v="2" data-xref="士師記 11:25; 民數記 21:20–35; 民數記 21:3"> 以色列人向亞摩利人所行的一切事，西撥的兒子巴勒都看見了。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 15:15; 以賽亞書 23:5; 約書亞記 9:24"> 摩押人因以色列民甚多，就大大懼怕，心內憂急，</span>
<span className="v" id="v4" data-v="4" data-xref="民數記 25:15–18; 民數記 31:8; 民數記 24:17"> 對米甸的長老說：「現在這眾人要把我們四圍所有的一概餂盡，就如牛餂盡田間的草一般。」那時西撥的兒子巴勒作摩押王。</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 23:4; 約書亞記 24:9; 彌迦書 6:5"> 他差遣使者往大河邊的毗奪去，到比珥的兒子巴蘭本鄉那裏，召巴蘭來，說：「有一宗民從埃及出來，遮滿地面，與我對居。</span>
<span className="v" id="v6" data-v="6" data-xref="民數記 24:9; 民數記 23:7–8; 使徒行傳 16:16"> 這民比我強盛，現在求你來為我咒詛他們，或者我能得勝，攻打他們，趕出此地。因為我知道，你為誰祝福，誰就得福；你咒詛誰，誰就受咒詛。」</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳記上 9:7–8; 彌迦書 3:11; 羅馬書 16:18"> 摩押的長老和米甸的長老手裏拿着卦金，到了巴蘭那裏，將巴勒的話都告訴了他。</span>
<span className="v" id="v8" data-v="8" data-xref="民數記 23:12; 民數記 22:19–20; 耶利米書 12:2"> 巴蘭說：「你們今夜在這裏住宿，我必照耶和華所曉諭我的回報你們。」摩押的使臣就在巴蘭那裏住下了。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 20:3; 民數記 22:20; 創世記 16:8"> 上帝臨到巴蘭那裏，說：「在你這裏的人都是誰？」</span>
<span className="v" id="v10" data-v="10"> 巴蘭回答說：「是摩押王西撥的兒子巴勒打發人到我這裏來，說：</span>
<span className="v" id="v11" data-v="11"> 『從埃及出來的民遮滿地面，你來為我咒詛他們，或者我能與他們爭戰，把他們趕出去。』」</span>
<span className="v" id="v12" data-v="12" data-xref="申命記 23:5; 以弗所書 1:3; 創世記 12:2"> 上帝對巴蘭說：「你不可同他們去，也不可咒詛那民，因為那民是蒙福的。」</span>
<span className="v" id="v13" data-v="13" data-xref="申命記 23:5; 民數記 22:14"> 巴蘭早晨起來，對巴勒的使臣說：「你們回本地去吧，因為耶和華不容我和你們同去。」</span>
<span className="v" id="v14" data-v="14" data-xref="民數記 22:37; 民數記 22:13"> 摩押的使臣就起來，回巴勒那裏去，說：「巴蘭不肯和我們同來。」</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行傳 10:7–8; 民數記 22:7–8"> 巴勒又差遣使臣，比先前的又多又尊貴。</span>
<span className="v" id="v16" data-v="16"> 他們到了巴蘭那裏，對他說：「西撥的兒子巴勒這樣說：『求你不容甚麼事攔阻你不到我這裏來，</span>
<span className="v" id="v17" data-v="17" data-xref="民數記 24:11; 以斯帖記 5:11; 馬太福音 4:8–9"> 因為我必使你得極大的尊榮。你向我要甚麼，我就給你甚麼；只求你來為我咒詛這民。』」</span>
<span className="v" id="v18" data-v="18" data-xref="民數記 24:13; 列王紀上 22:14; 歷代志下 18:13"> 巴蘭回答巴勒的臣僕說：「巴勒就是將他滿屋的金銀給我，我行大事小事也不得越過耶和華－我上帝的命。</span>
<span className="v" id="v19" data-v="19" data-xref="猶大書 1:11; 彼得後書 2:3; 提摩太前書 6:9–10"> 現在我請你們今夜在這裏住宿，等我得知耶和華還要對我說甚麼。」</span>
<span className="v" id="v20" data-v="20" data-xref="民數記 23:12; 民數記 24:13; 民數記 23:26"> 當夜，上帝臨到巴蘭那裏，說：「這些人若來召你，你就起來同他們去，你只要遵行我對你所說的話。」</span>
</div>
</div>

## 巴蘭和他的驢

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="箴言 1:15–16"> 巴蘭早晨起來，備上驢，和摩押的使臣一同去了。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及記 4:24; 耶利米哀歌 2:4; 民數記 22:32"> 上帝因他去就發了怒；耶和華的使者站在路上敵擋他。他騎着驢，有兩個僕人跟隨他。</span>
<span className="v" id="v23" data-v="23" data-xref="猶大書 1:11; 彼得後書 2:16; 哥林多前書 1:27–29"> 驢看見耶和華的使者站在路上，手裏有拔出來的刀，就從路上跨進田間，巴蘭便打驢，要叫牠回轉上路。</span>
<span className="v" id="v24" data-v="24"> 耶和華的使者就站在葡萄園的窄路上；這邊有牆，那邊也有牆。</span>
<span className="v" id="v25" data-v="25" data-xref="以賽亞書 47:12; 約伯記 5:13–15"> 驢看見耶和華的使者，就貼靠牆，將巴蘭的腳擠傷了；巴蘭又打驢。</span>
<span className="v" id="v26" data-v="26" data-xref="何西阿書 2:6; 以賽亞書 26:11"> 耶和華的使者又往前去，站在狹窄之處，左右都沒有轉折的地方。</span>
<span className="v" id="v27" data-v="27" data-xref="箴言 14:16; 雅各書 1:19; 箴言 27:3–4"> 驢看見耶和華的使者，就臥在巴蘭底下，巴蘭發怒，用杖打驢。</span>
<span className="v" id="v28" data-v="28" data-xref="彼得後書 2:16; 路加福音 1:37; 出埃及記 4:11"> 耶和華叫驢開口，對巴蘭說：「我向你行了甚麼，你竟打我這三次呢？」</span>
<span className="v" id="v29" data-v="29" data-xref="箴言 12:10; 馬太福音 15:19; 箴言 12:16"> 巴蘭對驢說：「因為你戲弄我，我恨不能手中有刀，把你殺了。」</span>
<span className="v" id="v30" data-v="30" data-xref="彼得後書 2:16; 哥林多前書 1:27–28"> 驢對巴蘭說：「我不是你從小時直到今日所騎的驢嗎？我素常向你這樣行過嗎？」巴蘭說：「沒有。」</span>
<span className="v" id="v31" data-v="31" data-xref="創世記 21:19; 路加福音 24:31; 使徒行傳 26:18"> 當時，耶和華使巴蘭的眼目明亮，他就看見耶和華的使者站在路上，手裏有拔出來的刀，巴蘭便低頭俯伏在地。</span>
<span className="v" id="v32" data-v="32" data-xref="箴言 28:18; 使徒行傳 13:10; 民數記 22:22"> 耶和華的使者對他說：「你為何這三次打你的驢呢？我出來敵擋你，因你所行的，在我面前偏僻。</span>
<span className="v" id="v33" data-v="33" data-xref="民數記 16:33–35; 民數記 14:37; 列王紀上 13:24–28"> 驢看見我就三次從我面前偏過去；驢若沒有偏過去，我早把你殺了，留牠存活。」</span>
<span className="v" id="v34" data-v="34" data-xref="約伯記 34:31–32; 撒母耳記下 12:13; 撒母耳記上 15:24"> 巴蘭對耶和華的使者說：「我有罪了。我不知道你站在路上阻擋我；你若不喜歡我去，我就轉回。」</span>
<span className="v" id="v35" data-v="35" data-xref="帖撒羅尼迦後書 2:9–12; 以賽亞書 37:26–29; 民數記 22:20–21"> 耶和華的使者對巴蘭說：「你同這些人去吧！你只要說我對你說的話。」於是巴蘭同着巴勒的使臣去了。</span>
</div>
</div>

## 巴勒歡迎巴蘭

<div className="bt">
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="以賽亞書 16:2; 使徒行傳 28:15; 耶利米書 48:20"> 巴勒聽見巴蘭來了，就往摩押京城去迎接他；這城是在邊界上，在亞嫩河旁。</span>
<span className="v" id="v37" data-v="37" data-xref="民數記 24:11; 約翰福音 5:44; 馬太福音 4:8–9"> 巴勒對巴蘭說：「我不是急急地打發人到你那裏去召你嗎？你為何不到我這裏來呢？我豈不能使你得尊榮嗎？」</span>
<span className="v" id="v38" data-v="38" data-xref="民數記 22:18; 箴言 19:21; 民數記 23:16"> 巴蘭說：「我已經到你這裏來了！現在我豈能擅自說甚麼呢？上帝將甚麼話傳給我，我就說甚麼。」</span>
<span className="v" id="v39" data-v="39"> 巴蘭和巴勒同行，來到基列‧胡瑣。</span>
<span className="v" id="v40" data-v="40" data-xref="民數記 23:14; 箴言 1:16; 民數記 23:2"> 巴勒宰了<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是獻">a</a></sup>牛羊，送給巴蘭和陪伴的使臣。</span>
</div>

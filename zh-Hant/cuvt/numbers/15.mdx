## 獻祭的條例

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華對摩西說：</span>
<span className="v" id="v2" data-v="2" data-xref="利未記 23:10; 民數記 15:18; 利未記 25:2"> 「你曉諭以色列人說：你們到了我所賜給你們居住的地，</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 29:18; 創世記 8:21; 腓立比書 4:18"> 若願意從牛群羊群中取牛羊作火祭，獻給耶和華，無論是燔祭是平安祭，為要還特許的願，或是作甘心祭，或是逢你們節期獻的，都要奉給耶和華為馨香之祭。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及記 29:40; 利未記 23:13; 利未記 6:14"> 那獻供物的就要將細麵伊法十分之一，並油一欣四分之一，調和作素祭，獻給耶和華。</span>
<span className="v" id="v5" data-v="5" data-xref="民數記 28:7; 民數記 28:14; 士師記 9:13"> 無論是燔祭是平安祭，你要為每隻綿羊羔，一同預備奠祭的酒一欣四分之一。</span>
<span className="v" id="v6" data-v="6" data-xref="民數記 28:12–14; 民數記 15:4"> 為公綿羊預備細麵伊法十分之二，並油一欣三分之一，調和作素祭，</span>
<span className="v" id="v7" data-v="7"> 又用酒一欣三分之一作奠祭，獻給耶和華為馨香之祭。</span>
<span className="v" id="v8" data-v="8" data-xref="利未記 3:1; 利未記 7:11–18; 利未記 1:3"> 你預備公牛作燔祭，或是作平安祭，為要還特許的願，或是作平安祭，獻給耶和華，</span>
<span className="v" id="v9" data-v="9" data-xref="民數記 28:14; 民數記 28:12; 利未記 6:14"> 就要把細麵伊法十分之三，並油半欣，調和作素祭，和公牛一同獻上，</span>
<span className="v" id="v10" data-v="10" data-xref="民數記 15:5; 民數記 6:15"> 又用酒半欣作奠祭，獻給耶和華為馨香的火祭。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11"> 「獻公牛、公綿羊、綿羊羔、山羊羔，每隻都要這樣辦理。</span>
<span className="v" id="v12" data-v="12"> 照你們所預備的數目，按着隻數都要這樣辦理。</span>
<span className="v" id="v13" data-v="13"> 凡本地人將馨香的火祭獻給耶和華，都要這樣辦理。</span>
<span className="v" id="v14" data-v="14"> 若有外人和你們同居，或有人世世代代住在你們中間，願意將馨香的火祭獻給耶和華，你們怎樣辦理，他也要照樣辦理。</span>
<span className="v" id="v15" data-v="15" data-xref="民數記 9:14; 民數記 15:29; 出埃及記 12:49"> 至於會眾，你們和同居的外人都歸一例，作為你們世世代代永遠的定例，在耶和華面前，你們怎樣，寄居的也要怎樣。</span>
<span className="v" id="v16" data-v="16"> 你們並與你們同居的外人當有一樣的條例，一樣的典章。」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17"> 耶和華對摩西說：</span>
<span className="v" id="v18" data-v="18" data-xref="民數記 15:2; 申命記 26:1–15"> 「你曉諭以色列人說：你們到了我所領你們進去的那地，</span>
<span className="v" id="v19" data-v="19" data-xref="約書亞記 5:11–12"> 吃那地的糧食，就要把舉祭獻給耶和華。</span>
<span className="v" id="v20" data-v="20" data-xref="利未記 2:14; 出埃及記 34:26; 申命記 26:2–10"> 你們要用初熟的麥子磨麵，做餅當舉祭奉獻；你們舉上，好像舉禾場的舉祭一樣。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及記 29:28; 民數記 18:26"> 你們世世代代要用初熟的麥子磨麵，當舉祭獻給耶和華。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="利未記 4:2; 利未記 4:27; 利未記 5:15–17"> 「你們有錯誤的時候，不守耶和華所曉諭摩西的這一切命令，</span>
<span className="v" id="v23" data-v="23"> 就是耶和華藉摩西一切所吩咐你們的，自那日以至你們的世世代代，</span>
<span className="v" id="v24" data-v="24" data-xref="利未記 4:23; 利未記 4:13–21; 利未記 5:15"> 若有誤行，是會眾所不知道的，後來全會眾就要將一隻公牛犢作燔祭，並照典章把素祭和奠祭一同獻給耶和華為馨香之祭，又獻一隻公山羊作贖罪祭。</span>
<span className="v" id="v25" data-v="25" data-xref="利未記 4:20; 羅馬書 3:25; 希伯來書 2:17"> 祭司要為以色列全會眾贖罪，他們就必蒙赦免，因為這是錯誤。他們又因自己的錯誤，把供物，就是向耶和華獻的火祭和贖罪祭，一並奉到耶和華面前。</span>
<span className="v" id="v26" data-v="26" data-xref="民數記 15:24"> 以色列全會眾和寄居在他們中間的外人就必蒙赦免，因為這罪是百姓誤犯的。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="利未記 4:27–28; 使徒行傳 17:30; 使徒行傳 3:17"> 「若有一個人誤犯了罪，他就要獻一歲的母山羊作贖罪祭。</span>
<span className="v" id="v28" data-v="28" data-xref="利未記 4:35"> 那誤行的人犯罪的時候，祭司要在耶和華面前為他贖罪，他就必蒙赦免。</span>
<span className="v" id="v29" data-v="29" data-xref="民數記 15:15; 利未記 16:29; 利未記 17:15"> 以色列中的本地人和寄居在他們中間的外人，若誤行了甚麼事，必歸一樣的條例。</span>
<span className="v" id="v30" data-v="30" data-xref="希伯來書 10:26; 詩篇 19:13; 申命記 1:43"> 但那擅敢行事的，無論是本地人是寄居的，他褻瀆了耶和華，必從民中剪除。</span>
<span className="v" id="v31" data-v="31" data-xref="撒母耳記下 12:9; 箴言 13:13; 以西結書 18:20"> 因他藐視耶和華的言語，違背耶和華的命令，那人總要剪除；他的罪孽要歸到他身上。」</span>
</div>
</div>

## 違反安息日的人

<div className="bt">
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="出埃及記 35:2–3; 出埃及記 31:14–15; 出埃及記 20:8–10"> 以色列人在曠野的時候，遇見一個人在安息日撿柴。</span>
<span className="v" id="v33" data-v="33" data-xref="約翰福音 8:3–20"> 遇見他撿柴的人，就把他帶到摩西、亞倫並全會眾那裏，</span>
<span className="v" id="v34" data-v="34" data-xref="利未記 24:12; 民數記 9:8"> 將他收在監內；因為當怎樣辦他，還沒有指明。</span>
<span className="v" id="v35" data-v="35" data-xref="使徒行傳 7:58; 出埃及記 31:14–15; 列王紀上 21:13"> 耶和華吩咐摩西說：「總要把那人治死；全會眾要在營外用石頭把他打死。」</span>
<span className="v" id="v36" data-v="36" data-xref="約書亞記 7:25"> 於是全會眾將他帶到營外，用石頭打死他，是照耶和華所吩咐摩西的。</span>
</div>
</div>

## 有關衣服繸子的條例

<div className="bt">
<div className="bp">
<span className="v" id="v37" data-v="37"> 耶和華曉諭摩西說：</span>
<span className="v" id="v38" data-v="38" data-xref="馬太福音 23:5; 申命記 22:12; 馬太福音 9:20"> 「你吩咐以色列人，叫他們世世代代在衣服邊上做繸子，又在底邊的繸子上釘一根藍細帶子。</span>
<span className="v" id="v39" data-v="39" data-xref="詩篇 106:39; 箴言 28:26; 詩篇 73:27"> 你們佩帶這繸子，好叫你們看見就記念遵行耶和華一切的命令，不隨從自己的心意、眼目行邪淫，像你們素常一樣；</span>
<span className="v" id="v40" data-v="40" data-xref="羅馬書 12:1; 帖撒羅尼迦前書 4:7; 利未記 11:44–45"> 使你們記念遵行我一切的命令，成為聖潔，歸與你們的上帝。</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="彼得前書 2:9–10; 以西結書 36:25–27; 希伯來書 11:16"> 「我是耶和華－你們的上帝，曾把你們從埃及地領出來，要作你們的上帝。我是耶和華－你們的上帝。」</span>
</div>

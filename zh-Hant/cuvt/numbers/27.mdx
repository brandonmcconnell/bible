## 西羅非哈的女兒們

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民數記 26:33; 加拉太書 3:28; 歷代志上 7:15"> 屬約瑟的兒子瑪拿西的各族，有瑪拿西的玄孫，瑪吉的曾孫，基列的孫子，希弗的兒子西羅非哈的女兒，名叫瑪拉、挪阿、曷拉、密迦、得撒。她們前來，</span>
<span className="v" id="v2" data-v="2" data-xref="民數記 15:33–34; 申命記 17:8–10; 出埃及記 18:19–26"> 站在會幕門口，在摩西和祭司以利亞撒，並眾首領與全會眾面前，說：</span>
<span className="v" id="v3" data-v="3" data-xref="民數記 26:64–65; 以西結書 18:4; 民數記 14:35"> 「我們的父親死在曠野。他不與可拉同黨聚集攻擊耶和華，是在自己罪中死的；他也沒有兒子。</span>
<span className="v" id="v4" data-v="4" data-xref="約書亞記 17:4; 詩篇 109:13; 出埃及記 32:11"> 為甚麼因我們的父親沒有兒子就把他的名從他族中除掉呢？求你們在我們父親的弟兄中分給我們產業。」</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="利未記 24:12–13; 約伯記 23:4; 箴言 3:5–6"> 於是，摩西將她們的案件呈到耶和華面前。</span>
<span className="v" id="v6" data-v="6" data-xref="加拉太書 3:28; 詩篇 68:5–6"> 耶和華曉諭摩西說：</span>
<span className="v" id="v7" data-v="7" data-xref="加拉太書 3:28; 耶利米書 49:11; 約書亞記 17:4"> 「西羅非哈的女兒說得有理。你定要在她們父親的弟兄中，把地分給她們為業；要將她們父親的產業歸給她們。</span>
<span className="v" id="v8" data-v="8"> 你也要曉諭以色列人說：『人若死了沒有兒子，就要把他的產業歸給他的女兒。</span>
<span className="v" id="v9" data-v="9"> 他若沒有女兒，就要把他的產業給他的弟兄。</span>
<span className="v" id="v10" data-v="10"> 他若沒有弟兄，就要把他的產業給他父親的弟兄。</span>
<span className="v" id="v11" data-v="11" data-xref="民數記 35:29; 路得記 4:3–6; 耶利米書 32:8"> 他父親若沒有弟兄，就要把他的產業給他族中最近的親屬，他便要得為業。』這要作以色列人的律例典章，是照耶和華吩咐摩西的。」</span>
</div>
</div>

## 約書亞被選為摩西的繼承人

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="民數記 33:47–48; 申命記 34:1–4; 申命記 3:23–27"> 耶和華對摩西說：「你上這亞巴琳山，觀看我所賜給以色列人的地。</span>
<span className="v" id="v13" data-v="13" data-xref="申命記 10:6; 民數記 31:2; 民數記 20:24–28"> 看了以後，你也必歸到你列祖<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是本民">a</a></sup>那裏，像你哥哥亞倫一樣。</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 1:37; 民數記 20:8–13; 出埃及記 17:7"> 因為你們在尋的曠野，當會眾爭鬧的時候，違背了我的命，沒有在湧水之地、會眾眼前尊我為聖。」（這水就是尋的曠野加低斯米利巴水。）</span>
<span className="v" id="v15" data-v="15"> 摩西對耶和華說：</span>
<span className="v" id="v16" data-v="16" data-xref="民數記 16:22; 耶利米書 3:15; 希伯來書 12:9"> 「願耶和華萬人之靈的上帝，立一個人治理會眾，</span>
<span className="v" id="v17" data-v="17" data-xref="以西結書 34:5; 馬可福音 6:34; 列王紀上 22:17"> 可以在他們面前出入，也可以引導他們，免得耶和華的會眾如同沒有牧人的羊群一般。」</span>
<span className="v" id="v18" data-v="18" data-xref="申命記 34:9; 民數記 27:23; 創世記 41:38"> 耶和華對摩西說：「嫩的兒子約書亞是心中有聖靈的；你將他領來，按手在他頭上，</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 3:28; 申命記 31:7–8; 申命記 31:23"> 使他站在祭司以利亞撒和全會眾面前，囑咐他，</span>
<span className="v" id="v20" data-v="20" data-xref="約書亞記 1:16–18; 撒母耳記上 10:9; 列王紀下 2:9–10"> 又將你的尊榮給他幾分，使以色列全會眾都聽從他。</span>
<span className="v" id="v21" data-v="21" data-xref="約書亞記 9:14; 撒母耳記上 28:6; 出埃及記 28:30"> 他要站在祭司以利亞撒面前；以利亞撒要憑烏陵的判斷，在耶和華面前為他求問。他和以色列全會眾都要遵以利亞撒的命出入。」</span>
<span className="v" id="v22" data-v="22"> 於是摩西照耶和華所吩咐的將約書亞領來，使他站在祭司以利亞撒和全會眾面前，</span>
<span className="v" id="v23" data-v="23" data-xref="申命記 3:28; 民數記 27:19; 申命記 31:7–8"> 按手在他頭上，囑咐他，是照耶和華藉摩西所說的話。</span>
</div>
</div>

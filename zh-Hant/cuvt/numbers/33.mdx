## 從埃及到摩押

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="詩篇 77:20; 彌迦書 6:4; 出埃及記 12:51"> 以色列人按着軍隊，在摩西、亞倫的手下出埃及地所行的路程<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或譯：站口；下同">a</a></sup>記在下面。</span>
<span className="v" id="v2" data-v="2" data-xref="民數記 9:17–23; 申命記 10:11; 民數記 10:6"> 摩西遵着耶和華的吩咐記載他們所行的路程，其路程乃是這樣：</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 14:8; 出埃及記 12:37; 出埃及記 13:4"> 正月十五日，就是逾越節的次日，以色列人從蘭塞起行，在一切埃及人眼前昂然無懼地出去。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及記 12:12; 以賽亞書 19:1; 出埃及記 18:11"> 那時，埃及人正葬埋他們的長子，就是耶和華在他們中間所擊殺的；耶和華也敗壞他們的神。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 12:37"> 以色列人從蘭塞起行，安營在疏割。</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及記 13:20"> 從疏割起行，安營在曠野邊的以倘。</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及記 14:2; 出埃及記 14:9; 民數記 33:8"> 從以倘起行，轉到比‧哈希錄，是在巴力‧洗分對面，就在密奪安營。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及記 15:22–26; 出埃及記 14:21–31"> 從比‧哈希錄對面起行，經過海中到了書珥曠野，又在伊坦的曠野走了三天的路程，就安營在瑪拉。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及記 15:27"> 從瑪拉起行，來到以琳（以琳有十二股水泉，七十棵棕樹），就在那裏安營。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及記 16:1; 出埃及記 17:1"> 從以琳起行，安營在紅海邊。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及記 16:1"> 從紅海邊起行，安營在汛的曠野。</span>
<span className="v" id="v12" data-v="12"> 從汛的曠野起行，安營在脫加。</span>
<span className="v" id="v13" data-v="13"> 從脫加起行，安營在亞錄。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及記 17:1–8; 出埃及記 19:2"> 從亞錄起行，安營在利非訂；在那裏，百姓沒有水喝。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及記 19:1–2; 出埃及記 16:1"> 從利非訂起行，安營在西奈的曠野。</span>
<span className="v" id="v16" data-v="16" data-xref="民數記 11:34; 民數記 10:11–13; 民數記 10:33"> 從西奈的曠野起行，安營在基博羅‧哈他瓦。</span>
<span className="v" id="v17" data-v="17" data-xref="民數記 11:35"> 從基博羅‧哈他瓦起行，安營在哈洗錄。</span>
<span className="v" id="v18" data-v="18" data-xref="民數記 12:16"> 從哈洗錄起行，安營在利提瑪。</span>
<span className="v" id="v19" data-v="19"> 從利提瑪起行，安營在臨門‧帕烈。</span>
<span className="v" id="v20" data-v="20"> 從臨門‧帕烈起行，安營在立拿。</span>
<span className="v" id="v21" data-v="21" data-xref="申命記 1:1"> 從立拿起行，安營在勒撒。</span>
<span className="v" id="v22" data-v="22"> 從勒撒起行，安營在基希拉他。</span>
<span className="v" id="v23" data-v="23"> 從基希拉他起行，安營在沙斐山。</span>
<span className="v" id="v24" data-v="24"> 從沙斐山起行，安營在哈拉大。</span>
<span className="v" id="v25" data-v="25"> 從哈拉大起行，安營在瑪吉希錄。</span>
<span className="v" id="v26" data-v="26"> 從瑪吉希錄起行，安營在他哈。</span>
<span className="v" id="v27" data-v="27"> 從他哈起行，安營在他拉。</span>
<span className="v" id="v28" data-v="28"> 從他拉起行，安營在密加。</span>
<span className="v" id="v29" data-v="29"> 從密加起行，安營在哈摩拿。</span>
<span className="v" id="v30" data-v="30" data-xref="申命記 10:5–6"> 從哈摩拿起行，安營在摩西錄。</span>
<span className="v" id="v31" data-v="31" data-xref="申命記 10:6; 創世記 36:27; 歷代志上 1:43"> 從摩西錄起行，安營在比尼‧亞干。</span>
<span className="v" id="v32" data-v="32" data-xref="申命記 10:7"> 從比尼‧亞干起行，安營在曷‧哈及甲。</span>
<span className="v" id="v33" data-v="33" data-xref="申命記 10:7"> 從曷‧哈及甲起行，安營在約巴他。</span>
<span className="v" id="v34" data-v="34"> 從約巴他起行，安營在阿博拿。</span>
<span className="v" id="v35" data-v="35" data-xref="申命記 2:8; 列王紀上 9:26; 列王紀上 22:48"> 從阿博拿起行，安營在以旬‧迦別。</span>
<span className="v" id="v36" data-v="36" data-xref="民數記 20:1; 民數記 27:14; 申命記 32:51"> 從以旬‧迦別起行，安營在尋的曠野，就是加低斯。</span>
<span className="v" id="v37" data-v="37" data-xref="民數記 21:4; 民數記 20:22–23; 民數記 20:16"> 從加低斯起行，安營在何珥山，以東地的邊界。</span>
<span className="v" id="v38" data-v="38" data-xref="申命記 10:6; 申命記 32:50; 民數記 20:24–28"> 以色列人出了埃及地後四十年，五月初一日，祭司亞倫遵着耶和華的吩咐上何珥山，就死在那裏。</span>
<span className="v" id="v39" data-v="39"> 亞倫死在何珥山的時候年一百二十三歲。</span>
<span className="v" id="v40" data-v="40" data-xref="民數記 21:1–9"> 住在迦南南地的迦南人亞拉得王聽說以色列人來了。</span>
<span className="v" id="v41" data-v="41" data-xref="民數記 21:4"> 以色列人從何珥山起行，安營在撒摩拿。</span>
<span className="v" id="v42" data-v="42"> 從撒摩拿起行，安營在普嫩。</span>
<span className="v" id="v43" data-v="43" data-xref="民數記 21:10"> 從普嫩起行，安營在阿伯。</span>
<span className="v" id="v44" data-v="44" data-xref="民數記 21:11"> 從阿伯起行，安營在以耶‧亞巴琳，摩押的邊界。</span>
<span className="v" id="v45" data-v="45"> 從以耶‧亞巴琳起行，安營在底本‧迦得。</span>
<span className="v" id="v46" data-v="46" data-xref="耶利米書 48:18; 以西結書 6:14; 以賽亞書 15:2"> 從底本‧迦得起行，安營在亞門‧低比拉太音。</span>
<span className="v" id="v47" data-v="47" data-xref="申命記 32:49; 申命記 34:1; 民數記 27:12"> 從亞門‧低比拉太音起行，安營在尼波對面的亞巴琳山裏。</span>
<span className="v" id="v48" data-v="48" data-xref="民數記 22:1"> 從亞巴琳山起行，安營在摩押平原－約旦河邊、耶利哥對面。</span>
<span className="v" id="v49" data-v="49" data-xref="約書亞記 2:1; 約書亞記 13:20; 民數記 25:1–9"> 他們在摩押平原沿約旦河邊安營，從伯‧耶施末直到亞伯‧什亭。</span>
</div>
</div>

## 過約旦河前的指示

<div className="bt">
<div className="bp">
<span className="v" id="v50" data-v="50" data-xref="民數記 33:48–49"> 耶和華在摩押平原－約旦河邊、耶利哥對面曉諭摩西說：</span>
<span className="v" id="v51" data-v="51" data-xref="約書亞記 3:17; 申命記 9:1; 申命記 7:1"> 「你吩咐以色列人說：你們過約旦河進迦南地的時候，</span>
<span className="v" id="v52" data-v="52" data-xref="出埃及記 23:24; 利未記 26:1; 申命記 20:16–18"> 就要從你們面前趕出那裏所有的居民，毀滅他們一切鏨成的石像和他們一切鑄成的偶像，又拆毀他們一切的邱壇。</span>
<span className="v" id="v53" data-v="53" data-xref="申命記 11:31; 詩篇 115:16; 申命記 32:8"> 你們要奪那地，住在其中，因我把那地賜給你們為業。</span>
<span className="v" id="v54" data-v="54" data-xref="民數記 26:53–56; 約書亞記 18:11–48; 約書亞記 15:1–12"> 你們要按家室拈鬮，承受那地；人多的，要把產業多分給他們；人少的，要把產業少分給他們。拈出何地給何人，就要歸何人。你們要按宗族的支派承受。</span>
<span className="v" id="v55" data-v="55" data-xref="士師記 2:3; 詩篇 106:34–36; 申命記 7:16"> 倘若你們不趕出那地的居民，所容留的居民就必作你們眼中的刺，肋下的荊棘，也必在你們所住的地上擾害你們。</span>
<span className="v" id="v56" data-v="56" data-xref="路加福音 21:23–24; 申命記 28:63; 利未記 20:23"> 而且我素常有意怎樣待他們，也必照樣待你們。」</span>
</div>

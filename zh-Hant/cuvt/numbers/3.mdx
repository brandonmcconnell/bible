## 亞倫的兒子們

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及記 6:20; 創世記 10:1; 出埃及記 6:16"> 耶和華在西奈山曉諭摩西的日子，亞倫和摩西的後代如下：</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 6:23; 民數記 26:60; 出埃及記 28:1"> 亞倫的兒子，長子名叫拿答，還有亞比戶、以利亞撒、以他瑪。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 28:41; 利未記 8:30; 利未記 8:12"> 這是亞倫兒子的名字，都是受膏的祭司，是摩西叫他們承接聖職供祭司職分的。</span>
<span className="v" id="v4" data-v="4" data-xref="利未記 10:1–2; 民數記 26:61"> 拿答、亞比戶在西奈的曠野向耶和華獻凡火的時候就死在耶和華面前了。他們也沒有兒子。以利亞撒、以他瑪在他們的父親亞倫面前供祭司的職分。</span>
</div>
</div>

## 利未人被派作祭司

<div className="bt">
<div className="bp">
<span className="v" id="v5" data-v="5"> 耶和華曉諭摩西說：</span>
<span className="v" id="v6" data-v="6" data-xref="申命記 10:8; 民數記 2:33; 民數記 1:49–53"> 「你使利未支派近前來，站在祭司亞倫面前好服事他，</span>
<span className="v" id="v7" data-v="7" data-xref="民數記 1:50; 民數記 8:15; 民數記 8:11"> 替他和會眾在會幕前守所吩咐的，辦理帳幕的事。</span>
<span className="v" id="v8" data-v="8" data-xref="民數記 4:33; 民數記 10:17; 以賽亞書 52:11"> 又要看守會幕的器具，並守所吩咐以色列人的，辦理帳幕的事。</span>
<span className="v" id="v9" data-v="9" data-xref="民數記 8:19; 民數記 18:6–7; 以弗所書 4:8"> 你要將利未人給亞倫和他的兒子，因為他們是從以色列人中選出來給他的。</span>
<span className="v" id="v10" data-v="10" data-xref="民數記 1:51; 民數記 3:38; 羅馬書 12:7"> 你要囑咐亞倫和他的兒子謹守自己祭司的職任。近前來的外人必被治死。」</span>
<span className="v" id="v11" data-v="11"> 耶和華曉諭摩西說：</span>
<span className="v" id="v12" data-v="12" data-xref="民數記 3:41; 民數記 8:16; 民數記 18:6"> 「我從以色列人中揀選了利未人，代替以色列人一切頭生的；利未人要歸我。</span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 2:23; 出埃及記 13:12; 出埃及記 13:2"> 因為凡頭生的是我的；我在埃及地擊殺一切頭生的那日就把以色列中一切頭生的，連人帶牲畜都分別為聖歸我；他們定要屬我。我是耶和華。」</span>
</div>
</div>

## 利未人男丁的統計

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14"> 耶和華在西奈的曠野曉諭摩西說：</span>
<span className="v" id="v15" data-v="15" data-xref="民數記 26:62; 馬可福音 10:14; 提摩太後書 3:15"> 「你要照利未人的宗族、家室數點他們。凡一個月以外的男子都要數點。」</span>
<span className="v" id="v16" data-v="16" data-xref="民數記 3:39; 民數記 4:37; 民數記 4:49"> 於是摩西照耶和華所吩咐的數點他們。</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 46:11; 出埃及記 6:16–19; 民數記 15:5–23"> 利未眾子的名字是革順、哥轄、米拉利。</span>
<span className="v" id="v18" data-v="18" data-xref="歷代志上 6:17; 歷代志上 26:1–32; 出埃及記 6:17–19"> 革順的兒子，按着家室，是立尼、示每。</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及記 6:18; 歷代志上 6:18; 歷代志上 15:17–21"> 哥轄的兒子，按着家室，是暗蘭、以斯哈、希伯倫、烏薛。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及記 6:19; 歷代志上 6:19; 民數記 3:33"> 米拉利的兒子，按着家室，是抹利、母示。這些按着宗族是利未人的家室。</span>
<span className="v" id="v21" data-v="21"> 屬革順的，有立尼族、示每族。這是革順的二族。</span>
<span className="v" id="v22" data-v="22" data-xref="民數記 4:38–40"> 其中被數、從一個月以外所有的男子共有七千五百名。</span>
<span className="v" id="v23" data-v="23" data-xref="民數記 1:53; 民數記 2:17"> 這革順的二族要在帳幕後西邊安營。</span>
<span className="v" id="v24" data-v="24"> 拉伊勒的兒子以利雅薩作革順人宗族的首領。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及記 25:9; 歷代志上 23:32; 歷代志上 9:14–33"> 革順的子孫在會幕中所要看守的，就是帳幕和罩棚，並罩棚的蓋與會幕的門簾，</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及記 35:18; 出埃及記 38:9–16; 出埃及記 27:9–16"> 院子的帷子和門簾（院子是圍帳幕和壇的），並一切使用的繩子。</span>
<span className="v" id="v27" data-v="27" data-xref="歷代志上 26:23; 民數記 3:19; 歷代志上 23:12"> 屬哥轄的，有暗蘭族、以斯哈族、希伯倫族、烏薛族。這是哥轄的諸族。</span>
<span className="v" id="v28" data-v="28" data-xref="民數記 3:31; 民數記 4:35–36; 民數記 3:7"> 按所有男子的數目，從一個月以外看守聖所的，共有八千六百名。</span>
<span className="v" id="v29" data-v="29" data-xref="民數記 1:53; 民數記 3:23; 民數記 2:10"> 哥轄兒子的諸族要在帳幕的南邊安營。</span>
<span className="v" id="v30" data-v="30"> 烏薛的兒子以利撒反作哥轄宗族家室的首領。</span>
<span className="v" id="v31" data-v="31" data-xref="出埃及記 36:35–36; 出埃及記 27:1–8; 出埃及記 26:31–33"> 他們所要看守的是約櫃、桌子、燈臺、兩座壇與聖所內使用的器皿，並簾子和一切使用之物。</span>
<span className="v" id="v32" data-v="32" data-xref="民數記 4:27; 民數記 4:16; 民數記 20:25–28"> 祭司亞倫的兒子以利亞撒作利未人眾首領的領袖，要監察那些看守聖所的人。</span>
<span className="v" id="v33" data-v="33" data-xref="民數記 3:20; 歷代志上 6:19; 歷代志上 23:21"> 屬米拉利的，有抹利族、母示族。這是米拉利的二族。</span>
<span className="v" id="v34" data-v="34" data-xref="民數記 2:9; 民數記 2:11; 民數記 1:21"> 他們被數的，按所有男子的數目，從一個月以外的，共有六千二百名。</span>
<span className="v" id="v35" data-v="35" data-xref="民數記 1:53; 民數記 2:25; 民數記 3:28–29"> 亞比亥的兒子蘇列作米拉利二宗族的首領。他們要在帳幕的北邊安營。</span>
<span className="v" id="v36" data-v="36" data-xref="出埃及記 26:32; 出埃及記 26:37; 出埃及記 26:15–29"> 米拉利子孫的職分是看守帳幕的板、閂、柱子、帶卯的座，和帳幕一切所使用的器具，</span>
<span className="v" id="v37" data-v="37"> 院子四圍的柱子、帶卯的座、橛子，和繩子。</span>
<span className="v" id="v38" data-v="38" data-xref="民數記 3:10; 民數記 1:53; 民數記 2:3"> 在帳幕前東邊，向日出之地安營的是摩西、亞倫，和亞倫的兒子。他們看守聖所，替以色列人守耶和華所吩咐的。近前來的外人必被治死。</span>
<span className="v" id="v39" data-v="39" data-xref="民數記 26:62; 馬太福音 7:14; 民數記 4:47–48"> 凡被數的利未人，就是摩西、亞倫照耶和華吩咐所數的，按着家室，從一個月以外的男子，共有二萬二千名。</span>
</div>
</div>

## 利未人代替長子的地位

<div className="bt">
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="民數記 3:15; 路加福音 10:20; 詩篇 87:6"> 耶和華對摩西說：「你要從以色列人中數點一個月以外、凡頭生的男子，把他們的名字記下。</span>
<span className="v" id="v41" data-v="41" data-xref="民數記 3:12; 民數記 3:45; 民數記 8:16"> 我是耶和華。你要揀選利未人歸我，代替以色列人所有頭生的，也取利未人的牲畜代替以色列所有頭生的牲畜。」</span>
<span className="v" id="v42" data-v="42"> 摩西就照耶和華所吩咐的把以色列人頭生的都數點了。</span>
<span className="v" id="v43" data-v="43" data-xref="民數記 3:39"> 按人名的數目，從一個月以外、凡頭生的男子，共有二萬二千二百七十三名。</span>
<span className="v" id="v44" data-v="44"> 耶和華曉諭摩西說：</span>
<span className="v" id="v45" data-v="45" data-xref="民數記 3:12; 民數記 3:40–41"> 「你揀選利未人代替以色列人所有頭生的，也取利未人的牲畜代替以色列人的牲畜。利未人要歸我；我是耶和華。</span>
<span className="v" id="v46" data-v="46" data-xref="出埃及記 13:13; 民數記 18:15–16"> 以色列人中頭生的男子比利未人多二百七十三個，必當將他們贖出來。</span>
<span className="v" id="v47" data-v="47" data-xref="出埃及記 30:13; 利未記 27:6; 民數記 18:16"> 你要按人丁，照聖所的平，每人取贖銀五舍客勒（一舍客勒是二十季拉），</span>
<span className="v" id="v48" data-v="48"> 把那多餘之人的贖銀交給亞倫和他的兒子。」</span>
<span className="v" id="v49" data-v="49"> 於是摩西從那被利未人所贖以外的人取了贖銀。</span>
<span className="v" id="v50" data-v="50" data-xref="民數記 3:46–47; 彼得前書 3:18; 馬太福音 20:28"> 從以色列人頭生的所取之銀，按聖所的平，有一千三百六十五舍客勒。</span>
<span className="v" id="v51" data-v="51" data-xref="民數記 3:48; 民數記 16:15; 撒母耳記上 12:3–4"> 摩西照耶和華的話把這贖銀給亞倫和他的兒子，正如耶和華所吩咐的。</span>
</div>
</div>

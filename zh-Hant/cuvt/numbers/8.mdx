## 安置七盞燈

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華曉諭摩西說：</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 25:37; 出埃及記 40:25; 利未記 24:1–2"> 「你告訴亞倫說：點燈的時候，七盞燈都要向燈臺前面發光。」</span>
<span className="v" id="v3" data-v="3"> 亞倫便這樣行。他點燈臺上的燈，使燈向前發光，是照耶和華所吩咐摩西的。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及記 25:31–40; 出埃及記 25:9; 出埃及記 25:18"> 這燈臺的做法是用金子錘出來的，連座帶花都是錘出來的。摩西製造燈臺，是照耶和華所指示的樣式。</span>
</div>
</div>

## 為利未人行潔淨與奉獻禮

<div className="bt">
<div className="bp">
<span className="v" id="v5" data-v="5"> 耶和華曉諭摩西說：</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多後書 7:1; 雅各書 4:8; 出埃及記 19:15"> 「你從以色列人中選出利未人來，潔淨他們。</span>
<span className="v" id="v7" data-v="7" data-xref="民數記 19:13; 民數記 19:7–10; 利未記 8:6"> 潔淨他們當這樣行：用除罪水彈在他們身上，又叫他們用剃頭刀刮全身，洗衣服，潔淨自己。</span>
<span className="v" id="v8" data-v="8" data-xref="利未記 2:1; 出埃及記 29:1; 利未記 16:3"> 然後叫他們取一隻公牛犢，並同獻的素祭，就是調油的細麵；你要另取一隻公牛犢作贖罪祭。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及記 40:12; 利未記 8:3; 出埃及記 29:4–37"> 將利未人奉到會幕前，招聚以色列全會眾。</span>
<span className="v" id="v10" data-v="10" data-xref="利未記 1:4; 使徒行傳 6:6; 提摩太前書 4:14"> 將利未人奉到耶和華面前，以色列人要按手在他們頭上。</span>
<span className="v" id="v11" data-v="11" data-xref="利未記 7:30; 利未記 8:29; 民數記 1:49–53"> 亞倫也將他們奉到耶和華面前，為以色列人當作搖祭，使他們好辦耶和華的事。</span>
<span className="v" id="v12" data-v="12" data-xref="希伯來書 10:4–10; 出埃及記 29:10; 利未記 1:4"> 利未人要按手在那兩隻牛的頭上；你要將一隻作贖罪祭，一隻作燔祭，獻給耶和華，為利未人贖罪。</span>
<span className="v" id="v13" data-v="13" data-xref="民數記 8:21; 民數記 8:11; 羅馬書 15:16"> 你也要使利未人站在亞倫和他兒子面前，將他們當作搖祭奉給耶和華。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="民數記 3:45; 瑪拉基書 3:17; 民數記 18:6"> 「這樣，你從以色列人中將利未人分別出來，利未人便要歸我。</span>
<span className="v" id="v15" data-v="15" data-xref="民數記 8:11; 民數記 8:13; 民數記 3:23–37"> 此後利未人要進去辦會幕的事，你要潔淨他們，將他們當作搖祭奉上；</span>
<span className="v" id="v16" data-v="16" data-xref="民數記 3:12; 民數記 3:45; 民數記 3:9"> 因為他們是從以色列人中全然給我的，我揀選他們歸我，是代替以色列人中一切頭生的。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及記 13:2; 路加福音 2:23; 出埃及記 13:12–15"> 以色列人中一切頭生的，連人帶牲畜，都是我的。我在埃及地擊殺一切頭生的那天，將他們分別為聖歸我。</span>
<span className="v" id="v18" data-v="18"> 我揀選利未人代替以色列人中一切頭生的。</span>
<span className="v" id="v19" data-v="19" data-xref="民數記 1:53; 民數記 16:46; 歷代志下 26:16–20"> 我從以色列人中將利未人當作賞賜給亞倫和他的兒子，在會幕中辦以色列人的事，又為以色列人贖罪，免得他們挨近聖所，有災殃臨到他們中間。」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20"> 摩西、亞倫，並以色列全會眾便向利未人如此行。凡耶和華指着利未人所吩咐摩西的，以色列人就向他們這樣行。</span>
<span className="v" id="v21" data-v="21" data-xref="民數記 8:7; 民數記 19:19; 民數記 8:15"> 於是利未人潔淨自己，除了罪，洗了衣服；亞倫將他們當作搖祭奉到耶和華面前，又為他們贖罪，潔淨他們。</span>
<span className="v" id="v22" data-v="22" data-xref="歷代志下 31:2; 歷代志下 35:8–15; 民數記 8:15"> 然後利未人進去，在亞倫和他兒子面前，在會幕中辦事。耶和華指着利未人怎樣吩咐摩西，以色列人就怎樣向他們行了。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23"> 耶和華曉諭摩西說：</span>
<span className="v" id="v24" data-v="24" data-xref="民數記 4:3; 歷代志上 23:3; 民數記 4:23"> 「利未人是這樣：從二十五歲以外，他們要前來任職，辦會幕的事。</span>
<span className="v" id="v25" data-v="25" data-xref="民數記 4:23; 提摩太後書 4:7"> 到了五十歲要停工退任，不再辦事，</span>
<span className="v" id="v26" data-v="26" data-xref="民數記 1:53; 民數記 3:32; 提摩太前書 4:15"> 只要在會幕裏，和他們的弟兄一同伺候，謹守所吩咐的，不再辦事了。至於所吩咐利未人的，你要這樣向他們行。」</span>
</div>
</div>

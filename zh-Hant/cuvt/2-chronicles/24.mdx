## 猶大王約阿施

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歷代志上 3:11; 列王紀下 11:21–15"> 約阿施登基的時候年七歲，在耶路撒冷作王四十年。他母親名叫西比亞，是別是巴人。</span>
<span className="v" id="v2" data-v="2" data-xref="歷代志下 26:4–5; 歷代志下 25:2; 歷代志下 24:17–22"> 祭司耶何耶大在世的時候，約阿施行耶和華眼中看為正的事。</span>
<span className="v" id="v3" data-v="3" data-xref="歷代志下 24:15; 馬太福音 19:4–8; 創世記 4:19"> 耶何耶大為他娶了兩個妻，並且生兒養女。</span>
<span className="v" id="v4" data-v="4"> 此後，約阿施有意重修耶和華的殿，</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀下 12:4–7; 歷代志下 34:8–9; 歷代志下 29:3"> 便召聚眾祭司和利未人，吩咐他們說：「你們要往猶大各城去，使以色列眾人捐納銀子，每年可以修理你們上帝的殿；你們要急速辦理這事。」只是利未人不急速辦理。</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及記 30:12–16; 民數記 1:50; 民數記 17:7–8"> 王召了大祭司耶何耶大來，對他說：「從前耶和華的僕人摩西，為法櫃的帳幕與以色列會眾所定的捐項，你為何不叫利未人照這例從猶大和耶路撒冷帶來作殿的費用呢？」（</span>
<span className="v" id="v7" data-v="7" data-xref="歷代志下 21:17; 歷代志下 28:22–24; 列王紀下 12:4"> 因為那惡婦亞她利雅的眾子曾拆毀上帝的殿，又用耶和華殿中分別為聖的物供奉巴力。）</span>
<span className="v" id="v8" data-v="8" data-xref="馬可福音 12:41; 列王紀下 12:8–9"> 於是王下令，眾人做了一櫃，放在耶和華殿的門外，</span>
<span className="v" id="v9" data-v="9" data-xref="歷代志下 24:6; 馬太福音 17:24–27"> 又通告猶大和耶路撒冷的百姓，要將上帝僕人摩西在曠野所吩咐以色列人的捐項給耶和華送來。</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行傳 2:45–47; 哥林多後書 9:7; 歷代志上 29:9"> 眾首領和百姓都歡歡喜喜地將銀子送來，投入櫃中，直到捐完。</span>
<span className="v" id="v11" data-v="11" data-xref="列王紀下 12:10–12; 哥林多前書 16:2"> 利未人見銀子多了，就把櫃抬到王所派的司事面前；王的書記和大祭司的屬員來將櫃倒空，仍放在原處。日日都是這樣，積蓄的銀子甚多。</span>
<span className="v" id="v12" data-v="12" data-xref="列王紀上 5:15; 歷代志下 34:9–11"> 王與耶何耶大將銀子交給耶和華殿裏辦事的人，他們就雇了石匠、木匠重修耶和華的殿，又雇了鐵匠、銅匠修理耶和華的殿。</span>
<span className="v" id="v13" data-v="13" data-xref="尼希米記 4:7; 馬可福音 13:1–2; 哈該書 2:3"> 工人操作，漸漸修成，將上帝殿修造得與從前一樣，而且甚是堅固。</span>
<span className="v" id="v14" data-v="14" data-xref="民數記 28:2–29; 箴言 27:22; 列王紀下 12:13–14"> 工程完了，他們就把其餘的銀子拿到王與耶何耶大面前，用以製造耶和華殿供奉所用的器皿和調羹，並金銀的器皿。 耶何耶大的政策被廢棄 耶何耶大在世的時候，眾人常在耶和華殿裏獻燔祭。</span>
<span className="v" id="v15" data-v="15" data-xref="創世記 47:9; 歷代志上 23:1; 詩篇 90:10"> 耶何耶大年紀老邁，日子滿足而死。死的時候年一百三十歲，</span>
<span className="v" id="v16" data-v="16" data-xref="希伯來書 6:10; 歷代志下 31:20; 尼希米記 13:14"> 葬在大衛城列王的墳墓裏；因為他在以色列人中行善，又事奉上帝，修理上帝的殿。</span>
<span className="v" id="v17" data-v="17" data-xref="申命記 31:27; 箴言 26:28; 使徒行傳 20:29–30"> 耶何耶大死後，猶大的眾首領來朝拜王；王就聽從他們。</span>
<span className="v" id="v18" data-v="18" data-xref="約書亞記 22:20; 歷代志下 19:2; 以弗所書 5:6"> 他們離棄耶和華－他們列祖上帝的殿，去事奉亞舍拉和偶像；因他們這罪，就有忿怒臨到猶大和耶路撒冷。</span>
<span className="v" id="v19" data-v="19" data-xref="以賽亞書 42:23; 路加福音 20:9–15; 馬太福音 13:9"> 但上帝仍遣先知到他們那裏，引導他們歸向耶和華。這先知警戒他們，他們卻不肯聽。</span>
<span className="v" id="v20" data-v="20" data-xref="民數記 14:41; 耶利米書 5:25; 歷代志下 15:1–2"> 那時，上帝的靈感動祭司耶何耶大的兒子撒迦利亞，他就站在上面對民說：「上帝如此說：你們為何干犯耶和華的誡命，以致不得亨通呢？因為你們離棄耶和華，所以他也離棄你們。」</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行傳 7:58–59; 尼希米記 9:26; 耶利米書 38:4–6"> 眾民同心謀害撒迦利亞，就照王的吩咐，在耶和華殿的院內用石頭打死他。</span>
<span className="v" id="v22" data-v="22" data-xref="創世記 9:5; 路加福音 11:51; 啟示錄 6:9–11"> 這樣，約阿施王不想念撒迦利亞的父親耶何耶大向自己所施的恩，殺了他的兒子。撒迦利亞臨死的時候說：「願耶和華鑒察伸冤！」</span>
</div>
</div>

## 約阿施被殺

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="列王紀下 12:17–18; 申命記 32:35; 列王紀上 20:22"> 滿了一年，亞蘭的軍兵上來攻擊約阿施，來到猶大和耶路撒冷，殺了民中的眾首領，將所掠的財貨送到大馬士革王那裏。</span>
<span className="v" id="v24" data-v="24" data-xref="歷代志下 22:8; 利未記 26:37; 利未記 26:8"> 亞蘭的軍兵雖來了一小隊，耶和華卻將大隊的軍兵交在他們手裏，是因猶大人離棄耶和華－他們列祖的上帝，所以藉亞蘭人懲罰約阿施。</span>
<span className="v" id="v25" data-v="25" data-xref="歷代志下 24:21–22; 歷代志下 28:27; 歷代志下 21:18–20"> 亞蘭人離開約阿施的時候，他患重病；臣僕背叛他，要報祭司耶何耶大兒子流血之仇，殺他在床上，葬他在大衛城，只是不葬在列王的墳墓裏。</span>
<span className="v" id="v26" data-v="26" data-xref="列王紀下 12:21"> 背叛他的是亞捫婦人示米押的兒子撒拔和摩押婦人示米利的兒子約薩拔。</span>
<span className="v" id="v27" data-v="27" data-xref="歷代志下 16:11; 歷代志下 13:22; 歷代志下 24:12"> 至於他的眾子和他所受的警戒，並他重修上帝殿的事，都寫在列王的傳上。他兒子亞瑪謝接續他作王。</span>

## 猶大王瑪拿西

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀下 21:1–18; 歷代志上 3:13; 以賽亞書 3:12"> 瑪拿西登基的時候年十二歲，在耶路撒冷作王五十五年。</span>
<span className="v" id="v2" data-v="2" data-xref="歷代志下 28:3; 申命記 18:9; 列王紀下 17:11"> 他行耶和華眼中看為惡的事，效法耶和華在以色列人面前趕出的外邦人那可憎的事，</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 16:21; 申命記 17:3; 歷代志下 31:1"> 重新建築他父希西家所拆毀的邱壇，又為巴力築壇，做木偶，且敬拜事奉天上的萬象，</span>
<span className="v" id="v4" data-v="4" data-xref="歷代志下 7:16; 列王紀上 8:29; 申命記 12:11"> 在耶和華的殿宇中築壇－耶和華曾指着這殿說：「我的名必永遠在耶路撒冷。」</span>
<span className="v" id="v5" data-v="5" data-xref="歷代志下 4:9; 耶利米書 32:34–35; 以西結書 8:7–18"> 他在耶和華殿的兩院中為天上的萬象築壇，</span>
<span className="v" id="v6" data-v="6" data-xref="利未記 18:21; 利未記 20:6; 歷代志下 28:3"> 並在欣嫩子谷使他的兒女經火，又觀兆，用法術，行邪術，立交鬼的和行巫術的，多行耶和華眼中看為惡的事，惹動他的怒氣，</span>
<span className="v" id="v7" data-v="7" data-xref="歷代志下 33:4; 歷代志下 7:16; 列王紀上 11:13"> 又在上帝殿內立雕刻的偶像。上帝曾對大衛和他兒子所羅門說：「我在以色列各支派中所選擇的耶路撒冷和這殿，必立我的名直到永遠。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳記下 7:10; 申命記 5:31–1; 利未記 8:36"> 以色列人若謹守遵行我藉摩西所吩咐他們的一切法度、律例、典章，我就不再使他們挪移離開我所賜給他們列祖之地。」</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀下 24:3–4; 箴言 29:12; 歷代志下 33:2"> 瑪拿西引誘猶大和耶路撒冷的居民，以致他們行惡比耶和華在以色列人面前所滅的列國更甚。</span>
</div>
</div>

## 瑪拿西悔改

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="歷代志下 36:15–16; 耶利米書 44:4–5; 撒迦利亞書 1:4"> 耶和華警戒瑪拿西和他的百姓，他們卻是不聽。</span>
<span className="v" id="v11" data-v="11" data-xref="申命記 28:36; 歷代志下 36:6; 尼希米記 9:32"> 所以耶和華使亞述王的將帥來攻擊他們，用鐃鉤鉤住瑪拿西，用銅鍊鎖住他，帶到巴比倫去。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及記 10:3; 詩篇 50:15; 歷代志下 32:26"> 他在急難的時候，就懇求耶和華－他的上帝，且在他列祖的上帝面前極其自卑。</span>
<span className="v" id="v13" data-v="13" data-xref="歷代志上 5:20; 但以理書 4:25; 馬太福音 7:7–8"> 他祈禱耶和華，耶和華就允准他的祈求，垂聽他的禱告，使他歸回耶路撒冷，仍坐國位。瑪拿西這才知道惟獨耶和華是上帝。</span>
<span className="v" id="v14" data-v="14" data-xref="歷代志下 27:3; 列王紀上 1:33; 尼希米記 3:3"> 此後，瑪拿西在大衛城外，從谷內基訓西邊直到魚門口，建築城牆，環繞俄斐勒，這牆築得甚高；又在猶大各堅固城內設立勇敢的軍長；</span>
<span className="v" id="v15" data-v="15" data-xref="歷代志下 33:3–7; 何西阿書 14:1–3; 列王紀下 21:7"> 並除掉外邦人的神像與耶和華殿中的偶像，又將他在耶和華殿的山上和耶路撒冷所築的各壇都拆毀拋在城外；</span>
<span className="v" id="v16" data-v="16" data-xref="歷代志下 14:4; 列王紀上 18:30; 歷代志下 33:9"> 重修耶和華的祭壇，在壇上獻平安祭、感謝祭，吩咐猶大人事奉耶和華－以色列的上帝。</span>
<span className="v" id="v17" data-v="17" data-xref="歷代志下 32:12; 列王紀上 22:43; 列王紀下 15:4"> 百姓卻仍在邱壇上獻祭，只獻給耶和華－他們的上帝。</span>
</div>
</div>

## 瑪拿西逝世

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="歷代志下 33:19; 歷代志下 33:12–13; 阿摩司書 7:12"> 瑪拿西其餘的事和禱告他上帝的話，並先見奉耶和華－以色列上帝的名警戒他的言語，都寫在以色列諸王記上。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行傳 9:11; 約翰一書 1:9; 但以理書 5:22"> 他的禱告，與上帝怎樣應允他，他未自卑以前的罪愆過犯，並在何處建築邱壇，設立亞舍拉和雕刻的偶像，都寫在何賽的書上。</span>
<span className="v" id="v20" data-v="20" data-xref="馬太福音 1:10; 歷代志下 32:33; 列王紀下 21:18–25"> 瑪拿西與他列祖同睡，葬在自己的宮院裏。他兒子亞們接續他作王。</span>
</div>
</div>

## 猶大王亞們

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="雅各書 4:13–15; 路加福音 12:19–20; 歷代志下 33:1"> 亞們登基的時候年二十二歲，在耶路撒冷作王二年。</span>
<span className="v" id="v22" data-v="22" data-xref="列王紀下 21:20; 以西結書 20:18; 列王紀下 21:1–11"> 他行耶和華眼中看為惡的事，效法他父瑪拿西所行的，祭祀事奉他父瑪拿西所雕刻的偶像，</span>
<span className="v" id="v23" data-v="23" data-xref="歷代志下 33:12; 歷代志下 33:19; 耶利米書 7:26"> 不在耶和華面前像他父瑪拿西自卑。這亞們所犯的罪越犯越大。</span>
<span className="v" id="v24" data-v="24" data-xref="羅馬書 11:22; 歷代志下 25:27–28; 歷代志下 24:25–26"> 他的臣僕背叛，在宮裏殺了他。</span>
<span className="v" id="v25" data-v="25" data-xref="民數記 35:31; 歷代志下 34:1; 歷代志下 36:1"> 但國民殺了那些背叛亞們王的人，立他兒子約西亞接續他作王。</span>
</div>
</div>

## 猶大王希西家

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀下 18:1–3; 歷代志上 3:13; 歷代志下 26:5"> 希西家登基的時候年二十五歲，在耶路撒冷作王二十九年。他母親名叫亞比雅，是撒迦利雅的女兒。</span>
<span className="v" id="v2" data-v="2" data-xref="歷代志下 34:2; 歷代志下 28:1"> 希西家行耶和華眼中看為正的事，效法他祖大衛一切所行的。</span>
</div>
</div>

## 潔淨聖殿

<div className="bt">
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="歷代志下 28:24; 歷代志下 29:7; 馬太福音 6:33"> 元年正月，開了耶和華殿的門，重新修理。</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米書 19:2; 尼希米記 3:29; 歷代志下 32:6"> 他召眾祭司和利未人來，聚集在東邊的寬闊處，</span>
<span className="v" id="v5" data-v="5" data-xref="歷代志下 35:6; 哥林多前書 3:16–17; 歷代志下 34:3–8"> 對他們說：「利未人哪，當聽我說：現在你們要潔淨自己，又潔淨耶和華－你們列祖上帝的殿，從聖所中除去污穢之物。</span>
<span className="v" id="v6" data-v="6" data-xref="以西結書 8:16; 耶利米書 2:27; 但以理書 9:16"> 我們列祖犯了罪，行耶和華－我們上帝眼中看為惡的事，離棄他，轉臉背向他的居所，</span>
<span className="v" id="v7" data-v="7" data-xref="歷代志下 28:24; 利未記 24:2–8; 歷代志下 29:3"> 封鎖廊門，吹滅燈火，不在聖所中向以色列上帝燒香，或獻燔祭。</span>
<span className="v" id="v8" data-v="8" data-xref="耶利米書 25:9; 耶利米書 25:18; 耶利米書 29:18"> 因此，耶和華的忿怒臨到猶大和耶路撒冷，將其中的人拋來拋去，令人驚駭、嗤笑，正如你們親眼所見的。</span>
<span className="v" id="v9" data-v="9" data-xref="歷代志下 28:17; 歷代志下 28:5–8; 耶利米哀歌 5:7"> 所以我們的祖宗倒在刀下，我們的妻子兒女也被擄掠。</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米書 50:5; 歷代志下 23:16; 以斯拉記 10:3"> 現在我心中有意與耶和華－以色列的上帝立約，好使他的烈怒轉離我們。</span>
<span className="v" id="v11" data-v="11" data-xref="申命記 10:8; 加拉太書 6:7–8; 民數記 8:6–14"> 我的眾子啊，現在不要懈怠；因為耶和華揀選你們站在他面前事奉他，與他燒香。」</span>
<span className="v" id="v12" data-v="12" data-xref="民數記 3:19–20; 歷代志上 15:5–7; 民數記 4:2–20"> 於是，利未人哥轄的子孫、亞瑪賽的兒子瑪哈，亞撒利雅的兒子約珥；米拉利的子孫、亞伯底的兒子基士，耶哈利勒的兒子亞撒利雅；革順的子孫、薪瑪的兒子約亞，約亞的兒子伊甸；</span>
<span className="v" id="v13" data-v="13" data-xref="歷代志上 6:39; 歷代志上 15:8; 歷代志上 15:17"> 以利撒反的子孫申利和耶利；亞薩的子孫撒迦利雅和瑪探雅；</span>
<span className="v" id="v14" data-v="14" data-xref="歷代志上 6:33; 歷代志上 25:1; 歷代志上 25:6"> 希幔的子孫耶歇和示每；耶杜頓的子孫示瑪雅和烏薛；</span>
<span className="v" id="v15" data-v="15" data-xref="歷代志下 30:12; 歷代志上 23:28; 歷代志下 29:5"> 起來聚集他們的弟兄，潔淨自己，照着王的吩咐、耶和華的命令，進去潔淨耶和華的殿。</span>
<span className="v" id="v16" data-v="16" data-xref="歷代志下 15:16; 馬太福音 21:12–13; 馬太福音 23:27"> 祭司進入耶和華的殿要潔淨殿，將殿中所有污穢之物搬到耶和華殿的院內，利未人接去，搬到外頭汲淪溪邊。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及記 12:2–8; 歷代志下 3:4; 列王紀上 6:3"> 從正月初一日潔淨起，初八日到了耶和華的殿廊，用八日的工夫潔淨耶和華的殿，到正月十六日才潔淨完了。</span>
</div>
</div>

## 重新奉獻聖殿

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="歷代志下 4:1; 歷代志下 4:7–8; 歷代志下 13:11"> 於是，他們晉見希西家王，說：「我們已將耶和華的全殿和燔祭壇，並壇的一切器皿、陳設餅的桌子，與桌子的一切器皿都潔淨了；</span>
<span className="v" id="v19" data-v="19" data-xref="歷代志下 28:24"> 並且亞哈斯王在位犯罪的時候所廢棄的器皿，我們預備齊全，且潔淨了，現今都在耶和華的壇前。」</span>
<span className="v" id="v20" data-v="20" data-xref="約書亞記 6:12; 耶利米書 25:4; 出埃及記 24:4"> 希西家王清早起來，聚集城裏的首領都上耶和華的殿；</span>
<span className="v" id="v21" data-v="21" data-xref="利未記 4:3–14; 約伯記 42:8; 以西結書 45:23"> 牽了七隻公牛，七隻公羊，七隻羊羔，七隻公山羊，要為國、為殿、為猶大人作贖罪祭。王吩咐亞倫的子孫眾祭司，獻在耶和華的壇上，</span>
<span className="v" id="v22" data-v="22" data-xref="利未記 4:18; 利未記 8:19; 利未記 8:24"> 就宰了公牛，祭司接血灑在壇上，宰了公羊，把血灑在壇上，又宰了羊羔，也把血灑在壇上；</span>
<span className="v" id="v23" data-v="23" data-xref="利未記 4:15; 利未記 4:24; 利未記 1:4"> 把那作贖罪祭的公山羊牽到王和會眾面前，他們就按手在其上。</span>
<span className="v" id="v24" data-v="24" data-xref="利未記 14:20; 以西結書 45:15; 哥林多後書 5:18–21"> 祭司宰了羊，將血獻在壇上作贖罪祭，為以色列眾人贖罪，因為王吩咐將燔祭和贖罪祭為以色列眾人獻上。</span>
<span className="v" id="v25" data-v="25" data-xref="歷代志下 8:14; 歷代志上 23:5; 撒母耳記下 24:11"> 王又派利未人在耶和華殿中敲鈸，鼓瑟，彈琴，乃照大衛和他先見迦得，並先知拿單所吩咐的，就是耶和華藉先知所吩咐的。</span>
<span className="v" id="v26" data-v="26" data-xref="歷代志上 23:5; 歷代志上 15:24; 阿摩司書 6:5"> 利未人拿大衛的樂器，祭司拿號，一同站立。</span>
<span className="v" id="v27" data-v="27" data-xref="歷代志下 23:18; 詩篇 137:3–4; 歷代志下 20:21"> 希西家吩咐在壇上獻燔祭，燔祭一獻，就唱讚美耶和華的歌，用號，並用以色列王大衛的樂器相和。</span>
<span className="v" id="v28" data-v="28" data-xref="啟示錄 5:8–14; 詩篇 89:15; 詩篇 68:24–26"> 會眾都敬拜，歌唱的歌唱，吹號的吹號，如此直到燔祭獻完了。</span>
<span className="v" id="v29" data-v="29" data-xref="歷代志下 20:18; 歷代志上 29:20; 腓立比書 2:10–11"> 獻完了祭，王和一切跟隨的人都俯伏敬拜。</span>
<span className="v" id="v30" data-v="30" data-xref="腓立比書 4:4; 詩篇 95:1–2; 歷代志上 16:7–36"> 希西家王與眾首領又吩咐利未人用大衛和先見亞薩的詩詞頌讚耶和華；他們就歡歡喜喜地頌讚耶和華，低頭敬拜。</span>
<span className="v" id="v31" data-v="31" data-xref="歷代志下 13:9; 出埃及記 35:22; 利未記 7:12"> 希西家說：「你們既然歸耶和華為聖，就要前來把祭物和感謝祭奉到耶和華殿裏。」會眾就把祭物和感謝祭奉來，凡甘心樂意的也將燔祭奉來。</span>
<span className="v" id="v32" data-v="32" data-xref="以斯拉記 6:17; 列王紀上 3:4; 歷代志上 29:21"> 會眾所奉的燔祭如下：公牛七十隻，公羊一百隻，羊羔二百隻，這都是作燔祭獻給耶和華的；</span>
<span className="v" id="v33" data-v="33"> 又有分別為聖之物，公牛六百隻，綿羊三千隻。</span>
<span className="v" id="v34" data-v="34" data-xref="歷代志下 35:11; 歷代志下 30:3; 詩篇 94:15"> 但祭司太少，不能剝盡燔祭牲的皮，所以他們的弟兄利未人幫助他們，直等燔祭的事完了，又等別的祭司自潔了；因為利未人誠心自潔，勝過祭司。</span>
<span className="v" id="v35" data-v="35" data-xref="民數記 15:5–10; 出埃及記 29:13; 歷代志上 16:37–42"> 燔祭和平安祭牲的脂油，並燔祭同獻的奠祭甚多。這樣，耶和華殿中的事務俱都齊備了<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或譯：就整頓了">a</a></sup>。</span>
<span className="v" id="v36" data-v="36" data-xref="使徒行傳 2:41; 帖撒羅尼迦前書 3:8–9; 歷代志上 29:9"> 這事辦的甚速，希西家和眾民都喜樂，是因上帝為眾民所預備的。</span>

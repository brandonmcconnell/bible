## 示巴女王訪問所羅門

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="馬太福音 12:42; 路加福音 11:31; 列王紀上 10:1–13"> 示巴女王聽見所羅門的名聲，就來到耶路撒冷，要用難解的話試問所羅門；跟隨她的人甚多，又有駱駝馱着香料、寶石，和許多金子。她來見了所羅門，就把心裏所有的對所羅門都說出來。</span>
<span className="v" id="v2" data-v="2" data-xref="約翰福音 15:15; 列王紀上 3:12; 馬可福音 4:34"> 所羅門將她所問的都答上了，沒有一句不明白、不能答的。</span>
<span className="v" id="v3" data-v="3" data-xref="歷代志下 3:1–4; 列王紀上 10:3; 列王紀上 6:1–7"> 示巴女王見所羅門的智慧和他所建造的宮室、</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 12:37; 列王紀上 4:22–23; 詩篇 143:7"> 席上的珍饈美味、群臣分列而坐、僕人兩旁侍立，以及他們的衣服裝飾、酒政，和酒政的衣服裝飾，又見他上耶和華殿的臺階，就詫異得神不守舍，</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀上 10:6"> 對王說：「我在本國裏所聽見論到你的事和你的智慧實在是真的！</span>
<span className="v" id="v6" data-v="6" data-xref="列王紀上 10:7; 歷代志下 9:5; 列王紀上 4:34"> 我先不信那些話，及至我來親眼見了，才知道你的大智慧；人所告訴我的，還不到一半；你的實跡越過我所聽見的名聲。</span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 27:4; 箴言 3:14; 箴言 10:21"> 你的群臣、你的僕人常侍立在你面前聽你智慧的話是有福的。</span>
<span className="v" id="v8" data-v="8" data-xref="歷代志下 2:11; 歷代志上 29:23; 以賽亞書 32:1–2"> 耶和華－你的上帝是應當稱頌的！他喜悅你，使你坐他的國位，為耶和華－你的上帝作王；因為你的上帝愛以色列人，要永遠堅立他們，所以立你作他們的王，使你秉公行義。」</span>
<span className="v" id="v9" data-v="9" data-xref="歷代志下 9:1; 詩篇 72:10; 詩篇 72:15"> 於是示巴女王將一百二十他連得金子和寶石，與極多的香料送給所羅門王；她送給王的香料，以後再沒有這樣的。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="歷代志下 8:18; 列王紀上 10:11; 列王紀上 10:22"> 希蘭的僕人和所羅門的僕人從俄斐運了金子來，也運了檀香木<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或譯：烏木；下同">a</a></sup>和寶石來。</span>
<span className="v" id="v11" data-v="11" data-xref="列王紀上 10:12; 歷代志上 23:5; 詩篇 92:1–3"> 王用檀香木為耶和華殿和王宮做臺，又為歌唱的人做琴瑟；猶大地從來沒有見過這樣的。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="列王紀上 10:13; 以弗所書 3:20; 詩篇 20:4"> 所羅門王按示巴女王所帶來的，還她禮物，另外照她一切所要所求的，都送給她。於是女王和她臣僕轉回本國去了。</span>
</div>
</div>

## 所羅門王的財富

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="詩篇 72:15; 詩篇 68:29; 列王紀上 10:14–28"> 所羅門每年所得的金子共有六百六十六他連得，</span>
<span className="v" id="v14" data-v="14" data-xref="詩篇 68:29; 詩篇 72:10"> 另外還有商人所進的金子，並且阿拉伯諸王與屬國的省長都帶金銀給所羅門。</span>
<span className="v" id="v15" data-v="15" data-xref="列王紀上 10:16–17; 歷代志下 12:9–10"> 所羅門王用錘出來的金子打成擋牌二百面，每面用金子六百舍客勒；</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀上 7:2"> 又用錘出來的金子打成盾牌三百面，每面用金子三百舍客勒，都放在黎巴嫩林宮裏。</span>
<span className="v" id="v17" data-v="17" data-xref="列王紀上 10:18–20; 詩篇 45:8; 啟示錄 20:11"> 王用象牙製造一個大寶座，用精金包裹。</span>
<span className="v" id="v18" data-v="18" data-xref="民數記 24:9; 啟示錄 5:5; 民數記 23:24"> 寶座有六層臺階，又有金腳凳，與寶座相連。寶座兩旁有扶手，靠近扶手有兩個獅子站立。</span>
<span className="v" id="v19" data-v="19" data-xref="馬太福音 19:28; 啟示錄 21:12"> 六層臺階上有十二個獅子站立，每層有兩個：左邊一個，右邊一個；在列國中沒有這樣做的。</span>
<span className="v" id="v20" data-v="20" data-xref="列王紀上 10:21; 以斯帖記 1:7; 歷代志下 9:27"> 所羅門王一切的飲器都是金的，黎巴嫩林宮裏的一切器皿都是精金的。所羅門年間，銀子算不了甚麼。</span>
<span className="v" id="v21" data-v="21" data-xref="列王紀上 22:48; 約伯記 39:13; 列王紀上 10:22"> 因為王的船隻與希蘭的僕人一同往他施去；他施船隻三年一次裝載金、銀、象牙、猿猴、孔雀回來。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="歷代志下 1:12; 詩篇 89:27; 列王紀上 4:30–31"> 所羅門王的財寶與智慧勝過天下的列王。</span>
<span className="v" id="v23" data-v="23" data-xref="雅各書 1:5; 雅各書 3:17; 箴言 2:6"> 普天下的王都求見所羅門，要聽上帝賜給他智慧的話。</span>
<span className="v" id="v24" data-v="24" data-xref="列王紀上 10:25; 約伯記 42:11; 詩篇 72:10"> 他們各帶貢物，就是金器、銀器、衣服、軍械、香料、騾馬，每年有一定之例。</span>
<span className="v" id="v25" data-v="25" data-xref="列王紀上 4:26; 列王紀上 10:26; 歷代志下 1:14"> 所羅門有套車的馬四千棚，有馬兵一萬二千，安置在屯車的城邑和耶路撒冷，就是王那裏。</span>
<span className="v" id="v26" data-v="26" data-xref="列王紀上 4:21; 創世記 15:18; 列王紀上 4:24"> 所羅門統管諸王，從大河到非利士地，直到埃及的邊界。</span>
<span className="v" id="v27" data-v="27" data-xref="歷代志下 1:15–17; 以賽亞書 9:10; 列王紀上 10:27–29"> 王在耶路撒冷使銀子多如石頭，香柏木多如高原的桑樹。</span>
<span className="v" id="v28" data-v="28" data-xref="歷代志下 1:16; 列王紀上 10:28; 以賽亞書 31:1"> 有人從埃及和各國為所羅門趕馬群來。</span>
</div>
</div>

## 所羅門政績簡述

<div className="bt">
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="歷代志上 29:29; 列王紀上 11:41–43; 列王紀上 11:29"> 所羅門其餘的事，自始至終，不都寫在先知拿單的書上和示羅人亞希雅的預言書上，並先見易多論尼八兒子耶羅波安的默示書上嗎？</span>
<span className="v" id="v30" data-v="30" data-xref="列王紀上 11:42–43"> 所羅門在耶路撒冷作以色列眾人的王共四十年。</span>
<span className="v" id="v31" data-v="31" data-xref="列王紀上 2:10; 撒母耳記下 7:12; 列王紀上 1:21"> 所羅門與他列祖同睡，葬在他父大衛城裏。他兒子羅波安接續他作王。</span>
</div>

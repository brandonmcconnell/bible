## 猶大王約蘭

<div className="bt">
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="歷代志下 12:6; 歷代志下 23:2; 歷代志下 24:5"> 約蘭有幾個兄弟，就是約沙法的兒子亞撒利雅、耶歇、撒迦利雅、亞撒利雅、米迦勒、示法提雅。這都是猶大王約沙法的兒子。</span>
<span className="v" id="v3" data-v="3" data-xref="歷代志下 11:23; 申命記 21:15–17; 歷代志下 11:5"> 他們的父親將許多金銀、財寶，和猶大地的堅固城賜給他們；但將國賜給約蘭，因為他是長子。</span>
<span className="v" id="v4" data-v="4" data-xref="士師記 9:5; 歷代志下 21:17; 創世記 4:8"> 約蘭興起坐他父的位，奮勇自強，就用刀殺了他的眾兄弟和以色列的幾個首領。</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀下 8:17–22"> 約蘭登基的時候年三十二歲，在耶路撒冷作王八年。</span>
<span className="v" id="v6" data-v="6" data-xref="歷代志下 18:1; 列王紀上 12:28–30; 列王紀下 8:18"> 他行以色列諸王的道，與亞哈家一樣；因他娶了亞哈的女兒為妻，行耶和華眼中看為惡的事。</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀上 11:36; 詩篇 132:17–18; 撒母耳記下 7:12–17"> 耶和華卻因自己與大衛所立的約，不肯滅大衛的家，照他所應許的，永遠賜燈光與大衛和他的子孫。</span>
<span className="v" id="v8" data-v="8" data-xref="歷代志下 21:10; 歷代志下 20:22–23; 創世記 27:40"> 約蘭年間，以東人背叛猶大，脫離他的權下，自己立王。</span>
<span className="v" id="v9" data-v="9"> 約蘭就率領軍長和所有的戰車，夜間起來，攻擊圍困他的以東人和車兵長。</span>
<span className="v" id="v10" data-v="10" data-xref="歷代志下 15:2; 耶利米書 2:13; 歷代志下 13:10"> 這樣，以東人背叛猶大，脫離他的權下，直到今日。那時，立拿人也背叛了，因為約蘭離棄耶和華－他列祖的上帝。</span>
<span className="v" id="v11" data-v="11" data-xref="利未記 20:5; 列王紀上 11:7; 利未記 17:7"> 他又在猶大諸山建築邱壇，使耶路撒冷的居民行邪淫，誘惑猶大人。</span>
<span className="v" id="v12" data-v="12" data-xref="歷代志下 14:2–5; 歷代志下 17:3–4; 列王紀下 2:1"> 先知以利亞達信與約蘭說：「耶和華－你祖大衛的上帝如此說：『因為你不行你父約沙法和猶大王亞撒的道，</span>
<span className="v" id="v13" data-v="13" data-xref="歷代志下 21:4; 歷代志下 21:11; 列王紀上 16:30–33"> 乃行以色列諸王的道，使猶大人和耶路撒冷的居民行邪淫，像亞哈家一樣，又殺了你父家比你好的諸兄弟。</span>
<span className="v" id="v14" data-v="14" data-xref="利未記 26:21; 出埃及記 20:5; 何西阿書 5:11"> 故此，耶和華降大災與你的百姓和你的妻子、兒女，並你一切所有的。</span>
<span className="v" id="v15" data-v="15" data-xref="歷代志下 21:18–19; 使徒行傳 1:18; 申命記 28:67"> 你的腸子必患病，日加沉重，以致你的腸子墜落下來。』」</span>
<span className="v" id="v16" data-v="16" data-xref="歷代志下 17:11; 歷代志下 33:11; 列王紀上 11:14"> 以後，耶和華激動非利士人和靠近古實的阿拉伯人來攻擊約蘭。</span>
<span className="v" id="v17" data-v="17" data-xref="歷代志下 22:1; 歷代志下 22:6; 歷代志下 25:23"> 他們上來攻擊猶大，侵入境內，擄掠了王宮裏所有的財貨和他的妻子、兒女，除了他小兒子約哈斯<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="又名亞哈謝">a</a></sup>之外，沒有留下一個兒子。</span>
<span className="v" id="v18" data-v="18" data-xref="歷代志下 21:15; 使徒行傳 12:23; 列王紀下 9:29"> 這些事以後，耶和華使約蘭的腸子患不能醫治的病。</span>
<span className="v" id="v19" data-v="19" data-xref="歷代志下 16:14; 耶利米書 34:5"> 他患此病纏綿日久，過了二年，腸子墜落下來，病重而死。他的民沒有為他燒甚麼物件，像從前為他列祖所燒的一樣。</span>
<span className="v" id="v20" data-v="20" data-xref="耶利米書 22:18; 歷代志下 28:27; 耶利米書 22:28"> 約蘭登基的時候年三十二歲，在耶路撒冷作王八年。他去世無人思慕，眾人葬他在大衛城，只是不在列王的墳墓裏。</span>

## 亞述人恐嚇耶路撒冷

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀下 18:13–37; 列王紀下 17:6; 歷代志下 20:1–2"> 這虔誠的事以後，亞述王西拿基立來侵入猶大，圍困一切堅固城，想要攻破佔據。</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 9:53; 路加福音 9:51; 列王紀下 12:17"> 希西家見西拿基立來，定意要攻打耶路撒冷，</span>
<span className="v" id="v3" data-v="3" data-xref="箴言 24:6; 箴言 20:18; 箴言 15:22"> 就與首領和勇士商議，塞住城外的泉源；他們就都幫助他。</span>
<span className="v" id="v4" data-v="4" data-xref="歷代志下 32:30; 列王紀下 18:9; 列王紀上 19:21"> 於是有許多人聚集，塞了一切泉源，並通流國中的小河，說：「亞述王來，為何讓他得着許多水呢？」</span>
<span className="v" id="v5" data-v="5" data-xref="歷代志下 25:23; 列王紀上 9:24; 列王紀下 25:4"> 希西家力圖自強，就修築所有拆毀的城牆，高與城樓相齊；在城外又築一城，堅固大衛城的米羅，製造了許多軍器、盾牌；</span>
<span className="v" id="v6" data-v="6" data-xref="以賽亞書 40:2; 歷代志下 30:22; 尼希米記 8:16"> 設立軍長管理百姓，將他們招聚在城門的寬闊處，用話勉勵他們，說：</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀下 6:16; 羅馬書 8:31; 以弗所書 6:10"> 「你們當剛強壯膽，不要因亞述王和跟隨他的大軍恐懼、驚慌；因為與我們同在的，比與他們同在的更大。</span>
<span className="v" id="v8" data-v="8" data-xref="耶利米書 17:5; 歷代志下 20:17; 以賽亞書 41:10"> 與他們同在的是肉臂，與我們同在的是耶和華－我們的上帝，他必幫助我們，為我們爭戰。」百姓就靠猶大王希西家的話，安然無懼了。</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀下 18:17; 約書亞記 10:31; 以賽亞書 36:2"> 此後，亞述王西拿基立和他的全軍攻打拉吉，就差遣臣僕到耶路撒冷見猶大王希西家和一切在耶路撒冷的猶大人，說：</span>
<span className="v" id="v10" data-v="10" data-xref="列王紀下 18:19; 以賽亞書 36:4"> 「亞述王西拿基立如此說：『你們倚靠甚麼，還在耶路撒冷受困呢？</span>
<span className="v" id="v11" data-v="11" data-xref="馬太福音 27:43; 詩篇 11:1–3; 以賽亞書 36:18"> 希西家對你們說「耶和華－我們的上帝必救我們脫離亞述王的手」，這不是誘惑你們，使你們受飢渴而死嗎？</span>
<span className="v" id="v12" data-v="12" data-xref="歷代志下 31:1; 申命記 12:13–14; 申命記 12:26–27"> 這希西家豈不是廢去耶和華的邱壇和祭壇，吩咐猶大與耶路撒冷的人說「你們當在一個壇前敬拜，在其上燒香」嗎？</span>
<span className="v" id="v13" data-v="13" data-xref="列王紀下 18:33–35; 以賽亞書 44:8–10; 但以理書 4:30"> 我與我列祖向列邦所行的，你們豈不知道嗎？列邦的神何嘗能救自己的國脫離我手呢？</span>
<span className="v" id="v14" data-v="14" data-xref="以賽亞書 10:11–12; 出埃及記 15:9–11; 以賽亞書 42:8"> 我列祖所滅的國，那些神中誰能救自己的民脫離我手呢？難道你們的神能救你們脫離我手嗎？</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及記 5:2; 但以理書 3:15; 以賽亞書 36:18"> 所以你們不要叫希西家這樣欺哄誘惑你們，也不要信他；因為沒有一國一邦的神能救自己的民脫離我手和我列祖的手，何況你們的神更不能救你們脫離我的手。』」</span>
<span className="v" id="v16" data-v="16" data-xref="詩篇 73:9; 約翰福音 15:21; 約伯記 15:25–26"> 西拿基立的臣僕還有別的話毀謗耶和華上帝和他僕人希西家。</span>
<span className="v" id="v17" data-v="17" data-xref="以賽亞書 37:14; 列王紀下 19:12; 以賽亞書 37:28–29"> 西拿基立也寫信毀謗耶和華－以色列的上帝說：「列邦的神既不能救他的民脫離我手，希西家的神也不能救他的民脫離我手了。」</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳記上 17:10; 列王紀下 18:26–28; 撒母耳記上 17:26"> 亞述王的臣僕用猶大言語向耶路撒冷城上的民大聲呼叫，要驚嚇他們，擾亂他們，以便取城。</span>
<span className="v" id="v19" data-v="19" data-xref="列王紀下 19:18; 以賽亞書 2:8; 耶利米書 32:30"> 他們論耶路撒冷的上帝，如同論世上人手所造的神一樣。</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 91:14–15; 以賽亞書 37:14–20; 歷代志下 14:11"> 希西家王和亞摩斯的兒子先知以賽亞因此禱告，向天呼求。</span>
<span className="v" id="v21" data-v="21" data-xref="以賽亞書 37:36–38; 詩篇 76:5; 詩篇 18:50"> 耶和華就差遣一個使者進入亞述王營中，把所有大能的勇士和官長、將帥盡都滅了。亞述王滿面含羞地回到本國，進了他神的廟中，有他親生的兒子在那裏用刀殺了他。</span>
<span className="v" id="v22" data-v="22" data-xref="以賽亞書 31:4–5; 詩篇 18:48–50; 帖撒羅尼迦後書 3:5"> 這樣，耶和華救希西家和耶路撒冷的居民脫離亞述王西拿基立的手，也脫離一切仇敵的手，又賜他們四境平安。</span>
<span className="v" id="v23" data-v="23" data-xref="歷代志下 17:5; 馬太福音 2:11; 歷代志下 1:1"> 有許多人到耶路撒冷，將供物獻與耶和華，又將寶物送給猶大王希西家。此後，希西家在列邦人的眼中看為尊大。</span>
</div>
</div>

## 希西家的疾病和驕傲

<div className="bt">
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="以賽亞書 38:1–8; 列王紀下 20:1–11; 以賽亞書 38:21–22"> 那時希西家病得要死，就禱告耶和華，耶和華應允他，賜他一個兆頭。</span>
<span className="v" id="v25" data-v="25" data-xref="歷代志下 24:18; 歷代志下 26:16; 歷代志下 32:31"> 希西家卻沒有照他所蒙的恩報答耶和華；因他心裏驕傲，所以忿怒要臨到他和猶大並耶路撒冷。</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米書 26:18–19; 歷代志下 34:27–28; 歷代志下 33:12"> 但希西家和耶路撒冷的居民覺得心裏驕傲，就一同自卑，以致耶和華的忿怒在希西家的日子沒有臨到他們。</span>
</div>
</div>

## 希西家的財富和尊榮

<div className="bt">
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="歷代志上 27:25–31; 歷代志下 1:12; 箴言 10:22"> 希西家大有尊榮資財，建造府庫，收藏金銀、寶石、香料、盾牌，和各樣的寶器，</span>
<span className="v" id="v28" data-v="28" data-xref="撒母耳記下 7:8; 歷代志下 26:10; 列王紀上 4:26"> 又建造倉房，收藏五穀、新酒，和油，又為各類牲畜蓋棚立圈；</span>
<span className="v" id="v29" data-v="29" data-xref="歷代志上 29:12; 箴言 10:22; 撒母耳記上 2:7"> 並且建立城邑，還有許多的羊群牛群，因為上帝賜他極多的財產。</span>
<span className="v" id="v30" data-v="30" data-xref="列王紀上 1:33; 以賽亞書 22:9–11; 詩篇 1:1–3"> 這希西家也塞住基訓的上源，引水直下，流在大衛城的西邊。希西家所行的事盡都亨通。</span>
<span className="v" id="v31" data-v="31" data-xref="申命記 8:2; 箴言 17:3; 創世記 22:1"> 惟有一件事，就是巴比倫王差遣使者來見希西家，訪問國中所現的奇事；這件事上帝離開他，要試驗他，好知道他心內如何。</span>
</div>
</div>

## 希西家逝世

<div className="bt">
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="以賽亞書 36:1–22; 列王紀下 18:1–20; 歷代志下 31:20–21"> 希西家其餘的事和他的善行都寫在亞摩斯的兒子先知以賽亞的默示書上和猶大、以色列的諸王記上。</span>
<span className="v" id="v33" data-v="33" data-xref="箴言 10:7; 列王紀上 1:21; 歷代志下 16:14"> 希西家與他列祖同睡，葬在大衛子孫的高陵上。他死的時候，猶大人和耶路撒冷的居民都尊敬他。他兒子瑪拿西接續他作王。</span>
</div>

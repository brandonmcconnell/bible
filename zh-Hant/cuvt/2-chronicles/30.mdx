## 預備守逾越節

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多前書 5:7–8; 歷代志下 11:13; 何西阿書 5:4"> 希西家差遣人去見以色列和猶大眾人，又寫信給以法蓮和瑪拿西人，叫他們到耶路撒冷耶和華的殿，向耶和華－以色列的上帝守逾越節；</span>
<span className="v" id="v2" data-v="2" data-xref="民數記 9:10–11; 歷代志上 13:1–3; 歷代志下 30:13"> 因為王和眾首領，並耶路撒冷全會眾已經商議，要在二月內守逾越節。</span>
<span className="v" id="v3" data-v="3" data-xref="歷代志下 29:34; 出埃及記 12:6; 出埃及記 12:18"> 正月<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是那時">a</a></sup>間他們不能守；因為自潔的祭司尚不敷用，百姓也沒有聚集在耶路撒冷；</span>
<span className="v" id="v4" data-v="4" data-xref="歷代志上 13:4"> 王與全會眾都以這事為善。</span>
<span className="v" id="v5" data-v="5" data-xref="士師記 20:1; 利未記 23:2; 以斯帖記 8:8–10"> 於是定了命令，傳遍以色列，從別是巴直到但，使他們都來，在耶路撒冷向耶和華－以色列的上帝守逾越節；因為照所寫的例，守這節的不多了<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或譯：因為民許久沒有照所寫的例守節了">b</a></sup>。</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米書 51:31; 以斯帖記 8:14; 列王紀下 15:19"> 驛卒就把王和眾首領的信，遵着王命傳遍以色列和猶大。信內說：「以色列人哪，你們當轉向耶和華－亞伯拉罕、以撒、以色列的上帝，好叫他轉向你們這脫離亞述王手的餘民。</span>
<span className="v" id="v7" data-v="7" data-xref="歷代志下 29:8; 以西結書 20:13–18; 撒迦利亞書 1:3–4"> 你們不要效法你們列祖和你們的弟兄；他們干犯耶和華－他們列祖的上帝，以致耶和華丟棄他們，使他們敗亡<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="或譯：令人驚駭">c</a></sup>，正如你們所見的。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及記 32:9; 歷代志下 29:10; 申命記 10:16"> 現在不要像你們列祖硬着頸項，只要歸順耶和華，進入他的聖所，就是永遠成聖的居所；又要事奉耶和華－你們的上帝，好使他的烈怒轉離你們。</span>
<span className="v" id="v9" data-v="9" data-xref="以賽亞書 55:7; 彌迦書 7:18; 詩篇 86:5"> 你們若轉向耶和華，你們的弟兄和兒女必在擄掠他們的人面前蒙憐恤，得以歸回這地，因為耶和華－你們的上帝有恩典、施憐憫。你們若轉向他，他必不轉臉不顧你們。」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="歷代志下 36:16; 歷代志下 30:6; 尼希米記 2:19"> 驛卒就由這城跑到那城，傳遍了以法蓮、瑪拿西，直到西布倫。那裏的人卻戲笑他們，譏誚他們。</span>
<span className="v" id="v11" data-v="11" data-xref="歷代志下 30:18; 歷代志下 30:21; 歷代志下 30:25"> 然而亞設、瑪拿西、西布倫中也有人自卑，來到耶路撒冷。</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米書 32:39; 耶利米書 24:7; 腓立比書 2:13"> 上帝也感動猶大人，使他們一心遵行王與眾首領憑耶和華之言所發的命令。</span>
</div>
</div>

## 守逾越節

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="歷代志下 30:2; 詩篇 84:7"> 二月，有許多人在耶路撒冷聚集，成為大會，要守除酵節。</span>
<span className="v" id="v14" data-v="14" data-xref="歷代志下 28:24; 撒母耳記下 15:23; 歷代志下 15:16"> 他們起來，把耶路撒冷的祭壇和燒香的壇盡都除去，拋在汲淪溪中。</span>
<span className="v" id="v15" data-v="15" data-xref="歷代志下 29:34; 歷代志下 5:11; 出埃及記 19:22"> 二月十四日，宰了逾越節的羊羔。祭司與利未人覺得慚愧，就潔淨自己，把燔祭奉到耶和華殿中，</span>
<span className="v" id="v16" data-v="16" data-xref="申命記 33:1; 歷代志下 35:15; 列王紀下 11:14"> 遵着神人摩西的律法，照例站在自己的地方；祭司從利未人手裏接過血來，灑在壇上。</span>
<span className="v" id="v17" data-v="17" data-xref="歷代志下 29:34; 歷代志下 35:3–6; 出埃及記 12:6"> 會中有許多人尚未自潔，所以利未人為一切不潔之人宰逾越節的羊羔，使他們在耶和華面前成為聖潔。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前書 11:28; 雅各書 5:15–16; 但以理書 9:19"> 以法蓮、瑪拿西、以薩迦、西布倫有許多人尚未自潔，他們卻也吃逾越節的羊羔，不合所記錄的定例。希西家為他們禱告說：「凡專心尋求上帝，就是耶和華－他列祖之上帝的，雖不照着聖所潔淨之禮自潔，求至善的耶和華也饒恕他。」</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及記 15:26; 雅各書 5:15–16; 詩篇 103:3"> 耶和華垂聽希西家的禱告，就饒恕<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="原文是醫治">d</a></sup>百姓。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及記 12:15; 出埃及記 13:6; 申命記 12:12"> 在耶路撒冷的以色列人大大喜樂，守除酵節七日。利未人和祭司用響亮的樂器，日日頌讚耶和華。</span>
<span className="v" id="v22" data-v="22" data-xref="歷代志下 32:6; 尼希米記 9:3; 以賽亞書 40:1–2"> 希西家慰勞一切善於事奉耶和華的利未人。於是眾人吃節筵七日，又獻平安祭，且向耶和華－他們列祖的上帝認罪。</span>
</div>
</div>

## 再度守節

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="列王紀上 8:65; 歷代志下 7:9"> 全會眾商議，要再守節七日；於是歡歡喜喜地又守節七日。</span>
<span className="v" id="v24" data-v="24" data-xref="歷代志下 29:34; 歷代志下 35:7–8; 以弗所書 4:8"> 猶大王希西家賜給會眾公牛一千隻，羊七千隻為祭物；眾首領也賜給會眾公牛一千隻，羊一萬隻，並有許多的祭司潔淨自己。</span>
<span className="v" id="v25" data-v="25" data-xref="歷代志下 30:11; 歷代志下 30:18; 歷代志上 16:10–11"> 猶大全會眾、祭司、利未人，並那從以色列地來的會眾和寄居的人，以及猶大寄居的人，盡都喜樂。</span>
<span className="v" id="v26" data-v="26" data-xref="歷代志下 7:8–10"> 這樣，在耶路撒冷大有喜樂，自從以色列王大衛兒子所羅門的時候，在耶路撒冷沒有這樣的喜樂。</span>
<span className="v" id="v27" data-v="27" data-xref="申命記 26:15; 詩篇 68:5; 民數記 6:23–26"> 那時，祭司、利未人起來，為民祝福。他們的聲音蒙上帝垂聽，他們的禱告達到天上的聖所。</span>
</div>

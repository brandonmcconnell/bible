## 猶大王亞瑪謝

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀下 14:1–6"> 亞瑪謝登基的時候年二十五歲，在耶路撒冷作王二十九年。他母親名叫約耶但，是耶路撒冷人。</span>
<span className="v" id="v2" data-v="2" data-xref="歷代志下 25:14; 雅各書 4:8; 使徒行傳 8:21"> 亞瑪謝行耶和華眼中看為正的事，只是心不專誠。</span>
<span className="v" id="v3" data-v="3" data-xref="歷代志下 24:25–26; 列王紀下 14:5–22; 創世記 9:5–6"> 國一堅定，就把殺他父王的臣僕殺了，</span>
<span className="v" id="v4" data-v="4" data-xref="申命記 24:16; 以西結書 18:20; 列王紀下 14:5–6"> 卻沒有治死他們的兒子，是照摩西律法書上耶和華所吩咐的說：「不可因子殺父，也不可因父殺子，各人要為本身的罪而死。」</span>
</div>
</div>

## 與以東交戰

<div className="bt">
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="民數記 1:3; 歷代志下 17:14–18; 歷代志下 11:1"> 亞瑪謝招聚猶大人，按着猶大和便雅憫的宗族設立千夫長、百夫長，又數點人數，從二十歲以外，能拿槍拿盾牌出去打仗的精兵共有三十萬；</span>
<span className="v" id="v6" data-v="6"> 又用銀子一百他連得，從以色列招募了十萬大能的勇士。</span>
<span className="v" id="v7" data-v="7" data-xref="歷代志下 19:2; 列王紀上 12:28; 何西阿書 9:13"> 有一個神人來見亞瑪謝，對他說：「王啊，不要使以色列的軍兵與你同去，因為耶和華不與以色列人以法蓮的後裔同在。</span>
<span className="v" id="v8" data-v="8" data-xref="歷代志下 14:11; 歷代志下 20:6; 腓立比書 4:19"> 你若一定要去，就奮勇爭戰吧！但上帝必使你敗在敵人面前；因為上帝能助人得勝，也能使人傾敗。」</span>
<span className="v" id="v9" data-v="9" data-xref="箴言 10:22; 申命記 8:18"> 亞瑪謝問神人說：「我給了以色列軍的那一百他連得銀子怎麼樣呢？」神人回答說：「耶和華能把更多的賜給你。」</span>
<span className="v" id="v10" data-v="10" data-xref="列王紀上 12:24; 撒母耳記下 19:43; 箴言 29:22"> 於是亞瑪謝將那從以法蓮來的軍兵分別出來，叫他們回家去。故此，他們甚惱怒猶大人，氣忿忿地回家去了。</span>
<span className="v" id="v11" data-v="11" data-xref="列王紀下 14:7; 詩篇 60:1; 撒母耳記下 8:13"> 亞瑪謝壯起膽來，率領他的民到鹽谷，殺了西珥人一萬。</span>
<span className="v" id="v12" data-v="12" data-xref="歷代志下 20:10; 歷代志上 20:3; 撒母耳記下 12:31"> 猶大人又生擒了一萬帶到山崖上，從那裏把他們扔下去，以致他們都摔碎了。</span>
<span className="v" id="v13" data-v="13" data-xref="歷代志下 8:5; 列王紀上 16:29; 列王紀上 9:17"> 但亞瑪謝所打發回去、不許一同出征的那些軍兵攻打猶大各城，從撒馬利亞直到伯‧和崙，殺了三千人，搶了許多財物。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="歷代志下 28:23; 申命記 7:25; 申命記 7:5"> 亞瑪謝殺了以東人回來，就把西珥的神像帶回，立為自己的神，在它面前叩拜燒香。</span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 96:5; 歷代志下 25:11–12; 歷代志下 25:7"> 因此，耶和華的怒氣向亞瑪謝發作，就差一個先知去見他，說：「這些神不能救它的民脫離你的手，你為何尋求它呢？」</span>
<span className="v" id="v16" data-v="16" data-xref="歷代志下 18:20–21; 耶利米書 29:26; 歷代志下 18:25"> 先知與王說話的時候，王對他說：「誰立你作王的謀士呢？你住口吧！為何找打呢？」先知就止住了，又說：「你行這事，不聽從我的勸戒，我知道上帝定意要滅你。」</span>
</div>
</div>

## 與以色列爭戰

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="列王紀下 14:8–14; 歷代志下 25:13; 箴言 20:3"> 猶大王亞瑪謝與群臣商議，就差遣使者去見耶戶的孫子、約哈斯的兒子、以色列王約阿施，說：「你來，我們二人相見於戰場。」</span>
<span className="v" id="v18" data-v="18" data-xref="士師記 9:8–15; 列王紀上 4:33; 詩篇 80:13"> 以色列王約阿施差遣使者去見猶大王亞瑪謝，說：「黎巴嫩的蒺藜差遣使者去見黎巴嫩的香柏樹，說：『將你的女兒給我兒子為妻。』後來黎巴嫩有一個野獸經過，把蒺藜踐踏了。</span>
<span className="v" id="v19" data-v="19" data-xref="歷代志下 26:16; 歷代志下 32:25; 箴言 18:6"> 你說：『看哪，我打敗了以東人』，你就心高氣傲，以致矜誇。你在家裏安居就罷了，為何要惹禍使自己和猶大國一同敗亡呢？」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="歷代志下 22:7; 列王紀上 12:15; 彼得前書 2:8"> 亞瑪謝卻不肯聽從。這是出乎上帝，好將他們交在敵人手裏，因為他們尋求以東的神。</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳記上 6:19–20; 撒母耳記上 6:9; 約書亞記 21:16"> 於是以色列王約阿施上來，在猶大的伯‧示麥與猶大王亞瑪謝相見於戰場。</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳記上 4:10; 歷代志下 28:5–6; 列王紀上 22:36"> 猶大人敗在以色列人面前，各自逃回家裏去了。</span>
<span className="v" id="v23" data-v="23" data-xref="歷代志下 21:17; 尼希米記 8:16; 歷代志下 26:9"> 以色列王約阿施在伯‧示麥擒住約哈斯<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="就是亞哈謝">a</a></sup>的孫子、約阿施的兒子、猶大王亞瑪謝，將他帶到耶路撒冷，又拆毀耶路撒冷的城牆，從以法蓮門直到角門，共四百肘；</span>
<span className="v" id="v24" data-v="24" data-xref="歷代志上 26:15; 歷代志下 12:9; 列王紀下 14:14"> 又將俄別‧以東所看守上帝殿裏的一切金銀和器皿，與王宮裏的財寶都拿了去，並帶人去為質，就回撒馬利亞去了。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="列王紀下 14:17–22"> 以色列王約哈斯的兒子約阿施死後，猶大王約阿施的兒子亞瑪謝又活了十五年。</span>
<span className="v" id="v26" data-v="26" data-xref="歷代志下 20:34; 列王紀下 14:15"> 亞瑪謝其餘的事，自始至終不都寫在猶大和以色列諸王記上嗎？</span>
<span className="v" id="v27" data-v="27" data-xref="歷代志下 24:25; 約書亞記 10:31; 列王紀下 14:19"> 自從亞瑪謝離棄耶和華之後，在耶路撒冷有人背叛他，他就逃到拉吉；叛黨卻打發人到拉吉，將他殺了。</span>
<span className="v" id="v28" data-v="28" data-xref="列王紀下 14:20"> 人就用馬將他的屍首馱回，葬在猶大京城他列祖的墳地裏。</span>
</div>
</div>

## 希西家的改革

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀下 18:4; 歷代志下 32:12; 創世記 19:15"> 這事既都完畢，在那裏的以色列眾人就到猶大的城邑，打碎柱像，砍斷木偶，又在猶大、便雅憫、以法蓮、瑪拿西遍地將邱壇和祭壇拆毀淨盡。於是以色列眾人各回各城，各歸各地。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="歷代志上 24:1; 歷代志上 16:4–6; 歷代志下 29:24–26"> 希西家派定祭司利未人的班次，各按各職獻燔祭和平安祭，又在耶和華殿<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是營">a</a></sup>門內事奉，稱謝頌讚耶和華。</span>
<span className="v" id="v3" data-v="3" data-xref="以西結書 45:17; 歷代志下 35:7; 歌羅西書 2:16–17"> 王又從自己的產業中定出分來為燔祭，就是早晚的燔祭和安息日、月朔，並節期的燔祭，都是按耶和華律法上所載的；</span>
<span className="v" id="v4" data-v="4" data-xref="瑪拉基書 2:7; 民數記 18:8–21; 尼希米記 13:10–13"> 又吩咐住耶路撒冷的百姓將祭司、利未人所應得的分給他們，使他們專心遵守耶和華的律法。</span>
<span className="v" id="v5" data-v="5" data-xref="尼希米記 13:12; 歷代志下 24:10–11; 尼希米記 10:35–39"> 諭旨一出，以色列人就把初熟的五穀、新酒、油、蜜，和田地的出產多多送來，又把各物的十分之一送來的極多。</span>
<span className="v" id="v6" data-v="6" data-xref="利未記 27:30; 歷代志下 11:16–17; 申命記 14:28"> 住猶大各城的以色列人和猶大人也將牛羊的十分之一，並分別為聖歸耶和華－他們上帝之物，就是十分取一之物，盡都送來，積成堆壘；</span>
<span className="v" id="v7" data-v="7" data-xref="利未記 23:16–24"> 從三月積起，到七月才完。</span>
<span className="v" id="v8" data-v="8" data-xref="以弗所書 1:3; 創世記 14:19–20; 腓立比書 4:10"> 希西家和眾首領來，看見堆壘，就稱頌耶和華，又為耶和華的民以色列人祝福。</span>
<span className="v" id="v9" data-v="9"> 希西家向祭司、利未人查問這堆壘。</span>
<span className="v" id="v10" data-v="10" data-xref="瑪拉基書 3:10; 歷代志上 6:8; 哥林多後書 9:8–11"> 撒督家的大祭司亞撒利雅回答說：「自從民將供物送到耶和華殿以來，我們不但吃飽，且剩下的甚多；因為耶和華賜福給他的民，所剩下的才這樣豐盛。」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="尼希米記 10:38–39; 尼希米記 13:5; 尼希米記 13:12–13"> 希西家吩咐在耶和華殿裏預備倉房，他們就預備了。</span>
<span className="v" id="v12" data-v="12" data-xref="歷代志下 35:9; 列王紀下 12:15; 歷代志上 26:20–26"> 他們誠心將供物和十分取一之物，並分別為聖之物，都搬入倉內。利未人歌楠雅掌管這事，他兄弟示每為副管。</span>
<span className="v" id="v13" data-v="13" data-xref="歷代志上 24:5; 歷代志下 31:10–11; 歷代志上 9:11"> 耶歇、亞撒細雅、拿哈、亞撒黑、耶利末、約撒拔、以列、伊斯瑪基雅、瑪哈、比拿雅都是督理，在歌楠雅和他兄弟示每的手下，是希西家王和管理上帝殿的亞撒利雅所派的。</span>
<span className="v" id="v14" data-v="14" data-xref="利未記 23:38; 歷代志上 26:12; 利未記 27:28"> 守東門的利未人音拿的兒子可利，掌管樂意獻與上帝的禮物，發放獻與耶和華的供物和至聖的物。</span>
<span className="v" id="v15" data-v="15" data-xref="約書亞記 21:9–19; 歷代志上 9:22; 歷代志下 29:12"> 在他手下有伊甸、珉雅珉、耶書亞、示瑪雅、亞瑪利雅、示迦尼雅，在祭司的各城裏供緊要的職任，無論弟兄大小，都按着班次分給他們。</span>
<span className="v" id="v16" data-v="16" data-xref="以斯拉記 3:4; 利未記 21:22–23; 歷代志上 23:3"> 按家譜，三歲以外的男丁，凡每日進耶和華殿、按班次供職的，也分給他；</span>
<span className="v" id="v17" data-v="17" data-xref="歷代志上 23:24; 歷代志上 23:27; 民數記 3:15"> 又按宗族家譜分給祭司，按班次職任分給二十歲以外的利未人，</span>
<span className="v" id="v18" data-v="18" data-xref="羅馬書 15:16; 以賽亞書 5:16; 歷代志下 31:15"> 又按家譜計算，分給他們會中的妻子、兒女；因他們身供要職，自潔成聖。</span>
<span className="v" id="v19" data-v="19" data-xref="歷代志下 31:12–15; 利未記 25:34; 民數記 35:2–5"> 按名派定的人要把應得的分給亞倫子孫，住在各城郊野、祭司所有的男丁和一切載入家譜的利未人。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="列王紀下 20:3; 列王紀下 22:2; 使徒行傳 24:16"> 希西家在猶大遍地這樣辦理，行耶和華－他上帝眼中看為善為正為忠的事。</span>
<span className="v" id="v21" data-v="21" data-xref="馬太福音 6:33; 耶利米書 29:13; 約書亞記 1:7–8"> 凡他所行的，無論是辦上帝殿的事，是遵律法守誡命，是尋求他的上帝，都是盡心去行，無不亨通。</span>
</div>
</div>

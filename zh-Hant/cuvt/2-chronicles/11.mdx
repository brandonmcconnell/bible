## 示瑪雅的預言

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀上 12:21–24; 詩篇 33:10; 詩篇 33:16"> 羅波安來到耶路撒冷，招聚猶大家和便雅憫家，共十八萬人，都是挑選的戰士，要與以色列人爭戰，好將國奪回再歸自己。</span>
<span className="v" id="v2" data-v="2" data-xref="歷代志下 12:15; 歷代志下 12:5–7; 歷代志下 8:14"> 但耶和華的話臨到神人示瑪雅說：</span>
<span className="v" id="v3" data-v="3" data-xref="列王紀下 17:34; 創世記 49:28; 啟示錄 7:4–8"> 「你去告訴所羅門的兒子猶大王羅波安和住猶大、便雅憫的以色列眾人說，</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 50:20; 列王紀上 11:29–38; 歷代志下 10:15–16"> 耶和華如此說：『你們不可上去與你們的弟兄爭戰，各歸各家去吧！因為這事出於我。』」眾人就聽從耶和華的話歸回，不去與耶羅波安爭戰。</span>
</div>
</div>

## 羅波安修築諸城

<div className="bt">
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="歷代志下 8:2–6; 歷代志下 14:6–7; 以賽亞書 22:8–11"> 羅波安住在耶路撒冷，在猶大地修築城邑，</span>
<span className="v" id="v6" data-v="6" data-xref="尼希米記 3:5; 阿摩司書 1:1; 歷代志上 4:32"> 為保障修築伯利恆、以坦、提哥亞、</span>
<span className="v" id="v7" data-v="7" data-xref="約書亞記 15:35; 撒母耳記上 22:1; 約書亞記 15:58"> 伯‧夙、梭哥、亞杜蘭、</span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 54:1; 約書亞記 15:24; 撒母耳記上 23:19"> 迦特、瑪利沙、西弗、</span>
<span className="v" id="v9" data-v="9" data-xref="約書亞記 15:39; 約書亞記 15:35; 約書亞記 10:5"> 亞多萊音、拉吉、亞西加、</span>
<span className="v" id="v10" data-v="10" data-xref="民數記 13:22; 約書亞記 15:33; 約書亞記 14:14"> 瑣拉、亞雅崙、希伯崙。這都是猶大和便雅憫的堅固城。</span>
<span className="v" id="v11" data-v="11" data-xref="歷代志下 17:19; 以賽亞書 22:10–11; 歷代志下 11:23"> 羅波安又堅固各處的保障，在其中安置軍長，又預備下糧食、油、酒。</span>
<span className="v" id="v12" data-v="12" data-xref="撒母耳記下 13:22; 歷代志下 26:14–15; 歷代志下 32:5"> 他在各城裏預備盾牌和槍，且使城極其堅固。猶大和便雅憫都歸了他。</span>
</div>
</div>

## 祭司和利未人都歸猶大

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13"> 以色列全地的祭司和利未人都從四方來歸羅波安。</span>
<span className="v" id="v14" data-v="14" data-xref="歷代志下 13:9; 民數記 35:2–5; 列王紀上 12:28–33"> 利未人撇下他們的郊野和產業，來到猶大與耶路撒冷，是因耶羅波安和他的兒子拒絕他們，不許他們供祭司職分事奉耶和華。</span>
<span className="v" id="v15" data-v="15" data-xref="列王紀上 12:28; 列王紀上 12:31; 列王紀上 13:33"> 耶羅波安為邱壇、為鬼魔<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是公山羊">a</a></sup>、為自己所鑄造的牛犢設立祭司。</span>
<span className="v" id="v16" data-v="16" data-xref="歷代志下 15:9; 使徒行傳 11:23; 詩篇 84:5–7"> 以色列各支派中，凡立定心意尋求耶和華－以色列上帝的，都隨從利未人，來到耶路撒冷祭祀耶和華－他們列祖的上帝。</span>
<span className="v" id="v17" data-v="17" data-xref="歷代志下 12:1; 歷代志下 1:1–12; 歷代志下 7:17–19"> 這樣，就堅固猶大國，使所羅門的兒子羅波安強盛三年，因為他們三年遵行大衛和所羅門的道。</span>
</div>
</div>

## 羅波安的家室

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="撒母耳記上 16:6; 歷代志上 27:18; 撒母耳記上 17:13"> 羅波安娶大衛兒子耶利摩的女兒瑪哈拉為妻，又娶耶西兒子以利押的女兒亞比孩為妻。</span>
<span className="v" id="v19" data-v="19"> 從她生了幾個兒子，就是耶烏施、示瑪利雅、撒罕。</span>
<span className="v" id="v20" data-v="20" data-xref="歷代志下 13:2; 歷代志下 11:21; 歷代志下 12:16"> 後來又娶押沙龍的女兒瑪迦<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="十三章二節是烏列的女兒米該亞">b</a></sup>，從她生了亞比雅、亞太、細撒、示羅密。</span>
<span className="v" id="v21" data-v="21" data-xref="士師記 8:30; 申命記 17:17; 列王紀上 11:3"> 羅波安娶十八個妻，立六十個妾，生二十八個兒子，六十個女兒；他卻愛押沙龍的女兒瑪迦，比愛別的妻妾更甚。</span>
<span className="v" id="v22" data-v="22" data-xref="申命記 21:15–17; 歷代志上 29:1; 歷代志上 5:1–2"> 羅波安立瑪迦的兒子亞比雅作太子，在他弟兄中為首，因為想要立他接續作王。</span>
<span className="v" id="v23" data-v="23" data-xref="歷代志下 21:3; 創世記 25:6; 路加福音 16:8"> 羅波安辦事精明，使他眾子分散在猶大和便雅憫全地各堅固城裏，又賜他們許多糧食，為他們多尋妻子。</span>
</div>
</div>

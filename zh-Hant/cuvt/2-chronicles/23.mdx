## 推翻亞她利雅

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歷代志下 15:12; 列王紀下 11:4–20; 尼希米記 9:38"> 第七年，耶何耶大奮勇自強，將百夫長耶羅罕的兒子亞撒利雅，約哈難的兒子以實瑪利，俄備得的兒子亞撒利雅，亞大雅的兒子瑪西雅，細基利的兒子以利沙法召來，與他們立約。</span>
<span className="v" id="v2" data-v="2" data-xref="歷代志下 11:13–17; 歷代志下 21:2; 歷代志上 15:12"> 他們走遍猶大，從猶大各城裏招聚利未人和以色列的眾族長到耶路撒冷來。</span>
<span className="v" id="v3" data-v="3" data-xref="歷代志下 21:7; 撒母耳記下 7:12; 歷代志下 6:16"> 會眾在上帝殿裏與王立約。耶何耶大對他們說：「看哪，王的兒子必當作王，正如耶和華指着大衛子孫所應許的話」；</span>
<span className="v" id="v4" data-v="4" data-xref="歷代志上 23:3–6; 歷代志上 26:13–16; 路加福音 1:8–9"> 又說：「你們當這樣行：祭司和利未人凡安息日進班的，三分之一要把守各門，</span>
<span className="v" id="v5" data-v="5" data-xref="以西結書 46:2–3; 使徒行傳 3:2; 列王紀下 11:5–6"> 三分之一要在王宮，三分之一要在基址門；眾百姓要在耶和華殿的院內。</span>
<span className="v" id="v6" data-v="6" data-xref="歷代志上 23:28–32; 列王紀下 11:6–7"> 除了祭司和供職的利未人之外，不准別人進耶和華的殿；惟獨他們可以進去，因為他們聖潔。眾百姓要遵守耶和華所吩咐的。</span>
<span className="v" id="v7" data-v="7" data-xref="民數記 3:38; 民數記 3:10; 列王紀下 11:8–9"> 利未人要手中各拿兵器，四圍護衛王；凡擅入殿宇的，必當治死。王出入的時候，你們當跟隨他。」</span>
<span className="v" id="v8" data-v="8" data-xref="列王紀下 11:9; 歷代志上 24:1–26"> 利未人和猶大眾人都照着祭司耶何耶大一切所吩咐的去行，各帶所管安息日進班出班的人來，因為祭司耶何耶大不許他們下班。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳記上 21:9; 撒母耳記下 8:7"> 祭司耶何耶大便將上帝殿裏所藏大衛王的槍、盾牌、擋牌交給百夫長，</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及記 40:6; 歷代志下 6:12; 列王紀下 11:11"> 又分派眾民手中各拿兵器，在壇和殿那裏，從殿右直到殿左，站在王子的四圍；</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳記上 10:24; 出埃及記 25:16; 列王紀下 11:12"> 於是領王子出來，給他戴上冠冕，將律法書交給他，立他作王。耶何耶大和眾子膏他，眾人說：「願王萬歲！」</span>
<span className="v" id="v12" data-v="12" data-xref="列王紀下 11:13–16; 列王紀下 9:32–37"> 亞她利雅聽見民奔走讚美王的聲音，就到民那裏，進耶和華的殿，</span>
<span className="v" id="v13" data-v="13" data-xref="箴言 29:2; 歷代志下 34:31; 列王紀下 9:23"> 看見王站在殿門的柱旁，百夫長和吹號的人侍立在王左右，國民都歡樂吹號，又有歌唱的，用各樣的樂器領人歌唱讚美；亞她利雅就撕裂衣服，喊叫說：「反了！反了！」</span>
<span className="v" id="v14" data-v="14" data-xref="以西結書 9:7; 列王紀下 11:8; 列王紀下 11:15"> 祭司耶何耶大帶管轄軍兵的百夫長出來，吩咐他們說：「將她趕到班外，凡跟隨她的必用刀殺死！」因為祭司說：「不可在耶和華殿裏殺她。」</span>
<span className="v" id="v15" data-v="15" data-xref="尼希米記 3:28; 耶利米書 31:40; 歷代志下 22:10"> 眾兵就閃開，讓她去；她走到王宮的馬門，便在那裏把她殺了。</span>
</div>
</div>

## 耶何耶大的改革

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="歷代志下 29:10; 尼希米記 9:38; 列王紀下 11:17"> 耶何耶大與眾民和王立約，都要作耶和華的民。</span>
<span className="v" id="v17" data-v="17" data-xref="列王紀上 18:40; 列王紀下 10:25–28; 列王紀下 18:4"> 於是眾民都到巴力廟，拆毀了廟，打碎壇和像，又在壇前將巴力的祭司瑪坦殺了。</span>
<span className="v" id="v18" data-v="18" data-xref="歷代志下 5:5; 民數記 28:1–31; 歷代志下 29:25"> 耶何耶大派官看守耶和華的殿，是在祭司利未人手下。這祭司利未人是大衛分派在耶和華殿中、照摩西律法上所寫的，給耶和華獻燔祭，又按大衛所定的例，歡樂歌唱；</span>
<span className="v" id="v19" data-v="19" data-xref="歷代志上 26:1–32; 歷代志上 9:22–24"> 且設立守門的把守耶和華殿的各門，無論為何事，不潔淨的人都不准進去。</span>
<span className="v" id="v20" data-v="20" data-xref="列王紀下 11:19; 列王紀下 15:35; 列王紀下 11:9–10"> 又率領百夫長和貴冑，與民間的官長，並國中的眾民，請王從耶和華殿下來，由上門進入王宮，立王坐在國位上。</span>
<span className="v" id="v21" data-v="21" data-xref="列王紀下 11:20; 啟示錄 18:20; 啟示錄 19:1–4"> 國民都歡樂，合城都安靜。眾人已將亞她利雅用刀殺了。</span>

## 與以東交戰

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="詩篇 83:5–8; 以賽亞書 16:6; 歷代志下 32:1"> 此後，摩押人和亞捫人，又有米烏尼人，一同來攻擊約沙法。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 14:7; 撒母耳記上 23:29; 約書亞記 15:62"> 有人來報告約沙法說：「從海外亞蘭<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="又作以東">a</a></sup>那邊有大軍來攻擊你，如今他們在哈洗遜‧他瑪，就是隱‧基底。」</span>
<span className="v" id="v3" data-v="3" data-xref="但以理書 9:3; 歷代志下 19:3; 撒母耳記上 7:6"> 約沙法便懼怕，定意尋求耶和華，在猶大全地宣告禁食。</span>
<span className="v" id="v4" data-v="4" data-xref="詩篇 50:15; 詩篇 60:10–12; 詩篇 69:35"> 於是猶大人聚會，求耶和華幫助。猶大各城都有人出來尋求耶和華。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="列王紀下 19:15–19; 歷代志下 6:12–13; 歷代志下 34:31"> 約沙法就在猶大和耶路撒冷的會中，站在耶和華殿的新院前，</span>
<span className="v" id="v6" data-v="6" data-xref="申命記 4:39; 歷代志上 29:11–12; 但以理書 4:17"> 說：「耶和華－我們列祖的上帝啊，你不是天上的上帝嗎？你不是萬邦萬國的主宰嗎？在你手中有大能大力，無人能抵擋你。</span>
<span className="v" id="v7" data-v="7" data-xref="以賽亞書 41:8; 雅各書 2:23; 詩篇 44:2"> 我們的上帝啊，你不是曾在你民以色列人面前驅逐這地的居民，將這地賜給你朋友亞伯拉罕的後裔永遠為業嗎？</span>
<span className="v" id="v8" data-v="8" data-xref="歷代志下 6:10; 歷代志下 2:4"> 他們住在這地，又為你的名建造聖所，說：</span>
<span className="v" id="v9" data-v="9" data-xref="歷代志下 6:28–30; 歷代志下 6:20; 列王紀上 8:33"> 『倘有禍患臨到我們，或刀兵災殃，或瘟疫饑荒，我們在急難的時候，站在這殿前向你呼求，你必垂聽而拯救，因為你的名在這殿裏。』</span>
<span className="v" id="v10" data-v="10" data-xref="申命記 2:19; 申命記 2:4–5; 申命記 2:9"> 從前以色列人出埃及地的時候，你不容以色列人侵犯亞捫人、摩押人，和西珥山人，以色列人就離開他們，不滅絕他們。</span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 83:3–12; 士師記 11:23–24; 耶利米書 18:20"> 看哪，他們怎樣報復我們，要來驅逐我們出離你的地，就是你賜給我們為業之地。</span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 121:1–2; 詩篇 25:15; 詩篇 141:8"> 我們的上帝啊，你不懲罰他們嗎？因為我們無力抵擋這來攻擊我們的大軍，我們也不知道怎樣行，我們的眼目單仰望你。」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="以斯拉記 10:1; 使徒行傳 21:5; 申命記 29:10"> 猶大眾人和他們的嬰孩、妻子、兒女都站在耶和華面前。</span>
<span className="v" id="v14" data-v="14" data-xref="歷代志下 15:1; 歷代志下 24:20; 使徒行傳 10:31"> 那時，耶和華的靈在會中臨到利未人亞薩的後裔－瑪探雅的玄孫，耶利的曾孫，比拿雅的孫子，撒迦利雅的兒子雅哈悉。</span>
<span className="v" id="v15" data-v="15" data-xref="歷代志下 32:7–8; 申命記 31:6; 出埃及記 14:13–14"> 他說：「猶大眾人、耶路撒冷的居民，和約沙法王，你們請聽。耶和華對你們如此說：『不要因這大軍恐懼驚惶；因為勝敗不在乎你們，乃在乎上帝。</span>
<span className="v" id="v16" data-v="16"> 明日你們要下去迎敵，他們是從洗斯坡上來，你們必在耶魯伊勒曠野前的谷口遇見他們。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及記 14:13–14; 歷代志下 15:2; 以賽亞書 41:10"> 猶大和耶路撒冷人哪，這次你們不要爭戰，要擺陣站着，看耶和華為你們施行拯救。不要恐懼，也不要驚惶。明日當出去迎敵，因為耶和華與你們同在。』」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="出埃及記 4:31; 歷代志下 7:3; 創世記 24:26"> 約沙法就面伏於地，猶大眾人和耶路撒冷的居民也俯伏在耶和華面前，叩拜耶和華。</span>
<span className="v" id="v19" data-v="19" data-xref="歷代志上 15:16–22; 歷代志上 16:42; 歷代志上 16:5"> 哥轄族和可拉族的利未人都起來，用極大的聲音讚美耶和華以色列的上帝。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="羅馬書 8:31; 約翰福音 14:1; 約翰福音 11:40"> 次日清早，眾人起來往提哥亞的曠野去。出去的時候，約沙法站着說：「猶大人和耶路撒冷的居民哪，要聽我說：信耶和華－你們的上帝就必立穩；信他的先知就必亨通。」</span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 107:1; 詩篇 106:1; 歷代志下 5:13"> 約沙法既與民商議了，就設立歌唱的人，頌讚耶和華，使他們穿上聖潔的禮服，走在軍前讚美耶和華說：「當稱謝耶和華，因他的慈愛永遠長存！」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="撒母耳記上 14:20; 以賽亞書 19:2; 以西結書 38:21"> 眾人方唱歌讚美的時候，耶和華就派伏兵擊殺那來攻擊猶大人的亞捫人、摩押人，和西珥山人，他們就被打敗了。</span>
<span className="v" id="v23" data-v="23" data-xref="士師記 7:22; 撒母耳記上 14:20; 以西結書 35:2–3"> 因為亞捫人和摩押人起來，擊殺住西珥山的人，將他們滅盡；滅盡住西珥山的人之後，他們又彼此自相擊殺。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="以賽亞書 37:36; 詩篇 110:6; 歷代志上 5:22"> 猶大人來到曠野的望樓，向那大軍觀看，見屍橫遍地，沒有一個逃脫的。</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳記上 30:19–20; 列王紀下 7:9–16; 民數記 31:15"> 約沙法和他的百姓就來收取敵人的財物，在屍首中見了許多財物、珍寶，他們剝脫下來的多得不可攜帶；因為甚多，直收取了三日。</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及記 17:15; 創世記 32:20; 歷代志下 5:9"> 第四日眾人聚集在比拉迦谷<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="就是稱頌的意思">b</a></sup>，在那裏稱頌耶和華。因此那地方名叫比拉迦谷，直到今日。</span>
<span className="v" id="v27" data-v="27" data-xref="尼希米記 12:43; 希伯來書 6:20; 詩篇 30:1"> 猶大人和耶路撒冷人都歡歡喜喜地回耶路撒冷，約沙法率領他們；因為耶和華使他們戰勝仇敵，就歡喜快樂。</span>
<span className="v" id="v28" data-v="28" data-xref="啟示錄 14:2–3; 詩篇 57:8; 詩篇 92:3"> 他們彈琴、鼓瑟、吹號來到耶路撒冷，進了耶和華的殿。</span>
<span className="v" id="v29" data-v="29" data-xref="歷代志下 17:10; 列王紀下 7:6; 出埃及記 23:27"> 列邦諸國聽見耶和華戰敗以色列的仇敵，就甚懼怕。</span>
<span className="v" id="v30" data-v="30" data-xref="歷代志下 15:15; 歷代志下 14:6–7; 撒母耳記下 7:1"> 這樣，約沙法的國得享太平，因為上帝賜他四境平安。</span>
</div>
</div>

## 約沙法逝世

<div className="bt">
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="列王紀上 22:41–44"> 約沙法作猶大王，登基的時候年三十五歲，在耶路撒冷作王二十五年。他母親名叫阿蘇巴，乃示利希的女兒。</span>
<span className="v" id="v32" data-v="32" data-xref="歷代志下 14:2–5; 列王紀上 15:11; 歷代志下 14:11–13"> 約沙法效法他父亞撒所行的，不偏左右，行耶和華眼中看為正的事。</span>
<span className="v" id="v33" data-v="33" data-xref="歷代志下 17:6; 歷代志下 19:3; 歷代志下 12:14"> 只是邱壇還沒有廢去，百姓也沒有立定心意歸向他們列祖的上帝。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="列王紀上 16:1; 歷代志下 19:2; 列王紀上 16:7"> 約沙法其餘的事，自始至終都寫在哈拿尼的兒子耶戶的書上，也載入以色列諸王記上。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="列王紀上 22:48–49; 列王紀下 1:2–16"> 此後，猶大王約沙法與以色列王亞哈謝交好；亞哈謝行惡太甚。</span>
<span className="v" id="v36" data-v="36" data-xref="列王紀上 10:22; 歷代志下 9:21; 列王紀上 9:26"> 二王合夥造船要往他施去，遂在以旬‧迦別造船。</span>
<span className="v" id="v37" data-v="37" data-xref="箴言 13:20; 歷代志下 19:2; 歷代志下 9:21"> 那時瑪利沙人、多大瓦的兒子以利以謝向約沙法預言說：「因你與亞哈謝交好，耶和華必破壞你所造的。」後來那船果然破壞，不能往他施去了。</span>
</div>

## 所羅門的成就

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀上 9:10–28"> 所羅門建造耶和華殿和王宮，二十年才完畢了。</span>
<span className="v" id="v2" data-v="2" data-xref="列王紀上 9:11–18"> 以後所羅門重新修築希蘭送給他的那些城邑，使以色列人住在那裏。</span>
<span className="v" id="v3" data-v="3" data-xref="民數記 13:21; 歷代志上 18:3; 撒母耳記下 8:3"> 所羅門往哈馬瑣巴去，攻取了那地方。</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀上 9:17–19"> 所羅門建造曠野裏的達莫，又建造哈馬所有的積貨城，</span>
<span className="v" id="v5" data-v="5" data-xref="歷代志上 7:24; 約書亞記 16:5; 歷代志下 14:7"> 又建造上伯‧和崙、下伯‧和崙作為保障，都有牆，有門，有閂；</span>
<span className="v" id="v6" data-v="6" data-xref="列王紀上 7:2; 歷代志下 8:4; 歷代志下 1:14"> 又建造巴拉和所有的積貨城，並屯車輛馬兵的城，與耶路撒冷、黎巴嫩，以及自己治理的全國中所願意建造的。</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 15:18–21; 申命記 7:1; 列王紀上 9:20–22"> 至於國中所剩下不屬以色列人的赫人、亞摩利人、比利洗人、希未人、耶布斯人，</span>
<span className="v" id="v8" data-v="8" data-xref="約書亞記 16:10; 列王紀上 9:21; 列王紀上 4:6"> 就是以色列人未曾滅絕的，所羅門挑取他們的後裔作服苦的奴僕，直到今日。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳記上 8:11–12; 出埃及記 19:5–6; 加拉太書 4:31"> 惟有以色列人，所羅門不使他們當奴僕做工，乃是作他的戰士、軍長的統領、車兵長、馬兵長。</span>
<span className="v" id="v10" data-v="10" data-xref="列王紀上 9:23; 列王紀上 5:16; 歷代志下 2:18"> 所羅門王有二百五十督工的，監管工人。</span>
<span className="v" id="v11" data-v="11" data-xref="列王紀上 3:1; 列王紀上 7:8; 列王紀上 9:24"> 所羅門將法老的女兒帶出大衛城，上到為她建造的宮裏；因所羅門說：「耶和華約櫃所到之處都為聖地，所以我的妻不可住在以色列王大衛的宮裏。」</span>
<span className="v" id="v12" data-v="12" data-xref="歷代志下 4:1; 歷代志下 15:8; 約翰福音 10:23"> 所羅門在耶和華的壇上，就是在廊子前他所築的壇上，與耶和華獻燔祭；</span>
<span className="v" id="v13" data-v="13" data-xref="申命記 16:16; 出埃及記 29:38–42; 以西結書 46:3–15"> 又遵着摩西的吩咐在安息日、月朔，並一年三節，就是除酵節、七七節、住棚節，獻每日所當獻的祭。</span>
<span className="v" id="v14" data-v="14" data-xref="歷代志上 9:17; 以斯拉記 6:18; 尼希米記 12:36"> 所羅門照着他父大衛所定的例，派定祭司的班次，使他們各供己事，又使利未人各盡其職，讚美耶和華，在祭司面前做每日所當做的；又派守門的按着班次看守各門，因為神人大衛是這樣吩咐的。</span>
<span className="v" id="v15" data-v="15" data-xref="歷代志下 30:12; 歷代志上 9:29; 列王紀上 7:51"> 王所吩咐眾祭司和利未人的，無論是管府庫或辦別的事，他們都不違背。</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀上 5:18; 列王紀上 6:7"> 所羅門建造耶和華的殿，從立根基直到成功的日子，工料俱備。這樣，耶和華的殿全然完畢。</span>
<span className="v" id="v17" data-v="17" data-xref="列王紀下 14:22; 申命記 2:8; 民數記 33:35"> 那時，所羅門往以東地靠海的以旬‧迦別和以祿去。</span>
<span className="v" id="v18" data-v="18" data-xref="歷代志下 9:10; 歷代志下 9:13; 傳道書 2:8"> 希蘭差遣他的臣僕，將船隻和熟悉泛海的僕人送到所羅門那裏。他們同着所羅門的僕人到了俄斐，得了四百五十他連得金子，運到所羅門王那裏。</span>

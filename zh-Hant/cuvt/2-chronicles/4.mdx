## 聖殿的設備

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀上 8:64; 以西結書 43:13–17; 列王紀上 9:25"> 他又製造一座銅壇，長二十肘，寬二十肘，高十肘；</span>
<span className="v" id="v2" data-v="2" data-xref="提多書 3:5; 撒迦利亞書 13:1; 出埃及記 30:18–21"> 又鑄一個銅海，樣式是圓的，高五肘，徑十肘，圍三十肘；</span>
<span className="v" id="v3" data-v="3" data-xref="以西結書 1:10; 以西結書 10:14; 哥林多前書 9:9–10"> 海周圍有野瓜<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="野瓜：原文是牛">a</a></sup>的樣式，每肘十瓜，共有兩行，是鑄海的時候鑄上的；</span>
<span className="v" id="v4" data-v="4" data-xref="馬太福音 28:19–20; 啟示錄 21:14; 馬可福音 16:15"> 有十二隻銅牛馱海：三隻向北，三隻向西，三隻向南，三隻向東；海在牛上，牛尾向內；</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀上 7:26"> 海厚一掌，邊如杯邊，又如百合花，可容三千罷特；</span>
<span className="v" id="v6" data-v="6" data-xref="列王紀上 7:38; 出埃及記 30:18–21; 列王紀上 7:40"> 又製造十個盆：五個放在右邊，五個放在左邊，獻燔祭所用之物都洗在其內；但海是為祭司沐浴的。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="出埃及記 25:31–40; 列王紀上 7:49; 約翰福音 8:12"> 他又照所定的樣式造十個金燈臺，放在殿裏：五個在右邊，五個在左邊；</span>
<span className="v" id="v8" data-v="8" data-xref="列王紀上 7:48; 瑪拉基書 1:12; 出埃及記 25:23–30"> 又造十張桌子，放在殿裏：五張在右邊，五張在左邊；又造一百個金碗；</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀上 6:36; 列王紀下 21:5; 列王紀上 7:12"> 又建立祭司院和大院，並院門，用銅包裹門扇；</span>
<span className="v" id="v10" data-v="10" data-xref="列王紀上 7:39"> 將海安在殿門的右邊，就是南邊。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="列王紀上 7:40–51; 列王紀上 7:14"> 戶蘭又造了盆、鏟、碗。這樣，他為所羅門王做完了上帝殿的工。</span>
<span className="v" id="v12" data-v="12" data-xref="列王紀上 7:41; 歷代志下 3:15–17"> 所造的就是：兩根柱子和柱上兩個如球的頂，並兩個蓋柱頂的網子</span>
<span className="v" id="v13" data-v="13" data-xref="列王紀上 7:20; 列王紀上 7:42; 耶利米書 52:23"> 和四百石榴，安在兩個網子上（每網兩行蓋着兩個柱上如球的頂）。</span>
<span className="v" id="v14" data-v="14" data-xref="列王紀上 7:27–43"> 盆座和其上的盆，</span>
<span className="v" id="v15" data-v="15"> 海和海下的十二隻牛，</span>
<span className="v" id="v16" data-v="16" data-xref="歷代志下 2:13; 列王紀上 7:13–14; 歷代志下 4:11"> 盆、鏟子、肉鍤子，與耶和華殿裏的一切器皿，都是巧匠戶蘭用光亮的銅為所羅門王造成的，</span>
<span className="v" id="v17" data-v="17" data-xref="列王紀上 7:46"> 是在約旦平原疏割和撒利但中間藉膠泥鑄成的。</span>
<span className="v" id="v18" data-v="18" data-xref="列王紀上 7:47; 耶利米書 52:20; 歷代志上 22:14"> 所羅門製造的這一切甚多，銅的輕重無法可查。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="啟示錄 9:13; 但以理書 5:2–3; 出埃及記 25:23–30"> 所羅門又造上帝殿裏的金壇和陳設餅的桌子，</span>
<span className="v" id="v20" data-v="20" data-xref="歷代志下 4:7; 出埃及記 25:31–37; 列王紀上 6:5"> 並精金的燈臺和燈盞，可以照例點在內殿前。</span>
<span className="v" id="v21" data-v="21" data-xref="列王紀上 6:29; 出埃及記 37:20; 列王紀上 6:35"> 燈臺上的花和燈盞，並蠟剪都是金的，且是純金的；</span>
<span className="v" id="v22" data-v="22" data-xref="列王紀下 12:13; 列王紀下 25:14; 耶利米書 52:18"> 又用精金製造鑷子、盤子、調羹、火鼎。至於殿門和至聖所的門扇，並殿的門扇，都是金子妝飾的。</span>
</div>
</div>

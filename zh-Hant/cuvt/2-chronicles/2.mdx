## 籌備建造聖殿

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀上 5:5; 歷代志上 22:10; 列王紀上 7:1"> 所羅門定意要為耶和華的名建造殿宇，又為自己的國建造宮室。</span>
<span className="v" id="v2" data-v="2" data-xref="歷代志下 2:18; 列王紀上 5:15–16"> 所羅門就挑選七萬扛抬的，八萬在山上鑿石頭的，三千六百督工的。</span>
<span className="v" id="v3" data-v="3" data-xref="歷代志上 14:1; 撒母耳記下 5:11; 列王紀上 5:1–11"> 所羅門差人去見泰爾王希蘭，說：「你曾運香柏木與我父大衛建宮居住，求你也這樣待我。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及記 30:7; 出埃及記 25:30; 歷代志下 2:1"> 我要為耶和華－我上帝的名建造殿宇，分別為聖獻給他，在他面前焚燒美香，常擺陳設餅，每早晚、安息日、月朔，並耶和華－我們上帝所定的節期獻燔祭。這是以色列人永遠的定例。</span>
<span className="v" id="v5" data-v="5" data-xref="歷代志上 16:25; 出埃及記 15:11; 詩篇 135:5"> 我所要建造的殿宇甚大；因為我們的上帝至大，超乎諸神。</span>
<span className="v" id="v6" data-v="6" data-xref="以賽亞書 66:1; 歷代志下 6:18; 列王紀上 8:27"> 天和天上的天，尚且不足他居住的，誰能為他建造殿宇呢？我是誰？能為他建造殿宇嗎？不過在他面前燒香而已。</span>
<span className="v" id="v7" data-v="7" data-xref="歷代志下 2:13–14; 歷代志上 22:15–16; 出埃及記 31:3–5"> 現在求你差一個巧匠來，就是善用金、銀、銅、鐵，和紫色、朱紅色、藍色線，並精於雕刻之工的巧匠，與我父大衛在猶大和耶路撒冷所預備的巧匠一同做工；</span>
<span className="v" id="v8" data-v="8" data-xref="列王紀上 5:6; 列王紀上 10:11; 歷代志下 9:10–11"> 又求你從黎巴嫩運些香柏木、松木、檀香木到我這裏來，因我知道你的僕人善於砍伐黎巴嫩的樹木。我的僕人也必與你的僕人同工。</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀上 9:8; 歷代志下 2:5; 歷代志下 7:21"> 這樣，可以給我預備許多的木料，因我要建造的殿宇高大出奇。</span>
<span className="v" id="v10" data-v="10" data-xref="列王紀上 5:11; 以斯拉記 7:22; 羅馬書 13:7–8"> 你的僕人砍伐樹木，我必給他們打好了的小麥二萬歌珥，大麥二萬歌珥，酒二萬罷特，油二萬罷特。」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="列王紀上 10:9; 歷代志下 9:8; 詩篇 72:17"> 泰爾王希蘭寫信回答所羅門說：「耶和華因為愛他的子民，所以立你作他們的王」；</span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 33:6; 彼得前書 1:3; 啟示錄 4:11"> 又說：「創造天地的耶和華－以色列的上帝是應當稱頌的！他賜給大衛王一個有智慧的兒子，使他有謀略聰明，可以為耶和華建造殿宇，又為自己的國建造宮室。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="歷代志下 4:16"> 「現在我打發一個精巧有聰明的人去，他是我父親希蘭所用的，</span>
<span className="v" id="v14" data-v="14" data-xref="歷代志下 2:7; 出埃及記 31:3–4; 列王紀上 7:13–14"> 是但支派一個婦人的兒子。他父親是泰爾人，他善用金、銀、銅、鐵、石、木，和紫色、藍色、朱紅色線與細麻製造各物，並精於雕刻，又能想出各樣的巧工。請你派定這人，與你的巧匠和你父－我主大衛的巧匠一同做工。</span>
<span className="v" id="v15" data-v="15" data-xref="歷代志下 2:10; 列王紀上 5:11"> 我主所說的小麥、大麥、酒、油，願我主運來給眾僕人。</span>
<span className="v" id="v16" data-v="16" data-xref="約書亞記 19:46; 列王紀上 5:8–9; 以斯拉記 3:7"> 我們必照你所需用的，從黎巴嫩砍伐樹木，紮成筏子，浮海運到約帕；你可以從那裏運到耶路撒冷。」</span>
</div>
</div>

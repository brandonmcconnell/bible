## 請為我們禱告

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="帖撒羅尼迦前書 5:25; 歌羅西書 4:3; 哥林多前書 16:9"> 弟兄們，我還有話說：請你們為我們禱告，好叫主的道理快快行開，得着榮耀，正如在你們中間一樣，</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多後書 4:3–4; 羅馬書 15:31; 申命記 32:20"> 也叫我們脫離無理之惡人的手；因為人不都是有信心。</span>
<span className="v" id="v3" data-v="3" data-xref="提摩太後書 4:18; 帖撒羅尼迦前書 5:24; 哥林多前書 10:13"> 但主是信實的，要堅固你們，保護你們脫離那惡者<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或譯：脫離凶惡">a</a></sup>。</span>
<span className="v" id="v4" data-v="4" data-xref="腓立比書 1:6; 腓利門書 1:21; 帖撒羅尼迦前書 4:10"> 我們靠主深信，你們現在是遵行我們所吩咐的，後來也必要遵行。</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 119:36; 歷代志上 29:18; 申命記 30:6"> 願主引導你們的心，叫你們愛上帝，並學基督的忍耐！</span>
</div>
</div>

## 警戒懶惰的人

<div className="bt">
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="帖撒羅尼迦後書 3:10–11; 帖撒羅尼迦後書 3:7; 羅馬書 16:17"> 弟兄們，我們奉主耶穌基督的名吩咐你們，凡有弟兄不按規矩而行，不遵守從我們所受的教訓，就當遠離他。</span>
<span className="v" id="v7" data-v="7" data-xref="帖撒羅尼迦後書 3:6; 帖撒羅尼迦後書 3:9; 哥林多前書 4:16"> 你們自己原知道應當怎樣效法我們。因為我們在你們中間，未嘗不按規矩而行，</span>
<span className="v" id="v8" data-v="8" data-xref="馬太福音 6:11; 帖撒羅尼迦前書 2:9; 以弗所書 4:28"> 也未嘗白吃人的飯，倒是辛苦勞碌，晝夜做工，免得叫你們一人受累。</span>
<span className="v" id="v9" data-v="9" data-xref="帖撒羅尼迦後書 3:7; 帖撒羅尼迦前書 2:6; 哥林多前書 9:4–14"> 這並不是因我們沒有權柄，乃是要給你們作榜樣，叫你們效法我們。</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 3:19; 箴言 13:4; 箴言 20:4"> 我們在你們那裏的時候，曾吩咐你們說，若有人不肯做工，就不可吃飯。</span>
<span className="v" id="v11" data-v="11" data-xref="提摩太前書 5:13; 帖撒羅尼迦後書 3:6; 帖撒羅尼迦前書 4:11"> 因我們聽說，在你們中間有人不按規矩而行，甚麼工都不做，反倒專管閒事。</span>
<span className="v" id="v12" data-v="12" data-xref="以弗所書 4:28; 帖撒羅尼迦前書 4:11; 帖撒羅尼迦後書 3:8"> 我們靠主耶穌基督吩咐、勸戒這樣的人，要安靜做工，吃自己的飯。</span>
<span className="v" id="v13" data-v="13" data-xref="加拉太書 6:9–10; 希伯來書 12:3; 哥林多後書 4:1"> 弟兄們，你們行善不可喪志。</span>
<span className="v" id="v14" data-v="14" data-xref="提多書 3:10; 帖撒羅尼迦後書 3:6; 哥林多前書 5:11"> 若有人不聽從我們這信上的話，要記下他，不和他交往，叫他自覺羞愧。</span>
<span className="v" id="v15" data-v="15" data-xref="提多書 3:10; 帖撒羅尼迦前書 5:14; 哥林多前書 5:5"> 但不要以他為仇人，要勸他如弟兄。</span>
</div>
</div>

</div>
<div className="bp">

## 香壇

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="啟示錄 8:3; 出埃及記 37:25–28; 出埃及記 40:5"> 「你要用皂莢木做一座燒香的壇。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 27:2"> 這壇要四方的，長一肘，寬一肘，高二肘；壇的四角要與壇接連一塊。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 25:11; 出埃及記 25:24"> 要用精金把壇的上面與壇的四圍，並壇的四角，包裹；又要在壇的四圍鑲上金牙邊。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及記 25:27; 出埃及記 26:29; 出埃及記 27:7"> 要做兩個金環安在牙子邊以下，在壇的兩旁，兩根橫撐上，作為穿槓的用處，以便抬壇。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 25:13; 出埃及記 25:27"> 要用皂莢木做槓，用金包裹。</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及記 25:21–22; 出埃及記 30:36; 利未記 16:13"> 要把壇放在法櫃前的幔子外，對着法櫃上的施恩座，就是我要與你相會的地方。</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳記上 2:28; 歷代志上 23:13; 出埃及記 27:20–21"> 亞倫在壇上要燒馨香料做的香；每早晨他收拾燈的時候，要燒這香。</span>
<span className="v" id="v8" data-v="8" data-xref="希伯來書 9:24; 帖撒羅尼迦前書 5:17; 希伯來書 7:25"> 黃昏點燈的時候，他要在耶和華面前燒這香，作為世世代代常燒的香。</span>
<span className="v" id="v9" data-v="9" data-xref="利未記 10:1"> 在這壇上不可奉上異樣的香，不可獻燔祭、素祭，也不可澆上奠祭。</span>
<span className="v" id="v10" data-v="10" data-xref="利未記 16:18; 希伯來書 9:22–23; 利未記 16:29–30"> 亞倫一年一次要在壇的角上行贖罪之禮。他一年一次要用贖罪祭牲的血在壇上行贖罪之禮，作為世世代代的定例。這壇在耶和華面前為至聖。」</span>
</div>
</div>

## 會幕的捐獻

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11"> 耶和華曉諭摩西說：</span>
<span className="v" id="v12" data-v="12" data-xref="民數記 31:50; 歷代志上 27:24; 出埃及記 38:25–26"> 「你要按以色列人被數的，計算總數，你數的時候，他們各人要為自己的生命把贖價奉給耶和華，免得數的時候在他們中間有災殃。</span>
<span className="v" id="v13" data-v="13" data-xref="利未記 27:25; 民數記 3:47; 以西結書 45:12"> 凡過去歸那些被數之人的，每人要按聖所的平，拿銀子半舍客勒；這半舍客勒是奉給耶和華的禮物（一舍客勒是二十季拉）。</span>
<span className="v" id="v14" data-v="14" data-xref="民數記 1:20; 民數記 1:18; 民數記 1:3"> 凡過去歸那些被數的人，從二十歲以外的，要將這禮物奉給耶和華。</span>
<span className="v" id="v15" data-v="15" data-xref="民數記 31:50; 利未記 17:11; 出埃及記 30:12"> 他們為贖生命將禮物奉給耶和華，富足的不可多出，貧窮的也不可少出，各人要出半舍客勒。</span>
<span className="v" id="v16" data-v="16" data-xref="尼希米記 10:32–33; 民數記 16:40; 出埃及記 38:25–31"> 你要從以色列人收這贖罪銀，作為會幕的使用，可以在耶和華面前為以色列人作紀念，贖生命。」</span>
</div>
</div>

## 銅盆

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17"> 耶和華曉諭摩西說：</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及記 40:7; 出埃及記 38:8; 列王紀上 7:23"> 「你要用銅做洗濯盆和盆座，以便洗濯。要將盆放在會幕和壇的中間，在盆裏盛水。</span>
<span className="v" id="v19" data-v="19" data-xref="以賽亞書 52:11; 出埃及記 40:31–32; 詩篇 26:6"> 亞倫和他的兒子要在這盆裏洗手洗腳。</span>
<span className="v" id="v20" data-v="20" data-xref="利未記 10:1–3; 希伯來書 12:28–29; 歷代志上 13:10"> 他們進會幕，或是就近壇前供職給耶和華獻火祭的時候，必用水洗濯，免得死亡。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及記 28:43; 出埃及記 27:21"> 他們洗手洗腳就免得死亡。這要作亞倫和他後裔世世代代永遠的定例。」</span>
</div>
</div>

## 聖膏

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22"> 耶和華曉諭摩西說：</span>
<span className="v" id="v23" data-v="23" data-xref="以西結書 27:19; 雅歌 4:14; 以西結書 27:22"> 「你要取上品的香料，就是流質的沒藥五百舍客勒，香肉桂一半，就是二百五十舍客勒，菖蒲二百五十舍客勒，</span>
<span className="v" id="v24" data-v="24" data-xref="詩篇 45:8; 出埃及記 29:40; 民數記 3:47"> 桂皮五百舍客勒，都按着聖所的平，又取橄欖油一欣，</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及記 37:29; 歷代志上 9:30; 出埃及記 40:9"> 按做香之法調和做成聖膏油。</span>
<span className="v" id="v26" data-v="26" data-xref="民數記 7:1; 約翰一書 2:20; 以賽亞書 61:1"> 要用這膏油抹會幕和法櫃，</span>
<span className="v" id="v27" data-v="27"> 桌子與桌子的一切器具，燈臺和燈臺的器具，並香壇、</span>
<span className="v" id="v28" data-v="28"> 燔祭壇，和壇的一切器具，洗濯盆和盆座。</span>
<span className="v" id="v29" data-v="29" data-xref="馬太福音 23:19; 出埃及記 29:37; 利未記 6:18"> 要使這些物成為聖，好成為至聖；凡挨着的都成為聖。</span>
<span className="v" id="v30" data-v="30" data-xref="利未記 8:12; 出埃及記 28:3; 利未記 8:30"> 要膏亞倫和他的兒子，使他們成為聖，可以給我供祭司的職分。</span>
<span className="v" id="v31" data-v="31" data-xref="出埃及記 37:29; 利未記 21:10; 詩篇 89:20"> 你要對以色列人說：『這油，我要世世代代以為聖膏油。</span>
<span className="v" id="v32" data-v="32" data-xref="出埃及記 30:25; 出埃及記 30:37–38; 利未記 21:10"> 不可倒在別人的身上，也不可按這調和之法做與此相似的。這膏油是聖的，你們也要以為聖。</span>
<span className="v" id="v33" data-v="33" data-xref="出埃及記 30:38; 創世記 17:14; 出埃及記 12:15"> 凡調和與此相似的，或將這膏膏在別人身上的，這人要從民中剪除。』」</span>
</div>
</div>

## 香的做法

<div className="bt">
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="出埃及記 37:29; 出埃及記 25:6; 出埃及記 30:23"> 耶和華吩咐摩西說：「你要取馨香的香料，就是拿他弗、施喜列、喜利比拿；這馨香的香料和淨乳香各樣要一般大的分量。</span>
<span className="v" id="v35" data-v="35" data-xref="利未記 2:13; 出埃及記 30:25; 約翰福音 12:3"> 你要用這些加上鹽，按做香之法做成清淨聖潔的香。</span>
<span className="v" id="v36" data-v="36" data-xref="出埃及記 25:22; 出埃及記 30:6; 出埃及記 16:34"> 這香要取點搗得極細，放在會幕內、法櫃前，我要在那裏與你相會。你們要以這香為至聖。</span>
<span className="v" id="v37" data-v="37" data-xref="利未記 2:3; 出埃及記 29:37; 出埃及記 30:32–33"> 你們不可按這調和之法為自己做香；要以這香為聖，歸耶和華。</span>
<span className="v" id="v38" data-v="38" data-xref="出埃及記 30:33"> 凡做香和這香一樣，為要聞香味的，這人要從民中剪除。」</span>
</div>
</div>

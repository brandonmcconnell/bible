## 復造法版

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及記 32:19; 出埃及記 31:18; 詩篇 119:89"> 耶和華吩咐摩西說：「你要鑿出兩塊石版，和先前你摔碎的那版一樣；其上的字我要寫在這版上。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 19:20; 申命記 9:25; 出埃及記 19:11"> 明日早晨，你要預備好了，上西奈山，在山頂上站在我面前。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 19:12–13; 出埃及記 19:21; 提摩太前書 2:5"> 誰也不可和你一同上去，遍山都不可有人，在山根也不可叫羊群牛群吃草。」</span>
<span className="v" id="v4" data-v="4"> 摩西就鑿出兩塊石版，和先前的一樣。清晨起來，照耶和華所吩咐的上西奈山去，手裏拿着兩塊石版。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 33:19; 民數記 11:25; 路加福音 9:34–35"> 耶和華在雲中降臨，和摩西一同站在那裏，宣告耶和華的名。</span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 86:15; 約珥書 2:13; 詩篇 103:8–13"> 耶和華在他面前宣告說：「耶和華，耶和華，是有憐憫有恩典的上帝，不輕易發怒，並有豐盛的慈愛和誠實，</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及記 20:5–6; 詩篇 103:3; 申命記 5:9–10"> 為千萬人存留慈愛，赦免罪孽、過犯，和罪惡，萬不以有罪的為無罪，必追討他的罪，自父及子，直到三、四代。」</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及記 4:31; 歷代志下 20:18; 創世記 17:3"> 摩西急忙伏地下拜，</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 33:12; 申命記 32:9; 詩篇 94:14"> 說：「主啊，我若在你眼前蒙恩，求你在我們中間同行，因為這是硬着頸項的百姓。又求你赦免我們的罪孽和罪惡，以我們為你的產業。」</span>
</div>
</div>

## 重新立約

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="申命記 10:21; 詩篇 77:14; 以賽亞書 64:3"> 耶和華說：「我要立約，要在百姓面前行奇妙的事，是在遍地萬國中所未曾行的。在你四圍的外邦人就要看見耶和華的作為，因我向你所行的是可畏懼的事。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及記 33:2; 出埃及記 3:17; 出埃及記 3:8"> 「我今天所吩咐你的，你要謹守。我要從你面前攆出亞摩利人、迦南人、赫人、比利洗人、希未人、耶布斯人。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及記 23:32–33; 約書亞記 23:12–13; 申命記 7:2"> 你要謹慎，不可與你所去那地的居民立約，恐怕成為你們中間的網羅；</span>
<span className="v" id="v13" data-v="13" data-xref="列王紀下 18:4; 出埃及記 23:24; 申命記 7:25–26"> 卻要拆毀他們的祭壇，打碎他們的柱像，砍下他們的木偶。</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 4:24; 申命記 32:21; 哥林多前書 10:22"> 不可敬拜別神；因為耶和華是忌邪的上帝，名為忌邪者。</span>
<span className="v" id="v15" data-v="15" data-xref="士師記 2:17; 詩篇 106:28; 民數記 25:2"> 只怕你與那地的居民立約，百姓隨從他們的神，就行邪淫，祭祀他們的神，有人叫你，你便吃他的祭物，</span>
<span className="v" id="v16" data-v="16" data-xref="申命記 7:3–4; 列王紀上 11:2–4; 以斯拉記 9:2"> 又為你的兒子娶他們的女兒為妻，他們的女兒隨從她們的神，就行邪淫，使你的兒子也隨從她們的神行邪淫。</span>
<span className="v" id="v17" data-v="17" data-xref="利未記 19:4; 出埃及記 32:8; 以賽亞書 46:6–7"> 「不可為自己鑄造神像。</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及記 13:4; 利未記 23:6; 出埃及記 13:6–7"> 「你要守除酵節，照我所吩咐你的，在亞筆月內所定的日期吃無酵餅七天，因為你是這亞筆月內出了埃及。</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及記 13:2; 出埃及記 22:29; 出埃及記 13:12"> 凡頭生的都是我的；一切牲畜頭生的，無論是牛是羊，公的都是我的。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及記 13:13; 出埃及記 23:15; 申命記 16:16"> 頭生的驢要用羊羔代贖，若不代贖就要打折牠的頸項。凡頭生的兒子都要贖出來。誰也不可空手朝見我。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及記 23:12; 申命記 21:4; 路加福音 13:14"> 「你六日要做工，第七日要安息，雖在耕種收割的時候也要安息。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及記 23:16; 申命記 16:10–15; 約翰福音 7:2"> 在收割初熟麥子的時候要守七七節；又在年底要守收藏節。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及記 23:14; 申命記 16:16; 出埃及記 23:17"> 你們一切男丁要一年三次朝見主耶和華－以色列的上帝。</span>
<span className="v" id="v24" data-v="24" data-xref="詩篇 78:55; 出埃及記 33:2; 箴言 16:7"> 我要從你面前趕出外邦人，擴張你的境界。你一年三次上去朝見耶和華－你上帝的時候，必沒有人貪慕你的地土。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及記 23:18; 出埃及記 12:10; 哥林多前書 5:7–8"> 「你不可將我祭物的血和有酵的餅一同獻上。逾越節的祭物也不可留到早晨。</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及記 23:19; 申命記 14:21; 申命記 26:2"> 地裏首先初熟之物要送到耶和華－你上帝的殿。不可用山羊羔母的奶煮山羊羔。」</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及記 24:4; 申命記 31:9; 申命記 4:13"> 耶和華吩咐摩西說：「你要將這些話寫上，因為我是按這話與你和以色列人立約。」</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及記 34:1; 出埃及記 24:18; 申命記 9:18"> 摩西在耶和華那裏四十晝夜，也不吃飯也不喝水。耶和華將這約的話，就是十條誡，寫在兩塊版上。</span>
</div>
</div>

## 摩西下西奈山

<div className="bt">
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="馬太福音 17:2; 路加福音 9:29; 出埃及記 32:15"> 摩西手裏拿着兩塊法版下西奈山的時候，不知道自己的面皮因耶和華和他說話就發了光。</span>
<span className="v" id="v30" data-v="30" data-xref="馬可福音 9:3; 路加福音 5:8; 民數記 12:8"> 亞倫和以色列眾人看見摩西的面皮發光就怕挨近他。</span>
<span className="v" id="v31" data-v="31" data-xref="出埃及記 3:15; 出埃及記 24:1–3; 創世記 45:3"> 摩西叫他們來；於是亞倫和會眾的官長都到他那裏去，摩西就與他們說話。</span>
<span className="v" id="v32" data-v="32" data-xref="列王紀上 22:14; 出埃及記 24:3; 馬太福音 28:20"> 隨後以色列眾人都近前來，他就把耶和華在西奈山與他所說的一切話都吩咐他們。</span>
<span className="v" id="v33" data-v="33" data-xref="哥林多後書 4:4–6; 哥林多後書 3:13–18; 羅馬書 10:4"> 摩西與他們說完了話就用帕子蒙上臉。</span>
<span className="v" id="v34" data-v="34" data-xref="哥林多後書 3:16; 希伯來書 10:19–22; 希伯來書 4:16"> 但摩西進到耶和華面前與他說話就揭去帕子，及至出來的時候便將耶和華所吩咐的告訴以色列人。</span>
<span className="v" id="v35" data-v="35" data-xref="出埃及記 34:29–30; 約翰福音 5:35; 但以理書 12:3"> 以色列人看見摩西的面皮發光。摩西又用帕子蒙上臉，等到他進去與耶和華說話就揭去帕子。</span>
</div>

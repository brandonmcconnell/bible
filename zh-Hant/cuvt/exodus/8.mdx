## －蛙災

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及記 3:18; 出埃及記 3:12; 出埃及記 5:1"> 耶和華吩咐摩西說：「你進去見法老，對他說：『耶和華這樣說：容我的百姓去，好事奉我。</span>
<span className="v" id="v2" data-v="2" data-xref="詩篇 78:45; 出埃及記 9:2; 出埃及記 7:14"> 你若不肯容他們去，我必使青蛙糟蹋你的四境。</span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 105:30; 出埃及記 12:34"> 河裏要滋生青蛙；這青蛙要上來進你的宮殿和你的臥房，上你的床榻，進你臣僕的房屋，上你百姓的身上，進你的爐訿和你的摶麵盆，</span>
<span className="v" id="v4" data-v="4" data-xref="以賽亞書 19:11; 但以理書 4:37; 使徒行傳 12:22–23"> 又要上你和你百姓並你眾臣僕的身上。』」</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 7:19"> 耶和華曉諭摩西說：「你對亞倫說：『把你的杖伸在江、河、池以上，使青蛙到埃及地上來。』」</span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 105:30; 詩篇 78:45; 啟示錄 16:13"> 亞倫便伸杖在埃及的諸水以上，青蛙就上來，遮滿了埃及地。</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及記 7:11; 出埃及記 7:22; 申命記 13:1–3"> 行法術的也用他們的邪術照樣而行，叫青蛙上了埃及地。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="出埃及記 10:17; 出埃及記 9:28; 出埃及記 8:25–28"> 法老召了摩西、亞倫來，說：「請你們求耶和華使這青蛙離開我和我的民，我就容百姓去祭祀耶和華。」</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀上 18:25; 以賽亞書 10:15; 士師記 7:2"> 摩西對法老說：「任憑你吧，我要何時為你和你的臣僕並你的百姓祈求，除滅青蛙離開你和你的宮殿只留在河裏呢？」</span>
<span className="v" id="v10" data-v="10" data-xref="以賽亞書 46:9; 詩篇 86:8; 歷代志上 17:20"> 他說：「明天。」摩西說：「可以照你的話吧，好叫你知道沒有像耶和華－我們上帝的。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及記 8:3; 出埃及記 8:9"> 青蛙要離開你和你的宮殿，並你的臣僕與你的百姓，只留在河裏。」</span>
<span className="v" id="v12" data-v="12" data-xref="雅各書 5:16–18; 出埃及記 8:30; 出埃及記 10:18"> 於是摩西、亞倫離開法老出去。摩西為擾害法老的青蛙呼求耶和華。</span>
<span className="v" id="v13" data-v="13" data-xref="申命記 34:10–12"> 耶和華就照摩西的話行。凡在房裏、院中、田間的青蛙都死了。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及記 8:24; 出埃及記 7:21; 約珥書 2:20"> 眾人把青蛙聚攏成堆，遍地就都腥臭。</span>
<span className="v" id="v15" data-v="15" data-xref="以賽亞書 26:10; 傳道書 8:11; 希伯來書 3:8"> 但法老見災禍鬆緩，就硬着心，不肯聽他們，正如耶和華所說的。</span>
</div>
</div>

## －虱災

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="出埃及記 8:5; 出埃及記 8:17"> 耶和華吩咐摩西說：「你對亞倫說：『伸出你的杖擊打地上的塵土，使塵土在埃及遍地變作虱子<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或譯：虼蚤；下同">a</a></sup>。』」</span>
<span className="v" id="v17" data-v="17" data-xref="詩篇 105:31; 以賽亞書 23:9; 使徒行傳 12:23"> 他們就這樣行。亞倫伸杖擊打地上的塵土，就在人身上和牲畜身上有了虱子；埃及遍地的塵土都變成虱子了。</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及記 7:11; 出埃及記 9:11; 但以理書 5:8"> 行法術的也用邪術要生出虱子來，卻是不能。於是在人身上和牲畜身上都有了虱子。</span>
<span className="v" id="v19" data-v="19" data-xref="路加福音 11:20; 詩篇 8:3; 出埃及記 7:5"> 行法術的就對法老說：「這是上帝的手段。」法老心裏剛硬，不肯聽摩西、亞倫，正如耶和華所說的。</span>
</div>
</div>

## －蠅災

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="出埃及記 7:15; 出埃及記 9:13; 出埃及記 8:1"> 耶和華對摩西說：「你清早起來，法老來到水邊，你站在他面前，對他說：『耶和華這樣說：容我的百姓去，好事奉我。</span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 78:45; 以賽亞書 7:18; 詩篇 105:31"> 你若不容我的百姓去，我要叫成群的蒼蠅到你和你臣僕並你百姓的身上，進你的房屋，並且埃及人的房屋和他們所住的地都要滿了成群的蒼蠅。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及記 9:4; 瑪拉基書 3:18; 出埃及記 10:23"> 當那日，我必分別我百姓所住的歌珊地，使那裏沒有成群的蒼蠅，好叫你知道我是天下的耶和華。</span>
<span className="v" id="v23" data-v="23"> 我要將我的百姓和你的百姓分別出來。明天必有這神蹟。』」</span>
<span className="v" id="v24" data-v="24" data-xref="詩篇 105:31; 詩篇 78:45; 出埃及記 8:21"> 耶和華就這樣行。蒼蠅成了大群，進入法老的宮殿，和他臣僕的房屋；埃及遍地就因這成群的蒼蠅敗壞了。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="出埃及記 8:8; 出埃及記 9:27; 出埃及記 10:16"> 法老召了摩西、亞倫來，說：「你們去，在這地祭祀你們的上帝吧！」</span>
<span className="v" id="v26" data-v="26" data-xref="創世記 43:32; 創世記 46:34; 申命記 7:25–26"> 摩西說：「這樣行本不相宜，因為我們要把埃及人所厭惡的祭祀耶和華－我們的上帝；若把埃及人所厭惡的在他們眼前獻為祭，他們豈不拿石頭打死我們嗎？</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及記 3:18; 出埃及記 3:12; 出埃及記 34:11"> 我們要往曠野去，走三天的路程，照着耶和華－我們上帝所要吩咐我們的祭祀他。」</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及記 8:8; 出埃及記 9:28; 列王紀上 13:6"> 法老說：「我容你們去，在曠野祭祀耶和華－你們的上帝；只是不要走得很遠。求你們為我祈禱。」</span>
<span className="v" id="v29" data-v="29" data-xref="出埃及記 8:15; 耶利米書 42:20–21; 出埃及記 8:8"> 摩西說：「我要出去求耶和華，使成群的蒼蠅明天離開法老和法老的臣僕並法老的百姓；法老卻不可再行詭詐，不容百姓去祭祀耶和華。」</span>
<span className="v" id="v30" data-v="30" data-xref="出埃及記 8:12; 出埃及記 9:33; 雅各書 5:16"> 於是摩西離開法老去求耶和華。</span>
<span className="v" id="v31" data-v="31"> 耶和華就照摩西的話行，叫成群的蒼蠅離開法老和他的臣僕並他的百姓，一個也沒有留下。</span>
<span className="v" id="v32" data-v="32" data-xref="出埃及記 8:15; 出埃及記 4:21; 羅馬書 2:5"> 這一次法老又硬着心，不容百姓去。</span>
</div>
</div>

## 祭司的聖服

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民數記 18:7; 希伯來書 5:1–5; 民數記 17:2–9"> 「你要從以色列人中，使你的哥哥亞倫和他的兒子拿答、亞比戶、以利亞撒、以他瑪一同就近你，給我供祭司的職分。</span>
<span className="v" id="v2" data-v="2" data-xref="利未記 8:30; 出埃及記 31:10; 啟示錄 19:8"> 你要給你哥哥亞倫做聖衣為榮耀，為華美。</span>
<span className="v" id="v3" data-v="3" data-xref="以弗所書 1:17; 哥林多前書 12:7–11; 以賽亞書 11:2"> 又要吩咐一切心中有智慧的，就是我用智慧的靈所充滿的，給亞倫做衣服，使他分別為聖，可以給我供祭司的職分。</span>
<span className="v" id="v4" data-v="4" data-xref="以弗所書 6:14; 啟示錄 9:17; 以賽亞書 59:17"> 所要做的就是胸牌、以弗得、外袍、雜色的內袍、冠冕、腰帶，使你哥哥亞倫和他兒子穿這聖服，可以給我供祭司的職分。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 25:3–4; 出埃及記 39:2–3"> 要用金線和藍色、紫色、朱紅色線，並細麻去做。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="出埃及記 39:2–7; 出埃及記 26:1"> 「他們要拿金線和藍色、紫色、朱紅色線，並撚的細麻，用巧匠的手工做以弗得。</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及記 39:4"> 以弗得當有兩條肩帶，接上兩頭，使它相連。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及記 28:27–28; 利未記 8:7; 出埃及記 29:5"> 其上巧工織的帶子，要和以弗得一樣的做法，用以束上，與以弗得接連一塊，要用金線和藍色、紫色、朱紅色線，並撚的細麻做成。</span>
<span className="v" id="v9" data-v="9" data-xref="以西結書 28:13; 歷代志下 2:7; 以賽亞書 49:16"> 要取兩塊紅瑪瑙，在上面刻以色列兒子的名字：</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及記 1:1–4; 創世記 43:33"> 六個名字在這塊寶石上，六個名字在那塊寶石上，都照他們生來的次序。</span>
<span className="v" id="v11" data-v="11" data-xref="提摩太後書 2:19; 啟示錄 7:2; 耶利米書 22:24"> 要用刻寶石的手工，彷彿刻圖書，按着以色列兒子的名字，刻這兩塊寶石，要鑲在金槽上。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及記 28:29; 約書亞記 4:7; 出埃及記 39:6–7"> 要將這兩塊寶石安在以弗得的兩條肩帶上，為以色列人做紀念石。亞倫要在兩肩上擔他們的名字，在耶和華面前作為紀念。</span>
<span className="v" id="v13" data-v="13"> 要用金子做二槽，</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及記 39:15; 出埃及記 39:17–18; 列王紀上 7:17"> 又拿精金，用擰工彷彿擰繩子，做兩條鍊子，把這擰成的鍊子搭在二槽上。」</span>
</div>
</div>

## 胸牌

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="出埃及記 28:30; 出埃及記 26:1; 出埃及記 28:4"> 「你要用巧匠的手工做一個決斷的胸牌。要和以弗得一樣的做法：用金線和藍色、紫色、朱紅色線，並撚的細麻做成。</span>
<span className="v" id="v16" data-v="16"> 這胸牌要四方的，疊為兩層，長一虎口，寬一虎口。</span>
<span className="v" id="v17" data-v="17" data-xref="以西結書 28:13; 出埃及記 39:10–21; 箴言 8:11"> 要在上面鑲寶石四行：第一行是紅寶石、紅璧璽、紅玉；</span>
<span className="v" id="v18" data-v="18" data-xref="以西結書 27:16; 約伯記 28:6; 雅歌 5:14"> 第二行是綠寶石、藍寶石、金鋼石；</span>
<span className="v" id="v19" data-v="19" data-xref="以賽亞書 54:12; 出埃及記 39:12"> 第三行是紫瑪瑙、白瑪瑙、紫晶；</span>
<span className="v" id="v20" data-v="20" data-xref="以西結書 1:16; 啟示錄 4:3; 但以理書 10:6"> 第四行是水蒼玉、紅瑪瑙、碧玉。這都要鑲在金槽中。</span>
<span className="v" id="v21" data-v="21" data-xref="啟示錄 21:12; 啟示錄 7:4–8; 列王紀上 18:31"> 這些寶石都要按着以色列十二個兒子的名字，彷彿刻圖書，刻十二個支派的名字。</span>
<span className="v" id="v22" data-v="22"> 要在胸牌上用精金擰成如繩的鍊子。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及記 25:11–15"> 在胸牌上也要做兩個金環，安在胸牌的兩頭。</span>
<span className="v" id="v24" data-v="24"> 要把那兩條擰成的金鍊子，穿過胸牌兩頭的環子。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及記 39:15; 出埃及記 39:4; 出埃及記 28:14"> 又要把鍊子的那兩頭接在兩槽上，安在以弗得前面肩帶上。</span>
<span className="v" id="v26" data-v="26"> 要做兩個金環，安在胸牌的兩頭，在以弗得裏面的邊上。</span>
<span className="v" id="v27" data-v="27"> 又要做兩個金環，安在以弗得前面兩條肩帶的下邊，挨近相接之處，在以弗得巧工織的帶子以上。</span>
<span className="v" id="v28" data-v="28" data-xref="民數記 15:38; 出埃及記 28:31; 出埃及記 39:30–31"> 要用藍細帶子把胸牌的環子與以弗得的環子繫住，使胸牌貼在以弗得巧工織的帶子上，不可與以弗得離縫。</span>
<span className="v" id="v29" data-v="29" data-xref="出埃及記 28:12; 出埃及記 28:30; 耶利米書 30:21"> 亞倫進聖所的時候，要將決斷胸牌，就是刻着以色列兒子名字的，帶在胸前，在耶和華面前常作紀念。</span>
<span className="v" id="v30" data-v="30" data-xref="尼希米記 7:65; 以斯拉記 2:63; 民數記 27:21"> 又要將烏陵和土明放在決斷的胸牌裏；亞倫進到耶和華面前的時候，要帶在胸前，在耶和華面前常將以色列人的決斷牌帶在胸前。」</span>
</div>
</div>

## 祭司的其他聖服

<div className="bt">
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="利未記 8:7; 出埃及記 28:4; 出埃及記 39:22–26"> 「你要做以弗得的外袍，顏色全是藍的。</span>
<span className="v" id="v32" data-v="32" data-xref="尼希米記 4:16; 約翰福音 19:23–24; 出埃及記 39:28"> 袍上要為頭留一領口，口的周圍織出領邊來，彷彿鎧甲的領口，免得破裂。</span>
<span className="v" id="v33" data-v="33" data-xref="出埃及記 39:24–26; 撒迦利亞書 14:20; 列王紀上 7:18"> 袍子周圍底邊上要用藍色、紫色、朱紅色線做石榴。在袍子周圍的石榴中間要有金鈴鐺：</span>
<span className="v" id="v34" data-v="34" data-xref="雅歌 8:2; 約翰福音 15:4–8; 歌羅西書 1:10"> 一個金鈴鐺一個石榴，一個金鈴鐺一個石榴，在袍子周圍的底邊上。</span>
<span className="v" id="v35" data-v="35" data-xref="希伯來書 9:12; 利未記 16:2"> 亞倫供職的時候要穿這袍子。他進聖所到耶和華面前，以及出來的時候，袍上的響聲必被聽見，使他不至於死亡。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="撒迦利亞書 14:20; 利未記 8:9; 出埃及記 39:30"> 「你要用精金做一面牌，在上面按刻圖書之法刻着『歸耶和華為聖』。</span>
<span className="v" id="v37" data-v="37" data-xref="出埃及記 29:6; 出埃及記 28:4; 撒迦利亞書 3:5"> 要用一條藍細帶子將牌繫在冠冕的前面。</span>
<span className="v" id="v38" data-v="38" data-xref="彼得前書 2:24; 民數記 18:1; 利未記 10:17"> 這牌必在亞倫的額上，亞倫要擔當干犯聖物條例的罪孽；這聖物是以色列人在一切的聖禮物上所分別為聖的。這牌要常在他的額上，使他們可以在耶和華面前蒙悅納。</span>
<span className="v" id="v39" data-v="39" data-xref="詩篇 45:14"> 要用雜色細麻線織內袍，用細麻布做冠冕，又用繡花的手工做腰帶。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="出埃及記 39:41; 出埃及記 28:4; 出埃及記 28:2"> 「你要為亞倫的兒子做內袍、腰帶、裹頭巾，為榮耀，為華美。</span>
<span className="v" id="v41" data-v="41" data-xref="出埃及記 29:7; 利未記 8:1–36; 出埃及記 40:15"> 要把這些給你的哥哥亞倫和他的兒子穿戴，又要膏他們，將他們分別為聖，好給我供祭司的職分。</span>
<span className="v" id="v42" data-v="42" data-xref="以西結書 44:18; 利未記 6:10; 利未記 16:4"> 要給他們做細麻布褲子，遮掩下體；褲子當從腰達到大腿。</span>
<span className="v" id="v43" data-v="43" data-xref="出埃及記 27:21; 出埃及記 20:26; 利未記 5:17"> 亞倫和他兒子進入會幕，或就近壇，在聖所供職的時候必穿上，免得擔罪而死。這要為亞倫和他的後裔作永遠的定例。」</span>
</div>
</div>

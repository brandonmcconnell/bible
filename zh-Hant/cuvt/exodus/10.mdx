## －蝗災

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及記 4:21; 出埃及記 7:13–14; 出埃及記 3:20"> 耶和華對摩西說：「你進去見法老。我使他和他臣僕的心剛硬，為要在他們中間顯我這些神蹟，</span>
<span className="v" id="v2" data-v="2" data-xref="約珥書 1:3; 申命記 4:9; 申命記 6:20–22"> 並要叫你將我向埃及人所做的事，和在他們中間所行的神蹟，傳於你兒子和你孫子的耳中，好叫你們知道我是耶和華。」</span>
<span className="v" id="v3" data-v="3" data-xref="彼得前書 5:6; 列王紀上 21:29; 雅各書 4:10"> 摩西、亞倫就進去見法老，對他說：「耶和華－希伯來人的上帝這樣說：『你在我面前不肯自卑要到幾時呢？容我的百姓去，好事奉我。</span>
<span className="v" id="v4" data-v="4" data-xref="啟示錄 9:3; 約珥書 2:25; 出埃及記 11:4–5"> 你若不肯容我的百姓去，明天我要使蝗蟲進入你的境內，</span>
<span className="v" id="v5" data-v="5" data-xref="約珥書 1:4; 出埃及記 9:32; 約珥書 2:25"> 遮滿地面，甚至看不見地，並且吃那冰雹所剩的和田間所長的一切樹木。</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及記 8:21; 出埃及記 8:3; 出埃及記 11:6"> 你的宮殿和你眾臣僕的房屋，並一切埃及人的房屋，都要被蝗蟲佔滿了；自從你祖宗和你祖宗的祖宗在世以來，直到今日，沒有見過這樣的災。』」摩西就轉身離開法老出去。</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳記上 18:21; 出埃及記 23:33; 約書亞記 23:13"> 法老的臣僕對法老說：「這人為我們的網羅要到幾時呢？容這些人去事奉耶和華－他們的上帝吧！埃及已經敗壞了，你還不知道嗎？」</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及記 10:24; 出埃及記 12:31; 出埃及記 8:8"> 於是摩西、亞倫被召回來見法老；法老對他們說：「你們去事奉耶和華－你們的上帝；但那要去的是誰呢？」</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及記 5:1; 哥林多前書 5:7–8; 申命記 31:12–13"> 摩西說：「我們要和我們老的少的、兒子女兒同去，且把羊群牛群一同帶去，因為我們務要向耶和華守節。」</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及記 13:21; 歷代志下 32:15; 出埃及記 12:30–31"> 法老對他們說：「我容你們和你們婦人孩子去的時候，耶和華與你們同在吧！你們要謹慎；因為有禍在你們眼前<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或譯：你們存着惡意">a</a></sup>，</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及記 10:28; 詩篇 119:69; 出埃及記 5:4"> 不可都去！你們這壯年人去事奉耶和華吧，因為這是你們所求的。」於是把他們從法老面前攆出去。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及記 7:19; 出埃及記 10:4–5"> 耶和華對摩西說：「你向埃及地伸杖，使蝗蟲到埃及地上來，吃地上一切的菜蔬，就是冰雹所剩的。」</span>
<span className="v" id="v13" data-v="13" data-xref="約拿書 1:4; 詩篇 78:26; 詩篇 148:8"> 摩西就向埃及地伸杖，那一晝一夜，耶和華使東風颳在埃及地上；到了早晨，東風把蝗蟲颳了來。</span>
<span className="v" id="v14" data-v="14" data-xref="詩篇 78:46; 約珥書 1:2–4; 詩篇 105:34–35"> 蝗蟲上來，落在埃及的四境，甚是厲害；以前沒有這樣的，以後也必沒有。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及記 10:5; 詩篇 78:46; 約珥書 1:6–7"> 因為這蝗蟲遮滿地面，甚至地都黑暗了，又吃地上一切的菜蔬和冰雹所剩樹上的果子。埃及遍地，無論是樹木，是田間的菜蔬，連一點青的也沒有留下。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 9:27; 撒母耳記下 19:20; 撒母耳記上 15:30"> 於是法老急忙召了摩西、亞倫來，說：「我得罪耶和華－你們的上帝，又得罪了你們。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及記 8:8; 出埃及記 9:28; 列王紀上 13:6"> 現在求你，只這一次，饒恕我的罪，求耶和華－你們的上帝使我脫離這一次的死亡。」</span>
<span className="v" id="v18" data-v="18" data-xref="路加福音 6:28; 出埃及記 8:28–30; 出埃及記 8:9"> 摩西就離開法老去求耶和華。</span>
<span className="v" id="v19" data-v="19" data-xref="約珥書 2:20; 出埃及記 13:18; 出埃及記 15:4"> 耶和華轉了極大的西風，把蝗蟲颳起，吹入紅海；在埃及的四境連一個也沒有留下。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及記 4:21; 出埃及記 11:10; 申命記 2:30"> 但耶和華使法老的心剛硬，不容以色列人去。</span>
</div>
</div>

## －黑暗之災

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="啟示錄 16:10–11; 猶大書 1:6; 路加福音 23:44"> 耶和華對摩西說：「你向天伸杖，使埃及地黑暗；這黑暗似乎摸得着。」</span>
<span className="v" id="v22" data-v="22" data-xref="詩篇 105:28; 啟示錄 16:10; 出埃及記 20:21"> 摩西向天伸杖，埃及遍地就烏黑了三天。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及記 8:22; 以賽亞書 42:16; 彼得前書 2:9"> 三天之久，人不能相見，誰也不敢起來離開本處；惟有以色列人家中都有亮光。</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及記 10:8–10; 出埃及記 8:28; 創世記 34:23"> 法老就召摩西來，說：「你們去事奉耶和華；只是你們的羊群牛群要留下；你們的婦人孩子可以和你們同去。」</span>
<span className="v" id="v25" data-v="25" data-xref="利未記 9:22; 利未記 16:9; 出埃及記 29:1–46"> 摩西說：「你總要把祭物和燔祭牲交給我們，使我們可以祭祀耶和華－我們的上帝。</span>
<span className="v" id="v26" data-v="26" data-xref="以賽亞書 23:18; 使徒行傳 2:44–45; 箴言 3:9"> 我們的牲畜也要帶去，連一蹄也不留下；因為我們要從其中取出來，事奉耶和華－我們的上帝。我們未到那裏，還不知道用甚麼事奉耶和華。」</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及記 10:20; 出埃及記 4:21; 出埃及記 14:8"> 但耶和華使法老的心剛硬，不肯容他們去。</span>
<span className="v" id="v28" data-v="28" data-xref="歷代志下 25:16; 歷代志下 16:10; 阿摩司書 7:13"> 法老對摩西說：「你離開我去吧，你要小心，不要再見我的面！因為你見我面的那日你就必死！」</span>
<span className="v" id="v29" data-v="29" data-xref="希伯來書 11:27; 出埃及記 12:30–31; 出埃及記 11:4–8"> 摩西說：「你說得好！我必不再見你的面了。」</span>
</div>

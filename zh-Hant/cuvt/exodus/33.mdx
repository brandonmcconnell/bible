## 耶和華吩咐以色列人離開西奈山

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 12:7; 出埃及記 32:13; 出埃及記 32:7"> 耶和華吩咐摩西說：「我曾起誓應許亞伯拉罕、以撒、雅各說：『要將迦南地賜給你的後裔。』現在你和你從埃及地所領出來的百姓，要從這裏往那地去。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 32:34; 約書亞記 24:11; 出埃及記 23:27–31"> 我要差遣使者在你前面，攆出迦南人、亞摩利人、赫人、比利洗人、希未人、耶布斯人，</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 32:9–10; 出埃及記 3:8; 使徒行傳 7:51"> 領你到那流奶與蜜之地。我自己不同你們上去；因為你們是硬着頸項的百姓，恐怕我在路上把你們滅絕。」</span>
<span className="v" id="v4" data-v="4" data-xref="民數記 14:39; 民數記 14:1; 以西結書 26:16"> 百姓聽見這凶信就悲哀，也沒有人佩戴妝飾。</span>
<span className="v" id="v5" data-v="5" data-xref="民數記 16:21; 民數記 16:45–46; 出埃及記 33:3–4"> 耶和華對摩西說：「你告訴以色列人說：『耶和華說：你們是硬着頸項的百姓，我若一霎時臨到你們中間，必滅絕你們。現在你們要把身上的妝飾摘下來，使我可以知道怎樣待你們。』」</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及記 33:4; 出埃及記 32:3; 耶利米書 2:19"> 以色列人從住何烈山以後，就把身上的妝飾摘得乾淨。</span>
</div>
</div>

## 耶和華的會幕

<div className="bt">
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="以賽亞書 55:6–7; 出埃及記 29:42–43; 箴言 15:29"> 摩西素常將帳棚支搭在營外，離營卻遠，他稱這帳棚為會幕。凡求問耶和華的，就到營外的會幕那裏去。</span>
<span className="v" id="v8" data-v="8" data-xref="民數記 16:27"> 當摩西出營到會幕去的時候，百姓就都起來，各人站在自己帳棚的門口，望着摩西，直等到他進了會幕。</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 99:7; 出埃及記 31:18; 出埃及記 13:21–22"> 摩西進會幕的時候，雲柱降下來，立在會幕的門前，耶和華便與摩西說話。</span>
<span className="v" id="v10" data-v="10" data-xref="列王紀上 8:22; 列王紀上 8:14; 出埃及記 4:31"> 眾百姓看見雲柱立在會幕門前，就都起來，各人在自己帳棚的門口下拜。</span>
<span className="v" id="v11" data-v="11" data-xref="民數記 12:8; 申命記 34:10; 出埃及記 24:13"> 耶和華與摩西面對面說話，好像人與朋友說話一般。摩西轉到營裏去，惟有他的幫手－一個少年人嫩的兒子約書亞不離開會幕。</span>
</div>
</div>

## 耶和華應許跟百姓同在

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="出埃及記 33:17; 耶利米書 1:5; 約翰福音 10:14–15"> 摩西對耶和華說：「你吩咐我說：『將這百姓領上去』，卻沒有叫我知道你要打發誰與我同去，只說：『我按你的名認識你，你在我眼前也蒙了恩。』</span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 119:33; 詩篇 25:4; 詩篇 27:11"> 我如今若在你眼前蒙恩，求你將你的道指示我，使我可以認識你，好在你眼前蒙恩。求你想到這民是你的民。」</span>
<span className="v" id="v14" data-v="14" data-xref="約書亞記 21:44; 馬太福音 11:28; 約書亞記 1:5"> 耶和華說：「我必親自和你同去，使你得安息。」</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及記 34:9; 詩篇 4:6; 出埃及記 33:3"> 摩西說：「你若不親自和我同去，就不要把我們從這裏領上去。</span>
<span className="v" id="v16" data-v="16" data-xref="申命記 4:7; 民數記 14:14; 列王紀上 8:53"> 人在何事上得以知道我和你的百姓在你眼前蒙恩呢？豈不是因你與我們同去、使我和你的百姓與地上的萬民有分別嗎？」</span>
<span className="v" id="v17" data-v="17" data-xref="以賽亞書 65:24; 約翰一書 5:14–15; 出埃及記 33:12"> 耶和華對摩西說：「你這所求的我也要行；因為你在我眼前蒙了恩，並且我按你的名認識你。」</span>
<span className="v" id="v18" data-v="18" data-xref="啟示錄 21:23; 出埃及記 33:20; 提多書 2:13"> 摩西說：「求你顯出你的榮耀給我看。」</span>
<span className="v" id="v19" data-v="19" data-xref="羅馬書 9:15–18; 以弗所書 1:6–8; 耶利米書 31:14"> 耶和華說：「我要顯我一切的恩慈，在你面前經過，宣告我的名。我要恩待誰就恩待誰；要憐憫誰就憐憫誰」；</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 32:30; 約翰福音 1:18; 提摩太前書 6:16"> 又說：「你不能看見我的面，因為人見我的面不能存活。」</span>
<span className="v" id="v21" data-v="21" data-xref="申命記 5:31; 撒迦利亞書 3:7; 約書亞記 20:4"> 耶和華說：「看哪，在我這裏有地方，你要站在磐石上。</span>
<span className="v" id="v22" data-v="22" data-xref="詩篇 91:1; 以賽亞書 2:21; 詩篇 91:4"> 我的榮耀經過的時候，我必將你放在磐石穴中，用我的手遮掩你，等我過去，</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及記 33:20; 約翰福音 1:18; 提摩太前書 6:16"> 然後我要將我的手收回，你就得見我的背，卻不得見我的面。」</span>
</div>
</div>

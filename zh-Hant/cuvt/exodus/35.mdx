## 安息日的條例

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及記 34:32; 出埃及記 31:1–11; 羅馬書 2:13"> 摩西招聚以色列全會眾，對他們說：「這是耶和華所吩咐的話，叫你們照着行：</span>
<span className="v" id="v2" data-v="2" data-xref="利未記 23:3; 路加福音 13:14–15; 出埃及記 20:9–10"> 六日要做工，第七日乃為聖日，當向耶和華守為安息聖日。凡這日之內做工的，必把他治死。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 16:23; 民數記 15:32–36; 出埃及記 12:16"> 當安息日，不可在你們一切的住處生火。」</span>
</div>
</div>

## 為會幕奉獻

<div className="bt">
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="出埃及記 25:1–2"> 摩西對以色列全會眾說：「耶和華所吩咐的是這樣：</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多後書 9:7; 詩篇 110:3; 出埃及記 25:2–7"> 你們中間要拿禮物獻給耶和華，凡樂意獻的可以拿耶和華的禮物來，就是金、銀、銅，</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及記 26:7–14; 出埃及記 26:31; 出埃及記 28:15"> 藍色、紫色、朱紅色線，細麻，山羊毛，</span>
<span className="v" id="v7" data-v="7"> 染紅的公羊皮，海狗皮，皂莢木，</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及記 27:20; 出埃及記 25:1–40; 出埃及記 30:23"> 點燈的油，並做膏油和香的香料，</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及記 39:6–14; 出埃及記 28:9; 出埃及記 25:5"> 紅瑪瑙與別樣的寶石，可以鑲嵌在以弗得和胸牌上。」</span>
</div>
</div>

## 會幕的器物

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="出埃及記 31:1–6; 出埃及記 36:1–4"> 「你們中間凡心裏有智慧的都要來做耶和華一切所吩咐的：</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及記 26:1–37; 出埃及記 36:8–34; 出埃及記 31:7–9"> 就是帳幕和帳幕的罩棚，並帳幕的蓋、鉤子、板、閂、柱子、帶卯的座，</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及記 25:10–22; 出埃及記 26:31–33; 出埃及記 37:1–9"> 櫃和櫃的槓，施恩座和遮掩櫃的幔子，</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及記 25:23–30; 利未記 24:5–6; 出埃及記 37:10–16"> 桌子和桌子的槓與桌子的一切器具，並陳設餅，</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及記 25:31–39; 馬太福音 5:14–15; 出埃及記 37:17–24"> 燈臺和燈臺的器具，燈盞並點燈的油，</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及記 30:1–10; 出埃及記 30:22–38; 出埃及記 37:25–28"> 香壇和壇的槓，膏油和馨香的香料，並帳幕門口的簾子，</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 27:1–8; 出埃及記 30:18–21; 出埃及記 38:1–8"> 燔祭壇和壇的銅網，壇的槓並壇的一切器具，洗濯盆和盆座，</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳記下 7:2; 出埃及記 38:9–20; 出埃及記 27:9–19"> 院子的帷子和帷子的柱子，帶卯的座和院子的門簾，</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及記 27:19"> 帳幕的橛子並院子的橛子，和這兩處的繩子，</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及記 31:10; 民數記 4:5–15; 出埃及記 28:1–43"> 精工做的禮服和祭司亞倫並他兒子在聖所用以供祭司職分的聖衣。」</span>
</div>
</div>

## 百姓奉獻禮物

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20"> 以色列全會眾從摩西面前退去。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及記 25:2; 出埃及記 35:26; 歷代志上 29:14"> 凡心裏受感和甘心樂意的都拿耶和華的禮物來，用以做會幕和其中一切的使用，又用以做聖衣。</span>
<span className="v" id="v22" data-v="22" data-xref="尼希米記 7:70–72; 馬太福音 2:11; 以斯拉記 2:68–69"> 凡心裏樂意獻禮物的，連男帶女，各將金器，就是胸前鍼、耳環<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或譯：鼻環">a</a></sup>、打印的戒指，和手釧帶來獻給耶和華。</span>
<span className="v" id="v23" data-v="23" data-xref="歷代志上 29:8; 出埃及記 25:2–7; 出埃及記 35:6–10"> 凡有藍色、紫色、朱紅色線，細麻，山羊毛，染紅的公羊皮，海狗皮的，都拿了來；</span>
<span className="v" id="v24" data-v="24" data-xref="哥林多後書 8:12"> 凡獻銀子和銅給耶和華為禮物的都拿了來；凡有皂莢木可做甚麼使用的也拿了來。</span>
<span className="v" id="v25" data-v="25" data-xref="羅馬書 16:12; 路加福音 8:2–3; 箴言 14:1"> 凡心中有智慧的婦女親手紡線，把所紡的藍色、紫色、朱紅色線，和細麻都拿了來。</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及記 35:21; 出埃及記 36:8; 出埃及記 35:29"> 凡有智慧、心裏受感的婦女就紡山羊毛。</span>
<span className="v" id="v27" data-v="27" data-xref="以斯拉記 2:68; 歷代志上 29:6; 出埃及記 35:9"> 眾官長把紅瑪瑙和別樣的寶石，可以鑲嵌在以弗得與胸牌上的，都拿了來；</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及記 30:23–38; 出埃及記 35:8"> 又拿香料做香，拿油點燈，做膏油。</span>
<span className="v" id="v29" data-v="29" data-xref="哥林多後書 9:7; 出埃及記 35:21–22; 出埃及記 35:4"> 以色列人，無論男女，凡甘心樂意獻禮物給耶和華的，都將禮物拿來，做耶和華藉摩西所吩咐的一切工。</span>
</div>
</div>

## 造會幕的技工

<div className="bt">
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="出埃及記 31:1–6; 雅各書 1:17; 哥林多前書 12:11"> 摩西對以色列人說：「猶大支派中，戶珥的孫子、烏利的兒子比撒列，耶和華已經提他的名召他，</span>
<span className="v" id="v31" data-v="31" data-xref="雅各書 1:17; 以賽亞書 11:2–5; 以賽亞書 61:1–3"> 又以上帝的靈充滿了他，使他有智慧、聰明、知識，能做各樣的工，</span>
<span className="v" id="v32" data-v="32"> 能想出巧工，用金、銀、銅製造各物，</span>
<span className="v" id="v33" data-v="33"> 又能刻寶石，可以鑲嵌，能雕刻木頭，能做各樣的巧工。</span>
<span className="v" id="v34" data-v="34" data-xref="出埃及記 31:6; 歷代志下 2:14; 以斯拉記 7:27"> 耶和華又使他，和但支派中亞希撒抹的兒子亞何利亞伯，心裏靈明，能教導人。</span>
<span className="v" id="v35" data-v="35" data-xref="出埃及記 35:31; 列王紀上 7:14; 以賽亞書 28:26"> 耶和華使他們的心滿有智慧，能做各樣的工，無論是雕刻的工，巧匠的工，用藍色、紫色、朱紅色線，和細麻、繡花的工，並機匠的工，他們都能做，也能想出奇巧的工。</span>
</div>
</div>

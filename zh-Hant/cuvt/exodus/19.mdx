## 以色列人在西奈山

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及記 16:1; 出埃及記 12:6; 利未記 23:16–18"> 以色列人出埃及地以後，滿了三個月的那一天，就來到西奈的曠野。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 3:1; 出埃及記 17:1; 出埃及記 3:12"> 他們離了利非訂，來到西奈的曠野，就在那裏的山下安營。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 3:4; 使徒行傳 7:38; 出埃及記 20:21"> 摩西到上帝那裏，耶和華從山上呼喚他說：「你要這樣告訴雅各家，曉諭以色列人說：</span>
<span className="v" id="v4" data-v="4" data-xref="申命記 32:11–12; 以賽亞書 63:9; 以賽亞書 40:31"> 『我向埃及人所行的事，你們都看見了，且看見我如鷹將你們背在翅膀上，帶來歸我。</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 14:2; 申命記 7:6; 申命記 26:18"> 如今你們若實在聽從我的話，遵守我的約，就要在萬民中作屬我的子民，因為全地都是我的。</span>
<span className="v" id="v6" data-v="6" data-xref="啟示錄 5:10; 彼得前書 2:9; 彼得前書 2:5"> 你們要歸我作祭司的國度，為聖潔的國民。』這些話你要告訴以色列人。」</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及記 4:29–30; 出埃及記 3:16; 哥林多前書 15:1"> 摩西去召了民間的長老來，將耶和華所吩咐他的話都在他們面前陳明。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及記 24:7; 出埃及記 24:3; 約書亞記 24:24"> 百姓都同聲回答說：「凡耶和華所說的，我們都要遵行。」摩西就將百姓的話回覆耶和華。</span>
<span className="v" id="v9" data-v="9" data-xref="申命記 4:36; 出埃及記 19:16; 出埃及記 24:15–16"> 耶和華對摩西說：「我要在密雲中臨到你那裏，叫百姓在我與你說話的時候可以聽見，也可以永遠信你了。」 於是，摩西將百姓的話奏告耶和華。</span>
<span className="v" id="v10" data-v="10" data-xref="希伯來書 10:22; 創世記 35:2; 利未記 11:44–45"> 耶和華又對摩西說：「你往百姓那裏去，叫他們今天明天自潔，又叫他們洗衣服。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及記 19:16; 出埃及記 34:5; 申命記 33:2"> 到第三天要預備好了，因為第三天耶和華要在眾百姓眼前降臨在西奈山上。</span>
<span className="v" id="v12" data-v="12" data-xref="希伯來書 12:20–21; 約書亞記 3:4; 出埃及記 19:21"> 你要在山的四圍給百姓定界限，說：『你們當謹慎，不可上山去，也不可摸山的邊界；凡摸這山的，必要治死他。</span>
<span className="v" id="v13" data-v="13" data-xref="帖撒羅尼迦前書 4:16; 希伯來書 12:20; 出埃及記 19:16"> 不可用手摸他，必用石頭打死，或用箭射透；無論是人是牲畜，都不得活。到角聲拖長的時候，他們才可到山根來。』」</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及記 19:10"> 摩西下山往百姓那裏去，叫他們自潔，他們就洗衣服。</span>
<span className="v" id="v15" data-v="15" data-xref="哥林多前書 7:5; 撒母耳記上 21:4–5; 出埃及記 19:11"> 他對百姓說：「到第三天要預備好了。不可親近女人。」</span>
<span className="v" id="v16" data-v="16" data-xref="希伯來書 12:18–19; 詩篇 18:11–14; 希伯來書 12:21"> 到了第三天早晨，在山上有雷轟、閃電，和密雲，並且角聲甚大，營中的百姓盡都發顫。</span>
<span className="v" id="v17" data-v="17" data-xref="申命記 4:10; 申命記 5:5"> 摩西率領百姓出營迎接上帝，都站在山下。</span>
<span className="v" id="v18" data-v="18" data-xref="士師記 5:5; 出埃及記 3:2; 詩篇 144:5"> 西奈全山冒煙，因為耶和華在火中降於山上。山的煙氣上騰，如燒窯一般，遍山大大地震動。</span>
<span className="v" id="v19" data-v="19" data-xref="詩篇 81:7; 出埃及記 19:16; 尼希米記 9:13"> 角聲漸漸地高而又高，摩西就說話，上帝有聲音答應他。</span>
<span className="v" id="v20" data-v="20" data-xref="尼希米記 9:13; 出埃及記 34:2; 出埃及記 19:11"> 耶和華降臨在西奈山頂上，耶和華召摩西上山頂，摩西就上去。</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳記上 6:19; 出埃及記 3:5; 希伯來書 12:28–29"> 耶和華對摩西說：「你下去囑咐百姓，不可闖過來到我面前觀看，恐怕他們有多人死亡；</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及記 24:5; 使徒行傳 5:10; 歷代志上 13:9–11"> 又叫親近我的祭司自潔，恐怕我忽然出來擊殺他們。」</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及記 19:12; 約書亞記 3:4–5"> 摩西對耶和華說：「百姓不能上西奈山，因為你已經囑咐我們說：『要在山的四圍定界限，叫山成聖。』」</span>
<span className="v" id="v24" data-v="24" data-xref="希伯來書 4:16; 希伯來書 12:18–25; 希伯來書 12:29"> 耶和華對他說：「下去吧，你要和亞倫一同上來；只是祭司和百姓不可闖過來上到我面前，恐怕我忽然出來擊殺他們。」</span>
<span className="v" id="v25" data-v="25"> 於是摩西下到百姓那裏告訴他們。</span>

## 逾越節

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華在埃及地曉諭摩西、亞倫說：</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 13:4; 申命記 16:1; 出埃及記 34:18"> 「你們要以本月為正月，為一年之首。</span>
<span className="v" id="v3" data-v="3" data-xref="利未記 1:2; 哥林多前書 5:7; 約翰福音 1:29"> 你們吩咐以色列全會眾說：本月初十日，各人要按着父家取羊羔，一家一隻。</span>
<span className="v" id="v4" data-v="4"> 若是一家的人太少，吃不了一隻羊羔，本人就要和他隔壁的鄰舍共取一隻。你們預備羊羔，要按着人數和飯量計算。</span>
<span className="v" id="v5" data-v="5" data-xref="彼得前書 1:18–19; 希伯來書 9:13–14; 瑪拉基書 1:14"> 要無殘疾、一歲的公羊羔，你們或從綿羊裏取，或從山羊裏取，都可以。</span>
<span className="v" id="v6" data-v="6" data-xref="利未記 23:5; 歷代志下 30:15–18; 民數記 28:16"> 要留到本月十四日，在黃昏的時候，以色列全會眾把羊羔宰了。</span>
<span className="v" id="v7" data-v="7" data-xref="希伯來書 11:28; 出埃及記 12:22–23; 希伯來書 9:22"> 各家要取點血，塗在吃羊羔的房屋左右的門框上和門楣上。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及記 34:25; 申命記 16:7; 出埃及記 13:3"> 當夜要吃羊羔的肉；用火烤了，與無酵餅和苦菜同吃。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及記 12:8; 申命記 16:7; 耶利米哀歌 1:13"> 不可吃生的，斷不可吃水煮的，要帶着頭、腿、五臟，用火烤了吃。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及記 23:18; 出埃及記 34:25; 出埃及記 29:34"> 不可剩下一點留到早晨；若留到早晨，要用火燒了。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及記 12:27; 以弗所書 6:15; 哥林多前書 5:7"> 你們吃羊羔當腰間束帶，腳上穿鞋，手中拿杖，趕緊地吃；這是耶和華的逾越節。</span>
<span className="v" id="v12" data-v="12" data-xref="民數記 33:4; 出埃及記 12:23; 詩篇 82:6"> 因為那夜我要巡行埃及地，把埃及地一切頭生的，無論是人是牲畜，都擊殺了，又要敗壞埃及一切的神。我是耶和華。</span>
<span className="v" id="v13" data-v="13" data-xref="希伯來書 11:28; 出埃及記 12:23; 約翰一書 1:7"> 這血要在你們所住的房屋上作記號；我一見這血，就越過你們去。我擊殺埃及地頭生的時候，災殃必不臨到你們身上滅你們。」</span>
</div>
</div>

## 除酵節

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="列王紀下 23:21; 出埃及記 12:24; 出埃及記 13:9–10"> 「你們要記念這日，守為耶和華的節，作為你們世世代代永遠的定例。</span>
<span className="v" id="v15" data-v="15" data-xref="創世記 17:14; 申命記 16:3; 出埃及記 23:15"> 你們要吃無酵餅七日。頭一日要把酵從你們各家中除去；因為從頭一日起，到第七日為止，凡吃有酵之餅的，必從以色列中剪除。</span>
<span className="v" id="v16" data-v="16" data-xref="利未記 23:7–8; 民數記 28:18; 出埃及記 16:23"> 頭一日你們當有聖會，第七日也當有聖會。這兩日之內，除了預備各人所要吃的以外，無論何工都不可做。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及記 7:5; 出埃及記 13:3; 出埃及記 12:41"> 你們要守無酵節，因為我正當這日把你們的軍隊從埃及地領出來。所以，你們要守這日，作為世世代代永遠的定例。</span>
<span className="v" id="v18" data-v="18" data-xref="利未記 23:5–8; 出埃及記 12:15; 出埃及記 12:1–2"> 從正月十四日晚上，直到二十一日晚上，你們要吃無酵餅。</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及記 12:15; 出埃及記 23:15; 申命記 16:3"> 在你們各家中，七日之內不可有酵；因為凡吃有酵之物的，無論是寄居的，是本地的，必從以色列的會中剪除。</span>
<span className="v" id="v20" data-v="20"> 有酵的物，你們都不可吃；在你們一切住處要吃無酵餅。」</span>
</div>
</div>

## 第一個逾越節

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="出埃及記 12:3; 路加福音 22:7–13; 歷代志下 35:5–6"> 於是，摩西召了以色列的眾長老來，對他們說：「你們要按着家口取出羊羔，把這逾越節的羊羔宰了。</span>
<span className="v" id="v22" data-v="22" data-xref="希伯來書 11:28; 民數記 19:18; 詩篇 51:7"> 拿一把牛膝草，蘸盆裏的血，打在門楣上和左右的門框上。你們誰也不可出自己的房門，直到早晨。</span>
<span className="v" id="v23" data-v="23" data-xref="啟示錄 7:3; 啟示錄 9:4; 希伯來書 11:28"> 因為耶和華要巡行擊殺埃及人，他看見血在門楣上和左右的門框上，就必越過那門，不容滅命的進你們的房屋，擊殺你們。</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及記 12:14; 創世記 17:8–10"> 這例，你們要守着，作為你們和你們子孫永遠的定例。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及記 3:17; 出埃及記 3:8; 申命記 12:8–9"> 日後，你們到了耶和華按着所應許賜給你們的那地，就要守這禮。</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及記 13:14–15; 申命記 32:7; 詩篇 145:4"> 你們的兒女問你們說：『行這禮是甚麼意思？』</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及記 4:31; 出埃及記 12:11; 哥林多前書 5:7"> 你們就說：『這是獻給耶和華逾越節的祭。當以色列人在埃及的時候，他擊殺埃及人，越過以色列人的房屋，救了我們各家。』」於是百姓低頭下拜。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="希伯來書 11:28"> 耶和華怎樣吩咐摩西、亞倫，以色列人就怎樣行。</span>
</div>
</div>

## 頭胎的被殺

<div className="bt">
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="詩篇 78:51; 出埃及記 4:23; 詩篇 105:36"> 到了半夜，耶和華把埃及地所有的長子，就是從坐寶座的法老，直到被擄囚在監裏之人的長子，以及一切頭生的牲畜，盡都殺了。</span>
<span className="v" id="v30" data-v="30" data-xref="出埃及記 11:6; 阿摩司書 5:17; 箴言 21:13"> 法老和一切臣僕，並埃及眾人，夜間都起來了。在埃及有大哀號，無一家不死一個人的。</span>
<span className="v" id="v31" data-v="31" data-xref="出埃及記 6:1; 出埃及記 10:9; 出埃及記 3:19–20"> 夜間，法老召了摩西、亞倫來，說：「起來！連你們帶以色列人，從我民中出去，依你們所說的，去事奉耶和華吧！</span>
<span className="v" id="v32" data-v="32" data-xref="出埃及記 10:26; 創世記 27:34; 創世記 27:38"> 也依你們所說的，連羊群牛群帶着走吧！並要為我祝福。」</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="詩篇 105:38; 出埃及記 11:1; 創世記 20:3"> 埃及人催促百姓，打發他們快快出離那地，因為埃及人說：「我們都要死了。」</span>
<span className="v" id="v34" data-v="34" data-xref="出埃及記 8:3"> 百姓就拿着沒有酵的生麵，把摶麵盆包在衣服中，扛在肩頭上。</span>
<span className="v" id="v35" data-v="35" data-xref="出埃及記 3:21–22; 出埃及記 11:2–3; 創世記 15:14"> 以色列人照着摩西的話行，向埃及人要金器、銀器，和衣裳。</span>
<span className="v" id="v36" data-v="36" data-xref="創世記 15:14; 使徒行傳 7:10; 出埃及記 3:21–22"> 耶和華叫百姓在埃及人眼前蒙恩，以致埃及人給他們所要的。他們就把埃及人的財物奪去了。</span>
</div>
</div>

## 以色列人出埃及

<div className="bt">
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="民數記 1:46; 出埃及記 38:26; 民數記 33:3"> 以色列人從蘭塞起行，往疏割去；除了婦人孩子，步行的男人約有六十萬。</span>
<span className="v" id="v38" data-v="38" data-xref="民數記 11:4; 撒迦利亞書 8:23"> 又有許多閒雜人，並有羊群牛群，和他們一同上去。</span>
<span className="v" id="v39" data-v="39" data-xref="出埃及記 11:1; 出埃及記 6:1; 出埃及記 12:31–33"> 他們用埃及帶出來的生麵烤成無酵餅。這生麵原沒有發起；因為他們被催逼離開埃及，不能耽延，也沒有為自己預備甚麼食物。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="創世記 15:13; 使徒行傳 7:6; 使徒行傳 13:17"> 以色列人住在埃及共有四百三十年。</span>
<span className="v" id="v41" data-v="41" data-xref="哈巴谷書 2:3; 約翰福音 7:8; 使徒行傳 1:7"> 正滿了四百三十年的那一天，耶和華的軍隊都從埃及地出來了。</span>
<span className="v" id="v42" data-v="42" data-xref="申命記 16:1–6; 出埃及記 12:14; 出埃及記 13:10"> 這夜是耶和華的夜；因耶和華領他們出了埃及地，所以當向耶和華謹守，是以色列眾人世世代代該謹守的。</span>
</div>
</div>

## 逾越節的條例

<div className="bt">
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="出埃及記 12:48; 民數記 9:14; 出埃及記 12:11"> 耶和華對摩西、亞倫說：「逾越節的例是這樣：外邦人都不可吃這羊羔。</span>
<span className="v" id="v44" data-v="44" data-xref="創世記 17:12–13; 創世記 17:23"> 但各人用銀子買的奴僕，既受了割禮就可以吃。</span>
<span className="v" id="v45" data-v="45" data-xref="利未記 22:10; 以弗所書 2:12"> 寄居的和雇工人都不可吃。</span>
<span className="v" id="v46" data-v="46" data-xref="民數記 9:12; 約翰福音 19:36; 約翰福音 19:33"> 應當在一個房子裏吃；不可把一點肉從房子裏帶到外頭去。羊羔的骨頭一根也不可折斷。</span>
<span className="v" id="v47" data-v="47" data-xref="出埃及記 12:6; 民數記 9:13; 出埃及記 12:3"> 以色列全會眾都要守這禮。</span>
<span className="v" id="v48" data-v="48" data-xref="民數記 9:14; 歌羅西書 3:11; 加拉太書 3:28"> 若有外人寄居在你們中間，願向耶和華守逾越節，他所有的男子務要受割禮，然後才容他前來遵守，他也就像本地人一樣；但未受割禮的，都不可吃這羊羔。</span>
<span className="v" id="v49" data-v="49" data-xref="民數記 15:15–16; 民數記 15:29; 利未記 24:22"> 本地人和寄居在你們中間的外人同歸一例。」</span>
</div>
<div className="bp">
<span className="v" id="v50" data-v="50" data-xref="馬太福音 7:24–25; 出埃及記 6:26; 出埃及記 7:4"> 耶和華怎樣吩咐摩西、亞倫，以色列眾人就怎樣行了。</span>
<span className="v" id="v51" data-v="51" data-xref="出埃及記 12:41; 出埃及記 6:26"> 正當那日，耶和華將以色列人按着他們的軍隊，從埃及地領出來。</span>
</div>
</div>

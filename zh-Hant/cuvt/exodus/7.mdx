<span className="v" id="v1" data-v="1" data-xref="出埃及記 4:15–16; 詩篇 82:6; 約翰福音 10:35–36"> 耶和華對摩西說：「我使你在法老面前代替上帝，你的哥哥亞倫是替你說話的。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 4:15; 出埃及記 6:29; 申命記 4:2"> 凡我所吩咐你的，你都要說。你的哥哥亞倫要對法老說，容以色列人出他的地。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 4:21; 出埃及記 11:9; 詩篇 105:27–36"> 我要使法老的心剛硬，也要在埃及地多行神蹟奇事。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及記 11:9; 出埃及記 6:6; 出埃及記 12:51"> 但法老必不聽你們；我要伸手重重地刑罰埃及，將我的軍隊以色列民從埃及地領出來。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 14:18; 出埃及記 7:17; 出埃及記 8:22"> 我伸手攻擊埃及，將以色列人從他們中間領出來的時候，埃及人就要知道我是耶和華。」</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及記 7:2; 創世記 6:22; 出埃及記 7:10"> 摩西、亞倫這樣行；耶和華怎樣吩咐他們，他們就照樣行了。</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 34:7; 使徒行傳 7:30; 申命記 31:2"> 摩西、亞倫與法老說話的時候，摩西八十歲，亞倫八十三歲。</span>

## 亞倫的杖

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8"> 耶和華曉諭摩西、亞倫說：</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及記 4:2; 約翰福音 2:18; 以賽亞書 7:11"> 「法老若對你們說：『你們行件奇事吧！』你就吩咐亞倫說：『把杖丟在法老面前，使杖變作蛇。』」</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及記 4:3; 路加福音 10:19; 阿摩司書 9:3"> 摩西、亞倫進去見法老，就照耶和華所吩咐的行。亞倫把杖丟在法老和臣僕面前，杖就變作蛇。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及記 7:22; 提摩太後書 3:8; 出埃及記 8:18"> 於是法老召了博士和術士來；他們是埃及行法術的，也用邪術照樣而行。</span>
<span className="v" id="v12" data-v="12" data-xref="約翰一書 4:4; 出埃及記 9:11; 出埃及記 8:18–19"> 他們各人丟下自己的杖，杖就變作蛇；但亞倫的杖吞了他們的杖。</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及記 4:21; 出埃及記 8:15; 撒迦利亞書 7:11–12"> 法老心裏剛硬，不肯聽從摩西、亞倫，正如耶和華所說的。</span>
</div>
</div>

## 埃及遭災－血災

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="出埃及記 10:20; 出埃及記 8:15; 出埃及記 10:1"> 耶和華對摩西說：「法老心裏固執，不肯容百姓去。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及記 8:20; 出埃及記 2:5; 出埃及記 7:10"> 明日早晨，他出來往水邊去，你要往河邊迎接他，手裏要拿着那變過蛇的杖，</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 3:18; 出埃及記 9:1; 出埃及記 9:13"> 對他說：『耶和華－希伯來人的上帝打發我來見你，說：容我的百姓去，好在曠野事奉我。到如今你還是不聽。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及記 4:9; 出埃及記 5:2; 出埃及記 7:5"> 耶和華這樣說：我要用我手裏的杖擊打河中的水，水就變作血；因此，你必知道我是耶和華。</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及記 7:24; 出埃及記 7:21; 民數記 11:20"> 河裏的魚必死，河也要腥臭，埃及人就要厭惡吃這河裏的水。』」</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及記 14:21; 出埃及記 10:12; 出埃及記 8:5–6"> 耶和華曉諭摩西說：「你對亞倫說：『把你的杖伸在埃及所有的水以上，就是在他們的江、河、池、塘以上，叫水都變作血。在埃及遍地，無論在木器中，石器中，都必有血。』」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="詩篇 78:44; 詩篇 105:29; 出埃及記 7:17–18"> 摩西、亞倫就照耶和華所吩咐的行。亞倫在法老和臣僕眼前舉杖擊打河裏的水，河裏的水都變作血了。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及記 7:18; 啟示錄 8:9"> 河裏的魚死了，河也腥臭了，埃及人就不能吃這河裏的水；埃及遍地都有了血。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及記 7:11; 提摩太後書 3:8; 耶利米書 27:18"> 埃及行法術的，也用邪術照樣而行。法老心裏剛硬，不肯聽摩西、亞倫，正如耶和華所說的。</span>
<span className="v" id="v23" data-v="23" data-xref="耶利米書 36:24; 以西結書 40:4; 瑪拉基書 2:2"> 法老轉身進宮，也不把這事放在心上。</span>
<span className="v" id="v24" data-v="24"> 埃及人都在河的兩邊挖地，要得水喝，因為他們不能喝這河裏的水。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="出埃及記 10:23; 出埃及記 8:9–10; 撒母耳記下 24:13"> 耶和華擊打河以後滿了七天。</span>
</div>
</div>

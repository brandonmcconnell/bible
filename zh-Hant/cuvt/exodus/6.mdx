## 上帝呼召摩西

<div className="bt">
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="耶利米書 9:24; 瑪拉基書 3:6; 使徒行傳 17:24–25"> 上帝曉諭摩西說：「我是耶和華。</span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 83:18; 詩篇 68:4; 創世記 17:1"> 我從前向亞伯拉罕、以撒、雅各顯現為全能的上帝；至於我名耶和華，他們未曾知道。</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 28:4; 創世記 15:18; 創世記 17:7–8"> 我與他們堅定所立的約，要把他們寄居的迦南地賜給他們。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 2:24; 詩篇 106:44–45; 以賽亞書 63:9"> 我也聽見以色列人被埃及人苦待的哀聲，我也記念我的約。</span>
<span className="v" id="v6" data-v="6" data-xref="申命記 26:8; 歷代志上 17:21; 出埃及記 7:4"> 所以你要對以色列人說：『我是耶和華；我要用伸出來的膀臂重重地刑罰埃及人，救贖你們脫離他們的重擔，不做他們的苦工。</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 7:6; 申命記 29:13; 申命記 4:20"> 我要以你們為我的百姓，我也要作你們的上帝。你們要知道我是耶和華－你們的上帝，是救你們脫離埃及人之重擔的。</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 26:3; 創世記 15:18; 以西結書 20:42"> 我起誓應許給亞伯拉罕、以撒、雅各的那地，我要把你們領進去，將那地賜給你們為業。我是耶和華。』」</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及記 5:21; 約伯記 21:4; 出埃及記 14:12"> 摩西將這話告訴以色列人，只是他們因苦工愁煩，不肯聽他的話。</span>
<span className="v" id="v10" data-v="10"> 耶和華曉諭摩西說：</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及記 6:29; 出埃及記 5:23; 出埃及記 3:10"> 「你進去對埃及王法老說，要容以色列人出他的地。」</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及記 4:10; 耶利米書 1:6; 出埃及記 6:30"> 摩西在耶和華面前說：「以色列人尚且不聽我的話，法老怎肯聽我這拙口笨舌的人呢？」</span>
<span className="v" id="v13" data-v="13" data-xref="民數記 27:23; 提摩太前書 6:13; 詩篇 91:11"> 耶和華吩咐摩西、亞倫往以色列人和埃及王法老那裏去，把以色列人從埃及地領出來。</span>
</div>
</div>

## 摩西和亞倫的族譜

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="創世記 46:9; 歷代志上 5:3; 民數記 26:5–7"> 以色列人家長的名字記在下面。以色列長子呂便的兒子是哈諾、法路、希斯倫、迦米；這是呂便的各家。</span>
<span className="v" id="v15" data-v="15" data-xref="歷代志上 4:24; 創世記 46:10; 民數記 26:12–13"> 西緬的兒子是耶母利、雅憫、阿轄、雅斤、瑣轄，和迦南女子的兒子掃羅；這是西緬的各家。</span>
<span className="v" id="v16" data-v="16" data-xref="民數記 3:17; 創世記 46:11; 歷代志上 6:1"> 利未眾子的名字按着他們的後代記在下面：就是革順、哥轄、米拉利。利未一生的歲數是一百三十七歲。</span>
<span className="v" id="v17" data-v="17" data-xref="歷代志上 6:17; 民數記 3:18; 歷代志上 23:7"> 革順的兒子按着家室是立尼、示每。</span>
<span className="v" id="v18" data-v="18" data-xref="歷代志上 6:18; 歷代志上 6:2; 民數記 3:19"> 哥轄的兒子是暗蘭、以斯哈、希伯倫、烏薛。哥轄一生的歲數是一百三十三歲。</span>
<span className="v" id="v19" data-v="19" data-xref="民數記 3:20; 歷代志上 23:21; 歷代志上 6:19"> 米拉利的兒子是抹利和母示；這是利未的家，都按着他們的後代。</span>
<span className="v" id="v20" data-v="20" data-xref="民數記 26:59; 出埃及記 2:1–2; 出埃及記 6:18"> 暗蘭娶了他父親的妹妹約基別為妻，她給他生了亞倫和摩西。暗蘭一生的歲數是一百三十七歲。</span>
<span className="v" id="v21" data-v="21" data-xref="民數記 16:1; 歷代志上 6:37–38; 民數記 16:32"> 以斯哈的兒子是可拉、尼斐、細基利。</span>
<span className="v" id="v22" data-v="22" data-xref="利未記 10:4; 民數記 3:30; 尼希米記 3:20"> 烏薛的兒子是米沙利、以利撒反、西提利。</span>
<span className="v" id="v23" data-v="23" data-xref="路得記 4:19–20; 民數記 2:3; 民數記 1:7"> 亞倫娶了亞米拿達的女兒，拿順的妹妹，以利沙巴為妻，她給他生了拿答、亞比戶、以利亞撒、以他瑪。</span>
<span className="v" id="v24" data-v="24" data-xref="歷代志上 6:22–23; 民數記 16:1; 撒母耳記上 1:1"> 可拉的兒子是亞惜、以利加拿、亞比亞撒；這是可拉的各家。</span>
<span className="v" id="v25" data-v="25" data-xref="約書亞記 24:33; 民數記 25:7–13; 約書亞記 22:31–32"> 亞倫的兒子以利亞撒娶了普鐵的一個女兒為妻，她給他生了非尼哈。這是利未人的家長，都按着他們的家。</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及記 12:51; 出埃及記 12:17; 出埃及記 7:4"> 耶和華說：「將以色列人按着他們的軍隊從埃及地領出來。」這是對那亞倫、摩西說的。</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及記 6:26; 出埃及記 7:10; 詩篇 77:20"> 對埃及王法老說要將以色列人從埃及領出來的，就是這摩西、亞倫。</span>
</div>
</div>

## 耶和華吩咐摩西和亞倫

<div className="bt">
<div className="bp">
<span className="v" id="v28" data-v="28"> 當耶和華在埃及地對摩西說話的日子，</span>
<span className="v" id="v29" data-v="29" data-xref="出埃及記 6:11; 出埃及記 7:2; 出埃及記 6:2"> 他向摩西說：「我是耶和華；我對你說的一切話，你都要告訴埃及王法老。」</span>
<span className="v" id="v30" data-v="30" data-xref="出埃及記 6:12; 出埃及記 4:10; 哥林多前書 9:16–17"> 摩西在耶和華面前說：「看哪，我是拙口笨舌的人，法老怎肯聽我呢？」</span>
</div>

## 葉忒羅訪問摩西

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及記 2:16; 詩篇 77:14–15; 出埃及記 3:1"> 摩西的岳父，米甸祭司葉忒羅，聽見上帝為摩西和上帝的百姓以色列所行的一切事，就是耶和華將以色列從埃及領出來的事，</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 2:21; 出埃及記 4:25–26"> 便帶着摩西的妻子西坡拉，就是摩西從前打發回去的，</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 2:22; 使徒行傳 7:29; 詩篇 39:12"> 又帶着西坡拉的兩個兒子，一個名叫革舜，因為摩西說：「我在外邦作了寄居的」；</span>
<span className="v" id="v4" data-v="4" data-xref="希伯來書 13:6; 提摩太後書 4:17; 哥林多後書 1:8–10"> 一個名叫以利以謝，因為他說：「我父親的上帝幫助了我，救我脫離法老的刀。」</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 3:1; 出埃及記 3:12; 出埃及記 24:16–17"> 摩西的岳父葉忒羅帶着摩西的妻子和兩個兒子來到上帝的山，就是摩西在曠野安營的地方。</span>
<span className="v" id="v6" data-v="6"> 他對摩西說：「我是你岳父葉忒羅，帶着你的妻子和兩個兒子來到你這裏。」</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 29:13; 創世記 14:17; 撒母耳記下 11:7"> 摩西迎接他的岳父，向他下拜，與他親嘴，彼此問安，都進了帳棚。</span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 145:4–12; 尼希米記 9:9–15; 詩篇 107:2"> 摩西將耶和華為以色列的緣故向法老和埃及人所行的一切事，以及路上所遭遇的一切艱難，並耶和華怎樣搭救他們，都述說與他岳父聽。</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多前書 12:26; 羅馬書 12:15; 以賽亞書 66:10"> 葉忒羅因耶和華待以色列的一切好處，就是拯救他們脫離埃及人的手，便甚歡喜。</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 14:20; 撒母耳記下 18:28; 路加福音 1:68"> 葉忒羅說：「耶和華是應當稱頌的；他救了你們脫離埃及人和法老的手，將這百姓從埃及人的手下救出來。</span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 95:3; 出埃及記 15:11; 歷代志下 2:5"> 我現今在埃及人向這百姓發狂傲的事上得知，耶和華比萬神都大。」</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 31:54; 申命記 12:7; 出埃及記 24:11"> 摩西的岳父葉忒羅把燔祭和平安祭獻給上帝。亞倫和以色列的眾長老都來了，與摩西的岳父在上帝面前吃飯。</span>
</div>
</div>

## 選立百姓的官長

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="以賽亞書 16:5; 約伯記 29:7; 士師記 5:10"> 第二天，摩西坐着審判百姓，百姓從早到晚都站在摩西的左右。</span>
<span className="v" id="v14" data-v="14"> 摩西的岳父看見他向百姓所做的一切事，就說：「你向百姓做的是甚麼事呢？你為甚麼獨自坐着，眾百姓從早到晚都站在你的左右呢？」</span>
<span className="v" id="v15" data-v="15" data-xref="民數記 15:34; 民數記 27:5; 民數記 9:8"> 摩西對岳父說：「這是因百姓到我這裏來求問上帝。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 24:14; 哥林多前書 6:1; 撒母耳記下 15:3"> 他們有事的時候就到我這裏來，我便在兩造之間施行審判；我又叫他們知道上帝的律例和法度。」</span>
<span className="v" id="v17" data-v="17"> 摩西的岳父說：「你這做的不好。</span>
<span className="v" id="v18" data-v="18" data-xref="民數記 11:14–17; 使徒行傳 6:1–4; 哥林多後書 12:15"> 你和這些百姓必都疲憊；因為這事太重，你獨自一人辦理不了。</span>
<span className="v" id="v19" data-v="19" data-xref="民數記 27:5; 申命記 5:5; 出埃及記 20:19"> 現在你要聽我的話。我為你出個主意，願上帝與你同在。你要替百姓到上帝面前，將案件奏告上帝；</span>
<span className="v" id="v20" data-v="20" data-xref="申命記 5:1; 詩篇 143:8; 申命記 1:18"> 又要將律例和法度教訓他們，指示他們當行的道，當做的事；</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行傳 6:3; 申命記 1:13–17; 歷代志下 19:5–10"> 並要從百姓中揀選有才能的人，就是敬畏上帝、誠實無妄、恨不義之財的人，派他們作千夫長、百夫長、五十夫長、十夫長，管理百姓，</span>
<span className="v" id="v22" data-v="22" data-xref="民數記 11:17; 民數記 27:2; 民數記 15:33"> 叫他們隨時審判百姓，大事都要呈到你這裏，小事他們自己可以審判。這樣，你就輕省些，他們也可以同當此任。</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳記上 8:6–7; 出埃及記 18:18; 撒母耳記上 8:22"> 你若這樣行，上帝也這樣吩咐你，你就能受得住，這百姓也都平平安安歸回他們的住處。」</span>
<span className="v" id="v24" data-v="24" data-xref="以斯拉記 10:2; 出埃及記 18:19; 出埃及記 18:2–5"> 於是，摩西聽從他岳父的話，按着他所說的去行。</span>
<span className="v" id="v25" data-v="25" data-xref="申命記 1:15; 出埃及記 18:21; 使徒行傳 6:5"> 摩西從以色列人中揀選了有才能的人，立他們為百姓的首領，作千夫長、百夫長、五十夫長、十夫長。</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及記 18:22; 出埃及記 18:14–15; 申命記 17:8"> 他們隨時審判百姓，有難斷的案件就呈到摩西那裏，但各樣小事他們自己審判。</span>
<span className="v" id="v27" data-v="27" data-xref="民數記 10:29–30; 士師記 19:9; 創世記 31:55"> 此後，摩西讓他的岳父去，他就往本地去了。</span>
</div>

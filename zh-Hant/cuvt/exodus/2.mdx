## 摩西的出生

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民數記 26:59; 歷代志上 23:12–14; 出埃及記 6:16–20"> 有一個利未家的人娶了一個利未女子為妻。</span>
<span className="v" id="v2" data-v="2" data-xref="希伯來書 11:23; 使徒行傳 7:20; 詩篇 112:5"> 那女人懷孕，生一個兒子，見他俊美，就藏了他三個月，</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 1:22; 使徒行傳 7:19; 創世記 6:14"> 後來不能再藏，就取了一個蒲草箱，抹上石漆和石油，將孩子放在裏頭，把箱子擱在河邊的蘆荻中。</span>
<span className="v" id="v4" data-v="4" data-xref="民數記 26:59; 出埃及記 15:20; 彌迦書 6:4"> 孩子的姊姊遠遠站着，要知道他究竟怎麼樣。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行傳 7:21; 詩篇 12:5; 詩篇 9:9"> 法老的女兒來到河邊洗澡，她的使女們在河邊行走。她看見箱子在蘆荻中，就打發一個婢女拿來。</span>
<span className="v" id="v6" data-v="6" data-xref="列王紀上 8:50; 彼得前書 3:8; 使徒行傳 7:21"> 她打開箱子，看見那孩子。孩子哭了，她就可憐他，說：「這是希伯來人的一個孩子。」</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及記 2:4; 民數記 26:59; 民數記 12:1"> 孩子的姊姊對法老的女兒說：「我去在希伯來婦人中叫一個奶媽來，為你奶這孩子，可以不可以？」</span>
<span className="v" id="v8" data-v="8" data-xref="以賽亞書 46:3–4; 詩篇 27:10; 出埃及記 6:20"> 法老的女兒說：「可以。」童女就去叫了孩子的母親來。</span>
<span className="v" id="v9" data-v="9"> 法老的女兒對她說：「你把這孩子抱去，為我奶他，我必給你工價。」婦人就抱了孩子去奶他。</span>
<span className="v" id="v10" data-v="10" data-xref="希伯來書 11:24; 創世記 16:11; 撒母耳記上 1:20"> 孩子漸長，婦人把他帶到法老的女兒那裏，就作了她的兒子。她給孩子起名叫摩西，意思說：「因我把他從水裏拉出來。」</span>
</div>
</div>

## 摩西逃往米甸

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="希伯來書 11:24–26; 使徒行傳 7:22–24; 出埃及記 1:11"> 後來，摩西長大，他出去到他弟兄那裏，看他們的重擔，見一個埃及人打希伯來人的一個弟兄。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行傳 7:24–26"> 他左右觀看，見沒有人，就把埃及人打死了，藏在沙土裏。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行傳 7:26–28; 哥林多前書 6:7–8"> 第二天他出去，見有兩個希伯來人爭鬥，就對那欺負人的說：「你為甚麼打你同族的人呢？」</span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 12:14; 馬太福音 21:23; 創世記 19:9"> 那人說：「誰立你作我們的首領和審判官呢？難道你要殺我，像殺那埃及人嗎？」摩西便懼怕，說：「這事必是被人知道了。」</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行傳 7:29; 希伯來書 11:27; 創世記 24:11"> 法老聽見這事，就想殺摩西，但摩西躲避法老，逃往米甸地居住。</span>
<span className="v" id="v16" data-v="16" data-xref="創世記 24:11; 出埃及記 3:1; 撒母耳記上 9:11"> 一日，他在井旁坐下。米甸的祭司有七個女兒；她們來打水，打滿了槽，要飲父親的群羊。</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 29:10; 創世記 21:25; 創世記 26:15–22"> 有牧羊的人來，把她們趕走了，摩西卻起來幫助她們，又飲了她們的群羊。</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及記 3:1; 民數記 10:29; 出埃及記 4:18"> 她們來到父親流珥那裏；他說：「今日你們為何來得這麼快呢？」</span>
<span className="v" id="v19" data-v="19" data-xref="創世記 50:11; 創世記 29:10"> 她們說：「有一個埃及人救我們脫離牧羊人的手，並且為我們打水飲了群羊。」</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 31:54; 創世記 43:25; 希伯來書 13:2"> 他對女兒們說：「那個人在哪裏？你們為甚麼撇下他呢？你們去請他來吃飯。」</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 31:38–40; 希伯來書 13:5; 希伯來書 11:25"> 摩西甘心和那人同住；那人把他的女兒西坡拉給摩西為妻。</span>
<span className="v" id="v22" data-v="22" data-xref="希伯來書 11:13–14; 使徒行傳 7:29; 出埃及記 22:21"> 西坡拉生了一個兒子，摩西給他起名叫革舜，意思說：「因我在外邦作了寄居的。」</span>
<span className="v" id="v23" data-v="23" data-xref="創世記 18:20–21; 雅各書 5:4; 出埃及記 3:7–9"> 過了多年，埃及王死了。以色列人因做苦工，就歎息哀求，他們的哀聲達於上帝。</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 26:3; 詩篇 105:42; 出埃及記 6:5"> 上帝聽見他們的哀聲，就記念他與亞伯拉罕、以撒、雅各所立的約。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及記 4:31; 詩篇 55:22; 出埃及記 3:7–8"> 上帝看顧以色列人，也知道他們的苦情。</span>

## 賠償的條例

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 19:8; 撒母耳記下 12:6; 箴言 6:31"> 「人若偷牛或羊，無論是宰了，是賣了，他就要以五牛賠一牛，四羊賠一羊。</span>
<span className="v" id="v2" data-v="2" data-xref="馬太福音 24:43; 馬太福音 6:19–20; 民數記 35:27"> 人若遇見賊挖窟窿，把賊打了，以至於死，就不能為他有流血的罪。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 21:2; 以賽亞書 50:1; 馬太福音 18:25"> 若太陽已經出來，就為他有流血的罪。賊若被拿，總要賠還。若他一無所有，就要被賣，頂他所偷的物。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及記 22:7; 出埃及記 22:1; 出埃及記 22:9"> 若他所偷的，或牛，或驢，或羊，仍在他手下存活，他就要加倍賠還。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="出埃及記 22:3; 出埃及記 22:12; 約伯記 20:18"> 「人若在田間或在葡萄園裏放牲畜，任憑牲畜上別人的田裏去吃，就必拿自己田間上好的和葡萄園上好的賠還。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="出埃及記 22:9; 出埃及記 21:33–34; 撒母耳記下 14:30–31"> 「若點火焚燒荊棘，以致將別人堆積的禾捆，站着的禾稼，或是田園，都燒盡了，那點火的必要賠還。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="出埃及記 22:4; 箴言 6:30–31; 耶利米書 2:26"> 「人若將銀錢或家具交付鄰舍看守，這物從那人的家被偷去，若把賊找到了，賊要加倍賠還；</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及記 22:28; 申命記 16:18; 出埃及記 21:6"> 若找不到賊，那家主必就近審判官，要看看他拿了原主的物件沒有。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="申命記 25:1; 出埃及記 22:4; 民數記 5:6–7"> 「兩個人的案件，無論是為甚麼過犯，或是為牛，為驢，為羊，為衣裳，或是為甚麼失掉之物，有一人說：『這是我的』，兩造就要將案件稟告審判官，審判官定誰有罪，誰就要加倍賠還。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="路加福音 12:48; 提摩太後書 1:12; 路加福音 16:11"> 「人若將驢，或牛，或羊，或別的牲畜，交付鄰舍看守，牲畜或死，或受傷，或被趕去，無人看見，</span>
<span className="v" id="v11" data-v="11" data-xref="希伯來書 6:16; 利未記 5:1; 列王紀上 2:42–43"> 那看守的人要憑着耶和華起誓，手裏未曾拿鄰舍的物，本主就要罷休，看守的人不必賠還。</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 31:39; 出埃及記 22:7"> 牲畜若從看守的那裏被偷去，他就要賠還本主；</span>
<span className="v" id="v13" data-v="13" data-xref="那鴻書 2:12; 彌迦書 5:8; 以西結書 4:14"> 若被野獸撕碎，看守的要帶來當作證據，所撕的不必賠還。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="申命記 23:19–20; 出埃及記 21:34; 申命記 15:2"> 「人若向鄰舍借甚麼，所借的或受傷，或死，本主沒有同在一處，借的人總要賠還；</span>
<span className="v" id="v15" data-v="15" data-xref="撒迦利亞書 8:10"> 若本主同在一處，他就不必賠還；若是雇的，也不必賠還，本是為雇價來的。」</span>
</div>
</div>

## 道德上和宗教上的條例

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="申命記 22:28–29; 創世記 34:2–4"> 「人若引誘沒有受聘的處女，與她行淫，他總要交出聘禮，娶她為妻。</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 34:12; 撒母耳記上 18:25; 申命記 22:29"> 若女子的父親決不肯將女子給他，他就要按處女的聘禮，交出錢來。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="利未記 20:27; 申命記 18:10–11; 撒母耳記上 28:3"> 「行邪術的女人，不可容她存活。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="利未記 18:23; 申命記 27:21; 利未記 20:15–16"> 「凡與獸淫合的，總要把他治死。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="申命記 17:2–5; 民數記 25:7–8; 申命記 18:20"> 「祭祀別神，不單單祭祀耶和華的，那人必要滅絕。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="出埃及記 23:9; 申命記 10:19; 利未記 19:33"> 「不可虧負寄居的，也不可欺壓他，因為你們在埃及地也作過寄居的。</span>
<span className="v" id="v22" data-v="22" data-xref="申命記 24:17; 以賽亞書 1:17; 以賽亞書 1:23"> 不可苦待寡婦和孤兒；</span>
<span className="v" id="v23" data-v="23" data-xref="詩篇 18:6; 詩篇 10:17–18; 路加福音 18:7"> 若是苦待他們一點，他們向我一哀求，我總要聽他們的哀聲，</span>
<span className="v" id="v24" data-v="24" data-xref="詩篇 109:9; 耶利米書 15:8; 詩篇 76:7"> 並要發烈怒，用刀殺你們，使你們的妻子為寡婦，兒女為孤兒。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="詩篇 15:5; 利未記 25:35–37; 申命記 23:19–20"> 「我民中有貧窮人與你同住，你若借錢給他，不可如放債的向他取利。</span>
<span className="v" id="v26" data-v="26" data-xref="箴言 20:16; 阿摩司書 2:8; 申命記 24:6"> 你即或拿鄰舍的衣服作當頭，必在日落以先歸還他；</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及記 34:6; 歷代志下 30:9; 詩篇 136:10–11"> 因他只有這一件當蓋頭，是他蓋身的衣服，若是沒有，他拿甚麼睡覺呢？他哀求我，我就應允，因為我是有恩惠的。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="使徒行傳 23:5; 傳道書 10:20; 出埃及記 22:8–9"> 「不可毀謗上帝；也不可毀謗你百姓的官長。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="出埃及記 23:16; 出埃及記 13:2; 雅各書 1:18"> 「你要從你莊稼中的穀和酒醡中滴出來的酒拿來獻上，不可遲延。<br />「你要將頭生的兒子歸給我。</span>
<span className="v" id="v30" data-v="30" data-xref="利未記 22:27; 申命記 15:19; 出埃及記 13:12"> 你牛羊頭生的，也要這樣；七天當跟着母，第八天要歸給我。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="以西結書 4:14; 利未記 19:2; 申命記 14:21"> 「你們要在我面前為聖潔的人。因此，田間被野獸撕裂牲畜的肉，你們不可吃，要丟給狗吃。」</span>
</div>
</div>

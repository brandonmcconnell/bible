## 嗎哪和鵪鶉

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民數記 33:10–12; 出埃及記 15:27; 出埃及記 17:1"> 以色列全會眾從以琳起行，在出埃及後第二個月十五日到了以琳和西奈中間、汛的曠野。</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多前書 10:10; 出埃及記 15:24; 詩篇 106:25"> 以色列全會眾在曠野向摩西、亞倫發怨言，</span>
<span className="v" id="v3" data-v="3" data-xref="民數記 11:4–5; 民數記 20:3–5; 出埃及記 17:3"> 說：「巴不得我們早死在埃及地、耶和華的手下；那時我們坐在肉鍋旁邊，吃得飽足。你們將我們領出來，到這曠野，是要叫這全會眾都餓死啊！」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="哥林多前書 10:3; 詩篇 78:24–25; 申命記 8:2"> 耶和華對摩西說：「我要將糧食從天降給你們。百姓可以出去，每天收每天的分，我好試驗他們遵不遵我的法度。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 16:22–23; 出埃及記 35:2–3; 利未記 25:21–22"> 到第六天，他們要把所收進來的預備好了，比每天所收的多一倍。」</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及記 6:7; 民數記 16:28; 出埃及記 16:12–13"> 摩西、亞倫對以色列眾人說：「到了晚上，你們要知道是耶和華將你們從埃及地領出來的。</span>
<span className="v" id="v7" data-v="7" data-xref="以賽亞書 40:5; 民數記 16:11; 約翰福音 11:40"> 早晨，你們要看見耶和華的榮耀，因為耶和華聽見你們向他所發的怨言了。我們算甚麼，你們竟向我們發怨言呢？」</span>
<span className="v" id="v8" data-v="8" data-xref="羅馬書 13:2; 撒母耳記上 8:7; 帖撒羅尼迦前書 4:8"> 摩西又說：「耶和華晚上必給你們肉吃，早晨必給你們食物得飽；因為你們向耶和華發的怨言，他都聽見了。我們算甚麼，你們的怨言不是向我們發的，乃是向耶和華發的。」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="民數記 16:16; 出埃及記 16:2; 出埃及記 16:8"> 摩西對亞倫說：「你告訴以色列全會眾說：『你們就近耶和華面前，因為他已經聽見你們的怨言了。』」</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及記 16:7; 民數記 16:19; 民數記 16:42"> 亞倫正對以色列全會眾說話的時候，他們向曠野觀看，不料，耶和華的榮光在雲中顯現。</span>
<span className="v" id="v11" data-v="11"> 耶和華曉諭摩西說：</span>
<span className="v" id="v12" data-v="12" data-xref="約珥書 3:17; 以西結書 39:22; 出埃及記 6:7"> 「我已經聽見以色列人的怨言。你告訴他們說：『到黃昏的時候，你們要吃肉，早晨必有食物得飽，你們就知道我是耶和華－你們的上帝。』」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="民數記 11:9; 詩篇 105:40; 詩篇 78:27–28"> 到了晚上，有鵪鶉飛來，遮滿了營；早晨在營四圍的地上有露水。</span>
<span className="v" id="v14" data-v="14" data-xref="民數記 11:7–9; 詩篇 105:40; 詩篇 78:24"> 露水上升之後，不料，野地面上有如白霜的小圓物。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及記 16:4; 約翰福音 6:58; 出埃及記 16:31"> 以色列人看見，不知道是甚麼，就彼此對問說：「這是甚麼呢？」摩西對他們說：「這就是耶和華給你們吃的食物。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 16:36; 出埃及記 16:18; 出埃及記 16:32–33"> 耶和華所吩咐的是這樣：你們要按着各人的飯量，為帳棚裏的人，按着人數收起來，各拿一俄梅珥。」</span>
<span className="v" id="v17" data-v="17"> 以色列人就這樣行；有多收的，有少收的。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多後書 8:14–15"> 及至用俄梅珥量一量，多收的也沒有餘，少收的也沒有缺；各人按着自己的飯量收取。</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及記 12:10; 出埃及記 23:18; 馬太福音 6:34"> 摩西對他們說：「所收的，不許甚麼人留到早晨。」</span>
<span className="v" id="v20" data-v="20" data-xref="馬可福音 10:14; 民數記 16:15; 以弗所書 4:26"> 然而他們不聽摩西的話，內中有留到早晨的，就生蟲變臭了；摩西便向他們發怒。</span>
<span className="v" id="v21" data-v="21" data-xref="箴言 6:6–11; 傳道書 12:1; 哥林多後書 6:2"> 他們每日早晨，按着各人的飯量收取，日頭一發熱，就消化了。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="出埃及記 16:5; 利未記 25:22; 出埃及記 16:16"> 到第六天，他們收了雙倍的食物，每人兩俄梅珥。會眾的官長來告訴摩西；</span>
<span className="v" id="v23" data-v="23" data-xref="利未記 23:3; 出埃及記 31:15; 出埃及記 20:8–11"> 摩西對他們說：「耶和華這樣說：『明天是聖安息日，是向耶和華守的聖安息日。你們要烤的就烤了，要煮的就煮了，所剩下的都留到早晨。』」</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及記 16:20; 出埃及記 16:33"> 他們就照摩西的吩咐留到早晨，也不臭，裏頭也沒有蟲子。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及記 16:23; 出埃及記 16:29; 尼希米記 9:14"> 摩西說：「你們今天吃這個吧！因為今天是向耶和華守的安息日；你們在田野必找不着了。</span>
<span className="v" id="v26" data-v="26" data-xref="申命記 5:13; 出埃及記 20:9–11; 以西結書 46:1"> 六天可以收取，第七天乃是安息日，那一天必沒有了。」</span>
<span className="v" id="v27" data-v="27" data-xref="箴言 20:4"> 第七天，百姓中有人出去收，甚麼也找不着。</span>
<span className="v" id="v28" data-v="28" data-xref="詩篇 78:10; 詩篇 106:13; 民數記 14:11"> 耶和華對摩西說：「你們不肯守我的誡命和律法，要到幾時呢？</span>
<span className="v" id="v29" data-v="29" data-xref="出埃及記 31:13; 以賽亞書 58:13–14; 以西結書 20:12"> 你們看！耶和華既將安息日賜給你們，所以第六天他賜給你們兩天的食物，第七天各人要住在自己的地方，不許甚麼人出去。」</span>
<span className="v" id="v30" data-v="30" data-xref="申命記 5:12–14; 利未記 23:3; 希伯來書 4:9"> 於是百姓第七天安息了。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="雅歌 2:3; 民數記 11:6–9; 出埃及記 16:15"> 這食物，以色列家叫嗎哪；樣子像芫荽子，顏色是白的，滋味如同攙蜜的薄餅。</span>
<span className="v" id="v32" data-v="32" data-xref="詩篇 105:5; 路加福音 22:19; 詩篇 111:4–5"> 摩西說：「耶和華所吩咐的是這樣：『要將一滿俄梅珥嗎哪留到世世代代，使後人可以看見我當日將你們領出埃及地，在曠野所給你們吃的食物。』」</span>
<span className="v" id="v33" data-v="33" data-xref="希伯來書 9:4"> 摩西對亞倫說：「你拿一個罐子，盛一滿俄梅珥嗎哪，存在耶和華面前，要留到世世代代。」</span>
<span className="v" id="v34" data-v="34" data-xref="出埃及記 27:21; 出埃及記 25:21; 出埃及記 25:16"> 耶和華怎麼吩咐摩西，亞倫就怎麼行，把嗎哪放在法櫃前存留。</span>
<span className="v" id="v35" data-v="35" data-xref="尼希米記 9:20–21; 約書亞記 5:12; 申命記 8:2–3"> 以色列人吃嗎哪共四十年，直到進了有人居住之地，就是迦南的境界。（</span>
<span className="v" id="v36" data-v="36" data-xref="出埃及記 16:16; 出埃及記 16:32–33"> 俄梅珥就是伊法十分之一。）</span>
</div>
</div>

## －畜疫之災

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及記 8:1; 出埃及記 10:3; 出埃及記 8:20"> 耶和華吩咐摩西說：「你進去見法老，對他說：『耶和華－希伯來人的上帝這樣說：容我的百姓去，好事奉我。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 8:2; 出埃及記 4:23; 利未記 26:27–28"> 你若不肯容他們去，仍舊強留他們，</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 7:4; 使徒行傳 13:11; 撒母耳記上 6:9"> 耶和華的手加在你田間的牲畜上，就是在馬、驢、駱駝、牛群、羊群上，必有重重的瘟疫。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及記 8:22; 出埃及記 10:23; 瑪拉基書 3:18"> 耶和華要分別以色列的牲畜和埃及的牲畜，凡屬以色列人的，一樣都不死。』」</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 8:23; 出埃及記 10:4; 耶利米書 28:16–17"> 耶和華就定了時候，說：「明天耶和華必在此地行這事。」</span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 78:48; 出埃及記 9:25; 詩篇 78:50"> 第二天，耶和華就行這事。埃及的牲畜幾乎都死了，只是以色列人的牲畜，一個都沒有死。</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及記 7:14; 出埃及記 8:32; 以賽亞書 48:4"> 法老打發人去看，誰知以色列人的牲畜連一個都沒有死。法老的心卻是固執，不容百姓去。</span>
</div>
</div>

## －瘡災

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="出埃及記 8:16"> 耶和華吩咐摩西、亞倫說：「你們取幾捧爐灰，摩西要在法老面前向天揚起來。</span>
<span className="v" id="v9" data-v="9" data-xref="啟示錄 16:2; 申命記 28:27; 約伯記 2:7"> 這灰要在埃及全地變作塵土，在人身上和牲畜身上成了起泡的瘡。」</span>
<span className="v" id="v10" data-v="10" data-xref="申命記 28:27"> 摩西、亞倫取了爐灰，站在法老面前。摩西向天揚起來，就在人身上和牲畜身上成了起泡的瘡。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及記 7:11–12; 出埃及記 8:18–19; 啟示錄 16:2"> 行法術的在摩西面前站立不住，因為在他們身上和一切埃及人身上都有這瘡。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及記 4:21; 出埃及記 7:13–14; 詩篇 81:11–12"> 耶和華使法老的心剛硬，不聽他們，正如耶和華對摩西所說的。</span>
</div>
</div>

## －雹災

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="出埃及記 8:20; 出埃及記 7:15; 出埃及記 9:1"> 耶和華對摩西說：「你清早起來，站在法老面前，對他說：『耶和華－希伯來人的上帝這樣說：容我的百姓去，好事奉我。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及記 8:10; 利未記 26:28; 歷代志上 17:20"> 因為這一次我要叫一切的災殃臨到你和你臣僕並你百姓的身上，叫你知道在普天下沒有像我的。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及記 3:20; 出埃及記 9:3; 出埃及記 9:16"> 我若伸手用瘟疫攻擊你和你的百姓，你早就從地上除滅了。</span>
<span className="v" id="v16" data-v="16" data-xref="羅馬書 9:17; 箴言 16:4; 詩篇 83:17–18"> 其實，我叫你存立，是特要向你顯我的大能，並要使我的名傳遍天下。</span>
<span className="v" id="v17" data-v="17" data-xref="以賽亞書 37:29; 以賽亞書 10:15; 以賽亞書 37:23–24"> 你還向我的百姓自高，不容他們去嗎？</span>
<span className="v" id="v18" data-v="18" data-xref="列王紀上 20:6; 詩篇 83:15; 出埃及記 9:22–25"> 到明天約在這時候，我必叫重大的冰雹降下，自從埃及開國以來，沒有這樣的冰雹。</span>
<span className="v" id="v19" data-v="19" data-xref="哈巴谷書 3:2"> 現在你要打發人把你的牲畜和你田間一切所有的催進來；凡在田間不收回家的，無論是人是牲畜，冰雹必降在他們身上，他們就必死。』」</span>
<span className="v" id="v20" data-v="20" data-xref="箴言 13:13; 箴言 22:3; 希伯來書 11:7"> 法老的臣僕中，懼怕耶和華這話的，便叫他的奴僕和牲畜跑進家來。</span>
<span className="v" id="v21" data-v="21" data-xref="以西結書 40:4; 約伯記 34:14; 歷代志上 22:19"> 但那不把耶和華這話放在心上的，就將他的奴僕和牲畜留在田裏。</span>
<span className="v" id="v22" data-v="22" data-xref="啟示錄 16:21; 出埃及記 7:19; 出埃及記 8:5"> 耶和華對摩西說：「你向天伸杖，使埃及遍地的人身上和牲畜身上，並田間各樣菜蔬上，都有冰雹。」</span>
<span className="v" id="v23" data-v="23" data-xref="詩篇 18:13; 約書亞記 10:11; 以賽亞書 30:30"> 摩西向天伸杖，耶和華就打雷下雹，有火閃到地上；耶和華下雹在埃及地上。</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及記 9:23; 馬太福音 24:21; 出埃及記 10:6"> 那時，雹與火攙雜，甚是厲害，自從埃及成國以來，遍地沒有這樣的。</span>
<span className="v" id="v25" data-v="25" data-xref="詩篇 78:47; 詩篇 105:32–33"> 在埃及遍地，雹擊打了田間所有的人和牲畜，並一切的菜蔬，又打壞田間一切的樹木。</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及記 11:7; 出埃及記 9:4; 出埃及記 10:23"> 惟獨以色列人所住的歌珊地沒有冰雹。</span>
<span className="v" id="v27" data-v="27" data-xref="耶利米哀歌 1:18; 詩篇 129:4; 出埃及記 10:16"> 法老打發人召摩西、亞倫來，對他們說：「這一次我犯了罪了。耶和華是公義的；我和我的百姓是邪惡的。</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及記 8:8; 出埃及記 10:17; 出埃及記 8:28"> 這雷轟和冰雹已經夠了。請你們求耶和華，我就容你們去，不再留住你們。」</span>
<span className="v" id="v29" data-v="29" data-xref="哥林多前書 10:26; 列王紀上 8:38; 以賽亞書 1:15"> 摩西對他說：「我一出城，就要向耶和華舉手禱告；雷必止住，也不再有冰雹，叫你知道全地都是屬耶和華的。</span>
<span className="v" id="v30" data-v="30" data-xref="以賽亞書 26:10; 箴言 16:6; 以賽亞書 63:17"> 至於你和你的臣僕，我知道你們還是不懼怕耶和華上帝。」（</span>
<span className="v" id="v31" data-v="31" data-xref="路得記 1:22; 路得記 2:23; 哈巴谷書 3:17"> 那時，麻和大麥被雹擊打；因為大麥已經吐穗，麻也開了花。</span>
<span className="v" id="v32" data-v="32" data-xref="出埃及記 10:22"> 只是小麥和粗麥沒有被擊打，因為還沒有長成。）</span>
<span className="v" id="v33" data-v="33" data-xref="出埃及記 9:29; 出埃及記 8:12; 雅各書 5:17–18"> 摩西離了法老出城，向耶和華舉手禱告；雷和雹就止住，雨也不再澆在地上了。</span>
<span className="v" id="v34" data-v="34" data-xref="出埃及記 7:14; 歷代志下 36:13; 出埃及記 4:21"> 法老見雨和雹與雷止住，就越發犯罪；他和他的臣僕都硬着心。</span>
<span className="v" id="v35" data-v="35" data-xref="出埃及記 4:21"> 法老的心剛硬，不容以色列人去，正如耶和華藉着摩西所說的。</span>
</div>
</div>

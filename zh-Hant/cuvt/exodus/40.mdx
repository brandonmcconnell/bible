## 耶和華會幕的建立和奉獻

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華曉諭摩西說：</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 26:30; 出埃及記 13:4; 民數記 7:1"> 「正月初一日，你要立起帳幕，</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 35:12; 民數記 4:5; 啟示錄 11:19"> 把法櫃安放在裏面，用幔子將櫃遮掩。</span>
<span className="v" id="v4" data-v="4" data-xref="利未記 24:8; 出埃及記 40:22–25; 出埃及記 37:10–24"> 把桌子搬進去，擺設上面的物。把燈臺搬進去，點其上的燈。</span>
<span className="v" id="v5" data-v="5" data-xref="希伯來書 10:19–22; 希伯來書 9:24; 約翰一書 2:1–2"> 把燒香的金壇安在法櫃前，掛上帳幕的門簾。</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及記 40:29; 約翰一書 4:9–10; 希伯來書 13:10"> 把燔祭壇安在帳幕門前。</span>
<span className="v" id="v7" data-v="7" data-xref="撒迦利亞書 13:1; 約翰一書 1:7; 詩篇 26:6"> 把洗濯盆安在會幕和壇的中間，在盆裏盛水。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及記 40:33; 以弗所書 4:11–12; 馬太福音 16:18"> 又在四圍立院帷，把院子的門簾掛上。</span>
<span className="v" id="v9" data-v="9" data-xref="利未記 8:10; 民數記 7:1; 馬太福音 3:16"> 用膏油把帳幕和其中所有的都抹上，使帳幕和一切器具成聖，就都成聖。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及記 29:36–37; 路加福音 1:35; 以賽亞書 61:1"> 又要抹燔祭壇和一切器具，使壇成聖，就都成為至聖。</span>
<span className="v" id="v11" data-v="11"> 要抹洗濯盆和盆座，使盆成聖。</span>
<span className="v" id="v12" data-v="12" data-xref="利未記 8:1–13; 利未記 9:1–24; 出埃及記 29:1–35"> 要使亞倫和他兒子到會幕門口來，用水洗身。</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及記 28:41; 約翰一書 2:20; 約翰一書 2:27"> 要給亞倫穿上聖衣，又膏他，使他成聖，可以給我供祭司的職分；</span>
<span className="v" id="v14" data-v="14" data-xref="以賽亞書 61:10; 羅馬書 8:30; 哥林多前書 1:30"> 又要使他兒子來，給他們穿上內袍。</span>
<span className="v" id="v15" data-v="15" data-xref="民數記 25:13; 希伯來書 5:1–14; 希伯來書 8:1–10"> 怎樣膏他們的父親，也要照樣膏他們，使他們給我供祭司的職分。他們世世代代凡受膏的，就永遠當祭司的職任。」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="申命記 4:1; 出埃及記 40:17–32; 申命記 12:32"> 摩西這樣行，都是照耶和華所吩咐他的。</span>
<span className="v" id="v17" data-v="17" data-xref="民數記 7:1; 出埃及記 40:1–2; 民數記 9:1"> 第二年正月初一日，帳幕就立起來。</span>
<span className="v" id="v18" data-v="18" data-xref="以西結書 37:27–28; 彼得前書 1:5; 利未記 26:11"> 摩西立起帳幕，安上帶卯的座，立上板，穿上閂，立起柱子。</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及記 26:1–14; 出埃及記 36:8–19"> 在帳幕以上搭罩棚，把罩棚的頂蓋蓋在其上，是照耶和華所吩咐他的。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及記 16:34; 申命記 10:5; 希伯來書 10:19–21"> 又把法版放在櫃裏，把槓穿在櫃的兩旁，把施恩座安在櫃上。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及記 26:33; 出埃及記 40:3; 出埃及記 35:12"> 把櫃抬進帳幕，掛上遮掩櫃的幔子，把法櫃遮掩了，是照耶和華所吩咐他的。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及記 26:35; 約翰福音 6:53–57; 以弗所書 3:8"> 又把桌子安在會幕內，在帳幕北邊，在幔子外。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及記 25:30; 出埃及記 40:4; 希伯來書 9:2"> 在桌子上將餅陳設在耶和華面前，是照耶和華所吩咐他的。</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及記 26:35; 啟示錄 2:5; 約翰福音 1:1"> 又把燈臺安在會幕內，在帳幕南邊，與桌子相對，</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及記 40:4; 出埃及記 25:37; 啟示錄 4:5"> 在耶和華面前點燈，是照耶和華所吩咐他的。</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及記 40:5; 希伯來書 7:25; 約翰福音 11:42"> 把金壇安在會幕內的幔子前，</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及記 30:7"> 在壇上燒了馨香料做的香，是照耶和華所吩咐他的。</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及記 40:5; 希伯來書 10:19–20; 以弗所書 2:18"> 又掛上帳幕的門簾。</span>
<span className="v" id="v29" data-v="29" data-xref="出埃及記 40:6; 希伯來書 13:5–6; 希伯來書 13:10"> 在會幕的帳幕門前，安設燔祭壇，把燔祭和素祭獻在其上，是照耶和華所吩咐他的。</span>
<span className="v" id="v30" data-v="30" data-xref="出埃及記 40:7; 出埃及記 38:8; 以西結書 36:25"> 把洗濯盆安在會幕和壇的中間，盆中盛水，以便洗濯。</span>
<span className="v" id="v31" data-v="31" data-xref="出埃及記 30:19–20; 詩篇 26:6; 約翰福音 13:10"> 摩西和亞倫並亞倫的兒子在這盆裏洗手洗腳。</span>
<span className="v" id="v32" data-v="32" data-xref="詩篇 73:19; 出埃及記 30:19–20; 出埃及記 40:19"> 他們進會幕或就近壇的時候，便都洗濯，是照耶和華所吩咐他的。</span>
<span className="v" id="v33" data-v="33" data-xref="出埃及記 40:8; 出埃及記 27:9–16; 約翰福音 17:4"> 在帳幕和壇的四圍立了院帷，把院子的門簾掛上。這樣，摩西就完了工。</span>
</div>
</div>

## 雲彩覆蓋會幕

<div className="bt">
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="啟示錄 15:8; 民數記 9:15–23; 歷代志下 7:2"> 當時，雲彩遮蓋會幕，耶和華的榮光就充滿了帳幕。</span>
<span className="v" id="v35" data-v="35" data-xref="列王紀上 8:11; 利未記 16:2; 歷代志下 7:2"> 摩西不能進會幕；因為雲彩停在其上，並且耶和華的榮光充滿了帳幕。</span>
<span className="v" id="v36" data-v="36" data-xref="尼希米記 9:19; 民數記 9:17; 出埃及記 13:21–22"> 每逢雲彩從帳幕收上去，以色列人就起程前往；</span>
<span className="v" id="v37" data-v="37" data-xref="民數記 9:19–22; 詩篇 31:15"> 雲彩若不收上去，他們就不起程，直等到雲彩收上去。</span>
<span className="v" id="v38" data-v="38" data-xref="詩篇 78:14; 民數記 9:15; 出埃及記 13:21"> 日間，耶和華的雲彩是在帳幕以上；夜間，雲中有火，在以色列全家的眼前。在他們所行的路上都是這樣。</span>
</div>

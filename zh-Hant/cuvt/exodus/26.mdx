## 會幕

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及記 36:8–19; 出埃及記 26:36; 出埃及記 26:31"> 「你要用十幅幔子做帳幕。這些幔子要用撚的細麻和藍色、紫色、朱紅色線製造，並用巧匠的手工繡上基路伯。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳記下 7:2; 民數記 4:25; 歷代志上 17:1"> 每幅幔子要長二十八肘，寬四肘，幔子都要一樣的尺寸。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 36:10; 歌羅西書 2:2; 以弗所書 2:21–22"> 這五幅幔子要幅幅相連；那五幅幔子也要幅幅相連。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及記 36:11–12; 出埃及記 36:17; 出埃及記 26:10–11"> 在這相連的幔子末幅邊上要做藍色的鈕扣；在那相連的幔子末幅邊上也要照樣做。</span>
<span className="v" id="v5" data-v="5"> 要在這相連的幔子上做五十個鈕扣；在那相連的幔子上也做五十個鈕扣，都要兩兩相對。</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及記 36:13; 出埃及記 26:11; 出埃及記 26:33"> 又要做五十個金鉤，用鉤使幔子相連，這才成了一個帳幕。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="出埃及記 26:14; 詩篇 45:13; 出埃及記 26:9"> 「你要用山羊毛織十一幅幔子，作為帳幕以上的罩棚。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及記 26:13; 出埃及記 26:2"> 每幅幔子要長三十肘，寬四肘；十一幅幔子都要一樣的尺寸。</span>
<span className="v" id="v9" data-v="9"> 要把五幅幔子連成一幅，又把六幅幔子連成一幅，這第六幅幔子要在罩棚的前面摺上去。</span>
<span className="v" id="v10" data-v="10"> 在這相連的幔子末幅邊上要做五十個鈕扣；在那相連的幔子末幅邊上也做五十個鈕扣。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及記 26:3; 出埃及記 26:6"> 又要做五十個銅鉤，鉤在鈕扣中，使罩棚連成一個。</span>
<span className="v" id="v12" data-v="12"> 罩棚的幔子所餘那垂下來的半幅幔子，要垂在帳幕的後頭。</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及記 26:2; 出埃及記 26:8"> 罩棚的幔子所餘長的，這邊一肘，那邊一肘，要垂在帳幕的兩旁，遮蓋帳幕。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及記 36:19; 出埃及記 25:5; 出埃及記 35:23"> 又要用染紅的公羊皮做罩棚的蓋；再用海狗皮做一層罩棚上的頂蓋。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="出埃及記 36:20–33; 民數記 4:31–32; 出埃及記 40:17–18"> 「你要用皂莢木做帳幕的豎板。</span>
<span className="v" id="v16" data-v="16"> 每塊要長十肘，寬一肘半；</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及記 36:22; 出埃及記 26:19; 出埃及記 36:24"> 每塊必有兩榫相對。帳幕一切的板都要這樣做。</span>
<span className="v" id="v18" data-v="18"> 帳幕的南面要做板二十塊。</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及記 38:27; 出埃及記 38:30–31; 出埃及記 26:37"> 在這二十塊板底下要做四十個帶卯的銀座，兩卯接這塊板上的兩榫，兩卯接那塊板上的兩榫。</span>
<span className="v" id="v20" data-v="20"> 帳幕第二面，就是北面，也要做板二十塊</span>
<span className="v" id="v21" data-v="21"> 和帶卯的銀座四十個；這板底下有兩卯，那板底下也有兩卯。</span>
<span className="v" id="v22" data-v="22"> 帳幕的後面，就是西面，要做板六塊。</span>
<span className="v" id="v23" data-v="23"> 帳幕後面的拐角要做板兩塊。</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及記 36:29–30; 詩篇 133:1–3; 哥林多前書 1:10"> 板的下半截要雙的，上半截要整的，直頂到第一個環子；兩塊都要這樣做兩個拐角。</span>
<span className="v" id="v25" data-v="25"> 必有八塊板和十六個帶卯的銀座；這板底下有兩卯，那板底下也有兩卯。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="羅馬書 15:1; 民數記 4:31; 加拉太書 6:1–2"> 「你要用皂莢木做閂：為帳幕這面的板做五閂，</span>
<span className="v" id="v27" data-v="27"> 為帳幕那面的板做五閂，又為帳幕後面的板做五閂。</span>
<span className="v" id="v28" data-v="28"> 板腰間的中閂要從這一頭通到那一頭。</span>
<span className="v" id="v29" data-v="29" data-xref="出埃及記 25:11–12"> 板要用金子包裹，又要做板上的金環套閂；閂也要用金子包裹。</span>
<span className="v" id="v30" data-v="30" data-xref="出埃及記 25:40; 希伯來書 8:5; 出埃及記 25:9"> 要照着在山上指示你的樣式立起帳幕。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="馬太福音 27:51; 歷代志下 3:14; 出埃及記 36:35"> 「你要用藍色、紫色、朱紅色線，和撚的細麻織幔子，以巧匠的手工繡上基路伯。</span>
<span className="v" id="v32" data-v="32" data-xref="出埃及記 26:37; 出埃及記 36:38; 以斯帖記 1:6"> 要把幔子掛在四根包金的皂莢木柱子上，柱子上當有金鉤，柱子安在四個帶卯的銀座上。</span>
<span className="v" id="v33" data-v="33" data-xref="希伯來書 9:2–3; 利未記 16:2; 出埃及記 40:21"> 要使幔子垂在鉤子下，把法櫃抬進幔子內；這幔子要將聖所和至聖所隔開。</span>
<span className="v" id="v34" data-v="34" data-xref="出埃及記 40:20; 出埃及記 25:21; 希伯來書 9:5"> 又要把施恩座安在至聖所內的法櫃上，</span>
<span className="v" id="v35" data-v="35" data-xref="出埃及記 40:24; 出埃及記 40:22; 希伯來書 9:2"> 把桌子安在幔子外帳幕的北面；把燈臺安在帳幕的南面，彼此相對。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="出埃及記 36:37; 民數記 9:15; 出埃及記 26:31"> 「你要拿藍色、紫色、朱紅色線，和撚的細麻，用繡花的手工織帳幕的門簾。</span>
<span className="v" id="v37" data-v="37" data-xref="出埃及記 36:38"> 要用皂莢木為簾子做五根柱子，用金子包裹。柱子上當有金鉤；又要為柱子用銅鑄造五個帶卯的座。」</span>
</div>
</div>

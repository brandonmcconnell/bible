## 摩西和亞倫見埃及王

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及記 10:9; 使徒行傳 4:29; 馬太福音 10:28"> 後來摩西、亞倫去對法老說：「耶和華－以色列的上帝這樣說：『容我的百姓去，在曠野向我守節。』」</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 3:19; 約伯記 21:15; 列王紀下 18:35"> 法老說：「耶和華是誰，使我聽他的話，容以色列人去呢？我不認識耶和華，也不容以色列人去！」</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 3:18; 撒迦利亞書 14:16–19; 以西結書 6:11"> 他們說：「希伯來人的上帝遇見了我們。求你容我們往曠野去，走三天的路程，祭祀耶和華－我們的上帝，免得他用瘟疫、刀兵攻擊我們。」</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及記 1:11; 使徒行傳 24:5; 阿摩司書 7:10"> 埃及王對他們說：「摩西、亞倫！你們為甚麼叫百姓曠工呢？你們去擔你們的擔子吧！」</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 1:7–11; 箴言 14:28"> 又說：「看哪，這地的以色列人如今眾多，你們竟叫他們歇下擔子！」</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及記 5:10; 出埃及記 5:19; 申命記 16:18"> 當天，法老吩咐督工的和官長說：</span>
<span className="v" id="v7" data-v="7" data-xref="士師記 19:19; 創世記 24:25"> 「你們不可照常把草給百姓做磚，叫他們自己去撿草。</span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 106:41"> 他們素常做磚的數目，你們仍舊向他們要，一點不可減少；因為他們是懶惰的，所以呼求說：『容我們去祭祀我們的上帝。』</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀下 18:20; 耶利米書 43:2; 約伯記 16:3"> 你們要把更重的工夫加在這些人身上，叫他們勞碌，不聽虛謊的言語。」</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及記 1:11; 出埃及記 3:7; 箴言 29:12"> 督工的和官長出來對百姓說：「法老這樣說：『我不給你們草。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及記 5:13–14"> 你們自己在哪裏能找草，就往那裏去找吧！但你們的工一點不可減少。』」</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及記 15:7; 以賽亞書 5:24; 以賽亞書 47:14"> 於是百姓散在埃及遍地，撿碎稭當作草。</span>
<span className="v" id="v13" data-v="13"> 督工的催着說：「你們一天當完一天的工，與先前有草一樣。」</span>
<span className="v" id="v14" data-v="14" data-xref="以賽亞書 10:24"> 法老督工的，責打他所派以色列人的官長，說：「你們昨天今天為甚麼沒有照向來的數目做磚、完你們的工作呢？」</span>
<span className="v" id="v15" data-v="15"> 以色列人的官長就來哀求法老說：「為甚麼這樣待你的僕人？</span>
<span className="v" id="v16" data-v="16"> 督工的不把草給僕人，並且對我們說：『做磚吧！』看哪，你僕人挨了打，其實是你百姓的錯。」</span>
<span className="v" id="v17" data-v="17" data-xref="馬太福音 26:8; 約翰福音 6:27; 出埃及記 5:8"> 但法老說：「你們是懶惰的！你們是懶惰的！所以說：『容我們去祭祀耶和華。』</span>
<span className="v" id="v18" data-v="18" data-xref="以西結書 18:18; 但以理書 2:9–13"> 現在你們去做工吧！草是不給你們的，磚卻要如數交納。」</span>
<span className="v" id="v19" data-v="19" data-xref="傳道書 5:8; 傳道書 4:1; 申命記 32:36"> 以色列人的官長聽說「你們每天做磚的工作一點不可減少」，就知道是遭遇禍患了。</span>
<span className="v" id="v20" data-v="20"> 他們離了法老出來，正遇見摩西、亞倫站在對面，</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 34:30; 撒母耳記上 13:4; 歷代志上 19:6"> 就向他們說：「願耶和華鑒察你們，施行判斷；因你們使我們在法老和他臣僕面前有了臭名，把刀遞在他們手中殺我們。」</span>
</div>
</div>

## 摩西向耶和華訴苦

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="耶利米書 20:7; 列王紀上 19:10; 民數記 11:14–15"> 摩西回到耶和華那裏，說：「主啊，你為甚麼苦待這百姓呢？為甚麼打發我去呢？</span>
<span className="v" id="v23" data-v="23" data-xref="耶利米書 11:21; 希伯來書 10:36–37; 以賽亞書 28:16"> 自從我去見法老，奉你的名說話，他就苦待這百姓，你一點也沒有拯救他們。」</span>
</div>

## 奉獻聖所

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華曉諭摩西說：</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多後書 9:7; 尼希米記 11:2; 以斯拉記 2:68"> 「你告訴以色列人當為我送禮物來；凡甘心樂意的，你們就可以收下歸我。</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 8:9; 約伯記 28:2"> 所要收的禮物：就是金、銀、銅，</span>
<span className="v" id="v4" data-v="4" data-xref="啟示錄 19:8; 創世記 41:42; 以西結書 16:10"> 藍色、紫色、朱紅色線，細麻，山羊毛，</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 26:37–1; 出埃及記 26:14–15; 出埃及記 36:20"> 染紅的公羊皮，海狗皮，皂莢木，</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及記 27:20; 出埃及記 25:37; 出埃及記 40:24–25"> 點燈的油並做膏油和香的香料，</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及記 28:4; 出埃及記 28:6–30"> 紅瑪瑙與別樣的寶石，可以鑲嵌在以弗得和胸牌上。</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多後書 6:16; 列王紀上 6:13; 啟示錄 21:3"> 又當為我造聖所，使我可以住在他們中間。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及記 25:40; 希伯來書 8:5; 使徒行傳 7:44"> 製造帳幕和其中的一切器具都要照我所指示你的樣式。」</span>
</div>
</div>

## 約櫃

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="希伯來書 9:4; 出埃及記 37:1–3; 申命記 10:1–3"> 「要用皂莢木做一櫃，長二肘半，寬一肘半，高一肘半。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及記 25:24; 出埃及記 30:3; 歷代志下 3:4"> 要裏外包上精金，四圍鑲上金牙邊。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及記 27:7; 出埃及記 25:26; 出埃及記 25:15"> 也要鑄四個金環，安在櫃的四腳上；這邊兩環，那邊兩環。</span>
<span className="v" id="v13" data-v="13" data-xref="歷代志上 15:15; 民數記 4:11; 出埃及記 27:6"> 要用皂莢木做兩根槓，用金包裹。</span>
<span className="v" id="v14" data-v="14"> 要把槓穿在櫃旁的環內，以便抬櫃。</span>
<span className="v" id="v15" data-v="15" data-xref="列王紀上 8:8; 歷代志下 5:9"> 這槓要常在櫃的環內，不可抽出來。</span>
<span className="v" id="v16" data-v="16" data-xref="申命記 31:26; 列王紀上 8:9; 希伯來書 9:4"> 必將我所要賜給你的法版放在櫃裏。</span>
<span className="v" id="v17" data-v="17" data-xref="希伯來書 9:5; 出埃及記 37:6; 希伯來書 4:16"> 要用精金做施恩座<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="施恩：或譯蔽罪；下同">a</a></sup>，長二肘半，寬一肘半。</span>
<span className="v" id="v18" data-v="18" data-xref="以西結書 10:20; 希伯來書 9:5; 列王紀上 8:6–7"> 要用金子錘出兩個基路伯來，安在施恩座的兩頭。</span>
<span className="v" id="v19" data-v="19"> 這頭做一個基路伯，那頭做一個基路伯，二基路伯要接連一塊，在施恩座的兩頭。</span>
<span className="v" id="v20" data-v="20" data-xref="歷代志上 28:18; 列王紀上 8:7; 希伯來書 9:5"> 二基路伯要高張翅膀，遮掩施恩座。基路伯要臉對臉，朝着施恩座。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及記 26:34; 羅馬書 10:4; 出埃及記 25:16–17"> 要將施恩座安在櫃的上邊，又將我所要賜給你的法版放在櫃裏。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及記 29:42–43; 民數記 7:89; 以賽亞書 37:16"> 我要在那裏與你相會，又要從法櫃施恩座上二基路伯中間，和你說我所要吩咐你傳給以色列人的一切事。」</span>
</div>
</div>

## 陳設餅的桌子

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="希伯來書 9:2; 出埃及記 37:10–16; 列王紀上 7:48"> 「要用皂莢木做一張桌子，長二肘，寬一肘，高一肘半。</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及記 25:11; 列王紀上 6:20–22"> 要包上精金，四圍鑲上金牙邊。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及記 37:2; 出埃及記 30:3"> 桌子的四圍各做一掌寬的橫樑，橫樑上鑲着金牙邊。</span>
<span className="v" id="v26" data-v="26"> 要做四個金環，安在桌子的四角上，就是桌子四腳上的四角。</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及記 25:14; 出埃及記 25:28"> 安環子的地方要挨近橫樑，可以穿槓抬桌子。</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及記 25:14; 使徒行傳 9:15; 民數記 10:17"> 要用皂莢木做兩根槓，用金包裹，以便抬桌子。</span>
<span className="v" id="v29" data-v="29" data-xref="民數記 4:7; 出埃及記 37:16; 啟示錄 3:20"> 要做桌子上的盤子、調羹，並奠酒的爵和瓶；這都要用精金製作。</span>
<span className="v" id="v30" data-v="30" data-xref="利未記 24:5–9; 馬太福音 12:4; 出埃及記 39:36"> 又要在桌子上，在我面前，常擺陳設餅。」</span>
</div>
</div>

## 燈臺

<div className="bt">
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="列王紀上 7:49; 撒迦利亞書 4:2; 出埃及記 37:17–24"> 「要用精金做一個燈臺。燈臺的座和幹與杯、球、花，都要接連一塊錘出來。</span>
<span className="v" id="v32" data-v="32"> 燈臺兩旁要杈出六個枝子：這旁三個，那旁三個。</span>
<span className="v" id="v33" data-v="33" data-xref="民數記 17:4–8; 耶利米書 1:11–12; 撒迦利亞書 4:3"> 這旁每枝上有三個杯，形狀像杏花，有球，有花；那旁每枝上也有三個杯，形狀像杏花，有球，有花。從燈臺杈出來的六個枝子都是如此。</span>
<span className="v" id="v34" data-v="34"> 燈臺上有四個杯，形狀像杏花，有球，有花。</span>
<span className="v" id="v35" data-v="35"> 燈臺每兩個枝子以下有球與枝子接連一塊。燈臺出的六個枝子都是如此。</span>
<span className="v" id="v36" data-v="36" data-xref="出埃及記 25:18; 列王紀上 10:16–17; 歷代志下 9:15"> 球和枝子要接連一塊，都是一塊精金錘出來的。</span>
<span className="v" id="v37" data-v="37" data-xref="民數記 8:2; 啟示錄 1:20–1; 利未記 24:2–4"> 要做燈臺的七個燈盞。祭司要點這燈，使燈光對照。</span>
<span className="v" id="v38" data-v="38" data-xref="列王紀下 12:13; 耶利米書 52:18; 列王紀下 25:14"> 燈臺的蠟剪和蠟花盤也是要精金的。</span>
<span className="v" id="v39" data-v="39"> 做燈臺和這一切的器具要用精金一他連得。</span>
<span className="v" id="v40" data-v="40" data-xref="希伯來書 8:5; 出埃及記 26:30; 使徒行傳 7:44"> 要謹慎做這些物件，都要照着在山上指示你的樣式。」</span>
</div>
</div>

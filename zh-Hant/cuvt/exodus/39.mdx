## 為祭司製聖服

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及記 31:10; 出埃及記 35:23; 出埃及記 35:19"> 比撒列用藍色、紫色、朱紅色線做精緻的衣服，在聖所用以供職，又為亞倫做聖衣，是照耶和華所吩咐摩西的。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 28:6–12; 利未記 8:7; 出埃及記 25:7"> 他用金線和藍色、紫色、朱紅色線，並撚的細麻做以弗得；</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 36:8; 出埃及記 26:1"> 把金子錘成薄片，剪出線來，與藍色、紫色、朱紅色線，用巧匠的手工一同繡上。</span>
<span className="v" id="v4" data-v="4"> 又為以弗得做兩條相連的肩帶，接連在以弗得的兩頭。</span>
<span className="v" id="v5" data-v="5" data-xref="啟示錄 1:13; 馬太福音 28:20; 以賽亞書 11:5"> 其上巧工織的帶子和以弗得一樣的做法，用以束上，與以弗得接連一塊，是用金線和藍色、紫色、朱紅色線，並撚的細麻做的，是照耶和華所吩咐摩西的。</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及記 28:9; 以西結書 28:13; 約伯記 28:16"> 又琢出兩塊紅瑪瑙，鑲在金槽上，彷彿刻圖書，按着以色列兒子的名字雕刻；</span>
<span className="v" id="v7" data-v="7" data-xref="約書亞記 4:7; 出埃及記 28:12; 出埃及記 28:29"> 將這兩塊寶石安在以弗得的兩條肩帶上，為以色列人做紀念石，是照耶和華所吩咐摩西的。</span>
</div>
</div>

## 製胸牌

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="出埃及記 28:4; 利未記 8:8–9; 以賽亞書 59:17"> 他用巧匠的手工做胸牌，和以弗得一樣的做法，用金線與藍色、紫色、朱紅色線，並撚的細麻做的。</span>
<span className="v" id="v9" data-v="9"> 胸牌是四方的，疊為兩層；這兩層長一虎口，寬一虎口，</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及記 28:21; 出埃及記 28:16–17; 啟示錄 21:19–21"> 上面鑲着寶石四行：第一行是紅寶石、紅璧璽、紅玉；</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及記 28:18; 以西結書 28:13"> 第二行是綠寶石、藍寶石、金鋼石；</span>
<span className="v" id="v12" data-v="12"> 第三行是紫瑪瑙、白瑪瑙、紫晶；</span>
<span className="v" id="v13" data-v="13"> 第四行是水蒼玉、紅瑪瑙、碧玉。這都鑲在金槽中。</span>
<span className="v" id="v14" data-v="14" data-xref="啟示錄 21:12"> 這些寶石都是按着以色列十二個兒子的名字，彷彿刻圖書，刻十二個支派的名字。</span>
<span className="v" id="v15" data-v="15" data-xref="約翰福音 10:28; 約翰福音 17:12; 彼得前書 1:5"> 在胸牌上，用精金擰成如繩子的鍊子。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 25:12"> 又做兩個金槽和兩個金環，安在胸牌的兩頭。</span>
<span className="v" id="v17" data-v="17"> 把那兩條擰成的金鍊子穿過胸牌兩頭的環子，</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及記 28:14; 雅歌 1:10"> 又把鍊子的那兩頭接在兩槽上，安在以弗得前面肩帶上。</span>
<span className="v" id="v19" data-v="19"> 做兩個金環，安在胸牌的兩頭，在以弗得裏面的邊上，</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及記 26:3"> 又做兩個金環，安在以弗得前面兩條肩帶的下邊，挨近相接之處，在以弗得巧工織的帶子以上。</span>
<span className="v" id="v21" data-v="21" data-xref="馬太福音 16:24; 哥林多前書 1:25; 哥林多前書 1:27"> 用一條藍細帶子把胸牌的環子和以弗得的環子繫住，使胸牌貼在以弗得巧工織的帶子上，不可與以弗得離縫，是照耶和華所吩咐摩西的。</span>
</div>
</div>

## 祭司其他的聖服

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="出埃及記 28:31–35"> 他用織工做以弗得的外袍，顏色全是藍的。</span>
<span className="v" id="v23" data-v="23"> 袍上留一領口，口的周圍織出領邊來，彷彿鎧甲的領口，免得破裂。</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及記 28:33; 加拉太書 5:22"> 在袍子底邊上，用藍色、紫色、朱紅色線，並撚的細麻做石榴，</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及記 28:33–34; 雅歌 4:13; 詩篇 89:15"> 又用精金做鈴鐺，把鈴鐺釘在袍子周圍底邊上的石榴中間：</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及記 28:34; 雅歌 4:13; 雅歌 6:7"> 一個鈴鐺一個石榴，一個鈴鐺一個石榴，在袍子周圍底邊上用以供職，是照耶和華所吩咐摩西的。</span>
<span className="v" id="v27" data-v="27" data-xref="以西結書 44:18; 彼得前書 1:13; 以賽亞書 61:10"> 他用織成的細麻布為亞倫和他的兒子做內袍，</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及記 28:4; 以西結書 44:18; 出埃及記 28:39"> 並用細麻布做冠冕和華美的裹頭巾，用撚的細麻布做褲子，</span>
<span className="v" id="v29" data-v="29" data-xref="出埃及記 28:39"> 又用藍色、紫色、朱紅色線，並撚的細麻，以繡花的手工做腰帶，是照耶和華所吩咐摩西的。</span>
<span className="v" id="v30" data-v="30" data-xref="啟示錄 5:10; 希伯來書 7:26; 希伯來書 1:3"> 他用精金做聖冠上的牌，在上面按刻圖書之法，刻着「歸耶和華為聖」。</span>
<span className="v" id="v31" data-v="31"> 又用一條藍細帶子將牌繫在冠冕上，是照耶和華所吩咐摩西的。</span>
</div>
</div>

## 會幕完工

<div className="bt">
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="出埃及記 39:42–43; 馬太福音 28:20; 出埃及記 25:40"> 帳幕，就是會幕，一切的工就這樣做完了。凡耶和華所吩咐摩西的，以色列人都照樣做了。</span>
<span className="v" id="v33" data-v="33" data-xref="出埃及記 35:11–19; 出埃及記 31:7–11; 出埃及記 36:1–38"> 他們送到摩西那裏。帳幕和帳幕的一切器具，就是鉤子、板、閂、柱子、帶卯的座，</span>
<span className="v" id="v34" data-v="34"> 染紅公羊皮的蓋、海狗皮的頂蓋，和遮掩櫃的幔子，</span>
<span className="v" id="v35" data-v="35" data-xref="希伯來書 9:5; 出埃及記 25:17; 希伯來書 9:8"> 法櫃和櫃的槓並施恩座，</span>
<span className="v" id="v36" data-v="36" data-xref="出埃及記 25:30; 列王紀上 7:48"> 桌子和桌子的一切器具並陳設餅，</span>
<span className="v" id="v37" data-v="37" data-xref="腓立比書 2:15; 出埃及記 27:21; 馬太福音 5:14–16"> 精金的燈臺和擺列的燈盞，與燈臺的一切器具，並點燈的油，</span>
<span className="v" id="v38" data-v="38" data-xref="出埃及記 30:7; 出埃及記 37:29; 出埃及記 30:3"> 金壇、膏油、馨香的香料、會幕的門簾，</span>
<span className="v" id="v39" data-v="39" data-xref="列王紀上 8:64; 出埃及記 38:30"> 銅壇和壇上的銅網，壇的槓並壇的一切器具，洗濯盆和盆座，</span>
<span className="v" id="v40" data-v="40" data-xref="出埃及記 27:9–16"> 院子的帷子和柱子，並帶卯的座，院子的門簾、繩子、橛子，並帳幕和會幕中一切使用的器具，</span>
<span className="v" id="v41" data-v="41" data-xref="出埃及記 28:2; 出埃及記 31:10; 出埃及記 39:1"> 精工做的禮服，和祭司亞倫並他兒子在聖所用以供祭司職分的聖衣。</span>
<span className="v" id="v42" data-v="42" data-xref="出埃及記 35:10; 出埃及記 23:21–22; 提摩太後書 2:15"> 這一切工作都是以色列人照耶和華所吩咐摩西做的。</span>
<span className="v" id="v43" data-v="43" data-xref="民數記 6:23–27; 利未記 9:22–23; 撒母耳記下 6:18"> 耶和華怎樣吩咐的，他們就怎樣做了。摩西看見一切的工都做成了，就給他們祝福。</span>
</div>
</div>

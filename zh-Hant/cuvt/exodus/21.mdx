## 對待奴僕的條例

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命記 4:14; 申命記 6:20; 出埃及記 24:3–4"> 「你在百姓面前所要立的典章是這樣：</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 15:12–15; 出埃及記 12:44; 申命記 15:18"> 你若買希伯來人作奴僕，他必服事你六年；第七年他可以自由，白白地出去。</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 15:12–14"> 他若孤身來就可以孤身去；他若有妻，他的妻就可以同他出去。</span>
<span className="v" id="v4" data-v="4"> 他主人若給他妻子，妻子給他生了兒子或女兒，妻子和兒女要歸主人，他要獨自出去。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多後書 5:14–15; 申命記 15:16–17; 以賽亞書 26:13"> 倘或奴僕明說：『我愛我的主人和我的妻子兒女，不願意自由出去。』</span>
<span className="v" id="v6" data-v="6" data-xref="申命記 15:17; 利未記 25:40; 申命記 19:17–18"> 他的主人就要帶他到審判官<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或譯：上帝；下同">a</a></sup>那裏，又要帶他到門前，靠近門框，用錐子穿他的耳朵，他就永遠服事主人。</span>
<span className="v" id="v7" data-v="7" data-xref="尼希米記 5:5; 出埃及記 21:2–3"> 「人若賣女兒作婢女，婢女不可像男僕那樣出去。</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 28:8; 申命記 20:7; 瑪拉基書 2:11–15"> 主人選定她歸自己，若不喜歡她，就要許她贖身；主人既然用詭詐待她，就沒有權柄賣給外邦人。</span>
<span className="v" id="v9" data-v="9"> 主人若選定她給自己的兒子，就當待她如同女兒。</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多前書 7:1–6"> 若另娶一個，那女子的吃食、衣服，並好合的事，仍不可減少。</span>
<span className="v" id="v11" data-v="11"> 若不向她行這三樣，她就可以不用錢贖，白白地出去。」</span>
</div>
</div>

## 懲罰暴行的條例

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="創世記 9:6; 馬太福音 26:52; 利未記 24:17"> 「打人以致打死的，必要把他治死。</span>
<span className="v" id="v13" data-v="13" data-xref="約書亞記 20:2–9; 撒母耳記上 24:18; 申命記 4:41–43"> 人若不是埋伏着殺人，乃是上帝交在他手中，我就設下一個地方，他可以往那裏逃跑。</span>
<span className="v" id="v14" data-v="14" data-xref="列王紀上 2:28–34; 希伯來書 10:26; 民數記 15:30–31"> 人若任意用詭計殺了他的鄰舍，就是逃到我的壇那裏，也當捉去把他治死。</span>
<span className="v" id="v15" data-v="15" data-xref="申命記 21:18–21; 箴言 30:17; 提摩太前書 1:9"> 「打父母的，必要把他治死。</span>
<span className="v" id="v16" data-v="16" data-xref="申命記 24:7; 提摩太前書 1:10; 出埃及記 22:4"> 「拐帶人口，或是把人賣了，或是留在他手下，必要把他治死。</span>
<span className="v" id="v17" data-v="17" data-xref="箴言 20:20; 馬可福音 7:10–11; 申命記 27:16"> 「咒罵父母的，必要把他治死。</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及記 21:20; 申命記 25:11; 撒母耳記下 14:6"> 「人若彼此相爭，這個用石頭或是拳頭打那個，尚且不至於死，不過躺臥在床，</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳記下 3:29; 撒迦利亞書 8:4"> 若再能起來扶杖而出，那打他的可算無罪；但要將他耽誤的工夫用錢賠補，並要將他全然醫好。</span>
<span className="v" id="v20" data-v="20" data-xref="箴言 29:19; 申命記 19:21; 民數記 35:19"> 「人若用棍子打奴僕或婢女，立時死在他的手下，他必要受刑。</span>
<span className="v" id="v21" data-v="21" data-xref="利未記 25:44–46"> 若過一兩天才死，就可以不受刑，因為是用錢買的。</span>
<span className="v" id="v22" data-v="22" data-xref="申命記 22:18–19; 出埃及記 21:30; 申命記 16:18"> 「人若彼此爭鬥，傷害有孕的婦人，甚至墜胎，隨後卻無別害，那傷害她的，總要按婦人的丈夫所要的，照審判官所斷的，受罰。</span>
<span className="v" id="v23" data-v="23" data-xref="申命記 19:21; 民數記 35:31; 利未記 24:19"> 若有別害，就要以命償命，</span>
<span className="v" id="v24" data-v="24" data-xref="申命記 19:21; 馬太福音 5:38–40; 馬太福音 7:2"> 以眼還眼，以牙還牙，以手還手，以腳還腳，</span>
<span className="v" id="v25" data-v="25"> 以烙還烙，以傷還傷，以打還打。</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及記 21:20; 約伯記 31:13–15; 詩篇 72:12–14"> 「人若打壞了他奴僕或是婢女的一隻眼，就要因他的眼放他去得以自由。</span>
<span className="v" id="v27" data-v="27"> 若打掉了他奴僕或是婢女的一個牙，就要因他的牙放他去得以自由。」</span>
</div>
</div>

## 物主的責任

<div className="bt">
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="出埃及記 21:32; 利未記 20:15–16; 創世記 9:5–6"> 「牛若觸死男人或是女人，總要用石頭打死那牛，卻不可吃牠的肉；牛的主人可算無罪。</span>
<span className="v" id="v29" data-v="29" data-xref="申命記 21:1–9"> 倘若那牛素來是觸人的，有人報告了牛主，他竟不把牛拴着，以致把男人或是女人觸死，就要用石頭打死那牛，牛主也必治死。</span>
<span className="v" id="v30" data-v="30" data-xref="出埃及記 21:22; 出埃及記 30:12; 民數記 35:31–33"> 若罰他贖命的價銀，他必照所罰的贖他的命。</span>
<span className="v" id="v31" data-v="31"> 牛無論觸了人的兒子或是女兒，必照這例辦理。</span>
<span className="v" id="v32" data-v="32" data-xref="馬太福音 26:15; 撒迦利亞書 11:12–13; 馬太福音 27:3–9"> 牛若觸了奴僕或是婢女，必將銀子三十舍客勒給他們的主人，也要用石頭把牛打死。</span>
<span className="v" id="v33" data-v="33" data-xref="箴言 28:10; 耶利米書 18:20; 傳道書 10:8"> 「人若敞着井口，或挖井不遮蓋，有牛或驢掉在裏頭，</span>
<span className="v" id="v34" data-v="34" data-xref="出埃及記 22:6; 出埃及記 21:29–30; 出埃及記 22:14"> 井主要拿錢賠還本主人，死牲畜要歸自己。</span>
<span className="v" id="v35" data-v="35"> 「這人的牛若傷了那人的牛，以至於死，他們要賣了活牛，平分價值，也要平分死牛。</span>
<span className="v" id="v36" data-v="36"> 人若知道這牛素來是觸人的，主人竟不把牛拴着，他必要以牛還牛，死牛要歸自己。」</span>
</div>

## 正義和公道

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="詩篇 101:5; 箴言 19:5; 申命記 19:16–21"> 「不可隨夥佈散謠言；不可與惡人連手妄作見證。</span>
<span className="v" id="v2" data-v="2" data-xref="箴言 1:10–11; 箴言 1:15; 路加福音 23:23–24"> 不可隨眾行惡；不可在爭訟的事上隨眾偏行，作見證屈枉正直；</span>
<span className="v" id="v3" data-v="3" data-xref="雅各書 3:17; 利未記 19:15; 詩篇 82:2–3"> 也不可在爭訟的事上偏護窮人。</span>
<span className="v" id="v4" data-v="4" data-xref="申命記 22:1–4; 帖撒羅尼迦前書 5:15; 馬太福音 5:44"> 「若遇見你仇敵的牛或驢失迷了路，總要牽回來交給他。</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 22:4"> 若看見恨你人的驢壓臥在重馱之下，不可走開，務要和驢主一同抬開重馱。</span>
<span className="v" id="v6" data-v="6" data-xref="瑪拉基書 3:5; 耶利米書 5:28; 利未記 19:15"> 「不可在窮人爭訟的事上屈枉正直。</span>
<span className="v" id="v7" data-v="7" data-xref="以弗所書 4:25; 出埃及記 34:7; 出埃及記 23:1"> 當遠離虛假的事。不可殺無辜和有義的人，因我必不以惡人為義。</span>
<span className="v" id="v8" data-v="8" data-xref="申命記 16:19; 箴言 17:23; 以賽亞書 5:23"> 不可受賄賂；因為賄賂能叫明眼人變瞎了，又能顛倒義人的話。</span>
<span className="v" id="v9" data-v="9" data-xref="申命記 27:19; 出埃及記 22:21; 申命記 24:14–18"> 「不可欺壓寄居的；因為你們在埃及地作過寄居的，知道寄居的心。」</span>
</div>
</div>

## 安息年和安息日

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="利未記 25:3–4"> 「六年你要耕種田地，收藏土產，</span>
<span className="v" id="v11" data-v="11" data-xref="利未記 26:34–35; 利未記 25:2–7; 利未記 25:11–12"> 只是第七年要叫地歇息，不耕不種，使你民中的窮人有吃的；他們所剩下的，野獸可以吃。你的葡萄園和橄欖園也要照樣辦理。</span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 13:14; 出埃及記 34:21; 出埃及記 35:3"> 「六日你要做工，第七日要安息，使牛、驢可以歇息，並使你婢女的兒子和寄居的都可以舒暢。</span>
<span className="v" id="v13" data-v="13" data-xref="約書亞記 23:7; 撒迦利亞書 13:2; 提摩太前書 4:16"> 「凡我對你們說的話，你們要謹守。別神的名，你不可提，也不可從你口中傳說。」</span>
</div>
</div>

## 三大節期

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="申命記 16:16; 出埃及記 34:22–24; 利未記 23:34"> 「一年三次，你要向我守節。</span>
<span className="v" id="v15" data-v="15" data-xref="路加福音 22:7; 出埃及記 34:20; 民數記 28:16–25"> 你要守除酵節，照我所吩咐你的，在亞筆月內所定的日期，吃無酵餅七天。誰也不可空手朝見我，因為你是這月出了埃及。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 34:22; 出埃及記 22:29; 利未記 23:9–21"> 又要守收割節，所收的是你田間所種、勞碌得來初熟之物。並在年底收藏，要守收藏節。</span>
<span className="v" id="v17" data-v="17" data-xref="申命記 16:16; 出埃及記 34:23; 出埃及記 23:14"> 一切的男丁要一年三次朝見主耶和華。</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及記 34:25; 利未記 2:11; 申命記 16:4"> 「不可將我祭牲的血和有酵的餅一同獻上；也不可將我節上祭牲的脂油留到早晨。</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及記 34:26; 申命記 14:21; 申命記 26:10"> 「地裏首先初熟之物要送到耶和華－你上帝的殿。 「不可用山羊羔母的奶煮山羊羔。」</span>
</div>
</div>

## 應許和指示

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="出埃及記 33:14; 詩篇 91:11; 出埃及記 32:34"> 「看哪，我差遣使者在你前面，在路上保護你，領你到我所預備的地方去。</span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 78:56; 詩篇 78:40; 希伯來書 12:25"> 他是奉我名來的；你們要在他面前謹慎，聽從他的話，不可惹<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或譯：違背">a</a></sup>他，因為他必不赦免你們的過犯。</span>
<span className="v" id="v22" data-v="22" data-xref="創世記 12:3; 申命記 30:7; 撒迦利亞書 2:8"> 「你若實在聽從他的話，照着我一切所說的去行，我就向你的仇敵作仇敵，向你的敵人作敵人。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及記 23:20; 以賽亞書 5:13; 創世記 15:19–21"> 「我的使者要在你前面行，領你到亞摩利人、赫人、比利洗人、迦南人、希未人、耶布斯人那裏去，我必將他們剪除。</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及記 20:5; 申命記 12:30–31; 民數記 33:52"> 你不可跪拜他們的神，不可事奉他，也不可效法他們的行為，卻要把神像盡行拆毀，打碎他們的柱像。</span>
<span className="v" id="v25" data-v="25" data-xref="申命記 7:15; 出埃及記 15:26; 約書亞記 22:5"> 你們要事奉耶和華－你們的上帝，他必賜福與你的糧與你的水，也必從你們中間除去疾病。</span>
<span className="v" id="v26" data-v="26" data-xref="申命記 7:14; 約伯記 5:26; 申命記 28:4"> 你境內必沒有墜胎的，不生產的。我要使你滿了你年日的數目。</span>
<span className="v" id="v27" data-v="27" data-xref="申命記 2:25; 創世記 35:5; 申命記 11:25"> 凡你所到的地方，我要使那裏的眾民在你面前驚駭，擾亂，又要使你一切仇敵轉背逃跑。</span>
<span className="v" id="v28" data-v="28" data-xref="申命記 7:20; 約書亞記 24:11–12"> 我要打發黃蜂飛在你前面，把希未人、迦南人、赫人攆出去。</span>
<span className="v" id="v29" data-v="29" data-xref="申命記 7:22; 約書亞記 17:12–13; 士師記 3:1–4"> 我不在一年之內將他們從你面前攆出去，恐怕地成為荒涼，野地的獸多起來害你。</span>
<span className="v" id="v30" data-v="30"> 我要漸漸地將他們從你面前攆出去，等到你的人數加多，承受那地為業。</span>
<span className="v" id="v31" data-v="31" data-xref="創世記 15:18; 申命記 11:24; 約書亞記 21:44"> 我要定你的境界，從紅海直到非利士海，又從曠野直到大河。我要將那地的居民交在你手中，你要將他們從你面前攆出去。</span>
<span className="v" id="v32" data-v="32" data-xref="申命記 7:2; 出埃及記 34:12; 出埃及記 34:15"> 不可和他們並他們的神立約。</span>
<span className="v" id="v33" data-v="33" data-xref="詩篇 106:36; 申命記 7:16; 出埃及記 34:12"> 他們不可住在你的地上，恐怕他們使你得罪我。你若事奉他們的神，這必成為你的網羅。」</span>
</div>

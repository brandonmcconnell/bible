## 百姓奉獻禮物

<div className="bt">
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="歌羅西書 4:17; 希伯來書 5:4; 出埃及記 31:6"> 凡耶和華賜他心裏有智慧、而且受感前來做這工的，摩西把他們和比撒列並亞何利亞伯一同召來。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 35:29; 出埃及記 35:27; 出埃及記 35:5–21"> 這些人就從摩西收了以色列人為做聖所並聖所使用之工所拿來的禮物。百姓每早晨還把甘心獻的禮物拿來。</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多前書 3:10; 路加福音 12:42; 馬太福音 24:45"> 凡做聖所一切工的智慧人各都離開他所做的工，</span>
<span className="v" id="v5" data-v="5" data-xref="歷代志下 31:6–10; 哥林多後書 8:2–3; 歷代志下 24:14"> 來對摩西說：「百姓為耶和華吩咐使用之工所拿來的，富富有餘。」</span>
<span className="v" id="v6" data-v="6"> 摩西傳命，他們就在全營中宣告說：「無論男女，不必再為聖所拿甚麼禮物來。」這樣才攔住百姓不再拿禮物來。</span>
<span className="v" id="v7" data-v="7" data-xref="歷代志下 31:10"> 因為他們所有的材料夠做一切當做的物，而且有餘。</span>
</div>
</div>

## 造耶和華的會幕

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="列王紀上 6:23; 出埃及記 26:1–37; 以西結書 1:5–28"> 他們中間，凡心裏有智慧做工的，用十幅幔子做帳幕。這幔子是比撒列用撚的細麻和藍色、紫色、朱紅色線製造的，並用巧匠的手工繡上基路伯。</span>
<span className="v" id="v9" data-v="9"> 每幅幔子長二十八肘，寬四肘，都是一樣的尺寸。</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多前書 12:27; 出埃及記 26:3; 詩篇 122:3"> 他使這五幅幔子幅幅相連，又使那五幅幔子幅幅相連；</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及記 26:4"> 在這相連的幔子末幅邊上做藍色的鈕扣，在那相連的幔子末幅邊上也照樣做；</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及記 26:5; 出埃及記 26:10"> 在這相連的幔子上做五十個鈕扣，在那相連的幔子上也做五十個鈕扣，都是兩兩相對；</span>
<span className="v" id="v13" data-v="13" data-xref="彼得前書 2:4–5; 以弗所書 2:20–22; 哥林多前書 12:20"> 又做五十個金鉤，使幔子相連。這才成了一個帳幕。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及記 26:7–13"> 他用山羊毛織十一幅幔子，作為帳幕以上的罩棚。</span>
<span className="v" id="v15" data-v="15"> 每幅幔子長三十肘，寬四肘；十一幅幔子都是一樣的尺寸。</span>
<span className="v" id="v16" data-v="16"> 他把五幅幔子連成一幅，又把六幅幔子連成一幅；</span>
<span className="v" id="v17" data-v="17"> 在這相連的幔子末幅邊上做五十個鈕扣，在那相連的幔子末幅邊上也做五十個鈕扣；</span>
<span className="v" id="v18" data-v="18"> 又做五十個銅鉤，使罩棚連成一個；</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及記 26:14"> 並用染紅的公羊皮做罩棚的蓋，再用海狗皮做一層罩棚上的頂蓋。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及記 25:5; 民數記 25:1; 出埃及記 40:18–19"> 他用皂莢木做帳幕的豎板。</span>
<span className="v" id="v21" data-v="21"> 每塊長十肘，寬一肘半；</span>
<span className="v" id="v22" data-v="22"> 每塊有兩榫相對。帳幕一切的板都是這樣做。</span>
<span className="v" id="v23" data-v="23"> 帳幕的南面做板二十塊。</span>
<span className="v" id="v24" data-v="24"> 在這二十塊板底下又做四十個帶卯的銀座：兩卯接這塊板上的兩榫，兩卯接那塊板上的兩榫。</span>
<span className="v" id="v25" data-v="25"> 帳幕的第二面，就是北面，也做板二十塊</span>
<span className="v" id="v26" data-v="26"> 和帶卯的銀座四十個：這板底下有兩卯，那板底下也有兩卯。</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及記 26:22; 出埃及記 26:27"> 帳幕的後面，就是西面，做板六塊。</span>
<span className="v" id="v28" data-v="28"> 帳幕後面的拐角做板兩塊。</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行傳 4:32; 以弗所書 3:18–19; 哥林多前書 1:10"> 板的下半截是雙的，上半截是整的，直到第一個環子；在帳幕的兩個拐角上都是這樣做。</span>
<span className="v" id="v30" data-v="30" data-xref="出埃及記 26:25"> 有八塊板和十六個帶卯的銀座，每塊板底下有兩卯。</span>
<span className="v" id="v31" data-v="31" data-xref="出埃及記 26:26–29; 出埃及記 25:28; 出埃及記 30:5"> 他用皂莢木做閂：為帳幕這面的板做五閂，</span>
<span className="v" id="v32" data-v="32" data-xref="出埃及記 26:26"> 為帳幕那面的板做五閂，又為帳幕後面的板做五閂，</span>
<span className="v" id="v33" data-v="33"> 使板腰間的中閂從這一頭通到那一頭。</span>
<span className="v" id="v34" data-v="34"> 用金子將板包裹，又做板上的金環套閂；閂也用金子包裹。</span>
<span className="v" id="v35" data-v="35" data-xref="馬太福音 27:51; 希伯來書 10:20; 出埃及記 40:21"> 他用藍色、紫色、朱紅色線，和撚的細麻織幔子，以巧匠的手工繡上基路伯。</span>
<span className="v" id="v36" data-v="36" data-xref="耶利米書 1:18"> 為幔子做四根皂莢木柱子，用金包裹，柱子上有金鉤，又為柱子鑄了四個帶卯的銀座。</span>
<span className="v" id="v37" data-v="37" data-xref="出埃及記 26:36–37; 出埃及記 40:28"> 拿藍色、紫色、朱紅色線，和撚的細麻，用繡花的手工織帳幕的門簾；</span>
<span className="v" id="v38" data-v="38" data-xref="出埃及記 27:10"> 又為簾子做五根柱子和柱子上的鉤子，用金子把柱頂和柱子上的杆子包裹。柱子有五個帶卯的座，是銅的。</span>
</div>

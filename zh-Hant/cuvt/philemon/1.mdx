## 腓利門的愛心和信心

<div className="bt">
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="羅馬書 1:8; 以弗所書 1:16; 帖撒羅尼迦後書 1:3"> 我禱告的時候提到你，常為你感謝我的上帝；</span>
<span className="v" id="v5" data-v="5" data-xref="歌羅西書 1:4; 以弗所書 1:15; 哥林多前書 16:1"> 因聽說你的愛心並你向主耶穌和眾聖徒的信心<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或譯：因聽說你向主耶穌和眾聖徒有愛心有信心">a</a></sup>。</span>
<span className="v" id="v6" data-v="6" data-xref="腓立比書 1:9–11; 彼得後書 1:8; 歌羅西書 1:9"> 願你與人所同有的信心顯出功效，使人知道你們各樣善事都是為基督做的。</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多後書 7:13; 帖撒羅尼迦前書 3:9; 哥林多後書 7:4"> 兄弟啊，我為你的愛心，大有快樂，大得安慰，因眾聖徒的心從你得了暢快。</span>
</div>
</div>

## 保羅為阿尼西謀請求

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="帖撒羅尼迦前書 2:6; 哥林多後書 10:8; 哥林多後書 3:12"> 我雖然靠着基督能放膽吩咐你合宜的事，</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多後書 5:20; 以弗所書 4:1; 羅馬書 12:1"> 然而像我這有年紀的保羅，現在又是為基督耶穌被囚的，寧可憑着愛心求你，</span>
<span className="v" id="v10" data-v="10" data-xref="歌羅西書 4:9; 哥林多前書 4:15; 提摩太前書 1:2"> 就是為我在捆鎖中所生的兒子阿尼西謀<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="就是有益處的意思">b</a></sup>求你。</span>
<span className="v" id="v11" data-v="11" data-xref="提摩太後書 4:11; 約伯記 30:1–2; 彼得前書 2:10"> 他從前與你沒有益處，但如今與你我都有益處。</span>
<span className="v" id="v12" data-v="12" data-xref="馬太福音 6:14–15; 耶利米書 31:20; 馬可福音 11:25"> 我現在打發他親自回你那裏去；他是我心上的人。</span>
<span className="v" id="v13" data-v="13" data-xref="腓立比書 1:7; 以弗所書 3:1; 哥林多前書 16:17"> 我本來有意將他留下，在我為福音所受的捆鎖中替你伺候我。</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多後書 9:7; 歷代志上 29:17; 彼得前書 5:2–3"> 但不知道你的意思，我就不願意這樣行，叫你的善行不是出於勉強，乃是出於甘心。</span>
<span className="v" id="v15" data-v="15" data-xref="創世記 50:20; 創世記 45:5–8; 以賽亞書 20:6"> 他暫時離開你，或者是叫你永遠得着他，</span>
<span className="v" id="v16" data-v="16" data-xref="歌羅西書 3:22; 馬太福音 23:8; 哥林多前書 7:22"> 不再是奴僕，乃是高過奴僕，是親愛的兄弟。在我實在是如此，何況在你呢！這也不拘是按肉體說，是按主說。</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多後書 8:23; 馬太福音 10:40; 腓利門書 1:12"> 你若以我為同伴，就收納他，如同收納我一樣。</span>
<span className="v" id="v18" data-v="18" data-xref="以賽亞書 53:4–7"> 他若虧負你，或欠你甚麼，都歸在我的帳上；</span>
<span className="v" id="v19" data-v="19" data-xref="加拉太書 6:11; 加拉太書 5:2; 哥林多前書 4:15"> 我必償還，這是我－保羅親筆寫的。我並不用對你說，連你自己也是虧欠於我。</span>
<span className="v" id="v20" data-v="20" data-xref="約翰三書 1:4; 腓利門書 1:7; 腓利門書 1:12"> 兄弟啊，望你使我在主裏因你得快樂<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="或譯：益處">c</a></sup>，並望你使我的心在基督裏得暢快。</span>
<span className="v" id="v21" data-v="21" data-xref="帖撒羅尼迦後書 3:4; 哥林多後書 2:3; 哥林多後書 7:16"> 我寫信給你，深信你必順服，知道你所要行的必過於我所說的。</span>
<span className="v" id="v22" data-v="22" data-xref="哥林多後書 1:11; 腓立比書 2:24; 約翰二書 1:12"> 此外你還要給我預備住處；因為我盼望藉着你們的禱告，必蒙恩到你們那裏去。</span>
</div>
</div>

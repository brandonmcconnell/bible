## 終止與異族通婚的措施

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="但以理書 9:20; 詩篇 119:136; 羅馬書 9:2"> 以斯拉禱告，認罪，哭泣，俯伏在上帝殿前的時候，有以色列中的男女孩童聚集到以斯拉那裏，成了大會，眾民無不痛哭。</span>
<span className="v" id="v2" data-v="2" data-xref="尼希米記 13:27; 以斯拉記 9:2; 耶利米書 3:12–13"> 屬以攔的子孫、耶歇的兒子示迦尼對以斯拉說：「我們在此地娶了外邦女子為妻，干犯了我們的上帝，然而以色列人還有指望。</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 7:2–3; 以斯拉記 9:4; 約書亞記 23:12–13"> 現在當與我們的上帝立約，休這一切的妻，離絕她們所生的，照着我主和那因上帝命令戰兢之人所議定的，按律法而行。</span>
<span className="v" id="v4" data-v="4" data-xref="歷代志上 28:10; 傳道書 9:10; 希伯來書 12:12–13"> 你起來，這是你當辦的事，我們必幫助你，你當奮勉而行。」</span>
<span className="v" id="v5" data-v="5" data-xref="尼希米記 13:25; 尼希米記 5:12; 箴言 9:9"> 以斯拉便起來，使祭司長和利未人，並以色列眾人起誓說，必照這話去行；他們就起了誓。</span>
<span className="v" id="v6" data-v="6" data-xref="申命記 9:18; 尼希米記 3:1; 尼希米記 12:22"> 以斯拉從上帝殿前起來，進入以利亞實的兒子約哈難的屋裏，到了那裏不吃飯，也不喝水；因為被擄歸回之人所犯的罪，心裏悲傷。</span>
<span className="v" id="v7" data-v="7" data-xref="以斯拉記 1:1; 歷代志下 30:5"> 他們通告猶大和耶路撒冷被擄歸回的人，叫他們在耶路撒冷聚集。</span>
<span className="v" id="v8" data-v="8" data-xref="以斯拉記 7:26; 約翰福音 9:22; 士師記 21:5"> 凡不遵首領和長老所議定、三日之內不來的，就必抄他的家，使他離開被擄歸回之人的會。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳記上 12:17–18; 耶利米書 10:13; 以斯拉記 7:8–9"> 於是，猶大和便雅憫眾人，三日之內都聚集在耶路撒冷。那日正是九月二十日，眾人都坐在上帝殿前的寬闊處；因這事，又因下大雨，就都戰兢。</span>
<span className="v" id="v10" data-v="10" data-xref="以斯拉記 9:6; 民數記 32:14; 馬太福音 23:32"> 祭司以斯拉站起來，對他們說：「你們有罪了；因你們娶了外邦的女子為妻，增添以色列人的罪惡。</span>
<span className="v" id="v11" data-v="11" data-xref="羅馬書 12:2; 以斯拉記 10:3; 以賽亞書 1:16–18"> 現在當向耶和華－你們列祖的上帝認罪，遵行他的旨意，離絕這些國的民和外邦的女子。」</span>
<span className="v" id="v12" data-v="12" data-xref="尼希米記 13:23; 詩篇 78:57; 以斯拉記 10:3–4"> 會眾都大聲回答說：「我們必照着你的話行，</span>
<span className="v" id="v13" data-v="13" data-xref="以斯拉記 10:18–44; 馬太福音 7:13–14"> 只是百姓眾多，又逢大雨的時令，我們不能站在外頭，這也不是一兩天辦完的事，因我們在這事上犯了大罪；</span>
<span className="v" id="v14" data-v="14" data-xref="歷代志下 29:10; 歷代志下 30:8; 民數記 25:4"> 不如為全會眾派首領辦理。凡我們城邑中娶外邦女子為妻的，當按所定的日期，同着本城的長老和士師而來，直到辦完這事，上帝的烈怒就轉離我們了。」</span>
<span className="v" id="v15" data-v="15" data-xref="尼希米記 11:16; 尼希米記 10:20; 尼希米記 12:33"> 惟有亞撒黑的兒子約拿單，特瓦的兒子雅哈謝阻擋<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或譯：總辦">a</a></sup>這事，並有米書蘭和利未人沙比太幫助他們。</span>
<span className="v" id="v16" data-v="16" data-xref="約伯記 29:16; 申命記 13:14; 約翰福音 7:51"> 被擄歸回的人如此而行。祭司以斯拉和些族長按着宗族都指名見派；在十月初一日，一同在座查辦這事，</span>
<span className="v" id="v17" data-v="17"> 到正月初一日，才查清娶外邦女子的人數。</span>
</div>
</div>

## 娶外邦女子的人

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="以斯拉記 5:2; 以斯拉記 3:2; 撒迦利亞書 3:1"> 在祭司中查出娶外邦女子為妻的，就是耶書亞的子孫約薩達的兒子，和他弟兄瑪西雅、以利以謝、雅立、基大利；</span>
<span className="v" id="v19" data-v="19" data-xref="利未記 6:6; 列王紀下 10:15; 歷代志下 30:8"> 他們便應許必休他們的妻。他們因有罪，就獻群中的一隻公綿羊贖罪。</span>
<span className="v" id="v20" data-v="20" data-xref="以斯拉記 2:37; 歷代志上 24:14; 尼希米記 7:40"> 音麥的子孫中，有哈拿尼、西巴第雅。</span>
<span className="v" id="v21" data-v="21" data-xref="歷代志上 24:8; 以斯拉記 2:39; 尼希米記 7:42"> 哈琳的子孫中，有瑪西雅、以利雅、示瑪雅、耶歇、烏西雅。</span>
<span className="v" id="v22" data-v="22" data-xref="歷代志上 9:12; 尼希米記 7:41; 以斯拉記 2:38"> 巴施戶珥的子孫中，有以利約乃、瑪西雅、以實瑪利、拿坦業、約撒拔、以利亞撒。</span>
<span className="v" id="v23" data-v="23" data-xref="尼希米記 10:10; 尼希米記 11:16; 以斯拉記 8:33"> 利未人中，有約撒拔、示每、基拉雅（基拉雅就是基利他），還有毗他希雅、猶大、以利以謝。</span>
<span className="v" id="v24" data-v="24"> 歌唱的人中有以利亞實。守門的人中，有沙龍、提聯、烏利。</span>
<span className="v" id="v25" data-v="25" data-xref="以斯拉記 2:3; 尼希米記 7:8"> 以色列人巴錄的子孫中，有拉米、耶西雅、瑪基雅、米雅民、以利亞撒、瑪基雅、比拿雅。</span>
<span className="v" id="v26" data-v="26" data-xref="以斯拉記 10:2; 以斯拉記 2:31; 尼希米記 7:12"> 以攔的子孫中，有瑪他尼、撒迦利亞、耶歇、押底、耶利末、以利雅。</span>
<span className="v" id="v27" data-v="27" data-xref="尼希米記 7:13; 以斯拉記 2:8"> 薩土的子孫中，有以利約乃、以利亞實、瑪他尼、耶利末、撒拔、亞西撒。</span>
<span className="v" id="v28" data-v="28" data-xref="以斯拉記 8:11; 以斯拉記 2:11; 尼希米記 7:16"> 比拜的子孫中，有約哈難、哈拿尼雅、薩拜、亞勒。</span>
<span className="v" id="v29" data-v="29" data-xref="尼希米記 7:15; 尼希米記 10:4; 以斯拉記 2:10"> 巴尼的子孫中，有米書蘭、瑪鹿、亞大雅、雅述、示押、耶利末。</span>
<span className="v" id="v30" data-v="30" data-xref="以斯拉記 8:4; 尼希米記 7:11; 以斯拉記 2:6"> 巴哈‧摩押的子孫中，有阿底拿、基拉、比拿雅、瑪西雅、瑪他尼、比撒列、賓內、瑪拿西。</span>
<span className="v" id="v31" data-v="31" data-xref="尼希米記 3:11; 尼希米記 7:35; 以斯拉記 2:32"> 哈琳的子孫中，有以利以謝、伊示雅、瑪基雅、示瑪雅、西緬、</span>
<span className="v" id="v32" data-v="32"> 便雅憫、瑪鹿、示瑪利雅。</span>
<span className="v" id="v33" data-v="33" data-xref="以斯拉記 2:19; 尼希米記 7:22"> 哈順的子孫中，有瑪特乃、瑪達他、撒拔、以利法列、耶利買、瑪拿西、示每。</span>
<span className="v" id="v34" data-v="34"> 巴尼的子孫中，有瑪玳、暗蘭、烏益、</span>
<span className="v" id="v35" data-v="35"> 比拿雅、比底雅、基祿、</span>
<span className="v" id="v36" data-v="36"> 瓦尼雅、米利末、以利亞實、</span>
<span className="v" id="v37" data-v="37"> 瑪他尼、瑪特乃、雅掃、</span>
<span className="v" id="v38" data-v="38"> 巴尼、賓內、示每、</span>
<span className="v" id="v39" data-v="39"> 示利米雅、拿單、亞大雅、</span>
<span className="v" id="v40" data-v="40"> 瑪拿底拜、沙賽、沙賴、</span>
<span className="v" id="v41" data-v="41"> 亞薩利、示利米雅、示瑪利雅、</span>
<span className="v" id="v42" data-v="42"> 沙龍、亞瑪利雅、約瑟。</span>
<span className="v" id="v43" data-v="43" data-xref="以斯拉記 2:29; 尼希米記 7:33"> 尼波的子孫中，有耶利、瑪他提雅、撒拔、西比拿、雅玳、約珥、比拿雅。</span>
<span className="v" id="v44" data-v="44" data-xref="箴言 5:20; 以斯拉記 10:3; 箴言 2:16"> 這些人都娶了外邦女子為妻，其中也有生了兒女的。</span>
</div>

## 從被擄之地回來的人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以斯拉記 7:7; 以斯拉記 2:62; 歷代志上 9:1"> 當亞達薛西王年間，同我從巴比倫上來的人，他們的族長和他們的家譜記在下面：</span>
<span className="v" id="v2" data-v="2" data-xref="歷代志上 3:22; 歷代志上 3:1; 歷代志上 6:3–15"> 屬非尼哈的子孫有革順；屬以他瑪的子孫有但以理；屬大衛的子孫有哈突；</span>
<span className="v" id="v3" data-v="3" data-xref="以斯拉記 2:3; 尼希米記 10:14; 尼希米記 7:8"> 屬巴錄的後裔，就是示迦尼的子孫有撒迦利亞，同着他，按家譜計算，男丁一百五十人；</span>
<span className="v" id="v4" data-v="4" data-xref="以斯拉記 2:6; 尼希米記 10:14; 尼希米記 7:11"> 屬巴哈‧摩押的子孫有西拉希雅的兒子以利約乃，同着他有男丁二百；</span>
<span className="v" id="v5" data-v="5"> 屬示迦尼的子孫有雅哈悉的兒子，同着他有男丁三百；</span>
<span className="v" id="v6" data-v="6" data-xref="以斯拉記 2:15; 尼希米記 10:16; 尼希米記 7:20"> 屬亞丁的子孫有約拿單的兒子以別，同着他有男丁五十；</span>
<span className="v" id="v7" data-v="7" data-xref="以斯拉記 2:31; 尼希米記 7:34; 以斯拉記 2:7"> 屬以攔的子孫有亞他利雅的兒子耶篩亞，同着他有男丁七十；</span>
<span className="v" id="v8" data-v="8" data-xref="尼希米記 11:4; 以斯拉記 2:4; 尼希米記 7:9"> 屬示法提雅的子孫有米迦勒的兒子西巴第雅，同着他有男丁八十；</span>
<span className="v" id="v9" data-v="9" data-xref="尼希米記 7:11; 以斯拉記 2:6"> 屬約押的子孫有耶歇的兒子俄巴底亞，同着他有男丁二百一十八；</span>
<span className="v" id="v10" data-v="10"> 屬示羅密的子孫有約細斐的兒子，同着他有男丁一百六十；</span>
<span className="v" id="v11" data-v="11" data-xref="以斯拉記 10:28; 尼希米記 7:16; 以斯拉記 2:11"> 屬比拜的子孫有比拜的兒子撒迦利亞，同着他有男丁二十八；</span>
<span className="v" id="v12" data-v="12" data-xref="以斯拉記 2:12; 尼希米記 7:17"> 屬押甲的子孫有哈加坦的兒子約哈難，同着他有男丁一百一十；</span>
<span className="v" id="v13" data-v="13" data-xref="以斯拉記 2:13; 尼希米記 7:18"> 屬亞多尼干的子孫，就是末尾的，他們的名字是以利法列、耶利、示瑪雅，同着他們有男丁六十；</span>
<span className="v" id="v14" data-v="14" data-xref="尼希米記 10:12; 以斯拉記 2:14; 尼希米記 7:19"> 屬比革瓦伊的子孫有烏太和撒布，同着他們有男丁七十。</span>

## 以斯拉為聖殿招集利未人

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="以斯拉記 8:21; 以斯拉記 8:31; 以斯拉記 7:7"> 我招聚這些人在流入亞哈瓦的河邊，我們在那裏住了三日。我查看百姓和祭司，見沒有利未人在那裏，</span>
<span className="v" id="v16" data-v="16" data-xref="箴言 2:6; 以斯拉記 8:18; 以斯拉記 10:39"> 就召首領以利以謝、亞列、示瑪雅、以利拿單、雅立、以利拿單、拿單、撒迦利亞、米書蘭，又召教習約雅立和以利拿單。</span>
<span className="v" id="v17" data-v="17" data-xref="以斯拉記 2:43; 出埃及記 4:15; 民數記 8:22–26"> 我打發他們往迦西斐雅地方去見那裏的首領易多，又告訴他們當向易多和他的弟兄尼提寧說甚麼話，叫他們為我們上帝的殿帶使用的人來。</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米書 3:15; 以斯拉記 7:28; 尼希米記 2:8"> 蒙我們上帝施恩的手幫助我們，他們在以色列的曾孫、利未的孫子、抹利的後裔中帶一個通達人來；還有示利比和他的眾子與弟兄共一十八人。</span>
<span className="v" id="v19" data-v="19" data-xref="歷代志上 6:1; 歷代志上 6:16; 尼希米記 10:11"> 又有哈沙比雅，同着他有米拉利的子孫耶篩亞，並他的眾子和弟兄共二十人。</span>
<span className="v" id="v20" data-v="20" data-xref="以斯拉記 2:43; 以斯拉記 7:7; 歷代志上 9:2"> 從前大衛和眾首領派尼提寧服事利未人，現在從這尼提寧中也帶了二百二十人來，都是按名指定的。</span>
</div>
</div>

## 以斯拉領百姓禁食禱告

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="歷代志下 20:3; 約珥書 1:14; 撒母耳記上 7:6"> 那時，我在亞哈瓦河邊宣告禁食，為要在我們上帝面前克苦己心，求他使我們和婦人孩子，並一切所有的，都得平坦的道路。</span>
<span className="v" id="v22" data-v="22" data-xref="彼得前書 3:12; 詩篇 33:18–19; 歷代志下 16:9"> 我求王撥步兵馬兵幫助我們抵擋路上的仇敵，本以為羞恥；因我曾對王說：「我們上帝施恩的手必幫助一切尋求他的；但他的能力和忿怒必攻擊一切離棄他的。」</span>
<span className="v" id="v23" data-v="23" data-xref="耶利米書 29:12–13; 馬太福音 7:7–8; 以斯拉記 8:31"> 所以我們禁食祈求我們的上帝，他就應允了我們。</span>
</div>
</div>

## 獻給聖殿的禮物

<div className="bt">
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="以斯拉記 8:18–19"> 我分派祭司長十二人，就是示利比、哈沙比雅，和他們的弟兄十人，</span>
<span className="v" id="v25" data-v="25" data-xref="以斯拉記 8:33; 以斯拉記 7:14–16; 以斯拉記 1:8"> 將王和謀士、軍長，並在那裏的以色列眾人為我們上帝殿所獻的金銀和器皿，都秤了交給他們。</span>
<span className="v" id="v26" data-v="26" data-xref="以斯拉記 1:9–11"> 我秤了交在他們手中的銀子有六百五十他連得；銀器重一百他連得；金子一百他連得；</span>
<span className="v" id="v27" data-v="27" data-xref="耶利米哀歌 4:2"> 金碗二十個，重一千達利克；上等光銅的器皿兩個，寶貴如金。</span>
<span className="v" id="v28" data-v="28" data-xref="利未記 22:2–3; 利未記 21:6–8; 歷代志上 23:28"> 我對他們說：「你們歸耶和華為聖，器皿也為聖；金銀是甘心獻給耶和華－你們列祖之上帝的。</span>
<span className="v" id="v29" data-v="29" data-xref="以斯拉記 8:33–34; 馬可福音 13:34–35; 歷代志上 26:20–26"> 你們當警醒看守，直到你們在耶路撒冷耶和華殿的庫內，在祭司長和利未族長，並以色列的各族長面前過了秤。」</span>
<span className="v" id="v30" data-v="30" data-xref="以斯拉記 8:22; 歷代志上 29:2–3; 以賽亞書 60:13"> 於是，祭司、利未人按着分量接受金銀和器皿，要帶到耶路撒冷我們上帝的殿裏。</span>
</div>
</div>

## 返回耶路撒冷

<div className="bt">
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="以斯拉記 8:21–22; 以斯拉記 7:9; 以斯拉記 8:15"> 正月十二日，我們從亞哈瓦河邊起行，要往耶路撒冷去。我們上帝的手保佑我們，救我們脫離仇敵和路上埋伏之人的手。</span>
<span className="v" id="v32" data-v="32" data-xref="尼希米記 2:11; 以斯拉記 7:8–9"> 我們到了耶路撒冷，在那裏住了三日。</span>
<span className="v" id="v33" data-v="33" data-xref="尼希米記 3:4; 尼希米記 3:21; 以斯拉記 8:30"> 第四日，在我們上帝的殿裏把金銀和器皿都秤了，交在祭司烏利亞的兒子米利末的手中。同着他有非尼哈的兒子以利亞撒，還有利未人耶書亞的兒子約撒拔和賓內的兒子挪亞底。</span>
<span className="v" id="v34" data-v="34"> 當時都點了數目，按着分量寫在冊上。</span>
<span className="v" id="v35" data-v="35" data-xref="以斯拉記 6:17; 歷代志下 29:31–32; 詩篇 66:10–15"> 從擄到之地歸回的人向以色列的上帝獻燔祭，就是為以色列眾人獻公牛十二隻，公綿羊九十六隻，綿羊羔七十七隻，又獻公山羊十二隻作贖罪祭，這都是向耶和華焚獻的。</span>
<span className="v" id="v36" data-v="36" data-xref="以斯拉記 7:21–24; 以斯拉記 4:7–23; 以斯拉記 6:13"> 他們將王的諭旨交給王所派的總督與河西的省長，他們就幫助百姓，又供給上帝殿裏所需用的。</span>
</div>

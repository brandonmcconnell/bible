## 以斯拉到達耶路撒冷

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="尼希米記 2:1; 歷代志上 6:4–14; 以斯拉記 7:21"> 這事以後，波斯王亞達薛西年間，有個以斯拉，他是西萊雅的兒子，西萊雅是亞撒利雅的兒子，亞撒利雅是希勒家的兒子，</span>
<span className="v" id="v2" data-v="2" data-xref="列王紀上 2:35; 撒母耳記下 8:17"> 希勒家是沙龍的兒子，沙龍是撒督的兒子，撒督是亞希突的兒子，</span>
<span className="v" id="v3" data-v="3"> 亞希突是亞瑪利雅的兒子，亞瑪利雅是亞撒利雅的兒子，亞撒利雅是米拉約的兒子，</span>
<span className="v" id="v4" data-v="4"> 米拉約是西拉希雅的兒子，西拉希雅是烏西的兒子，烏西是布基的兒子，</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 6:25; 歷代志下 26:20; 歷代志上 6:4"> 布基是亞比書的兒子，亞比書是非尼哈的兒子，非尼哈是以利亞撒的兒子，以利亞撒是大祭司亞倫的兒子。</span>
<span className="v" id="v6" data-v="6" data-xref="以斯拉記 8:22; 以斯拉記 7:28; 以斯拉記 8:31"> 這以斯拉從巴比倫上來，他是敏捷的文士，通達耶和華－以色列上帝所賜摩西的律法書。王允准他一切所求的，是因耶和華－他上帝的手幫助他。</span>
<span className="v" id="v7" data-v="7" data-xref="以斯拉記 8:1–20; 歷代志上 6:31–48; 歷代志上 9:17–27"> 亞達薛西王第七年，以色列人、祭司、利未人、歌唱的、守門的、尼提寧，有上耶路撒冷的。</span>
<span className="v" id="v8" data-v="8"> 王第七年五月，以斯拉到了耶路撒冷。</span>
<span className="v" id="v9" data-v="9" data-xref="以斯拉記 7:6; 尼希米記 2:8; 尼希米記 2:18"> 正月初一日，他從巴比倫起程；因他上帝施恩的手幫助他，五月初一日就到了耶路撒冷。</span>
<span className="v" id="v10" data-v="10" data-xref="瑪拉基書 2:7; 提摩太後書 4:2; 馬太福音 7:24"> 以斯拉定志考究遵行耶和華的律法，又將律例典章教訓以色列人。</span>
</div>
</div>

## 亞達薛西王給以斯拉的文件

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="以斯拉記 5:6; 以斯拉記 7:6; 馬太福音 23:2"> 祭司以斯拉是通達耶和華誡命和賜以色列之律例的文士。亞達薛西王賜給他們諭旨，上面寫着說：</span>
<span className="v" id="v12" data-v="12" data-xref="但以理書 2:37; 以西結書 26:7; 以斯拉記 4:17"> 「諸王之王亞達薛西，達於祭司以斯拉通達天上上帝律法大德的文士，云云。</span>
<span className="v" id="v13" data-v="13" data-xref="以斯拉記 6:1; 詩篇 148:6; 歷代志下 30:5"> 住在我國中的以色列人、祭司、利未人，凡甘心上耶路撒冷去的，我降旨准他們與你同去。</span>
<span className="v" id="v14" data-v="14" data-xref="以斯帖記 1:14; 以斯拉記 7:25–26; 以斯拉記 7:28"> 王與七個謀士既然差你去，照你手中上帝的律法書察問猶大和耶路撒冷的景況；</span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 135:21; 歷代志下 6:2; 以斯拉記 6:12"> 又帶金銀，就是王和謀士甘心獻給住耶路撒冷、以色列上帝的，</span>
<span className="v" id="v16" data-v="16" data-xref="歷代志上 29:6; 以斯拉記 1:4; 歷代志上 29:9"> 並帶你在巴比倫全省所得的金銀，和百姓、祭司樂意獻給耶路撒冷－他們上帝殿的禮物。</span>
<span className="v" id="v17" data-v="17" data-xref="申命記 12:5–11; 民數記 15:4–13; 以斯拉記 6:9–10"> 所以你當用這金銀，急速買公牛、公綿羊、綿羊羔，和同獻的素祭奠祭之物，獻在耶路撒冷－你們上帝殿的壇上。</span>
<span className="v" id="v18" data-v="18" data-xref="列王紀下 22:7; 以弗所書 5:17; 列王紀下 12:15"> 剩下的金銀，你和你的弟兄看着怎樣好，就怎樣用，總要遵着你們上帝的旨意。</span>
<span className="v" id="v19" data-v="19" data-xref="耶利米書 3:17; 以斯拉記 8:33–34; 歷代志下 32:19"> 所交給你上帝殿中使用的器皿，你要交在耶路撒冷上帝面前。</span>
<span className="v" id="v20" data-v="20" data-xref="以斯拉記 6:4; 以斯拉記 6:8–18"> 你上帝殿裏若再有需用的經費，你可以從王的府庫裏支取。</span>
<span className="v" id="v21" data-v="21" data-xref="以斯拉記 4:16; 以斯拉記 7:6; 以斯拉記 7:10–13"> 「我－亞達薛西王又降旨與河西的一切庫官，說：『通達天上上帝律法的文士祭司以斯拉，無論向你們要甚麼，你們要速速地備辦，</span>
<span className="v" id="v22" data-v="22" data-xref="路加福音 16:6–7; 利未記 2:13; 以西結書 45:14"> 就是銀子直到一百他連得，麥子一百柯珥，酒一百罷特，油一百罷特，鹽不計其數，也要給他。</span>
<span className="v" id="v23" data-v="23" data-xref="詩篇 119:4; 以斯拉記 7:18; 以斯拉記 6:10–12"> 凡天上之上帝所吩咐的，當為天上上帝的殿詳細辦理。為何使忿怒臨到王和王眾子的國呢？</span>
<span className="v" id="v24" data-v="24" data-xref="以斯拉記 7:7; 以斯拉記 4:13; 以斯拉記 2:36–55"> 我又曉諭你們，至於祭司、利未人、歌唱的、守門的，和尼提寧，並在上帝殿當差的人，不可叫他們進貢，交課，納稅。』</span>
<span className="v" id="v25" data-v="25" data-xref="以斯拉記 7:10; 申命記 16:18; 雅各書 1:5"> 「以斯拉啊，要照着你上帝賜你的智慧，將所有明白你上帝律法的人立為士師、審判官，治理河西的百姓，使他們教訓一切不明白上帝律法的人。</span>
<span className="v" id="v26" data-v="26" data-xref="以斯拉記 6:11; 申命記 13:1–18; 利未記 20:1–27"> 凡不遵行你上帝律法和王命令的人就當速速定他的罪，或治死，或充軍，或抄家，或囚禁。」</span>
</div>
</div>

## 以斯拉稱頌耶和華

<div className="bt">
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="以斯拉記 6:22; 啟示錄 17:17; 以賽亞書 60:13"> 以斯拉說：「耶和華－我們列祖的上帝是應當稱頌的！因他使王起這心意修飾耶路撒冷耶和華的殿，</span>
<span className="v" id="v28" data-v="28" data-xref="提摩太後書 4:17–18; 以斯拉記 5:5; 創世記 32:28"> 又在王和謀士，並大能的軍長面前施恩於我。因耶和華－我上帝的手幫助我，我就得以堅強，從以色列中招聚首領，與我一同上來。」</span>
</div>

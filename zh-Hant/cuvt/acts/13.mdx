## 巴拿巴和掃羅奉差遣

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行傳 4:36; 使徒行傳 15:35; 使徒行傳 11:22–27"> 在安提阿的教會中，有幾位先知和教師，就是巴拿巴和稱呼尼結的西面、古利奈人路求，與分封之王希律同養的馬念，並掃羅。</span>
<span className="v" id="v2" data-v="2" data-xref="加拉太書 1:15; 使徒行傳 9:15; 哥林多前書 12:11"> 他們事奉主、禁食的時候，聖靈說：「要為我分派巴拿巴和掃羅，去做我召他們所做的工。」</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行傳 6:6; 提摩太後書 2:2; 使徒行傳 13:2"> 於是禁食禱告，按手在他們頭上，就打發他們去了。</span>
</div>
</div>

## 在塞浦路斯傳道

<div className="bt">
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="使徒行傳 4:36; 使徒行傳 13:2; 使徒行傳 11:19"> 他們既被聖靈差遣，就下到西流基，從那裏坐船往塞浦路斯去。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行傳 13:14; 使徒行傳 13:46; 使徒行傳 14:1"> 到了撒拉米，就在猶太人各會堂裏傳講上帝的道，也有約翰作他們的幫手。</span>
<span className="v" id="v6" data-v="6" data-xref="馬太福音 7:15; 約翰一書 4:1; 哥林多後書 11:13"> 經過全島，直到帕弗，在那裏遇見一個有法術、假充先知的猶太人，名叫巴‧耶穌。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行傳 19:38; 使徒行傳 13:12; 使徒行傳 18:12"> 這人常和方伯士求‧保羅同在。士求‧保羅是個通達人，他請了巴拿巴和掃羅來，要聽上帝的道。</span>
<span className="v" id="v8" data-v="8" data-xref="提摩太後書 3:8; 使徒行傳 13:6–7; 提摩太後書 4:14–15"> 只是那行法術的以呂馬（這名翻出來就是行法術的意思）敵擋使徒，要叫方伯不信真道。</span>
<span className="v" id="v9" data-v="9" data-xref="彌迦書 3:8; 使徒行傳 4:8; 使徒行傳 2:4"> 掃羅又名保羅，被聖靈充滿，定睛看他，</span>
<span className="v" id="v10" data-v="10" data-xref="約翰福音 8:44; 哥林多後書 11:3; 馬太福音 13:38"> 說：「你這充滿各樣詭詐奸惡，魔鬼的兒子，眾善的仇敵，你混亂主的正道還不止住嗎？</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及記 9:3; 詩篇 32:4; 希伯來書 10:31"> 現在主的手加在你身上，你要瞎眼，暫且不見日光。」他的眼睛立刻昏蒙黑暗，四下裏求人拉着手領他。</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多後書 10:4–5; 使徒行傳 13:7; 路加福音 4:22"> 方伯看見所做的事，很希奇主的道，就信了。</span>
</div>
</div>

## 在彼西底的安提阿傳道

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="使徒行傳 15:38; 使徒行傳 2:10; 使徒行傳 14:24–25"> 保羅和他的同人從帕弗開船，來到旁非利亞的別加，約翰就離開他們，回耶路撒冷去。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行傳 16:13; 使徒行傳 14:19; 使徒行傳 13:5"> 他們離了別加往前行，來到彼西底的安提阿，在安息日進會堂坐下。</span>
<span className="v" id="v15" data-v="15" data-xref="希伯來書 13:22; 使徒行傳 15:21; 馬可福音 5:22"> 讀完了律法和先知的書，管會堂的叫人過去，對他們說：「二位兄台，若有甚麼勸勉眾人的話，請說。」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="使徒行傳 12:17; 使徒行傳 13:26; 使徒行傳 10:2"> 保羅就站起來，舉手，說：「以色列人和一切敬畏上帝的人，請聽。</span>
<span className="v" id="v17" data-v="17" data-xref="申命記 7:6–8; 以賽亞書 63:9–14; 詩篇 105:23–24"> 這以色列民的上帝揀選了我們的祖宗，當民寄居埃及的時候抬舉他們，用大能的手領他們出來；</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行傳 7:36; 詩篇 95:8–11; 詩篇 106:13–29"> 又在曠野容忍<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或譯：撫養">a</a></sup>他們，約有四十年。</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 7:1; 詩篇 78:55; 使徒行傳 7:45"> 既滅了迦南地七族的人，就把那地分給他們為業；</span>
<span className="v" id="v20" data-v="20" data-xref="士師記 2:16; 撒母耳記上 3:20; 列王紀下 23:22"> 此後給他們設立士師，約有四百五十年，直到先知撒母耳的時候。</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳記上 10:1; 撒母耳記上 15:1; 撒母耳記上 12:12–19"> 後來他們求一個王，上帝就將便雅憫支派中基士的兒子掃羅，給他們作王四十年。</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳記上 13:13–14; 列王紀上 15:5; 詩篇 78:70–72"> 既廢了掃羅，就選立大衛作他們的王，又為他作見證說：『我尋得耶西的兒子大衛，他是合我心意的人，凡事要遵行我的旨意。』</span>
<span className="v" id="v23" data-v="23" data-xref="馬太福音 1:1; 詩篇 132:11; 啟示錄 22:16"> 從這人的後裔中，上帝已經照着所應許的，為以色列人立了一位救主，就是耶穌。</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行傳 1:22; 約翰福音 1:6–8; 路加福音 3:2–20"> 在他沒有出來以先，約翰向以色列眾民宣講悔改的洗禮。</span>
<span className="v" id="v25" data-v="25" data-xref="馬太福音 3:11; 馬可福音 1:7; 約翰福音 1:26–27"> 約翰將行盡他的程途說：『你們以為我是誰？我不是基督；只是有一位在我以後來的，我解他腳上的鞋帶也是不配的。』</span>
</div>
<div className="bp poetry">
<span className="v" id="v26" data-v="26" data-xref="路加福音 1:77; 羅馬書 1:16; 路加福音 1:69"> 「弟兄們，亞伯拉罕的子孫和你們中間敬畏上帝的人哪，這救世的道是傳給我們的。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行傳 3:17; 路加福音 24:24–27; 路加福音 24:20"> 耶路撒冷居住的人和他們的官長，因為不認識基督，也不明白每安息日所讀眾先知的書，就把基督定了死罪，正應了先知的預言；</span>
<span className="v" id="v28" data-v="28" data-xref="路加福音 23:21–25; 路加福音 23:14–16; 約翰福音 19:4"> 雖然查不出他有當死的罪來，還是求彼拉多殺他；</span>
<span className="v" id="v29" data-v="29" data-xref="路加福音 23:53; 約翰福音 19:28; 約翰福音 19:30"> 既成就了經上指着他所記的一切話，就把他從木頭上取下來，放在墳墓裏。</span>
<span className="v" id="v30" data-v="30" data-xref="使徒行傳 2:24; 使徒行傳 17:31; 馬太福音 28:6"> 上帝卻叫他從死裏復活。</span>
<span className="v" id="v31" data-v="31" data-xref="路加福音 24:48; 使徒行傳 1:3; 使徒行傳 1:11"> 那從加利利同他上耶路撒冷的人多日看見他，這些人如今在民間是他的見證。</span>
<span className="v" id="v32" data-v="32" data-xref="羅馬書 4:13; 使徒行傳 26:6; 以西結書 34:23"> 我們也報好信息給你們，就是那應許祖宗的話，</span>
<span className="v" id="v33" data-v="33" data-xref="詩篇 2:7; 希伯來書 5:5; 希伯來書 1:5–6"> 上帝已經向我們這作兒女的應驗，叫耶穌復活了。正如詩篇第二篇上記着說：<br /><span className="pl pl-1">你是我的兒子，</span><br /><span className="pl pl-1">我今日生你。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v34" data-v="34" data-xref="以賽亞書 55:3; 詩篇 89:2–4; 羅馬書 6:9"> 論到上帝叫他從死裏復活，不再歸於朽壞，就這樣說：<br /><span className="pl pl-1">我必將所應許大衛那聖潔、</span><br /><span className="pl pl-1">可靠的恩典賜給你們。</span><br /></span>
<span className="v" id="v35" data-v="35" data-xref="詩篇 16:10; 使徒行傳 2:27–31; 詩篇 49:9"> <span className="pl pl-1">又有一篇上說：</span><br /><span className="pl pl-1">你必不叫你的聖者見朽壞。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v36" data-v="36" data-xref="使徒行傳 2:29; 撒母耳記下 7:12; 列王紀上 2:10"> 「大衛在世的時候遵行了上帝的旨意，就睡了<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或譯：大衛按上帝的旨意服事了他那一世的人，就睡了">b</a></sup>，歸到他祖宗那裏，已見朽壞；</span>
<span className="v" id="v37" data-v="37" data-xref="使徒行傳 13:30; 使徒行傳 2:24"> 惟獨上帝所復活的，他並未見朽壞。</span>
<span className="v" id="v38" data-v="38" data-xref="路加福音 24:47; 約翰一書 2:12; 哥林多後書 5:18–21"> 所以，弟兄們，你們當曉得：赦罪的道是由這人傳給你們的。</span>
<span className="v" id="v39" data-v="39" data-xref="羅馬書 10:4; 加拉太書 2:16; 羅馬書 8:3"> 你們靠摩西的律法，在一切不得稱義的事上信靠這人，就都得稱義了。</span>
<span className="v" id="v40" data-v="40" data-xref="瑪拉基書 4:1; 希伯來書 3:12; 瑪拉基書 3:2"> 所以，你們務要小心，免得先知書上所說的臨到你們。</span>
<span className="v" id="v41" data-v="41" data-xref="哈巴谷書 1:5; 彼得前書 4:17; 羅馬書 11:7–14"> 主說：<br /><span className="pl pl-1">你們這輕慢的人要觀看，要驚奇，要滅亡；</span><br /><span className="pl pl-1">因為在你們的時候，我行一件事，</span><br /><span className="pl pl-1">雖有人告訴你們，</span><br /><span className="pl pl-1">你們總是不信。」</span></span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="使徒行傳 28:28; 使徒行傳 10:33; 馬太福音 19:30"> 他們出會堂的時候，眾人請他們到下安息日再講這話給他們聽。</span>
<span className="v" id="v43" data-v="43" data-xref="使徒行傳 11:23; 使徒行傳 14:22; 以弗所書 2:8"> 散會以後，猶太人和敬虔進猶太教的人多有跟從保羅、巴拿巴的。二人對他們講道，勸他們務要恆久在上帝的恩中。</span>
</div>
<div className="bp poetry">
<span className="v" id="v44" data-v="44" data-xref="詩篇 110:3; 創世記 49:10; 以賽亞書 11:10"> 到下安息日，合城的人幾乎都來聚集，要聽上帝的道。</span>
<span className="v" id="v45" data-v="45" data-xref="猶大書 1:10; 使徒行傳 18:6; 使徒行傳 5:17"> 但猶太人看見人這樣多，就滿心嫉妒，硬駁保羅所說的話，並且毀謗。</span>
<span className="v" id="v46" data-v="46" data-xref="使徒行傳 28:28; 馬太福音 21:43; 使徒行傳 18:5–6"> 保羅和巴拿巴放膽說：「上帝的道先講給你們原是應當的；只因你們棄絕這道，斷定自己不配得永生，我們就轉向外邦人去。</span>
<span className="v" id="v47" data-v="47" data-xref="以賽亞書 49:6; 以賽亞書 42:6; 路加福音 2:32"> 因為主曾這樣吩咐我們說：<br /><span className="pl pl-1">我已經立你作外邦人的光，</span><br /><span className="pl pl-1">叫你施行救恩，直到地極。」</span></span>
</div>
<div className="bp">
<span className="v" id="v48" data-v="48" data-xref="羅馬書 8:29–30; 以弗所書 1:4; 羅馬書 11:7"> 外邦人聽見這話，就歡喜了，讚美上帝的道；凡預定得永生的人都信了。</span>
<span className="v" id="v49" data-v="49" data-xref="使徒行傳 12:24; 使徒行傳 19:10; 使徒行傳 19:26"> 於是主的道傳遍了那一帶地方。</span>
<span className="v" id="v50" data-v="50" data-xref="使徒行傳 14:19; 使徒行傳 13:45; 使徒行傳 14:2"> 但猶太人挑唆虔敬、尊貴的婦女和城內有名望的人，逼迫保羅、巴拿巴，將他們趕出境外。</span>
<span className="v" id="v51" data-v="51" data-xref="馬太福音 10:14; 使徒行傳 18:6; 路加福音 9:5"> 二人對着眾人跺下腳上的塵土，就往以哥念去了。</span>
<span className="v" id="v52" data-v="52" data-xref="羅馬書 15:13; 帖撒羅尼迦前書 1:6; 使徒行傳 4:31"> 門徒滿心喜樂，又被聖靈充滿。</span>
</div>
</div>

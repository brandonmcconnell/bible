## 賜聖靈的應許

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 1:3; 路加福音 24:19; 馬太福音 4:23–24"> 提阿非羅啊，我已經作了前書，論到耶穌開頭一切所行所教訓的，</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行傳 1:9; 約翰福音 20:21; 以賽亞書 59:20–21"> 直到他藉着聖靈吩咐所揀選的使徒，以後被接上升的日子為止。</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多前書 15:5–7; 使徒行傳 13:31; 約翰福音 20:26"> 他受害之後，用許多的憑據將自己活活地顯給使徒看，四十天之久向他們顯現，講說上帝國的事。</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 24:49; 約翰福音 14:16; 約翰福音 15:26"> 耶穌和他們聚集的時候，囑咐他們說：「不要離開耶路撒冷，要等候父所應許的，就是你們聽見我說過的。</span>
<span className="v" id="v5" data-v="5" data-xref="馬太福音 3:11; 使徒行傳 11:15–16; 路加福音 3:16"> 約翰是用水施洗，但不多幾日，你們要受聖靈的洗。」</span>
</div>
</div>

## 耶穌升天

<div className="bt">
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="路加福音 19:11; 路加福音 17:20; 但以理書 7:27"> 他們聚集的時候，問耶穌說：「主啊，你復興以色列國就在這時候嗎？」</span>
<span className="v" id="v7" data-v="7" data-xref="馬太福音 24:36; 帖撒羅尼迦前書 5:1–2; 馬可福音 13:32"> 耶穌對他們說：「父憑着自己的權柄所定的時候、日期，不是你們可以知道的。</span>
<span className="v" id="v8" data-v="8" data-xref="馬太福音 28:19; 馬可福音 16:15; 羅馬書 15:19"> 但聖靈降臨在你們身上，你們就必得着能力，並要在耶路撒冷、猶太全地，和撒馬利亞，直到地極，作我的見證。」</span>
<span className="v" id="v9" data-v="9" data-xref="但以理書 7:13; 路加福音 24:50–51; 馬可福音 16:19"> 說了這話，他們正看的時候，他就被取上升，有一朵雲彩把他接去，便看不見他了。</span>
<span className="v" id="v10" data-v="10" data-xref="路加福音 24:4; 約翰福音 20:12; 啟示錄 7:14"> 當他往上去，他們定睛望天的時候，忽然有兩個人身穿白衣，站在旁邊，說：</span>
<span className="v" id="v11" data-v="11" data-xref="啟示錄 1:7; 帖撒羅尼迦前書 4:16; 馬可福音 13:26"> 「加利利人哪，你們為甚麼站着望天呢？這離開你們被接升天的耶穌，你們見他怎樣往天上去，他還要怎樣來。」</span>
</div>
</div>

## 接替猶大職分的人

<div className="bt">
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="路加福音 24:52; 馬太福音 21:1; 路加福音 24:50"> 有一座山，名叫橄欖山，離耶路撒冷不遠，約有安息日可走的路程。當下，門徒從那裏回耶路撒冷去，</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行傳 20:8; 路加福音 22:12; 馬可福音 14:15"> 進了城，就上了所住的一間樓房；在那裏有彼得、約翰、雅各、安得烈、腓力、多馬、巴多羅買、馬太、亞勒腓的兒子雅各、奮銳黨的西門，和雅各的兒子<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或譯：兄弟">a</a></sup>猶大。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行傳 6:4; 以弗所書 6:18; 歌羅西書 4:2"> 這些人同着幾個婦人和耶穌的母親馬利亞，並耶穌的弟兄，都同心合意地恆切禱告。</span>
<span className="v" id="v15" data-v="15" data-xref="哥林多前書 15:6; 使徒行傳 21:20; 啟示錄 3:4"> 那時，有許多人聚會，約有一百二十名，彼得就在弟兄中間站起來，</span>
<span className="v" id="v16" data-v="16" data-xref="詩篇 41:9; 約翰福音 13:18; 詩篇 55:12–15"> 說：「弟兄們！聖靈藉大衛的口，在聖經上預言領人捉拿耶穌的猶大，這話是必須應驗的。</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行傳 1:25; 馬可福音 3:19; 約翰福音 17:12"> 他本來列在我們數中，並且在使徒的職任上得了一分。</span>
<span className="v" id="v18" data-v="18" data-xref="馬太福音 27:3–10; 馬太福音 26:14–15; 詩篇 55:23"> 這人用他作惡的工價買了一塊田，以後身子仆倒，肚腹崩裂，腸子都流出來。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行傳 2:22; 馬太福音 28:15; 使徒行傳 21:40"> 住在耶路撒冷的眾人都知道這事，所以按着他們那裏的話給那塊田起名叫亞革大馬，就是「血田」的意思。</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 69:25; 詩篇 109:8–15; 使徒行傳 1:25"> 因為詩篇上寫着，說：<br /><span className="pl pl-1">願他的住處變為荒場，</span><br /><span className="pl pl-1">無人在內居住；</span>又說：<br /><span className="pl pl-1">願別人得他的職分。</span></span>
<span className="v" id="v21" data-v="21" data-xref="約翰福音 15:27; 路加福音 10:1–2; 民數記 27:17"> 所以，主耶穌在我們中間始終出入的時候，</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行傳 1:2; 使徒行傳 4:33; 使徒行傳 1:8–9"> 就是從約翰施洗起，直到主離開我們被接上升的日子為止，必須從那常與我們作伴的人中立一位與我們同作耶穌復活的見證。」</span>
<span className="v" id="v23" data-v="23" data-xref="使徒行傳 15:22; 使徒行傳 1:26"> 於是選舉兩個人，就是那叫做巴撒巴，又稱呼猶士都的約瑟，和馬提亞。</span>
<span className="v" id="v24" data-v="24" data-xref="撒母耳記上 16:7; 使徒行傳 15:8; 希伯來書 4:13"> 眾人就禱告說：「主啊，你知道萬人的心，求你從這兩個人中，指明你所揀選的是誰，叫他得這使徒的位分。這位分猶大已經丟棄，往自己的地方去了。」</span>
<span className="v" id="v26" data-v="26" data-xref="利未記 16:8; 約書亞記 18:10; 撒母耳記上 14:41–42"> 於是眾人為他們搖籤，搖出馬提亞來；他就和十一個使徒同列。</span>
</div>

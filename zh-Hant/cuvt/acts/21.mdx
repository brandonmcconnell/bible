## 保羅上耶路撒冷

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="帖撒羅尼迦前書 2:17; 路加福音 5:4; 撒母耳記上 20:41–42"> 我們離別了眾人，就開船一直行到哥士。第二天到了羅底，從那裏到帕大喇，</span>
<span className="v" id="v2" data-v="2" data-xref="約拿書 1:3; 使徒行傳 11:19; 使徒行傳 15:3"> 遇見一隻船要往腓尼基去，就上船起行。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行傳 21:16; 使徒行傳 4:36; 馬太福音 4:24"> 望見塞浦路斯，就從南邊行過，往敘利亞去，我們就在泰爾上岸，因為船要在那裏卸貨。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行傳 20:22–23; 使徒行傳 21:10–12; 使徒行傳 20:6–7"> 找着了門徒，就在那裏住了七天。他們被聖靈感動，對保羅說：「不要上耶路撒冷去。」</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行傳 20:36; 使徒行傳 9:40; 詩篇 95:6"> 過了這幾天，我們就起身前行。他們眾人同妻子兒女，送我們到城外，我們都跪在岸上禱告，彼此辭別。</span>
<span className="v" id="v6" data-v="6" data-xref="約翰福音 19:27; 約翰福音 1:11; 哥林多後書 2:13"> 我們上了船，他們就回家去了。</span>
<span className="v" id="v7" data-v="7" data-xref="希伯來書 13:24; 撒母耳記上 10:4; 使徒行傳 28:12"> 我們從泰爾行盡了水路，來到多利買，就問那裏的弟兄安，和他們同住了一天。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行傳 6:5; 使徒行傳 8:26–40; 以弗所書 4:11"> 第二天，我們離開那裏，來到凱撒利亞，就進了傳福音的腓利家裏，和他同住。他是那七個執事裏的一個。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行傳 2:17; 啟示錄 2:20; 約珥書 2:28"> 他有四個女兒，都是處女，是說預言的。</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行傳 11:28; 使徒行傳 21:4; 使徒行傳 20:16"> 我們在那裏多住了幾天，有一個先知，名叫亞迦布，從猶太下來，</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行傳 21:33; 耶利米書 13:1–11; 撒母耳記上 15:27–28"> 到了我們這裏，就拿保羅的腰帶捆上自己的手腳，說：「聖靈說：猶太人在耶路撒冷，要如此捆綁這腰帶的主人，把他交在外邦人手裏。」</span>
<span className="v" id="v12" data-v="12" data-xref="馬太福音 16:21–23; 使徒行傳 20:22; 使徒行傳 21:4"> 我們和那本地的人聽見這話，都苦勸保羅不要上耶路撒冷去。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行傳 20:24; 腓立比書 2:17; 腓立比書 1:20–21"> 保羅說：「你們為甚麼這樣痛哭，使我心碎呢？我為主耶穌的名，不但被人捆綁，就是死在耶路撒冷也是願意的。」</span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 22:42; 馬太福音 26:42; 馬太福音 26:39"> 保羅既不聽勸，我們便住了口，只說：「願主的旨意成就」，便了。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行傳 25:1; 使徒行傳 25:6; 使徒行傳 25:9"> 過了幾日，我們收拾行李上耶路撒冷去。</span>
<span className="v" id="v16" data-v="16" data-xref="箴言 16:31; 使徒行傳 21:8; 詩篇 92:14"> 有凱撒利亞的幾個門徒和我們同去，帶我們到一個久為<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="久為：或譯老">a</a></sup>門徒的家裏，叫我們與他同住；他名叫拿孫，是塞浦路斯人。</span>
</div>
</div>

## 保羅訪問雅各

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="使徒行傳 15:4; 羅馬書 15:7; 希伯來書 13:1–2"> 到了耶路撒冷，弟兄們歡歡喜喜地接待我們。</span>
<span className="v" id="v18" data-v="18" data-xref="加拉太書 1:19; 加拉太書 2:9; 使徒行傳 15:13"> 第二天，保羅同我們去見雅各；長老們也都在那裏。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行傳 14:27; 使徒行傳 1:17; 羅馬書 15:18–19"> 保羅問了他們安，便將上帝用他傳教，在外邦人中間所行之事，一一地述說了。</span>
<span className="v" id="v20" data-v="20" data-xref="羅馬書 10:2; 加拉太書 1:14; 使徒行傳 22:3"> 他們聽見，就歸榮耀與上帝，對保羅說：「兄台，你看猶太人中信主的有多少萬，並且都為律法熱心。</span>
<span className="v" id="v21" data-v="21" data-xref="加拉太書 6:12–15; 哥林多前書 9:19–21; 加拉太書 5:1–6"> 他們聽見人說，你教訓一切在外邦的猶太人離棄摩西，對他們說，不要給孩子行割禮，也不要遵行條規。</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行傳 15:12; 使徒行傳 15:22; 使徒行傳 19:32"> 眾人必聽見你來了，這可怎麼辦呢？</span>
<span className="v" id="v23" data-v="23" data-xref="使徒行傳 18:18; 民數記 6:2–7"> 你就照着我們的話行吧！ 我們這裏有四個人，都有願在身。</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行傳 21:26; 使徒行傳 24:18; 使徒行傳 18:18"> 你帶他們去，與他們一同行潔淨的禮，替他們拿出規費，叫他們得以剃頭。這樣，眾人就可知道，先前所聽見你的事都是虛的；並可知道，你自己為人，循規蹈矩，遵行律法。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行傳 15:29; 使徒行傳 15:19–20"> 至於信主的外邦人，我們已經寫信擬定，叫他們謹忌那祭偶像之物，和血，並勒死的牲畜，與姦淫。」</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行傳 24:18; 使徒行傳 21:24; 民數記 6:13–20"> 於是保羅帶着那四個人，第二天與他們一同行了潔淨的禮，進了殿，報明潔淨的日期滿足，只等祭司為他們各人獻祭。</span>
</div>
</div>

## 保羅在聖殿裏被捕

<div className="bt">
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="使徒行傳 26:21; 使徒行傳 24:18; 使徒行傳 13:50"> 那七日將完，從亞細亞來的猶太人看見保羅在殿裏，就聳動了眾人，下手拿他，</span>
<span className="v" id="v28" data-v="28" data-xref="使徒行傳 24:5–6; 使徒行傳 21:21; 使徒行傳 26:20–21"> 喊叫說：「以色列人來幫助，這就是在各處教訓眾人糟踐我們百姓和律法，並這地方的。他又帶着希臘人進殿，污穢了這聖地。」（</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行傳 20:4; 提摩太後書 4:20; 使徒行傳 18:19"> 這話是因他們曾看見以弗所人特羅非摩同保羅在城裏，以為保羅帶他進了殿。）</span>
<span className="v" id="v30" data-v="30" data-xref="使徒行傳 26:21; 哥林多後書 11:26; 使徒行傳 16:19–22"> 合城都震動，百姓一齊跑來，拿住保羅，拉他出殿，殿門立刻都關了。</span>
<span className="v" id="v31" data-v="31" data-xref="哥林多後書 11:23–33; 使徒行傳 17:5; 使徒行傳 26:9–10"> 他們正想要殺他，有人報信給營裏的千夫長說：「耶路撒冷合城都亂了。」</span>
<span className="v" id="v32" data-v="32" data-xref="使徒行傳 23:27; 以賽亞書 3:15; 使徒行傳 5:40"> 千夫長立時帶着兵丁和幾個百夫長，跑下去到他們那裏。他們見了千夫長和兵丁，就止住不打保羅。</span>
<span className="v" id="v33" data-v="33" data-xref="以弗所書 6:20; 使徒行傳 21:11; 使徒行傳 20:23"> 於是千夫長上前拿住他，吩咐用兩條鐵鍊捆鎖；又問他是甚麼人，做的是甚麼事。</span>
<span className="v" id="v34" data-v="34" data-xref="使徒行傳 19:32; 使徒行傳 23:10; 使徒行傳 22:24"> 眾人有喊叫這個的，有喊叫那個的；千夫長因為這樣亂嚷，得不着實情，就吩咐人將保羅帶進營樓去。</span>
<span className="v" id="v35" data-v="35" data-xref="哈巴谷書 1:2–3; 詩篇 55:9; 詩篇 58:2"> 到了臺階上，眾人擠得兇猛，兵丁只得將保羅抬起來。</span>
<span className="v" id="v36" data-v="36" data-xref="約翰福音 19:15; 使徒行傳 22:22; 路加福音 23:18"> 眾人跟在後面，喊着說：「除掉他！」</span>
</div>
</div>

<span className="v" id="v38" data-v="38" data-xref="馬太福音 24:26; 使徒行傳 5:36–37; 馬太福音 5:11"> 你莫非是從前作亂、帶領四千兇徒往曠野去的那埃及人嗎？」</span>

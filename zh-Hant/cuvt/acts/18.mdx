## 保羅在哥林多

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多前書 1:2; 提摩太後書 4:20; 哥林多後書 1:1"> 這事以後，保羅離了雅典，來到哥林多。</span>
<span className="v" id="v2" data-v="2" data-xref="羅馬書 16:3–4; 哥林多前書 16:19; 提摩太後書 4:19"> 遇見一個猶太人，名叫亞居拉，他生在本都；因為克勞第命猶太人都離開羅馬，新近帶着妻百基拉，從意大利來。保羅就投奔了他們。</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多前書 4:12; 帖撒羅尼迦前書 2:9; 哥林多後書 11:9"> 他們本是製造帳棚為業。保羅因與他們同業，就和他們同住做工。</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多後書 5:11; 使徒行傳 17:17; 使徒行傳 28:23"> 每逢安息日，保羅在會堂裏辯論，勸化猶太人和希臘人。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多後書 5:14; 使徒行傳 18:28; 使徒行傳 20:21"> 西拉和提摩太從馬其頓來的時候，保羅為道迫切，向猶太人證明耶穌是基督。</span>
<span className="v" id="v6" data-v="6" data-xref="以西結書 33:4; 撒母耳記下 1:16; 以西結書 33:8–9"> 他們既抗拒、毀謗，保羅就抖着衣裳，說：「你們的罪<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是血">a</a></sup>歸到你們自己頭上，與我無干<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原文是我卻乾淨">b</a></sup>。從今以後，我要往外邦人那裏去。」</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行傳 16:14; 歌羅西書 4:11; 使徒行傳 10:2"> 於是離開那裏，到了一個人的家中；這人名叫提多‧猶士都，是敬拜上帝的，他的家靠近會堂。</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多前書 1:13–17; 羅馬書 10:14–17; 馬可福音 16:15–16"> 管會堂的基利司布和全家都信了主，還有許多哥林多人聽了，就相信受洗。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行傳 23:11; 以弗所書 6:19–20; 使徒行傳 27:23–25"> 夜間，主在異象中對保羅說：「不要怕，只管講，不要閉口，</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多後書 12:9; 出埃及記 4:12; 以賽亞書 41:10"> 有我與你同在，必沒有人下手害你，因為在這城裏我有許多的百姓。」</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行傳 14:3; 使徒行傳 19:10; 使徒行傳 20:31"> 保羅在那裏住了一年零六個月，將上帝的道教訓他們。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行傳 13:50; 使徒行傳 18:27; 使徒行傳 13:7"> 到迦流作亞該亞方伯的時候，猶太人同心起來攻擊保羅，拉他到公堂，</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行傳 25:8; 使徒行傳 24:5–6; 使徒行傳 6:13"> 說：「這個人勸人不按着律法敬拜上帝。」</span>
<span className="v" id="v14" data-v="14" data-xref="彼得前書 3:14–15; 使徒行傳 25:11; 馬可福音 9:19"> 保羅剛要開口，迦流就對猶太人說：「你們這些猶太人！如果是為冤枉或奸惡的事，我理當耐性聽你們。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行傳 23:29; 使徒行傳 25:19; 提摩太前書 6:4"> 但所爭論的，若是關乎言語、名目，和你們的律法，你們自己去辦吧！這樣的事我不願意審問」；</span>
<span className="v" id="v16" data-v="16" data-xref="啟示錄 12:16; 詩篇 76:10; 羅馬書 13:3–4"> 就把他們攆出公堂。</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多前書 1:1; 阿摩司書 6:6; 使徒行傳 17:32"> 眾人便揪住管會堂的所提尼，在堂前打他。這些事迦流都不管。</span>
</div>
</div>

## 保羅回到安提阿

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="使徒行傳 21:24; 民數記 6:18; 民數記 6:5–9"> 保羅又住了多日，就辭別了弟兄，坐船往敘利亞去；百基拉、亞居拉和他同去。他因為許過願，就在堅革哩剪了頭髮。</span>
<span className="v" id="v19" data-v="19" data-xref="以弗所書 1:1; 提摩太前書 1:3; 提摩太後書 1:18"> 到了以弗所，保羅就把他們留在那裏，自己進了會堂，和猶太人辯論。</span>
<span className="v" id="v20" data-v="20" data-xref="馬可福音 1:37–38; 哥林多前書 16:12; 使徒行傳 20:16"> 眾人請他多住些日子，他卻不允，</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多前書 4:19; 雅各書 4:15; 羅馬書 15:32"> 就辭別他們，說：「上帝若許我，我還要回到你們這裏」；於是開船離了以弗所。</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行傳 8:40; 使徒行傳 15:4; 使徒行傳 23:23"> 在凱撒利亞下了船，就上耶路撒冷去問教會安，隨後下安提阿去。</span>
<span className="v" id="v23" data-v="23" data-xref="使徒行傳 14:22; 使徒行傳 16:6; 使徒行傳 15:41"> 住了些日子，又離開那裏，挨次經過加拉太和弗呂家地方，堅固眾門徒。</span>
</div>
</div>

## 亞波羅在以弗所講道

<div className="bt">
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="哥林多前書 4:6; 提多書 3:13; 哥林多前書 3:5–6"> 有一個猶太人，名叫亞波羅，來到以弗所。他生在亞歷山大，是有學問<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="或譯：口才">c</a></sup>的，最能講解聖經。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行傳 19:3; 羅馬書 12:11; 何西阿書 14:9"> 這人已經在主的道上受了教訓，心裏火熱，將耶穌的事詳細講論教訓人；只是他單曉得約翰的洗禮。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行傳 18:25; 使徒行傳 14:3; 哥林多前書 12:21"> 他在會堂裏放膽講道；百基拉、亞居拉聽見，就接他來，將上帝的道給他講解更加詳細。</span>
<span className="v" id="v27" data-v="27" data-xref="帖撒羅尼迦後書 2:13–14; 雅各書 1:16–18; 彼得前書 1:2–3"> 他想要往亞該亞去，弟兄們就勉勵他，並寫信請門徒接待他<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="或譯：弟兄們就寫信勸門徒接待他">d</a></sup>。他到了那裏，多幫助那蒙恩信主的人，</span>
<span className="v" id="v28" data-v="28" data-xref="使徒行傳 18:5; 哥林多前書 15:3–4; 使徒行傳 9:22"> 在眾人面前極有能力駁倒猶太人，引聖經證明耶穌是基督。</span>
</div>
</div>

## 猶太人控告保羅

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行傳 24:11; 使徒行傳 23:2; 使徒行傳 25:2"> 過了五天，大祭司亞拿尼亞同幾個長老，和一個辯士帖土羅下來，向巡撫控告保羅。</span>
<span className="v" id="v2" data-v="2" data-xref="箴言 29:5; 箴言 26:28; 使徒行傳 24:26–27"> 保羅被提了來，帖土羅就告他說：</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行傳 23:26; 使徒行傳 26:25; 路加福音 1:3"> 「腓力斯大人，我們因你得以大享太平，並且這一國的弊病，因着你的先見得以更正了；我們隨時隨地滿心感謝不盡。</span>
<span className="v" id="v4" data-v="4" data-xref="希伯來書 11:32"> 惟恐多說，你嫌煩絮，只求你寬容聽我們說幾句話。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行傳 28:22; 使徒行傳 24:14; 使徒行傳 26:5"> 我們看這個人，如同瘟疫一般，是鼓動普天下眾猶太人生亂的，又是拿撒勒教黨裏的一個頭目，</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行傳 24:12; 使徒行傳 21:27–32; 約翰福音 18:31"> 連聖殿他也想要污穢；我們把他捉住了。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古卷加：要按我們的律法審問，7不料，千夫長呂西亞前來，甚是強橫，從我們手中把他奪去，吩咐告他的人到你這裏來。">a</a></sup></span>
<span className="v" id="v8" data-v="8" data-xref="使徒行傳 23:35; 使徒行傳 25:15–16; 使徒行傳 25:5"> 你自己究問他，就可以知道我們告他的一切事了。」</span>
<span className="v" id="v9" data-v="9" data-xref="帖撒羅尼迦前書 2:16; 彌迦書 7:2–3; 詩篇 4:2"> 眾猶太人也隨着告他說：「事情誠然是這樣。」</span>
</div>
</div>

## 保羅為自己辯護

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="彼得前書 3:15; 撒母耳記上 2:25; 路加福音 18:2"> 巡撫點頭叫保羅說話。他就說：「我知道你在這國裏斷事多年，所以我樂意為自己分訴。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行傳 24:1; 使徒行傳 21:18; 使徒行傳 23:11"> 你查問就可以知道，從我上耶路撒冷禮拜到今日不過有十二天。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行傳 25:8; 使徒行傳 28:17; 使徒行傳 24:18"> 他們並沒有看見我在殿裏，或是在會堂裏，或是在城裏，和人辯論，聳動眾人。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行傳 25:7; 彼得前書 3:16"> 他們現在所告我的事並不能對你證實了。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行傳 9:2; 羅馬書 3:21; 使徒行傳 3:13"> 但有一件事，我向你承認，就是他們所稱為異端的道，我正按着那道事奉我祖宗的上帝，又信合乎律法的和先知書上一切所記載的，</span>
<span className="v" id="v15" data-v="15" data-xref="但以理書 12:2; 約翰福音 5:28–29; 帖撒羅尼迦前書 4:14–16"> 並且靠着上帝，盼望死人，無論善惡，都要復活，就是他們自己也有這個盼望。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行傳 23:1; 提摩太前書 1:5; 哥林多後書 4:2"> 我因此自己勉勵，對上帝對人，常存無虧的良心。</span>
<span className="v" id="v17" data-v="17" data-xref="加拉太書 2:10; 羅馬書 15:25–28; 哥林多前書 16:1–4"> 過了幾年，我帶着賙濟本國的捐項和供獻的物上去。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行傳 26:21; 使徒行傳 21:26–30; 使徒行傳 24:12"> 正獻的時候，他們看見我在殿裏已經潔淨了，並沒有聚眾，也沒有吵嚷，惟有幾個從亞細亞來的猶太人。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行傳 23:30; 使徒行傳 25:16"> 他們若有告我的事，就應當到你面前來告我。</span>
<span className="v" id="v20" data-v="20"> 即或不然，這些人若看出我站在公會前，有妄為的地方，他們自己也可以說明。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行傳 23:6; 使徒行傳 4:2; 使徒行傳 26:6–8"> 縱然有，也不過一句話，就是我站在他們中間大聲說：『我今日在你們面前受審，是為死人復活的道理。』」</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行傳 24:6; 使徒行傳 24:24; 使徒行傳 25:26"> 腓力斯本是詳細曉得這道，就支吾他們說：「且等千夫長呂西亞下來，我要審斷你們的事。」</span>
<span className="v" id="v23" data-v="23" data-xref="使徒行傳 28:16; 使徒行傳 27:3; 箴言 16:7"> 於是吩咐百夫長看守保羅，並且寬待他，也不攔阻他的親友來供給他。</span>
</div>
</div>

## 腓力斯留保羅在監裏

<div className="bt">
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="使徒行傳 20:21; 加拉太書 2:16; 馬可福音 6:20"> 過了幾天，腓力斯和他夫人－猶太的女子土西拉－一同來到，就叫了保羅來，聽他講論信基督耶穌的道。</span>
<span className="v" id="v25" data-v="25" data-xref="約翰福音 16:8; 彼得前書 3:15; 使徒行傳 10:42"> 保羅講論公義、節制，和將來的審判。腓力斯甚覺恐懼，說：「你暫且去吧，等我得便再叫你來。」</span>
<span className="v" id="v26" data-v="26" data-xref="提摩太前書 6:9–10; 箴言 17:23; 以賽亞書 56:11"> 腓力斯又指望保羅送他銀錢，所以屢次叫他來，和他談論。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行傳 25:9; 使徒行傳 25:14; 使徒行傳 12:3"> 過了兩年，波求‧非斯都接了腓力斯的任；腓力斯要討猶太人的喜歡，就留保羅在監裏。</span>
</div>

## 亞拿尼亞和撒非喇

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="利未記 10:1–3; 提摩太後書 2:20; 馬太福音 13:47–48"> 有一個人，名叫亞拿尼亞，同他的妻子撒非喇賣了田產，</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行傳 4:37; 彼得後書 2:14–15; 馬太福音 23:5"> 把價銀私自留下幾分，他的妻子也知道，其餘的幾分拿來放在使徒腳前。</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米書 23:24; 以賽亞書 29:15; 約翰福音 13:2"> 彼得說：「亞拿尼亞！為甚麼撒但充滿了你的心，叫你欺哄聖靈，把田地的價銀私自留下幾分呢？</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行傳 5:3; 約書亞記 7:25–26; 列王紀下 5:25–27"> 田地還沒有賣，不是你自己的嗎？既賣了，價銀不是你作主嗎？你怎麼心裏起這意念呢？你不是欺哄人，是欺哄上帝了。」</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行傳 5:10–11; 使徒行傳 2:43; 使徒行傳 5:13"> 亞拿尼亞聽見這話，就仆倒，斷了氣；聽見的人都甚懼怕。</span>
<span className="v" id="v6" data-v="6" data-xref="約翰福音 19:40; 撒母耳記下 18:17; 申命記 21:23"> 有些少年人起來，把他包裹，抬出去埋葬了。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7"> 約過了三小時，他的妻子進來，還不知道這事。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行傳 5:2"> 彼得對她說：「你告訴我，你們賣田地的價銀就是這些嗎？」她說：「就是這些。」</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多前書 10:9; 使徒行傳 5:3–4; 詩篇 95:8–11"> 彼得說：「你們為甚麼同心試探主的靈呢？埋葬你丈夫之人的腳已到門口，他們也要把你抬出去。」</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行傳 5:5"> 婦人立刻仆倒在彼得腳前，斷了氣。那些少年人進來，見她已經死了，就抬出去，埋在她丈夫旁邊。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行傳 5:5; 哥林多前書 10:11–12; 使徒行傳 19:17"> 全教會和聽見這事的人都甚懼怕。</span>
</div>
</div>

## 主藉使徒行了許多神蹟奇事

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="使徒行傳 19:11; 哥林多後書 12:12; 希伯來書 2:4"> 主藉使徒的手在民間行了許多神蹟奇事；他們<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或譯：信的人">a</a></sup>都同心合意地在所羅門的廊下。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行傳 2:47; 使徒行傳 4:21; 約翰福音 12:42"> 其餘的人沒有一個敢貼近他們，百姓卻尊重他們。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行傳 2:47; 使徒行傳 4:4; 以賽亞書 55:11–13"> 信而歸主的人越發增添，連男帶女很多。</span>
<span className="v" id="v15" data-v="15" data-xref="馬太福音 14:36; 使徒行傳 19:11–12; 約翰福音 14:12"> 甚至有人將病人抬到街上，放在床上或褥子上，指望彼得過來的時候，或者得他的影兒照在甚麼人身上。</span>
<span className="v" id="v16" data-v="16" data-xref="馬可福音 16:17–18; 馬可福音 2:3–4; 馬太福音 15:30–31"> 還有許多人帶着病人和被污鬼纏磨的，從耶路撒冷四圍的城邑來，全都得了醫治。</span>
</div>
</div>

## 使徒受迫害

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="使徒行傳 13:45; 使徒行傳 7:9; 使徒行傳 17:5"> 大祭司和他的一切同人，就是撒都該教門的人，都起來，滿心忌恨，</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行傳 4:3; 路加福音 21:12; 哥林多後書 11:23"> 就下手拿住使徒，收在外監。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行傳 16:26; 詩篇 34:7; 使徒行傳 12:7–11"> 但主的使者夜間開了監門，領他們出來，</span>
<span className="v" id="v20" data-v="20" data-xref="約翰福音 6:63; 約翰福音 6:68; 約翰一書 5:11–12"> 說：「你們去站在殿裏，把這生命的道都講給百姓聽。」</span>
<span className="v" id="v21" data-v="21" data-xref="約翰福音 8:2; 使徒行傳 22:15; 使徒行傳 12:18–19"> 使徒聽了這話，天將亮的時候就進殿裏去教訓人。大祭司和他的同人來了，叫齊公會的人和以色列族的眾長老，就差人到監裏去，要把使徒提出來。</span>
<span className="v" id="v22" data-v="22"> 但差役到了，不見他們在監裏，就回來稟報說：</span>
<span className="v" id="v23" data-v="23" data-xref="詩篇 2:4; 詩篇 33:10; 但以理書 6:22–24"> 「我們看見監牢關得極妥當，看守的人也站在門外；及至開了門，裏面一個人都不見。」</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行傳 4:1; 使徒行傳 5:26; 約翰福音 12:19"> 守殿官和祭司長聽見這話，心裏犯難，不知這事將來如何。</span>
<span className="v" id="v25" data-v="25"> 有一個人來稟報說：「你們收在監裏的人，現在站在殿裏教訓百姓。」</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行傳 5:13; 使徒行傳 4:21; 馬太福音 26:5"> 於是守殿官和差役去帶使徒來，並沒有用強暴，因為怕百姓用石頭打他們。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="馬太福音 5:22; 使徒行傳 4:7; 路加福音 22:66"> 帶到了，便叫使徒站在公會前；大祭司問他們說：</span>
<span className="v" id="v28" data-v="28" data-xref="馬太福音 27:25; 使徒行傳 7:52; 使徒行傳 4:10–11"> 「我們不是嚴嚴地禁止你們，不可奉這名教訓人嗎？你們倒把你們的道理充滿了耶路撒冷，想要叫這人的血歸到我們身上！」</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行傳 4:19; 撒母耳記上 15:24; 馬可福音 7:7–9"> 彼得和眾使徒回答說：「順從上帝，不順從人，是應當的。</span>
<span className="v" id="v30" data-v="30" data-xref="加拉太書 3:13; 彼得前書 2:24; 使徒行傳 10:39"> 你們掛在木頭上殺害的耶穌，我們祖宗的上帝已經叫他復活。</span>
<span className="v" id="v31" data-v="31" data-xref="路加福音 24:47; 使徒行傳 2:33; 希伯來書 2:10"> 上帝且用右手將他高舉<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或譯：他就是上帝高舉在自己的右邊">b</a></sup>，叫他作君王，作救主，將悔改的心和赦罪的恩賜給以色列人。</span>
<span className="v" id="v32" data-v="32" data-xref="約翰福音 15:26–27; 希伯來書 2:3–4; 使徒行傳 1:8"> 我們為這事作見證；上帝賜給順從之人的聖靈也為這事作見證。」</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="使徒行傳 7:54; 使徒行傳 2:37; 路加福音 4:28–29"> 公會的人聽見就極其惱怒，想要殺他們。</span>
<span className="v" id="v34" data-v="34" data-xref="使徒行傳 22:3; 路加福音 2:46; 路加福音 5:17"> 但有一個法利賽人，名叫迦瑪列，是眾百姓所敬重的教法師，在公會中站起來，吩咐人把使徒暫且帶到外面去，</span>
<span className="v" id="v35" data-v="35" data-xref="使徒行傳 22:26; 耶利米書 26:19; 馬太福音 27:19"> 就對眾人說：「以色列人哪，論到這些人，你們應當小心怎樣辦理。</span>
<span className="v" id="v36" data-v="36" data-xref="使徒行傳 8:9; 彼得後書 2:2; 加拉太書 6:3"> 從前杜達起來，自誇為大，附從他的人約有四百，他被殺後，附從他的全都散了，歸於無有。</span>
<span className="v" id="v37" data-v="37" data-xref="路加福音 2:1–2; 詩篇 7:14–15; 馬太福音 26:52"> 此後，報名上冊的時候，又有加利利的猶大起來，引誘些百姓跟從他；他也滅亡，附從他的人也都四散了。</span>
<span className="v" id="v38" data-v="38" data-xref="馬太福音 15:13; 耶利米哀歌 3:37; 以賽亞書 8:9–10"> 現在，我勸你們不要管這些人，任憑他們吧！他們所謀的、所行的，若是出於人，必要敗壞；</span>
<span className="v" id="v39" data-v="39" data-xref="箴言 21:30; 以賽亞書 46:10; 馬太福音 16:18"> 若是出於上帝，你們就不能敗壞他們，恐怕你們倒是攻擊上帝了。」</span>
<span className="v" id="v40" data-v="40" data-xref="馬太福音 10:17; 使徒行傳 5:28; 使徒行傳 4:17–21"> 公會的人聽從了他，便叫使徒來，把他們打了，又吩咐他們不可奉耶穌的名講道，就把他們釋放了。</span>
<span className="v" id="v41" data-v="41" data-xref="雅各書 1:2; 彼得前書 4:13–16; 路加福音 6:22"> 他們離開公會，心裏歡喜，因被算是配為這名受辱。</span>
<span className="v" id="v42" data-v="42" data-xref="使徒行傳 2:46; 使徒行傳 20:20; 路加福音 21:37"> 他們就每日在殿裏、在家裏不住地教訓人，傳耶穌是基督。</span>
</div>
</div>

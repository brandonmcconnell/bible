## 司提反當眾申訴

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="約翰福音 18:19–21; 馬太福音 26:61–62; 使徒行傳 6:13–14"> 大祭司就說：「這些事果然有嗎？」</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行傳 22:1; 創世記 11:31; 詩篇 29:3"> 司提反說：「諸位父兄請聽！當日我們的祖宗亞伯拉罕在美索不達米亞還未住哈蘭的時候，榮耀的上帝向他顯現，</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 12:1; 希伯來書 11:8; 約書亞記 24:3"> 對他說：『你要離開本地和親族，往我所要指示你的地方去。』</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 12:4–5; 創世記 11:31–32; 以賽亞書 41:9"> 他就離開迦勒底人之地，住在哈蘭。他父親死了以後，上帝使他從那裏搬到你們現在所住之地。</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 17:8; 創世記 12:7; 創世記 13:15"> 在這地方，上帝並沒有給他產業，連立足之地也沒有給他；但應許要將這地賜給他和他的後裔為業；那時他還沒有兒子。</span>
<span className="v" id="v6" data-v="6" data-xref="創世記 15:13; 出埃及記 12:40–41; 加拉太書 3:17"> 上帝說：『他的後裔必寄居外邦，那裏的人要叫他們作奴僕，苦待他們四百年。』</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及記 3:12; 詩篇 105:27–36; 尼希米記 9:9–11"> 上帝又說：『使他們作奴僕的那國，我要懲罰。以後他們要出來，在這地方事奉我。』</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 35:23–26; 創世記 17:9–14; 創世記 21:1–4"> 上帝又賜他割禮的約。於是亞伯拉罕生了以撒，第八日給他行了割禮。以撒生雅各；雅各生十二位先祖。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="創世記 39:2; 詩篇 105:17; 以賽亞書 43:2"> 「先祖嫉妒約瑟，把他賣到埃及去；上帝卻與他同在，</span>
<span className="v" id="v10" data-v="10" data-xref="箴言 3:4; 提摩太後書 4:18; 箴言 2:6"> 救他脫離一切苦難，又使他在埃及王法老面前得恩典，有智慧。法老就派他作埃及國的宰相兼管全家。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 41:54–57; 創世記 45:11; 創世記 42:5"> 後來埃及和迦南全地遭遇饑荒，大受艱難，我們的祖宗就絕了糧。</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 42:1–24; 創世記 43:2"> 雅各聽見在埃及有糧，就打發我們的祖宗初次往那裏去。</span>
<span className="v" id="v13" data-v="13" data-xref="創世記 45:1–18; 創世記 46:31–10"> 第二次約瑟與弟兄們相認，他的親族也被法老知道了。</span>
<span className="v" id="v14" data-v="14" data-xref="創世記 46:26–27; 申命記 10:22; 出埃及記 1:5"> 約瑟就打發弟兄請父親雅各和全家七十五個人都來。</span>
<span className="v" id="v15" data-v="15" data-xref="創世記 49:33; 出埃及記 1:6; 創世記 46:3–7"> 於是雅各下了埃及，後來他和我們的祖宗都死在那裏；</span>
<span className="v" id="v16" data-v="16" data-xref="約書亞記 24:32; 創世記 23:16; 出埃及記 13:19"> 又被帶到示劍，葬於亞伯拉罕在示劍用銀子從哈抹子孫買來的墳墓裏。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="出埃及記 1:7–12; 使徒行傳 7:6; 使徒行傳 13:17"> 「及至上帝應許亞伯拉罕的日期將到，以色列民在埃及興盛眾多，</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及記 1:8"> 直到有不曉得約瑟的新王興起。</span>
<span className="v" id="v19" data-v="19" data-xref="詩篇 105:25; 出埃及記 1:9–22; 啟示錄 12:4–5"> 他用詭計待我們的宗族，苦害我們的祖宗，叫他們丟棄嬰孩，使嬰孩不能存活。</span>
<span className="v" id="v20" data-v="20" data-xref="希伯來書 11:23; 出埃及記 2:2–10; 撒母耳記上 16:12"> 那時，摩西生下來，俊美非凡，在他父親家裏撫養了三個月。</span>
<span className="v" id="v21" data-v="21" data-xref="希伯來書 11:24; 出埃及記 2:2–10; 申命記 32:26"> 他被丟棄的時候，法老的女兒拾了去，養為自己的兒子。</span>
<span className="v" id="v22" data-v="22" data-xref="以賽亞書 19:11; 但以理書 1:17–20; 歷代志下 9:22"> 摩西學了埃及人一切的學問，說話行事都有才能。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="出埃及記 2:11–12; 箴言 21:1; 希伯來書 11:24–26"> 「他將到四十歲，心中起意去看望他的弟兄以色列人；</span>
<span className="v" id="v24" data-v="24" data-xref="約翰福音 18:10–11; 使徒行傳 7:28; 約翰福音 18:25–27"> 到了那裏，見他們一個人受冤屈，就護庇他，為那受欺壓的人報仇，打死了那埃及人。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行傳 15:7; 馬可福音 9:32; 列王紀下 5:1"> 他以為弟兄必明白上帝是藉他的手搭救他們；他們卻不明白。</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及記 2:13–15; 箴言 18:19; 約翰一書 3:11–15"> 第二天，遇見兩個以色列人爭鬥，就勸他們和睦，說：『你們二位是弟兄，為甚麼彼此欺負呢？』</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行傳 7:35; 路加福音 12:14; 使徒行傳 7:54"> 那欺負鄰舍的把他推開，說：『誰立你作我們的首領和審判官呢？</span>
<span className="v" id="v28" data-v="28"> 難道你要殺我，像昨天殺那埃及人嗎？』</span>
<span className="v" id="v29" data-v="29" data-xref="出埃及記 18:2–4; 出埃及記 2:14–22; 出埃及記 4:19–20"> 摩西聽見這話就逃走了，寄居於米甸；在那裏生了兩個兒子。</span>
</div>
<div className="bp poetry">
<span className="v" id="v30" data-v="30" data-xref="出埃及記 3:1–2; 使徒行傳 7:35; 以賽亞書 43:2"> 「過了四十年，在西奈山的曠野，有一位天使從荊棘火焰中向摩西顯現。</span>
<span className="v" id="v31" data-v="31" data-xref="出埃及記 3:3–4"> 摩西見了那異象，便覺希奇，正進前觀看的時候，有主的聲音說：</span>
<span className="v" id="v32" data-v="32" data-xref="出埃及記 3:6; 馬太福音 22:32; 約伯記 4:14"> 『我是你列祖的上帝，就是亞伯拉罕的上帝，以撒的上帝，雅各的上帝。』摩西戰戰兢兢，不敢觀看。</span>
<span className="v" id="v33" data-v="33" data-xref="出埃及記 3:5; 約書亞記 5:15; 傳道書 5:1"> 主對他說：『把你腳上的鞋脫下來，因為你所站之地是聖地。</span>
<span className="v" id="v34" data-v="34" data-xref="出埃及記 3:7–10; 出埃及記 4:31; 詩篇 106:44"> 我的百姓在埃及所受的困苦，我實在看見了，他們悲歎的聲音，我也聽見了。我下來要救他們。你來！我要差你往埃及去。』</span>
<span className="v" id="v35" data-v="35" data-xref="詩篇 118:22–23; 路加福音 19:14; 詩篇 113:7–8"> 這摩西就是百姓棄絕說『誰立你作我們的首領和審判官』的；上帝卻藉那在荊棘中顯現之使者的手差派他作首領、作救贖的。</span>
<span className="v" id="v36" data-v="36" data-xref="出埃及記 12:41; 出埃及記 14:21; 出埃及記 33:1"> 這人領百姓出來，在埃及，在紅海，在曠野，四十年間行了奇事神蹟。</span>
<span className="v" id="v37" data-v="37" data-xref="申命記 18:15–19; 使徒行傳 3:22–23; 約翰福音 18:37"> 那曾對以色列人說『上帝要從你們弟兄中間給你們興起一位先知像我』的，就是這位摩西。</span>
<span className="v" id="v38" data-v="38" data-xref="羅馬書 3:2; 希伯來書 5:12; 彼得前書 4:11"> 這人曾在曠野會中和西奈山上，與那對他說話的天使同在，又與我們的祖宗同在，並且領受活潑的聖言傳給我們。</span>
<span className="v" id="v39" data-v="39" data-xref="民數記 14:3–4; 民數記 11:5; 尼希米記 9:16–17"> 我們的祖宗不肯聽從，反棄絕他，心裏歸向埃及，</span>
<span className="v" id="v40" data-v="40" data-xref="出埃及記 32:1; 出埃及記 32:23"> 對亞倫說：『你且為我們造些神像，在我們前面引路；因為領我們出埃及地的那個摩西，我們不知道他遭了甚麼事。』</span>
<span className="v" id="v41" data-v="41" data-xref="詩篇 106:19–21; 尼希米記 9:18; 啟示錄 9:20"> 那時，他們造了一個牛犢，又拿祭物獻給那像，歡喜自己手中的工作。</span>
<span className="v" id="v42" data-v="42" data-xref="阿摩司書 5:25–26; 以西結書 20:39; 耶利米書 19:13"> 上帝就轉臉不顧，任憑他們事奉天上的日月星辰，正如先知書上所寫的說：<br /><span className="pl pl-1">以色列家啊，</span><br /><span className="pl pl-1">你們四十年間在曠野，</span><br /><span className="pl pl-1">豈是將犧牲和祭物獻給我嗎？</span><br /></span>
<span className="v" id="v43" data-v="43" data-xref="阿摩司書 5:26–27; 出埃及記 20:4–5; 申命記 5:8–9"> <span className="pl pl-1">你們抬着摩洛的帳幕和理番神的星，</span><br /><span className="pl pl-1">就是你們所造為要敬拜的像。</span><br /><span className="pl pl-1">因此，我要把你們遷到巴比倫外去。</span></span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="出埃及記 25:40; 出埃及記 38:21; 希伯來書 8:5"> 「我們的祖宗在曠野，有法櫃的帳幕，是上帝吩咐摩西叫他照所看見的樣式做的。</span>
<span className="v" id="v45" data-v="45" data-xref="詩篇 44:2; 約書亞記 18:1; 約書亞記 23:9"> 這帳幕，我們的祖宗相繼承受。當上帝在他們面前趕出外邦人去的時候，他們同約書亞把帳幕搬進承受為業之地，直存到大衛的日子。</span>
<span className="v" id="v46" data-v="46" data-xref="詩篇 132:1–5; 使徒行傳 13:22; 撒母耳記下 7:1–5"> 大衛在上帝面前蒙恩，祈求為雅各的上帝預備居所；</span>
<span className="v" id="v47" data-v="47" data-xref="列王紀上 8:20; 列王紀上 6:37–38; 撒母耳記下 7:13"> 卻是所羅門為上帝造成殿宇。</span>
<span className="v" id="v48" data-v="48" data-xref="使徒行傳 17:24–25; 以賽亞書 66:1–2; 列王紀上 8:27"> 其實，至高者並不住人手所造的，就如先知所言：</span>
</div>
<div className="bp poetry">
<span className="v" id="v49" data-v="49" data-xref="以賽亞書 66:1; 詩篇 11:4; 約翰福音 4:21"> 主說：天是我的座位，<br /><span className="pl pl-1">地是我的腳凳；</span><br /><span className="pl pl-1">你們要為我造何等的殿宇？</span><br /><span className="pl pl-1">哪裏是我安息的地方呢？</span><br /></span>
<span className="v" id="v50" data-v="50" data-xref="耶利米書 32:17; 詩篇 33:6–9; 使徒行傳 14:15"> <span className="pl pl-1">這一切不都是我手所造的嗎？</span></span>
</div>
<div className="bp">
<span className="v" id="v51" data-v="51" data-xref="申命記 10:16; 以弗所書 4:30; 以賽亞書 63:10"> 「你們這硬着頸項、心與耳未受割禮的人，常時抗拒聖靈！你們的祖宗怎樣，你們也怎樣。</span>
<span className="v" id="v52" data-v="52" data-xref="馬太福音 5:12; 歷代志下 36:16; 列王紀上 19:10"> 哪一個先知不是你們祖宗逼迫呢？他們也把預先傳說那義者要來的人殺了；如今你們又把那義者賣了，殺了。</span>
<span className="v" id="v53" data-v="53" data-xref="希伯來書 2:2; 加拉太書 3:19; 使徒行傳 7:38"> 你們受了天使所傳的律法，竟不遵守。」</span>
</div>
</div>

## 眾人用石頭打死司提反

<div className="bt">
<div className="bp">
<span className="v" id="v54" data-v="54" data-xref="使徒行傳 5:33; 詩篇 35:16; 馬太福音 25:30"> 眾人聽見這話就極其惱怒，向司提反咬牙切齒。</span>
<span className="v" id="v55" data-v="55" data-xref="馬可福音 16:19; 希伯來書 1:3; 哥林多後書 4:6"> 但司提反被聖靈充滿，定睛望天，看見上帝的榮耀，又看見耶穌站在上帝的右邊，</span>
<span className="v" id="v56" data-v="56" data-xref="馬太福音 26:64–65; 使徒行傳 10:11; 啟示錄 11:19"> 就說：「我看見天開了，人子站在上帝的右邊。」</span>
<span className="v" id="v57" data-v="57" data-xref="撒迦利亞書 7:11; 詩篇 58:4; 使徒行傳 23:27"> 眾人大聲喊叫，摀着耳朵，齊心擁上前去，</span>
<span className="v" id="v58" data-v="58" data-xref="使徒行傳 22:20; 使徒行傳 8:1; 使徒行傳 6:13"> 把他推到城外，用石頭打他。作見證的人把衣裳放在一個少年人名叫掃羅的腳前。</span>
<span className="v" id="v59" data-v="59" data-xref="路加福音 23:46; 詩篇 31:5; 使徒行傳 22:16"> 他們正用石頭打的時候，司提反呼籲主說：「求主耶穌接收我的靈魂！」</span>
<span className="v" id="v60" data-v="60" data-xref="馬太福音 5:44; 路加福音 23:34; 哥林多前書 15:20"> 又跪下大聲喊着說：「主啊，不要將這罪歸於他們！」說了這話，就睡了。掃羅也喜悅他被害。</span>
</div>
</div>

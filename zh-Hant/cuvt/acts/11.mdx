## 向耶路撒冷教會報告

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="詩篇 22:27; 瑪拉基書 1:11; 以賽亞書 32:15"> 使徒和在猶太的眾弟兄聽說外邦人也領受了上帝的道。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行傳 10:45; 使徒行傳 10:9; 使徒行傳 15:1"> 及至彼得上了耶路撒冷，那些奉割禮的門徒和他爭辯說：</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行傳 10:28; 加拉太書 2:12; 路加福音 15:2"> 「你進入未受割禮之人的家和他們一同吃飯了。」</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 1:3; 使徒行傳 14:27; 約書亞記 22:21–31"> 彼得就開口把這事挨次給他們講解說：</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行傳 10:9–32; 使徒行傳 9:10; 使徒行傳 22:17"> 「我在約帕城裏禱告的時候，魂遊象外，看見異象，有一物降下，好像一塊大布，繫着四角，從天縋下，直來到我跟前。</span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 4:20; 使徒行傳 3:4"> 我定睛觀看，見內中有地上四足的牲畜和野獸、昆蟲，並天上的飛鳥。</span>
<span className="v" id="v7" data-v="7"> 我且聽見有聲音向我說：『彼得，起來，宰了吃！』</span>
<span className="v" id="v8" data-v="8" data-xref="羅馬書 14:14; 何西阿書 9:3; 哥林多前書 7:14"> 我說：『主啊，這是不可的！凡俗而不潔淨的物從來沒有入過我的口。』</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行傳 15:9; 希伯來書 9:13–14; 使徒行傳 10:34–35"> 第二次，有聲音從天上說：『上帝所潔淨的，你不可當作俗物。』</span>
<span className="v" id="v10" data-v="10" data-xref="約翰福音 21:17; 民數記 24:10; 哥林多後書 12:8"> 這樣一連三次，就都收回天上去了。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及記 4:27; 使徒行傳 9:10–12; 出埃及記 4:14"> 正當那時，有三個人站在我們所住的房門前，是從凱撒利亞差來見我的。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行傳 8:29; 羅馬書 3:22; 帖撒羅尼迦後書 2:2"> 聖靈吩咐我和他們同去，不要疑惑<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或譯：不要分別等類">a</a></sup>。同着我去的，還有這六位弟兄，我們都進了那人的家。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行傳 10:30–32; 使徒行傳 10:3–6; 使徒行傳 9:43"> 那人就告訴我們，他如何看見一位天使站在他屋裏，說：『你打發人往約帕去，請那稱呼彼得的西門來，</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行傳 16:15; 使徒行傳 10:22; 使徒行傳 16:31–34"> 他有話告訴你，可以叫你和你的全家得救。』</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行傳 19:6; 使徒行傳 10:34–46; 使徒行傳 2:2–12"> 我一開講，聖靈便降在他們身上，正像當初降在我們身上一樣。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行傳 1:5; 馬可福音 1:8; 箴言 1:23"> 我就想起主的話說：『約翰是用水施洗，但你們要受聖靈的洗。』</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行傳 10:47; 羅馬書 9:20–26; 但以理書 4:35"> 上帝既然給他們恩賜，像在我們信主耶穌基督的時候給了我們一樣；我是誰，能攔阻上帝呢？」</span>
<span className="v" id="v18" data-v="18" data-xref="羅馬書 10:12–13; 哥林多後書 7:10; 以西結書 36:26"> 眾人聽見這話，就不言語了，只歸榮耀與上帝，說：「這樣看來，上帝也賜恩給外邦人，叫他們悔改得生命了。」</span>
</div>
</div>

## 安提阿的教會

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="使徒行傳 4:36; 使徒行傳 21:2; 使徒行傳 15:3"> 那些因司提反的事遭患難四散的門徒直走到腓尼基和塞浦路斯，並安提阿；他們不向別人講道，只向猶太人講。</span>
<span className="v" id="v20" data-v="20" data-xref="馬太福音 27:32; 使徒行傳 13:1; 哥林多前書 1:23–24"> 但內中有塞浦路斯和古利奈人，他們到了安提阿也向希臘人傳講主耶穌<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有古卷：也向說希臘話的猶太人傳講主耶穌">b</a></sup>。</span>
<span className="v" id="v21" data-v="21" data-xref="路加福音 1:66; 使徒行傳 2:47; 使徒行傳 5:14"> 主與他們同在，信而歸主的人就很多了。</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行傳 9:27; 使徒行傳 8:14; 使徒行傳 13:1–3"> 這風聲傳到耶路撒冷教會人的耳中，他們就打發巴拿巴出去，走到安提阿為止。</span>
<span className="v" id="v23" data-v="23" data-xref="哥林多前書 15:58; 使徒行傳 14:22; 使徒行傳 13:43"> 他到了那裏，看見上帝所賜的恩就歡喜，勸勉眾人，立定心志，恆久靠主。</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行傳 11:21; 使徒行傳 5:14; 使徒行傳 9:31"> 這巴拿巴原是個好人，被聖靈充滿，大有信心。於是有許多人歸服了主。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行傳 9:11; 使徒行傳 9:27; 使徒行傳 9:30"> 他又往大數去找掃羅，</span>
<span className="v" id="v26" data-v="26" data-xref="彼得前書 4:16; 使徒行傳 26:28; 彼得前書 4:14"> 找着了，就帶他到安提阿去。他們足有一年的工夫和教會一同聚集，教訓了許多人。門徒稱為「基督徒」是從安提阿起首。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="使徒行傳 13:1; 哥林多前書 12:28; 以弗所書 4:11"> 當那些日子，有幾位先知從耶路撒冷下到安提阿。</span>
<span className="v" id="v28" data-v="28" data-xref="使徒行傳 21:10; 使徒行傳 18:2; 路加福音 3:1"> 內中有一位，名叫亞迦布，站起來，藉着聖靈指明天下將有大饑荒。（這事到克勞第年間果然有了。）</span>
<span className="v" id="v29" data-v="29" data-xref="哥林多後書 8:12–14; 加拉太書 2:10; 哥林多後書 8:2–4"> 於是門徒定意照各人的力量捐錢，送去供給住在猶太的弟兄。</span>
<span className="v" id="v30" data-v="30" data-xref="使徒行傳 14:23; 使徒行傳 12:25; 使徒行傳 15:4"> 他們就這樣行，把捐項託巴拿巴和掃羅送到眾長老那裏。</span>
</div>
</div>

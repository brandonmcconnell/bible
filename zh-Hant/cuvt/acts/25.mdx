## 保羅要向凱撒上訴

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行傳 23:34; 使徒行傳 25:5; 使徒行傳 8:40"> 非斯都到了任，過了三天，就從凱撒利亞上耶路撒冷去。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行傳 25:15; 箴言 4:16; 使徒行傳 24:1"> 祭司長和猶太人的首領向他控告保羅，</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行傳 9:24; 使徒行傳 23:12–15; 撒母耳記上 23:19–21"> 又央告他，求他的情，將保羅提到耶路撒冷來，他們要在路上埋伏殺害他。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行傳 24:23"> 非斯都卻回答說：「保羅押在凱撒利亞，我自己快要往那裏去」；</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行傳 25:25; 約翰福音 18:29–30; 使徒行傳 25:18–19"> 又說：「你們中間有權勢的人與我一同下去，那人若有甚麼不是，就可以告他。」</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行傳 25:17; 使徒行傳 25:10; 馬太福音 27:19"> 非斯都在他們那裏住了不過十天八天，就下凱撒利亞去；第二天坐堂，吩咐將保羅提上來。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行傳 24:13; 路加福音 23:10; 使徒行傳 25:24"> 保羅來了，那些從耶路撒冷下來的猶太人周圍站着，將許多重大的事控告他，都是不能證實的。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行傳 24:12; 使徒行傳 28:17; 哥林多後書 1:12"> 保羅分訴說：「無論猶太人的律法，或是聖殿，或是凱撒，我都沒有干犯。」</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行傳 24:27; 使徒行傳 12:3; 使徒行傳 25:20"> 但非斯都要討猶太人的喜歡，就問保羅說：「你願意上耶路撒冷去，在那裏聽我審斷這事嗎？」</span>
<span className="v" id="v10" data-v="10" data-xref="馬太福音 27:18; 哥林多後書 4:2; 使徒行傳 28:18"> 保羅說：「我站在凱撒的堂前，這就是我應當受審的地方。我向猶太人並沒有行過甚麼不義的事，這也是你明明知道的。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行傳 28:19; 使徒行傳 26:32; 使徒行傳 25:25"> 我若行了不義的事，犯了甚麼該死的罪，就是死，我也不辭。他們所告我的事若都不實，就沒有人可以把我交給他們。我要上告於凱撒。」</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行傳 19:21; 腓立比書 1:12–14; 腓立比書 1:20"> 非斯都和議會商量了，就說：「你既上告於凱撒，可以往凱撒那裏去。」</span>
</div>
</div>

## 保羅被帶到亞基帕王面前

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="使徒行傳 8:40; 使徒行傳 26:1; 使徒行傳 26:27–28"> 過了些日子，亞基帕王和百妮基氏來到凱撒利亞，問非斯都安。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行傳 24:27"> 在那裏住了多日，非斯都將保羅的事告訴王，說：「這裏有一個人，是腓力斯留在監裏的。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行傳 25:1–3; 以斯帖記 3:9; 路加福音 18:3–5"> 我在耶路撒冷的時候，祭司長和猶太的長老將他的事稟報了我，求我定他的罪。</span>
<span className="v" id="v16" data-v="16" data-xref="約翰福音 7:51; 申命記 19:17–18; 使徒行傳 23:30"> 我對他們說，無論甚麼人，被告還沒有和原告對質，未得機會分訴所告他的事，就先定他的罪，這不是羅馬人的條例。</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行傳 25:6; 使徒行傳 25:10"> 及至他們都來到這裏，我就不耽延，第二天便坐堂，吩咐把那人提上來。</span>
<span className="v" id="v18" data-v="18"> 告他的人站着告他；所告的，並沒有我所逆料的那等惡事。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行傳 23:29; 使徒行傳 18:15; 哥林多前書 15:3–4"> 不過是有幾樣辯論，為他們自己敬鬼神的事，又為一個人名叫耶穌，是已經死了，保羅卻說他是活着的。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行傳 25:9"> 這些事當怎樣究問，我心裏作難，所以問他說：『你願意上耶路撒冷去，在那裏為這些事聽審嗎？』</span>
<span className="v" id="v21" data-v="21" data-xref="提摩太後書 4:16; 路加福音 2:1; 使徒行傳 25:10–11"> 但保羅求我留下他，要聽皇上審斷，我就吩咐把他留下，等我解他到凱撒那裏去。」</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行傳 9:15; 馬太福音 10:18; 以賽亞書 52:15"> 亞基帕對非斯都說：「我自己也願聽這人辯論。」非斯都說：「明天你可以聽。」</span>
<span className="v" id="v23" data-v="23" data-xref="使徒行傳 26:30; 使徒行傳 25:13; 約翰一書 2:16"> 第二天，亞基帕和百妮基大張威勢而來，同着眾千夫長和城裏的尊貴人進了公廳。非斯都吩咐一聲，就有人將保羅帶進來。</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行傳 22:22; 使徒行傳 25:7; 使徒行傳 25:2–3"> 非斯都說：「亞基帕王和在這裏的諸位啊，你們看這人，就是一切猶太人，在耶路撒冷和這裏，曾向我懇求、呼叫說：『不可容他再活着。』</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行傳 23:29; 使徒行傳 25:11–12; 路加福音 23:4"> 但我查明他沒有犯甚麼該死的罪，並且他自己上告於皇帝，所以我定意把他解去。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行傳 26:2–3"> 論到這人，我沒有確實的事可以奏明主上。因此，我帶他到你們面前，也特意帶他到你亞基帕王面前，為要在查問之後有所陳奏。</span>
<span className="v" id="v27" data-v="27" data-xref="約翰福音 7:51; 箴言 18:13"> 據我看來，解送囚犯，不指明他的罪案是不合理的。」</span>
</div>

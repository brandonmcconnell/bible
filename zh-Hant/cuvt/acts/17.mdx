## 帖撒羅尼迦的騷動

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="帖撒羅尼迦前書 1:1; 腓立比書 4:16; 使徒行傳 20:4"> 保羅和西拉經過暗妃坡里、亞波羅尼亞，來到帖撒羅尼迦，在那裏有猶太人的會堂。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行傳 9:20; 使徒行傳 17:17; 使徒行傳 18:4"> 保羅照他素常的規矩進去，一連三個安息日，本着聖經與他們辯論，</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行傳 18:28; 使徒行傳 9:22; 路加福音 24:32"> 講解陳明基督必須受害，從死裏復活；又說：「我所傳與你們的這位耶穌就是基督。」</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行傳 17:12; 使徒行傳 13:43; 使徒行傳 14:4"> 他們中間有些人聽了勸，就附從保羅和西拉，並有許多虔敬的希臘人，尊貴的婦女也不少。</span>
<span className="v" id="v5" data-v="5" data-xref="加拉太書 5:26; 使徒行傳 17:13; 羅馬書 16:21"> 但那不信的猶太人心裏嫉妒，招聚了些市井匪類，搭夥成群，聳動合城的人闖進耶孫 的家，要將保羅、西拉帶到百姓那裏。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行傳 24:5; 使徒行傳 16:19–21; 使徒行傳 28:22"> 找不着他們，就把耶孫和幾個弟兄拉到地方官那裏，喊叫說：「那攪亂天下的也到這裏來了，</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 23:2; 使徒行傳 16:21; 約翰福音 19:12"> 耶孫收留他們。這些人都違背凱撒的命令，說另有一個王耶穌。」</span>
<span className="v" id="v8" data-v="8" data-xref="馬太福音 2:3; 約翰福音 11:48"> 眾人和地方官聽見這話，就驚慌了；</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行傳 17:5"> 於是取了耶孫和其餘之人的保狀，就釋放了他們。</span>
</div>
</div>

## 使徒們在庇哩亞傳道

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="使徒行傳 17:2; 帖撒羅尼迦前書 2:2; 使徒行傳 17:13–14"> 弟兄們隨即在夜間打發保羅和西拉往庇哩亞去。二人到了，就進入猶太人的會堂。</span>
<span className="v" id="v11" data-v="11" data-xref="以賽亞書 34:16; 箴言 2:1–5; 約翰福音 5:39"> 這地方的人賢於帖撒羅尼迦的人，甘心領受這道，天天考查聖經，要曉得這道是與不是。</span>
<span className="v" id="v12" data-v="12" data-xref="以弗所書 5:14; 使徒行傳 14:1; 使徒行傳 13:50"> 所以他們中間多有相信的，又有希臘尊貴的婦女，男子也不少。</span>
<span className="v" id="v13" data-v="13" data-xref="帖撒羅尼迦前書 2:14–16; 箴言 28:25; 使徒行傳 6:12"> 但帖撒羅尼迦的猶太人知道保羅又在庇哩亞傳上帝的道，也就往那裏去，聳動攪擾眾人。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行傳 17:10; 馬太福音 10:23; 使徒行傳 9:25"> 當時弟兄們便打發保羅往海邊去，西拉和提摩太仍住在庇哩亞。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行傳 18:5; 帖撒羅尼迦前書 3:1; 使徒行傳 18:1"> 送保羅的人帶他到了雅典，既領了保羅的命，叫西拉和提摩太速速到他這裏來，就回去了。</span>
</div>
</div>

## 保羅在雅典

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="詩篇 119:158; 彼得後書 2:7; 詩篇 119:136"> 保羅在雅典等候他們的時候，看見滿城都是偶像，就心裏着急；</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行傳 13:16; 使徒行傳 14:1–4; 使徒行傳 17:2–4"> 於是在會堂裏與猶太人和虔敬的人，並每日在市上所遇見的人，辯論。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前書 1:20–21; 歌羅西書 2:8; 路加福音 11:53"> 還有伊壁鳩魯和斯多亞兩門的學士，與他爭論。有的說：「這胡言亂語的要說甚麼？」有的說：「他似乎是傳說外邦鬼神的。」這話是因保羅傳講耶穌與復活的道。</span>
<span className="v" id="v19" data-v="19" data-xref="馬可福音 1:27; 使徒行傳 17:22; 使徒行傳 24:24"> 他們就把他帶到亞略‧巴古，說：「你所講的這新道，我們也可以知道嗎？</span>
<span className="v" id="v20" data-v="20" data-xref="哥林多前書 1:23; 何西阿書 8:12; 哥林多前書 2:14"> 因為你有些奇怪的事傳到我們耳中，我們願意知道這些事是甚麼意思。」（</span>
<span className="v" id="v21" data-v="21" data-xref="提摩太後書 2:16–17; 歌羅西書 4:5; 以弗所書 5:16"> 雅典人和住在那裏的客人都不顧別的事，只將新聞說說聽聽。）</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="使徒行傳 25:19; 使徒行傳 19:35; 使徒行傳 17:16"> 保羅站在亞略‧巴古當中，說：「眾位雅典人哪，我看你們凡事很敬畏鬼神。</span>
<span className="v" id="v23" data-v="23" data-xref="約翰福音 4:22; 加拉太書 4:8–9; 約翰福音 17:3"> 我遊行的時候，觀看你們所敬拜的，遇見一座壇，上面寫着『未識之神』。你們所不認識而敬拜的，我現在告訴你們。</span>
<span className="v" id="v24" data-v="24" data-xref="列王紀上 8:27; 申命記 10:14; 使徒行傳 7:48"> 創造宇宙和其中萬物的上帝，既是天地的主，就不住人手所造的殿，</span>
<span className="v" id="v25" data-v="25" data-xref="詩篇 50:8–13; 創世記 2:7; 以賽亞書 42:5"> 也不用人手服事，好像缺少甚麼；自己倒將生命、氣息、萬物，賜給萬人。</span>
<span className="v" id="v26" data-v="26" data-xref="申命記 32:7–8; 創世記 3:20; 羅馬書 5:12–19"> 他從一本<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="本：有古卷是血脈">a</a></sup>造出萬族的人，住在全地上，並且預先定準他們的年限和所住的疆界，</span>
<span className="v" id="v27" data-v="27" data-xref="耶利米書 23:23–24; 申命記 4:7; 使徒行傳 14:17"> 要叫他們尋求上帝，或者可以揣摩而得，其實他離我們各人不遠；</span>
<span className="v" id="v28" data-v="28" data-xref="約伯記 12:10; 歌羅西書 1:17; 希伯來書 1:3"> 我們生活、動作、存留，都在乎他。就如你們作詩的，有人說：『我們也是他所生的。』</span>
<span className="v" id="v29" data-v="29" data-xref="以賽亞書 40:25; 出埃及記 20:4; 詩篇 115:4–8"> 我們既是上帝所生的，就不當以為上帝的神性像人用手藝、心思所雕刻的金、銀、石。</span>
<span className="v" id="v30" data-v="30" data-xref="使徒行傳 14:16; 提多書 2:11–12; 路加福音 24:47"> 世人蒙昧無知的時候，上帝並不監察，如今卻吩咐各處的人都要悔改。</span>
<span className="v" id="v31" data-v="31" data-xref="馬太福音 25:31–46; 彼得後書 3:7; 羅馬書 2:16"> 因為他已經定了日子，要藉着他所設立的人按公義審判天下，並且叫他從死裏復活，給萬人作可信的憑據。」</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="使徒行傳 17:18; 使徒行傳 26:8; 使徒行傳 25:19"> 眾人聽見從死裏復活的話，就有譏誚他的；又有人說：「我們再聽你講這個吧！」</span>
<span className="v" id="v33" data-v="33"> 於是保羅從他們當中出去了。</span>
<span className="v" id="v34" data-v="34" data-xref="使徒行傳 17:19; 羅馬書 11:5–6; 使徒行傳 13:48"> 但有幾個人貼近他，信了主，其中有亞略‧巴古的官丟尼修，並一個婦人，名叫大馬哩，還有別人一同信從。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行傳 24:16; 提摩太後書 1:3; 哥林多後書 1:12"> 保羅定睛看着公會的人，說：「弟兄們，我在上帝面前行事為人都是憑着良心，直到今日。」</span>
<span className="v" id="v2" data-v="2" data-xref="約翰福音 18:22; 使徒行傳 24:1; 彌迦書 5:1"> 大祭司亞拿尼亞就吩咐旁邊站着的人打他的嘴。</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 25:1–2; 約翰福音 7:51; 馬太福音 23:27–28"> 保羅對他說：「你這粉飾的牆，上帝要打你！你坐堂為的是按律法審問我，你竟違背律法，吩咐人打我嗎？」</span>
<span className="v" id="v4" data-v="4"> 站在旁邊的人說：「你辱罵上帝的大祭司嗎？」</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 22:28; 傳道書 10:20; 猶大書 1:8–9"> 保羅說：「弟兄們，我不曉得他是大祭司；經上記着說：『不可毀謗你百姓的官長。』」</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行傳 24:15; 使徒行傳 24:21; 使徒行傳 26:5–8"> 保羅看出大眾一半是撒都該人，一半是法利賽人，就在公會中大聲說：「弟兄們，我是法利賽人，也是法利賽人的子孫。我現在受審問，是為盼望死人復活。」</span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 55:9; 約翰福音 7:40–43; 馬太福音 10:34"> 說了這話，法利賽人和撒都該人就爭論起來，會眾分為兩黨。</span>
<span className="v" id="v8" data-v="8" data-xref="路加福音 20:27; 馬太福音 22:23; 馬可福音 12:18"> 因為撒都該人說，沒有復活，也沒有天使和鬼魂；法利賽人卻說，兩樣都有。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行傳 22:7; 使徒行傳 22:17–18; 約翰福音 12:29"> 於是大大地喧嚷起來。有幾個法利賽黨的文士站起來爭辯說：「我們看不出這人有甚麼惡處，倘若有鬼魂或是天使對他說過話，怎麼樣呢？」</span>
<span className="v" id="v10" data-v="10" data-xref="雅各書 1:19; 雅各書 3:14–2; 使徒行傳 22:24"> 那時大起爭吵，千夫長恐怕保羅被他們扯碎了，就吩咐兵丁下去，把他從眾人當中搶出來，帶進營樓去。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行傳 18:9; 使徒行傳 19:21; 提摩太後書 4:17"> 當夜，主站在保羅旁邊，說：「放心吧！你怎樣在耶路撒冷為我作見證，也必怎樣在羅馬為我作見證。」</span>
</div>
</div>

## 殺害保羅的陰謀

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="使徒行傳 23:30; 以賽亞書 8:9–10; 使徒行傳 23:21"> 到了天亮，猶太人同謀起誓，說：「若不先殺保羅就不吃不喝。」</span>
<span className="v" id="v13" data-v="13" data-xref="約翰福音 16:2; 撒母耳記下 15:31; 撒母耳記下 15:12"> 這樣同心起誓的有四十多人。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行傳 23:12; 耶利米書 8:12; 以賽亞書 3:9"> 他們來見祭司長和長老，說：「我們已經起了一個大誓，若不先殺保羅就不吃甚麼。</span>
<span className="v" id="v15" data-v="15" data-xref="以賽亞書 59:7; 詩篇 37:32–33; 箴言 1:16"> 現在你們和公會要知會千夫長，叫他帶下保羅到你們這裏來，假作要詳細察考他的事；我們已經預備好了，不等他來到跟前就殺他。」</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行傳 23:10; 哥林多前書 3:19; 使徒行傳 23:32"> 保羅的外甥聽見他們設下埋伏，就來到營樓裏告訴保羅。</span>
<span className="v" id="v17" data-v="17" data-xref="箴言 22:3; 馬太福音 8:8–9; 馬太福音 10:16"> 保羅請一個百夫長來，說：「你領這少年人去見千夫長，他有事告訴他。」</span>
<span className="v" id="v18" data-v="18" data-xref="以弗所書 3:1; 以弗所書 4:1; 使徒行傳 28:17"> 於是把他領去見千夫長，說：「被囚的保羅請我到他那裏，求我領這少年人來見你；他有事告訴你。」</span>
<span className="v" id="v19" data-v="19" data-xref="耶利米書 31:32; 以斯帖記 9:12; 以斯帖記 7:2"> 千夫長就拉着他的手，走到一旁，私下問他說：「你有甚麼事告訴我呢？」</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行傳 23:14–15; 使徒行傳 23:1; 詩篇 12:2"> 他說：「猶太人已經約定，要求你明天帶下保羅到公會裏去，假作要詳細查問他的事。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行傳 23:12–14; 使徒行傳 14:5–6; 哥林多後書 11:26"> 你切不要隨從他們；因為他們有四十多人埋伏，已經起誓說，若不先殺保羅就不吃不喝。現在預備好了，只等你應允。」</span>
<span className="v" id="v22" data-v="22" data-xref="馬可福音 1:44; 約書亞記 2:14"> 於是千夫長打發少年人走，囑咐他說：「不要告訴人你將這事報給我了。」</span>
</div>
</div>

## 保羅被解交腓力斯巡撫

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="馬太福音 14:25; 使徒行傳 23:33; 路加福音 12:38"> 千夫長便叫了兩個百夫長來，說：「預備步兵二百，馬兵七十，長槍手二百，今夜亥初往凱撒利亞去；</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行傳 25:14; 使徒行傳 23:26; 使徒行傳 24:10"> 也要預備牲口叫保羅騎上，護送到巡撫腓力斯那裏去。」</span>
<span className="v" id="v25" data-v="25"> 千夫長又寫了文書，</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行傳 15:23; 使徒行傳 26:25; 路加福音 1:3"> 大略說：「克勞第‧呂西亞，請巡撫腓力斯大人安。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行傳 22:25–29; 使徒行傳 21:31–33; 使徒行傳 24:6"> 這人被猶太人拿住，將要殺害，我得知他是羅馬人，就帶兵丁下去救他出來。</span>
<span className="v" id="v28" data-v="28" data-xref="使徒行傳 22:30"> 因要知道他們告他的緣故，我就帶他下到他們的公會去，</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行傳 26:31; 使徒行傳 25:25; 使徒行傳 18:15"> 便查知他被告是因他們律法的辯論，並沒有甚麼該死該綁的罪名。</span>
<span className="v" id="v30" data-v="30" data-xref="使徒行傳 23:35; 使徒行傳 25:16; 使徒行傳 25:5–6"> 後來有人把要害他的計謀告訴我，我就立時解他到你那裏去，又吩咐告他的人在你面前告他。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古卷加：願你平安！">a</a></sup>」</span>
<span className="v" id="v31" data-v="31" data-xref="提摩太後書 2:3–4; 路加福音 7:8; 使徒行傳 23:23–24"> 於是，兵丁照所吩咐他們的，將保羅夜裏帶到安提帕底。</span>
<span className="v" id="v32" data-v="32" data-xref="使徒行傳 23:23; 使徒行傳 23:10"> 第二天，讓馬兵護送，他們就回營樓去。</span>
<span className="v" id="v33" data-v="33" data-xref="使徒行傳 23:26; 使徒行傳 23:23–24; 使徒行傳 28:16"> 馬兵來到凱撒利亞，把文書呈給巡撫，便叫保羅站在他面前。</span>
<span className="v" id="v34" data-v="34" data-xref="使徒行傳 21:39; 使徒行傳 25:1; 但以理書 2:49"> 巡撫看了文書，問保羅是哪省的人，既曉得他是基利家人，</span>
<span className="v" id="v35" data-v="35" data-xref="使徒行傳 23:30; 使徒行傳 25:16; 馬太福音 27:27"> 就說：「等告你的人來到，我要細聽你的事」；便吩咐人把他看守在希律的衙門裏。</span>
</div>
</div>

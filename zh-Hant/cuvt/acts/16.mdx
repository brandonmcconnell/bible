## 提摩太跟保羅、西拉同工

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="提摩太後書 1:5; 提摩太後書 1:2; 哥林多前書 4:17"> 保羅來到特庇，又到路司得。在那裏有一個門徒，名叫提摩太，是信主之猶太婦人的兒子，他父親卻是希臘人。</span>
<span className="v" id="v2" data-v="2" data-xref="提摩太前書 5:10; 提摩太後書 3:15; 使徒行傳 14:21"> 路司得和以哥念的弟兄都稱讚他。</span>
<span className="v" id="v3" data-v="3" data-xref="加拉太書 2:3; 哥林多前書 9:20; 加拉太書 5:6"> 保羅要帶他同去，只因那些地方的猶太人都知道他父親是希臘人，就給他行了割禮。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行傳 15:28–29; 使徒行傳 15:2; 使徒行傳 11:30"> 他們經過各城，把耶路撒冷使徒和長老所定的條規交給門徒遵守。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行傳 9:31; 使徒行傳 2:47; 使徒行傳 6:7"> 於是眾教會信心越發堅固，人數天天加增。</span>
</div>
</div>

## 保羅看見馬其頓人的異象

<div className="bt">
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="使徒行傳 18:23; 使徒行傳 16:7; 使徒行傳 13:2–4"> 聖靈既然禁止他們在亞細亞講道，他們就經過弗呂家、加拉太一帶地方。</span>
<span className="v" id="v7" data-v="7" data-xref="羅馬書 8:9; 腓立比書 1:19; 加拉太書 4:6"> 到了每西亞的邊界，他們想要往庇推尼去，耶穌的靈卻不許。</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多後書 2:12; 提摩太後書 4:13; 使徒行傳 16:11"> 他們就越過每西亞，下到特羅亞去。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行傳 9:10–12; 使徒行傳 19:21; 使徒行傳 18:5"> 在夜間有異象現與保羅。有一個馬其頓人站着求他說：「請你過到馬其頓來幫助我們。」</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多後書 2:12–13; 使徒行傳 14:7; 使徒行傳 16:10–17"> 保羅既看見這異象，我們隨即想要往馬其頓去，以為上帝召我們傳福音給那裏的人聽。</span>
</div>
</div>

## 呂底亞歸主

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="使徒行傳 21:1; 使徒行傳 16:8"> 於是從特羅亞開船，一直行到撒摩特喇，第二天到了尼亞坡里。</span>
<span className="v" id="v12" data-v="12" data-xref="帖撒羅尼迦前書 2:2; 腓立比書 1:1; 使徒行傳 20:6"> 從那裏來到腓立比，就是馬其頓這一方的頭一個城，也是羅馬的駐防城。我們在這城裏住了幾天。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行傳 13:14; 歌羅西書 1:23; 使徒行傳 17:2"> 當安息日，我們出城門，到了河邊，知道那裏有一個禱告的地方，我們就坐下對那聚會的婦女講道。</span>
<span className="v" id="v14" data-v="14" data-xref="以弗所書 1:17–18; 路加福音 24:45; 以賽亞書 50:5"> 有一個賣紫色布疋的婦人，名叫呂底亞，是推雅推喇城的人，素來敬拜上帝。她聽見了，主就開導她的心，叫她留心聽保羅所講的話。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行傳 11:14; 希伯來書 13:2; 使徒行傳 16:33"> 她和她一家既領了洗，便求我們說：「你們若以為我是真信主的<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或譯：你們若以為我是忠心事主的">a</a></sup>，請到我家裏來住」；於是強留我們。</span>
</div>
</div>

## 在腓立比被囚

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="利未記 19:31; 申命記 18:9–11; 以賽亞書 8:19"> 後來，我們往那禱告的地方去。有一個使女迎着面來，她被巫鬼所附，用法術，叫她主人們大得財利。</span>
<span className="v" id="v17" data-v="17" data-xref="約翰福音 14:6; 彼得前書 2:16; 馬可福音 5:7"> 她跟隨保羅和我們，喊着說：「這些人是至高上帝的僕人，對你們傳說救人的道。」</span>
<span className="v" id="v18" data-v="18" data-xref="馬可福音 16:17; 路加福音 10:17–19; 使徒行傳 3:6"> 她一連多日這樣喊叫，保羅就心中厭煩，轉身對那鬼說：「我奉耶穌基督的名，吩咐你從她身上出來！」那鬼當時就出來了。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行傳 17:6; 使徒行傳 21:30; 使徒行傳 8:3"> 使女的主人們見得利的指望沒有了，便揪住保羅和西拉，拉他們到市上去見首領；</span>
<span className="v" id="v20" data-v="20" data-xref="雅各書 4:4; 約翰福音 15:18–20; 使徒行傳 28:22"> 又帶到官長面前說：「這些人原是猶太人，竟騷擾我們的城，</span>
<span className="v" id="v21" data-v="21" data-xref="以斯帖記 3:8; 使徒行傳 26:3; 耶利米書 10:3"> 傳我們羅馬人所不可受不可行的規矩。」</span>
<span className="v" id="v22" data-v="22" data-xref="帖撒羅尼迦前書 2:2; 哥林多後書 6:5; 哥林多後書 11:23–25"> 眾人就一同起來攻擊他們。官長吩咐剝了他們的衣裳，用棍打；</span>
<span className="v" id="v23" data-v="23" data-xref="啟示錄 2:10; 提摩太後書 2:9; 撒母耳記上 23:22–23"> 打了許多棍，便將他們下在監裏，囑咐禁卒嚴緊看守。</span>
<span className="v" id="v24" data-v="24" data-xref="約伯記 13:27; 約伯記 33:11; 耶利米書 29:26"> 禁卒領了這樣的命，就把他們下在內監裏，兩腳上了木狗。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="帖撒羅尼迦前書 5:16–18; 詩篇 119:62; 雅各書 1:2"> 約在半夜，保羅和西拉禱告，唱詩讚美上帝，眾囚犯也側耳而聽。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行傳 4:31; 使徒行傳 5:19; 使徒行傳 12:10"> 忽然，地大震動，甚至監牢的地基都搖動了，監門立刻全開，眾囚犯的鎖鍊也都鬆開了。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行傳 12:19; 馬太福音 27:5; 士師記 9:54"> 禁卒一醒，看見監門全開，以為囚犯已經逃走，就拔刀要自殺。</span>
<span className="v" id="v28" data-v="28" data-xref="帖撒羅尼迦前書 5:15; 路加福音 23:34; 路加福音 6:27–28"> 保羅大聲呼叫說：「不要傷害自己！我們都在這裏。」</span>
<span className="v" id="v29" data-v="29" data-xref="啟示錄 3:9; 使徒行傳 24:25; 以賽亞書 60:14"> 禁卒叫人拿燈來，就跳進去，戰戰兢兢地俯伏在保羅、西拉面前；</span>
<span className="v" id="v30" data-v="30" data-xref="使徒行傳 2:37; 約翰福音 6:27–29; 以賽亞書 58:9"> 又領他們出來，說：「二位先生，我當怎樣行才可以得救？」</span>
<span className="v" id="v31" data-v="31" data-xref="約翰福音 1:12; 使徒行傳 2:38–39; 約翰福音 3:36"> 他們說：「當信主耶穌，你和你一家都必得救。」</span>
<span className="v" id="v32" data-v="32" data-xref="羅馬書 1:16; 歌羅西書 1:27–28; 提摩太前書 1:13–16"> 他們就把主的道講給他和他全家的人聽。</span>
<span className="v" id="v33" data-v="33" data-xref="哥林多前書 1:16; 使徒行傳 16:15; 使徒行傳 16:25"> 當夜，就在那時候，禁卒把他們帶去，洗他們的傷；他和屬乎他的人立時都受了洗。</span>
<span className="v" id="v34" data-v="34" data-xref="羅馬書 15:13; 使徒行傳 2:46; 羅馬書 5:11"> 於是禁卒領他們上自己家裏去，給他們擺上飯。他和全家，因為信了上帝，都很喜樂。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="耶利米書 5:22; 詩篇 76:10; 使徒行傳 5:40"> 到了天亮，官長打發差役來，說：「釋放那兩個人吧。」</span>
<span className="v" id="v36" data-v="36" data-xref="使徒行傳 15:33; 約翰福音 14:27; 撒母耳記上 1:17"> 禁卒就把這話告訴保羅說：「官長打發人來叫釋放你們，如今可以出監，平平安安地去吧。」</span>
<span className="v" id="v37" data-v="37" data-xref="使徒行傳 22:25–29; 詩篇 58:1–2; 馬太福音 10:16"> 保羅卻說：「我們是羅馬人，並沒有定罪，他們就在眾人面前打了我們，又把我們下在監裏，現在要私下攆我們出去嗎？這是不行的。叫他們自己來領我們出去吧！」</span>
<span className="v" id="v38" data-v="38" data-xref="使徒行傳 22:29; 馬太福音 21:46; 馬太福音 14:5"> 差役把這話回稟官長。官長聽見他們是羅馬人，就害怕了，</span>
<span className="v" id="v39" data-v="39" data-xref="馬太福音 8:34; 馬可福音 5:17; 但以理書 6:23"> 於是來勸他們，領他們出來，請他們離開那城。</span>
<span className="v" id="v40" data-v="40" data-xref="帖撒羅尼迦前書 3:2–3; 使徒行傳 16:14; 使徒行傳 14:22"> 二人出了監，往呂底亞家裏去， 見了弟兄們，勸慰他們一番，就走了。</span>
</div>
</div>

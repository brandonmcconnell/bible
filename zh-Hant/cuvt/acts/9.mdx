## 掃羅的轉變

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行傳 8:3; 提摩太前書 1:13; 加拉太書 1:13"> 掃羅仍然向主的門徒口吐威嚇凶煞的話，去見大祭司，</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行傳 19:9; 使徒行傳 19:23; 使徒行傳 24:14"> 求文書給大馬士革的各會堂，若是找着信奉這道的人，無論男女，都准他捆綁帶到耶路撒冷。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行傳 26:12–13; 哥林多前書 15:8; 使徒行傳 22:6"> 掃羅行路，將到大馬士革，忽然從天上發光，四面照着他；</span>
<span className="v" id="v4" data-v="4" data-xref="撒迦利亞書 2:8; 創世記 22:11; 羅馬書 11:22"> 他就仆倒在地，聽見有聲音對他說：「掃羅！掃羅！你為甚麼逼迫我？」</span>
<span className="v" id="v5" data-v="5" data-xref="提摩太前書 1:13; 撒母耳記上 3:4–10; 約伯記 9:4"> 他說：「主啊！你是誰？」主說：「我就是你所逼迫的耶穌。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行傳 22:10; 使徒行傳 26:16; 提摩太前書 1:14–16"> 起來！進城去，你所當做的事，必有人告訴你。」</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行傳 22:9; 但以理書 10:7; 使徒行傳 26:13–14"> 同行的人站在那裏，說不出話來，聽見聲音，卻看不見人。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行傳 22:11; 使徒行傳 9:18; 列王紀下 6:17–20"> 掃羅從地上起來，睜開眼睛，竟不能看見甚麼。有人拉他的手，領他進了大馬士革；</span>
<span className="v" id="v9" data-v="9" data-xref="約拿書 3:6–8; 以斯帖記 4:16; 歷代志下 33:12–13"> 三日不能看見，也不吃也不喝。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="創世記 22:1; 使徒行傳 10:3; 使徒行傳 22:12"> 當下，在大馬士革有一個門徒，名叫亞拿尼亞。主在異象中對他說：「亞拿尼亞。」他說：「主，我在這裏。」</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行傳 21:39; 使徒行傳 22:3; 使徒行傳 9:30"> 主對他說：「起來！往直街去，在猶大的家裏，訪問一個大數人，名叫掃羅。他正禱告，</span>
<span className="v" id="v12" data-v="12" data-xref="馬可福音 5:23; 使徒行傳 9:10; 使徒行傳 9:17–18"> 又看見了一個人，名叫亞拿尼亞，進來按手在他身上，叫他能看見。」</span>
<span className="v" id="v13" data-v="13" data-xref="提摩太前書 1:13–15; 使徒行傳 8:3; 使徒行傳 22:19–20"> 亞拿尼亞回答說：「主啊，我聽見許多人說，這人怎樣在耶路撒冷多多苦害你的聖徒，</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行傳 9:21; 使徒行傳 7:59; 提摩太後書 2:22"> 並且他在這裏有從祭司長得來的權柄捆綁一切求告你名的人。」</span>
<span className="v" id="v15" data-v="15" data-xref="加拉太書 1:15–16; 以弗所書 3:7–8; 提摩太後書 4:16–17"> 主對亞拿尼亞說：「你只管去！他是我所揀選的器皿，要在外邦人和君王，並以色列人面前宣揚我的名。</span>
<span className="v" id="v16" data-v="16" data-xref="帖撒羅尼迦前書 3:3; 使徒行傳 21:11; 哥林多後書 6:4"> 我也要指示他，為我的名必須受許多的苦難。」</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行傳 8:17; 使徒行傳 6:6; 使徒行傳 2:4"> 亞拿尼亞就去了，進入那家，把手按在掃羅身上，說：「兄弟掃羅，在你來的路上向你顯現的主，就是耶穌，打發我來，叫你能看見，又被聖靈充滿。」</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多後書 3:14; 使徒行傳 22:16; 使徒行傳 2:38"> 掃羅的眼睛上，好像有鱗立刻掉下來，他就能看見。於是起來受了洗；</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行傳 26:20; 撒母耳記上 30:12; 加拉太書 1:17"> 吃過飯就健壯了。 掃羅在大馬士革傳道<br />掃羅和大馬士革的門徒同住了些日子，</span>
<span className="v" id="v20" data-v="20" data-xref="約翰福音 20:28; 加拉太書 2:20; 約翰一書 4:14–15"> 就在各會堂裏宣傳耶穌，說他是上帝的兒子。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行傳 9:13–14; 使徒行傳 8:3; 帖撒羅尼迦後書 1:10"> 凡聽見的人都驚奇，說：「在耶路撒冷殘害求告這名的，不是這人嗎？並且他到這裏來，特要捆綁他們，帶到祭司長那裏。」</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行傳 18:5; 以賽亞書 40:29; 路加福音 21:15"> 但掃羅越發有能力，駁倒住大馬士革的猶太人，證明耶穌是基督。</span>
</div>
</div>

## 未受猶太人的謀害

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="加拉太書 1:17–18; 帖撒羅尼迦前書 2:15–16; 使徒行傳 14:19"> 過了好些日子，猶太人商議要殺掃羅，</span>
<span className="v" id="v24" data-v="24" data-xref="哥林多後書 11:32; 使徒行傳 25:3; 使徒行傳 20:3"> 但他們的計謀被掃羅知道了。他們又晝夜在城門守候，要殺他。</span>
<span className="v" id="v25" data-v="25" data-xref="約書亞記 2:15; 哥林多後書 11:33; 撒母耳記上 19:11–12"> 他的門徒就在夜間用筐子把他從城牆上縋下去。</span>
</div>
</div>

## 掃羅在耶路撒冷

<div className="bt">
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="使徒行傳 26:20; 加拉太書 1:17–19; 使徒行傳 9:19"> 掃羅到了耶路撒冷，想與門徒結交，他們卻都怕他，不信他是門徒。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行傳 4:36; 使徒行傳 4:29; 使徒行傳 4:13"> 惟有巴拿巴接待他，領去見使徒，把他在路上怎麼看見主，主怎麼向他說話，他在大馬士革怎麼奉耶穌的名放膽傳道，都述說出來。</span>
<span className="v" id="v28" data-v="28" data-xref="使徒行傳 1:21; 民數記 27:16–17; 詩篇 121:8"> 於是掃羅在耶路撒冷和門徒出入來往，</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行傳 6:1; 猶大書 1:9; 使徒行傳 11:20"> 奉主的名放膽傳道，並與說希臘話的猶太人講論辯駁；他們卻想法子要殺他。</span>
<span className="v" id="v30" data-v="30" data-xref="使徒行傳 11:25; 使徒行傳 8:40; 使徒行傳 9:11"> 弟兄們知道了就送他下凱撒利亞，打發他往大數去。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="詩篇 111:10; 約翰福音 14:16–18; 以賽亞書 33:6"> 那時，猶太、加利利、撒馬利亞各處的教會都得平安，被建立；凡事敬畏主，蒙聖靈的安慰，人數就增多了。</span>
</div>
</div>

## 以尼雅得醫治

<div className="bt">
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="使徒行傳 9:13; 使徒行傳 8:25; 箴言 2:8"> 彼得周流四方的時候，也到了居住呂大的聖徒那裏；</span>
<span className="v" id="v33" data-v="33" data-xref="路加福音 13:16; 約翰福音 5:5; 馬可福音 2:3–11"> 遇見一個人，名叫以尼雅，得了癱瘓，在褥子上躺臥八年。</span>
<span className="v" id="v34" data-v="34" data-xref="馬太福音 9:6; 使徒行傳 3:12; 使徒行傳 3:6"> 彼得對他說：「以尼雅，耶穌基督醫好你了， 起來！收拾你的褥子。」他就立刻起來了。</span>
<span className="v" id="v35" data-v="35" data-xref="使徒行傳 11:21; 使徒行傳 9:42; 歷代志上 5:16"> 凡住呂大和沙崙的人都看見了他，就歸服主。</span>
</div>
</div>

## 多加復活

<div className="bt">
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="提多書 3:8; 提多書 2:7; 歷代志下 2:16"> 在約帕有一個女徒，名叫大比大，翻希臘話就是多加<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="就是羚羊的意思">a</a></sup>；她廣行善事，多施賙濟。</span>
<span className="v" id="v37" data-v="37" data-xref="使徒行傳 1:13; 使徒行傳 20:8; 約翰福音 11:36–37"> 當時，她患病而死，有人把她洗了，停在樓上。</span>
<span className="v" id="v38" data-v="38" data-xref="使徒行傳 9:36; 使徒行傳 11:26; 使徒行傳 9:32"> 呂大原與約帕相近；門徒聽見彼得在那裏，就打發兩個人去見他，央求他說：「快到我們那裏去，不要耽延。」</span>
<span className="v" id="v39" data-v="39" data-xref="箴言 10:7; 箴言 31:30–31; 帖撒羅尼迦前書 1:3"> 彼得就起身和他們同去；到了，便有人領他上樓。眾寡婦都站在彼得旁邊哭，拿多加與她們同在時所做的裏衣外衣給他看。</span>
<span className="v" id="v40" data-v="40" data-xref="馬太福音 9:25; 馬可福音 5:40–42; 路加福音 8:54"> 彼得叫她們都出去，就跪下禱告，轉身對着死人說：「大比大，起來！」她就睜開眼睛，見了彼得，便坐起來。</span>
<span className="v" id="v41" data-v="41" data-xref="馬可福音 1:31; 使徒行傳 6:1; 創世記 45:26"> 彼得伸手扶她起來，叫眾聖徒和寡婦進去，把多加活活地交給他們。</span>
<span className="v" id="v42" data-v="42" data-xref="約翰福音 12:44; 約翰福音 12:11; 約翰福音 11:45"> 這事傳遍了約帕，就有許多人信了主。</span>
<span className="v" id="v43" data-v="43" data-xref="使徒行傳 10:6; 使徒行傳 10:32"> 此後，彼得在約帕一個硝皮匠西門的家裏住了多日。</span>
</div>

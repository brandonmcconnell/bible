## 聖靈降臨

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="羅馬書 15:6; 腓立比書 2:2; 使徒行傳 1:13–15"> 五旬節到了，門徒都聚集在一處。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行傳 4:31; 列王紀上 19:11; 詩篇 18:10"> 忽然，從天上有響聲下來，好像一陣大風吹過，充滿了他們所坐的屋子，</span>
<span className="v" id="v3" data-v="3" data-xref="馬太福音 3:11; 約翰福音 1:32–33; 耶利米書 23:29"> 又有舌頭如火焰顯現出來，分開落在他們各人頭上。</span>
<span className="v" id="v4" data-v="4" data-xref="馬可福音 16:17; 使徒行傳 13:52; 使徒行傳 4:31"> 他們就都被聖靈充滿，按着聖靈所賜的口才說起別國的話來。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="路加福音 2:25; 使徒行傳 8:2; 歌羅西書 1:23"> 那時，有虔誠的猶太人從天下各國來，住在耶路撒冷。</span>
<span className="v" id="v6" data-v="6" data-xref="馬太福音 2:3; 哥林多前書 16:9; 使徒行傳 2:2"> 這聲音一響，眾人都來聚集，各人聽見門徒用眾人的鄉談說話，就甚納悶；</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行傳 2:12; 使徒行傳 1:11; 約翰福音 7:52"> 都驚訝希奇說：「看哪，這說話的不都是加利利人嗎？</span>
<span className="v" id="v8" data-v="8"> 我們各人怎麼聽見他們說我們生來所用的鄉談呢？</span>
<span className="v" id="v9" data-v="9" data-xref="彼得前書 1:1; 使徒行傳 18:2; 啟示錄 1:4"> 我們帕提亞人、米底亞人、以攔人，和住在美索不達米亞、猶太、加帕多家、本都、亞細亞、</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行傳 16:6; 撒迦利亞書 8:23; 撒迦利亞書 8:20"> 弗呂家、旁非利亞、埃及的人，並靠近古利奈的利比亞一帶地方的人，從羅馬來的客旅中，或是猶太人，或是進猶太教的人，</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多前書 12:10; 出埃及記 15:11; 詩篇 78:4"> 克里特和阿拉伯人，都聽見他們用我們的鄉談，講說上帝的大作為。」</span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 15:26; 使徒行傳 17:20; 路加福音 18:36"> 眾人就都驚訝猜疑，彼此說：「這是甚麼意思呢？」</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多前書 14:23; 使徒行傳 2:15; 撒母耳記上 1:14"> 還有人譏誚說：「他們無非是新酒灌滿了。」</span>
</div>
</div>

## 彼得在五旬節的講論

<div className="bt">
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="以賽亞書 51:7; 以賽亞書 51:1; 申命記 27:9"> 彼得和十一個使徒站起，高聲說：「猶太人和一切住在耶路撒冷的人哪，這件事你們當知道，也當側耳聽我的話。</span>
<span className="v" id="v15" data-v="15" data-xref="帖撒羅尼迦前書 5:5–8; 撒母耳記上 1:15; 馬太福音 20:3"> 你們想這些人是醉了；其實不是醉了，因為時候剛到巳初。</span>
<span className="v" id="v16" data-v="16" data-xref="約珥書 2:28–32"> 這正是先知約珥所說的：</span>
<span className="v" id="v17" data-v="17" data-xref="約珥書 2:28–32; 以賽亞書 44:3; 提多書 3:4–6"> <span className="pl pl-1">上帝說：在末後的日子，</span><br /><span className="pl pl-1">我要將我的靈澆灌凡有血氣的。</span><br /><span className="pl pl-1">你們的兒女要說預言；</span><br /><span className="pl pl-1">你們的少年人要見異象；</span><br /><span className="pl pl-1">老年人要做異夢。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="加拉太書 3:28; 歌羅西書 3:11; 哥林多前書 7:21–22"> <span className="pl pl-1">在那些日子，</span><br /><span className="pl pl-1">我要將我的靈澆灌我的僕人和使女，</span><br /><span className="pl pl-1">他們就要說預言。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="約珥書 2:30–31; 西番雅書 1:14–18; 瑪拉基書 4:1–6"> <span className="pl pl-1">在天上，我要顯出奇事；</span><br /><span className="pl pl-1">在地下， 我要顯出神蹟；</span><br /><span className="pl pl-1">有血，有火，有煙霧。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="彼得後書 3:10; 阿摩司書 8:9; 馬太福音 24:29"> <span className="pl pl-1">日頭要變為黑暗，</span><br /><span className="pl pl-1">月亮要變為血；</span><br /><span className="pl pl-1">這都在主大而明顯的日子未到以前。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="羅馬書 10:12–13; 約珥書 2:32; 詩篇 86:5"> <span className="pl pl-1">到那時候，</span><br /><span className="pl pl-1">凡求告主名的，就必得救。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v22" data-v="22" data-xref="約翰福音 3:2; 約翰福音 14:10–11; 馬太福音 12:28"> 「以色列人哪，請聽我的話：上帝藉着拿撒勒人耶穌在你們中間施行異能、奇事、神蹟，將他證明出來，這是你們自己知道的。</span>
<span className="v" id="v23" data-v="23" data-xref="路加福音 22:22; 使徒行傳 4:28; 使徒行傳 3:18"> 他既按着上帝的定旨先見被交與人，你們就藉着無法之人的手，把他釘在十字架上，殺了。</span>
<span className="v" id="v24" data-v="24" data-xref="哥林多前書 6:14; 彼得前書 1:21; 使徒行傳 2:32"> 上帝卻將死的痛苦解釋了，叫他復活，因為他原不能被死拘禁。</span>
<span className="v" id="v25" data-v="25" data-xref="詩篇 16:8–11; 以賽亞書 41:13; 詩篇 62:6"> 大衛指着他說：<br /><span className="pl pl-1">我看見主常在我眼前；</span><br /><span className="pl pl-1">他在我右邊，叫我不至於搖動。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v26" data-v="26" data-xref="詩篇 16:9; 詩篇 63:5; 詩篇 71:23"> 所以，我心裏歡喜，<br /><span className="pl pl-1">我的靈</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是舌">a</a></sup><br /><span className="pl pl-1">快樂；</span><br /><span className="pl pl-1">並且我的肉身要安居在指望中。</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="詩篇 16:10; 使徒行傳 2:31; 啟示錄 1:18"> <span className="pl pl-1">因你必不將我的靈魂撇在陰間，</span><br /><span className="pl pl-1">也不叫你的聖者見朽壞。</span><br /></span>
<span className="v" id="v28" data-v="28" data-xref="詩篇 16:11; 詩篇 25:4; 詩篇 21:6"> <span className="pl pl-1">你已將生命的道路指示我，</span><br /><span className="pl pl-1">必叫我因見你的面</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或譯：叫我在你面前">b</a></sup><br /><span className="pl pl-1">得着滿足的快樂。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v29" data-v="29" data-xref="使徒行傳 13:36; 列王紀上 2:10; 使徒行傳 7:8–9"> 「弟兄們！先祖大衛的事，我可以明明地對你們說：他死了，也葬埋了，並且他的墳墓直到今日還在我們這裏。</span>
<span className="v" id="v30" data-v="30" data-xref="詩篇 132:11–18; 詩篇 89:3–4; 耶利米書 33:14–15"> 大衛既是先知，又曉得上帝曾向他起誓，要從他的後裔中立一位坐在他的寶座上，</span>
<span className="v" id="v31" data-v="31" data-xref="使徒行傳 2:27; 詩篇 16:10; 使徒行傳 13:35"> 就預先看明這事，講論基督復活說：<br /><span className="pl pl-1">他的靈魂不撇在陰間；</span><br /><span className="pl pl-1">他的肉身也不見朽壞。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v32" data-v="32" data-xref="使徒行傳 3:15; 使徒行傳 1:8; 使徒行傳 1:22"> 這耶穌，上帝已經叫他復活了，我們都為這事作見證。</span>
<span className="v" id="v33" data-v="33" data-xref="使徒行傳 1:4; 使徒行傳 5:31; 使徒行傳 2:17"> 他既被上帝的右手高舉<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="或譯：他既高舉在上帝的右邊">c</a></sup>，又從父受了所應許的聖靈，就把你們所看見所聽見的，澆灌下來。</span>
<span className="v" id="v34" data-v="34" data-xref="詩篇 110:1; 馬太福音 22:42–45; 希伯來書 1:13"> 大衛並沒有升到天上，但自己說：<br /><span className="pl pl-1">主對我主說：</span><br /><span className="pl pl-1">你坐在我的右邊，</span></span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="啟示錄 19:19–3; 羅馬書 16:20; 以賽亞書 60:14"> 等我使你仇敵作你的腳凳。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="使徒行傳 5:30–31; 羅馬書 14:8–12; 哥林多後書 5:10"> 「故此，以色列全家當確實地知道，你們釘在十字架上的這位耶穌，上帝已經立他為主，為基督了。」</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="路加福音 3:10; 使徒行傳 22:10; 希伯來書 4:12–13"> 眾人聽見這話，覺得扎心，就對彼得和其餘的使徒說：「弟兄們，我們當怎樣行？」</span>
<span className="v" id="v38" data-v="38" data-xref="使徒行傳 22:16; 馬可福音 16:16; 使徒行傳 8:12"> 彼得說：「你們各人要悔改，奉耶穌基督的名受洗，叫你們的罪得赦，就必領受所賜的聖靈；</span>
<span className="v" id="v39" data-v="39" data-xref="以賽亞書 44:3; 創世記 17:7–8; 羅馬書 8:30"> 因為這應許是給你們和你們的兒女，並一切在遠方的人，就是主－我們上帝所召來的。」</span>
<span className="v" id="v40" data-v="40" data-xref="腓立比書 2:15; 申命記 32:5; 馬太福音 17:17"> 彼得還用許多話作見證，勸勉他們說：「你們當救自己脫離這彎曲的世代。」</span>
<span className="v" id="v41" data-v="41" data-xref="使徒行傳 4:4; 使徒行傳 2:47; 使徒行傳 16:31–34"> 於是領受他話的人就受了洗。那一天，門徒約添了三千人，</span>
<span className="v" id="v42" data-v="42" data-xref="希伯來書 10:25; 使徒行傳 1:14; 約翰一書 1:3"> 都恆心遵守使徒的教訓，彼此交接，擘餅，祈禱。</span>
</div>
</div>

## 在聖徒中間的生活

<div className="bt">
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="路加福音 7:16; 約翰福音 14:12; 路加福音 8:37"> 眾人都懼怕；使徒又行了許多奇事神蹟。</span>
<span className="v" id="v44" data-v="44" data-xref="使徒行傳 4:32; 約翰一書 3:16–18; 哥林多後書 8:14–15"> 信的人都在一處，凡物公用，</span>
<span className="v" id="v45" data-v="45" data-xref="約翰一書 3:17; 提摩太前書 6:18–19; 雅各書 2:14–16"> 並且賣了田產、家業，照各人所需用的分給各人。</span>
<span className="v" id="v46" data-v="46" data-xref="使徒行傳 5:42; 使徒行傳 20:7; 使徒行傳 2:42"> 他們天天同心合意恆切地在殿裏，且在家中擘餅，存着歡喜、誠實的心用飯，</span>
<span className="v" id="v47" data-v="47" data-xref="使徒行傳 16:5; 使徒行傳 5:13–14; 使徒行傳 2:41"> 讚美上帝，得眾民的喜愛。主將得救的人天天加給他們。</span>
</div>

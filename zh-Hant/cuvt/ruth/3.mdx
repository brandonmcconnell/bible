## 拿俄米替路得找歸宿

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路得記 1:9; 提摩太前書 5:8; 提摩太前書 5:14"> 路得的婆婆拿俄米對她說：「女兒啊，我不當為你找個安身之處，使你享福嗎？</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 25:5–10; 路得記 2:20–23; 路得記 2:8"> 你與波阿斯的使女常在一處，波阿斯不是我們的親族嗎？他今夜在場上簸大麥；</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳記下 14:2; 提摩太前書 2:9–10; 以斯帖記 5:1"> 你要沐浴抹膏，換上衣服，下到場上，卻不要使那人認出你來。你等他吃喝完了，</span>
<span className="v" id="v4" data-v="4" data-xref="帖撒羅尼迦前書 5:22"> 到他睡的時候，你看準他睡的地方，就進去掀開他腳上的被，躺臥在那裏，他必告訴你所當做的事。」</span>
<span className="v" id="v5" data-v="5" data-xref="歌羅西書 3:20; 以弗所書 6:1"> 路得說：「凡你所吩咐的，我必遵行。」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="箴言 1:8; 約翰福音 2:5; 出埃及記 20:12"> 路得就下到場上，照她婆婆所吩咐她的而行。</span>
<span className="v" id="v7" data-v="7" data-xref="士師記 19:6; 以斯帖記 1:10; 撒母耳記下 13:28"> 波阿斯吃喝完了，心裏歡暢，就去睡在麥堆旁邊。路得便悄悄地來掀開他腳上的被，躺臥在那裏。</span>
<span className="v" id="v8" data-v="8"> 到了夜半，那人忽然驚醒，翻過身來，不料有女子躺在他的腳下。</span>
<span className="v" id="v9" data-v="9" data-xref="以西結書 16:8; 路得記 2:20; 路得記 3:12"> 他就說：「你是誰？」回答說：「我是你的婢女路得。求你用你的衣襟遮蓋我，因為你是我一個至近的親屬。」</span>
<span className="v" id="v10" data-v="10" data-xref="路得記 2:20; 哥林多前書 13:4–5; 路得記 1:8"> 波阿斯說：「女兒啊，願你蒙耶和華賜福。你末後的恩比先前更大；因為少年人無論貧富，你都沒有跟從。</span>
<span className="v" id="v11" data-v="11" data-xref="箴言 31:29–31; 箴言 31:10; 箴言 12:4"> 女兒啊，現在不要懼怕，凡你所說的，我必照着行；我本城的人都知道你是個賢德的女子。</span>
<span className="v" id="v12" data-v="12" data-xref="路得記 4:1; 帖撒羅尼迦前書 4:6; 馬太福音 7:12"> 我實在是你一個至近的親屬，只是還有一個人比我更近。</span>
<span className="v" id="v13" data-v="13" data-xref="路得記 4:5; 耶利米書 4:2; 路得記 2:20"> 你今夜在這裏住宿，明早他若肯為你盡親屬的本分，就由他吧！倘若不肯，我指着永生的耶和華起誓，我必為你盡了本分，你只管躺到天亮。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="哥林多後書 8:21; 羅馬書 14:16; 哥林多前書 10:32"> 路得便在他腳下躺到天快亮，人彼此不能辨認的時候就起來了。波阿斯說：「不可使人知道有女子到場上來」；</span>
<span className="v" id="v15" data-v="15" data-xref="以賽亞書 32:8; 加拉太書 6:10"> 又對路得說：「打開你所披的外衣。」她打開了，波阿斯就撮了六簸箕大麥，幫她扛在肩上，她便進城去了。</span>
<span className="v" id="v16" data-v="16"> 路得回到婆婆那裏，婆婆說：「女兒啊，怎麼樣了？」路得就將那人向她所行的述說了一遍，</span>
<span className="v" id="v17" data-v="17"> 又說：「那人給了我六簸箕大麥，對我說：『你不可空手回去見你的婆婆。』」</span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 37:3–5; 以賽亞書 28:16; 以賽亞書 30:7"> 婆婆說：「女兒啊，你只管安坐等候，看這事怎樣成就，因為那人今日不辦成這事必不休息。」</span>
</div>
</div>

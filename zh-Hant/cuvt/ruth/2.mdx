## 路得在波阿斯田裏撿麥穗

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路得記 4:21; 路得記 3:12; 路得記 3:2"> 拿俄米的丈夫以利米勒的親族中，有一個人名叫波阿斯，是個大財主。</span>
<span className="v" id="v2" data-v="2" data-xref="利未記 23:22; 利未記 19:9; 申命記 24:19–21"> 摩押女子路得對拿俄米說：「容我往田間去，我蒙誰的恩，就在誰的身後拾取麥穗。」拿俄米說：「女兒啊，你只管去。」</span>
<span className="v" id="v3" data-v="3" data-xref="帖撒羅尼迦後書 3:12; 馬太福音 10:29; 路加福音 10:31"> 路得就去了，來到田間，在收割的人身後拾取麥穗。她恰巧到了以利米勒本族的人波阿斯那塊田裏。</span>
<span className="v" id="v4" data-v="4" data-xref="詩篇 129:7–8; 士師記 6:12; 路加福音 1:28"> 波阿斯正從伯利恆來，對收割的人說：「願耶和華與你們同在！」他們回答說：「願耶和華賜福與你！」</span>
<span className="v" id="v5" data-v="5" data-xref="路得記 4:21; 歷代志上 2:11–12"> 波阿斯問監管收割的僕人說：「那是誰家的女子？」</span>
<span className="v" id="v6" data-v="6" data-xref="路得記 1:22; 馬太福音 24:45; 創世記 24:2"> 監管收割的僕人回答說：「是那摩押女子，跟隨拿俄米從摩押地回來的。</span>
<span className="v" id="v7" data-v="7" data-xref="箴言 13:4; 箴言 18:23; 箴言 15:33"> 她說：『請你容我跟着收割的人拾取打捆剩下的麥穗。』她從早晨直到如今，除了在屋子裏坐一會兒，常在這裏。」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="列王紀下 5:13; 雅歌 1:7–8; 撒母耳記上 3:6"> 波阿斯對路得說：「女兒啊，聽我說，不要往別人田裏拾取麥穗，也不要離開這裏，要常與我使女們在一處。</span>
<span className="v" id="v9" data-v="9" data-xref="約翰一書 5:18; 創世記 20:6; 箴言 6:29"> 我的僕人在那塊田收割，你就跟着他們去。我已經吩咐僕人不可欺負你；你若渴了，就可以到器皿那裏喝僕人打來的水。」</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳記上 25:23; 路得記 2:13; 路加福音 1:43"> 路得就俯伏在地叩拜，對他說：「我既是外邦人，怎麼蒙你的恩，這樣顧恤我呢？」</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 14:33; 路加福音 18:29–30; 路加福音 5:11"> 波阿斯回答說：「自從你丈夫死後，凡你向婆婆所行的，並你離開父母和本地，到素不認識的民中，這些事人全都告訴我了。</span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 36:7; 詩篇 91:4; 詩篇 63:7"> 願耶和華照你所行的賞賜你。你來投靠耶和華－以色列上帝的翅膀下，願你滿得他的賞賜。」</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳記上 1:18; 創世記 34:3; 創世記 33:8"> 路得說：「我主啊，願在你眼前蒙恩。我雖然不及你的一個使女，你還用慈愛的話安慰我的心。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="路得記 2:18; 列王紀下 4:43–44; 馬太福音 14:20"> 到了吃飯的時候，波阿斯對路得說：「你到這裏來吃餅，將餅蘸在醋裏。」路得就在收割的人旁邊坐下；他們把烘了的穗子遞給她。她吃飽了，還有餘剩的。</span>
<span className="v" id="v15" data-v="15" data-xref="雅各書 1:5"> 她起來又拾取麥穗，波阿斯吩咐僕人說：「她就是在捆中拾取麥穗，也可以容她，不可羞辱她；</span>
<span className="v" id="v16" data-v="16" data-xref="羅馬書 12:13; 約翰一書 3:17–18; 申命記 24:19–21"> 並要從捆裏抽出些來，留在地下任她拾取，不可叱嚇她。」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="以西結書 45:11–12; 箴言 31:27; 出埃及記 16:36"> 這樣，路得在田間拾取麥穗，直到晚上，將所拾取的打了，約有一伊法大麥。</span>
<span className="v" id="v18" data-v="18" data-xref="路得記 2:14; 約翰福音 6:12–13; 提摩太前書 5:4"> 她就把所拾取的帶進城去給婆婆看，又把她吃飽了所剩的給了婆婆。</span>
<span className="v" id="v19" data-v="19" data-xref="路得記 2:10; 詩篇 41:1; 列王紀上 7:21"> 婆婆問她說：「你今日在哪裏拾取麥穗，在哪裏做工呢？願那顧恤你的得福。」路得就告訴婆婆說：「我今日在一個名叫波阿斯的人那裏做工。」</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳記下 2:5; 路得記 3:9–10; 利未記 25:25"> 拿俄米對兒婦說：「願那人蒙耶和華賜福，因為他不斷地恩待活人死人。」拿俄米又說：「那是我們本族的人，是一個至近的親屬。」</span>
<span className="v" id="v21" data-v="21" data-xref="雅歌 1:7–8; 路得記 2:7–8; 路得記 2:22"> 摩押女子路得說：「他對我說：『你要緊隨我的僕人拾取麥穗，直等他們收完了我的莊稼。』」</span>
<span className="v" id="v22" data-v="22" data-xref="雅歌 1:8; 箴言 27:10"> 拿俄米對兒婦路得說：「女兒啊，你跟着他的使女出去，不叫人遇見你在別人田間，這才為好。」</span>
<span className="v" id="v23" data-v="23" data-xref="箴言 6:6–8; 申命記 16:9; 以弗所書 6:1–3"> 於是路得與波阿斯的使女常在一處拾取麥穗，直到收完了大麥和小麥。路得仍與婆婆同住。</span>
</div>
</div>

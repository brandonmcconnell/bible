## 耶路撒冷的混亂

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="利未記 26:26; 以西結書 14:13; 以賽亞書 1:24"> <span className="pl pl-1">主－萬軍之耶和華從耶路撒冷和猶大，</span><br /><span className="pl pl-1">除掉眾人所倚靠的，所仗賴的，</span><br /><span className="pl pl-1">就是所倚靠的糧，所仗賴的水；</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="以賽亞書 9:14–15; 列王紀下 24:14–16; 耶利米哀歌 5:12–14"> <span className="pl pl-1">除掉勇士和戰士，</span><br /><span className="pl pl-1">審判官和先知，</span><br /><span className="pl pl-1">占卜的和長老，</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="士師記 8:18; 申命記 1:15; 出埃及記 18:21"> <span className="pl pl-1">五十夫長和尊貴人，</span><br /><span className="pl pl-1">謀士和有巧藝的，</span><br /><span className="pl pl-1">以及妙行法術的。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="傳道書 10:16; 歷代志下 33:1; 列王紀上 3:7–9"> <span className="pl pl-1">主說：我必使孩童作他們的首領，</span><br /><span className="pl pl-1">使嬰孩轄管他們。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="耶利米書 9:3–8; 瑪拉基書 3:5; 馬太福音 27:28–30"> <span className="pl pl-1">百姓要彼此欺壓；</span><br /><span className="pl pl-1">各人受鄰舍的欺壓。</span><br /><span className="pl pl-1">少年人必侮慢老年人；</span><br /><span className="pl pl-1">卑賤人必侮慢尊貴人。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="以賽亞書 4:1; 約翰福音 6:15; 士師記 11:6–8"> <span className="pl pl-1">人在父家拉住弟兄，說：</span><br /><span className="pl pl-1">你有衣服，可以作我們的官長。</span><br /><span className="pl pl-1">這敗落的事歸在你手下吧！</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="何西阿書 5:13; 耶利米哀歌 2:13; 以西結書 34:4"> <span className="pl pl-1">那時，他必揚聲說：</span><br /><span className="pl pl-1">我不作醫治你們的人；</span><br /><span className="pl pl-1">因我家中沒有糧食，也沒有衣服，</span><br /><span className="pl pl-1">你們不可立我作百姓的官長。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="哥林多前書 10:22; 以西結書 9:9; 瑪拉基書 3:13–15"> <span className="pl pl-1">耶路撒冷敗落，</span><br /><span className="pl pl-1">猶大傾倒；</span><br /><span className="pl pl-1">因為他們的舌頭和行為與耶和華反對，</span><br /><span className="pl pl-1">惹了他榮光的眼目。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="創世記 13:13; 創世記 18:20–21; 列王紀下 9:30"> <span className="pl pl-1">他們的面色證明自己的不正；</span><br /><span className="pl pl-1">他們述說自己的罪惡，並不隱瞞，</span><br /><span className="pl pl-1">好像所多瑪一樣。</span><br /><span className="pl pl-1">他們有禍了！因為作惡自害。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 128:1–2; 希伯來書 6:10; 傳道書 8:12"> <span className="pl pl-1">你們要論義人說：他必享福樂，</span><br /><span className="pl pl-1">因為要吃自己行為所結的果子。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="傳道書 8:13; 雅各書 2:13; 詩篇 62:12"> <span className="pl pl-1">惡人有禍了！他必遭災難！</span><br /><span className="pl pl-1">因為要照自己手所行的受報應。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="以賽亞書 3:4; 那鴻書 3:13; 列王紀下 11:1"> <span className="pl pl-1">至於我的百姓，</span><br /><span className="pl pl-1">孩童欺壓他們，</span><br /><span className="pl pl-1">婦女轄管他們。</span><br /><span className="pl pl-1">我的百姓啊，引導你的使你走錯，</span><br /><span className="pl pl-1">並毀壞你所行的道路。</span></span>
</div>
</div>

## 耶和華審判他的子民

<div className="bt">
<div className="bp poetry">
<span className="v" id="v13" data-v="13" data-xref="彌迦書 6:2; 何西阿書 4:1–2; 箴言 22:22–23"> <span className="pl pl-1">耶和華起來辯論，</span><br /><span className="pl pl-1">站着審判眾民。</span><br /></span>

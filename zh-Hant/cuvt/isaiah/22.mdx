## 論耶路撒冷的信息

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="耶利米書 21:13; 詩篇 125:2; 約珥書 3:12"> 論異象谷的默示：<br /><span className="pl pl-1">有甚麼事使你這滿城的人都上房頂呢？</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="以賽亞書 32:13; 以賽亞書 23:7; 耶利米哀歌 2:20"> <span className="pl pl-1">你這滿處吶喊、大有喧嘩的城，</span><br /><span className="pl pl-1">歡樂的邑啊，</span><br /><span className="pl pl-1">你中間被殺的並不是被刀殺，</span><br /><span className="pl pl-1">也不是因打仗死亡。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="列王紀下 25:4–7; 以賽亞書 3:1–8; 耶利米書 39:4–7"> <span className="pl pl-1">你所有的官長一同逃跑，</span><br /><span className="pl pl-1">都為弓箭手所捆綁。</span><br /><span className="pl pl-1">你中間一切被找到的都一同被捆綁；</span><br /><span className="pl pl-1">他們本是逃往遠方的。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="耶利米書 9:1; 馬太福音 2:18; 詩篇 77:2"> <span className="pl pl-1">所以我說：你們轉眼不看我，</span><br /><span className="pl pl-1">我要痛哭。</span><br /><span className="pl pl-1">不要因我眾民</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是民女">a</a></sup><br /><span className="pl pl-1">的毀滅，</span><br /><span className="pl pl-1">就竭力安慰我。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="彌迦書 7:4; 以賽亞書 37:3; 路加福音 23:30"> <span className="pl pl-1">因為主－萬軍之耶和華使「異象谷」</span><br /><span className="pl pl-1">有潰亂、踐踏、煩擾的日子。</span><br /><span className="pl pl-1">城被攻破，</span><br /><span className="pl pl-1">哀聲達到山間。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="列王紀下 16:9; 以賽亞書 21:2; 阿摩司書 1:5"> <span className="pl pl-1">以攔帶着箭袋，</span><br /><span className="pl pl-1">還有坐戰車的和馬兵；</span><br /><span className="pl pl-1">吉珥揭開盾牌。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="以賽亞書 8:7–8; 以賽亞書 10:28–32; 耶利米書 39:1–3"> <span className="pl pl-1">你嘉美的谷遍滿戰車，</span><br /><span className="pl pl-1">也有馬兵在城門前排列。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="列王紀上 7:2; 列王紀上 10:17; 以賽亞書 36:1–3"> <span className="pl pl-1">他去掉猶大的遮蓋。</span>那日，你就仰望林庫內的軍器。</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀下 20:20; 尼希米記 3:16; 歷代志下 32:1–6"> 你們看見大衛城的破口很多，便聚積下池的水，</span>
<span className="v" id="v10" data-v="10"> 又數點耶路撒冷的房屋，將房屋拆毀，修補城牆，</span>
<span className="v" id="v11" data-v="11" data-xref="彌迦書 7:7; 耶利米書 33:2–3; 以賽亞書 31:1"> 又在兩道城牆中間挖一個聚水池可盛舊池的水，卻不仰望做這事的主，也不顧念從古定這事的。</span>
</div>

## 對舍伯那的警告

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="以賽亞書 36:3; 列王紀下 18:18; 列王紀下 19:2"> 主－萬軍之耶和華這樣說：「你去見掌銀庫的，就是家宰舍伯那，對他說：</span>
<span className="v" id="v16" data-v="16" data-xref="馬太福音 27:60; 歷代志下 16:14; 撒母耳記下 18:18"> 『你在這裏做甚麼呢？有甚麼人竟在這裏鑿墳墓，就是在高處為自己鑿墳墓，在磐石中為自己鑿出安身之所？</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米書 14:3; 約伯記 9:24; 以斯帖記 7:8"> 看哪，耶和華必像大有力的人，將你緊緊纏裹，竭力拋去。</span>
<span className="v" id="v18" data-v="18" data-xref="以賽亞書 17:13; 阿摩司書 7:17"> 他必將你滾成一團，拋在寬闊之地，好像拋球一樣。你這主人家的羞辱，必在那裏坐你榮耀的車，也必在那裏死亡。</span>
<span className="v" id="v19" data-v="19" data-xref="以西結書 17:24; 詩篇 75:6–7; 約伯記 40:11–12"> 我必趕逐你離開官職；你必從你的原位撤下。』</span>
<span className="v" id="v20" data-v="20" data-xref="以賽亞書 36:3; 列王紀下 18:18; 以賽亞書 37:2"> 「到那日，我必召我僕人希勒家的兒子以利亞敬來，</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 45:8; 以賽亞書 9:6–7; 創世記 41:42–43"> 將你的外袍給他穿上，將你的腰帶給他繫緊，將你的政權交在他手中。他必作耶路撒冷居民和猶大家的父。</span>
<span className="v" id="v22" data-v="22" data-xref="馬太福音 16:18–19; 啟示錄 3:7; 約伯記 12:14"> 我必將大衛家的鑰匙放在他肩頭上。他開，無人能關；他關，無人能開。</span>
<span className="v" id="v23" data-v="23" data-xref="以斯拉記 9:8; 約伯記 36:7; 撒迦利亞書 10:4"> 我必將他安穩，像釘子釘在堅固處；他必作為他父家榮耀的寶座。</span>
<span className="v" id="v24" data-v="24" data-xref="但以理書 6:1–3; 約翰福音 20:21–23; 馬太福音 28:18"> 他父家所有的榮耀，連兒女帶子孫，都掛在他身上，好像一切小器皿，從杯子到酒瓶掛上一樣。</span>
<span className="v" id="v25" data-v="25" data-xref="以賽亞書 46:11; 以斯帖記 9:24–25; 詩篇 146:3"> 萬軍之耶和華說：當那日，釘在堅固處的釘子必壓斜，被砍斷落地；掛在其上的重擔必被剪斷。因為這是耶和華說的。」</span>
</div>

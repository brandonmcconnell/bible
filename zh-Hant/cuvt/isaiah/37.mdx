## 國王下令徵求以賽亞的意見

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀下 19:1–37; 以斯拉記 9:5; 以賽亞書 36:22–38"> 希西家王聽見就撕裂衣服，披上麻布，進了耶和華的殿，</span>
<span className="v" id="v2" data-v="2" data-xref="以賽亞書 1:1; 列王紀下 18:18; 以賽亞書 36:3"> 使家宰以利亞敬和書記舍伯那，並祭司中的長老，都披上麻布，去見亞摩斯的兒子先知以賽亞，</span>
<span className="v" id="v3" data-v="3" data-xref="以賽亞書 66:9; 何西阿書 13:13; 以賽亞書 26:17–18"> 對他說：「希西家如此說：『今日是急難、責罰、凌辱的日子，就如婦人將要生產嬰孩，卻沒有力量生產。</span>
<span className="v" id="v4" data-v="4" data-xref="以賽亞書 1:9; 以賽亞書 36:20; 以賽亞書 10:22"> 或者耶和華－你的上帝聽見拉伯沙基的話，就是他主人亞述王打發他來辱罵永生上帝的話；耶和華－你的上帝聽見這話就發斥責。故此，求你為餘剩的民揚聲禱告。』」</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5"> 希西家王的臣僕就去見以賽亞。</span>
<span className="v" id="v6" data-v="6" data-xref="以賽亞書 7:4; 以賽亞書 35:4; 馬可福音 5:36"> 以賽亞對他們說：「要這樣對你們的主人說，耶和華如此說：『你聽見亞述王的僕人褻瀆我的話，不要懼怕。</span>
<span className="v" id="v7" data-v="7" data-xref="以賽亞書 31:8–9; 歷代志下 32:21; 以賽亞書 33:10–12"> 我必驚動<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是使靈進入">a</a></sup>他的心；他要聽見風聲就歸回本地，我必使他在那裏倒在刀下。』」</span>
</div>
</div>

## 亞述人再來威脅

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="約書亞記 10:29; 民數記 33:20–21; 列王紀下 19:8–9"> 拉伯沙基回去，正遇見亞述王攻打立拿；原來他早聽見亞述王拔營離開拉吉。</span>
<span className="v" id="v9" data-v="9" data-xref="以賽亞書 18:1; 以賽亞書 20:5; 以賽亞書 37:7"> 亞述王聽見人論古實王特哈加說：「他出來要與你爭戰。」亞述王一聽見，就打發使者去見希西家，吩咐他們說：</span>
<span className="v" id="v10" data-v="10" data-xref="以賽亞書 36:15; 列王紀下 18:5; 馬太福音 27:43"> 「你們對猶大王希西家如此說：『不要聽你所倚靠的上帝欺哄你說：耶路撒冷必不交在亞述王的手中。</span>
<span className="v" id="v11" data-v="11" data-xref="以賽亞書 36:18–20; 列王紀下 18:33–35; 以賽亞書 14:17"> 你總聽說亞述諸王向列國所行的乃是盡行滅絕，難道你還能得救嗎？</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 11:31; 列王紀下 17:6; 列王紀下 18:11"> 我列祖所毀滅的，就是歌散、哈蘭、利色，和屬提‧拉撒的伊甸人；這些國的神何曾拯救這些國呢？</span>
<span className="v" id="v13" data-v="13" data-xref="列王紀下 19:13; 列王紀下 17:24; 以賽亞書 36:19"> 哈馬的王，亞珥拔的王，西法瓦音城的王，希拿和以瓦的王，都在哪裏呢？』」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="列王紀下 19:14; 詩篇 123:1–4; 約珥書 2:17–20"> 希西家從使者手裏接過書信來，看完了，就上耶和華的殿，將書信在耶和華面前展開。</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳記上 7:8–9; 但以理書 9:3–4; 雅各書 5:13"> 希西家向耶和華禱告說：</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 25:22; 詩篇 99:1; 詩篇 86:10"> 「坐在二基路伯上萬軍之耶和華－以色列的上帝啊，你－惟有你是天下萬國的上帝，你曾創造天地。</span>
<span className="v" id="v17" data-v="17" data-xref="歷代志下 6:40; 詩篇 17:6; 以賽亞書 37:4"> 耶和華啊，求你側耳而聽；耶和華啊，求你睜眼而看，要聽西拿基立的一切話，他是打發使者來辱罵永生上帝的。</span>
<span className="v" id="v18" data-v="18" data-xref="那鴻書 2:11–12; 列王紀下 15:29; 列王紀下 17:6"> 耶和華啊，亞述諸王果然使列國和列國之地變為荒涼，</span>
<span className="v" id="v19" data-v="19" data-xref="以賽亞書 44:9–10; 耶利米書 10:11; 何西阿書 8:6"> 將列國的神像都扔在火裏；因為他本不是神，乃是人手所造的，是木頭、石頭的，所以滅絕他。</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 46:10; 列王紀上 18:36–37; 詩篇 83:17–18"> 耶和華－我們的上帝啊，現在求你救我們脫離亞述王的手，使天下萬國都知道惟有你是耶和華。」</span>
</div>
</div>

## 以賽亞給王的信息

<div className="bt">
<div className="bp poetry">
<span className="v" id="v21" data-v="21" data-xref="以賽亞書 58:9; 以賽亞書 38:3–6; 使徒行傳 4:31"> 亞摩斯的兒子以賽亞就打發人去見希西家，說：「耶和華－以色列的上帝如此說，你既然求我攻擊亞述王西拿基立，</span>
<span className="v" id="v22" data-v="22" data-xref="約伯記 16:4; 耶利米哀歌 2:13; 以賽亞書 1:8"> 所以耶和華論他這樣說：<br /><span className="pl pl-1">錫安的處女藐視你，嗤笑你；</span><br /><span className="pl pl-1">耶路撒冷的女子向你搖頭。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v23" data-v="23" data-xref="以西結書 39:7; 但以理書 5:20–23; 以賽亞書 17:7"> <span className="pl pl-1">你辱罵誰，褻瀆誰？</span><br /><span className="pl pl-1">揚起聲來，高舉眼目攻擊誰呢？</span><br /><span className="pl pl-1">乃是攻擊以色列的聖者。</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="以賽亞書 14:8; 以賽亞書 10:18; 出埃及記 15:9"> <span className="pl pl-1">你藉你的臣僕辱罵主說：</span><br /><span className="pl pl-1">我率領許多戰車上山頂，</span><br /><span className="pl pl-1">到黎巴嫩極深之處；</span><br /><span className="pl pl-1">我要砍伐其中高大的香柏樹</span><br /><span className="pl pl-1">和佳美的松樹。</span><br /><span className="pl pl-1">我必上極高之處，</span><br /><span className="pl pl-1">進入肥田的樹林。</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="列王紀上 20:10; 以賽亞書 36:12; 列王紀下 19:23–24"> <span className="pl pl-1">我已經挖井喝水；</span><br /><span className="pl pl-1">我必用腳掌踏乾埃及的一切河。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v26" data-v="26" data-xref="使徒行傳 4:27–28; 使徒行傳 2:23; 彼得前書 2:8"> <span className="pl pl-1">耶和華說：你豈沒有聽見</span><br /><span className="pl pl-1">我早先所做的、古時所立的嗎？</span><br /><span className="pl pl-1">現在藉你使堅固城荒廢，變為亂堆。</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="詩篇 129:6; 詩篇 37:2; 彼得前書 1:24"> <span className="pl pl-1">所以其中的居民力量甚小，</span><br /><span className="pl pl-1">驚惶羞愧。</span><br /><span className="pl pl-1">他們像野草，像青菜，</span><br /><span className="pl pl-1">如房頂上的草，</span><br /><span className="pl pl-1">又如田間未長成的禾稼。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v28" data-v="28" data-xref="啟示錄 2:13; 詩篇 139:1–11; 耶利米書 23:23–24"> <span className="pl pl-1">你坐下，你出去，你進來，</span><br /><span className="pl pl-1">你向我發烈怒，我都知道。</span><br /></span>
<span className="v" id="v29" data-v="29" data-xref="以西結書 38:4; 以賽亞書 30:28; 以賽亞書 37:34"> <span className="pl pl-1">因你向我發烈怒，</span><br /><span className="pl pl-1">又因你狂傲的話達到我耳中，</span><br /><span className="pl pl-1">我就要用鉤子鉤上你的鼻子，</span><br /><span className="pl pl-1">把嚼環放在你口裏，</span><br /><span className="pl pl-1">使你從原路轉回去。</span></span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="列王紀下 19:29; 利未記 25:4–5; 列王紀上 13:3–5"> 「以色列人哪，我賜你們一個證據：你們今年要吃自生的，明年也要吃自長的，至於後年，你們要耕種收割，栽植葡萄園，吃其中的果子。</span>
<span className="v" id="v31" data-v="31" data-xref="以賽亞書 27:6; 列王紀下 19:30–31; 詩篇 80:9"> 猶大家所逃脫餘剩的，仍要往下扎根，向上結果。</span>
<span className="v" id="v32" data-v="32" data-xref="以賽亞書 9:7; 列王紀下 19:31; 以賽亞書 59:17"> 必有餘剩的民從耶路撒冷而出；必有逃脫的人從錫安山而來。萬軍之耶和華的熱心必成就這事。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="以賽亞書 17:12; 以賽亞書 10:32–34; 以賽亞書 17:14"> 「所以耶和華論亞述王如此說：他必不得來到這城，也不在這裏射箭，不得拿盾牌到城前，也不築壘攻城。</span>
<span className="v" id="v34" data-v="34" data-xref="以賽亞書 37:29; 箴言 21:30"> 他從哪條路來，必從那條路回去，必不得來到這城。這是耶和華說的。</span>
<span className="v" id="v35" data-v="35" data-xref="列王紀下 20:6; 以賽亞書 38:6; 以賽亞書 31:5"> 因我為自己的緣故，又為我僕人大衛的緣故，必保護拯救這城。」</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="以賽亞書 10:12; 列王紀下 19:35; 以賽亞書 10:33–34"> 耶和華的使者出去，在亞述營中殺了十八萬五千人。清早有人起來一看，都是死屍了。</span>
<span className="v" id="v37" data-v="37" data-xref="約拿書 1:2; 約拿書 3:3; 創世記 10:11–12"> 亞述王西拿基立就拔營回去，住在尼尼微。</span>
<span className="v" id="v38" data-v="38" data-xref="創世記 8:4; 耶利米書 51:27; 以斯拉記 4:2"> 一日在他的神－尼斯洛廟裏叩拜，他兒子亞得米勒和沙利色用刀殺了他，就逃到亞拉臘地。他兒子以撒哈頓接續他作王。</span>
</div>

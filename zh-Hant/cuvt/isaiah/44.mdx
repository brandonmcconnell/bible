## 耶和華是獨一的上帝

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="以賽亞書 41:8; 羅馬書 11:5–6; 耶利米書 30:10"> <span className="pl pl-1">我的僕人雅各，</span><br /><span className="pl pl-1">我所揀選的以色列啊，</span><br /><span className="pl pl-1">現在你當聽。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="耶利米書 1:5; 以賽亞書 43:1; 以賽亞書 46:3–4"> <span className="pl pl-1">造作你，又從你出胎造就你，</span><br /><span className="pl pl-1">並要幫助你的耶和華如此說：</span><br /><span className="pl pl-1">我的僕人雅各，</span><br /><span className="pl pl-1">我所揀選的耶書崙哪，</span><br /><span className="pl pl-1">不要害怕！</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="約珥書 2:28; 使徒行傳 2:17; 以賽亞書 59:21"> <span className="pl pl-1">因為我要將水澆灌口渴的人，</span><br /><span className="pl pl-1">將河澆灌乾旱之地。</span><br /><span className="pl pl-1">我要將我的靈澆灌你的後裔，</span><br /><span className="pl pl-1">將我的福澆灌你的子孫。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="以賽亞書 58:11; 詩篇 1:3; 詩篇 92:13–15"> <span className="pl pl-1">他們要發生在草中，</span><br /><span className="pl pl-1">像溪水旁的柳樹。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="哥林多後書 8:5; 撒迦利亞書 13:9; 彼得前書 2:9"> <span className="pl pl-1">這個要說：我是屬耶和華的；</span><br /><span className="pl pl-1">那個要以雅各的名自稱；</span><br /><span className="pl pl-1">又一個要親手寫：歸耶和華的</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或譯：在手上寫歸耶和華">a</a></sup><br /><span className="pl pl-1">，</span><br /><span className="pl pl-1">並自稱為以色列。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="以賽亞書 41:4; 以賽亞書 43:10–11; 啟示錄 1:8"> <span className="pl pl-1">耶和華－以色列的君，</span><br /><span className="pl pl-1">以色列的救贖主－萬軍之耶和華如此說：</span><br /><span className="pl pl-1">我是首先的，我是末後的；</span><br /><span className="pl pl-1">除我以外再沒有真神。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="以賽亞書 41:26; 以賽亞書 41:22; 以賽亞書 46:9–10"> <span className="pl pl-1">自從我設立古時的民，</span><br /><span className="pl pl-1">誰能像我宣告，並且指明，又為自己陳說呢？</span><br /><span className="pl pl-1">讓他將未來的事和必成的事說明。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="以賽亞書 43:10; 撒母耳記上 2:2; 申命記 4:35"> <span className="pl pl-1">你們不要恐懼，也不要害怕。</span><br /><span className="pl pl-1">我豈不是從上古就說明指示你們嗎？</span><br /><span className="pl pl-1">並且你們是我的見證！</span><br /><span className="pl pl-1">除我以外，豈有真神嗎？</span><br /><span className="pl pl-1">誠然沒有磐石，我不知道一個！</span></span>
</div>

## 虛無的偶像

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="以賽亞書 41:24; 耶利米書 10:14–15; 詩篇 97:7"> 製造雕刻偶像的盡都虛空；他們所喜悅的都無益處；他們的見證無所看見，無所知曉，他們便覺羞愧。</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米書 10:5; 哈巴谷書 2:18; 使徒行傳 19:26"> 誰製造神像，鑄造無益的偶像？</span>
<span className="v" id="v11" data-v="11" data-xref="以賽亞書 42:17; 以賽亞書 45:16; 詩篇 97:7"> 看哪，他的同伴都必羞愧。工匠也不過是人，任他們聚會，任他們站立，都必懼怕，一同羞愧。</span>
<span className="v" id="v12" data-v="12" data-xref="以賽亞書 41:6–7; 以賽亞書 40:19; 以賽亞書 46:6–7"> 鐵匠把鐵在火炭中燒熱，用鎚打鐵器，用他有力的膀臂錘成；他飢餓而無力，不喝水而發倦。</span>
<span className="v" id="v13" data-v="13" data-xref="士師記 17:4–5; 詩篇 115:5–7; 使徒行傳 17:29"> 木匠拉線，用筆劃出樣子，用鉋子鉋成形狀，用圓尺劃了模樣，仿照人的體態，做成人形，好住在房屋中。</span>
<span className="v" id="v14" data-v="14" data-xref="以賽亞書 40:20; 耶利米書 10:3–8; 何西阿書 4:12"> 他砍伐香柏樹，又取柞<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或譯：青桐">b</a></sup>樹和橡樹，在樹林中選定了一棵。他栽種松樹，得雨長養。</span>
<span className="v" id="v15" data-v="15" data-xref="歷代志下 25:14; 啟示錄 9:20; 士師記 2:19"> 這樹，人可用以燒火；他自己取些烤火，又燒着烤餅，而且做神像跪拜，做雕刻的偶像向它叩拜。</span>
<span className="v" id="v16" data-v="16"> 他把一分燒在火中，把一分烤肉吃飽。自己烤火說：「啊哈，我暖和了，我見火了。」</span>
<span className="v" id="v17" data-v="17" data-xref="以賽亞書 45:20; 列王紀上 18:26; 但以理書 6:27"> 他用剩下的做了一神，就是雕刻的偶像。他向這偶像俯伏叩拜，禱告它說：「求你拯救我，因你是我的神。」</span>
<span className="v" id="v18" data-v="18" data-xref="以賽亞書 6:9–10; 哥林多後書 4:3–4; 約翰福音 12:39–40"> 他們不知道，也不思想；因為耶和華閉住他們的眼，不能看見，塞住他們的心，不能明白。</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 27:15; 列王紀上 11:7; 列王紀上 11:5"> 誰心裏也不醒悟，也沒有知識，沒有聰明，能說：「我曾拿一分在火中燒了，在炭火上烤過餅；我也烤過肉吃。這剩下的，我豈要做可憎的物嗎？我豈可向木墩子叩拜呢？」</span>
<span className="v" id="v20" data-v="20" data-xref="羅馬書 1:28; 約伯記 15:31; 何西阿書 12:1"> 他以灰為食，心中昏迷，使他偏邪，他不能自救，也不能說：「我右手中豈不是有虛謊嗎？」</span>
</div>
</div>

## 耶和華是創造主也是救贖主

<div className="bt">
<div className="bp poetry">
<span className="v" id="v21" data-v="21" data-xref="以賽亞書 44:1–2; 以賽亞書 49:15–16; 以賽亞書 43:15"> <span className="pl pl-1">雅各，以色列啊，</span><br /><span className="pl pl-1">你是我的僕人，要記念這些事。</span><br /><span className="pl pl-1">以色列啊，你是我的僕人，</span><br /><span className="pl pl-1">我造就你必不忘記你。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="以賽亞書 43:25; 哥林多前書 6:20; 使徒行傳 3:18–19"> <span className="pl pl-1">我塗抹了你的過犯，像厚雲消散；</span><br /><span className="pl pl-1">我塗抹了你的罪惡，如薄雲滅沒。</span><br /><span className="pl pl-1">你當歸向我，因我救贖了你。</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="以弗所書 1:6–7; 啟示錄 5:8–14; 詩篇 69:34"> <span className="pl pl-1">諸天哪，應當歌唱，</span><br /><span className="pl pl-1">因為耶和華做成這事。</span><br /><span className="pl pl-1">地的深處啊，應當歡呼；</span><br /><span className="pl pl-1">眾山應當發聲歌唱；</span><br /><span className="pl pl-1">樹林和其中所有的樹都當如此！</span><br /><span className="pl pl-1">因為耶和華救贖了雅各，</span><br /><span className="pl pl-1">並要因以色列榮耀自己。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v24" data-v="24" data-xref="以賽亞書 45:12; 以賽亞書 42:5; 以賽亞書 54:5"> <span className="pl pl-1">從你出胎，造就你的救贖主－耶和華如此說：</span><br /><span className="pl pl-1">我－耶和華是創造萬物的，</span><br /><span className="pl pl-1">是獨自鋪張諸天、鋪開大地的。</span><br /><span className="pl pl-1">誰與我同在呢？</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="詩篇 33:10; 約伯記 5:12–14; 耶利米書 50:36"> <span className="pl pl-1">使說假話的兆頭失效，</span><br /><span className="pl pl-1">使占卜的癲狂，</span><br /><span className="pl pl-1">使智慧人退後，</span><br /><span className="pl pl-1">使他的知識變為愚拙；</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="列王紀上 18:36–38; 以賽亞書 42:9; 尼希米記 1:3"> <span className="pl pl-1">使我僕人的話語立定，</span><br /><span className="pl pl-1">我使者的謀算成就。</span><br /><span className="pl pl-1">論到耶路撒冷說：必有人居住；</span><br /><span className="pl pl-1">論到猶大的城邑說：必被建造，</span><br /><span className="pl pl-1">其中的荒場我也必興起。</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="以賽亞書 42:15; 耶利米書 51:36; 耶利米書 50:38"> <span className="pl pl-1">對深淵說：你乾了吧！</span><br /><span className="pl pl-1">我也要使你的江河乾涸。</span><br /></span>
<span className="v" id="v28" data-v="28" data-xref="歷代志下 36:22–3; 以賽亞書 45:1; 以賽亞書 45:13"> <span className="pl pl-1">論塞魯士說：他是我的牧人，</span><br /><span className="pl pl-1">必成就我所喜悅的，</span><br /><span className="pl pl-1">必下令建造耶路撒冷，</span><br /><span className="pl pl-1">發命立穩聖殿的根基。</span></span>

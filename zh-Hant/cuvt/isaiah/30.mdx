## 跟埃及訂立無用的條約

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="以賽亞書 65:2; 以賽亞書 1:2; 何西阿書 7:13"> <span className="pl pl-1">耶和華說：</span><br /><span className="pl pl-1">禍哉！這悖逆的兒女。</span><br /><span className="pl pl-1">他們同謀，卻不由於我，</span><br /><span className="pl pl-1">結盟，卻不由於我的靈，</span><br /><span className="pl pl-1">以致罪上加罪；</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="以賽亞書 36:6; 民數記 27:21; 申命記 28:68"> <span className="pl pl-1">起身下埃及去，並沒有求問我；</span><br /><span className="pl pl-1">要靠法老的力量加添自己的力量，</span><br /><span className="pl pl-1">並投在埃及的蔭下。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="以賽亞書 20:5; 羅馬書 10:11; 耶利米書 17:5–6"> <span className="pl pl-1">所以，法老的力量必作你們的羞辱；</span><br /><span className="pl pl-1">投在埃及的蔭下，要為你們的慚愧。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="以賽亞書 19:11; 以賽亞書 57:9; 耶利米書 43:7"> <span className="pl pl-1">他們的首領已在瑣安；</span><br /><span className="pl pl-1">他們的使臣到了哈內斯。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="耶利米書 2:36; 以賽亞書 30:7; 以賽亞書 30:16"> <span className="pl pl-1">他們必因那不利於他們的民蒙羞。</span><br /><span className="pl pl-1">那民並非幫助，也非利益，</span><br /><span className="pl pl-1">只作羞恥凌辱。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="申命記 8:15; 以賽亞書 46:1–2; 耶利米書 11:4"> <span className="pl pl-1">論南方牲畜的默示：</span><br /><span className="pl pl-1">他們把財物馱在驢駒的脊背上，</span><br /><span className="pl pl-1">將寶物馱在駱駝的肉鞍上，</span><br /><span className="pl pl-1">經過艱難困苦之地，</span><br /><span className="pl pl-1">就是公獅、母獅、蝮蛇、火焰的飛龍之地，</span><br /><span className="pl pl-1">往那不利於他們的民那裏去。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="以賽亞書 2:22; 以賽亞書 7:4; 詩篇 118:8–9"> <span className="pl pl-1">埃及的幫助是徒然無益的；</span><br /><span className="pl pl-1">所以我稱她為「坐而不動的拉哈伯」。</span></span>
</div>
</div>

## 不順服的百姓

<div className="bt">
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="申命記 31:22; 哈巴谷書 2:2; 以賽亞書 8:1"> <span className="pl pl-1">現今你去，</span><br /><span className="pl pl-1">在他們面前將這話刻在版上，</span><br /><span className="pl pl-1">寫在書上，</span><br /><span className="pl pl-1">以便傳留後世，直到永永遠遠。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="以賽亞書 30:1; 使徒行傳 7:51; 撒迦利亞書 1:4–6"> <span className="pl pl-1">因為他們是悖逆的百姓、說謊的兒女，</span><br /><span className="pl pl-1">不肯聽從耶和華訓誨的兒女。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="以西結書 13:7–10; 羅馬書 16:18; 阿摩司書 2:12"> <span className="pl pl-1">他們對先見說：不要望見不吉利的事，</span><br /><span className="pl pl-1">對先知說：不要向我們講正直的話；</span><br /><span className="pl pl-1">要向我們說柔和的話，</span><br /><span className="pl pl-1">言虛幻的事。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="羅馬書 8:7; 羅馬書 1:30; 約翰福音 15:23–24"> <span className="pl pl-1">你們要離棄正道，偏離直路，</span><br /><span className="pl pl-1">不要在我們面前再提說以色列的聖者。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="以賽亞書 31:1–3; 以賽亞書 5:24; 帖撒羅尼迦前書 4:8"> <span className="pl pl-1">所以，以色列的聖者如此說：</span><br /><span className="pl pl-1">因為你們藐視這訓誨的話，</span><br /><span className="pl pl-1">倚賴欺壓和乖僻，以此為可靠的，</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="以賽亞書 29:5; 以西結書 13:10–15; 列王紀上 20:30"> <span className="pl pl-1">故此，這罪孽在你們身上，</span><br /><span className="pl pl-1">好像將要破裂凸出來的高牆，</span><br /><span className="pl pl-1">頃刻之間忽然坍塌；</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="詩篇 2:9; 耶利米書 19:10–11; 彼得後書 2:4–5"> <span className="pl pl-1">要被打碎，好像把窯匠的瓦器打碎，</span><br /><span className="pl pl-1">毫不顧惜，</span><br /><span className="pl pl-1">甚至碎塊中找不到一片可用以從爐內取火，</span><br /><span className="pl pl-1">從池中舀水。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="以賽亞書 26:3–4; 以賽亞書 32:17; 耶利米書 3:22–23"> <span className="pl pl-1">主耶和華－以色列的聖者曾如此說：</span><br /><span className="pl pl-1">你們得救在乎歸回安息；</span><br /><span className="pl pl-1">你們得力在乎平靜安穩；</span><br /><span className="pl pl-1">你們竟自不肯。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="以賽亞書 31:1; 以賽亞書 31:3; 申命記 28:25"> <span className="pl pl-1">你們卻說：不然，我們要騎馬奔走。</span><br /><span className="pl pl-1">所以你們必然奔走；</span><br /><span className="pl pl-1">又說：我們要騎飛快的牲口。</span><br /><span className="pl pl-1">所以追趕你們的，也必飛快。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="申命記 28:25; 約書亞記 23:10; 申命記 32:30"> <span className="pl pl-1">一人叱喝，必令千人逃跑；</span><br /><span className="pl pl-1">五人叱喝，你們都必逃跑；</span><br /><span className="pl pl-1">以致剩下的，好像山頂的旗杆，</span><br /><span className="pl pl-1">岡上的大旗。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="耶利米哀歌 3:25–26; 彼得後書 3:9; 箴言 16:20"> <span className="pl pl-1">耶和華必然等候，要施恩給你們；</span><br /><span className="pl pl-1">必然興起，好憐憫你們。</span><br /><span className="pl pl-1">因為耶和華是公平的上帝；</span><br /><span className="pl pl-1">凡等候他的都是有福的！</span></span>
</div>
</div>

## 主要賜福給他的子民

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="以賽亞書 60:20; 詩篇 50:15; 以賽亞書 65:24"> 百姓必在錫安、在耶路撒冷居住；你不再哭泣。主必因你哀求的聲音施恩給你；他聽見的時候就必應允你。</span>
<span className="v" id="v20" data-v="20" data-xref="列王紀上 22:27; 詩篇 80:5; 阿摩司書 8:11–12"> 主雖然以艱難給你當餅，以困苦給你當水，你的教師卻不再隱藏；你眼必看見你的教師。</span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 32:8; 箴言 3:5–6; 以賽亞書 58:11"> 你或向左或向右，你必聽見後邊有聲音說：「這是正路，要行在其間。」</span>
<span className="v" id="v22" data-v="22" data-xref="士師記 17:3–4; 以賽亞書 31:7; 撒迦利亞書 13:2"> 你雕刻偶像所包的銀子和鑄造偶像所鍍的金子，你要玷污，要拋棄，好像污穢之物，對偶像說：「去吧！」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="撒迦利亞書 8:11–12; 以賽亞書 32:20; 詩篇 65:9–13"> 你將種子撒在地裏，主必降雨在其上，並使地所出的糧肥美豐盛。到那時，你的牲畜必在寬闊的草場吃草。</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 45:6; 申命記 25:4; 撒母耳記上 8:12"> 耕地的牛和驢駒必吃加鹽的料；這料是用木杴和杈子揚淨的。</span>
<span className="v" id="v25" data-v="25" data-xref="以賽亞書 43:19–20; 以賽亞書 35:6–7; 以賽亞書 2:14–15"> 在大行殺戮的日子，高臺倒塌的時候，各高山岡陵必有川流河湧。</span>
<span className="v" id="v26" data-v="26" data-xref="以賽亞書 60:19–20; 申命記 32:39; 啟示錄 22:5"> 當耶和華纏裹他百姓的損處，醫治他民鞭傷的日子，月光必像日光，日光必加七倍，像七日的光一樣。</span>
</div>
</div>

## 上帝要懲罰亞述

<div className="bt">
<div className="bp poetry">
<span className="v" id="v27" data-v="27" data-xref="帖撒羅尼迦後書 2:8; 那鴻書 1:5–6; 詩篇 18:7–9"> <span className="pl pl-1">看哪，耶和華的名從遠方來，</span><br /><span className="pl pl-1">怒氣燒起，密煙上騰。</span><br /><span className="pl pl-1">他的嘴唇滿有忿恨；</span><br /><span className="pl pl-1">他的舌頭像吞滅的火。</span><br /></span>
<span className="v" id="v28" data-v="28" data-xref="以賽亞書 37:29; 以賽亞書 11:4; 帖撒羅尼迦後書 2:8"> <span className="pl pl-1">他的氣如漲溢的河水，直漲到頸項，</span><br /><span className="pl pl-1">要用毀滅的篩籮篩淨列國，</span><br /><span className="pl pl-1">並且在眾民的口中必有使人錯行的嚼環。</span></span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="詩篇 42:4; 詩篇 95:1–2; 出埃及記 15:1–21"> 你們必唱歌，像守聖節的夜間一樣，並且心中喜樂，像人吹笛，上耶和華的山，到以色列的磐石那裏。</span>
<span className="v" id="v30" data-v="30" data-xref="詩篇 18:13–14; 約書亞記 10:11; 以賽亞書 29:6"> 耶和華必使人聽他威嚴的聲音，又顯他降罰的膀臂和他怒中的忿恨，並吞滅的火焰與霹雷、暴風、冰雹。</span>
<span className="v" id="v31" data-v="31" data-xref="以賽亞書 11:4; 以賽亞書 9:4; 彌迦書 5:5–6"> 亞述人必因耶和華的聲音驚惶；耶和華必用杖擊打他。</span>
<span className="v" id="v32" data-v="32" data-xref="以賽亞書 11:15; 以賽亞書 19:16; 以賽亞書 2:19"> 耶和華必將命定的杖加在他身上；每打一下，人必擊鼓彈琴。打仗的時候，耶和華必掄起手來，與他交戰。</span>
<span className="v" id="v33" data-v="33" data-xref="列王紀下 23:10; 創世記 19:24; 耶利米書 19:6"> 原來陀斐特又深又寬，早已為王預備好了；其中堆的是火與許多木柴。耶和華的氣如一股硫磺火使他着起來。</span>
</div>

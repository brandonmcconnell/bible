## 神要責罰泰爾的海港

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="約珥書 3:4–8; 阿摩司書 1:9–10; 創世記 10:4"> 論泰爾的默示：<br /><span className="pl pl-1">他施的船隻都要哀號；</span><br /><span className="pl pl-1">因為泰爾變為荒場，</span><br /><span className="pl pl-1">甚至沒有房屋，沒有可進之路。</span><br /><span className="pl pl-1">這消息是從基提地得來的。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="以賽亞書 47:5; 以賽亞書 41:1; 以西結書 28:2"> <span className="pl pl-1">沿海的居民，</span><br /><span className="pl pl-1">就是素來靠航海西頓的商家得豐盛的，</span><br /><span className="pl pl-1">你們當靜默無言。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="耶利米書 2:18; 歷代志上 13:5; 以西結書 27:33"> <span className="pl pl-1">在大水之上，</span><br /><span className="pl pl-1">西曷的糧食、</span><br /><span className="pl pl-1">尼羅河的莊稼是泰爾的進項；</span><br /><span className="pl pl-1">她作列國的大碼頭。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="啟示錄 18:23; 創世記 10:15; 耶利米書 47:3–4"> <span className="pl pl-1">西頓哪，你當慚愧；</span><br /><span className="pl pl-1">因為大海說，</span><br /><span className="pl pl-1">就是海中的保障說：</span><br /><span className="pl pl-1">我沒有劬勞，也沒有生產，</span><br /><span className="pl pl-1">沒有養育男子，也沒有撫養童女。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="約書亞記 2:9–11; 出埃及記 15:14–16; 啟示錄 18:17–19"> <span className="pl pl-1">這風聲傳到埃及；</span><br /><span className="pl pl-1">埃及人為泰爾的風聲極其疼痛。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="以賽亞書 23:12; 以賽亞書 21:15; 以賽亞書 23:10"> <span className="pl pl-1">泰爾人哪，你們當過到他施去；</span><br /><span className="pl pl-1">沿海的居民哪，你們都當哀號。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="以賽亞書 22:2; 以賽亞書 32:13; 約書亞記 19:29"> <span className="pl pl-1">這是你們歡樂的城，</span><br /><span className="pl pl-1">從上古而有的嗎？</span><br /><span className="pl pl-1">其中的居民往遠方寄居。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="以賽亞書 10:8; 耶利米書 50:44–45; 申命記 29:24–28"> <span className="pl pl-1">泰爾本是賜冠冕的。</span><br /><span className="pl pl-1">她的商家是王子；</span><br /><span className="pl pl-1">她的買賣人是世上的尊貴人。</span><br /><span className="pl pl-1">遭遇如此是誰定的呢？</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="雅各書 4:6; 以賽亞書 13:11; 約伯記 40:11–12"> <span className="pl pl-1">是萬軍之耶和華所定的！</span><br /><span className="pl pl-1">為要污辱一切高傲的榮耀，</span><br /><span className="pl pl-1">使地上一切的尊貴人被藐視。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="約伯記 12:21; 以賽亞書 23:14; 詩篇 18:32"> <span className="pl pl-1">他施的民</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是女">a</a></sup><br /><span className="pl pl-1">哪，</span><br /><span className="pl pl-1">可以流行你的地，好像尼羅河；</span><br /><span className="pl pl-1">不再有腰帶拘緊你。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="撒迦利亞書 9:3–4; 出埃及記 14:21; 耶利米書 47:7"> <span className="pl pl-1">耶和華已經向海伸手，</span><br /><span className="pl pl-1">震動列國。</span><br /><span className="pl pl-1">至於迦南，</span><br /><span className="pl pl-1">他已經吩咐拆毀其中的保障。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="啟示錄 18:22; 以西結書 26:13–14; 以賽亞書 23:1–2"> <span className="pl pl-1">他又說：受欺壓西頓的居民</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原文是處女">b</a></sup><br /><span className="pl pl-1">哪，</span><br /><span className="pl pl-1">你必不得再歡樂。</span><br /><span className="pl pl-1">起來！過到基提去；</span><br /><span className="pl pl-1">就是在那裏也不得安歇。</span><br />（</span>
<span className="v" id="v13" data-v="13" data-xref="哈巴谷書 1:6; 以賽亞書 10:5; 列王紀下 17:24"> 看哪，迦勒底人之地向來沒有這民，這國是亞述人為住曠野的人所立的。現在他們建築戍樓，拆毀泰爾的宮殿，使她成為荒涼。）</span>
<span className="v" id="v14" data-v="14" data-xref="以賽亞書 23:1; 以賽亞書 23:6; 以西結書 27:25–30"> <span className="pl pl-1">他施的船隻都要哀號，</span><br /><span className="pl pl-1">因為你們的保障變為荒場。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="耶利米書 25:22; 耶利米書 25:9–11; 但以理書 7:14"> 到那時，泰爾必被忘記七十年，照着一王的年日。七十年後，泰爾的景況必像妓女所唱的歌：</span>
<span className="v" id="v16" data-v="16" data-xref="耶利米書 30:14; 箴言 7:10–12"> <span className="pl pl-1">你這被忘記的妓女啊，</span><br /><span className="pl pl-1">拿琴周流城內，</span><br /><span className="pl pl-1">巧彈多唱，使人再想念你。</span></span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="那鴻書 3:4; 以西結書 27:6–36; 啟示錄 19:2"> 七十年後，耶和華必眷顧泰爾，她就仍得利息<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="原文是雇價；下同">c</a></sup>，與地上的萬國交易<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="原文是行淫">d</a></sup>。</span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 72:10; 申命記 26:12–14; 腓立比書 4:17–18"> 她的貨財和利息要歸耶和華為聖，必不積攢存留；因為她的貨財必為住在耶和華面前的人所得，使他們吃飽，穿耐久的衣服。</span>
</div>

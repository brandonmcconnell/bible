## 摩押的難民逃到猶大

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="列王紀下 3:4; 以賽亞書 10:32; 列王紀下 14:7"> <span className="pl pl-1">你們當將羊羔奉給那地掌權的，</span><br /><span className="pl pl-1">從西拉往曠野，送到錫安城</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是女子">a</a></sup><br /><span className="pl pl-1">的山。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="箴言 27:8; 士師記 11:18; 耶利米書 48:20"> <span className="pl pl-1">摩押的居民</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原文是女子">b</a></sup><br /><span className="pl pl-1">在亞嫩渡口，</span><br /><span className="pl pl-1">必像遊飛的鳥，如拆窩的雛。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="以賽亞書 32:2; 列王紀上 18:4; 以賽亞書 25:4"> <span className="pl pl-1">求你獻謀略，行公平，</span><br /><span className="pl pl-1">使你的影子在午間如黑夜，</span><br /><span className="pl pl-1">隱藏被趕散的人，不可顯露逃民。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="以賽亞書 14:4; 以賽亞書 51:13; 以賽亞書 9:4"> <span className="pl pl-1">求你容我這被趕散的人和你同居。</span><br /><span className="pl pl-1">至於摩押，求你作他的隱密處，</span><br /><span className="pl pl-1">脫離滅命者的面。</span><br /><span className="pl pl-1">勒索人的歸於無有，</span><br /><span className="pl pl-1">毀滅的事止息了，</span><br /><span className="pl pl-1">欺壓人的從國中除滅了，</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="但以理書 7:14; 彌迦書 4:7; 以賽亞書 9:6–7"> <span className="pl pl-1">必有寶座因慈愛堅立；</span><br /><span className="pl pl-1">必有一位誠誠實實坐在其上，</span><br /><span className="pl pl-1">在大衛帳幕中施行審判，</span><br /><span className="pl pl-1">尋求公平，速行公義。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="阿摩司書 2:1; 俄巴底亞書 1:3–4; 耶利米書 48:29–30"> <span className="pl pl-1">我們聽說摩押人驕傲，</span><br /><span className="pl pl-1">是極其驕傲；</span><br /><span className="pl pl-1">聽說他狂妄、驕傲、忿怒；</span><br /><span className="pl pl-1">他誇大的話是虛空的。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="列王紀下 3:25; 歷代志上 16:3; 耶利米書 48:20"> <span className="pl pl-1">因此，摩押人必為摩押哀號；</span><br /><span className="pl pl-1">人人都要哀號。</span><br /><span className="pl pl-1">你們摩押人要為吉珥‧哈列設的葡萄餅哀歎，</span><br /><span className="pl pl-1">極其憂傷。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="以賽亞書 15:4; 民數記 32:38; 耶利米書 48:32"> <span className="pl pl-1">因為希實本的田地</span><br /><span className="pl pl-1">和西比瑪的葡萄樹都衰殘了。</span><br /><span className="pl pl-1">列國的君主折斷其上美好的枝子；</span><br /><span className="pl pl-1">這枝子長到雅謝延到曠野，</span><br /><span className="pl pl-1">嫩枝向外探出，直探過鹽海。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="耶利米書 40:12; 以賽亞書 15:4–5; 耶利米書 40:10"> <span className="pl pl-1">因此，我要為西比瑪的葡萄樹哀哭，</span><br /><span className="pl pl-1">與雅謝人哀哭一樣。</span><br /><span className="pl pl-1">希實本、以利亞利啊，</span><br /><span className="pl pl-1">我要以眼淚澆灌你；</span><br /><span className="pl pl-1">因為有交戰吶喊的聲音</span><br /><span className="pl pl-1">臨到你夏天的果子，</span><br /><span className="pl pl-1">並你收割的莊稼。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="耶利米書 48:33; 士師記 9:27; 阿摩司書 5:17"> <span className="pl pl-1">從肥美的田中奪去了歡喜快樂；</span><br /><span className="pl pl-1">在葡萄園裏必無歌唱，也無歡呼的聲音。</span><br /><span className="pl pl-1">踹酒的在酒醡中不得踹出酒來；</span><br /><span className="pl pl-1">我使他歡呼的聲音止息。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="以賽亞書 15:5; 耶利米書 48:36; 何西阿書 11:8"> <span className="pl pl-1">因此，我心腹為摩押哀鳴如琴；</span><br /><span className="pl pl-1">我心腸為吉珥‧哈列設也是如此。</span></span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="以賽亞書 15:2; 列王紀上 18:29; 耶利米書 48:35"> 摩押人朝見的時候，在高處疲乏，又到他聖所祈禱，也不蒙應允。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="以賽亞書 44:8"> 這是耶和華從前論摩押的話。</span>
<span className="v" id="v14" data-v="14" data-xref="以賽亞書 21:16; 耶利米書 48:46–47; 以賽亞書 23:9"> 但現在耶和華說：「三年之內，照雇工的年數，摩押的榮耀與他的群眾必被藐視，餘剩的人甚少無幾。」</span>
</div>

## 上帝要保護耶路撒冷

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="詩篇 20:7; 耶利米書 17:5; 申命記 17:16"> <span className="pl pl-1">禍哉！那些下埃及求幫助的，</span><br /><span className="pl pl-1">是因仗賴馬匹，倚靠甚多的車輛，</span><br /><span className="pl pl-1">並倚靠強壯的馬兵，</span><br /><span className="pl pl-1">卻不仰望以色列的聖者，</span><br /><span className="pl pl-1">也不求問耶和華。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="民數記 23:19; 以賽亞書 45:7; 阿摩司書 3:6"> <span className="pl pl-1">其實，耶和華有智慧；</span><br /><span className="pl pl-1">他必降災禍，</span><br /><span className="pl pl-1">並不反悔自己的話，</span><br /><span className="pl pl-1">卻要興起攻擊那作惡之家，</span><br /><span className="pl pl-1">又攻擊那作孽幫助人的。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="以賽亞書 9:17; 以西結書 20:33–34; 以西結書 28:9"> <span className="pl pl-1">埃及人不過是人，並不是上帝；</span><br /><span className="pl pl-1">他們的馬不過是血肉，並不是靈。</span><br /><span className="pl pl-1">耶和華一伸手，那幫助人的必絆跌，</span><br /><span className="pl pl-1">那受幫助的也必跌倒，都一同滅亡。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v4" data-v="4" data-xref="何西阿書 11:10; 阿摩司書 3:8; 以賽亞書 42:13"> <span className="pl pl-1">耶和華對我如此說：</span><br /><span className="pl pl-1">獅子和少壯獅子護食咆哮，</span><br /><span className="pl pl-1">就是喊許多牧人來攻擊牠，</span><br /><span className="pl pl-1">牠總不因他們的聲音驚惶，</span><br /><span className="pl pl-1">也不因他們的喧嘩縮伏。</span><br /><span className="pl pl-1">如此，萬軍之耶和華</span><br /><span className="pl pl-1">也必降臨在錫安山岡上爭戰。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 91:4; 詩篇 37:40; 以賽亞書 37:35"> <span className="pl pl-1">雀鳥怎樣搧翅覆雛，</span><br /><span className="pl pl-1">萬軍之耶和華也要照樣保護耶路撒冷。</span><br /><span className="pl pl-1">他必保護拯救，</span><br /><span className="pl pl-1">要越門保守。</span></span>
<span className="v" id="v6" data-v="6" data-xref="耶利米書 3:22; 耶利米書 3:14; 以賽亞書 55:7"> 以色列人哪，你們深深地悖逆耶和華，現今要歸向他。</span>
<span className="v" id="v7" data-v="7" data-xref="以賽亞書 30:22; 以賽亞書 2:20; 以西結書 36:25"> 到那日，各人必將他金偶像銀偶像，就是親手所造、陷自己在罪中的，都拋棄了。</span>
<span className="v" id="v8" data-v="8" data-xref="以賽亞書 14:25; 創世記 49:15; 以賽亞書 37:7"> <span className="pl pl-1">亞述人必倒在刀下，並非人的刀；</span><br /><span className="pl pl-1">有刀要將他吞滅，並非人的刀。</span><br /><span className="pl pl-1">他必逃避這刀；</span><br /><span className="pl pl-1">他的少年人必成為服苦的。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="瑪拉基書 4:1; 以賽亞書 29:6; 利未記 6:13"> <span className="pl pl-1">他的磐石必因驚嚇挪去；</span><br /><span className="pl pl-1">他的首領必因大旗驚惶。</span><br /><span className="pl pl-1">這是那有火在錫安、</span><br /><span className="pl pl-1">有爐在耶路撒冷的耶和華說的。</span></span>
</div>

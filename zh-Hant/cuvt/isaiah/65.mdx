## 上帝對悖逆者的懲罰

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="羅馬書 10:20; 羅馬書 9:24–26; 彼得前書 2:10"> <span className="pl pl-1">素來沒有訪問我的，現在求問我；</span><br /><span className="pl pl-1">沒有尋找我的，我叫他們遇見；</span><br /><span className="pl pl-1">沒有稱為我名下的，我對他們說：</span><br /><span className="pl pl-1">我在這裏！我在這裏！</span><br /></span>

</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="羅馬書 9:27–29; 阿摩司書 9:8–9; 羅馬書 11:24–26"> <span className="pl pl-1">耶和華如此說：葡萄中尋得新酒，</span><br /><span className="pl pl-1">人就說：不要毀壞，</span><br /><span className="pl pl-1">因為福在其中。</span><br /><span className="pl pl-1">我因我僕人的緣故也必照樣而行，</span><br /><span className="pl pl-1">不將他們全然毀滅。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="阿摩司書 9:11–15; 以賽亞書 27:6; 羅馬書 11:5–7"> <span className="pl pl-1">我必從雅各中領出後裔，</span><br /><span className="pl pl-1">從猶大中領出承受我眾山的。</span><br /><span className="pl pl-1">我的選民必承受；</span><br /><span className="pl pl-1">我的僕人要在那裏居住。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="以賽亞書 35:2; 以賽亞書 33:9; 何西阿書 2:15"> <span className="pl pl-1">沙崙平原必成為羊群的圈；</span><br /><span className="pl pl-1">亞割谷必成為牛群躺臥之處，</span><br /><span className="pl pl-1">都為尋求我的民所得。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="以賽亞書 2:2; 以賽亞書 1:28; 申命記 32:17"> <span className="pl pl-1">但你們這些離棄耶和華、</span><br /><span className="pl pl-1">忘記我的聖山、給時運擺筵席</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原文是桌子">b</a></sup><br /><span className="pl pl-1">、</span><br /><span className="pl pl-1">給天命盛滿調和酒的，</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="耶利米書 7:13; 歷代志下 36:15–16; 撒迦利亞書 7:11–13"> <span className="pl pl-1">我要命定你們歸在刀下，</span><br /><span className="pl pl-1">都必屈身被殺；</span><br /><span className="pl pl-1">因為我呼喚，你們沒有答應；</span><br /><span className="pl pl-1">我說話，你們沒有聽從；</span><br /><span className="pl pl-1">反倒行我眼中看為惡的，</span><br /><span className="pl pl-1">揀選我所不喜悅的。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v13" data-v="13" data-xref="瑪拉基書 3:18; 以賽亞書 66:14; 以賽亞書 61:7"> <span className="pl pl-1">所以，主耶和華如此說：</span><br /><span className="pl pl-1">我的僕人必得吃，你們卻飢餓；</span><br /><span className="pl pl-1">我的僕人必得喝，你們卻乾渴；</span><br /><span className="pl pl-1">我的僕人必歡喜，你們卻蒙羞。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="馬太福音 8:12; 詩篇 66:4; 馬太福音 22:13"> <span className="pl pl-1">我的僕人因心中高興歡呼，</span><br /><span className="pl pl-1">你們卻因心中憂愁哀哭，</span><br /><span className="pl pl-1">又因心裏憂傷哀號。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="以賽亞書 62:2; 羅馬書 9:26; 使徒行傳 11:26"> <span className="pl pl-1">你們必留下自己的名，</span><br /><span className="pl pl-1">為我選民指着賭咒。</span><br /><span className="pl pl-1">主耶和華必殺你們，</span><br /><span className="pl pl-1">另起別名稱呼他的僕人。</span><br /></span>

</div>

## 新天新地

<div className="bp poetry">

<span className="v" id="v18" data-v="18" data-xref="詩篇 98:1–9; 啟示錄 19:1–6; 以賽亞書 66:10–14"> <span className="pl pl-1">你們當因我所造的永遠歡喜快樂；</span><br /><span className="pl pl-1">因我造耶路撒冷為人所喜，</span><br /><span className="pl pl-1">造其中的居民為人所樂。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="啟示錄 21:4; 啟示錄 7:17; 以賽亞書 25:8"> <span className="pl pl-1">我必因耶路撒冷歡喜，</span><br /><span className="pl pl-1">因我的百姓快樂；</span><br /><span className="pl pl-1">其中必不再聽見哭泣的聲音和哀號的聲音。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="約伯記 5:26; 傳道書 8:12–13; 申命記 4:40"> <span className="pl pl-1">其中必沒有數日夭亡的嬰孩，</span><br /><span className="pl pl-1">也沒有壽數不滿的老者；</span><br /><span className="pl pl-1">因為百歲死的仍算孩童，</span><br /><span className="pl pl-1">有百歲死的罪人算被咒詛。</span><br /></span>

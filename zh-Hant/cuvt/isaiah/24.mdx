## 耶和華要責罰世界

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="那鴻書 2:10; 以賽亞書 2:19; 以賽亞書 42:15"> <span className="pl pl-1">看哪，耶和華使地空虛，變為荒涼；</span><br /><span className="pl pl-1">又翻轉大地，將居民分散。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="何西阿書 4:9; 耶利米哀歌 5:12–14; 以西結書 7:12–13"> <span className="pl pl-1">那時百姓怎樣，祭司也怎樣；</span><br /><span className="pl pl-1">僕人怎樣，主人也怎樣；</span><br /><span className="pl pl-1">婢女怎樣，主母也怎樣；</span><br /><span className="pl pl-1">買物的怎樣，賣物的也怎樣；</span><br /><span className="pl pl-1">放債的怎樣，借債的也怎樣；</span><br /><span className="pl pl-1">取利的怎樣，出利的也怎樣。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="以賽亞書 24:1; 以賽亞書 6:11; 申命記 29:23"> <span className="pl pl-1">地必全然空虛，盡都荒涼；</span><br /><span className="pl pl-1">因為這話是耶和華說的。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v4" data-v="4" data-xref="何西阿書 4:3; 以賽亞書 33:9; 以賽亞書 3:26"> <span className="pl pl-1">地上悲哀衰殘，</span><br /><span className="pl pl-1">世界敗落衰殘；</span><br /><span className="pl pl-1">地上居高位的人也敗落了。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="希伯來書 13:20; 羅馬書 8:20–21; 但以理書 7:25"> <span className="pl pl-1">地被其上的居民污穢；</span><br /><span className="pl pl-1">因為他們犯了律法，</span><br /><span className="pl pl-1">廢了律例，背了永約。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="瑪拉基書 4:1; 馬太福音 7:14; 撒迦利亞書 5:3–4"> <span className="pl pl-1">所以，地被咒詛吞滅；</span><br /><span className="pl pl-1">住在其上的顯為有罪。</span><br /><span className="pl pl-1">地上的居民被火焚燒，</span><br /><span className="pl pl-1">剩下的人稀少。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="以賽亞書 16:10; 約珥書 1:10–12; 以賽亞書 16:8"> <span className="pl pl-1">新酒悲哀，葡萄樹衰殘；</span><br /><span className="pl pl-1">心中歡樂的俱都歎息。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="何西阿書 2:11; 啟示錄 18:22; 以西結書 26:13"> <span className="pl pl-1">擊鼓之樂止息；</span><br /><span className="pl pl-1">宴樂人的聲音完畢，</span><br /><span className="pl pl-1">彈琴之樂也止息了。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="以賽亞書 5:22; 傳道書 9:7; 以賽亞書 5:20"> <span className="pl pl-1">人必不得飲酒唱歌；</span><br /><span className="pl pl-1">喝濃酒的，必以為苦。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="啟示錄 18:2; 啟示錄 17:5–6; 以賽亞書 24:12"> <span className="pl pl-1">荒涼的城拆毀了；</span><br /><span className="pl pl-1">各家關門閉戶，使人都不得進去。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="何西阿書 7:14; 以賽亞書 24:7–9; 耶利米書 48:33"> <span className="pl pl-1">在街上因酒有悲歎的聲音；</span><br /><span className="pl pl-1">一切喜樂變為昏暗；</span><br /><span className="pl pl-1">地上的歡樂歸於無有。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="耶利米書 9:11; 彌迦書 1:12; 耶利米哀歌 5:18"> <span className="pl pl-1">城中只有荒涼；</span><br /><span className="pl pl-1">城門拆毀淨盡。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="以賽亞書 1:9; 以西結書 6:8–11; 以西結書 11:16–20"> <span className="pl pl-1">在地上的萬民中，</span><br /><span className="pl pl-1">必像打過的橄欖樹，</span><br /><span className="pl pl-1">又像已摘的葡萄所剩無幾。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="以賽亞書 40:9; 耶利米書 31:12; 以賽亞書 54:1"> <span className="pl pl-1">這些人要高聲歡呼；</span><br /><span className="pl pl-1">他們為耶和華的威嚴，從海那裏揚起聲來。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="瑪拉基書 1:11; 以賽亞書 42:4; 以賽亞書 60:9"> <span className="pl pl-1">因此，你們要在東方榮耀耶和華，</span><br /><span className="pl pl-1">在眾海島榮耀耶和華－以色列上帝的名。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="以賽亞書 21:2; 耶利米書 5:11; 以賽亞書 33:1"> <span className="pl pl-1">我們聽見從地極有人歌唱，說：</span><br /><span className="pl pl-1">榮耀歸於義人。</span><br /><span className="pl pl-1">我卻說：我消滅了！</span><br /><span className="pl pl-1">我消滅了，我有禍了！</span><br /><span className="pl pl-1">詭詐的行詭詐；</span><br /><span className="pl pl-1">詭詐的大行詭詐。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v17" data-v="17" data-xref="耶利米書 48:43–44; 列王紀上 19:17; 利未記 26:21–22"> <span className="pl pl-1">地上的居民哪，</span><br /><span className="pl pl-1">恐懼、陷坑、網羅都臨近你。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="創世記 7:11; 詩篇 18:7; 約書亞記 10:10–11"> <span className="pl pl-1">躲避恐懼聲音的必墜入陷坑；</span><br /><span className="pl pl-1">從陷坑上來的必被網羅纏住；</span><br /><span className="pl pl-1">因為天上的窗戶都開了，</span><br /><span className="pl pl-1">地的根基也震動了。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="以賽亞書 34:4–10; 申命記 11:6; 啟示錄 20:11"> <span className="pl pl-1">地全然破壞，盡都崩裂，</span><br /><span className="pl pl-1">大大地震動了。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="以賽亞書 19:14; 何西阿書 4:1–5; 但以理書 11:19"> <span className="pl pl-1">地要東倒西歪，好像醉酒的人；</span><br /><span className="pl pl-1">又搖來搖去，好像吊床。</span><br /><span className="pl pl-1">罪過在其上沉重，</span><br /><span className="pl pl-1">必然塌陷，不能復起。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v21" data-v="21" data-xref="詩篇 76:12; 以賽亞書 34:2–17; 撒迦利亞書 14:12–19"> <span className="pl pl-1">到那日，耶和華在高處必懲罰高處的眾軍，</span><br /><span className="pl pl-1">在地上必懲罰地上的列王。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="撒迦利亞書 9:11; 以賽亞書 42:22; 耶利米書 38:6–13"> <span className="pl pl-1">他們必被聚集，像囚犯被聚在牢獄中，</span><br /><span className="pl pl-1">並要囚在監牢裏，</span><br /><span className="pl pl-1">多日之後便被討罪</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或譯：眷顧">a</a></sup><br /><span className="pl pl-1">。</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="以賽亞書 60:19; 啟示錄 21:23; 以賽亞書 13:10"> <span className="pl pl-1">那時，月亮要蒙羞，日頭要慚愧；</span><br /><span className="pl pl-1">因為萬軍之耶和華必在錫安山，</span><br /><span className="pl pl-1">在耶路撒冷作王；</span><br /><span className="pl pl-1">在敬畏他的長老面前，必有榮耀。</span></span>
</div>

## 保羅受患難後的感恩

<div className="bt">
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="以弗所書 1:3; 彼得前書 1:3; 羅馬書 15:5–6"> 願頌讚歸與我們的主耶穌基督的父上帝，就是發慈悲的父，賜各樣安慰的上帝。</span>
<span className="v" id="v4" data-v="4" data-xref="帖撒羅尼迦前書 5:11; 以賽亞書 51:12; 帖撒羅尼迦後書 2:16–17"> 我們在一切患難中，他就安慰我們，叫我們能用上帝所賜的安慰去安慰那遭各樣患難的人。</span>
<span className="v" id="v5" data-v="5" data-xref="歌羅西書 1:24; 腓立比書 3:10; 哥林多後書 4:10–11"> 我們既多受基督的苦楚，就靠基督多得安慰。</span>
<span className="v" id="v6" data-v="6" data-xref="提摩太後書 2:10; 哥林多後書 1:4; 哥林多後書 4:15–18"> 我們受患難呢，是為叫你們得安慰，得拯救；我們得安慰呢，也是為叫你們得安慰；這安慰能叫你們忍受我們所受的那樣苦楚。</span>
<span className="v" id="v7" data-v="7" data-xref="羅馬書 8:17–18; 帖撒羅尼迦後書 1:4–7; 雅各書 1:12"> 我們為你們所存的盼望是確定的，因為知道你們既是同受苦楚，也必同得安慰。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="哥林多後書 4:7–12; 哥林多前書 15:32; 哥林多前書 4:8"> 弟兄們，我們不要你們不曉得，我們從前在亞細亞遭遇苦難，被壓太重，力不能勝，甚至連活命的指望都絕了；</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多後書 3:5; 希伯來書 11:19; 哥林多後書 4:7"> 自己心裏也斷定是必死的，叫我們不靠自己，只靠叫死人復活的上帝。</span>
<span className="v" id="v10" data-v="10" data-xref="提摩太前書 4:10; 詩篇 34:19; 彼得後書 2:9"> 他曾救我們脫離那極大的死亡，現在仍要救我們，並且我們指望他將來還要救我們。</span>
<span className="v" id="v11" data-v="11" data-xref="腓立比書 1:19; 哥林多後書 4:15; 使徒行傳 12:5"> 你們以祈禱幫助我們，好叫許多人為我們謝恩，就是為我們因許多人所得的恩。</span>
</div>
</div>

## 保羅延期訪問哥林多

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="哥林多後書 2:17; 哥林多前書 2:13; 雅各書 3:13–18"> 我們所誇的是自己的良心，見證我們憑着上帝的聖潔和誠實；在世為人不靠人的聰明，乃靠上帝的恩惠，向你們更是這樣。</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多後書 4:2; 腓利門書 1:6; 哥林多後書 13:6"> 我們現在寫給你們的話，並不外乎你們所念的、所認識的，我也盼望你們到底還是要認識；</span>
<span className="v" id="v14" data-v="14" data-xref="腓立比書 2:16; 哥林多前書 1:8; 帖撒羅尼迦前書 2:19–20"> 正如你們已經有幾分認識我們，以我們誇口，好像我們在我們主耶穌的日子以你們誇口一樣。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="哥林多前書 4:19; 羅馬書 1:11; 羅馬書 15:29"> 我既然這樣深信，就早有意到你們那裏去，叫你們再得益處；</span>
<span className="v" id="v16" data-v="16" data-xref="哥林多前書 16:5–7; 使徒行傳 21:5; 使徒行傳 19:21–22"> 也要從你們那裏經過，往馬其頓去，再從馬其頓回到你們那裏，叫你們給我送行往猶太去。</span>
<span className="v" id="v17" data-v="17" data-xref="馬太福音 5:37; 雅各書 5:12; 哥林多後書 10:2–3"> 我有此意，豈是反覆不定嗎？我所起的意，豈是從情慾起的，叫我忽是忽非嗎？</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前書 1:9; 啟示錄 3:7; 約翰福音 7:28"> 我指着信實的上帝說，我們向你們所傳的道，並沒有是而又非的。</span>
<span className="v" id="v19" data-v="19" data-xref="希伯來書 13:8; 啟示錄 1:17; 約翰二書 1:9"> 因為我和西拉並提摩太，在你們中間所傳上帝的兒子耶穌基督，總沒有是而又非的，在他只有一是。</span>
<span className="v" id="v20" data-v="20" data-xref="約翰一書 2:24–25; 加拉太書 3:22; 啟示錄 7:12"> 上帝的應許，不論有多少，在基督都是是的。所以藉着他也都是實在<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="實在：原文是阿們">a</a></sup>的，叫上帝因我們得榮耀。</span>
<span className="v" id="v21" data-v="21" data-xref="約翰一書 2:27; 彼得前書 5:10; 約翰一書 2:20"> 那在基督裏堅固我們和你們，並且膏我們的就是上帝。</span>
<span className="v" id="v22" data-v="22" data-xref="以弗所書 4:30; 哥林多後書 5:5; 以弗所書 1:13–14"> 他又用印印了我們，並賜聖靈在我們心裏作憑據<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原文是質">b</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="加拉太書 1:20; 哥林多前書 4:21; 羅馬書 1:9"> 我呼籲上帝給我的心作見證，我沒有往哥林多去是為要寬容你們。</span>
<span className="v" id="v24" data-v="24" data-xref="彼得前書 5:3; 哥林多前書 15:1; 腓立比書 1:25–26"> 我們並不是轄管你們的信心，乃是幫助你們的快樂，因為你們憑信才站立得住。</span>
</div>
</div>

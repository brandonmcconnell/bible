<span className="v" id="v1" data-v="1" data-xref="約伯記 19:25–26; 約翰一書 3:2; 彼得後書 1:13–14"> 我們原知道，我們這地上的帳棚若拆毀了，必得上帝所造，不是人手所造，在天上永存的房屋。</span>
<span className="v" id="v2" data-v="2" data-xref="羅馬書 8:23; 哥林多前書 15:53–54; 哥林多後書 5:3–4"> 我們在這帳棚裏歎息，深想得那從天上來的房屋，好像穿上衣服；</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 3:7–11; 啟示錄 16:15; 啟示錄 3:18"> 倘若穿上，被遇見的時候就不至於赤身了。</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多前書 15:53–54; 哥林多後書 5:2; 以賽亞書 25:8"> 我們在這帳棚裏歎息勞苦，並非願意脫下這個，乃是願意穿上那個，好叫這必死的被生命吞滅了。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多後書 1:22; 以弗所書 1:13–14; 羅馬書 8:23"> 為此，培植我們的就是上帝，他又賜給我們聖靈作憑據<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是質">a</a></sup>。</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多後書 5:1; 腓立比書 3:20–21; 希伯來書 11:13"> 所以，我們時常坦然無懼，並且曉得我們住在身內，便與主相離。</span>
<span className="v" id="v7" data-v="7" data-xref="希伯來書 11:1–27; 哥林多後書 4:18; 羅馬書 8:24–25"> 因我們行事為人是憑着信心，不是憑着眼見。</span>
<span className="v" id="v8" data-v="8" data-xref="腓立比書 1:20–24; 哥林多後書 5:6; 約翰福音 14:3"> 我們坦然無懼，是更願意離開身體與主同住。</span>
<span className="v" id="v9" data-v="9" data-xref="歌羅西書 1:10; 彼得後書 3:14; 羅馬書 14:18"> 所以，無論是住在身內，離開身外，我們立了志向，要得主的喜悅。</span>
<span className="v" id="v10" data-v="10" data-xref="馬太福音 16:27; 啟示錄 22:12; 以弗所書 6:8"> 因為我們眾人必要在基督臺前顯露出來，叫各人按着本身所行的，或善或惡受報。</span>
</div>

## 勸人與上帝和好的職分

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="猶大書 1:23; 希伯來書 10:31; 提摩太後書 2:24–26"> 我們既知道主是可畏的，所以勸人。但我們在上帝面前是顯明的，盼望在你們的良心裏也是顯明的。</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多後書 3:1; 哥林多後書 1:14; 加拉太書 6:12–14"> 我們不是向你們再舉薦自己，乃是叫你們因我們有可誇之處，好對那憑外貌不憑內心誇口的人，有言可答。</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多後書 11:16–17; 哥林多後書 11:1; 哥林多後書 12:6"> 我們若果顛狂，是為上帝；若果謹守，是為你們。</span>
<span className="v" id="v14" data-v="14" data-xref="加拉太書 2:20; 羅馬書 14:7–9; 馬太福音 10:37–38"> 原來基督的愛激勵我們；因我們想，一人既替眾人死，眾人就都死了；</span>
<span className="v" id="v15" data-v="15" data-xref="羅馬書 14:7–9; 彼得前書 4:2–4; 彼得前書 1:14–15"> 並且他替眾人死，是叫那些活着的人不再為自己活，乃為替他們死而復活的主活。</span>
<span className="v" id="v16" data-v="16" data-xref="歌羅西書 3:11; 腓立比書 3:7–8; 約翰福音 6:63"> 所以，我們從今以後，不憑着外貌<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原文是肉體；本節同">b</a></sup>認人了。雖然憑着外貌認過基督，如今卻不再這樣認他了。</span>
<span className="v" id="v17" data-v="17" data-xref="以西結書 36:26; 以弗所書 4:22–24; 以賽亞書 43:18–19"> 若有人在基督裏，他就是新造的人，舊事已過，都變成新的了。</span>
<span className="v" id="v18" data-v="18" data-xref="歌羅西書 1:20–21; 哥林多後書 5:19–20; 羅馬書 5:10–11"> 一切都是出於上帝；他藉着基督使我們與他和好，又將勸人與他和好的職分賜給我們。</span>
<span className="v" id="v19" data-v="19" data-xref="以賽亞書 43:25; 以賽亞書 44:22; 約翰一書 2:1–2"> 這就是上帝在基督裏，叫世人與自己和好，不將他們的過犯歸到他們身上，並且將這和好的道理託付了我們。</span>
<span className="v" id="v20" data-v="20" data-xref="以弗所書 6:20; 路加福音 14:23; 瑪拉基書 2:7"> 所以，我們作基督的使者，就好像上帝藉我們勸你們一般。我們替基督求你們與上帝和好。</span>
<span className="v" id="v21" data-v="21" data-xref="彼得前書 2:22–24; 彼得前書 3:18; 羅馬書 5:19"> 上帝使那無罪<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="無罪：原文是不知罪">c</a></sup>的，替我們成為罪，好叫我們在他裏面成為上帝的義。</span>
</div>

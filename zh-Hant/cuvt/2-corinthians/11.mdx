## 保羅和假使徒

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多後書 11:4; 哥林多前書 1:21; 哥林多後書 11:19"> 但願你們寬容我這一點愚妄，其實你們原是寬容我的。</span>
<span className="v" id="v2" data-v="2" data-xref="何西阿書 2:19–20; 以弗所書 5:26–27; 以賽亞書 54:5"> 我為你們起的憤恨，原是上帝那樣的憤恨。因為我曾把你們許配一個丈夫，要把你們如同貞潔的童女，獻給基督。</span>
<span className="v" id="v3" data-v="3" data-xref="歌羅西書 2:8; 加拉太書 1:6; 以弗所書 4:14"> 我只怕你們的心或偏於邪，失去那向基督所存純一清潔的心，就像蛇用詭詐誘惑了夏娃一樣。</span>
<span className="v" id="v4" data-v="4" data-xref="加拉太書 1:6–8; 哥林多前書 3:11; 提摩太前書 2:5"> 假如有人來另傳一個耶穌，不是我們所傳過的；或者你們另受一個靈，不是你們所受過的；或者另得一個福音，不是你們所得過的；你們容讓他也就罷了。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多後書 12:11–12; 哥林多前書 15:10; 加拉太書 2:6–9"> 但我想，我一點不在那些最大的使徒以下。</span>
<span className="v" id="v6" data-v="6" data-xref="以弗所書 3:4; 哥林多前書 1:17; 哥林多後書 4:2"> 我的言語雖然粗俗，我的知識卻不粗俗。這是我們在凡事上向你們眾人顯明出來的。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="哥林多後書 12:13; 帖撒羅尼迦前書 2:9; 哥林多後書 10:1"> 我因為白白傳上帝的福音給你們，就自居卑微，叫你們高升，這算是我犯罪嗎？</span>
<span className="v" id="v8" data-v="8" data-xref="腓立比書 4:18; 哥林多後書 11:9; 腓立比書 4:14–16"> 我虧負了別的教會，向他們取了工價來給你們效力。</span>
<span className="v" id="v9" data-v="9" data-xref="帖撒羅尼迦後書 3:8–9; 帖撒羅尼迦前書 2:9; 帖撒羅尼迦前書 2:6"> 我在你們那裏缺乏的時候，並沒有累着你們一個人；因我所缺乏的，那從馬其頓來的弟兄們都補足了。我向來凡事謹守，後來也必謹守，總不至於累着你們。</span>
<span className="v" id="v10" data-v="10" data-xref="羅馬書 9:1; 羅馬書 1:9; 使徒行傳 18:12"> 既有基督的誠實在我裏面，就無人能在亞該亞一帶地方阻擋我這自誇。</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多後書 12:15; 哥林多後書 6:11–12; 哥林多後書 7:3"> 為甚麼呢？是因我不愛你們嗎？這有上帝知道。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="哥林多前書 9:12; 哥林多前書 5:6; 哥林多後書 5:12"> 我現在所做的，後來還要做，為要斷絕那些尋機會人的機會，使他們在所誇的事上也不過與我們一樣。</span>
<span className="v" id="v13" data-v="13" data-xref="加拉太書 1:7; 啟示錄 2:2; 約翰一書 4:1"> 那等人是假使徒，行事詭詐，裝作基督使徒的模樣。</span>
<span className="v" id="v14" data-v="14" data-xref="加拉太書 1:8; 哥林多後書 2:11; 哥林多後書 11:3"> 這也不足為怪，因為連撒但也裝作光明的天使。</span>
<span className="v" id="v15" data-v="15" data-xref="腓立比書 3:19; 啟示錄 9:11; 以賽亞書 9:14–15"> 所以他的差役，若裝作仁義的差役，也不算希奇。他們的結局必然照着他們的行為。</span>
</div>
</div>

## 保羅作使徒所受的患難

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="哥林多後書 11:1; 哥林多後書 12:6; 哥林多後書 12:11"> 我再說，人不可把我看作愚妄的。縱然如此，也要把我當作愚妄人接納，叫我可以略略自誇。</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多前書 7:12; 腓立比書 3:3–6; 哥林多後書 9:4"> 我說的話不是奉主命說的，乃是像愚妄人放膽自誇；</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前書 4:10; 哥林多後書 11:21–23; 哥林多後書 10:12–18"> 既有好些人憑着血氣自誇，我也要自誇了。</span>
<span className="v" id="v19" data-v="19" data-xref="哥林多前書 4:10; 哥林多前書 10:15; 哥林多前書 8:1"> 你們既是精明人，就能甘心忍耐愚妄人。</span>
<span className="v" id="v20" data-v="20" data-xref="加拉太書 2:4; 加拉太書 4:3; 加拉太書 5:1"> 假若有人強你們作奴僕，或侵吞你們，或擄掠你們，或侮慢你們，或打你們的臉，你們都能忍耐他。</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多後書 10:10; 哥林多後書 11:17; 哥林多後書 10:1–2"> 我說這話是羞辱自己，好像我們從前是軟弱的。然而，人在何事上勇敢，（我說句愚妄話，）我也勇敢。</span>
<span className="v" id="v22" data-v="22" data-xref="腓立比書 3:5; 羅馬書 11:1; 羅馬書 9:4"> 他們是希伯來人嗎？我也是。他們是以色列人嗎？我也是。他們是亞伯拉罕的後裔嗎？我也是。</span>
<span className="v" id="v23" data-v="23" data-xref="哥林多後書 6:4–5; 哥林多後書 1:9–10; 哥林多後書 6:9"> 他們是基督的僕人嗎？（我說句狂話，）我更是。我比他們多受勞苦，多下監牢，受鞭打是過重的，冒死是屢次有的。</span>
<span className="v" id="v24" data-v="24" data-xref="馬可福音 13:9; 申命記 25:2–3; 馬太福音 10:17"> 被猶太人鞭打五次，每次四十減去一下；</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行傳 14:19; 使徒行傳 16:37; 希伯來書 11:37"> 被棍打了三次；被石頭打了一次；遇着船壞三次，一晝一夜在深海裏。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行傳 14:5; 使徒行傳 17:5; 使徒行傳 13:50"> 又屢次行遠路，遭江河的危險、盜賊的危險、同族的危險、外邦人的危險、城裏的危險、曠野的危險、海中的危險、假弟兄的危險。</span>
<span className="v" id="v27" data-v="27" data-xref="腓立比書 4:12; 哥林多後書 6:5; 帖撒羅尼迦前書 2:9"> 受勞碌、受困苦，多次不得睡，又飢又渴，多次不得食，受寒冷，赤身露體。</span>
<span className="v" id="v28" data-v="28" data-xref="哥林多前書 7:17; 羅馬書 15:16; 使徒行傳 20:18–35"> 除了這外面的事，還有為眾教會掛心的事，天天壓在我身上。</span>
<span className="v" id="v29" data-v="29" data-xref="哥林多前書 8:13; 哥林多前書 9:22; 加拉太書 4:8–20"> 有誰軟弱，我不軟弱呢？有誰跌倒，我不焦急呢？</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="哥林多後書 12:5–11; 箴言 25:27; 哥林多前書 2:3"> 我若必須自誇，就誇那關乎我軟弱的事便了。</span>
<span className="v" id="v31" data-v="31" data-xref="羅馬書 9:5; 以弗所書 1:3; 約翰福音 10:30"> 那永遠可稱頌之主耶穌的父上帝知道我不說謊。</span>
<span className="v" id="v32" data-v="32" data-xref="使徒行傳 9:24–25; 哥林多後書 11:26"> 在大馬士革的亞哩達王手下的提督把守大馬士革城，要捉拿我，</span>
<span className="v" id="v33" data-v="33" data-xref="使徒行傳 9:25; 撒母耳記上 19:12; 約書亞記 2:18"> 我就從窗戶中，在筐子裏，從城牆上被人縋下去，脫離了他的手。</span>
</div>
</div>

## 異象和啟示

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="加拉太書 1:12; 哥林多後書 12:7; 約翰一書 5:20"> 我自誇固然無益，但我是不得已的。如今我要說到主的顯現和啟示。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行傳 22:17; 以西結書 8:1–3; 帖撒羅尼迦前書 4:17"> 我認得一個在基督裏的人，他前十四年被提到第三層天上去；（或在身內，我不知道；或在身外，我也不知道；只有上帝知道。）</span>
<span className="v" id="v3" data-v="3"> 我認得這人；（或在身內，或在身外，我都不知道，只有上帝知道。）</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 23:43; 啟示錄 2:7; 以西結書 31:9"> 他被提到樂園裏，聽見隱祕的言語，是人不可說的。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多後書 11:30; 哥林多前書 2:3; 哥林多後書 12:9–10"> 為這人，我要誇口；但是為我自己，除了我的軟弱以外，我並不誇口。</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多後書 11:16; 哥林多後書 11:31; 哥林多後書 12:11"> 我就是願意誇口也不算狂，因為我必說實話；只是我禁止不說，恐怕有人把我看高了，過於他在我身上所看見、所聽見的。</span>
<span className="v" id="v7" data-v="7" data-xref="民數記 33:55; 士師記 2:3; 歷代志下 32:25–26"> 又恐怕我因所得的啟示甚大，就過於自高，所以有一根刺加在我肉體上，就是撒但的差役要攻擊我，免得我過於自高。</span>
<span className="v" id="v8" data-v="8" data-xref="希伯來書 5:7; 馬太福音 26:39–44; 撒母耳記上 15:11"> 為這事，我三次求過主，叫這刺離開我。</span>
<span className="v" id="v9" data-v="9" data-xref="腓立比書 4:13; 哥林多後書 12:10; 以賽亞書 40:29–31"> 他對我說：「我的恩典夠你用的，因為我的能力是在人的軟弱上顯得完全。」所以，我更喜歡誇自己的軟弱，好叫基督的能力覆庇我。</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多後書 12:9; 以弗所書 6:10; 羅馬書 5:3"> 我為基督的緣故，就以軟弱、凌辱、急難、逼迫、困苦為可喜樂的；因我甚麼時候軟弱，甚麼時候就剛強了。</span>
</div>
</div>

## 保羅關心哥林多教會

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="哥林多後書 11:5; 哥林多後書 11:1; 哥林多前書 15:8–10"> 我成了愚妄人，是被你們強逼的。我本該被你們稱許才是。我雖算不了甚麼，卻沒有一件事在那些最大的使徒以下。</span>
<span className="v" id="v12" data-v="12" data-xref="羅馬書 15:18–19; 哥林多後書 11:4; 哥林多後書 4:2"> 我在你們中間，用百般的忍耐，藉着神蹟、奇事、異能顯出使徒的憑據來。</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多前書 9:12; 哥林多前書 9:6; 哥林多後書 11:7–9"> 除了我不累着你們這一件事，你們還有甚麼事不及別的教會呢？這不公之處，求你們饒恕我吧。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="箴言 19:14; 創世記 24:35–36; 哥林多前書 10:33"> 如今，我打算第三次到你們那裏去，也必不累着你們；因我所求的是你們，不是你們的財物。兒女不該為父母積財，父母該為兒女積財。</span>
<span className="v" id="v15" data-v="15" data-xref="帖撒羅尼迦前書 2:8; 哥林多後書 1:6; 腓立比書 2:17"> 我也甘心樂意為你們的靈魂費財費力。難道我越發愛你們，就越發少得你們的愛嗎？</span>
<span className="v" id="v16" data-v="16" data-xref="帖撒羅尼迦前書 2:5; 哥林多後書 10:2–3; 哥林多後書 12:13"> 罷了，我自己並沒有累着你們，你們卻有人說，我是詭詐，用心計牢籠你們。</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多後書 9:5; 哥林多前書 4:17; 列王紀下 5:20–27"> 我所差到你們那裏去的人，我藉着他們一個人佔過你們的便宜嗎？</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多後書 8:6; 羅馬書 4:12; 使徒行傳 20:33–35"> 我勸了提多到你們那裏去，又差那位兄弟與他同去。提多佔過你們的便宜嗎？我們行事，不同是一個心靈<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或譯：聖靈">a</a></sup>嗎？不同是一個腳蹤嗎？</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="羅馬書 9:1; 哥林多前書 14:26; 哥林多後書 10:8"> 你們到如今，還想我們是向你們分訴；我們本是在基督裏當上帝面前說話。親愛的弟兄啊，一切的事都是為造就你們。</span>
<span className="v" id="v20" data-v="20" data-xref="加拉太書 5:19–21; 彼得前書 2:1; 羅馬書 1:29"> 我怕我再來的時候，見你們不合我所想望的，你們見我也不合你們所想望的；又怕有紛爭、嫉妒、惱怒、結黨、毀謗、讒言、狂傲、混亂的事。</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多後書 13:2; 彼得前書 4:2–3; 歌羅西書 3:5"> 且怕我來的時候，我的上帝叫我在你們面前慚愧，又因許多人從前犯罪，行污穢、姦淫、邪蕩的事不肯悔改，我就憂愁。</span>
</div>
</div>

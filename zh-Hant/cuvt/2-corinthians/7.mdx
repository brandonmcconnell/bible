## 保羅為教會悔改而歡樂

<div className="bt">
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="使徒行傳 20:33; 哥林多後書 6:12–13; 哥林多後書 11:9"> 你們要心地寬大收納我們。我們未曾虧負誰，未曾敗壞誰，未曾佔誰的便宜。</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多後書 6:11–12; 帖撒羅尼迦前書 2:8; 哥林多後書 11:11"> 我說這話，不是要定你們的罪。我已經說過，你們常在我們心裏，情願與你們同生同死。</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多後書 1:4; 哥林多後書 3:12; 雅各書 1:2"> 我大大地放膽，向你們說話；我因你們多多誇口，滿得安慰；我們在一切患難中分外地快樂。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="哥林多後書 2:13; 申命記 32:25; 使徒行傳 20:1"> 我們從前就是到了馬其頓的時候，身體也不得安寧，周圍遭患難，外有爭戰，內有懼怕。</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多後書 1:3–4; 帖撒羅尼迦後書 2:16–17; 哥林多後書 7:13"> 但那安慰喪氣之人的上帝藉着提多來安慰了我們；</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多後書 5:2; 猶大書 1:3; 哥林多後書 8:16"> 不但藉着他來，也藉着他從你們所得的安慰，安慰了我們；因他把你們的想念、哀慟，和向我的熱心，都告訴了我，叫我更加歡喜。</span>
<span className="v" id="v8" data-v="8" data-xref="啟示錄 3:19; 耶利米書 20:7–9; 馬太福音 26:21–22"> 我先前寫信叫你們憂愁，我後來雖然懊悔，如今卻不懊悔；因我知道，那信叫你們憂愁不過是暫時的。</span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 15:7; 耶利米書 31:18–20; 哥林多後書 7:10–11"> 如今我歡喜，不是因你們憂愁，是因你們從憂愁中生出懊悔來。你們依着上帝的意思憂愁，凡事就不至於因我們受虧損了。</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行傳 3:19; 使徒行傳 11:18; 提摩太後書 2:25–26"> 因為依着上帝的意思憂愁，就生出沒有後悔的懊悔來，以致得救；但世俗的憂愁是叫人死。</span>
<span className="v" id="v11" data-v="11" data-xref="羅馬書 14:18; 提摩太前書 5:21–22; 提摩太後書 2:15"> 你看，你們依着上帝的意思憂愁，從此就生出何等的殷勤、自訴、自恨、恐懼、想念、熱心、責罰<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或譯：自責">a</a></sup>。在這一切事上，你們都表明自己是潔淨的。</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多後書 2:9; 提摩太前書 3:5; 哥林多後書 2:17"> 我雖然從前寫信給你們，卻不是為那虧負人的，也不是為那受人虧負的，乃要在上帝面前把你們顧念我們的熱心表明出來。</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多後書 7:6; 哥林多前書 12:26; 哥林多前書 16:13"> 故此，我們得了安慰。<br />並且在安慰之中，因你們眾人使提多心裏暢快歡喜，我們就更加歡喜了。</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多後書 7:4; 帖撒羅尼迦後書 1:4; 哥林多後書 1:18–20"> 我若對提多誇獎了你們甚麼，也覺得沒有慚愧；因我對提多誇獎你們的話成了真的，正如我對你們所說的話也都是真的。</span>
<span className="v" id="v15" data-v="15" data-xref="腓立比書 2:12; 哥林多後書 2:9; 約翰一書 3:17"> 並且提多想起你們眾人的順服，是怎樣恐懼戰兢地接待他，他愛你們的心腸就越發熱了。</span>
<span className="v" id="v16" data-v="16" data-xref="哥林多後書 2:3; 腓利門書 1:8; 腓利門書 1:21"> 我如今歡喜，能在凡事上為你們放心。</span>
</div>

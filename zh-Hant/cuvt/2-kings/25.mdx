## 耶路撒冷陷落

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="耶利米書 52:4–11; 歷代志上 6:15; 耶利米書 34:1–6"> 西底家背叛巴比倫王。他作王第九年十月初十日，巴比倫王尼布甲尼撒率領全軍來攻擊耶路撒冷，對城安營，四圍築壘攻城。</span>
<span className="v" id="v2" data-v="2"> 於是城被圍困，直到西底家王十一年。</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米書 52:6; 以西結書 5:12; 耶利米書 38:2"> 四月初九日，城裏有大饑荒，甚至百姓都沒有糧食。</span>
<span className="v" id="v4" data-v="4" data-xref="以西結書 33:21; 列王紀下 25:5; 耶利米書 39:2–7"> 城被攻破，一切兵丁就在夜間從靠近王園兩城中間的門逃跑。迦勒底人正在四圍攻城，王就向亞拉巴逃走。</span>
<span className="v" id="v5" data-v="5" data-xref="以賽亞書 30:16; 耶利米書 39:5; 阿摩司書 2:14–16"> 迦勒底的軍隊追趕王，在耶利哥的平原追上他；他的全軍都離開他四散了。</span>
<span className="v" id="v6" data-v="6" data-xref="列王紀下 23:33; 耶利米書 34:21–22; 耶利米書 21:7"> 迦勒底人就拿住王，帶他到在利比拉的巴比倫王那裏審判他。</span>
<span className="v" id="v7" data-v="7" data-xref="耶利米書 32:4–5; 士師記 16:21; 耶利米書 39:6–7"> 在西底家眼前殺了他的眾子，並且剜了西底家的眼睛，用銅鍊鎖着他，帶到巴比倫去。</span>
</div>
</div>

## 聖殿被毀

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="耶利米書 52:12–16; 耶利米書 40:1–4; 耶利米哀歌 4:12"> 巴比倫王尼布甲尼撒十九年五月初七日，巴比倫王的臣僕、護衛長尼布撒拉旦來到耶路撒冷，</span>
<span className="v" id="v9" data-v="9" data-xref="阿摩司書 2:5; 詩篇 74:3–7; 列王紀上 9:8"> 用火焚燒耶和華的殿和王宮，又焚燒耶路撒冷的房屋，就是各大戶家的房屋。</span>
<span className="v" id="v10" data-v="10" data-xref="尼希米記 1:3; 耶利米書 39:8; 耶利米書 52:14–23"> 跟從護衛長迦勒底的全軍就拆毀耶路撒冷四圍的城牆。</span>
<span className="v" id="v11" data-v="11" data-xref="以西結書 5:2; 耶利米書 15:1–2; 耶利米書 39:9"> 那時護衛長尼布撒拉旦將城裏所剩下的百姓，並已經投降巴比倫王的人，以及大眾所剩下的人，都擄去了。</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米書 40:7; 列王紀下 24:14; 以西結書 33:24"> 但護衛長留下些民中最窮的，使他們修理葡萄園，耕種田地。</span>
<span className="v" id="v13" data-v="13" data-xref="歷代志下 36:18; 耶利米哀歌 1:10; 列王紀下 20:17"> 耶和華殿的銅柱，並耶和華殿的盆座和銅海，迦勒底人都打碎了，將那銅運到巴比倫去了，</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及記 27:3; 列王紀上 7:47–50; 出埃及記 38:3"> 又帶去鍋、鏟子、蠟剪、調羹，並所用的一切銅器，</span>
<span className="v" id="v15" data-v="15" data-xref="但以理書 5:2–3; 民數記 7:13–14; 列王紀上 7:48–51"> 火鼎、碗，無論金的銀的，護衛長也都帶去了。</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀上 7:47"> 所羅門為耶和華殿所造的兩根銅柱、一個銅海，和幾個盆座，這一切的銅，多得無法可稱。</span>
<span className="v" id="v17" data-v="17" data-xref="列王紀上 7:15–22; 耶利米書 52:21–23"> 這一根柱子高十八肘，柱上有銅頂，高三肘；銅頂的周圍有網子和石榴，都是銅的。那一根柱子，照此一樣，也有網子。</span>
</div>
</div>

## 猶大人被擄

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="耶利米書 29:25; 以斯拉記 7:1; 耶利米書 21:1"> 護衛長拿住大祭司西萊雅、副祭司西番亞，和三個把門的，</span>
<span className="v" id="v19" data-v="19" data-xref="以斯帖記 1:14"> 又從城中拿住一個管理兵丁的官<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或譯：太監">a</a></sup>，並在城裏所遇常見王面的五個人和檢點國民軍長的書記，以及城裏遇見的國民六十個人。</span>
<span className="v" id="v20" data-v="20" data-xref="耶利米哀歌 4:16; 耶利米書 52:26–27; 列王紀下 23:33"> 護衛長尼布撒拉旦將這些人帶到在利比拉的巴比倫王那裏。</span>
<span className="v" id="v21" data-v="21" data-xref="申命記 28:64; 列王紀下 23:27; 申命記 4:26"> 巴比倫王就把他們擊殺在哈馬地的利比拉。這樣，猶大人被擄去離開本地。</span>
</div>
</div>

## 立基大利作猶大省長

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="耶利米書 39:14; 列王紀下 22:12; 耶利米書 41:2"> 至於猶大國剩下的民，就是巴比倫王尼布甲尼撒所剩下的，巴比倫王立了沙番的孫子、亞希甘的兒子基大利作他們的省長。</span>
<span className="v" id="v23" data-v="23" data-xref="耶利米書 40:7–9; 耶利米書 40:11–12; 約書亞記 18:26"> 眾軍長和屬他們的人聽見巴比倫王立了基大利作省長，於是軍長尼探雅的兒子以實瑪利、加利亞的兒子約哈難、尼陀法人單戶蔑的兒子西萊雅、瑪迦人的兒子雅撒尼亞，和屬他們的人都到米斯巴見基大利。</span>
<span className="v" id="v24" data-v="24" data-xref="耶利米書 40:9–10; 耶利米書 43:6; 撒母耳記下 19:23"> 基大利向他們和屬他們的人起誓說：「你們不必懼怕迦勒底臣僕，只管住在這地服事巴比倫王，就可以得福。」</span>
<span className="v" id="v25" data-v="25" data-xref="撒迦利亞書 7:5; 撒迦利亞書 8:19; 耶利米書 40:15"> 七月間，宗室以利沙瑪的孫子、尼探雅的兒子以實瑪利帶着十個人來，殺了基大利和同他在米斯巴的猶大人與迦勒底人。</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米書 43:4–7; 耶利米書 41:16–18; 耶利米書 42:14–22"> 於是眾民，無論大小，連眾軍長；因為懼怕迦勒底人，都起身往埃及去了。</span>
</div>
</div>

## 約雅斤被釋

<div className="bt">
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="耶利米書 52:31–34; 創世記 40:20; 創世記 40:13"> 猶大王約雅斤被擄後三十七年，巴比倫王以未‧米羅達元年十二月二十七日，使猶大王約雅斤抬頭，提他出監；</span>
<span className="v" id="v28" data-v="28" data-xref="但以理書 2:37; 耶利米書 27:6–11; 但以理書 5:18–19"> 又對他說恩言，使他的位高過與他一同在巴比倫眾王的位，</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳記下 9:7; 以賽亞書 61:3; 創世記 41:42"> 給他脫了囚服。他終身常在巴比倫王面前吃飯。</span>
<span className="v" id="v30" data-v="30" data-xref="路加福音 11:3; 馬太福音 6:11; 尼希米記 11:23"> 王賜他所需用的食物，日日賜他一分，終身都是這樣。</span>
</div>

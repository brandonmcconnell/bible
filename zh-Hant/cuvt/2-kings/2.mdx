## 以利亞被接升天

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 5:24; 希伯來書 11:5; 列王紀上 19:16–21"> 耶和華要用旋風接以利亞升天的時候，以利亞與以利沙從吉甲前往。</span>
<span className="v" id="v2" data-v="2" data-xref="列王紀下 2:6; 路得記 1:15–18; 列王紀下 4:30"> 以利亞對以利沙說：「耶和華差我往伯特利去，你可以在這裏等候。」以利沙說：「我指着永生的耶和華，又敢在你面前起誓，我必不離開你。」於是二人下到伯特利。</span>
<span className="v" id="v3" data-v="3" data-xref="列王紀下 4:1; 列王紀下 4:38; 列王紀下 9:1"> 住伯特利的先知門徒出來見以利沙，對他說：「耶和華今日要接你的師傅離開你，你知道不知道？」他說：「我知道，你們不要作聲。」</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀下 2:2; 約書亞記 6:26; 列王紀上 16:34"> 以利亞對以利沙說：「耶和華差遣我往耶利哥去，你可以在這裏等候。」以利沙說：「我指着永生的耶和華，又敢在你面前起誓，我必不離開你。」於是二人到了耶利哥。</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀下 2:3; 約書亞記 1:1–2; 使徒行傳 1:11"> 住耶利哥的先知門徒就近以利沙，對他說：「耶和華今日要接你的師傅離開你，你知道不知道？」他說：「我知道，你們不要作聲。」</span>
<span className="v" id="v6" data-v="6" data-xref="列王紀下 2:2; 約書亞記 3:15"> 以利亞對以利沙說：「耶和華差遣我往約旦河去，你可以在這裏等候。」以利沙說：「我指着永生的耶和華，又敢在你面前起誓，我必不離開你。」於是二人一同前往。</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀上 18:13; 列王紀下 2:17; 列王紀上 18:4"> 有先知門徒去了五十人，遠遠地站在他們對面；二人在約旦河邊站住。</span>
<span className="v" id="v8" data-v="8" data-xref="列王紀上 19:19; 出埃及記 14:21–22; 約書亞記 3:14–17"> 以利亞將自己的外衣捲起來，用以打水，水就左右分開，二人走乾地而過。</span>
<span className="v" id="v9" data-v="9" data-xref="民數記 11:17; 申命記 21:17; 約翰福音 16:7"> 過去之後，以利亞對以利沙說：「我未曾被接去離開你，你要我為你做甚麼，只管求我。」以利沙說：「願感動你的靈加倍地感動我。」</span>
<span className="v" id="v10" data-v="10" data-xref="馬可福音 11:22–24; 列王紀下 2:12; 約翰福音 16:24"> 以利亞說：「你所求的難得。雖然如此，我被接去離開你的時候，你若看見我，就必得着；不然，必得不着了。」</span>
</div>
</div>

## 以利亞乘旋風升天

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="列王紀下 6:17; 詩篇 104:3–4; 希伯來書 1:14"> 他們正走着說話，忽有火車火馬將二人隔開，以利亞就乘旋風升天去了。</span>
<span className="v" id="v12" data-v="12" data-xref="列王紀下 13:14; 以賽亞書 37:21; 馬可福音 16:19"> 以利沙看見，就呼叫說：「我父啊！我父啊！以色列的戰車馬兵啊！」以後不再見他了。 於是以利沙把自己的衣服撕為兩片。</span>
<span className="v" id="v13" data-v="13" data-xref="列王紀上 19:19; 列王紀下 2:8; 列王紀上 9:26"> 他拾起以利亞身上掉下來的外衣，回去站在約旦河邊。</span>
<span className="v" id="v14" data-v="14" data-xref="約翰福音 14:12; 詩篇 42:10; 詩篇 115:2"> 他用以利亞身上掉下來的外衣打水，說：「耶和華－以利亞的上帝在哪裏呢？」打水之後，水也左右分開，以利沙就過來了。</span>
<span className="v" id="v15" data-v="15" data-xref="彼得前書 4:14; 使徒行傳 1:8; 約書亞記 3:7"> 住耶利哥的先知門徒從對面看見他，就說：「感動以利亞的靈感動以利沙了。」他們就來迎接他，在他面前俯伏於地，</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀上 18:12; 使徒行傳 8:39; 哥林多後書 12:2–3"> 對他說：「僕人們這裏有五十個壯士，求你容他們去尋找你師傅，或者耶和華的靈將他提起來，投在某山某谷。」以利沙說：「你們不必打發人去。」</span>
<span className="v" id="v17" data-v="17" data-xref="列王紀下 8:11; 希伯來書 11:5; 羅馬書 10:2"> 他們再三催促他，他難以推辭，就說：「你們打發人去吧！」他們便打發五十人去，尋找了三天，也沒有找着。</span>
<span className="v" id="v18" data-v="18"> 以利沙仍然在耶利哥等候他們回到他那裏；他對他們說：「我豈沒有告訴你們不必去嗎？」</span>
</div>
</div>

## 以利沙行的神蹟

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="出埃及記 23:26; 申命記 28:2–4; 申命記 28:11"> 耶利哥城的人對以利沙說：「這城的地勢美好，我主看見了；只是水惡劣，土產不熟而落。」</span>
<span className="v" id="v20" data-v="20" data-xref="士師記 9:45; 西番雅書 2:9; 以西結書 47:11"> 以利沙說：「你們拿一個新瓶來，裝鹽給我」；他們就拿來給他。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及記 15:25–26; 列王紀下 4:41; 利未記 2:13"> 他出到水源，將鹽倒在水中，說：「耶和華如此說：『我治好了這水，從此必不再使人死，也不再使地土不生產。』」</span>
<span className="v" id="v22" data-v="22"> 於是那水治好了，直到今日，正如以利沙所說的。</span>
<span className="v" id="v23" data-v="23" data-xref="歷代志下 36:16; 約伯記 19:18; 約伯記 30:1"> 以利沙從那裏上伯特利去，正上去的時候，有些童子從城裏出來，戲笑他說：「禿頭的上去吧！禿頭的上去吧！」</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行傳 13:9–11; 使徒行傳 5:5; 何西阿書 13:8"> 他回頭看見，就奉耶和華的名咒詛他們。於是有兩個母熊從林中出來，撕裂他們中間四十二個童子。</span>
<span className="v" id="v25" data-v="25" data-xref="列王紀下 4:25; 列王紀上 18:19–20; 列王紀上 18:42"> 以利沙從伯特利上迦密山，又從迦密山回到撒馬利亞。</span>
</div>

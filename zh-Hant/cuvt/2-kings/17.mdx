## 以色列王何細亞

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀下 15:30"> 猶大王亞哈斯十二年，以拉的兒子何細亞在撒馬利亞登基作以色列王九年。</span>
<span className="v" id="v2" data-v="2" data-xref="列王紀下 3:2; 列王紀下 13:11; 歷代志下 30:5–11"> 他行耶和華眼中看為惡的事，只是不像在他以前的以色列諸王。</span>
<span className="v" id="v3" data-v="3" data-xref="何西阿書 10:14; 列王紀下 15:19; 列王紀下 19:36–37"> 亞述王撒縵以色上來攻擊何細亞，何細亞就服事他，給他進貢。</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀下 18:21; 列王紀下 24:20; 以西結書 17:13–19"> 何細亞背叛，差人去見埃及王梭，不照往年所行的與亞述王進貢。亞述王知道了，就把他鎖禁，囚在監裏。</span>
<span className="v" id="v5" data-v="5" data-xref="何西阿書 13:16; 列王紀下 25:1–3; 列王紀下 18:9"> 亞述王上來攻擊以色列遍地，上到撒馬利亞，圍困三年。</span>
<span className="v" id="v6" data-v="6" data-xref="歷代志上 5:26; 何西阿書 13:16; 申命記 28:64"> 何細亞第九年亞述王攻取了撒馬利亞，將以色列人擄到亞述，把他們安置在哈臘與歌散的哈博河邊，並米底亞人的城邑。</span>
<span className="v" id="v7" data-v="7" data-xref="約書亞記 23:16; 詩篇 106:35–41; 尼希米記 9:26"> 這是因以色列人得罪那領他們出埃及地、脫離埃及王法老手的耶和華－他們的上帝，去敬畏別神，</span>
<span className="v" id="v8" data-v="8" data-xref="利未記 18:3; 列王紀下 16:3; 申命記 18:9"> 隨從耶和華在他們面前所趕出外邦人的風俗和以色列諸王所立的條規。</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀下 18:8; 約伯記 31:27; 申命記 13:6"> 以色列人暗中行不正的事，違背耶和華－他們的上帝，在他們所有的城邑，從瞭望樓直到堅固城，建築邱壇；</span>
<span className="v" id="v10" data-v="10" data-xref="列王紀上 14:23; 彌迦書 5:14; 出埃及記 34:13"> 在各高岡上、各青翠樹下立柱像和木偶；</span>
<span className="v" id="v11" data-v="11" data-xref="歷代志下 28:25; 列王紀下 21:6; 耶利米書 44:17"> 在邱壇上燒香，效法耶和華在他們面前趕出的外邦人所行的，又行惡事惹動耶和華的怒氣；</span>
<span className="v" id="v12" data-v="12" data-xref="申命記 12:4; 出埃及記 20:3–5; 申命記 4:23–25"> 且事奉偶像，就是耶和華警戒他們不可行的。</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米書 35:15; 撒母耳記上 9:9; 耶利米書 18:11"> 但耶和華藉眾先知、先見勸戒以色列人和猶大人說：「當離開你們的惡行，謹守我的誡命律例，遵行我吩咐你們列祖，並藉我僕人眾先知所傳給你們的律法。」</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 31:27; 使徒行傳 7:51; 詩篇 106:24"> 他們卻不聽從，竟硬着頸項，效法他們列祖，不信服耶和華－他們的上帝，</span>
<span className="v" id="v15" data-v="15" data-xref="申命記 12:30–31; 申命記 32:21; 羅馬書 1:21–23"> 厭棄他的律例和他與他們列祖所立的約，並勸戒他們的話，隨從虛無的神，自己成為虛妄，效法周圍的外邦人，就是耶和華囑咐他們不可效法的；</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀上 14:23; 列王紀上 16:31; 列王紀上 14:15"> 離棄耶和華－他們上帝的一切誡命，為自己鑄了兩個牛犢的像，立了亞舍拉，敬拜天上的萬象，事奉巴力，</span>
<span className="v" id="v17" data-v="17" data-xref="列王紀下 21:6; 列王紀下 16:3; 申命記 18:10–12"> 又使他們的兒女經火，用占卜，行法術賣了自己，行耶和華眼中看為惡的事，惹動他的怒氣。</span>
<span className="v" id="v18" data-v="18" data-xref="列王紀上 12:20; 列王紀上 11:13; 何西阿書 11:12"> 所以耶和華向以色列人大大發怒，從自己面前趕出他們，只剩下猶大一個支派。</span>
<span className="v" id="v19" data-v="19" data-xref="列王紀下 16:3; 列王紀上 14:22–23; 以西結書 16:51–52"> 猶大人也不遵守耶和華－他們上帝的誡命，隨從以色列人所立的條規。</span>
<span className="v" id="v20" data-v="20" data-xref="列王紀下 15:29; 耶利米書 6:30; 列王紀下 13:3"> 耶和華就厭棄以色列全族，使他們受苦，把他們交在搶奪他們的人手中，以致趕出他們離開自己面前，</span>
<span className="v" id="v21" data-v="21" data-xref="列王紀上 11:11; 列王紀上 11:31; 列王紀上 14:16"> 將以色列國從大衛家奪回；他們就立尼八的兒子耶羅波安作王。耶羅波安引誘以色列人不隨從耶和華，陷在大罪裏。</span>
<span className="v" id="v22" data-v="22" data-xref="列王紀下 3:3; 列王紀下 13:6; 列王紀下 13:11"> 以色列人犯耶羅波安所犯的一切罪，總不離開，</span>
<span className="v" id="v23" data-v="23" data-xref="列王紀下 17:6; 列王紀下 17:13; 列王紀下 17:20"> 以致耶和華從自己面前趕出他們，正如藉他僕人眾先知所說的。這樣，以色列人從本地被擄到亞述，直到今日。</span>
</div>
</div>

## 亞述人定居於以色列人中

<div className="bt">
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="列王紀下 18:34; 列王紀下 17:30–31; 馬太福音 10:5"> 亞述王從巴比倫、古他、亞瓦、哈馬，和西法瓦音遷移人來，安置在撒馬利亞的城邑，代替以色列人；他們就得了撒馬利亞，住在其中。</span>
<span className="v" id="v25" data-v="25" data-xref="列王紀下 17:32; 列王紀下 17:34; 列王紀下 17:41"> 他們才住那裏的時候，不敬畏耶和華，所以耶和華叫獅子進入他們中間，咬死了些人。</span>
<span className="v" id="v26" data-v="26" data-xref="列王紀下 17:27; 撒母耳記上 8:9; 阿摩司書 8:14"> 有人告訴亞述王說：「你所遷移安置在撒馬利亞各城的那些民，不知道那地之神的規矩，所以那神叫獅子進入他們中間，咬死他們。」</span>
<span className="v" id="v27" data-v="27" data-xref="士師記 17:13; 列王紀上 12:31; 列王紀上 13:2"> 亞述王就吩咐說：「叫所擄來的祭司回去一個，使他住在那裏，將那地之神的規矩指教那些民。」</span>
<span className="v" id="v28" data-v="28" data-xref="列王紀上 12:29–32; 以賽亞書 29:13; 馬太福音 15:14"> 於是有一個從撒馬利亞擄去的祭司回來，住在伯特利，指教他們怎樣敬畏耶和華。</span>
<span className="v" id="v29" data-v="29" data-xref="列王紀上 12:31; 彌迦書 4:5; 列王紀上 13:32"> 然而，各族之人在所住的城裏各為自己製造神像，安置在撒馬利亞人所造有邱壇的殿中。</span>
<span className="v" id="v30" data-v="30" data-xref="列王紀下 17:24"> 巴比倫人造疏割‧比訥像；古他人造匿甲像；哈馬人造亞示瑪像；</span>
<span className="v" id="v31" data-v="31" data-xref="列王紀下 17:24; 列王紀下 17:17; 列王紀下 19:37"> 亞瓦人造匿哈和他珥他像；西法瓦音人用火焚燒兒女，獻給西法瓦音的神亞得米勒和亞拿米勒。</span>
<span className="v" id="v32" data-v="32" data-xref="列王紀上 12:31; 列王紀下 17:29; 列王紀上 13:33"> 他們懼怕耶和華，也從他們中間立邱壇的祭司，為他們在有邱壇的殿中獻祭。</span>
<span className="v" id="v33" data-v="33" data-xref="列王紀下 17:41; 路加福音 16:13; 馬太福音 6:24"> 他們又懼怕耶和華，又事奉自己的神，從何邦遷移，就隨何邦的風俗。</span>
<span className="v" id="v34" data-v="34" data-xref="創世記 32:28; 創世記 35:10; 列王紀下 17:27–28"> 他們直到如今仍照先前的風俗去行，不專心敬畏耶和華，不全守自己的規矩、典章，也不遵守耶和華吩咐雅各後裔的律法、誡命。（雅各，就是從前耶和華起名叫以色列的。）</span>
<span className="v" id="v35" data-v="35" data-xref="士師記 6:10; 約書亞記 23:16; 約書亞記 23:7"> 耶和華曾與他們立約，囑咐他們說：「不可敬畏別神，不可跪拜事奉他，也不可向他獻祭。</span>
<span className="v" id="v36" data-v="36" data-xref="出埃及記 6:6; 申命記 6:13; 利未記 19:32"> 但那用大能和伸出來的膀臂領你們出埃及地的耶和華，你們當敬畏，跪拜，向他獻祭。</span>
<span className="v" id="v37" data-v="37" data-xref="利未記 19:37; 申命記 5:31–2; 申命記 4:44–45"> 他給你們寫的律例、典章、律法、誡命，你們應當永遠謹守遵行，不可敬畏別神。</span>
<span className="v" id="v38" data-v="38" data-xref="申命記 4:23; 申命記 6:12; 申命記 8:14–18"> 我－耶和華與你們所立的約你們不可忘記，也不可敬畏別神。</span>
<span className="v" id="v39" data-v="39" data-xref="路加福音 1:74–75; 撒母耳記上 12:24; 馬太福音 10:28"> 但要敬畏耶和華－你們的上帝，他必救你們脫離一切仇敵的手。」</span>
<span className="v" id="v40" data-v="40" data-xref="申命記 4:28; 列王紀下 17:8; 耶利米書 13:23"> 他們卻不聽從，仍照先前的風俗去行。</span>
<span className="v" id="v41" data-v="41" data-xref="馬太福音 6:24; 西番雅書 1:5; 列王紀上 18:21"> 如此這些民又懼怕耶和華，又事奉他們的偶像。他們子子孫孫也都照樣行，效法他們的祖宗，直到今日。</span>

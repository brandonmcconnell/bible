## 亞蘭軍棄營逃命

<div className="bt">
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="利未記 13:45–46; 民數記 5:2–4; 列王紀下 7:4"> 在城門那裏有四個長大痲瘋的人，他們彼此說：「我們為何坐在這裏等死呢？</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米書 14:18; 路加福音 15:17–19; 撒母耳記下 14:14"> 我們若說，進城去吧！城裏有饑荒，必死在那裏；若在這裏坐着不動，也必是死。來吧，我們去投降亞蘭人的軍隊，他們若留我們的活命，就活着；若殺我們，就死了吧！」</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 28:7; 申命記 32:25; 撒母耳記上 30:17"> 黃昏的時候，他們起來往亞蘭人的營盤去；到了營邊，不見一人在那裏。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳記下 5:24; 以賽亞書 31:1; 列王紀上 10:29"> 因為主使亞蘭人的軍隊聽見車馬的聲音，是大軍的聲音；他們就彼此說：「這必是以色列王賄買赫人的諸王和埃及人的諸王來攻擊我們。」</span>
<span className="v" id="v7" data-v="7" data-xref="箴言 28:1; 詩篇 48:4–6; 希伯來書 6:18"> 所以，在黃昏的時候他們起來逃跑，撇下帳棚、馬、驢，營盤照舊，只顧逃命。</span>
<span className="v" id="v8" data-v="8" data-xref="馬太福音 13:44; 約書亞記 7:21; 馬太福音 25:18"> 那些長大痲瘋的到了營邊，進了帳棚，吃了喝了，且從其中拿出金銀和衣服來，去收藏了；回來又進了一座帳棚，從其中拿出財物來去收藏了。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="以賽亞書 52:7; 腓立比書 2:4; 那鴻書 1:15"> 那時，他們彼此說：「我們所做的不好！今日是有好信息的日子，我們竟不作聲！若等到天亮，罪必臨到我們。來吧，我們與王家報信去！」</span>
<span className="v" id="v10" data-v="10" data-xref="列王紀下 7:11; 馬可福音 13:34–35; 詩篇 127:1"> 他們就去叫守城門的，告訴他們說：「我們到了亞蘭人的營，不見一人在那裏，也無人聲，只有拴着的馬和驢，帳棚都照舊。」</span>
<span className="v" id="v11" data-v="11"> 守城門的叫了眾守門的人來，他們就進去與王家報信。</span>
<span className="v" id="v12" data-v="12" data-xref="列王紀下 6:25–29; 約書亞記 8:4"> 王夜間起來，對臣僕說：「我告訴你們亞蘭人向我們如何行。他們知道我們飢餓，所以離營，埋伏在田野，說：『以色列人出城的時候，我們就活捉他們，得以進城。』」</span>
<span className="v" id="v13" data-v="13" data-xref="列王紀下 7:4; 耶利米哀歌 4:9; 列王紀下 5:13"> 有一個臣僕對王說：「我們不如用城裏剩下之馬中的五匹馬（馬和城裏剩下的以色列人都是一樣，快要滅絕），打發人去窺探。」</span>
<span className="v" id="v14" data-v="14"> 於是取了兩輛車和馬，王差人去追尋亞蘭軍，說：「你們去窺探窺探。」</span>
<span className="v" id="v15" data-v="15" data-xref="以賽亞書 22:24; 馬太福音 24:16–18; 希伯來書 12:1"> 他們就追尋到約旦河，看見滿道上都是亞蘭人急跑時丟棄的衣服器具，使者就回來報告王。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="列王紀下 7:1; 以賽亞書 33:4; 以賽亞書 33:23"> 眾人就出去，擄掠亞蘭人的營盤。於是一細亞細麵賣銀一舍客勒，二細亞大麥也賣銀一舍客勒，正如耶和華所說的。</span>
<span className="v" id="v17" data-v="17" data-xref="列王紀下 7:2; 列王紀下 6:32; 士師記 20:43"> 王派攙扶他的那軍長在城門口彈壓，眾人在那裏將他踐踏，他就死了，正如神人在王下來見他的時候所說的。</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 18:14; 列王紀下 7:1–2; 列王紀下 6:32"> 神人曾對王說：「明日約到這時候，在撒馬利亞城門口，二細亞大麥要賣銀一舍客勒，一細亞細麵也要賣銀一舍客勒。」</span>
<span className="v" id="v19" data-v="19" data-xref="列王紀下 7:2"> 那軍長對神人說：「即便耶和華使天開了窗戶，也不能有這事。」神人說：「你必親眼看見，卻不得吃。」</span>
<span className="v" id="v20" data-v="20" data-xref="耶利米書 17:5–6; 歷代志下 20:20; 約伯記 20:23"> 這話果然應驗在他身上；因為眾人在城門口將他踐踏，他就死了。</span>
</div>

## 猶大王約阿施

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歷代志上 3:11; 列王紀下 11:21; 列王紀下 11:1–4"> 耶戶第七年，約阿施登基，在耶路撒冷作王四十年。他母親名叫西比亞，是別是巴人。</span>
<span className="v" id="v2" data-v="2" data-xref="歷代志下 24:17–22; 歷代志下 26:4; 歷代志下 25:2"> 約阿施在祭司耶何耶大教訓他的時候，就行耶和華眼中看為正的事；</span>
<span className="v" id="v3" data-v="3" data-xref="列王紀下 14:4; 列王紀上 22:43; 列王紀上 15:14"> 只是邱壇還沒有廢去，百姓仍在那裏獻祭燒香。</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀下 22:4; 出埃及記 35:5; 歷代志上 29:3–9"> 約阿施對眾祭司說：「凡奉到耶和華殿分別為聖之物所值通用的銀子，或各人當納的身價，或樂意奉到耶和華殿的銀子，</span>
<span className="v" id="v5" data-v="5" data-xref="以賽亞書 58:12; 列王紀上 11:27; 列王紀下 22:5–6"> 你們當從所認識的人收了來，修理殿的一切破壞之處。」</span>
<span className="v" id="v6" data-v="6" data-xref="歷代志下 29:34; 彼得前書 5:2; 以賽亞書 56:10–12"> 無奈到了約阿施王二十三年，祭司仍未修理殿的破壞之處。</span>
<span className="v" id="v7" data-v="7" data-xref="歷代志下 24:16; 歷代志下 24:5–14; 列王紀下 11:4"> 所以約阿施王召了大祭司耶何耶大和眾祭司來，對他們說：「你們怎麼不修理殿的破壞之處呢？從今以後，你們不要從所認識的人再收銀子，要將所收的交出來，修理殿的破壞之處。」</span>
<span className="v" id="v8" data-v="8"> 眾祭司答應不再收百姓的銀子，也不修理殿的破壞之處。</span>
<span className="v" id="v9" data-v="9" data-xref="馬可福音 12:41; 詩篇 84:10; 耶利米書 35:4"> 祭司耶何耶大取了一個櫃子，在櫃蓋上鑽了一個窟窿，放於壇旁，在進耶和華殿的右邊；守門的祭司將奉到耶和華殿的一切銀子投在櫃裏。</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳記下 8:17; 列王紀下 22:12; 列王紀下 19:2"> 他們見櫃裏的銀子多了，便叫王的書記和大祭司上來，將耶和華殿裏的銀子數算包起來。</span>
<span className="v" id="v11" data-v="11" data-xref="列王紀下 22:5–6; 歷代志下 24:11–12; 歷代志下 34:9–11"> 把所平的銀子交給督工的，就是耶和華殿裏辦事的人；他們把銀子轉交修理耶和華殿的木匠和工人，</span>
<span className="v" id="v12" data-v="12" data-xref="列王紀下 22:5–6; 列王紀上 5:17–18; 以斯拉記 3:7"> 並瓦匠、石匠，又買木料和鑿成的石頭，修理耶和華殿的破壞之處，以及修理殿的各樣使用。</span>
<span className="v" id="v13" data-v="13" data-xref="歷代志下 24:14; 列王紀上 7:48–50; 以斯拉記 1:9–11"> 但那奉到耶和華殿的銀子，沒有用以做耶和華殿裏的銀杯、蠟剪、碗、號，和別樣的金銀器皿，</span>
<span className="v" id="v14" data-v="14"> 乃將那銀子交給督工的人修理耶和華的殿；</span>
<span className="v" id="v15" data-v="15" data-xref="列王紀下 22:7; 約翰三書 1:5; 哥林多前書 4:2–3"> 且將銀子交給辦事的人轉交做工的人，不與他們算賬，因為他們辦事誠實。</span>
<span className="v" id="v16" data-v="16" data-xref="利未記 7:7; 利未記 5:15–18; 利未記 4:24"> 惟有贖愆祭、贖罪祭的銀子沒有奉到耶和華的殿，都歸祭司。</span>
<span className="v" id="v17" data-v="17" data-xref="歷代志下 24:23–24; 路加福音 9:53; 耶利米書 42:15"> 那時，亞蘭王哈薛上來攻打迦特，攻取了，就定意上來攻打耶路撒冷。</span>
<span className="v" id="v18" data-v="18" data-xref="列王紀上 15:18; 列王紀下 18:15–16; 列王紀下 12:4"> 猶大王約阿施將他列祖猶大王約沙法、約蘭、亞哈謝所分別為聖的物和自己所分別為聖的物，並耶和華殿與王宮府庫裏所有的金子都送給亞蘭王哈薛；哈薛就不上耶路撒冷來了。</span>
<span className="v" id="v19" data-v="19" data-xref="列王紀上 14:29; 列王紀上 14:19; 列王紀上 11:41"> 約阿施其餘的事，凡他所行的都寫在猶大列王記上。</span>
<span className="v" id="v20" data-v="20" data-xref="歷代志下 24:24–27; 列王紀下 14:5; 撒母耳記下 5:9"> 約阿施的臣僕起來背叛，在下悉拉的米羅宮那裏將他殺了。</span>
<span className="v" id="v21" data-v="21" data-xref="列王紀下 14:1; 歷代志下 24:26–27"> 殺他的那臣僕就是示米押的兒子約撒甲和朔默的兒子約薩拔。眾人將他葬在大衛城他列祖的墳地裏。他兒子亞瑪謝接續他作王。</span>

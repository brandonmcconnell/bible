## 耶戶被膏立為以色列王

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳記上 10:1; 列王紀下 4:29; 列王紀上 1:39"> 先知以利沙叫了一個先知門徒來，吩咐他說：「你束上腰，手拿這瓶膏油往基列的拉末去。</span>
<span className="v" id="v2" data-v="2" data-xref="列王紀下 9:5; 列王紀上 19:16–17; 列王紀下 9:11"> 到了那裏，要尋找寧示的孫子、約沙法的兒子耶戶，使他從同僚中起來，帶他進嚴密的屋子，</span>
<span className="v" id="v3" data-v="3" data-xref="列王紀上 19:16; 出埃及記 29:7; 撒母耳記上 16:2"> 將瓶裏的膏油倒在他頭上，說：『耶和華如此說：我膏你作以色列王。』說完了，就開門逃跑，不要遲延。」</span>
<span className="v" id="v4" data-v="4"> 於是那少年先知往基列的拉末去了。</span>
<span className="v" id="v5" data-v="5" data-xref="士師記 3:19"> 到了那裏，看見眾軍長都坐着，就說：「將軍哪，我有話對你說。」耶戶說：「我們眾人裏，你要對哪一個說呢？」回答說：「將軍哪，我要對你說。」</span>
<span className="v" id="v6" data-v="6" data-xref="歷代志下 22:7; 列王紀上 19:16; 列王紀下 9:3"> 耶戶就起來，進了屋子，少年人將膏油倒在他頭上，對他說：「耶和華－以色列的上帝如此說：『我膏你作耶和華民以色列的王。</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀上 21:15; 列王紀上 18:4; 申命記 32:43"> 你要擊殺你主人亞哈的全家，我好在耶洗別身上伸我僕人眾先知和耶和華一切僕人流血的冤。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳記上 25:22; 申命記 32:36; 列王紀下 14:26"> 亞哈全家必都滅亡，凡屬亞哈的男丁，無論是困住的、自由的，我必從以色列中剪除，</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀上 15:29; 列王紀上 21:22; 列王紀上 14:10–11"> 使亞哈的家像尼八兒子耶羅波安的家，又像亞希雅兒子巴沙的家。</span>
<span className="v" id="v10" data-v="10" data-xref="列王紀上 21:23; 列王紀下 9:35–36; 列王紀下 9:3"> 耶洗別必在耶斯列田裏被狗所吃，無人葬埋。』」說完了，少年人就開門逃跑了。</span>
<span className="v" id="v11" data-v="11" data-xref="耶利米書 29:26; 使徒行傳 26:24; 何西阿書 9:7"> 耶戶出來，回到他主人的臣僕那裏，有一人問他說：「平安嗎？這狂妄的人來見你有甚麼事呢？」回答說：「你們認得那人，也知道他說甚麼。」</span>
<span className="v" id="v12" data-v="12"> 他們說：「這是假話，你據實地告訴我們。」回答說：「他如此如此對我說。他說：『耶和華如此說：我膏你作以色列王。』」</span>
<span className="v" id="v13" data-v="13" data-xref="馬可福音 11:7–8; 列王紀上 1:39; 列王紀上 1:34"> 他們就急忙各將自己的衣服鋪在上層臺階，使耶戶坐在其上；他們吹角，說：「耶戶作王了！」</span>
</div>
</div>

## 以色列王約蘭被殺

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="列王紀下 8:28; 列王紀上 22:3; 列王紀上 16:16"> 這樣，寧示的孫子、約沙法的兒子耶戶背叛約蘭。先是約蘭和以色列眾人因為亞蘭王哈薛的緣故，把守基列的拉末；</span>
<span className="v" id="v15" data-v="15" data-xref="列王紀下 8:29; 撒母耳記上 27:9–11; 歷代志下 22:6"> 但約蘭王回到耶斯列，醫治與亞蘭王哈薛打仗所受的傷。耶戶說：「若合你們的意思，就不容人逃出城往耶斯列報信去。」</span>
<span className="v" id="v16" data-v="16" data-xref="歷代志下 22:6–7; 列王紀下 8:28–29"> 於是耶戶坐車往耶斯列去，因為約蘭病臥在那裏。猶大王亞哈謝已經下去看望他。</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳記上 16:4; 以西結書 33:2–9; 列王紀下 7:14"> 有一個守望的人站在耶斯列的樓上，看見耶戶帶着一群人來，就說：「我看見一群人。」約蘭說：「打發一個騎馬的去迎接他們，問說：平安不平安？」</span>
<span className="v" id="v18" data-v="18" data-xref="列王紀下 9:19; 列王紀下 9:22; 耶利米書 16:5"> 騎馬的就去迎接耶戶，說：「王問說，平安不平安？」耶戶說：「平安不平安與你何干？你轉在我後頭吧！」守望的人又說：「使者到了他們那裏，卻不回來。」</span>
<span className="v" id="v19" data-v="19"> 王又打發一個騎馬的去。這人到了他們那裏，說：「王問說，平安不平安？」耶戶說：「平安不平安與你何干？你轉在我後頭吧！」</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳記下 18:27; 列王紀上 19:17; 傳道書 9:10"> 守望的人又說：「他到了他們那裏，也不回來；車趕得甚猛，像寧示的孫子耶戶的趕法。」</span>
<span className="v" id="v21" data-v="21" data-xref="列王紀上 21:1–7; 歷代志下 22:7; 彌迦書 1:13"> 約蘭吩咐說：「套車！」人就給他套車。以色列王約蘭和猶大王亞哈謝各坐自己的車出去迎接耶戶，在耶斯列人拿伯的田那裏遇見他。</span>
<span className="v" id="v22" data-v="22" data-xref="歷代志下 21:13; 那鴻書 3:4; 列王紀上 16:30–33"> 約蘭見耶戶就說：「耶戶啊，平安嗎？」耶戶說：「你母親耶洗別的淫行邪術這樣多，焉能平安呢？」</span>
<span className="v" id="v23" data-v="23" data-xref="列王紀下 11:14; 歷代志下 23:13"> 約蘭就轉車逃跑，對亞哈謝說：「亞哈謝啊，反了！」</span>
<span className="v" id="v24" data-v="24" data-xref="列王紀上 22:34; 箴言 21:30; 帖撒羅尼迦前書 5:3"> 耶戶開滿了弓，射中約蘭的脊背，箭從心窩穿出，約蘭就仆倒在車上。</span>
<span className="v" id="v25" data-v="25" data-xref="列王紀上 21:19; 列王紀上 21:24–29; 以賽亞書 13:1"> 耶戶對他的軍長畢甲說：「你把他拋在耶斯列人拿伯的田間。你當追想，你我一同坐車跟隨他父亞哈的時候，耶和華對亞哈所說的預言，</span>
<span className="v" id="v26" data-v="26" data-xref="列王紀上 21:19; 申命記 5:9; 歷代志下 25:4"> 說：『我昨日看見拿伯的血和他眾子的血，我必在這塊田上報應你。』這是耶和華說的，現在你要照着耶和華的話，把他拋在這田間。」</span>
</div>
</div>

## 猶大王亞哈謝被殺

<div className="bt">
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="士師記 1:27; 約書亞記 17:11; 列王紀下 8:29"> 猶大王亞哈謝見這光景，就從園亭之路逃跑。耶戶追趕他，說：「把這人也殺在車上。」到了靠近以伯蓮的姑珥坡上擊傷了他。他逃到米吉多，就死在那裏。</span>
<span className="v" id="v28" data-v="28" data-xref="歷代志下 35:24; 列王紀下 23:30; 列王紀下 12:21"> 他的臣僕用車將他的屍首送到耶路撒冷，葬在大衛城他自己的墳墓裏，與他列祖同葬。</span>
<span className="v" id="v29" data-v="29" data-xref="歷代志下 21:18–19; 歷代志下 22:1–2; 列王紀下 8:24–25"> 亞哈謝登基作猶大王的時候，是在亞哈的兒子約蘭第十一年。</span>
</div>
</div>

## 耶洗別王后被殺

<div className="bt">
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="耶利米書 4:30; 以西結書 23:40; 以西結書 24:17"> 耶戶到了耶斯列；耶洗別聽見就擦粉、梳頭，從窗戶裏往外觀看。</span>
<span className="v" id="v31" data-v="31" data-xref="列王紀上 16:9–20"> 耶戶進門的時候，耶洗別說：「殺主人的心利啊，平安嗎？」</span>
<span className="v" id="v32" data-v="32" data-xref="以斯帖記 2:15; 出埃及記 32:26; 歷代志下 11:12"> 耶戶抬頭向窗戶觀看，說：「誰順從我？」有兩三個太監從窗戶往外看他。</span>
<span className="v" id="v33" data-v="33" data-xref="彌迦書 7:10; 耶利米哀歌 1:15; 以賽亞書 25:10"> 耶戶說：「把她扔下來！」他們就把她扔下來。她的血濺在牆上和馬上；於是把她踐踏了。</span>
<span className="v" id="v34" data-v="34" data-xref="列王紀上 16:31; 列王紀上 21:25; 以賽亞書 65:15"> 耶戶進去，吃了喝了，吩咐說：「你們把這被咒詛的婦人葬埋了，因為她是王的女兒。」</span>
<span className="v" id="v35" data-v="35" data-xref="使徒行傳 12:23; 以賽亞書 14:18–20; 約伯記 31:3"> 他們就去葬埋她，只尋得她的頭骨和腳，並手掌。</span>
<span className="v" id="v36" data-v="36" data-xref="列王紀上 21:23; 利未記 8:36; 列王紀下 14:25"> 他們回去告訴耶戶，耶戶說：「這正應驗耶和華藉他僕人提斯比人以利亞所說的話，說：『在耶斯列田間，狗必吃耶洗別的肉；</span>
<span className="v" id="v37" data-v="37" data-xref="耶利米書 8:2; 詩篇 83:10; 耶利米書 16:4"> 耶洗別的屍首必在耶斯列田間如同糞土，甚至人不能說這是耶洗別。』」</span>

## 希西家病重康復

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以賽亞書 38:1–22; 歷代志下 32:24–26; 腓立比書 2:27"> 那時，希西家病得要死。亞摩斯的兒子先知以賽亞去見他，對他說：「耶和華如此說：『你當留遺命與你的家，因為你必死，不能活了。』」</span>
<span className="v" id="v2" data-v="2" data-xref="詩篇 50:15; 馬太福音 6:6; 以賽亞書 38:2–3"> 希西家就轉臉朝牆，禱告耶和華說：</span>
<span className="v" id="v3" data-v="3" data-xref="尼希米記 13:14; 尼希米記 13:22; 尼希米記 5:19"> 「耶和華啊，求你記念我在你面前怎樣存完全的心，按誠實行事，又做你眼中所看為善的。」希西家就痛哭了。</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀下 22:14; 列王紀上 7:8"> 以賽亞出來，還沒有到中院<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="院：或譯城">a</a></sup>，耶和華的話就臨到他，說：</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 66:19–20; 以賽亞書 38:5; 撒母耳記上 9:16"> 「你回去告訴我民的君希西家說：耶和華－你祖大衛的上帝如此說：『我聽見了你的禱告，看見了你的眼淚，我必醫治你；到第三日，你必上到耶和華的殿。</span>
<span className="v" id="v6" data-v="6" data-xref="列王紀下 19:34; 使徒行傳 27:24; 以賽亞書 10:24"> 我必加增你十五年的壽數，並且我要救你和這城脫離亞述王的手。我為自己和我僕人大衛的緣故，必保護這城。』」</span>
<span className="v" id="v7" data-v="7" data-xref="以賽亞書 38:21; 列王紀下 2:20–22; 列王紀下 4:41"> 以賽亞說：「當取一塊無花果餅來。」人就取了來，貼在瘡上，王便痊癒了。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="士師記 6:17; 以賽亞書 7:11; 列王紀下 19:29"> 希西家問以賽亞說：「耶和華必醫治我，到第三日，我能上耶和華的殿，有甚麼兆頭呢？」</span>
<span className="v" id="v9" data-v="9" data-xref="以賽亞書 38:7–8; 馬可福音 8:11–12; 馬太福音 16:1–4"> 以賽亞說：「耶和華必成就他所說的。這是他給你的兆頭：你要日影向前進十度呢？是要往後退十度呢？」</span>
<span className="v" id="v10" data-v="10" data-xref="列王紀下 3:18; 列王紀下 2:10; 約翰福音 14:12"> 希西家回答說：「日影向前進十度容易，我要日影往後退十度。」</span>
<span className="v" id="v11" data-v="11" data-xref="以賽亞書 38:8; 約書亞記 10:12–14; 歷代志下 32:24"> 先知以賽亞求告耶和華，耶和華就使亞哈斯的日晷向前進的日影，往後退了十度。</span>
</div>
</div>

## 從巴比倫來的使者

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="以賽亞書 39:1–8; 歷代志下 32:31; 以賽亞書 13:1"> 那時，巴比倫王巴拉但的兒子米羅達‧巴拉但聽見希西家病而痊癒，就送書信和禮物給他。</span>
<span className="v" id="v13" data-v="13" data-xref="以賽亞書 39:2; 歷代志下 32:25–27; 列王紀上 10:15"> 希西家聽從使者的話，就把他寶庫的金子、銀子、香料、貴重的膏油，和他武庫的一切軍器，並他所有的財寶，都給他們看。他家中和他全國之內，希西家沒有一樣不給他們看的。</span>
<span className="v" id="v14" data-v="14" data-xref="以賽亞書 13:5; 撒母耳記下 12:7–15; 列王紀下 5:25–26"> 於是先知以賽亞來見希西家王，問他說：「這些人說甚麼？他們從哪裏來見你？」希西家說：「他們從遠方的巴比倫來。」</span>
<span className="v" id="v15" data-v="15" data-xref="約伯記 31:33; 約書亞記 7:19; 列王紀下 20:13"> 以賽亞說：「他們在你家裏看見了甚麼？」希西家說：「凡我家中所有的，他們都看見了；我財寶中沒有一樣不給他們看的。」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="列王紀上 22:19; 列王紀下 7:1; 以賽亞書 1:10"> 以賽亞對希西家說：「你要聽耶和華的話，</span>
<span className="v" id="v17" data-v="17" data-xref="列王紀下 24:13; 歷代志下 36:10; 耶利米書 52:17–19"> 日子必到，凡你家裏所有的，並你列祖積蓄到如今的，都要被擄到巴比倫去，不留下一樣。這是耶和華說的。</span>
<span className="v" id="v18" data-v="18" data-xref="歷代志下 33:11; 列王紀下 24:12; 但以理書 1:3"> 並且從你本身所生的眾子，其中必有被擄去在巴比倫王宮裏當太監的。」</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳記上 3:18; 撒迦利亞書 8:19; 路加福音 2:10"> 希西家對以賽亞說：「你所說耶和華的話甚好！若在我的年日中有太平和穩固的景況，豈不是好嗎？」</span>
</div>
</div>

## 希西家逝世

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="尼希米記 3:16; 歷代志下 32:32; 歷代志下 32:4"> 希西家其餘的事和他的勇力，他怎樣挖池、挖溝、引水入城，都寫在猶大列王記上。</span>
<span className="v" id="v21" data-v="21" data-xref="歷代志下 32:33; 列王紀上 14:31; 歷代志下 26:23"> 希西家與他列祖同睡。他兒子瑪拿西接續他作王。</span>
</div>
</div>

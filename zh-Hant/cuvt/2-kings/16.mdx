## 猶大王亞哈斯

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以賽亞書 1:1; 以賽亞書 7:1; 列王紀下 15:38"> 利瑪利的兒子比加十七年，猶大王約坦的兒子亞哈斯登基。</span>
<span className="v" id="v2" data-v="2" data-xref="歷代志下 28:1–4; 列王紀下 15:34; 列王紀上 11:4–8"> 他登基的時候年二十歲，在耶路撒冷作王十六年；不像他祖大衛行耶和華－他上帝眼中看為正的事，</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 12:31; 利未記 18:21; 列王紀下 21:2"> 卻效法以色列諸王所行的，又照着耶和華從以色列人面前趕出的外邦人所行可憎的事，使他的兒子經火，</span>
<span className="v" id="v4" data-v="4" data-xref="申命記 12:2; 列王紀上 14:23; 耶利米書 17:2"> 並在邱壇上、山岡上、各青翠樹下獻祭燒香。</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀下 15:37; 以賽亞書 9:6–7; 以賽亞書 8:9–10"> 亞蘭王利汛和以色列王利瑪利的兒子比加上來攻打耶路撒冷，圍困亞哈斯，卻不能勝他。</span>
<span className="v" id="v6" data-v="6" data-xref="列王紀下 14:22; 申命記 2:8; 列王紀上 9:26"> 當時亞蘭王利汛收回以拉他歸與亞蘭，將猶大人從以拉他趕出去。亞蘭人<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有譯以東人的">a</a></sup>就來到以拉他，住在那裏，直到今日。</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀下 15:29; 耶利米哀歌 4:17; 何西阿書 14:3"> 亞哈斯差遣使者去見亞述王提革拉‧毗列色，說：「我是你的僕人、你的兒子。現在亞蘭王和以色列王攻擊我，求你來救我脫離他們的手。」</span>
<span className="v" id="v8" data-v="8" data-xref="列王紀下 12:17–18; 歷代志下 28:20–21; 歷代志下 16:2"> 亞哈斯將耶和華殿裏和王宮府庫裏所有的金銀都送給亞述王為禮物。</span>
<span className="v" id="v9" data-v="9" data-xref="阿摩司書 9:7; 以賽亞書 22:6; 阿摩司書 1:3–5"> 亞述王應允了他，就上去攻打大馬士革，將城攻取，殺了利汛，把居民擄到吉珥。</span>
<span className="v" id="v10" data-v="10" data-xref="羅馬書 12:2; 以西結書 23:16–17; 以賽亞書 8:2"> 亞哈斯王上大馬士革去迎接亞述王提革拉‧毗列色，在大馬士革看見一座壇，就照壇的規模樣式作法畫了圖樣，送到祭司烏利亞那裏。</span>
<span className="v" id="v11" data-v="11" data-xref="何西阿書 4:6; 歷代志下 26:17–18; 何西阿書 5:11"> 祭司烏利亞照着亞哈斯王從大馬士革送來的圖樣，在亞哈斯王沒有從大馬士革回來之先，建築一座壇。</span>
<span className="v" id="v12" data-v="12" data-xref="歷代志下 26:16–19; 歷代志下 28:25; 列王紀上 13:1"> 王從大馬士革回來看見壇，就近前來，在壇上獻祭；</span>
<span className="v" id="v13" data-v="13" data-xref="利未記 1:1–3"> 燒燔祭、素祭、澆奠祭，將平安祭牲的血灑在壇上，</span>
<span className="v" id="v14" data-v="14" data-xref="歷代志下 4:1; 出埃及記 40:6; 出埃及記 40:29"> 又將耶和華面前的銅壇從耶和華殿和新壇的中間搬到新壇的北邊。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及記 29:39–41; 列王紀上 8:64; 歷代志下 29:21–24"> 亞哈斯王吩咐祭司烏利亞說：「早晨的燔祭、晚上的素祭，王的燔祭、素祭，國內眾民的燔祭、素祭、奠祭都要燒在大壇上。燔祭牲和平安祭牲的血也要灑在這壇上，只是銅壇我要用以求問耶和華。」</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行傳 4:19; 使徒行傳 5:29; 猶大書 1:11"> 祭司烏利亞就照着亞哈斯王所吩咐的行了。</span>
<span className="v" id="v17" data-v="17" data-xref="歷代志下 4:14–15; 耶利米書 52:20; 歷代志下 28:24"> 亞哈斯王打掉盆座四面鑲着的心子，把盆從座上挪下來，又將銅海從馱海的銅牛上搬下來，放在鋪石地；</span>
<span className="v" id="v18" data-v="18" data-xref="列王紀下 11:5; 列王紀上 10:5; 以西結書 46:2"> 又因亞述王的緣故，將耶和華殿為安息日所蓋的廊子和王從外入殿的廊子挪移，圍繞耶和華的殿。</span>
<span className="v" id="v19" data-v="19" data-xref="列王紀下 15:36; 歷代志下 28:26; 列王紀下 20:20–21"> 亞哈斯其餘所行的事都寫在猶大列王記上。</span>
<span className="v" id="v20" data-v="20" data-xref="馬太福音 1:9; 以賽亞書 1:1; 歷代志上 3:13"> 亞哈斯與他列祖同睡，葬在大衛城他列祖的墳地裏。他兒子希西家接續他作王。</span>

<span className="v" id="v1" data-v="1" data-xref="但以理書 1:1; 耶利米書 25:1; 耶利米書 25:9"> 約雅敬年間，巴比倫王尼布甲尼撒上到 猶大；約雅敬服事他三年，然後背叛他。</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米書 35:11; 列王紀下 23:27; 列王紀下 21:12–14"> 耶和華使迦勒底軍、亞蘭軍、摩押軍，和亞捫人的軍來攻擊約雅敬，毀滅猶大，正如耶和華藉他僕人眾先知所說的。</span>
<span className="v" id="v3" data-v="3" data-xref="列王紀下 18:25; 列王紀下 21:2–11; 列王紀下 23:26–27"> 這禍臨到猶大人，誠然是耶和華所命的，要將他們從自己面前趕出，是因瑪拿西所犯的一切罪；</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀下 21:16; 詩篇 106:38; 民數記 35:33"> 又因他流無辜人的血，充滿了耶路撒冷；耶和華決不肯赦免。</span>
<span className="v" id="v5" data-v="5" data-xref="歷代志下 36:8; 耶利米書 26:1–24; 耶利米書 22:13–17"> 約雅敬其餘的事，凡他所行的都寫在猶大列王記上。</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米書 22:18–19; 歷代志下 36:6; 耶利米書 36:30"> 約雅敬與他列祖同睡。他兒子約雅斤接續他作王。</span>
<span className="v" id="v7" data-v="7" data-xref="耶利米書 37:5–7; 耶利米書 46:2; 創世記 15:18"> 埃及王不再從他國中出來；因為巴比倫王將埃及王所管之地，從埃及小河直到幼發拉底河都奪去了。</span>

## 猶大王約雅斤

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="歷代志下 36:9; 歷代志上 3:16; 耶利米書 37:1"> 約雅斤登基的時候年十八歲，在耶路撒冷作王三個月。他母親名叫尼護施她，是耶路撒冷人以利拿單的女兒。</span>
<span className="v" id="v9" data-v="9"> 約雅斤行耶和華眼中看為惡的事，效法他父親一切所行的。</span>
<span className="v" id="v10" data-v="10" data-xref="列王紀下 25:2; 但以理書 1:1–2"> 那時，巴比倫王尼布甲尼撒的軍兵上到耶路撒冷，圍困城。</span>
<span className="v" id="v11" data-v="11"> 當他軍兵圍困城的時候，巴比倫王尼布甲尼撒就親自來了。</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米書 24:1; 耶利米書 52:28; 列王紀下 25:27"> 猶大王約雅斤和他母親、臣僕、首領、太監一同出城，投降巴比倫王；巴比倫王便拿住他。那時是巴比倫王第八年。</span>
<span className="v" id="v13" data-v="13" data-xref="以賽亞書 39:6; 列王紀下 20:17; 耶利米書 20:5"> 巴比倫王將耶和華殿和王宮裏的寶物都拿去了，將以色列王所羅門所造耶和華殿裏的金器都毀壞了，正如耶和華所說的；</span>
<span className="v" id="v14" data-v="14" data-xref="耶利米書 52:28; 列王紀下 25:12; 列王紀下 24:16"> 又將耶路撒冷的眾民和眾首領，並所有大能的勇士，共一萬人，連一切木匠、鐵匠都擄了去；除了國中極貧窮的人以外，沒有剩下的；</span>
<span className="v" id="v15" data-v="15" data-xref="歷代志下 36:10; 耶利米書 22:24–28; 以斯帖記 2:6"> 並將約雅斤和王母、后妃、太監，與國中的大官，都從耶路撒冷擄到巴比倫去了；</span>
<span className="v" id="v16" data-v="16" data-xref="耶利米書 52:28; 列王紀下 24:14; 耶利米書 29:2"> 又將一切勇士七千人和木匠、鐵匠一千人，都是能上陣的勇士，全擄到巴比倫去了。</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米書 37:1; 歷代志下 36:4; 列王紀下 23:34"> 巴比倫王立約雅斤的叔叔瑪探雅代替他作王，給瑪探雅改名叫西底家。</span>
</div>
</div>

## 猶大王西底家

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="列王紀下 23:31; 耶利米書 52:1–11; 耶利米書 37:1"> 西底家登基的時候年二十一歲，在耶路撒冷作王十一年。他母親名叫哈慕她，是立拿人耶利米的女兒。</span>
<span className="v" id="v19" data-v="19" data-xref="列王紀下 23:37; 耶利米書 24:8; 以西結書 21:25"> 西底家行耶和華眼中看為惡的事，是照約雅敬一切所行的。</span>
<span className="v" id="v20" data-v="20" data-xref="歷代志下 36:13; 帖撒羅尼迦後書 2:9–11; 耶利米書 38:17–21"> 因此耶和華的怒氣在耶路撒冷和猶大發作，以致將人民從自己面前趕出。</span>
</div>
</div>

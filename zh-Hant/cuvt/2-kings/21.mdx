## 猶大王瑪拿西

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以賽亞書 62:4; 歷代志下 32:33–9; 馬太福音 1:10"> 瑪拿西登基的時候年十二歲，在耶路撒冷作王五十五年。他母親名叫協西巴。</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 12:31; 歷代志下 36:14; 歷代志下 33:2–4"> 瑪拿西行耶和華眼中看為惡的事，效法耶和華在以色列人面前趕出的外邦人所行可憎的事。</span>
<span className="v" id="v3" data-v="3" data-xref="列王紀下 18:4; 列王紀下 17:16; 申命記 17:3"> 重新建築他父希西家所毀壞的邱壇，又為巴力築壇，做亞舍拉像，效法以色列王亞哈所行的，且敬拜事奉天上的萬象；</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀上 8:29; 撒母耳記下 7:13; 耶利米書 32:34"> 在耶和華殿宇中築壇。耶和華曾指着這殿說：「我必立我的名在耶路撒冷。」</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀上 7:12; 列王紀下 23:4; 列王紀下 23:12"> 他在耶和華殿的兩院中為天上的萬象築壇，</span>
<span className="v" id="v6" data-v="6" data-xref="列王紀下 17:17; 利未記 19:31; 利未記 18:21"> 並使他的兒子經火，又觀兆，用法術，立交鬼的和行巫術的，多行耶和華眼中看為惡的事，惹動他的怒氣；</span>
<span className="v" id="v7" data-v="7" data-xref="歷代志下 7:16; 列王紀上 9:3; 撒母耳記下 7:13"> 又在殿內立雕刻的亞舍拉像。耶和華曾對大衛和他兒子所羅門說：「我在以色列眾支派中所選擇的耶路撒冷和這殿，必立我的名，直到永遠。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳記下 7:10; 申命記 5:28–29; 詩篇 81:11–16"> 以色列人若謹守遵行我一切所吩咐他們的和我僕人摩西所吩咐他們的一切律法，我就不再使他們挪移離開我所賜給他們列祖之地。」</span>
<span className="v" id="v9" data-v="9" data-xref="箴言 29:12; 尼希米記 9:26; 列王紀上 14:16"> 他們卻不聽從。瑪拿西引誘他們行惡，比耶和華在以色列人面前所滅的列國更甚。</span>
<span className="v" id="v10" data-v="10" data-xref="馬太福音 23:34–37; 歷代志下 33:10; 歷代志下 36:15"> 耶和華藉他僕人眾先知說：</span>
<span className="v" id="v11" data-v="11" data-xref="列王紀下 24:3–4; 列王紀上 21:26; 列王紀下 21:9"> 「因猶大王瑪拿西行這些可憎的惡事比先前亞摩利人所行的更甚，使猶大人拜他的偶像，陷在罪裏；</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米書 19:3; 撒母耳記上 3:11; 但以理書 9:12"> 所以耶和華－以色列的上帝如此說：我必降禍與耶路撒冷和猶大，叫一切聽見的人無不耳鳴。</span>
<span className="v" id="v13" data-v="13" data-xref="阿摩司書 7:7–8; 耶利米哀歌 2:8; 以賽亞書 34:11"> 我必用量撒馬利亞的準繩和亞哈家的線鉈拉在耶路撒冷上，必擦淨耶路撒冷，如人擦盤，將盤倒扣。</span>
<span className="v" id="v14" data-v="14" data-xref="耶利米書 23:33; 列王紀下 19:4; 詩篇 89:38–45"> 我必棄掉所餘剩的子民<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是產業">a</a></sup>，把他們交在仇敵手中，使他們成為一切仇敵擄掠之物；</span>
<span className="v" id="v15" data-v="15" data-xref="以西結書 20:30; 申命記 31:27; 以西結書 20:21"> 是因他們自從列祖出埃及直到如今，常行我眼中看為惡的事，惹動我的怒氣。」</span>
<span className="v" id="v16" data-v="16" data-xref="民數記 35:33; 歷代志下 33:9; 列王紀下 21:11"> 瑪拿西行耶和華眼中看為惡的事，使猶大人陷在罪裏，又流許多無辜人的血，充滿了耶路撒冷，從這邊直到那邊。</span>
<span className="v" id="v17" data-v="17" data-xref="列王紀下 20:20–21; 歷代志下 33:1–20"> 瑪拿西其餘的事，凡他所行的和他所犯的罪都寫在猶大列王記上。</span>
<span className="v" id="v18" data-v="18" data-xref="歷代志下 33:20; 列王紀下 21:26; 歷代志下 32:33"> 瑪拿西與他列祖同睡，葬在自己宮院烏撒的園內；他兒子亞們接續他作王。</span>
</div>
</div>

## 猶大王亞們

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="歷代志下 33:21–23; 列王紀上 22:51; 歷代志上 3:14"> 亞們登基的時候年二十二歲，在耶路撒冷作王二年。他母親名叫米舒利密，是約提巴人哈魯斯的女兒。</span>
<span className="v" id="v20" data-v="20" data-xref="馬太福音 23:32; 列王紀下 21:11; 使徒行傳 7:51"> 亞們行耶和華眼中看為惡的事，與他父親瑪拿西所行的一樣；</span>
<span className="v" id="v21" data-v="21"> 行他父親一切所行的，敬奉他父親所敬奉的偶像，</span>
<span className="v" id="v22" data-v="22" data-xref="列王紀下 22:17; 列王紀上 11:33; 歷代志上 28:9"> 離棄耶和華－他列祖的上帝，不遵行耶和華的道。</span>
<span className="v" id="v23" data-v="23" data-xref="列王紀下 12:20; 列王紀下 14:19; 歷代志下 33:24–25"> 亞們王的臣僕背叛他，在宮裏殺了他。</span>
<span className="v" id="v24" data-v="24" data-xref="列王紀下 14:5; 列王紀下 11:17; 列王紀下 14:21"> 但國民殺了那些背叛亞們王的人，立他兒子約西亞接續他作王。</span>
<span className="v" id="v25" data-v="25" data-xref="列王紀下 20:20; 列王紀下 21:17"> 亞們其餘所行的事都寫在猶大列王記上。</span>
<span className="v" id="v26" data-v="26" data-xref="列王紀下 21:18; 馬太福音 1:10; 列王紀上 13:5"> 亞們葬在烏撒的園內自己的墳墓裏。他兒子約西亞接續他作王。</span>
</div>

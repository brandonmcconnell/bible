## 猶大王亞瑪謝

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀下 13:10; 歷代志下 25:1–4; 列王紀下 14:15"> 以色列王約哈斯的兒子約阿施第二年，猶大王約阿施的兒子亞瑪謝登基。</span>
<span className="v" id="v2" data-v="2"> 他登基的時候年二十五歲，在耶路撒冷作王二十九年。他母親名叫約耶但，是耶路撒冷人。</span>
<span className="v" id="v3" data-v="3" data-xref="歷代志下 25:2–3; 撒迦利亞書 1:4–6; 列王紀上 11:4"> 亞瑪謝行耶和華眼中看為正的事，但不如他祖大衛，乃效法他父約阿施一切所行的；</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀下 12:3; 列王紀下 16:4; 列王紀下 15:35"> 只是邱壇還沒有廢去，百姓仍在那裏獻祭燒香。</span>
<span className="v" id="v5" data-v="5" data-xref="歷代志下 25:3–4; 列王紀下 12:20–21; 民數記 35:33"> 國一堅定，就把殺他父王的臣僕殺了，</span>
<span className="v" id="v6" data-v="6" data-xref="申命記 24:16; 以西結書 18:20; 以西結書 18:4"> 卻沒有治死殺王之人的兒子，是照摩西律法書上耶和華所吩咐的說：「不可因子殺父，也不可因父殺子，各人要為本身的罪而死。」</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳記下 8:13; 歷代志上 18:12; 約書亞記 15:38"> 亞瑪謝在鹽谷殺了以東人一萬，又攻取了西拉，改名叫約帖，直到今日。</span>
<span className="v" id="v8" data-v="8" data-xref="歷代志下 25:17–24; 撒母耳記下 2:14–17; 列王紀下 14:11"> 那時，亞瑪謝差遣使者去見耶戶的孫子約哈斯的兒子以色列王約阿施，說：「你來，我們二人相見於戰場。」</span>
<span className="v" id="v9" data-v="9" data-xref="士師記 9:8–15; 列王紀上 4:33; 歷代志下 33:11"> 以色列王約阿施差遣使者去見猶大王亞瑪謝，說：「黎巴嫩的蒺藜差遣使者去見黎巴嫩的香柏樹，說：將你的女兒給我兒子為妻。後來黎巴嫩有一個野獸經過，把蒺藜踐踏了。</span>
<span className="v" id="v10" data-v="10" data-xref="歷代志下 26:16; 申命記 8:14; 歷代志下 32:25"> 你打敗了以東人就心高氣傲，你以此為榮耀，在家裏安居就罷了，為何要惹禍，使自己和猶大國一同敗亡呢？」</span>
<span className="v" id="v11" data-v="11" data-xref="約書亞記 19:38; 歷代志下 25:16; 約書亞記 15:10"> 亞瑪謝卻不肯聽這話。於是以色列王約阿施上來，在猶大的伯‧示麥與猶大王亞瑪謝相見於戰場。</span>
<span className="v" id="v12" data-v="12" data-xref="撒母耳記下 18:17; 撒母耳記上 4:10; 列王紀上 22:36"> 猶大人敗在以色列人面前，各自逃回家裏去了。</span>
<span className="v" id="v13" data-v="13" data-xref="尼希米記 8:16; 尼希米記 12:39; 撒迦利亞書 14:10"> 以色列王約阿施在伯‧示麥擒住亞哈謝的孫子、約阿施的兒子猶大王亞瑪謝，就來到耶路撒冷，拆毀耶路撒冷的城牆，從以法蓮門直到角門共四百肘，</span>
<span className="v" id="v14" data-v="14" data-xref="列王紀上 14:26; 列王紀上 7:51; 列王紀上 15:18"> 又將耶和華殿裏與王宮府庫裏所有的金銀和器皿都拿了去，並帶人去為質，就回撒馬利亞去了。</span>
<span className="v" id="v15" data-v="15" data-xref="列王紀下 13:12–13; 列王紀上 14:19–20; 列王紀下 10:34–35"> 約阿施其餘所行的事和他的勇力，並與猶大王亞瑪謝爭戰的事，都寫在以色列諸王記上。</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀下 13:9; 列王紀下 13:13; 列王紀上 1:21"> 約阿施與他列祖同睡，葬在撒馬利亞，以色列諸王的墳地裏。他兒子耶羅波安接續他作王。</span>
</div>
</div>

## 猶大王亞瑪謝去世

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="歷代志下 25:25–28; 列王紀下 13:10; 列王紀下 14:23"> 以色列王約哈斯的兒子約阿施死後，猶大王約阿施的兒子亞瑪謝又活了十五年。</span>
<span className="v" id="v18" data-v="18" data-xref="列王紀上 11:41; 列王紀上 14:29; 列王紀下 13:8"> 亞瑪謝其餘的事都寫在猶大列王記上。</span>
<span className="v" id="v19" data-v="19" data-xref="約書亞記 10:31; 列王紀下 15:25; 列王紀下 12:20–21"> 耶路撒冷有人背叛亞瑪謝，他就逃到拉吉；叛黨卻打發人到拉吉將他殺了。</span>
<span className="v" id="v20" data-v="20" data-xref="列王紀下 9:28; 列王紀下 12:21; 歷代志下 33:20"> 人就用馬將他的屍首馱到耶路撒冷，葬在大衛城他列祖的墳地裏。</span>
<span className="v" id="v21" data-v="21" data-xref="列王紀下 21:24; 馬太福音 1:8–9; 列王紀下 15:13"> 猶大眾民立亞瑪謝的兒子亞撒利雅<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="又名烏西雅">a</a></sup>接續他父作王，那時他年十六歲。</span>
<span className="v" id="v22" data-v="22" data-xref="列王紀下 16:6; 列王紀上 9:26; 申命記 2:8"> 亞瑪謝與他列祖同睡之後，亞撒利雅收回以拉他仍歸猶大，又重新修理。</span>
</div>
</div>

## 以色列王耶羅波安二世

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="何西阿書 1:1; 阿摩司書 7:9–11; 阿摩司書 1:1"> 猶大王約阿施的兒子亞瑪謝十五年，以色列王約阿施的兒子耶羅波安在撒馬利亞登基，作王四十一年。</span>
<span className="v" id="v24" data-v="24" data-xref="列王紀下 13:6; 列王紀下 13:11; 創世記 38:7"> 他行耶和華眼中看為惡的事，不離開尼八的兒子耶羅波安使以色列人陷在罪裏的一切罪。</span>
<span className="v" id="v25" data-v="25" data-xref="申命記 3:17; 馬太福音 12:39–40; 約書亞記 19:13"> 他收回以色列邊界之地，從哈馬口直到亞拉巴海，正如耶和華－以色列的上帝藉他僕人迦特希弗人亞米太的兒子先知約拿所說的。</span>
<span className="v" id="v26" data-v="26" data-xref="申命記 32:36; 出埃及記 3:7; 列王紀下 13:4"> 因為耶和華看見以色列人甚是艱苦，無論困住的、自由的都沒有了，也無人幫助以色列人。</span>
<span className="v" id="v27" data-v="27" data-xref="列王紀下 13:23; 列王紀下 13:5; 羅馬書 11:2–12"> 耶和華並沒有說要將以色列的名從天下塗抹，乃藉約阿施的兒子耶羅波安拯救他們。</span>
<span className="v" id="v28" data-v="28" data-xref="列王紀上 11:24; 歷代志上 18:5–6; 撒母耳記下 8:6"> 耶羅波安其餘的事，凡他所行的和他的勇力，他怎樣爭戰，怎樣收回大馬士革和先前屬猶大的哈馬歸以色列，都寫在以色列諸王記上。</span>
<span className="v" id="v29" data-v="29" data-xref="列王紀下 15:8"> 耶羅波安與他列祖以色列諸王同睡。他兒子撒迦利雅接續他作王。</span>
</div>

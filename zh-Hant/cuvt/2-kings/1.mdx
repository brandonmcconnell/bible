## 以利亞和亞哈謝王

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳記下 8:2; 民數記 24:7; 列王紀下 3:4–5"> 亞哈死後，摩押背叛以色列。</span>
<span className="v" id="v2" data-v="2" data-xref="列王紀下 1:16; 馬太福音 10:25; 馬可福音 3:22"> 亞哈謝在撒馬利亞，一日從樓上的欄杆裏掉下來，就病了；於是差遣使者說：「你們去問以革倫的神巴力‧西卜，我這病能好不能好。」</span>
<span className="v" id="v3" data-v="3" data-xref="列王紀上 17:1; 約拿書 2:8; 使徒行傳 12:7–11"> 但耶和華的使者對提斯比人以利亞說：「你起來，去迎着撒馬利亞王的使者，對他們說：『你們去問以革倫神巴力‧西卜，豈因以色列中沒有上帝嗎？』</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 3:4; 創世記 2:17; 以西結書 18:4"> 所以耶和華如此說：『你必不下你所上的床，必定要死！』」以利亞就去了。</span>
<span className="v" id="v5" data-v="5"> 使者回來見王，王問他們說：「你們為甚麼回來呢？」</span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 16:4; 歷代志上 10:13–14; 以賽亞書 41:22–23"> 使者回答說：「有一個人迎着我們來，對我們說：『你們回去見差你們來的王，對他說：耶和華如此說，你差人去問以革倫神巴力‧西卜，豈因以色列中沒有上帝嗎？所以你必不下所上的床，必定要死。』」</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳記上 28:14; 士師記 8:18"> 王問他們說：「迎着你們來告訴你們這話的，是怎樣的人？」</span>
<span className="v" id="v8" data-v="8" data-xref="馬太福音 3:4; 撒迦利亞書 13:4; 馬可福音 1:6"> 回答說：「他身穿毛衣，腰束皮帶。」王說：「這必是提斯比人以利亞。」</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀下 6:13–14; 路加福音 6:11–12; 希伯來書 11:36"> 於是，王差遣五十夫長，帶領五十人去見以利亞，他就上到以利亞那裏；以利亞正坐在山頂上。五十夫長對他說：「神人哪，王吩咐你下來！」</span>
<span className="v" id="v10" data-v="10" data-xref="路加福音 9:54; 但以理書 3:25; 列王紀上 18:36–38"> 以利亞回答說：「我若是神人，願火從天上降下來，燒滅你和你那五十人！」於是有火從天上降下來，燒滅五十夫長和他那五十人。</span>
<span className="v" id="v11" data-v="11" data-xref="馬太福音 2:16; 路加福音 22:63–64; 耶利米書 5:3"> 王第二次差遣一個五十夫長，帶領五十人去見以利亞。五十夫長對以利亞說：「神人哪，王吩咐你快快下來！」</span>
<span className="v" id="v12" data-v="12" data-xref="列王紀下 1:9–10"> 以利亞回答說：「我若是神人，願火從天上降下來，燒滅你和你那五十人！」於是上帝的火從天上降下來，燒滅五十夫長和他那五十人。</span>
<span className="v" id="v13" data-v="13" data-xref="以賽亞書 1:5; 撒母耳記上 26:21; 傳道書 9:3"> 王第三次差遣一個五十夫長，帶領五十人去。這五十夫長上去，雙膝跪在以利亞面前，哀求他說：「神人哪，願我的性命和你這五十個僕人的性命在你眼前看為寶貴！</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行傳 20:24; 詩篇 49:8; 箴言 6:26"> 已經有火從天上降下來，燒滅前兩次來的五十夫長和他們各自帶的五十人；現在願我的性命在你眼前看為寶貴！」</span>
<span className="v" id="v15" data-v="15" data-xref="以賽亞書 51:12; 以西結書 2:6; 耶利米書 1:17"> 耶和華的使者對以利亞說：「你同着他下去，不要怕他！」以利亞就起來，同着他下去見王，</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀下 1:2–4; 列王紀上 22:28; 出埃及記 4:22–23"> 對王說：「耶和華如此說：『你差人去問以革倫神巴力‧西卜，豈因以色列中沒有上帝可以求問嗎？所以你必不下所上的床，必定要死！』」</span>
</div>
</div>

## 亞哈謝死後約蘭繼位

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="列王紀下 3:1; 列王紀上 22:51; 列王紀下 8:16–17"> 亞哈謝果然死了，正如耶和華藉以利亞所說的話。因他沒有兒子，他兄弟約蘭接續他作王，正在猶大王約沙法的兒子約蘭第二年。</span>
<span className="v" id="v18" data-v="18" data-xref="列王紀上 22:39; 列王紀上 14:19"> 亞哈謝其餘所行的事都寫在以色列諸王記上。</span>
</div>

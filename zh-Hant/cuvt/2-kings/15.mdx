## 猶大王亞撒利雅

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歷代志下 26:3–4; 列王紀下 14:21; 歷代志下 26:1"> 以色列王耶羅波安二十七年，猶大王亞瑪謝的兒子亞撒利雅登基，</span>
<span className="v" id="v2" data-v="2" data-xref="歷代志下 26:3–4"> 他登基的時候年十六歲，在耶路撒冷作王五十二年。他母親名叫耶可利雅，是耶路撒冷人。</span>
<span className="v" id="v3" data-v="3" data-xref="列王紀下 14:3–4; 列王紀下 12:2–3; 歷代志下 26:4"> 亞撒利雅行耶和華眼中看為正的事，效法他父親亞瑪謝一切所行的；</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀下 15:35; 列王紀下 14:4; 列王紀下 12:3"> 只是邱壇還沒有廢去，百姓仍在那裏獻祭燒香。</span>
<span className="v" id="v5" data-v="5" data-xref="利未記 13:46; 民數記 12:14; 列王紀下 7:3"> 耶和華降災與王，使他長大痲瘋，直到死日，他就住在別的宮裏。他的兒子約坦管理家事，治理國民。</span>
<span className="v" id="v6" data-v="6" data-xref="歷代志下 26:5–15; 列王紀下 14:18"> 亞撒利雅其餘的事，凡他所行的都寫在猶大列王記上。</span>
<span className="v" id="v7" data-v="7" data-xref="歷代志下 26:23; 以賽亞書 6:1"> 亞撒利雅與他列祖同睡，葬在大衛城他列祖的墳地裏。他兒子約坦接續他作王。</span>
</div>
</div>

## 以色列王撒迦利雅

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="列王紀下 14:16–17; 列王紀下 14:29–1; 列王紀下 14:21"> 猶大王亞撒利雅三十八年，耶羅波安的兒子撒迦利雅在撒馬利亞作以色列王六個月。</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀下 14:24; 列王紀下 13:2; 列王紀下 13:11"> 他行耶和華眼中看為惡的事，效法他列祖所行的，不離開尼八的兒子耶羅波安使以色列人陷在罪裏的那罪。</span>
<span className="v" id="v10" data-v="10" data-xref="列王紀上 15:28; 列王紀下 15:14; 列王紀下 9:24"> 雅比的兒子沙龍背叛他，在百姓面前擊殺他，篡了他的位。</span>
<span className="v" id="v11" data-v="11" data-xref="列王紀下 14:28"> 撒迦利雅其餘的事都寫在以色列諸王記上。</span>
<span className="v" id="v12" data-v="12" data-xref="列王紀下 10:30; 馬可福音 13:31; 列王紀下 13:13"> 這是從前耶和華應許耶戶說：「你的子孫必坐以色列的國位直到四代。」這話果然應驗了。</span>
</div>
</div>

## 以色列王沙龍

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="列王紀下 15:1; 馬太福音 1:8–9; 列王紀下 15:8"> 猶大王烏西雅<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="就是亞撒利雅">a</a></sup>三十九年，雅比的兒子沙龍登基在撒馬利亞作王一個月。</span>
<span className="v" id="v14" data-v="14" data-xref="列王紀上 14:17; 列王紀上 16:17; 列王紀上 16:15"> 迦底的兒子米拿現從得撒上撒馬利亞，殺了雅比的兒子沙龍，篡了他的位。</span>
<span className="v" id="v15" data-v="15" data-xref="列王紀上 14:19; 列王紀上 14:29; 列王紀下 15:11"> 沙龍其餘的事和他背叛的情形都寫在以色列諸王記上。</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀下 8:12; 列王紀上 4:24; 何西阿書 13:16"> 那時米拿現從得撒起攻打提斐薩和其四境，擊殺城中一切的人，剖開其中所有的孕婦，都因他們沒有給他開城。</span>
</div>
</div>

## 以色列王米拿現

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17"> 猶大王亞撒利雅三十九年，迦底的兒子米拿現登基，在撒馬利亞作以色列王十年。</span>
<span className="v" id="v18" data-v="18"> 他行耶和華眼中看為惡的事，終身不離開尼八的兒子耶羅波安使以色列人陷在罪裏的那罪。</span>
<span className="v" id="v19" data-v="19" data-xref="列王紀下 14:5; 歷代志上 5:25–26; 列王紀下 18:16"> 亞述王普勒來攻擊以色列國，米拿現給他一千他連得銀子，請普勒幫助他堅定國位。</span>
<span className="v" id="v20" data-v="20" data-xref="列王紀下 18:14–17; 列王紀下 23:35; 列王紀下 17:3–4"> 米拿現向以色列一切大富戶索要銀子，使他們各出五十舍客勒，就給了亞述王。於是亞述王回去，不在國中停留。</span>
<span className="v" id="v21" data-v="21"> 米拿現其餘的事，凡他所行的都寫在以色列諸王記上。</span>
<span className="v" id="v22" data-v="22"> 米拿現與他列祖同睡。他兒子比加轄接續他作王。</span>
</div>
</div>

## 以色列王比加轄

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="列王紀上 15:25; 列王紀上 22:51; 約伯記 20:5"> 猶大王亞撒利雅五十年，米拿現的兒子比加轄在撒馬利亞登基作以色列王二年。</span>
<span className="v" id="v24" data-v="24" data-xref="列王紀下 15:9; 列王紀下 15:18"> 他行耶和華眼中看為惡的事，不離開尼八的兒子耶羅波安使以色列人陷在罪裏的那罪。</span>
<span className="v" id="v25" data-v="25" data-xref="歷代志下 28:6; 列王紀下 9:14; 列王紀上 16:9"> 比加轄的將軍、利瑪利的兒子比加背叛他，在撒馬利亞王宮裏的衛所殺了他。亞珥歌伯和亞利耶並基列的五十人幫助比加；比加擊殺他，篡了他的位。</span>
<span className="v" id="v26" data-v="26"> 比加轄其餘的事，凡他所行的都寫在以色列諸王記上。</span>
</div>
</div>

## 以色列王比加

<div className="bt">
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="以賽亞書 7:4; 以賽亞書 7:1; 列王紀下 15:23"> 猶大王亞撒利雅五十二年，利瑪利的兒子比加在撒馬利亞登基作以色列王二十年。</span>
<span className="v" id="v28" data-v="28" data-xref="列王紀下 15:18; 列王紀下 13:6; 列王紀下 15:9"> 他行耶和華眼中看為惡的事，不離開尼八的兒子耶羅波安使以色列人陷在罪裏的那罪。</span>
<span className="v" id="v29" data-v="29" data-xref="歷代志上 5:26; 列王紀下 17:6; 列王紀下 16:7"> 以色列王比加年間，亞述王提革拉‧毗列色來奪了以雲、亞伯‧伯‧瑪迦、亞挪、基低斯、夏瑣、基列、加利利，和拿弗他利全地，將這些地方的居民都擄到亞述去了。</span>
<span className="v" id="v30" data-v="30" data-xref="列王紀下 17:1; 歷代志下 28:4–6; 列王紀下 16:1"> 烏西雅的兒子約坦二十年，以拉的兒子何細亞背叛利瑪利的兒子比加，擊殺他，篡了他的位。</span>
<span className="v" id="v31" data-v="31"> 比加其餘的事，凡他所行的都寫在以色列諸王記上。</span>
</div>

## 猶大王約坦

<div className="bt">
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="歷代志上 3:12; 列王紀下 15:7; 歷代志下 27:1–9"> 以色列王利瑪利的兒子比加第二年，猶大王烏西雅的兒子約坦登基。</span>
<span className="v" id="v33" data-v="33" data-xref="歷代志下 27:1"> 他登基的時候年二十五歲，在耶路撒冷作王十六年。他母親名叫耶路沙，是撒督的女兒。</span>
<span className="v" id="v34" data-v="34" data-xref="歷代志下 26:4–5; 列王紀下 15:3–4; 歷代志下 27:2"> 約坦行耶和華眼中看為正的事，效法他父親烏西雅一切所行的；</span>
<span className="v" id="v35" data-v="35" data-xref="列王紀下 12:3; 歷代志下 23:20; 歷代志下 27:3–9"> 只是邱壇還沒有廢去，百姓仍在那裏獻祭燒香。約坦建立耶和華殿的上門。</span>
<span className="v" id="v36" data-v="36" data-xref="歷代志下 27:4–9; 列王紀下 15:6–7"> 約坦其餘的事，凡他所行的都寫在猶大列王記上。</span>
<span className="v" id="v37" data-v="37" data-xref="列王紀下 16:5; 以賽亞書 7:1; 路加福音 21:28"> 在那些日子，耶和華才使亞蘭王利汛和利瑪利的兒子比加去攻擊猶大。</span>
<span className="v" id="v38" data-v="38" data-xref="列王紀上 14:20; 列王紀上 14:31; 列王紀下 16:1"> 約坦與他列祖同睡，葬在他祖大衛城他列祖的墳地裏。他兒子亞哈斯接續他作王。</span>
</div>

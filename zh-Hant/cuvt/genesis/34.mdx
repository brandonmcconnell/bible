## 底拿受辱

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 30:21; 耶利米書 2:36; 創世記 30:13"> 利亞給雅各所生的女兒底拿出去，要見那地的女子們。</span>
<span className="v" id="v2" data-v="2" data-xref="馬太福音 5:28; 約伯記 31:1; 約伯記 31:9"> 那地的主－希未人、哈抹的兒子示劍看見她，就拉住她，與她行淫，玷辱她。</span>
<span className="v" id="v3" data-v="3" data-xref="何西阿書 2:14; 以賽亞書 40:2; 歷代志下 30:22"> 示劍的心繫戀雅各的女兒底拿，喜愛這女子，甜言蜜語地安慰她。</span>
<span className="v" id="v4" data-v="4" data-xref="士師記 14:2; 撒母耳記下 13:13; 創世記 21:21"> 示劍對他父親哈抹說：「求你為我聘這女子為妻。」</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳記下 13:22; 利未記 10:3; 撒母耳記上 10:27"> 雅各聽見示劍玷污了他的女兒底拿。那時他的兒子們正和群畜在田野，雅各就閉口不言，等他們回來。</span>
<span className="v" id="v6" data-v="6"> 示劍的父親哈抹出來見雅各，要和他商議。</span>
<span className="v" id="v7" data-v="7" data-xref="約書亞記 7:15; 士師記 20:6; 申命記 22:21"> 雅各的兒子們聽見這事，就從田野回來，人人忿恨，十分惱怒；因示劍在以色列家做了醜事，與雅各的女兒行淫，這本是不該做的事。</span>
<span className="v" id="v8" data-v="8" data-xref="列王紀上 11:2; 詩篇 119:20; 詩篇 84:2"> 哈抹和他們商議說：「我兒子示劍的心戀慕這女子，求你們將她給我的兒子為妻。</span>
<span className="v" id="v9" data-v="9" data-xref="申命記 7:3; 創世記 26:34–35; 創世記 19:14"> 你們與我們彼此結親；你們可以把女兒給我們，也可以娶我們的女兒。</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 20:15; 創世記 47:27; 創世記 42:34"> 你們與我們同住吧！這地都在你們面前，只管在此居住，做買賣，置產業。」</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 33:15; 創世記 18:3"> 示劍對女兒的父親和弟兄們說：「但願我在你們眼前蒙恩，你們向我要甚麼，我必給你們。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及記 22:16–17; 申命記 22:28–29; 撒母耳記上 18:25–27"> 任憑向我要多重的聘金和禮物，我必照你們所說的給你們；只要把女子給我為妻。」</span>
<span className="v" id="v13" data-v="13" data-xref="創世記 25:27–34; 以賽亞書 59:13; 約伯記 13:4"> 雅各的兒子們因為示劍玷污了他們的妹子底拿，就用詭詐的話回答示劍和他父親哈抹，</span>
<span className="v" id="v14" data-v="14" data-xref="馬太福音 23:1–39; 撒母耳記下 15:7; 創世記 17:11"> 對他們說：「我們不能把我們的妹子給沒有受割禮的人為妻，因為那是我們的羞辱。</span>
<span className="v" id="v15" data-v="15" data-xref="加拉太書 4:12"> 惟有一件才可以應允：若你們所有的男丁都受割禮，和我們一樣，</span>
<span className="v" id="v16" data-v="16"> 我們就把女兒給你們，也娶你們的女兒；我們便與你們同住，兩下成為一樣的人民。</span>
<span className="v" id="v17" data-v="17"> 倘若你們不聽從我們受割禮，我們就帶着妹子走了。」</span>
<span className="v" id="v18" data-v="18"> 哈抹和他的兒子示劍喜歡這話。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行傳 17:12; 使徒行傳 13:50; 撒母耳記上 22:14"> 那少年人做這事並不遲延，因為他喜愛雅各的女兒；他在他父親家中也是人最尊重的。</span>
<span className="v" id="v20" data-v="20" data-xref="路得記 4:1; 箴言 31:23; 阿摩司書 5:12"> 哈抹和他兒子示劍到本城的門口，對本城的人說：</span>
<span className="v" id="v21" data-v="21"> 「這些人與我們和睦，不如許他們在這地居住，做買賣；這地也寬闊，足可容下他們。我們可以娶他們的女兒為妻，也可以把我們的女兒嫁給他們。</span>
<span className="v" id="v22" data-v="22"> 惟有一件事我們必須做，他們才肯應允和我們同住，成為一樣的人民：就是我們中間所有的男丁都要受割禮，和他們一樣。</span>
<span className="v" id="v23" data-v="23" data-xref="箴言 1:12–13; 約翰福音 6:26–27; 約翰福音 2:16"> 他們的群畜、貨財，和一切的牲口豈不都歸我們嗎？只要依從他們，他們就與我們同住。」</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 23:10; 哥林多前書 7:19; 以賽亞書 1:10–16"> 凡從城門出入的人就都聽從哈抹和他兒子示劍的話；於是凡從城門出入的男丁都受了割禮。</span>
<span className="v" id="v25" data-v="25" data-xref="創世記 49:5–7; 創世記 29:33–34; 民數記 31:7"> 到第三天，眾人正在疼痛的時候，雅各的兩個兒子，就是底拿的哥哥西緬和利未，各拿刀劍，趁着眾人想不到的時候來到城中，把一切男丁都殺了，</span>
<span className="v" id="v26" data-v="26" data-xref="撒母耳記下 2:26; 申命記 32:42; 以賽亞書 31:8"> 又用刀殺了哈抹和他兒子示劍，把底拿從示劍家裏帶出來就走了。</span>
<span className="v" id="v27" data-v="27" data-xref="約書亞記 7:13; 約書亞記 7:21; 出埃及記 2:14"> 雅各的兒子們因為他們的妹子受了玷污，就來到被殺的人那裏，擄掠那城，</span>
<span className="v" id="v28" data-v="28" data-xref="約伯記 1:15–16; 申命記 8:17–18; 約伯記 20:5"> 奪了他們的羊群、牛群，和驢，並城裏田間所有的；</span>
<span className="v" id="v29" data-v="29"> 又把他們一切貨財、孩子、婦女，並各房中所有的，都擄掠去了。</span>
<span className="v" id="v30" data-v="30" data-xref="詩篇 105:12; 約書亞記 7:25; 出埃及記 5:21"> 雅各對西緬和利未說：「你們連累我，使我在這地的居民中，就是在迦南人和比利洗人中，有了臭名。我的人丁既然稀少，他們必聚集來擊殺我，我和全家的人都必滅絕。」</span>
<span className="v" id="v31" data-v="31" data-xref="箴言 6:34; 創世記 34:13; 創世記 49:7"> 他們說：「他豈可待我們的妹子如同妓女嗎？」</span>

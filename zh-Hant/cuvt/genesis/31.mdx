## 雅各逃離拉班

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="傳道書 4:4; 詩篇 49:16–17; 約伯記 31:31"> 雅各聽見拉班的兒子們有話說：「雅各把我們父親所有的都奪了去，並藉着我們父親的，得了這一切的榮耀<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或譯：財">a</a></sup>。」</span>
<span className="v" id="v2" data-v="2" data-xref="但以理書 3:19; 撒母耳記上 18:9–11; 創世記 4:5"> 雅各見拉班的氣色向他不如從前了。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 28:15; 創世記 32:9; 希伯來書 13:5"> 耶和華對雅各說：「你要回你祖、你父之地，到你親族那裏去，我必與你同在。」</span>
<span className="v" id="v4" data-v="4"> 雅各就打發人，叫拉結和利亞到田野羊群那裏來，</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 31:2–3; 創世記 31:53; 創世記 48:15"> 對她們說：「我看你們父親的氣色向我不如從前了；但我父親的上帝向來與我同在。</span>
<span className="v" id="v6" data-v="6" data-xref="創世記 30:29; 以弗所書 6:5–8; 提多書 2:9–10"> 你們也知道，我盡了我的力量服事你們的父親。</span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 37:28; 創世記 31:29; 民數記 14:22"> 你們的父親欺哄我，十次改了我的工價；然而上帝不容他害我。</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 30:32"> 他若說：『有點的歸你作工價』，羊群所生的都有點；他若說：『有紋的歸你作工價』，羊群所生的都有紋。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 31:1; 創世記 31:16; 箴言 13:22"> 這樣，上帝把你們父親的牲畜奪來賜給我了。</span>
<span className="v" id="v10" data-v="10" data-xref="申命記 13:1; 創世記 30:39; 創世記 20:6"> 羊配合的時候，我夢中舉目一看，見跳母羊的公羊都是有紋的、有點的、有花斑的。</span>
<span className="v" id="v11" data-v="11" data-xref="以賽亞書 58:9; 創世記 31:13; 撒母耳記上 3:6"> 上帝的使者在那夢中呼叫我說：『雅各。』我說：『我在這裏。』</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及記 3:7; 申命記 24:15; 創世記 31:42"> 他說：『你舉目觀看，跳母羊的公羊都是有紋的、有點的、有花斑的；凡拉班向你所做的，我都看見了。</span>
<span className="v" id="v13" data-v="13" data-xref="創世記 31:3; 創世記 32:9; 創世記 28:12–22"> 我是伯特利的上帝；你在那裏用油澆過柱子，向我許過願。現今你起來，離開這地，回你本地去吧！』」</span>
<span className="v" id="v14" data-v="14" data-xref="路得記 4:11; 創世記 2:24; 創世記 29:24"> 拉結和利亞回答雅各說：「在我們父親的家裏還有我們可得的分嗎？還有我們的產業嗎？</span>
<span className="v" id="v15" data-v="15" data-xref="創世記 29:15–20; 創世記 31:41; 創世記 29:27–30"> 我們不是被他當作外人嗎？因為他賣了我們，吞了我們的價值。</span>
<span className="v" id="v16" data-v="16" data-xref="創世記 30:35–1; 創世記 31:9; 詩篇 45:10"> 上帝從我們父親所奪出來的一切財物，那就是我們和我們孩子們的。現今凡上帝所吩咐你的，你只管去行吧！」</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳記上 30:17; 創世記 24:61; 創世記 24:10"> 雅各起來，使他的兒子和妻子都騎上駱駝，</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 27:1–2; 創世記 27:41; 創世記 35:27–29"> 又帶着他在巴旦‧亞蘭所得的一切牲畜和財物，往迦南地、他父親以撒那裏去了。</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳記上 19:13; 創世記 31:30; 何西阿書 3:4"> 當時拉班剪羊毛去了，拉結偷了他父親家中的神像。</span>
<span className="v" id="v20" data-v="20"> 雅各背着亞蘭人拉班偷走了，並不告訴他，</span>
<span className="v" id="v21" data-v="21" data-xref="列王紀下 12:17; 創世記 37:25; 創世記 46:28"> 就帶着所有的逃跑。他起身過大河，面向基列山行去。</span>
</div>
</div>

## 拉班追趕雅各

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="約伯記 5:12–13; 創世記 30:36; 出埃及記 14:5–31"> 到第三日，有人告訴拉班，雅各逃跑了。</span>
<span className="v" id="v23" data-v="23" data-xref="創世記 13:8; 創世記 24:27; 出埃及記 2:11"> 拉班帶領他的眾弟兄去追趕，追了七日，在基列山就追上了。</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 24:50; 創世記 31:29; 創世記 20:3"> 夜間，上帝到亞蘭人拉班那裏，在夢中對他說：「你要小心，不可與雅各說好說歹。」</span>
<span className="v" id="v25" data-v="25" data-xref="創世記 12:8; 創世記 33:18; 希伯來書 11:9"> 拉班追上雅各。雅各在山上支搭帳棚；拉班和他的眾弟兄也在基列山上支搭帳棚。</span>
<span className="v" id="v26" data-v="26" data-xref="撒母耳記上 30:2; 創世記 12:18; 創世記 20:9–10"> 拉班對雅各說：「你做的是甚麼事呢？你背着我偷走了，又把我的女兒們帶了去，如同用刀劍擄去的一般。</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及記 15:20; 箴言 26:23–26; 創世記 31:3–5"> 你為甚麼暗暗地逃跑，偷着走，並不告訴我，叫我可以歡樂、唱歌、擊鼓、彈琴地送你回去？</span>
<span className="v" id="v28" data-v="28" data-xref="創世記 31:55; 路得記 1:14; 使徒行傳 20:37"> 又不容我與外孫和女兒親嘴？你所行的真是愚昧！</span>
<span className="v" id="v29" data-v="29" data-xref="創世記 31:53; 創世記 31:42; 創世記 31:24"> 我手中原有能力害你，只是你父親的上帝昨夜對我說：『你要小心，不可與雅各說好說歹。』</span>
<span className="v" id="v30" data-v="30" data-xref="耶利米書 10:11; 創世記 31:19; 士師記 18:24"> 現在你雖然想你父家，不得不去，為甚麼又偷了我的神像呢？」</span>
<span className="v" id="v31" data-v="31" data-xref="箴言 29:25; 創世記 31:26–27; 創世記 20:11"> 雅各回答拉班說：「恐怕你把你的女兒從我奪去，所以我逃跑。</span>
<span className="v" id="v32" data-v="32" data-xref="撒母耳記上 12:3–5; 創世記 31:30; 創世記 31:19"> 至於你的神像，你在誰那裏搜出來，就不容誰存活。當着我們的眾弟兄，你認一認，在我這裏有甚麼東西是你的，就拿去。」原來雅各不知道拉結偷了那些神像。</span>
<span className="v" id="v33" data-v="33" data-xref="創世記 24:67; 創世記 24:28"> 拉班進了雅各、利亞，並兩個使女的帳棚，都沒有搜出來，就從利亞的帳棚出來，進了拉結的帳棚。</span>
<span className="v" id="v34" data-v="34" data-xref="創世記 31:19; 創世記 31:17"> 拉結已經把神像藏在駱駝的馱簍裏，便坐在上頭。拉班摸遍了那帳棚，並沒有摸着。</span>
<span className="v" id="v35" data-v="35" data-xref="利未記 19:32; 出埃及記 20:12; 彼得前書 2:18"> 拉結對她父親說：「現在我身上不便，不能在你面前起來，求我主不要生氣。」這樣，拉班搜尋神像，竟沒有搜出來。</span>
<span className="v" id="v36" data-v="36" data-xref="以弗所書 4:26; 創世記 49:7; 民數記 16:15"> 雅各就發怒斥責拉班說：「我有甚麼過犯，有甚麼罪惡，你竟這樣火速地追我？</span>
<span className="v" id="v37" data-v="37" data-xref="彼得前書 2:12; 哥林多前書 6:4–5; 撒母耳記上 12:3–4"> 你摸遍了我一切的家具，你搜出甚麼來呢？可以放在你我弟兄面前，叫他們在你我中間辨別辨別。</span>
<span className="v" id="v38" data-v="38" data-xref="創世記 30:27; 申命記 28:4; 以西結書 34:2–4"> 我在你家這二十年，你的母綿羊、母山羊沒有掉過胎。你群中的公羊，我沒有吃過；</span>
<span className="v" id="v39" data-v="39" data-xref="出埃及記 22:31; 出埃及記 22:10–13; 利未記 22:8"> 被野獸撕裂的，我沒有帶來給你，是我自己賠上。無論是白日，是黑夜，被偷去的，你都向我索要。</span>
<span className="v" id="v40" data-v="40" data-xref="路加福音 2:8; 出埃及記 2:19–22; 彼得前書 5:2–4"> 我白日受盡乾熱，黑夜受盡寒霜，不得合眼睡着，我常是這樣。</span>
<span className="v" id="v41" data-v="41" data-xref="創世記 31:7; 哥林多前書 15:10; 哥林多後書 11:26"> 我這二十年在你家裏，為你的兩個女兒服事你十四年，為你的羊群服事你六年，你又十次改了我的工價。</span>
<span className="v" id="v42" data-v="42" data-xref="詩篇 31:7; 創世記 31:53; 以賽亞書 8:13"> 若不是我父親以撒所敬畏的上帝，就是亞伯拉罕的上帝與我同在，你如今必定打發我空手而去。上帝看見我的苦情和我的勞碌，就在昨夜責備你。」</span>
</div>

## 雅各和拉班立約

<div className="bt">
<div className="bp">
<span className="v" id="v43" data-v="43"> 拉班回答雅各說：「這女兒是我的女兒，這些孩子是我的孩子，這些羊群也是我的羊群；凡在你眼前的都是我的。我的女兒並她們所生的孩子，我今日能向他們做甚麼呢？</span>
<span className="v" id="v44" data-v="44" data-xref="創世記 31:52; 約書亞記 24:25–27; 約書亞記 22:27"> 來吧！你我二人可以立約，作你我中間的證據。」</span>
<span className="v" id="v45" data-v="45" data-xref="創世記 28:18–22"> 雅各就拿一塊石頭立作柱子，</span>
<span className="v" id="v46" data-v="46" data-xref="傳道書 3:5; 創世記 31:23; 創世記 31:54"> 又對眾弟兄說：「你們堆聚石頭。」他們就拿石頭來堆成一堆，大家便在旁邊吃喝。</span>
<span className="v" id="v47" data-v="47" data-xref="希伯來書 12:1"> 拉班稱那石堆為伊迦爾‧撒哈杜他，雅各卻稱那石堆為迦累得<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="都是以石堆為證的意思">b</a></sup>。</span>
<span className="v" id="v48" data-v="48" data-xref="約書亞記 24:27; 約書亞記 13:8–9; 創世記 31:23"> 拉班說：「今日這石堆作你我中間的證據。」因此這地方名叫迦累得，</span>
<span className="v" id="v49" data-v="49" data-xref="士師記 11:29; 士師記 10:17; 撒母耳記上 7:5–6"> 又叫米斯巴，意思說：「我們彼此離別以後，願耶和華在你我中間鑒察。</span>
<span className="v" id="v50" data-v="50" data-xref="耶利米書 42:5; 耶利米書 29:23; 彌迦書 1:2"> 你若苦待我的女兒，又在我的女兒以外另娶妻，雖沒有人知道，卻有上帝在你我中間作見證。」</span>
<span className="v" id="v51" data-v="51"> 拉班又說：「你看我在你我中間所立的這石堆和柱子。</span>
<span className="v" id="v52" data-v="52" data-xref="創世記 31:48; 創世記 31:44–45"> 這石堆作證據，這柱子也作證據。我必不過這石堆去害你；你也不可過這石堆和柱子來害我。</span>
<span className="v" id="v53" data-v="53" data-xref="創世記 31:42; 創世記 16:5; 約書亞記 24:2"> 但願亞伯拉罕的上帝和拿鶴的上帝，就是他們父親的上帝，在你我中間判斷。」雅各就指着他父親以撒所敬畏的上帝起誓，</span>
<span className="v" id="v54" data-v="54" data-xref="出埃及記 18:12; 創世記 37:25; 創世記 26:30"> 又在山上獻祭，請眾弟兄來吃飯。他們吃了飯，便在山上住宿。</span>
<span className="v" id="v55" data-v="55" data-xref="創世記 31:28; 申命記 23:5; 創世記 18:33"> 拉班清早起來，與他外孫和女兒親嘴，給他們祝福，回往自己的地方去了。</span>

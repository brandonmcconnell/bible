## 人違背命令

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多後書 11:3; 哥林多後書 11:14; 啟示錄 12:9"> 耶和華上帝所造的，惟有蛇比田野一切的活物更狡猾。蛇對女人說：「上帝豈是真說不許你們吃園中所有樹上的果子嗎？」</span>
<span className="v" id="v2" data-v="2" data-xref="詩篇 58:4"> 女人對蛇說：「園中樹上的果子，我們可以吃，</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 2:16–17; 哥林多後書 6:17; 出埃及記 19:12–13"> 惟有園當中那棵樹上的果子，上帝曾說：『你們不可吃，也不可摸，免得你們死。』」</span>
<span className="v" id="v4" data-v="4" data-xref="約翰福音 8:44; 哥林多後書 11:3; 提摩太前書 2:14"> 蛇對女人說：「你們不一定死；</span>
<span className="v" id="v5" data-v="5" data-xref="以西結書 28:2; 帖撒羅尼迦後書 2:4; 哥林多後書 11:13–15"> 因為上帝知道，你們吃的日子眼睛就明亮了，你們便如上帝能知道善惡。」</span>
<span className="v" id="v6" data-v="6" data-xref="約翰一書 2:16; 雅各書 1:14–15; 提摩太前書 2:14"> 於是女人見那棵樹的果子好作食物，也悅人的眼目，且是可喜愛的，能使人有智慧，就摘下果子來吃了，又給她丈夫，她丈夫也吃了。</span>
<span className="v" id="v7" data-v="7" data-xref="以賽亞書 59:6; 創世記 2:25; 創世記 3:5"> 他們二人的眼睛就明亮了，才知道自己是赤身露體，便拿無花果樹的葉子為自己編做裙子。</span>
<span className="v" id="v8" data-v="8" data-xref="耶利米書 23:24; 箴言 15:3; 希伯來書 4:13"> 天起了涼風，耶和華上帝在園中行走。那人和他妻子聽見上帝的聲音，就藏在園裏的樹木中，躲避耶和華上帝的面。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 4:9; 創世記 16:8; 創世記 18:20–21"> 耶和華上帝呼喚那人，對他說：「你在哪裏？」</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 2:25; 詩篇 119:120; 以賽亞書 47:3"> 他說：「我在園中聽見你的聲音，我就害怕；因為我赤身露體，我便藏了。」</span>
<span className="v" id="v11" data-v="11" data-xref="羅馬書 3:20; 創世記 4:10; 詩篇 50:21"> 耶和華說：「誰告訴你赤身露體呢？莫非你吃了我吩咐你不可吃的那樹上的果子嗎？」</span>
<span className="v" id="v12" data-v="12" data-xref="箴言 28:13; 雅各書 1:13–15; 約伯記 31:33"> 那人說：「你所賜給我、與我同居的女人，她把那樹上的果子給我，我就吃了。」</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多後書 11:3; 提摩太前書 2:14; 創世記 4:10–12"> 耶和華上帝對女人說：「你做的是甚麼事呢？」女人說：「那蛇引誘我，我就吃了。」</span>
</div>
</div>

## 上帝的宣判

<div className="bt">
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="彌迦書 7:17; 以賽亞書 65:25; 詩篇 72:9"> <span className="pl pl-1">耶和華上帝對蛇說：</span><br /><span className="pl pl-1">你既做了這事，就必受咒詛，</span><br /><span className="pl pl-1">比一切的牲畜野獸更甚；</span><br /><span className="pl pl-1">你必用肚子行走，</span><br /><span className="pl pl-1">終身吃土。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="羅馬書 16:20; 約翰一書 3:8; 啟示錄 12:17"> <span className="pl pl-1">我又要叫你和女人彼此為仇；</span><br /><span className="pl pl-1">你的後裔和女人的後裔也彼此為仇。</span><br /><span className="pl pl-1">女人的後裔要傷你的頭；</span><br /><span className="pl pl-1">你要傷他的腳跟。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="提多書 2:5; 歌羅西書 3:18; 哥林多前書 11:3"> <span className="pl pl-1">又對女人說：</span><br /><span className="pl pl-1">我必多多加增你懷胎的苦楚；</span><br /><span className="pl pl-1">你生產兒女必多受苦楚。</span><br /><span className="pl pl-1">你必戀慕你丈夫；</span><br /><span className="pl pl-1">你丈夫必管轄你。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="羅馬書 8:20–22; 創世記 5:29; 以賽亞書 24:5–6"> <span className="pl pl-1">又對亞當說：</span><br /><span className="pl pl-1">你既聽從妻子的話，</span><br /><span className="pl pl-1">吃了我所吩咐你不可吃的那樹上的果子，</span><br /><span className="pl pl-1">地必為你的緣故受咒詛；</span><br /><span className="pl pl-1">你必終身勞苦才能從地裏得吃的。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="馬太福音 13:7; 約伯記 5:5; 以賽亞書 7:23"> <span className="pl pl-1">地必給你長出荊棘和蒺藜來；</span><br /><span className="pl pl-1">你也要吃田間的菜蔬。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="傳道書 12:7; 約伯記 34:15; 詩篇 104:29"> <span className="pl pl-1">你必汗流滿面才得糊口，</span><br /><span className="pl pl-1">直到你歸了土，</span><br /><span className="pl pl-1">因為你是從土而出的。</span><br /><span className="pl pl-1">你本是塵土，仍要歸於塵土。</span></span>
<span className="v" id="v20" data-v="20" data-xref="創世記 2:23; 馬太福音 1:23; 創世記 5:29"> 亞當給他妻子起名叫夏娃，因為她是眾生之母。</span>
<span className="v" id="v21" data-v="21" data-xref="以賽亞書 61:10; 哥林多後書 5:21; 哥林多後書 5:2–3"> 耶和華上帝為亞當和他妻子用皮子做衣服給他們穿。</span>
</div>
</div>

## 亞當和夏娃被趕出伊甸園

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="啟示錄 2:7; 啟示錄 22:14; 箴言 3:18"> 耶和華上帝說：「那人已經與我們相似，能知道善惡；現在恐怕他伸手又摘生命樹的果子吃，就永遠活着。」</span>
<span className="v" id="v23" data-v="23" data-xref="創世記 4:2; 創世記 3:19; 創世記 4:12"> 耶和華上帝便打發他出伊甸園去，耕種他所自出之土。</span>
<span className="v" id="v24" data-v="24" data-xref="希伯來書 1:7; 詩篇 104:4; 出埃及記 25:18–22"> 於是把他趕出去了；又在伊甸園的東邊安設基路伯和四面轉動發火焰的劍，要把守生命樹的道路。</span>
</div>

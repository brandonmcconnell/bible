## 以撒娶妻

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="詩篇 112:1–3; 加拉太書 3:9; 馬太福音 6:33"> 亞伯拉罕年紀老邁，向來在一切事上耶和華都賜福給他。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 47:29; 創世記 39:4–6; 創世記 15:2"> 亞伯拉罕對管理他全業最老的僕人說：「請你把手放在我大腿底下。</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多後書 6:14–17; 創世記 26:34–35; 創世記 28:8"> 我要叫你指着耶和華－天地的主起誓，不要為我兒子娶這迦南地中的女子為妻。</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 28:2; 創世記 22:20–23; 創世記 12:7"> 你要往我本地本族去，為我的兒子以撒娶一個妻子。」</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米書 4:2; 出埃及記 9:2; 出埃及記 20:7"> 僕人對他說：「倘若女子不肯跟我到這地方來，我必須將你的兒子帶回你原出之地嗎？」</span>
<span className="v" id="v6" data-v="6" data-xref="加拉太書 5:1; 彼得後書 2:20–22; 希伯來書 10:39"> 亞伯拉罕對他說：「你要謹慎，不要帶我的兒子回那裏去。</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及記 33:2; 創世記 13:15; 希伯來書 1:14"> 耶和華－天上的主曾帶領我離開父家和本族的地，對我說話，向我起誓說：『我要將這地賜給你的後裔。』他必差遣使者在你面前，你就可以從那裏為我兒子娶一個妻子。</span>
<span className="v" id="v8" data-v="8" data-xref="約書亞記 2:17–20; 民數記 30:5; 民數記 30:8"> 倘若女子不肯跟你來，我使你起的誓就與你無干了，只是不可帶我的兒子回那裏去。」</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 24:2"> 僕人就把手放在他主人亞伯拉罕的大腿底下，為這事向他起誓。</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 11:31; 申命記 23:4; 創世記 27:43"> 那僕人從他主人的駱駝裏取了十匹駱駝，並帶些他主人各樣的財物，起身往美索不達米亞去，到了拿鶴的城。</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳記上 9:11; 出埃及記 2:16; 約翰福音 4:7"> 天將晚，眾女子出來打水的時候，他便叫駱駝跪在城外的水井那裏。</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 24:27; 出埃及記 3:6; 創世記 26:24"> 他說：「耶和華－我主人亞伯拉罕的上帝啊，求你施恩給我主人亞伯拉罕，使我今日遇見好機會。</span>
<span className="v" id="v13" data-v="13" data-xref="創世記 24:43; 詩篇 37:5; 出埃及記 2:16"> 我現今站在井旁，城內居民的女子們正出來打水。</span>
<span className="v" id="v14" data-v="14" data-xref="士師記 6:37; 士師記 6:17; 創世記 15:8"> 我向那一個女子說：『請你拿下水瓶來，給我水喝。』她若說：『請喝！我也給你的駱駝喝。』願那女子就作你所預定給你僕人以撒的妻。這樣，我便知道你施恩給我主人了。」</span>
<span className="v" id="v15" data-v="15" data-xref="創世記 11:29; 創世記 24:45; 以賽亞書 65:24"> 話還沒有說完，不料，利百加肩頭上扛着水瓶出來。利百加是彼土利所生的；彼土利是亞伯拉罕兄弟拿鶴妻子密迦的兒子。</span>
<span className="v" id="v16" data-v="16" data-xref="創世記 26:7; 民數記 31:17–18; 創世記 39:6"> 那女子容貌極其俊美，還是處女，也未曾有人親近她。她下到井旁，打滿了瓶，又上來。</span>
<span className="v" id="v17" data-v="17" data-xref="約翰福音 4:7; 以賽亞書 21:14; 創世記 26:1–35"> 僕人跑上前去迎着她，說：「求你將瓶裏的水給我一點喝。」</span>
<span className="v" id="v18" data-v="18" data-xref="箴言 31:26; 彼得前書 3:8; 創世記 24:14"> 女子說：「我主請喝！」就急忙拿下瓶來，托在手上給他喝。</span>
<span className="v" id="v19" data-v="19" data-xref="創世記 24:14; 彼得前書 4:9; 創世記 24:45–46"> 女子給他喝了，就說：「我再為你的駱駝打水，叫駱駝也喝足。」</span>
<span className="v" id="v20" data-v="20"> 她就急忙把瓶裏的水倒在槽裏，又跑到井旁打水，就為所有的駱駝打上水來。</span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 107:43; 創世記 24:12; 撒母耳記下 7:18–20"> 那人定睛看她，一句話也不說，要曉得耶和華賜他通達的道路沒有。</span>
<span className="v" id="v22" data-v="22" data-xref="以西結書 16:11–12; 出埃及記 32:2–3; 創世記 23:15–16"> 駱駝喝足了，那人就拿一個金環，重半舍客勒，兩個金鐲，重十舍客勒，給了那女子，</span>
<span className="v" id="v23" data-v="23"> 說：「請告訴我，你是誰的女兒？你父親家裏有我們住宿的地方沒有？」</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 24:15; 創世記 22:23; 創世記 22:20"> 女子說：「我是密迦與拿鶴之子彼土利的女兒」；</span>
<span className="v" id="v25" data-v="25" data-xref="以賽亞書 32:8; 彼得前書 4:9; 士師記 19:19–21"> 又說：「我們家裏足有糧草，也有住宿的地方。」</span>
<span className="v" id="v26" data-v="26" data-xref="創世記 24:48; 出埃及記 4:31; 創世記 24:52"> 那人就低頭向耶和華下拜，</span>
<span className="v" id="v27" data-v="27" data-xref="創世記 24:48; 創世記 24:12; 詩篇 98:3"> 說：「耶和華－我主人亞伯拉罕的上帝是應當稱頌的，因他不斷地以慈愛誠實待我主人。至於我，耶和華在路上引領我，直走到我主人的兄弟家裏。」</span>
<span className="v" id="v28" data-v="28" data-xref="創世記 24:67; 創世記 24:55; 創世記 31:33"> 女子跑回去，照着這些話告訴她母親和她家裏的人。</span>
<span className="v" id="v29" data-v="29" data-xref="創世記 29:5; 創世記 29:13; 創世記 24:55"> 利百加有一個哥哥，名叫拉班，看見金環，又看見金鐲在他妹子的手上，並聽見他妹子利百加的話，說那人對我如此如此說。拉班就跑出來往井旁去，到那人跟前，見他仍站在駱駝旁邊的井旁那裏，</span>
<span className="v" id="v31" data-v="31" data-xref="路得記 3:10; 創世記 26:29; 詩篇 115:15"> 便對他說：「你這蒙耶和華賜福的，請進來，為甚麼站在外邊？我已經收拾了房屋，也為駱駝預備了地方。」</span>
<span className="v" id="v32" data-v="32" data-xref="士師記 19:21; 創世記 43:24; 創世記 18:4"> 那人就進了拉班的家。拉班卸了駱駝，用草料餵上，拿水給那人和跟隨的人洗腳；</span>
<span className="v" id="v33" data-v="33" data-xref="詩篇 132:3–5; 提摩太前書 6:2; 以弗所書 6:5–8"> 把飯擺在他面前，叫他吃，他卻說：「我不吃，等我說明白我的事情再吃。」拉班說：「請說。」</span>
<span className="v" id="v34" data-v="34"> 他說：「我是亞伯拉罕的僕人。</span>
<span className="v" id="v35" data-v="35" data-xref="創世記 24:1; 創世記 13:2; 箴言 10:22"> 耶和華大大地賜福給我主人，使他昌大，又賜給他羊群、牛群、金銀、僕婢、駱駝，和驢。</span>
<span className="v" id="v36" data-v="36" data-xref="創世記 25:5; 創世記 21:10; 創世記 21:1–7"> 我主人的妻子撒拉年老的時候給我主人生了一個兒子；我主人也將一切所有的都給了這個兒子。</span>
<span className="v" id="v37" data-v="37" data-xref="創世記 27:46; 以斯拉記 9:1–3; 創世記 24:2–9"> 我主人叫我起誓說：『你不要為我兒子娶迦南地的女子為妻。</span>
<span className="v" id="v38" data-v="38" data-xref="創世記 24:4; 創世記 31:19; 創世記 12:1"> 你要往我父家、我本族那裏去，為我的兒子娶一個妻子。』</span>
<span className="v" id="v39" data-v="39" data-xref="創世記 24:5"> 我對我主人說：『恐怕女子不肯跟我來。』</span>
<span className="v" id="v40" data-v="40" data-xref="出埃及記 23:20; 詩篇 16:8; 創世記 5:24"> 他就說：『我所事奉的耶和華必要差遣他的使者與你同去，叫你的道路通達，你就得以在我父家、我本族那裏，給我的兒子娶一個妻子。</span>
<span className="v" id="v41" data-v="41" data-xref="創世記 24:8; 申命記 29:12"> 只要你到了我本族那裏，我使你起的誓就與你無干。他們若不把女子交給你，我使你起的誓也與你無干。』</span>
<span className="v" id="v42" data-v="42" data-xref="尼希米記 1:11; 創世記 24:12–14; 以斯拉記 8:21"> 「我今日到了井旁，便說：『耶和華－我主人亞伯拉罕的上帝啊，願你叫我所行的道路通達。</span>
<span className="v" id="v43" data-v="43" data-xref="創世記 24:13–14"> 我如今站在井旁，對哪一個出來打水的女子說：請你把你瓶裏的水給我一點喝；</span>
<span className="v" id="v44" data-v="44" data-xref="創世記 24:14; 彼得前書 3:8; 創世記 2:22"> 她若說：你只管喝，我也為你的駱駝打水；願那女子就作耶和華給我主人兒子所預定的妻。』</span>
<span className="v" id="v45" data-v="45" data-xref="馬太福音 7:7; 使徒行傳 12:12–17; 創世記 24:15–20"> 我心裏的話還沒有說完，利百加就出來，肩頭上扛着水瓶，下到井旁打水。我便對她說：『請你給我水喝。』</span>
<span className="v" id="v46" data-v="46" data-xref="創世記 24:18–19"> 她就急忙從肩頭上拿下瓶來，說：『請喝！我也給你的駱駝喝。』我便喝了；她又給我的駱駝喝了。</span>
<span className="v" id="v47" data-v="47" data-xref="詩篇 45:13–14; 創世記 24:22–24; 以賽亞書 62:3–5"> 我問她說：『你是誰的女兒？』她說：『我是密迦與拿鶴之子彼土利的女兒。』我就把環子戴在她鼻子上，把鐲子戴在她兩手上。</span>
<span className="v" id="v48" data-v="48" data-xref="箴言 3:5–6; 創世記 24:26–27; 詩篇 48:14"> 隨後我低頭向耶和華下拜，稱頌耶和華－我主人亞伯拉罕的上帝；因為他引導我走合式的道路，使我得着我主人兄弟的孫女，給我主人的兒子為妻。</span>
<span className="v" id="v49" data-v="49" data-xref="創世記 47:29; 約書亞記 2:14; 箴言 3:3"> 現在你們若願以慈愛誠實待我主人，就告訴我；若不然，也告訴我，使我可以或向左，或向右。」</span>
<span className="v" id="v50" data-v="50" data-xref="詩篇 118:23; 創世記 31:24; 創世記 31:29"> 拉班和彼土利回答說：「這事乃出於耶和華，我們不能向你說好說歹。</span>
<span className="v" id="v51" data-v="51" data-xref="創世記 20:15; 創世記 24:15; 撒母耳記下 16:10"> 看哪，利百加在你面前，可以將她帶去，照着耶和華所說的，給你主人的兒子為妻。」</span>
<span className="v" id="v52" data-v="52" data-xref="創世記 24:26; 創世記 24:48; 詩篇 116:1–2"> 亞伯拉罕的僕人聽見他們這話，就向耶和華俯伏在地。</span>
<span className="v" id="v53" data-v="53" data-xref="創世記 24:22; 創世記 24:10; 出埃及記 12:35"> 當下僕人拿出金器、銀器，和衣服送給利百加，又將寶物送給她哥哥和她母親。</span>
<span className="v" id="v54" data-v="54" data-xref="創世記 24:56; 創世記 24:59; 創世記 28:5–6"> 僕人和跟從他的人吃了喝了，住了一夜。早晨起來，僕人就說：「請打發我回我主人那裏去吧。」</span>
<span className="v" id="v55" data-v="55" data-xref="創世記 4:3; 利未記 25:29; 士師記 14:8"> 利百加的哥哥和她母親說：「讓女子同我們再住幾天，至少十天，然後她可以去。」</span>
<span className="v" id="v56" data-v="56" data-xref="箴言 25:25; 約書亞記 1:8; 以賽亞書 48:15"> 僕人說：「耶和華既賜給我通達的道路，你們不要耽誤我，請打發我走，回我主人那裏去吧。」</span>
<span className="v" id="v57" data-v="57"> 他們說：「我們把女子叫來問問她」，</span>
<span className="v" id="v58" data-v="58" data-xref="路加福音 1:38; 詩篇 45:10–11"> 就叫了利百加來，問她說：「你和這人同去嗎？」利百加說：「我去。」</span>
<span className="v" id="v59" data-v="59" data-xref="創世記 35:8; 民數記 11:12; 創世記 24:50"> 於是他們打發妹子利百加和她的乳母，同亞伯拉罕的僕人，並跟從僕人的，都走了。</span>
<span className="v" id="v60" data-v="60" data-xref="創世記 22:17; 創世記 17:16; 路得記 4:11–12"> 他們就給利百加祝福說：<br /><span className="pl pl-1">我們的妹子啊，願你作千萬人的母！</span><br /><span className="pl pl-1">願你的後裔得着仇敵的城門！</span></span>
<span className="v" id="v61" data-v="61" data-xref="詩篇 45:10; 創世記 2:24; 以斯帖記 8:14"> 利百加和她的使女們起來，騎上駱駝，跟着那僕人，僕人就帶着利百加走了。</span>
<span className="v" id="v62" data-v="62" data-xref="創世記 25:11; 創世記 16:14; 創世記 12:9"> 那時，以撒住在南地，剛從庇耳‧拉海‧萊回來。</span>
<span className="v" id="v63" data-v="63" data-xref="詩篇 119:15; 詩篇 1:2; 詩篇 104:34"> 天將晚，以撒出來在田間默想，舉目一看，見來了些駱駝。</span>
<span className="v" id="v64" data-v="64" data-xref="士師記 1:14; 約書亞記 15:18"> 利百加舉目看見以撒，就急忙下了駱駝，</span>
<span className="v" id="v65" data-v="65" data-xref="提摩太前書 2:9; 哥林多前書 11:5–6; 哥林多前書 11:10"> 問那僕人說：「這田間走來迎接我們的是誰？」僕人說：「是我的主人。」利百加就拿帕子蒙上臉。</span>
<span className="v" id="v66" data-v="66" data-xref="馬可福音 6:30"> 僕人就將所辦的一切事都告訴以撒。</span>
<span className="v" id="v67" data-v="67" data-xref="雅歌 8:2; 以弗所書 5:22–33; 創世記 23:1–2"> 以撒便領利百加進了他母親撒拉的帳棚，娶了她為妻，並且愛她。以撒自從他母親不在了，這才得了安慰。</span>

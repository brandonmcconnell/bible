## 以掃的子孫

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 22:17; 歷代志上 1:35; 申命記 23:7"> 以掃就是以東，他的後代記在下面。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 36:25; 創世記 28:9; 創世記 9:25"> 以掃娶迦南的女子為妻，就是赫人以倫的女兒亞大和希未人祭便的孫女、亞拿的女兒阿何利巴瑪，</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 28:9; 創世記 25:13"> 又娶了以實瑪利的女兒、尼拜約的妹子巴實抹。</span>
<span className="v" id="v4" data-v="4" data-xref="歷代志上 1:35; 出埃及記 2:18; 約伯記 2:11"> 亞大給以掃生了以利法；巴實抹生了流珥；</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 35:29"> 阿何利巴瑪生了耶烏施、雅蘭、可拉。這都是以掃的兒子，是在迦南地生的。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="創世記 32:3; 創世記 12:5; 創世記 17:8"> 以掃帶着他的妻子、兒女，與家中一切的人口，並他的牛羊、牲畜，和一切貨財，就是他在迦南地所得的，往別處去，離了他兄弟雅各。</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 13:6; 創世記 17:8; 創世記 28:4"> 因為二人的財物群畜甚多，寄居的地方容不下他們，所以不能同居。</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 32:3; 瑪拉基書 1:3; 以西結書 35:2–7"> 於是以掃住在西珥山裏；以掃就是以東。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="創世記 19:37"> 以掃是西珥山裏以東人的始祖，他的後代記在下面。</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 36:3–4; 歷代志上 1:35–54"> 以掃眾子的名字如下。以掃的妻子亞大生以利法；以掃的妻子巴實抹生流珥。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 36:15–16; 歷代志上 1:35–36"> 以利法的兒子是提幔、阿抹、洗玻、迦坦、基納斯。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及記 17:8–16; 申命記 25:17–19; 撒母耳記上 15:2–9"> 亭納是以掃兒子以利法的妾；她給以利法生了亞瑪力。這是以掃的妻子亞大的子孫。</span>
<span className="v" id="v13" data-v="13" data-xref="歷代志上 1:37; 創世記 36:17"> 流珥的兒子是拿哈、謝拉、沙瑪、米撒。這是以掃妻子巴實抹的子孫。</span>
<span className="v" id="v14" data-v="14" data-xref="創世記 36:2; 創世記 36:18; 歷代志上 1:35"> 以掃的妻子阿何利巴瑪是祭便的孫女，亞拿的女兒；她給以掃生了耶烏施、雅蘭、可拉。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="俄巴底亞書 1:9; 約伯記 2:11; 創世記 36:11–12"> 以掃子孫中作族長的記在下面。以掃的長子以利法的子孫中，有提幔族長、阿抹族長、洗玻族長、基納斯族長、</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 15:15"> 可拉族長、迦坦族長、亞瑪力族長。這是在以東地從以利法所出的族長，都是亞大的子孫。</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 36:13; 歷代志上 1:37; 創世記 36:4"> 以掃的兒子流珥的子孫中，有拿哈族長、謝拉族長、沙瑪族長、米撒族長。這是在以東地從流珥所出的族長，都是以掃妻子巴實抹的子孫。</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 36:14; 歷代志上 1:35; 創世記 36:5"> 以掃的妻子阿何利巴瑪的子孫中，有耶烏施族長、雅蘭族長、可拉族長。這是從以掃妻子，亞拿的女兒，阿何利巴瑪子孫中所出的族長。</span>
<span className="v" id="v19" data-v="19"> 以上的族長都是以掃的子孫；以掃就是以東。</span>
</div>
</div>

## 西珥的子孫

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="申命記 2:12; 申命記 2:22; 創世記 14:6"> 那地原有的居民－何利人西珥的子孫記在下面：就是羅坍、朔巴、祭便、亞拿、</span>
<span className="v" id="v21" data-v="21"> 底順、以察、底珊。這是從以東地的何利人西珥子孫中所出的族長。</span>
<span className="v" id="v22" data-v="22" data-xref="歷代志上 1:39"> 羅坍的兒子是何利、希幔；羅坍的妹子是亭納。</span>
<span className="v" id="v23" data-v="23" data-xref="歷代志上 1:40"> 朔巴的兒子是亞勒文、瑪拿轄、以巴錄、示玻、阿南。</span>
<span className="v" id="v24" data-v="24" data-xref="申命記 2:10; 撒母耳記下 18:9; 列王紀上 4:28"> 祭便的兒子是亞雅、亞拿（當時在曠野放他父親祭便的驢，遇着溫泉的，就是這亞拿）。</span>
<span className="v" id="v25" data-v="25" data-xref="創世記 36:2; 創世記 36:18; 歷代志上 1:41"> 亞拿的兒子是底順；亞拿的女兒是阿何利巴瑪。</span>
<span className="v" id="v26" data-v="26" data-xref="歷代志上 1:41"> 底順的兒子是欣但、伊是班、益蘭、基蘭。</span>
<span className="v" id="v27" data-v="27" data-xref="歷代志上 1:42; 創世記 36:21; 歷代志上 1:38"> 以察的兒子是辟罕、撒番、亞干。</span>
<span className="v" id="v28" data-v="28" data-xref="耶利米哀歌 4:21; 約伯記 1:1; 耶利米書 25:20"> 底珊的兒子是烏斯、亞蘭。</span>
<span className="v" id="v29" data-v="29" data-xref="創世記 36:20; 創世記 36:28; 歷代志上 1:41–42"> 從何利人所出的族長記在下面：就是羅坍族長、朔巴族長、祭便族長、亞拿族長、</span>
<span className="v" id="v30" data-v="30" data-xref="但以理書 7:23; 以賽亞書 23:15; 列王紀下 11:19"> 底順族長、以察族長、底珊族長。這是從何利人所出的族長，都在西珥地，按着宗族作族長。</span>
</div>
</div>

## 以東諸王

<div className="bt">
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="創世記 17:6; 歷代志上 1:43–50; 創世記 17:16"> 以色列人未有君王治理以先，在以東地作王的記在下面。</span>
<span className="v" id="v32" data-v="32"> 比珥的兒子比拉在以東作王，他的京城名叫亭哈巴。</span>
<span className="v" id="v33" data-v="33" data-xref="耶利米書 49:13; 耶利米書 49:22; 阿摩司書 1:12"> 比拉死了，波斯拉人謝拉的兒子約巴接續他作王。</span>
<span className="v" id="v34" data-v="34" data-xref="創世記 36:11; 約伯記 2:11; 創世記 36:15"> 約巴死了，提幔地的人戶珊接續他作王。</span>
<span className="v" id="v35" data-v="35"> 戶珊死了，比達的兒子哈達接續他作王；這哈達就是在摩押地殺敗米甸人的，他的京城名叫亞未得。</span>
<span className="v" id="v36" data-v="36" data-xref="歷代志上 1:47"> 哈達死了，瑪士利加人桑拉接續他作王。</span>
<span className="v" id="v37" data-v="37" data-xref="歷代志上 1:48; 創世記 10:11"> 桑拉死了，大河邊的利河伯人掃羅接續他作王。</span>
<span className="v" id="v38" data-v="38"> 掃羅死了，亞革波的兒子巴勒‧哈南接續他作王。</span>
<span className="v" id="v39" data-v="39" data-xref="出埃及記 15:15; 歷代志上 1:50"> 亞革波的兒子巴勒‧哈南死了，哈達接續他作王，他的京城名叫巴烏；他的妻子名叫米希她別，是米‧薩合的孫女，瑪特列的女兒。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="歷代志上 1:51–54; 出埃及記 15:15; 創世記 36:31"> 從以掃所出的族長，按着他們的宗族、住處、名字記在下面：就是亭納族長、亞勒瓦族長、耶帖族長、</span>
<span className="v" id="v41" data-v="41"> 阿何利巴瑪族長、以拉族長、比嫩族長、</span>
<span className="v" id="v42" data-v="42"> 基納斯族長、提幔族長、米比薩族長、</span>
<span className="v" id="v43" data-v="43" data-xref="創世記 45:8; 歷代志上 4:14; 創世記 25:30"> 瑪基疊族長、以蘭族長。這是以東人在所得為業的地上，按着他們的住處。（所有的族長都是以東人的始祖以掃的後代。）</span>
</div>
</div>

</div>

## 雅各到了拉班的家

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士師記 6:3; 士師記 6:33; 何西阿書 12:12"> 雅各起行，到了東方人之地，</span>
<span className="v" id="v2" data-v="2" data-xref="約翰福音 4:14; 以賽亞書 49:10; 約翰福音 4:6"> 看見田間有一口井，有三群羊臥在井旁；因為人飲羊群都是用那井裏的水。井口上的石頭是大的。</span>
<span className="v" id="v3" data-v="3"> 常有羊群在那裏聚集，牧人把石頭轉離井口飲羊，隨後又把石頭放在井口的原處。</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 28:10; 創世記 27:43; 使徒行傳 7:2"> 雅各對牧人說：「弟兄們，你們是哪裏來的？」他們說：「我們是哈蘭來的。」</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 24:24; 創世記 24:29; 創世記 31:53"> 他問他們說：「拿鶴的孫子拉班，你們認識嗎？」他們說：「我們認識。」</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳記下 20:9; 創世記 37:14; 出埃及記 18:7"> 雅各說：「他平安嗎？」他們說：「平安。看哪，他女兒拉結領着羊來了。」</span>
<span className="v" id="v7" data-v="7" data-xref="以弗所書 5:16; 加拉太書 6:9–10"> 雅各說：「日頭還高，不是羊群聚集的時候，你們不如飲羊，再去放一放。」</span>
<span className="v" id="v8" data-v="8" data-xref="馬可福音 16:3; 路加福音 24:2; 創世記 34:14"> 他們說：「我們不能，必等羊群聚齊，人把石頭轉離井口才可飲羊。」</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及記 2:21; 雅歌 1:7–8; 出埃及記 2:15–16"> 雅各正和他們說話的時候，拉結領着她父親的羊來了，因為那些羊是她牧放的。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及記 2:17"> 雅各看見母舅拉班的女兒拉結和母舅拉班的羊群，就上前把石頭轉離井口，飲他母舅拉班的羊群。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 33:4; 創世記 45:14–15; 創世記 45:2"> 雅各與拉結親嘴，就放聲而哭。</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 24:28; 創世記 13:8; 創世記 14:14–16"> 雅各告訴拉結，自己是她父親的外甥，是利百加的兒子，拉結就跑去告訴她父親。</span>
<span className="v" id="v13" data-v="13" data-xref="創世記 24:29; 使徒行傳 20:37; 羅馬書 16:16"> 拉班聽見外甥雅各的信息，就跑去迎接，抱着他，與他親嘴，領他到自己的家。雅各將一切的情由告訴拉班。</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳記下 19:12–13; 創世記 2:23; 士師記 9:2"> 拉班對他說：「你實在是我的骨肉。」雅各就和他同住了一個月。</span>
</div>
</div>

## 雅各為拉結和利亞服事拉班

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="創世記 30:28; 創世記 31:7"> 拉班對雅各說：「你雖是我的骨肉<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是弟兄">a</a></sup>，豈可白白地服事我？請告訴我，你要甚麼為工價？」</span>
<span className="v" id="v16" data-v="16" data-xref="路得記 4:11; 創世記 49:31; 創世記 31:4"> 拉班有兩個女兒，大的名叫利亞，小的名叫拉結。</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 12:11; 創世記 46:19–22; 創世記 24:16"> 利亞的眼睛沒有神氣，拉結卻生得美貌俊秀。</span>
<span className="v" id="v18" data-v="18" data-xref="何西阿書 12:12; 出埃及記 22:16–17; 創世記 34:12"> 雅各愛拉結，就說：「我願為你小女兒拉結服事你七年。」</span>
<span className="v" id="v19" data-v="19" data-xref="以賽亞書 6:11; 以賽亞書 6:5; 詩篇 12:2"> 拉班說：「我把她給你，勝似給別人，你與我同住吧！」</span>
<span className="v" id="v20" data-v="20" data-xref="哥林多前書 13:7; 以弗所書 5:2; 何西阿書 12:12"> 雅各就為拉結服事了七年；他因為深愛拉結，就看這七年如同幾天。</span>
<span className="v" id="v21" data-v="21" data-xref="士師記 15:1; 創世記 29:20; 創世記 4:1"> 雅各對拉班說：「日期已經滿了，求你把我的妻子給我，我好與她同房。」</span>
<span className="v" id="v22" data-v="22" data-xref="啟示錄 19:9; 路得記 4:10–13; 士師記 14:10–18"> 拉班就擺設筵席，請齊了那地方的眾人。</span>
<span className="v" id="v23" data-v="23" data-xref="彌迦書 7:5; 創世記 38:14–15; 創世記 24:65"> 到晚上，拉班將女兒利亞送來給雅各，雅各就與她同房。</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 16:1; 創世記 30:9–12; 創世記 46:18"> 拉班又將婢女悉帕給女兒利亞作使女。</span>
<span className="v" id="v25" data-v="25" data-xref="馬太福音 7:2; 箴言 11:31; 哥林多前書 3:13"> 到了早晨，雅各一看是利亞，就對拉班說：「你向我做的是甚麼事呢？我服事你，不是為拉結嗎？你為甚麼欺哄我呢？」</span>
<span className="v" id="v26" data-v="26"> 拉班說：「大女兒還沒有給人，先把小女兒給人，在我們這地方沒有這規矩。</span>
<span className="v" id="v27" data-v="27" data-xref="利未記 18:18; 士師記 14:12; 創世記 2:2–3"> 你為這個滿了七日，我就把那個也給你，你再為她服事我七年。」</span>
<span className="v" id="v28" data-v="28"> 雅各就如此行。滿了利亞的七日，拉班便將女兒拉結給雅各為妻。</span>
<span className="v" id="v29" data-v="29" data-xref="創世記 35:22; 創世記 29:24; 創世記 30:3–8"> 拉班又將婢女辟拉給女兒拉結作使女。</span>
<span className="v" id="v30" data-v="30" data-xref="創世記 31:41; 創世記 29:20; 創世記 31:15"> 雅各也與拉結同房，並且愛拉結勝似愛利亞，於是又服事了拉班七年。</span>
</div>
</div>

## 雅各的兒女

<div className="bt">
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="撒母耳記上 2:21; 馬太福音 10:37; 申命記 21:15"> 耶和華見利亞失寵<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原文是被恨；下同">b</a></sup>，就使她生育，拉結卻不生育。</span>
<span className="v" id="v32" data-v="32" data-xref="申命記 26:7; 出埃及記 4:31; 出埃及記 3:7"> 利亞懷孕生子，就給他起名叫呂便<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="就是有兒子的意思">c</a></sup>，因而說：「耶和華看見我的苦情，如今我的丈夫必愛我。」</span>
<span className="v" id="v33" data-v="33" data-xref="創世記 34:25; 創世記 49:5–6; 創世記 34:30"> 她又懷孕生子，就說：「耶和華因為聽見我失寵，所以又賜給我這個兒子」，於是給他起名叫西緬<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="就是聽見的意思">d</a></sup>。</span>
<span className="v" id="v34" data-v="34" data-xref="出埃及記 32:26–29; 創世記 49:5–7; 創世記 46:11"> 她又懷孕生子，起名叫利未<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="就是聯合的意思">e</a></sup>，說：「我給丈夫生了三個兒子，他必與我聯合。」</span>
<span className="v" id="v35" data-v="35" data-xref="馬太福音 1:2; 歷代志上 5:2; 創世記 49:8–12"> 她又懷孕生子，說：「這回我要讚美耶和華」，因此給他起名叫猶大<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="就是讚美的意思">f</a></sup>。這才停了生育。</span>
</div>

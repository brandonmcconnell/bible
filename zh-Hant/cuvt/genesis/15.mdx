## 上帝與亞伯蘭立約

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以賽亞書 41:10; 詩篇 119:114; 詩篇 84:11"> 這事以後，耶和華在異象中有話對亞伯蘭說：「亞伯蘭，你不要懼怕！我是你的盾牌，必大大地賞賜你。」</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 25:21; 使徒行傳 7:5; 創世記 12:1–3"> 亞伯蘭說：「主耶和華啊，我既無子，你還賜我甚麼呢？並且要承受我家業的是大馬士革人以利以謝。」</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 14:14; 箴言 29:21; 傳道書 2:7"> 亞伯蘭又說：「你沒有給我兒子；那生在我家中的人就是我的後嗣。」</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 17:16; 加拉太書 4:28; 撒母耳記下 7:12"> 耶和華又有話對他說：「這人必不成為你的後嗣；你本身所生的才成為你的後嗣。」</span>
<span className="v" id="v5" data-v="5" data-xref="希伯來書 11:12; 羅馬書 4:18; 申命記 1:10"> 於是領他走到外邊，說：「你向天觀看，數算眾星，能數得過來嗎？」又對他說：「你的後裔將要如此。」</span>
<span className="v" id="v6" data-v="6" data-xref="雅各書 2:23; 加拉太書 3:6–14; 羅馬書 4:9"> 亞伯蘭信耶和華，耶和華就以此為他的義。</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 12:1; 使徒行傳 7:2–4; 羅馬書 4:13"> 耶和華又對他說：「我是耶和華，曾領你出了迦勒底的吾珥，為要將這地賜你為業。」</span>
<span className="v" id="v8" data-v="8" data-xref="路加福音 1:18; 路加福音 1:34; 以賽亞書 7:11"> 亞伯蘭說：「主耶和華啊，我怎能知道必得這地為業呢？」</span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 2:24; 利未記 14:30; 利未記 14:22"> 他說：「你為我取一隻三年的母牛，一隻三年的母山羊，一隻三年的公綿羊，一隻斑鳩，一隻雛鴿。」</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米書 34:18–19; 利未記 1:17; 創世記 15:17"> 亞伯蘭就取了這些來，每樣劈開，分成兩半，一半對着一半地擺列，只有鳥沒有劈開。</span>
<span className="v" id="v11" data-v="11" data-xref="馬太福音 13:4; 詩篇 119:13; 以西結書 17:3"> 有鷙鳥下來，落在那死畜的肉上，亞伯蘭就把牠嚇飛了。</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 2:21; 約伯記 33:15; 但以理書 10:8–9"> 日頭正落的時候，亞伯蘭沉沉地睡了；忽然有驚人的大黑暗落在他身上。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行傳 7:6–7; 出埃及記 1:11; 出埃及記 12:40–41"> 耶和華對亞伯蘭說：「你要的確知道，你的後裔必寄居別人的地，又服事那地的人；那地的人要苦待他們四百年。</span>
<span className="v" id="v14" data-v="14" data-xref="尼希米記 9:9–11; 出埃及記 6:5–6; 出埃及記 12:32–38"> 並且他們所要服事的那國，我要懲罰，後來他們必帶着許多財物從那裏出來。</span>
<span className="v" id="v15" data-v="15" data-xref="約伯記 5:26; 創世記 25:7–9; 歷代志下 34:28"> 但你要享大壽數，平平安安地歸到你列祖那裏，被人埋葬。</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀上 21:26; 但以理書 8:23; 出埃及記 12:40"> 到了第四代，他們必回到此地，因為亞摩利人的罪孽還沒有滿盈。」</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米書 34:18–19; 士師記 6:21; 耶利米書 11:4"> 日落天黑，不料有冒煙的爐並燒着的火把從那些肉塊中經過。</span>
<span className="v" id="v18" data-v="18" data-xref="約書亞記 1:3–4; 創世記 12:7; 創世記 24:7"> 當那日，耶和華與亞伯蘭立約，說：「我已賜給你的後裔，從埃及河直到幼發拉底大河之地，</span>
<span className="v" id="v19" data-v="19" data-xref="民數記 24:21–22"> 就是基尼人、基尼洗人、甲摩尼人、</span>
<span className="v" id="v20" data-v="20" data-xref="以賽亞書 17:5; 創世記 14:5"> 赫人、比利洗人、利乏音人、</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 10:15–19; 出埃及記 23:23–28; 申命記 7:1"> 亞摩利人、迦南人、革迦撒人、耶布斯人之地。」</span>

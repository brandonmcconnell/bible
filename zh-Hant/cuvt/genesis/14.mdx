## 亞伯蘭搶救羅得

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 10:10; 創世記 10:22; 以賽亞書 37:12"> 當暗拉非作示拿王，亞略作以拉撒王，基大老瑪作以攔王，提達作戈印王的時候，</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 13:10; 申命記 29:23; 創世記 10:19"> 他們都攻打所多瑪王比拉、蛾摩拉王比沙、押瑪王示納、洗扁王善以別，和比拉王；比拉就是瑣珥。</span>
<span className="v" id="v3" data-v="3" data-xref="約書亞記 3:16; 申命記 3:17; 民數記 34:12"> 這五王都在西訂谷會合；西訂谷就是鹽海。</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 9:25–26; 以西結書 17:15"> 他們已經事奉基大老瑪十二年，到十三年就背叛了。</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 3:11; 創世記 15:20; 申命記 1:4"> 十四年，基大老瑪和同盟的王都來在亞特律‧加寧，殺敗了利乏音人，在哈麥殺敗了蘇西人，在沙微‧基列亭殺敗了以米人，</span>
<span className="v" id="v6" data-v="6" data-xref="申命記 2:22; 申命記 2:12; 創世記 21:21"> 在何利人的西珥山殺敗了何利人，一直殺到靠近曠野的伊勒‧巴蘭。</span>
<span className="v" id="v7" data-v="7" data-xref="歷代志下 20:2; 創世記 16:14; 創世記 20:1"> 他們回到安‧密巴，就是加低斯，殺敗了亞瑪力全地的人，以及住在哈洗遜‧他瑪的亞摩利人。</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 19:22; 創世記 13:10; 創世記 19:20"> 於是所多瑪王、蛾摩拉王、押瑪王、洗扁王，和比拉王（比拉就是瑣珥）都出來，在西訂谷擺陣，與他們交戰，</span>
<span className="v" id="v9" data-v="9"> 就是與以攔王基大老瑪、戈印王提達、示拿王暗拉非、以拉撒王亞略交戰；乃是四王與五王交戰。</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 19:17; 創世記 19:30; 以賽亞書 24:18"> 西訂谷有許多石漆坑。所多瑪王和蛾摩拉王逃跑，有掉在坑裏的，其餘的人都往山上逃跑。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 14:21; 創世記 14:16; 申命記 28:31"> 四王就把所多瑪和蛾摩拉所有的財物，並一切的糧食都擄掠去了；</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 12:5; 創世記 11:27; 啟示錄 3:19"> 又把亞伯蘭的姪兒羅得和羅得的財物擄掠去了。當時羅得正住在所多瑪。</span>
<span className="v" id="v13" data-v="13" data-xref="創世記 13:18; 創世記 14:24; 創世記 40:15"> 有一個逃出來的人告訴希伯來人亞伯蘭；亞伯蘭正住在亞摩利人幔利的橡樹那裏。幔利和以實各並亞乃都是弟兄，曾與亞伯蘭聯盟。</span>
<span className="v" id="v14" data-v="14" data-xref="士師記 18:29; 創世記 15:3; 創世記 17:27"> 亞伯蘭聽見他姪兒<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是弟兄">a</a></sup>被擄去，就率領他家裏生養的精練壯丁三百一十八人，直追到但，</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行傳 9:2; 詩篇 112:5; 列王紀上 15:18"> 便在夜間，自己同僕人分隊殺敗敵人，又追到大馬士革左邊的何把，</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳記上 30:18–19; 撒母耳記上 30:8; 創世記 12:2"> 將被擄掠的一切財物奪回來，連他姪兒羅得和他的財物，以及婦女、人民也都奪回來。</span>
</div>
</div>

## 麥基洗德祝福亞伯蘭

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="撒母耳記下 18:18; 箴言 19:4; 希伯來書 7:1"> 亞伯蘭殺敗基大老瑪和與他同盟的王回來的時候，所多瑪王出來，在沙微谷迎接他；沙微谷就是王谷。</span>
<span className="v" id="v18" data-v="18" data-xref="希伯來書 6:20–3; 詩篇 110:4; 希伯來書 5:6"> 又有撒冷王麥基洗德帶着餅和酒出來迎接；他是至高上帝的祭司。</span>
<span className="v" id="v19" data-v="19" data-xref="希伯來書 7:6–7; 創世記 14:22; 詩篇 24:1"> 他為亞伯蘭祝福，說：「願天地的主、至高的上帝賜福與亞伯蘭！</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 28:22; 希伯來書 7:4–9; 瑪拉基書 3:10"> 至高的上帝把敵人交在你手裏，是應當稱頌的！」亞伯蘭就把所得的拿出十分之一來，給麥基洗德。</span>
<span className="v" id="v21" data-v="21"> 所多瑪王對亞伯蘭說：「你把人口給我，財物你自己拿去吧！」</span>
<span className="v" id="v22" data-v="22" data-xref="但以理書 12:7; 但以理書 4:34; 申命記 32:40"> 亞伯蘭對所多瑪王說：「我已經向天地的主－至高的上帝耶和華起誓：</span>
<span className="v" id="v23" data-v="23" data-xref="列王紀下 5:16; 哥林多後書 11:9–12; 以斯帖記 9:15–16"> 凡是你的東西，就是一根線、一根鞋帶，我都不拿，免得你說：『我使亞伯蘭富足！』</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 14:13; 箴言 3:27; 馬太福音 7:12"> 只有僕人所吃的，並與我同行的亞乃、以實各、幔利所應得的分，可以任憑他們拿去。」</span>
</div>

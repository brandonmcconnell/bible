## 上帝的創造

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="約翰福音 1:1–3; 希伯來書 11:3; 以賽亞書 45:18"> 起初，上帝創造天地。</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米書 4:23; 詩篇 104:30; 以賽亞書 45:18"> 地是空虛混沌，淵面黑暗；上帝的靈運行在水面上。</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多後書 4:6; 約翰福音 1:5; 以賽亞書 45:7"> 上帝說：「要有光」，就有了光。</span>
<span className="v" id="v4" data-v="4" data-xref="傳道書 2:13; 創世記 1:18; 傳道書 11:7"> 上帝看光是好的，就把光暗分開了。</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 74:16; 以賽亞書 45:7; 帖撒羅尼迦前書 5:5"> 上帝稱光為「晝」，稱暗為「夜」。有晚上，有早晨，這是頭一日。</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米書 51:15; 詩篇 33:6; 約伯記 37:18"> 上帝說：「諸水之間要有空氣，將水分為上下。」</span>
<span className="v" id="v7" data-v="7" data-xref="箴言 8:28–29; 詩篇 148:4; 馬太福音 8:27"> 上帝就造出空氣，將空氣以下的水、空氣以上的水分開了。事就這樣成了。</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 1:5; 創世記 1:19; 創世記 1:10"> 上帝稱空氣為「天」。有晚上，有早晨，是第二日。</span>
<span className="v" id="v9" data-v="9" data-xref="彼得後書 3:5; 約拿書 1:9; 耶利米書 5:22"> 上帝說：「天下的水要聚在一處，使旱地露出來。」事就這樣成了。</span>
<span className="v" id="v10" data-v="10" data-xref="申命記 32:4; 詩篇 104:31; 創世記 1:4"> 上帝稱旱地為「地」，稱水的聚處為「海」。上帝看着是好的。</span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 104:14–17; 希伯來書 6:7; 詩篇 147:8"> 上帝說：「地要發生青草和結種子的菜蔬，並結果子的樹木，各從其類，果子都包着核。」事就這樣成了。</span>
<span className="v" id="v12" data-v="12" data-xref="馬可福音 4:28; 以賽亞書 55:10–11; 馬太福音 13:24–26"> 於是地發生了青草和結種子的菜蔬，各從其類；並結果子的樹木，各從其類；果子都包着核。上帝看着是好的。</span>
<span className="v" id="v13" data-v="13"> 有晚上，有早晨，是第三日。</span>
<span className="v" id="v14" data-v="14" data-xref="詩篇 104:19–20; 申命記 4:19; 耶利米書 31:35"> 上帝說：「天上要有光體，可以分晝夜，作記號，定節令、日子、年歲，</span>
<span className="v" id="v15" data-v="15"> 並要發光在天空，普照在地上。」事就這樣成了。</span>
<span className="v" id="v16" data-v="16" data-xref="詩篇 136:7–9; 申命記 4:19; 詩篇 8:3"> 於是上帝造了兩個大光，大的管晝，小的管夜，又造眾星，</span>
<span className="v" id="v17" data-v="17" data-xref="詩篇 8:3; 詩篇 8:1; 約伯記 38:12"> 就把這些光擺列在天空，普照在地上，</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米書 31:35; 詩篇 19:6"> 管理晝夜，分別明暗。上帝看着是好的。</span>
<span className="v" id="v19" data-v="19"> 有晚上，有早晨，是第四日。</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 2:19; 詩篇 104:24–25; 列王紀上 4:33"> 上帝說：「水要多多滋生有生命的物；要有雀鳥飛在地面以上，天空之中。」</span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 104:24–26; 創世記 1:25; 創世記 8:19"> 上帝就造出大魚和水中所滋生各樣有生命的動物，各從其類；又造出各樣飛鳥，各從其類。上帝看着是好的。</span>
<span className="v" id="v22" data-v="22" data-xref="約伯記 40:15; 創世記 8:17; 詩篇 107:38"> 上帝就賜福給這一切，說：「滋生繁多，充滿海中的水；雀鳥也要多生在地上。」</span>
<span className="v" id="v23" data-v="23"> 有晚上，有早晨，是第五日。</span>
<span className="v" id="v24" data-v="24" data-xref="詩篇 50:9–10; 創世記 6:20; 創世記 8:19"> 上帝說：「地要生出活物來，各從其類；牲畜、昆蟲、野獸，各從其類。」事就這樣成了。</span>
<span className="v" id="v25" data-v="25" data-xref="耶利米書 27:5; 約伯記 12:8–10; 創世記 2:19–20"> 於是上帝造出野獸，各從其類；牲畜，各從其類；地上一切昆蟲，各從其類。上帝看着是好的。</span>
<span className="v" id="v26" data-v="26" data-xref="歌羅西書 3:10; 以弗所書 4:24; 詩篇 8:4–8"> 上帝說：「我們要照着我們的形像、按着我們的樣式造人，使他們管理海裏的魚、空中的鳥、地上的牲畜，和全地，並地上所爬的一切昆蟲。」</span>
<span className="v" id="v27" data-v="27" data-xref="馬太福音 19:4; 以弗所書 2:10; 創世記 5:1–2"> 上帝就照着自己的形像造人，乃是照着他的形像造男造女。</span>
<span className="v" id="v28" data-v="28" data-xref="創世記 9:1; 創世記 9:7; 利未記 26:9"> 上帝就賜福給他們，又對他們說：「要生養眾多，遍滿地面，治理這地，也要管理海裏的魚、空中的鳥，和地上各樣行動的活物。」</span>
<span className="v" id="v29" data-v="29" data-xref="創世記 9:3; 詩篇 104:14–15; 詩篇 145:15–16"> 上帝說：「看哪，我將遍地上一切結種子的菜蔬和一切樹上所結有核的果子全賜給你們作食物。</span>
<span className="v" id="v30" data-v="30" data-xref="詩篇 104:14; 詩篇 145:15–16; 詩篇 147:9"> 至於地上的走獸和空中的飛鳥，並各樣爬在地上有生命的物，我將青草賜給牠們作食物。」事就這樣成了。</span>
<span className="v" id="v31" data-v="31" data-xref="提摩太前書 4:4; 詩篇 104:24; 詩篇 19:1–2"> 上帝看着一切所造的都甚好。有晚上，有早晨，是第六日。</span>

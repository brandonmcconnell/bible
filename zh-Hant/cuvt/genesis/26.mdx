## 以撒住在基拉耳

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 12:10; 創世記 25:11; 創世記 21:22–32"> 在亞伯拉罕的日子，那地有一次饑荒；這時又有饑荒，以撒就往基拉耳去，到非利士人的王亞比米勒那裏。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 12:7; 詩篇 37:3; 創世記 17:1"> 耶和華向以撒顯現，說：「你不要下埃及去，要住在我所指示你的地。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 28:15; 詩篇 105:9; 創世記 17:8"> 你寄居在這地，我必與你同在，賜福給你，因為我要將這些地都賜給你和你的後裔。我必堅定我向你父亞伯拉罕所起的誓。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行傳 3:25; 創世記 15:5; 創世記 22:17–18"> 我要加增你的後裔，像天上的星那樣多，又要將這些地都賜給你的後裔。並且地上萬國必因你的後裔得福－</span>
<span className="v" id="v5" data-v="5" data-xref="馬太福音 7:24; 創世記 22:18; 創世記 22:16"> 都因亞伯拉罕聽從我的話，遵守我的吩咐和我的命令、律例、法度。」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="創世記 20:1"> 以撒就住在基拉耳。</span>
<span className="v" id="v7" data-v="7" data-xref="箴言 29:25; 創世記 12:13; 創世記 20:2"> 那地方的人問到他的妻子，他便說：「那是我的妹子。」原來他怕說：「是我的妻子」；他心裏想：「恐怕這地方的人為利百加的緣故殺我」，因為她容貌俊美。</span>
<span className="v" id="v8" data-v="8" data-xref="以賽亞書 62:5; 箴言 5:18–19; 箴言 7:6"> 他在那裏住了許久。有一天，非利士人的王亞比米勒從窗戶裏往外觀看，見以撒和他的妻子利百加戲玩。</span>
<span className="v" id="v9" data-v="9"> 亞比米勒召了以撒來，對他說：「她實在是你的妻子，你怎麼說她是你的妹子？」以撒說：「我心裏想，恐怕我因她而死。」</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 20:9–10; 創世記 12:18–19"> 亞比米勒說：「你向我們做的是甚麼事呢？民中險些有人和你的妻同寢，把我們陷在罪裏。」</span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 105:15; 創世記 20:6; 箴言 6:29"> 於是亞比米勒曉諭眾民說：「凡沾着這個人，或是他妻子的，定要把他治死。」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="馬可福音 4:8; 創世記 24:1; 創世記 26:3"> 以撒在那地耕種，那一年有百倍的收成。耶和華賜福給他，</span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 112:3; 箴言 10:22; 創世記 24:35"> 他就昌大，日增月盛，成了大富戶。</span>
<span className="v" id="v14" data-v="14" data-xref="創世記 37:11; 創世記 13:2; 箴言 27:4"> 他有羊群牛群，又有許多僕人，非利士人就嫉妒他。</span>
<span className="v" id="v15" data-v="15" data-xref="創世記 21:30; 創世記 21:25"> 當他父親亞伯拉罕在世的日子，他父親的僕人所挖的井，非利士人全都塞住，填滿了土。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 1:9"> 亞比米勒對以撒說：「你離開我們去吧。因為你比我們強盛得多。」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17"> 以撒就離開那裏，在基拉耳谷支搭帳棚，住在那裏。</span>
<span className="v" id="v18" data-v="18" data-xref="撒迦利亞書 13:2; 何西阿書 2:17; 民數記 32:38"> 當他父親亞伯拉罕在世之日所挖的水井因非利士人在亞伯拉罕死後塞住了，以撒就重新挖出來，仍照他父親所叫的叫那些井的名字。</span>
<span className="v" id="v19" data-v="19" data-xref="約翰福音 4:10–11; 約翰福音 7:38; 雅歌 4:15"> 以撒的僕人在谷中挖井，便得了一口活水井。</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 21:25"> 基拉耳的牧人與以撒的牧人爭競，說：「這水是我們的。」以撒就給那井起名叫埃色<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="就是相敵的意思">a</a></sup>，因為他們和他相爭。</span>
<span className="v" id="v21" data-v="21" data-xref="以斯拉記 4:6"> 以撒的僕人又挖了一口井，他們又為這井爭競，因此以撒給這井起名叫西提拿<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="就是為敵的意思">b</a></sup>。</span>
<span className="v" id="v22" data-v="22" data-xref="創世記 17:6; 出埃及記 1:7; 詩篇 118:5"> 以撒離開那裏，又挖了一口井，他們不為這井爭競了，他就給那井起名叫利河伯<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="就是寬闊的意思">c</a></sup>。他說：「耶和華現在給我們寬闊之地，我們必在這地昌盛。」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="士師記 20:1; 創世記 21:31; 創世記 46:1"> 以撒從那裏上別是巴去。</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 15:1; 出埃及記 3:6; 以賽亞書 43:1–2"> 當夜耶和華向他顯現，說：「我是你父親亞伯拉罕的上帝，不要懼怕！因為我與你同在，要賜福給你，並要為我僕人亞伯拉罕的緣故，使你的後裔繁多。」</span>
<span className="v" id="v25" data-v="25" data-xref="創世記 13:18; 詩篇 116:17; 創世記 12:7–8"> 以撒就在那裏築了一座壇，求告耶和華的名，並且支搭帳棚；他的僕人便在那裏挖了一口井。</span>
</div>
</div>

## 以撒跟亞比米勒立約

<div className="bt">
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="創世記 21:22–32; 創世記 20:3"> 亞比米勒，同他的朋友亞戶撒和他的軍長非各，從基拉耳來見以撒。</span>
<span className="v" id="v27" data-v="27" data-xref="創世記 26:16; 士師記 11:7; 使徒行傳 7:14"> 以撒對他們說：「你們既然恨我，打發我走了，為甚麼到我這裏來呢？」</span>
<span className="v" id="v28" data-v="28" data-xref="創世記 21:22–23; 以賽亞書 45:14; 以賽亞書 61:9"> 他們說：「我們明明地看見耶和華與你同在，便說，不如我們兩下彼此起誓，彼此立約，</span>
<span className="v" id="v29" data-v="29" data-xref="創世記 24:31; 創世記 21:22; 創世記 22:17"> 使你不害我們，正如我們未曾害你，一味地厚待你，並且打發你平平安安地走。你是蒙耶和華賜福的了。」</span>
<span className="v" id="v30" data-v="30" data-xref="創世記 19:3; 羅馬書 12:18; 希伯來書 12:14"> 以撒就為他們設擺筵席，他們便吃了喝了。</span>
<span className="v" id="v31" data-v="31" data-xref="撒母耳記上 20:16–17; 希伯來書 6:16; 創世記 25:33"> 他們清早起來彼此起誓。以撒打發他們走，他們就平平安安地離開他走了。</span>
<span className="v" id="v32" data-v="32" data-xref="箴言 10:4; 箴言 13:4; 箴言 2:4–5"> 那一天，以撒的僕人來，將挖井的事告訴他說：「我們得了水了。」</span>
<span className="v" id="v33" data-v="33" data-xref="創世記 21:31; 創世記 26:28"> 他就給那井起名叫示巴；因此那城叫做別是巴，直到今日。</span>
</div>
</div>

## 以掃的外族妻子

<div className="bt">
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="創世記 36:2; 創世記 36:13; 出埃及記 34:16"> 以掃四十歲的時候娶了赫人比利的女兒猶滴，與赫人以倫的女兒巴實抹為妻。</span>
<span className="v" id="v35" data-v="35" data-xref="創世記 27:46–2; 創世記 28:8; 創世記 6:2"> 她們常使以撒和利百加心裏愁煩。</span>
</div>

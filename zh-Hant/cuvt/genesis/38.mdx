## 猶大和她瑪

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳記上 22:1; 列王紀下 4:8; 箴言 13:20"> 那時，猶大離開他弟兄下去，到一個亞杜蘭人名叫希拉的家裏去。</span>
<span className="v" id="v2" data-v="2" data-xref="歷代志上 2:3; 創世記 24:3; 創世記 6:2"> 猶大在那裏看見一個迦南人名叫書亞的女兒，就娶她為妻，與她同房，</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 46:12; 民數記 26:19"> 她就懷孕生了兒子，猶大給他起名叫珥。</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 46:12; 民數記 26:19"> 她又懷孕生了兒子，母親給他起名叫俄南。</span>
<span className="v" id="v5" data-v="5" data-xref="民數記 26:20; 創世記 38:26; 創世記 46:12"> 她復又生了兒子，給他起名叫示拉。她生示拉的時候，猶大正在基悉。</span>
<span className="v" id="v6" data-v="6" data-xref="創世記 24:3; 創世記 21:21; 馬太福音 1:3"> 猶大為長子珥娶妻，名叫她瑪。</span>
<span className="v" id="v7" data-v="7" data-xref="歷代志上 2:3; 創世記 46:12; 民數記 26:19"> 猶大的長子珥在耶和華眼中看為惡，耶和華就叫他死了。</span>
<span className="v" id="v8" data-v="8" data-xref="申命記 25:5–10; 馬太福音 22:23–27; 路得記 4:5–11"> 猶大對俄南說：「你當與你哥哥的妻子同房，向她盡你為弟的本分，為你哥哥生子立後。」</span>
<span className="v" id="v9" data-v="9" data-xref="提多書 3:3; 申命記 25:6; 雅各書 3:16"> 俄南知道生子不歸自己，所以同房的時候便遺在地，免得給他哥哥留後。</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 46:12; 民數記 11:1; 歷代志上 21:7"> 俄南所做的在耶和華眼中看為惡，耶和華也就叫他死了。</span>
<span className="v" id="v11" data-v="11" data-xref="利未記 22:13; 路得記 1:11–13"> 猶大心裏說：「恐怕示拉也死，像他兩個哥哥一樣」，就對他兒婦她瑪說：「你去，在你父親家裏守寡，等我兒子示拉長大。」她瑪就回去，住在她父親家裏。</span>
<span className="v" id="v12" data-v="12" data-xref="約書亞記 15:10; 撒母耳記下 13:39; 士師記 14:1"> 過了許久，猶大的妻子書亞的女兒死了。猶大得了安慰，就和他朋友亞杜蘭人希拉上亭拿去，到他剪羊毛的人那裏。</span>
<span className="v" id="v13" data-v="13"> 有人告訴她瑪說：「你的公公上亭拿剪羊毛去了。」</span>
<span className="v" id="v14" data-v="14" data-xref="創世記 38:26; 創世記 38:11–13; 耶利米書 3:2"> 她瑪見示拉已經長大，還沒有娶她為妻，就脫了她作寡婦的衣裳，用帕子蒙着臉，又遮住身體，坐在亭拿路上的伊拿印城門口。</span>
<span className="v" id="v15" data-v="15"> 猶大看見她，以為是妓女，因為她蒙着臉。</span>
<span className="v" id="v16" data-v="16" data-xref="提摩太前書 6:10; 馬太福音 26:15; 撒母耳記下 13:11"> 猶大就轉到她那裏去，說：「來吧！讓我與你同寢。」他原不知道是他的兒婦。她瑪說：「你要與我同寢，把甚麼給我呢？」</span>
<span className="v" id="v17" data-v="17" data-xref="以西結書 16:33; 創世記 38:20; 箴言 20:16"> 猶大說：「我從羊群裏取一隻山羊羔，打發人送來給你。」她瑪說：「在未送以先，你願意給我一個當頭嗎？」</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 38:25–26; 何西阿書 4:11; 耶利米書 22:24"> 他說：「我給你甚麼當頭呢？」她瑪說：「你的印、你的帶子，和你手裏的杖。」猶大就給了她，與她同寢，她就從猶大懷了孕。</span>
<span className="v" id="v19" data-v="19" data-xref="創世記 38:14; 撒母耳記下 14:5; 撒母耳記下 14:2"> 她瑪起來走了，除去帕子，仍舊穿上作寡婦的衣裳。</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 20:9; 利未記 19:17; 撒母耳記下 13:3"> 猶大託他朋友亞杜蘭人送一隻山羊羔去，要從那女人手裏取回當頭來，卻找不着她，</span>
<span className="v" id="v21" data-v="21"> 就問那地方的人說：「伊拿印路旁的妓女在哪裏？」他們說：「這裏並沒有妓女。」</span>
<span className="v" id="v22" data-v="22"> 他回去見猶大說：「我沒有找着她，並且那地方的人說：『這裏沒有妓女。』」</span>
<span className="v" id="v23" data-v="23" data-xref="以弗所書 5:12; 箴言 6:33; 啟示錄 16:15"> 猶大說：「我把這山羊羔送去了，你竟找不着她。任憑她拿去吧，免得我們被羞辱。」</span>
<span className="v" id="v24" data-v="24" data-xref="利未記 21:9; 以西結書 23:19; 士師記 19:2"> 約過了三個月，有人告訴猶大說：「你的兒婦她瑪作了妓女，且因行淫有了身孕。」猶大說：「拉出她來，把她燒了！」</span>
<span className="v" id="v25" data-v="25" data-xref="創世記 37:32; 創世記 38:18; 哥林多前書 4:5"> 她瑪被拉出來的時候便打發人去見她公公，對他說：「這些東西是誰的，我就是從誰懷的孕。請你認一認，這印和帶子並杖都是誰的？」</span>
<span className="v" id="v26" data-v="26" data-xref="撒母耳記上 24:17; 約翰福音 8:9; 提多書 2:11–12"> 猶大承認說：「她比我更有義，因為我沒有將她給我的兒子示拉。」從此猶大不再與她同寢了。</span>
<span className="v" id="v27" data-v="27" data-xref="創世記 25:24"> 她瑪將要生產，不料她腹裏是一對雙生。</span>
<span className="v" id="v28" data-v="28"> 到生產的時候，一個孩子伸出一隻手來；收生婆拿紅線拴在他手上，說：「這是頭生的。」</span>
<span className="v" id="v29" data-v="29" data-xref="歷代志上 2:4; 馬太福音 1:3; 創世記 46:12"> 隨後這孩子把手收回去，他哥哥生出來了；收生婆說：「你為甚麼搶着來呢？」因此給他起名叫法勒斯。</span>
<span className="v" id="v30" data-v="30" data-xref="歷代志上 9:6; 歷代志上 2:4; 馬太福音 1:3"> 後來，他兄弟那手上有紅線的也生出來，就給他起名叫謝拉。</span>

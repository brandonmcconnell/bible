## 洪水消退

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 30:22; 創世記 19:29; 詩篇 136:23"> 上帝記念挪亞和挪亞方舟裏的一切走獸牲畜。上帝叫風吹地，水勢漸落。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 7:11; 馬太福音 8:26–27; 箴言 8:28"> 淵源和天上的窗戶都閉塞了，天上的大雨也止住了。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 7:24; 創世記 7:11"> 水從地上漸退。過了一百五十天，水就漸消。</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀下 19:37; 耶利米書 51:27; 以賽亞書 37:38"> 七月十七日，方舟停在亞拉臘山上。</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 7:11"> 水又漸消，到十月初一日，山頂都現出來了。</span>
<span className="v" id="v6" data-v="6" data-xref="創世記 6:16; 但以理書 6:10"> 過了四十天，挪亞開了方舟的窗戶，</span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 147:9; 列王紀上 17:6; 列王紀上 17:4"> 放出一隻烏鴉去；那烏鴉飛來飛去，直到地上的水都乾了。</span>
<span className="v" id="v8" data-v="8" data-xref="雅歌 2:14; 雅歌 1:15; 馬太福音 10:16"> 他又放出一隻鴿子去，要看看水從地上退了沒有。</span>
<span className="v" id="v9" data-v="9" data-xref="馬太福音 11:28; 詩篇 116:7; 申命記 28:65"> 但遍地上都是水，鴿子找不着落腳之地，就回到方舟挪亞那裏，挪亞伸手把鴿子接進方舟來。</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 7:4; 創世記 7:10; 創世記 8:12"> 他又等了七天，再把鴿子從方舟放出去。</span>
<span className="v" id="v11" data-v="11" data-xref="尼希米記 8:15; 撒迦利亞書 4:12–14; 羅馬書 10:15"> 到了晚上，鴿子回到他那裏，嘴裏叼着一個新擰下來的橄欖葉子，挪亞就知道地上的水退了。</span>
<span className="v" id="v12" data-v="12" data-xref="以賽亞書 25:9; 以賽亞書 30:18; 創世記 8:10"> 他又等了七天，放出鴿子去，鴿子就不再回來了。</span>
<span className="v" id="v13" data-v="13" data-xref="創世記 7:11"> 到挪亞六百零一歲，正月初一日，地上的水都乾了。挪亞撤去方舟的蓋觀看，便見地面上乾了。</span>
<span className="v" id="v14" data-v="14" data-xref="創世記 7:13–14; 創世記 7:11"> 到了二月二十七日，地就都乾了。</span>
<span className="v" id="v15" data-v="15"> 上帝對挪亞說：</span>
<span className="v" id="v16" data-v="16" data-xref="創世記 7:13; 詩篇 121:8; 詩篇 91:11"> 「你和你的妻子、兒子、兒婦都可以出方舟。</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 1:22; 創世記 9:1; 耶利米書 31:27–28"> 在你那裏凡有血肉的活物，就是飛鳥、牲畜，和一切爬在地上的昆蟲，都要帶出來，叫牠在地上多多滋生，大大興旺。」</span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 121:8"> 於是挪亞和他的妻子、兒子、兒婦都出來了。</span>
<span className="v" id="v19" data-v="19"> 一切走獸、昆蟲、飛鳥，和地上所有的動物，各從其類，也都出了方舟。</span>
</div>
</div>

## 挪亞獻祭

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="希伯來書 13:15–16; 羅馬書 12:1; 創世記 22:9"> 挪亞為耶和華築了一座壇，拿各類潔淨的牲畜、飛鳥獻在壇上為燔祭。</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多後書 2:15; 以弗所書 5:2; 以賽亞書 54:9–10"> 耶和華聞那馨香之氣，就心裏說：「我不再因人的緣故咒詛地（人從小時心裏懷着惡念），也不再按着我才行的滅各種的活物了。</span>
<span className="v" id="v22" data-v="22" data-xref="雅各書 5:7; 詩篇 74:16–17; 耶利米書 5:24"> 地還存留的時候，稼穡、寒暑、冬夏、晝夜就永不停息了。」</span>
</div>

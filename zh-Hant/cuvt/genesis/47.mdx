<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 45:10; 創世記 46:31; 創世記 46:28"> 約瑟進去告訴法老說：「我的父親和我的弟兄帶着羊群牛群，並一切所有的，從迦南地來了，如今在歌珊地。」</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行傳 7:13; 歌羅西書 1:28; 猶大書 1:24"> 約瑟從他弟兄中挑出五個人來，引他們去見法老。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 46:33–34; 帖撒羅尼迦後書 3:10; 創世記 4:2"> 法老問約瑟的弟兄說：「你們以何事為業？」他們對法老說：「你僕人是牧羊的，連我們的祖宗也是牧羊的。」</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 46:34; 創世記 15:13; 申命記 26:5"> 他們又對法老說：「迦南地的饑荒甚大，僕人的羊群沒有草吃，所以我們來到這地寄居。現在求你容僕人住在歌珊地。」</span>
<span className="v" id="v5" data-v="5"> 法老對約瑟說：「你父親和你弟兄到你這裏來了，</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及記 18:21; 箴言 22:29; 創世記 47:11"> 埃及地都在你面前，只管叫你父親和你弟兄住在國中最好的地；他們可以住在歌珊地。你若知道他們中間有甚麼能人，就派他們看管我的牲畜。」</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 47:10; 撒母耳記下 8:10; 撒母耳記上 2:20"> 約瑟領他父親雅各進到法老面前，雅各就給法老祝福。</span>
<span className="v" id="v8" data-v="8"> 法老問雅各說：「你平生的年日是多少呢？」</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 39:12; 詩篇 39:5; 約伯記 14:1"> 雅各對法老說：「我寄居在世的年日是一百三十歲，我平生的年日又少又苦，不及我列祖在世寄居的年日。」</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 47:7; 詩篇 129:8; 希伯來書 7:7"> 雅各又給法老祝福，就從法老面前出去了。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 47:6; 出埃及記 1:11; 出埃及記 12:37"> 約瑟遵着法老的命，把埃及國最好的地，就是蘭塞境內的地，給他父親和弟兄居住，作為產業。</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 45:11; 提摩太前書 5:8; 創世記 47:1"> 約瑟用糧食奉養他父親和他弟兄，並他父親全家的眷屬，都是照各家的人口奉養他們。</span>

## 饑荒

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="使徒行傳 7:11; 列王紀上 18:5; 耶利米哀歌 4:9"> 饑荒甚大，全地都絕了糧，甚至埃及地和迦南地的人因那饑荒的緣故都餓昏了。</span>
<span className="v" id="v14" data-v="14" data-xref="創世記 41:56; 路加福音 16:10–12; 路加福音 16:1–2"> 約瑟收聚了埃及地和迦南地所有的銀子，就是眾人糴糧的銀子，約瑟就把那銀子帶到法老的宮裏。</span>
<span className="v" id="v15" data-v="15" data-xref="士師記 8:8; 詩篇 37:3; 馬太福音 6:11"> 埃及地和迦南地的銀子都花盡了，埃及眾人都來見約瑟，說：「我們的銀子都用盡了，求你給我們糧食，我們為甚麼死在你面前呢？」</span>
<span className="v" id="v16" data-v="16" data-xref="歌羅西書 4:5; 但以理書 6:5–7; 哥林多前書 10:32"> 約瑟說：「若是銀子用盡了，可以把你們的牲畜給我，我就為你們的牲畜給你們糧食。」</span>
<span className="v" id="v17" data-v="17" data-xref="約伯記 2:4; 出埃及記 9:3; 以賽亞書 31:1"> 於是他們把牲畜趕到約瑟那裏，約瑟就拿糧食換了他們的牛、羊、驢、馬；那一年因換他們一切的牲畜，就用糧食養活他們。</span>
<span className="v" id="v18" data-v="18" data-xref="列王紀下 6:26; 耶利米書 38:9"> 那一年過去，第二年他們又來見約瑟，說：「我們不瞞我主，我們的銀子都花盡了，牲畜也都歸了我主。我們在我主眼前，除了我們的身體和田地之外，一無所剩。</span>
<span className="v" id="v19" data-v="19" data-xref="尼希米記 5:2–3; 約伯記 2:4; 耶利米哀歌 1:11"> 你何忍見我們人死地荒呢？求你用糧食買我們和我們的地，我們和我們的地就要給法老效力。又求你給我們種子，使我們得以存活，不致死亡，地土也不致荒涼。」</span>
<span className="v" id="v20" data-v="20"> 於是，約瑟為法老買了埃及所有的地，埃及人因被饑荒所迫，各都賣了自己的田地；那地就都歸了法老。</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 41:48"> 至於百姓，約瑟叫他們，從埃及這邊直到埃及那邊，都各歸各城。</span>
<span className="v" id="v22" data-v="22" data-xref="以斯拉記 7:24; 尼希米記 13:10; 帖撒羅尼迦後書 3:10"> 惟有祭司的地，約瑟沒有買，因為祭司有從法老所得的常俸。他們吃法老所給的常俸，所以他們不賣自己的地。</span>
<span className="v" id="v23" data-v="23" data-xref="詩篇 112:5; 詩篇 41:1; 傳道書 11:6"> 約瑟對百姓說：「我今日為法老買了你們和你們的地，看哪，這裏有種子給你們，你們可以種地。</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 41:34; 詩篇 41:1; 詩篇 112:5"> 後來打糧食的時候，你們要把五分之一納給法老，四分可以歸你們做地裏的種子，也做你們和你們家口孩童的食物。」</span>
<span className="v" id="v25" data-v="25" data-xref="創世記 33:15; 箴言 11:26–27; 創世記 18:3"> 他們說：「你救了我們的性命。但願我們在我主眼前蒙恩，我們就作法老的僕人。」</span>
<span className="v" id="v26" data-v="26" data-xref="創世記 47:22; 以西結書 7:24"> 於是約瑟為埃及地定下常例，直到今日：法老必得五分之一，惟獨祭司的地不歸法老。</span>
</div>
</div>

## 雅各最後的吩咐

<div className="bt">
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="創世記 46:3; 出埃及記 1:7; 使徒行傳 7:17"> 以色列人住在埃及的歌珊地。他們在那裏置了產業，並且生育甚多。</span>
<span className="v" id="v28" data-v="28" data-xref="詩篇 90:10; 創世記 47:8–9; 創世記 37:2"> 雅各住在埃及地十七年，雅各平生的年日是一百四十七歲。</span>
<span className="v" id="v29" data-v="29" data-xref="申命記 31:14; 創世記 24:49; 創世記 24:2"> 以色列的死期臨近了，他就叫了他兒子約瑟來，說：「我若在你眼前蒙恩，請你把手放在我大腿底下，用慈愛和誠實待我，請你不要將我葬在埃及。</span>
<span className="v" id="v30" data-v="30" data-xref="創世記 49:29–32; 創世記 23:19; 創世記 25:9"> 我與我祖我父同睡的時候，你要將我帶出埃及，葬在他們所葬的地方。」約瑟說：「我必遵着你的命而行。」</span>
<span className="v" id="v31" data-v="31" data-xref="列王紀上 1:47; 希伯來書 11:21; 創世記 24:3"> 雅各說：「你要向我起誓。」約瑟就向他起了誓，於是以色列在床頭上<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或譯：扶着杖頭">a</a></sup>敬拜上帝。</span>

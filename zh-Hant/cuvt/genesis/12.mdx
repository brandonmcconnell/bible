## 上帝呼召亞伯蘭

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="希伯來書 11:8; 尼希米記 9:7; 使徒行傳 7:2–6"> 耶和華對亞伯蘭說：「你要離開本地、本族、父家，往我所要指示你的地去。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳記下 7:9; 創世記 18:18; 加拉太書 3:14"> 我必叫你成為大國。我必賜福給你，叫你的名為大；你也要叫別人得福。</span>
<span className="v" id="v3" data-v="3" data-xref="加拉太書 3:8; 創世記 22:18; 創世記 27:29"> 為你祝福的，我必賜福與他；那咒詛你的，我必咒詛他。地上的萬族都要因你得福。」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="希伯來書 11:8; 創世記 11:31; 創世記 11:27"> 亞伯蘭就照着耶和華的吩咐去了；羅得也和他同去。亞伯蘭出哈蘭的時候年七十五歲。</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 14:14; 創世記 11:31; 希伯來書 11:8–9"> 亞伯蘭將他妻子撒萊和姪兒羅得，連他們在哈蘭所積蓄的財物、所得的人口，都帶往迦南地去。他們就到了迦南地。</span>
<span className="v" id="v6" data-v="6" data-xref="希伯來書 11:9; 申命記 11:30; 創世記 35:4"> 亞伯蘭經過那地，到了示劍地方、摩利橡樹那裏。那時迦南人住在那地。</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 17:8; 創世記 18:1; 創世記 13:15"> 耶和華向亞伯蘭顯現，說：「我要把這地賜給你的後裔。」亞伯蘭就在那裏為向他顯現的耶和華築了一座壇。</span>
<span className="v" id="v8" data-v="8" data-xref="尼希米記 11:31; 創世記 4:26; 創世記 21:33"> 從那裏他又遷到伯特利東邊的山，支搭帳棚；西邊是伯特利，東邊是艾。他在那裏又為耶和華築了一座壇，求告耶和華的名。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 13:3; 創世記 24:62; 創世記 13:1"> 後來亞伯蘭又漸漸遷往南地去。</span>
</div>
</div>

## 亞伯蘭到埃及

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="創世記 43:1; 創世記 26:1–3; 列王紀上 17:1–18"> 那地遭遇饑荒。因饑荒甚大，亞伯蘭就下埃及去，要在那裏暫居。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 26:7; 創世記 29:17; 創世記 12:14"> 將近埃及，就對他妻子撒萊說：「我知道你是容貌俊美的婦人。</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 20:11; 創世記 26:7; 約翰一書 1:8–10"> 埃及人看見你必說：『這是他的妻子』，他們就要殺我，卻叫你存活。</span>
<span className="v" id="v13" data-v="13" data-xref="創世記 26:7; 創世記 20:12–13; 創世記 20:2"> 求你說，你是我的妹子，使我因你得平安，我的命也因你存活。」</span>
<span className="v" id="v14" data-v="14" data-xref="創世記 6:2; 馬太福音 5:28; 創世記 39:7"> 及至亞伯蘭到了埃及，埃及人看見那婦人極其美貌。</span>
<span className="v" id="v15" data-v="15" data-xref="創世記 20:2; 創世記 41:1; 列王紀下 18:21"> 法老的臣宰看見了她，就在法老面前誇獎她。那婦人就被帶進法老的宮去。</span>
<span className="v" id="v16" data-v="16" data-xref="創世記 20:14; 創世記 13:2; 創世記 24:35"> 法老因這婦人就厚待亞伯蘭，亞伯蘭得了許多牛、羊、駱駝、公驢、母驢、僕婢。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="歷代志上 16:21; 創世記 20:18; 詩篇 105:14–15"> 耶和華因亞伯蘭妻子撒萊的緣故，降大災與法老和他的全家。</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 20:9–10; 創世記 26:9–11; 撒母耳記上 14:43"> 法老就召了亞伯蘭來，說：「你這向我做的是甚麼事呢？為甚麼沒有告訴我她是你的妻子？</span>
<span className="v" id="v19" data-v="19"> 為甚麼說她是你的妹子，以致我把她取來要作我的妻子？現在你的妻子在這裏，可以帶她走吧。」</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 105:14–15; 箴言 21:1; 出埃及記 18:27"> 於是法老吩咐人將亞伯蘭和他妻子，並他所有的都送走了。</span>
</div>
</div>

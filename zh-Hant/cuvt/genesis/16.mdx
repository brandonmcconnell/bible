## 夏甲和以實瑪利

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="加拉太書 4:24; 創世記 12:16; 創世記 15:2–3"> 亞伯蘭的妻子撒萊不給他生兒女。撒萊有一個使女，名叫夏甲，是埃及人。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 21:4; 創世記 18:10; 創世記 3:17"> 撒萊對亞伯蘭說：「耶和華使我不能生育。求你和我的使女同房，或者我可以因她得孩子<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="得孩子：原文是被建立">a</a></sup>。」亞伯蘭聽從了撒萊的話。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 16:5; 創世記 12:4–5; 撒母耳記下 5:13"> 於是亞伯蘭的妻子撒萊將使女埃及人夏甲給了丈夫為妾；那時亞伯蘭在迦南已經住了十年。</span>
<span className="v" id="v4" data-v="4" data-xref="箴言 30:23; 撒母耳記下 6:16; 哥林多前書 13:4–5"> 亞伯蘭與夏甲同房，夏甲就懷了孕；她見自己有孕，就小看她的主母。</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 31:53; 出埃及記 5:21; 詩篇 7:8"> 撒萊對亞伯蘭說：「我因你受屈。我將我的使女放在你懷中，她見自己有了孕，就小看我。願耶和華在你我中間判斷。」</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米書 38:5; 箴言 14:29; 彼得前書 3:7"> 亞伯蘭對撒萊說：「使女在你手下，你可以隨意待她。」撒萊苦待她，她就從撒萊面前逃走了。</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 25:18; 出埃及記 15:22; 創世記 21:17"> 耶和華的使者在曠野書珥路上的水泉旁遇見她，</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 3:9; 創世記 4:10; 傳道書 10:4"> 對她說：「撒萊的使女夏甲，你從哪裏來？要往哪裏去？」夏甲說：「我從我的主母撒萊面前逃出來。」</span>
<span className="v" id="v9" data-v="9" data-xref="彼得前書 5:5–6; 傳道書 10:4; 提多書 2:9"> 耶和華的使者對她說：「你回到你主母那裏，服在她手下」；</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 17:20; 詩篇 83:6–7; 創世記 25:12–18"> 又說：「我必使你的後裔極其繁多，甚至不可勝數」；</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及記 2:23–24; 出埃及記 3:7; 以賽亞書 7:14"> 並說：「你如今懷孕要生一個兒子，可以給他起名叫以實瑪利<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="就是上帝聽見的意思">b</a></sup>，因為耶和華聽見了你的苦情。</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 25:18; 創世記 21:20; 約伯記 39:5–8"> 他為人必像野驢。他的手要攻打人，人的手也要攻打他；他必住在眾弟兄的東邊。」</span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 139:1–12; 創世記 32:30; 箴言 5:21"> 夏甲就稱那對她說話的耶和華為「看顧人的上帝」。因而說：「在這裏我也看見那看顧我的嗎？」</span>
<span className="v" id="v14" data-v="14" data-xref="創世記 24:62; 創世記 25:11; 創世記 21:31"> 所以這井名叫庇耳‧拉海‧萊。這井正在加低斯和巴列中間。</span>
<span className="v" id="v15" data-v="15" data-xref="創世記 25:12; 創世記 21:9–21; 創世記 17:25–26"> 後來夏甲給亞伯蘭生了一個兒子；亞伯蘭給他起名叫以實瑪利。</span>
<span className="v" id="v16" data-v="16"> 夏甲給亞伯蘭生以實瑪利的時候，亞伯蘭年八十六歲。</span>
</div>

## 人類的邪惡

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 1:28"> 當人在世上多起來、又生女兒的時候，</span>
<span className="v" id="v2" data-v="2" data-xref="詩篇 82:6–7; 約翰一書 2:16; 彼得後書 2:14"> 上帝的兒子們看見人的女子美貌，就隨意挑選，娶來為妻。</span>
<span className="v" id="v3" data-v="3" data-xref="尼希米記 9:30; 以賽亞書 63:10; 耶利米書 11:11"> 耶和華說：「人既屬乎血氣，我的靈就不永遠住在他裏面；然而他的日子還可到一百二十年。」</span>
<span className="v" id="v4" data-v="4" data-xref="民數記 13:33; 撒母耳記下 21:15–22; 撒母耳記上 17:4"> 那時候有偉人在地上，後來上帝的兒子們和人的女子們交合生子；那就是上古英武有名的人。</span>
<span className="v" id="v5" data-v="5" data-xref="馬太福音 15:19; 羅馬書 1:28–31; 馬可福音 7:21–23"> 耶和華見人在地上罪惡很大，終日所思想的盡都是惡，</span>
<span className="v" id="v6" data-v="6" data-xref="以賽亞書 63:10; 撒母耳記上 15:11; 以弗所書 4:30"> 耶和華就後悔造人在地上，心中憂傷。</span>
<span className="v" id="v7" data-v="7" data-xref="西番雅書 1:3; 詩篇 37:20; 耶利米書 12:3–4"> 耶和華說：「我要將所造的人和走獸，並昆蟲，以及空中的飛鳥，都從地上除滅，因為我造他們後悔了。」</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 19:19; 希伯來書 4:16; 路加福音 1:30"> 惟有挪亞在耶和華眼前蒙恩。</span>
</div>
</div>

## 挪亞

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="路加福音 1:6; 希伯來書 11:7; 彼得後書 2:5"> 挪亞的後代記在下面。挪亞是個義人，在當時的世代是個完全人。挪亞與上帝同行。</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 5:32"> 挪亞生了三個兒子，就是閃、含、雅弗。</span>
<span className="v" id="v11" data-v="11" data-xref="以西結書 8:17; 何西阿書 4:1–2; 哈巴谷書 2:8"> 世界在上帝面前敗壞，地上滿了強暴。</span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 53:2–3; 箴言 15:3; 詩篇 14:1–3"> 上帝觀看世界，見是敗壞了；凡有血氣的人在地上都敗壞了行為。</span>
<span className="v" id="v13" data-v="13" data-xref="何西阿書 4:1–2; 彼得前書 4:7; 以西結書 7:2–6"> 上帝就對挪亞說：「凡有血氣的人，他的盡頭已經來到我面前；因為地上滿了他們的強暴，我要把他們和地一併毀滅。</span>
<span className="v" id="v14" data-v="14" data-xref="彼得前書 3:20; 路加福音 17:27; 馬太福音 24:38"> 你要用歌斐木造一隻方舟，分一間一間地造，裏外抹上松香。</span>
<span className="v" id="v15" data-v="15" data-xref="申命記 3:11; 創世記 7:20"> 方舟的造法乃是這樣：要長三百肘，寬五十肘，高三十肘。</span>
<span className="v" id="v16" data-v="16" data-xref="創世記 8:6; 創世記 7:16; 以西結書 41:16"> 方舟上邊要留透光處，高一肘。方舟的門要開在旁邊。方舟要分上、中、下三層。</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 7:4; 彼得後書 2:5; 創世記 7:21–23"> 看哪，我要使洪水氾濫在地上，毀滅天下；凡地上有血肉、有氣息的活物，無一不死。</span>
<span className="v" id="v18" data-v="18" data-xref="希伯來書 11:7; 創世記 7:7; 創世記 17:7"> 我卻要與你立約；你同你的妻，與兒子兒婦，都要進入方舟。</span>
<span className="v" id="v19" data-v="19" data-xref="創世記 7:15–16; 創世記 7:8–9; 創世記 8:17"> 凡有血肉的活物，每樣兩個，一公一母，你要帶進方舟，好在你那裏保全生命。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行傳 10:11–12; 創世記 2:19; 創世記 7:8–16"> 飛鳥各從其類，牲畜各從其類，地上的昆蟲各從其類，每樣兩個，要到你那裏，好保全生命。</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 1:29–30; 詩篇 145:16; 詩篇 136:25"> 你要拿各樣食物積蓄起來，好作你和牠們的食物。」</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及記 40:16; 約翰福音 15:14; 馬太福音 7:24–27"> 挪亞就這樣行。凡上帝所吩咐的，他都照樣行了。</span>
</div>
</div>

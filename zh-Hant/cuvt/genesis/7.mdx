## 洪水

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="馬太福音 24:37–39; 彼得後書 2:5–9; 創世記 6:9"> 耶和華對挪亞說：「你和你的全家都要進入方舟；因為在這世代中，我見你在我面前是義人。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 8:20; 利未記 10:10; 利未記 11:1–47"> 凡潔淨的畜類，你要帶七公七母；不潔淨的畜類，你要帶一公一母；</span>
<span className="v" id="v3" data-v="3"> 空中的飛鳥也要帶七公七母，可以留種，活在全地上；</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 6:13; 創世記 7:12; 創世記 7:17"> 因為再過七天，我要降雨在地上四十晝夜，把我所造的各種活物都從地上除滅。」</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 6:22; 路加福音 8:21; 出埃及記 39:32"> 挪亞就遵着耶和華所吩咐的行了。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="創世記 5:32; 創世記 8:13"> 當洪水氾濫在地上的時候，挪亞整六百歲。</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 17:27; 創世記 6:18; 馬太福音 24:38"> 挪亞就同他的妻和兒子兒婦都進入方舟，躲避洪水。</span>
<span className="v" id="v8" data-v="8"> 潔淨的畜類和不潔淨的畜類，飛鳥並地上一切的昆蟲，</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 7:16; 創世記 2:19; 耶利米書 8:7"> 都是一對一對地，有公有母，到挪亞那裏進入方舟，正如上帝所吩咐挪亞的。</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 6:17; 創世記 7:4; 路加福音 17:27"> 過了那七天，洪水氾濫在地上。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="創世記 8:2; 瑪拉基書 3:10; 箴言 8:28–29"> 當挪亞六百歲，二月十七日那一天，大淵的泉源都裂開了，天上的窗戶也敞開了，</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 7:4; 馬太福音 4:2; 創世記 7:17"> 四十晝夜降大雨在地上。</span>
<span className="v" id="v13" data-v="13" data-xref="創世記 6:18; 創世記 7:1; 創世記 6:10"> 正當那日，挪亞和他三個兒子閃、含、雅弗，並挪亞的妻子和三個兒婦，都進入方舟。</span>
<span className="v" id="v14" data-v="14" data-xref="創世記 7:8–9; 創世記 7:2–3"> 他們和百獸，各從其類，一切牲畜，各從其類，爬在地上的昆蟲，各從其類，一切禽鳥，各從其類，都進入方舟。</span>
<span className="v" id="v15" data-v="15" data-xref="創世記 6:19–20; 以賽亞書 11:6"> 凡有血肉、有氣息的活物，都一對一對地到挪亞那裏，進入方舟。</span>
<span className="v" id="v16" data-v="16" data-xref="馬太福音 25:10; 路加福音 13:25; 詩篇 91:1–10"> 凡有血肉進入方舟的，都是有公有母，正如上帝所吩咐挪亞的。耶和華就把他關在方舟裏頭。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="創世記 7:4; 創世記 7:12"> 洪水氾濫在地上四十天，水往上長，把方舟從地上漂起。</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及記 14:28; 詩篇 69:15; 約伯記 22:16"> 水勢浩大，在地上大大地往上長，方舟在水面上漂來漂去。</span>
<span className="v" id="v19" data-v="19" data-xref="詩篇 104:6–9; 詩篇 46:2–3; 彼得後書 3:6"> 水勢在地上極其浩大，天下的高山都淹沒了。</span>
<span className="v" id="v20" data-v="20" data-xref="耶利米書 3:23; 詩篇 104:6"> 水勢比山高過十五肘，山嶺都淹沒了。</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 6:13; 創世記 7:4; 創世記 6:17"> 凡在地上有血肉的動物，就是飛鳥、牲畜、走獸，和爬在地上的昆蟲，以及所有的人，都死了。</span>
<span className="v" id="v22" data-v="22" data-xref="創世記 2:7; 創世記 6:17"> 凡在旱地上、鼻孔有氣息的生靈都死了。</span>
<span className="v" id="v23" data-v="23" data-xref="彼得後書 2:5; 彼得前書 3:20; 希伯來書 11:7"> 凡地上各類的活物，連人帶牲畜、昆蟲，以及空中的飛鳥，都從地上除滅了，只留下挪亞和那些與他同在方舟裏的。</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 8:3–4"> 水勢浩大，在地上共一百五十天。</span>
</div>

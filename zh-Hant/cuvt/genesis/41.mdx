## 約瑟為法老解夢

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 20:3; 創世記 29:14; 出埃及記 4:9"> 過了兩年，法老做夢，夢見自己站在河邊，</span>
<span className="v" id="v2" data-v="2" data-xref="以賽亞書 19:6"> 有七隻母牛從河裏上來，又美好又肥壯，在蘆荻中吃草。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 41:20–21; 創世記 41:4"> 隨後又有七隻母牛從河裏上來，又醜陋又乾瘦，與那七隻母牛一同站在河邊。</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀上 3:15"> 這又醜陋又乾瘦的七隻母牛吃盡了那又美好又肥壯的七隻母牛。法老就醒了。</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 32:14"> 他又睡着，第二回做夢，夢見一棵麥子長了七個穗子，又肥大又佳美，</span>
<span className="v" id="v6" data-v="6" data-xref="以西結書 17:10; 何西阿書 13:15; 以西結書 19:12"> 隨後又長了七個穗子，又細弱又被東風吹焦了。</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 37:5; 創世記 20:3"> 這細弱的穗子吞了那七個又肥大又飽滿的穗子。法老醒了，不料是個夢。</span>
<span className="v" id="v8" data-v="8" data-xref="但以理書 4:7; 出埃及記 7:22; 馬太福音 2:1"> 到了早晨，法老心裏不安，就差人召了埃及所有的術士和博士來；法老就把所做的夢告訴他們，卻沒有人能給法老圓解。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="創世記 40:14; 創世記 40:23; 創世記 40:1–3"> 那時酒政對法老說：「我今日想起我的罪來。</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 39:20; 創世記 40:2–3; 創世記 37:36"> 從前法老惱怒臣僕，把我和膳長下在護衛長府內的監裏。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 40:5–8"> 我們二人同夜各做一夢，各夢都有講解。</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 40:12–19; 創世記 37:36; 創世記 39:1"> 在那裏同着我們有一個希伯來的少年人，是護衛長的僕人，我們告訴他，他就把我們的夢圓解，是按着各人的夢圓解的。</span>
<span className="v" id="v13" data-v="13" data-xref="以西結書 43:3; 創世記 40:20–22; 創世記 40:12"> 後來正如他給我們圓解的成就了：我官復原職，膳長被掛起來了。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="但以理書 2:25; 詩篇 113:7–8; 詩篇 105:19–22"> 法老遂即差人去召約瑟，他們便急忙帶他出監，他就剃頭，刮臉，換衣裳，進到法老面前。</span>
<span className="v" id="v15" data-v="15" data-xref="但以理書 5:16; 但以理書 5:12; 詩篇 25:14"> 法老對約瑟說：「我做了一夢，沒有人能解；我聽見人說，你聽了夢就能解。」</span>
<span className="v" id="v16" data-v="16" data-xref="哥林多後書 3:5; 創世記 40:8; 但以理書 2:47"> 約瑟回答法老說：「這不在乎我，上帝必將平安的話回答法老。」</span>
<span className="v" id="v17" data-v="17"> 法老對約瑟說：「我夢見我站在河邊，</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米書 24:8; 耶利米書 24:1–3; 耶利米書 24:5"> 有七隻母牛從河裏上來，又肥壯又美好，在蘆荻中吃草。</span>
<span className="v" id="v19" data-v="19"> 隨後又有七隻母牛上來，又軟弱又醜陋又乾瘦，在埃及遍地，我沒有見過這樣不好的。</span>
<span className="v" id="v20" data-v="20"> 這又乾瘦又醜陋的母牛吃盡了那以先的七隻肥母牛，</span>
<span className="v" id="v21" data-v="21" data-xref="以西結書 3:3; 詩篇 37:19; 啟示錄 10:9–10"> 吃了以後卻看不出是吃了，那醜陋的樣子仍舊和先前一樣。我就醒了。</span>
<span className="v" id="v22" data-v="22"> 我又夢見一棵麥子，長了七個穗子，又飽滿又佳美，</span>
<span className="v" id="v23" data-v="23" data-xref="詩篇 129:6–7; 何西阿書 13:15; 列王紀下 19:26"> 隨後又長了七個穗子，枯槁細弱，被東風吹焦了。</span>
<span className="v" id="v24" data-v="24" data-xref="但以理書 4:7; 創世記 41:8; 出埃及記 8:19"> 這些細弱的穗子吞了那七個佳美的穗子。我將這夢告訴了術士，卻沒有人能給我解說。」</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="但以理書 2:45; 啟示錄 4:1; 以弗所書 1:17"> 約瑟對法老說：「法老的夢乃是一個。上帝已將所要做的事指示法老了。</span>
<span className="v" id="v26" data-v="26" data-xref="創世記 41:47; 創世記 41:2; 創世記 41:53"> 七隻好母牛是七年，七個好穗子也是七年；這夢乃是一個。</span>
<span className="v" id="v27" data-v="27" data-xref="列王紀下 8:1; 撒母耳記下 24:19"> 那隨後上來的七隻又乾瘦又醜陋的母牛是七年，那七個虛空、被東風吹焦的穗子也是七年，都是七個荒年。</span>
<span className="v" id="v28" data-v="28" data-xref="創世記 41:25; 創世記 41:16"> 這就是我對法老所說，上帝已將所要做的事顯明給法老了。</span>
<span className="v" id="v29" data-v="29" data-xref="創世記 41:26; 創世記 41:46–47; 創世記 41:49"> 埃及遍地必來七個大豐年，</span>
<span className="v" id="v30" data-v="30" data-xref="創世記 47:13; 創世記 41:54; 雅各書 5:17"> 隨後又要來七個荒年，甚至在埃及地都忘了先前的豐收，全地必被饑荒所滅。</span>
<span className="v" id="v31" data-v="31" data-xref="以賽亞書 24:20; 撒母耳記上 5:6"> 因那以後的饑荒甚大，便不覺得先前的豐收了。</span>
<span className="v" id="v32" data-v="32" data-xref="民數記 23:19; 以賽亞書 46:10–11; 以賽亞書 14:24–27"> 至於法老兩回做夢，是因上帝命定這事，而且必速速成就。</span>
<span className="v" id="v33" data-v="33" data-xref="創世記 41:39; 使徒行傳 6:3; 申命記 1:13"> 所以，法老當揀選一個有聰明有智慧的人，派他治理埃及地。</span>
<span className="v" id="v34" data-v="34" data-xref="箴言 22:3; 路加福音 16:5; 箴言 6:6–8"> 法老當這樣行，又派官員管理這地。當七個豐年的時候，征收埃及地的五分之一，</span>
<span className="v" id="v35" data-v="35" data-xref="創世記 45:6–7; 創世記 41:56; 出埃及記 4:13"> 叫他們把將來豐年一切的糧食聚斂起來，積蓄五穀，收存在各城裏做食物，歸於法老的手下。</span>
<span className="v" id="v36" data-v="36" data-xref="創世記 47:13–25"> 所積蓄的糧食可以防備埃及地將來的七個荒年，免得這地被饑荒所滅。」</span>
</div>
</div>

## 約瑟被立為埃及的宰相

<div className="bt">
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="使徒行傳 7:10; 列王紀上 21:2; 撒母耳記下 3:36"> 法老和他一切臣僕都以這事為妙。</span>
<span className="v" id="v38" data-v="38" data-xref="約伯記 32:8; 但以理書 5:14; 民數記 27:18"> 法老對臣僕說：「像這樣的人，有上帝的靈在他裏頭，我們豈能找得着呢？」</span>
<span className="v" id="v39" data-v="39" data-xref="創世記 41:33; 創世記 41:28; 創世記 41:25"> 法老對約瑟說：「上帝既將這事都指示你，可見沒有人像你這樣有聰明有智慧。</span>
<span className="v" id="v40" data-v="40" data-xref="箴言 22:29; 使徒行傳 7:10; 詩篇 105:21–22"> 你可以掌管我的家；我的民都必聽從你的話。惟獨在寶座上我比你大。」</span>
<span className="v" id="v41" data-v="41" data-xref="馬太福音 28:18; 腓立比書 2:9–11; 創世記 42:6"> 法老又對約瑟說：「我派你治理埃及全地。」</span>
<span className="v" id="v42" data-v="42" data-xref="但以理書 5:29; 但以理書 5:7; 以斯帖記 3:10"> 法老就摘下手上打印的戒指，戴在約瑟的手上，給他穿上細麻衣，把金鍊戴在他的頸項上，</span>
<span className="v" id="v43" data-v="43" data-xref="使徒行傳 7:10; 創世記 45:8; 創世記 45:26"> 又叫約瑟坐他的副車，喝道的在前呼叫說：「跪下。」這樣，法老派他治理埃及全地。</span>
<span className="v" id="v44" data-v="44" data-xref="詩篇 105:22; 出埃及記 11:7"> 法老對約瑟說：「我是法老，在埃及全地，若沒有你的命令，不許人擅自辦事<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是動手動腳">a</a></sup>。」</span>
<span className="v" id="v45" data-v="45" data-xref="創世記 46:20; 以西結書 30:17; 出埃及記 2:16"> 法老賜名給約瑟，叫撒發那忒‧巴內亞，又將安城的祭司波提非拉的女兒亞西納給他為妻。約瑟就出去巡行埃及地。</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="但以理書 1:19; 列王紀上 12:6; 撒母耳記上 16:21"> 約瑟見埃及王法老的時候年三十歲。他從法老面前出去，遍行埃及全地。</span>
<span className="v" id="v47" data-v="47" data-xref="創世記 26:12; 詩篇 72:16"> 七個豐年之內，地的出產極豐極盛<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原文是一把一把的">b</a></sup>，</span>
<span className="v" id="v48" data-v="48" data-xref="創世記 41:34–36; 創世記 47:21"> 約瑟聚斂埃及地七個豐年一切的糧食，把糧食積存在各城裏；各城周圍田地的糧食都積存在本城裏。</span>
<span className="v" id="v49" data-v="49" data-xref="詩篇 78:27; 士師記 6:5; 創世記 22:17"> 約瑟積蓄五穀甚多，如同海邊的沙，無法計算，因為穀不可勝數。</span>
</div>
<div className="bp">
<span className="v" id="v50" data-v="50" data-xref="創世記 46:20; 創世記 48:5; 撒母耳記下 8:18"> 荒年未到以前，安城的祭司波提非拉的女兒亞西納給約瑟生了兩個兒子。</span>
<span className="v" id="v51" data-v="51" data-xref="詩篇 30:5; 箴言 31:7; 申命記 33:17"> 約瑟給長子起名叫瑪拿西<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="就是使之忘了的意思">c</a></sup>，因為他說：「上帝使我忘了一切的困苦和我父的全家。」</span>
<span className="v" id="v52" data-v="52" data-xref="創世記 49:22; 創世記 50:23; 創世記 17:6"> 他給次子起名叫以法蓮<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="就是使之昌盛的意思">d</a></sup>，因為他說：「上帝使我在受苦的地方昌盛。」</span>
</div>
<div className="bp">
<span className="v" id="v53" data-v="53" data-xref="創世記 41:29–31; 詩篇 73:20; 路加福音 16:25"> 埃及地的七個豐年一完，</span>
<span className="v" id="v54" data-v="54" data-xref="創世記 45:11; 使徒行傳 7:11; 詩篇 105:16"> 七個荒年就來了。正如約瑟所說的，各地都有饑荒；惟獨埃及全地有糧食。</span>
<span className="v" id="v55" data-v="55" data-xref="馬太福音 17:5; 馬太福音 3:17; 耶利米書 14:1–6"> 及至埃及全地有了饑荒，眾民向法老哀求糧食，法老對他們說：「你們往約瑟那裏去，凡他所說的，你們都要做。」</span>
<span className="v" id="v56" data-v="56" data-xref="創世記 42:6; 撒迦利亞書 5:3; 路加福音 21:35"> 當時饑荒遍滿天下，約瑟開了各處的倉，糶糧給埃及人；在埃及地饑荒甚大。</span>
<span className="v" id="v57" data-v="57" data-xref="創世記 41:54; 創世記 42:5; 創世記 41:56"> 各地的人都往埃及去，到約瑟那裏糴糧，因為天下的饑荒甚大。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 46:4; 申命記 6:7–8; 使徒行傳 8:2"> 約瑟伏在他父親的面上哀哭，與他親嘴。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 50:26; 歷代志下 16:14; 約翰福音 19:39–40"> 約瑟吩咐伺候他的醫生用香料薰他父親，醫生就用香料薰了以色列。</span>
<span className="v" id="v3" data-v="3" data-xref="民數記 20:29; 申命記 34:8; 創世記 50:10"> 薰屍的常例是四十天；那四十天滿了，埃及人為他哀哭了七十天。</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 18:3; 以斯帖記 4:2"> 為他哀哭的日子過了，約瑟對法老家中的人說：「我若在你們眼前蒙恩，請你們報告法老說：</span>
<span className="v" id="v5" data-v="5" data-xref="歷代志下 16:14; 以賽亞書 22:16; 馬太福音 27:60"> 『我父親要死的時候叫我起誓說：你要將我葬在迦南地，在我為自己所掘的墳墓裏。』現在求你讓我上去葬我父親，以後我必回來。」</span>
<span className="v" id="v6" data-v="6" data-xref="創世記 48:21"> 法老說：「你可以上去，照着你父親叫你起的誓，將他葬埋。」</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 14:16"> 於是約瑟上去葬他父親。與他一同上去的，有法老的臣僕和法老家中的長老，並埃及國的長老，</span>
<span className="v" id="v8" data-v="8" data-xref="民數記 32:24–27; 出埃及記 10:26; 出埃及記 10:8–9"> 還有約瑟的全家和他的弟兄們，並他父親的眷屬；只有他們的婦人孩子，和羊群牛群，都留在歌珊地。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及記 14:28; 列王紀下 18:24; 雅歌 1:9"> 又有車輛馬兵，和他一同上去；那一幫人甚多。</span>
<span className="v" id="v10" data-v="10" data-xref="約伯記 2:13; 使徒行傳 8:2; 撒母耳記下 1:17"> 他們到了約旦河外、亞達的禾場，就在那裏大大地號咷痛哭。約瑟為他父親哀哭了七天。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 10:15–19; 創世記 24:6; 申命記 11:30"> 迦南的居民見亞達禾場上的哀哭，就說：「這是埃及人一場極大的哀哭。」因此那地方名叫亞伯‧麥西，是在約旦河東。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行傳 7:16; 創世記 49:29–32; 以弗所書 6:1"> 雅各的兒子們就遵着他父親所吩咐的辦了，</span>
<span className="v" id="v13" data-v="13" data-xref="創世記 49:29–31; 創世記 23:16–18; 使徒行傳 7:16"> 把他搬到迦南地，葬在幔利前、麥比拉田間的洞裏；那洞和田是亞伯拉罕向赫人以弗崙買來為業，作墳地的。</span>
<span className="v" id="v14" data-v="14"> 約瑟葬了他父親以後，就和眾弟兄，並一切同他上去葬他父親的人，都回埃及去了。</span>
</div>
</div>

## 約瑟安慰哥哥們

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="箴言 28:1; 創世記 42:21–22; 詩篇 53:5"> 約瑟的哥哥們見父親死了，就說：「或者約瑟懷恨我們，照着我們從前待他一切的惡足足地報復我們。」</span>
<span className="v" id="v16" data-v="16" data-xref="箴言 29:25"> 他們就打發人去見約瑟，說：「你父親未死以先吩咐說：</span>
<span className="v" id="v17" data-v="17" data-xref="以弗所書 4:32; 馬太福音 6:14–15; 創世記 45:8"> 『你們要對約瑟這樣說：從前你哥哥們惡待你，求你饒恕他們的過犯和罪惡。』如今求你饒恕你父親上帝之僕人的過犯。」他們對約瑟說這話，約瑟就哭了。</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 37:7–11; 創世記 42:6; 創世記 45:3"> 他的哥哥們又來俯伏在他面前，說：「我們是你的僕人。」</span>
<span className="v" id="v19" data-v="19" data-xref="羅馬書 12:19; 創世記 45:5; 創世記 30:2"> 約瑟對他們說：「不要害怕，我豈能代替上帝呢？</span>
<span className="v" id="v20" data-v="20" data-xref="羅馬書 8:28; 詩篇 119:71; 創世記 45:5–8"> 從前你們的意思是要害我，但上帝的意思原是好的，要保全許多人的性命，成就今日的光景。</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 47:12; 彼得前書 3:9; 創世記 45:10–11"> 現在你們不要害怕，我必養活你們和你們的婦人孩子。」於是約瑟用親愛的話安慰他們。</span>
</div>
</div>

## 約瑟的死

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22"> 約瑟和他父親的眷屬都住在埃及。約瑟活了一百一十歲。</span>
<span className="v" id="v23" data-v="23" data-xref="民數記 32:39; 創世記 30:3; 約伯記 42:16"> 約瑟得見以法蓮第三代的子孫。瑪拿西的孫子、瑪吉的兒子也養在約瑟的膝上。</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及記 3:16–17; 創世記 35:12; 創世記 26:3"> 約瑟對他弟兄們說：「我要死了，但上帝必定看顧你們，領你們從這地上去，到他起誓所應許給亞伯拉罕、以撒、雅各之地。」</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及記 13:19; 約書亞記 24:32; 創世記 47:29–31"> 約瑟叫以色列的子孫起誓說：「上帝必定看顧你們；你們要把我的骸骨從這裏搬上去。」</span>
<span className="v" id="v26" data-v="26" data-xref="創世記 50:2–3; 創世記 47:9; 約書亞記 24:29"> 約瑟死了，正一百一十歲。人用香料將他薰了，把他收殮在棺材裏，停在埃及。</span>
</div>

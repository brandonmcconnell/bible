<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="約伯記 5:2; 創世記 29:31; 創世記 37:11"> 拉結見自己不給雅各生子，就嫉妒她姊姊，對雅各說：「你給我孩子，不然我就死了。」</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 16:2; 詩篇 127:3; 列王紀下 5:7"> 雅各向拉結生氣，說：「叫你不生育的是上帝，我豈能代替他作主呢？」</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 50:23; 約伯記 3:12; 路得記 4:11"> 拉結說：「有我的使女辟拉在這裏，你可以與她同房，使她生子在我膝下，我便因她也得孩子<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是被建立">a</a></sup>。」</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 35:22; 創世記 21:10; 撒母耳記下 12:11"> 拉結就把她的使女辟拉給丈夫為妾；雅各便與她同房，</span>
<span className="v" id="v5" data-v="5"> 辟拉就懷孕，給雅各生了一個兒子。</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米哀歌 3:59; 詩篇 35:24; 詩篇 43:1"> 拉結說：「上帝伸了我的冤，也聽了我的聲音，賜我一個兒子」，因此給他起名叫但<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="就是伸冤的意思">b</a></sup>。</span>
<span className="v" id="v7" data-v="7"> 拉結的使女辟拉又懷孕，給雅各生了第二個兒子。</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 32:24–25; 創世記 23:6; 創世記 49:21"> 拉結說：「我與我姊姊大大相爭，並且得勝」，於是給他起名叫拿弗他利<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="就是相爭的意思">c</a></sup>。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 30:4; 創世記 30:17; 創世記 29:35"> 利亞見自己停了生育，就把使女悉帕給雅各為妾。</span>
<span className="v" id="v10" data-v="10"> 利亞的使女悉帕給雅各生了一個兒子。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 49:19; 以賽亞書 65:11; 創世記 35:26"> 利亞說：「萬幸！」於是給他起名叫迦得<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="就是萬幸的意思">d</a></sup>。</span>
<span className="v" id="v12" data-v="12"> 利亞的使女悉帕又給雅各生了第二個兒子。</span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 1:48; 箴言 31:28; 雅歌 6:9"> 利亞說：「我有福啊，眾女子都要稱我是有福的」，於是給他起名叫亞設<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="就是有福的意思">e</a></sup>。</span>
<span className="v" id="v14" data-v="14" data-xref="雅歌 7:13; 創世記 25:30"> 割麥子的時候，呂便往田裏去，尋見風茄，拿來給他母親利亞。拉結對利亞說：「請你把你兒子的風茄給我些。」</span>
<span className="v" id="v15" data-v="15" data-xref="民數記 16:13; 哥林多前書 4:3; 民數記 16:9–10"> 利亞說：「你奪了我的丈夫還算小事嗎？你又要奪我兒子的風茄嗎？」拉結說：「為你兒子的風茄，今夜他可以與你同寢。」</span>
<span className="v" id="v16" data-v="16"> 到了晚上，雅各從田裏回來，利亞出來迎接他，說：「你要與我同寢，因為我實在用我兒子的風茄把你雇下了。」那一夜，雅各就與她同寢。</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 30:6; 創世記 30:22; 出埃及記 3:7"> 上帝應允了利亞，她就懷孕，給雅各生了第五個兒子。</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 49:14–15; 申命記 33:18; 創世記 46:13"> 利亞說：「上帝給了我價值，因為我把使女給了我丈夫」，於是給他起名叫以薩迦<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="就是價值的意思">f</a></sup>。</span>
<span className="v" id="v19" data-v="19"> 利亞又懷孕，給雅各生了第六個兒子。</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 35:23; 馬太福音 4:13; 創世記 49:13"> 利亞說：「上帝賜我厚賞；我丈夫必與我同住，因我給他生了六個兒子」，於是給他起名西布倫<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="就是同住的意思">g</a></sup>。</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 34:1–3; 創世記 34:26; 創世記 46:15"> 後來又生了一個女兒，給她起名叫底拿。</span>
<span className="v" id="v22" data-v="22" data-xref="創世記 29:31; 詩篇 113:9; 詩篇 127:3"> 上帝顧念拉結，應允了她，使她能生育。</span>
<span className="v" id="v23" data-v="23" data-xref="路加福音 1:25; 創世記 29:31; 路加福音 1:27"> 拉結懷孕生子，說：「上帝除去了我的羞恥」，</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 49:22–26; 創世記 35:24; 創世記 37:2"> 就給他起名叫約瑟<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="就是增添的意思">h</a></sup>，意思說：「願耶和華再增添我一個兒子。」</span>
</div>
</div>

## 雅各和拉班定工價

<div className="bt">
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="創世記 24:54; 創世記 24:56; 創世記 28:15"> 拉結生約瑟之後，雅各對拉班說：「請打發我走，叫我回到我本鄉本土去。</span>
<span className="v" id="v26" data-v="26" data-xref="創世記 29:30; 何西阿書 12:12; 創世記 31:26"> 請你把我服事你所得的妻子和兒女給我，讓我走；我怎樣服事你，你都知道。」</span>
<span className="v" id="v27" data-v="27" data-xref="路得記 2:13; 使徒行傳 7:10; 以賽亞書 61:9"> 拉班對他說：「我若在你眼前蒙恩，請你仍與我同住，因為我已算定，耶和華賜福與我是為你的緣故」；</span>
<span className="v" id="v28" data-v="28" data-xref="創世記 29:15; 創世記 29:19"> 又說：「請你定你的工價，我就給你。」</span>
<span className="v" id="v29" data-v="29" data-xref="創世記 31:6; 創世記 31:38–40; 彼得前書 2:18"> 雅各對他說：「我怎樣服事你，你的牲畜在我手裏怎樣，是你知道的。</span>
<span className="v" id="v30" data-v="30" data-xref="提摩太前書 5:8; 哥林多後書 12:14; 申命記 11:10"> 我未來之先，你所有的很少，現今卻發大眾多，耶和華隨我的腳步賜福與你。如今，我甚麼時候才為自己興家立業呢？」</span>
<span className="v" id="v31" data-v="31" data-xref="撒母耳記下 21:4–6; 希伯來書 13:5; 詩篇 118:8"> 拉班說：「我當給你甚麼呢？」雅各說：「甚麼你也不必給我，只有一件事，你若應承，我便仍舊牧放你的羊群。</span>
<span className="v" id="v32" data-v="32" data-xref="創世記 31:8; 創世記 31:10; 創世記 30:35"> 今天我要走遍你的羊群，把綿羊中凡有點的、有斑的，和黑色的，並山羊中凡有斑的、有點的，都挑出來；將來這一等的就算我的工價。</span>
<span className="v" id="v33" data-v="33" data-xref="出埃及記 13:14; 撒母耳記下 22:21; 撒母耳記上 26:23"> 以後你來查看我的工價，凡在我手裏的山羊不是有點有斑的，綿羊不是黑色的，那就算是我偷的；這樣便可證出我的公義來。」</span>
<span className="v" id="v34" data-v="34" data-xref="哥林多前書 7:7; 民數記 22:29; 哥林多前書 14:5"> 拉班說：「好啊！我情願照着你的話行。」</span>
<span className="v" id="v35" data-v="35" data-xref="創世記 31:9"> 當日，拉班把有紋的、有斑的公山羊，有點的、有斑的、有雜白紋的母山羊，並黑色的綿羊，都挑出來，交在他兒子們的手下，</span>
<span className="v" id="v36" data-v="36"> 又使自己和雅各相離三天的路程。雅各就牧養拉班其餘的羊。</span>
<span className="v" id="v37" data-v="37" data-xref="創世記 31:9–13; 以西結書 31:8"> 雅各拿楊樹、杏樹、楓樹的嫩枝，將皮剝成白紋，使枝子露出白的來，</span>
<span className="v" id="v38" data-v="38"> 將剝了皮的枝子，對着羊群，插在飲羊的水溝裏和水槽裏，羊來喝的時候，牝牡配合。</span>
<span className="v" id="v39" data-v="39" data-xref="出埃及記 12:35–36; 創世記 31:9–12; 創世記 31:40"> 羊對着枝子配合，就生下有紋的、有點的、有斑的來。</span>
<span className="v" id="v40" data-v="40"> 雅各把羊羔分出來，使拉班的羊與這有紋和黑色的羊相對，把自己的羊另放一處，不叫他和拉班的羊混雜。</span>
<span className="v" id="v41" data-v="41"> 到羊群肥壯配合的時候，雅各就把枝子插在水溝裏，使羊對着枝子配合。</span>
<span className="v" id="v42" data-v="42"> 只是到羊瘦弱配合的時候就不插枝子。這樣，瘦弱的就歸拉班，肥壯的就歸雅各。</span>
<span className="v" id="v43" data-v="43" data-xref="創世記 24:35; 創世記 30:30; 創世記 26:13–14"> 於是雅各極其發大，得了許多的羊群、僕婢、駱駝，和驢。</span>
</div>

## 雅各的遺囑

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="民數記 24:14; 耶利米書 23:20; 但以理書 10:14"> 雅各叫了他的兒子們來，說：「你們都來聚集，我好把你們日後必遇的事告訴你們。</span>
<span className="v" id="v2" data-v="2" data-xref="詩篇 34:11; 箴言 7:1; 箴言 23:22"> <span className="pl pl-1">雅各的兒子們，你們要聚集而聽，</span><br /><span className="pl pl-1">要聽你們父親以色列的話。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v3" data-v="3" data-xref="申命記 21:17; 詩篇 78:51; 詩篇 105:36"> <span className="pl pl-1">呂便哪，你是我的長子，</span><br /><span className="pl pl-1">是我力量強壯的時候生的，</span><br /><span className="pl pl-1">本當大有尊榮，權力超眾。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="創世記 35:22; 歷代志上 5:1; 申命記 27:20"> <span className="pl pl-1">但你放縱情慾，滾沸如水，</span><br /><span className="pl pl-1">必不得居首位；</span><br /><span className="pl pl-1">因為你上了你父親的床，</span><br /><span className="pl pl-1">污穢了我的榻。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="創世記 34:25–31; 創世記 46:10–11; 創世記 29:33–34"> <span className="pl pl-1">西緬和利未是弟兄；</span><br /><span className="pl pl-1">他們的刀劍是殘忍的器具。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="創世記 34:30; 詩篇 26:9; 詩篇 16:9"> <span className="pl pl-1">我的靈啊，不要與他們同謀；</span><br /><span className="pl pl-1">我的心哪，不要與他們聯絡；</span><br /><span className="pl pl-1">因為他們趁怒殺害人命，</span><br /><span className="pl pl-1">任意砍斷牛腿大筋。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="約書亞記 19:1–9; 歷代志上 4:24–31; 歷代志上 6:65"> <span className="pl pl-1">他們的怒氣暴烈可咒；</span><br /><span className="pl pl-1">他們的忿恨殘忍可詛。</span><br /><span className="pl pl-1">我要使他們分居在雅各家裏，</span><br /><span className="pl pl-1">散住在以色列地中。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="希伯來書 7:14; 創世記 27:29; 歷代志上 5:2"> <span className="pl pl-1">猶大啊，你弟兄們必讚美你；</span><br /><span className="pl pl-1">你手必掐住仇敵的頸項；</span><br /><span className="pl pl-1">你父親的兒子們必向你下拜。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="民數記 24:9; 民數記 23:24; 啟示錄 5:5"> <span className="pl pl-1">猶大是個小獅子；</span><br /><span className="pl pl-1">我兒啊，你抓了食便上去。</span><br /><span className="pl pl-1">你屈下身去，臥如公獅，</span><br /><span className="pl pl-1">蹲如母獅，誰敢惹你？</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="路加福音 1:32–33; 民數記 24:17; 以賽亞書 9:6"> <span className="pl pl-1">圭必不離猶大，</span><br /><span className="pl pl-1">杖必不離他兩腳之間，</span><br /><span className="pl pl-1">直等細羅</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="就是賜平安者">a</a></sup><br /><span className="pl pl-1">來到，</span><br /><span className="pl pl-1">萬民都必歸順。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="以賽亞書 63:1–3; 約珥書 3:18; 啟示錄 7:14"> <span className="pl pl-1">猶大把小驢拴在葡萄樹上，</span><br /><span className="pl pl-1">把驢駒拴在美好的葡萄樹上。</span><br /><span className="pl pl-1">他在葡萄酒中洗了衣服，</span><br /><span className="pl pl-1">在葡萄汁中洗了袍褂。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="箴言 23:29"> <span className="pl pl-1">他的眼睛必因酒紅潤；</span><br /><span className="pl pl-1">他的牙齒必因奶白亮。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v13" data-v="13" data-xref="申命記 33:18–19; 創世記 30:20; 約書亞記 19:10–16"> <span className="pl pl-1">西布倫必住在海口，</span><br /><span className="pl pl-1">必成為停船的海口；</span><br /><span className="pl pl-1">他的境界必延到西頓。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="歷代志上 12:32; 創世記 30:18; 申命記 33:18"> <span className="pl pl-1">以薩迦是個強壯的驢，</span><br /><span className="pl pl-1">臥在羊圈之中。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 81:6; 馬太福音 23:4; 約書亞記 14:15"> <span className="pl pl-1">他以安靜為佳，以肥地為美，</span><br /><span className="pl pl-1">便低肩背重，成為服苦的僕人。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v16" data-v="16" data-xref="創世記 30:6; 申命記 33:22; 士師記 18:26–27"> <span className="pl pl-1">但必判斷他的民，</span><br /><span className="pl pl-1">作以色列支派之一。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="歷代志上 12:35; 士師記 18:22–31; 士師記 14:1–15"> <span className="pl pl-1">但必作道上的蛇，路中的虺，</span><br /><span className="pl pl-1">咬傷馬蹄，使騎馬的墜落於後。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 119:174; 詩篇 119:166; 彌迦書 7:7"> <span className="pl pl-1">耶和華啊，我向來等候你的救恩。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v19" data-v="19" data-xref="創世記 30:11; 歷代志上 5:11–22; 申命記 33:20–21"> <span className="pl pl-1">迦得必被敵軍追逼，</span><br /><span className="pl pl-1">他卻要追逼他們的腳跟。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v20" data-v="20" data-xref="申命記 33:24–25; 創世記 30:13; 創世記 46:17"> <span className="pl pl-1">亞設之地必出肥美的糧食，</span><br /><span className="pl pl-1">且出君王的美味。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v21" data-v="21" data-xref="申命記 33:23; 創世記 30:8; 約書亞記 19:32–39"> <span className="pl pl-1">拿弗他利是被釋放的母鹿；</span><br /><span className="pl pl-1">他出嘉美的言語。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v22" data-v="22" data-xref="創世記 41:52; 詩篇 128:3; 詩篇 1:1–3"> <span className="pl pl-1">約瑟是多結果子的樹枝，</span><br /><span className="pl pl-1">是泉旁多結果的枝子；</span><br /><span className="pl pl-1">他的枝條探出牆外。</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="創世記 37:24; 詩篇 64:3; 詩篇 118:13"> <span className="pl pl-1">弓箭手將他苦害，</span><br /><span className="pl pl-1">向他射箭，逼迫他。</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="詩篇 132:2; 以賽亞書 28:16; 詩篇 132:5"> <span className="pl pl-1">但他的弓仍舊堅硬；</span><br /><span className="pl pl-1">他的手健壯敏捷。</span><br /><span className="pl pl-1">這是因以色列的牧者，以色列的磐石－</span><br /><span className="pl pl-1">就是雅各的大能者。</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="創世記 28:13; 創世記 35:11; 腓立比書 4:19"> <span className="pl pl-1">你父親的上帝必幫助你；</span><br /><span className="pl pl-1">那全能者必將天上所有的福，</span><br /><span className="pl pl-1">地裏所藏的福，以及生產乳養的福，都賜給你。</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="申命記 33:15–16; 哈巴谷書 3:6; 以賽亞書 66:5"> <span className="pl pl-1">你父親所祝的福</span><br /><span className="pl pl-1">勝過我祖先所祝的福，</span><br /><span className="pl pl-1">如永世的山嶺，至極的邊界；</span><br /><span className="pl pl-1">這些福必降在約瑟的頭上，</span><br /><span className="pl pl-1">臨到那與弟兄迥別之人的頂上。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v27" data-v="27" data-xref="士師記 20:25; 創世記 35:18; 以西結書 22:27"> <span className="pl pl-1">便雅憫是個撕掠的狼，</span><br /><span className="pl pl-1">早晨要吃他所抓的，</span><br /><span className="pl pl-1">晚上要分他所奪的。」</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="啟示錄 7:4; 以斯帖記 8:11; 列王紀上 18:31"> 這一切是以色列的十二支派；這也是他們的父親對他們所說的話，為他們所祝的福，都是按着各人的福分為他們祝福。</span>
</div>
</div>

## 雅各的死和埋葬

<div className="bt">
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="創世記 47:30; 創世記 50:13; 創世記 15:15"> 他又囑咐他們說：「我將要歸到我列祖<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原文是本民">b</a></sup>那裏，你們要將我葬在赫人以弗崙田間的洞裏，與我祖我父在一處，</span>
<span className="v" id="v30" data-v="30" data-xref="創世記 23:20; 創世記 23:16–18; 創世記 23:8–9"> 就是在迦南地幔利前、麥比拉田間的洞；那洞和田是亞伯拉罕向赫人以弗崙買來為業，作墳地的。</span>
<span className="v" id="v31" data-v="31" data-xref="創世記 25:9; 創世記 35:29; 創世記 50:13"> 他們在那裏葬了亞伯拉罕和他妻子撒拉，又在那裏葬了以撒和他的妻子利百加；我也在那裏葬了利亞。</span>
<span className="v" id="v32" data-v="32" data-xref="創世記 23:17–20"> 那塊田和田間的洞原是向赫人買的。」</span>
<span className="v" id="v33" data-v="33" data-xref="創世記 49:29; 創世記 25:8; 創世記 35:29"> 雅各囑咐眾子已畢，就把腳收在床上，氣絕而死，歸他列祖<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="原文是本民">c</a></sup>那裏去了。</span>
</div>

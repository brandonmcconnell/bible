## 約瑟和兄弟相認

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="馬太福音 18:15; 使徒行傳 10:41; 創世記 43:30–31"> 約瑟在左右站着的人面前情不自禁，吩咐一聲說：「人都要離開我出去！」約瑟和弟兄們相認的時候並沒有一人站在他面前。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 46:29; 使徒行傳 20:37; 民數記 14:1"> 他就放聲大哭；埃及人和法老家中的人都聽見了。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行傳 7:13; 使徒行傳 9:5; 撒迦利亞書 12:10"> 約瑟對他弟兄們說：「我是約瑟。我的父親還在嗎？」他弟兄不能回答，因為在他面前都驚惶。</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 37:28; 馬太福音 14:27; 創世記 50:18"> 約瑟又對他弟兄們說：「請你們近前來。」他們就近前來。他說：「我是你們的兄弟約瑟，就是你們所賣到埃及的。</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 50:20; 使徒行傳 7:9–15; 創世記 45:7–8"> 現在，不要因為把我賣到這裏自憂自恨。這是上帝差我在你們以先來，為要保全生命。</span>
<span className="v" id="v6" data-v="6" data-xref="創世記 47:23; 創世記 41:54; 創世記 41:56"> 現在這地的饑荒已經二年了，還有五年不能耕種，不能收成。</span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 44:4; 使徒行傳 7:35; 詩篇 18:50"> 上帝差我在你們以先來，為要給你們存留餘種在世上，又要大施拯救，保全你們的生命。</span>
<span className="v" id="v8" data-v="8" data-xref="約翰福音 15:16; 羅馬書 9:16; 約翰福音 19:11"> 這樣看來，差我到這裏來的不是你們，乃是上帝。他又使我如法老的父，作他全家的主，並埃及全地的宰相。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 45:19–20; 創世記 45:13"> 你們要趕緊上到我父親那裏，對他說：『你兒子約瑟這樣說：上帝使我作全埃及的主，請你下到我這裏來，不要耽延。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及記 9:26; 出埃及記 8:22; 創世記 46:34–6"> 你和你的兒子孫子，連牛群羊群，並一切所有的，都可以住在歌珊地，與我相近。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 47:12; 創世記 47:6; 馬太福音 15:5–6"> 我要在那裏奉養你；因為還有五年的饑荒，免得你和你的眷屬，並一切所有的，都敗落了。』</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 42:23; 路加福音 24:39; 約翰福音 20:27"> 況且你們的眼和我兄弟便雅憫的眼都看見是我親口對你們說話。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行傳 7:14; 啟示錄 21:23; 彼得前書 1:10–12"> 你們也要將我在埃及一切的榮耀和你們所看見的事都告訴我父親，又要趕緊地將我父親搬到我這裏來。」</span>
<span className="v" id="v14" data-v="14" data-xref="創世記 33:4; 創世記 29:11; 創世記 46:29"> 於是約瑟伏在他兄弟便雅憫的頸項上哭，便雅憫也在他的頸項上哭。</span>
<span className="v" id="v15" data-v="15" data-xref="路加福音 15:20; 撒母耳記上 10:1; 詩篇 77:4"> 他又與眾弟兄親嘴，抱着他們哭，隨後他弟兄們就和他說話。</span>
<span className="v" id="v16" data-v="16" data-xref="創世記 41:33; 以斯帖記 1:21; 創世記 20:15"> 這風聲傳到法老的宮裏，說：「約瑟的弟兄們來了。」法老和他的臣僕都很喜歡。</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 42:25–26; 創世記 44:1–2"> 法老對約瑟說：「你吩咐你的弟兄們說：『你們要這樣行：把馱子抬在牲口上，起身往迦南地去。</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 27:28; 民數記 18:12; 創世記 47:6"> 將你們的父親和你們的眷屬都搬到我這裏來，我要把埃及地的美物賜給你們，你們也要吃這地肥美的出產。</span>
<span className="v" id="v19" data-v="19" data-xref="創世記 46:5; 創世記 45:27; 創世記 31:17–18"> 現在我吩咐你們要這樣行：從埃及地帶着車輛去，把你們的孩子和妻子，並你們的父親都搬來。</span>
<span className="v" id="v20" data-v="20" data-xref="以賽亞書 1:19; 路加福音 17:31; 申命記 7:16"> 你們眼中不要愛惜你們的家具，因為埃及全地的美物都是你們的。』」</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 45:19; 以西結書 23:24; 耶利米哀歌 1:18"> 以色列的兒子們就如此行。約瑟照着法老的吩咐給他們車輛和路上用的食物，</span>
<span className="v" id="v22" data-v="22" data-xref="創世記 43:34; 列王紀下 5:5; 士師記 14:12"> 又給他們各人一套衣服，惟獨給便雅憫三百銀子，五套衣服；</span>
<span className="v" id="v23" data-v="23" data-xref="創世記 24:10; 出埃及記 16:3; 創世記 43:11"> 送給他父親公驢十匹，馱着埃及的美物，母驢十匹，馱着糧食與餅和菜，為他父親路上用。</span>
<span className="v" id="v24" data-v="24" data-xref="帖撒羅尼迦前書 5:13; 詩篇 133:1–3; 創世記 42:21–22"> 於是約瑟打發他弟兄們回去，又對他們說：「你們不要在路上相爭。」</span>
<span className="v" id="v25" data-v="25"> 他們從埃及上去，來到迦南地、他們的父親雅各那裏，</span>
<span className="v" id="v26" data-v="26" data-xref="創世記 44:28; 創世記 37:35; 路加福音 24:34"> 告訴他說：「約瑟還在，並且作埃及全地的宰相。」雅各心裏冰涼，因為不信他們。</span>
<span className="v" id="v27" data-v="27" data-xref="詩篇 85:6; 以賽亞書 57:15; 創世記 45:19"> 他們便將約瑟對他們說的一切話都告訴了他。他們父親雅各又看見約瑟打發來接他的車輛，心就甦醒了。</span>
<span className="v" id="v28" data-v="28" data-xref="路加福音 2:28–30; 約翰福音 16:21–22; 創世記 46:30"> 以色列說：「罷了！罷了！我的兒子約瑟還在，趁我未死以先，我要去見他一面。」</span>

## 約瑟為囚犯解夢

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 40:13; 創世記 39:20–23; 以斯帖記 6:1"> 這事以後，埃及王的酒政和膳長得罪了他們的主－埃及王，</span>
<span className="v" id="v2" data-v="2" data-xref="箴言 16:14; 箴言 19:12; 詩篇 76:10"> 法老就惱怒酒政和膳長這二臣，</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 39:20; 創世記 39:23"> 把他們下在護衛長府內的監裏，就是約瑟被囚的地方。</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 39:1; 詩篇 37:5; 創世記 37:36"> 護衛長把他們交給約瑟，約瑟便伺候他們；他們有些日子在監裏。</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 41:11; 創世記 40:8; 創世記 37:5–10"> 被囚在監之埃及王的酒政和膳長二人同夜各做一夢，各夢都有講解。</span>
<span className="v" id="v6" data-v="6" data-xref="創世記 41:8; 但以理書 2:1–3; 創世記 40:8"> 到了早晨，約瑟進到他們那裏，見他們有愁悶的樣子。</span>
<span className="v" id="v7" data-v="7" data-xref="尼希米記 2:2; 撒母耳記上 1:8; 路加福音 24:17"> 他便問法老的二臣，就是與他同囚在他主人府裏的，說：「你們今日為甚麼面帶愁容呢？」</span>
<span className="v" id="v8" data-v="8" data-xref="但以理書 2:47; 創世記 41:15–16; 但以理書 2:28"> 他們對他說：「我們各人做了一夢，沒有人能解。」約瑟說：「解夢不是出於上帝嗎？請你們將夢告訴我。」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="士師記 7:13–15; 創世記 37:5–10; 但以理書 4:8"> 酒政便將他的夢告訴約瑟說：「我夢見在我面前有一棵葡萄樹，</span>
<span className="v" id="v10" data-v="10"> 樹上有三根枝子，好像發了芽，開了花，上頭的葡萄都成熟了。</span>
<span className="v" id="v11" data-v="11" data-xref="尼希米記 1:11–1; 列王紀上 10:5; 歷代志下 9:4"> 法老的杯在我手中，我就拿葡萄擠在法老的杯裏，將杯遞在他手中。」</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 41:12; 士師記 7:14; 創世記 41:25–26"> 約瑟對他說：「你所做的夢是這樣解：三根枝子就是三天；</span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 3:3; 耶利米書 52:31; 列王紀下 25:27"> 三天之內，法老必提你出監，叫你官復原職，你仍要遞杯在法老的手中，和先前作他的酒政一樣。</span>
<span className="v" id="v14" data-v="14" data-xref="約書亞記 2:12; 路加福音 23:42; 撒母耳記上 20:14–15"> 但你得好處的時候，求你記念我，施恩與我，在法老面前提說我，救我出這監牢。</span>
<span className="v" id="v15" data-v="15" data-xref="彼得前書 3:17–18; 創世記 39:20; 提摩太前書 1:10"> 我實在是從希伯來人之地被拐來的；我在這裏也沒有做過甚麼，叫他們把我下在監裏。」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="創世記 40:1–2"> 膳長見夢解得好，就對約瑟說：「我在夢中見我頭上頂着三筐白餅；</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 49:20; 歷代志上 12:20"> 極上的筐子裏有為法老烤的各樣食物，有飛鳥來吃我頭上筐子裏的食物。」</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 40:12; 創世記 41:26; 哥林多前書 11:24"> 約瑟說：「你的夢是這樣解：三個筐子就是三天；</span>
<span className="v" id="v19" data-v="19" data-xref="創世記 40:22; 使徒行傳 20:27; 撒母耳記下 21:6"> 三天之內，法老必斬斷你的頭，把你掛在木頭上，必有飛鳥來吃你身上的肉。」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="創世記 40:19; 創世記 40:13; 馬太福音 14:6"> 到了第三天，是法老的生日，他為眾臣僕設擺筵席，把酒政和膳長提出監來，</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 40:13; 尼希米記 2:1"> 使酒政官復原職，他仍舊遞杯在法老手中；</span>
<span className="v" id="v22" data-v="22" data-xref="創世記 40:19; 創世記 41:16; 但以理書 2:30"> 但把膳長掛起來，正如約瑟向他們所解的話。</span>
<span className="v" id="v23" data-v="23" data-xref="詩篇 31:12; 約伯記 19:14; 詩篇 105:19"> 酒政卻不記念約瑟，竟忘了他。</span>
</div>
</div>

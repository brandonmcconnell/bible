## 所多瑪的罪惡

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 18:22; 創世記 18:1–5; 希伯來書 13:2"> 那兩個天使晚上到了所多瑪；羅得正坐在所多瑪城門口，看見他們，就起來迎接，臉伏於地下拜，</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 18:4; 路加福音 24:28–29; 希伯來書 13:2"> 說：「我主啊，請你們到僕人家裏洗洗腳，住一夜，清早起來再走。」他們說：「不！我們要在街上過夜。」</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 18:6–8; 士師記 6:19; 撒母耳記上 28:24"> 羅得切切地請他們，他們這才進去，到他屋裏。羅得為他們預備筵席，烤無酵餅，他們就吃了。</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 13:13; 箴言 4:16; 出埃及記 23:2"> 他們還沒有躺下，所多瑪城裏各處的人，連老帶少，都來圍住那房子，</span>
<span className="v" id="v5" data-v="5" data-xref="士師記 19:22; 以賽亞書 3:9; 猶大書 1:7"> 呼叫羅得說：「今日晚上到你這裏來的人在哪裏呢？把他們帶出來，任我們所為。」</span>
<span className="v" id="v6" data-v="6" data-xref="士師記 19:23"> 羅得出來，把門關上，到眾人那裏，</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多前書 6:9–11; 士師記 19:23; 利未記 20:13"> 說：「眾弟兄，請你們不要做這惡事。</span>
<span className="v" id="v8" data-v="8" data-xref="士師記 19:24; 創世記 19:31–38; 士師記 9:15"> 我有兩個女兒，還是處女，容我領出來，任憑你們的心願而行；只是這兩個人既然到我舍下，不要向他們做甚麼。」</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及記 2:14; 彼得後書 2:7–8; 創世記 13:12"> 眾人說：「退去吧！」又說：「這個人來寄居，還想要作官哪！現在我們要害你比害他們更甚。」眾人就向前擁擠羅得，要攻破房門。</span>
<span className="v" id="v10" data-v="10"> 只是那二人伸出手來，將羅得拉進屋去，把門關上，</span>
<span className="v" id="v11" data-v="11" data-xref="列王紀下 6:18; 使徒行傳 13:11; 申命記 28:28–29"> 並且使門外的人，無論老少，眼都昏迷；他們摸來摸去，總尋不着房門。</span>
</div>
</div>

## 羅得離開所多瑪

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="創世記 7:1; 彼得後書 2:7; 啟示錄 18:4"> 二人對羅得說：「你這裏還有甚麼人嗎？無論是女婿是兒女，和這城中一切屬你的人，你都要將他們從這地方帶出去。</span>
<span className="v" id="v13" data-v="13" data-xref="創世記 18:20; 馬太福音 13:49–50; 猶大書 1:7"> 我們要毀滅這地方；因為城內罪惡的聲音在耶和華面前甚大，耶和華差我們來，要毀滅這地方。」</span>
<span className="v" id="v14" data-v="14" data-xref="民數記 16:21; 耶利米書 51:6; 民數記 16:45"> 羅得就出去，告訴娶了<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或譯：將要娶">a</a></sup>他女兒的女婿們說：「你們起來離開這地方，因為耶和華要毀滅這城。」他女婿們卻以為他說的是戲言。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="民數記 16:24–27; 啟示錄 18:4; 創世記 19:22"> 天明了，天使催逼羅得說：「起來！帶着你的妻子和你在這裏的兩個女兒出去，免得你因這城裏的罪惡同被剿滅。」</span>
<span className="v" id="v16" data-v="16" data-xref="羅馬書 9:15–16; 提多書 3:5; 約翰福音 6:44"> 但羅得遲延不走。二人因為耶和華憐恤羅得，就拉着他的手和他妻子的手，並他兩個女兒的手，把他們領出來，安置在城外；</span>
<span className="v" id="v17" data-v="17" data-xref="馬太福音 24:16–18; 路加福音 9:62; 腓立比書 3:13–14"> 領他們出來以後，就說：「逃命吧！不可回頭看，也不可在平原站住。要往山上逃跑，免得你被剿滅。」</span>
<span className="v" id="v18" data-v="18" data-xref="約翰福音 13:6–8; 使徒行傳 10:14; 創世記 32:26"> 羅得對他們說：「我主啊，不要如此！</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳記上 27:1; 詩篇 103:1–22; 提摩太前書 1:14–16"> 你僕人已經在你眼前蒙恩；你又向我顯出莫大的慈愛，救我的性命。我不能逃到山上去，恐怕這災禍臨到我，我便死了。</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 119:175; 箴言 3:5–7; 創世記 19:30"> 看哪，這座城又小又近，容易逃到，這不是一個小的嗎？求你容我逃到那裏，我的性命就得存活。」</span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 145:19; 詩篇 34:15; 詩篇 102:17"> 天使對他說：「這事我也應允你；我不傾覆你所說的這城。</span>
<span className="v" id="v22" data-v="22" data-xref="創世記 13:10; 創世記 14:2; 創世記 32:25–28"> 你要速速地逃到那城；因為你還沒有到那裏，我不能做甚麼。」因此那城名叫瑣珥<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="就是小的意思">b</a></sup>。</span>
</div>
</div>

## 所多瑪蛾摩拉的毀滅

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23"> 羅得到了瑣珥，日頭已經出來了。</span>
<span className="v" id="v24" data-v="24" data-xref="申命記 29:23; 以賽亞書 13:19; 阿摩司書 4:11"> 當時，耶和華將硫磺與火從天上耶和華那裏降與所多瑪和蛾摩拉，</span>
<span className="v" id="v25" data-v="25" data-xref="詩篇 107:34; 創世記 14:3; 創世記 13:10"> 把那些城和全平原，並城裏所有的居民，連地上生長的，都毀滅了。</span>
<span className="v" id="v26" data-v="26" data-xref="路加福音 17:31–32; 創世記 19:17; 箴言 14:14"> 羅得的妻子在後邊回頭一看，就變成了一根鹽柱。</span>
<span className="v" id="v27" data-v="27" data-xref="哈巴谷書 2:1; 詩篇 5:3; 希伯來書 2:1"> 亞伯拉罕清早起來，到了他從前站在耶和華面前的地方，</span>
<span className="v" id="v28" data-v="28" data-xref="啟示錄 18:9; 啟示錄 9:2; 啟示錄 21:8"> 向所多瑪和蛾摩拉與平原的全地觀看，不料，那地方煙氣上騰，如同燒窯一般。</span>
<span className="v" id="v29" data-v="29" data-xref="創世記 8:1; 申命記 9:5; 創世記 18:23–33"> 當上帝毀滅平原諸城的時候，他記念亞伯拉罕，正在傾覆羅得所住之城的時候，就打發羅得從傾覆之中出來。</span>
</div>
</div>

## 摩押人和亞捫人的起源

<div className="bt">
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="創世記 19:19; 以賽亞書 15:5; 雅各書 1:8"> 羅得因為怕住在瑣珥，就同他兩個女兒從瑣珥上去，住在山裏；他和兩個女兒住在一個洞裏。</span>
<span className="v" id="v31" data-v="31" data-xref="申命記 25:5; 以賽亞書 4:1; 創世記 16:2"> 大女兒對小女兒說：「我們的父親老了，地上又無人按着世上的常規進到我們這裏。</span>
<span className="v" id="v32" data-v="32" data-xref="利未記 18:6–7; 創世記 11:3; 創世記 9:21"> 來！我們可以叫父親喝酒，與他同寢。這樣，我們好從他存留後裔。」</span>
<span className="v" id="v33" data-v="33" data-xref="哈巴谷書 2:15–16; 箴言 23:29–35; 箴言 20:1"> 於是，那夜她們叫父親喝酒，大女兒就進去和她父親同寢；她幾時躺下，幾時起來，父親都不知道。</span>
<span className="v" id="v34" data-v="34" data-xref="耶利米書 8:12; 耶利米書 6:15; 以賽亞書 3:9"> 第二天，大女兒對小女兒說：「我昨夜與父親同寢。今夜我們再叫他喝酒，你可以進去與他同寢。這樣，我們好從父親存留後裔。」</span>
<span className="v" id="v35" data-v="35" data-xref="箴言 24:16; 詩篇 8:4; 彼得前書 4:7"> 於是，那夜她們又叫父親喝酒，小女兒起來與她父親同寢；她幾時躺下，幾時起來，父親都不知道。</span>
<span className="v" id="v36" data-v="36" data-xref="哈巴谷書 2:15; 士師記 1:7; 馬太福音 7:2"> 這樣，羅得的兩個女兒都從她父親懷了孕。</span>
<span className="v" id="v37" data-v="37" data-xref="申命記 2:9; 列王紀下 3:1–27; 民數記 21:29"> 大女兒生了兒子，給他起名叫摩押，就是現今摩押人的始祖。</span>
<span className="v" id="v38" data-v="38" data-xref="申命記 2:19; 士師記 10:6–40; 詩篇 83:4–8"> 小女兒也生了兒子，給他起名叫便‧亞米，就是現今亞捫人的始祖。</span>
</div>

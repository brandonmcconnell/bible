## 雅各準備迎見以掃

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="詩篇 91:11; 詩篇 34:7; 希伯來書 1:4"> 雅各仍舊行路，上帝的使者遇見他。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳記下 2:8; 約書亞記 5:14; 約書亞記 21:38"> 雅各看見他們就說：「這是上帝的軍兵」，於是給那地方起名叫瑪哈念<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="就是二軍兵的意思">a</a></sup>。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 25:30; 約書亞記 24:4; 申命記 2:5"> 雅各打發人先往西珥地去，就是以東地，見他哥哥以掃，</span>
<span className="v" id="v4" data-v="4" data-xref="彼得前書 3:6; 路加福音 14:11; 創世記 33:8"> 吩咐他們說：「你們對我主以掃說：『你的僕人雅各這樣說：我在拉班那裏寄居，直到如今。</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 33:8; 創世記 33:15; 創世記 33:11"> 我有牛、驢、羊群、僕婢，現在打發人來報告我主，為要在你眼前蒙恩。』」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="創世記 33:1; 創世記 32:8; 創世記 32:11"> 所打發的人回到雅各那裏，說：「我們到了你哥哥以掃那裏，他帶着四百人，正迎着你來。」</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 35:3; 哥林多後書 1:8–10; 出埃及記 14:10"> 雅各就甚懼怕，而且愁煩，便把那與他同在的人口和羊群、牛群、駱駝分做兩隊，</span>
<span className="v" id="v8" data-v="8" data-xref="馬太福音 10:16; 創世記 33:1–3"> 說：「以掃若來擊殺這一隊，剩下的那一隊還可以逃避。」</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 31:42; 詩篇 34:4–6; 創世記 31:3"> 雅各說：「耶和華－我祖亞伯拉罕的上帝，我父親以撒的上帝啊，你曾對我說：『回你本地本族去，我要厚待你。』</span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 18:35; 創世記 24:27; 撒母耳記下 7:18"> 你向僕人所施的一切慈愛和誠實，我一點也不配得；我先前只拿着我的杖過這約旦河，如今我卻成了兩隊了。</span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 59:1–2; 箴言 18:19; 馬太福音 6:13"> 求你救我脫離我哥哥以掃的手；因為我怕他來殺我，連妻子帶兒女一同殺了。</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 28:13–15; 希伯來書 6:17; 提多書 1:2"> 你曾說：『我必定厚待你，使你的後裔如同海邊的沙，多得不可勝數。』」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="箴言 18:16; 創世記 43:11; 箴言 19:6"> 當夜，雅各在那裏住宿，就從他所有的物中拿禮物要送給他哥哥以掃：</span>
<span className="v" id="v14" data-v="14" data-xref="約伯記 1:3; 申命記 8:18; 約伯記 42:12"> 母山羊二百隻，公山羊二十隻，母綿羊二百隻，公綿羊二十隻，</span>
<span className="v" id="v15" data-v="15"> 奶崽子的駱駝三十隻－各帶着崽子，母牛四十隻，公牛十隻，母驢二十匹，驢駒十匹；</span>
<span className="v" id="v16" data-v="16" data-xref="創世記 33:8–9; 創世記 32:20; 箴言 2:11"> 每樣各分一群，交在僕人手下，就對僕人說：「你們要在我前頭過去，使群群相離，有空閒的地方」；</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 33:3"> 又吩咐儘先走的說：「我哥哥以掃遇見你的時候，問你說：『你是哪家的人？要往哪裏去？你前頭這些是誰的？』</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 32:4–5"> 你就說：『是你僕人雅各的，是送給我主以掃的禮物；他自己也在我們後邊。』」</span>
<span className="v" id="v19" data-v="19"> 又吩咐第二、第三，和一切趕群畜的人說：「你們遇見以掃的時候也要這樣對他說；</span>
<span className="v" id="v20" data-v="20" data-xref="約伯記 42:8–9; 箴言 21:14; 創世記 43:11"> 並且你們要說：『你僕人雅各在我們後邊。』」因雅各心裏說：「我藉着在我前頭去的禮物解他的恨，然後再見他的面，或者他容納我。」</span>
<span className="v" id="v21" data-v="21"> 於是禮物先過去了；那夜，雅各在隊中住宿。</span>
</div>
</div>

## 雅各在毗努伊勒摔跤

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="申命記 3:16; 申命記 2:37; 提摩太前書 5:8"> 他夜間起來，帶着兩個妻子，兩個使女，並十一個兒子，都過了雅博渡口，</span>
<span className="v" id="v23" data-v="23"> 先打發他們過河，又打發所有的都過去，</span>
<span className="v" id="v24" data-v="24" data-xref="何西阿書 12:3–5; 以弗所書 6:12; 路加福音 13:24"> 只剩下雅各一人。有一個人來和他摔跤，直到黎明。</span>
<span className="v" id="v25" data-v="25" data-xref="哥林多後書 12:7–9; 何西阿書 12:3–4; 馬太福音 26:41"> 那人見自己勝不過他，就將他的大腿窩摸了一把，雅各的大腿窩正在摔跤的時候就扭了。</span>
<span className="v" id="v26" data-v="26" data-xref="何西阿書 12:4; 詩篇 115:12–13; 哥林多後書 12:8–9"> 那人說：「天黎明了，容我去吧！」雅各說：「你不給我祝福，我就不容你去。」</span>
<span className="v" id="v27" data-v="27"> 那人說：「你名叫甚麼？」他說：「我名叫雅各。」</span>
<span className="v" id="v28" data-v="28" data-xref="啟示錄 2:17; 創世記 35:10; 以賽亞書 62:2–4"> 那人說：「你的名不要再叫雅各，要叫以色列；因為你與上帝與人較力，都得了勝。」</span>
<span className="v" id="v29" data-v="29" data-xref="以賽亞書 9:6; 士師記 13:16–18; 約伯記 11:7"> 雅各問他說：「請將你的名告訴我。」那人說：「何必問我的名？」於是在那裏給雅各祝福。</span>
<span className="v" id="v30" data-v="30" data-xref="出埃及記 24:10–11; 民數記 12:8; 以賽亞書 6:5"> 雅各便給那地方起名叫毗努伊勒<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="就是上帝之面的意思">b</a></sup>，意思說：「我面對面見了上帝，我的性命仍得保全。」</span>
<span className="v" id="v31" data-v="31" data-xref="哥林多後書 12:7; 創世記 19:15; 士師記 8:8"> 日頭剛出來的時候，雅各經過毗努伊勒，他的大腿就瘸了。</span>
<span className="v" id="v32" data-v="32" data-xref="撒母耳記上 5:5"> 故此，以色列人不吃大腿窩的筋，直到今日，因為那人摸了雅各大腿窩的筋。</span>
</div>
</div>

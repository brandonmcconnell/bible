## 上帝吩咐亞伯拉罕獻以撒

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="希伯來書 11:17; 雅各書 2:21; 申命記 8:2"> 這些事以後，上帝要試驗亞伯拉罕，就呼叫他說：「亞伯拉罕！」他說：「我在這裏。」</span>
<span className="v" id="v2" data-v="2" data-xref="約翰福音 3:16; 羅馬書 8:32; 希伯來書 11:17"> 上帝說：「你帶着你的兒子，就是你獨生的兒子，你所愛的以撒，往摩利亞地去，在我所要指示你的山上，把他獻為燔祭。」</span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 119:60; 馬太福音 10:37; 路加福音 14:26"> 亞伯拉罕清早起來，備上驢，帶着兩個僕人和他兒子以撒，也劈好了燔祭的柴，就起身往上帝所指示他的地方去了。</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 13:32; 馬太福音 17:23; 何西阿書 6:2"> 到了第三日，亞伯拉罕舉目遠遠地看見那地方。</span>
<span className="v" id="v5" data-v="5" data-xref="希伯來書 11:19; 希伯來書 12:1"> 亞伯拉罕對他的僕人說：「你們和驢在此等候，我與童子往那裏去拜一拜，就回到你們這裏來。」</span>
<span className="v" id="v6" data-v="6" data-xref="約翰福音 19:17; 彼得前書 2:24; 以賽亞書 53:6"> 亞伯拉罕把燔祭的柴放在他兒子以撒身上，自己手裏拿着火與刀；於是二人同行。</span>
<span className="v" id="v7" data-v="7" data-xref="羅馬書 8:15; 馬太福音 26:39; 創世記 8:20"> 以撒對他父親亞伯拉罕說：「父親哪！」亞伯拉罕說：「我兒，我在這裏。」以撒說：「請看，火與柴都有了，但燔祭的羊羔在哪裏呢？」</span>
<span className="v" id="v8" data-v="8" data-xref="約翰福音 1:36; 約翰福音 1:29; 啟示錄 5:12"> 亞伯拉罕說：「我兒，上帝必自己預備作燔祭的羊羔。」於是二人同行。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="雅各書 2:21; 希伯來書 11:17–19; 腓立比書 2:7–8"> 他們到了上帝所指示的地方，亞伯拉罕在那裏築壇，把柴擺好，捆綁他的兒子以撒，放在壇的柴上。</span>
<span className="v" id="v10" data-v="10" data-xref="雅各書 2:21–23; 希伯來書 11:17–19; 以賽亞書 53:6–12"> 亞伯拉罕就伸手拿刀，要殺他的兒子。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 21:17; 出埃及記 3:4; 創世記 16:9–10"> 耶和華的使者從天上呼叫他說：「亞伯拉罕！亞伯拉罕！」他說：「我在這裏。」</span>
<span className="v" id="v12" data-v="12" data-xref="雅各書 2:21–22; 雅各書 2:18; 撒母耳記上 15:22"> 天使說：「你不可在這童子身上下手。一點不可害他！現在我知道你是敬畏上帝的了；因為你沒有將你的兒子，就是你獨生的兒子，留下不給我。」</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多前書 10:13; 詩篇 40:6–8; 哥林多後書 1:9–10"> 亞伯拉罕舉目觀看，不料，有一隻公羊，兩角扣在稠密的小樹中。亞伯拉罕就取了那隻公羊來，獻為燔祭，代替他的兒子。</span>
<span className="v" id="v14" data-v="14" data-xref="創世記 22:13; 出埃及記 17:15; 創世記 22:8"> 亞伯拉罕給那地方起名叫「耶和華以勒」<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="就是耶和華必預備的意思">a</a></sup>，直到今日人還說：「在耶和華的山上必有預備。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15"> 耶和華的使者第二次從天上呼叫亞伯拉罕說：</span>
<span className="v" id="v16" data-v="16" data-xref="希伯來書 6:13–14; 路加福音 1:73; 詩篇 105:9"> 「耶和華說：『你既行了這事，不留下你的兒子，就是你獨生的兒子，我便指着自己起誓說：</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 15:5; 創世記 24:60; 耶利米書 33:22"> 論福，我必賜大福給你；論子孫，我必叫你的子孫多起來，如同天上的星，海邊的沙。你子孫必得着仇敵的城門，</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行傳 3:25; 創世記 12:3; 加拉太書 3:16"> 並且地上萬國都必因你的後裔得福，因為你聽從了我的話。』」</span>
<span className="v" id="v19" data-v="19" data-xref="創世記 21:31; 士師記 20:1; 約書亞記 15:28"> 於是亞伯拉罕回到他僕人那裏，他們一同起身往別是巴去，亞伯拉罕就住在別是巴。</span>
</div>
</div>

## 拿鶴的後代

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="創世記 11:29; 創世記 24:24; 箴言 25:25"> 這事以後，有人告訴亞伯拉罕說：「密迦給你兄弟拿鶴生了幾個兒子，</span>
<span className="v" id="v21" data-v="21" data-xref="約伯記 1:1; 約伯記 32:2; 詩篇 60:1–12"> 長子是烏斯，他的兄弟是布斯和亞蘭的父親基母利，</span>
<span className="v" id="v22" data-v="22"> 並基薛、哈瑣、必達、益拉、彼土利（彼土利生利百加）。」</span>
<span className="v" id="v23" data-v="23" data-xref="創世記 24:15; 創世記 28:5; 創世記 24:51"> 這八個人都是密迦給亞伯拉罕的兄弟拿鶴生的。</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 16:3; 創世記 25:6; 箴言 15:25"> 拿鶴的妾名叫流瑪，生了提八、迦含、他轄，和瑪迦。</span>
</div>

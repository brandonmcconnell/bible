## 約瑟和他的兄弟

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 17:8; 創世記 23:4; 創世記 36:7"> 雅各住在迦南地，就是他父親寄居的地。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 35:25–26; 創世記 35:22; 撒母耳記上 2:22–24"> 雅各的記略如下。 約瑟十七歲與他哥哥們一同牧羊。他是個童子，與他父親的妾辟拉、悉帕的兒子們常在一處。約瑟將他哥哥們的惡行報給他們的父親。</span>
<span className="v" id="v3" data-v="3" data-xref="約翰福音 3:35; 創世記 37:32; 撒母耳記下 13:18"> 以色列原來愛約瑟過於愛他的眾子，因為約瑟是他年老生的；他給約瑟做了一件彩衣。</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 27:41; 約翰一書 3:12; 約翰一書 4:20"> 約瑟的哥哥們見父親愛約瑟過於愛他們，就恨約瑟，不與他說和睦的話。</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 28:12; 創世記 42:9; 約翰福音 17:14"> 約瑟做了一夢，告訴他哥哥們，他們就越發恨他。</span>
<span className="v" id="v6" data-v="6" data-xref="創世記 44:18; 士師記 9:7"> 約瑟對他們說：「請聽我所做的夢：</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 44:14; 創世記 42:6; 創世記 43:26"> 我們在田裏捆禾稼，我的捆起來站着，你們的捆來圍着我的捆下拜。」</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳記上 10:27; 使徒行傳 7:35; 希伯來書 10:29"> 他的哥哥們回答說：「難道你真要作我們的王嗎？難道你真要管轄我們嗎？」他們就因為他的夢和他的話越發恨他。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行傳 7:9–14; 創世記 37:7; 但以理書 8:10"> 後來他又做了一夢，也告訴他的哥哥們說：「看哪，我又做了一夢，夢見太陽、月亮，與十一個星向我下拜。」</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 27:29; 腓立比書 2:10–11; 以賽亞書 60:14"> 約瑟將這夢告訴他父親和他哥哥們，他父親就責備他說：「你做的這是甚麼夢！難道我和你母親、你弟兄果然要來俯伏在地，向你下拜嗎？」</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行傳 7:9; 路加福音 2:19; 路加福音 2:51"> 他哥哥們都嫉妒他，他父親卻把這話存在心裏。</span>
</div>
</div>

## 約瑟被賣到埃及

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="創世記 37:1; 創世記 33:18; 創世記 34:25–31"> 約瑟的哥哥們往示劍去放他們父親的羊。</span>
<span className="v" id="v13" data-v="13" data-xref="以弗所書 6:1–3; 撒母耳記上 3:8; 撒母耳記上 3:16"> 以色列對約瑟說：「你哥哥們不是在示劍放羊嗎？你來，我要打發你往他們那裏去。」約瑟說：「我在這裏。」</span>
<span className="v" id="v14" data-v="14" data-xref="創世記 35:27; 路加福音 19:42; 詩篇 125:5"> 以色列說：「你去看看你哥哥們平安不平安，群羊平安不平安，就回來報信給我」；於是打發他出希伯崙谷，他就往示劍去了。</span>
<span className="v" id="v15" data-v="15" data-xref="約翰福音 4:27; 士師記 4:22; 創世記 21:14"> 有人遇見他在田野走迷了路，就問他說：「你找甚麼？」</span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 19:10; 雅歌 1:7"> 他說：「我找我的哥哥們，求你告訴我，他們在何處放羊。」</span>
<span className="v" id="v17" data-v="17" data-xref="列王紀下 6:13"> 那人說：「他們已經走了，我聽見他們說要往多坍去。」約瑟就去追趕他哥哥們，遇見他們在多坍。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行傳 23:12; 詩篇 37:12; 詩篇 37:32"> 他們遠遠地看見他，趁他還沒有走到跟前，大家就同謀要害死他，</span>
<span className="v" id="v19" data-v="19" data-xref="創世記 28:12; 創世記 37:11; 創世記 37:5"> 彼此說：「你看！那做夢的來了。</span>
<span className="v" id="v20" data-v="20" data-xref="提多書 3:3; 箴言 27:4; 馬太福音 2:2–16"> 來吧！我們將他殺了，丟在一個坑裏，就說有惡獸把他吃了。我們且看他的夢將來怎麼樣。」</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 42:22; 創世記 35:22; 約書亞記 10:28"> 呂便聽見了，要救他脫離他們的手，說：「我們不可害他的性命」；</span>
<span className="v" id="v22" data-v="22" data-xref="創世記 22:12; 申命記 13:9; 創世記 42:22"> 又說：「不可流他的血，可以把他丟在這野地的坑裏，不可下手害他。」呂便的意思是要救他脫離他們的手，把他歸還他的父親。</span>
<span className="v" id="v23" data-v="23" data-xref="創世記 37:3; 馬太福音 27:28; 創世記 42:21"> 約瑟到了他哥哥們那裏，他們就剝了他的外衣，就是他穿的那件彩衣，</span>
<span className="v" id="v24" data-v="24" data-xref="耶利米書 38:6; 詩篇 130:1–2; 撒迦利亞書 9:11"> 把他丟在坑裏；那坑是空的，裏頭沒有水。</span>
<span className="v" id="v25" data-v="25" data-xref="創世記 37:28; 創世記 43:11; 耶利米書 8:22"> 他們坐下吃飯，舉目觀看，見有一夥米甸 的以實瑪利人從基列來，用駱駝馱着香料、乳香、沒藥，要帶下埃及去。</span>
<span className="v" id="v26" data-v="26" data-xref="創世記 37:20; 創世記 4:10; 創世記 25:32"> 猶大對眾弟兄說：「我們殺我們的兄弟，藏了他的血有甚麼益處呢？</span>
<span className="v" id="v27" data-v="27" data-xref="馬太福音 16:26; 創世記 42:21; 撒母耳記上 18:17"> 我們不如將他賣給以實瑪利人，不可下手害他；因為他是我們的兄弟，我們的骨肉。」眾弟兄就聽從了他。</span>
<span className="v" id="v28" data-v="28" data-xref="使徒行傳 7:9; 詩篇 105:17; 創世記 45:4–5"> 有些米甸的商人從那裏經過，哥哥們就把約瑟從坑裏拉上來，講定二十舍客勒銀子，把約瑟賣給以實瑪利人。他們就把約瑟帶到埃及去了。</span>
<span className="v" id="v29" data-v="29" data-xref="約伯記 1:20; 創世記 37:34; 創世記 44:13"> 呂便回到坑邊，見約瑟不在坑裏，就撕裂衣服，</span>
<span className="v" id="v30" data-v="30" data-xref="創世記 42:13; 耶利米書 31:15; 創世記 42:32"> 回到兄弟們那裏，說：「童子沒有了。我往哪裏去才好呢？」</span>
<span className="v" id="v31" data-v="31" data-xref="創世記 37:23; 箴言 28:13; 創世記 37:3"> 他們宰了一隻公山羊，把約瑟的那件彩衣染了血，</span>
<span className="v" id="v32" data-v="32" data-xref="路加福音 15:30; 創世記 37:3; 創世記 44:20–23"> 打發人送到他們的父親那裏，說：「我們撿了這個；請認一認是你兒子的外衣不是？」</span>
<span className="v" id="v33" data-v="33" data-xref="創世記 37:20; 創世記 44:28; 約翰福音 13:7"> 他認得，就說：「這是我兒子的外衣。有惡獸把他吃了，約瑟被撕碎了！撕碎了！」</span>
<span className="v" id="v34" data-v="34" data-xref="創世記 37:29; 撒母耳記下 3:31; 詩篇 69:11"> 雅各便撕裂衣服，腰間圍上麻布，為他兒子悲哀了多日。</span>
<span className="v" id="v35" data-v="35" data-xref="創世記 42:38; 約伯記 2:11; 撒母耳記下 12:17"> 他的兒女都起來安慰他，他卻不肯受安慰，說：「我必悲哀着下陰間，到我兒子那裏。」約瑟的父親就為他哀哭。</span>
<span className="v" id="v36" data-v="36" data-xref="創世記 40:4; 創世記 37:28; 列王紀下 25:8"> 米甸人帶約瑟到埃及，把他賣給法老的內臣－護衛長波提乏。</span>
</div>
</div>

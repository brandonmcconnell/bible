## 亞伯拉罕買墳地埋葬撒拉

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 17:17"> 撒拉享壽一百二十七歲，這是撒拉一生的歲數。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 23:19; 創世記 13:18; 歷代志上 6:57"> 撒拉死在迦南地的基列‧亞巴，就是希伯崙。亞伯拉罕為她哀慟哭號。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 10:15; 創世記 23:7; 撒母耳記上 26:6"> 後來亞伯拉罕從死人面前起來，對赫人說：</span>
<span className="v" id="v4" data-v="4" data-xref="歷代志上 29:15; 希伯來書 11:9; 創世記 17:8"> 「我在你們中間是外人，是寄居的。求你們在這裏給我一塊地，我好埋葬我的死人，使她不在我眼前。」</span>
<span className="v" id="v5" data-v="5"> 赫人回答亞伯拉罕說：</span>
<span className="v" id="v6" data-v="6" data-xref="創世記 24:35; 創世記 14:14; 出埃及記 32:22"> 「我主請聽。你在我們中間是一位尊大的王子，只管在我們最好的墳地裏埋葬你的死人；我們沒有一人不容你在他的墳地裏埋葬你的死人。」</span>
<span className="v" id="v7" data-v="7" data-xref="希伯來書 12:14; 創世記 19:1; 箴言 18:24"> 亞伯拉罕就起來，向那地的赫人下拜，</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 25:9; 約翰一書 2:1–2; 列王紀上 2:17"> 對他們說：「你們若有意叫我埋葬我的死人，使她不在我眼前，就請聽我的話，為我求瑣轄的兒子以弗崙，</span>
<span className="v" id="v9" data-v="9" data-xref="羅馬書 13:8; 羅馬書 12:17"> 把田頭上那麥比拉洞給我，他可以按着足價賣給我，作我在你們中間的墳地。」</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 34:20; 創世記 34:24; 創世記 23:18"> 當時以弗崙正坐在赫人中間。於是，赫人以弗崙在城門出入的赫人面前對亞伯拉罕說：</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 19:24; 以賽亞書 32:8; 申命記 19:15"> 「不然，我主請聽。我送給你這塊田，連田間的洞也送給你，在我同族的人面前都給你，可以埋葬你的死人。」</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 23:7; 創世記 18:2; 創世記 19:1"> 亞伯拉罕就在那地的人民面前下拜，</span>
<span className="v" id="v13" data-v="13" data-xref="羅馬書 13:8; 撒母耳記下 24:24; 創世記 14:22–23"> 在他們面前對以弗崙說：「你若應允，請聽我的話。我要把田價給你，求你收下，我就在那裏埋葬我的死人。」</span>
<span className="v" id="v14" data-v="14"> 以弗崙回答亞伯拉罕說：</span>
<span className="v" id="v15" data-v="15" data-xref="以西結書 45:12; 出埃及記 30:13; 出埃及記 30:15"> 「我主請聽。值四百舍客勒銀子的一塊田，在你我中間還算甚麼呢？只管埋葬你的死人吧！」</span>
<span className="v" id="v16" data-v="16" data-xref="撒迦利亞書 11:12; 耶利米書 32:9; 出埃及記 30:13"> 亞伯拉罕聽從了以弗崙，照着他在赫人面前所說的話，把買賣通用的銀子平了四百舍客勒給以弗崙。</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 25:9; 創世記 50:13; 創世記 23:20"> 於是，麥比拉、幔利前、以弗崙的那塊田和其中的洞，並田間四圍的樹木，</span>
<span className="v" id="v18" data-v="18" data-xref="路得記 4:1; 耶利米書 32:12; 創世記 34:20"> 都定準歸與亞伯拉罕，乃是他在赫人面前並城門出入的人面前買妥的。</span>
<span className="v" id="v19" data-v="19" data-xref="創世記 50:13; 傳道書 12:7; 傳道書 12:5"> 此後，亞伯拉罕把他妻子撒拉埋葬在迦南地幔利前的麥比拉田間的洞裏。（幔利就是希伯崙）。</span>
<span className="v" id="v20" data-v="20" data-xref="耶利米書 32:10–14; 路得記 4:7–10; 創世記 49:31–32"> 從此，那塊田和田間的洞就藉着赫人定準歸與亞伯拉罕作墳地。</span>

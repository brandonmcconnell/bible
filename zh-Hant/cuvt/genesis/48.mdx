## 雅各祝福以法蓮和瑪拿西

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 41:50–52; 創世記 46:20; 詩篇 128:6"> 這事以後，有人告訴約瑟說：「你的父親病了。」他就帶着兩個兒子瑪拿西和以法蓮同去。</span>
<span className="v" id="v2" data-v="2" data-xref="以弗所書 6:10; 撒母耳記上 23:16; 申命記 3:28"> 有人告訴雅各說：「請看，你兒子約瑟到你這裏來了。」以色列就勉強在床上坐起來。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 35:9–12; 出埃及記 6:3; 創世記 28:3"> 雅各對約瑟說：「全能的上帝曾在迦南地的路斯向我顯現，賜福與我，</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 17:8; 創世記 35:11; 創世記 26:4"> 對我說：『我必使你生養眾多，成為多民，又要把這地賜給你的後裔，永遠為業。』</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 41:50–52; 約書亞記 14:4; 創世記 46:20"> 我未到埃及見你之先，你在埃及地所生的以法蓮和瑪拿西這兩個兒子是我的，正如呂便和西緬是我的一樣。</span>
<span className="v" id="v6" data-v="6" data-xref="約書亞記 14:4"> 你在他們以後所生的就是你的，他們可以歸於他們弟兄的名下得產業。</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 35:16–19; 馬太福音 2:18; 創世記 35:9"> 至於我，我從巴旦來的時候，拉結死在我眼前，在迦南地的路上，離以法他還有一段路程，我就把她葬在以法他的路上（以法他就是伯利恆）。」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8"> 以色列看見約瑟的兩個兒子，就說：「這是誰？」</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 27:4; 創世記 33:5; 希伯來書 11:21"> 約瑟對他父親說：「這是上帝在這裏賜給我的兒子。」以色列說：「請你領他們到我跟前，我要給他們祝福。」</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 27:1; 創世記 27:27; 撒母耳記上 3:2"> 以色列年紀老邁，眼睛昏花，不能看見。約瑟領他們到他跟前，他就和他們親嘴，抱着他們。</span>
<span className="v" id="v11" data-v="11" data-xref="以弗所書 3:20; 創世記 45:26; 創世記 42:36"> 以色列對約瑟說：「我想不到得見你的面，不料，上帝又使我得見你的兒子。」</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 42:6; 利未記 19:32; 創世記 19:1"> 約瑟把兩個兒子從以色列兩膝中領出來，自己就臉伏於地下拜。</span>
<span className="v" id="v13" data-v="13"> 隨後，約瑟又拉着他們兩個，以法蓮在他的右手裏，對着以色列的左手，瑪拿西在他的左手裏，對着以色列的右手，領他們到以色列的跟前。</span>
<span className="v" id="v14" data-v="14" data-xref="創世記 41:51; 詩篇 118:16; 馬太福音 19:15"> 以色列伸出右手來，按在以法蓮的頭上（以法蓮乃是次子），又剪搭過左手來，按在瑪拿西的頭上（瑪拿西原是長子）。</span>
<span className="v" id="v15" data-v="15" data-xref="創世記 17:1; 歌羅西書 2:6; 以賽亞書 33:16"> 他就給約瑟祝福說：「願我祖亞伯拉罕和我父以撒所事奉的上帝，就是一生牧養我直到今日的上帝，</span>
<span className="v" id="v16" data-v="16" data-xref="詩篇 34:22; 創世記 49:22; 創世記 48:5"> 救贖我脫離一切患難的那使者，賜福與這兩個童子。願他們歸在我的名下和我祖亞伯拉罕、我父以撒的名下。又願他們在世界中生養眾多。」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="創世記 48:14; 羅馬書 9:7–8; 歷代志上 21:7"> 約瑟見他父親把右手按在以法蓮的頭上，就不喜悅，便提起他父親的手，要從以法蓮頭上挪到瑪拿西的頭上。</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 19:18; 創世記 29:26; 創世記 43:33"> 約瑟對他父親說：「我父，不是這樣。這本是長子，求你把右手按在他的頭上。」</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 33:17; 民數記 1:33–35; 創世記 25:28"> 他父親不從，說：「我知道，我兒，我知道。他也必成為一族，也必昌大。只是他的兄弟將來比他還大；他兄弟的後裔要成為多族。」</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 24:60; 路得記 4:11–12; 創世記 28:3"> 當日就給他們祝福說：「以色列人要指着你們祝福說：『願上帝使你如以法蓮、瑪拿西一樣。』」於是立以法蓮在瑪拿西以上。</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 50:24; 創世記 46:4; 創世記 28:15"> 以色列又對約瑟說：「我要死了，但上帝必與你們同在，領你們回到你們列祖之地。</span>
<span className="v" id="v22" data-v="22" data-xref="約翰福音 4:5; 約書亞記 24:32; 歷代志上 5:2"> 並且我從前用弓用刀從亞摩利人手下奪的那塊地，我都賜給你，使你比眾弟兄多得一分。」</span>
</div>
</div>

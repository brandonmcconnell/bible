## 耶路撒冷和列國

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以賽亞書 13:9; 以賽亞書 2:12; 以賽亞書 13:6"> 耶和華的日子臨近，你的財物必被搶掠，在你中間分散。</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 21:20–24; 以賽亞書 13:16; 羅馬書 9:27–29"> 因為我必聚集萬國與耶路撒冷爭戰，城必被攻取，房屋被搶奪，婦女被玷污，城中的民一半被擄去；剩下的民仍在城中，不致剪除。</span>
<span className="v" id="v3" data-v="3" data-xref="撒迦利亞書 12:9; 西番雅書 3:19; 撒迦利亞書 2:8–9"> 那時，耶和華必出去與那些國爭戰，好像從前爭戰一樣。</span>
<span className="v" id="v4" data-v="4" data-xref="彌迦書 1:3–4; 以西結書 11:23; 使徒行傳 1:11–12"> 那日，他的腳必站在耶路撒冷前面朝東的橄欖山上。這山必從中間分裂，自東至西成為極大的谷。山的一半向北挪移，一半向南挪移。</span>
<span className="v" id="v5" data-v="5" data-xref="猶大書 1:14–15; 阿摩司書 1:1; 馬太福音 25:31"> 你們要從我山的谷中逃跑，因為山谷必延到亞薩。你們逃跑，必如猶大王烏西雅年間的人逃避大地震一樣。耶和華－我的上帝必降臨，有一切聖者同來。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="詩篇 97:10–11; 詩篇 112:4; 約翰福音 12:46"> 那日，必沒有光，三光必退縮。</span>
<span className="v" id="v7" data-v="7" data-xref="啟示錄 22:5; 帖撒羅尼迦前書 5:2; 但以理書 12:4"> 那日，必是耶和華所知道的，不是白晝，也不是黑夜，到了晚上才有光明。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="啟示錄 22:1–2; 約翰福音 7:38; 約翰福音 4:14"> 那日，必有活水從耶路撒冷出來，一半往東海流，一半往西海流；冬夏都是如此。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="以弗所書 4:5–6; 啟示錄 11:15; 但以理書 7:27"> 耶和華必作全地的王。那日耶和華必為獨一無二的，他的名也是獨一無二的。</span>
<span className="v" id="v10" data-v="10" data-xref="撒迦利亞書 12:6; 約書亞記 15:32; 列王紀上 15:22"> 全地，從迦巴直到耶路撒冷南方的臨門，要變為亞拉巴。耶路撒冷必仍居高位，就是從便雅憫門到第一門之處，又到角門，並從哈楠業樓，直到王的酒醡。</span>
<span className="v" id="v11" data-v="11" data-xref="啟示錄 22:3; 耶利米書 23:5–6; 阿摩司書 9:15"> 人必住在其中，不再有咒詛。耶路撒冷人必安然居住。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="以西結書 39:17–20; 以賽亞書 66:15–16; 彌迦書 4:11–13"> 耶和華用災殃攻擊那與耶路撒冷爭戰的列國人，必是這樣：他們兩腳站立的時候，肉必消沒，眼在眶中乾癟，舌在口中潰爛。</span>
<span className="v" id="v13" data-v="13" data-xref="撒迦利亞書 12:4; 啟示錄 17:12–17; 士師記 7:22"> 那日，耶和華必使他們大大擾亂。他們各人彼此揪住，舉手攻擊。</span>
<span className="v" id="v14" data-v="14" data-xref="以賽亞書 23:18; 撒迦利亞書 12:2; 歷代志下 20:25–27"> 猶大也必在耶路撒冷爭戰。那時四圍各國的財物，就是許多金銀衣服，必被收聚。</span>
<span className="v" id="v15" data-v="15" data-xref="撒迦利亞書 14:12"> 那臨到馬匹、騾子、駱駝、驢，和營中一切牲畜的災殃是與那災殃一般。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="撒迦利亞書 14:17–19; 以賽亞書 66:23; 以賽亞書 66:18–21"> 所有來攻擊耶路撒冷列國中剩下的人，必年年上來敬拜大君王－萬軍之耶和華，並守住棚節。</span>
<span className="v" id="v17" data-v="17" data-xref="阿摩司書 4:7–8; 以賽亞書 60:12; 耶利米書 14:4"> 地上萬族中，凡不上耶路撒冷敬拜大君王－萬軍之耶和華的，必無雨降在他們的地上。</span>
<span className="v" id="v18" data-v="18" data-xref="撒迦利亞書 14:15; 申命記 11:10–11; 撒迦利亞書 14:12"> 埃及族若不上來，雨也不降在他們的地上；凡不上來守住棚節的列國人，耶和華也必用這災攻擊他們。</span>
<span className="v" id="v19" data-v="19" data-xref="約翰福音 3:19"> 這就是埃及的刑罰和那不上來守住棚節之列國的刑罰。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="哥林多前書 3:16–17; 出埃及記 39:30; 利未記 8:9"> 當那日，馬的鈴鐺上必有「歸耶和華為聖」的這句話。耶和華殿內的鍋必如祭壇前的碗一樣。</span>
<span className="v" id="v21" data-v="21" data-xref="以西結書 44:9; 羅馬書 14:6–7; 哥林多前書 10:31"> 凡耶路撒冷和猶大的鍋都必歸萬軍之耶和華為聖。凡獻祭的都必來取這鍋，煮肉在其中。當那日，在萬軍之耶和華的殿中必不再有迦南人。</span>
</div>
</div>

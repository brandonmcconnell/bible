## 金燈臺的異象

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="耶利米書 31:26; 但以理書 8:18; 撒迦利亞書 1:9"> 那與我說話的天使又來叫醒我，好像人睡覺被喚醒一樣。</span>
<span className="v" id="v2" data-v="2" data-xref="啟示錄 4:5; 啟示錄 1:12; 馬太福音 5:14–16"> 他問我說：「你看見了甚麼？」我說：「我看見了一個純金的燈臺，頂上有燈盞，燈臺上有七盞燈，每盞有七個管子。</span>
<span className="v" id="v3" data-v="3" data-xref="啟示錄 11:4; 撒迦利亞書 4:14; 羅馬書 11:17"> 旁邊有兩棵橄欖樹，一棵在燈盞的右邊，一棵在燈盞的左邊。」</span>
<span className="v" id="v4" data-v="4" data-xref="撒迦利亞書 6:4; 撒迦利亞書 1:9; 撒迦利亞書 1:19"> 我問與我說話的天使說：「主啊，這是甚麼意思？」</span>
<span className="v" id="v5" data-v="5" data-xref="撒迦利亞書 4:13; 撒迦利亞書 1:9; 但以理書 2:30"> 與我說話的天使回答我說：「你不知道這是甚麼意思嗎？」我說：「主啊，我不知道。」</span>

## 上帝給所羅巴伯的應許

<div className="bt">
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="歷代志下 32:7–8; 哥林多後書 10:4–5; 哥林多前書 2:4–5"> 他對我說：「這是耶和華指示所羅巴伯的。萬軍之耶和華說：不是倚靠勢力，不是倚靠才能，乃是倚靠我的靈方能成事。</span>
<span className="v" id="v7" data-v="7" data-xref="耶利米書 51:25; 撒迦利亞書 4:9; 彌迦書 4:1"> 大山哪，你算甚麼呢？在所羅巴伯面前，你必成為平地。他必搬出一塊石頭，安在殿頂上。人且大聲歡呼說：『願恩惠恩惠歸與這殿<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="殿：或譯石">a</a></sup>！』」</span>
<span className="v" id="v8" data-v="8"> 耶和華的話又臨到我說：</span>
<span className="v" id="v9" data-v="9" data-xref="以斯拉記 6:14–15; 撒迦利亞書 6:12–13; 撒迦利亞書 6:15"> 「所羅巴伯的手立了這殿的根基，他的手也必完成這工，你就知道萬軍之耶和華差遣我到你們這裏來了。</span>
<span className="v" id="v10" data-v="10" data-xref="約伯記 8:7; 哥林多前書 1:28–29; 歷代志下 16:9"> 誰藐視這日的事為小呢？這七眼乃是耶和華的眼睛，遍察全地，見所羅巴伯手拿線鉈就歡喜。」</span>
<span className="v" id="v11" data-v="11" data-xref="撒迦利亞書 4:3; 啟示錄 11:4"> 我又問天使說：「這燈臺左右的兩棵橄欖樹是甚麼意思？」</span>
<span className="v" id="v12" data-v="12" data-xref="啟示錄 11:4; 馬太福音 20:23; 哈該書 1:1"> 我二次問他說：「這兩根橄欖枝在兩個流出金色油的金嘴旁邊是甚麼意思？」</span>
<span className="v" id="v13" data-v="13" data-xref="撒迦利亞書 4:5; 希伯來書 5:11–12"> 他對我說：「你不知道這是甚麼意思嗎？」我說：「主啊，我不知道。」</span>
<span className="v" id="v14" data-v="14" data-xref="啟示錄 11:4; 以賽亞書 61:1–3; 但以理書 9:24–26"> 他說：「這是兩個受膏者站在普天下主的旁邊。」</span>
</div>

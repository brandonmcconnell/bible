## 耶路撒冷將蒙拯救

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以賽亞書 42:5; 耶利米書 51:15; 以賽亞書 57:16"> 耶和華論以色列的默示。 鋪張諸天、建立地基、造人裏面之靈的耶和華說：</span>
<span className="v" id="v2" data-v="2" data-xref="撒迦利亞書 14:14; 詩篇 75:8; 以賽亞書 51:22–23"> 「我必使耶路撒冷被圍困的時候，向四圍列國的民成為令人昏醉的杯；這默示也論到猶大<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或譯：猶大也是如此">a</a></sup>。</span>
<span className="v" id="v3" data-v="3" data-xref="馬太福音 21:44; 撒迦利亞書 14:2–4; 但以理書 2:34–35"> 那日，我必使耶路撒冷向聚集攻擊他的萬民當作一塊重石頭；凡舉起的必受重傷。</span>
<span className="v" id="v4" data-v="4" data-xref="申命記 28:28; 撒迦利亞書 12:3; 撒迦利亞書 12:6"> 耶和華說：到那日，我必使一切馬匹驚惶，使騎馬的顛狂。我必看顧猶大家，使列國的一切馬匹瞎眼。</span>
<span className="v" id="v5" data-v="5" data-xref="撒迦利亞書 10:12; 約珥書 3:16; 詩篇 18:32"> 猶大的族長必心裏說：『耶路撒冷的居民倚靠萬軍之耶和華－他們的上帝，就作我們的能力。』</span>
<span className="v" id="v6" data-v="6" data-xref="俄巴底亞書 1:18; 彌迦書 5:5–8; 撒迦利亞書 2:4"> 「那日，我必使猶大的族長如火盆在木柴中，又如火把在禾捆裏；他們必左右燒滅四圍列國的民。耶路撒冷人必仍住本處，就是耶路撒冷。</span>
<span className="v" id="v7" data-v="7" data-xref="耶利米書 30:18; 羅馬書 3:27; 路加福音 1:51–53"> 「耶和華必先拯救猶大的帳棚，免得大衛家的榮耀和耶路撒冷居民的榮耀勝過猶大。</span>
<span className="v" id="v8" data-v="8" data-xref="彌迦書 5:2–4; 撒迦利亞書 9:8; 約珥書 3:16–17"> 那日，耶和華必保護耶路撒冷的居民。他們中間軟弱的必如大衛；大衛的家必如上帝，如行在他們前面之耶和華的使者。</span>
<span className="v" id="v9" data-v="9" data-xref="以賽亞書 54:17; 撒迦利亞書 14:2–3; 哈該書 2:22"> 那日，我必定意滅絕來攻擊耶路撒冷各國的民。</span>
<span className="v" id="v10" data-v="10" data-xref="啟示錄 1:7; 以西結書 39:29; 約珥書 2:28–29"> 「我必將那施恩叫人懇求的靈，澆灌大衛家和耶路撒冷的居民。他們必仰望我<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或譯：他；本節同">b</a></sup>，就是他們所扎的；必為我悲哀，如喪獨生子，又為我愁苦，如喪長子。</span>
<span className="v" id="v11" data-v="11" data-xref="歷代志下 35:24; 列王紀下 23:29"> 那日，耶路撒冷必有大大的悲哀，如米吉多平原之哈達臨門的悲哀。</span>
<span className="v" id="v12" data-v="12" data-xref="撒迦利亞書 7:3; 路加福音 3:31; 撒母耳記下 5:14"> 境內一家一家地都必悲哀。大衛家，男的獨在一處，女的獨在一處。拿單家，男的獨在一處，女的獨在一處。</span>
<span className="v" id="v13" data-v="13" data-xref="歷代志上 23:7; 撒母耳記下 16:5; 歷代志上 23:10"> 利未家，男的獨在一處，女的獨在一處。示每家，男的獨在一處，女的獨在一處。</span>
<span className="v" id="v14" data-v="14" data-xref="箴言 9:12"> 其餘的各家，男的獨在一處，女的獨在一處。</span>
</div>

## 耶和華應許解救

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="雅各書 5:16–18; 馬太福音 7:7–8; 以賽亞書 44:3"> <span className="pl pl-1">當春雨的時候，</span><br /><span className="pl pl-1">你們要向發閃電的耶和華求雨。</span><br /><span className="pl pl-1">他必為眾人降下甘霖，</span><br /><span className="pl pl-1">使田園生長菜蔬。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="馬太福音 9:36; 耶利米書 27:9; 以西結書 34:5"> <span className="pl pl-1">因為，家神所言的是虛空；</span><br /><span className="pl pl-1">卜士所見的是虛假；</span><br /><span className="pl pl-1">做夢者所說的是假夢。</span><br /><span className="pl pl-1">他們白白地安慰人，</span><br /><span className="pl pl-1">所以眾人如羊流離，</span><br /><span className="pl pl-1">因無牧人就受苦。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v3" data-v="3" data-xref="以西結書 34:2; 以西結書 34:7–10; 耶利米書 23:1–2"> <span className="pl pl-1">我的怒氣向牧人發作；</span><br /><span className="pl pl-1">我必懲罰公山羊；</span><br /><span className="pl pl-1">因我－萬軍之耶和華</span><br /><span className="pl pl-1">眷顧自己的羊群，就是猶大家，</span><br /><span className="pl pl-1">必使他們如駿馬在陣上。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="撒迦利亞書 9:10; 撒迦利亞書 9:8; 民數記 24:17"> <span className="pl pl-1">房角石、釘子、爭戰的弓，</span><br /><span className="pl pl-1">和一切掌權的都從他而出。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="哈該書 2:22; 撒迦利亞書 9:13; 詩篇 20:7"> <span className="pl pl-1">他們必如勇士在陣上</span><br /><span className="pl pl-1">將仇敵踐踏在街上的泥土中。</span><br /><span className="pl pl-1">他們必爭戰，因為耶和華與他們同在；</span><br /><span className="pl pl-1">騎馬的也必羞愧。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="撒迦利亞書 13:9; 撒迦利亞書 10:12; 耶利米書 3:18"> <span className="pl pl-1">我要堅固猶大家，拯救約瑟家，</span><br /><span className="pl pl-1">要領他們歸回。</span><br /><span className="pl pl-1">我要憐恤他們；</span><br /><span className="pl pl-1">他們必像未曾棄絕的一樣，</span><br /><span className="pl pl-1">都因我是耶和華－他們的上帝，</span><br /><span className="pl pl-1">我必應允他們的禱告。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="撒迦利亞書 9:15; 撒迦利亞書 9:17; 撒母耳記上 2:1"> <span className="pl pl-1">以法蓮人必如勇士；</span><br /><span className="pl pl-1">他們心中暢快如同喝酒；</span><br /><span className="pl pl-1">他們的兒女必看見而快活；</span><br /><span className="pl pl-1">他們的心必因耶和華喜樂。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="以賽亞書 5:26; 以賽亞書 7:18; 耶利米書 33:22"> <span className="pl pl-1">我要發嘶聲，聚集他們，</span><br /><span className="pl pl-1">因我已經救贖他們。</span><br /><span className="pl pl-1">他們的人數必加增，</span><br /><span className="pl pl-1">如從前加增一樣。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="以西結書 6:9; 何西阿書 2:23; 以斯帖記 8:17"> <span className="pl pl-1">我雖然</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或譯：必">a</a></sup><br /><span className="pl pl-1">播散他們在列國中，</span><br /><span className="pl pl-1">他們必在遠方記念我。</span><br /><span className="pl pl-1">他們與兒女都必存活，且得歸回。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="何西阿書 11:11; 彌迦書 7:14; 撒迦利亞書 8:7"> <span className="pl pl-1">我必再領他們出埃及地，</span><br /><span className="pl pl-1">招聚他們出亞述，</span><br /><span className="pl pl-1">領他們到基列和黎巴嫩；</span><br /><span className="pl pl-1">這地尚且不夠他們居住。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="以西結書 30:13; 彌迦書 5:5–6; 以賽亞書 43:2"> <span className="pl pl-1">耶和華必經過苦海，擊打海浪，</span><br /><span className="pl pl-1">使尼羅河的深處都枯乾。</span><br /><span className="pl pl-1">亞述的驕傲必致卑微；</span><br /><span className="pl pl-1">埃及的權柄必然滅沒。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="以賽亞書 41:10; 以賽亞書 2:5; 撒迦利亞書 10:6"> <span className="pl pl-1">我必使他們倚靠我，得以堅固；</span><br /><span className="pl pl-1">一舉一動必奉我的名。</span><br /><span className="pl pl-1">這是耶和華說的。</span></span>
</div>

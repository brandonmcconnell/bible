## 耶和華應許復興耶路撒冷

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 萬軍之耶和華的話臨到我說：</span>
<span className="v" id="v2" data-v="2" data-xref="約珥書 2:18; 撒迦利亞書 1:14–16; 以賽亞書 42:13–14"> 「萬軍之耶和華如此說：我為錫安心裏極其火熱，我為她火熱，向她的仇敵發烈怒。</span>
<span className="v" id="v3" data-v="3" data-xref="撒迦利亞書 1:16; 撒迦利亞書 2:10–11; 約翰福音 1:14"> 耶和華如此說：我現在回到錫安，要住在耶路撒冷中。耶路撒冷必稱為誠實的城，萬軍之耶和華的山必稱為聖山。</span>
<span className="v" id="v4" data-v="4" data-xref="以賽亞書 65:20–22; 約伯記 5:26; 耶利米哀歌 5:11–15"> 萬軍之耶和華如此說：將來必有年老的男女坐在耶路撒冷街上，因為年紀老邁就手拿柺杖。</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米書 31:13; 馬太福音 11:16–17; 耶利米書 30:19–20"> 城中街上必滿有男孩女孩玩耍。</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米書 32:27; 羅馬書 4:20–21; 民數記 11:22–23"> 萬軍之耶和華如此說：到那日，這事在餘剩的民眼中看為希奇，在我眼中也看為希奇嗎？這是萬軍之耶和華說的。</span>
<span className="v" id="v7" data-v="7" data-xref="耶利米書 31:8; 羅馬書 11:25–27; 瑪拉基書 1:11"> 萬軍之耶和華如此說：我要從東方從西方救回我的民。</span>
<span className="v" id="v8" data-v="8" data-xref="以西結書 36:28; 以西結書 11:20; 耶利米書 31:33"> 我要領他們來，使他們住在耶路撒冷中。他們要作我的子民，我要作他們的上帝，都憑誠實和公義。」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="以賽亞書 35:4; 歷代志上 22:13; 以斯拉記 5:1–2"> 萬軍之耶和華如此說：「當建造萬軍之耶和華的殿，立根基之日的先知所說的話，現在你們聽見，應當手裏強壯。</span>
<span className="v" id="v10" data-v="10" data-xref="哈該書 1:6–11; 哈該書 2:16–18; 阿摩司書 3:6"> 那日以先，人得不着雇價，牲畜也是如此；且因敵人的緣故，出入之人不得平安，乃因我使眾人互相攻擊。</span>
<span className="v" id="v11" data-v="11" data-xref="以賽亞書 12:1; 哈該書 2:19; 撒迦利亞書 8:8–9"> 但如今，我待這餘剩的民必不像從前。這是萬軍之耶和華說的。</span>
<span className="v" id="v12" data-v="12" data-xref="利未記 26:4–5; 申命記 33:13; 創世記 27:28"> 因為他們必平安撒種，葡萄樹必結果子，地土必有出產，天也必降甘露。我要使這餘剩的民享受這一切的福。</span>
<span className="v" id="v13" data-v="13" data-xref="西番雅書 3:20; 撒迦利亞書 8:9; 詩篇 72:17"> 猶大家和以色列家啊，你們從前在列國中怎樣成為可咒詛的；照樣，我要拯救你們，使人稱你們為有福的<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或譯：使你們叫人得福">a</a></sup>。你們不要懼怕，手要強壯。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="耶利米書 31:28; 以西結書 24:14; 耶利米書 4:28"> 萬軍之耶和華如此說：「你們列祖惹我發怒的時候，我怎樣定意降禍，並不後悔。</span>
<span className="v" id="v15" data-v="15" data-xref="撒迦利亞書 8:13; 彌迦書 7:18–20; 路加福音 12:32"> 現在我照樣定意施恩與耶路撒冷和猶大家，你們不要懼怕。</span>
<span className="v" id="v16" data-v="16" data-xref="以弗所書 4:25; 撒迦利亞書 7:9; 詩篇 15:2"> 你們所當行的是這樣：各人與鄰舍說話誠實，在城門口按至理判斷，使人和睦。</span>
<span className="v" id="v17" data-v="17" data-xref="箴言 6:16–19; 彌迦書 2:1–3; 耶利米書 44:4"> 誰都不可心裏謀害鄰舍，也不可喜愛起假誓，因為這些事都為我所恨惡。這是耶和華說的。」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18"> 萬軍之耶和華的話臨到我說：</span>
<span className="v" id="v19" data-v="19" data-xref="撒迦利亞書 8:16; 耶利米書 39:2; 撒迦利亞書 7:5"> 「萬軍之耶和華如此說：四月、五月禁食的日子，七月、十月禁食的日子，必變為猶大家歡喜快樂的日子和歡樂的節期；所以你們要喜愛誠實與和平。」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="以賽亞書 2:2–3; 彌迦書 4:1–2; 撒迦利亞書 2:11"> 萬軍之耶和華如此說：「將來必有列國的人和多城的居民來到。</span>
<span className="v" id="v21" data-v="21" data-xref="撒迦利亞書 7:2; 何西阿書 6:3; 詩篇 146:1–2"> 這城的居民必到那城，說：『我們要快去懇求耶和華的恩，尋求萬軍之耶和華；我也要去。』</span>
<span className="v" id="v22" data-v="22" data-xref="撒迦利亞書 8:21; 以賽亞書 60:3–22; 啟示錄 21:24"> 必有列邦的人和強國的民來到耶路撒冷尋求萬軍之耶和華，懇求耶和華的恩。</span>
<span className="v" id="v23" data-v="23" data-xref="以賽亞書 55:5; 哥林多前書 14:25; 以賽亞書 60:3"> 萬軍之耶和華如此說：在那些日子，必有十個人從列國諸族<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原文是方言">b</a></sup>中出來，拉住一個猶大人的衣襟，說：『我們要與你們同去，因為我們聽見上帝與你們同在了。』」</span>
</div>

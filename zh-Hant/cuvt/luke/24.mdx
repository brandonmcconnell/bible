## 耶穌復活

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="約翰福音 20:1–2; 馬可福音 16:1–8; 馬太福音 28:1–8"> 七日的頭一日，黎明的時候，那些婦女帶着所預備的香料來到墳墓前，</span>
<span className="v" id="v2" data-v="2" data-xref="馬可福音 16:3–4; 馬太福音 27:60–66; 馬可福音 15:46–47"> 看見石頭已經從墳墓滾開了，</span>
<span className="v" id="v3" data-v="3" data-xref="路加福音 24:23; 約翰福音 20:6–7; 馬太福音 16:5"> 她們就進去，只是不見主耶穌的身體。</span>
<span className="v" id="v4" data-v="4" data-xref="馬可福音 16:5; 約翰福音 20:11–12; 使徒行傳 1:10"> 正在猜疑之間，忽然有兩個人站在旁邊，衣服放光。</span>
<span className="v" id="v5" data-v="5" data-xref="馬可福音 16:5–6; 馬太福音 28:3–5; 啟示錄 1:18"> 婦女們驚怕，將臉伏地。那兩個人就對她們說：「為甚麼在死人中找活人呢？</span>
<span className="v" id="v6" data-v="6" data-xref="馬太福音 17:22–23; 路加福音 9:22; 馬可福音 8:31"> 他不在這裏，已經復活了。當記念他還在加利利的時候怎樣告訴你們，</span>
<span className="v" id="v7" data-v="7" data-xref="馬太福音 16:21"> 說：『人子必須被交在罪人手裏，釘在十字架上，第三日復活。』」</span>
<span className="v" id="v8" data-v="8" data-xref="約翰福音 12:16; 約翰福音 14:26; 約翰福音 2:19–22"> 她們就想起耶穌的話來，</span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 24:22–24; 馬可福音 16:7–8; 馬太福音 28:7–8"> 便從墳墓那裏回去，把這一切的事告訴十一個使徒和其餘的人。</span>
<span className="v" id="v10" data-v="10" data-xref="馬太福音 27:56; 約翰福音 20:11–18; 路加福音 8:2–3"> 那告訴使徒的就是抹大拉的馬利亞和約亞拿，並雅各的母親馬利亞，還有與她們在一處的婦女。</span>
<span className="v" id="v11" data-v="11" data-xref="約伯記 9:16; 馬可福音 16:11; 創世記 19:14"> 她們這些話，使徒以為是胡言，就不相信。</span>
<span className="v" id="v12" data-v="12" data-xref="約翰福音 20:3–10"> 彼得起來，跑到墳墓前，低頭往裏看，見細麻布獨在一處，就回去了，心裏希奇所成的事。</span>
</div>
</div>

## 在以馬忤斯的路上

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="路加福音 24:18; 馬可福音 16:12–13"> 正當那日，門徒中有兩個人往一個村子去；這村子名叫以馬忤斯，離耶路撒冷約有二十五里。</span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 6:45; 申命記 6:7; 瑪拉基書 3:6"> 他們彼此談論所遇見的這一切事。</span>
<span className="v" id="v15" data-v="15" data-xref="馬太福音 18:20; 約翰福音 14:18–19; 路加福音 24:36"> 正談論相問的時候，耶穌親自就近他們，和他們同行；</span>
<span className="v" id="v16" data-v="16" data-xref="約翰福音 20:14; 約翰福音 21:4; 路加福音 24:31"> 只是他們的眼睛迷糊了，不認識他。</span>
<span className="v" id="v17" data-v="17" data-xref="約翰福音 16:20–22; 約翰福音 16:6; 以西結書 9:4–6"> 耶穌對他們說：「你們走路彼此談論的是甚麼事呢？」他們就站住，臉上帶着愁容。</span>
<span className="v" id="v18" data-v="18" data-xref="約翰福音 19:25"> 二人中有一個名叫革流巴的回答說：「你在耶路撒冷作客，還不知道這幾天在那裏所出的事嗎？」</span>
<span className="v" id="v19" data-v="19" data-xref="馬太福音 21:11; 使徒行傳 7:22; 約翰福音 4:19"> 耶穌說：「甚麼事呢？」他們說：「就是拿撒勒人耶穌的事。他是個先知，在上帝和眾百姓面前，說話行事都有大能。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行傳 3:13–15; 使徒行傳 4:8–10; 路加福音 23:13"> 祭司長和我們的官府竟把他解去，定了死罪，釘在十字架上。</span>
<span className="v" id="v21" data-v="21" data-xref="路加福音 1:68; 彼得前書 1:18–19; 路加福音 2:38"> 但我們素來所盼望、要贖以色列民的就是他！不但如此，而且這事成就，現在已經三天了。</span>
<span className="v" id="v22" data-v="22" data-xref="馬可福音 16:9–10; 馬太福音 28:7–8; 約翰福音 20:1–2"> 再者，我們中間有幾個婦女使我們驚奇；她們清早到了墳墓那裏，</span>
<span className="v" id="v23" data-v="23"> 不見他的身體，就回來告訴我們，說看見了天使顯現，說他活了。</span>
<span className="v" id="v24" data-v="24" data-xref="路加福音 24:12; 約翰福音 20:1–10"> 又有我們的幾個人往墳墓那裏去，所遇見的正如婦女們所說的，只是沒有看見他。」</span>
<span className="v" id="v25" data-v="25" data-xref="馬可福音 7:18; 馬可福音 9:19; 希伯來書 5:11–12"> 耶穌對他們說：「無知的人哪，先知所說的一切話，你們的心信得太遲鈍了。</span>
<span className="v" id="v26" data-v="26" data-xref="彼得前書 1:11; 以賽亞書 53:1–12; 撒迦利亞書 13:7"> 基督這樣受害，又進入他的榮耀，豈不是應當的嗎？」</span>
<span className="v" id="v27" data-v="27" data-xref="以賽亞書 7:14; 路加福音 24:44; 申命記 18:15"> 於是從摩西和眾先知起，凡經上所指着自己的話都給他們講解明白了。</span>
<span className="v" id="v28" data-v="28" data-xref="馬可福音 6:48; 創世記 19:2; 創世記 32:26"> 將近他們所去的村子，耶穌好像還要往前行，</span>
<span className="v" id="v29" data-v="29" data-xref="列王紀下 4:8; 路加福音 14:23; 創世記 19:3"> 他們卻強留他，說：「時候晚了，日頭已經平西了，請你同我們住下吧！」耶穌就進去，要同他們住下。</span>
<span className="v" id="v30" data-v="30" data-xref="馬太福音 14:19; 路加福音 24:35; 馬太福音 15:36"> 到了坐席的時候，耶穌拿起餅來，祝謝了，擘開，遞給他們。</span>
<span className="v" id="v31" data-v="31" data-xref="路加福音 24:16; 約翰福音 8:59; 路加福音 4:30"> 他們的眼睛明亮了，這才認出他來。忽然耶穌不見了。</span>
<span className="v" id="v32" data-v="32" data-xref="路加福音 24:45; 耶利米書 23:29; 希伯來書 4:12"> 他們彼此說：「在路上，他和我們說話，給我們講解聖經的時候，我們的心豈不是火熱的嗎？」</span>
<span className="v" id="v33" data-v="33" data-xref="馬可福音 16:13; 約翰福音 20:19–26; 使徒行傳 1:14"> 他們就立時起身，回耶路撒冷去，正遇見十一個使徒和他們的同人聚集在一處，</span>
<span className="v" id="v34" data-v="34" data-xref="哥林多前書 15:5; 馬可福音 16:7; 路加福音 22:54–62"> 說：「主果然復活，已經現給西門看了。」</span>
<span className="v" id="v35" data-v="35" data-xref="馬可福音 16:12–13; 使徒行傳 2:42; 路加福音 24:30–31"> 兩個人就把路上所遇見，和擘餅的時候怎麼被他們認出來的事，都述說了一遍。</span>
</div>
</div>

## 向門徒顯現

<div className="bt">
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="帖撒羅尼迦後書 3:16; 以賽亞書 57:18; 馬可福音 16:14"> 正說這話的時候，耶穌親自站在他們當中，說：「願你們平安！」</span>
<span className="v" id="v37" data-v="37" data-xref="撒母耳記上 28:13; 馬太福音 14:26–27; 約伯記 4:14–16"> 他們卻驚慌害怕，以為所看見的是魂。</span>
<span className="v" id="v38" data-v="38" data-xref="耶利米書 4:14; 希伯來書 4:13; 但以理書 4:19"> 耶穌說：「你們為甚麼愁煩？為甚麼心裏起疑念呢？</span>
<span className="v" id="v39" data-v="39" data-xref="約翰福音 20:27; 約翰一書 1:1; 傳道書 12:7"> 你們看我的手，我的腳，就知道實在是我了。摸我看看！魂無骨無肉，你們看，我是有的。」</span>
<span className="v" id="v40" data-v="40"> 說了這話，就把手和腳給他們看。</span>
<span className="v" id="v41" data-v="41" data-xref="約翰福音 21:5; 詩篇 126:1–2; 創世記 45:26–28"> 他們正喜得不敢信，並且希奇；耶穌就說：「你們這裏有甚麼吃的沒有？」</span>
<span className="v" id="v42" data-v="42"> 他們便給他一片燒魚。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古卷加：和一塊蜜房。">a</a></sup></span>
<span className="v" id="v43" data-v="43" data-xref="使徒行傳 10:41"> 他接過來，在他們面前吃了。</span>
<span className="v" id="v44" data-v="44" data-xref="撒迦利亞書 12:10; 路加福音 24:26–27; 撒迦利亞書 9:9"> 耶穌對他們說：「這就是我從前與你們同在之時所告訴你們的話說：摩西的律法、先知的書，和詩篇上所記的，凡指着我的話都必須應驗。」</span>
<span className="v" id="v45" data-v="45" data-xref="使徒行傳 16:14; 約翰一書 5:20; 詩篇 119:18"> 於是耶穌開他們的心竅，使他們能明白聖經，</span>
<span className="v" id="v46" data-v="46" data-xref="以賽亞書 53:2–12; 以賽亞書 50:6; 路加福音 24:44"> 又對他們說：「照經上所寫的，基督必受害，第三日從死裏復活，</span>
<span className="v" id="v47" data-v="47" data-xref="使徒行傳 5:31; 以賽亞書 49:6; 使徒行傳 2:38"> 並且人要奉他的名傳悔改、赦罪的道，從耶路撒冷起直傳到萬邦。</span>
<span className="v" id="v48" data-v="48" data-xref="使徒行傳 1:8; 使徒行傳 2:32; 使徒行傳 13:31"> 你們就是這些事的見證。</span>
<span className="v" id="v49" data-v="49" data-xref="使徒行傳 1:8; 使徒行傳 1:4; 約珥書 2:28–32"> 我要將我父所應許的降在你們身上，你們要在城裏等候，直到你們領受從上頭來的能力。」</span>
</div>
</div>

## 耶穌升天

<div className="bt">
<div className="bp">
<span className="v" id="v50" data-v="50" data-xref="使徒行傳 1:12; 馬太福音 21:17; 馬可福音 11:1"> 耶穌領他們到伯大尼的對面，就舉手給他們祝福。</span>
<span className="v" id="v51" data-v="51" data-xref="使徒行傳 1:9; 馬可福音 16:19; 列王紀下 2:11"> 正祝福的時候，他就離開他們，被帶到天上去了。</span>
<span className="v" id="v52" data-v="52" data-xref="馬太福音 28:9; 約翰福音 16:22; 詩篇 30:11"> 他們就拜他，大大地歡喜，回耶路撒冷去，</span>
<span className="v" id="v53" data-v="53" data-xref="馬可福音 16:20; 使徒行傳 2:46–47; 使徒行傳 5:41–42"> 常在殿裏稱頌上帝。</span>
</div>

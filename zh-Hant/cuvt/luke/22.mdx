## 殺害耶穌的陰謀

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及記 12:6–23; 馬太福音 26:2–5; 約翰福音 11:55–57"> 除酵節（又名逾越節）近了。</span>
<span className="v" id="v2" data-v="2" data-xref="約翰福音 11:47–53; 馬太福音 12:14; 路加福音 20:19"> 祭司長和文士想法子怎麼才能殺害耶穌，是因他們懼怕百姓。</span>
<span className="v" id="v3" data-v="3" data-xref="約翰福音 13:2; 馬可福音 14:10–11; 約翰福音 13:26–27"> 這時，撒但入了那稱為加略人猶大的心；他本是十二門徒裏的一個。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行傳 4:1; 使徒行傳 5:24; 路加福音 22:52"> 他去和祭司長並守殿官商量，怎麼可以把耶穌交給他們。</span>
<span className="v" id="v5" data-v="5" data-xref="馬太福音 26:15–16; 使徒行傳 1:18; 馬太福音 27:3–5"> 他們歡喜，就約定給他銀子。</span>
<span className="v" id="v6" data-v="6" data-xref="馬可福音 14:2; 馬太福音 26:5"> 他應允了，就找機會，要趁眾人不在跟前的時候把耶穌交給他們。</span>
</div>
</div>

## 預備逾越節的筵席

<div className="bt">
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="出埃及記 12:18; 馬可福音 14:12–16; 哥林多前書 5:7"> 除酵節，須宰逾越羊羔的那一天到了。</span>
<span className="v" id="v8" data-v="8" data-xref="馬可福音 14:13–16; 使徒行傳 4:19; 使徒行傳 4:13"> 耶穌打發彼得、約翰，說：「你們去為我們預備逾越節的筵席，好叫我們吃。」</span>
<span className="v" id="v9" data-v="9"> 他們問他說：「要我們在哪裏預備？」</span>
<span className="v" id="v10" data-v="10" data-xref="約翰福音 16:4; 馬太福音 26:18–19; 使徒行傳 8:26–29"> 耶穌說：「你們進了城，必有人拿着一瓶水迎面而來，你們就跟着他，到他所進的房子裏去，</span>
<span className="v" id="v11" data-v="11" data-xref="約翰福音 11:28; 啟示錄 3:20; 路加福音 19:34"> 對那家的主人說：『夫子說：客房在哪裏？我與門徒好在那裏吃逾越節的筵席。』</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行傳 16:14–15; 使徒行傳 1:13; 約翰福音 2:25"> 他必指給你們擺設整齊的一間大樓，你們就在那裏預備。」</span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 21:33; 路加福音 19:32; 約翰福音 2:5"> 他們去了，所遇見的正如耶穌所說的；他們就預備了逾越節的筵席。</span>
</div>
</div>

## 設立主的晚餐

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="馬太福音 26:20; 馬可福音 14:17; 申命記 16:6–7"> 時候到了，耶穌坐席，使徒也和他同坐。</span>
<span className="v" id="v15" data-v="15" data-xref="路加福音 12:50; 約翰福音 4:34; 約翰福音 17:1"> 耶穌對他們說：「我很願意在受害以先和你們吃這逾越節的筵席。</span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 14:15; 啟示錄 19:9; 路加福音 22:30"> 我告訴你們，我不再吃這筵席，直到成就在上帝的國裏。」</span>
<span className="v" id="v17" data-v="17" data-xref="路加福音 22:19; 詩篇 116:13; 申命記 8:10"> 耶穌接過杯來，祝謝了，說：「你們拿這個，大家分着喝。</span>
<span className="v" id="v18" data-v="18" data-xref="馬太福音 26:29; 路加福音 22:16; 馬可福音 14:25"> 我告訴你們，從今以後，我不再喝這葡萄汁，直等上帝的國來到。」</span>
<span className="v" id="v19" data-v="19" data-xref="哥林多前書 11:23–29; 哥林多前書 10:16; 馬可福音 14:22–24"> 又拿起餅來，祝謝了，就擘開，遞給他們，說：「這是我的身體，為你們捨的，你們也應當如此行，為的是記念我。」</span>
<span className="v" id="v20" data-v="20" data-xref="馬太福音 26:28; 哥林多前書 11:25; 撒迦利亞書 9:11"> 飯後也照樣拿起杯來，說：「這杯是用我血所立的新約，是為你們流出來的。</span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 41:9; 約翰福音 13:26; 約翰福音 13:21–22"> 看哪， 那賣我之人的手與我一同在桌子上。</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行傳 2:23; 詩篇 109:6–15; 詩篇 55:12–15"> 人子固然要照所預定的去世，但賣人子的人有禍了！」</span>
<span className="v" id="v23" data-v="23" data-xref="約翰福音 13:22–25; 馬可福音 14:19; 馬太福音 26:22"> 他們就彼此對問，是哪一個要做這事。</span>
</div>
</div>

## 爭論誰為大

<div className="bt">
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="路加福音 9:46; 馬可福音 9:34; 馬可福音 10:37–41"> 門徒起了爭論，他們中間哪一個可算為大。</span>
<span className="v" id="v25" data-v="25" data-xref="馬太福音 20:25–28; 馬可福音 10:41–45"> 耶穌說：「外邦人有君王為主治理他們，那掌權管他們的稱為恩主。</span>
<span className="v" id="v26" data-v="26" data-xref="彼得前書 5:5; 路加福音 9:48; 馬太福音 18:3–5"> 但你們不可這樣；你們裏頭為大的，倒要像年幼的，為首領的，倒要像服事人的。</span>
<span className="v" id="v27" data-v="27" data-xref="馬太福音 20:28; 路加福音 12:37; 約翰福音 13:5–16"> 是誰為大？是坐席的呢？是服事人的呢？不是坐席的大嗎？然而，我在你們中間如同服事人的。</span>
<span className="v" id="v28" data-v="28" data-xref="希伯來書 2:18; 希伯來書 4:15; 使徒行傳 1:25"> 我在磨煉之中，常和我同在的就是你們。</span>
<span className="v" id="v29" data-v="29" data-xref="馬太福音 25:34; 提摩太後書 2:12; 雅各書 2:5"> 我將國賜給你們，正如我父賜給我一樣，</span>
<span className="v" id="v30" data-v="30" data-xref="馬太福音 19:28; 馬太福音 8:11; 啟示錄 2:26–27"> 叫你們在我國裏，坐在我的席上吃喝，並且坐在寶座上，審判以色列十二個支派。」</span>
</div>
</div>

## 預言彼得不認主

<div className="bt">
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="彼得前書 5:8; 撒迦利亞書 3:1; 約伯記 1:6–12"> 主又說：「西門！西門！撒但想要得着你們，好篩你們像篩麥子一樣；</span>
<span className="v" id="v32" data-v="32" data-xref="彼得前書 5:8–10; 約翰福音 21:15–17; 約翰福音 17:9–11"> 但我已經為你祈求，叫你不至於失了信心。你回頭以後，要堅固你的弟兄。」</span>
<span className="v" id="v33" data-v="33" data-xref="馬可福音 14:31; 馬太福音 26:33–35; 馬可福音 14:29"> 彼得說：「主啊，我就是同你下監，同你受死，也是甘心！」</span>
<span className="v" id="v34" data-v="34" data-xref="約翰福音 13:38; 馬太福音 26:34; 馬可福音 14:30"> 耶穌說：「彼得，我告訴你，今日雞還沒有叫，你要三次說不認得我。」</span>
</div>
</div>

## 錢囊、口袋、刀

<div className="bt">
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="馬太福音 10:9–10; 路加福音 10:4; 詩篇 23:1"> 耶穌又對他們說：「我差你們出去的時候，沒有錢囊，沒有口袋，沒有鞋，你們缺少甚麼沒有？」他們說：「沒有。」</span>
<span className="v" id="v36" data-v="36" data-xref="馬太福音 10:22–25; 帖撒羅尼迦前書 3:4; 帖撒羅尼迦前書 2:14–15"> 耶穌說：「但如今有錢囊的可以帶着，有口袋的也可以帶着，沒有刀的要賣衣服買刀。</span>
<span className="v" id="v37" data-v="37" data-xref="以賽亞書 53:12; 路加福音 23:32; 哥林多後書 5:21"> 我告訴你們，經上寫着說：『他被列在罪犯之中。』這話必應驗在我身上，因為那關係我的事必然成就。」</span>
<span className="v" id="v38" data-v="38" data-xref="路加福音 22:49; 馬太福音 26:52–54; 約翰福音 18:36"> 他們說：「主啊，請看！這裏有兩把刀。」耶穌說：「夠了。」</span>
</div>
</div>

## 在橄欖山上禱告

<div className="bt">
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="路加福音 21:37; 約翰福音 18:1–2; 馬太福音 21:1"> 耶穌出來，照常往橄欖山去，門徒也跟隨他。</span>
<span className="v" id="v40" data-v="40" data-xref="馬太福音 6:13; 馬太福音 26:36–46; 路加福音 22:46"> 到了那地方，就對他們說：「你們要禱告，免得入了迷惑。」</span>
<span className="v" id="v41" data-v="41" data-xref="馬太福音 26:39; 馬可福音 14:35; 路加福音 18:11"> 於是離開他們約有扔一塊石頭那麼遠，跪下禱告，</span>
<span className="v" id="v42" data-v="42" data-xref="約翰福音 12:27–28; 馬太福音 26:39; 馬太福音 26:42"> 說：「父啊！你若願意，就把這杯撤去；然而，不要成就我的意思，只要成就你的意思。」</span>
<span className="v" id="v43" data-v="43" data-xref="馬太福音 4:11; 馬太福音 26:53; 詩篇 91:11–12"> 有一位天使從天上顯現，加添他的力量。</span>
<span className="v" id="v44" data-v="44" data-xref="耶利米哀歌 1:12; 希伯來書 5:7; 詩篇 22:12–21"> 耶穌極其傷痛，禱告更加懇切，汗珠如大血點滴在地上。</span>
<span className="v" id="v45" data-v="45" data-xref="馬可福音 14:40–41; 馬太福音 26:43; 馬太福音 26:40"> 禱告完了，就起來，到門徒那裏，見他們因為憂愁都睡着了，</span>
<span className="v" id="v46" data-v="46" data-xref="路加福音 22:40; 約拿書 1:6; 路加福音 21:34–36"> 就對他們說：「你們為甚麼睡覺呢？起來禱告，免得入了迷惑！」</span>
</div>
</div>

## 耶穌被捕

<div className="bt">
<div className="bp">
<span className="v" id="v47" data-v="47" data-xref="馬可福音 14:41–50; 約翰福音 18:2–11; 路加福音 22:3–6"> 說話之間，來了許多人。那十二個門徒裏名叫猶大的，走在前頭，就近耶穌，要與他親嘴。</span>
<span className="v" id="v48" data-v="48" data-xref="馬可福音 14:44–46; 撒母耳記下 20:9–10; 箴言 27:6"> 耶穌對他說：「猶大！你用親嘴的暗號賣人子嗎？」</span>
<span className="v" id="v49" data-v="49" data-xref="路加福音 22:38"> 左右的人見光景不好，就說：「主啊！我們拿刀砍可以不可以？」</span>
<span className="v" id="v50" data-v="50" data-xref="約翰福音 18:10–11; 馬可福音 14:47; 羅馬書 12:19"> 內中有一個人把大祭司的僕人砍了一刀，削掉了他的右耳。</span>
<span className="v" id="v51" data-v="51" data-xref="羅馬書 12:21; 哥林多後書 10:1; 彼得前書 2:21–23"> 耶穌說：「到了這個地步，由他們吧！」就摸那人的耳朵，把他治好了。</span>
<span className="v" id="v52" data-v="52" data-xref="路加福音 22:4; 馬可福音 14:48–49; 約翰福音 17:12"> 耶穌對那些來拿他的祭司長和守殿官並長老說：「你們帶着刀棒出來拿我，如同拿強盜嗎？</span>
<span className="v" id="v53" data-v="53" data-xref="約翰福音 12:27; 以弗所書 6:12; 使徒行傳 26:18"> 我天天同你們在殿裏，你們不下手拿我。現在卻是你們的時候，黑暗掌權了。」</span>
</div>
</div>

## 彼得三次不認主

<div className="bt">
<div className="bp">
<span className="v" id="v54" data-v="54" data-xref="馬可福音 14:53–54; 馬太福音 26:57–58; 約翰福音 18:12–17"> 他們拿住耶穌，把他帶到大祭司的宅裏。彼得遠遠地跟着。</span>
<span className="v" id="v55" data-v="55" data-xref="詩篇 26:4–5; 哥林多後書 6:15–17; 馬可福音 14:66–72"> 他們在院子裏生了火，一同坐着；彼得也坐在他們中間。</span>
<span className="v" id="v56" data-v="56" data-xref="約翰福音 18:17; 馬可福音 14:6; 馬可福音 14:17"> 有一個使女看見彼得坐在火光裏，就定睛看他，說：「這個人素來也是同那人一夥的。」</span>
<span className="v" id="v57" data-v="57" data-xref="約翰一書 1:9; 約翰福音 18:25; 馬太福音 26:70"> 彼得卻不承認，說：「女子，我不認得他。」</span>
<span className="v" id="v58" data-v="58" data-xref="約翰福音 18:25; 馬太福音 26:71–72; 馬可福音 14:69–70"> 過了不多的時候，又有一個人看見他，說：「你也是他們一黨的。」彼得說：「你這個人！我不是。」</span>
<span className="v" id="v59" data-v="59" data-xref="約翰福音 18:26–27; 馬可福音 14:69–70; 馬太福音 26:73–74"> 約過了一小時，又有一個人極力地說：「他實在是同那人一夥的，因為他也是加利利人。」</span>
<span className="v" id="v60" data-v="60" data-xref="馬太福音 26:74–75; 路加福音 22:34; 馬可福音 14:71–72"> 彼得說：「你這個人！我不曉得你說的是甚麼！」正說話之間，雞就叫了。</span>
<span className="v" id="v61" data-v="61" data-xref="路加福音 22:34; 以賽亞書 57:15–18; 耶利米書 31:18–20"> 主轉過身來看彼得，彼得便想起主對他所說的話：「今日雞叫以先，你要三次不認我。」</span>
<span className="v" id="v62" data-v="62" data-xref="馬太福音 26:75; 哥林多前書 10:12; 馬可福音 14:72"> 他就出去痛哭。</span>
</div>
</div>

<span className="v" id="v67" data-v="67" data-xref="馬太福音 11:3–5; 約翰福音 8:43–45; 馬太福音 26:63–68"> 說：「你若是基督，就告訴我們。」耶穌說：「我若告訴你們，你們也不信；</span>
<span className="v" id="v68" data-v="68" data-xref="路加福音 20:41–44; 路加福音 20:3–7"> 我若問你們，你們也不回答。</span>

<span className="v" id="v71" data-v="71" data-xref="馬太福音 26:65–66; 馬可福音 14:63–64"> 他們說：「何必再用見證呢？他親口所說的，我們都親自聽見了。」</span>

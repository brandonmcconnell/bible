## 不義的管家

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="彼得前書 4:10; 馬太福音 25:14–30; 雅各書 4:3"> 耶穌又對門徒說：「有一個財主的管家，別人向他主人告他浪費主人的財物。</span>
<span className="v" id="v2" data-v="2" data-xref="傳道書 11:9–10; 彼得前書 4:5; 啟示錄 20:12"> 主人叫他來，對他說：『我聽見你這事怎麼樣呢？把你所經管的交代明白，因你不能再作我的管家。』</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米書 5:31; 以賽亞書 10:3; 箴言 18:9"> 那管家心裏說：『主人辭我，不用我再作管家，我將來做甚麼？鋤地呢？無力；討飯呢？怕羞。</span>
<span className="v" id="v4" data-v="4" data-xref="箴言 30:9; 耶利米書 4:22; 雅各書 3:15"> 我知道怎麼行，好叫人在我不作管家之後，接我到他們家裏去。』</span>
<span className="v" id="v5" data-v="5" data-xref="路加福音 7:41–42; 馬太福音 18:24"> 於是把欠他主人債的，一個一個地叫了來，問頭一個說：『你欠我主人多少？』</span>
<span className="v" id="v6" data-v="6" data-xref="提多書 2:10; 路加福音 16:12; 路加福音 16:9"> 他說：『一百簍<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="每簍約五十斤">a</a></sup>油。』管家說：『拿你的帳，快坐下，寫五十。』</span>
<span className="v" id="v7" data-v="7" data-xref="雅歌 8:11–12; 路加福音 20:9; 路加福音 20:12"> 又問一個說：『你欠多少？』他說：『一百石麥子。』管家說：『拿你的帳，寫八十。』</span>
<span className="v" id="v8" data-v="8" data-xref="帖撒羅尼迦前書 5:5; 以弗所書 5:8; 箴言 6:6–8"> 主人就誇獎這不義的管家做事聰明；因為今世之子，在世事之上，較比光明之子更加聰明。</span>
<span className="v" id="v9" data-v="9" data-xref="馬太福音 19:21; 提摩太前書 6:17–19; 但以理書 4:27"> 我又告訴你們，要藉着那不義的錢財結交朋友，到了錢財無用的時候，他們可以接你們到永存的帳幕裏去。</span>
<span className="v" id="v10" data-v="10" data-xref="路加福音 16:11–12; 馬太福音 25:21; 路加福音 19:17"> 人在最小的事上忠心，在大事上也忠心；在最小的事上不義，在大事上也不義。</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 12:33; 雅各書 2:5; 箴言 8:18–19"> 倘若你們在不義的錢財上不忠心，誰還把那真實的錢財託付你們呢？</span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 19:13–26; 馬太福音 25:14–29; 約伯記 1:21"> 倘若你們在別人的東西上不忠心，誰還把你們自己的東西給你們呢？</span>
<span className="v" id="v13" data-v="13" data-xref="約翰一書 2:15–16; 馬太福音 6:24; 雅各書 4:4"> 一個僕人不能事奉兩個主；不是惡這個愛那個，就是重這個輕那個。你們不能又事奉上帝，又事奉瑪門。」</span>
</div>
</div>

## 律法和上帝的國

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="路加福音 23:35; 路加福音 20:47; 耶利米書 6:13"> 法利賽人是貪愛錢財的；他們聽見這一切話，就嗤笑耶穌。</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳記上 16:7; 箴言 21:2; 哥林多前書 4:5"> 耶穌對他們說：「你們是在人面前自稱為義的，你們的心，上帝卻知道；因為人所尊貴的，是上帝看為可憎惡的。</span>
<span className="v" id="v16" data-v="16" data-xref="馬太福音 11:9–14; 馬太福音 21:32; 使徒行傳 3:24–25"> 律法和先知到約翰為止，從此上帝國的福音傳開了，人人努力要進去。</span>
<span className="v" id="v17" data-v="17" data-xref="馬太福音 5:18; 路加福音 21:33; 彼得前書 1:25"> 天地廢去較比律法的一點一畫落空還容易。</span>
<span className="v" id="v18" data-v="18" data-xref="馬太福音 19:9; 馬可福音 10:11–12; 馬太福音 5:31–32"> 凡休妻另娶的就是犯姦淫；娶被休之妻的也是犯姦淫。」</span>
</div>
</div>

## 財主和拉撒路

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="以西結書 16:49; 阿摩司書 6:4–6; 路加福音 18:24–25"> 「有一個財主穿着紫色袍和細麻布衣服，天天奢華宴樂。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行傳 3:2; 撒母耳記上 2:8; 雅各書 2:5"> 又有一個討飯的，名叫拉撒路，渾身生瘡，被人放在財主門口，</span>
<span className="v" id="v21" data-v="21" data-xref="馬太福音 15:27; 馬可福音 7:28; 約翰福音 6:12"> 要得財主桌子上掉下來的零碎充飢，並且狗來舔他的瘡。</span>
<span className="v" id="v22" data-v="22" data-xref="彼得前書 2:24; 詩篇 49:16–19; 雅各書 1:11"> 後來那討飯的死了，被天使帶去放在亞伯拉罕的懷裏。財主也死了，並且埋葬了。</span>
<span className="v" id="v23" data-v="23" data-xref="彼得後書 2:4; 路加福音 16:28; 馬太福音 18:9"> 他在陰間受痛苦，舉目遠遠地望見亞伯拉罕，又望見拉撒路在他懷裏，</span>
<span className="v" id="v24" data-v="24" data-xref="約翰福音 4:10; 啟示錄 22:1; 啟示錄 7:16–17"> 就喊着說：『我祖亞伯拉罕哪，可憐我吧！打發拉撒路來，用指頭尖蘸點水，涼涼我的舌頭；因為我在這火焰裏，極其痛苦。』</span>
<span className="v" id="v25" data-v="25" data-xref="路加福音 6:24; 約翰一書 2:15; 詩篇 17:14"> 亞伯拉罕說：『兒啊，你該回想你生前享過福，拉撒路也受過苦；如今他在這裏得安慰，你倒受痛苦。</span>
<span className="v" id="v26" data-v="26" data-xref="約翰福音 3:36; 詩篇 49:14; 詩篇 50:22"> 不但這樣，並且在你我之間，有深淵限定，以致人要從這邊過到你們那邊是不能的；要從那邊過到我們這邊也是不能的。』</span>
<span className="v" id="v27" data-v="27"> 財主說：『我祖啊！既是這樣，求你打發拉撒路到我父家去；</span>
<span className="v" id="v28" data-v="28" data-xref="使徒行傳 2:40; 詩篇 49:12–13; 帖撒羅尼迦前書 4:6"> 因為我還有五個弟兄，他可以對他們作見證，免得他們也來到這痛苦的地方。』</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行傳 15:21; 路加福音 24:27; 路加福音 16:16"> 亞伯拉罕說：『他們有摩西和先知的話可以聽從。』</span>
<span className="v" id="v30" data-v="30" data-xref="啟示錄 16:9–11; 路加福音 16:24; 路加福音 13:5"> 他說：『我祖亞伯拉罕哪，不是的，若有一個從死裏復活的，到他們那裏去的，他們必要悔改。』</span>
<span className="v" id="v31" data-v="31" data-xref="哥林多後書 4:3; 使徒行傳 19:8; 約翰福音 11:43–53"> 亞伯拉罕說：『若不聽從摩西和先知的話，就是有一個從死裏復活的，他們也是不聽勸。』」</span>
</div>
</div>

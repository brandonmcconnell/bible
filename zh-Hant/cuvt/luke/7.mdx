## 治好百夫長的僕人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="馬太福音 8:5–13; 路加福音 7:1–10; 馬太福音 7:28–29"> 耶穌對百姓講完了這一切的話，就進了迦百農。</span>
<span className="v" id="v2" data-v="2" data-xref="列王紀下 5:2–3; 創世記 24:27; 約翰福音 4:46–47"> 有一個百夫長所寶貴的僕人害病，快要死了。</span>
<span className="v" id="v3" data-v="3" data-xref="馬太福音 8:5; 約翰福音 4:47; 路加福音 9:38"> 百夫長風聞耶穌的事，就託猶太人的幾個長老去求耶穌來救他的僕人。</span>
<span className="v" id="v4" data-v="4" data-xref="啟示錄 3:4; 馬太福音 10:11; 路加福音 7:6–7"> 他們到了耶穌那裏，就切切地求他說：「你給他行這事是他所配得的；</span>
<span className="v" id="v5" data-v="5" data-xref="歷代志下 2:11–12; 歷代志上 29:3–9; 列王紀上 5:1"> 因為他愛我們的百姓，給我們建造會堂。」</span>
<span className="v" id="v6" data-v="6" data-xref="馬可福音 5:24; 創世記 32:10; 雅各書 4:6"> 耶穌就和他們同去。離那家不遠，百夫長託幾個朋友去見耶穌，對他說：「主啊！不要勞動；因你到我舍下，我不敢當。</span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 107:20; 詩篇 33:9; 路加福音 4:36"> 我也自以為不配去見你，只要你說一句話，我的僕人就必好了。</span>
<span className="v" id="v8" data-v="8" data-xref="歌羅西書 3:22; 使徒行傳 23:17; 使徒行傳 22:25–26"> 因為我在人的權下，也有兵在我以下，對這個說：『去！』他就去；對那個說：『來！』他就來；對我的僕人說：『你做這事！』他就去做。」</span>
<span className="v" id="v9" data-v="9" data-xref="馬太福音 15:28; 羅馬書 3:1–3; 馬太福音 8:10"> 耶穌聽見這話，就希奇他，轉身對跟隨的眾人說：「我告訴你們，這麼大的信心，就是在以色列中，我也沒有遇見過。」</span>
<span className="v" id="v10" data-v="10" data-xref="約翰福音 4:50–53; 馬太福音 8:13; 馬太福音 15:28"> 那託來的人回到百夫長家裏，看見僕人已經好了。</span>
</div>
</div>

## 使拿因城寡婦之子復活

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="使徒行傳 10:38"> 過了不多時<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古卷：次日">a</a></sup>，耶穌往一座城去，這城名叫拿因，他的門徒和極多的人與他同行。</span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 8:42; 路加福音 8:52; 列王紀上 17:9"> 將近城門，有一個死人被抬出來。這人是他母親獨生的兒子；他母親又是寡婦。有城裏的許多人同着寡婦送殯。</span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 103:13; 以賽亞書 63:9; 詩篇 86:15"> 主看見那寡婦，就憐憫她，對她說：「不要哭！」</span>
<span className="v" id="v14" data-v="14" data-xref="約翰福音 5:25; 約翰福音 11:43–44; 使徒行傳 9:40–41"> 於是進前按着槓，抬的人就站住了。耶穌說：「少年人，我吩咐你，起來！」</span>
<span className="v" id="v15" data-v="15" data-xref="列王紀下 13:21; 列王紀下 4:32–37; 列王紀上 17:23–24"> 那死人就坐起，並且說話。耶穌便把他交給他母親。</span>
<span className="v" id="v16" data-v="16" data-xref="馬太福音 9:8; 路加福音 7:39; 路加福音 1:68"> 眾人都驚奇，歸榮耀與上帝，說：「有大先知在我們中間興起來了！」又說：「上帝眷顧了他的百姓！」</span>
<span className="v" id="v17" data-v="17" data-xref="馬太福音 4:24; 馬可福音 6:14; 馬太福音 9:26"> 他這事的風聲就傳遍了猶太和周圍地方。</span>
</div>
</div>

## 施洗約翰的門徒來見耶穌

<div className="bt">
<div className="bp poetry">
<span className="v" id="v18" data-v="18" data-xref="約翰福音 3:26; 馬太福音 11:2–19"> 約翰的門徒把這些事都告訴約翰。</span>
<span className="v" id="v19" data-v="19" data-xref="以賽亞書 9:6–7; 約翰福音 4:25; 創世記 22:18"> 他便叫了兩個門徒來，打發他們到主那裏去，說：「那將要來的是你嗎？還是我們等候別人呢？」</span>
<span className="v" id="v20" data-v="20" data-xref="路加福音 7:19"> 那兩個人來到耶穌那裏，說：「施洗的約翰打發我們來問你：『那將要來的是你嗎？還是我們等候別人呢？』」</span>
<span className="v" id="v21" data-v="21" data-xref="馬可福音 3:10; 詩篇 90:7–9; 希伯來書 12:6"> 正當那時候，耶穌治好了許多有疾病的，受災患的，被惡鬼附着的，又開恩叫好些瞎子能看見。</span>
<span className="v" id="v22" data-v="22" data-xref="以賽亞書 35:5–6; 以賽亞書 61:1–3; 路加福音 4:18"> 耶穌回答說：「你們去，把所看見所聽見的事告訴約翰，就是瞎子看見，瘸子行走，長大痲瘋的潔淨，聾子聽見，死人復活，窮人有福音傳給他們。</span>
<span className="v" id="v23" data-v="23" data-xref="馬太福音 11:6; 彼得前書 2:7–8; 羅馬書 9:32–33"> 凡不因我跌倒的，就有福了！」</span>
<span className="v" id="v24" data-v="24" data-xref="以弗所書 4:14; 約翰福音 1:23; 路加福音 1:80"> 約翰所差來的人既走了，耶穌就對眾人講論約翰說：「你們從前出去到曠野，是要看甚麼呢？要看風吹動的蘆葦嗎？</span>
<span className="v" id="v25" data-v="25" data-xref="以賽亞書 59:17; 以斯帖記 8:15; 以斯帖記 1:3"> 你們出去，到底是要看甚麼？要看穿細軟衣服的人嗎？那穿華麗衣服、宴樂度日的人是在王宮裏。</span>
<span className="v" id="v26" data-v="26" data-xref="路加福音 1:76; 約翰福音 5:35; 路加福音 20:6"> 你們出去，究竟是要看甚麼？要看先知嗎？我告訴你們，是的，他比先知大多了。</span>
<span className="v" id="v27" data-v="27" data-xref="瑪拉基書 3:1; 路加福音 1:76; 馬可福音 1:2"> 經上記着說：『我要差遣我的使者在你前面預備道路』，所說的就是這個人。</span>
<span className="v" id="v28" data-v="28" data-xref="馬太福音 13:16–17; 馬太福音 11:11; 歌羅西書 1:25–27"> 我告訴你們，凡婦人所生的，沒有一個大過約翰的；然而上帝國裏最小的比他還大。」</span>
<span className="v" id="v29" data-v="29" data-xref="路加福音 3:12; 路加福音 7:35; 使徒行傳 18:25"> 眾百姓和稅吏既受過約翰的洗，聽見這話，就以上帝為義；</span>
<span className="v" id="v30" data-v="30" data-xref="路加福音 13:34; 哥林多後書 6:1; 馬太福音 22:35"> 但法利賽人和律法師沒有受過約翰的洗，竟為自己廢棄了上帝的旨意。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="29－30兩節或譯：眾百姓和稅吏聽見了約翰的話，就受了他的洗，便以上帝為義；但法利賽人和律法師不受約翰的洗，竟為自己廢棄了上帝的旨意。">b</a></sup></span>
<span className="v" id="v31" data-v="31" data-xref="馬太福音 11:16–19; 耶利米哀歌 2:13; 馬可福音 4:30"> 主又說：「這樣，我可用甚麼比這世代的人呢？他們好像甚麼呢？</span>
<span className="v" id="v32" data-v="32" data-xref="馬太福音 11:16–19; 耶利米書 5:3–5; 箴言 17:16"> 好像孩童坐在街市上，彼此呼叫說：<br /><span className="pl pl-1">我們向你們吹笛，</span><br /><span className="pl pl-1">你們不跳舞；</span><br /><span className="pl pl-1">我們向你們舉哀，</span><br /><span className="pl pl-1">你們不啼哭。</span></span>
<span className="v" id="v33" data-v="33" data-xref="路加福音 1:15; 馬可福音 1:6; 約翰福音 8:52"> 施洗的約翰來，不吃餅，不喝酒，你們說他是被鬼附着的。</span>
<span className="v" id="v34" data-v="34" data-xref="路加福音 15:2; 路加福音 7:36; 約翰福音 12:2"> 人子來，也吃也喝，你們說他是貪食好酒的人，是稅吏和罪人的朋友。</span>
<span className="v" id="v35" data-v="35" data-xref="箴言 8:32–36; 馬太福音 11:19; 何西阿書 14:9"> 但智慧之子都以智慧為是。」</span>
</div>
</div>

## 有罪的女人得蒙赦免

<div className="bt">
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="馬可福音 14:3–9; 馬太福音 26:5–6; 路加福音 14:1"> 有一個法利賽人請耶穌和他吃飯；耶穌就到法利賽人家裏去坐席。</span>
<span className="v" id="v37" data-v="37" data-xref="馬可福音 14:3–9; 馬太福音 26:6–13; 馬太福音 21:31"> 那城裏有一個女人，是個罪人，知道耶穌在法利賽人家裏坐席，就拿着盛香膏的玉瓶，</span>
<span className="v" id="v38" data-v="38" data-xref="詩篇 126:5–6; 詩篇 51:17; 創世記 18:4"> 站在耶穌背後，挨着他的腳哭，眼淚濕了耶穌的腳，就用自己的頭髮擦乾，又用嘴連連親他的腳，把香膏抹上。</span>
<span className="v" id="v39" data-v="39" data-xref="路加福音 7:16; 路加福音 15:2; 馬可福音 7:21"> 請耶穌的法利賽人看見這事，心裏說：「這人若是先知，必知道摸他的是誰，是個怎樣的女人；乃是個罪人。」</span>
<span className="v" id="v40" data-v="40" data-xref="約翰福音 16:19; 路加福音 5:31; 以西結書 33:31"> 耶穌對他說：「西門！我有句話要對你說。」西門說：「夫子，請說。」</span>
<span className="v" id="v41" data-v="41" data-xref="路加福音 7:47; 羅馬書 5:20; 馬太福音 18:28"> 耶穌說：「一個債主有兩個人欠他的債；一個欠五十兩銀子，一個欠五兩銀子；</span>
<span className="v" id="v42" data-v="42" data-xref="但以理書 9:18–19; 歌羅西書 3:13; 羅馬書 3:24"> 因為他們無力償還，債主就開恩免了他們兩個人的債。這兩個人哪一個更愛他呢？」</span>
<span className="v" id="v43" data-v="43" data-xref="詩篇 116:16–18; 提摩太前書 1:13–16; 路加福音 7:47"> 西門回答說：「我想是那多得恩免的人。」耶穌說：「你斷的不錯。」</span>
<span className="v" id="v44" data-v="44" data-xref="提摩太前書 5:10; 士師記 19:21; 創世記 18:4"> 於是轉過來向着那女人，便對西門說：「你看見這女人嗎？我進了你的家，你沒有給我水洗腳；但這女人用眼淚濕了我的腳，用頭髮擦乾。</span>
<span className="v" id="v45" data-v="45" data-xref="撒母耳記下 15:5; 撒母耳記下 19:39; 羅馬書 16:16"> 你沒有與我親嘴；但這女人從我進來的時候就不住地用嘴親我的腳。</span>
<span className="v" id="v46" data-v="46" data-xref="詩篇 23:5; 傳道書 9:8; 馬太福音 6:17"> 你沒有用油抹我的頭；但這女人用香膏抹我的腳。</span>
<span className="v" id="v47" data-v="47" data-xref="約翰一書 4:19; 約翰一書 3:18; 以賽亞書 1:18"> 所以我告訴你，她許多的罪都赦免了，因為她的愛多；但那赦免少的，他的愛就少。」</span>
<span className="v" id="v48" data-v="48" data-xref="馬太福音 9:2; 馬可福音 2:5; 路加福音 5:20"> 於是對那女人說：「你的罪赦免了。」</span>
<span className="v" id="v49" data-v="49" data-xref="路加福音 5:20–21; 馬太福音 9:3; 馬可福音 2:7"> 同席的人心裏說：「這是甚麼人，竟赦免人的罪呢？」</span>
<span className="v" id="v50" data-v="50" data-xref="馬可福音 5:34; 路加福音 8:48; 路加福音 18:42"> 耶穌對那女人說：「你的信救了你；平平安安回去吧！」</span>
</div>

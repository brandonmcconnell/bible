## 耶穌受試探

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="馬太福音 4:1–11; 使徒行傳 10:38; 馬可福音 1:12–13"> 耶穌被聖靈充滿，從約旦河回來，聖靈將他引到曠野，</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 34:28; 希伯來書 4:15; 申命記 9:9"> 四十天受魔鬼的試探。那些日子沒有吃甚麼；日子滿了，他就餓了。</span>
<span className="v" id="v3" data-v="3" data-xref="馬太福音 4:3; 路加福音 3:22"> 魔鬼對他說：「你若是上帝的兒子，可以吩咐這塊石頭變成食物。」</span>
<span className="v" id="v4" data-v="4" data-xref="申命記 8:3; 馬太福音 4:4; 馬太福音 6:31"> 耶穌回答說：「經上記着說：『人活着不是單靠食物，乃是靠上帝口裏所出的一切話。』」</span>
<span className="v" id="v5" data-v="5" data-xref="約翰一書 2:15–16; 哥林多前書 15:52; 馬太福音 4:8"> 魔鬼又領他上了高山，霎時間把天下的萬國都指給他看，</span>
<span className="v" id="v6" data-v="6" data-xref="約翰福音 12:31; 約翰一書 5:19; 約翰福音 14:30"> 對他說：「這一切權柄、榮華，我都要給你，因為這原是交付我的，我願意給誰就給誰。</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 8:28; 詩篇 72:11; 以賽亞書 45:14"> 你若在我面前下拜，這都要歸你。」</span>
<span className="v" id="v8" data-v="8" data-xref="申命記 6:13; 申命記 10:20; 馬太福音 4:10"> 耶穌說：「經上記着說：<br /><span className="pl pl-1">當拜主－你的上帝，</span><br /><span className="pl pl-1">單要事奉他。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="馬太福音 4:5–6; 路加福音 4:3; 馬太福音 8:29"> 魔鬼又領他到耶路撒冷去，叫他站在殿頂<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="頂：原文是翅">a</a></sup>上，對他說：「你若是上帝的兒子，可以從這裏跳下去；</span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 91:11–12; 希伯來書 1:14; 哥林多後書 11:14"> 因為經上記着說：<br /><span className="pl pl-1">主要為你吩咐他的使者保護你；</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 91:12"> <span className="pl pl-1">他們要用手托着你，</span><br /><span className="pl pl-1">免得你的腳碰在石頭上。」</span></span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="申命記 6:16; 希伯來書 3:8–9; 哥林多前書 10:9"> 耶穌對他說：「經上說：『不可試探主－你的上帝。』」</span>
<span className="v" id="v13" data-v="13" data-xref="希伯來書 4:15; 雅各書 4:7; 馬太福音 4:11"> 魔鬼用完了各樣的試探，就暫時離開耶穌。</span>
</div>
</div>

## 開始在加利利傳道

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="馬太福音 4:23–25; 使徒行傳 10:37; 馬太福音 4:12"> 耶穌滿有聖靈的能力，回到加利利；他的名聲就傳遍了四方。</span>
<span className="v" id="v15" data-v="15" data-xref="馬太福音 4:23; 馬太福音 9:8; 馬太福音 9:35"> 他在各會堂裏教訓人，眾人都稱讚他。</span>
</div>
</div>

## 拿撒勒人厭棄耶穌

<div className="bt">
<div className="bp poetry">
<span className="v" id="v16" data-v="16" data-xref="使徒行傳 17:2; 使徒行傳 13:14–16; 馬太福音 2:23"> 耶穌來到拿撒勒，就是他長大的地方。在安息日，照他平常的規矩進了會堂，站起來要念聖經。</span>
<span className="v" id="v17" data-v="17" data-xref="以賽亞書 61:1–3; 使徒行傳 13:15; 使徒行傳 7:42"> 有人把先知以賽亞的書交給他，他就打開，找到一處寫着說：</span>
<span className="v" id="v18" data-v="18" data-xref="以賽亞書 61:1; 馬太福音 11:5; 詩篇 146:7–8"> <span className="pl pl-1">主的靈在我身上，</span><br /><span className="pl pl-1">因為他用膏膏我，</span><br /><span className="pl pl-1">叫我傳福音給貧窮的人；</span><br /><span className="pl pl-1">差遣我報告：</span><br /><span className="pl pl-1">被擄的得釋放，</span><br /><span className="pl pl-1">瞎眼的得看見，</span><br /><span className="pl pl-1">叫那受壓制的得自由，</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="以賽亞書 61:2; 以賽亞書 63:4; 哥林多後書 6:1"> <span className="pl pl-1">報告上帝悅納人的禧年。</span></span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="路加福音 4:17; 約翰福音 8:2; 路加福音 19:48"> 於是把書捲起來，交還執事，就坐下。會堂裏的人都定睛看他。</span>
<span className="v" id="v21" data-v="21" data-xref="約翰福音 4:25–26; 使徒行傳 3:18; 使徒行傳 2:16–18"> 耶穌對他們說：「今天這經應驗在你們耳中了。」</span>
<span className="v" id="v22" data-v="22" data-xref="馬太福音 13:54–56; 詩篇 45:2; 使徒行傳 6:10"> 眾人都稱讚他，並希奇他口中所出的恩言；又說：「這不是約瑟的兒子嗎？」</span>
<span className="v" id="v23" data-v="23" data-xref="約翰福音 4:46–53; 馬太福音 11:23–24; 馬可福音 2:1–12"> 耶穌對他們說：「你們必引這俗語向我說：『醫生，你醫治自己吧！我們聽見你在迦百農所行的事，也當行在你自己家鄉裏』」；</span>
<span className="v" id="v24" data-v="24" data-xref="馬太福音 13:57; 約翰福音 4:44; 馬可福音 6:4–5"> 又說：「我實在告訴你們，沒有先知在自己家鄉被人悅納的。</span>
<span className="v" id="v25" data-v="25" data-xref="雅各書 5:17; 列王紀上 17:1; 馬太福音 20:15"> 我對你們說實話，當以利亞的時候，天閉塞了三年零六個月，遍地有大饑荒，那時，以色列中有許多寡婦，</span>
<span className="v" id="v26" data-v="26" data-xref="列王紀上 17:9–24; 馬太福音 11:21; 俄巴底亞書 1:20"> 以利亞並沒有奉差往她們一個人那裏去，只奉差往西頓的撒勒法一個寡婦那裏去。</span>
<span className="v" id="v27" data-v="27" data-xref="列王紀下 5:1–27; 約翰福音 17:12; 馬太福音 12:4"> 先知以利沙的時候，以色列中有許多長大痲瘋的，但內中除了敘利亞國的乃縵，沒有一個得潔淨的。」</span>
<span className="v" id="v28" data-v="28" data-xref="使徒行傳 5:33; 歷代志下 24:20–21; 耶利米書 38:6"> 會堂裏的人聽見這話，都怒氣滿胸，</span>
<span className="v" id="v29" data-v="29" data-xref="約翰福音 8:59; 使徒行傳 21:28–32; 民數記 15:35"> 就起來攆他出城（他們的城造在山上）；他們帶他到山崖，要把他推下去。</span>
<span className="v" id="v30" data-v="30" data-xref="約翰福音 10:39; 約翰福音 8:59; 約翰福音 18:6–7"> 他卻從他們中間直行，過去了。</span>
</div>
</div>

## 一個污鬼附身的人

<div className="bt">
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="馬可福音 1:21–28; 馬太福音 4:13; 使徒行傳 13:50–2"> 耶穌下到迦百農，就是加利利的一座城，在安息日教訓眾人。</span>
<span className="v" id="v32" data-v="32" data-xref="路加福音 4:36; 馬太福音 7:28–29; 約翰福音 6:63"> 他們很希奇他的教訓，因為他的話裏有權柄。</span>
<span className="v" id="v33" data-v="33" data-xref="馬可福音 1:23"> 在會堂裏有一個人，被污鬼的精氣附着，大聲喊叫說：</span>
<span className="v" id="v34" data-v="34" data-xref="馬可福音 1:24; 雅各書 2:19; 馬太福音 8:29"> 「唉！拿撒勒的耶穌，我們與你有甚麼相干？你來滅我們嗎？我知道你是誰，乃是上帝的聖者。」</span>
<span className="v" id="v35" data-v="35" data-xref="路加福音 4:41; 路加福音 4:39; 馬太福音 8:26"> 耶穌責備他說：「不要作聲，從這人身上出來吧！」鬼把那人摔倒在眾人中間，就出來了，卻也沒有害他。</span>
<span className="v" id="v36" data-v="36" data-xref="路加福音 4:32; 彼得前書 3:22; 馬太福音 12:22–23"> 眾人都驚訝，彼此對問說：「這是甚麼道理呢？因為他用權柄能力吩咐污鬼，污鬼就出來。」</span>
<span className="v" id="v37" data-v="37" data-xref="馬可福音 1:45; 路加福音 4:14; 以賽亞書 52:13"> 於是耶穌的名聲傳遍了周圍地方。</span>
</div>
</div>

## 治好許多病人

<div className="bt">
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="馬太福音 8:14–15; 馬可福音 1:29–31; 約翰福音 11:22"> 耶穌出了會堂，進了西門的家。西門的岳母害熱病甚重，有人為她求耶穌。</span>
<span className="v" id="v39" data-v="39" data-xref="路加福音 4:41; 路加福音 4:35; 路加福音 8:24"> 耶穌站在她旁邊，斥責那熱病，熱就退了。她立刻起來服事他們。</span>
<span className="v" id="v40" data-v="40" data-xref="馬可福音 1:32–34; 馬太福音 8:16–17; 馬可福音 5:23"> 日落的時候，凡有病人的，不論害甚麼病，都帶到耶穌那裏。耶穌按手在他們各人身上，醫好他們。</span>
<span className="v" id="v41" data-v="41" data-xref="馬可福音 1:34; 雅各書 2:19; 路加福音 4:34–35"> 又有鬼從好些人身上出來，喊着說：「你是上帝的兒子。」耶穌斥責他們，不許他們說話，因為他們知道他是基督。</span>
</div>
</div>

## 在加利利各會堂傳道

<div className="bt">
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="路加福音 6:12; 馬可福音 1:35–38; 約翰福音 4:34"> 天亮的時候，耶穌出來，走到曠野地方。眾人去找他，到了他那裏，要留住他，不要他離開他們。</span>
<span className="v" id="v43" data-v="43" data-xref="馬可福音 1:38–39; 提摩太後書 4:2; 約翰福音 9:4"> 但耶穌對他們說：「我也必須在別城傳上帝國的福音，因我奉差原是為此。」</span>
<span className="v" id="v44" data-v="44" data-xref="馬太福音 4:23; 馬可福音 1:39; 路加福音 4:15"> 於是耶穌在加利利的各會堂傳道。</span>
</div>

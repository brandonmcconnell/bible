## 質問耶穌的權柄

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="馬太福音 21:23–27; 路加福音 19:47–48; 使徒行傳 6:12"> 有一天，耶穌在殿裏教訓百姓，講福音的時候，祭司長和文士並長老上前來，</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 2:14; 馬可福音 11:28–33; 約翰福音 2:18"> 問他說：「你告訴我們，你仗着甚麼權柄做這些事？給你這權柄的是誰呢？」</span>
<span className="v" id="v3" data-v="3" data-xref="馬太福音 15:2–3; 路加福音 22:68; 歌羅西書 4:6"> 耶穌回答說：「我也要問你們一句話，你們且告訴我。</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 15:18; 馬太福音 11:7–19; 馬太福音 17:11–12"> 約翰的洗禮是從天上來的？是從人間來的呢？」</span>
<span className="v" id="v5" data-v="5" data-xref="約翰福音 1:34; 約翰福音 1:15–18; 約翰福音 1:30"> 他們彼此商議說：「我們若說『從天上來』，他必說：『你們為甚麼不信他呢？』</span>
<span className="v" id="v6" data-v="6" data-xref="馬太福音 21:26; 馬太福音 11:9; 約翰福音 10:41"> 若說『從人間來』，百姓都要用石頭打死我們，因為他們信約翰是先知。」</span>
<span className="v" id="v7" data-v="7" data-xref="以賽亞書 29:14; 彼得後書 3:3; 以賽亞書 41:28"> 於是回答說：「不知道是從哪裏來的。」</span>
<span className="v" id="v8" data-v="8" data-xref="箴言 26:4–5; 馬太福音 21:27; 馬可福音 11:33"> 耶穌說：「我也不告訴你們，我仗着甚麼權柄做這些事。」</span>
</div>
</div>

## 凶惡園戶的比喻

<div className="bt">
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="馬太福音 21:33–46; 馬可福音 12:1–12; 以賽亞書 5:1–7"> 耶穌就設比喻對百姓說：「有人栽了一個葡萄園，租給園戶，就往外國去住了許久。</span>
<span className="v" id="v10" data-v="10" data-xref="歷代志下 36:15–16; 尼希米記 9:26; 馬太福音 21:34–36"> 到了時候，打發一個僕人到園戶那裏去，叫他們把園中當納的果子交給他；園戶竟打了他，叫他空手回去。</span>
<span className="v" id="v11" data-v="11" data-xref="何西阿書 10:1; 希伯來書 11:36–37; 帖撒羅尼迦前書 2:2"> 又打發一個僕人去，他們也打了他，並且凌辱他，叫他空手回去。</span>
<span className="v" id="v12" data-v="12"> 又打發第三個僕人去，他們也打傷了他，把他推出去了。</span>
<span className="v" id="v13" data-v="13" data-xref="馬太福音 3:17; 約翰福音 3:16–17; 耶利米書 36:7"> 園主說：『我怎麼辦呢？我要打發我的愛子去，或者他們尊敬他。』</span>
<span className="v" id="v14" data-v="14" data-xref="羅馬書 8:17; 希伯來書 1:2; 使徒行傳 2:23"> 不料，園戶看見他，就彼此商量說：『這是承受產業的，我們殺他吧，使產業歸於我們！』</span>
<span className="v" id="v15" data-v="15" data-xref="希伯來書 13:12; 馬可福音 12:6–9; 馬太福音 21:37–40"> 於是把他推出葡萄園外，殺了。這樣，葡萄園的主人要怎樣處治他們呢？</span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 19:27; 使徒行傳 13:46; 馬太福音 21:41"> 他要來除滅這些園戶，將葡萄園轉給別人。」聽見的人說：「這是萬不可的！」</span>
<span className="v" id="v17" data-v="17" data-xref="詩篇 118:22; 以賽亞書 28:16; 使徒行傳 4:11"> 耶穌看着他們說：「經上記着：<br /><span className="pl pl-1">匠人所棄的石頭</span><br /><span className="pl pl-1">已作了房角的頭塊石頭。</span><br />這是甚麼意思呢？</span>
<span className="v" id="v18" data-v="18" data-xref="以賽亞書 8:14–15; 撒迦利亞書 12:3; 但以理書 2:44–45"> 凡掉在那石頭上的，必要跌碎；那石頭掉在誰的身上，就要把誰砸得稀爛。」</span>
</div>
</div>

## 納稅給凱撒的問題

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="路加福音 19:47–48; 路加福音 20:14; 馬太福音 21:45–46"> 文士和祭司長看出這比喻是指着他們說的，當時就想要下手拿他，只是懼怕百姓。</span>
<span className="v" id="v20" data-v="20" data-xref="路加福音 11:54; 馬太福音 22:15–22; 馬太福音 27:2"> 於是窺探耶穌，打發奸細裝作好人，要在他的話上得把柄，好將他交在巡撫的政權之下。</span>
<span className="v" id="v21" data-v="21" data-xref="帖撒羅尼迦前書 2:4–5; 馬太福音 26:49–50; 馬太福音 22:16"> 奸細就問耶穌說：「夫子，我們曉得你所講所傳都是正道，也不取人的外貌，乃是誠誠實實傳上帝的道。</span>
<span className="v" id="v22" data-v="22" data-xref="尼希米記 9:37; 馬可福音 12:14–17; 使徒行傳 5:37"> 我們納稅給凱撒，可以不可以？」</span>
<span className="v" id="v23" data-v="23" data-xref="馬太福音 22:18; 哥林多前書 3:19; 路加福音 5:22"> 耶穌看出他們的詭詐，就對他們說：</span>
<span className="v" id="v24" data-v="24" data-xref="馬太福音 18:28; 使徒行傳 11:28; 使徒行傳 26:32"> 「拿一個銀錢來給我看。這像和這號是誰的？」他們說：「是凱撒的。」</span>
<span className="v" id="v25" data-v="25" data-xref="羅馬書 13:6–7; 馬可福音 12:17; 彼得前書 2:13–17"> 耶穌說：「這樣，凱撒的物當歸給凱撒，上帝的物當歸給上帝。」</span>
<span className="v" id="v26" data-v="26" data-xref="路加福音 20:20; 箴言 26:4–5; 提多書 1:10"> 他們當着百姓，在這話上得不着把柄，又希奇他的應對，就閉口無言了。</span>
</div>
</div>

## 復活的問題

<div className="bt">
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="使徒行傳 4:1–2; 哥林多前書 15:12; 馬可福音 12:18–27"> 撒都該人常說沒有復活的事。有幾個來問耶穌說：</span>
<span className="v" id="v28" data-v="28" data-xref="申命記 25:5–10; 創世記 38:8; 創世記 38:11"> 「夫子！摩西為我們寫着說：『人若有妻無子就死了，他兄弟當娶他的妻，為哥哥生子立後。』</span>
<span className="v" id="v29" data-v="29" data-xref="利未記 20:20; 耶利米書 22:30"> 有弟兄七人，第一個娶了妻，沒有孩子死了；</span>
<span className="v" id="v30" data-v="30"> 第二個、第三個也娶過她；</span>
<span className="v" id="v31" data-v="31"> 那七個人都娶過她，沒有留下孩子就死了。</span>
<span className="v" id="v32" data-v="32" data-xref="傳道書 1:4; 傳道書 9:5; 希伯來書 9:27"> 後來婦人也死了。</span>
<span className="v" id="v33" data-v="33" data-xref="馬太福音 22:24–28; 馬可福音 12:19–23"> 這樣，當復活的時候，她是哪一個的妻子呢？因為他們七個人都娶過她。」</span>
<span className="v" id="v34" data-v="34" data-xref="路加福音 16:8; 路加福音 17:27; 希伯來書 13:4"> 耶穌說：「這世界的人有娶有嫁；</span>
<span className="v" id="v35" data-v="35" data-xref="帖撒羅尼迦後書 1:5; 約翰福音 5:29; 但以理書 12:2–3"> 惟有算為配得那世界，與從死裏復活的人也不娶也不嫁；</span>
<span className="v" id="v36" data-v="36" data-xref="啟示錄 21:4; 腓立比書 3:21; 馬太福音 22:30"> 因為他們不能再死，和天使一樣；既是復活的人，就為上帝的兒子。</span>
<span className="v" id="v37" data-v="37" data-xref="出埃及記 3:2–6; 馬可福音 12:26–27; 使徒行傳 7:30–32"> 至於死人復活，摩西在荊棘篇上，稱主是亞伯拉罕的上帝，以撒的上帝，雅各的上帝，就指示明白了。</span>
<span className="v" id="v38" data-v="38" data-xref="約翰福音 11:25–26; 歌羅西書 3:3–4; 羅馬書 6:10–11"> 上帝原不是死人的上帝，乃是活人的上帝；因為在他那裏<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="那裏：或譯看來">a</a></sup>，人都是活的。」</span>
<span className="v" id="v39" data-v="39" data-xref="使徒行傳 23:9; 馬可福音 12:28–34; 馬太福音 22:34–40"> 有幾個文士說：「夫子！你說得好。」</span>
<span className="v" id="v40" data-v="40" data-xref="馬太福音 22:46; 馬可福音 12:34; 箴言 26:5"> 以後他們不敢再問他甚麼。</span>
</div>
</div>

## 譴責文士

<div className="bt">
<div className="bp">

<span className="v" id="v46" data-v="46" data-xref="路加福音 11:43; 馬可福音 12:38–39; 路加福音 14:7"> 「你們要防備文士。他們好穿長衣遊行，喜愛人在街市上問他們安，又喜愛會堂裏的高位，筵席上的首座；</span>
<span className="v" id="v47" data-v="47" data-xref="馬可福音 12:40; 雅各書 3:1; 提多書 1:16"> 他們侵吞寡婦的家產，假意作很長的禱告。這些人要受更重的刑罰！」</span>

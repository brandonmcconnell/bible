## 罪，信心，僕人的本分

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="馬太福音 18:7; 羅馬書 14:13; 哥林多前書 11:19"> 耶穌又對門徒說：「絆倒人的事是免不了的；但那絆倒人的有禍了。</span>
<span className="v" id="v2" data-v="2" data-xref="馬可福音 9:42; 馬太福音 18:14; 馬太福音 18:3–6"> 就是把磨石拴在這人的頸項上，丟在海裏，還強如他把這小子裏的一個絆倒了。</span>
<span className="v" id="v3" data-v="3" data-xref="利未記 19:17; 馬太福音 18:21; 馬太福音 18:15–17"> 你們要謹慎！若是你的弟兄得罪你，就勸戒他；他若懊悔，就饒恕他。</span>
<span className="v" id="v4" data-v="4" data-xref="歌羅西書 3:12–13; 馬太福音 18:21–22; 羅馬書 12:20"> 倘若他一天七次得罪你，又七次回轉，說：『我懊悔了』，你總要饒恕他。」</span>
<span className="v" id="v5" data-v="5" data-xref="馬可福音 9:24; 希伯來書 12:2; 腓立比書 4:13"> 使徒對主說：「求主加增我們的信心。」</span>
<span className="v" id="v6" data-v="6" data-xref="馬太福音 17:20; 馬太福音 21:21; 馬可福音 9:23"> 主說：「你們若有信心像一粒芥菜種，就是對這棵桑樹說：『你要拔起根來，栽在海裏』，它也必聽從你們。</span>
<span className="v" id="v7" data-v="7" data-xref="馬太福音 12:11; 路加福音 13:15; 路加福音 14:5"> 你們誰有僕人耕地或是放羊，從田裏回來，就對他說：『你快來坐下吃飯』呢？</span>
<span className="v" id="v8" data-v="8" data-xref="路加福音 12:37; 創世記 43:16; 撒母耳記下 12:20"> 豈不對他說：『你給我預備晚飯，束上帶子伺候我，等我吃喝完了，你才可以吃喝』嗎？</span>
<span className="v" id="v9" data-v="9"> 僕人照所吩咐的去做，主人還謝謝他嗎？</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多前書 9:16–17; 約伯記 22:2–3; 彼得前書 5:5–6"> 這樣，你們做完了一切所吩咐的，只當說：『我們是無用的僕人，所做的本是我們應分做的。』」</span>
</div>
</div>

## 治好十個長大痲瘋的

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="路加福音 9:51–52; 約翰福音 4:3–4"> 耶穌往耶路撒冷去，經過撒馬利亞和加利利。</span>
<span className="v" id="v12" data-v="12" data-xref="利未記 13:45–46; 路加福音 5:12; 列王紀下 7:3"> 進入一個村子，有十個長大痲瘋的，迎面而來，遠遠地站着，</span>
<span className="v" id="v13" data-v="13" data-xref="馬太福音 15:22; 馬太福音 20:30–31; 馬太福音 9:27"> 高聲說：「耶穌，夫子，可憐我們吧！」</span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 5:14; 利未記 13:1–46; 列王紀下 5:14"> 耶穌看見，就對他們說：「你們去把身體給祭司察看。」他們去的時候就潔淨了。</span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 30:11–12; 詩篇 103:1–4; 詩篇 118:18–19"> 內中有一個見自己已經好了，就回來大聲歸榮耀與上帝，</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行傳 8:5–25; 馬太福音 10:5; 啟示錄 19:10"> 又俯伏在耶穌腳前感謝他；這人是撒馬利亞人。</span>
<span className="v" id="v17" data-v="17" data-xref="羅馬書 1:21; 詩篇 106:13; 創世記 3:9"> 耶穌說：「潔淨了的不是十個人嗎？那九個在哪裏呢？</span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 50:23; 馬太福音 15:24–28; 詩篇 106:13"> 除了這外族人，再沒有別人回來歸榮耀與上帝嗎？」</span>
<span className="v" id="v19" data-v="19" data-xref="路加福音 7:50; 路加福音 8:48; 馬可福音 10:52"> 就對那人說：「起來，走吧！你的信救了你了。 」</span>
</div>
</div>

## 上帝國的來到

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="約翰福音 18:36; 路加福音 19:11; 但以理書 2:44"> 法利賽人問：「上帝的國幾時來到？」耶穌回答說：「上帝的國來到不是眼所能見的。</span>
<span className="v" id="v21" data-v="21" data-xref="馬太福音 12:28; 羅馬書 14:17; 馬可福音 13:21"> 人也不得說：『看哪，在這裏！看哪，在那裏！』因為上帝的國就在你們心裏<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="心裏：或譯中間">a</a></sup>。」</span>
<span className="v" id="v22" data-v="22" data-xref="路加福音 5:35; 馬太福音 9:15; 約翰福音 8:21–24"> 他又對門徒說：「日子將到，你們巴不得看見人子的一個日子，卻不得看見。</span>
<span className="v" id="v23" data-v="23" data-xref="路加福音 21:8; 馬太福音 24:23–26; 路加福音 17:21"> 人將要對你們說：『看哪，在那裏！看哪，在這裏！』你們不要出去，也不要跟隨他們！</span>
<span className="v" id="v24" data-v="24" data-xref="馬太福音 24:27; 馬太福音 24:30; 瑪拉基書 4:1–2"> 因為人子在他降臨的日子，好像閃電從天這邊一閃直照到天那邊。</span>
<span className="v" id="v25" data-v="25" data-xref="馬太福音 16:21; 路加福音 9:22; 馬可福音 8:31"> 只是他必須先受許多苦，又被這世代棄絕。</span>
<span className="v" id="v26" data-v="26" data-xref="馬太福音 24:37–39; 路加福音 17:24; 創世記 7:7–23"> 挪亞的日子怎樣，人子的日子也要怎樣。</span>
<span className="v" id="v27" data-v="27" data-xref="路加福音 12:19–20; 帖撒羅尼迦前書 5:1–3; 路加福音 16:19–23"> 那時候的人又吃又喝，又娶又嫁，到挪亞進方舟的那日，洪水就來，把他們全都滅了。</span>
<span className="v" id="v28" data-v="28" data-xref="以西結書 16:49–50; 創世記 18:20–21; 雅各書 5:1–5"> 又好像羅得的日子；人又吃又喝，又買又賣，又耕種又蓋造。</span>
<span className="v" id="v29" data-v="29" data-xref="彼得後書 2:6; 西番雅書 2:9; 猶大書 1:7"> 到羅得出所多瑪的那日，就有火與硫磺從天上降下來，把他們全都滅了。</span>
<span className="v" id="v30" data-v="30" data-xref="哥林多前書 1:7; 帖撒羅尼迦後書 1:7; 啟示錄 1:7"> 人子顯現的日子也要這樣。</span>
<span className="v" id="v31" data-v="31" data-xref="路加福音 21:21; 馬可福音 13:14–16; 耶利米書 45:5"> 當那日，人在房上，器具在屋裏，不要下來拿；人在田裏，也不要回家。</span>
<span className="v" id="v32" data-v="32" data-xref="創世記 19:26; 希伯來書 10:38–39; 彼得後書 2:18–22"> 你們要回想羅得的妻子。</span>
<span className="v" id="v33" data-v="33" data-xref="馬可福音 8:35–37; 馬太福音 10:39; 約翰福音 12:25"> 凡想要保全生命的，必喪掉生命；凡喪掉生命的，必救活生命。</span>
<span className="v" id="v34" data-v="34" data-xref="馬太福音 24:40–41; 彼得後書 2:9; 瑪拉基書 3:16–18"> 我對你們說，當那一夜，兩個人在一個床上，要取去一個，撇下一個。</span>
<span className="v" id="v35" data-v="35" data-xref="馬太福音 24:41; 出埃及記 11:5; 士師記 16:21"> 兩個女人一同推磨，要取去一個，撇下一個。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有古卷加：36兩個人在田裏，要取去一個，撇下一個。">b</a></sup>」</span>
<span className="v" id="v37" data-v="37" data-xref="馬太福音 24:28; 約伯記 39:29–30; 啟示錄 19:17–18"> 門徒說：「主啊，在哪裏有這事呢？」耶穌說：「屍首在哪裏，鷹也必聚在那裏。」</span>
</div>

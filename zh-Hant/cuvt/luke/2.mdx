## 耶穌降生

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 3:1; 馬太福音 24:14; 使徒行傳 25:21"> 當那些日子，凱撒奧古斯都有旨意下來，叫天下人民都報名上冊。</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 3:1; 馬太福音 4:24; 使徒行傳 26:30"> 這是居里扭作敘利亞巡撫的時候，頭一次行報名上冊的事。</span>
<span className="v" id="v3" data-v="3"> 眾人各歸各城，報名上冊。</span>
<span className="v" id="v4" data-v="4" data-xref="彌迦書 5:2; 約翰福音 7:42; 撒母耳記上 16:1"> 約瑟也從加利利的拿撒勒城上猶太去，到了大衛的城，名叫伯利恆，因他本是大衛一族一家的人，</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 22:22–27; 馬太福音 1:18–19"> 要和他所聘之妻馬利亞一同報名上冊。那時馬利亞的身孕已經重了。</span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 33:11; 啟示錄 12:1–5; 彌迦書 5:2"> 他們在那裏的時候，馬利亞的產期到了，</span>
<span className="v" id="v7" data-v="7" data-xref="加拉太書 4:4; 哥林多後書 8:9; 以賽亞書 53:2–3"> 就生了頭胎的兒子，用布包起來，放在馬槽裏，因為客店裏沒有地方。</span>
</div>
</div>

## 天使報喜訊給牧羊的人

<div className="bt">
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="創世記 31:39–40; 詩篇 78:70–71; 撒母耳記上 17:34–35"> 在伯利恆之野地裏有牧羊的人，夜間按着更次看守羊群。</span>
<span className="v" id="v9" data-v="9" data-xref="以賽亞書 60:1; 哥林多後書 3:18; 列王紀上 8:11"> 有主的使者站在他們旁邊，主的榮光四面照着他們；牧羊的人就甚懼怕。</span>
<span className="v" id="v10" data-v="10" data-xref="以賽亞書 40:9; 以賽亞書 61:1; 以賽亞書 52:7"> 那天使對他們說：「不要懼怕！我報給你們大喜的信息，是關乎萬民的；</span>
<span className="v" id="v11" data-v="11" data-xref="以賽亞書 9:6; 馬太福音 1:21; 使徒行傳 2:36"> 因今天在大衛的城裏，為你們生了救主，就是主基督。</span>
<span className="v" id="v12" data-v="12" data-xref="以賽亞書 7:14; 以賽亞書 53:1–2; 以賽亞書 7:11"> 你們要看見一個嬰孩，包着布，臥在馬槽裏，那就是記號了。」</span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 103:20–21; 啟示錄 5:11; 詩篇 148:2"> 忽然，有一大隊天兵同那天使讚美上帝說：</span>
<span className="v" id="v14" data-v="14" data-xref="羅馬書 5:1; 路加福音 19:38; 歌羅西書 1:20"> <span className="pl pl-1">在至高之處榮耀歸與上帝！</span><br /><span className="pl pl-1">在地上平安歸與他所喜悅的人</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古卷：喜悅歸與人">a</a></sup><br /><span className="pl pl-1">！</span></span>
<span className="v" id="v15" data-v="15" data-xref="彼得前書 3:22; 馬太福音 2:1–2; 馬太福音 2:9–11"> 眾天使離開他們，升天去了。牧羊的人彼此說：「我們往伯利恆去，看看所成的事，就是主所指示我們的。」</span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 19:32; 路加福音 2:12; 路加福音 2:7"> 他們急忙去了，就尋見馬利亞和約瑟，又有那嬰孩臥在馬槽裏；</span>
<span className="v" id="v17" data-v="17" data-xref="詩篇 66:16; 路加福音 8:39; 詩篇 71:17–18"> 既然看見，就把天使論這孩子的話傳開了。</span>
<span className="v" id="v18" data-v="18" data-xref="路加福音 2:47; 路加福音 4:36; 路加福音 1:65–66"> 凡聽見的，就詫異牧羊之人對他們所說的話。</span>
<span className="v" id="v19" data-v="19" data-xref="路加福音 2:51; 路加福音 1:66; 箴言 4:4"> 馬利亞卻把這一切的事存在心裏，反覆思想。</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 106:48; 以賽亞書 29:19; 使徒行傳 11:18"> 牧羊的人回去了，因所聽見所看見的一切事，正如天使向他們所說的，就歸榮耀與上帝，讚美他。</span>
<span className="v" id="v21" data-v="21" data-xref="路加福音 1:31; 創世記 17:12; 加拉太書 4:4–5"> 滿了八天，就給孩子行割禮，與他起名叫耶穌；這就是沒有成胎以前，天使所起的名。</span>
</div>
</div>

## 在聖殿裏獻與主

<div className="bt">
<div className="bp poetry">
<span className="v" id="v22" data-v="22" data-xref="利未記 12:1–8"> 按摩西律法滿了潔淨的日子，他們帶着孩子上耶路撒冷去，要把他獻與主，（</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及記 13:2; 出埃及記 22:29; 民數記 3:13"> 正如主的律法上所記：「凡頭生的男子必稱聖歸主。」）</span>
<span className="v" id="v24" data-v="24" data-xref="利未記 12:6–8; 利未記 12:2; 哥林多後書 8:9"> 又要照主的律法上所說，或用一對斑鳩，或用兩隻雛鴿獻祭。</span>
<span className="v" id="v25" data-v="25" data-xref="以賽亞書 25:9; 路加福音 2:38; 路加福音 1:6"> 在耶路撒冷有一個人，名叫西面；這人又公義又虔誠，素常盼望以色列的安慰者來到，又有聖靈在他身上。</span>
<span className="v" id="v26" data-v="26" data-xref="約翰福音 8:51; 希伯來書 11:5; 路加福音 9:27"> 他得了聖靈的啟示，知道自己未死以前，必看見主所立的基督。</span>
<span className="v" id="v27" data-v="27" data-xref="馬太福音 4:1; 路加福音 2:41; 路加福音 2:51"> 他受了聖靈的感動，進入聖殿，正遇見耶穌的父母抱着孩子進來，要照律法的規矩辦理。</span>
<span className="v" id="v28" data-v="28" data-xref="路加福音 1:64; 路加福音 2:20; 路加福音 2:13–14"> 西面就用手接過他來，稱頌上帝說：</span>
<span className="v" id="v29" data-v="29" data-xref="啟示錄 14:13; 創世記 15:15; 腓立比書 1:23"> <span className="pl pl-1">主啊！如今可以照你的話，</span><br /><span className="pl pl-1">釋放僕人安然去世；</span><br /></span>
<span className="v" id="v30" data-v="30" data-xref="以賽亞書 49:6; 路加福音 2:10–11; 路加福音 3:6"> <span className="pl pl-1">因為我的眼睛已經看見你的救恩－</span><br /></span>
<span className="v" id="v31" data-v="31" data-xref="以賽亞書 62:1–2; 以賽亞書 42:1–4; 詩篇 98:2–3"> <span className="pl pl-1">就是你在萬民面前所預備的：</span><br /></span>
<span className="v" id="v32" data-v="32" data-xref="以賽亞書 60:1–3; 以賽亞書 49:6; 使徒行傳 26:23"> <span className="pl pl-1">是照亮外邦人的光，</span><br /><span className="pl pl-1">又是你民以色列的榮耀。</span></span>
<span className="v" id="v33" data-v="33" data-xref="路加福音 1:65–66; 以賽亞書 8:18; 路加福音 2:48"> 孩子的父母因這論耶穌的話就希奇。</span>
<span className="v" id="v34" data-v="34" data-xref="哥林多前書 1:23; 彼得前書 2:7–8; 以賽亞書 8:14–15"> 西面給他們祝福，又對孩子的母親馬利亞說：「這孩子被立，是要叫以色列中許多人跌倒，許多人興起；又要作毀謗的話柄，叫許多人心裏的意念顯露出來；你自己的心也要被刀刺透。」</span>
<span className="v" id="v36" data-v="36" data-xref="出埃及記 15:20; 創世記 30:13; 使徒行傳 21:9"> 又有女先知，名叫亞拿，是亞設支派法內力的女兒，年紀已經老邁，從作童女出嫁的時候，同丈夫住了七年就寡居了，</span>
<span className="v" id="v37" data-v="37" data-xref="提摩太前書 5:5; 詩篇 23:6; 使徒行傳 14:23"> 現在已經八十四歲<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或譯：就寡居了八十四年">b</a></sup>，並不離開聖殿，禁食祈求，晝夜事奉上帝。</span>
<span className="v" id="v38" data-v="38" data-xref="路加福音 2:25; 哥林多後書 9:15; 馬可福音 15:43"> 正當那時，她進前來稱謝上帝，將孩子的事對一切盼望耶路撒冷得救贖的人講說。</span>
</div>
</div>

## 回拿撒勒

<div className="bt">
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="路加福音 2:4; 加拉太書 4:4–5; 申命記 12:32"> 約瑟和馬利亞照主的律法辦完了一切的事，就回加利利，到自己的城拿撒勒去了。</span>
<span className="v" id="v40" data-v="40" data-xref="路加福音 2:52; 路加福音 1:80; 以賽亞書 11:1–5"> 孩子漸漸長大，強健起來，充滿智慧，又有上帝的恩在他身上。</span>
</div>
</div>

## 孩童耶穌在聖殿裏

<div className="bt">
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="出埃及記 12:14; 民數記 28:16; 申命記 12:18"> 每年到逾越節，他父母就上耶路撒冷去。</span>
<span className="v" id="v42" data-v="42"> 當他十二歲的時候，他們按着節期的規矩上去。</span>
<span className="v" id="v43" data-v="43" data-xref="歷代志下 30:21–23; 出埃及記 12:15; 歷代志下 25:17"> 守滿了節期，他們回去，孩童耶穌仍舊在耶路撒冷。他的父母並不知道，</span>
<span className="v" id="v44" data-v="44" data-xref="詩篇 122:1–4; 以賽亞書 2:3; 詩篇 42:4"> 以為他在同行的人中間，走了一天的路程，就在親族和熟識的人中找他，</span>
<span className="v" id="v45" data-v="45"> 既找不着，就回耶路撒冷去找他。</span>
<span className="v" id="v46" data-v="46" data-xref="路加福音 5:17; 以賽亞書 49:1–2; 以賽亞書 50:4"> 過了三天，就遇見他在殿裏，坐在教師中間，一面聽，一面問。</span>
<span className="v" id="v47" data-v="47" data-xref="馬太福音 7:28; 路加福音 4:32; 詩篇 119:99"> 凡聽見他的，都希奇他的聰明和他的應對。</span>
<span className="v" id="v48" data-v="48" data-xref="路加福音 2:49; 馬太福音 12:46; 路加福音 3:23"> 他父母看見就很希奇。他母親對他說：「我兒！為甚麼向我們這樣行呢？看哪，你父親和我傷心來找你！」</span>
<span className="v" id="v49" data-v="49" data-xref="約翰福音 6:38; 約翰福音 8:29; 瑪拉基書 3:1"> 耶穌說：「為甚麼找我呢？豈不知我應當以我父的事為念嗎<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="或譯：豈不知我應當在我父的家裏嗎">c</a></sup>？」</span>
<span className="v" id="v50" data-v="50" data-xref="路加福音 18:34; 路加福音 9:45; 馬可福音 9:32"> 他所說的這話，他們不明白。</span>
<span className="v" id="v51" data-v="51" data-xref="路加福音 2:19; 但以理書 7:28; 創世記 37:11"> 他就同他們下去，回到拿撒勒，並且順從他們。他母親把這一切的事都存在心裏。</span>
<span className="v" id="v52" data-v="52" data-xref="路加福音 2:40; 箴言 3:3–4; 撒母耳記上 2:26"> 耶穌的智慧和身量<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="或譯：年紀">d</a></sup>，並上帝和人喜愛他的心，都一齊增長。</span>
</div>

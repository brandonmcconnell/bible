## 耶穌在彼拉多面前受審

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="馬太福音 27:1–2; 馬太福音 27:11–14; 路加福音 22:66"> 眾人都起來，把耶穌解到彼拉多面前，</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行傳 17:6–7; 約翰福音 19:12; 路加福音 23:14"> 就告他說：「我們見這人誘惑國民，禁止納稅給凱撒，並說自己是基督，是王。」</span>
<span className="v" id="v3" data-v="3" data-xref="約翰福音 1:49; 提摩太前書 6:13; 路加福音 22:70"> 彼拉多問耶穌說：「你是猶太人的王嗎？」耶穌回答說：「你說的是。」</span>
<span className="v" id="v4" data-v="4" data-xref="約翰福音 18:38; 路加福音 23:14–15; 路加福音 23:22"> 彼拉多對祭司長和眾人說：「我查不出這人有甚麼罪來。」</span>
<span className="v" id="v5" data-v="5" data-xref="馬可福音 1:14; 約翰福音 1:43; 約翰福音 2:11"> 但他們越發極力地說：「他煽惑百姓，在猶太遍地傳道，從加利利起，直到這裏了。」</span>
</div>
</div>

## 希律藐視耶穌

<div className="bt">
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="使徒行傳 5:37; 路加福音 13:1"> 彼拉多一聽見，就問：「這人是加利利人嗎？」</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 3:1; 路加福音 13:31; 馬太福音 14:1"> 既曉得耶穌屬希律所管，就把他送到希律那裏去。那時希律正在耶路撒冷。</span>
<span className="v" id="v8" data-v="8" data-xref="路加福音 9:7–9; 馬太福音 14:1; 馬可福音 6:14"> 希律看見耶穌，就很歡喜；因為聽見過他的事，久已想要見他，並且指望看他行一件神蹟，</span>
<span className="v" id="v9" data-v="9" data-xref="馬太福音 27:14; 馬太福音 7:6; 彼得前書 2:23"> 於是問他許多的話，耶穌卻一言不答。</span>
<span className="v" id="v10" data-v="10" data-xref="路加福音 11:53; 路加福音 23:14–15; 路加福音 23:5"> 祭司長和文士都站着，極力地告他。</span>
<span className="v" id="v11" data-v="11" data-xref="馬可福音 15:16–20; 馬太福音 27:27–30; 詩篇 69:19–20"> 希律和他的兵丁就藐視耶穌，戲弄他，給他穿上華麗衣服，把他送回彼拉多那裏去。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行傳 4:27; 啟示錄 17:13–14; 詩篇 83:4–6"> 從前希律和彼拉多彼此有仇，在那一天就成了朋友。</span>
</div>
</div>

## 耶穌被判死刑

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="馬可福音 15:14; 馬太福音 27:21–23; 約翰福音 18:38"> 彼拉多傳齊了祭司長和官府並百姓，</span>
<span className="v" id="v14" data-v="14" data-xref="但以理書 6:4; 希伯來書 7:26; 路加福音 23:1–2"> 就對他們說：「你們解這人到我這裏，說他是誘惑百姓的。看哪，我也曾將你們告他的事，在你們面前審問他，並沒有查出他甚麼罪來；</span>
<span className="v" id="v15" data-v="15"> 就是希律也是如此，所以把他送回來。可見他沒有做甚麼該死的事。</span>
<span className="v" id="v16" data-v="16" data-xref="馬太福音 27:26; 路加福音 23:22; 馬可福音 15:15"> 故此，我要責打他，把他釋放了。」<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古卷加：17每逢這節期，巡撫必須釋放一個囚犯給他們。">a</a></sup></span>
<span className="v" id="v18" data-v="18" data-xref="使徒行傳 21:36; 使徒行傳 3:14; 使徒行傳 22:22"> 眾人卻一齊喊着說：「除掉這個人！釋放巴拉巴給我們！」</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行傳 3:14; 路加福音 23:5; 路加福音 23:2"> 這巴拉巴是因在城裏作亂殺人，下在監裏的。</span>
<span className="v" id="v20" data-v="20" data-xref="馬可福音 15:15; 馬太福音 14:8–9; 馬太福音 27:19"> 彼拉多願意釋放耶穌，就又勸解他們。</span>
<span className="v" id="v21" data-v="21" data-xref="馬太福音 27:22–25; 馬可福音 15:13; 約翰福音 19:15"> 無奈他們喊着說：「釘他十字架！釘他十字架！」</span>
<span className="v" id="v22" data-v="22" data-xref="路加福音 23:14; 路加福音 23:20; 彼得前書 3:18"> 彼拉多第三次對他們說：「為甚麼呢？這人做了甚麼惡事呢？我並沒有查出他甚麼該死的罪來。所以，我要責打他，把他釋放了。」</span>
<span className="v" id="v23" data-v="23" data-xref="撒迦利亞書 11:8; 詩篇 57:4; 詩篇 22:12–13"> 他們大聲催逼彼拉多，求他把耶穌釘在十字架上。他們的聲音就得了勝。</span>
<span className="v" id="v24" data-v="24" data-xref="馬太福音 27:26; 出埃及記 23:2; 箴言 17:15"> 彼拉多這才照他們所求的定案，</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行傳 3:14; 馬可福音 15:6–7; 馬可福音 15:15"> 把他們所求的那作亂殺人、下在監裏的釋放了，把耶穌交給他們，任憑他們的意思行。</span>
</div>
</div>

## 耶穌被釘十字架

<div className="bt">
<div className="bp poetry">
<span className="v" id="v26" data-v="26" data-xref="馬太福音 27:32–44; 馬可福音 15:21–32; 使徒行傳 6:9"> 帶耶穌去的時候，有一個古利奈人西門，從鄉下來；他們就抓住他，把十字架擱在他身上，叫他背着跟隨耶穌。</span>
<span className="v" id="v27" data-v="27" data-xref="路加福音 8:52; 路加福音 8:2; 馬可福音 15:40"> 有許多百姓跟隨耶穌，內中有好些婦女；婦女們為他號咷痛哭。</span>
<span className="v" id="v28" data-v="28" data-xref="雅歌 8:4; 雅歌 5:8; 雅歌 1:5"> 耶穌轉身對她們說：「耶路撒冷的女子，不要為我哭，當為自己和自己的兒女哭。</span>
<span className="v" id="v29" data-v="29" data-xref="馬太福音 24:19; 路加福音 21:23–24; 馬可福音 13:17–19"> 因為日子要到，人必說：『不生育的，和未曾懷胎的，未曾乳養嬰孩的，有福了！』</span>
<span className="v" id="v30" data-v="30" data-xref="啟示錄 6:16; 何西阿書 10:8; 以賽亞書 2:19"> 那時，人要向大山說：<br /><span className="pl pl-1">倒在我們身上！</span><br /><span className="pl pl-1">向小山說：</span><br /><span className="pl pl-1">遮蓋我們！</span></span>
<span className="v" id="v31" data-v="31" data-xref="彼得前書 4:17–18; 約翰福音 15:6; 箴言 11:31"> 「這些事既行在有汁水的樹上，那枯乾的樹將來怎麼樣呢？」</span>
<span className="v" id="v32" data-v="32" data-xref="馬可福音 15:27; 以賽亞書 53:12; 馬太福音 27:38"> 又有兩個犯人，和耶穌一同帶來處死。</span>
<span className="v" id="v33" data-v="33" data-xref="馬可福音 15:22–23; 約翰福音 19:17–18; 約翰福音 18:32"> 到了一個地方，名叫「髑髏地」，就在那裏把耶穌釘在十字架上，又釘了兩個犯人：一個在左邊，一個在右邊。</span>
<span className="v" id="v34" data-v="34" data-xref="馬太福音 5:44; 使徒行傳 7:60; 彼得前書 3:9"> 當下耶穌說：「父啊！赦免他們；因為他們所做的，他們不曉得。」兵丁就拈鬮分他的衣服。</span>
<span className="v" id="v35" data-v="35" data-xref="詩篇 22:17; 以賽亞書 42:1; 彼得前書 2:4"> 百姓站在那裏觀看。官府也嗤笑他，說：「他救了別人；他若是基督，上帝所揀選的，可以救自己吧！」</span>
<span className="v" id="v36" data-v="36" data-xref="詩篇 69:21; 馬太福音 27:48; 馬太福音 27:34"> 兵丁也戲弄他，上前拿醋送給他喝，</span>
<span className="v" id="v37" data-v="37"> 說：「你若是猶太人的王，可以救自己吧！」</span>
<span className="v" id="v38" data-v="38" data-xref="馬可福音 15:26; 馬太福音 27:37; 約翰福音 19:19–22"> 在耶穌以上有一個牌子<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有古卷加：用希臘、羅馬、希伯來的文字">b</a></sup>寫着：「這是猶太人的王。」</span>
<span className="v" id="v39" data-v="39" data-xref="馬太福音 27:44; 馬可福音 15:32; 路加福音 23:35"> 那同釘的兩個犯人有一個譏笑他，說：「你不是基督嗎？可以救自己和我們吧！」</span>
<span className="v" id="v40" data-v="40" data-xref="以弗所書 5:11; 路加福音 12:5; 啟示錄 15:4"> 那一個就應聲責備他，說：「你既是一樣受刑的，還不怕上帝嗎？</span>
<span className="v" id="v41" data-v="41" data-xref="利未記 26:40–41; 以斯拉記 9:13; 彼得前書 1:19"> 我們是應該的，因我們所受的與我們所做的相稱，但這個人沒有做過一件不好的事。」</span>
<span className="v" id="v42" data-v="42" data-xref="羅馬書 10:9–14; 使徒行傳 16:31; 約翰一書 5:11–13"> 就說：「耶穌啊，你得國降臨的時候，求你記念我！」</span>
<span className="v" id="v43" data-v="43" data-xref="啟示錄 2:7; 詩篇 50:15; 提摩太前書 1:15–16"> 耶穌對他說：「我實在告訴你，今日你要同我在樂園裏了。」</span>
</div>
</div>

## 耶穌的死

<div className="bt">
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="馬太福音 27:45; 馬可福音 15:33–34; 阿摩司書 8:9"> 那時約有午正，遍地都黑暗了，直到申初，</span>
<span className="v" id="v45" data-v="45" data-xref="希伯來書 10:19–22; 馬太福音 27:51; 希伯來書 9:3–8"> 日頭變黑了；殿裏的幔子從當中裂為兩半。</span>
<span className="v" id="v46" data-v="46" data-xref="詩篇 31:5; 使徒行傳 7:59; 約翰福音 19:30"> 耶穌大聲喊着說：「父啊！我將我的靈魂交在你手裏。」說了這話，氣就斷了。</span>
<span className="v" id="v47" data-v="47" data-xref="馬太福音 27:54; 馬可福音 15:39; 路加福音 23:41"> 百夫長看見所成的事，就歸榮耀與上帝，說：「這真是個義人！」</span>
<span className="v" id="v48" data-v="48" data-xref="路加福音 18:13; 使徒行傳 2:37; 耶利米書 31:19"> 聚集觀看的眾人見了這所成的事都捶着胸回去了。</span>
<span className="v" id="v49" data-v="49" data-xref="路加福音 8:2; 詩篇 38:11; 路加福音 23:55"> 還有一切與耶穌熟識的人，和從加利利跟着他來的婦女們，都遠遠地站着看這些事。</span>
</div>
</div>

## 耶穌的安葬

<div className="bt">
<div className="bp">
<span className="v" id="v50" data-v="50" data-xref="約翰福音 19:38–42; 使徒行傳 11:24; 使徒行傳 10:22"> 有一個人名叫約瑟，是個議士，為人善良公義；</span>
<span className="v" id="v51" data-v="51" data-xref="路加福音 2:25; 路加福音 2:38; 以賽亞書 8:12"> 眾人所謀所為，他並沒有附從。他本是猶太、亞利馬太城裏素常盼望上帝國的人。</span>
<span className="v" id="v52" data-v="52" data-xref="約翰福音 19:38–42"> 這人去見彼拉多，求耶穌的身體，</span>
<span className="v" id="v53" data-v="53" data-xref="馬太福音 27:59–60; 以賽亞書 53:9; 馬可福音 15:46"> 就取下來，用細麻布裹好，安放在石頭鑿成的墳墓裏；那裏頭從來沒有葬過人。</span>
<span className="v" id="v54" data-v="54" data-xref="馬太福音 27:62; 約翰福音 19:31; 馬可福音 15:42"> 那日是預備日，安息日也快到了。</span>
<span className="v" id="v55" data-v="55" data-xref="路加福音 23:49; 馬太福音 27:61; 馬可福音 15:47"> 那些從加利利和耶穌同來的婦女跟在後面，看見了墳墓和他的身體怎樣安放。</span>
<span className="v" id="v56" data-v="56" data-xref="路加福音 24:1; 馬可福音 16:1; 申命記 5:14"> 她們就回去，預備了香料香膏。她們在安息日，便遵着誡命安息了。</span>
</div>

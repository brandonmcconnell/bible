## 寡婦和法官的比喻

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歌羅西書 4:2; 羅馬書 12:12; 帖撒羅尼迦前書 5:17"> 耶穌設一個比喻，是要人常常禱告，不可灰心。</span>
<span className="v" id="v2" data-v="2" data-xref="箴言 29:7; 詩篇 8:1–4; 路加福音 18:4"> 說：「某城裏有一個官，不懼怕上帝，也不尊重世人。</span>
<span className="v" id="v3" data-v="3" data-xref="以賽亞書 1:17; 耶利米書 5:28; 申命記 27:19"> 那城裏有個寡婦，常到他那裏，說：『我有一個對頭，求你給我伸冤。』</span>
<span className="v" id="v4" data-v="4" data-xref="希伯來書 4:12–13; 路加福音 16:3; 路加福音 12:17"> 他多日不准， 後來心裏說：『我雖不懼怕上帝，也不尊重世人，</span>
<span className="v" id="v5" data-v="5" data-xref="路加福音 11:8; 路加福音 18:39; 士師記 16:16"> 只因這寡婦煩擾我，我就給她伸冤吧，免得她常來纏磨我！』」</span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 7:13"> 主說：「你們聽這不義之官所說的話。</span>
<span className="v" id="v7" data-v="7" data-xref="希伯來書 10:35–37; 彼得後書 3:9; 路加福音 11:13"> 上帝的選民晝夜呼籲他，他縱然為他們忍了多時，豈不終久給他們伸冤嗎？</span>
<span className="v" id="v8" data-v="8" data-xref="希伯來書 10:23–26; 彼得後書 3:8–9; 馬太福音 24:9–13"> 我告訴你們，要快快地給他們伸冤了。然而，人子來的時候，遇得見世上有信德嗎？」</span>
</div>
</div>

## 法利賽人和稅吏的禱告

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="路加福音 16:15; 箴言 30:12; 以賽亞書 65:5"> 耶穌向那些仗着自己是義人，藐視別人的，設一個比喻，</span>
<span className="v" id="v10" data-v="10" data-xref="馬太福音 21:31–32; 列王紀上 8:30; 列王紀下 20:5"> 說：「有兩個人上殿裏去禱告：一個是法利賽人，一個是稅吏。</span>
<span className="v" id="v11" data-v="11" data-xref="馬太福音 6:5; 以賽亞書 65:5; 啟示錄 3:17"> 法利賽人站着，自言自語地禱告說：『上帝啊，我感謝你，我不像別人勒索、不義、姦淫，也不像這個稅吏。</span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 11:42; 馬太福音 23:23–24; 馬太福音 9:14"> 我一個禮拜禁食兩次，凡我所得的都捐上十分之一。』</span>
<span className="v" id="v13" data-v="13" data-xref="以斯拉記 9:6; 約翰一書 1:8–10; 提摩太前書 1:15"> 那稅吏遠遠地站着，連舉目望天也不敢，只捶着胸說：『上帝啊，開恩可憐我這個罪人！』</span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 14:11; 路加福音 16:15; 雅各書 4:10"> 我告訴你們，這人回家去比那人倒算為義了；因為，凡自高的，必降為卑；自卑的，必升為高。」</span>
</div>
</div>

## 耶穌為小孩祝福

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="馬可福音 10:13–16; 馬太福音 19:13–15; 撒母耳記上 1:24"> 有人抱着自己的嬰孩來見耶穌，要他摸他們；門徒看見就責備那些人。</span>
<span className="v" id="v16" data-v="16" data-xref="馬太福音 18:3–4; 哥林多前書 14:20; 哥林多前書 7:14"> 耶穌卻叫他們來，說：「讓小孩子到我這裏來，不要禁止他們，因為在上帝國的正是這樣的人。</span>
<span className="v" id="v17" data-v="17" data-xref="馬太福音 18:3; 馬可福音 10:15; 詩篇 131:1–2"> 我實在告訴你們，凡要承受上帝國的，若不像小孩子，斷不能進去。」</span>
</div>
</div>

## 富足的官尋求永生之道

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="馬可福音 10:17–31; 使徒行傳 16:30; 馬太福音 19:16–30"> 有一個官問耶穌說：「良善的夫子，我該做甚麼事才可以承受永生？」</span>
<span className="v" id="v19" data-v="19" data-xref="約伯記 15:14–16; 雅各書 1:17; 希伯來書 7:26"> 耶穌對他說：「你為甚麼稱我是良善的？除了上帝一位之外，再沒有良善的。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及記 20:12–17; 申命記 5:16–21; 羅馬書 13:9"> 誡命你是曉得的：『不可姦淫；不可殺人；不可偷盜；不可作假見證；當孝敬父母。』」</span>
<span className="v" id="v21" data-v="21" data-xref="腓立比書 3:6; 羅馬書 10:2–3; 馬可福音 10:20–21"> 那人說：「這一切我從小都遵守了。」</span>
<span className="v" id="v22" data-v="22" data-xref="路加福音 12:33; 提摩太前書 6:18–19; 馬太福音 19:21"> 耶穌聽見了，就說：「你還缺少一件：要變賣你一切所有的，分給窮人，就必有財寶在天上；你還要來跟從我。」</span>
<span className="v" id="v23" data-v="23" data-xref="以西結書 33:31; 約翰一書 2:15; 約伯記 31:24–25"> 他聽見這話，就甚憂愁，因為他很富足。</span>
<span className="v" id="v24" data-v="24" data-xref="箴言 30:9; 雅各書 2:5–7; 馬可福音 10:23–27"> 耶穌看見他，就說：「有錢財的人進上帝的國是何等的難哪！</span>
<span className="v" id="v25" data-v="25" data-xref="馬太福音 23:24"> 駱駝穿過針的眼比財主進上帝的國還容易呢！」</span>
<span className="v" id="v26" data-v="26" data-xref="路加福音 13:23"> 聽見的人說：「這樣，誰能得救呢？」</span>
<span className="v" id="v27" data-v="27" data-xref="耶利米書 32:17; 馬太福音 19:26; 路加福音 1:37"> 耶穌說：「在人所不能的事，在上帝卻能。」</span>
<span className="v" id="v28" data-v="28" data-xref="馬可福音 10:28; 腓立比書 3:7; 馬太福音 19:27"> 彼得說：「看哪，我們已經撇下自己所有的跟從你了。」</span>
<span className="v" id="v29" data-v="29" data-xref="馬可福音 10:29–31; 馬太福音 10:37–39; 路加福音 14:26–28"> 耶穌說：「我實在告訴你們，人為上帝的國撇下房屋，或是妻子、弟兄、父母、兒女，</span>
<span className="v" id="v30" data-v="30" data-xref="希伯來書 13:5–6; 約伯記 42:10; 啟示錄 2:17"> 沒有在今世不得百倍，在來世不得永生的。」</span>
</div>
</div>

## 耶穌第三次預言受難和復活

<div className="bt">
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="馬太福音 20:17–19; 以賽亞書 53:1–12; 詩篇 22:1–31"> 耶穌帶着十二個門徒，對他們說：「看哪，我們上耶路撒冷去，先知所寫的一切事都要成就在人子身上。</span>
<span className="v" id="v32" data-v="32" data-xref="路加福音 23:11; 以賽亞書 50:6; 以賽亞書 53:3"> 他將要被交給外邦人；他們要戲弄他，凌辱他，吐唾沫在他臉上，</span>
<span className="v" id="v33" data-v="33" data-xref="哥林多前書 15:3–4; 路加福音 24:7; 馬太福音 27:63"> 並要鞭打他，殺害他；第三日他要復活。」</span>
<span className="v" id="v34" data-v="34" data-xref="路加福音 9:45; 馬可福音 9:32; 路加福音 24:25"> 這些事門徒一樣也不懂得，意思乃是隱藏的；他們不曉得所說的是甚麼。</span>
</div>
</div>

## 治好耶利哥的瞎子

<div className="bt">
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="馬太福音 20:29–34; 馬可福音 10:46–52; 路加福音 16:20–21"> 耶穌將近耶利哥的時候，有一個瞎子坐在路旁討飯。</span>
<span className="v" id="v36" data-v="36" data-xref="馬太福音 21:10–11; 路加福音 15:26"> 聽見許多人經過，就問是甚麼事。</span>
<span className="v" id="v37" data-v="37" data-xref="馬太福音 2:23; 約翰福音 19:19; 約翰福音 12:35–36"> 他們告訴他，是拿撒勒人耶穌經過。</span>
<span className="v" id="v38" data-v="38" data-xref="馬太福音 9:27; 路加福音 18:39; 馬太福音 15:22"> 他就呼叫說：「大衛的子孫耶穌啊，可憐我吧！」</span>
<span className="v" id="v39" data-v="39" data-xref="創世記 32:26–28; 詩篇 141:1; 路加福音 18:15"> 在前頭走的人就責備他，不許他作聲；他卻越發喊叫說：「大衛的子孫，可憐我吧！」</span>
<span className="v" id="v40" data-v="40" data-xref="馬太福音 20:31–34; 馬可福音 10:48–52"> 耶穌站住，吩咐把他領過來，到了跟前，就問他說：</span>
<span className="v" id="v41" data-v="41" data-xref="列王紀上 3:5–15; 馬太福音 20:21–22; 腓立比書 4:6"> 「你要我為你做甚麼？」他說：「主啊，我要能看見。」</span>
<span className="v" id="v42" data-v="42" data-xref="馬太福音 8:3; 路加福音 8:48; 路加福音 17:19"> 耶穌說：「你可以看見！你的信救了你了。」</span>
<span className="v" id="v43" data-v="43" data-xref="詩篇 146:8; 帖撒羅尼迦後書 1:10–12; 以賽亞書 43:21"> 瞎子立刻看見了，就跟隨耶穌，一路歸榮耀與上帝。眾人看見這事，也讚美上帝。</span>
</div>
</div>

## 在安息日治好臌脹的人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="馬可福音 3:2; 路加福音 20:20; 詩篇 62:4"> 安息日，耶穌到一個法利賽人的首領家裏去吃飯，他們就窺探他。</span>
<span className="v" id="v2" data-v="2"> 在他面前有一個患水臌的人。</span>
<span className="v" id="v3" data-v="3" data-xref="馬太福音 12:10; 馬可福音 3:4; 路加福音 13:14–16"> 耶穌對律法師和法利賽人說：「安息日治病可以不可以？」</span>
<span className="v" id="v4" data-v="4" data-xref="馬太福音 22:46; 馬太福音 21:25–27"> 他們卻不言語。耶穌就治好那人，叫他走了；</span>
<span className="v" id="v5" data-v="5" data-xref="路加福音 13:15; 出埃及記 23:4–5; 馬太福音 12:11–12"> 便對他們說：「你們中間誰有驢或有牛，在安息日掉在井裏，不立時拉牠上來呢？」</span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 20:40; 路加福音 21:15; 使徒行傳 6:10"> 他們不能對答這話。</span>
</div>
</div>

## 給客人和主人的教訓

<div className="bt">
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="腓立比書 2:3; 路加福音 11:43; 馬太福音 23:6"> 耶穌見所請的客揀擇首位，就用比喻對他們說：</span>
<span className="v" id="v8" data-v="8" data-xref="箴言 25:6–7"> 「你被人請去赴婚姻的筵席，不要坐在首位上，恐怕有比你尊貴的客被他請來；</span>
<span className="v" id="v9" data-v="9" data-xref="箴言 16:18; 箴言 11:2; 箴言 3:35"> 那請你們的人前來對你說：『讓座給這一位吧！』你就羞羞慚慚地退到末位上去了。</span>
<span className="v" id="v10" data-v="10" data-xref="箴言 25:6–7; 箴言 15:33; 撒母耳記上 15:17"> 你被請的時候，就去坐在末位上，好叫那請你的人來對你說：『朋友，請上座。』那時，你在同席的人面前就有光彩了。</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 18:14; 馬太福音 23:12; 箴言 29:23"> 因為，凡自高的，必降為卑；自卑的，必升為高。」</span>
<span className="v" id="v12" data-v="12" data-xref="馬太福音 5:46; 雅各書 2:1–6; 路加福音 6:32–36"> 耶穌又對請他的人說：「你擺設午飯或晚飯，不要請你的朋友、弟兄、親屬，和富足的鄰舍，恐怕他們也請你，你就得了報答。</span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 14:21; 以賽亞書 58:10; 箴言 14:31"> 你擺設筵席，倒要請那貧窮的、殘廢的、瘸腿的、瞎眼的，你就有福了！</span>
<span className="v" id="v14" data-v="14" data-xref="箴言 19:17; 使徒行傳 24:15; 約翰福音 5:29"> 因為他們沒有甚麼可報答你。到義人復活的時候，你要得着報答。」</span>
</div>
</div>

## 大筵席的比喻

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="啟示錄 19:9; 路加福音 22:30; 路加福音 13:29"> 同席的有一人聽見這話，就對耶穌說：「在上帝國裏吃飯的有福了！」</span>
<span className="v" id="v16" data-v="16" data-xref="馬太福音 22:2–14; 啟示錄 22:17; 以賽亞書 55:1–7"> 耶穌對他說：「有一人擺設大筵席，請了許多客。</span>
<span className="v" id="v17" data-v="17" data-xref="馬太福音 11:27–29; 馬太福音 10:1–4; 馬太福音 22:3–4"> 到了坐席的時候，打發僕人去對所請的人說：『請來吧！樣樣都齊備了。』</span>
<span className="v" id="v18" data-v="18" data-xref="提摩太前書 6:9–10; 路加福音 17:26–31; 路加福音 18:24"> 眾人一口同音地推辭。頭一個說：『我買了一塊地，必須去看看。請你准我辭了。』</span>
<span className="v" id="v19" data-v="19"> 又有一個說：『我買了五對牛，要去試一試。請你准我辭了。』</span>
<span className="v" id="v20" data-v="20" data-xref="申命記 24:5; 哥林多前書 7:33; 路加福音 14:26–28"> 又有一個說：『我才娶了妻，所以不能去。』</span>
<span className="v" id="v21" data-v="21" data-xref="路加福音 14:13; 馬太福音 11:5; 路加福音 14:24"> 那僕人回來，把這事都告訴了主人。家主就動怒，對僕人說：『快出去，到城裏大街小巷，領那貧窮的、殘廢的、瞎眼的、瘸腿的來。』</span>
<span className="v" id="v22" data-v="22" data-xref="約翰福音 14:2; 以弗所書 3:8; 提摩太前書 2:5–6"> 僕人說：『主啊，你所吩咐的已經辦了，還有空座。』</span>
<span className="v" id="v23" data-v="23" data-xref="馬太福音 22:9–10; 歌羅西書 1:28; 使徒行傳 13:47–48"> 主人對僕人說：『你出去到路上和籬笆那裏，勉強人進來，坐滿我的屋子。</span>
<span className="v" id="v24" data-v="24" data-xref="馬太福音 21:43; 使徒行傳 13:46; 約翰福音 8:24"> 我告訴你們，先前所請的人沒有一個得嘗我的筵席。』」</span>
</div>
</div>

## 作門徒的代價

<div className="bt">
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="約翰福音 6:24–27; 路加福音 12:1"> 有極多的人和耶穌同行。他轉過來對他們說：</span>
<span className="v" id="v26" data-v="26" data-xref="馬太福音 10:37; 約翰福音 12:25; 腓立比書 3:8"> 「人到我這裏來，若不愛我勝過愛<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="愛我勝過愛：原文是恨">a</a></sup>自己的父母、妻子、兒女、弟兄、姊妹，和自己的性命，就不能作我的門徒。</span>
<span className="v" id="v27" data-v="27" data-xref="馬太福音 10:38; 路加福音 9:23–25; 馬可福音 8:34–37"> 凡不背着自己十字架跟從我的，也不能作我的門徒。</span>
<span className="v" id="v28" data-v="28" data-xref="箴言 24:27; 馬太福音 10:22; 約書亞記 24:19–24"> 你們哪一個要蓋一座樓，不先坐下算計花費，能蓋成不能呢？</span>
<span className="v" id="v29" data-v="29"> 恐怕安了地基，不能成功，看見的人都笑話他，說：</span>
<span className="v" id="v30" data-v="30" data-xref="希伯來書 6:11; 約翰二書 1:8; 哥林多前書 3:11–14"> 『這個人開了工，卻不能完工。』</span>
<span className="v" id="v31" data-v="31" data-xref="箴言 20:18; 箴言 25:8; 列王紀下 18:20–22"> 或是一個王出去和別的王打仗，豈不先坐下酌量，能用一萬兵去敵那領二萬兵來攻打他的嗎？</span>
<span className="v" id="v32" data-v="32" data-xref="使徒行傳 12:20; 雅各書 4:6–10; 路加福音 12:58"> 若是不能，就趁敵人還遠的時候，派使者去求和息的條款。</span>
<span className="v" id="v33" data-v="33" data-xref="腓立比書 3:7–8; 約翰一書 2:15–16; 路加福音 5:28"> 這樣，你們無論甚麼人，若不撇下一切所有的，就不能作我的門徒。」</span>
</div>
</div>

## 失味的鹽

<div className="bt">
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="馬太福音 5:13; 歌羅西書 4:6; 馬可福音 9:49–50"> 「鹽本是好的；鹽若失了味，可用甚麼叫它再鹹呢？</span>
<span className="v" id="v35" data-v="35" data-xref="馬太福音 11:15; 路加福音 9:44; 啟示錄 2:11"> 或用在田裏，或堆在糞裏，都不合式，只好丟在外面。有耳可聽的，就應當聽！」</span>
</div>

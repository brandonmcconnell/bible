## 禱告的教訓

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="詩篇 19:14; 路加福音 22:39–45; 羅馬書 8:26–27"> 耶穌在一個地方禱告；禱告完了，有個門徒對他說：「求主教導我們禱告，像約翰教導他的門徒。」</span>
<span className="v" id="v2" data-v="2" data-xref="馬太福音 6:6–15; 傳道書 5:2; 詩篇 72:18–19"> 耶穌說：「你們禱告的時候，要說：<br /><span className="pl pl-1">我們在天上的父</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古卷：父啊">a</a></sup><br /><span className="pl pl-1">：</span><br /><span className="pl pl-1">願人都尊你的名為聖。</span><br /><span className="pl pl-1">願你的國降臨；</span><br /><span className="pl pl-1">願你的旨意行在地上，</span><br /><span className="pl pl-1">如同行在天上</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有古卷沒有願你的旨意…">b</a></sup><br /><span className="pl pl-1">。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="馬太福音 6:11; 馬太福音 6:34; 箴言 30:8"> <span className="pl pl-1">我們日用的飲食，</span><br /><span className="pl pl-1">天天賜給我們。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="馬太福音 6:12–15; 馬太福音 26:41; 以賽亞書 43:25–26"> <span className="pl pl-1">赦免我們的罪，</span><br /><span className="pl pl-1">因為我們也赦免凡虧欠我們的人。</span><br /><span className="pl pl-1">不叫我們遇見試探；</span><br /><span className="pl pl-1">救我們脫離凶惡</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="有古卷沒有末句">c</a></sup><br /><span className="pl pl-1">。」</span></span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="路加福音 18:1–8"> 耶穌又說：「你們中間誰有一個朋友半夜到他那裏去，說：『朋友！請借給我三個餅；</span>
<span className="v" id="v6" data-v="6"> 因為我有一個朋友行路，來到我這裏，我沒有甚麼給他擺上。』</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 13:25; 加拉太書 6:17; 路加福音 7:6"> 那人在裏面回答說：『不要攪擾我，門已經關閉，孩子們也同我在床上了，我不能起來給你。』</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 32:26; 歌羅西書 4:12; 羅馬書 15:30"> 我告訴你們，雖不因他是朋友起來給他，但因他情詞迫切地直求，就必起來照他所需用的給他。</span>
<span className="v" id="v9" data-v="9" data-xref="馬可福音 11:24; 約翰福音 16:23–24; 馬太福音 21:22"> 我又告訴你們，你們祈求，就給你們；尋找，就尋見；叩門，就給你們開門。</span>
<span className="v" id="v10" data-v="10" data-xref="雅各書 4:3; 耶利米哀歌 3:54–58; 詩篇 31:22"> 因為，凡祈求的，就得着；尋找的，就尋見；叩門的，就給他開門。</span>
<span className="v" id="v11" data-v="11" data-xref="馬太福音 7:9; 以賽亞書 49:15"> 你們中間作父親的，誰有兒子求餅，反給他石頭呢？求魚，反拿蛇當魚給他呢？</span>
<span className="v" id="v12" data-v="12" data-xref="啟示錄 9:10; 路加福音 10:19; 以西結書 2:6"> 求雞蛋，反給他蠍子呢？</span>
<span className="v" id="v13" data-v="13" data-xref="馬太福音 7:11; 以賽亞書 44:3–4; 羅馬書 8:32"> 你們雖然不好，尚且知道拿好東西給兒女；何況天父，豈不更將聖靈給求他的人嗎？」</span>
</div>
</div>

## 耶穌和別西卜

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="馬太福音 12:22–24; 馬太福音 9:32–34; 馬可福音 7:32–37"> 耶穌趕出一個叫人啞巴的鬼；鬼出去了，啞巴就說出話來；眾人都希奇。</span>
<span className="v" id="v15" data-v="15" data-xref="馬太福音 9:34; 馬太福音 12:24–30; 約翰福音 8:48"> 內中卻有人說：「他是靠着鬼王別西卜趕鬼。」</span>
<span className="v" id="v16" data-v="16" data-xref="約翰福音 6:30; 哥林多前書 1:22; 馬可福音 8:11–12"> 又有人試探耶穌，向他求從天上來的神蹟。</span>
<span className="v" id="v17" data-v="17" data-xref="馬可福音 3:23–27; 馬太福音 12:25–29; 以賽亞書 19:2–3"> 他曉得他們的意念，便對他們說：「凡一國自相紛爭，就成為荒場；凡一家自相紛爭，就必敗落。</span>
<span className="v" id="v18" data-v="18" data-xref="馬太福音 12:26; 馬太福音 12:31–34; 路加福音 11:15"> 若撒但自相紛爭，他的國怎能站得住呢？因為你們說我是靠着別西卜趕鬼。</span>
<span className="v" id="v19" data-v="19" data-xref="路加福音 9:49; 約伯記 15:6; 羅馬書 3:19"> 我若靠着別西卜趕鬼，你們的子弟趕鬼又靠着誰呢？這樣，他們就要斷定你們的是非。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及記 8:19; 馬太福音 12:28; 路加福音 10:9"> 我若靠着上帝的能力趕鬼，這就是上帝的國臨到你們了。</span>
<span className="v" id="v21" data-v="21" data-xref="馬可福音 3:27; 馬太福音 12:29"> 壯士披掛整齊，看守自己的住宅，他所有的都平安無事；</span>
<span className="v" id="v22" data-v="22" data-xref="以賽亞書 49:24–25; 以賽亞書 53:12; 約翰一書 3:8"> 但有一個比他更壯的來，勝過他，就奪去他所倚靠的盔甲兵器，又分了他的贓。</span>
<span className="v" id="v23" data-v="23" data-xref="馬太福音 12:30; 路加福音 9:50; 馬可福音 9:40"> 不與我相合的，就是敵我的；不同我收聚的，就是分散的。」</span>
</div>
</div>

## 污鬼回來

<div className="bt">
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="馬太福音 12:43–45; 彼得前書 5:8; 約伯記 2:2"> 「污鬼離了人身，就在無水之地過來過去，尋求安歇之處；既尋不着，便說：『我要回到我所出來的屋裏去。』</span>
<span className="v" id="v25" data-v="25" data-xref="帖撒羅尼迦後書 2:9–12; 彼得後書 2:10–19; 猶大書 1:8–13"> 到了，就看見裏面打掃乾淨，修飾好了，</span>
<span className="v" id="v26" data-v="26" data-xref="約翰福音 5:14; 馬太福音 12:45; 彼得後書 2:20–22"> 便去另帶了七個比自己更惡的鬼來，都進去住在那裏。那人末後的景況比先前更不好了。」</span>
</div>
</div>

## 真正的福

<div className="bt">
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="路加福音 1:42; 路加福音 1:48; 路加福音 23:29"> 耶穌正說這話的時候，眾人中間有一個女人大聲說：「懷你胎的和乳養你的有福了！」</span>
<span className="v" id="v28" data-v="28" data-xref="路加福音 6:47–48; 路加福音 8:21; 詩篇 112:1"> 耶穌說：「是，卻還不如聽上帝之道而遵守的人有福。」</span>
</div>

## 求神蹟的受責備

<div className="bt">
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="路加福音 11:16; 馬可福音 8:11–12; 哥林多前書 1:22"> 當眾人聚集的時候，耶穌開講說：「這世代是一個邪惡的世代。他們求看神蹟，除了約拿的神蹟以外，再沒有神蹟給他們看。</span>
<span className="v" id="v30" data-v="30" data-xref="馬太福音 12:40–42; 約拿書 1:17; 約拿書 3:2–10"> 約拿怎樣為尼尼微人成了神蹟，人子也要照樣為這世代的人成了神蹟。</span>
<span className="v" id="v31" data-v="31" data-xref="歷代志下 9:1; 列王紀上 10:1–13; 羅馬書 2:27"> 當審判的時候，南方的女王要起來定這世代的罪；因為她從地極而來，要聽所羅門的智慧話。看哪，在這裏有一人比所羅門更大。</span>
<span className="v" id="v32" data-v="32" data-xref="希伯來書 7:26; 路加福音 11:31; 約拿書 3:5–4"> 當審判的時候，尼尼微人要起來定這世代的罪，因為尼尼微人聽了約拿所傳的就悔改了。看哪，在這裏有一人比約拿更大。」</span>
</div>
</div>

## 論心裏的光

<div className="bt">
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="路加福音 8:16–17; 馬可福音 4:21–22; 馬太福音 5:15–16"> 「沒有人點燈放在地窨子裏，或是斗底下，總是放在燈臺上，使進來的人得見亮光。</span>
<span className="v" id="v34" data-v="34" data-xref="馬太福音 6:22–23; 使徒行傳 26:18; 耶利米書 5:21"> 你眼睛就是身上的燈。你的眼睛若瞭亮，全身就光明；眼睛若昏花，全身就黑暗。</span>
<span className="v" id="v35" data-v="35" data-xref="箴言 16:25; 彼得後書 1:9; 雅各書 3:13–17"> 所以，你要省察，恐怕你裏頭的光或者黑暗了。</span>
<span className="v" id="v36" data-v="36" data-xref="箴言 20:27; 箴言 6:23; 箴言 4:18–19"> 若是你全身光明，毫無黑暗，就必全然光明，如同燈的明光照亮你。」</span>
</div>
</div>

## 譴責法利賽人和文士

<div className="bt">
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="路加福音 7:36; 哥林多前書 9:19–23; 路加福音 14:1"> 說話的時候，有一個法利賽人請耶穌同他吃飯，耶穌就進去坐席。</span>
<span className="v" id="v38" data-v="38" data-xref="馬太福音 15:2–3; 馬可福音 7:2–5; 約翰福音 3:25"> 這法利賽人看見耶穌飯前不洗手便詫異。</span>
<span className="v" id="v39" data-v="39" data-xref="提多書 1:15; 箴言 30:12; 創世記 6:5"> 主對他說：「如今你們法利賽人洗淨杯盤的外面，你們裏面卻滿了勒索和邪惡。</span>
<span className="v" id="v40" data-v="40" data-xref="路加福音 12:20; 哥林多前書 15:36; 馬太福音 23:26"> 無知的人哪，造外面的，不也造裏面嗎？</span>
<span className="v" id="v41" data-v="41" data-xref="路加福音 12:33; 雅各書 1:27; 提多書 1:15"> 只要把裏面的施捨給人，凡物於你們就都潔淨了。</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="馬太福音 23:23; 路加福音 18:12; 箴言 21:3"> 「你們法利賽人有禍了！因為你們將薄荷、芸香並各樣菜蔬獻上十分之一，那公義和愛上帝的事反倒不行了。這原是你們當行的；那也是不可不行的。</span>
<span className="v" id="v43" data-v="43" data-xref="路加福音 20:46; 馬可福音 12:38–39; 路加福音 14:7–11"> 你們法利賽人有禍了！因為你們喜愛會堂裏的首位，又喜愛人在街市上問你們的安。</span>
<span className="v" id="v44" data-v="44" data-xref="馬太福音 23:27–28; 詩篇 5:9; 使徒行傳 23:3"> 你們有禍了！因為你們如同不顯露的墳墓，走在上面的人並不知道。」</span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="約翰福音 9:40; 馬太福音 22:35; 耶利米書 6:10"> 律法師中有一個回答耶穌說：「夫子！你這樣說也把我們糟蹋了。」</span>
<span className="v" id="v46" data-v="46" data-xref="路加福音 11:52; 以賽亞書 10:1; 馬太福音 23:2–4"> 耶穌說：「你們律法師也有禍了！因為你們把難擔的擔子放在人身上，自己一個指頭卻不肯動。</span>
<span className="v" id="v47" data-v="47" data-xref="帖撒羅尼迦前書 2:15; 使徒行傳 7:51; 馬太福音 23:29–33"> 你們有禍了！因為你們修造先知的墳墓，那先知正是你們的祖宗所殺的。</span>
<span className="v" id="v48" data-v="48" data-xref="雅各書 5:10; 馬太福音 23:31; 歷代志下 36:16"> 可見你們祖宗所做的事，你們又證明又喜歡；因為他們殺了先知，你們修造先知的墳墓。</span>
<span className="v" id="v49" data-v="49" data-xref="哥林多前書 1:30; 歌羅西書 2:3; 以弗所書 4:11"> 所以上帝用智慧<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="用智慧：或譯的智者">d</a></sup>曾說：『我要差遣先知和使徒到他們那裏去，有的他們要殺害，有的他們要逼迫』，</span>
<span className="v" id="v50" data-v="50" data-xref="創世記 9:5–6; 啟示錄 18:20–24; 列王紀下 24:4"> 使創世以來所流眾先知血的罪都要問在這世代的人身上，</span>
<span className="v" id="v51" data-v="51" data-xref="歷代志下 24:20–22; 馬太福音 23:35; 希伯來書 11:4"> 就是從亞伯的血起，直到被殺在壇和殿中間撒迦利亞的血為止。我實在告訴你們，這都要問在這世代的人身上。</span>
<span className="v" id="v52" data-v="52" data-xref="馬太福音 23:13; 瑪拉基書 2:7; 路加福音 11:45–46"> 你們律法師有禍了！因為你們把知識的鑰匙奪了去，自己不進去，正要進去的人你們也阻擋他們。」</span>
<span className="v" id="v53" data-v="53" data-xref="哥林多前書 13:5; 耶利米書 20:10; 路加福音 20:20"> 耶穌從那裏出來，文士和法利賽人就極力地催逼他，引動他多說話，</span>
<span className="v" id="v54" data-v="54" data-xref="馬可福音 12:13; 馬太福音 22:15; 馬太福音 22:35"> 私下窺聽，要拿他的話柄。</span>
</div>

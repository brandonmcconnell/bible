## 迷羊的比喻

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="提摩太前書 1:15; 馬太福音 9:10–13; 路加福音 5:29–32"> 眾稅吏和罪人都挨近耶穌，要聽他講道。</span>
<span className="v" id="v2" data-v="2" data-xref="馬太福音 9:11; 路加福音 19:7; 路加福音 7:39"> 法利賽人和文士私下議論說：「這個人接待罪人，又同他們吃飯。」</span>
<span className="v" id="v3" data-v="3"> 耶穌就用比喻說：</span>
<span className="v" id="v4" data-v="4" data-xref="以西結書 34:16; 以西結書 34:11–12; 馬太福音 18:12–14"> 「你們中間誰有一百隻羊失去一隻，不把這九十九隻撇在曠野、去找那失去的羊，直到找着呢？</span>
<span className="v" id="v5" data-v="5" data-xref="希伯來書 12:2; 路加福音 19:9; 以賽亞書 46:3–4"> 找着了，就歡歡喜喜地扛在肩上，回到家裏，</span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 15:10; 路加福音 15:24; 彼得前書 2:25"> 就請朋友鄰舍來，對他們說：『我失去的羊已經找着了，你們和我一同歡喜吧！』</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 5:32; 路加福音 15:10; 路加福音 15:32"> 我告訴你們，一個罪人悔改，在天上也要這樣為他歡喜，較比為九十九個不用悔改的義人歡喜更大。」</span>
</div>
</div>

## 失錢的比喻

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="路加福音 19:10; 以西結書 34:12; 約翰福音 10:16"> 「或是一個婦人有十塊錢，若失落一塊，豈不點上燈，打掃屋子，細細地找，直到找着嗎？</span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 15:6–7"> 找着了，就請朋友鄰舍來，對他們說：『我失落的那塊錢已經找着了，你們和我一同歡喜吧！』</span>
<span className="v" id="v10" data-v="10" data-xref="路加福音 15:7; 哥林多後書 7:10; 以西結書 33:11"> 我告訴你們，一個罪人悔改，在上帝的使者面前也是這樣為他歡喜。」</span>
</div>
</div>

## 浪子的比喻

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="馬太福音 21:23–31"> 耶穌又說：「一個人有兩個兒子。</span>
<span className="v" id="v12" data-v="12" data-xref="申命記 21:16–17; 馬可福音 12:44; 路加福音 15:30"> 小兒子對父親說：『父親，請你把我應得的家業分給我。』他父親就把產業分給他們。</span>
<span className="v" id="v13" data-v="13" data-xref="箴言 29:3; 耶利米書 2:5; 箴言 21:17"> 過了不多幾日，小兒子就把他一切所有的都收拾起來，往遠方去了。在那裏任意放蕩，浪費資財。</span>
<span className="v" id="v14" data-v="14" data-xref="歷代志下 33:11; 阿摩司書 8:9–12; 何西阿書 2:9–14"> 既耗盡了一切所有的，又遇着那地方大遭饑荒，就窮苦起來。</span>
<span className="v" id="v15" data-v="15" data-xref="提多書 3:3; 提摩太後書 2:25–26; 以賽亞書 1:5"> 於是去投靠那地方的一個人；那人打發他到田裏去放豬。</span>
<span className="v" id="v16" data-v="16" data-xref="羅馬書 6:19–21; 耶利米哀歌 4:5; 何西阿書 12:1"> 他恨不得拿豬所吃的豆莢充飢，也沒有人給他。</span>
<span className="v" id="v17" data-v="17" data-xref="以西結書 18:28; 以弗所書 2:4–5; 路加福音 15:18–19"> 他醒悟過來，就說：『我父親有多少的雇工，口糧有餘，我倒在這裏餓死嗎？</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米哀歌 3:40; 約翰一書 1:8–10; 路加福音 15:21"> 我要起來，到我父親那裏去，向他說：父親！我得罪了天，又得罪了你；</span>
<span className="v" id="v19" data-v="19" data-xref="約伯記 42:6; 路加福音 5:8; 詩篇 84:10"> 從今以後，我不配稱為你的兒子，把我當作一個雇工吧！』</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 103:10–13; 詩篇 86:5; 詩篇 86:15"> 於是起來，往他父親那裏去。相離還遠，他父親看見，就動了慈心，跑去抱着他的頸項，連連與他親嘴。</span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 51:4; 路加福音 15:18–19; 耶利米書 3:13"> 兒子說：『父親！我得罪了天，又得罪了你；從今以後，我不配稱為你的兒子。』</span>
<span className="v" id="v22" data-v="22" data-xref="創世記 41:42; 以斯帖記 8:2; 啟示錄 6:11"> 父親卻吩咐僕人說：『把那上好的袍子快拿出來給他穿；把戒指戴在他指頭上；把鞋穿在他腳上；</span>
<span className="v" id="v23" data-v="23" data-xref="以賽亞書 25:6; 馬太福音 22:2–14; 詩篇 63:5"> 把那肥牛犢牽來宰了，我們可以吃喝快樂；</span>
<span className="v" id="v24" data-v="24" data-xref="以弗所書 2:5; 以西結書 34:16; 路加福音 19:10"> 因為我這個兒子是死而復活，失而又得的。』他們就快樂起來。</span>
<span className="v" id="v25" data-v="25" data-xref="詩篇 150:4; 耶利米書 31:4; 路加福音 15:11–12"> 那時，大兒子正在田裏。他回來，離家不遠，聽見作樂跳舞的聲音，</span>
<span className="v" id="v26" data-v="26"> 便叫過一個僕人來，問是甚麼事。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行傳 9:17; 腓利門書 1:16; 使徒行傳 22:13"> 僕人說：『你兄弟來了；你父親因為得他無災無病地回來，把肥牛犢宰了。』</span>
<span className="v" id="v28" data-v="28" data-xref="約拿書 4:9; 撒母耳記上 18:8; 約拿書 4:1–4"> 大兒子卻生氣，不肯進去；他父親就出來勸他。</span>
<span className="v" id="v29" data-v="29" data-xref="路加福音 18:11–12; 撒迦利亞書 7:3; 以賽亞書 65:5"> 他對父親說：『我服事你這多年，從來沒有違背過你的命，你並沒有給我一隻山羊羔，叫我和朋友一同快樂。</span>
<span className="v" id="v30" data-v="30" data-xref="箴言 29:3; 路加福音 15:12–13; 路加福音 15:32"> 但你這個兒子和娼妓吞盡了你的產業，他一來了，你倒為他宰了肥牛犢。』</span>
<span className="v" id="v31" data-v="31" data-xref="馬可福音 7:27–28; 羅馬書 9:4; 羅馬書 11:1"> 父親對他說：『兒啊！你常和我同在，我一切所有的都是你的；</span>
<span className="v" id="v32" data-v="32" data-xref="以弗所書 2:1–10; 路加福音 15:24; 以賽亞書 35:10"> 只是你這個兄弟是死而復活、失而又得的，所以我們理當歡喜快樂。』」</span>
</div>
</div>

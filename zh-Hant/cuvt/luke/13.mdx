## 悔改或滅亡

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="彼得前書 4:17–18; 耶利米哀歌 2:20; 以西結書 9:5–7"> 正當那時，有人將彼拉多使加利利人的血攙雜在他們祭物中的事告訴耶穌。</span>
<span className="v" id="v2" data-v="2" data-xref="約翰福音 9:2; 使徒行傳 28:4; 約伯記 22:5–16"> 耶穌說：「你們以為這些加利利人比眾加利利人更有罪，所以受這害嗎？</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行傳 3:19; 馬太福音 3:2; 使徒行傳 2:38–40"> 我告訴你們，不是的！你們若不悔改，都要如此滅亡！</span>
<span className="v" id="v4" data-v="4" data-xref="尼希米記 3:15; 約伯記 1:19; 約翰福音 9:11"> 從前西羅亞樓倒塌了，壓死十八個人；你們以為那些人比一切住在耶路撒冷的人更有罪嗎？</span>
<span className="v" id="v5" data-v="5" data-xref="以西結書 18:30; 路加福音 13:3; 以賽亞書 28:10–13"> 我告訴你們，不是的！你們若不悔改，都要如此滅亡！」</span>
</div>

## 不結實的無花果樹

<div className="bt">
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="約翰福音 15:16; 以賽亞書 5:1–4; 加拉太書 5:22"> 於是用比喻說：「一個人有一棵無花果樹栽在葡萄園裏。他來到樹前找果子，卻找不着。</span>
<span className="v" id="v7" data-v="7" data-xref="馬太福音 7:19; 路加福音 3:9; 約翰福音 15:6"> 就對管園的說：『看哪，我這三年來到這無花果樹前找果子，竟找不着。把它砍了吧，何必白佔地土呢！』</span>
<span className="v" id="v8" data-v="8" data-xref="彼得後書 3:9; 約珥書 2:17; 羅馬書 10:1"> 管園的說：『 主啊，今年且留着，等我周圍掘開土，加上糞；</span>
<span className="v" id="v9" data-v="9" data-xref="約翰福音 15:2; 帖撒羅尼迦前書 2:15; 希伯來書 6:8"> 以後若結果子便罷，不然再把它砍了。』」</span>
</div>
</div>

## 安息日治好駝背的女人

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="馬太福音 4:23; 路加福音 4:44; 路加福音 4:15–16"> 安息日，耶穌在會堂裏教訓人。</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 8:2; 路加福音 8:27; 路加福音 13:16"> 有一個女人被鬼附着，病了十八年，腰彎得一點直不起來。</span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 107:20; 馬太福音 8:16; 路加福音 6:8–10"> 耶穌看見，便叫過她來，對她說：「女人，你脫離這病了！」</span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 107:20–22; 馬可福音 16:18; 馬可福音 5:23"> 於是用兩隻手按着她；她立刻直起腰來，就歸榮耀與上帝。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及記 20:9; 馬太福音 12:2; 約翰福音 9:14–16"> 管會堂的因為耶穌在安息日治病，就氣忿忿地對眾人說：「有六日應當做工；那六日之內可以來求醫，在安息日卻不可。」</span>
<span className="v" id="v15" data-v="15" data-xref="路加福音 14:5; 約翰福音 7:21–24; 使徒行傳 13:9–10"> 主說：「假冒為善的人哪，難道你們各人在安息日不解開槽上的牛、驢，牽去飲嗎？</span>
<span className="v" id="v16" data-v="16" data-xref="馬可福音 2:27; 提摩太後書 2:26; 路加福音 19:9"> 況且這女人本是亞伯拉罕的後裔，被撒但捆綁了這十八年，不當在安息日解開她的綁嗎？」</span>
<span className="v" id="v17" data-v="17" data-xref="彼得前書 3:16; 詩篇 132:18; 以賽亞書 45:24"> 耶穌說這話，他的敵人都慚愧了；眾人因他所行一切榮耀的事，就都歡喜了。</span>
</div>
</div>

## 芥菜種和麵酵的比喻

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="馬可福音 4:30–34; 路加福音 17:21; 馬太福音 13:31–32"> 耶穌說：「上帝的國好像甚麼？我拿甚麼來比較呢？</span>
<span className="v" id="v19" data-v="19" data-xref="但以理書 4:12; 但以理書 4:21; 但以理書 2:44–45"> 好像一粒芥菜種，有人拿去種在園子裏，長大成樹，天上的飛鳥宿在它的枝上。」</span>
<span className="v" id="v20" data-v="20"> 又說：「我拿甚麼來比上帝的國呢？</span>
<span className="v" id="v21" data-v="21" data-xref="馬太福音 13:33; 哥林多前書 5:6; 帖撒羅尼迦前書 5:23–24"> 好比麵酵，有婦人拿來藏在三斗麵裏，直等全團都發起來。」</span>
</div>
</div>

## 當進窄門

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="路加福音 9:51; 馬太福音 9:35; 馬可福音 10:32–34"> 耶穌往耶路撒冷去，在所經過的各城各鄉教訓人。</span>
<span className="v" id="v23" data-v="23" data-xref="馬太福音 7:14; 馬太福音 22:14; 約翰福音 21:21–22"> 有一個人問他說：「主啊，得救的人少嗎？」</span>
<span className="v" id="v24" data-v="24" data-xref="馬太福音 7:13–14; 彼得後書 1:10; 哥林多前書 9:24–27"> 耶穌對眾人說：「你們要努力進窄門。我告訴你們，將來有許多人想要進去，卻是不能。</span>
<span className="v" id="v25" data-v="25" data-xref="馬太福音 25:10–12; 路加福音 13:27; 馬太福音 7:21–23"> 及至家主起來關了門，你們站在外面叩門，說：『主啊，給我們開門！』他就回答說：『我不認識你們，不曉得你們是哪裏來的！』</span>
<span className="v" id="v26" data-v="26" data-xref="以賽亞書 58:2; 提多書 1:16; 提摩太後書 3:5"> 那時，你們要說：『我們在你面前吃過喝過，你也在我們的街上教訓過人。』</span>
<span className="v" id="v27" data-v="27" data-xref="詩篇 6:8; 馬太福音 25:41; 馬太福音 7:22–23"> 他要說：『我告訴你們，我不曉得你們是哪裏來的。你們這一切作惡的人，離開我去吧！』</span>
<span className="v" id="v28" data-v="28" data-xref="馬太福音 8:11–12; 馬太福音 22:13; 馬太福音 25:30"> 你們要看見亞伯拉罕、以撒、雅各，和眾先知都在上帝的國裏，你們卻被趕到外面，在那裏必要哀哭切齒了。</span>
<span className="v" id="v29" data-v="29" data-xref="以賽亞書 43:6; 以賽亞書 66:18–20; 以賽亞書 49:6"> 從東、從西、從南、從北將有人來，在上帝的國裏坐席。</span>
<span className="v" id="v30" data-v="30" data-xref="馬太福音 19:30; 馬可福音 10:31; 馬太福音 20:16"> 只是有在後的，將要在前；有在前的，將要在後。」</span>
</div>
</div>

## 為耶路撒冷哀哭

<div className="bt">
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="尼希米記 6:9–11; 詩篇 11:1–2; 馬太福音 14:1"> 正當那時，有幾個法利賽人來對耶穌說：「離開這裏去吧，因為希律想要殺你。」</span>
<span className="v" id="v32" data-v="32" data-xref="希伯來書 2:10; 希伯來書 5:9; 約翰福音 17:4–5"> 耶穌說：「你們去告訴那個狐狸說：『今天、明天我趕鬼治病，第三天我的事就成全了。』</span>
<span className="v" id="v33" data-v="33" data-xref="路加福音 9:53; 馬太福音 21:11; 使徒行傳 13:27"> 雖然這樣，今天、明天、後天，我必須前行，因為先知在耶路撒冷之外喪命是不能的。</span>
<span className="v" id="v34" data-v="34" data-xref="馬太福音 23:37–39; 申命記 32:11–12; 使徒行傳 7:52"> 耶路撒冷啊！耶路撒冷啊！你常殺害先知，又用石頭打死那奉差遣到你這裏來的人。我多次願意聚集你的兒女，好像母雞把小雞聚集在翅膀底下；只是你們不願意。</span>
<span className="v" id="v35" data-v="35" data-xref="詩篇 118:26; 馬可福音 11:9–10; 馬太福音 21:9"> 看哪，你們的家成為荒場留給你們。我告訴你們，從今以後你們不得再見我，直等到你們說：『奉主名來的是應當稱頌的。』」</span>
</div>

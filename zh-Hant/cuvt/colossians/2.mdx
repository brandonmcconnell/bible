<span className="v" id="v2" data-v="2" data-xref="歌羅西書 1:27; 歌羅西書 4:8; 以弗所書 6:22"> 要叫他們的心得安慰，因愛心互相聯絡，以致豐豐足足在悟性中有充足的信心，使他們真知上帝的奧祕，就是基督；</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多前書 1:24; 哥林多前書 1:30; 羅馬書 11:33"> 所積蓄的一切智慧知識，都在他裏面藏着。</span>
<span className="v" id="v4" data-v="4" data-xref="約翰一書 4:1; 以弗所書 4:14; 羅馬書 16:18–19"> 我說這話，免得有人用花言巧語迷惑你們。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多前書 5:3–4; 帖撒羅尼迦前書 2:17; 哥林多前書 16:13"> 我身子雖與你們相離，心卻與你們同在，見你們循規蹈矩，信基督的心也堅固，我就歡喜了。</span>

## 基督裏生命的豐盛

<div className="bt">
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="歌羅西書 1:10; 約翰一書 2:6; 帖撒羅尼迦前書 4:1"> 你們既然接受了主基督耶穌，就當遵他而行，</span>
<span className="v" id="v7" data-v="7" data-xref="以弗所書 3:17; 耶利米書 17:8; 以弗所書 2:20–22"> 在他裏面生根建造，信心堅固，正如你們所領的教訓，感謝的心也更增長了。</span>
<span className="v" id="v8" data-v="8" data-xref="提摩太前書 6:20; 以弗所書 5:6; 馬太福音 7:15"> 你們要謹慎，恐怕有人用他的理學和虛空的妄言，不照着基督，乃照人間的遺傳和世上的小學就把你們擄去。</span>
<span className="v" id="v9" data-v="9" data-xref="歌羅西書 1:19; 約翰福音 10:30; 約翰福音 1:14"> 因為上帝本性一切的豐盛都有形有體地居住在基督裏面，</span>
<span className="v" id="v10" data-v="10" data-xref="以弗所書 3:19; 歌羅西書 1:16–18; 以弗所書 1:20–23"> 你們在他裏面也得了豐盛。他是各樣執政掌權者的元首。</span>
<span className="v" id="v11" data-v="11" data-xref="羅馬書 2:29; 腓立比書 3:3; 羅馬書 6:6"> 你們在他裏面也受了不是人手所行的割禮，乃是基督使你們脫去肉體情慾的割禮。</span>
<span className="v" id="v12" data-v="12" data-xref="羅馬書 6:3–5; 彼得前書 3:21; 加拉太書 3:27"> 你們既受洗與他一同埋葬，也就在此與他一同復活，都因信那叫他從死裏復活上帝的功用。</span>
<span className="v" id="v13" data-v="13" data-xref="以弗所書 2:5–6; 羅馬書 8:11; 以弗所書 2:1"> 你們從前在過犯和未受割禮的肉體中死了，上帝赦免了你們<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或譯：我們">a</a></sup>一切過犯，便叫你們與基督一同活過來；</span>
<span className="v" id="v14" data-v="14" data-xref="以賽亞書 44:22; 以弗所書 2:14–16; 以賽亞書 43:25"> 又塗抹了在律例上所寫、攻擊我們、有礙於我們的字據，把它撤去，釘在十字架上。</span>
<span className="v" id="v15" data-v="15" data-xref="希伯來書 2:14; 以弗所書 4:8; 馬太福音 12:29"> 既將一切執政的、掌權的擄來，明顯給眾人看，就仗着十字架誇勝。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="羅馬書 14:5–6; 羅馬書 14:10; 加拉太書 4:10"> 所以，不拘在飲食上，或節期、月朔、安息日都不可讓人論斷你們。</span>
<span className="v" id="v17" data-v="17" data-xref="希伯來書 10:1; 希伯來書 8:5; 約翰福音 1:17"> 這些原是後事的影兒；那形體卻是基督。</span>
<span className="v" id="v18" data-v="18" data-xref="歌羅西書 2:8; 約翰一書 4:1–2; 歌羅西書 2:23"> 不可讓人因着故意謙虛和敬拜天使，就奪去你們的獎賞。這等人拘泥在所見過的<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有古卷：這等人窺察所沒有見過的">b</a></sup>，隨着自己的慾心，無故地自高自大，</span>
<span className="v" id="v19" data-v="19" data-xref="以弗所書 4:15–16; 約翰福音 15:4–6; 彼得後書 3:18"> 不持定元首。全身既然靠着他，筋節得以相助聯絡，就因上帝大得長進。</span>
</div>
</div>

## 基督裏的新生活

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="歌羅西書 2:8; 歌羅西書 2:16; 加拉太書 4:3"> 你們若是與基督同死，脫離了世上的小學，為甚麼仍像在世俗中活着、服從那「不可拿、不可嘗、不可摸」等類的規條呢？</span>
<span className="v" id="v22" data-v="22" data-xref="以賽亞書 29:13; 提多書 1:14; 哥林多前書 6:13"> 這都是照人所吩咐、所教導的。說到這一切，正用的時候就都敗壞了。</span>
<span className="v" id="v23" data-v="23" data-xref="提摩太前書 4:8; 歌羅西書 2:18; 歌羅西書 2:8"> 這些規條使人徒有智慧之名，用私意崇拜，自表謙卑，苦待己身，其實在克制肉體的情慾上是毫無功效。</span>
</div>
</div>

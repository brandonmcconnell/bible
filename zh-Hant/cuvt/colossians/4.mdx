## 勸導

<div className="bt">
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="帖撒羅尼迦前書 5:17–18; 腓立比書 4:6; 以弗所書 6:18"> 你們要恆切禱告，在此警醒感恩。</span>
<span className="v" id="v3" data-v="3" data-xref="以弗所書 6:19–20; 使徒行傳 14:27; 帖撒羅尼迦後書 3:1–2"> 也要為我們禱告，求上帝給我們開傳道的門，能以講基督的奧祕（我為此被捆鎖），</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多後書 4:1–4; 以弗所書 6:20; 歌羅西書 4:6"> 叫我按着所該說的話將這奧祕發明出來。</span>
<span className="v" id="v5" data-v="5" data-xref="以弗所書 5:15–17; 帖撒羅尼迦前書 4:12; 雅各書 3:13"> 你們要愛惜光陰，用智慧與外人交往。</span>
<span className="v" id="v6" data-v="6" data-xref="以弗所書 4:29; 彼得前書 3:15; 傳道書 10:12"> 你們的言語要常常帶着和氣，好像用鹽調和，就可知道該怎樣回答各人。</span>

## 最後的問候

<div className="bt">
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="以弗所書 6:21–23; 使徒行傳 20:4; 提摩太後書 4:12"> 有我親愛的兄弟推基古要將我一切的事都告訴你們。他是忠心的執事，和我一同作主的僕人。</span>
<span className="v" id="v8" data-v="8" data-xref="以弗所書 6:22; 歌羅西書 2:2; 腓立比書 2:28"> 我特意打發他到你們那裏去，好叫你們知道我們的光景，又叫他安慰你們的心。</span>
<span className="v" id="v9" data-v="9" data-xref="腓利門書 1:10–19; 歌羅西書 4:7"> 我又打發一位親愛忠心的兄弟阿尼西謀同去；他也是你們那裏的人。他們要把這裏一切的事都告訴你們。</span>
<span className="v" id="v10" data-v="10" data-xref="腓利門書 1:24; 提摩太後書 4:11; 使徒行傳 19:29"> 與我一同坐監的亞里達古問你們安。巴拿巴的表弟馬可也問你們安。（說到這馬可，你們已經受了吩咐；他若到了你們那裏，你們就接待他。）</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行傳 11:2; 哥林多後書 6:1; 使徒行傳 10:45"> 耶數又稱為猶士都，也問你們安。奉割禮的人中，只有這三個人是為上帝的國與我一同做工的，也是叫我心裏得安慰的。</span>
<span className="v" id="v12" data-v="12" data-xref="羅馬書 15:30; 歌羅西書 1:9; 歌羅西書 1:7"> 有你們那裏的人，作基督耶穌僕人的以巴弗問你們安。他在禱告之間，常為你們竭力地祈求，願你們在上帝一切的旨意上得以完全，信心充足，能站立得穩。</span>
<span className="v" id="v13" data-v="13" data-xref="歌羅西書 2:1; 羅馬書 10:2; 啟示錄 1:11"> 他為你們和老底嘉並希拉坡里的弟兄多多地勞苦，這是我可以給他作見證的。</span>
<span className="v" id="v14" data-v="14" data-xref="腓利門書 1:24; 提摩太後書 4:10–11"> 所親愛的醫生路加和底馬問你們安。</span>
<span className="v" id="v15" data-v="15" data-xref="羅馬書 16:5; 腓利門書 1:2; 哥林多前書 16:9"> 請問老底嘉的弟兄和寧法，並她家裏的教會安。</span>
<span className="v" id="v16" data-v="16" data-xref="帖撒羅尼迦前書 5:27; 帖撒羅尼迦後書 3:14"> 你們念了這書信，便交給老底嘉的教會，叫他們也念；你們也要念從老底嘉來的書信。</span>
<span className="v" id="v17" data-v="17" data-xref="腓利門書 1:2; 使徒行傳 1:17; 以西結書 44:23–24"> 要對亞基布說：「務要謹慎，盡你從主所受的職分。」</span>
<span className="v" id="v18" data-v="18" data-xref="希伯來書 13:3; 提摩太後書 4:22; 提摩太前書 6:21"> 我－保羅親筆問你們安。你們要記念我的捆鎖。願恩惠常與你們同在！</span>

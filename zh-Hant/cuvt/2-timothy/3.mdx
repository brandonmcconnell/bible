## 末世的人性

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="彼得後書 3:3; 提摩太後書 4:3; 提摩太前書 4:1–3"> 你該知道，末世必有危險的日子來到。</span>
<span className="v" id="v2" data-v="2" data-xref="腓立比書 2:21; 羅馬書 1:29–31; 猶大書 1:16"> 因為那時，人要專顧自己，貪愛錢財，自誇，狂傲，謗讟，違背父母，忘恩負義，心不聖潔，</span>
<span className="v" id="v3" data-v="3" data-xref="猶大書 1:18; 羅馬書 1:31; 馬太福音 10:21"> 無親情，不解怨，好說讒言，不能自約，性情凶暴，不愛良善，</span>
<span className="v" id="v4" data-v="4" data-xref="腓立比書 3:18–19; 提摩太前書 3:6; 猶大書 1:4"> 賣主賣友，任意妄為，自高自大，愛宴樂，不愛上帝，</span>
<span className="v" id="v5" data-v="5" data-xref="以賽亞書 29:13; 提多書 1:16; 馬太福音 23:27–28"> 有敬虔的外貌，卻背了敬虔的實意；這等人你要躲開。</span>
<span className="v" id="v6" data-v="6" data-xref="猶大書 1:4; 彼得後書 3:17; 提多書 3:3"> 那偷進人家、牢籠無知婦女的，正是這等人。這些婦女擔負罪惡，被各樣的私慾引誘，</span>
<span className="v" id="v7" data-v="7" data-xref="提摩太後書 4:3–4; 以弗所書 4:14; 提摩太前書 2:4"> 常常學習，終久不能明白真道。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行傳 13:8–11; 啟示錄 2:20; 提摩太前書 6:5"> 從前雅尼和佯庇怎樣敵擋摩西，這等人也怎樣敵擋真道。他們的心地壞了，在真道上是可廢棄的。</span>
<span className="v" id="v9" data-v="9" data-xref="提摩太後書 3:8; 出埃及記 7:12; 耶利米書 28:15–17"> 然而他們不能再這樣敵擋；因為他們的愚昧必在眾人面前顯露出來，像那二人一樣。</span>
</div>
</div>

## 對提摩太的最後指示

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="提摩太前書 6:11; 提多書 2:7; 彼得後書 1:5–7"> 但你已經服從了我的教訓、品行、志向、信心、寬容、愛心、忍耐，</span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 34:19; 使徒行傳 14:5–6; 哥林多後書 11:23–28"> 以及我在安提阿、以哥念、路司得所遭遇的逼迫、苦難。我所忍受是何等的逼迫；但從這一切苦難中，主都把我救出來了。</span>
<span className="v" id="v12" data-v="12" data-xref="彼得前書 3:14; 彼得前書 4:12–16; 彼得前書 2:20–21"> 不但如此，凡立志在基督耶穌裏敬虔度日的也都要受逼迫。</span>
<span className="v" id="v13" data-v="13" data-xref="提摩太前書 4:1; 彼得後書 2:20; 提多書 3:3"> 只是作惡的和迷惑人的，必越久越惡，他欺哄人，也被人欺哄。</span>
<span className="v" id="v14" data-v="14" data-xref="帖撒羅尼迦前書 2:13; 提摩太後書 2:2; 提摩太後書 1:13"> 但你所學習的，所確信的，要存在心裏；因為你知道是跟誰學的，</span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 119:98–99; 路加福音 24:45; 箴言 22:6"> 並且知道你是從小明白聖經，這聖經能使你因信基督耶穌，有得救的智慧。</span>
<span className="v" id="v16" data-v="16" data-xref="羅馬書 15:4; 希伯來書 4:12; 彼得後書 1:19–21"> 聖經都是上帝所默示的<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或譯：凡上帝所默示的聖經">a</a></sup>，於教訓、督責、使人歸正、教導人學義都是有益的，</span>
<span className="v" id="v17" data-v="17" data-xref="提摩太後書 2:21; 以弗所書 2:10; 哥林多後書 9:8"> 叫屬上帝的人得以完全，預備行各樣的善事。</span>
</div>
</div>

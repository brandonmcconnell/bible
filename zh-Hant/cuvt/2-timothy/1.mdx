## 忠於福音

<div className="bt">
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="羅馬書 1:8–9; 希伯來書 13:8; 使徒行傳 23:1"> 我感謝上帝，就是我接續祖先用清潔的良心所事奉的上帝。祈禱的時候，不住的想念你，</span>
<span className="v" id="v4" data-v="4" data-xref="提摩太後書 4:9; 腓立比書 1:8; 帖撒羅尼迦前書 2:17–1"> 記念你的眼淚，晝夜切切地想要見你，好叫我滿心快樂。</span>
<span className="v" id="v5" data-v="5" data-xref="提摩太前書 1:5; 使徒行傳 16:1; 提摩太後書 3:15"> 想到你心裏無偽之信，這信是先在你外祖母羅以和你母親友妮基心裏的，我深信也在你的心裏。</span>
<span className="v" id="v6" data-v="6" data-xref="提摩太前書 4:14; 彼得前書 4:10–11; 羅馬書 12:6–8"> 為此我提醒你，使你將上帝藉我按手所給你的恩賜再如火挑旺起來。</span>
<span className="v" id="v7" data-v="7" data-xref="羅馬書 8:15; 約翰一書 4:18; 加拉太書 5:22"> 因為上帝賜給我們，不是膽怯的心，乃是剛強、仁愛、謹守的心。</span>
<span className="v" id="v8" data-v="8" data-xref="羅馬書 1:16; 馬可福音 8:38; 彼得前書 4:13–15"> 你不要以給我們的主作見證為恥，也不要以我這為主被囚的為恥；總要按上帝的能力，與我為福音同受苦難。</span>
<span className="v" id="v9" data-v="9" data-xref="以弗所書 2:8–9; 提多書 3:4–5; 以弗所書 1:3–4"> 上帝救了我們，以聖召召我們，不是按我們的行為，乃是按他的旨意和恩典；這恩典是萬古之先，在基督耶穌裏賜給我們的，</span>
<span className="v" id="v10" data-v="10" data-xref="約翰一書 1:2; 羅馬書 16:26; 彼得後書 3:18"> 但如今藉着我們救主基督耶穌的顯現才表明出來了。他已經把死廢去，藉着福音，將不能壞的生命彰顯出來。</span>
<span className="v" id="v11" data-v="11" data-xref="提摩太前書 2:7; 以弗所書 3:7–8; 使徒行傳 9:15"> 我為這福音奉派作傳道的，作使徒，作師傅。</span>
<span className="v" id="v12" data-v="12" data-xref="提摩太後書 1:8; 猶大書 1:24; 彼得前書 4:19"> 為這緣故，我也受這些苦難。然而我不以為恥；因為知道我所信的是誰，也深信他能保全我所交付他的<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或譯：他所交託我的">a</a></sup>，直到那日。</span>
<span className="v" id="v13" data-v="13" data-xref="提多書 1:9; 提摩太後書 3:14; 腓立比書 4:9"> 你從我聽的那純正話語的規模，要用在基督耶穌裏的信心和愛心，常常守着。</span>
<span className="v" id="v14" data-v="14" data-xref="約翰福音 14:17; 羅馬書 8:13; 提摩太前書 6:20"> 從前所交託你的善道，你要靠着那住在我們裏面的聖靈牢牢地守着。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="提摩太後書 4:16; 腓立比書 2:21; 使徒行傳 19:10"> 凡在亞細亞的人都離棄我，這是你知道的，其中有腓吉路和黑摩其尼。</span>
<span className="v" id="v16" data-v="16" data-xref="提摩太後書 4:19; 腓利門書 1:20; 腓利門書 1:7"> 願主憐憫阿尼色弗一家的人；因他屢次使我暢快，不以我的鎖鍊為恥，</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行傳 28:30–31"> 反倒在羅馬的時候，殷勤地找我，並且找着了。</span>
<span className="v" id="v18" data-v="18" data-xref="希伯來書 6:10; 提摩太後書 1:12; 提摩太前書 1:3"> 願主使他在那日得主的憐憫。他在以弗所怎樣多多地服事我，是你明明知道的。</span>
</div>

## 尼希米處理官長們的剝削

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以賽亞書 5:7; 出埃及記 22:25–27; 哥林多前書 6:6–8"> 百姓和他們的妻大大呼號，埋怨他們的弟兄猶大人。</span>
<span className="v" id="v2" data-v="2" data-xref="瑪拉基書 2:2; 詩篇 128:2–4; 詩篇 127:3–5"> 有的說：「我們和兒女人口眾多，要去得糧食度命」；</span>
<span className="v" id="v3" data-v="3" data-xref="利未記 25:35–39; 瑪拉基書 3:8–11; 創世記 47:15–25"> 有的說：「我們典了田地、葡萄園、房屋，要得糧食充飢」；</span>
<span className="v" id="v4" data-v="4" data-xref="以斯拉記 4:13; 以斯拉記 4:20; 申命記 28:47–48"> 有的說：「我們已經指着田地、葡萄園，借了錢給王納稅。</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀下 4:1; 利未記 25:39–43; 以賽亞書 58:7"> 我們的身體與我們弟兄的身體一樣；我們的兒女與他們的兒女一般。現在我們將要使兒女作人的僕婢，我們的女兒已有為婢的；我們並無力拯救，因為我們的田地、葡萄園已經歸了別人。」</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及記 11:8; 尼希米記 13:25; 以弗所書 4:26"> 我聽見他們呼號說這些話，便甚發怒。</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 23:19–20; 利未記 25:36; 出埃及記 22:25"> 我心裏籌劃，就斥責貴冑和官長說：「你們各人向弟兄取利！」於是我招聚大會攻擊他們。</span>
<span className="v" id="v8" data-v="8" data-xref="利未記 25:47–49; 哥林多前書 8:11; 馬太福音 25:29"> 我對他們說：「我們盡力贖回我們弟兄，就是賣與外邦的猶大人；你們還要賣弟兄，使我們贖回來嗎？」他們就靜默不語，無話可答。</span>
<span className="v" id="v9" data-v="9" data-xref="利未記 25:36; 撒母耳記下 12:14; 羅馬書 2:24"> 我又說：「你們所行的不善！你們行事不當敬畏我們的上帝嗎？不然，難免我們的仇敵外邦人毀謗我們。</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多後書 6:1; 出埃及記 22:25–27; 以西結書 18:13"> 我和我的弟兄與僕人也將銀錢糧食借給百姓；我們大家都當免去利息。</span>
<span className="v" id="v11" data-v="11" data-xref="以賽亞書 58:6; 利未記 6:4–5; 路加福音 3:8"> 如今我勸你們將他們的田地、葡萄園、橄欖園、房屋，並向他們所取的銀錢、糧食、新酒，和油，百分之一的利息都歸還他們。」</span>
<span className="v" id="v12" data-v="12" data-xref="以斯拉記 10:5; 耶利米書 34:8–10; 馬太福音 19:21–22"> 眾人說：「我們必歸還，不再向他們索要，必照你的話行。」我就召了祭司來，叫眾人起誓，必照着所應許的而行。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行傳 18:6; 歷代志上 16:36; 馬太福音 10:14"> 我也抖着胸前的衣襟，說：「凡不成就這應許的，願上帝照樣抖他離開家產和他勞碌得來的，直到抖空了。」會眾都說：「阿們！」又讚美耶和華。百姓就照着所應許的去行。</span>
</div>
</div>

## 尼希米大公無私

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="尼希米記 13:6; 帖撒羅尼迦後書 3:8–9; 哥林多前書 9:4–15"> 自從我奉派作猶大地的省長，就是從亞達薛西王二十年直到三十二年，共十二年之久，我與我弟兄都沒有吃省長的俸祿。</span>
<span className="v" id="v15" data-v="15" data-xref="尼希米記 5:9; 以賽亞書 50:10; 箴言 16:6"> 在我以前的省長加重百姓的擔子，每日索要糧食和酒，並銀子四十舍客勒，就是他們的僕人也轄制百姓；但我因敬畏上帝不這樣行。</span>
<span className="v" id="v16" data-v="16" data-xref="加拉太書 6:9; 帖撒羅尼迦前書 2:5–6; 哥林多前書 15:58"> 並且我恆心修造城牆，並沒有置買田地；我的僕人也都聚集在那裏做工。</span>
<span className="v" id="v17" data-v="17" data-xref="列王紀上 18:19; 彼得前書 4:9–10; 撒母耳記下 9:7"> 除了從四圍外邦中來的猶大人以外，有猶大平民和官長一百五十人在我席上吃飯。</span>
<span className="v" id="v18" data-v="18" data-xref="列王紀上 4:22–23; 詩篇 37:21; 詩篇 37:26"> 每日預備一隻公牛，六隻肥羊，又預備些飛禽；每十日一次，多預備各樣的酒。雖然如此，我並不要省長的俸祿，因為百姓服役甚重。</span>
<span className="v" id="v19" data-v="19" data-xref="尼希米記 13:31; 詩篇 106:4; 尼希米記 13:14"> 我的上帝啊，求你記念我為這百姓所行的一切事，施恩與我。</span>
</div>

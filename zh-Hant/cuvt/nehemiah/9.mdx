## 以色列人承認他們的罪

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行傳 13:2–3; 以斯拉記 8:23; 尼希米記 8:2"> 這月二十四日，以色列人聚集禁食，身穿麻衣，頭蒙灰塵。</span>
<span className="v" id="v2" data-v="2" data-xref="但以理書 9:3–10; 尼希米記 13:3; 以斯拉記 10:11"> 以色列人<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="人：原文是種類">a</a></sup>就與一切外邦人離絕，站着承認自己的罪惡和列祖的罪孽。</span>
<span className="v" id="v3" data-v="3" data-xref="尼希米記 8:7–8; 尼希米記 8:3–4"> 那日的四分之一站在自己的地方念耶和華－他們上帝的律法書，又四分之一認罪，敬拜耶和華－他們的上帝。</span>
<span className="v" id="v4" data-v="4" data-xref="尼希米記 8:7; 尼希米記 12:8; 尼希米記 9:5"> 耶書亞、巴尼、甲篾、示巴尼、布尼、示利比、巴尼、基拿尼站在利未人的臺上，大聲哀求耶和華－他們的上帝。</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 103:1–2; 彼得前書 1:3; 哥林多後書 4:6"> 利未人耶書亞、甲篾、巴尼、哈沙尼、示利比、荷第雅、示巴尼、毗他希雅說：「你們要站起來稱頌耶和華－你們的上帝，永世無盡。耶和華啊，你榮耀之名是應當稱頌的！超乎一切稱頌和讚美。」</span>
</div>
</div>

## 認罪的禱告

<div className="bt">
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="以賽亞書 37:16; 創世記 1:1; 啟示錄 4:11"> 「你，惟獨你是耶和華！你造了天和天上的天，並天上的萬象，地和地上的萬物，海和海中所有的；這一切都是你所保存的。天軍也都敬拜你。</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 11:31; 創世記 17:5; 以賽亞書 51:2"> 你是耶和華上帝，曾揀選亞伯蘭，領他出迦勒底的吾珥，給他改名叫亞伯拉罕。</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 15:6; 創世記 15:18–21; 希伯來書 6:18"> 你見他在你面前心裏誠實，就與他立約，應許把迦南人、赫人、亞摩利人、比利洗人、耶布斯人、革迦撒人之地賜給他的後裔，且應驗了你的話，因為你是公義的。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="出埃及記 3:7–9; 使徒行傳 7:34; 出埃及記 3:16"> 「你曾看見我們列祖在埃及所受的困苦，垂聽他們在紅海邊的哀求，</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米書 32:20; 但以理書 9:15; 出埃及記 18:11"> 就施行神蹟奇事在法老和他一切臣僕，並他國中的眾民身上。你也得了名聲，正如今日一樣，因為你知道他們向我們列祖行事狂傲。</span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 78:13; 出埃及記 14:21–22; 出埃及記 14:27–28"> 你又在我們列祖面前把海分開，使他們在海中行走乾地，將追趕他們的人拋在深海，如石頭拋在大水中；</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及記 13:21–22; 尼希米記 9:19; 詩篇 107:7"> 並且白晝用雲柱引導他們，黑夜用火柱照亮他們當行的路。</span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 119:160; 出埃及記 20:1; 詩篇 119:127–128"> 你也降臨在西奈山，從天上與他們說話，賜給他們正直的典章、真實的律法、美好的條例與誡命，</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及記 20:8–11; 創世記 2:3; 以西結書 20:12"> 又使他們知道你的安息聖日，並藉你僕人摩西傳給他們誡命、條例、律法。</span>
<span className="v" id="v15" data-v="15" data-xref="哥林多前書 10:3–4; 申命記 1:8; 出埃及記 17:6"> 從天上賜下糧食充他們的飢，從磐石使水流出解他們的渴，又吩咐他們進去得你起誓應許賜給他們的地。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="尼希米記 9:29; 詩篇 81:11–14; 希伯來書 3:15"> 「但我們的列祖行事狂傲，硬着頸項不聽從你的誡命；</span>
<span className="v" id="v17" data-v="17" data-xref="詩篇 86:5; 約珥書 2:13; 詩篇 145:8–9"> 不肯順從，也不記念你在他們中間所行的奇事，竟硬着頸項，居心背逆，自立首領，要回他們為奴之地。但你是樂意饒恕人，有恩典，有憐憫，不輕易發怒，有豐盛慈愛的上帝，並不丟棄他們。</span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 106:19–23; 出埃及記 32:4–8; 以西結書 20:7–44"> 他們雖然鑄了一隻牛犢，彼此說『這是領你出埃及的神』，因而大大惹動你的怒氣；</span>
<span className="v" id="v19" data-v="19" data-xref="詩篇 106:45; 尼希米記 9:27; 瑪拉基書 3:6"> 你還是大施憐憫，在曠野不丟棄他們。白晝，雲柱不離開他們，仍引導他們行路；黑夜，火柱也不離開他們，仍照亮他們當行的路。</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 143:10; 民數記 11:17; 以賽亞書 63:11–14"> 你也賜下你良善的靈教訓他們；未嘗不賜嗎哪使他們糊口，並賜水解他們的渴。</span>
<span className="v" id="v21" data-v="21" data-xref="申命記 2:7; 申命記 8:4; 詩篇 34:10"> 在曠野四十年，你養育他們，他們就一無所缺：衣服沒有穿破，腳也沒有腫。</span>
<span className="v" id="v22" data-v="22" data-xref="民數記 21:21–35; 申命記 3:1–17; 申命記 2:26–36"> 並且你將列國之地照分賜給他們，他們就得了西宏之地、希實本王之地，和巴珊王噩之地。</span>
<span className="v" id="v23" data-v="23" data-xref="創世記 22:17; 創世記 15:5; 歷代志上 27:23"> 你也使他們的子孫多如天上的星，帶他們到你所應許他們列祖進入得為業之地。</span>
<span className="v" id="v24" data-v="24" data-xref="約書亞記 21:43; 約書亞記 11:23; 詩篇 44:2–3"> 這樣，他們進去得了那地，你在他們面前制伏那地的居民，就是迦南人；將迦南人和其君王，並那地的居民，都交在他們手裏，讓他們任意而待。</span>
<span className="v" id="v25" data-v="25" data-xref="申命記 32:15; 尼希米記 9:35; 申命記 3:5"> 他們得了堅固的城邑、肥美的地土、充滿各樣美物的房屋、鑿成的水井、葡萄園、橄欖園，並許多果木樹。他們就吃而得飽，身體肥胖，因你的大恩，心中快樂。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="列王紀上 14:9; 士師記 2:11–12; 尼希米記 9:18"> 「然而，他們不順從，竟背叛你，將你的律法丟在背後，殺害那勸他們歸向你的眾先知，大大惹動你的怒氣。</span>
<span className="v" id="v27" data-v="27" data-xref="詩篇 106:41–45; 列王紀下 14:27; 列王紀下 13:5"> 所以你將他們交在敵人的手中，磨難他們。他們遭難的時候哀求你，你就從天上垂聽，照你的大憐憫賜給他們拯救者，救他們脫離敵人的手。</span>
<span className="v" id="v28" data-v="28" data-xref="士師記 5:31–1; 士師記 4:1; 列王紀上 8:39"> 但他們得平安之後，又在你面前行惡，所以你丟棄他們在仇敵的手中，使仇敵轄制他們。然而他們轉回哀求你，你仍從天上垂聽，屢次照你的憐憫拯救他們，</span>
<span className="v" id="v29" data-v="29" data-xref="尼希米記 9:16; 利未記 18:5; 尼希米記 9:26"> 又警戒他們，要使他們歸服你的律法。他們卻行事狂傲，不聽從你的誡命，干犯你的典章（人若遵行就必因此活着），扭轉肩頭，硬着頸項，不肯聽從。</span>
<span className="v" id="v30" data-v="30" data-xref="羅馬書 2:4; 歷代志下 36:15–16; 以賽亞書 42:24"> 但你多年寬容他們，又用你的靈藉眾先知勸戒他們，他們仍不聽從，所以你將他們交在列國之民的手中。</span>
<span className="v" id="v31" data-v="31" data-xref="耶利米哀歌 3:22; 耶利米書 4:27; 尼希米記 9:17"> 然而你大發憐憫，不全然滅絕他們，也不丟棄他們；因為你是有恩典、有憐憫的上帝。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="申命記 7:9; 尼希米記 1:5; 但以理書 9:4"> 「我們的上帝啊，你是至大、至能、至可畏、守約施慈愛的上帝。我們的君王、首領、祭司、先知、列祖，和你的眾民，從亞述列王的時候直到今日所遭遇的苦難，現在求你不要以為小。</span>
<span className="v" id="v33" data-v="33" data-xref="創世記 18:25; 詩篇 106:6; 約伯記 34:23"> 在一切臨到我們的事上，你卻是公義的；因你所行的是誠實，我們所做的是邪惡。</span>
<span className="v" id="v34" data-v="34" data-xref="耶利米書 29:19; 列王紀下 17:13; 申命記 31:21"> 我們的君王、首領、祭司、列祖都不遵守你的律法，不聽從你的誡命和你警戒他們的話。</span>
<span className="v" id="v35" data-v="35" data-xref="申命記 28:47; 申命記 32:12–15; 耶利米書 5:19"> 他們在本國裏沾你大恩的時候，在你所賜給他們這廣大肥美之地上不事奉你，也不轉離他們的惡行。</span>
<span className="v" id="v36" data-v="36" data-xref="以斯拉記 9:9; 申命記 28:48; 歷代志下 12:8"> 我們現今作了奴僕；至於你所賜給我們列祖享受其上的土產，並美物之地，看哪，我們在這地上作了奴僕！</span>
<span className="v" id="v37" data-v="37" data-xref="申命記 28:33; 申命記 28:48; 以斯拉記 7:24"> 這地許多出產歸了列王，就是你因我們的罪所派轄制我們的。他們任意轄制我們的身體和牲畜，我們遭了大難。」</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="尼希米記 10:1; 歷代志下 34:31; 以斯拉記 10:3"> 因這一切的事，我們立確實的約，寫在冊上。我們的首領、利未人，和祭司都簽了名。</span>
</div>
</div>

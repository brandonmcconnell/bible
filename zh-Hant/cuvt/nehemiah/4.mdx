## 尼希米勝過阻撓他工作的人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="尼希米記 2:10; 希伯來書 11:36; 詩篇 35:15–16"> 參巴拉聽見我們修造城牆就發怒，大大惱恨，嗤笑猶大人，</span>
<span className="v" id="v2" data-v="2" data-xref="以斯拉記 4:9–10; 哥林多前書 1:27; 以西結書 37:3–13"> 對他弟兄和撒馬利亞的軍兵說：「這些軟弱的猶大人做甚麼呢？要保護自己嗎？要獻祭嗎？要一日成功嗎？要從土堆裏拿出火燒的石頭再立牆嗎？」</span>
<span className="v" id="v3" data-v="3" data-xref="尼希米記 2:19; 列王紀上 20:10; 尼希米記 2:10"> 亞捫人多比雅站在旁邊，說：「他們所修造的石牆，就是狐狸上去也必跐倒。」</span>
<span className="v" id="v4" data-v="4" data-xref="詩篇 79:12; 詩篇 123:3–4; 箴言 3:34"> 我們的上帝啊，求你垂聽，因為我們被藐視。求你使他們的毀謗歸於他們的頭上，使他們在擄到之地作為掠物。</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 109:14; 耶利米書 18:23; 詩篇 69:27–28"> 不要遮掩他們的罪孽，不要使他們的罪惡從你面前塗抹，因為他們在修造的人眼前惹動你的怒氣。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="腓立比書 2:13; 尼希米記 6:15; 希伯來書 13:21"> 這樣，我們修造城牆，城牆就都連絡，高至一半，因為百姓專心做工。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="尼希米記 2:10; 尼希米記 4:1; 使徒行傳 5:33"> 參巴拉、多比雅、阿拉伯人、亞捫人、亞實突人聽見修造耶路撒冷城牆，着手進行堵塞破裂的地方，就甚發怒。</span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 83:3–11; 以賽亞書 8:9–10; 耶利米書 20:10"> 大家同謀要來攻擊耶路撒冷，使城內擾亂。</span>
<span className="v" id="v9" data-v="9" data-xref="彼得前書 5:8; 使徒行傳 4:24–30; 詩篇 50:15"> 然而，我們禱告我們的上帝，又因他們的緣故，就派人看守，晝夜防備。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="詩篇 11:1–2; 哈該書 1:2; 歷代志下 2:18"> 猶大人說：「灰土尚多，扛抬的人力氣已經衰敗，所以我們不能建造城牆。」</span>
<span className="v" id="v11" data-v="11" data-xref="帖撒羅尼迦前書 5:2; 使徒行傳 23:12; 詩篇 56:6"> 我們的敵人且說：「趁他們不知不見，我們進入他們中間，殺他們，使工作止住。」</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 31:7; 創世記 31:41; 民數記 14:22"> 那靠近敵人居住的猶大人十次從各處來見我們，說：「你們必要回到我們那裏。」</span>
<span className="v" id="v13" data-v="13" data-xref="尼希米記 4:17–18; 以弗所書 6:11–20; 雅歌 3:7–8"> 所以我使百姓各按宗族拿刀、拿槍、拿弓站在城牆後邊低窪的空處。</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳記下 10:12; 民數記 14:9; 以賽亞書 41:10–14"> 我察看了，就起來對貴冑、官長，和其餘的人說：「不要怕他們！當記念主是大而可畏的。你們要為弟兄、兒女、妻子、家產爭戰。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="撒母耳記下 17:14; 羅馬書 12:11; 約伯記 5:12–13"> 仇敵聽見我們知道他們的心意，見上帝也破壞他們的計謀，就不來了。我們都回到城牆那裏，各做各的工。</span>
<span className="v" id="v16" data-v="16" data-xref="尼希米記 4:23; 詩篇 101:6; 尼希米記 5:15–16"> 從那日起，我的僕人一半做工，一半拿槍、拿盾牌、拿弓、穿<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或譯：拿">a</a></sup>鎧甲，官長都站在猶大眾人的後邊。</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多後書 6:7; 提摩太後書 4:7; 提摩太後書 2:3"> 修造城牆的，扛抬材料的，都一手做工一手拿兵器。</span>
<span className="v" id="v18" data-v="18" data-xref="民數記 10:9; 歷代志下 13:12–17"> 修造的人都腰間佩刀修造，吹角的人在我旁邊。</span>
<span className="v" id="v19" data-v="19"> 我對貴冑、官長，和其餘的人說：「這工程浩大，我們在城牆上相離甚遠；</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及記 14:14; 申命記 1:30; 申命記 20:4"> 你們聽見角聲在哪裏，就聚集到我們那裏去。我們的上帝必為我們爭戰。」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="加拉太書 6:9; 歌羅西書 1:29; 哥林多前書 15:58"> 於是，我們做工，一半拿兵器，從天亮直到星宿出現的時候。</span>
<span className="v" id="v22" data-v="22" data-xref="尼希米記 11:1–2"> 那時，我又對百姓說：「各人和他的僕人當在耶路撒冷住宿，好在夜間保守我們，白晝做工。」</span>
<span className="v" id="v23" data-v="23" data-xref="士師記 9:48; 尼希米記 7:2; 哥林多前書 15:10"> 這樣，我和弟兄僕人，並跟從我的護兵都不脫衣服，出去打水也帶兵器。</span>
</div>
</div>

## 以斯拉向民眾宣讀律法書

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以斯拉記 7:6; 尼希米記 3:26; 歷代志下 34:15"> 到了七月，以色列人住在自己的城裏。那時，他們如同一人聚集在水門前的寬闊處，請文士以斯拉將耶和華藉摩西傳給以色列人的律法書帶來。</span>
<span className="v" id="v2" data-v="2" data-xref="利未記 23:24; 瑪拉基書 2:7; 民數記 29:1"> 七月初一日，祭司以斯拉將律法書帶到聽了能明白的男女會眾面前。</span>
<span className="v" id="v3" data-v="3" data-xref="啟示錄 3:22; 啟示錄 2:29; 希伯來書 2:1–3"> 在水門前的寬闊處，從清早到晌午，在眾男女、一切聽了能明白的人面前讀這律法書。眾民側耳而聽。</span>
<span className="v" id="v4" data-v="4" data-xref="以斯拉記 10:29; 尼希米記 12:13; 尼希米記 10:20"> 文士以斯拉站在為這事特備的木臺上。瑪他提雅、示瑪、亞奈雅、烏利亞、希勒家，和瑪西雅站在他的右邊；毗大雅、米沙利、瑪基雅、哈順、哈拔大拿、撒迦利亞，和米書蘭站在他的左邊。</span>
<span className="v" id="v5" data-v="5" data-xref="士師記 3:20; 列王紀上 8:14; 路加福音 4:16–17"> 以斯拉站在眾民以上，在眾民眼前展開這書。他一展開，眾民就都站起來。</span>
<span className="v" id="v6" data-v="6" data-xref="提摩太前書 2:8; 耶利米哀歌 3:41; 出埃及記 4:31"> 以斯拉稱頌耶和華至大的上帝；眾民都舉手應聲說：「阿們！阿們！」就低頭，面伏於地，敬拜耶和華。</span>
<span className="v" id="v7" data-v="7" data-xref="尼希米記 9:4; 利未記 10:11; 尼希米記 3:23"> 耶書亞、巴尼、示利比、雅憫、亞谷、沙比太、荷第雅、瑪西雅、基利他、亞撒利雅、約撒拔、哈難、毗萊雅，和利未人使百姓明白律法；百姓都站在自己的地方。</span>
<span className="v" id="v8" data-v="8" data-xref="路加福音 24:45; 使徒行傳 28:23; 路加福音 24:32"> 他們清清楚楚地念上帝的律法書，講明意思，使百姓明白所念的。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="尼希米記 7:65; 尼希米記 7:70; 申命記 12:12"> 省長尼希米和作祭司的文士以斯拉，並教訓百姓的利未人，對眾民說：「今日是耶和華－你們上帝的聖日，不要悲哀哭泣。」這是因為眾民聽見律法書上的話都哭了；</span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 28:7–8; 箴言 17:22; 哥林多後書 12:8–9"> 又對他們說：「你們去吃肥美的，喝甘甜的，有不能預備的就分給他，因為今日是我們主的聖日。你們不要憂愁，因靠耶和華而得的喜樂是你們的力量。」</span>
<span className="v" id="v11" data-v="11" data-xref="民數記 13:30"> 於是利未人使眾民靜默，說：「今日是聖日；不要作聲，也不要憂愁。」</span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 119:174; 詩篇 119:111; 詩篇 119:130"> 眾民都去吃喝，也分給人，大大快樂，因為他們明白所教訓他們的話。</span>
</div>
</div>

## 住棚節

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="箴言 2:1–6; 箴言 8:33–34; 箴言 12:1"> 次日，眾民的族長、祭司，和利未人都聚集到文士以斯拉那裏，要留心聽律法上的話。</span>
<span className="v" id="v14" data-v="14" data-xref="利未記 23:34; 申命記 16:13–15; 利未記 23:40–43"> 他們見律法上寫着，耶和華藉摩西吩咐以色列人要在七月節住棚，</span>
<span className="v" id="v15" data-v="15" data-xref="利未記 23:40; 申命記 16:16; 利未記 23:4"> 並要在各城和耶路撒冷宣傳報告說：「你們當上山，將橄欖樹、野橄欖樹、番石榴樹、棕樹，和各樣茂密樹的枝子取來，照着所寫的搭棚。」</span>
<span className="v" id="v16" data-v="16" data-xref="尼希米記 12:39; 列王紀下 14:13; 尼希米記 12:37"> 於是百姓出去，取了樹枝來，各人在自己的房頂上，或院內，或上帝殿的院內，或水門的寬闊處，或以法蓮門的寬闊處搭棚。</span>
<span className="v" id="v17" data-v="17" data-xref="歷代志下 8:13; 以斯拉記 3:4; 歷代志下 7:8–10"> 從擄到之地歸回的全會眾就搭棚，住在棚裏。從嫩的兒子約書亞的時候直到這日，以色列人沒有這樣行。於是眾人大大喜樂。</span>
<span className="v" id="v18" data-v="18" data-xref="民數記 29:35; 利未記 23:36; 申命記 31:10–13"> 從頭一天直到末一天，以斯拉每日念上帝的律法書。眾人守節七日，第八日照例有嚴肅會。</span>
</div>
</div>

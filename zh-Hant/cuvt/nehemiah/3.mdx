## 重建耶路撒冷城牆

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="尼希米記 12:39; 耶利米書 31:38; 約翰福音 5:2"> 那時，大祭司以利亞實和他的弟兄眾祭司起來建立羊門，分別為聖，安立門扇，又築城牆到哈米亞樓，直到哈楠業樓，分別為聖。</span>
<span className="v" id="v2" data-v="2" data-xref="尼希米記 7:36; 以斯拉記 2:34; 尼希米記 10:12"> 其次是耶利哥人建造。其次是音利的兒子撒刻建造。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="歷代志下 33:14; 尼希米記 12:39; 西番雅書 1:10"> 哈西拿的子孫建立魚門，架橫樑、安門扇，和閂鎖。</span>
<span className="v" id="v4" data-v="4" data-xref="以斯拉記 8:33; 尼希米記 3:21; 尼希米記 10:7"> 其次是哈哥斯的孫子、烏利亞的兒子米利末修造。其次是米示薩別的孫子、比利迦的兒子米書蘭修造。其次是巴拿的兒子撒督修造。</span>
<span className="v" id="v5" data-v="5" data-xref="尼希米記 3:27; 撒母耳記下 14:2; 耶利米書 27:2"> 其次是提哥亞人修造；但是他們的貴冑不用肩<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是頸項">a</a></sup>擔他們主的工作。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="尼希米記 12:39"> 巴西亞的兒子耶何耶大與比所玳的兒子米書蘭修造古門，架橫樑，安門扇和閂鎖。</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳記下 21:2; 約書亞記 9:3–27; 尼希米記 3:19"> 其次是基遍人米拉提，米倫人雅頓與基遍人，並屬河西總督所管的米斯巴人修造。</span>
<span className="v" id="v8" data-v="8" data-xref="尼希米記 12:38; 尼希米記 3:31–32; 創世記 50:2"> 其次是銀匠哈海雅的兒子烏薛修造。其次是做香的哈拿尼雅修造。這些人修堅耶路撒冷，直到寬牆。</span>
<span className="v" id="v9" data-v="9" data-xref="尼希米記 3:12; 尼希米記 3:17"> 其次是管理耶路撒冷一半、戶珥的兒子利法雅修造。</span>
<span className="v" id="v10" data-v="10" data-xref="尼希米記 3:28–30; 尼希米記 10:4; 尼希米記 3:23"> 其次是哈路抹的兒子耶大雅對着自己的房屋修造。其次是哈沙尼的兒子哈突修造。</span>
<span className="v" id="v11" data-v="11" data-xref="尼希米記 12:38; 以斯拉記 2:6; 尼希米記 10:14"> 哈琳的兒子瑪基雅和巴哈‧摩押的兒子哈述修造一段，並修造爐樓。</span>
<span className="v" id="v12" data-v="12" data-xref="尼希米記 3:9; 使徒行傳 21:8–9; 出埃及記 35:25"> 其次是管理耶路撒冷那一半、哈羅黑的兒子沙龍和他的女兒們修造。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="尼希米記 2:13; 約書亞記 15:34; 歷代志下 26:9"> 哈嫩和撒挪亞的居民修造谷門，立門，安門扇和閂鎖，又建築城牆一千肘，直到糞廠門。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="耶利米書 6:1; 尼希米記 2:13; 尼希米記 3:12–13"> 管理伯‧哈基琳、利甲的兒子瑪基雅修造糞廠門，立門，安門扇和閂鎖。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="約翰福音 9:7; 以賽亞書 8:6; 尼希米記 12:37"> 管理米斯巴、各荷西的兒子沙崙修造泉門，立門，蓋門頂，安門扇和閂鎖，又修造靠近王園西羅亞池的牆垣，直到那從大衛城下來的臺階。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行傳 2:29; 尼希米記 3:9; 列王紀下 20:20"> 其次是管理伯‧夙一半、押卜的兒子尼希米修造，直到大衛墳地的對面，又到挖成的池子，並勇士的房屋。</span>
</div>
</div>

## 造城牆的利未人

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="約書亞記 15:44; 尼希米記 3:16; 撒母耳記上 23:1–13"> 其次是利未人巴尼的兒子利宏修造。其次是管理基伊拉一半、哈沙比雅為他所管的本境修造。</span>
<span className="v" id="v18" data-v="18"> 其次是利未人弟兄中管理基伊拉那一半、希拿達的兒子巴瓦伊修造。</span>
<span className="v" id="v19" data-v="19" data-xref="歷代志下 26:9; 尼希米記 10:9; 尼希米記 12:8"> 其次是管理米斯巴、耶書亞的兒子以謝修造一段，對着武庫的上坡、城牆轉彎之處。</span>
<span className="v" id="v20" data-v="20" data-xref="尼希米記 3:1; 傳道書 9:10; 羅馬書 12:11"> 其次是薩拜的兒子巴錄竭力修造一段，從城牆轉彎，直到大祭司以利亞實的府門。</span>
<span className="v" id="v21" data-v="21" data-xref="尼希米記 7:63; 以斯拉記 2:61"> 其次是哈哥斯的孫子、烏利亞的兒子米利末修造一段，從以利亞實的府門，直到以利亞實府的盡頭。</span>
</div>
</div>

## 造城牆的祭司

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="尼希米記 12:28; 尼希米記 6:2"> 其次是住平原的祭司修造。</span>
<span className="v" id="v23" data-v="23" data-xref="尼希米記 10:2; 尼希米記 8:4; 尼希米記 3:29–30"> 其次是便雅憫與哈述對着自己的房屋修造。其次是亞難尼的孫子、瑪西雅的兒子亞撒利雅在靠近自己的房屋修造。</span>
<span className="v" id="v24" data-v="24" data-xref="尼希米記 3:19; 尼希米記 3:27; 尼希米記 10:9"> 其次是希拿達的兒子賓內修造一段，從亞撒利雅的房屋直到城牆轉彎，又到城角。</span>
<span className="v" id="v25" data-v="25" data-xref="耶利米書 32:2; 耶利米書 37:21; 尼希米記 12:39"> 烏賽的兒子巴拉修造對着城牆的轉彎和王上宮凸出來的城樓，靠近護衛院的那一段。其次是巴錄的兒子毗大雅修造。（</span>
<span className="v" id="v26" data-v="26" data-xref="尼希米記 8:1; 尼希米記 11:21; 尼希米記 12:37"> 尼提寧住在俄斐勒，直到朝東水門的對面和凸出來的城樓。）</span>
</div>
</div>

## 其他建造的人

<div className="bt">
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="尼希米記 3:5"> 其次是提哥亞人又修一段，對着那凸出來的大樓，直到俄斐勒的牆。</span>
<span className="v" id="v28" data-v="28" data-xref="歷代志下 23:15; 耶利米書 31:40; 列王紀下 11:16"> 從馬門往上，眾祭司各對自己的房屋修造。</span>
<span className="v" id="v29" data-v="29" data-xref="耶利米書 19:2; 以斯拉記 2:37; 尼希米記 7:40"> 其次是音麥的兒子撒督對着自己的房屋修造。其次是守東門、示迦尼的兒子示瑪雅修造。</span>
<span className="v" id="v30" data-v="30"> 其次是示利米雅的兒子哈拿尼雅和薩拉的第六子哈嫩又修一段。其次是比利迦的兒子米書蘭對着自己的房屋修造。</span>
<span className="v" id="v31" data-v="31" data-xref="尼希米記 3:8; 尼希米記 3:32"> 其次是銀匠瑪基雅修造到尼提寧和商人的房屋，對着哈米弗甲門，直到城的角樓。</span>
<span className="v" id="v32" data-v="32" data-xref="尼希米記 3:1; 約翰福音 5:2; 尼希米記 12:39"> 銀匠與商人在城的角樓和羊門中間修造。</span>
</div>
</div>

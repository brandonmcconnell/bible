<div className="bp">

## 城牆落成時尼希米行奉獻之禮

<div className="bt">
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="歷代志上 15:16; 歷代志上 15:28; 歷代志下 29:30"> 耶路撒冷城牆告成的時候，眾民就把各處的利未人招到耶路撒冷，要稱謝、歌唱、敲鈸、鼓瑟、彈琴，歡歡喜喜地行告成之禮。</span>
<span className="v" id="v28" data-v="28" data-xref="歷代志上 9:16; 歷代志上 2:54; 尼希米記 6:2"> 歌唱的人從耶路撒冷的周圍和尼陀法的村莊與伯‧吉甲，又從迦巴和押瑪弗的田地聚集，因為歌唱的人在耶路撒冷四圍為自己立了村莊。</span>
<span className="v" id="v30" data-v="30" data-xref="約伯記 1:5; 出埃及記 19:10; 歷代志下 29:5"> 祭司和利未人就潔淨自己，也潔淨百姓和城門，並城牆。</span>
<span className="v" id="v31" data-v="31" data-xref="尼希米記 2:13; 尼希米記 12:38; 歷代志上 13:1"> 我帶猶大的首領上城，使稱謝的人分為兩大隊，排列而行：第一隊在城上往右邊向糞廠門行走，</span>
<span className="v" id="v32" data-v="32"> 在他們後頭的有何沙雅與猶大首領的一半，</span>
<span className="v" id="v33" data-v="33" data-xref="尼希米記 10:2–7"> 又有亞撒利雅、以斯拉、米書蘭、</span>
<span className="v" id="v34" data-v="34"> 猶大、便雅憫、示瑪雅、耶利米。</span>
<span className="v" id="v35" data-v="35" data-xref="約書亞記 6:4; 民數記 10:2–10; 歷代志下 5:12"> 還有些吹號之祭司的子孫，約拿單的兒子撒迦利亞。約拿單是示瑪雅的兒子；示瑪雅是瑪他尼的兒子；瑪他尼是米該亞的兒子；米該亞是撒刻的兒子；撒刻是亞薩的兒子；</span>
<span className="v" id="v36" data-v="36" data-xref="尼希米記 12:24; 歷代志下 8:14; 歷代志上 23:5"> 又有撒迦利亞的弟兄示瑪雅、亞撒利、米拉萊、基拉萊、瑪艾、拿坦業、猶大、哈拿尼，都拿着神人大衛的樂器，文士以斯拉引領他們。</span>
<span className="v" id="v37" data-v="37" data-xref="尼希米記 3:26; 尼希米記 2:14; 尼希米記 8:3"> 他們經過泉門往前，從大衛城的臺階隨地勢而上，在大衛宮殿以上，直行到朝東的水門。</span>
<span className="v" id="v38" data-v="38" data-xref="尼希米記 3:8; 尼希米記 3:11; 尼希米記 12:31"> 第二隊稱謝的人要與那一隊相迎而行。我和民的一半跟隨他們，在城牆上過了爐樓，直到寬牆；</span>
<span className="v" id="v39" data-v="39" data-xref="尼希米記 3:1; 尼希米記 3:3; 尼希米記 8:16"> 又過了以法蓮門、古門、魚門、哈楠業樓、哈米亞樓，直到羊門，就在護衛門站住。</span>
<span className="v" id="v40" data-v="40" data-xref="詩篇 42:4; 詩篇 134:1–3; 尼希米記 12:31–32"> 於是，這兩隊稱謝的人連我和官長的一半，站在上帝的殿裏。</span>
<span className="v" id="v41" data-v="41"> 還有祭司以利亞金、瑪西雅、米拿民、米該亞、以利約乃、撒迦利亞、哈楠尼亞吹號；</span>
<span className="v" id="v42" data-v="42" data-xref="詩篇 81:1; 尼希米記 11:14; 詩篇 100:1–2"> 又有瑪西雅、示瑪雅、以利亞撒、烏西、約哈難、瑪基雅、以攔，和以謝奏樂。歌唱的就大聲歌唱，伊斯拉希雅管理他們。</span>
<span className="v" id="v43" data-v="43" data-xref="以斯拉記 3:13; 詩篇 92:4; 耶利米書 31:13"> 那日，眾人獻大祭而歡樂；因為上帝使他們大大歡樂，連婦女帶孩童也都歡樂，甚至耶路撒冷中的歡聲聽到遠處。</span>
</div>

## 聖殿的各種職責

<div className="bt">
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="尼希米記 13:12–13; 尼希米記 10:37–39; 歷代志下 31:11–13"> 當日，派人管理庫房，將舉祭、初熟之物和所取的十分之一，就是按各城田地，照律法所定歸給祭司和利未人的分，都收在裏頭。猶大人因祭司和利未人供職，就歡樂了。</span>
<span className="v" id="v45" data-v="45" data-xref="歷代志上 25:1–26; 歷代志下 23:6; 歷代志上 23:28"> 祭司利未人遵守上帝所吩咐的，並守潔淨的禮。歌唱的、守門的，照着大衛和他兒子所羅門的命令也如此行。</span>
<span className="v" id="v46" data-v="46" data-xref="歷代志下 29:30; 詩篇 73:1; 歷代志上 25:1–31"> 古時，在大衛和亞薩的日子，有歌唱的伶長，並有讚美稱謝上帝的詩歌。</span>
<span className="v" id="v47" data-v="47" data-xref="民數記 18:21–29; 尼希米記 12:26; 尼希米記 13:10–12"> 當所羅巴伯和尼希米的時候，以色列眾人將歌唱的、守門的，每日所當得的分供給他們，又給利未人當得的分；利未人又給亞倫的子孫當得的分。</span>
</div>

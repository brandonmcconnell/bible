## 約書亞繼承摩西

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 摩西去告訴以色列眾人</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 34:7; 民數記 27:17; 列王紀上 3:7"> 說：「我現在一百二十歲了，不能照常出入；耶和華也曾對我說：『你必不得過這約旦河。』</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 9:3; 申命記 31:23; 申命記 3:28"> 耶和華－你們的上帝必引導你們過去，將這些國民在你們面前滅絕，你們就得他們的地。約書亞必引導你們過去，正如耶和華所說的。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及記 23:28–31; 申命記 2:33; 申命記 3:3–11"> 耶和華必待他們，如同從前待他所滅絕的亞摩利二王西宏與噩以及他們的國一樣。</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 7:2; 申命記 20:16–17; 出埃及記 23:32–33"> 耶和華必將他們交給你們；你們要照我所吩咐的一切命令待他們。</span>
<span className="v" id="v6" data-v="6" data-xref="約書亞記 1:9; 以弗所書 6:10; 詩篇 27:14"> 你們當剛強壯膽，不要害怕，也不要畏懼他們，因為耶和華－你的上帝和你同去。他必不撇下你，也不丟棄你。」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="申命記 3:28; 申命記 31:6; 申命記 1:38"> 摩西召了約書亞來，在以色列眾人眼前對他說：「你當剛強壯膽！因為，你要和這百姓一同進入耶和華向他們列祖起誓應許所賜之地；你也要使他們承受那地為業。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及記 33:14; 申命記 31:6; 約書亞記 1:9"> 耶和華必在你前面行；他必與你同在，必不撇下你，也不丟棄你。不要懼怕，也不要驚惶。」</span>
</div>
</div>

## 每七年誦讀律法一次

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="民數記 4:15; 約書亞記 3:3; 申命記 17:18"> 摩西將這律法寫出來，交給抬耶和華約櫃的祭司利未子孫和以色列的眾長老。</span>
<span className="v" id="v10" data-v="10" data-xref="利未記 23:34–43; 申命記 15:1–2"> 摩西吩咐他們說：「每逢七年的末一年，就在豁免年的定期住棚節的時候，</span>
<span className="v" id="v11" data-v="11" data-xref="列王紀下 23:2; 約書亞記 8:34–35; 申命記 16:16–17"> 以色列眾人來到耶和華－你上帝所選擇的地方朝見他。那時，你要在以色列眾人面前將這律法念給他們聽。</span>
<span className="v" id="v12" data-v="12" data-xref="申命記 4:10; 詩篇 34:11–14; 申命記 6:6–7"> 要招聚他們男、女、孩子，並城裏寄居的，使他們聽，使他們學習，好敬畏耶和華－你們的上帝，謹守、遵行這律法的一切話，</span>
<span className="v" id="v13" data-v="13" data-xref="申命記 11:2; 申命記 6:7; 箴言 22:6"> 也使他們未曾曉得這律法的兒女得以聽見，學習敬畏耶和華－你們的上帝，在你們過約旦河要得為業之地，存活的日子，常常這樣行。」</span>
</div>
</div>

## 對摩西和約書亞的最後囑咐

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="民數記 27:13; 申命記 31:23; 約伯記 2:1"> 耶和華對摩西說：「你的死期臨近了；要召約書亞來，你們二人站在會幕裏，我好囑咐他。」於是摩西和約書亞去站在會幕裏。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及記 40:38; 詩篇 99:7; 出埃及記 33:9–10"> 耶和華在會幕裏雲柱中顯現，雲柱停在會幕門以上。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="士師記 10:6; 士師記 10:13; 士師記 2:12"> 耶和華又對摩西說：「你必和你列祖同睡。這百姓要起來，在他們所要去的地上，在那地的人中，隨從外邦神行邪淫，離棄我，違背我與他們所立的約。</span>
<span className="v" id="v17" data-v="17" data-xref="民數記 14:42; 以賽亞書 8:17; 詩篇 104:29"> 那時，我的怒氣必向他們發作；我也必離棄他們，掩面不顧他們，以致他們被吞滅，並有許多的禍患災難臨到他們。那日他們必說：『這些禍患臨到我們，豈不是因我們的上帝不在我們中間嗎？』</span>
<span className="v" id="v18" data-v="18" data-xref="申命記 31:16–17"> 那時，因他們偏向別神所行的一切惡，我必定掩面不顧他們。</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 6:7; 申命記 31:21–22; 申命記 31:26"> 現在你要寫一篇歌，教導以色列人，傳給他們，使這歌見證他們的不是；</span>
<span className="v" id="v20" data-v="20" data-xref="何西阿書 13:6; 申命記 6:10–12; 尼希米記 9:25–26"> 因為我將他們領進我向他們列祖起誓應許那流奶與蜜之地，他們在那裏吃得飽足，身體肥胖，就必偏向別神，事奉他們，藐視我，背棄我的約。</span>
<span className="v" id="v21" data-v="21" data-xref="何西阿書 5:3; 詩篇 139:2; 約翰福音 2:24–25"> 那時，有許多禍患災難臨到他們，這歌必在他們面前作見證，他們後裔的口中必念誦不忘。我未領他們到我所起誓應許之地以先，他們所懷的意念我都知道了。」</span>
<span className="v" id="v22" data-v="22" data-xref="申命記 31:19; 申命記 31:9"> 當日摩西就寫了一篇歌，教導以色列人。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="申命記 31:7–8; 申命記 31:14; 使徒行傳 7:45"> 耶和華囑咐嫩的兒子約書亞說：「你當剛強壯膽，因為你必領以色列人進我所起誓應許他們的地；我必與你同在。」</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="申命記 31:9; 申命記 17:18"> 摩西將這律法的話寫在書上，及至寫完了，</span>
<span className="v" id="v25" data-v="25" data-xref="申命記 31:9"> 就吩咐抬耶和華約櫃的利未人說：</span>
<span className="v" id="v26" data-v="26" data-xref="申命記 31:19; 列王紀下 22:8–11; 加拉太書 2:19"> 「將這律法書放在耶和華－你們上帝的約櫃旁，可以在那裏見證以色列人的不是；</span>
<span className="v" id="v27" data-v="27" data-xref="申命記 32:20; 申命記 9:24; 使徒行傳 7:51"> 因為我知道你們是悖逆的，是硬着頸項的。我今日還活着與你們同在，你們尚且悖逆耶和華，何況我死後呢？</span>
<span className="v" id="v28" data-v="28" data-xref="申命記 32:1; 申命記 4:26; 申命記 30:19"> 你們要將你們支派的眾長老和官長都招聚了來，我好將這些話說與他們聽，並呼天喚地見證他們的不是。</span>
<span className="v" id="v29" data-v="29" data-xref="士師記 2:19; 申命記 32:5; 路加福音 21:24"> 我知道我死後，你們必全然敗壞，偏離我所吩咐你們的道，行耶和華眼中看為惡的事，以手所做的惹他發怒；日後必有禍患臨到你們。」</span>
</div>
</div>

## 主的偉大

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命記 6:5; 申命記 10:12; 路加福音 1:74–75"> 「你要愛耶和華－你的上帝，常守他的吩咐、律例、典章、誡命。</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 8:2–5; 申命記 29:10; 使徒行傳 26:22"> 你們今日當知道，我本不是和你們的兒女說話；因為他們不知道，也沒有看見耶和華－你們上帝的管教、威嚴、大能的手，和伸出來的膀臂，</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 7:19; 申命記 4:34; 詩篇 105:27–45"> 並他在埃及中向埃及王法老和其全地所行的神蹟奇事；</span>
<span className="v" id="v4" data-v="4" data-xref="詩篇 106:11; 出埃及記 14:23–31; 出埃及記 15:19"> 也沒有看見他怎樣待埃及的軍兵、車馬，他們追趕你們的時候，耶和華怎樣使紅海的水淹沒他們，將他們滅絕，直到今日，</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 77:20; 詩篇 106:12–48; 詩篇 78:14–72"> 並他在曠野怎樣待你們，以致你們來到這地方；</span>
<span className="v" id="v6" data-v="6" data-xref="民數記 26:9–10; 詩篇 106:17; 民數記 16:1–35"> 也沒有看見他怎樣待呂便子孫以利押的兒子大坍、亞比蘭，地怎樣在以色列人中間開口，吞了他們和他們的家眷，並帳棚與跟他們的一切活物。</span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 145:4–6; 詩篇 145:12; 詩篇 150:2"> 惟有你們親眼看見耶和華所做的一切大事。」</span>

## 應許之地的福澤

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="以弗所書 6:10; 約書亞記 1:6–7; 以弗所書 3:16"> 「所以，你們要守我今日所吩咐的一切誡命，使你們膽壯，能以進去，得你們所要得的那地，</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及記 3:8; 申命記 4:40; 申命記 6:2"> 並使你們的日子在耶和華向你們列祖起誓、應許給他們和他們後裔的地上得以長久；那是流奶與蜜之地。</span>
<span className="v" id="v10" data-v="10" data-xref="撒迦利亞書 14:18"> 你要進去得為業的那地，本不像你出來的埃及地。你在那裏撒種，用腳澆灌，像澆灌菜園一樣。</span>
<span className="v" id="v11" data-v="11" data-xref="希伯來書 6:7; 申命記 8:7–9; 詩篇 65:12–13"> 你們要過去得為業的那地乃是有山有谷、雨水滋潤之地，</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米書 24:6; 詩篇 33:18; 列王紀上 9:3"> 是耶和華－你上帝所眷顧的；從歲首到年終，耶和華－你上帝的眼目時常看顧那地。</span>
<span className="v" id="v13" data-v="13" data-xref="申命記 10:12; 申命記 4:29; 申命記 6:17"> 「你們若留意聽從我今日所吩咐的誡命，愛耶和華－你們的上帝，盡心盡性事奉他，</span>
<span className="v" id="v14" data-v="14" data-xref="雅各書 5:7; 利未記 26:4; 以西結書 34:26"> 他<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是我">a</a></sup>必按時降秋雨春雨在你們的地上，使你們可以收藏五穀、新酒，和油，</span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 104:14; 申命記 6:11; 約珥書 2:19"> 也必使你吃得飽足，並使田野為你的牲畜長草。</span>
<span className="v" id="v16" data-v="16" data-xref="約伯記 31:27; 希伯來書 3:12; 希伯來書 2:1"> 你們要謹慎，免得心中受迷惑，就偏離正路，去事奉敬拜別神。</span>
<span className="v" id="v17" data-v="17" data-xref="列王紀上 8:35; 申命記 6:15; 歷代志下 6:26"> 耶和華的怒氣向你們發作，就使天閉塞不下雨，地也不出產，使你們在耶和華所賜給你們的美地上速速滅亡。</span>
<span className="v" id="v18" data-v="18" data-xref="歌羅西書 3:16; 申命記 6:6–9; 箴言 3:1"> 「你們要將我這話存在心內，留在意中，繫在手上為記號，戴在額上為經文；</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 6:7; 以賽亞書 38:19; 申命記 4:9–10"> 也要教訓你們的兒女，無論坐在家裏，行在路上，躺下，起來，都要談論；</span>
<span className="v" id="v20" data-v="20" data-xref="申命記 6:9"> 又要寫在房屋的門框上，並城門上，</span>
<span className="v" id="v21" data-v="21" data-xref="箴言 4:10; 箴言 3:2; 箴言 9:11"> 使你們和你們子孫的日子在耶和華向你們列祖起誓、應許給他們的地上得以增多，如天覆地的日子那樣多。</span>
<span className="v" id="v22" data-v="22" data-xref="申命記 6:17; 申命記 11:13; 申命記 10:20"> 你們若留意謹守遵行我所吩咐這一切的誡命，愛耶和華－你們的上帝，行他的道，專靠他，</span>
<span className="v" id="v23" data-v="23" data-xref="申命記 4:38; 申命記 9:1; 申命記 7:1–2"> 他必從你們面前趕出這一切國民，就是比你們更大更強的國民，你們也要得他們的地。</span>
<span className="v" id="v24" data-v="24" data-xref="約書亞記 14:9; 出埃及記 23:31; 創世記 15:18–21"> 凡你們腳掌所踏之地都必歸你們；從曠野和黎巴嫩，並幼發拉底大河，直到西海，都要作你們的境界。</span>
<span className="v" id="v25" data-v="25" data-xref="申命記 7:24; 出埃及記 23:27; 約書亞記 1:5"> 必無一人能在你們面前站立得住；耶和華－你們的上帝必照他所說的，使懼怕驚恐臨到你們所踏之地的居民。</span>
<span className="v" id="v26" data-v="26" data-xref="申命記 30:1; 申命記 30:15–20; 加拉太書 3:10"> 「看哪，我今日將祝福與咒詛的話都陳明在你們面前。</span>
<span className="v" id="v27" data-v="27" data-xref="以賽亞書 1:19; 申命記 28:1–14; 以賽亞書 3:10"> 你們若聽從耶和華－你們上帝的誡命，就是我今日所吩咐你們的，就必蒙福。</span>
<span className="v" id="v28" data-v="28" data-xref="申命記 28:15–68; 羅馬書 2:8–9; 加拉太書 3:10"> 你們若不聽從耶和華－你們上帝的誡命，偏離我今日所吩咐你們的道，去事奉你們素來所不認識的別神，就必受禍。</span>
<span className="v" id="v29" data-v="29" data-xref="申命記 27:12–26; 約書亞記 8:30–35"> 及至耶和華－你的上帝領你進入要去得為業的那地，你就要將祝福的話陳明在基利心山上，將咒詛的話陳明在以巴路山上。</span>
<span className="v" id="v30" data-v="30" data-xref="創世記 12:6; 士師記 7:1; 約書亞記 4:19"> 這二山豈不是在約旦河那邊，日落之處，在住亞拉巴的迦南人之地與吉甲相對，靠近摩利橡樹嗎？</span>
<span className="v" id="v31" data-v="31" data-xref="約書亞記 1:11; 申命記 9:1; 約書亞記 3:13–17"> 你們要過約旦河，進去得耶和華－你們上帝所賜你們為業之地，在那地居住。</span>
<span className="v" id="v32" data-v="32" data-xref="馬太福音 28:20; 申命記 12:32; 帖撒羅尼迦前書 4:1–2"> 你們要謹守遵行我今日在你們面前所陳明的一切律例典章。」</span>
</div>
</div>

## 摩西回憶

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳記上 25:1; 約書亞記 22:7; 民數記 33:17–18"> 以下所記的是摩西在約旦河東的曠野、疏弗對面的亞拉巴－就是巴蘭、陀弗、拉班、哈洗錄、底撒哈中間－向以色列眾人所說的話。（</span>
<span className="v" id="v2" data-v="2" data-xref="民數記 32:8; 民數記 13:26; 申命記 9:23"> 從何烈山經過西珥山到加低斯‧巴尼亞有十一天的路程。）</span>
<span className="v" id="v3" data-v="3" data-xref="民數記 33:38; 申命記 4:1–2; 民數記 20:1"> 出埃及第四十年十一月初一日，摩西照耶和華藉着他所吩咐以色列人的話都曉諭他們。</span>
<span className="v" id="v4" data-v="4" data-xref="民數記 21:21–35; 約書亞記 12:2–6; 約書亞記 13:10–12"> 那時，他已經擊殺了住希實本的亞摩利王西宏和住以得來、亞斯他錄的巴珊王噩。</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 4:8; 申命記 32:46; 申命記 31:9"> 摩西在約旦河東的摩押地講律法說：</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及記 3:1; 民數記 10:11–13; 出埃及記 19:1–2"> 「耶和華－我們的上帝在何烈山曉諭我們說：你們在這山上住的日子夠了；</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 11:24; 約書亞記 10:40; 阿摩司書 2:9"> 要起行轉到亞摩利人的山地和靠近這山地的各處，就是亞拉巴、山地、高原、南地，沿海一帶迦南人的地，並黎巴嫩山又到幼發拉底大河。</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 15:18; 創世記 12:7; 創世記 26:3–4"> 如今我將這地擺在你們面前；你們要進去得這地，就是耶和華向你們列祖亞伯拉罕、以撒、雅各起誓應許賜給他們和他們後裔為業之地。」</span>
</div>
</div>

## 摩西指派審判官

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="出埃及記 18:18; 民數記 11:17; 民數記 11:11–14"> 「那時，我對你們說：『管理你們的重任，我獨自擔當不起。</span>
<span className="v" id="v10" data-v="10" data-xref="申命記 10:22; 出埃及記 32:13; 創世記 22:17"> 耶和華－你們的上帝使你們多起來。看哪，你們今日像天上的星那樣多。</span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 115:14; 創世記 22:17; 民數記 6:27"> 惟願耶和華－你們列祖的上帝使你們比如今更多千倍，照他所應許你們的話賜福與你們。</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多後書 3:5; 列王紀上 3:7–9; 哥林多後書 2:16"> 但你們的麻煩，和管理你們的重任，並你們的爭訟，我獨自一人怎能擔當得起呢？</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及記 18:21; 使徒行傳 1:21–23; 民數記 11:16–17"> 你們要按着各支派選舉有智慧、有見識、為眾人所認識的，我立他們為你們的首領。』</span>
<span className="v" id="v14" data-v="14"> 你們回答我說：『照你所說的行了為妙。』</span>
<span className="v" id="v15" data-v="15" data-xref="申命記 16:18; 出埃及記 18:25–26; 以弗所書 4:11"> 我便將你們各支派的首領，有智慧、為眾人所認識的，照你們的支派，立他們為官長、千夫長、百夫長、五十夫長、十夫長，管理你們。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="約翰福音 7:24; 出埃及記 22:21; 歷代志下 19:6–10"> 「當時，我囑咐你們的審判官說：『你們聽訟，無論是弟兄彼此爭訟，是與同居的外人爭訟，都要按公義判斷。</span>
<span className="v" id="v17" data-v="17" data-xref="申命記 16:19; 出埃及記 18:26; 雅各書 2:9"> 審判的時候，不可看人的外貌；聽訟不可分貴賤，不可懼怕人，因為審判是屬乎上帝的。若有難斷的案件，可以呈到我這裏，我就判斷。』</span>
<span className="v" id="v18" data-v="18" data-xref="申命記 12:32; 申命記 4:5; 使徒行傳 20:20"> 那時，我將你們所當行的事都吩咐你們了。」</span>
</div>
</div>

## 從加低斯‧巴尼亞派探子偵察

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="申命記 1:2; 申命記 8:15; 耶利米書 2:6"> 「我們照着耶和華－我們上帝所吩咐的從何烈山起行，經過你們所看見那大而可怕的曠野，往亞摩利人的山地去，到了加低斯‧巴尼亞。</span>
<span className="v" id="v20" data-v="20" data-xref="申命記 1:7–8"> 我對你們說：『你們已經到了耶和華－我們上帝所賜給我們的亞摩利人之山地。</span>
<span className="v" id="v21" data-v="21" data-xref="約書亞記 1:9; 詩篇 46:1; 民數記 14:8–9"> 看哪，耶和華－你的上帝已將那地擺在你面前，你要照耶和華－你列祖的上帝所說的上去得那地為業；不要懼怕，也不要驚惶。』</span>
<span className="v" id="v22" data-v="22" data-xref="民數記 13:1–20"> 你們都就近我來說：『我們要先打發人去，為我們窺探那地，將我們上去該走何道，必進何城，都回報我們。』</span>
<span className="v" id="v23" data-v="23" data-xref="民數記 13:3–33"> 這話我以為美，就從你們中間選了十二個人，每支派一人。</span>
<span className="v" id="v24" data-v="24" data-xref="民數記 13:21–27; 約書亞記 2:1–2"> 於是他們起身上山地去，到以實各谷，窺探那地。</span>
<span className="v" id="v25" data-v="25"> 他們手裏拿着那地的果子下來，到我們那裏，回報說：『耶和華－我們的上帝所賜給我們的是美地。』</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="民數記 14:1–4; 使徒行傳 7:51; 詩篇 106:24–25"> 「你們卻不肯上去，竟違背了耶和華－你們上帝的命令，</span>
<span className="v" id="v27" data-v="27" data-xref="申命記 9:28; 詩篇 106:25; 民數記 14:3"> 在帳棚內發怨言說：『耶和華因為恨我們，所以將我們從埃及地領出來，要交在亞摩利人手中，除滅我們。</span>
<span className="v" id="v28" data-v="28" data-xref="民數記 13:28–33; 申命記 9:1–2; 約書亞記 15:14"> 我們上哪裏去呢？我們的弟兄使我們的心消化，說那地的民比我們又大又高，城邑又廣大又堅固，高得頂天，並且我們在那裏看見亞衲族的人。』</span>
<span className="v" id="v29" data-v="29"> 我就對你們說：『不要驚恐，也不要怕他們。</span>
<span className="v" id="v30" data-v="30" data-xref="出埃及記 14:14; 尼希米記 4:20; 羅馬書 8:31"> 在你們前面行的耶和華－你們的上帝必為你們爭戰，正如他在埃及和曠野，在你們眼前所行的一樣。</span>
<span className="v" id="v31" data-v="31" data-xref="以賽亞書 46:3–4; 使徒行傳 13:18; 何西阿書 11:3–4"> 你們在曠野所行的路上，也曾見耶和華－你們的上帝撫養你們，如同人撫養兒子一般，直等你們來到這地方。』</span>
<span className="v" id="v32" data-v="32" data-xref="詩篇 106:24; 猶大書 1:5; 希伯來書 3:18–19"> 你們在這事上卻不信耶和華－你們的上帝。</span>
<span className="v" id="v33" data-v="33" data-xref="民數記 10:33; 詩篇 78:14; 尼希米記 9:12"> 他在路上，在你們前面行，為你們找安營的地方；夜間在火柱裏，日間在雲柱裏，指示你們所當行的路。」</span>
</div>
</div>

## 耶和華刑罰以色列人

<div className="bt">
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="民數記 14:22–30; 詩篇 95:11; 以西結書 20:15"> 「耶和華聽見你們這話，就發怒，起誓說：</span>
<span className="v" id="v35" data-v="35" data-xref="詩篇 95:11"> 『這惡世代的人，連一個也不得見我起誓應許賜給你們列祖的美地；</span>
<span className="v" id="v36" data-v="36" data-xref="民數記 14:24; 約書亞記 14:6–14; 民數記 32:12"> 惟有耶孚尼的兒子迦勒必得看見，並且我要將他所踏過的地賜給他和他的子孫，因為他專心跟從我。』</span>
<span className="v" id="v37" data-v="37" data-xref="民數記 20:12; 申命記 4:21; 申命記 34:4"> 耶和華為你的緣故也向我發怒，說：『你必不得進入那地。</span>
<span className="v" id="v38" data-v="38" data-xref="申命記 3:28; 民數記 14:30; 申命記 31:7–8"> 伺候你、嫩的兒子約書亞，他必得進入那地；你要勉勵他，因為他要使以色列人承受那地為業。</span>
<span className="v" id="v39" data-v="39" data-xref="以賽亞書 7:15–16; 民數記 14:3; 民數記 14:31"> 並且你們的婦人孩子，就是你們所說、必被擄掠的，和今日不知善惡的兒女，必進入那地。我要將那地賜給他們，他們必得為業。</span>
<span className="v" id="v40" data-v="40" data-xref="民數記 14:25"> 至於你們，要轉回，從紅海的路往曠野去。』</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="民數記 14:39–45; 箴言 19:3; 民數記 22:34"> 「那時，你們回答我說：『我們得罪了耶和華，情願照耶和華－我們上帝一切所吩咐的上去爭戰。』於是你們各人帶着兵器，爭先上山地去了。</span>
<span className="v" id="v42" data-v="42" data-xref="民數記 14:41–43; 約書亞記 7:8–13; 以賽亞書 59:1–2"> 耶和華吩咐我說：『你對他們說：不要上去，也不要爭戰；因我不在你們中間，恐怕你們被仇敵殺敗了。』</span>
<span className="v" id="v43" data-v="43" data-xref="民數記 14:44; 以賽亞書 63:10; 使徒行傳 7:51"> 我就告訴了你們，你們卻不聽從，竟違背耶和華的命令，擅自上山地去了。</span>
<span className="v" id="v44" data-v="44" data-xref="詩篇 118:12; 民數記 14:45; 民數記 21:3"> 住那山地的亞摩利人就出來攻擊你們，追趕你們，如蜂擁一般，在西珥殺退你們，直到何珥瑪。</span>
<span className="v" id="v45" data-v="45" data-xref="希伯來書 12:17; 詩篇 78:34"> 你們便回來，在耶和華面前哭號；耶和華卻不聽你們的聲音，也不向你們側耳。</span>
<span className="v" id="v46" data-v="46" data-xref="民數記 20:1; 民數記 20:22; 士師記 11:16–17"> 於是你們在加低斯住了許多日子。」</span>
</div>
</div>

## 有關未結案的謀殺案件

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以賽亞書 26:21; 詩篇 5:6; 箴言 28:17"> 「在耶和華－你上帝所賜你為業的地上，若遇見被殺的人倒在田野，不知道是誰殺的，</span>
<span className="v" id="v2" data-v="2" data-xref="羅馬書 13:3–4; 申命記 16:18–19"> 長老和審判官就要出去，從被殺的人那裏量起，直量到四圍的城邑，</span>
<span className="v" id="v3" data-v="3" data-xref="民數記 19:2; 馬太福音 11:28–30; 耶利米書 31:18"> 看哪城離被殺的人最近，那城的長老就要從牛群中取一隻未曾耕地、未曾負軛的母牛犢，</span>
<span className="v" id="v4" data-v="4" data-xref="彼得前書 2:21–24; 彼得前書 3:18"> 把母牛犢牽到流水、未曾耕種的山谷去，在谷中打折母牛犢的頸項。</span>
<span className="v" id="v5" data-v="5" data-xref="歷代志上 23:13; 瑪拉基書 2:7; 申命記 10:8"> 祭司利未的子孫要近前來；因為耶和華－你的上帝揀選了他們事奉他，奉耶和華的名祝福，所有爭訟毆打的事都要憑他們判斷。</span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 73:13; 詩篇 26:6; 詩篇 51:7"> 那城的眾長老，就是離被殺的人最近的，要在那山谷中，在所打折頸項的母牛犢以上洗手，</span>
<span className="v" id="v7" data-v="7" data-xref="約伯記 21:21–23; 約伯記 21:31–34; 撒母耳記下 16:8"> 禱告<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是回答">a</a></sup>說：『我們的手未曾流這人的血；我們的眼也未曾看見這事。</span>
<span className="v" id="v8" data-v="8" data-xref="約拿書 1:14; 列王紀下 24:4; 以西結書 23:24–25"> 耶和華啊，求你赦免你所救贖的以色列民，不要使流無辜血的罪歸在你的百姓以色列中間。』這樣，流血的罪必得赦免。</span>
<span className="v" id="v9" data-v="9" data-xref="申命記 19:12–13; 列王紀下 10:30–31; 申命記 13:18"> 你行耶和華眼中看為正的事，就可以從你們中間除掉流無辜血的罪。」</span>
</div>
</div>

## 有關女戰俘的案件

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="申命記 20:10–16; 約書亞記 21:44"> 「你出去與仇敵爭戰的時候，耶和華－你的上帝將他們交在你手中，你就擄了他們去。</span>
<span className="v" id="v11" data-v="11" data-xref="箴言 31:10; 創世記 34:3; 創世記 12:14–15"> 若在被擄的人中見有美貌的女子，戀慕她，要娶她為妻，</span>
<span className="v" id="v12" data-v="12" data-xref="利未記 14:9; 民數記 6:9; 以弗所書 4:22"> 就可以領她到你家裏去；她便要剃頭髮，修指甲，</span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 45:10–11; 路加福音 14:26–27"> 脫去被擄時所穿的衣服，住在你家裏哀哭父母一個整月，然後可以與她同房。你作她的丈夫，她作你的妻子。</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 22:29; 創世記 34:2; 申命記 22:19"> 後來你若不喜悅她，就要由她隨意出去，決不可為錢賣她，也不可當婢女待她，因為你玷污了她。」</span>
</div>
</div>

## 有關長子的繼承權

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="創世記 29:33; 創世記 29:20; 創世記 29:18"> 「人若有二妻，一為所愛，一為所惡，所愛的、所惡的都給他生了兒子，但長子是所惡之妻生的。</span>
<span className="v" id="v16" data-v="16" data-xref="歷代志上 26:10; 歷代志上 5:2; 歷代志下 21:3"> 到了把產業分給兒子承受的時候，不可將所愛之妻生的兒子立為長子，在所惡之妻生的兒子以上，</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 49:3; 創世記 25:31–34; 詩篇 105:36"> 卻要認所惡之妻生的兒子為長子，將產業多加一分給他；因這兒子是他力量強壯的時候生的，長子的名分本當歸他。」</span>
</div>
</div>

## 有關逆子的處置

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="利未記 19:3; 出埃及記 20:12; 阿摩司書 4:11–12"> 「人若有頑梗悖逆的兒子，不聽從父母的話，他們雖懲治他，他仍不聽從，</span>
<span className="v" id="v19" data-v="19" data-xref="撒迦利亞書 13:3; 申命記 21:2; 申命記 16:18"> 父母就要抓住他，將他帶到本地的城門、本城的長老那裏，</span>
<span className="v" id="v20" data-v="20" data-xref="箴言 23:29–35; 箴言 20:1; 箴言 23:19–21"> 對長老說：『我們這兒子頑梗悖逆，不聽從我們的話，是貪食好酒的人。』</span>
<span className="v" id="v21" data-v="21" data-xref="申命記 19:19–20; 申命記 13:10–11; 利未記 24:16"> 本城的眾人就要用石頭將他打死。這樣，就把那惡從你們中間除掉，以色列眾人都要聽見害怕。」</span>
</div>
</div>

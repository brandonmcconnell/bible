## 惟一的敬拜場所

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀上 8:40; 約伯記 7:1; 申命記 4:19"> 「你們存活於世的日子，在耶和華－你們列祖的上帝所賜你們為業的地上，要謹守遵行的律例典章乃是這些：</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 7:5; 列王紀下 16:4; 民數記 33:51–52"> 你們要將所趕出的國民事奉神的各地方，無論是在高山，在小山，在各青翠樹下，都毀壞了；</span>
<span className="v" id="v3" data-v="3" data-xref="士師記 2:2; 撒迦利亞書 13:2; 民數記 33:52"> 也要拆毀他們的祭壇，打碎他們的柱像，用火焚燒他們的木偶，砍下他們雕刻的神像，並將其名從那地方除滅。</span>
<span className="v" id="v4" data-v="4" data-xref="利未記 20:23; 申命記 20:18; 申命記 16:21–22"> 你們不可照他們那樣事奉耶和華－你們的上帝。</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 12:11; 申命記 26:2; 歷代志下 7:12"> 但耶和華－你們的上帝從你們各支派中選擇何處為立他名的居所，你們就當往那裏去求問，</span>
<span className="v" id="v6" data-v="6" data-xref="申命記 15:19–20; 瑪拉基書 3:10; 利未記 27:32–33"> 將你們的燔祭、平安祭、十分取一之物，和手中的舉祭，並還願祭、甘心祭，以及牛群羊群中頭生的，都奉到那裏。</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 12:18; 利未記 23:40; 申命記 14:26"> 在那裏，耶和華－你們上帝的面前，你們和你們的家屬都可以吃，並且因你手所辦的一切事蒙耶和華－你的上帝賜福，就都歡樂。</span>
<span className="v" id="v8" data-v="8" data-xref="士師記 21:25; 士師記 17:6; 箴言 21:2"> 我們今日在這裏所行的是各人行自己眼中看為正的事，你們將來不可這樣行；</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀上 8:56; 詩篇 95:11; 申命記 25:19"> 因為你們還沒有到耶和華－你上帝所賜你的安息地，所給你的產業。</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米書 33:11; 以西結書 34:28; 申命記 3:27"> 但你們過了約旦河，得以住在耶和華－你們上帝使你們承受為業之地，又使你們太平，不被四圍的一切仇敵擾亂，安然居住。</span>
<span className="v" id="v11" data-v="11" data-xref="申命記 12:5; 申命記 15:20; 申命記 17:8"> 那時要將我所吩咐你們的燔祭、平安祭、十分取一之物，和手中的舉祭，並向耶和華許願獻的一切美祭，都奉到耶和華－你們上帝所選擇要立為他名的居所。</span>
<span className="v" id="v12" data-v="12" data-xref="申命記 12:7; 申命記 10:9; 申命記 26:12"> 你們和兒女、僕婢，並住在你們城裏無分無業的利未人，都要在耶和華－你們的上帝面前歡樂。</span>
<span className="v" id="v13" data-v="13" data-xref="列王紀上 12:28–32; 列王紀上 15:34; 歷代志下 15:17"> 你要謹慎，不可在你所看中的各處獻燔祭。</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 12:11; 哥林多後書 5:19; 申命記 12:5"> 惟獨耶和華從你那一支派中所選擇的地方，你就要在那裏獻燔祭，行我一切所吩咐你的。</span>
<span className="v" id="v15" data-v="15" data-xref="申命記 14:5; 申命記 15:22–23; 申命記 14:26"> 「然而，在你各城裏都可以照耶和華－你上帝所賜你的福分，隨心所欲宰牲吃肉；無論潔淨人不潔淨人都可以吃，就如吃羚羊與鹿一般。</span>
<span className="v" id="v16" data-v="16" data-xref="創世記 9:4; 申命記 15:23; 申命記 12:23–24"> 只是不可吃血，要倒在地上，如同倒水一樣。</span>
<span className="v" id="v17" data-v="17" data-xref="申命記 26:14; 申命記 12:6; 申命記 14:22–29"> 你的五穀、新酒，和油的十分之一，或是牛群羊群中頭生的，或是你許願獻的，甘心獻的，或是手中的舉祭，都不可在你城裏吃。</span>
<span className="v" id="v18" data-v="18" data-xref="申命記 12:7; 申命記 14:23; 申命記 12:5"> 但要在耶和華－你的上帝面前吃，在耶和華－你上帝所要選擇的地方，你和兒女、僕婢，並住在你城裏的利未人，都可以吃；也要因你手所辦的，在耶和華－你上帝面前歡樂。</span>
<span className="v" id="v19" data-v="19" data-xref="歷代志下 31:4–21; 尼希米記 10:34–39; 申命記 14:27–29"> 你要謹慎，在你所住的地方永不可丟棄利未人。</span>
<span className="v" id="v20" data-v="20" data-xref="申命記 19:8; 申命記 11:24; 出埃及記 34:24"> 「耶和華－你的上帝照他所應許擴張你境界的時候，你心裏想要吃肉，說：『我要吃肉』，就可以隨心所欲地吃肉。</span>
<span className="v" id="v21" data-v="21" data-xref="申命記 12:5; 列王紀上 14:21; 申命記 16:11"> 耶和華－你上帝所選擇要立他名的地方若離你太遠，就可以照我所吩咐的，將耶和華賜給你的牛羊取些宰了，可以隨心所欲在你城裏吃。</span>
<span className="v" id="v22" data-v="22" data-xref="申命記 12:15–16"> 你吃那肉，要像吃羚羊與鹿一般；無論潔淨人不潔淨人都可以吃。</span>
<span className="v" id="v23" data-v="23" data-xref="利未記 17:11; 創世記 9:4; 利未記 17:13–14"> 只是你要心意堅定，不可吃血，因為血是生命；不可將血<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是生命">a</a></sup>與肉同吃。</span>
<span className="v" id="v24" data-v="24" data-xref="申命記 12:16; 申命記 15:23"> 不可吃血，要倒在地上，如同倒水一樣。</span>
<span className="v" id="v25" data-v="25" data-xref="列王紀上 11:38; 申命記 4:40; 以賽亞書 3:10"> 不可吃血。這樣，你行耶和華眼中看為正的事，你和你的子孫就可以得福。</span>
<span className="v" id="v26" data-v="26" data-xref="民數記 18:19; 民數記 5:9–10; 申命記 12:11"> 只是你分別為聖的物和你的還願祭要奉到耶和華所選擇的地方去。</span>
<span className="v" id="v27" data-v="27" data-xref="利未記 1:13; 利未記 17:11; 利未記 1:9"> 你的燔祭，連肉帶血，都要獻在耶和華－你上帝的壇上。平安祭的血要倒在耶和華－你上帝的壇上；平安祭的肉，你自己可以吃。</span>
<span className="v" id="v28" data-v="28" data-xref="申命記 4:40; 約翰福音 15:14; 約翰福音 15:10"> 你要謹守聽從我所吩咐的一切話，行耶和華－你上帝眼中看為善，看為正的事。這樣，你和你的子孫就可以永遠享福。」</span>
</div>

## 警告不可拜偶像

<div className="bt">
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="約書亞記 23:4; 申命記 19:1; 申命記 9:3"> 「耶和華－你上帝將你要去趕出的國民從你面前剪除，你得了他們的地居住，</span>
<span className="v" id="v30" data-v="30" data-xref="耶利米書 10:2; 以西結書 20:32; 申命記 7:16"> 那時就要謹慎，不可在他們除滅之後隨從他們的惡俗，陷入網羅，也不可訪問他們的神說：『這些國民怎樣事奉他們的神，我也要照樣行。』</span>
<span className="v" id="v31" data-v="31" data-xref="耶利米書 32:35; 申命記 18:9–10; 列王紀下 17:15–17"> 你不可向耶和華－你的上帝這樣行，因為他們向他們的神行了耶和華所憎嫌所恨惡的一切事，甚至將自己的兒女用火焚燒，獻與他們的神。</span>
<span className="v" id="v32" data-v="32" data-xref="申命記 4:2; 啟示錄 22:18–19; 約書亞記 1:7"> 凡我所吩咐的，你們都要謹守遵行，不可加添，也不可刪減。</span>

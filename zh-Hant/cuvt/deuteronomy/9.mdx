## 百姓悖逆

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命記 11:31; 申命記 4:38; 申命記 1:28"> 「以色列啊，你當聽！你今日要過約旦河，進去趕出比你強大的國民，得着廣大堅固、高得頂天的城邑。</span>
<span className="v" id="v2" data-v="2" data-xref="民數記 13:22; 那鴻書 1:6; 申命記 7:24"> 那民是亞衲族的人，又大又高，是你所知道的；也曾聽見有人指着他們說：『誰能在亞衲族人面前站立得住呢？』</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 4:24; 希伯來書 12:29; 羅馬書 8:31"> 你今日當知道，耶和華－你的上帝在你前面過去，如同烈火，要滅絕他們，將他們制伏在你面前。這樣，你就要照耶和華所說的趕出他們，使他們速速滅亡。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="申命記 8:17; 申命記 9:5; 申命記 18:9–14"> 「耶和華－你的上帝將這些國民從你面前攆出以後，你心裏不可說：『耶和華將我領進來得這地是因我的義。』其實，耶和華將他們從你面前趕出去是因他們的惡。</span>
<span className="v" id="v5" data-v="5" data-xref="提多書 3:5; 創世記 17:8; 創世記 26:4"> 你進去得他們的地，並不是因你的義，也不是因你心裏正直，乃是因這些國民的惡，耶和華－你的上帝將他們從你面前趕出去，又因耶和華要堅定他向你列祖亞伯拉罕、以撒、雅各起誓所應許的話。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="申命記 10:16; 使徒行傳 7:51; 申命記 31:27"> 「你當知道，耶和華－你上帝將這美地賜你為業，並不是因你的義；你本是硬着頸項的百姓。</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及記 16:2; 出埃及記 14:11; 民數記 21:5"> 你當記念不忘，你在曠野怎樣惹耶和華－你上帝發怒。自從你出了埃及地的那日，直到你們來到這地方，你們時常悖逆耶和華。</span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 106:19–22; 出埃及記 32:16; 出埃及記 32:7–10"> 你們在何烈山又惹耶和華發怒；他惱怒你們，要滅絕你們。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及記 34:28; 出埃及記 24:18; 列王紀上 19:8"> 我上了山，要領受兩塊石版，就是耶和華與你們立約的版。那時我在山上住了四十晝夜，沒有吃飯，也沒有喝水。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及記 31:18; 希伯來書 8:10; 申命記 10:4"> 耶和華把那兩塊石版交給我，是上帝用指頭寫的。版上所寫的是照耶和華在大會的日子、在山上、從火中對你們所說的一切話。</span>
<span className="v" id="v11" data-v="11" data-xref="申命記 9:9; 民數記 10:33; 希伯來書 8:6–10"> 過了四十晝夜，耶和華把那兩塊石版，就是約版，交給我。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及記 32:7–8; 申命記 31:29; 士師記 2:17"> 對我說：『你起來，趕快下去！因為你從埃及領出來的百姓已經敗壞了自己；他們快快地偏離了我所吩咐的道，為自己鑄成了偶像。』</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="申命記 9:6; 列王紀下 17:14; 申命記 10:16"> 「耶和華又對我說：『我看這百姓是硬着頸項的百姓。</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 29:20; 出埃及記 32:10–13; 詩篇 9:5"> 你且由着我，我要滅絕他們，將他們的名從天下塗抹，使你的後裔比他們成為更大更強的國。』</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及記 19:18; 申命記 5:23; 申命記 4:11"> 於是我轉身下山，山被火燒着，兩塊約版在我兩手之中。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 32:19; 使徒行傳 7:40–41"> 我一看見你們得罪了耶和華－你們的上帝，鑄成了牛犢，快快地偏離了耶和華所吩咐你們的道，</span>
<span className="v" id="v17" data-v="17"> 我就把那兩塊版從我手中扔下去，在你們眼前摔碎了。</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及記 34:28; 申命記 9:9; 詩篇 106:23"> 因你們所犯的一切罪，行了耶和華眼中看為惡的事，惹他發怒，我就像從前俯伏在耶和華面前四十晝夜，沒有吃飯，也沒有喝水。</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 10:10; 出埃及記 32:14; 雅各書 5:16–17"> 我因耶和華向你們大發烈怒，要滅絕你們，就甚害怕；但那次耶和華又應允了我。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及記 32:35; 出埃及記 32:21; 希伯來書 7:26–28"> 耶和華也向亞倫甚是發怒，要滅絕他；那時我又為亞倫祈禱。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及記 32:20; 以賽亞書 31:7; 以賽亞書 2:18–21"> 我把那叫你們犯罪所鑄的牛犢用火焚燒，又搗碎磨得很細，以致細如灰塵，我就把這灰塵撒在從山上流下來的溪水中。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="民數記 11:34; 出埃及記 17:7; 民數記 11:1–5"> 「你們在他備拉、瑪撒、基博羅‧哈他瓦又惹耶和華發怒。</span>
<span className="v" id="v23" data-v="23" data-xref="詩篇 106:24–25; 希伯來書 4:2; 詩篇 78:22"> 耶和華打發你們離開加低斯‧巴尼亞，說：『你們上去得我所賜給你們的地。』那時你們違背了耶和華－你們上帝的命令，不信服他，不聽從他的話。</span>
<span className="v" id="v24" data-v="24" data-xref="申命記 31:27; 使徒行傳 7:51; 申命記 9:6–7"> 自從我認識你們以來，你們常常悖逆耶和華。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="申命記 9:18; 申命記 9:16"> 「我因耶和華說要滅絕你們，就在耶和華面前照舊俯伏四十晝夜。</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及記 32:11–13; 提多書 2:14; 詩篇 107:2"> 我祈禱耶和華說：『主耶和華啊，求你不要滅絕你的百姓。他們是你的產業，是你用大力救贖的，用大能從埃及領出來的。</span>
<span className="v" id="v27" data-v="27" data-xref="耶利米書 14:21; 彌迦書 7:18–19; 撒母耳記上 25:25"> 求你記念你的僕人亞伯拉罕、以撒、雅各，不要想念這百姓的頑梗、邪惡、罪過，</span>
<span className="v" id="v28" data-v="28" data-xref="民數記 14:16; 出埃及記 32:12"> 免得你領我們出來的那地之人說，耶和華因為不能將這百姓領進他所應許之地，又因恨他們，所以領他們出去，要在曠野殺他們。</span>
<span className="v" id="v29" data-v="29" data-xref="尼希米記 1:10; 列王紀上 8:51; 申命記 9:26"> 其實他們是你的百姓，你的產業，是你用大能和伸出來的膀臂領出來的。』」</span>
</div>
</div>

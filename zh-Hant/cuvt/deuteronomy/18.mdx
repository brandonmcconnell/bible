## 祭司當得的分

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民數記 18:8–9; 申命記 10:9; 哥林多前書 9:13–14"> 「祭司利未人和利未全支派必在以色列中無分無業；他們所吃用的就是獻給耶和華的火祭和一切所捐的。</span>
<span className="v" id="v2" data-v="2" data-xref="啟示錄 1:5–6; 詩篇 84:11; 彼得前書 2:5"> 他們在弟兄中必沒有產業；耶和華是他們的產業，正如耶和華所應許他們的。</span>
<span className="v" id="v3" data-v="3" data-xref="利未記 7:30–34; 申命記 12:27"> 祭司從百姓所當得的分乃是這樣：凡獻牛或羊為祭的，要把前腿和兩腮並脾胃給祭司。</span>
<span className="v" id="v4" data-v="4" data-xref="尼希米記 12:44–47; 民數記 18:12–24; 歷代志下 31:4–10"> 初收的五穀、新酒和油，並初剪的羊毛，也要給他；</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 10:8; 民數記 3:10; 出埃及記 28:1–14"> 因為耶和華－你的上帝從你各支派中將他揀選出來，使他和他子孫永遠奉耶和華的名侍立，事奉。</span>
<span className="v" id="v6" data-v="6" data-xref="民數記 35:2–3; 申命記 12:5; 申命記 16:2"> 「利未人無論寄居在以色列中的哪一座城，若從那裏出來，一心願意到耶和華所選擇的地方，</span>
<span className="v" id="v7" data-v="7" data-xref="歷代志下 31:2–4"> 就要奉耶和華－他上帝的名事奉，像他眾弟兄利未人侍立在耶和華面前事奉一樣。</span>
<span className="v" id="v8" data-v="8" data-xref="尼希米記 12:44; 尼希米記 12:47; 歷代志下 31:4"> 除了他賣祖父產業所得的以外，還要得一分祭物與他們同吃。」</span>
</div>
</div>

## 不可隨從異邦的惡俗

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="申命記 12:29–31; 利未記 18:26–27; 利未記 18:30"> 「你到了耶和華－你上帝所賜之地，那些國民所行可憎惡的事，你不可學着行。</span>
<span className="v" id="v10" data-v="10" data-xref="利未記 19:31; 出埃及記 22:18; 利未記 19:26"> 你們中間不可有人使兒女經火，也不可有占卜的、觀兆的、用法術的、行邪術的、</span>
<span className="v" id="v11" data-v="11" data-xref="利未記 19:31; 撒母耳記上 28:11–14"> 用迷術的、交鬼的、行巫術的、過陰的。</span>
<span className="v" id="v12" data-v="12" data-xref="利未記 18:24; 申命記 9:4; 利未記 18:27"> 凡行這些事的都為耶和華所憎惡；因那些國民行這可憎惡的事，所以耶和華－你的上帝將他們從你面前趕出。</span>
<span className="v" id="v13" data-v="13" data-xref="馬太福音 5:48; 創世記 17:1; 創世記 6:9"> 你要在耶和華－你的上帝面前作完全人。」</span>
</div>
</div>

## 應許興起先知

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="使徒行傳 14:16; 申命記 18:10; 創世記 20:6"> 「因你所要趕出的那些國民都聽信觀兆的和占卜的，至於你，耶和華－你的上帝從來不許你這樣行。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行傳 3:22–23; 使徒行傳 7:37; 約翰福音 1:45"> 耶和華－你的上帝要從你們弟兄中間給你興起一位先知，像我，你們要聽從他。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 20:19; 申命記 5:23–28; 申命記 9:10"> 正如你在何烈山大會的日子求耶和華－你上帝一切的話，說：『求你不再叫我聽見耶和華－我上帝的聲音，也不再叫我看見這大火，免得我死亡。』</span>
<span className="v" id="v17" data-v="17" data-xref="申命記 5:28"> 耶和華就對我說：『他們所說的是。</span>
<span className="v" id="v18" data-v="18" data-xref="申命記 18:15; 約翰福音 8:28; 約翰福音 12:49–50"> 我必在他們弟兄中間給他們興起一位先知，像你。我要將當說的話傳給他；他要將我一切所吩咐的都傳給他們。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行傳 3:22–23; 希伯來書 2:3; 希伯來書 10:26"> 誰不聽他奉我名所說的話，我必討誰的罪。</span>
<span className="v" id="v20" data-v="20" data-xref="申命記 13:1–5; 耶利米書 27:15; 耶利米書 23:13–15"> 若有先知擅敢託我的名說我所未曾吩咐他說的話，或是奉別神的名說話，那先知就必治死。』</span>
<span className="v" id="v21" data-v="21" data-xref="約翰一書 4:1–3; 帖撒羅尼迦前書 5:24; 啟示錄 2:2"> 你心裏若說：『耶和華所未曾吩咐的話，我們怎能知道呢？』</span>
<span className="v" id="v22" data-v="22" data-xref="申命記 18:20; 列王紀下 20:1; 耶利米書 28:1–17"> 先知託耶和華的名說話，所說的若不成就，也無效驗，這就是耶和華所未曾吩咐的，是那先知擅自說的，你不要怕他。」</span>
</div>
</div>

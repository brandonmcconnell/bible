## 擊敗巴珊王噩

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民數記 21:33–35; 申命記 1:4; 申命記 29:7"> 「以後，我們轉回，向巴珊去。巴珊王噩和他的眾民都出來，在以得來與我們交戰。</span>
<span className="v" id="v2" data-v="2" data-xref="啟示錄 2:10; 歷代志下 20:17; 民數記 21:23–25"> 耶和華對我說：『不要怕他！因我已將他和他的眾民，並他的地，都交在你手中；你要待他像從前待住希實本的亞摩利王西宏一樣。』</span>
<span className="v" id="v3" data-v="3" data-xref="民數記 21:35; 約書亞記 13:12; 約書亞記 13:30"> 於是耶和華－我們的上帝也將巴珊王噩和他的眾民都交在我們手中；我們殺了他們，沒有留下一個。</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀上 4:13; 約書亞記 12:4; 約書亞記 13:30–31"> 那時，我們奪了他所有的城，共有六十座，沒有一座城不被我們所奪。這為亞珥歌伯的全境，就是巴珊地噩王的國。</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 1:28; 民數記 13:28; 希伯來書 11:30"> 這些城都有堅固的高牆，有門有閂。此外還有許多無城牆的鄉村。</span>
<span className="v" id="v6" data-v="6" data-xref="申命記 2:34; 詩篇 135:10–12; 申命記 2:24"> 我們將這些都毀滅了，像從前待希實本王西宏一樣，把有人煙的各城，連女人帶孩子，盡都毀滅；</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 2:35; 約書亞記 8:27; 約書亞記 11:11–14"> 惟有一切牲畜和城中的財物都取為自己的掠物。</span>
<span className="v" id="v8" data-v="8" data-xref="約書亞記 13:9–12; 約書亞記 12:2–6; 民數記 32:33–42"> 那時，我們從約旦河東兩個亞摩利王的手將亞嫩谷直到黑門山之地奪過來（</span>
<span className="v" id="v9" data-v="9" data-xref="歷代志上 5:23; 詩篇 29:6; 以西結書 27:5"> 這黑門山，西頓人稱為西連，亞摩利人稱為示尼珥），</span>
<span className="v" id="v10" data-v="10" data-xref="約書亞記 13:31; 約書亞記 13:11–12; 申命記 4:49"> 就是奪了平原的各城、基列全地、巴珊全地，直到撒迦和以得來，都是巴珊王噩國內的城邑。（</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 14:5; 耶利米書 49:2; 撒母耳記下 12:26"> 利乏音人所剩下的只有巴珊王噩。他的床是鐵的，長九肘，寬四肘，都是以人肘為度。現今豈不是在亞捫人的拉巴嗎？）」</span>
</div>
</div>

## 定居約旦河東的二支派半

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="申命記 2:36; 民數記 32:32–38; 約書亞記 13:8–28"> 「那時，我們得了這地。從亞嫩谷邊的亞羅珥起，我將基列山地的一半，並其中的城邑，都給了呂便人和迦得人。</span>
<span className="v" id="v13" data-v="13" data-xref="民數記 32:39–42; 約書亞記 13:29–32; 歷代志上 5:23–26"> 其餘的基列地和巴珊全地，就是噩王的國，我給了瑪拿西半支派。亞珥歌伯全地乃是巴珊全地；這叫做利乏音人之地。</span>
<span className="v" id="v14" data-v="14" data-xref="民數記 32:41; 約書亞記 13:13; 撒母耳記下 3:3"> 瑪拿西的子孫睚珥佔了亞珥歌伯全境，直到基述人和瑪迦人的交界，就按自己的名稱這巴珊地為哈倭特‧睚珥，直到今日。</span>
<span className="v" id="v15" data-v="15" data-xref="民數記 32:39–40; 約書亞記 17:1–3; 約書亞記 22:7"> 我又將基列給了瑪吉。</span>
<span className="v" id="v16" data-v="16" data-xref="民數記 21:24; 申命記 2:37; 撒母耳記下 24:5"> 從基列到亞嫩谷，以谷中為界，直到亞捫人交界的雅博河，我給了呂便人和迦得人，</span>
<span className="v" id="v17" data-v="17" data-xref="約書亞記 12:3; 創世記 14:3; 約書亞記 3:16"> 又將亞拉巴和靠近約旦河之地，從基尼烈直到亞拉巴海，就是鹽海，並毗斯迦山根東邊之地，都給了他們。</span>
<span className="v" id="v18" data-v="18" data-xref="民數記 32:20–24; 約書亞記 4:12–13; 約書亞記 1:12–15"> 「那時，我吩咐你們說：『耶和華－你們的上帝已將這地賜給你們為業；你們所有的勇士都要帶着兵器，在你們的弟兄以色列人前面過去。</span>
<span className="v" id="v19" data-v="19"> 但你們的妻子、孩子、牲畜（我知道你們有許多的牲畜）可以住在我所賜給你們的各城裏。</span>
<span className="v" id="v20" data-v="20" data-xref="約書亞記 22:4; 約書亞記 22:8"> 等到你們弟兄在約旦河那邊，也得耶和華－你們上帝所賜給他們的地，又使他們得享平安，與你們一樣，你們才可以回到我所賜給你們為業之地。』</span>
<span className="v" id="v21" data-v="21" data-xref="民數記 27:18–23; 哥林多後書 12:10; 詩篇 9:10"> 那時我吩咐約書亞說：『你親眼看見了耶和華－你上帝向這二王所行的；耶和華也必向你所要去的各國照樣行。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及記 14:14; 申命記 20:4; 申命記 1:30"> 你不要怕他們，因那為你爭戰的是耶和華－你的上帝。』」</span>
</div>
</div>

## 摩西不得進入迦南

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="哥林多後書 12:8–9"> 「那時，我懇求耶和華說：</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及記 15:11; 申命記 11:2; 詩篇 71:19"> 『主耶和華啊，你已將你的大力大能顯給僕人看。在天上，在地下，有甚麼神能像你行事、像你有大能的作為呢？</span>
<span className="v" id="v25" data-v="25" data-xref="申命記 4:21–22; 以西結書 20:6; 出埃及記 3:8"> 求你容我過去，看約旦河那邊的美地，就是那佳美的山地和黎巴嫩。』</span>
<span className="v" id="v26" data-v="26" data-xref="申命記 1:37; 申命記 31:2; 歷代志上 22:7–9"> 但耶和華因你們的緣故向我發怒，不應允我，對我說：『罷了！你不要向我再提這事。</span>
<span className="v" id="v27" data-v="27" data-xref="民數記 27:12; 申命記 34:1–4; 創世記 13:14–15"> 你且上毗斯迦山頂去，向東、西、南、北舉目觀望，因為你必不能過這約旦河。</span>
<span className="v" id="v28" data-v="28" data-xref="申命記 31:3; 申命記 31:7; 申命記 1:38"> 你卻要囑咐約書亞，勉勵他，使他膽壯；因為他必在這百姓前面過去，使他們承受你所要觀看之地。』</span>
<span className="v" id="v29" data-v="29" data-xref="申命記 34:6; 申命記 4:46; 民數記 25:3"> 於是我們住在伯‧毗珥對面的谷中。」</span>
</div>
</div>

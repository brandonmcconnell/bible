## 上帝的律法寫在石頭上

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="約翰福音 15:14; 路加福音 11:28; 雅各書 2:10"> 摩西和以色列的眾長老吩咐百姓說：「你們要遵守我今日所吩咐的一切誡命。</span>
<span className="v" id="v2" data-v="2" data-xref="約書亞記 8:31; 以西結書 36:26; 以西結書 11:19"> 你們過約旦河，到了耶和華－你上帝所賜給你的地，當天要立起幾塊大石頭，墁上石灰，</span>
<span className="v" id="v3" data-v="3" data-xref="約書亞記 8:32; 申命記 26:9; 哥林多後書 3:2–3"> 把這律法的一切話寫在石頭上。你過了河，可以進入耶和華－你上帝所賜你流奶與蜜之地，正如耶和華－你列祖之上帝所應許你的。</span>
<span className="v" id="v4" data-v="4" data-xref="申命記 11:29–30; 約書亞記 8:30–33"> 你們過了約旦河，就要在以巴路山上照我今日所吩咐的，將這些石頭立起來，墁上石灰。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 20:25; 出埃及記 24:4; 約書亞記 8:30–31"> 在那裏要為耶和華－你的上帝築一座石壇；在石頭上不可動鐵器。</span>
<span className="v" id="v6" data-v="6" data-xref="以弗所書 5:2; 利未記 1:1–17"> 要用沒有鑿過的石頭築耶和華－你上帝的壇，在壇上要將燔祭獻給耶和華－你的上帝。</span>
<span className="v" id="v7" data-v="7" data-xref="利未記 3:1–17; 以賽亞書 12:3; 詩篇 100:1–2"> 又要獻平安祭，且在那裏吃，在耶和華－你的上帝面前歡樂。</span>
<span className="v" id="v8" data-v="8" data-xref="哈巴谷書 2:2; 約翰福音 16:25; 哥林多後書 3:12"> 你要將這律法的一切話明明地寫在石頭上。」</span>
<span className="v" id="v9" data-v="9" data-xref="彼得前書 2:10–11; 申命記 26:16–18; 以弗所書 5:8–9"> 摩西和祭司利未人曉諭以色列眾人說：「以色列啊，要默默靜聽。你今日成為耶和華－你上帝的百姓了。</span>
<span className="v" id="v10" data-v="10" data-xref="申命記 11:1; 彼得前書 1:14–16; 馬太福音 5:48"> 所以要聽從耶和華－你上帝的話，遵行他的誡命律例，就是我今日所吩咐你的。」</span>
</div>
</div>

## 違命必受咒詛

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11"> 當日，摩西囑咐百姓說：</span>
<span className="v" id="v12" data-v="12" data-xref="士師記 9:7; 創世記 30:24; 創世記 35:18"> 「你們過了約旦河，西緬、利未、猶大、以薩迦、約瑟、便雅憫六個支派的人都要站在基利心山上為百姓祝福。</span>
<span className="v" id="v13" data-v="13" data-xref="申命記 27:4; 創世記 29:32; 創世記 30:20"> 呂便、迦得、亞設、西布倫、但、拿弗他利六個支派的人都要站在以巴路山上宣布咒詛。</span>
<span className="v" id="v14" data-v="14" data-xref="但以理書 9:11; 申命記 33:9–10; 約書亞記 8:33"> 利未人要向以色列眾人高聲說：</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及記 34:17; 出埃及記 20:4; 申命記 5:8"> 「『有人製造耶和華所憎惡的偶像，或雕刻，或鑄造，就是工匠手所做的，在暗中設立，那人必受咒詛！』百姓都要答應說：『阿們！』</span>
<span className="v" id="v16" data-v="16" data-xref="利未記 19:3; 出埃及記 21:17; 申命記 21:18–21"> 「『輕慢父母的，必受咒詛！』百姓都要說：『阿們！』</span>
<span className="v" id="v17" data-v="17" data-xref="申命記 19:14; 箴言 22:28; 箴言 23:10–11"> 「『挪移鄰舍地界的，必受咒詛！』百姓都要說：『阿們！』</span>
<span className="v" id="v18" data-v="18" data-xref="利未記 19:14; 馬太福音 15:14; 箴言 28:10"> 「『使瞎子走差路的，必受咒詛！』百姓都要說：『阿們！』</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 10:18; 申命記 24:17; 箴言 17:23"> 「『向寄居的和孤兒寡婦屈枉正直的，必受咒詛！』百姓都要說：『阿們！』</span>
<span className="v" id="v20" data-v="20" data-xref="申命記 22:30; 利未記 18:8; 哥林多前書 5:1"> 「『與繼母行淫的，必受咒詛！因為掀開他父親的衣襟。』百姓都要說：『阿們！』</span>
<span className="v" id="v21" data-v="21" data-xref="利未記 18:23; 出埃及記 22:19; 利未記 20:15"> 「『與獸淫合的，必受咒詛！』百姓都要說：『阿們！』</span>
<span className="v" id="v22" data-v="22" data-xref="利未記 20:17; 利未記 18:9; 以西結書 22:11"> 「『與異母同父，或異父同母的姊妹行淫的，必受咒詛！』百姓都要說：『阿們！』</span>
<span className="v" id="v23" data-v="23" data-xref="利未記 20:14; 利未記 18:17"> 「『與岳母行淫的，必受咒詛！』百姓都要說：『阿們！』</span>
<span className="v" id="v24" data-v="24" data-xref="民數記 35:31; 利未記 24:17; 撒母耳記下 11:15–17"> 「『暗中殺人的，必受咒詛！』百姓都要說：『阿們！』</span>
<span className="v" id="v25" data-v="25" data-xref="申命記 10:17; 出埃及記 23:7–8; 詩篇 15:5"> 「『受賄賂害死無辜之人的，必受咒詛！』百姓都要說：『阿們！』</span>
<span className="v" id="v26" data-v="26" data-xref="加拉太書 3:10; 申命記 28:15–68; 羅馬書 10:5"> 「『不堅守遵行這律法言語的，必受咒詛！』百姓都要說：『阿們！』」</span>

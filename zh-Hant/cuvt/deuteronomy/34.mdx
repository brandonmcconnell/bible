## 摩西去世

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西結書 40:2; 申命記 32:49; 約書亞記 19:47"> 摩西從摩押平原登尼波山，上了那與耶利哥相對的毗斯迦山頂。耶和華把基列全地直到但，</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 11:24; 民數記 34:6; 出埃及記 23:31"> 拿弗他利全地，以法蓮、瑪拿西的地，猶大全地直到西海，</span>
<span className="v" id="v3" data-v="3" data-xref="歷代志下 28:15; 士師記 1:16; 士師記 3:13"> 南地和棕樹城耶利哥的平原，直到瑣珥，都指給他看。</span>
<span className="v" id="v4" data-v="4" data-xref="申命記 32:52; 創世記 12:7; 創世記 28:13"> 耶和華對他說：「這就是我向亞伯拉罕、以撒、雅各起誓應許之地，說：『我必將這地賜給你的後裔。』現在我使你眼睛看見了，你卻不得過到那裏去。」</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 32:50; 約書亞記 1:1–2; 希伯來書 3:3–6"> 於是，耶和華的僕人摩西死在摩押地，正如耶和華所說的。</span>
<span className="v" id="v6" data-v="6" data-xref="猶大書 1:9; 申命記 3:29"> 耶和華將他埋葬在摩押地、伯‧毗珥對面的谷中，只是到今日沒有人知道他的墳墓。</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 31:2; 約書亞記 14:10–11; 創世記 27:1"> 摩西死的時候年一百二十歲；眼目沒有昏花，精神沒有衰敗。</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 50:3; 民數記 20:29; 創世記 50:10"> 以色列人在摩押平原為摩西哀哭了三十日，為摩西居喪哀哭的日子就滿了。</span>
<span className="v" id="v9" data-v="9" data-xref="以賽亞書 11:2; 但以理書 6:3; 使徒行傳 6:6"> 嫩的兒子約書亞；因為摩西曾按手在他頭上，就被智慧的靈充滿，以色列人便聽從他，照着耶和華吩咐摩西的行了。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及記 33:11; 民數記 12:6–8; 申命記 18:15–18"> 以後以色列中再沒有興起先知像摩西的。他是耶和華面對面所認識的。</span>
<span className="v" id="v11" data-v="11" data-xref="申命記 7:19; 申命記 4:34; 詩篇 105:26–38"> 耶和華打發他在埃及地向法老和他的一切臣僕，並他的全地，行各樣神蹟奇事，</span>
<span className="v" id="v12" data-v="12"> 又在以色列眾人眼前顯大能的手，行一切大而可畏的事。</span>

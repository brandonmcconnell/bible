## 十誡

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命記 4:1; 馬太福音 23:3; 申命記 29:10"> 摩西將以色列眾人召了來，對他們說：「以色列人哪，我今日曉諭你們的律例典章，你們要聽，可以學習，謹守遵行。</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 4:23; 出埃及記 19:5–8; 出埃及記 24:8"> 耶和華－我們的上帝在何烈山與我們立約。</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 29:10–15; 創世記 17:21; 創世記 17:7"> 這約不是與我們列祖立的，乃是與我們今日在這裏存活之人立的。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及記 19:18–19; 申命記 34:10; 出埃及記 19:9"> 耶和華在山上，從火中，面對面與你們說話－</span>
<span className="v" id="v5" data-v="5" data-xref="加拉太書 3:19; 出埃及記 19:16; 出埃及記 20:18–21"> 那時我站在耶和華和你們中間，要將耶和華的話傳給你們；因為你們懼怕那火，沒有上山－說：</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="出埃及記 20:2–17; 詩篇 81:5–10; 利未記 26:1–2"> 「『我是耶和華－你的上帝，曾將你從埃及地為奴之家領出來。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="出埃及記 20:3; 馬太福音 4:10; 約翰一書 5:21"> 「『除了我以外，你不可有別的神。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="出埃及記 20:4; 申命記 4:15–19"> 「『不可為自己雕刻偶像，也不可做甚麼形像，彷彿上天、下地和地底下、水中的百物。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及記 20:4–6; 出埃及記 34:7; 但以理書 9:4–9"> 不可跪拜那些像，也不可事奉它，因為我耶和華－你的上帝是忌邪的上帝。恨我的，我必追討他的罪，自父及子，直到三、四代；</span>
<span className="v" id="v10" data-v="10" data-xref="羅馬書 8:28; 約翰一書 1:7; 耶利米書 32:18"> 愛我、守我誡命的，我必向他們發慈愛，直到千代。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="出埃及記 20:7; 利未記 19:12; 申命記 6:13"> 「『不可妄稱耶和華－你上帝的名；因為妄稱耶和華名的，耶和華必不以他為無罪。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="出埃及記 20:8–11; 以賽亞書 58:13; 以賽亞書 56:6"> 「『當照耶和華－你上帝所吩咐的守安息日為聖日。</span>
<span className="v" id="v13" data-v="13" data-xref="以西結書 20:12; 路加福音 13:14–16; 出埃及記 23:12"> 六日要勞碌做你一切的工，</span>
<span className="v" id="v14" data-v="14" data-xref="希伯來書 4:4; 創世記 2:2; 出埃及記 23:12"> 但第七日是向耶和華－你上帝當守的安息日。這一日，你和你的兒女、僕婢、牛、驢、牲畜，並在你城裏寄居的客旅，無論何工都不可做，使你的僕婢可以和你一樣安息。</span>
<span className="v" id="v15" data-v="15" data-xref="申命記 5:6; 申命記 15:15; 申命記 16:12"> 你也要記念你在埃及地作過奴僕；耶和華－你上帝用大能的手和伸出來的膀臂將你從那裏領出來。因此，耶和華－你的上帝吩咐你守安息日。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="出埃及記 20:12; 以弗所書 6:1–3; 歌羅西書 3:20"> 「『當照耶和華－你上帝所吩咐的孝敬父母，使你得福，並使你的日子在耶和華－你上帝所賜你的地上得以長久。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="出埃及記 20:13; 羅馬書 13:9; 馬太福音 5:21–22"> 「『不可殺人。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="出埃及記 20:14; 路加福音 18:20; 利未記 20:10"> 「『不可姦淫。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="出埃及記 20:15; 羅馬書 13:9; 以弗所書 4:28"> 「『不可偷盜。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="出埃及記 20:16; 出埃及記 23:1; 箴言 19:9"> 「『不可作假見證陷害人。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="出埃及記 20:17; 羅馬書 13:9; 路加福音 12:15"> 「『不可貪戀人的妻子；也不可貪圖人的房屋、田地、僕婢、牛、驢，並他一切所有的。』</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="出埃及記 24:12; 出埃及記 31:18; 申命記 4:12–15"> 「這些話是耶和華在山上，從火中、雲中、幽暗中，大聲曉諭你們全會眾的；此外並沒有添別的話。他就把這話寫在兩塊石版上，交給我了。」</span>
</div>
</div>

## 百姓看見火焰燒山而懼怕

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="出埃及記 20:18–19; 希伯來書 12:18–21"> 「那時，火焰燒山，你們聽見從黑暗中出來的聲音；你們支派中所有的首領和長老都來就近我，</span>
<span className="v" id="v24" data-v="24" data-xref="申命記 4:33; 出埃及記 19:19; 出埃及記 33:20"> 說：『看哪，耶和華－我們上帝將他的榮光和他的大能顯給我們看，我們又聽見他的聲音從火中出來。今日我們得見上帝與人說話，人還存活。</span>
<span className="v" id="v25" data-v="25" data-xref="申命記 18:16; 加拉太書 3:10; 哥林多後書 3:7–9"> 現在這大火將要燒滅我們，我們何必冒死呢？若再聽見耶和華－我們上帝的聲音就必死亡。</span>
<span className="v" id="v26" data-v="26" data-xref="申命記 4:33; 羅馬書 3:20; 馬太福音 26:63"> 凡屬血氣的，曾有何人聽見永生上帝的聲音從火中出來，像我們聽見還能存活呢？</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及記 20:19; 希伯來書 12:19"> 求你近前去，聽耶和華－我們上帝所要說的一切話，將他對你說的話都傳給我們，我們就聽從遵行。』</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="申命記 18:17; 民數記 36:5; 民數記 27:7"> 「你們對我說的話，耶和華都聽見了。耶和華對我說：『這百姓的話，我聽見了；他們所說的都是。</span>
<span className="v" id="v29" data-v="29" data-xref="以賽亞書 48:18; 以西結書 33:31–32; 申命記 11:1"> 惟願他們存這樣的心敬畏我，常遵守我的一切誡命，使他們和他們的子孫永遠得福。</span>
<span className="v" id="v30" data-v="30"> 你去對他們說：你們回帳棚去吧！</span>
<span className="v" id="v31" data-v="31" data-xref="加拉太書 3:19; 以西結書 20:11; 申命記 5:1"> 至於你，可以站在我這裏，我要將一切誡命、律例、典章傳給你；你要教訓他們，使他們在我賜他們為業的地上遵行。』</span>
<span className="v" id="v32" data-v="32" data-xref="約書亞記 23:6; 箴言 4:27; 約書亞記 1:7"> 所以，你們要照耶和華－你們上帝所吩咐的謹守遵行，不可偏離左右。</span>
<span className="v" id="v33" data-v="33" data-xref="耶利米書 7:23; 申命記 4:40; 路加福音 1:6"> 耶和華－你們上帝所吩咐你們行的，你們都要去行，使你們可以存活得福，並使你們的日子在所要承受的地上得以長久。」</span>
</div>
</div>

<span className="v" id="v1" data-v="1" data-xref="耶利米書 23:25–28; 約翰一書 4:1; 耶利米書 29:8"> 「你們中間若有先知或是做夢的起來，向你顯個神蹟奇事，</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 13:6; 馬太福音 7:22–23; 啟示錄 13:13–14"> 對你說：『我們去隨從你素來所不認識的別神，事奉它吧。』他所顯的神蹟奇事雖有應驗，</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 8:2; 哥林多前書 11:19; 詩篇 66:10"> 你也不可聽那先知或是那做夢之人的話；因為這是耶和華－你們的上帝試驗你們，要知道你們是盡心盡性愛耶和華－你們的上帝不是。</span>
<span className="v" id="v4" data-v="4" data-xref="歌羅西書 1:10; 申命記 10:20; 哥林多前書 6:17"> 你們要順從耶和華－你們的上帝，敬畏他，謹守他的誡命，聽從他的話，事奉他，專靠他。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多前書 5:13; 申命記 18:20; 耶利米書 14:15"> 那先知或是那做夢的既用言語叛逆那領你們出埃及地、救贖你脫離為奴之家的耶和華－你們的上帝，要勾引你離開耶和華－你上帝所吩咐你行的道，你便要將他治死。這樣，就把那惡從你們中間除掉。</span>
<span className="v" id="v6" data-v="6" data-xref="申命記 17:2–7; 彼得後書 2:1; 以弗所書 4:14"> 「你的同胞弟兄，或是你的兒女，或是你懷中的妻，或是如同你性命的朋友，若暗中引誘你，說：『我們不如去事奉你和你列祖素來所不認識的別神－</span>
<span className="v" id="v7" data-v="7"> 是你四圍列國的神。』無論是離你近，離你遠，從地這邊到地那邊的神，</span>
<span className="v" id="v8" data-v="8" data-xref="申命記 19:13; 箴言 1:10; 申命記 7:16"> 你不可依從他，也不可聽從他，眼不可顧惜他。你不可憐恤他，也不可遮庇他，</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行傳 7:58; 路加福音 14:26; 馬太福音 10:37"> 總要殺他；你先下手，然後眾民也下手，將他治死。</span>
<span className="v" id="v10" data-v="10" data-xref="約書亞記 7:25; 利未記 24:14–16; 出埃及記 20:2"> 要用石頭打死他，因為他想要勾引你離開那領你出埃及地為奴之家的耶和華－你的上帝。</span>
<span className="v" id="v11" data-v="11" data-xref="申命記 19:20; 申命記 17:13; 提摩太前書 5:20"> 以色列眾人都要聽見害怕，就不敢在你們中間再行這樣的惡了。</span>
<span className="v" id="v12" data-v="12" data-xref="士師記 20:1–17; 約書亞記 22:11–34"> 「在耶和華－你上帝所賜你居住的各城中，你若聽人說，有些匪類從你們中間的一座城出來勾引本城的居民，說：『我們不如去事奉你們素來所不認識的別神』；</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 17:4; 以賽亞書 11:3–4; 約翰福音 7:24"> 你就要探聽，查究，細細地訪問，果然是真，準有這可憎惡的事行在你們中間，</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及記 22:20; 利未記 27:28; 申命記 7:2"> 你必要用刀殺那城裏的居民，把城裏所有的，連牲畜，都用刀殺盡。</span>
<span className="v" id="v16" data-v="16" data-xref="耶利米書 49:2; 約書亞記 8:28; 以賽亞書 25:2"> 你從那城裏所奪的財物都要堆積在街市上，用火將城和其內所奪的財物都在耶和華－你上帝面前燒盡；那城就永為荒堆，不可再建造。</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 26:4; 申命記 7:26; 約書亞記 7:26"> 那當毀滅的物連一點都不可粘你的手。你要聽從耶和華－你上帝的話，遵守我今日所吩咐你的一切誡命，行耶和華－你上帝眼中看為正的事，耶和華就必轉意，不發烈怒，恩待你，憐恤你，照他向你列祖所起的誓使你人數增多。」</span>

## 摩西祝福以色列眾支派

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="約書亞記 14:6; 詩篇 90:1; 創世記 27:4"> 以下是神人摩西在未死之先為以色列人所祝的福：</span>
<span className="v" id="v2" data-v="2" data-xref="猶大書 1:14; 哈巴谷書 3:3; 啟示錄 5:11"> <span className="pl pl-1">他說：耶和華從西奈而來，</span><br /><span className="pl pl-1">從西珥向他們顯現，</span><br /><span className="pl pl-1">從巴蘭山發出光輝，</span><br /><span className="pl pl-1">從萬萬聖者中來臨，</span><br /><span className="pl pl-1">從他右手為百姓傳出烈火的律法。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="路加福音 10:39; 瑪拉基書 1:2; 申命記 7:6–8"> <span className="pl pl-1">他疼愛百姓；</span><br /><span className="pl pl-1">眾聖徒都在他手中。</span><br /><span className="pl pl-1">他們坐在他的腳下，</span><br /><span className="pl pl-1">領受他的言語。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="約翰福音 1:17; 詩篇 119:111; 約翰福音 7:19"> <span className="pl pl-1">摩西將律法傳給我們，</span><br /><span className="pl pl-1">作為雅各會眾的產業。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="申命記 32:15; 士師記 17:6; 民數記 23:21"> <span className="pl pl-1">百姓的眾首領，</span><br /><span className="pl pl-1">以色列的各支派，</span><br /><span className="pl pl-1">一同聚會的時候，</span><br /><span className="pl pl-1">耶和華</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是他">a</a></sup><br /><span className="pl pl-1">在耶書崙中為王。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="創世記 49:8; 民數記 32:31–32; 約書亞記 22:1–9"> <span className="pl pl-1">願呂便存活，不致死亡；</span><br /><span className="pl pl-1">願他人數不致稀少。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="創世記 49:8–12; 詩篇 20:2; 撒母耳記下 7:9–12"> <span className="pl pl-1">為猶大祝福說：</span><br /><span className="pl pl-1">求耶和華俯聽猶大的聲音，</span><br /><span className="pl pl-1">引導他歸於本族；</span><br /><span className="pl pl-1">他曾用手為自己爭戰，</span><br /><span className="pl pl-1">你必幫助他攻擊敵人。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="出埃及記 17:7; 出埃及記 28:30; 民數記 20:13"> <span className="pl pl-1">論利未說：</span><br /><span className="pl pl-1">耶和華啊，你的土明和烏陵</span><br /><span className="pl pl-1">都在你的虔誠人那裏。</span><br /><span className="pl pl-1">你在瑪撒曾試驗他，</span><br /><span className="pl pl-1">在米利巴水與他爭論。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="馬太福音 10:37; 出埃及記 32:25–29; 馬太福音 12:48"> <span className="pl pl-1">他論自己的父母說：</span><br /><span className="pl pl-1">我未曾看見；</span><br /><span className="pl pl-1">他也不承認弟兄，</span><br /><span className="pl pl-1">也不認識自己的兒女。</span><br /><span className="pl pl-1">這是因利未人遵行你的話，</span><br /><span className="pl pl-1">謹守你的約。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="利未記 10:11; 詩篇 51:19; 申命記 17:9–11"> <span className="pl pl-1">他們要將你的典章教訓雅各，</span><br /><span className="pl pl-1">將你的律法教訓以色列。</span><br /><span className="pl pl-1">他們要把香焚在你面前，</span><br /><span className="pl pl-1">把全牲的燔祭獻在你的壇上。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳記下 24:23; 以西結書 43:27; 以西結書 20:40–41"> <span className="pl pl-1">求耶和華降福在他的財物上，</span><br /><span className="pl pl-1">悅納他手裏所辦的事。</span><br /><span className="pl pl-1">那些起來攻擊他和恨惡他的人，</span><br /><span className="pl pl-1">願你刺透他們的腰，</span><br /><span className="pl pl-1">使他們不得再起來。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="歷代志下 15:2; 詩篇 91:4; 馬太福音 23:37"> <span className="pl pl-1">論便雅憫說：</span><br /><span className="pl pl-1">耶和華所親愛的必同耶和華安然居住；</span><br /><span className="pl pl-1">耶和華終日遮蔽他，也住在他兩肩之中。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v13" data-v="13" data-xref="創世記 49:22–26; 彌迦書 5:7; 以賽亞書 18:4"> <span className="pl pl-1">論約瑟說：</span><br /><span className="pl pl-1">願他的地蒙耶和華賜福，</span><br /><span className="pl pl-1">得天上的寶物、甘露，</span><br /><span className="pl pl-1">以及地裏所藏的泉水；</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="詩篇 104:19; 馬太福音 5:45; 詩篇 8:3"> <span className="pl pl-1">得太陽所曬熟的美果，</span><br /><span className="pl pl-1">月亮所養成的寶物；</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="哈巴谷書 3:6; 創世記 49:26; 雅各書 5:7"> <span className="pl pl-1">得上古之山的至寶，</span><br /><span className="pl pl-1">永世之嶺的寶物；</span><br /></span>

<span className="v" id="v17" data-v="17" data-xref="列王紀上 22:11; 民數記 23:22; 詩篇 44:5"> <span className="pl pl-1">他為牛群中頭生的，有威嚴；</span><br /><span className="pl pl-1">他的角是野牛的角，</span><br /><span className="pl pl-1">用以牴觸萬邦，直到地極。</span><br /><span className="pl pl-1">這角是以法蓮的萬萬，</span><br /><span className="pl pl-1">瑪拿西的千千。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="創世記 49:13–15; 約書亞記 19:11; 士師記 5:14"> <span className="pl pl-1">論西布倫說：</span><br /><span className="pl pl-1">西布倫哪，你出外可以歡喜。</span><br /><span className="pl pl-1">以薩迦啊，在你帳棚裏可以快樂。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="以賽亞書 60:5; 以賽亞書 2:3; 詩篇 4:5"> <span className="pl pl-1">他們要將列邦召到山上，</span><br /><span className="pl pl-1">在那裏獻公義的祭；</span><br /><span className="pl pl-1">因為他們要吸取海裏的豐富，</span><br /><span className="pl pl-1">並沙中所藏的珍寶。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v20" data-v="20" data-xref="創世記 49:19; 創世記 9:26–27; 歷代志上 5:18–21"> <span className="pl pl-1">論迦得說：</span><br /><span className="pl pl-1">使迦得擴張的應當稱頌！</span><br /><span className="pl pl-1">迦得住如母獅；</span><br /><span className="pl pl-1">他撕裂膀臂，連頭頂也撕裂。</span><br /></span>

</div>
<div className="bp poetry">
<span className="v" id="v24" data-v="24" data-xref="創世記 49:20; 約伯記 29:6; 羅馬書 14:18"> <span className="pl pl-1">論亞設說：</span><br /><span className="pl pl-1">願亞設享受多子的福樂，</span><br /><span className="pl pl-1">得他弟兄的喜悅，</span><br /><span className="pl pl-1">可以把腳蘸在油中。</span><br /></span>

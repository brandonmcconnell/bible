## 潔淨和不潔淨的動物

<div className="bt">
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="以西結書 4:14; 羅馬書 14:14; 利未記 20:25"> 「凡可憎的物都不可吃。</span>
<span className="v" id="v4" data-v="4" data-xref="利未記 11:2–45; 使徒行傳 10:14; 列王紀上 4:23"> 可吃的牲畜就是牛、綿羊、山羊、</span>
<span className="v" id="v5" data-v="5"> 鹿、羚羊、誁子、野山羊、麋鹿、黃羊、青羊。</span>
<span className="v" id="v6" data-v="6" data-xref="箴言 18:1; 哥林多後書 6:17; 詩篇 1:1–2"> 凡分蹄成為兩瓣又倒嚼的走獸，你們都可以吃。</span>
<span className="v" id="v7" data-v="7" data-xref="馬太福音 7:22–23; 提多書 1:16; 提摩太後書 3:5"> 但那些倒嚼或是分蹄之中不可吃的乃是駱駝、觠子、沙番－因為是倒嚼不分蹄，就與你們不潔淨；</span>
<span className="v" id="v8" data-v="8" data-xref="利未記 11:26–27; 以賽亞書 66:3; 彼得後書 2:22"> 豬－因為是分蹄卻不倒嚼，就與你們不潔淨。這些獸的肉，你們不可吃，死的也不可摸。</span>
<span className="v" id="v9" data-v="9" data-xref="利未記 11:9–12"> 「水中可吃的乃是這些：凡有翅有鱗的都可以吃；</span>
<span className="v" id="v10" data-v="10"> 凡無翅無鱗的都不可吃，是與你們不潔淨。</span>
<span className="v" id="v11" data-v="11"> 「凡潔淨的鳥，你們都可以吃。</span>
<span className="v" id="v12" data-v="12" data-xref="利未記 11:13–19"> 不可吃的乃是鵰、狗頭鵰、紅頭鵰、</span>
<span className="v" id="v13" data-v="13"> 鸇、小鷹、鷂鷹與其類，</span>
<span className="v" id="v14" data-v="14"> 烏鴉與其類，</span>
<span className="v" id="v15" data-v="15" data-xref="約伯記 30:29"> 鴕鳥、夜鷹、魚鷹、鷹與其類，</span>
<span className="v" id="v16" data-v="16"> 鴞鳥、貓頭鷹、角鴟、</span>
<span className="v" id="v17" data-v="17"> 鵜鶘、禿鵰、鸕鶿、</span>
<span className="v" id="v18" data-v="18"> 鸛、鷺鷥與其類，戴鵀與蝙蝠。</span>
<span className="v" id="v19" data-v="19" data-xref="腓立比書 3:19; 利未記 11:20–23"> 凡有翅膀爬行的物是與你們不潔淨，都不可吃。</span>
<span className="v" id="v20" data-v="20"> 凡潔淨的鳥，你們都可以吃。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及記 23:19; 出埃及記 34:26; 利未記 22:8"> 「凡自死的，你們都不可吃，可以給你城裏寄居的吃，或賣與外人吃，因為你是歸耶和華－你上帝為聖潔的民。 「不可用山羊羔母的奶煮山羊羔。」</span>
</div>
</div>

## 十分獻一的條例

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="尼希米記 10:37; 申命記 12:17; 申命記 26:12–15"> 「你要把你撒種所產的，就是你田地每年所出的，十分取一分；</span>
<span className="v" id="v23" data-v="23" data-xref="申命記 12:5–7; 申命記 4:10; 申命記 12:17–18"> 又要把你的五穀、新酒、和油的十分之一，並牛群羊群中頭生的，吃在耶和華－你上帝面前，就是他所選擇要立為他名的居所。這樣，你可以學習時常敬畏耶和華－你的上帝。</span>
<span className="v" id="v24" data-v="24" data-xref="申命記 12:21; 申命記 12:5; 申命記 11:24"> 當耶和華－你上帝賜福與你的時候，耶和華－你上帝所選擇要立為他名的地方若離你太遠，那路也太長，使你不能把這物帶到那裏去，</span>
<span className="v" id="v25" data-v="25"> 你就可以換成銀子，將銀子包起來，拿在手中，往耶和華－你上帝所要選擇的地方去。</span>
<span className="v" id="v26" data-v="26" data-xref="傳道書 9:7; 申命記 12:7; 馬太福音 21:12"> 你用這銀子，隨心所欲，或買牛羊，或買清酒濃酒，凡你心所想的都可以買；你和你的家屬在耶和華－你上帝的面前吃喝快樂。</span>
<span className="v" id="v27" data-v="27" data-xref="民數記 18:20; 申命記 14:29; 申命記 12:12"> 「住在你城裏的利未人，你不可丟棄他，因為他在你們中間無分無業。</span>
<span className="v" id="v28" data-v="28" data-xref="申命記 14:22; 阿摩司書 4:4; 申命記 26:12–15"> 每逢三年的末一年，你要將本年的土產十分之一都取出來，積存在你的城中。</span>
<span className="v" id="v29" data-v="29" data-xref="申命記 15:10; 申命記 14:27; 箴言 19:17"> 在你城裏無分無業的利未人，和你城裏寄居的，並孤兒寡婦，都可以來，吃得飽足。這樣，耶和華－你的上帝必在你手裏所辦的一切事上賜福與你。」</span>
</div>
</div>

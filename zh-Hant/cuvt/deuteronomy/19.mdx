## 設立庇護城

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命記 12:29; 申命記 6:10; 申命記 7:1–2"> 「耶和華－你上帝將列國之民剪除的時候，耶和華－你上帝也將他們的地賜給你，你接着住他們的城邑並他們的房屋，</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 21:13; 約書亞記 20:2–7; 申命記 4:41–43"> 就要在耶和華－你上帝所賜你為業的地上分定三座城。</span>
<span className="v" id="v3" data-v="3" data-xref="以賽亞書 57:14; 希伯來書 12:13; 以賽亞書 35:8"> 要將耶和華－你上帝使你承受為業的地分為三段；又要預備道路，使誤殺人的，都可以逃到那裏去。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="民數記 35:15–24; 申命記 4:42; 以賽亞書 30:33"> 「誤殺人的逃到那裏可以存活，定例乃是這樣：凡素無仇恨，無心殺了人的，</span>
<span className="v" id="v5" data-v="5" data-xref="民數記 35:25; 箴言 27:12; 列王紀下 6:5–7"> 就如人與鄰舍同入樹林砍伐樹木，手拿斧子一砍，本想砍下樹木，不料，斧頭脫了把，飛落在鄰舍身上，以致於死，這人逃到那些城的一座城，就可以存活，</span>
<span className="v" id="v6" data-v="6" data-xref="民數記 35:12; 撒母耳記下 14:7; 申命記 21:22"> 免得報血仇的，心中火熱追趕他，因路遠就追上，將他殺死；其實他不該死，因為他與被殺的素無仇恨。</span>
<span className="v" id="v7" data-v="7"> 所以我吩咐你說，要分定三座城。</span>
<span className="v" id="v8" data-v="8" data-xref="申命記 12:20; 出埃及記 34:24; 出埃及記 23:31"> 耶和華－你上帝若照他向你列祖所起的誓擴張你的境界，將所應許賜你列祖的地全然給你，</span>
<span className="v" id="v9" data-v="9" data-xref="約書亞記 20:7–8; 申命記 11:22–25; 申命記 12:32"> 你若謹守遵行我今日所吩咐的這一切誡命，愛耶和華－你的上帝，常常遵行他的道，就要在這三座城之外，再添三座城，</span>
<span className="v" id="v10" data-v="10" data-xref="以賽亞書 59:7; 箴言 6:17; 馬太福音 27:4–5"> 免得無辜之人的血流在耶和華－你上帝所賜你為業的地上，流血的罪就歸於你。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="民數記 35:16–21; 申命記 27:24; 創世記 9:6"> 「若有人恨他的鄰舍，埋伏着起來擊殺他，以致於死，便逃到這些城的一座城，</span>
<span className="v" id="v12" data-v="12" data-xref="列王紀上 2:28–34; 列王紀上 2:5–6"> 本城的長老就要打發人去，從那裏帶出他來，交在報血仇的手中，將他治死。</span>
<span className="v" id="v13" data-v="13" data-xref="列王紀上 2:31; 申命記 21:9; 申命記 7:16"> 你眼不可顧惜他，卻要從以色列中除掉流無辜血的罪，使你可以得福。」</span>
</div>
</div>

## 有關證人的條例

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="民數記 35:30; 申命記 17:6; 哥林多後書 13:1"> 「人無論犯甚麼罪，作甚麼惡，不可憑一個人的口作見證，總要憑兩三個人的口作見證才可定案。</span>
<span className="v" id="v16" data-v="16" data-xref="詩篇 27:12; 詩篇 35:11; 出埃及記 23:1–7"> 若有凶惡的見證人起來，見證某人作惡，</span>
<span className="v" id="v17" data-v="17" data-xref="申命記 17:9; 申命記 21:5; 瑪拉基書 2:7"> 這兩個爭訟的人就要站在耶和華面前，和當時的祭司，並審判官面前，</span>
<span className="v" id="v18" data-v="18" data-xref="申命記 13:14; 申命記 17:4; 歷代志下 19:6–7"> 審判官要細細地查究，若見證人果然是作假見證的，以假見證陷害弟兄，</span>
<span className="v" id="v19" data-v="19" data-xref="箴言 19:5; 箴言 19:9; 但以理書 6:24"> 你們就要待他如同他想要待的弟兄。這樣，就把那惡從你們中間除掉。</span>
<span className="v" id="v20" data-v="20" data-xref="申命記 21:21; 申命記 17:13; 申命記 13:11"> 別人聽見都要害怕，就不敢在你們中間再行這樣的惡了。</span>
<span className="v" id="v21" data-v="21" data-xref="馬太福音 5:38–39; 出埃及記 21:23–25; 申命記 19:13"> 你眼不可顧惜，要以命償命，以眼還眼，以牙還牙，以手還手，以腳還腳。」</span>
</div>
</div>

## 遵行誡命蒙福

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以賽亞書 1:19; 出埃及記 23:22; 利未記 26:3–13"> 「你若留意聽從耶和華－你上帝的話，謹守遵行他的一切誡命，就是我今日所吩咐你的，他必使你超乎天下萬民之上。</span>
<span className="v" id="v2" data-v="2" data-xref="撒迦利亞書 1:6; 申命記 28:15; 提摩太前書 4:8"> 你若聽從耶和華－你上帝的話，這以下的福必追隨你，臨到你身上：</span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 144:12–15; 創世記 39:5; 哈該書 2:19"> 你在城裏必蒙福，在田間也必蒙福。</span>
<span className="v" id="v4" data-v="4" data-xref="箴言 10:22; 創世記 49:25; 申命記 7:13"> 你身所生的，地所產的，牲畜所下的，以及牛犢、羊羔，都必蒙福。</span>
<span className="v" id="v5" data-v="5"> 你的筐子和你的摶麵盆都必蒙福。</span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 121:8; 民數記 27:17; 歷代志下 1:10"> 你出也蒙福，入也蒙福。</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳記下 22:38–41; 利未記 26:7–8; 詩篇 89:23"> 「仇敵起來攻擊你，耶和華必使他們在你面前被你殺敗；他們從一條路來攻擊你，必從七條路逃跑。</span>
<span className="v" id="v8" data-v="8" data-xref="申命記 15:10; 利未記 26:10; 箴言 3:9–10"> 在你倉房裏，並你手所辦的一切事上，耶和華所命的福必臨到你。耶和華－你上帝也要在所給你的地上賜福與你。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及記 19:5–6; 申命記 7:6; 申命記 26:18–19"> 你若謹守耶和華－你上帝的誡命，遵行他的道，他必照着向你所起的誓立你作為自己的聖民。</span>
<span className="v" id="v10" data-v="10" data-xref="歷代志下 7:14; 申命記 11:25; 耶利米書 33:9"> 天下萬民見你歸在耶和華的名下，就要懼怕你。</span>
<span className="v" id="v11" data-v="11" data-xref="申命記 30:9; 箴言 10:22; 利未記 26:9"> 你在耶和華向你列祖起誓應許賜你的地上，他必使你身所生的，牲畜所下的，地所產的，都綽綽有餘。</span>
<span className="v" id="v12" data-v="12" data-xref="申命記 15:6; 約珥書 2:23–24; 申命記 15:10"> 耶和華必為你開天上的府庫，按時降雨在你的地上。在你手裏所辦的一切事上賜福與你。你必借給許多國民，卻不致向他們借貸。</span>
<span className="v" id="v13" data-v="13" data-xref="申命記 28:1; 申命記 4:6–9; 腓立比書 1:27"> 你若聽從耶和華－你上帝的誡命，就是我今日所吩咐你的，謹守遵行，不偏左右，也不隨從事奉別神，耶和華就必使你作首不作尾，但居上不居下。」</span>
</div>
</div>

## 悖逆的後果

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="瑪拉基書 2:2; 申命記 28:2; 申命記 29:20"> 「你若不聽從耶和華－你上帝的話，不謹守遵行他的一切誡命律例，就是我今日所吩咐你的，這以下的咒詛都必追隨你，臨到你身上：</span>
<span className="v" id="v16" data-v="16" data-xref="瑪拉基書 3:9–12; 箴言 3:33; 約珥書 1:4"> 你在城裏必受咒詛，在田間也必受咒詛。</span>
<span className="v" id="v17" data-v="17" data-xref="哈該書 1:6; 申命記 28:5; 詩篇 69:22"> 你的筐子和你的摶麵盆都必受咒詛。</span>
<span className="v" id="v18" data-v="18" data-xref="利未記 26:26; 利未記 26:19–20; 約伯記 18:16–19"> 你身所生的，地所產的，以及牛犢、羊羔，都必受咒詛。</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 28:6; 士師記 5:6–7; 歷代志下 15:5"> 你出也受咒詛，入也受咒詛。</span>
<span className="v" id="v20" data-v="20" data-xref="以賽亞書 66:15; 瑪拉基書 2:2; 申命記 4:26"> 耶和華因你行惡離棄他，必在你手裏所辦的一切事上，使咒詛、擾亂、責罰臨到你，直到你被毀滅，速速地滅亡。</span>
<span className="v" id="v21" data-v="21" data-xref="利未記 26:25; 耶利米書 24:10; 耶利米書 16:4"> 耶和華必使瘟疫貼在你身上，直到他將你從所進去得為業的地上滅絕。</span>
<span className="v" id="v22" data-v="22" data-xref="阿摩司書 4:9; 利未記 26:16; 哈該書 2:17"> 耶和華要用癆病、熱病、火症、瘧疾、刀劍、旱風<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或譯：乾旱">a</a></sup>、霉爛攻擊你。這都要追趕你，直到你滅亡。</span>
<span className="v" id="v23" data-v="23" data-xref="利未記 26:19; 耶利米書 14:1–6; 列王紀上 18:2"> 你頭上的天要變為銅，腳下的地要變為鐵。</span>
<span className="v" id="v24" data-v="24" data-xref="申命記 28:12; 以賽亞書 5:24; 阿摩司書 4:11"> 耶和華要使那降在你地上的雨變為塵沙，從天臨在你身上，直到你滅亡。</span>
<span className="v" id="v25" data-v="25" data-xref="以賽亞書 30:17; 以西結書 23:46; 耶利米書 24:9"> 「耶和華必使你敗在仇敵面前，你從一條路去攻擊他們，必從七條路逃跑。你必在天下萬國中拋來拋去。</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米書 34:20; 耶利米書 16:4; 耶利米書 7:33"> 你的屍首必給空中的飛鳥和地上的走獸作食物，並無人鬨趕。</span>
<span className="v" id="v27" data-v="27" data-xref="撒母耳記上 5:6; 申命記 28:35; 利未記 21:20"> 耶和華必用埃及人的瘡並痔瘡、牛皮癬與疥攻擊你，使你不能醫治。</span>
<span className="v" id="v28" data-v="28" data-xref="帖撒羅尼迦後書 2:9–11; 以賽亞書 19:11–17; 以賽亞書 6:9–10"> 耶和華必用癲狂、眼瞎、心驚攻擊你。</span>
<span className="v" id="v29" data-v="29" data-xref="以賽亞書 59:10; 約伯記 5:14; 士師記 6:1–6"> 你必在午間摸索，好像瞎子在暗中摸索一樣。你所行的必不亨通，時常遭遇欺壓、搶奪，無人搭救。</span>
<span className="v" id="v30" data-v="30" data-xref="阿摩司書 5:11; 耶利米書 8:10; 約伯記 31:10"> 你聘定了妻，別人必與她同房；你建造房屋，不得住在其內；你栽種葡萄園，也不得用其中的果子。</span>
<span className="v" id="v31" data-v="31" data-xref="約伯記 1:14–15; 士師記 6:1"> 你的牛在你眼前宰了，你必不得吃牠的肉；你的驢在你眼前被搶奪，不得歸還；你的羊歸了仇敵，無人搭救。</span>
<span className="v" id="v32" data-v="32" data-xref="約珥書 3:6; 申命記 28:41; 約伯記 17:5"> 你的兒女必歸與別國的民；你的眼目終日切望，甚至失明，你手中無力拯救。</span>
<span className="v" id="v33" data-v="33" data-xref="耶利米書 5:17; 申命記 28:29–30; 以賽亞書 1:7"> 你的土產和你勞碌得來的，必被你所不認識的國民吃盡。你時常被欺負，受壓制，</span>
<span className="v" id="v34" data-v="34" data-xref="啟示錄 16:10–11; 申命記 28:68; 以賽亞書 33:14"> 甚至你因眼中所看見的，必致瘋狂。</span>
<span className="v" id="v35" data-v="35" data-xref="申命記 28:27; 以賽亞書 3:24; 以賽亞書 3:17"> 耶和華必攻擊你，使你膝上腿上，從腳掌到頭頂，長毒瘡無法醫治。</span>
<span className="v" id="v36" data-v="36" data-xref="耶利米書 16:13; 申命記 4:28; 列王紀下 25:11"> 「耶和華必將你和你所立的王領到你和你列祖素不認識的國去；在那裏你必事奉木頭石頭的神。</span>
<span className="v" id="v37" data-v="37" data-xref="耶利米書 25:9; 列王紀上 9:7–8; 耶利米書 24:9"> 你在耶和華領你到的各國中，要令人驚駭、笑談、譏誚。</span>
<span className="v" id="v38" data-v="38" data-xref="哈該書 1:6; 彌迦書 6:15; 約珥書 1:4"> 你帶到田間的種子雖多，收進來的卻少，因為被蝗蟲吃了。</span>
<span className="v" id="v39" data-v="39" data-xref="以賽亞書 17:10–11; 約珥書 2:2–4; 約拿書 4:7"> 你栽種、修理葡萄園，卻不得收葡萄，也不得喝葡萄酒，因為被蟲子吃了。</span>
<span className="v" id="v40" data-v="40" data-xref="彌迦書 6:15; 詩篇 23:5; 詩篇 104:15"> 你全境有橄欖樹，卻不得其油抹身，因為樹上的橄欖不熟自落了。</span>
<span className="v" id="v41" data-v="41" data-xref="申命記 28:32; 耶利米哀歌 1:5; 列王紀下 24:14"> 你生兒養女，卻不算是你的，因為必被擄去。</span>
<span className="v" id="v42" data-v="42" data-xref="阿摩司書 7:1–2; 申命記 28:38–39"> 你所有的樹木和你地裏的出產必被蝗蟲所吃。</span>
<span className="v" id="v43" data-v="43" data-xref="申命記 28:13; 撒母耳記上 13:19–23; 列王紀下 17:20"> 在你中間寄居的，必漸漸上升，比你高而又高；你必漸漸下降，低而又低。</span>
<span className="v" id="v44" data-v="44" data-xref="申命記 28:12–13; 耶利米哀歌 1:5"> 他必借給你，你卻不能借給他；他必作首，你必作尾。</span>
<span className="v" id="v45" data-v="45" data-xref="申命記 28:15; 以賽亞書 1:20; 耶利米書 24:9–10"> 這一切咒詛必追隨你，趕上你，直到你滅亡；因為你不聽從耶和華－你上帝的話，不遵守他所吩咐的誡命律例。</span>
<span className="v" id="v46" data-v="46" data-xref="以賽亞書 8:18; 申命記 28:37; 以西結書 14:8"> 這些咒詛必在你和你後裔的身上成為異蹟奇事，直到永遠！</span>
<span className="v" id="v47" data-v="47" data-xref="申命記 16:11; 申命記 12:7–12; 尼希米記 9:35–37"> 「因為你富有的時候，不歡心樂意地事奉耶和華－你的上帝，</span>
<span className="v" id="v48" data-v="48" data-xref="耶利米書 28:13–14; 耶利米哀歌 5:2–6; 以西結書 4:16–17"> 所以你必在飢餓、乾渴、赤露、缺乏之中事奉耶和華所打發來攻擊你的仇敵。他必把鐵軛加在你的頸項上，直到將你滅絕。</span>
<span className="v" id="v49" data-v="49" data-xref="耶利米哀歌 4:19; 耶利米書 49:22; 耶利米書 48:40"> 「耶和華要從遠方、地極帶一國的民，如鷹飛來攻擊你。這民的言語，你不懂得。</span>
<span className="v" id="v50" data-v="50" data-xref="以賽亞書 47:6; 歷代志下 36:17; 路加福音 21:23–24"> 這民的面貌凶惡，不顧恤年老的，也不恩待年少的。</span>
<span className="v" id="v51" data-v="51" data-xref="申命記 28:33; 以賽亞書 62:8; 利未記 26:26"> 他們必吃你牲畜所下的和你地土所產的，直到你滅亡。你的五穀、新酒，和油，以及牛犢、羊羔，都不給你留下，直到將你滅絕。</span>
<span className="v" id="v52" data-v="52" data-xref="耶利米書 52:4–7; 以西結書 4:1–8; 馬太福音 24:15–16"> 他們必將你困在你各城裏，直到你所倚靠、高大堅固的城牆都被攻塌。他們必將你困在耶和華－你上帝所賜你遍地的各城裏。</span>
<span className="v" id="v53" data-v="53" data-xref="耶利米哀歌 4:10; 耶利米書 19:9; 利未記 26:29"> 你在仇敵圍困窘迫之中，必吃你本身所生的，就是耶和華－你上帝所賜給你的兒女之肉。</span>
<span className="v" id="v54" data-v="54" data-xref="申命記 15:9; 馬太福音 20:15; 申命記 13:6"> 你們中間，柔弱嬌嫩的人必惡眼看他弟兄和他懷中的妻，並他餘剩的兒女；</span>
<span className="v" id="v55" data-v="55" data-xref="耶利米書 34:2; 耶利米書 52:6; 耶利米書 5:10"> 甚至在你受仇敵圍困窘迫的城中，他要吃兒女的肉，不肯分一點給他的親人，因為他一無所剩。</span>
<span className="v" id="v56" data-v="56" data-xref="申命記 28:54; 以賽亞書 3:16; 耶利米哀歌 4:3–6"> 你們中間，柔弱嬌嫩的婦人，是因嬌嫩柔弱不肯把腳踏地的，必惡眼看她懷中的丈夫和她的兒女。</span>
<span className="v" id="v57" data-v="57" data-xref="以賽亞書 49:15; 創世記 49:10"> 她兩腿中間出來的嬰孩與她所要生的兒女，她因缺乏一切就要在你受仇敵圍困窘迫的城中將他們暗暗地吃了。</span>
<span className="v" id="v58" data-v="58" data-xref="以賽亞書 42:8; 耶利米書 7:9–10; 瑪拉基書 1:14"> 「這書上所寫律法的一切話是叫你敬畏耶和華－你上帝可榮可畏的名。你若不謹守遵行，耶和華就必將奇災，就是至大至長的災，至重至久的病，加在你和你後裔的身上，</span>
<span className="v" id="v60" data-v="60" data-xref="申命記 7:15; 出埃及記 15:26; 申命記 28:27"> 也必使你所懼怕、埃及人的病都臨到你，貼在你身上，</span>
<span className="v" id="v61" data-v="61" data-xref="申命記 4:25–26"> 又必將沒有寫在這律法書上的各樣疾病、災殃降在你身上，直到你滅亡。</span>
<span className="v" id="v62" data-v="62" data-xref="申命記 10:22; 尼希米記 9:23; 申命記 4:27"> 你們先前雖然像天上的星那樣多，卻因不聽從耶和華－你上帝的話，所剩的人數就稀少了。</span>
<span className="v" id="v63" data-v="63" data-xref="箴言 1:26; 耶利米書 32:41; 申命記 30:9"> 先前耶和華怎樣喜悅善待你們，使你們眾多，也要照樣喜悅毀滅你們，使你們滅亡；並且你們從所要進去得的地上必被拔除。</span>
<span className="v" id="v64" data-v="64" data-xref="申命記 4:27–28; 利未記 26:33; 耶利米書 16:13"> 耶和華必使你們分散在萬民中，從地這邊到地那邊，你必在那裏事奉你和你列祖素不認識、木頭石頭的神。</span>
<span className="v" id="v65" data-v="65" data-xref="利未記 26:36; 羅馬書 11:10; 阿摩司書 9:4"> 在那些國中，你必不得安逸，也不得落腳之地；耶和華卻使你在那裏心中跳動，眼目失明，精神消耗。</span>
<span className="v" id="v66" data-v="66" data-xref="耶利米哀歌 1:13; 希伯來書 10:27; 啟示錄 6:15–17"> 你的性命必懸懸無定；你晝夜恐懼，自料性命難保。</span>
<span className="v" id="v67" data-v="67" data-xref="申命記 28:34; 約伯記 7:3–4; 啟示錄 9:6"> 你因心裏所恐懼的，眼中所看見的，早晨必說，巴不得到晚上才好；晚上必說，巴不得到早晨才好。</span>
<span className="v" id="v68" data-v="68" data-xref="耶利米書 44:12; 耶利米書 43:7; 何西阿書 8:13"> 耶和華必使你坐船回埃及去，走我曾告訴你不得再見的路；在那裏你必賣己身與仇敵作奴婢，卻無人買。」</span>

## 在摩押跟以色列人立約

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命記 5:2–3; 希伯來書 8:9; 出埃及記 24:2–8"> 這是耶和華在摩押地吩咐摩西與以色列人立約的話，是在他和他們於何烈山所立的約之外。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 19:4; 出埃及記 8:12; 約書亞記 24:5–6"> 摩西召了以色列眾人來，對他們說：「耶和華在埃及地，在你們眼前向法老和他眾臣僕，並他全地所行的一切事，你們都看見了，</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 4:32–35; 尼希米記 9:9–11; 申命記 7:18–19"> 就是你親眼看見的大試驗和神蹟，並那些大奇事。</span>
<span className="v" id="v4" data-v="4" data-xref="以弗所書 4:18; 以賽亞書 6:9–10; 箴言 20:12"> 但耶和華到今日沒有使你們心能明白，眼能看見，耳能聽見。</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 8:4; 尼希米記 9:21; 申命記 8:2"> 我領你們在曠野四十年，你們身上的衣服並沒有穿破，腳上的鞋也沒有穿壞。</span>
<span className="v" id="v6" data-v="6" data-xref="申命記 8:3; 以弗所書 5:18; 哥林多前書 9:25"> 你們沒有吃餅，也沒有喝清酒濃酒。這要使你們知道，耶和華是你們的上帝。</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 2:24–17; 民數記 32:33–42; 詩篇 135:10–12"> 你們來到這地方，希實本王西宏、巴珊王噩都出來與我們交戰，我們就擊殺了他們，</span>
<span className="v" id="v8" data-v="8" data-xref="申命記 3:12–13; 民數記 32:33"> 取了他們的地給呂便支派、迦得支派，和瑪拿西半支派為業。</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀上 2:3; 申命記 4:6; 路加福音 11:28"> 所以你們要謹守遵行這約的話，好叫你們在一切所行的事上亨通。</span>
<span className="v" id="v10" data-v="10" data-xref="約珥書 2:16–17; 啟示錄 20:12; 申命記 31:12–13"> 「今日，你們的首領、族長<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="-11 原文是支派">a</a></sup>、長老、官長、以色列的男丁，你們的妻子兒女，和營中寄居的，以及為你們劈柴挑水的人，都站在耶和華－你們的上帝面前，</span>
<span className="v" id="v12" data-v="12" data-xref="歷代志下 15:12–15; 列王紀下 11:17; 申命記 5:2–3"> 為要你順從耶和華－你上帝今日與你所立的約，向你所起的誓。</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及記 6:7; 創世記 17:7; 申命記 28:9"> 這樣，他要照他向你所應許的話，又向你列祖亞伯拉罕、以撒、雅各所起的誓，今日立你作他的子民，他作你的上帝。</span>
<span className="v" id="v14" data-v="14" data-xref="耶利米書 31:31–34; 希伯來書 8:7–12"> 我不但與你們立這約，起這誓，</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行傳 2:39; 哥林多前書 7:14; 耶利米書 50:5"> 凡與我們一同站在耶和華－我們上帝面前的，並今日不在我們這裏的人，我也與他們立這約，起這誓。</span>
<span className="v" id="v16" data-v="16" data-xref="申命記 2:19; 申命記 2:9; 申命記 2:4"> 「我們曾住過埃及地，也從列國經過；這是你們知道的。</span>
<span className="v" id="v17" data-v="17" data-xref="申命記 28:36"> 你們也看見他們中間可憎之物，並他們木、石、金、銀的偶像。</span>
<span className="v" id="v18" data-v="18" data-xref="希伯來書 12:15; 申命記 11:16–17; 申命記 13:1–15"> 惟恐你們中間，或男或女，或族長或支派長，今日心裏偏離耶和華－我們的上帝，去事奉那些國的神；又怕你們中間有惡根生出苦菜和茵蔯來，</span>
<span className="v" id="v19" data-v="19" data-xref="耶利米書 7:24; 民數記 15:30; 民數記 15:39"> 聽見這咒詛的話，心裏仍是自誇說：『我雖然行事心裏頑梗，連累眾人，卻還是平安。』</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 74:1; 詩篇 79:5; 申命記 9:14"> 耶和華必不饒恕他；耶和華的怒氣與憤恨要向他發作，如煙冒出，將這書上所寫的一切咒詛都加在他身上。耶和華又要從天下塗抹他的名，</span>
<span className="v" id="v21" data-v="21" data-xref="馬太福音 25:41; 約書亞記 7:1–26; 以西結書 13:9"> 也必照着寫在律法書上、約中的一切咒詛將他從以色列眾支派中分別出來，使他受禍。</span>
<span className="v" id="v22" data-v="22" data-xref="耶利米書 19:8"> 你們的後代，就是以後興起來的子孫，和遠方來的外人，看見這地的災殃，並耶和華所降與這地的疾病，</span>
<span className="v" id="v23" data-v="23" data-xref="西番雅書 2:9; 耶利米書 17:6; 以賽亞書 34:9"> 又看見遍地有硫磺，有鹽鹵，有火跡，沒有耕種，沒有出產，連草都不生長－好像耶和華在忿怒中所傾覆的所多瑪、蛾摩拉、押瑪、洗扁一樣－</span>
<span className="v" id="v24" data-v="24" data-xref="耶利米書 22:8–9; 列王紀上 9:8–9; 羅馬書 2:5"> 所看見的人，連萬國人，都必問說：『耶和華為何向此地這樣行呢？這樣大發烈怒是甚麼意思呢？』</span>
<span className="v" id="v25" data-v="25" data-xref="希伯來書 8:9; 以賽亞書 47:6; 耶利米書 50:7"> 人必回答說：『是因這地的人離棄了耶和華－他們列祖的上帝，領他們出埃及地的時候與他們所立的約，</span>
<span className="v" id="v26" data-v="26" data-xref="申命記 28:64; 士師記 2:12–13; 士師記 5:8"> 去事奉敬拜素不認識的別神，是耶和華所未曾給他們安排的。</span>
<span className="v" id="v27" data-v="27" data-xref="但以理書 9:11–14; 申命記 28:15–68; 申命記 27:15–26"> 所以耶和華的怒氣向這地發作，將這書上所寫的一切咒詛都降在這地上。</span>
<span className="v" id="v28" data-v="28" data-xref="歷代志下 7:20; 列王紀上 14:15; 詩篇 52:5"> 耶和華在怒氣、忿怒、大惱恨中將他們從本地拔出來，扔在別的地上，像今日一樣。』</span>
<span className="v" id="v29" data-v="29" data-xref="但以理書 2:22; 使徒行傳 1:7; 羅馬書 11:33–34"> 「隱祕的事是屬耶和華－我們上帝的；惟有明顯的事是永遠屬我們和我們子孫的，好叫我們遵行這律法上的一切話。」</span>

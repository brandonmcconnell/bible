## 安息年

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命記 31:10; 出埃及記 23:10–11; 利未記 25:2–4"> 「每逢七年末一年，你要施行豁免。</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 7:42; 雅各書 2:13; 路加福音 6:34–38"> 豁免的定例乃是這樣：凡債主要把所借給鄰舍的豁免了；不可向鄰舍和弟兄追討，因為耶和華的豁免年已經宣告了。</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 23:20; 馬太福音 17:25–26; 哥林多前書 6:6–7"> 若借給外邦人，你可以向他追討；但借給你弟兄，無論是甚麼，你要鬆手豁免了。</span>
<span className="v" id="v4" data-v="4" data-xref="以賽亞書 58:10–11; 箴言 28:27; 箴言 11:24–25"> 你若留意聽從耶和華－你上帝的話，謹守遵行我今日所吩咐你這一切的命令，就必在你們中間沒有窮人了（在耶和華－你上帝所賜你為業的地上，耶和華必大大賜福與你。）</span>
<span className="v" id="v6" data-v="6" data-xref="申命記 28:12–13; 路加福音 6:35; 尼希米記 9:27"> 因為耶和華－你的上帝必照他所應許你的賜福與你。你必借給許多國民，卻不致向他們借貸；你必管轄許多國民，他們卻不能管轄你。</span>
<span className="v" id="v7" data-v="7" data-xref="約翰一書 3:16–17; 申命記 15:9; 箴言 21:13"> 「在耶和華－你上帝所賜你的地上，無論哪一座城裏，你弟兄中若有一個窮人，你不可忍着心、揝着手不幫補你窮乏的弟兄。</span>
<span className="v" id="v8" data-v="8" data-xref="路加福音 6:34; 馬太福音 5:42"> 總要向他鬆開手，照他所缺乏的借給他，補他的不足。</span>
<span className="v" id="v9" data-v="9" data-xref="申命記 24:15; 馬太福音 20:15; 耶利米書 17:10"> 你要謹慎，不可心裏起惡念，說：『第七年的豁免年快到了』，你便惡眼看你窮乏的弟兄，甚麼都不給他，以致他因你求告耶和華，罪便歸於你了。</span>
<span className="v" id="v10" data-v="10" data-xref="箴言 22:9; 希伯來書 13:16; 以賽亞書 58:10"> 你總要給他，給他的時候心裏不可愁煩；因耶和華－你的上帝必在你這一切所行的，並你手裏所辦的事上，賜福與你。</span>
<span className="v" id="v11" data-v="11" data-xref="馬可福音 14:7; 馬太福音 26:11; 約翰福音 12:8"> 原來那地上的窮人永不斷絕；所以我吩咐你說：『總要向你地上困苦窮乏的弟兄鬆開手。』」</span>
</div>
</div>

## 對待奴婢的條例

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="耶利米書 34:14; 利未記 25:39–41; 出埃及記 21:2–6"> 「你弟兄中，若有一個希伯來男人或希伯來女人被賣給你，服事你六年，到第七年就要任他自由出去。</span>
<span className="v" id="v13" data-v="13" data-xref="瑪拉基書 3:5; 耶利米書 22:13; 箴言 3:27–28"> 你任他自由的時候，不可使他空手而去，</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多前書 16:2; 箴言 10:22; 詩篇 68:10"> 要從你羊群、禾場、酒醡之中多多地給他；耶和華－你的上帝怎樣賜福與你，你也要照樣給他。</span>
<span className="v" id="v15" data-v="15" data-xref="申命記 16:12; 馬太福音 18:32–33; 申命記 5:14–15"> 要記念你在埃及地作過奴僕，耶和華－你的上帝將你救贖；因此，我今日吩咐你這件事。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 21:5–6; 詩篇 40:8; 詩篇 40:6"> 他若對你說：『我不願意離開你』，是因他愛你和你的家，且因在你那裏很好，</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳記上 1:22; 利未記 25:39–42"> 你就要拿錐子將他的耳朵在門上刺透，他便永為你的奴僕了。你待婢女也要這樣。</span>
<span className="v" id="v18" data-v="18" data-xref="路加福音 17:7–8; 以賽亞書 16:14; 以賽亞書 21:16"> 你任他自由的時候，不可以為難事，因他服事你六年，較比雇工的工價多加一倍了。耶和華－你的上帝就必在你所做的一切事上賜福與你。」</span>
</div>
</div>

## 頭生牛羊的條例

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="出埃及記 13:2; 出埃及記 13:12; 利未記 27:26"> 「你牛群羊群中頭生的，凡是公的，都要分別為聖，歸耶和華－你的上帝。牛群中頭生的，不可用牠耕地；羊群中頭生的，不可剪毛。</span>
<span className="v" id="v20" data-v="20" data-xref="申命記 12:17; 申命記 14:23; 申命記 12:5–7"> 這頭生的，你和你的家屬，每年要在耶和華所選擇的地方，在耶和華－你上帝面前吃。</span>
<span className="v" id="v21" data-v="21" data-xref="申命記 17:1; 瑪拉基書 1:7–8; 利未記 22:19–25"> 這頭生的若有甚麼殘疾，就如瘸腿的、瞎眼的，無論有甚麼惡殘疾，都不可獻給耶和華－你的上帝；</span>
<span className="v" id="v22" data-v="22" data-xref="申命記 12:21–22; 申命記 12:15–16"> 可以在你城裏吃；潔淨人與不潔淨人都可以吃，就如吃羚羊與鹿一般。</span>
<span className="v" id="v23" data-v="23" data-xref="申命記 12:16; 利未記 7:26; 申命記 12:23"> 只是不可吃牠的血；要倒在地上，如同倒水一樣。」</span>
</div>

## 主再來的應許

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="提摩太後書 1:6; 彼得後書 1:12–15; 彼得前書 1:22"> 親愛的弟兄啊，我現在寫給你們的是第二封信。這兩封都是提醒你們，激發你們誠實的心，</span>
<span className="v" id="v2" data-v="2" data-xref="猶大書 1:17; 彼得後書 2:21; 路加福音 1:70"> 叫你們記念聖先知預先所說的話和主救主的命令，就是使徒所傳給你們的。</span>
<span className="v" id="v3" data-v="3" data-xref="猶大書 1:18; 提摩太前書 4:1–2; 彼得後書 2:10"> 第一要緊的，該知道在末世必有好譏誚的人隨從自己的私慾出來譏誚說：</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米書 17:15; 瑪拉基書 2:17; 耶利米書 5:12–13"> 「主要降臨的應許在哪裏呢？因為從列祖睡了以來，萬物與起初創造的時候仍是一樣。」</span>
<span className="v" id="v5" data-v="5" data-xref="希伯來書 11:3; 創世記 1:9; 詩篇 24:2"> 他們故意忘記，從太古，憑上帝的命有了天，並從水而出、藉水而成的地。</span>
<span className="v" id="v6" data-v="6" data-xref="馬太福音 24:38–39; 彼得後書 2:5; 路加福音 17:27"> 故此，當時的世界被水淹沒就消滅了。</span>
<span className="v" id="v7" data-v="7" data-xref="彼得後書 3:10; 以賽亞書 51:6; 彼得後書 3:12"> 但現在的天地還是憑着那命存留，直留到不敬虔之人受審判遭沉淪的日子，用火焚燒。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="詩篇 90:4; 羅馬書 11:25; 哥林多前書 12:1"> 親愛的弟兄啊，有一件事你們不可忘記，就是主看一日如千年，千年如一日。</span>
<span className="v" id="v9" data-v="9" data-xref="提摩太前書 2:4; 羅馬書 2:4; 哈巴谷書 2:3"> 主所應許的尚未成就，有人以為他是耽延，其實不是耽延，乃是寬容你們，不願有一人沉淪，乃願人人都悔改。</span>
<span className="v" id="v10" data-v="10" data-xref="啟示錄 21:1; 馬太福音 24:35; 彼得後書 3:7"> 但主的日子要像賊來到一樣。那日，天必大有響聲廢去，有形質的都要被烈火銷化，地和其上的物都要燒盡了。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="彼得前書 1:15; 腓立比書 1:27; 彼得前書 2:12"> 這一切既然都要如此銷化，你們為人該當怎樣聖潔，怎樣敬虔，</span>
<span className="v" id="v12" data-v="12" data-xref="彼得後書 3:10; 以賽亞書 34:4; 彌迦書 1:4"> 切切仰望上帝的日子來到。在那日，天被火燒就銷化了，有形質的都要被烈火鎔化。</span>
<span className="v" id="v13" data-v="13" data-xref="以賽亞書 65:17; 啟示錄 21:1; 以賽亞書 66:22"> 但我們照他的應許，盼望新天新地，有義居在其中。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="帖撒羅尼迦前書 5:23; 帖撒羅尼迦前書 3:13; 腓立比書 1:10"> 親愛的弟兄啊，你們既盼望這些事，就當殷勤，使自己沒有玷污，無可指摘，安然見主；</span>
<span className="v" id="v15" data-v="15" data-xref="羅馬書 2:4; 彼得後書 3:9; 提摩太前書 1:16"> 並且要以我主長久忍耐為得救的因由，就如我們所親愛的兄弟保羅，照着所賜給他的智慧寫了信給你們。</span>
<span className="v" id="v16" data-v="16" data-xref="馬太福音 15:6; 希伯來書 5:11; 雅各書 1:8"> 他一切的信上也都是講論這事。信中有些難明白的，那無學問、不堅固的人強解，如強解別的經書一樣，就自取沉淪。</span>
<span className="v" id="v17" data-v="17" data-xref="希伯來書 3:14; 歌羅西書 2:8; 哥林多後書 11:13–15"> 親愛的弟兄啊，你們既然預先知道這事，就當防備，恐怕被惡人的錯謬誘惑，就從自己堅固的地步上墜落。</span>
<span className="v" id="v18" data-v="18" data-xref="歌羅西書 1:10; 以弗所書 4:15; 彼得前書 2:2"> 你們卻要在我們主－救主耶穌基督的恩典和知識上有長進。願榮耀歸給他，從今直到永遠。阿們！</span>
</div>
</div>

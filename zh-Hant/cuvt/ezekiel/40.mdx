## 新聖殿的異象


## 以西結被帶到耶路撒冷

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西結書 33:21; 以西結書 1:2–3; 以西結書 3:14"> 我們被擄掠第二十五年，耶路撒冷城攻破後十四年，正在年初，月之初十日，耶和華的靈<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是手">a</a></sup>降在我身上，他把我帶到以色列地。</span>
<span className="v" id="v2" data-v="2" data-xref="以西結書 1:1; 但以理書 7:1; 但以理書 7:7"> 在上帝的異象中帶我到以色列地，安置在至高的山上；在山上的南邊有彷彿一座城建立。</span>
<span className="v" id="v3" data-v="3" data-xref="以西結書 47:3; 啟示錄 11:1; 但以理書 10:5–6"> 他帶我到那裏，見有一人，顏色<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原文是形狀">b</a></sup>如銅，手拿麻繩和量度的竿，站在門口。</span>
<span className="v" id="v4" data-v="4" data-xref="以西結書 44:5; 馬太福音 10:27; 以西結書 2:7–8"> 那人對我說：「人子啊，凡我所指示你的，你都要用眼看，用耳聽，並要放在心上。我帶你到這裏來，特為要指示你；凡你所見的，你都要告訴以色列家。」</span>
</div>
</div>

## 東門

<div className="bt">
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="以西結書 42:20; 以賽亞書 26:1; 啟示錄 21:12"> 我見殿四圍有牆。那人手拿量度的竿，長六肘，每肘是一肘零一掌。他用竿量牆，厚一竿，高一竿。</span>
<span className="v" id="v6" data-v="6" data-xref="以西結書 43:1; 以西結書 8:16; 以西結書 11:1"> 他到了朝東的門，就上門的臺階，量門的這檻，寬一竿；又量門的那檻，寬一竿。</span>
<span className="v" id="v7" data-v="7" data-xref="以西結書 40:36; 以西結書 40:33; 歷代志上 23:28"> 又有衛房，每房長一竿，寬一竿，相隔五肘。門檻，就是挨着向殿的廊門檻，寬一竿。</span>
<span className="v" id="v8" data-v="8"> 他又量向殿門的廊子，寬一竿。</span>
<span className="v" id="v9" data-v="9" data-xref="以西結書 45:19"> 又量門廊，寬八肘，牆柱厚二肘；那門的廊子向着殿。</span>
<span className="v" id="v10" data-v="10"> 東門洞有衛房：這旁三間，那旁三間，都是一樣的尺寸；這邊的柱子和那邊的柱子，也是一樣的尺寸。</span>
<span className="v" id="v11" data-v="11"> 他量門口，寬十肘，長十三肘。</span>
<span className="v" id="v12" data-v="12"> 衛房前展出的境界：這邊一肘，那邊一肘；衛房這邊六肘，那邊六肘。</span>
<span className="v" id="v13" data-v="13"> 又量門洞，從這衛房頂的後檐到那衛房頂的後檐，寬二十五肘；衛房門與門相對。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及記 27:9; 以賽亞書 62:9; 以西結書 42:1"> 又量<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="原文是造">c</a></sup>廊子六十肘<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="七十士譯本是二十肘">d</a></sup>，牆柱外是院子，有廊為界，在門洞兩邊。</span>
<span className="v" id="v15" data-v="15"> 從大門口到內廊前，共五十肘。</span>
<span className="v" id="v16" data-v="16" data-xref="歷代志下 3:5; 列王紀上 6:4; 以西結書 41:26"> 衛房和門洞兩旁柱間並廊子，都有嚴緊的窗櫺；裏邊都有窗櫺，柱上有雕刻的棕樹。</span>
</div>
</div>

## 外院

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="啟示錄 11:2; 以西結書 42:1; 歷代志上 23:28"> 他帶我到外院，見院的四圍有鋪石地；鋪石地上有屋子三十間。</span>
<span className="v" id="v18" data-v="18"> 鋪石地，就是矮鋪石地在各門洞兩旁，以門洞的長短為度。</span>
<span className="v" id="v19" data-v="19" data-xref="以西結書 40:23; 以西結書 40:27; 以西結書 46:1–2"> 他從下門量到內院外，共寬一百肘，東面北面都是如此。</span>
</div>
</div>

## 北門

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="以西結書 40:6"> 他量外院朝北的門，長寬若干。</span>
<span className="v" id="v21" data-v="21" data-xref="以西結書 40:29–30; 以西結書 40:25–26; 以西結書 40:10–16"> 門洞的衛房，這旁三間，那旁三間。門洞的柱子和廊子，與第一門的尺寸一樣。門洞長五十肘，寬二十五肘。</span>
<span className="v" id="v22" data-v="22" data-xref="以西結書 40:31; 以西結書 40:37; 以西結書 40:6"> 其窗櫺和廊子，並雕刻的棕樹，與朝東的門尺寸一樣。登七層臺階上到這門，前面有廊子。</span>
<span className="v" id="v23" data-v="23" data-xref="以西結書 40:19; 以西結書 40:27–28; 出埃及記 38:9–12"> 內院有門與這門相對，北面東面都是如此。他從這門量到那門，共一百肘。</span>
</div>
</div>

## 南門

<div className="bt">
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="以西結書 46:9; 以西結書 40:6; 以西結書 40:20–21"> 他帶我往南去，見朝南有門，又照先前的尺寸量門洞的柱子和廊子。</span>
<span className="v" id="v25" data-v="25" data-xref="以西結書 40:33; 以西結書 40:16; 以西結書 40:21–22"> 門洞兩旁與廊子的周圍都有窗櫺，和先量的窗櫺一樣。門洞長五十肘，寬二十五肘。</span>
<span className="v" id="v26" data-v="26" data-xref="以西結書 40:22; 以西結書 40:16; 以西結書 40:6"> 登七層臺階上到這門，前面有廊子；柱上有雕刻的棕樹，這邊一棵，那邊一棵。</span>
<span className="v" id="v27" data-v="27" data-xref="以西結書 40:23; 以西結書 40:32; 以西結書 40:19"> 內院朝南有門。從這門量到朝南的那門，共一百肘。</span>
</div>
</div>

## 內院的南門

<div className="bt">
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="以西結書 40:35; 以西結書 40:32"> 他帶我從南門到內院，就照先前的尺寸量南門。</span>
<span className="v" id="v29" data-v="29" data-xref="以西結書 40:25; 以西結書 40:16; 以西結書 40:7"> 衛房和柱子，並廊子都照先前的尺寸。門洞兩旁與廊子的周圍都有窗櫺。門洞長五十肘，寬二十五肘。</span>
<span className="v" id="v30" data-v="30" data-xref="以西結書 40:21; 以西結書 40:36; 以西結書 40:25"> 周圍有廊子，長二十五肘，寬五肘。</span>
<span className="v" id="v31" data-v="31" data-xref="以西結書 40:26; 以西結書 40:34; 以西結書 40:22"> 廊子朝着外院，柱上有雕刻的棕樹。登八層臺階上到這門。</span>
</div>
</div>

<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="以西結書 40:35; 以西結書 40:28–31"> 他帶我到內院的東面，就照先前的尺寸量東門。</span>
<span className="v" id="v33" data-v="33" data-xref="以西結書 40:21; 以西結書 40:36; 以西結書 40:25"> 衛房和柱子，並廊子都照先前的尺寸。門洞兩旁與廊子的周圍都有窗櫺。門洞長五十肘，寬二十五肘。</span>
<span className="v" id="v34" data-v="34" data-xref="以西結書 40:22; 以西結書 40:31; 以西結書 40:37"> 廊子朝着外院。門洞兩旁的柱子都有雕刻的棕樹。登八層臺階上到這門。</span>
</div>
</div>

## 內院的北門

<div className="bt">
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="以西結書 47:2; 以西結書 40:32; 以西結書 44:4"> 他帶我到北門，就照先前的尺寸量那門，</span>
<span className="v" id="v36" data-v="36" data-xref="以西結書 40:29; 以西結書 40:21; 以西結書 40:16"> 就是量衛房和柱子，並廊子。門洞周圍都有窗櫺；門洞長五十肘，寬二十五肘。</span>
<span className="v" id="v37" data-v="37" data-xref="以西結書 40:34; 以西結書 40:31"> 廊柱朝着外院。門洞兩旁的柱子都有雕刻的棕樹。登八層臺階上到這門。</span>
</div>
</div>

## 廂房

<div className="bt">
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="歷代志下 4:6; 以西結書 40:17; 利未記 8:21"> 門洞的柱旁有屋子和門；祭司<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="原文是他們">e</a></sup>在那裏洗燔祭牲。</span>
<span className="v" id="v39" data-v="39" data-xref="以西結書 46:2; 利未記 1:3–17; 利未記 4:2–3"> 在門廊內，這邊有兩張桌子，那邊有兩張桌子，在其上可以宰殺燔祭牲、贖罪祭牲，和贖愆祭牲。</span>
<span className="v" id="v40" data-v="40"> 上到朝北的門口，這邊有兩張桌子，門廊那邊也有兩張桌子。</span>
<span className="v" id="v41" data-v="41" data-xref="以西結書 40:39–40"> 門這邊有四張桌子，那邊有四張桌子，共八張；在其上祭司宰殺犧牲。</span>
<span className="v" id="v42" data-v="42" data-xref="以西結書 40:39; 出埃及記 20:25"> 為燔祭牲有四張桌子，是鑿過的石頭做成的，長一肘半，寬一肘半，高一肘。祭司將宰殺燔祭牲和平安祭牲所用的器皿放在其上。</span>
<span className="v" id="v43" data-v="43" data-xref="利未記 1:8; 利未記 1:6; 利未記 8:20"> 有鉤子，寬一掌，釘在廊內的四圍。桌子上有犧牲的肉。</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="歷代志上 6:31–32; 歷代志上 16:41–43; 以西結書 40:27"> 在北門旁，內院裏有屋子，為歌唱的人而設。這屋子朝南；在南<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="南：原文是東">f</a></sup>門旁，又有一間朝北。</span>
<span className="v" id="v45" data-v="45" data-xref="歷代志上 9:23; 詩篇 134:1; 利未記 8:35"> 他對我說：「這朝南的屋子是為看守殿宇的祭司；</span>
<span className="v" id="v46" data-v="46" data-xref="以西結書 44:15; 以西結書 43:19; 列王紀上 2:35"> 那朝北的屋子是為看守祭壇的祭司。這些祭司是利未人中撒督的子孫，近前來事奉耶和華的。」</span>
</div>
</div>

## 內院和聖殿

<div className="bt">
<div className="bp">
<span className="v" id="v47" data-v="47" data-xref="以西結書 40:19; 以西結書 40:23; 以西結書 40:27"> 他又量內院，長一百肘，寬一百肘，是見方的。祭壇在殿前。</span>
<span className="v" id="v48" data-v="48" data-xref="歷代志下 3:4; 列王紀上 6:3"> 於是他帶我到殿前的廊子，量廊子的牆柱。這面厚五肘，那面厚五肘。門兩旁，這邊三肘，那邊三肘。</span>
<span className="v" id="v49" data-v="49" data-xref="列王紀上 7:15–21; 以西結書 40:34; 歷代志下 3:17"> 廊子長二十肘，寬十一肘。上廊子有臺階。靠近牆柱又有柱子，這邊一根，那邊一根。</span>
</div>

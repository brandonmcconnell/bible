## 上帝斥責拜偶像的罪

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西結書 8:1; 以西結書 20:1; 列王紀下 6:32"> 有幾個以色列長老到我這裏來，坐在我面前。</span>
<span className="v" id="v2" data-v="2" data-xref="阿摩司書 3:7; 列王紀上 14:4"> 耶和華的話就臨到我說：</span>
<span className="v" id="v3" data-v="3" data-xref="以西結書 14:7; 以西結書 7:19; 以西結書 20:3"> 「人子啊，這些人已將他們的假神接到心裏，把陷於罪的絆腳石放在面前，我豈能絲毫被他們求問嗎？</span>
<span className="v" id="v4" data-v="4" data-xref="以賽亞書 66:4; 以西結書 14:7; 以賽亞書 3:11"> 所以你要告訴他們：『主耶和華如此說：以色列家的人中，凡將他的假神接到心裏，把陷於罪的絆腳石放在面前，又就了先知來的，我－耶和華在他所求的事上，必按他眾多的假神回答他<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或譯：必按他拜許多假神的罪報應他">a</a></sup>，</span>
<span className="v" id="v5" data-v="5" data-xref="以賽亞書 1:4; 撒迦利亞書 11:8; 羅馬書 1:28"> 好在以色列家的心事上捉住他們，因為他們都藉着假神與我生疏。』</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="以西結書 18:30; 以賽亞書 30:22; 以西結書 36:31–32"> 「所以你要告訴以色列家說：『主耶和華如此說：回頭吧！離開你們的偶像，轉臉莫從你們一切可憎的事。』</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及記 12:48; 以賽亞書 58:1–2; 利未記 24:22"> 因為以色列家的人，或在以色列中寄居的外人，凡與我隔絕，將他的假神接到心裏，把陷於罪的絆腳石放在面前，又就了先知來要為自己的事求問我的，我－耶和華必親自回答他。</span>
<span className="v" id="v8" data-v="8" data-xref="以西結書 15:7; 耶利米書 44:11; 以西結書 5:15"> 我必向那人變臉，使他作了警戒，笑談，令人驚駭，並且我要將他從我民中剪除；你們就知道我是耶和華。</span>
<span className="v" id="v9" data-v="9" data-xref="以西結書 20:25; 耶利米書 4:10; 詩篇 81:11–12"> 先知若被迷惑說一句預言，是我－耶和華任那先知受迷惑，我也必向他伸手，將他從我民以色列中除滅。</span>
<span className="v" id="v10" data-v="10" data-xref="以西結書 23:49; 以西結書 14:4; 耶利米書 8:11–12"> 他們必擔當自己的罪孽。先知的罪孽和求問之人的罪孽都是一樣，</span>
<span className="v" id="v11" data-v="11" data-xref="以西結書 37:23; 以西結書 44:10; 啟示錄 21:7"> 好使以色列家不再走迷離開我，不再因各樣的罪過玷污自己，只要作我的子民，我作他們的上帝。這是主耶和華說的。」</span>
</div>
</div>

## 挪亞、但以理、約伯

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12"> 耶和華的話臨到我說：</span>
<span className="v" id="v13" data-v="13" data-xref="利未記 26:26; 以西結書 4:16; 以賽亞書 24:20"> 「人子啊，若有一國犯罪干犯我，我也向他伸手折斷他們的杖，就是斷絕他們的糧，使饑荒臨到那地，將人與牲畜從其中剪除；</span>
<span className="v" id="v14" data-v="14" data-xref="以西結書 14:20; 耶利米書 15:1; 以西結書 28:3"> 其中雖有挪亞、但以理、約伯這三人，他們只能因他們的義救自己的性命。這是主耶和華說的。</span>
<span className="v" id="v15" data-v="15" data-xref="以西結書 5:17; 利未記 26:22; 耶利米書 15:3"> 我若使惡獸經過糟踐那地，使地荒涼，以致因這些獸，人都不得經過；</span>
<span className="v" id="v16" data-v="16" data-xref="創世記 19:29; 雅各書 5:16; 以西結書 33:11"> 雖有這三人在其中，主耶和華說：我指着我的永生起誓，他們連兒帶女都不能得救，只能自己得救，那地仍然荒涼。</span>
<span className="v" id="v17" data-v="17" data-xref="利未記 26:25; 以西結書 21:3–4; 西番雅書 1:3"> 或者我使刀劍臨到那地，說：刀劍哪，要經過那地，以致我將人與牲畜從其中剪除；</span>
<span className="v" id="v18" data-v="18"> 雖有這三人在其中，主耶和華說：我指着我的永生起誓，他們連兒帶女都不能得救，只能自己得救。</span>
<span className="v" id="v19" data-v="19" data-xref="以西結書 38:22; 以西結書 5:12; 耶利米書 14:12"> 或者我叫瘟疫流行那地，使我滅命<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原文是帶血">b</a></sup>的忿怒傾在其上，好將人與牲畜從其中剪除；</span>
<span className="v" id="v20" data-v="20" data-xref="以西結書 14:14; 約翰一書 2:29; 以賽亞書 3:10"> 雖有挪亞、但以理、約伯在其中，主耶和華說：我指着我的永生起誓，他們連兒帶女都不能救，只能因他們的義救自己的性命。」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="以西結書 33:27; 以西結書 5:17; 以西結書 14:13"> 主耶和華如此說：「我將這四樣大災－就是刀劍、饑荒、惡獸、瘟疫降在耶路撒冷，將人與牲畜從其中剪除，豈不更重嗎？</span>
<span className="v" id="v22" data-v="22" data-xref="以西結書 12:16; 以西結書 20:43; 希伯來書 12:6–11"> 然而其中必有剩下的人，他們連兒帶女必帶到你們這裏來，你們看見他們所行所為的，要因我降給耶路撒冷的一切災禍，便得了安慰。</span>
<span className="v" id="v23" data-v="23" data-xref="耶利米書 22:8–9; 啟示錄 15:4; 申命記 8:2"> 你們看見他們所行所為的，得了安慰，就知道我在耶路撒冷中所行的並非無故。這是主耶和華說的。」</span>
</div>
</div>

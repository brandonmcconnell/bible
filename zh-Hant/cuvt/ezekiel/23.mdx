## 兩個犯罪的姊妹

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華的話又臨到我說：</span>
<span className="v" id="v2" data-v="2" data-xref="以西結書 16:44–46; 耶利米書 3:7–10"> 「人子啊，有兩個女子，是一母所生，</span>
<span className="v" id="v3" data-v="3" data-xref="利未記 17:7; 以西結書 16:22; 約書亞記 24:14"> 她們在埃及行邪淫，在幼年時行邪淫。她們在那裏作處女的時候，有人擁抱她們的懷，撫摸她們的乳。</span>
<span className="v" id="v4" data-v="4" data-xref="以西結書 16:8; 詩篇 76:2; 耶利米書 2:2–3"> 她們的名字，姊姊名叫阿荷拉，妹妹名叫阿荷利巴。她們都歸於我，生了兒女。論到她們的名字，阿荷拉就是撒馬利亞，阿荷利巴就是耶路撒冷。</span>
<span className="v" id="v5" data-v="5" data-xref="何西阿書 5:13; 列王紀下 17:3; 列王紀下 16:7"> 「阿荷拉歸我之後行邪淫，貪戀所愛的人，就是她的鄰邦亞述人。</span>
<span className="v" id="v6" data-v="6" data-xref="以西結書 23:23"> 這些人都穿藍衣，作省長、副省長，都騎着馬，是可愛的少年人。</span>
<span className="v" id="v7" data-v="7" data-xref="何西阿書 5:3; 何西阿書 6:10; 以西結書 22:3–4"> 阿荷拉就與亞述人中最美的男子放縱淫行，她因所戀愛之人的一切偶像，玷污自己。</span>
<span className="v" id="v8" data-v="8" data-xref="以西結書 23:19; 以西結書 23:3; 出埃及記 32:4"> 自從在埃及的時候，她就沒有離開淫亂，因為她年幼作處女的時候，埃及人與她行淫，撫摸她的乳，縱慾與她行淫。</span>
<span className="v" id="v9" data-v="9" data-xref="何西阿書 11:5; 列王紀下 15:29; 列王紀下 17:23"> 因此，我將她交在她所愛的人手中，就是她所戀愛的亞述人手中。</span>
<span className="v" id="v10" data-v="10" data-xref="以西結書 23:29; 何西阿書 2:10; 耶利米書 22:8–9"> 他們就露了她的下體，擄掠她的兒女，用刀殺了她，使她在婦女中留下臭名，因他們向她施行審判。</span>
<span className="v" id="v11" data-v="11" data-xref="耶利米書 3:8–11; 以西結書 16:47–51; 以西結書 23:4"> 「她妹妹阿荷利巴雖然看見了，卻還貪戀，比她姊姊更醜；行淫亂比她姊姊更多。</span>
<span className="v" id="v12" data-v="12" data-xref="列王紀下 16:7–15; 以西結書 23:23; 歷代志下 28:16–23"> 她貪戀鄰邦的亞述人，就是穿極華美的衣服，騎着馬的省長、副省長，都是可愛的少年人。</span>
<span className="v" id="v13" data-v="13" data-xref="何西阿書 12:1–2; 列王紀下 17:18–19; 以西結書 23:31"> 我看見她被玷污了，她姊妹二人同行一路。</span>
<span className="v" id="v14" data-v="14" data-xref="以西結書 8:10; 耶利米書 22:14; 耶利米書 50:2"> 阿荷利巴又加增淫行，因她看見人像畫在牆上，就是用丹色所畫迦勒底人的像，</span>
<span className="v" id="v15" data-v="15" data-xref="士師記 8:18; 撒母耳記上 18:4; 以賽亞書 22:21"> 腰間繫着帶子，頭上有下垂的裹頭巾，都是軍長的形狀，仿照巴比倫人的形像；他們的故土就是迦勒底。</span>
<span className="v" id="v16" data-v="16" data-xref="以西結書 16:29; 馬太福音 5:28; 約伯記 31:1"> 阿荷利巴一看見就貪戀他們，打發使者往迦勒底去見他們。</span>
<span className="v" id="v17" data-v="17" data-xref="以西結書 23:28; 以西結書 23:22; 創世記 10:10"> 巴比倫人就來登她愛情的床，與她行淫玷污她。她被玷污，隨後心裏與他們生疏。</span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 78:59; 詩篇 106:40; 耶利米書 12:8"> 這樣，她顯露淫行，又顯露下體；我心就與她生疏，像先前與她姊姊生疏一樣。</span>
<span className="v" id="v19" data-v="19" data-xref="以西結書 23:3; 以西結書 20:7; 以西結書 16:51"> 她還加增她的淫行，追念她幼年在埃及地行邪淫的日子，</span>
<span className="v" id="v20" data-v="20" data-xref="以西結書 17:15; 以西結書 16:26; 耶利米書 5:8"> 貪戀情人身壯精足，如驢如馬。</span>
<span className="v" id="v21" data-v="21"> 這樣，你就想起你幼年的淫行。那時，埃及人擁抱你的懷，撫摸你的乳。」</span>
</div>
</div>

## 上帝審判妹妹

<div className="bt">
<div className="bp poetry">
<span className="v" id="v22" data-v="22" data-xref="以西結書 16:37; 啟示錄 17:16; 耶利米書 6:22–23"> 阿荷利巴啊，主耶和華如此說：「我必激動你先愛而後生疏的人來攻擊你。我必使他們來，在你四圍攻擊你。</span>
<span className="v" id="v23" data-v="23" data-xref="耶利米書 50:21; 列王紀下 24:2; 列王紀下 20:14–17"> 所來的就是巴比倫人、迦勒底的眾人、比割人、書亞人、哥亞人，同着他們的還有亞述眾人，乃是作省長、副省長、作軍長有名聲的，都騎着馬，是可愛的少年人。</span>
<span className="v" id="v24" data-v="24" data-xref="撒母耳記下 24:14; 以西結書 26:10; 以西結書 23:45"> 他們必帶兵器、戰車、輜重車，率領大眾來攻擊你。他們要拿大小盾牌，頂盔擺陣，在你四圍攻擊你。我要將審判的事交給他們，他們必按着自己的條例審判你。</span>
<span className="v" id="v25" data-v="25" data-xref="以西結書 23:47; 以西結書 8:1–18; 以西結書 15:6–7"> 我必以忌恨攻擊你；他們必以忿怒辦你。他們必割去你的鼻子和耳朵；你遺留<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或譯：餘剩；下同">a</a></sup>的人必倒在刀下。他們必擄去你的兒女；你所遺留的必被火焚燒。</span>
<span className="v" id="v26" data-v="26" data-xref="以西結書 16:39; 耶利米書 13:22; 以西結書 23:29"> 他們必剝去你的衣服，奪取你華美的寶器。</span>
<span className="v" id="v27" data-v="27" data-xref="以西結書 16:41; 以西結書 23:3; 以西結書 23:19"> 這樣，我必使你的淫行和你從埃及地染來的淫亂止息了，使你不再仰望亞述，也不再追念埃及。</span>
<span className="v" id="v28" data-v="28" data-xref="以西結書 23:22; 以西結書 23:17; 耶利米書 34:20"> 主耶和華如此說：我必將你交在你所恨惡的人手中，就是你心與他生疏的人手中。</span>
<span className="v" id="v29" data-v="29" data-xref="以西結書 16:39; 以西結書 23:25–26; 以西結書 23:45–47"> 他們必以恨惡辦你，奪取你一切勞碌得來的，留下你赤身露體。你淫亂的下體，連你的淫行，帶你的淫亂，都被顯露。</span>
<span className="v" id="v30" data-v="30" data-xref="以西結書 6:9; 詩篇 106:35–38; 耶利米書 2:18–20"> 人必向你行這些事；因為你隨從外邦人行邪淫，被他們的偶像玷污了。</span>
<span className="v" id="v31" data-v="31" data-xref="列王紀下 21:13; 耶利米書 7:14–15; 以西結書 16:47–51"> 你走了你姊姊所走的路，所以我必將她的杯交在你手中。」</span>
<span className="v" id="v32" data-v="32" data-xref="以賽亞書 51:17; 詩篇 60:3; 以西結書 22:4–5"> <span className="pl pl-1">主耶和華如此說：</span><br /><span className="pl pl-1">你必喝你姊姊所喝的杯；</span><br /><span className="pl pl-1">那杯又深又廣，盛得甚多，</span><br /><span className="pl pl-1">使你被人嗤笑譏刺。</span><br /></span>
<span className="v" id="v33" data-v="33" data-xref="以賽亞書 51:17; 耶利米書 25:27; 耶利米書 25:15–16"> <span className="pl pl-1">你必酩酊大醉，滿有愁苦，</span><br /><span className="pl pl-1">喝乾你姊姊撒馬利亞的杯，</span><br /><span className="pl pl-1">就是令人驚駭淒涼的杯。</span><br /></span>
<span className="v" id="v34" data-v="34" data-xref="詩篇 75:8; 以賽亞書 51:17; 啟示錄 18:7"> <span className="pl pl-1">你必喝這杯，以致喝盡。</span><br /><span className="pl pl-1">杯破又齦杯片，</span><br /><span className="pl pl-1">撕裂自己的乳；</span><br /><span className="pl pl-1">因為這事我曾說過。</span><br /><span className="pl pl-1">這是主耶和華說的。</span></span>
<span className="v" id="v35" data-v="35" data-xref="列王紀上 14:9; 以賽亞書 17:10; 耶利米書 32:33"> 主耶和華如此說：「因你忘記我，將我丟在背後，所以你要擔當你淫行和淫亂的報應。」</span>
</div>
</div>

## 上帝審判兩姊妹

<div className="bt">
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="以西結書 22:2; 以賽亞書 58:1; 以西結書 16:2"> 耶和華又對我說：「人子啊，你要審問阿荷拉與阿荷利巴嗎？當指出她們所行可憎的事。</span>
<span className="v" id="v37" data-v="37" data-xref="以西結書 16:36; 耶利米書 32:35; 耶利米書 7:31"> 她們行淫，手中有殺人的血，又與偶像行淫，並使她們為我所生的兒女經火燒給偶像。</span>
<span className="v" id="v38" data-v="38" data-xref="以西結書 20:13; 列王紀下 21:7; 以西結書 7:20"> 此外，她們還有向我所行的，就是同日玷污我的聖所，干犯我的安息日。</span>
<span className="v" id="v39" data-v="39" data-xref="列王紀下 21:4; 以西結書 44:7; 耶利米書 23:11"> 她們殺了兒女獻與偶像，當天又入我的聖所，將聖所褻瀆了。她們在我殿中所行的乃是如此。</span>
<span className="v" id="v40" data-v="40" data-xref="列王紀下 9:30; 耶利米書 4:30; 以西結書 16:13–16"> 「況且你們二婦打發使者去請遠方人。使者到他們那裏，他們就來了。你們為他們沐浴己身，粉飾眼目，佩戴妝飾，</span>
<span className="v" id="v41" data-v="41" data-xref="以斯帖記 1:6; 耶利米書 44:17; 以賽亞書 65:11"> 坐在華美的床上，前面擺設桌案，將我的香料膏油擺在其上。</span>
<span className="v" id="v42" data-v="42" data-xref="以西結書 16:11–12; 啟示錄 12:3; 出埃及記 32:18–19"> 在那裏有群眾安逸歡樂的聲音，並有粗俗的人和酒徒從曠野同來，把鐲子戴在二婦的手上，把華冠戴在她們的頭上。</span>
<span className="v" id="v43" data-v="43" data-xref="以西結書 23:3; 耶利米書 13:23; 以斯拉記 9:7"> 「我論這行淫衰老的婦人說：現在人還要與她行淫，她也要與人行淫。</span>
<span className="v" id="v44" data-v="44" data-xref="以西結書 23:9–13; 以西結書 23:3"> 人與阿荷拉，並阿荷利巴二淫婦苟合，好像與妓女苟合。</span>
<span className="v" id="v45" data-v="45" data-xref="何西阿書 6:5; 利未記 20:10; 以西結書 23:36–39"> 必有義人，照審判淫婦和流人血的婦人之例，審判她們；因為她們是淫婦，手中有殺人的血。」</span>
<span className="v" id="v46" data-v="46" data-xref="以西結書 16:40; 耶利米書 15:4; 耶利米書 24:9"> 主耶和華如此說：「我必使多人來攻擊她們，使她們拋來拋去，被人搶奪。</span>
<span className="v" id="v47" data-v="47" data-xref="以西結書 16:40–41; 耶利米書 39:8; 以西結書 24:21"> 這些人必用石頭打死她們，用刀劍殺害她們，又殺戮她們的兒女，用火焚燒她們的房屋。</span>
<span className="v" id="v48" data-v="48" data-xref="以西結書 6:6; 以西結書 23:27; 以西結書 16:41"> 這樣，我必使淫行從境內止息，好叫一切婦人都受警戒，不效法你們的淫行。</span>
<span className="v" id="v49" data-v="49" data-xref="以西結書 9:10; 以西結書 7:4; 以西結書 6:7"> 人必照着你們的淫行報應你們；你們要擔當拜偶像的罪，就知道我是主耶和華。」</span>

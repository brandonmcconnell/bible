<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="以西結書 27:2; 以西結書 26:17; 列王紀下 24:6"> 你當為以色列的王作起哀歌，</span>
<span className="v" id="v2" data-v="2" data-xref="撒迦利亞書 11:3; 以賽亞書 5:29; 約伯記 4:11"> 說：<br /><span className="pl pl-1">你的母親是甚麼呢？</span><br /><span className="pl pl-1">是個母獅子，蹲伏在獅子中間，</span><br /><span className="pl pl-1">在少壯獅子中養育小獅子。</span><br /></span>

<span className="v" id="v6" data-v="6" data-xref="歷代志下 36:5; 歷代志下 36:9; 耶利米書 26:1–24"> <span className="pl pl-1">牠在眾獅子中走來走去，</span><br /><span className="pl pl-1">成了少壯獅子，</span><br /><span className="pl pl-1">學會抓食而吃人。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="以西結書 30:12; 以西結書 12:19; 彌迦書 1:2"> <span className="pl pl-1">牠知道列國的宮殿，</span><br /><span className="pl pl-1">又使他們的城邑變為荒場；</span><br /><span className="pl pl-1">因牠咆哮的聲音，</span><br /><span className="pl pl-1">遍地和其中所有的就都荒廢。</span><br /></span>

<span className="v" id="v9" data-v="9" data-xref="歷代志下 36:6; 以西結書 6:2; 耶利米書 36:30–31"> <span className="pl pl-1">他們用鉤子鉤住牠，將牠放在籠中，</span><br /><span className="pl pl-1">帶到巴比倫王那裏，</span><br /><span className="pl pl-1">將牠放入堅固之所，</span><br /><span className="pl pl-1">使牠的聲音在以色列山上不再聽見。</span></span>

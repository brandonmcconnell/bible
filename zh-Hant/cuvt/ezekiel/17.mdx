## 老鷹和葡萄樹的比喻

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華的話臨到我說：</span>
<span className="v" id="v2" data-v="2" data-xref="以西結書 20:49; 馬太福音 13:35; 哥林多前書 13:12"> 「人子啊，你要向以色列家出謎語，設比喻，</span>
<span className="v" id="v3" data-v="3" data-xref="何西阿書 8:1; 耶利米書 48:40; 以西結書 17:7"> 說主耶和華如此說：有一大鷹，翅膀大，翎毛長，羽毛豐滿，彩色俱備，來到黎巴嫩，將香柏樹梢擰去，</span>
<span className="v" id="v4" data-v="4" data-xref="以賽亞書 43:14; 以賽亞書 47:15; 啟示錄 18:11–19"> 就是折去香柏樹儘尖的嫩枝，叼到貿易之地，放在買賣城中；</span>
<span className="v" id="v5" data-v="5" data-xref="以賽亞書 44:4; 申命記 8:7–9; 耶利米書 37:1"> 又將以色列地的枝子栽於肥田裏，插在大水旁，如插柳樹，</span>
<span className="v" id="v6" data-v="6" data-xref="以西結書 17:14; 箴言 16:18–19"> 就漸漸生長，成為蔓延矮小的葡萄樹。其枝轉向那鷹，其根在鷹以下，於是成了葡萄樹，生出枝子，發出小枝。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="以西結書 31:4; 以西結書 17:15; 列王紀下 24:20"> 「又有一大鷹，翅膀大，羽毛多。這葡萄樹從栽種的畦中向這鷹彎過根來，發出枝子，好得它的澆灌。</span>
<span className="v" id="v8" data-v="8" data-xref="以西結書 17:5–6"> 這樹栽於肥田多水的旁邊，好生枝子，結果子，成為佳美的葡萄樹。</span>
<span className="v" id="v9" data-v="9" data-xref="以西結書 17:10; 耶利米書 32:5; 以賽亞書 30:1–7"> 你要說，主耶和華如此說：這葡萄樹豈能發旺呢？鷹豈不拔出它的根來，芟除它的果子，使它枯乾，使它發的嫩葉都枯乾了嗎？也不用大力和多民，就拔出它的根來。</span>
<span className="v" id="v10" data-v="10" data-xref="何西阿書 13:15; 約翰福音 15:6; 馬太福音 21:19"> 葡萄樹雖然栽種，豈能發旺呢？一經東風，豈不全然枯乾嗎？必在生長的畦中枯乾了。」</span>
</div>
</div>

## 解釋比喻

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11"> 耶和華的話臨到我說：</span>
<span className="v" id="v12" data-v="12" data-xref="以西結書 24:19; 以西結書 17:3; 以西結書 1:2"> 「你對那悖逆之家說：你們不知道這些事是甚麼意思嗎？你要告訴他們說，巴比倫王曾到耶路撒冷，將其中的君王和首領帶到巴比倫自己那裏去。</span>
<span className="v" id="v13" data-v="13" data-xref="歷代志下 36:13; 列王紀下 24:15–17; 以西結書 17:5"> 從以色列的宗室中取一人與他立約，使他發誓，並將國中有勢力的人擄去，</span>
<span className="v" id="v14" data-v="14" data-xref="以西結書 29:14; 申命記 28:43; 撒母耳記上 2:30"> 使國低微不能自強，惟因守盟約得以存立。</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米書 52:3; 耶利米書 38:18; 以西結書 17:7"> 他卻背叛巴比倫王，打發使者往埃及去，要他們給他馬匹和多民。他豈能亨通呢？行這樣事的人豈能逃脫呢？他背約豈能逃脫呢？</span>
<span className="v" id="v16" data-v="16" data-xref="以西結書 12:13; 耶利米書 52:11; 以西結書 17:18–19"> 他輕看向王所起的誓，背棄王與他所立的約。主耶和華說：我指着我的永生起誓，他定要死在立他作王、巴比倫王的京都。</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米書 37:7; 以西結書 4:2; 以西結書 29:6–7"> 敵人築壘造臺，與他打仗的時候，為要剪除多人，法老雖領大軍隊和大群眾，還是不能幫助他。</span>
<span className="v" id="v18" data-v="18" data-xref="歷代志上 29:24; 歷代志下 30:8; 耶利米哀歌 5:6"> 他輕看誓言，背棄盟約，已經投降，卻又做這一切的事，他必不能逃脫。」</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 5:11; 耶利米書 5:9; 耶利米書 5:2"> 所以主耶和華如此說：「我指着我的永生起誓，他既輕看指我所起的誓，背棄指我所立的約，我必要使這罪歸在他頭上。</span>
<span className="v" id="v20" data-v="20" data-xref="以西結書 12:13; 以西結書 32:3; 耶利米書 2:35"> 我必將我的網撒在他身上，他必在我的網羅中纏住。我必帶他到巴比倫，並要在那裏因他干犯我的罪刑罰他。</span>
<span className="v" id="v21" data-v="21" data-xref="列王紀下 25:5; 列王紀下 25:11; 以西結書 12:14"> 他的一切軍隊，凡逃跑的，都必倒在刀下；所剩下的，也必分散四方<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="方：原文是風">a</a></sup>。你們就知道說這話的是我－耶和華。」</span>
</div>
</div>

## 上帝對將來的應許

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="以賽亞書 53:2; 撒迦利亞書 6:12–13; 以賽亞書 11:1–5"> 主耶和華如此說：「我要將香柏樹梢擰去栽上，就是從儘尖的嫩枝中折一嫩枝，栽於極高的山上；</span>
<span className="v" id="v23" data-v="23" data-xref="馬太福音 13:32; 以西結書 31:6; 以賽亞書 2:2"> 在以色列高處的山栽上。它就生枝子，結果子，成為佳美的香柏樹，各類飛鳥都必宿在其下，就是宿在枝子的蔭下。</span>
<span className="v" id="v24" data-v="24" data-xref="阿摩司書 9:11; 哥林多前書 1:27–28; 以西結書 24:14"> 田野的樹木都必知道我－耶和華使高樹矮小，矮樹高大；青樹枯乾，枯樹發旺。我－耶和華如此說，也如此行了。」</span>
</div>

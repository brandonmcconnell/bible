## 以西結剃髮

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以賽亞書 7:20; 以西結書 44:20; 利未記 21:5"> 「人子啊，你要拿一把快刀，當作剃頭刀，用這刀剃你的頭髮和你的鬍鬚，用天平將鬚髮平分。</span>
<span className="v" id="v2" data-v="2" data-xref="以西結書 5:12; 利未記 26:33; 以西結書 4:1–8"> 圍困城的日子滿了，你要將三分之一在城中用火焚燒，將三分之一在城的四圍用刀砍碎，將三分之一任風吹散；我也要拔刀追趕。</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米書 52:16; 耶利米書 40:6; 耶利米書 39:10"> 你要從其中取幾根包在衣襟裏，</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米書 4:4; 耶利米書 41:1–18; 列王紀下 25:25"> 再從這幾根中取些扔在火中焚燒，從裏面必有火出來燒入以色列全家。</span>
<span className="v" id="v5" data-v="5" data-xref="以西結書 4:1; 申命記 4:6; 耶利米書 6:6"> 主耶和華如此說：這就是耶路撒冷。我曾將她安置在列邦之中；列國都在她的四圍。</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米書 11:10; 以西結書 16:47–48; 尼希米記 9:16–17"> 她行惡，違背我的典章，過於列國；干犯我的律例，過於四圍的列邦，因為她棄掉我的典章。至於我的律例，她並沒有遵行。</span>
<span className="v" id="v7" data-v="7" data-xref="耶利米書 2:10–11; 歷代志下 33:9; 列王紀下 21:9–11"> 所以主耶和華如此說：因為你們紛爭過於四圍的列國，也不遵行我的律例，不謹守我的典章，並以遵從四圍列國的惡規尚不滿意，</span>
<span className="v" id="v8" data-v="8" data-xref="以西結書 15:7; 耶利米書 24:9; 以西結書 21:3"> 所以主耶和華如此說：看哪，我與你反對，必在列國的眼前，在你中間，施行審判；</span>
<span className="v" id="v9" data-v="9" data-xref="馬太福音 24:21; 但以理書 9:12; 阿摩司書 3:2"> 並且因你一切可憎的事，我要在你中間行我所未曾行的，以後我也不再照着行。</span>
<span className="v" id="v10" data-v="10" data-xref="撒迦利亞書 2:6; 申命記 28:64; 以西結書 12:14"> 在你中間父親要吃兒子，兒子要吃父親。我必向你施行審判，我必將你所剩下的分散四方<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="方：原文是風">a</a></sup>。」</span>
<span className="v" id="v11" data-v="11" data-xref="以西結書 7:20; 以西結書 7:9; 以西結書 11:18"> 主耶和華說：「我指着我的永生起誓，因你用一切可憎的物、可厭的事玷污了我的聖所，故此，我定要使你人數減少，我眼必不顧惜你，也不可憐你。</span>
<span className="v" id="v12" data-v="12" data-xref="以西結書 5:2; 耶利米書 15:2; 耶利米書 43:10–11"> 你的民三分之一必遭瘟疫而死，在你中間必因饑荒消滅；三分之一必在你四圍倒在刀下；我必將三分之一分散四方<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="方：原文是風">b</a></sup>，並要拔刀追趕他們。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="以賽亞書 1:24; 以西結書 36:5–6; 以西結書 21:17"> 「我要這樣成就怒中所定的；我向他們發的忿怒止息了，自己就得着安慰。我在他們身上成就怒中所定的那時，他們就知道我－耶和華所說的是出於熱心；</span>
<span className="v" id="v14" data-v="14" data-xref="以西結書 22:4; 尼希米記 2:17; 詩篇 79:1–4"> 並且我必使你在四圍的列國中，在經過的眾人眼前，成了荒涼和羞辱。</span>
<span className="v" id="v15" data-v="15" data-xref="以西結書 25:17; 耶利米書 22:8–9; 列王紀上 9:7"> 這樣，我必以怒氣和忿怒，並烈怒的責備，向你施行審判。那時，你就在四圍的列國中成為羞辱、譏刺、警戒、驚駭。這是我－耶和華說的。</span>
<span className="v" id="v16" data-v="16" data-xref="以西結書 4:16; 申命記 32:23–24; 以西結書 14:13"> 那時，我要將滅人、使人饑荒的惡箭，就是射去滅人的，射在你們身上，並要加增你們的饑荒，斷絕你們所倚靠的糧食；</span>
<span className="v" id="v17" data-v="17" data-xref="以西結書 38:22; 以西結書 14:21; 利未記 26:22"> 又要使饑荒和惡獸到你那裏，叫你喪子，瘟疫和流血的事也必盛行在你那裏；我也要使刀劍臨到你。這是我－耶和華說的。」</span>
</div>

## 生銹的鍋

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="以西結書 8:1; 以西結書 20:1; 以西結書 29:17"> 第九年十月初十日，耶和華的話又臨到我說：</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米書 39:1; 耶利米書 52:4; 列王紀下 25:1"> 「人子啊，今日正是巴比倫王就近耶路撒冷的日子，你要將這日記下，</span>
<span className="v" id="v3" data-v="3" data-xref="以西結書 11:3; 以西結書 17:2; 以西結書 20:49"> 要向這悖逆之家設比喻說，主耶和華如此說：<br /><span className="pl pl-1">將鍋放在火上，</span><br /><span className="pl pl-1">放好了，就倒水在其中；</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="彌迦書 3:2–3; 以西結書 22:18–22; 馬太福音 7:2"> <span className="pl pl-1">將肉塊，就是一切肥美的肉塊、腿，</span><br /><span className="pl pl-1">和肩都聚在其中，</span><br /><span className="pl pl-1">拿美好的骨頭把鍋裝滿；</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="耶利米書 52:24–27; 耶利米書 52:10; 耶利米書 39:6"> <span className="pl pl-1">取羊群中最好的，</span><br /><span className="pl pl-1">將柴堆在鍋下，</span><br /><span className="pl pl-1">使鍋開滾，</span><br /><span className="pl pl-1">好把骨頭煮在其中。</span></span>
<span className="v" id="v6" data-v="6" data-xref="以西結書 22:2; 那鴻書 3:1; 俄巴底亞書 1:11"> 「主耶和華如此說：禍哉！這流人血的城，就是長銹的鍋。其中的銹未曾除掉，須要將肉塊從其中一一取出來，不必為它拈鬮。</span>
<span className="v" id="v7" data-v="7" data-xref="利未記 17:13; 申命記 12:16; 約伯記 16:18"> 城中所流的血倒在淨光的磐石上，不倒在地上，用土掩蓋。</span>
<span className="v" id="v8" data-v="8" data-xref="申命記 32:21–22; 啟示錄 18:5–10; 以西結書 22:30–31"> 這城中所流的血倒在淨光的磐石上，不得掩蓋，乃是出於我，為要發忿怒施行報應。</span>
<span className="v" id="v9" data-v="9" data-xref="以西結書 24:6; 哈巴谷書 2:12; 以賽亞書 31:9"> 所以主耶和華如此說：禍哉！這流人血的城，我也必大堆火柴，</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米哀歌 2:16; 耶利米書 17:3; 耶利米哀歌 1:10"> 添上木柴，使火着旺，將肉煮爛，把湯熬濃，使骨頭烤焦；</span>
<span className="v" id="v11" data-v="11" data-xref="耶利米書 21:10; 瑪拉基書 4:1; 以賽亞書 1:25"> 把鍋倒空坐在炭火上，使鍋燒熱，使銅燒紅，鎔化其中的污穢，除淨其上的銹。</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米書 9:5; 耶利米書 2:13; 耶利米書 5:3"> 這鍋勞碌疲乏，所長的大銹仍未除掉；這銹就是用火也不能除掉。</span>
<span className="v" id="v13" data-v="13" data-xref="以西結書 22:24; 以西結書 5:13; 西番雅書 3:2"> 在你污穢中有淫行，我潔淨你，你卻不潔淨。你的污穢再不能潔淨，直等我向你發的忿怒止息。</span>
<span className="v" id="v14" data-v="14" data-xref="馬太福音 16:27; 以西結書 18:30; 以賽亞書 3:11"> 我－耶和華說過的必定成就，必照話而行，必不返回，必不顧惜，也不後悔。人必照你的舉動行為審判你。這是主耶和華說的。」</span>
</div>

## 先知妻子的死

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15"> 耶和華的話又臨到我說：</span>
<span className="v" id="v16" data-v="16" data-xref="耶利米書 22:10; 耶利米書 13:17; 雅歌 7:10"> 「人子啊，我要將你眼目所喜愛的忽然取去，你卻不可悲哀哭泣，也不可流淚，</span>
<span className="v" id="v17" data-v="17" data-xref="何西阿書 9:4; 撒母耳記下 15:30; 利未記 10:6"> 只可歎息，不可出聲，不可辦理喪事；頭上仍勒裹頭巾，腳上仍穿鞋，不可蒙着嘴唇，也不可吃弔喪的食物。」</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前書 7:29–30"> 於是我將這事早晨告訴百姓，晚上我的妻就死了。次日早晨我便遵命而行。</span>
<span className="v" id="v19" data-v="19" data-xref="以西結書 12:9; 以西結書 37:18; 瑪拉基書 3:7–8"> 百姓問我說：「你這樣行與我們有甚麼關係，你不告訴我們嗎？」</span>
<span className="v" id="v20" data-v="20"> 我回答他們：「耶和華的話臨到我說：</span>
<span className="v" id="v21" data-v="21" data-xref="以西結書 23:47; 以西結書 23:25; 詩篇 27:4"> 『你告訴以色列家，主耶和華如此說：我必使我的聖所，就是你們勢力所誇耀、眼裏所喜愛、心中所愛惜的被褻瀆，並且你們所遺留的兒女必倒在刀下。</span>
<span className="v" id="v22" data-v="22" data-xref="詩篇 78:64; 耶利米書 16:4–7; 以西結書 24:16–17"> 那時，你們必行我僕人所行的，不蒙着嘴唇，也不吃弔喪的食物。</span>
<span className="v" id="v23" data-v="23" data-xref="以西結書 33:10; 以西結書 4:17; 利未記 26:39"> 你們仍要頭上勒裹頭巾，腳上穿鞋；不可悲哀哭泣。你們必因自己的罪孽相對歎息，漸漸消滅。</span>
<span className="v" id="v24" data-v="24" data-xref="以西結書 4:3; 以賽亞書 20:3; 路加福音 11:29–30"> 以西結必這樣為你們作預兆；凡他所行的，你們也必照樣行。那事來到，你們就知道我是主耶和華。』</span>
<span className="v" id="v25" data-v="25" data-xref="以西結書 24:21; 詩篇 48:2; 耶利米書 11:22"> 「人子啊，我除掉他們所倚靠、所歡喜的榮耀，並眼中所喜愛、心裏所重看的兒女。</span>
<span className="v" id="v26" data-v="26" data-xref="約伯記 1:15–19; 以西結書 33:21–22; 撒母耳記上 4:12–18"> 那日逃脫的人豈不來到你這裏，使你耳聞這事嗎？</span>
<span className="v" id="v27" data-v="27" data-xref="以西結書 33:22; 以西結書 29:21; 路加福音 21:15"> 你必向逃脫的人開口說話，不再啞口。你必這樣為他們作預兆，他們就知道我是耶和華。」</span>
</div>

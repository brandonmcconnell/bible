## 枯骨的復甦

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西結書 3:22; 以西結書 1:3; 使徒行傳 8:39"> 耶和華的靈<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是手">a</a></sup>降在我身上。耶和華藉他的靈帶我出去，將我放在平原中；這平原遍滿骸骨。</span>
<span className="v" id="v2" data-v="2" data-xref="詩篇 141:7; 以西結書 37:11; 申命記 11:30"> 他使我從骸骨的四圍經過，誰知在平原的骸骨甚多，而且極其枯乾。</span>
<span className="v" id="v3" data-v="3" data-xref="約翰福音 11:25–26; 約翰福音 5:21; 申命記 32:39"> 他對我說：「人子啊，這些骸骨能復活嗎？」我說：「主耶和華啊，你是知道的。」</span>
<span className="v" id="v4" data-v="4" data-xref="約翰福音 5:25; 約翰福音 5:28–29; 馬太福音 21:21"> 他又對我說：「你向這些骸骨發預言說：枯乾的骸骨啊，要聽耶和華的話。</span>
<span className="v" id="v5" data-v="5" data-xref="以西結書 37:14; 詩篇 104:29–30; 創世記 2:7"> 主耶和華對這些骸骨如此說：『我必使氣息進入你們裏面，你們就要活了。</span>
<span className="v" id="v6" data-v="6" data-xref="約珥書 2:27; 以賽亞書 49:23; 約珥書 3:17"> 我必給你們加上筋，使你們長肉，又將皮遮蔽你們，使氣息進入你們裏面，你們就要活了；你們便知道我是耶和華。』」</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行傳 2:2; 列王紀上 19:11–13; 耶利米書 13:5–7"> 於是，我遵命說預言。正說預言的時候，不料，有響聲，有地震；骨與骨互相聯絡。</span>
<span className="v" id="v8" data-v="8"> 我觀看，見骸骨上有筋，也長了肉，又有皮遮蔽其上，只是還沒有氣息。</span>
<span className="v" id="v9" data-v="9" data-xref="約翰福音 3:8; 雅歌 4:16; 詩篇 104:30"> 主對我說：「人子啊，你要發預言，向風發預言，說主耶和華如此說：氣息啊，要從四方<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原文是風">b</a></sup>而來，吹在這些被殺的人身上，使他們活了。」</span>
<span className="v" id="v10" data-v="10" data-xref="啟示錄 11:11; 詩篇 104:30; 啟示錄 20:4–5"> 於是我遵命說預言，氣息就進入骸骨，骸骨便活了，並且站起來，成為極大的軍隊。</span>
<span className="v" id="v11" data-v="11" data-xref="以弗所書 2:1; 詩篇 77:7–9; 以西結書 39:25"> 主對我說：「人子啊，這些骸骨就是以色列全家。他們說：『我們的骨頭枯乾了，我們的指望失去了，我們滅絕淨盡了。』</span>
<span className="v" id="v12" data-v="12" data-xref="以賽亞書 26:19; 何西阿書 13:14; 帖撒羅尼迦前書 4:16"> 所以你要發預言對他們說，主耶和華如此說：『我的民哪，我必開你們的墳墓，使你們從墳墓中出來，領你們進入以色列地。</span>
<span className="v" id="v13" data-v="13" data-xref="以西結書 37:6; 以西結書 16:62; 詩篇 126:2–3"> 我的民哪，我開你們的墳墓，使你們從墳墓中出來，你們就知道我是耶和華。</span>
<span className="v" id="v14" data-v="14" data-xref="以西結書 36:27; 約珥書 2:28–29; 以西結書 36:36"> 我必將我的靈放在你們裏面，你們就要活了。我將你們安置在本地，你們就知道我－耶和華如此說，也如此成就了。這是耶和華說的。』」</span>
</div>
</div>

## 猶大和以色列組成聯合王國

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15"> 耶和華的話又臨到我說：</span>
<span className="v" id="v16" data-v="16" data-xref="歷代志下 15:9; 歷代志下 10:19; 歷代志下 10:17"> 「人子啊，你要取一根木杖，在其上寫『為猶大和他的同伴以色列人』；又取一根木杖，在其上寫『為約瑟，就是為以法蓮，又為他的同伴以色列全家』。</span>
<span className="v" id="v17" data-v="17" data-xref="何西阿書 1:11; 耶利米書 50:4; 以賽亞書 11:13"> 你要使這兩根木杖接連為一，在你手中成為一根。</span>
<span className="v" id="v18" data-v="18" data-xref="以西結書 24:19; 以西結書 12:9; 以西結書 17:12"> 你本國的子民問你說：『這是甚麼意思？你不指示我們嗎？』</span>
<span className="v" id="v19" data-v="19" data-xref="撒迦利亞書 10:6; 以西結書 37:16–17; 以弗所書 2:13–14"> 你就對他們說：『主耶和華如此說：我要將約瑟和他同伴以色列支派的杖，就是那在以法蓮手中的，與猶大的杖一同接連為一，在我手中成為一根。』</span>
<span className="v" id="v20" data-v="20" data-xref="以西結書 12:3; 民數記 17:6–9; 何西阿書 12:10"> 你所寫的那兩根杖要在他們眼前拿在手中，</span>
<span className="v" id="v21" data-v="21" data-xref="以西結書 36:24; 耶利米書 29:14; 耶利米書 23:8"> 要對他們說，主耶和華如此說：我要將以色列人從他們所到的各國收取，又從四圍聚集他們，引導他們歸回本地。</span>
<span className="v" id="v22" data-v="22" data-xref="以西結書 37:24; 以西結書 34:23–24; 耶利米書 3:18"> 我要使他們在那地，在以色列山上成為一國，有一王作他們眾民的王。他們不再為二國，決不再分為二國；</span>
<span className="v" id="v23" data-v="23" data-xref="啟示錄 21:3–4; 以西結書 36:28–29; 約翰一書 1:9"> 也不再因偶像和可憎的物，並一切的罪過玷污自己。我卻要救他們出離一切的住處，就是他們犯罪的地方；我要潔淨他們，如此，他們要作我的子民，我要作他們的上帝。</span>
<span className="v" id="v24" data-v="24" data-xref="以西結書 34:23–24; 何西阿書 3:5; 以西結書 37:25"> 「我的僕人大衛必作他們的王；眾民必歸一個牧人。他們必順從我的典章，謹守遵行我的律例。</span>
<span className="v" id="v25" data-v="25" data-xref="阿摩司書 9:15; 以西結書 37:24; 以西結書 28:25"> 他們必住在我賜給我僕人雅各的地上，就是你們列祖所住之地。他們和他們的子孫，並子孫的子孫，都永遠住在那裏。我的僕人大衛必作他們的王，直到永遠。</span>
<span className="v" id="v26" data-v="26" data-xref="以賽亞書 55:3; 耶利米書 30:19; 以西結書 34:25"> 並且我要與他們立平安的約，作為永約。我也要將他們安置在本地，使他們的人數增多，又在他們中間設立我的聖所，直到永遠。</span>
<span className="v" id="v27" data-v="27" data-xref="啟示錄 21:3; 約翰福音 1:14; 以西結書 37:23"> 我的居所必在他們中間；我要作他們的上帝，他們要作我的子民。</span>
<span className="v" id="v28" data-v="28" data-xref="約翰福音 17:17–19; 以西結書 20:12; 出埃及記 31:13"> 我的聖所在以色列人中間直到永遠，外邦人就必知道我是叫以色列成為聖的耶和華。」</span>
</div>

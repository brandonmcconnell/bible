## 東門的使用

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西結書 43:1; 以西結書 40:17; 以西結書 42:14"> 他又帶我回到聖地朝東的外門；那門關閉了。</span>
<span className="v" id="v2" data-v="2" data-xref="以西結書 43:2–4; 出埃及記 24:10; 以賽亞書 6:1–5"> 耶和華對我說：「這門必須關閉，不可敞開，誰也不可由其中進入；因為耶和華－以色列的上帝已經由其中進入，所以必須關閉。</span>
<span className="v" id="v3" data-v="3" data-xref="以西結書 46:2; 以西結書 34:24; 以西結書 37:25"> 至於王，他必按王的位分，坐在其內，在耶和華面前吃餅。他必由這門的廊而入，也必由此而出。」</span>
</div>
</div>

## 進入聖殿的規則

<div className="bt">
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="以西結書 1:28; 啟示錄 1:17; 以西結書 3:23"> 他又帶我由北門來到殿前。我觀看，見耶和華的榮光充滿耶和華的殿，我就俯伏在地。</span>
<span className="v" id="v5" data-v="5" data-xref="以西結書 40:4; 以西結書 43:10–11; 申命記 12:32"> 耶和華對我說：「人子啊，我對你所說耶和華殿中的一切典章法則，你要放在心上，用眼看，用耳聽，並要留心殿宇和聖地一切出入之處。</span>
<span className="v" id="v6" data-v="6" data-xref="以西結書 3:9; 以西結書 45:9; 彼得前書 4:3"> 你要對那悖逆的以色列家說，主耶和華如此說：以色列家啊，你們行一切可憎的事，當夠了吧！</span>
<span className="v" id="v7" data-v="7" data-xref="利未記 22:25; 耶利米書 9:26; 以西結書 44:9"> 你們把我的食物，就是脂油和血獻上的時候，將身心未受割禮的外邦人領進我的聖地，玷污了我的殿；又背了我的約，在你們一切可憎的事上，加上這一層。</span>
<span className="v" id="v8" data-v="8" data-xref="以西結書 44:14; 民數記 18:3–5; 以西結書 40:45–46"> 你們也沒有看守我的聖物，卻派別人在聖地替你們看守我所吩咐你們的。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="約珥書 3:17; 以西結書 44:7; 撒迦利亞書 14:21"> 「主耶和華如此說：以色列中的外邦人，就是身心未受割禮的，都不可入我的聖地。」</span>
</div>
</div>

## 不准當祭司的利未人

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="以西結書 22:26; 以西結書 48:11; 列王紀下 23:8–9"> 「當以色列人走迷的時候，有利未人遠離我，就是走迷離開我、隨從他們的偶像，他們必擔當自己的罪孽。</span>
<span className="v" id="v11" data-v="11" data-xref="民數記 16:9; 歷代志下 29:34; 歷代志下 30:17"> 然而他們必在我的聖地當僕役，照管殿門，在殿中供職；必為民宰殺燔祭牲和平安祭牲，必站在民前伺候他們。</span>
<span className="v" id="v12" data-v="12" data-xref="列王紀下 16:10–16; 詩篇 106:26; 以西結書 14:3–4"> 因為這些利未人曾在偶像前伺候這民，成了以色列家罪孽的絆腳石，所以我向他們起誓：他們必擔當自己的罪孽。這是主耶和華說的。</span>
<span className="v" id="v13" data-v="13" data-xref="民數記 18:3; 列王紀下 23:9; 以西結書 16:61"> 他們不可親近我，給我供祭司的職分，也不可挨近我的一件聖物，就是至聖的物；他們卻要擔當自己的羞辱和所行可憎之事的報應。</span>
<span className="v" id="v14" data-v="14" data-xref="歷代志上 23:28–32; 民數記 18:4"> 然而我要使他們看守殿宇，辦理其中的一切事，並做其內一切當做之工。」</span>
</div>
</div>

## 祭司

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="申命記 10:8; 以西結書 48:11; 以西結書 44:7"> 「以色列人走迷離開我的時候，祭司利未人撒督的子孫仍看守我的聖所。他們必親近我，事奉我，並且侍立在我面前，將脂油與血獻給我。這是主耶和華說的。</span>
<span className="v" id="v16" data-v="16" data-xref="以西結書 41:22; 瑪拉基書 1:12; 民數記 18:7–8"> 他們必進入我的聖所，就近我的桌前事奉我，守我所吩咐的。</span>
<span className="v" id="v17" data-v="17" data-xref="啟示錄 19:8; 出埃及記 28:43; 出埃及記 39:27–29"> 他們進內院門必穿細麻衣。在內院門和殿內供職的時候不可穿羊毛衣服。</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及記 39:28; 哥林多前書 11:4–10; 以賽亞書 3:20"> 他們頭上要戴細麻布裹頭巾，腰穿細麻布褲子；不可穿使身體出汗的衣服。</span>
<span className="v" id="v19" data-v="19" data-xref="以西結書 46:20; 利未記 6:27; 利未記 6:10–11"> 他們出到外院的民那裏，當脫下供職的衣服，放在聖屋內，穿上別的衣服，免得因聖衣使民成聖。</span>
<span className="v" id="v20" data-v="20" data-xref="哥林多前書 11:14; 民數記 6:5; 利未記 21:5–24"> 不可剃頭，也不可容髮綹長長，只可剪髮。</span>
<span className="v" id="v21" data-v="21" data-xref="利未記 10:9; 提多書 1:7–8; 提摩太前書 5:23"> 祭司進內院的時候都不可喝酒。</span>
<span className="v" id="v22" data-v="22" data-xref="利未記 21:7; 利未記 21:13–14; 提摩太前書 3:2"> 不可娶寡婦和被休的婦人為妻，只可娶以色列後裔中的處女，或是祭司遺留的寡婦。</span>
<span className="v" id="v23" data-v="23" data-xref="以西結書 22:26; 利未記 10:10–11; 提摩太後書 2:24–25"> 他們要使我的民知道聖俗的分別，又使他們分辨潔淨的和不潔淨的。</span>
<span className="v" id="v24" data-v="24" data-xref="歷代志上 23:4; 以西結書 22:26; 歷代志下 19:8–10"> 有爭訟的事，他們應當站立判斷，要按我的典章判斷。在我一切的節期必守我的律法、條例，也必以我的安息日為聖日。</span>
<span className="v" id="v25" data-v="25" data-xref="哥林多後書 5:16; 利未記 22:4; 馬太福音 8:21–22"> 他們不可挨近死屍沾染自己，只可為父親、母親、兒子、女兒、弟兄，和未嫁人的姊妹沾染自己。</span>
<span className="v" id="v26" data-v="26" data-xref="希伯來書 9:13–14; 民數記 19:11–14; 民數記 6:10–21"> 祭司潔淨之後，必再計算七日。</span>
<span className="v" id="v27" data-v="27" data-xref="民數記 6:9–11; 以西結書 44:17; 利未記 4:3–35"> 當他進內院，進聖所，在聖所中事奉的日子，要為自己獻贖罪祭。這是主耶和華說的。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="約書亞記 13:33; 民數記 18:20; 申命記 18:1–2"> 「祭司必有產業，我是他們的產業。不可在以色列中給他們基業；我是他們的基業。</span>
<span className="v" id="v29" data-v="29" data-xref="民數記 18:14; 利未記 27:21; 利未記 27:28"> 素祭、贖罪祭，和贖愆祭他們都可以吃，以色列中一切永獻的物都要歸他們。</span>
<span className="v" id="v30" data-v="30" data-xref="尼希米記 10:35–37; 歷代志下 31:10; 申命記 18:4"> 首先初熟之物和一切所獻的供物都要歸給祭司。你們也要用初熟的麥子磨麵給祭司；這樣，福氣就必臨到你們的家了。</span>
<span className="v" id="v31" data-v="31" data-xref="利未記 22:8; 出埃及記 22:31; 申命記 14:21"> 無論是鳥是獸，凡自死的，或是撕裂的，祭司都不可吃。」</span>
</div>
</div>

## 以西結所見的第二個異象


## 耶路撒冷城裏的偶像崇拜

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西結書 20:1; 以西結書 1:2–3; 以西結書 14:1"> 第六年六月初五日，我坐在家中；猶大的眾長老坐在我面前。在那裏主耶和華的靈<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是手">a</a></sup>降在我身上。</span>
<span className="v" id="v2" data-v="2" data-xref="以西結書 1:4; 以西結書 1:26–27; 但以理書 7:9–10"> 我觀看，見有形像彷彿火的形狀，從他腰以下的形狀有火，從他腰以上有光輝的形狀，彷彿光耀的精金。</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 32:16; 以西結書 11:1; 以西結書 5:11"> 他伸出彷彿一隻手的樣式，抓住我的一綹頭髮，靈就將我舉到天地中間，在上帝的異象中，帶我到耶路撒冷朝北的內院門口，在那裏有觸動主怒偶像的坐位，就是惹動忌邪的。</span>
<span className="v" id="v4" data-v="4" data-xref="以西結書 3:22–23; 出埃及記 40:34–35; 以西結書 11:22–23"> 誰知，在那裏有以色列上帝的榮耀，形狀與我在平原所見的一樣。</span>
<span className="v" id="v5" data-v="5" data-xref="以西結書 8:3; 耶利米書 3:2; 耶利米書 32:34"> 上帝對我說：「人子啊，你舉目向北觀看。」我就舉目向北觀看，見祭壇門的北邊，在門口有這惹忌邪的偶像；</span>
<span className="v" id="v6" data-v="6" data-xref="以西結書 5:11; 以西結書 10:19; 以西結書 8:9"> 又對我說：「人子啊，以色列家所行的，就是在此行這大可憎的事，使我遠離我的聖所，你看見了嗎？你還要看見另有大可憎的事。」</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀下 21:5; 列王紀上 7:12"> 他領我到院門口。我觀看，見牆上有個窟窿。</span>
<span className="v" id="v8" data-v="8" data-xref="以賽亞書 29:15; 約伯記 34:22; 阿摩司書 9:2–3"> 他對我說：「人子啊，你要挖牆。」我一挖牆，見有一門。</span>
<span className="v" id="v9" data-v="9" data-xref="以西結書 20:8"> 他說：「你進去，看他們在這裏所行可憎的惡事。」</span>
<span className="v" id="v10" data-v="10" data-xref="羅馬書 1:23; 出埃及記 20:4; 耶利米書 16:18"> 我進去一看，誰知，在四面牆上畫着各樣爬物和可憎的走獸，並以色列家一切的偶像。</span>
<span className="v" id="v11" data-v="11" data-xref="民數記 16:17; 民數記 16:35; 民數記 11:16"> 在這些像前有以色列家的七十個長老站立，沙番的兒子雅撒尼亞也站在其中。各人手拿香爐，煙雲的香氣上騰。</span>
<span className="v" id="v12" data-v="12" data-xref="以賽亞書 29:15; 以西結書 9:9; 以西結書 8:15"> 他對我說：「人子啊，以色列家的長老暗中在各人畫像屋裏所行的，你看見了嗎？他們常說：『耶和華看不見我們；耶和華已經離棄這地。』」</span>
<span className="v" id="v13" data-v="13" data-xref="以西結書 8:6; 耶利米書 9:3; 以西結書 8:15"> 他又說：「你還要看見他們另外行大可憎的事。」</span>
<span className="v" id="v14" data-v="14" data-xref="以西結書 46:9; 以西結書 44:4"> 他領我到耶和華殿外院朝北的門口。誰知，在那裏有婦女坐着，為搭模斯哭泣。</span>
<span className="v" id="v15" data-v="15" data-xref="以西結書 8:12–13; 以西結書 8:9; 以西結書 8:6"> 他對我說：「人子啊，你看見了嗎？你還要看見比這更可憎的事。」</span>
<span className="v" id="v16" data-v="16" data-xref="申命記 4:19; 申命記 17:3; 耶利米書 32:33"> 他又領我到耶和華殿的內院。誰知，在耶和華的殿門口、廊子和祭壇中間，約有二十五個人背向耶和華的殿，面向東方拜日頭。</span>
<span className="v" id="v17" data-v="17" data-xref="以西結書 9:9; 以西結書 7:23; 耶利米書 6:7"> 他對我說：「人子啊，你看見了嗎？猶大家在此行這可憎的事還算為小嗎？他們在這地遍行強暴，再三惹我發怒，他們手拿枝條舉向鼻前。</span>
<span className="v" id="v18" data-v="18" data-xref="彌迦書 3:4; 耶利米書 11:11; 以賽亞書 1:15"> 因此，我也要以忿怒行事，我眼必不顧惜，也不可憐他們；他們雖向我耳中大聲呼求，我還是不聽。」</span>

## 上帝指派以西結作守望者

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華的話臨到我說：</span>
<span className="v" id="v2" data-v="2" data-xref="以西結書 33:30; 以西結書 33:17; 以西結書 3:11"> 「人子啊，你要告訴本國的子民說：我使刀劍臨到哪一國，那一國的民從他們中間選立一人為守望的。</span>
<span className="v" id="v3" data-v="3" data-xref="何西阿書 8:1; 尼希米記 4:20; 尼希米記 4:18"> 他見刀劍臨到那地，若吹角警戒眾民，</span>
<span className="v" id="v4" data-v="4" data-xref="以西結書 18:13; 使徒行傳 18:6; 耶利米書 6:17"> 凡聽見角聲不受警戒的，刀劍若來除滅了他，他的罪<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是血">a</a></sup>就必歸到自己的頭上。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 9:19–21; 希伯來書 11:7; 約翰福音 8:39"> 他聽見角聲，不受警戒，他的罪必歸到自己的身上；他若受警戒，便是救了自己的性命。</span>
<span className="v" id="v6" data-v="6" data-xref="以西結書 3:18–20; 以西結書 33:8–9; 創世記 42:22"> 倘若守望的人見刀劍臨到，不吹角，以致民不受警戒，刀劍來殺了他們中間的一個人，他雖然死在罪孽之中，我卻要向守望的人討他喪命的罪<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原文是血">b</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="以西結書 3:17–21; 耶利米書 26:2; 以西結書 2:7–8"> 「人子啊，我照樣立你作以色列家守望的人。所以你要聽我口中的話，替我警戒他們。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行傳 20:26–27; 以西結書 33:6; 以西結書 33:14"> 我對惡人說：『惡人哪，你必要死！』你－以西結若不開口警戒惡人，使他離開所行的道，這惡人必死在罪孽之中，我卻要向你討他喪命的罪<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="原文是血">c</a></sup>。</span>
<span className="v" id="v9" data-v="9" data-xref="以西結書 3:19; 使徒行傳 20:26; 箴言 15:10"> 倘若你警戒惡人轉離所行的道，他仍不轉離，他必死在罪孽之中，你卻救自己脫離了罪。」</span>
</div>
</div>

## 個人的責任

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="以賽亞書 49:14; 以西結書 37:11; 以西結書 24:23"> 「人子啊，你要對以色列家說：『你們常說：我們的過犯罪惡在我們身上，我們必因此消滅，怎能存活呢？』</span>
<span className="v" id="v11" data-v="11" data-xref="提摩太前書 2:4; 以西結書 18:23; 彼得後書 3:9"> 你對他們說，主耶和華說：我指着我的永生起誓，我斷不喜悅惡人死亡，惟喜悅惡人轉離所行的道而活。以色列家啊，你們轉回，轉回吧！離開惡道，何必死亡呢？</span>
<span className="v" id="v12" data-v="12" data-xref="歷代志下 7:14; 以西結書 33:18–19; 羅馬書 3:25"> 人子啊，你要對本國的人民說：義人的義，在犯罪之日不能救他；至於惡人的惡，在他轉離惡行之日也不能使他傾倒；義人在犯罪之日也不能因他的義存活。</span>
<span className="v" id="v13" data-v="13" data-xref="以西結書 18:24; 希伯來書 10:38; 以西結書 18:4"> 我對義人說：『你必定存活！』他若倚靠他的義而作罪孽，他所行的義都不被記念。他必因所作的罪孽死亡。</span>
<span className="v" id="v14" data-v="14" data-xref="以西結書 18:27; 耶利米書 18:7–8; 何西阿書 14:1"> 再者，我對惡人說：『你必定死亡！』他若轉離他的罪，行正直與合理的事：</span>
<span className="v" id="v15" data-v="15" data-xref="以西結書 20:11; 路加福音 19:8; 出埃及記 22:1–4"> 還人的當頭和所搶奪的，遵行生命的律例，不作罪孽，他必定存活，不致死亡。</span>
<span className="v" id="v16" data-v="16" data-xref="以賽亞書 43:25; 以西結書 18:22; 彌迦書 7:18–19"> 他所犯的一切罪必不被記念。他行了正直與合理的事，必定存活。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="馬太福音 25:24–26; 以西結書 18:25; 以西結書 18:29"> 「你本國的子民還說：『主的道不公平。』其實他們的道不公平。</span>
<span className="v" id="v18" data-v="18" data-xref="以西結書 33:12–13; 彼得後書 2:20–22; 希伯來書 10:38"> 義人轉離他的義而作罪孽，就必因此死亡。</span>
<span className="v" id="v19" data-v="19" data-xref="以西結書 18:27–28; 以西結書 33:14"> 惡人轉離他的惡，行正直與合理的事，就必因此存活。</span>
<span className="v" id="v20" data-v="20" data-xref="馬太福音 16:27; 以西結書 18:25; 以西結書 33:17"> 你們還說：『主的道不公平。』以色列家啊，我必按你們各人所行的審判你們。」</span>
</div>
</div>

## 耶路撒冷陷落的消息

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="以西結書 1:2; 耶利米書 39:1–8; 列王紀下 25:4"> 我們被擄之後十二年十月初五日，有人從耶路撒冷逃到我這裏，說：「城已攻破。」</span>
<span className="v" id="v22" data-v="22" data-xref="以西結書 1:3; 以西結書 3:26–27; 以西結書 24:26–27"> 逃來的人未到前一日的晚上，耶和華的靈<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="原文是手">d</a></sup>降在我身上，開我的口。到第二日早晨，那人來到我這裏，我口就開了，不再緘默。</span>
</div>
</div>

## 百姓的罪

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23"> 耶和華的話臨到我說：</span>
<span className="v" id="v24" data-v="24" data-xref="以西結書 33:27; 以賽亞書 51:2; 使徒行傳 7:5"> 「人子啊，住在以色列荒廢之地的人說：『亞伯拉罕獨自一人能得這地為業，我們人數眾多，這地更是給我們為業的。』</span>
<span className="v" id="v25" data-v="25" data-xref="申命記 12:16; 耶利米書 7:9–10; 創世記 9:4"> 所以你要對他們說，主耶和華如此說：你們吃帶血的物，仰望偶像，並且殺人流血，你們還能得這地為業嗎？</span>
<span className="v" id="v26" data-v="26" data-xref="創世記 27:40; 彌迦書 2:1–2; 西番雅書 3:3"> 你們倚仗自己的刀劍行可憎的事，人人玷污鄰舍的妻，你們還能得這地為業嗎？</span>
<span className="v" id="v27" data-v="27" data-xref="撒母耳記上 13:6; 耶利米書 42:22; 以西結書 39:4"> 你要對他們這樣說，主耶和華如此說：我指着我的永生起誓，在荒場中的，必倒在刀下；在田野間的，必交給野獸吞吃；在保障和洞裏的，必遭瘟疫而死。</span>
<span className="v" id="v28" data-v="28" data-xref="以西結書 7:24; 耶利米書 44:2; 耶利米書 44:6"> 我必使這地荒涼，令人驚駭；她因勢力而有的驕傲也必止息。以色列的山都必荒涼，無人經過。</span>
<span className="v" id="v29" data-v="29" data-xref="以西結書 6:7; 以西結書 36:17–18; 以西結書 22:2–15"> 我因他們所行一切可憎的事使地荒涼，令人驚駭。那時，他們就知道我是耶和華。」</span>
</div>
</div>

## 先知傳講信息的結果

<div className="bt">
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="馬太福音 22:16–17; 耶利米書 23:35; 以賽亞書 29:13"> 「人子啊，你本國的子民在牆垣旁邊、在房屋門口談論你。弟兄對弟兄彼此說：『來吧！聽聽有甚麼話從耶和華而出。』</span>
<span className="v" id="v31" data-v="31" data-xref="馬太福音 13:22; 詩篇 78:36–37; 雅各書 1:22–24"> 他們來到你這裏如同民來聚會，坐在你面前彷彿是我的民。他們聽你的話卻不去行；因為他們的口多顯愛情，心卻追隨財利。</span>
<span className="v" id="v32" data-v="32" data-xref="馬可福音 6:20; 馬可福音 4:16–17; 約翰福音 5:35"> 他們看你如善於奏樂、聲音幽雅之人所唱的雅歌，他們聽你的話卻不去行。</span>
<span className="v" id="v33" data-v="33" data-xref="耶利米書 28:9; 撒母耳記上 3:19–20; 以西結書 2:5"> 看哪，所說的快要應驗；應驗了，他們就知道在他們中間有了先知。」</span>
</div>

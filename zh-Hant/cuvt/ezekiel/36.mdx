## 上帝賜福給以色列

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西結書 37:4; 以西結書 34:14; 以西結書 37:22"> 「人子啊，你要對以色列山發預言說：以色列山哪，要聽耶和華的話。</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 32:13; 以西結書 25:3; 以西結書 35:10"> 主耶和華如此說：因仇敵說：『阿哈！這永久的山岡都歸我們為業了！』</span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 44:13–14; 耶利米哀歌 2:15–16; 耶利米書 18:16"> 所以要發預言說，主耶和華如此說：因為敵人使你荒涼，四圍吞吃，好叫你歸與其餘的外邦人為業，並且多嘴多舌的人提起你來，百姓也說你有臭名。</span>
<span className="v" id="v4" data-v="4" data-xref="以西結書 34:28; 申命記 11:11; 以西結書 36:6"> 故此，以色列山要聽主耶和華的話。大山小岡、水溝山谷、荒廢之地、被棄之城，為四圍其餘的外邦人所佔據、所譏刺的，</span>
<span className="v" id="v5" data-v="5" data-xref="彌迦書 7:8; 以西結書 36:3; 詩篇 137:7"> 主耶和華對你們如此說：我真發憤恨如火，責備那其餘的外邦人和以東的眾人。他們快樂滿懷，心存恨惡，將我的地歸自己為業，又看為被棄的掠物。</span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 123:3–4; 以西結書 34:29; 詩篇 74:23"> 所以，你要指着以色列地說預言，對大山小岡、水溝山谷說，主耶和華如此說：我發憤恨和忿怒說，因你們曾受外邦人的羞辱，</span>
<span className="v" id="v7" data-v="7" data-xref="以西結書 20:5; 阿摩司書 1:1–15; 以西結書 20:15"> 所以我起誓說：你們四圍的外邦人總要擔當自己的羞辱。這是主耶和華說的。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="以賽亞書 27:6; 希伯來書 10:37; 以西結書 34:26–29"> 「以色列山哪，你必發枝條，為我的民以色列結果子，因為他們快要來到。</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 46:11; 何西阿書 2:21–23; 以西結書 36:34"> 看哪，我是幫助你的，也必向你轉意，使你得以耕種。</span>
<span className="v" id="v10" data-v="10" data-xref="以西結書 36:33; 耶利米書 33:12; 以西結書 36:37"> 我必使以色列全家的人數在你上面增多，城邑有人居住，荒場再被建造。</span>
<span className="v" id="v11" data-v="11" data-xref="耶利米書 33:12; 耶利米書 23:5–8; 耶利米書 31:27"> 我必使人和牲畜在你上面加增；他們必生養眾多。我要使你照舊有人居住，並要賜福與你比先前更多，你就知道我是耶和華。</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米書 15:7; 以西結書 36:13; 耶利米書 32:44"> 我必使人，就是我的民以色列，行在你上面。他們必得你為業；你也不再使他們喪子。</span>
<span className="v" id="v13" data-v="13" data-xref="民數記 13:32"> 主耶和華如此說：因為人對你說：『你是吞吃人的，又使國民喪子』，</span>
<span className="v" id="v14" data-v="14" data-xref="以西結書 37:25–28; 阿摩司書 9:15; 以賽亞書 60:21"> 所以主耶和華說：你必不再吞吃人，也不再使國民喪子。</span>
<span className="v" id="v15" data-v="15" data-xref="以西結書 34:29; 詩篇 89:50; 以西結書 36:6"> 我使你不再聽見各國的羞辱，不再受萬民的辱罵，也不再使國民絆跌。這是主耶和華說的。」</span>
</div>
</div>

## 以色列的新生活

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16"> 耶和華的話又臨到我說：</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米書 2:7; 民數記 35:33–34; 彌迦書 2:10"> 「人子啊，以色列家住在本地的時候，在行動作為上玷污那地。他們的行為在我面前，好像正在經期的婦人那樣污穢。</span>
<span className="v" id="v18" data-v="18" data-xref="歷代志下 34:21; 以西結書 7:8; 耶利米哀歌 2:4"> 所以我因他們在那地上流人的血，又因他們以偶像玷污那地，就把我的忿怒傾在他們身上。</span>
<span className="v" id="v19" data-v="19" data-xref="以西結書 39:24; 申命記 28:64; 以西結書 5:12"> 我將他們分散在列國，四散在列邦，按他們的行動作為懲罰他們。</span>
<span className="v" id="v20" data-v="20" data-xref="羅馬書 2:24; 以賽亞書 52:5; 耶利米書 33:24"> 他們到了所去的列國，就使我的聖名被褻瀆；因為人談論他們說，這是耶和華的民，是從耶和華的地出來的。</span>
<span className="v" id="v21" data-v="21" data-xref="以賽亞書 48:9; 詩篇 74:18; 以西結書 20:9"> 我卻顧惜我的聖名，就是以色列家在所到的列國中所褻瀆的。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="詩篇 106:8; 以西結書 36:32; 詩篇 115:1–2"> 「所以，你要對以色列家說，主耶和華如此說：以色列家啊，我行這事不是為你們，乃是為我的聖名，就是在你們到的列國中所褻瀆的。</span>
<span className="v" id="v23" data-v="23" data-xref="以西結書 20:41; 以賽亞書 5:16; 以西結書 39:7"> 我要使我的大名顯為聖；這名在列國中已被褻瀆，就是你們在他們中間所褻瀆的。我在他們眼前，在你們身上顯為聖的時候，他們就知道我是耶和華。這是主耶和華說的。</span>
<span className="v" id="v24" data-v="24" data-xref="以西結書 37:21; 以西結書 34:13; 阿摩司書 9:14–15"> 我必從各國收取你們，從列邦聚集你們，引導你們歸回本地。</span>
<span className="v" id="v25" data-v="25" data-xref="希伯來書 10:22; 約翰福音 3:5; 耶利米書 33:8"> 我必用清水灑在你們身上，你們就潔淨了。我要潔淨你們，使你們脫離一切的污穢，棄掉一切的偶像。</span>
<span className="v" id="v26" data-v="26" data-xref="以西結書 11:19–20; 詩篇 51:10; 哥林多後書 5:17"> 我也要賜給你們一個新心，將新靈放在你們裏面，又從你們的肉體中除掉石心，賜給你們肉心。</span>
<span className="v" id="v27" data-v="27" data-xref="提多書 3:3–6; 希伯來書 13:21; 哥林多前書 3:16"> 我必將我的靈放在你們裏面，使你們順從我的律例，謹守遵行我的典章。</span>
<span className="v" id="v28" data-v="28" data-xref="耶利米書 31:33; 耶利米書 32:38; 以西結書 37:27"> 你們必住在我所賜給你們列祖之地。你們要作我的子民，我要作你們的上帝。</span>
<span className="v" id="v29" data-v="29" data-xref="約翰福音 1:7–9; 馬太福音 1:21; 何西阿書 2:21–23"> 我必救你們脫離一切的污穢，也必命五穀豐登，不使你們遭遇饑荒。</span>
<span className="v" id="v30" data-v="30" data-xref="以西結書 34:27; 約珥書 2:26; 申命記 29:23–28"> 我必使樹木多結果子，田地多出土產，好叫你們不再因饑荒受外邦人的譏誚。</span>
<span className="v" id="v31" data-v="31" data-xref="以西結書 6:9; 以西結書 20:43; 尼希米記 9:26–35"> 那時，你們必追想你們的惡行和你們不善的作為，就因你們的罪孽和可憎的事厭惡自己。</span>
<span className="v" id="v32" data-v="32" data-xref="申命記 9:5; 以西結書 36:22; 提摩太後書 1:9"> 主耶和華說：你們要知道，我這樣行不是為你們。以色列家啊，當為自己的行為抱愧蒙羞。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="以賽亞書 58:12; 以西結書 36:10; 耶利米書 33:10"> 「主耶和華如此說：我潔淨你們，使你們脫離一切罪孽的日子，必使城邑有人居住，荒場再被建造。</span>
<span className="v" id="v34" data-v="34" data-xref="以西結書 6:14; 耶利米書 25:9–11; 歷代志下 36:21"> 過路的人雖看為荒廢之地，現今這荒廢之地仍得耕種。</span>
<span className="v" id="v35" data-v="35" data-xref="以賽亞書 51:3; 約珥書 2:3; 耶利米書 33:9"> 他們必說：『這先前為荒廢之地，現在成如伊甸園；這荒廢淒涼、毀壞的城邑現在堅固有人居住。』</span>
<span className="v" id="v36" data-v="36" data-xref="馬太福音 24:35; 民數記 23:19; 以西結書 17:24"> 那時，在你們四圍其餘的外邦人必知道我－耶和華修造那毀壞之處，培植那荒廢之地。我－耶和華說過，也必成就。</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="約翰一書 5:14; 希伯來書 10:21–22; 以西結書 14:3"> 「主耶和華如此說：我要加增以色列家的人數，多如羊群。他們必為這事向我求問，我要給他們成就。</span>
<span className="v" id="v38" data-v="38" data-xref="列王紀上 8:63; 使徒行傳 2:5–11; 約翰福音 10:16"> 耶路撒冷在守節作祭物所獻的羊群怎樣多，照樣，荒涼的城邑必被人群充滿。他們就知道我是耶和華。」</span>
</div>
</div>

## 君王和節期

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以賽亞書 66:23; 以西結書 44:1–2; 出埃及記 20:9"> 主耶和華如此說：「內院朝東的門，在辦理事務的六日內必須關閉；惟有安息日和月朔必須敞開。</span>
<span className="v" id="v2" data-v="2" data-xref="以西結書 44:3; 以西結書 46:8; 歷代志上 29:10–12"> 王要從這門的廊進入，站在門框旁邊。祭司要為他預備燔祭和平安祭，他就要在門檻那裏敬拜，然後出去。這門直到晚上不可關閉。</span>
<span className="v" id="v3" data-v="3" data-xref="路加福音 1:10; 約翰福音 10:9; 希伯來書 10:19–22"> 在安息日和月朔，國內的居民要在這門口，耶和華面前敬拜。</span>
<span className="v" id="v4" data-v="4" data-xref="以西結書 45:17; 民數記 28:9–10"> 安息日，王所獻與耶和華的燔祭要用無殘疾的羊羔六隻，無殘疾的公綿羊一隻；</span>
<span className="v" id="v5" data-v="5" data-xref="以西結書 45:24; 以西結書 46:7; 申命記 16:17"> 同獻的素祭要為公綿羊獻一伊法細麵，為羊羔照他的力量而獻，一伊法細麵加油一欣。</span>
<span className="v" id="v6" data-v="6" data-xref="以西結書 46:1"> 當月朔，要獻無殘疾的公牛犢一隻，羊羔六隻，公綿羊一隻，都要無殘疾的。</span>
<span className="v" id="v7" data-v="7" data-xref="以西結書 46:5"> 他也要預備素祭，為公牛獻一伊法細麵，為公綿羊獻一伊法細麵，為羊羔照他的力量而獻，一伊法細麵加油一欣。</span>
<span className="v" id="v8" data-v="8" data-xref="以西結書 46:2; 以西結書 44:1–3; 歌羅西書 1:18"> 王進入的時候必由這門的廊而入，也必由此而出。</span>
<span className="v" id="v9" data-v="9" data-xref="申命記 16:16; 出埃及記 23:14–17; 彼得後書 2:20–21"> 「在各節期，國內居民朝見耶和華的時候，從北門進入敬拜的，必由南門而出；從南門進入的，必由北門而出。不可從所入的門而出，必要直往前行，由對門而出。</span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 42:4; 歷代志上 29:20; 歷代志上 29:22"> 民進入，王也要在民中進入；民出去，王也要一同出去。</span>
<span className="v" id="v11" data-v="11" data-xref="以西結書 46:5; 以西結書 46:7; 民數記 15:1–41"> 「在節期和聖會的日子同獻的素祭，要為一隻公牛獻一伊法細麵，為一隻公綿羊獻一伊法細麵，為羊羔照他的力量而獻，一伊法細麵加油一欣。</span>
<span className="v" id="v12" data-v="12" data-xref="以西結書 46:1–2; 以西結書 45:17; 以西結書 44:3"> 王預備甘心獻的燔祭或平安祭，就是向耶和華甘心獻的，當有人為他開朝東的門。他就預備燔祭和平安祭，與安息日預備的一樣，獻畢就出去。他出去之後，當有人將門關閉。」</span>
</div>
</div>

## 每日的祭

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="以賽亞書 50:4; 約翰福音 1:29; 出埃及記 12:5"> 「每日，你要預備無殘疾一歲的羊羔一隻，獻與耶和華為燔祭；要每早晨預備。</span>
<span className="v" id="v14" data-v="14" data-xref="民數記 28:5"> 每早晨也要預備同獻的素祭，細麵一伊法六分之一，並油一欣三分之一，調和細麵。這素祭要常獻與耶和華為永遠的定例。</span>
<span className="v" id="v15" data-v="15" data-xref="希伯來書 10:1–10; 民數記 28:6; 出埃及記 29:42"> 每早晨要這樣預備羊羔、素祭，並油為常獻的燔祭。」</span>
</div>
</div>

## 王和土地

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="歷代志下 21:3; 加拉太書 4:7; 創世記 25:5–6"> 主耶和華如此說：「王若將產業賜給他的兒子，就成了他兒子的產業，那是他們承受為業的。</span>
<span className="v" id="v17" data-v="17" data-xref="利未記 25:10; 路加福音 19:25–26; 加拉太書 4:30–31"> 倘若王將一分產業賜給他的臣僕，就成了他臣僕的產業；到自由之年仍要歸與王。至於王的產業，必歸與他的兒子。</span>
<span className="v" id="v18" data-v="18" data-xref="以西結書 45:8; 列王紀上 21:19; 以西結書 22:27"> 王不可奪取民的產業，以致驅逐他們離開所承受的；他要從自己的地業中，將產業賜給他兒子，免得我的民分散，各人離開所承受的。」</span>
</div>
</div>

## 聖殿的廚房

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="以西結書 42:9; 以西結書 44:4–5; 以西結書 40:44–46"> 那帶我的，將我從門旁進入之處、領進為祭司預備的聖屋，是朝北的，見後頭西邊有一塊地。</span>
<span className="v" id="v20" data-v="20" data-xref="歷代志下 35:13; 以西結書 44:29; 以西結書 44:19"> 他對我說：「這是祭司煮贖愆祭、贖罪祭，烤素祭之地，免得帶到外院，使民成聖。」</span>
<span className="v" id="v21" data-v="21"> 他又帶我到外院，使我經過院子的四拐角，見每拐角各有一個院子。</span>
<span className="v" id="v22" data-v="22"> 院子四拐角的院子，周圍有牆，每院長四十肘，寬三十肘。四拐角院子的尺寸都是一樣，</span>
<span className="v" id="v23" data-v="23"> 其中周圍有一排房子，房子內有煮肉的地方。</span>
<span className="v" id="v24" data-v="24" data-xref="以西結書 46:20; 約翰福音 21:15–17; 彼得前書 5:2"> 他對我說：「這都是煮肉的房子，殿內的僕役要在這裏煮民的祭物。」</span>
</div>

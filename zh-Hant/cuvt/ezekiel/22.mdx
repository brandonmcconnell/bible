## 耶路撒冷的過犯

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華的話又臨到我說：</span>
<span className="v" id="v2" data-v="2" data-xref="以賽亞書 58:1; 以西結書 24:6; 以西結書 24:9"> 「人子啊，你要審問審問這流人血的城嗎？當使她知道她一切可憎的事。</span>
<span className="v" id="v3" data-v="3" data-xref="以西結書 22:27; 羅馬書 2:5; 彼得後書 2:3"> 你要說，主耶和華如此說：哎！這城有流人血的事在其中，叫她受報的日期來到，又做偶像玷污自己，陷害自己。</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀下 21:16; 詩篇 44:13–14; 以西結書 22:2"> 你因流了人的血，就為有罪；你做了偶像，就玷污自己，使你受報之日臨近，報應之年來到。所以我叫你受列國的凌辱和列邦的譏誚。</span>
<span className="v" id="v5" data-v="5" data-xref="以賽亞書 22:2; 耶利米書 15:2–3"> 你這名臭、多亂的城啊，那些離你近、離你遠的都必譏誚你。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="以西結書 22:27; 以賽亞書 1:23; 撒迦利亞書 3:3"> 「看哪，以色列的首領各逞其能，在你中間流人之血。</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 27:16; 出埃及記 22:21–22; 利未記 20:9"> 在你中間有輕慢父母的，有欺壓寄居的，有虧負孤兒寡婦的。</span>
<span className="v" id="v8" data-v="8" data-xref="以西結書 23:38–39; 以西結書 22:26; 以西結書 20:13"> 你藐視了我的聖物，干犯了我的安息日。</span>
<span className="v" id="v9" data-v="9" data-xref="何西阿書 4:14; 利未記 19:16; 何西阿書 4:10"> 在你中間有讒謗人、流人血的；有在山上吃過祭偶像之物的，有行淫亂的。</span>
<span className="v" id="v10" data-v="10" data-xref="利未記 18:19; 利未記 18:7–8; 以西結書 18:6"> 在你中間有露繼母下體羞辱父親的，有玷辱月經不潔淨之婦人的。</span>
<span className="v" id="v11" data-v="11" data-xref="利未記 18:15; 撒母耳記下 13:14; 利未記 20:17"> 這人與鄰舍的妻行可憎的事；那人貪淫玷污兒婦；還有玷辱同父之姊妹的。</span>
<span className="v" id="v12" data-v="12" data-xref="申命記 27:25; 以西結書 23:35; 詩篇 106:21"> 在你中間有為流人血受賄賂的；有向借錢的弟兄取利，向借糧的弟兄多要的。且因貪得無饜，欺壓鄰舍奪取財物，竟忘了我。這是主耶和華說的。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="以西結書 21:17; 以賽亞書 33:15; 阿摩司書 2:6–8"> 「看哪，我因你所得不義之財和你中間所流的血，就拍掌歎息。</span>
<span className="v" id="v14" data-v="14" data-xref="以西結書 21:7; 以西結書 17:24; 以西結書 24:14"> 到了我懲罰你的日子，你的心還能忍受嗎？你的手還能有力嗎？我－耶和華說了這話，就必照着行。</span>
<span className="v" id="v15" data-v="15" data-xref="尼希米記 1:8; 以西結書 22:22; 申命記 4:27"> 我必將你分散在列國，四散在列邦。我也必從你中間除掉你的污穢。</span>
<span className="v" id="v16" data-v="16" data-xref="以西結書 6:7; 詩篇 83:18; 以西結書 7:24"> 你必在列國人的眼前因自己所行的被褻瀆，你就知道我是耶和華。」</span>
</div>
</div>

## 上帝的大煉爐

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17"> 耶和華的話臨到我說：</span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 119:119; 以賽亞書 1:22; 耶利米書 6:28–30"> 「人子啊，以色列家在我看為渣滓。他們都是爐中的銅、錫、鐵、鉛，都是銀渣滓。</span>
<span className="v" id="v19" data-v="19" data-xref="馬太福音 13:30; 以西結書 24:3–6; 彌迦書 4:12"> 所以主耶和華如此說：因你們都成為渣滓，我必聚集你們在耶路撒冷中。</span>
<span className="v" id="v20" data-v="20" data-xref="耶利米書 4:11–12; 以賽亞書 54:16; 以西結書 24:13"> 人怎樣將銀、銅、鐵、鉛、錫聚在爐中，吹火鎔化；照樣，我也要發怒氣和忿怒，將你們聚集放在城中，鎔化你們。</span>
<span className="v" id="v21" data-v="21" data-xref="以賽亞書 64:7; 那鴻書 1:6; 詩篇 50:3"> 我必聚集你們，把我烈怒的火吹在你們身上，你們就在其中鎔化。</span>
<span className="v" id="v22" data-v="22" data-xref="以西結書 20:8; 以西結書 20:33; 何西阿書 5:10"> 銀子怎樣鎔化在爐中，你們也必照樣鎔化在城中，你們就知道我－耶和華是將忿怒倒在你們身上了。」</span>
</div>
</div>

## 以色列領袖們的罪惡

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23"> 耶和華的話臨到我說：</span>
<span className="v" id="v24" data-v="24" data-xref="歷代志下 36:14–16; 耶利米書 2:30; 歷代志下 28:22"> 「人子啊，你要對這地說：你是未得潔淨之地，在惱恨的日子也沒有雨下在你以上。</span>
<span className="v" id="v25" data-v="25" data-xref="何西阿書 6:9; 耶利米書 2:34; 以西結書 13:19"> 其中的先知同謀背叛，如咆哮的獅子抓撕掠物。他們吞滅人民，搶奪財寶，使這地多有寡婦。</span>
<span className="v" id="v26" data-v="26" data-xref="利未記 10:10; 以西結書 44:23; 以西結書 22:8"> 其中的祭司強解我的律法，褻瀆我的聖物，不分別聖的和俗的，也不使人分辨潔淨的和不潔淨的，又遮眼不顧我的安息日；我也在他們中間被褻慢。</span>
<span className="v" id="v27" data-v="27" data-xref="以西結書 22:13; 以賽亞書 1:23; 以西結書 22:6"> 其中的首領彷彿豺狼抓撕掠物，殺人流血，傷害人命，要得不義之財。</span>
<span className="v" id="v28" data-v="28" data-xref="以西結書 13:6–7; 以西結書 13:10–16; 耶利米書 23:25–32"> 其中的先知為百姓用未泡透的灰抹牆，就是為他們見虛假的異象，用謊詐的占卜，說：『主耶和華如此說』，其實耶和華沒有說。</span>
<span className="v" id="v29" data-v="29" data-xref="以西結書 22:7; 出埃及記 23:9; 出埃及記 22:21"> 國內眾民一味地欺壓，慣行搶奪，虧負困苦窮乏的，背理欺壓寄居的。</span>
<span className="v" id="v30" data-v="30" data-xref="以賽亞書 59:16; 耶利米書 5:1; 詩篇 106:23"> 我在他們中間尋找一人重修牆垣，在我面前為這國站在破口防堵，使我不滅絕這國，卻找不着一個。</span>
<span className="v" id="v31" data-v="31" data-xref="以西結書 16:43; 以西結書 7:8–9; 以西結書 9:10"> 所以我將惱恨倒在他們身上，用烈怒的火滅了他們，照他們所行的報應在他們頭上。這是主耶和華說的。」</span>
</div>
</div>

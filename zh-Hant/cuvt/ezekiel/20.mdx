## 上帝的旨意，人的抗命

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西結書 8:1; 以西結書 30:20; 以西結書 24:1"> 第七年五月初十日，有以色列的幾個長老來求問耶和華，坐在我面前。</span>
<span className="v" id="v2" data-v="2"> 耶和華的話臨到我說：</span>
<span className="v" id="v3" data-v="3" data-xref="箴言 28:9; 馬太福音 15:8–9; 詩篇 50:15–21"> 「人子啊，你要告訴以色列的長老說，主耶和華如此說：你們來是求問我嗎？主耶和華說：我指着我的永生起誓，我必不被你們求問。</span>
<span className="v" id="v4" data-v="4" data-xref="以西結書 22:2; 以西結書 23:36; 以西結書 14:20"> 人子啊，你要審問審問他們嗎？你當使他們知道他們列祖那些可憎的事，</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 7:6; 以西結書 20:15; 出埃及記 3:8"> 對他們說，主耶和華如此說：當日我揀選以色列，向雅各家的後裔起誓，在埃及地將自己向他們顯現，說：我是耶和華－你們的上帝。</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及記 3:8; 耶利米書 32:22; 以西結書 20:15"> 那日我向他們起誓，必領他們出埃及地，到我為他們察看的流奶與蜜之地；那地在萬國中是有榮耀的。</span>
<span className="v" id="v7" data-v="7" data-xref="利未記 18:3; 以西結書 20:8; 利未記 11:44"> 我對他們說，你們各人要拋棄眼所喜愛那可憎之物，不可因埃及的偶像玷污自己。我是耶和華－你們的上帝。</span>
<span className="v" id="v8" data-v="8" data-xref="以西結書 20:7; 以賽亞書 63:10; 以西結書 20:21"> 他們卻悖逆我，不肯聽從我，不拋棄他們眼所喜愛那可憎之物，不離棄埃及的偶像。 「我就說，我要將我的忿怒傾在他們身上，在埃及地向他們成就我怒中所定的。</span>
<span className="v" id="v9" data-v="9" data-xref="以西結書 39:7; 以西結書 20:22; 出埃及記 32:12"> 我卻為我名的緣故沒有這樣行，免得我名在他們所住的列國人眼前被褻瀆；我領他們出埃及地，在這列國人的眼前將自己向他們顯現。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及記 15:22; 出埃及記 13:17–18; 出埃及記 14:17–22"> 這樣，我就使他們出埃及地，領他們到曠野，</span>
<span className="v" id="v11" data-v="11" data-xref="羅馬書 10:5; 利未記 18:5; 申命記 4:8"> 將我的律例賜給他們，將我的典章指示他們；人若遵行就必因此活着。</span>
<span className="v" id="v12" data-v="12" data-xref="以西結書 20:20; 以西結書 37:28; 利未記 21:23"> 又將我的安息日賜給他們，好在我與他們中間為證據，使他們知道我－耶和華是叫他們成為聖的。</span>
<span className="v" id="v13" data-v="13" data-xref="以西結書 20:21; 以西結書 20:8; 以賽亞書 56:6"> 以色列家卻在曠野悖逆我，不順從我的律例，厭棄我的典章（人若遵行就必因此活着），大大干犯我的安息日。 「我就說，要在曠野將我的忿怒傾在他們身上，滅絕他們。</span>
<span className="v" id="v14" data-v="14" data-xref="以西結書 20:9; 以西結書 36:22–23; 以西結書 20:22"> 我卻為我名的緣故，沒有這樣行，免得我的名在我領他們出埃及的列國人眼前被褻瀆。</span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 95:11; 詩篇 106:26; 希伯來書 3:18"> 並且我在曠野向他們起誓，必不領他們進入我所賜給他們流奶與蜜之地（那地在萬國中是有榮耀的）；</span>
<span className="v" id="v16" data-v="16" data-xref="民數記 15:39; 以西結書 20:8; 以西結書 14:3–4"> 因為他們厭棄我的典章，不順從我的律例，干犯我的安息日，他們的心隨從自己的偶像。</span>
<span className="v" id="v17" data-v="17" data-xref="以西結書 11:13; 耶利米書 4:27; 耶利米書 5:18"> 雖然如此，我眼仍顧惜他們，不毀滅他們，不在曠野將他們滅絕淨盡。</span>
<span className="v" id="v18" data-v="18" data-xref="撒迦利亞書 1:2–4; 詩篇 78:6–8; 彼得前書 1:18"> 「我在曠野對他們的兒女說：不要遵行你們父親的律例，不要謹守他們的惡規，也不要因他們的偶像玷污自己。</span>
<span className="v" id="v19" data-v="19" data-xref="以西結書 36:27; 申命記 5:32–8; 以西結書 37:24"> 我是耶和華－你們的上帝，你們要順從我的律例，謹守遵行我的典章，</span>
<span className="v" id="v20" data-v="20" data-xref="以賽亞書 58:13; 耶利米書 17:22; 出埃及記 31:13–17"> 且以我的安息日為聖。這日在我與你們中間為證據，使你們知道我是耶和華－你們的上帝。</span>
<span className="v" id="v21" data-v="21" data-xref="以西結書 20:13; 民數記 21:5; 以西結書 20:8"> 只是他們的兒女悖逆我，不順從我的律例，也不謹守遵行我的典章（人若遵行就必因此活着），干犯我的安息日。 「我就說，要將我的忿怒傾在他們身上，在曠野向他們成就我怒中所定的。</span>
<span className="v" id="v22" data-v="22" data-xref="以西結書 20:14; 以西結書 20:9; 耶利米書 14:21"> 雖然如此，我卻為我名的緣故縮手沒有這樣行，免得我的名在我領他們出埃及的列國人眼前被褻瀆。</span>
<span className="v" id="v23" data-v="23" data-xref="利未記 26:33; 申命記 28:64–68; 申命記 32:26–27"> 並且我在曠野向他們起誓，必將他們分散在列國，四散在列邦；</span>
<span className="v" id="v24" data-v="24" data-xref="以西結書 20:16; 以西結書 6:9; 阿摩司書 2:4"> 因為他們不遵行我的典章，竟厭棄我的律例，干犯我的安息日，眼目仰望他們父親的偶像。</span>
<span className="v" id="v25" data-v="25" data-xref="詩篇 81:12; 以賽亞書 66:4; 以西結書 20:39"> 我也任他們遵行不美的律例，謹守不能使人活着的惡規。</span>
<span className="v" id="v26" data-v="26" data-xref="以西結書 6:7; 利未記 18:21; 以西結書 20:31"> 因他們將一切頭生的經火，我就任憑他們在這供獻的事上玷污自己，好叫他們淒涼，使他們知道我是耶和華。</span>
<span className="v" id="v27" data-v="27" data-xref="羅馬書 2:24; 以西結書 2:7; 以西結書 3:11"> 「人子啊，你要告訴以色列家說，主耶和華如此說：你們的列祖在得罪我的事上褻瀆我；</span>
<span className="v" id="v28" data-v="28" data-xref="以西結書 6:13; 尼希米記 9:22–26; 耶利米書 3:6"> 因為我領他們到了我起誓應許賜給他們的地，他們看見各高山、各茂密樹，就在那裏獻祭，奉上惹我發怒的供物，也在那裏焚燒馨香的祭牲，並澆上奠祭。</span>
<span className="v" id="v29" data-v="29" data-xref="以西結書 16:24–25; 以西結書 16:31"> 我就對他們說：你們所上的那高處叫甚麼呢？（那高處的名字叫巴麻直到今日。）</span>
<span className="v" id="v30" data-v="30" data-xref="耶利米書 16:12; 耶利米書 7:26; 士師記 2:19"> 所以你要對以色列家說，主耶和華如此說：你們仍照你們列祖所行的玷污自己嗎？仍照他們可憎的事行邪淫嗎？</span>
<span className="v" id="v31" data-v="31" data-xref="以西結書 20:26; 詩篇 106:37–39; 耶利米書 7:31"> 你們奉上供物使你們兒子經火的時候，仍將一切偶像玷污自己，直到今日嗎？以色列家啊，我豈被你們求問嗎？主耶和華說：我指着我的永生起誓，我必不被你們求問。</span>
<span className="v" id="v32" data-v="32" data-xref="以西結書 11:5; 耶利米書 44:17; 詩篇 139:2"> 「你們說：我們要像外邦人和列國的宗族一樣，去事奉木頭與石頭。你們所起的這心意萬不能成就。」</span>
</div>
</div>

## 上帝的懲罰和赦免

<div className="bt">
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="耶利米書 21:5; 以西結書 8:18; 耶利米書 44:6"> 主耶和華說：「我指着我的永生起誓，我總要作王，用大能的手和伸出來的膀臂，並傾出來的忿怒，治理你們。</span>
<span className="v" id="v34" data-v="34" data-xref="以西結書 20:38; 阿摩司書 9:9–10; 以西結書 34:16"> 我必用大能的手和伸出來的膀臂，並傾出來的忿怒，將你們從萬民中領出來，從分散的列國內聚集你們。</span>
<span className="v" id="v35" data-v="35" data-xref="何西阿書 2:14; 耶利米書 2:35; 以西結書 17:20"> 我必帶你們到外邦人的曠野，在那裏當面刑罰你們。</span>
<span className="v" id="v36" data-v="36" data-xref="哥林多前書 10:5–10; 民數記 11:1–35; 以西結書 20:13"> 我怎樣在埃及地的曠野刑罰你們的列祖，也必照樣刑罰你們。這是主耶和華說的。</span>
<span className="v" id="v37" data-v="37" data-xref="耶利米書 33:13; 利未記 27:32; 馬太福音 25:32–33"> 我必使你們從杖下經過，使你們被約拘束。</span>
<span className="v" id="v38" data-v="38" data-xref="以西結書 13:9; 阿摩司書 9:9–10; 詩篇 95:11"> 我必從你們中間除淨叛逆和得罪我的人，將他們從所寄居的地方領出來，他們卻不得入以色列地。你們就知道我是耶和華。</span>
<span className="v" id="v39" data-v="39" data-xref="何西阿書 4:17; 以賽亞書 1:13–15; 以西結書 43:7"> 「以色列家啊，至於你們，主耶和華如此說：從此以後若不聽從我，就任憑你們去事奉偶像，只是不可再因你們的供物和偶像褻瀆我的聖名。</span>
<span className="v" id="v40" data-v="40" data-xref="以賽亞書 56:7; 瑪拉基書 3:4; 以賽亞書 60:7"> 「主耶和華說：在我的聖山，就是以色列高處的山，所有以色列的全家都要事奉我。我要在那裏悅納你們，向你們要供物和初熟的土產，並一切的聖物。</span>
<span className="v" id="v41" data-v="41" data-xref="以西結書 28:25; 以西結書 11:17; 以西結書 38:23"> 我從萬民中領你們出來，從分散的列國內聚集你們，那時我必悅納你們好像馨香之祭，要在外邦人眼前在你們身上顯為聖。</span>
<span className="v" id="v42" data-v="42" data-xref="以西結書 34:13; 以西結書 38:23; 以西結書 36:23–24"> 我領你們進入以色列地，就是我起誓應許賜給你們列祖之地，那時你們就知道我是耶和華。</span>
<span className="v" id="v43" data-v="43" data-xref="以西結書 6:9; 何西阿書 5:15; 耶利米書 31:18"> 你們在那裏要追念玷污自己的行動作為，又要因所做的一切惡事厭惡自己。</span>
<span className="v" id="v44" data-v="44" data-xref="以西結書 24:24; 詩篇 115:1; 以西結書 20:9"> 主耶和華說：以色列家啊，我為我名的緣故，不照着你們的惡行和你們的壞事待你們；你們就知道我是耶和華。」</span>
</div>
</div>

## 南方大火

<div className="bt">
<div className="bp">
<span className="v" id="v45" data-v="45"> 耶和華的話臨到我說：</span>
<span className="v" id="v46" data-v="46" data-xref="阿摩司書 7:16; 以西結書 21:2; 耶利米書 13:19"> 「人子啊，你要面向南方，向南滴下預言攻擊南方田野的樹林。</span>
<span className="v" id="v47" data-v="47" data-xref="耶利米書 21:14; 以賽亞書 24:1–6; 以西結書 17:24"> 對南方的樹林說，要聽耶和華的話。主耶和華如此說：我必使火在你中間着起，燒滅你中間的一切青樹和枯樹，猛烈的火焰必不熄滅。從南到北，人的臉面都被燒焦。</span>
<span className="v" id="v48" data-v="48" data-xref="耶利米書 40:2–3; 耶利米書 7:20; 申命記 29:24–28"> 凡有血氣的都必知道是我－耶和華使火着起，這火必不熄滅。」</span>
<span className="v" id="v49" data-v="49" data-xref="約翰福音 16:25; 使徒行傳 17:18; 以西結書 17:2"> 於是我說：「哎！主耶和華啊，人都指着我說：他豈不是說比喻的嗎？」</span>

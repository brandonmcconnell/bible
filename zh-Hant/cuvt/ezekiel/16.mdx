## 不忠實的耶路撒冷

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華的話又臨到我說：</span>
<span className="v" id="v2" data-v="2" data-xref="以西結書 22:2; 以西結書 20:4; 以賽亞書 58:1"> 「人子啊，你要使耶路撒冷知道她那些可憎的事，</span>
<span className="v" id="v3" data-v="3" data-xref="以西結書 16:45; 以賽亞書 51:1–2; 申命記 20:17"> 說主耶和華對耶路撒冷如此說：你根本，你出世，是在迦南地；你父親是亞摩利人，你母親是赫人。</span>
<span className="v" id="v4" data-v="4" data-xref="何西阿書 2:3; 創世記 15:13; 出埃及記 5:16–21"> 論到你出世的景況，在你初生的日子沒有為你斷臍帶，也沒有用水洗你，使你潔淨，絲毫沒有撒鹽在你身上，也沒有用布裹你。</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 32:10; 創世記 21:10; 出埃及記 1:22"> 誰的眼也不可憐你，為你做一件這樣的事憐恤你；但你初生的日子扔在田野，是因你被厭惡。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="以弗所書 2:4–5; 約翰福音 5:25; 提多書 3:3–7"> 「我從你旁邊經過，見你滾在血中，就對你說：你雖在血中，仍可存活；你雖在血中，仍可存活。</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 1:10; 出埃及記 1:7; 以賽亞書 62:3"> 我使你生長好像田間所長的，你就漸漸長大，以致極其俊美，兩乳成形，頭髮長成，你卻仍然赤身露體。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="路得記 3:9; 耶利米書 2:2–3; 羅馬書 5:8"> 「我從你旁邊經過，看見你的時候正動愛情，便用衣襟搭在你身上，遮蓋你的赤體；又向你起誓，與你結盟，你就歸於我。這是主耶和華說的。</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 23:5; 路得記 3:3; 約翰一書 2:27"> 那時我用水洗你，洗淨你身上的血，又用油抹你。</span>
<span className="v" id="v10" data-v="10" data-xref="以西結書 16:18; 以西結書 16:13; 以賽亞書 61:10"> 我也使你身穿繡花衣服，腳穿海狗皮鞋，並用細麻布給你束腰，用絲綢為衣披在你身上，</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 24:22; 以賽亞書 3:19; 創世記 41:42"> 又用妝飾打扮你，將鐲子戴在你手上，將金鍊戴在你項上。</span>
<span className="v" id="v12" data-v="12" data-xref="以賽亞書 3:21; 以賽亞書 28:5; 耶利米書 13:18"> 我也將環子戴在你鼻子上，將耳環戴在你耳朵上，將華冠戴在你頭上。</span>
<span className="v" id="v13" data-v="13" data-xref="申命記 32:13–14; 詩篇 50:2; 列王紀上 4:21"> 這樣，你就有金銀的妝飾，穿的是細麻衣和絲綢，並繡花衣；吃的是細麵、蜂蜜，並油。你也極其美貌，發達到王后的尊榮。</span>
<span className="v" id="v14" data-v="14" data-xref="列王紀上 10:24; 耶利米哀歌 2:15; 哥林多前書 4:7"> 你美貌的名聲傳在列邦中，你十分美貌，是因我加在你身上的威榮。這是主耶和華說的。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="以賽亞書 57:8; 耶利米書 2:20; 以西結書 16:25"> 「只是你仗着自己的美貌，又因你的名聲就行邪淫。你縱情淫亂，使過路的任意而行。</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀下 23:7; 以西結書 7:20; 歷代志下 28:24"> 你用衣服為自己在高處結彩，在其上行邪淫。這樣的事將來必沒有，也必不再行了。</span>
<span className="v" id="v17" data-v="17" data-xref="以西結書 23:14–21; 耶利米書 3:9; 以西結書 16:11"> 你又將我所給你那華美的金銀、寶器為自己製造人像，與他行邪淫；</span>
<span className="v" id="v18" data-v="18"> 又用你的繡花衣服給他披上，並將我的膏油和香料擺在他跟前；</span>
<span className="v" id="v19" data-v="19" data-xref="以西結書 16:13; 何西阿書 2:8–13; 創世記 8:21"> 又將我賜給你的食物，就是我賜給你吃的細麵、油，和蜂蜜，都擺在他跟前為馨香的供物。這是主耶和華說的。</span>
<span className="v" id="v20" data-v="20" data-xref="以西結書 23:37; 以西結書 20:31; 耶利米書 7:31"> 並且你將給我所生的兒女焚獻給他。</span>
<span className="v" id="v21" data-v="21" data-xref="列王紀下 17:17; 利未記 18:21; 申命記 18:10"> 你行淫亂豈是小事，竟將我的兒女殺了，使他們經火歸與他嗎？</span>
<span className="v" id="v22" data-v="22" data-xref="耶利米書 2:2; 何西阿書 11:1; 以西結書 16:43"> 你行這一切可憎和淫亂的事，並未追念你幼年赤身露體滾在血中的日子。」</span>
</div>
</div>

## 耶路撒冷像淫婦

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="啟示錄 12:12; 以西結書 2:10; 以西結書 24:6"> 「你行這一切惡事之後（主耶和華說：你有禍了！有禍了！）</span>
<span className="v" id="v24" data-v="24" data-xref="詩篇 78:58; 以西結書 16:39; 以西結書 16:31"> 又為自己建造圓頂花樓，在各街上做了高臺。</span>
<span className="v" id="v25" data-v="25" data-xref="以西結書 16:31; 耶利米書 3:2; 創世記 38:21"> 你在一切市口上建造高臺，使你的美貌變為可憎的，又與一切過路的多行淫亂。</span>
<span className="v" id="v26" data-v="26" data-xref="以西結書 23:19–21; 以西結書 20:7–8; 以西結書 8:10"> 你也和你鄰邦放縱情慾的埃及人行淫，加增你的淫亂，惹我發怒。</span>
<span className="v" id="v27" data-v="27" data-xref="以賽亞書 9:12; 以西結書 16:57; 以西結書 16:37"> 因此我伸手攻擊你，減少你應用的糧食，又將你交給恨你的非利士眾女<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="眾女是城邑的意思；本章下同">a</a></sup>，使她們任意待你。她們見你的淫行，為你羞恥。</span>
<span className="v" id="v28" data-v="28" data-xref="列王紀下 16:7; 何西阿書 10:6; 列王紀下 16:10–18"> 你因貪色無厭，又與亞述人行淫，與他們行淫之後，仍不滿意，</span>
<span className="v" id="v29" data-v="29" data-xref="列王紀下 21:9; 士師記 2:12–19; 以西結書 13:14–23"> 並且多行淫亂，直到那貿易之地，就是迦勒底，你仍不滿意。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="耶利米書 3:3; 以賽亞書 1:3; 以賽亞書 3:9"> 「主耶和華說：你行這一切事，都是不知羞恥妓女所行的，可見你的心是何等懦弱！</span>
<span className="v" id="v31" data-v="31" data-xref="以西結書 16:33–34; 以賽亞書 52:3; 以西結書 16:39"> 因你在一切市口上建造圓頂花樓，在各街上做了高臺，你卻藐視賞賜，不像妓女。</span>
<span className="v" id="v32" data-v="32" data-xref="耶利米書 2:28; 以西結書 23:37; 耶利米書 2:25"> 哎！你這行淫的妻啊，寧肯接外人，不接丈夫。</span>
<span className="v" id="v33" data-v="33" data-xref="以賽亞書 57:9; 何西阿書 8:9–10; 以西結書 16:41"> 凡妓女是得人贈送，你反倒贈送你所愛的人，賄賂他們從四圍來與你行淫。</span>
<span className="v" id="v34" data-v="34"> 你行淫與別的婦女相反，因為不是人從你行淫；你既贈送人，人並不贈送你；所以你與別的婦女相反。」</span>
</div>
</div>

## 上帝審判耶路撒冷

<div className="bt">
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="約翰福音 4:18; 列王紀上 22:19; 約翰福音 4:10"> 「你這妓女啊，要聽耶和華的話。</span>
<span className="v" id="v36" data-v="36" data-xref="以西結書 23:10; 以西結書 24:13; 西番雅書 3:1"> 主耶和華如此說：因你的污穢傾洩了，你與你所愛的行淫露出下體，又因你拜一切可憎的偶像，流兒女的血獻給他，</span>
<span className="v" id="v37" data-v="37" data-xref="何西阿書 2:10; 耶利米書 13:22; 何西阿書 2:3"> 我就要將你一切相歡相愛的和你一切所恨的都聚集來，從四圍攻擊你；又將你的下體露出，使他們看盡了。</span>
<span className="v" id="v38" data-v="38" data-xref="利未記 20:10; 創世記 9:6; 西番雅書 1:17"> 我也要審判你，好像官長審判淫婦和流人血的婦女一樣。我因忿怒忌恨，使流血的罪歸到你身上。</span>
<span className="v" id="v39" data-v="39" data-xref="以西結書 23:26; 何西阿書 2:3; 以西結書 16:24–25"> 我又要將你交在他們手中；他們必拆毀你的圓頂花樓，毀壞你的高臺，剝去你的衣服，奪取你的華美寶器，留下你赤身露體。</span>
<span className="v" id="v40" data-v="40" data-xref="以西結書 23:47; 哈巴谷書 1:6–10; 約翰福音 8:5–7"> 他們也必帶多人來攻擊你，用石頭打死你，用刀劍刺透你，</span>
<span className="v" id="v41" data-v="41" data-xref="以西結書 23:48; 耶利米書 52:13; 耶利米書 39:8"> 用火焚燒你的房屋，在許多婦人眼前向你施行審判。我必使你不再行淫，也不再贈送與人。</span>
<span className="v" id="v42" data-v="42" data-xref="以西結書 5:13; 以西結書 21:17; 以賽亞書 40:1–2"> 這樣，我就止息向你發的忿怒，我的忌恨也要離開你，我要安靜不再惱怒。</span>
<span className="v" id="v43" data-v="43" data-xref="以西結書 16:22; 以西結書 11:21; 詩篇 78:42"> 因你不追念你幼年的日子，在這一切的事上向我發烈怒，所以我必照你所行的報應在你頭上，你就不再貪淫，行那一切可憎的事。這是主耶和華說的。」</span>
</div>
</div>

## 有其母必有其女

<div className="bt">
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="以西結書 18:2–3; 詩篇 106:35–38; 撒母耳記上 24:13"> 「凡說俗語的必用俗語攻擊你，說：『母親怎樣，女兒也怎樣。』</span>
<span className="v" id="v45" data-v="45" data-xref="撒迦利亞書 11:8; 以賽亞書 1:4; 以西結書 23:37–39"> 你正是你母親的女兒，厭棄丈夫和兒女；你正是你姊妹的姊妹，厭棄丈夫和兒女。你母親是赫人，你父親是亞摩利人。</span>
<span className="v" id="v46" data-v="46" data-xref="以西結書 23:4; 以西結書 16:48–49; 以西結書 16:53–56"> 你的姊姊是撒馬利亞，她和她的眾女住在你左邊；你的妹妹是所多瑪，她和她的眾女住在你右邊。</span>
<span className="v" id="v47" data-v="47" data-xref="列王紀下 21:9; 以西結書 16:51; 以西結書 5:6–7"> 你沒有效法她們的行為，也沒有照她們可憎的事去做，你以那為小事，你一切所行的倒比她們更壞。</span>
<span className="v" id="v48" data-v="48" data-xref="馬太福音 10:15; 路加福音 10:12; 使徒行傳 7:52"> 主耶和華說：我指着我的永生起誓，你妹妹所多瑪與她的眾女尚未行你和你眾女所行的事。</span>
<span className="v" id="v49" data-v="49" data-xref="詩篇 138:6; 以西結書 28:2; 創世記 13:10"> 看哪，你妹妹所多瑪的罪孽是這樣：她和她的眾女都心驕氣傲，糧食飽足，大享安逸，並沒有扶助困苦和窮乏人的手。</span>
<span className="v" id="v50" data-v="50" data-xref="創世記 19:24; 創世記 18:20; 創世記 19:5"> 她們狂傲，在我面前行可憎的事，我看見便將她們除掉。</span>
<span className="v" id="v51" data-v="51" data-xref="耶利米書 3:8–11; 路加福音 12:47–48; 羅馬書 3:9–20"> 撒馬利亞沒有犯你一半的罪，你行可憎的事比她更多，使你的姊妹因你所行一切可憎的事，倒顯為義。</span>
<span className="v" id="v52" data-v="52" data-xref="馬太福音 7:1–5; 以西結書 36:15; 以西結書 16:56"> 你既斷定你姊妹為義<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="為義：或譯當受羞辱">b</a></sup>，就要擔當自己的羞辱；因你所犯的罪比她們更為可憎，她們就比你更顯為義；你既使你的姊妹顯為義，你就要抱愧擔當自己的羞辱。」</span>
</div>
</div>

## 所多瑪、撒馬利亞要復興

<div className="bt">
<div className="bp">
<span className="v" id="v53" data-v="53" data-xref="以西結書 29:14; 耶利米書 12:16; 以西結書 39:25"> 「我必叫她們被擄的歸回，就是叫所多瑪和她的眾女，撒馬利亞和她的眾女，並你們中間被擄的，都要歸回，</span>
<span className="v" id="v54" data-v="54" data-xref="以西結書 14:22–23; 耶利米書 2:26; 以西結書 36:31–32"> 好使你擔當自己的羞辱，並因你一切所行的使她們得安慰，你就抱愧。</span>
<span className="v" id="v55" data-v="55" data-xref="以西結書 36:11; 瑪拉基書 3:4; 以西結書 16:53"> 你的妹妹所多瑪和她的眾女必歸回原位；撒馬利亞和她的眾女，你和你的眾女，也必歸回原位。</span>
<span className="v" id="v56" data-v="56" data-xref="以賽亞書 65:5; 路加福音 15:28–30; 西番雅書 3:11"> 在你驕傲的日子，你的惡行沒有顯露以先，你的口就不提你的妹妹所多瑪。那受了凌辱的亞蘭眾女和亞蘭四圍非利士的眾女都恨惡你，藐視你。</span>
<span className="v" id="v58" data-v="58" data-xref="以西結書 23:49; 耶利米哀歌 5:7; 創世記 4:13"> 耶和華說：你貪淫和可憎的事，你已經擔當了。」</span>
</div>
</div>

## 永遠的約

<div className="bt">
<div className="bp">
<span className="v" id="v59" data-v="59" data-xref="以賽亞書 24:5; 以西結書 17:19; 申命記 29:25"> 「主耶和華如此說：你這輕看誓言、背棄盟約的，我必照你所行的待你。</span>
<span className="v" id="v60" data-v="60" data-xref="何西阿書 2:19–20; 希伯來書 12:24; 以西結書 16:8"> 然而我要追念在你幼年時與你所立的約，也要與你立定永約。</span>
<span className="v" id="v61" data-v="61" data-xref="希伯來書 8:13; 加拉太書 4:26–31; 以賽亞書 66:7–12"> 你接待你姊姊和你妹妹的時候，你要追念你所行的，自覺慚愧；並且我要將她們賜你為女兒，卻不是按着前約。</span>
<span className="v" id="v62" data-v="62" data-xref="耶利米書 24:7; 以西結書 6:7; 以西結書 39:22"> 我要堅定與你所立的約（你就知道我是耶和華），</span>
<span className="v" id="v63" data-v="63" data-xref="詩篇 39:9; 羅馬書 3:19; 以西結書 36:31–32"> 好使你在我赦免你一切所行的時候，心裏追念，自覺抱愧，又因你的羞辱就不再開口。這是主耶和華說的。」</span>
</div>

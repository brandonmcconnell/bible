## 耶和華的刀

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1"> 耶和華的話臨到我說：</span>
<span className="v" id="v2" data-v="2" data-xref="以西結書 20:46; 以西結書 4:7; 以西結書 25:2"> 「人子啊，你要面向耶路撒冷和聖所滴下預言，攻擊以色列地。</span>
<span className="v" id="v3" data-v="3" data-xref="約伯記 9:22; 耶利米書 21:13; 以西結書 5:8"> 對以色列地說，耶和華如此說：我與你為敵，並要拔刀出鞘，從你中間將義人和惡人一併剪除。</span>
<span className="v" id="v4" data-v="4" data-xref="以西結書 20:47; 以西結書 7:2; 以西結書 6:11–14"> 我既要從你中間剪除義人和惡人，所以我的刀要出鞘，自南至北攻擊一切有血氣的；</span>
<span className="v" id="v5" data-v="5" data-xref="以西結書 21:30; 那鴻書 1:9; 撒母耳記上 3:12"> 一切有血氣的就知道我－耶和華已經拔刀出鞘，必不再入鞘。</span>
<span className="v" id="v6" data-v="6" data-xref="以賽亞書 22:4; 以西結書 6:11; 耶利米書 19:10"> 人子啊，你要歎息，在他們眼前彎着腰，苦苦地歎息。</span>
<span className="v" id="v7" data-v="7" data-xref="以西結書 7:17; 以西結書 7:26; 以賽亞書 13:7"> 他們問你說：『為何歎息呢？』你就說：『因為有風聲、災禍要來。人心都必消化，手都發軟，精神衰敗，膝弱如水。看哪，這災禍臨近，必然成就。這是主耶和華說的。』」</span>
<span className="v" id="v8" data-v="8"> 耶和華的話臨到我說：</span>
<span className="v" id="v9" data-v="9" data-xref="以賽亞書 34:5–6; 以西結書 21:28; 以西結書 21:3"> 「人子啊，你要預言。耶和華吩咐我如此說：<br /><span className="pl pl-1">有刀、有刀，</span><br /><span className="pl pl-1">是磨快擦亮的；</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 110:5–6; 以西結書 20:47; 以西結書 21:25–27"> <span className="pl pl-1">磨快為要行殺戮，</span><br /><span className="pl pl-1">擦亮為要像閃電。</span>我們豈可快樂嗎？罰我子的杖藐視各樹。</span>
<span className="v" id="v11" data-v="11" data-xref="以西結書 21:19; 耶利米書 25:33; 耶利米書 51:20–23"> 這刀已經交給人擦亮，為要應手使用。這刀已經磨快擦亮，好交在行殺戮的人手中。</span>
<span className="v" id="v12" data-v="12" data-xref="以西結書 21:6; 約珥書 1:13; 以西結書 21:14"> 人子啊，你要呼喊哀號，因為這刀臨到我的百姓和以色列一切的首領。他們和我的百姓都交在刀下，所以你要拍腿歎息。</span>
<span className="v" id="v13" data-v="13" data-xref="以西結書 21:10; 哥林多後書 8:2; 以西結書 21:25"> 有試驗的事；若那藐視的杖歸於無有，怎麼樣呢？這是主耶和華說的。</span>
<span className="v" id="v14" data-v="14" data-xref="列王紀下 24:1; 民數記 24:10; 利未記 26:24"> 「人子啊，你要拍掌預言。我－耶和華要使這刀，就是致死傷的刀，一連三次加倍刺人，進入他們的內屋，使大人受死傷的就是這刀。</span>
<span className="v" id="v15" data-v="15" data-xref="以西結書 21:10; 耶利米書 17:27; 以西結書 21:22"> 我設立這恐嚇人的刀，攻擊他們的一切城門，使他們的心消化，加增他們跌倒的事。哎！這刀造得像閃電，磨得尖利，要行殺戮。</span>
<span className="v" id="v16" data-v="16" data-xref="以西結書 21:20; 以西結書 21:4; 以西結書 14:17"> 刀啊，你歸在右邊，擺在左邊；你面向哪方，就向那方殺戮。</span>
<span className="v" id="v17" data-v="17" data-xref="以西結書 5:13; 以西結書 21:14; 撒迦利亞書 6:8"> 我也要拍掌，並要使我的忿怒止息。這是我－耶和華說的。」</span>
</div>
</div>

## 巴比倫王的刀

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18"> 耶和華的話又臨到我說：</span>
<span className="v" id="v19" data-v="19" data-xref="以西結書 4:1–3; 耶利米書 1:10; 以西結書 5:1–17"> 「人子啊，你要定出兩條路，好使巴比倫王的刀來。這兩條路必從一地分出來，又要在通城的路口上畫出一隻手來。</span>
<span className="v" id="v20" data-v="20" data-xref="阿摩司書 1:14; 耶利米書 49:2; 以西結書 25:5"> 你要定出一條路，使刀來到亞捫人的拉巴；又要定出一條路，使刀來到猶大的堅固城耶路撒冷。</span>
<span className="v" id="v21" data-v="21" data-xref="士師記 18:20; 箴言 16:33; 士師記 17:5"> 因為巴比倫王站在岔路那裏，在兩條路口上要占卜。他搖籤<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是箭">a</a></sup>求問神像，察看犧牲的肝；</span>
<span className="v" id="v22" data-v="22" data-xref="以西結書 4:2; 以西結書 26:9; 耶利米書 51:14"> 在右手中拿着為耶路撒冷占卜的籤，使他安設撞城錘，張口叫殺，揚聲吶喊，築壘造臺，以撞城錘，攻打城門。</span>
<span className="v" id="v23" data-v="23" data-xref="民數記 5:15; 以西結書 21:24; 以西結書 29:16"> 據那些曾起誓的猶大人看來，這是虛假的占卜；但巴比倫王要使他們想起罪孽，以致將他們捉住。」</span>
<span className="v" id="v24" data-v="24" data-xref="何西阿書 4:2; 彌迦書 3:10–12; 耶利米書 3:2"> 主耶和華如此說：「因你們的過犯顯露，使你們的罪孽被記念，以致你們的罪惡在行為上都彰顯出來；又因你們被記念，就被捉住。</span>
<span className="v" id="v25" data-v="25" data-xref="以西結書 35:5; 以西結書 21:29; 以西結書 17:19"> 你這受死傷行惡的以色列王啊，罪孽的盡頭到了，受報的日子已到。</span>
<span className="v" id="v26" data-v="26" data-xref="以西結書 17:24; 詩篇 75:7; 耶利米書 13:18"> 主耶和華如此說：當除掉冠，摘下冕，景況必不再像先前；要使卑者升為高，使高者降為卑。</span>
<span className="v" id="v27" data-v="27" data-xref="彌迦書 5:2; 耶利米書 23:5–6; 撒迦利亞書 9:9"> 我要將這國傾覆，傾覆，而又傾覆；這國也必不再有，直等到那應得的人來到，我就賜給他。」</span>
</div>
</div>

## 刀和亞捫人

<div className="bt">
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="以西結書 21:20; 以西結書 21:9–10; 西番雅書 2:8–10"> 「人子啊，要發預言說：主耶和華論到亞捫人和他們的凌辱，吩咐我如此說：有刀，有拔出來的刀，已經擦亮，為行殺戮，使他像閃電以行吞滅。</span>
<span className="v" id="v29" data-v="29" data-xref="以西結書 21:25; 以西結書 22:28; 詩篇 37:13"> 人為你見虛假的異象，行謊詐的占卜，使你倒在受死傷之惡人的頸項上。他們罪孽到了盡頭，受報的日子已到。</span>
<span className="v" id="v30" data-v="30" data-xref="以西結書 16:38; 創世記 15:14; 耶利米書 47:6–7"> 你將刀收入鞘吧！在你受造之處、生長之地，我必刑罰你。</span>
<span className="v" id="v31" data-v="31" data-xref="那鴻書 1:6; 耶利米書 6:22–23; 以西結書 14:19"> 我必將我的惱恨倒在你身上，將我烈怒的火噴在你身上；又將你交在善於殺滅的畜類人手中。</span>
<span className="v" id="v32" data-v="32" data-xref="以西結書 25:10; 瑪拉基書 4:1; 以西結書 20:47–48"> 你必當柴被火焚燒；你的血必流在國中。你必不再被記念，因為這是我－耶和華說的。」</span>
</div>

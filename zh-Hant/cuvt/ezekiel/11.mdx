## 耶路撒冷被判罪

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西結書 3:14; 以西結書 11:24; 以西結書 11:13"> 靈將我舉起，帶到耶和華殿向東的東門。誰知，在門口有二十五個人，我見其中有民間的首領押朔的兒子雅撒尼亞和比拿雅的兒子毗拉提。</span>
<span className="v" id="v2" data-v="2" data-xref="以賽亞書 30:1; 耶利米書 5:5; 詩篇 2:1–2"> 耶和華對我說：「人子啊，這就是圖謀罪孽的人，在這城中給人設惡謀。</span>
<span className="v" id="v3" data-v="3" data-xref="以西結書 12:27; 以西結書 12:22; 以西結書 11:7–11"> 他們說：『蓋房屋的時候尚未臨近；這城是鍋，我們是肉。』</span>
<span className="v" id="v4" data-v="4" data-xref="以西結書 20:46–47; 以西結書 21:2; 以西結書 3:2–15"> 人子啊，因此你當說預言，說預言攻擊他們。」</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米書 17:10; 耶利米書 16:17; 啟示錄 2:23"> 耶和華的靈降在我身上，對我說：「你當說，耶和華如此說：以色列家啊，你們口中所說的，心裏所想的，我都知道。</span>
<span className="v" id="v6" data-v="6" data-xref="以西結書 7:23; 以西結書 22:27; 以西結書 22:12"> 你們在這城中殺人增多，使被殺的人充滿街道。</span>
<span className="v" id="v7" data-v="7" data-xref="以西結書 24:3–13; 彌迦書 3:2–3; 列王紀下 25:18–22"> 所以主耶和華如此說：你們殺在城中的人就是肉，這城就是鍋；你們卻要從其中被帶出去。</span>
<span className="v" id="v8" data-v="8" data-xref="箴言 10:24; 以賽亞書 24:17–18; 約伯記 3:25"> 你們怕刀劍，我必使刀劍臨到你們。這是主耶和華說的。</span>
<span className="v" id="v9" data-v="9" data-xref="以西結書 5:8; 詩篇 106:41; 申命記 28:36"> 我必從這城中帶出你們去，交在外邦人的手中，且要在你們中間施行審判。</span>
<span className="v" id="v10" data-v="10" data-xref="列王紀下 14:25; 耶利米書 52:9–10; 列王紀下 25:19–21"> 你們必倒在刀下；我必在以色列的境界審判你們，你們就知道我是耶和華。</span>
<span className="v" id="v11" data-v="11" data-xref="以西結書 11:3; 以西結書 11:7–10"> 這城必不作你們的鍋，你們也不作其中的肉。我必在以色列的境界審判你們，</span>
<span className="v" id="v12" data-v="12" data-xref="以西結書 8:10; 以西結書 8:16; 以西結書 8:14"> 你們就知道我是耶和華；因為你們沒有遵行我的律例，也沒有順從我的典章，卻隨從你們四圍列國的惡規。」</span>
<span className="v" id="v13" data-v="13" data-xref="以西結書 11:1; 以西結書 9:8; 使徒行傳 5:5"> 我正說預言的時候，比拿雅的兒子毗拉提死了。於是我俯伏在地，大聲呼叫說：「哎！主耶和華啊，你要將以色列剩下的人滅絕淨盡嗎？」</span>
</div>
</div>

## 上帝對流亡者的應許

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14"> 耶和華的話臨到我說：</span>
<span className="v" id="v15" data-v="15" data-xref="以西結書 33:24; 以賽亞書 65:5; 約翰福音 16:2"> 「人子啊，耶路撒冷的居民對你的弟兄、你的本族、你的親屬、以色列全家，就是對大眾說：『你們遠離耶和華吧！這地是賜給我們為業的。』</span>
<span className="v" id="v16" data-v="16" data-xref="以賽亞書 8:14; 申命記 30:3–4; 詩篇 90:1"> 所以你當說：『耶和華如此說：我雖將以色列全家遠遠遷移到列國中，將他們分散在列邦內，我還要在他們所到的列邦，暫作他們的聖所。』</span>
<span className="v" id="v17" data-v="17" data-xref="以西結書 28:25; 耶利米書 3:18; 以西結書 34:13"> 你當說：『主耶和華如此說：我必從萬民中招聚你們，從分散的列國內聚集你們，又要將以色列地賜給你們。』</span>
<span className="v" id="v18" data-v="18" data-xref="以西結書 37:23; 以西結書 5:11; 以西結書 42:7–8"> 他們必到那裏，也必從其中除掉一切可憎可厭的物。</span>
<span className="v" id="v19" data-v="19" data-xref="以西結書 36:26–27; 耶利米書 31:33; 詩篇 51:10"> 我要使他們有合一的心，也要將新靈放在他們裏面，又從他們肉體中除掉石心，賜給他們肉心，</span>
<span className="v" id="v20" data-v="20" data-xref="以西結書 14:11; 詩篇 105:45; 耶利米書 30:22"> 使他們順從我的律例，謹守遵行我的典章。他們要作我的子民，我要作他們的上帝。</span>
<span className="v" id="v21" data-v="21" data-xref="以西結書 9:10; 傳道書 11:9; 耶利米書 1:16"> 至於那些心中隨從可憎可厭之物的，我必照他們所行的報應在他們頭上。這是主耶和華說的。」</span>
</div>
</div>

## 上帝的榮耀離開耶路撒冷

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="以西結書 10:19; 以西結書 1:19–20"> 於是，基路伯展開翅膀，輪子都在他們旁邊；在他們以上有以色列上帝的榮耀。</span>
<span className="v" id="v23" data-v="23" data-xref="撒迦利亞書 14:4; 以西結書 8:4; 以西結書 10:4"> 耶和華的榮耀從城中上升，停在城東的那座山上。</span>
<span className="v" id="v24" data-v="24" data-xref="以西結書 3:12; 以西結書 8:3; 以西結書 11:1"> 靈將我舉起，在異象中藉着上帝的靈將我帶進迦勒底地，到被擄的人那裏；我所見的異象就離我上升去了。</span>
<span className="v" id="v25" data-v="25" data-xref="以西結書 3:4; 以西結書 3:27; 以西結書 3:17"> 我便將耶和華所指示我的一切事都說給被擄的人聽。</span>
</div>

## 歌革－耶和華的工具

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華的話臨到我說：</span>
<span className="v" id="v2" data-v="2" data-xref="以西結書 39:1; 以西結書 27:13; 以西結書 38:3"> 「人子啊，你要面向瑪各地的歌革，就是羅施、米設、土巴的王發預言攻擊他，</span>
<span className="v" id="v3" data-v="3" data-xref="以西結書 13:8; 以西結書 39:1–10; 以西結書 29:3"> 說主耶和華如此說：羅施、米設、土巴的王歌革啊，我與你為敵。</span>
<span className="v" id="v4" data-v="4" data-xref="以西結書 29:4; 但以理書 11:40; 以西結書 38:15"> 我必用鉤子鉤住你的腮頰，調轉你，將你和你的軍兵、馬匹、馬兵帶出來，都披掛整齊，成了大隊，有大小盾牌，各拿刀劍。</span>
<span className="v" id="v5" data-v="5" data-xref="以西結書 27:10; 創世記 10:6; 以西結書 30:5"> 波斯人、古實人，和弗人<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="又作利比亞人">a</a></sup>，各拿盾牌，頭上戴盔；</span>
<span className="v" id="v6" data-v="6" data-xref="以西結書 27:14; 創世記 10:2–3; 歷代志上 1:5–6"> 歌篾人和他的軍隊，北方極處的陀迦瑪族和他的軍隊，這許多國的民都同着你。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="歷代志下 25:8; 約珥書 3:9–12; 以賽亞書 37:22"> 「那聚集到你這裏的各隊都當準備；你自己也要準備，作他們的大帥。</span>
<span className="v" id="v8" data-v="8" data-xref="以西結書 38:16; 以賽亞書 24:22; 以西結書 38:11–12"> 過了多日，你必被差派。到末後之年，你必來到脫離刀劍從列國收回之地，到以色列常久荒涼的山上；但那從列國中招聚出來的必在其上安然居住。</span>
<span className="v" id="v9" data-v="9" data-xref="以賽亞書 28:2; 耶利米書 4:13; 約珥書 2:2"> 你和你的軍隊，並同着你許多國的民，必如暴風上來，如密雲遮蓋地面。」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="詩篇 36:4; 彌迦書 2:1; 詩篇 83:3–4"> 主耶和華如此說：「到那時，你心必起意念，圖謀惡計，</span>
<span className="v" id="v11" data-v="11" data-xref="撒迦利亞書 2:4–5; 箴言 3:29–30; 耶利米書 49:31–32"> 說：『我要上那無城牆的鄉村，我要到那安靜的民那裏，他們都沒有城牆，無門、無閂，安然居住。</span>
<span className="v" id="v12" data-v="12" data-xref="以賽亞書 10:6; 以西結書 38:8; 以西結書 29:19"> 我去要搶財為擄物，奪貨為掠物，反手攻擊那從前荒涼、現在有人居住之地，又攻擊那住世界中間、從列國招聚、得了牲畜財貨的民。』</span>
<span className="v" id="v13" data-v="13" data-xref="以西結書 27:15; 以西結書 27:22–23; 以西結書 32:2"> 示巴人、底但人、他施的客商，和其間的少壯獅子都必問你說：『你來要搶財為擄物嗎？你聚集軍隊要奪貨為掠物嗎？要奪取金銀，擄去牲畜、財貨嗎？要搶奪許多財寶為擄物嗎？』</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="以西結書 38:8; 撒迦利亞書 2:5; 耶利米書 23:6"> 「人子啊，你要因此發預言，對歌革說，主耶和華如此說：到我民以色列安然居住之日，你豈不知道嗎？</span>
<span className="v" id="v15" data-v="15" data-xref="以西結書 39:2; 以西結書 38:6; 啟示錄 20:8"> 你必從本地，從北方的極處率領許多國的民來，都騎着馬，乃一大隊極多的軍兵。</span>
<span className="v" id="v16" data-v="16" data-xref="以西結書 39:21; 以西結書 38:23; 何西阿書 3:5"> 歌革啊，你必上來攻擊我的民以色列，如密雲遮蓋地面。末後的日子，我必帶你來攻擊我的地，到我在外邦人眼前，在你身上顯為聖的時候，好叫他們認識我。</span>
<span className="v" id="v17" data-v="17" data-xref="但以理書 11:40–45; 以賽亞書 63:1–6; 約珥書 3:9–14"> 主耶和華如此說：我在古時藉我的僕人以色列的先知所說的，就是你嗎？當日他們多年預言我必帶你來攻擊以色列人。」</span>
</div>
</div>

## 上帝懲罰歌革

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="以西結書 36:5–6; 希伯來書 12:29; 詩篇 89:46"> 主耶和華說：「歌革上來攻擊以色列地的時候，我的怒氣要從鼻孔裏發出。</span>
<span className="v" id="v19" data-v="19" data-xref="哈該書 2:6–7; 啟示錄 11:13; 啟示錄 16:20"> 我發憤恨和烈怒如火說：那日在以色列地必有大震動，</span>
<span className="v" id="v20" data-v="20" data-xref="何西阿書 4:3; 那鴻書 1:4–6; 啟示錄 6:12–13"> 甚至海中的魚、天空的鳥、田野的獸，並地上的一切昆蟲，和其上的眾人，因見我的面就都震動；山嶺必崩裂，陡巖必塌陷，牆垣都必坍倒。」</span>
<span className="v" id="v21" data-v="21" data-xref="哈該書 2:22; 士師記 7:22; 以西結書 14:17"> 主耶和華說：「我必命我的諸山發刀劍來攻擊歌革；人都要用刀劍殺害弟兄。</span>
<span className="v" id="v22" data-v="22" data-xref="以賽亞書 66:16; 詩篇 11:6; 啟示錄 16:21"> 我必用瘟疫和流血的事刑罰他。我也必將暴雨、大雹與火，並硫磺降與他和他的軍隊，並他所率領的眾民。</span>
<span className="v" id="v23" data-v="23" data-xref="詩篇 9:16; 啟示錄 19:1–6; 以西結書 38:16"> 我必顯為大，顯為聖，在多國人的眼前顯現；他們就知道我是耶和華。」</span>
</div>
</div>

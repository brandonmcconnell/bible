## 以香柏樹比擬埃及

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="以西結書 30:20; 耶利米書 52:5–6; 以西結書 1:2"> 十一年三月初一日，耶和華的話臨到我說：</span>
<span className="v" id="v2" data-v="2" data-xref="以西結書 29:19; 以西結書 30:10; 以西結書 31:18"> 「人子啊，你要向埃及王法老和他的眾人說：<br /><span className="pl pl-1">在威勢上誰能與你相比呢？</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="以賽亞書 10:33–34; 但以理書 4:10; 但以理書 4:20–23"> <span className="pl pl-1">亞述王曾如黎巴嫩中的香柏樹，</span><br /><span className="pl pl-1">枝條榮美，影密如林，</span><br /><span className="pl pl-1">極其高大，樹尖插入雲中。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="啟示錄 17:15; 箴言 14:28; 以西結書 17:5"> <span className="pl pl-1">眾水使它生長；</span><br /><span className="pl pl-1">深水使它長大。</span><br /><span className="pl pl-1">所栽之地有江河圍流，</span><br /><span className="pl pl-1">汊出的水道延到田野諸樹。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="但以理書 4:11; 以西結書 17:5; 詩篇 1:3"> <span className="pl pl-1">所以它高大超過田野諸樹；</span><br /><span className="pl pl-1">發旺的時候，枝子繁多，</span><br /><span className="pl pl-1">因得大水之力枝條長長。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="以西結書 17:23; 馬太福音 13:32; 但以理書 4:12"> <span className="pl pl-1">空中的飛鳥都在枝子上搭窩；</span><br /><span className="pl pl-1">田野的走獸都在枝條下生子；</span><br /><span className="pl pl-1">所有大國的人民都在它蔭下居住。</span><br /></span>
<span className="v" id="v7" data-v="7"> <span className="pl pl-1">樹大條長，成為榮美，</span><br /><span className="pl pl-1">因為根在眾水之旁。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="以西結書 28:13; 創世記 13:10; 以賽亞書 51:3"> <span className="pl pl-1">上帝園中的香柏樹不能遮蔽它；</span><br /><span className="pl pl-1">松樹不及它的枝子；</span><br /><span className="pl pl-1">楓樹不及它的枝條；</span><br /><span className="pl pl-1">上帝園中的樹都沒有它榮美。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="以西結書 28:13; 但以理書 2:37–38; 創世記 13:10"> <span className="pl pl-1">我使它的枝條蕃多，成為榮美，</span><br /><span className="pl pl-1">以致上帝伊甸園中的樹都嫉妒它。」</span></span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="以西結書 28:17; 但以理書 5:20; 歷代志下 32:25"> 所以主耶和華如此說：「因它高大，樹尖插入雲中，心驕氣傲，</span>
<span className="v" id="v11" data-v="11" data-xref="以西結書 32:11–12; 那鴻書 3:18; 但以理書 5:18–19"> 我就必將它交給列國中大有威勢的人；他必定辦它。我因它的罪惡，已經驅逐它。</span>
<span className="v" id="v12" data-v="12" data-xref="以西結書 28:7; 以西結書 35:8; 以西結書 30:11"> 外邦人，就是列邦中強暴的，將它砍斷棄掉。它的枝條落在山間和一切谷中，它的枝子折斷，落在地的一切河旁。地上的眾民已經走去，離開它的蔭下。</span>
<span className="v" id="v13" data-v="13" data-xref="以西結書 32:4; 以西結書 29:5; 以賽亞書 18:6"> 空中的飛鳥都要宿在這敗落的樹上，田野的走獸都要臥在它的枝條下，</span>
<span className="v" id="v14" data-v="14" data-xref="詩篇 63:9–10; 尼希米記 13:18; 彼得後書 2:6"> 好使水旁的諸樹不因高大而自尊，也不將樹尖插入雲中，並且那些得水滋潤、有勢力的，也不得高大自立。因為它們在世人中，和下坑的人都被交與死亡，到陰府去了。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="瑪拉基書 3:4; 那鴻書 2:8–10; 啟示錄 18:9–11"> 主耶和華如此說：「它下陰間的那日，我便使人悲哀。我為它遮蓋深淵，使江河凝結，大水停流；我也使黎巴嫩為它悽慘，田野的諸樹都因它發昏。</span>
<span className="v" id="v16" data-v="16" data-xref="以賽亞書 14:15; 以賽亞書 14:8; 以西結書 26:15"> 我將它扔到陰間，與下坑的人一同下去。那時，列國聽見它墜落的響聲就都震動，並且伊甸的一切樹－就是黎巴嫩得水滋潤、最佳最美的樹－都在陰府受了安慰。</span>
<span className="v" id="v17" data-v="17" data-xref="詩篇 9:17; 以西結書 31:6; 以西結書 31:3"> 它們也與它同下陰間，到被殺的人那裏。它們曾作它的膀臂，在列國中它的蔭下居住。</span>
<span className="v" id="v18" data-v="18" data-xref="以西結書 32:19; 以西結書 32:21; 以西結書 28:10"> 在這樣榮耀威勢上，在伊甸園諸樹中，誰能與你相比呢？然而你要與伊甸的諸樹一同下到陰府，在未受割禮的人中，與被殺的人一同躺臥。<br />「法老和他的群眾乃是如此。這是主耶和華說的。」</span>
</div>

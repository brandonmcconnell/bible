<div className="bible-chapter" lang="zh-Hant" dir="ltr" data-lang="zh-Hant" data-translation="cuvt" data-translation-id="cmn_cuv" data-translation-label="和合本" data-book="EZK" data-book-slug="ezekiel" data-book-name="以西結書" data-chapter="18" data-verses="31">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華的話又臨到我說：</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米書 31:29–30; 耶利米哀歌 5:7; 以西結書 37:11"> 「你們在以色列地怎麼用這俗語說『父親吃了酸葡萄，兒子的牙酸倒了』呢？」</span>
<span className="v" id="v3" data-v="3" data-xref="以西結書 18:19–20; 以西結書 33:11–20; 以西結書 18:30"> 主耶和華說：「我指着我的永生起誓，你們在以色列中，必不再有用這俗語的因由。</span>
<span className="v" id="v4" data-v="4" data-xref="以西結書 18:20; 羅馬書 6:23; 民數記 16:22"> 看哪，世人都是屬我的；為父的怎樣屬我，為子的也照樣屬我；犯罪的，他必死亡。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="以西結書 33:14; 約翰一書 3:7; 箴言 21:3"> 「人若是公義，且行正直與合理的事：</span>
<span className="v" id="v6" data-v="6" data-xref="以西結書 18:15; 申命記 4:19; 以西結書 6:13"> 未曾在山上吃過祭偶像之物，未曾仰望以色列家的偶像，未曾玷污鄰舍的妻，未曾在婦人的經期內親近她，</span>
<span className="v" id="v7" data-v="7" data-xref="以西結書 18:16; 出埃及記 22:26; 以西結書 18:12"> 未曾虧負人，乃將欠債之人的當頭還給他；未曾搶奪人的物件，卻將食物給飢餓的人吃，將衣服給赤身的人穿；</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及記 22:25; 撒迦利亞書 8:16; 申命記 23:19–20"> 未曾向借錢的弟兄取利，也未曾向借糧的弟兄多要，縮手不作罪孽，在兩人之間，按至理判斷；</span>
<span className="v" id="v9" data-v="9" data-xref="以西結書 20:11; 哈巴谷書 2:4; 阿摩司書 5:4"> 遵行我的律例，謹守我的典章，按誠實行事－這人是公義的，必定存活。這是主耶和華說的。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="出埃及記 21:12; 約翰一書 3:12; 約翰福音 18:40"> 「他若生一個兒子，作強盜，是流人血的，不行以上所說之善，反行其中之惡，乃在山上吃過祭偶像之物，並玷污鄰舍的妻，</span>
<span className="v" id="v12" data-v="12" data-xref="以西結書 8:17; 以西結書 8:6; 列王紀下 21:11"> 虧負困苦和窮乏的人，搶奪人的物，未曾將當頭還給人，仰望偶像，並行可憎的事，</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及記 22:25; 利未記 20:9; 以西結書 3:18"> 向借錢的弟兄取利，向借糧的弟兄多要－這人豈能存活呢？他必不能存活。他行這一切可憎的事，必要死亡，他的罪<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是血">a</a></sup>必歸到他身上。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="歷代志下 34:21; 箴言 23:24; 耶利米書 8:6"> 「他若生一個兒子，見父親所犯的一切罪便懼怕<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有古卷：思量">b</a></sup>，不照樣去做；</span>
<span className="v" id="v15" data-v="15" data-xref="以西結書 18:6–7; 以西結書 18:11–13"> 未曾在山上吃過祭偶像之物，未曾仰望以色列家的偶像，未曾玷污鄰舍的妻，</span>
<span className="v" id="v16" data-v="16" data-xref="以西結書 18:7; 以賽亞書 58:7–10; 約伯記 22:7"> 未曾虧負人，未曾取人的當頭，未曾搶奪人的物件，卻將食物給飢餓的人吃，將衣服給赤身的人穿，</span>
<span className="v" id="v17" data-v="17" data-xref="以西結書 18:8–9; 馬太福音 18:27–35; 以西結書 18:13"> 縮手不害貧窮人，未曾向借錢的弟兄取利，也未曾向借糧的弟兄多要；他順從我的典章，遵行我的律例，就不因父親的罪孽死亡，定要存活。</span>
<span className="v" id="v18" data-v="18" data-xref="以西結書 3:18; 以西結書 18:26; 以西結書 18:24"> 至於他父親；因為欺人太甚，搶奪弟兄，在本國的民中行不善，他必因自己的罪孽死亡。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="出埃及記 20:5; 撒迦利亞書 1:3–6; 申命記 5:9"> 「你們還說：『兒子為何不擔當父親的罪孽呢？』兒子行正直與合理的事，謹守遵行我的一切律例，他必定存活。</span>
<span className="v" id="v20" data-v="20" data-xref="申命記 24:16; 列王紀下 14:6; 以西結書 18:4"> 惟有犯罪的，他必死亡。兒子必不擔當父親的罪孽，父親也不擔當兒子的罪孽。義人的善果必歸自己，惡人的惡報也必歸自己。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="以西結書 18:27–28; 提多書 2:11–14; 以西結書 33:19"> 「惡人若回頭離開所做的一切罪惡，謹守我一切的律例，行正直與合理的事，他必定存活，不致死亡。</span>
<span className="v" id="v22" data-v="22" data-xref="彌迦書 7:19; 以西結書 33:16; 以賽亞書 43:25"> 他所犯的一切罪過都不被記念，因所行的義，他必存活。</span>
<span className="v" id="v23" data-v="23" data-xref="以西結書 33:11; 提摩太前書 2:4; 彼得後書 3:9"> 主耶和華說：惡人死亡，豈是我喜悅的嗎？不是喜悅他回頭離開所行的道存活嗎？</span>
<span className="v" id="v24" data-v="24" data-xref="以西結書 33:18; 箴言 21:16; 約翰二書 1:8"> 義人若轉離義行而作罪孽，照着惡人所行一切可憎的事而行，他豈能存活嗎？他所行的一切義都不被記念；他必因所犯的罪、所行的惡死亡。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="以西結書 33:17; 瑪拉基書 3:13–15; 瑪拉基書 2:17"> 「你們還說：『主的道不公平！』以色列家啊，你們當聽，我的道豈不公平嗎？你們的道豈不是不公平嗎？</span>
<span className="v" id="v26" data-v="26"> 義人若轉離義行而作罪孽死亡，他是因所作的罪孽死亡。</span>
<span className="v" id="v27" data-v="27" data-xref="以西結書 18:21; 以賽亞書 1:18; 以賽亞書 55:7"> 再者，惡人若回頭離開所行的惡，行正直與合理的事，他必將性命救活了。</span>
<span className="v" id="v28" data-v="28" data-xref="申命記 32:29; 路加福音 15:17–18; 雅各書 2:10–12"> 因為他思量，回頭離開所犯的一切罪過，必定存活，不致死亡。</span>
<span className="v" id="v29" data-v="29" data-xref="以西結書 18:25; 箴言 19:3; 以西結書 18:2"> 以色列家還說：『主的道不公平！』以色列家啊，我的道豈不公平嗎？你們的道豈不是不公平嗎？」</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="以西結書 18:21; 馬太福音 16:27; 馬太福音 3:2"> 所以主耶和華說：「以色列家啊，我必按你們各人所行的審判你們。你們當回頭離開所犯的一切罪過。這樣，罪孽必不使你們敗亡。</span>
<span className="v" id="v31" data-v="31" data-xref="詩篇 51:10; 以西結書 36:26; 以西結書 11:19"> 你們要將所犯的一切罪過盡行拋棄，自做一個新心和新靈。以色列家啊，你們何必死亡呢？</span>
<span className="v" id="v32" data-v="32" data-xref="彼得後書 3:9; 以西結書 18:23; 以西結書 33:11"> 主耶和華說：我不喜悅那死人之死，所以你們當回頭而存活。」</span>
</div>
</div>

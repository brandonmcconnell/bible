## 耶和華的榮耀離開聖城

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及記 24:10; 啟示錄 4:2–3; 啟示錄 1:13"> 我觀看，見基路伯頭上的穹蒼之中，顯出藍寶石的形狀，彷彿寶座的形像。</span>
<span className="v" id="v2" data-v="2" data-xref="啟示錄 8:5; 以西結書 10:16; 以西結書 1:13"> 主對那穿細麻衣的人說：「你進去，在旋轉的輪內基路伯以下，從基路伯中間將火炭取滿兩手，撒在城上。」 我就見他進去。</span>
<span className="v" id="v3" data-v="3" data-xref="以西結書 43:4; 以西結書 9:3; 以西結書 8:16"> 那人進去的時候，基路伯站在殿的右邊，雲彩充滿了內院。</span>
<span className="v" id="v4" data-v="4" data-xref="以西結書 1:28; 以西結書 9:3; 出埃及記 40:35"> 耶和華的榮耀從基路伯那裏上升，停在門檻以上；殿內滿了雲彩，院宇也被耶和華榮耀的光輝充滿。</span>
<span className="v" id="v5" data-v="5" data-xref="以西結書 1:24; 約伯記 40:9; 出埃及記 19:16"> 基路伯翅膀的響聲聽到外院，好像全能上帝說話的聲音。</span>
<span className="v" id="v6" data-v="6" data-xref="以西結書 10:2; 詩篇 99:1; 詩篇 80:1"> 他吩咐那穿細麻衣的人說：「要從旋轉的輪內基路伯中間取火。」那人就進去站在一個輪子旁邊。</span>
<span className="v" id="v7" data-v="7" data-xref="馬太福音 13:41–42; 以西結書 1:13; 以西結書 41:23–26"> 有一個基路伯從基路伯中伸手到基路伯中間的火那裏，取些放在那穿細麻衣的人兩手中，那人就拿出去了。</span>
<span className="v" id="v8" data-v="8" data-xref="以西結書 1:8; 以西結書 10:21; 以賽亞書 6:6"> 在基路伯翅膀之下，顯出有人手的樣式。</span>
<span className="v" id="v9" data-v="9" data-xref="以西結書 1:15–17; 但以理書 10:6; 啟示錄 21:20"> 我又觀看，見基路伯旁邊有四個輪子。這基路伯旁有一個輪子，那基路伯旁有一個輪子，每基路伯都是如此；輪子的顏色<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是形狀">a</a></sup>彷彿水蒼玉。</span>
<span className="v" id="v10" data-v="10" data-xref="以西結書 1:16; 詩篇 36:6; 詩篇 104:24"> 至於四輪的形狀，都是一個樣式，彷彿輪中套輪。</span>
<span className="v" id="v11" data-v="11" data-xref="以西結書 1:17; 以西結書 10:22; 以西結書 1:20"> 輪行走的時候，向四方都能直行，並不掉轉。頭向何方，他們也隨向何方，行走的時候並不掉轉。</span>
<span className="v" id="v12" data-v="12" data-xref="以西結書 1:18; 啟示錄 4:8; 啟示錄 4:6"> 他們全身，連背帶手和翅膀，並輪周圍都滿了眼睛。這四個基路伯的輪子都是如此。</span>
<span className="v" id="v13" data-v="13"> 至於這些輪子，我耳中聽見說是旋轉的。</span>
<span className="v" id="v14" data-v="14" data-xref="啟示錄 4:7; 以西結書 10:21; 列王紀上 7:36"> 基路伯各有四臉：第一是基路伯的臉，第二是人的臉，第三是獅子的臉，第四是鷹的臉。</span>
<span className="v" id="v15" data-v="15" data-xref="以西結書 1:5; 何西阿書 9:12; 以西結書 11:22"> 基路伯升上去了；這是我在迦巴魯河邊所見的活物。</span>
<span className="v" id="v16" data-v="16" data-xref="以西結書 1:19–21"> 基路伯行走，輪也在旁邊行走。基路伯展開翅膀，離地上升，輪也不轉離他們旁邊。</span>
<span className="v" id="v17" data-v="17" data-xref="以西結書 1:20–21; 羅馬書 8:2; 以西結書 1:12"> 那些站住，這些也站住；那些上升，這些也一同上升，因為活物的靈在輪中。</span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 18:10; 馬太福音 23:37–39; 詩篇 78:60–61"> 耶和華的榮耀從殿的門檻那裏出去，停在基路伯以上。</span>
<span className="v" id="v19" data-v="19" data-xref="以西結書 8:16; 以西結書 1:17–21; 以西結書 1:26–28"> 基路伯出去的時候，就展開翅膀，在我眼前離地上升。輪也在他們的旁邊，都停在耶和華殿的東門口。在他們以上有以色列上帝的榮耀。</span>
<span className="v" id="v20" data-v="20" data-xref="以西結書 1:1; 以西結書 10:15; 列王紀上 7:36"> 這是我在迦巴魯河邊所見、以色列上帝榮耀以下的活物，我就知道他們是基路伯。</span>
<span className="v" id="v21" data-v="21" data-xref="以西結書 1:6; 以西結書 41:18–19; 以西結書 10:14"> 各有四個臉面，四個翅膀，翅膀以下有人手的樣式。</span>
<span className="v" id="v22" data-v="22" data-xref="以西結書 10:11; 以西結書 1:10; 以西結書 1:12"> 至於他們臉的模樣，並身體的形像，是我從前在迦巴魯河邊所看見的。他們俱各直往前行。</span>

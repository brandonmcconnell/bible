## 哀悼泰爾的輓歌

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1"> 耶和華的話又臨到我說：</span>
<span className="v" id="v2" data-v="2" data-xref="以西結書 19:1; 耶利米書 9:10; 以西結書 28:12"> 「人子啊，要為泰爾作起哀歌，</span>
<span className="v" id="v3" data-v="3" data-xref="以西結書 27:4; 以賽亞書 23:11; 以賽亞書 23:2–3"> 說：你居住海口，是眾民的商埠；你的交易通到許多的海島。主耶和華如此說：<br /><span className="pl pl-1">泰爾啊，你曾說：</span><br /><span className="pl pl-1">我是全然美麗的。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="以西結書 26:5"> <span className="pl pl-1">你的境界在海中，</span><br /><span className="pl pl-1">造你的使你全然美麗。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="申命記 3:9; 以賽亞書 14:8; 雅歌 4:8"> <span className="pl pl-1">他們用示尼珥的松樹做你的一切板，</span><br /><span className="pl pl-1">用黎巴嫩的香柏樹做桅杆，</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="創世記 10:4; 以賽亞書 2:13; 撒迦利亞書 11:2"> <span className="pl pl-1">用巴珊的橡樹做你的槳，</span><br /><span className="pl pl-1">用象牙鑲嵌基提海島的黃楊木為坐板</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或譯：艙板">a</a></sup><br /><span className="pl pl-1">。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="耶利米書 10:9; 出埃及記 25:4; 創世記 10:4"> <span className="pl pl-1">你的篷帆是用埃及繡花細麻布做的，</span><br /><span className="pl pl-1">可以做你的大旗；</span><br /><span className="pl pl-1">你的涼棚是用以利沙島的藍色、紫色布做的。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="創世記 10:18; 列王紀上 9:27; 以西結書 27:11"> <span className="pl pl-1">西頓和亞發的居民作你盪槳的。</span><br /><span className="pl pl-1">泰爾啊，你中間的智慧人作掌舵的。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="列王紀上 5:18; 約書亞記 13:5; 詩篇 83:7"> <span className="pl pl-1">迦巴勒的老者和聰明人</span><br /><span className="pl pl-1">都在你中間作補縫的；</span><br /><span className="pl pl-1">一切泛海的船隻和水手</span><br /><span className="pl pl-1">都在你中間經營交易的事。</span></span>
<span className="v" id="v10" data-v="10" data-xref="以西結書 38:5; 以西結書 30:5; 以賽亞書 66:19"> 「波斯人、路德人、弗人在你軍營中作戰士；他們在你中間懸掛盾牌和頭盔，彰顯你的尊榮。</span>
<span className="v" id="v11" data-v="11" data-xref="以西結書 27:3–4"> 亞發人和你的軍隊都在你四圍的牆上，你的望樓也有勇士；他們懸掛盾牌，成全你的美麗。</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 10:4; 以賽亞書 23:10; 以西結書 38:13"> 「他施人因你多有各類的財物，就作你的客商，拿銀、鐵、錫、鉛兌換你的貨物。</span>
<span className="v" id="v13" data-v="13" data-xref="創世記 10:2; 以賽亞書 66:19; 以西結書 39:1"> 雅完人、土巴人、米設人都與你交易；他們用人口和銅器兌換你的貨物。</span>
<span className="v" id="v14" data-v="14" data-xref="創世記 10:3; 以西結書 38:6; 歷代志上 1:6"> 陀迦瑪族用馬和戰馬並騾子兌換你的貨物。</span>
<span className="v" id="v15" data-v="15" data-xref="創世記 10:7; 啟示錄 18:12; 列王紀上 10:22"> 底但人與你交易，許多海島作你的碼頭；他們拿象牙、烏木與你兌換<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或譯：進貢">b</a></sup>。</span>
<span className="v" id="v16" data-v="16" data-xref="士師記 10:6; 以西結書 28:13; 撒母耳記下 10:6"> 亞蘭人因你的工作很多，就作你的客商；他們用綠寶石、紫色布繡貨、細麻布、珊瑚、紅寶石兌換你的貨物。</span>
<span className="v" id="v17" data-v="17" data-xref="士師記 11:33; 列王紀上 5:9; 耶利米書 8:22"> 猶大和以色列地的人都與你交易；他們用米匿的麥子、餅、蜜、油、乳香兌換你的貨物。</span>
<span className="v" id="v18" data-v="18" data-xref="以賽亞書 7:8; 創世記 15:2; 以西結書 47:16–18"> 大馬士革人因你的工作很多，又因你多有各類的財物，就拿黑本酒和白羊毛與你交易。</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及記 30:23–24; 詩篇 45:8; 雅歌 4:13–14"> 威但人和雅完人拿紡成的線、亮鐵、桂皮、菖蒲兌換你的貨物。</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 25:3; 以西結書 27:15"> 底但人用高貴的毯子、鞍、屜與你交易。</span>
<span className="v" id="v21" data-v="21" data-xref="以賽亞書 60:7; 創世記 25:13; 列王紀上 10:15"> 阿拉伯人和基達的一切首領都作你的客商，用羊羔、公綿羊、公山羊與你交易。</span>
<span className="v" id="v22" data-v="22" data-xref="創世記 10:7; 以賽亞書 60:6; 詩篇 72:10"> 示巴和拉瑪的商人與你交易，他們用各類上好的香料、各類的寶石，和黃金兌換你的貨物。</span>
<span className="v" id="v23" data-v="23" data-xref="列王紀下 19:12; 以賽亞書 37:12; 阿摩司書 1:5"> 哈蘭人、干尼人、伊甸人、示巴的商人，和亞述人、基抹人與你交易。</span>
<span className="v" id="v24" data-v="24" data-xref="列王紀下 2:8"> 這些商人以美好的貨物包在繡花藍色包袱內，又有華麗的衣服裝在香柏木的箱子裏，用繩捆着與你交易。</span>
<span className="v" id="v25" data-v="25" data-xref="以賽亞書 2:16; 詩篇 48:7; 以賽亞書 23:14"> <span className="pl pl-1">他施的船隻接連成幫為你運貨，</span><br /><span className="pl pl-1">你便在海中豐富極其榮華。</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="詩篇 48:7; 以西結書 26:19; 使徒行傳 27:14"> <span className="pl pl-1">盪槳的已經把你盪到大水之處，</span><br /><span className="pl pl-1">東風在海中將你打破。</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="箴言 11:4; 以西結書 27:24; 以西結書 27:12"> <span className="pl pl-1">你的資財、物件、貨物、</span><br /><span className="pl pl-1">水手、掌舵的、</span><br /><span className="pl pl-1">補縫的、經營交易的，</span><br /><span className="pl pl-1">並你中間的戰士和人民，</span><br /><span className="pl pl-1">在你破壞的日子必都沉在海中。</span><br /></span>
<span className="v" id="v28" data-v="28" data-xref="以西結書 26:10; 出埃及記 15:14; 以西結書 31:16"> <span className="pl pl-1">你掌舵的呼號之聲一發，</span><br /><span className="pl pl-1">郊野都必震動。</span><br /></span>
<span className="v" id="v29" data-v="29" data-xref="以西結書 26:16; 以西結書 32:10; 啟示錄 18:17–24"> <span className="pl pl-1">凡盪槳的和水手，</span><br /><span className="pl pl-1">並一切泛海掌舵的，</span><br /><span className="pl pl-1">都必下船登岸。</span><br /></span>
<span className="v" id="v30" data-v="30" data-xref="耶利米書 6:26; 撒母耳記下 1:2; 耶利米哀歌 2:10"> <span className="pl pl-1">他們必為你放聲痛哭，</span><br /><span className="pl pl-1">把塵土撒在頭上，</span><br /><span className="pl pl-1">在灰中打滾；</span><br /></span>
<span className="v" id="v31" data-v="31" data-xref="以西結書 7:18; 以賽亞書 22:12; 以賽亞書 15:2"> <span className="pl pl-1">又為你使頭上光禿，</span><br /><span className="pl pl-1">用麻布束腰，</span><br /><span className="pl pl-1">號咷痛哭，</span><br /><span className="pl pl-1">苦苦悲哀。</span><br /></span>
<span className="v" id="v32" data-v="32" data-xref="以西結書 26:17; 啟示錄 18:18; 以西結書 27:2"> <span className="pl pl-1">他們哀號的時候，</span><br /><span className="pl pl-1">為你作起哀歌哀哭，</span><br /><span className="pl pl-1">說：有何城如泰爾？</span><br /><span className="pl pl-1">有何城如她在海中成為寂寞的呢？</span><br /></span>
<span className="v" id="v33" data-v="33" data-xref="啟示錄 18:19; 以西結書 27:3; 以西結書 28:16"> <span className="pl pl-1">你由海上運出貨物，</span><br /><span className="pl pl-1">就使許多國民充足；</span><br /><span className="pl pl-1">你以許多資財、貨物</span><br /><span className="pl pl-1">使地上的君王豐富。</span><br /></span>
<span className="v" id="v34" data-v="34" data-xref="以西結書 27:26–27; 撒迦利亞書 9:3–4; 以西結書 26:19–21"> <span className="pl pl-1">你在深水中被海浪打破的時候，</span><br /><span className="pl pl-1">你的貨物和你中間的一切人民，</span><br /><span className="pl pl-1">就都沉下去了。</span><br /></span>
<span className="v" id="v35" data-v="35" data-xref="以西結書 32:10; 以賽亞書 23:6; 以西結書 26:15–18"> <span className="pl pl-1">海島的居民為你驚奇；</span><br /><span className="pl pl-1">他們的君王都甚恐慌，</span><br /><span className="pl pl-1">面帶愁容。</span><br /></span>
<span className="v" id="v36" data-v="36" data-xref="耶利米書 18:16; 詩篇 37:10; 西番雅書 2:15"> <span className="pl pl-1">各國民中的客商都向你發嘶聲；</span><br /><span className="pl pl-1">你令人驚恐，</span><br /><span className="pl pl-1">不再存留於世，直到永遠。」</span></span>

## 各人的重擔要互相擔當

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="羅馬書 15:1; 提摩太後書 2:25; 帖撒羅尼迦後書 3:15"> 弟兄們，若有人偶然被過犯所勝，你們屬靈的人就當用溫柔的心把他挽回過來；又當自己小心，恐怕也被引誘。</span>
<span className="v" id="v2" data-v="2" data-xref="羅馬書 15:1; 帖撒羅尼迦前書 5:14; 約翰福音 13:34"> 你們各人的重擔要互相擔當，如此，就完全了基督的律法。</span>
<span className="v" id="v3" data-v="3" data-xref="箴言 26:12; 哥林多前書 8:2; 哥林多前書 3:18"> 人若無有，自己還以為有，就是自欺了。</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多後書 13:5; 詩篇 26:2; 哥林多前書 11:28"> 各人應當察驗自己的行為；這樣，他所誇的就專在自己，不在別人了，</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米書 32:19; 羅馬書 14:10–12; 哥林多後書 5:10–11"> 因為各人必擔當自己的擔子。</span>
<span className="v" id="v6" data-v="6" data-xref="提摩太前書 5:17–18; 羅馬書 15:27; 申命記 12:19"> 在道理上受教的，當把一切需用的供給施教的人。</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多後書 9:6; 何西阿書 10:12; 約伯記 4:8"> 不要自欺，上帝是輕慢不得的。人種的是甚麼，收的也是甚麼。</span>
<span className="v" id="v8" data-v="8" data-xref="羅馬書 8:13; 雅各書 3:18; 彼得後書 2:19"> 順着情慾撒種的，必從情慾收敗壞；順着聖靈撒種的，必從聖靈收永生。</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多前書 15:58; 帖撒羅尼迦後書 3:13; 以賽亞書 40:30–31"> 我們行善，不可喪志；若不灰心，到了時候就要收成。</span>
<span className="v" id="v10" data-v="10" data-xref="希伯來書 13:16; 箴言 3:27; 帖撒羅尼迦前書 5:15"> 所以，有了機會就當向眾人行善，向信徒一家的人更當這樣。</span>
</div>
</div>

## 警告和祝福

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="哥林多前書 16:21–23; 羅馬書 16:22"> 請看我親手寫給你們的字是何等的大呢！</span>
<span className="v" id="v12" data-v="12" data-xref="加拉太書 5:11; 歌羅西書 2:23; 使徒行傳 15:1"> 凡希圖外貌體面的人都勉強你們受割禮，無非是怕自己為基督的十字架受逼迫。</span>
<span className="v" id="v13" data-v="13" data-xref="腓立比書 3:3; 哥林多前書 5:6; 羅馬書 2:17–25"> 他們那些受割禮的，連自己也不守律法；他們願意你們受割禮，不過要藉着你們的肉體誇口。</span>
<span className="v" id="v14" data-v="14" data-xref="羅馬書 6:6; 耶利米書 9:23–24; 加拉太書 2:20"> 但我斷不以別的誇口，只誇我們主耶穌基督的十字架；因這十字架，就我而論，世界已經釘在十字架上；就世界而論，我已經釘在十字架上。</span>
<span className="v" id="v15" data-v="15" data-xref="哥林多後書 5:17; 歌羅西書 3:10–11; 以弗所書 2:10"> 受割禮不受割禮都無關緊要，要緊的就是作新造的人。</span>
<span className="v" id="v16" data-v="16" data-xref="加拉太書 3:29; 羅馬書 9:6–8; 腓立比書 3:3"> 凡照此理而行的，願平安、憐憫加給他們，和上帝的以色列民。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="哥林多後書 1:5; 歌羅西書 1:24; 哥林多後書 11:23–25"> 從今以後，人都不要攪擾我，因為我身上帶着耶穌的印記。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="羅馬書 16:20; 提摩太後書 4:22; 腓利門書 1:25"> 弟兄們，願我主耶穌基督的恩常在你們心裏。阿們！</span>
</div>

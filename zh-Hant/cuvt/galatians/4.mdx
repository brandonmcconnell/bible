## 保羅關懷加拉太人

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="哥林多前書 8:4; 以弗所書 2:11–12; 帖撒羅尼迦後書 1:8"> 但從前你們不認識上帝的時候，是給那些本來不是神的作奴僕；</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多前書 8:3; 加拉太書 3:3; 羅馬書 8:3"> 現在你們既然認識上帝，更可說是被上帝所認識的，怎麼還要歸回那懦弱無用的小學，情願再給他作奴僕呢？</span>
<span className="v" id="v10" data-v="10" data-xref="歌羅西書 2:16–17; 羅馬書 14:5; 利未記 23:1–44"> 你們謹守日子、月份、節期、年份，</span>
<span className="v" id="v11" data-v="11" data-xref="帖撒羅尼迦前書 3:5; 腓立比書 2:16; 加拉太書 2:2"> 我為你們害怕，惟恐我在你們身上是枉費了工夫。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="哥林多後書 2:5; 列王紀上 22:4; 創世記 34:15"> 弟兄們，我勸你們要像我一樣，因為我也像你們一樣。你們一點沒有虧負我。</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多前書 2:3; 哥林多後書 12:7–10; 哥林多後書 11:30"> 你們知道我頭一次傳福音給你們，是因為身體有疾病。</span>
<span className="v" id="v14" data-v="14" data-xref="馬太福音 10:40; 帖撒羅尼迦前書 2:13; 希伯來書 13:2"> 你們為我身體的緣故受試煉，沒有輕看我，也沒有厭棄我，反倒接待我，如同上帝的使者，如同基督耶穌。</span>
<span className="v" id="v15" data-v="15" data-xref="羅馬書 5:2; 約翰一書 3:16–18; 歌羅西書 4:13"> 你們當日所誇的福氣在哪裏呢？那時你們若能行，就是把自己的眼睛剜出來給我，也都情願。這是我可以給你們作見證的。</span>
<span className="v" id="v16" data-v="16" data-xref="阿摩司書 5:10; 箴言 9:8; 約翰福音 8:45"> 如今我將真理告訴你們，就成了你們的仇敵嗎？</span>
<span className="v" id="v17" data-v="17" data-xref="羅馬書 16:18; 哥林多後書 11:13–15; 彼得後書 2:3"> 那些人熱心待你們，卻不是好意，是要離間你們<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原文是把你們關在外面">b</a></sup>，叫你們熱心待他們。</span>
<span className="v" id="v18" data-v="18" data-xref="腓立比書 2:12; 啟示錄 3:19; 腓立比書 1:27"> 在善事上，常用熱心待人原是好的，卻不單我與你們同在的時候才這樣。</span>
<span className="v" id="v19" data-v="19" data-xref="以弗所書 4:13; 羅馬書 8:29; 羅馬書 13:14"> 我小子啊，我為你們再受生產之苦，直等到基督成形在你們心裏。</span>
<span className="v" id="v20" data-v="20" data-xref="帖撒羅尼迦前書 2:17–18; 哥林多前書 4:19–21; 帖撒羅尼迦前書 3:9"> 我巴不得現今在你們那裏，改換口氣，因我為你們心裏作難。</span>
</div>
</div>

## 夏甲和撒拉的例子

<div className="bt">
<div className="bp poetry">
<span className="v" id="v21" data-v="21" data-xref="加拉太書 3:10; 加拉太書 3:23–24; 羅馬書 7:5–6"> 你們這願意在律法以下的人，請告訴我，你們豈沒有聽見律法嗎？</span>
<span className="v" id="v22" data-v="22" data-xref="創世記 16:15; 創世記 21:10; 創世記 21:1–2"> 因為律法上記着，亞伯拉罕有兩個兒子，一個是使女生的，一個是自主之婦人生的。</span>
<span className="v" id="v23" data-v="23" data-xref="希伯來書 11:11; 羅馬書 9:7–8; 加拉太書 4:28–29"> 然而，那使女所生的是按着血氣生的；那自主之婦人所生的是憑着應許生的。</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 21:9–13; 希伯來書 10:15–18; 創世記 16:8"> 這都是比方：那兩個婦人就是兩約。一約是出於西奈山，生子為奴，乃是夏甲。</span>
<span className="v" id="v25" data-v="25" data-xref="路加福音 19:44; 使徒行傳 1:11; 加拉太書 1:17"> 這夏甲二字是指着阿拉伯的西奈山，與現在的耶路撒冷同類，因耶路撒冷和她的兒女都是為奴的。</span>
<span className="v" id="v26" data-v="26" data-xref="希伯來書 12:22; 腓立比書 3:20; 彌迦書 4:1–2"> 但那在上的耶路撒冷是自主的，她是我們的母。</span>
<span className="v" id="v27" data-v="27" data-xref="以賽亞書 54:1–5; 詩篇 113:9; 路得記 4:14–16"> 因為經上記着：<br /><span className="pl pl-1">不懷孕、不生養的，你要歡樂；</span><br /><span className="pl pl-1">未曾經過產難的，你要高聲歡呼；</span><br /><span className="pl pl-1">因為沒有丈夫的，比有丈夫的兒女更多。</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="加拉太書 4:23; 羅馬書 9:8–9; 羅馬書 4:13–18"> 弟兄們，我們是憑着應許作兒女，如同以撒一樣。</span>
<span className="v" id="v29" data-v="29" data-xref="創世記 21:9; 羅馬書 8:13; 加拉太書 5:11"> 當時，那按着血氣生的逼迫了那按着聖靈生的，現在也是這樣。</span>
<span className="v" id="v30" data-v="30" data-xref="創世記 21:10–12; 約翰福音 8:35; 羅馬書 8:15–17"> 然而經上是怎麼說的呢？是說：「把使女和她兒子趕出去！因為使女的兒子不可與自主婦人的兒子一同承受產業。」</span>
<span className="v" id="v31" data-v="31" data-xref="約翰福音 8:36; 約翰福音 1:12–13; 加拉太書 5:1"> 弟兄們，這樣看來，我們不是使女的兒女，乃是自主婦人的兒女了。</span>
</div>
</div>

## 道成肉身

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 1:1; 約翰福音 17:5; 啟示錄 19:13"> 太初有道，道與上帝同在，道就是上帝。</span>
<span className="v" id="v2" data-v="2"> 這道太初與上帝同在。</span>
<span className="v" id="v3" data-v="3" data-xref="歌羅西書 1:16–17; 哥林多前書 8:6; 啟示錄 4:11"> 萬物是藉着他造的；凡被造的，沒有一樣不是藉着他造的。</span>
<span className="v" id="v4" data-v="4" data-xref="約翰福音 8:12; 約翰福音 12:46; 約翰福音 5:26"> 生命在他裏頭，這生命就是人的光。</span>
<span className="v" id="v5" data-v="5" data-xref="約翰福音 3:19–20; 約翰福音 12:36–40; 哥林多前書 2:14"> 光照在黑暗裏，黑暗卻不接受光。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="瑪拉基書 3:1; 約翰福音 3:28; 以賽亞書 40:3–5"> 有一個人，是從上帝那裏差來的，名叫約翰。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行傳 19:4; 約翰福音 1:36; 約翰福音 5:33–35"> 這人來，為要作見證，就是為光作見證，叫眾人因他可以信。</span>
<span className="v" id="v8" data-v="8" data-xref="約翰福音 1:20; 約翰福音 3:28; 使徒行傳 19:4"> 他不是那光，乃是要為光作見證。</span>
<span className="v" id="v9" data-v="9" data-xref="約翰福音 12:46; 約翰福音 1:4; 約翰一書 2:8"> 那光是真光，照亮一切生在世上的人。</span>
<span className="v" id="v10" data-v="10" data-xref="約翰福音 17:25; 約翰一書 3:1; 哥林多前書 2:8"> 他在世界，世界也是藉着他造的，世界卻不認識他。</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 19:14; 以賽亞書 53:2–3; 約翰福音 3:32"> 他到自己的地方來，自己的人倒不接待他。</span>
<span className="v" id="v12" data-v="12" data-xref="加拉太書 3:26; 羅馬書 8:14; 約翰一書 3:1"> 凡接待他的，就是信他名的人，他就賜他們權柄作上帝的兒女。</span>
<span className="v" id="v13" data-v="13" data-xref="約翰一書 3:9; 雅各書 1:18; 彼得前書 1:23"> 這等人不是從血氣生的，不是從情慾生的，也不是從人意生的，乃是從上帝生的。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="約翰一書 4:9; 提摩太前書 3:16; 以賽亞書 40:5"> 道成了肉身，住在我們中間，充充滿滿地有恩典有真理。我們也見過他的榮光，正是父獨生子的榮光。</span>
<span className="v" id="v15" data-v="15" data-xref="馬太福音 3:11; 歌羅西書 1:17; 路加福音 3:16"> 約翰為他作見證，喊着說：「這就是我曾說：『那在我以後來的，反成了在我以前的，因他本來在我以前。』」</span>
<span className="v" id="v16" data-v="16" data-xref="歌羅西書 1:19; 羅馬書 5:2; 以弗所書 2:5–10"> 從他豐滿的恩典裏，我們都領受了，而且恩上加恩。</span>
<span className="v" id="v17" data-v="17" data-xref="羅馬書 6:14; 約翰福音 14:6; 羅馬書 3:19–26"> 律法本是藉着摩西傳的；恩典和真理都是由耶穌基督來的。</span>
<span className="v" id="v18" data-v="18" data-xref="歌羅西書 1:15; 約翰福音 6:46; 馬太福音 11:27"> 從來沒有人看見上帝，只有在父懷裏的獨生子將他表明出來。</span>
</div>
</div>

## 施洗約翰的見證

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="路加福音 3:15–18; 約翰福音 10:24; 使徒行傳 19:4"> 約翰所作的見證記在下面：猶太人從耶路撒冷差祭司和利未人到約翰那裏，問他說：「你是誰？」</span>
<span className="v" id="v20" data-v="20" data-xref="馬可福音 1:7–8; 馬太福音 3:11–12; 約翰福音 3:28–36"> 他就明說，並不隱瞞，明說：「我不是基督。」</span>
<span className="v" id="v21" data-v="21" data-xref="瑪拉基書 4:5; 申命記 18:15–18; 馬太福音 11:14"> 他們又問他說：「這樣，你是誰呢？是以利亞嗎？」他說：「我不是。」「是那先知嗎？」他回答說：「不是。」</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳記下 24:13"> 於是他們說：「你到底是誰，叫我們好回覆差我們來的人。你自己說，你是誰？」</span>
<span className="v" id="v23" data-v="23" data-xref="以賽亞書 40:3–5; 馬可福音 1:3; 馬太福音 3:3"> 他說：「我就是那在曠野有人聲喊着說：『修直主的道路』，正如先知以賽亞所說的。」</span>
<span className="v" id="v24" data-v="24" data-xref="路加福音 11:53; 馬太福音 23:13–15; 路加福音 11:39–44"> 那些人是法利賽人差來的<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或譯：那差來的是法利賽人">a</a></sup>；</span>
<span className="v" id="v25" data-v="25" data-xref="申命記 18:18; 申命記 18:15; 約翰福音 1:20–22"> 他們就問他說：「你既不是基督，不是以利亞，也不是那先知，為甚麼施洗呢？」</span>
<span className="v" id="v26" data-v="26" data-xref="約翰福音 1:10–11; 路加福音 3:16; 使徒行傳 1:5"> 約翰回答說：「我是用水施洗，但有一位站在你們中間，是你們不認識的，</span>
<span className="v" id="v27" data-v="27" data-xref="約翰福音 1:30; 馬可福音 1:7; 馬太福音 3:11"> 就是那在我以後來的，我給他解鞋帶也不配。」</span>
<span className="v" id="v28" data-v="28" data-xref="約翰福音 10:40; 約翰福音 3:23; 士師記 7:24"> 這是在約旦河外伯大尼<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有古卷：伯大巴喇">b</a></sup>，約翰施洗的地方作的見證。</span>
</div>
</div>

## 上帝的羔羊

<div className="bt">
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="以賽亞書 53:7; 約翰一書 2:2; 約翰一書 3:5"> 次日，約翰看見耶穌來到他那裏，就說：「看哪，上帝的羔羊，除去<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="或譯：背負">c</a></sup>世人罪孽的！</span>
<span className="v" id="v30" data-v="30" data-xref="約翰福音 1:27; 約翰福音 1:15; 路加福音 3:16"> 這就是我曾說：『有一位在我以後來、反成了在我以前的，因他本來在我以前。』</span>
<span className="v" id="v31" data-v="31" data-xref="瑪拉基書 3:1; 路加福音 1:17; 瑪拉基書 4:2–5"> 我先前不認識他，如今我來用水施洗，為要叫他顯明給以色列人。」</span>
<span className="v" id="v32" data-v="32" data-xref="馬可福音 1:10; 路加福音 3:22; 馬太福音 3:16"> 約翰又作見證說：「我曾看見聖靈，彷彿鴿子從天降下，住在他的身上。</span>
<span className="v" id="v33" data-v="33" data-xref="使徒行傳 1:5; 馬太福音 3:11; 路加福音 3:16"> 我先前不認識他，只是那差我來用水施洗的、對我說：『你看見聖靈降下來，住在誰的身上，誰就是用聖靈施洗的。』</span>
<span className="v" id="v34" data-v="34" data-xref="詩篇 2:7; 約翰福音 1:49; 詩篇 89:26–27"> 我看見了，就證明這是上帝的兒子。」</span>
</div>
</div>

## 初次選召門徒

<div className="bt">
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="約翰福音 3:25–26; 瑪拉基書 3:16"> 再次日，約翰同兩個門徒站在那裏。</span>
<span className="v" id="v36" data-v="36" data-xref="約翰福音 1:29; 彼得前書 1:19–20; 以賽亞書 65:1–2"> 他見耶穌行走，就說：「看哪，這是上帝的羔羊！」</span>
<span className="v" id="v37" data-v="37" data-xref="羅馬書 10:17; 約翰福音 1:43; 撒迦利亞書 8:21"> 兩個門徒聽見他的話，就跟從了耶穌。</span>
<span className="v" id="v38" data-v="38" data-xref="約翰福音 18:7; 約翰福音 3:2; 約翰福音 1:49"> 耶穌轉過身來，看見他們跟着，就問他們說：「你們要甚麼？」他們說：「拉比，在哪裏住？」（拉比翻出來就是夫子。）</span>
<span className="v" id="v39" data-v="39" data-xref="路加福音 24:29; 馬太福音 11:28–30; 約翰福音 6:37"> 耶穌說：「你們來看。」他們就去看他在哪裏住，這一天便與他同住；那時約有申正了。</span>
<span className="v" id="v40" data-v="40" data-xref="馬可福音 1:16–20; 馬太福音 4:18–22; 約翰福音 1:40–42"> 聽見約翰的話跟從耶穌的那兩個人，一個是西門‧彼得的兄弟安得烈。</span>
<span className="v" id="v41" data-v="41" data-xref="約翰福音 4:25; 約翰福音 1:45; 詩篇 89:20"> 他先找着自己的哥哥西門，對他說：「我們遇見彌賽亞了。」（彌賽亞翻出來就是基督。）</span>
<span className="v" id="v42" data-v="42" data-xref="約翰福音 21:15–17; 哥林多前書 3:22; 哥林多前書 15:5"> 於是領他去見耶穌。耶穌看着他，說：「你是約翰的兒子西門<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="約翰在馬太十六章十七節稱約拿">d</a></sup>，你要稱為磯法。」（磯法翻出來就是彼得。）</span>
</div>
</div>

## 呼召腓力和拿但業

<div className="bt">
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="馬太福音 9:9; 約翰福音 14:8; 以賽亞書 65:1"> 又次日，耶穌想要往加利利去，遇見腓力，就對他說：「來跟從我吧。」</span>
<span className="v" id="v44" data-v="44" data-xref="約翰福音 12:21; 馬太福音 11:21; 馬可福音 8:22"> 這腓力是伯賽大人，和安得烈、彼得同城。</span>
<span className="v" id="v45" data-v="45" data-xref="申命記 18:18–22; 路加福音 24:27; 彌迦書 5:2"> 腓力找着拿但業，對他說：「摩西在律法上所寫的和眾先知所記的那一位，我們遇見了，就是約瑟的兒子拿撒勒人耶穌。」</span>
<span className="v" id="v46" data-v="46" data-xref="約翰福音 7:52; 約翰福音 7:41–42; 約翰福音 4:29"> 拿但業對他說：「拿撒勒還能出甚麼好的嗎？」腓力說：「你來看！」</span>
<span className="v" id="v47" data-v="47" data-xref="啟示錄 14:5; 詩篇 32:2; 詩篇 73:1"> 耶穌看見拿但業來，就指着他說：「看哪，這是個真以色列人，他心裏是沒有詭詐的。」</span>
<span className="v" id="v48" data-v="48" data-xref="以賽亞書 65:24; 約翰福音 2:25; 詩篇 139:1–2"> 拿但業對耶穌說：「你從哪裏知道我呢？」耶穌回答說：「腓力還沒有招呼你，你在無花果樹底下，我就看見你了。」</span>
<span className="v" id="v49" data-v="49" data-xref="西番雅書 3:15; 撒迦利亞書 9:9; 馬太福音 27:42"> 拿但業說：「拉比，你是上帝的兒子，你是以色列的王！」</span>
<span className="v" id="v50" data-v="50" data-xref="約翰福音 11:40; 約翰福音 20:29; 路加福音 1:45"> 耶穌對他說：「因為我說『在無花果樹底下看見你』，你就信嗎？你將要看見比這更大的事」；</span>
<span className="v" id="v51" data-v="51" data-xref="創世記 28:12; 使徒行傳 7:56; 路加福音 22:43"> 又說：「我實實在在地告訴你們，你們將要看見天開了，上帝的使者上去下來在人子身上。」</span>
</div>

## 在伯大尼受膏

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="馬可福音 14:3–8; 約翰福音 11:1; 路加福音 24:50"> 逾越節前六日，耶穌來到伯大尼，就是他叫拉撒路從死裏復活之處。</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 22:27; 路加福音 10:38–42; 啟示錄 3:20"> 有人在那裏給耶穌預備筵席；馬大伺候，拉撒路也在那同耶穌坐席的人中。</span>
<span className="v" id="v3" data-v="3" data-xref="馬可福音 14:3–9; 約翰福音 11:2; 路加福音 10:38–39"> 馬利亞就拿着一斤極貴的真哪噠香膏，抹耶穌的腳，又用自己頭髮去擦，屋裏就滿了膏的香氣。</span>
<span className="v" id="v4" data-v="4" data-xref="馬太福音 10:4; 撒母耳記上 17:28–29; 約翰福音 13:2"> 有一個門徒，就是那將要賣耶穌的加略人猶大，</span>
<span className="v" id="v5" data-v="5" data-xref="路加福音 18:22; 路加福音 12:33; 馬可福音 14:4–5"> 說：「這香膏為甚麼不賣三十兩銀子賙濟窮人呢？」</span>
<span className="v" id="v6" data-v="6" data-xref="約翰福音 13:29; 詩篇 50:16–20; 雅各書 2:6"> 他說這話，並不是掛念窮人，乃因他是個賊，又帶着錢囊，常取其中所存的。</span>
<span className="v" id="v7" data-v="7" data-xref="馬太福音 26:12; 馬可福音 14:6; 馬太福音 27:57–60"> 耶穌說：「由她吧！她是為我安葬之日存留的。</span>
<span className="v" id="v8" data-v="8" data-xref="申命記 15:11; 馬可福音 14:7; 馬太福音 26:11"> 因為常有窮人和你們同在，只是你們不常有我。」</span>
</div>
</div>

## 殺害拉撒路的陰謀

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="使徒行傳 4:14; 約翰福音 11:43–45; 使徒行傳 3:10–11"> 有許多猶太人知道耶穌在那裏，就來了，不但是為耶穌的緣故，也是要看他從死裏所復活的拉撒路。</span>
<span className="v" id="v10" data-v="10" data-xref="路加福音 16:31; 馬太福音 2:16; 約翰福音 11:47–53"> 但祭司長商議連拉撒路也要殺了；</span>
<span className="v" id="v11" data-v="11" data-xref="約翰福音 11:45; 約翰福音 12:18; 使徒行傳 13:45"> 因有好些猶太人為拉撒路的緣故，回去信了耶穌。</span>
</div>
</div>

## 光榮地進耶路撒冷

<div className="bt">
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="馬可福音 11:7–10; 馬太福音 21:4–9; 路加福音 19:35–38"> 第二天，有許多上來過節的人聽見耶穌將到耶路撒冷，</span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 118:25–26; 啟示錄 15:3; 馬太福音 21:9–11"> 就拿着棕樹枝出去迎接他，喊着說：<br /><span className="pl pl-1">和散那！</span><br /><span className="pl pl-1">奉主名來的以色列王是應當稱頌的！</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="撒迦利亞書 9:9; 馬可福音 11:1–7; 馬太福音 21:1–7"> 耶穌得了一個驢駒，就騎上，如經上所記的說：</span>
<span className="v" id="v15" data-v="15" data-xref="撒迦利亞書 9:9; 以賽亞書 62:11; 西番雅書 3:16–17"> <span className="pl pl-1">錫安的民</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是女子">a</a></sup><br /><span className="pl pl-1">哪，不要懼怕！</span><br /><span className="pl pl-1">你的王騎着驢駒來了。</span></span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="約翰福音 2:22; 約翰福音 14:26; 約翰福音 7:39"> 這些事門徒起先不明白，等到耶穌得了榮耀以後才想起這話是指着他寫的，並且眾人果然向他這樣行了。</span>
<span className="v" id="v17" data-v="17" data-xref="啟示錄 1:2; 約翰一書 5:9–12; 約翰福音 19:35"> 當耶穌呼喚拉撒路，叫他從死復活出墳墓的時候，同耶穌在那裏的眾人就作見證。</span>
<span className="v" id="v18" data-v="18" data-xref="約翰福音 12:11"> 眾人因聽見耶穌行了這神蹟，就去迎接他。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行傳 17:6; 詩篇 22:27; 約翰一書 2:2"> 法利賽人彼此說：「看哪，你們是徒勞無益，世人都隨從他去了。」</span>
</div>
</div>

## 希臘人求見耶穌

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="約翰福音 7:35; 以賽亞書 11:10; 使徒行傳 17:4"> 那時，上來過節禮拜的人中，有幾個希臘人。</span>
<span className="v" id="v21" data-v="21" data-xref="馬太福音 2:2; 路加福音 19:2–4; 約翰福音 6:40"> 他們來見加利利、伯賽大的腓力，求他說：「先生，我們願意見耶穌。」</span>
<span className="v" id="v22" data-v="22" data-xref="馬可福音 10:13–14; 路加福音 9:49–50; 約翰福音 1:40–41"> 腓力去告訴安得烈，安得烈同腓力去告訴耶穌。</span>
<span className="v" id="v23" data-v="23" data-xref="約翰福音 13:31–32; 約翰福音 17:1–5; 以賽亞書 60:9"> 耶穌說：「人子得榮耀的時候到了。</span>
<span className="v" id="v24" data-v="24" data-xref="哥林多前書 15:36–38; 以賽亞書 53:10–12; 希伯來書 2:9–10"> 我實實在在地告訴你們，一粒麥子不落在地裏死了，仍舊是一粒，若是死了，就結出許多子粒來。</span>
<span className="v" id="v25" data-v="25" data-xref="馬太福音 10:39; 路加福音 9:23–24; 馬可福音 8:35"> 愛惜自己生命的，就失喪生命；在這世上恨惡自己生命的，就要保守生命到永生。</span>
<span className="v" id="v26" data-v="26" data-xref="歌羅西書 3:24; 加拉太書 1:10; 撒母耳記上 2:30"> 若有人服事我，就當跟從我；我在哪裏，服事我的人也要在那裏；若有人服事我，我父必尊重他。」</span>
</div>
</div>

## 人子必須被舉起來

<div className="bt">
<div className="bp poetry">
<span className="v" id="v27" data-v="27" data-xref="約翰福音 12:23; 希伯來書 5:7; 馬太福音 26:42"> 「我現在心裏憂愁，我說甚麼才好呢？父啊，救我脫離這時候；但我原是為這時候來的。</span>
<span className="v" id="v28" data-v="28" data-xref="約翰福音 13:31–32; 馬太福音 26:42; 啟示錄 5:9–14"> 父啊，願你榮耀你的名！」當時就有聲音從天上來，說：「我已經榮耀了我的名，還要再榮耀。」</span>
<span className="v" id="v29" data-v="29" data-xref="約伯記 37:2–5; 啟示錄 6:1; 啟示錄 14:2"> 站在旁邊的眾人聽見，就說：「打雷了。」還有人說：「有天使對他說話。」</span>
<span className="v" id="v30" data-v="30" data-xref="約翰福音 11:42; 約翰福音 11:15; 約翰福音 5:34"> 耶穌說：「這聲音不是為我，是為你們來的。</span>
<span className="v" id="v31" data-v="31" data-xref="哥林多後書 4:4; 約翰一書 5:19; 約翰一書 3:8"> 現在這世界受審判，這世界的王要被趕出去。</span>
<span className="v" id="v32" data-v="32" data-xref="約翰福音 3:14; 約翰福音 8:28; 彼得前書 2:24"> 我若從地上被舉起來，就要吸引萬人來歸我。」</span>
<span className="v" id="v33" data-v="33" data-xref="約翰福音 18:32; 約翰福音 21:19"> 耶穌這話原是指着自己將要怎樣死說的。</span>
<span className="v" id="v34" data-v="34" data-xref="以西結書 37:24–25; 以賽亞書 9:7; 但以理書 7:14"> 眾人回答說：「我們聽見律法上有話說，基督是永存的，你怎麼說『人子必須被舉起來』呢？這人子是誰呢？」</span>
<span className="v" id="v35" data-v="35" data-xref="約翰福音 12:46; 約翰福音 16:16; 以弗所書 5:8"> 耶穌對他們說：「光在你們中間還有不多的時候，應當趁着有光行走，免得黑暗臨到你們；那在黑暗裏行走的，不知道往何處去。</span>
<span className="v" id="v36" data-v="36" data-xref="以弗所書 5:8; 約翰福音 8:59; 使徒行傳 13:47–48"> 你們應當趁着有光，信從這光，使你們成為光明之子。」 猶太人的不信<br />耶穌說了這話，就離開他們隱藏了。</span>
<span className="v" id="v37" data-v="37" data-xref="路加福音 16:31; 約翰福音 1:11; 約翰福音 15:24"> 他雖然在他們面前行了許多神蹟，他們還是不信他。</span>
<span className="v" id="v38" data-v="38" data-xref="以賽亞書 53:1; 羅馬書 10:16; 羅馬書 10:20"> 這是要應驗先知以賽亞的話，說：<br /><span className="pl pl-1">主啊，我們所傳的有誰信呢？</span><br /><span className="pl pl-1">主的膀臂向誰顯露呢？</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v39" data-v="39" data-xref="約翰福音 10:38; 約翰福音 5:44; 彼得後書 2:14"> 他們所以不能信，因為以賽亞又說：</span>
<span className="v" id="v40" data-v="40" data-xref="以賽亞書 6:10; 馬太福音 13:13–15; 路加福音 8:10"> <span className="pl pl-1">主叫他們瞎了眼，</span><br /><span className="pl pl-1">硬了心，</span><br /><span className="pl pl-1">免得他們眼睛看見，</span><br /><span className="pl pl-1">心裏明白，回轉過來，</span><br /><span className="pl pl-1">我就醫治他們。</span></span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="以賽亞書 6:1–5; 以賽亞書 6:9–10; 約翰福音 1:14"> 以賽亞因為看見他的榮耀，就指着他說這話。</span>
<span className="v" id="v42" data-v="42" data-xref="約翰福音 9:22; 約翰福音 7:13; 以賽亞書 51:7"> 雖然如此，官長中卻有好些信他的，只因法利賽人的緣故，就不承認，恐怕被趕出會堂。</span>
<span className="v" id="v43" data-v="43" data-xref="約翰福音 5:44; 馬太福音 23:5–7; 約翰福音 5:41"> 這是因他們愛人的榮耀過於愛上帝的榮耀。</span>
</div>
</div>

## 耶穌的話要審判人

<div className="bt">
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="馬太福音 10:40; 約翰福音 13:20; 約翰福音 5:24"> 耶穌大聲說：「信我的，不是信我，乃是信那差我來的。</span>
<span className="v" id="v45" data-v="45" data-xref="約翰福音 14:9–10; 哥林多後書 4:6; 歌羅西書 1:15"> 人看見我，就是看見那差我來的。</span>
<span className="v" id="v46" data-v="46" data-xref="約翰福音 8:12; 詩篇 36:9; 約翰福音 9:5"> 我到世上來，乃是光，叫凡信我的，不住在黑暗裏。</span>
<span className="v" id="v47" data-v="47" data-xref="約翰福音 3:17; 約翰福音 8:15–16; 約翰福音 12:48"> 若有人聽見我的話不遵守，我不審判他。我來本不是要審判世界，乃是要拯救世界。</span>
<span className="v" id="v48" data-v="48" data-xref="路加福音 10:16; 希伯來書 9:27–28; 羅馬書 2:16"> 棄絕我、不領受我話的人，有審判他的－就是我所講的道在末日要審判他。</span>
<span className="v" id="v49" data-v="49" data-xref="約翰福音 14:10; 約翰福音 8:26; 約翰福音 5:30"> 因為我沒有憑着自己講，惟有差我來的父已經給我命令，叫我說甚麼，講甚麼。</span>
<span className="v" id="v50" data-v="50" data-xref="約翰福音 17:3; 約翰福音 6:68; 約翰一書 5:20"> 我也知道他的命令就是永生。故此，我所講的話正是照着父對我所說的。」</span>
</div>
</div>

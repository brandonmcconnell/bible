## 耶穌與尼哥德慕

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="約翰福音 19:39; 約翰福音 7:47–50; 約翰福音 3:10"> 有一個法利賽人，名叫尼哥德慕，是猶太人的官。</span>
<span className="v" id="v2" data-v="2" data-xref="約翰福音 5:36; 使徒行傳 10:38; 使徒行傳 2:22"> 這人夜裏來見耶穌，說：「拉比，我們知道你是由上帝那裏來作師傅的；因為你所行的神蹟，若沒有上帝同在，無人能行。」</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多後書 5:17; 約翰福音 3:5–6; 彼得前書 1:23–25"> 耶穌回答說：「我實實在在地告訴你，人若不重生，就不能見上帝的國。」</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多前書 2:14; 哥林多前書 1:18; 約翰福音 3:3"> 尼哥德慕說：「人已經老了，如何能重生呢？豈能再進母腹生出來嗎？」</span>
<span className="v" id="v5" data-v="5" data-xref="以西結書 36:25–27; 以弗所書 5:26; 使徒行傳 2:38"> 耶穌說：「我實實在在地告訴你，人若不是從水和聖靈生的，就不能進上帝的國。</span>
<span className="v" id="v6" data-v="6" data-xref="加拉太書 5:16–21; 以西結書 36:26–27; 羅馬書 8:4–9"> 從肉身生的就是肉身；從靈生的就是靈。</span>
<span className="v" id="v7" data-v="7" data-xref="約翰福音 3:3; 以弗所書 4:22–24; 羅馬書 12:1–2"> 我說：『你們必須重生』，你不要以為希奇。</span>
<span className="v" id="v8" data-v="8" data-xref="傳道書 11:4–5; 哥林多前書 2:11; 使徒行傳 2:2"> 風隨着意思吹，你聽見風的響聲，卻不曉得從哪裏來，往哪裏去；凡從聖靈生的，也是如此。」</span>
<span className="v" id="v9" data-v="9" data-xref="約翰福音 6:60; 路加福音 1:34; 以賽亞書 42:16"> 尼哥德慕問他說：「怎能有這事呢？」</span>
<span className="v" id="v10" data-v="10" data-xref="馬太福音 22:29; 耶利米書 8:8–9; 以西結書 11:19"> 耶穌回答說：「你是以色列人的先生，還不明白這事嗎？</span>
<span className="v" id="v11" data-v="11" data-xref="約翰福音 8:38; 約翰一書 5:6–12; 約翰福音 12:49"> 我實實在在地告訴你，我們所說的是我們知道的；我們所見證的是我們見過的；你們卻不領受我們的見證。</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多前書 3:1–2; 哥林多前書 2:7–9; 希伯來書 5:11"> 我對你們說地上的事，你們尚且不信，若說天上的事，如何能信呢？</span>
<span className="v" id="v13" data-v="13" data-xref="箴言 30:4; 約翰福音 6:38; 使徒行傳 2:34"> 除了從天降下、仍舊在天的人子，沒有人升過天。</span>
<span className="v" id="v14" data-v="14" data-xref="民數記 21:7–9; 約翰福音 8:28; 約翰福音 12:32–34"> 摩西在曠野怎樣舉蛇，人子也必照樣被舉起來，</span>
<span className="v" id="v15" data-v="15" data-xref="約翰福音 3:16; 約翰福音 6:40; 約翰福音 12:44–46"> 叫一切信他的都得永生<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或譯：叫一切信的人在他裏面得永生">a</a></sup>。</span>
<span className="v" id="v16" data-v="16" data-xref="羅馬書 5:8; 約翰一書 4:9–10; 約翰福音 3:15"> 「上帝愛世人，甚至將他的獨生子賜給他們，叫一切信他的，不致滅亡，反得永生。</span>
<span className="v" id="v17" data-v="17" data-xref="約翰一書 4:14; 路加福音 19:10; 約翰福音 12:47–48"> 因為上帝差他的兒子降世，不是要定世人的罪<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或譯：審判世人；下同">b</a></sup>，乃是要叫世人因他得救。</span>
<span className="v" id="v18" data-v="18" data-xref="馬可福音 16:16; 約翰一書 5:10; 羅馬書 8:1"> 信他的人，不被定罪；不信的人，罪已經定了，因為他不信上帝獨生子的名。</span>
<span className="v" id="v19" data-v="19" data-xref="約翰福音 8:12; 帖撒羅尼迦後書 2:12; 約翰福音 9:39–41"> 光來到世間，世人因自己的行為是惡的，不愛光，倒愛黑暗，定他們的罪就是在此。</span>
<span className="v" id="v20" data-v="20" data-xref="以弗所書 5:11–13; 約翰福音 7:7; 約伯記 24:13–17"> 凡作惡的便恨光，並不來就光，恐怕他的行為受責備。</span>
<span className="v" id="v21" data-v="21" data-xref="約翰一書 1:6; 詩篇 139:23–24; 約翰三書 1:11"> 但行真理的必來就光，要顯明他所行的是靠上帝而行。」</span>
</div>
</div>

## 耶穌和施洗約翰

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="約翰福音 4:1–3; 約翰福音 3:26; 約翰福音 2:13"> 這事以後，耶穌和門徒到了猶太地，在那裏居住，施洗。</span>
<span className="v" id="v23" data-v="23" data-xref="馬可福音 1:4–5; 以西結書 43:2; 馬太福音 3:5–6"> 約翰在靠近撒冷的哀嫩也施洗；因為那裏水多，眾人都去受洗。（</span>
<span className="v" id="v24" data-v="24" data-xref="馬太福音 4:12; 馬太福音 14:3; 馬可福音 6:17"> 那時約翰還沒有下在監裏。）</span>
<span className="v" id="v25" data-v="25" data-xref="約翰福音 2:6; 馬太福音 3:11; 希伯來書 6:2"> 約翰的門徒和一個猶太人辯論潔淨的禮，</span>
<span className="v" id="v26" data-v="26" data-xref="約翰福音 1:7; 約翰福音 1:15; 約翰福音 12:19"> 就來見約翰，說：「拉比，從前同你在約旦河外、你所見證的那位，現在施洗，眾人都往他那裏去了。」</span>
<span className="v" id="v27" data-v="27" data-xref="雅各書 1:17; 哥林多前書 4:7; 哥林多前書 15:10"> 約翰說：「若不是從天上賜的，人就不能得甚麼。</span>
<span className="v" id="v28" data-v="28" data-xref="約翰福音 1:20; 約翰福音 1:23; 馬太福音 3:11–12"> 我曾說：『我不是基督，是奉差遣在他前面的』，你們自己可以給我作見證。</span>
<span className="v" id="v29" data-v="29" data-xref="馬太福音 9:15; 何西阿書 2:19; 以賽亞書 54:5"> 娶新婦的就是新郎；新郎的朋友站着，聽見新郎的聲音就甚喜樂。故此，我這喜樂滿足了。</span>
<span className="v" id="v30" data-v="30" data-xref="歌羅西書 1:18; 詩篇 72:17–19; 希伯來書 3:2–6"> 他必興旺，我必衰微。」</span>
</div>
</div>

## 從天上來的那一位

<div className="bt">
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="約翰福音 8:23; 馬太福音 28:18; 羅馬書 9:5"> 「從天上來的是在萬有之上；從地上來的是屬乎地，他所說的也是屬乎地。從天上來的是在萬有之上。</span>
<span className="v" id="v32" data-v="32" data-xref="約翰福音 3:11; 約翰福音 15:15; 約翰福音 1:11"> 他將所見所聞的見證出來，只是沒有人領受他的見證。</span>
<span className="v" id="v33" data-v="33" data-xref="希伯來書 6:17; 以弗所書 1:13; 提多書 1:1–2"> 那領受他見證的，就印上印，證明上帝是真的。</span>
<span className="v" id="v34" data-v="34" data-xref="使徒行傳 10:38; 馬太福音 12:18; 約翰福音 15:26"> 上帝所差來的就說上帝的話，因為上帝賜聖靈給他是沒有限量的。</span>
<span className="v" id="v35" data-v="35" data-xref="馬太福音 28:18; 約翰福音 5:22; 約翰福音 5:20"> 父愛子，已將萬有交在他手裏。</span>
<span className="v" id="v36" data-v="36" data-xref="約翰福音 5:24; 約翰福音 1:12; 帖撒羅尼迦前書 5:9"> 信子的人有永生；不信子的人得不着永生<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="原文是不得見永生">c</a></sup>，上帝的震怒常在他身上。」</span>
</div>

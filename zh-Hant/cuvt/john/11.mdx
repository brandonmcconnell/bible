## 拉撒路的死

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 10:38–42; 約翰福音 12:17; 列王紀下 20:1–12"> 有一個患病的人，名叫拉撒路，住在伯大尼，就是馬利亞和她姊姊馬大的村莊。</span>
<span className="v" id="v2" data-v="2" data-xref="約翰福音 12:3; 馬可福音 14:3; 馬太福音 26:6–7"> 這馬利亞就是那用香膏抹主，又用頭髮擦他腳的；患病的拉撒路是她的兄弟。</span>
<span className="v" id="v3" data-v="3" data-xref="約翰福音 11:5; 啟示錄 3:19; 提摩太後書 4:20"> 她姊妹兩個就打發人去見耶穌，說：「主啊，你所愛的人病了。」</span>
<span className="v" id="v4" data-v="4" data-xref="約翰福音 11:40; 約翰福音 9:3; 彼得前書 4:14"> 耶穌聽見，就說：「這病不至於死，乃是為上帝的榮耀，叫上帝的兒子因此得榮耀。」</span>
<span className="v" id="v5" data-v="5" data-xref="約翰福音 15:9–13; 約翰福音 16:27; 約翰福音 17:26"> 耶穌素來愛馬大和她妹子並拉撒路。</span>
<span className="v" id="v6" data-v="6" data-xref="以賽亞書 30:18; 以賽亞書 55:8–9; 創世記 45:1–5"> 聽見拉撒路病了，就在所居之地仍住了兩天。</span>
<span className="v" id="v7" data-v="7" data-xref="約翰福音 10:40–42; 路加福音 9:51; 使徒行傳 20:22–24"> 然後對門徒說：「我們再往猶太去吧。」</span>
<span className="v" id="v8" data-v="8" data-xref="約翰福音 10:31; 約翰福音 8:59; 使徒行傳 21:12–13"> 門徒說：「拉比，猶太人近來要拿石頭打你，你還往那裏去嗎？」</span>
<span className="v" id="v9" data-v="9" data-xref="約翰福音 9:4; 約翰福音 12:35; 耶利米書 31:9"> 耶穌回答說：「白日不是有十二小時嗎？人在白日走路，就不致跌倒，因為看見這世上的光。</span>
<span className="v" id="v10" data-v="10" data-xref="約翰一書 2:10–11; 箴言 4:18–19; 耶利米書 13:16"> 若在黑夜走路，就必跌倒，因為他沒有光。」</span>
<span className="v" id="v11" data-v="11" data-xref="但以理書 12:2; 約翰福音 11:13; 約翰福音 11:43–44"> 耶穌說了這話，隨後對他們說：「我們的朋友拉撒路睡了，我去叫醒他。」</span>
<span className="v" id="v12" data-v="12"> 門徒說：「主啊，他若睡了，就必好了。」</span>
<span className="v" id="v13" data-v="13" data-xref="馬太福音 9:24"> 耶穌這話是指着他死說的，他們卻以為是說照常睡了。</span>
<span className="v" id="v14" data-v="14" data-xref="約翰福音 16:25; 約翰福音 16:29; 約翰福音 10:24"> 耶穌就明明地告訴他們說：「拉撒路死了。</span>
<span className="v" id="v15" data-v="15" data-xref="提摩太後書 2:10; 約翰福音 14:10–11; 以賽亞書 54:15"> 我沒有在那裏就歡喜，這是為你們的緣故，好叫你們相信。如今我們可以往他那裏去吧。」</span>
<span className="v" id="v16" data-v="16" data-xref="約翰福音 13:37; 馬太福音 10:3; 約翰福音 21:2"> 多馬，又稱為低土馬，就對那同作門徒的說：「我們也去和他同死吧。」</span>
</div>
</div>

## 復活在我，生命在我

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="約翰福音 11:39; 何西阿書 6:2; 使徒行傳 2:27–31"> 耶穌到了，就知道拉撒路在墳墓裏已經四天了。</span>
<span className="v" id="v18" data-v="18" data-xref="啟示錄 14:20; 啟示錄 21:16; 約翰福音 6:19"> 伯大尼離耶路撒冷不遠，約有六里路。</span>
<span className="v" id="v19" data-v="19" data-xref="約伯記 2:11; 約翰福音 11:31; 帖撒羅尼迦前書 5:11"> 有好些猶太人來看馬大和馬利亞，要為她們的兄弟安慰她們。</span>
<span className="v" id="v20" data-v="20" data-xref="路加福音 10:38–42; 帖撒羅尼迦前書 4:17; 馬太福音 25:1"> 馬大聽見耶穌來了，就出去迎接他；馬利亞卻仍然坐在家裏。</span>
<span className="v" id="v21" data-v="21" data-xref="約翰福音 11:32; 列王紀上 17:18; 馬太福音 9:18"> 馬大對耶穌說：「主啊，你若早在這裏，我兄弟必不死。</span>
<span className="v" id="v22" data-v="22" data-xref="約翰福音 9:31; 約翰福音 11:41–42; 馬太福音 28:18"> 就是現在，我也知道，你無論向上帝求甚麼，上帝也必賜給你。」</span>
<span className="v" id="v23" data-v="23" data-xref="約翰福音 11:43–44"> 耶穌說：「你兄弟必然復活。」</span>
<span className="v" id="v24" data-v="24" data-xref="但以理書 12:2–3; 使徒行傳 24:15; 約翰福音 5:28–29"> 馬大說：「我知道在末日復活的時候，他必復活。」</span>
<span className="v" id="v25" data-v="25" data-xref="帖撒羅尼迦前書 4:14; 約翰福音 3:36; 約翰一書 5:11–12"> 耶穌對她說：「復活在我，生命也在我。信我的人雖然死了，也必復活；</span>
<span className="v" id="v26" data-v="26" data-xref="約翰福音 10:28; 約翰福音 5:24; 羅馬書 8:13"> 凡活着信我的人必永遠不死。你信這話嗎？」</span>
<span className="v" id="v27" data-v="27" data-xref="馬太福音 16:16; 約翰福音 6:69; 約翰福音 6:14"> 馬大說：「主啊，是的，我信你是基督，是上帝的兒子，就是那要臨到世界的。」</span>
</div>
</div>

## 耶穌哭了

<div className="bt">
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="約翰福音 11:20; 約翰福音 13:13; 馬可福音 10:49"> 馬大說了這話，就回去暗暗地叫她妹子馬利亞，說：「夫子來了，叫你。」</span>
<span className="v" id="v29" data-v="29" data-xref="箴言 15:23; 詩篇 27:8; 雅歌 3:1–4"> 馬利亞聽見了，就急忙起來，到耶穌那裏去。</span>
<span className="v" id="v30" data-v="30" data-xref="約翰福音 11:20"> 那時，耶穌還沒有進村子，仍在馬大迎接他的地方。</span>
<span className="v" id="v31" data-v="31" data-xref="約翰福音 11:19; 創世記 37:35; 撒母耳記下 12:16–18"> 那些同馬利亞在家裏安慰她的猶太人，見她急忙起來出去，就跟着她，以為她要往墳墓那裏去哭。</span>
<span className="v" id="v32" data-v="32" data-xref="約翰福音 11:21; 路加福音 17:16; 路加福音 5:8"> 馬利亞到了耶穌那裏，看見他，就俯伏在他腳前，說：「主啊，你若早在這裏，我兄弟必不死。」</span>
<span className="v" id="v33" data-v="33" data-xref="約翰福音 11:38; 約翰福音 12:27; 馬可福音 3:5"> 耶穌看見她哭，並看見與她同來的猶太人也哭，就心裏悲歎，又甚憂愁，</span>
<span className="v" id="v34" data-v="34" data-xref="馬可福音 15:47; 馬太福音 28:6; 約翰福音 1:39"> 便說：「你們把他安放在哪裏？」他們回答說：「請主來看。」</span>
<span className="v" id="v35" data-v="35" data-xref="路加福音 19:41; 希伯來書 4:15; 約翰福音 11:33"> 耶穌哭了。</span>
<span className="v" id="v36" data-v="36" data-xref="約翰福音 11:3; 約翰一書 3:1; 約翰一書 4:9–10"> 猶太人就說：「你看他愛這人是何等懇切。」</span>
<span className="v" id="v37" data-v="37" data-xref="約翰福音 9:6–7; 約翰福音 11:32; 路加福音 23:39"> 其中有人說：「他既然開了瞎子的眼睛，豈不能叫這人不死嗎？」</span>
</div>
</div>

## 拉撒路復活

<div className="bt">
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="約翰福音 11:33; 路加福音 24:2; 馬太福音 27:60"> 耶穌又心裏悲歎，來到墳墓前；那墳墓是個洞，有一塊石頭擋着。</span>
<span className="v" id="v39" data-v="39" data-xref="約翰福音 11:17; 馬可福音 16:3; 詩篇 49:7"> 耶穌說：「你們把石頭挪開。」那死人的姊姊馬大對他說：「主啊，他現在必是臭了，因為他死了已經四天了。」</span>
<span className="v" id="v40" data-v="40" data-xref="約翰福音 11:4; 約翰福音 11:23–26; 羅馬書 4:17–25"> 耶穌說：「我不是對你說過，你若信，就必看見上帝的榮耀嗎？」</span>
<span className="v" id="v41" data-v="41" data-xref="馬太福音 11:25; 約翰福音 17:1; 詩篇 123:1"> 他們就把石頭挪開。耶穌舉目望天，說：「父啊，我感謝你，因為你已經聽我。</span>
<span className="v" id="v42" data-v="42" data-xref="約翰福音 3:17; 約翰福音 17:21; 約翰一書 4:14"> 我也知道你常聽我，但我說這話是為周圍站着的眾人，叫他們信是你差了我來。」</span>
<span className="v" id="v43" data-v="43" data-xref="列王紀下 4:33–36; 使徒行傳 9:40; 使徒行傳 9:34"> 說了這話，就大聲呼叫說：「拉撒路出來！」</span>
<span className="v" id="v44" data-v="44" data-xref="約翰福音 5:25; 約翰福音 20:7; 約翰福音 11:25–26"> 那死人就出來了，手腳裹着布，臉上包着手巾。耶穌對他們說：「解開，叫他走！」</span>
</div>
</div>

## 殺害耶穌的陰謀

<div className="bt">
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="約翰福音 2:23; 約翰福音 11:19; 約翰福音 10:41"> 那些來看馬利亞的猶太人見了耶穌所做的事，就多有信他的；</span>
<span className="v" id="v46" data-v="46" data-xref="約翰福音 9:13; 使徒行傳 5:25; 約翰福音 12:37"> 但其中也有去見法利賽人的，將耶穌所做的事告訴他們。</span>
<span className="v" id="v47" data-v="47" data-xref="馬太福音 26:3; 約翰福音 12:19; 使徒行傳 4:5–6"> 祭司長和法利賽人聚集公會，說：「這人行好些神蹟，我們怎麼辦呢？</span>
<span className="v" id="v48" data-v="48" data-xref="帖撒羅尼迦前書 2:15–16; 馬太福音 23:35–38; 馬太福音 27:25"> 若這樣由着他，人人都要信他，羅馬人也要來奪我們的地土和我們的百姓。」</span>
<span className="v" id="v49" data-v="49" data-xref="馬太福音 26:3; 約翰福音 11:51; 約翰福音 18:13–14"> 內中有一個人，名叫該亞法，本年作大祭司，對他們說：「你們不知道甚麼。</span>
<span className="v" id="v50" data-v="50" data-xref="約翰福音 18:14; 路加福音 24:46; 羅馬書 3:8"> 獨不想一個人替百姓死，免得通國滅亡，就是你們的益處。」</span>
<span className="v" id="v51" data-v="51" data-xref="但以理書 9:26; 哥林多後書 5:21; 出埃及記 28:30"> 他這話不是出於自己，是因他本年作大祭司，所以預言耶穌將要替這一國死；</span>
<span className="v" id="v52" data-v="52" data-xref="約翰福音 10:16; 以賽亞書 49:6; 約翰一書 2:2"> 也不但替這一國死，並要將上帝四散的子民都聚集歸一。</span>
<span className="v" id="v53" data-v="53" data-xref="使徒行傳 5:33; 使徒行傳 9:23; 馬可福音 14:1"> 從那日起，他們就商議要殺耶穌。</span>
</div>
<div className="bp">
<span className="v" id="v54" data-v="54" data-xref="約翰福音 7:1; 約翰福音 7:4; 歷代志下 13:19"> 所以，耶穌不再顯然行在猶太人中間，就離開那裏往靠近曠野的地方去，到了一座城，名叫以法蓮，就在那裏和門徒同住。</span>
</div>
<div className="bp">
<span className="v" id="v55" data-v="55" data-xref="歷代志下 30:17–20; 希伯來書 9:13–14; 約翰福音 6:4"> 猶太人的逾越節近了，有許多人從鄉下上耶路撒冷去，要在節前潔淨自己。</span>
<span className="v" id="v56" data-v="56" data-xref="約翰福音 7:11; 約翰福音 11:7–8"> 他們就尋找耶穌，站在殿裏彼此說：「你們的意思如何，他不來過節嗎？」</span>
<span className="v" id="v57" data-v="57" data-xref="約翰福音 9:22; 約翰福音 8:59; 約翰福音 5:16–18"> 那時，祭司長和法利賽人早已吩咐說，若有人知道耶穌在哪裏，就要報明，好去拿他。</span>
</div>
</div>

## 耶穌的禱告

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="約翰福音 13:31–32; 約翰福音 17:4–5; 腓立比書 2:9–11"> 耶穌說了這話，就舉目望天，說：「父啊，時候到了，願你榮耀你的兒子，使兒子也榮耀你；</span>
<span className="v" id="v2" data-v="2" data-xref="約翰福音 10:28–29; 約翰福音 6:39; 但以理書 7:14"> 正如你曾賜給他權柄管理凡有血氣的，叫他將永生賜給你所賜給他的人。</span>
<span className="v" id="v3" data-v="3" data-xref="約翰一書 5:20; 約翰一書 5:11–12; 耶利米書 9:23–24"> 認識你－獨一的真神，並且認識你所差來的耶穌基督，這就是永生。</span>
<span className="v" id="v4" data-v="4" data-xref="約翰福音 4:34; 使徒行傳 20:24; 提摩太後書 4:7"> 我在地上已經榮耀你，你所託付我的事，我已成全了。</span>
<span className="v" id="v5" data-v="5" data-xref="約翰福音 1:1–3; 歌羅西書 1:15–17; 約翰福音 10:30"> 父啊，現在求你使我同你享榮耀，就是未有世界以先，我同你所有的榮耀。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="約翰福音 17:26; 約翰福音 14:21–24; 約翰一書 5:20"> 「你從世上賜給我的人，我已將你的名顯明與他們。他們本是你的，你將他們賜給我，他們也遵守了你的道。</span>
<span className="v" id="v7" data-v="7" data-xref="約翰福音 7:16–17; 約翰福音 16:15; 約翰福音 14:7–10"> 如今他們知道，凡你所賜給我的，都是從你那裏來的；</span>
<span className="v" id="v8" data-v="8" data-xref="約翰福音 17:14; 約翰福音 15:15; 約翰福音 16:30"> 因為你所賜給我的道，我已經賜給他們，他們也領受了，又確實知道，我是從你出來的，並且信你差了我來。</span>
<span className="v" id="v9" data-v="9" data-xref="希伯來書 9:24; 約翰福音 17:2; 約翰福音 17:6"> 我為他們祈求，不為世人祈求，卻為你所賜給我的人祈求，因他們本是你的。</span>
<span className="v" id="v10" data-v="10" data-xref="約翰福音 10:30; 彼得前書 2:9; 啟示錄 5:8–14"> 凡是我的，都是你的；你的也是我的，並且我因他們得了榮耀。</span>
<span className="v" id="v11" data-v="11" data-xref="馬太福音 6:9; 箴言 18:10; 約翰福音 17:12–18"> 從今以後，我不在世上，他們卻在世上；我往你那裏去。聖父啊，求你因你所賜給我的名保守他們，叫他們合而為一像我們一樣。</span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 109:6–19; 約翰福音 10:27–28; 約翰福音 18:9"> 我與他們同在的時候，因你所賜給我的名保守了他們，我也護衛了他們；其中除了那滅亡之子，沒有一個滅亡的，好叫經上的話得應驗。</span>
<span className="v" id="v13" data-v="13" data-xref="希伯來書 12:2; 加拉太書 5:22; 約翰福音 15:11"> 現在我往你那裏去，我還在世上說這話，是叫他們心裏充滿我的喜樂。</span>
<span className="v" id="v14" data-v="14" data-xref="約翰福音 17:16; 約翰福音 15:18–21; 約翰一書 5:19–20"> 我已將你的道賜給他們。世界又恨他們；因為他們不屬世界，正如我不屬世界一樣。</span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 121:7; 約翰一書 5:18; 馬太福音 6:13"> 我不求你叫他們離開世界，只求你保守他們脫離那惡者<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或譯：脫離罪惡">a</a></sup>。</span>
<span className="v" id="v16" data-v="16" data-xref="約翰福音 17:14"> 他們不屬世界，正如我不屬世界一樣。</span>
<span className="v" id="v17" data-v="17" data-xref="約翰福音 15:3; 詩篇 119:160; 以弗所書 5:26"> 求你用真理使他們成聖；你的道就是真理。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多後書 5:20; 約翰福音 20:21; 約翰福音 17:3"> 你怎樣差我到世上，我也照樣差他們到世上。</span>
<span className="v" id="v19" data-v="19" data-xref="提多書 2:14; 希伯來書 2:11; 約翰福音 17:17"> 我為他們的緣故，自己分別為聖，叫他們也因真理成聖。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="約翰福音 17:6–11; 使徒行傳 2:41; 使徒行傳 4:4"> 「我不但為這些人祈求，也為那些因他們的話信我的人祈求，</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多前書 12:12; 歌羅西書 3:11–14; 約翰福音 17:11"> 使他們都合而為一。正如你父在我裏面，我在你裏面，使他們也在我們裏面，叫世人可以信你差了我來。</span>
<span className="v" id="v22" data-v="22" data-xref="哥林多後書 3:18; 約翰福音 14:20; 馬可福音 16:17–20"> 你所賜給我的榮耀，我已賜給他們，使他們合而為一，像我們合而為一。</span>
<span className="v" id="v23" data-v="23" data-xref="約翰福音 17:21; 約翰福音 16:27; 約翰一書 3:1"> 我在他們裏面，你在我裏面，使他們完完全全地合而為一，叫世人知道你差了我來，也知道你愛他們如同愛我一樣。</span>
<span className="v" id="v24" data-v="24" data-xref="約翰福音 17:5; 約翰福音 12:26; 約翰福音 14:3"> 父啊，我在哪裏，願你所賜給我的人也同我在那裏，叫他們看見你所賜給我的榮耀；因為創立世界以前，你已經愛我了。</span>
<span className="v" id="v25" data-v="25" data-xref="約翰福音 17:11; 約翰福音 7:29; 約翰福音 17:8"> 公義的父啊，世人未曾認識你，我卻認識你；這些人也知道你差了我來。</span>
<span className="v" id="v26" data-v="26" data-xref="約翰福音 17:23; 約翰福音 17:6; 約翰福音 15:9"> 我已將你的名指示他們，還要指示他們，使你所愛我的愛在他們裏面，我也在他們裏面。」</span>
</div>

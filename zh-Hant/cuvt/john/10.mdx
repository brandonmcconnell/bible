## 羊圈的比喻

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="馬太福音 7:15; 約翰福音 10:8–10; 羅馬書 16:18"> 「我實實在在地告訴你們，人進羊圈，不從門進去，倒從別處爬進去，那人就是賊，就是強盜。</span>
<span className="v" id="v2" data-v="2" data-xref="約翰福音 10:14; 使徒行傳 20:28; 彼得前書 5:4"> 從門進去的，才是羊的牧人。</span>
<span className="v" id="v3" data-v="3" data-xref="以西結書 34:11–16; 提摩太後書 2:19; 約翰福音 10:4"> 看門的就給他開門；羊也聽他的聲音。他按着名叫自己的羊，把羊領出來。</span>
<span className="v" id="v4" data-v="4" data-xref="申命記 1:30; 約翰福音 10:16; 約翰福音 12:26"> 既放出自己的羊來，就在前頭走，羊也跟着他，因為認得他的聲音。</span>
<span className="v" id="v5" data-v="5" data-xref="約翰一書 4:5–6; 歌羅西書 2:6–10; 馬可福音 4:24"> 羊不跟着生人；因為不認得他的聲音， 必要逃跑。」</span>
<span className="v" id="v6" data-v="6" data-xref="以賽亞書 56:11; 詩篇 82:5; 箴言 28:5"> 耶穌將這比喻告訴他們，但他們不明白所說的是甚麼意思。</span>
</div>
</div>

## 好牧人耶穌

<div className="bt">
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="約翰福音 14:6; 以弗所書 2:18; 約翰福音 10:1"> 所以，耶穌又對他們說：「我實實在在地告訴你們，我就是羊的門。</span>
<span className="v" id="v8" data-v="8" data-xref="以西結書 34:2; 耶利米書 23:1; 約翰福音 10:1"> 凡在我以先來的都是賊，是強盜；羊卻不聽他們。</span>
<span className="v" id="v9" data-v="9" data-xref="約翰福音 14:6; 以弗所書 2:18; 約翰福音 10:7"> 我就是門；凡從我進來的，必然得救，並且出入得草吃。</span>
<span className="v" id="v10" data-v="10" data-xref="路加福音 19:10; 約翰福音 6:51; 約翰福音 12:47"> 盜賊來，無非要偷竊，殺害，毀壞；我來了，是要叫羊<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或譯：人">a</a></sup>得生命，並且得的更豐盛。</span>
<span className="v" id="v11" data-v="11" data-xref="約翰福音 10:14–15; 詩篇 23:1; 約翰福音 15:13"> 我是好牧人；好牧人為羊捨命。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行傳 20:29; 撒迦利亞書 11:16–17; 以西結書 34:2–6"> 若是雇工，不是牧人，羊也不是他自己的，他看見狼來，就撇下羊逃走；狼抓住羊，趕散了羊群。</span>
<span className="v" id="v13" data-v="13" data-xref="腓立比書 2:20; 約翰福音 12:6; 使徒行傳 18:17"> 雇工逃走，因他是雇工，並不顧念羊。</span>
<span className="v" id="v14" data-v="14" data-xref="約翰福音 10:27; 約翰福音 10:11; 提摩太後書 2:19"> 我是好牧人；我認識我的羊，我的羊也認識我，</span>
<span className="v" id="v15" data-v="15" data-xref="加拉太書 1:4; 約翰福音 10:11; 以賽亞書 53:10"> 正如父認識我，我也認識父一樣；並且我為羊捨命。</span>
<span className="v" id="v16" data-v="16" data-xref="以賽亞書 56:8; 約翰福音 11:52; 彼得前書 2:25"> 我另外有羊，不是這圈裏的；我必須領他們來，他們也要聽我的聲音，並且要合成一群，歸一個牧人了。</span>
<span className="v" id="v17" data-v="17" data-xref="約翰福音 10:18; 約翰福音 10:11; 希伯來書 2:9"> 我父愛我；因我將命捨去，好再取回來。</span>
<span className="v" id="v18" data-v="18" data-xref="希伯來書 2:9; 提多書 2:14; 約翰福音 2:19–21"> 沒有人奪我的命去，是我自己捨的。我有權柄捨了，也有權柄取回來。這是我從我父所受的命令。」</span>
<span className="v" id="v19" data-v="19" data-xref="約翰福音 9:16; 哥林多前書 3:3; 約翰福音 7:40–43"> 猶太人為這些話又起了紛爭。</span>
<span className="v" id="v20" data-v="20" data-xref="約翰福音 7:20; 馬可福音 3:21; 約翰福音 8:47–48"> 內中有好些人說：「他是被鬼附着，而且瘋了，為甚麼聽他呢？」</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及記 4:11; 以賽亞書 35:5–6; 詩篇 94:9"> 又有人說：「這不是鬼附之人所說的話。鬼豈能叫瞎子的眼睛開了呢？」</span>
</div>
</div>

## 被猶太人棄絕

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22"> 在耶路撒冷有修殿節，是冬天的時候。</span>
<span className="v" id="v23" data-v="23" data-xref="使徒行傳 5:12; 使徒行傳 3:11"> 耶穌在殿裏所羅門的廊下行走。</span>
<span className="v" id="v24" data-v="24" data-xref="路加福音 22:67–70; 約翰福音 1:19; 約翰福音 8:25"> 猶太人圍着他，說：「你叫我們猶疑不定到幾時呢？你若是基督，就明明地告訴我們。」</span>
<span className="v" id="v25" data-v="25" data-xref="約翰福音 10:38; 約翰福音 8:58; 約翰福音 14:11"> 耶穌回答說：「我已經告訴你們，你們不信。我奉我父之名所行的事可以為我作見證；</span>
<span className="v" id="v26" data-v="26" data-xref="約翰福音 8:47; 哥林多後書 4:3–4; 約翰福音 12:37–40"> 只是你們不信，因為你們不是我的羊。</span>
<span className="v" id="v27" data-v="27" data-xref="約翰福音 10:16; 約翰福音 10:14; 啟示錄 3:20"> 我的羊聽我的聲音，我也認識他們，他們也跟着我。</span>
<span className="v" id="v28" data-v="28" data-xref="約翰福音 6:39–40; 約翰福音 6:37; 約翰福音 3:15–16"> 我又賜給他們永生；他們永不滅亡，誰也不能從我手裏把他們奪去。</span>
<span className="v" id="v29" data-v="29" data-xref="約翰福音 6:37; 約翰福音 17:2; 約翰福音 17:9"> 我父把羊賜給我，他比萬有都大，誰也不能從我父手裏把他們奪去。</span>
<span className="v" id="v30" data-v="30" data-xref="約翰福音 1:1–2; 約翰福音 14:9; 約翰福音 17:21–23"> 我與父原為一。」</span>
<span className="v" id="v31" data-v="31" data-xref="約翰福音 5:18; 約翰福音 8:59; 撒母耳記上 30:6"> 猶太人又拿起石頭來要打他。</span>
<span className="v" id="v32" data-v="32" data-xref="約翰一書 3:12; 約翰福音 5:36; 詩篇 35:12"> 耶穌對他們說：「我從父顯出許多善事給你們看，你們是為哪一件拿石頭打我呢？」</span>
<span className="v" id="v33" data-v="33" data-xref="約翰福音 5:18; 利未記 24:16; 約翰福音 10:30"> 猶太人回答說：「我們不是為善事拿石頭打你，是為你說僭妄的話；又為你是個人，反將自己當作上帝。」</span>
<span className="v" id="v34" data-v="34" data-xref="詩篇 82:6–7; 出埃及記 7:1; 詩篇 82:1"> 耶穌說：「你們的律法上豈不是寫着『我曾說你們是神』嗎？</span>
<span className="v" id="v35" data-v="35" data-xref="馬太福音 24:35; 羅馬書 13:1; 路加福音 16:17"> 經上的話是不能廢的；若那些承受上帝道的人尚且稱為神，</span>
<span className="v" id="v36" data-v="36" data-xref="約翰福音 5:17–18; 約翰福音 3:17; 耶利米書 1:5"> 父所分別為聖、又差到世間來的，他自稱是上帝的兒子，你們還向他說『你說僭妄的話』嗎？</span>
<span className="v" id="v37" data-v="37" data-xref="約翰福音 15:24; 約翰福音 10:25; 約翰福音 12:37–40"> 我若不行我父的事，你們就不必信我；</span>
<span className="v" id="v38" data-v="38" data-xref="約翰福音 14:20; 約翰福音 10:25; 約翰福音 10:30"> 我若行了，你們縱然不信我，也當信這些事，叫你們又知道又明白父在我裏面，我也在父裏面。」</span>
<span className="v" id="v39" data-v="39" data-xref="約翰福音 7:30; 約翰福音 8:59; 約翰福音 7:44"> 他們又要拿他，他卻逃出他們的手走了。</span>
<span className="v" id="v40" data-v="40" data-xref="約翰福音 1:28; 約翰福音 11:54; 約翰福音 7:1"> 耶穌又往約旦河外去，到了約翰起初施洗的地方，就住在那裏。</span>
<span className="v" id="v41" data-v="41" data-xref="約翰福音 1:33–34; 約翰福音 1:29–30; 馬可福音 1:37"> 有許多人來到他那裏。他們說：「約翰一件神蹟沒有行過，但約翰指着這人所說的一切話都是真的。」</span>
<span className="v" id="v42" data-v="42" data-xref="約翰福音 4:41; 約翰福音 2:23; 約翰福音 7:31"> 在那裏，信耶穌的人就多了。</span>
</div>
</div>

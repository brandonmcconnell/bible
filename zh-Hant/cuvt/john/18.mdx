## 耶穌被捕

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="馬可福音 14:32; 馬太福音 26:36; 撒母耳記下 15:23"> 耶穌說了這話，就同門徒出去，過了汲淪溪。在那裏有一個園子，他和門徒進去了。</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 21:37; 路加福音 22:39; 馬可福音 11:11–12"> 賣耶穌的猶大也知道那地方，因為耶穌和門徒屢次上那裏去聚集。</span>
<span className="v" id="v3" data-v="3" data-xref="約翰福音 18:12; 路加福音 22:47–53; 詩篇 22:12"> 猶大領了一隊兵，和祭司長並法利賽人的差役，拿着燈籠、火把、兵器，就來到園裏。</span>
<span className="v" id="v4" data-v="4" data-xref="約翰福音 13:1; 約翰福音 18:7; 詩篇 27:3"> 耶穌知道將要臨到自己的一切事，就出來對他們說：「你們找誰？」</span>
<span className="v" id="v5" data-v="5" data-xref="馬太福音 21:11; 約翰福音 19:19; 馬太福音 2:23"> 他們回答說：「找拿撒勒人耶穌。」耶穌說：「我就是！」賣他的猶大也同他們站在那裏。</span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 27:2; 詩篇 70:2–3; 列王紀下 1:9–15"> 耶穌一說「我就是」，他們就退後倒在地上。</span>
<span className="v" id="v7" data-v="7" data-xref="約翰福音 18:4"> 他又問他們說：「你們找誰？」他們說：「找拿撒勒人耶穌。」</span>
<span className="v" id="v8" data-v="8" data-xref="約翰福音 10:28; 馬太福音 26:56; 哥林多後書 12:9"> 耶穌說：「我已經告訴你們，我就是。你們若找我，就讓這些人去吧。」</span>
<span className="v" id="v9" data-v="9" data-xref="約翰福音 17:12"> 這要應驗耶穌從前的話，說：「你所賜給我的人，我沒有失落一個。」</span>
<span className="v" id="v10" data-v="10" data-xref="馬可福音 14:47; 馬太福音 26:51–54; 路加福音 22:49–51"> 西門‧彼得帶着一把刀，就拔出來，將大祭司的僕人砍了一刀，削掉他的右耳；那僕人名叫馬勒古。</span>
<span className="v" id="v11" data-v="11" data-xref="馬太福音 20:22; 馬太福音 26:39; 約翰福音 20:17"> 耶穌就對彼得說：「收刀入鞘吧，我父所給我的那杯，我豈可不喝呢？」</span>
</div>
</div>

## 耶穌被帶到亞那面前

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="馬太福音 26:57; 約翰福音 18:3; 使徒行傳 21:37"> 那隊兵和千夫長，並猶太人的差役就拿住耶穌，把他捆綁了，</span>
<span className="v" id="v13" data-v="13" data-xref="約翰福音 18:24; 約翰福音 11:51; 馬太福音 26:3"> 先帶到亞那面前，因為亞那是本年作大祭司該亞法的岳父。</span>
<span className="v" id="v14" data-v="14" data-xref="約翰福音 11:49–52"> 這該亞法就是從前向猶太人發議論說「一個人替百姓死是有益的」那位。</span>
</div>
</div>

## 彼得不認耶穌

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="路加福音 22:54; 馬可福音 14:54; 馬太福音 26:58–68"> 西門‧彼得跟着耶穌，還有一個門徒跟着。那門徒是大祭司所認識的，他就同耶穌進了大祭司的院子。</span>
<span className="v" id="v16" data-v="16" data-xref="馬太福音 26:69; 馬可福音 14:66–68; 路加福音 22:55–57"> 彼得卻站在門外。大祭司所認識的那個門徒出來，和看門的使女說了一聲，就領彼得進去。</span>
<span className="v" id="v17" data-v="17" data-xref="馬太福音 26:69–70; 約翰福音 21:15; 路加福音 22:56–57"> 那看門的使女對彼得說：「你不也是這人的門徒嗎？」他說：「我不是。」</span>
<span className="v" id="v18" data-v="18" data-xref="馬可福音 14:54; 約翰福音 18:25; 馬可福音 14:67"> 僕人和差役因為天冷，就生了炭火，站在那裏烤火；彼得也同他們站着烤火。</span>
</div>
</div>

## 大祭司盤問耶穌

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="馬可福音 14:55–65; 路加福音 20:20; 路加福音 22:63–71"> 大祭司就以耶穌的門徒和他的教訓盤問他。</span>
<span className="v" id="v20" data-v="20" data-xref="約翰福音 7:26; 以賽亞書 48:16; 馬太福音 4:23"> 耶穌回答說：「我從來是明明地對世人說話。我常在會堂和殿裏，就是猶太人聚集的地方教訓人；我在暗地裏並沒有說甚麼。</span>
<span className="v" id="v21" data-v="21" data-xref="馬太福音 26:59–60; 使徒行傳 24:12–13; 路加福音 22:67"> 你為甚麼問我呢？可以問那聽見的人，我對他們說的是甚麼；我所說的，他們都知道。」</span>
<span className="v" id="v22" data-v="22" data-xref="約翰福音 19:3; 馬可福音 14:65; 路加福音 22:63–64"> 耶穌說了這話，旁邊站着的一個差役用手掌打他，說：「你這樣回答大祭司嗎？」</span>
<span className="v" id="v23" data-v="23" data-xref="彼得前書 2:20–23; 哥林多後書 10:1; 馬太福音 5:39"> 耶穌說：「我若說的不是，你可以指證那不是；我若說的是，你為甚麼打我呢？」</span>
<span className="v" id="v24" data-v="24" data-xref="約翰福音 18:13; 馬太福音 26:57"> 亞那就把耶穌解到大祭司該亞法那裏，仍是捆着解去的。</span>
</div>
</div>

## 彼得再次不認耶穌

<div className="bt">
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="馬可福音 14:67–72; 約翰福音 18:17–18; 創世記 18:15"> 西門‧彼得正站着烤火，有人對他說：「你不也是他的門徒嗎？」彼得不承認，說：「我不是。」</span>
<span className="v" id="v26" data-v="26" data-xref="約翰福音 18:1; 約翰福音 18:10; 馬太福音 26:73"> 有大祭司的一個僕人，是彼得削掉耳朵那人的親屬，說：「我不是看見你同他在園子裏嗎？」</span>
<span className="v" id="v27" data-v="27" data-xref="約翰福音 13:38; 馬可福音 14:71–72; 路加福音 22:60–62"> 彼得又不承認。立時雞就叫了。</span>
</div>
</div>

## 耶穌在彼拉多面前受審

<div className="bt">
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="約翰福音 18:33; 約翰福音 19:9; 馬太福音 27:27"> 眾人將耶穌從該亞法那裏往衙門內解去，那時天還早。他們自己卻不進衙門，恐怕染了污穢，不能吃逾越節的筵席。</span>
<span className="v" id="v29" data-v="29" data-xref="馬太福音 27:23; 馬可福音 15:2–5; 馬太福音 27:11–14"> 彼拉多就出來，到他們那裏，說：「你們告這人是為甚麼事呢？」</span>
<span className="v" id="v30" data-v="30" data-xref="使徒行傳 3:13; 路加福音 20:19–26; 馬可福音 10:33"> 他們回答說：「這人若不是作惡的，我們就不把他交給你。」</span>
<span className="v" id="v31" data-v="31" data-xref="約翰福音 19:6–7; 約翰福音 19:15; 使徒行傳 25:18–20"> 彼拉多說：「你們自己帶他去，按着你們的律法審問他吧。」猶太人說：「我們沒有殺人的權柄。」</span>
<span className="v" id="v32" data-v="32" data-xref="約翰福音 3:14; 馬太福音 20:19; 馬太福音 26:2"> 這要應驗耶穌所說自己將要怎樣死的話了。</span>
<span className="v" id="v33" data-v="33" data-xref="路加福音 23:3–4; 約翰福音 18:37; 約翰福音 19:3"> 彼拉多又進了衙門，叫耶穌來，對他說：「你是猶太人的王嗎？」</span>
<span className="v" id="v34" data-v="34"> 耶穌回答說：「這話是你自己說的，還是別人論我對你說的呢？」</span>
<span className="v" id="v35" data-v="35" data-xref="使徒行傳 18:14–16; 尼希米記 4:2; 羅馬書 3:1–2"> 彼拉多說：「我豈是猶太人呢？你本國的人和祭司長把你交給我。你做了甚麼事呢？」</span>
<span className="v" id="v36" data-v="36" data-xref="路加福音 17:20–21; 歌羅西書 1:12–14; 羅馬書 14:17"> 耶穌回答說：「我的國不屬這世界；我的國若屬這世界，我的臣僕必要爭戰，使我不至於被交給猶太人。只是我的國不屬這世界。」</span>
<span className="v" id="v37" data-v="37" data-xref="約翰一書 4:6; 約翰福音 8:47; 約翰福音 8:14"> 彼拉多就對他說：「這樣，你是王嗎？」耶穌回答說：「你說我是王。我為此而生，也為此來到世間，特為給真理作見證。凡屬真理的人就聽我的話。」</span>
<span className="v" id="v38" data-v="38" data-xref="約翰福音 19:4; 路加福音 23:4; 約翰福音 19:6"> 彼拉多說：「真理是甚麼呢？」 耶穌被判死刑 （太27‧15－31；可15‧6－20；路23‧13－25）<br />說了這話，又出來到猶太人那裏，對他們說：「我查不出他有甚麼罪來。</span>
<span className="v" id="v39" data-v="39" data-xref="馬太福音 27:15–18; 路加福音 23:16–23; 馬可福音 15:6–14"> 但你們有個規矩，在逾越節要我給你們釋放一個人，你們要我給你們釋放猶太人的王嗎？」</span>
<span className="v" id="v40" data-v="40" data-xref="路加福音 23:25; 馬可福音 15:15; 馬太福音 27:16"> 他們又喊着說：「不要這人，要巴拉巴！」這巴拉巴是個強盜。</span>

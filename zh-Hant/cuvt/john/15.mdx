## 耶穌是真葡萄樹

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="耶利米書 2:21; 以賽亞書 27:2–3; 哥林多前書 3:9"> 「我是真葡萄樹，我父是栽培的人。</span>
<span className="v" id="v2" data-v="2" data-xref="馬太福音 3:10; 希伯來書 12:10–11; 馬太福音 15:13"> 凡屬我不結果子的枝子，他就剪去；凡結果子的，他就修理乾淨，使枝子結果子更多。</span>
<span className="v" id="v3" data-v="3" data-xref="約翰福音 17:17; 以弗所書 5:26; 彼得前書 1:22"> 現在你們因我講給你們的道，已經乾淨了。</span>
<span className="v" id="v4" data-v="4" data-xref="約翰一書 2:6; 加拉太書 2:20; 約翰福音 8:31"> 你們要常在我裏面，我也常在你們裏面。枝子若不常在葡萄樹上，自己就不能結果子；你們若不常在我裏面，也是這樣。</span>
<span className="v" id="v5" data-v="5" data-xref="腓立比書 4:13; 歌羅西書 1:10; 約翰福音 15:16"> 我是葡萄樹，你們是枝子。常在我裏面的，我也常在他裏面，這人就多結果子；因為離了我，你們就不能做甚麼。</span>
<span className="v" id="v6" data-v="6" data-xref="馬太福音 7:19; 希伯來書 6:7–8; 馬太福音 13:41"> 人若不常在我裏面，就像枝子丟在外面枯乾，人拾起來，扔在火裏燒了。</span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 37:4; 約翰一書 5:14; 約翰福音 14:13"> 你們若常在我裏面，我的話也常在你們裏面，凡你們所願意的，祈求，就給你們成就。</span>
<span className="v" id="v8" data-v="8" data-xref="約翰福音 8:31; 馬太福音 5:16; 腓立比書 1:11"> 你們多結果子，我父就因此得榮耀，你們也就是我的門徒了。</span>
<span className="v" id="v9" data-v="9" data-xref="約翰福音 17:23–24; 約翰福音 17:26; 約翰一書 2:28"> 我愛你們，正如父愛我一樣；你們要常在我的愛裏。</span>
<span className="v" id="v10" data-v="10" data-xref="約翰福音 14:15; 約翰一書 5:3; 約翰一書 3:21–24"> 你們若遵守我的命令，就常在我的愛裏，正如我遵守了我父的命令，常在他的愛裏。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="約翰福音 17:13; 羅馬書 15:13; 約翰福音 16:24"> 「這些事我已經對你們說了，是要叫我的喜樂存在你們心裏，並叫你們的喜樂可以滿足。</span>
<span className="v" id="v12" data-v="12" data-xref="約翰一書 4:21; 彼得前書 4:8; 約翰福音 13:34"> 你們要彼此相愛，像我愛你們一樣；這就是我的命令。</span>
<span className="v" id="v13" data-v="13" data-xref="約翰福音 10:11; 以弗所書 5:2; 羅馬書 5:6–8"> 人為朋友捨命，人的愛心沒有比這個大的。</span>
<span className="v" id="v14" data-v="14" data-xref="馬太福音 12:50; 約翰一書 5:3; 雅各書 2:23"> 你們若遵行我所吩咐的，就是我的朋友了。</span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 25:14; 哥林多前書 2:9–12; 馬太福音 13:11"> 以後我不再稱你們為僕人，因僕人不知道主人所做的事。我乃稱你們為朋友；因我從我父所聽見的，已經都告訴你們了。</span>
<span className="v" id="v16" data-v="16" data-xref="約翰福音 15:19; 耶利米書 1:5–7; 以弗所書 2:10"> 不是你們揀選了我，是我揀選了你們，並且分派你們去結果子，叫你們的果子常存，使你們奉我的名，無論向父求甚麼，他就賜給你們。</span>
<span className="v" id="v17" data-v="17" data-xref="約翰福音 15:12; 約翰一書 3:14–17; 彼得前書 2:17"> 我這樣吩咐你們，是要叫你們彼此相愛。」</span>
</div>
</div>

## 世人的憎恨

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="約翰一書 3:13; 約翰福音 7:7; 馬可福音 13:13"> 「世人若恨你們，你們知道<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或譯：該知道">a</a></sup>，恨你們以先已經恨我了。</span>
<span className="v" id="v19" data-v="19" data-xref="約翰一書 4:4–5; 約翰福音 17:14–16; 以弗所書 1:4–11"> 你們若屬世界，世界必愛屬自己的；只因你們不屬世界，乃是我從世界中揀選了你們，所以世界就恨你們。</span>
<span className="v" id="v20" data-v="20" data-xref="提摩太後書 3:12; 約翰福音 13:16; 馬太福音 10:24"> 你們要記念我從前對你們所說的話：『僕人不能大於主人。』他們若逼迫了我，也要逼迫你們；若遵守了我的話，也要遵守你們的話。</span>
<span className="v" id="v21" data-v="21" data-xref="馬太福音 10:22; 約翰福音 16:3; 馬太福音 10:18"> 但他們因我的名要向你們行這一切的事，因為他們不認識那差我來的。</span>
<span className="v" id="v22" data-v="22" data-xref="約翰福音 9:41; 雅各書 4:17; 使徒行傳 17:30"> 我若沒有來教訓他們，他們就沒有罪；但如今他們的罪無可推諉了。</span>
<span className="v" id="v23" data-v="23" data-xref="約翰福音 8:40–42; 約翰二書 1:9; 約翰一書 2:23"> 恨我的，也恨我的父。</span>
<span className="v" id="v24" data-v="24" data-xref="約翰福音 5:36; 約翰福音 14:9; 約翰福音 7:31"> 我若沒有在他們中間行過別人未曾行的事，他們就沒有罪；但如今連我與我的父，他們也看見也恨惡了。</span>
<span className="v" id="v25" data-v="25" data-xref="詩篇 109:3; 詩篇 69:4; 詩篇 35:19"> 這要應驗他們律法上所寫的話，說：『他們無故地恨我。』</span>
<span className="v" id="v26" data-v="26" data-xref="約翰福音 14:26; 約翰福音 14:16–17; 約翰福音 16:13–15"> 但我要從父那裏差保惠師來，就是從父出來真理的聖靈；他來了，就要為我作見證。</span>
<span className="v" id="v27" data-v="27" data-xref="約翰一書 4:14; 約翰福音 21:24; 使徒行傳 10:39–42"> 你們也要作見證，因為你們從起頭就與我同在。」</span>
</div>

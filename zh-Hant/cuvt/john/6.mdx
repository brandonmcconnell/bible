## 耶穌給五千人吃飽

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="馬可福音 6:31–44; 約翰福音 6:23; 路加福音 5:1"> 這事以後，耶穌渡過加利利海，就是提比哩亞海。</span>
<span className="v" id="v2" data-v="2" data-xref="馬太福音 4:24–25; 馬太福音 12:15; 馬太福音 15:30–31"> 有許多人因為看見他在病人身上所行的神蹟，就跟隨他。</span>
<span className="v" id="v3" data-v="3" data-xref="約翰福音 6:15; 路加福音 9:28; 路加福音 6:12–13"> 耶穌上了山，和門徒一同坐在那裏。</span>
<span className="v" id="v4" data-v="4" data-xref="約翰福音 2:13; 約翰福音 11:55; 約翰福音 5:1"> 那時猶太人的逾越節近了。</span>
<span className="v" id="v5" data-v="5" data-xref="馬太福音 15:33; 路加福音 9:12–13; 馬太福音 14:14–15"> 耶穌舉目看見許多人來，就對腓力說：「我們從哪裏買餅叫這些人吃呢？」（</span>
<span className="v" id="v6" data-v="6" data-xref="創世記 22:1; 申命記 13:3; 歷代志下 32:31"> 他說這話是要試驗腓力；他自己原知道要怎樣行。）</span>
<span className="v" id="v7" data-v="7" data-xref="民數記 11:21–22; 馬可福音 6:37; 約翰福音 12:5"> 腓力回答說：「就是二十兩銀子的餅，叫他們各人吃一點也是不夠的。」</span>
<span className="v" id="v8" data-v="8" data-xref="約翰福音 1:40–44; 馬太福音 4:18"> 有一個門徒，就是西門‧彼得的兄弟安得烈，對耶穌說：</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀下 4:42–44; 馬太福音 14:17; 馬可福音 6:38"> 「在這裏有一個孩童，帶着五個大麥餅、兩條魚，只是分給這許多人還算甚麼呢？」</span>
<span className="v" id="v10" data-v="10" data-xref="路加福音 9:14–16; 馬太福音 15:35–36; 馬可福音 6:39–41"> 耶穌說：「你們叫眾人坐下。」原來那地方的草多，眾人就坐下，數目約有五千。</span>
<span className="v" id="v11" data-v="11" data-xref="約翰福音 6:23; 帖撒羅尼迦前書 5:18; 馬太福音 15:36"> 耶穌拿起餅來，祝謝了，就分給那坐着的人；分魚也是這樣，都隨着他們所要的。</span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 1:53; 尼希米記 9:25; 尼希米記 8:10"> 他們吃飽了，耶穌對門徒說：「把剩下的零碎收拾起來，免得有糟蹋的。」</span>
<span className="v" id="v13" data-v="13" data-xref="箴言 11:24–25; 列王紀下 4:2–7; 哥林多後書 9:8–9"> 他們便將那五個大麥餅的零碎，就是眾人吃了剩下的，收拾起來，裝滿了十二個籃子。</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 18:15–18; 馬太福音 21:11; 使徒行傳 7:37"> 眾人看見耶穌所行的神蹟，就說：「這真是那要到世間來的先知！」</span>
<span className="v" id="v15" data-v="15" data-xref="約翰福音 18:36; 約翰福音 6:15–21; 約翰福音 7:3–4"> 耶穌既知道眾人要來強逼他作王，就獨自又退到山上去了。</span>
</div>
</div>

## 耶穌在海面上行走

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16"> 到了晚上，他的門徒下海邊去，</span>
<span className="v" id="v17" data-v="17" data-xref="馬可福音 6:45; 約翰福音 6:24–25; 約翰福音 2:12"> 上了船，要過海往迦百農去。天已經黑了，耶穌還沒有來到他們那裏。</span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 107:25; 詩篇 135:7; 馬太福音 14:24"> 忽然狂風大作，海就翻騰起來。</span>
<span className="v" id="v19" data-v="19" data-xref="馬可福音 6:47–49; 馬太福音 14:25–26; 約伯記 9:8"> 門徒搖櫓，約行了十里多路，看見耶穌在海面上走，漸漸近了船，他們就害怕。</span>
<span className="v" id="v20" data-v="20" data-xref="馬太福音 14:27–31; 以賽亞書 43:1–2; 以賽亞書 44:8"> 耶穌對他們說：「是我，不要怕！」</span>
<span className="v" id="v21" data-v="21" data-xref="馬可福音 6:51; 馬太福音 14:32–33; 啟示錄 3:20"> 門徒就喜歡接他上船，船立時到了他們所要去的地方。</span>
</div>
</div>

## 耶穌是生命的糧

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="馬可福音 6:45; 馬太福音 14:22; 約翰福音 6:2"> 第二日，站在海那邊的眾人知道那裏沒有別的船，只有一隻小船，又知道耶穌沒有同他的門徒上船，乃是門徒自己去的。</span>
<span className="v" id="v23" data-v="23" data-xref="約翰福音 6:1; 約翰福音 6:11–12"> 然而，有幾隻小船從提比哩亞來，靠近主祝謝後分餅給人吃的地方。</span>
<span className="v" id="v24" data-v="24" data-xref="約翰福音 6:17; 路加福音 8:40; 馬可福音 6:53"> 眾人見耶穌和門徒都不在那裏，就上了船，往迦百農去找耶穌。</span>
<span className="v" id="v25" data-v="25" data-xref="約翰福音 1:38–39; 馬太福音 23:7"> 既在海那邊找着了，就對他說：「拉比，是幾時到這裏來的？」</span>
<span className="v" id="v26" data-v="26" data-xref="雅各書 4:3–4; 腓立比書 3:19; 腓立比書 2:21"> 耶穌回答說：「我實實在在地告訴你們，你們找我，並不是因見了神蹟，乃是因吃餅得飽。</span>
<span className="v" id="v27" data-v="27" data-xref="歌羅西書 3:2; 以賽亞書 55:2; 約翰福音 6:54"> 不要為那必壞的食物勞力，要為那存到永生的食物勞力，就是人子要賜給你們的，因為人子是父上帝所印證的。」</span>
<span className="v" id="v28" data-v="28" data-xref="使徒行傳 16:30; 使徒行傳 9:6; 馬太福音 19:16"> 眾人問他說：「我們當行甚麼才算做上帝的工呢？」</span>
<span className="v" id="v29" data-v="29" data-xref="約翰一書 3:23; 使徒行傳 16:31; 約翰福音 3:36"> 耶穌回答說：「信上帝所差來的，這就是做上帝的工。」</span>
<span className="v" id="v30" data-v="30" data-xref="約翰福音 12:37; 約翰福音 10:38; 哥林多前書 1:22"> 他們又說：「你行甚麼神蹟，叫我們看見就信你；你到底做甚麼事呢？</span>
<span className="v" id="v31" data-v="31" data-xref="尼希米記 9:15; 詩篇 105:40; 詩篇 78:24–25"> 我們的祖宗在曠野吃過嗎哪，如經上寫着說：『他從天上賜下糧來給他們吃。』」</span>
<span className="v" id="v32" data-v="32" data-xref="約翰福音 15:1; 約翰福音 6:58; 出埃及記 16:4"> 耶穌說：「我實實在在地告訴你們，那從天上來的糧不是摩西賜給你們的，乃是我父將天上來的真糧賜給你們。</span>
<span className="v" id="v33" data-v="33" data-xref="約翰福音 8:42; 約翰福音 17:8; 約翰福音 3:13"> 因為上帝的糧就是那從天上降下來、賜生命給世界的。」</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="約翰福音 4:15; 約翰福音 6:26; 詩篇 4:6"> 他們說：「主啊，常將這糧賜給我們！」</span>
<span className="v" id="v35" data-v="35" data-xref="約翰福音 6:48–58; 啟示錄 22:17; 約翰福音 6:41"> 耶穌說：「我就是生命的糧。到我這裏來的，必定不餓；信我的，永遠不渴。</span>
<span className="v" id="v36" data-v="36" data-xref="彼得前書 1:8–9; 路加福音 16:31; 約翰福音 12:37"> 只是我對你們說過，你們已經看見我，還是不信。</span>
<span className="v" id="v37" data-v="37" data-xref="馬太福音 11:28; 約翰福音 6:39; 約翰福音 17:24"> 凡父所賜給我的人必到我這裏來；到我這裏來的，我總不丟棄他。</span>
<span className="v" id="v38" data-v="38" data-xref="約翰福音 5:30; 約翰福音 4:34; 約翰福音 3:31"> 因為我從天上降下來，不是要按自己的意思行，乃是要按那差我來者的意思行。</span>
<span className="v" id="v39" data-v="39" data-xref="約翰福音 17:12; 約翰福音 6:40; 約翰福音 18:9"> 差我來者的意思就是：他所賜給我的，叫我一個也不失落，在末日卻叫他復活。</span>
<span className="v" id="v40" data-v="40" data-xref="約翰福音 6:54; 約翰福音 5:24; 羅馬書 6:23"> 因為我父的意思是叫一切見子而信的人得永生，並且在末日我要叫他復活。」</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="約翰福音 6:51–52; 約翰福音 6:48; 約翰福音 6:33"> 猶太人因為耶穌說「我是從天上降下來的糧」，就私下議論他，</span>
<span className="v" id="v42" data-v="42" data-xref="路加福音 4:22; 馬可福音 6:3; 馬太福音 13:55–56"> 說：「這不是約瑟的兒子耶穌嗎？他的父母我們豈不認得嗎？他如今怎麼說『我是從天上降下來的』呢？」</span>
<span className="v" id="v43" data-v="43" data-xref="希伯來書 4:13; 約翰福音 6:64; 馬可福音 9:33"> 耶穌回答說：「你們不要大家議論。</span>
<span className="v" id="v44" data-v="44" data-xref="約翰福音 6:65; 約翰福音 6:39–40; 馬太福音 11:25–27"> 若不是差我來的父吸引人，就沒有能到我這裏來的；到我這裏來的，在末日我要叫他復活。</span>
<span className="v" id="v45" data-v="45" data-xref="以賽亞書 54:13; 耶利米書 31:33–34; 希伯來書 10:16"> 在先知書上寫着說：『他們都要蒙上帝的教訓。』凡聽見父之教訓又學習的，就到我這裏來。</span>
<span className="v" id="v46" data-v="46" data-xref="約翰福音 1:18; 約翰福音 7:29; 馬太福音 11:27"> 這不是說有人看見過父，惟獨從上帝來的，他看見過父。</span>
<span className="v" id="v47" data-v="47" data-xref="約翰福音 3:36; 歌羅西書 3:3–4; 羅馬書 5:9–10"> 我實實在在地告訴你們，信的人有永生。</span>
<span className="v" id="v48" data-v="48" data-xref="約翰福音 6:51; 哥林多前書 11:24–25; 哥林多前書 10:16–17"> 我就是生命的糧。</span>
<span className="v" id="v49" data-v="49" data-xref="哥林多前書 10:3–5; 猶大書 1:5; 撒迦利亞書 1:5"> 你們的祖宗在曠野吃過嗎哪，還是死了。</span>
<span className="v" id="v50" data-v="50" data-xref="約翰福音 6:33; 約翰福音 6:51; 羅馬書 8:10"> 這是從天上降下來的糧，叫人吃了就不死。</span>
<span className="v" id="v51" data-v="51" data-xref="路加福音 22:19; 約翰福音 6:33; 希伯來書 10:5–12"> 我是從天上降下來生命的糧；人若吃這糧，就必永遠活着。我所要賜的糧就是我的肉，為世人之生命所賜的。」</span>
</div>
<div className="bp">
<span className="v" id="v52" data-v="52" data-xref="約翰福音 9:16; 約翰福音 10:19; 約翰福音 6:41"> 因此，猶太人彼此爭論說：「這個人怎能把他的肉給我們吃呢？」</span>
<span className="v" id="v53" data-v="53" data-xref="約翰一書 5:12; 馬太福音 26:26–28; 約翰福音 6:55"> 耶穌說：「我實實在在地告訴你們，你們若不吃人子的肉，不喝人子的血，就沒有生命在你們裏面。</span>
<span className="v" id="v54" data-v="54" data-xref="約翰福音 6:39–40; 約翰福音 6:27; 腓立比書 3:7–10"> 吃我肉、喝我血的人就有永生，在末日我要叫他復活。</span>
<span className="v" id="v55" data-v="55" data-xref="約翰福音 15:1; 約翰福音 8:31; 約翰福音 6:32"> 我的肉真是可吃的，我的血真是可喝的。</span>
<span className="v" id="v56" data-v="56" data-xref="約翰一書 3:24; 約翰福音 15:4–5; 約翰福音 14:20"> 吃我肉、喝我血的人常在我裏面，我也常在他裏面。</span>
<span className="v" id="v57" data-v="57" data-xref="加拉太書 2:20; 約翰福音 5:26; 約翰福音 17:21"> 永活的父怎樣差我來，我又因父活着；照樣，吃我肉的人也要因我活着。</span>
<span className="v" id="v58" data-v="58" data-xref="約翰福音 3:36; 約翰福音 6:47–51; 約翰福音 6:41"> 這就是從天上降下來的糧。吃這糧的人就永遠活着，不像你們的祖宗吃過嗎哪還是死了。」</span>
<span className="v" id="v59" data-v="59" data-xref="約翰福音 6:24; 箴言 8:1–3; 路加福音 4:31"> 這些話是耶穌在迦百農會堂裏教訓人說的。</span>
</div>
</div>

## 永生的話語

<div className="bt">
<div className="bp">
<span className="v" id="v60" data-v="60" data-xref="約翰福音 6:66; 約翰福音 8:43; 約翰福音 8:31"> 他的門徒中有好些人聽見了，就說：「這話甚難，誰能聽呢？」</span>
<span className="v" id="v61" data-v="61" data-xref="約翰福音 2:24–25; 約翰福音 6:64; 約翰福音 21:17"> 耶穌心裏知道門徒為這話議論，就對他們說：「這話是叫你們厭棄<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是跌倒">a</a></sup>嗎？</span>
<span className="v" id="v62" data-v="62" data-xref="馬可福音 16:19; 約翰福音 3:13; 約翰福音 17:4–5"> 倘或你們看見人子升到他原來所在之處，怎麼樣呢？</span>
<span className="v" id="v63" data-v="63" data-xref="加拉太書 5:25; 希伯來書 4:12; 詩篇 119:93"> 叫人活着的乃是靈，肉體是無益的。我對你們所說的話就是靈，就是生命。</span>
<span className="v" id="v64" data-v="64" data-xref="約翰福音 10:26; 提摩太後書 2:19; 希伯來書 4:13"> 只是你們中間有不信的人。」耶穌從起頭就知道誰不信他，誰要賣他。</span>
<span className="v" id="v65" data-v="65" data-xref="約翰福音 6:44–45; 約翰福音 6:37; 約翰福音 3:27"> 耶穌又說：「所以我對你們說過，若不是蒙我父的恩賜，沒有人能到我這裏來。」</span>
</div>
<div className="bp">
<span className="v" id="v66" data-v="66" data-xref="路加福音 9:62; 約翰一書 2:19; 希伯來書 10:38"> 從此，他門徒中多有退去的，不再和他同行。</span>
<span className="v" id="v67" data-v="67" data-xref="路得記 1:11–18; 約翰福音 6:70; 路加福音 14:25–33"> 耶穌就對那十二個門徒說：「你們也要去嗎？」</span>
<span className="v" id="v68" data-v="68" data-xref="詩篇 73:25; 約翰福音 5:24; 約翰一書 5:11–13"> 西門‧彼得回答說：「主啊，你有永生之道，我們還歸從誰呢？</span>
<span className="v" id="v69" data-v="69" data-xref="約翰福音 11:27; 路加福音 9:20; 馬可福音 8:29"> 我們已經信了，又知道你是上帝的聖者。」</span>
<span className="v" id="v70" data-v="70" data-xref="約翰福音 13:27; 約翰福音 13:2; 約翰福音 17:12"> 耶穌說：「我不是揀選了你們十二個門徒嗎？但你們中間有一個是魔鬼。」</span>
<span className="v" id="v71" data-v="71" data-xref="馬太福音 26:14–16; 猶大書 1:4; 使徒行傳 1:16–20"> 耶穌這話是指着加略人西門的兒子猶大說的；他本是十二個門徒裏的一個，後來要賣耶穌的。</span>
</div>

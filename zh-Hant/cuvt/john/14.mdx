## 耶穌是道路、真理、生命

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以賽亞書 26:3; 約翰福音 16:22–23; 以賽亞書 12:2–3"> 「你們心裏不要憂愁；你們信上帝，也當信我。</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多後書 5:1; 約翰福音 13:36; 希伯來書 13:14"> 在我父的家裏有許多住處；若是沒有，我就早已告訴你們了。我去原是為你們預備地方去。</span>
<span className="v" id="v3" data-v="3" data-xref="帖撒羅尼迦前書 4:16–17; 約翰福音 12:26; 提摩太後書 2:12"> 我若去為你們預備了地方，就必再來接你們到我那裏去，我在哪裏，叫你們也在那裏。</span>
<span className="v" id="v4" data-v="4" data-xref="約翰福音 10:9; 約翰福音 16:28; 約翰福音 13:3"> 我往哪裏去，你們知道；那條路，你們也知道<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古卷：我往哪裏去，你們知道那條路">a</a></sup>。」</span>
<span className="v" id="v5" data-v="5" data-xref="約翰福音 11:16; 馬可福音 9:19; 約翰福音 20:25–28"> 多馬對他說：「主啊，我們不知道你往哪裏去，怎麼知道那條路呢？」</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行傳 4:12; 約翰福音 10:9; 以弗所書 2:18"> 耶穌說：「我就是道路、真理、生命；若不藉着我，沒有人能到父那裏去。</span>
<span className="v" id="v7" data-v="7" data-xref="歌羅西書 1:15–17; 約翰福音 8:19; 路加福音 10:22"> 你們若認識我，也就認識我的父。從今以後，你們認識他，並且已經看見他。」</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及記 33:18–23; 啟示錄 22:3–5; 約翰福音 1:43–46"> 腓力對他說：「求主將父顯給我們看，我們就知足了。」</span>
<span className="v" id="v9" data-v="9" data-xref="歌羅西書 1:15; 約翰福音 12:45; 約翰福音 14:7"> 耶穌對他說：「腓力，我與你們同在這樣長久，你還不認識我嗎？人看見了我，就是看見了父；你怎麼說『將父顯給我們看』呢？</span>
<span className="v" id="v10" data-v="10" data-xref="約翰福音 5:19; 約翰福音 10:38; 約翰福音 10:30"> 我在父裏面，父在我裏面，你不信嗎？我對你們所說的話，不是憑着自己說的，乃是住在我裏面的父做他自己的事。</span>
<span className="v" id="v11" data-v="11" data-xref="約翰福音 10:38; 約翰福音 10:25; 約翰福音 5:36"> 你們當信我，我在父裏面，父在我裏面；即或不信，也當因我所做的事信我。</span>
<span className="v" id="v12" data-v="12" data-xref="馬太福音 21:21; 馬可福音 16:17; 路加福音 10:17–19"> 我實實在在地告訴你們，我所做的事，信我的人也要做，並且要做比這更大的事，因為我往父那裏去。</span>
<span className="v" id="v13" data-v="13" data-xref="約翰福音 15:7; 馬可福音 11:24; 馬太福音 7:7"> 你們奉我的名無論求甚麼，我必成就，叫父因兒子得榮耀。</span>
<span className="v" id="v14" data-v="14"> 你們若奉我的名求甚麼，我必成就。」</span>
</div>
</div>

## 應許賜聖靈

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="約翰一書 2:3–5; 約翰一書 5:2–3; 約翰福音 14:21–24"> 「你們若愛我，就必遵守我的命令。</span>
<span className="v" id="v16" data-v="16" data-xref="約翰福音 14:26; 約翰福音 15:26; 約翰福音 16:7–15"> 我要求父，父就另外賜給你們一位保惠師<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或譯：訓慰師；下同">b</a></sup>，叫他永遠與你們同在，</span>
<span className="v" id="v17" data-v="17" data-xref="以西結書 36:27; 約翰福音 16:13; 約翰一書 2:27"> 就是真理的聖靈，乃世人不能接受的；因為不見他，也不認識他。你們卻認識他，因他常與你們同在，也要在你們裏面。</span>
<span className="v" id="v18" data-v="18" data-xref="約翰福音 14:3; 詩篇 23:4; 馬太福音 18:20"> 我不撇下你們為孤兒，我必到你們這裏來。</span>
<span className="v" id="v19" data-v="19" data-xref="約翰福音 16:16; 約翰福音 7:33; 希伯來書 7:25"> 還有不多的時候，世人不再看見我，你們卻看見我；因為我活着，你們也要活着。</span>
<span className="v" id="v20" data-v="20" data-xref="約翰福音 15:5–7; 加拉太書 2:20; 約翰福音 17:21–23"> 到那日，你們就知道我在父裏面，你們在我裏面，我也在你們裏面。</span>
<span className="v" id="v21" data-v="21" data-xref="約翰福音 14:15; 約翰一書 5:3; 約翰一書 2:5"> 有了我的命令又遵守的，這人就是愛我的；愛我的必蒙我父愛他，我也要愛他，並且要向他顯現。」</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行傳 1:13; 路加福音 6:16; 馬太福音 10:3"> 猶大（不是加略人猶大）問耶穌說：「主啊，為甚麼要向我們顯現，不向世人顯現呢？」</span>
<span className="v" id="v23" data-v="23" data-xref="約翰福音 14:21; 約翰福音 14:15; 啟示錄 3:20–21"> 耶穌回答說：「人若愛我，就必遵守我的道；我父也必愛他，並且我們要到他那裏去，與他同住。</span>
<span className="v" id="v24" data-v="24" data-xref="約翰福音 7:16; 約翰福音 14:10; 約翰福音 8:42"> 不愛我的人就不遵守我的道。你們所聽見的道不是我的，乃是差我來之父的道。</span>
<span className="v" id="v25" data-v="25" data-xref="約翰福音 17:6–8; 約翰福音 13:19; 約翰福音 16:12"> 「我還與你們同住的時候，已將這些話對你們說了。</span>
<span className="v" id="v26" data-v="26" data-xref="約翰福音 15:26; 約翰福音 14:16; 約翰一書 2:27"> 但保惠師，就是父因我的名所要差來的聖靈，他要將一切的事指教你們，並且要叫你們想起我對你們所說的一切話。</span>
<span className="v" id="v27" data-v="27" data-xref="腓立比書 4:7; 約翰福音 16:33; 以賽亞書 41:10"> 我留下平安給你們；我將我的平安賜給你們。我所賜的，不像世人所賜的。你們心裏不要憂愁，也不要膽怯。</span>
<span className="v" id="v28" data-v="28" data-xref="約翰福音 10:29–30; 哥林多前書 15:24–28; 哥林多前書 11:3"> 你們聽見我對你們說了，我去還要到你們這裏來。你們若愛我，因我到父那裏去，就必喜樂，因為父是比我大的。</span>
<span className="v" id="v29" data-v="29" data-xref="約翰福音 13:19; 約翰福音 16:4–31; 馬太福音 24:24–25"> 現在事情還沒有成就，我預先告訴你們，叫你們到事情成就的時候就可以信。</span>
<span className="v" id="v30" data-v="30" data-xref="約翰一書 5:19; 約翰一書 4:4; 啟示錄 12:9"> 以後我不再和你們多說話，因為這世界的王將到。他在我裏面是毫無所有；</span>
<span className="v" id="v31" data-v="31" data-xref="約翰福音 10:18; 腓立比書 2:8; 約翰福音 12:49"> 但要叫世人知道我愛父，並且父怎樣吩咐我，我就怎樣行。起來，我們走吧！」</span>
</div>
</div>

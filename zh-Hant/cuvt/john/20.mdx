## 耶穌復活

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="馬可福音 16:9; 馬太福音 27:60; 約翰福音 19:25"> 七日的第一日清早，天還黑的時候，抹大拉的馬利亞來到墳墓那裏，看見石頭從墳墓挪開了，</span>
<span className="v" id="v2" data-v="2" data-xref="約翰福音 13:23; 約翰福音 20:13; 約翰福音 21:24"> 就跑來見西門‧彼得和耶穌所愛的那個門徒，對他們說：「有人把主從墳墓裏挪了去，我們不知道放在哪裏。」</span>
<span className="v" id="v3" data-v="3" data-xref="路加福音 24:12"> 彼得和那門徒就出來，往墳墓那裏去。</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳記下 18:23; 哥林多後書 8:12; 哥林多前書 9:24"> 兩個人同跑，那門徒比彼得跑得更快，先到了墳墓，</span>
<span className="v" id="v5" data-v="5" data-xref="約翰福音 19:40; 約翰福音 20:11; 約翰福音 11:44"> 低頭往裏看，就見細麻布還放在那裏，只是沒有進去。</span>
<span className="v" id="v6" data-v="6" data-xref="約翰福音 18:17; 約翰福音 21:7; 馬太福音 16:15–16"> 西門‧彼得隨後也到了，進墳墓裏去，就看見細麻布還放在那裏，</span>
<span className="v" id="v7" data-v="7" data-xref="約翰福音 11:44"> 又看見耶穌的裹頭巾沒有和細麻布放在一處，是另在一處捲着。</span>
<span className="v" id="v8" data-v="8" data-xref="約翰福音 20:25; 約翰福音 20:4; 約翰福音 1:50"> 先到墳墓的那門徒也進去，看見就信了。（</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 16:10; 以賽亞書 25:8; 以賽亞書 53:10–12"> 因為他們還不明白聖經的意思，就是耶穌必要從死裏復活。）</span>
<span className="v" id="v10" data-v="10" data-xref="約翰福音 7:53; 約翰福音 16:32"> 於是兩個門徒回自己的住處去了。</span>
</div>
</div>

## 向抹大拉的馬利亞顯現

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="約翰福音 20:5"> 馬利亞卻站在墳墓外面哭。哭的時候，低頭往墳墓裏看，</span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 24:3–7; 啟示錄 3:4; 馬可福音 16:5–6"> 就見兩個天使，穿着白衣，在安放耶穌身體的地方坐着，一個在頭，一個在腳。</span>
<span className="v" id="v13" data-v="13" data-xref="約翰福音 20:15; 約翰福音 2:4; 撒母耳記上 1:8"> 天使對她說：「婦人，你為甚麼哭？」她說：「因為有人把我主挪了去，我不知道放在哪裏。」</span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 24:16; 約翰福音 21:4; 馬太福音 28:9"> 說了這話，就轉過身來，看見耶穌站在那裏，卻不知道是耶穌。</span>
<span className="v" id="v15" data-v="15" data-xref="約翰福音 20:13; 約翰福音 18:7; 約翰福音 1:38"> 耶穌問她說：「婦人，為甚麼哭？你找誰呢？」馬利亞以為是看園的，就對他說：「先生，若是你把他移了去，請告訴我，你把他放在哪裏，我便去取他。」</span>
<span className="v" id="v16" data-v="16" data-xref="約翰福音 10:3; 約翰福音 1:38; 使徒行傳 10:3"> 耶穌說：「馬利亞。」馬利亞就轉過來，用希伯來話對他說：「拉波尼！」（拉波尼就是夫子的意思。）</span>
<span className="v" id="v17" data-v="17" data-xref="約翰福音 16:28; 以弗所書 4:8–10; 加拉太書 4:6–7"> 耶穌說：「不要摸我，因我還沒有升上去見我的父。你往我弟兄那裏去，告訴他們說，我要升上去見我的父，也是你們的父，見我的上帝，也是你們的上帝。」</span>
<span className="v" id="v18" data-v="18" data-xref="路加福音 24:10; 馬太福音 28:10; 約翰福音 20:1"> 抹大拉的馬利亞就去告訴門徒說：「我已經看見了主。」她又將主對她說的這話告訴他們。</span>
</div>
</div>

## 向門徒顯現

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="約翰福音 20:26; 約翰福音 14:27; 約翰福音 20:21"> 那日（就是七日的第一日）晚上，門徒所在的地方，因怕猶太人，門都關了。耶穌來，站在當中，對他們說：「願你們平安！」</span>
<span className="v" id="v20" data-v="20" data-xref="約翰福音 16:22; 約翰福音 16:20; 約翰福音 20:27"> 說了這話，就把手和肋旁指給他們看。門徒看見主，就喜樂了。</span>
<span className="v" id="v21" data-v="21" data-xref="約翰福音 17:18–19; 約翰福音 13:20; 約翰福音 3:17"> 耶穌又對他們說：「願你們平安！父怎樣差遣了我，我也照樣差遣你們。」</span>
<span className="v" id="v22" data-v="22" data-xref="約伯記 33:4; 創世記 2:7; 使徒行傳 8:15"> 說了這話，就向他們吹一口氣，說：「你們受聖靈！</span>
<span className="v" id="v23" data-v="23" data-xref="馬太福音 18:18; 馬太福音 16:19; 馬可福音 2:5–10"> 你們赦免誰的罪，誰的罪就赦免了；你們留下誰的罪，誰的罪就留下了。」</span>
</div>
</div>

## 耶穌和多馬

<div className="bt">
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="約翰福音 11:16; 約翰福音 6:66–67; 希伯來書 10:25"> 那十二個門徒中，有稱為低土馬的多馬；耶穌來的時候，他沒有和他們同在。</span>
<span className="v" id="v25" data-v="25" data-xref="約翰福音 6:30; 馬可福音 16:11; 希伯來書 3:12"> 那些門徒就對他說：「我們已經看見主了。」多馬卻說：「我非看見他手上的釘痕，用指頭探入那釘痕，又用手探入他的肋旁，我總不信。」</span>
<span className="v" id="v26" data-v="26" data-xref="約翰福音 20:19; 以賽亞書 54:10; 約翰福音 20:21"> 過了八日，門徒又在屋裏，多馬也和他們同在，門都關了。耶穌來，站在當中說：「願你們平安！」</span>
<span className="v" id="v27" data-v="27" data-xref="約翰福音 20:25; 約翰一書 1:1–2; 約翰福音 20:20"> 就對多馬說：「伸過你的指頭來，摸<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是看">a</a></sup>我的手；伸出你的手來，探入我的肋旁。不要疑惑，總要信！」</span>
<span className="v" id="v28" data-v="28" data-xref="約翰福音 1:1; 以賽亞書 9:6; 以賽亞書 7:14"> 多馬說：「我的主！我的上帝！」</span>
<span className="v" id="v29" data-v="29" data-xref="彼得前書 1:8; 哥林多後書 5:7; 希伯來書 11:1"> 耶穌對他說：「你因看見了我才信；那沒有看見就信的有福了。」</span>
</div>
</div>

## 本書的目的

<div className="bt">
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="約翰福音 21:25; 提摩太後書 3:15–17; 羅馬書 15:4"> 耶穌在門徒面前另外行了許多神蹟，沒有記在這書上。</span>
<span className="v" id="v31" data-v="31" data-xref="使徒行傳 10:43; 約翰福音 3:15–16; 約翰一書 5:1"> 但記這些事要叫你們信耶穌是基督，是上帝的兒子，並且叫你們信了他，就可以因他的名得生命。</span>

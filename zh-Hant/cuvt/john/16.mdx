<span className="v" id="v2" data-v="2" data-xref="約翰福音 9:22; 使徒行傳 26:9–11; 羅馬書 10:2–3"> 人要把你們趕出會堂，並且時候將到，凡殺你們的就以為是事奉上帝。</span>
<span className="v" id="v3" data-v="3" data-xref="約翰福音 15:21; 約翰福音 17:25; 約翰福音 8:55"> 他們這樣行，是因未曾認識父，也未曾認識我。</span>
<span className="v" id="v4" data-v="4" data-xref="約翰福音 14:29; 馬可福音 13:23; 約翰福音 17:12–13"> 我將這事告訴你們，是叫你們到了時候可以想起我對你們說過了。」 聖靈的工作<br />「我起先沒有將這事告訴你們，因為我與你們同在。</span>
<span className="v" id="v5" data-v="5" data-xref="約翰福音 13:36; 約翰福音 7:33; 約翰福音 16:28"> 現今我往差我來的父那裏去，你們中間並沒有人問我：『你往哪裏去？』</span>
<span className="v" id="v6" data-v="6" data-xref="約翰福音 14:1; 約翰福音 16:20–22; 路加福音 24:17"> 只因我將這事告訴你們，你們就滿心憂愁。</span>
<span className="v" id="v7" data-v="7" data-xref="約翰福音 14:26; 約翰福音 14:16–17; 約翰福音 15:26"> 然而，我將真情告訴你們，我去是與你們有益的；我若不去，保惠師就不到你們這裏來；我若去，就差他來。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行傳 2:37; 猶大書 1:15; 撒迦利亞書 12:10"> 他既來了，就要叫世人為罪、為義、為審判，自己責備自己。</span>
<span className="v" id="v9" data-v="9" data-xref="約翰福音 15:22–25; 約翰福音 8:23–24; 約翰福音 12:47–48"> 為罪，是因他們不信我；</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多後書 5:21; 彼得前書 3:18; 羅馬書 10:3–4"> 為義，是因我往父那裏去，你們就不再見我；</span>
<span className="v" id="v11" data-v="11" data-xref="約翰福音 12:31; 約翰一書 3:8; 希伯來書 2:14"> 為審判，是因這世界的王受了審判。</span>

<span className="v" id="v14" data-v="14" data-xref="約翰一書 4:13–14; 哥林多後書 3:14–18; 約翰福音 15:26"> 他要榮耀我，因為他要將受於我的告訴你們。</span>
<span className="v" id="v15" data-v="15" data-xref="約翰福音 17:10; 馬太福音 11:27; 約翰福音 3:35"> 凡父所有的，都是我的；所以我說，他要將受於我的告訴你們。」</span>

## 憂愁變為喜樂

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="約翰福音 7:33; 使徒行傳 1:3; 約翰福音 14:18–24"> 「等不多時，你們就不得見我；再等不多時，你們還要見我。」</span>
<span className="v" id="v17" data-v="17" data-xref="約翰福音 16:16; 馬可福音 9:32; 約翰福音 16:5"> 有幾個門徒就彼此說：「他對我們說：『等不多時，你們就不得見我；再等不多時，你們還要見我』；又說：『因我往父那裏去。』這是甚麼意思呢？」</span>
<span className="v" id="v18" data-v="18" data-xref="路加福音 24:25; 馬太福音 16:9–11; 希伯來書 5:12"> 門徒彼此說：「他說『等不多時』到底是甚麼意思呢？我們不明白他所說的話。」</span>
<span className="v" id="v19" data-v="19" data-xref="約翰福音 16:30; 約翰福音 16:16; 約翰福音 14:19"> 耶穌看出他們要問他，就說：「我說『等不多時，你們就不得見我；再等不多時，你們還要見我』，你們為這話彼此相問嗎？</span>
<span className="v" id="v20" data-v="20" data-xref="雅各書 1:2; 馬太福音 5:4; 詩篇 126:5–6"> 我實實在在地告訴你們，你們將要痛哭、哀號，世人倒要喜樂；你們將要憂愁，然而你們的憂愁要變為喜樂。</span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 113:9; 以賽亞書 13:8; 帖撒羅尼迦前書 5:3"> 婦人生產的時候就憂愁，因為她的時候到了；既生了孩子，就不再記念那苦楚，因為歡喜世上生了一個人。</span>
<span className="v" id="v22" data-v="22" data-xref="彼得前書 1:8; 使徒行傳 13:52; 約翰福音 16:6"> 你們現在也是憂愁，但我要再見你們，你們的心就喜樂了；這喜樂也沒有人能奪去。</span>
<span className="v" id="v23" data-v="23" data-xref="約翰福音 15:7; 約翰福音 14:13–14; 馬太福音 21:22"> 到那日，你們甚麼也就不問我了。我實實在在地告訴你們，你們若向父求甚麼，他必因我的名賜給你們。</span>
<span className="v" id="v24" data-v="24" data-xref="馬太福音 7:7–8; 雅各書 4:2–3; 約翰福音 15:11"> 向來你們沒有奉我的名求甚麼，如今你們求，就必得着，叫你們的喜樂可以滿足。」</span>
</div>
</div>

## 我已經勝過世界

<div className="bt">
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="約翰福音 16:12; 馬可福音 4:13; 馬太福音 13:34–35"> 「這些事，我是用比喻對你們說的；時候將到，我不再用比喻對你們說，乃要將父明明地告訴你們。</span>
<span className="v" id="v26" data-v="26" data-xref="羅馬書 8:34; 約翰福音 17:24; 約翰福音 17:19"> 到那日，你們要奉我的名祈求；我並不對你們說，我要為你們求父。</span>
<span className="v" id="v27" data-v="27" data-xref="約翰福音 14:21; 約翰福音 14:23; 約翰福音 17:23"> 父自己愛你們；因為你們已經愛我，又信我是從父出來的。</span>
<span className="v" id="v28" data-v="28" data-xref="約翰福音 13:1; 約翰福音 13:3; 約翰福音 8:14"> 我從父出來，到了世界；我又離開世界，往父那裏去。」</span>
<span className="v" id="v29" data-v="29" data-xref="約翰福音 16:25"> 門徒說：「如今你是明說，並不用比喻了。</span>
<span className="v" id="v30" data-v="30" data-xref="約翰福音 21:17; 約翰福音 17:8; 約翰福音 16:17"> 現在我們曉得你凡事都知道，也不用人問你，因此我們信你是從上帝出來的。」</span>
<span className="v" id="v31" data-v="31" data-xref="路加福音 9:44–45; 約翰福音 13:38"> 耶穌說：「現在你們信嗎？</span>
<span className="v" id="v32" data-v="32" data-xref="撒迦利亞書 13:7; 馬太福音 26:31; 約翰福音 8:29"> 看哪，時候將到，且是已經到了，你們要分散，各歸自己的地方去，留下我獨自一人；其實我不是獨自一人，因為有父與我同在。</span>
<span className="v" id="v33" data-v="33" data-xref="約翰福音 14:27; 約翰一書 5:4; 帖撒羅尼迦後書 3:16"> 我將這些事告訴你們，是要叫你們在我裏面有平安。在世上，你們有苦難；但你們可以放心，我已經勝了世界。」</span>
</div>

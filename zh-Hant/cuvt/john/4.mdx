## 耶穌和撒馬利亞婦人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="約翰福音 3:26; 約翰福音 3:22; 哥林多後書 4:5"> 主知道法利賽人聽見他收門徒，施洗，比約翰還多，（</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行傳 10:48; 哥林多前書 1:13–17"> 其實不是耶穌親自施洗，乃是他的門徒施洗，）</span>
<span className="v" id="v3" data-v="3" data-xref="馬太福音 10:23; 約翰福音 10:40; 約翰福音 2:11"> 他就離了猶太，又往加利利去。</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 17:11; 路加福音 2:49; 路加福音 9:51–52"> 必須經過撒馬利亞，</span>
<span className="v" id="v5" data-v="5" data-xref="約書亞記 24:32; 創世記 33:19; 創世記 48:22"> 於是到了撒馬利亞的一座城，名叫敘加，靠近雅各給他兒子約瑟的那塊地。</span>
<span className="v" id="v6" data-v="6" data-xref="希伯來書 4:15; 希伯來書 2:17; 馬太福音 8:24"> 在那裏有雅各井；耶穌因走路困乏，就坐在井旁。那時約有午正。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="馬太福音 10:42; 列王紀上 17:10; 創世記 24:43"> 有一個撒馬利亞的婦人來打水。耶穌對她說：「請你給我水喝。」（</span>
<span className="v" id="v8" data-v="8" data-xref="路加福音 9:13; 約翰福音 4:39; 約翰福音 4:5"> 那時門徒進城買食物去了。）</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行傳 10:28; 馬太福音 10:5; 列王紀下 17:24–41"> 撒馬利亞的婦人對他說：「你既是猶太人，怎麼向我一個撒馬利亞婦人要水喝呢？」原來猶太人和撒馬利亞人沒有來往。</span>
<span className="v" id="v10" data-v="10" data-xref="約翰福音 4:14; 啟示錄 7:17; 約翰福音 7:37–39"> 耶穌回答說：「你若知道上帝的恩賜，和對你說『給我水喝』的是誰，你必早求他，他也必早給了你活水。」</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多前書 2:14; 約翰福音 3:4"> 婦人說：「先生，沒有打水的器具，井又深，你從哪裏得活水呢？</span>
<span className="v" id="v12" data-v="12" data-xref="約翰福音 4:6; 約翰福音 8:53; 馬太福音 12:42"> 我們的祖宗雅各將這井留給我們，他自己和兒子並牲畜也都喝這井裏的水，難道你比他還大嗎？」</span>
<span className="v" id="v13" data-v="13" data-xref="約翰福音 6:27; 以賽亞書 65:13–14; 路加福音 16:24"> 耶穌回答說：「凡喝這水的還要再渴；</span>
<span className="v" id="v14" data-v="14" data-xref="約翰福音 7:38–39; 約翰福音 6:35; 以賽亞書 49:10"> 人若喝我所賜的水就永遠不渴。我所賜的水要在他裏頭成為泉源，直湧到永生。」</span>
<span className="v" id="v15" data-v="15" data-xref="約翰福音 6:34; 羅馬書 8:5; 詩篇 4:6"> 婦人說：「先生，請把這水賜給我，叫我不渴，也不用來這麼遠打水。」</span>
<span className="v" id="v16" data-v="16" data-xref="希伯來書 4:13; 啟示錄 2:23; 約翰福音 4:18"> 耶穌說：「你去叫你丈夫也到這裏來。」</span>
<span className="v" id="v17" data-v="17"> 婦人說：「我沒有丈夫。」耶穌說：「你說沒有丈夫是不錯的。</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米書 3:20; 哥林多前書 7:10–11; 羅馬書 7:3"> 你已經有五個丈夫，你現在有的並不是你的丈夫。你這話是真的。」</span>
<span className="v" id="v19" data-v="19" data-xref="路加福音 7:39; 約翰福音 6:14; 約翰福音 9:17"> 婦人說：「先生，我看出你是先知。</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 12:6–7; 申命記 27:12; 申命記 11:29"> 我們的祖宗在這山上禮拜，你們倒說，應當禮拜的地方是在耶路撒冷。」</span>
<span className="v" id="v21" data-v="21" data-xref="提摩太前書 2:8; 瑪拉基書 1:11; 約翰福音 4:23"> 耶穌說：「婦人，你當信我。時候將到，你們拜父，也不在這山上，也不在耶路撒冷。</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行傳 17:23; 以賽亞書 2:3; 羅馬書 9:4–5"> 你們所拜的，你們不知道；我們所拜的，我們知道，因為救恩是從猶太人出來的。</span>
<span className="v" id="v23" data-v="23" data-xref="腓立比書 3:3; 約翰福音 5:25; 馬太福音 15:7–9"> 時候將到，如今就是了，那真正拜父的，要用心靈和誠實拜他，因為父要這樣的人拜他。」</span>
<span className="v" id="v24" data-v="24" data-xref="哥林多後書 3:17; 馬太福音 15:8–9; 腓立比書 3:3"> 上帝是個靈<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或無個字">a</a></sup>，所以拜他的必須用心靈和誠實拜他。」</span>
<span className="v" id="v25" data-v="25" data-xref="約翰福音 1:49; 但以理書 9:24–26; 約翰福音 1:41–42"> 婦人說：「我知道彌賽亞（就是那稱為基督的）要來；他來了，必將一切的事都告訴我們。」</span>
<span className="v" id="v26" data-v="26" data-xref="約翰福音 8:24; 馬可福音 14:61–62; 羅馬書 10:20–21"> 耶穌說：「這和你說話的就是他！」</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="路加福音 7:39; 約翰福音 4:8–9"> 當下門徒回來，就希奇耶穌和一個婦人說話；只是沒有人說：「你是要甚麼？」或說：「你為甚麼和她說話？」</span>
<span className="v" id="v28" data-v="28" data-xref="約翰福音 4:7; 路加福音 24:33; 馬可福音 16:8–10"> 那婦人就留下水罐子，往城裏去，對眾人說：</span>
<span className="v" id="v29" data-v="29" data-xref="啟示錄 22:17; 哥林多前書 14:24–25; 約翰福音 4:25"> 「你們來看！有一個人將我素來所行的一切事都給我說出來了，莫非這就是基督嗎？」</span>
<span className="v" id="v30" data-v="30" data-xref="羅馬書 5:20; 使徒行傳 8:5–8; 路加福音 17:16–18"> 眾人就出城，往耶穌那裏去。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="約翰福音 1:38; 創世記 24:33; 使徒行傳 16:30–34"> 這其間，門徒對耶穌說：「拉比，請吃。」</span>
<span className="v" id="v32" data-v="32" data-xref="約伯記 23:12; 詩篇 119:103; 約翰福音 4:34"> 耶穌說：「我有食物吃，是你們不知道的。」</span>
<span className="v" id="v33" data-v="33" data-xref="馬太福音 16:6–11; 路加福音 9:45"> 門徒就彼此對問說：「莫非有人拿甚麼給他吃嗎？」</span>
<span className="v" id="v34" data-v="34" data-xref="約翰福音 6:38; 約翰福音 5:30; 約伯記 23:12"> 耶穌說：「我的食物就是遵行差我來者的旨意，做成他的工。</span>
<span className="v" id="v35" data-v="35" data-xref="路加福音 10:2–3; 馬太福音 9:37–38; 約翰福音 4:30"> 你們豈不說『到收割的時候還有四個月』嗎？我告訴你們，舉目向田觀看，莊稼已經熟了<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原文是發白">b</a></sup>，可以收割了。</span>
<span className="v" id="v36" data-v="36" data-xref="雅各書 5:19–20; 羅馬書 1:13; 哥林多前書 3:5–9"> 收割的人得工價，積蓄五穀到永生，叫撒種的和收割的一同快樂。</span>
<span className="v" id="v37" data-v="37" data-xref="彌迦書 6:15; 約伯記 31:8; 路加福音 19:21"> 俗語說：『那人撒種，這人收割』，這話可見是真的。</span>
<span className="v" id="v38" data-v="38" data-xref="約翰福音 1:7; 歷代志下 36:15; 使徒行傳 10:42–43"> 我差你們去收你們所沒有勞苦的；別人勞苦，你們享受他們所勞苦的。」</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="約翰福音 4:29; 約翰福音 4:5; 約翰福音 10:41–42"> 那城裏有好些撒馬利亞人信了耶穌，因為那婦人作見證說：「他將我素來所行的一切事都給我說出來了。」</span>
<span className="v" id="v40" data-v="40" data-xref="啟示錄 3:20; 使徒行傳 16:15; 路加福音 24:29"> 於是撒馬利亞人來見耶穌，求他在他們那裏住下，他便在那裏住了兩天。</span>
<span className="v" id="v41" data-v="41" data-xref="哥林多前書 2:4–5; 使徒行傳 1:8; 使徒行傳 8:12"> 因耶穌的話，信的人就更多了，</span>
<span className="v" id="v42" data-v="42" data-xref="約翰一書 4:14; 約翰福音 1:29; 約翰一書 5:20"> 便對婦人說：「現在我們信，不是因為你的話，是我們親自聽見了，知道這真是救世主。」</span>
</div>
</div>

## 耶穌治好大臣的兒子

<div className="bt">
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="馬太福音 4:13; 羅馬書 15:8; 馬可福音 7:27–28"> 過了那兩天，耶穌離了那地方，往加利利去。</span>
<span className="v" id="v44" data-v="44" data-xref="馬太福音 13:57; 路加福音 4:24; 馬可福音 6:4"> 因為耶穌自己作過見證說：「先知在本地是沒有人尊敬的。」</span>
<span className="v" id="v45" data-v="45" data-xref="約翰福音 2:23; 約翰福音 2:13–16; 申命記 16:16"> 到了加利利，加利利人既然看見他在耶路撒冷過節所行的一切事，就接待他，因為他們也是上去過節。</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="約翰福音 2:1–11; 路加福音 7:2; 何西阿書 5:15"> 耶穌又到了加利利的迦拿，就是他從前變水為酒的地方。有一個大臣，他的兒子在迦百農患病。</span>
<span className="v" id="v47" data-v="47" data-xref="約翰福音 4:3; 約翰福音 11:21; 約翰福音 11:32"> 他聽見耶穌從猶太到了加利利，就來見他，求他下去醫治他的兒子，因為他兒子快要死了。</span>
<span className="v" id="v48" data-v="48" data-xref="約翰福音 20:29; 希伯來書 2:4; 哥林多前書 1:22"> 耶穌就對他說：「若不看見神蹟奇事，你們總是不信。」</span>
<span className="v" id="v49" data-v="49" data-xref="馬可福音 5:23; 詩篇 88:10–12; 詩篇 40:17"> 那大臣說：「先生，求你趁着我的孩子還沒有死就下去。」</span>
<span className="v" id="v50" data-v="50" data-xref="馬太福音 8:13; 馬可福音 7:29–30; 羅馬書 4:20–21"> 耶穌對他說：「回去吧，你的兒子活了！」那人信耶穌所說的話就回去了。</span>
<span className="v" id="v51" data-v="51" data-xref="列王紀上 17:23; 約翰福音 4:50; 約翰福音 4:53"> 正下去的時候，他的僕人迎見他，說他的兒子活了。</span>
<span className="v" id="v52" data-v="52"> 他就問甚麼時候見好的。他們說：「昨日未時熱就退了。」</span>
<span className="v" id="v53" data-v="53" data-xref="詩篇 107:20; 路加福音 19:9; 使徒行傳 16:34"> 他便知道這正是耶穌對他說「你兒子活了」的時候；他自己和全家就都信了。</span>
<span className="v" id="v54" data-v="54" data-xref="約翰福音 4:45; 約翰福音 2:1–11"> 這是耶穌在加利利行的第二件神蹟，是他從猶太回去以後行的。</span>
</div>

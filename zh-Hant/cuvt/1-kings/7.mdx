## 所羅門的王宮

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀上 9:10; 歷代志下 8:1; 傳道書 2:4–5"> 所羅門為自己建造宮室，十三年方才造成；</span>
<span className="v" id="v2" data-v="2" data-xref="列王紀上 10:17; 歷代志下 9:16; 列王紀上 10:21"> 又建造黎巴嫩林宮，長一百肘，寬五十肘，高三十肘，有香柏木柱三<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是四">a</a></sup>行，柱上有香柏木柁樑。</span>
<span className="v" id="v3" data-v="3" data-xref="列王紀上 6:5"> 其上以香柏木為蓋，每行柱子十五根，共有四十五根。</span>
<span className="v" id="v4" data-v="4" data-xref="以西結書 40:22; 以西結書 40:16; 列王紀上 6:4"> 有窗戶三層，窗與窗相對。</span>
<span className="v" id="v5" data-v="5"> 所有的門框都是厚木見方的，有窗戶三層，窗與窗相對。</span>
<span className="v" id="v6" data-v="6" data-xref="列王紀上 7:12; 以西結書 41:25–26"> 並建造有柱子的廊子，長五十肘，寬三十肘；在這廊前又有廊子，廊外有柱子和臺階。</span>
<span className="v" id="v7" data-v="7" data-xref="箴言 20:8; 詩篇 122:5; 以賽亞書 9:7"> 又建造一廊，其中設立審判的座位，這廊從地到頂都用香柏木遮蔽。</span>
<span className="v" id="v8" data-v="8" data-xref="歷代志下 8:11; 列王紀上 3:1; 列王紀上 9:24"> 廊後院內有所羅門住的宮室；工作與這工作相同。所羅門又為所娶法老的女兒建造一宮，做法與這廊子一樣。</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀上 7:10–11; 列王紀上 5:17"> 建造這一切所用的石頭都是寶貴的，是按着尺寸鑿成的，是用鋸裏外鋸齊的；從根基直到檐石，從外頭直到大院，都是如此。</span>
<span className="v" id="v10" data-v="10" data-xref="啟示錄 21:19–20; 哥林多前書 3:10–11; 以賽亞書 54:11"> 根基是寶貴的大石頭，有長十肘的，有長八肘的；</span>
<span className="v" id="v11" data-v="11" data-xref="以弗所書 2:20–22; 彼得前書 2:5"> 上面有香柏木和按着尺寸鑿成寶貴的石頭。</span>
<span className="v" id="v12" data-v="12" data-xref="列王紀上 6:36; 列王紀上 7:6; 約翰福音 10:23"> 大院周圍有鑿成的石頭三層、香柏木一層，都照耶和華殿的內院和殿廊的樣式。</span>
</div>
</div>

## 戶蘭的工作

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="歷代志下 4:11; 歷代志下 2:13–14; 列王紀上 7:40"> 所羅門王差遣人往泰爾去，將戶蘭召了來。</span>
<span className="v" id="v14" data-v="14" data-xref="歷代志下 2:14; 歷代志下 4:16; 出埃及記 31:2–6"> 他是拿弗他利支派中一個寡婦的兒子，他父親是泰爾人，作銅匠的。戶蘭滿有智慧、聰明、技能，善於各樣銅作。他來到所羅門王那裏，做王一切所要做的。</span>
</div>
</div>

## 兩支銅柱

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="耶利米書 52:21; 歷代志下 3:15–17; 列王紀上 7:21"> 他製造兩根銅柱，每根高十八肘，圍十二肘；</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 38:19; 歷代志下 4:12–13; 出埃及記 38:17"> 又用銅鑄了兩個柱頂安在柱上，各高五肘。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及記 28:14; 出埃及記 28:24–25; 出埃及記 28:22"> 柱頂上有裝修的網子和擰成的鍊索，每頂七個。</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及記 28:14; 出埃及記 39:15–18; 出埃及記 28:22"> 網子周圍有兩行石榴遮蓋柱頂，兩個柱頂都是如此。</span>
<span className="v" id="v19" data-v="19" data-xref="列王紀上 7:22; 列王紀上 6:32–35; 列王紀上 6:18"> 廊子的柱頂徑四肘，刻着百合花。</span>
<span className="v" id="v20" data-v="20" data-xref="歷代志下 3:16; 歷代志下 4:13; 耶利米書 52:22–23"> 兩柱頂的鼓肚上挨着網子，各有兩行石榴環繞，兩行共有二百。</span>
<span className="v" id="v21" data-v="21" data-xref="歷代志下 3:17; 列王紀上 6:3; 列王紀上 7:12"> 他將兩根柱子立在殿廊前頭：右邊立一根，起名叫雅斤；左邊立一根，起名叫波阿斯。</span>
<span className="v" id="v22" data-v="22"> 在柱頂上刻着百合花。這樣，造柱子的工就完畢了。</span>
</div>
</div>

## 銅海

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="歷代志下 4:2; 列王紀下 25:13; 耶利米書 52:17"> 他又鑄一個銅海，樣式是圓的，高五肘，徑十肘，圍三十肘。</span>
<span className="v" id="v24" data-v="24" data-xref="列王紀上 6:18; 歷代志下 4:3; 出埃及記 37:17–22"> 在海邊之下，周圍有野瓜的樣式；每肘十瓜，共有兩行，是鑄海的時候鑄上的。</span>
<span className="v" id="v25" data-v="25" data-xref="耶利米書 52:20; 歷代志下 4:4–5; 馬太福音 28:19"> 有十二隻銅牛馱海：三隻向北，三隻向西，三隻向南，三隻向東；海在牛上，牛尾都向內。</span>
<span className="v" id="v26" data-v="26" data-xref="歷代志下 4:5; 列王紀上 7:38; 列王紀上 6:18"> 海厚一掌，邊如杯邊，又如百合花，可容二千罷特。</span>
</div>
</div>

## 銅座

<div className="bt">
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="歷代志下 4:14; 列王紀下 25:13; 耶利米書 52:17"> 他用銅製造十個盆座，每座長四肘，寬四肘，高三肘。</span>
<span className="v" id="v28" data-v="28"> 座的造法是這樣：四面都有心子，心子在邊子當中，</span>
<span className="v" id="v29" data-v="29" data-xref="何西阿書 5:14; 以西結書 10:14; 出埃及記 37:7"> 心子上有獅子和牛，並基路伯；邊上有小座，獅子和牛以下有垂下的瓔珞。</span>
<span className="v" id="v30" data-v="30" data-xref="以西結書 10:10–13; 以西結書 3:13; 以西結書 1:15–21"> 每盆座有四個銅輪和銅軸。小座的四角上在盆以下，有鑄成的盆架，其旁都有瓔珞。</span>
<span className="v" id="v31" data-v="31"> 小座高一肘，口是圓的，彷彿座的樣式，徑一肘半，在口上有雕工，心子是方的，不是圓的。</span>
<span className="v" id="v32" data-v="32"> 四個輪子在心子以下，輪軸與座相連，每輪高一肘半。</span>
<span className="v" id="v33" data-v="33" data-xref="以西結書 1:18; 以西結書 1:16"> 輪的樣式如同車輪；軸、輞、輻、轂都是鑄的。</span>
<span className="v" id="v34" data-v="34"> 每座四角上都有盆架，是與座一同鑄成的。</span>
<span className="v" id="v35" data-v="35"> 座上有圓架，高半肘；座上有撐子和心子，是與座一同鑄的。</span>
<span className="v" id="v36" data-v="36" data-xref="列王紀上 7:29; 列王紀上 6:29; 以西結書 41:18–20"> 在撐子和心子上刻着基路伯、獅子，和棕樹，周圍有瓔珞。</span>
<span className="v" id="v37" data-v="37"> 十個盆座都是這樣，鑄法、尺寸、樣式相同。</span>
<span className="v" id="v38" data-v="38" data-xref="出埃及記 40:11–12; 撒迦利亞書 13:1; 約翰一書 1:7"> 又用銅製造十個盆，每盆可容四十罷特。盆徑四肘，在那十座上，每座安設一盆。</span>
<span className="v" id="v39" data-v="39" data-xref="歷代志下 4:10; 歷代志下 4:6"> 五個安在殿門的右邊，五個放在殿門的左邊；又將海放在殿門的右旁，就是南邊。</span>
</div>
</div>

## 聖殿設備清單

<div className="bt">
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="歷代志下 4:11–16; 出埃及記 24:6; 出埃及記 39:32–43"> 戶蘭又造了盆、鏟子，和盤子。這樣，他為所羅門王做完了耶和華殿的一切工。</span>
<span className="v" id="v41" data-v="41" data-xref="列王紀上 7:15–22; 歷代志下 4:12"> 所造的就是：兩根柱子和柱上兩個如球的頂；並兩個蓋柱頂的網子；</span>
<span className="v" id="v42" data-v="42" data-xref="列王紀上 7:20"> 和四百石榴，安在兩個網子上，每網兩行，蓋着兩個柱上如球的頂；</span>
<span className="v" id="v43" data-v="43"> 十個座和其上的十個盆；</span>
<span className="v" id="v44" data-v="44" data-xref="列王紀上 7:23; 列王紀上 7:25"> 海和海下的十二隻牛；</span>
<span className="v" id="v45" data-v="45" data-xref="出埃及記 27:3; 出埃及記 38:3; 歷代志下 4:16"> 盆、鏟子、盤子。這一切都是戶蘭給所羅門王用光亮的銅為耶和華的殿造成的，</span>
<span className="v" id="v46" data-v="46" data-xref="約書亞記 3:16; 歷代志下 4:17; 創世記 33:17"> 是遵王命在約旦平原、疏割和撒拉但中間藉膠泥鑄成的。</span>
<span className="v" id="v47" data-v="47" data-xref="歷代志上 22:14; 歷代志上 22:3; 歷代志下 4:18"> 這一切所羅門都沒有過秤；因為甚多，銅的輕重也無法可查。</span>
<span className="v" id="v48" data-v="48" data-xref="出埃及記 37:10–16; 歷代志下 4:8; 出埃及記 39:36"> 所羅門又造耶和華殿裏的金壇和陳設餅的金桌子；</span>
<span className="v" id="v49" data-v="49" data-xref="歷代志下 4:7; 歷代志下 4:20; 撒迦利亞書 4:11–14"> 內殿前的精金燈臺：右邊五個，左邊五個，並其上的金花、燈盞、蠟剪，</span>
<span className="v" id="v50" data-v="50" data-xref="出埃及記 25:29; 歷代志下 4:21–22; 出埃及記 27:3"> 與精金的杯、盤、鑷子、調羹、火鼎，以及至聖所、內殿的門樞，和外殿的門樞。</span>
</div>
</div>

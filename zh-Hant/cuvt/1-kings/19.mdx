## 以利亞在何烈山上

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀上 18:40; 列王紀上 21:25; 列王紀上 21:5–7"> 亞哈將以利亞一切所行的和他用刀殺眾先知的事都告訴耶洗別。</span>
<span className="v" id="v2" data-v="2" data-xref="路得記 1:17; 列王紀下 6:31; 列王紀上 20:10"> 耶洗別就差遣人去見以利亞，告訴他說：「明日約在這時候，我若不使你的性命像那些人的性命一樣，願神明重重地降罰與我。」</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 21:31; 馬太福音 26:70–74; 馬太福音 26:56"> 以利亞見這光景就起來逃命，到了猶大的別是巴，將僕人留在那裏，</span>
<span className="v" id="v4" data-v="4" data-xref="約拿書 4:3; 民數記 11:15; 約拿書 4:8"> 自己在曠野走了一日的路程，來到一棵羅騰樹下<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="羅騰，小樹名，松類；下同">a</a></sup>，就坐在那裏求死，說：「耶和華啊，罷了！求你取我的性命，因為我不勝於我的列祖。」</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 34:7; 使徒行傳 12:7; 希伯來書 13:5"> 他就躺在羅騰樹下，睡着了。有一個天使拍他，說：「起來吃吧！」</span>
<span className="v" id="v6" data-v="6" data-xref="列王紀上 17:6; 馬太福音 4:11; 馬太福音 6:32"> 他觀看，見頭旁有一瓶水與炭火燒的餅，他就吃了喝了，仍然躺下。</span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 103:13–14; 申命記 33:25"> 耶和華的使者第二次來拍他，說：「起來吃吧！因為你當走的路甚遠。」</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及記 34:28; 出埃及記 24:18; 出埃及記 3:1"> 他就起來吃了喝了，仗着這飲食的力，走了四十晝夜，到了上帝的山，就是何烈山。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="列王紀上 19:13; 出埃及記 33:21–22; 耶利米書 2:18"> 他在那裏進了一個洞，就住在洞中。耶和華的話臨到他說：「以利亞啊，你在這裏做甚麼？」</span>
<span className="v" id="v10" data-v="10" data-xref="列王紀上 18:4; 列王紀上 18:22; 出埃及記 34:14"> 他說：「我為耶和華－萬軍之上帝大發熱心；因為以色列人背棄了你的約，毀壞了你的壇，用刀殺了你的先知，只剩下我一個人，他們還要尋索我的命。」</span>
<span className="v" id="v11" data-v="11" data-xref="以西結書 1:4; 詩篇 50:3; 約伯記 38:1"> 耶和華說：「你出來站在山上，在我面前。」那時耶和華從那裏經過，在他面前有烈風大作，崩山碎石，耶和華卻不在風中；風後地震，耶和華卻不在其中；</span>
<span className="v" id="v12" data-v="12" data-xref="約伯記 4:16; 撒迦利亞書 4:6; 申命記 4:33"> 地震後有火，耶和華也不在火中；火後有微小的聲音。</span>
<span className="v" id="v13" data-v="13" data-xref="列王紀上 19:9; 以賽亞書 6:2; 創世記 16:8"> 以利亞聽見，就用外衣蒙上臉，出來站在洞口。有聲音向他說：「以利亞啊，你在這裏做甚麼？」</span>
<span className="v" id="v14" data-v="14" data-xref="列王紀上 19:9–10; 耶利米書 22:9; 以賽亞書 62:1"> 他說：「我為耶和華－萬軍之上帝大發熱心；因為以色列人背棄了你的約，毀壞了你的壇，用刀殺了你的先知，只剩下我一個人，他們還要尋索我的命。」</span>
<span className="v" id="v15" data-v="15" data-xref="以賽亞書 45:1; 耶利米書 1:10; 列王紀下 8:7–15"> 耶和華對他說：「你回去，從曠野往大馬士革去。到了那裏，就要膏哈薛作亞蘭王，</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀下 9:1–14; 列王紀上 19:19–21; 列王紀下 2:9"> 又膏寧示的孫子耶戶作以色列王，並膏亞伯‧米何拉人沙法的兒子以利沙作先知接續你。</span>
<span className="v" id="v17" data-v="17" data-xref="列王紀下 13:22; 列王紀下 8:12; 列王紀下 13:3"> 將來躲避哈薛之刀的，必被耶戶所殺；躲避耶戶之刀的，必被以利沙所殺。</span>
<span className="v" id="v18" data-v="18" data-xref="羅馬書 11:4–5; 以賽亞書 1:9; 以賽亞書 10:20–22"> 但我在以色列人中為自己留下七千人，是未曾向巴力屈膝的，未曾與巴力親嘴的。」</span>
</div>
</div>

## 以利沙蒙選召

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="列王紀下 2:8; 列王紀下 2:13–14; 撒母耳記上 28:14"> 於是，以利亞離開那裏走了，遇見沙法的兒子以利沙耕地；在他前頭有十二對牛，自己趕着第十二對。以利亞到他那裏去，將自己的外衣搭在他身上。</span>
<span className="v" id="v20" data-v="20" data-xref="馬太福音 8:21–22; 路加福音 9:61–62; 使徒行傳 20:37"> 以利沙就離開牛，跑到以利亞那裏，說：「求你容我先與父母親嘴，然後我便跟隨你。」以利亞對他說：「你回去吧，我向你做了甚麼呢？」</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳記下 24:22; 提摩太後書 4:11; 腓利門書 1:13"> 以利沙就離開他回去，宰了一對牛，用套牛的器具煮肉給民吃，隨後就起身跟隨以利亞，服事他。</span>
</div>

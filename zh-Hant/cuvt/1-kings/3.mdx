## 所羅門祈禱求智慧

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀上 9:24; 列王紀上 11:1; 列王紀上 6:1–15"> 所羅門與埃及王法老結親，娶了法老的女兒為妻，接她進入大衛城，直等到造完了自己的宮和耶和華的殿，並耶路撒冷周圍的城牆。</span>
<span className="v" id="v2" data-v="2" data-xref="列王紀上 22:43; 歷代志下 33:17; 申命記 12:2–5"> 當那些日子，百姓仍在邱壇獻祭，因為還沒有為耶和華的名建殿。</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多前書 8:3; 詩篇 31:23; 申命記 30:16"> 所羅門愛耶和華，遵行他父親大衛的律例，只是還在邱壇獻祭燒香。</span>
<span className="v" id="v4" data-v="4" data-xref="歷代志上 16:39; 歷代志下 1:3; 歷代志下 7:5"> 所羅門王上基遍去獻祭；因為在那裏有極大<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或譯：出名">a</a></sup>的邱壇，他在那壇上獻一千犧牲作燔祭。</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀上 9:2; 雅各書 1:5–6; 民數記 12:6"> 在基遍，夜間夢中，耶和華向所羅門顯現，對他說：「你願我賜你甚麼？你可以求。」</span>
<span className="v" id="v6" data-v="6" data-xref="列王紀上 9:4; 列王紀上 1:48; 哥林多後書 9:11"> 所羅門說：「你僕人－我父親大衛用誠實、公義、正直的心行在你面前，你就向他大施恩典，又為他存留大恩，賜他一個兒子坐在他的位上，正如今日一樣。</span>
<span className="v" id="v7" data-v="7" data-xref="歷代志上 29:1; 民數記 27:17; 耶利米書 1:6"> 耶和華－我的上帝啊，如今你使僕人接續我父親大衛作王；但我是幼童，不知道應當怎樣出入。</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 15:5; 創世記 13:16; 歷代志上 21:2"> 僕人住在你所揀選的民中，這民多得不可勝數。</span>
<span className="v" id="v9" data-v="9" data-xref="雅各書 1:5; 箴言 16:16; 希伯來書 5:14"> 所以求你賜我智慧，可以判斷你的民，能辨別是非。不然，誰能判斷這眾多的民呢？」</span>
<span className="v" id="v10" data-v="10" data-xref="箴言 15:8"> 所羅門因為求這事，就蒙主喜悅。</span>
<span className="v" id="v11" data-v="11" data-xref="羅馬書 8:26; 雅各書 4:2–3; 箴言 16:31"> 上帝對他說：「你既然求這事，不為自己求壽、求富，也不求滅絕你仇敵的性命，單求智慧可以聽訟，</span>
<span className="v" id="v12" data-v="12" data-xref="約翰一書 5:14–15; 傳道書 1:16; 馬太福音 12:42"> 我就應允你所求的，賜你聰明智慧，甚至在你以前沒有像你的，在你以後也沒有像你的。</span>
<span className="v" id="v13" data-v="13" data-xref="以弗所書 3:20; 馬太福音 6:33; 箴言 3:16"> 你所沒有求的，我也賜給你，就是富足、尊榮，使你在世的日子，列王中沒有一個能比你的。</span>
<span className="v" id="v14" data-v="14" data-xref="箴言 3:2; 詩篇 91:16; 列王紀上 15:5"> 你若效法你父親大衛，遵行我的道，謹守我的律例、誡命，我必使你長壽。」</span>
<span className="v" id="v15" data-v="15" data-xref="創世記 41:7; 列王紀上 8:65; 以斯帖記 1:3"> 所羅門醒了，不料是個夢。他就回到耶路撒冷，站在耶和華的約櫃前，獻燔祭和平安祭，又為他眾臣僕設擺筵席。</span>
</div>
</div>

## 所羅門審斷一件疑難的案件

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="出埃及記 18:16; 士師記 11:1; 民數記 27:2"> 一日，有兩個妓女來，站在王面前。</span>
<span className="v" id="v17" data-v="17" data-xref="羅馬書 13:7; 創世記 43:20"> 一個說：「我主啊，我和這婦人同住一房；她在房中的時候，我生了一個男孩。</span>
<span className="v" id="v18" data-v="18"> 我生孩子後第三日，這婦人也生了孩子。我們是同住的，除了我們二人之外，房中再沒有別人。</span>
<span className="v" id="v19" data-v="19"> 夜間，這婦人睡着的時候，壓死了她的孩子。</span>
<span className="v" id="v20" data-v="20" data-xref="約翰福音 3:20; 馬太福音 13:25; 詩篇 139:11"> 她半夜起來，趁我睡着，從我旁邊把我的孩子抱去，放在她懷裏，將她的死孩子放在我懷裏。</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 21:7; 撒母耳記上 1:23; 耶利米哀歌 4:3–4"> 天要亮的時候，我起來要給我的孩子吃奶，不料，孩子死了；及至天亮，我細細地察看，不是我所生的孩子。」</span>
<span className="v" id="v22" data-v="22" data-xref="列王紀上 3:23–24"> 那婦人說：「不然，活孩子是我的，死孩子是你的。」這婦人說：「不然，死孩子是你的，活孩子是我的。」她們在王面前如此爭論。</span>
<span className="v" id="v23" data-v="23"> 王說：「這婦人說『活孩子是我的，死孩子是你的』，那婦人說『不然，死孩子是你的，活孩子是我的』」，</span>
<span className="v" id="v24" data-v="24"> 就吩咐說：「拿刀來！」人就拿刀來。</span>
<span className="v" id="v25" data-v="25" data-xref="箴言 25:8"> 王說：「將活孩子劈成兩半，一半給那婦人，一半給這婦人。」</span>
<span className="v" id="v26" data-v="26" data-xref="以賽亞書 49:15; 耶利米書 31:20; 約翰一書 3:17"> 活孩子的母親為自己的孩子心裏急痛，就說：「求我主將活孩子給那婦人吧，萬不可殺他！」那婦人說：「這孩子也不歸我，也不歸你，把他劈了吧！」</span>
<span className="v" id="v27" data-v="27"> 王說：「將活孩子給這婦人，萬不可殺他；這婦人實在是他的母親。」</span>
<span className="v" id="v28" data-v="28" data-xref="但以理書 2:47; 列王紀上 3:9–12; 歌羅西書 2:3"> 以色列眾人聽見王這樣判斷，就都敬畏他；因為見他心裏有上帝的智慧，能以斷案。</span>
</div>

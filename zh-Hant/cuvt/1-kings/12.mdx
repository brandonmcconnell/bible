## 北方的支派反叛

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="士師記 9:6; 歷代志下 10:1–19; 士師記 9:1"> 羅波安往示劍去；因為以色列人都到了示劍要立他作王。</span>
<span className="v" id="v2" data-v="2" data-xref="列王紀上 11:40; 歷代志下 10:2–3; 列王紀上 11:26–31"> 尼八的兒子耶羅波安先前躲避所羅門王，逃往埃及，住在那裏（他聽見這事。）</span>
<span className="v" id="v3" data-v="3"> 以色列人打發人去請他來，他就和以色列會眾都來見羅波安，對他說：</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳記上 8:11–18; 列王紀上 4:7; 馬太福音 11:29–30"> 「你父親使我們負重軛，做苦工，現在求你使我們做的苦工、負的重軛輕鬆些，我們就事奉你。」</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀上 12:12"> 羅波安對他們說：「你們暫且去，第三日再來見我。」民就去了。</span>
<span className="v" id="v6" data-v="6" data-xref="約伯記 12:12; 約伯記 32:7; 撒母耳記下 16:20"> 羅波安之父所羅門在世的日子，有侍立在他面前的老年人，羅波安王和他們商議，說：「你們給我出個甚麼主意，我好回覆這民。」</span>
<span className="v" id="v7" data-v="7" data-xref="箴言 15:1; 歷代志下 10:6–7; 列王紀上 12:13"> 老年人對他說：「現在王若服事這民如僕人，用好話回答他們，他們就永遠作王的僕人。」</span>
<span className="v" id="v8" data-v="8" data-xref="箴言 19:20; 傳道書 10:2–3; 歷代志下 10:8"> 王卻不用老年人給他出的主意，就和那些與他一同長大、在他面前侍立的少年人商議，</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀上 22:6–8; 撒母耳記下 17:5–6; 歷代志下 10:9"> 說：「這民對我說：『你父親使我們負重軛，求你使我們輕鬆些。』你們給我出個甚麼主意，我好回覆他們。」</span>
<span className="v" id="v10" data-v="10" data-xref="歷代志下 10:10–11; 箴言 10:14; 以賽亞書 47:6"> 那同他長大的少年人說：「這民對王說：『你父親使我們負重軛，求你使我們輕鬆些。』王要對他們如此說：『我的小拇指頭比我父親的腰還粗。</span>
<span className="v" id="v11" data-v="11" data-xref="耶利米書 27:11; 以西結書 2:6; 耶利米書 28:13–14"> 我父親使你們負重軛，我必使你們負更重的軛！我父親用鞭子責打你們，我要用蠍子鞭責打你們！』」</span>
<span className="v" id="v12" data-v="12" data-xref="列王紀上 12:5; 歷代志下 10:12–14"> 耶羅波安和眾百姓遵着羅波安王所說「你們第三日再來見我」的那話，第三日他們果然來了。</span>
<span className="v" id="v13" data-v="13" data-xref="雅各書 3:17; 箴言 13:20; 傳道書 10:12"> 王用嚴厲的話回答百姓，不用老年人給他所出的主意，</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及記 5:16–18; 列王紀上 12:10–11; 出埃及記 5:5–9"> 照着少年人所出的主意對民說：「我父親使你們負重軛，我必使你們負更重的軛！我父親用鞭子責打你們，我要用蠍子鞭責打你們！」</span>
<span className="v" id="v15" data-v="15" data-xref="列王紀上 12:24; 申命記 2:30; 士師記 14:4"> 王不肯依從百姓，這事乃出於耶和華，為要應驗他藉示羅人亞希雅對尼八的兒子耶羅波安所說的話。</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳記下 20:1; 耶利米書 23:5–6; 歷代志下 10:16"> 以色列眾民見王不依從他們，就對王說：<br /><span className="pl pl-1">我們與大衛有甚麼分兒呢？</span><br /><span className="pl pl-1">與耶西的兒子並沒有關涉。</span><br /><span className="pl pl-1">以色列人哪，各回各家去吧！</span><br /><span className="pl pl-1">大衛家啊，自己顧自己吧！</span>於是，以色列人都回自己家裏去了，</span>
<span className="v" id="v17" data-v="17" data-xref="列王紀上 11:36; 列王紀上 11:13; 歷代志下 11:13–17"> 惟獨住猶大城邑的以色列人，羅波安仍作他們的王。</span>
<span className="v" id="v18" data-v="18" data-xref="列王紀上 4:6; 撒母耳記下 20:24; 列王紀上 5:14"> 羅波安王差遣掌管服苦之人的亞多蘭往以色列人那裏去，以色列人就用石頭打死他。羅波安王急忙上車，逃回耶路撒冷去了。</span>
<span className="v" id="v19" data-v="19" data-xref="列王紀下 17:21; 歷代志下 10:19; 約書亞記 4:9"> 這樣，以色列人背叛大衛家，直到今日。</span>
<span className="v" id="v20" data-v="20" data-xref="列王紀上 11:13; 列王紀上 11:32; 何西阿書 8:4"> 以色列眾人聽見耶羅波安回來了，就打發人去請他到會眾面前，立他作以色列眾人的王。除了猶大支派以外，沒有順從大衛家的。</span>
</div>
</div>

## 示瑪雅的預言

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="歷代志下 11:1–3; 歷代志上 21:5; 歷代志下 14:8"> 羅波安來到耶路撒冷，招聚猶大全家和便雅憫支派的人共十八萬，都是挑選的戰士，要與以色列家爭戰，好將國奪回，再歸所羅門的兒子羅波安。</span>
<span className="v" id="v22" data-v="22" data-xref="歷代志下 11:2; 歷代志下 12:5–7; 列王紀上 13:1"> 但上帝的話臨到神人示瑪雅，說：</span>
<span className="v" id="v23" data-v="23" data-xref="列王紀上 12:17"> 「你去告訴所羅門的兒子猶大王羅波安和猶大、便雅憫全家，並其餘的民說：</span>
<span className="v" id="v24" data-v="24" data-xref="列王紀上 12:15; 歷代志下 25:7–8; 何西阿書 8:4"> 『耶和華如此說：你們不可上去與你們的弟兄以色列人爭戰。各歸各家去吧！因為這事出於我。』」眾人就聽從耶和華的話，遵着耶和華的命回去了。</span>
</div>

## 耶羅波安離棄上帝

<div className="bt">
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="士師記 8:17; 士師記 8:8; 士師記 9:45–49"> 耶羅波安在以法蓮山地建築示劍，就住在其中；又從示劍出去，建築毗努伊勒。</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米書 38:18–21; 以賽亞書 7:9; 馬可福音 2:6–8"> 耶羅波安心裏說：「恐怕這國仍歸大衛家；</span>
<span className="v" id="v27" data-v="27" data-xref="申命記 12:5–7; 箴言 29:25; 申命記 12:14"> 這民若上耶路撒冷去，在耶和華的殿裏獻祭，他們的心必歸向他們的主－猶大王羅波安，就把我殺了，仍歸猶大王羅波安。」</span>
<span className="v" id="v28" data-v="28" data-xref="列王紀下 10:29; 出埃及記 32:8; 列王紀下 17:16"> 耶羅波安王就籌劃定妥，鑄造了兩個金牛犢，對眾民說：「以色列人哪，你們上耶路撒冷去實在是難；這就是領你們出埃及地的神。」</span>
<span className="v" id="v29" data-v="29" data-xref="創世記 28:19; 士師記 18:27–31; 何西阿書 4:15"> 他就把牛犢一隻安在伯特利，一隻安在但。</span>
<span className="v" id="v30" data-v="30" data-xref="列王紀下 17:21; 列王紀上 13:34; 列王紀下 10:31"> 這事叫百姓陷在罪裏，因為他們往但去拜那牛犢。</span>
<span className="v" id="v31" data-v="31" data-xref="歷代志下 13:9; 列王紀下 17:32; 列王紀上 13:32–33"> 耶羅波安在邱壇那裏建殿，將那不屬利未人的凡民立為祭司。</span>
</div>
</div>

## 在伯特利拜牛犢被定罪

<div className="bt">
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="列王紀上 8:5; 列王紀上 8:2; 阿摩司書 7:10–13"> 耶羅波安定八月十五日為節期，像在猶大的節期一樣，自己上壇獻祭。他在伯特利也這樣向他所鑄的牛犢獻祭，又將立為邱壇的祭司安置在伯特利。</span>
<span className="v" id="v33" data-v="33" data-xref="列王紀上 13:1; 民數記 15:39; 馬太福音 15:6"> 他在八月十五日，就是他私自所定的月日，為以色列人立作節期的日子，在伯特利上壇燒香。</span>
</div>

## 以利亞和巴力的先知們

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 4:25; 雅各書 5:17; 申命記 28:12"> 過了許久，到第三年，耶和華的話臨到以利亞說：「你去，使亞哈得見你；我要降雨在地上。」</span>
<span className="v" id="v2" data-v="2" data-xref="列王紀下 6:25; 箴言 28:1; 利未記 26:26"> 以利亞就去，要使亞哈得見他。那時，撒馬利亞有大饑荒；</span>
<span className="v" id="v3" data-v="3" data-xref="尼希米記 7:2; 列王紀上 16:9; 馬太福音 10:28"> 亞哈將他的家宰俄巴底召了來。（俄巴底甚是敬畏耶和華，</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀上 18:13; 馬太福音 10:40–42; 啟示錄 17:4–6"> 耶洗別殺耶和華眾先知的時候，俄巴底將一百個先知藏了，每五十人藏在一個洞裏，拿餅和水供養他們。）</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米書 14:5–6; 約珥書 1:18; 約珥書 2:22"> 亞哈對俄巴底說：「我們走遍這地，到一切水泉旁和一切溪邊，或者找得着青草，可以救活騾馬，免得絕了牲畜。」</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米書 14:3"> 於是二人分地遊行，亞哈獨走一路，俄巴底獨走一路。</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀下 1:6–8; 創世記 44:20; 以賽亞書 60:14"> 俄巴底在路上恰與以利亞相遇，俄巴底認出他來，就俯伏在地，說：「你是我主以利亞不是？」</span>
<span className="v" id="v8" data-v="8" data-xref="羅馬書 13:7; 列王紀上 18:3; 彼得前書 2:17–18"> 回答說：「是。你去告訴你主人說，以利亞在這裏。」</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及記 5:21; 列王紀上 18:12; 列王紀上 17:18"> 俄巴底說：「僕人有甚麼罪，你竟要將我交在亞哈手裏，使他殺我呢？</span>
<span className="v" id="v10" data-v="10" data-xref="列王紀上 17:1; 列王紀上 1:29; 列王紀上 18:15"> 我指着永生耶和華－你的上帝起誓，無論哪一邦哪一國，我主都打發人去找你。若說你沒有在那裏，就必使那邦那國的人起誓說，實在是找不着你。</span>
<span className="v" id="v11" data-v="11" data-xref="列王紀上 18:8; 列王紀上 18:14"> 現在你說，要去告訴你主人說，以利亞在這裏；</span>
<span className="v" id="v12" data-v="12" data-xref="列王紀下 2:16; 使徒行傳 8:39; 以西結書 8:3"> 恐怕我一離開你，耶和華的靈就提你到我所不知道的地方去。這樣，我去告訴亞哈，他若找不着你，就必殺我；僕人卻是自幼敬畏耶和華的。</span>
<span className="v" id="v13" data-v="13" data-xref="列王紀上 18:4; 馬太福音 25:35; 詩篇 18:21–24"> 耶洗別殺耶和華眾先知的時候，我將耶和華的一百個先知藏了，每五十人藏在一個洞裏，拿餅和水供養他們，豈沒有人將這事告訴我主嗎？</span>
<span className="v" id="v14" data-v="14" data-xref="馬太福音 10:28"> 現在你說，要去告訴你主人說，以利亞在這裏，他必殺我。」</span>
<span className="v" id="v15" data-v="15" data-xref="列王紀上 17:1; 列王紀上 18:10; 路加福音 2:13–14"> 以利亞說：「我指着所事奉永生的萬軍之耶和華起誓，我今日必使亞哈得見我。」</span>
<span className="v" id="v16" data-v="16"> 於是俄巴底去迎着亞哈，告訴他；亞哈就去迎着以利亞。</span>
<span className="v" id="v17" data-v="17" data-xref="約書亞記 7:25; 列王紀上 21:20; 使徒行傳 16:20"> 亞哈見了以利亞，便說：「使以色列遭災的就是你嗎？」</span>
<span className="v" id="v18" data-v="18" data-xref="歷代志下 15:2; 列王紀上 9:9; 耶利米書 2:19"> 以利亞說：「使以色列遭災的不是我，乃是你和你父家；因為你們離棄耶和華的誡命，去隨從巴力。</span>
<span className="v" id="v19" data-v="19" data-xref="約書亞記 19:26; 列王紀上 16:33; 彼得後書 2:1"> 現在你當差遣人，招聚以色列眾人和事奉巴力的那四百五十個先知，並耶洗別所供養事奉亞舍拉的那四百個先知，使他們都上迦密山去見我。」</span>
<span className="v" id="v20" data-v="20" data-xref="列王紀上 22:9"> 亞哈就差遣人招聚以色列眾人和先知都上迦密山。</span>
<span className="v" id="v21" data-v="21" data-xref="馬太福音 6:24; 約書亞記 24:15; 哥林多前書 10:21–22"> 以利亞前來對眾民說：「你們心持兩意要到幾時呢？若耶和華是上帝，就當順從耶和華；若巴力是上帝，就當順從巴力。」眾民一言不答。</span>
<span className="v" id="v22" data-v="22" data-xref="列王紀上 19:10; 列王紀上 19:14; 提摩太後書 4:3–4"> 以利亞對眾民說：「作耶和華先知的只剩下我一個人；巴力的先知卻有四百五十個人。</span>
<span className="v" id="v23" data-v="23"> 當給我們兩隻牛犢，巴力的先知可以挑選一隻，切成塊子，放在柴上，不要點火；我也預備一隻牛犢放在柴上，也不點火。</span>
<span className="v" id="v24" data-v="24" data-xref="列王紀上 18:38; 歷代志上 21:26; 歷代志下 7:1"> 你們求告你們神的名，我也求告耶和華的名。那降火顯應的神，就是上帝。」眾民回答說：「這話甚好。」</span>
<span className="v" id="v25" data-v="25"> 以利亞對巴力的先知說：「你們既是人多，當先挑選一隻牛犢，預備好了，就求告你們神的名，卻不要點火。」</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米書 10:5; 哥林多前書 8:4; 馬太福音 6:7"> 他們將所得的牛犢預備好了，從早晨到午間，求告巴力的名說：「巴力啊，求你應允我們！」卻沒有聲音，沒有應允的。他們在所築的壇四圍踊跳。</span>
<span className="v" id="v27" data-v="27" data-xref="詩篇 78:65–66; 以賽亞書 41:23; 傳道書 11:9"> 到了正午，以利亞嬉笑他們，說：「大聲求告吧！因為他是神，他或默想，或走到一邊，或行路，或睡覺，你們當叫醒他。」</span>
<span className="v" id="v28" data-v="28" data-xref="利未記 19:28; 申命記 14:1; 馬可福音 5:5"> 他們大聲求告，按着他們的規矩，用刀槍自割、自刺，直到身體流血。</span>
<span className="v" id="v29" data-v="29" data-xref="列王紀上 18:26; 撒母耳記上 18:10; 出埃及記 29:39"> 從午後直到獻晚祭的時候，他們狂呼亂叫，卻沒有聲音，沒有應允的，也沒有理會的。</span>
<span className="v" id="v30" data-v="30" data-xref="歷代志下 33:16; 列王紀上 19:14; 列王紀上 19:10"> 以利亞對眾民說：「你們到我這裏來。」眾民就到他那裏。他便重修已經毀壞耶和華的壇。</span>
<span className="v" id="v31" data-v="31" data-xref="列王紀下 17:34; 創世記 35:10; 創世記 32:28"> 以利亞照雅各子孫支派的數目，取了十二塊石頭（耶和華的話曾臨到雅各說：「你的名要叫以色列」），</span>
<span className="v" id="v32" data-v="32" data-xref="歌羅西書 3:17; 出埃及記 20:24–25; 士師記 21:4"> 用這些石頭為耶和華的名築一座壇，在壇的四圍挖溝，可容穀種二細亞，</span>
<span className="v" id="v33" data-v="33" data-xref="創世記 22:9; 士師記 6:20; 利未記 1:6–8"> 又在壇上擺好了柴，把牛犢切成塊子放在柴上，對眾人說：「你們用四個桶盛滿水，倒在燔祭和柴上」；</span>
<span className="v" id="v34" data-v="34" data-xref="哥林多後書 8:21; 哥林多後書 4:2"> 又說：「倒第二次。」他們就倒第二次；又說：「倒第三次。」他們就倒第三次。</span>
<span className="v" id="v35" data-v="35" data-xref="列王紀上 18:32; 列王紀上 18:38"> 水流在壇的四圍，溝裏也滿了水。</span>
<span className="v" id="v36" data-v="36" data-xref="列王紀上 18:29; 列王紀下 19:19; 出埃及記 3:6"> 到了獻晚祭的時候，先知以利亞近前來，說：「亞伯拉罕、以撒、以色列的上帝，耶和華啊，求你今日使人知道你是以色列的上帝，也知道我是你的僕人，又是奉你的命行這一切事。</span>
<span className="v" id="v37" data-v="37" data-xref="但以理書 9:17–19; 路加福音 1:16–17; 以西結書 36:25–27"> 耶和華啊，求你應允我，應允我！使這民知道你－耶和華是上帝，又知道是你叫這民的心回轉。」</span>
<span className="v" id="v38" data-v="38" data-xref="歷代志上 21:26; 利未記 9:24; 歷代志下 7:1"> 於是，耶和華降下火來，燒盡燔祭、木柴、石頭、塵土，又燒乾溝裏的水。</span>
<span className="v" id="v39" data-v="39" data-xref="列王紀上 18:24; 歷代志下 7:3; 列王紀上 18:21"> 眾民看見了，就俯伏在地，說：「耶和華是上帝！耶和華是上帝！」</span>
<span className="v" id="v40" data-v="40" data-xref="申命記 18:20; 士師記 4:7; 申命記 13:5"> 以利亞對他們說：「拿住巴力的先知，不容一人逃脫！」眾人就拿住他們。以利亞帶他們到基順河邊，在那裏殺了他們。</span>
</div>

## 旱災停止

<div className="bt">
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="列王紀上 18:1; 傳道書 9:7; 列王紀上 17:1"> 以利亞對亞哈說：「你現在可以上去吃喝，因為有多雨的響聲了。」</span>
<span className="v" id="v42" data-v="42" data-xref="路加福音 6:12; 但以理書 9:7; 約書亞記 7:6"> 亞哈就上去吃喝。以利亞上了迦密山頂，屈身在地，將臉伏在兩膝之中；</span>
<span className="v" id="v43" data-v="43" data-xref="哈巴谷書 2:3; 路加福音 18:7; 路加福音 18:1"> 對僕人說：「你上去，向海觀看。」僕人就上去觀看，說：「沒有甚麼。」他說：「你再去觀看。」如此七次。</span>
<span className="v" id="v44" data-v="44" data-xref="路加福音 12:54; 約伯記 8:7; 撒迦利亞書 4:10"> 第七次僕人說：「我看見有一小片雲從海裏上來，不過如人手那樣大。」以利亞說：「你上去告訴亞哈，當套車下去，免得被雨阻擋。」</span>
<span className="v" id="v45" data-v="45" data-xref="列王紀上 18:39–40; 約書亞記 17:16; 列王紀上 21:1"> 霎時間，天因風雲黑暗，降下大雨。亞哈就坐車往耶斯列去了。</span>
<span className="v" id="v46" data-v="46" data-xref="以西結書 3:14; 以西結書 1:3; 列王紀下 9:1"> 耶和華的靈<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是手">a</a></sup>降在以利亞身上，他就束上腰，奔在亞哈前頭，直到耶斯列的城門。</span>

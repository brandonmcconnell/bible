## 猶大王亞比央

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀上 14:31; 歷代志下 13:1–22"> 尼八的兒子耶羅波安王十八年，亞比央登基作猶大王，</span>
<span className="v" id="v2" data-v="2" data-xref="歷代志下 13:2; 歷代志下 11:20–22; 列王紀上 15:13"> 在耶路撒冷作王三年。他母親名叫瑪迦，是押沙龍的女兒。</span>
<span className="v" id="v3" data-v="3" data-xref="列王紀上 11:4; 詩篇 119:80; 列王紀上 3:14"> 亞比央行他父親在他以前所行的一切惡，他的心不像他祖大衛的心，誠誠實實地順服耶和華－他的上帝。</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀上 11:36; 歷代志下 21:7; 以賽亞書 37:35"> 然而耶和華－他的上帝因大衛的緣故，仍使他在耶路撒冷有燈光，叫他兒子接續他作王，堅立耶路撒冷。</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀上 14:8; 撒母耳記下 11:15–17; 列王紀上 15:3"> 因為大衛除了赫人烏利亞那件事，都是行耶和華眼中看為正的事，一生沒有違背耶和華一切所吩咐的。</span>
<span className="v" id="v6" data-v="6" data-xref="列王紀上 14:30"> 羅波安在世的日子常與耶羅波安爭戰。</span>
<span className="v" id="v7" data-v="7" data-xref="歷代志下 13:2–22; 列王紀上 14:29"> 亞比央其餘的事，凡他所行的，都寫在猶大列王記上。亞比央常與耶羅波安爭戰。</span>
<span className="v" id="v8" data-v="8" data-xref="歷代志下 14:1; 列王紀上 14:31; 馬太福音 1:7–8"> 亞比央與他列祖同睡，葬在大衛的城裏。他兒子亞撒接續他作王。</span>
</div>
</div>

## 猶大王亞撒

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9"> 以色列王耶羅波安二十年，亞撒登基作猶大王，</span>
<span className="v" id="v10" data-v="10" data-xref="列王紀上 15:2; 列王紀上 15:13; 歷代志下 13:2"> 在耶路撒冷作王四十一年。他祖母名叫瑪迦，是押沙龍的女兒。</span>
<span className="v" id="v11" data-v="11" data-xref="歷代志下 14:2; 歷代志下 15:17; 列王紀上 15:3"> 亞撒效法他祖大衛行耶和華眼中看為正的事，</span>
<span className="v" id="v12" data-v="12" data-xref="列王紀上 22:46; 列王紀上 14:23–24; 歷代志下 14:2–5"> 從國中除去孌童，又除掉他列祖所造的一切偶像；</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及記 32:20; 申命記 7:5; 撒迦利亞書 13:3"> 並且貶了他祖母瑪迦太后的位，因她造了可憎的偶像亞舍拉。亞撒砍下她的偶像，燒在汲淪溪邊，</span>
<span className="v" id="v14" data-v="14" data-xref="列王紀上 22:43; 列王紀上 8:61; 列王紀上 15:3"> 只是邱壇還沒有廢去。亞撒一生卻向耶和華存誠實的心。</span>
<span className="v" id="v15" data-v="15" data-xref="列王紀上 7:51; 歷代志下 14:13; 歷代志下 15:18"> 亞撒將他父親所分別為聖與自己所分別為聖的金銀和器皿都奉到耶和華的殿裏。</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀上 15:32; 列王紀上 14:30; 歷代志下 16:1–6"> 亞撒和以色列王巴沙在世的日子常常爭戰。</span>
<span className="v" id="v17" data-v="17" data-xref="列王紀上 12:27; 歷代志下 16:1–6; 約書亞記 18:25"> 以色列王巴沙上來要攻擊猶大，修築拉瑪，不許人從猶大王亞撒那裏出入。</span>
<span className="v" id="v18" data-v="18" data-xref="列王紀上 14:26; 列王紀下 12:18; 列王紀上 11:23–24"> 於是亞撒將耶和華殿和王宮府庫裏所剩下的金銀都交在他臣僕手中，打發他們往住大馬士革的亞蘭王－希旬的孫子、他伯利們的兒子便‧哈達那裏去，</span>
<span className="v" id="v19" data-v="19" data-xref="羅馬書 1:31; 歷代志下 16:7; 羅馬書 3:8"> 說：「你父曾與我父立約，我與你也要立約。現在我將金銀送你為禮物，求你廢掉你與以色列王巴沙所立的約，使他離開我。」</span>
<span className="v" id="v20" data-v="20" data-xref="列王紀下 15:29; 士師記 18:29; 約書亞記 11:2"> 便‧哈達聽從亞撒王的話，派軍長去攻擊以色列的城邑；他們就攻破以雲、但、亞伯‧伯‧瑪迦、基尼烈全境、拿弗他利全境。</span>
<span className="v" id="v21" data-v="21" data-xref="列王紀上 14:17; 列王紀上 16:15–18; 歷代志下 16:5"> 巴沙聽見，就停工不修築拉瑪了，仍住在得撒。</span>
<span className="v" id="v22" data-v="22" data-xref="約書亞記 21:17; 約書亞記 18:24; 約書亞記 18:26"> 於是亞撒王宣告猶大眾人，不准一個推辭，吩咐他們將巴沙修築拉瑪所用的石頭、木頭都運去，用以修築便雅憫的迦巴和米斯巴。</span>
<span className="v" id="v23" data-v="23" data-xref="歷代志下 16:11–14; 列王紀上 14:29–31; 列王紀上 15:7–8"> 亞撒其餘的事，凡他所行的，並他的勇力與他所建築的城邑，都寫在猶大列王記上。亞撒年老的時候，腳上有病。</span>
<span className="v" id="v24" data-v="24" data-xref="馬太福音 1:8; 列王紀上 22:41–43; 歷代志下 17:1–9"> 亞撒與他列祖同睡，葬在他祖大衛城他列祖的墳地裏。他兒子約沙法接續他作王。</span>
</div>
</div>

## 以色列王拿答

<div className="bt">
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="列王紀上 14:20; 列王紀上 14:12"> 猶大王亞撒第二年，耶羅波安的兒子拿答登基作以色列王共二年，</span>
<span className="v" id="v26" data-v="26" data-xref="列王紀上 14:16; 列王紀上 15:34; 列王紀上 15:30"> 拿答行耶和華眼中看為惡的事，行他父親所行的，犯他父親使以色列人陷在罪裏的那罪。</span>
<span className="v" id="v27" data-v="27" data-xref="約書亞記 19:44; 約書亞記 21:23; 列王紀上 14:14"> 以薩迦人亞希雅的兒子巴沙背叛拿答，在非利士的基比頓殺了他。那時拿答和以色列眾人正圍困基比頓。</span>
<span className="v" id="v28" data-v="28" data-xref="申命記 32:35"> 在猶大王亞撒第三年巴沙殺了他，篡了他的位。</span>
<span className="v" id="v29" data-v="29" data-xref="列王紀上 14:9–16; 列王紀下 19:25; 列王紀下 10:10–11"> 巴沙一作王就殺了耶羅波安的全家，凡有氣息的沒有留下一個，都滅盡了，正應驗耶和華藉他僕人示羅人亞希雅所說的話。</span>
<span className="v" id="v30" data-v="30" data-xref="列王紀上 15:26; 列王紀上 14:22; 列王紀上 14:9–16"> 這是因為耶羅波安所犯的罪使以色列人陷在罪裏，惹動耶和華－以色列上帝的怒氣。</span>
<span className="v" id="v31" data-v="31" data-xref="列王紀上 14:19; 列王紀上 16:20; 列王紀上 16:14"> 拿答其餘的事，凡他所行的，都寫在以色列諸王記上。</span>
<span className="v" id="v32" data-v="32" data-xref="列王紀上 15:16"> 亞撒和以色列王巴沙在世的日子常常爭戰。</span>
</div>
</div>

## 以色列王巴沙

<div className="bt">
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="列王紀上 16:8"> 猶大王亞撒第三年，亞希雅的兒子巴沙在得撒登基作以色列眾人的王共二十四年。</span>
<span className="v" id="v34" data-v="34" data-xref="列王紀上 15:26; 列王紀上 14:16; 列王紀上 12:28–29"> 他行耶和華眼中看為惡的事，行耶羅波安所行的道，犯他使以色列人陷在罪裏的那罪。</span>
</div>
</div>

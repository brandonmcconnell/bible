<span className="v" id="v1" data-v="1" data-xref="列王紀上 12:32–33; 列王紀下 23:17; 帖撒羅尼迦前書 4:15"> 那時，有一個神人奉耶和華的命從猶大來到伯特利。耶羅波安正站在壇旁要燒香；</span>
<span className="v" id="v2" data-v="2" data-xref="以西結書 36:1; 列王紀下 23:15–18; 列王紀下 22:1–2"> 神人奉耶和華的命向壇呼叫，說：「壇哪，壇哪！耶和華如此說：大衛家裏必生一個兒子，名叫約西亞，他必將邱壇的祭司，就是在你上面燒香的，殺在你上面，人的骨頭也必燒在你上面。」</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多前書 1:22; 出埃及記 4:3–5; 士師記 6:17"> 當日，神人設個預兆，說：「這壇必破裂，壇上的灰必傾撒，這是耶和華說的預兆。」</span>
<span className="v" id="v4" data-v="4" data-xref="啟示錄 11:5; 歷代志下 18:25–27; 路加福音 6:10"> 耶羅波安王聽見神人向伯特利的壇所呼叫的話，就從壇上伸手，說：「拿住他吧！」王向神人所伸的手就枯乾了，不能彎回；</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀上 13:3; 耶利米書 28:16–17; 申命記 18:22"> 壇也破裂了，壇上的灰傾撒了，正如神人奉耶和華的命所設的預兆。</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及記 9:28; 使徒行傳 8:24; 出埃及記 10:17"> 王對神人說：「請你為我禱告，求耶和華－你上帝的恩典使我的手復原。」於是神人祈禱耶和華，王的手就復了原，仍如尋常一樣。</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀下 5:15; 撒母耳記上 9:7–8; 士師記 13:15"> 王對神人說：「請你同我回去吃飯，加添心力，我也必給你賞賜。」</span>
<span className="v" id="v8" data-v="8" data-xref="民數記 24:13; 民數記 22:18; 馬可福音 6:23"> 神人對王說：「你就是把你的宮一半給我，我也不同你進去，也不在這地方吃飯喝水；</span>
<span className="v" id="v9" data-v="9" data-xref="約翰福音 13:17; 申命記 13:13–18; 羅馬書 16:17"> 因為有耶和華的話囑咐我，說不可在伯特利吃飯喝水，也不可從你去的原路回來。」</span>
<span className="v" id="v10" data-v="10"> 於是神人從別的路回去，不從伯特利來的原路回去。</span>
</div>

## 伯特利的老先知

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="列王紀下 23:18; 列王紀上 13:20–21; 民數記 24:2"> 有一個老先知住在伯特利，他兒子們來，將神人當日在伯特利所行的一切事和向王所說的話都告訴了父親。</span>
<span className="v" id="v12" data-v="12"> 父親問他們說：「神人從哪條路去了呢？」兒子們就告訴他；原來他們看見那從猶大來的神人所去的路。</span>
<span className="v" id="v13" data-v="13" data-xref="士師記 10:4; 撒母耳記下 19:26; 士師記 5:10"> 老先知就吩咐他兒子們說：「你們為我備驢。」他們備好了驢，他就騎上，</span>
<span className="v" id="v14" data-v="14" data-xref="腓立比書 4:12–13; 哥林多後書 11:27; 哥林多前書 4:11–12"> 去追趕神人，遇見他坐在橡樹底下，就問他說：「你是從猶大來的神人不是？」他說：「是。」</span>
<span className="v" id="v15" data-v="15"> 老先知對他說：「請你同我回家吃飯。」</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀上 13:8–9; 馬太福音 16:23; 民數記 22:19"> 神人說：「我不可同你回去進你的家，也不可在這裏同你吃飯喝水；</span>
<span className="v" id="v17" data-v="17" data-xref="列王紀上 20:35; 帖撒羅尼迦前書 4:15; 列王紀上 13:1"> 因為有耶和華的話囑咐我說：『你在那裏不可吃飯喝水，也不可從你去的原路回來。』」</span>
<span className="v" id="v18" data-v="18" data-xref="約翰一書 4:1; 馬太福音 7:15; 民數記 22:35"> 老先知對他說：「我也是先知，和你一樣。有天使奉耶和華的命對我說：『你去把他帶回你的家，叫他吃飯喝水。』」這都是老先知誆哄他。</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 13:1; 創世記 3:6; 使徒行傳 4:19"> 於是神人同老先知回去，在他家裏吃飯喝水。</span>
<span className="v" id="v20" data-v="20" data-xref="馬太福音 7:22; 民數記 24:4; 民數記 24:16–24"> 二人坐席的時候，耶和華的話臨到那帶神人回來的先知，</span>
<span className="v" id="v21" data-v="21" data-xref="列王紀上 13:17; 撒母耳記上 13:13–14; 撒母耳記上 4:18"> 他就對那從猶大來的神人說：「耶和華如此說：你既違背耶和華的話，不遵守耶和華－你上帝的命令，</span>
<span className="v" id="v22" data-v="22" data-xref="以賽亞書 14:18–20; 列王紀上 14:13; 耶利米書 22:18–19"> 反倒回來，在耶和華禁止你吃飯喝水的地方吃了喝了，因此你的屍身不得入你列祖的墳墓。」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23"> 吃喝完了，老先知為所帶回來的先知備驢。</span>
<span className="v" id="v24" data-v="24" data-xref="列王紀上 20:36; 列王紀下 2:24; 箴言 26:13"> 他就去了，在路上有個獅子遇見他，將他咬死，屍身倒在路上，驢站在屍身旁邊，獅子也站在屍身旁邊。</span>
<span className="v" id="v25" data-v="25" data-xref="列王紀上 13:11"> 有人從那裏經過，看見屍身倒在路上，獅子站在屍身旁邊，就來到老先知所住的城裏述說這事。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="以西結書 9:6; 箴言 11:31; 詩篇 119:120"> 那帶神人回來的先知聽見這事，就說：「這是那違背了耶和華命令的神人，所以耶和華把他交給獅子；獅子抓傷他，咬死他，是應驗耶和華對他說的話。」</span>
<span className="v" id="v27" data-v="27"> 老先知就吩咐他兒子們說：「你們為我備驢。」他們就備了驢。</span>
<span className="v" id="v28" data-v="28" data-xref="列王紀上 17:6; 詩篇 148:7–8; 但以理書 6:22–24"> 他去了，看見神人的屍身倒在路上，驢和獅子站在屍身旁邊，獅子卻沒有吃屍身，也沒有抓傷驢。</span>
<span className="v" id="v29" data-v="29"> 老先知就把神人的屍身馱在驢上，帶回自己的城裏，要哀哭他，葬埋他；</span>
<span className="v" id="v30" data-v="30" data-xref="耶利米書 22:18; 使徒行傳 8:2; 列王紀上 14:13"> 就把他的屍身葬在自己的墳墓裏，哀哭他，說：「哀哉！我兄啊。」</span>
<span className="v" id="v31" data-v="31" data-xref="列王紀下 23:17–18; 民數記 23:10; 路加福音 16:22–23"> 安葬之後，老先知對他兒子們說：「我死了，你們要葬我在神人的墳墓裏，使我的屍骨靠近他的屍骨，</span>
<span className="v" id="v32" data-v="32" data-xref="列王紀上 16:24; 列王紀上 13:2; 列王紀上 12:31"> 因為他奉耶和華的命指着伯特利的壇和撒馬利亞各城有邱壇之殿所說的話必定應驗。」</span>
</div>
</div>

## 耶羅波安的嚴重罪行

<div className="bt">
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="歷代志下 11:15; 歷代志下 13:9; 民數記 17:12–13"> 這事以後，耶羅波安仍不離開他的惡道，將凡民立為邱壇的祭司；凡願意的，他都分別為聖，立為邱壇的祭司。</span>
<span className="v" id="v34" data-v="34" data-xref="列王紀上 14:10; 列王紀上 15:29–30; 列王紀上 12:30"> 這事叫耶羅波安的家陷在罪裏，甚至他的家從地上除滅了。</span>
</div>
</div>

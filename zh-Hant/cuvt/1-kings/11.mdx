## 所羅門離棄上帝

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命記 17:17; 箴言 6:24; 尼希米記 13:23–27"> 所羅門王在法老的女兒之外，又寵愛許多外邦女子，就是摩押女子、亞捫女子、以東女子、西頓女子、赫人女子。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 34:16; 申命記 7:3–4; 約書亞記 23:12–13"> 論到這些國的人，耶和華曾曉諭以色列人說：「你們不可與她們往來相通，因為她們必誘惑你們的心去隨從她們的神。」所羅門卻戀愛這些女子。</span>
<span className="v" id="v3" data-v="3" data-xref="傳道書 7:28; 撒母耳記下 5:13–16; 歷代志下 11:21"> 所羅門有妃七百，都是公主；還有嬪三百。這些妃嬪誘惑他的心。</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀上 9:4; 列王紀上 8:61; 列王紀上 11:6"> 所羅門年老的時候，他的妃嬪誘惑他的心去隨從別神，不效法他父親大衛誠誠實實地順服耶和華－他的上帝。</span>
<span className="v" id="v5" data-v="5" data-xref="士師記 2:13; 列王紀上 11:7; 列王紀下 23:13"> 因為所羅門隨從西頓人的女神亞斯她錄和亞捫人可憎的神米勒公。</span>
<span className="v" id="v6" data-v="6" data-xref="民數記 14:24; 約書亞記 14:8; 約書亞記 14:14"> 所羅門行耶和華眼中看為惡的事，不效法他父親大衛專心順從耶和華。</span>
<span className="v" id="v7" data-v="7" data-xref="民數記 21:29; 士師記 11:24; 使徒行傳 7:43"> 所羅門為摩押可憎的神基抹和亞捫人可憎的神摩洛，在耶路撒冷對面的山上建築邱壇。</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多前書 10:11–12; 列王紀上 11:1; 以西結書 16:22–29"> 他為那些向自己的神燒香獻祭的外邦女子，就是他娶來的妃嬪也是這樣行。</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀上 9:2; 列王紀上 3:5; 申命記 7:4"> 耶和華向所羅門發怒，因為他的心偏離向他兩次顯現的耶和華－以色列的上帝。</span>
<span className="v" id="v10" data-v="10" data-xref="列王紀上 6:12–13; 歷代志下 7:17–22; 列王紀上 9:4–7"> 耶和華曾吩咐他不可隨從別神，他卻沒有遵守耶和華所吩咐的。</span>
<span className="v" id="v11" data-v="11" data-xref="列王紀上 12:15–16; 列王紀上 11:31; 列王紀下 17:21"> 所以耶和華對他說：「你既行了這事，不遵守我所吩咐你守的約和律例，我必將你的國奪回，賜給你的臣子。</span>
<span className="v" id="v12" data-v="12" data-xref="列王紀下 20:19; 撒母耳記上 9:4–5; 列王紀下 22:19–20"> 然而，因你父親大衛的緣故，我不在你活着的日子行這事，必從你兒子的手中將國奪回。</span>
<span className="v" id="v13" data-v="13" data-xref="列王紀上 12:20; 申命記 12:11; 列王紀上 11:32"> 只是我不將全國奪回，要因我僕人大衛和我所選擇的耶路撒冷，還留一支派給你的兒子。」</span>
</div>
</div>

## 所羅門的敵人

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="歷代志上 5:26; 詩篇 89:30–34; 以賽亞書 13:17"> 耶和華使以東人哈達興起，作所羅門的敵人；他是以東王的後裔。</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳記下 8:14; 歷代志上 18:12–13; 申命記 20:13"> 先前大衛攻擊以東，元帥約押上去葬埋陣亡的人，將以東的男丁都殺了。</span>
<span className="v" id="v16" data-v="16"> 約押和以色列眾人在以東住了六個月，直到將以東的男丁盡都剪除。</span>
<span className="v" id="v17" data-v="17" data-xref="馬太福音 2:13–14; 出埃及記 2:1–10; 列王紀下 11:2"> 那時哈達還是幼童；他和他父親的臣僕，幾個以東人逃往埃及。</span>
<span className="v" id="v18" data-v="18" data-xref="民數記 10:12; 申命記 33:2; 申命記 1:1"> 他們從米甸起行，到了巴蘭；從巴蘭帶着幾個人來到埃及見埃及王法老；法老為他派定糧食，又給他房屋田地。</span>
<span className="v" id="v19" data-v="19" data-xref="創世記 39:4; 耶利米書 43:7–9; 創世記 39:21"> 哈達在法老面前大蒙恩惠，以致法老將王后答比匿的妹子賜他為妻。</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 21:7; 撒母耳記上 1:24"> 答比匿的妹子給哈達生了一個兒子，名叫基努拔。答比匿使基努拔在法老的宮裏斷奶，基努拔就與法老的眾子一同住在法老的宮裏。</span>
<span className="v" id="v21" data-v="21" data-xref="列王紀上 2:10; 出埃及記 4:19; 馬太福音 2:20"> 哈達在埃及聽見大衛與他列祖同睡，元帥約押也死了，就對法老說：「求王容我回本國去。」</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳記下 18:22–23; 路加福音 22:35; 馬可福音 14:31"> 法老對他說：「你在我這裏有甚麼缺乏，你竟要回你本國去呢？」他回答說：「我沒有缺乏甚麼，只是求王容我回去。」</span>
<span className="v" id="v23" data-v="23" data-xref="列王紀上 11:14; 撒母耳記下 8:3; 撒母耳記下 10:15–18"> 上帝又使以利亞大的兒子利遜興起，作所羅門的敵人。他先前逃避主人瑣巴王哈大底謝。</span>
<span className="v" id="v24" data-v="24" data-xref="撒母耳記下 10:8; 撒母耳記下 10:18; 列王紀上 20:34"> 大衛擊殺 瑣巴人的時候，利遜招聚了一群人，自己作他們的頭目，往大馬士革居住，在那裏作王。</span>
<span className="v" id="v25" data-v="25" data-xref="歷代志下 15:2; 詩篇 106:40; 列王紀上 5:4"> 所羅門活着的時候，哈達為患之外，利遜也作以色列的敵人。他恨惡以色列人，且作了亞蘭人的王。</span>
</div>
</div>

## 上帝給耶羅波安的應許

<div className="bt">
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="歷代志下 13:6; 列王紀上 12:2; 列王紀上 11:28"> 所羅門的臣僕、尼八的兒子耶羅波安也舉手攻擊王。他是以法蓮支派的洗利達人，他母親是寡婦，名叫洗魯阿。</span>
<span className="v" id="v27" data-v="27" data-xref="列王紀上 9:24; 列王紀上 9:15; 箴言 30:32"> 他舉手攻擊王的緣故，乃由先前所羅門建造米羅，修補他父親大衛城的破口。</span>
<span className="v" id="v28" data-v="28" data-xref="箴言 22:29; 撒母耳記下 19:20; 士師記 1:22–23"> 耶羅波安是大有才能的人。所羅門見這少年人殷勤，就派他監管約瑟家的一切工程。</span>
<span className="v" id="v29" data-v="29" data-xref="列王紀上 12:15; 列王紀上 14:2; 歷代志下 9:29"> 一日，耶羅波安出了耶路撒冷，示羅人先知亞希雅在路上遇見他；亞希雅身上穿着一件新衣。他們二人在田野，以外並無別人。</span>
<span className="v" id="v30" data-v="30" data-xref="撒母耳記上 15:27–28; 撒母耳記上 24:4–5"> 亞希雅將自己穿的那件新衣撕成十二片，</span>
<span className="v" id="v31" data-v="31" data-xref="列王紀上 11:11–12"> 對耶羅波安說：「你可以拿十片。耶和華－以色列的上帝如此說：『我必將國從所羅門手裏奪回，將十個支派賜給你。（</span>
<span className="v" id="v32" data-v="32" data-xref="列王紀上 11:13; 列王紀上 12:20–21; 列王紀上 14:21"> 我因僕人大衛和我在以色列眾支派中所選擇的耶路撒冷城的緣故，仍給所羅門留一個支派。）</span>
<span className="v" id="v33" data-v="33" data-xref="列王紀上 11:9; 列王紀上 11:5–7; 列王紀上 9:5–7"> 因為他離棄我，敬拜西頓人的女神亞斯她錄、摩押的神基抹，和亞捫人的神米勒公，沒有遵從我的道，行我眼中看為正的事，守我的律例典章，像他父親大衛一樣。</span>
<span className="v" id="v34" data-v="34" data-xref="列王紀上 11:12–13; 列王紀上 11:31; 約伯記 11:6"> 但我不從他手裏將全國奪回；使他終身為君，是因我所揀選的僕人大衛謹守我的誡命律例。</span>
<span className="v" id="v35" data-v="35" data-xref="列王紀上 12:20; 列王紀上 11:12; 出埃及記 20:5–6"> 我必從他兒子的手裏將國奪回，以十個支派賜給你，</span>
<span className="v" id="v36" data-v="36" data-xref="列王紀下 8:19; 列王紀上 11:13; 列王紀上 15:4"> 還留一個支派給他的兒子，使我僕人大衛在我所選擇立我名的耶路撒冷城裏，在我面前長有燈光。</span>
<span className="v" id="v37" data-v="37" data-xref="申命記 14:26; 列王紀上 11:26; 撒母耳記下 3:21"> 我必揀選你，使你照心裏一切所願的，作王治理以色列。</span>
<span className="v" id="v38" data-v="38" data-xref="撒母耳記下 7:11; 約書亞記 1:5; 申命記 31:8"> 你若聽從我一切所吩咐你的，遵行我的道，行我眼中看為正的事，謹守我的律例誡命，像我僕人大衛所行的，我就與你同在，為你立堅固的家，像我為大衛所立的一樣，將以色列人賜給你。</span>
<span className="v" id="v39" data-v="39" data-xref="路加福音 1:32–33; 路加福音 2:11; 以賽亞書 11:1–10"> 我必因所羅門所行的使大衛後裔受患難，但不至於永遠。』」</span>
<span className="v" id="v40" data-v="40" data-xref="歷代志下 12:2–9; 以賽亞書 14:24–27; 耶利米哀歌 3:37"> 所羅門因此想要殺耶羅波安。耶羅波安卻起身逃往埃及；到了埃及王示撒那裏，就住在埃及，直到所羅門死了。</span>
</div>
</div>

## 所羅門去世

<div className="bt">
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="歷代志下 9:29–31"> 所羅門其餘的事，凡他所行的和他的智慧都寫在所羅門記上。</span>
<span className="v" id="v42" data-v="42" data-xref="列王紀上 2:11"> 所羅門在耶路撒冷作以色列眾人的王共四十年。</span>
<span className="v" id="v43" data-v="43" data-xref="列王紀下 21:18; 列王紀上 2:10; 馬太福音 1:7"> 所羅門與他列祖同睡，葬在他父親大衛的城裏。他兒子羅波安接續他作王。</span>
</div>

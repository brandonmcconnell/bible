## 先知米該雅警告亞哈

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀上 20:34"> 亞蘭國和以色列國三年沒有爭戰。</span>
<span className="v" id="v2" data-v="2" data-xref="列王紀上 15:24; 列王紀上 22:1; 列王紀上 22:41"> 到第三年，猶大王約沙法下去見以色列王。</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 4:43; 列王紀上 4:13; 約書亞記 21:38"> 以色列王對臣僕說：「你們不知道基列的拉末是屬我們的嗎？我們豈可靜坐不動，不從亞蘭王手裏奪回來嗎？」</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀下 3:7; 以弗所書 5:11; 約翰二書 1:11"> 亞哈問約沙法說：「你肯同我去攻取基列的拉末嗎？」約沙法對以色列王說：「你我不分彼此，我的民與你的民一樣，我的馬與你的馬一樣。」</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="箴言 3:5–6; 歷代志下 18:4–5; 耶利米書 42:2–6"> 約沙法對以色列王說：「請你先求問耶和華。」</span>
<span className="v" id="v6" data-v="6" data-xref="列王紀上 18:19; 耶利米書 23:14–17; 以西結書 13:7–16"> 於是以色列王招聚先知，約有四百人，問他們說：「我上去攻取基列的拉末可以不可以？」他們說：「可以上去，因為主必將那城交在王的手裏。」</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀下 3:11–13; 歷代志下 18:6–7"> 約沙法說：「這裏不是還有耶和華的先知，我們可以求問他嗎？」</span>
<span className="v" id="v8" data-v="8" data-xref="阿摩司書 5:10; 約翰福音 3:19–21; 約翰福音 7:7"> 以色列王對約沙法說：「還有一個人，是音拉的兒子米該雅，我們可以託他求問耶和華。只是我恨他；因為他指着我所說的預言，不說吉語，單說凶言。」約沙法說：「王不必這樣說。」</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀下 9:32; 以賽亞書 39:7; 列王紀上 22:26–27"> 以色列王就召了一個太監來，說：「你快去，將音拉的兒子米該雅召來。」</span>
<span className="v" id="v10" data-v="10" data-xref="以斯帖記 5:1; 以斯帖記 6:8–9; 列王紀上 18:29"> 以色列王和猶大王約沙法在撒馬利亞城門前的空場上，各穿朝服，坐在位上，所有的先知都在他們面前說預言。</span>
<span className="v" id="v11" data-v="11" data-xref="撒迦利亞書 1:18–21; 申命記 33:17; 以西結書 22:27–28"> 基拿拿的兒子西底家造了兩個鐵角，說：「耶和華如此說：『你要用這角牴觸亞蘭人，直到將他們滅盡。』」</span>
<span className="v" id="v12" data-v="12" data-xref="歷代志下 35:22; 列王紀上 22:6–15; 列王紀上 22:32–36"> 所有的先知也都這樣預言說：「可以上基列的拉末去，必然得勝，因為耶和華必將那城交在王的手中。」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="彌迦書 2:6–7; 詩篇 11:1; 以賽亞書 30:10–11"> 那去召米該雅的使者對米該雅說：「眾先知一口同音地都向王說吉言，你不如與他們說一樣的話，也說吉言。」</span>
<span className="v" id="v14" data-v="14" data-xref="民數記 24:13; 民數記 22:18; 歷代志下 18:12–13"> 米該雅說：「我指着永生的耶和華起誓，耶和華對我說甚麼，我就說甚麼。」</span>
<span className="v" id="v15" data-v="15" data-xref="列王紀上 18:27; 士師記 10:14; 馬太福音 26:45"> 米該雅到王面前，王問他說：「米該雅啊，我們上去攻取基列的拉末可以不可以？」他回答說：「可以上去，必然得勝，耶和華必將那城交在王的手中。」</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行傳 19:13; 馬太福音 26:63; 約書亞記 6:26"> 王對他說：「我當囑咐你幾次，你才奉耶和華的名向我說實話呢？」</span>
<span className="v" id="v17" data-v="17" data-xref="民數記 27:17; 馬太福音 9:36; 列王紀上 22:34–36"> 米該雅說：「我看見以色列眾民散在山上，如同沒有牧人的羊群一般。耶和華說：『這民沒有主人，他們可以平平安安地各歸各家去。』」</span>
<span className="v" id="v18" data-v="18" data-xref="列王紀上 22:8; 箴言 10:24; 路加福音 11:45"> 以色列王對約沙法說：「我豈沒有告訴你，這人指着我所說的預言，不說吉語單說凶言嗎？」</span>
<span className="v" id="v19" data-v="19" data-xref="約伯記 2:1; 約伯記 1:6; 但以理書 7:9–10"> 米該雅說：「你要聽耶和華的話！我看見耶和華坐在寶座上，天上的萬軍侍立在他左右。</span>
<span className="v" id="v20" data-v="20" data-xref="以西結書 14:9; 約伯記 12:16; 耶利米書 4:10"> 耶和華說：『誰去引誘亞哈上基列的拉末去陣亡呢？』這個就這樣說，那個就那樣說。</span>
<span className="v" id="v21" data-v="21" data-xref="約伯記 2:1; 列王紀上 22:23; 約伯記 1:6–7"> 隨後有一個神靈出來，站在耶和華面前，說：『我去引誘他。』</span>
<span className="v" id="v22" data-v="22" data-xref="士師記 9:23; 撒母耳記上 19:9; 撒母耳記上 16:14"> 耶和華問他說：『你用何法呢？』他說：『我去，要在他眾先知口中作謊言的靈。』耶和華說：『這樣，你必能引誘他，你去如此行吧！』</span>
<span className="v" id="v23" data-v="23" data-xref="以西結書 14:9; 馬太福音 24:24–25; 以賽亞書 44:20"> 現在耶和華使謊言的靈入了你這些先知的口，並且耶和華已經命定降禍與你。」</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="使徒行傳 23:2; 耶利米哀歌 3:30; 彌迦書 5:1"> 基拿拿的兒子西底家前來，打米該雅的臉，說：「耶和華的靈從哪裏離開我與你說話呢？」</span>
<span className="v" id="v25" data-v="25" data-xref="列王紀上 20:30; 彼得後書 2:1; 啟示錄 19:20"> 米該雅說：「你進嚴密的屋子藏躲的那日，就必看見了。」</span>
<span className="v" id="v26" data-v="26"> 以色列王說：「將米該雅帶回，交給邑宰亞們和王的兒子約阿施，說</span>
<span className="v" id="v27" data-v="27" data-xref="歷代志下 16:10; 歷代志下 18:25–27; 啟示錄 2:10"> 王如此說，把這個人下在監裏，使他受苦，吃不飽喝不足，等候我平平安安地回來。」</span>
<span className="v" id="v28" data-v="28" data-xref="民數記 16:29; 彌迦書 1:2; 使徒行傳 13:10–11"> 米該雅說：「你若能平平安安地回來，那就是耶和華沒有藉我說這話了」；又說：「眾民哪，你們都要聽！」</span>
</div>
</div>

## 亞哈陣亡

<div className="bt">
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="歷代志下 18:28; 列王紀上 22:2–9"> 以色列王和猶大王約沙法上基列的拉末去了。</span>
<span className="v" id="v30" data-v="30" data-xref="歷代志下 35:22; 耶利米書 23:24; 撒母耳記上 28:8"> 以色列王對約沙法說：「我要改裝上陣，你可以仍穿王服。」以色列王就改裝上陣。</span>
<span className="v" id="v31" data-v="31" data-xref="列王紀上 20:24; 歷代志下 18:30; 耶利米書 16:6"> 先是亞蘭王吩咐他的三十二個車兵長說：「他們的兵將，無論大小，你們都不可與他們爭戰，只要與以色列王爭戰。」</span>
<span className="v" id="v32" data-v="32" data-xref="箴言 13:20; 約拿書 2:1–2; 詩篇 130:1–4"> 車兵長看見約沙法，便說：「這必是以色列王！」就轉過去與他爭戰，約沙法便呼喊。</span>
<span className="v" id="v33" data-v="33" data-xref="詩篇 76:10; 列王紀上 22:31"> 車兵長見不是以色列王，就轉去不追他了。</span>
<span className="v" id="v34" data-v="34" data-xref="歷代志下 35:23; 彌迦書 6:13; 撒母耳記上 17:49"> 有一人隨便開弓，恰巧射入以色列王的甲縫裏。王對趕車的說：「我受了重傷，你轉過車來，拉我出陣吧！」</span>
<span className="v" id="v35" data-v="35" data-xref="列王紀上 22:28; 列王紀上 20:42"> 那日，陣勢越戰越猛，有人扶王站在車上，抵擋亞蘭人。到晚上，王就死了，血從傷處流在車中。</span>
<span className="v" id="v36" data-v="36" data-xref="列王紀下 14:12; 列王紀上 22:31; 士師記 21:24"> 約在日落的時候，有號令傳遍軍中，說：「各歸本城，各歸本地吧！」</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37"> 王既死了，眾人將他送到撒馬利亞，就葬在那裏；</span>
<span className="v" id="v38" data-v="38" data-xref="列王紀上 21:19; 馬太福音 24:35; 耶利米書 44:21–23"> 又有人把他的車洗在撒馬利亞的池旁（妓女在那裏洗澡），狗來舔他的血，正如耶和華所說的話。</span>
<span className="v" id="v39" data-v="39" data-xref="阿摩司書 3:15; 以西結書 27:6; 詩篇 45:8"> 亞哈其餘的事，凡他所行的和他所修造的象牙宮，並所建築的一切城邑，都寫在以色列諸王記上。</span>
<span className="v" id="v40" data-v="40" data-xref="撒母耳記下 7:12; 列王紀下 1:17; 列王紀下 1:2"> 亞哈與他列祖同睡。他兒子亞哈謝接續他作王。</span>
</div>
</div>

## 猶大王約沙法

<div className="bt">
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="歷代志下 20:31; 列王紀上 22:2; 歷代志下 17:1"> 以色列王亞哈第四年，亞撒的兒子約沙法登基作了猶大王。</span>
<span className="v" id="v42" data-v="42" data-xref="列王紀下 1:17; 列王紀上 15:2; 列王紀上 15:10"> 約沙法登基的時候年三十五歲，在耶路撒冷作王二十五年。他母親名叫阿蘇巴，乃示利希的女兒。</span>
<span className="v" id="v43" data-v="43" data-xref="列王紀上 15:14; 列王紀下 12:3; 箴言 4:27"> 約沙法行他父親亞撒所行的道，不偏離左右，行耶和華眼中看為正的事；只是邱壇還沒有廢去，百姓仍在那裏獻祭燒香。</span>
<span className="v" id="v44" data-v="44" data-xref="列王紀上 22:2; 歷代志下 19:2; 列王紀下 8:18"> 約沙法與以色列王和好。</span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="列王紀上 14:29; 列王紀上 11:41; 歷代志下 20:34"> 約沙法其餘的事和他所顯出的勇力，並他怎樣爭戰，都寫在猶大列王記上。</span>
<span className="v" id="v46" data-v="46" data-xref="列王紀上 15:12; 列王紀上 14:24; 申命記 23:17"> 約沙法將他父親亞撒在世所剩下的孌童都從國中除去了。</span>
</div>
<div className="bp">
<span className="v" id="v47" data-v="47" data-xref="撒母耳記下 8:14; 列王紀下 3:9; 列王紀下 8:20"> 那時以東沒有王，有總督治理。</span>
<span className="v" id="v48" data-v="48" data-xref="列王紀上 9:26; 列王紀上 10:22; 列王紀上 9:28"> 約沙法製造他施船隻，要往俄斐去，將金子運來；只是沒有去，因為船在以旬‧迦別破壞了。</span>
<span className="v" id="v49" data-v="49"> 亞哈的兒子亞哈謝對約沙法說：「容我的僕人和你的僕人坐船同去吧！」約沙法卻不肯。</span>
<span className="v" id="v50" data-v="50" data-xref="歷代志下 21:1; 列王紀上 22:40; 列王紀上 15:24"> 約沙法與列祖同睡。葬在大衛城他列祖的墳地裏。他兒子約蘭接續他作王。</span>
</div>
</div>

## 以色列王亞哈謝

<div className="bt">
<div className="bp">
<span className="v" id="v51" data-v="51" data-xref="列王紀下 1:17; 列王紀上 22:40; 列王紀上 15:25"> 猶大王約沙法十七年，亞哈的兒子亞哈謝在撒馬利亞登基，作以色列王共二年。</span>
<span className="v" id="v52" data-v="52" data-xref="列王紀上 15:26; 列王紀上 21:25; 啟示錄 3:20"> 他行耶和華眼中看為惡的事，效法他的父母，又行尼八的兒子耶羅波安使以色列人陷在罪裏的事。</span>
<span className="v" id="v53" data-v="53" data-xref="列王紀上 16:30–32; 以賽亞書 65:3; 列王紀下 3:2"> 他照他父親一切所行的，事奉敬拜巴力，惹耶和華－以色列上帝的怒氣。</span>
</div>
</div>

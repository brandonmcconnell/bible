## 示巴女王拜訪所羅門

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="馬太福音 12:42; 路加福音 11:31; 歷代志下 9:1–12"> 示巴女王聽見所羅門因耶和華之名所得的名聲，就來要用難解的話試問所羅門。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行傳 25:23; 詩篇 4:4; 約伯記 4:2"> 跟隨她到耶路撒冷的人甚多，又有駱駝馱着香料、寶石，和許多金子。她來見了所羅門王，就把心裏所有的對所羅門都說出來。</span>
<span className="v" id="v3" data-v="3" data-xref="箴言 1:5–6; 馬太福音 13:11; 列王紀上 10:1"> 所羅門王將她所問的都答上了，沒有一句不明白、不能答的。</span>
<span className="v" id="v4" data-v="4" data-xref="馬太福音 12:42; 列王紀上 3:28; 歷代志下 9:3–4"> 示巴女王見所羅門大有智慧，和他所建造的宮室，</span>
<span className="v" id="v5" data-v="5" data-xref="歷代志上 26:16; 列王紀上 4:22–23; 列王紀下 16:18"> 席上的珍饈美味，群臣分列而坐，僕人兩旁侍立，以及他們的衣服裝飾和酒政的衣服裝飾，又見他上耶和華殿的臺階<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或譯：他在耶和華殿裏所獻的燔祭">a</a></sup>，就詫異得神不守舍；</span>
<span className="v" id="v6" data-v="6" data-xref="歷代志下 9:5–6"> 對王說：「我在本國裏所聽見論到你的事和你的智慧實在是真的！</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多前書 2:9; 約翰福音 20:25–29; 約翰一書 3:2"> 我先不信那些話，及至我來親眼見了才知道人所告訴我的還不到一半。你的智慧和你的福分越過我所聽見的風聲。</span>
<span className="v" id="v8" data-v="8" data-xref="箴言 8:34; 箴言 10:21; 路加福音 11:31"> 你的臣子、你的僕人常侍立在你面前聽你智慧的話是有福的！</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 72:2; 列王紀上 5:7; 撒母耳記下 8:15"> 耶和華－你的上帝是應當稱頌的！他喜悅你，使你坐以色列的國位；因為他永遠愛以色列，所以立你作王，使你秉公行義。」</span>
<span className="v" id="v10" data-v="10" data-xref="列王紀上 10:2; 馬太福音 2:11; 列王紀上 9:14"> 於是，示巴女王將一百二十他連得金子和寶石，與極多的香料，送給所羅門王。她送給王的香料，以後奉來的不再有這樣多。<br />（</span>
<span className="v" id="v11" data-v="11" data-xref="列王紀上 9:27–28; 歷代志下 8:18; 詩篇 45:9"> 希蘭的船隻從俄斐運了金子來，又從俄斐運了許多檀香木<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或譯：烏木；下同">b</a></sup>和寶石來。</span>
<span className="v" id="v12" data-v="12" data-xref="歷代志上 25:1–31; 詩篇 150:3–5; 啟示錄 14:2–3"> 王用檀香木為耶和華殿和王宮做欄杆，又為歌唱的人做琴瑟。以後再沒有這樣的檀香木進國來，也沒有人看見過，直到如今。）</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="詩篇 37:4; 馬太福音 15:28; 詩篇 20:4"> 示巴女王一切所要所求的，所羅門王都送給她，另外照自己的厚意餽送她。於是女王和她臣僕轉回本國去了。</span>
</div>
</div>

## 所羅門的財富

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="歷代志下 9:13–28; 列王紀上 9:28"> 所羅門每年所得的金子共有六百六十六他連得。</span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 72:10; 歷代志上 9:24; 以賽亞書 21:13"> 另外還有商人和雜族<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="雜族在歷代下九章十四節是阿拉伯">c</a></sup>的諸王，與國中的省長所進的金子。</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀上 14:26–28; 歷代志下 12:9–10; 歷代志下 9:15–16"> 所羅門王用錘出來的金子打成擋牌二百面，每面用金子六百舍客勒；</span>
<span className="v" id="v17" data-v="17" data-xref="列王紀上 7:2; 列王紀上 14:26"> 又用錘出來的金子打成盾牌三百面，每面用金子三彌那，都放在黎巴嫩林宮裏。</span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 45:8; 列王紀上 10:22; 啟示錄 20:11"> 王用象牙製造一個寶座，用精金包裹。</span>
<span className="v" id="v19" data-v="19"> 寶座有六層臺階，座的後背是圓的，兩旁有扶手，靠近扶手有兩個獅子站立。</span>
<span className="v" id="v20" data-v="20" data-xref="民數記 24:9; 創世記 49:9; 民數記 23:24"> 六層臺階上有十二個獅子站立，每層有兩個：左邊一個，右邊一個；在列國中沒有這樣做的。</span>
<span className="v" id="v21" data-v="21" data-xref="列王紀上 10:17; 列王紀上 7:2; 歷代志下 9:20–22"> 所羅門王一切的飲器都是金子的。黎巴嫩林宮裏的一切器皿都是精金的。所羅門年間，銀子算不了甚麼。</span>
<span className="v" id="v22" data-v="22" data-xref="列王紀上 22:48; 創世記 10:4; 歷代志下 20:36–37"> 因為王有他施船隻與希蘭的船隻一同航海，三年一次，裝載金銀、象牙、猿猴、孔雀回來。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="列王紀上 3:12–13; 歌羅西書 2:2–3; 列王紀上 4:29–34"> 所羅門王的財寶與智慧勝過天下的列王。</span>
<span className="v" id="v24" data-v="24" data-xref="列王紀上 3:12; 雅各書 1:5; 列王紀上 3:28"> 普天下的王都求見所羅門，要聽上帝賜給他智慧的話。</span>
<span className="v" id="v25" data-v="25" data-xref="約伯記 42:11; 詩篇 72:10; 詩篇 72:15"> 他們各帶貢物，就是金器、銀器、衣服、軍械、香料、騾馬，每年有一定之例。</span>
</div>
</div>

## 所羅門的車騎

<div className="bt">
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="歷代志下 9:25; 列王紀上 4:26; 申命記 17:16"> 所羅門聚集戰車馬兵，有戰車一千四百輛，馬兵一萬二千名，安置在屯車的城邑和耶路撒冷，就是王那裏。</span>
<span className="v" id="v27" data-v="27" data-xref="歷代志下 1:15–17; 申命記 17:17; 歷代志下 9:27"> 王在耶路撒冷使銀子多如石頭，香柏木多如高原的桑樹。</span>
<span className="v" id="v28" data-v="28" data-xref="申命記 17:16; 歷代志下 9:28; 以賽亞書 31:1–3"> 所羅門的馬是從埃及帶來的，是王的商人一群一群按着定價買來的。</span>
<span className="v" id="v29" data-v="29" data-xref="約書亞記 1:4; 列王紀下 7:6–7; 瑪拉基書 1:1"> 從埃及買來的車，每輛價銀六百舍客勒，馬每匹一百五十舍客勒。赫人諸王和亞蘭諸王所買的車馬，也是按這價值經他們手買來的。</span>
</div>
</div>

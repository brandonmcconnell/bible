## 拿伯的葡萄園

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士師記 6:33; 歷代志下 28:22; 約書亞記 19:18"> 這事以後，又有一事。耶斯列人拿伯在耶斯列有一個葡萄園，靠近撒馬利亞王亞哈的宮。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳記上 8:14; 雅各書 1:14–15; 提摩太前書 6:9"> 亞哈對拿伯說：「你將你的葡萄園給我作菜園，因為是靠近我的宮；我就把更好的葡萄園換給你，或是你要銀子，我就按着價值給你。」</span>
<span className="v" id="v3" data-v="3" data-xref="民數記 36:7; 利未記 25:23; 以西結書 46:18"> 拿伯對亞哈說：「我敬畏耶和華，萬不敢將我先人留下的產業給你。」</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀上 20:43; 雅各書 1:14; 約拿書 4:9"> 亞哈因耶斯列人拿伯說「我不敢將我先人留下的產業給你」，就悶悶不樂地回宮，躺在床上，轉臉向內，也不吃飯。</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀上 16:31; 創世記 3:6; 列王紀上 19:2"> 王后耶洗別來問他說：「你為甚麼心裏這樣憂悶，不吃飯呢？」</span>
<span className="v" id="v6" data-v="6" data-xref="以斯帖記 5:9–14; 雅各書 4:2–7; 提摩太前書 6:9–10"> 他回答說：「因我向耶斯列人拿伯說：『你將你的葡萄園給我，我給你價銀，或是你願意，我就把別的葡萄園換給你』；他卻說：『我不將我的葡萄園給你。』」</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳記上 8:14; 彌迦書 7:3; 撒母耳記下 13:4"> 王后耶洗別對亞哈說：「你現在是治理以色列國不是？只管起來，心裏暢暢快快地吃飯，我必將耶斯列人拿伯的葡萄園給你。」</span>
<span className="v" id="v8" data-v="8" data-xref="尼希米記 6:5; 列王紀下 10:11; 以斯拉記 4:7–8"> 於是託亞哈的名寫信，用王的印印上，送給那些與拿伯同城居住的長老貴冑。</span>
<span className="v" id="v9" data-v="9" data-xref="以賽亞書 58:4; 馬太福音 23:13; 路加福音 20:47"> 信上寫着說：「你們當宣告禁食，叫拿伯坐在民間的高位上，</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及記 22:28; 使徒行傳 6:11; 利未記 24:15–16"> 又叫兩個匪徒坐在拿伯對面，作見證告他說：『你謗瀆上帝和王了』；隨後就把他拉出去用石頭打死。」</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行傳 4:19; 利未記 19:15; 列王紀下 10:6–7"> 那些與拿伯同城居住的長老貴冑得了耶洗別的信，就照信而行，</span>
<span className="v" id="v12" data-v="12" data-xref="以賽亞書 58:4; 列王紀上 21:8–10"> 宣告禁食，叫拿伯坐在民間的高位上。</span>
<span className="v" id="v13" data-v="13" data-xref="列王紀下 9:26; 申命記 22:24; 傳道書 10:20"> 有兩個匪徒來，坐在拿伯的對面，當着眾民作見證告他說：「拿伯謗瀆上帝和王了！」眾人就把他拉到城外，用石頭打死。</span>
<span className="v" id="v14" data-v="14" data-xref="傳道書 8:14; 撒母耳記下 11:14–24; 傳道書 5:8"> 於是打發人去見耶洗別，說：「拿伯被石頭打死了。」</span>
<span className="v" id="v15" data-v="15" data-xref="箴言 1:10–16; 箴言 4:17; 列王紀上 21:7"> 耶洗別聽見拿伯被石頭打死，就對亞哈說：「你起來得耶斯列人拿伯不肯為價銀給你的葡萄園吧！現在他已經死了。」</span>
<span className="v" id="v16" data-v="16" data-xref="俄巴底亞書 1:12–14; 羅馬書 1:32; 撒母耳記下 11:25–27"> 亞哈聽見拿伯死了，就起來，下去要得耶斯列人拿伯的葡萄園。</span>
<span className="v" id="v17" data-v="17" data-xref="詩篇 9:12; 以賽亞書 26:21; 列王紀下 5:26"> 耶和華的話臨到提斯比人以利亞說：</span>
<span className="v" id="v18" data-v="18" data-xref="列王紀上 13:32; 歷代志下 22:9"> 「你起來，去見住撒馬利亞的以色列王亞哈，他下去要得拿伯的葡萄園，現今正在那園裏。</span>
<span className="v" id="v19" data-v="19" data-xref="列王紀上 22:38; 撒母耳記下 12:9; 哈巴谷書 2:9"> 你要對他說：『耶和華如此說：你殺了人，又得他的產業嗎？』又要對他說：『耶和華如此說：狗在何處舔拿伯的血，也必在何處舔你的血。』」</span>
<span className="v" id="v20" data-v="20" data-xref="列王紀下 17:17; 羅馬書 7:14; 列王紀上 21:25"> 亞哈對以利亞說：「我仇敵啊，你找到我嗎？」他回答說：「我找到你了；因為你賣了自己，行耶和華眼中看為惡的事。</span>
<span className="v" id="v21" data-v="21" data-xref="列王紀上 14:10; 撒母耳記上 25:34; 列王紀下 10:1–7"> 耶和華說：『我必使災禍臨到你，將你除盡。凡屬你的男丁，無論困住的、自由的，都從以色列中剪除。</span>
<span className="v" id="v22" data-v="22" data-xref="列王紀上 16:3; 列王紀上 14:16; 列王紀上 16:11"> 我必使你的家像尼八的兒子耶羅波安的家，又像亞希雅的兒子巴沙的家；因為你惹我發怒，又使以色列人陷在罪裏。』</span>
<span className="v" id="v23" data-v="23" data-xref="列王紀下 9:10; 列王紀下 9:30–37; 列王紀上 21:25"> 論到耶洗別，耶和華也說：『狗在耶斯列的外郭必吃耶洗別的肉。</span>
<span className="v" id="v24" data-v="24" data-xref="列王紀上 16:4; 列王紀上 14:11; 耶利米書 15:3"> 凡屬亞哈的人，死在城中的必被狗吃，死在田野的必被空中的鳥吃。』」 （</span>
<span className="v" id="v25" data-v="25" data-xref="箴言 22:14; 列王紀上 21:20; 列王紀上 16:30–33"> 從來沒有像亞哈的，因他自賣，行耶和華眼中看為惡的事，受了王后耶洗別的聳動；</span>
<span className="v" id="v26" data-v="26" data-xref="列王紀下 21:11; 創世記 15:16; 利未記 18:25–30"> 就照耶和華在以色列人面前所趕出的亞摩利人，行了最可憎惡的事，信從偶像。）</span>
<span className="v" id="v27" data-v="27" data-xref="列王紀下 6:30; 創世記 37:34; 撒母耳記下 3:31"> 亞哈聽見這話，就撕裂衣服，禁食，身穿麻布，睡臥也穿着麻布，並且緩緩而行。</span>
<span className="v" id="v28" data-v="28"> 耶和華的話臨到提斯比人以利亞說：</span>
<span className="v" id="v29" data-v="29" data-xref="彼得後書 3:9; 彌迦書 7:18; 詩篇 86:15"> 「亞哈在我面前這樣自卑，你看見了嗎？因他在我面前自卑，他還在世的時候，我不降這禍；到他兒子的時候，我必降這禍與他的家。」</span>

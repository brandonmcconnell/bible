## 以利亞和旱災

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 4:25–26; 雅各書 5:17; 路加福音 1:17"> 基列寄居的提斯比人以利亞對亞哈說：「我指着所事奉永生耶和華－以色列的上帝起誓，這幾年我若不禱告，必不降露，不下雨。」</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米書 18:1; 耶利米書 7:1; 何西阿書 1:1–2"> 耶和華的話臨到以利亞說：</span>
<span className="v" id="v3" data-v="3" data-xref="啟示錄 12:6; 耶利米書 36:26; 詩篇 83:3"> 「你離開這裏往東去，藏在約旦河東邊的基立溪旁。</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀上 17:9; 詩篇 147:9; 約伯記 38:41"> 你要喝那溪裏的水，我已吩咐烏鴉在那裏供養你。」</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀上 19:9; 馬太福音 16:24; 約翰福音 15:14"> 於是以利亞照着耶和華的話，去住在約旦河東的基立溪旁。</span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 78:23–24; 馬太福音 6:31–33; 耶利米書 37:21"> 烏鴉早晚給他叼餅和肉來，他也喝那溪裏的水。</span>
<span className="v" id="v7" data-v="7" data-xref="以賽亞書 54:10; 以賽亞書 40:30–31"> 過了些日子，溪水就乾了，因為雨沒有下在地上。</span>
</div>
</div>

## 以利亞和撒勒法的寡婦

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="創世記 22:14; 列王紀上 17:2; 希伯來書 13:6"> 耶和華的話臨到他說：</span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 4:26; 俄巴底亞書 1:20; 哥林多後書 4:7"> 「你起身往西頓的撒勒法<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="撒勒法與路加福音四章二十六節同">a</a></sup>去，住在那裏；我已吩咐那裏的一個寡婦供養你。」</span>
<span className="v" id="v10" data-v="10" data-xref="約翰福音 4:7; 創世記 24:17; 創世記 21:15"> 以利亞就起身往撒勒法去。到了城門，見有一個寡婦在那裏撿柴，以利亞呼叫她說：「求你用器皿取點水來給我喝。」</span>
<span className="v" id="v11" data-v="11" data-xref="馬太福音 25:35–40; 列王紀上 18:4; 希伯來書 13:2"> 她去取水的時候，以利亞又呼叫她說：「也求你拿點餅來給我！」</span>
<span className="v" id="v12" data-v="12" data-xref="馬太福音 15:33–34; 列王紀上 17:1; 創世記 21:16"> 她說：「我指着永生耶和華－你的上帝起誓，我沒有餅，罈內只有一把麵，瓶裏只有一點油；我現在找兩根柴，回家要為我和我兒子做餅；我們吃了，死就死吧！」</span>
<span className="v" id="v13" data-v="13" data-xref="馬太福音 6:33; 瑪拉基書 3:10; 創世記 22:1–2"> 以利亞對她說：「不要懼怕！可以照你所說的去做吧！只要先為我做一個小餅拿來給我，然後為你和你的兒子做餅。</span>
<span className="v" id="v14" data-v="14" data-xref="馬太福音 15:36–38; 馬太福音 14:17–20; 列王紀下 4:42–44"> 因為耶和華－以色列的上帝如此說：罈內的麵必不減少，瓶裏的油必不缺短，直到耶和華使雨降在地上的日子。」</span>
<span className="v" id="v15" data-v="15" data-xref="希伯來書 11:17; 馬可福音 12:43; 馬太福音 15:28"> 婦人就照以利亞的話去行。她和她家中的人，並以利亞，吃了許多日子。</span>
<span className="v" id="v16" data-v="16" data-xref="馬太福音 9:28–30; 約翰福音 4:50–51; 路加福音 1:37"> 罈內的麵果不減少，瓶裏的油也不缺短，正如耶和華藉以利亞所說的話。</span>
<span className="v" id="v17" data-v="17" data-xref="彼得前書 1:7; 但以理書 5:23; 約翰福音 11:14"> 這事以後，作那家主母的婦人，她兒子病了；病得甚重，以致身無氣息。</span>
<span className="v" id="v18" data-v="18" data-xref="路加福音 5:8; 約翰福音 2:4; 列王紀下 3:13"> 婦人對以利亞說：「神人哪，我與你何干？你竟到我這裏來，使上帝想念我的罪，以致我的兒子死呢？」</span>
<span className="v" id="v19" data-v="19" data-xref="列王紀下 4:32; 列王紀下 4:10; 使徒行傳 9:37"> 以利亞對她說：「把你兒子交給我。」以利亞就從婦人懷中將孩子接過來，抱到他所住的樓中，放在自己的床上，</span>
<span className="v" id="v20" data-v="20" data-xref="雅各書 5:15–18; 馬太福音 21:22; 約書亞記 7:8–9"> 就求告耶和華說：「耶和華－我的上帝啊，我寄居在這寡婦的家裏，你就降禍與她，使她的兒子死了嗎？」</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行傳 20:10; 使徒行傳 9:40; 列王紀下 4:33–35"> 以利亞三次伏在孩子的身上，求告耶和華說：「耶和華－我的上帝啊，求你使這孩子的靈魂仍入他的身體！」</span>
<span className="v" id="v22" data-v="22" data-xref="申命記 32:39; 啟示錄 11:11; 希伯來書 11:35"> 耶和華應允以利亞的話，孩子的靈魂仍入他的身體，他就活了。</span>
<span className="v" id="v23" data-v="23" data-xref="列王紀下 4:36–37; 使徒行傳 9:41; 路加福音 7:15"> 以利亞將孩子從樓上抱下來，進屋子交給他母親，說：「看哪，你的兒子活了！」</span>
<span className="v" id="v24" data-v="24" data-xref="約翰福音 16:30; 約翰福音 2:11; 約翰福音 3:2"> 婦人對以利亞說：「現在我知道你是神人，耶和華藉你口所說的話是真的。」</span>
</div>

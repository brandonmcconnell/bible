## 智愚之別

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="啟示錄 14:13; 箴言 22:1; 傳道書 4:2"> <span className="pl pl-1">名譽強如美好的膏油；人死的日子勝過人生的日子。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="詩篇 90:12; 申命記 32:29; 希伯來書 9:27"> <span className="pl pl-1">往遭喪的家去，</span><br /><span className="pl pl-1">強如往宴樂的家去；</span><br /><span className="pl pl-1">因為死是眾人的結局，</span><br /><span className="pl pl-1">活人也必將這事放在心上。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="哥林多後書 7:9–11; 羅馬書 5:3–4; 雅各書 4:8–10"> <span className="pl pl-1">憂愁強如喜笑；</span><br /><span className="pl pl-1">因為面帶愁容，終必使心喜樂。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="馬太福音 8:14–16; 撒母耳記上 25:36; 路加福音 7:12–13"> <span className="pl pl-1">智慧人的心在遭喪之家；</span><br /><span className="pl pl-1">愚昧人的心在快樂之家。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="箴言 15:31–32; 詩篇 141:5; 啟示錄 3:19"> <span className="pl pl-1">聽智慧人的責備，</span><br /><span className="pl pl-1">強如聽愚昧人的歌唱。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 58:9; 詩篇 118:12; 傳道書 2:2"> <span className="pl pl-1">愚昧人的笑聲，</span><br /><span className="pl pl-1">好像鍋下燒荊棘的爆聲；</span><br /><span className="pl pl-1">這也是虛空。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="申命記 16:19; 出埃及記 23:8; 箴言 17:23"> <span className="pl pl-1">勒索使智慧人變為愚妄；</span><br /><span className="pl pl-1">賄賂能敗壞人的慧心。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="希伯來書 10:36; 箴言 14:29; 詩篇 126:5–6"> <span className="pl pl-1">事情的終局強如事情的起頭；</span><br /><span className="pl pl-1">存心忍耐的，勝過居心驕傲的。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="雅各書 1:19; 箴言 14:17; 以弗所書 4:26–27"> <span className="pl pl-1">你不要心裏急躁惱怒，</span><br /><span className="pl pl-1">因為惱怒存在愚昧人的懷中。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="士師記 6:13; 詩篇 14:2–3; 創世記 6:11–12"> <span className="pl pl-1">不要說：</span><br /><span className="pl pl-1">先前的日子強過如今的日子，</span><br /><span className="pl pl-1">是甚麼緣故呢？</span><br /><span className="pl pl-1">你這樣問，不是出於智慧。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="傳道書 11:7; 提摩太前書 6:17–19; 傳道書 2:13"> <span className="pl pl-1">智慧和產業並好，</span><br /><span className="pl pl-1">而且見天日的人得智慧更為有益。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="箴言 8:35; 箴言 2:7; 箴言 3:18"> <span className="pl pl-1">因為智慧護庇人，</span><br /><span className="pl pl-1">好像銀錢護庇人一樣。</span><br /><span className="pl pl-1">惟獨智慧能保全智慧人的生命。</span><br /><span className="pl pl-1">這就是知識的益處。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="傳道書 1:15; 約伯記 12:14; 詩篇 107:43"> <span className="pl pl-1">你要察看上帝的作為；</span><br /><span className="pl pl-1">因上帝使為曲的，誰能變為直呢？</span></span>
<span className="v" id="v14" data-v="14" data-xref="傳道書 3:4; 傳道書 3:22; 傳道書 12:13"> 遇亨通的日子你當喜樂；遭患難的日子你當思想；因為上帝使這兩樣並列，為的是叫人查不出身後有甚麼事。</span>
<span className="v" id="v15" data-v="15" data-xref="傳道書 8:12–14; 傳道書 6:12; 詩篇 73:3–13"> 有義人行義，反致滅亡；有惡人行惡，倒享長壽。這都是我在虛度之日中所見過的。</span>
<span className="v" id="v16" data-v="16" data-xref="羅馬書 12:3; 箴言 25:16; 歌羅西書 2:18"> 不要行義過分，也不要過於自逞智慧，何必自取敗亡呢？</span>
<span className="v" id="v17" data-v="17" data-xref="箴言 10:27; 詩篇 55:23; 約伯記 22:16"> 不要行惡過分，也不要為人愚昧，何必不到期而死呢？</span>
<span className="v" id="v18" data-v="18" data-xref="傳道書 12:13; 瑪拉基書 4:2; 傳道書 11:6"> 你持守這個為美，那個也不要鬆手；因為敬畏上帝的人，必從這兩樣出來。</span>
<span className="v" id="v19" data-v="19" data-xref="箴言 21:22; 歌羅西書 1:9–11; 箴言 24:5"> 智慧使有智慧的人比城中十個官長更有能力。</span>
<span className="v" id="v20" data-v="20" data-xref="羅馬書 3:23; 以賽亞書 53:6; 約翰一書 1:8–10"> 時常行善而不犯罪的義人，世上實在沒有。</span>
<span className="v" id="v21" data-v="21" data-xref="箴言 30:10; 以賽亞書 29:21; 撒母耳記下 16:10"> 人所說的一切話，你不要放在心上，恐怕聽見你的僕人咒詛你。</span>
<span className="v" id="v22" data-v="22" data-xref="雅各書 3:9; 馬太福音 18:32–35; 約翰福音 8:7–9"> 因為你心裏知道，自己也曾屢次咒詛別人。</span>
<span className="v" id="v23" data-v="23" data-xref="羅馬書 1:22; 創世記 3:5; 哥林多前書 1:20"> 我曾用智慧試驗這一切事；我說，要得智慧，智慧卻離我遠。</span>
<span className="v" id="v24" data-v="24" data-xref="羅馬書 11:33; 提摩太前書 6:16; 以賽亞書 55:8–9"> 萬事之理，離我甚遠，而且最深，誰能測透呢？</span>
<span className="v" id="v25" data-v="25" data-xref="傳道書 10:13; 約書亞記 7:13; 傳道書 2:20"> 我轉念，一心要知道，要考察，要尋求智慧和萬事的理由；又要知道邪惡為愚昧，愚昧為狂妄。</span>
<span className="v" id="v26" data-v="26" data-xref="箴言 22:14; 箴言 5:3–5; 箴言 2:18–19"> 我得知有等婦人比死還苦：她的心是網羅，手是鎖鍊。凡蒙上帝喜悅的人必能躲避她；有罪的人卻被她纏住了。</span>
<span className="v" id="v27" data-v="27" data-xref="傳道書 12:8–10; 傳道書 1:1–2"> 傳道者說：「看哪，一千男子中，我找到一個正直人，但眾女子中，沒有找到一個。」我將這事一一比較，要尋求其理，我心仍要尋找，卻未曾找到。</span>
<span className="v" id="v29" data-v="29" data-xref="耶利米書 4:22; 馬可福音 7:8–9; 提多書 3:3"> 我所找到的只有一件，就是上帝造人原是正直，但他們尋出許多巧計。</span>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 12:19; 傳道書 8:15; 雅各書 5:5"> 我心裏說：「來吧，我以喜樂試試你，你好享福！」誰知，這也是虛空。</span>
<span className="v" id="v2" data-v="2" data-xref="箴言 14:13; 傳道書 7:2–6; 彼得前書 4:2–4"> 我指嬉笑說：「這是狂妄。」論喜樂說：「有何功效呢？」</span>
<span className="v" id="v3" data-v="3" data-xref="箴言 20:1; 傳道書 1:17; 箴言 31:4–5"> 我心裏察究，如何用酒使我肉體舒暢，我心卻仍以智慧引導我；又如何持住愚昧，等我看明世人，在天下一生當行何事為美。</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀上 7:1–12; 歷代志下 8:11; 歷代志下 26:10"> 我為自己動大工程，建造房屋，栽種葡萄園，</span>
<span className="v" id="v5" data-v="5" data-xref="路加福音 17:27–29; 雅歌 4:12–1; 耶利米書 39:4"> 修造園囿，在其中栽種各樣果木樹；</span>
<span className="v" id="v6" data-v="6" data-xref="尼希米記 2:14; 詩篇 1:3; 耶利米書 17:8"> 挖造水池，用以澆灌嫩小的樹木。</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀下 3:4; 創世記 15:3; 列王紀上 4:23"> 我買了僕婢，也有生在家中的僕婢；又有許多牛群羊群，勝過以前在耶路撒冷眾人所有的。</span>
<span className="v" id="v8" data-v="8" data-xref="列王紀上 10:10; 列王紀上 9:28; 撒母耳記下 19:35"> 我又為自己積蓄金銀和君王的財寶，並各省的財寶；又得唱歌的男女和世人所喜愛的物，並許多的妃嬪。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="歷代志上 29:25; 傳道書 1:16; 列王紀上 10:23"> 這樣，我就日見昌盛，勝過以前在耶路撒冷的眾人。我的智慧仍然存留。</span>
<span className="v" id="v10" data-v="10" data-xref="傳道書 9:9; 傳道書 5:18; 傳道書 3:22"> 凡我眼所求的，我沒有留下不給它的；我心所樂的，我沒有禁止不享受的；因我的心為我一切所勞碌的快樂，這就是我從勞碌中所得的分。</span>
<span className="v" id="v11" data-v="11" data-xref="傳道書 1:14; 約翰一書 2:16–17; 傳道書 1:3"> 後來，我察看我手所經營的一切事和我勞碌所成的功。誰知都是虛空，都是捕風；在日光之下毫無益處。</span>
<span className="v" id="v12" data-v="12" data-xref="傳道書 1:17; 傳道書 7:25; 傳道書 1:9–10"> 我轉念觀看智慧、狂妄，和愚昧。在王以後而來的人還能做甚麼呢？也不過行早先所行的就是了。</span>
<span className="v" id="v13" data-v="13" data-xref="以弗所書 5:8; 傳道書 7:11–12; 馬太福音 6:23"> 我便看出智慧勝過愚昧，如同光明勝過黑暗。</span>
<span className="v" id="v14" data-v="14" data-xref="詩篇 49:10; 箴言 17:24; 傳道書 9:11"> 智慧人的眼目光明<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="光明：原文是在他頭上">a</a></sup>，愚昧人在黑暗裏行。我卻看明有一件事，這兩等人都必遇見。</span>
<span className="v" id="v15" data-v="15" data-xref="傳道書 6:8; 傳道書 1:14; 傳道書 1:2"> 我就心裏說：「愚昧人所遇見的，我也必遇見，我為何更有智慧呢？」我心裏說，這也是虛空。</span>
<span className="v" id="v16" data-v="16" data-xref="傳道書 1:11; 傳道書 9:5; 詩篇 88:12"> 智慧人和愚昧人一樣，永遠無人記念，因為日後都被忘記；可歎智慧人死亡，與愚昧人無異。</span>
<span className="v" id="v17" data-v="17" data-xref="傳道書 2:11; 約拿書 4:8; 傳道書 4:2"> 我所以恨惡生命；因為在日光之下所行的事我都以為煩惱，都是虛空，都是捕風。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="詩篇 39:6; 詩篇 49:10; 路加福音 16:27–28"> 我恨惡一切的勞碌，就是我在日光之下的勞碌，因為我得來的必留給我以後的人。</span>
<span className="v" id="v19" data-v="19" data-xref="雅各書 3:17; 傳道書 3:22; 傳道書 9:13"> 那人是智慧是愚昧，誰能知道？他竟要管理我勞碌所得的，就是我在日光之下用智慧所得的。這也是虛空。</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 43:14; 約伯記 17:11–15; 哥林多後書 1:8–10"> 故此，我轉想我在日光之下所勞碌的一切工作，心便絕望。</span>
<span className="v" id="v21" data-v="21" data-xref="傳道書 2:17–18; 歷代志下 31:20–21; 歷代志下 34:2"> 因為有人用智慧、知識、靈巧所勞碌得來的，卻要留給未曾勞碌的人為分。這也是虛空，也是大患。</span>
<span className="v" id="v22" data-v="22" data-xref="詩篇 127:2; 傳道書 1:3; 腓立比書 4:6"> 人在日光之下勞碌累心，在他一切的勞碌上得着甚麼呢？</span>
<span className="v" id="v23" data-v="23" data-xref="約伯記 14:1; 約伯記 5:7; 詩篇 6:6–7"> 因為他日日憂慮，他的勞苦成為愁煩，連夜間心也不安。這也是虛空。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="傳道書 3:22; 傳道書 8:15; 提摩太前書 6:17"> 人莫強如吃喝，且在勞碌中享福，我看這也是出於上帝的手。</span>
<span className="v" id="v25" data-v="25" data-xref="傳道書 2:1–12; 列王紀上 4:21–24"> 論到吃用、享福，誰能勝過我呢？</span>
<span className="v" id="v26" data-v="26" data-xref="箴言 13:22; 約伯記 27:16–17; 箴言 28:8"> 上帝喜悅誰，就給誰智慧、知識，和喜樂；惟有罪人，上帝使他勞苦，叫他將所收聚的、所堆積的歸給上帝所喜悅的人。這也是虛空，也是捕風。</span>
</div>

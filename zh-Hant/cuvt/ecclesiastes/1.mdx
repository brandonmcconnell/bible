## 人生的虛空

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="傳道書 12:8–10; 傳道書 1:12; 傳道書 7:27"> 在耶路撒冷作王、大衛的兒子、傳道者的言語。</span>
<span className="v" id="v2" data-v="2" data-xref="詩篇 144:4; 羅馬書 8:20; 傳道書 5:10"> <span className="pl pl-1">傳道者說：虛空的虛空，</span><br /><span className="pl pl-1">虛空的虛空，凡事都是虛空。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="傳道書 3:9; 傳道書 5:16; 傳道書 2:22"> <span className="pl pl-1">人一切的勞碌，</span><br /><span className="pl pl-1">就是他在日光之下的勞碌，有甚麼益處呢？</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="詩篇 104:5; 撒迦利亞書 1:5; 傳道書 6:12"> <span className="pl pl-1">一代過去，一代又來，</span><br /><span className="pl pl-1">地卻永遠長存。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 19:4–6; 哈巴谷書 3:11; 詩篇 42:1"> <span className="pl pl-1">日頭出來，日頭落下，</span><br /><span className="pl pl-1">急歸所出之地。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="約翰福音 3:8; 傳道書 11:5; 詩篇 107:25"> <span className="pl pl-1">風往南颳，又向北轉，</span><br /><span className="pl pl-1">不住地旋轉，而且返回轉行原道。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="約伯記 38:10–11; 詩篇 104:6–9"> <span className="pl pl-1">江河都往海裏流，海卻不滿；</span><br /><span className="pl pl-1">江河從何處流，仍歸還何處。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="箴言 27:20; 馬太福音 11:28; 傳道書 4:8"> <span className="pl pl-1">萬事令人厭煩</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或譯：萬物滿有困乏">a</a></sup><br /><span className="pl pl-1">，</span><br /><span className="pl pl-1">人不能說盡。</span><br /><span className="pl pl-1">眼看，看不飽；</span><br /><span className="pl pl-1">耳聽，聽不足。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="傳道書 3:15; 傳道書 6:10; 傳道書 2:12"> <span className="pl pl-1">已有的事後必再有；</span><br /><span className="pl pl-1">已行的事後必再行。</span><br /><span className="pl pl-1">日光之下並無新事。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="使徒行傳 7:51; 路加福音 17:26–30; 馬太福音 23:30–32"> <span className="pl pl-1">豈有一件事人能指着說這是新的？</span><br /><span className="pl pl-1">哪知，在我們以前的世代早已有了。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="傳道書 2:16; 詩篇 9:6; 傳道書 9:5"> <span className="pl pl-1">已過的世代，無人記念；</span><br /><span className="pl pl-1">將來的世代，後來的人也不記念。</span></span>
</div>
</div>

## 傳道者的經驗

<div className="bt">
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="傳道書 1:1; 列王紀上 4:1–19"> 我傳道者在耶路撒冷作過以色列的王。</span>
<span className="v" id="v13" data-v="13" data-xref="傳道書 3:10; 創世記 3:19; 提摩太前書 4:15"> 我專心用智慧尋求、查究天下所做的一切事，乃知上帝叫世人所經練的是極重的勞苦。</span>
<span className="v" id="v14" data-v="14" data-xref="傳道書 2:11; 傳道書 2:17; 傳道書 2:26"> 我見日光之下所做的一切事，都是虛空，都是捕風。</span>
<span className="v" id="v15" data-v="15" data-xref="傳道書 7:12–13; 以賽亞書 40:4; 傳道書 3:14"> <span className="pl pl-1">彎曲的，不能變直；</span><br /><span className="pl pl-1">缺少的，不能足數。</span></span>
<span className="v" id="v16" data-v="16" data-xref="傳道書 2:9; 列王紀上 4:30; 列王紀上 10:7"> 我心裏議論說：我得了大智慧，勝過我以前在耶路撒冷的眾人，而且我心中多經歷智慧和知識的事。</span>
<span className="v" id="v17" data-v="17" data-xref="傳道書 2:3; 帖撒羅尼迦前書 5:21; 傳道書 1:13–14"> 我又專心察明智慧、狂妄，和愚昧，乃知這也是捕風。</span>
<span className="v" id="v18" data-v="18" data-xref="約伯記 28:28; 傳道書 12:12–13; 哥林多前書 3:18–20"> <span className="pl pl-1">因為多有智慧，就多有愁煩；</span><br /><span className="pl pl-1">加增知識的，就加增憂傷。</span></span>
</div>
</div>

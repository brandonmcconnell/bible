## 萬事均有定時

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="傳道書 3:17; 馬太福音 16:3; 傳道書 8:5–6"> <span className="pl pl-1">凡事都有定期，</span><br /><span className="pl pl-1">天下萬務都有定時。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="希伯來書 9:27; 約伯記 14:5; 馬太福音 15:13"> <span className="pl pl-1">生有時，死有時；</span><br /><span className="pl pl-1">栽種有時，拔出所栽種的也有時；</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="何西阿書 6:1–2; 撒母耳記上 2:6; 耶利米書 45:4"> <span className="pl pl-1">殺戮有時，醫治有時；</span><br /><span className="pl pl-1">拆毀有時，建造有時；</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="羅馬書 12:15; 詩篇 30:5; 雅各書 4:9"> <span className="pl pl-1">哭有時，笑有時；</span><br /><span className="pl pl-1">哀慟有時，跳舞有時；</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="列王紀下 3:25; 約書亞記 10:27; 約書亞記 4:3–9"> <span className="pl pl-1">拋擲石頭有時，堆聚石頭有時；</span><br /><span className="pl pl-1">懷抱有時，不懷抱有時；</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="腓立比書 3:7–8; 路加福音 9:24–25; 馬可福音 8:35–37"> <span className="pl pl-1">尋找有時，失落有時；</span><br /><span className="pl pl-1">保守有時，捨棄有時；</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="阿摩司書 5:13; 彌迦書 7:5; 耶利米哀歌 3:28"> <span className="pl pl-1">撕裂有時，縫補有時；</span><br /><span className="pl pl-1">靜默有時，言語有時；</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="以弗所書 5:25; 以弗所書 5:28–29; 路加福音 14:26"> <span className="pl pl-1">喜愛有時，恨惡有時；</span><br /><span className="pl pl-1">爭戰有時，和好有時。</span></span>

<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="傳道書 1:3; 傳道書 5:16; 箴言 14:23"> 這樣看來，做事的人在他的勞碌上有甚麼益處呢？</span>
<span className="v" id="v10" data-v="10" data-xref="傳道書 1:13–14; 創世記 3:19; 傳道書 2:26"> 我見上帝叫世人勞苦，使他們在其中受經練。</span>
<span className="v" id="v11" data-v="11" data-xref="羅馬書 11:33; 羅馬書 1:19–20; 約伯記 11:7"> 上帝造萬物，各按其時成為美好，又將永生<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是永遠">a</a></sup>安置在世人心裏。然而上帝從始至終的作為，人不能參透。</span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 37:3; 傳道書 3:22; 提摩太前書 6:18"> 我知道世人，莫強如終身喜樂行善；</span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 128:2; 傳道書 9:7; 傳道書 2:24"> 並且人人吃喝，在他一切勞碌中享福，這也是上帝的恩賜。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="雅各書 1:17; 詩篇 33:11; 羅馬書 11:36"> 我知道上帝一切所做的都必永存；無所增添，無所減少。上帝這樣行，是要人在他面前存敬畏的心。</span>
<span className="v" id="v15" data-v="15" data-xref="傳道書 1:9–10; 傳道書 6:10"> 現今的事早先就有了，將來的事早已也有了，並且上帝使已過的事重新再來<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或譯：並且上帝再尋回已過的事">b</a></sup>。</span>

## 世上的不公平

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="傳道書 4:1; 傳道書 5:8; 詩篇 94:21–22"> 我又見日光之下，在審判之處有奸惡，在公義之處也有奸惡。</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多後書 5:10; 傳道書 12:14; 馬太福音 16:27"> 我心裏說，上帝必審判義人和惡人；因為在那裏，各樣事務，一切工作，都有定時。</span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 73:22; 詩篇 49:12; 希伯來書 9:27"> 我心裏說，這乃為世人的緣故，是上帝要試驗他們，使他們覺得自己不過像獸一樣。</span>
<span className="v" id="v19" data-v="19" data-xref="詩篇 49:12; 詩篇 49:20; 詩篇 89:47–48"> 因為世人遭遇的，獸也遭遇，所遭遇的都是一樣：這個怎樣死，那個也怎樣死，氣息都是一樣。人不能強於獸，都是虛空。</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 3:19; 約伯記 34:15; 傳道書 12:7"> 都歸一處，都是出於塵土，也都歸於塵土。</span>
<span className="v" id="v21" data-v="21" data-xref="傳道書 12:7; 約翰福音 14:3; 哥林多後書 5:1"> 誰知道人的靈是往上升，獸的魂是下入地呢？</span>
<span className="v" id="v22" data-v="22" data-xref="傳道書 2:24; 傳道書 3:11–12; 傳道書 10:14"> 故此，我見人莫強如在他經營的事上喜樂，因為這是他的分。他身後的事誰能使他回來得見呢？</span>
</div>
</div>

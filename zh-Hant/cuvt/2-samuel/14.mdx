## 約押設法讓押沙龍回來

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳記下 13:39; 撒母耳記下 2:18; 撒母耳記下 18:33"> 洗魯雅的兒子約押，知道王心裏想念押沙龍，</span>
<span className="v" id="v2" data-v="2" data-xref="歷代志下 11:6; 阿摩司書 1:1; 路得記 3:3"> 就打發人往提哥亞去，從那裏叫了一個聰明的婦人來，對她說：「請你假裝居喪的，穿上孝衣，不要用膏抹身，要裝作為死者許久悲哀的婦人；</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳記下 14:19; 出埃及記 4:15; 以賽亞書 51:16"> 進去見王，對王如此如此說。」於是約押將當說的話教導了婦人。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="撒母耳記下 1:2; 列王紀下 6:26–28; 撒母耳記上 25:23"> 提哥亞婦人到王面前，伏地叩拜，說：「王啊，求你拯救！」</span>
<span className="v" id="v5" data-v="5" data-xref="士師記 9:8–15; 撒母耳記下 12:1–3"> 王問她說：「你有甚麼事呢？」回答說：「婢女實在是寡婦，我丈夫死了。</span>
<span className="v" id="v6" data-v="6" data-xref="創世記 4:8; 申命記 22:26–27; 出埃及記 2:13"> 我有兩個兒子，一日在田間爭鬥，沒有人解勸，這個就打死那個。</span>
<span className="v" id="v7" data-v="7" data-xref="民數記 35:19; 馬太福音 21:38; 撒母耳記下 12:17"> 現在全家的人都起來攻擊婢女，說：『你將那打死兄弟的交出來，我們好治死他，償他打死兄弟的命，滅絕那承受家業的。』這樣，他們要將我剩下的炭火滅盡，不與我丈夫留名留後在世上。」</span>
<span className="v" id="v8" data-v="8" data-xref="箴言 18:13; 以賽亞書 11:3–4; 約伯記 29:16"> 王對婦人說：「你回家去吧！我必為你下令。」</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳記上 25:24; 列王紀上 2:33; 馬太福音 27:25"> 提哥亞婦人又對王說：「我主我王，願這罪歸我和我父家，與王和王的位無干。」</span>
<span className="v" id="v10" data-v="10"> 王說：「凡難為你的，你就帶他到我這裏來，他必不再攪擾你。」</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳記上 14:45; 馬太福音 10:30; 民數記 35:19"> 婦人說：「願王記念耶和華－你的上帝，不許報血仇的人施行滅絕，恐怕他們滅絕我的兒子。」王說：「我指着永生的耶和華起誓：你的兒子連一根頭髮也不致落在地上。」</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 18:27; 撒母耳記上 25:24; 使徒行傳 26:1"> 婦人說：「求我主我王容婢女再說一句話。」王說：「你說吧！」</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳記下 13:37–38; 撒母耳記下 12:7; 士師記 20:2"> 婦人說：「王為何也起意要害上帝的民呢？王不使那逃亡的人回來，王的這話就是自證己錯了！</span>
<span className="v" id="v14" data-v="14" data-xref="約伯記 30:23; 民數記 35:28; 希伯來書 9:27"> 我們都是必死的，如同水潑在地上，不能收回。上帝並不奪取人的性命，乃設法使逃亡的人不致成為趕出、回不來的。</span>
<span className="v" id="v15" data-v="15"> 我來將這話告訴我主我王，是因百姓使我懼怕。婢女想，不如將這話告訴王，或者王成就婢女所求的。</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳記上 26:19"> 人要將我和我兒子從上帝的地業上一同除滅，王必應允救我脫離他的手。</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳記上 29:9; 撒母耳記下 19:27; 撒母耳記下 14:20"> 婢女又想，我主我王的話必安慰我；因為我主我王能辨別是非，如同上帝的使者一樣。惟願耶和華－你的上帝與你同在！」</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米書 38:25; 撒母耳記上 3:17–18; 耶利米書 38:14"> 王對婦人說：「我要問你一句話，你一點不要瞞我。」婦人說：「願我主我王說。」</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳記下 14:3; 撒母耳記上 1:26; 撒母耳記上 20:3"> 王說：「你這些話莫非是約押的主意嗎？」婦人說：「我敢在我主我王面前起誓：王的話正對，不偏左右，是王的僕人約押吩咐我的，這些話是他教導我的。</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳記下 14:17; 撒母耳記下 19:27; 約伯記 32:21–22"> 王的僕人約押如此行，為要挽回這事。我主的智慧卻如上帝使者的智慧，能知世上一切事。」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="撒母耳記下 14:11; 撒母耳記上 14:39; 馬可福音 6:26"> 王對約押說：「我應允你這事。你可以去，把那少年人押沙龍帶回來。」</span>
<span className="v" id="v22" data-v="22" data-xref="路得記 2:2; 約伯記 31:20; 約伯記 29:11"> 約押就面伏於地叩拜，祝謝於王，又說：「王既應允僕人所求的，僕人今日知道在我主我王眼前蒙恩了。」</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳記下 3:3; 撒母耳記下 13:37–38"> 於是約押起身往基述去，將押沙龍帶回耶路撒冷。</span>
<span className="v" id="v24" data-v="24" data-xref="啟示錄 22:4; 創世記 43:3; 撒母耳記下 3:13"> 王說：「使他回自己家裏去，不要見我的面。」押沙龍就回自己家裏去，沒有見王的面。</span>
</div>
</div>

## 大衛饒恕押沙龍

<div className="bt">
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="以賽亞書 1:6; 申命記 28:35; 約伯記 2:7"> 以色列全地之中，無人像押沙龍那樣俊美，得人的稱讚，從腳底到頭頂毫無瑕疵。</span>
<span className="v" id="v26" data-v="26" data-xref="以西結書 44:20; 哥林多前書 11:14; 撒母耳記下 18:9"> 他的頭髮甚重，每到年底剪髮一次；所剪下來的，按王的平稱一稱，重二百舍客勒。</span>
<span className="v" id="v27" data-v="27" data-xref="撒母耳記下 18:18; 撒母耳記下 13:1; 以賽亞書 14:22"> 押沙龍生了三個兒子，一個女兒。女兒名叫她瑪，是個容貌俊美的女子。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28"> 押沙龍住在耶路撒冷足有二年，沒有見王的面。</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳記下 14:30–31; 以斯帖記 1:12; 馬太福音 22:3"> 押沙龍打發人去叫約押來，要託他去見王，約押卻不肯來。第二次打發人去叫他，他仍不肯來。</span>
<span className="v" id="v30" data-v="30" data-xref="士師記 15:4–5; 列王紀下 10:6–7; 列王紀下 9:33"> 所以押沙龍對僕人說：「你們看，約押有一塊田，與我的田相近，其中有大麥，你們去放火燒了。」押沙龍的僕人就去放火燒了那田。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31"> 於是約押起來，到了押沙龍家裏，問他說：「你的僕人為何放火燒了我的田呢？」</span>
<span className="v" id="v32" data-v="32" data-xref="撒母耳記上 20:8; 出埃及記 14:12; 箴言 28:13"> 押沙龍回答約押說：「我打發人去請你來，好託你去見王，替我說：『我為何從基述回來呢？不如仍在那裏。』現在要許我見王的面；我若有罪，任憑王殺我就是了。」</span>
<span className="v" id="v33" data-v="33" data-xref="創世記 33:4; 路加福音 15:20; 創世記 27:26"> 於是約押去見王，將這話奏告王，王便叫押沙龍來。押沙龍來見王，在王面前俯伏於地，王就與押沙龍親嘴。</span>
</div>
</div>

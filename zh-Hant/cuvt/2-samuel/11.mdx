## 大衛和拔示巴

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歷代志上 20:1; 列王紀上 20:26; 列王紀上 20:22"> 過了一年，到列王出戰的時候，大衛又差派約押，率領臣僕和以色列眾人出戰。他們就打敗亞捫人，圍攻拉巴。大衛仍住在耶路撒冷。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="馬太福音 5:28; 詩篇 119:37; 約伯記 31:1"> 一日，太陽平西，大衛從床上起來，在王宮的平頂上遊行，看見一個婦人沐浴，容貌甚美，</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳記下 23:39; 歷代志上 3:5; 雅各書 1:14–15"> 大衛就差人打聽那婦人是誰。有人說：「她是以連的女兒，赫人烏利亞的妻拔示巴。」</span>
<span className="v" id="v4" data-v="4" data-xref="利未記 18:19; 雅各書 1:14–15; 詩篇 51:1–19"> 大衛差人去，將婦人接來；那時她的月經才得潔淨。她來了，大衛與她同房，她就回家去了。</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 22:22; 箴言 6:34"> 於是她懷了孕，打發人去告訴大衛說：「我懷了孕。」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="箴言 28:13; 創世記 4:7; 撒母耳記上 15:30"> 大衛差人到約押那裏，說：「你打發赫人烏利亞到我這裏來。」約押就打發烏利亞去見大衛。</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 37:14; 撒母耳記上 17:22; 創世記 29:6"> 烏利亞來了，大衛問約押好，也問兵好，又問爭戰的事怎樣。</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 18:4; 創世記 43:34; 以賽亞書 29:15"> 大衛對烏利亞說：「你回家去，洗洗腳吧！」烏利亞出了王宮，隨後王送他一分食物。</span>
<span className="v" id="v9" data-v="9" data-xref="箴言 21:30; 約伯記 5:12–14"> 烏利亞卻和他主人的僕人一同睡在宮門外，沒有回家去。</span>
<span className="v" id="v10" data-v="10"> 有人告訴大衛說：「烏利亞沒有回家去。」大衛就問烏利亞說：「你從遠路上來，為甚麼不回家去呢？」</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳記下 7:2; 撒母耳記下 20:6; 撒母耳記下 7:6"> 烏利亞對大衛說：「約櫃和以色列與猶大兵都住在棚裏，我主約押和我主<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或譯：王">a</a></sup>的僕人都在田野安營，我豈可回家吃喝、與妻子同寢呢？我敢在王面前起誓<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原文是我指着王和王的性命起誓">b</a></sup>：我決不行這事！」</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米書 2:37; 耶利米書 2:22–23"> 大衛吩咐烏利亞說：「你今日仍住在這裏，明日我打發你去。」於是烏利亞那日和次日住在耶路撒冷。</span>
<span className="v" id="v13" data-v="13" data-xref="哈巴谷書 2:15; 創世記 19:32–35; 箴言 20:1"> 大衛召了烏利亞來，叫他在自己面前吃喝，使他喝醉。到了晚上，烏利亞出去與他主的僕人一同住宿，還沒有回到家裏去。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="耶利米書 17:9; 列王紀上 21:8–10; 詩篇 19:13"> 次日早晨，大衛寫信與約押，交烏利亞隨手帶去。</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳記下 12:9; 詩篇 51:4; 耶利米書 20:13"> 信內寫着說：「要派烏利亞前進，到陣勢極險之處，你們便退後，使他被殺。」</span>
<span className="v" id="v16" data-v="16" data-xref="箴言 29:12; 撒母耳記上 22:17–19; 使徒行傳 5:29"> 約押圍城的時候，知道敵人那裏有勇士，便將烏利亞派在那裏。</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳記下 12:9; 詩篇 51:14"> 城裏的人出來和約押打仗；大衛的僕人中有幾個被殺的，赫人烏利亞也死了。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18"> 於是，約押差人去將爭戰的一切事告訴大衛，</span>
<span className="v" id="v19" data-v="19"> 又囑咐使者說：「你把爭戰的一切事對王說完了，</span>
<span className="v" id="v20" data-v="20"> 王若發怒，問你說：『你們打仗為甚麼挨近城牆呢？豈不知敵人必從城上射箭嗎？</span>
<span className="v" id="v21" data-v="21" data-xref="士師記 7:1; 士師記 9:50–54; 撒母耳記下 3:27"> 從前打死耶路‧比設<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="就是耶路‧巴力，見士師記九章一節">c</a></sup>兒子亞比米勒的是誰呢？豈不是一個婦人從城上拋下一塊上磨石來，打在他身上，他就死在提備斯嗎？你們為甚麼挨近城牆呢？』你就說：『王的僕人－赫人烏利亞也死了。』」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22"> 使者起身，來見大衛，照着約押所吩咐他的話奏告大衛。</span>
<span className="v" id="v23" data-v="23"> 使者對大衛說：「敵人強過我們，出到郊野與我們打仗，我們追殺他們，直到城門口。</span>
<span className="v" id="v24" data-v="24"> 射箭的從城上射王的僕人，射死幾個，赫人烏利亞也死了。」</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳記下 12:26; 約書亞記 7:8–9; 傳道書 9:1–3"> 王向使者說：「你告訴約押說：『不要因這事愁悶，刀劍或吞滅這人或吞滅那人，沒有一定的；你只管竭力攻城，將城傾覆。』可以用這話勉勵約押。」</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="撒母耳記下 14:2; 創世記 27:41; 撒母耳記下 3:31"> 烏利亞的妻聽見丈夫烏利亞死了，就為他哀哭。</span>
<span className="v" id="v27" data-v="27" data-xref="詩篇 51:4–5; 撒母耳記下 12:9; 申命記 22:29"> 哀哭的日子過了，大衛差人將她接到宮裏，她就作了大衛的妻，給大衛生了一個兒子。但大衛所行的這事，耶和華甚不喜悅。</span>
</div>
</div>

## 運約櫃到耶路撒冷

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歷代志上 13:1–4; 列王紀上 8:1; 歷代志上 13:6–14"> 大衛又聚集以色列中所有挑選的人三萬。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳記上 4:4; 撒母耳記上 7:1; 詩篇 80:1"> 大衛起身，率領跟隨他的眾人前往，要從巴拉‧猶大將上帝的約櫃運來；這約櫃就是坐在二基路伯上萬軍之耶和華留名的約櫃。</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳記上 6:7; 民數記 7:4–9; 民數記 4:5–12"> 他們將上帝的約櫃從岡上亞比拿達的家裏抬出來，放在新車上；亞比拿達的兩個兒子烏撒和亞希約趕這新車。</span>
<span className="v" id="v4" data-v="4" data-xref="歷代志上 13:7; 撒母耳記上 7:1–2"> 他們將上帝的約櫃從岡上亞比拿達家裏抬出來的時候，亞希約在櫃前行走。</span>
<span className="v" id="v5" data-v="5" data-xref="歷代志上 13:8; 詩篇 150:3–5; 阿摩司書 5:23"> 大衛和以色列的全家在耶和華面前，用松木製造的各樣樂器和琴、瑟、鼓、鈸、鑼，作樂跳舞。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="歷代志上 13:9; 民數記 4:15; 民數記 4:19–20"> 到了拿艮的禾場，因為牛失前蹄<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或譯：驚跳">a</a></sup>，烏撒就伸手扶住上帝的約櫃。</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳記上 6:19; 歷代志上 15:13; 歷代志上 13:10"> 上帝耶和華向烏撒發怒，因這錯誤擊殺他，他就死在上帝的約櫃旁。</span>
<span className="v" id="v8" data-v="8" data-xref="約拿書 4:1; 歷代志上 13:11–12; 約拿書 4:9"> 大衛因耶和華擊殺<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原文是闖殺">b</a></sup>烏撒，心裏愁煩，就稱那地方為毗列斯‧烏撒，直到今日。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="詩篇 119:120; 歷代志上 13:11–12; 民數記 17:12–13"> 那日，大衛懼怕耶和華，說：「耶和華的約櫃怎可運到我這裏來？」</span>
<span className="v" id="v10" data-v="10" data-xref="歷代志上 26:4–8; 撒母耳記下 15:19; 歷代志上 15:18"> 於是大衛不肯將耶和華的約櫃運進大衛的城，卻運到迦特人俄別‧以東的家中。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 39:5; 創世記 30:27; 箴言 3:9–10"> 耶和華的約櫃在迦特人俄別‧以東家中三個月；耶和華賜福給俄別‧以東和他的全家。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="歷代志上 15:25–3; 列王紀上 8:1; 馬太福音 10:42"> 有人告訴大衛王說：「耶和華因為約櫃賜福給俄別‧以東的家和一切屬他的。」大衛就去，歡歡喜喜地將上帝的約櫃從俄別‧以東家中抬到大衛的城裏。</span>
<span className="v" id="v13" data-v="13" data-xref="列王紀上 8:5; 歷代志上 15:15; 民數記 4:15"> 抬耶和華約櫃的人走了六步，大衛就獻牛與肥羊為祭。</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳記上 2:18; 出埃及記 15:20; 詩篇 150:4"> 大衛穿着細麻布的以弗得，在耶和華面前極力跳舞。</span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 68:24–27; 歷代志上 15:28; 歷代志上 15:25"> 這樣，大衛和以色列的全家歡呼吹角，將耶和華的約櫃抬上來。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="哥林多前書 2:14; 歷代志上 15:29; 詩篇 69:7"> 耶和華的約櫃進了大衛城的時候，掃羅的女兒米甲從窗戶裏觀看，見大衛王在耶和華面前踴躍跳舞，心裏就輕視他。</span>
<span className="v" id="v17" data-v="17" data-xref="歷代志上 15:1; 歷代志下 1:4; 列王紀上 8:5"> 眾人將耶和華的約櫃請進去，安放在所預備的地方，就是在大衛所搭的帳幕裏。大衛在耶和華面前獻燔祭和平安祭。</span>
<span className="v" id="v18" data-v="18" data-xref="列王紀上 8:55; 歷代志上 16:2; 創世記 14:19"> 大衛獻完了燔祭和平安祭，就奉萬軍之耶和華的名給民祝福，</span>
<span className="v" id="v19" data-v="19" data-xref="尼希米記 8:10; 歷代志下 35:7–8; 歷代志上 16:3"> 並且分給以色列眾人，無論男女，每人一個餅，一塊肉，一個葡萄餅；眾人就各回各家去了。</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳記下 6:16; 撒母耳記下 6:14; 士師記 9:4"> 大衛回家要給眷屬祝福；掃羅的女兒米甲出來迎接他，說：「以色列王今日在臣僕的婢女眼前露體，如同一個輕賤人無恥露體一樣，有好大的榮耀啊！」</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行傳 13:22; 詩篇 89:19–20; 撒母耳記上 13:14"> 大衛對米甲說：「這是在耶和華面前；耶和華已揀選我，廢了你父和你父的全家，立我作耶和華民以色列的君，所以我必在耶和華面前跳舞。</span>
<span className="v" id="v22" data-v="22" data-xref="彼得前書 4:14; 希伯來書 12:2; 以賽亞書 51:7"> 我也必更加卑微，自己看為輕賤。你所說的那些婢女，她們倒要尊敬我。」</span>
<span className="v" id="v23" data-v="23" data-xref="馬太福音 1:25; 以賽亞書 22:14; 以賽亞書 4:1"> 掃羅的女兒米甲，直到死日，沒有生養兒女。</span>
</div>

## 暗嫩和她瑪

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歷代志上 3:9; 撒母耳記下 3:2–3; 撒母耳記下 13:15"> 大衛的兒子押沙龍有一個美貌的妹子，名叫她瑪。大衛的兒子暗嫩愛她。</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多後書 7:10; 列王紀上 21:4; 雅歌 5:8"> 暗嫩為他妹子她瑪憂急成病。她瑪還是處女，暗嫩以為難向她行事。</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳記上 16:9; 哥林多前書 3:19; 雅各書 3:15"> 暗嫩有一個朋友，名叫約拿達，是大衛長兄示米亞的兒子。這約拿達為人極其狡猾；</span>
<span className="v" id="v4" data-v="4" data-xref="利未記 20:17; 利未記 18:9; 以斯帖記 5:13–14"> 他問暗嫩說：「王的兒子啊，為何一天比一天瘦弱呢？請你告訴我。」暗嫩回答說：「我愛我兄弟押沙龍的妹子她瑪。」</span>
<span className="v" id="v5" data-v="5" data-xref="馬可福音 6:24–25; 箴言 19:27; 使徒行傳 23:15"> 約拿達說：「你不如躺在床上裝病；你父親來看你，就對他說：『求父叫我妹子她瑪來，在我眼前預備食物，遞給我吃，使我看見，好從她手裏接過來吃。』」</span>
<span className="v" id="v6" data-v="6" data-xref="創世記 18:6; 馬太福音 13:33"> 於是暗嫩躺臥裝病。王來看他，他對王說：「求父叫我妹子她瑪來，在我眼前為我做兩個餅，我好從她手裏接過來吃。」</span>
<span className="v" id="v7" data-v="7"> 大衛就打發人到宮裏，對她瑪說：「你往你哥哥暗嫩的屋裏去，為他預備食物。」</span>
<span className="v" id="v8" data-v="8"> 她瑪就到她哥哥暗嫩的屋裏；暗嫩正躺臥。她瑪摶麵，在他眼前做餅，且烤熟了，</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 45:1; 約翰福音 3:20; 士師記 3:19"> 在他面前將餅從鍋裏倒出來，他卻不肯吃，便說：「眾人離開我出去吧！」眾人就都離開他，出去了。</span>
<span className="v" id="v10" data-v="10"> 暗嫩對她瑪說：「你把食物拿進臥房，我好從你手裏接過來吃。」她瑪就把所做的餅拿進臥房，到她哥哥暗嫩那裏，</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 39:11–12"> 拿着餅上前給他吃，他便拉住她瑪，說：「我妹妹，你來與我同寢。」</span>
<span className="v" id="v12" data-v="12" data-xref="士師記 19:23; 利未記 20:17; 士師記 20:6"> 她瑪說：「我哥哥，不要玷辱我。以色列人中不當這樣行，你不要做這醜事；</span>
<span className="v" id="v13" data-v="13" data-xref="士師記 19:24; 創世記 20:12; 創世記 19:8"> 你玷辱了我，我何以掩蓋我的羞恥呢？你在以色列中也成了愚妄人。你可以求王，他必不禁止我歸你。」</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳記下 12:11; 以斯帖記 7:8; 士師記 20:5"> 但暗嫩不肯聽她的話，因比她力大，就玷辱她，與她同寢。</span>
<span className="v" id="v15" data-v="15" data-xref="以西結書 23:17"> 隨後，暗嫩極其恨她，那恨她的心比先前愛她的心更甚，對她說：「你起來，去吧！」</span>
<span className="v" id="v16" data-v="16"> 她瑪說：「不要這樣！你趕出我去的這罪比你才行的更重！」但暗嫩不肯聽她的話，</span>
<span className="v" id="v17" data-v="17"> 就叫伺候自己的僕人來，說：「將這個女子趕出去！她一出去，你就關門，上閂。」</span>
<span className="v" id="v18" data-v="18" data-xref="士師記 5:30; 創世記 37:3; 詩篇 45:13–14"> 那時她瑪穿着彩衣，因為沒有出嫁的公主都是這樣穿。暗嫩的僕人就把她趕出去，關門上閂。</span>
<span className="v" id="v19" data-v="19" data-xref="約書亞記 7:6; 耶利米書 2:37; 撒母耳記下 1:11"> 她瑪把灰塵撒在頭上，撕裂所穿的彩衣，以手抱頭，一面行走，一面哭喊。</span>
<span className="v" id="v20" data-v="20" data-xref="羅馬書 12:19; 創世記 46:15; 創世記 34:2"> 她胞兄押沙龍問她說：「莫非你哥哥暗嫩與你親近了嗎？我妹妹，暫且不要作聲，他是你的哥哥，不要將這事放在心上。」她瑪就孤孤單單地住在她胞兄押沙龍家裏。</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 34:7; 撒母耳記下 3:28–29; 撒母耳記上 2:29"> 大衛王聽見這事，就甚發怒。</span>
<span className="v" id="v22" data-v="22" data-xref="利未記 19:17–18; 創世記 31:24; 創世記 24:50"> 押沙龍並不和他哥哥暗嫩說好說歹；因為暗嫩玷辱他妹妹她瑪，所以押沙龍恨惡他。</span>
</div>
</div>

## 押沙龍為妹報仇

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="創世記 38:12–13; 撒母耳記上 25:4; 歷代志下 26:10"> 過了二年，在靠近以法蓮的巴力‧夏瑣有人為押沙龍剪羊毛；押沙龍請王的眾子與他同去。</span>
<span className="v" id="v24" data-v="24" data-xref="撒母耳記下 11:8–15; 耶利米書 41:6–7; 詩篇 55:21"> 押沙龍來見王，說：「現在有人為僕人剪羊毛，請王和王的臣僕與僕人同去。」</span>
<span className="v" id="v25" data-v="25" data-xref="路加福音 14:23; 士師記 19:7–10; 撒母耳記下 14:22"> 王對押沙龍說：「我兒，我們不必都去，恐怕使你耗費太多。」押沙龍再三請王，王仍是不肯去，只為他祝福。</span>
<span className="v" id="v26" data-v="26" data-xref="撒母耳記下 20:9; 撒母耳記下 3:27; 撒母耳記下 11:13–15"> 押沙龍說：「王若不去，求王許我哥哥暗嫩同去。」王說：「何必要他去呢？」</span>
<span className="v" id="v27" data-v="27" data-xref="箴言 26:24–26"> 押沙龍再三求王，王就許暗嫩和王的眾子與他同去。</span>
<span className="v" id="v28" data-v="28" data-xref="士師記 19:6; 士師記 19:22; 士師記 19:9"> 押沙龍吩咐僕人說：「你們注意，看暗嫩飲酒暢快的時候，我對你們說殺暗嫩，你們便殺他，不要懼怕。這不是我吩咐你們的嗎？你們只管壯膽奮勇！」</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳記下 18:9; 列王紀上 1:33; 列王紀下 1:9–12"> 押沙龍的僕人就照押沙龍所吩咐的，向暗嫩行了。王的眾子都起來，各人騎上騾子，逃跑了。</span>
<span className="v" id="v30" data-v="30"> 他們還在路上，有風聲傳到大衛那裏，說：「押沙龍將王的眾子都殺了，沒有留下一個。」</span>
<span className="v" id="v31" data-v="31" data-xref="撒母耳記下 1:11; 撒母耳記下 12:16; 約伯記 1:20"> 王就起來，撕裂衣服，躺在地上。王的臣僕也都撕裂衣服，站在旁邊。</span>
<span className="v" id="v32" data-v="32" data-xref="撒母耳記上 16:9; 撒母耳記下 13:3; 創世記 27:41"> 大衛的長兄，示米亞的兒子約拿達說：「我主，不要以為王的眾子－少年人都殺了，只有暗嫩一個人死了。自從暗嫩玷辱押沙龍妹子她瑪的那日，押沙龍就定意殺暗嫩了。</span>
<span className="v" id="v33" data-v="33" data-xref="撒母耳記下 19:19"> 現在，我主我王，不要把這事放在心上，以為王的眾子都死了，只有暗嫩一個人死了。」</span>
<span className="v" id="v34" data-v="34" data-xref="創世記 4:8–14; 箴言 28:17; 阿摩司書 5:19"> 押沙龍逃跑了。 守望的少年人舉目觀看，見有許多人從山坡的路上來。</span>
<span className="v" id="v35" data-v="35"> 約拿達對王說：「看哪，王的眾子都來了，果然與你僕人所說的相合。」</span>
<span className="v" id="v36" data-v="36" data-xref="撒母耳記下 18:33; 撒母耳記下 12:21; 撒母耳記下 13:15"> 話才說完，王的眾子都到了，放聲大哭；王和臣僕也都哭得甚慟。</span>
<span className="v" id="v37" data-v="37" data-xref="撒母耳記下 3:3; 撒母耳記下 14:32; 撒母耳記下 13:34"> 押沙龍逃到基述王亞米忽的兒子達買那裏去了。大衛天天為他兒子悲哀。</span>
<span className="v" id="v38" data-v="38" data-xref="撒母耳記下 15:8; 撒母耳記下 14:23; 撒母耳記下 14:32"> 押沙龍逃到基述，在那裏住了三年。</span>
<span className="v" id="v39" data-v="39" data-xref="創世記 24:67; 創世記 38:12; 創世記 37:35"> 暗嫩死了以後，大衛王得了安慰，心裏切切想念押沙龍。</span>

## 約押勸諫王

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳記下 18:5; 撒母耳記下 18:14; 箴言 17:25"> 有人告訴約押說：「王為押沙龍哭泣悲哀。」</span>
<span className="v" id="v2" data-v="2" data-xref="箴言 19:12; 箴言 16:15"> 眾民聽說王為他兒子憂愁，他們得勝的歡樂卻變成悲哀。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 31:27; 撒母耳記下 19:32; 撒母耳記下 17:24"> 那日眾民暗暗地進城，就如敗陣逃跑、慚愧的民一般。</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳記下 18:33; 撒母耳記下 15:30"> 王蒙着臉，大聲哭號說：「我兒押沙龍啊！押沙龍，我兒，我兒啊！」</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 18:47–48; 詩篇 3:8; 尼希米記 9:27"> 約押進去見王，說：「你今日使你一切僕人臉面慚愧了！他們今日救了你的性命和你兒女妻妾的性命，</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行傳 23:5; 撒母耳記下 3:24–25; 箴言 19:9–10"> 你卻愛那恨你的人，恨那愛你的人。你今日明明地不以將帥、僕人為念。我今日看明，若押沙龍活着，我們都死亡，你就喜悅了。</span>
<span className="v" id="v7" data-v="7" data-xref="箴言 14:28; 創世記 34:3; 箴言 19:15"> 現在你當出去，安慰你僕人的心。我指着耶和華起誓：你若不出去，今夜必無一人與你同在一處；這禍患就比你從幼年到如今所遭的更甚！」</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳記下 18:24; 撒母耳記下 18:4; 撒母耳記下 19:3"> 於是王起來，坐在城門口。眾民聽說王坐在城門口，就都到王面前。 大衛回耶路撒冷 以色列人已經逃跑，各回各家去了。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳記下 15:14; 創世記 3:12–13; 撒母耳記下 8:1–14"> 以色列眾支派的人紛紛議論說：「王曾救我們脫離仇敵的手，又救我們脫離非利士人的手，現在他躲避押沙龍逃走了。</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳記下 18:14; 士師記 18:9; 何西阿書 8:4"> 我們膏押沙龍治理我們，他已經陣亡。現在為甚麼不出一言請王回來呢？」</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳記下 15:29; 列王紀上 2:35; 撒母耳記下 15:35–36"> 大衛王差人去見祭司撒督和亞比亞他，說：「你們當向猶大長老說：『以色列眾人已經有話請王回宮，你們為甚麼落在他們後頭呢？</span>
<span className="v" id="v12" data-v="12" data-xref="撒母耳記下 5:1; 創世記 2:23; 以弗所書 5:30"> 你們是我的弟兄，是我的骨肉，為甚麼在人後頭請王回來呢？』</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳記下 17:25; 列王紀上 19:2; 路得記 1:17"> 也要對亞瑪撒說：『你不是我的骨肉嗎？我若不立你替約押常作元帥，願上帝重重地降罰與我！』」</span>
<span className="v" id="v14" data-v="14" data-xref="士師記 20:1; 使徒行傳 4:32; 詩篇 110:2–3"> 如此就挽回猶大眾人的心，如同一人的心。他們便打發人去見王，說：「請王和王的一切臣僕回來。」</span>
<span className="v" id="v15" data-v="15" data-xref="約書亞記 5:9; 撒母耳記上 11:14–15"> 王就回來，到了約旦河。猶大人來到吉甲，要去迎接王，請他過約旦河。</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀上 2:8; 撒母耳記下 16:5–13; 列王紀上 2:36–46"> 巴戶琳的便雅憫人、基拉的兒子示每急忙與猶大人一同下去迎接大衛王。</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳記下 16:1–4; 撒母耳記下 9:2; 撒母耳記下 9:10"> 跟從示每的有一千便雅憫人，還有掃羅家的僕人洗巴和他十五個兒子，二十個僕人；他們都詵過約旦河迎接王。</span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 81:15; 啟示錄 3:9; 詩篇 66:3"> 有擺渡船過去，渡王的家眷，任王使用。 大衛寬恕示每 王要過約旦河的時候，基拉的兒子示每就俯伏在王面前，</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳記上 22:15; 撒母耳記下 13:20; 撒母耳記下 13:33"> 對王說：「我主我王出耶路撒冷的時候，僕人行悖逆的事，現在求我主不要因此加罪與僕人，不要記念，也不要放在心上。</span>
<span className="v" id="v20" data-v="20" data-xref="列王紀上 12:25; 詩篇 78:34–37; 創世記 48:14"> 僕人明知自己有罪，所以約瑟全家之中，今日我首先下來迎接我主我王。」</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及記 22:28; 撒母耳記上 26:9; 列王紀上 21:10–11"> 洗魯雅的兒子亞比篩說：「示每既咒罵耶和華的受膏者，不應當治死他嗎？」</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳記上 11:13; 撒母耳記下 16:10; 撒母耳記下 3:39"> 大衛說：「洗魯雅的兒子，我與你們有何關涉，使你們今日與我反對呢？今日在以色列中豈可治死人呢？我豈不知今日我作以色列的王嗎？」</span>
<span className="v" id="v23" data-v="23" data-xref="列王紀上 2:46; 列王紀上 2:8–9; 列王紀上 2:37"> 於是王對示每說：「你必不死。」王就向他起誓。</span>
</div>

## 大衛善待米非波設

<div className="bt">
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="耶利米書 41:5; 馬太福音 6:16; 撒母耳記下 15:30"> 掃羅的孫子米非波設也下去迎接王。他自從王去的日子，直到王平平安安地回來，沒有修腳，沒有剃鬍鬚，也沒有洗衣服。</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳記下 16:17"> 他來到耶路撒冷迎接王的時候，王問他說：「米非波設，你為甚麼沒有與我同去呢？」</span>
<span className="v" id="v26" data-v="26" data-xref="撒母耳記下 16:2–3; 撒母耳記下 4:4; 撒母耳記下 9:3"> 他回答說：「我主我王，僕人是瘸腿的。那日我想要備驢騎上，與王同去，無奈我的僕人欺哄了我，</span>
<span className="v" id="v27" data-v="27" data-xref="撒母耳記下 14:17; 撒母耳記下 14:20; 撒母耳記上 29:9"> 又在我主我王面前讒毀我。然而我主我王如同上帝的使者一般，你看怎樣好，就怎樣行吧！</span>
<span className="v" id="v28" data-v="28" data-xref="撒母耳記下 9:13; 撒母耳記下 9:10; 撒母耳記下 21:6–9"> 因為我祖全家的人，在我主我王面前都算為死人，王卻使僕人在王的席上同人吃飯，我現在向王還能辨理訴冤嗎？」</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行傳 18:15; 詩篇 101:5; 詩篇 82:2"> 王對他說：「你何必再提你的事呢？我說，你與洗巴均分地土。」</span>
<span className="v" id="v30" data-v="30" data-xref="腓立比書 1:20; 使徒行傳 20:24; 撒母耳記下 1:26"> 米非波設對王說：「我主我王既平平安安地回宮，就任憑洗巴都取了也可以。」</span>
</div>
</div>

## 大衛善待巴西萊

<div className="bt">
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="列王紀上 2:7; 尼希米記 7:63; 以斯拉記 2:61"> 基列人巴西萊從羅基琳下來，要送王過約旦河，就與王一同過了約旦河。</span>
<span className="v" id="v32" data-v="32" data-xref="撒母耳記上 25:2; 約伯記 1:3; 箴言 16:31"> 巴西萊年紀老邁，已經八十歲了。王住在瑪哈念的時候，他就拿食物來供給王；他原是大富戶。</span>
<span className="v" id="v33" data-v="33" data-xref="馬太福音 25:34–40; 路加福音 22:28–30; 撒母耳記下 9:11"> 王對巴西萊說：「你與我同去，我要在耶路撒冷那裏養你的老。」</span>
<span className="v" id="v34" data-v="34" data-xref="雅各書 4:14; 哥林多前書 7:29; 創世記 47:8–9"> 巴西萊對王說：「我在世的年日還能有多少，使我與王同上耶路撒冷呢？</span>
<span className="v" id="v35" data-v="35" data-xref="撒母耳記下 15:33; 以斯拉記 2:65; 詩篇 90:10"> 僕人現在八十歲了，還能嘗出飲食的滋味、辨別美惡嗎？還能聽男女歌唱的聲音嗎？僕人何必累贅我主我王呢？</span>
<span className="v" id="v36" data-v="36" data-xref="路加福音 6:38"> 僕人只要送王過約旦河，王何必賜我這樣的恩典呢？</span>
<span className="v" id="v37" data-v="37" data-xref="列王紀上 2:7; 耶利米書 41:17; 撒母耳記下 19:40"> 求你准我回去，好死在我本城，葬在我父母的墓旁。這裏有王的僕人金罕，讓他同我主我王過去，可以隨意待他。」</span>
<span className="v" id="v38" data-v="38"> 王說：「金罕可以與我同去，我必照你的心願待他。你向我求甚麼，我都必為你成就。」</span>
<span className="v" id="v39" data-v="39" data-xref="創世記 31:55; 路得記 1:14; 創世記 47:7"> 於是眾民過約旦河，王也過去。王與巴西萊親嘴，為他祝福，巴西萊就回本地去了。</span>
</div>
</div>

## 以色列人和猶大人為王起爭論

<div className="bt">
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="馬太福音 21:9; 創世記 49:10; 撒母耳記下 19:11–15"> 王過去，到了吉甲，金罕也跟他過去。猶大眾民和以色列民的一半也都送王過去。</span>
<span className="v" id="v41" data-v="41" data-xref="士師記 8:1; 士師記 12:1; 約翰福音 7:5–6"> 以色列眾人來見王，對他說：「我們弟兄猶大人為甚麼暗暗送王和王的家眷，並跟隨王的人過約旦河？」</span>
<span className="v" id="v42" data-v="42" data-xref="撒母耳記下 19:12; 撒母耳記下 5:1; 歷代志上 2:3–17"> 猶大眾人回答以色列人說：「因為王與我們是親屬，你們為何因這事發怒呢？我們吃了王的甚麼呢？王賞賜了我們甚麼呢？」</span>
<span className="v" id="v43" data-v="43" data-xref="加拉太書 5:20; 撒母耳記下 5:1; 列王紀上 11:30–31"> 以色列人回答猶大人說：「按支派，我們與王有十分的情分；在大衛身上，我們也比你們更有情分。你們為何藐視我們，請王回來不先與我們商量呢？」 但猶大人的話比以色列人的話更硬。</span>

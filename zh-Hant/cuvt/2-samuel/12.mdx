## 拿單的信息和大衛的悔改

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀上 20:35–41; 詩篇 51:1–19; 撒母耳記下 11:10–17"> 耶和華差遣拿單去見大衛。拿單到了大衛那裏，對他說：「在一座城裏有兩個人：一個是富戶，一個是窮人。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳記下 15:16; 約伯記 1:3; 撒母耳記下 5:13–16"> 富戶有許多牛群羊群；</span>
<span className="v" id="v3" data-v="3" data-xref="彌迦書 7:5; 撒母耳記下 11:3; 箴言 5:18–19"> 窮人除了所買來養活的一隻小母羊羔之外，別無所有。羊羔在他家裏和他兒女一同長大，吃他所吃的，喝他所喝的，睡在他懷中，在他看來如同女兒一樣。</span>
<span className="v" id="v4" data-v="4" data-xref="雅各書 1:14; 撒母耳記下 11:3–4; 創世記 18:2–7"> 有一客人來到這富戶家裏；富戶捨不得從自己的牛群羊群中取一隻預備給客人吃，卻取了那窮人的羊羔，預備給客人吃。」</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 38:24; 羅馬書 2:1; 撒母耳記上 26:16"> 大衛就甚惱怒那人，對拿單說：「我指着永生的耶和華起誓，行這事的人該死！</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及記 22:1; 路加福音 19:8; 箴言 6:31"> 他必償還羊羔四倍；因為他行這事，沒有憐恤的心。」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="馬太福音 14:14; 撒母耳記上 16:13; 撒母耳記下 22:1"> 拿單對大衛說：「你就是那人！耶和華－以色列的上帝如此說：『我膏你作以色列的王，救你脫離掃羅的手。</span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 84:11; 羅馬書 8:32; 撒母耳記下 9:7"> 我將你主人的家業賜給你，將你主人的妻交在你懷裏，又將以色列和猶大家賜給你；你若還以為不足，我早就加倍地賜給你。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳記上 15:19; 詩篇 139:1–2; 撒母耳記上 15:23"> 你為甚麼藐視耶和華的命令，行他眼中看為惡的事呢？你借亞捫人的刀殺害赫人烏利亞，又娶了他的妻為妻。</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳記下 18:14–15; 馬太福音 26:52; 羅馬書 2:4"> 你既藐視我，娶了赫人烏利亞的妻為妻，所以刀劍必永不離開你的家。』</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳記下 16:21–22; 申命記 28:30; 撒母耳記下 15:10"> 耶和華如此說：『我必從你家中興起禍患攻擊你；我必在你眼前把你的妃嬪賜給別人，他在日光之下就與她們同寢。</span>
<span className="v" id="v12" data-v="12" data-xref="撒母耳記下 16:22; 撒母耳記下 11:4–15; 傳道書 12:14"> 你在暗中行這事，我卻要在以色列眾人面前，日光之下，報應你。』」</span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 51:4; 撒母耳記下 24:10; 箴言 28:13"> 大衛對拿單說：「我得罪耶和華了！」拿單說：「耶和華已經除掉你的罪，你必不至於死。</span>
<span className="v" id="v14" data-v="14" data-xref="羅馬書 2:24; 以賽亞書 52:5; 詩篇 89:31–33"> 只是你行這事，叫耶和華的仇敵大得褻瀆的機會，故此，你所得的孩子必定要死。」</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳記上 25:38; 詩篇 104:29; 歷代志下 13:20"> 拿單就回家去了。 大衛的兒子夭折<br />耶和華擊打烏利亞妻給大衛所生的孩子，使他得重病。</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳記下 13:31; 使徒行傳 9:9; 詩篇 69:10"> 所以大衛為這孩子懇求上帝，而且禁食，進入內室，終夜躺在地上。</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳記下 3:35; 撒母耳記上 28:23"> 他家中的老臣來到他旁邊，要把他從地上扶起來，他卻不肯起來，也不同他們吃飯。</span>
<span className="v" id="v18" data-v="18" data-xref="民數記 20:15"> 到第七日，孩子死了。大衛的臣僕不敢告訴他孩子死了，因他們說：「孩子還活着的時候，我們勸他，他尚且不肯聽我們的話，若告訴他孩子死了，豈不更加憂傷嗎？」</span>
<span className="v" id="v19" data-v="19"> 大衛見臣僕彼此低聲說話，就知道孩子死了，問臣僕說：「孩子死了嗎？」他們說：「死了。」</span>
<span className="v" id="v20" data-v="20" data-xref="約伯記 1:20; 路得記 3:3; 耶利米哀歌 3:39–41"> 大衛就從地上起來，沐浴，抹膏，換了衣裳，進耶和華的殿敬拜；然後回宮，吩咐人擺飯，他便吃了。</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多前書 2:15"> 臣僕問他說：「你所行的是甚麼意思？孩子活着的時候，你禁食哭泣；孩子死了，你倒起來吃飯。」</span>
<span className="v" id="v22" data-v="22" data-xref="以賽亞書 38:1–3; 以賽亞書 38:5; 約拿書 3:9–10"> 大衛說：「孩子還活着，我禁食哭泣；因為我想，或者耶和華憐恤我，使孩子不死也未可知。</span>
<span className="v" id="v23" data-v="23" data-xref="創世記 37:35; 約伯記 30:23; 路加福音 23:43"> 孩子死了，我何必禁食，我豈能使他返回呢？我必往他那裏去，他卻不能回我這裏來。」</span>
</div>
</div>

## 所羅門出生

<div className="bt">
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="馬太福音 1:6; 歷代志上 28:5–6; 歷代志上 22:9–10"> 大衛安慰他的妻拔示巴，與她同寢，她就生了兒子，給他起名叫所羅門。耶和華也喜愛他，</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳記下 7:4; 尼希米記 13:26; 列王紀上 1:11"> 就藉先知拿單賜他一個名字，叫耶底底亞，因為耶和華愛他。</span>
</div>
</div>

## 大衛攻取拉巴

<div className="bt">
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="歷代志上 20:1–3; 申命記 3:11; 撒母耳記下 11:25"> 約押攻取亞捫人的京城拉巴。</span>
<span className="v" id="v27" data-v="27" data-xref="以西結書 21:20; 撒母耳記下 11:1; 申命記 3:11"> 約押打發使者去見大衛，說：「我攻打拉巴，取其水城。</span>
<span className="v" id="v28" data-v="28" data-xref="約翰福音 7:18"> 現在你要聚集其餘的軍兵來，安營圍攻這城，恐怕我取了這城，人就以我的名叫這城。」</span>
<span className="v" id="v29" data-v="29"> 於是大衛聚集眾軍，往拉巴去攻城，就取了這城，</span>
<span className="v" id="v30" data-v="30" data-xref="歷代志上 20:2"> 奪了亞捫人之王所戴的金冠冕<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="王：或譯瑪勒堪；瑪勒堪就是米勒公，又名摩洛，亞捫族之神名">a</a></sup>，其上的金子重一他連得，又嵌着寶石。人將這冠冕戴在大衛頭上。大衛從城裏奪了許多財物，</span>
<span className="v" id="v31" data-v="31" data-xref="歷代志上 20:3; 詩篇 21:8–9; 阿摩司書 1:3"> 將城裏的人拉出來，放在鋸下，或鐵耙下，或鐵斧下，或叫他經過磚窯<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或譯：強他們用鋸，或用打糧食的鐵器，或用鐵斧做工，或使在磚窯裏服役">b</a></sup>；大衛待亞捫各城的居民都是如此。其後，大衛和眾軍都回耶路撒冷去了。</span>
</div>

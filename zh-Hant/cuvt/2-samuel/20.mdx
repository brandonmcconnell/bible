## 示巴反叛

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀上 12:16; 歷代志下 10:16; 申命記 13:13"> 在那裏恰巧有一個匪徒，名叫示巴，是便雅憫人比基利的兒子。他吹角，說：「我們與大衛無分，與耶西的兒子無涉。以色列人哪，你們各回各家去吧！」</span>
<span className="v" id="v2" data-v="2" data-xref="約翰福音 6:66–68; 使徒行傳 11:23; 撒母耳記下 19:15"> 於是以色列人都離開大衛，跟隨比基利的兒子示巴。但猶大人從約旦河直到耶路撒冷，都緊緊跟隨他們的王。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="撒母耳記下 16:21–22; 撒母耳記下 15:16; 創世記 40:3"> 大衛王來到耶路撒冷，進了宮殿，就把從前留下看守宮殿的十個妃嬪禁閉在冷宮，養活她們，不與她們親近。她們如同寡婦被禁，直到死的日子。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="撒母耳記下 19:13; 撒母耳記下 17:25; 歷代志上 2:17"> 王對亞瑪撒說：「你要在三日之內將猶大人招聚了來，你也回到這裏來。」</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳記下 19:13; 撒母耳記上 13:8"> 亞瑪撒就去招聚猶大人，卻耽延過了王所限的日期。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳記下 21:17; 撒母耳記下 11:11; 列王紀上 1:33"> 大衛對亞比篩說：「現在恐怕比基利的兒子示巴加害於我們比押沙龍更甚。你要帶領你主的僕人追趕他，免得他得了堅固城，躲避我們。」</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳記下 8:18; 列王紀上 1:38; 撒母耳記下 20:23"> 約押的人和基利提人、比利提人，並所有的勇士，都跟着亞比篩，從耶路撒冷出去追趕比基利的兒子示巴。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳記下 3:30; 撒母耳記下 2:13; 撒母耳記下 20:4–5"> 他們到了基遍的大磐石那裏，亞瑪撒來迎接他們。那時約押穿着戰衣，腰束佩刀的帶子，刀在鞘內；約押前行，刀從鞘內掉出來。</span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 22:47–48; 馬太福音 26:48–49; 彌迦書 7:2"> 約押左手拾起刀來，對亞瑪撒說：「我兄弟，你好啊！」就用右手抓住亞瑪撒的鬍子，要與他親嘴。</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳記下 2:23; 撒母耳記下 3:27; 士師記 3:21"> 亞瑪撒沒有防備約押手裏所拿的刀；約押用刀刺入他的肚腹，他的腸子流在地上，沒有再刺他，就死了。<br />約押和他兄弟亞比篩往前追趕比基利的兒子示巴。</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳記下 20:13; 撒母耳記下 20:21; 列王紀下 9:32"> 有約押的一個少年人站在亞瑪撒屍身旁邊，對眾人說：「誰喜悅約押，誰歸順大衛，就當跟隨約押去。」</span>
<span className="v" id="v12" data-v="12" data-xref="箴言 24:21–22; 詩篇 9:16; 撒母耳記下 17:25"> 亞瑪撒在道路上滾在自己的血裏。那人見眾民經過都站住，就把亞瑪撒的屍身從路上挪到田間，用衣服遮蓋。</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳記上 6:12; 以賽亞書 7:3; 列王紀下 18:17"> 屍身從路上挪移之後，眾民就都跟隨約押去追趕比基利的兒子示巴。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="列王紀下 15:29; 列王紀上 15:20; 歷代志下 16:4"> 他走遍以色列各支派，直到伯‧瑪迦的亞比拉，並比利人的全地；那些地方的人也都聚集跟隨他。</span>
<span className="v" id="v15" data-v="15" data-xref="列王紀下 19:32; 耶利米書 32:24; 列王紀上 15:20"> 約押和跟隨的人到了伯‧瑪迦的亞比拉，圍困示巴，就對着城築壘；跟隨約押的眾民用錘撞城，要使城塌陷。</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳記下 14:2; 傳道書 9:14–18; 撒母耳記上 25:32–33"> 有一個聰明婦人從城上呼叫說：「聽啊，聽啊，請約押近前來，我好與他說話。」</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳記下 14:12; 撒母耳記上 25:24"> 約押就近前來，婦人問他說：「你是約押不是？」他說：「我是。」婦人說：「求你聽婢女的話。」約押說：「我聽。」</span>
<span className="v" id="v18" data-v="18" data-xref="申命記 20:10–11"> 婦人說：「古時有話說，當先在亞比拉求問，然後事就定妥。</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳記上 26:19; 撒母耳記下 21:3; 撒母耳記下 17:16"> 我們這城的人在以色列人中是和平、忠厚的。你為何要毀壞以色列中的大城，吞滅耶和華的產業呢？」</span>
<span className="v" id="v20" data-v="20" data-xref="路加福音 10:29; 箴言 28:13; 耶利米書 17:9"> 約押回答說：「我決不吞滅毀壞，</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳記上 26:9; 士師記 2:9; 撒母耳記下 17:2–3"> 乃因以法蓮山地的一個人－比基利的兒子示巴－舉手攻擊大衛王，你們若將他一人交出來，我便離城而去。」婦人對約押說：「那人的首級必從城牆上丟給你。」</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳記下 20:1; 傳道書 7:19; 撒母耳記下 11:6–21"> 婦人就憑她的智慧去勸眾人。他們便割下比基利的兒子示巴的首級，丟給約押。約押吹角，眾人就離城而散，各歸各家去了。約押回耶路撒冷，到王那裏。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="撒母耳記下 8:16–18; 歷代志上 18:15–17; 列王紀上 4:3–6"> 約押作以色列全軍的元帥；耶何耶大的兒子比拿雅統轄基利提人和比利提人；</span>
<span className="v" id="v24" data-v="24" data-xref="列王紀上 4:3; 列王紀上 12:18; 列王紀上 4:6"> 亞多蘭掌管服苦的人；亞希律的兒子約沙法作史官；</span>
<span className="v" id="v25" data-v="25" data-xref="列王紀上 4:4; 撒母耳記下 8:17; 歷代志上 18:16"> 示法作書記；撒督和亞比亞他作祭司長；</span>
<span className="v" id="v26" data-v="26" data-xref="撒母耳記下 23:38; 出埃及記 2:14; 創世記 41:45"> 睚珥人以拉作大衛的宰相。</span>
</div>

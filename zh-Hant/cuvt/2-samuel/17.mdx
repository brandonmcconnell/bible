## 戶篩破壞亞希多弗的計謀

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以賽亞書 59:7–8; 詩篇 109:2–4; 詩篇 3:3–5"> 亞希多弗又對押沙龍說：「求你准我挑選一萬二千人，今夜我就起身追趕大衛，</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳記下 16:14; 列王紀上 22:31; 撒迦利亞書 13:7"> 趁他疲乏手軟，我忽然追上他，使他驚惶；跟隨他的民必都逃跑，我就單殺王一人，</span>
<span className="v" id="v3" data-v="3" data-xref="帖撒羅尼迦前書 5:3; 以賽亞書 48:22; 以賽亞書 57:21"> 使眾民都歸順你。你所尋找的人既然死了，眾民就如已經歸順你；這樣，也都平安無事了。」</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳記上 18:20–21; 羅馬書 1:32; 歷代志下 30:4"> 押沙龍和以色列的長老都以這話為美。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="撒母耳記下 15:32–37; 撒母耳記下 16:16–19"> 押沙龍說：「要召亞基人戶篩來，我們也要聽他怎樣說。」</span>
<span className="v" id="v6" data-v="6"> 戶篩到了押沙龍面前，押沙龍向他說：「亞希多弗是如此如此說的，我們照着他的話行可以不可以？若不可，你就說吧！」</span>
<span className="v" id="v7" data-v="7" data-xref="箴言 31:8"> 戶篩對押沙龍說：「亞希多弗這次所定的謀不善。」</span>
<span className="v" id="v8" data-v="8" data-xref="何西阿書 13:8; 撒母耳記上 16:18; 希伯來書 11:32–34"> 戶篩又說：「你知道，你父親和跟隨他的人都是勇士，現在他們心裏惱怒，如同田野丟崽子的母熊一般，而且你父親是個戰士，必不和民一同住宿。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳記上 24:3; 撒母耳記上 14:14–15; 士師記 20:32–33"> 他現今或藏在坑中或在別處，若有人首先被殺，凡聽見的必說：『跟隨押沙龍的民被殺了。』</span>
<span className="v" id="v10" data-v="10" data-xref="約書亞記 2:9–11; 出埃及記 15:15; 創世記 49:9"> 雖有人膽大如獅子，他的心也必消化；因為以色列人都知道你父親是英雄，跟隨他的人也都是勇士。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 22:17; 士師記 20:1; 詩篇 9:16"> 依我之計，不如將以色列眾人－從但直到別是巴，如同海邊的沙那樣多－聚集到你這裏來，你也親自率領他們出戰。</span>
<span className="v" id="v12" data-v="12" data-xref="撒母耳記上 23:23; 俄巴底亞書 1:3; 列王紀上 20:10"> 這樣，我們在何處遇見他，就下到他那裏，如同露水下在地上一般，連他帶跟隨他的人，一個也不留下。</span>
<span className="v" id="v13" data-v="13" data-xref="馬太福音 24:2; 彌迦書 1:6"> 他若進了哪一座城，以色列眾人必帶繩子去，將那城拉到河裏，甚至連一塊小石頭都不剩下。」</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳記下 15:34; 哥林多前書 1:19–20; 箴言 19:21"> 押沙龍和以色列眾人說：「亞基人戶篩的計謀比亞希多弗的計謀更好！」這是因耶和華定意破壞亞希多弗的良謀，為要降禍與押沙龍。</span>
</div>
</div>

## 大衛因接獲警告而逃脫

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="撒母耳記下 15:35–36"> 戶篩對祭司撒督和亞比亞他說：「亞希多弗為押沙龍和以色列的長老所定的計謀是如此如此，我所定的計謀是如此如此。</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳記下 15:28; 哥林多前書 15:54; 哥林多後書 5:4"> 現在你們要急速打發人去，告訴大衛說：『今夜不可住在曠野的渡口，務要過河，免得王和跟隨他的人都被吞滅。』」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="撒母耳記下 15:36; 約書亞記 18:16; 撒母耳記下 15:27"> 那時，約拿單和亞希瑪斯在隱‧羅結那裏等候，不敢進城，恐怕被人看見。有一個使女出來，將這話告訴他們，他們就去報信給大衛王。</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳記下 3:16; 撒母耳記下 16:5; 撒母耳記下 19:16"> 然而有一個童子看見他們，就去告訴押沙龍。他們急忙跑到巴戶琳某人的家裏；那人院中有一口井，他們就下到井裏。</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及記 1:19; 約書亞記 2:4–24"> 那家的婦人用蓋蓋上井口，又在上頭鋪上碎麥，事就沒有洩漏。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及記 1:19; 約書亞記 2:22–23; 撒母耳記上 19:12–17"> 押沙龍的僕人來到那家，問婦人說：「亞希瑪斯和約拿單在哪裏？」婦人說：「他們過了河了。」<br />僕人找他們，找不着，就回耶路撒冷去了。</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳記下 17:15–16"> 他們走後，二人從井裏上來，去告訴大衛王說：「亞希多弗如此如此定計害你，你們務要起來，快快過河。」</span>
<span className="v" id="v22" data-v="22" data-xref="馬太福音 10:16; 約翰福音 18:9; 箴言 27:12"> 於是大衛和跟隨他的人都起來，過約旦河。到了天亮，無一人不過約旦河的。</span>
<span className="v" id="v23" data-v="23" data-xref="馬太福音 27:5; 列王紀下 20:1; 撒母耳記下 15:12"> 亞希多弗見不依從他的計謀，就備上驢，歸回本城；到了家，留下遺言，便吊死了，葬在他父親的墳墓裏。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="創世記 32:2; 撒母耳記下 2:8; 約書亞記 13:26"> 大衛到了瑪哈念，押沙龍和跟隨他的以色列人也都過了約旦河。</span>
<span className="v" id="v25" data-v="25" data-xref="歷代志上 2:13; 撒母耳記下 19:13; 撒母耳記下 20:9–12"> 押沙龍立亞瑪撒作元帥，代替約押。亞瑪撒是以實瑪利人<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="又作以色列人">a</a></sup>以特拉的兒子。以特拉曾與拿轄的女兒亞比該親近；這亞比該與約押的母親洗魯雅是姊妹。</span>
<span className="v" id="v26" data-v="26" data-xref="約書亞記 17:1; 申命記 3:15; 民數記 32:1–42"> 押沙龍和以色列人都安營在基列地。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="列王紀上 2:7; 撒母耳記下 10:1–2; 撒母耳記下 9:4"> 大衛到了瑪哈念，亞捫族的拉巴人拿轄的兒子朔比，羅‧底巴人亞‧米利的兒子瑪吉，基列的羅基琳人巴西萊，</span>
<span className="v" id="v28" data-v="28" data-xref="撒母耳記上 25:18; 俄巴底亞書 1:3; 撒母耳記下 16:1–2"> 帶着被、褥、盆、碗、瓦器、小麥、大麥、麥麵、炒穀、豆子、紅豆、炒豆、</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳記下 16:2; 以賽亞書 21:14; 撒母耳記下 16:14"> 蜂蜜、奶油、綿羊、奶餅，供給大衛和跟隨他的人吃；他們說：「民在曠野，必飢渴困乏了。」</span>
</div>
</div>

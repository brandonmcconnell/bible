## 大衛的兒子們

<div className="bt">
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="歷代志上 3:1–4; 創世記 49:3–4; 撒母耳記下 13:1–29"> 大衛在希伯崙得了幾個兒子：長子暗嫩是耶斯列人亞希暖所生的；</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳記上 27:8; 歷代志上 3:1; 申命記 3:14"> 次子基利押<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="在歷代上三章一節作但以利">a</a></sup>是作過迦密人拿八的妻亞比該所生的；三子押沙龍是基述王達買的女兒瑪迦所生的；</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀上 2:13–25; 列王紀上 1:5–18"> 四子亞多尼雅是哈及所生的；五子示法提雅是亞比她所生的；</span>
<span className="v" id="v5" data-v="5"> 六子以特念是大衛的妻以格拉所生的。大衛這六個兒子都是在希伯崙生的。</span>
</div>
</div>

## 押尼珥投效大衛

<div className="bt">
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="撒母耳記下 2:8–9; 歷代志下 25:8; 以賽亞書 8:9–10"> 掃羅家和大衛家爭戰的時候，押尼珥在掃羅家大有權勢。</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳記下 21:8–11; 列王紀上 2:21–22; 撒母耳記下 12:8"> 掃羅有一妃嬪，名叫利斯巴，是愛亞的女兒。一日，伊施波設對押尼珥說：「你為甚麼與我父的妃嬪同房呢？」</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳記下 9:8; 撒母耳記下 16:9; 馬可福音 6:18–19"> 押尼珥因伊施波設的話就甚發怒，說：「我豈是猶大的狗頭呢？我恩待你父掃羅的家和他的弟兄、朋友，不將你交在大衛手裏，今日你竟為這婦人責備我嗎？</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳記上 15:28; 列王紀上 19:2; 路得記 1:17"> 我若不照着耶和華起誓應許大衛的話行，廢去掃羅的位，建立大衛的位，使他治理以色列和猶大，從但直到別是巴，願上帝重重地降罰與我！」</span>
<span className="v" id="v11" data-v="11"> 伊施波設懼怕押尼珥，不敢回答一句。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="歷代志上 12:38–40; 撒母耳記下 3:21; 路加福音 16:5–8"> 押尼珥打發人去見大衛，替他說：「這國歸誰呢？」又說：「你與我立約，我必幫助你，使以色列人都歸服你。」</span>
<span className="v" id="v13" data-v="13" data-xref="創世記 43:3; 撒母耳記上 19:11–17; 創世記 44:23"> 大衛說：「好！我與你立約。但有一件，你來見我面的時候，若不將掃羅的女兒米甲帶來，必不得見我的面。」</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳記上 18:27; 撒母耳記上 18:25; 撒母耳記下 2:10"> 大衛就打發人去見掃羅的兒子伊施波設，說：「你要將我的妻米甲歸還我；她是我從前用一百非利士人的陽皮所聘定的。」</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳記上 25:44"> 伊施波設就打發人去，將米甲從拉億的兒子、她丈夫帕鐵那裏接回來。</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳記下 16:5; 撒母耳記下 19:16; 列王紀上 2:8"> 米甲的丈夫跟着她，一面走一面哭，直跟到巴戶琳。押尼珥說：「你回去吧！」帕鐵就回去了。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17"> 押尼珥對以色列長老說：「從前你們願意大衛作王治理你們，</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳記上 15:28; 詩篇 89:19–23; 撒母耳記上 9:16"> 現在你們可以照心願而行。因為耶和華曾論到大衛說：『我必藉我僕人大衛的手，救我民以色列脫離非利士人和眾仇敵的手。』」</span>
<span className="v" id="v19" data-v="19" data-xref="歷代志上 12:29; 撒母耳記上 10:20–21; 詩篇 68:27"> 押尼珥也用這話說給便雅憫人聽，又到希伯崙，將以色列人和便雅憫全家一切所喜悅的事說給大衛聽。</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 31:54; 創世記 26:30; 以斯帖記 1:3"> 押尼珥帶着二十個人來到希伯崙見大衛，大衛就為押尼珥和他帶來的人設擺筵席。</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳記下 3:12; 列王紀上 11:37; 撒母耳記下 3:10"> 押尼珥對大衛說：「我要起身去招聚以色列眾人來見我主我王，與你立約，你就可以照着心願作王。」於是大衛送押尼珥去，押尼珥就平平安安地去了。</span>
</div>
</div>

## 押尼珥被殺

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22"> 約押和大衛的僕人攻擊敵軍，帶回許多的掠物。那時押尼珥不在希伯崙大衛那裏，因大衛已經送他去，他也平平安安地去了。</span>
<span className="v" id="v23" data-v="23"> 約押和跟隨他的全軍到了，就有人告訴約押說：「尼珥的兒子押尼珥來見王，王送他去，他也平平安安地去了。」</span>
<span className="v" id="v24" data-v="24" data-xref="撒母耳記下 3:8; 撒母耳記下 19:5–7; 約翰福音 18:35"> 約押去見王說：「你這是做甚麼呢？押尼珥來見你，你為何送他去，他就蹤影不見了呢？</span>
<span className="v" id="v25" data-v="25" data-xref="申命記 28:6; 以賽亞書 37:28; 民數記 27:17"> 你當曉得，尼珥的兒子押尼珥來是要誆哄你，要知道你的出入和你一切所行的事。」</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="箴言 26:23–26; 箴言 27:4–6"> 約押從大衛那裏出來，就打發人去追趕押尼珥，在西拉井追上他，將他帶回來，大衛卻不知道。</span>
<span className="v" id="v27" data-v="27" data-xref="列王紀上 2:5; 撒母耳記下 20:9–10; 列王紀上 2:32"> 押尼珥回到希伯崙，約押領他到城門的甕洞，假作要與他說機密話，就在那裏刺透他的肚腹，他便死了。這是報殺他兄弟亞撒黑的仇。</span>
<span className="v" id="v28" data-v="28" data-xref="民數記 35:33; 出埃及記 21:12; 創世記 9:6"> 大衛聽見了，就說：「流尼珥的兒子押尼珥的血，這罪在耶和華面前必永不歸我和我的國。</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳記下 1:16; 詩篇 109:8–19; 利未記 13:44–46"> 願流他血的罪歸到約押頭上和他父的全家；又願約押家不斷有患漏症的，長大痲瘋的，架柺而行的，被刀殺死的，缺乏飲食的。」</span>
<span className="v" id="v30" data-v="30" data-xref="箴言 28:17; 使徒行傳 28:4; 撒母耳記下 2:19–23"> 約押和他兄弟亞比篩殺了押尼珥，是因押尼珥在基遍爭戰的時候殺了他們的兄弟亞撒黑。</span>
</div>
</div>

## 安葬押尼珥

<div className="bt">
<div className="bp poetry">
<span className="v" id="v31" data-v="31" data-xref="創世記 37:34; 撒母耳記下 1:11; 撒母耳記下 1:2"> 大衛吩咐約押和跟隨他的眾人說：「你們當撕裂衣服，腰束麻布，在押尼珥棺前哀哭。」大衛王也跟在棺後。</span>
<span className="v" id="v32" data-v="32" data-xref="箴言 24:17; 約伯記 31:28; 撒母耳記上 30:4"> 他們將押尼珥葬在希伯崙。王在押尼珥的墓旁放聲而哭，眾民也都哭了。</span>
<span className="v" id="v33" data-v="33" data-xref="撒母耳記下 1:17; 歷代志下 35:25; 路加福音 12:19–20"> 王為押尼珥舉哀，說：<br /><span className="pl pl-1">押尼珥何竟像愚頑人死呢？</span><br /></span>
<span className="v" id="v34" data-v="34" data-xref="士師記 16:21; 撒母耳記下 1:12; 約伯記 24:14"> <span className="pl pl-1">你手未曾捆綁，腳未曾鎖住。</span><br /><span className="pl pl-1">你死，如人死在罪孽之輩手下一樣。</span><br />於是眾民又為押尼珥哀哭。</span>
<span className="v" id="v35" data-v="35" data-xref="撒母耳記下 12:17; 撒母耳記下 1:12; 路得記 1:17"> 日頭未落的時候，眾民來勸大衛吃飯，但大衛起誓說：「我若在日頭未落以前吃飯，或吃別物，願上帝重重地降罰與我！」</span>
<span className="v" id="v36" data-v="36" data-xref="馬可福音 7:37; 詩篇 62:9; 馬可福音 15:11–13"> 眾民知道了就都喜悅。凡王所行的，眾民無不喜悅。</span>
<span className="v" id="v37" data-v="37"> 那日，以色列眾民才知道殺尼珥的兒子押尼珥並非出於王意。</span>
<span className="v" id="v38" data-v="38" data-xref="約伯記 32:9; 撒母耳記下 2:8; 撒母耳記下 3:12"> 王對臣僕說：「你們豈不知今日以色列人中死了一個作元帥的大丈夫嗎？</span>
<span className="v" id="v39" data-v="39" data-xref="列王紀上 2:33–34; 詩篇 101:8; 詩篇 28:4"> 我雖然受膏為王，今日還是軟弱；這洗魯雅的兩個兒子比我剛強。願耶和華照着惡人所行的惡報應他。」</span>
</div>
</div>

## 大衛作猶大和以色列王

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歷代志上 11:1–3; 撒母耳記下 19:13; 創世記 29:14"> 以色列眾支派來到希伯崙見大衛，說：「我們原是你的骨肉。</span>
<span className="v" id="v2" data-v="2" data-xref="馬太福音 2:6; 彌迦書 5:4; 以西結書 34:23"> 從前掃羅作我們王的時候，率領以色列人出入的是你；耶和華也曾應許你說：『你必牧養我的民以色列，作以色列的君。』」</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳記下 2:4; 撒母耳記上 16:13; 撒母耳記上 23:18"> 於是以色列的長老都來到希伯崙見大衛王，大衛在希伯崙耶和華面前與他們立約，他們就膏大衛作以色列的王。</span>
<span className="v" id="v4" data-v="4" data-xref="歷代志上 29:27; 路加福音 3:23; 列王紀上 2:11"> 大衛登基的時候年三十歲，在位四十年；</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳記下 2:11; 歷代志上 3:4; 列王紀上 2:11"> 在希伯崙作猶大王七年零六個月，在耶路撒冷作以色列和猶大王三十三年。</span>
<span className="v" id="v6" data-v="6" data-xref="士師記 1:8; 耶利米書 37:10; 歷代志上 11:4–9"> 大衛和跟隨他的人到了耶路撒冷，要攻打住那地方的耶布斯人。耶布斯人對大衛說：「你若不趕出瞎子、瘸子，必不能進這地方」；心裏想大衛決不能進去。</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀上 2:10; 撒母耳記下 6:16; 撒母耳記下 6:12"> 然而大衛攻取錫安的保障，就是大衛的城。</span>
<span className="v" id="v8" data-v="8" data-xref="約書亞記 15:16–17; 歷代志上 11:6–9; 撒母耳記上 17:25"> 當日，大衛說：「誰攻打耶布斯人，當上水溝攻打我心裏所恨惡的瘸子、瞎子。」從此有俗語說：「在那裏有瞎子、瘸子，他不能進屋去。」</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀上 9:15; 列王紀上 9:24; 歷代志下 32:5"> 大衛住在保障裏，給保障起名叫大衛城。大衛又從米羅以裏，周圍築牆。</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳記下 3:1; 羅馬書 8:31; 詩篇 46:11"> 大衛日見強盛，因為耶和華－萬軍之上帝與他同在。</span>
<span className="v" id="v11" data-v="11" data-xref="歷代志上 14:1; 列王紀上 5:1–2; 列王紀上 5:18"> 泰爾王希蘭將香柏木運到大衛那裏，又差遣使者和木匠、石匠給大衛建造宮殿。</span>
<span className="v" id="v12" data-v="12" data-xref="撒母耳記下 7:16; 列王紀上 10:9; 歷代志上 14:2"> 大衛就知道耶和華堅立他作以色列王，又為自己的民以色列使他的國興旺。</span>
<span className="v" id="v13" data-v="13" data-xref="歷代志上 3:9; 申命記 17:17; 歷代志下 13:21"> 大衛離開希伯崙之後，在耶路撒冷又立后妃，又生兒女。</span>
<span className="v" id="v14" data-v="14" data-xref="歷代志上 3:5–9; 路加福音 2:31; 歷代志上 14:4"> 在耶路撒冷所生的兒子是沙母亞、朔罷、拿單、所羅門、</span>
<span className="v" id="v15" data-v="15" data-xref="歷代志上 3:6; 歷代志上 14:5"> 益轄、以利書亞、尼斐、雅非亞、</span>
<span className="v" id="v16" data-v="16" data-xref="歷代志上 3:8; 歷代志上 14:7"> 以利沙瑪、以利雅大、以利法列。</span>
</div>
</div>

## 戰勝非利士人

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="撒母耳記下 23:14; 歷代志上 14:8–9; 歷代志上 11:16"> 非利士人聽見人膏大衛作以色列王，非利士眾人就上來尋索大衛；大衛聽見，就下到保障。</span>
<span className="v" id="v18" data-v="18" data-xref="約書亞記 15:8; 撒母耳記下 23:13; 創世記 14:5"> 非利士人來了，布散在利乏音谷。</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳記下 2:1; 撒母耳記上 23:2; 撒母耳記下 5:23"> 大衛求問耶和華說：「我可以上去攻打非利士人嗎？你將他們交在我手裏嗎？」耶和華說：「你可以上去，我必將非利士人交在你手裏。」</span>
<span className="v" id="v20" data-v="20" data-xref="以賽亞書 28:21"> 大衛來到巴力‧毗拉心，在那裏擊殺非利士人，說：「耶和華在我面前沖破敵人，如同水沖去一般。」因此稱那地方為巴力‧毗拉心。</span>
<span className="v" id="v21" data-v="21" data-xref="歷代志上 14:11–12; 申命記 7:5; 撒母耳記上 5:2–6"> 非利士人將偶像撇在那裏，大衛和跟隨他的人拿去了。</span>
<span className="v" id="v22" data-v="22" data-xref="歷代志上 14:13; 撒母耳記下 5:18; 列王紀上 20:22"> 非利士人又上來，布散在利乏音谷。</span>
<span className="v" id="v23" data-v="23" data-xref="歷代志上 14:14; 馬太福音 9:29–30; 馬太福音 8:23–25"> 大衛求問耶和華；耶和華說：「不要一直地上去，要轉到他們後頭，從桑林對面攻打他們。</span>
<span className="v" id="v24" data-v="24" data-xref="列王紀下 7:6; 士師記 4:14; 士師記 7:15"> 你聽見桑樹梢上有腳步的聲音，就要急速前去，因為那時耶和華已經在你前頭去攻打非利士人的軍隊。」</span>
<span className="v" id="v25" data-v="25" data-xref="歷代志上 14:16; 約書亞記 16:10; 以賽亞書 28:21"> 大衛就遵着耶和華所吩咐的去行，攻打非利士人，從迦巴直到基色。</span>

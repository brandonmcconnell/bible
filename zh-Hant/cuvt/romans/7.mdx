## 以婚姻關係為例

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="羅馬書 6:14; 羅馬書 7:6; 羅馬書 6:3"> 弟兄們，我現在對明白律法的人說，你們豈不曉得律法管人是在活着的時候嗎？</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 2:23–24; 哥林多前書 7:39; 哥林多前書 7:4"> 就如女人有了丈夫，丈夫還活着，就被律法約束；丈夫若死了，就脫離了丈夫的律法。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 20:14; 馬太福音 5:32; 馬可福音 10:6–12"> 所以丈夫活着，她若歸於別人，便叫淫婦；丈夫若死了，她就脫離了丈夫的律法，雖然歸於別人，也不是淫婦。</span>
<span className="v" id="v4" data-v="4" data-xref="彼得前書 2:24; 加拉太書 5:22–23; 以賽亞書 54:5"> 我的弟兄們，這樣說來，你們藉着基督的身體，在律法上也是死了，叫你們歸於別人，就是歸於那從死裏復活的，叫我們結果子給上帝。</span>
<span className="v" id="v5" data-v="5" data-xref="以弗所書 2:3; 加拉太書 5:16–17; 加拉太書 5:24"> 因為我們屬肉體的時候，那因律法而生的惡慾就在我們肢體中發動，以致結成死亡的果子。</span>
<span className="v" id="v6" data-v="6" data-xref="加拉太書 3:23–25; 哥林多後書 3:6; 羅馬書 7:4"> 但我們既然在捆我們的律法上死了，現今就脫離了律法，叫我們服事主，要按着心靈<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="心靈：或譯聖靈">a</a></sup>的新樣，不按着儀文的舊樣。</span>
</div>
</div>

## 內在的罪

<div className="bt">
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="羅馬書 3:20; 羅馬書 4:15; 哥林多前書 15:56"> 這樣，我們可說甚麼呢？律法是罪嗎？斷乎不是！只是非因律法，我就不知何為罪。非律法說「不可起貪心」，我就不知何為貪心。</span>
<span className="v" id="v8" data-v="8" data-xref="羅馬書 7:11; 哥林多前書 15:56; 羅馬書 4:15"> 然而，罪趁着機會， 就藉着誡命叫諸般的貪心在我裏頭發動；因為沒有律法，罪是死的。</span>
<span className="v" id="v9" data-v="9" data-xref="加拉太書 3:10; 羅馬書 8:7; 雅各書 2:10–11"> 我以前沒有律法是活着的；但是誡命來到，罪又活了，我就死了。</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多後書 3:7; 羅馬書 10:5; 利未記 18:5"> 那本來叫人活的誡命，反倒叫我死；</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 3:13; 羅馬書 7:8; 希伯來書 3:13"> 因為罪趁着機會， 就藉着誡命引誘我，並且殺了我。</span>
<span className="v" id="v12" data-v="12" data-xref="提摩太前書 1:8; 詩篇 119:137; 詩篇 19:7–12"> 這樣看來，律法是聖潔的，誡命也是聖潔、公義、良善的。</span>
<span className="v" id="v13" data-v="13" data-xref="雅各書 1:13–15; 加拉太書 3:21; 羅馬書 8:3"> 既然如此，那良善的是叫我死嗎？斷乎不是！叫我死的乃是罪。但罪藉着那良善的叫我死，就顯出真是罪，叫罪因着誡命更顯出是惡極了。</span>
<span className="v" id="v14" data-v="14" data-xref="列王紀上 21:25; 列王紀下 17:17; 羅馬書 7:18"> 我們原曉得律法是屬乎靈的，但我是屬乎肉體的，是已經賣給罪了。</span>
<span className="v" id="v15" data-v="15" data-xref="加拉太書 5:17; 羅馬書 7:19–20; 傳道書 7:20"> 因為我所做的，我自己不明白；我所願意的，我並不做；我所恨惡的，我倒去做。</span>
<span className="v" id="v16" data-v="16" data-xref="羅馬書 7:12; 羅馬書 7:14; 提摩太前書 1:8"> 若我所做的，是我所不願意的，我就應承律法是善的。</span>
<span className="v" id="v17" data-v="17" data-xref="羅馬書 7:20; 腓立比書 3:8–9; 羅馬書 7:18"> 既是這樣，就不是我做的，乃是住在我裏頭的罪做的。</span>
<span className="v" id="v18" data-v="18" data-xref="約翰福音 3:6; 詩篇 51:5; 加拉太書 5:17"> 我也知道，在我裏頭，就是我肉體之中，沒有良善。因為，立志為善由得我，只是行出來由不得我。</span>
<span className="v" id="v19" data-v="19" data-xref="羅馬書 7:15"> 故此，我所願意的善，我反不做；我所不願意的惡，我倒去做。</span>
<span className="v" id="v20" data-v="20" data-xref="羅馬書 7:17"> 若我去做所不願意做的，就不是我做的，乃是住在我裏頭的罪做的。</span>
<span className="v" id="v21" data-v="21" data-xref="羅馬書 6:14; 羅馬書 7:23; 詩篇 119:133"> 我覺得有個律，就是我願意為善的時候，便有惡與我同在。</span>
<span className="v" id="v22" data-v="22" data-xref="詩篇 1:2; 詩篇 40:8; 詩篇 119:35"> 因為按着我裏面的意思<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原文是人">b</a></sup>，我是喜歡上帝的律；</span>
<span className="v" id="v23" data-v="23" data-xref="加拉太書 5:17; 雅各書 4:1; 羅馬書 8:2"> 但我覺得肢體中另有個律和我心中的律交戰，把我擄去，叫我附從那肢體中犯罪的律。</span>
<span className="v" id="v24" data-v="24" data-xref="羅馬書 6:6; 提摩太後書 4:18; 提多書 2:14"> 我真是苦啊！誰能救我脫離這取死的身體呢？</span>
<span className="v" id="v25" data-v="25" data-xref="加拉太書 5:17–24; 歌羅西書 3:17; 哥林多後書 12:9–10"> 感謝上帝，靠着我們的主耶穌基督就能脫離了。這樣看來，我以內心順服上帝的律，我肉體卻順服罪的律了。</span>
</div>
</div>

## 不求自己的喜悅，要叫鄰舍喜悅

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="帖撒羅尼迦前書 5:14; 羅馬書 14:1; 加拉太書 6:1–2"> 我們堅固的人應該擔代不堅固人的軟弱，不求自己的喜悅。</span>
<span className="v" id="v2" data-v="2" data-xref="羅馬書 14:19; 哥林多前書 10:24; 腓立比書 2:4–5"> 我們各人務要叫鄰舍喜悅，使他得益處，建立德行。</span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 69:9; 腓立比書 2:8; 約翰福音 4:34"> 因為基督也不求自己的喜悅，如經上所記：「辱罵你人的辱罵都落在我身上。」</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多前書 10:11; 提摩太後書 3:16–17; 羅馬書 4:23–24"> 從前所寫的聖經都是為教訓我們寫的，叫我們因聖經所生的忍耐和安慰可以得着盼望。</span>
<span className="v" id="v5" data-v="5" data-xref="腓立比書 2:4–5; 彼得前書 3:8; 羅馬書 12:16"> 但願賜忍耐安慰的上帝叫你們彼此同心，效法基督耶穌，</span>
<span className="v" id="v6" data-v="6" data-xref="約翰福音 10:29–30; 啟示錄 1:6; 以弗所書 1:3"> 一心一口榮耀上帝－我們主耶穌基督的父！</span>
</div>
</div>

## 上帝的福音一視同仁

<div className="bt">
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="馬太福音 10:40; 約翰福音 13:34; 羅馬書 5:2"> 所以，你們要彼此接納，如同基督接納你們一樣，使榮耀歸與上帝。</span>
<span className="v" id="v8" data-v="8" data-xref="加拉太書 4:4–5; 馬太福音 15:24; 約翰福音 1:11"> 我說，基督是為上帝真理作了受割禮人的執事，要證實所應許列祖的話，</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳記下 22:50; 詩篇 18:49; 羅馬書 3:29"> 並叫外邦人因他的憐憫榮耀上帝。如經上所記：<br /><span className="pl pl-1">因此，我要在外邦中稱讚你，</span><br /><span className="pl pl-1">歌頌你的名；</span></span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 67:3–4; 申命記 32:43; 以賽亞書 42:10–12"> 又說：<br /><span className="pl pl-1">你們外邦人當與主的百姓一同歡樂；</span></span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 117:1"> 又說：<br /><span className="pl pl-1">外邦啊，你們當讚美主！</span><br /><span className="pl pl-1">萬民哪，你們都當頌讚他！</span></span>
<span className="v" id="v12" data-v="12" data-xref="以賽亞書 11:10; 以賽亞書 11:1; 馬太福音 12:21"> 又有以賽亞說：<br /><span className="pl pl-1">將來有耶西的根，</span><br /><span className="pl pl-1">就是那興起來要治理外邦的；</span><br /><span className="pl pl-1">外邦人要仰望他。</span></span>
<span className="v" id="v13" data-v="13" data-xref="帖撒羅尼迦後書 2:16–17; 羅馬書 12:12; 哥林多後書 9:8"> 但願使人有盼望的上帝，因信將諸般的喜樂、平安充滿你們的心，使你們藉着聖靈的能力大有盼望！</span>
</div>
</div>

## 保羅的宣教使命

<div className="bt">
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="歌羅西書 3:16; 彼得後書 1:12; 約翰一書 2:21"> 弟兄們，我自己也深信你們是滿有良善，充足了諸般的知識，也能彼此勸戒。</span>
<span className="v" id="v15" data-v="15" data-xref="羅馬書 12:3; 哥林多前書 15:10; 羅馬書 1:5"> 但我稍微放膽寫信給你們，是要提醒你們的記性，特因上帝所給我的恩典，</span>
<span className="v" id="v16" data-v="16" data-xref="羅馬書 11:13; 羅馬書 1:1; 使徒行傳 9:15"> 使我為外邦人作基督耶穌的僕役，作上帝福音的祭司，叫所獻上的外邦人，因着聖靈成為聖潔，可蒙悅納。</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多後書 2:14–16; 哥林多後書 12:11–21; 希伯來書 5:1"> 所以論到上帝的事，我在基督耶穌裏有可誇的。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行傳 15:12; 羅馬書 1:5; 使徒行傳 21:19"> 除了基督藉我做的那些事，我甚麼都不敢提，只提他藉我言語作為，用神蹟奇事的能力，並聖靈的能力，使外邦人順服；</span>
<span className="v" id="v19" data-v="19" data-xref="哥林多後書 12:12; 希伯來書 2:4; 使徒行傳 19:11–12"> 甚至我從耶路撒冷，直轉到以利哩古，到處傳了基督的福音。</span>
<span className="v" id="v20" data-v="20" data-xref="哥林多後書 10:13–16; 哥林多前書 3:9–15; 以弗所書 2:20–22"> 我立了志向，不在基督的名被稱過的地方傳福音，免得建造在別人的根基上。</span>
<span className="v" id="v21" data-v="21" data-xref="以賽亞書 52:15; 以賽亞書 65:1"> 就如經上所記：<br /><span className="pl pl-1">未曾聞知他信息的，將要看見；</span><br /><span className="pl pl-1">未曾聽過的，將要明白。</span></span>
</div>
</div>

## 保羅計劃訪問羅馬

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="羅馬書 1:13; 帖撒羅尼迦前書 2:17–18"> 我因多次被攔阻，總不得到你們那裏去。</span>
<span className="v" id="v23" data-v="23" data-xref="羅馬書 15:32; 羅馬書 1:10–12; 羅馬書 15:29"> 但如今，在這裏再沒有可傳的地方，而且這好幾年，我切心想望到西班牙去的時候，可以到你們那裏，</span>
<span className="v" id="v24" data-v="24" data-xref="羅馬書 15:28; 羅馬書 1:12; 使徒行傳 15:3"> 盼望從你們那裏經過，得見你們，先與你們彼此交往，心裏稍微滿足，然後蒙你們送行。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行傳 24:17; 使徒行傳 19:21; 使徒行傳 20:22"> 但現在，我往耶路撒冷去供給聖徒。</span>
<span className="v" id="v26" data-v="26" data-xref="哥林多後書 8:1–9; 使徒行傳 11:27–30; 哥林多後書 9:2"> 因為馬其頓和亞該亞人樂意湊出捐項給耶路撒冷聖徒中的窮人。</span>
<span className="v" id="v27" data-v="27" data-xref="哥林多前書 9:11; 加拉太書 6:6; 腓利門書 1:19"> 這固然是他們樂意的，其實也算是所欠的債；因外邦人既然在他們屬靈的好處上有分，就當把養身之物供給他們。</span>
<span className="v" id="v28" data-v="28" data-xref="羅馬書 15:24; 腓立比書 4:17; 歌羅西書 1:6"> 等我辦完了這事，把這善果向他們交付明白，我就要路過你們那裏，往西班牙去。</span>
<span className="v" id="v29" data-v="29" data-xref="以弗所書 4:13; 羅馬書 1:10–12; 詩篇 16:11"> 我也曉得，去的時候必帶着基督豐盛的恩典而去。</span>
<span className="v" id="v30" data-v="30" data-xref="歌羅西書 4:12; 哥林多後書 1:11; 哥林多後書 4:11"> 弟兄們，我藉着我們主耶穌基督，又藉着聖靈的愛，勸你們與我一同竭力，為我祈求上帝，</span>
<span className="v" id="v31" data-v="31" data-xref="帖撒羅尼迦後書 3:2; 哥林多後書 8:4; 哥林多後書 9:1"> 叫我脫離在猶太不順從的人，也叫我為耶路撒冷所辦的捐項可蒙聖徒悅納，</span>
<span className="v" id="v32" data-v="32" data-xref="哥林多前書 16:18; 腓利門書 1:20; 腓利門書 1:7"> 並叫我順着上帝的旨意，歡歡喜喜地到你們那裏，與你們同得安息。</span>
<span className="v" id="v33" data-v="33" data-xref="哥林多後書 13:11; 腓立比書 4:9; 帖撒羅尼迦前書 5:23"> 願賜平安的上帝常和你們眾人同在。阿們！</span>
</div>
</div>

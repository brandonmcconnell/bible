## 問安

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行傳 18:18; 彼得前書 1:22–23; 提摩太前書 5:9–10"> 我對你們舉薦我們的姊妹非比；她是堅革哩教會中的女執事。</span>
<span className="v" id="v2" data-v="2" data-xref="腓立比書 2:29; 腓立比書 1:27; 馬太福音 10:40–42"> 請你們為主接待她，合乎聖徒的體統。她在何事上要你們幫助，你們就幫助她；因她素來幫助許多人，也幫助了我。</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多前書 16:19; 提摩太後書 4:19; 使徒行傳 18:26"> 問百基拉和亞居拉安。他們在基督耶穌裏與我同工，</span>
<span className="v" id="v4" data-v="4" data-xref="腓立比書 2:30; 約翰一書 3:16; 哥林多前書 16:1"> 也為我的命將自己的頸項置之度外。不但我感謝他們，就是外邦的眾教會也感謝他們。</span>
<span className="v" id="v5" data-v="5" data-xref="歌羅西書 4:15; 腓利門書 1:2; 哥林多前書 16:19"> 又問在他們家中的教會安。問我所親愛的以拜尼土安；他在亞細亞是歸基督初結的果子。</span>
<span className="v" id="v6" data-v="6" data-xref="羅馬書 16:12; 馬太福音 27:55; 提摩太前書 5:10"> 又問馬利亞安；她為你們多受勞苦。</span>
<span className="v" id="v7" data-v="7" data-xref="羅馬書 16:11; 羅馬書 16:21; 腓利門書 1:23"> 又問我親屬與我一同坐監的安多尼古和猶尼亞安；他們在使徒中是有名望的，也是比我先在基督裏。</span>
<span className="v" id="v8" data-v="8" data-xref="腓立比書 4:1; 約翰一書 3:14; 羅馬書 16:5"> 又問我在主裏面所親愛的暗伯利安。</span>
<span className="v" id="v9" data-v="9" data-xref="羅馬書 16:2–3; 羅馬書 16:21"> 又問在基督裏與我們同工的耳巴奴，並我所親愛的士大古安。</span>
<span className="v" id="v10" data-v="10" data-xref="羅馬書 14:18; 彼得前書 1:7; 申命記 8:2"> 又問在基督裏經過試驗的亞比利安。問亞利多布家裏的人安。</span>
<span className="v" id="v11" data-v="11" data-xref="羅馬書 16:21; 羅馬書 16:7"> 又問我親屬希羅天安。問拿其數家在主裏的人安。</span>
<span className="v" id="v12" data-v="12" data-xref="帖撒羅尼迦前書 5:12–13; 希伯來書 6:10–11; 哥林多前書 15:58"> 又問為主勞苦的土非拿氏和土富撒氏安。問可親愛為主多受勞苦的彼息氏安。</span>
<span className="v" id="v13" data-v="13" data-xref="馬可福音 15:21; 提摩太前書 5:2; 約翰二書 1:1"> 又問在主蒙揀選的魯孚和他母親安；他的母親就是我的母親。</span>
<span className="v" id="v14" data-v="14" data-xref="歌羅西書 1:2; 羅馬書 8:29; 希伯來書 3:1"> 又問亞遜其土、弗勒干、黑米、八羅巴、黑馬，並與他們在一處的弟兄們安。</span>
<span className="v" id="v15" data-v="15" data-xref="羅馬書 16:2; 羅馬書 1:7; 羅馬書 16:14"> 又問非羅羅古和猶利亞，尼利亞和他姊妹，同阿林巴並與他們在一處的眾聖徒安。</span>
<span className="v" id="v16" data-v="16" data-xref="帖撒羅尼迦前書 5:26; 哥林多前書 16:20; 哥林多後書 13:12"> 你們親嘴問安，彼此務要聖潔。基督的眾教會都問你們安。</span>
<span className="v" id="v17" data-v="17" data-xref="猶大書 1:19; 帖撒羅尼迦後書 3:6; 提摩太前書 6:3–5"> 弟兄們，那些離間你們、叫你們跌倒、背乎所學之道的人，我勸你們要留意躲避他們。</span>
<span className="v" id="v18" data-v="18" data-xref="歌羅西書 2:4; 馬太福音 7:15; 提摩太前書 6:5"> 因為這樣的人不服事我們的主基督，只服事自己的肚腹，用花言巧語誘惑那些老實人的心。</span>
<span className="v" id="v19" data-v="19" data-xref="馬太福音 10:16; 哥林多前書 14:20; 腓立比書 2:15"> 你們的順服已經傳於眾人，所以我為你們歡喜；但我願意你們在善上聰明，在惡上愚拙。</span>
<span className="v" id="v20" data-v="20" data-xref="路加福音 10:19; 約翰一書 3:8; 創世記 3:15"> 賜平安的上帝快要將撒但踐踏在你們腳下。願我主耶穌基督的恩常和你們同在！</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行傳 20:4; 使徒行傳 17:5; 使徒行傳 13:1"> 與我同工的提摩太，和我的親屬路求、耶孫、所西巴德，問你們安。</span>
<span className="v" id="v22" data-v="22" data-xref="加拉太書 6:11; 哥林多前書 16:21; 羅馬書 16:8"> 我這代筆寫信的德提，在主裏面問你們安。</span>
<span className="v" id="v23" data-v="23" data-xref="哥林多前書 1:14; 使徒行傳 19:22; 提摩太後書 4:20"> 那接待我、也接待全教會的該猶問你們安。</span>
<span className="v" id="v24" data-v="24"> 城內管銀庫的以拉都和兄弟括土問你們安。</span>
</div>
</div>

## 頌讚

<div className="bt">
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="哥林多前書 2:7; 羅馬書 2:16; 歌羅西書 1:26–27"> 惟有上帝能照我所傳的福音和所講的耶穌基督，並照永古隱藏不言的奧祕，堅固你們的心。</span>
<span className="v" id="v26" data-v="26" data-xref="羅馬書 1:5; 加拉太書 3:8; 羅馬書 15:18"> 這奧祕如今顯明出來，而且按着永生上帝的命，藉眾先知的書指示萬國的民，使他們信服真道。</span>
<span className="v" id="v27" data-v="27" data-xref="提摩太前書 1:17; 羅馬書 11:36; 啟示錄 7:10–12"> 願榮耀，因耶穌基督，歸與獨一全智的上帝，直到永遠。阿們！</span>
</div>

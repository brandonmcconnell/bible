## 在聖靈裏的生活

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="約翰福音 3:18–19; 哥林多後書 5:17; 加拉太書 3:13"> 如今，那些在基督耶穌裏的就不定罪了。</span>
<span className="v" id="v2" data-v="2" data-xref="羅馬書 6:14; 哥林多後書 3:17; 羅馬書 6:18"> 因為賜生命聖靈的律，在基督耶穌裏釋放了我，使我脫離罪和死的律了。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行傳 13:39; 加拉太書 4:4–5; 希伯來書 7:18–19"> 律法既因肉體軟弱，有所不能行的，上帝就差遣自己的兒子，成為罪身的形狀，作了贖罪祭，在肉體中定了罪案，</span>
<span className="v" id="v4" data-v="4" data-xref="加拉太書 5:16; 加拉太書 5:22–25; 歌羅西書 1:22"> 使律法的義成就在我們這不隨從肉體、只隨從聖靈的人身上。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多前書 2:14; 加拉太書 5:19–25; 約翰福音 3:6"> 因為，隨從肉體的人體貼肉體的事；隨從聖靈的人體貼聖靈的事。</span>
<span className="v" id="v6" data-v="6" data-xref="加拉太書 6:8; 羅馬書 8:7; 羅馬書 8:13"> 體貼肉體的，就是死；體貼聖靈的，乃是生命、平安。</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多前書 2:14; 約翰一書 2:15–16; 雅各書 4:4"> 原來體貼肉體的，就是與上帝為仇；因為不服上帝的律法，也是不能服，</span>
<span className="v" id="v8" data-v="8" data-xref="約翰福音 3:5–6; 希伯來書 11:5–6; 羅馬書 8:9"> 而且屬肉體的人不能得上帝的喜歡。</span>
<span className="v" id="v9" data-v="9" data-xref="加拉太書 4:6; 哥林多前書 3:16; 提摩太後書 1:14"> 如果上帝的靈住在你們心裏，你們就不屬肉體，乃屬聖靈了。人若沒有基督的靈，就不是屬基督的。</span>
<span className="v" id="v10" data-v="10" data-xref="以弗所書 3:17; 加拉太書 2:20; 哥林多後書 5:21"> 基督若在你們心裏，身體就因罪而死，心靈卻因義而活。</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多後書 4:14; 羅馬書 6:4–5; 哥林多後書 4:11"> 然而，叫耶穌從死裏復活者的靈若住在你們心裏，那叫基督耶穌從死裏復活的，也必藉着住在你們心裏的聖靈，使你們必死的身體又活過來。</span>
<span className="v" id="v12" data-v="12" data-xref="羅馬書 6:2–15; 哥林多前書 6:19–20; 彼得前書 4:2–3"> 弟兄們，這樣看來，我們並不是欠肉體的債去順從肉體活着。</span>
<span className="v" id="v13" data-v="13" data-xref="加拉太書 6:8; 彼得前書 2:11; 哥林多前書 9:27"> 你們若順從肉體活着，必要死；若靠着聖靈治死身體的惡行，必要活着。</span>
<span className="v" id="v14" data-v="14" data-xref="加拉太書 5:18; 約翰福音 1:12; 加拉太書 3:26"> 因為凡被上帝的靈引導的，都是上帝的兒子。</span>
<span className="v" id="v15" data-v="15" data-xref="加拉太書 4:5–7; 提摩太後書 1:7; 哥林多前書 2:12"> 你們所受的，不是奴僕的心，仍舊害怕；所受的，乃是兒子的心，因此我們呼叫：「阿爸！父！」</span>
<span className="v" id="v16" data-v="16" data-xref="約翰一書 4:13; 哥林多後書 1:22; 哥林多後書 5:5"> 聖靈與我們的心同證我們是上帝的兒女；</span>
<span className="v" id="v17" data-v="17" data-xref="加拉太書 4:7; 加拉太書 3:29; 以弗所書 3:6"> 既是兒女，便是後嗣，就是上帝的後嗣，和基督同作後嗣。如果我們和他一同受苦，也必和他一同得榮耀。</span>
</div>
</div>

## 將來的榮耀

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="哥林多後書 4:17–18; 彼得前書 4:13; 彼得前書 1:5–7"> 我想，現在的苦楚若比起將來要顯於我們的榮耀就不足介意了。</span>
<span className="v" id="v19" data-v="19" data-xref="瑪拉基書 3:17–18; 羅馬書 8:23; 約翰一書 3:2"> 受造之物切望等候上帝的眾子顯出來。</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 3:17–19; 創世記 5:29; 羅馬書 8:22"> 因為受造之物服在虛空之下，不是自己願意，乃是因那叫他如此的。</span>
<span className="v" id="v21" data-v="21" data-xref="啟示錄 22:3–5; 使徒行傳 3:21; 彼得後書 3:13"> 但受造之物仍然指望脫離敗壞的轄制，得享<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="享：原文是入">a</a></sup>上帝兒女自由的榮耀。</span>
<span className="v" id="v22" data-v="22" data-xref="耶利米書 12:4; 耶利米書 12:11; 約翰福音 16:21"> 我們知道，一切受造之物一同歎息，勞苦，直到如今。</span>
<span className="v" id="v23" data-v="23" data-xref="腓立比書 3:20–21; 哥林多後書 5:2–5; 希伯來書 9:28"> 不但如此，就是我們這有聖靈初結果子的，也是自己心裏歎息，等候得着兒子的名分，乃是我們的身體得贖。</span>
<span className="v" id="v24" data-v="24" data-xref="哥林多後書 5:7; 希伯來書 11:1; 哥林多後書 4:18"> 我們得救是在乎盼望；只是所見的盼望不是盼望，誰還盼望他所見的呢<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有古卷：人所看見的何必再盼望呢">b</a></sup>？</span>
<span className="v" id="v25" data-v="25" data-xref="羅馬書 12:12; 希伯來書 10:36; 詩篇 27:14"> 但我們若盼望那所不見的，就必忍耐等候。</span>
<span className="v" id="v26" data-v="26" data-xref="馬太福音 10:20; 以弗所書 6:18; 加拉太書 4:6"> 況且，我們的軟弱有聖靈幫助；我們本不曉得當怎樣禱告，只是聖靈親自用說不出來的歎息替我們禱告。</span>
<span className="v" id="v27" data-v="27" data-xref="耶利米書 17:10; 約翰一書 5:14–15; 以弗所書 2:18"> 鑒察人心的，曉得聖靈的意思，因為聖靈照着上帝的旨意替聖徒祈求。</span>
<span className="v" id="v28" data-v="28" data-xref="彼得前書 5:10; 雅各書 1:12; 創世記 50:20"> 我們曉得萬事都互相效力，叫愛上帝的人得益處，就是按他旨意被召的人。</span>
<span className="v" id="v29" data-v="29" data-xref="以弗所書 1:4–5; 耶利米書 1:5; 以弗所書 1:11"> 因為他預先所知道的人，就預先定下效法他兒子的模樣，使他兒子在許多弟兄中作長子。</span>
<span className="v" id="v30" data-v="30" data-xref="啟示錄 17:14; 羅馬書 8:28; 以弗所書 1:11"> 預先所定下的人又召他們來；所召來的人又稱他們為義；所稱為義的人又叫他們得榮耀。</span>
</div>
</div>

## 上帝的愛

<div className="bt">
<div className="bp poetry">
<span className="v" id="v31" data-v="31" data-xref="詩篇 118:6; 耶利米書 1:19; 詩篇 56:11"> 既是這樣，還有甚麼說的呢？上帝若幫助我們，誰能敵擋我們呢？</span>
<span className="v" id="v32" data-v="32" data-xref="約翰福音 3:16; 羅馬書 8:28; 詩篇 84:11"> 上帝既不愛惜自己的兒子，為我們眾人捨了，豈不也把萬物和他一同白白地賜給我們嗎？</span>
<span className="v" id="v33" data-v="33" data-xref="啟示錄 12:10–11; 以賽亞書 50:8–9; 以賽亞書 54:17"> 誰能控告上帝所揀選的人呢？有上帝稱他們為義了<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="或譯：是稱他們為義的上帝嗎">c</a></sup>。</span>
<span className="v" id="v34" data-v="34" data-xref="希伯來書 7:25; 羅馬書 8:27; 希伯來書 9:24"> 誰能定他們的罪呢？有基督耶穌已經死了，而且從死裏復活，現今在上帝的右邊，也替我們祈求<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="有基督......或譯：是已經死了，而且從死裏復活，現今在上帝的右邊，也替我們祈求的基督耶穌嗎">d</a></sup>。</span>
<span className="v" id="v35" data-v="35" data-xref="約翰福音 10:28; 詩篇 103:17; 約翰福音 16:33"> 誰能使我們與基督的愛隔絕呢？難道是患難嗎？是困苦嗎？是逼迫嗎？是飢餓嗎？是赤身露體嗎？是危險嗎？是刀劍嗎？</span>
<span className="v" id="v36" data-v="36" data-xref="詩篇 44:22; 以賽亞書 53:7; 哥林多前書 15:30"> 如經上所記：<br /><span className="pl pl-1">我們為你的緣故終日被殺；</span><br /><span className="pl pl-1">人看我們如將宰的羊。</span></span>
<span className="v" id="v37" data-v="37" data-xref="哥林多前書 15:57; 約翰一書 4:4; 哥林多後書 2:14"> 然而，靠着愛我們的主，在這一切的事上已經得勝有餘了。</span>
<span className="v" id="v38" data-v="38" data-xref="約翰福音 10:28; 羅馬書 14:8; 提摩太後書 1:12"> 因為我深信無論是死，是生，是天使，是掌權的，是有能的，是現在的事，是將來的事，</span>
<span className="v" id="v39" data-v="39" data-xref="約翰福音 10:28–30; 羅馬書 8:35; 羅馬書 5:8"> 是高處的，是低處的，是別的受造之物，都不能叫我們與上帝的愛隔絕；這愛是在我們的主基督耶穌裏的。</span>
</div>
</div>

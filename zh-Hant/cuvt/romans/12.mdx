## 基督裏的新生活

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="彼得前書 2:5; 羅馬書 6:13; 希伯來書 13:15–16"> 所以，弟兄們，我以上帝的慈悲勸你們，將身體獻上，當作活祭，是聖潔的，是上帝所喜悅的；你們如此事奉乃是理所當然的。</span>
<span className="v" id="v2" data-v="2" data-xref="彼得前書 1:14; 以弗所書 4:22–24; 哥林多後書 5:17"> 不要效法這個世界，只要心意更新而變化，叫你們察驗何為上帝的善良、純全、可喜悅的旨意。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="加拉太書 6:3; 腓立比書 2:3–8; 箴言 26:12"> 我憑着所賜我的恩對你們各人說：不要看自己過於所當看的；要照着上帝所分給各人信心的大小，看得合乎中道。</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多前書 12:27; 哥林多前書 12:12–14; 以弗所書 4:15–16"> 正如我們一個身子上有好些肢體，肢體也不都是一樣的用處。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多前書 12:20; 哥林多前書 10:17; 哥林多前書 12:27–28"> 我們這許多人，在基督裏成為一身，互相聯絡作肢體，也是如此。</span>
<span className="v" id="v6" data-v="6" data-xref="彼得前書 4:10–11; 哥林多前書 7:7; 哥林多前書 12:28–31"> 按我們所得的恩賜，各有不同。或說預言，就當照着信心的程度說預言；</span>
<span className="v" id="v7" data-v="7" data-xref="以弗所書 4:11; 提摩太後書 4:2; 使徒行傳 13:1"> 或作執事，就當專一執事；或作教導的，就當專一教導；</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多後書 9:7; 提摩太前書 5:17; 哥林多前書 12:28"> 或作勸化的，就當專一勸化；施捨的，就當誠實；治理的，就當殷勤；憐憫人的，就當甘心。</span>
</div>
</div>

## 基督徒的生活守則

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="詩篇 34:14; 彼得前書 4:8; 提摩太前書 1:5"> 愛人不可虛假。惡，要厭惡；善，要親近。</span>
<span className="v" id="v10" data-v="10" data-xref="腓立比書 2:3; 約翰福音 13:34–35; 希伯來書 13:1"> 愛弟兄，要彼此親熱；恭敬人，要彼此推讓。</span>
<span className="v" id="v11" data-v="11" data-xref="希伯來書 6:10–11; 使徒行傳 18:25; 啟示錄 3:15–16"> 殷勤，不可懶惰；要心裏火熱，常常服事主。</span>
<span className="v" id="v12" data-v="12" data-xref="羅馬書 15:13; 希伯來書 10:36; 詩篇 62:8"> 在指望中要喜樂；在患難中要忍耐；禱告要恆切。</span>
<span className="v" id="v13" data-v="13" data-xref="希伯來書 13:16; 哥林多後書 9:12; 約翰一書 3:17"> 聖徒缺乏，要幫補；客，要一味地款待。</span>
<span className="v" id="v14" data-v="14" data-xref="彼得前書 3:9; 馬太福音 5:44; 帖撒羅尼迦前書 5:15"> 逼迫你們的，要給他們祝福；只要祝福，不可咒詛。</span>
<span className="v" id="v15" data-v="15" data-xref="哥林多前書 12:26; 希伯來書 13:3; 詩篇 35:13–14"> 與喜樂的人要同樂；與哀哭的人要同哭。</span>
<span className="v" id="v16" data-v="16" data-xref="彼得前書 3:8; 箴言 3:7; 雅各書 3:13–17"> 要彼此同心；不要志氣高大，倒要俯就卑微的人<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="人：或譯事">a</a></sup>。不要自以為聰明。</span>
<span className="v" id="v17" data-v="17" data-xref="箴言 20:22; 帖撒羅尼迦前書 5:15; 馬太福音 5:39"> 不要以惡報惡；眾人以為美的事要留心去做。</span>
<span className="v" id="v18" data-v="18" data-xref="希伯來書 12:14; 馬太福音 5:9; 羅馬書 14:19"> 若是能行，總要盡力與眾人和睦。</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 32:35; 希伯來書 10:30; 箴言 24:29"> 親愛的弟兄，不要自己伸冤，寧可讓步，聽憑主怒<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或譯：讓人發怒">b</a></sup>；因為經上記着：「主說：『伸冤在我，我必報應。』」</span>
<span className="v" id="v20" data-v="20" data-xref="箴言 25:21–22; 馬太福音 5:44; 路加福音 6:27"> 所以，「你的仇敵若餓了，就給他吃，若渴了，就給他喝；因為你這樣行就是把炭火堆在他的頭上。」</span>
<span className="v" id="v21" data-v="21" data-xref="彼得前書 3:9; 路加福音 6:27–30; 箴言 16:32"> 你不可為惡所勝，反要以善勝惡。</span>
</div>
</div>

## 以亞伯拉罕為例

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="以賽亞書 51:2; 羅馬書 4:16; 哥林多後書 11:22"> 如此說來，我們的祖宗亞伯拉罕憑着肉體得了甚麼呢？</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多前書 1:31; 哥林多後書 11:30; 腓立比書 3:9"> 倘若亞伯拉罕是因行為稱義，就有可誇的；只是在上帝面前並無可誇。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 15:6; 雅各書 2:23; 加拉太書 3:6–8"> 經上說甚麼呢？說：「亞伯拉罕信上帝，這就算為他的義。」</span>
<span className="v" id="v4" data-v="4" data-xref="羅馬書 11:6; 羅馬書 9:32; 羅馬書 11:35"> 做工的得工價，不算恩典，乃是該得的；</span>
<span className="v" id="v5" data-v="5" data-xref="腓立比書 3:9; 羅馬書 3:22; 提多書 3:3–7"> 惟有不做工的，只信稱罪人為義的上帝，他的信就算為義。</span>
<span className="v" id="v6" data-v="6" data-xref="提摩太後書 1:9; 腓立比書 3:9; 哥林多前書 1:30"> 正如大衛稱那在行為以外蒙上帝算為義的人是有福的。</span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 32:1–2; 詩篇 130:3–4; 路加福音 7:47–50"> 他說：<br /><span className="pl pl-1">得赦免其過、遮蓋其罪的，</span><br /><span className="pl pl-1">這人是有福的。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 32:2; 彼得前書 2:24; 哥林多後書 5:19–20"> <span className="pl pl-1">主不算為有罪的，</span><br /><span className="pl pl-1">這人是有福的。</span></span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="加拉太書 3:14; 歌羅西書 3:11; 加拉太書 3:26–28"> 如此看來，這福是單加給那受割禮的人嗎？不也是加給那未受割禮的人嗎？因我們所說，亞伯拉罕的信，就算為他的義，</span>
<span className="v" id="v10" data-v="10" data-xref="加拉太書 6:15; 加拉太書 5:6; 創世記 17:10"> 是怎麼算的呢？是在他受割禮的時候呢？是在他未受割禮的時候呢？不是在受割禮的時候，乃是在未受割禮的時候。</span>
<span className="v" id="v11" data-v="11" data-xref="羅馬書 3:22; 路加福音 19:9; 哥林多後書 1:22"> 並且他受了割禮的記號，作他未受割禮的時候因信稱義的印證，叫他作一切未受割禮而信之人的父，使他們也算為義；</span>
<span className="v" id="v12" data-v="12" data-xref="雅歌 1:8; 約翰福音 8:39–40; 箴言 2:20"> 又作受割禮之人的父，就是那些不但受割禮，並且按我們的祖宗亞伯拉罕未受割禮而信之蹤跡去行的人。</span>
</div>
</div>

## 應許因信而實現

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="加拉太書 3:29; 創世記 22:17–18; 創世記 28:14"> 因為上帝應許亞伯拉罕和他後裔，必得承受世界，不是因律法，乃是因信而得的義。</span>
<span className="v" id="v14" data-v="14" data-xref="加拉太書 3:18–24; 腓立比書 3:9; 羅馬書 4:16"> 若是屬乎律法的人才得為後嗣，信就歸於虛空，應許也就廢棄了。</span>
<span className="v" id="v15" data-v="15" data-xref="羅馬書 5:13; 加拉太書 3:10; 羅馬書 3:19–20"> 因為律法是惹動忿怒的<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或譯：叫人受刑的">a</a></sup>；哪裏沒有律法，那裏就沒有過犯。</span>
<span className="v" id="v16" data-v="16" data-xref="羅馬書 3:24–26; 以弗所書 2:8; 加拉太書 3:22"> 所以人得為後嗣是本乎信，因此就屬乎恩，叫應許定然歸給一切後裔；不但歸給那屬乎律法的，也歸給那效法亞伯拉罕之信的。</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多前書 1:28; 創世記 17:4–5; 約翰福音 5:21"> 亞伯拉罕所信的，是那叫死人復活、使無變為有的上帝，他在主面前作我們世人的父。如經上所記：「我已經立你作多國的父。」</span>
<span className="v" id="v18" data-v="18" data-xref="羅馬書 8:24; 創世記 15:5–6; 使徒行傳 27:25"> 他在無可指望的時候，因信仍有指望，就得以作多國的父，正如先前所說：「你的後裔將要如此。」</span>
<span className="v" id="v19" data-v="19" data-xref="希伯來書 11:11–19; 羅馬書 4:20–21; 創世記 17:17"> 他將近百歲的時候，雖然想到自己的身體如同已死，撒拉的生育已經斷絕，他的信心還是不軟弱；</span>
<span className="v" id="v20" data-v="20" data-xref="路加福音 1:45; 哥林多前書 16:13; 但以理書 10:19"> 並且仰望上帝的應許，總沒有因不信心裏起疑惑，反倒因信心裏得堅固，將榮耀歸給上帝，</span>
<span className="v" id="v21" data-v="21" data-xref="路加福音 1:37; 耶利米書 32:27; 創世記 18:14"> 且滿心相信上帝所應許的必能做成。</span>
<span className="v" id="v22" data-v="22" data-xref="羅馬書 4:6; 羅馬書 4:3"> 所以，這就算為他的義。</span>
<span className="v" id="v23" data-v="23" data-xref="哥林多前書 10:11; 羅馬書 15:4; 哥林多前書 10:6"> 「算為他義」的這句話不是單為他寫的，</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行傳 2:24; 彼得前書 1:21; 使徒行傳 13:30"> 也是為我們將來得算為義之人寫的，就是我們這信上帝使我們的主耶穌從死裏復活的人。</span>
<span className="v" id="v25" data-v="25" data-xref="約翰一書 4:9–10; 以賽亞書 53:5–6; 哥林多後書 5:21"> 耶穌被交給人，是為我們的過犯；復活，是為叫我們稱義<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或譯：耶穌是為我們的過犯交付了，是為我們稱義復活了">b</a></sup>。</span>
</div>
</div>

## 上帝的公義判斷

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 6:37; 羅馬書 2:3; 約翰福音 8:7–9"> 你這論斷人的，無論你是誰，也無可推諉。你在甚麼事上論斷人，就在甚麼事上定自己的罪；因你這論斷人的，自己所行卻和別人一樣。</span>
<span className="v" id="v2" data-v="2" data-xref="詩篇 9:7–8; 西番雅書 3:5; 詩篇 145:17"> 我們知道這樣行的人，上帝必照真理審判他。</span>
<span className="v" id="v3" data-v="3" data-xref="箴言 16:5; 路加福音 12:14; 羅馬書 1:32–1"> 你這人哪，你論斷行這樣事的人，自己所行的卻和別人一樣，你以為能逃脫上帝的審判嗎？</span>
<span className="v" id="v4" data-v="4" data-xref="彼得後書 3:9; 以賽亞書 30:18; 出埃及記 34:6"> 還是你藐視他豐富的恩慈、寬容、忍耐，不曉得他的恩慈是領你悔改呢？</span>
<span className="v" id="v5" data-v="5" data-xref="傳道書 12:14; 羅馬書 1:18; 羅馬書 2:2–3"> 你竟任着你剛硬不悔改的心，為自己積蓄忿怒，以致上帝震怒，顯他公義審判的日子來到。</span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 62:12; 耶利米書 32:19; 馬太福音 16:27"> 他必照各人的行為報應各人。</span>
<span className="v" id="v7" data-v="7" data-xref="提摩太後書 4:7–8; 路加福音 8:15; 提摩太後書 1:10"> 凡恆心行善、尋求榮耀、尊貴和不能朽壞之福的，就以永生報應他們；</span>
<span className="v" id="v8" data-v="8" data-xref="約翰福音 3:18–21; 帖撒羅尼迦後書 1:8; 提摩太前書 6:3–4"> 惟有結黨、不順從真理、反順從不義的，就以忿怒、惱恨報應他們；</span>
<span className="v" id="v9" data-v="9" data-xref="彼得前書 4:17; 以西結書 18:4; 羅馬書 1:16"> 將患難、困苦加給一切作惡的人，先是猶太人，後是希臘人，</span>
<span className="v" id="v10" data-v="10" data-xref="以賽亞書 32:17; 以賽亞書 26:12; 民數記 6:26"> 卻將榮耀、尊貴、平安加給一切行善的人，先是猶太人，後是希臘人。</span>
<span className="v" id="v11" data-v="11" data-xref="申命記 10:17; 使徒行傳 10:34; 歷代志下 19:7"> 因為上帝不偏待人。</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多前書 9:21; 加拉太書 3:10; 加拉太書 2:16–19"> 凡沒有律法犯了罪的，也必不按律法滅亡；凡在律法以下犯了罪的，也必按律法受審判。（</span>
<span className="v" id="v13" data-v="13" data-xref="雅各書 1:22–25; 約翰一書 3:7; 雅各書 2:21–25"> 原來在上帝面前，不是聽律法的為義，乃是行律法的稱義。</span>
<span className="v" id="v14" data-v="14" data-xref="羅馬書 2:12; 羅馬書 1:19–20; 羅馬書 2:27"> 沒有律法的外邦人若順着本性行律法上的事，他們雖然沒有律法，自己就是自己的律法。</span>
<span className="v" id="v15" data-v="15" data-xref="哥林多後書 5:11; 哥林多後書 1:12; 羅馬書 1:18–19"> 這是顯出律法的功用刻在他們心裏，他們是非之心同作見證，並且他們的思念互相較量，或以為是，或以為非。）</span>
<span className="v" id="v16" data-v="16" data-xref="傳道書 12:14; 哥林多前書 4:5; 使徒行傳 17:31"> 就在上帝藉耶穌基督審判人隱祕事的日子，照着我的福音所言。</span>
</div>
</div>

## 猶太人與律法

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="羅馬書 2:23; 彌迦書 3:11; 以賽亞書 48:1–2"> 你稱為猶太人，又倚靠律法，且指着上帝誇口；</span>
<span className="v" id="v18" data-v="18" data-xref="帖撒羅尼迦前書 5:21; 申命記 4:8; 雅各書 4:17"> 既從律法中受了教訓，就曉得上帝的旨意，也能分別是非<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或譯：也喜愛那美好的事">a</a></sup>；</span>
<span className="v" id="v19" data-v="19" data-xref="啟示錄 3:17–18; 馬太福音 15:14; 以賽亞書 49:6"> 又深信自己是給瞎子領路的，是黑暗中人的光，</span>
<span className="v" id="v20" data-v="20" data-xref="提摩太後書 3:5; 提多書 1:16; 提摩太後書 1:13"> 是蠢笨人的師傅，是小孩子的先生，在律法上有知識和真理的模範。</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多前書 9:27; 馬太福音 23:3–28; 路加福音 12:47"> 你既是教導別人，還不教導自己嗎？你講說人不可偷竊，自己還偷竊嗎？</span>
<span className="v" id="v22" data-v="22" data-xref="瑪拉基書 3:8; 馬太福音 12:39; 馬可福音 11:17"> 你說人不可姦淫，自己還姦淫嗎？你厭惡偶像，自己還偷竊廟中之物嗎？</span>
<span className="v" id="v23" data-v="23" data-xref="雅各書 4:16–17; 羅馬書 2:17; 羅馬書 3:2"> 你指着律法誇口，自己倒犯律法、玷辱上帝嗎？</span>
<span className="v" id="v24" data-v="24" data-xref="以西結書 36:20–23; 以賽亞書 52:5; 彼得後書 2:2"> 上帝的名在外邦人中，因你們受了褻瀆，正如經上所記的。</span>
<span className="v" id="v25" data-v="25" data-xref="耶利米書 4:4; 加拉太書 5:3–6; 使徒行傳 7:51"> 你若是行律法的，割禮固然於你有益；若是犯律法的，你的割禮就算不得割禮。</span>
<span className="v" id="v26" data-v="26" data-xref="歌羅西書 2:11; 哥林多前書 7:18–19; 羅馬書 8:4"> 所以那未受割禮的，若遵守律法的條例，他雖然未受割禮，豈不算是有割禮嗎？</span>
<span className="v" id="v27" data-v="27" data-xref="馬太福音 12:41–42; 羅馬書 2:29; 哥林多後書 3:6"> 而且那本來未受割禮的，若能全守律法，豈不是要審判你這有儀文和割禮竟犯律法的人嗎？</span>
<span className="v" id="v28" data-v="28" data-xref="加拉太書 6:15; 馬太福音 3:9; 羅馬書 9:6–8"> 因為外面作猶太人的，不是真猶太人；外面肉身的割禮，也不是真割禮。</span>
<span className="v" id="v29" data-v="29" data-xref="申命記 30:6; 腓立比書 3:3; 申命記 10:16"> 惟有裏面作的，才是真猶太人；真割禮也是心裏的，在乎靈，不在乎儀文。這人的稱讚不是從人來的，乃是從上帝來的。</span>
</div>

## 我們的中保基督

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="提摩太前書 2:5; 羅馬書 8:34; 約翰福音 14:6"> 我小子們哪，我將這些話寫給你們，是要叫你們不犯罪。若有人犯罪，在父那裏我們有一位中保，就是那義者耶穌基督。</span>
<span className="v" id="v2" data-v="2" data-xref="約翰一書 4:14; 彼得前書 3:18; 約翰一書 4:10"> 他為我們的罪作了挽回祭，不是單為我們的罪，也是為普天下人的罪。</span>
<span className="v" id="v3" data-v="3" data-xref="約翰福音 14:15; 約翰福音 15:10; 路加福音 6:46"> 我們若遵守他的誡命，就曉得是認識他。</span>
<span className="v" id="v4" data-v="4" data-xref="約翰一書 1:6; 提多書 1:16; 雅各書 2:14–16"> 人若說「我認識他」，卻不遵守他的誡命，便是說謊話的，真理也不在他心裏了。</span>
<span className="v" id="v5" data-v="5" data-xref="約翰福音 14:23; 約翰福音 14:21; 約翰一書 4:12–13"> 凡遵守主道的，愛上帝的心在他裏面實在是完全的。從此，我們知道我們是在主裏面。</span>
<span className="v" id="v6" data-v="6" data-xref="彼得前書 2:21; 約翰福音 13:15; 哥林多前書 11:1"> 人若說他住在主裏面，就該自己照主所行的去行。</span>
</div>
</div>

## 新命令

<div className="bt">
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="約翰一書 3:11; 利未記 19:18; 馬可福音 12:29–34"> 親愛的弟兄啊，我寫給你們的，不是一條新命令，乃是你們從起初所受的舊命令；這舊命令就是你們所聽見的道。</span>
<span className="v" id="v8" data-v="8" data-xref="以弗所書 5:8; 羅馬書 13:12; 約翰福音 13:34"> 再者，我寫給你們的，是一條新命令，在主是真的，在你們也是真的；因為黑暗漸漸過去，真光已經照耀。</span>
<span className="v" id="v9" data-v="9" data-xref="約翰一書 4:20; 約翰一書 2:11; 約翰一書 3:13–17"> 人若說自己在光明中，卻恨他的弟兄，他到如今還是在黑暗裏。</span>
<span className="v" id="v10" data-v="10" data-xref="約翰一書 3:14; 羅馬書 9:32–33; 羅馬書 14:13"> 愛弟兄的，就是住在光明中，在他並沒有絆跌的緣由。</span>
<span className="v" id="v11" data-v="11" data-xref="約翰福音 12:35; 提多書 3:3; 約翰一書 1:6"> 惟獨恨弟兄的，是在黑暗裏，且在黑暗裏行，也不知道往哪裏去，因為黑暗叫他眼睛瞎了。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行傳 10:43; 使徒行傳 13:38; 以弗所書 1:7"> <span className="pl pl-1">小子們哪，我寫信給你們，</span><br /><span className="pl pl-1">因為你們的罪藉着主名得了赦免。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="約翰福音 14:7; 約翰一書 2:14; 路加福音 10:22"> <span className="pl pl-1">父老啊，我寫信給你們，</span><br /><span className="pl pl-1">因為你們認識那從起初原有的。</span><br /><span className="pl pl-1">少年人哪，我寫信給你們，</span><br /><span className="pl pl-1">因為你們勝了那惡者。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="詩篇 119:11; 約翰一書 2:13; 歌羅西書 3:16"> <span className="pl pl-1">小子們哪，我曾寫信給你們，</span><br /><span className="pl pl-1">因為你們認識父。</span><br /><span className="pl pl-1">父老啊，我曾寫信給你們，</span><br /><span className="pl pl-1">因為你們認識那從起初原有的。</span><br /><span className="pl pl-1">少年人哪，我曾寫信給你們；</span><br /><span className="pl pl-1">因為你們剛強，</span><br /><span className="pl pl-1">上帝的道常存在你們心裏；</span><br /><span className="pl pl-1">你們也勝了那惡者。</span></span>
<span className="v" id="v15" data-v="15" data-xref="雅各書 4:4; 羅馬書 12:2; 馬太福音 6:24"> 不要愛世界和世界上的事。人若愛世界，愛父的心就不在他裏面了。</span>
<span className="v" id="v16" data-v="16" data-xref="羅馬書 13:14; 加拉太書 5:17; 詩篇 119:36–37"> 因為，凡世界上的事，就像肉體的情慾、眼目的情慾，並今生的驕傲，都不是從父來的，乃是從世界來的。</span>
<span className="v" id="v17" data-v="17" data-xref="馬太福音 24:35; 羅馬書 12:2; 哥林多前書 7:31"> 這世界和其上的情慾都要過去，惟獨遵行上帝旨意的，是永遠常存。</span>
</div>
</div>

## 敵基督者

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="約翰一書 4:3; 約翰二書 1:7; 馬太福音 24:24"> 小子們哪，如今是末時了。你們曾聽見說，那敵基督的要來；現在已經有好些敵基督的出來了，從此我們就知道如今是末時了。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行傳 20:30; 哥林多前書 11:19; 路加福音 8:13"> 他們從我們中間出去，卻不是屬我們的；若是屬我們的，就必仍舊與我們同在；他們出去，顯明都不是屬我們的。</span>
<span className="v" id="v20" data-v="20" data-xref="約翰福音 14:26; 約翰一書 2:27; 哥林多後書 1:21–22"> 你們從那聖者受了恩膏，並且知道這一切的事<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或譯：都有知識">a</a></sup>。</span>
<span className="v" id="v21" data-v="21" data-xref="彼得後書 1:12; 猶大書 1:5; 箴言 1:5"> 我寫信給你們，不是因你們不知道真理，正是因你們知道，並且知道沒有虛謊是從真理出來的。</span>
<span className="v" id="v22" data-v="22" data-xref="約翰二書 1:7; 約翰一書 4:3; 約翰一書 2:18"> 誰是說謊話的呢？不是那不認耶穌為基督的嗎？不認父與子的，這就是敵基督的。</span>
<span className="v" id="v23" data-v="23" data-xref="約翰一書 4:15; 約翰福音 8:19; 約翰福音 5:23"> 凡不認子的，就沒有父；認子的，連父也有了。</span>
<span className="v" id="v24" data-v="24" data-xref="約翰福音 14:23; 約翰福音 15:9–10; 約翰一書 4:13"> 論到你們，務要將那從起初所聽見的，常存在心裏。若將從起初所聽見的存在心裏，你們就必住在子裏面，也必住在父裏面。</span>
<span className="v" id="v25" data-v="25" data-xref="約翰福音 10:28; 提多書 3:7; 猶大書 1:21"> 主所應許我們的就是永生。</span>
<span className="v" id="v26" data-v="26" data-xref="彼得後書 2:1–3; 約翰二書 1:7; 使徒行傳 20:29–30"> 我將這些話寫給你們，是指着那引誘你們的人說的。</span>
<span className="v" id="v27" data-v="27" data-xref="約翰福音 14:26; 約翰一書 2:20–21; 哥林多前書 2:13"> 你們從主所受的恩膏常存在你們心裏，並不用人教訓你們，自有主的恩膏在凡事上教訓你們。這恩膏是真的，不是假的；你們要按這恩膏的教訓住在主裏面。</span>
</div>
</div>

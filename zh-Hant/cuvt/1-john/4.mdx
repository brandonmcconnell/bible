## 上帝的靈和敵基督者的靈

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="帖撒羅尼迦前書 5:21; 彼得後書 2:1; 提摩太前書 4:1"> 親愛的弟兄啊，一切的靈，你們不可都信，總要試驗那些靈是出於上帝的不是，因為世上有許多假先知已經出來了。</span>
<span className="v" id="v2" data-v="2" data-xref="約翰福音 1:14; 哥林多前書 12:3; 提摩太前書 3:16"> 凡靈認耶穌基督是成了肉身來的，就是出於上帝的；從此你們可以認出上帝的靈來。</span>
<span className="v" id="v3" data-v="3" data-xref="約翰一書 2:22; 約翰二書 1:7; 約翰一書 2:18"> 凡靈不認耶穌，就不是出於上帝，這是那敵基督者的靈。你們從前聽見他要來，現在已經在世上了。</span>
<span className="v" id="v4" data-v="4" data-xref="羅馬書 8:31; 約翰一書 5:4; 羅馬書 8:37"> 小子們哪，你們是屬上帝的，並且勝了他們；因為那在你們裏面的，比那在世界上的更大。</span>
<span className="v" id="v5" data-v="5" data-xref="約翰福音 8:23; 彼得後書 2:2–3; 約翰福音 17:14"> 他們是屬世界的，所以論世界的事，世人也聽從他們。</span>
<span className="v" id="v6" data-v="6" data-xref="約翰福音 14:17; 約翰福音 10:27; 哥林多前書 2:12–14"> 我們是屬上帝的，認識上帝的就聽從我們；不屬上帝的就不聽從我們。從此我們可以認出真理的靈和謬妄的靈來。</span>
</div>
</div>

## 上帝就是愛

<div className="bt">
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="約翰一書 4:20–1; 約翰一書 4:8; 彼得前書 1:22"> 親愛的弟兄啊，我們應當彼此相愛，因為愛是從上帝來的。凡有愛心的，都是由上帝而生，並且認識上帝。</span>
<span className="v" id="v8" data-v="8" data-xref="約翰一書 4:16; 詩篇 86:15; 哥林多後書 13:11"> 沒有愛心的，就不認識上帝，因為上帝就是愛。</span>
<span className="v" id="v9" data-v="9" data-xref="約翰福音 3:16; 約翰一書 5:11; 羅馬書 8:32"> 上帝差他獨生子到世間來，使我們藉着他得生，上帝愛我們的心在此就顯明了。</span>
<span className="v" id="v10" data-v="10" data-xref="以弗所書 2:4–5; 羅馬書 5:8–10; 約翰一書 4:19"> 不是我們愛上帝，乃是上帝愛我們，差他的兒子為我們的罪作了挽回祭，這就是愛了。</span>
<span className="v" id="v11" data-v="11" data-xref="約翰福音 15:12–13; 歌羅西書 3:13; 約翰福音 13:34"> 親愛的弟兄啊，上帝既是這樣愛我們，我們也當彼此相愛。</span>
<span className="v" id="v12" data-v="12" data-xref="約翰福音 1:18; 約翰一書 2:5; 約翰一書 4:17–18"> 從來沒有人見過上帝，我們若彼此相愛，上帝就住在我們裏面，愛他的心在我們裏面得以完全了。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="以弗所書 2:20–22; 約翰一書 3:24; 哥林多前書 3:16–17"> 上帝將他的靈賜給我們，從此就知道我們是住在他裏面，他也住在我們裏面。</span>
<span className="v" id="v14" data-v="14" data-xref="約翰一書 4:10; 約翰福音 3:16–17; 約翰福音 4:42"> 父差子作世人的救主；這是我們所看見且作見證的。</span>
<span className="v" id="v15" data-v="15" data-xref="羅馬書 10:9; 約翰一書 5:5; 馬太福音 10:32"> 凡認耶穌為上帝兒子的，上帝就住在他裏面，他也住在上帝裏面。</span>
<span className="v" id="v16" data-v="16" data-xref="約翰一書 3:24; 詩篇 36:7–9; 約翰一書 3:1"> 上帝愛我們的心，我們也知道也信。<br />上帝就是愛；住在愛裏面的，就是住在上帝裏面，上帝也住在他裏面。</span>
<span className="v" id="v17" data-v="17" data-xref="約翰一書 4:12; 約翰一書 2:28; 羅馬書 8:29"> 這樣，愛在我們裏面得以完全，我們就可以在審判的日子坦然無懼。因為他如何，我們在這世上也如何。</span>
<span className="v" id="v18" data-v="18" data-xref="提摩太後書 1:7; 羅馬書 8:15; 約翰一書 4:12"> 愛裏沒有懼怕；愛既完全，就把懼怕除去。因為懼怕裏含着刑罰，懼怕的人在愛裏未得完全。</span>
<span className="v" id="v19" data-v="19" data-xref="約翰一書 4:10; 約翰福音 3:16; 約翰福音 15:16"> 我們愛，因為上帝先愛我們。</span>
<span className="v" id="v20" data-v="20" data-xref="約翰一書 3:17; 約翰一書 2:9; 約翰一書 4:12"> 人若說「我愛上帝」，卻恨他的弟兄，就是說謊話的；不愛他所看見的弟兄，就不能愛沒有看見的上帝<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古卷：怎能愛沒有看見的上帝呢">a</a></sup>。</span>
<span className="v" id="v21" data-v="21" data-xref="馬太福音 22:37–39; 利未記 19:18; 約翰一書 3:11"> 愛上帝的，也當愛弟兄，這是我們從上帝所受的命令。</span>
</div>
</div>

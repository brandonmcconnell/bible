## 利未的後裔

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 46:11; 出埃及記 6:16; 民數記 26:57"> 利未的兒子是革順、哥轄、米拉利。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 6:18; 出埃及記 6:21–24; 歷代志上 23:12"> 哥轄的兒子是暗蘭、以斯哈、希伯倫、烏薛。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 6:20; 利未記 10:1; 利未記 10:12"> 暗蘭的兒子是亞倫、摩西，還有女兒米利暗。亞倫的兒子是拿答、亞比戶、以利亞撒、以他瑪。</span>
<span className="v" id="v4" data-v="4" data-xref="歷代志上 6:50; 出埃及記 6:25; 以斯拉記 7:1–5"> 以利亞撒生非尼哈；非尼哈生亞比書；</span>
<span className="v" id="v5" data-v="5"> 亞比書生布基；布基生烏西；</span>
<span className="v" id="v6" data-v="6"> 烏西生西拉希雅；西拉希雅生米拉約；</span>
<span className="v" id="v7" data-v="7"> 米拉約生亞瑪利雅；亞瑪利雅生亞希突；</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳記下 8:17; 撒母耳記下 15:27; 列王紀上 1:44"> 亞希突生撒督；撒督生亞希瑪斯；</span>
<span className="v" id="v9" data-v="9"> 亞希瑪斯生亞撒利雅；亞撒利雅生約哈難；</span>
<span className="v" id="v10" data-v="10" data-xref="歷代志下 3:4; 歷代志下 3:1; 列王紀上 6:1–7"> 約哈難生亞撒利雅（這亞撒利雅在所羅門於耶路撒冷所建造的殿中，供祭司的職分）；</span>
<span className="v" id="v11" data-v="11" data-xref="以斯拉記 7:3"> 亞撒利雅生亞瑪利雅；亞瑪利雅生亞希突；</span>
<span className="v" id="v12" data-v="12" data-xref="尼希米記 11:11; 歷代志上 9:11"> 亞希突生撒督；撒督生沙龍；</span>
<span className="v" id="v13" data-v="13" data-xref="歷代志下 35:8; 列王紀下 22:12–14; 列王紀下 22:4"> 沙龍生希勒家；希勒家生亞撒利雅；</span>
<span className="v" id="v14" data-v="14" data-xref="列王紀下 25:18; 尼希米記 11:11; 撒迦利亞書 6:11"> 亞撒利雅生西萊雅；西萊雅生約薩答。</span>
<span className="v" id="v15" data-v="15" data-xref="哈該書 2:2; 列王紀下 25:18; 哈該書 1:1"> 當耶和華藉尼布甲尼撒的手擄掠猶大和耶路撒冷人的時候，這約薩答也被擄去。</span>

## 利未的其餘後裔

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="出埃及記 6:16; 歷代志上 6:1"> 利未的兒子是革順、哥轄、米拉利。</span>
<span className="v" id="v17" data-v="17" data-xref="歷代志上 23:7; 民數記 3:18; 民數記 3:21"> 革順的兒子名叫立尼、示每。</span>
<span className="v" id="v18" data-v="18" data-xref="歷代志上 23:12; 歷代志上 6:2–3"> 哥轄的兒子是暗蘭、以斯哈、希伯倫、烏薛。</span>
<span className="v" id="v19" data-v="19" data-xref="歷代志上 23:21; 歷代志上 24:26; 出埃及記 6:19"> 米拉利的兒子是抹利、母示。這是按着利未人宗族分的各家。</span>
<span className="v" id="v20" data-v="20" data-xref="歷代志上 6:43"> 革順的兒子是立尼；立尼的兒子是雅哈；雅哈的兒子是薪瑪；</span>
<span className="v" id="v21" data-v="21"> 薪瑪的兒子是約亞；約亞的兒子是易多；易多的兒子是謝拉；謝拉的兒子是耶特賴。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及記 6:24; 歷代志上 6:18; 歷代志上 6:2"> 哥轄的兒子是亞米拿達；亞米拿達的兒子是可拉；可拉的兒子是亞惜；</span>
<span className="v" id="v23" data-v="23"> 亞惜的兒子是以利加拿；以利加拿的兒子是以比雅撒；以比雅撒的兒子是亞惜；</span>
<span className="v" id="v24" data-v="24"> 亞惜的兒子是他哈；他哈的兒子是烏列；烏列的兒子是烏西雅；烏西雅的兒子是少羅。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及記 6:24; 歷代志上 6:35–36"> 以利加拿的兒子是亞瑪賽和亞希摩。</span>
<span className="v" id="v26" data-v="26" data-xref="撒母耳記上 1:1; 歷代志上 6:35"> 亞希摩的兒子是以利加拿；以利加拿的兒子是瑣菲；瑣菲的兒子是拿哈；</span>
<span className="v" id="v27" data-v="27" data-xref="撒母耳記上 1:1; 撒母耳記上 1:19–20"> 拿哈的兒子是以利押；以利押的兒子是耶羅罕；耶羅罕的兒子是以利加拿；以利加拿的兒子是撒母耳。</span>
<span className="v" id="v28" data-v="28" data-xref="歷代志上 6:33; 撒母耳記上 8:2"> 撒母耳的長子是約珥，次子是亞比亞。</span>
<span className="v" id="v29" data-v="29" data-xref="歷代志上 6:19; 民數記 3:33"> 米拉利的兒子是抹利；抹利的兒子是立尼；立尼的兒子是示每；示每的兒子是烏撒；</span>
<span className="v" id="v30" data-v="30"> 烏撒的兒子是示米亞；示米亞的兒子是哈基雅；哈基雅的兒子是亞帥雅。</span>
</div>

## 聖殿中的歌者

<div className="bt">
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="撒母耳記下 6:17; 歷代志上 15:25–1; 歷代志上 15:16–22"> 約櫃安設之後，大衛派人在耶和華殿中管理歌唱的事。</span>
<span className="v" id="v32" data-v="32" data-xref="詩篇 135:1–3; 列王紀上 8:6–13; 以斯拉記 6:18"> 他們就在會幕前當歌唱的差，及至所羅門在耶路撒冷建造了耶和華的殿，他們便按着班次供職。</span>
<span className="v" id="v33" data-v="33" data-xref="歷代志上 6:28; 歷代志上 15:17; 歷代志上 25:1–5"> 供職的人和他們的子孫記在下面： 哥轄的子孫中有歌唱的希幔。希幔是約珥的兒子；約珥是撒母耳的兒子；</span>
<span className="v" id="v34" data-v="34"> 撒母耳是以利加拿的兒子；以利加拿是耶羅罕的兒子；耶羅罕是以列的兒子；以列是陀亞的兒子；</span>
<span className="v" id="v35" data-v="35"> 陀亞是蘇弗的兒子；蘇弗是以利加拿的兒子；以利加拿是瑪哈的兒子；瑪哈是亞瑪賽的兒子；</span>
<span className="v" id="v36" data-v="36"> 亞瑪賽是以利加拿的兒子；以利加拿是約珥的兒子；約珥是亞撒利雅的兒子；亞撒利雅是西番雅的兒子；</span>
<span className="v" id="v37" data-v="37" data-xref="詩篇 45:1; 民數記 26:10–11; 出埃及記 6:21–24"> 西番雅是他哈的兒子；他哈是亞惜的兒子；亞惜是以比雅撒的兒子；以比雅撒是可拉的兒子；</span>
<span className="v" id="v38" data-v="38" data-xref="民數記 3:19; 歷代志上 16:1"> 可拉是以斯哈的兒子；以斯哈是哥轄的兒子；哥轄是利未的兒子；利未是以色列的兒子。</span>
<span className="v" id="v39" data-v="39" data-xref="尼希米記 7:44; 以斯拉記 2:41; 詩篇 75:1"> 希幔的族兄亞薩是比利家的兒子，亞薩在希幔右邊供職。比利家是示米亞的兒子；</span>
<span className="v" id="v40" data-v="40"> 示米亞是米迦勒的兒子；米迦勒是巴西雅的兒子；巴西雅是瑪基雅的兒子；</span>
<span className="v" id="v41" data-v="41"> 瑪基雅是伊特尼的兒子；伊特尼是謝拉的兒子；謝拉是亞大雅的兒子；</span>
<span className="v" id="v42" data-v="42"> 亞大雅是以探的兒子；以探是薪瑪的兒子；薪瑪是示每的兒子；</span>
<span className="v" id="v43" data-v="43" data-xref="出埃及記 6:16; 歷代志上 6:16–17; 創世記 46:11"> 示每是雅哈的兒子；雅哈是革順的兒子。革順是利未的兒子。</span>
<span className="v" id="v44" data-v="44" data-xref="詩篇 89:1; 歷代志上 15:17; 歷代志上 25:1"> 他們的族弟兄米拉利的子孫，在他們左邊供職的有以探。以探是基示的兒子；基示是亞伯底的兒子；亞伯底是瑪鹿的兒子；</span>
<span className="v" id="v45" data-v="45"> 瑪鹿是哈沙比雅的兒子；哈沙比雅是亞瑪謝的兒子；亞瑪謝是希勒家的兒子；</span>
<span className="v" id="v46" data-v="46"> 希勒家是暗西的兒子；暗西是巴尼的兒子；巴尼是沙麥的兒子；</span>
<span className="v" id="v47" data-v="47" data-xref="約書亞記 21:7; 出埃及記 6:19; 歷代志上 23:21"> 沙麥是末力的兒子；末力是母示的兒子；母示是米拉利的兒子；米拉利是利未的兒子。</span>
<span className="v" id="v48" data-v="48" data-xref="歷代志上 23:2; 民數記 3:1–4; 民數記 18:1–32"> 他們的族弟兄利未人也被派辦上帝殿中的一切事。</span>
</div>
</div>

## 亞倫的後裔

<div className="bt">
<div className="bp">
<span className="v" id="v49" data-v="49" data-xref="利未記 4:20; 出埃及記 27:1–8; 出埃及記 30:1–7"> 亞倫和他的子孫在燔祭壇和香壇上獻祭燒香，又在至聖所辦理一切的事，為以色列人贖罪，是照上帝僕人摩西所吩咐的。</span>
<span className="v" id="v50" data-v="50" data-xref="利未記 10:16; 歷代志上 24:1; 民數記 20:26–28"> 亞倫的兒子是以利亞撒；以利亞撒的兒子是非尼哈；非尼哈的兒子是亞比書；</span>
<span className="v" id="v51" data-v="51"> 亞比書的兒子是布基；布基的兒子是烏西；烏西的兒子是西拉希雅；</span>
<span className="v" id="v52" data-v="52"> 西拉希雅的兒子是米拉約；米拉約的兒子是亞瑪利雅；亞瑪利雅的兒子是亞希突；</span>
<span className="v" id="v53" data-v="53" data-xref="撒母耳記下 8:17; 以西結書 44:15; 撒母耳記下 15:35–36"> 亞希突的兒子是撒督；撒督的兒子是亞希瑪斯。</span>

## 利未支派的居地

<div className="bt">
<div className="bp">
<span className="v" id="v54" data-v="54" data-xref="創世記 25:16; 約書亞記 21:10; 約書亞記 21:3–8"> 他們的住處按着境內的營寨，記在下面：哥轄族亞倫的子孫先拈鬮得地，</span>
<span className="v" id="v55" data-v="55" data-xref="約書亞記 14:13; 約書亞記 21:11–13; 約書亞記 15:13"> 在猶大地中得了希伯崙和四圍的郊野；</span>
<span className="v" id="v56" data-v="56" data-xref="約書亞記 15:13; 約書亞記 14:13"> 只是屬城的田地和村莊都為耶孚尼的兒子迦勒所得。</span>
<span className="v" id="v57" data-v="57" data-xref="約書亞記 21:13–14; 約書亞記 15:48; 約書亞記 10:29"> 亞倫的子孫得了逃城希伯崙，又得了立拿與其郊野，雅提珥、以實提莫與其郊野；</span>
<span className="v" id="v58" data-v="58" data-xref="約書亞記 10:3; 約書亞記 15:49; 約書亞記 12:13"> 希崙與其郊野，底璧與其郊野，</span>
<span className="v" id="v59" data-v="59" data-xref="約書亞記 21:16; 約書亞記 15:42; 撒母耳記上 6:12–19"> 亞珊與其郊野，伯‧示麥與其郊野。</span>
<span className="v" id="v60" data-v="60" data-xref="耶利米書 1:1; 列王紀上 2:26; 耶利米書 11:23"> 在便雅憫支派的地中，得了迦巴與其郊野，阿勒篾與其郊野，亞拿突與其郊野。他們諸家所得的城共十三座。</span>
<span className="v" id="v61" data-v="61" data-xref="約書亞記 21:4–5; 歷代志上 6:18; 約書亞記 21:20–26"> 哥轄族其餘的人又拈鬮，在瑪拿西半支派的地中得了十座城。</span>
<span className="v" id="v62" data-v="62" data-xref="約書亞記 21:27–33; 歷代志上 6:71–76; 出埃及記 2:22"> 革順族按着宗族，在以薩迦支派的地中，亞設支派的地中，拿弗他利支派的地中，巴珊內瑪拿西支派的地中，得了十三座城。</span>
<span className="v" id="v63" data-v="63" data-xref="約書亞記 21:7; 約書亞記 21:34–40; 民數記 3:20"> 米拉利族按着宗族拈鬮，在呂便支派的地中，迦得支派的地中，西布倫支派的地中，得了十二座城。</span>
<span className="v" id="v64" data-v="64" data-xref="約書亞記 21:41–42; 約書亞記 21:3; 民數記 35:1–8"> 以色列人將這些城與其郊野給了利未人。</span>
<span className="v" id="v65" data-v="65" data-xref="歷代志上 6:57–60"> 這以上錄名的城，在猶大、西緬、便雅憫三支派的地中，以色列人拈鬮給了他們。</span>
<span className="v" id="v66" data-v="66" data-xref="約書亞記 21:20–26"> 哥轄族中有幾家在以法蓮支派的地中也得了城邑，</span>
<span className="v" id="v67" data-v="67" data-xref="約書亞記 21:21; 創世記 33:18; 創世記 35:4"> 在以法蓮山地得了逃城示劍與其郊野，又得了基色與其郊野，</span>
<span className="v" id="v68" data-v="68" data-xref="約書亞記 21:22; 約書亞記 16:5; 撒母耳記上 13:18"> 約緬與其郊野，伯‧和崙與其郊野，</span>
<span className="v" id="v69" data-v="69" data-xref="約書亞記 10:12; 約書亞記 21:24–25"> 亞雅崙與其郊野，迦特‧臨門與其郊野。</span>
<span className="v" id="v70" data-v="70" data-xref="約書亞記 21:25; 約書亞記 17:11"> 哥轄族其餘的人在瑪拿西半支派的地中得了亞乃與其郊野，比連與其郊野。</span>
<span className="v" id="v71" data-v="71" data-xref="約書亞記 21:27; 約書亞記 9:10; 約書亞記 20:8"> 革順族在瑪拿西半支派的地中得了巴珊的哥蘭與其郊野，亞斯他錄與其郊野；</span>
<span className="v" id="v72" data-v="72" data-xref="約書亞記 21:28–29; 約書亞記 21:32; 約書亞記 19:37"> 又在以薩迦支派的地中得了基低斯與其郊野，大比拉與其郊野，</span>
<span className="v" id="v73" data-v="73"> 拉末與其郊野，亞年與其郊野；</span>
<span className="v" id="v74" data-v="74" data-xref="約書亞記 19:26; 約書亞記 21:30"> 在亞設支派的地中得了瑪沙與其郊野，押頓與其郊野，</span>
<span className="v" id="v75" data-v="75" data-xref="約書亞記 21:31"> 戶割與其郊野，利合與其郊野；</span>
<span className="v" id="v76" data-v="76" data-xref="約書亞記 21:32; 約書亞記 19:37; 士師記 4:6"> 在拿弗他利支派的地中得了加利利的基低斯與其郊野，哈們與其郊野，基列亭與其郊野。</span>
<span className="v" id="v77" data-v="77" data-xref="約書亞記 21:34–35"> 還有米拉利族的人在西布倫支派的地中得了臨摩挪與其郊野，他泊與其郊野；</span>
<span className="v" id="v78" data-v="78" data-xref="約書亞記 20:8; 約書亞記 21:36–37; 申命記 4:41–43"> 又在耶利哥的約旦河東，在呂便支派的地中得了曠野的比悉與其郊野，雅哈撒與其郊野，</span>
<span className="v" id="v79" data-v="79"> 基底莫與其郊野，米法押與其郊野；</span>
<span className="v" id="v80" data-v="80" data-xref="創世記 32:2; 列王紀下 9:1; 約書亞記 21:38–39"> 又在迦得支派的地中得了基列的拉末與其郊野，瑪哈念與其郊野，</span>
<span className="v" id="v81" data-v="81" data-xref="約書亞記 21:39; 民數記 21:32; 民數記 32:3"> 希實本與其郊野，雅謝與其郊野。</span>

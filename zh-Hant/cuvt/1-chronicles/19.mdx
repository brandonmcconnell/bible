## 大衛擊敗亞捫人和亞蘭人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳記上 11:1–2; 撒母耳記下 10:1–19; 撒母耳記上 12:12"> 此後，亞捫人的王拿轄死了，他兒子接續他作王。</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 23:3–6; 撒母耳記上 30:26; 創世記 19:37–38"> 大衛說：「我要照哈嫩的父親拿轄厚待我的恩典厚待哈嫩。」於是大衛差遣使者為他喪父安慰他。大衛的臣僕到了亞捫人的境內見哈嫩，要安慰他，</span>
<span className="v" id="v3" data-v="3" data-xref="士師記 1:23–24; 哥林多前書 13:5–7; 列王紀上 12:8–11"> 但亞捫人的首領對哈嫩說：「大衛差人來安慰你，你想他是尊敬你父親嗎？他的臣僕來見你不是為詳察窺探、傾覆這地嗎？」</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳記下 10:4–5; 以賽亞書 15:2; 馬可福音 12:4"> 哈嫩便將大衛臣僕的鬍鬚剃去一半，又割斷他們下半截的衣服，使他們露出下體，打發他們回去。</span>
<span className="v" id="v5" data-v="5" data-xref="約書亞記 6:24–26; 馬太福音 18:31; 列王紀上 16:34"> 有人將臣僕所遇的事告訴大衛，他就差人去迎接他們，因為他們甚覺羞恥；告訴他們說：「可以住在耶利哥，等到鬍鬚長起再回來。」</span>
<span className="v" id="v6" data-v="6" data-xref="歷代志上 18:5; 創世記 34:30; 歷代志上 18:9"> 亞捫人知道大衛憎惡他們，哈嫩和亞捫人就打發人拿一千他連得銀子，從美索不達米亞、亞蘭、瑪迦、瑣巴雇戰車和馬兵，</span>
<span className="v" id="v7" data-v="7" data-xref="民數記 21:30; 約書亞記 13:9; 約書亞記 13:16"> 於是雇了三萬二千輛戰車和瑪迦王並他的軍兵；他們來安營在米底巴前。亞捫人也從他們的城裏出來，聚集交戰。</span>
<span className="v" id="v8" data-v="8" data-xref="歷代志上 11:6; 歷代志上 11:10–47; 撒母耳記下 23:8–39"> 大衛聽見了，就差派約押統帶勇猛的全軍出去。</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀上 20:1; 列王紀上 20:24; 以賽亞書 28:6"> 亞捫人出來在城門前擺陣，所來的諸王另在郊野擺陣。</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳記下 10:9–14; 士師記 20:42–43; 約書亞記 8:22"> 約押看見敵人在他前後擺陣，就從以色列軍中挑選精兵，使他們對着亞蘭人擺陣；</span>
<span className="v" id="v11" data-v="11" data-xref="歷代志上 18:12; 歷代志上 11:20; 歷代志上 19:9"> 其餘的兵交與他兄弟亞比篩，對着亞捫人擺陣。</span>
<span className="v" id="v12" data-v="12" data-xref="腓立比書 1:27–28; 尼希米記 4:20; 傳道書 4:9–12"> 約押對亞比篩說：「亞蘭人若強過我，你就來幫助我；亞捫人若強過你，我就去幫助你。</span>
<span className="v" id="v13" data-v="13" data-xref="尼希米記 4:14; 詩篇 27:14; 撒母耳記下 10:12"> 我們都當剛強，為本國的民和上帝的城邑作大丈夫，願耶和華憑他的意旨而行。」</span>
<span className="v" id="v14" data-v="14" data-xref="列王紀上 20:19–21; 歷代志下 13:5–16; 耶利米書 46:15–16"> 於是約押和跟隨他的人前進攻打亞蘭人；亞蘭人在約押面前逃跑。</span>
<span className="v" id="v15" data-v="15" data-xref="羅馬書 8:31; 利未記 26:7"> 亞捫人見亞蘭人逃跑，他們也在約押的兄弟亞比篩面前逃跑進城。約押就回耶路撒冷去了。</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳記下 10:16; 撒迦利亞書 14:1–3; 彌迦書 4:11–12"> 亞蘭人見自己被以色列人打敗，就打發使者將大河那邊的亞蘭人調來，哈大利謝的將軍朔法率領他們。</span>
<span className="v" id="v17" data-v="17" data-xref="以賽亞書 22:6–7; 歷代志上 19:9"> 有人告訴大衛，他就聚集以色列眾人過約旦河，來到亞蘭人那裏，迎着他們擺陣。大衛既擺陣攻擊亞蘭人，亞蘭人就與他打仗。</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳記下 10:18; 詩篇 33:16; 詩篇 18:32"> 亞蘭人在以色列人面前逃跑。大衛殺了亞蘭七千輛戰車的人，四萬步兵，又殺了亞蘭的將軍朔法。</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳記下 10:19; 約書亞記 9:9–11; 列王紀上 20:1"> 屬哈大利謝的諸王見自己被以色列人打敗，就與大衛和好，歸服他。於是亞蘭人不敢再幫助亞捫人了。</span>

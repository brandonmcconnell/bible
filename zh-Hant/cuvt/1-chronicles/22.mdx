## 籌備建殿

<div className="bt">
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="歷代志下 2:17; 列王紀上 9:20–21; 列王紀上 5:17–18"> 大衛吩咐聚集住以色列地的外邦人，從其中派石匠鑿石頭，要建造上帝的殿。</span>
<span className="v" id="v3" data-v="3" data-xref="歷代志上 22:14; 歷代志上 29:2; 列王紀上 7:47"> 大衛預備許多鐵做門上的釘子和鉤子，又預備許多銅，多得無法可稱；</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀上 5:6–10; 以斯拉記 3:7; 歷代志下 2:3"> 又預備無數的香柏木，因為西頓人和泰爾人給大衛運了許多香柏木來。</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀上 3:7; 歷代志上 29:1; 約翰福音 3:30"> 大衛說：「我兒子所羅門還年幼嬌嫩，要為耶和華建造的殿宇必須高大輝煌，使名譽榮耀傳遍萬國；所以我要為殿預備材料。」於是，大衛在未死之先預備的材料甚多。</span>
<span className="v" id="v6" data-v="6" data-xref="民數記 27:23; 使徒行傳 20:25–31; 使徒行傳 1:2"> 大衛召了他兒子所羅門來，囑咐他給耶和華－以色列的上帝建造殿宇，</span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 132:5; 列王紀上 8:16–20; 歷代志下 6:7–9"> 對所羅門說：「我兒啊，我心裏本想為耶和華－我上帝的名建造殿宇，</span>
<span className="v" id="v8" data-v="8" data-xref="列王紀上 5:3; 歷代志上 28:3; 歷代志上 17:4–10"> 只是耶和華的話臨到我說：『你流了多人的血，打了多次大仗，你不可為我的名建造殿宇，因為你在我眼前使多人的血流在地上。</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀上 4:25; 列王紀上 5:4; 列王紀上 4:20"> 你要生一個兒子，他必作太平的人；我必使他安靜，不被四圍的仇敵擾亂。他的名要叫所羅門<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="就是太平的意思">a</a></sup>。他在位的日子，我必使以色列人平安康泰。</span>
<span className="v" id="v10" data-v="10" data-xref="希伯來書 1:5; 撒母耳記下 7:13–14; 歷代志上 17:12–14"> 他必為我的名建造殿宇。他要作我的子；我要作他的父。他作以色列王；我必堅定他的國位，直到永遠。』</span>
<span className="v" id="v11" data-v="11" data-xref="歷代志上 22:16; 歷代志上 28:20; 提摩太後書 4:22"> 我兒啊，現今願耶和華與你同在，使你亨通，照他指着你說的話，建造耶和華－你上帝的殿。</span>
<span className="v" id="v12" data-v="12" data-xref="雅各書 1:5; 箴言 14:8; 列王紀上 3:9–12"> 但願耶和華賜你聰明智慧，好治理以色列國，遵行耶和華－你上帝的律法。</span>
<span className="v" id="v13" data-v="13" data-xref="約書亞記 1:6–9; 歷代志上 28:20; 歷代志上 28:7"> 你若謹守遵行耶和華藉摩西吩咐以色列的律例典章，就得亨通。你當剛強壯膽，不要懼怕，也不要驚惶。</span>
<span className="v" id="v14" data-v="14" data-xref="歷代志上 22:3; 列王紀下 25:16; 歷代志上 29:4–7"> 我在困難之中為耶和華的殿預備了金子十萬他連得，銀子一百萬他連得，銅和鐵多得無法可稱；我也預備了木頭、石頭，你還可以增添。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及記 28:6; 出埃及記 35:32; 列王紀上 7:14"> 你有許多匠人，就是石匠、木匠，和一切能做各樣工的巧匠，</span>
<span className="v" id="v16" data-v="16" data-xref="歷代志上 22:11; 腓立比書 4:13; 以弗所書 5:14"> 並有無數的金銀銅鐵。你當起來辦事，願耶和華與你同在。」</span>
<span className="v" id="v17" data-v="17" data-xref="歷代志上 28:1–6; 約翰三書 1:8; 歷代志上 29:6"> 大衛又吩咐以色列的眾首領幫助他兒子所羅門，說：</span>
<span className="v" id="v18" data-v="18" data-xref="歷代志上 22:9; 歷代志上 23:25; 撒母耳記下 7:1"> 「耶和華－你們的上帝不是與你們同在嗎？不是叫你們四圍都平安嗎？因他已將這地的居民交在我手中，這地就在耶和華與他百姓面前制伏了。</span>
<span className="v" id="v19" data-v="19" data-xref="歷代志上 28:9; 申命記 4:29; 歷代志上 16:11"> 現在你們應當立定心意，尋求耶和華－你們的神；也當起來建造耶和華上帝的聖所，好將耶和華的約櫃和供奉上帝的聖器皿都搬進為耶和華名建造的殿裏。」</span>

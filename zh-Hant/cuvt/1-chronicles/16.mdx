## 頌讚之歌

<div className="bt">
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="詩篇 105:1–15; 以賽亞書 12:4; 列王紀下 19:19"> <span className="pl pl-1">你們要稱謝耶和華，求告他的名，</span><br /><span className="pl pl-1">在萬民中傳揚他的作為！</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="歌羅西書 3:16; 詩篇 96:1–3; 詩篇 98:1–4"> <span className="pl pl-1">要向他唱詩、歌頌，</span><br /><span className="pl pl-1">談論他一切奇妙的作為。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="馬太福音 7:7–8; 耶利米書 29:13; 詩篇 34:2"> <span className="pl pl-1">要以他的聖名誇耀；</span><br /><span className="pl pl-1">尋求耶和華的人，心中應當歡喜。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 27:8–9; 西番雅書 2:2–3; 詩篇 68:35"> <span className="pl pl-1">要尋求耶和華與他的能力，</span><br /><span className="pl pl-1">時常尋求他的面。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 111:4; 詩篇 119:20; 詩篇 103:2"> <span className="pl pl-1">他僕人以色列的後裔，</span><br /><span className="pl pl-1">他所揀選雅各的子孫哪，</span><br /><span className="pl pl-1">你們要記念他奇妙的作為和他的奇事，</span><br /><span className="pl pl-1">並他口中的判語。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="詩篇 48:10–11; 以賽亞書 26:9; 出埃及記 15:2"> <span className="pl pl-1">他是耶和華－我們的上帝，</span><br /><span className="pl pl-1">全地都有他的判斷。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 105:8; 瑪拉基書 4:4; 申命記 7:9"> <span className="pl pl-1">你們要記念他的約，直到永遠；</span><br /><span className="pl pl-1">他所吩咐的話，直到千代，</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="創世記 26:3; 創世記 17:2; 創世記 35:11"> <span className="pl pl-1">就是與亞伯拉罕所立的約，</span><br /><span className="pl pl-1">向以撒所起的誓。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="創世記 17:7–8; 創世記 35:11–12; 約書亞記 24:11–13"> <span className="pl pl-1">他又將這約向雅各定為律例，</span><br /><span className="pl pl-1">向以色列定為永遠的約，</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="創世記 13:15; 彌迦書 2:5; 創世記 17:8"> <span className="pl pl-1">說：我必將迦南地賜給你，</span><br /><span className="pl pl-1">作你產業的分。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v19" data-v="19" data-xref="創世記 34:30; 申命記 7:7; 使徒行傳 7:5"> <span className="pl pl-1">當時你們人丁有限，數目稀少，</span><br /><span className="pl pl-1">並且在那地為寄居的；</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="創世記 46:6; 創世記 20:1; 創世記 46:3"> <span className="pl pl-1">他們從這邦游到那邦，</span><br /><span className="pl pl-1">從這國行到那國。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="創世記 12:17; 創世記 20:3; 出埃及記 7:15–18"> <span className="pl pl-1">耶和華不容甚麼人欺負他們，</span><br /><span className="pl pl-1">為他們的緣故責備君王，</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="創世記 20:7; 詩篇 105:15; 創世記 49:8–10"> <span className="pl pl-1">說：不可難為我受膏的人，</span><br /><span className="pl pl-1">也不可惡待我的先知！</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v23" data-v="23" data-xref="詩篇 96:1–13; 詩篇 71:15; 以賽亞書 51:6–8"> <span className="pl pl-1">全地都要向耶和華歌唱！</span><br /><span className="pl pl-1">天天傳揚他的救恩，</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="以賽亞書 12:2–6; 但以理書 4:1–3; 詩篇 22:27"> <span className="pl pl-1">在列邦中述說他的榮耀，</span><br /><span className="pl pl-1">在萬民中述說他的奇事。</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="詩篇 89:7; 詩篇 76:7; 詩篇 66:3–5"> <span className="pl pl-1">因耶和華為大，當受極大的讚美；</span><br /><span className="pl pl-1">他在萬神之上，當受敬畏。</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="詩篇 102:25; 利未記 19:4; 以賽亞書 42:5"> <span className="pl pl-1">外邦的神都屬虛無，</span><br /><span className="pl pl-1">惟獨耶和華創造諸天。</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="詩篇 16:11; 詩篇 96:6; 詩篇 28:7–8"> <span className="pl pl-1">有尊榮和威嚴在他面前，</span><br /><span className="pl pl-1">有能力和喜樂在他聖所。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v28" data-v="28" data-xref="哥林多前書 15:10; 腓立比書 4:13; 詩篇 100:1–2"> <span className="pl pl-1">民中的萬族啊，</span><br /><span className="pl pl-1">你們要將榮耀能力歸給耶和華，都歸給耶和華！</span><br /></span>
<span className="v" id="v29" data-v="29" data-xref="詩篇 100:4; 詩篇 96:9; 以賽亞書 6:3"> <span className="pl pl-1">要將耶和華的名所當得的榮耀歸給他，</span><br /><span className="pl pl-1">拿供物來奉到他面前；</span><br /><span className="pl pl-1">當以聖潔的</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="的：或譯為">a</a></sup><br /><span className="pl pl-1">妝飾敬拜耶和華。</span><br /></span>
<span className="v" id="v30" data-v="30" data-xref="詩篇 33:9; 詩篇 148:5–6; 希伯來書 1:3"> <span className="pl pl-1">全地要在他面前顫抖，</span><br /><span className="pl pl-1">世界也堅定不得動搖。</span><br /></span>
<span className="v" id="v31" data-v="31" data-xref="詩篇 96:10; 啟示錄 19:6; 詩篇 97:1"> <span className="pl pl-1">願天歡喜，願地快樂；</span><br /><span className="pl pl-1">願人在列邦中說：</span><br /><span className="pl pl-1">耶和華作王了！</span><br /></span>
<span className="v" id="v32" data-v="32" data-xref="詩篇 148:9–10; 以賽亞書 44:23; 詩篇 98:7–8"> <span className="pl pl-1">願海和其中所充滿的澎湃；</span><br /><span className="pl pl-1">願田和其中所有的都歡樂。</span><br /></span>
<span className="v" id="v33" data-v="33" data-xref="詩篇 98:9; 詩篇 96:12–13; 啟示錄 11:17–18"> <span className="pl pl-1">那時，林中的樹木都要在耶和華面前歡呼，</span><br /><span className="pl pl-1">因為他來要審判全地。</span><br /></span>
<span className="v" id="v34" data-v="34" data-xref="詩篇 106:1; 歷代志下 7:3; 詩篇 107:1"> <span className="pl pl-1">應當稱謝耶和華；</span><br /><span className="pl pl-1">因他本為善，他的慈愛永遠長存！</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v35" data-v="35" data-xref="詩篇 106:47–48; 彼得前書 2:9; 詩篇 14:7"> <span className="pl pl-1">要說：拯救我們的上帝啊，求你救我們，</span><br /><span className="pl pl-1">聚集我們，使我們脫離外邦，</span><br /><span className="pl pl-1">我們好稱讚你的聖名，以讚美你為誇勝。</span><br /></span>
<span className="v" id="v36" data-v="36" data-xref="列王紀上 8:15; 詩篇 72:18–19; 列王紀上 8:56"> <span className="pl pl-1">耶和華－以色列的上帝，</span><br /><span className="pl pl-1">從亙古直到永遠，是應當稱頌的！</span><br /><span className="pl pl-1">眾民都說：「阿們！」並且讚美耶和華。</span></span>

## 在耶路撒冷和基遍的敬拜

<div className="bt">
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="歷代志下 8:14; 以斯拉記 3:4; 歷代志上 16:4–6"> 大衛派亞薩和他的弟兄在約櫃前常常事奉耶和華，一日盡一日的職分；</span>
<span className="v" id="v38" data-v="38" data-xref="歷代志上 26:10; 歷代志上 13:14; 歷代志上 25:3"> 又派俄別‧以東和他的弟兄六十八人，與耶杜頓的兒子俄別‧以東，並何薩作守門的；</span>
<span className="v" id="v39" data-v="39" data-xref="列王紀上 3:4; 歷代志上 15:11; 歷代志下 1:3–4"> 且派祭司撒督和他弟兄眾祭司在基遍的邱壇、耶和華的帳幕前燔祭壇上，每日早晚，照着耶和華律法書上所吩咐以色列人的，常給耶和華獻燔祭。</span>
<span className="v" id="v41" data-v="41" data-xref="歷代志下 5:13; 歷代志上 25:1–6; 歷代志下 20:21"> 與他們一同被派的有希幔、耶杜頓，和其餘被選名字錄在冊上的，稱謝耶和華，因他的慈愛永遠長存。</span>
<span className="v" id="v42" data-v="42" data-xref="詩篇 150:3–6; 歷代志上 25:6–7; 歷代志下 29:25–28"> 希幔、耶杜頓同着他們吹號、敲鈸，大發響聲，並用別的樂器隨着歌頌上帝。耶杜頓的子孫作守門的。</span>
<span className="v" id="v43" data-v="43" data-xref="撒母耳記下 6:19–20; 創世記 18:19; 詩篇 101:2"> 於是眾民各歸各家；大衛也回去為家眷祝福。</span>

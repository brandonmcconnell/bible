## 祭司的職務

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歷代志上 23:6; 出埃及記 6:23; 民數記 26:60"> 亞倫子孫的班次記在下面：亞倫的兒子是拿答、亞比戶、以利亞撒、以他瑪。</span>
<span className="v" id="v2" data-v="2" data-xref="利未記 10:2; 民數記 3:4; 民數記 26:61"> 拿答、亞比戶死在他們父親之先，沒有留下兒子；故此，以利亞撒、以他瑪供祭司的職分。</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳記下 8:17; 歷代志上 24:31; 撒母耳記上 21:1"> 以利亞撒的子孫撒督和以他瑪的子孫亞希米勒，同着大衛將他們的族弟兄分成班次。</span>
<span className="v" id="v4" data-v="4" data-xref="歷代志上 23:24; 民數記 25:11–13; 歷代志上 15:6–12"> 以利亞撒子孫中為首的比以他瑪子孫中為首的更多，分班如下：以利亞撒的子孫中有十六個族長，以他瑪的子孫中有八個族長；</span>
<span className="v" id="v5" data-v="5" data-xref="歷代志上 24:31; 約書亞記 18:10; 使徒行傳 4:1"> 都掣籤分立，彼此一樣。在聖所和上帝面前作首領的有以利亞撒的子孫，也有以他瑪的子孫。</span>
<span className="v" id="v6" data-v="6" data-xref="歷代志上 18:16; 馬太福音 8:19; 尼希米記 8:1"> 作書記的利未人拿坦業的兒子示瑪雅在王和首領，與祭司撒督、亞比亞他的兒子亞希米勒，並祭司利未人的族長面前記錄他們的名字。在以利亞撒的子孫中取一族，在以他瑪的子孫中取一族。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="以斯拉記 2:36; 尼希米記 11:10; 尼希米記 12:19"> 掣籤的時候，第一掣出來的是耶何雅立，第二是耶大雅，</span>
<span className="v" id="v8" data-v="8" data-xref="以斯拉記 2:39; 尼希米記 7:35; 尼希米記 12:15"> 第三是哈琳，第四是梭琳，</span>
<span className="v" id="v9" data-v="9" data-xref="尼希米記 12:17"> 第五是瑪基雅，第六是米雅民，</span>
<span className="v" id="v10" data-v="10" data-xref="路加福音 1:5; 尼希米記 12:4; 尼希米記 12:17"> 第七是哈歌斯，第八是亞比雅，</span>
<span className="v" id="v11" data-v="11" data-xref="以斯拉記 2:36; 尼希米記 12:10; 尼希米記 7:39"> 第九是耶書亞，第十是示迦尼，</span>
<span className="v" id="v12" data-v="12" data-xref="尼希米記 12:10"> 第十一是以利亞實，第十二是雅金，</span>
<span className="v" id="v13" data-v="13"> 第十三是胡巴，第十四是耶是比押，</span>
<span className="v" id="v14" data-v="14" data-xref="尼希米記 7:40; 以斯拉記 2:37; 以斯拉記 10:20"> 第十五是璧迦，第十六是音麥，</span>
<span className="v" id="v15" data-v="15"> 第十七是希悉，第十八是哈闢悉，</span>
<span className="v" id="v16" data-v="16"> 第十九是毗他希雅，第二十是以西結，</span>
<span className="v" id="v17" data-v="17"> 第二十一是雅斤，第二十二是迦末，</span>
<span className="v" id="v18" data-v="18"> 第二十三是第來雅，第二十四是瑪西亞。</span>
<span className="v" id="v19" data-v="19" data-xref="歷代志上 9:25; 哥林多前書 14:40; 希伯來書 7:11"> 這就是他們的班次，要照耶和華－以色列的上帝藉他們祖宗亞倫所吩咐的條例進入耶和華的殿辦理事務。</span>
</div>
</div>

## 利未人名單

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="歷代志上 26:24; 歷代志上 23:16; 歷代志上 6:18"> 利未其餘的子孫如下：暗蘭的子孫裏有書巴業；書巴業的子孫裏有耶希底亞。</span>
<span className="v" id="v21" data-v="21" data-xref="歷代志上 23:17; 歷代志上 26:25"> 利哈比雅的子孫裏有長子伊示雅。</span>
<span className="v" id="v22" data-v="22" data-xref="歷代志上 23:18; 民數記 3:27; 民數記 3:19"> 以斯哈的子孫裏有示羅摩；示羅摩的子孫裏有雅哈。</span>
<span className="v" id="v23" data-v="23" data-xref="歷代志上 23:19; 歷代志上 26:31"> 希伯倫 的子孫裏有長子耶利雅，次子亞瑪利亞，三子雅哈悉，四子耶加面。</span>
<span className="v" id="v24" data-v="24" data-xref="歷代志上 23:20"> 烏薛的子孫裏有米迦；米迦的子孫裏有沙密。</span>
<span className="v" id="v25" data-v="25" data-xref="歷代志上 15:20; 歷代志上 15:18; 歷代志上 23:20"> 米迦的兄弟是伊示雅；伊示雅的子孫裏有撒迦利雅。</span>
<span className="v" id="v26" data-v="26" data-xref="歷代志上 23:21"> 米拉利的兒子是抹利、母示、雅西雅；雅西雅的兒子有比挪；</span>
<span className="v" id="v27" data-v="27" data-xref="民數記 3:20; 歷代志上 23:21; 歷代志上 6:19"> 米拉利的子孫裏有雅西雅的兒子比挪、朔含、撒刻、伊比利。</span>
<span className="v" id="v28" data-v="28" data-xref="歷代志上 23:22"> 抹利的兒子是以利亞撒；以利亞撒沒有兒子。</span>
<span className="v" id="v29" data-v="29"> 基士的子孫裏有耶拉篾。</span>
<span className="v" id="v30" data-v="30" data-xref="歷代志上 23:23; 歷代志上 6:47"> 母示的兒子是末力、以得、耶利摩。按着宗族這都是利未的子孫。</span>
<span className="v" id="v31" data-v="31" data-xref="歷代志上 24:5–6; 歷代志上 26:13; 歷代志上 25:8"> 他們在大衛王和撒督，並亞希米勒與祭司利未人的族長面前掣籤，正如他們弟兄亞倫的子孫一般。各族的長者與兄弟沒有分別。</span>
</div>
</div>

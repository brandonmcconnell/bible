## 以薩迦的後裔

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 46:13; 民數記 26:23–24"> 以薩迦的兒子是陀拉、普瓦、雅述<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="在創世記第四十六章十三節是約伯">a</a></sup>、伸崙，共四人。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳記下 24:1–9; 歷代志上 27:23–24; 歷代志上 27:1"> 陀拉的兒子是烏西、利法雅、耶勒、雅買、易伯散、示母利，都是陀拉的族長，是大能的勇士。到大衛年間，他們的人數共有二萬二千六百名。</span>
<span className="v" id="v3" data-v="3"> 烏西的兒子是伊斯拉希；伊斯拉希的兒子是米迦勒、俄巴底亞、約珥、伊示雅，共五人，都是族長。</span>
<span className="v" id="v4" data-v="4" data-xref="歷代志上 12:32"> 他們所率領的，按着宗族出戰的軍隊，共有三萬六千人，因為他們的妻和子眾多。</span>
<span className="v" id="v5" data-v="5"> 他們的族弟兄在以薩迦各族中都是大能的勇士，按着家譜計算共有八萬七千人。</span>
</div>
</div>

## 便雅憫和但的後裔

<div className="bt">
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="創世記 46:21; 歷代志上 8:1–40; 歷代志上 7:10–11"> 便雅憫的兒子是比拉、比結、耶疊，共三人。</span>
<span className="v" id="v7" data-v="7" data-xref="歷代志下 17:17–18; 歷代志上 21:1–5"> 比拉的兒子是以斯本、烏西、烏薛、耶利摩、以利，共五人，都是族長，是大能的勇士。按着家譜計算，他們的子孫共有二萬二千零三十四人。</span>
<span className="v" id="v8" data-v="8"> 比結的兒子是細米拉、約阿施、以利以謝、以利約乃、暗利、耶利摩、亞比雅、亞拿突、亞拉篾。這都是比結的兒子。</span>
<span className="v" id="v9" data-v="9"> 他們都是族長，是大能的勇士。按着家譜計算，他們的子孫共有二萬零二百人。</span>
<span className="v" id="v10" data-v="10" data-xref="士師記 3:15–30"> 耶疊的兒子是比勒罕；比勒罕的兒子是耶烏施、便雅憫、以忽、基拿拿、細坦、他施、亞希沙哈。</span>
<span className="v" id="v11" data-v="11" data-xref="歷代志下 17:13–19"> 這都是耶疊的兒子，都是族長，是大能的勇士；他們的子孫能上陣打仗的，共有一萬七千二百人。</span>
<span className="v" id="v12" data-v="12" data-xref="民數記 26:38–39; 創世記 46:21; 歷代志上 7:15"> 還有以珥的兒子書品、戶品，並亞黑的兒子戶伸。</span>
</div>
</div>

<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="民數記 26:48–49; 創世記 30:3–8; 創世記 35:22"> 拿弗他利的兒子是雅薛、沽尼、耶色、沙龍。這都是辟拉的子孫。</span>
</div>

## 瑪拿西的後裔

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="民數記 32:30–42; 士師記 5:14; 申命記 3:13–15"> 瑪拿西的兒子亞斯列是他妾亞蘭人所生的，又生了基列之父瑪吉。</span>
<span className="v" id="v15" data-v="15" data-xref="民數記 26:33; 民數記 36:1–12; 民數記 27:1–11"> 瑪吉娶的妻是戶品、書品的妹子，名叫瑪迦。瑪拿西的次子名叫西羅非哈；西羅非哈但有幾個女兒。</span>
<span className="v" id="v16" data-v="16"> 瑪吉的妻瑪迦生了一個兒子，起名叫毗利施。毗利施的兄弟名叫示利施；示利施的兒子是烏蘭和利金。</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳記上 12:11"> 烏蘭的兒子是比但。這都是基列的子孫。基列是瑪吉的兒子，瑪吉是瑪拿西的兒子。</span>
<span className="v" id="v18" data-v="18" data-xref="士師記 6:24; 士師記 6:11; 士師記 8:2"> 基列的妹子哈摩利吉生了伊施荷、亞比以謝、瑪拉。（</span>
<span className="v" id="v19" data-v="19"> 示米大的兒子是亞現、示劍、利克希、阿尼安。）</span>
</div>
</div>

## 以法蓮的後裔

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="民數記 26:35–36"> 以法蓮的兒子是書提拉；書提拉的兒子是比列；比列的兒子是他哈；他哈的兒子是以拉大；以拉大的兒子是他哈；</span>
<span className="v" id="v21" data-v="21"> 他哈的兒子是撒拔；撒拔的兒子是書提拉。以法蓮又生以謝、以列；這二人因為下去奪取迦特人的牲畜，被本地的迦特人殺了。</span>
<span className="v" id="v22" data-v="22" data-xref="約伯記 2:11; 創世記 37:34"> 他們的父親以法蓮為他們悲哀了多日，他的弟兄都來安慰他。</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳記下 23:5"> 以法蓮與妻同房，他妻就懷孕生了一子，以法蓮因為家裏遭禍，就給這兒子起名叫比利亞。</span>
<span className="v" id="v24" data-v="24" data-xref="約書亞記 16:3; 約書亞記 16:5; 歷代志下 8:5"> 他的女兒名叫舍伊拉，就是建築上伯‧和崙、下伯‧和崙與烏羨‧舍伊拉的。</span>
<span className="v" id="v25" data-v="25"> 比利亞的兒子是利法和利悉。利悉的兒子是他拉；他拉的兒子是他罕；</span>
<span className="v" id="v26" data-v="26"> 他罕的兒子是拉但；拉但的兒子是亞米忽；亞米忽的兒子是以利沙瑪；</span>
<span className="v" id="v27" data-v="27" data-xref="民數記 13:8; 民數記 13:16; 出埃及記 17:9–14"> 以利沙瑪的兒子是嫩；嫩的兒子是約書亞。</span>
<span className="v" id="v28" data-v="28" data-xref="創世記 28:19; 約書亞記 16:2–3; 歷代志上 6:66–67"> 以法蓮人的地業和住處是伯特利與其村莊；東邊拿蘭，西邊基色與其村莊；示劍與其村莊，直到迦薩與其村莊；</span>
<span className="v" id="v29" data-v="29" data-xref="士師記 1:22–29; 撒迦利亞書 12:11; 列王紀下 9:27"> 還有靠近瑪拿西人的境界，伯‧善與其村莊；他納與其村莊；米吉多與其村莊；多珥與其村莊。以色列兒子約瑟的子孫住在這些地方。</span>
</div>
</div>

## 亞設的後裔

<div className="bt">
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="創世記 46:17; 民數記 26:44–46"> 亞設的兒子是音拿、亦施瓦、亦施韋、比利亞，還有他們的妹子西拉。</span>
<span className="v" id="v31" data-v="31"> 比利亞的兒子是希別、瑪結；瑪結是比撒威的父親。</span>
<span className="v" id="v32" data-v="32"> 希別生雅弗勒、朔默、何坦，和他們的妹子書雅。</span>
<span className="v" id="v33" data-v="33"> 雅弗勒的兒子是巴薩、賓哈、亞施法。這都是雅弗勒的兒子。</span>
<span className="v" id="v34" data-v="34"> 朔默的兒子是亞希、羅迦、耶戶巴、亞蘭。</span>
<span className="v" id="v35" data-v="35"> 朔默兄弟希連的兒子是瑣法、音那、示利斯、亞抹。</span>
<span className="v" id="v36" data-v="36"> 瑣法的兒子是書亞、哈尼弗、書阿勒、比利、音拉、</span>
<span className="v" id="v37" data-v="37"> 比悉、河得、珊瑪、施沙、益蘭、比拉。</span>
<span className="v" id="v38" data-v="38"> 益帖的兒子是耶孚尼、毗斯巴、亞拉。</span>
<span className="v" id="v39" data-v="39"> 烏拉的兒子是亞拉、漢尼業、利寫。</span>
<span className="v" id="v40" data-v="40" data-xref="歷代志上 21:1–5; 撒母耳記下 24:1–9"> 這都是亞設的子孫，都是族長，是精壯大能的勇士，也是首領中的頭目，按着家譜計算，他們的子孫能出戰的共有二萬六千人。</span>
</div>

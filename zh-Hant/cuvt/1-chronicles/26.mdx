## 聖殿的衛隊

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歷代志下 23:19; 民數記 26:9–11; 詩篇 44:1"> 守門的班次記在下面：可拉族亞薩的子孫中，有可利的兒子米施利米雅。</span>
<span className="v" id="v2" data-v="2" data-xref="歷代志上 9:21"> 米施利米雅的長子是撒迦利亞，次子是耶疊，三子是西巴第雅，四子是耶提聶，</span>
<span className="v" id="v3" data-v="3"> 五子是以攔，六子是約哈難，七子是以利約乃。</span>
<span className="v" id="v4" data-v="4" data-xref="歷代志上 16:38; 歷代志上 15:24; 歷代志上 15:18"> 俄別‧以東的長子是示瑪雅，次子是約薩拔，三子是約亞，四子是沙甲，五子是拿坦業，</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 128:1"> 六子是亞米利，七子是以薩迦，八子是毗烏利太，因為上帝賜福與俄別‧以東。</span>
<span className="v" id="v6" data-v="6" data-xref="歷代志上 12:28; 提摩太前書 6:12; 士師記 6:12"> 他的兒子示瑪雅有幾個兒子，都是大能的壯士，掌管父親的家。</span>
<span className="v" id="v7" data-v="7"> 示瑪雅的兒子是俄得尼、利法益、俄備得、以利薩巴。以利薩巴的弟兄是壯士，還有以利戶和西瑪迦。</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多後書 3:6; 彼得前書 4:11; 哥林多前書 12:4–11"> 這都是俄別‧以東的子孫，他們和他們的兒子並弟兄，都是善於辦事的壯士。俄別‧以東的子孫共六十二人。</span>
<span className="v" id="v9" data-v="9" data-xref="歷代志上 26:14; 歷代志上 26:1"> 米施利米雅的兒子和弟兄都是壯士，共十八人。</span>
<span className="v" id="v10" data-v="10" data-xref="歷代志上 16:38; 歷代志上 5:1–2"> 米拉利子孫何薩有幾個兒子：長子是申利，他原不是長子，是他父親立他作長子。</span>
<span className="v" id="v11" data-v="11"> 次子是希勒家，三子是底巴利雅，四子是撒迦利亞。何薩的兒子並弟兄共十三人。</span>
<span className="v" id="v12" data-v="12" data-xref="歷代志上 25:8"> 這些人都是守門的班長，與他們的弟兄一同在耶和華殿裏按班供職。</span>
<span className="v" id="v13" data-v="13" data-xref="歷代志上 25:8; 歷代志上 24:31; 歷代志上 24:5"> 他們無論大小，都按着宗族掣籤分守各門。</span>
<span className="v" id="v14" data-v="14"> 掣籤守東門的是示利米雅；他的兒子撒迦利亞是精明的謀士，掣籤守北門。</span>
<span className="v" id="v15" data-v="15" data-xref="歷代志下 25:24; 歷代志上 26:17"> 俄別‧以東守南門，他的兒子守庫房。</span>
<span className="v" id="v16" data-v="16" data-xref="尼希米記 12:24; 歷代志上 26:10–12; 列王紀上 10:5"> 書聘與何薩守西門，在靠近沙利基門、通着往上去的街道上，班與班相對。</span>
<span className="v" id="v17" data-v="17" data-xref="歷代志下 8:14; 歷代志上 9:24"> 每日東門有六個利未人，北門有四個，南門有四個，庫房有兩個，又有兩個輪班替換。</span>
<span className="v" id="v18" data-v="18" data-xref="列王紀下 23:11"> 在西面街道上有四個，在遊廊上有兩個。</span>
<span className="v" id="v19" data-v="19" data-xref="民數記 16:11"> 以上是可拉子孫和米拉利子孫守門的班次。</span>
</div>
</div>

## 其他職守

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="歷代志上 26:22; 歷代志上 28:12–19; 歷代志上 22:14–16"> 利未子孫中有亞希雅掌管上帝殿的府庫和聖物的府庫。</span>
<span className="v" id="v21" data-v="21" data-xref="歷代志上 23:7; 歷代志上 6:17; 歷代志上 29:8"> 革順族、拉但子孫裏，作族長的是革順族拉但的子孫耶希伊利。</span>
<span className="v" id="v22" data-v="22" data-xref="歷代志上 23:8; 尼希米記 10:38; 歷代志上 26:20"> 耶希伊利的兒子西坦和他兄弟約珥掌管耶和華殿裏的府庫。</span>
<span className="v" id="v23" data-v="23" data-xref="民數記 3:27; 歷代志上 23:12; 民數記 3:19"> 暗蘭族、以斯哈族、希伯倫族、烏泄族也有職分。</span>
<span className="v" id="v24" data-v="24" data-xref="歷代志上 24:20; 歷代志上 23:15–16"> 摩西的孫子、革舜的兒子細布業掌管府庫。</span>
<span className="v" id="v25" data-v="25" data-xref="歷代志上 23:17–18; 歷代志上 23:15; 出埃及記 18:4"> 還有他的弟兄以利以謝。以利以謝的兒子是利哈比雅；利哈比雅的兒子是耶篩亞；耶篩亞的兒子是約蘭；約蘭的兒子是細基利；細基利的兒子是示羅密。</span>
<span className="v" id="v26" data-v="26" data-xref="撒母耳記下 8:11; 歷代志上 29:2–9; 歷代志上 22:14"> 這示羅密和他的弟兄掌管府庫的聖物，就是大衛王和眾族長、千夫長、百夫長，並軍長所分別為聖的物。</span>
<span className="v" id="v27" data-v="27" data-xref="列王紀下 12:14; 約書亞記 6:19; 尼希米記 10:32–34"> 他們將爭戰時所奪的財物分別為聖，以備修造耶和華的殿。</span>
<span className="v" id="v28" data-v="28" data-xref="撒母耳記上 9:9; 撒母耳記上 17:55; 撒母耳記下 10:9–14"> 先見撒母耳、基士的兒子掃羅、尼珥的兒子押尼珥、洗魯雅的兒子約押所分別為聖的物都歸示羅密和他的弟兄掌管。</span>
</div>
</div>

## 其餘利未人的職守

<div className="bt">
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="歷代志上 23:4; 尼希米記 11:16; 歷代志下 34:13"> 以斯哈族有基拿尼雅和他眾子作官長和士師，管理以色列的外事。</span>
<span className="v" id="v30" data-v="30" data-xref="歷代志上 27:17; 歷代志上 23:19; 歷代志上 23:12"> 希伯倫族有哈沙比雅和他弟兄一千七百人，都是壯士，在約旦河西、以色列地辦理耶和華與王的事。</span>
<span className="v" id="v31" data-v="31" data-xref="歷代志上 23:19; 約書亞記 21:39; 歷代志上 29:27"> 希伯倫族中有耶利雅作族長。大衛作王第四十年，在基列的雅謝，從這族中尋得大能的勇士。</span>
<span className="v" id="v32" data-v="32" data-xref="歷代志下 19:11; 歷代志上 12:37; 歷代志上 23:24"> 耶利雅的弟兄有二千七百人，都是壯士，且作族長；大衛王派他們在呂便支派、迦得支派、瑪拿西半支派中辦理上帝和王的事。</span>
</div>

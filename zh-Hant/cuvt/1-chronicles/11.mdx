## 大衛作以色列和猶大的王

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳記下 5:1–16; 歷代志上 12:23–40; 士師記 9:2"> 以色列眾人聚集到希伯崙見大衛，說：「我們原是你的骨肉。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳記下 5:2; 約翰福音 10:4; 詩篇 78:71"> 從前掃羅作王的時候，率領以色列人出入的是你；耶和華－你的上帝也曾應許你說：『你必牧養我的民以色列，作以色列的君。』」</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳記上 16:12–13; 撒母耳記上 16:1; 撒母耳記下 5:3"> 於是以色列的長老都來到希伯崙見大衛王。大衛在希伯崙耶和華面前與他們立約，他們就膏大衛作以色列的王，是照耶和華藉撒母耳所說的話。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="士師記 1:21; 創世記 15:21; 約書亞記 15:8"> 大衛和以色列眾人到了耶路撒冷，就是耶布斯；那時耶布斯人住在那裏。</span>
<span className="v" id="v5" data-v="5" data-xref="歷代志下 5:2; 列王紀上 8:1; 詩篇 87:2"> 耶布斯人對大衛說：「你決不能進這地方。」然而大衛攻取錫安的保障，就是大衛的城。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳記下 8:16; 撒母耳記下 20:23; 撒母耳記下 3:27"> 大衛說：「誰先攻打耶布斯人，必作首領元帥。」洗魯雅的兒子約押先上去，就作了元帥。</span>
<span className="v" id="v7" data-v="7" data-xref="歷代志上 11:5; 撒母耳記下 5:7; 詩篇 2:6"> 大衛住在保障裏，所以那保障叫作大衛城。</span>
<span className="v" id="v8" data-v="8" data-xref="士師記 9:6; 列王紀上 11:27; 列王紀下 12:20"> 大衛又從米羅起，四圍建築城牆，其餘的是約押修理。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳記下 3:1; 以賽亞書 41:10; 歷代志上 9:20"> 大衛日見強盛，因為萬軍之耶和華與他同在。</span>
</div>
</div>

## 大衛的有名將領

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="歷代志上 11:3; 撒母耳記上 16:1; 歷代志上 12:38"> 以下記錄跟隨大衛勇士的首領，就是奮勇幫助他得國、照着耶和華吩咐以色列人的話、與以色列人一同立他作王的。</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳記下 23:8; 歷代志上 27:2; 歷代志上 12:18"> 大衛勇士的數目記在下面：哈革摩尼的兒子雅朔班，他是軍長的統領，一時舉槍殺了三百人。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="歷代志上 27:4; 撒母耳記下 23:17–19; 撒母耳記下 23:23"> 其次是亞合人朵多的兒子以利亞撒，他是三個勇士裏的一個。</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳記下 23:11–12; 撒母耳記上 17:1"> 他從前與大衛在巴斯‧達閔，非利士人聚集要打仗。那裏有一塊長滿大麥的田，眾民就在非利士人面前逃跑；</span>
<span className="v" id="v14" data-v="14" data-xref="詩篇 144:10; 列王紀下 5:1; 撒母耳記上 14:23"> 這勇士便站在那田間擊殺非利士人，救護了那田。耶和華使以色列人大獲全勝。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="歷代志上 14:9; 撒母耳記下 5:18; 以賽亞書 17:5"> 三十個勇士中的三個人下到磐石那裏，進了亞杜蘭洞見大衛；非利士的軍隊在利乏音谷安營。</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳記上 10:5; 撒母耳記上 13:4; 撒母耳記上 13:23"> 那時大衛在山寨，非利士人的防營在伯利恆。</span>
<span className="v" id="v17" data-v="17" data-xref="約翰福音 4:14; 以賽亞書 12:3; 撒母耳記下 23:15–16"> 大衛渴想，說：「甚願有人將伯利恆城門旁井裏的水打來給我喝！」</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行傳 21:13; 撒母耳記上 19:5; 使徒行傳 20:24"> 這三個勇士就闖過非利士人的營盤，從伯利恆城門旁的井裏打水，拿來奉給大衛。他卻不肯喝，將水奠在耶和華面前，</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳記下 23:17; 詩篇 72:14; 士師記 9:17"> 說：「我的上帝啊，這三個人冒死去打水，這水好像他們的血一般，我斷不敢喝！」如此，大衛不肯喝。這是三個勇士所做的事。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="撒母耳記上 26:6; 歷代志上 2:16; 撒母耳記下 20:6"> 約押的兄弟亞比篩是這三個勇士的首領；他舉槍殺了三百人，就在三個勇士裏得了名。</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多前書 15:41; 馬太福音 13:8"> 他在這三個勇士裏是最尊貴的，所以作他們的首領；只是不及前三個勇士。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="撒母耳記下 23:20–23; 撒母耳記下 8:18; 約書亞記 15:21"> 有甲薛勇士耶何耶大的兒子比拿雅行過大能的事：他殺了摩押人亞利伊勒的兩個兒子，又在下雪的時候下坑裏去殺了一個獅子，</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳記上 17:7; 撒母耳記上 17:4; 申命記 3:11"> 又殺了一個埃及人。埃及人身高五肘，手裏拿着槍，槍桿粗如織布的機軸；比拿雅只拿着棍子下去，從埃及人手裏奪過槍來，用那槍將他刺死。</span>
<span className="v" id="v24" data-v="24"> 這是耶何耶大的兒子比拿雅所行的事，就在三個勇士裏得了名。</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳記下 20:23"> 他比那三十個勇士都尊貴，只是不及前三個勇士。大衛立他作護衛長。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="歷代志上 27:7; 撒母耳記下 21:19; 撒母耳記下 2:18–23"> 軍中的勇士有約押的兄弟亞撒黑，伯利恆人朵多的兒子伊勒哈難，</span>
<span className="v" id="v27" data-v="27" data-xref="撒母耳記下 23:25–26"> 哈律人沙瑪，比倫人希利斯，</span>
<span className="v" id="v28" data-v="28" data-xref="歷代志上 27:12; 歷代志上 27:9; 撒母耳記下 23:27"> 提哥亞人益吉的兒子以拉，亞拿突人亞比以謝，</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳記下 23:27–28; 歷代志上 27:11"> 戶沙人西比該，亞合人以來，</span>
<span className="v" id="v30" data-v="30" data-xref="歷代志上 27:13; 歷代志上 27:15; 撒母耳記下 23:29"> 尼陀法人瑪哈萊，尼陀法人巴拿的兒子希立，</span>
<span className="v" id="v31" data-v="31" data-xref="撒母耳記下 23:29"> 便雅憫族基比亞人利拜的兒子以太，比拉頓人比拿雅，</span>
<span className="v" id="v32" data-v="32" data-xref="撒母耳記下 23:30–31"> 迦實溪人戶萊，亞拉巴人亞比，</span>
<span className="v" id="v33" data-v="33"> 巴路米人押斯瑪弗，沙本人以利雅哈巴，</span>
<span className="v" id="v34" data-v="34" data-xref="撒母耳記下 23:32–33"> 基孫人哈深的眾子，哈拉人沙基的兒子約拿單，</span>
<span className="v" id="v35" data-v="35" data-xref="撒母耳記下 23:33–34"> 哈拉人沙甲的兒子亞希暗，吾珥的兒子以利法勒，</span>
<span className="v" id="v36" data-v="36"> 米基拉人希弗，比倫人亞希雅，</span>
<span className="v" id="v37" data-v="37" data-xref="撒母耳記下 23:35"> 迦密人希斯羅，伊斯拜的兒子拿萊，</span>
<span className="v" id="v38" data-v="38" data-xref="撒母耳記下 23:36"> 拿單的兄弟約珥，哈基利的兒子彌伯哈，</span>
<span className="v" id="v39" data-v="39"> 亞捫人洗勒，比錄人拿哈萊（拿哈萊是給洗魯雅的兒子約押拿兵器的），</span>
<span className="v" id="v40" data-v="40" data-xref="撒母耳記下 20:26"> 以帖人以拉，以帖人迦立，</span>
<span className="v" id="v41" data-v="41" data-xref="歷代志上 2:36; 撒母耳記下 23:39; 撒母耳記下 11:6–27"> 赫人烏利亞，亞萊的兒子撒拔，</span>
<span className="v" id="v42" data-v="42"> 呂便人示撒的兒子亞第拿（他是呂便支派中的一個族長，率領三十人），</span>
<span className="v" id="v43" data-v="43"> 瑪迦的兒子哈難，彌特尼人約沙法，</span>
<span className="v" id="v44" data-v="44"> 亞施他拉人烏西亞，亞羅珥人何坦的兒子沙瑪、耶利，</span>
<span className="v" id="v45" data-v="45"> 提洗人申利的兒子耶疊和他的兄弟約哈，</span>
<span className="v" id="v46" data-v="46"> 瑪哈未人以利業，伊利拿安的兒子耶利拜、約沙未雅，摩押人伊特瑪、</span>
<span className="v" id="v47" data-v="47"> 以利業、俄備得，並米瑣八人雅西業。</span>
</div>
</div>

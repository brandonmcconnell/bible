## 復記猶大的後裔

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 46:12; 創世記 38:29; 民數記 26:20–21"> 猶大的兒子是法勒斯、希斯崙、迦米、戶珥、朔巴。</span>
<span className="v" id="v2" data-v="2" data-xref="士師記 13:25; 歷代志上 2:52–54; 約書亞記 15:33"> 朔巴的兒子利亞雅生雅哈；雅哈生亞戶買和拉哈。這是瑣拉人的諸族。</span>
<span className="v" id="v3" data-v="3" data-xref="士師記 15:11; 歷代志下 11:6"> 以坦之祖的兒子是耶斯列、伊施瑪、伊得巴；他們的妹子名叫哈悉勒玻尼。</span>
<span className="v" id="v4" data-v="4" data-xref="歷代志上 4:18; 歷代志上 2:50; 歷代志上 4:39"> 基多之祖是毗努伊勒。戶沙之祖是以謝珥。這都是伯利恆之祖以法她的長子戶珥所生的。</span>
<span className="v" id="v5" data-v="5" data-xref="歷代志上 2:24"> 提哥亞之祖亞施戶有兩個妻子：一名希拉，一名拿拉。</span>
<span className="v" id="v6" data-v="6"> 拿拉給亞施戶生亞戶撒、希弗、提米尼、哈轄斯他利。這都是拿拉的兒子。</span>
<span className="v" id="v7" data-v="7"> 希拉的兒子是洗列、瑣轄、伊提南。</span>
<span className="v" id="v8" data-v="8"> 哥斯生亞諾、瑣比巴，並哈崙兒子亞哈黑的諸族。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳記上 4:21; 歷代志上 7:23; 創世記 35:18"> 雅比斯比他眾弟兄更尊貴，他母親給他起名叫雅比斯，意思說：我生他甚是痛苦。</span>
<span className="v" id="v10" data-v="10" data-xref="馬太福音 7:7–11; 詩篇 116:1–4; 箴言 10:22"> 雅比斯求告以色列的上帝說：「甚願你賜福與我，擴張我的境界，常與我同在，保佑我不遭患難，不受艱苦。」上帝就應允他所求的。</span>
</div>
</div>

## 其他的家族

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11"> 書哈的弟兄基綠生米黑，米黑是伊施屯之祖。</span>
<span className="v" id="v12" data-v="12"> 伊施屯生伯拉巴、巴西亞，並珥拿轄之祖提欣拿，這都是利迦人。</span>
<span className="v" id="v13" data-v="13" data-xref="約書亞記 15:17; 士師記 1:13; 士師記 3:9–11"> 基納斯的兒子是俄陀聶、西萊雅。俄陀聶的兒子是哈塔。</span>
<span className="v" id="v14" data-v="14" data-xref="尼希米記 11:35; 列王紀下 24:14"> 憫挪太生俄弗拉；西萊雅生革‧夏納欣人之祖約押。他們都是匠人。</span>
<span className="v" id="v15" data-v="15" data-xref="民數記 13:6; 民數記 14:6–10; 約書亞記 15:13–20"> 耶孚尼的兒子是迦勒；迦勒的兒子是以路、以拉、拿安。以拉的兒子是基納斯。</span>
<span className="v" id="v16" data-v="16"> 耶哈利勒的兒子是西弗、西法、提利、亞撒列。</span>
<span className="v" id="v17" data-v="17" data-xref="歷代志上 4:19; 歷代志上 6:57; 約書亞記 15:50"> 以斯拉的兒子是益帖、米列、以弗、雅倫。米列娶法老女兒比提雅為妻，生米利暗、沙買，和以實提摩之祖益巴。米列又娶猶大女子為妻，生基多之祖雅列，梭哥之祖希伯，和撒挪亞之祖耶古鐵。</span>
<span className="v" id="v19" data-v="19" data-xref="約書亞記 15:44; 撒母耳記上 23:1–13"> 荷第雅的妻是拿含的妹子，她所生的兒子是迦米人基伊拉和瑪迦人以實提摩之祖。</span>
<span className="v" id="v20" data-v="20"> 示門的兒子是暗嫩、林拿、便‧哈南、提倫。 以示的兒子是梭黑與便‧梭黑。</span>
</div>
</div>

## 示拉的後裔

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="創世記 38:5; 歷代志上 2:3; 民數記 26:20"> 猶大的兒子是示拉；示拉的兒子是利迦之祖珥，瑪利沙之祖拉大，和屬亞實比族織細麻布的各家。</span>
<span className="v" id="v22" data-v="22"> 還有約敬、哥西巴人、約阿施、薩拉，就是在摩押地掌權的，又有雅叔比利恆。這都是古時所記載的。</span>
<span className="v" id="v23" data-v="23" data-xref="詩篇 81:6; 歷代志上 4:14"> 這些人都是窯匠，是尼他應和基低拉的居民；與王同處，為王做工。</span>
</div>
</div>

## 西緬的後裔

<div className="bt">
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="創世記 46:10; 出埃及記 6:15; 民數記 26:12–14"> 西緬的兒子是尼母利、雅憫、雅立、謝拉、掃羅。</span>
<span className="v" id="v25" data-v="25"> 掃羅的兒子是沙龍；沙龍的兒子是米比衫；米比衫的兒子是米施瑪；</span>
<span className="v" id="v26" data-v="26"> 米施瑪的兒子是哈母利；哈母利的兒子是撒刻；撒刻的兒子是示每。</span>
<span className="v" id="v27" data-v="27" data-xref="民數記 26:14; 民數記 26:22; 民數記 2:13"> 示每有十六個兒子，六個女兒，他弟兄的兒女不多，他們各家不如猶大族的人丁增多。</span>
<span className="v" id="v28" data-v="28" data-xref="約書亞記 19:2–3; 約書亞記 15:28–29; 約書亞記 19:9"> 西緬人住在別是巴、摩拉大、哈薩‧書亞、</span>
<span className="v" id="v29" data-v="29" data-xref="約書亞記 19:3–4"> 辟拉、以森、陀臘、</span>
<span className="v" id="v30" data-v="30" data-xref="尼希米記 11:28; 約書亞記 19:4–5; 撒母耳記上 30:1"> 彼土利、何珥瑪、洗革拉、</span>
<span className="v" id="v31" data-v="31" data-xref="約書亞記 19:5–6"> 伯‧瑪嘉博、哈薩‧蘇撒、伯‧比利、沙拉音，這些城邑直到大衛作王的時候都是屬西緬人的。</span>
<span className="v" id="v32" data-v="32" data-xref="約書亞記 19:7"> 他們的五個城邑是以坦、亞因、臨門、陀健、亞珊；</span>
<span className="v" id="v33" data-v="33" data-xref="約書亞記 19:8"> 還有屬城的鄉村，直到巴力。這是他們的住處，他們都有家譜。</span>
<span className="v" id="v34" data-v="34"> 還有米所巴、雅米勒、亞瑪謝的兒子約沙、</span>
<span className="v" id="v35" data-v="35"> 約珥、約示比的兒子耶戶；約示比是西萊雅的兒子；西萊雅是亞薛的兒子。</span>
<span className="v" id="v36" data-v="36"> 還有以利約乃、雅哥巴、約朔海、亞帥雅、亞底業、耶西篾、比拿雅、</span>
<span className="v" id="v37" data-v="37"> 示非的兒子細撒。示非是亞龍的兒子；亞龍是耶大雅的兒子；耶大雅是申利的兒子；申利是示瑪雅的兒子。</span>
<span className="v" id="v38" data-v="38" data-xref="歷代志上 5:24; 創世記 6:4"> 以上所記的人名都是作族長的，他們宗族的人數增多。</span>
<span className="v" id="v39" data-v="39" data-xref="歷代志上 4:4; 歷代志上 4:18; 約書亞記 15:58"> 他們往平原東邊基多口去，尋找牧放羊群的草場，</span>
<span className="v" id="v40" data-v="40" data-xref="士師記 18:7–10; 詩篇 105:23; 詩篇 78:51"> 尋得肥美的草場地，又寬闊又平靜。從前住那裏的是含族的人。</span>
<span className="v" id="v41" data-v="41" data-xref="以賽亞書 14:28–32; 列王紀下 18:8–12; 歷代志上 4:34–38"> 以上錄名的人，在猶大王希西家年間，來攻擊含族人的帳棚和那裏所有的米烏尼人，將他們滅盡，就住在他們的地方，直到今日，因為那裏有草場可以牧放羊群。</span>
<span className="v" id="v42" data-v="42" data-xref="創世記 36:8–9; 申命記 1:2"> 這西緬人中，有五百人上西珥山，率領他們的是以示的兒子毗拉提、尼利雅、利法雅，和烏薛，</span>
<span className="v" id="v43" data-v="43" data-xref="撒母耳記上 30:17; 撒母耳記上 15:7–8; 撒母耳記下 8:12"> 殺了逃脫剩下的亞瑪力人，就住在那裏直到今日。</span>
</div>
</div>

## 猶大的後裔

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 32:28; 創世記 35:22–26; 啟示錄 7:5–8"> 以色列的兒子是呂便、西緬、利未、猶大、以薩迦、西布倫、</span>
<span className="v" id="v2" data-v="2"> 但、約瑟、便雅憫、拿弗他利、迦得、亞設。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 38:2–10; 創世記 46:12; 民數記 26:19"> 猶大的兒子是珥、俄南、示拉，這三人是迦南人書亞女兒所生的。猶大的長子珥在耶和華眼中看為惡，耶和華就使他死了。</span>
<span className="v" id="v4" data-v="4" data-xref="馬太福音 1:3; 創世記 38:13–30; 尼希米記 11:4"> 猶大的兒婦她瑪給猶大生法勒斯和謝拉。猶大共有五個兒子。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="創世記 46:12; 路得記 4:18; 民數記 26:21"> 法勒斯的兒子是希斯崙、哈母勒。</span>
<span className="v" id="v6" data-v="6" data-xref="列王紀上 4:31; 約書亞記 7:17–18; 約書亞記 7:1"> 謝拉的兒子是心利、以探、希幔、甲各、大拉<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="就是達大">a</a></sup>，共五人。</span>
<span className="v" id="v7" data-v="7" data-xref="約書亞記 6:18; 申命記 7:26; 約書亞記 7:25"> 迦米的兒子是亞干，這亞干在當滅的物上犯了罪，連累了以色列人。</span>
<span className="v" id="v8" data-v="8"> 以探的兒子是亞撒利雅。</span>
</div>
</div>

## 大衛王的家譜

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="歷代志上 2:42; 馬太福音 1:3; 路得記 4:19"> 希斯崙所生的兒子是耶拉篾、蘭、基路拜。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="馬太福音 1:4; 民數記 1:7; 民數記 2:3"> 蘭生亞米拿達；亞米拿達生拿順。拿順作猶大人的首領。</span>
<span className="v" id="v11" data-v="11" data-xref="路得記 4:21; 馬太福音 1:4–5; 路加福音 3:32"> 拿順生撒門；撒門生波阿斯；</span>
<span className="v" id="v12" data-v="12" data-xref="羅馬書 15:12; 歷代志上 10:14; 以賽亞書 11:10"> 波阿斯生俄備得；俄備得生耶西；</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳記上 17:13; 撒母耳記上 17:28; 歷代志上 20:7"> 耶西生長子以利押，次子亞比拿達，三子示米亞<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="示米亞就是沙瑪，見撒母耳上十六章九節">b</a></sup>，</span>
<span className="v" id="v14" data-v="14"> 四子拿坦業，五子拉代，</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳記上 16:10–11; 撒母耳記上 17:12–14"> 六子阿鮮，七子大衛。</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳記上 26:6; 撒母耳記下 3:39; 撒母耳記下 2:18–23"> 他們的姊妹是洗魯雅和亞比該。洗魯雅的兒子是亞比篩、約押、亞撒黑，共三人。</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳記下 17:25; 列王紀上 2:32; 撒母耳記下 20:4–12"> 亞比該生亞瑪撒；亞瑪撒的父親是以實瑪利人益帖。</span>
</div>
</div>

## 希斯崙的後裔

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18"> 希斯崙的兒子迦勒娶阿蘇巴和耶略為妻，阿蘇巴的兒子是耶設、朔罷、押墩。</span>
<span className="v" id="v19" data-v="19" data-xref="歷代志上 2:50; 歷代志上 2:24; 歷代志上 4:4"> 阿蘇巴死了，迦勒又娶以法她，生了戶珥。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及記 31:2; 出埃及記 36:1–2; 出埃及記 37:1"> 戶珥生烏利；烏利生比撒列。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="民數記 27:1; 申命記 3:15; 民數記 26:29"> 希斯崙正六十歲娶了基列父親瑪吉的女兒，與她同房；瑪吉的女兒生了西割；</span>
<span className="v" id="v22" data-v="22" data-xref="約書亞記 13:30; 申命記 3:14; 民數記 32:41"> 西割生睚珥。睚珥在基列地有二十三個城邑。</span>
<span className="v" id="v23" data-v="23" data-xref="約書亞記 13:30; 申命記 3:14; 民數記 32:41–42"> 後來基述人和亞蘭人奪了睚珥的城邑，並基納和其鄉村，共六十個。這都是基列父親瑪吉之子的。</span>
<span className="v" id="v24" data-v="24" data-xref="歷代志上 4:5; 歷代志上 2:9; 撒母耳記上 30:14"> 希斯崙在迦勒‧以法他死後，他的妻亞比雅給他生了亞施戶；亞施戶是提哥亞的父親。</span>
</div>
</div>

## 耶拉篾的後裔

<div className="bt">
<div className="bp">
<span className="v" id="v25" data-v="25"> 希斯崙的長子耶拉篾生長子蘭，又生布拿、阿連、阿鮮、亞希雅。</span>
<span className="v" id="v26" data-v="26"> 耶拉篾又娶一妻名叫亞她拉，是阿南的母親。</span>
<span className="v" id="v27" data-v="27"> 耶拉篾長子蘭的兒子是瑪斯、雅憫、以結。</span>
<span className="v" id="v28" data-v="28"> 阿南的兒子是沙買、雅大。沙買的兒子是拿答、亞比述。</span>
<span className="v" id="v29" data-v="29"> 亞比述的妻名叫亞比孩，亞比孩給他生了亞辦和摩利。</span>
<span className="v" id="v30" data-v="30"> 拿答的兒子是西列、亞遍；西列死了沒有兒子。</span>
<span className="v" id="v31" data-v="31" data-xref="歷代志上 2:34–35"> 亞遍的兒子是以示；以示的兒子是示珊；示珊的兒子是亞來。</span>
<span className="v" id="v32" data-v="32"> 沙買兄弟雅大的兒子是益帖、約拿單；益帖死了沒有兒子。</span>
<span className="v" id="v33" data-v="33"> 約拿單的兒子是比勒、撒薩。這都是耶拉篾的子孫。</span>
<span className="v" id="v34" data-v="34"> 示珊沒有兒子，只有女兒。示珊有一個僕人名叫耶哈，是埃及人。</span>
<span className="v" id="v35" data-v="35"> 示珊將女兒給了僕人耶哈為妻，給他生了亞太。</span>
<span className="v" id="v36" data-v="36" data-xref="歷代志上 11:41"> 亞太生拿單；拿單生撒拔；</span>
<span className="v" id="v37" data-v="37"> 撒拔生以弗拉；以弗拉生俄備得；</span>
<span className="v" id="v38" data-v="38"> 俄備得生耶戶；耶戶生亞撒利雅；</span>
<span className="v" id="v39" data-v="39"> 亞撒利雅生希利斯；希利斯生以利亞薩；</span>
<span className="v" id="v40" data-v="40"> 以利亞薩生西斯買；西斯買生沙龍；</span>
<span className="v" id="v41" data-v="41"> 沙龍生耶加米雅；耶加米雅生以利沙瑪。</span>
</div>
</div>

## 迦勒的其餘後裔

<div className="bt">
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="歷代志上 2:23–24; 希伯來書 12:23; 羅馬書 8:29"> 耶拉篾兄弟迦勒的長子米沙，是西弗之祖瑪利沙的兒子，是希伯崙之祖。</span>
<span className="v" id="v43" data-v="43"> 希伯崙的兒子是可拉、他普亞、利肯、示瑪。</span>
<span className="v" id="v44" data-v="44"> 示瑪生拉含，是約干之祖。利肯生沙買。</span>
<span className="v" id="v45" data-v="45" data-xref="約書亞記 15:58"> 沙買的兒子是瑪雲；瑪雲是伯‧夙之祖。</span>
<span className="v" id="v46" data-v="46" data-xref="歷代志上 2:18–19; 歷代志上 2:48"> 迦勒的妾以法生哈蘭、摩撒、迦謝；哈蘭生迦卸。（</span>
<span className="v" id="v47" data-v="47"> 雅代的兒子是利健、約坦、基珊、毗力、以法、沙亞弗。）</span>
<span className="v" id="v48" data-v="48" data-xref="創世記 25:5–6; 歷代志上 2:46"> 迦勒的妾瑪迦生示別、特哈拿，</span>
<span className="v" id="v49" data-v="49" data-xref="約書亞記 15:31; 歷代志上 2:42; 以賽亞書 10:31"> 又生麥瑪拿之祖沙亞弗、抹比拿和基比亞之祖示法。迦勒的女兒是押撒。</span>
</div>
<div className="bp">
<span className="v" id="v50" data-v="50" data-xref="撒母耳記上 7:1; 約書亞記 15:60; 歷代志上 2:53"> 迦勒的子孫就是以法她的長子、戶珥的兒子，記在下面：基列‧耶琳之祖朔巴，</span>
<span className="v" id="v51" data-v="51" data-xref="歷代志上 4:4; 約翰福音 7:42; 馬太福音 2:6"> 伯利恆之祖薩瑪，伯迦得之祖哈勒。</span>
<span className="v" id="v52" data-v="52" data-xref="歷代志上 4:2"> 基列‧耶琳之祖朔巴的子孫是哈羅以和一半米努‧哈人<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="米努‧哈人就是瑪拿哈人">c</a></sup>。</span>
<span className="v" id="v53" data-v="53" data-xref="撒母耳記下 23:38; 士師記 13:25; 士師記 13:2"> 基列‧耶琳的諸族是以帖人、布特人、舒瑪人、密來人，又從這些族中生出瑣拉人和以實陶人來。</span>
<span className="v" id="v54" data-v="54" data-xref="尼希米記 7:26; 以斯拉記 2:22; 尼希米記 12:28"> 薩瑪的子孫是伯利恆人、尼陀法人、亞他綠‧伯‧約押人、一半瑪拿哈人、瑣利人，</span>
<span className="v" id="v55" data-v="55" data-xref="列王紀下 10:15; 士師記 1:16; 耶利米書 35:19"> 和住雅比斯眾文士家的特拉人、示米押人、蘇甲人。這都是基尼人利甲家之祖哈末所生的。</span>
</div>

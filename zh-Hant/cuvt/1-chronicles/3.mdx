## 大衛的兒女

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳記下 3:2–5; 約書亞記 15:56; 撒母耳記下 13:1"> 大衛在希伯崙所生的兒子記在下面：長子暗嫩是耶斯列人亞希暖生的。次子但以利是迦密人亞比該生的。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳記下 19:4–10; 撒母耳記下 3:4; 列王紀上 2:24–25"> 三子押沙龍是基述王達買的女兒瑪迦生的。四子亞多尼雅是哈及生的。</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳記下 3:5"> 五子示法提雅是亞比她生的。六子以特念是大衛的妻以格拉生的。</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳記下 2:11; 撒母耳記下 5:4–5; 列王紀上 2:11"> 這六人都是大衛在希伯崙生的。大衛在希伯崙作王七年零六個月，在耶路撒冷作王三十三年。</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳記下 11:3; 撒母耳記下 12:24–25; 撒母耳記下 12:1–15"> 大衛在耶路撒冷所生的兒子是示米亞、朔罷、拿單、所羅門。這四人是亞米利的女兒拔‧書亞生的。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳記下 5:15; 歷代志上 14:5; 撒母耳記上 14:5"> 還有益轄、以利沙瑪、以利法列、</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳記下 5:15–16"> 挪迦、尼斐、雅非亞、</span>
<span className="v" id="v8" data-v="8" data-xref="歷代志上 14:7; 撒母耳記下 5:14–16"> 以利沙瑪、以利雅大、以利法列，共九人。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳記下 13:1–20; 撒母耳記下 5:13"> 這都是大衛的兒子，還有他們的妹子她瑪，妃嬪的兒子不在其內。</span>
</div>

## 所羅門的後裔

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="列王紀上 11:43; 列王紀上 14:31–1; 列王紀上 15:24"> 所羅門的兒子是羅波安；羅波安的兒子是亞比雅；亞比雅的兒子是亞撒；亞撒的兒子是約沙法；</span>
<span className="v" id="v11" data-v="11" data-xref="列王紀下 8:24; 歷代志下 21:17; 列王紀下 11:21"> 約沙法的兒子是約蘭；約蘭的兒子是亞哈謝；亞哈謝的兒子是約阿施；</span>
<span className="v" id="v12" data-v="12" data-xref="歷代志下 25:1; 列王紀下 14:21; 列王紀下 14:1"> 約阿施的兒子是亞瑪謝；亞瑪謝的兒子是亞撒利雅；亞撒利雅的兒子是約坦；</span>
<span className="v" id="v13" data-v="13" data-xref="列王紀下 18:1; 列王紀下 16:1; 歷代志下 29:1"> 約坦的兒子是亞哈斯；亞哈斯的兒子是希西家；希西家的兒子是瑪拿西；</span>
<span className="v" id="v14" data-v="14" data-xref="列王紀下 23:30; 歷代志下 34:1; 列王紀下 21:19"> 瑪拿西的兒子是亞們；亞們的兒子是約西亞；</span>
<span className="v" id="v15" data-v="15" data-xref="列王紀下 23:34"> 約西亞的長子是約哈難，次子是約雅敬，三子是西底家，四子是沙龍。</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀下 24:6; 馬太福音 1:11; 列王紀下 24:17"> 約雅敬的兒子是耶哥尼雅和西底家。</span>
</div>

## 耶哥尼雅的後裔

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="以斯拉記 3:2; 以斯拉記 5:2; 馬太福音 1:12"> 耶哥尼雅被擄。他的兒子是撒拉鐵、</span>
<span className="v" id="v18" data-v="18"> 瑪基蘭、毗大雅、示拿薩、耶加米、何沙瑪、尼大比雅。</span>

<span className="v" id="v20" data-v="20"> 米書蘭的兒子是哈舒巴、阿黑、比利家、哈撒底、于沙‧希悉，共五人。</span>
<span className="v" id="v21" data-v="21" data-xref="尼希米記 10:22"> 哈拿尼雅的兒子是毗拉提、耶篩亞。還有利法雅的眾子，亞珥難的眾子，俄巴底亞的眾子，示迦尼的眾子。</span>
<span className="v" id="v22" data-v="22" data-xref="以斯拉記 8:2"> 示迦尼的兒子是示瑪雅；示瑪雅的兒子是哈突、以甲、巴利亞、尼利雅、沙法，共六人。</span>
<span className="v" id="v23" data-v="23"> 尼利雅的兒子是以利約乃、希西家、亞斯利干，共三人。</span>
<span className="v" id="v24" data-v="24"> 以利約乃的兒子是何大雅、以利亞實、毗萊雅、阿谷、約哈難、第萊雅、阿拿尼，共七人。</span>

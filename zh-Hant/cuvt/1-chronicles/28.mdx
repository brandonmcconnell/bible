## 大衛對建殿的指示

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歷代志上 23:2; 歷代志上 11:10–47; 歷代志上 27:1–34"> 大衛招聚以色列各支派的首領和輪班服事王的軍長，與千夫長、百夫長，掌管王和王子產業牲畜的，並太監，以及大能的勇士，都到耶路撒冷來。</span>
<span className="v" id="v2" data-v="2" data-xref="詩篇 99:5; 以賽亞書 66:1; 歷代志上 17:1–2"> 大衛王就站起來，說：「我的弟兄，我的百姓啊，你們當聽我言，我心裏本想建造殿宇，安放耶和華的約櫃，作為我上帝的腳凳；我已經預備建造的材料。</span>
<span className="v" id="v3" data-v="3" data-xref="歷代志上 22:8; 歷代志上 17:4; 歷代志下 6:8–9"> 只是上帝對我說：『你不可為我的名建造殿宇；因你是戰士，流了人的血。』</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳記上 16:1; 歷代志上 5:2; 撒母耳記上 16:6–13"> 然而，耶和華－以色列的上帝在我父的全家揀選我作以色列的王，直到永遠。因他揀選猶大為首領；在猶大支派中揀選我父家，在我父的眾子裏喜悅我，立我作以色列眾人的王。</span>
<span className="v" id="v5" data-v="5" data-xref="歷代志上 3:1–9; 歷代志上 23:1; 歷代志上 22:9–10"> 耶和華賜我許多兒子，在我兒子中揀選所羅門坐耶和華的國位，治理以色列人。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳記下 7:13–14; 歷代志上 22:9–10; 希伯來書 3:6"> 耶和華對我說：『你兒子所羅門必建造我的殿和院宇；因為我揀選他作我的子，我也必作他的父。</span>
<span className="v" id="v7" data-v="7" data-xref="歷代志上 22:13; 列王紀上 8:61; 列王紀上 6:12–13"> 他若恆久遵行我的誡命典章如今日一樣，我就必堅定他的國位，直到永遠。』</span>
<span className="v" id="v8" data-v="8" data-xref="申命記 4:1; 申命記 5:32–3; 箴言 2:1–5"> 現今在耶和華的會中，以色列眾人眼前所說的，我們的上帝也聽見了。你們應當尋求耶和華－你們上帝的一切誡命，謹守遵行，如此你們可以承受這美地，遺留給你們的子孫，永遠為業。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="耶利米書 29:13; 雅各書 4:8–11; 馬太福音 7:7–8"> 「我兒所羅門哪，你當認識耶和華－你父的上帝，誠心樂意地事奉他；因為他鑒察眾人的心，知道一切心思意念。你若尋求他，他必使你尋見；你若離棄他，他必永遠丟棄你。</span>
<span className="v" id="v10" data-v="10" data-xref="歷代志上 28:6; 提摩太前書 4:16; 歷代志上 22:16–19"> 你當謹慎，因耶和華揀選你建造殿宇作為聖所。你當剛強去行。」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="歷代志上 28:19; 列王紀上 6:3; 出埃及記 25:40"> 大衛將殿的遊廊、旁屋、府庫、樓房、內殿，和施恩所的樣式指示他兒子所羅門，</span>
<span className="v" id="v12" data-v="12" data-xref="歷代志上 26:20; 列王紀上 14:26; 出埃及記 25:40"> 又將被靈感動所得的樣式，就是耶和華上帝殿的院子、周圍的房屋、殿的府庫，和聖物府庫的一切樣式都指示他；</span>
<span className="v" id="v13" data-v="13" data-xref="歷代志上 9:29; 歷代志上 25:1–31; 列王紀上 7:1–51"> 又指示他祭司和利未人的班次與耶和華殿裏各樣的工作，並耶和華殿裏一切器皿的樣式，</span>
<span className="v" id="v14" data-v="14"> 以及各樣應用金器的分兩和各樣應用銀器的分兩，</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及記 25:31–39; 撒迦利亞書 4:11–14; 啟示錄 1:12–13"> 金燈臺和金燈的分兩，銀燈臺和銀燈的分兩，輕重各都合宜；</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀上 7:48; 歷代志下 4:8; 出埃及記 25:23–30"> 陳設餅金桌子的分兩，銀桌子的分兩，</span>
<span className="v" id="v17" data-v="17" data-xref="列王紀上 10:21; 歷代志下 4:20–22; 民數記 7:13–14"> 精金的肉叉子、盤子，和爵的分兩，各金碗與各銀碗的分兩，</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及記 25:18–22; 出埃及記 30:1–10; 詩篇 80:1"> 精金香壇的分兩，並用金子做基路伯<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是用金子做車式的基路伯">a</a></sup>；基路伯張開翅膀，遮掩耶和華的約櫃。</span>
<span className="v" id="v19" data-v="19" data-xref="歷代志上 28:11–12; 出埃及記 25:40; 以西結書 3:14"> 大衛說：「這一切工作的樣式都是耶和華用手劃出來使我明白的。」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="歷代志上 22:13; 約書亞記 1:5–9; 以賽亞書 41:10"> 大衛又對他兒子所羅門說：「你當剛強壯膽去行！不要懼怕，也不要驚惶。因為耶和華上帝就是我的上帝，與你同在；他必不撇下你，也不丟棄你，直到耶和華殿的工作都完畢了。</span>
<span className="v" id="v21" data-v="21" data-xref="歷代志上 24:1–26; 歷代志上 22:17–18; 出埃及記 31:3"> 有祭司和利未人的各班，為要辦理上帝殿各樣的事，又有靈巧的人在各樣的工作上樂意幫助你；並有眾首領和眾民一心聽從你的命令。」</span>
</div>
</div>

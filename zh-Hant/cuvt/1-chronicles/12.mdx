## 早期跟隨大衛的便雅憫人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳記上 27:2–6; 歷代志上 11:24–25; 歷代志上 8:33"> 大衛因怕基士的兒子掃羅，躲在洗革拉的時候，有勇士到他那裏幫助他打仗。</span>
<span className="v" id="v2" data-v="2" data-xref="士師記 3:15; 士師記 20:16; 撒母耳記上 17:49"> 他們善於拉弓，能用左右兩手甩石射箭，都是便雅憫人掃羅的族弟兄。</span>
<span className="v" id="v3" data-v="3" data-xref="歷代志上 11:28; 撒母耳記下 21:6; 歷代志上 11:33"> 為首的是亞希以謝，其次是約阿施，都是基比亞人示瑪的兒子。還有亞斯瑪威的兒子耶薛和毗力，又有比拉迦，並亞拿突人耶戶，</span>
<span className="v" id="v4" data-v="4" data-xref="約書亞記 9:3; 約書亞記 15:36; 歷代志上 11:15"> 基遍人以實買雅（他在三十人中是勇士，管理他們），且有耶利米、雅哈悉、約哈難，和基得拉人約撒拔、</span>
<span className="v" id="v5" data-v="5"> 伊利烏賽、耶利摩、比亞利雅、示瑪利雅，哈律弗人示法提雅，</span>
<span className="v" id="v6" data-v="6"> 可拉人以利加拿、耶西亞、亞薩列、約以謝、雅朔班，</span>
<span className="v" id="v7" data-v="7" data-xref="約書亞記 15:58; 歷代志上 4:18; 歷代志上 4:39"> 基多人耶羅罕的兒子猶拉和西巴第雅。</span>
</div>
</div>

## 跟隨大衛的迦得人

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="撒母耳記下 2:18; 撒母耳記下 17:10; 撒母耳記下 23:20"> 迦得支派中有人到曠野的山寨投奔大衛，都是大能的勇士，能拿盾牌和槍的戰士。他們的面貌好像獅子，快跑如同山上的鹿。</span>
<span className="v" id="v9" data-v="9"> 第一以薛，第二俄巴底雅，第三以利押，</span>
<span className="v" id="v10" data-v="10"> 第四彌施瑪拿，第五耶利米，</span>
<span className="v" id="v11" data-v="11"> 第六亞太，第七以利業，</span>
<span className="v" id="v12" data-v="12"> 第八約哈難，第九以利薩巴，</span>
<span className="v" id="v13" data-v="13"> 第十耶利米，第十一末巴奈。</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 32:30; 利未記 26:8"> 這都是迦得人中的軍長，至小的能抵一百人，至大的能抵一千人。</span>
<span className="v" id="v15" data-v="15" data-xref="約書亞記 3:15; 約書亞記 4:18; 耶利米書 49:19"> 正月，約旦河水漲過兩岸的時候，他們過河，使一切住平原的人東奔西逃。</span>
</div>
</div>

## 跟隨大衛的便雅憫人和猶大人

<div className="bt">
<div className="bp poetry">
<span className="v" id="v16" data-v="16"> 又有便雅憫和猶大人到山寨大衛那裏。</span>
<span className="v" id="v17" data-v="17" data-xref="彼得前書 2:23; 猶大書 1:9; 哥林多後書 13:11"> 大衛出去迎接他們，對他們說：「你們若是和和平平地來幫助我，我心就與你們相契；你們若是將我這無罪的人賣在敵人手裏，願我們列祖的上帝察看責罰。」</span>
<span className="v" id="v18" data-v="18" data-xref="士師記 6:34; 士師記 3:10; 撒母耳記下 17:25"> 那時上帝的靈感動那三十個勇士的首領亞瑪撒，他就說：<br /><span className="pl pl-1">大衛啊，我們是歸於你的！</span><br /><span className="pl pl-1">耶西的兒子啊，我們是幫助你的！</span><br /><span className="pl pl-1">願你平平安安，</span><br /><span className="pl pl-1">願幫助你的也都平安！</span><br /><span className="pl pl-1">因為你的上帝幫助你。</span><br />大衛就收留他們，立他們作軍長。</span>
</div>
</div>

## 跟隨大衛的瑪拿西人

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="撒母耳記上 29:2–9"> 大衛從前與非利士人同去，要與掃羅爭戰，有些瑪拿西人來投奔大衛，他們卻沒有幫助非利士人；因為非利士人的首領商議，打發他們回去，說：「恐怕大衛拿我們的首級，歸降他的主人掃羅。」</span>
<span className="v" id="v20" data-v="20" data-xref="申命記 33:17; 申命記 1:15; 撒母耳記上 29:11"> 大衛往洗革拉去的時候，有瑪拿西人的千夫長押拿、約撒拔、耶疊、米迦勒、約撒拔、以利戶、洗勒太都來投奔他。</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳記上 30:1–17; 歷代志上 12:20; 歷代志上 5:24"> 這些人幫助大衛攻擊群賊；他們都是大能的勇士，且作軍長。</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳記下 3:1; 約伯記 17:9; 創世記 32:2"> 那時天天有人來幫助大衛，以致成了大軍，如上帝的軍一樣。</span>
</div>
</div>

## 大衛的軍力

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="撒母耳記下 2:3–4; 歷代志上 11:10; 撒母耳記上 16:1"> 預備打仗的兵來到希伯崙見大衛，要照着耶和華的話將掃羅的國位歸與大衛。他們的數目如下：</span>
<span className="v" id="v24" data-v="24"> 猶大支派，拿盾牌和槍預備打仗的有六千八百人。</span>
<span className="v" id="v25" data-v="25"> 西緬支派，能上陣大能的勇士有七千一百人。</span>
<span className="v" id="v26" data-v="26"> 利未支派有四千六百人。</span>
<span className="v" id="v27" data-v="27" data-xref="列王紀下 11:9; 列王紀下 25:18; 歷代志上 6:49–57"> 耶何耶大是亞倫家的首領，跟從他的有三千七百人。</span>
<span className="v" id="v28" data-v="28" data-xref="撒母耳記下 8:17; 歷代志上 6:8; 歷代志上 6:53"> 還有少年大能的勇士撒督，同着他的有族長二十二人。</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳記下 2:8–9; 歷代志上 12:2; 創世記 31:23"> 便雅憫支派，掃羅的族弟兄也有三千人，他們向來大半歸順掃羅家。</span>
<span className="v" id="v30" data-v="30" data-xref="創世記 6:4"> 以法蓮支派大能的勇士，在本族著名的有二萬零八百人。</span>
<span className="v" id="v31" data-v="31" data-xref="約書亞記 17:1–18"> 瑪拿西半支派，冊上有名的共一萬八千人，都來立大衛作王。</span>
<span className="v" id="v32" data-v="32" data-xref="以弗所書 5:17; 路加福音 12:56–57; 以斯帖記 1:13"> 以薩迦支派，有二百族長都通達時務，知道以色列人所當行的；他們族弟兄都聽從他們的命令。</span>
<span className="v" id="v33" data-v="33" data-xref="詩篇 12:2; 約翰福音 1:47"> 西布倫支派，能上陣用各樣兵器打仗、行伍整齊、不生二心的有五萬人。</span>
<span className="v" id="v34" data-v="34"> 拿弗他利支派，有一千軍長；跟從他們、拿盾牌和槍的有三萬七千人。</span>
<span className="v" id="v35" data-v="35"> 但支派，能擺陣的有二萬八千六百人。</span>
<span className="v" id="v36" data-v="36" data-xref="歷代志上 12:33; 約珥書 2:7"> 亞設支派，能上陣打仗的有四萬人。</span>
<span className="v" id="v37" data-v="37" data-xref="約書亞記 14:3; 申命記 3:12–16; 約書亞記 13:7–32"> 約旦河東的呂便支派、迦得支派、瑪拿西半支派，拿着各樣兵器打仗的有十二萬人。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="創世記 49:8–10; 列王紀上 8:61; 詩篇 101:2"> 以上都是能守行伍的戰士，他們都誠心來到希伯崙，要立大衛作以色列的王。以色列其餘的人也都一心要立大衛作王。</span>
<span className="v" id="v39" data-v="39" data-xref="創世記 31:54; 撒母耳記下 19:42; 創世記 26:30"> 他們在那裏三日，與大衛一同吃喝，因為他們的族弟兄給他們預備了。</span>
<span className="v" id="v40" data-v="40" data-xref="撒母耳記上 25:18; 撒母耳記下 16:1; 耶利米書 23:5–6"> 靠近他們的人以及以薩迦、西布倫、拿弗他利人將許多麵餅、無花果餅、乾葡萄、酒、油，用驢、駱駝、騾子、牛馱來，又帶了許多的牛和羊來，因為以色列人甚是歡樂。</span>
</div>
</div>

## 保羅為腓立比信徒禱告

<div className="bt">
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="哥林多前書 1:4; 帖撒羅尼迦前書 1:2–3; 腓利門書 1:4–5"> 我每逢想念你們，就感謝我的上帝；</span>
<span className="v" id="v4" data-v="4" data-xref="帖撒羅尼迦前書 1:2; 羅馬書 1:9; 約翰二書 1:4"> 每逢為你們眾人祈求的時候，常是歡歡喜喜地祈求。</span>
<span className="v" id="v5" data-v="5" data-xref="腓立比書 4:14–15; 腓立比書 1:7; 希伯來書 3:14"> 因為從頭一天直到如今，你們是同心合意地興旺福音。</span>
<span className="v" id="v6" data-v="6" data-xref="帖撒羅尼迦前書 5:23–24; 腓立比書 2:13; 以弗所書 4:12"> 我深信那在你們心裏動了善工的，必成全這工，直到耶穌基督的日子。</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多後書 7:3; 腓立比書 1:5; 歌羅西書 4:18"> 我為你們眾人有這樣的意念，原是應當的；因你們常在我心裏，無論我是在捆鎖之中，是辯明證實福音的時候，你們都與我一同得恩。</span>
<span className="v" id="v8" data-v="8" data-xref="腓立比書 4:1; 羅馬書 1:9; 提摩太後書 1:4"> 我體會基督耶穌的心腸，切切地想念你們眾人；這是上帝可以給我作見證的。</span>
<span className="v" id="v9" data-v="9" data-xref="帖撒羅尼迦前書 3:12; 歌羅西書 1:9; 彼得後書 1:5–6"> 我所禱告的，就是要你們的愛心在知識和各樣見識上多而又多，</span>
<span className="v" id="v10" data-v="10" data-xref="羅馬書 12:2; 帖撒羅尼迦前書 3:13; 帖撒羅尼迦前書 5:23"> 使你們能分別是非<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或譯：喜愛那美好的事">a</a></sup>，作誠實無過的人，直到基督的日子；</span>
<span className="v" id="v11" data-v="11" data-xref="希伯來書 12:11; 約翰福音 15:8; 約翰福音 15:4–5"> 並靠着耶穌基督結滿了仁義的果子，叫榮耀稱讚歸與上帝。</span>
</div>
</div>

## 我活着就是基督

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="提摩太後書 2:9; 羅馬書 8:28; 使徒行傳 11:19–21"> 弟兄們，我願意你們知道，我所遭遇的事更是叫福音興旺，</span>
<span className="v" id="v13" data-v="13" data-xref="提摩太後書 2:9; 以弗所書 3:1; 腓立比書 1:7"> 以致我受的捆鎖在御營全軍和其餘的人中，已經顯明是為基督的緣故。</span>
<span className="v" id="v14" data-v="14" data-xref="以弗所書 6:19–20; 帖撒羅尼迦前書 2:2; 路加福音 1:74"> 並且那在主裏的弟兄多半因我受的捆鎖就篤信不疑，越發放膽傳上帝的道，無所懼怕。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="羅馬書 16:17–18; 腓立比書 2:3; 哥林多後書 11:13"> 有的傳基督是出於嫉妒紛爭，也有的是出於好意。</span>
<span className="v" id="v16" data-v="16" data-xref="哥林多後書 2:17; 哥林多後書 4:1–2; 詩篇 69:26"> 這一等是出於愛心，知道我是為辯明福音設立的；</span>
<span className="v" id="v17" data-v="17" data-xref="提摩太後書 1:11–12; 腓立比書 2:3; 腓立比書 1:7"> 那一等傳基督是出於結黨，並不誠實，意思要加增我捆鎖的苦楚。</span>
<span className="v" id="v18" data-v="18" data-xref="路加福音 9:50; 馬可福音 9:38–40; 哥林多前書 15:11"> 這有何妨呢？或是假意，或是真心，無論怎樣，基督究竟被傳開了。為此，我就歡喜，並且還要歡喜；</span>
<span className="v" id="v19" data-v="19" data-xref="羅馬書 8:28; 使徒行傳 16:7; 哥林多後書 1:11"> 因為我知道，這事藉着你們的祈禱和耶穌基督之靈的幫助，終必叫我得救。</span>
<span className="v" id="v20" data-v="20" data-xref="彼得前書 4:16; 哥林多前書 6:20; 以賽亞書 54:4"> 照着我所切慕、所盼望的，沒有一事叫我羞愧。只要凡事放膽，無論是生是死，總叫基督在我身上照常顯大。</span>
<span className="v" id="v21" data-v="21" data-xref="加拉太書 2:20; 哥林多後書 5:8; 哥林多後書 5:1"> 因我活着就是基督，我死了就有益處。</span>
<span className="v" id="v22" data-v="22" data-xref="彼得前書 4:2; 加拉太書 2:20; 腓立比書 1:24"> 但我在肉身活着，若成就我工夫的果子，我就不知道該挑選甚麼。</span>
<span className="v" id="v23" data-v="23" data-xref="哥林多後書 5:8; 詩篇 17:15; 啟示錄 14:13"> 我正在兩難之間，情願離世與基督同在，因為這是好得無比的。</span>
<span className="v" id="v24" data-v="24" data-xref="約翰福音 16:7; 腓立比書 1:22; 腓立比書 1:25–26"> 然而，我在肉身活着，為你們更是要緊的。</span>
<span className="v" id="v25" data-v="25" data-xref="腓立比書 2:24; 哥林多後書 1:24; 以弗所書 4:11–13"> 我既然這樣深信，就知道仍要住在世間，且與你們眾人同住，使你們在所信的道上又長進又喜樂，</span>
<span className="v" id="v26" data-v="26" data-xref="哥林多後書 1:14; 哥林多後書 5:12; 腓立比書 3:3"> 叫你們在基督耶穌裏的歡樂，因我再到你們那裏去，就越發加增。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="以弗所書 4:1; 哥林多前書 16:13–14; 哥林多前書 1:10"> 只要你們行事為人與基督的福音相稱，叫我或來見你們，或不在你們那裏，可以聽見你們的景況，知道你們同有一個心志，站立得穩，為所信的福音齊心努力。</span>
<span className="v" id="v28" data-v="28" data-xref="提摩太後書 1:7–8; 帖撒羅尼迦後書 1:5–6; 馬太福音 10:28"> 凡事不怕敵人的驚嚇，這是證明他們沉淪，你們得救都是出於上帝。</span>
<span className="v" id="v29" data-v="29" data-xref="雅各書 1:2; 彼得前書 4:13; 使徒行傳 5:41"> 因為你們蒙恩，不但得以信服基督，並要為他受苦。</span>
<span className="v" id="v30" data-v="30" data-xref="帖撒羅尼迦前書 2:2; 使徒行傳 16:19–40; 提摩太後書 4:7"> 你們的爭戰，就與你們在我身上從前所看見、現在所聽見的一樣。</span>
</div>
</div>

## 保羅的勸導

<div className="bt">
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="希伯來書 12:14; 哥林多前書 1:10; 馬可福音 9:50"> 我勸友阿蝶和循都基，要在主裏同心。</span>
<span className="v" id="v3" data-v="3" data-xref="啟示錄 3:5; 啟示錄 13:8; 路加福音 10:20"> 我也求你這真實同負一軛的，幫助這兩個女人，因為她們在福音上曾與我一同勞苦；還有革利免，並其餘和我一同做工的，他們的名字都在生命冊上。</span>
<span className="v" id="v4" data-v="4" data-xref="帖撒羅尼迦前書 5:16–18; 羅馬書 12:12; 雅各書 1:2–4"> 你們要靠主常常喜樂。我再說，你們要喜樂。</span>
<span className="v" id="v5" data-v="5" data-xref="雅各書 5:8–9; 馬太福音 6:25; 提多書 3:2"> 當叫眾人知道你們謙讓的心。主已經近了。</span>
<span className="v" id="v6" data-v="6" data-xref="箴言 3:5–6; 彼得前書 5:7; 馬太福音 6:25–33"> 應當一無掛慮，只要凡事藉着禱告、祈求，和感謝，將你們所要的告訴上帝。</span>
<span className="v" id="v7" data-v="7" data-xref="約翰福音 14:27; 以賽亞書 26:3; 帖撒羅尼迦後書 3:16"> 上帝所賜、出人意外的平安必在基督耶穌裏保守你們的心懷意念。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="雅各書 3:17; 提多書 2:7; 羅馬書 12:9–21"> 弟兄們，我還有未盡的話：凡是真實的、可敬的、公義的、清潔的、可愛的、有美名的，若有甚麼德行，若有甚麼稱讚，這些事你們都要思念。</span>
<span className="v" id="v9" data-v="9" data-xref="雅各書 1:22; 腓立比書 3:17; 帖撒羅尼迦前書 4:1–8"> 你們在我身上所學習的，所領受的，所聽見的，所看見的，這些事你們都要去行，賜平安的上帝就必與你們同在。</span>
</div>
</div>

## 為餽送而致謝

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="哥林多後書 11:9; 加拉太書 6:6; 哥林多後書 7:6–7"> 我靠主大大地喜樂，因為你們思念我的心如今又發生；你們向來就思念我，只是沒得機會。</span>
<span className="v" id="v11" data-v="11" data-xref="提摩太前書 6:6–9; 希伯來書 13:5–6; 馬太福音 6:31–34"> 我並不是因缺乏說這話；我無論在甚麼景況都可以知足，這是我已經學會了。</span>
<span className="v" id="v12" data-v="12" data-xref="馬太福音 11:29; 哥林多後書 12:7–10; 哥林多後書 11:27"> 我知道怎樣處卑賤，也知道怎樣處豐富；或飽足，或飢餓；或有餘，或缺乏，隨事隨在，我都得了秘訣。</span>
<span className="v" id="v13" data-v="13" data-xref="以賽亞書 41:10; 哥林多後書 12:9–10; 歌羅西書 1:11"> 我靠着那加給我力量的，凡事都能做。</span>
<span className="v" id="v14" data-v="14" data-xref="希伯來書 13:16; 腓立比書 1:7; 希伯來書 10:34"> 然而，你們和我同受患難原是美事。</span>
<span className="v" id="v15" data-v="15" data-xref="腓立比書 1:5; 哥林多後書 11:8–12; 使徒行傳 16:40–5"> 腓立比人哪，你們也知道我初傳福音離了馬其頓的時候，論到授受的事，除了你們以外，並沒有別的教會供給我。</span>
<span className="v" id="v16" data-v="16" data-xref="帖撒羅尼迦前書 2:9; 使徒行傳 17:1; 帖撒羅尼迦前書 2:18"> 就是我在帖撒羅尼迦，你們也一次兩次地打發人供給我的需用。</span>
<span className="v" id="v17" data-v="17" data-xref="提多書 3:14; 希伯來書 6:10; 哥林多後書 9:9–13"> 我並不求甚麼餽送，所求的就是你們的果子漸漸增多，歸在你們的帳上。</span>
<span className="v" id="v18" data-v="18" data-xref="希伯來書 13:16; 腓立比書 4:12; 哥林多後書 9:12"> 但我樣樣都有，並且有餘。我已經充足，因我從以巴弗提受了你們的餽送，當作極美的香氣，為上帝所收納、所喜悅的祭物。</span>
<span className="v" id="v19" data-v="19" data-xref="哥林多後書 9:8–11; 詩篇 84:11; 彼得前書 5:10"> 我的上帝必照他榮耀的豐富，在基督耶穌裏，使你們一切所需用的都充足。</span>
<span className="v" id="v20" data-v="20" data-xref="羅馬書 11:36; 詩篇 115:1; 啟示錄 14:7"> 願榮耀歸給我們的父上帝，直到永永遠遠。阿們！</span>
</div>
</div>

## 耶和華命令重建聖殿

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以斯拉記 2:2; 以斯拉記 3:8; 以斯拉記 3:2"> 大流士王第二年六月初一日，耶和華的話藉先知哈該向猶大省長撒拉鐵的兒子所羅巴伯和約撒答的兒子大祭司約書亞說：</span>
<span className="v" id="v2" data-v="2" data-xref="以斯拉記 4:23–2; 尼希米記 4:10; 傳道書 11:4"> 萬軍之耶和華如此說：「這百姓說，建造耶和華殿的時候尚未來到。」</span>
<span className="v" id="v3" data-v="3" data-xref="以斯拉記 5:1; 撒迦利亞書 1:1"> 那時耶和華的話臨到先知哈該說：</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳記下 7:2; 詩篇 132:3–5; 腓立比書 2:21"> 「這殿仍然荒涼，你們自己還住天花板的房屋嗎？</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米哀歌 3:40; 哥林多後書 13:5; 哈該書 1:7"> 現在萬軍之耶和華如此說：你們要省察自己的行為。</span>
<span className="v" id="v6" data-v="6" data-xref="哈該書 1:9; 申命記 28:38–40; 何西阿書 4:10"> 你們撒的種多，收的卻少；你們吃，卻不得飽；喝，卻不得足；穿衣服，卻不得暖；得工錢的，將工錢裝在破漏的囊中。」</span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 119:59–60; 哈該書 1:5; 腓立比書 3:1"> 萬軍之耶和華如此說：「你們要省察自己的行為。</span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 132:13–14; 歷代志下 7:16; 哈該書 2:7"> 你們要上山取木料，建造這殿，我就因此喜樂，且得榮耀。這是耶和華說的。</span>
<span className="v" id="v9" data-v="9" data-xref="哈該書 1:4; 哈該書 2:16–17; 哈該書 1:6"> 你們盼望多得，所得的卻少；你們收到家中，我就吹去。這是為甚麼呢？因為我的殿荒涼，你們各人卻顧<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是奔">a</a></sup>自己的房屋。這是萬軍之耶和華說的。</span>
<span className="v" id="v10" data-v="10" data-xref="列王紀上 8:35; 利未記 26:19; 申命記 28:23–24"> 所以為你們的緣故，天就不降甘露，地也不出土產。</span>
<span className="v" id="v11" data-v="11" data-xref="哈該書 2:17; 申命記 28:22; 列王紀下 8:1"> 我命乾旱臨到地土、山岡、五穀、新酒，和油，並地上的出產、人民、牲畜，以及人手一切勞碌得來的。」</span>
</div>
</div>

## 百姓順從耶和華的命令

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="以賽亞書 50:10; 以斯拉記 5:2; 哈該書 1:14"> 那時，撒拉鐵的兒子所羅巴伯和約撒答的兒子大祭司約書亞，並剩下的百姓，都聽從耶和華－他們上帝的話和先知哈該奉耶和華－他們上帝差來所說的話；百姓也在耶和華面前存敬畏的心。</span>
<span className="v" id="v13" data-v="13" data-xref="以賽亞書 43:2; 馬太福音 28:20; 瑪拉基書 3:1"> 耶和華的使者哈該奉耶和華差遣對百姓說：「耶和華說：我與你們同在。」</span>
<span className="v" id="v14" data-v="14" data-xref="歷代志下 36:22; 希伯來書 13:21; 哈該書 2:21"> 耶和華激動猶大省長撒拉鐵的兒子所羅巴伯和約撒答的兒子大祭司約書亞，並剩下之百姓的心，他們就來為萬軍之耶和華－他們上帝的殿做工。</span>
<span className="v" id="v15" data-v="15" data-xref="哈該書 1:1; 哈該書 2:20; 哈該書 2:1"> 這是在大流士王第二年六月二十四日。</span>
</div>

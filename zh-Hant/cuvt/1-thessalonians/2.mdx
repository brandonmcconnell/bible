## 保羅在帖撒羅尼迦工作

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="帖撒羅尼迦後書 3:1; 哥林多前書 15:2; 哥林多前書 15:58"> 弟兄們，你們自己原曉得我們進到你們那裏並不是徒然的。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行傳 16:22–24; 使徒行傳 4:13; 使徒行傳 17:2–9"> 我們從前在腓立比被害受辱，這是你們知道的；然而還是靠我們的上帝放開膽量，在大爭戰中把上帝的福音傳給你們。</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多後書 2:17; 哥林多後書 4:2; 帖撒羅尼迦前書 4:7"> 我們的勸勉不是出於錯誤，不是出於污穢，也不是用詭詐。</span>
<span className="v" id="v4" data-v="4" data-xref="加拉太書 1:10; 羅馬書 8:27; 加拉太書 2:7"> 但上帝既然驗中了我們，把福音託付我們，我們就照樣講，不是要討人喜歡，乃是要討那察驗我們心的上帝喜歡。</span>
<span className="v" id="v5" data-v="5" data-xref="羅馬書 1:9; 哥林多後書 12:17; 使徒行傳 20:33"> 因為我們從來沒有用過諂媚的話，這是你們知道的；也沒有藏着貪心，這是上帝可以作見證的。</span>
<span className="v" id="v6" data-v="6" data-xref="加拉太書 1:10; 帖撒羅尼迦前書 2:9; 約翰福音 5:41"> 我們作基督的使徒，雖然可以叫人尊重，卻沒有向你們或向別人求榮耀；</span>
<span className="v" id="v7" data-v="7" data-xref="以賽亞書 66:13; 帖撒羅尼迦前書 2:11; 提摩太後書 2:24–25"> 只在你們中間存心溫柔，如同母親乳養自己的孩子。</span>
<span className="v" id="v8" data-v="8" data-xref="約翰一書 3:16; 哥林多後書 12:15; 腓立比書 2:17"> 我們既是這樣愛你們，不但願意將上帝的福音給你們，連自己的性命也願意給你們，因你們是我們所疼愛的。</span>
<span className="v" id="v9" data-v="9" data-xref="帖撒羅尼迦後書 3:7–9; 哥林多後書 11:9; 使徒行傳 18:3"> 弟兄們，你們記念我們的辛苦勞碌，晝夜做工，傳上帝的福音給你們，免得叫你們一人受累。</span>
<span className="v" id="v10" data-v="10" data-xref="彼得前書 5:3; 帖撒羅尼迦前書 1:5; 哥林多後書 1:12"> 我們向你們信主的人，是何等聖潔、公義、無可指摘，有你們作見證，也有上帝作見證。</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多前書 4:14–15; 希伯來書 13:22; 提摩太前書 5:21"> 你們也曉得，我們怎樣勸勉你們，安慰你們，囑咐你們各人，好像父親待自己的兒女一樣，</span>
<span className="v" id="v12" data-v="12" data-xref="以弗所書 4:1; 約翰一書 2:6; 約翰一書 1:6–7"> 要叫你們行事對得起那召你們進他國、得他榮耀的上帝。</span>
<span className="v" id="v13" data-v="13" data-xref="希伯來書 4:12; 羅馬書 10:17; 彼得前書 1:23"> 為此，我們也不住地感謝上帝，因你們聽見我們所傳上帝的道就領受了；不以為是人的道，乃以為是上帝的道。這道實在是上帝的，並且運行在你們信主的人心中。</span>
<span className="v" id="v14" data-v="14" data-xref="帖撒羅尼迦前書 3:4; 希伯來書 10:33–34; 希伯來書 5:7–8"> 弟兄們，你們曾效法猶太中在基督耶穌裏上帝的各教會；因為你們也受了本地人的苦害，像他們受了猶太人的苦害一樣。</span>
<span className="v" id="v15" data-v="15" data-xref="馬太福音 5:12; 路加福音 11:48–53; 使徒行傳 7:52"> 這猶太人殺了主耶穌和先知，又把我們趕出去。他們不得上帝的喜悅，且與眾人為敵，</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行傳 17:13; 使徒行傳 14:19; 馬可福音 16:16"> 不許我們傳道給外邦人使外邦人得救，常常充滿自己的罪惡。上帝的忿怒臨在他們身上已經到了極處。</span>
</div>
</div>

## 保羅希望再訪問帖撒羅尼迦教會

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="歌羅西書 2:5; 哥林多前書 5:3; 帖撒羅尼迦前書 3:6"> 弟兄們，我們暫時與你們離別，是面目離別，心裏卻不離別；我們極力地想法子，很願意見你們的面。</span>
<span className="v" id="v18" data-v="18" data-xref="羅馬書 15:22; 羅馬書 1:13; 啟示錄 2:10"> 所以我們有意到你們那裏；我－保羅有一兩次要去，只是撒但阻擋了我們。</span>
<span className="v" id="v19" data-v="19" data-xref="腓立比書 4:1; 帖撒羅尼迦前書 3:13; 腓立比書 2:16"> 我們的盼望和喜樂，並所誇的冠冕是甚麼呢？豈不是我們主耶穌來的時候、你們在他面前站立得住嗎？</span>
<span className="v" id="v20" data-v="20" data-xref="哥林多後書 1:14; 哥林多前書 11:7; 箴言 17:6"> 因為你們就是我們的榮耀，我們的喜樂。</span>

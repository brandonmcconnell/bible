<span className="v" id="v2" data-v="2" data-xref="使徒行傳 14:22–23; 以弗所書 6:21–22; 腓立比書 2:19–25"> 打發我們的兄弟在基督福音上作上帝執事的<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="作上帝執事的：有古卷是與上帝同工的">a</a></sup>提摩太前去，堅固你們，並在你們所信的道上勸慰你們，</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行傳 14:22; 羅馬書 5:3; 使徒行傳 9:16"> 免得有人被諸般患難搖動。因為你們自己知道，我們受患難原是命定的。</span>
<span className="v" id="v4" data-v="4" data-xref="帖撒羅尼迦前書 2:14; 哥林多後書 8:1–2; 帖撒羅尼迦前書 2:2"> 我們在你們那裏的時候，預先告訴你們，我們必受患難，以後果然應驗了，你們也知道。</span>
<span className="v" id="v5" data-v="5" data-xref="雅各書 1:13–14; 馬太福音 4:3; 哥林多後書 2:11"> 為此，我既不能再忍，就打發人去，要曉得你們的信心如何，恐怕那誘惑人的到底誘惑了你們，叫我們的勞苦歸於徒然。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="哥林多前書 11:2; 以賽亞書 52:7; 箴言 25:25"> 但提摩太剛才從你們那裏回來，將你們信心和愛心的好消息報給我們，又說你們常常記念我們，切切地想見我們，如同我們想見你們一樣。</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多後書 1:4; 約翰二書 1:4; 帖撒羅尼迦前書 3:8–9"> 所以，弟兄們，我們在一切困苦患難之中，因着你們的信心就得了安慰。</span>
<span className="v" id="v8" data-v="8" data-xref="歌羅西書 1:23; 哥林多前書 16:13; 啟示錄 3:11"> 你們若靠主站立得穩，我們就活了。</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 71:14–15; 詩篇 96:12–13; 哥林多後書 9:15"> 我們在上帝面前，因着你們甚是喜樂；為這一切喜樂，可用何等的感謝為你們報答上帝呢？</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多後書 13:9; 帖撒羅尼迦前書 3:11; 腓立比書 1:25"> 我們晝夜切切地祈求，要見你們的面，補滿你們信心的不足。</span>
</div>
<div className="bp">

<span className="v" id="v12" data-v="12" data-xref="腓立比書 1:9; 約翰一書 4:7–16; 馬太福音 22:39"> 又願主叫你們彼此相愛的心，並愛眾人的心都能增長，充足，如同我們愛你們一樣，</span>
<span className="v" id="v13" data-v="13" data-xref="歌羅西書 1:22; 帖撒羅尼迦前書 5:23; 以弗所書 5:27"> 好使你們當我們主耶穌同他眾聖徒來的時候，在我們父上帝面前，心裏堅固，成為聖潔，無可責備。</span>
</div>

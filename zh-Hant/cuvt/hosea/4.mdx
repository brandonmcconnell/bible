## 耶和華譴責以色列

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="耶利米書 4:22; 彌迦書 6:2; 以賽亞書 3:13–14"> <span className="pl pl-1">以色列人哪，你們當聽耶和華的話。</span><br /><span className="pl pl-1">耶和華與這地的居民爭辯，</span><br /><span className="pl pl-1">因這地上無誠實，</span><br /><span className="pl pl-1">無良善，無人認識上帝。</span><br /></span>

## 譴責祭司

<div className="bt">
<div className="bp poetry">
<span className="v" id="v4" data-v="4" data-xref="申命記 17:12; 何西阿書 4:17; 阿摩司書 5:13"> <span className="pl pl-1">然而，人都不必爭辯，也不必指責，</span><br /><span className="pl pl-1">因為這民與抗拒祭司的人一樣。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="耶利米書 15:8; 何西阿書 2:2; 加拉太書 4:26"> <span className="pl pl-1">你這祭司必日間跌倒；</span><br /><span className="pl pl-1">先知也必夜間與你一同跌倒；</span><br /><span className="pl pl-1">我必滅絕你的母親。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="以賽亞書 5:13; 箴言 19:2; 何西阿書 6:6"> <span className="pl pl-1">我的民因無知識而滅亡。</span><br /><span className="pl pl-1">你棄掉知識，</span><br /><span className="pl pl-1">我也必棄掉你，</span><br /><span className="pl pl-1">使你不再給我作祭司。</span><br /><span className="pl pl-1">你既忘了你上帝的律法，</span><br /><span className="pl pl-1">我也必忘記你的兒女。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="何西阿書 13:6; 腓立比書 3:19; 撒母耳記上 2:30"> <span className="pl pl-1">祭司越發增多，就越發得罪我；</span><br /><span className="pl pl-1">我必使他們的榮耀變為羞辱。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="彌迦書 3:11; 以賽亞書 56:11; 提多書 1:11"> <span className="pl pl-1">他們吃我民的贖罪祭，</span><br /><span className="pl pl-1">滿心願意我民犯罪。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="以賽亞書 24:2; 耶利米書 5:31; 馬太福音 15:14"> <span className="pl pl-1">將來民如何，</span><br /><span className="pl pl-1">祭司也必如何；</span><br /><span className="pl pl-1">我必因他們所行的懲罰他們，</span><br /><span className="pl pl-1">照他們所做的報應他們。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="彌迦書 6:14; 利未記 26:26; 哈該書 1:6"> <span className="pl pl-1">他們吃，卻不得飽；</span><br /><span className="pl pl-1">行淫，而不得立後；</span><br /><span className="pl pl-1">因為他們離棄耶和華，</span><br /><span className="pl pl-1">不遵他的命。</span></span>
</div>
</div>

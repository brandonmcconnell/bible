## 災難的起頭

<div className="bt">
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="馬太福音 21:1; 馬可福音 4:34; 馬可福音 14:33"> 耶穌在橄欖山上對聖殿而坐。彼得、雅各、約翰，和安得烈暗暗地問他說：</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行傳 1:6–7; 馬太福音 24:3; 但以理書 12:6"> 「請告訴我們，甚麼時候有這些事呢？這一切事將成的時候有甚麼預兆呢？」</span>
<span className="v" id="v5" data-v="5" data-xref="歌羅西書 2:8; 以弗所書 5:6; 耶利米書 29:8"> 耶穌說：「你們要謹慎，免得有人迷惑你們。</span>
<span className="v" id="v6" data-v="6" data-xref="馬可福音 13:22; 耶利米書 23:21–25; 約翰福音 8:24"> 將來有好些人冒我的名來，說：『我是基督』，並且要迷惑許多人。</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 21:9–11; 約翰福音 14:27; 馬太福音 24:6–7"> 你們聽見打仗和打仗的風聲，不要驚慌。這些事是必須有的，只是末期還沒有到。</span>
<span className="v" id="v8" data-v="8" data-xref="馬太福音 24:8; 以賽亞書 37:3; 詩篇 48:6"> 民要攻打民，國要攻打國；多處必有地震、饑荒。這都是災難<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="災難：原文是生產之難">a</a></sup>的起頭。</span>
<span className="v" id="v9" data-v="9" data-xref="馬太福音 10:17–18; 約翰福音 16:2; 腓立比書 1:29"> 但你們要謹慎；因為人要把你們交給公會， 並且你們在會堂裏要受鞭打，又為我的緣故站在諸侯與君王面前，對他們作見證。</span>
<span className="v" id="v10" data-v="10" data-xref="馬太福音 24:14; 歌羅西書 1:23; 羅馬書 10:18"> 然而，福音必須先傳給萬民。</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 21:14–15; 路加福音 12:11–12; 馬太福音 10:19–21"> 人把你們拉去交官的時候，不要預先思慮說甚麼；到那時候，賜給你們甚麼話，你們就說甚麼；因為說話的不是你們，乃是聖靈。</span>
<span className="v" id="v12" data-v="12" data-xref="馬太福音 10:21; 路加福音 12:52–53; 路加福音 21:16"> 弟兄要把弟兄，父親要把兒子，送到死地；兒女要起來與父母為敵，害死他們；</span>
<span className="v" id="v13" data-v="13" data-xref="約翰福音 15:18–19; 馬太福音 10:22; 馬太福音 24:13"> 並且你們要為我的名被眾人恨惡。惟有忍耐到底的，必然得救。」</span>
</div>
</div>

## 大災難

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="但以理書 9:27; 但以理書 12:11; 但以理書 11:31"> 「你們看見那行毀壞可憎的，站在不當站的地方（讀這經的人須要會意）。那時，在猶太的，應當逃到山上；</span>
<span className="v" id="v15" data-v="15" data-xref="路加福音 17:31–33; 希伯來書 11:7; 腓立比書 3:7–8"> 在房上的，不要下來，也不要進去拿家裏的東西；</span>
<span className="v" id="v16" data-v="16"> 在田裏的，也不要回去取衣裳。</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米哀歌 4:10; 路加福音 23:29; 何西阿書 9:14"> 當那些日子，懷孕的和奶孩子的有禍了！</span>
<span className="v" id="v18" data-v="18"> 你們應當祈求，叫這些事不在冬天臨到。</span>
<span className="v" id="v19" data-v="19" data-xref="但以理書 12:1; 約珥書 2:2; 馬太福音 24:21"> 因為在那些日子必有災難，自從上帝創造萬物直到如今，並沒有這樣的災難，後來也必沒有。</span>
<span className="v" id="v20" data-v="20" data-xref="馬太福音 24:22; 撒迦利亞書 13:8–9; 以賽亞書 65:8–9"> 若不是主減少那日子，凡有血氣的，總沒有一個得救的；只是為主的選民，他將那日子減少了。</span>
<span className="v" id="v21" data-v="21" data-xref="路加福音 21:8; 馬太福音 24:23–25; 馬太福音 24:5"> 那時若有人對你們說：『看哪，基督在這裏』，或說：『基督在那裏』，你們不要信！</span>
<span className="v" id="v22" data-v="22" data-xref="馬太福音 24:24; 帖撒羅尼迦後書 2:8–14; 馬可福音 13:6"> 因為假基督、假先知將要起來，顯神蹟奇事，倘若能行，就把選民迷惑了。</span>
<span className="v" id="v23" data-v="23" data-xref="彼得後書 3:17; 馬可福音 13:5; 約翰福音 14:29"> 你們要謹慎。看哪，凡事我都預先告訴你們了。」</span>
</div>
</div>

## 人子的降臨

<div className="bt">
<div className="bp poetry">
<span className="v" id="v24" data-v="24" data-xref="以賽亞書 13:10; 使徒行傳 2:19–20; 啟示錄 6:12–14"> <span className="pl pl-1">「在那些日子，那災難以後，</span><br /><span className="pl pl-1">日頭要變黑了，</span><br /><span className="pl pl-1">月亮也不放光，</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="以賽亞書 34:4; 啟示錄 6:13"> <span className="pl pl-1">眾星要從天上墜落，</span><br /><span className="pl pl-1">天勢都要震動。</span></span>
<span className="v" id="v26" data-v="26" data-xref="啟示錄 1:7; 馬太福音 16:27; 馬太福音 24:30"> 那時，他們<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="馬太二十四章三十節是地上的萬族">b</a></sup>要看見人子有大能力、大榮耀，駕雲降臨。</span>
<span className="v" id="v27" data-v="27" data-xref="撒迦利亞書 2:6; 馬太福音 24:31; 申命記 30:4"> 他要差遣天使，把他的選民，從四方<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="方：原文是風">c</a></sup>，從地極直到天邊，都招聚了來。」</span>

## 從無花果樹學個比方

<div className="bt">
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="路加福音 21:29–31; 馬太福音 24:32–33"> 「你們可以從無花果樹學個比方：當樹枝發嫩長葉的時候，你們就知道夏天近了。</span>
<span className="v" id="v29" data-v="29" data-xref="彼得前書 4:17–18; 雅各書 5:9; 以西結書 12:25–28"> 這樣，你們幾時看見這些事成就，也該知道人子<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="人子：或譯上帝的國">d</a></sup>近了，正在門口了。</span>
<span className="v" id="v30" data-v="30" data-xref="馬太福音 24:34; 路加福音 21:32; 馬太福音 16:28"> 我實在告訴你們，這世代還沒有過去，這些事都要成就。</span>
<span className="v" id="v31" data-v="31" data-xref="以賽亞書 40:8; 以賽亞書 51:6; 馬太福音 24:35"> 天地要廢去，我的話卻不能廢去。」</span>
</div>

## 那日那時沒有人知道

<div className="bt">
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="使徒行傳 1:7; 馬太福音 24:36–42; 馬太福音 25:13"> 「但那日子，那時辰，沒有人知道，連天上的使者也不知道，子也不知道，惟有父知道。</span>
<span className="v" id="v33" data-v="33" data-xref="以弗所書 6:18; 路加福音 12:40; 羅馬書 13:11–12"> 你們要謹慎，警醒祈禱，因為你們不曉得那日期幾時來到。</span>
<span className="v" id="v34" data-v="34" data-xref="馬太福音 25:14–30; 約翰福音 10:3; 路加福音 12:36–40"> 這事正如一個人離開本家，寄居外邦，把權柄交給僕人，分派各人當做的工，又吩咐看門的警醒。</span>
<span className="v" id="v35" data-v="35" data-xref="馬可福音 13:33; 馬太福音 24:42; 馬太福音 24:44"> 所以，你們要警醒；因為你們不知道家主甚麼時候來，或晚上，或半夜，或雞叫，或早晨；</span>
<span className="v" id="v36" data-v="36" data-xref="帖撒羅尼迦前書 5:6–7; 羅馬書 13:11–14; 馬太福音 24:48–51"> 恐怕他忽然來到，看見你們睡着了。</span>
<span className="v" id="v37" data-v="37" data-xref="馬可福音 13:33; 路加福音 12:41–46; 馬可福音 13:35"> 我對你們所說的話，也是對眾人說：要警醒！」</span>
</div>
</div>

## 治好枯乾了一隻手的人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="馬太福音 12:9–14; 路加福音 6:6–11; 馬可福音 1:21"> 耶穌又進了會堂，在那裏有一個人枯乾了一隻手。</span>
<span className="v" id="v2" data-v="2" data-xref="詩篇 37:32; 路加福音 14:1; 路加福音 6:7"> 眾人窺探耶穌，在安息日醫治不醫治，意思是要控告耶穌。</span>
<span className="v" id="v3" data-v="3" data-xref="腓立比書 1:28–30; 以賽亞書 42:4; 路加福音 6:8"> 耶穌對那枯乾一隻手的人說：「起來，站在當中。」</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 6:9; 馬太福音 12:10–12; 何西阿書 6:6"> 又問眾人說：「在安息日行善行惡，救命害命，哪樣是可以的呢？」他們都不作聲。</span>
<span className="v" id="v5" data-v="5" data-xref="路加福音 6:10; 以弗所書 4:18; 羅馬書 11:25"> 耶穌怒目周圍看他們，憂愁他們的心剛硬，就對那人說：「伸出手來！」他把手一伸，手就復了原。</span>
<span className="v" id="v6" data-v="6" data-xref="馬太福音 22:16; 馬可福音 12:13; 馬太福音 12:14"> 法利賽人出去，同希律一黨的人商議怎樣可以除滅耶穌。</span>
</div>
</div>

## 海邊的群眾

<div className="bt">
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="馬太福音 4:25; 路加福音 6:17; 馬太福音 12:15"> 耶穌和門徒退到海邊去，有許多人從加利利跟隨他。</span>
<span className="v" id="v8" data-v="8" data-xref="以西結書 35:15; 以賽亞書 34:5; 馬太福音 11:21"> 還有許多人聽見他所做的大事，就從猶太、耶路撒冷、以土買、約旦河外，並泰爾、西頓的四方來到他那裏。</span>
<span className="v" id="v9" data-v="9" data-xref="馬可福音 5:30; 約翰福音 6:15"> 他因為人多，就吩咐門徒叫一隻小船伺候着，免得眾人擁擠他。</span>
<span className="v" id="v10" data-v="10" data-xref="馬太福音 14:36; 馬可福音 6:56; 馬太福音 4:23"> 他治好了許多人，所以凡有災病的，都擠進來要摸他。</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 4:41; 馬可福音 1:23–24; 路加福音 8:28"> 污鬼無論何時看見他，就俯伏在他面前，喊着說：「你是上帝的兒子。」</span>
<span className="v" id="v12" data-v="12" data-xref="馬太福音 12:16; 馬可福音 1:25; 馬可福音 1:34"> 耶穌再三地囑咐他們，不要把他顯露出來。</span>
</div>
</div>

## 設立十二門徒

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="路加福音 9:1; 路加福音 6:12–16; 馬太福音 10:1–4"> 耶穌上了山，隨自己的意思叫人來；他們便來到他那裏。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行傳 1:8; 路加福音 9:1–6; 約翰福音 15:16"> 他就設立十二個人，要他們常和自己同在，也要差他們去傳道，</span>
<span className="v" id="v15" data-v="15"> 並給他們權柄趕鬼。</span>
<span className="v" id="v16" data-v="16" data-xref="約翰福音 1:42; 使徒行傳 1:13; 馬太福音 16:16–18"> 這十二個人有西門（耶穌又給他起名叫彼得），</span>
<span className="v" id="v17" data-v="17" data-xref="希伯來書 4:12; 馬可福音 14:33; 耶利米書 23:29"> 還有西庇太的兒子雅各和雅各的兄弟約翰（又給這兩個人起名叫半尼其，就是雷子的意思），</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行傳 1:13; 馬可福音 2:14; 馬太福音 9:9"> 又有安得烈、腓力、巴多羅買、馬太、多馬、亞勒腓的兒子雅各，和達太，並奮銳黨的西門，</span>
<span className="v" id="v19" data-v="19" data-xref="約翰福音 6:71; 約翰福音 13:2; 使徒行傳 1:16–25"> 還有賣耶穌的加略人猶大。</span>
</div>
</div>

## 耶穌和別西卜

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="馬可福音 6:31; 約翰福音 4:31–34; 馬可福音 9:28"> 耶穌進了一個屋子，眾人又聚集，甚至他連飯也顧不得吃。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行傳 26:24; 約翰福音 10:20; 馬可福音 3:31"> 耶穌的親屬聽見，就出來要拉住他，因為他們說他癲狂了。</span>
<span className="v" id="v22" data-v="22" data-xref="馬太福音 15:1; 馬太福音 10:25; 馬太福音 9:34"> 從耶路撒冷下來的文士說：「他是被別西卜附着」；又說：「他是靠着鬼王趕鬼。」</span>
<span className="v" id="v23" data-v="23" data-xref="路加福音 11:17–23; 馬太福音 12:25–30; 馬太福音 13:34"> 耶穌叫他們來，用比喻對他們說：「撒但怎能趕出撒但呢？</span>
<span className="v" id="v24" data-v="24" data-xref="撒迦利亞書 11:14; 以賽亞書 19:2–3; 撒母耳記下 20:6"> 若一國自相紛爭，那國就站立不住；</span>
<span className="v" id="v25" data-v="25" data-xref="雅各書 3:16; 詩篇 133:1; 加拉太書 5:15"> 若一家自相紛爭，那家就站立不住。</span>
<span className="v" id="v26" data-v="26"> 若撒但自相攻打紛爭，他就站立不住，必要滅亡。</span>
<span className="v" id="v27" data-v="27" data-xref="以賽亞書 49:24–26; 馬太福音 12:29; 路加福音 11:21–23"> 沒有人能進壯士家裏，搶奪他的家具；必先捆住那壯士，才可以搶奪他的家。</span>
<span className="v" id="v28" data-v="28" data-xref="路加福音 12:10; 馬太福音 12:31–32; 約翰一書 5:16"> 我實在告訴你們，世人一切的罪和一切褻瀆的話都可得赦免；</span>
<span className="v" id="v29" data-v="29" data-xref="馬太福音 12:31–32; 路加福音 12:10; 帖撒羅尼迦後書 1:9"> 凡褻瀆聖靈的，卻永不得赦免，乃要擔當永遠的罪。」</span>
<span className="v" id="v30" data-v="30" data-xref="約翰福音 10:20; 馬可福音 3:22"> 這話是因為他們說：「他是被污鬼附着的。」</span>
</div>
</div>

## 耶穌的母親和兄弟們

<div className="bt">
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="路加福音 8:19–21; 馬太福音 12:46–50"> 當下，耶穌的母親和弟兄來，站在外邊，打發人去叫他。</span>
<span className="v" id="v32" data-v="32"> 有許多人在耶穌周圍坐着，他們就告訴他說：「看哪，你母親和你弟兄在外邊找你。」</span>
<span className="v" id="v33" data-v="33" data-xref="馬可福音 3:21; 申命記 33:9; 馬可福音 6:3"> 耶穌回答說：「誰是我的母親？誰是我的弟兄？」</span>
<span className="v" id="v34" data-v="34" data-xref="馬太福音 12:49–50; 路加福音 11:27–28; 羅馬書 8:29"> 就四面觀看那周圍坐着的人，說：「看哪，我的母親，我的弟兄。</span>
<span className="v" id="v35" data-v="35" data-xref="約翰一書 2:17; 馬太福音 7:21; 約翰一書 3:22–23"> 凡遵行上帝旨意的人就是我的弟兄姊妹和母親了。」</span>
</div>
</div>

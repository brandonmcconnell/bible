## 耶穌在彼拉多面前受審

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="馬太福音 27:1–2; 路加福音 23:1–5; 路加福音 22:66"> 一到早晨，祭司長和長老、文士、全公會的人大家商議，就把耶穌捆綁，解去交給彼拉多。</span>
<span className="v" id="v2" data-v="2" data-xref="馬太福音 2:2; 馬太福音 27:11–14; 提摩太前書 6:13"> 彼拉多問他說：「你是猶太人的王嗎？」耶穌回答說：「你說的是。」</span>
<span className="v" id="v3" data-v="3" data-xref="以賽亞書 53:7; 馬可福音 15:5; 約翰福音 18:29–31"> 祭司長告他許多的事。</span>
<span className="v" id="v4" data-v="4" data-xref="約翰福音 19:10; 馬太福音 27:13; 馬太福音 26:62"> 彼拉多又問他說：「你看，他們告你這麼多的事，你甚麼都不回答嗎？」</span>
<span className="v" id="v5" data-v="5" data-xref="以賽亞書 53:7; 撒迦利亞書 3:8; 詩篇 71:7"> 耶穌仍不回答，以致彼拉多覺得希奇。</span>
</div>
</div>

## 耶穌被判死刑

<div className="bt">
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="約翰福音 18:39–40; 使徒行傳 25:9; 使徒行傳 24:27"> 每逢這節期，巡撫照眾人所求的，釋放一個囚犯給他們。</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 23:18–19; 馬太福音 27:16; 路加福音 23:25"> 有一個人名叫巴拉巴，和作亂的人一同捆綁。他們作亂的時候，曾殺過人。</span>
<span className="v" id="v8" data-v="8"> 眾人上去求巡撫，照常例給他們辦。</span>
<span className="v" id="v9" data-v="9" data-xref="約翰福音 19:14–16; 約翰福音 19:4–5; 約翰福音 18:39"> 彼拉多說：「你們要我釋放猶太人的王給你們嗎？」</span>
<span className="v" id="v10" data-v="10" data-xref="箴言 27:4; 提多書 3:3; 創世記 4:4–6"> 他原曉得，祭司長是因為嫉妒才把耶穌解了來。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行傳 3:14; 約翰福音 18:40; 何西阿書 5:1"> 只是祭司長挑唆眾人，寧可釋放巴拉巴給他們。</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米書 23:5–6; 以賽亞書 9:6–7; 撒迦利亞書 9:9"> 彼拉多又說：「那麼樣，你們所稱為猶太人的王，我怎麼辦他呢？」</span>
<span className="v" id="v13" data-v="13"> 他們又喊着說：「把他釘十字架！」</span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 23:41; 路加福音 23:23–24; 以賽亞書 53:3"> 彼拉多說：「為甚麼呢？他做了甚麼惡事呢？」他們便極力地喊着說：「把他釘十字架！」</span>
<span className="v" id="v15" data-v="15" data-xref="約翰福音 19:1; 馬太福音 27:26; 以賽亞書 50:6"> 彼拉多要叫眾人喜悅，就釋放巴拉巴給他們，將耶穌鞭打了，交給人釘十字架。</span>
</div>
</div>

## 兵丁戲弄耶穌

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="約翰福音 19:9; 馬太福音 27:27–31; 約翰福音 18:28"> 兵丁把耶穌帶進衙門院裏，叫齊了全營的兵。</span>
<span className="v" id="v17" data-v="17" data-xref="馬太福音 27:28–30; 約翰福音 19:2–5; 路加福音 23:11"> 他們給他穿上紫袍，又用荊棘編做冠冕給他戴上，</span>
<span className="v" id="v18" data-v="18" data-xref="馬太福音 27:42–43; 馬可福音 15:2; 創世記 37:10"> 就慶賀他說：「恭喜，猶太人的王啊！」</span>
<span className="v" id="v19" data-v="19" data-xref="馬可福音 14:65; 以賽亞書 53:3–5; 路加福音 23:11"> 又拿一根葦子打他的頭，吐唾沫在他臉上，屈膝拜他。</span>
<span className="v" id="v20" data-v="20" data-xref="約翰福音 19:16; 馬太福音 27:31"> 戲弄完了，就給他脫了紫袍，仍穿上他自己的衣服，帶他出去，要釘十字架。</span>
</div>
</div>

## 耶穌被釘十字架

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="馬太福音 27:32; 路加福音 23:26; 羅馬書 16:13"> 有一個古利奈人西門，就是亞歷山大和魯孚的父親，從鄉下來，經過那地方，他們就勉強他同去，好背着耶穌的十字架。</span>
<span className="v" id="v22" data-v="22" data-xref="馬太福音 27:33–44; 約翰福音 19:17–27; 路加福音 23:27–38"> 他們帶耶穌到了各各他地方（各各他翻出來就是髑髏地），</span>
<span className="v" id="v23" data-v="23" data-xref="馬太福音 27:34; 約翰福音 19:28–30; 路加福音 23:36"> 拿沒藥調和的酒給耶穌，他卻不受。</span>
<span className="v" id="v24" data-v="24" data-xref="路加福音 23:34; 約翰福音 19:23–24; 馬太福音 27:35–36"> 於是將他釘在十字架上，拈鬮分他的衣服，看是誰得甚麼。</span>
<span className="v" id="v25" data-v="25" data-xref="約翰福音 19:14; 馬可福音 15:33; 馬太福音 27:45"> 釘他在十字架上是巳初的時候。</span>
<span className="v" id="v26" data-v="26" data-xref="馬太福音 27:37; 馬太福音 2:2; 約翰福音 19:18–22"> 在上面有他的罪狀，寫的是：「猶太人的王。」</span>
<span className="v" id="v27" data-v="27" data-xref="路加福音 23:32–33; 馬太福音 27:38; 約翰福音 19:18"> 他們又把兩個強盜和他同釘十字架，一個在右邊，一個在左邊。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古卷加：28這就應了經上的話說：他被列在罪犯之中。">a</a></sup></span>
<span className="v" id="v29" data-v="29" data-xref="馬可福音 14:58; 詩篇 109:25; 耶利米哀歌 1:12"> 從那裏經過的人辱罵他，搖着頭說：「咳！你這拆毀聖殿、三日又建造起來的，</span>
<span className="v" id="v30" data-v="30"> 可以救自己，從十字架上下來吧！」</span>
<span className="v" id="v31" data-v="31" data-xref="約翰福音 12:23–24; 馬太福音 27:41–43; 路加福音 23:35–37"> 祭司長和文士也是這樣戲弄他，彼此說：「他救了別人，不能救自己。</span>
<span className="v" id="v32" data-v="32" data-xref="馬太福音 27:44; 路加福音 23:39–43; 撒迦利亞書 9:9"> 以色列的王基督，現在可以從十字架上下來，叫我們看見，就信了。」那和他同釘的人也是譏誚他。</span>
</div>
</div>

## 耶穌的死

<div className="bt">
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="馬太福音 27:45; 路加福音 23:44–45; 阿摩司書 8:9–10"> 從午正到申初，遍地都黑暗了。</span>
<span className="v" id="v34" data-v="34" data-xref="詩篇 22:1; 馬太福音 27:46; 希伯來書 5:7"> 申初的時候，耶穌大聲喊着說：「以羅伊！以羅伊！拉馬撒巴各大尼？」（翻出來就是：我的上帝！我的上帝！為甚麼離棄我？）</span>
<span className="v" id="v35" data-v="35" data-xref="馬太福音 27:47–49; 馬可福音 9:11–13; 馬太福音 17:11–13"> 旁邊站着的人，有的聽見就說：「看哪，他叫以利亞呢！」</span>
<span className="v" id="v36" data-v="36" data-xref="詩篇 69:21; 馬可福音 15:23; 約翰福音 19:28–30"> 有一個人跑去，把海絨蘸滿了醋，綁在葦子上，送給他喝，說：「且等着，看以利亞來不來把他取下。」</span>
<span className="v" id="v37" data-v="37" data-xref="約翰福音 19:30; 路加福音 23:46; 馬太福音 27:50"> 耶穌大聲喊叫，氣就斷了。</span>
<span className="v" id="v38" data-v="38" data-xref="希伯來書 10:19–23; 路加福音 23:45; 希伯來書 9:3–12"> 殿裏的幔子從上到下裂為兩半。</span>
<span className="v" id="v39" data-v="39" data-xref="馬太福音 27:54; 路加福音 23:47–48; 馬太福音 27:43"> 對面站着的百夫長看見耶穌這樣喊叫<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有古卷沒有喊叫二字">b</a></sup>斷氣，就說：「這人真是上帝的兒子！」</span>
<span className="v" id="v40" data-v="40" data-xref="路加福音 23:49; 路加福音 8:2–3; 馬太福音 27:55–56"> 還有些婦女遠遠地觀看；內中有抹大拉的馬利亞，又有小雅各和約西的母親馬利亞，並有撒羅米，</span>
<span className="v" id="v41" data-v="41" data-xref="路加福音 8:2–3; 馬太福音 27:55–56"> 就是耶穌在加利利的時候，跟隨他、服事他的那些人，還有同耶穌上耶路撒冷的好些婦女在那裏觀看。</span>
</div>
</div>

## 耶穌的安葬

<div className="bt">
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="路加福音 23:50–56; 約翰福音 19:38–42; 約翰福音 19:31"> 到了晚上，因為這是預備日，就是安息日的前一日，</span>
<span className="v" id="v43" data-v="43" data-xref="路加福音 2:38; 路加福音 2:25; 路加福音 23:51"> 有亞利馬太的約瑟前來，他是尊貴的議士，也是等候上帝國的。他放膽進去見彼拉多，求耶穌的身體；</span>
<span className="v" id="v44" data-v="44" data-xref="約翰福音 19:31–37"> 彼拉多詫異耶穌已經死了，便叫百夫長來，問他耶穌死了久不久。</span>
<span className="v" id="v45" data-v="45" data-xref="馬太福音 27:58; 約翰福音 19:38; 馬可福音 15:39"> 既從百夫長得知實情，就把耶穌的屍首賜給約瑟。</span>
<span className="v" id="v46" data-v="46" data-xref="以賽亞書 53:9; 馬太福音 27:59–60; 以賽亞書 22:16"> 約瑟買了細麻布，把耶穌取下來，用細麻布裹好，安放在磐石中鑿出來的墳墓裏，又滾過一塊石頭來擋住墓門。</span>
<span className="v" id="v47" data-v="47" data-xref="馬可福音 15:40; 馬可福音 16:1; 路加福音 23:55–2"> 抹大拉的馬利亞和約西的母親馬利亞都看見安放他的地方。</span>
</div>
</div>

## 拿撒勒人厭棄耶穌

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 4:16–30; 馬太福音 13:54–58; 馬太福音 2:23"> 耶穌離開那裏，來到自己的家鄉；門徒也跟從他。</span>
<span className="v" id="v2" data-v="2" data-xref="約翰福音 7:15; 約翰福音 6:42; 使徒行傳 4:13–14"> 到了安息日，他在會堂裏教訓人。眾人聽見，就甚希奇，說：「這人從哪裏有這些事呢？所賜給他的是甚麼智慧？他手所做的是何等的異能呢？</span>
<span className="v" id="v3" data-v="3" data-xref="馬太福音 12:46; 馬太福音 13:55–57; 約翰福音 6:42"> 這不是那木匠嗎？不是馬利亞的兒子雅各、約西、猶大、西門的長兄嗎？他妹妹們不也是在我們這裏嗎？」他們就厭棄他<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="厭棄他：原文是因他跌倒">a</a></sup>。</span>
<span className="v" id="v4" data-v="4" data-xref="約翰福音 4:44; 路加福音 4:24; 馬太福音 13:57"> 耶穌對他們說：「大凡先知，除了本地、親屬、本家之外，沒有不被人尊敬的。」</span>
<span className="v" id="v5" data-v="5" data-xref="馬太福音 13:58; 馬可福音 9:23; 馬可福音 5:23"> 耶穌就在那裏不得行甚麼異能，不過按手在幾個病人身上，治好他們。</span>
<span className="v" id="v6" data-v="6" data-xref="馬太福音 9:35; 馬太福音 8:10; 路加福音 13:22"> 他也詫異他們不信，就往周圍鄉村教訓人去了。</span>
</div>
</div>

## 耶穌差遣十二門徒

<div className="bt">
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="傳道書 4:9–10; 路加福音 10:17–20; 馬太福音 10:1–5"> 耶穌叫了十二個門徒來，差遣他們兩個兩個地出去，也賜給他們權柄，制伏污鬼；</span>
<span className="v" id="v8" data-v="8" data-xref="路加福音 9:3; 馬太福音 10:9–10; 路加福音 10:4"> 並且囑咐他們：「行路的時候不要帶食物和口袋，腰袋裏也不要帶錢，除了柺杖以外，甚麼都不要帶；</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行傳 12:8; 以弗所書 6:15"> 只要穿鞋，也不要穿兩件褂子」；</span>
<span className="v" id="v10" data-v="10" data-xref="路加福音 10:7–8; 路加福音 9:4; 馬太福音 10:11–13"> 又對他們說：「你們無論到何處，進了人的家，就住在那裏，直到離開那地方。</span>
<span className="v" id="v11" data-v="11" data-xref="馬太福音 10:14–15; 使徒行傳 18:6; 路加福音 10:10–15"> 何處的人不接待你們，不聽你們，你們離開那裏的時候，就把腳上的塵土跺下去，對他們作見證。」</span>
<span className="v" id="v12" data-v="12" data-xref="馬太福音 4:17; 路加福音 13:3; 使徒行傳 20:21"> 門徒就出去傳道，叫人悔改，</span>
<span className="v" id="v13" data-v="13" data-xref="雅各書 5:14–15; 馬可福音 6:7; 路加福音 10:17"> 又趕出許多的鬼，用油抹了許多病人，治好他們。</span>
</div>
</div>

## 施洗約翰的死

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="路加福音 9:7–9; 馬可福音 6:14–29; 路加福音 23:7–12"> 耶穌的名聲傳揚出來。希律王聽見了，就說：「施洗的約翰從死裏復活了，所以這些異能由他裏面發出來。」</span>
<span className="v" id="v15" data-v="15" data-xref="馬太福音 16:14; 瑪拉基書 4:5; 馬太福音 21:11"> 但別人說：「是以利亞。」又有人說：「是先知，正像先知中的一位。」</span>
<span className="v" id="v16" data-v="16" data-xref="啟示錄 11:10–13; 馬太福音 27:4; 路加福音 9:9"> 希律聽見卻說：「是我所斬的約翰，他復活了。」</span>
<span className="v" id="v17" data-v="17" data-xref="路加福音 3:19–20; 馬太福音 11:2; 路加福音 3:1"> 先是希律為他兄弟腓力的妻子希羅底的緣故，差人去拿住約翰，鎖在監裏，因為希律已經娶了那婦人。</span>
<span className="v" id="v18" data-v="18" data-xref="利未記 20:21; 利未記 18:16; 列王紀上 22:14"> 約翰曾對希律說：「你娶你兄弟的妻子是不合理的。」</span>
<span className="v" id="v19" data-v="19" data-xref="傳道書 7:9; 以弗所書 4:26–27; 創世記 39:17–20"> 於是希羅底懷恨他，想要殺他，只是不能；</span>
<span className="v" id="v20" data-v="20" data-xref="馬太福音 21:26; 馬太福音 14:5; 歷代志下 24:15–22"> 因為希律知道約翰是義人，是聖人，所以敬畏他，保護他，聽他講論，就多照着行<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有古卷：游移不定">b</a></sup>，並且樂意聽他。</span>
<span className="v" id="v21" data-v="21" data-xref="以斯帖記 2:18; 創世記 40:20; 彼得前書 4:3"> 有一天，恰巧是希律的生日，希律擺設筵席，請了大臣和千夫長，並加利利作首領的。</span>
<span className="v" id="v22" data-v="22" data-xref="以斯帖記 1:10–12; 馬太福音 14:6; 但以理書 5:2"> 希羅底的女兒進來跳舞，使希律和同席的人都歡喜。王就對女子說：「你隨意向我求甚麼，我必給你。」</span>
<span className="v" id="v23" data-v="23" data-xref="以斯帖記 7:2; 以斯帖記 5:3; 以斯帖記 5:6"> 又對她起誓說：「隨你向我求甚麼，就是我國的一半，我也必給你。」</span>
<span className="v" id="v24" data-v="24" data-xref="約伯記 31:31; 以西結書 19:2–3; 創世記 27:8–11"> 她就出去對她母親說：「我可以求甚麼呢？」她母親說：「施洗約翰的頭。」</span>
<span className="v" id="v25" data-v="25" data-xref="羅馬書 3:15; 民數記 7:19–89; 民數記 7:13"> 她就急忙進去見王，求他說：「我願王立時把施洗約翰的頭放在盤子裏給我。」</span>
<span className="v" id="v26" data-v="26" data-xref="馬太福音 27:24–25; 馬太福音 14:9; 馬太福音 27:3–5"> 王就甚憂愁；但因他所起的誓，又因同席的人，就不肯推辭，</span>
<span className="v" id="v27" data-v="27" data-xref="馬太福音 14:10–11"> 隨即差一個護衛兵，吩咐拿約翰的頭來。護衛兵就去，在監裏斬了約翰，</span>
<span className="v" id="v28" data-v="28"> 把頭放在盤子裏，拿來給女子，女子就給她母親。</span>
<span className="v" id="v29" data-v="29" data-xref="馬太福音 14:12; 歷代志下 24:16; 馬太福音 27:57–60"> 約翰的門徒聽見了，就來把他的屍首領去，葬在墳墓裏。</span>
</div>
</div>

## 耶穌給五千人吃飽

<div className="bt">
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="路加福音 9:10; 路加福音 10:17; 馬太福音 10:2"> 使徒聚集到耶穌那裏，將一切所做的事、所傳的道全告訴他。</span>
<span className="v" id="v31" data-v="31" data-xref="馬可福音 3:20; 約翰福音 6:1; 馬可福音 1:45"> 他就說：「你們來，同我暗暗地到曠野地方去歇一歇。」這是因為來往的人多，他們連吃飯也沒有工夫。</span>
<span className="v" id="v32" data-v="32" data-xref="馬可福音 8:2–9; 馬可福音 6:45; 馬可福音 4:36"> 他們就坐船，暗暗地往曠野地方去。</span>
<span className="v" id="v33" data-v="33" data-xref="約翰福音 6:2; 馬太福音 15:29–31; 馬可福音 6:54–55"> 眾人看見他們去，有許多認識他們的，就從各城步行，一同跑到那裏，比他們先趕到了。</span>
<span className="v" id="v34" data-v="34" data-xref="馬太福音 9:36; 路加福音 9:11; 民數記 27:17"> 耶穌出來，見有許多的人，就憐憫他們，因為他們如同羊沒有牧人一般，於是開口教訓他們許多道理。</span>
<span className="v" id="v35" data-v="35" data-xref="約翰福音 6:5–15; 路加福音 9:12–17; 馬太福音 14:15–21"> 天已經晚了，門徒進前來，說：「這是野地，天已經晚了，</span>
<span className="v" id="v36" data-v="36" data-xref="馬太福音 15:23; 馬可福音 3:21; 馬可福音 5:31"> 請叫眾人散開，他們好往四面鄉村裏去，自己買甚麼吃。」</span>
<span className="v" id="v37" data-v="37" data-xref="列王紀下 4:42–44; 馬太福音 15:32–33; 馬可福音 8:2–3"> 耶穌回答說：「你們給他們吃吧。」門徒說：「我們可以去買二十兩銀子的餅給他們吃嗎？」</span>
<span className="v" id="v38" data-v="38" data-xref="馬太福音 15:34; 馬可福音 8:5; 約翰福音 6:9"> 耶穌說：「你們有多少餅，可以去看看。」他們知道了，就說：「五個餅，兩條魚。」</span>
<span className="v" id="v39" data-v="39" data-xref="哥林多前書 14:40; 哥林多前書 14:33; 馬太福音 15:35"> 耶穌吩咐他們，叫眾人一幫一幫地坐在青草地上。</span>
<span className="v" id="v40" data-v="40" data-xref="路加福音 9:14–15"> 眾人就一排一排地坐下，有一百一排的，有五十一排的。</span>
<span className="v" id="v41" data-v="41" data-xref="馬太福音 14:19; 馬可福音 7:34; 路加福音 9:16"> 耶穌拿着這五個餅，兩條魚，望着天祝福，擘開餅，遞給門徒，擺在眾人面前，也把那兩條魚分給眾人。</span>
<span className="v" id="v42" data-v="42" data-xref="路加福音 9:17; 馬可福音 8:8–9; 馬太福音 15:37–38"> 他們都吃，並且吃飽了。</span>
<span className="v" id="v43" data-v="43" data-xref="馬可福音 8:19–20"> 門徒就把碎餅碎魚收拾起來，裝滿了十二個籃子。</span>
<span className="v" id="v44" data-v="44"> 吃餅的男人共有五千。</span>
</div>
</div>

## 耶穌在海上行走

<div className="bt">
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="馬太福音 14:22–33; 約翰福音 6:15–21; 馬可福音 6:32"> 耶穌隨即催門徒上船，先渡到那邊伯賽大去，等他叫眾人散開。</span>
<span className="v" id="v46" data-v="46" data-xref="馬可福音 1:35; 馬太福音 6:6; 路加福音 6:12"> 他既辭別了他們，就往山上去禱告。</span>
<span className="v" id="v47" data-v="47" data-xref="馬太福音 14:23; 約翰福音 6:16–17"> 到了晚上，船在海中，耶穌獨自在岸上；</span>
<span className="v" id="v48" data-v="48" data-xref="路加福音 24:28; 路加福音 12:38; 約伯記 9:8"> 看見門徒因風不順，搖櫓甚苦。夜裏約有四更天，就在海面上走，往他們那裏去，意思要走過他們去。</span>
<span className="v" id="v49" data-v="49" data-xref="馬太福音 14:25–26; 路加福音 24:37; 約伯記 9:8"> 但門徒看見他在海面上走，以為是鬼怪，就喊叫起來；</span>
<span className="v" id="v50" data-v="50" data-xref="馬太福音 14:27; 約翰福音 6:19–20; 以賽亞書 43:2"> 因為他們都看見了他，且甚驚慌。耶穌連忙對他們說：「你們放心！是我，不要怕！」</span>
<span className="v" id="v51" data-v="51" data-xref="詩篇 93:3–4; 馬可福音 4:39; 約翰福音 6:21"> 於是到他們那裏，上了船，風就住了；他們心裏十分驚奇。</span>
<span className="v" id="v52" data-v="52" data-xref="馬可福音 8:17–21; 路加福音 24:25; 以賽亞書 63:17"> 這是因為他們不明白那分餅的事，心裏還是愚頑。</span>
</div>
</div>

## 治好革尼撒勒的病人

<div className="bt">
<div className="bp">
<span className="v" id="v53" data-v="53" data-xref="馬太福音 14:34–36; 約翰福音 6:24–25; 路加福音 5:1"> 既渡過去，來到革尼撒勒地方，就靠了岸，</span>
<span className="v" id="v54" data-v="54" data-xref="詩篇 9:10; 腓立比書 3:10"> 一下船，眾人認得是耶穌，</span>
<span className="v" id="v55" data-v="55" data-xref="馬太福音 4:24; 馬可福音 2:1–3; 馬可福音 3:7–11"> 就跑遍那一帶地方，聽見他在何處，便將有病的人用褥子抬到那裏。</span>
<span className="v" id="v56" data-v="56" data-xref="馬太福音 9:20; 路加福音 6:19; 民數記 15:38–39"> 凡耶穌所到的地方，或村中，或城裏，或鄉間，他們都將病人放在街市上，求耶穌只容他們摸他的衣裳繸子；凡摸着的人就都好了。</span>
</div>

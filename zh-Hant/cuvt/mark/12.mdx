## 凶惡園戶的比喻

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="以賽亞書 5:1–4; 馬可福音 13:34; 雅歌 8:11–12"> 耶穌就用比喻對他們說：「有人栽了一個葡萄園，周圍圈上籬笆，挖了一個壓酒池，蓋了一座樓，租給園戶，就往外國去了。</span>
<span className="v" id="v2" data-v="2" data-xref="約翰福音 15:1–8; 希伯來書 1:1; 耶利米書 44:4"> 到了時候，打發一個僕人到園戶那裏，要從園戶收葡萄園的果子。</span>
<span className="v" id="v3" data-v="3" data-xref="帖撒羅尼迦前書 2:15; 尼希米記 9:26; 耶利米書 29:26"> 園戶拿住他，打了他，叫他空手回去。</span>
<span className="v" id="v4" data-v="4"> 再打發一個僕人到他們那裏。他們打傷他的頭，並且凌辱他。</span>
<span className="v" id="v5" data-v="5" data-xref="馬太福音 22:6; 馬太福音 23:37; 尼希米記 9:30"> 又打發一個僕人去，他們就殺了他。後又打發好些僕人去，有被他們打的，有被他們殺的。</span>
<span className="v" id="v6" data-v="6" data-xref="希伯來書 1:1–2; 馬太福音 3:17; 約翰福音 1:34"> 園主還有一位是他的愛子，末後又打發他去，意思說：『他們必尊敬我的兒子。』</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 37:20; 馬太福音 2:16; 使徒行傳 2:23"> 不料，那些園戶彼此說：『這是承受產業的。來吧，我們殺他，產業就歸我們了！』</span>
<span className="v" id="v8" data-v="8" data-xref="馬太福音 21:39; 路加福音 20:15; 馬太福音 21:33"> 於是拿住他，殺了他，把他丟在園外。</span>
<span className="v" id="v9" data-v="9" data-xref="羅馬書 10:20–12; 馬太福音 21:43; 路加福音 19:27"> 這樣，葡萄園的主人要怎麼辦呢？他要來除滅那些園戶，將葡萄園轉給別人。</span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 118:22–23; 彼得前書 2:7–8; 以賽亞書 28:16"> 經上寫着說：<br /><span className="pl pl-1">匠人所棄的石頭</span><br /><span className="pl pl-1">已作了房角的頭塊石頭。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 118:23; 使徒行傳 3:12–16; 哈巴谷書 1:5"> <span className="pl pl-1">這是主所做的，</span><br /><span className="pl pl-1">在我們眼中看為希奇。</span><br />這經你們沒有念過嗎？」</span>
<span className="v" id="v12" data-v="12" data-xref="馬可福音 11:18; 馬太福音 22:22; 約翰福音 7:44"> 他們看出這比喻是指着他們說的，就想要捉拿他，只是懼怕百姓，於是離開他走了。</span>
</div>
</div>

## 納稅給凱撒的問題

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="路加福音 20:20–26; 路加福音 11:54; 馬可福音 3:6"> 後來，他們打發幾個法利賽人和幾個希律黨的人到耶穌那裏，要就着他的話陷害他。</span>
<span className="v" id="v14" data-v="14" data-xref="帖撒羅尼迦前書 2:4; 路加福音 20:22; 約翰福音 7:18"> 他們來了，就對他說：「夫子，我們知道你是誠實的，甚麼人你都不徇情面；因為你不看人的外貌，乃是誠誠實實傳上帝的道。納稅給凱撒可以不可以？</span>
<span className="v" id="v15" data-v="15" data-xref="以西結書 17:2; 啟示錄 2:23; 馬可福音 10:2"> 我們該納不該納？」耶穌知道他們的假意，就對他們說：「你們為甚麼試探我？拿一個銀錢來給我看！」</span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 20:24–26; 啟示錄 3:12; 馬太福音 22:19–22"> 他們就拿了來。耶穌說：「這像和這號是誰的？」他們說：「是凱撒的。」</span>
<span className="v" id="v17" data-v="17" data-xref="羅馬書 13:7; 彼得前書 2:17; 哥林多後書 5:14–15"> 耶穌說：「凱撒的物當歸給凱撒，上帝的物當歸給上帝。」他們就很希奇他。</span>
</div>
</div>

## 復活的問題

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="馬太福音 22:23–33; 使徒行傳 4:1–2; 使徒行傳 23:6–9"> 撒都該人常說沒有復活的事。他們來問耶穌說：</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 25:5–10; 路得記 4:5; 路得記 1:11–13"> 「夫子，摩西為我們寫着說：『人若死了，撇下妻子，沒有孩子，他兄弟當娶他的妻，為哥哥生子立後。』</span>
<span className="v" id="v20" data-v="20" data-xref="馬太福音 22:25–28; 路加福音 20:29–33"> 有弟兄七人，第一個娶了妻，死了，沒有留下孩子。</span>
<span className="v" id="v21" data-v="21"> 第二個娶了她，也死了，沒有留下孩子。第三個也是這樣。</span>
<span className="v" id="v22" data-v="22"> 那七個人都沒有留下孩子；末了，那婦人也死了。</span>
<span className="v" id="v23" data-v="23"> 當復活的時候，她是哪一個的妻子呢？因為他們七個人都娶過她。」</span>
<span className="v" id="v24" data-v="24" data-xref="約翰福音 20:9; 提摩太後書 3:15–17; 馬太福音 22:29"> 耶穌說：「你們所以錯了，豈不是因為不明白聖經，不曉得上帝的大能嗎？</span>
<span className="v" id="v25" data-v="25" data-xref="路加福音 20:35–36; 馬太福音 22:30; 約翰一書 3:2"> 人從死裏復活，也不娶也不嫁，乃像天上的使者一樣。</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及記 3:2–6; 路加福音 20:37; 創世記 17:7–8"> 論到死人復活，你們沒有念過摩西的書荊棘篇上所載的嗎？上帝對摩西說：『我是亞伯拉罕的上帝，以撒的上帝，雅各的上帝。』</span>
<span className="v" id="v27" data-v="27" data-xref="羅馬書 14:9; 羅馬書 4:17; 馬可福音 12:24"> 上帝不是死人的上帝，乃是活人的上帝。你們是大錯了。」</span>
</div>
</div>

## 最大的誡命

<div className="bt">
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="馬太福音 22:34–40; 路加福音 10:25–28; 路加福音 20:39"> 有一個文士來，聽見他們辯論，曉得耶穌回答的好，就問他說：「誡命中哪是第一要緊的呢？」</span>
<span className="v" id="v29" data-v="29" data-xref="申命記 6:4; 路加福音 10:27; 加拉太書 3:20"> 耶穌回答說：「第一要緊的就是說：『以色列啊，你要聽，主－我們上帝是獨一的主。</span>
<span className="v" id="v30" data-v="30" data-xref="申命記 6:5"> 你要盡心、盡性、盡意、盡力愛主－你的上帝。』</span>
<span className="v" id="v31" data-v="31" data-xref="羅馬書 13:8–9; 馬太福音 22:39; 利未記 19:18"> 其次就是說：『要愛人如己。 』再沒有比這兩條誡命更大的了。」</span>
<span className="v" id="v32" data-v="32" data-xref="申命記 4:39; 申命記 4:35; 以賽亞書 46:9"> 那文士對耶穌說：「夫子說，上帝是一位，實在不錯；除了他以外，再沒有別的上帝；</span>
<span className="v" id="v33" data-v="33" data-xref="何西阿書 6:6; 彌迦書 6:6–8; 撒母耳記上 15:22"> 並且盡心、盡智、盡力愛他，又愛人如己，就比一切燔祭和各樣祭祀好的多。」</span>
<span className="v" id="v34" data-v="34" data-xref="歌羅西書 4:6; 路加福音 20:40; 馬太福音 22:46"> 耶穌見他回答的有智慧，就對他說：「你離上帝的國不遠了。」從此以後，沒有人敢再問他甚麼。</span>
</div>
</div>

## 寡婦的奉獻

<div className="bt">
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="路加福音 21:1–4; 列王紀下 12:9; 約翰福音 8:20"> 耶穌對銀庫坐着，看眾人怎樣投錢入庫。有好些財主往裏投了若干的錢。</span>
<span className="v" id="v42" data-v="42"> 有一個窮寡婦來，往裏投了兩個小錢，就是一個大錢。</span>
<span className="v" id="v43" data-v="43" data-xref="哥林多後書 9:6–8; 哥林多後書 8:2; 使徒行傳 11:29"> 耶穌叫門徒來，說：「我實在告訴你們，這窮寡婦投入庫裏的，比眾人所投的更多。</span>
<span className="v" id="v44" data-v="44" data-xref="哥林多後書 8:2–3; 約翰一書 3:17; 以斯拉記 2:68–69"> 因為，他們都是自己有餘，拿出來投在裏頭；但這寡婦是自己不足，把她一切養生的都投上了。」</span>

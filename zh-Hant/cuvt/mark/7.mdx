## 古人的傳統

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="馬太福音 15:1–20; 馬可福音 3:22; 路加福音 5:17"> 有法利賽人和幾個文士從耶路撒冷來，到耶穌那裏聚集。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行傳 10:28; 馬太福音 7:3–5; 羅馬書 14:14"> 他們曾看見他的門徒中有人用俗手，就是沒有洗的手，吃飯。（</span>
<span className="v" id="v3" data-v="3" data-xref="加拉太書 1:14; 馬可福音 7:13; 歌羅西書 2:8"> 原來法利賽人和猶太人都拘守古人的遺傳，若不仔細洗手就不吃飯；</span>
<span className="v" id="v4" data-v="4" data-xref="希伯來書 9:10; 馬太福音 23:25; 路加福音 11:38–39"> 從市上來，若不洗浴也不吃飯；還有好些別的規矩，他們歷代拘守，就是洗杯、罐、銅器等物。）</span>
<span className="v" id="v5" data-v="5" data-xref="帖撒羅尼迦後書 3:6; 使徒行傳 21:21; 馬太福音 15:2"> 法利賽人和文士問他說：「你的門徒為甚麼不照古人的遺傳，用俗手吃飯呢？」</span>
<span className="v" id="v6" data-v="6" data-xref="以賽亞書 29:13; 提多書 1:16; 馬太福音 15:7–9"> 耶穌說：「以賽亞指着你們假冒為善之人所說的預言是不錯的。如經上說：<br /><span className="pl pl-1">這百姓用嘴唇尊敬我，</span><br /><span className="pl pl-1">心卻遠離我。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="以賽亞書 29:13; 馬太福音 15:9; 雅各書 1:26"> <span className="pl pl-1">他們將人的吩咐當作道理教導人，</span><br /><span className="pl pl-1">所以拜我也是枉然。</span></span>
<span className="v" id="v8" data-v="8" data-xref="馬可福音 7:3–4; 以賽亞書 1:12"> 你們是離棄上帝的誡命，拘守人的遺傳」；</span>
<span className="v" id="v9" data-v="9" data-xref="耶利米書 44:16–17; 加拉太書 2:21; 以賽亞書 29:13"> 又說：「你們誠然是廢棄上帝的誡命，要守自己的遺傳。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及記 21:17; 出埃及記 20:12; 申命記 5:16"> 摩西說：『當孝敬父母』；又說：『咒罵父母的，必治死他。』</span>
<span className="v" id="v11" data-v="11" data-xref="馬太福音 23:18; 提摩太前書 5:4–8; 馬太福音 15:5"> 你們倒說：『人若對父母說：我所當奉給你的，已經作了各耳板』（各耳板就是供獻的意思），</span>
<span className="v" id="v12" data-v="12"> 以後你們就不容他再奉養父母。</span>
<span className="v" id="v13" data-v="13" data-xref="馬可福音 7:9; 提多書 1:14; 馬太福音 5:17–20"> 這就是你們承接遺傳，廢了上帝的道。你們還做許多這樣的事。」</span>
<span className="v" id="v14" data-v="14" data-xref="馬太福音 15:10; 以賽亞書 6:9; 箴言 8:5"> 耶穌又叫眾人來，對他們說：「你們都要聽我的話，也要明白。</span>
<span className="v" id="v15" data-v="15" data-xref="箴言 4:23; 利未記 11:42–47; 提多書 1:15"> 從外面進去的不能污穢人，惟有從裏面出來的乃能污穢人。」<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古卷加：16有耳可聽的，就應當聽！">a</a></sup></span>
<span className="v" id="v17" data-v="17" data-xref="馬太福音 15:15; 馬太福音 13:36; 馬可福音 9:28"> 耶穌離開眾人，進了屋子，門徒就問他這比喻的意思。</span>
<span className="v" id="v18" data-v="18" data-xref="馬太福音 15:16–17; 希伯來書 5:11; 以賽亞書 28:9–10"> 耶穌對他們說：「你們也是這樣不明白嗎？豈不曉得凡從外面進入的，不能污穢人，</span>
<span className="v" id="v19" data-v="19" data-xref="馬太福音 15:17; 哥林多前書 6:13; 歌羅西書 2:21–22"> 因為不是入他的心，乃是入他的肚腹，又落到茅廁裏（ 這是說，各樣的食物都是潔淨的）」；</span>
<span className="v" id="v20" data-v="20" data-xref="雅各書 3:6; 雅各書 1:14–15; 雅各書 4:1"> 又說：「從人裏面出來的，那才能污穢人；</span>
<span className="v" id="v21" data-v="21" data-xref="耶利米書 17:9; 羅馬書 8:7–8; 雅各書 4:1–3"> 因為從裏面，就是從人心裏，發出惡念、苟合、</span>
<span className="v" id="v22" data-v="22" data-xref="馬太福音 20:15; 馬太福音 6:23; 彼得前書 2:15"> 偷盜、凶殺、姦淫、貪婪、邪惡、詭詐、淫蕩、嫉妒、謗讟、驕傲、狂妄。</span>
<span className="v" id="v23" data-v="23" data-xref="馬可福音 7:15; 提多書 1:15; 哥林多前書 3:17"> 這一切的惡都是從裏面出來，且能污穢人。」</span>
</div>
</div>

## 一個婦人的信心

<div className="bt">
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="馬太福音 15:21–28; 馬太福音 11:21; 以西結書 28:2"> 耶穌從那裏起身，往泰爾、西頓的境內去，進了一家，不願意人知道，卻隱藏不住。</span>
<span className="v" id="v25" data-v="25" data-xref="馬太福音 15:22; 馬可福音 9:17–23; 使徒行傳 10:25–26"> 當下，有一個婦人，她的小女兒被污鬼附着，聽見耶穌的事，就來俯伏在他腳前。</span>
<span className="v" id="v26" data-v="26" data-xref="馬太福音 15:22; 以賽亞書 49:12; 加拉太書 3:28"> 這婦人是希臘人，屬敘利腓尼基族。她求耶穌趕出那鬼離開她的女兒。</span>
<span className="v" id="v27" data-v="27" data-xref="馬太福音 15:23–28; 馬太福音 7:6; 使徒行傳 22:21"> 耶穌對她說：「讓兒女們先吃飽，不好拿兒女的餅丟給狗吃。」</span>
<span className="v" id="v28" data-v="28" data-xref="羅馬書 10:12; 羅馬書 3:29; 使徒行傳 11:17–18"> 婦人回答說：「主啊，不錯；但是狗在桌子底下也吃孩子們的碎渣兒。」</span>
<span className="v" id="v29" data-v="29" data-xref="以賽亞書 66:2; 馬太福音 5:3; 約翰一書 3:8"> 耶穌對她說：「因這句話，你回去吧；鬼已經離開你的女兒了。」</span>
<span className="v" id="v30" data-v="30" data-xref="約翰一書 3:8; 約翰福音 4:50–52"> 她就回家去，見小孩子躺在床上，鬼已經出去了。</span>
</div>
</div>

## 耶穌治好耳聾舌結的人

<div className="bt">
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="馬可福音 5:20; 馬太福音 15:29–31; 馬太福音 4:25"> 耶穌又離了泰爾的境界，經過西頓，就從低加坡里境內來到加利利 海。</span>
<span className="v" id="v32" data-v="32" data-xref="路加福音 11:14; 馬可福音 5:23; 馬太福音 9:32–33"> 有人帶着一個耳聾舌結的人來見耶穌，求他按手在他身上。</span>
<span className="v" id="v33" data-v="33" data-xref="馬可福音 8:23; 約翰福音 9:6–7; 馬可福音 5:40"> 耶穌領他離開眾人，到一邊去，就用指頭探他的耳朵，吐唾沫抹他的舌頭，</span>
<span className="v" id="v34" data-v="34" data-xref="約翰福音 11:41; 馬可福音 5:41; 馬可福音 6:41"> 望天歎息，對他說：「以法大！」就是說：「開了吧！」</span>
<span className="v" id="v35" data-v="35" data-xref="以賽亞書 35:5–6; 詩篇 33:9; 馬可福音 2:12"> 他的耳朵就開了，舌結也解了，說話也清楚了。</span>
<span className="v" id="v36" data-v="36" data-xref="馬太福音 8:4; 馬可福音 8:26; 馬可福音 3:12"> 耶穌囑咐他們不要告訴人；但他越發囑咐，他們越發傳揚開了。</span>
<span className="v" id="v37" data-v="37" data-xref="馬可福音 6:51; 馬可福音 5:42; 出埃及記 4:10–11"> 眾人分外希奇，說：「他所做的事都好，他連聾子也叫他們聽見，啞巴也叫他們說話。」</span>
</div>

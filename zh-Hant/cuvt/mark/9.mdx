## 耶穌改變形像

<div className="bt">
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="路加福音 9:28–36; 以賽亞書 33:17; 馬太福音 17:1–8"> 過了六天，耶穌帶着彼得、雅各、約翰暗暗地上了高山，就在他們面前變了形像，</span>
<span className="v" id="v3" data-v="3" data-xref="馬太福音 28:3; 但以理書 7:9; 啟示錄 7:14"> 衣服放光，極其潔白，地上漂布的，沒有一個能漂得那樣白。</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 9:30–31; 馬太福音 17:3–4; 使徒行傳 3:21–24"> 忽然，有以利亞同摩西向他們顯現，並且和耶穌說話。</span>
<span className="v" id="v5" data-v="5" data-xref="腓立比書 1:23; 約翰福音 14:8–9; 啟示錄 22:3–4"> 彼得對耶穌說：「拉比<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="就是夫子">a</a></sup>，我們在這裏真好！可以搭三座棚，一座為你，一座為摩西，一座為以利亞。」</span>
<span className="v" id="v6" data-v="6" data-xref="啟示錄 1:17; 但以理書 10:15–19; 馬可福音 16:5–8"> 彼得不知道說甚麼才好，因為他們甚是懼怕。</span>
<span className="v" id="v7" data-v="7" data-xref="彼得後書 1:17; 馬太福音 3:17; 馬可福音 1:11"> 有一朵雲彩來遮蓋他們；也有聲音從雲彩裏出來，說：「這是我的愛子，你們要聽他。」</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行傳 10:16; 使徒行傳 8:39–40; 路加福音 24:31"> 門徒忽然周圍一看，不再見一人，只見耶穌同他們在那裏。</span>
<span className="v" id="v9" data-v="9" data-xref="馬太福音 12:40; 馬太福音 17:9–13; 馬可福音 5:43"> 下山的時候，耶穌囑咐他們說：「人子還沒有從死裏復活，你們不要將所看見的告訴人。」</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行傳 17:18; 路加福音 24:7–8; 路加福音 18:33–34"> 門徒將這話存記在心，彼此議論「從死裏復活」是甚麼意思。</span>
<span className="v" id="v11" data-v="11" data-xref="瑪拉基書 4:5; 瑪拉基書 3:1; 馬太福音 11:14"> 他們就問耶穌說：「文士為甚麼說以利亞必須先來？」</span>
<span className="v" id="v12" data-v="12" data-xref="以賽亞書 53:1–12; 以賽亞書 50:6; 以賽亞書 52:14"> 耶穌說：「以利亞固然先來復興萬事；經上不是指着人子說，他要受許多的苦被人輕慢呢？</span>
<span className="v" id="v13" data-v="13" data-xref="馬太福音 14:3–11; 馬太福音 17:12–13; 馬太福音 11:14"> 我告訴你們，以利亞已經來了，他們也任意待他，正如經上所指着他的話。」</span>
</div>
</div>

## 治好被污鬼附身的孩子

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="路加福音 9:37–42; 馬太福音 17:14–20; 路加福音 11:53–54"> 耶穌到了門徒那裏，看見有許多人圍着他們，又有文士和他們辯論。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及記 34:30; 馬可福音 9:2–3"> 眾人一見耶穌，都甚希奇，就跑上去問他的安。</span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 5:30–32; 馬可福音 8:11"> 耶穌問他們說：「你們和他們辯論的是甚麼？」</span>
<span className="v" id="v17" data-v="17" data-xref="馬可福音 9:25; 路加福音 11:14; 約翰福音 4:47"> 眾人中間有一個人回答說：「夫子，我帶了我的兒子到你這裏來，他被啞巴鬼附着。</span>
<span className="v" id="v18" data-v="18" data-xref="馬太福音 17:19–20; 馬可福音 11:23; 馬太福音 17:16"> 無論在哪裏，鬼捉弄他，把他摔倒，他就口中流沫，咬牙切齒，身體枯乾。我請過你的門徒把鬼趕出去，他們卻是不能。」</span>
<span className="v" id="v19" data-v="19" data-xref="民數記 14:11; 約翰福音 20:27; 民數記 14:27"> 耶穌說：「噯！不信的世代啊，我在你們這裏要到幾時呢？我忍耐你們要到幾時呢？把他帶到我這裏來吧。」</span>
<span className="v" id="v20" data-v="20" data-xref="馬可福音 1:26; 路加福音 4:35; 約翰福音 8:44"> 他們就帶了他來。他一見耶穌，鬼便叫他重重地抽瘋，倒在地上，翻來覆去，口中流沫。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行傳 9:33; 使徒行傳 4:22; 馬可福音 5:25"> 耶穌問他父親說：「他得這病有多少日子呢？」回答說：「從小的時候。</span>
<span className="v" id="v22" data-v="22" data-xref="馬太福音 15:22–28; 馬可福音 5:19; 馬太福音 20:34"> 鬼屢次把他扔在火裏、水裏，要滅他。你若能做甚麼，求你憐憫我們，幫助我們。」</span>
<span className="v" id="v23" data-v="23" data-xref="約翰福音 11:40; 希伯來書 11:6; 馬可福音 11:23"> 耶穌對他說：「你若能信，在信的人，凡事都能。」</span>
<span className="v" id="v24" data-v="24" data-xref="路加福音 17:5; 希伯來書 12:2; 以弗所書 2:8"> 孩子的父親立時喊着說<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有古卷：立時流淚地喊着說">b</a></sup>：「我信！但我信不足，求主幫助。」</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行傳 16:18; 路加福音 9:42; 馬可福音 9:15"> 耶穌看見眾人都跑上來， 就斥責那污鬼，說：「你這聾啞的鬼，我吩咐你從他裏頭出來，再不要進去！」</span>
<span className="v" id="v26" data-v="26" data-xref="馬可福音 9:20; 馬可福音 1:26; 馬可福音 9:18"> 那鬼喊叫，使孩子大大地抽了一陣瘋，就出來了。孩子好像死了一般，以致眾人多半說：「他是死了。」</span>
<span className="v" id="v27" data-v="27" data-xref="馬可福音 1:31; 使徒行傳 3:7; 馬可福音 1:41"> 但耶穌拉着他的手，扶他起來，他就站起來了。</span>
<span className="v" id="v28" data-v="28" data-xref="馬太福音 17:19–20; 馬可福音 7:17; 馬太福音 15:15"> 耶穌進了屋子，門徒就暗暗地問他說：「我們為甚麼不能趕出他去呢？」</span>
<span className="v" id="v29" data-v="29" data-xref="雅各書 5:15; 但以理書 9:3; 馬太福音 17:20"> 耶穌說：「非用禱告<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="有古卷加：禁食二字">c</a></sup>，這一類的鬼總不能出來<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="或譯：不能趕他 出來">d</a></sup>。」</span>
</div>
</div>

## 耶穌第二次預言受難和復活

<div className="bt">
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="馬太福音 17:22–23; 路加福音 9:43–45; 馬可福音 6:31–32"> 他們離開那地方，經過加利利；耶穌不願意人知道。</span>
<span className="v" id="v31" data-v="31" data-xref="馬太福音 16:21; 馬可福音 9:12; 路加福音 24:44–46"> 於是教訓門徒，說：「人子將要被交在人手裏，他們要殺害他；被殺以後，過三天他要復活。」</span>
<span className="v" id="v32" data-v="32" data-xref="路加福音 2:50; 路加福音 9:45; 路加福音 18:34"> 門徒卻不明白這話，又不敢問他。</span>
</div>
</div>

## 誰最偉大

<div className="bt">
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="馬太福音 18:1–5; 希伯來書 4:13; 路加福音 9:46–48"> 他們來到迦百農。耶穌在屋裏問門徒說：「你們在路上議論的是甚麼？」</span>
<span className="v" id="v34" data-v="34" data-xref="馬可福音 9:50; 馬太福音 20:21–24; 馬太福音 18:1–5"> 門徒不作聲，因為他們在路上彼此爭論誰為大。</span>
<span className="v" id="v35" data-v="35" data-xref="馬太福音 20:25–28; 馬可福音 10:42–45; 路加福音 22:26"> 耶穌坐下，叫十二個門徒來，說：「若有人願意作首先的，他必作眾人末後的，作眾人的用人。」</span>
<span className="v" id="v36" data-v="36" data-xref="馬可福音 10:16; 馬太福音 19:14–15; 馬太福音 18:2"> 於是領過一個小孩子來，叫他站在門徒中間，又抱起他來，對他們說：</span>
<span className="v" id="v37" data-v="37" data-xref="馬太福音 18:3–5; 路加福音 10:16; 馬太福音 10:40–42"> 「凡為我名接待一個像這小孩子的，就是接待我；凡接待我的，不是接待我，乃是接待那差我來的。」</span>
</div>
</div>

## 不敵擋我們就是幫助我們

<div className="bt">
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="路加福音 9:49–50; 民數記 11:26–29; 路加福音 11:19"> 約翰對耶穌說：「夫子，我們看見一個人奉你的名趕鬼，我們就禁止他，因為他不跟從我們。」</span>
<span className="v" id="v39" data-v="39" data-xref="哥林多前書 12:3; 哥林多前書 13:1–2; 馬太福音 13:28–29"> 耶穌說：「不要禁止他；因為沒有人奉我名行異能，反倒輕易毀謗我。</span>
<span className="v" id="v40" data-v="40" data-xref="馬太福音 12:30; 路加福音 11:23"> 不敵擋我們的，就是幫助我們的。</span>
<span className="v" id="v41" data-v="41" data-xref="馬太福音 10:42; 馬太福音 25:40; 哥林多前書 15:23"> 凡因你們是屬基督，給你們一杯水喝的，我實在告訴你們，他不能不得賞賜。」</span>
</div>

## 罪的誘惑

<div className="bt">
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="馬太福音 18:6; 路加福音 17:1–2; 馬太福音 18:10"> 「凡使這信我的一個小子跌倒的，倒不如把大磨石拴在這人的頸項上，扔在海裏。</span>
<span className="v" id="v43" data-v="43" data-xref="馬太福音 5:29–30; 馬太福音 18:8–9; 馬太福音 25:41"> 倘若你一隻手叫你跌倒，就把它砍下來；</span>
<span className="v" id="v44" data-v="44"> 你缺了肢體進入永生，強如有兩隻手落到地獄，入那不滅的火裏去。</span>
<span className="v" id="v45" data-v="45" data-xref="馬太福音 18:8; 馬太福音 5:22; 馬可福音 9:43"> 倘若你一隻腳叫你跌倒，就把它 砍下來；</span>
<span className="v" id="v46" data-v="46"> 你瘸腿進入永生，強如有兩隻腳被丟在地獄裏。</span>
<span className="v" id="v47" data-v="47" data-xref="馬太福音 18:9; 馬可福音 9:43; 馬太福音 5:22"> 倘若你一隻眼叫你跌倒，就去掉它；你只有一隻眼進入上帝的國，強如有兩隻眼被丟在地獄裏。</span>
<span className="v" id="v48" data-v="48" data-xref="以賽亞書 66:24; 馬可福音 9:43–45; 馬太福音 25:41"> 在那裏，蟲是不死的，火是不滅的。</span>
<span className="v" id="v49" data-v="49" data-xref="利未記 2:13; 以西結書 43:24"> 因為必用火當鹽醃各人。<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="有古卷加：凡祭物必用鹽醃。">e</a></sup></span>
<span className="v" id="v50" data-v="50" data-xref="歌羅西書 4:6; 羅馬書 12:18; 馬太福音 5:13"> 鹽本是好的，若失了味，可用甚麼叫它再鹹呢？你們裏頭應當有鹽，彼此和睦。」</span>
</div>

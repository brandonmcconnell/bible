## 耶路撒冷的憂患

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="以賽亞書 3:26; 以斯拉記 4:20; 列王紀上 4:21"> <span className="pl pl-1">先前滿有人民的城，</span><br /><span className="pl pl-1">現在何竟獨坐！</span><br /><span className="pl pl-1">先前在列國中為大的，</span><br /><span className="pl pl-1">現在竟如寡婦；</span><br /><span className="pl pl-1">先前在諸省中為王后的，</span><br /><span className="pl pl-1">現在成為進貢的。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v2" data-v="2" data-xref="詩篇 6:6; 彌迦書 7:5; 詩篇 77:2–6"> <span className="pl pl-1">她夜間痛哭，淚流滿腮；</span><br /><span className="pl pl-1">在一切所親愛的中間沒有一個安慰她的。</span><br /><span className="pl pl-1">她的朋友都以詭詐待她，</span><br /><span className="pl pl-1">成為她的仇敵。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v3" data-v="3" data-xref="申命記 28:64–67; 耶利米哀歌 2:9; 阿摩司書 9:1–4"> <span className="pl pl-1">猶大因遭遇苦難，</span><br /><span className="pl pl-1">又因多服勞苦就遷到外邦。</span><br /><span className="pl pl-1">她住在列國中，尋不着安息；</span><br /><span className="pl pl-1">追逼她的都在狹窄之地將她追上。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v4" data-v="4" data-xref="耶利米書 9:11; 約珥書 1:8–13; 耶利米書 10:22"> <span className="pl pl-1">錫安的路徑因無人來守聖節就悲傷；</span><br /><span className="pl pl-1">她的城門淒涼；</span><br /><span className="pl pl-1">她的祭司歎息；</span><br /><span className="pl pl-1">她的處女受艱難，自己也愁苦。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="申命記 32:15–27; 耶利米書 30:14–15; 以西結書 9:9"> <span className="pl pl-1">她的敵人為首；</span><br /><span className="pl pl-1">她的仇敵亨通；</span><br /><span className="pl pl-1">因耶和華為她許多的罪過使她受苦；</span><br /><span className="pl pl-1">她的孩童被敵人擄去。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="以西結書 24:25; 耶利米書 13:18; 申命記 28:25"> <span className="pl pl-1">錫安城</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是女子；下同">a</a></sup><br /><span className="pl pl-1">的威榮全都失去。</span><br /><span className="pl pl-1">她的首領像找不着草場的鹿；</span><br /><span className="pl pl-1">在追趕的人前無力行走。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="詩篇 79:4; 申命記 4:34–37; 詩篇 42:4"> <span className="pl pl-1">耶路撒冷在困苦窘迫之時，</span><br /><span className="pl pl-1">就追想古時一切的樂境。</span><br /><span className="pl pl-1">她百姓落在敵人手中，無人救濟；</span><br /><span className="pl pl-1">敵人看見，就因她的荒涼嗤笑。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="以賽亞書 59:2–13; 耶利米哀歌 1:20–22; 耶利米書 13:26"> <span className="pl pl-1">耶路撒冷大大犯罪，</span><br /><span className="pl pl-1">所以成為不潔之物；</span><br /><span className="pl pl-1">素來尊敬她的，見她赤露就都藐視她；</span><br /><span className="pl pl-1">她自己也歎息退後。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="申命記 32:29; 以賽亞書 47:7; 詩篇 25:18"> <span className="pl pl-1">她的污穢是在衣襟上；</span><br /><span className="pl pl-1">她不思想自己的結局，</span><br /><span className="pl pl-1">所以非常地敗落，</span><br /><span className="pl pl-1">無人安慰她。</span><br /><span className="pl pl-1">她說：耶和華啊，求你看我的苦難，</span><br /><span className="pl pl-1">因為仇敵誇大。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="申命記 23:3; 耶利米書 51:51; 詩篇 74:4–8"> <span className="pl pl-1">敵人伸手，奪取她的美物；</span><br /><span className="pl pl-1">她眼見外邦人進入她的聖所－</span><br /><span className="pl pl-1">論這外邦人，你曾吩咐不可入你的會中。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v11" data-v="11" data-xref="耶利米書 52:6; 耶利米書 38:9; 耶利米哀歌 2:12"> <span className="pl pl-1">她的民都歎息，尋求食物；</span><br /><span className="pl pl-1">他們用美物換糧食，要救性命。</span><br /><span className="pl pl-1">他們說：耶和華啊，求你觀看，</span><br /><span className="pl pl-1">因為我甚是卑賤。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="路加福音 23:28–31; 但以理書 9:12; 耶利米書 30:24"> <span className="pl pl-1">你們一切過路的人哪，這事你們不介意嗎？</span><br /><span className="pl pl-1">你們要觀看：</span><br /><span className="pl pl-1">有像這臨到我的痛苦沒有－</span><br /><span className="pl pl-1">就是耶和華在他發烈怒的日子使我所受的苦？</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v13" data-v="13" data-xref="約伯記 30:30; 哈巴谷書 3:16; 以西結書 17:20"> <span className="pl pl-1">他從高天使火進入我的骨頭，</span><br /><span className="pl pl-1">剋制了我；</span><br /><span className="pl pl-1">他鋪下網羅，絆我的腳，</span><br /><span className="pl pl-1">使我轉回；</span><br /><span className="pl pl-1">他使我終日淒涼發昏。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="申命記 28:48; 以賽亞書 47:6; 箴言 5:22"> <span className="pl pl-1">我罪過的軛是他手所綁的，</span><br /><span className="pl pl-1">猶如軛繩縛在我頸項上；</span><br /><span className="pl pl-1">他使我的力量衰敗。</span><br /><span className="pl pl-1">主將我交在我所不能敵擋的人手中。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="瑪拉基書 4:3; 以賽亞書 28:18; 以賽亞書 63:3"> <span className="pl pl-1">主輕棄我中間的一切勇士，</span><br /><span className="pl pl-1">招聚多人</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原文是大會">b</a></sup><br /><span className="pl pl-1">攻擊我，</span><br /><span className="pl pl-1">要壓碎我的少年人。</span><br /><span className="pl pl-1">主將猶大居民踹下，</span><br /><span className="pl pl-1">像在酒醡中一樣。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v16" data-v="16" data-xref="耶利米哀歌 1:2; 耶利米書 13:17; 詩篇 119:136"> <span className="pl pl-1">我因這些事哭泣；</span><br /><span className="pl pl-1">我眼淚汪汪；</span><br /><span className="pl pl-1">因為那當安慰我、救我性命的，</span><br /><span className="pl pl-1">離我甚遠。</span><br /><span className="pl pl-1">我的兒女孤苦，</span><br /><span className="pl pl-1">因為仇敵得了勝。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v17" data-v="17" data-xref="以賽亞書 1:15; 耶利米書 4:31; 耶利米哀歌 1:9"> <span className="pl pl-1">錫安舉手，無人安慰。</span><br /><span className="pl pl-1">耶和華論雅各已經出令，</span><br /><span className="pl pl-1">使四圍的人作他仇敵；</span><br /><span className="pl pl-1">耶路撒冷在他們中間像不潔之物。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v18" data-v="18" data-xref="撒母耳記上 12:14–15; 西番雅書 3:5; 詩篇 119:75"> <span className="pl pl-1">耶和華是公義的！</span><br /><span className="pl pl-1">他這樣待我，是因我違背他的命令。</span><br /><span className="pl pl-1">眾民哪，請聽我的話，</span><br /><span className="pl pl-1">看我的痛苦；</span><br /><span className="pl pl-1">我的處女和少年人都被擄去。</span></span>
</div>
<div className="bp poetry">

</div>
<div className="bp poetry">

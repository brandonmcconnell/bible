## 尼布甲尼撒下令拜金像

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哈巴谷書 2:19; 耶利米書 16:20; 以賽亞書 46:6"> 尼布甲尼撒王造了一個金像，高六十肘，寬六肘，立在巴比倫省杜拉平原。</span>
<span className="v" id="v2" data-v="2" data-xref="但以理書 3:27; 箴言 29:12; 列王紀上 12:32"> 尼布甲尼撒王差人將總督、欽差、巡撫、臬司、藩司、謀士、法官，和各省的官員都召了來，為尼布甲尼撒王所立的像行開光之禮。</span>
<span className="v" id="v3" data-v="3" data-xref="啟示錄 17:17; 啟示錄 17:13; 啟示錄 13:13–16"> 於是總督、欽差、巡撫、臬司、藩司、謀士、法官，和各省的官員都聚集了來，要為尼布甲尼撒王所立的像行開光之禮，就站在尼布甲尼撒所立的像前。</span>
<span className="v" id="v4" data-v="4" data-xref="但以理書 4:1; 但以理書 6:25; 彌迦書 6:16"> 那時傳令的大聲呼叫說：「各方、各國、各族<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是舌；下同">a</a></sup>的人哪，有令傳與你們：</span>
<span className="v" id="v5" data-v="5" data-xref="但以理書 3:15; 但以理書 3:10; 但以理書 3:7"> 你們一聽見角、笛、琵琶、琴、瑟、笙，和各樣樂器的聲音，就當俯伏敬拜尼布甲尼撒王所立的金像。</span>
<span className="v" id="v6" data-v="6" data-xref="馬太福音 13:50; 馬太福音 13:42; 耶利米書 29:22"> 凡不俯伏敬拜的，必立時扔在烈火的窯中。」</span>
<span className="v" id="v7" data-v="7" data-xref="啟示錄 17:8; 啟示錄 13:3; 啟示錄 13:8"> 因此各方、各國、各族的人民一聽見角、笛、琵琶、琴、瑟，和各樣樂器的聲音，就都俯伏敬拜尼布甲尼撒王所立的金像。</span>
</div>
</div>

## 但以理的三個朋友被控違令

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="以斯拉記 4:12–16; 但以理書 6:12–13; 以斯帖記 3:8–9"> 那時，有幾個迦勒底人進前來控告猶大人。</span>
<span className="v" id="v9" data-v="9" data-xref="但以理書 5:10; 但以理書 6:6; 但以理書 6:21"> 他們對尼布甲尼撒王說：「願王萬歲！</span>
<span className="v" id="v10" data-v="10" data-xref="但以理書 3:4–7; 但以理書 6:12; 以斯帖記 3:12–14"> 王啊，你曾降旨說，凡聽見角、笛、琵琶、琴、瑟、笙，和各樣樂器聲音的都當俯伏敬拜金像。</span>
<span className="v" id="v11" data-v="11"> 凡不俯伏敬拜的，必扔在烈火的窯中。</span>
<span className="v" id="v12" data-v="12" data-xref="但以理書 6:13; 但以理書 2:49; 使徒行傳 17:7"> 現在有幾個猶大人，就是王所派管理巴比倫省事務的沙得拉、米煞、亞伯尼歌；王啊，這些人不理你，不事奉你的神，也不敬拜你所立的金像。」</span>
<span className="v" id="v13" data-v="13" data-xref="但以理書 3:19; 但以理書 2:12; 以斯帖記 3:5–6"> 當時，尼布甲尼撒沖沖大怒，吩咐人把沙得拉、米煞、亞伯尼歌帶過來，他們就把那些人帶到王面前。</span>
<span className="v" id="v14" data-v="14" data-xref="耶利米書 50:2; 但以理書 3:1; 以賽亞書 46:1"> 尼布甲尼撒問他們說：「沙得拉、米煞、亞伯尼歌，你們不事奉我的神，也不敬拜我所立的金像，是故意的嗎？</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行傳 5:29; 歷代志下 32:15–17; 出埃及記 5:2"> 你們再聽見角、笛、琵琶、琴、瑟、笙，和各樣樂器的聲音，若俯伏敬拜我所造的像，卻還可以；若不敬拜，必立時扔在烈火的窯中，有何神能救你們脫離我手呢？」</span>
<span className="v" id="v16" data-v="16" data-xref="但以理書 1:7; 但以理書 3:12"> 沙得拉、米煞、亞伯尼歌對王說：「尼布甲尼撒啊，這件事我們不必回答你，</span>
<span className="v" id="v17" data-v="17" data-xref="羅馬書 8:31; 路加福音 1:37; 希伯來書 7:25"> 即便如此，我們所事奉的上帝能將我們從烈火的窯中救出來。王啊，他也必救我們脫離你的手；</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行傳 5:29–32; 馬太福音 10:39; 啟示錄 2:10–11"> 即或不然，王啊，你當知道我們決不事奉你的神，也不敬拜你所立的金像。」</span>
</div>
</div>

## 但以理的三個朋友被扔進火窯

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="但以理書 3:13; 利未記 26:24; 箴言 21:24"> 當時，尼布甲尼撒怒氣填胸，向沙得拉、米煞、亞伯尼歌變了臉色，吩咐人把窯燒熱，比尋常更加七倍；</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行傳 16:23; 使徒行傳 16:25; 但以理書 3:15"> 又吩咐他軍中的幾個壯士，將沙得拉、米煞、亞伯尼歌捆起來，扔在烈火的窯中。</span>
<span className="v" id="v21" data-v="21"> 這三人穿着褲子、內袍、外衣，和別的衣服，被捆起來扔在烈火的窯中。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及記 12:33; 箴言 21:18; 箴言 11:8"> 因為王命緊急，窯又甚熱，那抬沙得拉、米煞、亞伯尼歌的人都被火焰燒死。</span>
<span className="v" id="v23" data-v="23" data-xref="但以理書 6:16–17; 耶利米書 38:6; 詩篇 34:19"> 沙得拉、米煞、亞伯尼歌這三個人都被捆着落在烈火的窯中。</span>
<span className="v" id="v24" data-v="24" data-xref="但以理書 6:7; 但以理書 6:22; 但以理書 3:9–10"> 那時，尼布甲尼撒王驚奇，急忙起來，對謀士說：「我們捆起來扔在火裏的不是三個人嗎？」他們回答王說：「王啊，是。」</span>
<span className="v" id="v25" data-v="25" data-xref="以賽亞書 43:2; 使徒行傳 28:5; 馬可福音 16:18"> 王說：「看哪，我見有四個人，並沒有捆綁，在火中遊行，也沒有受傷；那第四個的相貌好像神子。」</span>
</div>
</div>

## 三人獲釋且得高升

<div className="bt">
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="但以理書 3:17; 以賽亞書 52:12; 啟示錄 19:5"> 於是，尼布甲尼撒就近烈火窯門，說：「至高上帝的僕人沙得拉、米煞、亞伯尼歌出來，上這裏來吧！」沙得拉、米煞、亞伯尼歌就從火中出來了。</span>
<span className="v" id="v27" data-v="27" data-xref="以賽亞書 43:2; 希伯來書 11:34; 以賽亞書 26:11"> 那些總督、欽差、巡撫，和王的謀士一同聚集看這三個人，見火無力傷他們的身體，頭髮也沒有燒焦，衣裳也沒有變色，並沒有火燎的氣味。</span>
<span className="v" id="v28" data-v="28" data-xref="羅馬書 14:7–8; 詩篇 34:7–8; 詩篇 84:11–12"> 尼布甲尼撒說：「沙得拉、米煞、亞伯尼歌的上帝是應當稱頌的！他差遣使者救護倚靠他的僕人，他們不遵王命，捨去己身，在他們上帝以外不肯事奉敬拜別神。</span>
<span className="v" id="v29" data-v="29" data-xref="但以理書 2:5; 詩篇 76:10; 申命記 32:31"> 現在我降旨，無論何方、何國、何族的人，謗讟沙得拉、米煞、亞伯尼歌之上帝的，必被凌遲，他的房屋必成糞堆，因為沒有別神能這樣施行拯救。」</span>
<span className="v" id="v30" data-v="30" data-xref="但以理書 2:49; 撒母耳記上 2:30; 但以理書 3:12"> 那時王在巴比倫省，高升了沙得拉、米煞、亞伯尼歌。</span>
</div>
</div>

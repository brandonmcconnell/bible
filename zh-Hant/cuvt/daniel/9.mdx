## 但以理為同胞禱告

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="但以理書 11:1; 但以理書 1:21; 但以理書 5:31–1"> 米底亞族亞哈隨魯的兒子大流士立為迦勒底國的王元年，</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米書 29:10; 耶利米書 25:11–12; 歷代志下 36:21"> 就是他在位第一年，我－但以理從書上得知耶和華的話臨到先知耶利米，論耶路撒冷荒涼的年數，七十年為滿。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="耶利米書 33:3; 耶利米書 29:10–13; 雅各書 5:16–18"> 我便禁食，披麻蒙灰，定意向主上帝祈禱懇求。</span>
<span className="v" id="v4" data-v="4" data-xref="羅馬書 8:28; 出埃及記 20:6; 申命記 5:10"> 我向耶和華－我的上帝祈禱、認罪，說：「主啊，大而可畏的上帝，向愛主、守主誡命的人守約施慈愛。</span>
<span className="v" id="v5" data-v="5" data-xref="瑪拉基書 3:7; 但以理書 9:11; 但以理書 9:15"> 我們犯罪作孽，行惡叛逆，偏離你的誡命典章，</span>
<span className="v" id="v6" data-v="6" data-xref="但以理書 9:10; 歷代志下 36:15–16; 路加福音 20:10–12"> 沒有聽從你僕人眾先知奉你名向我們君王、首領、列祖，和國中一切百姓所說的話。</span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 44:15; 耶利米書 3:25; 耶利米書 2:26–27"> 主啊，你是公義的，我們是臉上蒙羞的；因我們猶大人和耶路撒冷的居民，並以色列眾人，或在近處，或在遠處，被你趕到各國的人，都得罪了你，正如今日一樣。</span>
<span className="v" id="v8" data-v="8" data-xref="但以理書 9:6–7; 耶利米哀歌 1:7–8; 耶利米哀歌 1:18"> 主啊，我們和我們的君王、首領、列祖因得罪了你，就都臉上蒙羞。</span>
<span className="v" id="v9" data-v="9" data-xref="以弗所書 1:6–8; 但以理書 9:7; 但以理書 9:5"> 主－我們的上帝是憐憫饒恕人的，我們卻違背了他，</span>
<span className="v" id="v10" data-v="10" data-xref="但以理書 9:6; 列王紀下 18:12; 尼希米記 9:13–17"> 也沒有聽從耶和華－我們上帝的話，沒有遵行他藉僕人眾先知向我們所陳明的律法。</span>
<span className="v" id="v11" data-v="11" data-xref="耶利米書 8:5–10; 以賽亞書 1:4–6; 申命記 28:15–68"> 以色列眾人都犯了你的律法，偏行，不聽從你的話；因此，在你僕人摩西律法上所寫的咒詛和誓言都傾在我們身上，因我們得罪了上帝。</span>
<span className="v" id="v12" data-v="12" data-xref="以西結書 5:9; 耶利米哀歌 1:12; 約伯記 12:17"> 他使大災禍臨到我們，成就了警戒我們和審判我們官長的話；原來在普天之下未曾行過像在耶路撒冷所行的。</span>
<span className="v" id="v13" data-v="13" data-xref="申命記 28:15–68; 以賽亞書 9:13; 但以理書 9:11"> 這一切災禍臨到我們身上是照摩西律法上所寫的，我們卻沒有求耶和華－我們上帝的恩典，使我們回頭離開罪孽，明白你的真理。</span>
<span className="v" id="v14" data-v="14" data-xref="但以理書 9:7; 尼希米記 9:33; 詩篇 51:14"> 所以耶和華留意使這災禍臨到我們身上，因為耶和華－我們的上帝在他所行的事上都是公義；我們並沒有聽從他的話。</span>
<span className="v" id="v15" data-v="15" data-xref="尼希米記 9:10; 出埃及記 32:11; 尼希米記 1:10"> 主－我們的上帝啊，你曾用大能的手領你的子民出埃及地，使自己得了名，正如今日一樣。我們犯了罪，作了惡。</span>
<span className="v" id="v16" data-v="16" data-xref="撒迦利亞書 8:3; 約珥書 3:17; 詩篇 87:1–3"> 主啊，求你按你的大仁大義，使你的怒氣和忿怒轉離你的城耶路撒冷，就是你的聖山。耶路撒冷和你的子民，因我們的罪惡和我們列祖的罪孽被四圍的人羞辱。</span>
<span className="v" id="v17" data-v="17" data-xref="詩篇 80:19; 耶利米哀歌 5:18; 哥林多後書 1:20"> 我們的上帝啊，現在求你垂聽僕人的祈禱懇求，為自己使臉光照你荒涼的聖所。</span>
<span className="v" id="v18" data-v="18" data-xref="以賽亞書 37:17; 耶利米書 36:7; 列王紀下 19:16"> 我的上帝啊，求你側耳而聽，睜眼而看，眷顧我們荒涼之地和稱為你名下的城。我們在你面前懇求，原不是因自己的義，乃因你的大憐憫。</span>
<span className="v" id="v19" data-v="19" data-xref="但以理書 9:18; 以弗所書 1:12; 阿摩司書 7:2"> 求主垂聽，求主赦免，求主應允而行，為你自己不要遲延。我的上帝啊，因這城和這民都是稱為你名下的。」</span>
</div>
</div>

## 加百列解釋預言

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="詩篇 145:18; 但以理書 9:3–4; 羅馬書 3:23"> 我說話，禱告，承認我的罪和本國之民以色列的罪，為我上帝的聖山，在耶和華－我上帝面前懇求。</span>
<span className="v" id="v21" data-v="21" data-xref="路加福音 1:19; 但以理書 8:16; 列王紀上 18:36"> 我正禱告的時候，先前在異象中所見的那位加百列，奉命迅速飛來，約在獻晚祭的時候，按手在我身上。</span>
<span className="v" id="v22" data-v="22" data-xref="但以理書 9:24–27; 但以理書 10:21; 但以理書 8:16"> 他指教我說：「但以理啊，現在我出來要使你有智慧，有聰明。</span>
<span className="v" id="v23" data-v="23" data-xref="但以理書 10:19; 馬太福音 24:15; 但以理書 10:11–12"> 你初懇求的時候，就發出命令，我來告訴你，因你大蒙眷愛；所以你要思想明白這以下的事和異象。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="希伯來書 9:11–14; 羅馬書 5:10; 耶利米書 23:5–6"> 「為你本國之民和你聖城，已經定了七十個七。要止住罪過，除淨罪惡，贖盡罪孽，引進<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或譯：彰顯">a</a></sup>永義，封住異象和預言，並膏至聖者<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="者：或譯所">b</a></sup>。</span>
<span className="v" id="v25" data-v="25" data-xref="以斯拉記 4:24; 以賽亞書 9:6; 以賽亞書 55:4"> 你當知道，當明白，從出令重新建造耶路撒冷，直到有受膏君的時候，必有七個七和六十二個七。正在艱難的時候，耶路撒冷城連街帶濠都必重新建造。</span>
<span className="v" id="v26" data-v="26" data-xref="以賽亞書 53:8; 那鴻書 1:8; 馬可福音 13:2"> 過了六十二個七，那<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="或譯：有">c</a></sup>受膏者必被剪除，一無所有；必有一王的民來毀滅這城和聖所，至終必如洪水沖沒。必有爭戰，一直到底，荒涼的事已經定了。</span>
<span className="v" id="v27" data-v="27" data-xref="馬太福音 24:15; 路加福音 21:20; 但以理書 12:11"> 一七之內，他必與許多人堅定盟約；一七之半，他必使祭祀與供獻止息。那行毀壞可憎的<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="或譯：使地荒涼的">d</a></sup>如飛而來，並且有忿怒傾在那行毀壞的身上<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="或譯：傾在那荒涼之地">e</a></sup>，直到所定的結局。」</span>
</div>
</div>

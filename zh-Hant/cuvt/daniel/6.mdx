## 但以理在獅子坑中

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="出埃及記 18:21–22; 但以理書 5:31; 以斯帖記 1:1"> 大流士隨心所願，立一百二十個總督，治理通國。</span>
<span className="v" id="v2" data-v="2" data-xref="但以理書 2:48–49; 但以理書 5:29; 以斯帖記 7:4"> 又在他們以上立總長三人（但以理在其中），使總督在他們三人面前回覆事務，免得王受虧損。</span>
<span className="v" id="v3" data-v="3" data-xref="但以理書 5:14; 箴言 22:29; 創世記 41:38–41"> 因這但以理有美好的靈性，所以顯然超乎其餘的總長和總督，王又想立他治理通國。</span>
<span className="v" id="v4" data-v="4" data-xref="彼得前書 3:16; 腓立比書 2:15; 彼得前書 2:12"> 那時，總長和總督尋找但以理誤國的把柄，為要參他；只是找不着他的錯誤過失，因他忠心辦事，毫無錯誤過失。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行傳 24:13–16; 以斯帖記 3:8; 使徒行傳 24:20–21"> 那些人便說：「我們要找參這但以理的把柄，除非在他上帝的律法中就尋不着。」</span>
<span className="v" id="v6" data-v="6" data-xref="但以理書 2:4; 尼希米記 2:3; 但以理書 6:21"> 於是，總長和總督紛紛聚集來見王，說：「願大流士王萬歲！</span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 59:3; 詩篇 62:4; 但以理書 3:27"> 國中的總長、欽差、總督、謀士，和巡撫彼此商議，要立一條堅定的禁令<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或譯：求王下旨要立一條......">a</a></sup>，三十日內，不拘何人，若在王以外，或向神或向人求甚麼，就必扔在獅子坑中。</span>
<span className="v" id="v8" data-v="8" data-xref="但以理書 6:15; 以斯帖記 1:19; 但以理書 6:12"> 王啊，現在求你立這禁令，加蓋玉璽，使禁令決不更改；照米底亞和波斯人的例是不可更改的。」</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 146:3; 詩篇 118:9; 詩篇 62:9–10"> 於是大流士王立這禁令，加蓋玉璽。</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行傳 5:29; 詩篇 55:17; 帖撒羅尼迦前書 5:17–18"> 但以理知道這禁令蓋了玉璽，就到自己家裏（他樓上的窗戶開向耶路撒冷），一日三次，雙膝跪在他上帝面前，禱告感謝，與素常一樣。</span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 37:32–33; 詩篇 10:9; 但以理書 6:6"> 那些人就紛紛聚集，見但以理在他上帝面前祈禱懇求。</span>
<span className="v" id="v12" data-v="12" data-xref="但以理書 6:8; 但以理書 3:8–12; 以斯帖記 1:19"> 他們便進到王前，提王的禁令，說：「王啊，三十日內不拘何人，若在王以外，或向神或向人求甚麼，必被扔在獅子坑中。王不是在這禁令上蓋了玉璽嗎？」王回答說：「實有這事，照米底亞和波斯人的例是不可更改的。」</span>
<span className="v" id="v13" data-v="13" data-xref="但以理書 3:12; 使徒行傳 5:29; 但以理書 2:25"> 他們對王說：「王啊，那被擄之猶大人中的但以理不理你，也不遵你蓋了玉璽的禁令，他竟一日三次祈禱。」</span>
<span className="v" id="v14" data-v="14" data-xref="馬可福音 6:26; 馬太福音 27:17–24; 撒母耳記下 3:28–29"> 王聽見這話，就甚愁煩，一心要救但以理，籌劃解救他，直到日落的時候。</span>
<span className="v" id="v15" data-v="15" data-xref="但以理書 6:12; 詩篇 94:20–21; 但以理書 6:8"> 那些人就紛紛聚集來見王，說：「王啊，當知道米底亞人和波斯人有例，凡王所立的禁令和律例都不可更改。」</span>
<span className="v" id="v16" data-v="16" data-xref="詩篇 37:39–40; 約伯記 5:19; 詩篇 91:14–16"> 王下令，人就把但以理帶來，扔在獅子坑中。王對但以理說：「你所常事奉的上帝，他必救你。」</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米哀歌 3:53; 使徒行傳 12:4; 馬太福音 27:60–66"> 有人搬石頭放在坑口，王用自己的璽和大臣的印，封閉那坑，使懲辦但以理的事毫無更改。</span>
<span className="v" id="v18" data-v="18" data-xref="以斯帖記 6:1; 但以理書 2:1; 撒母耳記下 12:16–17"> 王回宮，終夜禁食，無人拿樂器到他面前，並且睡不着覺。</span>
<span className="v" id="v19" data-v="19" data-xref="帖撒羅尼迦前書 3:5; 馬可福音 16:2; 馬太福音 28:1"> 次日黎明，王就起來，急忙往獅子坑那裏去。</span>
<span className="v" id="v20" data-v="20" data-xref="歷代志上 16:11; 希伯來書 7:25; 但以理書 6:27"> 臨近坑邊，哀聲呼叫但以理，對但以理說：「永生上帝的僕人但以理啊，你所常事奉的上帝能救你脫離獅子嗎？」</span>
<span className="v" id="v21" data-v="21" data-xref="但以理書 2:4; 但以理書 6:6; 尼希米記 2:3"> 但以理對王說：「願王萬歲！</span>
<span className="v" id="v22" data-v="22" data-xref="提摩太後書 4:17; 希伯來書 11:33; 使徒行傳 12:11"> 我的上帝差遣使者，封住獅子的口，叫獅子不傷我；因我在上帝面前無辜，我在王面前也沒有行過虧損的事。」</span>
<span className="v" id="v23" data-v="23" data-xref="歷代志上 5:20; 馬可福音 9:23; 但以理書 3:27–28"> 王就甚喜樂，吩咐人將但以理從坑裏繫上來。於是但以理從坑裏被繫上來，身上毫無傷損，因為信靠他的上帝。</span>
<span className="v" id="v24" data-v="24" data-xref="以賽亞書 38:13; 以斯帖記 7:10; 申命記 24:16"> 王下令，人就把那些控告但以理的人，連他們的妻子兒女都帶來，扔在獅子坑中。他們還沒有到坑底，獅子就抓住<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原文是勝了">b</a></sup>他們，咬碎他們的骨頭。</span>
<span className="v" id="v25" data-v="25" data-xref="但以理書 4:1; 以斯拉記 1:1–2; 以斯帖記 3:12"> 那時，大流士王傳旨，曉諭住在全地各方、各國、各族的人說：「願你們大享平安！</span>
<span className="v" id="v26" data-v="26" data-xref="但以理書 4:34; 路加福音 1:33; 但以理書 3:29"> 現在我降旨曉諭我所統轄的全國人民，要在但以理的上帝面前，戰兢恐懼。<br /><span className="pl pl-1">因為他是永遠長存的活上帝，</span><br /><span className="pl pl-1">他的國永不敗壞；</span><br /><span className="pl pl-1">他的權柄永存無極！</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="但以理書 4:2–3; 詩篇 18:50; 使徒行傳 4:30"> <span className="pl pl-1">他護庇人，搭救人，</span><br /><span className="pl pl-1">在天上地下施行神蹟奇事，</span><br /><span className="pl pl-1">救了但以理脫離獅子的口。」</span></span>
<span className="v" id="v28" data-v="28" data-xref="但以理書 1:21; 歷代志下 36:22–2; 以賽亞書 44:28–1"> 如此，這但以理，當大流士王在位的時候和波斯王塞魯士在位的時候，大享亨通。</span>

## 但以理敘述異象


## 四獸的異象

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="但以理書 1:17; 阿摩司書 3:7; 但以理書 5:1"> 巴比倫王伯沙撒元年，但以理在床上做夢，見了腦中的異象，就記錄這夢，述說其中的大意。</span>
<span className="v" id="v2" data-v="2" data-xref="啟示錄 7:1; 啟示錄 17:15"> 但以理說：<br />我夜裏見異象，看見天的四風陡起，颳在大海之上。</span>
<span className="v" id="v3" data-v="3" data-xref="啟示錄 13:1; 但以理書 7:17; 但以理書 2:32–33"> 有四個大獸從海中上來，形狀各有不同：</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米書 4:7; 以賽亞書 14:13–17; 以西結書 17:3"> 頭一個像獅子，有鷹的翅膀；我正觀看的時候，獸的翅膀被拔去，獸從地上得立起來，用兩腳站立，像人一樣，又得了人心。</span>
<span className="v" id="v5" data-v="5" data-xref="但以理書 2:39; 以賽亞書 13:17–18; 箴言 17:12"> 又有一獸如熊，就是第二獸，旁跨而坐，口齒內啣着三根肋骨。有吩咐這獸的說：「起來吞吃多肉。」</span>
<span className="v" id="v6" data-v="6" data-xref="啟示錄 13:2; 但以理書 8:20–22; 但以理書 8:5–8"> 此後我觀看，又有一獸如豹，背上有鳥的四個翅膀；這獸有四個頭，又得了權柄。</span>
<span className="v" id="v7" data-v="7" data-xref="啟示錄 13:1; 啟示錄 12:3; 啟示錄 17:12"> 其後我在夜間的異象中觀看，見第四獸甚是可怕，極其強壯，大有力量，有大鐵牙，吞吃嚼碎，所剩下的用腳踐踏。這獸與前三獸大不相同，頭有十角。</span>
<span className="v" id="v8" data-v="8" data-xref="啟示錄 13:5–6; 啟示錄 13:1; 詩篇 12:3"> 我正觀看這些角，見其中又長起一個小角；先前的角中有三角在這角前，連根被牠拔出來。這角有眼，像人的眼，有口說誇大的話。</span>
</div>
</div>

## 永存者的異象

<div className="bt">
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="啟示錄 1:14; 馬可福音 9:3; 但以理書 7:13"> <span className="pl pl-1">我觀看，</span><br /><span className="pl pl-1">見有寶座設立，</span><br /><span className="pl pl-1">上頭坐着亙古常在者。</span><br /><span className="pl pl-1">他的衣服潔白如雪，</span><br /><span className="pl pl-1">頭髮如純淨的羊毛。</span><br /><span className="pl pl-1">寶座乃火焰，</span><br /><span className="pl pl-1">其輪乃烈火。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="以賽亞書 30:27; 申命記 33:2; 啟示錄 20:11–15"> <span className="pl pl-1">從他面前有火，像河發出；</span><br /><span className="pl pl-1">事奉他的有千千，</span><br /><span className="pl pl-1">在他面前侍立的有萬萬；</span><br /><span className="pl pl-1">他坐着要行審判，</span><br /><span className="pl pl-1">案卷都展開了。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v11" data-v="11" data-xref="啟示錄 19:20; 啟示錄 20:10; 帖撒羅尼迦後書 2:8"> 那時我觀看，見那獸因小角說誇大話的聲音被殺，身體損壞，扔在火中焚燒。</span>
<span className="v" id="v12" data-v="12" data-xref="但以理書 8:7; 但以理書 7:4–6"> 其餘的獸，權柄都被奪去，生命卻仍存留，直到所定的時候和日期。</span>
<span className="v" id="v13" data-v="13" data-xref="馬太福音 26:64; 啟示錄 1:7; 路加福音 21:27"> <span className="pl pl-1">我在夜間的異象中觀看，</span><br /><span className="pl pl-1">見有一位像人子的，</span><br /><span className="pl pl-1">駕着天雲而來，</span><br /><span className="pl pl-1">被領到亙古常在者面前，</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="啟示錄 11:15; 但以理書 7:27; 約翰福音 3:35"> <span className="pl pl-1">得了權柄、榮耀、國度，</span><br /><span className="pl pl-1">使各方、各國、各族的人都事奉他。</span><br /><span className="pl pl-1">他的權柄是永遠的，不能廢去；</span><br /><span className="pl pl-1">他的國必不敗壞。</span></span>
</div>
</div>

## 解釋異象

<div className="bt">
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="但以理書 7:28; 耶利米書 17:16; 創世記 40:7–8"> 至於我－但以理，我的靈在我裏面愁煩，我腦中的異象使我驚惶。</span>
<span className="v" id="v16" data-v="16" data-xref="啟示錄 7:13–14; 撒迦利亞書 2:3; 啟示錄 5:5"> 我就近一位侍立者，問他這一切的真情。他就告訴我，將那事的講解給我說明：</span>
<span className="v" id="v17" data-v="17" data-xref="但以理書 8:19–22; 但以理書 2:37–40; 約翰福音 18:36"> 這四個大獸就是四王將要在世上興起。</span>
<span className="v" id="v18" data-v="18" data-xref="但以理書 7:27; 以賽亞書 60:12–14; 啟示錄 5:10"> 然而，至高者的聖民，必要得國享受，直到永永遠遠。</span>
<span className="v" id="v19" data-v="19" data-xref="但以理書 7:7; 但以理書 2:40–43"> 那時我願知道第四獸的真情，牠為何與那三獸的真情大不相同，甚是可怕，有鐵牙銅爪，吞吃嚼碎，所剩下的用腳踐踏；</span>
<span className="v" id="v20" data-v="20" data-xref="但以理書 7:23; 但以理書 7:8; 但以理書 7:11"> 頭有十角和那另長的一角，在這角前有三角被牠打落。這角有眼，有說誇大話的口，形狀強橫，過於牠的同類。</span>
<span className="v" id="v21" data-v="21" data-xref="但以理書 12:7; 啟示錄 17:14; 但以理書 8:24"> 我觀看，見這角與聖民爭戰，勝了他們。</span>
<span className="v" id="v22" data-v="22" data-xref="但以理書 7:18; 啟示錄 20:4; 啟示錄 5:10"> 直到亙古常在者來給至高者的聖民伸冤，聖民得國的時候就到了。</span>
<span className="v" id="v23" data-v="23" data-xref="但以理書 2:40; 但以理書 7:7; 路加福音 2:1"> <span className="pl pl-1">那侍立者這樣說：</span><br /><span className="pl pl-1">第四獸就是世上必有的第四國，</span><br /><span className="pl pl-1">與一切國大不相同，</span><br /><span className="pl pl-1">必吞吃全地，</span><br /><span className="pl pl-1">並且踐踏嚼碎。</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="但以理書 7:20; 但以理書 11:36; 啟示錄 13:1"> <span className="pl pl-1">至於那十角，就是從這國中必興起的十王，</span><br /><span className="pl pl-1">後來又興起一王，</span><br /><span className="pl pl-1">與先前的不同；</span><br /><span className="pl pl-1">他必制伏三王。</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="但以理書 12:7; 啟示錄 12:14; 帖撒羅尼迦後書 2:4"> <span className="pl pl-1">他必向至高者說誇大的話，</span><br /><span className="pl pl-1">必折磨至高者的聖民，</span><br /><span className="pl pl-1">必想改變節期和律法。</span><br /><span className="pl pl-1">聖民必交付他手一載、二載、半載。</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="啟示錄 20:10–11; 帖撒羅尼迦後書 2:8; 啟示錄 11:13"> <span className="pl pl-1">然而，審判者必坐着行審判；</span><br /><span className="pl pl-1">他的權柄必被奪去，</span><br /><span className="pl pl-1">毀壞，滅絕，一直到底。</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="詩篇 72:11; 路加福音 1:33; 啟示錄 11:15"> <span className="pl pl-1">國度、權柄，和天下諸國的大權</span><br /><span className="pl pl-1">必賜給至高者的聖民。</span><br /><span className="pl pl-1">他的國是永遠的；</span><br /><span className="pl pl-1">一切掌權的都必事奉他，順從他。</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="路加福音 2:19; 路加福音 2:51; 但以理書 10:8"> 那事至此完畢。至於我－但以理，心中甚是驚惶，臉色也改變了，卻將那事存記在心。</span>

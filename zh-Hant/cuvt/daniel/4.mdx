## 尼布甲尼撒的第二個夢

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="但以理書 6:25; 彼得前書 1:2; 但以理書 3:4"> 尼布甲尼撒王曉諭住在全地各方、各國、各族的人說：「願你們大享平安！</span>
<span className="v" id="v2" data-v="2" data-xref="但以理書 3:26; 詩篇 66:16; 詩篇 71:18"> 我樂意將至高的上帝向我所行的神蹟奇事宣揚出來。</span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 145:13; 以賽亞書 25:1; 但以理書 2:44"> <span className="pl pl-1">他的神蹟何其大！</span><br /><span className="pl pl-1">他的奇事何其盛！</span><br /><span className="pl pl-1">他的國是永遠的；</span><br /><span className="pl pl-1">他的權柄存到萬代！</span></span>
<span className="v" id="v4" data-v="4" data-xref="以賽亞書 47:7–8; 帖撒羅尼迦前書 5:2–3; 詩篇 30:6–7"> 「我－尼布甲尼撒安居在宮中，平順在殿內。</span>
<span className="v" id="v5" data-v="5" data-xref="但以理書 2:1; 約伯記 7:13–14; 但以理書 2:28–29"> 我做了一夢，使我懼怕。我在床上的思念，並腦中的異象，使我驚惶。</span>
<span className="v" id="v6" data-v="6" data-xref="但以理書 2:2; 創世記 41:7–8; 以賽亞書 8:19"> 所以我降旨召巴比倫的一切哲士到我面前，叫他們把夢的講解告訴我。</span>
<span className="v" id="v7" data-v="7" data-xref="以賽亞書 44:25; 但以理書 2:7; 創世記 41:8"> 於是那些術士、用法術的、迦勒底人、觀兆的都進來，我將那夢告訴了他們，他們卻不能把夢的講解告訴我。</span>
<span className="v" id="v8" data-v="8" data-xref="但以理書 1:7; 但以理書 5:14; 但以理書 4:18"> 末後那照我神的名，稱為伯提沙撒的但以理來到我面前，他裏頭有聖神的靈，我將夢告訴他說：</span>
<span className="v" id="v9" data-v="9" data-xref="但以理書 2:48; 但以理書 5:11; 但以理書 4:8"> 『術士的領袖伯提沙撒啊，因我知道你裏頭有聖神的靈，甚麼奧祕的事都不能使你為難。現在要把我夢中所見的異象和夢的講解告訴我。』</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米書 12:2; 但以理書 4:5; 詩篇 37:35–36"> 「我在床上腦中的異象是這樣：我看見地當中有一棵樹，極其高大。</span>
<span className="v" id="v11" data-v="11" data-xref="但以理書 4:21–22; 申命記 9:1; 馬太福音 11:23"> 那樹漸長，而且堅固，高得頂天，從地極都能看見，</span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 13:19; 耶利米哀歌 4:20; 以西結書 31:6–7"> 葉子華美，果子甚多，可作眾生的食物；田野的走獸臥在蔭下，天空的飛鳥宿在枝上；凡有血氣的都從這樹得食。</span>
<span className="v" id="v13" data-v="13" data-xref="申命記 33:2; 但以理書 8:13; 但以理書 7:1"> 「我在床上腦中的異象，見有一位守望的聖者從天而降。</span>
<span className="v" id="v14" data-v="14" data-xref="馬太福音 3:10; 但以理書 4:23; 以西結書 31:12–13"> 大聲呼叫說：『伐倒這樹！砍下枝子！搖掉葉子！拋散果子！使走獸離開樹下，飛鳥躲開樹枝。</span>
<span className="v" id="v15" data-v="15" data-xref="約伯記 14:7–9; 但以理書 4:25–27; 以西結書 29:14–15"> 樹墩卻要留在地內，用鐵圈和銅圈箍住，在田野的青草中讓天露滴濕，使他與地上的獸一同吃草，</span>
<span className="v" id="v16" data-v="16" data-xref="但以理書 4:23; 啟示錄 12:14; 但以理書 4:25"> 使他的心改變，不如人心，給他一個獸心，使他經過七期<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="期：或譯年；本章同">a</a></sup>。</span>
<span className="v" id="v17" data-v="17" data-xref="但以理書 4:25; 但以理書 2:21; 詩篇 75:6–7"> 這是守望者所發的命，聖者所出的令，好叫世人知道至高者在人的國中掌權，要將國賜與誰就賜與誰，或立極卑微的人執掌國權。』</span>
<span className="v" id="v18" data-v="18" data-xref="但以理書 5:15; 創世記 41:8; 但以理書 5:8"> 「這是我－尼布甲尼撒王所做的夢。伯提沙撒啊，你要說明這夢的講解；因為我國中的一切哲士都不能將夢的講解告訴我，惟獨你能，因你裏頭有聖神的靈。」</span>
</div>
</div>

## 但以理解夢

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="但以理書 8:27; 但以理書 7:28; 但以理書 4:24"> 於是稱為伯提沙撒的但以理驚訝片時，心意驚惶。王說：「伯提沙撒啊，不要因夢和夢的講解驚惶。」伯提沙撒回答說：「我主啊，願這夢歸與恨惡你的人，講解歸與你的敵人。</span>
<span className="v" id="v20" data-v="20" data-xref="但以理書 4:10–12; 以西結書 31:3; 以西結書 31:16"> 你所見的樹漸長，而且堅固，高得頂天，從地極都能看見；</span>
<span className="v" id="v21" data-v="21"> 葉子華美，果子甚多，可作眾生的食物；田野的走獸住在其下；天空的飛鳥宿在枝上。</span>
<span className="v" id="v22" data-v="22" data-xref="但以理書 2:37–38; 撒母耳記下 12:7; 耶利米書 27:6–8"> 「王啊，這漸長又堅固的樹就是你。你的威勢漸長及天，你的權柄管到地極。</span>
<span className="v" id="v23" data-v="23" data-xref="但以理書 5:21; 但以理書 4:13–16"> 王既看見一位守望的聖者從天而降，說：『將這樹砍伐毀壞，樹墩卻要留在地內，用鐵圈和銅圈箍住；在田野的青草中，讓天露滴濕，使他與地上的獸一同吃草，直到經過七期。』</span>
<span className="v" id="v24" data-v="24" data-xref="詩篇 107:40; 約伯記 40:11–12; 以賽亞書 46:10–11"> 「王啊，講解就是這樣：臨到我主我王的事是出於至高者的命。</span>
<span className="v" id="v25" data-v="25" data-xref="但以理書 4:17; 耶利米書 27:5; 詩篇 83:18"> 你必被趕出離開世人，與野地的獸同居，吃草如牛，被天露滴濕，且要經過七期。等你知道至高者在人的國中掌權，要將國賜與誰就賜與誰。</span>
<span className="v" id="v26" data-v="26" data-xref="但以理書 4:15; 馬太福音 5:34; 馬太福音 21:20"> 守望者既吩咐存留樹墩，等你知道諸天掌權，以後你的國必定歸你。</span>
<span className="v" id="v27" data-v="27" data-xref="以賽亞書 55:6–7; 約拿書 3:9; 使徒行傳 8:22"> 王啊，求你悅納我的諫言，以施行公義斷絕罪過，以憐憫窮人除掉罪孽，或者你的平安可以延長。」</span>
<span className="v" id="v28" data-v="28" data-xref="民數記 23:19; 撒迦利亞書 1:6; 箴言 10:24"> 這事都臨到尼布甲尼撒王。</span>
<span className="v" id="v29" data-v="29" data-xref="啟示錄 2:21; 傳道書 8:11; 彼得前書 3:20"> 過了十二個月，他遊行在巴比倫王宮裏<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原文是上">b</a></sup>。</span>
<span className="v" id="v30" data-v="30" data-xref="箴言 16:18; 啟示錄 18:10; 路加福音 14:11"> 他說：「這大巴比倫不是我用大能大力建為京都，要顯我威嚴的榮耀嗎？」</span>
<span className="v" id="v31" data-v="31" data-xref="使徒行傳 9:3–5; 啟示錄 16:7; 路加福音 12:20"> 這話在王口中尚未說完，有聲音從天降下，說：「尼布甲尼撒王啊，有話對你說，你的國位離開你了。</span>
<span className="v" id="v32" data-v="32" data-xref="耶利米書 27:5; 但以理書 5:21; 箴言 8:15–16"> 你必被趕出離開世人，與野地的獸同居，吃草如牛，且要經過七期。等你知道至高者在人的國中掌權，要將國賜與誰就賜與誰。」</span>
<span className="v" id="v33" data-v="33" data-xref="但以理書 4:32; 但以理書 4:25; 但以理書 5:5"> 當時這話就應驗在尼布甲尼撒的身上，他被趕出離開世人，吃草如牛，身被天露滴濕，頭髮長長，好像鷹毛；指甲長長，如同鳥爪。</span>
</div>
</div>

## 尼布甲尼撒頌讚上帝

<div className="bt">
<div className="bp poetry">
<span className="v" id="v34" data-v="34" data-xref="啟示錄 4:10; 耶利米書 10:10; 但以理書 12:7"> 日子滿足，我－尼布甲尼撒舉目望天，我的聰明復歸於我，我便稱頌至高者，讚美尊敬活到永遠的上帝。<br /><span className="pl pl-1">他的權柄是永有的；</span><br /><span className="pl pl-1">他的國存到萬代。</span><br /></span>
<span className="v" id="v35" data-v="35" data-xref="約伯記 42:2; 詩篇 135:6; 詩篇 115:3"> <span className="pl pl-1">世上所有的居民都算為虛無；</span><br /><span className="pl pl-1">在天上的萬軍和世上的居民中，</span><br /><span className="pl pl-1">他都憑自己的意旨行事。</span><br /><span className="pl pl-1">無人能攔住他手，</span><br /><span className="pl pl-1">或問他說，你做甚麼呢？</span></span>
<span className="v" id="v36" data-v="36" data-xref="但以理書 4:34; 箴言 22:4; 但以理書 4:15–16"> 那時，我的聰明復歸於我，為我國的榮耀、威嚴，和光耀也都復歸於我；並且我的謀士和大臣也來朝見我。我又得堅立在國位上，至大的權柄加增於我。</span>
<span className="v" id="v37" data-v="37" data-xref="雅各書 4:6–7; 詩篇 33:4–5; 彼得前書 5:5–6"> 現在我－尼布甲尼撒讚美、尊崇、恭敬天上的王；因為他所做的全都誠實，他所行的也都公平。那行動驕傲的，他能降為卑。</span>
</div>

## 基甸

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="尼希米記 9:26–29; 士師記 2:19–20; 士師記 2:13–14"> 以色列人又行耶和華眼中看為惡的事，耶和華就把他們交在米甸人手裏七年。</span>
<span className="v" id="v2" data-v="2" data-xref="希伯來書 11:38; 撒母耳記上 13:6; 申命記 28:47–48"> 米甸人壓制以色列人；以色列人因為米甸人，就在山中挖穴、挖洞、建造營寨。</span>
<span className="v" id="v3" data-v="3" data-xref="士師記 6:33; 士師記 3:13; 士師記 7:12"> 以色列人每逢撒種之後，米甸人、亞瑪力人，和東方人都上來攻打他們，</span>
<span className="v" id="v4" data-v="4" data-xref="利未記 26:16; 申命記 28:51; 彌迦書 6:15"> 對着他們安營，毀壞土產，直到迦薩，沒有給以色列人留下食物，牛、羊、驢也沒有留下；</span>
<span className="v" id="v5" data-v="5" data-xref="士師記 7:12; 士師記 8:10; 耶利米書 46:23"> 因為那些人帶着牲畜帳棚來，像蝗蟲那樣多，人和駱駝無數，都進入國內，毀壞全地。</span>
<span className="v" id="v6" data-v="6" data-xref="士師記 3:9; 耶利米書 5:17; 詩篇 50:15"> 以色列人因米甸人的緣故，極其窮乏，就呼求耶和華。</span>
<span className="v" id="v7" data-v="7"> 以色列人因米甸人的緣故，呼求耶和華，</span>
<span className="v" id="v8" data-v="8" data-xref="以西結書 20:5–32; 以賽亞書 63:9–14; 詩篇 136:10–16"> 耶和華就差遣先知到以色列人那裏，對他們說：「耶和華－以色列的上帝如此說：『我曾領你們從埃及上來，出了為奴之家，</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 44:2–3"> 救你們脫離埃及人的手，並脫離一切欺壓你們之人的手，把他們從你們面前趕出，將他們的地賜給你們』；</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米書 10:2; 列王紀下 17:35–39; 耶利米書 9:13"> 又對你們說：『我是耶和華－你們的上帝。你們住在亞摩利人的地，不可敬畏他們的神。你們竟不聽從我的話。』」</span>
<span className="v" id="v11" data-v="11" data-xref="約書亞記 17:2; 希伯來書 11:32; 士師記 13:3"> 耶和華的使者到了俄弗拉，坐在亞比以謝族人約阿施的橡樹下。約阿施的兒子基甸正在酒醡那裏打麥子，為要防備米甸人。</span>
<span className="v" id="v12" data-v="12" data-xref="約書亞記 1:5; 路加福音 1:28; 士師記 2:18"> 耶和華的使者向基甸顯現，對他說：「大能的勇士啊，耶和華與你同在！」</span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 77:7–9; 歷代志下 15:2; 以賽亞書 59:1–2"> 基甸說：「主啊，耶和華若與我們同在，我們何致遭遇這一切事呢？我們的列祖不是向我們說『耶和華領我們從埃及上來』嗎？他那樣奇妙的作為在哪裏呢？現在他卻丟棄我們，將我們交在米甸人手裏。」</span>
<span className="v" id="v14" data-v="14" data-xref="約書亞記 1:5–9; 希伯來書 11:34; 撒母耳記上 12:11"> 耶和華觀看基甸，說：「你靠着你這能力去從米甸人手裏拯救以色列人，不是我差遣你去的嗎？」</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳記上 9:21; 出埃及記 3:11; 出埃及記 4:10"> 基甸說：「主啊，我有何能拯救以色列人呢？我家在瑪拿西支派中是至貧窮的。我在我父家是至微小的。」</span>
<span className="v" id="v16" data-v="16" data-xref="約書亞記 1:5; 出埃及記 3:12; 使徒行傳 11:21"> 耶和華對他說：「我與你同在，你就必擊打米甸人，如擊打一人一樣。」</span>
<span className="v" id="v17" data-v="17" data-xref="詩篇 86:17; 出埃及記 33:13; 以賽亞書 7:11"> 基甸說：「我若在你眼前蒙恩，求你給我一個證據，使我知道與我說話的就是主。</span>
<span className="v" id="v18" data-v="18" data-xref="士師記 13:15; 創世記 18:3; 創世記 18:5"> 求你不要離開這裏，等我歸回將禮物帶來供在你面前。」主說：「我必等你回來。」</span>
<span className="v" id="v19" data-v="19" data-xref="創世記 18:6–8; 士師記 13:15–19; 利未記 2:4"> 基甸去預備了一隻山羊羔，用一伊法細麵做了無酵餅，將肉放在筐內，把湯盛在壺中，帶到橡樹下，獻在使者面前。</span>
<span className="v" id="v20" data-v="20" data-xref="士師記 13:19; 列王紀上 18:33–34"> 上帝的使者吩咐基甸說：「將肉和無酵餅放在這磐石上，把湯倒出來。」他就這樣行了。</span>
<span className="v" id="v21" data-v="21" data-xref="利未記 9:24; 列王紀上 18:38; 歷代志下 7:1"> 耶和華的使者伸出手內的杖，杖頭挨了肉和無酵餅，就有火從磐石中出來，燒盡了肉和無酵餅。耶和華的使者也就不見了。</span>
<span className="v" id="v22" data-v="22" data-xref="創世記 32:30; 出埃及記 33:20; 申命記 5:26"> 基甸見他是耶和華的使者，就說：「哀哉！主耶和華啊，我不好了，因為我覿面看見耶和華的使者。」</span>
<span className="v" id="v23" data-v="23" data-xref="但以理書 10:19; 約翰福音 20:26; 創世記 43:23"> 耶和華對他說：「你放心，不要懼怕，你必不致死。」</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 22:14; 出埃及記 17:15; 士師記 8:32"> 於是基甸在那裏為耶和華築了一座壇，起名叫「耶和華沙龍」<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="就是耶和華賜平安的意思">a</a></sup>。（這壇在亞比以謝族的俄弗拉直到如今。）</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及記 34:13; 士師記 3:7; 使徒行傳 5:29"> 當那夜，耶和華吩咐基甸說：「你取你父親的牛來，就是<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或譯：和">b</a></sup>那七歲的第二隻牛，並拆毀你父親為巴力所築的壇，砍下壇旁的木偶，</span>
<span className="v" id="v26" data-v="26" data-xref="哥林多前書 14:40; 撒母耳記下 24:18; 哥林多前書 14:33"> 在這磐石<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="原文是保障">c</a></sup>上整整齊齊地為耶和華－你的上帝築一座壇，將第二隻牛獻為燔祭，用你所砍下的木偶作柴。」</span>
<span className="v" id="v27" data-v="27" data-xref="帖撒羅尼迦前書 2:4; 約翰福音 2:5; 申命記 4:1"> 基甸就從他僕人中挑了十個人，照着耶和華吩咐他的行了。他因怕父家和本城的人，不敢在白晝行這事，就在夜間行了。</span>
<span className="v" id="v28" data-v="28"> 城裏的人清早起來，見巴力的壇拆毀，壇旁的木偶砍下，第二隻牛獻在新築的壇上，</span>
<span className="v" id="v29" data-v="29"> 就彼此說：「這事是誰做的呢？」他們訪查之後，就說：「這是約阿施的兒子基甸做的。」</span>
<span className="v" id="v30" data-v="30" data-xref="使徒行傳 26:9; 腓立比書 3:6; 耶利米書 50:38"> 城裏的人對約阿施說：「將你兒子交出來，好治死他；因為他拆毀了巴力的壇，砍下壇旁的木偶。」</span>
<span className="v" id="v31" data-v="31" data-xref="耶利米書 10:11; 哥林多前書 8:4; 以弗所書 5:11"> 約阿施回答站着攻擊他的眾人說：「你們是為巴力爭論嗎？你們要救他嗎？誰為他爭論，趁早將誰治死！巴力若果是神，有人拆毀他的壇，讓他為自己爭論吧！」</span>
<span className="v" id="v32" data-v="32" data-xref="撒母耳記上 12:11; 士師記 7:1; 撒母耳記下 11:21"> 所以當日人稱基甸為耶路‧巴力，意思說：「他拆毀巴力的壇，讓巴力與他爭論。」</span>
<span className="v" id="v33" data-v="33" data-xref="約書亞記 17:16; 士師記 6:3; 羅馬書 8:35–39"> 那時，米甸人、亞瑪力人，和東方人都聚集過河，在耶斯列平原安營。</span>
<span className="v" id="v34" data-v="34" data-xref="士師記 3:27; 歷代志下 24:20; 士師記 3:10"> 耶和華的靈降在基甸身上，他就吹角；亞比以謝族都聚集跟隨他。</span>
<span className="v" id="v35" data-v="35" data-xref="歷代志下 30:6–12; 士師記 4:6"> 他打發人走遍瑪拿西地，瑪拿西人也聚集跟隨他；又打發人去見亞設人、西布倫人、拿弗他利人，他們也都出來與他們會合。</span>
<span className="v" id="v36" data-v="36" data-xref="士師記 6:14; 馬太福音 16:1; 士師記 6:17–20"> 基甸對上帝說：「你若果照着所說的話，藉我手拯救以色列人，</span>
<span className="v" id="v37" data-v="37" data-xref="何西阿書 14:5; 馬太福音 10:5–6; 馬太福音 15:24"> 我就把一團羊毛放在禾場上：若單是羊毛上有露水，別的地方都是乾的，我就知道你必照着所說的話，藉我手拯救以色列人。」</span>
<span className="v" id="v38" data-v="38" data-xref="以賽亞書 35:7"> 次日早晨基甸起來，見果然是這樣；將羊毛擠一擠，從羊毛中擰出滿盆的露水來。</span>
<span className="v" id="v39" data-v="39" data-xref="創世記 18:32; 以賽亞書 50:2; 詩篇 107:33–35"> 基甸又對上帝說：「求你不要向我發怒，我再說這一次：讓我將羊毛再試一次。但願羊毛是乾的，別的地方都有露水。」</span>
<span className="v" id="v40" data-v="40"> 這夜上帝也如此行：獨羊毛上是乾的，別的地方都有露水。</span>

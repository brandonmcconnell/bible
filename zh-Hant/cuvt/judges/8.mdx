## 擊敗米甸人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳記下 19:41; 士師記 12:1–6; 約伯記 5:2"> 以法蓮人對基甸說：「你去與米甸人爭戰，沒有招我們同去，為甚麼這樣待我們呢？」他們就與基甸大大地爭吵。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="哥林多前書 13:4–7; 腓立比書 2:2–3; 雅各書 3:13–18"> 基甸對他們說：「我所行的豈能比你們所行的呢？以法蓮拾取剩下的葡萄不強過亞比以謝所摘的葡萄嗎？</span>
<span className="v" id="v3" data-v="3" data-xref="箴言 15:1; 士師記 7:24–25; 約翰福音 4:37"> 上帝已將米甸人的兩個首領俄立和西伊伯交在你們手中；我所行的豈能比你們所行的呢？」基甸說了這話，以法蓮人的怒氣就消了。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="加拉太書 6:9; 哥林多後書 4:16; 撒母耳記上 14:28–29"> 基甸和跟隨他的三百人到約旦河過渡，雖然疲乏，還是追趕。</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 33:17; 詩篇 60:6; 撒母耳記上 25:18"> 基甸對疏割人說：「求你們拿餅來給跟隨我的人吃，因為他們疲乏了；我們追趕米甸人的兩個王西巴和撒慕拿。」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="列王紀上 20:11; 腓立比書 2:21; 箴言 18:23"> 疏割人的首領回答說：「西巴和撒慕拿已經在你手裏，你使我們將餅給你的軍兵嗎？」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="士師記 7:15"> 基甸說：「耶和華將西巴和撒慕拿交在我手之後，我就用野地的荊條和枳棘打傷你們。」</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 32:30–31; 列王紀上 12:25"> 基甸從那裏上到毗努伊勒，對那裏的人也是這樣說；毗努伊勒人也與疏割人回答他的話一樣。</span>
<span className="v" id="v9" data-v="9" data-xref="士師記 8:17; 列王紀上 22:27–28"> 他向毗努伊勒人說：「我平平安安回來的時候，我必拆毀這樓。」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="士師記 7:12; 士師記 20:25; 士師記 20:2"> 那時西巴和撒慕拿，並跟隨他們的軍隊都在加各，約有一萬五千人，就是東方人全軍所剩下的；已經被殺約有十二萬拿刀的。</span>
<span className="v" id="v11" data-v="11" data-xref="民數記 32:35; 民數記 32:42; 士師記 18:27"> 基甸就由挪巴和約比哈東邊，從住帳棚人的路上去，殺敗了米甸人的軍兵，因為他們坦然無懼。</span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 83:11; 阿摩司書 2:14; 約伯記 12:16–21"> 西巴和撒慕拿逃跑；基甸追趕他們，捉住米甸的二王西巴和撒慕拿，驚散全軍。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13"> 約阿施的兒子基甸由希列斯坡從陣上回來，</span>
<span className="v" id="v14" data-v="14" data-xref="士師記 1:24–25; 撒母耳記上 30:11–15"> 捉住疏割的一個少年人，問他：「疏割的首領長老是誰？」他就將首領長老七十七個人的名字寫出來。</span>
<span className="v" id="v15" data-v="15" data-xref="士師記 8:6–7"> 基甸到了疏割，對那裏的人說：「你們從前譏誚我說：『西巴和撒慕拿已經在你手裏，你使我們將餅給跟隨你的疲乏人嗎？』現在西巴和撒慕拿在這裏。」</span>
<span className="v" id="v16" data-v="16" data-xref="士師記 8:7; 以斯拉記 2:6; 箴言 10:13"> 於是捉住那城內的長老，用野地的荊條和枳棘責打<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是指教">a</a></sup>疏割人；</span>
<span className="v" id="v17" data-v="17" data-xref="士師記 8:9; 列王紀上 12:25"> 又拆了毗努伊勒的樓，殺了那城裏的人。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="士師記 4:6; 猶大書 1:16; 詩篇 89:12"> 基甸問西巴和撒慕拿說：「你們在他泊山所殺的人是甚麼樣式？」回答說：「他們好像你，各人都有王子的樣式。」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19"> 基甸說：「他們是我同母的弟兄，我指着永生的耶和華起誓，你們從前若存留他們的性命，我如今就不殺你們了。」</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 149:9; 撒母耳記上 15:33; 約書亞記 10:24"> 於是對他的長子益帖說：「你起來殺他們。」但益帖因為是童子，害怕，不敢拔刀。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="詩篇 83:11; 士師記 8:26; 以賽亞書 3:18"> 西巴和撒慕拿說：「你自己起來殺我們吧！因為人如何，力量也是如何。」基甸就起來，殺了西巴和撒慕拿，奪獲他們駱駝項上戴的月牙圈。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="約翰福音 6:15; 士師記 9:8–15; 撒母耳記上 12:12"> 以色列人對基甸說：「你既救我們脫離米甸人的手，願你和你的兒孫管理我們。」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="以賽亞書 33:22; 撒母耳記上 12:12; 撒母耳記上 10:19"> 基甸說：「我不管理你們，我的兒子也不管理你們，惟有耶和華管理你們。」</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 25:13; 創世記 37:25; 創世記 37:28"> 基甸又對他們說：「我有一件事求你們：請你們各人將所奪的耳環給我。」（原來仇敵是以實瑪利人，都是戴金耳環的。）</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25"> 他們說：「我們情願給你」，就鋪開一件外衣，各人將所奪的耳環丟在其上。</span>
<span className="v" id="v26" data-v="26" data-xref="啟示錄 18:16; 約翰福音 19:2; 啟示錄 18:12"> 基甸所要出來的金耳環重一千七百舍客勒金子。此外還有米甸王所戴的月環、耳墜，和所穿的紫色衣服，並駱駝項上的金鍊子。</span>
<span className="v" id="v27" data-v="27" data-xref="士師記 17:5; 士師記 18:14; 詩篇 106:39"> 基甸以此製造了一個以弗得，設立在本城俄弗拉。後來以色列人拜那以弗得行了邪淫；這就作了基甸和他全家的網羅。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="士師記 5:31; 士師記 3:11; 士師記 3:30"> 這樣，米甸人被以色列人制伏了，不敢再抬頭。基甸還在的日子，國中太平四十年。</span>
</div>
</div>

## 基甸去世

<div className="bt">
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="士師記 6:32; 士師記 7:1; 撒母耳記上 12:11"> 約阿施的兒子耶路‧巴力回去，住在自己家裏。</span>
<span className="v" id="v30" data-v="30" data-xref="士師記 9:5; 士師記 9:2; 列王紀上 11:3"> 基甸有七十個親生的兒子，因為他有許多的妻。</span>
<span className="v" id="v31" data-v="31" data-xref="士師記 9:18; 創世記 22:24; 創世記 16:15"> 他的妾住在示劍，也給他生了一個兒子。基甸與他起名叫亞比米勒。</span>
<span className="v" id="v32" data-v="32" data-xref="創世記 25:8; 士師記 6:24; 約伯記 5:26"> 約阿施的兒子基甸，年紀老邁而死，葬在亞比以謝族的俄弗拉，在他父親約阿施的墳墓裏。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="士師記 9:46; 士師記 2:19; 士師記 9:4"> 基甸死後，以色列人又去隨從諸巴力行邪淫，以巴力‧比利土為他們的神。</span>
<span className="v" id="v34" data-v="34" data-xref="詩篇 78:42; 詩篇 106:21; 詩篇 78:11"> 以色列人不記念耶和華－他們的上帝，就是拯救他們脫離四圍仇敵之手的，</span>
<span className="v" id="v35" data-v="35" data-xref="傳道書 9:14–15; 士師記 9:5; 士師記 9:16–19"> 也不照着耶路‧巴力，就是基甸向他們所施的恩惠厚待他的家。</span>
</div>
</div>

## 米迦和但支派

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士師記 17:6; 士師記 19:1; 士師記 1:34"> 那時，以色列中沒有王。但支派的人仍是尋地居住；因為到那日子，他們還沒有在以色列支派中得地為業。</span>
<span className="v" id="v2" data-v="2" data-xref="士師記 13:25; 約書亞記 2:1; 士師記 18:11"> 但人從瑣拉和以實陶打發本族中的五個勇士，去仔細窺探那地，吩咐他們說：「你們去窺探那地。」他們來到以法蓮山地，進了米迦的住宅，就在那裏住宿。</span>
<span className="v" id="v3" data-v="3" data-xref="士師記 12:6; 創世記 27:22; 馬太福音 26:73"> 他們臨近米迦的住宅，聽出那少年利未人的口音來，就進去問他說：「誰領你到這裏來？你在這裏做甚麼？你在這裏得甚麼？」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="士師記 17:10; 以西結書 13:19; 箴言 28:21"> 他回答說：「米迦待我如此如此，請我作祭司。」</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="使徒行傳 8:10; 以賽亞書 30:1; 列王紀上 22:5"> 他們對他說：「請你求問上帝，使我們知道所行的道路通達不通達。」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="列王紀上 22:6; 列王紀上 22:15; 詩篇 33:18"> 祭司對他們說：「你們可以平平安安地去，你們所行的道路是在耶和華面前的。」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="約書亞記 19:47; 士師記 18:27–28; 撒母耳記上 3:13"> 五人就走了，來到拉億，見那裏的民安居無慮，如同西頓人安居一樣。在那地沒有人掌權擾亂他們；他們離西頓人也遠，與別人沒有來往。</span>
<span className="v" id="v8" data-v="8" data-xref="士師記 18:11; 士師記 18:2; 士師記 13:2"> 五人回到瑣拉和以實陶，見他們的弟兄；弟兄問他們說：「你們有甚麼話？」</span>
<span className="v" id="v9" data-v="9" data-xref="約書亞記 2:23–24; 民數記 13:30; 約書亞記 18:3"> 他們回答說：「起來，我們上去攻擊他們吧！我們已經窺探那地，見那地甚好。你們為何靜坐不動呢？要急速前往得那地為業，不可遲延。</span>
<span className="v" id="v10" data-v="10" data-xref="士師記 18:27; 士師記 18:7; 申命記 2:29"> 你們到了那裏，必看見安居無慮的民，地也寬闊。上帝已將那地交在你們手中；那地百物俱全，一無所缺。」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="士師記 18:16"> 於是但族中的六百人，各帶兵器，從瑣拉和以實陶前往，</span>
<span className="v" id="v12" data-v="12" data-xref="士師記 13:25; 約書亞記 15:60; 歷代志下 1:4"> 上到猶大的基列‧耶琳，在基列‧耶琳後邊安營。因此那地方名叫瑪哈尼‧但，直到今日。</span>
<span className="v" id="v13" data-v="13" data-xref="約書亞記 24:30; 士師記 19:1; 士師記 18:2–3"> 他們從那裏往以法蓮山地去，來到米迦的住宅。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="士師記 17:5; 士師記 18:3–4; 撒母耳記上 14:28"> 從前窺探拉億地的五個人對他們的弟兄說：「這宅子裏有以弗得和家中的神像，並雕刻的像與鑄成的像，你們知道嗎？現在你們要想一想當怎樣行。」</span>
<span className="v" id="v15" data-v="15" data-xref="創世記 43:27; 撒母耳記上 17:22; 約翰福音 14:27"> 五人就進入米迦的住宅，到了那少年利未人的房內問他好。</span>
<span className="v" id="v16" data-v="16" data-xref="士師記 18:11"> 那六百但人各帶兵器，站在門口。</span>
<span className="v" id="v17" data-v="17" data-xref="士師記 18:14; 士師記 17:4–5; 士師記 18:2"> 窺探地的五個人走進去，將雕刻的像、以弗得、家中的神像，並鑄成的像，都拿了去。祭司和帶兵器的六百人，一同站在門口。</span>
<span className="v" id="v18" data-v="18"> 那五個人進入米迦的住宅，拿出雕刻的像、以弗得、家中的神像，並鑄成的像，祭司就問他們說：「你們做甚麼呢？」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="約伯記 29:9; 約伯記 21:5; 士師記 17:10"> 他們回答說：「不要作聲，用手摀口，跟我們去吧！我們必以你為父、為祭司。你作一家的祭司好呢？還是作以色列一族一支派的祭司好呢？」</span>
<span className="v" id="v20" data-v="20" data-xref="以賽亞書 56:11; 以西結書 13:19; 箴言 30:15"> 祭司心裏喜悅，便拿着以弗得和家中的神像，並雕刻的像，進入他們中間。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21"> 他們就轉身離開那裏，妻子、兒女、牲畜、財物都在前頭。</span>
<span className="v" id="v22" data-v="22"> 離米迦的住宅已遠，米迦的近鄰都聚集來，追趕但人，</span>
<span className="v" id="v23" data-v="23" data-xref="詩篇 114:5; 撒母耳記下 14:5; 撒母耳記上 11:5"> 呼叫但人。但人回頭問米迦說：「你聚集這許多人來做甚麼呢？」</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="哈巴谷書 2:18–19; 以賽亞書 44:18–20; 詩篇 115:8"> 米迦說：「你們將我所做的神像和祭司都帶了去，我還有所剩的嗎？怎麼還問我說『做甚麼』呢？」</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="約伯記 27:2; 約伯記 3:5; 撒母耳記上 30:6"> 但人對米迦說：「你不要使我們聽見你的聲音，恐怕有性暴的人攻擊你，以致你和你的全家盡都喪命。」</span>
<span className="v" id="v26" data-v="26"> 但人還是走他們的路。米迦見他們的勢力比自己強盛，就轉身回家去了。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="約書亞記 19:47; 士師記 18:7; 士師記 18:10"> 但人將米迦所做的神像和他的祭司都帶到拉億，見安居無慮的民，就用刀殺了那民，又放火燒了那城，</span>
<span className="v" id="v28" data-v="28" data-xref="撒母耳記下 10:6; 士師記 18:7; 民數記 13:21"> 並無人搭救；因為離西頓遠，他們又與別人沒有來往。城在平原，那平原靠近伯‧利合。但人又在那裏修城居住，</span>
<span className="v" id="v29" data-v="29" data-xref="約書亞記 19:47; 創世記 14:14; 列王紀上 15:20"> 照着他們始祖以色列之子但的名字，給那城起名叫但；原先那城名叫拉億。</span>
<span className="v" id="v30" data-v="30" data-xref="撒母耳記上 4:10–11; 士師記 13:1; 士師記 17:5"> 但人就為自己設立那雕刻的像。摩西的孫子、革舜的兒子約拿單，和他的子孫作但支派的祭司，直到那地遭擄掠的日子。</span>
<span className="v" id="v31" data-v="31" data-xref="約書亞記 18:1; 撒母耳記上 1:3; 士師記 19:18"> 上帝的殿在示羅多少日子，但人為自己設立米迦所雕刻的像也在但多少日子。</span>
</div>
</div>

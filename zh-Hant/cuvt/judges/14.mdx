## 參孫和亭拿的女子

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="約書亞記 15:10; 約書亞記 19:43; 約翰一書 2:16"> 參孫下到亭拿，在那裏看見一個女子，是非利士人的女兒。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 34:4; 創世記 21:21; 創世記 24:2–3"> 參孫上來稟告他父母說：「我在亭拿看見一個女子，是非利士人的女兒，願你們給我娶來為妻。」</span>
<span className="v" id="v3" data-v="3" data-xref="士師記 15:18; 撒母耳記上 17:36; 撒母耳記上 14:6"> 他父母說：「在你弟兄的女兒中，或在本國的民中，豈沒有一個女子，何致你去在未受割禮的非利士人中娶妻呢？」參孫對他父親說：「願你給我娶那女子，因我喜悅她。」</span>
<span className="v" id="v4" data-v="4" data-xref="約書亞記 11:20; 詩篇 115:3; 士師記 13:1"> 他的父母卻不知道這事是出於耶和華，因為他找機會攻擊非利士人。那時，非利士人轄制以色列人。</span>
<span className="v" id="v5" data-v="5"> 參孫跟他父母下亭拿去，到了亭拿的葡萄園，見有一隻少壯獅子向他吼叫。</span>
<span className="v" id="v6" data-v="6" data-xref="士師記 3:10; 士師記 13:25; 撒母耳記上 11:6"> 耶和華的靈大大感動參孫，他雖然手無器械，卻將獅子撕裂，如同撕裂山羊羔一樣。他行這事並沒有告訴父母。</span>
<span className="v" id="v7" data-v="7"> 參孫下去與女子說話，就喜悅她；</span>
<span className="v" id="v8" data-v="8" data-xref="馬太福音 1:20; 創世記 29:21"> 過了些日子，再下去要娶那女子，轉向道旁要看死獅，見有一群蜂子和蜜在死獅之內，</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳記上 14:25–30; 箴言 25:15"> 就用手取蜜，且吃且走；到了父母那裏，給他父母，他們也吃了；只是沒有告訴這蜜是從死獅之內取來的。</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 29:22; 啟示錄 19:9; 以斯帖記 1:7–22"> 他父親下去見女子。參孫在那裏設擺筵宴，因為向來少年人都有這個規矩。</span>
<span className="v" id="v11" data-v="11" data-xref="馬太福音 9:15; 撒母耳記上 16:6; 撒母耳記上 10:23"> 眾人看見參孫，就請了三十個人陪伴他。</span>
<span className="v" id="v12" data-v="12" data-xref="列王紀上 10:1; 以西結書 17:2; 創世記 45:22"> 參孫對他們說：「我給你們出一個謎語，你們在七日筵宴之內，若能猜出意思告訴我，我就給你們三十件裏衣，三十套衣裳；</span>
<span className="v" id="v13" data-v="13"> 你們若不能猜出意思告訴我，你們就給我三十件裏衣，三十套衣裳。」他們說：「請將謎語說給我們聽。」</span>
<span className="v" id="v14" data-v="14" data-xref="雅各書 1:2–4; 列王紀上 17:6; 羅馬書 8:37"> 參孫對他們說：<br /><span className="pl pl-1">吃的從吃者出來；</span><br /><span className="pl pl-1">甜的從強者出來。</span>他們三日不能猜出謎語的意思。</span>
<span className="v" id="v15" data-v="15" data-xref="士師記 16:5; 士師記 15:6; 箴言 6:26"> 到第七天，他們對參孫的妻說：「你誆哄你丈夫，探出謎語的意思告訴我們，免得我們用火燒你和你父家。你們請了我們來，是要奪我們所有的嗎？」</span>
<span className="v" id="v16" data-v="16" data-xref="士師記 16:15; 創世記 2:24"> 參孫的妻在丈夫面前啼哭說：「你是恨我，不是愛我，你給我本國的人出謎語，卻沒有將意思告訴我。」參孫回答說：「連我父母我都沒有告訴，豈可告訴你呢？」</span>
<span className="v" id="v17" data-v="17" data-xref="士師記 16:16; 約伯記 2:9; 士師記 16:13"> 七日筵宴之內，她在丈夫面前啼哭，到第七天逼着他，他才將謎語的意思告訴他妻，他妻就告訴本國的人。</span>
<span className="v" id="v18" data-v="18"> 到第七天，日頭未落以前，那城裏的人對參孫說：<br /><span className="pl pl-1">有甚麼比蜜還甜呢？</span><br /><span className="pl pl-1">有甚麼比獅子還強呢？</span>參孫對他們說：<br /><span className="pl pl-1">你們若非用我的母牛犢耕地，</span><br /><span className="pl pl-1">就猜不出我謎語的意思來。</span></span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳記上 11:6; 士師記 3:10; 士師記 13:25"> 耶和華的靈大大感動參孫，他就下到亞實基倫，擊殺了三十個人，奪了他們的衣裳，將衣裳給了猜出謎語的人。參孫發怒，就上父家去了。</span>
<span className="v" id="v20" data-v="20" data-xref="士師記 15:2; 約翰福音 3:29; 詩篇 55:12–13"> 參孫的妻便歸了參孫的陪伴，就是作過他朋友的。</span>

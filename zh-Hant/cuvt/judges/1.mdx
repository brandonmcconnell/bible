## 猶大和西緬支派俘虜亞多尼‧比色

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士師記 20:18; 民數記 27:21; 士師記 20:28"> 約書亞死後，以色列人求問耶和華說：「我們中間誰當首先上去攻擊迦南人，與他們爭戰？」</span>
<span className="v" id="v2" data-v="2" data-xref="啟示錄 5:5; 希伯來書 7:14; 民數記 2:3"> 耶和華說：「猶大當先上去，我已將那地交在他手中。」</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳記下 10:11; 約書亞記 19:1; 士師記 1:17"> 猶大對他哥哥西緬說：「請你同我到拈鬮所得之地去，好與迦南人爭戰；以後我也同你到你拈鬮所得之地去。」於是西緬與他同去。</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳記上 11:8; 出埃及記 23:28–29; 約書亞記 11:6–8"> 猶大就上去；耶和華將迦南人和比利洗人交在他們手中。他們在比色擊殺了一萬人，</span>
<span className="v" id="v5" data-v="5"> 又在那裏遇見亞多尼‧比色，與他爭戰，殺敗迦南人和比利洗人。</span>
<span className="v" id="v6" data-v="6"> 亞多尼‧比色逃跑；他們追趕，拿住他，砍斷他手腳的大拇指。</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳記上 15:33; 啟示錄 13:10; 路加福音 6:37–38"> 亞多尼‧比色說：「從前有七十個王，手腳的大拇指都被我砍斷，在我桌子底下拾取零碎食物。現在上帝按着我所行的報應我了。」於是他們將亞多尼‧比色帶到耶路撒冷，他就死在那裏。</span>
</div>
</div>

## 猶大支派攻取耶路撒冷和希伯崙

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="約書亞記 15:63; 士師記 1:21"> 猶大人攻打耶路撒冷，將城攻取，用刀殺了城內的人，並且放火燒城。</span>
<span className="v" id="v9" data-v="9" data-xref="約書亞記 15:13–20; 約書亞記 11:21; 約書亞記 10:36"> 後來猶大人下去，與住山地、南地，和高原的迦南人爭戰。</span>
<span className="v" id="v10" data-v="10" data-xref="民數記 13:22; 約書亞記 14:15; 耶利米書 9:23"> 猶大人去攻擊住希伯崙的迦南人，殺了示篩、亞希幔、撻買。希伯崙從前名叫基列‧亞巴。</span>
</div>
</div>

## 俄陀聶攻取底壁城

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="約書亞記 15:15; 約書亞記 10:38–39"> 他們從那裏去攻擊底壁的居民；底壁從前名叫基列‧西弗。</span>
<span className="v" id="v12" data-v="12" data-xref="約書亞記 15:16–17; 撒母耳記上 17:25; 撒母耳記上 18:23"> 迦勒說：「誰能攻打基列‧西弗，將城奪取，我就把我女兒押撒給他為妻。」</span>
<span className="v" id="v13" data-v="13" data-xref="士師記 3:9"> 迦勒兄弟基納斯的兒子俄陀聶奪取了那城，迦勒就把女兒押撒給他為妻。</span>
<span className="v" id="v14" data-v="14" data-xref="約書亞記 15:18–19"> 押撒過門的時候，勸丈夫向她父親求一塊田。押撒一下驢，迦勒問她說：「你要甚麼？」</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳記上 25:18; 哥林多後書 9:5; 彼得前書 3:9"> 她說：「求你賜福給我，你既將我安置在南地，求你也給我水泉。」迦勒就把上泉下泉賜給她。</span>
</div>
</div>

## 猶大和便雅憫支派的勝利

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="民數記 10:29–32; 士師記 4:11; 撒母耳記上 15:6"> 摩西的內兄<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或譯：岳父">a</a></sup>是基尼人，他的子孫與猶大人一同離了棕樹城，往亞拉得以南的猶大曠野去，就住在民中。</span>
<span className="v" id="v17" data-v="17" data-xref="民數記 21:3; 士師記 1:3; 約書亞記 19:4"> 猶大和他哥哥西緬同去，擊殺了住洗法的迦南人，將城盡行毀滅，那城的名便叫何珥瑪。</span>
<span className="v" id="v18" data-v="18" data-xref="約書亞記 11:22; 士師記 3:3; 約書亞記 15:45–47"> 猶大又取了迦薩和迦薩的四境，亞實基倫和亞實基倫的四境，以革倫和以革倫的四境。</span>
<span className="v" id="v19" data-v="19" data-xref="以賽亞書 41:10; 士師記 1:2; 詩篇 60:12"> 耶和華與猶大同在，猶大就趕出山地的居民，只是不能趕出平原的居民，因為他們有鐵車。</span>
<span className="v" id="v20" data-v="20" data-xref="士師記 1:10; 約書亞記 15:13–14; 民數記 14:24"> 以色列人照摩西所說的，將希伯崙給了迦勒；迦勒就從那裏趕出亞衲族的三個族長。</span>
<span className="v" id="v21" data-v="21" data-xref="約書亞記 15:63; 士師記 19:10–12; 士師記 1:8"> 便雅憫人沒有趕出住耶路撒冷的耶布斯人。耶布斯人仍在耶路撒冷與便雅憫人同住，直到今日。</span>
</div>
</div>

## 以法蓮和瑪拿西支派攻取伯特利

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="士師記 1:19; 列王紀下 18:7; 民數記 1:32"> 約瑟家也上去攻打伯特利；耶和華與他們同在。</span>
<span className="v" id="v23" data-v="23" data-xref="創世記 28:19; 創世記 35:6; 創世記 48:3"> 約瑟家打發人去窺探伯特利（那城起先名叫路斯）。</span>
<span className="v" id="v24" data-v="24" data-xref="約書亞記 2:12–14; 撒母耳記上 30:15"> 窺探的人看見一個人從城裏出來，就對他說：「求你將進城的路指示我們，我們必恩待你。」</span>
<span className="v" id="v25" data-v="25" data-xref="約書亞記 6:22–25"> 那人將進城的路指示他們，他們就用刀擊殺了城中的居民，但將那人和他全家放去。</span>
<span className="v" id="v26" data-v="26" data-xref="列王紀下 7:6; 歷代志下 1:17"> 那人往赫人之地去，築了一座城，起名叫路斯。那城到如今還叫這名。</span>
</div>
</div>

## 以色列人沒有趕出去的民

<div className="bt">
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="約書亞記 17:11–13; 耶利米書 48:10; 詩篇 106:34–35"> 瑪拿西沒有趕出伯‧善和屬伯‧善鄉村的居民，他納和屬他納鄉村的居民，多珥和屬多珥鄉村的居民，以伯蓮和屬以伯蓮鄉村的居民，米吉多和屬米吉多鄉村的居民；迦南人卻執意住在那些地方。</span>
<span className="v" id="v28" data-v="28"> 及至以色列強盛了，就使迦南人做苦工，沒有把他們全然趕出。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="約書亞記 16:10; 列王紀上 9:16"> 以法蓮沒有趕出住基色的迦南人。於是迦南人仍住在基色，在以法蓮中間。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="約書亞記 19:15"> 西布倫沒有趕出基倫的居民和拿哈拉的居民。於是迦南人仍住在西布倫中間，成了服苦的人。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="約書亞記 19:24–30"> 亞設沒有趕出亞柯和西頓的居民，亞黑拉和亞革悉的居民，黑巴、亞弗革與利合的居民。</span>
<span className="v" id="v32" data-v="32" data-xref="詩篇 106:34–35"> 於是，亞設因為沒有趕出那地的迦南人，就住在他們中間。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="約書亞記 19:32–38; 士師記 1:30; 詩篇 18:24"> 拿弗他利沒有趕出伯‧示麥和伯‧亞納的居民，於是拿弗他利就住在那地的迦南人中間；然而伯‧示麥和伯‧亞納的居民成了服苦的人。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="約書亞記 19:47; 士師記 18:1"> 亞摩利人強逼但人住在山地，不容他們下到平原；</span>
<span className="v" id="v35" data-v="35" data-xref="約書亞記 19:42; 士師記 12:12; 約書亞記 10:12"> 亞摩利人卻執意住在希烈山和亞雅崙並沙賓。然而約瑟家勝了他們，使他們成了服苦的人。</span>
<span className="v" id="v36" data-v="36" data-xref="民數記 34:4; 約書亞記 15:2–3"> 亞摩利人的境界，是從亞克拉濱坡，從西拉而上。</span>
</div>
</div>

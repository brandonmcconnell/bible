## 利未人和他的妾

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士師記 18:1; 士師記 17:8; 瑪拉基書 2:15"> 當以色列中沒有王的時候，有住以法蓮山地那邊的一個利未人，娶了一個猶大伯利恆的女子為妾。</span>
<span className="v" id="v2" data-v="2" data-xref="以西結書 16:28; 申命記 22:21; 利未記 21:9"> 妾行淫離開丈夫，回猶大的伯利恆，到了父家，在那裏住了四個月。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 34:3; 創世記 50:21; 利未記 19:17"> 她丈夫起來，帶着一個僕人、兩匹驢去見她，用好話勸她回來。女子就引丈夫進入父家。她父見了那人，便歡歡喜喜地迎接。</span>
<span className="v" id="v4" data-v="4"> 那人的岳父，就是女子的父親，將那人留下住了三天。於是二人一同吃喝、住宿。</span>
<span className="v" id="v5" data-v="5" data-xref="士師記 19:8; 創世記 18:5; 詩篇 104:15"> 到第四天，利未人清早起來要走，女子的父親對女婿說：「請你吃點飯，加添心力，然後可以行路。」</span>
<span className="v" id="v6" data-v="6" data-xref="士師記 19:9; 士師記 16:25; 路得記 3:7"> 於是二人坐下一同吃喝。女子的父親對那人說：「請你再住一夜，暢快你的心。」</span>
<span className="v" id="v7" data-v="7"> 那人起來要走，他岳父強留他，他又住了一宿。</span>
<span className="v" id="v8" data-v="8"> 到第五天，他清早起來要走，女子的父親說：「請你吃點飯，加添心力，等到日頭偏西再走。」於是二人一同吃飯。</span>
<span className="v" id="v9" data-v="9" data-xref="箴言 27:1; 路加福音 24:29; 雅各書 4:13–14"> 那人同他的妾和僕人起來要走，他岳父，就是女子的父親，對他說：「看哪，日頭偏西了，請你再住一夜；天快晚了，可以在這裏住宿，暢快你的心。明天早早起行回家去。」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="約書亞記 15:63; 約書亞記 15:8; 士師記 1:8"> 那人不願再住一夜，就備上那兩匹驢，帶着妾起身走了，來到耶布斯的對面（耶布斯就是耶路撒冷。）</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳記下 5:6; 士師記 1:21; 士師記 19:10"> 臨近耶布斯的時候，日頭快要落了，僕人對主人說：「我們不如進這耶布斯人的城裏住宿。」</span>
<span className="v" id="v12" data-v="12"> 主人回答說：「我們不可進不是以色列人住的外邦城，不如過到基比亞去」；</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳記上 10:26; 何西阿書 5:8; 以賽亞書 10:29"> 又對僕人說：「我們可以到一個地方，或住在基比亞，或住在拉瑪。」</span>
<span className="v" id="v14" data-v="14"> 他們就往前走。將到便雅憫的基比亞，日頭已經落了；</span>
<span className="v" id="v15" data-v="15" data-xref="士師記 19:18; 馬太福音 25:35; 馬太福音 25:43"> 他們進入基比亞要在那裏住宿，就坐在城裏的街上，因為無人接他們進家住宿。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="士師記 19:1; 詩篇 104:23; 創世記 3:19"> 晚上，有一個老年人從田間做工回來。他原是以法蓮山地的人，住在基比亞；那地方的人卻是便雅憫人。</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 32:17; 創世記 16:8"> 老年人舉目看見客人坐在城裏的街上，就問他說：「你從哪裏來？要往哪裏去？」</span>
<span className="v" id="v18" data-v="18" data-xref="士師記 18:31; 約翰福音 15:6; 撒母耳記上 1:7"> 他回答說：「我們從猶大的伯利恆來，要往以法蓮山地那邊去。我原是那裏的人，到過猶大的伯利恆，現在我往耶和華的殿去，在這裏無人接我進他的家。</span>
<span className="v" id="v19" data-v="19"> 其實我有糧草可以餵驢，我與我的妾，並我的僕人，有餅有酒，並不缺少甚麼。」</span>
<span className="v" id="v20" data-v="20" data-xref="士師記 6:23; 雅各書 2:15–16; 希伯來書 13:2"> 老年人說：「願你平安！你所需用的我都給你，只是不可在街上過夜。」</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 43:24; 創世記 18:4; 路加福音 7:44"> 於是領他們到家裏，餵上驢，他們就洗腳吃喝。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="創世記 19:4–5; 哥林多前書 6:9; 士師記 20:5"> 他們心裏正歡暢的時候，城中的匪徒圍住房子，連連叩門，對房主老人說：「你把那進你家的人帶出來，我們要與他交合。」</span>
<span className="v" id="v23" data-v="23" data-xref="創世記 34:7; 撒母耳記下 13:12; 士師記 20:6"> 那房主出來對他們說：「弟兄們哪，不要這樣作惡；這人既然進了我的家，你們就不要行這醜事。</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 19:8; 申命記 21:14; 創世記 34:2"> 我有個女兒，還是處女，並有這人的妾，我將她們領出來任憑你們玷辱她們，只是向這人不可行這樣的醜事。」</span>
<span className="v" id="v25" data-v="25" data-xref="何西阿書 10:9; 何西阿書 9:9; 何西阿書 7:4–7"> 那些人卻不聽從他的話。那人就把他的妾拉出去交給他們，他們便與她交合，終夜凌辱她，直到天色快亮才放她去。</span>
<span className="v" id="v26" data-v="26" data-xref="士師記 19:3; 創世記 18:12; 彼得前書 3:6"> 天快亮的時候，婦人回到她主人住宿的房門前，就仆倒在地，直到天亮。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27"> 早晨，她的主人起來開了房門，出去要行路，不料那婦人仆倒在房門前，兩手搭在門檻上；</span>
<span className="v" id="v28" data-v="28" data-xref="士師記 20:5; 列王紀上 18:29"> 就對婦人說：「起來，我們走吧！」婦人卻不回答。那人便將她馱在驢上，起身回本處去了。</span>
<span className="v" id="v29" data-v="29" data-xref="士師記 20:6–7; 撒母耳記上 11:7; 羅馬書 10:2"> 到了家裏，用刀將妾的屍身切成十二塊，使人拿着傳送以色列的四境。</span>
<span className="v" id="v30" data-v="30" data-xref="士師記 20:7; 箴言 13:10; 何西阿書 9:9"> 凡看見的人都說：「從以色列人出埃及地，直到今日，這樣的事沒有行過，也沒有見過。現在應當思想，大家商議當怎樣辦理。」</span>
</div>

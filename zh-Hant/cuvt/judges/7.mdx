## 基甸擊敗米甸人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士師記 6:32; 傳道書 9:10; 創世記 12:6"> 耶路‧巴力就是基甸，他和一切跟隨的人早晨起來，在哈律泉旁安營。米甸營在他們北邊的平原，靠近摩利岡。</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 8:17; 哥林多前書 1:27–29; 哥林多後書 4:7"> 耶和華對基甸說：「跟隨你的人過多，我不能將米甸人交在他們手中，免得以色列人向我誇大，說：『是我們自己的手救了我們。』</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 20:8; 啟示錄 17:14; 啟示錄 21:8"> 現在你要向這些人宣告說：『凡懼怕膽怯的，可以離開基列山回去。』」於是有二萬二千人回去，只剩下一萬。</span>
<span className="v" id="v4" data-v="4" data-xref="詩篇 33:16; 撒母耳記上 16:7; 撒母耳記上 14:6"> 耶和華對基甸說：「人還是過多；你要帶他們下到水旁，我好在那裏為你試試他們。我指點誰說：『這人可以同你去』，他就可以同你去；我指點誰說：『這人不可同你去』，他就不可同你去。」</span>
<span className="v" id="v5" data-v="5"> 基甸就帶他們下到水旁。耶和華對基甸說：「凡用舌頭舔水，像狗舔的，要使他單站在一處；凡跪下喝水的，也要使他單站在一處。」</span>
<span className="v" id="v6" data-v="6"> 於是用手捧着舔水的有三百人，其餘的都跪下喝水。</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳記上 14:6; 以賽亞書 41:14–16; 士師記 7:18–22"> 耶和華對基甸說：「我要用這舔水的三百人拯救你們，將米甸人交在你手中；其餘的人都可以各歸各處去。」</span>
<span className="v" id="v8" data-v="8" data-xref="約書亞記 6:20; 民數記 10:9; 約書亞記 6:4"> 這三百人就帶着食物和角；其餘的以色列人，基甸都打發他們各歸各的帳棚，只留下這三百人。米甸營在他下邊的平原裏。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 46:2–3; 士師記 3:28; 使徒行傳 18:9–10"> 當那夜，耶和華吩咐基甸說：「起來，下到米甸營裏去，因我已將他們交在你手中。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及記 4:10–14; 士師記 4:8–9"> 倘若你怕下去，就帶你的僕人普拉下到那營裏去。</span>
<span className="v" id="v11" data-v="11" data-xref="以弗所書 6:10; 士師記 7:13–15; 以賽亞書 35:3–4"> 你必聽見他們所說的，然後你就有膽量下去攻營。」於是基甸帶着僕人普拉下到營旁。</span>
<span className="v" id="v12" data-v="12" data-xref="士師記 8:10; 士師記 6:5; 約書亞記 11:4"> 米甸人、亞瑪力人，和一切東方人都布散在平原，如同蝗蟲那樣多。他們的駱駝無數，多如海邊的沙。</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多前書 1:27; 以賽亞書 41:14–15; 士師記 4:9"> 基甸到了，就聽見一人將夢告訴同伴說：「我做了一夢，夢見一個大麥餅滾入米甸營中，到了帳幕，將帳幕撞倒，帳幕就翻轉傾覆了。」</span>
<span className="v" id="v14" data-v="14" data-xref="列王紀下 7:6–7; 約書亞記 2:9; 約書亞記 2:24"> 那同伴說：「這不是別的，乃是以色列人約阿施的兒子基甸的刀；上帝已將米甸和全軍都交在他的手中。」</span>
<span className="v" id="v15" data-v="15" data-xref="哥林多後書 10:4–6; 創世記 40:8; 歷代志下 20:18–19"> 基甸聽見這夢和夢的講解，就敬拜上帝，回到以色列營中，說：「起來吧！耶和華已將米甸的軍隊交在你們手中了。」</span>
<span className="v" id="v16" data-v="16" data-xref="哥林多後書 4:7"> 於是基甸將三百人分作三隊，把角和空瓶交在各人手裏（瓶內都藏着火把），</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多前書 11:1; 馬太福音 16:24; 希伯來書 13:7"> 吩咐他們說：「你們要看我行事：我到了營的旁邊怎樣行，你們也要怎樣行。</span>
<span className="v" id="v18" data-v="18" data-xref="歷代志下 20:15–17; 撒母耳記上 17:47"> 我和一切跟隨我的人吹角的時候，你們也要在營的四圍吹角，喊叫說：『耶和華和基甸的刀！』」</span>
<span className="v" id="v19" data-v="19" data-xref="詩篇 2:9; 出埃及記 14:24; 馬太福音 25:6"> 基甸和跟隨他的一百人，在三更之初才換更的時候，來到營旁，就吹角，打破手中的瓶。</span>
<span className="v" id="v20" data-v="20" data-xref="以賽亞書 27:13; 哥林多後書 4:7; 哥林多前書 15:52"> 三隊的人就都吹角，打破瓶子，左手拿着火把，右手拿着角，喊叫說：「耶和華和基甸的刀！」</span>
<span className="v" id="v21" data-v="21" data-xref="歷代志下 20:17; 箴言 28:1; 列王紀下 7:6–7"> 他們在營的四圍各站各的地方；全營的人都亂竄。三百人吶喊，使他們逃跑。</span>
<span className="v" id="v22" data-v="22" data-xref="列王紀上 4:12; 約書亞記 6:20; 約書亞記 6:4"> 三百人就吹角，耶和華使全營的人用刀互相擊殺，逃到西利拉的伯‧哈示他，直逃到靠近他巴的亞伯‧米何拉。</span>
<span className="v" id="v23" data-v="23" data-xref="士師記 6:35; 撒母耳記上 14:21–22"> 以色列人就從拿弗他利、亞設，和瑪拿西全地聚集來追趕米甸人。</span>
<span className="v" id="v24" data-v="24" data-xref="士師記 3:27–28; 腓立比書 1:27; 羅馬書 15:30"> 基甸打發人走遍以法蓮山地，說：「你們下來攻擊米甸人，爭先把守約旦河的渡口，直到伯‧巴拉。」於是以法蓮的眾人聚集，把守約旦河的渡口，直到伯‧巴拉，</span>
<span className="v" id="v25" data-v="25" data-xref="以賽亞書 10:26; 士師記 8:3–4; 詩篇 83:11–12"> 捉住了米甸人的兩個首領：一名俄立，一名西伊伯；將俄立殺在俄立磐石上，將西伊伯殺在西伊伯酒醡那裏；又追趕米甸人，將俄立和西伊伯的首級帶過約旦河，到基甸那裏。</span>

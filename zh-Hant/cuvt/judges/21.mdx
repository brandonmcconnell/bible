## 為便雅憫支派人找妻

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士師記 20:1; 馬可福音 6:23; 使徒行傳 23:12"> 以色列人在米斯巴曾起誓說：「我們都不將女兒給便雅憫人為妻。」</span>
<span className="v" id="v2" data-v="2" data-xref="士師記 20:26; 士師記 20:18; 撒母耳記上 30:4"> 以色列人來到伯特利，坐在上帝面前直到晚上，放聲痛哭，</span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 74:1; 約書亞記 7:7–9; 以賽亞書 63:17"> 說：「耶和華－以色列的上帝啊，為何以色列中有這樣缺了一支派的事呢？」</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳記下 24:25; 列王紀上 8:64; 詩篇 78:34–35"> 次日清早，百姓起來，在那裏築了一座壇，獻燔祭和平安祭。</span>
<span className="v" id="v5" data-v="5" data-xref="士師記 5:23; 士師記 21:18; 士師記 21:1"> 以色列人彼此問說：「以色列各支派中，誰沒有同會眾上到耶和華面前來呢？」先是以色列人起過大誓說，凡不上米斯巴到耶和華面前來的，必將他治死。</span>
<span className="v" id="v6" data-v="6" data-xref="士師記 21:15; 士師記 20:23; 路加福音 19:41–42"> 以色列人為他們的弟兄便雅憫後悔，說：「如今以色列中絕了一個支派了。</span>
<span className="v" id="v7" data-v="7" data-xref="士師記 21:1; 士師記 21:18; 撒母耳記上 14:28–29"> 我們既在耶和華面前起誓說，必不將我們的女兒給便雅憫人為妻，現在我們當怎樣辦理、使他們剩下的人有妻呢？」</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳記上 31:11–13; 撒母耳記上 11:1–3; 撒母耳記下 2:5–6"> 又彼此問說：「以色列支派中誰沒有上米斯巴到耶和華面前來呢？」他們就查出基列‧雅比沒有一人進營到會眾那裏；</span>
<span className="v" id="v9" data-v="9"> 因為百姓被數的時候，沒有一個基列‧雅比人在那裏。</span>
<span className="v" id="v10" data-v="10" data-xref="士師記 5:23; 士師記 21:5; 撒母耳記上 11:7"> 會眾就打發一萬二千大勇士，吩咐他們說：「你們去用刀將基列‧雅比人連婦女帶孩子都擊殺了。</span>
<span className="v" id="v11" data-v="11" data-xref="民數記 31:17–18; 申命記 2:34"> 所當行的就是這樣：要將一切男子和已嫁的女子盡行殺戮。」</span>
<span className="v" id="v12" data-v="12" data-xref="約書亞記 18:1; 耶利米書 7:12; 詩篇 78:60"> 他們在基列‧雅比人中，遇見了四百個未嫁的處女，就帶到迦南地的示羅營裏。</span>
<span className="v" id="v13" data-v="13" data-xref="士師記 20:47; 申命記 20:10; 以弗所書 2:17"> 全會眾打發人到臨門磐的便雅憫人那裏，向他們說和睦的話。</span>
<span className="v" id="v14" data-v="14" data-xref="士師記 21:12; 哥林多前書 7:2; 士師記 20:47"> 當時便雅憫人回來了，以色列人就把所存活基列‧雅比的女子給他們為妻，還是不夠。</span>
<span className="v" id="v15" data-v="15" data-xref="士師記 21:6; 歷代志上 15:13; 以賽亞書 58:12"> 百姓為便雅憫人後悔，因為耶和華使以色列人缺了一個支派<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是使以色列中有了破口">a</a></sup>。</span>
<span className="v" id="v16" data-v="16"> 會中的長老說：「便雅憫中的女子既然除滅了，我們當怎樣辦理、使那餘剩的人有妻呢？」</span>
<span className="v" id="v17" data-v="17" data-xref="民數記 26:55; 民數記 36:7"> 又說：「便雅憫逃脫的人當有地業，免得以色列中塗抹了一個支派。</span>
<span className="v" id="v18" data-v="18" data-xref="士師記 21:1; 士師記 11:35"> 只是我們不能將自己的女兒給他們為妻；因為以色列人曾起誓說，有將女兒給便雅憫人為妻的，必受咒詛。」</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 16:10; 申命記 16:1; 申命記 16:13"> 他們又說：「在利波拿以南，伯特利以北，在示劍大路以東的示羅，年年有耶和華的節期」；</span>
<span className="v" id="v20" data-v="20"> 就吩咐便雅憫人說：「你們去，在葡萄園中埋伏。</span>
<span className="v" id="v21" data-v="21" data-xref="士師記 11:34; 出埃及記 15:20; 傳道書 3:4"> 若看見示羅的女子出來跳舞，就從葡萄園出來，在示羅的女子中各搶一個為妻，回便雅憫地去。</span>
<span className="v" id="v22" data-v="22" data-xref="士師記 21:1; 士師記 21:18; 士師記 21:14"> 他們的父親或是弟兄若來與我們爭競，我們就說：『求你們看我們的情面，施恩給這些人，因我們在爭戰的時候沒有給他們留下女子為妻。這也不是你們將女子給他們的；若是你們給的，就算有罪。』」</span>
<span className="v" id="v23" data-v="23" data-xref="士師記 20:48"> 於是便雅憫人照樣而行，按着他們的數目從跳舞的女子中搶去為妻，就回自己的地業去，又重修城邑居住。</span>
<span className="v" id="v24" data-v="24"> 當時以色列人離開那裏，各歸本支派、本宗族、本地業去了。</span>
<span className="v" id="v25" data-v="25" data-xref="申命記 12:8; 士師記 17:6; 箴言 3:5"> 那時，以色列中沒有王，各人任意而行。</span>

<span className="v" id="v1" data-v="1" data-xref="創世記 38:17; 創世記 29:21; 路加福音 15:29"> 過了些日子，到割麥子的時候，參孫帶着一隻山羊羔去看他的妻，說：「我要進內室見我的妻。」他岳父不容他進去，</span>
<span className="v" id="v2" data-v="2" data-xref="士師記 14:20; 士師記 14:16; 創世記 38:14"> 說：「我估定你是極其恨她，因此我將她給了你的陪伴。她的妹子不是比她還美麗嗎？你可以娶來代替她吧！」</span>
<span className="v" id="v3" data-v="3" data-xref="士師記 14:15"> 參孫說：「這回我加害於非利士人不算有罪。」</span>
<span className="v" id="v4" data-v="4" data-xref="雅歌 2:15; 詩篇 63:10; 耶利米哀歌 5:18"> 於是參孫去捉了三百隻狐狸<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或譯：野狗">a</a></sup>，將狐狸尾巴一對一對地捆上，將火把捆在兩條尾巴中間，</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳記下 14:30; 出埃及記 22:6"> 點着火把，就放狐狸進入非利士人站着的禾稼，將堆集的禾捆和未割的禾稼，並橄欖園盡都燒了。</span>
<span className="v" id="v6" data-v="6" data-xref="士師記 14:15; 帖撒羅尼迦前書 4:6; 箴言 22:8"> 非利士人說：「這事是誰做的呢？」有人說：「是亭拿人的女婿參孫，因為他岳父將他的妻給了他的陪伴。」於是非利士人上去，用火燒了婦人和她的父親。</span>
<span className="v" id="v7" data-v="7" data-xref="士師記 14:4; 羅馬書 12:19; 士師記 14:19"> 參孫對非利士人說：「你們既然這樣行，我必向你們報仇才肯罷休。」</span>
<span className="v" id="v8" data-v="8" data-xref="以賽亞書 63:3; 以賽亞書 63:6; 以賽亞書 25:10"> 參孫就大大擊殺他們，連腿帶腰都砍斷了。他便下去，住在以坦磐的穴內。</span>

## 參孫擊敗非利士人

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="士師記 15:17; 士師記 15:19; 士師記 15:14"> 非利士人上去安營在猶大，布散在利希。</span>
<span className="v" id="v10" data-v="10"> 猶大人說：「你們為何上來攻擊我們呢？」他們說：「我們上來是要捆綁參孫；他向我們怎樣行，我們也要向他怎樣行。」</span>
<span className="v" id="v11" data-v="11" data-xref="士師記 13:1; 士師記 14:4; 申命記 28:47–48"> 於是有三千猶大人下到以坦磐的穴內，對參孫說：「非利士人轄制我們，你不知道嗎？你向我們行的是甚麼事呢？」他回答說：「他們向我怎樣行，我也要向他們怎樣行。」</span>
<span className="v" id="v12" data-v="12" data-xref="士師記 8:21; 使徒行傳 7:25; 列王紀上 2:25"> 猶大人對他說：「我們下來是要捆綁你，將你交在非利士人手中。」參孫說：「你們要向我起誓，應承你們自己不害死我。」</span>
<span className="v" id="v13" data-v="13"> 他們說：「我們斷不殺你，只要將你捆綁交在非利士人手中。」於是用兩條新繩捆綁參孫，將他從以坦磐帶上去。</span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="士師記 14:19; 士師記 3:10; 詩篇 118:11"> 參孫到了利希，非利士人都迎着喧嚷。耶和華的靈大大感動參孫，他臂上的繩就像火燒的麻一樣，他的綁繩都從他手上脫落下來。</span>
<span className="v" id="v15" data-v="15" data-xref="約書亞記 23:10; 利未記 26:8; 士師記 3:31"> 他見一塊未乾的驢腮骨，就伸手拾起來，用以擊殺一千人。</span>
<span className="v" id="v16" data-v="16"> 參孫說：<br /><span className="pl pl-1">我用驢腮骨殺人成堆，</span><br /><span className="pl pl-1">用驢腮骨殺了一千人。</span></span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17"> 說完這話，就把那腮骨從手裏拋出去了。那地便叫拉末‧利希。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="哥林多後書 12:7–8; 希伯來書 11:32; 士師記 8:4"> 參孫甚覺口渴，就求告耶和華說：「你既藉僕人的手施行這麼大的拯救，豈可任我渴死、落在未受割禮的人手中呢？」</span>
<span className="v" id="v19" data-v="19" data-xref="以賽亞書 44:3; 創世記 45:27; 詩篇 34:6"> 上帝就使利希的窪處裂開，有水從其中湧出來。參孫喝了，精神復原；因此那泉名叫隱‧哈歌利，那泉直到今日還在利希。</span>
<span className="v" id="v20" data-v="20" data-xref="士師記 13:1; 士師記 16:31; 士師記 13:5"> 當非利士人轄制以色列人的時候，參孫作以色列的士師二十年。</span>
</div>
</div>

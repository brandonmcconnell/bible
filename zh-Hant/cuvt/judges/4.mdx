## 底波拉和巴拉

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="耶利米書 5:3; 士師記 3:12; 士師記 3:7"> 以笏死後，以色列人又行耶和華眼中看為惡的事，</span>
<span className="v" id="v2" data-v="2" data-xref="約書亞記 11:1; 士師記 4:16; 士師記 4:13"> 耶和華就把他們付與在夏瑣作王的迦南王耶賓手中；他的將軍是西西拉，住在外邦人的夏羅設。</span>
<span className="v" id="v3" data-v="3" data-xref="士師記 1:19; 詩篇 106:42; 士師記 3:9"> 耶賓王有鐵車九百輛。他大大欺壓以色列人二十年，以色列人就呼求耶和華。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及記 15:20; 路加福音 2:36; 列王紀下 22:14"> 有一位女先知名叫底波拉，是拉比多的妻，當時作以色列的士師。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 18:19; 耶利米書 31:15; 出埃及記 18:26"> 她住在以法蓮山地拉瑪和伯特利中間，在底波拉的棕樹下。以色列人都上她那裏去聽判斷。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行傳 13:47; 士師記 8:18; 希伯來書 11:32"> 她打發人從拿弗他利的基低斯將亞比挪菴的兒子巴拉召了來，對他說：「耶和華－以色列的上帝吩咐你說：『你率領一萬拿弗他利和西布倫人上他泊山去。</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀上 18:40; 以西結書 38:10–16; 詩篇 83:9–10"> 我必使耶賓的將軍西西拉率領他的車輛和全軍往基順河，到你那裏去；我必將他交在你手中。』」</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及記 4:10–14; 馬太福音 14:30–31"> 巴拉說：「你若同我去，我就去；你若不同我去，我就不去。」</span>
<span className="v" id="v9" data-v="9" data-xref="士師記 2:14; 撒母耳記上 2:30; 士師記 4:17–22"> 底波拉說：「我必與你同去，只是你在所行的路上得不着榮耀，因為耶和華要將西西拉交在一個婦人手裏。」於是底波拉起來，與巴拉一同往基低斯去了。</span>
<span className="v" id="v10" data-v="10" data-xref="士師記 5:18; 士師記 5:15; 士師記 4:14"> 巴拉就招聚西布倫人和拿弗他利人到基低斯，跟他上去的有一萬人。底波拉也同他上去。</span>
<span className="v" id="v11" data-v="11" data-xref="士師記 1:16; 約書亞記 19:33; 民數記 10:29"> 摩西岳父<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或譯：內兄">a</a></sup>何巴的後裔，基尼人希百曾離開基尼族，到靠近基低斯、撒拿音的橡樹旁支搭帳棚。</span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 89:12; 耶利米書 46:18; 約書亞記 19:12"> 有人告訴西西拉說：「亞比挪菴的兒子巴拉已經上他泊山了。」</span>
<span className="v" id="v13" data-v="13" data-xref="士師記 4:2–3; 士師記 4:7"> 西西拉就聚集所有的鐵車九百輛和跟隨他的全軍，從外邦人的夏羅設出來，到了基順河。</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 9:3; 撒母耳記下 5:24; 以賽亞書 52:12"> 底波拉對巴拉說：「你起來，今日就是耶和華將西西拉交在你手的日子。耶和華豈不在你前頭行嗎？」於是巴拉下了他泊山，跟隨他有一萬人。</span>
<span className="v" id="v15" data-v="15" data-xref="約書亞記 10:10; 詩篇 83:9–10; 士師記 5:20–21"> 耶和華使西西拉和他一切車輛全軍潰亂，在巴拉面前被刀殺敗；西西拉下車步行逃跑。</span>
<span className="v" id="v16" data-v="16" data-xref="羅馬書 2:12; 利未記 26:7–8; 雅各書 2:13"> 巴拉追趕車輛、軍隊，直到外邦人的夏羅設。西西拉的全軍都倒在刀下，沒有留下一人。</span>
<span className="v" id="v17" data-v="17" data-xref="詩篇 69:22; 以賽亞書 57:21; 阿摩司書 5:19–20"> 只有西西拉步行逃跑，到了基尼人希百之妻雅億的帳棚，因為夏瑣王耶賓與基尼人希百家和好。</span>
<span className="v" id="v18" data-v="18" data-xref="列王紀下 6:19"> 雅億出來迎接西西拉，對他說：「請我主進來，不要懼怕」；西西拉就進了她的帳棚。雅億用被將他遮蓋。</span>
<span className="v" id="v19" data-v="19" data-xref="士師記 5:25–26; 創世記 24:43; 以賽亞書 41:17"> 西西拉對雅億說：「我渴了，求你給我一點水喝。」雅億就打開皮袋，給他奶子喝，仍舊把他遮蓋。</span>
<span className="v" id="v20" data-v="20" data-xref="約書亞記 2:3–5; 撒母耳記下 17:20"> 西西拉又對雅億說：「請你站在帳棚門口，若有人來問你說：『有人在這裏沒有？』你就說：『沒有。』」</span>
<span className="v" id="v21" data-v="21" data-xref="士師記 5:26–27; 哥林多前書 1:27; 士師記 3:21"> 西西拉疲乏沉睡。希百的妻雅億取了帳棚的橛子，手裏拿着錘子，輕悄悄地到他旁邊，將橛子從他鬢邊釘進去，釘入地裏。西西拉就死了。</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳記下 17:10–15; 撒母耳記下 17:3"> 巴拉追趕西西拉的時候，雅億出來迎接他說：「來吧，我將你所尋找的人給你看。」他就進入帳棚，看見西西拉已經死了，倒在地上，橛子還在他鬢中。</span>
<span className="v" id="v23" data-v="23" data-xref="尼希米記 9:24; 詩篇 18:47; 詩篇 18:39"> 這樣，上帝使迦南王耶賓被以色列人制伏了。</span>
<span className="v" id="v24" data-v="24" data-xref="撒母耳記上 3:12"> 從此以色列人的手越發有力，勝了迦南王耶賓，直到將他滅絕了。</span>

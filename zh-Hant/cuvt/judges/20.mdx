## 以色列人準備打仗

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士師記 11:11; 撒母耳記上 3:20; 撒母耳記上 10:17"> 於是以色列從但到別是巴，以及住基列地的眾人都出來，如同一人，聚集在米斯巴耶和華面前。</span>
<span className="v" id="v2" data-v="2" data-xref="士師記 8:10; 士師記 20:17; 士師記 20:15"> 以色列民的首領，就是各支派的軍長，都站在上帝百姓的會中；拿刀的步兵共有四十萬。</span>
<span className="v" id="v3" data-v="3" data-xref="士師記 19:22–27; 路加福音 14:31–32; 路加福音 12:58–59"> 以色列人上到米斯巴，便雅憫人都聽見了。以色列人說：「請你將這件惡事的情由對我們說明。」</span>
<span className="v" id="v4" data-v="4" data-xref="士師記 19:15–28"> 那利未人，就是被害之婦人的丈夫，回答說：「我和我的妾到了便雅憫的基比亞住宿。</span>
<span className="v" id="v5" data-v="5" data-xref="士師記 19:22; 士師記 19:25–26; 創世記 19:4–8"> 基比亞人夜間起來，圍了我住的房子，想要殺我，又將我的妾強姦致死。</span>
<span className="v" id="v6" data-v="6" data-xref="士師記 19:29; 約書亞記 7:15; 士師記 19:23"> 我就把我妾的屍身切成塊子，使人拿着傳送以色列得為業的全地，因為基比亞人在以色列中行了兇淫醜惡的事。</span>
<span className="v" id="v7" data-v="7" data-xref="士師記 19:30; 哥林多前書 5:6; 哥林多前書 5:10–12"> 你們以色列人都當籌劃商議。」</span>
<span className="v" id="v8" data-v="8" data-xref="傳道書 9:10; 士師記 20:1; 箴言 21:3"> 眾民都起來如同一人，說：「我們連一人都不回自己帳棚、自己房屋去。</span>
<span className="v" id="v9" data-v="9" data-xref="約拿書 1:7; 尼希米記 11:1; 約書亞記 14:2"> 我們向基比亞人必這樣行，照所掣的籤去攻擊他們。</span>
<span className="v" id="v10" data-v="10"> 我們要在以色列各支派中，一百人挑取十人，一千人挑取百人，一萬人挑取千人，為民運糧，等大眾到了便雅憫的基比亞，就照基比亞人在以色列中所行的醜事征伐他們。」</span>
<span className="v" id="v11" data-v="11"> 於是以色列眾人彼此連合如同一人，聚集攻擊那城。</span>
<span className="v" id="v12" data-v="12" data-xref="申命記 13:14; 申命記 20:10; 羅馬書 12:18"> 以色列眾支派打發人去，問便雅憫支派的各家說：「你們中間怎麼做了這樣的惡事呢？</span>
<span className="v" id="v13" data-v="13" data-xref="申命記 17:12; 申命記 13:13; 士師記 19:22"> 現在你們要將基比亞的那些匪徒交出來，我們好治死他們，從以色列中除掉這惡。」便雅憫人卻不肯聽從他們弟兄以色列人的話。</span>
<span className="v" id="v14" data-v="14" data-xref="民數記 20:20; 約伯記 15:25–26; 民數記 21:23"> 便雅憫人從他們的各城裏出來，聚集到了基比亞，要與以色列人打仗。</span>
<span className="v" id="v15" data-v="15" data-xref="民數記 26:41; 士師記 20:25; 民數記 1:37"> 那時便雅憫人從各城裏點出拿刀的，共有二萬六千；另外還有基比亞人點出七百精兵。</span>
<span className="v" id="v16" data-v="16" data-xref="士師記 3:15; 歷代志上 12:2; 撒母耳記上 17:49–50"> 在眾軍之中有揀選的七百精兵，都是左手便利的，能用機弦甩石打人，毫髮不差。</span>
<span className="v" id="v17" data-v="17" data-xref="民數記 1:46; 歷代志下 17:14–18; 民數記 26:51"> 便雅憫人之外，點出以色列人拿刀的，共有四十萬，都是戰士。</span>
</div>
</div>

## 攻打便雅憫人

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="士師記 20:23; 士師記 20:26–27; 民數記 27:21"> 以色列人就起來，到伯特利去求問上帝說：「我們中間誰當首先上去與便雅憫人爭戰呢？」耶和華說：「猶大當先上去。」</span>
<span className="v" id="v19" data-v="19" data-xref="約書亞記 7:16; 約書亞記 3:1; 約書亞記 6:12"> 以色列人早晨起來，對着基比亞安營。</span>
<span className="v" id="v20" data-v="20"> 以色列人出來，要與便雅憫人打仗，就在基比亞前擺陣。</span>
<span className="v" id="v21" data-v="21" data-xref="士師記 20:25; 詩篇 73:18–19; 歷代志下 28:10"> 便雅憫人就從基比亞出來，當日殺死以色列人二萬二千。</span>
<span className="v" id="v22" data-v="22" data-xref="詩篇 64:5; 士師記 20:17; 撒母耳記上 30:6"> 以色列人彼此奮勇，仍在頭一日擺陣的地方又擺陣。</span>
<span className="v" id="v23" data-v="23" data-xref="士師記 20:26–27; 詩篇 78:34–36; 約書亞記 7:6"> 未擺陣之先，以色列人上去，在耶和華面前哭號，直到晚上，求問耶和華說：「我們再去與我們弟兄便雅憫人打仗可以不可以？」耶和華說：「可以上去攻擊他們。」</span>
<span className="v" id="v24" data-v="24"> 第二日，以色列人就上前攻擊便雅憫人。</span>
<span className="v" id="v25" data-v="25" data-xref="士師記 20:21; 創世記 18:25; 羅馬書 2:5"> 便雅憫人也在這日從基比亞出來，與以色列人接戰，又殺死他們一萬八千，都是拿刀的。</span>
<span className="v" id="v26" data-v="26" data-xref="士師記 20:23; 約珥書 2:12–18; 士師記 20:18"> 以色列眾人就上到伯特利，坐在耶和華面前哭號，當日禁食直到晚上；又在耶和華面前獻燔祭和平安祭。</span>
<span className="v" id="v27" data-v="27" data-xref="約書亞記 18:1; 士師記 20:18; 撒母耳記上 4:3–4"> 那時，上帝的約櫃在那裏；亞倫的孫子、以利亞撒的兒子非尼哈侍立在約櫃前。以色列人問耶和華說：「我們當再出去與我們弟兄便雅憫人打仗呢？還是罷兵呢？」耶和華說：「你們當上去，因為明日我必將他們交在你們手中。」</span>
<span className="v" id="v29" data-v="29" data-xref="約書亞記 8:4; 撒母耳記下 5:23; 士師記 20:34"> 以色列人在基比亞的四圍設下伏兵。</span>
<span className="v" id="v30" data-v="30"> 第三日，以色列人又上去攻擊便雅憫人，在基比亞前擺陣，與前兩次一樣。</span>
<span className="v" id="v31" data-v="31" data-xref="士師記 19:13–14; 約書亞記 7:5; 以賽亞書 10:29"> 便雅憫人也出來迎敵，就被引誘離城；在田間兩條路上，一通伯特利，一通基比亞，像前兩次，動手殺死以色列人約有三十個。</span>
<span className="v" id="v32" data-v="32" data-xref="約書亞記 8:15–16"> 便雅憫人說：「他們仍舊敗在我們面前。」但以色列人說：「我們不如逃跑，引誘他們離開城到路上來。」</span>
<span className="v" id="v33" data-v="33" data-xref="約書亞記 8:18–22"> 以色列眾人都起來，在巴力‧他瑪擺陣，以色列的伏兵從馬利‧迦巴埋伏的地方衝上前去。</span>
<span className="v" id="v34" data-v="34" data-xref="約書亞記 8:14; 以賽亞書 47:11; 約伯記 21:13"> 有以色列人中的一萬精兵，來到基比亞前接戰，勢派甚是凶猛；便雅憫人卻不知道災禍臨近了。</span>
<span className="v" id="v35" data-v="35" data-xref="約伯記 20:5; 士師記 20:15; 士師記 20:44–46"> 耶和華使以色列人殺敗便雅憫人。那日，以色列人殺死便雅憫人二萬五千一百，都是拿刀的。</span>
</div>
</div>

## 以色列人得勝

<div className="bt">
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="約書亞記 8:15–29"> 於是便雅憫人知道自己敗了。先是以色列人；因為靠着在基比亞前所設的伏兵，就在便雅憫人面前詐敗。</span>
<span className="v" id="v37" data-v="37" data-xref="約書亞記 8:19; 約書亞記 6:5; 出埃及記 19:13"> 伏兵急忙闖進基比亞，用刀殺死全城的人。</span>
<span className="v" id="v38" data-v="38" data-xref="約書亞記 8:20; 創世記 17:21; 列王紀下 4:16"> 以色列人預先同伏兵約定在城內放火，以煙氣上騰為號。</span>
<span className="v" id="v39" data-v="39" data-xref="士師記 20:32"> 以色列人臨退陣的時候，便雅憫人動手殺死以色列人，約有三十個，就說：「他們仍像前次被我們殺敗了。」</span>
<span className="v" id="v40" data-v="40" data-xref="約書亞記 8:20; 啟示錄 19:3; 創世記 19:28"> 當煙氣如柱從城中上騰的時候，便雅憫人回頭觀看，見全城的煙氣沖天。</span>
<span className="v" id="v41" data-v="41" data-xref="彼得後書 2:12; 路加福音 21:26; 啟示錄 6:15–17"> 以色列人又轉身回來，便雅憫人就甚驚惶，因為看見災禍臨到自己了。</span>
<span className="v" id="v42" data-v="42" data-xref="約書亞記 8:15; 何西阿書 9:9; 耶利米哀歌 1:3"> 他們在以色列人面前轉身往曠野逃跑；以色列人在後面追殺。那從各城裏出來的，也都夾攻殺滅他們。</span>
<span className="v" id="v43" data-v="43" data-xref="約書亞記 8:20–22"> 以色列人圍繞便雅憫人，追趕他們，在他們歇腳之處、對着日出之地的基比亞踐踏他們。</span>
<span className="v" id="v44" data-v="44"> 便雅憫人死了的有一萬八千，都是勇士。</span>
<span className="v" id="v45" data-v="45" data-xref="約書亞記 15:32; 士師記 21:13; 撒迦利亞書 14:10"> 其餘的人轉身向曠野逃跑，往臨門磐去。以色列人在道路上殺了他們五千人，如拾取遺穗一樣，追到基頓又殺了他們二千人。</span>
<span className="v" id="v46" data-v="46" data-xref="士師記 20:35; 士師記 20:15"> 那日便雅憫死了的共有二萬五千人，都是拿刀的勇士。</span>
<span className="v" id="v47" data-v="47" data-xref="以賽亞書 1:9; 詩篇 103:9–10; 哈巴谷書 3:2"> 只剩下六百人，轉身向曠野逃跑，到了臨門磐，就在那裏住了四個月。</span>
<span className="v" id="v48" data-v="48" data-xref="申命記 13:15–17; 歷代志下 25:13; 歷代志下 28:6–9"> 以色列人又轉到便雅憫地，將各城的人和牲畜，並一切所遇見的，都用刀殺盡，又放火燒了一切城邑。</span>
</div>

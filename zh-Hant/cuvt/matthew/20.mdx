## 葡萄園的比喻

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="馬太福音 13:47; 馬太福音 13:24; 雅歌 8:11–12"> 「因為天國好像家主清早去雇人進他的葡萄園做工，</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳記上 2:26; 傳道書 12:1; 馬太福音 22:19"> 和工人講定一天一錢銀子，就打發他們進葡萄園去。</span>
<span className="v" id="v3" data-v="3" data-xref="提摩太前書 5:13; 使徒行傳 2:15; 馬太福音 20:6–7"> 約在巳初出去，看見市上還有閒站的人，</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多前書 6:11; 彼得前書 4:2–3; 路加福音 19:7–10"> 就對他們說：『你們也進葡萄園去，所當給的，我必給你們。』他們也進去了。</span>
<span className="v" id="v5" data-v="5" data-xref="希伯來書 11:24–26; 使徒行傳 10:3; 馬可福音 15:33–34"> 約在午正和申初又出去，也是這樣行。</span>
<span className="v" id="v6" data-v="6" data-xref="希伯來書 6:12; 約翰福音 9:4; 使徒行傳 17:21"> 約在酉初出去，看見還有人站在那裏，就問他們說：『你們為甚麼整天在這裏閒站呢？』</span>
<span className="v" id="v7" data-v="7" data-xref="以弗所書 2:11–12; 希伯來書 6:10; 約翰福音 9:4"> 他們說：『因為沒有人雇我們。』他說：『你們也進葡萄園去。』</span>
<span className="v" id="v8" data-v="8" data-xref="申命記 24:15; 彼得前書 4:10; 羅馬書 2:6–10"> 到了晚上，園主對管事的說：『叫工人都來，給他們工錢，從後來的起，到先來的為止。』</span>
<span className="v" id="v9" data-v="9" data-xref="馬太福音 20:6–7; 路加福音 23:40–43; 馬太福音 20:2"> 約在酉初雇的人來了，各人得了一錢銀子。</span>
<span className="v" id="v10" data-v="10"> 及至那先雇的來了，他們以為必要多得；誰知也是各得一錢。</span>
<span className="v" id="v11" data-v="11" data-xref="帖撒羅尼迦前書 2:16; 路加福音 19:7; 使徒行傳 22:21–22"> 他們得了，就埋怨家主說：</span>
<span className="v" id="v12" data-v="12" data-xref="羅馬書 11:5–6; 哥林多後書 11:23–28; 路加福音 12:55"> 『我們整天勞苦受熱，那後來的只做了一小時，你竟叫他們和我們一樣嗎？』</span>
<span className="v" id="v13" data-v="13" data-xref="馬太福音 26:50; 馬太福音 22:12; 羅馬書 9:14–15"> 家主回答其中的一人說：『朋友，我不虧負你，你與我講定的不是一錢銀子嗎？</span>
<span className="v" id="v14" data-v="14" data-xref="約翰福音 17:2; 路加福音 15:31; 馬太福音 6:6"> 拿你的走吧！我給那後來的和給你一樣，這是我願意的。</span>
<span className="v" id="v15" data-v="15" data-xref="羅馬書 9:15–24; 申命記 15:9; 約拿書 4:1–4"> 我的東西難道不可隨我的意思用嗎？因為我作好人，你就紅了眼嗎？』</span>
<span className="v" id="v16" data-v="16" data-xref="馬太福音 19:30; 馬可福音 10:31; 馬太福音 22:14"> 這樣，那在後的，將要在前；在前的，將要在後了。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古卷加：因為被召的人多，選上的人少。">a</a></sup>」</span>
</div>

## 耶穌第三次預言受難和復活

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="馬可福音 10:32–34; 路加福音 18:31–34; 馬太福音 16:13"> 耶穌上耶路撒冷去的時候，在路上把十二個門徒帶到一邊，對他們說：</span>
<span className="v" id="v18" data-v="18" data-xref="馬太福音 16:21; 使徒行傳 2:23; 馬太福音 27:1"> 「看哪，我們上耶路撒冷去，人子要被交給祭司長和文士。他們要定他死罪，</span>
<span className="v" id="v19" data-v="19" data-xref="馬太福音 16:21; 馬可福音 15:16–20; 馬太福音 27:27–31"> 又交給外邦人，將他戲弄，鞭打，釘在十字架上；第三日他要復活。」</span>
</div>
</div>

## 母親的請求

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="馬太福音 4:21; 馬可福音 10:35–45; 馬太福音 8:2"> 那時，西庇太兒子的母親同她兩個兒子上前來拜耶穌，求他一件事。</span>
<span className="v" id="v21" data-v="21" data-xref="馬太福音 19:28; 馬可福音 10:36–37; 以斯帖記 5:3"> 耶穌說：「你要甚麼呢？」她說：「願你叫我這兩個兒子在你國裏，一個坐在你右邊，一個坐在你左邊。」</span>
<span className="v" id="v22" data-v="22" data-xref="馬太福音 26:42; 路加福音 22:42; 馬太福音 26:39"> 耶穌回答說：「你們不知道所求的是甚麼；我將要喝的杯，你們能喝嗎？」他們說：「我們能。」</span>
<span className="v" id="v23" data-v="23" data-xref="啟示錄 1:9; 馬太福音 25:34; 使徒行傳 12:2"> 耶穌說：「我所喝的杯，你們必要喝；只是坐在我的左右，不是我可以賜的，乃是我父為誰預備的，就賜給誰。」</span>
<span className="v" id="v24" data-v="24" data-xref="彼得前書 5:5; 腓立比書 2:3; 馬可福音 10:41"> 那十個門徒聽見，就惱怒他們弟兄二人。</span>
<span className="v" id="v25" data-v="25" data-xref="路加福音 22:25–27; 馬太福音 20:25–28; 約翰福音 13:12–17"> 耶穌叫了他們來，說：「你們知道外邦人有君王為主治理他們，有大臣操權管束他們。</span>
<span className="v" id="v26" data-v="26" data-xref="馬可福音 10:43; 馬可福音 9:35; 馬可福音 10:45"> 只是在你們中間，不可這樣；你們中間誰願為大，就必作你們的用人；</span>
<span className="v" id="v27" data-v="27" data-xref="路加福音 22:26; 馬可福音 9:33–35; 馬太福音 18:4"> 誰願為首，就必作你們的僕人。</span>
<span className="v" id="v28" data-v="28" data-xref="路加福音 22:27; 希伯來書 9:28; 提多書 2:14"> 正如人子來，不是要受人的服事，乃是要服事人，並且要捨命，作多人的贖價。」</span>
</div>
</div>

## 治好兩個瞎子

<div className="bt">
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="馬可福音 10:46–52; 路加福音 18:35–43; 馬太福音 9:27–31"> 他們出耶利哥的時候，有極多的人跟隨他。</span>
<span className="v" id="v30" data-v="30" data-xref="馬可福音 10:46; 以賽亞書 42:16; 馬太福音 21:9"> 有兩個瞎子坐在路旁，聽說是耶穌經過，就喊着說：「主啊，大衛的子孫，可憐我們吧！」</span>
<span className="v" id="v31" data-v="31" data-xref="馬太福音 19:13; 歌羅西書 4:2; 馬太福音 7:7–8"> 眾人責備他們，不許他們作聲；他們卻越發喊着說：「主啊，大衛的子孫，可憐我們吧！」</span>
<span className="v" id="v32" data-v="32" data-xref="以西結書 36:37; 腓立比書 4:6; 馬太福音 20:21"> 耶穌就站住，叫他們來，說：「要我為你們做甚麼？」</span>
<span className="v" id="v33" data-v="33" data-xref="詩篇 119:18; 以弗所書 1:17–19"> 他們說：「主啊，要我們的眼睛能看見！」</span>
<span className="v" id="v34" data-v="34" data-xref="希伯來書 4:15–16; 馬太福音 9:29; 使徒行傳 26:18"> 耶穌就動了慈心，把他們的眼睛一摸，他們立刻看見，就跟從了耶穌。</span>
</div>

## 治好癱瘓病人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="馬太福音 4:13; 路加福音 8:37; 馬太福音 8:18"> 耶穌上了船，渡過海，來到自己的城裏。</span>
<span className="v" id="v2" data-v="2" data-xref="馬可福音 2:1–12; 路加福音 5:18–26; 耶利米書 31:33–34"> 有人用褥子抬着一個癱子到耶穌跟前來。耶穌見他們的信心，就對癱子說：「小子，放心吧！你的罪赦了。」</span>
<span className="v" id="v3" data-v="3" data-xref="馬太福音 26:65; 路加福音 5:21; 利未記 24:16"> 有幾個文士心裏說：「這個人說僭妄的話了。」</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 6:8; 馬太福音 12:25; 啟示錄 2:23"> 耶穌知道他們的心意，就說：「你們為甚麼心裏懷着惡念呢？</span>
<span className="v" id="v5" data-v="5" data-xref="約翰福音 5:8–14; 馬可福音 2:9–12; 使徒行傳 3:16"> 或說『你的罪赦了』，或說『你起來行走』，哪一樣容易呢？</span>
<span className="v" id="v6" data-v="6" data-xref="以賽亞書 43:25; 馬太福音 9:5; 約翰福音 20:21–23"> 但要叫你們知道，人子在地上有赦罪的權柄」；就對癱子說：「起來！拿你的褥子回家去吧。」</span>
<span className="v" id="v7" data-v="7"> 那人就起來，回家去了。</span>
<span className="v" id="v8" data-v="8" data-xref="路加福音 7:16; 馬太福音 15:31; 使徒行傳 4:21"> 眾人看見都驚奇，就歸榮耀與上帝，因為他將這樣的權柄賜給人。</span>
</div>
</div>

## 呼召馬太

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="路加福音 5:27–38; 馬可福音 2:14–22; 路加福音 19:2–10"> 耶穌從那裏往前走，看見一個人名叫馬太，坐在稅關上，就對他說：「你跟從我來。」他就起來跟從了耶穌。</span>
<span className="v" id="v10" data-v="10" data-xref="提摩太前書 1:13–16; 路加福音 5:29–32; 馬可福音 2:15–17"> 耶穌在屋裏坐席的時候，有好些稅吏和罪人來，與耶穌和他的門徒一同坐席。</span>
<span className="v" id="v11" data-v="11" data-xref="馬太福音 11:19; 路加福音 5:30; 馬可福音 2:16"> 法利賽人看見，就對耶穌的門徒說：「你們的先生為甚麼和稅吏並罪人一同吃飯呢？」</span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 5:31; 啟示錄 3:17–18; 馬可福音 2:17"> 耶穌聽見，就說：「康健的人用不着醫生，有病的人才用得着。</span>
<span className="v" id="v13" data-v="13" data-xref="馬可福音 2:17; 路加福音 19:10; 何西阿書 6:6"> 經上說：『我喜愛憐恤，不喜愛祭祀。』這句話的意思，你們且去揣摩。我來本不是召義人，乃是召罪人。」</span>
</div>
</div>

## 禁食的問題

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="路加福音 5:33–39; 馬可福音 2:18–22; 馬太福音 6:16"> 那時，約翰的門徒來見耶穌，說：「我們和法利賽人常常禁食，你的門徒倒不禁食，這是為甚麼呢？」</span>
<span className="v" id="v15" data-v="15" data-xref="啟示錄 19:9; 約翰福音 3:29; 啟示錄 21:2"> 耶穌對他們說：「新郎和陪伴之人同在的時候，陪伴之人豈能哀慟呢？但日子將到，新郎要離開他們，那時候他們就要禁食。</span>
<span className="v" id="v16" data-v="16" data-xref="哥林多前書 3:1–2; 約翰福音 16:12; 詩篇 125:3"> 沒有人把新布補在舊衣服上；因為所補上的反帶壞了那衣服，破的就更大了。</span>
<span className="v" id="v17" data-v="17" data-xref="約書亞記 9:4; 約伯記 32:19; 詩篇 119:83"> 也沒有人把新酒裝在舊皮袋裏；若是這樣，皮袋就裂開，酒漏出來，連皮袋也壞了。惟獨把新酒裝在新皮袋裏，兩樣就都保全了。」</span>
</div>
</div>

## 管會堂者的女兒和血漏的女人

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="路加福音 8:41–56; 馬可福音 5:22–43; 馬太福音 8:2"> 耶穌說這話的時候，有一個管會堂的來拜他，說：「我女兒剛才死了，求你去按手在她身上，她就必活了。」</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行傳 10:38; 加拉太書 6:9–10; 馬太福音 8:7"> 耶穌便起來跟着他去；門徒也跟了去。</span>
<span className="v" id="v20" data-v="20" data-xref="路加福音 8:43–56; 馬太福音 14:36; 馬可福音 6:56"> 有一個女人，患了十二年的血漏 ，來到耶穌背後，摸他的衣裳繸子；</span>
<span className="v" id="v21" data-v="21" data-xref="馬可福音 5:26–33; 路加福音 8:45–47; 使徒行傳 19:12"> 因為她心裏說：「我只摸他的衣裳，就必痊癒。」</span>
<span className="v" id="v22" data-v="22" data-xref="路加福音 7:50; 馬太福音 15:28; 馬太福音 9:2"> 耶穌轉過來，看見她，就說：「女兒，放心！你的信救了你。」從那時候，女人就痊癒了。</span>
<span className="v" id="v23" data-v="23" data-xref="歷代志下 35:25; 馬可福音 5:35–40; 路加福音 8:49–51"> 耶穌到了管會堂的家裏，看見有吹手，又有許多人亂嚷，</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行傳 20:10; 約翰福音 11:11–13; 馬太福音 27:39–43"> 就說：「退去吧！這閨女不是死了，是睡着了。」他們就嗤笑他。</span>
<span className="v" id="v25" data-v="25" data-xref="馬可福音 9:27; 馬可福音 5:41; 路加福音 8:54"> 眾人既被攆出，耶穌就進去，拉着閨女的手，閨女便起來了。</span>
<span className="v" id="v26" data-v="26" data-xref="馬太福音 4:24; 馬太福音 14:1–2; 馬可福音 1:45"> 於是這風聲傳遍了那地方。</span>
</div>
</div>

## 兩個瞎子得醫治

<div className="bt">
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="馬太福音 15:22; 馬太福音 20:30–31; 馬可福音 10:46–48"> 耶穌從那裏往前走，有兩個瞎子跟着他，喊叫說：「大衛的子孫，可憐我們吧！」</span>
<span className="v" id="v28" data-v="28" data-xref="馬可福音 9:23–24; 馬太福音 13:58; 馬太福音 8:2"> 耶穌進了房子，瞎子就來到他跟前。耶穌說：「你們信我能做這事嗎？」他們說：「主啊，我們信。」</span>
<span className="v" id="v29" data-v="29" data-xref="馬太福音 15:28; 馬可福音 10:52; 馬太福音 8:13"> 耶穌就摸他們的眼睛，說：「照着你們的信給你們成全了吧。」</span>
<span className="v" id="v30" data-v="30" data-xref="馬太福音 8:4; 路加福音 5:14; 馬太福音 17:9"> 他們的眼睛就開了。耶穌切切地囑咐他們說：「你們要小心，不可叫人知道。」</span>
<span className="v" id="v31" data-v="31" data-xref="馬可福音 7:36; 馬太福音 9:26; 馬可福音 1:44–45"> 他們出去，竟把他的名聲傳遍了那地方。</span>
</div>
</div>

## 治好啞巴

<div className="bt">
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="馬太福音 4:24; 馬太福音 12:22–24; 路加福音 11:14"> 他們出去的時候，有人將鬼所附的一個啞巴帶到耶穌跟前來。</span>
<span className="v" id="v33" data-v="33" data-xref="以賽亞書 35:6; 馬可福音 7:32–37; 出埃及記 4:11–12"> 鬼被趕出去，啞巴就說出話來。眾人都希奇，說：「在以色列中，從來沒有見過這樣的事。」</span>
<span className="v" id="v34" data-v="34" data-xref="路加福音 11:15; 馬可福音 3:22; 馬太福音 12:23–24"> 法利賽人卻說：「他是靠着鬼王趕鬼。」</span>
</div>
</div>

## 耶穌的憐憫

<div className="bt">
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="馬太福音 4:23–24; 使徒行傳 10:38; 馬可福音 6:56"> 耶穌走遍各城各鄉，在會堂裏教訓人，宣講天國的福音，又醫治各樣的病症。</span>
<span className="v" id="v36" data-v="36" data-xref="馬可福音 6:34; 民數記 27:17; 耶利米書 50:6"> 他看見許多的人，就憐憫他們；因為他們困苦流離，如同羊沒有牧人一般。</span>
<span className="v" id="v37" data-v="37" data-xref="路加福音 10:2; 馬可福音 16:15; 哥林多前書 3:9"> 於是對門徒說：「要收的莊稼多，做工的人少。</span>
<span className="v" id="v38" data-v="38" data-xref="路加福音 10:1–2; 耶利米書 3:15; 帖撒羅尼迦後書 3:1"> 所以，你們當求莊稼的主打發工人出去收他的莊稼。」</span>
</div>

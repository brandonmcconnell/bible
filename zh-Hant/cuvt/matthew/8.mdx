## 潔淨長大痲瘋的人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="馬太福音 8:18; 馬太福音 4:25–1; 路加福音 5:15"> 耶穌下了山，有許多人跟着他。</span>
<span className="v" id="v2" data-v="2" data-xref="馬太福音 15:25; 路加福音 17:12–19; 馬太福音 18:26"> 有一個長大痲瘋的來拜他，說：「主若肯，必能叫我潔淨了。」</span>
<span className="v" id="v3" data-v="3" data-xref="路加福音 5:13; 詩篇 33:9; 列王紀下 5:14"> 耶穌伸手摸他，說：「我肯，你潔淨了吧！」他的大痲瘋立刻就潔淨了。</span>
<span className="v" id="v4" data-v="4" data-xref="利未記 14:2–32; 路加福音 5:14; 路加福音 17:14"> 耶穌對他說：「你切不可告訴人，只要去把身體給祭司察看，獻上摩西所吩咐的禮物，對眾人作證據。」</span>
</div>
</div>

## 治好百夫長的僕人

<div className="bt">
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="路加福音 7:1–10; 使徒行傳 27:43; 使徒行傳 10:1–33"> 耶穌進了迦百農，有一個百夫長進前來，求他說：</span>
<span className="v" id="v6" data-v="6" data-xref="歌羅西書 4:1; 馬太福音 4:24; 使徒行傳 9:33"> 「主啊，我的僕人害癱瘓病，躺在家裏，甚是疼苦。」</span>
<span className="v" id="v7" data-v="7" data-xref="馬太福音 9:18–19; 路加福音 7:6; 馬可福音 5:23–24"> 耶穌說：「我去醫治他。」</span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 107:20; 路加福音 7:6–7; 詩篇 33:9"> 百夫長回答說：「主啊，你到我舍下，我不敢當；只要你說一句話，我的僕人就必好了。</span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 4:35–36; 提多書 2:9; 歌羅西書 3:22"> 因為我在人的權下，也有兵在我以下；對這個說『去！』他就去；對那個說『來！』他就來；對我的僕人說『你做這事！』他就去做。」</span>
<span className="v" id="v10" data-v="10" data-xref="馬太福音 15:28; 路加福音 7:9; 馬可福音 6:6"> 耶穌聽見就希奇，對跟從的人說：「我實在告訴你們，這麼大的信心，就是在以色列中，我也沒有遇見過。</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 13:28–29; 以弗所書 3:6; 加拉太書 3:28–29"> 我又告訴你們，從東從西，將有許多人來，在天國裏與亞伯拉罕、以撒、雅各一同坐席；</span>
<span className="v" id="v12" data-v="12" data-xref="馬太福音 25:30; 路加福音 13:28; 馬太福音 21:43"> 惟有本國的子民竟被趕到外邊黑暗裏去，在那裏必要哀哭切齒了。」</span>
<span className="v" id="v13" data-v="13" data-xref="馬太福音 9:29–30; 馬可福音 9:23; 約翰福音 4:50"> 耶穌對百夫長說：「你回去吧！照你的信心，給你成全了。」那時，他的僕人就好了。</span>
</div>
</div>

## 治好許多病人

<div className="bt">
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="路加福音 4:38–41; 馬可福音 1:29–34; 哥林多前書 9:5"> 耶穌到了彼得家裏，見彼得的岳母害熱病躺着。</span>
<span className="v" id="v15" data-v="15" data-xref="列王紀下 13:21; 路加福音 4:38–39; 路加福音 8:54"> 耶穌把她的手一摸，熱就退了；她就起來服事耶穌。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 15:26; 馬太福音 14:14; 馬可福音 1:32–34"> 到了晚上，有人帶着許多被鬼附的來到耶穌跟前，他只用一句話就把鬼都趕出去，並且治好了一切有病的人。</span>
<span className="v" id="v17" data-v="17" data-xref="以賽亞書 53:4; 彼得前書 2:24; 馬太福音 1:22"> 這是要應驗先知以賽亞的話，說：<br /><span className="pl pl-1">他代替我們的軟弱，</span><br /><span className="pl pl-1">擔當我們的疾病。</span></span>
</div>
</div>

## 要跟從耶穌的人

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="路加福音 4:42–43; 路加福音 8:22; 馬可福音 4:35"> 耶穌見許多人圍着他，就吩咐渡到那邊去。</span>
<span className="v" id="v19" data-v="19" data-xref="路加福音 22:33–34; 約翰福音 13:36–38; 路加福音 14:25–27"> 有一個文士來，對他說：「夫子，你無論往哪裏去，我要跟從你。」</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 84:3; 路加福音 2:7; 以賽亞書 53:2–3"> 耶穌說：「狐狸有洞，天空的飛鳥有窩，人子卻沒有枕頭的地方。」</span>
<span className="v" id="v21" data-v="21" data-xref="路加福音 9:59–62; 利未記 21:11–12; 民數記 6:6–7"> 又有一個門徒對耶穌說：「主啊，容我先回去埋葬我的父親。」</span>
<span className="v" id="v22" data-v="22" data-xref="歌羅西書 2:13; 路加福音 15:32; 以弗所書 5:14"> 耶穌說：「任憑死人埋葬他們的死人；你跟從我吧！」</span>
</div>
</div>

## 平靜風和海

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="路加福音 8:22–25; 馬可福音 4:36–41; 馬太福音 9:1"> 耶穌上了船，門徒跟着他。</span>
<span className="v" id="v24" data-v="24" data-xref="路加福音 8:23; 詩篇 107:23–27; 馬可福音 4:37–38"> 海裏忽然起了暴風，甚至船被波浪掩蓋；耶穌卻睡着了。</span>
<span className="v" id="v25" data-v="25" data-xref="約拿書 1:6; 歷代志下 14:11; 馬可福音 4:38–39"> 門徒來叫醒了他，說：「主啊，救我們，我們喪命啦！」</span>
<span className="v" id="v26" data-v="26" data-xref="以賽亞書 41:10–14; 詩篇 65:7; 詩篇 107:28–30"> 耶穌說：「你們這小信的人哪，為甚麼膽怯呢？」於是起來，斥責風和海，風和海就大大地平靜了。</span>
<span className="v" id="v27" data-v="27" data-xref="馬可福音 7:37; 馬可福音 6:51; 馬太福音 14:33"> 眾人希奇，說：「這是怎樣的人？連風和海也聽從他了！」</span>
</div>
</div>

## 治好加大拉被鬼附的人

<div className="bt">
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="路加福音 8:26–39; 馬可福音 5:1–20; 使徒行傳 10:38"> 耶穌既渡到那邊去，來到加大拉人的地方，就有兩個被鬼附的人從墳塋裏出來迎着他，極其凶猛，甚至沒有人能從那條路上經過。</span>
<span className="v" id="v29" data-v="29" data-xref="馬可福音 1:24; 路加福音 4:34; 雅各書 2:19"> 他們喊着說：「上帝的兒子，我們與你有甚麼相干？時候還沒有到，你就上這裏來叫我們受苦嗎？」</span>
<span className="v" id="v30" data-v="30" data-xref="申命記 14:8; 利未記 11:7; 馬可福音 5:11"> 離他們很遠，有一大群豬吃食。</span>
<span className="v" id="v31" data-v="31" data-xref="啟示錄 20:1–2; 路加福音 8:30–33; 馬可福音 5:12"> 鬼就央求耶穌，說：「若把我們趕出去，就打發我們進入豬群吧！」</span>
<span className="v" id="v32" data-v="32" data-xref="馬可福音 5:13; 使徒行傳 2:23; 啟示錄 20:7"> 耶穌說：「去吧！」鬼就出來，進入豬群。全群忽然闖下山崖，投在海裏淹死了。</span>
<span className="v" id="v33" data-v="33" data-xref="路加福音 8:34–36; 馬可福音 5:14–16; 使徒行傳 19:15–17"> 放豬的就逃跑進城，將這一切事和被鬼附的人所遭遇的都告訴人。</span>
<span className="v" id="v34" data-v="34" data-xref="使徒行傳 16:39; 路加福音 8:37–39; 路加福音 5:8"> 合城的人都出來迎見耶穌，既見了就央求他離開他們的境界。</span>
</div>
</div>

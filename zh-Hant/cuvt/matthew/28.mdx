## 耶穌復活

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="馬可福音 16:1–8; 約翰福音 20:1–10; 馬太福音 27:56"> 安息日將盡，七日的頭一日，天快亮的時候，抹大拉的馬利亞和那個馬利亞來看墳墓。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行傳 16:26; 約翰福音 20:12–13; 馬可福音 16:3–5"> 忽然，地大震動；因為有主的使者從天上下來，把石頭滾開，坐在上面。</span>
<span className="v" id="v3" data-v="3" data-xref="馬可福音 9:3; 使徒行傳 1:10; 馬可福音 16:5"> 他的相貌如同閃電，衣服潔白如雪。</span>
<span className="v" id="v4" data-v="4" data-xref="啟示錄 1:17; 但以理書 10:7; 馬太福音 27:65–66"> 看守的人就因他嚇得渾身亂戰，甚至和死人一樣。</span>
<span className="v" id="v5" data-v="5" data-xref="啟示錄 1:17–18; 希伯來書 1:14; 以賽亞書 41:10"> 天使對婦女說：「不要害怕！我知道你們是尋找那釘十字架的耶穌。</span>
<span className="v" id="v6" data-v="6" data-xref="馬可福音 16:6; 馬太福音 12:40; 路加福音 24:6–8"> 他不在這裏，照他所說的，已經復活了。你們來看安放主的地方。</span>
<span className="v" id="v7" data-v="7" data-xref="馬太福音 26:32; 路加福音 24:22–24; 馬太福音 28:10"> 快去告訴他的門徒，說他從死裏復活了，並且在你們以先往加利利去，在那裏你們要見他。看哪，我已經告訴你們了。」</span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 2:11; 馬可福音 16:8; 路加福音 24:36–41"> 婦女們就急忙離開墳墓，又害怕，又大大地歡喜，跑去要報給他的門徒。</span>
<span className="v" id="v9" data-v="9" data-xref="馬太福音 28:17; 約翰福音 20:14–17; 馬太福音 14:33"> 忽然，耶穌遇見她們，說：「願你們平安！」她們就上前抱住他的腳拜他。</span>
<span className="v" id="v10" data-v="10" data-xref="羅馬書 8:29; 約翰福音 20:17; 馬太福音 28:7"> 耶穌對她們說：「不要害怕！你們去告訴我的弟兄，叫他們往加利利去，在那裏必見我。」</span>
</div>
</div>

## 看守的兵報告祭司長

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="馬太福音 27:65–66; 馬太福音 28:4"> 她們去的時候，看守的兵有幾個進城去，將所經歷的事都報給祭司長。</span>
<span className="v" id="v12" data-v="12" data-xref="馬太福音 26:3–4; 使徒行傳 4:5–22; 馬太福音 27:1–2"> 祭司長和長老聚集商議，就拿許多銀錢給兵丁，說：</span>
<span className="v" id="v13" data-v="13" data-xref="馬太福音 26:64"> 「你們要這樣說：『夜間我們睡覺的時候，他的門徒來，把他偷去了。』</span>
<span className="v" id="v14" data-v="14" data-xref="馬太福音 27:2; 使徒行傳 12:19"> 倘若這話被巡撫聽見，有我們勸他，保你們無事。」</span>
<span className="v" id="v15" data-v="15" data-xref="提摩太前書 6:10; 馬太福音 27:8; 馬太福音 26:15"> 兵丁受了銀錢，就照所囑咐他們的去行。這話就傳說在猶太人中間，直到今日。</span>
</div>
</div>

## 門徒奉差遣

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="馬太福音 26:32; 馬太福音 28:10; 馬太福音 28:7"> 十一個門徒往加利利去，到了耶穌約定的山上。</span>
<span className="v" id="v17" data-v="17" data-xref="詩篇 45:11; 詩篇 2:12; 約翰福音 5:23"> 他們見了耶穌就拜他，然而還有人疑惑。</span>
<span className="v" id="v18" data-v="18" data-xref="約翰福音 3:35; 彼得前書 3:22; 馬太福音 11:27"> 耶穌進前來，對他們說：「天上地下所有的權柄都賜給我了。</span>
<span className="v" id="v19" data-v="19" data-xref="馬可福音 16:15–16; 使徒行傳 2:38–39; 使徒行傳 1:8"> 所以，你們要去，使萬民作我的門徒，奉父、子、聖靈的名給他們施洗<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或譯：給他們施洗，歸於父、子、聖靈的名">a</a></sup>。</span>
<span className="v" id="v20" data-v="20" data-xref="以賽亞書 41:10; 約書亞記 1:5; 使徒行傳 18:9–10"> 凡我所吩咐你們的，都教訓他們遵守，我就常與你們同在，直到世界的末了。」</span>
</div>

<div className="bp">

## 論禱告

<div className="bt">
<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="路加福音 18:10–11; 馬太福音 6:2; 路加福音 18:13"> 「你們禱告的時候，不可像那假冒為善的人，愛站在會堂裏和十字路口上禱告，故意叫人看見。我實在告訴你們，他們已經得了他們的賞賜。</span>
<span className="v" id="v6" data-v="6" data-xref="列王紀下 4:33; 馬太福音 14:23; 以賽亞書 65:24"> 你禱告的時候，要進你的內屋，關上門，禱告你在暗中的父；你父在暗中察看，必然報答你。</span>
<span className="v" id="v7" data-v="7" data-xref="傳道書 5:2–3; 傳道書 5:7; 列王紀上 18:26–29"> 你們禱告，不可像外邦人，用許多重複話，他們以為話多了必蒙垂聽。</span>
<span className="v" id="v8" data-v="8" data-xref="馬太福音 6:32; 路加福音 12:30; 腓立比書 4:6"> 你們不可效法他們；因為你們沒有祈求以先，你們所需用的，你們的父早已知道了。</span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 11:1–4; 啟示錄 4:11; 羅馬書 8:15"> 所以，你們禱告要這樣說：<br /><span className="pl pl-1">我們在天上的父：</span><br /><span className="pl pl-1">願人都尊你的名為聖。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="希伯來書 10:36; 馬太福音 26:42; 馬太福音 12:50"> <span className="pl pl-1">願你的國降臨；</span><br /><span className="pl pl-1">願你的旨意行在地上，</span><br /><span className="pl pl-1">如同行在天上。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="箴言 30:8; 路加福音 11:3; 馬太福音 4:4"> <span className="pl pl-1">我們日用的飲食，今日賜給我們。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="以弗所書 4:32; 馬可福音 11:25; 以弗所書 1:7"> <span className="pl pl-1">免我們的債，</span><br /><span className="pl pl-1">如同我們免了人的債。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="哥林多前書 10:13; 啟示錄 7:14–17; 馬太福音 26:41"> <span className="pl pl-1">不叫我們遇見試探；</span><br /><span className="pl pl-1">救我們脫離凶惡</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或譯：脫離惡者">b</a></sup><br /><span className="pl pl-1">。</span><br /><span className="pl pl-1">因為國度、權柄、榮耀，全是你的，</span><br /><span className="pl pl-1">直到永遠。阿們</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="有古卷沒有因為…阿們等字">c</a></sup><br /><span className="pl pl-1">！</span></span>
<span className="v" id="v14" data-v="14" data-xref="以弗所書 4:32; 馬可福音 11:25; 歌羅西書 3:13"> 「你們饒恕人的過犯，你們的天父也必饒恕你們的過犯；</span>
<span className="v" id="v15" data-v="15" data-xref="馬太福音 18:35"> 你們不饒恕人的過犯，你們的天父也必不饒恕你們的過犯。」</span>
</div>

<div className="bp">

## 不要憂慮

<div className="bt">
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="腓立比書 4:6; 彼得前書 5:7; 羅馬書 8:32"> 「所以我告訴你們，不要為生命憂慮吃甚麼，喝甚麼；為身體憂慮穿甚麼。生命不勝於飲食嗎？身體不勝於衣裳嗎？</span>
<span className="v" id="v26" data-v="26" data-xref="馬太福音 10:29–31; 詩篇 147:9; 路加福音 12:24–32"> 你們看那天上的飛鳥，也不種，也不收，也不積蓄在倉裏，你們的天父尚且養活牠。你們不比飛鳥貴重得多嗎？</span>
<span className="v" id="v27" data-v="27" data-xref="路加福音 12:25–26; 傳道書 3:14; 詩篇 39:5–6"> 你們哪一個能用思慮使壽數多加一刻呢<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="或譯：使身量多加一肘呢">e</a></sup>？</span>
<span className="v" id="v28" data-v="28" data-xref="馬太福音 6:25; 腓立比書 4:6; 路加福音 12:27"> 何必為衣裳憂慮呢？你想野地裏的百合花怎麼長起來；它也不勞苦，也不紡線。</span>
<span className="v" id="v29" data-v="29" data-xref="歷代志下 9:20–22; 歷代志下 9:4–6; 彼得前書 3:2–5"> 然而我告訴你們，就是所羅門極榮華的時候，他所穿戴的，還不如這花一朵呢！</span>
<span className="v" id="v30" data-v="30" data-xref="馬太福音 14:31; 路加福音 12:28; 彼得前書 1:24"> 你們這小信的人哪！野地裏的草今天還在，明天就丟在爐裏，上帝還給它這樣的妝飾，何況你們呢！</span>
<span className="v" id="v31" data-v="31" data-xref="彼得前書 5:7; 路加福音 12:29; 馬太福音 4:4"> 所以，不要憂慮說，吃甚麼？喝甚麼？穿甚麼？</span>
<span className="v" id="v32" data-v="32" data-xref="馬太福音 6:8; 路加福音 12:30; 以弗所書 4:17"> 這都是外邦人所求的。你們需用的這一切東西，你們的天父是知道的。</span>
<span className="v" id="v33" data-v="33" data-xref="路加福音 12:31; 馬太福音 5:6; 約翰福音 6:27"> 你們要先求他的國和他的義，這些東西都要加給你們了。</span>
<span className="v" id="v34" data-v="34" data-xref="馬太福音 6:25; 約翰福音 14:27; 希伯來書 13:5–6"> 所以，不要為明天憂慮，因為明天自有明天的憂慮；一天的難處一天當就夠了。」</span>
</div>

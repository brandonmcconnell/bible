## 光榮地進耶路撒冷

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="撒迦利亞書 14:4; 馬可福音 11:1–10; 路加福音 21:37"> 耶穌和門徒將近耶路撒冷，到了伯法其，在橄欖山那裏。</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 19:30–32; 馬可福音 11:2–3; 約翰福音 2:5–8"> 耶穌就打發兩個門徒，對他們說：「你們往對面村子裏去，必看見一匹驢拴在那裏，還有驢駒同在一處；你們解開，牽到我這裏來。</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多後書 8:1–2; 使徒行傳 17:25; 哥林多後書 8:9"> 若有人對你們說甚麼，你們就說：『主要用牠。』那人必立時讓你們牽來。</span>
<span className="v" id="v4" data-v="4" data-xref="撒迦利亞書 9:9; 約翰福音 12:15; 馬太福音 1:22"> 這事成就是要應驗先知的話，說：</span>
<span className="v" id="v5" data-v="5" data-xref="撒迦利亞書 9:9–10; 以賽亞書 62:11; 以賽亞書 12:6"> 要對錫安的居民<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是女子">a</a></sup>說：<br /><span className="pl pl-1">看哪，你的王來到你這裏，</span><br /><span className="pl pl-1">是溫柔的，又騎着驢，</span><br /><span className="pl pl-1">就是騎着驢駒子。」</span></span>
<span className="v" id="v6" data-v="6" data-xref="出埃及記 39:43; 約翰福音 15:14; 出埃及記 40:16"> 門徒就照耶穌所吩咐的去行，</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀下 9:13; 馬可福音 11:4–8; 路加福音 19:32–35"> 牽了驢和驢駒來，把自己的衣服搭在上面，耶穌就騎上。</span>
<span className="v" id="v8" data-v="8" data-xref="列王紀下 9:13; 約翰福音 12:13; 利未記 23:40"> 眾人多半把衣服鋪在路上；還有人砍下樹枝來鋪在路上。</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 118:24–26; 路加福音 2:14; 約翰福音 12:13–15"> 前行後隨的眾人喊着說：<br /><span className="pl pl-1">和散那</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原有求救的意思，在此是稱頌的話">b</a></sup><br /><span className="pl pl-1">歸於大衛的子孫！</span><br /><span className="pl pl-1">奉主名來的是應當稱頌的！</span><br /><span className="pl pl-1">高高在上和散那！</span></span>
<span className="v" id="v10" data-v="10" data-xref="使徒行傳 9:5; 路得記 1:19; 約翰福音 12:16–19"> 耶穌既進了耶路撒冷，合城都驚動了，說：「這是誰？」</span>
<span className="v" id="v11" data-v="11" data-xref="約翰福音 6:14; 路加福音 7:16; 約翰福音 7:40"> 眾人說：「這是加利利拿撒勒的先知耶穌。」</span>
</div>
</div>

## 潔淨聖殿

<div className="bt">
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="約翰福音 2:14–17; 路加福音 19:45–47; 馬可福音 11:15–18"> 耶穌進了上帝的殿，趕出殿裏一切做買賣的人，推倒兌換銀錢之人的桌子，和賣鴿子之人的凳子，</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米書 7:11; 以賽亞書 56:7; 路加福音 19:46"> 對他們說：「經上記着說：<br /><span className="pl pl-1">我的殿必稱為禱告的殿，</span><br /><span className="pl pl-1">你們倒使它成為賊窩了。」</span></span>
<span className="v" id="v14" data-v="14" data-xref="使徒行傳 3:1–9; 使徒行傳 10:38; 馬太福音 11:4–5"> 在殿裏有瞎子、瘸子到耶穌跟前，他就治好了他們。</span>
<span className="v" id="v15" data-v="15" data-xref="馬太福音 21:9; 路加福音 19:39–40; 以賽亞書 26:11"> 祭司長和文士看見耶穌所行的奇事，又見小孩子在殿裏喊着說：「和散那歸於大衛的子孫！」就甚惱怒，</span>
<span className="v" id="v16" data-v="16" data-xref="詩篇 8:2; 馬太福音 11:25; 路加福音 19:39–40"> 對他說：「這些人所說的，你聽見了嗎？」耶穌說：「是的。經上說『你從嬰孩和吃奶的口中完全了讚美』的話，你們沒有念過嗎？」</span>
<span className="v" id="v17" data-v="17" data-xref="約翰福音 11:18; 馬可福音 11:11; 路加福音 24:50"> 於是離開他們，出城到伯大尼去，在那裏住宿。</span>
</div>
</div>

## 咒詛無花果樹

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="馬太福音 4:2; 希伯來書 4:15; 馬太福音 12:1"> 早晨回城的時候，他餓了，</span>
<span className="v" id="v19" data-v="19" data-xref="約翰福音 15:6; 馬可福音 11:14; 提多書 1:16"> 看見路旁有一棵無花果樹，就走到跟前，在樹上找不着甚麼，不過有葉子，就對樹說：「從今以後，你永不結果子。」那無花果樹就立刻枯乾了。</span>
<span className="v" id="v20" data-v="20" data-xref="以賽亞書 40:6–8; 馬可福音 11:20–21; 雅各書 1:10–11"> 門徒看見了，便希奇說：「無花果樹怎麼立刻枯乾了呢？」</span>
<span className="v" id="v21" data-v="21" data-xref="雅各書 1:6; 馬太福音 17:20; 馬可福音 11:22–23"> 耶穌回答說：「我實在告訴你們，你們若有信心，不疑惑，不但能行無花果樹上所行的事，就是對這座山說：『你挪開此地，投在海裏！』也必成就。</span>
<span className="v" id="v22" data-v="22" data-xref="馬太福音 7:7; 約翰一書 5:14–15; 馬可福音 11:24"> 你們禱告，無論求甚麼，只要信，就必得着。」</span>
</div>
</div>

## 質問耶穌的權柄

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="使徒行傳 4:7; 馬可福音 11:27–33; 歷代志上 24:1–19"> 耶穌進了殿，正教訓人的時候，祭司長和民間的長老來問他說：「你仗着甚麼權柄做這些事？給你這權柄的是誰呢？」</span>
<span className="v" id="v24" data-v="24" data-xref="路加福音 6:9; 歌羅西書 4:6; 馬太福音 10:16"> 耶穌回答說：「我也要問你們一句話，你們若告訴我，我就告訴你們我仗着甚麼權柄做這些事。</span>
<span className="v" id="v25" data-v="25" data-xref="約翰一書 3:20; 馬可福音 1:1–11; 約翰福音 3:18"> 約翰的洗禮是從哪裏來的？是從天上來的？是從人間來的呢？」他們彼此商議說：「我們若說『從天上來』，他必對我們說：『這樣，你們為甚麼不信他呢？』</span>
<span className="v" id="v26" data-v="26" data-xref="馬可福音 6:20; 馬太福音 14:5; 約翰福音 5:35"> 若說『從人間來』，我們又怕百姓，因為他們都以約翰為先知。」</span>
<span className="v" id="v27" data-v="27" data-xref="羅馬書 1:18–22; 帖撒羅尼迦後書 2:9–10; 路加福音 20:7–8"> 於是回答耶穌說：「我們不知道。」耶穌說：「我也不告訴你們我仗着甚麼權柄做這些事。」</span>
</div>
</div>

## 兩個兒子的比喻

<div className="bt">
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="哥林多前書 15:58; 馬太福音 20:1; 哥林多前書 10:15"> 又說：「一個人有兩個兒子。他來對大兒子說：『我兒，你今天到葡萄園裏去做工。』</span>
<span className="v" id="v29" data-v="29" data-xref="以西結書 18:28–32; 馬太福音 3:2–8; 以賽亞書 55:6–7"> 他回答說：『我不去』，以後自己懊悔，就去了。</span>
<span className="v" id="v30" data-v="30" data-xref="提多書 1:16; 以西結書 33:31; 馬太福音 23:3"> 又來對小兒子也是這樣說。他回答說：『父啊，我去』，他卻不去。</span>
<span className="v" id="v31" data-v="31" data-xref="路加福音 7:29; 路加福音 7:37–50; 馬太福音 7:21"> 你們想，這兩個兒子是哪一個遵行父命呢？」他們說：「大兒子。」耶穌說：「我實在告訴你們，稅吏和娼妓倒比你們先進上帝的國。</span>
<span className="v" id="v32" data-v="32" data-xref="路加福音 7:37–50; 撒迦利亞書 7:11–12; 路加福音 7:29–30"> 因為約翰遵着義路到你們這裏來，你們卻不信他；稅吏和娼妓倒信他。你們看見了，後來還是不懊悔去信他。」</span>
</div>
</div>

## 凶惡園戶的比喻

<div className="bt">
<div className="bp poetry">
<span className="v" id="v33" data-v="33" data-xref="以賽亞書 5:1–4; 馬可福音 12:1–12; 路加福音 20:9–19"> 「你們再聽一個比喻：有個家主栽了一個葡萄園，周圍圈上籬笆，裏面挖了一個壓酒池，蓋了一座樓，租給園戶，就往外國去了。</span>
<span className="v" id="v34" data-v="34" data-xref="路加福音 20:10–19; 以賽亞書 5:4; 撒迦利亞書 1:3–6"> 收果子的時候近了，就打發僕人到園戶那裏去收果子。</span>
<span className="v" id="v35" data-v="35" data-xref="歷代志下 36:15–16; 馬太福音 5:12; 希伯來書 11:36–37"> 園戶拿住僕人，打了一個，殺了一個，用石頭打死一個。</span>
<span className="v" id="v36" data-v="36" data-xref="馬太福音 22:4"> 主人又打發別的僕人去，比先前更多；園戶還是照樣待他們。</span>
<span className="v" id="v37" data-v="37" data-xref="約翰福音 3:16; 約翰福音 3:35–36; 西番雅書 3:7"> 後來打發他的兒子到他們那裏去，意思說：『他們必尊敬我的兒子。』</span>
<span className="v" id="v38" data-v="38" data-xref="路加福音 20:14; 創世記 37:18–20; 馬可福音 12:7–8"> 不料，園戶看見他兒子，就彼此說：『這是承受產業的。來吧，我們殺他，佔他的產業！』</span>
<span className="v" id="v39" data-v="39" data-xref="使徒行傳 2:23; 雅各書 5:6; 路加福音 22:52–54"> 他們就拿住他，推出葡萄園外，殺了。</span>
<span className="v" id="v40" data-v="40" data-xref="希伯來書 10:29; 馬可福音 12:9; 路加福音 20:15–16"> 園主來的時候要怎樣處治這些園戶呢？」</span>
<span className="v" id="v41" data-v="41" data-xref="使徒行傳 18:6; 馬太福音 21:43; 使徒行傳 28:28"> 他們說：「要下毒手除滅那些惡人，將葡萄園另租給那按着時候交果子的園戶。」</span>
<span className="v" id="v42" data-v="42" data-xref="詩篇 118:22–23; 以賽亞書 28:16; 使徒行傳 4:11"> 耶穌說：「經上寫着：<br /><span className="pl pl-1">匠人所棄的石頭</span><br /><span className="pl pl-1">已作了房角的頭塊石頭。</span><br /><span className="pl pl-1">這是主所做的，</span><br /><span className="pl pl-1">在我們眼中看為希奇。</span>這經你們沒有念過嗎？</span>
<span className="v" id="v43" data-v="43" data-xref="馬太福音 21:41; 馬太福音 8:11–12; 彼得前書 2:9"> 所以我告訴你們，上帝的國必從你們奪去，賜給那能結果子的百姓。</span>
<span className="v" id="v44" data-v="44" data-xref="以賽亞書 8:14–15; 彼得前書 2:8; 但以理書 2:34–35"> 誰掉在這石頭上，必要跌碎；這石頭掉在誰的身上，就要把誰砸得稀爛。」</span>
<span className="v" id="v45" data-v="45" data-xref="路加福音 20:19; 路加福音 11:45; 馬太福音 12:12"> 祭司長和法利賽人聽見他的比喻，就看出他是指着他們說的。</span>
<span className="v" id="v46" data-v="46" data-xref="馬太福音 21:11; 馬太福音 21:26; 路加福音 7:16"> 他們想要捉拿他，只是怕眾人，因為眾人以他為先知。</span>
</div>

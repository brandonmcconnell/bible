## 十二使徒

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 9:1–6; 馬可福音 3:13–15; 馬可福音 6:7–13"> 耶穌叫了十二個門徒來，給他們權柄，能趕逐污鬼，並醫治各樣的病症。</span>
<span className="v" id="v2" data-v="2" data-xref="馬太福音 4:21; 使徒行傳 1:13; 路加福音 5:10"> 這十二使徒的名：頭一個叫西門（又稱彼得），還有他兄弟安得烈，西庇太的兒子雅各和雅各的兄弟約翰，</span>
<span className="v" id="v3" data-v="3" data-xref="馬可福音 3:18; 使徒行傳 1:13; 馬可福音 2:14"> 腓力和巴多羅買，多馬和稅吏馬太，亞勒腓的兒子雅各，和達太，</span>
<span className="v" id="v4" data-v="4" data-xref="馬太福音 26:14; 馬太福音 26:47; 約翰福音 13:2"> 奮銳黨的西門，還有賣耶穌的加略人猶大。</span>
</div>
</div>

## 十二使徒的使命

<div className="bt">
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="約翰福音 4:9; 使徒行傳 22:21–23; 列王紀下 17:24–41"> 耶穌差這十二個人去，吩咐他們說：「外邦人的路，你們不要走；撒馬利亞人的城，你們不要進；</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米書 50:6; 以西結書 34:6; 以賽亞書 53:6"> 寧可往以色列家迷失的羊那裏去。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行傳 28:31; 馬太福音 3:2; 路加福音 9:60"> 隨走隨傳，說『天國近了！』</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行傳 3:6; 路加福音 10:9; 使徒行傳 4:30"> 醫治病人，叫死人復活，叫長大痲瘋的潔淨，把鬼趕出去。你們白白地得來，也要白白地捨去。</span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 22:35; 路加福音 9:3–5; 路加福音 10:4–12"> 腰袋裏不要帶金銀銅錢；</span>
<span className="v" id="v10" data-v="10" data-xref="路加福音 10:7–12; 提摩太前書 5:17–18; 哥林多前書 9:4–14"> 行路不要帶口袋；不要帶兩件褂子，也不要帶鞋和柺杖。因為工人得飲食是應當的。</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 10:7–8; 約伯記 31:32; 士師記 19:16–21"> 你們無論進哪一城，哪一村，要打聽那裏誰是好人，就住在他家，直住到走的時候。</span>
<span className="v" id="v12" data-v="12" data-xref="撒母耳記上 25:6; 路加福音 10:5–6; 使徒行傳 10:36"> 進他家裏去，要請他的安。</span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 10:6; 詩篇 35:13; 哥林多後書 2:16"> 那家若配得平安，你們所求的平安就必臨到那家；若不配得，你們所求的平安仍歸你們。</span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 10:10–11; 使徒行傳 18:6; 尼希米記 5:13"> 凡不接待你們、不聽你們話的人，你們離開那家，或是那城的時候，就把腳上的塵土跺下去。</span>
<span className="v" id="v15" data-v="15" data-xref="彼得後書 2:6; 約翰一書 4:17; 約翰福音 15:22–24"> 我實在告訴你們，當審判的日子，所多瑪和蛾摩拉所受的，比那城還容易受呢！」</span>
</div>
</div>

## 將來的逼迫

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="路加福音 10:3; 腓立比書 2:15; 哥林多前書 14:20"> 「我差你們去，如同羊進入狼群；所以你們要靈巧像蛇，馴良像鴿子。</span>
<span className="v" id="v17" data-v="17" data-xref="馬可福音 13:9; 馬太福音 23:34; 使徒行傳 26:11"> 你們要防備人；因為他們要把你們交給公會 ，也要在會堂裏鞭打你們，</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行傳 5:25–27; 馬太福音 8:4; 詩篇 2:1–6"> 並且你們要為我的緣故被送到諸侯君王面前，對他們和外邦人作見證。</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及記 4:12; 馬可福音 13:11–13; 提摩太後書 4:17"> 你們被交的時候，不要思慮怎樣說話，或說甚麼話。到那時候，必賜給你們當說的話；</span>
<span className="v" id="v20" data-v="20" data-xref="路加福音 21:15; 使徒行傳 6:10; 路加福音 12:12"> 因為不是你們自己說的，乃是你們父的靈在你們裏頭說的。</span>
<span className="v" id="v21" data-v="21" data-xref="路加福音 21:16–17; 彌迦書 7:5–6; 馬可福音 13:12–13"> 弟兄要把弟兄，父親要把兒子，送到死地；兒女要與父母為敵，害死他們；</span>
<span className="v" id="v22" data-v="22" data-xref="馬太福音 24:13; 雅各書 1:12; 啟示錄 2:10"> 並且你們要為我的名被眾人恨惡。惟有忍耐到底的必然得救。</span>
<span className="v" id="v23" data-v="23" data-xref="馬太福音 16:28; 使徒行傳 8:1; 馬可福音 13:26"> 有人在這城裏逼迫你們，就逃到那城裏去。我實在告訴你們，以色列的城邑，你們還沒有走遍，人子就到了。</span>
<span className="v" id="v24" data-v="24" data-xref="約翰福音 15:20; 路加福音 6:40; 約翰福音 13:16"> 學生不能高過先生；僕人不能高過主人。</span>
<span className="v" id="v25" data-v="25" data-xref="路加福音 11:15; 馬太福音 12:24; 馬太福音 9:34"> 學生和先生一樣，僕人和主人一樣，也就罷了。人既罵家主是別西卜<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="別西卜：是鬼王的名">a</a></sup>，何況他的家人呢？」</span>
</div>
</div>

## 該怕的是誰

<div className="bt">
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="路加福音 8:17; 馬可福音 4:22; 耶利米書 1:8"> 「所以，不要怕他們；因為掩蓋的事沒有不露出來的，隱藏的事沒有不被人知道的。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行傳 5:20; 約翰福音 16:13; 約翰福音 16:1"> 我在暗中告訴你們的，你們要在明處說出來；你們耳中所聽的，要在房上宣揚出來。</span>
<span className="v" id="v28" data-v="28" data-xref="路加福音 12:4–5; 以賽亞書 8:12–13; 啟示錄 2:10"> 那殺身體、不能殺靈魂的，不要怕他們；惟有能把身體和靈魂都滅在地獄裏的，正要怕他。</span>
<span className="v" id="v29" data-v="29" data-xref="路加福音 12:6–7; 詩篇 104:27–30"> 兩個麻雀不是賣一分銀子嗎？若是你們的父不許，一個也不能掉在地上；</span>
<span className="v" id="v30" data-v="30" data-xref="路加福音 12:7; 撒母耳記上 14:45; 使徒行傳 27:34"> 就是你們的頭髮也都被數過了。</span>
<span className="v" id="v31" data-v="31" data-xref="路加福音 12:24; 詩篇 8:5; 馬太福音 6:26"> 所以，不要懼怕，你們比許多麻雀還貴重！」</span>
</div>
</div>

## 論報賞

<div className="bt">
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="約翰福音 13:20; 路加福音 9:48; 路加福音 10:16"> 「人接待你們就是接待我；接待我就是接待那差我來的。</span>
<span className="v" id="v41" data-v="41" data-xref="約翰三書 1:5–8; 希伯來書 6:10; 列王紀下 4:16–17"> 人因為先知的名接待先知，必得先知所得的賞賜；人因為義人的名接待義人，必得義人所得的賞賜。</span>

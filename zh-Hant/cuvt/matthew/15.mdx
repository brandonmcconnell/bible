## 古人的傳統

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="馬可福音 3:22; 馬太福音 23:2; 路加福音 5:21"> 那時，有法利賽人和文士從耶路撒冷來見耶穌，說：</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 11:38; 馬可福音 7:2; 歌羅西書 2:20–23"> 「你的門徒為甚麼犯古人的遺傳呢？因為吃飯的時候，他們不洗手。」</span>
<span className="v" id="v3" data-v="3" data-xref="歌羅西書 2:23; 提多書 1:14; 歌羅西書 2:8"> 耶穌回答說：「你們為甚麼因着你們的遺傳犯上帝的誡命呢？</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及記 20:12; 利未記 20:9; 出埃及記 21:17"> 上帝說：『當孝敬父母』；又說：『咒罵父母的，必治死他。』</span>
<span className="v" id="v5" data-v="5" data-xref="馬可福音 7:10–13; 使徒行傳 5:29; 馬太福音 23:16–18"> 你們倒說：『無論何人對父母說：我所當奉給你的已經作了供獻，</span>
<span className="v" id="v6" data-v="6" data-xref="提摩太前書 5:8; 耶利米書 8:8; 馬可福音 7:13"> 他就可以不孝敬父母。』這就是你們藉着遺傳，廢了上帝的誡命。</span>
<span className="v" id="v7" data-v="7" data-xref="馬可福音 7:6; 馬太福音 23:23–29; 使徒行傳 28:25–27"> 假冒為善的人哪，以賽亞指着你們說的預言是不錯的。他說：</span>
<span className="v" id="v8" data-v="8" data-xref="以賽亞書 29:13; 以西結書 33:31; 使徒行傳 8:21"> <span className="pl pl-1">這百姓用嘴唇尊敬我，</span><br /><span className="pl pl-1">心卻遠離我；</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="以賽亞書 29:13; 馬可福音 7:7; 提摩太前書 1:4"> <span className="pl pl-1">他們將人的吩咐當作道理教導人，</span><br /><span className="pl pl-1">所以拜我也是枉然。」</span></span>
<span className="v" id="v10" data-v="10" data-xref="馬可福音 7:14–15; 路加福音 20:45–47; 路加福音 24:45"> 耶穌就叫了眾人來，對他們說：「你們要聽，也要明白。</span>
<span className="v" id="v11" data-v="11" data-xref="馬可福音 7:15; 馬太福音 15:18–20; 雅各書 3:5–8"> 入口的不能污穢人，出口的乃能污穢人。」</span>
<span className="v" id="v12" data-v="12" data-xref="列王紀上 22:13–14; 哥林多前書 10:32–33; 加拉太書 2:5"> 當時，門徒進前來對他說：「法利賽人聽見這話，不服<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是跌倒">a</a></sup>，你知道嗎？」</span>
<span className="v" id="v13" data-v="13" data-xref="約翰福音 15:2; 以賽亞書 60:21; 約翰福音 15:6"> 耶穌回答說：「凡栽種的物，若不是我天父栽種的，必要拔出來。</span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 6:39; 以賽亞書 56:10; 馬太福音 23:16–24"> 任憑他們吧！他們是瞎眼領路的；若是瞎子領瞎子，兩個人都要掉在坑裏。」</span>
<span className="v" id="v15" data-v="15" data-xref="馬太福音 13:36; 馬可福音 4:34; 約翰福音 16:29"> 彼得對耶穌說：「請將這比喻講給我們聽。」</span>
<span className="v" id="v16" data-v="16" data-xref="馬太福音 16:9; 馬可福音 7:18; 馬可福音 9:32"> 耶穌說：「你們到如今還不明白嗎？</span>
<span className="v" id="v17" data-v="17" data-xref="路加福音 6:45; 哥林多前書 6:13; 馬太福音 7:19–20"> 豈不知凡入口的，是運到肚子裏，又落在茅廁裏嗎？</span>
<span className="v" id="v18" data-v="18" data-xref="箴言 15:28; 馬太福音 12:34; 雅各書 3:6–10"> 惟獨出口的，是從心裏發出來的，這才污穢人。</span>
<span className="v" id="v19" data-v="19" data-xref="馬可福音 7:21–23; 加拉太書 5:19–21; 耶利米書 17:9"> 因為從心裏發出來的，有惡念、凶殺、姦淫、苟合、偷盜、妄證、謗讟。</span>
<span className="v" id="v20" data-v="20" data-xref="馬可福音 7:3–4; 以弗所書 5:3–6; 哥林多前書 6:18–20"> 這都是污穢人的；至於不洗手吃飯，那卻不污穢人。」</span>
</div>
</div>

## 迦南婦人的信心

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="馬可福音 7:24–30; 馬太福音 11:21–23; 士師記 1:31"> 耶穌離開那裏，退到泰爾、西頓的境內去。</span>
<span className="v" id="v22" data-v="22" data-xref="馬太福音 9:27; 馬可福音 7:25–26; 馬太福音 17:15"> 有一個迦南婦人，從那地方出來，喊着說：「主啊，大衛的子孫，可憐我！我女兒被鬼附得甚苦。」</span>
<span className="v" id="v23" data-v="23" data-xref="馬太福音 14:15; 馬可福音 10:47–48; 耶利米哀歌 3:8"> 耶穌卻一言不答。門徒進前來，求他說：「這婦人在我們後頭喊叫，請打發她走吧。」</span>
<span className="v" id="v24" data-v="24" data-xref="馬太福音 10:5–6; 羅馬書 15:8; 耶利米書 50:6–7"> 耶穌說：「我奉差遣不過是到以色列家迷失的羊那裏去。」</span>
<span className="v" id="v25" data-v="25" data-xref="創世記 32:26; 馬太福音 20:31; 馬太福音 14:33"> 那婦人來拜他，說：「主啊，幫助我！」</span>
<span className="v" id="v26" data-v="26" data-xref="馬可福音 7:27–28; 馬太福音 7:6; 腓立比書 3:2"> 他回答說：「不好拿兒女的餅丟給狗吃。」</span>
<span className="v" id="v27" data-v="27" data-xref="以弗所書 3:8; 路加福音 16:21; 約伯記 40:4–5"> 婦人說：「主啊，不錯；但是狗也吃牠主人桌子上掉下來的碎渣兒。」</span>
<span className="v" id="v28" data-v="28" data-xref="馬可福音 9:23–24; 馬太福音 8:13; 詩篇 145:19"> 耶穌說：「婦人，你的信心是大的！照你所要的，給你成全了吧。」從那時候，她女兒就好了。</span>
</div>
</div>

## 治好許多病人

<div className="bt">
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="馬太福音 4:18; 約翰福音 6:1; 馬太福音 5:1"> 耶穌離開那地方，來到靠近加利利的海邊，就上山坐下。</span>
<span className="v" id="v30" data-v="30" data-xref="路加福音 6:17–19; 使徒行傳 5:15–16; 馬太福音 14:35–36"> 有許多人到他那裏，帶着瘸子、瞎子、啞巴、有殘疾的，和好些別的病人，都放在他腳前；他就治好了他們。</span>
<span className="v" id="v31" data-v="31" data-xref="馬太福音 9:8; 路加福音 18:43; 路加福音 17:15–18"> 甚至眾人都希奇；因為看見啞巴說話，殘疾的痊癒，瘸子行走，瞎子看見，他們就歸榮耀給以色列的上帝。</span>
</div>
</div>

## 耶穌給四千人吃飽

<div className="bt">
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="使徒行傳 27:33; 路加福音 12:29–30; 馬太福音 9:36"> 耶穌叫門徒來，說：「我憐憫這眾人；因為他們同我在這裏已經三天，也沒有吃的了。我不願意叫他們餓着回去，恐怕在路上困乏。」</span>
<span className="v" id="v33" data-v="33" data-xref="馬可福音 6:37; 馬太福音 14:15; 馬可福音 8:4–5"> 門徒說：「我們在這野地，哪裏有這麼多的餅叫這許多人吃飽呢？」</span>
<span className="v" id="v34" data-v="34" data-xref="馬太福音 16:9–10; 路加福音 24:41–42; 約翰福音 21:9–10"> 耶穌說：「你們有多少餅？」他們說：「有七個，還有幾條小魚。」</span>
<span className="v" id="v35" data-v="35" data-xref="路加福音 9:14–16; 馬可福音 6:39–40; 約翰福音 6:10"> 他就吩咐眾人坐在地上，</span>
<span className="v" id="v36" data-v="36" data-xref="路加福音 22:19; 羅馬書 14:6; 約翰福音 6:11"> 拿着這七個餅和幾條魚，祝謝了，擘開，遞給門徒；門徒又遞給眾人。</span>
<span className="v" id="v37" data-v="37" data-xref="馬可福音 8:19–21; 馬太福音 16:9–10; 馬太福音 15:33"> 眾人都吃，並且吃飽了，收拾剩下的零碎，裝滿了七個筐子。</span>
<span className="v" id="v38" data-v="38"> 吃的人，除了婦女孩子，共有四千。</span>
<span className="v" id="v39" data-v="39" data-xref="馬可福音 8:10; 馬太福音 14:22"> 耶穌叫眾人散去，就上船，來到馬加丹的境界。</span>
</div>

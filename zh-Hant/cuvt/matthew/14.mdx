## 施洗約翰的死

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 3:1; 馬可福音 8:15; 路加福音 9:7–9"> 那時，分封的王希律聽見耶穌的名聲，</span>
<span className="v" id="v2" data-v="2" data-xref="馬太福音 16:14; 約翰福音 10:41; 馬可福音 8:28"> 就對臣僕說：「這是施洗的約翰從死裏復活，所以這些異能從他裏面發出來。」</span>
<span className="v" id="v3" data-v="3" data-xref="馬可福音 6:17; 路加福音 3:19–20; 馬太福音 4:12"> 起先，希律為他兄弟腓力的妻子希羅底的緣故，把約翰拿住，鎖在監裏。</span>
<span className="v" id="v4" data-v="4" data-xref="利未記 20:21; 利未記 18:16; 馬可福音 6:18"> 因為約翰曾對他說：「你娶這婦人是不合理的。」</span>
<span className="v" id="v5" data-v="5" data-xref="馬太福音 21:26; 馬太福音 11:9; 馬可福音 6:19–20"> 希律就想要殺他，只是怕百姓，因為他們以約翰為先知。</span>
<span className="v" id="v6" data-v="6" data-xref="馬可福音 6:21–23; 創世記 40:20; 何西阿書 1:5–6"> 到了希律的生日，希羅底的女兒在眾人面前跳舞，使希律歡喜。</span>
<span className="v" id="v7" data-v="7" data-xref="以斯帖記 5:3; 以斯帖記 5:6; 以斯帖記 7:2"> 希律就起誓，應許隨她所求的給她。</span>
<span className="v" id="v8" data-v="8" data-xref="馬可福音 6:24; 箴言 29:10; 箴言 1:16"> 女兒被母親所使，就說：「請把施洗約翰的頭放在盤子裏，拿來給我。」</span>
<span className="v" id="v9" data-v="9" data-xref="約翰福音 19:12–16; 撒母耳記上 14:28; 馬可福音 6:26"> 王便憂愁，但因他所起的誓，又因同席的人，就吩咐給她；</span>
<span className="v" id="v10" data-v="10" data-xref="馬太福音 17:12; 馬太福音 21:35–36; 路加福音 9:9"> 於是打發人去，在監裏斬了約翰，</span>
<span className="v" id="v11" data-v="11" data-xref="啟示錄 16:6; 創世記 49:7; 以西結書 16:3–4"> 把頭放在盤子裏，拿來給了女子；女子拿去給她母親。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行傳 8:2; 馬太福音 27:58–61"> 約翰的門徒來，把屍首領去埋葬了，就去告訴耶穌。</span>
</div>
</div>

## 耶穌給五千人吃飽

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="路加福音 9:10–17; 馬太福音 14:1–2; 馬可福音 6:30–44"> 耶穌聽見了，就上船從那裏獨自退到野地裏去。眾人聽見，就從各城裏步行跟隨他。</span>
<span className="v" id="v14" data-v="14" data-xref="希伯來書 4:15; 馬太福音 9:36; 希伯來書 2:17"> 耶穌出來，見有許多的人，就憐憫他們，治好了他們的病人。</span>
<span className="v" id="v15" data-v="15" data-xref="馬太福音 15:23; 馬可福音 8:3; 馬可福音 6:35–36"> 天將晚的時候，門徒進前來，說：「這是野地，時候已經過了，請叫眾人散開，他們好往村子裏去，自己買吃的。」</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀下 4:42–44; 哥林多後書 8:2–3; 傳道書 11:2"> 耶穌說：「不用他們去，你們給他們吃吧！」</span>
<span className="v" id="v17" data-v="17" data-xref="馬太福音 15:33–34; 馬可福音 6:37–38; 路加福音 9:13"> 門徒說：「我們這裏只有五個餅，兩條魚。」</span>
<span className="v" id="v18" data-v="18"> 耶穌說：「拿過來給我。」</span>
<span className="v" id="v19" data-v="19" data-xref="馬可福音 8:6–7; 路加福音 24:30; 撒母耳記上 9:13"> 於是吩咐眾人坐在草地上，就拿着這五個餅，兩條魚，望着天祝福，擘開餅，遞給門徒，門徒又遞給眾人。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及記 16:12; 馬可福音 6:42–44; 馬太福音 16:8–10"> 他們都吃，並且吃飽了，把剩下的零碎收拾起來，裝滿了十二個籃子。</span>
<span className="v" id="v21" data-v="21" data-xref="腓立比書 4:19; 哥林多後書 9:8–11; 使徒行傳 4:4"> 吃的人，除了婦女孩子，約有五千。</span>
</div>
</div>

## 耶穌在海面上行走

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="馬可福音 6:45–51; 約翰福音 6:15–21; 馬太福音 15:39"> 耶穌隨即催門徒上船，先渡到那邊去，等他叫眾人散開。</span>
<span className="v" id="v23" data-v="23" data-xref="路加福音 6:12; 馬可福音 6:46; 馬太福音 26:36"> 散了眾人以後，他就獨自上山去禱告。到了晚上，只有他一人在那裏。</span>
<span className="v" id="v24" data-v="24" data-xref="約翰福音 6:18; 馬可福音 6:48; 馬太福音 8:24"> 那時船在海中，因風不順，被浪搖撼。</span>
<span className="v" id="v25" data-v="25" data-xref="約伯記 9:8; 約翰福音 6:19; 馬可福音 6:48"> 夜裏四更天，耶穌在海面上走，往門徒那裏去。</span>
<span className="v" id="v26" data-v="26" data-xref="馬可福音 6:49–50; 啟示錄 1:17; 路加福音 1:11–12"> 門徒看見他在海面上走，就驚慌了，說：「是個鬼怪！」便害怕，喊叫起來。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行傳 23:11; 啟示錄 1:17–18; 約翰福音 16:33"> 耶穌連忙對他們說：「你們放心，是我，不要怕！」</span>
<span className="v" id="v28" data-v="28" data-xref="約翰福音 6:68; 羅馬書 12:3; 馬太福音 26:33–35"> 彼得說：「主，如果是你，請叫我從水面上走到你那裏去。」</span>
<span className="v" id="v29" data-v="29" data-xref="腓立比書 4:13; 馬可福音 9:23; 使徒行傳 3:16"> 耶穌說：「你來吧。」彼得就從船上下去，在水面上走，要到耶穌那裏去；</span>
<span className="v" id="v30" data-v="30" data-xref="耶利米哀歌 3:54–57; 提摩太後書 4:16–17; 馬可福音 14:38"> 只因見風甚大，就害怕，將要沉下去，便喊着說：「主啊，救我！」</span>
<span className="v" id="v31" data-v="31" data-xref="雅各書 1:6–8; 詩篇 138:7; 創世記 22:14"> 耶穌趕緊伸手拉住他，說：「你這小信的人哪，為甚麼疑惑呢？」</span>
<span className="v" id="v32" data-v="32" data-xref="詩篇 107:29–30; 馬可福音 4:41; 約翰福音 6:21"> 他們上了船，風就住了。</span>
<span className="v" id="v33" data-v="33" data-xref="約翰福音 11:27; 詩篇 2:7; 羅馬書 1:4"> 在船上的人都拜他，說：「你真是上帝的兒子了。」</span>
</div>
</div>

## 治好革尼撒勒的病人

<div className="bt">
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="馬可福音 6:53–56; 路加福音 5:1; 約翰福音 6:24–25"> 他們過了海，來到革尼撒勒地方。</span>
<span className="v" id="v35" data-v="35" data-xref="馬太福音 4:24–25; 馬可福音 6:55; 馬可福音 1:28–34"> 那裏的人一認出是耶穌，就打發人到周圍地方去，把所有的病人帶到他那裏，</span>
<span className="v" id="v36" data-v="36" data-xref="路加福音 6:19; 馬可福音 3:10; 出埃及記 28:33–43"> 只求耶穌准他們摸他的衣裳繸子；摸着的人就都好了。</span>
</div>

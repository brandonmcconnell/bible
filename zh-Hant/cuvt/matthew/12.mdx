## 安息日的問題

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命記 23:25; 馬可福音 2:23–28; 路加福音 6:1–5"> 那時，耶穌在安息日從麥地經過。他的門徒餓了，就掐起麥穗來吃。</span>
<span className="v" id="v2" data-v="2" data-xref="馬太福音 12:10; 約翰福音 7:21–24; 路加福音 14:3"> 法利賽人看見，就對耶穌說：「看哪，你的門徒做安息日不可做的事了！」</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳記上 21:3–6; 路加福音 6:3; 馬可福音 2:25–26"> 耶穌對他們說：「經上記着大衛和跟從他的人飢餓之時所做的事，你們沒有念過嗎？</span>
<span className="v" id="v4" data-v="4" data-xref="利未記 24:5–9; 出埃及記 25:30; 利未記 8:31"> 他怎麼進了上帝的殿，吃了陳設餅，這餅不是他和跟從他的人可以吃得，惟獨祭司才可以吃。</span>
<span className="v" id="v5" data-v="5" data-xref="民數記 28:9–10; 約翰福音 7:22–23; 尼希米記 13:17"> 再者，律法上所記的，當安息日，祭司在殿裏犯了安息日還是沒有罪，你們沒有念過嗎？</span>
<span className="v" id="v6" data-v="6" data-xref="馬太福音 12:41–42; 歷代志下 6:18; 彼得前書 2:4–5"> 但我告訴你們，在這裏有一人比殿更大。</span>
<span className="v" id="v7" data-v="7" data-xref="何西阿書 6:6; 馬太福音 9:13; 彌迦書 6:6–8"> 『我喜愛憐恤，不喜愛祭祀。』你們若明白這話的意思，就不將無罪的當作有罪的了。</span>
<span className="v" id="v8" data-v="8" data-xref="馬可福音 2:28; 路加福音 6:5; 約翰福音 5:17–23"> 因為人子是安息日的主。」</span>
</div>
</div>

## 治好枯乾了一隻手的人

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="馬可福音 3:1–6; 路加福音 6:6–11"> 耶穌離開那地方，進了一個會堂。</span>
<span className="v" id="v10" data-v="10" data-xref="路加福音 13:14; 約翰福音 9:16; 約翰福音 8:6"> 那裏有一個人枯乾了一隻手。有人問耶穌說：「安息日治病可以不可以？」意思是要控告他。</span>
<span className="v" id="v11" data-v="11" data-xref="申命記 22:4; 路加福音 14:5; 路加福音 13:15–17"> 耶穌說：「你們中間誰有一隻羊，當安息日掉在坑裏，不把牠抓住、拉上來呢？</span>
<span className="v" id="v12" data-v="12" data-xref="馬太福音 6:26; 路加福音 6:9; 馬可福音 3:4"> 人比羊何等貴重呢！所以，在安息日做善事是可以的。」</span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 13:13; 使徒行傳 3:7–8"> 於是對那人說：「伸出手來！」他把手一伸，手就復了原，和那隻手一樣。</span>
<span className="v" id="v14" data-v="14" data-xref="約翰福音 11:53; 約翰福音 10:39; 馬可福音 3:6"> 法利賽人出去，商議怎樣可以除滅耶穌。</span>
</div>
</div>

## 上帝所揀選的僕人

<div className="bt">
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="馬可福音 3:7–12; 馬太福音 10:23; 馬太福音 19:2"> 耶穌知道了，就離開那裏，有許多人跟着他。他把其中有病的人都治好了；</span>
<span className="v" id="v16" data-v="16" data-xref="馬太福音 8:4; 馬太福音 9:30; 馬太福音 17:9"> 又囑咐他們，不要給他傳名。</span>
<span className="v" id="v17" data-v="17" data-xref="以賽亞書 42:1–4; 以賽亞書 42:9; 馬太福音 13:35"> 這是要應驗先知以賽亞的話，說：</span>
<span className="v" id="v18" data-v="18" data-xref="以賽亞書 42:1; 路加福音 4:18; 使徒行傳 10:38"> <span className="pl pl-1">看哪！我的僕人，</span><br /><span className="pl pl-1">我所揀選、所親愛、心裏所喜悅的，</span><br /><span className="pl pl-1">我要將我的靈賜給他；</span><br /><span className="pl pl-1">他必將公理傳給外邦。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="馬太福音 11:29; 約翰福音 18:36–38; 提摩太後書 2:24–25"> <span className="pl pl-1">他不爭競，不喧嚷；</span><br /><span className="pl pl-1">街上也沒有人聽見他的聲音。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="以賽亞書 42:3–4; 以西結書 34:16; 以賽亞書 61:1–3"> <span className="pl pl-1">壓傷的蘆葦，他不折斷；</span><br /><span className="pl pl-1">將殘的燈火，他不吹滅；</span><br /><span className="pl pl-1">等他施行公理，叫公理得勝。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="以賽亞書 11:10; 羅馬書 15:12–13; 以賽亞書 42:4"> <span className="pl pl-1">外邦人都要仰望他的名。</span></span>
</div>
</div>

## 耶穌和別西卜

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="路加福音 11:14–15; 馬可福音 7:35–37; 以賽亞書 29:18"> 當下，有人將一個被鬼附着、又瞎又啞的人帶到耶穌那裏，耶穌就醫治他，甚至那啞巴又能說話，又能看見。</span>
<span className="v" id="v23" data-v="23" data-xref="馬太福音 9:27; 約翰福音 4:29; 馬太福音 22:42–43"> 眾人都驚奇，說：「這不是大衛的子孫嗎？」</span>
<span className="v" id="v24" data-v="24" data-xref="馬可福音 3:22; 馬太福音 9:34; 路加福音 11:15"> 但法利賽人聽見，就說：「這個人趕鬼，無非是靠着鬼王別西卜啊。」</span>
<span className="v" id="v25" data-v="25" data-xref="加拉太書 5:15; 耶利米書 17:10; 馬太福音 9:4"> 耶穌知道他們的意念，就對他們說：「凡一國自相紛爭，就成為荒場；一城一家自相紛爭，必站立不住；</span>
<span className="v" id="v26" data-v="26" data-xref="歌羅西書 1:13; 啟示錄 20:2–3; 約翰一書 5:19"> 若撒但趕逐撒但，就是自相紛爭，他的國怎能站得住呢？</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行傳 19:13–16; 馬可福音 9:38–39; 路加福音 9:49–50"> 我若靠着別西卜趕鬼，你們的子弟趕鬼又靠着誰呢？這樣，他們就要斷定你們的是非。</span>
<span className="v" id="v28" data-v="28" data-xref="路加福音 11:20; 但以理書 7:14; 馬太福音 6:33"> 我若靠着上帝的靈趕鬼，這就是上帝的國臨到你們了。</span>
<span className="v" id="v29" data-v="29" data-xref="以賽亞書 49:24; 馬可福音 3:27; 路加福音 11:21–22"> 人怎能進壯士家裏，搶奪他的家具呢？除非先捆住那壯士，才可以搶奪他的家財。</span>
<span className="v" id="v30" data-v="30" data-xref="馬可福音 9:40; 路加福音 11:23; 約書亞記 24:15"> 不與我相合的，就是敵我的；不同我收聚的，就是分散的。」</span>
<span className="v" id="v31" data-v="31" data-xref="路加福音 12:10; 馬可福音 3:28–30; 希伯來書 10:29"> 所以我告訴你們：「人一切的罪和褻瀆的話都可得赦免，惟獨褻瀆聖靈，總不得赦免。</span>
<span className="v" id="v32" data-v="32" data-xref="馬可福音 3:29; 希伯來書 10:26–29; 希伯來書 6:4–6"> 凡說話干犯人子的，還可得赦免；惟獨說話干犯聖靈的，今世來世總不得赦免。」</span>
</div>
</div>

## 樹和果子

<div className="bt">
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="路加福音 6:43–44; 馬太福音 7:16–20; 雅各書 4:8"> 「你們或以為樹好，果子也好；樹壞，果子也壞；因為看果子就可以知道樹。</span>
<span className="v" id="v34" data-v="34" data-xref="路加福音 6:45; 馬太福音 15:18; 以弗所書 4:29"> 毒蛇的種類！你們既是惡人，怎能說出好話來呢？因為心裏所充滿的，口裏就說出來。</span>
<span className="v" id="v35" data-v="35" data-xref="箴言 15:4; 歌羅西書 4:6; 箴言 15:28"> 善人從他心裏所存的善就發出善來；惡人從他心裏所存的惡就發出惡來。</span>
<span className="v" id="v36" data-v="36" data-xref="傳道書 12:14; 羅馬書 2:16; 啟示錄 20:12"> 我又告訴你們，凡人所說的閒話，當審判的日子，必要句句供出來；</span>
<span className="v" id="v37" data-v="37" data-xref="箴言 13:3; 雅各書 2:21–25"> 因為要憑你的話定你為義，也要憑你的話定你有罪。」</span>
</div>
</div>

## 要求神蹟

<div className="bt">
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="哥林多前書 1:22; 馬可福音 8:11–12; 路加福音 11:16"> 當時，有幾個文士和法利賽人對耶穌說：「夫子，我們願意你顯個神蹟給我們看。」</span>
<span className="v" id="v39" data-v="39" data-xref="馬太福音 16:4; 路加福音 11:29–32; 馬可福音 8:38"> 耶穌回答說：「一個邪惡淫亂的世代求看神蹟，除了先知約拿的神蹟以外，再沒有神蹟給他們看。</span>
<span className="v" id="v40" data-v="40" data-xref="約拿書 1:17; 馬太福音 27:63–64; 馬太福音 16:21"> 約拿三日三夜在大魚肚腹中，人子也要這樣三日三夜在地裏頭。</span>
<span className="v" id="v41" data-v="41" data-xref="馬太福音 12:42; 希伯來書 11:7; 馬太福音 12:6"> 當審判的時候，尼尼微人要起來定這世代的罪，因為尼尼微人聽了約拿所傳的就悔改了。看哪，在這裏有一人比約拿更大！</span>
<span className="v" id="v42" data-v="42" data-xref="列王紀上 10:1–13; 歷代志下 9:1–12; 希伯來書 1:2–4"> 當審判的時候，南方的女王要起來定這世代的罪； 因為她從地極而來，要聽所羅門的智慧話。看哪，在這裏有一人比所羅門更大！」</span>
</div>
</div>

## 污鬼回來

<div className="bt">
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="路加福音 11:24–26; 路加福音 8:28–32; 馬太福音 8:29"> 「污鬼離了人身，就在無水之地過來過去，尋求安歇之處，卻尋不着。</span>
<span className="v" id="v44" data-v="44" data-xref="約翰一書 4:4; 啟示錄 13:8–9; 猶大書 1:4–5"> 於是說：『我要回到我所出來的屋裏去。』到了，就看見裏面空閒，打掃乾淨，修飾好了，</span>
<span className="v" id="v45" data-v="45" data-xref="路加福音 11:26; 馬可福音 5:9; 希伯來書 6:4–8"> 便去另帶了七個比自己更惡的鬼來，都進去住在那裏。那人末後的景況比先前更不好了。這邪惡的世代也要如此。」</span>
</div>
</div>

## 耶穌的母親和兄弟們

<div className="bt">
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="馬太福音 13:55; 約翰福音 2:12; 約翰福音 7:3"> 耶穌還對眾人說話的時候，不料他母親和他弟兄站在外邊，要與他說話。</span>
<span className="v" id="v47" data-v="47"> 有人告訴他說：「看哪，你母親和你弟兄站在外邊，要與你說話。」</span>
<span className="v" id="v48" data-v="48" data-xref="馬可福音 3:32–33; 馬太福音 10:37; 路加福音 2:52"> 他卻回答那人說：「誰是我的母親？誰是我的弟兄？」</span>
<span className="v" id="v49" data-v="49" data-xref="馬可福音 3:34; 約翰福音 17:8–9; 約翰福音 20:17–20"> 就伸手指着門徒，說：「看哪，我的母親，我的弟兄。</span>
<span className="v" id="v50" data-v="50" data-xref="路加福音 8:21; 馬可福音 3:35; 約翰福音 15:14"> 凡遵行我天父旨意的人，就是我的弟兄姊妹和母親了。」</span>

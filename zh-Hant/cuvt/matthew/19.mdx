## 休妻的問題

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="約翰福音 10:40; 馬太福音 19:1–9; 馬太福音 7:28"> 耶穌說完了這些話，就離開加利利，來到猶太的境界約旦河外。</span>
<span className="v" id="v2" data-v="2" data-xref="馬太福音 12:15; 馬可福音 6:55–56; 馬太福音 15:30–31"> 有許多人跟着他，他就在那裏把他們的病人治好了。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="馬可福音 10:2; 希伯來書 3:9; 馬太福音 16:1"> 有法利賽人來試探耶穌，說：「人無論甚麼緣故都可以休妻嗎？」</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 2:23; 創世記 1:27; 創世記 5:2"> 耶穌回答說：「那起初造人的，是造男造女，</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 2:21–24; 哥林多前書 7:4; 哥林多前書 7:2"> 並且說：『因此，人要離開父母，與妻子連合，二人成為一體。』這經你們沒有念過嗎？</span>
<span className="v" id="v6" data-v="6" data-xref="希伯來書 13:4; 馬可福音 10:9; 哥林多前書 7:10–14"> 既然如此，夫妻不再是兩個人，乃是一體的了。所以，上帝配合的，人不可分開。」</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 24:1–4; 馬太福音 5:31; 馬可福音 10:4"> 法利賽人說：「這樣，摩西為甚麼吩咐給妻子休書，就可以休她呢？」</span>
<span className="v" id="v8" data-v="8" data-xref="瑪拉基書 2:13–14; 創世記 2:24; 馬可福音 10:5"> 耶穌說：「摩西因為你們的心硬，所以許你們休妻，但起初並不是這樣。</span>
<span className="v" id="v9" data-v="9" data-xref="馬太福音 5:32; 路加福音 16:18; 哥林多前書 7:39"> 我告訴你們，凡休妻另娶的，若不是為淫亂的緣故，就是犯姦淫了；有人娶那被休的婦人，也是犯姦淫了。」</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多前書 7:32–35; 箴言 19:13–14; 箴言 21:19"> 門徒對耶穌說：「人和妻子既是這樣，倒不如不娶。」</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多前書 7:17; 哥林多前書 7:35; 哥林多前書 7:7–9"> 耶穌說：「這話不是人都能領受的，惟獨賜給誰，誰才能領受。</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多前書 7:32–38; 哥林多前書 9:5; 以賽亞書 56:3–4"> 因為有生來是閹人，也有被人閹的，並有為天國的緣故自閹的。這話誰能領受就可以領受。」</span>
</div>
</div>

## 耶穌為小孩祝福

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="馬可福音 10:13–16; 路加福音 18:15–17; 馬太福音 18:2–5"> 那時，有人帶着小孩子來見耶穌，要耶穌給他們按手禱告，門徒就責備那些人。</span>
<span className="v" id="v14" data-v="14" data-xref="馬太福音 18:3; 路加福音 18:16–17; 哥林多前書 14:20"> 耶穌說：「讓小孩子到我這裏來，不要禁止他們；因為在天國的，正是這樣的人。」</span>
<span className="v" id="v15" data-v="15" data-xref="馬可福音 10:16; 提摩太後書 3:15; 哥林多前書 7:14"> 耶穌給他們按手，就離開那地方去了。</span>
</div>
</div>

## 少年財主

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="馬可福音 10:17–30; 約翰福音 3:15; 猶大書 1:21"> 有一個人來見耶穌，說：「夫子<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古卷：良善的夫子">a</a></sup>，我該做甚麼善事才能得永生？」</span>
<span className="v" id="v17" data-v="17" data-xref="利未記 18:5; 路加福音 10:26–28; 加拉太書 3:11–13"> 耶穌對他說：「你為甚麼以善事問我呢？只有一位是善的<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有古卷：你為甚麼稱我是良善的？除了上帝以外，沒有一個良善的">b</a></sup>。你若要進入永生，就當遵守誡命。」</span>
<span className="v" id="v18" data-v="18" data-xref="申命記 5:16–21; 出埃及記 20:12–17; 馬可福音 10:19"> 他說：「甚麼誡命？」耶穌說：「就是不可殺人；不可姦淫；不可偷盜；不可作假見證；</span>
<span className="v" id="v19" data-v="19" data-xref="利未記 19:18; 出埃及記 20:12; 馬太福音 22:39"> 當孝敬父母；又當愛人如己。」</span>
<span className="v" id="v20" data-v="20" data-xref="加拉太書 3:24; 馬可福音 10:20–21; 腓立比書 3:6"> 那少年人說：「這一切我都遵守了，還缺少甚麼呢？」</span>
<span className="v" id="v21" data-v="21" data-xref="馬可福音 10:21; 路加福音 18:22; 路加福音 12:33"> 耶穌說：「你若願意作完全人，可去變賣你所有的，分給窮人，就必有財寶在天上；你還要來跟從我。」</span>
<span className="v" id="v22" data-v="22" data-xref="馬太福音 6:24; 以西結書 33:31; 馬太福音 13:22"> 那少年人聽見這話，就憂憂愁愁地走了，因為他的產業很多。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="提摩太前書 6:9–10; 馬太福音 13:22; 馬可福音 10:23"> 耶穌對門徒說：「我實在告訴你們，財主進天國是難的。</span>
<span className="v" id="v24" data-v="24" data-xref="約翰福音 5:44; 路加福音 18:25; 馬可福音 10:24–25"> 我又告訴你們，駱駝穿過針的眼，比財主進上帝的國還容易呢！」</span>
<span className="v" id="v25" data-v="25" data-xref="羅馬書 10:13; 馬太福音 24:22; 羅馬書 11:5–7"> 門徒聽見這話，就希奇得很，說：「這樣誰能得救呢？」</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米書 32:27; 路加福音 1:37; 約伯記 42:2"> 耶穌看着他們，說：「在人這是不能的，在上帝凡事都能。」</span>
<span className="v" id="v27" data-v="27" data-xref="腓立比書 3:8; 路加福音 18:28; 路加福音 5:11"> 彼得就對他說：「看哪，我們已經撇下所有的跟從你，將來我們要得甚麼呢？」</span>
<span className="v" id="v28" data-v="28" data-xref="路加福音 22:28–30; 哥林多前書 6:2–3; 馬太福音 25:31"> 耶穌說：「我實在告訴你們，你們這跟從我的人，到復興的時候，人子坐在他榮耀的寶座上，你們也要坐在十二個寶座上，審判以色列十二個支派。</span>
<span className="v" id="v29" data-v="29" data-xref="路加福音 18:29–30; 馬可福音 10:29–30; 腓立比書 3:8"> 凡為我的名撇下房屋，或是弟兄、姊妹、父親、母親、<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="有古卷加：妻子、">c</a></sup>兒女、田地的，必要得着百倍，並且承受永生。</span>
<span className="v" id="v30" data-v="30" data-xref="馬太福音 20:16; 路加福音 13:30; 馬可福音 10:31"> 然而，有許多在前的，將要在後；在後的，將要在前。」</span>
</div>
</div>

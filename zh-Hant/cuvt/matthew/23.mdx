## 譴責文士和法利賽人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 12:1; 路加福音 20:45–46; 馬太福音 15:10–20"> 那時，耶穌對眾人和門徒講論，</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 20:46; 馬可福音 12:38; 瑪拉基書 2:7"> 說：「文士和法利賽人坐在摩西的位上，</span>
<span className="v" id="v3" data-v="3" data-xref="提摩太後書 3:5; 提多書 1:16; 羅馬書 2:19–24"> 凡他們所吩咐你們的，你們都要謹守遵行。但不要效法他們的行為；因為他們能說，不能行。</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 11:46; 使徒行傳 15:10; 加拉太書 6:13"> 他們把難擔的重擔捆起來，擱在人的肩上，但自己一個指頭也不肯動。</span>
<span className="v" id="v5" data-v="5" data-xref="馬太福音 6:1–16; 約翰福音 12:43; 腓立比書 2:3"> 他們一切所做的事都是要叫人看見，所以將佩戴的經文做寬了，衣裳的繸子做長了，</span>
<span className="v" id="v6" data-v="6" data-xref="約翰三書 1:9; 路加福音 11:43–54; 馬可福音 12:38–39"> 喜愛筵席上的首座，會堂裏的高位，</span>
<span className="v" id="v7" data-v="7" data-xref="約翰福音 1:38; 約翰福音 1:49; 約翰福音 3:26"> 又喜愛人在街市上問他安，稱呼他拉比<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="拉比就是夫子">a</a></sup>。</span>
<span className="v" id="v8" data-v="8" data-xref="雅各書 3:1; 哥林多前書 1:12–13; 彼得前書 5:3"> 但你們不要受拉比的稱呼，因為只有一位是你們的夫子；你們都是弟兄。</span>
<span className="v" id="v9" data-v="9" data-xref="約翰一書 3:1; 希伯來書 12:9; 瑪拉基書 1:6"> 也不要稱呼地上的人為父，因為只有一位是你們的父，就是在天上的父。</span>
<span className="v" id="v10" data-v="10"> 也不要受師尊的稱呼，因為只有一位是你們的師尊，就是基督。</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多前書 9:19; 加拉太書 5:13; 約翰福音 13:14–15"> 你們中間誰為大，誰就要作你們的用人。</span>
<span className="v" id="v12" data-v="12" data-xref="彼得前書 5:5; 雅各書 4:6; 箴言 29:23"> 凡自高的，必降為卑；自卑的，必升為高。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="路加福音 11:52; 馬太福音 23:29; 馬太福音 23:23"> 「你們這假冒為善的文士和法利賽人有禍了！因為你們正當人前，把天國的門關了，自己不進去，正要進去的人，你們也不容他們進去。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有古卷加：14你們這假冒為善的文士和法利賽人有禍了！因為你們侵吞寡婦的家產，假意做很長的禱告，所以要受更重的刑罰。">b</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="以弗所書 2:3; 使徒行傳 13:10; 使徒行傳 13:43"> 「你們這假冒為善的文士和法利賽人有禍了！因為你們走遍洋海陸地，勾引一個人入教，既入了教，卻使他作地獄之子，比你們還加倍。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="馬太福音 15:14; 馬太福音 5:33–35; 雅各書 5:12"> 「你們這瞎眼領路的有禍了！你們說：『凡指着殿起誓的，這算不得甚麼；只是凡指着殿中金子起誓的，他就該謹守。』</span>
<span className="v" id="v17" data-v="17" data-xref="馬太福音 23:19; 民數記 16:38–39; 詩篇 94:8"> 你們這無知瞎眼的人哪，甚麼是大的？是金子呢？還是叫金子成聖的殿呢？</span>
<span className="v" id="v18" data-v="18"> 你們又說：『凡指着壇起誓的，這算不得甚麼；只是凡指着壇上禮物起誓的，他就該謹守。』</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及記 29:37; 出埃及記 30:29"> 你們這瞎眼的人哪，甚麼是大的？是禮物呢？還是叫禮物成聖的壇呢？</span>
<span className="v" id="v20" data-v="20"> 所以，人指着壇起誓，就是指着壇和壇上一切所有的起誓；</span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 26:8; 列王紀上 8:13; 歷代志下 6:2"> 人指着殿起誓，就是指着殿和那住在殿裏的起誓；</span>
<span className="v" id="v22" data-v="22" data-xref="馬太福音 5:34; 詩篇 11:4; 以賽亞書 66:1"> 人指着天起誓，就是指着上帝的寶座和那坐在上面的起誓。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="路加福音 11:42; 彌迦書 6:8; 何西阿書 6:6"> 「你們這假冒為善的文士和法利賽人有禍了！因為你們將薄荷、茴香、芹菜獻上十分之一，那律法上更重的事，就是公義、憐憫、信實，反倒不行了。這更重的是你們當行的；那也是不可不行的。</span>
<span className="v" id="v24" data-v="24" data-xref="馬太福音 19:24; 馬太福音 27:6–8; 馬太福音 15:2–6"> 你們這瞎眼領路的，蠓蟲你們就濾出來，駱駝你們倒吞下去。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="路加福音 11:39–40; 馬太福音 15:19–20; 馬可福音 7:4–13"> 「你們這假冒為善的文士和法利賽人有禍了！因為你們洗淨杯盤的外面，裏面卻盛滿了勒索和放蕩。</span>
<span className="v" id="v26" data-v="26" data-xref="哥林多後書 7:1; 雅各書 4:8; 希伯來書 10:22"> 你這瞎眼的法利賽人，先洗淨杯盤的裏面，好叫外面也乾淨了。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="路加福音 11:44; 使徒行傳 23:3; 民數記 19:16"> 「你們這假冒為善的文士和法利賽人有禍了！因為你們好像粉飾的墳墓，外面好看，裏面卻裝滿了死人的骨頭和一切的污穢。</span>
<span className="v" id="v28" data-v="28" data-xref="路加福音 16:15; 詩篇 51:6; 馬太福音 23:5"> 你們也是如此，在人前，外面顯出公義來，裏面卻裝滿了假善和不法的事。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="路加福音 11:47–48; 使徒行傳 2:29"> 「你們這假冒為善的文士和法利賽人有禍了！因為你們建造先知的墳，修飾義人的墓，說：</span>
<span className="v" id="v30" data-v="30" data-xref="耶利米書 2:30; 馬太福音 23:34–35; 馬太福音 21:35–36"> 『若是我們在我們祖宗的時候，必不和他們同流先知的血。』</span>
<span className="v" id="v31" data-v="31" data-xref="使徒行傳 7:51–52; 帖撒羅尼迦前書 2:15–16; 約書亞記 24:22"> 這就是你們自己證明是殺害先知者的子孫了。</span>
<span className="v" id="v32" data-v="32" data-xref="創世記 15:16; 民數記 32:14; 帖撒羅尼迦前書 2:16"> 你們去充滿你們祖宗的惡貫吧！</span>
<span className="v" id="v33" data-v="33" data-xref="馬太福音 3:7; 馬太福音 12:34; 馬太福音 5:22"> 你們這些蛇類、毒蛇之種啊，怎能逃脫地獄的刑罰呢？</span>
<span className="v" id="v34" data-v="34" data-xref="馬太福音 10:16–17; 馬太福音 13:52; 歌羅西書 1:28"> 所以我差遣先知和智慧人並文士到你們這裏來，有的你們要殺害，要釘十字架；有的你們要在會堂裏鞭打，從這城追逼到那城，</span>
<span className="v" id="v35" data-v="35" data-xref="歷代志下 24:20–22; 撒迦利亞書 1:1; 希伯來書 11:4"> 叫世上所流義人的血都歸到你們身上，從義人亞伯的血起，直到你們在殿和壇中間所殺的巴拉加的兒子撒迦利亞的血為止。</span>
<span className="v" id="v36" data-v="36" data-xref="馬太福音 10:23; 馬太福音 24:34; 馬可福音 13:30–31"> 我實在告訴你們，這一切的罪都要歸到這世代了。」</span>
</div>
</div>

## 為耶路撒冷哀哭

<div className="bt">
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="路加福音 13:34–35; 路得記 2:12; 詩篇 91:4"> 「耶路撒冷啊，耶路撒冷啊，你常殺害先知，又用石頭打死那奉差遣到你這裏來的人。我多次願意聚集你的兒女，好像母雞把小雞聚集在翅膀底下，只是你們不願意。</span>
<span className="v" id="v38" data-v="38" data-xref="耶利米書 22:5; 路加福音 13:35; 路加福音 21:24"> 看哪，你們的家成為荒場留給你們。</span>
<span className="v" id="v39" data-v="39" data-xref="詩篇 118:26; 馬太福音 21:9; 羅馬書 11:25"> 我告訴你們，從今以後，你們不得再見我，直等到你們說：『奉主名來的是應當稱頌的。』」</span>
</div>

## 天國裏最偉大的人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="馬可福音 9:33–37; 路加福音 9:46–48; 馬太福音 20:20–28"> 當時，門徒進前來，問耶穌說：「天國裏誰是最大的？」</span>
<span className="v" id="v2" data-v="2" data-xref="馬太福音 19:13–14; 馬可福音 9:36–37; 列王紀上 3:7"> 耶穌便叫一個小孩子來，使他站在他們當中，</span>
<span className="v" id="v3" data-v="3" data-xref="馬可福音 10:14–15; 彼得前書 2:2; 馬太福音 19:14"> 說：「我實在告訴你們，你們若不回轉，變成小孩子的樣式，斷不得進天國。</span>
<span className="v" id="v4" data-v="4" data-xref="雅各書 4:10; 路加福音 14:11; 馬可福音 10:43"> 所以，凡自己謙卑像這小孩子的，他在天國裏就是最大的。</span>
<span className="v" id="v5" data-v="5" data-xref="馬太福音 25:40; 馬可福音 9:37; 約翰福音 13:20"> 凡為我的名接待一個像這小孩子的，就是接待我。」</span>
</div>
</div>

## 罪的誘惑

<div className="bt">
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="馬可福音 9:42; 路加福音 17:1–2; 馬太福音 18:10"> 「凡使這信我的一個小子跌倒的，倒不如把大磨石拴在這人的頸項上，沉在深海裏。</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 17:1; 哥林多前書 11:19; 馬太福音 26:24"> 這世界有禍了，因為將人絆倒；絆倒人的事是免不了的，但那絆倒人的有禍了！</span>
<span className="v" id="v8" data-v="8" data-xref="馬太福音 5:29–30; 腓立比書 3:8–9; 羅馬書 13:12"> 倘若你一隻手，或是一隻腳，叫你跌倒，就砍下來丟掉。你缺一隻手，或是一隻腳，進入永生，強如有兩手兩腳被丟在永火裏。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行傳 14:22; 馬太福音 18:8; 馬太福音 5:29"> 倘若你一隻眼叫你跌倒，就把它剜出來丟掉。你只有一隻眼進入永生，強如有兩隻眼被丟在地獄的火裏。」</span>
</div>
</div>

## 迷羊的比喻

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="詩篇 91:11; 詩篇 34:7; 希伯來書 1:14"> 「你們要小心，不可輕看這小子裏的一個；我告訴你們，他們的使者在天上，常見我天父的面。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古卷加：11人子來，為要拯救失喪的人。">a</a></sup></span>
<span className="v" id="v12" data-v="12" data-xref="以西結書 34:12; 路加福音 15:4–7; 以西結書 34:16"> 一個人若有一百隻羊，一隻走迷了路，你們的意思如何？他豈不撇下這九十九隻，往山裏去找那隻迷路的羊嗎？</span>
<span className="v" id="v13" data-v="13" data-xref="西番雅書 3:17; 路加福音 15:5–10; 雅各書 2:13"> 若是找着了，我實在告訴你們，他為這一隻羊歡喜，比為那沒有迷路的九十九隻歡喜還大呢！</span>
<span className="v" id="v14" data-v="14" data-xref="約翰福音 17:12; 約翰福音 6:39–40; 彼得後書 3:9"> 你們在天上的父也是這樣，不願意這小子裏失喪一個。」</span>
</div>
</div>

## 如何對待犯過錯的弟兄

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="利未記 19:17; 路加福音 17:3–4; 加拉太書 6:1"> 「倘若你的弟兄得罪你，你就去，趁着只有他和你在一處的時候，指出他的錯來。他若聽你，你便得了你的弟兄；</span>
<span className="v" id="v16" data-v="16" data-xref="申命記 19:15; 哥林多後書 13:1; 約翰福音 8:17"> 他若不聽，你就另外帶一兩個人同去，要憑兩三個人的口作見證，句句都可定準。</span>
<span className="v" id="v17" data-v="17" data-xref="帖撒羅尼迦後書 3:6; 哥林多前書 5:9–7; 帖撒羅尼迦後書 3:14–15"> 若是不聽他們，就告訴教會；若是不聽教會，就看他像外邦人和稅吏一樣。</span>
<span className="v" id="v18" data-v="18" data-xref="馬太福音 16:19; 哥林多後書 2:10; 約翰福音 20:23"> 「我實在告訴你們，凡你們在地上所捆綁的，在天上也要捆綁；凡你們在地上所釋放的，在天上也要釋放。</span>
<span className="v" id="v19" data-v="19" data-xref="馬太福音 7:7; 約翰一書 5:14–16; 馬可福音 11:24"> 我又告訴你們，若是你們中間有兩個人在地上同心合意地求甚麼事，我在天上的父必為他們成全。</span>
<span className="v" id="v20" data-v="20" data-xref="哥林多前書 5:4; 啟示錄 21:3; 馬太福音 28:20"> 因為無論在哪裏，有兩三個人奉我的名聚會，那裏就有我在他們中間。」</span>
</div>
</div>

## 不饒恕人的惡僕

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="路加福音 17:3–4; 馬太福音 18:15"> 那時，彼得進前來，對耶穌說：「主啊，我弟兄得罪我，我當饒恕他幾次呢？到七次可以嗎？」</span>
<span className="v" id="v22" data-v="22" data-xref="歌羅西書 3:13; 馬可福音 11:25; 馬太福音 6:14–15"> 耶穌說：「我對你說，不是到七次，乃是到七十個七次。</span>
<span className="v" id="v23" data-v="23" data-xref="馬太福音 13:24; 羅馬書 14:12; 馬太福音 3:2"> 天國好像一個王要和他僕人算帳。</span>
<span className="v" id="v24" data-v="24" data-xref="詩篇 38:4; 詩篇 130:3–4; 路加福音 16:5"> 才算的時候，有人帶了一個欠一千萬銀子的來。</span>
<span className="v" id="v25" data-v="25" data-xref="列王紀下 4:1; 尼希米記 5:5; 路加福音 7:42"> 因為他沒有甚麼償還之物，主人吩咐把他和他妻子兒女，並一切所有的都賣了償還。</span>
<span className="v" id="v26" data-v="26" data-xref="馬太福音 18:29; 路加福音 7:43; 馬太福音 8:2"> 那僕人就俯伏拜他，說：『主啊，寬容我，將來我都要還清。』</span>
<span className="v" id="v27" data-v="27" data-xref="詩篇 145:8; 尼希米記 9:17; 詩篇 86:15"> 那僕人的主人就動了慈心，把他釋放了，並且免了他的債。</span>
<span className="v" id="v28" data-v="28" data-xref="馬太福音 20:2; 以西結書 45:9; 申命記 15:2"> 「那僕人出來，遇見他的一個同伴欠他十兩銀子，便揪着他，掐住他的喉嚨，說：『你把所欠的還我！』</span>
<span className="v" id="v29" data-v="29" data-xref="馬太福音 18:26; 馬太福音 6:12; 腓利門書 1:18–19"> 他的同伴就俯伏央求他，說：『寬容我吧，將來我必還清。』</span>
<span className="v" id="v30" data-v="30" data-xref="列王紀上 22:27; 列王紀上 21:27–29"> 他不肯，竟去把他下在監裏，等他還了所欠的債。</span>
<span className="v" id="v31" data-v="31" data-xref="羅馬書 12:15; 希伯來書 13:3; 馬可福音 3:5"> 眾同伴看見他所做的事就甚憂愁，去把這事都告訴了主人。</span>
<span className="v" id="v32" data-v="32" data-xref="路加福音 19:22; 馬太福音 25:26; 羅馬書 3:19"> 於是主人叫了他來，對他說：『你這惡奴才！你央求我，我就把你所欠的都免了，</span>
<span className="v" id="v33" data-v="33" data-xref="歌羅西書 3:13; 馬太福音 6:12; 以弗所書 4:32–2"> 你不應當憐恤你的同伴，像我憐恤你嗎？』</span>
<span className="v" id="v34" data-v="34" data-xref="馬太福音 5:25–26; 雅各書 2:13; 路加福音 12:58–59"> 主人就大怒，把他交給掌刑的，等他還清了所欠的債。</span>
<span className="v" id="v35" data-v="35" data-xref="馬太福音 6:14–15; 雅各書 2:13; 路加福音 6:37–38"> 你們各人若不從心裏饒恕你的弟兄，我天父也要這樣待你們了。」</span>
</div>
</div>

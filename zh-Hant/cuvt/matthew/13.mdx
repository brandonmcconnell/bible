## 撒種的比喻

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 8:4–10; 馬太福音 13:1–15; 馬可福音 4:1–12"> 當那一天，耶穌從房子裏出來，坐在海邊。</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 5:3; 馬太福音 4:25; 馬可福音 4:1"> 有許多人到他那裏聚集，他只得上船坐下，眾人都站在岸上。</span>
<span className="v" id="v3" data-v="3" data-xref="馬可福音 4:2–9; 馬可福音 4:13; 詩篇 78:2"> 他用比喻對他們講許多道理，說：「有一個撒種的出去撒種；</span>
<span className="v" id="v4" data-v="4" data-xref="馬太福音 13:18–19"> 撒的時候，有落在路旁的，飛鳥來吃盡了；</span>
<span className="v" id="v5" data-v="5" data-xref="以西結書 11:19; 以西結書 36:26; 撒迦利亞書 7:12"> 有落在土淺石頭地上的，土既不深，發苗最快，</span>
<span className="v" id="v6" data-v="6" data-xref="馬太福音 13:21; 雅各書 1:11–12; 歌羅西書 1:23"> 日頭出來一曬，因為沒有根，就枯乾了；</span>
<span className="v" id="v7" data-v="7" data-xref="馬可福音 4:18–19; 耶利米書 4:3–4; 創世記 3:18"> 有落在荊棘裏的，荊棘長起來，把它擠住了；</span>
<span className="v" id="v8" data-v="8" data-xref="馬太福音 13:23; 路加福音 8:15; 創世記 26:12"> 又有落在好土裏的，就結實，有一百倍的，有六十倍的，有三十倍的。</span>
<span className="v" id="v9" data-v="9" data-xref="啟示錄 2:11; 馬太福音 11:15; 啟示錄 2:7"> 有耳可聽的，就應當聽！」</span>
</div>
</div>

## 用比喻的目的

<div className="bt">
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="馬可福音 4:33–34; 馬可福音 4:10"> 門徒進前來，問耶穌說：「對眾人講話，為甚麼用比喻呢？」</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多前書 2:9–10; 哥林多前書 2:14; 馬太福音 19:11"> 耶穌回答說：「因為天國的奧祕只叫你們知道，不叫他們知道。</span>
<span className="v" id="v12" data-v="12" data-xref="馬太福音 25:29; 馬可福音 4:24–25; 路加福音 8:18"> 凡有的，還要加給他，叫他有餘；凡沒有的，連他所有的，也要奪去。</span>
<span className="v" id="v13" data-v="13" data-xref="以西結書 12:2; 耶利米書 5:21; 以賽亞書 42:18–20"> 所以我用比喻對他們講，是因他們看也看不見，聽也聽不見，也不明白。</span>
<span className="v" id="v14" data-v="14" data-xref="以賽亞書 6:9–10; 以西結書 12:2; 哥林多後書 3:14"> 在他們身上，正應了以賽亞的預言，說：<br /><span className="pl pl-1">你們聽是要聽見，卻不明白；</span><br /><span className="pl pl-1">看是要看見，卻不曉得；</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="以賽亞書 6:10; 馬可福音 4:12; 撒迦利亞書 7:11"> <span className="pl pl-1">因為這百姓油蒙了心，</span><br /><span className="pl pl-1">耳朵發沉，</span><br /><span className="pl pl-1">眼睛閉着，</span><br /><span className="pl pl-1">恐怕眼睛看見，</span><br /><span className="pl pl-1">耳朵聽見，</span><br /><span className="pl pl-1">心裏明白，回轉過來，</span><br /><span className="pl pl-1">我就醫治他們。</span></span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="路加福音 10:23–24; 以弗所書 1:17–18; 馬太福音 16:17"> 「但你們的眼睛是有福的，因為看見了；你們的耳朵也是有福的，因為聽見了。</span>
<span className="v" id="v17" data-v="17" data-xref="約翰福音 8:56; 希伯來書 11:13; 彼得前書 1:10–12"> 我實在告訴你們，從前有許多先知和義人要看你們所看的，卻沒有看見，要聽你們所聽的，卻沒有聽見。」</span>
</div>
</div>

## 解明撒種的比喻

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="馬太福音 13:11–12; 路加福音 8:11–15; 馬可福音 4:13–20"> 「所以，你們當聽這撒種的比喻。</span>
<span className="v" id="v19" data-v="19" data-xref="路加福音 8:11–15; 馬太福音 13:38; 希伯來書 2:1"> 凡聽見天國道理不明白的，那惡者就來，把所撒在他心裏的奪了去；這就是撒在路旁的了。</span>
<span className="v" id="v20" data-v="20" data-xref="以西結書 33:31–32; 詩篇 106:12–13; 約翰福音 5:35"> 撒在石頭地上的，就是人聽了道，當下歡喜領受，</span>
<span className="v" id="v21" data-v="21" data-xref="馬太福音 11:6; 彼得後書 1:8–9; 以弗所書 3:17"> 只因心裏沒有根，不過是暫時的，及至為道遭了患難，或是受了逼迫，立刻就跌倒了。</span>
<span className="v" id="v22" data-v="22" data-xref="提摩太前書 6:17; 路加福音 8:14; 提摩太前書 6:9–10"> 撒在荊棘裏的，就是人聽了道，後來有世上的思慮、錢財的迷惑把道擠住了，不能結實。</span>
<span className="v" id="v23" data-v="23" data-xref="腓立比書 1:11; 馬太福音 12:33; 約翰福音 15:16"> 撒在好地上的，就是人聽道明白了，後來結實，有一百倍的，有六十倍的，有三十倍的。」</span>
</div>
</div>

## 稗子的比喻

<div className="bt">
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="馬太福音 25:1; 馬太福音 13:47; 馬太福音 20:1"> 耶穌又設個比喻對他們說：「天國好像人撒好種在田裏，</span>
<span className="v" id="v25" data-v="25" data-xref="彼得前書 5:8; 彼得後書 2:1; 使徒行傳 20:30–31"> 及至人睡覺的時候，有仇敵來，將稗子撒在麥子裏就走了。</span>
<span className="v" id="v26" data-v="26" data-xref="馬可福音 4:26–29"> 到長苗吐穗的時候，稗子也顯出來。</span>
<span className="v" id="v27" data-v="27" data-xref="羅馬書 16:17; 哥林多後書 6:1; 哥林多後書 5:18–20"> 田主的僕人來告訴他說：『主啊，你不是撒好種在田裏嗎？從哪裏來的稗子呢？』</span>
<span className="v" id="v28" data-v="28" data-xref="哥林多前書 5:3–7; 帖撒羅尼迦前書 5:14; 路加福音 9:49–54"> 主人說：『這是仇敵做的。』僕人說：『你要我們去薅出來嗎？』</span>
<span className="v" id="v29" data-v="29"> 主人說：『不必，恐怕薅稗子，連麥子也拔出來。</span>
<span className="v" id="v30" data-v="30" data-xref="馬太福音 3:12; 提摩太前書 5:24; 哥林多前書 4:5"> 容這兩樣一齊長，等着收割。當收割的時候，我要對收割的人說，先將稗子薅出來，捆成捆，留着燒；惟有麥子要收在倉裏。』」</span>
</div>
</div>

## 芥菜種和麵酵的比喻

<div className="bt">
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="路加福音 13:18–19; 馬太福音 17:20; 馬可福音 4:30–32"> 他又設個比喻對他們說：「天國好像一粒芥菜種，有人拿去種在田裏。</span>
<span className="v" id="v32" data-v="32" data-xref="以西結書 31:6; 但以理書 4:12; 以西結書 17:23–24"> 這原是百種裏最小的，等到長起來，卻比各樣的菜都大，且成了樹，天上的飛鳥來宿在它的枝上。」</span>
<span className="v" id="v33" data-v="33" data-xref="加拉太書 5:9; 哥林多前書 5:6–7; 路加福音 13:21"> 他又對他們講個比喻說：「天國好像麵酵，有婦人拿來，藏在三斗麵裏，直等全團都發起來。」</span>
</div>
</div>

## 用比喻的原因

<div className="bt">
<div className="bp poetry">
<span className="v" id="v34" data-v="34" data-xref="馬可福音 4:33–34; 約翰福音 16:25; 馬太福音 13:13"> 這都是耶穌用比喻對眾人說的話；若不用比喻，就不對他們說甚麼。</span>
<span className="v" id="v35" data-v="35" data-xref="詩篇 78:2; 以弗所書 3:9; 彼得前書 1:20–21"> 這是要應驗先知的話，說：<br /><span className="pl pl-1">我要開口用比喻，</span><br /><span className="pl pl-1">把創世以來所隱藏的事發明出來。</span></span>
</div>
</div>

## 解明稗子的比喻

<div className="bt">
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="約翰福音 16:17–20; 馬太福音 13:11; 馬太福音 9:28"> 當下，耶穌離開眾人，進了房子。他的門徒進前來，說：「請把田間稗子的比喻講給我們聽。」</span>
<span className="v" id="v37" data-v="37" data-xref="哥林多前書 3:5–7; 馬太福音 13:41; 路加福音 10:16"> 他回答說：「那撒好種的就是人子；</span>
<span className="v" id="v38" data-v="38" data-xref="約翰福音 8:44; 腓立比書 3:18–19; 使徒行傳 13:10"> 田地就是世界；好種就是天國之子；稗子就是那惡者之子；</span>
<span className="v" id="v39" data-v="39" data-xref="馬太福音 13:49; 啟示錄 14:15–19; 馬太福音 25:31"> 撒稗子的仇敵就是魔鬼；收割的時候就是世界的末了；收割的人就是天使。</span>
<span className="v" id="v40" data-v="40" data-xref="馬太福音 13:39"> 將稗子薅出來用火焚燒，世界的末了也要如此。</span>
<span className="v" id="v41" data-v="41" data-xref="馬太福音 24:31; 馬太福音 18:7; 彼得後書 2:1–2"> 人子要差遣使者，把一切叫人跌倒的和作惡的，從他國裏挑出來，</span>
<span className="v" id="v42" data-v="42" data-xref="馬太福音 13:50; 路加福音 16:23–24; 馬太福音 8:12"> 丟在火爐裏；在那裏必要哀哭切齒了。</span>
<span className="v" id="v43" data-v="43" data-xref="但以理書 12:3; 馬太福音 11:15; 路加福音 12:32"> 那時，義人在他們父的國裏，要發出光來，像太陽一樣。有耳可聽的，就應當聽！」</span>
</div>
</div>

## 藏寶、尋珠、撒網的比喻

<div className="bt">
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="箴言 2:2–5; 歌羅西書 2:3; 腓立比書 3:7–9"> 「天國好像寶貝藏在地裏，人遇見了就把它藏起來，歡歡喜喜地去變賣一切所有的，買這塊地。</span>
<span className="v" id="v45" data-v="45" data-xref="箴言 3:13–18; 馬太福音 16:26; 馬太福音 13:24"> 天國又好像買賣人尋找好珠子，</span>
<span className="v" id="v46" data-v="46" data-xref="以弗所書 3:8; 路加福音 18:28–30; 箴言 2:4"> 遇見一顆重價的珠子，就去變賣他一切所有的，買了這顆珠子。</span>
<span className="v" id="v47" data-v="47" data-xref="約翰福音 15:6; 提摩太後書 3:2–5; 馬太福音 22:9–10"> 天國又好像網撒在海裏，聚攏各樣水族，</span>
<span className="v" id="v48" data-v="48" data-xref="馬太福音 13:30; 馬太福音 13:40–43; 馬太福音 3:12"> 網既滿了，人就拉上岸來，坐下，揀好的收在器具裏，將不好的丟棄了。</span>
<span className="v" id="v49" data-v="49" data-xref="啟示錄 20:12–15; 馬太福音 24:31; 馬太福音 13:39"> 世界的末了也要這樣。天使要出來，從義人中把惡人分別出來，</span>
<span className="v" id="v50" data-v="50" data-xref="馬太福音 13:42; 馬太福音 8:12; 啟示錄 14:10–11"> 丟在火爐裏；在那裏必要哀哭切齒了。」</span>
</div>
</div>

## 新舊的東西

<div className="bp">

## 拿撒勒人厭棄耶穌

<div className="bt">
<div className="bp">
<span className="v" id="v53" data-v="53" data-xref="馬太福音 7:28; 馬可福音 4:33–35"> 耶穌說完了這些比喻，就離開那裏，</span>
<span className="v" id="v54" data-v="54" data-xref="馬太福音 7:28; 約翰福音 7:15–16; 馬可福音 6:1–6"> 來到自己的家鄉，在會堂裏教訓人，甚至他們都希奇，說：「這人從哪裏有這等智慧和異能呢？</span>
<span className="v" id="v55" data-v="55" data-xref="約翰福音 6:42; 馬可福音 6:3; 路加福音 3:23"> 這不是木匠的兒子嗎？他母親不是叫馬利亞嗎？他弟兄們不是叫雅各、約西<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古卷：約瑟">a</a></sup>、 西門、猶大嗎？</span>
<span className="v" id="v56" data-v="56"> 他妹妹們不是都在我們這裏嗎？這人從哪裏有這一切的事呢？」</span>
<span className="v" id="v57" data-v="57" data-xref="約翰福音 4:44; 馬太福音 11:6; 路加福音 4:24"> 他們就厭棄他<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="厭棄他：原文是因他跌倒">b</a></sup>。耶穌對他們說：「大凡先知，除了本地本家之外，沒有不被人尊敬的。」</span>
<span className="v" id="v58" data-v="58" data-xref="馬可福音 6:5–6; 羅馬書 11:20; 希伯來書 3:12–19"> 耶穌因為他們不信，就在那裏不多行異能了。</span>

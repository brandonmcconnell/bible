## 在伯大尼受膏

<div className="bt">
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="馬可福音 14:3–9; 路加福音 7:37–39; 約翰福音 12:1–8"> 耶穌在伯大尼長大痲瘋的西門家裏，</span>
<span className="v" id="v7" data-v="7" data-xref="約翰福音 12:2–3; 路加福音 7:46; 路加福音 7:37–38"> 有一個女人拿着一玉瓶極貴的香膏來，趁耶穌坐席的時候，澆在他的頭上。</span>
<span className="v" id="v8" data-v="8" data-xref="約翰福音 12:4–6; 馬可福音 14:4; 出埃及記 5:17"> 門徒看見就很不喜悅，說：「何用這樣的枉費呢！</span>
<span className="v" id="v9" data-v="9" data-xref="約翰福音 12:5–6; 馬可福音 14:5; 約書亞記 7:20–21"> 這香膏可以賣許多錢，賙濟窮人。」</span>
<span className="v" id="v10" data-v="10" data-xref="提多書 3:8; 希伯來書 13:21; 提摩太前書 5:10"> 耶穌看出他們的意思，就說：「為甚麼難為這女人呢？她在我身上做的是一件美事。</span>
<span className="v" id="v11" data-v="11" data-xref="申命記 15:11; 馬可福音 14:7; 約翰福音 12:8"> 因為常有窮人和你們同在；只是你們不常有我。</span>
<span className="v" id="v12" data-v="12" data-xref="馬可福音 14:8; 約翰福音 12:7; 馬可福音 16:1"> 她將這香膏澆在我身上是為我安葬做的。</span>
<span className="v" id="v13" data-v="13" data-xref="馬可福音 14:9; 馬太福音 24:14; 詩篇 112:6"> 我實在告訴你們，普天之下，無論在甚麼地方傳這福音，也要述說這女人所行的，作個紀念。」</span>
</div>
</div>

## 和門徒同度逾越節

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="路加福音 22:7–13; 馬可福音 14:12–16; 出埃及記 12:18–20"> 除酵節的第一天，門徒來問耶穌說：「你吃逾越節的筵席，要我們在哪裏給你預備？」</span>
<span className="v" id="v18" data-v="18" data-xref="馬可福音 14:13–16; 約翰福音 7:6; 約翰福音 17:1"> 耶穌說：「你們進城去，到某人那裏，對他說：『夫子說：我的時候快到了，我與門徒要在你家裏守逾越節。』」</span>
<span className="v" id="v19" data-v="19" data-xref="約翰福音 2:5; 約翰福音 15:14; 馬太福音 21:6"> 門徒遵着耶穌所吩咐的就去預備了逾越節的筵席。</span>
<span className="v" id="v20" data-v="20" data-xref="馬可福音 14:17–21; 約翰福音 13:21; 路加福音 22:14–16"> 到了晚上，耶穌和十二個門徒坐席。</span>
<span className="v" id="v21" data-v="21" data-xref="約翰福音 13:21; 希伯來書 4:13; 約翰福音 6:70–71"> 正吃的時候，耶穌說：「我實在告訴你們，你們中間有一個人要賣我了。」</span>
<span className="v" id="v22" data-v="22" data-xref="約翰福音 13:22–25; 路加福音 22:23; 馬可福音 14:19–20"> 他們就甚憂愁，一個一個地問他說：「主，是我嗎？」</span>
<span className="v" id="v23" data-v="23" data-xref="約翰福音 13:18; 詩篇 41:9; 約翰福音 13:26–28"> 耶穌回答說：「同我蘸手在盤子裏的，就是他要賣我。</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行傳 26:22–23; 路加福音 24:46; 馬太福音 18:7"> 人子必要去世，正如經上指着他所寫的；但賣人子的人有禍了！那人不生在世上倒好。」</span>
<span className="v" id="v25" data-v="25" data-xref="馬太福音 26:64; 馬太福音 27:11; 路加福音 22:70"> 賣耶穌的猶大問他說：「拉比，是我嗎？」耶穌說：「你說的是。」</span>
</div>
</div>

## 在客西馬尼禱告

<div className="bt">
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="馬可福音 14:32–42; 馬太福音 26:42; 路加福音 22:39–46"> 耶穌同門徒來到一個地方，名叫客西馬尼，就對他們說：「你們坐在這裏，等我到那邊去禱告。」</span>
<span className="v" id="v37" data-v="37" data-xref="馬太福音 4:21; 馬太福音 17:1; 馬可福音 5:37"> 於是帶着彼得和西庇太的兩個兒子同去，就憂愁起來，極其難過，</span>
<span className="v" id="v38" data-v="38" data-xref="約翰福音 12:27; 彼得前書 3:18; 彼得前書 2:24"> 便對他們說：「我心裏甚是憂傷，幾乎要死；你們在這裏等候，和我一同警醒。」</span>
<span className="v" id="v39" data-v="39" data-xref="約翰福音 6:38; 腓立比書 2:8; 路加福音 22:41–42"> 他就稍往前走，俯伏在地，禱告說：「我父啊，倘若可行，求你叫這杯離開我。然而，不要照我的意思，只要照你的意思。」</span>
<span className="v" id="v40" data-v="40" data-xref="馬可福音 14:37; 路加福音 22:45; 馬太福音 26:43"> 來到門徒那裏，見他們睡着了，就對彼得說：「怎麼樣？你們不能同我警醒片時嗎？</span>
<span className="v" id="v41" data-v="41" data-xref="馬可福音 14:38; 路加福音 22:46; 以弗所書 6:18"> 總要警醒禱告，免得入了迷惑。你們心靈固然願意，肉體卻軟弱了。」</span>
<span className="v" id="v42" data-v="42" data-xref="馬太福音 26:39; 馬可福音 14:39–40; 希伯來書 4:15"> 第二次又去禱告說：「我父啊，這杯若不能離開我，必要我喝，就願你的意旨成全。」</span>
<span className="v" id="v43" data-v="43" data-xref="路加福音 9:32; 羅馬書 13:1; 箴言 23:34"> 又來，見他們睡着了，因為他們的眼睛困倦。</span>
<span className="v" id="v44" data-v="44" data-xref="哥林多後書 12:8; 路加福音 18:1; 馬太福音 6:7"> 耶穌又離開他們去了。第三次禱告，說的話還是與先前一樣。</span>
<span className="v" id="v45" data-v="45" data-xref="約翰福音 13:1; 約翰福音 12:27; 馬可福音 14:41–42"> 於是來到門徒那裏，對他們說：「現在你們仍然睡覺安歇吧<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="吧：或譯嗎？">a</a></sup>！時候到了，人子被賣在罪人手裏了。</span>
<span className="v" id="v46" data-v="46" data-xref="路加福音 9:51; 約翰福音 14:31; 撒母耳記上 17:48"> 起來！我們走吧。看哪，賣我的人近了！」</span>
</div>
</div>

## 耶穌被捕

<div className="bt">
<div className="bp">
<span className="v" id="v47" data-v="47" data-xref="使徒行傳 1:16; 馬太福音 26:55; 馬可福音 14:43–50"> 說話之間，那十二個門徒裏的猶大來了，並有許多人帶着刀棒，從祭司長和民間的長老那裏與他同來。</span>
<span className="v" id="v48" data-v="48" data-xref="詩篇 55:20–21; 詩篇 28:3; 撒母耳記下 3:27"> 那賣耶穌的給了他們一個暗號，說：「我與誰親嘴，誰就是他。你們可以拿住他。」</span>
<span className="v" id="v49" data-v="49" data-xref="馬太福音 26:25; 帖撒羅尼迦前書 5:26; 箴言 27:6"> 猶大隨即到耶穌跟前，說：「請拉比安」，就與他親嘴。</span>
<span className="v" id="v50" data-v="50" data-xref="馬太福音 20:13; 馬太福音 22:12; 詩篇 41:9"> 耶穌對他說：「朋友，你來要做的事，就做吧。」於是那些人上前，下手拿住耶穌。</span>
<span className="v" id="v51" data-v="51" data-xref="約翰福音 18:36; 馬可福音 14:47; 哥林多後書 10:4"> 有跟隨耶穌的一個人伸手拔出刀來，將大祭司的僕人砍了一刀，削掉了他一個耳朵。</span>
<span className="v" id="v52" data-v="52" data-xref="啟示錄 13:10; 創世記 9:6; 羅馬書 12:19"> 耶穌對他說：「收刀入鞘吧！凡動刀的，必死在刀下。</span>
<span className="v" id="v53" data-v="53" data-xref="列王紀下 6:17; 馬太福音 4:11; 但以理書 7:10"> 你想，我不能求我父現在為我差遣十二營多天使來嗎？</span>
<span className="v" id="v54" data-v="54" data-xref="撒迦利亞書 13:7; 馬太福音 26:24; 使徒行傳 1:16"> 若是這樣，經上所說，事情必須如此的話怎麼應驗呢？」</span>
<span className="v" id="v55" data-v="55" data-xref="馬可福音 12:35; 約翰福音 8:2; 路加福音 22:52–53"> 當時，耶穌對眾人說：「你們帶着刀棒出來拿我，如同拿強盜嗎？我天天坐在殿裏教訓人，你們並沒有拿我。</span>
<span className="v" id="v56" data-v="56" data-xref="撒迦利亞書 13:7; 約翰福音 16:32; 馬可福音 14:50–52"> 但這一切的事成就了，為要應驗先知書上的話。」當下，門徒都離開他，逃走了。</span>
</div>
</div>

## 耶穌在公會裏受審

<div className="bt">
<div className="bp">
<span className="v" id="v57" data-v="57" data-xref="馬太福音 26:3; 馬可福音 14:53–65; 詩篇 56:5–6"> 拿耶穌的人把他帶到大祭司該亞法那裏去；文士和長老已經在那裏聚會。</span>
<span className="v" id="v58" data-v="58" data-xref="約翰福音 7:32; 約翰福音 18:15–16; 約翰福音 18:25"> 彼得遠遠地跟着耶穌，直到大祭司的院子，進到裏面，就和差役同坐，要看這事到底怎樣。</span>
<span className="v" id="v59" data-v="59" data-xref="使徒行傳 6:11–13; 申命記 19:16–21; 馬可福音 14:55–56"> 祭司長和全公會尋找假見證控告耶穌，要治死他。</span>
<span className="v" id="v60" data-v="60" data-xref="申命記 19:15; 詩篇 35:11; 詩篇 27:12"> 雖有好些人來作假見證，總得不着實據。末後有兩個人前來，說：</span>
<span className="v" id="v61" data-v="61" data-xref="約翰福音 2:19–21; 馬太福音 27:40; 馬可福音 15:29"> 「這個人曾說：『我能拆毀上帝的殿，三日內又建造起來。』」</span>
<span className="v" id="v62" data-v="62" data-xref="約翰福音 19:9–11; 約翰福音 18:19–24; 馬可福音 14:60"> 大祭司就站起來，對耶穌說：「你甚麼都不回答嗎？這些人作見證告你的是甚麼呢？」</span>
<span className="v" id="v63" data-v="63" data-xref="利未記 5:1; 馬太福音 16:16; 以賽亞書 53:7"> 耶穌卻不言語。大祭司對他說：「我指着永生上帝叫你起誓告訴我們，你是上帝的兒子基督不是？」</span>
<span className="v" id="v64" data-v="64" data-xref="但以理書 7:13; 馬可福音 14:62; 詩篇 110:1"> 耶穌對他說：「你說的是。然而，我告訴你們，後來你們要看見人子坐在那權能者的右邊，駕着天上的雲降臨。」</span>

<span className="v" id="v66" data-v="66" data-xref="約翰福音 19:7; 使徒行傳 7:52; 利未記 24:11–16"> 你們的意見如何？」他們回答說：「他是該死的。」</span>
<span className="v" id="v67" data-v="67" data-xref="以賽亞書 50:6; 以賽亞書 53:3; 馬太福音 27:30"> 他們就吐唾沫在他臉上，用拳頭打他，也有用手掌打他的，說：</span>
<span className="v" id="v68" data-v="68" data-xref="路加福音 22:63–65; 馬可福音 14:65; 彼得前書 2:4–8"> 「基督啊！你是先知，告訴我們打你的是誰？」</span>
</div>

## 彼得三次不認主

<div className="bt">

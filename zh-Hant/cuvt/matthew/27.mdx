## 耶穌被交給彼拉多

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="馬可福音 15:1; 約翰福音 18:28; 彌迦書 2:1"> 到了早晨，眾祭司長和民間的長老大家商議要治死耶穌，</span>
<span className="v" id="v2" data-v="2" data-xref="馬太福音 20:19; 使徒行傳 3:13; 提摩太前書 6:13"> 就把他捆綁，解去，交給巡撫彼拉多。</span>

## 猶大的死

<div className="bt">
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="哥林多後書 7:10; 路加福音 22:47–48; 約伯記 20:15–29"> 這時候，賣耶穌的猶大看見耶穌已經定了罪，就後悔，把那三十塊錢拿回來給祭司長和長老，說：</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳記上 15:30; 提多書 1:16; 使徒行傳 18:15–17"> 「我賣了無辜之人的血是有罪了。」他們說：「那與我們有甚麼相干？你自己承當吧！」</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行傳 1:18–19; 撒母耳記下 17:23; 列王紀上 16:18"> 猶大就把那銀錢丟在殿裏，出去吊死了。</span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 6:7–9; 申命記 23:18; 以賽亞書 61:8"> 祭司長拾起銀錢來，說：「這是血價，不可放在庫裏。」</span>
<span className="v" id="v7" data-v="7"> 他們商議，就用那銀錢買了窯戶的一塊田，為要埋葬外鄉人。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行傳 1:19; 馬太福音 28:15; 約書亞記 4:9"> 所以那塊田直到今日還叫做「血田」。</span>
<span className="v" id="v9" data-v="9" data-xref="撒迦利亞書 11:12–13; 馬太福音 1:22; 利未記 27:2–7"> 這就應了先知耶利米的話，說：「他們用那三十塊錢，就是被估定之人的價錢，是以色列人中所估定的，</span>
<span className="v" id="v10" data-v="10" data-xref="撒迦利亞書 11:13"> 買了窯戶的一塊田；這是照着主所吩咐我的。」</span>
</div>
</div>

## 耶穌在彼拉多面前受審

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="路加福音 23:2–3; 馬可福音 15:2–5; 馬太福音 26:25"> 耶穌站在巡撫面前；巡撫問他說：「你是猶太人的王嗎？」耶穌說：「你說的是。」</span>
<span className="v" id="v12" data-v="12" data-xref="馬太福音 26:63; 以賽亞書 53:7; 馬太福音 27:14"> 他被祭司長和長老控告的時候，甚麼都不回答。</span>
<span className="v" id="v13" data-v="13" data-xref="馬太福音 26:62; 約翰福音 18:35; 使徒行傳 22:24"> 彼拉多就對他說：「他們作見證告你這麼多的事，你沒有聽見嗎？」</span>
<span className="v" id="v14" data-v="14" data-xref="以賽亞書 8:18; 詩篇 71:7; 哥林多前書 4:9"> 耶穌仍不回答，連一句話也不說，以致巡撫甚覺希奇。</span>
</div>
</div>

## 耶穌被判死刑

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="約翰福音 18:38–40; 路加福音 23:16; 約翰福音 19:16"> 巡撫有一個常例，每逢這節期，隨眾人所要的釋放一個囚犯給他們。</span>
<span className="v" id="v16" data-v="16" data-xref="馬可福音 15:7; 使徒行傳 3:14; 路加福音 23:25"> 當時有一個出名的囚犯叫巴拉巴。</span>
<span className="v" id="v17" data-v="17" data-xref="約翰福音 19:15; 列王紀上 18:21; 馬可福音 15:9–12"> 眾人聚集的時候，彼拉多就對他們說：「你們要我釋放哪一個給你們？是巴拉巴呢？是稱為基督的耶穌呢？」</span>
<span className="v" id="v18" data-v="18" data-xref="箴言 27:4; 使徒行傳 5:17; 馬可福音 15:10"> 巡撫原知道他們是因為嫉妒才把他解了來。</span>
<span className="v" id="v19" data-v="19" data-xref="撒迦利亞書 9:9; 箴言 29:1; 馬太福音 27:24"> 正坐堂的時候，他的夫人打發人來說：「這義人的事，你一點不可管，因為我今天在夢中為他受了許多的苦。」</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行傳 3:14–15; 約翰福音 19:15–16; 約翰福音 18:40"> 祭司長和長老挑唆眾人，求釋放巴拉巴，除滅耶穌。</span>
<span className="v" id="v21" data-v="21"> 巡撫對眾人說：「這兩個人，你們要我釋放哪一個給你們呢？」他們說：「巴拉巴。」</span>
<span className="v" id="v22" data-v="22" data-xref="以賽亞書 53:2–3; 以賽亞書 49:7; 使徒行傳 13:38"> 彼拉多說：「這樣，那稱為基督的耶穌我怎麼辦他呢？」他們都說：「把他釘十字架！」</span>
<span className="v" id="v23" data-v="23" data-xref="創世記 37:18–19; 使徒行傳 7:57; 使徒行傳 23:12–15"> 巡撫說：「為甚麼呢？他做了甚麼惡事呢？」他們便極力地喊着說：「把他釘十字架！」</span>
<span className="v" id="v24" data-v="24" data-xref="馬太福音 27:4; 詩篇 26:6; 哥林多後書 5:21"> 彼拉多見說也無濟於事，反要生亂，就拿水在眾人面前洗手，說：「流這義人的血，罪不在我，你們承當吧。」</span>
<span className="v" id="v25" data-v="25" data-xref="約書亞記 2:19; 使徒行傳 5:28; 使徒行傳 7:52"> 眾人都回答說：「他的血歸到我們和我們的子孫身上。」</span>
<span className="v" id="v26" data-v="26" data-xref="以賽亞書 53:5; 約翰福音 19:1; 馬可福音 15:15"> 於是彼拉多釋放巴拉巴給他們，把耶穌鞭打了，交給人釘十字架。</span>
</div>
</div>

## 兵丁戲弄耶穌

<div className="bt">
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="約翰福音 18:28; 約翰福音 18:33; 使徒行傳 10:1"> 巡撫的兵就把耶穌帶進衙門，叫全營的兵都聚集在他那裏。</span>
<span className="v" id="v28" data-v="28" data-xref="馬可福音 15:17; 約翰福音 19:2–5; 路加福音 23:11"> 他們給他脫了衣服，穿上一件朱紅色袍子，</span>
<span className="v" id="v29" data-v="29" data-xref="以賽亞書 53:3; 馬太福音 20:19; 詩篇 69:19–20"> 用荊棘編做冠冕，戴在他頭上，拿一根葦子放在他右手裏，跪在他面前，戲弄他，說：「恭喜，猶太人的王啊！」</span>
<span className="v" id="v30" data-v="30" data-xref="以賽亞書 50:6; 馬太福音 26:67; 以賽亞書 53:7"> 又吐唾沫在他臉上，拿葦子打他的頭。</span>
<span className="v" id="v31" data-v="31" data-xref="以賽亞書 53:7; 列王紀上 21:13; 列王紀上 21:10"> 戲弄完了，就給他脫了袍子，仍穿上他自己的衣服，帶他出去，要釘十字架。</span>
</div>
</div>

## 耶穌被釘十字架

<div className="bt">
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="馬可福音 15:21; 馬太福音 16:24; 路加福音 23:26"> 他們出來的時候，遇見一個古利奈人，名叫西門，就勉強他同去，好背着耶穌的十字架。</span>
<span className="v" id="v33" data-v="33" data-xref="約翰福音 19:17–19; 馬可福音 15:22–32; 馬可福音 15:34"> 到了一個地方名叫各各他，意思就是「髑髏地」。</span>
<span className="v" id="v34" data-v="34" data-xref="詩篇 69:21; 馬可福音 15:23; 馬太福音 27:48"> 兵丁拿苦膽調和的酒給耶穌喝；他嘗了，就不肯喝。</span>
<span className="v" id="v35" data-v="35" data-xref="詩篇 22:18; 馬可福音 15:24–32; 路加福音 23:34"> 他們既將他釘在十字架上，就拈鬮分他的衣服，</span>
<span className="v" id="v36" data-v="36" data-xref="馬太福音 27:54; 馬可福音 15:44; 馬可福音 15:39"> 又坐在那裏看守他。</span>
<span className="v" id="v37" data-v="37" data-xref="路加福音 23:38; 約翰福音 19:19–22; 馬可福音 15:26"> 在他頭以上安一個牌子，寫着他的罪狀，說：「這是猶太人的王耶穌。」</span>
<span className="v" id="v38" data-v="38" data-xref="約翰福音 19:18; 路加福音 23:39–43; 以賽亞書 53:12"> 當時，有兩個強盜和他同釘十字架，一個在右邊，一個在左邊。</span>
<span className="v" id="v39" data-v="39" data-xref="詩篇 109:25; 耶利米哀歌 1:12; 詩篇 69:7–12"> 從那裏經過的人譏誚他，搖着頭，說：</span>
<span className="v" id="v40" data-v="40" data-xref="馬太福音 26:61; 馬太福音 4:6; 馬太福音 4:3"> 「你這拆毀聖殿、三日又建造起來的，可以救自己吧！你如果是上帝的兒子，就從十字架上下來吧！」</span>
<span className="v" id="v41" data-v="41" data-xref="詩篇 35:26; 以賽亞書 28:22; 詩篇 22:12–13"> 祭司長和文士並長老也是這樣戲弄他，說：</span>
<span className="v" id="v42" data-v="42" data-xref="約翰福音 1:49; 馬太福音 27:37; 使徒行傳 4:14"> 「他救了別人，不能救自己。他是以色列的王，現在可以從十字架上下來，我們就信他。</span>
<span className="v" id="v43" data-v="43" data-xref="詩篇 22:8; 約翰福音 10:36; 以賽亞書 37:10"> 他倚靠上帝，上帝若喜悅他，現在可以救他；因為他曾說：『我是上帝的兒子。』」</span>
<span className="v" id="v44" data-v="44" data-xref="馬太福音 27:38; 馬可福音 15:32; 路加福音 23:39–43"> 那和他同釘的強盜也是這樣地譏誚他。</span>
</div>
</div>

## 耶穌的死

<div className="bt">
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="阿摩司書 8:9; 馬可福音 15:33–34; 路加福音 23:44–45"> 從午正到申初，遍地都黑暗了。</span>
<span className="v" id="v46" data-v="46" data-xref="詩篇 22:1; 希伯來書 5:7; 以賽亞書 53:10"> 約在申初，耶穌大聲喊着說：「以利！以利！拉馬撒巴各大尼？」就是說：「我的上帝！我的上帝！為甚麼離棄我？」</span>
<span className="v" id="v47" data-v="47" data-xref="瑪拉基書 4:5; 馬可福音 15:35–36; 馬太福音 11:14"> 站在那裏的人，有的聽見就說：「這個人呼叫以利亞呢！」</span>
<span className="v" id="v48" data-v="48" data-xref="詩篇 69:21; 馬太福音 27:34; 路加福音 23:36"> 內中有一個人趕緊跑去，拿海絨蘸滿了醋，綁在葦子上，送給他喝。</span>
<span className="v" id="v49" data-v="49"> 其餘的人說：「且等着，看以利亞來救他不來。」</span>
<span className="v" id="v50" data-v="50" data-xref="約翰福音 19:30; 以賽亞書 53:9–12; 詩篇 22:14–15"> 耶穌又大聲喊叫，氣就斷了。</span>
<span className="v" id="v51" data-v="51" data-xref="希伯來書 10:19–22; 馬可福音 15:38; 希伯來書 6:19"> 忽然，殿裏的幔子從上到下裂為兩半，地也震動，磐石也崩裂，</span>
<span className="v" id="v52" data-v="52" data-xref="以賽亞書 26:19; 帖撒羅尼迦前書 4:14; 哥林多前書 15:20"> 墳墓也開了，已睡聖徒的身體多有起來的。</span>
<span className="v" id="v53" data-v="53" data-xref="啟示錄 11:2; 以賽亞書 48:2; 啟示錄 21:2"> 到耶穌復活以後，他們從墳墓裏出來，進了聖城，向許多人顯現。</span>
<span className="v" id="v54" data-v="54" data-xref="馬太福音 27:36; 馬可福音 15:39; 馬太福音 27:43"> 百夫長和一同看守耶穌的人看見地震並所經歷的事，就極其害怕，說：「這真是上帝的兒子了！」</span>
<span className="v" id="v55" data-v="55" data-xref="路加福音 8:2–3; 路加福音 23:48–49; 約翰福音 19:25–27"> 有好些婦女在那裏，遠遠地觀看；她們是從加利利跟隨耶穌來服事他的。</span>
<span className="v" id="v56" data-v="56" data-xref="約翰福音 19:25; 馬可福音 15:47–1; 馬太福音 28:1"> 內中有抹大拉的馬利亞，又有雅各和約西的母親馬利亞，並有西庇太兩個兒子的母親。</span>
</div>
</div>

## 耶穌的安葬

<div className="bt">
<div className="bp">
<span className="v" id="v57" data-v="57" data-xref="約翰福音 19:38–42; 馬可福音 15:42–47; 路加福音 23:50–56"> 到了晚上，有一個財主，名叫約瑟，是亞利馬太來的，他也是耶穌的門徒。</span>
<span className="v" id="v58" data-v="58" data-xref="路加福音 23:52–53; 馬可福音 15:44–46"> 這人去見彼拉多，求耶穌的身體；彼拉多就吩咐給他。</span>
<span className="v" id="v59" data-v="59"> 約瑟取了身體，用乾淨細麻布裹好，</span>
<span className="v" id="v60" data-v="60" data-xref="以賽亞書 53:9; 馬太福音 28:2; 馬太福音 27:66"> 安放在自己的新墳墓裏，就是他鑿在磐石裏的。他又把大石頭滾到墓門口，就去了。</span>
<span className="v" id="v61" data-v="61" data-xref="馬太福音 28:1; 馬太福音 27:56"> 有抹大拉的馬利亞和那個馬利亞在那裏，對着墳墓坐着。</span>
</div>
</div>

## 封石妥守

<div className="bt">
<div className="bp">
<span className="v" id="v62" data-v="62" data-xref="馬可福音 15:42; 約翰福音 19:14; 約翰福音 19:42"> 次日，就是預備日的第二天，祭司長和法利賽人聚集來見彼拉多，說：</span>
<span className="v" id="v63" data-v="63" data-xref="路加福音 9:22; 馬太福音 16:21; 約翰福音 2:19"> 「大人，我們記得那誘惑人的還活着的時候曾說：『三日後我要復活。』</span>
<span className="v" id="v64" data-v="64" data-xref="馬太福音 28:13; 馬太福音 12:45"> 因此，請吩咐人將墳墓把守妥當，直到第三日，恐怕他的門徒來，把他偷了去，就告訴百姓說：『他從死裏復活了。』這樣，那後來的迷惑比先前的更利害了！」</span>
<span className="v" id="v65" data-v="65" data-xref="馬太福音 27:66; 馬太福音 28:11–15; 箴言 21:30"> 彼拉多說：「你們有看守的兵，去吧！盡你們所能的把守妥當。」</span>
<span className="v" id="v66" data-v="66" data-xref="但以理書 6:17; 馬太福音 27:60; 提摩太後書 2:19"> 他們就帶着看守的兵同去，封了石頭，將墳墓把守妥當。</span>
</div>

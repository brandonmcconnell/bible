## 對別人的本分

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="利未記 19:32; 彼得前書 5:5–6; 提多書 2:2"> 不可嚴責老年人，只要勸他如同父親；勸少年人如同弟兄；</span>
<span className="v" id="v2" data-v="2" data-xref="提摩太前書 4:12; 馬太福音 12:50; 腓立比書 4:8"> 勸老年婦女如同母親；勸少年婦女如同姊妹；總要清清潔潔的。</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 27:19; 使徒行傳 6:1; 申命記 10:18"> 要尊敬那真為寡婦的。</span>
<span className="v" id="v4" data-v="4" data-xref="以弗所書 6:1–3; 約翰福音 19:26–27; 馬太福音 15:4–6"> 若寡婦有兒女，或有孫子孫女，便叫他們先在自己家中學着行孝，報答親恩，因為這在上帝面前是可悅納的。</span>
<span className="v" id="v5" data-v="5" data-xref="提摩太前書 5:3; 路加福音 2:37; 哥林多前書 7:32"> 那獨居無靠、真為寡婦的，是仰賴上帝，晝夜不住地祈求禱告。</span>
<span className="v" id="v6" data-v="6" data-xref="雅各書 5:5; 啟示錄 18:7; 路加福音 15:24"> 但那好宴樂的寡婦正活着的時候也是死的。</span>
<span className="v" id="v7" data-v="7" data-xref="提摩太前書 4:11; 提多書 2:15; 提摩太後書 4:1"> 這些事你要囑咐她們，叫她們無可指責。</span>
<span className="v" id="v8" data-v="8" data-xref="加拉太書 6:10; 哥林多後書 12:14; 路加福音 11:11–13"> 人若不看顧親屬，就是背了真道，比不信的人還不好，不看顧自己家裏的人，更是如此。</span>
<span className="v" id="v9" data-v="9" data-xref="提摩太前書 3:2; 提摩太前書 5:11; 路加福音 2:36–37"> 寡婦記在冊子上，必須年紀到六十歲，從來只作一個丈夫的妻子，</span>
<span className="v" id="v10" data-v="10" data-xref="提摩太前書 6:18; 提多書 3:8; 使徒行傳 9:36"> 又有行善的名聲，就如養育兒女，接待遠人，洗聖徒的腳，救濟遭難的人，竭力行各樣善事。</span>
<span className="v" id="v11" data-v="11" data-xref="提摩太前書 5:14; 何西阿書 13:6; 雅各書 5:5"> 至於年輕的寡婦，就可以辭她；因為她們的情慾發動，違背基督的時候就想要嫁人。</span>
<span className="v" id="v12" data-v="12" data-xref="加拉太書 1:6; 雅各書 3:1; 哥林多前書 11:34"> 她們被定罪，是因廢棄了當初所許的願；</span>
<span className="v" id="v13" data-v="13" data-xref="箴言 20:19; 帖撒羅尼迦後書 3:6–11; 使徒行傳 20:30"> 並且她們又習慣懶惰，挨家閒遊；不但是懶惰，又說長道短，好管閒事，說些不當說的話。</span>
<span className="v" id="v14" data-v="14" data-xref="提多書 2:5; 提摩太前書 6:1; 提多書 2:8"> 所以我願意年輕的寡婦嫁人，生養兒女，治理家務，不給敵人辱罵的把柄。</span>
<span className="v" id="v15" data-v="15" data-xref="彼得後書 2:2; 猶大書 1:4–5; 彼得後書 2:20–22"> 因為已經有轉去隨從撒但的。</span>
<span className="v" id="v16" data-v="16" data-xref="提摩太前書 5:3–5; 提摩太前書 5:8"> 信主的婦女，若家中有寡婦，自己就當救濟她們，不可累着教會，好使教會能救濟那真無倚靠的寡婦。</span>
<span className="v" id="v17" data-v="17" data-xref="希伯來書 13:17; 帖撒羅尼迦前書 5:12–13; 加拉太書 6:6"> 那善於管理教會的長老，當以為配受加倍的敬奉；那勞苦傳道教導人的，更當如此。</span>
<span className="v" id="v18" data-v="18" data-xref="申命記 25:4; 哥林多前書 9:14; 哥林多前書 9:7–10"> 因為經上說：「牛在場上踹穀的時候，不可籠住牠的嘴」；又說：「工人得工價是應當的。」</span>
<span className="v" id="v19" data-v="19" data-xref="馬太福音 18:16; 申命記 19:15; 哥林多後書 13:1"> 控告長老的呈子，非有兩三個見證就不要收。</span>
<span className="v" id="v20" data-v="20" data-xref="提摩太後書 4:2; 提多書 1:13; 提摩太前書 1:20"> 犯罪的人，當在眾人面前責備他，叫其餘的人也可以懼怕。</span>
<span className="v" id="v21" data-v="21" data-xref="彼得後書 2:4; 提摩太後書 4:1; 提摩太前書 6:13"> 我在上帝和基督耶穌並蒙揀選的天使面前囑咐你：要遵守這些話，不可存成見，行事也不可有偏心。</span>
<span className="v" id="v22" data-v="22" data-xref="以弗所書 5:11; 提摩太前書 3:10; 提摩太前書 3:6"> 給人行按手的禮，不可急促；不要在別人的罪上有分，要保守自己清潔。</span>
<span className="v" id="v23" data-v="23" data-xref="詩篇 104:15; 箴言 31:4–7; 提摩太前書 4:4"> 因你胃口不清，屢次患病，再不要照常喝水，可以稍微用點酒。</span>
<span className="v" id="v24" data-v="24" data-xref="提摩太後書 4:10; 使徒行傳 8:18; 加拉太書 5:19–21"> 有些人的罪是明顯的，如同先到審判案前；有些人的罪是隨後跟了去的。</span>
<span className="v" id="v25" data-v="25" data-xref="箴言 10:9; 路加福音 11:33; 詩篇 37:5–6"> 這樣，善行也有明顯的，那不明顯的也不能隱藏。</span>

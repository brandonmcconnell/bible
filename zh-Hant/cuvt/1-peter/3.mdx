## 妻子和丈夫

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歌羅西書 3:18; 以弗所書 5:33; 以弗所書 5:22–24"> 你們作妻子的要順服自己的丈夫；這樣，若有不信從道理的丈夫，他們雖然不聽道，也可以因妻子的品行被感化過來；</span>
<span className="v" id="v2" data-v="2" data-xref="彼得前書 2:12; 彼得前書 1:15; 腓立比書 1:27"> 這正是因看見你們有貞潔的品行和敬畏的心。</span>
<span className="v" id="v3" data-v="3" data-xref="提摩太前書 2:9–10; 羅馬書 12:2; 以賽亞書 3:18–24"> 你們不要以外面的辮頭髮，戴金飾，穿美衣為妝飾，</span>
<span className="v" id="v4" data-v="4" data-xref="歌羅西書 3:12; 撒母耳記上 16:7; 羅馬書 2:29"> 只要以裏面存着長久溫柔、安靜的心為妝飾；這在上帝面前是極寶貴的。</span>
<span className="v" id="v5" data-v="5" data-xref="提多書 2:3–4; 提摩太前書 5:5; 路加福音 2:37"> 因為古時仰賴上帝的聖潔婦人正是以此為妝飾，順服自己的丈夫，</span>
<span className="v" id="v6" data-v="6" data-xref="創世記 18:12; 羅馬書 9:7–9; 以賽亞書 57:11"> 就如撒拉聽從亞伯拉罕，稱他為主。你們若行善，不因恐嚇而害怕，便是撒拉的女兒了。</span>
<span className="v" id="v7" data-v="7" data-xref="歌羅西書 3:19; 創世記 2:23–24; 馬太福音 19:3–9"> 你們作丈夫的也要按情理<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是知識">a</a></sup>和妻子同住；因她比你軟弱<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="比你軟弱：原文作是軟弱的器皿">b</a></sup>，與你一同承受生命之恩的，所以要敬重她。這樣，便叫你們的禱告沒有阻礙。</span>
</div>
</div>

## 為義受苦

<div className="bt">
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="羅馬書 12:10; 以弗所書 4:31–2; 彼得前書 1:22"> 總而言之，你們都要同心，彼此體恤，相愛如弟兄，存慈憐謙卑的心。</span>
<span className="v" id="v9" data-v="9" data-xref="箴言 20:22; 羅馬書 12:17; 羅馬書 12:14"> 不以惡報惡，以辱罵還辱罵，倒要祝福；因你們是為此蒙召，好叫你們承受福氣。</span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 34:12–16; 雅各書 1:26; 彼得前書 2:1"> 因為經上說：<br /><span className="pl pl-1">人若愛生命，</span><br /><span className="pl pl-1">願享美福，</span><br /><span className="pl pl-1">須要禁止舌頭不出惡言，</span><br /><span className="pl pl-1">嘴唇不說詭詐的話；</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="馬太福音 5:9; 詩篇 34:14; 希伯來書 12:14"> <span className="pl pl-1">也要離惡行善，</span><br /><span className="pl pl-1">尋求和睦，一心追趕。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 34:15–16; 約翰福音 9:31; 箴言 15:29"> <span className="pl pl-1">因為，主的眼看顧義人；</span><br /><span className="pl pl-1">主的耳聽他們的祈禱。</span><br /><span className="pl pl-1">惟有行惡的人，主向他們變臉。</span></span>
<span className="v" id="v13" data-v="13" data-xref="箴言 16:7; 羅馬書 8:28; 帖撒羅尼迦前書 5:15"> 你們若是熱心行善，有誰害你們呢？</span>
<span className="v" id="v14" data-v="14" data-xref="馬太福音 10:28; 彼得前書 2:19–20; 馬太福音 5:10–12"> 你們就是為義受苦，也是有福的。不要怕人的威嚇<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="的威嚇：或譯所怕的">c</a></sup>，也不要驚慌；</span>
<span className="v" id="v15" data-v="15" data-xref="歌羅西書 4:6; 提摩太後書 2:25–26; 路加福音 21:14–15"> 只要心裏尊主基督為聖。有人問你們心中盼望的緣由，就要常作準備，以溫柔、敬畏的心回答各人；</span>
<span className="v" id="v16" data-v="16" data-xref="彼得前書 2:12; 希伯來書 13:18; 彼得前書 2:15"> 存着無虧的良心，叫你們在何事上被毀謗，就在何事上可以叫那誣賴你們在基督裏有好品行的人自覺羞愧。</span>
<span className="v" id="v17" data-v="17" data-xref="彼得前書 3:14; 彼得前書 4:19; 馬太福音 26:39"> 上帝的旨意若是叫你們因行善受苦，總強如因行惡受苦。</span>
<span className="v" id="v18" data-v="18" data-xref="希伯來書 9:28; 希伯來書 9:26; 哥林多後書 5:21"> 因基督也曾一次為罪受苦<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="有古卷：受死">d</a></sup>，就是義的代替不義的，為要引我們到上帝面前。按着肉體說，他被治死；按着靈性說，他復活了。</span>
<span className="v" id="v19" data-v="19" data-xref="彼得前書 4:6; 以賽亞書 61:1; 以賽亞書 42:7"> 他藉這靈曾去傳道給那些在監獄裏的靈聽，</span>
<span className="v" id="v20" data-v="20" data-xref="希伯來書 11:7; 彼得後書 2:5; 創世記 6:3"> 就是那從前在挪亞預備方舟、上帝容忍等待的時候，不信從的人。當時進入方舟，藉着水得救的不多，只有八個人。</span>
<span className="v" id="v21" data-v="21" data-xref="馬可福音 16:16; 以西結書 36:25–26; 使徒行傳 2:38"> 這水所表明的洗禮，現在藉着耶穌基督復活也拯救你們；這洗禮本不在乎除掉肉體的污穢，只求在上帝面前有無虧的良心。</span>
<span className="v" id="v22" data-v="22" data-xref="希伯來書 9:24; 希伯來書 12:2; 希伯來書 10:12"> 耶穌已經進入天堂，在上帝的右邊；眾天使和有權柄的，並有能力的，都服從了他。</span>
</div>

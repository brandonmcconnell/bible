## 熱心行善

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="羅馬書 13:1–7; 彼得前書 2:13–17; 傳道書 10:4"> 你要提醒眾人，叫他們順服作官的、掌權的，遵他的命，預備行各樣的善事。</span>
<span className="v" id="v2" data-v="2" data-xref="以弗所書 4:31; 提摩太後書 2:24–25; 以弗所書 4:2"> 不要毀謗，不要爭競，總要和平，向眾人大顯溫柔。</span>
<span className="v" id="v3" data-v="3" data-xref="以弗所書 2:1–3; 羅馬書 6:17; 歌羅西書 1:21"> 我們從前也是無知、悖逆、受迷惑、服事各樣私慾，和宴樂，常存惡毒<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或譯：陰毒">a</a></sup>嫉妒的心，是可恨的，又是彼此相恨。</span>
<span className="v" id="v4" data-v="4" data-xref="以弗所書 2:4–10; 提多書 2:10–11; 提摩太前書 4:10"> 但到了上帝－我們救主的恩慈和他向人所施的慈愛顯明的時候，</span>
<span className="v" id="v5" data-v="5" data-xref="以弗所書 2:8–9; 提摩太後書 1:9; 哥林多前書 6:11"> 他便救了我們；並不是因我們自己所行的義，乃是照他的憐憫，藉着重生的洗和聖靈的更新。</span>
<span className="v" id="v6" data-v="6" data-xref="約珥書 2:28; 羅馬書 5:5; 使徒行傳 10:45"> 聖靈就是上帝藉着耶穌基督－我們救主厚厚澆灌在我們身上的，</span>
<span className="v" id="v7" data-v="7" data-xref="羅馬書 8:17; 提多書 2:11; 哥林多前書 6:11"> 好叫我們因他的恩得稱為義，可以憑着永生的盼望成為後嗣<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或譯：可以憑着盼望承受永生">b</a></sup>。</span>
<span className="v" id="v8" data-v="8" data-xref="提多書 3:14; 提多書 1:9; 詩篇 16:2–3"> 這話是可信的。 我也願你把這些事切切實實地講明，使那些已信上帝的人留心做正經事業<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="或譯：留心行善">c</a></sup>。這都是美事，並且與人有益。</span>
<span className="v" id="v9" data-v="9" data-xref="提摩太後書 2:14; 提摩太後書 2:23; 提摩太前書 4:7"> 要遠避無知的辯論和家譜的空談，以及紛爭，並因律法而起的爭競，因為這都是虛妄無益的。</span>
<span className="v" id="v10" data-v="10" data-xref="羅馬書 16:17; 約翰二書 1:10; 馬太福音 18:15–17"> 分門結黨的人，警戒過一兩次，就要棄絕他。</span>
<span className="v" id="v11" data-v="11" data-xref="希伯來書 10:26; 路加福音 19:22; 馬太福音 25:26–28"> 因為知道這等人已經背道，犯了罪，自己明知不是，還是去做。</span>
</div>
</div>

## 個人的指示和問安

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="提摩太後書 4:9; 提摩太後書 4:12; 哥林多前書 16:8–9"> 我打發亞提馬或是推基古到你那裏去的時候，你要趕緊往尼哥坡里去見我，因為我已經定意在那裏過冬。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行傳 18:24; 馬太福音 22:35; 約翰三書 1:6–8"> 你要趕緊給律師西納和亞波羅送行，叫他們沒有缺乏。</span>
<span className="v" id="v14" data-v="14" data-xref="歌羅西書 1:10; 提多書 3:8; 馬太福音 7:19"> 並且我們的人要學習正經事業<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="或譯：要學習行善">d</a></sup>，預備所需用的，免得不結果子。</span>
<span className="v" id="v15" data-v="15" data-xref="提摩太前書 1:5; 以弗所書 6:23–24; 約翰二書 1:1–2"> 同我在一處的人都問你安。請代問那些因有信心愛我們的人安。願恩惠常與你們眾人同在！</span>
</div>
</div>

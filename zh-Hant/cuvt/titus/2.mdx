## 純正的道理

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="提摩太後書 1:13; 提摩太前書 6:3; 提多書 2:11–14"> 但你所講的總要合乎那純正的道理。</span>
<span className="v" id="v2" data-v="2" data-xref="加拉太書 5:23; 彼得前書 4:7; 帖撒羅尼迦前書 5:8"> 勸老年人要有節制、端莊、自守，在信心、愛心、忍耐上都要純全無疵。</span>
<span className="v" id="v3" data-v="3" data-xref="提多書 2:4; 提摩太前書 3:11; 彼得前書 3:3–5"> 又勸老年婦人，舉止行動要恭敬，不說讒言，不給酒作奴僕，用善道教訓人，</span>
<span className="v" id="v4" data-v="4" data-xref="提摩太前書 5:14; 提摩太前書 5:2; 提摩太前書 5:11"> 好指教少年婦人，愛丈夫，愛兒女，</span>
<span className="v" id="v5" data-v="5" data-xref="箴言 31:10–31; 歌羅西書 3:18; 提摩太前書 5:10"> 謹守，貞潔，料理家務，待人有恩，順服自己的丈夫，免得上帝的道理被毀謗。</span>
<span className="v" id="v6" data-v="6" data-xref="傳道書 12:1; 彼得前書 5:5; 約珥書 2:28"> 又勸少年人要謹守。</span>
<span className="v" id="v7" data-v="7" data-xref="彼得前書 5:3; 提摩太前書 4:12; 哥林多後書 4:2"> 你自己凡事要顯出善行的榜樣；在教訓上要正直、端莊，</span>
<span className="v" id="v8" data-v="8" data-xref="彼得前書 2:12; 彼得前書 2:15; 彼得前書 3:16"> 言語純全，無可指責，叫那反對的人，既無處可說我們的不是，便自覺羞愧。</span>
<span className="v" id="v9" data-v="9" data-xref="彼得前書 2:18–25; 提摩太前書 6:1–2; 歌羅西書 3:22–25"> 勸僕人要順服自己的主人，凡事討他的喜歡，不可頂撞他，</span>
<span className="v" id="v10" data-v="10" data-xref="馬太福音 5:16; 彼得前書 2:12; 約翰二書 1:9"> 不可私拿東西，要顯為忠誠，以致凡事尊榮我們救主－上帝的道。</span>
<span className="v" id="v11" data-v="11" data-xref="以弗所書 2:8; 提摩太前書 2:4; 以賽亞書 45:22"> 因為上帝救眾人的恩典已經顯明出來，</span>
<span className="v" id="v12" data-v="12" data-xref="以西結書 36:27; 馬太福音 16:24; 羅馬書 6:19"> 教訓我們除去不敬虔的心和世俗的情慾，在今世自守、公義、敬虔度日，</span>
<span className="v" id="v13" data-v="13" data-xref="提摩太後書 4:8; 哥林多前書 1:7; 馬太福音 16:27"> 等候所盼望的福，並等候至大的上帝和我們<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或譯：上帝－我們">a</a></sup>救主耶穌基督的榮耀顯現。</span>
<span className="v" id="v14" data-v="14" data-xref="希伯來書 9:14; 以弗所書 2:10; 彼得前書 2:9"> 他為我們捨了自己，要贖我們脫離一切罪惡，又潔淨我們，特作自己的子民，熱心為善。</span>
<span className="v" id="v15" data-v="15" data-xref="提摩太後書 4:2; 提摩太前書 4:12–13; 提多書 1:13"> 這些事你要講明，勸戒人，用各等權柄責備人；不可叫人輕看你。</span>
</div>

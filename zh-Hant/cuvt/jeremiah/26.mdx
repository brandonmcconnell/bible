## 耶利米受審

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歷代志下 36:4–5; 耶利米書 27:1; 列王紀下 23:34–36"> 猶大王約西亞的兒子約雅敬登基的時候，有這話從耶和華臨到耶利米說：</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 4:2; 使徒行傳 20:27; 馬太福音 28:20"> 「耶和華如此說：你站在耶和華殿的院內，對猶大眾城邑的人，就是到耶和華殿來禮拜的，說我所吩咐你的一切話，一字不可刪減。</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米書 36:3; 以賽亞書 1:16–19; 耶利米書 18:7–10"> 或者他們肯聽從，各人回頭離開惡道，使我後悔不將我因他們所行的惡，想要施行的災禍降與他們。</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀上 9:6; 耶利米書 44:10; 以賽亞書 1:20"> 你要對他們說，耶和華如此說：『你們若不聽從我，不遵行我設立在你們面前的律法，</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米書 11:7; 列王紀下 9:7; 耶利米書 7:13"> 不聽我從早起來差遣到你們那裏去我僕人眾先知的話（你們還是沒有聽從），</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米書 24:9; 列王紀下 22:19; 耶利米書 25:18"> 我就必使這殿如示羅，使這城為地上萬國所咒詛的。』」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="耶利米書 5:31; 彌迦書 3:11; 使徒行傳 5:17"> 耶利米在耶和華殿中說的這些話，祭司、先知與眾民都聽見了。</span>
<span className="v" id="v8" data-v="8" data-xref="耶利米哀歌 4:13–14; 使徒行傳 7:52; 耶利米書 18:18"> 耶利米說完了耶和華所吩咐他對眾人說的一切話，祭司、先知與眾民都來抓住他，說：「你必要死！</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行傳 4:17–19; 使徒行傳 19:24–32; 彌迦書 2:6"> 你為何託耶和華的名預言，說這殿必如示羅，這城必變為荒場無人居住呢？」於是眾民都在耶和華的殿中聚集到耶利米那裏。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="耶利米書 36:10; 耶利米書 38:4–6; 耶利米書 37:14–16"> 猶大的首領聽見這事，就從王宮上到耶和華的殿，坐在耶和華殿的新門口。</span>
<span className="v" id="v11" data-v="11" data-xref="耶利米書 38:4; 馬太福音 26:66; 申命記 18:20"> 祭司、先知對首領和眾民說：「這人是該死的；因為他說預言攻擊這城，正如你們親耳所聽見的。」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="使徒行傳 5:29; 耶利米書 26:15; 使徒行傳 4:19"> 耶利米就對眾首領和眾民說：「耶和華差遣我預言，攻擊這殿和這城，說你們所聽見的這一切話。</span>
<span className="v" id="v13" data-v="13" data-xref="約拿書 3:9; 約拿書 4:2; 以賽亞書 1:19"> 現在要改正你們的行動作為，聽從耶和華－你們上帝的話，他就必後悔，不將所說的災禍降與你們。</span>
<span className="v" id="v14" data-v="14" data-xref="約書亞記 9:25; 撒母耳記下 15:26; 耶利米書 38:5"> 至於我，我在你們手中，你們眼看何為善，何為正，就那樣待我吧！</span>
<span className="v" id="v15" data-v="15" data-xref="民數記 35:33; 箴言 6:17; 馬太福音 26:25"> 但你們要確實地知道，若把我治死，就使無辜人的血歸到你們和這城，並其中的居民了；因為耶和華實在差遣我到你們這裏來，將這一切話傳與你們耳中。」</span>
</div>
<div className="bp poetry">
<span className="v" id="v16" data-v="16" data-xref="使徒行傳 5:34–39; 使徒行傳 23:29; 使徒行傳 25:25"> 首領和眾民就對祭司、先知說：「這人是不該死的，因為他是奉耶和華－我們上帝的名向我們說話。」</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行傳 5:34; 彌迦書 1:1"> 國中的長老就有幾個人起來，對聚會的眾民說：</span>
<span className="v" id="v18" data-v="18" data-xref="彌迦書 1:1; 尼希米記 4:2; 撒迦利亞書 8:3"> 「當猶大王希西家的日子，有摩利沙人彌迦對猶大眾人預言說：<br /><span className="pl pl-1">萬軍之耶和華如此說：</span><br /><span className="pl pl-1">錫安必被耕種像一塊田；</span><br /><span className="pl pl-1">耶路撒冷必變為亂堆；</span><br /><span className="pl pl-1">這殿的山必像叢林的高處。</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="出埃及記 32:14; 撒母耳記下 24:16; 以賽亞書 37:15–20"> 猶大王希西家和猶大眾人豈是把他治死呢？希西家豈不是敬畏耶和華、懇求他的恩嗎？耶和華就後悔，不把自己所說的災禍降與他們。若治死這人，我們就作了大惡，自害己命。」<br />（</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳記上 7:2; 約書亞記 9:17; 約書亞記 15:60"> 又有一個人奉耶和華的名說預言，是基列‧耶琳人示瑪雅的兒子烏利亞，他照耶利米的一切話說預言，攻擊這城和這地。</span>
<span className="v" id="v21" data-v="21" data-xref="馬太福音 10:23; 馬太福音 14:5; 耶利米書 36:26"> 約雅敬王和他眾勇士、眾首領聽見了烏利亞的話，王就想要把他治死。烏利亞聽見就懼怕，逃往埃及去了。</span>
<span className="v" id="v22" data-v="22" data-xref="耶利米書 36:12; 列王紀下 22:12; 列王紀下 22:14"> 約雅敬王便打發亞革波的兒子以利拿單，帶領幾個人往埃及去。</span>
<span className="v" id="v23" data-v="23" data-xref="耶利米書 2:30; 啟示錄 11:7; 以西結書 19:6"> 他們就從埃及將烏利亞帶出來，送到約雅敬王那裏；王用刀殺了他，把他的屍首拋在平民的墳地中。）</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="耶利米書 40:5–7; 耶利米書 39:14; 耶利米書 1:18–19"> 然而，沙番的兒子亞希甘保護耶利米，不交在百姓的手中治死他。</span>
</div>
</div>

## 耶利米和約

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華的話臨到耶利米說：</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米書 11:6; 出埃及記 19:5; 歷代志下 29:10"> 「當聽這約的話，告訴猶大人和耶路撒冷的居民，</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 27:26; 申命記 28:15–68; 申命記 29:19–20"> 對他們說，耶和華－以色列的上帝如此說：不聽從這約之話的人必受咒詛。</span>
<span className="v" id="v4" data-v="4" data-xref="利未記 26:12; 耶利米書 7:22–23; 申命記 4:20"> 這約是我將你們列祖從埃及地領出來、脫離鐵爐的那日所吩咐他們的，說：『你們要聽從我的話，照我一切所吩咐的去行。』這樣，你們就作我的子民，我也作你們的上帝；</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 7:12–13; 詩篇 105:9–11; 耶利米書 28:6"> 我好堅定向你們列祖所起的誓，給他們流奶與蜜之地，正如今日一樣。」我就回答說：「耶和華啊，阿們！」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="雅各書 1:22; 羅馬書 2:13; 耶利米書 7:2"> 耶和華對我說：「你要在猶大城邑中和耶路撒冷街市上，宣告這一切話說：你們當聽從遵行這約的話。</span>
<span className="v" id="v7" data-v="7" data-xref="歷代志下 36:15; 以弗所書 4:17; 撒母耳記上 8:9"> 因為我將你們列祖從埃及地領出來的那日，直到今日，都是從早起來，切切誥誡他們說：『你們當聽從我的話。』</span>
<span className="v" id="v8" data-v="8" data-xref="耶利米書 7:24; 耶利米書 7:26; 耶利米書 35:15"> 他們卻不聽從，不側耳而聽，竟隨從自己頑梗的惡心去行。所以我使這約中一切咒詛的話臨到他們身上；這約是我吩咐他們行的，他們卻不去行。」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="何西阿書 6:9; 馬太福音 26:3–4; 彌迦書 3:11"> 耶和華對我說：「在猶大人和耶路撒冷居民中有同謀背叛的事。</span>
<span className="v" id="v10" data-v="10" data-xref="申命記 31:16; 以西結書 16:59; 詩篇 78:8–10"> 他們轉去效法他們的先祖，不肯聽我的話，犯罪作孽，又隨從別神，事奉它。以色列家和猶大家背了我與他們列祖所立的約。」</span>
<span className="v" id="v11" data-v="11" data-xref="以西結書 8:18; 箴言 1:28; 以賽亞書 1:15"> 所以耶和華如此說：「我必使災禍臨到他們，是他們不能逃脫的。他們必向我哀求，我卻不聽。</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米書 2:28; 申命記 32:37; 歷代志下 28:22"> 那時，猶大城邑的人和耶路撒冷的居民要去哀求他們燒香所供奉的神；只是遭難的時候，這些神毫不拯救他們。</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米書 2:28; 列王紀下 23:13; 以賽亞書 2:8"> 猶大啊，你神的數目與你城的數目相等；你為那可恥的巴力所築燒香的壇也與耶路撒冷街道的數目相等。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="耶利米書 7:16; 耶利米書 11:11; 約翰一書 5:16"> 「所以你不要為這百姓祈禱，不要為他們呼求禱告；因為他們遭難向我哀求的時候，我必不應允。</span>
<span className="v" id="v15" data-v="15" data-xref="箴言 2:14; 提多書 1:15; 耶利米書 3:1–2"> 我所親愛的，既行許多淫亂，聖肉也離了你，你在我殿中做甚麼呢？你作惡就喜樂。</span>
<span className="v" id="v16" data-v="16" data-xref="羅馬書 11:17–24; 以賽亞書 27:11; 詩篇 52:8"> 從前耶和華給你起名叫青橄欖樹，又華美又結好果子；如今他用鬨嚷之聲，點火在其上，枝子也被折斷。</span>
<span className="v" id="v17" data-v="17" data-xref="以賽亞書 5:2; 耶利米書 2:21; 耶利米書 12:2"> 原來栽培你的萬軍之耶和華已經說，要降禍攻擊你，是因以色列家和猶大家行惡，向巴力燒香，惹我發怒，是自作自受。」</span>
</div>
</div>

## 殺害耶利米的陰謀

<div className="bt">
<div className="bp poetry">
<span className="v" id="v18" data-v="18" data-xref="撒母耳記上 23:11–12; 列王紀下 6:9–10; 以西結書 8:6–18"> <span className="pl pl-1">耶和華指示我，我就知道；</span><br /><span className="pl pl-1">你將他們所行的給我指明。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="以賽亞書 53:7–8; 耶利米書 20:10; 詩篇 83:4"> <span className="pl pl-1">我卻像柔順的羊羔被牽到宰殺之地；</span><br /><span className="pl pl-1">我並不知道他們設計謀害我，</span><br /><span className="pl pl-1">說：我們把樹連果子都滅了吧！</span><br /><span className="pl pl-1">將他從活人之地剪除，</span><br /><span className="pl pl-1">使他的名不再被紀念。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="耶利米書 20:12; 耶利米書 17:10; 撒母耳記上 16:7"> <span className="pl pl-1">按公義判斷、察驗人肺腑心腸的萬軍之耶和華啊，</span><br /><span className="pl pl-1">我卻要見你在他們身上報仇，</span><br /><span className="pl pl-1">因我將我的案件向你稟明了。</span></span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="耶利米書 20:10; 阿摩司書 2:12; 路加福音 13:33–34"> 所以，耶和華論到尋索你命的亞拿突人如此說：「他們說：你不要奉耶和華的名說預言，免得你死在我們手中。</span>
<span className="v" id="v22" data-v="22" data-xref="耶利米書 18:21; 歷代志下 36:17; 耶利米書 9:21"> 所以萬軍之耶和華如此說：看哪，我必刑罰他們；他們的少年人必被刀劍殺死，他們的兒女必因饑荒滅亡，</span>
<span className="v" id="v23" data-v="23" data-xref="耶利米書 23:12; 彌迦書 7:4; 何西阿書 9:7"> 並且沒有餘剩的人留給他們；因為在追討之年，我必使災禍臨到亞拿突人。」</span>
</div>
</div>

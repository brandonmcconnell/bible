<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="耶利米書 1:10; 撒迦利亞書 2:8; 耶利米書 4:7"> 耶和華論列國的話臨到先知耶利米。</span>

<span className="v" id="v11" data-v="11" data-xref="耶利米書 8:22; 彌迦書 1:9; 那鴻書 3:19"> <span className="pl pl-1">埃及的民</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="原文是處女">c</a></sup><br /><span className="pl pl-1">哪，</span><br /><span className="pl pl-1">可以上基列取乳香去；</span><br /><span className="pl pl-1">你雖多服良藥，</span><br /><span className="pl pl-1">總是徒然，不得治好。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="那鴻書 3:8–10; 以賽亞書 19:2; 耶利米書 46:6"> <span className="pl pl-1">列國聽見你的羞辱，</span><br /><span className="pl pl-1">遍地滿了你的哀聲；</span><br /><span className="pl pl-1">勇士與勇士彼此相碰，</span><br /><span className="pl pl-1">一齊跌倒。</span></span>
</div>

## 尼布甲尼撒來犯

<div className="bt">
<div className="bp poetry">
<span className="v" id="v13" data-v="13" data-xref="耶利米書 44:30; 耶利米書 43:10–13; 以賽亞書 19:1–25"> 耶和華對先知耶利米所說的話，論到巴比倫王尼布甲尼撒要來攻擊埃及地：</span>
<span className="v" id="v14" data-v="14" data-xref="耶利米書 46:10; 耶利米書 44:1; 耶利米書 46:3–4"> <span className="pl pl-1">你們要傳揚在埃及，宣告在密奪，</span><br /><span className="pl pl-1">報告在挪弗、答比匿說：</span><br /><span className="pl pl-1">要站起出隊，自作準備，</span><br /><span className="pl pl-1">因為刀劍在你四圍施行吞滅的事。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="以賽亞書 66:15–16; 詩篇 68:2; 詩篇 18:39"> <span className="pl pl-1">你的壯士為何被沖去呢？</span><br /><span className="pl pl-1">他們站立不住；</span><br /><span className="pl pl-1">因為耶和華驅逐他們，</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="利未記 26:36–37; 耶利米書 51:9; 耶利米書 46:6"> <span className="pl pl-1">使多人絆跌；</span><br /><span className="pl pl-1">他們也彼此撞倒，說：</span><br /><span className="pl pl-1">起來吧！我們再往本民本地去，</span><br /><span className="pl pl-1">好躲避欺壓的刀劍。</span><br /></span>

</div>
<div className="bp poetry">
<span className="v" id="v18" data-v="18" data-xref="耶利米書 48:15; 士師記 4:6; 約書亞記 19:22"> <span className="pl pl-1">君王－名為萬軍之耶和華的說：</span><br /><span className="pl pl-1">我指着我的永生起誓：</span><br /><span className="pl pl-1">尼布甲尼撒</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="原文是他">e</a></sup><br /><span className="pl pl-1">來的勢派</span><br /><span className="pl pl-1">必像他泊在眾山之中，</span><br /><span className="pl pl-1">像迦密在海邊一樣。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="以賽亞書 20:4; 耶利米書 48:18; 以西結書 30:13"> <span className="pl pl-1">住在埃及的民</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="原文是女子">f</a></sup><br /><span className="pl pl-1">哪，</span><br /><span className="pl pl-1">要預備擄去時所用的物件；</span><br /><span className="pl pl-1">因為挪弗必成為荒場，</span><br /><span className="pl pl-1">且被燒毀，無人居住。</span></span>

<div className="bp poetry">
<span className="v" id="v20" data-v="20" data-xref="何西阿書 10:11; 耶利米書 47:2; 耶利米書 1:14"> <span className="pl pl-1">埃及是肥美的母牛犢；</span><br /><span className="pl pl-1">但出於北方的毀滅</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="或譯：牛詴">g</a></sup><br /><span className="pl pl-1">來到了！來到了！</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="耶利米書 46:5; 俄巴底亞書 1:13; 列王紀下 7:6"> <span className="pl pl-1">其中的雇勇好像圈裏的肥牛犢，</span><br /><span className="pl pl-1">他們轉身退後，</span><br /><span className="pl pl-1">一齊逃跑，站立不住；</span><br /><span className="pl pl-1">因為他們遭難的日子、</span><br /><span className="pl pl-1">追討的時候已經臨到。</span></span>

<span className="v" id="v23" data-v="23" data-xref="士師記 7:12; 士師記 6:5; 約珥書 2:25"> <span className="pl pl-1">耶和華說：</span><br /><span className="pl pl-1">埃及的樹林雖然不能尋察</span><sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="或譯：穿不過">h</a></sup><br /><span className="pl pl-1">，</span><br /><span className="pl pl-1">敵人卻要砍伐，</span><br /><span className="pl pl-1">因他們多於蝗蟲，不可勝數。</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="耶利米書 1:15; 以西結書 29:1–21; 耶利米書 46:11"> <span className="pl pl-1">埃及的民</span><sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="原文是女子">i</a></sup><br /><span className="pl pl-1">必然蒙羞，</span><br /><span className="pl pl-1">必交在北方人的手中。</span></span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="西番雅書 2:11; 耶利米書 43:12–13; 以賽亞書 20:5–6"> 萬軍之耶和華－以色列的上帝說：「我必刑罰挪的亞捫<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="埃及尊大之神">j</a></sup>和法老，並埃及與埃及的神，以及君王，也必刑罰法老和倚靠他的人。</span>
<span className="v" id="v26" data-v="26" data-xref="以西結書 32:11; 耶利米書 44:30; 以西結書 29:8–14"> 我要將他們交付尋索其命之人的手和巴比倫王尼布甲尼撒與他臣僕的手；以後埃及必再有人居住，與從前一樣。這是耶和華說的。」</span>
</div>

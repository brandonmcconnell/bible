## 猶大百姓的厄運

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="以西結書 14:14; 以西結書 14:20–21; 耶利米書 14:11"> 耶和華對我說：「雖有摩西和撒母耳站在我面前代求，我的心也不顧惜這百姓。你將他們從我眼前趕出，叫他們去吧！</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米書 43:11; 撒迦利亞書 11:9; 啟示錄 13:10"> 他們問你說：『我們往哪裏去呢？』你便告訴他們，耶和華如此說：<br /><span className="pl pl-1">定為死亡的，必致死亡；</span><br /><span className="pl pl-1">定為刀殺的，必交刀殺；</span><br /><span className="pl pl-1">定為饑荒的，必遭饑荒；</span><br /><span className="pl pl-1">定為擄掠的，必被擄掠。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v3" data-v="3" data-xref="申命記 28:26; 利未記 26:22; 利未記 26:16"> 耶和華說：「我命定四樣害他們，就是刀劍殺戮、狗類撕裂、空中的飛鳥，和地上的野獸吞吃毀滅；</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米書 24:9; 列王紀下 23:26–27; 列王紀下 24:3–4"> 又必使他們在天下萬國中拋來拋去，都因猶大王希西家的兒子瑪拿西在耶路撒冷所行的事。」</span>
<span className="v" id="v5" data-v="5" data-xref="以賽亞書 51:19; 那鴻書 3:7; 耶利米書 21:7"> <span className="pl pl-1">耶路撒冷啊，誰可憐你呢？</span><br /><span className="pl pl-1">誰為你悲傷呢？</span><br /><span className="pl pl-1">誰轉身問你的安呢？</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="耶利米書 7:24; 西番雅書 1:4; 以賽亞書 1:4"> <span className="pl pl-1">耶和華說：你棄絕了我，</span><br /><span className="pl pl-1">轉身退後；</span><br /><span className="pl pl-1">因此我伸手攻擊你，毀壞你。</span><br /><span className="pl pl-1">我後悔甚不耐煩。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="馬太福音 3:12; 耶利米書 51:2; 以賽亞書 41:16"> <span className="pl pl-1">我在境內各城門口</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或譯：我在這地邊界的關口">a</a></sup><br /><span className="pl pl-1">，</span><br /><span className="pl pl-1">用簸箕簸了我的百姓，</span><br /><span className="pl pl-1">使他們喪掉兒女。</span><br /><span className="pl pl-1">我毀滅他們，</span><br /><span className="pl pl-1">他們仍不轉離所行的道。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="以賽亞書 3:25–1; 耶利米書 6:4–5; 路加福音 21:35"> <span className="pl pl-1">他們的寡婦在我面前比海沙更多；</span><br /><span className="pl pl-1">我使滅命的午間來，</span><br /><span className="pl pl-1">攻擊少年人的母親，</span><br /><span className="pl pl-1">使痛苦驚嚇忽然臨到她身上。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳記上 2:5; 以賽亞書 47:9; 耶利米哀歌 1:1"> <span className="pl pl-1">生過七子的婦人力衰氣絕；</span><br /><span className="pl pl-1">尚在白晝，日頭忽落；</span><br /><span className="pl pl-1">她抱愧蒙羞。</span><br /><span className="pl pl-1">其餘的人，</span><br /><span className="pl pl-1">我必在他們敵人跟前，交與刀劍。</span><br /><span className="pl pl-1">這是耶和華說的。</span></span>
</div>
</div>

## 耶利米向耶和華訴苦

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="路加福音 6:22; 出埃及記 22:25; 箴言 26:2"> 我的母親哪，我有禍了！因你生我作為遍地相爭相競的人。我素來沒有借貸與人，人也沒有借貸與我，人人卻都咒罵我。</span>
<span className="v" id="v11" data-v="11" data-xref="箴言 16:7; 耶利米書 29:11–14; 詩篇 106:46"> 耶和華說：「我必要堅固你，使你得好處。災禍苦難臨到的時候，我必要使仇敵央求你。（</span>
<span className="v" id="v12" data-v="12" data-xref="約伯記 40:9; 耶利米書 21:4–5; 以賽亞書 45:9"> 人豈能將銅與鐵，就是北方的鐵折斷呢？）</span>
</div>
<div className="bp poetry">
<span className="v" id="v13" data-v="13" data-xref="耶利米書 17:3; 詩篇 44:12; 以賽亞書 52:3"> 「我必因你在四境之內所犯的一切罪，把你的貨物財寶當掠物，白白地交給仇敵。</span>
<span className="v" id="v14" data-v="14" data-xref="耶利米書 16:13; 申命記 32:22; 耶利米書 17:4"> 我也必使仇敵帶這掠物到你所不認識的地去，因我怒中起的火要將你們焚燒。」</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米書 12:3; 詩篇 69:7–9; 路加福音 21:17"> <span className="pl pl-1">耶和華啊，你是知道的；</span><br /><span className="pl pl-1">求你記念我，眷顧我，</span><br /><span className="pl pl-1">向逼迫我的人為我報仇；</span><br /><span className="pl pl-1">不要向他們忍怒取我的命，</span><br /><span className="pl pl-1">要知道我為你的緣故受了凌辱。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="啟示錄 10:9–10; 以西結書 3:1–3; 詩篇 119:101–103"> <span className="pl pl-1">耶和華－萬軍之上帝啊，</span><br /><span className="pl pl-1">我得着你的言語就當食物吃了；</span><br /><span className="pl pl-1">你的言語是我心中的歡喜快樂，</span><br /><span className="pl pl-1">因我是稱為你名下的人。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="詩篇 1:1; 耶利米哀歌 3:28; 詩篇 26:4–5"> <span className="pl pl-1">我沒有坐在宴樂人的會中，</span><br /><span className="pl pl-1">也沒有歡樂；</span><br /><span className="pl pl-1">我因你的感動</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原文是手">b</a></sup><br /><span className="pl pl-1">獨自靜坐，</span><br /><span className="pl pl-1">因你使我滿心憤恨。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="耶利米書 30:15; 約伯記 34:6; 彌迦書 1:9"> <span className="pl pl-1">我的痛苦為何長久不止呢？</span><br /><span className="pl pl-1">我的傷痕為何無法醫治、不能痊癒呢？</span><br /><span className="pl pl-1">難道你待我有詭詐，像流乾的河道嗎？</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v19" data-v="19" data-xref="撒迦利亞書 3:7; 路加福音 21:15; 利未記 10:10"> <span className="pl pl-1">耶和華如此說：你若歸回，</span><br /><span className="pl pl-1">我就將你再帶來，</span><br /><span className="pl pl-1">使你站在我面前；</span><br /><span className="pl pl-1">你若將寶貴的和下賤的分別出來，</span><br /><span className="pl pl-1">你就可以當作我的口。</span><br /><span className="pl pl-1">他們必歸向你，</span><br /><span className="pl pl-1">你卻不可歸向他們。</span><br /></span>

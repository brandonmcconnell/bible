## 從北方來的敵人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="耶利米書 36:1; 列王紀下 24:1–2; 但以理書 1:1"> 猶大王約西亞的兒子約雅敬第四年，就是巴比倫王尼布甲尼撒的元年，耶和華論猶大眾民的話臨到耶利米。</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米書 18:11; 耶利米書 19:14–15; 馬可福音 7:14–15"> 先知耶利米就將這話對猶大眾人和耶路撒冷的一切居民說：</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米書 11:7; 耶利米書 26:5; 耶利米書 1:2"> 「從猶大王亞們的兒子約西亞十三年直到今日，這二十三年之內，常有耶和華的話臨到我；我也對你們傳說，就是從早起來傳說，只是你們沒有聽從。</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米書 25:3; 耶利米書 26:5; 耶利米書 13:10–11"> 耶和華也從早起來，差遣他的僕人眾先知到你們這裏來（只是你們沒有聽從，也沒有側耳而聽），</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米書 7:7; 創世記 17:8; 以賽亞書 55:6–7"> 說：『你們各人當回頭，離開惡道和所作的惡，便可居住耶和華古時所賜給你們和你們列祖之地，直到永遠。</span>
<span className="v" id="v6" data-v="6" data-xref="申命記 8:19; 耶利米書 7:6; 耶利米書 35:15"> 不可隨從別神事奉敬拜，以你們手所做的惹我發怒；這樣，我就不加害與你們。</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀下 21:15; 箴言 8:36; 申命記 32:21"> 然而你們沒有聽從我，竟以手所做的惹我發怒，陷害自己。這是耶和華說的。』」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8"> 所以萬軍之耶和華如此說：「因為你們沒有聽從我的話，</span>
<span className="v" id="v9" data-v="9" data-xref="以賽亞書 13:3; 耶利米書 18:16; 耶利米書 1:15"> 我必召北方的眾族和我僕人巴比倫王尼布甲尼撒來攻擊這地和這地的居民，並四圍一切的國民。我要將他們盡行滅絕，以致他們令人驚駭、嗤笑，並且永久荒涼。這是耶和華說的。</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米書 7:34; 啟示錄 18:22–23; 以西結書 26:13"> 我又要使歡喜和快樂的聲音，新郎和新婦的聲音，推磨的聲音和燈的亮光，從他們中間止息。</span>
<span className="v" id="v11" data-v="11" data-xref="但以理書 9:2; 撒迦利亞書 1:12; 歷代志下 36:21–22"> 這全地必然荒涼，令人驚駭。這些國民要服事巴比倫王七十年。</span>
<span className="v" id="v12" data-v="12" data-xref="但以理書 9:2; 以賽亞書 13:19; 耶利米書 29:10"> 七十年滿了以後，我必刑罰巴比倫王和那國民，並迦勒底人之地，因他們的罪孽使那地永遠荒涼。這是耶和華說的。</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米書 1:10; 耶利米書 1:5; 但以理書 5:31"> 我也必使我向那地所說的話，就是記在這書上的話，是耶利米向這些國民說的預言，都臨到那地。</span>
<span className="v" id="v14" data-v="14" data-xref="耶利米書 51:6; 耶利米書 27:7; 耶利米書 50:9"> 因為有多國和大君王必使迦勒底人作奴僕；我也必照他們的行為，按他們手所做的報應他們。」</span>
</div>
</div>

## 上帝審判列國

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="詩篇 75:8; 以賽亞書 51:17; 啟示錄 14:10"> 耶和華－以色列的上帝對我如此說：「你從我手中接這杯忿怒的酒，使我所差遣你去的各國的民喝。</span>
<span className="v" id="v16" data-v="16" data-xref="那鴻書 3:11; 耶利米書 51:7; 耶利米書 51:39"> 他們喝了就要東倒西歪，並要發狂，因我使刀劍臨到他們中間。」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="耶利米書 1:10; 耶利米書 25:28; 以西結書 43:3"> 我就從耶和華的手中接了這杯，給耶和華所差遣我去的各國的民喝，</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米書 24:9; 詩篇 60:3; 耶利米書 44:22"> 就是耶路撒冷和猶大的城邑，並耶路撒冷的君王與首領，使這城邑荒涼，令人驚駭、嗤笑、咒詛，正如今日一樣。</span>
<span className="v" id="v19" data-v="19" data-xref="耶利米書 46:13–26; 那鴻書 3:8–10; 耶利米書 46:2"> 又有埃及王法老和他的臣僕、首領，以及他的眾民，</span>
<span className="v" id="v20" data-v="20" data-xref="約伯記 1:1; 以西結書 30:5; 以賽亞書 20:1"> 並雜族的人民和烏斯地的諸王，與非利士地的諸王（亞實基倫、迦薩、以革倫，以及亞實突剩下的人）；</span>
<span className="v" id="v21" data-v="21" data-xref="耶利米書 48:1–22; 詩篇 137:7; 耶利米書 9:26"> 以東、摩押、亞捫人、</span>
<span className="v" id="v22" data-v="22" data-xref="耶利米書 47:4; 阿摩司書 1:9–10; 以西結書 28:22–23"> 泰爾的諸王、西頓的諸王、海島的諸王、</span>
<span className="v" id="v23" data-v="23" data-xref="耶利米書 9:26; 耶利米書 49:32; 耶利米書 49:8"> 底但、提瑪、布斯，和一切剃周圍頭髮的；</span>
<span className="v" id="v24" data-v="24" data-xref="歷代志下 9:14; 耶利米書 25:20; 以西結書 30:5"> 阿拉伯的諸王、住曠野雜族人民的諸王、</span>
<span className="v" id="v25" data-v="25" data-xref="以賽亞書 11:11; 創世記 10:22; 以賽亞書 13:17"> 心利的諸王、以攔的諸王、米底亞的諸王、</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米書 51:41; 耶利米書 25:9; 耶利米書 50:1–46"> 北方遠近的諸王，以及天下地上的萬國喝了，以後示沙克<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="就是巴比倫">a</a></sup>王也要喝。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="耶利米書 25:16; 哈巴谷書 2:16; 以西結書 21:4–5"> 「你要對他們說：『萬軍之耶和華－以色列的上帝如此說：你們要喝，且要喝醉，要嘔吐，且要跌倒，不得再起來，都因我使刀劍臨到你們中間。』</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="約伯記 34:33; 耶利米書 51:29; 以賽亞書 14:24–27"> 「他們若不肯從你手接這杯喝，你就要對他們說：『萬軍之耶和華如此說：你們一定要喝！</span>
<span className="v" id="v29" data-v="29" data-xref="以西結書 38:21; 箴言 11:31; 彼得前書 4:17"> 我既從稱為我名下的城起首施行災禍，你們能盡免刑罰嗎？你們必不能免，因為我要命刀劍臨到地上一切的居民。這是萬軍之耶和華說的。』</span>
</div>
<div className="bp poetry">
<span className="v" id="v30" data-v="30" data-xref="阿摩司書 1:2; 約珥書 3:16; 以賽亞書 42:13"> 「所以你要向他們預言這一切的話，攻擊他們，說：<br /><span className="pl pl-1">耶和華必從高天吼叫，</span><br /><span className="pl pl-1">從聖所發聲，</span><br /><span className="pl pl-1">向自己的羊群大聲吼叫；</span><br /><span className="pl pl-1">他要向地上一切的居民吶喊，</span><br /><span className="pl pl-1">像踹葡萄的一樣。</span><br /></span>
<span className="v" id="v31" data-v="31" data-xref="何西阿書 4:1; 約珥書 3:2; 以賽亞書 66:16"> <span className="pl pl-1">必有響聲達到地極，</span><br /><span className="pl pl-1">因為耶和華與列國相爭；</span><br /><span className="pl pl-1">凡有血氣的，他必審問；</span><br /><span className="pl pl-1">至於惡人，他必交給刀劍。</span><br /><span className="pl pl-1">這是耶和華說的。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v32" data-v="32" data-xref="耶利米書 23:19; 以賽亞書 34:2; 歷代志下 15:6"> <span className="pl pl-1">萬軍之耶和華如此說：</span><br /><span className="pl pl-1">看哪，必有災禍從這國發到那國，</span><br /><span className="pl pl-1">並有大暴風從地極颳起。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v33" data-v="33" data-xref="以賽亞書 66:16; 耶利米書 8:2; 詩篇 79:3"> 「到那日，從地這邊直到地那邊都有耶和華所殺戮的。必無人哀哭，不得收殮，不得葬埋，必在地上成為糞土。</span>
<span className="v" id="v34" data-v="34" data-xref="耶利米書 6:26; 耶利米書 50:27; 詩篇 2:9"> <span className="pl pl-1">牧人哪，你們當哀號，呼喊；</span><br /><span className="pl pl-1">群眾的頭目啊，你們要滾在灰中；</span><br /><span className="pl pl-1">因為你們被殺戮分散的日子足足來到。</span><br /><span className="pl pl-1">你們要跌碎，好像美器打碎一樣。</span><br /></span>
<span className="v" id="v35" data-v="35" data-xref="約伯記 11:20; 阿摩司書 2:14; 耶利米書 52:8–11"> <span className="pl pl-1">牧人無路逃跑；</span><br /><span className="pl pl-1">群眾的頭目也無法逃脫。</span><br /></span>
<span className="v" id="v36" data-v="36" data-xref="耶利米書 4:8; 耶利米書 25:34"> <span className="pl pl-1">聽啊，有牧人呼喊，</span><br /><span className="pl pl-1">有群眾頭目哀號的聲音，</span><br /><span className="pl pl-1">因為耶和華使他們的草場變為荒場。</span><br /></span>
<span className="v" id="v37" data-v="37" data-xref="以賽亞書 27:10–11; 以賽亞書 32:14"> <span className="pl pl-1">耶和華發出猛烈的怒氣，</span><br /><span className="pl pl-1">平安的羊圈就都寂靜無聲。</span><br /></span>
<span className="v" id="v38" data-v="38" data-xref="耶利米書 4:7; 耶利米書 5:6; 何西阿書 13:7–8"> <span className="pl pl-1">他離了隱密處像獅子一樣，</span><br /><span className="pl pl-1">他們的地，因刀劍凶猛的欺壓，</span><br /><span className="pl pl-1">又因他猛烈的怒氣都成為可驚駭的。」</span></span>
</div>
</div>

## 耶利米在聖殿講道

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華的話臨到耶利米說：</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米書 26:2; 啟示錄 3:22; 阿摩司書 7:16"> 「你當站在耶和華殿的門口，在那裏宣傳這話說：你們進這些門敬拜耶和華的一切猶大人，當聽耶和華的話。</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米書 18:11; 耶利米書 26:13; 以賽亞書 1:16–19"> 萬軍之耶和華－以色列的上帝如此說：你們改正行動作為，我就使你們在這地方仍然居住。</span>
<span className="v" id="v4" data-v="4" data-xref="彌迦書 3:11; 馬太福音 3:9–10; 西番雅書 3:11"> 你們不要倚靠虛謊的話，說：『這些是耶和華的殿，是耶和華的殿，是耶和華的殿！』</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="列王紀上 6:12–13; 以賽亞書 1:19; 耶利米書 7:3"> 「你們若實在改正行動作為，在人和鄰舍中間誠然施行公平，</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及記 22:21–24; 撒迦利亞書 7:9–12; 耶利米書 13:10"> 不欺壓寄居的和孤兒寡婦，在這地方不流無辜人的血，也不隨從別神陷害自己，</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 4:40; 耶利米書 25:5; 耶利米書 3:18"> 我就使你們在這地方仍然居住，就是我古時所賜給你們列祖的地，直到永遠。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="以賽亞書 28:15; 以西結書 13:6–16; 耶利米書 23:14–16"> 「看哪，你們倚靠虛謊無益的話。</span>
<span className="v" id="v9" data-v="9" data-xref="耶利米書 7:6; 出埃及記 20:3; 雅各書 4:1–4"> 你們偷盜，殺害，姦淫，起假誓，向巴力燒香，並隨從素不認識的別神，</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米書 32:34; 以西結書 23:37; 以西結書 23:39"> 且來到這稱為我名下的殿，在我面前敬拜；又說：『我們可以自由了。』你們這樣的舉動是要行那些可憎的事嗎？</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 19:45–46; 以賽亞書 56:7; 馬太福音 21:13"> 這稱為我名下的殿在你們眼中豈可看為賊窩嗎？我都看見了。這是耶和華說的。</span>
<span className="v" id="v12" data-v="12" data-xref="約書亞記 18:1; 耶利米書 26:6; 撒母耳記上 4:10–11"> 你們且往示羅去，就是我先前立為我名的居所，察看我因這百姓以色列的罪惡向那地所行的如何。」</span>
<span className="v" id="v13" data-v="13" data-xref="以賽亞書 65:12; 歷代志下 36:15–16; 耶利米書 7:25"> 耶和華說：「現在因你們行了這一切的事，我也從早起來警戒你們，你們卻不聽從；呼喚你們，你們卻不答應。</span>
<span className="v" id="v14" data-v="14" data-xref="詩篇 78:60; 列王紀下 25:9; 耶利米書 7:4"> 所以我要向這稱為我名下、你們所倚靠的殿，與我所賜給你們和你們列祖的地施行，照我從前向示羅所行的一樣。</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米書 15:1; 列王紀下 17:23; 耶利米書 52:3"> 我必將你們從我眼前趕出，正如趕出你們的眾弟兄，就是以法蓮的一切後裔。」</span>
</div>
</div>

## 人民違背命令

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="耶利米書 11:14; 耶利米書 14:11–12; 耶利米書 15:1"> 「所以，你不要為這百姓祈禱；不要為他們呼求禱告，也不要向我為他們祈求，因我不聽允你。</span>
<span className="v" id="v17" data-v="17" data-xref="以西結書 8:6–18; 以西結書 14:23; 耶利米書 6:27"> 他們在猶大城邑中和耶路撒冷街上所行的，你沒有看見嗎？</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米書 19:13; 耶利米書 44:17–19; 哥林多前書 10:22"> 孩子撿柴，父親燒火，婦女摶麵做餅，獻給天后，又向別神澆奠祭，惹我發怒。」</span>
<span className="v" id="v19" data-v="19" data-xref="耶利米書 20:11; 耶利米書 2:19; 但以理書 9:7–8"> 耶和華說：「他們豈是惹我發怒呢？不是自己惹禍，以致臉上慚愧嗎？」</span>
<span className="v" id="v20" data-v="20" data-xref="耶利米書 42:18; 耶利米哀歌 2:3–5; 以賽亞書 42:25"> 所以主耶和華如此說：「看哪，我必將我的怒氣和忿怒傾在這地方的人和牲畜身上，並田野的樹木和地裏的出產上，必如火着起，不能熄滅。」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="何西阿書 8:13; 耶利米書 6:20; 阿摩司書 5:21–23"> 萬軍之耶和華－以色列的上帝如此說：「你們將燔祭加在平安祭上，吃肉吧！</span>
<span className="v" id="v22" data-v="22" data-xref="何西阿書 6:6; 撒母耳記上 15:22; 詩篇 51:16–17"> 因為我將你們列祖從埃及地領出來的那日，燔祭平安祭的事我並沒有提說，也沒有吩咐他們。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及記 15:26; 申命記 5:33; 出埃及記 19:5–6"> 我只吩咐他們這一件說：『你們當聽從我的話，我就作你們的上帝，你們也作我的子民。你們行我所吩咐的一切道，就可以得福。』</span>
<span className="v" id="v24" data-v="24" data-xref="詩篇 81:11–12; 耶利米書 8:5; 耶利米書 7:26"> 他們卻不聽從，不側耳而聽，竟隨從自己的計謀和頑梗的惡心，向後不向前。</span>
<span className="v" id="v25" data-v="25" data-xref="歷代志下 36:15; 耶利米書 25:4; 尼希米記 9:26"> 自從你們列祖出埃及地的那日，直到今日，我差遣我的僕人眾先知到你們那裏去，每日從早起來差遣他們。</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米書 16:12; 歷代志下 30:8; 耶利米書 7:24"> 你們卻不聽從，不側耳而聽，竟硬着頸項行惡，比你們列祖更甚。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="耶利米書 26:2; 耶利米書 1:7; 以賽亞書 65:12"> 「你要將這一切的話告訴他們，他們卻不聽從；呼喚他們，他們卻不答應。</span>
<span className="v" id="v28" data-v="28" data-xref="以賽亞書 59:14–15; 箴言 1:7; 以賽亞書 1:4–5"> 你要對他們說：這就是不聽從耶和華－他們上帝的話、不受教訓的國民；從他們的口中，誠實滅絕了。」</span>
</div>
</div>

## 在欣嫩子谷的罪行

<div className="bt">
<div className="bp poetry">
<span className="v" id="v29" data-v="29" data-xref="約伯記 1:20; 彌迦書 1:16; 耶利米書 6:30"> <span className="pl pl-1">耶路撒冷啊，要剪髮拋棄，</span><br /><span className="pl pl-1">在淨光的高處舉哀；</span><br /><span className="pl pl-1">因為耶和華丟掉離棄了惹他忿怒的世代。</span></span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="耶利米書 32:34; 以西結書 7:20; 但以理書 9:27"> 耶和華說：「猶大人行我眼中看為惡的事，將可憎之物設立在稱為我名下的殿中，污穢這殿。</span>
<span className="v" id="v31" data-v="31" data-xref="列王紀下 23:10; 耶利米書 32:35; 利未記 18:21"> 他們在欣嫩子谷建築陀斐特的邱壇，好在火中焚燒自己的兒女。這並不是我所吩咐的，也不是我心所起的意。」</span>
<span className="v" id="v32" data-v="32" data-xref="耶利米書 19:11; 耶利米書 19:6; 列王紀下 23:10"> 耶和華說：「因此，日子將到，這地方不再稱為陀斐特和欣嫩子谷，反倒稱為殺戮谷。因為要在陀斐特葬埋屍首，甚至無處可葬；</span>
<span className="v" id="v33" data-v="33" data-xref="耶利米書 12:9; 申命記 28:26; 啟示錄 19:17–18"> 並且這百姓的屍首必給空中的飛鳥和地上的野獸作食物，並無人鬨趕。</span>
<span className="v" id="v34" data-v="34" data-xref="啟示錄 18:23; 何西阿書 2:11; 以西結書 26:13"> 那時，我必使猶大城邑中和耶路撒冷街上，歡喜和快樂的聲音，新郎和新婦的聲音，都止息了，因為地必成為荒場。」</span>
</div>
</div>

## 百姓求耶利米代禱

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="耶利米書 41:11; 耶利米書 40:13; 耶利米書 6:13"> 眾軍長和加利亞的兒子約哈難，並何沙雅的兒子耶撒尼亞<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="又名亞撒利雅，見四十三章二節">a</a></sup>以及眾百姓，從最小的到至大的都進前來，</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米書 36:7; 利未記 26:22; 使徒行傳 8:24"> 對先知耶利米說：「求你准我們在你面前祈求，為我們這剩下的人禱告耶和華－你的上帝。我們本來眾多，現在剩下的極少，這是你親眼所見的。</span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 86:11; 箴言 3:6; 詩篇 25:4–5"> 願耶和華－你的上帝指示我們所當走的路，所當做的事。」</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳記上 12:23; 撒母耳記上 3:17–18; 出埃及記 8:29"> 先知耶利米對他們說：「我已經聽見你們了，我必照着你們的話禱告耶和華－你們的上帝。耶和華無論回答甚麼，我必都告訴你們，毫不隱瞞。」</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 31:50; 士師記 11:10; 瑪拉基書 3:5"> 於是他們對耶利米說：「我們若不照耶和華－你的上帝差遣你來說的一切話行，願耶和華在我們中間作真實誠信的見證。</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米書 7:23; 申命記 5:29; 羅馬書 8:7"> 我們現在請你到耶和華－我們的上帝面前，他說的無論是好是歹，我們都必聽從；我們聽從耶和華－我們上帝的話，就可以得福。」</span>
</div>
</div>

## 耶和華回答耶利米的禱告

<div className="bt">
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="詩篇 27:14; 以賽亞書 28:16; 哈巴谷書 2:3"> 過了十天，耶和華的話臨到耶利米。</span>
<span className="v" id="v8" data-v="8" data-xref="耶利米書 42:1; 耶利米書 41:11–16; 耶利米書 43:2–5"> 他就將加利亞的兒子約哈難和同着他的眾軍長，並眾百姓，從最小的到至大的都叫了來，</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀下 19:4; 耶利米書 42:2; 列王紀下 19:6"> 對他們說：「耶和華－以色列的上帝，就是你們請我在他面前為你們祈求的主，如此說：</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米書 31:28; 以西結書 36:36; 耶利米書 24:6"> 『你們若仍住在這地，我就建立你們，必不拆毀，栽植你們，並不拔出，因我為降與你們的災禍後悔了。</span>
<span className="v" id="v11" data-v="11" data-xref="羅馬書 8:31; 耶利米書 1:19; 耶利米書 1:8"> 不要怕你們所怕的巴比倫王。』」耶和華說：「不要怕他！因為我與你們同在，要拯救你們脫離他的手。</span>
<span className="v" id="v12" data-v="12" data-xref="尼希米記 1:11; 詩篇 106:45–46; 箴言 16:7"> 我也要使他發憐憫，好憐憫你們，叫你們歸回本地。</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米書 44:16; 出埃及記 5:2; 耶利米書 42:10"> 倘若你們說：『我們不住在這地』，以致不聽從耶和華－你們上帝的話，</span>
<span className="v" id="v14" data-v="14" data-xref="耶利米書 41:17; 耶利米書 4:19; 以賽亞書 31:1"> 說：『我們不住這地，卻要進入埃及地，在那裏看不見爭戰，聽不見角聲，也不致無食飢餓。我們必住在那裏。』</span>
<span className="v" id="v15" data-v="15" data-xref="申命記 17:16; 耶利米書 44:12–14; 耶利米書 42:17"> 你們所剩下的猶大人哪，現在要聽耶和華的話。萬軍之耶和華－以色列的上帝如此說：『你們若定意要進入埃及，在那裏寄居，</span>
<span className="v" id="v16" data-v="16" data-xref="耶利米書 44:27; 以西結書 11:8; 阿摩司書 9:1–4"> 你們所懼怕的刀劍在埃及地必追上你們！你們所懼怕的饑荒在埃及要緊緊地跟隨你們！你們必死在那裏！</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米書 42:22; 耶利米書 44:28; 耶利米書 44:13–14"> 凡定意要進入埃及在那裏寄居的必遭刀劍、饑荒、瘟疫而死，無一人存留，逃脫我所降與他們的災禍。』</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米書 7:20; 耶利米書 18:16; 耶利米書 29:18"> 「萬軍之耶和華－以色列的上帝如此說：『我怎樣將我的怒氣和忿怒傾在耶路撒冷的居民身上，你們進入埃及的時候，我也必照樣將我的忿怒傾在你們身上，以致你們令人辱罵、驚駭、咒詛、羞辱，你們不得再見這地方。』</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 17:16; 以賽亞書 30:1–7; 尼希米記 9:26"> 所剩下的猶大人哪，耶和華論到你們說：『不要進入埃及去。』你們要確實地知道我今日警教你們了。</span>
<span className="v" id="v20" data-v="20" data-xref="以西結書 14:3–4; 以西結書 33:31; 馬太福音 22:15–18"> 你們行詭詐自害；因為你們請我到耶和華－你們的上帝那裏，說：『求你為我們禱告耶和華－我們上帝，照耶和華－我們的上帝一切所說的告訴我們，我們就必遵行。』</span>
<span className="v" id="v21" data-v="21" data-xref="以西結書 2:7; 撒迦利亞書 7:11–12; 使徒行傳 20:26–27"> 我今日將這話告訴你們，耶和華－你們的上帝為你們的事差遣我到你們那裏說的，你們卻一樣沒有聽從。</span>
<span className="v" id="v22" data-v="22" data-xref="耶利米書 42:17; 以西結書 6:11; 何西阿書 9:6"> 現在你們要確實地知道，你們在所要去寄居之地必遭刀劍、饑荒、瘟疫而死。」</span>
</div>
</div>

## 重申復國的應許

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="耶利米書 38:28; 耶利米書 37:21; 耶利米書 32:2–3"> 耶利米還囚在護衛兵的院內，耶和華的話第二次臨到他說：</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 6:3; 出埃及記 15:3; 以賽亞書 37:26"> 「成就的是耶和華，造作、為要建立的也是耶和華；耶和華是他的名。他如此說：</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米書 29:12; 以賽亞書 65:24; 以弗所書 3:20"> 你求告我，我就應允你，並將你所不知道、又大又難的事指示你。</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米書 32:24; 哈巴谷書 1:10; 以西結書 4:2"> 論到這城中的房屋和猶大王的宮室，就是拆毀為擋敵人高壘和刀劍的，耶和華－以色列的上帝如此說：</span>
<span className="v" id="v5" data-v="5" data-xref="以賽亞書 8:17; 耶利米書 21:10; 耶利米書 21:4–7"> 人要與迦勒底人爭戰，正是拿死屍充滿這房屋，就是我在怒氣和忿怒中所殺的人，因他們的一切惡，我就掩面不顧這城。</span>
<span className="v" id="v6" data-v="6" data-xref="約翰福音 10:10; 以賽亞書 30:26; 提多書 3:5–6"> 看哪，我要使這城得以痊癒安舒，使城中的人得醫治，又將豐盛的平安和誠實顯明與他們。</span>
<span className="v" id="v7" data-v="7" data-xref="以賽亞書 1:26; 耶利米書 30:3; 阿摩司書 9:14–15"> 我也要使猶大被擄的和以色列被擄的歸回，並建立他們和起初一樣。</span>
<span className="v" id="v8" data-v="8" data-xref="撒迦利亞書 13:1; 彌迦書 7:18–19; 詩篇 51:2"> 我要除淨他們的一切罪，就是向我所犯的罪；又要赦免他們的一切罪，就是干犯我、違背我的罪。</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 126:2–3; 以賽亞書 60:5; 西番雅書 3:17–20"> 這城要在地上萬國人面前使我得頌讚，得榮耀，名為可喜可樂之城。萬國人因聽見我向這城所賜的福樂、所施的恩惠平安，就懼怕戰兢。」</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米書 32:43; 耶利米書 32:36; 以西結書 37:11"> 耶和華如此說：「你們論這地方，說是荒廢無人民無牲畜之地，但在這荒涼無人民無牲畜的猶大城邑和耶路撒冷的街上，</span>
<span className="v" id="v11" data-v="11" data-xref="歷代志上 16:34; 詩篇 106:1; 詩篇 107:22"> 必再聽見有歡喜和快樂的聲音、新郎和新婦的聲音，並聽見有人說：<br /><span className="pl pl-1">要稱謝萬軍之耶和華，</span><br /><span className="pl pl-1">因耶和華本為善；</span><br /><span className="pl pl-1">他的慈愛永遠長存！</span>又有奉感謝祭到耶和華殿中之人的聲音；因為我必使這地被擄的人歸回，和起初一樣。這是耶和華說的。」</span>
<span className="v" id="v12" data-v="12" data-xref="以賽亞書 65:10; 以西結書 34:12–15; 耶利米書 36:29"> 萬軍之耶和華如此說：「在這荒廢無人民無牲畜之地，並其中所有的城邑，必再有牧人的住處；他們要使羊群躺臥在那裏。</span>
<span className="v" id="v13" data-v="13" data-xref="利未記 27:32; 路加福音 15:4; 耶利米書 17:26"> 在山地的城邑、高原的城邑、南地的城邑、便雅憫地、耶路撒冷四圍的各處，和猶大的城邑必再有羊群從數點的人手下經過。這是耶和華說的。」</span>
<span className="v" id="v14" data-v="14" data-xref="哈該書 2:6–9; 耶利米書 23:5; 歷代志上 17:13–14"> 耶和華說：「日子將到，我應許以色列家和猶大家的恩言必然成就。</span>
<span className="v" id="v15" data-v="15" data-xref="以賽亞書 11:1–5; 耶利米書 23:5–6; 以賽亞書 4:2"> 當那日子，那時候，我必使大衛公義的苗裔長起來；他必在地上施行公平和公義。</span>
<span className="v" id="v16" data-v="16" data-xref="耶利米書 23:6; 哥林多前書 1:30; 以賽亞書 45:17"> 在那日子猶大必得救，耶路撒冷必安然居住，他的名必稱為『耶和華－我們的義』。</span>
<span className="v" id="v17" data-v="17" data-xref="列王紀上 2:4; 詩篇 89:29–37; 路加福音 1:32–33"> 「因為耶和華如此說：大衛必永不斷人坐在以色列家的寶座上；</span>
<span className="v" id="v18" data-v="18" data-xref="以賽亞書 56:7; 啟示錄 1:6; 申命記 18:1"> 祭司、利未人在我面前也不斷人獻燔祭、燒素祭，時常辦理獻祭的事。」</span>
<span className="v" id="v19" data-v="19"> 耶和華的話臨到耶利米說：</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 8:22; 詩篇 89:37; 以賽亞書 54:9–10"> 「耶和華如此說：你們若能廢棄我所立白日黑夜的約，使白日黑夜不按時輪轉，</span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 89:34; 歷代志下 7:18; 撒母耳記下 23:5"> 就能廢棄我與我僕人大衛所立的約，使他沒有兒子在他的寶座上為王，並能廢棄我與事奉我的祭司、利未人所立的約。</span>
<span className="v" id="v22" data-v="22" data-xref="創世記 15:5; 創世記 22:17; 希伯來書 11:12"> 天上的萬象不能數算，海邊的塵沙也不能斗量；我必照樣使我僕人大衛的後裔和事奉我的利未人多起來。」</span>
<span className="v" id="v23" data-v="23"> 耶和華的話臨到耶利米說：</span>
<span className="v" id="v24" data-v="24" data-xref="尼希米記 4:2–4; 詩篇 83:4; 詩篇 44:13–14"> 「你沒有揣摩這百姓的話嗎？他們說：『耶和華所揀選的二族，他已經棄絕了。』他們這樣藐視我的百姓，以為不再成國。</span>
<span className="v" id="v25" data-v="25" data-xref="詩篇 74:16–17; 耶利米書 31:35–36; 詩篇 104:19"> 耶和華如此說：若是我立白日黑夜的約不能存住，若是我未曾安排天地的定例，</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米書 31:37; 以賽亞書 14:1; 何西阿書 2:23"> 我就棄絕雅各的後裔和我僕人大衛的後裔，不使大衛的後裔治理亞伯拉罕、以撒、雅各的後裔；因為我必使他們被擄的人歸回，也必憐憫他們。」</span>

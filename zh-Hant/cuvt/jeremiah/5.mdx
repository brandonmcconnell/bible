## 耶和華丟棄以色列

<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="歷代志下 36:16; 以西結書 12:22–28; 耶利米書 23:14–17"> <span className="pl pl-1">他們不認耶和華，說：</span><br /><span className="pl pl-1">這並不是他，</span><br /><span className="pl pl-1">災禍必不臨到我們；</span><br /><span className="pl pl-1">刀劍和饑荒，我們也看不見。</span><br /></span>

## 上帝警告他的子民

<div className="bt">
<div className="bp poetry">
<span className="v" id="v20" data-v="20"> <span className="pl pl-1">當傳揚在雅各家，</span><br /><span className="pl pl-1">報告在猶大說：</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="使徒行傳 28:26; 以西結書 12:2; 以賽亞書 6:9–10"> <span className="pl pl-1">愚昧無知的百姓啊，</span><br /><span className="pl pl-1">你們有眼不看，</span><br /><span className="pl pl-1">有耳不聽，</span><br /><span className="pl pl-1">現在當聽這話。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="約伯記 38:10–11; 詩篇 104:9; 約伯記 26:10"> <span className="pl pl-1">耶和華說：你們怎麼不懼怕我呢？</span><br /><span className="pl pl-1">我以永遠的定例，</span><br /><span className="pl pl-1">用沙為海的界限，</span><br /><span className="pl pl-1">水不得越過。</span><br /><span className="pl pl-1">因此，你們在我面前還不戰兢嗎？</span><br /><span className="pl pl-1">波浪雖然翻騰，卻不能逾越；</span><br /><span className="pl pl-1">雖然匉訇，卻不能過去。</span><br /></span>

<span className="v" id="v24" data-v="24" data-xref="詩篇 147:8; 約珥書 2:23; 創世記 8:22"> <span className="pl pl-1">心內也不說：</span><br /><span className="pl pl-1">我們應當敬畏耶和華－我們的上帝；</span><br /><span className="pl pl-1">他按時賜雨，就是秋雨春雨，</span><br /><span className="pl pl-1">又為我們定收割的節令，永存不廢。</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="以賽亞書 59:2; 詩篇 107:17; 詩篇 107:34"> <span className="pl pl-1">你們的罪孽使這些事轉離你們；</span><br /><span className="pl pl-1">你們的罪惡使你們不能得福。</span><br /></span>

<span className="v" id="v27" data-v="27" data-xref="彌迦書 1:12; 耶利米書 9:6; 何西阿書 12:7–8"> <span className="pl pl-1">籠內怎樣滿了雀鳥，</span><br /><span className="pl pl-1">他們的房中也照樣充滿詭詐；</span><br /><span className="pl pl-1">所以他們得成為大，而且富足。</span><br /></span>

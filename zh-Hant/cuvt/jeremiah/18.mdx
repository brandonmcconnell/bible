## 耶利米在陶匠的家

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華的話臨到耶利米說：</span>
<span className="v" id="v2" data-v="2" data-xref="希伯來書 1:1; 使徒行傳 9:6; 耶利米書 19:1–2"> 「你起來，下到窯匠的家裏去，我在那裏要使你聽我的話。」</span>
<span className="v" id="v3" data-v="3" data-xref="約翰福音 15:14; 約拿書 1:3; 使徒行傳 26:19"> 我就下到窯匠的家裏去，正遇他轉輪做器皿。</span>
<span className="v" id="v4" data-v="4" data-xref="羅馬書 9:20–23; 耶利米書 18:6; 以賽亞書 45:9"> 窯匠用泥做的器皿，在他手中做壞了，他又用這泥另做別的器皿；窯匠看怎樣好，就怎樣做。</span>
<span className="v" id="v5" data-v="5"> 耶和華的話就臨到我說：</span>
<span className="v" id="v6" data-v="6" data-xref="以賽亞書 64:8; 羅馬書 9:20–21; 耶利米書 18:4"> 「耶和華說：以色列家啊，我待你們，豈不能照這窯匠弄泥嗎？以色列家啊，泥在窯匠的手中怎樣，你們在我的手中也怎樣。</span>
<span className="v" id="v7" data-v="7" data-xref="耶利米書 1:10; 耶利米書 12:14–17; 耶利米書 45:4"> 我何時論到一邦或一國說，要拔出、拆毀、毀壞；</span>
<span className="v" id="v8" data-v="8" data-xref="以西結書 18:21; 耶利米書 26:13; 約拿書 3:9–10"> 我所說的那一邦，若是轉意離開他們的惡，我就必後悔，不將我想要施行的災禍降與他們。</span>
<span className="v" id="v9" data-v="9" data-xref="耶利米書 31:28; 阿摩司書 9:11–15; 耶利米書 1:10"> 我何時論到一邦或一國說，要建立、栽植；</span>
<span className="v" id="v10" data-v="10" data-xref="以西結書 33:18; 撒母耳記上 2:30; 以西結書 18:24"> 他們若行我眼中看為惡的事，不聽從我的話，我就必後悔，不將我所說的福氣賜給他們。</span>
<span className="v" id="v11" data-v="11" data-xref="列王紀下 17:13; 以賽亞書 55:6–7; 耶利米書 35:15"> 現在你要對猶大人和耶路撒冷的居民說：『耶和華如此說：我造出災禍攻擊你們，定意刑罰你們。你們各人當回頭離開所行的惡道，改正你們的行動作為。』</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米書 2:25; 耶利米書 7:24; 申命記 29:19"> 「他們卻說：『這是枉然。我們要照自己的計謀去行。』各人隨自己頑梗的惡心做事。」</span>
</div>
</div>

<div className="bt">
<div className="bp poetry">
<span className="v" id="v13" data-v="13" data-xref="耶利米書 5:30; 何西阿書 6:10; 耶利米書 23:14"> <span className="pl pl-1">所以，耶和華如此說：</span><br /><span className="pl pl-1">你們且往各國訪問，</span><br /><span className="pl pl-1">有誰聽見這樣的事？</span><br /><span className="pl pl-1">以色列民</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是處女">a</a></sup><br /><span className="pl pl-1">行了一件極可憎惡的事。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="約翰福音 6:68"> <span className="pl pl-1">黎巴嫩的雪從田野的磐石上豈能斷絕呢？</span><br /><span className="pl pl-1">從遠處流下的涼水豈能乾涸呢？</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="耶利米書 6:16; 耶利米書 2:32; 何西阿書 11:2"> <span className="pl pl-1">我的百姓竟忘記我，</span><br /><span className="pl pl-1">向假神燒香，</span><br /><span className="pl pl-1">使他們在所行的路上，在古道上絆跌，</span><br /><span className="pl pl-1">使他們行沒有修築的斜路，</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="詩篇 22:7; 耶利米書 25:9; 耶利米書 19:8"> <span className="pl pl-1">以致他們的地令人驚駭，</span><br /><span className="pl pl-1">常常嗤笑；</span><br /><span className="pl pl-1">凡經過這地的必驚駭搖頭。</span><br /></span>

## 謀害耶利米

<div className="bt">
<div className="bp poetry">
<span className="v" id="v18" data-v="18" data-xref="詩篇 52:2; 耶利米書 11:19; 瑪拉基書 2:7"> 他們就說：「來吧！我們可以設計謀害耶利米；因為我們有祭司講律法，智慧人設謀略，先知說預言，都不能斷絕。來吧！我們可以用舌頭擊打他，不要理會他的一切話。」</span>
<span className="v" id="v19" data-v="19" data-xref="尼希米記 6:9; 耶利米書 20:12; 詩篇 55:16–17"> <span className="pl pl-1">耶和華啊，求你理會我，</span><br /><span className="pl pl-1">且聽那些與我爭競之人的話。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 35:7; 詩篇 57:6; 詩篇 106:23"> <span className="pl pl-1">豈可以惡報善呢？</span><br /><span className="pl pl-1">他們竟挖坑要害我的性命！</span><br /><span className="pl pl-1">求你記念我怎樣站在你面前為他們代求，</span><br /><span className="pl pl-1">要使你的忿怒向他們轉消。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 109:9–20; 耶利米哀歌 5:3; 阿摩司書 4:10"> <span className="pl pl-1">故此，願你將他們的兒女交與饑荒和刀劍；</span><br /><span className="pl pl-1">願他們的妻無子，且作寡婦；</span><br /><span className="pl pl-1">又願他們的男人被死亡所滅，</span><br /><span className="pl pl-1">他們的少年人在陣上被刀擊殺。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="耶利米書 6:26; 詩篇 140:5; 西番雅書 1:10–11"> <span className="pl pl-1">你使敵軍忽然臨到他們的時候，</span><br /><span className="pl pl-1">願人聽見哀聲從他們的屋內發出；</span><br /><span className="pl pl-1">因他們挖坑要捉拿我，</span><br /><span className="pl pl-1">暗設網羅要絆我的腳。</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="詩篇 35:4; 詩篇 69:22–28; 尼希米記 4:4–5"> <span className="pl pl-1">耶和華啊，他們要殺我的那一切計謀，</span><br /><span className="pl pl-1">你都知道。</span><br /><span className="pl pl-1">不要赦免他們的罪孽，</span><br /><span className="pl pl-1">也不要從你面前塗抹他們的罪惡，</span><br /><span className="pl pl-1">要叫他們在你面前跌倒；</span><br /><span className="pl pl-1">願你發怒的時候罰辦他們。</span></span>
</div>

## 耶利米給猶大王的警告

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="耶利米書 34:2; 路加福音 3:19–20; 撒母耳記下 24:11–12"> 耶和華如此說：「你下到猶大王的宮中，在那裏說這話，</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 1:32; 以賽亞書 9:7; 耶利米書 22:4"> 說：『坐大衛寶座的猶大王啊，你和你的臣僕，並進入城門的百姓，都當聽耶和華的話。</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米書 21:12; 彌迦書 6:8; 耶利米書 22:17"> 耶和華如此說：你們要施行公平和公義，拯救被搶奪的脫離欺壓人的手，不可虧負寄居的和孤兒寡婦，不可以強暴待他們，在這地方也不可流無辜人的血。</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米書 17:25"> 你們若認真行這事，就必有坐大衛寶座的君王和他的臣僕百姓，或坐車或騎馬，從這城的各門進入。</span>
<span className="v" id="v5" data-v="5" data-xref="阿摩司書 6:8; 希伯來書 6:13; 創世記 22:16"> 你們若不聽這些話，耶和華說：我指着自己起誓，這城必變為荒場。』</span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 107:34; 以賽亞書 6:11; 以賽亞書 27:10"> 耶和華論到猶大王的家如此說：<br /><span className="pl pl-1">我看你如基列，</span><br /><span className="pl pl-1">如黎巴嫩頂；</span><br /><span className="pl pl-1">然而，我必使你變為曠野，</span><br /><span className="pl pl-1">為無人居住的城邑。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="以賽亞書 37:24; 以賽亞書 10:33–34; 耶利米書 4:6–7"> <span className="pl pl-1">我要預備行毀滅的人，</span><br /><span className="pl pl-1">各拿器械攻擊你；</span><br /><span className="pl pl-1">他們要砍下你佳美的香柏樹，</span><br /><span className="pl pl-1">扔在火中。</span></span>
<span className="v" id="v8" data-v="8" data-xref="列王紀上 9:8–9; 歷代志下 7:20–22; 申命記 29:23–26"> 「許多國的民要經過這城，各人對鄰舍說：『耶和華為何向這大城如此行呢？』</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀下 22:17; 歷代志下 34:25; 耶利米書 50:7"> 他們必回答說：『是因離棄了耶和華－他們上帝的約，事奉敬拜別神。』」</span>
</div>
</div>

## 關於約哈斯

<div className="bt">
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="傳道書 4:2; 耶利米書 22:11; 以賽亞書 57:1"> <span className="pl pl-1">不要為死人哭號；</span><br /><span className="pl pl-1">不要為他悲傷，</span><br /><span className="pl pl-1">卻要為離家出外的人大大哭號；</span><br /><span className="pl pl-1">因為他不得再回來，</span><br /><span className="pl pl-1">也不得再見他的本國。</span></span>
<span className="v" id="v11" data-v="11" data-xref="歷代志上 3:15; 歷代志下 36:1–4; 列王紀下 23:34"> 因為耶和華論到從這地方出去的猶大王約西亞的兒子沙龍<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="在列王下二十三章三十節名約哈斯">a</a></sup>，就是接續他父親約西亞作王的，這樣說：「他必不得再回到這裏來，</span>
<span className="v" id="v12" data-v="12" data-xref="列王紀下 23:34; 耶利米書 22:18"> 卻要死在被擄去的地方，必不得再見這地。」</span>
</div>
</div>

## 關於約雅敬

<div className="bt">
<div className="bp poetry">
<span className="v" id="v13" data-v="13" data-xref="雅各書 5:4; 彌迦書 3:10; 利未記 19:13"> <span className="pl pl-1">那行不義蓋房、行不公造樓、</span><br /><span className="pl pl-1">白白使用人的手工不給工價的有禍了！</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳記下 7:2; 以賽亞書 5:8–9; 哈該書 1:4"> <span className="pl pl-1">他說：我要為自己蓋廣大的房、寬敞的樓，</span><br /><span className="pl pl-1">為自己開窗戶。</span><br /><span className="pl pl-1">這樓房的護牆板是香柏木的，</span><br /><span className="pl pl-1">樓房是丹色油漆的。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="列王紀下 23:25; 以賽亞書 3:10; 傳道書 10:17"> <span className="pl pl-1">難道你作王是在乎造香柏木樓房爭勝嗎？</span><br /><span className="pl pl-1">你的父親豈不是也吃也喝、</span><br /><span className="pl pl-1">也施行公平和公義嗎？</span><br /><span className="pl pl-1">那時他得了福樂。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="耶利米書 9:24; 以賽亞書 1:17; 約翰一書 2:3–4"> <span className="pl pl-1">他為困苦和窮乏人伸冤，</span><br /><span className="pl pl-1">那時就得了福樂。</span><br /><span className="pl pl-1">認識我不在乎此嗎？</span><br /><span className="pl pl-1">這是耶和華說的。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="彼得後書 2:14; 列王紀下 24:4; 耶利米書 22:3"> <span className="pl pl-1">惟有你的眼和你的心專顧貪婪，</span><br /><span className="pl pl-1">流無辜人的血，</span><br /><span className="pl pl-1">行欺壓和強暴。</span></span>
<span className="v" id="v18" data-v="18" data-xref="列王紀上 13:30; 耶利米書 16:6; 耶利米書 16:4"> 所以，耶和華論到猶大王約西亞的兒子約雅敬如此說：<br /><span className="pl pl-1">人必不為他舉哀說：</span><br /><span className="pl pl-1">哀哉！我的哥哥；</span><br /><span className="pl pl-1">或說：哀哉！我的姊姊；</span><br /><span className="pl pl-1">也不為他舉哀說：</span><br /><span className="pl pl-1">哀哉！我的主；</span><br /><span className="pl pl-1">或說：哀哉！我主的榮華。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="耶利米書 36:30; 列王紀上 21:23–24; 歷代志下 36:6"> <span className="pl pl-1">他被埋葬，好像埋驢一樣，</span><br /><span className="pl pl-1">要拉出去扔在耶路撒冷的城門之外。</span></span>
</div>
</div>

<div className="bp poetry">

## 上帝審判哥尼雅

<div className="bt">
<div className="bp poetry">
<span className="v" id="v24" data-v="24" data-xref="耶利米書 37:1; 雅歌 8:6; 歷代志上 3:16"> 耶和華說：「猶大王約雅敬的兒子哥尼雅<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="又名耶哥尼雅；下同">b</a></sup>，雖是我右手上帶印的戒指，我憑我的永生起誓，也必將你從其上摘下來，</span>
<span className="v" id="v25" data-v="25" data-xref="耶利米書 34:20–21; 耶利米書 21:7; 列王紀下 24:15–16"> 並且我必將你交給尋索你命的人和你所懼怕的人手中，就是巴比倫王尼布甲尼撒和迦勒底人的手中。</span>
<span className="v" id="v26" data-v="26" data-xref="列王紀下 24:15; 耶利米書 15:2–4; 以賽亞書 22:17"> 我也必將你和生你的母親趕到別國，並不是你們生的地方；你們必死在那裏，</span>
<span className="v" id="v27" data-v="27" data-xref="耶利米書 44:14; 列王紀下 25:27–30; 詩篇 86:4"> 但心中甚想歸回之地，必不得歸回。」</span>
<span className="v" id="v28" data-v="28" data-xref="詩篇 31:12; 何西阿書 8:8; 耶利米書 48:38"> <span className="pl pl-1">哥尼雅這人是被輕看、破壞的器皿嗎？</span><br /><span className="pl pl-1">是無人喜愛的器皿嗎？</span><br /><span className="pl pl-1">他和他的後裔為何被趕到不認識之地呢？</span><br /></span>
<span className="v" id="v29" data-v="29" data-xref="申命記 32:1; 彌迦書 1:2; 耶利米書 6:19"> <span className="pl pl-1">地啊，地啊，地啊，當聽耶和華的話！</span><br /></span>
<span className="v" id="v30" data-v="30" data-xref="耶利米書 36:30; 詩篇 94:20; 馬太福音 1:11–16"> <span className="pl pl-1">耶和華如此說：</span><br /><span className="pl pl-1">要寫明這人算為無子，</span><br /><span className="pl pl-1">是平生不得亨通的；</span><br /><span className="pl pl-1">因為他後裔中再無一人得亨通，</span><br /><span className="pl pl-1">能坐在大衛的寶座上治理猶大。</span></span>
</div>
</div>

## 耶利米和利甲族

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀下 23:35; 耶利米書 1:3; 耶利米書 25:1"> 當猶大王約西亞之子約雅敬的時候，耶和華的話臨到耶利米說：</span>
<span className="v" id="v2" data-v="2" data-xref="歷代志上 2:55; 歷代志上 9:26; 列王紀上 6:5–6"> 「你去見利甲族的人，和他們說話，領他們進入耶和華殿的一間屋子，給他們酒喝。」</span>
<span className="v" id="v3" data-v="3"> 我就將哈巴洗尼雅的孫子雅利米雅的兒子雅撒尼亞和他弟兄，並他眾子，以及利甲全族的人，</span>
<span className="v" id="v4" data-v="4" data-xref="申命記 33:1; 列王紀下 12:9; 歷代志下 8:14"> 領到耶和華的殿，進入神人伊基大利的兒子哈難眾子的屋子。那屋子在首領的屋子旁邊，在沙龍之子把門的瑪西雅屋子以上。</span>
<span className="v" id="v5" data-v="5" data-xref="傳道書 9:7; 阿摩司書 2:12; 哥林多後書 2:9"> 於是我在利甲族人面前設擺盛滿酒的碗和杯，對他們說：「請你們喝酒。」</span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 1:15; 歷代志上 2:55; 列王紀下 10:15"> 他們卻說：「我們不喝酒；因為我們先祖利甲的兒子約拿達曾吩咐我們說：『你們與你們的子孫永不可喝酒，</span>
<span className="v" id="v7" data-v="7" data-xref="耶利米書 35:10; 創世記 25:27; 尼希米記 8:14–16"> 也不可蓋房、撒種、栽種葡萄園，但一生的年日要住帳棚，使你們的日子在寄居之地得以延長。』</span>
<span className="v" id="v8" data-v="8" data-xref="歌羅西書 3:20; 箴言 4:10; 箴言 1:8–9"> 凡我們先祖利甲的兒子約拿達所吩咐我們的話，我們都聽從了。我們和我們的妻子兒女一生的年日都不喝酒，</span>
<span className="v" id="v9" data-v="9" data-xref="提摩太前書 6:6; 耶利米書 35:7; 詩篇 37:16"> 也不蓋房居住，也沒有葡萄園、田地，和種子，</span>
<span className="v" id="v10" data-v="10"> 但住帳棚，聽從我們先祖約拿達的話，照他所吩咐我們的去行。</span>
<span className="v" id="v11" data-v="11" data-xref="耶利米書 8:14; 耶利米書 4:5–7; 但以理書 1:1–2"> 巴比倫王尼布甲尼撒上此地來，我們因怕迦勒底的軍隊和亞蘭的軍隊，就說：『來吧，我們到耶路撒冷去。』這樣，我們才住在耶路撒冷。」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12"> 耶和華的話臨到耶利米說：</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米書 32:33; 耶利米書 5:3; 耶利米書 6:8–10"> 「萬軍之耶和華－以色列的上帝如此說：你去對猶大人和耶路撒冷的居民說，耶和華說：你們不受教訓，不聽從我的話嗎？</span>
<span className="v" id="v14" data-v="14" data-xref="耶利米書 25:3–4; 耶利米書 7:24–26; 箴言 1:20–33"> 利甲的兒子約拿達所吩咐他子孫不可喝酒的話，他們已經遵守，直到今日也不喝酒，因為他們聽從先祖的吩咐。我從早起來警戒你們，你們卻不聽從我。</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米書 18:11; 以西結書 18:30–32; 耶利米書 25:5–6"> 我從早起來，差遣我的僕人眾先知去，說：『你們各人當回頭，離開惡道，改正行為，不隨從事奉別神，就必住在我所賜給你們和你們列祖的地上。』只是你們沒有聽從我，也沒有側耳而聽。</span>
<span className="v" id="v16" data-v="16" data-xref="瑪拉基書 1:6; 耶利米書 35:14; 路加福音 15:11–13"> 利甲的兒子約拿達的子孫能遵守先人所吩咐他們的命，這百姓卻沒有聽從我！</span>
<span className="v" id="v17" data-v="17" data-xref="以賽亞書 66:4; 以賽亞書 65:12; 羅馬書 10:21"> 因此，耶和華－萬軍之上帝、以色列的上帝如此說：我要使我所說的一切災禍臨到猶大人和耶路撒冷的一切居民。因為我對他們說話，他們沒有聽從；我呼喚他們，他們沒有答應。」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="申命記 5:16; 出埃及記 20:12; 以弗所書 6:1–3"> 耶利米對利甲族的人說：「萬軍之耶和華－以色列的上帝如此說：因你們聽從你們先祖約拿達的吩咐，謹守他的一切誡命，照他所吩咐你們的去行，</span>
<span className="v" id="v19" data-v="19" data-xref="耶利米書 15:19; 路加福音 21:36; 耶利米書 33:17–18"> 所以萬軍之耶和華－以色列的上帝如此說：利甲的兒子約拿達必永不缺人侍立在我面前。」</span>
</div>

## 耶和華給他子民的應許

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="耶利米書 26:15; 耶利米書 1:1–2"> 耶和華的話臨到耶利米說：</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米書 36:32; 以賽亞書 30:8; 哈巴谷書 2:2–3"> 「耶和華－以色列的上帝如此說：你將我對你說過的一切話都寫在書上。</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米書 29:14; 耶利米書 16:15; 耶利米書 30:18"> 耶和華說：日子將到，我要使我的百姓以色列和猶大被擄的人歸回；我也要使他們回到我所賜給他們列祖之地，他們就得這地為業。這是耶和華說的。」</span>
<span className="v" id="v4" data-v="4"> <span className="pl pl-1">以下是耶和華論到以色列和猶大所說的話：</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="西番雅書 1:10–11; 阿摩司書 8:10; 以賽亞書 5:30"> <span className="pl pl-1">耶和華如此說：我們聽見聲音，</span><br /><span className="pl pl-1">是戰抖懼怕而不平安的聲音。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="那鴻書 2:10; 約珥書 2:6; 耶利米書 4:31"> <span className="pl pl-1">你們且訪問看看，</span><br /><span className="pl pl-1">男人有產難嗎？</span><br /><span className="pl pl-1">我怎麼看見人人用手掐腰，</span><br /><span className="pl pl-1">像產難的婦人，</span><br /><span className="pl pl-1">臉面都變青了呢？</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="但以理書 12:1; 撒迦利亞書 14:1–2; 瑪拉基書 4:1"> <span className="pl pl-1">哀哉！那日為大，</span><br /><span className="pl pl-1">無日可比；</span><br /><span className="pl pl-1">這是雅各遭難的時候，</span><br /><span className="pl pl-1">但他必被救出來。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="那鴻書 1:13; 以西結書 34:27; 以賽亞書 9:4"> 萬軍之耶和華說：「到那日，我必從你頸項上折斷仇敵的軛，扭開他的繩索；外邦人不得再使你作他們的奴僕。</span>
<span className="v" id="v9" data-v="9" data-xref="何西阿書 3:5; 以賽亞書 55:3–5; 路加福音 1:69"> 你們卻要事奉耶和華－你們的上帝和我為你們所要興起的王大衛。」</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米書 46:27–28; 以賽亞書 43:5; 耶利米書 29:14"> <span className="pl pl-1">故此，耶和華說：</span><br /><span className="pl pl-1">我的僕人雅各啊，不要懼怕；</span><br /><span className="pl pl-1">以色列啊，不要驚惶；</span><br /><span className="pl pl-1">因我要從遠方拯救你，</span><br /><span className="pl pl-1">從被擄到之地拯救你的後裔；</span><br /><span className="pl pl-1">雅各必回來得享平靖安逸，</span><br /><span className="pl pl-1">無人使他害怕。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="耶利米書 10:24; 耶利米書 1:19; 以賽亞書 8:10"> <span className="pl pl-1">因我與你同在，要拯救你，</span><br /><span className="pl pl-1">也要將所趕散你到的那些國滅絕淨盡，</span><br /><span className="pl pl-1">卻不將你滅絕淨盡，倒要從寬懲治你，</span><br /><span className="pl pl-1">萬不能不罰你</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="不罰你：或譯以你為無罪">a</a></sup><br /><span className="pl pl-1">。</span><br /><span className="pl pl-1">這是耶和華說的。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="耶利米書 15:18; 耶利米書 30:15; 耶利米書 14:17"> <span className="pl pl-1">耶和華如此說：</span><br /><span className="pl pl-1">你的損傷無法醫治；</span><br /><span className="pl pl-1">你的傷痕極其重大。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="耶利米書 46:11; 耶利米書 8:22; 耶利米書 30:17"> <span className="pl pl-1">無人為你分訴，</span><br /><span className="pl pl-1">使你的傷痕得以纏裹；</span><br /><span className="pl pl-1">你沒有醫治的良藥。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="耶利米書 5:6; 約伯記 30:21; 耶利米哀歌 1:2"> <span className="pl pl-1">你所親愛的都忘記你，</span><br /><span className="pl pl-1">不來探問</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或譯：理會">b</a></sup><br /><span className="pl pl-1">你。</span><br /><span className="pl pl-1">我因你的罪孽甚大，罪惡眾多，</span><br /><span className="pl pl-1">曾用仇敵加的傷害傷害你，</span><br /><span className="pl pl-1">用殘忍者的懲治懲治你。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="耶利米書 30:14; 耶利米書 30:12; 耶利米書 6:6–7"> <span className="pl pl-1">你為何因損傷哀號呢？</span><br /><span className="pl pl-1">你的痛苦無法醫治。</span><br /><span className="pl pl-1">我因你的罪孽甚大，罪惡眾多，</span><br /><span className="pl pl-1">曾將這些加在你身上。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="耶利米書 10:25; 以賽亞書 33:1; 出埃及記 23:22"> <span className="pl pl-1">故此，凡吞吃你的必被吞吃；</span><br /><span className="pl pl-1">你的敵人個個都被擄去；</span><br /><span className="pl pl-1">擄掠你的必成為擄物；</span><br /><span className="pl pl-1">搶奪你的必成為掠物。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="詩篇 107:20; 耶利米書 33:6; 彼得前書 2:24"> <span className="pl pl-1">耶和華說：我必使你痊癒，</span><br /><span className="pl pl-1">醫好你的傷痕，</span><br /><span className="pl pl-1">都因人稱你為被趕散的，</span><br /><span className="pl pl-1">說：這是錫安，無人來探問</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="或譯：理會">c</a></sup><br /><span className="pl pl-1">的！</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v18" data-v="18" data-xref="哈該書 2:7–9; 詩篇 102:13; 耶利米書 30:3"> <span className="pl pl-1">耶和華如此說：</span><br /><span className="pl pl-1">我必使雅各被擄去的帳棚歸回，</span><br /><span className="pl pl-1">也必顧惜他的住處。</span><br /><span className="pl pl-1">城必建造在原舊的山岡；</span><br /><span className="pl pl-1">宮殿也照舊有人居住。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="耶利米書 33:22; 以賽亞書 51:11; 以賽亞書 60:22"> <span className="pl pl-1">必有感謝和歡樂的聲音從其中發出，</span><br /><span className="pl pl-1">我要使他們增多，不致減少；</span><br /><span className="pl pl-1">使他們尊榮，不致卑微。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="耶利米書 32:39; 耶利米書 2:3; 耶利米書 50:33–34"> <span className="pl pl-1">他們的兒女要如往日；</span><br /><span className="pl pl-1">他們的會眾堅立在我面前；</span><br /><span className="pl pl-1">凡欺壓他們的，我必刑罰他。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="民數記 16:5; 以西結書 34:23–24; 使徒行傳 5:31"> <span className="pl pl-1">他們的君王必是屬乎他們的；</span><br /><span className="pl pl-1">掌權的必從他們中間而出。</span><br /><span className="pl pl-1">我要使他就近我，</span><br /><span className="pl pl-1">他也要親近我；</span><br /><span className="pl pl-1">不然，誰有膽量親近我呢？</span><br /><span className="pl pl-1">這是耶和華說的。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="啟示錄 21:3; 以西結書 36:28; 耶利米書 31:33"> <span className="pl pl-1">你們要作我的子民，</span><br /><span className="pl pl-1">我要作你們的上帝。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v23" data-v="23" data-xref="耶利米書 23:19–20; 撒迦利亞書 9:14; 耶利米書 25:32"> <span className="pl pl-1">看哪，耶和華的忿怒</span><br /><span className="pl pl-1">好像暴風已經發出；</span><br /><span className="pl pl-1">是掃滅的暴風，</span><br /><span className="pl pl-1">必轉到惡人的頭上。</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="耶利米書 23:20; 何西阿書 3:5; 彌迦書 4:1"> <span className="pl pl-1">耶和華的烈怒必不轉消，</span><br /><span className="pl pl-1">直到他心中所擬定的成就了；</span><br /><span className="pl pl-1">末後的日子你們要明白。</span></span>
</div>

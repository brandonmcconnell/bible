## 以色列人還鄉

<div className="bt">
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="耶利米書 31:31; 何西阿書 1:11; 何西阿書 3:5"> 耶和華說：「當那日子、那時候，以色列人要和猶大人同來，隨走隨哭，尋求耶和華－他們的上帝。</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米書 32:40; 希伯來書 8:6–10; 以賽亞書 55:3"> 他們必訪問錫安，又面向這裏，說：『來吧，你們要與耶和華聯合為永遠不忘的約。』</span>
<span className="v" id="v6" data-v="6" data-xref="以賽亞書 53:6; 馬太福音 9:36; 以西結書 34:14"> 「我的百姓作了迷失的羊，牧人使他們走差路，使他們轉到山上。他們從大山走到小山，竟忘了安歇之處。</span>
<span className="v" id="v7" data-v="7" data-xref="耶利米書 14:8; 耶利米書 2:3; 撒迦利亞書 11:5"> 凡遇見他們的，就把他們吞滅。敵人說：『我們沒有罪；因他們得罪那作公義居所的耶和華，就是他們列祖所仰望的耶和華。』</span>
<span className="v" id="v8" data-v="8" data-xref="以賽亞書 48:20; 耶利米書 51:6; 啟示錄 18:4"> 「我民哪，你們要從巴比倫中逃走，從迦勒底人之地出去，要像羊群前面走的公山羊。</span>
<span className="v" id="v9" data-v="9" data-xref="耶利米書 51:11; 耶利米書 15:14; 撒母耳記下 1:22"> 因我必激動聯合的大國從北方上來攻擊巴比倫，他們要擺陣攻擊她；她必從那裏被攻取。他們的箭好像善射之勇士的箭，一枝也不徒然返回。</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米書 25:12; 以賽亞書 33:23; 以賽亞書 33:4"> 迦勒底必成為掠物；凡擄掠她的都必心滿意足。這是耶和華說的。」</span>
</div>

## 巴比倫陷落

<div className="bp poetry">

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="耶利米書 2:15; 約翰福音 10:10–12; 列王紀下 18:9–13"> 「以色列是打散的羊，是被獅子趕出的。首先是亞述王將他吞滅，末後是巴比倫王尼布甲尼撒將他的骨頭折斷。」</span>

<div className="bp poetry">

<span className="v" id="v22" data-v="22" data-xref="耶利米書 4:19–21; 耶利米書 51:54–56; 以賽亞書 21:2–4"> <span className="pl pl-1">境內有打仗和大毀滅的響聲。</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="耶利米書 51:20–24; 以賽亞書 14:4–6; 啟示錄 18:16"> <span className="pl pl-1">全地的大錘何竟砍斷破壞？</span><br /><span className="pl pl-1">巴比倫在列國中何竟荒涼？</span><br /></span>

<span className="v" id="v26" data-v="26" data-xref="以賽亞書 14:23; 耶利米書 50:10; 以賽亞書 45:3"> <span className="pl pl-1">你們要從極遠的邊界來攻擊她，</span><br /><span className="pl pl-1">開她的倉廩，</span><br /><span className="pl pl-1">將她堆如高堆，</span><br /><span className="pl pl-1">毀滅淨盡，絲毫不留。</span><br /></span>

<span className="v" id="v28" data-v="28" data-xref="以賽亞書 48:20; 耶利米書 50:15; 耶利米哀歌 1:10"> 有從巴比倫之地逃避出來的人，在錫安揚聲報告耶和華－我們的上帝報仇，就是為他的殿報仇。）</span>
<span className="v" id="v29" data-v="29" data-xref="耶利米書 51:56; 以賽亞書 47:10; 但以理書 4:37"> 「招集一切弓箭手來攻擊巴比倫。要在巴比倫四圍安營，不要容一人逃脫，照着她所做的報應她；她怎樣待人，也要怎樣待她，因為她向耶和華－以色列的聖者發了狂傲。</span>
<span className="v" id="v30" data-v="30" data-xref="耶利米書 49:26; 耶利米書 18:21; 耶利米書 9:21"> 所以她的少年人必仆倒在街上。當那日，一切兵丁必默默無聲。這是耶和華說的。」</span>
<span className="v" id="v31" data-v="31" data-xref="耶利米書 21:13; 耶利米書 50:29; 以西結書 39:1"> <span className="pl pl-1">主－萬軍之耶和華說：</span><br /><span className="pl pl-1">你這狂傲的啊，我與你反對，</span><br /><span className="pl pl-1">因為我追討你的日子已經來到。</span><br /></span>
<span className="v" id="v32" data-v="32" data-xref="耶利米書 21:14; 耶利米書 49:27; 以賽亞書 10:12–15"> <span className="pl pl-1">狂傲的必絆跌仆倒，無人扶起。</span><br /><span className="pl pl-1">我也必使火在他的城邑中着起來，</span><br /><span className="pl pl-1">將他四圍所有的盡行燒滅。</span></span>
<span className="v" id="v33" data-v="33" data-xref="以賽亞書 14:17; 出埃及記 9:2–3; 以賽亞書 58:6"> 萬軍之耶和華如此說：「以色列人和猶大人一同受欺壓；凡擄掠他們的都緊緊抓住他們，不肯釋放。</span>
<span className="v" id="v34" data-v="34" data-xref="以賽亞書 54:5; 耶利米書 15:21; 以賽亞書 41:14"> 他們的救贖主大有能力，萬軍之耶和華是他的名。他必伸清他們的冤，好使全地得平安，並攪擾巴比倫的居民。」</span>

<span className="v" id="v36" data-v="36" data-xref="耶利米書 49:22; 那鴻書 3:13; 以賽亞書 44:25"> <span className="pl pl-1">有刀劍臨到矜誇的人，</span><br /><span className="pl pl-1">他們就成為愚昧；</span><br /><span className="pl pl-1">有刀劍臨到她的勇士，</span><br /><span className="pl pl-1">他們就驚惶。</span><br /></span>

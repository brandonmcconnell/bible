## 耶利米寫信給巴比倫的猶大人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以斯帖記 9:20; 使徒行傳 15:23; 希伯來書 13:22"> 先知耶利米從耶路撒冷寄信與被擄的祭司、先知，和眾民，並生存的長老，就是尼布甲尼撒從耶路撒冷擄到巴比倫去的。（</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米書 22:24–28; 耶利米書 27:20; 歷代志下 36:9–10"> 這在耶哥尼雅王和太后、太監，並猶大、耶路撒冷的首領，以及工匠、鐵匠都離了耶路撒冷以後。）</span>
<span className="v" id="v3" data-v="3" data-xref="以西結書 8:11; 歷代志下 34:20; 耶利米書 39:14"> 他藉沙番的兒子以利亞薩和希勒家的兒子基瑪利的手寄去。他們二人是猶大王西底家打發往巴比倫去見尼布甲尼撒王的。</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米書 24:5; 以賽亞書 10:5–6; 以賽亞書 45:7"> 信上說：「萬軍之耶和華－以色列的上帝對一切被擄去的（就是我使他們從耶路撒冷被擄到巴比倫的人）如此說：</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米書 29:28; 耶利米書 29:10; 以西結書 28:26"> 你們要蓋造房屋，住在其中；栽種田園，吃其中所產的；</span>
<span className="v" id="v6" data-v="6" data-xref="創世記 24:3–4; 創世記 24:51; 創世記 28:1–4"> 娶妻生兒女，為你們的兒子娶妻，使你們的女兒嫁人，生兒養女。在那裏生養眾多，不致減少。</span>
<span className="v" id="v7" data-v="7" data-xref="提摩太前書 2:1–2; 以斯拉記 6:10; 彼得前書 2:13–17"> 我所使你們被擄到的那城，你們要為那城求平安，為那城禱告耶和華；因為那城得平安，你們也隨着得平安。</span>
<span className="v" id="v8" data-v="8" data-xref="以弗所書 5:6; 耶利米書 5:31; 帖撒羅尼迦後書 2:9–11"> 萬軍之耶和華－以色列的上帝如此說：不要被你們中間的先知和占卜的誘惑，也不要聽信自己所做的夢；</span>
<span className="v" id="v9" data-v="9" data-xref="耶利米書 27:15; 耶利米書 29:31; 耶利米書 29:23"> 因為他們託我的名對你們說假預言，我並沒有差遣他們。這是耶和華說的。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="但以理書 9:2; 撒迦利亞書 7:5; 耶利米書 24:6–7"> 「耶和華如此說：為巴比倫所定的七十年滿了以後，我要眷顧你們，向你們成就我的恩言，使你們仍回此地。</span>
<span className="v" id="v11" data-v="11" data-xref="以賽亞書 55:8–12; 詩篇 33:11; 彌迦書 4:12"> 耶和華說：我知道我向你們所懷的意念是賜平安的意念，不是降災禍的意念，要叫你們末後有指望。</span>
<span className="v" id="v12" data-v="12" data-xref="馬太福音 7:7–8; 耶利米書 33:3; 詩篇 50:15"> 你們要呼求我，禱告我，我就應允你們。</span>
<span className="v" id="v13" data-v="13" data-xref="申命記 4:29–31; 詩篇 119:2; 馬太福音 7:7"> 你們尋求我，若專心尋求我，就必尋見。</span>
<span className="v" id="v14" data-v="14" data-xref="以西結書 36:1–38; 耶利米書 30:3; 歷代志上 28:9"> 耶和華說：我必被你們尋見，我也必使你們被擄的人歸回，將你們從各國中和我所趕你們到的各處招聚了來，又將你們帶回我使你們被擄掠離開的地方。這是耶和華說的。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="耶利米書 29:8–9; 耶利米書 28:1–17; 以西結書 1:3"> 「你們說：『耶和華在巴比倫為我們興起先知』；</span>
<span className="v" id="v16" data-v="16" data-xref="耶利米書 38:2–3; 耶利米書 38:17–23; 以西結書 17:12–21"> 所以耶和華論到坐大衛寶座的王和住在這城裏的一切百姓，就是未曾與你們一同被擄的弟兄，</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米書 24:8–10; 耶利米書 29:18; 耶利米書 24:1–3"> 萬軍之耶和華如此說：『看哪，我必使刀劍、饑荒、瘟疫臨到他們，使他們像極壞的無花果，壞得不可吃。</span>
<span className="v" id="v18" data-v="18" data-xref="歷代志下 29:8; 耶利米書 15:4; 耶利米書 42:18"> 我必用刀劍、饑荒、瘟疫追趕他們，使他們在天下萬國拋來拋去，在我所趕他們到的各國中，令人咒詛、驚駭、嗤笑、羞辱。</span>
<span className="v" id="v19" data-v="19" data-xref="耶利米書 6:19; 耶利米書 26:5; 耶利米書 7:24–26"> 耶和華說：這是因為他們沒有聽從我的話，就是我從早起來差遣我僕人眾先知去說的，無奈他們不聽。這是耶和華說的。</span>
<span className="v" id="v20" data-v="20" data-xref="耶利米書 24:5; 彌迦書 4:10; 以西結書 3:15"> 所以你們一切被擄去的，就是我從耶路撒冷打發到巴比倫去的，當聽耶和華的話。』」</span>
<span className="v" id="v21" data-v="21" data-xref="耶利米書 14:14–15; 耶利米哀歌 2:14; 耶利米書 29:8–9"> 萬軍之耶和華－以色列的上帝論到哥賴雅的兒子亞哈，並瑪西雅的兒子西底家，如此說：「他們是託我名向你們說假預言的，我必將他們交在巴比倫王尼布甲尼撒的手中；他要在你們眼前殺害他們。</span>
<span className="v" id="v22" data-v="22" data-xref="以賽亞書 65:15; 但以理書 3:6; 但以理書 3:21"> 住巴比倫一切被擄的猶大人必藉這二人賭咒說：『願耶和華使你像巴比倫王在火中燒的西底家和亞哈一樣。』</span>
<span className="v" id="v23" data-v="23" data-xref="耶利米書 23:14; 希伯來書 4:13; 瑪拉基書 3:5"> 這二人是在以色列中行了醜事，與鄰舍的妻行淫，又假託我名說我未曾吩咐他們的話。知道的是我，作見證的也是我。這是耶和華說的。」</span>
</div>
</div>

## 示瑪雅的信件

<div className="bt">
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="耶利米書 29:31–32"> 「論到尼希蘭人示瑪雅，你當說，</span>
<span className="v" id="v25" data-v="25" data-xref="耶利米書 37:3; 耶利米書 29:29; 耶利米書 52:24"> 萬軍之耶和華－以色列的上帝如此說：你曾用自己的名寄信給耶路撒冷的眾民和祭司瑪西雅的兒子西番雅，並眾祭司，說：</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米書 20:1–2; 列王紀下 9:11; 約翰福音 10:20"> 『耶和華已經立你西番雅為祭司，代替祭司耶何耶大，使耶和華殿中有官長，好將一切狂妄自稱為先知的人用枷枷住，用鎖鎖住。</span>
<span className="v" id="v27" data-v="27" data-xref="歷代志下 25:16; 耶利米書 43:2–3; 耶利米書 29:26"> 現在亞拿突人耶利米向你們自稱為先知，你們為何沒有責備他呢？</span>
<span className="v" id="v28" data-v="28" data-xref="耶利米書 29:5; 耶利米書 29:1; 耶利米書 29:10"> 因為他寄信給我們在巴比倫的人說：被擄的事必長久。你們要蓋造房屋，住在其中；栽種田園，吃其中所產的。』」</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="耶利米書 29:25"> 祭司西番雅就把這信念給先知耶利米聽。</span>
<span className="v" id="v30" data-v="30"> 於是耶和華的話臨到耶利米說：</span>
<span className="v" id="v31" data-v="31" data-xref="耶利米書 29:9; 耶利米書 29:23–24; 耶利米書 14:14–15"> 「你當寄信給一切被擄的人說：『耶和華論到尼希蘭人示瑪雅說：因為示瑪雅向你們說預言，我並沒有差遣他，他使你們倚靠謊言；</span>
<span className="v" id="v32" data-v="32" data-xref="耶利米書 28:16; 列王紀下 7:19–20; 耶利米書 17:6"> 所以耶和華如此說：我必刑罰尼希蘭人示瑪雅和他的後裔，他必無一人存留住在這民中，也不得見我所要賜與我百姓的福樂，因為他向耶和華說了叛逆的話。這是耶和華說的。』」</span>
</div>
</div>

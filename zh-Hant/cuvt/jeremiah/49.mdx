## 耶和華審判亞捫

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="阿摩司書 1:13–15; 西番雅書 2:8–11; 以西結書 25:2–10"> 論亞捫人。耶和華如此說：<br /><span className="pl pl-1">以色列沒有兒子嗎？</span><br /><span className="pl pl-1">沒有後嗣嗎？</span><br /><span className="pl pl-1">瑪勒堪為何得迦得之地為業呢？</span><br /><span className="pl pl-1">屬他的民為何住其中的城邑呢？</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="耶利米書 4:19; 以西結書 21:20; 申命記 3:11"> <span className="pl pl-1">耶和華說：</span><br /><span className="pl pl-1">日子將到，我必使人聽見打仗的喊聲，</span><br /><span className="pl pl-1">是攻擊亞捫人拉巴的喊聲。</span><br /><span className="pl pl-1">拉巴要成為亂堆；</span><br /><span className="pl pl-1">屬她的鄉村</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是女子">a</a></sup><br /><span className="pl pl-1">要被火焚燒。</span><br /><span className="pl pl-1">先前得以色列地為業的，</span><br /><span className="pl pl-1">此時以色列倒要得他們的地為業。</span><br /><span className="pl pl-1">這是耶和華說的。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v3" data-v="3" data-xref="耶利米書 48:7; 耶利米書 48:37; 以賽亞書 15:2"> <span className="pl pl-1">希實本哪，你要哀號，</span><br /><span className="pl pl-1">因為愛地變為荒場。</span><br /><span className="pl pl-1">拉巴的居民</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原文是女子">b</a></sup><br /><span className="pl pl-1">哪，要呼喊，</span><br /><span className="pl pl-1">以麻布束腰；</span><br /><span className="pl pl-1">要哭號，在籬笆中跑來跑去；</span><br /><span className="pl pl-1">因瑪勒堪和屬他的祭司、</span><br /><span className="pl pl-1">首領要一同被擄去。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="提摩太前書 6:17; 耶利米書 9:23; 耶利米書 21:13"> <span className="pl pl-1">背道的民</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="原文是女子">c</a></sup><br /><span className="pl pl-1">哪，</span><br /><span className="pl pl-1">你們為何因有山谷，</span><br /><span className="pl pl-1">就是水流的山谷誇張呢？</span><br /><span className="pl pl-1">為何倚靠財寶說：</span><br /><span className="pl pl-1">誰能來到我們這裏呢？</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="耶利米書 46:5; 耶利米書 49:29; 耶利米書 15:8"> <span className="pl pl-1">主－萬軍之耶和華說：</span><br /><span className="pl pl-1">我要使恐嚇從四圍的人中臨到你們；</span><br /><span className="pl pl-1">你們必被趕出，</span><br /><span className="pl pl-1">各人一直前往，</span><br /><span className="pl pl-1">沒有人收聚逃民。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="耶利米書 49:39; 耶利米書 48:47; 以西結書 16:53"> <span className="pl pl-1">後來我還要使被擄的亞捫人歸回。</span><br /><span className="pl pl-1">這是耶和華說的。</span></span>
</div>
</div>

## 耶和華審判以東

<div className="bt">
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="阿摩司書 1:11–12; 耶利米書 25:21; 創世記 36:15"> 論以東。萬軍之耶和華如此說：<br /><span className="pl pl-1">提幔中再沒有智慧嗎？</span><br /><span className="pl pl-1">明哲人不再有謀略嗎？</span><br /><span className="pl pl-1">他們的智慧盡歸無有嗎？</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="耶利米書 25:23; 耶利米書 46:21; 耶利米書 49:30"> <span className="pl pl-1">底但的居民哪，要轉身逃跑，</span><br /><span className="pl pl-1">住在深密處；</span><br /><span className="pl pl-1">因為我向以掃追討的時候，</span><br /><span className="pl pl-1">必使災殃臨到他。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="俄巴底亞書 1:5–6; 以賽亞書 17:6"> <span className="pl pl-1">摘葡萄的若來到他那裏，</span><br /><span className="pl pl-1">豈不剩下些葡萄呢？</span><br /><span className="pl pl-1">盜賊若夜間而來，</span><br /><span className="pl pl-1">豈不毀壞直到夠了呢？</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="以賽亞書 17:14; 瑪拉基書 1:3–4; 以賽亞書 45:3"> <span className="pl pl-1">我卻使以掃赤露，</span><br /><span className="pl pl-1">顯出他的隱密處；</span><br /><span className="pl pl-1">他不能自藏。</span><br /><span className="pl pl-1">他的後裔、弟兄、鄰舍盡都滅絕；</span><br /><span className="pl pl-1">他也歸於無有。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 68:5; 何西阿書 14:3; 雅各書 1:27"> <span className="pl pl-1">你撇下孤兒，我必保全他們的命；</span><br /><span className="pl pl-1">你的寡婦可以倚靠我。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="耶利米書 25:28–29; 俄巴底亞書 1:16; 耶利米書 25:15"> 耶和華如此說：「原不該喝那杯的一定要喝。你能盡免刑罰嗎？你必不能免，一定要喝！」</span>
<span className="v" id="v13" data-v="13" data-xref="創世記 22:16; 以賽亞書 34:6; 創世記 36:33"> 耶和華說：「我指着自己起誓，波斯拉必令人驚駭、羞辱、咒詛，並且荒涼。她的一切城邑必變為永遠的荒場。」</span>
<span className="v" id="v14" data-v="14" data-xref="以賽亞書 30:4; 以賽亞書 37:7; 以西結書 7:25–26"> <span className="pl pl-1">我從耶和華那裏聽見信息，</span><br /><span className="pl pl-1">並有使者被差往列國去，說：</span><br /><span className="pl pl-1">你們聚集來攻擊以東，</span><br /><span className="pl pl-1">要起來爭戰。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="路加福音 1:51; 俄巴底亞書 1:2; 彌迦書 7:10"> <span className="pl pl-1">我使你在列國中為最小，</span><br /><span className="pl pl-1">在世人中被藐視。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="以賽亞書 49:25; 阿摩司書 9:2; 約伯記 39:27"> <span className="pl pl-1">住在山穴中據守山頂的啊，</span><br /><span className="pl pl-1">論到你的威嚇，</span><br /><span className="pl pl-1">你因心中的狂傲自欺；</span><br /><span className="pl pl-1">你雖如大鷹高高搭窩，</span><br /><span className="pl pl-1">我卻從那裏拉下你來。</span><br /><span className="pl pl-1">這是耶和華說的。</span></span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="以西結書 35:7; 耶利米書 50:13; 耶利米書 49:13"> 「以東必令人驚駭；凡經過的人就受驚駭，又因她一切的災禍嗤笑。</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米書 49:33; 申命記 29:23; 耶利米書 50:40"> 耶和華說：必無人住在那裏，也無人在其中寄居，要像所多瑪、蛾摩拉，和鄰近的城邑傾覆的時候一樣。</span>
<span className="v" id="v19" data-v="19" data-xref="耶利米書 12:5; 耶利米書 30:21; 耶利米書 50:44–46"> 仇敵必像獅子從約旦河邊的叢林上來，攻擊堅固的居所。轉眼之間，我要使以東人逃跑，離開這地。誰蒙揀選，我就派誰治理這地。誰能比我呢？誰能給我定規日期呢？有何牧人能在我面前站立得住呢？</span>
<span className="v" id="v20" data-v="20" data-xref="耶利米書 50:45; 瑪拉基書 1:3–4; 耶利米書 49:7"> 你們要聽耶和華攻擊以東所說的謀略和他攻擊提幔居民所定的旨意。仇敵定要將他們群眾微弱的拉去，定要使他們的居所荒涼。</span>
<span className="v" id="v21" data-v="21" data-xref="耶利米書 50:46; 以西結書 32:10; 以賽亞書 14:4–15"> 因他們仆倒的聲音，地就震動。人在紅海那裏必聽見呼喊的聲音。</span>
<span className="v" id="v22" data-v="22" data-xref="耶利米書 48:40–41; 何西阿書 8:1; 以賽亞書 13:8"> 仇敵必如大鷹飛起，展開翅膀攻擊波斯拉。到那日，以東的勇士心中疼痛如臨產的婦人。」</span>
</div>
</div>

## 耶和華審判大馬士革

<div className="bt">
<div className="bp poetry">
<span className="v" id="v23" data-v="23" data-xref="以賽亞書 10:9; 列王紀下 18:34; 創世記 15:2"> <span className="pl pl-1">論大馬士革。</span><br /><span className="pl pl-1">哈馬和亞珥拔蒙羞，</span><br /><span className="pl pl-1">因他們聽見凶惡的信息就消化了。</span><br /><span className="pl pl-1">海上有憂愁，不得平靜。</span><br /></span>
<span className="v" id="v24" data-v="24"> <span className="pl pl-1">大馬士革發軟，轉身逃跑。</span><br /><span className="pl pl-1">戰兢將她捉住；</span><br /><span className="pl pl-1">痛苦憂愁將她抓住，</span><br /><span className="pl pl-1">如產難的婦人一樣。</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="耶利米書 33:9; 耶利米書 51:41; 以賽亞書 1:26"> <span className="pl pl-1">我所喜樂可稱讚的城，</span><br /><span className="pl pl-1">為何被撇棄了呢？</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="耶利米書 50:30; 阿摩司書 4:10; 耶利米書 11:22"> <span className="pl pl-1">她的少年人必仆倒在街上；</span><br /><span className="pl pl-1">當那日，一切兵丁必默默無聲。</span><br /><span className="pl pl-1">這是萬軍之耶和華說的。</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="阿摩司書 1:3–5; 列王紀上 15:18–20; 耶利米書 43:12"> <span className="pl pl-1">我必在大馬士革城中使火着起，</span><br /><span className="pl pl-1">燒滅便‧哈達的宮殿。</span></span>
</div>
</div>

## 審判基達和夏瑣城

<div className="bt">
<div className="bp poetry">
<span className="v" id="v28" data-v="28" data-xref="士師記 6:3; 創世記 25:13; 以賽亞書 11:14"> 論巴比倫王尼布甲尼撒所攻打的基達和夏瑣的諸國。耶和華如此說：<br /><span className="pl pl-1">迦勒底人哪，起來上基達去，</span><br /><span className="pl pl-1">毀滅東方人。</span><br /></span>
<span className="v" id="v29" data-v="29" data-xref="耶利米書 46:5; 耶利米書 6:25; 哈巴谷書 3:7"> <span className="pl pl-1">他們的帳棚和羊群都要奪去，</span><br /><span className="pl pl-1">將幔子和一切器皿，並駱駝為自己掠去。</span><br /><span className="pl pl-1">人向他們喊着說：</span><br /><span className="pl pl-1">四圍都有驚嚇。</span><br /></span>
<span className="v" id="v30" data-v="30" data-xref="耶利米書 25:9; 耶利米書 27:6; 以賽亞書 10:7"> <span className="pl pl-1">耶和華說：</span><br /><span className="pl pl-1">夏瑣的居民哪，要逃奔遠方，</span><br /><span className="pl pl-1">住在深密處；</span><br /><span className="pl pl-1">因為巴比倫王尼布甲尼撒設計謀害你們，</span><br /><span className="pl pl-1">起意攻擊你們。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v31" data-v="31" data-xref="以西結書 38:11; 民數記 23:9; 申命記 33:28"> <span className="pl pl-1">耶和華說：</span><br /><span className="pl pl-1">迦勒底人哪，起來！</span><br /><span className="pl pl-1">上安逸無慮的居民那裏去；</span><br /><span className="pl pl-1">他們是無門無閂、獨自居住的。</span><br /></span>
<span className="v" id="v32" data-v="32" data-xref="耶利米書 9:26; 耶利米書 25:23; 耶利米書 49:36"> <span className="pl pl-1">他們的駱駝必成為掠物；</span><br /><span className="pl pl-1">他們眾多的牲畜必成為擄物。</span><br /><span className="pl pl-1">我必將剃周圍頭髮的人分散四方</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="原文是風">d</a></sup><br /><span className="pl pl-1">，</span><br /><span className="pl pl-1">使災殃從四圍臨到他們。</span><br /><span className="pl pl-1">這是耶和華說的。</span><br /></span>
<span className="v" id="v33" data-v="33" data-xref="耶利米書 10:22; 耶利米書 9:11; 耶利米書 51:37"> <span className="pl pl-1">夏瑣必成為野狗的住處，</span><br /><span className="pl pl-1">永遠淒涼；</span><br /><span className="pl pl-1">必無人住在那裏，</span><br /><span className="pl pl-1">也無人在其中寄居。</span></span>
</div>
</div>

## 耶和華審判以攔

<div className="bt">
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="創世記 10:22; 但以理書 8:2; 耶利米書 25:25"> 猶大王西底家登基的時候，耶和華論以攔的話臨到先知耶利米說：</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="以賽亞書 22:6; 耶利米書 51:56; 詩篇 46:9"> 「萬軍之耶和華如此說：我必折斷以攔人的弓，就是他們為首的權力。</span>
<span className="v" id="v36" data-v="36" data-xref="耶利米書 49:32; 啟示錄 7:1; 以西結書 5:10"> 我要使四風從天的四方颳來，臨到以攔人，將他們分散四方<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="原文是風">e</a></sup>。這被趕散的人沒有一國不到的。」</span>
<span className="v" id="v37" data-v="37" data-xref="耶利米書 9:16; 耶利米書 48:2; 耶利米書 49:22"> 耶和華說：「我必使以攔人在仇敵和尋索其命的人面前驚惶；我也必使災禍，就是我的烈怒臨到他們，又必使刀劍追殺他們，直到將他們滅盡。</span>
<span className="v" id="v38" data-v="38" data-xref="耶利米書 43:10; 但以理書 7:9–14"> 我要在以攔設立我的寶座，從那裏除滅君王和首領。這是耶和華說的。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="耶利米書 48:47; 何西阿書 3:5; 彌迦書 4:1"> 「到末後，我還要使被擄的以攔人歸回。這是耶和華說的。」</span>
</div>
</div>

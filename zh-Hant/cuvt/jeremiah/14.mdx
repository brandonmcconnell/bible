## 可怕的旱災

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="耶利米書 17:8"> 耶和華論到乾旱之災的話臨到耶利米：</span>
<span className="v" id="v2" data-v="2" data-xref="以賽亞書 3:26; 耶利米書 8:21; 撒母耳記上 5:12"> <span className="pl pl-1">猶大悲哀，城門衰敗。</span><br /><span className="pl pl-1">眾人披上黑衣坐在地上；</span><br /><span className="pl pl-1">耶路撒冷的哀聲上達。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳記下 15:30; 詩篇 40:14; 列王紀下 18:31"> <span className="pl pl-1">他們的貴冑打發家僮打水；</span><br /><span className="pl pl-1">他們來到水池，</span><br /><span className="pl pl-1">見沒有水，就拿着空器皿，</span><br /><span className="pl pl-1">蒙羞慚愧，抱頭而回。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="約珥書 1:19–20; 約珥書 1:11; 耶利米書 3:3"> <span className="pl pl-1">耕地的也蒙羞抱頭；</span><br /><span className="pl pl-1">因為無雨降在地上，</span><br /><span className="pl pl-1">地都乾裂。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 29:9; 約伯記 39:1–4; 以賽亞書 15:6"> <span className="pl pl-1">田野的母鹿生下小鹿，就撇棄，</span><br /><span className="pl pl-1">因為無草。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="耶利米書 2:24; 約伯記 39:5–6; 約珥書 1:18"> <span className="pl pl-1">野驢站在淨光的高處，喘氣好像野狗；</span><br /><span className="pl pl-1">因為無草，眼目失明。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="詩篇 25:11; 何西阿書 5:5; 耶利米書 14:20–21"> <span className="pl pl-1">耶和華啊，我們的罪孽雖然作見證告我們，</span><br /><span className="pl pl-1">還求你為你名的緣故行事。</span><br /><span className="pl pl-1">我們本是多次背道，得罪了你。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="耶利米書 17:13; 耶利米書 50:7; 以賽亞書 43:3"> <span className="pl pl-1">以色列所盼望、在患難時作他救主的啊，</span><br /><span className="pl pl-1">你為何在這地像寄居的，</span><br /><span className="pl pl-1">又像行路的只住一宵呢？</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="以賽亞書 63:19; 以賽亞書 59:1; 耶利米書 15:16"> <span className="pl pl-1">你為何像受驚的人，</span><br /><span className="pl pl-1">像不能救人的勇士呢？</span><br /><span className="pl pl-1">耶和華啊，你仍在我們中間；</span><br /><span className="pl pl-1">我們也稱為你名下的人，</span><br /><span className="pl pl-1">求你不要離開我們。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="何西阿書 9:9; 何西阿書 8:13; 詩篇 119:101"> <span className="pl pl-1">耶和華對這百姓如此說：</span><br /><span className="pl pl-1">這百姓喜愛妄行</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是飄流">a</a></sup><br /><span className="pl pl-1">，</span><br /><span className="pl pl-1">不禁止腳步，</span><br /><span className="pl pl-1">所以耶和華不悅納他們。</span><br /><span className="pl pl-1">現今要記念他們的罪孽，</span><br /><span className="pl pl-1">追討他們的罪惡。</span></span>
<span className="v" id="v11" data-v="11" data-xref="耶利米書 7:16; 耶利米書 11:14; 出埃及記 32:32–34"> 耶和華又對我說：「不要為這百姓祈禱求好處。</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米書 11:11; 以西結書 8:18; 箴言 1:28"> 他們禁食的時候，我不聽他們的呼求；他們獻燔祭和素祭，我也不悅納；我卻要用刀劍、饑荒、瘟疫滅絕他們。」</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米書 6:14; 耶利米書 4:10; 彼得後書 2:1"> 我就說：「唉！主耶和華啊，那些先知常對他們說：『你們必不看見刀劍，也不遭遇饑荒；耶和華要在這地方賜你們長久的平安。』」</span>
<span className="v" id="v14" data-v="14" data-xref="以西結書 13:6–7; 以西結書 12:24; 耶利米書 29:8–9"> 耶和華對我說：「那些先知託我的名說假預言，我並沒有打發他們，沒有吩咐他們，也沒有對他們說話；他們向你們預言的，乃是虛假的異象和占卜，並虛無的事，以及本心的詭詐。</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米書 5:12–13; 以西結書 14:10; 耶利米書 23:14–15"> 所以耶和華如此說：論到託我名說預言的那些先知，我並沒有打發他們；他們還說這地不能有刀劍饑荒，其實那些先知必被刀劍饑荒滅絕。</span>
<span className="v" id="v16" data-v="16" data-xref="耶利米書 7:33; 箴言 1:31; 耶利米書 15:2–3"> 聽他們說預言的百姓必因饑荒刀劍拋在耶路撒冷的街道上，無人葬埋。他們連妻子帶兒女，都是如此。我必將他們的惡倒在他們身上<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或譯：我必使他們罪惡的報應臨到他們身上">b</a></sup>。」</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米書 8:21; 耶利米書 9:1; 耶利米書 13:17"> <span className="pl pl-1">你要將這話對他們說：</span><br /><span className="pl pl-1">願我眼淚汪汪，</span><br /><span className="pl pl-1">晝夜不息，</span><br /><span className="pl pl-1">因為我百姓</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="原文是民的處女">c</a></sup><br /><span className="pl pl-1">受了裂口破壞的大傷。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="以西結書 7:15; 耶利米哀歌 1:20; 耶利米書 8:10"> <span className="pl pl-1">我若出往田間，</span><br /><span className="pl pl-1">就見有被刀殺的；</span><br /><span className="pl pl-1">我若進入城內，</span><br /><span className="pl pl-1">就見有因饑荒患病的；</span><br /><span className="pl pl-1">連先知帶祭司在國中往來，</span><br /><span className="pl pl-1">也是毫無知識</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="或譯：不知怎樣才好">d</a></sup><br /><span className="pl pl-1">。</span></span>
</div>
</div>

<div className="bt">
<div className="bp poetry">
<span className="v" id="v19" data-v="19" data-xref="耶利米哀歌 5:22; 耶利米書 8:15; 耶利米書 6:30"> <span className="pl pl-1">你全然棄掉猶大嗎？</span><br /><span className="pl pl-1">你心厭惡錫安嗎？</span><br /><span className="pl pl-1">為何擊打我們，以致無法醫治呢？</span><br /><span className="pl pl-1">我們指望平安，卻得不着好處；</span><br /><span className="pl pl-1">指望痊癒，不料，受了驚惶。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="耶利米書 3:25; 詩篇 32:5; 約翰一書 1:7–9"> <span className="pl pl-1">耶和華啊，我們承認自己的罪惡，</span><br /><span className="pl pl-1">和我們列祖的罪孽，</span><br /><span className="pl pl-1">因我們得罪了你。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="耶利米書 14:7; 詩篇 106:45; 耶利米書 3:17"> <span className="pl pl-1">求你為你名的緣故，</span><br /><span className="pl pl-1">不厭惡我們，</span><br /><span className="pl pl-1">不辱沒你榮耀的寶座。</span><br /><span className="pl pl-1">求你追念，</span><br /><span className="pl pl-1">不要背了與我們所立的約。</span><br /></span>

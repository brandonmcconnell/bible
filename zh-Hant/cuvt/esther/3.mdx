## 哈曼陰謀除滅猶大人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民數記 24:7; 以斯帖記 5:11; 但以理書 6:2"> 這事以後，亞哈隨魯王抬舉亞甲族哈米大他的兒子哈曼，使他高升，叫他的爵位超過與他同事的一切臣宰。</span>
<span className="v" id="v2" data-v="2" data-xref="以斯帖記 3:5; 詩篇 15:4; 以斯帖記 5:9"> 在朝門的一切臣僕都跪拜哈曼，因為王如此吩咐；惟獨末底改不跪不拜。</span>
<span className="v" id="v3" data-v="3" data-xref="以斯帖記 3:2; 出埃及記 1:17; 以斯帖記 2:19"> 在朝門的臣僕問末底改說：「你為何違背王的命令呢？」</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 39:10; 約拿書 1:9; 但以理書 6:20–28"> 他們天天勸他，他還是不聽，他們就告訴哈曼，要看末底改的事站得住站不住，因他已經告訴他們自己是猶大人。</span>
<span className="v" id="v5" data-v="5" data-xref="但以理書 3:19; 以斯帖記 5:9; 箴言 21:24"> 哈曼見末底改不跪不拜，他就怒氣填胸。</span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 83:4; 啟示錄 12:12"> 他們已將末底改的本族告訴哈曼；他以為下手害末底改一人是小事，就要滅絕亞哈隨魯王通國所有的猶大人，就是末底改的本族。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="以斯拉記 6:15; 以西結書 21:21–22; 以斯帖記 9:24–26"> 亞哈隨魯王十二年正月，就是尼散月，人在哈曼面前，按日日月月掣普珥，就是掣籤，要定何月何日為吉，擇定了十二月，就是亞達月。</span>
<span className="v" id="v8" data-v="8" data-xref="以斯拉記 4:12–15; 使徒行傳 16:20–21; 申命記 4:27"> 哈曼對亞哈隨魯王說：「有一種民散居在王國各省的民中；他們的律例與萬民的律例不同，也不守王的律例，所以容留他們與王無益。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 23:16; 馬太福音 18:24"> 王若以為美，請下旨意滅絕他們；我就捐一萬他連得銀子交給掌管國帑的人，納入王的府庫。」</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 41:42; 以斯帖記 8:2; 以斯帖記 7:6"> 於是王從自己手上摘下戒指給猶大人的仇敵－亞甲族哈米大他的兒子哈曼。</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 23:25; 耶利米書 40:4; 耶利米書 26:14"> 王對哈曼說：「這銀子仍賜給你，這民也交給你，你可以隨意待他們。」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="列王紀上 21:8; 以斯帖記 1:22; 但以理書 6:12"> 正月十三日，就召了王的書記來，照着哈曼一切所吩咐的，用各省的文字、各族的方言，奉亞哈隨魯王的名寫旨意，傳與總督和各省的省長，並各族的首領；又用王的戒指蓋印，</span>
<span className="v" id="v13" data-v="13" data-xref="歷代志下 30:6; 以斯帖記 9:10; 以斯帖記 8:10–14"> 交給驛卒傳到王的各省，吩咐將猶大人，無論老少婦女孩子，在一日之間，十二月，就是亞達月十三日，全然剪除，殺戮滅絕，並奪他們的財為掠物。</span>
<span className="v" id="v14" data-v="14" data-xref="以斯帖記 8:13–14"> 抄錄這旨意，頒行各省，宣告各族，使他們預備等候那日。</span>
<span className="v" id="v15" data-v="15" data-xref="以斯帖記 8:15; 約翰福音 16:20; 箴言 29:2"> 驛卒奉王命急忙起行，旨意也傳遍書珊城。王同哈曼坐下飲酒，書珊城的民卻都慌亂。</span>
</div>
</div>

## 末底改求以斯帖幫忙

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="但以理書 9:3; 以西結書 27:30–31; 撒母耳記下 13:19"> 末底改知道所做的這一切事，就撕裂衣服，穿麻衣，蒙灰塵，在城中行走，痛哭哀號。</span>
<span className="v" id="v2" data-v="2"> 到了朝門前停住腳步，因為穿麻衣的不可進朝門。</span>
<span className="v" id="v3" data-v="3" data-xref="以賽亞書 22:12; 但以理書 9:3; 以賽亞書 58:5"> 王的諭旨所到的各省各處，猶大人大大悲哀，禁食哭泣哀號，穿麻衣躺在灰中的甚多。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="詩篇 77:2; 耶利米書 31:15; 以斯帖記 1:12"> 王后以斯帖的宮女和太監來把這事告訴以斯帖，她甚是憂愁，就送衣服給末底改穿，要他脫下麻衣，他卻不受。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多前書 12:26; 羅馬書 12:15; 以斯帖記 1:10"> 以斯帖就把王所派伺候她的一個太監，名叫哈他革召來，吩咐他去見末底改，要知道這是甚麼事，是甚麼緣故。</span>
<span className="v" id="v6" data-v="6" data-xref="以斯帖記 4:3; 以斯帖記 7:2; 以斯帖記 9:12"> 於是哈他革出到朝門前的寬闊處見末底改。</span>
<span className="v" id="v7" data-v="7" data-xref="以斯帖記 3:2–15"> 末底改將自己所遇的事，並哈曼為滅絕猶大人應許捐入王庫的銀數都告訴了他；</span>
<span className="v" id="v8" data-v="8" data-xref="傳道書 10:4; 約伯記 9:15; 提摩太前書 6:13"> 又將所抄寫傳遍書珊城要滅絕猶大人的旨意交給哈他革，要給以斯帖看，又要給她說明，並囑咐她進去見王，為本族的人在王面前懇切祈求。</span>
<span className="v" id="v9" data-v="9"> 哈他革回來，將末底改的話告訴以斯帖；</span>
<span className="v" id="v10" data-v="10"> 以斯帖就吩咐哈他革去見末底改，說：</span>
<span className="v" id="v11" data-v="11" data-xref="以斯帖記 5:1–2; 以斯帖記 8:4; 但以理書 2:9"> 「王的一切臣僕和各省的人民都知道有一個定例：若不蒙召，擅入內院見王的，無論男女必被治死；除非王向他伸出金杖，不得存活。現在我沒有蒙召進去見王已經三十日了。」</span>
<span className="v" id="v12" data-v="12"> 人就把以斯帖這話告訴末底改。</span>
<span className="v" id="v13" data-v="13" data-xref="箴言 24:10–12; 腓立比書 2:30; 約翰福音 12:25"> 末底改託人回覆以斯帖說：「你莫想在王宮裏強過一切猶大人，得免這禍。</span>
<span className="v" id="v14" data-v="14" data-xref="創世記 45:4–8; 撒母耳記上 12:22; 申命記 32:36"> 此時你若閉口不言，猶大人必從別處得解脫，蒙拯救；你和你父家必致滅亡。焉知你得了王后的位分不是為現今的機會嗎？」</span>
<span className="v" id="v15" data-v="15"> 以斯帖就吩咐人回報末底改說：</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行傳 20:24; 歷代志下 20:3; 約珥書 2:12–17"> 「你當去招聚書珊城所有的猶大人，為我禁食三晝三夜，不吃不喝；我和我的宮女也要這樣禁食。然後我違例進去見王，我若死就死吧！」</span>
<span className="v" id="v17" data-v="17"> 於是末底改照以斯帖一切所吩咐的去行。</span>
</div>

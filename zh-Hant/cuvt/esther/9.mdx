## 猶大人除滅他們的仇敵

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以斯帖記 3:13; 以斯帖記 8:12; 詩篇 30:11"> 十二月，乃亞達月十三日，王的諭旨將要舉行，就是猶大人的仇敵盼望轄制他們的日子，猶大人反倒轄制恨他們的人。</span>
<span className="v" id="v2" data-v="2" data-xref="以斯帖記 8:17; 以斯帖記 8:11; 詩篇 71:13"> 猶大人在亞哈隨魯王各省的城裏聚集，下手擊殺那要害他們的人。無人能敵擋他們，因為各族都懼怕他們。</span>
<span className="v" id="v3" data-v="3" data-xref="以斯拉記 8:36; 以斯帖記 8:5; 但以理書 6:1–2"> 各省的首領、總督、省長，和辦理王事的人，因懼怕末底改，就都幫助猶大人。</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳記下 3:1; 歷代志上 11:9; 撒母耳記上 2:30"> 末底改在朝中為大，名聲傳遍各省，日漸昌盛。</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 18:34–40; 詩篇 20:7–8; 詩篇 149:6–9"> 猶大人用刀擊殺一切仇敵，任意殺滅恨他們的人。</span>
<span className="v" id="v6" data-v="6" data-xref="以斯帖記 3:15"> 在書珊城，猶大人殺滅了五百人；</span>
<span className="v" id="v7" data-v="7"> 又殺巴珊大他、達分、亞斯帕他、</span>
<span className="v" id="v8" data-v="8"> 破拉他、亞大利雅、亞利大他、</span>
<span className="v" id="v9" data-v="9"> 帕瑪斯他、亞利賽、亞利代、瓦耶撒他；</span>
<span className="v" id="v10" data-v="10" data-xref="以斯帖記 5:11; 以斯帖記 8:11; 創世記 14:23"> 這十人都是哈米大他的孫子、猶大人仇敵哈曼的兒子。猶大人卻沒有下手奪取財物。</span>
<span className="v" id="v11" data-v="11"> 當日，將書珊城被殺的人數呈在王前。</span>
<span className="v" id="v12" data-v="12" data-xref="以斯帖記 7:2; 以斯帖記 5:6"> 王對王后以斯帖說：「猶大人在書珊城殺滅了五百人，又殺了哈曼的十個兒子，在王的各省不知如何呢？現在你要甚麼，我必賜給你；你還求甚麼，也必為你成就。」</span>
<span className="v" id="v13" data-v="13" data-xref="以斯帖記 8:11; 申命記 21:23; 以斯帖記 9:15"> 以斯帖說：「王若以為美，求你准書珊的猶大人，明日也照今日的旨意行，並將哈曼十個兒子的屍首掛在木架上。」</span>
<span className="v" id="v14" data-v="14"> 王便允准如此行。旨意傳在書珊，人就把哈曼十個兒子的屍首掛起來了。</span>
<span className="v" id="v15" data-v="15" data-xref="以斯帖記 8:11; 以斯帖記 9:10; 以斯帖記 9:16"> 亞達月十四日，書珊的猶大人又聚集在書珊，殺了三百人，卻沒有下手奪取財物。</span>
<span className="v" id="v16" data-v="16" data-xref="以斯帖記 8:11; 以斯帖記 9:2; 利未記 26:7–8"> 在王各省其餘的猶大人也都聚集保護性命，殺了恨他們的人七萬五千，卻沒有下手奪取財物。這樣，就脫離仇敵，得享平安。</span>
<span className="v" id="v17" data-v="17" data-xref="以斯帖記 9:21; 以斯帖記 9:1; 以斯帖記 8:9"> 亞達月十三日，行了這事；十四日安息，以這日為設筵歡樂的日子。</span>
<span className="v" id="v18" data-v="18" data-xref="以斯帖記 9:21; 以斯帖記 9:1; 以斯帖記 9:15"> 但書珊的猶大人，這十三日、十四日聚集殺戮仇敵；十五日安息，以這日為設筵歡樂的日子。</span>
<span className="v" id="v19" data-v="19" data-xref="以斯帖記 8:17; 啟示錄 11:10; 尼希米記 8:10–12"> 所以住無城牆鄉村的猶大人，如今都以亞達月十四日為設筵歡樂的吉日，彼此餽送禮物。</span>
</div>

## 普珥日

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="申命記 31:19–22; 哥林多後書 1:10–11; 詩篇 145:4–12"> 末底改記錄這事，寫信與亞哈隨魯王各省遠近所有的猶大人，</span>
<span className="v" id="v21" data-v="21"> 囑咐他們每年守亞達月十四、十五兩日，</span>
<span className="v" id="v22" data-v="22" data-xref="詩篇 30:11; 以賽亞書 14:3; 以斯帖記 9:19"> 以這月的兩日為猶大人脫離仇敵得平安、轉憂為喜、轉悲為樂的吉日。在這兩日設筵歡樂，彼此餽送禮物，賙濟窮人。</span>
<span className="v" id="v23" data-v="23"> 於是，猶大人按着末底改所寫與他們的信，應承照初次所守的守為永例；</span>
<span className="v" id="v24" data-v="24" data-xref="以斯帖記 3:5–13; 以斯帖記 9:10"> 是因猶大人的仇敵亞甲族哈米大他的兒子哈曼設謀殺害猶大人，掣普珥，就是掣籤，為要殺盡滅絕他們；</span>
<span className="v" id="v25" data-v="25" data-xref="詩篇 7:16; 詩篇 140:9; 詩篇 141:10"> 這事報告於王，王便降旨使哈曼謀害猶大人的惡事歸到他自己的頭上，並吩咐把他和他的眾子都掛在木架上。</span>
<span className="v" id="v26" data-v="26" data-xref="以斯帖記 9:20; 民數記 16:40; 以西結書 39:11"> 照着普珥的名字，猶大人就稱這兩日為「普珥日」。他們因這信上的話，又因所看見所遇見的事，</span>
<span className="v" id="v27" data-v="27" data-xref="撒迦利亞書 2:11; 以賽亞書 56:6; 以斯帖記 8:17"> 就應承自己與後裔，並歸附他們的人，每年按時必守這兩日，永遠不廢。</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及記 13:8–9; 約書亞記 4:7; 詩篇 103:2"> 各省各城、家家戶戶、世世代代紀念遵守這兩日，使這「普珥日」在猶大人中不可廢掉，在他們後裔中也不可忘記。</span>
<span className="v" id="v29" data-v="29" data-xref="以斯帖記 9:20; 以斯帖記 2:15; 以斯帖記 8:10"> 亞比孩的女兒－王后以斯帖和猶大人末底改以全權寫第二封信，堅囑猶大人守這「普珥日」，</span>
<span className="v" id="v30" data-v="30" data-xref="以斯帖記 1:1; 以斯帖記 8:9; 撒迦利亞書 8:19"> 用和平誠實話寫信給亞哈隨魯王國中一百二十七省所有的猶大人，</span>
<span className="v" id="v31" data-v="31" data-xref="以斯帖記 4:3; 以斯帖記 4:16; 約拿書 3:2–9"> 勸他們按時守這「普珥日」，禁食呼求，是照猶大人末底改和王后以斯帖所囑咐的，也照猶大人為自己與後裔所應承的。</span>
<span className="v" id="v32" data-v="32" data-xref="以斯帖記 9:26"> 以斯帖命定守「普珥日」，這事也記錄在書上。</span>
</div>

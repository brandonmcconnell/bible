## 以斯帖為王和哈曼設筵席

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以斯帖記 6:4; 以斯帖記 4:16; 啟示錄 3:21"> 第三日，以斯帖穿上朝服，進王宮的內院，對殿站立。王在殿裏坐在寶座上，對着殿門。</span>
<span className="v" id="v2" data-v="2" data-xref="以斯帖記 8:4; 以斯帖記 4:11; 箴言 21:1"> 王見王后以斯帖站在院內，就施恩於她，向她伸出手中的金杖；以斯帖便向前摸杖頭。</span>
<span className="v" id="v3" data-v="3" data-xref="馬可福音 6:23; 以斯帖記 7:2; 以斯帖記 5:6"> 王對她說：「王后以斯帖啊，你要甚麼？你求甚麼，就是國的一半也必賜給你。」</span>
<span className="v" id="v4" data-v="4" data-xref="以斯帖記 5:8; 箴言 29:11; 以斯帖記 3:15"> 以斯帖說：「王若以為美，就請王帶着哈曼今日赴我所預備的筵席。」</span>
<span className="v" id="v5" data-v="5" data-xref="以斯帖記 6:14"> 王說：「叫哈曼速速照以斯帖的話去行。」於是王帶着哈曼赴以斯帖所預備的筵席。</span>
<span className="v" id="v6" data-v="6" data-xref="以斯帖記 7:2; 以斯帖記 5:3; 以斯帖記 9:12"> 在酒席筵前，王又問以斯帖說：「你要甚麼，我必賜給你；你求甚麼，就是國的一半也必為你成就。」</span>
<span className="v" id="v7" data-v="7"> 以斯帖回答說：「我有所要，我有所求。</span>
<span className="v" id="v8" data-v="8" data-xref="以斯帖記 7:3; 箴言 16:9; 以斯帖記 8:5"> 我若在王眼前蒙恩，王若願意賜我所要的，准我所求的，就請王帶着哈曼再赴我所要預備的筵席。明日我必照王所問的說明。」</span>
</div>
</div>

## 哈曼陰謀殺末底改

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="以斯帖記 3:5; 馬太福音 2:16; 詩篇 27:3"> 那日哈曼心中快樂，歡歡喜喜地出來；但見末底改在朝門不站起來，連身也不動，就滿心惱怒末底改。</span>
<span className="v" id="v10" data-v="10" data-xref="以斯帖記 6:13; 傳道書 7:9; 撒母耳記下 13:22–23"> 哈曼暫且忍耐回家，叫人請他朋友和他妻子細利斯來。</span>
<span className="v" id="v11" data-v="11" data-xref="以斯帖記 9:7–10; 以斯帖記 3:1; 路加福音 12:19–20"> 哈曼將他富厚的榮耀、眾多的兒女，和王抬舉他使他超乎首領臣僕之上，都述說給他們聽。</span>
<span className="v" id="v12" data-v="12" data-xref="箴言 27:1; 詩篇 37:35–36; 約伯記 20:5–8"> 哈曼又說：「王后以斯帖預備筵席，除了我之外不許別人隨王赴席。明日王后又請我隨王赴席；</span>
<span className="v" id="v13" data-v="13" data-xref="約伯記 15:20; 約伯記 18:4; 腓立比書 4:11–12"> 只是我見猶大人末底改坐在朝門，雖有這一切榮耀，也與我無益。」</span>
<span className="v" id="v14" data-v="14" data-xref="以斯帖記 6:4; 詩篇 37:14; 列王紀上 21:7"> 他的妻細利斯和他一切的朋友對他說：「不如立一個五丈高的木架，明早求王將末底改掛在其上，然後你可以歡歡喜喜地隨王赴席。」哈曼以這話為美，就叫人做了木架。</span>

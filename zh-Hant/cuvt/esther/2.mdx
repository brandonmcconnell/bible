## 以斯帖被立為王后

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="但以理書 6:14–18; 以斯帖記 7:10; 以斯帖記 1:12–21"> 這事以後，亞哈隨魯王的忿怒止息，就想念瓦實提和她所行的，並怎樣降旨辦她。</span>
<span className="v" id="v2" data-v="2" data-xref="列王紀上 1:2; 創世記 12:14; 以斯帖記 6:14"> 於是王的侍臣對王說：「不如為王尋找美貌的處女。</span>
<span className="v" id="v3" data-v="3" data-xref="以斯帖記 2:12–15; 以斯帖記 2:8–9; 以斯帖記 1:1–2"> 王可以派官在國中的各省招聚美貌的處女到書珊城<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或譯：宮">a</a></sup>的女院，交給掌管女子的太監希該，給她們當用的香品。</span>
<span className="v" id="v4" data-v="4" data-xref="馬太福音 14:6; 馬太福音 20:16; 以斯帖記 1:21"> 王所喜愛的女子可以立為王后，代替瓦實提。」王以這事為美，就如此行。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="撒母耳記下 16:5; 撒母耳記上 9:1; 以斯帖記 10:3"> 書珊城有一個猶大人，名叫末底改，是便雅憫人基士的曾孫，示每的孫子，睚珥的兒子。</span>
<span className="v" id="v6" data-v="6" data-xref="列王紀下 24:14–15; 歷代志下 36:20; 耶利米書 24:1"> 從前巴比倫王尼布甲尼撒將猶大王耶哥尼雅<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="又名約雅斤">b</a></sup>和百姓從耶路撒冷擄去，末底改也在其內。</span>
<span className="v" id="v7" data-v="7" data-xref="以斯帖記 2:15; 以斯帖記 1:11; 哥林多後書 6:18"> 末底改撫養他叔叔的女兒哈大沙（後名以斯帖），因為她沒有父母。這女子又容貌俊美；她父母死了，末底改就收她為自己的女兒。</span>
<span className="v" id="v8" data-v="8" data-xref="以斯帖記 2:3; 以斯帖記 2:15"> 王的諭旨傳出，就招聚許多女子到書珊城，交給掌管女子的希該；以斯帖也送入王宮，交付希該。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 39:21; 箴言 16:7; 以斯帖記 2:12"> 希該喜悅以斯帖，就恩待她，急忙給她需用的香品和她所當得的分，又派所當得的七個宮女服事她，使她和她的宮女搬入女院上好的房屋。</span>
<span className="v" id="v10" data-v="10" data-xref="以斯帖記 2:20; 馬太福音 10:16; 以斯帖記 3:8"> 以斯帖未曾將籍貫宗族告訴人，因為末底改囑咐她不可叫人知道。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 37:14; 撒母耳記上 17:18; 使徒行傳 15:36"> 末底改天天在女院前邊行走，要知道以斯帖平安不平安，並後事如何。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="帖撒羅尼迦前書 4:4–5; 箴言 7:17; 以賽亞書 57:9"> 眾女子照例先潔淨身體十二個月：六個月用沒藥油，六個月用香料和潔身之物。滿了日期，然後挨次進去見亞哈隨魯王。</span>
<span className="v" id="v13" data-v="13"> 女子進去見王是這樣：從女院到王宮的時候，凡她所要的都必給她。</span>
<span className="v" id="v14" data-v="14" data-xref="以斯帖記 4:11; 創世記 34:19; 以賽亞書 62:4–5"> 晚上進去，次日回到女子第二院，交給掌管妃嬪的太監沙甲；除非王喜愛她，再提名召她，就不再進去見王。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="雅歌 6:9; 以斯帖記 2:3; 以斯帖記 9:29"> 末底改叔叔亞比孩的女兒，就是末底改收為自己女兒的以斯帖，按次序當進去見王的時候，除了掌管女子的太監希該所派定給她的，她別無所求。凡看見以斯帖的都喜悅她。</span>
<span className="v" id="v16" data-v="16" data-xref="以斯帖記 8:9; 以斯帖記 2:3; 以斯帖記 2:1"> 亞哈隨魯王第七年十月，就是提別月，以斯帖被引入宮見王。</span>
<span className="v" id="v17" data-v="17" data-xref="詩篇 113:7–8; 路加福音 1:48–52; 以西結書 17:24"> 王愛以斯帖過於愛眾女，她在王眼前蒙寵愛比眾處女更甚。王就把王后的冠冕戴在她頭上，立她為王后，代替瓦實提。</span>
<span className="v" id="v18" data-v="18" data-xref="雅歌 3:11; 路加福音 14:8; 士師記 14:10–17"> 王因以斯帖的緣故給眾首領和臣僕設擺大筵席，又豁免各省的租稅，並照王的厚意大頒賞賜。</span>
</div>
</div>

## 末底改救王的命

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="以斯帖記 2:21; 以斯帖記 2:3–4; 以斯帖記 5:13"> 第二次招聚處女的時候，末底改坐在朝門。</span>
<span className="v" id="v20" data-v="20" data-xref="以弗所書 6:1–3; 以斯帖記 2:10; 以斯帖記 2:7"> 以斯帖照着末底改所囑咐的，還沒有將籍貫宗族告訴人；因為以斯帖遵&#42;末底改的命，如撫養她的時候一樣。</span>
<span className="v" id="v21" data-v="21" data-xref="以斯帖記 6:2; 列王紀上 16:9; 列王紀下 21:23"> 當那時候，末底改坐在朝門，王的太監中有兩個守門的，辟探和提列，惱恨亞哈隨魯王，想要下手害他。</span>
<span className="v" id="v22" data-v="22" data-xref="以斯帖記 6:1–2; 羅馬書 11:33; 傳道書 10:20"> 末底改知道了，就告訴王后以斯帖。以斯帖奉末底改的名，報告於王；</span>
<span className="v" id="v23" data-v="23" data-xref="創世記 40:22; 創世記 40:19; 以斯帖記 10:2"> 究察這事，果然是實，就把二人掛在木頭上，將這事在王面前寫於歷史上。</span>
</div>

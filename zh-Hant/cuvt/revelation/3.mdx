## 給撒狄教會的信

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="提摩太前書 5:6; 雅各書 2:26; 啟示錄 1:4"> 「你要寫信給撒狄教會的使者，說：『那有上帝的七靈和七星的，說：我知道你的行為，按名你是活的，其實是死的。</span>
<span className="v" id="v2" data-v="2" data-xref="彼得前書 5:8; 提摩太後書 4:1–4; 啟示錄 16:15"> 你要警醒，堅固那剩下將要衰微<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是死">a</a></sup>的；因我見你的行為，在我上帝面前，沒有一樣是完全的。</span>
<span className="v" id="v3" data-v="3" data-xref="啟示錄 2:5; 彼得後書 3:10; 帖撒羅尼迦前書 5:2"> 所以要回想你是怎樣領受、怎樣聽見的，又要遵守，並要悔改。若不警醒，我必臨到你那裏，如同賊一樣。我幾時臨到，你也決不能知道。</span>
<span className="v" id="v4" data-v="4" data-xref="啟示錄 3:5; 啟示錄 7:9; 傳道書 9:8"> 然而在撒狄，你還有幾名是未曾污穢自己衣服的，他們要穿白衣與我同行，因為他們是配得過的。</span>
<span className="v" id="v5" data-v="5" data-xref="馬太福音 10:32; 路加福音 12:8; 啟示錄 21:27"> 凡得勝的必這樣穿白衣，我也必不從生命冊上塗抹他的名；且要在我父面前，和我父眾使者面前，認他的名。</span>
<span className="v" id="v6" data-v="6" data-xref="啟示錄 2:7"> 聖靈向眾教會所說的話，凡有耳的，就應當聽！』」</span>
</div>
</div>

## 給非拉鐵非教會的信

<div className="bt">
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="以賽亞書 22:22; 馬太福音 16:19; 啟示錄 1:18"> 「你要寫信給非拉鐵非教會的使者，說：『那聖潔、真實、拿着大衛的鑰匙、開了就沒有人能關、關了就沒有人能開的，說：</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多前書 16:9; 歌羅西書 4:3; 啟示錄 3:7"> 我知道你的行為，你略有一點力量，也曾遵守我的道，沒有棄絕我的名。看哪，我在你面前給你一個敞開的門，是無人能關的。</span>
<span className="v" id="v9" data-v="9" data-xref="以賽亞書 60:14; 啟示錄 2:9; 以賽亞書 49:23"> 那撒但一會的，自稱是猶太人，其實不是猶太人，乃是說謊話的，我要使他們來，在你腳前下拜，也使他們知道我是已經愛你了。</span>
<span className="v" id="v10" data-v="10" data-xref="彼得後書 2:9; 啟示錄 14:12; 撒迦利亞書 13:9"> 你既遵守我忍耐的道，我必在普天下人受試煉的時候，保守你免去你的試煉。</span>
<span className="v" id="v11" data-v="11" data-xref="雅各書 1:12; 啟示錄 22:12; 啟示錄 2:10"> 我必快來，你要持守你所有的，免得人奪去你的冠冕。</span>
<span className="v" id="v12" data-v="12" data-xref="啟示錄 22:4; 啟示錄 21:2; 啟示錄 14:1"> 得勝的，我要叫他在我上帝殿中作柱子，他也必不再從那裏出去。我又要將我上帝的名和我上帝城的名（這城就是從天上、從我上帝那裏降下來的新耶路撒冷），並我的新名，都寫在他上面。</span>
<span className="v" id="v13" data-v="13" data-xref="啟示錄 2:7"> 聖靈向眾教會所說的話，凡有耳的，就應當聽！』」</span>
</div>
</div>

## 給老底嘉教會的信

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="歌羅西書 1:15; 啟示錄 1:5; 哥林多後書 1:20"> 「你要寫信給老底嘉教會的使者，說：『那為阿們的，為誠信真實見證的，在上帝創造萬物之上為元首的，說：</span>
<span className="v" id="v15" data-v="15" data-xref="羅馬書 12:11; 馬太福音 6:24; 列王紀上 18:21"> 我知道你的行為，你也不冷也不熱；我巴不得你或冷或熱。</span>
<span className="v" id="v16" data-v="16" data-xref="啟示錄 2:5; 撒迦利亞書 11:8–9; 耶利米書 14:19"> 你既如溫水，也不冷也不熱，所以我必從我口中把你吐出去。</span>
<span className="v" id="v17" data-v="17" data-xref="箴言 13:7; 何西阿書 12:8; 羅馬書 7:24"> 你說：我是富足，已經發了財，一樣都不缺；卻不知道你是那困苦、可憐、貧窮、瞎眼、赤身的。</span>
<span className="v" id="v18" data-v="18" data-xref="啟示錄 16:15; 彼得前書 1:7; 以賽亞書 55:1"> 我勸你向我買火煉的金子，叫你富足；又買白衣穿上，叫你赤身的羞恥不露出來；又買眼藥擦你的眼睛，使你能看見。</span>
<span className="v" id="v19" data-v="19" data-xref="箴言 3:11–12; 哥林多前書 11:32; 希伯來書 12:5–11"> 凡我所疼愛的，我就責備管教他；所以你要發熱心，也要悔改。</span>
<span className="v" id="v20" data-v="20" data-xref="路加福音 12:36–37; 啟示錄 19:9; 約翰福音 14:21–23"> 看哪，我站在門外叩門，若有聽見我聲音就開門的，我要進到他那裏去，我與他，他與我一同坐席。</span>
<span className="v" id="v21" data-v="21" data-xref="提摩太後書 2:12; 馬太福音 19:28; 啟示錄 2:26–27"> 得勝的，我要賜他在我寶座上與我同坐，就如我得了勝，在我父的寶座上與他同坐一般。</span>
<span className="v" id="v22" data-v="22" data-xref="啟示錄 2:7; 啟示錄 2:11; 啟示錄 2:17"> 聖靈向眾教會所說的話，凡有耳的，就應當聽！』」</span>
</div>
</div>

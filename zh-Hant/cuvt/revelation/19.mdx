## 羔羊的婚筵

<div className="bt">
<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="詩篇 134:1; 詩篇 148:11–13; 詩篇 150:6"> <span className="pl pl-1">有聲音從寶座出來說：</span><br /><span className="pl pl-1">上帝的眾僕人哪，</span><br /><span className="pl pl-1">凡敬畏他的，無論大小，</span><br /><span className="pl pl-1">都要讚美我們的上帝！</span></span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 97:1; 啟示錄 14:2; 詩篇 93:1"> 我聽見好像群眾的聲音，眾水的聲音，大雷的聲音，說：<br /><span className="pl pl-1">哈利路亞！</span><br /><span className="pl pl-1">因為主－我們的上帝、</span><br /><span className="pl pl-1">全能者作王了。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="啟示錄 21:9; 啟示錄 21:2; 啟示錄 19:9"> <span className="pl pl-1">我們要歡喜快樂，</span><br /><span className="pl pl-1">將榮耀歸給他。</span><br /><span className="pl pl-1">因為，羔羊婚娶的時候到了；</span><br /><span className="pl pl-1">新婦也自己預備好了，</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="以賽亞書 61:10; 啟示錄 7:13–14; 詩篇 132:9"> <span className="pl pl-1">就蒙恩得穿光明潔白的細麻衣。</span><br /><span className="pl pl-1">（這細麻衣就是聖徒所行的義。）</span></span>
<span className="v" id="v9" data-v="9" data-xref="啟示錄 22:6; 馬太福音 22:2–4; 路加福音 14:15–16"> 天使吩咐我說：「你要寫上：凡被請赴羔羊之婚筵的有福了！」又對我說：「這是上帝真實的話。」</span>
<span className="v" id="v10" data-v="10" data-xref="啟示錄 22:8–9; 使徒行傳 10:25–26; 約翰福音 5:39"> 我就俯伏在他腳前要拜他。他說：「千萬不可！我和你，並你那些為耶穌作見證的弟兄同是作僕人的，你要敬拜上帝。」因為預言中的靈意乃是為耶穌作見證。</span>
</div>
</div>

## 騎白馬者

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="詩篇 96:13; 以賽亞書 11:3–5; 詩篇 98:9"> 我觀看，見天開了。有一匹白馬，騎在馬上的稱為誠信真實，他審判，爭戰，都按着公義。</span>
<span className="v" id="v12" data-v="12" data-xref="啟示錄 19:16; 路加福音 10:22; 啟示錄 2:17–18"> 他的眼睛如火焰，他頭上戴着許多冠冕；又有寫着的名字，除了他自己沒有人知道。</span>
<span className="v" id="v13" data-v="13" data-xref="約翰福音 1:1; 以賽亞書 63:1–6; 約翰福音 1:14"> 他穿着濺了血的衣服；他的名稱為上帝之道。</span>
<span className="v" id="v14" data-v="14" data-xref="猶大書 1:14; 啟示錄 7:9; 啟示錄 19:8"> 在天上的眾軍騎着白馬，穿着細麻衣，又白又潔，跟隨他。</span>
<span className="v" id="v15" data-v="15" data-xref="以賽亞書 63:2–6; 啟示錄 1:16; 啟示錄 2:27"> 有利劍從他口中出來，可以擊殺列國。他必用鐵杖轄管<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="轄管：原文是牧">b</a></sup>他們，並要踹全能上帝烈怒的酒醡。</span>
<span className="v" id="v16" data-v="16" data-xref="啟示錄 17:14; 提摩太前書 6:15; 但以理書 2:47"> 在他衣服和大腿上有名寫着說：「萬王之王，萬主之主。」</span>
<span className="v" id="v17" data-v="17" data-xref="啟示錄 19:21; 啟示錄 8:13; 以西結書 39:17–20"> 我又看見一位天使站在日頭中，向天空所飛的鳥大聲喊着說：「你們聚集來赴上帝的大筵席，</span>
<span className="v" id="v18" data-v="18" data-xref="以西結書 39:18–20; 啟示錄 6:15; 撒母耳記上 17:44"> 可以吃君王與將軍的肉，壯士與馬和騎馬者的肉，並一切自主的為奴的，以及大小人民的肉。」</span>
<span className="v" id="v19" data-v="19" data-xref="啟示錄 16:16; 啟示錄 16:14; 啟示錄 17:12–14"> 我看見那獸和地上的君王，並他們的眾軍都聚集，要與騎白馬的並他的軍兵爭戰。</span>
<span className="v" id="v20" data-v="20" data-xref="啟示錄 20:10; 啟示錄 21:8; 帖撒羅尼迦後書 2:8–11"> 那獸被擒拿；那在獸面前曾行奇事、迷惑受獸印記和拜獸像之人的假先知，也與獸同被擒拿。他們兩個就活活地被扔在燒着硫磺的火湖裏；</span>
<span className="v" id="v21" data-v="21" data-xref="啟示錄 19:11–15; 啟示錄 1:16; 啟示錄 19:17–19"> 其餘的被騎白馬者口中出來的劍殺了；飛鳥都吃飽了他們的肉。</span>
</div>
</div>

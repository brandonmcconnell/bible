## 婦人和龍

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 21:25; 以弗所書 5:32; 路加福音 21:11"> 天上現出大異象來：有一個婦人身披日頭，腳踏月亮，頭戴十二星的冠冕。</span>
<span className="v" id="v2" data-v="2" data-xref="約翰福音 16:21; 加拉太書 4:19; 啟示錄 12:4"> 她懷了孕，在生產的艱難中疼痛呼叫。</span>
<span className="v" id="v3" data-v="3" data-xref="啟示錄 17:12; 啟示錄 12:9; 但以理書 7:24"> 天上又現出異象來：有一條大紅龍，七頭十角；七頭上戴着七個冠冕。</span>
<span className="v" id="v4" data-v="4" data-xref="但以理書 8:9–12; 啟示錄 12:9; 約翰福音 8:44"> 牠的尾巴拖拉着天上星辰的三分之一，摔在地上。龍就站在那將要生產的婦人面前，等她生產之後，要吞吃她的孩子。</span>
<span className="v" id="v5" data-v="5" data-xref="啟示錄 19:15; 啟示錄 2:26–27; 啟示錄 12:2"> 婦人生了一個男孩子，是將來要用鐵杖轄管<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="轄管：原文是牧">a</a></sup>萬國的；她的孩子被提到上帝寶座那裏去了。</span>
<span className="v" id="v6" data-v="6" data-xref="啟示錄 13:5; 啟示錄 11:2–3; 啟示錄 12:14"> 婦人就逃到曠野，在那裏有上帝給她預備的地方，使她被養活一千二百六十天。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="猶大書 1:9; 但以理書 12:1; 以弗所書 6:12"> 在天上就有了爭戰。米迦勒同他的使者與龍爭戰，龍也同牠的使者去爭戰，</span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 37:10; 啟示錄 12:11; 猶大書 1:6"> 並沒有得勝，天上再沒有牠們的地方。</span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 10:18; 約翰福音 12:31; 啟示錄 20:10"> 大龍就是那古蛇，名叫魔鬼，又叫撒但，是迷惑普天下的。牠被摔在地上，牠的使者也一同被摔下去。</span>
<span className="v" id="v10" data-v="10" data-xref="路加福音 22:31; 撒迦利亞書 3:1–2; 啟示錄 11:15"> 我聽見在天上有大聲音說：「我上帝的救恩、能力、國度，並他基督的權柄，現在都來到了！因為那在我們上帝面前晝夜控告我們弟兄的，已經被摔下去了。</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多後書 10:3–5; 約翰福音 16:33; 約翰一書 5:5"> 弟兄勝過牠，是因羔羊的血和自己所見證的道。他們雖至於死，也不愛惜性命。</span>
<span className="v" id="v12" data-v="12" data-xref="以賽亞書 49:13; 啟示錄 8:13; 詩篇 96:11–13"> 所以，諸天和住在其中的，你們都快樂吧！只是地與海有禍了！因為魔鬼知道自己的時候不多，就氣忿忿地下到你們那裏去了。」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="創世記 3:15; 啟示錄 12:3–5; 約翰福音 16:33"> 龍見自己被摔在地上，就逼迫那生男孩子的婦人。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及記 19:4; 以賽亞書 40:31; 啟示錄 12:6"> 於是有大鷹的兩個翅膀賜給婦人，叫她能飛到曠野，到自己的地方，躲避那蛇；她在那裏被養活一載二載半載。</span>
<span className="v" id="v15" data-v="15" data-xref="以賽亞書 8:7; 以賽亞書 59:19; 詩篇 18:4"> 蛇就在婦人身後，從口中吐出水來，像河一樣，要將婦人沖去。</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀上 17:6; 出埃及記 12:35–36; 列王紀下 8:9"> 地卻幫助婦人，開口吞了從龍口吐出來的水<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原文是河">b</a></sup>。</span>
<span className="v" id="v17" data-v="17" data-xref="啟示錄 14:12; 創世記 3:15; 啟示錄 11:7"> 龍向婦人發怒，去與她其餘的兒女爭戰，這兒女就是那守上帝誡命、為耶穌作見證的。</span>
<span className="v" id="v18" data-v="18"> 那時龍就站在海邊的沙上。</span>
</div>
</div>

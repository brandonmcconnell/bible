## 書卷和羔羊

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西結書 2:9–10; 以賽亞書 29:11; 啟示錄 5:7"> 我看見坐寶座的右手中有書卷，裏外都寫着字，用七印封嚴了。</span>
<span className="v" id="v2" data-v="2" data-xref="以賽亞書 29:11–12; 啟示錄 5:5; 啟示錄 10:1"> 我又看見一位大力的天使大聲宣傳說：「有誰配展開那書卷，揭開那七印呢？」</span>
<span className="v" id="v3" data-v="3" data-xref="啟示錄 5:13; 以賽亞書 40:13–14; 羅馬書 11:34"> 在天上、地上、地底下，沒有能展開、能觀看那書卷的。</span>
<span className="v" id="v4" data-v="4" data-xref="但以理書 12:8–9; 啟示錄 4:1"> 因為沒有配展開、配觀看那書卷的，我就大哭。</span>
<span className="v" id="v5" data-v="5" data-xref="以賽亞書 11:1; 耶利米書 23:5–6; 啟示錄 22:16"> 長老中有一位對我說：「不要哭！看哪，猶大支派中的獅子，大衛的根，他已得勝，能以展開那書卷，揭開那七印。」</span>
</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="撒迦利亞書 4:10; 約翰福音 1:29; 啟示錄 5:12"> 我又看見寶座與四活物，並長老之中有羔羊站立，像是被殺過的，有七角七眼，就是上帝的七靈，奉差遣往普天下去的。</span>
<span className="v" id="v7" data-v="7" data-xref="啟示錄 5:1; 啟示錄 4:2–3"> 這羔羊前來，從坐寶座的右手裏拿了書卷。</span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 141:2; 啟示錄 8:3–4; 腓立比書 2:9–11"> 他既拿了書卷，四活物和二十四位長老就俯伏在羔羊面前，各拿着琴和盛滿了香的金爐；這香就是眾聖徒的祈禱。</span>
<span className="v" id="v9" data-v="9" data-xref="彼得前書 1:18–19; 約翰一書 1:7; 馬太福音 26:28"> 他們唱新歌，說：<br /><span className="pl pl-1">你配拿書卷，</span><br /><span className="pl pl-1">配揭開七印；</span><br /><span className="pl pl-1">因為你曾被殺，</span><br /><span className="pl pl-1">用自己的血</span><br /><span className="pl pl-1">從各族、各方、各民、各國中買了人來，</span><br /><span className="pl pl-1">叫他們歸於上帝，</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="啟示錄 1:6; 但以理書 7:27; 啟示錄 20:6"> <span className="pl pl-1">又叫他們成為國民，</span><br /><span className="pl pl-1">作祭司歸於上帝，</span><br /><span className="pl pl-1">在地上執掌王權。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v11" data-v="11" data-xref="但以理書 7:10; 希伯來書 12:22; 啟示錄 4:4"> 我又看見且聽見，寶座與活物並長老的周圍有許多天使的聲音；他們的數目有千千萬萬，</span>
<span className="v" id="v12" data-v="12" data-xref="啟示錄 5:9; 啟示錄 19:1; 啟示錄 4:11"> 大聲說：<br /><span className="pl pl-1">曾被殺的羔羊是配得</span><br /><span className="pl pl-1">權柄、豐富、智慧、能力、</span><br /><span className="pl pl-1">尊貴、榮耀、頌讚的。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v13" data-v="13" data-xref="腓立比書 2:10; 歷代志上 29:11; 詩篇 148:2–13"> 我又聽見在天上、地上、地底下、滄海裏，和天地間一切所有被造之物，都說：<br /><span className="pl pl-1">但願頌讚、尊貴、榮耀、權勢</span><br /><span className="pl pl-1">都歸給坐寶座的和羔羊，</span><br /><span className="pl pl-1">直到永永遠遠！</span></span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="啟示錄 19:4; 啟示錄 4:9–11; 啟示錄 5:8"> 四活物就說：「阿們！」眾長老也俯伏敬拜。</span>
</div>
</div>

</div>

## 兩個獸

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="啟示錄 12:3; 啟示錄 17:3; 但以理書 7:23–25"> 我又看見一個獸從海中上來，有十角七頭，在十角上戴着十個冠冕，七頭上有褻瀆的名號。</span>
<span className="v" id="v2" data-v="2" data-xref="但以理書 7:4–7; 彼得前書 5:8; 啟示錄 17:12"> 我所看見的獸，形狀像豹，腳像熊的腳，口像獅子的口。那龍將自己的能力、座位，和大權柄都給了牠。</span>
<span className="v" id="v3" data-v="3" data-xref="啟示錄 17:8; 啟示錄 13:14; 啟示錄 17:17"> 我看見獸的七頭中，有一個似乎受了死傷，那死傷卻醫好了。全地的人都希奇跟從那獸，</span>
<span className="v" id="v4" data-v="4" data-xref="啟示錄 13:2; 啟示錄 18:18; 啟示錄 13:15"> 又拜那龍－因為牠將自己的權柄給了獸，也拜獸，說：「誰能比這獸，誰能與牠交戰呢？」</span>
</div>
<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="但以理書 7:8; 但以理書 7:25; 但以理書 11:36"> 又賜給牠說誇大褻瀆話的口，又有權柄賜給牠，可以任意而行四十二個月。</span>
<span className="v" id="v6" data-v="6" data-xref="馬太福音 12:34; 希伯來書 9:24; 啟示錄 12:12"> 獸就開口向上帝說褻瀆的話，褻瀆上帝的名並他的帳幕，以及那些住在天上的。</span>
<span className="v" id="v7" data-v="7" data-xref="但以理書 7:21; 啟示錄 11:7; 但以理書 7:25"> 又任憑牠與聖徒爭戰，並且得勝；也把權柄賜給牠，制伏各族、各民、各方、各國。</span>
<span className="v" id="v8" data-v="8" data-xref="彼得前書 1:19–20; 以弗所書 1:4; 馬太福音 25:34"> 凡住在地上、名字從創世以來沒有記在被殺之羔羊生命冊上的人，都要拜牠。</span>
<span className="v" id="v9" data-v="9" data-xref="啟示錄 2:7; 啟示錄 2:17; 啟示錄 2:11"> <span className="pl pl-1">凡有耳的，就應當聽！</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="耶利米書 15:2; 以賽亞書 33:1; 啟示錄 14:12"> <span className="pl pl-1">擄掠人的，必被擄掠；</span><br /><span className="pl pl-1">用刀殺人的，必被刀殺。</span><br /><span className="pl pl-1">聖徒的忍耐和信心就是在此。</span></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="但以理書 7:8; 哥林多後書 11:13–15; 馬太福音 7:15"> 我又看見另有一個獸從地中上來，有兩角如同羊羔，說話好像龍。</span>
<span className="v" id="v12" data-v="12" data-xref="啟示錄 17:10–11; 啟示錄 14:11; 啟示錄 14:9"> 牠在頭一個獸面前，施行頭一個獸所有的權柄，並且叫地和住在地上的人拜那死傷醫好的頭一個獸。</span>
<span className="v" id="v13" data-v="13" data-xref="馬太福音 24:24; 啟示錄 19:20; 帖撒羅尼迦後書 2:9–10"> 又行大奇事，甚至在人面前，叫火從天降在地上。</span>
<span className="v" id="v14" data-v="14" data-xref="啟示錄 12:9; 啟示錄 19:20; 啟示錄 13:8"> 牠因賜給牠權柄在獸面前能行奇事，就迷惑住在地上的人，說：「要給那受刀傷還活着的獸作個像。」</span>
<span className="v" id="v15" data-v="15" data-xref="啟示錄 20:4; 啟示錄 19:20; 但以理書 3:3–6"> 又有權柄賜給牠，叫獸像有生氣，並且能說話，又叫所有不拜獸像的人都被殺害。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="啟示錄 20:4; 啟示錄 19:20; 以西結書 9:4"> 牠又叫眾人，無論大小、貧富、自主的、為奴的，都在右手上或是在額上受一個印記。</span>
<span className="v" id="v17" data-v="17" data-xref="啟示錄 15:2; 啟示錄 13:16; 啟示錄 14:11"> 除了那受印記、有了獸名或有獸名數目的，都不得做買賣。</span>
<span className="v" id="v18" data-v="18" data-xref="啟示錄 15:2; 啟示錄 17:9; 啟示錄 21:17"> 在這裏有智慧：凡有聰明的，可以算計獸的數目；因為這是人的數目，它的數目是六百六十六。</span>
</div>
</div>

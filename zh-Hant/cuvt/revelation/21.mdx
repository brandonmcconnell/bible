## 新天新地

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以賽亞書 65:17–19; 彼得後書 3:13; 以賽亞書 66:22"> 我又看見一個新天新地；因為先前的天地已經過去了，海也不再有了。</span>
<span className="v" id="v2" data-v="2" data-xref="希伯來書 11:10; 啟示錄 3:12; 啟示錄 21:10"> 我又看見聖城新耶路撒冷由上帝那裏從天而降，預備好了，就如新婦妝飾整齊，等候丈夫。</span>
<span className="v" id="v3" data-v="3" data-xref="以西結書 37:27; 哥林多後書 6:16; 約翰福音 14:23"> 我聽見有大聲音從寶座出來說：「看哪，上帝的帳幕在人間。他要與人同住，他們要作他的子民。上帝要親自與他們同在，作他們的上帝。</span>
<span className="v" id="v4" data-v="4" data-xref="以賽亞書 25:8; 啟示錄 7:17; 哥林多前書 15:26"> 上帝要擦去他們一切的眼淚；不再有死亡，也不再有悲哀、哭號、疼痛，因為以前的事都過去了。」</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多後書 5:17; 以賽亞書 42:9; 以賽亞書 43:19"> 坐寶座的說：「看哪，我將一切都更新了！」又說：「你要寫上；因這些話是可信的，是真實的。」</span>
<span className="v" id="v6" data-v="6" data-xref="約翰福音 7:37–38; 約翰福音 4:10; 啟示錄 7:17"> 他又對我說：「都成了！我是阿拉法，我是俄梅戛；我是初，我是終。我要將生命泉的水白白賜給那口渴的人喝。</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多後書 6:18; 希伯來書 8:10; 啟示錄 2:11"> 得勝的，必承受這些為業：我要作他的上帝，他要作我的兒子。</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多前書 6:9–10; 啟示錄 2:11; 以弗所書 5:5–6"> 惟有膽怯的、不信的、可憎的、殺人的、淫亂的、行邪術的、拜偶像的，和一切說謊話的，他們的分就在燒着硫磺的火湖裏；這是第二次的死。」</span>
</div>
</div>

## 新耶路撒冷

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="啟示錄 21:2; 啟示錄 19:7; 啟示錄 16:1–17"> 拿着七個金碗、盛滿末後七災的七位天使中，有一位來對我說：「你到這裏來，我要將新婦，就是羔羊的妻，指給你看。」</span>
<span className="v" id="v10" data-v="10" data-xref="啟示錄 21:2; 以西結書 11:24; 以西結書 40:1–49"> 我被聖靈感動，天使就帶我到一座高大的山，將那由上帝那裏、從天而降的聖城耶路撒冷指示我。</span>
<span className="v" id="v11" data-v="11" data-xref="啟示錄 4:6; 啟示錄 22:5; 啟示錄 22:1"> 城中有上帝的榮耀；城的光輝如同極貴的寶石，好像碧玉，明如水晶。</span>
<span className="v" id="v12" data-v="12" data-xref="以西結書 48:31–34; 啟示錄 7:4–8; 啟示錄 21:17–21"> 有高大的牆，有十二個門，門上有十二位天使，門上又寫着以色列十二個支派的名字。</span>
<span className="v" id="v13" data-v="13" data-xref="以西結書 48:31–34"> 東邊有三門，北邊有三門，南邊有三門，西邊有三門。</span>
<span className="v" id="v14" data-v="14" data-xref="希伯來書 11:10; 以弗所書 2:20; 以賽亞書 54:11"> 城牆有十二根基，根基上有羔羊十二使徒的名字。</span>
<span className="v" id="v15" data-v="15" data-xref="撒迦利亞書 2:1; 啟示錄 11:1–2; 以西結書 41:1–5"> 對我說話的，拿着金葦子當尺，要量那城和城門城牆。</span>
<span className="v" id="v16" data-v="16" data-xref="以西結書 48:35; 以西結書 48:8–20"> 城是四方的，長寬一樣。天使用葦子量那城，共有四千里，長、寬、高都是一樣；</span>
<span className="v" id="v17" data-v="17" data-xref="啟示錄 7:4; 申命記 3:11; 啟示錄 13:18"> 又量了城牆，按着人的尺寸，就是天使的尺寸，共有一百四十四肘。</span>
<span className="v" id="v18" data-v="18" data-xref="啟示錄 21:11; 啟示錄 21:21; 啟示錄 21:19"> 牆是碧玉造的；城是精金的，如同明淨的玻璃。</span>
<span className="v" id="v19" data-v="19" data-xref="以賽亞書 54:11–12; 出埃及記 28:17–21; 約伯記 28:16–19"> 城牆的根基是用各樣寶石修飾的：第一根基是碧玉；第二是藍寶石；第三是綠瑪瑙；第四是綠寶石；</span>
<span className="v" id="v20" data-v="20" data-xref="啟示錄 4:3"> 第五是紅瑪瑙；第六是紅寶石；第七是黃璧璽；第八是水蒼玉；第九是紅璧璽；第十是翡翠；第十一是紫瑪瑙；第十二是紫晶。</span>
<span className="v" id="v21" data-v="21" data-xref="啟示錄 21:18; 啟示錄 17:4; 啟示錄 22:2"> 十二個門是十二顆珍珠，每門是一顆珍珠。城內的街道是精金，好像明透的玻璃。</span>
<span className="v" id="v22" data-v="22" data-xref="約翰福音 4:23; 列王紀上 8:27; 歷代志下 2:6"> 我未見城內有殿，因主上帝－全能者和羔羊為城的殿。</span>
<span className="v" id="v23" data-v="23" data-xref="以賽亞書 60:19–20; 啟示錄 22:5; 啟示錄 21:11"> 那城內又不用日月光照；因有上帝的榮耀光照，又有羔羊為城的燈。</span>
<span className="v" id="v24" data-v="24" data-xref="啟示錄 21:26; 啟示錄 22:2; 撒迦利亞書 8:22–23"> 列國要在城的光裏行走；地上的君王必將自己的榮耀歸與那城。</span>
<span className="v" id="v25" data-v="25" data-xref="以賽亞書 60:11; 撒迦利亞書 14:7; 啟示錄 22:5"> 城門白晝總不關閉，在那裏原沒有黑夜。</span>
<span className="v" id="v26" data-v="26" data-xref="啟示錄 21:24"> 人必將列國的榮耀、尊貴歸與那城。</span>
<span className="v" id="v27" data-v="27" data-xref="啟示錄 22:14–15; 以賽亞書 52:1; 啟示錄 20:15"> 凡不潔淨的，並那行可憎與虛謊之事的，總不得進那城；只有名字寫在羔羊生命冊上的才得進去。</span>
</div>

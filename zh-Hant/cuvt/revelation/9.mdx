<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="啟示錄 8:10; 羅馬書 10:7; 啟示錄 9:2"> 第五位天使吹號，我就看見一個星從天落到地上，有無底坑的鑰匙賜給它。</span>
<span className="v" id="v2" data-v="2" data-xref="約珥書 2:10; 創世記 19:28; 約珥書 2:2"> 它開了無底坑，便有煙從坑裏往上冒，好像大火爐的煙；日頭和天空都因這煙昏暗了。</span>
<span className="v" id="v3" data-v="3" data-xref="約珥書 1:4; 啟示錄 9:5; 約珥書 2:25"> 有蝗蟲從煙中出來，飛到地上；有能力賜給牠們，好像地上蠍子的能力一樣，</span>
<span className="v" id="v4" data-v="4" data-xref="啟示錄 7:2–4; 以西結書 9:4; 啟示錄 14:1"> 並且吩咐牠們說，不可傷害地上的草和各樣青物，並一切樹木，惟獨要傷害額上沒有上帝印記的人。</span>
<span className="v" id="v5" data-v="5" data-xref="啟示錄 9:10; 約伯記 2:6; 啟示錄 9:3"> 但不許蝗蟲害死他們，只叫他們受痛苦五個月。這痛苦就像蠍子螫人的痛苦一樣。</span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 23:30; 耶利米書 8:3; 啟示錄 6:16"> 在那些日子，人要求死，決不得死；願意死，死卻遠避他們。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="但以理書 7:8; 那鴻書 3:17; 約珥書 2:4–5"> 蝗蟲的形狀，好像預備出戰的馬一樣，頭上戴的好像金冠冕，臉面好像男人的臉面，</span>
<span className="v" id="v8" data-v="8" data-xref="約珥書 1:6; 哥林多前書 11:14–15; 彼得前書 3:3"> 頭髮像女人的頭髮，牙齒像獅子的牙齒。</span>
<span className="v" id="v9" data-v="9" data-xref="約珥書 2:5–8; 那鴻書 2:4–5; 約伯記 39:25"> 胸前有甲，好像鐵甲。牠們翅膀的聲音，好像許多車馬奔跑上陣的聲音。</span>
<span className="v" id="v10" data-v="10" data-xref="啟示錄 9:5; 啟示錄 9:3; 啟示錄 9:19"> 有尾巴像蠍子，尾巴上的毒鉤能傷人五個月。</span>
<span className="v" id="v11" data-v="11" data-xref="約伯記 26:6; 啟示錄 9:1–2; 以弗所書 2:2"> 有無底坑的使者作牠們的王，按着希伯來話，名叫亞巴頓，希臘話，名叫亞玻倫。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="啟示錄 11:14; 啟示錄 8:13–2; 啟示錄 9:13–21"> 第一樣災禍過去了，還有兩樣災禍要來。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="啟示錄 8:3–5; 出埃及記 30:2–3; 啟示錄 9:1"> 第六位天使吹號，我就聽見有聲音從上帝面前金壇的四角出來，</span>
<span className="v" id="v14" data-v="14" data-xref="啟示錄 16:12; 啟示錄 9:15; 撒母耳記下 8:3"> 吩咐那吹號的第六位天使，說：「把那捆綁在幼發拉底大河的四個使者釋放了。」</span>
<span className="v" id="v15" data-v="15" data-xref="啟示錄 9:18; 啟示錄 8:7; 啟示錄 8:9"> 那四個使者就被釋放；他們原是預備好了，到某年某月某日某時，要殺人的三分之一。</span>
<span className="v" id="v16" data-v="16" data-xref="啟示錄 7:4; 詩篇 68:17; 但以理書 7:10"> 馬軍有二萬萬；他們的數目我聽見了。</span>
<span className="v" id="v17" data-v="17" data-xref="啟示錄 9:18; 啟示錄 14:10; 歷代志上 12:8"> 我在異象中看見那些馬和騎馬的，騎馬的胸前有甲如火，與紫瑪瑙並硫磺。馬的頭好像獅子頭，有火、有煙、有硫磺從馬的口中出來。</span>
<span className="v" id="v18" data-v="18" data-xref="啟示錄 9:17; 啟示錄 9:15"> 口中所出來的火與煙並硫磺，這三樣災殺了人的三分之一。</span>
<span className="v" id="v19" data-v="19" data-xref="以賽亞書 9:15; 啟示錄 9:10; 以弗所書 4:14"> 這馬的能力是在口裏和尾巴上；因這尾巴像蛇，並且有頭用以害人。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="但以理書 5:23; 申命記 31:29; 提摩太前書 4:1"> 其餘未曾被這些災所殺的人仍舊不悔改自己手所做的，還是去拜鬼魔和那些不能看、不能聽、不能走，金、銀、銅、木、石的偶像，</span>
<span className="v" id="v21" data-v="21" data-xref="啟示錄 21:8; 哥林多後書 12:21; 啟示錄 17:5"> 又不悔改他們那些凶殺、邪術、姦淫、偷竊的事。</span>
</div>

## 引言和致意

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="啟示錄 22:16; 啟示錄 22:6; 加拉太書 1:12"> 耶穌基督的啟示，就是上帝賜給他，叫他將必要快成的事指示他的眾僕人。他就差遣使者曉諭他的僕人約翰。</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多前書 1:6; 約翰福音 19:35; 約翰一書 1:1"> 約翰便將上帝的道和耶穌基督的見證，凡自己所看見的都證明出來。</span>
<span className="v" id="v3" data-v="3" data-xref="路加福音 11:28; 啟示錄 22:10; 羅馬書 13:11"> 念這書上預言的和那些聽見又遵守其中所記載的，都是有福的，因為日期近了。</span>
</div>
<div className="bp poetry">
<span className="v" id="v4" data-v="4" data-xref="以賽亞書 11:2; 約翰福音 1:1; 希伯來書 13:8"> 約翰寫信給亞細亞的七個教會。但願從那昔在、今在、以後永在的上帝，和他寶座前的七靈，</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 89:27; 希伯來書 9:14; 約翰一書 1:7"> 並那誠實作見證的、從死裏首先復活、為世上君王元首的耶穌基督，有恩惠、平安歸與你們！<br />他愛我們，用自己的血使我們脫離<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古卷：洗去">a</a></sup>罪惡，</span>
<span className="v" id="v6" data-v="6" data-xref="啟示錄 5:10; 啟示錄 20:6; 出埃及記 19:6"> 又使我們成為國民，作他父上帝的祭司。但願榮耀、權能歸給他，直到永永遠遠。阿們！</span>
<span className="v" id="v7" data-v="7" data-xref="馬太福音 24:30; 撒迦利亞書 12:10; 但以理書 7:13"> <span className="pl pl-1">看哪，他駕雲降臨！</span><br /><span className="pl pl-1">眾目要看見他，</span><br /><span className="pl pl-1">連刺他的人也要看見他；</span><br /><span className="pl pl-1">地上的萬族都要因他哀哭。</span><br /><span className="pl pl-1">這話是真實的。阿們！</span></span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="以賽亞書 44:6; 啟示錄 22:13; 以賽亞書 43:10"> 主上帝說：「我是阿拉法，我是俄梅戛<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="阿拉法，俄梅戛：是希臘字母首末二字">b</a></sup>，是昔在、今在、以後永在的全能者。」</span>
</div>
</div>

## 基督的異象

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="使徒行傳 14:22; 啟示錄 3:10; 約翰福音 16:33"> 我－約翰就是你們的弟兄，和你們在耶穌的患難、國度、忍耐裏一同有分，為上帝的道，並為給耶穌作的見證，曾在那名叫拔摩的海島上。</span>
<span className="v" id="v10" data-v="10" data-xref="啟示錄 21:10; 哥林多後書 12:2–4; 啟示錄 4:1–2"> 當主日，我被聖靈感動，聽見在我後面有大聲音如吹號，說：</span>
<span className="v" id="v11" data-v="11" data-xref="啟示錄 3:1; 耶利米書 30:2; 哈巴谷書 2:2"> 「你所看見的當寫在書上，達與以弗所、士每拿、別迦摩、推雅推喇、撒狄、非拉鐵非、老底嘉那七個教會。」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="撒迦利亞書 4:2; 出埃及記 25:37; 啟示錄 1:20–1"> 我轉過身來，要看是誰發聲與我說話；既轉過來，就看見七個金燈臺。</span>
<span className="v" id="v13" data-v="13" data-xref="但以理書 7:13; 但以理書 10:5–6; 但以理書 10:16"> 燈臺中間有一位好像人子，身穿長衣，直垂到腳，胸間束着金帶。</span>
<span className="v" id="v14" data-v="14" data-xref="但以理書 10:6; 但以理書 7:9; 啟示錄 19:12"> 他的頭與髮皆白，如白羊毛，如雪；眼目如同火焰；</span>
<span className="v" id="v15" data-v="15" data-xref="以西結書 43:2; 但以理書 10:6; 啟示錄 14:2"> 腳好像在爐中鍛鍊光明的銅；聲音如同眾水的聲音。</span>
<span className="v" id="v16" data-v="16" data-xref="希伯來書 4:12; 啟示錄 19:15; 啟示錄 2:12"> 他右手拿着七星，從他口中出來一把兩刃的利劍；面貌如同烈日放光。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="以賽亞書 44:6; 啟示錄 22:13; 但以理書 10:8–10"> 我一看見，就仆倒在他腳前，像死了一樣。他用右手按着我，說：「不要懼怕！我是首先的，我是末後的，</span>
<span className="v" id="v18" data-v="18" data-xref="羅馬書 6:9; 希伯來書 7:25; 羅馬書 14:8–9"> 又是那存活的；我曾死過，現在又活了，直活到永永遠遠；並且拿着死亡和陰間的鑰匙。</span>
<span className="v" id="v19" data-v="19" data-xref="啟示錄 4:1–11; 啟示錄 1:11–3"> 所以你要把所看見的，和現在的事，並將來必成的事，都寫出來。</span>
<span className="v" id="v20" data-v="20" data-xref="啟示錄 2:1; 啟示錄 3:1; 啟示錄 1:16"> 論到你所看見、在我右手中的七星和七個金燈臺的奧祕，那七星就是七個教會的使者，七燈臺就是七個教會。」</span>
</div>
</div>

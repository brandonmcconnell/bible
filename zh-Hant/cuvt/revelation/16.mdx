## 上帝大怒的碗

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="西番雅書 3:8; 耶利米書 10:25; 啟示錄 15:1"> 我聽見有大聲音從殿中出來，向那七位天使說：「你們去，把盛上帝大怒的七碗倒在地上。」</span>
<span className="v" id="v2" data-v="2" data-xref="啟示錄 8:7; 啟示錄 16:11; 啟示錄 13:15–18"> 第一位天使便去，把碗倒在地上，就有惡而且毒的瘡生在那些有獸印記、拜獸像的人身上。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 7:17–21; 啟示錄 8:8–9; 啟示錄 11:6"> 第二位天使把碗倒在海裏，海就變成血，好像死人的血，海中的活物都死了。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及記 7:17–20; 啟示錄 8:10–11; 何西阿書 13:15"> 第三位天使把碗倒在江河與眾水的泉源裏，水就變成血了。</span>
<span className="v" id="v5" data-v="5" data-xref="啟示錄 1:8; 啟示錄 11:17; 啟示錄 1:4"> 我聽見掌管眾水的天使說：<br /><span className="pl pl-1">昔在、今在的聖者啊，</span><br /><span className="pl pl-1">你這樣判斷是公義的；</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="以賽亞書 49:26; 啟示錄 11:18; 啟示錄 6:10–11"> <span className="pl pl-1">他們曾流聖徒與先知的血，</span><br /><span className="pl pl-1">現在你給他們血喝；</span><br /><span className="pl pl-1">這是他們所該受的。</span></span>
<span className="v" id="v7" data-v="7" data-xref="啟示錄 19:2; 啟示錄 6:9; 啟示錄 15:3–4"> 我又聽見祭壇中有聲音說：<br /><span className="pl pl-1">是的，主上帝－全能者啊，</span><br /><span className="pl pl-1">你的判斷義哉！誠哉！</span></span>
<span className="v" id="v8" data-v="8" data-xref="使徒行傳 2:20; 啟示錄 14:18; 約拿書 4:8"> 第四位天使把碗倒在日頭上，叫日頭能用火烤人。</span>
<span className="v" id="v9" data-v="9" data-xref="啟示錄 2:21; 啟示錄 16:21; 啟示錄 11:13"> 人被大熱所烤，就褻瀆那有權掌管這些災的上帝之名，並不悔改將榮耀歸給上帝。</span>
<span className="v" id="v10" data-v="10" data-xref="啟示錄 9:2; 馬太福音 8:12; 以賽亞書 8:21–22"> 第五位天使把碗倒在獸的座位上，獸的國就黑暗了。人因疼痛就咬自己的舌頭；</span>
<span className="v" id="v11" data-v="11" data-xref="啟示錄 16:9; 啟示錄 16:2; 啟示錄 16:21"> 又因所受的疼痛，和生的瘡，就褻瀆天上的上帝，並不悔改所行的。</span>
<span className="v" id="v12" data-v="12" data-xref="啟示錄 9:14; 耶利米書 51:36; 以賽亞書 44:27"> 第六位天使把碗倒在幼發拉底大河上，河水就乾了，要給那從日出之地所來的眾王預備道路。</span>
<span className="v" id="v13" data-v="13" data-xref="啟示錄 19:20; 帖撒羅尼迦後書 2:9–11; 啟示錄 20:10"> 我又看見三個污穢的靈，好像青蛙，從龍口、獸口並假先知的口中出來。</span>
<span className="v" id="v14" data-v="14" data-xref="啟示錄 17:14; 提摩太前書 4:1; 啟示錄 20:8"> 他們本是鬼魔的靈，施行奇事，出去到普天下眾王那裏，叫他們在上帝全能者的大日聚集爭戰。（</span>
<span className="v" id="v15" data-v="15" data-xref="帖撒羅尼迦前書 5:2–3; 馬太福音 24:42–43; 彼得後書 3:10"> 看哪，我來像賊一樣。那警醒、看守衣服、免得赤身而行、叫人見他羞恥的有福了！）</span>
<span className="v" id="v16" data-v="16" data-xref="撒迦利亞書 12:11; 士師記 5:19; 約珥書 3:9–14"> 那三個鬼魔便叫眾王聚集在一處，希伯來話叫作哈米吉多頓。</span>
<span className="v" id="v17" data-v="17" data-xref="約翰福音 19:30; 啟示錄 21:6; 以弗所書 6:12"> 第七位天使把碗倒在空中，就有大聲音從殿中的寶座上出來，說：「成了！」</span>
<span className="v" id="v18" data-v="18" data-xref="但以理書 12:1; 啟示錄 4:5; 啟示錄 11:19"> 又有閃電、聲音、雷轟、大地震，自從地上有人以來，沒有這樣大、這樣厲害的地震。</span>
<span className="v" id="v19" data-v="19" data-xref="啟示錄 18:5; 啟示錄 17:18; 啟示錄 18:21"> 那大城裂為三段，列國的城也都倒塌了；上帝也想起巴比倫大城來，要把那盛自己烈怒的酒杯遞給他。</span>
<span className="v" id="v20" data-v="20" data-xref="啟示錄 6:14; 啟示錄 20:11; 耶利米書 4:23–25"> 各海島都逃避了，眾山也不見了。</span>
<span className="v" id="v21" data-v="21" data-xref="啟示錄 11:19; 約書亞記 10:11; 啟示錄 16:9"> 又有大雹子從天落在人身上，每一個約重一他連得<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一他連得約有九十斤">a</a></sup>。為這雹子的災極大，人就褻瀆上帝。</span>
</div>

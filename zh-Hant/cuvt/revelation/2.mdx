## 給以弗所教會的信

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="啟示錄 1:20; 啟示錄 1:16; 啟示錄 1:11–13"> 「你要寫信給以弗所教會的使者，說：『那右手拿着七星、在七個金燈臺中間行走的，說：</span>
<span className="v" id="v2" data-v="2" data-xref="約翰一書 4:1; 彼得後書 2:1–3; 帖撒羅尼迦前書 5:21"> 我知道你的行為、勞碌、忍耐，也知道你不能容忍惡人。你也曾試驗那自稱為使徒卻不是使徒的，看出他們是假的來。</span>
<span className="v" id="v3" data-v="3" data-xref="希伯來書 10:36; 加拉太書 6:9; 雅各書 5:7–11"> 你也能忍耐，曾為我的名勞苦，並不乏倦。</span>
<span className="v" id="v4" data-v="4" data-xref="馬太福音 24:12–13; 耶利米書 2:2–5; 希伯來書 6:10–11"> 然而有一件事我要責備你，就是你把起初的愛心離棄了。</span>
<span className="v" id="v5" data-v="5" data-xref="啟示錄 3:2–3; 啟示錄 3:19; 啟示錄 2:16"> 所以，應當回想你是從哪裏墜落的，並要悔改，行起初所行的事。你若不悔改，我就臨到你那裏，把你的燈臺從原處挪去。</span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 101:3; 約翰二書 1:9–10; 詩篇 26:5"> 然而你還有一件可取的事，就是你恨惡尼哥拉一黨人的行為，這也是我所恨惡的。</span>
<span className="v" id="v7" data-v="7" data-xref="啟示錄 2:17; 啟示錄 2:11; 馬太福音 11:15"> 聖靈向眾教會所說的話，凡有耳的，就應當聽！得勝的，我必將上帝樂園中生命樹的果子賜給他吃。』」</span>
</div>
</div>

## 給士每拿教會的信

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="啟示錄 1:17–18; 啟示錄 1:8; 啟示錄 1:11"> 「你要寫信給士每拿教會的使者，說：『那首先的、末後的、死過又活的，說：</span>
<span className="v" id="v9" data-v="9" data-xref="啟示錄 3:9; 哥林多後書 8:9; 雅各書 2:5–6"> 我知道你的患難，你的貧窮（你卻是富足的），也知道那自稱是猶太人所說的毀謗話，其實他們不是猶太人，乃是撒但一會的人。</span>
<span className="v" id="v10" data-v="10" data-xref="雅各書 1:12; 馬太福音 10:22; 啟示錄 3:10–11"> 你將要受的苦你不用怕。魔鬼要把你們中間幾個人下在監裏，叫你們被試煉，你們必受患難十日。你務要至死忠心，我就賜給你那生命的冠冕。</span>
<span className="v" id="v11" data-v="11" data-xref="啟示錄 20:6; 啟示錄 20:14; 啟示錄 21:8"> 聖靈向眾教會所說的話，凡有耳的，就應當聽！得勝的，必不受第二次死的害。』」</span>
</div>
</div>

## 給別迦摩教會的信

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="啟示錄 2:16; 希伯來書 4:12; 啟示錄 1:16"> 「你要寫信給別迦摩教會的使者，說：『那有兩刃利劍的，說：</span>
<span className="v" id="v13" data-v="13" data-xref="啟示錄 2:9–10; 提摩太前書 5:8; 啟示錄 3:8–9"> 我知道你的居所，就是有撒但座位之處；當我忠心的見證人安提帕在你們中間、撒但所住的地方被殺之時，你還堅守我的名，沒有棄絕我的道。</span>
<span className="v" id="v14" data-v="14" data-xref="民數記 31:16; 彼得後書 2:15; 啟示錄 2:20"> 然而，有幾件事我要責備你：因為在你那裏有人服從了巴蘭的教訓；這巴蘭曾教導巴勒將絆腳石放在以色列人面前，叫他們吃祭偶像之物，行姦淫的事。</span>
<span className="v" id="v15" data-v="15" data-xref="啟示錄 2:6"> 你那裏也有人照樣服從了尼哥拉一黨人的教訓。</span>
<span className="v" id="v16" data-v="16" data-xref="帖撒羅尼迦後書 2:8; 啟示錄 1:16; 啟示錄 2:5"> 所以，你當悔改；若不悔改，我就快臨到你那裏，用我口中的劍攻擊他們。</span>
<span className="v" id="v17" data-v="17" data-xref="以賽亞書 62:2; 以賽亞書 65:15; 啟示錄 19:12–13"> 聖靈向眾教會所說的話，凡有耳的，就應當聽！得勝的，我必將那隱藏的嗎哪賜給他，並賜他一塊白石，石上寫着新名；除了那領受的以外，沒有人能認識。』」</span>
</div>
</div>

## 給推雅推喇教會的信

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="啟示錄 1:14–15; 啟示錄 1:11; 約翰福音 3:35–36"> 「你要寫信給推雅推喇教會的使者，說：『那眼目如火焰、腳像光明銅的上帝之子說：</span>
<span className="v" id="v19" data-v="19" data-xref="提摩太前書 1:5; 彼得後書 1:7; 約翰福音 15:2"> 我知道你的行為、愛心、信心、勤勞、忍耐，又知道你末後所行的善事，比起初所行的更多。</span>
<span className="v" id="v20" data-v="20" data-xref="啟示錄 2:14; 列王紀上 16:31; 哥林多前書 10:18–21"> 然而，有一件事我要責備你，就是你容讓那自稱是先知的婦人耶洗別教導我的僕人，引誘他們行姦淫，吃祭偶像之物。</span>
<span className="v" id="v21" data-v="21" data-xref="彼得後書 3:9; 羅馬書 2:4–5; 啟示錄 9:20–21"> 我曾給她悔改的機會，她卻不肯悔改她的淫行。</span>
<span className="v" id="v22" data-v="22" data-xref="啟示錄 17:2; 路加福音 13:5; 以西結書 16:37–41"> 看哪，我要叫她病臥在床。那些與她行淫的人，若不悔改所行的，我也要叫他們同受大患難。</span>
<span className="v" id="v23" data-v="23" data-xref="馬太福音 16:27; 羅馬書 8:27; 詩篇 7:9"> 我又要殺死她的黨類<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是兒女">a</a></sup>，叫眾教會知道，我是那察看人肺腑心腸的，並要照你們的行為報應你們各人。</span>
<span className="v" id="v24" data-v="24" data-xref="哥林多後書 2:11; 啟示錄 12:9; 哥林多後書 11:3"> 至於你們推雅推喇其餘的人，就是一切不從那教訓、不曉得他們素常所說撒但深奧之理的人，我告訴你們，我不將別的擔子放在你們身上。</span>
<span className="v" id="v25" data-v="25" data-xref="啟示錄 3:11; 啟示錄 3:3; 希伯來書 10:23"> 但你們已經有的，總要持守，直等到我來。</span>
<span className="v" id="v26" data-v="26" data-xref="啟示錄 3:21; 但以理書 7:27; 啟示錄 2:7"> 那得勝又遵守我命令到底的，我要賜給他權柄制伏列國；</span>
<span className="v" id="v27" data-v="27" data-xref="詩篇 2:8–9; 啟示錄 12:5; 啟示錄 19:15"> 他必用鐵杖轄管<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="轄管：原文是牧">b</a></sup>他們，將他們如同窯戶的瓦器打得粉碎，像我從我父領受的權柄一樣。</span>
<span className="v" id="v28" data-v="28" data-xref="啟示錄 22:16; 彼得後書 1:19; 路加福音 1:78–79"> 我又要把晨星賜給他。</span>
<span className="v" id="v29" data-v="29" data-xref="啟示錄 2:7"> 聖靈向眾教會所說的話，凡有耳的，就應當聽！』」</span>
</div>
</div>

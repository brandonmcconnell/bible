## 與亞瑪力人爭戰

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳記上 9:16; 撒母耳記上 12:14; 詩篇 2:10–11"> 撒母耳對掃羅說：「耶和華差遣我膏你為王，治理他的百姓以色列；所以你當聽從耶和華的話。</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 25:17–19; 出埃及記 17:8–16; 民數記 24:20"> 萬軍之耶和華如此說：『以色列人出埃及的時候，在路上亞瑪力人怎樣待他們，怎樣抵擋他們，我都沒忘。</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 20:16–18; 民數記 24:20; 民數記 31:17"> 現在你要去擊打亞瑪力人，滅盡他們所有的，不可憐惜他們，將男女、孩童、吃奶的，並牛、羊、駱駝，和驢盡行殺死。』」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="約書亞記 15:24; 撒母耳記上 11:8; 撒母耳記上 13:15"> 於是掃羅招聚百姓在提拉因，數點他們，共有步兵二十萬，另有猶大人一萬。</span>
<span className="v" id="v5" data-v="5"> 掃羅到了亞瑪力的京城，在谷中設下埋伏。</span>
<span className="v" id="v6" data-v="6" data-xref="士師記 1:16; 民數記 10:29–32; 出埃及記 18:19"> 掃羅對基尼人說：「你們離開亞瑪力人下去吧，恐怕我將你們和亞瑪力人一同殺滅；因為以色列人出埃及的時候，你們曾恩待他們。」於是基尼人離開亞瑪力人去了。</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 16:7; 創世記 25:18; 撒母耳記上 14:48"> 掃羅擊打亞瑪力人，從哈腓拉直到埃及前的書珥，</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳記上 30:1; 以斯帖記 3:1; 民數記 24:7"> 生擒了亞瑪力王亞甲，用刀殺盡亞瑪力的眾民。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳記上 15:15; 撒母耳記上 15:19; 撒母耳記上 15:3"> 掃羅和百姓卻憐惜亞甲，也愛惜上好的牛、羊、牛犢、羊羔，並一切美物，不肯滅絕。凡下賤瘦弱的，盡都殺了。</span>
</div>
</div>

## 掃羅被廢

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10"> 耶和華的話臨到撒母耳說：</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳記上 13:13; 創世記 6:6; 撒母耳記下 24:16"> 「我立掃羅為王，我後悔了；因為他轉去不跟從我，不遵守我的命令。」撒母耳便甚憂愁，終夜哀求耶和華。</span>
<span className="v" id="v12" data-v="12" data-xref="約書亞記 15:55; 撒母耳記下 18:18; 撒母耳記上 25:2"> 撒母耳清早起來，迎接掃羅。有人告訴撒母耳說：「掃羅到了迦密，在那裏立了紀念碑，又轉身下到吉甲。」</span>
<span className="v" id="v13" data-v="13" data-xref="士師記 17:2; 路得記 3:10; 箴言 31:31"> 撒母耳到了掃羅那裏，掃羅對他說：「願耶和華賜福與你，耶和華的命令我已遵守了。」</span>
<span className="v" id="v14" data-v="14" data-xref="瑪拉基書 3:13–15; 耶利米書 2:18–19; 耶利米書 2:34–37"> 撒母耳說：「我耳中聽見有羊叫、牛鳴，是從哪裏來的呢？」</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳記上 15:21; 撒母耳記上 15:9; 出埃及記 32:22–23"> 掃羅說：「這是百姓從亞瑪力人那裏帶來的；因為他們愛惜上好的牛羊，要獻與耶和華－你的上帝；其餘的，我們都滅盡了。」</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳記上 9:27; 列王紀上 22:16; 撒母耳記上 12:7"> 撒母耳對掃羅說：「你住口吧！等我將耶和華昨夜向我所說的話告訴你。」掃羅說：「請講。」</span>
</div>
<div className="bp poetry">
<span className="v" id="v17" data-v="17" data-xref="撒母耳記上 10:22; 撒母耳記上 9:21; 撒母耳記上 15:1–3"> 撒母耳對掃羅說：「從前你雖然以自己為小，豈不是被立為以色列支派的元首嗎？耶和華膏你作以色列的王。</span>
<span className="v" id="v18" data-v="18" data-xref="箴言 10:29; 創世記 13:13; 創世記 15:16"> 耶和華差遣你，吩咐你說，你去擊打那些犯罪的亞瑪力人，將他們滅絕淨盡。</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳記上 14:32; 歷代志下 33:6; 歷代志下 36:12"> 你為何沒有聽從耶和華的命令，急忙擄掠財物，行耶和華眼中看為惡的事呢？」</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳記上 15:13; 馬太福音 19:20; 羅馬書 10:3"> 掃羅對撒母耳說：「我實在聽從了耶和華的命令，行了耶和華所差遣我行的路，擒了亞瑪力王亞甲來，滅盡了亞瑪力人。</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳記上 15:15; 出埃及記 32:22–23; 創世記 3:13"> 百姓卻在所當滅的物中，取了最好的牛羊，要在吉甲獻與耶和華－你的上帝。」</span>
<span className="v" id="v22" data-v="22" data-xref="何西阿書 6:6; 詩篇 51:16–17; 箴言 21:3"> 撒母耳說：<br /><span className="pl pl-1">耶和華喜悅燔祭和平安祭，</span><br /><span className="pl pl-1">豈如喜悅人聽從他的話呢？</span><br /><span className="pl pl-1">聽命勝於獻祭；</span><br /><span className="pl pl-1">順從勝於公羊的脂油。</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="耶利米書 28:16; 撒母耳記上 13:14; 利未記 20:6"> <span className="pl pl-1">悖逆的罪與行邪術的罪相等；</span><br /><span className="pl pl-1">頑梗的罪與拜虛神和偶像的罪相同。</span><br /><span className="pl pl-1">你既厭棄耶和華的命令，</span><br /><span className="pl pl-1">耶和華也厭棄你作王。</span></span>
</div>
</div>

## 掃羅認罪

<div className="bt">
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="撒母耳記下 12:13; 以賽亞書 51:12–13; 民數記 22:34"> 掃羅對撒母耳說：「我有罪了，我因懼怕百姓，聽從他們的話，就違背了耶和華的命令和你的言語。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及記 10:17"> 現在求你赦免我的罪，同我回去，我好敬拜耶和華。」</span>
<span className="v" id="v26" data-v="26" data-xref="何西阿書 4:6; 撒母耳記上 13:14; 撒母耳記上 16:1"> 撒母耳對掃羅說：「我不同你回去；因為你厭棄耶和華的命令，耶和華也厭棄你作以色列的王。」</span>
<span className="v" id="v27" data-v="27" data-xref="列王紀上 11:30–31"> 撒母耳轉身要走，掃羅就扯住他外袍的衣襟，衣襟就撕斷了。</span>
<span className="v" id="v28" data-v="28" data-xref="撒母耳記上 28:17–18; 使徒行傳 13:22; 但以理書 4:32"> 撒母耳對他說：「如此，今日耶和華使以色列國與你斷絕，將這國賜與比你更好的人。</span>
<span className="v" id="v29" data-v="29" data-xref="以西結書 24:14; 民數記 23:19; 提多書 1:2"> 以色列的大能者必不致說謊，也不致後悔；因為他迥非世人，決不後悔。」</span>
<span className="v" id="v30" data-v="30" data-xref="約翰福音 5:44; 約翰福音 12:43; 以賽亞書 29:13"> 掃羅說：「我有罪了，雖然如此，求你在我百姓的長老和以色列人面前抬舉我，同我回去，我好敬拜耶和華－你的上帝。」</span>
<span className="v" id="v31" data-v="31"> 於是撒母耳轉身跟隨掃羅回去，掃羅就敬拜耶和華。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="啟示錄 18:7; 帖撒羅尼迦前書 5:3; 耶利米書 48:44"> 撒母耳說：「要把亞瑪力王亞甲帶到我這裏來。」亞甲就歡歡喜喜地來到他面前，心裏說，死亡的苦難必定過去了。</span>
<span className="v" id="v33" data-v="33" data-xref="士師記 1:7; 創世記 9:6; 馬太福音 7:2"> 撒母耳說：「你既用刀使婦人喪子，這樣，你母親在婦人中也必喪子。」於是，撒母耳在吉甲耶和華面前將亞甲殺死。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="撒母耳記上 11:4; 撒母耳記上 7:17"> 撒母耳回了拉瑪。掃羅上他所住的基比亞，回自己的家去了。</span>
<span className="v" id="v35" data-v="35" data-xref="撒母耳記上 15:11; 撒母耳記上 19:24; 撒母耳記上 16:1"> 撒母耳直到死的日子，再沒有見掃羅；但撒母耳為掃羅悲傷，是因耶和華後悔立他為以色列的王。</span>
</div>
</div>

</div>

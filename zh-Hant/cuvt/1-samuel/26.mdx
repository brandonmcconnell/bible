## 大衛又饒掃羅的命

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳記上 23:19; 詩篇 54:1–7; 約書亞記 15:24"> 西弗人到基比亞見掃羅，說：「大衛不是在曠野前的哈基拉山藏着嗎？」</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳記上 24:2; 撒母耳記上 13:2; 詩篇 140:4–9"> 掃羅就起身，帶領以色列人中挑選的三千精兵下到西弗的曠野，要在那裏尋索大衛。</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳記上 23:19; 撒母耳記上 26:1"> 掃羅在曠野前的哈基拉山，在道路上安營。大衛住在曠野，聽說掃羅到曠野來追尋他，</span>
<span className="v" id="v4" data-v="4" data-xref="馬太福音 10:16; 約書亞記 2:1"> 就打發人去探聽，便知道掃羅果然來到。</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳記上 17:55; 撒母耳記上 17:20; 撒母耳記上 14:50–51"> 大衛起來，到掃羅安營的地方，看見掃羅和他的元帥尼珥的兒子押尼珥睡臥之處；掃羅睡在輜重營裏，百姓安營在他周圍。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="士師記 7:10–11; 撒母耳記下 2:18; 創世記 15:20"> 大衛對赫人亞希米勒和洗魯雅的兒子約押的兄弟亞比篩說：「誰同我下到掃羅營裏去？」亞比篩說：「我同你下去。」</span>
<span className="v" id="v7" data-v="7" data-xref="帖撒羅尼迦前書 5:2–3"> 於是大衛和亞比篩夜間到了百姓那裏，見掃羅睡在輜重營裏；他的槍在頭旁，插在地上。押尼珥和百姓睡在他周圍。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳記上 24:4; 撒母耳記上 26:23; 申命記 32:30"> 亞比篩對大衛說：「現在上帝將你的仇敵交在你手裏，求你容我拿槍將他刺透在地，一刺就成，不用再刺。」</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳記下 1:14; 詩篇 105:15; 撒母耳記下 1:16"> 大衛對亞比篩說：「不可害死他。有誰伸手害耶和華的受膏者而無罪呢？」</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 47:29; 申命記 31:14; 詩篇 37:13"> 大衛又說：「我指着永生的耶和華起誓，他或被耶和華擊打，或是死期到了，或是出戰陣亡；</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳記上 24:6; 撒母耳記上 24:12; 撒母耳記下 1:14"> 我在耶和華面前，萬不敢伸手害耶和華的受膏者。現在你可以將他頭旁的槍和水瓶拿來，我們就走。」</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 2:21; 創世記 15:12; 以賽亞書 29:10"> 大衛從掃羅的頭旁拿了槍和水瓶，二人就走了，沒有人看見，沒有人知道，也沒有人醒起，都睡着了，因為耶和華使他們沉沉地睡了。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="撒母耳記上 24:8; 士師記 9:7"> 大衛過到那邊去，遠遠地站在山頂上，與他們相離甚遠。</span>
<span className="v" id="v14" data-v="14"> 大衛呼叫百姓和尼珥的兒子押尼珥說：「押尼珥啊，你為何不答應呢？」押尼珥說：「你是誰？竟敢呼叫王呢？」</span>
<span className="v" id="v15" data-v="15"> 大衛對押尼珥說：「你不是個勇士嗎？以色列中誰能比你呢？民中有人進來要害死王－你的主，你為何沒有保護王－你的主呢？</span>
<span className="v" id="v16" data-v="16" data-xref="詩篇 79:11; 撒母耳記下 12:5; 撒母耳記上 26:9"> 你這樣是不好的！我指着永生的耶和華起誓，你們都是該死的；因為沒有保護你們的主，就是耶和華的受膏者。現在你看看王頭旁的槍和水瓶在哪裏。」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="撒母耳記上 24:16; 撒母耳記上 24:8"> 掃羅聽出是大衛的聲音，就說：「我兒大衛，這是你的聲音嗎？」大衛說：「主－我的王啊，是我的聲音」；</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳記上 24:9; 撒母耳記上 24:11–14; 約翰福音 10:32"> 又說：「我做了甚麼？我手裏有甚麼惡事？我主竟追趕僕人呢？</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳記下 14:16; 撒母耳記下 16:11; 撒母耳記下 20:19"> 求我主我王聽僕人的話：若是耶和華激發你攻擊我，願耶和華收納祭物；若是人激發你，願他在耶和華面前受咒詛；因為他現今趕逐我，不容我在耶和華的產業上有分，說：『你去事奉別神吧！』</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳記上 24:14; 馬太福音 26:55; 撒母耳記上 25:29"> 現在求王不要使我的血流在離耶和華遠的地方。以色列王出來是尋找一個虼蚤，如同人在山上獵取一個鷓鴣一般。」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="撒母耳記上 15:24; 撒母耳記上 24:17; 出埃及記 9:27"> 掃羅說：「我有罪了！我兒大衛，你可以回來，因你今日看我的性命為寶貴；我必不再加害於你。我是糊塗人，大大錯了。」</span>
<span className="v" id="v22" data-v="22"> 大衛說：「王的槍在這裏，可以吩咐一個僕人過來拿去。</span>
<span className="v" id="v23" data-v="23" data-xref="詩篇 62:12; 撒母耳記上 24:6–7; 詩篇 18:20–26"> 今日耶和華將王交在我手裏，我卻不肯伸手害耶和華的受膏者。耶和華必照各人的公義誠實報應他。</span>
<span className="v" id="v24" data-v="24" data-xref="馬太福音 5:7; 哥林多後書 1:9–10; 詩篇 54:7"> 我今日重看你的性命，願耶和華也重看我的性命，並且拯救我脫離一切患難。」</span>
<span className="v" id="v25" data-v="25" data-xref="民數記 24:9–10; 箴言 26:25; 撒母耳記上 24:19"> 掃羅對大衛說：「我兒大衛，願你得福！你必做大事，也必得勝。」於是大衛起行，掃羅回他的本處去了。</span>
</div>

## 大衛救基伊拉的居民

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="約書亞記 15:44; 彌迦書 6:15; 尼希米記 3:17–18"> 有人告訴大衛說：「非利士人攻擊基伊拉，搶奪禾場。」</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳記上 23:4; 撒母耳記下 5:19; 撒母耳記下 5:23"> 所以大衛求問耶和華說：「我去攻打那些非利士人可以不可以？」耶和華對大衛說：「你可以去攻打非利士人，拯救基伊拉。」</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米書 12:5; 詩篇 11:1; 撒母耳記上 23:15"> 跟隨大衛的人對他說：「我們在猶大地這裏尚且懼怕，何況往基伊拉去攻打非利士人的軍旅呢？」</span>
<span className="v" id="v4" data-v="4" data-xref="士師記 7:7; 約書亞記 8:7; 列王紀下 3:18"> 大衛又求問耶和華。耶和華回答說：「你起身下基伊拉去，我必將非利士人交在你手裏。」</span>
<span className="v" id="v5" data-v="5"> 大衛和跟隨他的人往基伊拉去，與非利士人打仗，大大殺敗他們，又奪獲他們的牲畜。這樣，大衛救了基伊拉的居民。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳記上 22:20; 撒母耳記上 14:3; 撒母耳記上 14:18"> 亞希米勒的兒子亞比亞他逃到基伊拉見大衛的時候，手裏拿着以弗得。</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳記上 24:4–6; 約伯記 20:5; 撒母耳記上 26:8–9"> 有人告訴掃羅說：「大衛到了基伊拉。」掃羅說：「他進了有門有閂的城，困閉在裏頭；這是上帝將他交在我手裏了。」</span>
<span className="v" id="v8" data-v="8"> 於是掃羅招聚眾民，要下去攻打基伊拉城，圍困大衛和跟隨他的人。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳記上 30:7; 撒母耳記上 23:6; 民數記 27:21"> 大衛知道掃羅設計謀害他，就對祭司亞比亞他說：「將以弗得拿過來。」</span>
<span className="v" id="v10" data-v="10" data-xref="羅馬書 3:15–16; 撒母耳記上 23:8; 創世記 18:24"> 大衛禱告說：「耶和華－以色列的上帝啊，你僕人聽真了掃羅要往基伊拉來，為我的緣故滅城。</span>
<span className="v" id="v11" data-v="11" data-xref="耶利米書 33:3; 詩篇 50:15; 馬太福音 7:7–8"> 基伊拉人將我交在掃羅手裏不交？掃羅照着你僕人所聽的話下來不下來？耶和華－以色列的上帝啊，求你指示僕人！」耶和華說：「掃羅必下來。」</span>
<span className="v" id="v12" data-v="12" data-xref="撒母耳記上 23:20; 詩篇 31:8; 詩篇 62:1"> 大衛又說：「基伊拉人將我和跟隨我的人交在掃羅手裏不交？」耶和華說：「必交出來。」</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳記上 22:2; 撒母耳記上 25:13; 撒母耳記上 30:9–10"> 大衛和跟隨他的約有六百人，就起身出了基伊拉，往他們所能往的地方去。有人告訴掃羅，大衛離開基伊拉逃走；於是掃羅不出來了。</span>
</div>
</div>

## 大衛在山地

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="詩篇 54:3–4; 詩篇 32:7; 約書亞記 15:24"> 大衛住在曠野的山寨裏，常在西弗曠野的山地。掃羅天天尋索大衛，上帝卻不將大衛交在他手裏。</span>
<span className="v" id="v15" data-v="15"> 大衛知道掃羅出來尋索他的命。那時，他住在西弗曠野的樹林裏；</span>
<span className="v" id="v16" data-v="16" data-xref="以賽亞書 35:3–4; 希伯來書 12:12–13; 約伯記 4:3–4"> 掃羅的兒子約拿單起身，往那樹林裏去見大衛，使他倚靠上帝得以堅固，</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳記上 20:31; 撒母耳記上 24:20; 使徒行傳 28:16"> 對他說：「不要懼怕！我父掃羅的手必不加害於你；你必作以色列的王，我也作你的宰相。這事我父掃羅知道了。」</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳記下 21:7; 撒母耳記上 20:42; 撒母耳記上 18:3"> 於是二人在耶和華面前立約。大衛仍住在樹林裏，約拿單回家去了。</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳記上 26:1; 撒母耳記上 26:3; 詩篇 54:1–7"> 西弗人上到基比亞見掃羅，說：「大衛不是在我們那裏的樹林裏山寨中、曠野南邊的哈基拉山藏着嗎？</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳記上 23:12; 箴言 29:26; 箴言 11:23"> 王啊，請你隨你的心願下來，我們必親自將他交在王的手裏。」</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳記上 22:8; 以賽亞書 66:5; 彌迦書 3:11"> 掃羅說：「願耶和華賜福與你們，因你們顧恤我。</span>
<span className="v" id="v22" data-v="22" data-xref="約伯記 5:13"> 請你們回去，再確實查明他的住處和行蹤，是誰看見他在那裏，因為我聽見人說他甚狡猾。</span>
<span className="v" id="v23" data-v="23" data-xref="羅馬書 3:15–16; 馬可福音 14:1; 民數記 10:36"> 所以要看準他藏匿的地方，回來據實地告訴我，我就與你們同去。他若在猶大的境內，我必從千門萬戶中搜出他來。」</span>
<span className="v" id="v24" data-v="24" data-xref="撒母耳記上 25:2; 約書亞記 15:55"> 西弗人就起身，在掃羅以先往西弗去。 大衛和跟隨他的人卻在瑪雲曠野南邊的亞拉巴。</span>
<span className="v" id="v25" data-v="25" data-xref="士師記 15:8; 撒母耳記上 23:28"> 掃羅和跟隨他的人去尋找大衛；有人告訴大衛，他就下到磐石，住在瑪雲的曠野。掃羅聽見，便在瑪雲的曠野追趕大衛。</span>
<span className="v" id="v26" data-v="26" data-xref="詩篇 17:9; 哥林多後書 1:8; 詩篇 140:1–9"> 掃羅在山這邊走，大衛和跟隨他的人在山那邊走。大衛急忙躲避掃羅；因為掃羅和跟隨他的人，四面圍住大衛和跟隨他的人，要拿獲他們。</span>
<span className="v" id="v27" data-v="27" data-xref="列王紀下 19:9; 詩篇 116:3; 申命記 32:36"> 忽有使者來報告掃羅說：「非利士人犯境搶掠，請王快快回去！」</span>
<span className="v" id="v28" data-v="28"> 於是掃羅不追趕大衛，回去攻打非利士人。因此那地方名叫西拉‧哈瑪希羅結。</span>
<span className="v" id="v29" data-v="29" data-xref="歷代志下 20:2; 約書亞記 15:62; 以西結書 47:10"> 大衛從那裏上去，住在隱‧基底的山寨裏。</span>
</div>

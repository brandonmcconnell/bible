<span className="v" id="v2" data-v="2" data-xref="撒母耳記上 17:15; 撒母耳記上 16:21–23"> 那日掃羅留住大衛，不容他再回父家。</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳記上 20:8–17; 撒母耳記上 20:42; 撒母耳記下 21:7"> 約拿單愛大衛如同愛自己的性命，就與他結盟。</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 41:42; 路加福音 15:22; 以斯帖記 6:8–9"> 約拿單從身上脫下外袍，給了大衛，又將戰衣、刀、弓、腰帶都給了他。</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳記上 18:30; 撒母耳記上 18:14–15; 歌羅西書 4:5"> 掃羅無論差遣大衛往何處去，他都做事精明。掃羅就立他作戰士長，眾百姓和掃羅的臣僕無不喜悅。</span>

## 掃羅妒忌大衛

<div className="bt">
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="出埃及記 15:20; 士師記 11:34; 詩篇 68:25"> 大衛打死了那非利士人，同眾人回來的時候，婦女們從以色列各城裏出來，歡歡喜喜，打鼓擊磬，歌唱跳舞，迎接掃羅王。</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳記上 21:11; 撒母耳記上 29:5; 出埃及記 15:21"> 眾婦女舞蹈唱和，說：「掃羅殺死千千，大衛殺死萬萬。」</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳記上 15:28; 箴言 13:10; 雅各書 4:5"> 掃羅甚發怒，不喜悅這話，就說：「將萬萬歸大衛，千千歸我，只剩下王位沒有給他了。」</span>
<span className="v" id="v9" data-v="9" data-xref="馬可福音 7:22; 創世記 31:2; 馬太福音 20:15"> 從這日起，掃羅就怒視大衛。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="撒母耳記上 19:9; 帖撒羅尼迦後書 2:11; 列王紀上 18:29"> 次日，從上帝那裏來的惡魔大大降在掃羅身上，他就在家中胡言亂語。大衛照常彈琴，掃羅手裏拿着槍。</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳記上 20:33; 以賽亞書 54:17; 路加福音 4:30"> 掃羅把槍一掄，心裏說，我要將大衛刺透，釘在牆上。大衛躲避他兩次。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="撒母耳記上 18:15; 撒母耳記上 18:29; 撒母耳記上 16:13–14"> 掃羅懼怕大衛；因為耶和華離開自己，與大衛同在。</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳記下 5:2; 詩篇 121:8; 撒母耳記上 18:16–17"> 所以掃羅使大衛離開自己，立他為千夫長，他就領兵出入。</span>
<span className="v" id="v14" data-v="14" data-xref="創世記 39:23; 馬太福音 28:20; 撒母耳記上 16:18"> 大衛做事無不精明，耶和華也與他同在。</span>
<span className="v" id="v15" data-v="15" data-xref="雅各書 3:17; 歌羅西書 4:5; 雅各書 1:5"> 掃羅見大衛做事精明，就甚怕他。</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳記上 18:5; 民數記 27:17; 列王紀上 3:7"> 但以色列和猶大眾人都愛大衛，因為他領他們出入。</span>
</div>
</div>

## 大衛娶掃羅的女兒

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="撒母耳記上 17:25; 撒母耳記上 25:28; 撒母耳記上 18:25"> 掃羅對大衛說：「我將大女兒米拉給你為妻，只要你為我奮勇，為耶和華爭戰。」掃羅心裏說：「我不好親手害他，要藉非利士人的手害他。」</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳記下 7:18; 撒母耳記上 9:21; 撒母耳記上 18:23"> 大衛對掃羅說：「我是誰，我是甚麼出身，我父家在以色列中是何等的家，豈敢作王的女婿呢？」</span>
<span className="v" id="v19" data-v="19" data-xref="士師記 7:22; 撒母耳記下 21:8; 士師記 14:20"> 掃羅的女兒米拉到了當給大衛的時候，掃羅卻給了米何拉人亞得列為妻。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="撒母耳記上 18:28"> 掃羅的次女米甲愛大衛。有人告訴掃羅，掃羅就喜悅。</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳記上 18:17; 出埃及記 10:7; 耶利米書 9:8"> 掃羅心裏說：「我將這女兒給大衛，作他的網羅，好藉非利士人的手害他。」所以掃羅對大衛說：「你今日可以第二次作我的女婿。」</span>
<span className="v" id="v22" data-v="22" data-xref="詩篇 36:1–3; 詩篇 55:21; 撒母耳記下 13:28–29"> 掃羅吩咐臣僕說：「你們暗中對大衛說：『王喜悅你，王的臣僕也都喜愛你，所以你當作王的女婿。』」</span>
<span className="v" id="v23" data-v="23" data-xref="詩篇 119:141; 箴言 14:20; 傳道書 9:15–16"> 掃羅的臣僕就照這話說給大衛聽。大衛說：「你們以為作王的女婿是一件小事嗎？我是貧窮卑微的人。」</span>
<span className="v" id="v24" data-v="24"> 掃羅的臣僕回奏說，大衛所說的如此如此。</span>
<span className="v" id="v25" data-v="25" data-xref="創世記 34:12; 撒母耳記上 18:17; 撒母耳記上 14:24"> 掃羅說：「你們要對大衛這樣說：『王不要甚麼聘禮，只要一百非利士人的陽皮，好在王的仇敵身上報仇。』」掃羅的意思要使大衛喪在非利士人的手裏。</span>
<span className="v" id="v26" data-v="26" data-xref="撒母耳記上 18:21"> 掃羅的臣僕將這話告訴大衛，大衛就歡喜作王的女婿。日期還沒有到，</span>
<span className="v" id="v27" data-v="27" data-xref="撒母耳記下 3:14; 士師記 14:19; 撒母耳記上 18:13"> 大衛和跟隨他的人起身前往，殺了二百非利士人，將陽皮滿數交給王，為要作王的女婿。於是掃羅將女兒米甲給大衛為妻。</span>
<span className="v" id="v28" data-v="28" data-xref="撒母耳記上 24:20; 撒母耳記上 26:25; 創世記 37:8–11"> 掃羅見耶和華與大衛同在，又知道女兒米甲愛大衛，</span>
<span className="v" id="v29" data-v="29" data-xref="傳道書 4:4; 約翰福音 11:53; 雅各書 2:19"> 就更怕大衛，常作大衛的仇敵。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="撒母耳記上 18:5; 撒母耳記下 11:1; 彼得前書 2:4"> 每逢非利士軍長出來打仗，大衛比掃羅的臣僕做事精明，因此他的名被人尊重。</span>
</div>
</div>

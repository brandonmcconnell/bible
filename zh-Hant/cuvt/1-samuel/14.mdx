## 約拿單的勇敢戰績

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士師記 6:27; 彌迦書 7:5; 撒母耳記下 1:25–26"> 有一日，掃羅的兒子約拿單對拿他兵器的少年人說：「我們不如過到那邊，到非利士人的防營那裏去。」但他沒有告訴父親。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳記上 13:15–16; 以賽亞書 10:28–29"> 掃羅在基比亞的儘邊，坐在米磯崙的石榴樹下，跟隨他的約有六百人。</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳記上 22:20; 撒母耳記上 2:28; 撒母耳記上 4:21"> 在那裏有亞希突的兒子亞希亞，穿着以弗得。（亞希突是以迦博的哥哥，非尼哈的兒子，以利的孫子。以利從前在示羅作耶和華的祭司。）約拿單去了，百姓卻不知道。</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳記上 13:23"> 約拿單要從隘口過到非利士防營那裏去。這隘口兩邊各有一個山峰：一名播薛，一名西尼；</span>
<span className="v" id="v5" data-v="5"> 一峰向北，與密抹相對，一峰向南，與迦巴相對。</span>
<span className="v" id="v6" data-v="6" data-xref="馬太福音 19:26; 羅馬書 8:31; 撒迦利亞書 4:6"> 約拿單對拿兵器的少年人說：「我們不如過到未受割禮人的防營那裏去，或者耶和華為我們施展能力；因為耶和華使人得勝，不在乎人多人少。」</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳記下 7:3; 撒迦利亞書 8:23; 撒母耳記上 10:7"> 拿兵器的對他說：「隨你的心意行吧。你可以上去，我必跟隨你，與你同心。」</span>
<span className="v" id="v8" data-v="8" data-xref="士師記 7:9–14"> 約拿單說：「我們要過到那些人那裏去，使他們看見我們。</span>
<span className="v" id="v9" data-v="9" data-xref="士師記 6:36–40; 創世記 24:13–14"> 他們若對我們說：『你們站住，等我們到你們那裏去』，我們就站住，不上他們那裏去。</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 24:14; 撒母耳記上 10:7; 士師記 7:11"> 他們若說：『你們上到我們這裏來』，這話就是我們的證據；我們便上去，因為耶和華將他們交在我們手裏了。」</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳記上 13:6; 撒母耳記上 14:22; 士師記 6:2"> 二人就使非利士的防兵看見。非利士人說：「希伯來人從所藏的洞穴裏出來了！」</span>
<span className="v" id="v12" data-v="12" data-xref="撒母耳記上 17:43–44; 撒母耳記下 5:24; 士師記 7:15"> 防兵對約拿單和拿兵器的人說：「你們上到這裏來，我們有一件事指示你們。」約拿單就對拿兵器的人說：「你跟隨我上去，因為耶和華將他們交在以色列人手裏了。」</span>
<span className="v" id="v13" data-v="13" data-xref="羅馬書 8:31; 約書亞記 23:10; 利未記 26:7–8"> 約拿單就爬上去，拿兵器的人跟隨他。約拿單殺倒非利士人，拿兵器的人也隨着殺他們。</span>
<span className="v" id="v14" data-v="14"> 約拿單和拿兵器的人起頭所殺的約有二十人，都在一畝地的半犂溝之內。</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳記上 13:17; 創世記 35:5; 撒母耳記下 5:24"> 於是在營中、在田野、在眾民內都有戰兢，防兵和掠兵也都戰兢，地也震動，戰兢之勢甚大。</span>
</div>
</div>

## 非利士人敗退

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="歷代志下 20:22–25; 以賽亞書 19:2; 士師記 7:22"> 在便雅憫的基比亞，掃羅的守望兵看見非利士的軍眾潰散，四圍亂竄。</span>
<span className="v" id="v17" data-v="17"> 掃羅就對跟隨他的民說：「你們查點查點，看從我們這裏出去的是誰？」他們一查點，就知道約拿單和拿兵器的人沒有在這裏。</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳記上 30:7–8; 撒母耳記上 5:2; 士師記 20:23"> 那時上帝的約櫃在以色列人那裏。掃羅對亞希亞說：「你將上帝的約櫃運了來。」</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳記上 14:24; 民數記 27:21; 約書亞記 9:14"> 掃羅正與祭司說話的時候，非利士營中的喧嚷越發大了；掃羅就對祭司說：「停手吧！」</span>
<span className="v" id="v20" data-v="20" data-xref="士師記 7:22; 歷代志下 20:23; 撒母耳記上 14:16"> 掃羅和跟隨他的人都聚集，來到戰場，看見非利士人用刀互相擊殺，大大惶亂。</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳記上 29:4; 士師記 7:23"> 從前由四方來跟隨非利士軍的希伯來人現在也轉過來，幫助跟隨掃羅和約拿單的以色列人了。</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳記上 13:6; 撒母耳記上 31:7"> 那藏在以法蓮山地的以色列人聽說非利士人逃跑，就出來緊緊地追殺他們。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及記 14:30; 撒母耳記上 13:5; 詩篇 44:6–8"> 那日，耶和華使以色列人得勝，一直戰到伯‧亞文。</span>
</div>
</div>

## 戰後發生的事件

<div className="bt">
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="約書亞記 6:26; 羅馬書 10:2; 士師記 1:28"> 掃羅叫百姓起誓說，凡不等到晚上向敵人報完了仇吃甚麼的，必受咒詛。因此這日百姓沒有吃甚麼，就極其困憊。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及記 3:8; 民數記 13:27; 申命記 9:28"> 眾民進入樹林，見有蜜在地上。</span>
<span className="v" id="v26" data-v="26" data-xref="傳道書 9:2"> 他們進了樹林，見有蜜流下來，卻沒有人敢用手取蜜入口，因為他們怕那誓言。</span>
<span className="v" id="v27" data-v="27" data-xref="撒母耳記上 14:29; 撒母耳記上 14:43; 撒母耳記上 30:12"> 約拿單沒有聽見他父親叫百姓起誓，所以伸手中的杖，用杖頭蘸在蜂房裏，轉手送入口內，眼睛就明亮了。</span>
<span className="v" id="v28" data-v="28" data-xref="撒母耳記上 14:43; 撒母耳記上 14:24"> 百姓中有一人對他說：「你父親曾叫百姓嚴嚴地起誓說，今日吃甚麼的，必受咒詛；因此百姓就疲乏了。」</span>
<span className="v" id="v29" data-v="29" data-xref="列王紀上 18:18; 約書亞記 7:25"> 約拿單說：「我父親連累你們了。你看，我嘗了這一點蜜，眼睛就明亮了。</span>
<span className="v" id="v30" data-v="30" data-xref="傳道書 9:18"> 今日百姓若任意吃了從仇敵所奪的物，擊殺的非利士人豈不更多嗎？」</span>
<span className="v" id="v31" data-v="31" data-xref="約書亞記 10:12; 約書亞記 19:42"> 這日，以色列人擊殺非利士人，從密抹直到亞雅崙。百姓甚是疲乏，</span>
<span className="v" id="v32" data-v="32" data-xref="撒母耳記上 15:19; 利未記 3:17; 利未記 17:10–14"> 就急忙將所奪的牛羊和牛犢宰於地上，肉還帶血就吃了。</span>
<span className="v" id="v33" data-v="33" data-xref="羅馬書 2:1; 馬太福音 7:5"> 有人告訴掃羅說：「百姓吃帶血的肉，得罪耶和華了。」掃羅說：「你們有罪了，今日要將大石頭滾到我這裏來。」</span>
<span className="v" id="v34" data-v="34"> 掃羅又說：「你們散在百姓中，對他們說，你們各人將牛羊牽到我這裏來宰了吃，不可吃帶血的肉得罪耶和華。」這夜，百姓就把牛羊牽到那裏宰了。</span>
<span className="v" id="v35" data-v="35" data-xref="撒母耳記上 7:17; 撒母耳記上 7:12; 提摩太後書 3:5"> 掃羅為耶和華築了一座壇，這是他初次為耶和華築的壇。</span>
<span className="v" id="v36" data-v="36" data-xref="以賽亞書 48:1–2; 詩篇 73:28; 瑪拉基書 2:7"> 掃羅說：「我們不如夜裏下去追趕非利士人，搶掠他們，直到天亮，不留他們一人。」眾民說：「你看怎樣好就去行吧！」祭司說：「我們先當親近上帝。」</span>
<span className="v" id="v37" data-v="37" data-xref="撒母耳記上 28:6; 撒母耳記上 30:7–8; 撒母耳記上 23:9–12"> 掃羅求問上帝說：「我下去追趕非利士人可以不可以？你將他們交在以色列人手裏不交？」這日上帝沒有回答他。</span>
<span className="v" id="v38" data-v="38" data-xref="士師記 20:2; 約書亞記 7:14–26; 民數記 24:17"> 掃羅說：「你們百姓中的長老都上這裏來，查明今日是誰犯了罪。</span>
<span className="v" id="v39" data-v="39" data-xref="撒母耳記上 14:44; 撒母耳記下 12:5; 撒母耳記上 14:24"> 我指着救以色列－永生的耶和華起誓，就是我兒子約拿單犯了罪，他也必死。」但百姓中無一人回答他。</span>
<span className="v" id="v40" data-v="40" data-xref="撒母耳記下 15:15; 撒母耳記上 14:7; 撒母耳記上 14:36"> 掃羅就對以色列眾人說：「你們站在一邊，我與我兒子約拿單也站在一邊。」百姓對掃羅說：「你看怎樣好就去行吧！」</span>
<span className="v" id="v41" data-v="41" data-xref="使徒行傳 1:24; 約書亞記 7:16–18; 撒母耳記上 10:20–21"> 掃羅禱告耶和華－以色列的上帝說：「求你指示實情。」於是掣籤掣出掃羅和約拿單來；百姓盡都無事。</span>
<span className="v" id="v42" data-v="42"> 掃羅說：「你們再掣籤，看是我，是我兒子約拿單」，就掣出約拿單來。</span>
<span className="v" id="v43" data-v="43" data-xref="約書亞記 7:19; 撒母耳記上 14:27; 約拿書 1:7–10"> 掃羅對約拿單說：「你告訴我，你做了甚麼事？」約拿單說：「我實在以手裏的杖，用杖頭蘸了一點蜜嘗了一嘗。這樣我就死嗎<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或譯：吧！">a</a></sup>？」</span>
<span className="v" id="v44" data-v="44" data-xref="撒母耳記上 14:39; 路得記 1:17; 撒母耳記上 25:22"> 掃羅說：「約拿單哪，你定要死！若不然，願上帝重重地降罰與我。」</span>
<span className="v" id="v45" data-v="45" data-xref="路加福音 21:18; 使徒行傳 27:34; 撒母耳記下 14:11"> 百姓對掃羅說：「約拿單在以色列人中這樣大行拯救，豈可使他死呢？斷乎不可！我們指着永生的耶和華起誓，連他的一根頭髮也不可落地，因為他今日與上帝一同做事。」於是百姓救約拿單免了死亡。</span>
<span className="v" id="v46" data-v="46"> 掃羅回去，不追趕非利士人；非利士人也回本地去了。</span>
</div>

## 掃羅的王權和家眷

<div className="bt">
<div className="bp">
<span className="v" id="v47" data-v="47" data-xref="撒母耳記下 10:6; 撒母耳記上 14:52; 撒母耳記下 8:3"> 掃羅執掌以色列的國權，常常攻擊他四圍的一切仇敵，就是摩押人、亞捫人、以東人，和瑣巴諸王，並非利士人。他無論往何處去，都打敗仇敵。</span>
<span className="v" id="v48" data-v="48" data-xref="出埃及記 17:14; 撒母耳記上 15:3–7; 申命記 25:19"> 掃羅奮勇攻擊亞瑪力人，救了以色列人脫離搶掠他們之人的手。</span>
<span className="v" id="v49" data-v="49" data-xref="歷代志上 8:33; 撒母耳記上 31:2; 撒母耳記下 6:20–23"> 掃羅的兒子是約拿單、亦施韋、麥基舒亞。他的兩個女兒：長女名米拉，次女名米甲。</span>
<span className="v" id="v50" data-v="50" data-xref="撒母耳記下 2:8; 撒母耳記上 17:55; 撒母耳記下 3:27"> 掃羅的妻名叫亞希暖，是亞希瑪斯的女兒。掃羅的元帥名叫押尼珥，是尼珥的兒子；尼珥是掃羅的叔叔。</span>
<span className="v" id="v51" data-v="51" data-xref="撒母耳記上 9:1; 撒母耳記上 9:21"> 掃羅的父親基士，押尼珥的父親尼珥，都是亞別的兒子。</span>
<span className="v" id="v52" data-v="52" data-xref="撒母耳記上 8:11; 撒母耳記上 8:1"> 掃羅平生常與非利士人大大爭戰。掃羅遇見有能力的人或勇士，都招募了來跟隨他。</span>

## 撒母耳去世

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳記上 28:3; 民數記 20:29; 申命記 34:8"> 撒母耳死了，以色列眾人聚集，為他哀哭，將他葬在拉瑪－他自己的墳墓<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是房屋">a</a></sup>裏。 大衛和亞比該 大衛起身，下到巴蘭的曠野。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 38:13; 撒母耳記上 23:24; 約書亞記 15:55"> 在瑪雲有一個人，他的產業在迦密，是一個大富戶，有三千綿羊，一千山羊；他正在迦密剪羊毛。</span>
<span className="v" id="v3" data-v="3" data-xref="箴言 14:1; 箴言 31:10; 以賽亞書 32:5–7"> 那人名叫拿八，是迦勒族的人；他的妻名叫亞比該，是聰明俊美的婦人。拿八為人剛愎凶惡。</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 38:13; 撒母耳記下 13:23"> 大衛在曠野聽見說拿八剪羊毛，</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 43:23; 撒母耳記上 17:22"> 大衛就打發十個僕人，吩咐他們說：「你們上迦密去見拿八，提我的名問他安。</span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 10:5; 歷代志上 12:18; 詩篇 122:7"> 要對那富戶如此說：『願你平安，願你家平安，願你一切所有的都平安。</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳記上 25:21; 撒母耳記上 25:15–16; 撒母耳記上 22:2"> 現在我聽說有人為你剪羊毛，你的牧人在迦密的時候和我們在一處，我們沒有欺負他們，他們也未曾失落甚麼。</span>
<span className="v" id="v8" data-v="8" data-xref="以斯帖記 9:19; 尼希米記 8:10–12; 路加福音 14:12–14"> 可以問你的僕人，他們必告訴你。所以願我的僕人在你眼前蒙恩，因為是在好日子來的。求你隨手取點賜與僕人和你兒子大衛。』」</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀下 2:15; 歷代志下 14:7; 創世記 8:4"> 大衛的僕人到了，將這話提大衛的名都告訴了拿八，就住了口。</span>
<span className="v" id="v10" data-v="10" data-xref="士師記 9:28; 以賽亞書 32:7; 撒母耳記上 22:7–8"> 拿八回答大衛的僕人說：「大衛是誰？耶西的兒子是誰？近來悖逆主人奔逃的僕人甚多，</span>
<span className="v" id="v11" data-v="11" data-xref="士師記 8:6; 加拉太書 6:10; 哥林多後書 6:9"> 我豈可將飲食和為我剪羊毛人所宰的肉給我不知道從哪裏來的人呢？」</span>
<span className="v" id="v12" data-v="12" data-xref="以賽亞書 36:21–22; 撒母耳記下 24:13; 希伯來書 13:17"> 大衛的僕人就轉身從原路回去，照這話告訴大衛。</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳記上 23:13; 箴言 25:8; 撒母耳記上 24:5–6"> 大衛向跟隨他的人說：「你們各人都要帶上刀！」眾人就都帶上刀，大衛也帶上刀。跟隨大衛上去的約有四百人，留下二百人看守器具。</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳記上 13:10; 馬可福音 15:29"> 有拿八的一個僕人告訴拿八的妻亞比該說：「大衛從曠野打發使者來問我主人的安，主人卻辱罵他們。</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳記上 25:7; 撒母耳記上 25:21; 腓立比書 2:15"> 但是那些人待我們甚好；我們在田野與他們來往的時候，沒有受他們的欺負，也未曾失落甚麼。</span>
<span className="v" id="v16" data-v="16" data-xref="約伯記 1:10; 出埃及記 14:22; 撒迦利亞書 2:5"> 我們在他們那裏牧羊的時候，他們晝夜作我們的保障。</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳記上 20:7; 申命記 13:13; 撒母耳記上 20:9"> 所以你當籌劃，看怎樣行才好；不然，禍患定要臨到我主人和他全家。他性情凶暴，無人敢與他說話。」</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳記下 16:1; 馬太福音 5:25; 箴言 6:4–5"> 亞比該急忙將二百餅，兩皮袋酒，五隻收拾好了的羊，五細亞烘好了的穗子，一百葡萄餅，二百無花果餅，都馱在驢上，</span>
<span className="v" id="v19" data-v="19" data-xref="創世記 32:20; 創世記 32:16; 箴言 31:11–12"> 對僕人說：「你們前頭走，我隨着你們去。」這事她卻沒有告訴丈夫拿八。</span>
<span className="v" id="v20" data-v="20" data-xref="列王紀下 4:24"> 亞比該騎着驢，正下山坡，見大衛和跟隨他的人從對面下來，亞比該就迎接他們。</span>
<span className="v" id="v21" data-v="21" data-xref="箴言 17:13; 以弗所書 4:31; 羅馬書 12:21"> 大衛曾說：「我在曠野為那人看守所有的，以致他一樣不失落，實在是徒然了！他向我以惡報善。</span>
<span className="v" id="v22" data-v="22" data-xref="列王紀上 14:10; 撒母耳記上 20:13; 撒母耳記上 3:17"> 凡屬拿八的男丁，我若留一個到明日早晨，願上帝重重降罰與我！」</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳記上 20:41; 士師記 1:14; 約書亞記 15:18"> 亞比該見大衛，便急忙下驢，在大衛面前臉伏於地叩拜，</span>
<span className="v" id="v24" data-v="24" data-xref="以斯帖記 8:3; 撒母耳記上 25:28; 撒母耳記下 14:9"> 俯伏在大衛的腳前，說：「我主啊，願這罪歸我！求你容婢女向你進言，更求你聽婢女的話。</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳記上 25:17; 瑪拉基書 2:2; 撒母耳記下 13:33"> 我主不要理這壞人拿八，他的性情與他的名相稱；他名叫拿八<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="就是愚頑的意思">b</a></sup>，他為人果然愚頑。但我主所打發的僕人，婢女並沒有看見。</span>
<span className="v" id="v26" data-v="26" data-xref="撒母耳記下 18:32; 羅馬書 12:19–20; 創世記 20:6"> 我主啊，耶和華既然阻止你親手報仇，取流血的罪，所以我指着永生的耶和華、又敢在你面前起誓說：『願你的仇敵和謀害你的人都像拿八一樣。』</span>
<span className="v" id="v27" data-v="27" data-xref="創世記 33:11; 撒母耳記上 30:26; 列王紀下 5:15"> 如今求你將婢女送來的禮物給跟隨你的僕人。</span>
<span className="v" id="v28" data-v="28" data-xref="撒母耳記上 18:17; 撒母耳記下 7:11; 撒母耳記上 24:11"> 求你饒恕婢女的罪過。耶和華必為我主建立堅固的家，因我主為耶和華爭戰；並且在你平生的日子查不出有甚麼過來。</span>
<span className="v" id="v29" data-v="29" data-xref="約翰福音 17:21; 馬太福音 10:29–30; 瑪拉基書 3:17"> 雖有人起來追逼你，尋索你的性命，你的性命卻在耶和華－你的上帝那裏蒙保護，如包裹寶器一樣；你仇敵的性命，耶和華必拋去，如用機弦甩石一樣。</span>
<span className="v" id="v30" data-v="30" data-xref="撒母耳記上 13:14; 詩篇 89:20; 撒母耳記上 23:17"> 我主現在若不親手報仇流無辜人的血，到了耶和華照所應許你的話賜福與你，立你作以色列的王，那時我主必不致心裏不安，覺得良心有虧。耶和華賜福與我主的時候，求你記念婢女。」</span>
<span className="v" id="v32" data-v="32" data-xref="路加福音 1:68; 出埃及記 18:10; 詩篇 72:18"> 大衛對亞比該說：「耶和華－以色列的上帝是應當稱頌的，因為他今日使你來迎接我。</span>
<span className="v" id="v33" data-v="33" data-xref="撒母耳記上 25:26; 箴言 28:23; 箴言 9:9"> 你和你的見識也當稱讚；因為你今日攔阻我親手報仇、流人的血。</span>
<span className="v" id="v34" data-v="34" data-xref="撒母耳記上 11:11; 撒母耳記上 25:26; 約書亞記 10:6"> 我指着阻止我加害於你的耶和華－以色列永生的上帝起誓，你若不速速地來迎接我，到明日早晨，凡屬拿八的男丁必定不留一個。」</span>
<span className="v" id="v35" data-v="35" data-xref="創世記 19:21; 撒母耳記上 20:42; 列王紀下 5:19"> 大衛受了亞比該送來的禮物，就對她說：「我聽了你的話，准了你的情面，你可以平平安安地回家吧！」</span>
<span className="v" id="v36" data-v="36" data-xref="撒母耳記上 25:19; 撒母耳記下 13:23; 撒母耳記下 13:28"> 亞比該到拿八那裏，見他在家裏設擺筵席，如同王的筵席；拿八快樂大醉。亞比該無論大小事都沒有告訴他，就等到次日早晨。</span>
<span className="v" id="v37" data-v="37" data-xref="申命記 28:28; 撒母耳記上 25:34; 撒母耳記上 25:22"> 到了早晨，拿八醒了酒，他的妻將這些事都告訴他，他就魂不附體，身僵如石頭一般。</span>
<span className="v" id="v38" data-v="38" data-xref="撒母耳記上 26:10; 列王紀下 15:5; 撒母耳記上 6:9"> 過了十天，耶和華擊打拿八，他就死了。</span>
<span className="v" id="v39" data-v="39" data-xref="撒母耳記上 25:26; 撒母耳記上 25:34; 箴言 22:23"> 大衛聽見拿八死了，就說：「應當稱頌耶和華，因他伸了拿八羞辱我的冤，又阻止僕人行惡；也使拿八的惡歸到拿八的頭上。」於是大衛打發人去，與亞比該說，要娶她為妻。</span>
<span className="v" id="v40" data-v="40" data-xref="創世記 24:51; 創世記 24:37–38"> 大衛的僕人到了迦密見亞比該，對她說：「大衛打發我們來見你，想要娶你為妻。」</span>
<span className="v" id="v41" data-v="41" data-xref="提摩太前書 5:10; 約翰福音 13:3–5; 路得記 2:10"> 亞比該就起來，俯伏在地，說：「我情願作婢女，洗我主僕人的腳。」</span>
<span className="v" id="v42" data-v="42" data-xref="創世記 24:61–67; 詩篇 45:10–11"> 亞比該立刻起身，騎上驢，帶着五個使女，跟從大衛的使者去了，就作了大衛的妻。</span>
<span className="v" id="v43" data-v="43" data-xref="撒母耳記上 30:5; 約書亞記 15:56; 撒母耳記上 27:3"> 大衛先娶了耶斯列人亞希暖，她們二人都作了他的妻。</span>
<span className="v" id="v44" data-v="44" data-xref="撒母耳記下 3:14; 撒母耳記上 18:27; 撒母耳記上 18:20"> 掃羅已將他的女兒米甲，就是大衛的妻，給了迦琳人拉億的兒子帕提為妻。</span>

## 與非利士人爭戰

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及記 12:5; 彌迦書 6:6"> 掃羅登基年四十歲；作以色列王二年的時候，</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳記上 10:26; 撒母耳記上 13:5; 撒母耳記上 14:31"> 就從以色列中揀選了三千人：二千跟隨掃羅在密抹和伯特利山，一千跟隨約拿單在便雅憫的基比亞；其餘的人掃羅都打發各回各家去了。</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳記上 10:5; 士師記 3:27; 士師記 6:34"> 約拿單攻擊在迦巴的非利士人的防營，非利士人聽見了。掃羅就在遍地吹角，意思說，要使希伯來人聽見。</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 34:30; 出埃及記 5:21; 撒迦利亞書 11:8"> 以色列眾人聽見掃羅攻擊非利士人的防營，又聽見以色列人為非利士人所憎惡，就跟隨掃羅聚集在吉甲。</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳記上 14:23; 約書亞記 11:4; 約書亞記 18:12"> 非利士人聚集，要與以色列人爭戰，有車三萬輛，馬兵六千，步兵像海邊的沙那樣多，就上來在伯‧亞文東邊的密抹安營。</span>
<span className="v" id="v6" data-v="6" data-xref="士師記 6:2; 希伯來書 11:38; 士師記 10:9"> 以色列百姓見自己危急窘迫，就藏在山洞、叢林、石穴、隱密處，和坑中。</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 20:8; 利未記 26:17; 民數記 32:1–5"> 有些希伯來人過了約旦河，逃到迦得和基列地。掃羅還是在吉甲，百姓都戰戰兢兢地跟隨他。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳記上 10:8"> 掃羅照着撒母耳所定的日期等了七日。撒母耳還沒有來到吉甲，百姓也離開掃羅散去了。</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀上 3:4; 箴言 21:27; 箴言 15:8"> 掃羅說：「把燔祭和平安祭帶到我這裏來。」掃羅就獻上燔祭。</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳記上 15:13; 路得記 2:4; 詩篇 129:8"> 剛獻完燔祭，撒母耳就到了。掃羅出去迎接他，要問他好。</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳記上 13:23; 撒母耳記上 13:5; 撒母耳記上 13:16"> 撒母耳說：「你做的是甚麼事呢？」掃羅說：「因為我見百姓離開我散去，你也不照所定的日期來到，而且非利士人聚集在密抹。</span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 66:3; 阿摩司書 8:5; 哥林多後書 9:7"> 所以我心裏說：恐怕我沒有禱告耶和華。非利士人下到吉甲攻擊我，我就勉強獻上燔祭。」</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳記上 15:22; 歷代志下 16:9; 撒母耳記上 15:28"> 撒母耳對掃羅說：「你做了糊塗事了，沒有遵守耶和華－你上帝所吩咐你的命令。若遵守，耶和華必在以色列中堅立你的王位，直到永遠。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行傳 13:22; 撒母耳記上 15:28; 詩篇 89:19–37"> 現在你的王位必不長久。耶和華已經尋着一個合他心意的人，立他作百姓的君，因為你沒有遵守耶和華所吩咐你的。」</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳記上 14:2; 撒母耳記上 13:2; 撒母耳記上 13:6–7"> 撒母耳就起來，從吉甲上到便雅憫的基比亞。 掃羅數點跟隨他的，約有六百人。</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳記上 13:3"> 掃羅和他兒子約拿單，並跟隨他們的人，都住在便雅憫的迦巴；但非利士人安營在密抹。</span>
<span className="v" id="v17" data-v="17" data-xref="約書亞記 18:23; 撒母耳記上 14:15; 約書亞記 19:3"> 有掠兵從非利士營中出來，分為三隊：一隊往俄弗拉向書亞地去，</span>
<span className="v" id="v18" data-v="18" data-xref="尼希米記 11:34; 約書亞記 18:13–14; 約書亞記 16:3"> 一隊往伯‧和崙去，一隊往洗波音谷對面的地境向曠野去。</span>
<span className="v" id="v19" data-v="19" data-xref="列王紀下 24:14; 士師記 5:8; 耶利米書 24:1"> 那時，以色列全地沒有一個鐵匠；因為非利士人說，恐怕希伯來人製造刀槍。</span>
<span className="v" id="v20" data-v="20"> 以色列人要磨鋤、犂、斧、鏟，就下到非利士人那裏去磨。</span>
<span className="v" id="v21" data-v="21"> 但有銼可以銼鏟、犂、三齒叉、斧子，並趕牛錐。</span>
<span className="v" id="v22" data-v="22" data-xref="士師記 5:8; 撒迦利亞書 4:6; 撒母耳記上 17:50"> 所以到了爭戰的日子，跟隨掃羅和約拿單的人沒有一個手裏有刀有槍的，惟獨掃羅和他兒子約拿單有。</span>
<span className="v" id="v23" data-v="23" data-xref="以賽亞書 10:28; 撒母耳記上 14:1; 撒母耳記上 14:4–5"> 非利士人的一隊防兵到了密抹的隘口。</span>

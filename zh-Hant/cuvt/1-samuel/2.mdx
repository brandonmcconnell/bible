## 哈拿的禱告

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="路加福音 1:46–56; 詩篇 13:5; 以賽亞書 12:2–3"> 哈拿禱告說：<br /><span className="pl pl-1">我的心因耶和華快樂；</span><br /><span className="pl pl-1">我的角因耶和華高舉。</span><br /><span className="pl pl-1">我的口向仇敵張開；</span><br /><span className="pl pl-1">我因耶和華的救恩歡欣。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v2" data-v="2" data-xref="撒母耳記下 22:32; 以賽亞書 44:6; 詩篇 86:8"> <span className="pl pl-1">只有耶和華為聖；</span><br /><span className="pl pl-1">除他以外沒有可比的，</span><br /><span className="pl pl-1">也沒有磐石像我們的上帝。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="箴言 8:13; 列王紀上 8:39; 箴言 24:12"> <span className="pl pl-1">人不要誇口說驕傲的話，</span><br /><span className="pl pl-1">也不要出狂妄的言語；</span><br /><span className="pl pl-1">因耶和華是大有智識的上帝，</span><br /><span className="pl pl-1">人的行為被他衡量。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="詩篇 76:3; 詩篇 37:15; 詩篇 46:9"> <span className="pl pl-1">勇士的弓都已折斷；</span><br /><span className="pl pl-1">跌倒的人以力量束腰。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="耶利米書 15:9; 路加福音 1:53; 詩篇 113:9"> <span className="pl pl-1">素來飽足的，反作用人求食；</span><br /><span className="pl pl-1">飢餓的，再不飢餓。</span><br /><span className="pl pl-1">不生育的，生了七個兒子；</span><br /><span className="pl pl-1">多有兒女的，反倒衰微。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="申命記 32:39; 以賽亞書 26:19; 啟示錄 1:18"> <span className="pl pl-1">耶和華使人死，也使人活，</span><br /><span className="pl pl-1">使人下陰間，也使人往上升。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 75:7; 約伯記 5:11; 申命記 8:17–18"> <span className="pl pl-1">他使人貧窮，也使人富足，</span><br /><span className="pl pl-1">使人卑微，也使人高貴。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 113:7–8; 但以理書 2:48; 雅各書 2:5"> <span className="pl pl-1">他從灰塵裏抬舉貧寒人，</span><br /><span className="pl pl-1">從糞堆中提拔窮乏人，</span><br /><span className="pl pl-1">使他們與王子同坐，</span><br /><span className="pl pl-1">得着榮耀的座位。</span><br /><span className="pl pl-1">地的柱子屬於耶和華；</span><br /><span className="pl pl-1">他將世界立在其上。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="詩篇 121:3; 詩篇 91:11–12; 詩篇 33:16–17"> <span className="pl pl-1">他必保護聖民的腳步，</span><br /><span className="pl pl-1">使惡人在黑暗中寂然不動；</span><br /><span className="pl pl-1">人都不能靠力量得勝。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 2:9; 詩篇 89:24; 詩篇 18:13–14"> <span className="pl pl-1">與耶和華爭競的，必被打碎；</span><br /><span className="pl pl-1">耶和華必從天上以雷攻擊他，</span><br /><span className="pl pl-1">必審判地極的人，</span><br /><span className="pl pl-1">將力量賜與所立的王，</span><br /><span className="pl pl-1">高舉受膏者的角。</span></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="撒母耳記上 3:1; 撒母耳記上 2:18; 撒母耳記上 1:28"> 以利加拿往拉瑪回家去了。那孩子在祭司以利面前事奉耶和華。</span>
</div>
</div>

## 以利的兩個兒子

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="羅馬書 1:28–30; 耶利米書 2:8; 士師記 2:10"> 以利的兩個兒子是惡人，不認識耶和華。</span>
<span className="v" id="v13" data-v="13" data-xref="利未記 7:29–34"> 這二祭司待百姓是這樣的規矩：凡有人獻祭，正煮肉的時候，祭司的僕人就來，手拿三齒的叉子，</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及記 29:27–28; 以賽亞書 56:11; 撒母耳記上 2:29"> 將叉子往罐裏，或鼎裏，或釜裏，或鍋裏一插，插上來的肉，祭司都取了去。凡上到示羅的以色列人，他們都是這樣看待。</span>
<span className="v" id="v15" data-v="15" data-xref="利未記 3:16; 利未記 3:3–5; 羅馬書 16:18"> 又在未燒脂油以前，祭司的僕人就來對獻祭的人說：「將肉給祭司，叫他烤吧。他不要煮過的，要生的。」</span>
<span className="v" id="v16" data-v="16" data-xref="利未記 7:23–25; 利未記 3:16; 彼得前書 5:2–3"> 獻祭的人若說：「必須先燒脂油，然後你可以隨意取肉。」僕人就說：「你立時給我，不然我便搶去。」</span>
<span className="v" id="v17" data-v="17" data-xref="瑪拉基書 2:7–9; 創世記 13:13; 瑪拉基書 2:13"> 如此，這二少年人的罪在耶和華面前甚重了，因為他們藐視耶和華的祭物<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或譯：他們使人厭棄給耶和華獻祭">a</a></sup>。</span>
</div>
</div>

## 撒母耳在示羅

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="撒母耳記上 3:1; 出埃及記 28:4; 撒母耳記上 2:11"> 那時，撒母耳還是孩子，穿着細麻布的以弗得，侍立在耶和華面前。</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳記上 1:3; 撒母耳記上 1:21; 出埃及記 23:14"> 他母親每年為他做一件小外袍，同着丈夫上來獻年祭的時候帶來給他。</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳記上 1:27–28; 路加福音 2:34; 路得記 4:11"> 以利為以利加拿和他的妻祝福，說：「願耶和華由這婦人再賜你後裔，代替你從耶和華求來的孩子。」他們就回本鄉去了。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="路加福音 2:40; 撒母耳記上 3:19; 創世記 21:1"> 耶和華眷顧哈拿，她就懷孕生了三個兒子，兩個女兒。那孩子撒母耳在耶和華面前漸漸長大。</span>
</div>
</div>

## 以利和他的兒子

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="出埃及記 38:8; 撒母耳記上 2:13–17; 耶利米書 7:9–10"> 以利年甚老邁，聽見他兩個兒子待以色列眾人的事，又聽見他們與會幕門前伺候的婦人苟合，</span>
<span className="v" id="v23" data-v="23" data-xref="耶利米書 8:12; 腓立比書 3:19; 使徒行傳 9:4"> 他就對他們說：「你們為何行這樣的事呢？我從這眾百姓聽見你們的惡行。</span>
<span className="v" id="v24" data-v="24" data-xref="瑪拉基書 2:8; 提摩太前書 3:7; 使徒行傳 6:3"> 我兒啊，不可這樣！我聽見你們的風聲不好，你們使耶和華的百姓犯了罪。</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳記上 3:14; 約書亞記 11:20; 希伯來書 10:26"> 人若得罪人，有士師審判他；人若得罪耶和華，誰能為他祈求呢？」然而他們還是不聽父親的話，因為耶和華想要殺他們。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="路加福音 2:52; 路加福音 2:40; 使徒行傳 2:47"> 孩子撒母耳漸漸長大，耶和華與人越發喜愛他。</span>
</div>
</div>

## 預言以利家遭禍

<div className="bt">
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="申命記 33:1; 出埃及記 4:27; 出埃及記 4:14–16"> 有神人來見以利，對他說：「耶和華如此說：『你祖父在埃及法老家作奴僕的時候，我不是向他們顯現嗎？</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及記 28:1; 利未記 8:7–8; 民數記 18:19"> 在以色列眾支派中，我不是揀選人作我的祭司，使他燒香，在我壇上獻祭，在我面前穿以弗得，又將以色列人所獻的火祭都賜給你父家嗎？</span>
<span className="v" id="v29" data-v="29" data-xref="馬太福音 10:37; 申命記 32:15; 撒母耳記上 2:13–17"> 我所吩咐獻在我居所的祭物，你們為何踐踏？尊重你的兒子過於尊重我，將我民以色列所獻美好的祭物肥己呢？』</span>
<span className="v" id="v30" data-v="30" data-xref="約翰福音 12:26; 耶利米書 18:9–10; 箴言 3:9–10"> 因此，耶和華－以色列的上帝說：『我曾說，你和你父家必永遠行在我面前；現在我卻說，決不容你們這樣行。因為尊重我的，我必重看他；藐視我的，他必被輕視。</span>
<span className="v" id="v31" data-v="31" data-xref="撒母耳記上 22:17–20; 列王紀上 2:26–27; 詩篇 37:17"> 日子必到，我要折斷你的膀臂和你父家的膀臂，使你家中沒有一個老年人。</span>
<span className="v" id="v32" data-v="32" data-xref="撒迦利亞書 8:4; 撒母耳記上 4:11; 詩篇 78:59–64"> 在上帝使以色列人享福的時候，你必看見我居所的敗落。在你家中必永遠沒有一個老年人。</span>
<span className="v" id="v33" data-v="33" data-xref="列王紀上 2:26–27; 列王紀上 1:7; 撒母耳記上 22:21–23"> 我必不從我壇前滅盡你家中的人；那未滅的必使你眼目乾癟、心中憂傷。你家中所生的人都必死在中年。</span>
<span className="v" id="v34" data-v="34" data-xref="撒母耳記上 4:11; 列王紀上 13:3; 撒母耳記上 4:17"> 你的兩個兒子何弗尼、非尼哈所遭遇的事可作你的證據：他們二人必一日同死。</span>
<span className="v" id="v35" data-v="35" data-xref="撒母耳記下 7:27; 撒母耳記下 7:11; 列王紀上 11:38"> 我要為自己立一個忠心的祭司；他必照我的心意而行。我要為他建立堅固的家；他必永遠行在我的受膏者面前。</span>
<span className="v" id="v36" data-v="36" data-xref="列王紀上 2:27; 瑪拉基書 1:13; 以西結書 44:10–12"> 你家所剩下的人都必來叩拜他，求塊銀子，求個餅，說：求你賜我祭司的職分，好叫我得點餅吃。』」</span>
</div>
</div>

## 撒母耳統治以色列

<div className="bt">
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="路加福音 4:8; 申命記 13:4; 馬太福音 4:10"> 撒母耳對以色列全家說：「你們若一心歸順耶和華，就要把外邦的神和亞斯她錄從你們中間除掉，專心歸向耶和華，單單地事奉他。他必救你們脫離非利士人的手。」</span>
<span className="v" id="v4" data-v="4" data-xref="何西阿書 14:8; 何西阿書 14:3; 士師記 2:11"> 以色列人就除掉諸巴力和亞斯她錄，單單地事奉耶和華。</span>
<span className="v" id="v5" data-v="5" data-xref="士師記 20:1; 撒母耳記上 12:23; 約書亞記 15:38"> 撒母耳說：「要使以色列眾人聚集在米斯巴，我好為你們禱告耶和華。」</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳記下 14:14; 撒母耳記上 1:15; 士師記 10:10"> 他們就聚集在米斯巴，打水澆在耶和華面前，當日禁食，說：「我們得罪了耶和華。」於是撒母耳在米斯巴審判以色列人。</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳記上 17:11; 撒母耳記上 13:6; 出埃及記 14:10"> 非利士人聽見以色列人聚集在米斯巴，非利士的首領就上來要攻擊以色列人。以色列人聽見，就懼怕非利士人。</span>
<span className="v" id="v8" data-v="8" data-xref="以賽亞書 37:4; 雅各書 5:16; 撒母耳記上 12:19–24"> 以色列人對撒母耳說：「願你不住地為我們呼求耶和華－我們的上帝，救我們脫離非利士人的手。」</span>
<span className="v" id="v9" data-v="9" data-xref="耶利米書 15:1; 詩篇 99:6; 撒母耳記上 7:17"> 撒母耳就把一隻吃奶的羊羔獻與耶和華作全牲的燔祭，為以色列人呼求耶和華；耶和華就應允他。</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳記上 2:10; 撒母耳記下 22:14–15; 約書亞記 10:10"> 撒母耳正獻燔祭的時候，非利士人前來要與以色列人爭戰。當日，耶和華大發雷聲，驚亂非利士人，他們就敗在以色列人面前。</span>
<span className="v" id="v11" data-v="11"> 以色列人從米斯巴出來，追趕非利士人，擊殺他們，直到伯‧甲的下邊。</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多後書 1:10; 約書亞記 4:9; 使徒行傳 26:22"> 撒母耳將一塊石頭立在米斯巴和善的中間，給石頭起名叫以便以謝，說：「到如今耶和華都幫助我們。」</span>
<span className="v" id="v13" data-v="13" data-xref="士師記 13:1; 撒母耳記上 17:49–53; 撒母耳記上 14:6–16"> 從此，非利士人就被制伏，不敢再入以色列人的境內。撒母耳作士師的時候，耶和華的手攻擊非利士人。</span>
<span className="v" id="v14" data-v="14" data-xref="詩篇 106:34; 申命記 7:2; 申命記 7:16"> 非利士人所取以色列人的城邑，從以革倫直到迦特，都歸以色列人了。屬這些城的四境，以色列人也從非利士人手下收回。那時以色列人與亞摩利人和好。</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳記上 7:6; 使徒行傳 13:20–21; 士師記 2:16"> 撒母耳平生作以色列的士師。</span>
<span className="v" id="v16" data-v="16" data-xref="士師記 10:4; 士師記 12:14; 士師記 5:10"> 他每年巡行到伯特利、吉甲、米斯巴，在這幾處審判以色列人。</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳記上 1:19; 撒母耳記上 8:4; 撒母耳記上 1:1"> 隨後回到拉瑪，因為他的家在那裏；也在那裏審判以色列人，且為耶和華築了一座壇。</span>

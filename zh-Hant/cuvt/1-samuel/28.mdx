## 掃羅求問女巫

<div className="bt">
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="利未記 19:31; 撒母耳記上 25:1; 利未記 20:27"> 那時撒母耳已經死了，以色列眾人為他哀哭，葬他在拉瑪，就是在他本城裏。掃羅曾在國內不容有交鬼的和行巫術的人。</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳記上 31:1; 約書亞記 19:18; 列王紀下 4:8"> 非利士人聚集，來到書念安營；掃羅聚集以色列眾人在基利波安營。</span>
<span className="v" id="v5" data-v="5" data-xref="以賽亞書 57:20–21; 但以理書 5:6; 以賽亞書 21:3–4"> 掃羅看見非利士的軍旅就懼怕，心中發顫。</span>
<span className="v" id="v6" data-v="6" data-xref="民數記 12:6; 撒母耳記上 14:37; 耶利米哀歌 2:9"> 掃羅求問耶和華，耶和華卻不藉夢，或烏陵，或先知回答他。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行傳 16:16; 約書亞記 17:11; 歷代志上 10:13"> 掃羅吩咐臣僕說：「當為我找一個交鬼的婦人，我好去問她。」臣僕說：「在隱‧多珥有一個交鬼的婦人。」</span>
<span className="v" id="v8" data-v="8" data-xref="以賽亞書 8:19; 歷代志上 10:13; 列王紀上 22:30"> 於是掃羅改了裝，穿上別的衣服，帶着兩個人，夜裏去見那婦人。掃羅說：「求你用交鬼的法術，將我所告訴你的死人，為我招上來。」</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳記上 28:3; 列王紀下 5:7; 撒母耳記下 18:13"> 婦人對他說：「你知道掃羅從國中剪除交鬼的和行巫術的。你為何陷害我的性命，使我死呢？」</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳記下 14:11; 撒母耳記上 19:6; 申命記 18:10–12"> 掃羅向婦人指着耶和華起誓說：「我指着永生的耶和華起誓，你必不因這事受刑。」</span>
<span className="v" id="v11" data-v="11"> 婦人說：「我為你招誰上來呢？」回答說：「為我招撒母耳上來。」</span>
<span className="v" id="v12" data-v="12" data-xref="撒母耳記上 28:3; 列王紀上 14:5"> 婦人看見撒母耳，就大聲呼叫，對掃羅說：「你是掃羅，為甚麼欺哄我呢？」</span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 82:6–7; 約翰福音 10:34–35; 出埃及記 22:28"> 王對婦人說：「不要懼怕，你看見了甚麼呢？」婦人對掃羅說：「我看見有神從地裏上來。」</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳記上 15:27; 列王紀下 2:8; 撒母耳記上 24:8"> 掃羅說：「他是怎樣的形狀？」婦人說：「有一個老人上來，身穿長衣。」掃羅知道是撒母耳，就屈身，臉伏於地下拜。</span>
<span className="v" id="v15" data-v="15" data-xref="路加福音 16:23–26; 撒母耳記上 28:6; 撒母耳記上 18:12"> 撒母耳對掃羅說：「你為甚麼攪擾我，招我上來呢？」掃羅回答說：「我甚窘急；因為非利士人攻擊我，上帝也離開我，不再藉先知或夢回答我。因此請你上來，好指示我應當怎樣行。」</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀下 6:27; 耶利米哀歌 2:5; 詩篇 68:1–3"> 撒母耳說：「耶和華已經離開你，且與你為敵，你何必問我呢？</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳記上 15:27–29; 撒母耳記上 16:13; 撒母耳記上 13:13–14"> 耶和華照他藉我說的話，已經從你手裏奪去國權，賜與別人，就是大衛。</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳記上 15:9; 列王紀上 20:42; 詩篇 50:21–22"> 因你沒有聽從耶和華的命令；他惱怒亞瑪力人，你沒有滅絕他們，所以今日耶和華向你這樣行，</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行傳 5:5; 耶利米書 28:16–17; 列王紀上 22:20"> 並且耶和華必將你和以色列人交在非利士人的手裏。明日你和你眾子必與我在一處了；耶和華必將以色列的軍兵交在非利士人手裏。」</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳記上 28:5; 約伯記 26:2; 約伯記 15:20–24"> 掃羅猛然仆倒，挺身在地，因撒母耳的話甚是懼怕；那一晝一夜，沒有吃甚麼，就毫無氣力。</span>
<span className="v" id="v21" data-v="21" data-xref="士師記 12:3; 約伯記 13:14; 撒母耳記上 19:5"> 婦人到掃羅面前，見他極其驚恐，對他說：「婢女聽從你的話，不顧惜自己的性命，遵從你所吩咐的。</span>
<span className="v" id="v22" data-v="22"> 現在求你聽婢女的話，容我在你面前擺上一點食物，你吃了，可以有氣力行路。」</span>
<span className="v" id="v23" data-v="23" data-xref="列王紀上 21:4; 路加福音 24:29; 路加福音 14:23"> 掃羅不肯，說：「我不吃。」但他的僕人和婦人再三勸他，他才聽了他們的話，從地上起來，坐在床上。</span>
<span className="v" id="v24" data-v="24" data-xref="路加福音 15:23; 創世記 18:7–8"> 婦人急忙將家裏的一隻肥牛犢宰了，又拿麵摶成無酵餅烤了，</span>
<span className="v" id="v25" data-v="25"> 擺在掃羅和他僕人面前。他們吃完，當夜就起身走了。</span>

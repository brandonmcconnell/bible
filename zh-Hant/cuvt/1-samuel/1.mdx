## 以利加拿和他的家眷在示羅

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歷代志上 6:34; 歷代志上 6:25–27; 撒母耳記上 1:19"> 以法蓮山地的拉瑪‧瑣非有一個以法蓮人，名叫以利加拿，是蘇弗的玄孫，託戶的曾孫，以利戶的孫子，耶羅罕的兒子。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 16:1–2; 士師記 13:2; 創世記 29:23–29"> 他有兩個妻：一名哈拿，一名毗尼拿。毗尼拿有兒女，哈拿沒有兒女。</span>
<span className="v" id="v3" data-v="3" data-xref="路加福音 2:41; 約書亞記 18:1; 申命記 12:5–7"> 這人每年從本城上到示羅，敬拜祭祀萬軍之耶和華；在那裏有以利的兩個兒子何弗尼、非尼哈當耶和華的祭司。</span>
<span className="v" id="v4" data-v="4" data-xref="申命記 12:17–18; 申命記 16:11; 申命記 12:5–7"> 以利加拿每逢獻祭的日子，將祭肉分給他的妻毗尼拿和毗尼拿所生的兒女；</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 30:2; 創世記 29:30–31; 創世記 45:22"> 給哈拿的卻是雙分，因為他愛哈拿。無奈耶和華不使哈拿生育。</span>
<span className="v" id="v6" data-v="6" data-xref="約伯記 6:14; 約伯記 24:21; 利未記 18:18"> 毗尼拿見耶和華不使哈拿生育，就作她的對頭，大大激動她，要使她生氣。</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳記上 2:19"> 每年上到耶和華殿的時候，以利加拿都以雙分給哈拿；毗尼拿仍是激動她，以致她哭泣不吃飯。</span>
<span className="v" id="v8" data-v="8" data-xref="路得記 4:15; 約伯記 6:14; 以賽亞書 54:6"> 她丈夫以利加拿對她說：「哈拿啊，你為何哭泣，不吃飯，心裏愁悶呢？有我不比十個兒子還好嗎？」</span>
</div>
</div>

## 哈拿和以利

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="撒母耳記上 3:3; 詩篇 27:4; 詩篇 5:7"> 他們在示羅吃喝完了，哈拿就站起來。祭司以利在耶和華殿的門框旁邊，坐在自己的位上。</span>
<span className="v" id="v10" data-v="10" data-xref="約伯記 7:11; 路加福音 22:44; 約伯記 10:1"> 哈拿心裏愁苦，就痛痛哭泣，祈禱耶和華，</span>
<span className="v" id="v11" data-v="11" data-xref="士師記 13:5; 民數記 6:5; 創世記 29:32"> 許願說：「萬軍之耶和華啊，你若垂顧婢女的苦情，眷念不忘婢女，賜我一個兒子，我必使他終身歸與耶和華，不用剃頭刀剃他的頭。」</span>
<span className="v" id="v12" data-v="12" data-xref="帖撒羅尼迦前書 5:17; 雅各書 5:16; 路加福音 18:1"> 哈拿在耶和華面前不住地祈禱，以利定睛看她的嘴。（</span>
<span className="v" id="v13" data-v="13" data-xref="羅馬書 8:26; 使徒行傳 2:13; 創世記 24:42–45"> 原來哈拿心中默禱，只動嘴唇，不出聲音，因此以利以為她喝醉了。）</span>
<span className="v" id="v14" data-v="14" data-xref="以弗所書 4:25; 約伯記 8:2; 箴言 6:9"> 以利對她說：「你要醉到幾時呢？你不應該喝酒。」</span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 62:8; 耶利米哀歌 2:19; 詩篇 42:4"> 哈拿回答說：「主啊，不是這樣。我是心裏愁苦的婦人，清酒濃酒都沒有喝，但在耶和華面前傾心吐意。</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳記上 2:12; 約伯記 6:2–3; 馬太福音 12:34–35"> 不要將婢女看作不正經的女子。我因被人激動，愁苦太多，所以祈求到如今。」</span>
<span className="v" id="v17" data-v="17" data-xref="馬可福音 5:34; 士師記 18:6; 詩篇 20:3–5"> 以利說：「你可以平平安安地回去。願以色列的上帝允准你向他所求的！」</span>
<span className="v" id="v18" data-v="18" data-xref="路得記 2:13; 羅馬書 15:13; 傳道書 9:7"> 哈拿說：「願婢女在你眼前蒙恩。」於是婦人走去吃飯，面上再不帶愁容了。</span>
</div>
</div>

## 撒母耳出生和奉獻

<div className="bt">
<div className="bp poetry">
<span className="v" id="v19" data-v="19" data-xref="創世記 21:1; 創世記 30:22; 撒母耳記上 1:11"> 次日清早，他們起來，在耶和華面前敬拜，就回拉瑪。到了家裏，以利加拿和妻哈拿同房，耶和華顧念哈拿，</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 41:51–52; 馬太福音 1:21; 出埃及記 2:10"> 哈拿就懷孕。日期滿足，生了一個兒子，給他起名叫撒母耳，說：「這是我從耶和華那裏求來的。」</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳記上 1:3; 申命記 12:11; 約書亞記 24:15"> 以利加拿和他全家都上示羅去，要向耶和華獻年祭，並還所許的願。</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳記上 1:28; 撒母耳記上 1:11; 路加福音 2:22"> 哈拿卻沒有上去，對丈夫說：「等孩子斷了奶，我便帶他上去朝見耶和華，使他永遠住在那裏。」</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳記下 7:25; 路加福音 11:27; 創世記 21:7–8"> 她丈夫以利加拿說：「就隨你的意行吧！可以等兒子斷了奶。但願耶和華應驗他的話。」於是婦人在家裏乳養兒子，直到斷了奶；</span>
<span className="v" id="v24" data-v="24" data-xref="民數記 15:9–10; 約書亞記 18:1; 撒母耳記上 4:3–4"> 既斷了奶，就把孩子帶上示羅，到了耶和華的殿；又帶了三隻公牛，一伊法細麵，一皮袋酒。（那時，孩子還小。）</span>
<span className="v" id="v25" data-v="25" data-xref="路加福音 18:15–16; 路加福音 2:22"> 宰了一隻公牛，就領孩子到以利面前。</span>
<span className="v" id="v26" data-v="26" data-xref="列王紀下 4:30; 列王紀下 2:4; 列王紀下 2:6"> 婦人說：「主啊，我敢在你面前起誓，從前在你這裏站着祈求耶和華的那婦人，就是我。</span>
<span className="v" id="v27" data-v="27" data-xref="約翰一書 5:15; 詩篇 118:5; 馬太福音 7:7"> 我祈求為要得這孩子；耶和華已將我所求的賜給我了。</span>
<span className="v" id="v28" data-v="28" data-xref="創世記 24:26; 創世記 24:52; 提摩太後書 3:15"> 所以，我將這孩子歸與耶和華，使他終身歸與耶和華。」<br /><span className="pl pl-1">於是在那裏敬拜耶和華。</span></span>
</div>

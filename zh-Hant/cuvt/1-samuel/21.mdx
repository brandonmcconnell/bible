## 大衛逃離掃羅

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="馬可福音 2:26; 尼希米記 11:32; 以賽亞書 10:32"> 大衛到了挪伯祭司亞希米勒那裏，亞希米勒戰戰兢兢地出來迎接他，問他說：「你為甚麼獨自來，沒有人跟隨呢？」</span>
<span className="v" id="v2" data-v="2" data-xref="加拉太書 2:12; 歌羅西書 3:9; 撒母耳記上 22:22"> 大衛回答祭司亞希米勒說：「王吩咐我一件事說：『我差遣你委託你的這件事，不要使人知道。』故此我已派定少年人在某處等候我。</span>
<span className="v" id="v3" data-v="3" data-xref="以賽亞書 3:6; 士師記 9:29; 撒母耳記上 21:4"> 現在你手下有甚麼？求你給我五個餅或是別樣的食物。」</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及記 19:15; 馬太福音 12:3–4; 出埃及記 25:30"> 祭司對大衛說：「我手下沒有尋常的餅，只有聖餅；若少年人沒有親近婦人才可以給。」</span>
<span className="v" id="v5" data-v="5" data-xref="利未記 24:9; 帖撒羅尼迦前書 4:3–4; 提摩太後書 2:20–21"> 大衛對祭司說：「實在約有三日我們沒有親近婦人；我出來的時候，雖是尋常行路，少年人的器皿還是潔淨的；何況今日不更是潔淨嗎？」</span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 6:3–4; 利未記 24:5–9; 馬太福音 12:3–4"> 祭司就拿聖餅給他；因為在那裏沒有別樣餅，只有更換新餅，從耶和華面前撤下來的陳設餅。 （</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳記上 22:9; 詩篇 52:1–9; 歷代志上 27:29"> 當日有掃羅的一個臣子留在耶和華面前。他名叫多益，是以東人，作掃羅的司牧長。）</span>
<span className="v" id="v8" data-v="8"> 大衛問亞希米勒說：「你手下有槍有刀沒有？因為王的事甚急，連刀劍器械我都沒有帶。」</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳記上 17:2; 撒母耳記上 17:50–54; 出埃及記 28:6–14"> 祭司說：「你在以拉谷殺非利士人歌利亞的那刀在這裏，裹在布中，放在以弗得後邊，你要就可以拿去；除此以外，再沒有別的。」大衛說：「這刀沒有可比的！求你給我。」</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米書 26:21; 列王紀上 19:3; 撒母耳記上 27:1–2"> 那日大衛起來，躲避掃羅，逃到迦特王亞吉那裏。</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳記上 29:5; 撒母耳記上 18:7–8; 撒母耳記上 16:1"> 亞吉的臣僕對亞吉說：「這不是以色列國王大衛嗎？那裏的婦女跳舞唱和，不是指着他說『掃羅殺死千千，大衛殺死萬萬』嗎？」</span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 2:19; 詩篇 56:3; 詩篇 34:4"> 大衛將這話放在心裏，甚懼怕迦特王亞吉，</span>
<span className="v" id="v13" data-v="13" data-xref="箴言 29:25; 傳道書 7:7; 詩篇 34:1–22"> 就在眾人面前改變了尋常的舉動，在他們手下假裝瘋癲，在城門的門扇上胡寫亂畫，使唾沫流在鬍子上。</span>
<span className="v" id="v14" data-v="14" data-xref="傳道書 7:7"> 亞吉對臣僕說：「你們看，這人是瘋子。為甚麼帶他到我這裏來呢？</span>
<span className="v" id="v15" data-v="15"> 我豈缺少瘋子，你們帶這人來在我面前瘋癲嗎？這人豈可進我的家呢？」</span>

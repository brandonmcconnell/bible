## 歌利亞向以色列軍挑戰

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="約書亞記 15:35; 歷代志下 28:18; 歷代志上 11:13"> 非利士人招聚他們的軍旅，要來爭戰；聚集在屬猶大的梭哥，安營在梭哥和亞西加中間的以弗‧大憫。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳記上 21:9; 撒母耳記上 17:19"> 掃羅和以色列人也聚集，在以拉谷安營，擺列隊伍，要與非利士人打仗。</span>
<span className="v" id="v3" data-v="3"> 非利士人站在這邊山上，以色列人站在那邊山上，當中有谷。</span>
<span className="v" id="v4" data-v="4" data-xref="約書亞記 11:22; 撒母耳記下 21:16–22; 歷代志上 20:4–8"> 從非利士營中出來一個討戰的人，名叫歌利亞，是迦特人，身高六肘零一虎口；</span>
<span className="v" id="v5" data-v="5"> 頭戴銅盔，身穿鎧甲，甲重五千舍客勒；</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳記上 17:45; 歷代志下 9:15; 列王紀上 10:16"> 腿上有銅護膝，兩肩之中背負銅戟；</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳記下 21:19; 撒母耳記上 17:41; 歷代志上 11:23"> 槍桿粗如織布的機軸，鐵槍頭重六百舍客勒。有一個拿盾牌的人在他前面走。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳記上 8:17; 歷代志上 21:3; 撒母耳記上 17:26"> 歌利亞對着以色列的軍隊站立，呼叫說：「你們出來擺列隊伍做甚麼呢？我不是非利士人嗎？你們不是掃羅的僕人嗎？可以從你們中間揀選一人，使他下到我這裏來。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳記上 11:1"> 他若能與我戰鬥，將我殺死，我們就作你們的僕人；我若勝了他，將他殺死，你們就作我們的僕人，服事我們。」</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳記上 17:25–26; 撒母耳記上 17:45; 撒母耳記上 17:36"> 那非利士人又說：「我今日向以色列人的軍隊罵陣。你們叫一個人出來，與我戰鬥。」</span>
<span className="v" id="v11" data-v="11" data-xref="約書亞記 1:9; 申命記 31:8; 箴言 28:1"> 掃羅和以色列眾人聽見非利士人的這些話，就驚惶，極其害怕。</span>
</div>
</div>

## 大衛在掃羅的營中

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="撒母耳記上 16:10–11; 創世記 35:19; 撒母耳記上 16:18"> 大衛是猶大伯利恆的以法他人耶西的兒子。耶西有八個兒子。當掃羅的時候，耶西已經老邁。</span>
<span className="v" id="v13" data-v="13" data-xref="歷代志上 2:13; 撒母耳記下 21:21; 撒母耳記上 17:28"> 耶西的三個大兒子跟隨掃羅出征。這出征的三個兒子：長子名叫以利押，次子名叫亞比拿達，三子名叫沙瑪。</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳記上 16:11; 創世記 25:23"> 大衛是最小的；那三個大兒子跟隨掃羅。</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳記上 16:11; 撒母耳記上 16:19–23"> 大衛有時離開掃羅，回伯利恆放他父親的羊。</span>
<span className="v" id="v16" data-v="16" data-xref="馬太福音 4:2; 路加福音 4:2"> 那非利士人早晚都出來站着，如此四十日。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="撒母耳記上 25:18; 撒母耳記下 17:28; 路得記 2:14"> 一日，耶西對他兒子大衛說：「你拿一伊法烘了的穗子和十個餅，速速地送到營裏去，交給你哥哥們；</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 37:14; 撒母耳記上 16:20; 撒母耳記下 17:29"> 再拿這十塊奶餅，送給他們的千夫長，且問你哥哥們好，向他們要一封信來。」</span>
<span className="v" id="v19" data-v="19"> 掃羅與大衛的三個哥哥和以色列眾人，在以拉谷與非利士人打仗。</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳記上 26:5; 路加福音 19:43; 以弗所書 6:1–2"> 大衛早晨起來，將羊交託一個看守的人，照着他父親所吩咐的話，帶着食物去了。到了輜重營，軍兵剛出到戰場，吶喊要戰。</span>
<span className="v" id="v21" data-v="21"> 以色列人和非利士人都擺列隊伍，彼此相對。</span>
<span className="v" id="v22" data-v="22" data-xref="路加福音 10:5–6; 士師記 18:15; 以賽亞書 10:28"> 大衛把他帶來的食物留在看守物件人的手下，跑到戰場，問他哥哥們安。</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳記上 17:8–10"> 與他們說話的時候，那討戰的，就是屬迦特的非利士人歌利亞，從非利士隊中出來，說從前所說的話；大衛都聽見了。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="撒母耳記上 13:6–7; 利未記 26:36; 以賽亞書 7:2"> 以色列眾人看見那人，就逃跑，極其害怕。</span>
<span className="v" id="v25" data-v="25" data-xref="約書亞記 15:16; 啟示錄 2:7; 啟示錄 3:12"> 以色列人彼此說：「這上來的人你看見了嗎？他上來是要向以色列人罵陣。若有能殺他的，王必賞賜他大財，將自己的女兒給他為妻，並在以色列人中免他父家納糧當差。」</span>
<span className="v" id="v26" data-v="26" data-xref="申命記 5:26; 撒母耳記上 11:2; 撒母耳記上 14:6"> 大衛問站在旁邊的人說：「有人殺這非利士人，除掉以色列人的恥辱，怎樣待他呢？這未受割禮的非利士人是誰呢？竟敢向永生上帝的軍隊罵陣嗎？」</span>
<span className="v" id="v27" data-v="27" data-xref="撒母耳記上 17:25"> 百姓照先前的話回答他說：「有人能殺這非利士人，必如此如此待他。」</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="馬太福音 10:36; 創世記 37:11; 箴言 18:19"> 大衛的長兄以利押聽見大衛與他們所說的話，就向他發怒，說：「你下來做甚麼呢？在曠野的那幾隻羊，你交託了誰呢？我知道你的驕傲和你心裏的惡意，你下來特為要看爭戰！」</span>
<span className="v" id="v29" data-v="29" data-xref="彼得前書 3:9; 哥林多前書 2:15; 箴言 15:1"> 大衛說：「我做了甚麼呢？我來豈沒有緣故嗎？」</span>
<span className="v" id="v30" data-v="30" data-xref="撒母耳記上 17:26–27"> 大衛就離開他轉向別人，照先前的話而問；百姓仍照先前的話回答他。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="箴言 22:29"> 有人聽見大衛所說的話，就告訴了掃羅；掃羅便打發人叫他來。</span>
<span className="v" id="v32" data-v="32" data-xref="撒母耳記上 16:18; 申命記 20:1–3; 詩篇 3:6"> 大衛對掃羅說：「人都不必因那非利士人膽怯。你的僕人要去與那非利士人戰鬥。」</span>
<span className="v" id="v33" data-v="33" data-xref="民數記 13:31; 申命記 9:2; 啟示錄 13:4"> 掃羅對大衛說：「你不能去與那非利士人戰鬥；因為你年紀太輕，他自幼就作戰士。」</span>
<span className="v" id="v34" data-v="34"> 大衛對掃羅說：「你僕人為父親放羊，有時來了獅子，有時來了熊，從群中啣一隻羊羔去。</span>
<span className="v" id="v35" data-v="35" data-xref="阿摩司書 3:12; 提摩太後書 4:17–18; 但以理書 6:22"> 我就追趕牠，擊打牠，將羊羔從牠口中救出來。牠起來要害我，我就揪着牠的鬍子，將牠打死。</span>
<span className="v" id="v36" data-v="36" data-xref="撒母耳記上 17:10; 使徒行傳 5:38–39; 羅馬書 2:28–29"> 你僕人曾打死獅子和熊，這未受割禮的非利士人向永生上帝的軍隊罵陣，也必像獅子和熊一般。」</span>
<span className="v" id="v37" data-v="37" data-xref="提摩太後書 4:17–18; 詩篇 138:7–8; 哥林多後書 1:9–10"> 大衛又說：「耶和華救我脫離獅子和熊的爪，也必救我脫離這非利士人的手。」掃羅對大衛說：「你可以去吧！耶和華必與你同在。」</span>
<span className="v" id="v38" data-v="38"> 掃羅就把自己的戰衣給大衛穿上，將銅盔給他戴上，又給他穿上鎧甲。</span>
<span className="v" id="v39" data-v="39" data-xref="撒迦利亞書 4:6; 哥林多後書 10:4–5; 何西阿書 1:7"> 大衛把刀跨在戰衣外，試試能走不能走；因為素來沒有穿慣，就對掃羅說：「我穿戴這些不能走，因為素來沒有穿慣。」於是摘脫了。</span>
<span className="v" id="v40" data-v="40" data-xref="哥林多前書 1:27–29; 馬太福音 10:10; 士師記 15:15–16"> 他手中拿杖，又在溪中挑選了五塊光滑石子，放在袋裏，就是牧人帶的囊裏；手中拿着甩石的機弦，就去迎那非利士人。</span>
</div>
</div>

## 大衛擊殺歌利亞

<div className="bt">
<div className="bp">
<span className="v" id="v41" data-v="41"> 非利士人也漸漸地迎着大衛來，拿盾牌的走在前頭。</span>
<span className="v" id="v42" data-v="42" data-xref="撒母耳記上 16:12; 撒母耳記上 17:33; 詩篇 123:3–4"> 非利士人觀看，見了大衛，就藐視他；因為他年輕，面色光紅，容貌俊美。</span>
<span className="v" id="v43" data-v="43" data-xref="撒母耳記下 9:8; 撒母耳記下 3:8; 撒母耳記上 24:14"> 非利士人對大衛說：「你拿杖到我這裏來，我豈是狗呢？」非利士人就指着自己的神咒詛大衛。</span>
<span className="v" id="v44" data-v="44" data-xref="以西結書 28:9–10; 箴言 18:12; 列王紀上 20:10–11"> 非利士人又對大衛說：「來吧！我將你的肉給空中的飛鳥、田野的走獸吃。」</span>
<span className="v" id="v45" data-v="45" data-xref="哥林多後書 10:4; 歷代志下 32:8; 哥林多後書 3:5"> 大衛對非利士人說：「你來攻擊我，是靠着刀槍和銅戟；我來攻擊你，是靠着萬軍之耶和華的名，就是你所怒罵帶領以色列軍隊的上帝。</span>
<span className="v" id="v46" data-v="46" data-xref="以賽亞書 52:10; 約書亞記 4:24; 列王紀下 19:19"> 今日耶和華必將你交在我手裏。我必殺你，斬你的頭，又將非利士軍兵的屍首給空中的飛鳥、地上的野獸吃，使普天下的人都知道以色列中有上帝；</span>
<span className="v" id="v47" data-v="47" data-xref="詩篇 44:6–7; 撒迦利亞書 4:6; 何西阿書 1:7"> 又使這眾人知道耶和華使人得勝，不是用刀用槍，因為爭戰的勝敗全在乎耶和華。他必將你們交在我們手裏。」</span>
</div>
<div className="bp">
<span className="v" id="v48" data-v="48" data-xref="箴言 28:1; 詩篇 27:1"> 非利士人起身，迎着大衛前來。大衛急忙迎着非利士人，往戰場跑去。</span>
<span className="v" id="v49" data-v="49" data-xref="哥林多前書 1:27–28; 列王紀下 9:24; 列王紀上 22:34"> 大衛用手從囊中掏出一塊石子來，用機弦甩去，打中非利士人的額，石子進入額內，他就仆倒，面伏於地。</span>
</div>
<div className="bp">
<span className="v" id="v50" data-v="50" data-xref="士師記 15:15; 撒母耳記上 17:39; 撒母耳記上 23:21"> 這樣，大衛用機弦甩石，勝了那非利士人，打死他；大衛手中卻沒有刀。</span>
<span className="v" id="v51" data-v="51" data-xref="希伯來書 11:34; 撒母耳記上 21:9; 撒母耳記下 23:21"> 大衛跑去，站在非利士人身旁，將他的刀從鞘中拔出來，殺死他，割了他的頭。非利士眾人看見他們討戰的勇士死了，就都逃跑。</span>
<span className="v" id="v52" data-v="52" data-xref="約書亞記 15:11; 約書亞記 15:33–36; 約書亞記 15:45–46"> 以色列人和猶大人便起身吶喊，追趕非利士人，直到迦特<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或譯：該">a</a></sup>和以革倫的城門。被殺的非利士人倒在沙拉音的路上，直到迦特和以革倫。</span>
<span className="v" id="v53" data-v="53" data-xref="耶利米書 4:20; 列王紀下 7:7–16; 耶利米書 30:16"> 以色列人追趕非利士人回來，就奪了他們的營盤。</span>
<span className="v" id="v54" data-v="54" data-xref="出埃及記 16:33; 約書亞記 4:7–8; 撒母耳記上 21:9"> 大衛將那非利士人的頭拿到耶路撒冷，卻將他軍裝放在自己的帳棚裏。</span>
</div>
</div>

## 大衛覲見掃羅

<div className="bt">
<div className="bp">
<span className="v" id="v55" data-v="55" data-xref="撒母耳記上 16:21–22; 撒母耳記上 17:58"> 掃羅看見大衛去攻擊非利士人，就問元帥押尼珥說：「押尼珥啊，那少年人是誰的兒子？」押尼珥說：「我敢在王面前起誓，我不知道。」</span>
<span className="v" id="v56" data-v="56"> 王說：「你可以問問那幼年人是誰的兒子。」</span>
<span className="v" id="v57" data-v="57" data-xref="撒母耳記上 17:54"> 大衛打死非利士人回來，押尼珥領他到掃羅面前，他手中拿着非利士人的頭。</span>
<span className="v" id="v58" data-v="58" data-xref="撒母耳記上 17:12; 撒母耳記上 16:18–19"> 掃羅問他說：「少年人哪，你是誰的兒子？」大衛說：「我是你僕人伯利恆人耶西的兒子。」</span>
</div>

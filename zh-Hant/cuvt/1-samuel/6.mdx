## 送回約櫃

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="詩篇 78:61; 撒母耳記上 5:3; 撒母耳記上 5:1"> 耶和華的約櫃在非利士人之地七個月。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 7:11; 創世記 41:8; 但以理書 5:7"> 非利士人將祭司和占卜的聚了來，問他們說：「我們向耶和華的約櫃應當怎樣行？請指示我們用何法將約櫃送回原處。」</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳記上 6:9; 出埃及記 23:15; 申命記 16:16"> 他們說：「若要將以色列上帝的約櫃送回去，不可空空地送去，必要給他獻賠罪的禮物，然後你們可得痊癒，並知道他的手為何不離開你們。」</span>
<span className="v" id="v4" data-v="4" data-xref="士師記 3:3; 撒母耳記上 6:17–18; 約書亞記 13:3"> 非利士人說：「應當用甚麼獻為賠罪的禮物呢？」他們回答說：「當照非利士首領的數目，用五個金痔瘡，五個金老鼠，因為在你們眾人和你們首領的身上都是一樣的災。</span>
<span className="v" id="v5" data-v="5" data-xref="約書亞記 7:19; 撒母耳記上 5:6–7; 撒母耳記上 5:11"> 所以當製造你們痔瘡的像和毀壞你們田地老鼠的像，並要歸榮耀給以色列的上帝，或者他向你們和你們的神，並你們的田地，把手放輕些。</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及記 8:15; 出埃及記 7:13; 出埃及記 14:17"> 你們為何硬着心像埃及人和法老一樣呢？上帝在埃及人中間行奇事，埃及人豈不釋放以色列人，他們就去了嗎？</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳記下 6:3; 民數記 19:2; 歷代志上 13:7"> 現在你們應當造一輛新車，將兩隻未曾負軛有乳的母牛套在車上，使牛犢回家去，離開母牛。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳記上 6:3–5"> 把耶和華的約櫃放在車上，將所獻賠罪的金物裝在匣子裏，放在櫃旁，將櫃送去。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳記上 6:3; 約書亞記 15:10; 約書亞記 21:16"> 你們要看看：車若直行以色列的境界到伯‧示麥去，這大災就是耶和華降在我們身上的；若不然，便可以知道不是他的手擊打我們，是我們偶然遇見的。」</span>
<span className="v" id="v10" data-v="10"> 非利士人就這樣行：將兩隻有乳的母牛套在車上，將牛犢關在家裏，</span>
<span className="v" id="v11" data-v="11" data-xref="歷代志上 15:13–15; 撒母耳記下 6:3; 歷代志上 13:7"> 把耶和華的約櫃和裝金老鼠並金痔瘡像的匣子都放在車上。</span>
<span className="v" id="v12" data-v="12" data-xref="民數記 20:19"> 牛直行大道，往伯‧示麥去，一面走一面叫，不偏左右。非利士的首領跟在後面，直到伯‧示麥的境界。</span>
<span className="v" id="v13" data-v="13"> 伯‧示麥人正在平原收割麥子，舉目看見約櫃，就歡喜了。</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳記下 24:22; 士師記 21:4; 撒母耳記上 11:5"> 車到了伯‧示麥人約書亞的田間，就站住了。在那裏有一塊大磐石，他們把車劈了，將兩隻母牛獻給耶和華為燔祭。</span>
<span className="v" id="v15" data-v="15" data-xref="約書亞記 3:3"> 利未人將耶和華的約櫃和裝金物的匣子拿下來，放在大磐石上。當日伯‧示麥人將燔祭和平安祭獻給耶和華。</span>
<span className="v" id="v16" data-v="16" data-xref="士師記 3:3; 撒母耳記上 6:4; 約書亞記 13:3"> 非利士人的五個首領看見，當日就回以革倫去了。</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳記下 1:20; 耶利米書 25:20; 撒母耳記上 5:10"> 非利士人獻給耶和華作賠罪的金痔瘡像，就是這些：一個是為亞實突，一個是為迦薩，一個是為亞實基倫，一個是為迦特，一個是為以革倫。</span>
<span className="v" id="v18" data-v="18" data-xref="約書亞記 13:3; 申命記 3:5; 撒母耳記上 6:14–16"> 金老鼠的數目是照非利士五個首領的城邑，就是堅固的城邑和鄉村，以及大磐石。這磐石是放耶和華約櫃的，到今日還在伯‧示麥人約書亞的田間。</span>
</div>
</div>

## 約櫃在基列‧耶琳

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="民數記 4:20; 出埃及記 19:21; 撒母耳記下 6:7"> 耶和華因伯‧示麥人擅觀他的約櫃，就擊殺了他們七十人；那時有五萬人在那裏<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是七十人加五萬人">a</a></sup>。百姓因耶和華大大擊殺他們，就哀哭了。</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳記下 6:9; 瑪拉基書 3:2; 啟示錄 6:17"> 伯‧示麥人說：「誰能在耶和華這聖潔的上帝面前侍立呢？這約櫃可以從我們這裏送到誰那裏去呢？」</span>
<span className="v" id="v21" data-v="21" data-xref="歷代志上 13:5–6; 約書亞記 9:17; 約書亞記 18:14"> 於是打發人去見基列‧耶琳的居民，說：「非利士人將耶和華的約櫃送回來了，你們下來將約櫃接到你們那裏去吧！」</span>
</div>

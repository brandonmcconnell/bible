## 大衛被膏立為王

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀下 9:1; 撒母耳記上 15:23; 詩篇 78:68–71"> 耶和華對撒母耳說：「我既厭棄掃羅作以色列的王，你為他悲傷要到幾時呢？你將膏油盛滿了角，我差遣你往伯利恆人耶西那裏去；因為我在他眾子之內，預定一個作王的。」</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳記上 9:12; 撒母耳記上 20:29; 馬太福音 10:16"> 撒母耳說：「我怎能去呢？掃羅若聽見，必要殺我。」耶和華說：「你可以帶一隻牛犢去，就說：『我來是要向耶和華獻祭。』</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳記上 9:16; 撒母耳記上 16:12–13; 撒母耳記下 15:11"> 你要請耶西來吃祭肉，我就指示你所當行的事。我所指給你的人，你要膏他。」</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀上 2:13; 歷代志上 12:17–18; 撒母耳記上 21:1"> 撒母耳就照耶和華的話去行。到了伯利恆，那城裏的長老都戰戰兢兢地出來迎接他，問他說：「你是為平安來的嗎？」</span>
<span className="v" id="v5" data-v="5" data-xref="約書亞記 3:5; 利未記 20:7–8; 出埃及記 19:10"> 他說：「為平安來的，我是給耶和華獻祭。你們當自潔，來與我同吃祭肉。」撒母耳就使耶西和他眾子自潔，請他們來吃祭肉。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳記上 17:13; 歷代志上 2:13; 撒母耳記上 17:22"> 他們來的時候，撒母耳看見以利押，就心裏說，耶和華的受膏者必定在他面前。</span>
<span className="v" id="v7" data-v="7" data-xref="約翰福音 7:24; 耶利米書 17:10; 路加福音 16:15"> 耶和華卻對撒母耳說：「不要看他的外貌和他身材高大，我不揀選他。因為，耶和華不像人看人：人是看外貌；耶和華是看內心。」</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳記上 17:13; 歷代志上 2:13"> 耶西叫亞比拿達從撒母耳面前經過，撒母耳說：「耶和華也不揀選他。」</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳記上 17:13; 歷代志上 2:13; 撒母耳記下 13:3"> 耶西又叫沙瑪從撒母耳面前經過，撒母耳說：「耶和華也不揀選他。」</span>
<span className="v" id="v10" data-v="10" data-xref="歷代志上 2:13–15"> 耶西叫他七個兒子都從撒母耳面前經過，撒母耳說：「這都不是耶和華所揀選的。」</span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 78:70–71; 撒母耳記下 7:8; 撒母耳記下 13:3"> 撒母耳對耶西說：「你的兒子都在這裏嗎？」他回答說：「還有個小的，現在放羊。」撒母耳對耶西說：「你打發人去叫他來；他若不來，我們必不坐席。」</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米哀歌 4:7; 詩篇 89:19–20; 雅歌 5:10"> 耶西就打發人去叫了他來。他面色光紅，雙目清秀，容貌俊美。耶和華說：「這就是他，你起來膏他。」</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳記上 10:6; 希伯來書 1:9; 約翰福音 3:34"> 撒母耳就用角裏的膏油，在他諸兄中膏了他。從這日起，耶和華的靈就大大感動大衛。撒母耳起身回拉瑪去了。</span>
</div>
</div>

## 大衛在掃羅的宮裏

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="詩篇 51:11; 撒母耳記上 18:12; 士師記 9:23"> 耶和華的靈離開掃羅，有惡魔從耶和華那裏來擾亂他。</span>
<span className="v" id="v15" data-v="15"> 掃羅的臣僕對他說：「現在有惡魔從上帝那裏來擾亂你。</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀下 3:15; 列王紀上 10:8; 撒母耳記上 19:9"> 我們的主可以吩咐面前的臣僕，找一個善於彈琴的來，等上帝那裏來的惡魔臨到你身上的時候，使他用手彈琴，你就好了。」</span>
<span className="v" id="v17" data-v="17"> 掃羅對臣僕說：「你們可以為我找一個善於彈琴的，帶到我這裏來。」</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳記上 3:19; 創世記 39:23; 創世記 39:2"> 其中有一個少年人說：「我曾見伯利恆人耶西的一個兒子善於彈琴，是大有勇敢的戰士，說話合宜，容貌俊美，耶和華也與他同在。」</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳記上 16:11; 撒母耳記上 17:15; 詩篇 78:70–72"> 於是掃羅差遣使者去見耶西，說：「請你打發你放羊的兒子大衛到我這裏來。」</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳記上 10:27; 箴言 18:16; 撒母耳記上 17:18"> 耶西就把幾個餅和一皮袋酒，並一隻山羊羔，都馱在驢上，交給他兒子大衛，送與掃羅。</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 41:46; 箴言 22:29; 詩篇 146:3"> 大衛到了掃羅那裏，就侍立在掃羅面前。掃羅甚喜愛他，他就作了掃羅拿兵器的人。</span>
<span className="v" id="v22" data-v="22"> 掃羅差遣人去見耶西，說：「求你容大衛侍立在我面前，因為他在我眼前蒙了恩。」</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳記上 16:14–16; 撒母耳記上 18:10–11; 路加福音 11:24–26"> 從上帝那裏來的惡魔臨到掃羅身上的時候，大衛就拿琴，用手而彈，掃羅便舒暢爽快，惡魔離了他。</span>
</div>

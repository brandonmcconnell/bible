## 約拿單幫助大衛

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="彼得後書 2:9; 哥林多後書 1:12; 約翰一書 3:21"> 大衛從拉瑪的拿約逃跑，來到約拿單那裏，對他說：「我做了甚麼？有甚麼罪孽呢？在你父親面前犯了甚麼罪，他竟尋索我的性命呢？」</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳記上 9:15; 約翰福音 17:8; 約翰福音 15:15"> 約拿單回答說：「斷然不是！你必不致死。我父做事，無論大小，沒有不叫我知道的。怎麼獨有這事隱瞞我呢？決不如此。」</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳記上 25:26; 申命記 6:13; 列王紀下 2:6"> 大衛又起誓說：「你父親準知我在你眼前蒙恩。他心裏說，不如不叫約拿單知道，恐怕他愁煩。我指着永生的耶和華，又敢在你面前起誓，我離死不過一步。」</span>
<span className="v" id="v4" data-v="4"> 約拿單對大衛說：「你心裏所求的，我必為你成就。」</span>
<span className="v" id="v5" data-v="5" data-xref="民數記 10:10; 撒母耳記上 19:2; 民數記 28:11"> 大衛對約拿單說：「明日是初一，我當與王同席，求你容我去藏在田野，直到第三日晚上。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳記上 17:58; 撒母耳記上 9:12; 申命記 12:5"> 你父親若見我不在席上，你就說：『大衛切求我許他回本城伯利恆去，因為他全家在那裏獻年祭。』</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳記上 25:17; 以斯帖記 7:7; 申命記 1:23"> 你父親若說好，僕人就平安了；他若發怒，你就知道他決意要害我。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳記下 14:32; 撒母耳記上 18:3; 撒母耳記上 23:18"> 求你施恩與僕人，因你在耶和華面前曾與僕人結盟。我若有罪，不如你自己殺我，何必將我交給你父親呢？」</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳記上 20:42; 撒母耳記上 19:2; 撒母耳記上 20:38"> 約拿單說：「斷無此事！我若知道我父親決意害你，我豈不告訴你呢？」</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳記上 25:14; 撒母耳記上 25:17; 創世記 42:30"> 大衛對約拿單說：「你父親若用厲言回答你，誰來告訴我呢？」</span>
<span className="v" id="v11" data-v="11"> 約拿單對大衛說：「你我且往田野去。」二人就往田野去了。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="約書亞記 22:22; 約伯記 31:4; 箴言 25:2–3"> 約拿單對大衛說：「願耶和華－以色列的上帝為證。明日約在這時候，或第三日，我探我父親的意思，若向你有好意，我豈不打發人告訴你嗎？</span>
<span className="v" id="v13" data-v="13" data-xref="路得記 1:17; 歷代志上 22:11; 約書亞記 1:5"> 我父親若有意害你，我不告訴你使你平平安安地走，願耶和華重重地降罰與我。願耶和華與你同在，如同從前與我父親同在一樣。</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳記下 9:3; 以弗所書 5:1–2"> 你要照耶和華的慈愛恩待我，不但我活着的時候免我死亡，</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳記下 21:7; 撒母耳記上 24:21; 撒母耳記下 9:1–7"> 就是我死後，耶和華從地上剪除你仇敵的時候，你也永不可向我家絕了恩惠。」</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳記上 25:22; 撒母耳記上 18:3; 撒母耳記下 21:8"> 於是約拿單與大衛家結盟，說：「願耶和華藉大衛的仇敵追討背約的罪。」</span>
<span className="v" id="v17" data-v="17" data-xref="箴言 18:24; 撒母耳記上 18:1; 撒母耳記上 18:3"> 約拿單因愛大衛如同愛自己的性命，就使他再起誓。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="撒母耳記上 20:25; 撒母耳記上 20:5"> 約拿單對他說：「明日是初一，你的座位空設，人必理會你不在那裏。</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳記上 19:2; 撒母耳記上 20:5"> 你等三日，就要速速下去，到你從前遇事所藏的地方，在以色磐石那裏等候。</span>
<span className="v" id="v20" data-v="20"> 我要向磐石旁邊射三箭，如同射箭靶一樣。</span>
<span className="v" id="v21" data-v="21" data-xref="耶利米書 5:2; 阿摩司書 8:14; 耶利米書 12:16"> 我要打發童子，說：『去把箭找來。』我若對童子說：『箭在後頭，把箭拿來』，你就可以回來；我指着永生的耶和華起誓，你必平安無事。</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳記上 20:37"> 我若對童子說：『箭在前頭』，你就要去，因為是耶和華打發你去的。</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳記上 20:14–15; 撒母耳記上 20:42; 創世記 31:50"> 至於你我今日所說的話，有耶和華在你我中間為證，直到永遠。」</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="箴言 4:17; 以賽亞書 1:11–15; 箴言 21:3"> 大衛就去藏在田野。到了初一日，王坐席要吃飯。</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳記上 20:18; 士師記 16:20"> 王照常坐在靠牆的位上，約拿單侍立，押尼珥坐在掃羅旁邊，大衛的座位空設。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="利未記 15:5; 利未記 11:24; 利未記 11:27"> 然而這日掃羅沒有說甚麼，他想大衛遇事，偶染不潔，他必定是不潔。</span>
<span className="v" id="v27" data-v="27" data-xref="彼得前書 2:4; 撒母耳記上 19:15; 撒母耳記上 18:11"> 初二日大衛的座位還空設。掃羅問他兒子約拿單說：「耶西的兒子為何昨日、今日沒有來吃飯呢？」</span>
<span className="v" id="v28" data-v="28" data-xref="撒母耳記上 20:6"> 約拿單回答掃羅說：「大衛切求我容他往伯利恆去。</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳記上 17:28"> 他說：『求你容我去，因為我家在城裏有獻祭的事；我長兄吩咐我去。如今我若在你眼前蒙恩，求你容我去見我的弟兄』；所以大衛沒有赴王的席。」</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="箴言 21:24; 雅各書 1:19–20; 箴言 25:28"> 掃羅向約拿單發怒，對他說：「你這頑梗背逆之婦人所生的，我豈不知道你喜悅耶西的兒子，自取羞辱，以致你母親露體蒙羞嗎？</span>
<span className="v" id="v31" data-v="31" data-xref="撒母耳記上 19:6; 撒母耳記上 20:8; 撒母耳記上 19:11–15"> 耶西的兒子若在世間活着，你和你的國位必站立不住。現在你要打發人去，將他捉拿交給我；他是該死的。」</span>
<span className="v" id="v32" data-v="32" data-xref="馬太福音 27:23; 撒母耳記上 19:5; 路加福音 23:22"> 約拿單對父親掃羅說：「他為甚麼該死呢？他做了甚麼呢？」</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="撒母耳記上 20:7; 撒母耳記上 18:11; 撒母耳記上 19:10"> 掃羅向約拿單掄槍要刺他，約拿單就知道他父親決意要殺大衛。</span>
<span className="v" id="v34" data-v="34" data-xref="以弗所書 4:26; 馬可福音 3:5; 傳道書 7:20"> 於是約拿單氣忿忿地從席上起來，在這初二日沒有吃飯。他因見父親羞辱大衛，就為大衛愁煩。</span>
<span className="v" id="v35" data-v="35" data-xref="撒母耳記下 20:5; 撒母耳記上 20:19"> 次日早晨，約拿單按着與大衛約會的時候出到田野，有一個童子跟隨。</span>
<span className="v" id="v36" data-v="36" data-xref="撒母耳記上 20:20–22"> 約拿單對童子說：「你跑去，把我所射的箭找來。」童子跑去，約拿單就把箭射在童子前頭。</span>
<span className="v" id="v37" data-v="37" data-xref="撒母耳記上 20:22"> 童子到了約拿單落箭之地，約拿單呼叫童子說：「箭不是在你前頭嗎？」</span>
<span className="v" id="v38" data-v="38" data-xref="詩篇 55:6–9; 箴言 6:4–5; 馬可福音 13:14–16"> 約拿單又呼叫童子說：「速速地去，不要遲延！」童子就拾起箭來，回到主人那裏。</span>
<span className="v" id="v39" data-v="39"> 童子卻不知道這是甚麼意思，只有約拿單和大衛知道。</span>
<span className="v" id="v40" data-v="40"> 約拿單將弓箭交給童子，吩咐說：「你拿到城裏去。」</span>
<span className="v" id="v41" data-v="41" data-xref="創世記 29:11; 撒母耳記上 18:3; 撒母耳記下 9:6"> 童子一去，大衛就從磐石的南邊出來，俯伏在地，拜了三拜；二人親嘴，彼此哭泣，大衛哭得更慟。</span>
<span className="v" id="v42" data-v="42" data-xref="撒母耳記上 1:17; 撒母耳記上 23:18; 撒母耳記上 20:22–23"> 約拿單對大衛說：「我們二人曾指着耶和華的名起誓說：『願耶和華在你我中間，並你我後裔中間為證，直到永遠。』如今你平平安安地去吧！」大衛就起身走了；約拿單也回城裏去了。</span>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳記上 16:13; 詩篇 78:71; 撒母耳記上 9:16"> 撒母耳拿瓶膏油倒在掃羅的頭上，與他親嘴，說：「這不是耶和華膏你作他產業的君嗎？</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳記上 9:3–5; 創世記 35:19–20; 約書亞記 18:28"> 你今日與我離別之後，在便雅憫境內的泄撒，靠近拉結的墳墓，要遇見兩個人。他們必對你說：『你去找的那幾頭驢已經找着了。現在你父親不為驢掛心，反為你擔憂，說：我為兒子怎麼才好呢？』</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 35:3; 創世記 35:1; 創世記 28:22"> 你從那裏往前行，到了他泊的橡樹那裏，必遇見三個往伯特利去拜上帝的人：一個帶着三隻山羊羔，一個帶着三個餅，一個帶着一皮袋酒。</span>
<span className="v" id="v4" data-v="4" data-xref="士師記 18:15"> 他們必問你安，給你兩個餅，你就從他們手中接過來。</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀下 3:15; 撒母耳記上 13:3; 撒母耳記上 19:20"> 此後你到上帝的山，在那裏有非利士人的防兵。你到了城的時候，必遇見一班先知從邱壇下來，前面有鼓瑟的、擊鼓的、吹笛的、彈琴的，他們都受感說話。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳記上 10:10; 撒母耳記上 19:23–24; 民數記 11:25"> 耶和華的靈必大大感動你，你就與他們一同受感說話；你要變為新人。</span>
<span className="v" id="v7" data-v="7" data-xref="士師記 6:12; 約書亞記 1:5; 以賽亞書 7:14"> 這兆頭臨到你，你就可以趁時而做，因為上帝與你同在。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳記上 11:14–15; 撒母耳記上 13:4; 撒母耳記上 13:8–15"> 你當在我以先下到吉甲，我也必下到那裏獻燔祭和平安祭。你要等候七日，等我到了那裏，指示你當行的事。」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="以賽亞書 38:7–8; 撒母耳記上 10:2–6; 士師記 7:11"> 掃羅轉身離別撒母耳，上帝就賜他一個新心。當日這一切兆頭都應驗了。</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳記上 10:5–6; 撒母耳記上 19:20–24"> 掃羅到了那山，有一班先知遇見他，上帝的靈大大感動他，他就在先知中受感說話。</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳記上 19:24; 約翰福音 7:15; 馬太福音 13:54–55"> 素來認識掃羅的，看見他和先知一同受感說話，就彼此說：「基士的兒子遇見甚麼了？掃羅也列在先知中嗎？」</span>
<span className="v" id="v12" data-v="12" data-xref="以賽亞書 54:13; 約翰福音 6:45; 雅各書 1:17"> 那地方有一個人說：「這些人的父親是誰呢？」此後有句俗語說：「掃羅也列在先知中嗎？」</span>
<span className="v" id="v13" data-v="13"> 掃羅受感說話已畢，就上邱壇去了。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="撒母耳記上 14:50; 列王紀下 5:25; 撒母耳記上 9:3–10"> 掃羅的叔叔問掃羅和他僕人說：「你們往哪裏去了？」回答說：「找驢去了。我們見沒有驢，就到了撒母耳那裏。」</span>
<span className="v" id="v15" data-v="15"> 掃羅的叔叔說：「請將撒母耳向你們所說的話告訴我。」</span>
<span className="v" id="v16" data-v="16" data-xref="箴言 29:11; 士師記 14:6; 撒母耳記上 9:20"> 掃羅對他叔叔說：「他明明地告訴我們驢已經找着了。」至於撒母耳所說的國事，掃羅卻沒有告訴叔叔。</span>
</div>

## 抽籤得掃羅為王

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="士師記 20:1; 撒母耳記上 7:5–6"> 撒母耳將百姓招聚到米斯巴耶和華那裏，</span>
<span className="v" id="v18" data-v="18" data-xref="士師記 6:8–9; 尼希米記 9:27–28; 士師記 2:1"> 對他們說：「耶和華－以色列的上帝如此說：『我領你們以色列人出埃及，救你們脫離埃及人的手，又救你們脫離欺壓你們各國之人的手。』</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳記上 12:12; 撒母耳記上 8:19; 約書亞記 24:1"> 你們今日卻厭棄了救你們脫離一切災難的上帝，說：『求你立一個王治理我們。』現在你們應當按着支派、宗族都站在耶和華面前。」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="約書亞記 7:16–18; 使徒行傳 1:24–26; 撒母耳記上 14:41"> 於是，撒母耳使以色列眾支派近前來掣籤，就掣出便雅憫支派來；</span>
<span className="v" id="v21" data-v="21"> 又使便雅憫支派按着宗族近前來，就掣出瑪特利族，從其中又掣出基士的兒子掃羅。眾人尋找他卻尋不着，</span>
<span className="v" id="v22" data-v="22" data-xref="民數記 27:21; 士師記 20:18; 撒母耳記上 23:2–4"> 就問耶和華說：「那人到這裏來了沒有？」耶和華說：「他藏在器具中了。」</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳記上 9:2; 撒母耳記上 16:7; 撒母耳記上 17:4"> 眾人就跑去從那裏領出他來。他站在百姓中間，身體比眾民高過一頭。</span>
<span className="v" id="v24" data-v="24" data-xref="列王紀上 1:25; 列王紀上 1:39; 撒母耳記下 21:6"> 撒母耳對眾民說：「你們看耶和華所揀選的人，眾民中有可比他的嗎？」眾民就大聲歡呼說：「願王萬歲！」</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="撒母耳記上 8:11–18; 申命記 17:14–20; 羅馬書 13:1–7"> 撒母耳將國法對百姓說明，又記在書上，放在耶和華面前，然後遣散眾民，各回各家去了。</span>
<span className="v" id="v26" data-v="26" data-xref="撒母耳記上 11:4; 約書亞記 18:28; 撒母耳記上 15:34"> 掃羅往基比亞回家去，有上帝感動的一群人跟隨他。</span>
<span className="v" id="v27" data-v="27" data-xref="申命記 13:13; 歷代志下 17:5; 列王紀上 10:25"> 但有些匪徒說：「這人怎能救我們呢？」就藐視他，沒有送他禮物；掃羅卻不理會。</span>
</div>
</div>

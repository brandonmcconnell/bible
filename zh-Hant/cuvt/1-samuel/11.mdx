## 掃羅擊敗亞捫人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳記上 12:12; 列王紀上 20:34; 以西結書 17:13"> 亞捫人的王拿轄上來，對着基列‧雅比安營。雅比眾人對拿轄說：「你與我們立約，我們就服事你。」</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳記上 17:26; 創世記 34:14; 民數記 16:14"> 亞捫人拿轄說：「你們若由我剜出你們各人的右眼，以此凌辱以色列眾人，我就與你們立約。」</span>
<span className="v" id="v3" data-v="3"> 雅比的長老對他說：「求你寬容我們七日，等我們打發人往以色列的全境去；若沒有人救我們，我們就出來歸順你。」</span>
<span className="v" id="v4" data-v="4" data-xref="士師記 2:4; 撒母耳記上 10:26; 撒母耳記上 15:34"> 使者到了掃羅住的基比亞，將這話說給百姓聽，百姓就都放聲而哭。</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀上 19:19; 士師記 18:23; 創世記 21:17"> 掃羅正從田間趕牛回來，問說：「百姓為甚麼哭呢？」眾人將雅比人的話告訴他。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳記上 10:10; 撒母耳記上 16:13; 士師記 6:34"> 掃羅聽見這話，就被上帝的靈大大感動，甚是發怒。</span>
<span className="v" id="v7" data-v="7" data-xref="士師記 19:29; 士師記 20:1; 士師記 21:5–11"> 他將一對牛切成塊子，託付使者傳送以色列的全境，說：「凡不出來跟隨掃羅和撒母耳的，也必這樣切開他的牛。」於是耶和華使百姓懼怕，他們就都出來，如同一人。</span>
<span className="v" id="v8" data-v="8" data-xref="士師記 1:4–5; 撒母耳記下 24:9; 歷代志下 17:12–19"> 掃羅在比色數點他們：以色列人有三十萬，猶大人有三萬。</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 18:17"> 眾人對那使者說：「你們要回覆基列‧雅比人說，明日太陽近午的時候，你們必得解救。」使者回去告訴雅比人，他們就歡喜了。</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳記上 11:2–3"> 於是雅比人對亞捫人說：「明日我們出來歸順你們，你們可以隨意待我們。」</span>
<span className="v" id="v11" data-v="11" data-xref="士師記 7:16; 雅各書 2:13; 出埃及記 14:24"> 第二日，掃羅將百姓分為三隊，在晨更的時候入了亞捫人的營，擊殺他們直到太陽近午，剩下的人都逃散，沒有二人同在一處的。</span>
<span className="v" id="v12" data-v="12" data-xref="撒母耳記上 10:27; 路加福音 19:27; 詩篇 21:8"> 百姓對撒母耳說：「那說『掃羅豈能管理我們』的是誰呢？可以將他交出來，我們好殺死他。」</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳記下 19:22; 撒母耳記上 19:5; 出埃及記 14:13"> 掃羅說：「今日耶和華在以色列中施行拯救，所以不可殺人。」</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳記上 10:8; 撒母耳記上 7:16; 歷代志上 12:38–39"> 撒母耳對百姓說：「我們要往吉甲去，在那裏立國。」</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳記上 10:8; 撒母耳記上 10:17; 歷代志上 29:21–24"> 眾百姓就到了吉甲那裏，在耶和華面前立掃羅為王，又在耶和華面前獻平安祭。掃羅和以色列眾人大大歡喜。</span>

## 耶和華的慈愛

<div className="bt">
<div className="hs">大衛的詩。</div>
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="詩篇 146:1–2; 詩篇 57:7–11; 約翰福音 4:24"> <span className="pl pl-1">我的心哪，你要稱頌耶和華！</span><br /><span className="pl pl-1">凡在我裏面的，也要稱頌他的聖名！</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="以賽亞書 63:7; 詩篇 116:12; 詩篇 105:5"> <span className="pl pl-1">我的心哪，你要稱頌耶和華！</span><br /><span className="pl pl-1">不可忘記他的一切恩惠！</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 15:26; 以賽亞書 53:5; 耶利米書 17:14"> <span className="pl pl-1">他赦免你的一切罪孽，</span><br /><span className="pl pl-1">醫治你的一切疾病。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="詩篇 56:13; 詩篇 71:23; 詩篇 103:12"> <span className="pl pl-1">他救贖你的命脫離死亡，</span><br /><span className="pl pl-1">以仁愛和慈悲為你的冠冕。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="以賽亞書 40:31; 詩篇 107:9; 提摩太前書 6:17"> <span className="pl pl-1">他用美物使你所願的得以知足，</span><br /><span className="pl pl-1">以致你如鷹返老還童。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="詩篇 9:9; 詩篇 12:5; 詩篇 72:12"> <span className="pl pl-1">耶和華施行公義，</span><br /><span className="pl pl-1">為一切受屈的人伸冤。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="出埃及記 33:13; 詩篇 147:19; 詩篇 78:11"> <span className="pl pl-1">他使摩西知道他的法則，</span><br /><span className="pl pl-1">叫以色列人曉得他的作為。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 86:15; 約珥書 2:13; 出埃及記 34:6–7"> <span className="pl pl-1">耶和華有憐憫，有恩典，</span><br /><span className="pl pl-1">不輕易發怒，且有豐盛的慈愛。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="以賽亞書 57:16; 詩篇 30:5; 彌迦書 7:18–19"> <span className="pl pl-1">他不長久責備，</span><br /><span className="pl pl-1">也不永遠懷怒。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="以斯拉記 9:13; 耶利米哀歌 3:22; 尼希米記 9:31"> <span className="pl pl-1">他沒有按我們的罪過待我們，</span><br /><span className="pl pl-1">也沒有照我們的罪孽報應我們。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 57:10; 路加福音 1:50; 詩篇 36:5"> <span className="pl pl-1">天離地何等的高，</span><br /><span className="pl pl-1">他的慈愛向敬畏他的人也是何等的大！</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="以賽亞書 43:25; 約翰一書 1:7; 彌迦書 7:18"> <span className="pl pl-1">東離西有多遠，</span><br /><span className="pl pl-1">他叫我們的過犯離我們也有多遠！</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 11:11–12; 希伯來書 12:5–11; 路加福音 15:21–22"> <span className="pl pl-1">父親怎樣憐恤他的兒女，</span><br /><span className="pl pl-1">耶和華也怎樣憐恤敬畏他的人！</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="傳道書 12:7; 約伯記 10:9; 詩篇 78:38–39"> <span className="pl pl-1">因為他知道我們的本體，</span><br /><span className="pl pl-1">思念我們不過是塵土。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="彼得前書 1:24; 雅各書 1:10–11; 以賽亞書 51:12"> <span className="pl pl-1">至於世人，他的年日如草一樣。</span><br /><span className="pl pl-1">他發旺如野地的花，</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="以賽亞書 40:7; 約伯記 20:9; 約伯記 14:10"> <span className="pl pl-1">經風一吹，便歸無有；</span><br /><span className="pl pl-1">它的原處也不再認識它。</span><br /></span>

<span className="v" id="v18" data-v="18" data-xref="申命記 7:9; 詩篇 132:12; 路加福音 1:6"> <span className="pl pl-1">就是那些遵守他的約、</span><br /><span className="pl pl-1">記念他的訓詞而遵行的人。</span></span>
</div>

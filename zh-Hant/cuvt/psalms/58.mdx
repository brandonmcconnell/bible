## 求上帝罰惡

<div className="bt">
<div className="hs">大衛的金詩，交與伶長。調用休要毀壞。</div>
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="詩篇 57:1; 申命記 16:18–19; 詩篇 72:1–4"> <span className="pl pl-1">世人哪，你們默然不語，真合公義嗎？</span><br /><span className="pl pl-1">施行審判，豈按正直嗎？</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="詩篇 94:20; 以賽亞書 10:1; 以西結書 22:27"> <span className="pl pl-1">不然！你們是心中作惡；</span><br /><span className="pl pl-1">你們在地上秤出你們手所行的強暴。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v3" data-v="3" data-xref="詩篇 51:5; 以賽亞書 48:8; 箴言 22:15"> <span className="pl pl-1">惡人一出母胎就與上帝疏遠，</span><br /><span className="pl pl-1">一離母腹便走錯路，說謊話。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="詩篇 140:3; 雅各書 3:8; 傳道書 10:11"> <span className="pl pl-1">他們的毒氣好像蛇的毒氣；</span><br /><span className="pl pl-1">他們好像塞耳的聾虺，</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="耶利米書 8:17; 以賽亞書 19:3; 申命記 18:11"> <span className="pl pl-1">不聽行法術的聲音，</span><br /><span className="pl pl-1">雖用極靈的咒語也是不聽。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="詩篇 3:7; 約伯記 4:10–11; 何西阿書 5:14"> <span className="pl pl-1">上帝啊，求你敲碎他們口中的牙！</span><br /><span className="pl pl-1">耶和華啊，求你敲掉少壯獅子的大牙！</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 112:10; 約書亞記 7:5; 詩篇 64:3"> <span className="pl pl-1">願他們消滅，如急流的水一般；</span><br /><span className="pl pl-1">他們瞅準射箭的時候，願箭頭彷彿砍斷。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="約伯記 3:16; 傳道書 6:3; 詩篇 37:35–36"> <span className="pl pl-1">願他們像蝸牛消化過去，</span><br /><span className="pl pl-1">又像婦人墜落未見天日的胎。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 118:12; 箴言 10:25; 傳道書 7:6"> <span className="pl pl-1">你們用荊棘燒火，鍋還未熱，</span><br /><span className="pl pl-1">他要用旋風把青的和燒着的一齊颳去。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="詩篇 68:23; 詩篇 91:8; 詩篇 64:10"> <span className="pl pl-1">義人見仇敵遭報就歡喜，</span><br /><span className="pl pl-1">要在惡人的血中洗腳。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 67:4; 以賽亞書 3:10; 詩篇 64:9"> <span className="pl pl-1">因此，人必說：義人誠然有善報；</span><br /><span className="pl pl-1">在地上果有施行判斷的上帝！</span></span>
</div>

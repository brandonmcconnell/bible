## 上帝的審判和恩惠

<div className="bt">
<div className="hs">以東人多益來告訴掃羅說：「大衛到了亞希米勒家。」那時，大衛作這訓誨詩，交與伶長。</div>
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="詩篇 103:17; 詩篇 94:4; 詩篇 107:1"> <span className="pl pl-1">勇士啊，你為何以作惡自誇？</span><br /><span className="pl pl-1">上帝的慈愛是常存的。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="箴言 18:21; 詩篇 57:4; 耶利米書 9:3–4"> <span className="pl pl-1">你的舌頭邪惡詭詐，</span><br /><span className="pl pl-1">好像剃頭刀，快利傷人。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="耶利米書 9:3–5; 提摩太後書 3:4; 約翰福音 8:44"> <span className="pl pl-1">你愛惡勝似愛善，</span><br /><span className="pl pl-1">又愛說謊，不愛說公義。（細拉）</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="詩篇 120:3; 雅各書 3:6–9; 撒母耳記上 22:18–19"> <span className="pl pl-1">詭詐的舌頭啊，</span><br /><span className="pl pl-1">你愛說一切毀滅的話！</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="箴言 2:22; 詩篇 27:13; 啟示錄 21:8"> <span className="pl pl-1">上帝也要毀滅你，直到永遠；</span><br /><span className="pl pl-1">他要把你拿去，從你的帳棚中抽出，</span><br /><span className="pl pl-1">從活人之地將你拔出。（細拉）</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="約伯記 22:19; 詩篇 40:3; 詩篇 37:34"> <span className="pl pl-1">義人要看見而懼怕，</span><br /><span className="pl pl-1">並要笑他，</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="耶利米書 17:5; 詩篇 73:18–20; 傳道書 8:8"> <span className="pl pl-1">說：看哪，這就是那不以上帝為他力量的人，</span><br /><span className="pl pl-1">只倚仗他豐富的財物，在邪惡上堅立自己。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="詩篇 92:12–14; 詩篇 1:3; 何西阿書 14:6–8"> <span className="pl pl-1">至於我，就像上帝殿中的青橄欖樹；</span><br /><span className="pl pl-1">我永永遠遠倚靠上帝的慈愛。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 130:5–6; 耶利米哀歌 3:25–26; 詩篇 54:6"> <span className="pl pl-1">我要稱謝你，直到永遠，</span><br /><span className="pl pl-1">因為你行了這事。</span><br /><span className="pl pl-1">我也要在你聖民面前仰望你的名；</span><br /><span className="pl pl-1">這名本為美好。</span></span>
</div>

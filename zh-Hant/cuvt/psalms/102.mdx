## 遭難中的祈禱

<div className="bt">
<div className="hs">困苦人發昏的時候，在耶和華面前吐露苦情的禱告。</div>
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="詩篇 18:6; 詩篇 130:1–2; 詩篇 142:2–3"> <span className="pl pl-1">耶和華啊，求你聽我的禱告，</span><br /><span className="pl pl-1">容我的呼求達到你面前！</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="詩篇 69:17; 詩篇 27:9; 以賽亞書 8:17"> <span className="pl pl-1">我在急難的日子，求你向我側耳；</span><br /><span className="pl pl-1">不要向我掩面！</span><br /><span className="pl pl-1">我呼求的日子，求你快快應允我！</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v3" data-v="3" data-xref="雅各書 4:14; 詩篇 37:20; 約伯記 30:30"> <span className="pl pl-1">因為，我的年日如煙雲消滅；</span><br /><span className="pl pl-1">我的骨頭如火把燒着。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="以賽亞書 40:7; 詩篇 37:2; 詩篇 77:3"> <span className="pl pl-1">我的心被傷，如草枯乾，</span><br /><span className="pl pl-1">甚至我忘記吃飯。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="約伯記 19:20; 耶利米哀歌 4:8; 詩篇 6:8"> <span className="pl pl-1">因我唉哼的聲音，</span><br /><span className="pl pl-1">我的肉緊貼骨頭。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="西番雅書 2:14; 以賽亞書 38:14; 以賽亞書 34:11–15"> <span className="pl pl-1">我如同曠野的鵜鶘；</span><br /><span className="pl pl-1">我好像荒場的鴞鳥。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 77:4; 詩篇 38:11; 申命記 28:66–67"> <span className="pl pl-1">我警醒不睡；</span><br /><span className="pl pl-1">我像房頂上孤單的麻雀。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="使徒行傳 26:11; 詩篇 69:9–10; 以賽亞書 65:15"> <span className="pl pl-1">我的仇敵終日辱罵我；</span><br /><span className="pl pl-1">向我猖狂的人指着我賭咒。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 42:3; 詩篇 80:5; 彌迦書 1:10"> <span className="pl pl-1">我吃過爐灰，如同吃飯；</span><br /><span className="pl pl-1">我所喝的與眼淚攙雜。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 38:3; 詩篇 90:7–9; 詩篇 147:6"> <span className="pl pl-1">這都因你的惱恨和忿怒；</span><br /><span className="pl pl-1">你把我拾起來，又把我摔下去。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="約伯記 14:2; 詩篇 109:23; 詩篇 144:4"> <span className="pl pl-1">我的年日如日影偏斜；</span><br /><span className="pl pl-1">我也如草枯乾。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="詩篇 135:13; 耶利米哀歌 5:19; 出埃及記 3:15"> <span className="pl pl-1">惟你－耶和華必存到永遠；</span><br /><span className="pl pl-1">你可記念的名也存到萬代。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="以賽亞書 60:1; 加拉太書 4:4; 以賽亞書 40:2"> <span className="pl pl-1">你必起來憐恤錫安，</span><br /><span className="pl pl-1">因現在是可憐她的時候，</span><br /><span className="pl pl-1">日期已經到了。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="尼希米記 4:2; 以斯拉記 7:27; 以斯拉記 3:1–3"> <span className="pl pl-1">你的僕人原來喜悅她的石頭，</span><br /><span className="pl pl-1">可憐她的塵土。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="列王紀上 8:43; 詩篇 138:4; 以賽亞書 60:3–22"> <span className="pl pl-1">列國要敬畏耶和華的名；</span><br /><span className="pl pl-1">世上諸王都敬畏你的榮耀。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="以賽亞書 60:1–2; 詩篇 147:2; 耶利米書 33:7"> <span className="pl pl-1">因為耶和華建造了錫安，</span><br /><span className="pl pl-1">在他榮耀裏顯現。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="尼希米記 1:6; 詩篇 22:24; 耶利米書 29:11–14"> <span className="pl pl-1">他垂聽窮人的禱告，</span><br /><span className="pl pl-1">並不藐視他們的祈求。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v18" data-v="18" data-xref="詩篇 22:30–31; 羅馬書 15:4; 以賽亞書 43:21"> <span className="pl pl-1">這必為後代的人記下，</span><br /><span className="pl pl-1">將來受造的民要讚美耶和華。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="申命記 26:15; 詩篇 14:2; 列王紀上 8:43"> <span className="pl pl-1">因為，他從至高的聖所垂看；</span><br /><span className="pl pl-1">耶和華從天向地觀察，</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 79:11; 詩篇 146:7; 出埃及記 3:7"> <span className="pl pl-1">要垂聽被囚之人的歎息，</span><br /><span className="pl pl-1">要釋放將要死的人，</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 22:22; 以賽亞書 51:11; 詩篇 79:13"> <span className="pl pl-1">使人在錫安傳揚耶和華的名，</span><br /><span className="pl pl-1">在耶路撒冷傳揚讚美他的話，</span><br /></span>

<div className="bp poetry">
<span className="v" id="v23" data-v="23" data-xref="詩篇 89:38–47; 提摩太前書 4:1–3; 帖撒羅尼迦後書 2:3–12"> <span className="pl pl-1">他使我的力量中道衰弱，</span><br /><span className="pl pl-1">使我的年日短少。</span><br /></span>

</div>

<span className="v" id="v25" data-v="25" data-xref="創世記 1:1; 出埃及記 20:11; 希伯來書 1:10–12"> <span className="pl pl-1">你起初立了地的根基；</span><br /><span className="pl pl-1">天也是你手所造的。</span><br /></span>

</div>

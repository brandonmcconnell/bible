## 求主保護

<div className="bt">
<div className="hs">大衛的詩，交與伶長。</div>
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="詩篇 34:4; 詩篇 143:1–3; 耶利米哀歌 3:55–56"> <span className="pl pl-1">上帝啊，我哀歎的時候，求你聽我的聲音！</span><br /><span className="pl pl-1">求你保護我的性命，不受仇敵的驚恐！</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="詩篇 143:9; 詩篇 59:2; 詩篇 109:2–3"> <span className="pl pl-1">求你把我隱藏，</span><br /><span className="pl pl-1">使我脫離作惡之人的暗謀和作孽之人的擾亂。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 57:4; 詩篇 58:7; 雅各書 3:6–8"> <span className="pl pl-1">他們磨舌如刀，</span><br /><span className="pl pl-1">發出苦毒的言語，好像比準了的箭，</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="詩篇 55:19; 詩篇 11:2; 彼得前書 2:22–23"> <span className="pl pl-1">要在暗地射完全人；</span><br /><span className="pl pl-1">他們忽然射他，並不懼怕。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 140:5; 詩篇 10:11; 以西結書 8:12"> <span className="pl pl-1">他們彼此勉勵設下惡計；</span><br /><span className="pl pl-1">他們商量暗設網羅，</span><br /><span className="pl pl-1">說：誰能看見？</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="耶利米書 17:9–10; 馬太福音 26:59; 詩篇 5:9"> <span className="pl pl-1">他們圖謀奸惡，</span><br /><span className="pl pl-1">說：我們是極力圖謀的。</span><br /><span className="pl pl-1">他們各人的意念心思是深的。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="詩篇 7:12–13; 帖撒羅尼迦前書 5:2–3; 箴言 6:15"> <span className="pl pl-1">但上帝要射他們；</span><br /><span className="pl pl-1">他們忽然被箭射傷。</span><br /></span>

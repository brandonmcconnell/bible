## 病中祈禱

<div className="bt">
<div className="hs">大衛的詩，交與伶長。</div>
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="箴言 19:17; 箴言 14:21; 哥林多後書 9:8–14"> <span className="pl pl-1">眷顧貧窮的有福了！</span><br /><span className="pl pl-1">他遭難的日子，耶和華必搭救他。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="耶利米書 45:4–5; 詩篇 27:12; 提摩太前書 4:8"> <span className="pl pl-1">耶和華必保全他，使他存活；</span><br /><span className="pl pl-1">他必在地上享福。</span><br /><span className="pl pl-1">求你不要把他交給仇敵，遂其所願。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="列王紀下 20:5–6; 詩篇 73:26; 腓立比書 2:26–27"> <span className="pl pl-1">他病重在榻，耶和華必扶持他；</span><br /><span className="pl pl-1">他在病中，你必給他鋪床。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v4" data-v="4" data-xref="詩篇 103:3; 雅各書 5:15–16; 歷代志下 30:18–20"> <span className="pl pl-1">我曾說：耶和華啊，求你憐恤我，醫治我！</span><br /><span className="pl pl-1">因為我得罪了你。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="箴言 10:7; 詩篇 102:8; 詩篇 38:12"> <span className="pl pl-1">我的仇敵用惡言議論我說：</span><br /><span className="pl pl-1">他幾時死，他的名才滅亡呢？</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 12:2; 路加福音 11:53–54; 箴言 26:24–26"> <span className="pl pl-1">他來看我就說假話；</span><br /><span className="pl pl-1">他心存奸惡，走到外邊才說出來。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="箴言 16:28; 詩篇 56:5–6; 詩篇 31:13"> <span className="pl pl-1">一切恨我的，都交頭接耳地議論我；</span><br /><span className="pl pl-1">他們設計要害我。</span></span>
</div>
<div className="bp poetry">

<span className="v" id="v10" data-v="10" data-xref="詩篇 21:8–10; 路加福音 19:27; 詩篇 18:37–42"> <span className="pl pl-1">耶和華啊，求你憐恤我，</span><br /><span className="pl pl-1">使我起來，好報復他們！</span></span>
</div>

<span className="v" id="v11" data-v="11" data-xref="歌羅西書 2:15; 詩篇 124:6; 詩篇 147:11"> <span className="pl pl-1">因我的仇敵不得向我誇勝，</span><br /><span className="pl pl-1">我從此便知道你喜愛我。</span><br /></span>

## 義人和惡人的結局

<div className="bt">
<div className="hs">大衛的詩。</div>
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="詩篇 37:7; 箴言 23:17; 箴言 24:19"> <span className="pl pl-1">不要為作惡的心懷不平，</span><br /><span className="pl pl-1">也不要向那行不義的生出嫉妒。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="詩篇 92:7; 詩篇 90:5–6; 雅各書 1:10–11"> <span className="pl pl-1">因為他們如草快被割下，</span><br /><span className="pl pl-1">又如青菜快要枯乾。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v3" data-v="3" data-xref="耶利米書 17:7–8; 馬太福音 6:31–33; 詩篇 62:8"> <span className="pl pl-1">你當倚靠耶和華而行善，</span><br /><span className="pl pl-1">住在地上，以他的信實為糧；</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="約翰福音 15:7; 詩篇 145:19; 約翰福音 15:16"> <span className="pl pl-1">又要以耶和華為樂，</span><br /><span className="pl pl-1">他就將你心裏所求的賜給你。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="箴言 16:3; 彼得前書 5:7; 腓立比書 4:6–7"> <span className="pl pl-1">當將你的事交託耶和華，</span><br /><span className="pl pl-1">並倚靠他，他就必成全。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="以賽亞書 54:17; 約伯記 11:17; 以賽亞書 58:8"> <span className="pl pl-1">他要使你的公義如光發出，</span><br /><span className="pl pl-1">使你的公平明如正午。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="雅各書 5:7–11; 詩篇 27:14; 詩篇 62:5"> <span className="pl pl-1">你當默然倚靠耶和華，耐性等候他；</span><br /><span className="pl pl-1">不要因那道路通達的和那惡謀成就的心懷不平。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="箴言 14:29; 箴言 16:32; 雅各書 1:19–20"> <span className="pl pl-1">當止住怒氣，離棄忿怒；</span><br /><span className="pl pl-1">不要心懷不平，以致作惡。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="以賽亞書 60:21; 詩篇 25:13; 詩篇 37:29"> <span className="pl pl-1">因為作惡的必被剪除；</span><br /><span className="pl pl-1">惟有等候耶和華的必承受地土。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="約伯記 24:24; 詩篇 103:16; 詩篇 37:35–36"> <span className="pl pl-1">還有片時，惡人要歸於無有；</span><br /><span className="pl pl-1">你就是細察他的住處也要歸於無有。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="馬太福音 5:5; 加拉太書 5:22–23; 以賽亞書 26:3"> <span className="pl pl-1">但謙卑人必承受地土，</span><br /><span className="pl pl-1">以豐盛的平安為樂。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="彌迦書 2:1; 詩篇 35:16; 詩篇 31:13"> <span className="pl pl-1">惡人設謀害義人，</span><br /><span className="pl pl-1">又向他咬牙。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 2:4; 箴言 1:26; 撒母耳記上 26:10"> <span className="pl pl-1">主要笑他，</span><br /><span className="pl pl-1">因見他受罰的日子將要來到。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="箴言 29:27; 詩篇 11:2; 約翰一書 3:12"> <span className="pl pl-1">惡人已經弓上弦，刀出鞘，</span><br /><span className="pl pl-1">要打倒困苦窮乏的人，</span><br /><span className="pl pl-1">要殺害行動正直的人。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 7:14–15; 詩篇 35:8; 耶利米書 51:56"> <span className="pl pl-1">他們的刀必刺入自己的心；</span><br /><span className="pl pl-1">他們的弓必被折斷。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v16" data-v="16" data-xref="箴言 16:8; 箴言 15:16–17; 提摩太前書 6:6"> <span className="pl pl-1">一個義人所有的雖少，</span><br /><span className="pl pl-1">強過許多惡人的富餘。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="以賽亞書 41:10; 詩篇 63:8; 詩篇 145:14"> <span className="pl pl-1">因為惡人的膀臂必被折斷；</span><br /><span className="pl pl-1">但耶和華是扶持義人。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v18" data-v="18" data-xref="詩篇 1:6; 羅馬書 6:23; 詩篇 103:17"> <span className="pl pl-1">耶和華知道完全人的日子；</span><br /><span className="pl pl-1">他們的產業要存到永遠。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="詩篇 33:19; 箴言 10:3; 約伯記 5:20–22"> <span className="pl pl-1">他們在急難的時候不致羞愧，</span><br /><span className="pl pl-1">在饑荒的日子必得飽足。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v20" data-v="20" data-xref="詩篇 68:2; 詩篇 102:3; 路加福音 13:3"> <span className="pl pl-1">惡人卻要滅亡。</span><br /><span className="pl pl-1">耶和華的仇敵要像羊羔的脂油</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或譯：像草地的華美">a</a></sup><br /><span className="pl pl-1">；</span><br /><span className="pl pl-1">他們要消滅，要如煙消滅。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v21" data-v="21" data-xref="希伯來書 13:16; 詩篇 112:5; 箴言 22:7"> <span className="pl pl-1">惡人借貸而不償還；</span><br /><span className="pl pl-1">義人卻恩待人，並且施捨。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="箴言 3:33; 哥林多前書 16:22; 加拉太書 3:13"> <span className="pl pl-1">蒙耶和華賜福的必承受地土；</span><br /><span className="pl pl-1">被他咒詛的必被剪除。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v23" data-v="23" data-xref="箴言 16:9; 詩篇 119:133; 箴言 4:26"> <span className="pl pl-1">義人的腳步被耶和華立定；</span><br /><span className="pl pl-1">他的道路，耶和華也喜愛。</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="箴言 24:16; 詩篇 145:14; 詩篇 94:18"> <span className="pl pl-1">他雖失腳也不致全身仆倒，</span><br /><span className="pl pl-1">因為耶和華用手攙扶他</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或譯：攙扶他的手">b</a></sup><br /><span className="pl pl-1">。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v25" data-v="25" data-xref="希伯來書 13:5; 詩篇 37:28; 詩篇 112:2"> <span className="pl pl-1">我從前年幼，現在年老，</span><br /><span className="pl pl-1">卻未見過義人被棄，</span><br /><span className="pl pl-1">也未見過他的後裔討飯。</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="詩篇 112:5; 馬太福音 5:7; 詩篇 37:21"> <span className="pl pl-1">他終日恩待人，借給人；</span><br /><span className="pl pl-1">他的後裔也蒙福！</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v27" data-v="27" data-xref="詩篇 34:14; 箴言 16:6; 約翰一書 2:16–17"> <span className="pl pl-1">你當離惡行善，</span><br /><span className="pl pl-1">就可永遠安居。</span><br /></span>
<span className="v" id="v28" data-v="28" data-xref="詩篇 11:7; 箴言 2:22; 詩篇 21:10"> <span className="pl pl-1">因為，耶和華喜愛公平，</span><br /><span className="pl pl-1">不撇棄他的聖民；</span><br /><span className="pl pl-1">他們永蒙保佑，</span><br /><span className="pl pl-1">但惡人的後裔必被剪除。</span><br /></span>
<span className="v" id="v29" data-v="29" data-xref="箴言 2:21; 詩篇 37:9; 彼得後書 3:13"> <span className="pl pl-1">義人必承受地土，</span><br /><span className="pl pl-1">永居其上。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v30" data-v="30" data-xref="歌羅西書 4:6; 箴言 25:11–13; 以弗所書 4:29"> <span className="pl pl-1">義人的口談論智慧；</span><br /><span className="pl pl-1">他的舌頭講說公平。</span><br /></span>
<span className="v" id="v31" data-v="31" data-xref="詩篇 40:8; 申命記 6:6; 以賽亞書 51:7"> <span className="pl pl-1">上帝的律法在他心裏；</span><br /><span className="pl pl-1">他的腳總不滑跌。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v32" data-v="32" data-xref="路加福音 19:47–48; 詩篇 10:8–10; 詩篇 37:12"> <span className="pl pl-1">惡人窺探義人，</span><br /><span className="pl pl-1">想要殺他。</span><br /></span>

</div>
<div className="bp poetry">
<span className="v" id="v34" data-v="34" data-xref="詩篇 27:14; 詩篇 37:9; 箴言 20:22"> <span className="pl pl-1">你當等候耶和華，遵守他的道，</span><br /><span className="pl pl-1">他就抬舉你，使你承受地土；</span><br /><span className="pl pl-1">惡人被剪除的時候，你必看見。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v35" data-v="35" data-xref="約伯記 5:3; 以西結書 31:18; 以賽亞書 14:14–19"> <span className="pl pl-1">我見過惡人大有勢力，</span><br /><span className="pl pl-1">好像一棵青翠樹在本土生發。</span><br /></span>

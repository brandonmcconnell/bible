## 義人之福

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="詩篇 128:1; 路加福音 1:50; 以賽亞書 50:10"> <span className="pl pl-1">你們要讚美耶和華！</span><br /><span className="pl pl-1">敬畏耶和華，甚喜愛他命令的，</span><br /><span className="pl pl-1">這人便為有福！</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="創世記 17:7; 箴言 20:7; 詩篇 37:26"> <span className="pl pl-1">他的後裔在世必強盛；</span><br /><span className="pl pl-1">正直人的後代必要蒙福。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="箴言 15:6; 箴言 3:16; 馬太福音 6:33"> <span className="pl pl-1">他家中有貨物，有錢財；</span><br /><span className="pl pl-1">他的公義存到永遠。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="約伯記 11:17; 詩篇 97:11; 歌羅西書 3:12–13"> <span className="pl pl-1">正直人在黑暗中，有光向他發現；</span><br /><span className="pl pl-1">他有恩惠，有憐憫，有公義。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 37:21; 箴言 2:20; 以弗所書 5:15"> <span className="pl pl-1">施恩與人、借貸與人的，這人事情順利；</span><br /><span className="pl pl-1">他被審判的時候要訴明自己的冤。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="箴言 10:7; 詩篇 125:1; 詩篇 62:2"> <span className="pl pl-1">他永不動搖；</span><br /><span className="pl pl-1">義人被記念，直到永遠。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="以賽亞書 26:3–4; 箴言 1:33; 詩篇 57:7"> <span className="pl pl-1">他必不怕凶惡的信息；</span><br /><span className="pl pl-1">他心堅定，倚靠耶和華。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 59:10; 詩篇 31:24; 詩篇 118:7"> <span className="pl pl-1">他心確定，總不懼怕，</span><br /><span className="pl pl-1">直到他看見敵人遭報。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 75:10; 希伯來書 13:16; 雅各書 2:15–16"> <span className="pl pl-1">他施捨錢財，賙濟貧窮；</span><br /><span className="pl pl-1">他的仁義存到永遠。</span><br /><span className="pl pl-1">他的角必被高舉，大有榮耀。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 58:7–8; 箴言 11:7; 箴言 10:28"> <span className="pl pl-1">惡人看見便惱恨，必咬牙而消化；</span><br /><span className="pl pl-1">惡人的心願要歸滅絕。</span></span>

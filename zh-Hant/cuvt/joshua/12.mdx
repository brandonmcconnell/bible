## 摩西擊敗的諸王

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命記 3:8–9; 士師記 11:18; 約書亞記 1:15"> 以色列人在約旦河外向日出之地擊殺二王，得他們的地，就是從亞嫩谷直到黑門山，並東邊的全亞拉巴之地。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 32:22; 士師記 11:22; 詩篇 136:19–20"> 這二王，有住希實本、亞摩利人的王西宏。他所管之地是從亞嫩谷邊的亞羅珥和谷中的城，並基列一半，直到亞捫人的境界，雅博河</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 3:17; 約書亞記 13:20; 約書亞記 11:2"> 與約旦河東邊的亞拉巴，直到基尼烈海，又到亞拉巴的海，就是鹽海，通伯‧耶西末的路，以及南方，直到毗斯迦的山根。</span>
<span className="v" id="v4" data-v="4" data-xref="申命記 1:4; 申命記 3:10–11; 約書亞記 13:12"> 又有巴珊王噩。他是利乏音人所剩下的，住在亞斯他錄和以得來。</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 3:14; 撒母耳記上 27:8; 約書亞記 13:11"> 他所管之地是黑門山、撒迦、巴珊全地，直到基述人和瑪迦人的境界，並基列一半，直到希實本王西宏的境界。</span>
<span className="v" id="v6" data-v="6" data-xref="民數記 32:33; 民數記 32:29; 路加福音 22:29–42"> 這二王是耶和華僕人摩西和以色列人所擊殺的；耶和華僕人摩西將他們的地賜給呂便人、迦得人，和瑪拿西半支派的人為業。</span>
</div>
</div>

## 約書亞擊敗的諸王

<div className="bt">
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="約書亞記 11:17; 約書亞記 11:23–1; 約書亞記 1:3–4"> 約書亞和以色列人在約旦河西擊殺了諸王。他們的地是從黎巴嫩平原的巴力‧迦得，直到上西珥的哈拉山。約書亞就將那地按着以色列支派的宗族分給他們為業，</span>
<span className="v" id="v8" data-v="8" data-xref="約書亞記 11:16; 約書亞記 10:40; 約書亞記 9:1"> 就是赫人、亞摩利人、迦南人、比利洗人、希未人、耶布斯人的山地、高原亞拉巴、山坡、曠野，和南地。</span>
<span className="v" id="v9" data-v="9" data-xref="約書亞記 8:29–35; 約書亞記 6:2–21; 約書亞記 8:1"> 他們的王：一個是耶利哥王，一個是靠近伯特利的艾城王，</span>
<span className="v" id="v10" data-v="10" data-xref="約書亞記 10:23; 約書亞記 10:36–37; 約書亞記 10:3"> 一個是耶路撒冷王，一個是希伯崙王，</span>
<span className="v" id="v11" data-v="11" data-xref="約書亞記 10:31–32; 約書亞記 10:3–23"> 一個是耶末王，一個是拉吉王，</span>
<span className="v" id="v12" data-v="12" data-xref="約書亞記 10:33; 約書亞記 15:39; 約書亞記 10:3"> 一個是伊磯倫王，一個是基色王，</span>
<span className="v" id="v13" data-v="13" data-xref="約書亞記 10:38; 約書亞記 10:3; 約書亞記 15:36"> 一個是底璧王，一個是基德王，</span>
<span className="v" id="v14" data-v="14" data-xref="民數記 21:1; 民數記 14:45; 民數記 21:3"> 一個是何珥瑪王，一個是亞拉得王，</span>
<span className="v" id="v15" data-v="15" data-xref="約書亞記 10:29–30; 撒母耳記上 22:1"> 一個是立拿王，一個是亞杜蘭王，</span>
<span className="v" id="v16" data-v="16" data-xref="約書亞記 10:28; 士師記 1:22; 約書亞記 8:17"> 一個是瑪基大王，一個是伯特利王，</span>
<span className="v" id="v17" data-v="17" data-xref="列王紀上 4:10; 約書亞記 15:34; 約書亞記 19:13"> 一個是他普亞王，一個是希弗王，</span>
<span className="v" id="v18" data-v="18" data-xref="約書亞記 19:30; 以賽亞書 33:9; 約書亞記 13:4"> 一個是亞弗王，一個是拉沙崙王，</span>
<span className="v" id="v19" data-v="19" data-xref="約書亞記 11:1; 士師記 4:2; 約書亞記 11:10–11"> 一個是瑪頓王，一個是夏瑣王，</span>
<span className="v" id="v20" data-v="20" data-xref="約書亞記 11:1; 約書亞記 19:15; 約書亞記 19:25"> 一個是伸崙‧米崙王，一個是押煞王，</span>
<span className="v" id="v21" data-v="21" data-xref="約書亞記 17:11; 列王紀下 23:29–30; 士師記 5:19"> 一個是他納王，一個是米吉多王，</span>
<span className="v" id="v22" data-v="22" data-xref="約書亞記 19:37; 約書亞記 21:32; 約書亞記 15:23"> 一個是基低斯王，一個是靠近迦密的約念王，</span>
<span className="v" id="v23" data-v="23" data-xref="約書亞記 11:2; 創世記 14:1–2; 約書亞記 4:19"> 一個是多珥山岡的多珥王，一個是吉甲的戈印王，</span>
<span className="v" id="v24" data-v="24" data-xref="列王紀下 15:14; 列王紀上 16:23; 申命記 7:24"> 一個是得撒王；共計三十一個王。</span>

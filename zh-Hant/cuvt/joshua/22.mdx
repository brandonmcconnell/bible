## 約書亞打發二支派半的人回去

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民數記 32:18–33; 申命記 29:7–8"> 當時，約書亞召了呂便人、迦得人，和瑪拿西半支派的人來，</span>
<span className="v" id="v2" data-v="2" data-xref="約書亞記 1:12–18; 申命記 3:16–20; 民數記 32:20–29"> 對他們說：「耶和華僕人摩西所吩咐你們的，你們都遵守了；我所吩咐你們的，你們也都聽從了。</span>
<span className="v" id="v3" data-v="3" data-xref="腓立比書 1:23–27"> 你們這許多日子，總沒有撇離你們的弟兄，直到今日，並守了耶和華－你們上帝所吩咐你們當守的。</span>
<span className="v" id="v4" data-v="4" data-xref="約書亞記 13:8; 民數記 32:18; 申命記 3:20"> 如今耶和華－你們上帝照着他所應許的，使你們弟兄得享平安，現在可以轉回你們的帳棚，到耶和華的僕人摩西在約旦河東所賜你們為業之地。</span>
<span className="v" id="v5" data-v="5" data-xref="馬太福音 22:37; 出埃及記 20:6; 羅馬書 8:28"> 只要切切地謹慎遵行耶和華僕人摩西所吩咐你們的誡命律法，愛耶和華－你們的上帝，行他一切的道，守他的誡命，專靠他，盡心盡性事奉他。」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="約書亞記 14:13; 路加福音 24:50; 創世記 47:7"> 於是約書亞為他們祝福，打發他們去，他們就回自己的帳棚去了。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="約書亞記 17:1–12; 民數記 32:33; 約書亞記 13:29–31"> 瑪拿西那半支派，摩西早已在巴珊分給他們地業。這半支派，約書亞在約旦河西，在他們弟兄中，分給他們地業。約書亞打發他們回帳棚的時候為他們祝福，</span>
<span className="v" id="v8" data-v="8" data-xref="民數記 31:27; 申命記 8:9–14; 箴言 3:16"> 對他們說：「你們帶許多財物，許多牲畜和金、銀、銅、鐵，並許多衣服，回你們的帳棚去，要將你們從仇敵奪來的物，與你們眾弟兄同分。」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="民數記 32:29; 民數記 32:26; 民數記 32:1"> 於是呂便人、迦得人、瑪拿西半支派的人從迦南地的示羅起行，離開以色列人，回往他們得為業的基列地，就是照耶和華藉摩西所吩咐的得了為業之地。</span>
</div>
</div>

## 約旦河旁的祭壇

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="約書亞記 24:26–27; 創世記 31:46–52; 約書亞記 4:5–9"> 呂便人、迦得人，和瑪拿西半支派的人到了靠近約旦河的一帶迦南地，就在約旦河那裏築了一座壇；那壇看着高大。</span>
<span className="v" id="v11" data-v="11" data-xref="申命記 13:12–14; 利未記 17:8–9; 約書亞記 2:7"> 以色列人聽說呂便人、迦得人、瑪拿西半支派的人靠近約旦河邊，在迦南地屬以色列人的那邊築了一座壇。</span>
<span className="v" id="v12" data-v="12" data-xref="士師記 20:1–11; 申命記 13:15; 加拉太書 4:17–18"> 全會眾一聽見，就聚集在示羅，要上去攻打他們。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="民數記 25:7; 詩篇 106:30–31; 出埃及記 6:25"> 以色列人打發祭司以利亞撒的兒子非尼哈，往基列地去見呂便人、迦得人、瑪拿西半支派的人；</span>
<span className="v" id="v14" data-v="14" data-xref="民數記 1:4; 出埃及記 18:25"> 又打發十個首領與非尼哈同去，就是以色列每支派的一個首領，都是以色列軍中的統領。</span>
<span className="v" id="v15" data-v="15" data-xref="歷代志上 21:3; 撒母耳記上 15:23; 申命記 30:17"> 他們到了基列地，見呂便人、迦得人，和瑪拿西半支派的人，對他們說：</span>
<span className="v" id="v16" data-v="16" data-xref="申命記 12:13–14"> 「耶和華全會眾這樣說，你們今日轉去不跟從耶和華，干犯以色列的上帝，為自己築一座壇，悖逆了耶和華，這犯的是甚麼罪呢？</span>
<span className="v" id="v17" data-v="17" data-xref="民數記 25:1–18; 詩篇 106:28–29; 申命記 4:3–4"> 從前拜毗珥的罪孽還算小嗎？雖然瘟疫臨到耶和華的會眾，到今日我們還沒有洗淨這罪。</span>
<span className="v" id="v18" data-v="18" data-xref="民數記 16:22; 約書亞記 22:16; 約書亞記 7:11"> 你們今日竟轉去不跟從耶和華嗎？你們今日既悖逆耶和華，明日他必向以色列全會眾發怒。</span>
<span className="v" id="v19" data-v="19" data-xref="約書亞記 18:1; 歷代志下 11:16–17; 使徒行傳 10:14–15"> 你們所得為業之地，若嫌不潔淨，就可以過到耶和華之地，就是耶和華的帳幕所住之地，在我們中間得地業。只是不可悖逆耶和華，也不可得罪我們，在耶和華－我們上帝的壇以外為自己築壇。</span>
<span className="v" id="v20" data-v="20" data-xref="約書亞記 7:1; 約書亞記 7:5; 約書亞記 7:18"> 從前謝拉的曾孫亞干豈不是在那當滅的物上犯了罪，就有忿怒臨到以色列全會眾嗎？那人在所犯的罪中不獨一人死亡。」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="雅各書 1:19; 箴言 16:1; 彼得前書 3:15"> 於是呂便人、迦得人、瑪拿西半支派的人回答以色列軍中的統領說：</span>
<span className="v" id="v22" data-v="22" data-xref="列王紀上 8:39; 詩篇 44:21; 申命記 10:17"> 「大能者上帝耶和華！大能者上帝耶和華！他是知道的！以色列人也必知道！我們若有悖逆的意思，或是干犯耶和華（願你今日不保佑我們），</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳記上 20:16; 申命記 18:19; 以西結書 3:18"> 為自己築壇，要轉去不跟從耶和華，或是要將燔祭、素祭、平安祭獻在壇上，願耶和華親自討我們的罪。</span>
<span className="v" id="v24" data-v="24" data-xref="約書亞記 4:6; 申命記 6:20; 創世記 30:33"> 我們行這事並非無故，是特意做的，說：恐怕日後你們的子孫對我們的子孫說：『你們與耶和華－以色列的上帝有何關涉呢？</span>
<span className="v" id="v25" data-v="25" data-xref="列王紀上 12:16; 以斯拉記 4:2–3; 撒母耳記上 26:19"> 因為耶和華把約旦河定為我們和你們這呂便人、迦得人的交界，你們與耶和華無分了。』這樣，你們的子孫就使我們的子孫不再敬畏耶和華了。</span>
<span className="v" id="v26" data-v="26"> 因此我們說：『不如為自己築一座壇，不是為獻燔祭，也不是為獻別的祭，</span>
<span className="v" id="v27" data-v="27" data-xref="約書亞記 24:27; 創世記 31:48; 申命記 12:17–18"> 乃是為你我中間和你我後人中間作證據，好叫我們也在耶和華面前獻燔祭、平安祭，和別的祭事奉他，免得你們的子孫日後對我們的子孫說，你們與耶和華無分了。』</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及記 25:40; 以西結書 43:10–11; 希伯來書 8:5"> 所以我們說：『日後你們對我們，或對我們的後人這樣說，我們就可以回答說，你們看我們列祖所築的壇是耶和華壇的樣式；這並不是為獻燔祭，也不是為獻別的祭，乃是為作你我中間的證據。』</span>
<span className="v" id="v29" data-v="29" data-xref="約書亞記 24:16; 申命記 12:13–14; 約書亞記 22:23"> 我們在耶和華－我們上帝帳幕前的壇以外，另築一座壇，為獻燔祭、素祭，和別的祭，悖逆耶和華，今日轉去不跟從他，我們斷沒有這個意思。」</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="約書亞記 22:33; 以斯帖記 1:21; 箴言 15:1"> 祭司非尼哈與會中的首領，就是與他同來以色列軍中的統領，聽見呂便人、迦得人、瑪拿西人所說的話，就都以為美。</span>
<span className="v" id="v31" data-v="31" data-xref="歷代志下 15:2; 利未記 26:11–12; 以賽亞書 12:6"> 祭司以利亞撒的兒子非尼哈對呂便人、迦得人、瑪拿西人說：「今日我們知道耶和華在我們中間，因為你們沒有向他犯了這罪。現在你們救以色列人脫離耶和華的手了。」</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="約書亞記 22:12–14; 箴言 25:13"> 祭司以利亞撒的兒子非尼哈與眾首領離了呂便人、迦得人，從基列地回往迦南地，到了以色列人那裏，便將這事回報他們。</span>
<span className="v" id="v33" data-v="33" data-xref="歷代志上 29:20; 路加福音 2:28; 但以理書 2:19"> 以色列人以這事為美，就稱頌上帝，不再提上去攻打呂便人、迦得人、毀壞他們所住的地了。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="約書亞記 22:27; 馬太福音 4:10; 以賽亞書 43:10"> 呂便人、迦得人給壇起名叫證壇，意思說：這壇在我們中間證明耶和華是上帝。</span>
</div>
</div>

</div>

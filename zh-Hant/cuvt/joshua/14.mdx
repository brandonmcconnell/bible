## 分配約旦河西的土地

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民數記 34:17–29"> 以色列人在迦南地所得的產業，就是祭司以利亞撒和嫩的兒子約書亞，並以色列各支派的族長所分給他們的，都記在下面，</span>
<span className="v" id="v2" data-v="2" data-xref="民數記 33:54; 民數記 34:13; 民數記 26:55–56"> 是照耶和華藉摩西所吩咐的，把產業拈鬮分給九個半支派。</span>
<span className="v" id="v3" data-v="3" data-xref="約書亞記 13:14; 約書亞記 13:8; 約書亞記 13:32–33"> 原來，摩西在約旦河東已經把產業分給那兩個半支派，只是在他們中間沒有把產業分給利未人。</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 48:5; 歷代志上 5:1–2; 民數記 35:2–8"> 因為約瑟的子孫是兩個支派，就是瑪拿西和以法蓮，所以沒有把地分給利未人，但給他們城邑居住，並城邑的郊野，可以牧養他們的牲畜，安置他們的財物。</span>
<span className="v" id="v5" data-v="5" data-xref="約書亞記 21:2; 民數記 35:1–2"> 耶和華怎樣吩咐摩西，以色列人就照樣行，把地分了。</span>
</div>
</div>

## 迦勒得希伯崙為業

<div className="bt">
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="民數記 14:30; 民數記 13:6; 民數記 14:24"> 那時，猶大人來到吉甲見約書亞，有基尼洗族耶孚尼的兒子迦勒對約書亞說：「耶和華在加低斯‧巴尼亞指着我與你對神人摩西所說的話，你都知道了。</span>
<span className="v" id="v7" data-v="7" data-xref="民數記 13:6; 民數記 13:26–33; 民數記 14:6–10"> 耶和華的僕人摩西從加低斯‧巴尼亞打發我窺探這地，那時我正四十歲；我按着心意回報他。</span>
<span className="v" id="v8" data-v="8" data-xref="民數記 14:24; 申命記 1:36; 民數記 13:31"> 然而，同我上去的眾弟兄使百姓的心消化；但我專心跟從耶和華－我的上帝。</span>
<span className="v" id="v9" data-v="9" data-xref="約書亞記 1:3; 申命記 1:36; 民數記 14:22–24"> 當日摩西起誓說：『你腳所踏之地定要歸你和你的子孫永遠為業，因為你專心跟從耶和華－我的上帝。』</span>
<span className="v" id="v10" data-v="10" data-xref="民數記 14:33–34; 民數記 14:30; 約書亞記 11:18"> 自從耶和華對摩西說這話的時候，耶和華照他所應許的使我存活這四十五年；其間以色列人在曠野行走。看哪，現今我八十五歲了，</span>
<span className="v" id="v11" data-v="11" data-xref="申命記 34:7; 詩篇 103:5; 申命記 31:2"> 我還是強壯，像摩西打發我去的那天一樣；無論是爭戰，是出入，我的力量那時如何，現在還是如何。</span>
<span className="v" id="v12" data-v="12" data-xref="希伯來書 11:33; 腓立比書 4:13; 民數記 13:33"> 求你將耶和華那日應許我的這山地給我；那裏有亞衲族人，並寬大堅固的城，你也曾聽見了。或者耶和華照他所應許的與我同在，我就把他們趕出去。」</span>
<span className="v" id="v13" data-v="13" data-xref="士師記 1:20; 約書亞記 22:6; 歷代志上 6:55–56"> 於是約書亞為耶孚尼的兒子迦勒祝福，將希伯崙給他為業。</span>
<span className="v" id="v14" data-v="14" data-xref="約書亞記 14:8–9; 哥林多前書 15:58"> 所以希伯崙作了基尼洗族耶孚尼的兒子迦勒的產業，直到今日，因為他專心跟從耶和華－以色列的上帝。</span>
<span className="v" id="v15" data-v="15" data-xref="約書亞記 11:23; 創世記 23:2; 約書亞記 15:13"> 希伯崙從前名叫基列‧亞巴；亞巴是亞衲族中最尊大的人。於是國中太平，沒有爭戰了。</span>

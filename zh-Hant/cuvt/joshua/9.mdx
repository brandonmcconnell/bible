## 基遍人欺瞞約書亞

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民數記 34:6; 出埃及記 3:17; 出埃及記 23:23"> 約旦河西，住山地、高原，並對着黎巴嫩山沿大海一帶的諸王，就是赫人、亞摩利人、迦南人、比利洗人、希未人、耶布斯人的諸王，聽見這事，</span>
<span className="v" id="v2" data-v="2" data-xref="啟示錄 16:14; 約珥書 3:9–13; 詩篇 2:1–2"> 就都聚集，同心合意地要與約書亞和以色列人爭戰。</span>
<span className="v" id="v3" data-v="3" data-xref="約書亞記 10:2; 約書亞記 9:17; 撒母耳記下 21:1–2"> 基遍的居民聽見約書亞向耶利哥和艾城所行的事，</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 16:8; 馬太福音 10:16; 馬可福音 2:22"> 就設詭計，假充使者，拿舊口袋和破裂縫補的舊皮酒袋馱在驢上，</span>
<span className="v" id="v5" data-v="5" data-xref="路加福音 15:22; 申命記 33:25; 申命記 29:5"> 將補過的舊鞋穿在腳上，把舊衣服穿在身上；他們所帶的餅都是乾的，長了霉了。</span>
<span className="v" id="v6" data-v="6" data-xref="約書亞記 5:10; 列王紀下 20:14; 約書亞記 9:9"> 他們到吉甲營中見約書亞，對他和以色列人說：「我們是從遠方來的，現在求你與我們立約。」</span>
<span className="v" id="v7" data-v="7" data-xref="約書亞記 11:19; 士師記 2:2; 出埃及記 34:12"> 以色列人對這些希未人說：「只怕你們是住在我們中間的；若是這樣，怎能和你們立約呢？」</span>
<span className="v" id="v8" data-v="8" data-xref="申命記 20:11; 列王紀下 10:5; 約書亞記 9:11"> 他們對約書亞說：「我們是你的僕人。」約書亞問他們說：「你們是甚麼人？是從哪裏來的？」</span>
<span className="v" id="v9" data-v="9" data-xref="申命記 20:15; 約書亞記 9:24; 以賽亞書 55:5"> 他們回答說：「僕人從極遠之地而來，是因聽見耶和華－你上帝的名聲和他在埃及所行的一切事，</span>
<span className="v" id="v10" data-v="10" data-xref="民數記 21:24–35; 申命記 1:4; 約書亞記 12:4"> 並他向約旦河東的兩個亞摩利王，就是希實本王西宏和在亞斯他錄的巴珊王噩一切所行的事。</span>
<span className="v" id="v11" data-v="11" data-xref="約書亞記 9:8; 以斯帖記 8:17; 約書亞記 1:11"> 我們的長老和我們那地的一切居民對我們說：『你們手裏要帶着路上用的食物去迎接以色列人，對他們說：我們是你們的僕人；現在求你們與我們立約。』</span>
<span className="v" id="v12" data-v="12" data-xref="約書亞記 9:4–5"> 我們出來要往你們這裏來的日子，從家裏帶出來的這餅還是熱的；看哪，現在都乾了，長了霉了。</span>
<span className="v" id="v13" data-v="13"> 這皮酒袋，我們盛酒的時候還是新的；看哪，現在已經破裂。我們這衣服和鞋，因為道路甚遠，也都穿舊了。」</span>
<span className="v" id="v14" data-v="14" data-xref="箴言 3:5–6; 民數記 27:21; 歷代志上 10:13–14"> 以色列人受了他們些食物，並沒有求問耶和華。</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳記下 21:2; 申命記 20:10–11; 約書亞記 11:19"> 於是約書亞與他們講和，與他們立約，容他們活着；會眾的首領也向他們起誓。</span>
<span className="v" id="v16" data-v="16" data-xref="箴言 12:19"> 以色列人與他們立約之後，過了三天才聽見他們是近鄰，住在以色列人中間的。</span>
<span className="v" id="v17" data-v="17" data-xref="以斯拉記 2:25; 約書亞記 18:25–28; 約書亞記 18:14"> 以色列人起行，第三天到了他們的城邑，就是基遍、基非拉、比錄、基列‧耶琳。</span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 15:4; 撒母耳記下 21:7; 傳道書 5:6"> 因為會眾的首領已經指着耶和華－以色列的上帝向他們起誓，所以以色列人不擊殺他們；全會眾就向首領發怨言。</span>
<span className="v" id="v19" data-v="19" data-xref="傳道書 8:2; 約書亞記 9:20; 傳道書 9:2"> 眾首領對全會眾說：「我們已經指着耶和華－以色列的上帝向他們起誓，現在我們不能害他們。</span>
<span className="v" id="v20" data-v="20" data-xref="瑪拉基書 3:5; 箴言 20:25; 提摩太前書 1:10"> 我們要如此待他們，容他們活着，免得有忿怒因我們所起的誓臨到我們身上。」</span>
<span className="v" id="v21" data-v="21" data-xref="申命記 29:11; 約書亞記 9:27; 約書亞記 9:23"> 首領又對會眾說：「要容他們活着。」於是他們為全會眾作了劈柴挑水的人，正如首領對他們所說的話。</span>
<span className="v" id="v22" data-v="22" data-xref="約書亞記 9:6; 約書亞記 9:16; 創世記 3:13–14"> 約書亞召了他們來，對他們說：「為甚麼欺哄我們說『我們離你們甚遠』呢？其實你們是住在我們中間。</span>
<span className="v" id="v23" data-v="23" data-xref="約書亞記 9:21; 創世記 9:25–26; 約書亞記 9:27"> 現在你們是被咒詛的！你們中間的人必斷不了作奴僕，為我上帝的殿作劈柴挑水的人。」</span>
<span className="v" id="v24" data-v="24" data-xref="申命記 20:15–17; 申命記 7:1–2; 出埃及記 23:31–33"> 他們回答約書亞說：「因為有人實在告訴你的僕人，耶和華－你的上帝曾吩咐他的僕人摩西，把這全地賜給你們，並在你們面前滅絕這地的一切居民，所以我們為你們的緣故甚怕喪命，就行了這事。</span>
<span className="v" id="v25" data-v="25" data-xref="創世記 16:6; 士師記 10:15; 耶利米書 26:14"> 現在我們在你手中，你以怎樣待我們為善為正，就怎樣做吧！」</span>
<span className="v" id="v26" data-v="26"> 於是約書亞這樣待他們，救他們脫離以色列人的手，以色列人就沒有殺他們。</span>
<span className="v" id="v27" data-v="27" data-xref="申命記 12:5"> 當日約書亞使他們在耶和華所要選擇的地方，為會眾和耶和華的壇作劈柴挑水的人，直到今日。</span>

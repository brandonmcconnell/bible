## 利未人的城邑

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="約書亞記 14:1; 約書亞記 19:51; 約書亞記 17:4"> 那時，利未人的眾族長來到祭司以利亞撒和嫩的兒子約書亞，並以色列各支派的族長面前，</span>
<span className="v" id="v2" data-v="2" data-xref="約書亞記 18:1; 民數記 35:2–8; 馬太福音 10:10"> 在迦南地的示羅對他們說：「從前耶和華藉着摩西吩咐給我們城邑居住，並城邑的郊野可以牧養我們的牲畜。」</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 49:7; 申命記 33:8–10; 歷代志上 6:54–81"> 於是以色列人照耶和華所吩咐的，從自己的地業中，將以下所記的城邑和城邑的郊野給了利未人。</span>
<span className="v" id="v4" data-v="4" data-xref="歷代志上 6:54–60; 約書亞記 24:33; 約書亞記 21:8–19"> 為哥轄族拈鬮：利未人的祭司、亞倫的子孫，從猶大支派、西緬支派、便雅憫支派的地業中，按鬮得了十三座城。</span>
<span className="v" id="v5" data-v="5" data-xref="約書亞記 21:20–26; 出埃及記 6:16–25; 歷代志上 6:66–70"> 哥轄其餘的子孫，從以法蓮支派、但支派、瑪拿西半支派的地業中，按鬮得了十座城。</span>
<span className="v" id="v6" data-v="6" data-xref="約書亞記 21:27–33; 歷代志上 6:71–76; 出埃及記 6:16–17"> 革順的子孫，從以薩迦支派、亞設支派、拿弗他利支派、住巴珊的瑪拿西半支派的地業中，按鬮得了十三座城。</span>
<span className="v" id="v7" data-v="7" data-xref="約書亞記 21:34–40; 歷代志上 6:77–81; 出埃及記 6:19"> 米拉利的子孫，按着宗族，從呂便支派、迦得支派、西布倫支派的地業中，按鬮得了十二座城。</span>
<span className="v" id="v8" data-v="8" data-xref="約書亞記 21:3; 約書亞記 18:6; 民數記 33:54"> 以色列人照着耶和華藉摩西所吩咐的，將這些城邑和城邑的郊野，按鬮分給利未人。</span>
<span className="v" id="v9" data-v="9" data-xref="歷代志上 6:65; 約書亞記 21:13–18"> 從猶大支派、西緬支派的地業中，將以下所記的城給了利未支派哥轄宗族亞倫的子孫；因為給他們拈出頭一鬮，</span>
<span className="v" id="v11" data-v="11" data-xref="歷代志上 6:55; 路加福音 1:39; 撒母耳記下 5:1–5"> 將猶大山地的基列‧亞巴和四圍的郊野給了他們。亞巴是亞衲族的始祖。（基列‧亞巴就是希伯崙）。</span>
<span className="v" id="v12" data-v="12" data-xref="約書亞記 14:13–15; 歷代志上 6:55–57"> 惟將屬城的田地和村莊給了耶孚尼的兒子迦勒為業。</span>
<span className="v" id="v13" data-v="13" data-xref="約書亞記 15:42; 約書亞記 10:29; 約書亞記 15:54"> 以色列人將希伯崙，就是誤殺人的逃城和屬城的郊野，給了祭司亞倫的子孫；又給他們立拿和屬城的郊野，</span>
<span className="v" id="v14" data-v="14" data-xref="約書亞記 15:48; 約書亞記 15:50; 撒母耳記上 30:27–28"> 雅提珥和屬城的郊野，以實提莫和屬城的郊野，</span>
<span className="v" id="v15" data-v="15" data-xref="約書亞記 15:49; 約書亞記 15:51; 約書亞記 12:13"> 何崙和屬城的郊野，底璧和屬城的郊野，</span>
<span className="v" id="v16" data-v="16" data-xref="約書亞記 15:10; 歷代志上 6:59; 約書亞記 15:55"> 亞因和屬城的郊野，淤他和屬城的郊野，伯‧示麥和屬城的郊野，共九座城，都是從這二支派中分出來的。</span>
<span className="v" id="v17" data-v="17" data-xref="約書亞記 18:24–25; 約書亞記 9:3; 歷代志上 6:60"> 又從便雅憫支派的地業中給了他們基遍和屬城的郊野，迦巴和屬城的郊野，</span>
<span className="v" id="v18" data-v="18" data-xref="以賽亞書 10:30; 歷代志上 6:60; 耶利米書 1:1"> 亞拿突和屬城的郊野，亞勒們和屬城的郊野，共四座城。</span>
<span className="v" id="v19" data-v="19"> 亞倫子孫作祭司的共有十三座城，還有屬城的郊野。</span>
<span className="v" id="v20" data-v="20" data-xref="歷代志上 6:66; 約書亞記 21:5"> 利未支派中哥轄的宗族，就是哥轄其餘的子孫，拈鬮所得的城有從以法蓮支派中分出來的。</span>
<span className="v" id="v21" data-v="21" data-xref="約書亞記 20:7; 士師記 9:1; 列王紀上 12:1"> 以色列人將以法蓮山地的示劍，就是誤殺人的逃城和屬城的郊野，給了他們；又給他們基色和屬城的郊野，</span>
<span className="v" id="v22" data-v="22" data-xref="歷代志上 6:68; 約書亞記 16:3; 約書亞記 18:13–14"> 基伯先和屬城的郊野，伯‧和崙和屬城的郊野，共四座城；</span>
<span className="v" id="v23" data-v="23" data-xref="約書亞記 19:44–45"> 又從但支派的地業中給了他們伊利提基和屬城的郊野，基比頓和屬城的郊野，</span>
<span className="v" id="v24" data-v="24" data-xref="約書亞記 19:42; 約書亞記 10:12; 歷代志上 6:69"> 亞雅崙和屬城的郊野，迦特‧臨門和屬城的郊野，共四座城；</span>
<span className="v" id="v25" data-v="25" data-xref="約書亞記 17:11; 士師記 5:19"> 又從瑪拿西半支派的地業中給了他們他納和屬城的郊野，迦特‧臨門和屬城的郊野，共兩座城。</span>
<span className="v" id="v26" data-v="26"> 哥轄其餘的子孫共有十座城，還有屬城的郊野。</span>
<span className="v" id="v27" data-v="27" data-xref="歷代志上 6:71; 申命記 1:4; 約書亞記 20:8"> 以色列人又從瑪拿西半支派的地業中將巴珊的哥蘭，就是誤殺人的逃城和屬城的郊野，給了利未支派革順的子孫；又給他們比‧施提拉和屬城的郊野，共兩座城；</span>
<span className="v" id="v28" data-v="28" data-xref="約書亞記 19:12; 歷代志上 6:72–73"> 又從以薩迦支派的地業中給了他們基善和屬城的郊野，大比拉和屬城的郊野，</span>
<span className="v" id="v29" data-v="29" data-xref="約書亞記 10:23; 約書亞記 12:11; 約書亞記 10:3"> 耶末和屬城的郊野，隱‧干寧和屬城的郊野，共四座城；</span>
<span className="v" id="v30" data-v="30" data-xref="歷代志上 6:74–75; 約書亞記 19:25–28"> 又從亞設支派的地業中給了他們米沙勒和屬城的郊野，押頓和屬城的郊野，</span>
<span className="v" id="v31" data-v="31" data-xref="士師記 18:21; 歷代志上 6:75; 士師記 1:31"> 黑甲和屬城的郊野，利合和屬城的郊野，共四座城；</span>
<span className="v" id="v32" data-v="32" data-xref="歷代志上 6:76; 約書亞記 20:7; 約書亞記 19:37"> 又從拿弗他利支派的地業中將加利利的基低斯，就是誤殺人的逃城和屬城的郊野，給了他們；又給他們哈末‧多珥和屬城的郊野，加珥坦和屬城的郊野，共三座城。</span>
<span className="v" id="v33" data-v="33"> 革順人按着宗族所得的城，共十三座，還有屬城的郊野。</span>
<span className="v" id="v34" data-v="34" data-xref="歷代志上 6:77; 約書亞記 19:11; 約書亞記 21:7"> 其餘利未支派米拉利子孫，從西布倫支派的地業中所得的，就是約念和屬城的郊野，加珥他和屬城的郊野，</span>
<span className="v" id="v35" data-v="35"> 丁拿和屬城的郊野，拿哈拉和屬城的郊野，共四座城；</span>
<span className="v" id="v36" data-v="36" data-xref="約書亞記 20:8; 申命記 4:43; 民數記 21:23"> 又從呂便支派的地業中給了他們比悉和屬城的郊野，雅雜和屬城的郊野，</span>
<span className="v" id="v37" data-v="37"> 基底莫和屬城的郊野，米法押和屬城的郊野，共四座城；</span>
<span className="v" id="v38" data-v="38" data-xref="創世記 32:2; 列王紀上 22:3; 歷代志上 6:80"> 又從迦得支派的地業中，將基列的拉末，就是誤殺人的逃城和屬城的郊野，給了他們；又給他們瑪哈念和屬城的郊野，</span>
<span className="v" id="v39" data-v="39" data-xref="以賽亞書 16:8–9; 民數記 32:35; 民數記 32:1"> 希實本和屬城的郊野，雅謝和屬城的郊野，共四座城。</span>
<span className="v" id="v40" data-v="40"> 其餘利未支派的人，就是米拉利的子孫，按着宗族拈鬮所得的，共十二座城。</span>
<span className="v" id="v41" data-v="41" data-xref="民數記 35:1–8; 申命記 33:10; 創世記 49:7"> 利未人在以色列人的地業中所得的城，共四十八座，並有屬城的郊野。</span>
<span className="v" id="v42" data-v="42"> 這些城四圍都有屬城的郊野，城城都是如此。</span>
</div>

## 以色列人得地為業

<div className="bt">
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="創世記 13:15; 詩篇 106:42–45; 出埃及記 23:27–31"> 這樣，耶和華將從前向他們列祖起誓所應許的全地賜給以色列人，他們就得了為業，住在其中。</span>
<span className="v" id="v44" data-v="44" data-xref="約書亞記 11:23; 希伯來書 4:9; 申命記 31:3–5"> 耶和華照着向他們列祖起誓所應許的一切話，使他們四境平安；他們一切仇敵中，沒有一人在他們面前站立得住。耶和華把一切仇敵都交在他們手中。</span>
<span className="v" id="v45" data-v="45" data-xref="列王紀上 8:56; 約書亞記 23:14–15; 民數記 23:19"> 耶和華應許賜福給以色列家的話一句也沒有落空，都應驗了。</span>

## 耶利哥城陷落

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="約書亞記 2:24; 約書亞記 2:9–14; 詩篇 127:1"> 耶利哥的城門因以色列人就關得嚴緊，無人出入。</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 7:24; 約書亞記 8:1; 約書亞記 2:24"> 耶和華曉諭約書亞說：「看哪，我已經把耶利哥和耶利哥的王，並大能的勇士，都交在你手中。</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多後書 4:7; 民數記 14:9; 約書亞記 6:7"> 你們的一切兵丁要圍繞這城，一日圍繞一次，六日都要這樣行。</span>
<span className="v" id="v4" data-v="4" data-xref="歷代志下 20:17; 啟示錄 16:1; 列王紀上 18:43"> 七個祭司要拿七個羊角走在約櫃前。到第七日，你們要繞城七次，祭司也要吹角。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多後書 10:4–5; 希伯來書 11:30; 出埃及記 19:19"> 他們吹的角聲拖長，你們聽見角聲，眾百姓要大聲呼喊，城牆就必塌陷，各人都要往前直上。」</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行傳 9:1; 申命記 20:2–4; 約書亞記 3:3"> 嫩的兒子約書亞召了祭司來，吩咐他們說：「你們抬起約櫃來，要有七個祭司拿七個羊角走在耶和華的約櫃前」；</span>
<span className="v" id="v7" data-v="7" data-xref="約書亞記 4:13; 約書亞記 6:3; 約書亞記 1:14"> 又對百姓說：「你們前去繞城，帶兵器的要走在耶和華的約櫃前。」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="民數記 32:20; 約書亞記 6:3–4"> 約書亞對百姓說完了話，七個祭司拿七個羊角走在耶和華面前吹角；耶和華的約櫃在他們後面跟隨。</span>
<span className="v" id="v9" data-v="9" data-xref="約書亞記 6:13; 民數記 10:25; 以賽亞書 58:8"> 帶兵器的走在吹角的祭司前面，後隊隨着約櫃行。祭司一面走一面吹。</span>
<span className="v" id="v10" data-v="10" data-xref="路加福音 24:49; 馬太福音 12:19; 以賽亞書 42:2"> 約書亞吩咐百姓說：「你們不可呼喊，不可出聲，連一句話也不可出你們的口，等到我吩咐你們呼喊的日子，那時才可以呼喊。」</span>
<span className="v" id="v11" data-v="11"> 這樣，他使耶和華的約櫃繞城，把城繞了一次；眾人回到營裏，就在營裏住宿。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="約書亞記 3:1; 希伯來書 11:7–8; 創世記 22:3"> 約書亞清早起來，祭司又抬起耶和華的約櫃。</span>
<span className="v" id="v13" data-v="13" data-xref="加拉太書 6:9; 馬太福音 24:13; 歷代志上 15:26"> 七個祭司拿七個羊角在耶和華的約櫃前，時常行走吹角；帶兵器的在他們前面走，後隊隨着耶和華的約櫃行。祭司一面走一面吹。</span>
<span className="v" id="v14" data-v="14" data-xref="約書亞記 6:15; 約書亞記 6:11; 約書亞記 6:3"> 第二日，眾人把城繞了一次，就回營裏去。六日都是這樣行。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="詩篇 119:147; 彼得後書 1:19; 馬太福音 28:1"> 第七日清早，黎明的時候，他們起來，照樣繞城七次；惟獨這日把城繞了七次。</span>
<span className="v" id="v16" data-v="16" data-xref="歷代志下 13:15; 約書亞記 6:5; 歷代志下 20:22–23"> 到了第七次，祭司吹角的時候，約書亞吩咐百姓說：「呼喊吧，因為耶和華已經把城交給你們了！</span>
<span className="v" id="v17" data-v="17" data-xref="申命記 20:17; 雅各書 2:25; 彌迦書 4:13"> 這城和其中所有的都要在耶和華面前毀滅；只有妓女喇合與她家中所有的可以存活，因為她隱藏了我們所打發的使者。</span>
<span className="v" id="v18" data-v="18" data-xref="約翰一書 5:21; 以弗所書 5:11; 約書亞記 7:1"> 至於你們，務要謹慎，不可取那當滅的物，恐怕你們取了那當滅的物就連累以色列的全營，使全營受咒詛。</span>
<span className="v" id="v19" data-v="19" data-xref="歷代志上 26:20; 馬太福音 27:6; 馬可福音 12:41"> 惟有金子、銀子，和銅鐵的器皿都要歸耶和華為聖，必入耶和華的庫中。」</span>
<span className="v" id="v20" data-v="20" data-xref="希伯來書 11:30; 哥林多後書 10:4–5; 約書亞記 6:5"> 於是百姓呼喊，祭司也吹角。百姓聽見角聲，便大聲呼喊，城牆就塌陷，百姓便上去進城，各人往前直上，將城奪取；</span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 137:8–9; 耶利米書 48:18; 約書亞記 11:14"> 又將城中所有的，不拘男女老少，牛羊和驢，都用刀殺盡。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="希伯來書 11:31; 約書亞記 6:17; 以西結書 17:18–19"> 約書亞吩咐窺探地的兩個人說：「你們進那妓女的家，照着你們向她所起的誓，將那女人和她所有的都從那裏帶出來。」</span>
<span className="v" id="v23" data-v="23" data-xref="希伯來書 11:7; 創世記 18:24; 使徒行傳 27:24"> 當探子的兩個少年人就進去，將喇合與她的父母、弟兄，和她所有的，並她一切的親眷，都帶出來，安置在以色列的營外。</span>
<span className="v" id="v24" data-v="24" data-xref="約書亞記 8:28; 啟示錄 17:16; 列王紀下 25:9"> 眾人就用火將城和其中所有的焚燒了；惟有金子、銀子，和銅鐵的器皿都放在耶和華殿的庫中。</span>
<span className="v" id="v25" data-v="25" data-xref="希伯來書 11:31; 馬太福音 1:5; 士師記 1:24–25"> 約書亞卻把妓女喇合與她父家，並她所有的，都救活了；因為她隱藏了約書亞所打發窺探耶利哥的使者，她就住在以色列中，直到今日。</span>
</div>
<div className="bp poetry">
<span className="v" id="v26" data-v="26" data-xref="列王紀上 16:34; 使徒行傳 19:13; 民數記 5:19–21"> 當時，約書亞叫眾人起誓說：「有興起重修這耶利哥城的人，當在耶和華面前受咒詛。<br /><span className="pl pl-1">他立根基的時候，必喪長子，</span><br /><span className="pl pl-1">安門的時候，必喪幼子。」</span></span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="約書亞記 9:3; 約書亞記 1:5; 馬太福音 28:20"> 耶和華與約書亞同在，約書亞的聲名傳揚遍地。</span>
</div>
</div>

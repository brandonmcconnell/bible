## 立石為記

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命記 27:2; 約書亞記 3:17"> 國民盡都過了約旦河，耶和華就對約書亞說：</span>
<span className="v" id="v2" data-v="2" data-xref="約書亞記 3:12; 民數記 1:4–15; 列王紀上 18:31"> 「你從民中要揀選十二個人，每支派一人，</span>
<span className="v" id="v3" data-v="3" data-xref="約書亞記 4:19–20; 約書亞記 3:13; 約書亞記 4:8"> 吩咐他們說：『你們從這裏，從約旦河中、祭司腳站定的地方，取十二塊石頭帶過去，放在你們今夜要住宿的地方。』」</span>
<span className="v" id="v4" data-v="4" data-xref="約書亞記 4:2; 馬可福音 3:14–19"> 於是，約書亞將他從以色列人中所預備的那十二個人，每支派一人，都召了來。</span>
<span className="v" id="v5" data-v="5"> 對他們說：「你們下約旦河中，過到耶和華－你們上帝的約櫃前頭，按着以色列人十二支派的數目，每人取一塊石頭扛在肩上。</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及記 13:14; 約書亞記 4:21; 詩篇 44:1"> 這些石頭在你們中間可以作為證據。日後，你們的子孫問你們說：『這些石頭是甚麼意思？』</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及記 12:14; 民數記 16:40; 出埃及記 28:12"> 你們就對他們說：『這是因為約旦河的水在耶和華的約櫃前斷絕；約櫃過約旦河的時候，約旦河的水就斷絕了。這些石頭要作以色列人永遠的紀念。』」</span>
<span className="v" id="v8" data-v="8" data-xref="約書亞記 4:2–5; 約書亞記 1:16–18; 約書亞記 4:20"> 以色列人就照約書亞所吩咐的，按着以色列人支派的數目，從約旦河中取了十二塊石頭，都遵耶和華所吩咐約書亞的行了。他們把石頭帶過去，到他們所住宿的地方，就放在那裏。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳記上 7:12; 士師記 1:26; 歷代志下 5:9"> 約書亞另把十二塊石頭立在約旦河中，在抬約櫃的祭司腳站立的地方；直到今日，那石頭還在那裏。</span>
<span className="v" id="v10" data-v="10" data-xref="約書亞記 3:13; 詩篇 119:60; 箴言 27:1"> 抬約櫃的祭司站在約旦河中，等到耶和華曉諭約書亞吩咐百姓的事辦完了，是照摩西所吩咐約書亞的一切話。 於是百姓急速過去了。</span>
<span className="v" id="v11" data-v="11" data-xref="約書亞記 3:8; 約書亞記 4:18; 約書亞記 3:17"> 眾百姓盡都過了河，耶和華的約櫃和祭司就在百姓面前過去。</span>
<span className="v" id="v12" data-v="12" data-xref="民數記 32:20–32; 約書亞記 1:14"> 呂便人、迦得人、瑪拿西半支派的人都照摩西所吩咐他們的，帶着兵器在以色列人前頭過去。</span>
<span className="v" id="v13" data-v="13" data-xref="以弗所書 6:11; 耶利米書 39:5; 耶利米書 52:8"> 約有四萬人都準備打仗，在耶和華面前過去，到耶利哥的平原，等候上陣。</span>
<span className="v" id="v14" data-v="14" data-xref="約書亞記 3:7; 歷代志下 30:12; 列王紀上 3:28"> 當那日，耶和華使約書亞在以色列眾人眼前尊大。在他平生的日子，百姓敬畏他，像從前敬畏摩西一樣。</span>
<span className="v" id="v15" data-v="15"> 耶和華曉諭約書亞說：</span>
<span className="v" id="v16" data-v="16" data-xref="啟示錄 11:19; 出埃及記 25:16–22; 約書亞記 3:3–6"> 「你吩咐抬法櫃的祭司從約旦河裏上來。」</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 8:16–18; 使徒行傳 16:35–39; 使徒行傳 16:23"> 約書亞就吩咐祭司說：「你們從約旦河裏上來。」</span>
<span className="v" id="v18" data-v="18" data-xref="約書亞記 3:15; 歷代志上 12:15; 約書亞記 3:13"> 抬耶和華約櫃的祭司從約旦河裏上來，腳掌剛落旱地，約旦河的水就流到原處，仍舊漲過兩岸。</span>
<span className="v" id="v19" data-v="19" data-xref="約書亞記 5:9; 彌迦書 6:5; 出埃及記 12:2–3"> 正月初十日，百姓從約旦河裏上來，就在吉甲，在耶利哥的東邊安營。</span>
<span className="v" id="v20" data-v="20" data-xref="約書亞記 4:3; 約書亞記 4:8"> 他們從約旦河中取來的那十二塊石頭，約書亞就立在吉甲，</span>
<span className="v" id="v21" data-v="21" data-xref="約書亞記 4:6; 詩篇 145:4–7; 詩篇 105:2–5"> 對以色列人說：「日後你們的子孫問他們的父親說：『這些石頭是甚麼意思？』</span>
<span className="v" id="v22" data-v="22" data-xref="約書亞記 3:17; 以賽亞書 51:10; 以賽亞書 44:27"> 你們就告訴他們說：『以色列人曾走乾地過這約旦河；</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及記 14:21; 以賽亞書 43:16; 以賽亞書 63:12–14"> 因為耶和華－你們的上帝在你們前面使約旦河的水乾了，等着你們過來，就如耶和華－你們的上帝從前在我們前面使紅海乾了，等着我們過來一樣，</span>
<span className="v" id="v24" data-v="24" data-xref="詩篇 106:8; 詩篇 89:13; 列王紀上 8:42–43"> 要使地上萬民都知道，耶和華的手大有能力，也要使你們永遠敬畏耶和華－你們的上帝。』」</span>

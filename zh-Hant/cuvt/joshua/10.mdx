## 擊敗亞摩利人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="約書亞記 6:21; 希伯來書 7:1; 約書亞記 8:2"> 耶路撒冷王亞多尼‧洗德聽見約書亞奪了艾城，盡行毀滅，怎樣待耶利哥和耶利哥的王，也照樣待艾城和艾城的王，又聽見基遍的居民與以色列人立了和約，住在他們中間，</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 11:25; 約書亞記 2:24; 出埃及記 15:14–16"> 就甚懼怕；因為基遍是一座大城，如都城一般，比艾城更大，並且城內的人都是勇士。</span>
<span className="v" id="v3" data-v="3" data-xref="歷代志下 11:9; 彌迦書 1:13; 約書亞記 10:1"> 所以耶路撒冷王亞多尼‧洗德打發人去見希伯崙王何咸、耶末王毗蘭、拉吉王雅非亞，和伊磯倫王底璧，說：</span>
<span className="v" id="v4" data-v="4" data-xref="約書亞記 9:15; 約書亞記 10:1; 以賽亞書 8:9–10"> 「求你們上來幫助我，我們好攻打基遍，因為他們與約書亞和以色列人立了和約。」</span>
<span className="v" id="v5" data-v="5" data-xref="以賽亞書 8:9–10; 創世記 15:16; 約書亞記 10:6"> 於是五個亞摩利王，就是耶路撒冷王、希伯崙王、耶末王、拉吉王、伊磯倫王，大家聚集，率領他們的眾軍上去，對着基遍安營，攻打基遍。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="約書亞記 9:6; 約書亞記 5:10; 申命記 1:15"> 基遍人就打發人往吉甲的營中去見約書亞，說：「你不要袖手不顧你的僕人，求你速速上來拯救我們，幫助我們，因為住山地亞摩利人的諸王都聚集攻擊我們。」</span>
<span className="v" id="v7" data-v="7" data-xref="約書亞記 8:1; 以賽亞書 8:12; 以賽亞書 8:14"> 於是約書亞和他一切兵丁，並大能的勇士，都從吉甲上去。</span>
<span className="v" id="v8" data-v="8" data-xref="羅馬書 8:31; 申命記 3:2; 詩篇 27:1–2"> 耶和華對約書亞說：「不要怕他們；因為我已將他們交在你手裏，他們無一人能在你面前站立得住。」</span>
<span className="v" id="v9" data-v="9" data-xref="傳道書 9:10; 提摩太後書 2:3; 箴言 24:11–12"> 約書亞就終夜從吉甲上去，猛然臨到他們那裏。</span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 18:14; 約書亞記 16:3; 約書亞記 16:5"> 耶和華使他們在以色列人面前潰亂。約書亞在基遍大大地殺敗他們，追趕他們，在伯‧和崙的上坡路擊殺他們，直到亞西加和瑪基大。</span>
<span className="v" id="v11" data-v="11" data-xref="以賽亞書 28:2; 士師記 5:20; 詩篇 18:12–14"> 他們在以色列人面前逃跑，正在伯‧和崙下坡的時候，耶和華從天上降大冰雹<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是石頭">a</a></sup>在他們身上，直降到亞西加，打死他們。被冰雹打死的，比以色列人用刀殺死的還多。</span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="哈巴谷書 3:11; 以賽亞書 38:8; 以賽亞書 60:20"> 當耶和華將亞摩利人交付以色列人的日子，約書亞就禱告耶和華，在以色列人眼前說：<br /><span className="pl pl-1">日頭啊，你要停在基遍；</span><br /><span className="pl pl-1">月亮啊，你要止在亞雅崙谷。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="哈巴谷書 3:11; 以賽亞書 38:8; 約書亞記 10:14"> <span className="pl pl-1">於是日頭停留，月亮止住，</span><br /><span className="pl pl-1">直等國民向敵人報仇。</span><br />這事豈不是寫在雅煞珥書上嗎？日頭在天當中停住，不急速下落，約有一日之久。</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 1:30; 出埃及記 14:14; 約書亞記 10:42"> 在這日以前，這日以後，耶和華聽人的禱告，沒有像這日的，是因耶和華為以色列爭戰。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="約書亞記 10:43; 約書亞記 10:6"> 約書亞和以色列眾人回到吉甲的營中。</span>
</div>
</div>

## 生擒亞摩利的五王

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="撒母耳記上 24:8; 阿摩司書 9:2; 詩篇 139:7–10"> 那五王逃跑，藏在瑪基大洞裏。</span>
<span className="v" id="v17" data-v="17"> 有人告訴約書亞說：「那五王已經找到了，都藏在瑪基大洞裏。」</span>
<span className="v" id="v18" data-v="18" data-xref="馬太福音 27:66; 約伯記 21:30; 阿摩司書 9:1"> 約書亞說：「你們把幾塊大石頭滾到洞口，派人看守，</span>
<span className="v" id="v19" data-v="19" data-xref="詩篇 18:37–41; 耶利米書 8:14; 以賽亞書 9:14–15"> 你們卻不可耽延，要追趕你們的仇敵，擊殺他們儘後邊的人，不容他們進自己的城邑，因為耶和華－你們的上帝已經把他們交在你們手裏。」</span>
<span className="v" id="v20" data-v="20" data-xref="約書亞記 8:24; 撒母耳記下 20:6; 約書亞記 10:10"> 約書亞和以色列人大大殺敗他們，直到將他們滅盡；其中剩下的人都進了堅固的城。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及記 11:7; 以賽亞書 54:17; 以賽亞書 57:4"> 眾百姓就安然回瑪基大營中，到約書亞那裏。沒有一人敢向以色列人饒舌。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="撒母耳記上 15:32"> 約書亞說：「打開洞口，將那五王從洞裏帶出來，領到我面前。」</span>
<span className="v" id="v23" data-v="23" data-xref="約書亞記 10:1; 約書亞記 10:5; 約書亞記 10:3"> 眾人就這樣行，將那五王，就是耶路撒冷王、希伯崙王、耶末王、拉吉王、伊磯倫王，從洞裏帶出來，領到約書亞面前。</span>
<span className="v" id="v24" data-v="24" data-xref="瑪拉基書 4:3; 羅馬書 16:20; 啟示錄 2:26–27"> 帶出那五王到約書亞面前的時候，約書亞就召了以色列眾人來，對那些和他同去的軍長說：「你們近前來，把腳踏在這些王的頸項上。」他們就近前來，把腳踏在這些王的頸項上。</span>
<span className="v" id="v25" data-v="25" data-xref="哥林多後書 1:10; 約書亞記 1:9; 以弗所書 6:10"> 約書亞對他們說：「你們不要懼怕，也不要驚惶。應當剛強壯膽，因為耶和華必這樣待你們所要攻打的一切仇敵。」</span>
<span className="v" id="v26" data-v="26" data-xref="約書亞記 8:29; 撒母耳記下 21:9; 馬太福音 27:25"> 隨後約書亞將這五王殺死，掛在五棵樹上。他們就在樹上直掛到晚上。</span>
<span className="v" id="v27" data-v="27" data-xref="約書亞記 8:29; 申命記 21:22–23; 約書亞記 7:26"> 日頭要落的時候，約書亞一吩咐，人就把屍首從樹上取下來，丟在他們藏過的洞裏，把幾塊大石頭放在洞口，直存到今日。</span>
</div>
</div>

## 約書亞攻取更多的城邑

<div className="bt">
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="約書亞記 6:21; 申命記 7:16; 申命記 20:16–17"> 當日，約書亞奪了瑪基大，用刀擊殺城中的人和王；將其中一切人口盡行殺滅，沒有留下一個。他待瑪基大王，像從前待耶利哥王一樣。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="約書亞記 21:13; 約書亞記 15:42; 耶利米書 52:1"> 約書亞和以色列眾人從瑪基大往立拿去，攻打立拿。</span>
<span className="v" id="v30" data-v="30"> 耶和華將立拿和立拿的王也交在以色列人手裏。約書亞攻打這城，用刀擊殺了城中的一切人口，沒有留下一個。他待立拿王，像從前待耶利哥王一樣。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="約書亞記 10:3; 約書亞記 12:11; 約書亞記 10:5"> 約書亞和以色列眾人從立拿往拉吉去，對着拉吉安營，攻打這城。</span>
<span className="v" id="v32" data-v="32"> 耶和華將拉吉交在以色列人的手裏。第二天約書亞就奪了拉吉，用刀擊殺了城中的一切人口，是照他向立拿一切所行的。</span>
<span className="v" id="v33" data-v="33" data-xref="約書亞記 16:10; 士師記 1:29; 約書亞記 16:3"> 那時基色王荷蘭上來幫助拉吉，約書亞就把他和他的民都擊殺了，沒有留下一個。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="約書亞記 10:3; 約書亞記 12:12; 約書亞記 15:39"> 約書亞和以色列眾人從拉吉往伊磯倫去，對着伊磯倫安營，攻打這城。</span>
<span className="v" id="v35" data-v="35" data-xref="利未記 26:44; 約書亞記 10:37; 約伯記 19:10"> 當日就奪了城，用刀擊殺了城中的人。那日，約書亞將城中的一切人口盡行殺滅，是照他向拉吉一切所行的。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="士師記 1:10; 約書亞記 15:13; 約書亞記 14:13–14"> 約書亞和以色列眾人從伊磯倫上希伯崙去，攻打這城，</span>
<span className="v" id="v37" data-v="37"> 就奪了希伯崙和屬希伯崙的諸城邑，用刀將城中的人與王，並那些城邑中的人口，都擊殺了，沒有留下一個，是照他向伊磯倫所行的，把城中的一切人口盡行殺滅。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="約書亞記 15:15; 約書亞記 12:13; 約書亞記 15:49"> 約書亞和以色列眾人回到底璧，攻打這城，</span>
<span className="v" id="v39" data-v="39" data-xref="俄巴底亞書 1:18; 約書亞記 11:8; 申命記 3:3"> 就奪了底璧和屬底璧的城邑，又擒獲底璧的王，用刀將這些城中的人口盡行殺滅，沒有留下一個。他待底璧和底璧王，像從前待希伯崙和立拿與立拿王一樣。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="申命記 7:2–16; 出埃及記 23:31–33; 約書亞記 8:27"> 這樣，約書亞擊殺全地的人，就是山地、南地、高原、山坡的人，和那些地的諸王，沒有留下一個。將凡有氣息的盡行殺滅，正如耶和華－以色列的上帝所吩咐的。</span>
<span className="v" id="v41" data-v="41" data-xref="約書亞記 11:16; 約書亞記 15:51; 申命記 9:23"> 約書亞從加低斯‧巴尼亞攻擊到迦薩，又攻擊歌珊全地，直到基遍。</span>
<span className="v" id="v42" data-v="42" data-xref="約書亞記 10:14; 詩篇 46:7; 詩篇 80:3"> 約書亞一時殺敗了這些王，並奪了他們的地，因為耶和華－以色列的上帝為以色列爭戰。</span>
<span className="v" id="v43" data-v="43" data-xref="約書亞記 10:15; 約書亞記 4:19; 撒母耳記上 11:14"> 於是約書亞和以色列眾人回到吉甲的營中。</span>
</div>
</div>

## 亞干犯罪

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="約書亞記 22:20; 傳道書 9:18; 歷代志上 2:6–7"> 以色列人在當滅的物上犯了罪；因為猶大支派中，謝拉的曾孫，撒底的孫子，迦米的兒子亞干取了當滅的物；耶和華的怒氣就向以色列人發作。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="約書亞記 18:12; 何西阿書 4:15; 撒母耳記上 14:23"> 當下，約書亞從耶利哥打發人往伯特利東邊、靠近伯‧亞文的艾城去，吩咐他們說：「你們上去窺探那地。」他們就上去窺探艾城。</span>
<span className="v" id="v3" data-v="3" data-xref="希伯來書 6:11–12; 路加福音 13:24; 彼得後書 1:5"> 他們回到約書亞那裏，對他說：「眾民不必都上去，只要二三千人上去就能攻取艾城；不必勞累眾民都去，因為那裏的人少。」</span>
<span className="v" id="v4" data-v="4" data-xref="申命記 28:25; 利未記 26:17; 申命記 32:30"> 於是民中約有三千人上那裏去，竟在艾城人面前逃跑了。</span>
<span className="v" id="v5" data-v="5" data-xref="約書亞記 2:11; 約書亞記 2:9; 利未記 26:36"> 艾城的人擊殺了他們三十六人，從城門前追趕他們，直到示巴琳，在下坡殺敗他們；眾民的心就消化如水。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="創世記 37:29; 創世記 37:34; 啟示錄 18:19"> 約書亞便撕裂衣服；他和以色列的長老把灰撒在頭上，在耶和華的約櫃前俯伏在地，直到晚上。</span>
<span className="v" id="v7" data-v="7" data-xref="希伯來書 12:5; 列王紀下 3:10; 馬太福音 17:20"> 約書亞說：「哀哉！主耶和華啊，你為甚麼竟領這百姓過約旦河，將我們交在亞摩利人的手中，使我們滅亡呢？我們不如住在約旦河那邊倒好。</span>
<span className="v" id="v8" data-v="8" data-xref="羅馬書 3:5–6; 以斯拉記 9:10; 哈巴谷書 2:1"> 主啊，以色列人既在仇敵面前轉背逃跑，我還有甚麼可說的呢？</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及記 32:12; 詩篇 83:4; 以西結書 36:22–23"> 迦南人和這地一切的居民聽見了就必圍困我們，將我們的名從地上除滅。那時你為你的大名要怎樣行呢？」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="撒母耳記上 15:22; 出埃及記 14:15; 撒母耳記上 16:1"> 耶和華吩咐約書亞說：「起來！你為何這樣俯伏在地呢？</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行傳 5:1–2; 希伯來書 4:13; 約書亞記 6:17–19"> 以色列人犯了罪，違背了我所吩咐他們的約，取了當滅的物；又偷竊，又行詭詐，又把那當滅的放在他們的家具裏。</span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 5:4–5; 以賽亞書 59:2; 約書亞記 6:18"> 因此，以色列人在仇敵面前站立不住。他們在仇敵面前轉背逃跑，是因成了被咒詛的；你們若不把當滅的物從你們中間除掉，我就不再與你們同在了。</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米哀歌 3:40–41; 約書亞記 3:5; 馬太福音 7:5"> 你起來，叫百姓自潔，對他們說：『你們要自潔，預備明天，因為耶和華－以色列的上帝這樣說：以色列啊，你們中間有當滅的物，你們若不除掉，在仇敵面前必站立不住！』</span>
<span className="v" id="v14" data-v="14" data-xref="箴言 16:33; 約拿書 1:7; 約書亞記 7:17–18"> 到了早晨，你們要按着支派近前來；耶和華所取的支派，要按着宗族近前來；耶和華所取的宗族，要按着家室近前來；耶和華所取的家室，要按着人丁，一個一個地近前來。</span>
<span className="v" id="v15" data-v="15" data-xref="創世記 34:7; 撒母耳記上 14:38–39; 士師記 20:6"> 被取的人有當滅的物在他那裏，他和他所有的必被火焚燒；因他違背了耶和華的約，又因他在以色列中行了愚妄的事。」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="詩篇 119:60; 約書亞記 3:1; 創世記 22:3"> 於是，約書亞清早起來，使以色列人按着支派近前來，取出來的是猶大支派；</span>
<span className="v" id="v17" data-v="17" data-xref="民數記 26:20; 歷代志上 2:4–7; 創世記 38:30"> 使猶大支派<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是宗族">a</a></sup>近前來，就取了謝拉的宗族；使謝拉的宗族，按着家室人丁，一個一個地近前來，取出來的是撒底；</span>
<span className="v" id="v18" data-v="18" data-xref="民數記 32:23; 使徒行傳 5:1–10; 撒母耳記上 14:42"> 使撒底的家室，按着人丁，一個一個地近前來，就取出猶大支派的人謝拉的曾孫，撒底的孫子，迦米的兒子亞干。</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳記上 6:5; 耶利米書 13:16; 約翰福音 9:24"> 約書亞對亞干說：「我兒，我勸你將榮耀歸給耶和華－以色列的上帝，在他面前認罪，將你所做的事告訴我，不要向我隱瞞。」</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 38:18; 約伯記 33:27; 創世記 42:21"> 亞干回答約書亞說：「我實在得罪了耶和華－以色列的上帝。我所做的事如此如此：</span>
<span className="v" id="v21" data-v="21" data-xref="雅各書 1:15; 詩篇 119:37; 約翰一書 2:15–16"> 我在所奪的財物中看見一件美好的示拿衣服，二百舍客勒銀子，一條金子重五十舍客勒，我就貪愛這些物件，便拿去了。現今藏在我帳棚內的地裏，銀子在衣服底下。」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22"> 約書亞就打發人跑到亞干的帳棚裏。那件衣服果然藏在他帳棚內，銀子在底下。</span>
<span className="v" id="v23" data-v="23"> 他們就從帳棚裏取出來，拿到約書亞和以色列眾人那裏，放在耶和華面前。</span>
<span className="v" id="v24" data-v="24" data-xref="箴言 15:27; 提摩太前書 6:9–10; 約書亞記 7:26"> 約書亞和以色列眾人把謝拉的曾孫亞干和那銀子、那件衣服、那條金子，並亞干的兒女、牛、驢、羊、帳棚，以及他所有的，都帶到亞割谷去。</span>
<span className="v" id="v25" data-v="25" data-xref="約書亞記 6:18; 歷代志上 2:7; 利未記 24:14"> 約書亞說：「你為甚麼連累我們呢？今日耶和華必叫你受連累。」於是以色列眾人用石頭打死他，將石頭扔在其上，又用火焚燒他所有的<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原文是他們">b</a></sup>。</span>
<span className="v" id="v26" data-v="26" data-xref="以賽亞書 65:10; 何西阿書 2:15; 申命記 13:17"> 眾人在亞干身上堆成一大堆石頭，直存到今日。於是耶和華轉意，不發他的烈怒。因此那地方名叫亞割谷<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="就是連累的意思">c</a></sup>，直到今日。</span>
</div>

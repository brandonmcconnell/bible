## 尚未佔領之地

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="約書亞記 14:10; 申命記 31:3; 約書亞記 24:29"> 約書亞年紀老邁，耶和華對他說：「你年紀老邁了，還有許多未得之地，</span>
<span className="v" id="v2" data-v="2" data-xref="約書亞記 13:11; 撒母耳記上 27:8; 約珥書 3:4"> 就是非利士人的全境和基述人的全地。</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 2:23; 士師記 3:3; 耶利米書 2:18"> 從埃及前的西曷河往北，直到以革倫的境界，就算屬迦南人之地。有非利士人五個首領所管的迦薩人、亞實突人、亞實基倫人、迦特人、以革倫人之地，並有南方亞衛人之地。</span>
<span className="v" id="v4" data-v="4" data-xref="約書亞記 19:30; 撒母耳記上 4:1; 士師記 1:34–36"> 又有迦南人的全地，並屬西頓人的米亞拉到亞弗，直到亞摩利人的境界。</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀上 5:18; 約書亞記 12:7; 詩篇 83:7"> 還有迦巴勒人之地，並向日出的全黎巴嫩，就是從黑門山根的巴力‧迦得，直到哈馬口。</span>
<span className="v" id="v6" data-v="6" data-xref="約書亞記 11:8; 約書亞記 23:13; 士師記 2:21–23"> 山地的一切居民，從黎巴嫩直到米斯利弗‧瑪音，就是所有的西頓人，我必在以色列人面前趕出他們去。你只管照我所吩咐的，將這地拈鬮分給以色列人為業。</span>
<span className="v" id="v7" data-v="7" data-xref="民數記 26:53–56; 民數記 33:54; 以西結書 48:23–29"> 現在你要把這地分給九個支派和瑪拿西半個支派為業。」</span>
</div>
</div>

## 分配約旦河東之地

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="約書亞記 12:6; 申命記 3:12–17; 約書亞記 22:4"> 瑪拿西那半支派和呂便、迦得二支派已經受了產業，就是耶和華的僕人摩西在約旦河東所賜給他們的：</span>
<span className="v" id="v9" data-v="9" data-xref="約書亞記 13:16; 民數記 21:30; 約書亞記 12:2"> 是從亞嫩谷邊的亞羅珥和谷中的城，並米底巴的全平原，直到底本，</span>
<span className="v" id="v10" data-v="10" data-xref="民數記 21:24–26"> 和在希實本作王亞摩利王西宏的諸城，直到亞捫人的境界；</span>
<span className="v" id="v11" data-v="11" data-xref="歷代志上 2:23; 約書亞記 12:2–5; 申命記 4:47–48"> 又有基列地、基述人、瑪迦人的地界，並黑門全山、巴珊全地，直到撒迦；</span>
<span className="v" id="v12" data-v="12" data-xref="約書亞記 12:4; 約書亞記 14:3–4; 民數記 21:23–35"> 又有巴珊王噩的全國－他在亞斯他錄和以得來作王（利乏音人所存留的只剩下他）。這些地的人都是摩西所擊殺、所趕逐的。</span>
<span className="v" id="v13" data-v="13" data-xref="約書亞記 23:12–13; 約書亞記 13:11; 民數記 33:55"> 以色列人卻沒有趕逐基述人、瑪迦人；這些人仍住在以色列中，直到今日。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="民數記 18:20–24; 約書亞記 14:3–4; 申命記 18:1–2"> 只是利未支派，摩西<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是他">a</a></sup>沒有把產業分給他們。他們的產業乃是獻與耶和華－以色列上帝的火祭，正如耶和華所應許他們的。</span>
</div>
</div>

## 分給呂便支派的土地

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15"> 摩西按着呂便支派的宗族分給他們產業。</span>
<span className="v" id="v16" data-v="16" data-xref="約書亞記 13:9; 約書亞記 12:2; 以賽亞書 16:7–9"> 他們的境界是亞嫩谷邊的亞羅珥和谷中的城，靠近米底巴的全平原；</span>
<span className="v" id="v17" data-v="17" data-xref="民數記 22:41; 民數記 32:38; 民數記 21:19"> 希實本並屬希實本平原的各城，底本、巴末‧巴力、伯‧巴力‧勉、</span>
<span className="v" id="v18" data-v="18" data-xref="民數記 21:23; 約書亞記 21:36–37; 歷代志上 6:78–79"> 雅雜、基底莫、米法押、</span>
<span className="v" id="v19" data-v="19" data-xref="民數記 32:37–38"> 基列亭、西比瑪、谷中山的細列‧哈沙轄、</span>
<span className="v" id="v20" data-v="20" data-xref="約書亞記 12:3; 申命記 4:46; 以西結書 25:9"> 伯‧毗珥、毗斯迦山坡、伯‧耶西末；</span>
<span className="v" id="v21" data-v="21" data-xref="民數記 31:8; 申命記 3:10; 申命記 2:30–36"> 平原的各城，並亞摩利王西宏的全國。這西宏曾在希實本作王，摩西把他和米甸的族長以未、利金、蘇珥、戶珥、利巴擊殺了；這都是住那地屬西宏為首領的。</span>
<span className="v" id="v22" data-v="22" data-xref="民數記 31:8; 猶大書 1:11; 彼得後書 2:15"> 那時以色列人在所殺的人中，也用刀殺了比珥的兒子術士巴蘭。</span>
<span className="v" id="v23" data-v="23"> 呂便人的境界就是約旦河與靠近約旦河的地。以上是呂便人按着宗族所得為業的諸城，並屬城的村莊。</span>
</div>
</div>

## 分給迦得支派的土地

<div className="bt">
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="民數記 32:34–36"> 摩西按着迦得支派的宗族分給他們產業。</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳記下 12:26; 撒母耳記下 11:1; 民數記 32:35"> 他們的境界是雅謝和基列的各城，並亞捫人的一半地，直到拉巴前的亞羅珥；</span>
<span className="v" id="v26" data-v="26" data-xref="撒母耳記下 17:27; 撒母耳記下 2:8; 士師記 10:17"> 從希實本到拉抹‧米斯巴和比多寧，又從瑪哈念到底璧的境界，</span>
<span className="v" id="v27" data-v="27" data-xref="民數記 32:36; 民數記 34:11; 創世記 33:17"> 並谷中的伯‧亞蘭、伯‧寧拉、疏割、撒分，就是希實本王西宏國中的餘地，以及約旦河與靠近約旦河的地，直到基尼烈海的極邊，都在約旦河東。</span>
<span className="v" id="v28" data-v="28"> 以上是迦得人按着宗族所得為業的諸城，並屬城的村莊。</span>
</div>
</div>

## 分給瑪拿西半支派的土地

<div className="bt">
<div className="bp">
<span className="v" id="v29" data-v="29"> 摩西把產業分給瑪拿西半支派，是按着瑪拿西半支派的宗族所分的。</span>
<span className="v" id="v30" data-v="30" data-xref="約書亞記 13:26; 申命記 3:13–15; 民數記 32:39–41"> 他們的境界是從瑪哈念起，包括巴珊全地，就是巴珊王噩的全國，並在巴珊、睚珥的一切城邑，共六十個。</span>
<span className="v" id="v31" data-v="31" data-xref="約書亞記 12:4; 民數記 32:39–40"> 基列的一半，並亞斯他錄、以得來，就是屬巴珊王噩國的二城，是按着宗族給瑪拿西的兒子瑪吉的一半子孫。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32"> 以上是摩西在約旦河東對着耶利哥的摩押平原所分給他們的產業。</span>
<span className="v" id="v33" data-v="33" data-xref="約書亞記 18:7; 約書亞記 13:14; 申命記 18:1–2"> 只是利未支派，摩西沒有把產業分給他們。耶和華－以色列的上帝是他們的產業，正如耶和華所應許他們的。</span>
</div>
</div>

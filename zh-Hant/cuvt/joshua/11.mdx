## 約書亞擊敗耶賓和他的盟國

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="約書亞記 11:10; 詩篇 2:1–4; 士師記 4:2"> 夏瑣王耶賓聽見這事，就打發人去見瑪頓王約巴、伸崙王、押煞王，</span>
<span className="v" id="v2" data-v="2" data-xref="約書亞記 12:3; 士師記 1:27; 約書亞記 17:11"> 與北方山地、基尼烈南邊的亞拉巴高原，並西邊多珥山岡的諸王；</span>
<span className="v" id="v3" data-v="3" data-xref="士師記 3:3; 約書亞記 18:26; 創世記 31:49"> 又去見東方和西方的迦南人，與山地的亞摩利人、赫人、比利洗人、耶布斯人，並黑門山根米斯巴地的希未人。</span>
<span className="v" id="v4" data-v="4" data-xref="士師記 7:12; 撒母耳記上 13:5; 創世記 32:12"> 這些王和他們的眾軍都出來，人數多如海邊的沙，並有許多馬匹車輛。</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 118:10–12; 啟示錄 16:14; 以賽亞書 8:9"> 這諸王會合，來到米倫水邊，一同安營，要與以色列人爭戰。</span>
<span className="v" id="v6" data-v="6" data-xref="約書亞記 10:8; 撒母耳記下 8:4; 士師記 20:28"> 耶和華對約書亞說：「你不要因他們懼怕。明日這時，我必將他們交付以色列人全然殺了。你要砍斷他們馬的蹄筋，用火焚燒他們的車輛。」</span>
<span className="v" id="v7" data-v="7" data-xref="約書亞記 10:9; 帖撒羅尼迦前書 5:2–3"> 於是約書亞率領一切兵丁，在米倫水邊突然向前攻打他們。</span>
<span className="v" id="v8" data-v="8" data-xref="約書亞記 13:6; 約書亞記 19:28; 撒迦利亞書 9:2"> 耶和華將他們交在以色列人手裏，以色列人就擊殺他們，追趕他們到西頓大城，到米斯利弗‧瑪音，直到東邊米斯巴的平原，將他們擊殺，沒有留下一個。</span>
<span className="v" id="v9" data-v="9" data-xref="約書亞記 11:6; 以西結書 39:9–10"> 約書亞就照耶和華所吩咐他的去行，砍斷他們馬的蹄筋，用火焚燒他們的車輛。</span>
<span className="v" id="v10" data-v="10" data-xref="約書亞記 11:1; 士師記 4:2"> 當時，約書亞轉回奪了夏瑣，用刀擊殺夏瑣王。（素來夏瑣在這諸國中是為首的。）</span>
<span className="v" id="v11" data-v="11" data-xref="約書亞記 10:40; 申命記 20:16"> 以色列人用刀擊殺城中的人口，將他們盡行殺滅；凡有氣息的沒有留下一個。約書亞又用火焚燒夏瑣。</span>
<span className="v" id="v12" data-v="12" data-xref="申命記 20:16–17; 申命記 7:2; 民數記 33:50–53"> 約書亞奪了這些王的一切城邑，擒獲其中的諸王，用刀擊殺他們，將他們盡行殺滅，正如耶和華僕人摩西所吩咐的。</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米書 30:18"> 至於造在山岡上的城，除了夏瑣以外，以色列人都沒有焚燒。約書亞只將夏瑣焚燒了。</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 20:14; 民數記 31:9; 約書亞記 8:27"> 那些城邑所有的財物和牲畜，以色列人都取為自己的掠物；惟有一切人口都用刀擊殺，直到殺盡；凡有氣息的沒有留下一個。</span>
<span className="v" id="v15" data-v="15" data-xref="約書亞記 1:7; 出埃及記 34:11–13; 使徒行傳 20:20"> 耶和華怎樣吩咐他僕人摩西，摩西就照樣吩咐約書亞，約書亞也照樣行。凡耶和華所吩咐摩西的，約書亞沒有一件懈怠不行的。</span>
</div>
</div>

## 約書亞佔領的土地

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="約書亞記 10:41; 約書亞記 11:21; 約書亞記 12:8"> 約書亞奪了那全地，就是山地、一帶南地、歌珊全地、高原、亞拉巴、以色列的山地，和山下的高原。</span>
<span className="v" id="v17" data-v="17" data-xref="申命記 7:24; 約書亞記 11:3; 約書亞記 13:5"> 從上西珥的哈拉山，直到黑門山下黎巴嫩平原的巴力‧迦得，並且擒獲那些地的諸王，將他們殺死。</span>
<span className="v" id="v18" data-v="18" data-xref="約書亞記 14:7–10; 約書亞記 11:23"> 約書亞和這諸王爭戰了許多年日。</span>
<span className="v" id="v19" data-v="19" data-xref="約書亞記 9:3–27"> 除了基遍的希未人之外，沒有一城與以色列人講和的，都是以色列人爭戰奪來的。</span>
<span className="v" id="v20" data-v="20" data-xref="羅馬書 9:18; 申命記 20:16–17; 出埃及記 4:21"> 因為耶和華的意思是要使他們心裏剛硬，來與以色列人爭戰，好叫他們盡被殺滅，不蒙憐憫，正如耶和華所吩咐摩西的。</span>
<span className="v" id="v21" data-v="21" data-xref="申命記 9:2; 民數記 13:22–23; 約書亞記 15:13–14"> 當時約書亞來到，將住山地、希伯崙、底璧、亞拿伯、猶大山地、以色列山地所有的亞衲族人剪除了。約書亞將他們和他們的城邑盡都毀滅。</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳記上 17:4; 歷代志上 18:1; 約書亞記 15:46"> 在以色列人的地沒有留下一個亞衲族人，只在迦薩、迦特，和亞實突有留下的。</span>
<span className="v" id="v23" data-v="23" data-xref="約書亞記 21:44–45; 民數記 26:52–55; 約書亞記 14:1–15"> 這樣，約書亞照着耶和華所吩咐摩西的一切話奪了那全地，就按着以色列支派的宗族將地分給他們為業。於是國中太平，沒有爭戰了。</span>
</div>

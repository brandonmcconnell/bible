## 約書亞派探子進耶利哥

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="希伯來書 11:31; 雅各書 2:25; 馬太福音 1:5"> 當下，嫩的兒子約書亞從什亭暗暗打發兩個人作探子，吩咐說：「你們去窺探那地和耶利哥。」於是二人去了，來到一個妓女名叫喇合的家裏，就在那裏躺臥。</span>
<span className="v" id="v2" data-v="2" data-xref="以賽亞書 43:13; 但以理書 4:35; 箴言 21:30"> 有人告訴耶利哥王說：「今夜有以色列人來到這裏窺探此地。」</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳記下 10:3; 創世記 42:9–12; 使徒行傳 12:6"> 耶利哥王打發人去見喇合說：「那來到你這裏、進了你家的人要交出來，因為他們來窺探全地。」</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀下 6:19; 撒母耳記下 17:19–20; 撒母耳記下 16:18–19"> 女人將二人隱藏，就回答說：「那人果然到我這裏來；他們是哪裏來的我卻不知道。</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米書 50:20; 以西結書 47:12; 啟示錄 21:25"> 天黑、要關城門的時候，他們出去了，往哪裏去我卻不知道。你們快快地去追趕，就必追上。」（</span>
<span className="v" id="v6" data-v="6" data-xref="希伯來書 11:23; 雅各書 2:25; 歌羅西書 3:3"> 先是女人領二人上了房頂，將他們藏在那裏所擺的麻稭中。）</span>
<span className="v" id="v7" data-v="7" data-xref="士師記 3:28; 約書亞記 2:5; 士師記 12:5"> 那些人就往約旦河的渡口追趕他們去了。追趕他們的人一出去，城門就關了。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8"> 二人還沒有躺臥，女人就上房頂，到他們那裏，</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及記 23:27; 申命記 2:25; 約書亞記 2:11"> 對他們說：「我知道耶和華已經把這地賜給你們，並且因你們的緣故我們都驚慌了。這地的一切居民在你們面前心都消化了；</span>
<span className="v" id="v10" data-v="10" data-xref="民數記 21:21–35; 出埃及記 15:14–16; 出埃及記 14:21–31"> 因為我們聽見你們出埃及的時候，耶和華怎樣在你們前面使紅海的水乾了，並且你們怎樣待約旦河東的兩個亞摩利王西宏和噩，將他們盡行毀滅。</span>
<span className="v" id="v11" data-v="11" data-xref="申命記 4:39; 約書亞記 5:1; 約書亞記 7:5"> 我們一聽見這些事，心就消化了。因你們的緣故，並無一人有膽氣。耶和華－你們的上帝本是上天下地的上帝。</span>
<span className="v" id="v12" data-v="12" data-xref="約書亞記 2:18; 約書亞記 9:18–20; 提摩太後書 1:16–18"> 現在我既是恩待你們，求你們指着耶和華向我起誓，也要恩待我父家，並給我一個實在的證據，</span>
<span className="v" id="v13" data-v="13"> 要救活我的父母、弟兄、姊妹，和一切屬他們的，拯救我們性命不死。」</span>
<span className="v" id="v14" data-v="14" data-xref="馬太福音 5:7; 士師記 1:24–25; 創世記 24:49"> 二人對她說：「你若不洩漏我們這件事，我們情願替你們死。耶和華將這地賜給我們的時候，我們必以慈愛誠實待你。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="使徒行傳 9:25; 哥林多後書 11:33; 約書亞記 6:20"> 於是女人用繩子將二人從窗戶裏縋下去；因她的房子是在城牆邊上，她也住在城牆上。</span>
<span className="v" id="v16" data-v="16" data-xref="雅各書 2:25; 撒母耳記上 23:14; 詩篇 11:1"> 她對他們說：「你們且往山上去，恐怕追趕的人碰見你們；要在那裏隱藏三天，等追趕的人回來，然後才可以走你們的路。」</span>
<span className="v" id="v17" data-v="17" data-xref="民數記 30:2; 撒母耳記下 21:7; 創世記 24:3–8"> 二人對她說：「你要這樣行。不然，你叫我們所起的誓就與我們無干了。</span>
<span className="v" id="v18" data-v="18" data-xref="約書亞記 6:23; 約書亞記 2:21; 約書亞記 2:12–13"> 我們來到這地的時候，你要把這條朱紅線繩繫在縋我們下去的窗戶上，並要使你的父母、弟兄，和你父的全家都聚集在你家中。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行傳 27:31; 列王紀上 2:36–42; 出埃及記 12:13"> 凡出了你家門往街上去的，他的罪<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是血">a</a></sup>必歸到自己的頭上，與我們無干了。凡在你家裏的，若有人下手害他，流他血的罪就歸到我們的頭上。</span>
<span className="v" id="v20" data-v="20" data-xref="箴言 11:13"> 你若洩漏我們這件事，你叫我們所起的誓就與我們無干了。」</span>
<span className="v" id="v21" data-v="21" data-xref="約翰福音 2:5; 約書亞記 2:18; 馬太福音 7:24"> 女人說：「照你們的話行吧！」於是打發他們去了，又把朱紅線繩繫在窗戶上。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="撒母耳記上 19:10–12; 撒母耳記下 17:20; 詩篇 32:6–7"> 二人到山上，在那裏住了三天，等着追趕的人回去了。追趕的人一路找他們，卻找不着。</span>
<span className="v" id="v23" data-v="23"> 二人就下山回來，過了河，到嫩的兒子約書亞那裏，向他述說所遭遇的一切事；</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及記 23:31; 約書亞記 1:8; 約書亞記 2:9–11"> 又對約書亞說：「耶和華果然將那全地交在我們手中；那地的一切居民在我們面前心都消化了。」</span>
</div>
</div>

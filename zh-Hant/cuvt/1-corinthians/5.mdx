## 判斷淫亂的事件

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="啟示錄 21:8; 啟示錄 2:21; 歌羅西書 3:5"> 風聞在你們中間有淫亂的事。這樣的淫亂連外邦人中也沒有，就是有人收了他的繼母。</span>
<span className="v" id="v2" data-v="2" data-xref="啟示錄 2:20–22; 哥林多後書 7:7–11; 哥林多前書 5:13"> 你們還是自高自大，並不哀痛，把行這事的人從你們中間趕出去。</span>
<span className="v" id="v3" data-v="3" data-xref="歌羅西書 2:5; 帖撒羅尼迦前書 2:17; 哥林多後書 13:2"> 我身子雖不在你們那裏，心卻在你們那裏，好像我親自與你們同在，已經判斷了行這事的人。</span>
<span className="v" id="v4" data-v="4" data-xref="約翰福音 20:23; 歌羅西書 3:17; 馬太福音 16:19"> 就是你們聚會的時候，我的心也同在。奉我們主耶穌的名，並用我們主耶穌的權能，</span>
<span className="v" id="v5" data-v="5" data-xref="提摩太前書 1:20; 帖撒羅尼迦後書 3:14–15; 加拉太書 6:1–2"> 要把這樣的人交給撒但，敗壞他的肉體，使他的靈魂在主耶穌的日子可以得救。</span>
<span className="v" id="v6" data-v="6" data-xref="加拉太書 5:9; 哥林多前書 15:33; 雅各書 4:16"> 你們這自誇是不好的。豈不知一點麵酵能使全團發起來嗎？</span>
<span className="v" id="v7" data-v="7" data-xref="彼得前書 1:19–20; 以弗所書 4:22; 歌羅西書 3:5–9"> 你們既是無酵的麵，應當把舊酵除淨，好使你們成為新團；因為我們逾越節的羔羊基督已經被殺獻祭了。</span>
<span className="v" id="v8" data-v="8" data-xref="彼得前書 2:1–2; 申命記 16:3; 出埃及記 12:15"> 所以，我們守這節不可用舊酵，也不可用惡毒<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或譯：陰毒">a</a></sup>、邪惡的酵，只用誠實真正的無酵餅。</span>
<span className="v" id="v9" data-v="9" data-xref="以弗所書 5:11; 帖撒羅尼迦後書 3:14; 哥林多後書 6:14"> 我先前寫信給你們說，不可與淫亂的人相交。</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多前書 10:27; 約翰福音 17:15–16; 馬太福音 5:14–16"> 此話不是指這世上一概行淫亂的，或貪婪的，勒索的，或拜偶像的；若是這樣，你們除非離開世界方可。</span>
<span className="v" id="v11" data-v="11" data-xref="羅馬書 16:17; 帖撒羅尼迦後書 3:14; 帖撒羅尼迦後書 3:6"> 但如今我寫信給你們說，若有稱為弟兄是行淫亂的，或貪婪的，或拜偶像的，或辱罵的，或醉酒的，或勒索的，這樣的人不可與他相交，就是與他吃飯都不可。</span>
<span className="v" id="v12" data-v="12" data-xref="馬可福音 4:11; 提摩太前書 3:7; 路加福音 12:14"> 因為審判教外的人與我何干？教內的人豈不是你們審判的嗎？</span>
<span className="v" id="v13" data-v="13" data-xref="申命記 17:7; 申命記 13:5; 申命記 21:21"> 至於外人有上帝審判他們。你們應當把那惡人從你們中間趕出去。</span>

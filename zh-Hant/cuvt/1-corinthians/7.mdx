## 婚姻的問題

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多前書 7:8; 哥林多前書 7:26–27; 哥林多前書 7:37–38"> 論到你們信上所提的事，我說男不近女倒好。</span>
<span className="v" id="v2" data-v="2" data-xref="以弗所書 5:28; 以弗所書 5:33; 哥林多前書 7:9"> 但要免淫亂的事，男子當各有自己的妻子；女子也當各有自己的丈夫。</span>
<span className="v" id="v3" data-v="3" data-xref="彼得前書 3:7; 出埃及記 21:10"> 丈夫當用合宜之分待妻子；妻子待丈夫也要如此。</span>
<span className="v" id="v4" data-v="4" data-xref="何西阿書 3:3; 馬太福音 19:9; 馬可福音 10:11–12"> 妻子沒有權柄主張自己的身子，乃在丈夫；丈夫也沒有權柄主張自己的身子，乃在妻子。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 19:15; 約珥書 2:16; 撒迦利亞書 12:12–14"> 夫妻不可彼此虧負，除非兩相情願，暫時分房，為要專心禱告方可；以後仍要同房，免得撒但趁着你們情不自禁，引誘你們。</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多後書 8:8; 哥林多前書 7:25; 哥林多前書 7:12"> 我說這話，原是准你們的，不是命你們的。</span>
<span className="v" id="v7" data-v="7" data-xref="馬太福音 19:11–12; 羅馬書 12:6; 哥林多前書 9:5"> 我願意眾人像我一樣；只是各人領受上帝的恩賜，一個是這樣，一個是那樣。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="哥林多前書 7:32; 哥林多前書 7:34–35; 哥林多前書 7:26–27"> 我對着沒有嫁娶的和寡婦說，若他們常像我就好。</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多前書 7:2; 提摩太前書 5:14; 提摩太前書 5:11"> 倘若自己禁止不住，就可以嫁娶。與其慾火攻心，倒不如嫁娶為妙。</span>
<span className="v" id="v10" data-v="10" data-xref="馬太福音 5:32; 路加福音 16:18; 馬太福音 19:3–9"> 至於那已經嫁娶的，我吩咐他們；其實不是我吩咐，乃是主吩咐說：妻子不可離開丈夫，</span>
<span className="v" id="v11" data-v="11" data-xref="耶利米書 3:1; 哥林多前書 7:10; 以賽亞書 50:1"> 若是離開了，不可再嫁，或是仍同丈夫和好。丈夫也不可離棄妻子。</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多後書 11:17; 哥林多前書 7:6; 哥林多前書 7:25"> 我對其餘的人說（不是主說）：倘若某弟兄有不信的妻子，妻子也情願和他同住，他就不要離棄妻子。</span>
<span className="v" id="v13" data-v="13"> 妻子有不信的丈夫，丈夫也情願和她同住，她就不要離棄丈夫。</span>
<span className="v" id="v14" data-v="14" data-xref="瑪拉基書 2:15–16; 提摩太前書 4:5; 提多書 1:15"> 因為不信的丈夫就因着妻子成了聖潔，並且不信的妻子就因着丈夫<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是弟兄">a</a></sup>成了聖潔。不然，你們的兒女就不潔淨，但如今他們是聖潔的了。</span>
<span className="v" id="v15" data-v="15" data-xref="羅馬書 14:19; 哥林多後書 13:11; 雅各書 3:17–18"> 倘若那不信的人要離去，就由他離去吧！無論是弟兄，是姊妹，遇着這樣的事都不必拘束。上帝召我們原是要我們和睦。</span>
<span className="v" id="v16" data-v="16" data-xref="彼得前書 3:1–2; 哥林多前書 9:22; 羅馬書 11:14"> 你這作妻子的，怎麼知道不能救你的丈夫呢？你這作丈夫的，怎麼知道不能救你的妻子呢？</span>
</div>
</div>

## 照主分給各人的去行

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="哥林多前書 4:17; 羅馬書 12:3–8; 哥林多前書 7:24"> 只要照主所分給各人的，和上帝所召各人的而行。我吩咐各教會都是這樣。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行傳 15:5; 使徒行傳 15:28; 使徒行傳 15:24"> 有人已受割禮蒙召呢，就不要廢割禮；有人未受割禮蒙召呢，就不要受割禮。</span>
<span className="v" id="v19" data-v="19" data-xref="加拉太書 6:15; 加拉太書 5:6; 約翰一書 2:3–4"> 受割禮算不得甚麼，不受割禮也算不得甚麼，只要守上帝的誡命就是了。</span>
<span className="v" id="v20" data-v="20" data-xref="哥林多前書 7:17; 帖撒羅尼迦前書 4:11; 帖撒羅尼迦後書 3:12"> 各人蒙召的時候是甚麼身分，仍要守住這身分。</span>
<span className="v" id="v21" data-v="21" data-xref="彼得前書 2:18–24; 歌羅西書 3:11; 路加福音 10:40–41"> 你是作奴隸蒙召的嗎？不要因此憂慮；若能以自由，就求自由更好。</span>
<span className="v" id="v22" data-v="22" data-xref="彼得前書 2:16; 腓利門書 1:16; 歌羅西書 3:22–24"> 因為作奴僕蒙召於主的，就是主所釋放的人；作自由之人蒙召的，就是基督的奴僕。</span>
<span className="v" id="v23" data-v="23" data-xref="哥林多前書 6:20; 彼得前書 1:18–19; 提多書 2:14"> 你們是重價買來的，不要作人的奴僕。</span>
<span className="v" id="v24" data-v="24" data-xref="哥林多前書 7:20; 歌羅西書 3:23–24; 哥林多前書 7:17"> 弟兄們，你們各人蒙召的時候是甚麼身分，仍要在上帝面前守住這身分。</span>
</div>
</div>

## 未婚和寡居

<div className="bt">
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="哥林多前書 7:6; 哥林多前書 4:2; 哥林多前書 7:40"> 論到童身的人，我沒有主的命令，但我既蒙主憐恤能作忠心的人，就把自己的意見告訴你們。</span>
<span className="v" id="v26" data-v="26" data-xref="哥林多前書 7:1; 哥林多前書 7:8; 彼得前書 4:17"> 因現今的艱難，據我看來，人不如守素安常才好。</span>
<span className="v" id="v27" data-v="27" data-xref="哥林多前書 7:20; 哥林多前書 7:12–14"> 你有妻子纏着呢，就不要求脫離；你沒有妻子纏着呢，就不要求妻子。</span>
<span className="v" id="v28" data-v="28" data-xref="希伯來書 13:4; 哥林多前書 7:32–36; 哥林多前書 7:26"> 你若娶妻，並不是犯罪；處女若出嫁，也不是犯罪。然而這等人肉身必受苦難，我卻願意你們免這苦難。</span>
<span className="v" id="v29" data-v="29" data-xref="約翰一書 2:17; 哥林多前書 7:31; 羅馬書 13:11–12"> 弟兄們，我對你們說：時候減少了。從此以後，那有妻子的，要像沒有妻子；</span>
<span className="v" id="v30" data-v="30" data-xref="詩篇 30:5; 路加福音 6:25; 路加福音 6:21"> 哀哭的，要像不哀哭；快樂的，要像不快樂；置買的，要像無有所得；</span>
<span className="v" id="v31" data-v="31" data-xref="約翰一書 2:17; 彼得前書 4:7; 雅各書 4:14"> 用世物的，要像不用世物，因為這世界的樣子將要過去了。</span>
<span className="v" id="v32" data-v="32" data-xref="馬太福音 6:25–34; 提摩太前書 5:5; 腓立比書 4:6"> 我願你們無所掛慮。沒有娶妻的，是為主的事掛慮，想怎樣叫主喜悅。</span>
<span className="v" id="v33" data-v="33" data-xref="彼得前書 3:7; 歌羅西書 3:19; 以弗所書 5:25–33"> 娶了妻的，是為世上的事掛慮，想怎樣叫妻子喜悅。</span>
<span className="v" id="v34" data-v="34" data-xref="路加福音 10:40–42; 哥林多前書 6:20; 路加福音 2:36–37"> 婦人和處女也有分別。沒有出嫁的，是為主的事掛慮，要身體、靈魂都聖潔；已經出嫁的，是為世上的事掛慮，想怎樣叫丈夫喜悅。</span>
<span className="v" id="v35" data-v="35" data-xref="哥林多前書 7:33–34; 哥林多前書 7:36; 路加福音 8:14"> 我說這話是為你們的益處，不是要牢籠你們，乃是要叫你們行合宜的事，得以殷勤服事主，沒有分心的事。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="哥林多前書 7:37; 哥林多前書 7:9; 撒母耳記上 2:33"> 若有人以為自己待他的女兒不合宜，女兒也過了年歲，事又當行，他就可隨意辦理，不算有罪，叫二人成親就是了。</span>
<span className="v" id="v37" data-v="37"> 倘若人心裏堅定，沒有不得已的事，並且由得自己作主，心裏又決定了留下女兒不出嫁，如此行也好。</span>
<span className="v" id="v38" data-v="38" data-xref="希伯來書 13:4; 哥林多前書 7:1–2; 哥林多前書 7:8"> 這樣看來，叫自己的女兒出嫁是好，不叫她出嫁更是好。</span>
<span className="v" id="v39" data-v="39" data-xref="羅馬書 7:2–3; 哥林多後書 6:14–16; 哥林多前書 7:10"> 丈夫活着的時候，妻子是被約束的；丈夫若死了，妻子就可以自由，隨意再嫁，只是要嫁這在主裏面的人。</span>
<span className="v" id="v40" data-v="40" data-xref="哥林多前書 7:35; 彼得後書 3:15–16; 哥林多前書 7:8"> 然而按我的意見，若常守節更有福氣。我也想自己是被上帝的靈感動了。</span>
</div>
</div>

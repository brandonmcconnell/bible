## 捐助聖徒

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="羅馬書 12:13; 哥林多後書 8:1–9; 哥林多後書 9:12–15"> 論到為聖徒捐錢，我從前怎樣吩咐加拉太的眾教會，你們也當怎樣行。</span>
<span className="v" id="v2" data-v="2" data-xref="瑪拉基書 3:9–10; 申命記 15:11–14; 申命記 8:18"> 每逢七日的第一日，各人要照自己的進項抽出來留着，免得我來的時候現湊。</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多後書 8:6; 哥林多前書 11:34; 哥林多前書 4:19–21"> 及至我來到了，你們寫信舉薦誰，我就打發他們，把你們的捐資送到耶路撒冷去。</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多後書 8:4; 哥林多後書 8:19; 羅馬書 15:25"> 若我也該去，他們可以和我同去。</span>
</div>
</div>

## 行程的計劃

<div className="bt">
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="使徒行傳 19:21; 哥林多前書 4:19; 哥林多後書 1:15–17"> 我要從馬其頓經過；既經過了，就要到你們那裏去，</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行傳 15:3; 羅馬書 15:24; 使徒行傳 20:38"> 或者和你們同住幾時，或者也過冬。無論我往哪裏去，你們就可以給我送行。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行傳 18:21; 哥林多前書 4:19; 雅各書 4:15"> 我如今不願意路過見你們；主若許我，我就指望和你們同住幾時。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行傳 2:1; 出埃及記 23:16; 使徒行傳 18:19"> 但我要仍舊住在以弗所，直等到五旬節；</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多後書 2:12; 使徒行傳 14:27; 歌羅西書 4:3"> 因為有寬大又有功效的門為我開了，並且反對的人也多。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="哥林多前書 15:58; 帖撒羅尼迦前書 3:2; 羅馬書 16:21"> 若是提摩太來到，你們要留心，叫他在你們那裏無所懼怕；因為他勞力做主的工，像我一樣。</span>
<span className="v" id="v11" data-v="11" data-xref="提摩太前書 4:12; 使徒行傳 15:33; 提多書 2:15"> 所以，無論誰都不可藐視他，只要送他平安前行，叫他到我這裏來，因我指望他和弟兄們同來。</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多前書 1:12; 哥林多前書 3:5; 提多書 3:4"> 至於兄弟亞波羅，我再三地勸他同弟兄們到你們那裏去；但這時他決不願意去，幾時有了機會他必去。</span>
</div>
</div>

## 請求和問安

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="約書亞記 1:9; 以弗所書 6:13–18; 以弗所書 6:10"> 你們務要警醒，在真道上站立得穩，要作大丈夫，要剛強。</span>
<span className="v" id="v14" data-v="14" data-xref="約翰福音 13:34–35; 彼得前書 4:8; 提摩太前書 1:5"> 凡你們所做的都要憑愛心而做。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="哥林多前書 1:16; 羅馬書 16:5; 羅馬書 16:2"> 弟兄們，你們曉得司提法那一家，是亞該亞初結的果子，並且他們專以服事聖徒為念。</span>
<span className="v" id="v16" data-v="16" data-xref="希伯來書 13:17; 帖撒羅尼迦前書 5:12; 約翰三書 1:8"> 我勸你們順服這樣的人，並一切同工同勞的人。</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多後書 11:9; 腓立比書 2:30; 腓利門書 1:13"> 司提法那和福徒拿都，並亞該古到這裏來，我很喜歡；因為你們待我有不及之處，他們補上了。</span>
<span className="v" id="v18" data-v="18" data-xref="腓利門書 1:7; 哥林多後書 7:13; 帖撒羅尼迦前書 5:12"> 他們叫我和你們心裏都快活。這樣的人，你們務要敬重。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="使徒行傳 18:2; 腓利門書 1:2; 羅馬書 16:3–5"> 亞細亞的眾教會問你們安。亞居拉和百基拉並在他們家裏的教會，因主多多地問你們安。</span>
<span className="v" id="v20" data-v="20" data-xref="羅馬書 16:16; 帖撒羅尼迦前書 5:26; 彼得前書 5:14"> 眾弟兄都問你們安。你們要親嘴問安，彼此務要聖潔。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="歌羅西書 4:18; 加拉太書 6:11; 帖撒羅尼迦後書 3:17"> 我－保羅親筆問安。</span>
<span className="v" id="v22" data-v="22" data-xref="以弗所書 6:24; 約翰福音 14:21; 哥林多後書 5:14–15"> 若有人不愛主，這人可詛可咒。主必要來！</span>
<span className="v" id="v23" data-v="23" data-xref="羅馬書 16:20; 羅馬書 16:23"> 願主耶穌基督的恩常與你們眾人同在！</span>
<span className="v" id="v24" data-v="24" data-xref="哥林多前書 14:16; 啟示錄 3:19; 哥林多後書 12:15"> 我在基督耶穌裏的愛與你們眾人同在。阿們！</span>
</div>
</div>

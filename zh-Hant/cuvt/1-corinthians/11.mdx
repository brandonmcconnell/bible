## 禮拜時蒙頭的問題

<div className="bt">
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="帖撒羅尼迦後書 2:15; 哥林多前書 4:17; 箴言 31:28–31"> 我稱讚你們，因你們凡事記念我，又堅守我所傳給你們的。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 3:16; 歌羅西書 1:18; 歌羅西書 3:18"> 我願意你們知道，基督是各人的頭；男人是女人的頭；上帝是基督的頭。</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳記下 15:30; 哥林多前書 12:28; 哥林多前書 12:10"> 凡男人禱告或是講道<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或譯：說預言；下同">a</a></sup>，若蒙着頭，就羞辱自己的頭。</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 21:12; 路加福音 2:36; 使徒行傳 2:17"> 凡女人禱告或是講道，若不蒙着頭，就羞辱自己的頭，因為這就如同剃了頭髮一樣。</span>
<span className="v" id="v6" data-v="6" data-xref="申命記 22:5; 民數記 5:18"> 女人若不蒙着頭，就該剪了頭髮；女人若以剪髮、剃髮為羞愧，就該蒙着頭。</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多前書 11:3; 創世記 5:1; 詩篇 8:6"> 男人本不該蒙着頭，因為他是上帝的形像和榮耀；但女人是男人的榮耀。</span>
<span className="v" id="v8" data-v="8" data-xref="提摩太前書 2:13; 創世記 2:21–23"> 起初，男人不是由女人而出，女人乃是由男人而出；</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 2:18; 創世記 2:23–24; 創世記 2:20"> 並且男人不是為女人造的，女人乃是為男人造的。</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 24:64–65; 希伯來書 1:14; 馬太福音 18:10"> 因此，女人為天使的緣故，應當在頭上有服權柄的記號。</span>
<span className="v" id="v11" data-v="11" data-xref="加拉太書 3:28; 哥林多前書 7:10–14; 哥林多前書 12:12–22"> 然而照主的安排，女也不是無男，男也不是無女。</span>
<span className="v" id="v12" data-v="12" data-xref="羅馬書 11:36; 哥林多前書 8:6; 希伯來書 1:2–3"> 因為女人原是由男人而出，男人也是由女人而出；但萬有都是出乎上帝。</span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 12:57; 約翰福音 7:24; 哥林多前書 10:15"> 你們自己審察，女人禱告上帝，不蒙着頭是合宜的嗎？</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳記下 14:26; 哥林多前書 14:35"> 你們的本性不也指示你們，男人若有長頭髮，便是他的羞辱嗎？</span>
<span className="v" id="v15" data-v="15"> 但女人有長頭髮，乃是她的榮耀，因為這頭髮是給她作蓋頭的。</span>
<span className="v" id="v16" data-v="16" data-xref="哥林多前書 7:17; 提摩太前書 6:3–4; 帖撒羅尼迦前書 2:14"> 若有人想要辯駁，我們卻沒有這樣的規矩，上帝的眾教會也是沒有的。</span>
</div>
</div>

## 聖餐時的混亂

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="希伯來書 10:25; 哥林多前書 14:23; 哥林多前書 11:22"> 我現今吩咐你們的話，不是稱讚你們；因為你們聚會不是受益，乃是招損。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前書 3:3; 哥林多前書 1:10–12; 哥林多前書 5:1"> 第一，我聽說，你們聚會的時候彼此分門別類，我也稍微地信這話。</span>
<span className="v" id="v19" data-v="19" data-xref="約翰一書 2:19; 提多書 3:10; 使徒行傳 20:30"> 在你們中間不免有分門結黨的事，好叫那些有經驗的人顯明出來。</span>
<span className="v" id="v20" data-v="20"> 你們聚會的時候，算不得吃主的晚餐；</span>
<span className="v" id="v21" data-v="21" data-xref="彼得後書 2:13; 猶大書 1:12; 哥林多前書 11:23–25"> 因為吃的時候，各人先吃自己的飯，甚至這個飢餓，那個酒醉。</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行傳 20:28; 箴言 17:5; 雅各書 2:5–6"> 你們要吃喝，難道沒有家嗎？還是藐視上帝的教會，叫那沒有的羞愧呢？我向你們可怎麼說呢？可因此稱讚你們嗎？我不稱讚！</span>
</div>
</div>

## 聖餐的設立

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="路加福音 22:19–20; 馬太福音 26:26–28; 哥林多前書 11:23–25"> 我當日傳給你們的，原是從主領受的，就是主耶穌被賣的那一夜，拿起餅來，</span>
<span className="v" id="v24" data-v="24" data-xref="約翰福音 6:53–58; 哥林多前書 11:27–28; 哥林多前書 10:3–4"> 祝謝了，就擘開，說：「這是我的身體，為你們捨<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有古卷：擘開">b</a></sup>的，你們應當如此行，為的是記念我。」</span>
<span className="v" id="v25" data-v="25" data-xref="路加福音 22:20; 希伯來書 9:15–20; 希伯來書 13:20"> 飯後，也照樣拿起杯來，說：「這杯是用我的血所立的新約，你們每逢喝的時候，要如此行，為的是記念我。」</span>
<span className="v" id="v26" data-v="26" data-xref="希伯來書 9:28; 啟示錄 1:7; 約翰福音 14:3"> 你們每逢吃這餅，喝這杯，是表明主的死，直等到他來。</span>
</div>
</div>

## 不按理吃主的晚餐

<div className="bt">
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="約翰福音 6:51; 哥林多前書 10:21; 希伯來書 10:29"> 所以，無論何人，不按理吃主的餅，喝主的杯，就是干犯主的身、主的血了。</span>
<span className="v" id="v28" data-v="28" data-xref="加拉太書 6:4; 哥林多後書 13:5; 耶利米哀歌 3:40"> 人應當自己省察，然後吃這餅、喝這杯。</span>
<span className="v" id="v29" data-v="29" data-xref="哥林多前書 11:27; 哥林多前書 11:30; 哥林多前書 11:32–34"> 因為人吃喝，若不分辨是主的身體，就是吃喝自己的罪了。</span>
<span className="v" id="v30" data-v="30" data-xref="啟示錄 3:19; 民數記 20:12; 阿摩司書 3:2"> 因此，在你們中間有好些軟弱的與患病的，死<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="原文是睡">c</a></sup>的也不少。</span>
<span className="v" id="v31" data-v="31" data-xref="約翰一書 1:9; 詩篇 32:3–5; 啟示錄 2:5"> 我們若是先分辨自己，就不至於受審。</span>
<span className="v" id="v32" data-v="32" data-xref="希伯來書 12:5–11; 詩篇 118:18; 箴言 3:11–12"> 我們受審的時候，乃是被主懲治，免得我們和世人一同定罪。</span>
<span className="v" id="v33" data-v="33"> 所以我弟兄們，你們聚會吃的時候，要彼此等待。</span>
<span className="v" id="v34" data-v="34" data-xref="哥林多前書 11:21–22; 哥林多前書 7:17; 哥林多前書 4:19"> 若有人飢餓，可以在家裏先吃，免得你們聚會，自己取罪。其餘的事，我來的時候再安排。</span>
</div>

## 使徒的權利

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行傳 9:17; 提摩太前書 2:7; 哥林多前書 9:19"> 我不是自由的嗎？我不是使徒嗎？我不是見過我們的主耶穌嗎？你們不是我在主裏面所做之工嗎？</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多後書 12:12; 約翰福音 6:27; 哥林多後書 3:1–3"> 假若在別人，我不是使徒，在你們，我總是使徒，因為你們在主裏正是我作使徒的印證。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="哥林多後書 12:16–19; 哥林多後書 13:3; 哥林多後書 13:10"> 我對那盤問我的人就是這樣分訴：</span>
<span className="v" id="v4" data-v="4" data-xref="帖撒羅尼迦前書 2:6; 帖撒羅尼迦後書 3:8–9; 路加福音 10:7"> 難道我們沒有權柄靠福音吃喝嗎？</span>
<span className="v" id="v5" data-v="5" data-xref="約翰福音 1:42; 希伯來書 13:4; 馬太福音 8:14"> 難道我們沒有權柄娶信主的姊妹為妻，帶着一同往來，彷彿其餘的使徒和主的弟兄並磯法一樣嗎？</span>
<span className="v" id="v6" data-v="6" data-xref="帖撒羅尼迦後書 3:7–9; 使徒行傳 13:1–2; 使徒行傳 4:36"> 獨有我與巴拿巴沒有權柄不做工嗎？</span>
<span className="v" id="v7" data-v="7" data-xref="箴言 27:18; 申命記 20:6; 提摩太後書 2:3–4"> 有誰當兵自備糧餉呢？有誰栽葡萄園不吃園裏的果子呢？有誰牧養牛羊不吃牛羊的奶呢？</span>
<span className="v" id="v8" data-v="8" data-xref="以賽亞書 8:20; 帖撒羅尼迦前書 4:8; 羅馬書 3:31"> 我說這話，豈是照人的意見；律法不也是這樣說嗎？</span>
<span className="v" id="v9" data-v="9" data-xref="申命記 25:4; 提摩太前書 5:18; 詩篇 104:27"> 就如摩西的律法記着說：「牛在場上踹穀的時候，不可籠住牠的嘴。」難道上帝所掛念的是牛嗎？</span>
<span className="v" id="v10" data-v="10" data-xref="提摩太後書 2:6; 羅馬書 15:4; 羅馬書 4:23–24"> 不全是為我們說的嗎？分明是為我們說的。因為耕種的當存着指望去耕種；打場的也當存得糧的指望去打場。</span>
<span className="v" id="v11" data-v="11" data-xref="羅馬書 15:27; 加拉太書 6:6; 哥林多後書 11:15"> 我們若把屬靈的種子撒在你們中間，就是從你們收割奉養肉身之物，這還算大事嗎？</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多前書 9:15; 哥林多前書 9:18; 哥林多後書 11:12"> 若別人在你們身上有這權柄，何況我們呢？<br />然而，我們沒有用過這權柄，倒凡事忍受，免得基督的福音被阻隔。</span>
<span className="v" id="v13" data-v="13" data-xref="民數記 18:8–20; 民數記 5:9–10; 利未記 6:26"> 你們豈不知為聖事勞碌的就吃殿中的物嗎？伺候祭壇的就分領壇上的物嗎？</span>
<span className="v" id="v14" data-v="14" data-xref="馬太福音 10:10; 提摩太前書 5:17–18; 哥林多前書 9:4"> 主也是這樣命定，叫傳福音的靠着福音養生。</span>
<span className="v" id="v15" data-v="15" data-xref="帖撒羅尼迦前書 2:9; 帖撒羅尼迦後書 3:8; 哥林多前書 9:12"> 但這權柄我全沒有用過。我寫這話，並非要你們這樣待我，因為我寧可死也不叫人使我所誇的落了空。</span>
<span className="v" id="v16" data-v="16" data-xref="羅馬書 1:14; 耶利米書 20:9; 歌羅西書 4:17"> 我傳福音原沒有可誇的，因為我是不得已的。若不傳福音，我便有禍了。</span>
<span className="v" id="v17" data-v="17" data-xref="加拉太書 2:7; 哥林多前書 3:8; 歷代志上 28:9"> 我若甘心做這事，就有賞賜；若不甘心，責任卻已經託付我了。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多後書 11:7–9; 哥林多前書 8:9; 帖撒羅尼迦前書 2:6"> 既是這樣，我的賞賜是甚麼呢？就是我傳福音的時候叫人不花錢得福音，免得用盡我傳福音的權柄。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="加拉太書 5:13; 馬太福音 18:15; 雅各書 5:19–20"> 我雖是自由的，無人轄管；然而我甘心作了眾人的僕人，為要多得人。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行傳 16:3; 加拉太書 5:18; 使徒行傳 21:20–26"> 向猶太人，我就作猶太人，為要得猶太人；向律法以下的人，我雖不在律法以下，還是作律法以下的人，為要得律法以下的人。</span>
<span className="v" id="v21" data-v="21" data-xref="羅馬書 2:12; 羅馬書 2:14; 加拉太書 3:2"> 向沒有律法的人，我就作沒有律法的人，為要得沒有律法的人；其實我在上帝面前，不是沒有律法；在基督面前，正在律法之下。</span>
<span className="v" id="v22" data-v="22" data-xref="哥林多前書 10:33; 羅馬書 15:1; 哥林多前書 9:19"> 向軟弱的人，我就作軟弱的人，為要得軟弱的人。向甚麼樣的人，我就作甚麼樣的人。無論如何，總要救些人。</span>
<span className="v" id="v23" data-v="23" data-xref="提摩太後書 2:10; 馬可福音 8:35; 哥林多前書 9:25–27"> 凡我所行的，都是為福音的緣故，為要與人同得這福音的好處。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="腓立比書 3:14; 希伯來書 12:1; 提摩太後書 4:7–8"> 豈不知在場上賽跑的都跑，但得獎賞的只有一人？你們也當這樣跑，好叫你們得着獎賞。</span>
<span className="v" id="v25" data-v="25" data-xref="提摩太後書 2:5; 啟示錄 2:10; 提摩太後書 4:7–8"> 凡較力爭勝的，諸事都有節制，他們不過是要得能壞的冠冕；我們卻是要得不能壞的冠冕。</span>
<span className="v" id="v26" data-v="26" data-xref="彼得後書 1:10; 腓立比書 1:21; 提摩太後書 2:5"> 所以，我奔跑不像無定向的；我鬥拳不像打空氣的。</span>
<span className="v" id="v27" data-v="27" data-xref="羅馬書 8:13; 哥林多前書 9:25; 歌羅西書 3:5"> 我是攻克己身，叫身服我，恐怕我傳福音給別人，自己反被棄絕了。</span>
</div>
</div>

## 基督的復活

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="加拉太書 1:6–12; 彼得前書 5:12; 哥林多前書 15:3–11"> 弟兄們，我如今把先前所傳給你們的福音告訴你們知道；這福音你們也領受了，又靠着站立得住，</span>
<span className="v" id="v2" data-v="2" data-xref="希伯來書 3:6; 希伯來書 2:1; 希伯來書 3:14"> 並且你們若不是徒然相信，能以持守我所傳給你們的，就必因這福音得救。</span>
<span className="v" id="v3" data-v="3" data-xref="彼得前書 2:24; 加拉太書 1:4; 以賽亞書 53:1–12"> 我當日所領受又傳給你們的：第一，就是基督照聖經所說，為我們的罪死了，</span>
<span className="v" id="v4" data-v="4" data-xref="何西阿書 6:2; 馬太福音 12:40; 詩篇 16:10–11"> 而且埋葬了；又照聖經所說，第三天復活了，</span>
<span className="v" id="v5" data-v="5" data-xref="馬可福音 16:14; 哥林多前書 1:12; 約翰福音 1:42"> 並且顯給磯法看，然後顯給十二使徒看；</span>
<span className="v" id="v6" data-v="6" data-xref="馬太福音 28:10; 馬可福音 16:7; 使徒行傳 13:36"> 後來一時顯給五百多弟兄看，其中一大半到如今還在，卻也有已經睡了的。</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 24:50; 使徒行傳 1:2–12; 路加福音 24:33"> 以後顯給雅各看，再顯給眾使徒看，</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多前書 9:1; 使徒行傳 26:16; 使徒行傳 22:18"> 末了也顯給我看；我如同未到產期而生的人一般。</span>
<span className="v" id="v9" data-v="9" data-xref="以弗所書 3:7–8; 提摩太前書 1:13–15; 使徒行傳 8:3"> 我原是使徒中最小的，不配稱為使徒，因為我從前逼迫上帝的教會。</span>
<span className="v" id="v10" data-v="10" data-xref="腓立比書 4:13; 哥林多後書 3:5; 腓立比書 2:13"> 然而，我今日成了何等人，是蒙上帝的恩才成的，並且他所賜我的恩不是徒然的。我比眾使徒格外勞苦；這原不是我，乃是上帝的恩與我同在。</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多前書 15:3–4; 哥林多前書 2:2"> 不拘是我，是眾使徒，我們如此傳，你們也如此信了。</span>
</div>
</div>

## 死人的復活

<div className="bt">
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="使徒行傳 26:8; 使徒行傳 17:32; 提摩太後書 2:18"> 既傳基督是從死裏復活了，怎麼在你們中間有人說沒有死人復活的事呢？</span>
<span className="v" id="v13" data-v="13" data-xref="約翰福音 11:25–26; 羅馬書 8:11; 帖撒羅尼迦前書 4:14"> 若沒有死人復活的事，基督也就沒有復活了。</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多前書 15:17; 帖撒羅尼迦前書 4:14; 加拉太書 2:2"> 若基督沒有復活，我們所傳的便是枉然，你們所信的也是枉然；</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行傳 2:24; 約伯記 13:7–10; 使徒行傳 2:32"> 並且明顯我們是為上帝妄作見證的，因我們見證上帝是叫基督復活了。若死人真不復活，上帝也就沒有叫基督復活了。</span>
<span className="v" id="v16" data-v="16"> 因為死人若不復活，基督也就沒有復活了。</span>
<span className="v" id="v17" data-v="17" data-xref="羅馬書 4:25; 彼得前書 1:3; 哥林多前書 15:14"> 基督若沒有復活，你們的信便是徒然，你們仍在罪裏。</span>
<span className="v" id="v18" data-v="18" data-xref="帖撒羅尼迦前書 4:13–14; 啟示錄 14:13; 帖撒羅尼迦前書 4:16"> 就是在基督裏睡了的人也滅亡了。</span>
<span className="v" id="v19" data-v="19" data-xref="彼得前書 1:21; 啟示錄 14:13; 提摩太後書 1:12"> 我們若靠基督只在今生有指望，就算比眾人更可憐。</span>
<span className="v" id="v20" data-v="20" data-xref="哥林多前書 15:23; 使徒行傳 26:23; 啟示錄 1:5"> 但基督已經從死裏復活，成為睡了之人初熟的果子。</span>
<span className="v" id="v21" data-v="21" data-xref="約翰福音 11:25; 羅馬書 5:12–17; 哥林多前書 15:22"> 死既是因一人而來，死人復活也是因一人而來。</span>
<span className="v" id="v22" data-v="22" data-xref="羅馬書 5:12–21; 哥林多前書 15:45–49; 約翰福音 5:21–29"> 在亞當裏眾人都死了；照樣，在基督裏眾人也都要復活。</span>
<span className="v" id="v23" data-v="23" data-xref="以賽亞書 26:19; 加拉太書 3:29; 哥林多前書 15:52"> 但各人是按着自己的次序復活：初熟的果子是基督；以後，在他來的時候，是那些屬基督的。</span>
<span className="v" id="v24" data-v="24" data-xref="但以理書 7:27; 但以理書 7:14; 馬太福音 28:18"> 再後，末期到了，那時基督既將一切執政的、掌權的、有能的都毀滅了，就把國交與父上帝。</span>
<span className="v" id="v25" data-v="25" data-xref="希伯來書 10:12–13; 詩篇 110:1; 馬太福音 22:44"> 因為基督必要作王，等上帝把一切仇敵都放在他的腳下。</span>
<span className="v" id="v26" data-v="26" data-xref="提摩太後書 1:10; 哥林多前書 15:55; 啟示錄 21:4"> 儘末了所毀滅的仇敵就是死。</span>
<span className="v" id="v27" data-v="27" data-xref="詩篇 8:6; 希伯來書 2:8; 馬太福音 28:18"> 因為經上說：「上帝叫萬物都服在他的腳下。」既說萬物都服了他，明顯那叫萬物服他的，不在其內了。</span>
<span className="v" id="v28" data-v="28" data-xref="歌羅西書 3:11; 哥林多前書 3:23; 以弗所書 1:23"> 萬物既服了他，那時子也要自己服那叫萬物服他的，叫上帝在萬物之上，為萬物之主。</span>
<span className="v" id="v29" data-v="29" data-xref="羅馬書 6:3–4; 哥林多前書 15:16; 馬太福音 20:22"> 不然，那些為死人受洗的，將來怎樣呢？若死人總不復活，因何為他們受洗呢？</span>
<span className="v" id="v30" data-v="30" data-xref="哥林多後書 6:9; 加拉太書 5:11; 哥林多後書 4:7–12"> 我們又因何時刻冒險呢？</span>
<span className="v" id="v31" data-v="31" data-xref="哥林多後書 4:10–11; 羅馬書 8:36; 哥林多前書 4:9–13"> 弟兄們，我在我主基督耶穌裏，指着你們所誇的口極力地說，我是天天冒死。</span>
<span className="v" id="v32" data-v="32" data-xref="以賽亞書 22:13; 以賽亞書 56:12; 路加福音 12:19"> 我若當日像尋常人，在以弗所同野獸戰鬥，那於我有甚麼益處呢？若死人不復活，<br /><span className="pl pl-1">我們就吃吃喝喝吧！</span><br /><span className="pl pl-1">因為明天要死了。</span></span>
<span className="v" id="v33" data-v="33" data-xref="箴言 13:20; 馬太福音 24:4; 哥林多前書 5:6"> 你們不要自欺；濫交是敗壞善行。</span>
<span className="v" id="v34" data-v="34" data-xref="哥林多前書 6:5; 羅馬書 13:11; 希伯來書 5:11–12"> 你們要醒悟為善，不要犯罪，因為有人不認識上帝。我說這話是要叫你們羞愧。</span>
</div>
</div>

## 復活的身體

<div className="bt">
<div className="bp poetry">
<span className="v" id="v35" data-v="35" data-xref="以西結書 37:3; 哥林多前書 15:38–53; 羅馬書 9:19"> 或有人問：「死人怎樣復活，帶着甚麼身體來呢？」</span>
<span className="v" id="v36" data-v="36" data-xref="約翰福音 12:24; 路加福音 11:40; 以弗所書 5:15"> 無知的人哪，你所種的，若不死就不能生。</span>
<span className="v" id="v37" data-v="37"> 並且你所種的不是那將來的形體，不過是子粒，即如麥子，或是別樣的穀。</span>
<span className="v" id="v38" data-v="38" data-xref="哥林多前書 3:7; 以賽亞書 61:11; 馬可福音 4:26–29"> 但上帝隨自己的意思給他一個形體，並叫各等子粒各有自己的形體。</span>
<span className="v" id="v39" data-v="39" data-xref="創世記 1:20–26"> 凡肉體各有不同：人是一樣，獸又是一樣，鳥又是一樣，魚又是一樣。</span>
<span className="v" id="v40" data-v="40"> 有天上的形體，也有地上的形體；但天上形體的榮光是一樣，地上形體的榮光又是一樣。</span>
<span className="v" id="v41" data-v="41" data-xref="以賽亞書 24:23; 詩篇 148:3–5; 申命記 4:19"> 日有日的榮光，月有月的榮光，星有星的榮光；這星和那星的榮光也有分別。</span>
<span className="v" id="v42" data-v="42" data-xref="馬太福音 13:43; 但以理書 12:3; 羅馬書 8:21"> 死人復活也是這樣：所種的是必朽壞的，復活的是不朽壞的；</span>
<span className="v" id="v43" data-v="43" data-xref="哥林多前書 6:14; 歌羅西書 3:4; 腓立比書 3:20–21"> 所種的是羞辱的，復活的是榮耀的；所種的是軟弱的，復活的是強壯的；</span>
<span className="v" id="v44" data-v="44" data-xref="哥林多前書 15:50; 路加福音 24:31; 約翰福音 20:19"> 所種的是血氣的身體，復活的是靈性的身體。若有血氣的身體，也必有靈性的身體。</span>
<span className="v" id="v45" data-v="45" data-xref="約翰福音 5:21; 創世記 2:7; 羅馬書 8:2"> 經上也是這樣記着說：「首先的人亞當成了有靈<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="靈：或譯血氣">a</a></sup>的活人」；末後的亞當成了叫人活的靈。</span>
<span className="v" id="v46" data-v="46" data-xref="歌羅西書 3:9–10; 羅馬書 6:6; 以弗所書 4:22–24"> 但屬靈的不在先，屬血氣的在先，以後才有屬靈的。</span>
<span className="v" id="v47" data-v="47" data-xref="約翰福音 3:31; 創世記 2:7; 創世記 3:19"> 頭一個人是出於地，乃屬土；第二個人是出於天。</span>
<span className="v" id="v48" data-v="48" data-xref="創世記 5:3; 羅馬書 5:12–21; 約翰福音 3:6"> 那屬土的怎樣，凡屬土的也就怎樣；屬天的怎樣，凡屬天的也就怎樣。</span>
<span className="v" id="v49" data-v="49" data-xref="羅馬書 8:29; 哥林多後書 3:18; 創世記 5:3"> 我們既有屬土的形狀，將來也必有屬天的形狀。</span>
<span className="v" id="v50" data-v="50" data-xref="約翰福音 3:3–6; 馬太福音 16:17; 以弗所書 4:17"> 弟兄們，我告訴你們說，血肉之體不能承受上帝的國，必朽壞的不能承受不朽壞的。</span>
<span className="v" id="v51" data-v="51" data-xref="帖撒羅尼迦前書 4:14–17; 腓立比書 3:21; 哥林多前書 15:20"> 我如今把一件奧祕的事告訴你們：我們不是都要睡覺，乃是都要改變，</span>
<span className="v" id="v52" data-v="52" data-xref="帖撒羅尼迦前書 4:16–17; 馬太福音 24:31; 約翰福音 5:28"> 就在一霎時，眨眼之間，號筒末次吹響的時候。因號筒要響，死人要復活成為不朽壞的，我們也要改變。</span>
<span className="v" id="v53" data-v="53" data-xref="哥林多後書 5:2–4; 約翰一書 3:2; 羅馬書 2:7"> 這必朽壞的總要變成<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="變成：原文是穿；下同">b</a></sup>不朽壞的，這必死的總要變成不死的。</span>
<span className="v" id="v54" data-v="54" data-xref="以賽亞書 25:8; 啟示錄 20:14; 希伯來書 2:14–15"> 這必朽壞的既變成不朽壞的，這必死的既變成不死的，那時經上所記「死被得勝吞滅」的話就應驗了。</span>
<span className="v" id="v55" data-v="55" data-xref="何西阿書 13:14; 詩篇 89:48; 使徒行傳 2:27"> <span className="pl pl-1">死啊！你得勝的權勢在哪裏？</span><br /><span className="pl pl-1">死啊！你的毒鉤在哪裏？</span></span>
<span className="v" id="v56" data-v="56" data-xref="羅馬書 4:15; 加拉太書 3:10–13; 羅馬書 7:5–13"> 死的毒鉤就是罪，罪的權勢就是律法。</span>
<span className="v" id="v57" data-v="57" data-xref="哥林多後書 2:14; 羅馬書 8:37; 約翰一書 5:4–5"> 感謝上帝，使我們藉着我們的主耶穌基督得勝。</span>
<span className="v" id="v58" data-v="58" data-xref="加拉太書 6:9; 歷代志下 15:7; 希伯來書 6:10"> 所以，我親愛的弟兄們，你們務要堅固，不可搖動，常常竭力多做主工；因為知道，你們的勞苦在主裏面不是徒然的。</span>
</div>

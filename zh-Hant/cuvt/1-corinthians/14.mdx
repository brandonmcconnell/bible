## 說方言和作先知講道

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="哥林多前書 14:39; 提摩太前書 4:14; 哥林多前書 12:1"> 你們要追求愛，也要切慕屬靈的恩賜，其中更要羨慕的，是作先知講道<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文作：是說預言；下同">a</a></sup>。</span>
<span className="v" id="v2" data-v="2" data-xref="馬可福音 16:17; 使徒行傳 19:6; 使徒行傳 10:46"> 那說方言的，原不是對人說，乃是對上帝說，因為沒有人聽出來。然而，他在心靈裏卻是講說各樣的奧祕。</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多前書 14:12; 提摩太前書 4:13; 猶大書 1:20"> 但作先知講道的，是對人說，要造就、安慰、勸勉人。</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多前書 14:22; 哥林多前書 14:26; 馬可福音 16:17"> 說方言的，是造就自己；作先知講道的，乃是造就教會。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多前書 12:28–30; 哥林多前書 12:10; 馬可福音 16:17"> 我願意你們都說方言，更願意你們作先知講道；因為說方言的，若不翻出來，使教會被造就，那作先知講道的，就比他強了。</span>
<span className="v" id="v6" data-v="6" data-xref="以弗所書 1:17; 羅馬書 6:17; 提摩太後書 3:16"> 弟兄們，我到你們那裏去，若只說方言，不用啟示，或知識，或預言，或教訓，給你們講解，我與你們有甚麼益處呢？</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多前書 14:8; 路加福音 7:32; 哥林多前書 13:1"> 就是那有聲無氣的物，或簫，或琴，若發出來的聲音沒有分別，怎能知道所吹所彈的是甚麼呢？</span>
<span className="v" id="v8" data-v="8" data-xref="民數記 10:9; 以西結書 33:3–6; 耶利米書 4:19"> 若吹無定的號聲，誰能預備打仗呢？</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多前書 9:26"> 你們也是如此。舌頭若不說容易明白的話，怎能知道所說的是甚麼呢？這就是向空說話了。</span>
<span className="v" id="v10" data-v="10"> 世上的聲音，或者甚多，卻沒有一樣是無意思的。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行傳 28:2; 羅馬書 1:14; 歌羅西書 3:11"> 我若不明白那聲音的意思，這說話的人必以我為化外之人，我也以他為化外之人。</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多前書 14:26; 哥林多前書 14:3–4; 哥林多前書 14:1"> 你們也是如此，既是切慕屬靈的恩賜，就當求多得造就教會的恩賜。</span>
<span className="v" id="v13" data-v="13" data-xref="馬可福音 11:24; 哥林多前書 12:30; 約翰福音 14:13–14"> 所以那說方言的，就當求着能翻出來。</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多前書 14:2; 哥林多前書 14:15–16; 哥林多前書 14:19"> 我若用方言禱告，是我的靈禱告，但我的悟性沒有果效。</span>
<span className="v" id="v15" data-v="15" data-xref="歌羅西書 3:16; 約翰福音 4:23–24; 以弗所書 6:18"> 這卻怎麼樣呢？我要用靈禱告，也要用悟性禱告；我要用靈歌唱，也要用悟性歌唱。</span>
<span className="v" id="v16" data-v="16" data-xref="歷代志上 16:36; 詩篇 106:48; 啟示錄 5:14"> 不然，你用靈祝謝，那在座不通方言的人，既然不明白你的話，怎能在你感謝的時候說「阿們」呢？</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多前書 14:4; 哥林多前書 14:6"> 你感謝的固然是好，無奈不能造就別人。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前書 1:4–6; 哥林多前書 4:7"> 我感謝上帝，我說方言比你們眾人還多。</span>
<span className="v" id="v19" data-v="19" data-xref="哥林多前書 14:21–22; 哥林多前書 14:4"> 但在教會中，寧可用悟性說五句教導人的話，強如說萬句方言。</span>
<span className="v" id="v20" data-v="20" data-xref="彼得前書 2:2; 哥林多前書 13:11; 羅馬書 16:19"> 弟兄們，在心志上不要作小孩子。然而，在惡事上要作嬰孩，在心志上總要作大人。</span>
<span className="v" id="v21" data-v="21" data-xref="以賽亞書 28:11–12; 耶利米書 5:15; 申命記 28:49"> 律法上記着：<br /><span className="pl pl-1">主說：我要用外邦人的舌頭</span><br /><span className="pl pl-1">和外邦人的嘴唇向這百姓說話；</span><br /><span className="pl pl-1">雖然如此，</span><br /><span className="pl pl-1">他們還是不聽從我。</span></span>
<span className="v" id="v22" data-v="22" data-xref="使徒行傳 2:6–12; 馬可福音 16:17; 哥林多前書 14:1"> 這樣看來，說方言不是為信的人作證據，乃是為不信的人；作先知講道不是為不信的人作證據，乃是為信的人。</span>
<span className="v" id="v23" data-v="23" data-xref="使徒行傳 2:13; 使徒行傳 26:24; 哥林多前書 11:18"> 所以，全教會聚在一處的時候，若都說方言，偶然有不通方言的，或是不信的人進來，豈不說你們癲狂了嗎？</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行傳 2:37; 哥林多前書 2:15; 希伯來書 4:12–13"> 若都作先知講道，偶然有不信的，或是不通方言的人進來，就被眾人勸醒，被眾人審明，</span>
<span className="v" id="v25" data-v="25" data-xref="以賽亞書 45:14; 撒迦利亞書 8:23; 詩篇 72:11"> 他心裏的隱情顯露出來，就必將臉伏地，敬拜上帝，說：「上帝真是在你們中間了。」</span>
</div>
</div>

## 凡事都要按次序行

<div className="bt">
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="以弗所書 5:19; 羅馬書 14:19; 哥林多前書 12:7–10"> 弟兄們，這卻怎麼樣呢？你們聚會的時候，各人或有詩歌，或有教訓，或有啟示，或有方言，或有翻出來的話，凡事都當造就人。</span>
<span className="v" id="v27" data-v="27" data-xref="哥林多前書 14:26"> 若有說方言的，只好兩個人，至多三個人，且要輪流着說，也要一個人翻出來。</span>
<span className="v" id="v28" data-v="28"> 若沒有人翻，就當在會中閉口，只對自己和上帝說就是了。</span>
<span className="v" id="v29" data-v="29" data-xref="哥林多前書 12:10; 帖撒羅尼迦前書 5:19–21; 約翰一書 4:1–3"> 至於作先知講道的，只好兩個人或是三個人，其餘的就當慎思明辨。</span>
<span className="v" id="v30" data-v="30" data-xref="帖撒羅尼迦前書 5:19–20; 約伯記 33:31–33; 約伯記 32:11"> 若旁邊坐着的得了啟示，那先說話的就當閉口不言。</span>
<span className="v" id="v31" data-v="31" data-xref="帖撒羅尼迦前書 5:14; 哥林多前書 14:3; 帖撒羅尼迦前書 5:11"> 因為你們都可以一個一個地作先知講道，叫眾人學道理，叫眾人得勸勉。</span>
<span className="v" id="v32" data-v="32" data-xref="使徒行傳 4:19–20; 約翰一書 4:1; 撒母耳記上 10:10–13"> 先知的靈原是順服先知的；</span>
<span className="v" id="v33" data-v="33" data-xref="雅各書 3:17–18; 哥林多前書 14:40; 帖撒羅尼迦後書 3:16"> 因為上帝不是叫人混亂，乃是叫人安靜。</span>
<span className="v" id="v34" data-v="34" data-xref="提摩太前書 2:11–12; 創世記 3:16; 民數記 30:3–13"> 婦女在會中要閉口不言，像在聖徒的眾教會一樣，因為不准她們說話。她們總要順服，正如律法所說的。</span>
<span className="v" id="v35" data-v="35" data-xref="以弗所書 5:12; 彼得前書 3:7; 以弗所書 5:25–27"> 她們若要學甚麼，可以在家裏問自己的丈夫，因為婦女在會中說話原是可恥的。</span>
<span className="v" id="v36" data-v="36" data-xref="使徒行傳 18:1–17; 撒迦利亞書 14:8; 使徒行傳 17:15"> 上帝的道理豈是從你們出來嗎？豈是單臨到你們嗎？</span>
<span className="v" id="v37" data-v="37" data-xref="約翰一書 4:6; 哥林多後書 10:7; 彼得後書 3:2"> 若有人以為自己是先知，或是屬靈的，就該知道，我所寫給你們的是主的命令。</span>
<span className="v" id="v38" data-v="38" data-xref="提摩太後書 4:3–4; 何西阿書 4:17; 啟示錄 22:11–12"> 若有不知道的，就由他不知道吧！</span>
<span className="v" id="v39" data-v="39" data-xref="哥林多前書 12:31; 哥林多前書 14:1; 帖撒羅尼迦前書 5:20"> 所以我弟兄們，你們要切慕作先知講道，也不要禁止說方言。</span>
<span className="v" id="v40" data-v="40" data-xref="歌羅西書 2:5; 提多書 1:5; 哥林多前書 14:26–33"> 凡事都要規規矩矩地按着次序行。</span>
</div>

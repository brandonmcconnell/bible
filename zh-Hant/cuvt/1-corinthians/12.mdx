## 屬靈的恩賜

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多前書 12:4–11; 哥林多前書 14:37; 哥林多前書 14:1–18"> 弟兄們，論到屬靈的恩賜，我不願意你們不明白。</span>
<span className="v" id="v2" data-v="2" data-xref="彼得前書 4:3; 帖撒羅尼迦前書 1:9; 詩篇 115:5"> 你們作外邦人的時候，隨事被牽引，受迷惑，去服事那啞巴偶像，這是你們知道的。</span>
<span className="v" id="v3" data-v="3" data-xref="約翰一書 4:2–3; 馬太福音 16:16–17; 羅馬書 10:9"> 所以我告訴你們，被上帝的靈感動的，沒有說「耶穌是可咒詛」的；若不是被聖靈感動的，也沒有能說「耶穌是主」的。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="彼得前書 4:10; 哥林多前書 12:28; 羅馬書 12:4–6"> 恩賜原有分別，聖靈卻是一位。</span>
<span className="v" id="v5" data-v="5" data-xref="以弗所書 4:11–12; 羅馬書 12:6–8; 羅馬書 14:8–9"> 職事也有分別，主卻是一位。</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多前書 3:7; 哥林多前書 12:11; 約翰福音 5:17"> 功用也有分別，上帝卻是一位，在眾人裏面運行一切的事。</span>
<span className="v" id="v7" data-v="7" data-xref="彼得前書 4:10–11; 羅馬書 12:6–8; 哥林多前書 14:19"> 聖靈顯在各人身上，是叫人得益處。</span>
<span className="v" id="v8" data-v="8" data-xref="箴言 2:6; 哥林多前書 2:6–10; 詩篇 143:10"> 這人蒙聖靈賜他智慧的言語，那人也蒙這位聖靈賜他知識的言語，</span>
<span className="v" id="v9" data-v="9" data-xref="雅各書 5:14–15; 哥林多後書 4:13; 以弗所書 2:8"> 又有一人蒙這位聖靈賜他信心，還有一人蒙這位聖靈賜他醫病的恩賜，</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多前書 14:39; 約翰一書 4:1; 馬可福音 16:17"> 又叫一人能行異能，又叫一人能作先知，又叫一人能辨別諸靈，又叫一人能說方言，又叫一人能翻方言。</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多前書 12:4; 希伯來書 2:4; 哥林多後書 10:13"> 這一切都是這位聖靈所運行、隨己意分給各人的。</span>
</div>
</div>

## 一個身體有許多肢體

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="羅馬書 12:4–5; 歌羅西書 3:15; 哥林多前書 12:27"> 就如身子是一個，卻有許多肢體；而且肢體雖多，仍是一個身子；基督也是這樣。</span>
<span className="v" id="v13" data-v="13" data-xref="以弗所書 4:5; 歌羅西書 3:11; 加拉太書 3:28"> 我們不拘是猶太人，是希臘人，是為奴的，是自主的，都從一位聖靈受洗，成了一個身體，飲於一位聖靈。</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多前書 12:27–28; 哥林多前書 12:12; 以弗所書 4:25"> 身子原不是一個肢體，乃是許多肢體。</span>
<span className="v" id="v15" data-v="15" data-xref="士師記 9:8–15; 列王紀下 14:9"> 設若腳說：「我不是手，所以不屬乎身子，」它不能因此就不屬乎身子。</span>
<span className="v" id="v16" data-v="16" data-xref="羅馬書 12:3; 哥林多前書 12:22; 腓立比書 2:3"> 設若耳說：「我不是眼，所以不屬乎身子，」它也不能因此就不屬乎身子。</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多前書 12:21; 詩篇 139:13–16; 箴言 20:12"> 若全身是眼，從哪裏聽聲呢？若全身是耳，從哪裏聞味呢？</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前書 12:28; 羅馬書 12:3; 哥林多前書 12:11"> 但如今，上帝隨自己的意思把肢體俱各安排在身上了。</span>
<span className="v" id="v19" data-v="19"> 若都是一個肢體，身子在哪裏呢？</span>
<span className="v" id="v20" data-v="20" data-xref="哥林多前書 12:14; 哥林多前書 12:12"> 但如今肢體是多的，身子卻是一個。</span>
<span className="v" id="v21" data-v="21" data-xref="以斯拉記 10:1–5; 尼希米記 4:16–21; 約伯記 29:11"> 眼不能對手說：「我用不着你。」頭也不能對腳說：「我用不着你。」</span>
<span className="v" id="v22" data-v="22" data-xref="箴言 14:28; 傳道書 9:14–15; 傳道書 4:9–12"> 不但如此，身上肢體人以為軟弱的，更是不可少的。</span>
<span className="v" id="v23" data-v="23" data-xref="創世記 3:21; 創世記 3:7"> 身上肢體，我們看為不體面的，越發給它加上體面；不俊美的，越發得着俊美。</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 3:11; 創世記 2:25"> 我們俊美的肢體，自然用不着裝飾；但上帝配搭這身子，把加倍的體面給那有缺欠的肢體，</span>
<span className="v" id="v25" data-v="25" data-xref="哥林多後書 13:11; 哥林多前書 1:10–12; 約翰福音 17:21–26"> 免得身上分門別類，總要肢體彼此相顧。</span>
<span className="v" id="v26" data-v="26" data-xref="羅馬書 12:15; 加拉太書 6:2; 希伯來書 13:3"> 若一個肢體受苦，所有的肢體就一同受苦；若一個肢體得榮耀，所有的肢體就一同快樂。</span>
<span className="v" id="v27" data-v="27" data-xref="以弗所書 4:12; 歌羅西書 1:24; 以弗所書 5:30"> 你們就是基督的身子，並且各自作肢體。</span>
<span className="v" id="v28" data-v="28" data-xref="以弗所書 4:11–13; 羅馬書 12:6–8; 哥林多前書 12:18"> 上帝在教會所設立的：第一是使徒，第二是先知，第三是教師，其次是行異能的，再次是得恩賜醫病的，幫助人的，治理事的，說方言的。</span>
<span className="v" id="v29" data-v="29" data-xref="哥林多前書 12:4–11; 哥林多前書 12:14–20"> 豈都是使徒嗎？豈都是先知嗎？豈都是教師嗎？豈都是行異能的嗎？</span>
<span className="v" id="v30" data-v="30" data-xref="哥林多前書 12:10"> 豈都是得恩賜醫病的嗎？豈都是說方言的嗎？豈都是翻方言的嗎？</span>
<span className="v" id="v31" data-v="31" data-xref="哥林多前書 13:1; 哥林多前書 14:39; 馬太福音 5:6"> 你們要切切地求那更大的恩賜。 愛<br />我現今把最妙的道指示你們。</span>
</div>
</div>

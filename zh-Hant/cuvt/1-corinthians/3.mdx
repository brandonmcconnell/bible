## 上帝的同工

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="希伯來書 5:13; 哥林多前書 2:14–15; 以弗所書 4:13–14"> 弟兄們，我從前對你們說話，不能把你們當作屬靈的，只得把你們當作屬肉體，在基督裏為嬰孩的。</span>
<span className="v" id="v2" data-v="2" data-xref="希伯來書 5:11–14; 約翰福音 16:12; 彼得前書 2:2"> 我是用奶餵你們，沒有用飯餵你們。那時你們不能吃，就是如今還是不能。</span>
<span className="v" id="v3" data-v="3" data-xref="雅各書 3:16; 加拉太書 5:15; 提多書 3:3"> 你們仍是屬肉體的，因為在你們中間有嫉妒、紛爭，這豈不是屬乎肉體、照着世人的樣子行嗎？</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多前書 1:12; 哥林多前書 3:3; 哥林多前書 4:6"> 有說：「我是屬保羅的」；有說：「我是屬亞波羅的。」這豈不是你們和世人一樣嗎？</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多後書 6:4; 哥林多後書 6:1; 彼得前書 4:10"> 亞波羅算甚麼？保羅算甚麼？無非是執事，照主所賜給他們各人的，引導你們相信。</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多前書 3:9–10; 箴言 11:25; 哥林多後書 10:14–15"> 我栽種了，亞波羅澆灌了，惟有上帝叫他生長。</span>
<span className="v" id="v7" data-v="7" data-xref="約翰福音 15:5; 加拉太書 6:3; 詩篇 115:1"> 可見栽種的，算不得甚麼，澆灌的，也算不得甚麼；只在那叫他生長的上帝。</span>
<span className="v" id="v8" data-v="8" data-xref="羅馬書 2:6; 馬太福音 16:27; 約翰二書 1:8"> 栽種的和澆灌的，都是一樣，但將來各人要照自己的工夫得自己的賞賜。</span>
<span className="v" id="v9" data-v="9" data-xref="彼得前書 2:5; 以弗所書 2:20–22; 哥林多後書 6:1"> 因為我們是與上帝同工的；你們是上帝所耕種的田地，所建造的房屋。</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多前書 3:11; 以弗所書 2:20; 羅馬書 15:20"> 我照上帝所給我的恩，好像一個聰明的工頭，立好了根基，有別人在上面建造；只是各人要謹慎怎樣在上面建造。</span>
<span className="v" id="v11" data-v="11" data-xref="以弗所書 2:20; 以賽亞書 28:16; 提摩太後書 2:19"> 因為那已經立好的根基就是耶穌基督，此外沒有人能立別的根基。</span>
<span className="v" id="v12" data-v="12" data-xref="提摩太後書 4:3; 提摩太後書 3:7; 提摩太後書 2:20"> 若有人用金、銀、寶石、草木、禾稭在這根基上建造，</span>
<span className="v" id="v13" data-v="13" data-xref="彼得前書 1:7; 哥林多前書 3:14–15; 啟示錄 20:12"> 各人的工程必然顯露，因為那日子要將它表明出來，有火發現；這火要試驗各人的工程怎樣。</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多前書 3:8; 馬太福音 25:21–23; 哥林多前書 4:5"> 人在那根基上所建造的工程若存得住，他就要得賞賜。</span>
<span className="v" id="v15" data-v="15" data-xref="約翰二書 1:8; 哥林多前書 3:12–13; 猶大書 1:23"> 人的工程若被燒了，他就要受虧損，自己卻要得救；雖然得救，乃像從火裏經過的一樣。</span>
<span className="v" id="v16" data-v="16" data-xref="哥林多前書 6:19; 以西結書 36:27; 哥林多後書 6:16"> 豈不知你們是上帝的殿，上帝的靈住在你們裏頭嗎？</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多前書 6:18–20; 以西結書 43:12; 民數記 19:20"> 若有人毀壞上帝的殿，上帝必要毀壞那人；因為上帝的殿是聖的，這殿就是你們。</span>
<span className="v" id="v18" data-v="18" data-xref="箴言 3:5; 以賽亞書 5:21; 加拉太書 6:3"> 人不可自欺。你們中間若有人在這世界自以為有智慧，倒不如變作愚拙，好成為有智慧的。</span>
<span className="v" id="v19" data-v="19" data-xref="約伯記 5:13; 詩篇 141:10; 哥林多前書 1:19–20"> 因這世界的智慧，在上帝看是愚拙。如經上記着說：「主叫有智慧的，中了自己的詭計」；</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 94:11; 歌羅西書 2:8; 羅馬書 1:21"> 又說：「主知道智慧人的意念是虛妄的。」</span>
<span className="v" id="v21" data-v="21" data-xref="羅馬書 8:32; 羅馬書 8:28; 耶利米書 9:23–24"> 所以無論誰，都不可拿人誇口，因為萬有全是你們的。</span>
<span className="v" id="v22" data-v="22" data-xref="以弗所書 4:11–12; 腓立比書 1:21; 哥林多前書 9:19–22"> 或保羅，或亞波羅，或磯法，或世界，或生，或死，或現今的事，或將來的事，全是你們的；</span>
<span className="v" id="v23" data-v="23" data-xref="加拉太書 3:29; 哥林多前書 11:3; 約翰福音 17:9–10"> 並且你們是屬基督的，基督又是屬上帝的。</span>

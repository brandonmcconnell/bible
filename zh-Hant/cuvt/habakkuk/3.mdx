## 哈巴谷的祈禱

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="詩篇 7:1–17; 詩篇 86:1–17; 詩篇 90:1–17"> 先知哈巴谷的禱告，調用流離歌。</span>
<span className="v" id="v2" data-v="2" data-xref="詩篇 85:6; 詩篇 90:13–17; 何西阿書 6:2–3"> <span className="pl pl-1">耶和華啊，我聽見你的名聲</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或譯：言語">a</a></sup><br /><span className="pl pl-1">就懼怕。</span><br /><span className="pl pl-1">耶和華啊，求你在這些年間復興你的作為，</span><br /><span className="pl pl-1">在這些年間顯明出來；</span><br /><span className="pl pl-1">在發怒的時候以憐憫為念。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v3" data-v="3" data-xref="申命記 33:2; 詩篇 4:4; 俄巴底亞書 1:9"> <span className="pl pl-1">上帝從提幔而來；</span><br /><span className="pl pl-1">聖者從巴蘭山臨到。（細拉）</span><br /><span className="pl pl-1">他的榮光遮蔽諸天；</span><br /><span className="pl pl-1">頌讚充滿大地。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="以賽亞書 60:19–20; 馬太福音 17:2; 約伯記 26:14"> <span className="pl pl-1">他的輝煌如同日光；</span><br /><span className="pl pl-1">從他手裏射出光線，</span><br /><span className="pl pl-1">在其中藏着他的能力。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 12:29–30; 民數記 16:46–49; 詩篇 78:50–51"> <span className="pl pl-1">在他前面有瘟疫流行；</span><br /><span className="pl pl-1">在他腳下有熱症發出。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="創世記 49:26; 申命記 33:15; 那鴻書 1:5"> <span className="pl pl-1">他站立，量了大地</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或譯：使地震動">b</a></sup><br /><span className="pl pl-1">，</span><br /><span className="pl pl-1">觀看，趕散萬民。</span><br /><span className="pl pl-1">永久的山崩裂；</span><br /><span className="pl pl-1">長存的嶺塌陷；</span><br /><span className="pl pl-1">他的作為與古時一樣。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="出埃及記 15:14–16; 創世記 10:6–7; 創世記 25:1–4"> <span className="pl pl-1">我見古珊的帳棚遭難，</span><br /><span className="pl pl-1">米甸的幔子戰兢。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 68:17; 申命記 33:26–27; 出埃及記 14:21–22"> <span className="pl pl-1">耶和華啊，你乘在馬上，</span><br /><span className="pl pl-1">坐在得勝的車上，</span><br /><span className="pl pl-1">豈是不喜悅江河、</span><br /><span className="pl pl-1">向江河發怒氣、</span><br /><span className="pl pl-1">向洋海發憤恨嗎？</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 7:12–13; 詩篇 105:41; 詩篇 78:15–16"> <span className="pl pl-1">你的弓全然顯露，</span><br /><span className="pl pl-1">向眾支派所起的誓都是可信的。（細拉）</span><br /><span className="pl pl-1">你以江河分開大地。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="耶利米書 4:24; 約書亞記 4:23–24; 詩篇 93:3"> <span className="pl pl-1">山嶺見你，無不戰懼；</span><br /><span className="pl pl-1">大水氾濫過去，</span><br /><span className="pl pl-1">深淵發聲，洶湧翻騰</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="原文是向上舉手">c</a></sup><br /><span className="pl pl-1">。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 144:5–6; 詩篇 18:12–14; 約書亞記 10:11–13"> <span className="pl pl-1">因你的箭射出發光，</span><br /><span className="pl pl-1">你的槍閃出光耀，</span><br /><span className="pl pl-1">日月都在本宮停住。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="耶利米書 51:33; 彌迦書 4:12–13; 民數記 21:23–35"> <span className="pl pl-1">你發忿恨通行大地，</span><br /><span className="pl pl-1">發怒氣責打列國，如同打糧。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 110:6; 詩篇 105:15; 詩篇 68:19–23"> <span className="pl pl-1">你出來要拯救你的百姓，</span><br /><span className="pl pl-1">拯救你的受膏者，</span><br /><span className="pl pl-1">打破惡人家長的頭，</span><br /><span className="pl pl-1">露出他的腳</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="原文是根基">d</a></sup><br /><span className="pl pl-1">，直到頸項。（細拉）</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="撒迦利亞書 9:14; 但以理書 11:40; 詩篇 118:10–12"> <span className="pl pl-1">你用敵人的戈矛刺透他戰士的頭；</span><br /><span className="pl pl-1">他們來如旋風，要將我們分散。</span><br /><span className="pl pl-1">他們所喜愛的是暗中吞吃貧民。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 77:19; 哈巴谷書 3:8; 出埃及記 15:8"> <span className="pl pl-1">你乘馬踐踏紅海，</span><br /><span className="pl pl-1">就是踐踏洶湧的大水。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v16" data-v="16" data-xref="耶利米書 23:9; 哈巴谷書 1:5–11; 哈巴谷書 3:2"> <span className="pl pl-1">我聽見耶和華的聲音，</span><br /><span className="pl pl-1">身體戰兢，嘴唇發顫，</span><br /><span className="pl pl-1">骨中朽爛；</span><br /><span className="pl pl-1">我在所立之處戰兢。</span><br /><span className="pl pl-1">我只可安靜等候災難之日臨到，</span><br /><span className="pl pl-1">犯境之民上來。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v17" data-v="17" data-xref="耶利米書 5:17; 約珥書 1:16–18; 申命記 28:15–18"> <span className="pl pl-1">雖然無花果樹不發旺，</span><br /><span className="pl pl-1">葡萄樹不結果，</span><br /><span className="pl pl-1">橄欖樹也不效力，</span><br /><span className="pl pl-1">田地不出糧食，</span><br /><span className="pl pl-1">圈中絕了羊，</span><br /><span className="pl pl-1">棚內也沒有牛；</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="約伯記 13:15; 腓立比書 4:4; 彌迦書 7:7"> <span className="pl pl-1">然而，我要因耶和華歡欣，</span><br /><span className="pl pl-1">因救我的上帝喜樂。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳記下 22:34; 詩篇 18:33; 腓立比書 4:13"> <span className="pl pl-1">主耶和華是我的力量；</span><br /><span className="pl pl-1">他使我的腳快如母鹿的蹄，</span><br /><span className="pl pl-1">又使我穩行在高處。</span><br /><span className="pl pl-1">這歌交與伶長，用絲弦的樂器。</span></span>
</div>

## 耶穌超越摩西

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="提摩太後書 1:9; 腓立比書 3:14; 希伯來書 4:14–15"> 同蒙天召的聖潔弟兄啊，你們應當思想我們所認為使者、為大祭司的耶穌。</span>
<span className="v" id="v2" data-v="2" data-xref="民數記 12:7; 提摩太前書 3:15; 以弗所書 2:22"> 他為那設立他的盡忠，如同摩西在上帝的全家盡忠一樣。</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多前書 3:9; 彼得前書 2:5–7; 撒迦利亞書 6:12–13"> 他比摩西算是更配多得榮耀，好像建造房屋的比房屋更尊榮；</span>
<span className="v" id="v4" data-v="4" data-xref="希伯來書 3:3; 希伯來書 1:2; 以斯帖記 2:10"> 因為房屋都必有人建造，但建造萬物的就是上帝。</span>
<span className="v" id="v5" data-v="5" data-xref="民數記 12:7; 希伯來書 3:2; 出埃及記 14:31"> 摩西為僕人，在上帝的全家誠然盡忠，為要證明將來必傳說的事。</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多後書 6:16; 哥林多前書 3:16; 希伯來書 10:35"> 但基督為兒子，治理上帝的家；我們若將可誇的盼望和膽量堅持到底，便是他的家了。</span>
</div>
</div>

## 上帝子民的安息

<div className="bt">
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="詩篇 95:7–11; 希伯來書 3:15; 以賽亞書 55:3"> 聖靈有話說：<br /><span className="pl pl-1">你們今日若聽他的話，</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="箴言 28:14; 出埃及記 17:7; 撒迦利亞書 7:11–12"> <span className="pl pl-1">就不可硬着心，</span><br /><span className="pl pl-1">像在曠野惹他發怒、</span><br /><span className="pl pl-1">試探他的時候一樣。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="使徒行傳 7:36; 申命記 4:9; 出埃及記 19:4"> <span className="pl pl-1">在那裏，你們的祖宗試我探我，</span><br /><span className="pl pl-1">並且觀看我的作為有四十年之久。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 95:10; 帖撒羅尼迦後書 2:10–12; 詩篇 67:2"> <span className="pl pl-1">所以，我厭煩那世代的人，說：</span><br /><span className="pl pl-1">他們心裏常常迷糊，</span><br /><span className="pl pl-1">竟不曉得我的作為！</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="申命記 1:34–35; 希伯來書 4:3; 民數記 32:10–13"> <span className="pl pl-1">我就在怒中起誓說：</span><br /><span className="pl pl-1">他們斷不可進入我的安息。</span></span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="耶利米書 17:5; 耶利米書 7:24; 耶利米書 17:9"> 弟兄們，你們要謹慎，免得你們中間或有人存着不信的惡心，把永生上帝離棄了。</span>
<span className="v" id="v13" data-v="13" data-xref="帖撒羅尼迦前書 5:11; 希伯來書 10:24–25; 提摩太後書 4:2"> 總要趁着還有今日，天天彼此相勸，免得你們中間有人被罪迷惑，心裏就剛硬了。</span>
<span className="v" id="v14" data-v="14" data-xref="希伯來書 3:6; 希伯來書 6:11; 希伯來書 12:10"> 我們若將起初確實的信心堅持到底，就在基督裏有分了。</span>
<span className="v" id="v15" data-v="15" data-xref="希伯來書 3:7–8; 詩篇 95:7; 希伯來書 10:38"> 經上說：「你們今日若聽他的話，就不可硬着心，像惹他發怒的日子一樣。」</span>
<span className="v" id="v16" data-v="16" data-xref="民數記 14:2; 民數記 14:30; 民數記 26:65"> 那時，聽見他話惹他發怒的是誰呢？豈不是跟着摩西從埃及出來的眾人嗎？</span>
<span className="v" id="v17" data-v="17" data-xref="民數記 14:29; 民數記 26:64–65; 民數記 14:32–33"> 上帝四十年之久，又厭煩誰呢？豈不是那些犯罪、屍首倒在曠野的人嗎？</span>
<span className="v" id="v18" data-v="18" data-xref="民數記 14:30; 希伯來書 4:6; 申命記 1:34–35"> 又向誰起誓，不容他們進入他的安息呢？豈不是向那些不信從的人嗎？</span>
<span className="v" id="v19" data-v="19" data-xref="猶大書 1:5; 約翰福音 3:36; 馬可福音 16:16"> 這樣看來，他們不能進入安息是因為不信的緣故了。</span>
</div>
</div>

## 上帝藉着他兒子說話

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="彼得後書 1:20–21; 約珥書 2:28; 民數記 12:6–8"> 上帝既在古時藉着眾先知多次多方地曉諭列祖，</span>
<span className="v" id="v2" data-v="2" data-xref="約翰福音 1:3; 哥林多前書 8:6; 歌羅西書 1:16–18"> 就在這末世藉着他兒子曉諭我們；又早已立他為承受萬有的，也曾藉着他創造諸世界。</span>
<span className="v" id="v3" data-v="3" data-xref="歌羅西書 1:15–17; 啟示錄 4:11; 約翰福音 14:9–10"> 他是上帝榮耀所發的光輝，是上帝本體的真像，常用他權能的命令托住萬有。他洗淨了人的罪，就坐在高天至大者的右邊。</span>
<span className="v" id="v4" data-v="4" data-xref="以弗所書 1:21; 腓立比書 2:9–11; 彼得前書 3:22"> 他所承受的名，既比天使的名更尊貴，就遠超過天使。</span>
</div>
</div>

## 兒子遠超過天使

<div className="bt">
<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="詩篇 2:7; 使徒行傳 13:33; 希伯來書 5:5"> 所有的天使，上帝從來對哪一個說：<br /><span className="pl pl-1">你是我的兒子，</span><br /><span className="pl pl-1">我今日生你？</span>又指着哪一個說：<br /><span className="pl pl-1">我要作他的父，</span><br /><span className="pl pl-1">他要作我的子？</span></span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 97:7; 歌羅西書 1:18; 申命記 32:43"> 再者，上帝使長子到世上來的時候<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或譯：上帝再使長子到世上來的時候">a</a></sup>，就說：<br /><span className="pl pl-1">上帝的使者都要拜他。</span></span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 104:4; 希伯來書 1:14; 列王紀下 6:17"> 論到使者，又說：<br /><span className="pl pl-1">上帝以風為使者，</span><br /><span className="pl pl-1">以火焰為僕役；</span></span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 45:6–7; 以賽亞書 9:6–7; 耶利米書 23:5–6"> 論到子卻說：<br /><span className="pl pl-1">上帝啊，你的寶座是永永遠遠的；</span><br /><span className="pl pl-1">你的國權是正直的。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 45:7; 詩篇 23:5; 以賽亞書 61:3"> <span className="pl pl-1">你喜愛公義，恨惡罪惡；</span><br /><span className="pl pl-1">所以上帝，就是你的上帝，用喜樂油膏你，</span><br /><span className="pl pl-1">勝過膏你的同伴；</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 102:25–27; 創世記 1:1; 約翰福音 1:1–3"> <span className="pl pl-1">又說：主啊，你起初立了地的根基；</span><br /><span className="pl pl-1">天也是你手所造的。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="以賽亞書 51:6; 馬可福音 13:31; 路加福音 21:33"> <span className="pl pl-1">天地都要滅沒，你卻要長存。</span><br /><span className="pl pl-1">天地都要像衣服漸漸舊了；</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 102:26–27; 希伯來書 13:8; 約翰福音 8:58"> <span className="pl pl-1">你要將天地捲起來，像一件外衣，</span><br /><span className="pl pl-1">天地就都改變了。</span><br /><span className="pl pl-1">惟有你永不改變；</span><br /><span className="pl pl-1">你的年數沒有窮盡。</span></span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 110:1; 馬可福音 12:36; 馬太福音 22:44"> 所有的天使，上帝從來對哪一個說：<br /><span className="pl pl-1">你坐在我的右邊，</span><br /><span className="pl pl-1">等我使你仇敵作你的腳凳？</span></span>
<span className="v" id="v14" data-v="14" data-xref="詩篇 34:7; 詩篇 103:20–21; 詩篇 91:11–12"> 天使豈不都是服役的靈、奉差遣為那將要承受救恩的人效力嗎？</span>
</div>

## 麥基洗德的祭司等次

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 14:18–20; 詩篇 57:2; 希伯來書 6:20"> 這麥基洗德就是撒冷王，又是至高上帝的祭司，本是長遠為祭司的。他當亞伯拉罕殺敗諸王回來的時候，就迎接他，給他祝福。</span>
<span className="v" id="v2" data-v="2" data-xref="民數記 18:21; 詩篇 85:10–11; 撒母耳記上 8:17"> 亞伯拉罕也將自己所得來的，取十分之一給他。他頭一個名翻出來就是仁義王，他又名撒冷王，就是平安王的意思。</span>
<span className="v" id="v3" data-v="3" data-xref="希伯來書 7:17; 希伯來書 7:23–28; 出埃及記 6:20–27"> 他無父，無母，無族譜，無生之始，無命之終，乃是與上帝的兒子相似。</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 14:20; 使徒行傳 2:29; 使徒行傳 7:8–9"> 你們想一想，先祖亞伯拉罕將自己所擄來上等之物取十分之一給他，這人是何等尊貴呢！</span>
<span className="v" id="v5" data-v="5" data-xref="利未記 27:30–33; 歷代志下 31:4–6; 民數記 18:21–32"> 那得祭司職任的利未子孫，領命照例向百姓取十分之一，這百姓是自己的弟兄，雖是從亞伯拉罕身<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是腰">a</a></sup>中生的，還是照例取十分之一。</span>
<span className="v" id="v6" data-v="6" data-xref="羅馬書 4:13; 希伯來書 7:3–4; 創世記 13:14–17"> 獨有麥基洗德，不與他們同譜，倒收納亞伯拉罕的十分之一，為那蒙應許的亞伯拉罕祝福。</span>
<span className="v" id="v7" data-v="7" data-xref="歷代志下 30:27; 創世記 48:15–20; 提摩太前書 3:16"> 從來位分大的給位分小的祝福，這是駁不倒的理。</span>
<span className="v" id="v8" data-v="8" data-xref="希伯來書 6:20; 希伯來書 5:6; 啟示錄 1:18"> 在這裏收十分之一的都是必死的人；但在那裏收十分之一的，有為他作見證的說，他是活的；</span>
<span className="v" id="v9" data-v="9" data-xref="羅馬書 5:12; 創世記 14:20; 希伯來書 7:4"> 並且可說那受十分之一的利未，也是藉着亞伯拉罕納了十分之一。</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 35:11; 希伯來書 7:5; 創世記 46:26"> 因為麥基洗德迎接亞伯拉罕的時候，利未已經在他先祖的身<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原文是腰">b</a></sup>中。</span>
<span className="v" id="v11" data-v="11" data-xref="希伯來書 8:7; 加拉太書 2:21; 加拉太書 4:9"> 從前百姓在利未人祭司職任以下受律法，倘若藉這職任能得完全，又何用另外興起一位祭司，照麥基洗德的等次，不照亞倫的等次呢？</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米書 31:31–34; 以賽亞書 66:21; 以西結書 16:61"> 祭司的職任既已更改，律法也必須更改。</span>
<span className="v" id="v13" data-v="13" data-xref="希伯來書 7:11; 希伯來書 7:14; 民數記 17:5"> 因為這話所指的人本屬別的支派，那支派裏從來沒有一人伺候祭壇。</span>
<span className="v" id="v14" data-v="14" data-xref="彌迦書 5:2; 以賽亞書 11:1; 路加福音 3:33"> 我們的主分明是從猶大出來的；但這支派，摩西並沒有提到祭司。</span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 110:4; 希伯來書 7:17–21; 希伯來書 7:3"> 倘若照麥基洗德的樣式，另外興起一位祭司來，我的話更是顯而易見的了。</span>
<span className="v" id="v16" data-v="16" data-xref="啟示錄 1:18; 歌羅西書 2:20; 希伯來書 7:28"> 他成為祭司，並不是照屬肉體的條例，乃是照無窮<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="原文是不能毀壞">c</a></sup>之生命的大能。</span>
<span className="v" id="v17" data-v="17" data-xref="詩篇 110:4; 希伯來書 5:6; 希伯來書 7:21"> 因為有給他作見證的說：「你是照着麥基洗德的等次永遠為祭司。」</span>
<span className="v" id="v18" data-v="18" data-xref="羅馬書 8:3; 使徒行傳 13:39; 加拉太書 4:9"> 先前的條例，因軟弱無益，所以廢掉了，</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行傳 13:39; 希伯來書 4:16; 希伯來書 9:9"> （律法原來一無所成）就引進了更美的指望；靠這指望，我們便可以進到上帝面前。</span>
<span className="v" id="v20" data-v="20" data-xref="民數記 18:7; 希伯來書 5:6; 詩篇 110:4"> 再者，耶穌為祭司，並不是不起誓立的。</span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 110:4; 希伯來書 7:17; 希伯來書 6:16–18"> 至於那些祭司，原不是起誓立的，只有耶穌是起誓立的；因為那立他的對他說：「主起了誓，決不後悔，你是永遠為祭司。」</span>
<span className="v" id="v22" data-v="22" data-xref="哥林多前書 11:25; 創世記 44:32; 希伯來書 8:6–12"> 既是起誓立的，耶穌就作了更美之約的中保。</span>
<span className="v" id="v23" data-v="23" data-xref="尼希米記 12:10–11; 歷代志上 6:3–14; 希伯來書 7:8"> 那些成為祭司的，數目本來多，是因為有死阻隔，不能長久。</span>
<span className="v" id="v24" data-v="24" data-xref="約翰福音 12:34; 希伯來書 7:28; 以賽亞書 9:6–7"> 這位既是永遠常存的，他祭司的職任就長久不更換。</span>
<span className="v" id="v25" data-v="25" data-xref="羅馬書 8:34; 約翰一書 2:1–2; 提摩太前書 2:5"> 凡靠着他進到上帝面前的人，他都能拯救到底；因為他是長遠活着，替他們祈求。</span>
<span className="v" id="v26" data-v="26" data-xref="哥林多後書 5:21; 希伯來書 4:14–15; 彼得前書 2:22"> 像這樣聖潔、無邪惡、無玷污、遠離罪人、高過諸天的大祭司，原是與我們合宜的。</span>
<span className="v" id="v27" data-v="27" data-xref="希伯來書 9:28; 希伯來書 9:12; 希伯來書 9:14"> 他不像那些大祭司，每日必須先為自己的罪，後為百姓的罪獻祭；因為他只一次將自己獻上，就把這事成全了。</span>
<span className="v" id="v28" data-v="28" data-xref="希伯來書 2:10; 希伯來書 7:21; 希伯來書 1:2"> 律法本是立軟弱的人為大祭司；但在律法以後起誓的話，是立兒子為大祭司，乃是成全到永遠的。</span>

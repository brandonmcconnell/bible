## 論信

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多後書 5:7; 哥林多後書 4:18; 羅馬書 8:24–25"> 信就是所望之事的實底，是未見之事的確據。</span>
<span className="v" id="v2" data-v="2" data-xref="希伯來書 11:39; 希伯來書 11:4"> 古人在這信上得了美好的證據。</span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 33:6; 彼得後書 3:5; 約翰福音 1:3"> 我們因着信，就知道諸世界是藉上帝話造成的；這樣，所看見的，並不是從顯然之物造出來的。</span>
<span className="v" id="v4" data-v="4" data-xref="希伯來書 12:24; 創世記 4:3–5; 約翰一書 3:11–12"> 亞伯因着信，獻祭與上帝，比該隱所獻的更美，因此便得了稱義的見證，就是上帝指他禮物作的見證。他雖然死了，卻因這信，仍舊說話。</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 5:21–24; 猶大書 1:14; 希伯來書 11:6"> 以諾因着信，被接去，不至於見死，人也找不着他，因為上帝已經把他接去了；只是他被接去以先，已經得了上帝喜悅他的明證。</span>
<span className="v" id="v6" data-v="6" data-xref="箴言 8:17; 耶利米書 29:13–14; 馬太福音 6:33"> 人非有信，就不能得上帝的喜悅；因為到上帝面前來的人必須信有上帝，且信他賞賜那尋求他的人。</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 6:13–1; 彼得前書 3:20; 以西結書 14:14"> 挪亞因着信，既蒙上帝指示他未見的事，動了敬畏的心，預備了一隻方舟，使他全家得救。因此就定了那世代的罪，自己也承受了那從信而來的義。</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 12:1–4; 使徒行傳 7:2–4; 馬太福音 7:24–25"> 亞伯拉罕因着信，蒙召的時候就遵命出去，往將來要得為業的地方去；出去的時候，還不知往哪裏去。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 12:8; 創世記 13:18; 創世記 13:3"> 他因着信，就在所應許之地作客，好像在異地居住帳棚，與那同蒙一個應許的以撒、雅各一樣。</span>
<span className="v" id="v10" data-v="10" data-xref="希伯來書 13:14; 腓立比書 3:20; 希伯來書 12:22"> 因為他等候那座有根基的城，就是上帝所經營所建造的。</span>
<span className="v" id="v11" data-v="11" data-xref="羅馬書 4:20–21; 希伯來書 10:23; 創世記 18:11–14"> 因着信，連撒拉自己，雖然過了生育的歲數，還能懷孕，因她以為那應許她的是可信的。</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 22:17; 創世記 32:12; 創世記 15:5"> 所以從一個彷彿已死的人就生出子孫，如同天上的星那樣眾多，海邊的沙那樣無數。</span>
<span className="v" id="v13" data-v="13" data-xref="創世記 23:4; 詩篇 39:12; 希伯來書 11:27"> 這些人都是存着信心死的，並沒有得着所應許的；卻從遠處望見，且歡喜迎接，又承認自己在世上是客旅，是寄居的。</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多後書 4:18–7; 希伯來書 11:16; 希伯來書 13:14"> 說這樣話的人是表明自己要找一個家鄉。</span>
<span className="v" id="v15" data-v="15" data-xref="創世記 24:6–8; 創世記 12:10; 創世記 32:9–11"> 他們若想念所離開的家鄉，還有可以回去的機會。</span>
<span className="v" id="v16" data-v="16" data-xref="希伯來書 13:14; 希伯來書 11:10; 腓立比書 3:20"> 他們卻羨慕一個更美的家鄉，就是在天上的。所以上帝被稱為他們的上帝，並不以為恥，因為他已經給他們預備了一座城。</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 22:16; 創世記 22:1–12; 雅各書 2:21–24"> 亞伯拉罕因着信，被試驗的時候，就把以撒獻上；這便是那歡喜領受應許的，將自己獨生的兒子獻上。</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 21:12; 羅馬書 9:7; 創世記 17:19"> 論到這兒子，曾有話說：「從以撒生的才要稱為你的後裔。」</span>
<span className="v" id="v19" data-v="19" data-xref="羅馬書 4:17–21; 馬太福音 9:28; 以弗所書 3:20"> 他以為上帝還能叫人從死裏復活；他也彷彿從死中得回他的兒子來。</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 27:27–40; 創世記 28:2–3"> 以撒因着信，就指着將來的事給雅各、以掃祝福。</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 47:31–1; 創世記 48:5–22"> 雅各因着信，臨死的時候，給約瑟的兩個兒子各自祝福，扶着杖頭敬拜上帝。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及記 13:19; 創世記 50:24–25; 約書亞記 24:32"> 約瑟因着信，臨終的時候，提到以色列族將來要出埃及，並為自己的骸骨留下遺命。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及記 1:22; 出埃及記 1:16; 希伯來書 13:6"> 摩西生下來，他的父母見他是個俊美的孩子，就因着信，把他藏了三個月，並不怕王命。</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及記 2:10–11; 使徒行傳 7:21–24"> 摩西因着信，長大了就不肯稱為法老女兒之子。</span>
<span className="v" id="v25" data-v="25" data-xref="詩篇 84:10; 提摩太後書 2:3–10; 約伯記 36:21"> 他寧可和上帝的百姓同受苦害，也不願暫時享受罪中之樂。</span>
<span className="v" id="v26" data-v="26" data-xref="希伯來書 10:35; 希伯來書 11:6; 彼得前書 4:14"> 他看為基督受的凌辱比埃及的財物更寶貴，因他想望所要得的賞賜。</span>
<span className="v" id="v27" data-v="27" data-xref="哥林多後書 4:18; 希伯來書 11:13; 希伯來書 11:1"> 他因着信，就離開埃及，不怕王怒；因為他恆心忍耐，如同看見那不能看見的主。</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及記 12:21–30; 希伯來書 9:19; 希伯來書 12:24"> 他因着信，就守<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或譯：立">a</a></sup>逾越節，行灑血的禮，免得那滅長子的臨近以色列人。</span>
<span className="v" id="v29" data-v="29" data-xref="出埃及記 14:13–21; 詩篇 106:9–11; 詩篇 78:13"> 他們因着信，過紅海如行乾地；埃及人試着要過去，就被吞滅了。</span>
<span className="v" id="v30" data-v="30" data-xref="約書亞記 6:3–20; 哥林多後書 10:4–5"> 以色列人因着信，圍繞耶利哥城七日，城牆就倒塌了。</span>
<span className="v" id="v31" data-v="31" data-xref="雅各書 2:25; 約書亞記 6:22–25; 馬太福音 1:5"> 妓女喇合因着信，曾和和平平地接待探子，就不與那些不順從的人一同滅亡。</span>
<span className="v" id="v32" data-v="32" data-xref="撒母耳記上 16:1; 撒母耳記上 1:20; 撒母耳記上 16:13"> 我又何必再說呢？若要一一細說，基甸、巴拉、參孫、耶弗他、大衛、撒母耳，和眾先知的事，時候就不夠了。</span>
<span className="v" id="v33" data-v="33" data-xref="詩篇 144:1–2; 希伯來書 6:12–15; 希伯來書 10:36"> 他們因着信，制伏了敵國，行了公義，得了應許，堵了獅子的口，</span>
<span className="v" id="v34" data-v="34" data-xref="列王紀下 6:16–18; 哥林多後書 12:9–10; 撒母耳記上 17:51–52"> 滅了烈火的猛勢，脫了刀劍的鋒刃；軟弱變為剛強，爭戰顯出勇敢，打退外邦的全軍。</span>
<span className="v" id="v35" data-v="35" data-xref="列王紀下 4:27–37; 列王紀上 17:22–24; 腓立比書 3:11"> 有婦人得自己的死人復活。又有人忍受嚴刑，不肯苟且得釋放<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原文是贖">b</a></sup>，為要得着更美的復活。</span>
<span className="v" id="v36" data-v="36" data-xref="耶利米書 20:2; 創世記 39:20; 耶利米書 37:15–21"> 又有人忍受戲弄、鞭打、捆鎖、監禁、各等的磨煉，</span>
<span className="v" id="v37" data-v="37" data-xref="歷代志下 24:21; 耶利米書 26:23; 列王紀上 19:10"> 被石頭打死，被鋸鋸死，受試探，被刀殺，披着綿羊、山羊的皮各處奔跑，受窮乏、患難、苦害，</span>
<span className="v" id="v38" data-v="38" data-xref="列王紀上 18:4; 撒母耳記上 22:1; 列王紀上 19:9"> 在曠野、山嶺、山洞、地穴，飄流無定，本是世界不配有的人。</span>
<span className="v" id="v39" data-v="39" data-xref="路加福音 10:23–24; 希伯來書 11:13; 希伯來書 11:2"> 這些人都是因信得了美好的證據，卻仍未得着所應許的；</span>
<span className="v" id="v40" data-v="40" data-xref="啟示錄 6:11; 希伯來書 8:6; 希伯來書 10:11–14"> 因為上帝給我們預備了更美的事，叫他們若不與我們同得，就不能完全。</span>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="希伯來書 12:15; 希伯來書 4:9; 箴言 28:14"> 我們既蒙留下，有進入他安息的應許，就當畏懼，免得我們<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是你們">a</a></sup>中間或有人似乎是趕不上了。</span>
<span className="v" id="v2" data-v="2" data-xref="帖撒羅尼迦前書 2:13; 羅馬書 10:16–17; 希伯來書 11:6"> 因為有福音傳給我們，像傳給他們一樣；只是所聽見的道與他們無益，因為他們沒有信心與所聽見的道調和。</span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 95:11; 馬太福音 11:28–29; 彼得前書 1:20"> 但我們已經相信的人得以進入那安息，正如上帝所說：「我在怒中起誓說：『他們斷不可進入我的安息！』」其實造物之工，從創世以來已經成全了。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及記 20:11; 出埃及記 31:17; 創世記 2:1–2"> 論到第七日，有一處說：「到第七日，上帝就歇了他一切的工。」</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 95:11; 希伯來書 4:3; 希伯來書 3:11"> 又有一處說：「他們斷不可進入我的安息！」</span>
<span className="v" id="v6" data-v="6" data-xref="馬太福音 21:43; 希伯來書 3:18–19; 使徒行傳 13:46–47"> 既有必進安息的人，那先前聽見福音的，因為不信從，不得進去。</span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 95:7; 希伯來書 3:7–8; 希伯來書 3:15"> 所以過了多年，就在大衛的書上，又限定一日，如以上所引的說：「你們今日若聽他的話，就不可硬着心。」</span>
<span className="v" id="v8" data-v="8" data-xref="約書亞記 1:15; 約書亞記 22:4; 申命記 12:9"> 若是約書亞已叫他們享了安息，後來上帝就不再提別的日子了。</span>
<span className="v" id="v9" data-v="9" data-xref="彼得前書 2:10; 啟示錄 21:4; 啟示錄 7:14–17"> 這樣看來，必另有一安息日的安息為上帝的子民存留。</span>
<span className="v" id="v10" data-v="10" data-xref="啟示錄 14:13; 希伯來書 4:3–4; 彼得前書 4:1–2"> 因為那進入安息的，乃是歇了自己的工，正如上帝歇了他的工一樣。</span>
<span className="v" id="v11" data-v="11" data-xref="馬太福音 11:28–30; 路加福音 13:24; 希伯來書 3:18–1"> 所以，我們務必竭力進入那安息，免得有人學那不信從的樣子跌倒了。</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米書 23:29; 以賽亞書 55:11; 以弗所書 6:17"> 上帝的道是活潑的，是有功效的，比一切兩刃的劍更快，甚至魂與靈，骨節與骨髓，都能刺入、剖開，連心中的思念和主意都能辨明。</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多前書 4:5; 詩篇 33:13–15; 箴言 15:3"> 並且被造的沒有一樣在他面前不顯然的；原來萬物在那與我們有關係的主眼前，都是赤露敞開的。</span>

## 大祭司耶穌

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="希伯來書 9:24; 希伯來書 12:2; 希伯來書 9:12"> 我們既然有一位已經升入高天尊榮的大祭司，就是上帝的兒子耶穌，便當持定所承認的道。</span>
<span className="v" id="v15" data-v="15" data-xref="希伯來書 2:17–18; 哥林多後書 5:21; 以賽亞書 53:4–5"> 因我們的大祭司並非不能體恤我們的軟弱。他也曾凡事受過試探，與我們一樣，只是他沒有犯罪。</span>
<span className="v" id="v16" data-v="16" data-xref="以弗所書 3:12; 希伯來書 7:25; 希伯來書 10:19–23"> 所以，我們只管坦然無懼地來到施恩的寶座前，為要得憐恤，蒙恩惠，作隨時的幫助。</span>
</div>

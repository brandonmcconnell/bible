## 蒙上帝悅納的服務

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="約翰一書 4:20–1; 彼得前書 3:8; 彼得前書 1:22"> 你們務要常存弟兄相愛的心。</span>
<span className="v" id="v2" data-v="2" data-xref="馬太福音 25:35; 創世記 18:1–3; 彼得前書 4:9"> 不可忘記用愛心接待客旅；因為曾有接待客旅的，不知不覺就接待了天使。</span>
<span className="v" id="v3" data-v="3" data-xref="馬太福音 25:36; 希伯來書 10:34; 羅馬書 12:15"> 你們要記念被捆綁的人，好像與他們同受捆綁；也要記念遭苦害的人，想到自己也在肉身之內。</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 2:24; 箴言 5:15–23; 加拉太書 5:19"> 婚姻，人人都當尊重，床也不可污穢；因為苟合行淫的人，上帝必要審判。</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 31:8; 約書亞記 1:5; 申命記 31:6"> 你們存心不可貪愛錢財，要以自己所有的為足；因為主曾說：「我總不撇下你，也不丟棄你。」</span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 118:6–9; 以賽亞書 41:10; 羅馬書 8:31"> 所以我們可以放膽說：<br /><span className="pl pl-1">主是幫助我的，我必不懼怕；</span><br /><span className="pl pl-1">人能把我怎麼樣呢？</span></span>
<span className="v" id="v7" data-v="7" data-xref="帖撒羅尼迦前書 5:12–13; 希伯來書 13:17; 腓立比書 3:17"> 從前引導你們、傳上帝之道給你們的人，你們要想念他們，效法他們的信心，留心看他們為人的結局。</span>
<span className="v" id="v8" data-v="8" data-xref="瑪拉基書 3:6; 雅各書 1:17; 啟示錄 1:8"> 耶穌基督昨日、今日、一直到永遠，是一樣的。</span>
<span className="v" id="v9" data-v="9" data-xref="以弗所書 4:14; 提摩太前書 6:3–5; 以弗所書 5:6"> 你們不要被那諸般怪異的教訓勾引了去；因為人心靠恩得堅固才是好的，並不是靠飲食。那在飲食上專心的從來沒有得着益處。</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多前書 5:7–8; 哥林多前書 10:20; 哥林多前書 9:13"> 我們有一祭壇，上面的祭物是那些在帳幕中供職的人不可同吃的。</span>
<span className="v" id="v11" data-v="11" data-xref="利未記 16:27; 出埃及記 29:14; 利未記 9:11"> 原來牲畜的血被大祭司帶入聖所作贖罪祭；牲畜的身子被燒在營外。</span>
<span className="v" id="v12" data-v="12" data-xref="希伯來書 9:12–14; 約翰福音 19:17–18; 使徒行傳 7:58"> 所以，耶穌要用自己的血叫百姓成聖，也就在城門外受苦。</span>
<span className="v" id="v13" data-v="13" data-xref="希伯來書 11:26; 彼得前書 4:14–16; 使徒行傳 5:41"> 這樣，我們也當出到營外，就了他去，忍受他所受的凌辱。</span>
<span className="v" id="v14" data-v="14" data-xref="腓立比書 3:20; 歌羅西書 3:1–3; 希伯來書 11:12–16"> 我們在這裏本沒有常存的城，乃是尋求那將來的城。</span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 107:21–22; 詩篇 50:14; 羅馬書 12:1"> 我們應當靠着耶穌，常常以頌讚為祭獻給上帝，這就是那承認主名之人嘴唇的果子。</span>
<span className="v" id="v16" data-v="16" data-xref="帖撒羅尼迦後書 3:13; 加拉太書 6:10; 羅馬書 12:13"> 只是不可忘記行善和捐輸的事，因為這樣的祭是上帝所喜悅的。</span>
<span className="v" id="v17" data-v="17" data-xref="帖撒羅尼迦前書 5:12–13; 提摩太前書 5:17; 希伯來書 13:7"> 你們要依從那些引導你們的，且要順服；因他們為你們的靈魂時刻警醒，好像那將來交帳的人。你們要使他們交的時候有快樂，不致憂愁；若憂愁就與你們無益了。</span>
<span className="v" id="v18" data-v="18" data-xref="帖撒羅尼迦前書 5:25; 帖撒羅尼迦後書 3:1; 歌羅西書 4:3"> 請你們為我們禱告，因我們自覺良心無虧，願意凡事按正道而行。</span>
<span className="v" id="v19" data-v="19" data-xref="腓利門書 1:22; 羅馬書 1:10–12; 羅馬書 15:31–32"> 我更求你們為我禱告，使我快些回到你們那裏去。</span>
</div>
</div>

## 祝福和問安

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="約翰福音 10:11; 希伯來書 10:22; 詩篇 23:1"> 但願賜平安的上帝，就是那憑永約之血、使群羊的大牧人－我主耶穌從死裏復活的上帝，</span>
<span className="v" id="v21" data-v="21" data-xref="腓立比書 2:13; 帖撒羅尼迦後書 2:17; 腓立比書 4:13"> 在各樣善事上成全你們，叫你們遵行他的旨意；又藉着耶穌基督在你們心裏行他所喜悅的事。願榮耀歸給他，直到永永遠遠。阿們！</span>
<span className="v" id="v22" data-v="22" data-xref="希伯來書 3:1; 彼得前書 5:12; 哥林多後書 6:1"> 弟兄們，我略略寫信給你們，望你們聽我勸勉的話。</span>
<span className="v" id="v23" data-v="23" data-xref="腓利門書 1:1; 帖撒羅尼迦前書 3:2; 提摩太後書 1:8"> 你們該知道，我們的兄弟提摩太已經釋放了；他若快來，我必同他去見你們。</span>
<span className="v" id="v24" data-v="24" data-xref="希伯來書 13:7; 希伯來書 13:17; 使徒行傳 18:2"> 請你們問引導你們的諸位和眾聖徒安。從意大利來的人也問你們安。</span>
<span className="v" id="v25" data-v="25" data-xref="歌羅西書 4:18; 提摩太後書 4:22; 提多書 3:15"> 願恩惠常與你們眾人同在。阿們！</span>
</div>

## 更美之約的大祭司

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="希伯來書 1:3; 歌羅西書 3:1; 啟示錄 3:21"> 我們所講的事，其中第一要緊的，就是我們有這樣的大祭司，已經坐在天上至大者寶座的右邊，</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 33:7; 哥林多後書 5:1; 希伯來書 9:23–24"> 在聖所，就是真帳幕裏，作執事；這帳幕是主所支的，不是人所支的。</span>
<span className="v" id="v3" data-v="3" data-xref="以弗所書 5:2; 希伯來書 5:1; 希伯來書 9:14"> 凡大祭司都是為獻禮物和祭物設立的，所以這位大祭司也必須有所獻的。</span>
<span className="v" id="v4" data-v="4" data-xref="希伯來書 7:11–15; 希伯來書 5:1; 民數記 17:12–13"> 他若在地上，必不得為祭司，因為已經有照律法獻禮物的祭司。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及記 25:40; 歌羅西書 2:17; 希伯來書 10:1"> 他們供奉的事本是天上事的形狀和影像，正如摩西將要造帳幕的時候，蒙上帝警戒他，說：「你要謹慎，作各樣的物件都要照着在山上指示你的樣式。」</span>
<span className="v" id="v6" data-v="6" data-xref="希伯來書 7:22; 加拉太書 3:16–21; 希伯來書 12:24"> 如今耶穌所得的職任是更美的，正如他作更美之約的中保；這約原是憑更美之應許立的。</span>
<span className="v" id="v7" data-v="7" data-xref="希伯來書 7:11; 加拉太書 3:21; 希伯來書 7:18"> 那前約若沒有瑕疵，就無處尋求後約了。</span>
<span className="v" id="v8" data-v="8" data-xref="耶利米書 31:31–34; 希伯來書 10:16–17; 希伯來書 12:24"> 所以主指責他的百姓說<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或譯：所以主指前約的缺欠說">a</a></sup>：<br /><span className="pl pl-1">日子將到，</span><br /><span className="pl pl-1">我要與以色列家和猶大家另立新約，</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="耶利米書 31:32; 加拉太書 4:24; 馬可福音 8:23"> <span className="pl pl-1">不像我拉着他們祖宗的手，</span><br /><span className="pl pl-1">領他們出埃及的時候，</span><br /><span className="pl pl-1">與他們所立的約。</span><br /><span className="pl pl-1">因為他們不恆心守我的約，</span><br /><span className="pl pl-1">我也不理他們。</span><br /><span className="pl pl-1">這是主說的。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="以西結書 36:26–28; 耶利米書 31:33; 以西結書 11:19–20"> <span className="pl pl-1">主又說：</span><br /><span className="pl pl-1">那些日子以後，</span><br /><span className="pl pl-1">我與以色列家所立的約乃是這樣：</span><br /><span className="pl pl-1">我要將我的律法放在他們裏面，</span><br /><span className="pl pl-1">寫在他們心上；</span><br /><span className="pl pl-1">我要作他們的上帝；</span><br /><span className="pl pl-1">他們要作我的子民。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="耶利米書 31:34; 以賽亞書 54:13; 約翰福音 6:45"> <span className="pl pl-1">他們不用各人教導自己的鄉鄰和自己的弟兄，</span><br /><span className="pl pl-1">說：你該認識主；</span><br /><span className="pl pl-1">因為他們從最小的到至大的，都必認識我。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="希伯來書 10:16–17; 以賽亞書 43:25; 羅馬書 11:27"> <span className="pl pl-1">我要寬恕他們的不義，</span><br /><span className="pl pl-1">不再記念他們的罪愆。</span></span>
<span className="v" id="v13" data-v="13" data-xref="哥林多後書 5:17; 希伯來書 7:18–19; 希伯來書 7:11–12"> 既說新約，就以前約為舊了；但那漸舊漸衰的，就必快歸無有了。</span>
</div>

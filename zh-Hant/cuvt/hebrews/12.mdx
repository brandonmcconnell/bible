## 主的管教

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="提摩太後書 4:7; 哥林多前書 9:24–27; 腓立比書 2:16"> 我們既有這許多的見證人，如同雲彩圍着我們，就當放下各樣的重擔，脫去容易纏累我們的罪，存心忍耐，奔那擺在我們前頭的路程，</span>
<span className="v" id="v2" data-v="2" data-xref="彌迦書 7:7; 彼得前書 3:18; 彼得前書 2:23–24"> 仰望為我們信心創始成終的耶穌<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或譯：仰望那將真道創始成終的耶穌">a</a></sup>。他因那擺在前面的喜樂，就輕看羞辱，忍受了十字架的苦難，便坐在上帝寶座的右邊。</span>
<span className="v" id="v3" data-v="3" data-xref="加拉太書 6:9; 哥林多後書 4:16; 啟示錄 2:3"> 那忍受罪人這樣頂撞的，你們要思想，免得疲倦灰心。</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多前書 10:13; 啟示錄 2:13; 希伯來書 10:32–34"> 你們與罪惡相爭，還沒有抵擋到流血的地步。</span>
<span className="v" id="v5" data-v="5" data-xref="箴言 3:11–12; 約伯記 5:17–18; 啟示錄 3:19"> 你們又忘了那勸你們如同勸兒子的話，說：<br /><span className="pl pl-1">我兒，你不可輕看主的管教，</span><br /><span className="pl pl-1">被他責備的時候也不可灰心；</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="啟示錄 3:19; 箴言 3:12; 詩篇 119:75"> <span className="pl pl-1">因為主所愛的，他必管教，</span><br /><span className="pl pl-1">又鞭打凡所收納的兒子。</span></span>
<span className="v" id="v7" data-v="7" data-xref="箴言 19:18; 申命記 8:5; 箴言 13:24"> 你們所忍受的，是上帝管教你們，待你們如同待兒子。焉有兒子不被父親管教的呢？</span>
<span className="v" id="v8" data-v="8" data-xref="希伯來書 12:6; 彼得前書 5:9–10; 詩篇 73:1"> 管教原是眾子所共受的。你們若不受管教，就是私子，不是兒子了。</span>
<span className="v" id="v9" data-v="9" data-xref="民數記 16:22; 民數記 27:16; 以賽亞書 42:5"> 再者，我們曾有生身的父管教我們，我們尚且敬重他，何況萬靈的父，我們豈不更當順服他得生嗎？</span>
<span className="v" id="v10" data-v="10" data-xref="彼得後書 1:4; 利未記 11:44–45; 提多書 2:14"> 生身的父都是暫隨己意管教我們；惟有萬靈的父管教我們，是要我們得益處，使我們在他的聖潔上有分。</span>
<span className="v" id="v11" data-v="11" data-xref="羅馬書 5:3–5; 哥林多後書 4:17; 希伯來書 12:5–6"> 凡管教的事，當時不覺得快樂，反覺得愁苦；後來卻為那經練過的人結出平安的果子，就是義。</span>
<span className="v" id="v12" data-v="12" data-xref="以賽亞書 35:3; 希伯來書 12:3; 帖撒羅尼迦前書 5:14"> 所以，你們要把下垂的手、發酸的腿挺起來；</span>
<span className="v" id="v13" data-v="13" data-xref="箴言 4:26–27; 以賽亞書 35:3; 加拉太書 6:1"> 也要為自己的腳，把道路修直了，使瘸子不致歪腳<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或譯：差路">b</a></sup>，反得痊癒。</span>
</div>

## 警告棄絕上帝恩典的人

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="哥林多後書 7:1; 彼得前書 1:15–16; 帖撒羅尼迦前書 4:7"> 你們要追求與眾人和睦，並要追求聖潔；非聖潔沒有人能見主。</span>
<span className="v" id="v15" data-v="15" data-xref="希伯來書 3:12; 申命記 29:18; 加拉太書 5:4"> 又要謹慎，恐怕有人失了上帝的恩；恐怕有毒根生出來擾亂你們，因此叫眾人沾染污穢；</span>
<span className="v" id="v16" data-v="16" data-xref="創世記 25:31–34; 哥林多前書 6:15–20; 啟示錄 22:15"> 恐怕有淫亂的，有貪戀世俗如以掃的，他因一點食物把自己長子的名分賣了。</span>
<span className="v" id="v17" data-v="17" data-xref="箴言 1:24–31; 馬太福音 25:11–12; 馬太福音 7:23"> 後來想要承受父所祝的福，竟被棄絕，雖然號哭切求，卻得不着門路使他父親的心意回轉。這是你們知道的。</span>
<span className="v" id="v18" data-v="18" data-xref="申命記 4:11; 出埃及記 24:17; 出埃及記 20:18"> 你們原不是來到那能摸的山；此山有火焰、密雲、黑暗、暴風、</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 18:16; 哥林多前書 15:52; 申命記 4:12"> 角聲與說話的聲音。那些聽見這聲音的，都求不要再向他們說話；</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及記 19:12–13; 出埃及記 19:16; 加拉太書 3:10"> 因為他們當不起所命他們的話，說：「靠近這山的，即便是走獸，也要用石頭打死。」</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及記 19:16; 申命記 9:19; 以賽亞書 6:3–5"> 所見的極其可怕，甚至摩西說：「我甚是恐懼戰兢。」</span>
<span className="v" id="v22" data-v="22" data-xref="加拉太書 4:26; 腓立比書 3:20; 啟示錄 14:1"> 你們乃是來到錫安山，永生上帝的城邑，就是天上的耶路撒冷。那裏有千萬的天使，</span>
<span className="v" id="v23" data-v="23" data-xref="雅各書 1:18; 希伯來書 11:40; 路加福音 10:20"> 有名錄在天上諸長子之會所共聚的總會，有審判眾人的上帝和被成全之義人的靈魂，</span>
<span className="v" id="v24" data-v="24" data-xref="希伯來書 9:15; 希伯來書 11:28; 希伯來書 11:4"> 並新約的中保耶穌，以及所灑的血；這血所說的比亞伯的血所說的更美。</span>
<span className="v" id="v25" data-v="25" data-xref="希伯來書 8:5; 申命記 30:17; 希伯來書 2:1–3"> 你們總要謹慎，不可棄絕那向你們說話的。因為，那些棄絕在地上警戒他們的尚且不能逃罪，何況我們違背那從天上警戒我們的呢？</span>
<span className="v" id="v26" data-v="26" data-xref="哈該書 2:6–7; 以賽亞書 13:13; 出埃及記 19:18"> 當時他的聲音震動了地，但如今他應許說：「再一次我不單要震動地，還要震動天。」</span>
<span className="v" id="v27" data-v="27" data-xref="哥林多前書 7:31; 馬太福音 24:35; 彼得後書 3:10–11"> 這再一次的話，是指明被震動的，就是受造之物都要挪去，使那不被震動的常存。</span>
<span className="v" id="v28" data-v="28" data-xref="羅馬書 12:1–2; 希伯來書 13:15; 但以理書 2:44"> 所以我們既得了不能震動的國，就當感恩，照上帝所喜悅的，用虔誠、敬畏的心事奉上帝。</span>
<span className="v" id="v29" data-v="29" data-xref="申命記 4:24; 申命記 9:3; 希伯來書 10:27"> 因為我們的上帝乃是烈火。</span>
</div>

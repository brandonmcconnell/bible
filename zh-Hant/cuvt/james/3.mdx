## 論舌頭

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 12:47–48; 提摩太前書 1:7; 彼得前書 5:3"> 我的弟兄們，不要多人作師傅，因為曉得我們要受更重的判斷。</span>
<span className="v" id="v2" data-v="2" data-xref="雅各書 1:26; 箴言 13:3; 彼得前書 3:10"> 原來我們在許多事上都有過失；若有人在話語上沒有過失，他就是完全人，也能勒住自己的全身。</span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 32:9; 詩篇 39:1; 雅各書 1:26"> 我們若把嚼環放在馬嘴裏，叫牠順服，就能調動牠的全身。</span>
<span className="v" id="v4" data-v="4" data-xref="詩篇 107:25–27; 馬太福音 8:24; 使徒行傳 27:14–38"> 看哪，船隻雖然甚大，又被大風催逼，只用小小的舵，就隨着掌舵的意思轉動。</span>
<span className="v" id="v5" data-v="5" data-xref="箴言 18:21; 耶利米書 9:3–8; 箴言 12:18"> 這樣，舌頭在百體裏也是最小的，卻能說大話。<br />看哪，最小的火能點着最大的樹林。</span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 120:2–3; 箴言 16:27; 馬可福音 7:15"> 舌頭就是火，在我們百體中，舌頭是個罪惡的世界，能污穢全身，也能把生命的輪子點起來，並且是從地獄裏點着的。</span>
<span className="v" id="v7" data-v="7" data-xref="馬可福音 5:4"> 各類的走獸、飛禽、昆蟲、水族，本來都可以制伏，也已經被人制伏了；</span>
<span className="v" id="v8" data-v="8" data-xref="羅馬書 3:13; 詩篇 140:3; 詩篇 55:21"> 惟獨舌頭沒有人能制伏，是不止息的惡物，滿了害死人的毒氣。</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 10:7; 創世記 1:26–27; 詩篇 62:4"> 我們用舌頭頌讚那為主、為父的，又用舌頭咒詛那照着上帝形像被造的人。</span>
<span className="v" id="v10" data-v="10" data-xref="羅馬書 12:14; 彼得前書 3:9; 哥林多前書 3:3"> 頌讚和咒詛從一個口裏出來！我的弟兄們，這是不應當的！</span>
<span className="v" id="v11" data-v="11"> 泉源從一個眼裏能發出甜苦兩樣的水嗎？</span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 6:43–44; 馬太福音 12:33; 馬太福音 7:16–20"> 我的弟兄們，無花果樹能生橄欖嗎？葡萄樹能結無花果嗎？鹹水裏也不能發出甜水來。</span>
</div>
</div>

## 論從上頭來的智慧

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="加拉太書 5:23; 雅各書 3:17; 馬太福音 5:5"> 你們中間誰是有智慧有見識的呢？他就當在智慧的溫柔上顯出他的善行來。</span>
<span className="v" id="v14" data-v="14" data-xref="雅各書 3:16; 哥林多前書 13:4; 腓立比書 2:3"> 你們心裏若懷着苦毒的嫉妒和紛爭，就不可自誇，也不可說謊話抵擋真道。</span>
<span className="v" id="v15" data-v="15" data-xref="雅各書 3:17; 雅各書 1:17; 哥林多前書 3:19"> 這樣的智慧不是從上頭來的，乃是屬地的，屬情慾的，屬鬼魔的。</span>
<span className="v" id="v16" data-v="16" data-xref="雅各書 3:14; 哥林多前書 3:3; 哥林多前書 14:33"> 在何處有嫉妒、紛爭，就在何處有擾亂和各樣的壞事。</span>
<span className="v" id="v17" data-v="17" data-xref="加拉太書 5:22–23; 箴言 2:6; 哥林多前書 13:4–7"> 惟獨從上頭來的智慧，先是清潔，後是和平，溫良柔順，滿有憐憫，多結善果，沒有偏見，沒有假冒。</span>
<span className="v" id="v18" data-v="18" data-xref="馬太福音 5:9; 何西阿書 10:12; 腓立比書 1:11"> 並且使人和平的，是用和平所栽種的義果。</span>
</div>
</div>

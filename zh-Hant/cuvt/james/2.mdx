## 警告偏私

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="箴言 24:23; 雅各書 2:9; 利未記 19:15"> 我的弟兄們，你們信奉我們榮耀的主耶穌基督，便不可按着外貌待人。</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 15:22; 以斯帖記 3:10; 以斯帖記 8:2"> 若有一個人帶着金戒指，穿着華美衣服，進你們的會堂去；又有一個窮人穿着骯髒衣服也進去；</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多後書 8:9; 雅各書 2:6; 路加福音 7:44–46"> 你們就重看那穿華美衣服的人，說：「請坐在這好位上」；又對那窮人說：「你站在那裏」，或「坐在我腳凳下邊。」</span>
<span className="v" id="v4" data-v="4" data-xref="約翰福音 7:24; 約伯記 34:19; 馬太福音 7:1–5"> 這豈不是你們偏心待人，用惡意斷定人嗎？</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="馬太福音 5:3; 路加福音 6:20; 啟示錄 2:9"> 我親愛的弟兄們，請聽，上帝豈不是揀選了世上的貧窮人，叫他們在信上富足，並承受他所應許給那些愛他之人的國嗎？</span>
<span className="v" id="v6" data-v="6" data-xref="箴言 17:5; 哥林多前書 11:22; 箴言 14:31"> 你們反倒羞辱貧窮人。那富足人豈不是欺壓你們、拉你們到公堂去嗎？</span>
<span className="v" id="v7" data-v="7" data-xref="腓立比書 2:9–11; 啟示錄 13:5–6; 提摩太前書 1:13"> 他們不是褻瀆你們所敬奉<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="所敬奉：或譯被稱">a</a></sup>的尊名嗎？</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="利未記 19:18; 加拉太書 5:14; 馬太福音 22:39"> 經上記着說：「要愛人如己。」你們若全守這至尊的律法才是好的。</span>
<span className="v" id="v9" data-v="9" data-xref="利未記 19:15; 雅各書 2:1–4; 約翰一書 3:4"> 但你們若按外貌待人，便是犯罪，被律法定為犯法的。</span>
<span className="v" id="v10" data-v="10" data-xref="加拉太書 3:10; 馬太福音 5:18–19; 申命記 27:26"> 因為凡遵守全律法的，只在一條上跌倒，他就是犯了眾條。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及記 20:13–14; 馬太福音 5:21–28; 申命記 5:17–18"> 原來那說「不可姦淫」的，也說「不可殺人」；你就是不姦淫，卻殺人，仍是成了犯律法的。</span>
<span className="v" id="v12" data-v="12" data-xref="雅各書 1:25; 雅各書 2:8; 彼得後書 1:4–8"> 你們既然要按使人自由的律法受審判，就該照這律法說話行事。</span>
<span className="v" id="v13" data-v="13" data-xref="馬太福音 5:7; 馬太福音 6:15; 箴言 21:13"> 因為那不憐憫人的，也要受無憐憫的審判；憐憫原是向審判誇勝。</span>
</div>
</div>

## 信心和行為

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="馬太福音 7:26–27; 馬太福音 7:21–23; 雅各書 1:22–25"> 我的弟兄們，若有人說自己有信心，卻沒有行為，有甚麼益處呢？這信心能救他嗎？</span>
<span className="v" id="v15" data-v="15" data-xref="路加福音 3:11; 馬太福音 25:35–40; 以賽亞書 58:7"> 若是弟兄或是姊妹，赤身露體，又缺了日用的飲食；</span>
<span className="v" id="v16" data-v="16" data-xref="箴言 3:27–28; 約翰一書 3:16–18; 馬太福音 25:42–45"> 你們中間有人對他們說：「平平安安地去吧！願你們穿得暖，吃得飽」，卻不給他們身體所需用的，這有甚麼益處呢？</span>
<span className="v" id="v17" data-v="17" data-xref="雅各書 2:26; 彼得後書 1:5–9; 雅各書 2:19–20"> 這樣，信心若沒有行為就是死的。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="雅各書 3:13; 雅各書 2:14; 加拉太書 5:6"> 必有人說：「你有信心，我有行為；你將你沒有行為的信心指給我看，我便藉着我的行為，將我的信心指給你看。」</span>
<span className="v" id="v19" data-v="19" data-xref="路加福音 4:34; 馬可福音 1:24; 馬太福音 8:29"> 你信上帝只有一位，你信的不錯；鬼魔也信，卻是戰驚。</span>
<span className="v" id="v20" data-v="20" data-xref="雅各書 2:17; 雅各書 2:26; 箴言 12:11"> 虛浮的人哪，你願意知道沒有行為的信心是死的嗎？</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 22:16–18; 創世記 22:9–12; 約翰福音 8:39"> 我們的祖宗亞伯拉罕把他兒子以撒獻在壇上，豈不是因行為稱義嗎？</span>
<span className="v" id="v22" data-v="22" data-xref="帖撒羅尼迦前書 1:3; 希伯來書 11:17–19; 加拉太書 5:6"> 可見，信心是與他的行為並行，而且信心因着行為才得成全。</span>
<span className="v" id="v23" data-v="23" data-xref="創世記 15:6; 以賽亞書 41:8; 歷代志下 20:7"> 這就應驗經上所說：「亞伯拉罕信上帝，這就算為他的義。」他又得稱為上帝的朋友。</span>
<span className="v" id="v24" data-v="24" data-xref="雅各書 2:21–22; 雅各書 2:15–18; 詩篇 60:12"> 這樣看來，人稱義是因着行為，不是單因着信。</span>
<span className="v" id="v25" data-v="25" data-xref="希伯來書 11:31; 約書亞記 6:22–25; 約書亞記 2:19–21"> 妓女喇合接待使者，又放他們從別的路上出去，不也是一樣因行為稱義嗎？</span>
<span className="v" id="v26" data-v="26" data-xref="雅各書 2:20; 雅各書 2:17; 雅各書 2:14"> 身體沒有靈魂是死的，信心沒有行為也是死的。</span>
</div>
</div>

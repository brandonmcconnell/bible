## 給青年人的忠告

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="箴言 4:5; 約翰福音 14:21–24; 申命記 6:6–9"> <span className="pl pl-1">我兒，不要忘記我的法則</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或譯：指教">a</a></sup><br /><span className="pl pl-1">；</span><br /><span className="pl pl-1">你心要謹守我的誡命；</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="以弗所書 6:1–3; 箴言 4:10; 詩篇 91:16"> <span className="pl pl-1">因為它必將長久的日子，</span><br /><span className="pl pl-1">生命的年數與平安，加給你。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="箴言 7:3; 哥林多後書 3:3; 希伯來書 10:16"> <span className="pl pl-1">不可使慈愛、誠實離開你，</span><br /><span className="pl pl-1">要繫在你頸項上，刻在你心版上。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 2:52; 撒母耳記上 2:26; 羅馬書 14:18"> <span className="pl pl-1">這樣，你必在上帝和世人眼前</span><br /><span className="pl pl-1">蒙恩寵，有聰明。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="詩篇 37:5; 耶利米書 17:7–8; 箴言 28:26"> <span className="pl pl-1">你要專心仰賴耶和華，</span><br /><span className="pl pl-1">不可倚靠自己的聰明，</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="箴言 16:3; 詩篇 32:8; 腓立比書 4:6"> <span className="pl pl-1">在你一切所行的事上都要認定他，</span><br /><span className="pl pl-1">他必指引你的路。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="約伯記 28:28; 羅馬書 12:16; 箴言 26:12"> <span className="pl pl-1">不要自以為有智慧；</span><br /><span className="pl pl-1">要敬畏耶和華，遠離惡事。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="箴言 4:22; 詩篇 147:3; 箴言 16:24"> <span className="pl pl-1">這便醫治你的肚臍，</span><br /><span className="pl pl-1">滋潤你的百骨。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="申命記 26:2–15; 哥林多前書 16:2; 出埃及記 23:19"> <span className="pl pl-1">你要以財物</span><br /><span className="pl pl-1">和一切初熟的土產尊榮耶和華。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="箴言 19:17; 申命記 28:8; 箴言 22:9"> <span className="pl pl-1">這樣，你的倉房必充滿有餘；</span><br /><span className="pl pl-1">你的酒醡有新酒盈溢。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v11" data-v="11" data-xref="約伯記 5:17; 啟示錄 3:19; 希伯來書 12:5–12"> <span className="pl pl-1">我兒，你不可輕看耶和華的管教</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或譯：懲治">b</a></sup><br /><span className="pl pl-1">，</span><br /><span className="pl pl-1">也不可厭煩他的責備；</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="申命記 8:5; 啟示錄 3:19; 箴言 29:17"> <span className="pl pl-1">因為耶和華所愛的，他必責備，</span><br /><span className="pl pl-1">正如父親責備所喜愛的兒子。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v13" data-v="13" data-xref="箴言 8:32–35; 箴言 4:5–9; 傳道書 9:15–18"> <span className="pl pl-1">得智慧，得聰明的，</span><br /><span className="pl pl-1">這人便為有福。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="箴言 16:16; 箴言 8:19; 約伯記 28:13–19"> <span className="pl pl-1">因為得智慧勝過得銀子，</span><br /><span className="pl pl-1">其利益強如精金，</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="箴言 8:11; 約伯記 28:18; 詩篇 73:25–26"> <span className="pl pl-1">比珍珠</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="或譯：紅寶石">c</a></sup><br /><span className="pl pl-1">寶貴；</span><br /><span className="pl pl-1">你一切所喜愛的，都不足與比較。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="箴言 3:2; 哥林多後書 6:10; 箴言 22:4"> <span className="pl pl-1">她右手有長壽，</span><br /><span className="pl pl-1">左手有富貴。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="路加福音 1:79; 以賽亞書 26:3; 腓立比書 4:8–9"> <span className="pl pl-1">她的道是安樂；</span><br /><span className="pl pl-1">她的路全是平安。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="箴言 11:30; 啟示錄 2:7; 箴言 15:4"> <span className="pl pl-1">她與持守她的作生命樹；</span><br /><span className="pl pl-1">持定她的，俱各有福。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="詩篇 104:24; 耶利米書 10:12; 約翰福音 1:3"> <span className="pl pl-1">耶和華以智慧立地，</span><br /><span className="pl pl-1">以聰明定天，</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="創世記 7:11; 詩篇 65:9–12; 約伯記 36:27–28"> <span className="pl pl-1">以知識使深淵裂開，</span><br /><span className="pl pl-1">使天空滴下甘露。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v21" data-v="21" data-xref="約書亞記 1:8; 申命記 6:6–9; 申命記 32:46–47"> <span className="pl pl-1">我兒，要謹守真智慧和謀略，</span><br /><span className="pl pl-1">不可使她離開你的眼目。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="箴言 4:22; 箴言 1:9; 以賽亞書 38:16"> <span className="pl pl-1">這樣，她必作你的生命，</span><br /><span className="pl pl-1">頸項的美飾。</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="箴言 4:12; 箴言 10:9; 詩篇 121:3"> <span className="pl pl-1">你就坦然行路，</span><br /><span className="pl pl-1">不致碰腳。</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="詩篇 3:5; 詩篇 4:8; 箴言 6:22"> <span className="pl pl-1">你躺下，必不懼怕；</span><br /><span className="pl pl-1">你躺臥，睡得香甜。</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="以賽亞書 41:10–14; 詩篇 112:7; 彼得前書 3:14"> <span className="pl pl-1">忽然來的驚恐，不要害怕；</span><br /><span className="pl pl-1">惡人遭毀滅，也不要恐懼。</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="詩篇 91:3; 撒母耳記上 2:9; 箴言 14:26"> <span className="pl pl-1">因為耶和華是你所倚靠的；</span><br /><span className="pl pl-1">他必保守你的腳不陷入網羅。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v27" data-v="27" data-xref="加拉太書 6:10; 雅各書 2:15–16; 羅馬書 13:7"> <span className="pl pl-1">你手若有行善的力量，不可推辭，</span><br /><span className="pl pl-1">就當向那應得的人施行。</span><br /></span>
<span className="v" id="v28" data-v="28" data-xref="利未記 19:13; 申命記 24:12–15; 哥林多後書 8:11"> <span className="pl pl-1">你那裏若有現成的，不可對鄰舍說：</span><br /><span className="pl pl-1">去吧，明天再來，我必給你。</span><br /></span>
<span className="v" id="v29" data-v="29" data-xref="箴言 6:14; 箴言 16:29–30; 詩篇 55:20"> <span className="pl pl-1">你的鄰舍既在你附近安居，</span><br /><span className="pl pl-1">你不可設計害他。</span><br /></span>
<span className="v" id="v30" data-v="30" data-xref="提摩太後書 2:24; 箴言 29:22; 羅馬書 12:18–21"> <span className="pl pl-1">人未曾加害與你，</span><br /><span className="pl pl-1">不可無故與他相爭。</span><br /></span>
<span className="v" id="v31" data-v="31" data-xref="箴言 24:1; 詩篇 37:1; 加拉太書 5:21"> <span className="pl pl-1">不可嫉妒強暴的人，</span><br /><span className="pl pl-1">也不可選擇他所行的路。</span><br /></span>
<span className="v" id="v32" data-v="32" data-xref="詩篇 25:14; 約翰福音 15:15; 箴言 11:20"> <span className="pl pl-1">因為，乖僻人為耶和華所憎惡；</span><br /><span className="pl pl-1">正直人為他所親密。</span><br /></span>
<span className="v" id="v33" data-v="33" data-xref="詩篇 37:22; 利未記 26:14–46; 約伯記 8:6–7"> <span className="pl pl-1">耶和華咒詛惡人的家庭，</span><br /><span className="pl pl-1">賜福與義人的居所。</span><br /></span>
<span className="v" id="v34" data-v="34" data-xref="雅各書 4:6; 彼得前書 5:5; 詩篇 138:6"> <span className="pl pl-1">他譏誚那好譏誚的人，</span><br /><span className="pl pl-1">賜恩給謙卑的人。</span><br /></span>
<span className="v" id="v35" data-v="35" data-xref="詩篇 132:18; 以賽亞書 65:13–15; 詩篇 73:24"> <span className="pl pl-1">智慧人必承受尊榮；</span><br /><span className="pl pl-1">愚昧人高升也成為羞辱。</span></span>
</div>

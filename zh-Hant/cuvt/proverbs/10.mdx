## 所羅門的箴言

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="箴言 1:1; 箴言 29:15; 箴言 17:25"> <span className="pl pl-1">所羅門的箴言：</span><br /><span className="pl pl-1">智慧之子使父親歡樂；</span><br /><span className="pl pl-1">愚昧之子叫母親擔憂。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="箴言 11:4; 箴言 12:28; 詩篇 49:6–10"> <span className="pl pl-1">不義之財毫無益處；</span><br /><span className="pl pl-1">惟有公義能救人脫離死亡。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 37:3; 馬太福音 6:30–33; 詩篇 37:25"> <span className="pl pl-1">耶和華不使義人受飢餓；</span><br /><span className="pl pl-1">惡人所欲的，他必推開。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="箴言 21:5; 箴言 20:4; 箴言 19:15"> <span className="pl pl-1">手懶的，要受貧窮；</span><br /><span className="pl pl-1">手勤的，卻要富足。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="箴言 6:8; 箴言 30:25; 箴言 17:2"> <span className="pl pl-1">夏天聚斂的，是智慧之子；</span><br /><span className="pl pl-1">收割時沉睡的，是貽羞之子。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="申命記 28:2; 箴言 28:20; 約伯記 29:13"> <span className="pl pl-1">福祉臨到義人的頭；</span><br /><span className="pl pl-1">強暴蒙蔽惡人的口。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 112:6; 路加福音 1:48; 馬可福音 14:9"> <span className="pl pl-1">義人的紀念被稱讚；</span><br /><span className="pl pl-1">惡人的名字必朽爛。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="馬太福音 7:24–25; 箴言 12:1; 雅各書 3:13"> <span className="pl pl-1">心中智慧的，必受命令；</span><br /><span className="pl pl-1">口裏愚妄的，必致傾倒。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="箴言 28:18; 馬太福音 10:26; 詩篇 26:11–12"> <span className="pl pl-1">行正直路的，步步安穩；</span><br /><span className="pl pl-1">走彎曲道的，必致敗露。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 35:19; 箴言 6:13; 約翰三書 1:10"> <span className="pl pl-1">以眼傳神的，使人憂患；</span><br /><span className="pl pl-1">口裏愚妄的，必致傾倒。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="箴言 13:14; 以弗所書 4:29; 箴言 10:6"> <span className="pl pl-1">義人的口是生命的泉源；</span><br /><span className="pl pl-1">強暴蒙蔽惡人的口。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="彼得前書 4:8; 哥林多前書 13:4–7; 箴言 17:9"> <span className="pl pl-1">恨能挑啟爭端；</span><br /><span className="pl pl-1">愛能遮掩一切過錯。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="箴言 26:3; 箴言 6:32; 以賽亞書 50:4"> <span className="pl pl-1">明哲人嘴裏有智慧；</span><br /><span className="pl pl-1">無知人背上受刑杖。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="箴言 18:7; 箴言 10:8; 箴言 13:3"> <span className="pl pl-1">智慧人積存知識；</span><br /><span className="pl pl-1">愚妄人的口速致敗壞。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="箴言 18:11; 箴言 19:7; 詩篇 52:7"> <span className="pl pl-1">富戶的財物是他的堅城；</span><br /><span className="pl pl-1">窮人的貧乏是他的敗壞。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="羅馬書 6:23; 以賽亞書 3:10–11; 希伯來書 6:10"> <span className="pl pl-1">義人的勤勞致生；</span><br /><span className="pl pl-1">惡人的進項致死</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="死：原文是罪">a</a></sup><br /><span className="pl pl-1">。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="彼得後書 1:5–11; 路加福音 11:28; 箴言 6:23"> <span className="pl pl-1">謹守訓誨的，乃在生命的道上；</span><br /><span className="pl pl-1">違棄責備的，便失迷了路。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="箴言 26:24–26; 詩篇 55:21; 撒母耳記下 3:27"> <span className="pl pl-1">隱藏怨恨的，有說謊的嘴；</span><br /><span className="pl pl-1">口出讒謗的，是愚妄的人。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="雅各書 1:19; 雅各書 3:2; 箴言 17:27–28"> <span className="pl pl-1">多言多語難免有過；</span><br /><span className="pl pl-1">禁止嘴唇是有智慧。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="耶利米書 17:9; 箴言 12:18; 創世記 6:5"> <span className="pl pl-1">義人的舌乃似高銀；</span><br /><span className="pl pl-1">惡人的心所值無幾。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="何西阿書 4:6; 箴言 17:16; 箴言 1:29"> <span className="pl pl-1">義人的口教養多人；</span><br /><span className="pl pl-1">愚昧人因無知而死亡。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="詩篇 107:38; 創世記 26:12; 撒母耳記上 2:7–8"> <span className="pl pl-1">耶和華所賜的福使人富足，</span><br /><span className="pl pl-1">並不加上憂慮。</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="箴言 15:21; 箴言 2:14; 箴言 14:9"> <span className="pl pl-1">愚妄人以行惡為戲耍；</span><br /><span className="pl pl-1">明哲人卻以智慧為樂。</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="詩篇 145:19; 以賽亞書 66:4; 馬太福音 5:6"> <span className="pl pl-1">惡人所怕的，必臨到他；</span><br /><span className="pl pl-1">義人所願的，必蒙應允。</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="詩篇 15:5; 詩篇 58:9; 馬太福音 7:24–27"> <span className="pl pl-1">暴風一過，惡人歸於無有；</span><br /><span className="pl pl-1">義人的根基卻是永久。</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="箴言 25:13; 箴言 26:6; 馬太福音 25:26"> <span className="pl pl-1">懶惰人叫差他的人</span><br /><span className="pl pl-1">如醋倒牙，如煙薰目。</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="箴言 9:11; 箴言 3:2; 詩篇 91:16"> <span className="pl pl-1">敬畏耶和華使人日子加多；</span><br /><span className="pl pl-1">但惡人的年歲必被減少。</span><br /></span>
<span className="v" id="v28" data-v="28" data-xref="約伯記 8:13; 羅馬書 15:13; 詩篇 73:24–26"> <span className="pl pl-1">義人的盼望必得喜樂；</span><br /><span className="pl pl-1">惡人的指望必致滅沒。</span><br /></span>
<span className="v" id="v29" data-v="29" data-xref="箴言 21:15; 羅馬書 2:8–9; 腓立比書 4:13"> <span className="pl pl-1">耶和華的道是正直人的保障，</span><br /><span className="pl pl-1">卻成了作孽人的敗壞。</span><br /></span>
<span className="v" id="v30" data-v="30" data-xref="詩篇 37:22; 詩篇 125:1; 詩篇 37:9–10"> <span className="pl pl-1">義人永不挪移；</span><br /><span className="pl pl-1">惡人不得住在地上。</span><br /></span>
<span className="v" id="v31" data-v="31" data-xref="詩篇 37:30; 箴言 10:13; 箴言 10:20–21"> <span className="pl pl-1">義人的口滋生智慧；</span><br /><span className="pl pl-1">乖謬的舌必被割斷。</span><br /></span>
<span className="v" id="v32" data-v="32" data-xref="箴言 15:28; 箴言 12:6; 箴言 11:11"> <span className="pl pl-1">義人的嘴能令人喜悅；</span><br /><span className="pl pl-1">惡人的口說乖謬的話。</span></span>

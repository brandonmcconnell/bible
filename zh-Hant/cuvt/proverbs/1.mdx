## 箴言的價值

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="箴言 10:1; 歷代志上 22:9; 歷代志上 28:5"> <span className="pl pl-1">以色列王大衛兒子所羅門的箴言：</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="箴言 7:4; 申命記 4:5–6; 提摩太後書 3:15–17"> <span className="pl pl-1">要使人曉得智慧和訓誨，</span><br /><span className="pl pl-1">分辨通達的言語，</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="箴言 2:1–9; 約伯記 22:22; 箴言 8:10–11"> <span className="pl pl-1">使人處事領受智慧、</span><br /><span className="pl pl-1">仁義、公平、正直的訓誨，</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="箴言 8:5; 箴言 8:17; 詩篇 119:9"> <span className="pl pl-1">使愚人靈明，</span><br /><span className="pl pl-1">使少年人有知識和謀略，</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="箴言 12:1; 箴言 9:9; 哥林多前書 10:15"> <span className="pl pl-1">使智慧人聽見，增長學問，</span><br /><span className="pl pl-1">使聰明人得着智謀，</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 78:2; 馬可福音 4:11; 詩篇 49:4"> <span className="pl pl-1">使人明白箴言和譬喻，</span><br /><span className="pl pl-1">懂得智慧人的言詞和謎語。</span></span>
</div>
</div>

## 給青年人的忠告

<div className="bt">
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="約伯記 28:28; 詩篇 111:10–1; 傳道書 12:13"> <span className="pl pl-1">敬畏耶和華是知識的開端；</span><br /><span className="pl pl-1">愚妄人藐視智慧和訓誨。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="箴言 6:20; 箴言 30:17; 箴言 5:1–2"> <span className="pl pl-1">我兒，要聽你父親的訓誨，</span><br /><span className="pl pl-1">不可離棄你母親的法則</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或譯：指教">a</a></sup><br /><span className="pl pl-1">；</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="但以理書 5:29; 箴言 4:9; 創世記 41:42"> <span className="pl pl-1">因為這要作你頭上的華冠，</span><br /><span className="pl pl-1">你項上的金鍊。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="以弗所書 5:11; 箴言 16:29; 詩篇 1:1"> <span className="pl pl-1">我兒，惡人若引誘你，</span><br /><span className="pl pl-1">你不可隨從。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="耶利米書 5:26; 箴言 1:18; 箴言 12:6"> <span className="pl pl-1">他們若說：你與我們同去，</span><br /><span className="pl pl-1">我們要埋伏流人之血，</span><br /><span className="pl pl-1">要蹲伏害無罪之人；</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 124:3; 詩篇 28:1; 羅馬書 3:13"> <span className="pl pl-1">我們好像陰間，把他們活活吞下；</span><br /><span className="pl pl-1">他們如同下坑的人，</span><br /><span className="pl pl-1">被我們囫圇吞了；</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="提摩太前書 6:9–10; 路加福音 12:15; 約伯記 24:2–3"> <span className="pl pl-1">我們必得各樣寶物，</span><br /><span className="pl pl-1">將所擄來的，裝滿房屋；</span><br /></span>
<span className="v" id="v14" data-v="14"> <span className="pl pl-1">你與我們大家同分，</span><br /><span className="pl pl-1">我們共用一個囊袋；</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 119:101; 詩篇 1:1; 箴言 4:14–15"> <span className="pl pl-1">我兒，不要與他們同行一道，</span><br /><span className="pl pl-1">禁止你腳走他們的路。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="以賽亞書 59:7; 箴言 6:18; 箴言 4:16"> <span className="pl pl-1">因為，他們的腳奔跑行惡；</span><br /><span className="pl pl-1">他們急速流人的血，</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="約伯記 35:11; 箴言 7:23; 耶利米書 8:7"> <span className="pl pl-1">好像飛鳥，</span><br /><span className="pl pl-1">網羅設在眼前仍不躲避。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 9:16; 以斯帖記 7:10; 箴言 5:22–23"> <span className="pl pl-1">這些人埋伏，是為自流己血；</span><br /><span className="pl pl-1">蹲伏，是為自害己命。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="箴言 15:27; 彼得後書 2:3; 雅各書 5:1–4"> <span className="pl pl-1">凡貪戀財利的，所行之路都是如此；</span><br /><span className="pl pl-1">這貪戀之心乃奪去得財者之命。</span></span>
</div>
</div>

## 智慧呼喚人

<div className="bt">
<div className="bp poetry">
<span className="v" id="v20" data-v="20" data-xref="箴言 9:3; 歌羅西書 2:3; 路加福音 11:49"> <span className="pl pl-1">智慧在街市上呼喊，</span><br /><span className="pl pl-1">在寬闊處發聲，</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="使徒行傳 5:20; 箴言 9:3; 馬太福音 13:2"> <span className="pl pl-1">在熱鬧街頭喊叫，</span><br /><span className="pl pl-1">在城門口，在城中發出言語，</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="箴言 1:29; 詩篇 1:1; 箴言 5:12"> <span className="pl pl-1">說：你們愚昧人喜愛愚昧，</span><br /><span className="pl pl-1">褻慢人喜歡褻慢，</span><br /><span className="pl pl-1">愚頑人恨惡知識，要到幾時呢？</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="使徒行傳 3:19; 以西結書 33:11; 以西結書 18:27–30"> <span className="pl pl-1">你們當因我的責備回轉；</span><br /><span className="pl pl-1">我要將我的靈澆灌你們，</span><br /><span className="pl pl-1">將我的話指示你們。</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="以賽亞書 65:12; 羅馬書 10:21; 耶利米書 7:13"> <span className="pl pl-1">我呼喚，你們不肯聽從；</span><br /><span className="pl pl-1">我伸手，無人理會；</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="詩篇 81:11; 路加福音 7:30; 箴言 1:30"> <span className="pl pl-1">反輕棄我一切的勸戒，</span><br /><span className="pl pl-1">不肯受我的責備。</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="詩篇 2:4; 箴言 10:24; 詩篇 37:13"> <span className="pl pl-1">你們遭災難，我就發笑；</span><br /><span className="pl pl-1">驚恐臨到你們，我必嗤笑。</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="箴言 3:25–26; 路加福音 21:34–35; 詩篇 58:9"> <span className="pl pl-1">驚恐臨到你們，好像狂風；</span><br /><span className="pl pl-1">災難來到，如同暴風；</span><br /><span className="pl pl-1">急難痛苦臨到你們身上。</span><br /></span>
<span className="v" id="v28" data-v="28" data-xref="彌迦書 3:4; 雅各書 4:3; 耶利米書 11:11"> <span className="pl pl-1">那時，你們必呼求我，我卻不答應，</span><br /><span className="pl pl-1">懇切地尋找我，卻尋不見。</span><br /></span>
<span className="v" id="v29" data-v="29" data-xref="箴言 1:22; 約伯記 21:14–15; 箴言 6:23"> <span className="pl pl-1">因為，你們恨惡知識，</span><br /><span className="pl pl-1">不喜愛敬畏耶和華，</span><br /></span>
<span className="v" id="v30" data-v="30" data-xref="詩篇 81:11; 箴言 1:25; 路加福音 14:18–20"> <span className="pl pl-1">不聽我的勸戒，</span><br /><span className="pl pl-1">藐視我一切的責備，</span><br /></span>
<span className="v" id="v31" data-v="31" data-xref="箴言 14:14; 耶利米書 6:19; 箴言 22:8"> <span className="pl pl-1">所以必吃自結的果子，</span><br /><span className="pl pl-1">充滿自設的計謀。</span><br /></span>
<span className="v" id="v32" data-v="32" data-xref="箴言 8:36; 耶利米書 2:19; 約翰福音 3:36"> <span className="pl pl-1">愚昧人背道，必殺己身；</span><br /><span className="pl pl-1">愚頑人安逸，必害己命。</span><br /></span>
<span className="v" id="v33" data-v="33" data-xref="詩篇 25:12–13; 詩篇 112:7–8; 以賽亞書 26:3"> <span className="pl pl-1">惟有聽從我的，必安然居住，</span><br /><span className="pl pl-1">得享安靜，不怕災禍。</span></span>

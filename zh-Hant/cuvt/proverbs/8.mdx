<div className="bp poetry">

<span className="v" id="v7" data-v="7" data-xref="詩篇 37:30; 約翰福音 8:14; 約翰福音 17:17"> <span className="pl pl-1">我的口要發出真理；</span><br /><span className="pl pl-1">我的嘴憎惡邪惡。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="約翰福音 7:46; 詩篇 12:6; 箴言 8:13"> <span className="pl pl-1">我口中的言語都是公義，</span><br /><span className="pl pl-1">並無彎曲乖僻。</span><br /></span>

<span className="v" id="v10" data-v="10" data-xref="箴言 2:4–5; 詩篇 119:127; 詩篇 119:72"> <span className="pl pl-1">你們當受我的教訓，不受白銀；</span><br /><span className="pl pl-1">寧得知識，勝過黃金。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v11" data-v="11" data-xref="箴言 3:14–15; 箴言 4:5–7; 箴言 16:16"> <span className="pl pl-1">因為智慧比珍珠</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或譯：紅寶石">a</a></sup><br /><span className="pl pl-1">更美；</span><br /><span className="pl pl-1">一切可喜愛的都不足與比較。</span><br /></span>

<span className="v" id="v13" data-v="13" data-xref="詩篇 97:10; 箴言 16:6; 撒母耳記上 2:3"> <span className="pl pl-1">敬畏耶和華在乎恨惡邪惡；</span><br /><span className="pl pl-1">那驕傲、狂妄，並惡道，</span><br /><span className="pl pl-1">以及乖謬的口，都為我所恨惡。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="傳道書 7:19; 以賽亞書 9:6; 以賽亞書 40:14"> <span className="pl pl-1">我有謀略和真知識；</span><br /><span className="pl pl-1">我乃聰明，我有能力。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="羅馬書 13:1; 但以理書 2:21; 馬太福音 28:18"> <span className="pl pl-1">帝王藉我坐國位；</span><br /><span className="pl pl-1">君王藉我定公平。</span><br /></span>
<span className="v" id="v16" data-v="16"> <span className="pl pl-1">王子和首領，</span><br /><span className="pl pl-1">世上一切的審判官，都是藉我掌權。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="約翰福音 14:23; 約翰福音 14:21; 詩篇 91:14"> <span className="pl pl-1">愛我的，我也愛他；</span><br /><span className="pl pl-1">懇切尋求我的，必尋得見。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="箴言 3:16; 馬太福音 6:33; 路加福音 16:11–12"> <span className="pl pl-1">豐富尊榮在我；</span><br /><span className="pl pl-1">恆久的財並公義也在我。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="箴言 3:14; 箴言 10:20; 傳道書 7:12"> <span className="pl pl-1">我的果實勝過黃金，強如精金；</span><br /><span className="pl pl-1">我的出產超乎高銀。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="申命記 5:32; 約翰福音 10:27–28; 詩篇 32:8"> <span className="pl pl-1">我在公義的道上走，</span><br /><span className="pl pl-1">在公平的路中行，</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="彼得前書 1:4; 箴言 24:4; 馬太福音 25:46"> <span className="pl pl-1">使愛我的，承受貨財，</span><br /><span className="pl pl-1">並充滿他們的府庫。</span></span>
</div>
<div className="bp poetry">

<span className="v" id="v28" data-v="28"> <span className="pl pl-1">上使穹蒼堅硬，</span><br /><span className="pl pl-1">下使淵源穩固，</span><br /></span>

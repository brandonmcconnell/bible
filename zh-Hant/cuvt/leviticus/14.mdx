## 皮膚病後潔淨的條例

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華曉諭摩西說：「</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 17:14; 路加福音 5:12–14; 馬可福音 1:40–44"> 長大痲瘋得潔淨的日子，其例乃是這樣：要帶他去見祭司；</span>
<span className="v" id="v3" data-v="3" data-xref="利未記 13:46; 路加福音 7:22; 路加福音 17:15–19"> 祭司要出到營外察看，若見他的大痲瘋痊癒了，</span>
<span className="v" id="v4" data-v="4" data-xref="民數記 19:6; 利未記 14:6; 希伯來書 9:19"> 就要吩咐人為那求潔淨的拿兩隻潔淨的活鳥和香柏木、朱紅色線，並牛膝草來。</span>
<span className="v" id="v5" data-v="5" data-xref="利未記 14:50; 希伯來書 2:14; 哥林多後書 5:1"> 祭司要吩咐用瓦器盛活水，把一隻鳥宰在上面。</span>
<span className="v" id="v6" data-v="6" data-xref="啟示錄 1:5; 撒迦利亞書 13:1; 腓立比書 2:9–11"> 至於那隻活鳥，祭司要把牠和香柏木、朱紅色線並牛膝草一同蘸於宰在活水上的鳥血中，</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀下 5:14; 以西結書 36:25; 以賽亞書 52:15"> 用以在那長大痲瘋求潔淨的人身上灑七次，就定他為潔淨，又把活鳥放在田野裏。</span>
<span className="v" id="v8" data-v="8" data-xref="利未記 11:25; 民數記 8:7; 彼得前書 3:21"> 求潔淨的人當洗衣服，剃去毛髮，用水洗澡，就潔淨了；然後可以進營，只是要在自己的帳棚外居住七天。</span>
<span className="v" id="v9" data-v="9" data-xref="民數記 6:9; 利未記 14:8; 民數記 8:7"> 第七天，再把頭上所有的頭髮與鬍鬚、眉毛，並全身的毛，都剃了；又要洗衣服，用水洗身，就潔淨了。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="利未記 2:1; 馬太福音 8:4; 路加福音 5:14"> 「第八天，他要取兩隻沒有殘疾的公羊羔和一隻沒有殘疾、一歲的母羊羔，又要把調油的細麵伊法十分之三為素祭，並油一羅革，一同取來。</span>
<span className="v" id="v11" data-v="11" data-xref="以弗所書 5:26–27; 出埃及記 29:1–4; 民數記 8:21"> 行潔淨之禮的祭司要將那求潔淨的人和這些東西安置在會幕門口、耶和華面前。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及記 29:24; 利未記 6:6–7; 利未記 8:27–29"> 祭司要取一隻公羊羔獻為贖愆祭，和那一羅革油一同作搖祭，在耶和華面前搖一搖；</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及記 29:11; 利未記 1:11; 利未記 4:24"> 把公羊羔宰於聖地，就是宰贖罪祭牲和燔祭牲之地。贖愆祭要歸祭司，與贖罪祭一樣，是至聖的。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及記 29:20; 利未記 8:23–24; 哥林多後書 7:1"> 祭司要取些贖愆祭牲的血，抹在求潔淨人的右耳垂上和右手的大拇指上，並右腳的大拇指上。</span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 45:7; 約翰福音 3:34; 約翰一書 2:20"> 祭司要從那一羅革油中取些倒在自己的左手掌裏，</span>
<span className="v" id="v16" data-v="16" data-xref="利未記 4:17; 哥林多前書 10:31; 利未記 4:6"> 把右手的一個指頭蘸在左手的油裏，在耶和華面前用指頭彈七次。</span>
<span className="v" id="v17" data-v="17" data-xref="彼得前書 1:2; 以西結書 36:27; 利未記 14:14"> 將手裏所剩的油抹在那求潔淨人的右耳垂上和右手的大拇指上，並右腳的大拇指上，就是抹在贖愆祭牲的血上。</span>
<span className="v" id="v18" data-v="18" data-xref="利未記 4:26; 哥林多後書 1:21–22; 以弗所書 1:17–18"> 祭司手裏所剩的油要抹在那求潔淨人的頭上，在耶和華面前為他贖罪。</span>
<span className="v" id="v19" data-v="19" data-xref="利未記 14:12; 利未記 5:1; 利未記 12:6–8"> 祭司要獻贖罪祭，為那本不潔淨、求潔淨的人贖罪；然後要宰燔祭牲，</span>
<span className="v" id="v20" data-v="20" data-xref="利未記 14:10; 以弗所書 5:2; 利未記 14:8"> 把燔祭和素祭獻在壇上，為他贖罪，他就潔淨了。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="利未記 5:7; 利未記 12:8; 箴言 17:5"> 「他若貧窮不能預備夠數，就要取一隻公羊羔作贖愆祭，可以搖一搖，為他贖罪；也要把調油的細麵伊法十分之一為素祭，和油一羅革一同取來；</span>
<span className="v" id="v22" data-v="22" data-xref="以西結書 7:16; 以賽亞書 59:11; 耶利米書 48:28"> 又照他的力量取兩隻斑鳩或是兩隻雛鴿，一隻作贖罪祭，一隻作燔祭。</span>
<span className="v" id="v23" data-v="23" data-xref="利未記 14:10–11"> 第八天，要為潔淨，把這些帶到會幕門口、耶和華面前，交給祭司。</span>
<span className="v" id="v24" data-v="24" data-xref="利未記 14:12; 利未記 14:10"> 祭司要把贖愆祭的羊羔和那一羅革油一同作搖祭，在耶和華面前搖一搖。</span>
<span className="v" id="v25" data-v="25" data-xref="傳道書 5:1; 詩篇 40:6; 利未記 14:14–20"> 要宰了贖愆祭的羊羔，取些贖愆祭牲的血，抹在那求潔淨人的右耳垂上和右手的大拇指上，並右腳的大拇指上。</span>
<span className="v" id="v26" data-v="26"> 祭司要把些油倒在自己的左手掌裏，</span>
<span className="v" id="v27" data-v="27"> 把左手裏的油，在耶和華面前，用右手的一個指頭彈七次，</span>
<span className="v" id="v28" data-v="28"> 又把手裏的油抹些在那求潔淨人的右耳垂上和右手的大拇指上，並右腳的大拇指上，就是抹贖愆祭之血的原處。</span>
<span className="v" id="v29" data-v="29" data-xref="利未記 14:18; 約翰一書 2:1–2; 出埃及記 30:15–16"> 祭司手裏所剩的油要抹在那求潔淨人的頭上，在耶和華面前為他贖罪。</span>
<span className="v" id="v30" data-v="30" data-xref="利未記 14:22; 羅馬書 8:3; 利未記 12:8"> 那人又要照他的力量獻上一隻斑鳩或是一隻雛鴿，</span>
<span className="v" id="v31" data-v="31" data-xref="利未記 14:18; 利未記 5:7"> 就是他所能辦的，一隻為贖罪祭，一隻為燔祭，與素祭一同獻上；祭司要在耶和華面前為他贖罪。</span>
<span className="v" id="v32" data-v="32" data-xref="利未記 14:10; 利未記 14:21; 馬太福音 11:5"> 這是那有大痲瘋災病的人、不能將關乎得潔淨之物預備夠數的條例。」</span>
</div>
</div>

## 處理房屋發霉的條例

<div className="bt">
<div className="bp">
<span className="v" id="v33" data-v="33"> 耶和華曉諭摩西、亞倫說：</span>
<span className="v" id="v34" data-v="34" data-xref="申命記 32:49; 創世記 17:8; 民數記 32:22"> 「你們到了我賜給你們為業的迦南地，我若使你們所得為業之地的房屋中有大痲瘋的災病，</span>
<span className="v" id="v35" data-v="35" data-xref="詩篇 91:10; 申命記 7:26; 撒迦利亞書 5:4"> 房主就要去告訴祭司說：『據我看，房屋中似乎有災病。』</span>
<span className="v" id="v36" data-v="36" data-xref="啟示錄 18:4; 希伯來書 12:15; 提摩太後書 2:17–18"> 祭司還沒有進去察看災病以前，就要吩咐人把房子騰空，免得房子裏所有的都成了不潔淨；然後祭司要進去察看房子。</span>
<span className="v" id="v37" data-v="37" data-xref="利未記 13:42; 利未記 13:3; 利未記 13:19–20"> 他要察看那災病，災病若在房子的牆上有發綠或發紅的凹斑紋，現象窪於牆，</span>
<span className="v" id="v38" data-v="38" data-xref="利未記 13:50"> 祭司就要出到房門外，把房子封鎖七天。</span>
<span className="v" id="v39" data-v="39" data-xref="利未記 13:36; 利未記 13:27; 利未記 13:22"> 第七天，祭司要再去察看，災病若在房子的牆上發散，</span>
<span className="v" id="v40" data-v="40" data-xref="啟示錄 2:20; 提多書 3:10; 哥林多前書 5:5–6"> 就要吩咐人把那有災病的石頭挖出來，扔在城外不潔淨之處；</span>
<span className="v" id="v41" data-v="41" data-xref="以賽亞書 65:4; 啟示錄 22:15; 馬太福音 24:51"> 也要叫人刮房內的四圍，所刮掉的灰泥要倒在城外不潔淨之處；</span>
<span className="v" id="v42" data-v="42" data-xref="提摩太後書 2:2; 提摩太前書 5:21–22; 歷代志下 17:7–9"> 又要用別的石頭代替那挖出來的石頭，要另用灰泥墁房子。</span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="耶利米書 6:28–30; 猶大書 1:12; 彼得後書 2:20"> 「他挖出石頭，刮了房子，墁了以後，災病若在房子裏又發現，</span>
<span className="v" id="v44" data-v="44" data-xref="利未記 13:51–52; 撒迦利亞書 5:4"> 祭司就要進去察看，災病若在房子裏發散，這就是房內蠶食的大痲瘋，是不潔淨。</span>
<span className="v" id="v45" data-v="45" data-xref="列王紀下 10:27; 馬太福音 24:2; 列王紀上 9:6–9"> 他就要拆毀房子，把石頭、木頭、灰泥都搬到城外不潔淨之處。</span>
<span className="v" id="v46" data-v="46" data-xref="民數記 19:21–22; 利未記 22:6; 利未記 11:28"> 在房子封鎖的時候，進去的人必不潔淨到晚上；</span>
<span className="v" id="v47" data-v="47" data-xref="利未記 14:8–9; 利未記 11:25"> 在房子裏躺着的必洗衣服；在房子裏吃飯的也必洗衣服。</span>
</div>
<div className="bp">
<span className="v" id="v48" data-v="48" data-xref="哥林多前書 6:11; 約伯記 5:18; 馬可福音 5:29"> 「房子墁了以後，祭司若進去察看，見災病在房內沒有發散，就要定房子為潔淨，因為災病已經消除。</span>
<span className="v" id="v49" data-v="49" data-xref="利未記 14:4"> 要為潔淨房子取兩隻鳥和香柏木、朱紅色線並牛膝草，</span>
<span className="v" id="v50" data-v="50"> 用瓦器盛活水，把一隻鳥宰在上面，</span>
<span className="v" id="v51" data-v="51" data-xref="詩篇 51:7"> 把香柏木、牛膝草、朱紅色線，並那活鳥，都蘸在被宰的鳥血中與活水中，用以灑房子七次。</span>
<span className="v" id="v52" data-v="52"> 要用鳥血、活水、活鳥、香柏木、牛膝草，並朱紅色線，潔淨那房子。</span>
<span className="v" id="v53" data-v="53" data-xref="利未記 14:20; 利未記 14:7"> 但要把活鳥放在城外田野裏。這樣潔淨房子<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是為房子贖罪">a</a></sup>，房子就潔淨了。」</span>
</div>
<div className="bp">
<span className="v" id="v54" data-v="54" data-xref="利未記 15:32; 利未記 14:32; 利未記 6:9"> 這是為各類大痲瘋的災病和頭疥，</span>
<span className="v" id="v55" data-v="55" data-xref="利未記 13:47–59"> 並衣服與房子的大痲瘋，</span>
<span className="v" id="v56" data-v="56" data-xref="利未記 13:2"> 以及癤子、癬、火斑所立的條例，</span>
<span className="v" id="v57" data-v="57" data-xref="利未記 10:10; 以西結書 44:23; 耶利米書 15:19"> 指明何時為潔淨，何時為不潔淨。這是大痲瘋的條例。</span>
</div>

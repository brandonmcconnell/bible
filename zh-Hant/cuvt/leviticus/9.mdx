## 亞倫獻祭

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="馬太福音 28:1; 以西結書 43:26–27; 利未記 15:14"> 到了第八天，摩西召了亞倫和他兒子，並以色列的眾長老來，</span>
<span className="v" id="v2" data-v="2" data-xref="利未記 4:3; 希伯來書 10:10–14; 利未記 8:14"> 對亞倫說：「你當取牛群中的一隻公牛犢作贖罪祭，一隻公綿羊作燔祭，都要沒有殘疾的，獻在耶和華面前。</span>
<span className="v" id="v3" data-v="3" data-xref="以斯拉記 6:17; 啟示錄 5:9; 提多書 2:14"> 你也要對以色列人說：『你們當取一隻公山羊作贖罪祭，又取一隻牛犢和一隻綿羊羔，都要一歲、沒有殘疾的，作燔祭，</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及記 29:43; 以西結書 43:2; 利未記 9:23"> 又取一隻公牛，一隻公綿羊作平安祭，獻在耶和華面前，並取調油的素祭，因為今天耶和華要向你們顯現。』」</span>
<span className="v" id="v5" data-v="5" data-xref="歷代志下 5:2–3; 出埃及記 19:17; 尼希米記 8:1"> 於是他們把摩西所吩咐的，帶到會幕前；全會眾都近前來，站在耶和華面前。</span>
<span className="v" id="v6" data-v="6" data-xref="利未記 9:23; 以西結書 43:2; 出埃及記 24:16"> 摩西說：「這是耶和華吩咐你們所當行的；耶和華的榮光就要向你們顯現。」</span>
<span className="v" id="v7" data-v="7" data-xref="希伯來書 5:3; 希伯來書 5:1; 利未記 4:3"> 摩西對亞倫說：「你就近壇前，獻你的贖罪祭和燔祭，為自己與百姓贖罪，又獻上百姓的供物，為他們贖罪，都照耶和華所吩咐的。」</span>
<span className="v" id="v8" data-v="8" data-xref="利未記 4:1–12; 利未記 1:4–5; 利未記 4:29"> 於是，亞倫就近壇前，宰了為自己作贖罪祭的牛犢。</span>
<span className="v" id="v9" data-v="9" data-xref="利未記 4:6–7; 利未記 8:15; 利未記 4:25"> 亞倫的兒子把血奉給他，他就把指頭蘸在血中，抹在壇的四角上，又把血倒在壇腳那裏。</span>
<span className="v" id="v10" data-v="10" data-xref="利未記 8:16–17; 箴言 23:26; 利未記 3:9–11"> 惟有贖罪祭的脂油和腰子，並肝上取的網子，都燒在壇上，是照耶和華所吩咐摩西的；</span>
<span className="v" id="v11" data-v="11" data-xref="利未記 8:17; 利未記 4:11–12; 利未記 16:27–28"> 又用火將肉和皮燒在營外。</span>
<span className="v" id="v12" data-v="12" data-xref="以弗所書 5:2; 以弗所書 5:25–27; 利未記 1:1–17"> 亞倫宰了燔祭牲，他兒子把血遞給他，他就灑在壇的周圍，</span>
<span className="v" id="v13" data-v="13"> 又把燔祭一塊一塊地、連頭遞給他，他都燒在壇上；</span>
<span className="v" id="v14" data-v="14" data-xref="利未記 8:21"> 又洗了臟腑和腿，燒在壇上的燔祭上。</span>
<span className="v" id="v15" data-v="15" data-xref="利未記 4:27–31; 希伯來書 5:3; 利未記 9:3"> 他奉上百姓的供物，把那給百姓作贖罪祭的公山羊宰了，為罪獻上，和先獻的一樣；</span>
<span className="v" id="v16" data-v="16" data-xref="利未記 9:12–14; 利未記 8:18–21; 希伯來書 10:1–22"> 也奉上燔祭，照例而獻。</span>
<span className="v" id="v17" data-v="17" data-xref="利未記 2:1–2; 約翰福音 6:53; 利未記 9:1"> 他又奉上素祭，從其中取一滿把，燒在壇上；這是在早晨的燔祭以外。</span>
<span className="v" id="v18" data-v="18" data-xref="歌羅西書 1:20; 羅馬書 5:1; 以弗所書 2:14–17"> 亞倫宰了那給百姓作平安祭的公牛和公綿羊。他兒子把血遞給他，他就灑在壇的周圍；</span>
<span className="v" id="v19" data-v="19" data-xref="利未記 3:16; 利未記 9:10; 利未記 3:9"> 又把公牛和公綿羊的脂油、肥尾巴，並蓋臟的脂油與腰子，和肝上的網子，都遞給他；</span>
<span className="v" id="v20" data-v="20" data-xref="利未記 3:14–17; 利未記 7:29–34"> 把脂油放在胸上，他就把脂油燒在壇上。</span>
<span className="v" id="v21" data-v="21" data-xref="利未記 7:30–34; 利未記 7:24; 出埃及記 29:24"> 胸和右腿，亞倫當作搖祭，在耶和華面前搖一搖，都是照摩西所吩咐的。</span>
<span className="v" id="v22" data-v="22" data-xref="申命記 21:5; 路加福音 24:50; 民數記 6:23–27"> 亞倫向百姓舉手，為他們祝福。他獻了贖罪祭、燔祭、平安祭就下來了。</span>
<span className="v" id="v23" data-v="23" data-xref="利未記 9:6; 民數記 16:19; 路加福音 1:21–22"> 摩西、亞倫進入會幕，又出來為百姓祝福，耶和華的榮光就向眾民顯現。</span>
<span className="v" id="v24" data-v="24" data-xref="士師記 6:21; 列王紀上 18:38–39; 歷代志上 21:26"> 有火從耶和華面前出來，在壇上燒盡燔祭和脂油；眾民一見，就都歡呼，俯伏在地。</span>

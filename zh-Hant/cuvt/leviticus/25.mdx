## 安息年

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民數記 1:1; 加拉太書 4:24–25; 出埃及記 19:1"> 耶和華在西奈山對摩西說：</span>
<span className="v" id="v2" data-v="2" data-xref="歷代志下 36:21; 利未記 26:34–35; 出埃及記 23:10"> 「你曉諭以色列人說：你們到了我所賜你們那地的時候，地就要向耶和華守安息。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 23:10"> 六年要耕種田地，也要修理葡萄園，收藏地的出產。</span>
<span className="v" id="v4" data-v="4" data-xref="歷代志下 36:21; 利未記 25:20–23; 出埃及記 23:10–11"> 第七年，地要守聖安息，就是向耶和華守的安息，不可耕種田地，也不可修理葡萄園。</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀下 19:29; 以賽亞書 37:30"> 遺落自長的莊稼不可收割；沒有修理的葡萄樹也不可摘取葡萄。這年，地要守聖安息。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行傳 2:44; 出埃及記 23:11; 使徒行傳 4:34–35"> 地在安息年所出的，要給你和你的僕人、婢女、雇工人，並寄居的外人當食物。</span>
<span className="v" id="v7" data-v="7"> 這年的土產也要給你的牲畜和你地上的走獸當食物。」</span>
</div>
</div>

## 禧年

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="利未記 23:15; 創世記 2:2"> 「你要計算七個安息年，就是七七年。這便為你成了七個安息年，共是四十九年。</span>
<span className="v" id="v9" data-v="9" data-xref="利未記 23:24; 利未記 23:27; 帖撒羅尼迦前書 1:8"> 當年七月初十日，你要大發角聲；這日就是贖罪日，要在遍地發出角聲。</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米書 34:8; 以賽亞書 63:4; 彼得前書 2:16"> 第五十年，你們要當作聖年，在遍地給一切的居民宣告自由。這年必為你們的禧年，各人要歸自己的產業，各歸本家。</span>
<span className="v" id="v11" data-v="11" data-xref="利未記 27:17; 利未記 25:4–5"> 第五十年要作為你們的禧年。這年不可耕種；地中自長的，不可收割；沒有修理的葡萄樹也不可摘取葡萄。</span>
<span className="v" id="v12" data-v="12" data-xref="利未記 25:6–7"> 因為這是禧年，你們要當作聖年，吃地中自出的土產。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="利未記 25:10; 利未記 27:17–24; 民數記 36:4"> 「這禧年，你們各人要歸自己的地業。</span>
<span className="v" id="v14" data-v="14" data-xref="利未記 19:13; 利未記 25:17; 撒母耳記上 12:3–4"> 你若賣甚麼給鄰舍，或是從鄰舍的手中買甚麼，彼此不可虧負。</span>
<span className="v" id="v15" data-v="15" data-xref="利未記 27:18–23; 腓立比書 4:5"> 你要按禧年以後的年數向鄰舍買；他也要按年數的收成賣給你。</span>
<span className="v" id="v16" data-v="16" data-xref="利未記 25:27; 利未記 25:51"> 年歲若多，要照數加添價值；年歲若少，要照數減去價值，因為他照收成的數目賣給你。</span>
<span className="v" id="v17" data-v="17" data-xref="利未記 19:14; 利未記 19:32; 利未記 25:43"> 你們彼此不可虧負，只要敬畏你們的上帝，因為我是耶和華－你們的上帝。」</span>
</div>
</div>

## 安息年的問題

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="耶利米書 23:6; 申命記 12:10; 箴言 1:33"> 「我的律例，你們要遵行，我的典章，你們要謹守，就可以在那地上安然居住。</span>
<span className="v" id="v19" data-v="19" data-xref="約珥書 2:26; 詩篇 85:12; 利未記 26:5"> 地必出土產，你們就要吃飽，在那地上安然居住。</span>
<span className="v" id="v20" data-v="20" data-xref="利未記 25:4; 路加福音 12:29; 民數記 11:4"> 你們若說：『這第七年我們不耕種，也不收藏土產，吃甚麼呢？』</span>
<span className="v" id="v21" data-v="21" data-xref="申命記 28:8; 箴言 10:22; 哥林多後書 9:10"> 我必在第六年將我所命的福賜給你們，地便生三年的土產。</span>
<span className="v" id="v22" data-v="22" data-xref="列王紀下 19:29; 利未記 26:10; 以賽亞書 37:30"> 第八年，你們要耕種，也要吃陳糧，等到第九年出產收來的時候，你們還吃陳糧。」</span>
</div>
</div>

## 贖房地產的條例

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="彼得前書 2:11; 詩篇 39:12; 以西結書 48:14"> 「地不可永賣，因為地是我的；你們在我面前是客旅，是寄居的。</span>
<span className="v" id="v24" data-v="24" data-xref="以弗所書 1:7; 利未記 25:51–53; 利未記 25:27"> 在你們所得為業的全地，也要准人將地贖回。</span>
<span className="v" id="v25" data-v="25" data-xref="路得記 2:20; 耶利米書 32:7–8; 路得記 3:12"> 你的弟兄<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="弟兄是指本國人說；下同">a</a></sup>若漸漸窮乏，賣了幾分地業，他至近的親屬就要來把弟兄所賣的贖回。</span>
<span className="v" id="v26" data-v="26" data-xref="利未記 5:7"> 若沒有能給他贖回的，他自己漸漸富足，能夠贖回，</span>
<span className="v" id="v27" data-v="27"> 就要算出賣地的年數，把餘剩年數的價值還那買主，自己便歸回自己的地業。</span>
<span className="v" id="v28" data-v="28" data-xref="以賽亞書 35:9–10; 利未記 25:10; 彼得前書 1:4–5"> 倘若不能為自己得回所賣的，仍要存在買主的手裏直到禧年；到了禧年，地業要出買主的手，自己便歸回自己的地業。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29"> 「人若賣城內的住宅，賣了以後，一年之內可以贖回；在一整年，必有贖回的權柄。</span>
<span className="v" id="v30" data-v="30"> 若在一整年之內不贖回，這城內的房屋就定准永歸買主，世世代代為業；在禧年也不得出買主的手。</span>
<span className="v" id="v31" data-v="31" data-xref="詩篇 49:7–8"> 但房屋在無城牆的村莊裏，要看如鄉下的田地一樣，可以贖回；到了禧年，都要出買主的手。</span>
<span className="v" id="v32" data-v="32" data-xref="約書亞記 21:1–45; 民數記 35:1–8"> 然而利未人所得為業的城邑，其中的房屋，利未人可以隨時贖回。</span>
<span className="v" id="v33" data-v="33" data-xref="民數記 18:20–24; 申命記 18:1–2"> 若是一個利未人不將所賣的房屋贖回，是在所得為業的城內，到了禧年就要出買主的手，因為利未人城邑的房屋是他們在以色列人中的產業。</span>
<span className="v" id="v34" data-v="34" data-xref="利未記 25:23; 使徒行傳 4:36–37; 民數記 35:2–5"> 只是他們各城郊野之地不可賣，因為是他們永遠的產業。」</span>
</div>
</div>

## 借貸給窮人的條例

<div className="bt">
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="申命記 15:7–8; 使徒行傳 11:29; 利未記 25:25"> 「你的弟兄在你那裏若漸漸貧窮，手中缺乏，你就要幫補他，使他與你同住，像外人和寄居的一樣。</span>
<span className="v" id="v36" data-v="36" data-xref="出埃及記 22:25; 申命記 23:19–20; 以西結書 18:8"> 不可向他取利，也不可向他多要；只要敬畏你的上帝，使你的弟兄與你同住。</span>
<span className="v" id="v37" data-v="37"> 你借錢給他，不可向他取利；借糧給他，也不可向他多要。</span>
<span className="v" id="v38" data-v="38" data-xref="利未記 11:45; 民數記 15:41; 出埃及記 20:2"> 我是耶和華－你們的上帝，曾領你們從埃及地出來，為要把迦南地賜給你們，要作你們的上帝。」</span>
</div>
</div>

## 贖回奴僕的條例

<div className="bt">
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="出埃及記 21:2; 列王紀上 9:22; 列王紀下 4:1"> 「你的弟兄若在你那裏漸漸窮乏，將自己賣給你，不可叫他像奴僕服事你。</span>
<span className="v" id="v40" data-v="40" data-xref="出埃及記 21:2–3"> 他要在你那裏像雇工人和寄居的一樣，要服事你直到禧年。</span>
<span className="v" id="v41" data-v="41" data-xref="利未記 25:28; 出埃及記 21:3; 約翰福音 8:32"> 到了禧年，他和他兒女要離開你，一同出去歸回本家，到他祖宗的地業那裏去。</span>
<span className="v" id="v42" data-v="42" data-xref="利未記 25:55; 羅馬書 6:22; 哥林多前書 7:21–23"> 因為他們是我的僕人，是我從埃及地領出來的，不可賣為奴僕。</span>
<span className="v" id="v43" data-v="43" data-xref="歌羅西書 4:1; 利未記 25:46; 出埃及記 1:13–14"> 不可嚴嚴地轄管他，只要敬畏你的上帝。</span>
<span className="v" id="v44" data-v="44" data-xref="出埃及記 12:44; 詩篇 2:8–9; 以賽亞書 14:1–2"> 至於你的奴僕、婢女，可以從你四圍的國中買。</span>
<span className="v" id="v45" data-v="45" data-xref="以賽亞書 56:3–6"> 並且那寄居在你們中間的外人和他們的家屬，在你們地上所生的，你們也可以從其中買人；他們要作你們的產業。</span>
<span className="v" id="v46" data-v="46" data-xref="以賽亞書 14:2; 利未記 25:43"> 你們要將他們遺留給你們的子孫為產業，要永遠從他們中間揀出奴僕；只是你們的弟兄以色列人，你們不可嚴嚴地轄管。</span>
</div>
<div className="bp">
<span className="v" id="v47" data-v="47" data-xref="雅各書 2:5; 利未記 25:26; 撒母耳記上 2:7–8"> 「住在你那裏的外人，或是寄居的，若漸漸富足，你的弟兄卻漸漸窮乏，將自己賣給那外人，或是寄居的，或是外人的宗族，</span>
<span className="v" id="v48" data-v="48" data-xref="尼希米記 5:5; 希伯來書 2:11–13; 利未記 25:35"> 賣了以後，可以將他贖回。無論是他的弟兄，</span>
<span className="v" id="v49" data-v="49" data-xref="利未記 25:26"> 或伯叔、伯叔的兒子，本家的近支，都可以贖他。他自己若漸漸富足，也可以自贖。</span>
<span className="v" id="v50" data-v="50" data-xref="以賽亞書 16:14; 以賽亞書 21:16; 利未記 25:53"> 他要和買主計算，從賣自己的那年起，算到禧年；所賣的價值照着年數多少，好像工人每年的工價。</span>
<span className="v" id="v51" data-v="51"> 若缺少的年數多，就要按着年數從買價中償還他的贖價。</span>
<span className="v" id="v52" data-v="52"> 若到禧年只缺少幾年，就要按着年數和買主計算，償還他的贖價。</span>
<span className="v" id="v53" data-v="53" data-xref="利未記 25:46; 利未記 25:43"> 他和買主同住，要像每年雇的工人，買主不可嚴嚴地轄管他。</span>
<span className="v" id="v54" data-v="54" data-xref="出埃及記 21:2–3; 利未記 25:40–41; 以賽亞書 49:9"> 他若不這樣被贖，到了禧年，要和他的兒女一同出去。</span>
<span className="v" id="v55" data-v="55" data-xref="利未記 25:42; 以賽亞書 43:3; 出埃及記 13:3"> 因為以色列人都是我的僕人，是我從埃及地領出來的。我是耶和華－你們的上帝。」</span>
</div>
</div>

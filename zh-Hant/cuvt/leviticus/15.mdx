## 漏症患者潔淨的條例

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="阿摩司書 3:7; 利未記 13:1; 利未記 11:1"> 耶和華對摩西、亞倫說：</span>
<span className="v" id="v2" data-v="2" data-xref="民數記 5:2; 撒母耳記下 3:29; 利未記 22:4"> 「你們曉諭以色列人說：人若身患漏症，他因這漏症就不潔淨了。</span>
<span className="v" id="v3" data-v="3" data-xref="以西結書 23:20; 以西結書 16:26; 利未記 12:3"> 他患漏症，無論是下流的，是止住的，都是不潔淨。</span>
<span className="v" id="v4" data-v="4" data-xref="提多書 1:15; 以弗所書 5:11; 哥林多前書 15:33"> 他所躺的床都為不潔淨，所坐的物也為不潔淨。</span>
<span className="v" id="v5" data-v="5" data-xref="利未記 11:25; 利未記 16:26; 利未記 17:15"> 凡摸那床的，必不潔淨到晚上，並要洗衣服，用水洗澡。</span>
<span className="v" id="v6" data-v="6" data-xref="雅各書 4:8; 以賽亞書 1:16"> 那坐患漏症人所坐之物的，必不潔淨到晚上，並要洗衣服，用水洗澡。</span>
<span className="v" id="v7" data-v="7"> 那摸患漏症人身體的，必不潔淨到晚上，並要洗衣服，用水洗澡。</span>
<span className="v" id="v8" data-v="8" data-xref="猶大書 1:4; 彼得後書 2:1–3; 以賽亞書 1:16"> 若患漏症人吐在潔淨的人身上，那人必不潔淨到晚上，並要洗衣服，用水洗澡。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 31:34"> 患漏症人所騎的鞍子也為不潔淨。</span>
<span className="v" id="v10" data-v="10" data-xref="雅各書 4:8; 詩篇 26:6; 利未記 15:8"> 凡摸了他身下之物的，必不潔淨到晚上；拿了那物的，必不潔淨到晚上，並要洗衣服，用水洗澡。</span>
<span className="v" id="v11" data-v="11"> 患漏症的人沒有用水涮手，無論摸了誰，誰必不潔淨到晚上，並要洗衣服，用水洗澡。</span>
<span className="v" id="v12" data-v="12" data-xref="利未記 6:28; 利未記 11:32–33; 哥林多後書 5:1"> 患漏症人所摸的瓦器就必打破；所摸的一切木器也必用水涮洗。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="利未記 14:8; 利未記 8:33; 利未記 15:28"> 「患漏症的人痊癒了，就要為潔淨自己計算七天，也必洗衣服，用活水洗身，就潔淨了。</span>
<span className="v" id="v14" data-v="14" data-xref="利未記 12:8; 利未記 12:6; 希伯來書 10:10"> 第八天，要取兩隻斑鳩或是兩隻雛鴿，來到會幕門口、耶和華面前，把鳥交給祭司。</span>
<span className="v" id="v15" data-v="15" data-xref="利未記 14:30–31; 利未記 4:26; 馬太福音 3:17"> 祭司要獻上一隻為贖罪祭，一隻為燔祭；因那人患的漏症，祭司要在耶和華面前為他贖罪。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="申命記 23:10–11; 利未記 22:4; 利未記 15:5"> 「人若夢遺，他必不潔淨到晚上，並要用水洗全身。</span>
<span className="v" id="v17" data-v="17"> 無論是衣服是皮子，被精所染，必不潔淨到晚上，並要用水洗。</span>
<span className="v" id="v18" data-v="18" data-xref="利未記 15:5; 帖撒羅尼迦前書 4:3–5; 哥林多前書 6:12"> 若男女交合，兩個人必不潔淨到晚上，並要用水洗澡。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="利未記 12:2; 馬太福音 15:19; 馬可福音 5:25"> 「女人行經，必污穢七天；凡摸她的，必不潔淨到晚上。</span>
<span className="v" id="v20" data-v="20" data-xref="利未記 15:4–9; 箴言 2:16–19; 箴言 6:35"> 女人在污穢之中，凡她所躺的物件都為不潔淨，所坐的物件也都不潔淨。</span>
<span className="v" id="v21" data-v="21" data-xref="啟示錄 7:14; 哥林多後書 7:1; 以賽亞書 22:14"> 凡摸她床的，必不潔淨到晚上，並要洗衣服，用水洗澡。</span>
<span className="v" id="v22" data-v="22"> 凡摸她所坐甚麼物件的，必不潔淨到晚上，並要洗衣服，用水洗澡。</span>
<span className="v" id="v23" data-v="23"> 在女人的床上，或在她坐的物上，若有別的物件，人一摸了，必不潔淨到晚上。</span>
<span className="v" id="v24" data-v="24" data-xref="利未記 20:18; 彼得前書 2:11; 利未記 18:19"> 男人若與那女人同房，染了她的污穢，就要七天不潔淨；所躺的床也為不潔淨。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="馬可福音 5:25; 馬太福音 9:20; 路加福音 8:43"> 「女人若在經期以外患多日的血漏，或是經期過長，有了漏症，她就因這漏症不潔淨，與她在經期不潔淨一樣。</span>
<span className="v" id="v26" data-v="26"> 她在患漏症的日子所躺的床、所坐的物都要看為不潔淨，與她月經的時候一樣。</span>
<span className="v" id="v27" data-v="27" data-xref="利未記 15:21; 希伯來書 10:22; 利未記 17:15–16"> 凡摸這些物件的，就為不潔淨，必不潔淨到晚上，並要洗衣服，用水洗澡。</span>
<span className="v" id="v28" data-v="28" data-xref="利未記 15:13–15; 加拉太書 3:13; 以弗所書 1:6–7"> 女人的漏症若好了，就要計算七天，然後才為潔淨。</span>
<span className="v" id="v29" data-v="29"> 第八天，要取兩隻斑鳩或是兩隻雛鴿，帶到會幕門口給祭司。</span>
<span className="v" id="v30" data-v="30"> 祭司要獻一隻為贖罪祭，一隻為燔祭；因那人血漏不潔，祭司要在耶和華面前為她贖罪。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="民數記 19:20; 民數記 19:13; 以西結書 5:11"> 「你們要這樣使以色列人與他們的污穢隔絕，免得他們玷污我的帳幕，就因自己的污穢死亡。」</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="利未記 11:46; 利未記 13:59; 民數記 6:13"> 這是患漏症和夢遺而不潔淨的，</span>
<span className="v" id="v33" data-v="33" data-xref="利未記 15:19; 利未記 20:18; 利未記 15:24–25"> 並有月經病的和患漏症的，無論男女，並人與不潔淨女人同房的條例。</span>
</div>
</div>

<span className="v" id="v1" data-v="1"> 耶和華曉諭摩西說：</span>
<span className="v" id="v2" data-v="2" data-xref="歌羅西書 3:9; 使徒行傳 5:4; 利未記 5:15"> 「若有人犯罪，干犯耶和華，在鄰舍交付他的物上，或是在交易上行了詭詐，或是搶奪人的財物，或是欺壓鄰舍，</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 23:4; 利未記 19:12; 出埃及記 22:9–11"> 或是在撿了遺失的物上行了詭詐，說謊起誓，在這一切的事上犯了甚麼罪；</span>
<span className="v" id="v4" data-v="4" data-xref="以西結書 18:18; 阿摩司書 3:10; 利未記 5:3–4"> 他既犯了罪，有了過犯，就要歸還他所搶奪的，或是因欺壓所得的，或是人交付他的，或是人遺失他所撿的物，</span>
<span className="v" id="v5" data-v="5" data-xref="利未記 5:16; 路加福音 19:8; 民數記 5:7–8"> 或是他因甚麼物起了假誓，就要如數歸還，另外加上五分之一，在查出他有罪的日子要交還本主。</span>
<span className="v" id="v6" data-v="6" data-xref="利未記 5:15; 利未記 5:18; 以賽亞書 53:10–11"> 也要照你所估定的價，把贖愆祭牲－就是羊群中一隻沒有殘疾的公綿羊－牽到耶和華面前，給祭司為贖愆祭。</span>
<span className="v" id="v7" data-v="7" data-xref="利未記 4:26; 約翰一書 1:9; 約翰一書 2:1–2"> 祭司要在耶和華面前為他贖罪；他無論行了甚麼事，使他有了罪，都必蒙赦免。」</span>
</div>

## 祭司獻燔祭的責任

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8"> 耶和華曉諭摩西說：</span>
<span className="v" id="v9" data-v="9" data-xref="利未記 6:12–13; 民數記 28:3; 出埃及記 29:38–42"> 「你要吩咐亞倫和他的子孫說，燔祭的條例乃是這樣：燔祭要放在壇的柴上，從晚上到天亮，壇上的火要常常燒着。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及記 28:39–43; 利未記 16:4; 利未記 1:13"> 祭司要穿上細麻布衣服，又要把細麻布褲子穿在身上，把壇上所燒的燔祭灰收起來，倒在壇的旁邊；</span>
<span className="v" id="v11" data-v="11" data-xref="利未記 4:12; 以西結書 44:19; 希伯來書 13:11–13"> 隨後要脫去這衣服，穿上別的衣服，把灰拿到營外潔淨之處。</span>
<span className="v" id="v12" data-v="12" data-xref="利未記 9:24; 出埃及記 29:38–42; 尼希米記 13:31"> 壇上的火要在其上常常燒着，不可熄滅。祭司要每日早晨在上面燒柴，並要把燔祭擺在壇上，在其上燒平安祭牲的脂油。</span>
<span className="v" id="v13" data-v="13"> 在壇上必有常常燒着的火，不可熄滅。」</span>
</div>
</div>

## 祭司獻素祭的責任

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="民數記 15:4; 利未記 2:1–2; 約翰福音 6:32"> 「素祭的條例乃是這樣：亞倫的子孫要在壇前把這祭獻在耶和華面前。</span>
<span className="v" id="v15" data-v="15" data-xref="利未記 2:2; 利未記 2:9"> 祭司要從其中－就是從素祭的細麵中－取出自己的一把，又要取些油和素祭上所有的乳香，燒在壇上，奉給耶和華為馨香素祭的紀念。</span>
<span className="v" id="v16" data-v="16" data-xref="以西結書 44:29; 利未記 2:3; 利未記 10:12–13"> 所剩下的，亞倫和他子孫要吃，必在聖處不帶酵而吃，要在會幕的院子裏吃。</span>
<span className="v" id="v17" data-v="17" data-xref="利未記 2:3; 利未記 2:11; 民數記 18:9–10"> 烤的時候不可攙酵。這是從所獻給我的火祭中賜給他們的分，是至聖的，和贖罪祭並贖愆祭一樣。</span>
<span className="v" id="v18" data-v="18" data-xref="利未記 6:29; 民數記 18:10; 哈該書 2:12–14"> 凡獻給耶和華的火祭，亞倫子孫中的男丁都要吃這一分，直到萬代，作他們永得的分。摸這些祭物的，都要成為聖。」</span>
<span className="v" id="v19" data-v="19"> 耶和華曉諭摩西說：</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及記 29:2; 出埃及記 16:36; 利未記 2:1–16"> 「當亞倫受膏的日子，他和他子孫所要獻給耶和華的供物，就是細麵伊法十分之一，為常獻的素祭：早晨一半，晚上一半。</span>
<span className="v" id="v21" data-v="21" data-xref="利未記 2:5; 利未記 7:9; 歷代志上 9:31"> 要在鐵鏊上用油調和做成，調勻了，你就拿進來；烤好了分成塊子，獻給耶和華為馨香的素祭。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及記 29:22–25; 以賽亞書 53:10; 利未記 8:21"> 亞倫的子孫中，接續他為受膏的祭司，要把這素祭獻上，要全燒給耶和華。這是永遠的定例。</span>
<span className="v" id="v23" data-v="23" data-xref="利未記 2:10; 利未記 6:16–17"> 祭司的素祭都要燒了，卻不可吃。」</span>
</div>
</div>

## 祭司獻贖罪祭的責任

<div className="bt">
<div className="bp">
<span className="v" id="v24" data-v="24"> 耶和華曉諭摩西說：</span>
<span className="v" id="v25" data-v="25" data-xref="利未記 4:24; 利未記 1:11; 利未記 1:3"> 「你對亞倫和他的子孫說，贖罪祭的條例乃是這樣：要在耶和華面前、宰燔祭牲的地方宰贖罪祭牲；這是至聖的。</span>
<span className="v" id="v26" data-v="26" data-xref="利未記 10:17–18; 以西結書 44:28–29; 何西阿書 4:8"> 為贖罪獻這祭的祭司要吃，要在聖處，就是在會幕的院子裏吃。</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及記 29:37; 哈該書 2:12; 哥林多後書 7:1"> 凡摸這祭肉的要成為聖；這祭牲的血若彈在甚麼衣服上，所彈的那一件要在聖處洗淨。</span>
<span className="v" id="v28" data-v="28" data-xref="利未記 11:33; 利未記 15:12; 希伯來書 9:9–10"> 惟有煮祭物的瓦器要打碎；若是煮在銅器裏，這銅器要擦磨，在水中涮淨。</span>
<span className="v" id="v29" data-v="29" data-xref="利未記 6:25; 利未記 6:17–18; 民數記 18:10"> 凡祭司中的男丁都可以吃；這是至聖的。</span>
<span className="v" id="v30" data-v="30" data-xref="利未記 10:18; 利未記 16:27–28; 希伯來書 13:11"> 凡贖罪祭，若將血帶進會幕在聖所贖罪，那肉都不可吃，必用火焚燒。」</span>
</div>
</div>

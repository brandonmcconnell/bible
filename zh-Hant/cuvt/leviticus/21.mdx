## 祭司聖潔的條例

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西結書 44:25; 利未記 21:11; 利未記 10:6–7"> 耶和華對摩西說：「你告訴亞倫子孫作祭司的說：祭司不可為民中的死人沾染自己，</span>
<span className="v" id="v2" data-v="2" data-xref="帖撒羅尼迦前書 4:13; 利未記 18:6"> 除非為他骨肉之親的父母、兒女、弟兄，</span>
<span className="v" id="v3" data-v="3"> 和未曾出嫁、作處女的姊妹，才可以沾染自己。</span>
<span className="v" id="v4" data-v="4" data-xref="以西結書 24:16–17"> 祭司既在民中為首，就不可從俗沾染自己。</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 14:1; 以西結書 44:20; 利未記 19:27–28"> 不可使頭光禿；不可剃除鬍鬚的周圍，也不可用刀劃身。</span>
<span className="v" id="v6" data-v="6" data-xref="利未記 3:11; 利未記 18:21; 彼得前書 2:9"> 要歸上帝為聖，不可褻瀆上帝的名；因為耶和華的火祭，就是上帝的食物，是他們獻的，所以他們要成為聖。</span>
<span className="v" id="v7" data-v="7" data-xref="利未記 21:13–14; 以西結書 44:22; 利未記 21:8"> 不可娶妓女或被污的女人為妻，也不可娶被休的婦人為妻，因為祭司是歸上帝為聖。</span>
<span className="v" id="v8" data-v="8" data-xref="利未記 20:7–8; 利未記 19:2; 利未記 11:44–45"> 所以你要使他成聖，因為他奉獻你上帝的食物；你要以他為聖，因為我－使你們成聖的耶和華－是聖的。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 38:24; 利未記 19:29; 以西結書 9:6"> 祭司的女兒若行淫辱沒自己，就辱沒了父親，必用火將她焚燒。</span>
<span className="v" id="v10" data-v="10" data-xref="利未記 10:6–7; 利未記 16:32; 馬太福音 26:65"> 「在弟兄中作大祭司、頭上倒了膏油、又承接聖職、穿了聖衣的，不可蓬頭散髮，也不可撕裂衣服。</span>
<span className="v" id="v11" data-v="11" data-xref="民數記 19:14; 利未記 21:1–2; 民數記 6:7"> 不可挨近死屍，也不可為父母沾染自己。</span>
<span className="v" id="v12" data-v="12" data-xref="利未記 10:7; 出埃及記 29:6–7; 利未記 8:9–12"> 不可出聖所，也不可褻瀆上帝的聖所，因為上帝膏油的冠冕在他頭上。我是耶和華。</span>
<span className="v" id="v13" data-v="13" data-xref="利未記 21:7; 哥林多後書 11:2; 啟示錄 14:4"> 他要娶處女為妻。</span>
<span className="v" id="v14" data-v="14" data-xref="利未記 21:7; 以西結書 44:22"> 寡婦或是被休的婦人，或是被污為妓的女人，都不可娶；只可娶本民中的處女為妻。</span>
<span className="v" id="v15" data-v="15" data-xref="羅馬書 11:16; 哥林多前書 7:14; 尼希米記 13:23–29"> 不可在民中辱沒他的兒女，因為我是叫他成聖的耶和華。」</span>
<span className="v" id="v16" data-v="16"> 耶和華對摩西說：</span>
<span className="v" id="v17" data-v="17" data-xref="詩篇 65:4; 民數記 16:5; 利未記 10:3"> 「你告訴亞倫說：你世世代代的後裔，凡有殘疾的，都不可近前來獻他上帝的食物。</span>
<span className="v" id="v18" data-v="18" data-xref="提摩太前書 3:2–3; 利未記 22:19–25; 提多書 1:7"> 因為凡有殘疾的，無論是瞎眼的、瘸腿的、塌鼻子的、肢體有餘的、</span>
<span className="v" id="v19" data-v="19"> 折腳折手的、</span>
<span className="v" id="v20" data-v="20" data-xref="申命記 23:1; 以賽亞書 56:3"> 駝背的、矮矬的、眼睛有毛病的、長癬的、長疥的，或是損壞腎子的，都不可近前來。</span>
<span className="v" id="v21" data-v="21" data-xref="利未記 21:6; 利未記 21:8; 利未記 21:17"> 祭司亞倫的後裔，凡有殘疾的，都不可近前來，將火祭獻給耶和華。他有殘疾，不可近前來獻上帝的食物。</span>
<span className="v" id="v22" data-v="22" data-xref="利未記 2:3; 民數記 18:19; 利未記 24:8–9"> 上帝的食物，無論是聖的，至聖的，他都可以吃。</span>
<span className="v" id="v23" data-v="23" data-xref="利未記 21:12; 以西結書 44:9–14; 出埃及記 30:6–8"> 但不可進到幔子前，也不可就近壇前；因為他有殘疾，免得褻瀆我的聖所。我是叫他成聖的耶和華。」</span>
<span className="v" id="v24" data-v="24" data-xref="提摩太前書 1:18; 瑪拉基書 2:1–7; 提摩太後書 2:2"> 於是，摩西曉諭亞倫和亞倫的子孫，並以色列眾人。</span>

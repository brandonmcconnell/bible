## 贖愆祭的條例

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="利未記 5:17; 箴言 29:24; 利未記 19:8"> 「若有人聽見發誓的聲音<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或譯：若有人聽見叫人發誓的聲音">a</a></sup>，他本是見證，卻不把所看見的、所知道的說出來，這就是罪；他要擔當他的罪孽。</span>
<span className="v" id="v2" data-v="2" data-xref="利未記 5:17; 申命記 14:8; 哈該書 2:13"> 或是有人摸了不潔的物，無論是不潔的死獸，是不潔的死畜，是不潔的死蟲，他卻不知道，因此成了不潔，就有了罪。</span>
<span className="v" id="v3" data-v="3" data-xref="民數記 19:11–16; 利未記 15:1–33; 利未記 12:1–8"> 或是他摸了別人的污穢，無論是染了甚麼污穢，他卻不知道，一知道了就有了罪。</span>
<span className="v" id="v4" data-v="4" data-xref="傳道書 5:2–6; 使徒行傳 23:12; 士師記 11:31"> 或是有人嘴裏冒失發誓，要行惡，要行善，無論人在甚麼事上冒失發誓，他卻不知道，一知道了就要在這其中的一件上有了罪。</span>
<span className="v" id="v5" data-v="5" data-xref="箴言 28:13; 民數記 5:7; 利未記 26:40"> 他有了罪的時候，就要承認所犯的罪，</span>
<span className="v" id="v6" data-v="6" data-xref="利未記 4:28; 利未記 4:32; 利未記 4:20"> 並要因所犯的罪，把他的贖愆祭牲－就是羊群中的母羊，或是一隻羊羔，或是一隻山羊－牽到耶和華面前為贖罪祭。至於他的罪，祭司要為他贖了。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="利未記 12:8; 利未記 14:21–22; 馬太福音 3:16"> 「他的力量若不夠獻一隻羊羔，就要因所犯的罪，把兩隻斑鳩或是兩隻雛鴿帶到耶和華面前為贖愆祭：一隻作贖罪祭，一隻作燔祭。</span>
<span className="v" id="v8" data-v="8" data-xref="利未記 1:15; 利未記 1:17; 羅馬書 4:25"> 把這些帶到祭司那裏，祭司就要先把那贖罪祭獻上，從鳥的頸項上揪下頭來，只是不可把鳥撕斷，</span>
<span className="v" id="v9" data-v="9" data-xref="利未記 4:30; 利未記 4:34; 利未記 4:18"> 也把些贖罪祭牲的血彈在壇的旁邊，剩下的血要流在壇的腳那裏；這是贖罪祭。</span>
<span className="v" id="v10" data-v="10" data-xref="利未記 1:14–17; 利未記 4:26; 利未記 4:20"> 他要照例獻第二隻為燔祭。至於他所犯的罪，祭司要為他贖了，他必蒙赦免。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="民數記 5:15; 利未記 2:1–2; 出埃及記 16:36"> 「他的力量若不夠獻兩隻斑鳩或是兩隻雛鴿，就要因所犯的罪帶供物來，就是細麵伊法十分之一為贖罪祭；不可加上油，也不可加上乳香，因為是贖罪祭。</span>
<span className="v" id="v12" data-v="12" data-xref="利未記 4:35; 利未記 2:9; 利未記 2:2"> 他要把供物帶到祭司那裏，祭司要取出自己的一把來作為紀念，按獻給耶和華火祭的條例燒在壇上；這是贖罪祭。</span>
<span className="v" id="v13" data-v="13" data-xref="利未記 2:3; 利未記 4:26; 哥林多前書 9:13"> 至於他在這幾件事中所犯的罪，祭司要為他贖了，他必蒙赦免。剩下的麵都歸與祭司，和素祭一樣。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14"> 耶和華曉諭摩西說：</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及記 30:13; 利未記 4:2; 利未記 6:6"> 「人若在耶和華的聖物上誤犯了罪，有了過犯，就要照你所估的，按聖所的舍客勒拿銀子，將贖愆祭牲－就是羊群中一隻沒有殘疾的公綿羊－牽到耶和華面前為贖愆祭；</span>
<span className="v" id="v16" data-v="16" data-xref="利未記 22:14; 民數記 5:7; 利未記 27:27"> 並且他因在聖物上的差錯要償還，另外加五分之一，都給祭司。祭司要用贖愆祭的公綿羊為他贖罪，他必蒙赦免。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="利未記 4:27; 利未記 4:13; 利未記 4:2–4"> 「若有人犯罪，行了耶和華所吩咐不可行的甚麼事，他雖然不知道，還是有了罪，就要擔當他的罪孽；</span>
<span className="v" id="v18" data-v="18" data-xref="利未記 5:15–16; 提摩太前書 2:5–6; 利未記 1:4"> 也要照你所估定的價，從羊群中牽一隻沒有殘疾的公綿羊來，給祭司作贖愆祭。至於他誤行的那錯事，祭司要為他贖罪，他必蒙赦免。</span>
<span className="v" id="v19" data-v="19" data-xref="詩篇 51:4; 瑪拉基書 3:8; 哥林多後書 5:19–21"> 這是贖愆祭，因他在耶和華面前實在有了罪。」</span>
</div>
</div>

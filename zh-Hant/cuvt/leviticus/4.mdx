## 為誤犯的罪獻祭的條例

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華對摩西說：</span>
<span className="v" id="v2" data-v="2" data-xref="詩篇 19:12; 希伯來書 9:7; 利未記 4:27"> 「你曉諭以色列人說：若有人在耶和華所吩咐不可行的甚麼事上誤犯了一件，</span>
<span className="v" id="v3" data-v="3" data-xref="希伯來書 7:27–28; 利未記 4:14; 利未記 9:2"> 或是受膏的祭司犯罪，使百姓陷在罪裏，就當為他所犯的罪把沒有殘疾的公牛犢獻給耶和華為贖罪祭。</span>
<span className="v" id="v4" data-v="4" data-xref="利未記 1:3–4; 但以理書 9:26; 以賽亞書 53:6"> 他要牽公牛到會幕門口，在耶和華面前按手在牛的頭上，把牛宰於耶和華面前。</span>
<span className="v" id="v5" data-v="5" data-xref="利未記 16:14; 民數記 19:4; 利未記 4:16–17"> 受膏的祭司要取些公牛的血帶到會幕，</span>
<span className="v" id="v6" data-v="6" data-xref="利未記 16:14; 利未記 14:18; 利未記 26:28"> 把指頭蘸於血中，在耶和華面前對着聖所的幔子彈血七次，</span>
<span className="v" id="v7" data-v="7" data-xref="利未記 8:15; 利未記 9:9; 利未記 16:18"> 又要把些血抹在會幕內、耶和華面前香壇的四角上，再把公牛所有的血倒在會幕門口、燔祭壇的腳那裏。</span>
<span className="v" id="v8" data-v="8" data-xref="利未記 3:3–5; 利未記 4:26; 利未記 4:31"> 要把贖罪祭公牛所有的脂油，乃是蓋臟的脂油和臟上所有的脂油，</span>
<span className="v" id="v9" data-v="9" data-xref="利未記 3:4"> 並兩個腰子和腰子上的脂油，就是靠腰兩旁的脂油，與肝上的網子和腰子，一概取下，</span>
<span className="v" id="v10" data-v="10"> 與平安祭公牛上所取的一樣；祭司要把這些燒在燔祭的壇上。</span>
<span className="v" id="v11" data-v="11" data-xref="民數記 19:5; 出埃及記 29:14; 利未記 9:8–11"> 公牛的皮和所有的肉，並頭、腿、臟、腑、糞，</span>
<span className="v" id="v12" data-v="12" data-xref="希伯來書 13:11; 出埃及記 29:14; 利未記 16:27"> 就是全公牛，要搬到營外潔淨之地、倒灰之所，用火燒在柴上。</span>
<span className="v" id="v13" data-v="13" data-xref="利未記 5:17; 利未記 5:2–5; 何西阿書 5:15"> 「以色列全會眾若行了耶和華所吩咐不可行的甚麼事，誤犯了罪，是隱而未現、會眾看不出來的，</span>
<span className="v" id="v14" data-v="14" data-xref="利未記 4:23; 利未記 4:3; 利未記 4:28"> 會眾一知道所犯的罪就要獻一隻公牛犢為贖罪祭，牽到會幕前。</span>
<span className="v" id="v15" data-v="15" data-xref="利未記 1:4; 利未記 16:21; 利未記 8:14"> 會中的長老就要在耶和華面前按手在牛的頭上，將牛在耶和華面前宰了。</span>
<span className="v" id="v16" data-v="16" data-xref="利未記 4:5–12; 希伯來書 9:12–14"> 受膏的祭司要取些公牛的血帶到會幕，</span>
<span className="v" id="v17" data-v="17" data-xref="利未記 4:6–7"> 把指頭蘸於血中，在耶和華面前對着幔子彈血七次，</span>
<span className="v" id="v18" data-v="18" data-xref="利未記 4:7"> 又要把些血抹在會幕內、耶和華面前壇的四角上，再把所有的血倒在會幕門口、燔祭壇的腳那裏。</span>
<span className="v" id="v19" data-v="19" data-xref="利未記 5:6; 利未記 4:26; 民數記 15:25"> 把牛所有的脂油都取下，燒在壇上；</span>
<span className="v" id="v20" data-v="20" data-xref="民數記 15:25; 希伯來書 10:10–12; 利未記 12:8"> 收拾這牛，與那贖罪祭的牛一樣。祭司要為他們贖罪，他們必蒙赦免。</span>
<span className="v" id="v21" data-v="21" data-xref="利未記 16:15; 馬太福音 20:28; 哥林多後書 5:21"> 他要把牛搬到營外燒了，像燒頭一個牛一樣；這是會眾的贖罪祭。</span>
<span className="v" id="v22" data-v="22" data-xref="利未記 4:2; 利未記 4:13; 民數記 31:13"> 「官長若行了耶和華－他上帝所吩咐不可行的甚麼事，誤犯了罪，</span>
<span className="v" id="v23" data-v="23" data-xref="利未記 4:14; 羅馬書 8:3; 民數記 7:22"> 所犯的罪自己知道了，就要牽一隻沒有殘疾的公山羊為供物，</span>
<span className="v" id="v24" data-v="24" data-xref="利未記 3:13; 利未記 7:2; 利未記 4:3–35"> 按手在羊的頭上，宰於耶和華面前、宰燔祭牲的地方；這是贖罪祭。</span>
<span className="v" id="v25" data-v="25" data-xref="利未記 4:7; 利未記 4:18; 利未記 4:30"> 祭司要用指頭蘸些贖罪祭牲的血，抹在燔祭壇的四角上，把血倒在燔祭壇的腳那裏。</span>
<span className="v" id="v26" data-v="26" data-xref="利未記 4:20; 利未記 4:31; 利未記 4:35"> 所有的脂油，祭司都要燒在壇上，正如平安祭的脂油一樣。至於他的罪，祭司要為他贖了，他必蒙赦免。</span>
<span className="v" id="v27" data-v="27" data-xref="利未記 4:2; 民數記 15:27; 利未記 4:13"> 「民中若有人行了耶和華所吩咐不可行的甚麼事，誤犯了罪，</span>
<span className="v" id="v28" data-v="28" data-xref="利未記 4:23; 利未記 4:3; 利未記 4:32"> 所犯的罪自己知道了，就要為所犯的罪牽一隻沒有殘疾的母山羊為供物，</span>
<span className="v" id="v29" data-v="29" data-xref="利未記 4:4; 利未記 4:24; 利未記 1:4"> 按手在贖罪祭牲的頭上，在那宰燔祭牲的地方宰了。</span>
<span className="v" id="v30" data-v="30" data-xref="利未記 4:7; 利未記 4:25; 利未記 4:34"> 祭司要用指頭蘸些羊的血，抹在燔祭壇的四角上，所有的血都要倒在壇的腳那裏，</span>
<span className="v" id="v31" data-v="31" data-xref="利未記 4:26; 利未記 4:35; 利未記 1:9"> 又要把羊所有的脂油都取下，正如取平安祭牲的脂油一樣。祭司要在壇上焚燒，在耶和華面前作為馨香的祭，為他贖罪，他必蒙赦免。</span>
<span className="v" id="v32" data-v="32" data-xref="利未記 4:28; 彼得前書 3:18; 彼得前書 2:22"> 「人若牽一隻綿羊羔為贖罪祭的供物，必要牽一隻沒有殘疾的母羊，</span>
<span className="v" id="v33" data-v="33" data-xref="利未記 4:29–31; 利未記 4:4"> 按手在贖罪祭牲的頭上，在那宰燔祭牲的地方宰了作贖罪祭。</span>
<span className="v" id="v34" data-v="34" data-xref="利未記 4:30; 利未記 4:25; 利未記 4:7"> 祭司要用指頭蘸些贖罪祭牲的血，抹在燔祭壇的四角上，所有的血都要倒在壇的腳那裏，</span>
<span className="v" id="v35" data-v="35" data-xref="利未記 4:26; 利未記 4:20; 利未記 14:18"> 又要把所有的脂油都取下，正如取平安祭羊羔的脂油一樣。祭司要按獻給耶和華火祭的條例，燒在壇上。至於所犯的罪，祭司要為他贖了，他必蒙赦免。」</span>

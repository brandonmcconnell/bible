## 有關淫亂的禁令

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華對摩西說：</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及記 6:7; 利未記 11:44; 以西結書 20:5"> 「你曉諭以色列人說：我是耶和華－你們的上帝。</span>
<span className="v" id="v3" data-v="3" data-xref="利未記 20:23; 出埃及記 23:24; 彼得前書 4:2–4"> 你們從前住的埃及地，那裏人的行為，你們不可效法，我要領你們到的迦南地，那裏人的行為也不可效法，也不可照他們的惡俗行。</span>
<span className="v" id="v4" data-v="4" data-xref="利未記 18:2; 利未記 18:26; 以西結書 20:19"> 你們要遵我的典章，守我的律例，按此而行。我是耶和華－你們的上帝。</span>
<span className="v" id="v5" data-v="5" data-xref="羅馬書 10:5; 以西結書 20:11; 加拉太書 3:12"> 所以，你們要守我的律例典章；人若遵行，就必因此活着。我是耶和華。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="利未記 20:17–21; 利未記 18:7–19; 利未記 20:11–12"> 「你們都不可露骨肉之親的下體，親近他們。我是耶和華。</span>
<span className="v" id="v7" data-v="7" data-xref="利未記 20:11; 以西結書 22:10; 利未記 18:8–16"> 不可露你母親的下體，羞辱了你父親。她是你的母親，不可露她的下體。</span>
<span className="v" id="v8" data-v="8" data-xref="利未記 20:11; 哥林多前書 5:1; 申命記 27:20"> 不可露你繼母的下體；這本是你父親的下體。</span>
<span className="v" id="v9" data-v="9" data-xref="利未記 20:17; 申命記 27:22; 以西結書 22:11"> 你的姊妹，不拘是異母同父的，是異父同母的，無論是生在家生在外的，都不可露她們的下體。</span>
<span className="v" id="v10" data-v="10"> 不可露你孫女或是外孫女的下體，露了她們的下體就是露了自己的下體。</span>
<span className="v" id="v11" data-v="11"> 你繼母從你父親生的女兒本是你的妹妹，不可露她的下體。</span>
<span className="v" id="v12" data-v="12" data-xref="利未記 20:19; 出埃及記 6:20"> 不可露你姑母的下體；她是你父親的骨肉之親。</span>
<span className="v" id="v13" data-v="13"> 不可露你姨母的下體；她是你母親的骨肉之親。</span>
<span className="v" id="v14" data-v="14" data-xref="利未記 20:20"> 不可親近你伯叔之妻，羞辱了你伯叔；她是你的伯叔母。</span>
<span className="v" id="v15" data-v="15" data-xref="利未記 20:12; 創世記 38:26; 以西結書 22:11"> 不可露你兒婦的下體；她是你兒子的妻，不可露她的下體。</span>
<span className="v" id="v16" data-v="16" data-xref="申命記 25:5; 利未記 20:21; 馬太福音 22:24"> 不可露你弟兄妻子的下體；這本是你弟兄的下體。</span>
<span className="v" id="v17" data-v="17" data-xref="利未記 20:14; 阿摩司書 2:7; 申命記 27:23"> 不可露了婦人的下體，又露她女兒的下體，也不可娶她孫女或是外孫女，露她們的下體；她們是骨肉之親，這本是大惡。</span>
<span className="v" id="v18" data-v="18" data-xref="瑪拉基書 2:15; 創世記 30:15; 創世記 29:28"> 你妻還在的時候，不可另娶她的姊妹作對頭，露她的下體。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="利未記 20:18; 利未記 15:24; 以西結書 22:10"> 「女人行經不潔淨的時候，不可露她的下體，與她親近。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及記 20:14; 哥林多前書 6:9; 希伯來書 13:4"> 不可與鄰舍的妻行淫，玷污自己。</span>
<span className="v" id="v21" data-v="21" data-xref="申命記 12:31; 利未記 20:2–5; 申命記 18:10"> 不可使你的兒女經火歸與摩洛，也不可褻瀆你上帝的名。我是耶和華。</span>
<span className="v" id="v22" data-v="22" data-xref="利未記 20:13; 羅馬書 1:26–27; 哥林多前書 6:9"> 不可與男人苟合，像與女人一樣；這本是可憎惡的。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及記 22:19; 利未記 20:15–16; 利未記 20:12"> 不可與獸淫合，玷污自己。女人也不可站在獸前，與牠淫合；這本是逆性的事。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="申命記 18:12; 利未記 18:30; 利未記 20:22–23"> 「在這一切的事上，你們都不可玷污自己；因為我在你們面前所逐出的列邦，在這一切的事上玷污了自己；</span>
<span className="v" id="v25" data-v="25" data-xref="利未記 18:28; 利未記 20:22–23; 耶利米書 2:7"> 連地也玷污了，所以我追討那地的罪孽，那地也吐出它的居民。</span>
<span className="v" id="v26" data-v="26" data-xref="利未記 18:5; 利未記 17:10; 利未記 18:30"> 故此，你們要守我的律例典章。這一切可憎惡的事，無論是本地人，是寄居在你們中間的外人，都不可行，（</span>
<span className="v" id="v27" data-v="27" data-xref="歷代志下 36:14; 利未記 18:24; 申命記 23:18"> 在你們以先居住那地的人行了這一切可憎惡的事，地就玷污了，）</span>
<span className="v" id="v28" data-v="28" data-xref="啟示錄 3:16; 利未記 20:22; 利未記 18:25"> 免得你們玷污那地的時候，地就把你們吐出，像吐出在你們以先的國民一樣。</span>
<span className="v" id="v29" data-v="29" data-xref="利未記 20:6; 出埃及記 12:15; 利未記 17:10"> 無論甚麼人，行了其中可憎的一件事，必從民中剪除。</span>
<span className="v" id="v30" data-v="30" data-xref="利未記 20:23; 申命記 18:9–12; 利未記 22:9"> 所以，你們要守我所吩咐的，免得你們隨從那些可憎的惡俗，就是在你們以先的人所常行的，以致玷污了自己。我是耶和華－你們的上帝。」</span>
</div>
</div>

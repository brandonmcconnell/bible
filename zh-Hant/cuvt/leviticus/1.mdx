## 燔祭的條例

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及記 19:3; 出埃及記 25:22; 出埃及記 29:42"> 耶和華從會幕中呼叫摩西，對他說：</span>
<span className="v" id="v2" data-v="2" data-xref="利未記 22:18–19; 羅馬書 12:6; 歷代志上 16:29"> 「你曉諭以色列人說：你們中間若有人獻供物給耶和華，要從牛群羊群中獻牲畜為供物。</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 15:21; 希伯來書 9:14; 利未記 22:19–24"> 「他的供物若以牛為燔祭，就要在會幕門口獻一隻沒有殘疾的公牛，可以在耶和華面前蒙悅納。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及記 29:10; 出埃及記 29:15; 利未記 4:20"> 他要按手在燔祭牲的頭上，燔祭便蒙悅納，為他贖罪。</span>
<span className="v" id="v5" data-v="5" data-xref="利未記 1:11; 利未記 3:8; 利未記 3:2"> 他要在耶和華面前宰公牛；亞倫子孫作祭司的，要奉上血，把血灑在會幕門口、壇的周圍。</span>
<span className="v" id="v6" data-v="6" data-xref="利未記 7:8; 創世記 3:21"> 那人要剝去燔祭牲的皮，把燔祭牲切成塊子。</span>
<span className="v" id="v7" data-v="7" data-xref="利未記 6:12–13; 創世記 22:9; 歷代志上 21:26"> 祭司亞倫的子孫要把火放在壇上，把柴擺在火上。</span>
<span className="v" id="v8" data-v="8" data-xref="利未記 9:13–14; 利未記 1:12; 列王紀上 18:33"> 亞倫子孫作祭司的，要把肉塊和頭並脂油擺在壇上火的柴上。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 8:21; 利未記 1:13; 以弗所書 5:2"> 但燔祭的臟腑與腿要用水洗。祭司就要把一切全燒在壇上，當作燔祭，獻與耶和華為馨香的火祭。</span>
<span className="v" id="v10" data-v="10" data-xref="以賽亞書 53:6–7; 利未記 1:2–3; 創世記 8:20"> 「人的供物若以綿羊或山羊為燔祭，就要獻上沒有殘疾的公羊。</span>
<span className="v" id="v11" data-v="11" data-xref="利未記 1:5; 出埃及記 40:22; 利未記 7:2"> 要把羊宰於壇的北邊，在耶和華面前；亞倫子孫作祭司的，要把羊血灑在壇的周圍。</span>
<span className="v" id="v12" data-v="12"> 要把燔祭牲切成塊子，連頭和脂油，祭司就要擺在壇上火的柴上；</span>
<span className="v" id="v13" data-v="13" data-xref="利未記 1:9"> 但臟腑與腿要用水洗，祭司就要全然奉獻，燒在壇上。這是燔祭，是獻與耶和華為馨香的火祭。</span>
<span className="v" id="v14" data-v="14" data-xref="利未記 5:7; 路加福音 2:24; 利未記 12:8"> 「人奉給耶和華的供物，若以鳥為燔祭，就要獻斑鳩或是雛鴿為供物。</span>
<span className="v" id="v15" data-v="15" data-xref="利未記 5:8–9; 詩篇 22:21; 約翰一書 2:27"> 祭司要把鳥拿到壇前，揪下頭來，把鳥燒在壇上；鳥的血要流在壇的旁邊；</span>
<span className="v" id="v16" data-v="16" data-xref="彼得前書 1:2; 路加福音 1:35; 利未記 16:27"> 又要把鳥的嗉子和髒物<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="髒物：或譯翎毛">a</a></sup>除掉，丟在壇的東邊倒灰的地方。</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 15:10; 約翰福音 19:30; 利未記 1:9–10"> 要拿着鳥的兩個翅膀，把鳥撕開，只是不可撕斷；祭司要在壇上、在火的柴上焚燒。這是燔祭，是獻與耶和華為馨香的火祭。」</span>

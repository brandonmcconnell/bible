## 素祭的條例

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="利未記 6:14–18; 利未記 9:17; 以賽亞書 66:20"> 「若有人獻素祭為供物給耶和華，要用細麵澆上油，加上乳香，</span>
<span className="v" id="v2" data-v="2" data-xref="利未記 5:12; 利未記 6:15; 使徒行傳 10:4"> 帶到亞倫子孫作祭司的那裏；祭司就要從細麵中取出一把來，並取些油和所有的乳香，然後要把所取的這些作為紀念，燒在壇上，是獻與耶和華為馨香的火祭。</span>
<span className="v" id="v3" data-v="3" data-xref="利未記 10:12–13; 民數記 18:9; 利未記 21:22"> 素祭所剩的要歸給亞倫和他的子孫；這是獻與耶和華的火祭中為至聖的。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="出埃及記 29:2; 哥林多前書 5:7–8; 詩篇 22:14"> 「若用爐中烤的物為素祭，就要用調油的無酵細麵餅，或是抹油的無酵薄餅。</span>
<span className="v" id="v5" data-v="5" data-xref="利未記 6:21; 利未記 7:9"> 若用鐵鏊上做的物為素祭，就要用調油的無酵細麵，</span>
<span className="v" id="v6" data-v="6" data-xref="約翰福音 18:1–19; 詩篇 22:1–21; 馬可福音 14:1–15"> 分成塊子，澆上油；這是素祭。</span>
<span className="v" id="v7" data-v="7" data-xref="利未記 2:1–2; 利未記 7:9"> 若用煎盤做的物為素祭，就要用油與細麵做成。</span>
<span className="v" id="v8" data-v="8"> 要把這些東西做的素祭帶到耶和華面前，並奉給祭司，帶到壇前。</span>
<span className="v" id="v9" data-v="9" data-xref="利未記 2:2; 腓立比書 4:18; 利未記 6:15"> 祭司要從素祭中取出作為紀念的，燒在壇上，是獻與耶和華為馨香的火祭。</span>
<span className="v" id="v10" data-v="10" data-xref="利未記 2:3"> 素祭所剩的要歸給亞倫和他的子孫。這是獻與耶和華的火祭中為至聖的。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="加拉太書 5:9; 路加福音 12:1; 出埃及記 23:18"> 「凡獻給耶和華的素祭都不可有酵；因為你們不可燒一點酵、一點蜜當作火祭獻給耶和華。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及記 23:19; 創世記 23:10–11; 出埃及記 22:29"> 這些物要獻給耶和華作為初熟的供物，只是不可在壇上獻為馨香的祭。</span>
<span className="v" id="v13" data-v="13" data-xref="以西結書 43:24; 馬太福音 5:13; 歌羅西書 4:6"> 凡獻為素祭的供物都要用鹽調和，在素祭上不可缺了你上帝立約的鹽。一切的供物都要配鹽而獻。</span>
<span className="v" id="v14" data-v="14" data-xref="利未記 23:10; 瑪拉基書 1:11; 民數記 28:2"> 若向耶和華獻初熟之物為素祭，要獻上烘了的禾穗子，就是軋了的新穗子，當作初熟之物的素祭。</span>
<span className="v" id="v15" data-v="15"> 並要抹上油，加上乳香；這是素祭。</span>
<span className="v" id="v16" data-v="16" data-xref="希伯來書 5:7; 羅馬書 8:26–27; 以賽亞書 61:1"> 祭司要把其中作為紀念的，就是一些軋了的禾穗子和一些油，並所有的乳香，都焚燒，是向耶和華獻的火祭。」</span>
</div>
</div>

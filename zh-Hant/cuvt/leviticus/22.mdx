## 聖物的聖潔

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華對摩西說：</span>
<span className="v" id="v2" data-v="2" data-xref="利未記 18:21; 申命記 15:19; 利未記 22:32"> 「你吩咐亞倫和他子孫說：要遠離以色列人所分別為聖、歸給我的聖物，免得褻瀆我的聖名。我是耶和華。</span>
<span className="v" id="v3" data-v="3" data-xref="利未記 7:20–21; 民數記 19:13; 詩篇 16:11"> 你要對他們說：你們世世代代的後裔，凡身上有污穢、親近以色列人所分別為聖、歸耶和華聖物的，那人必在我面前剪除。我是耶和華。</span>
<span className="v" id="v4" data-v="4" data-xref="利未記 11:39; 利未記 15:2–3; 利未記 15:13–16"> 亞倫的後裔，凡長大痲瘋的，或是有漏症的，不可吃聖物，直等他潔淨了。無論誰摸那因死屍不潔淨的物<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或譯：人">a</a></sup>，或是遺精的人，</span>
<span className="v" id="v5" data-v="5" data-xref="利未記 11:43–44; 利未記 15:7; 利未記 15:19"> 或是摸甚麼使他不潔淨的爬物，或是摸那使他不潔淨的人（不拘那人有甚麼不潔淨），</span>
<span className="v" id="v6" data-v="6" data-xref="利未記 15:5; 希伯來書 10:22; 哈該書 2:13"> 摸了這些人、物的，必不潔淨到晚上；若不用水洗身，就不可吃聖物。</span>
<span className="v" id="v7" data-v="7" data-xref="利未記 21:22; 申命記 18:3–4; 哥林多前書 9:13–14"> 日落的時候，他就潔淨了，然後可以吃聖物，因為這是他的食物。</span>
<span className="v" id="v8" data-v="8" data-xref="利未記 17:15; 出埃及記 22:31; 以西結書 44:31"> 自死的或是被野獸撕裂的，他不可吃，因此污穢自己。我是耶和華。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及記 28:43; 民數記 18:22; 民數記 18:32"> 所以他們要守我所吩咐的，免得輕忽了，因此擔罪而死。我是叫他們成聖的耶和華。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="馬太福音 12:4; 撒母耳記上 21:6; 出埃及記 29:33"> 「凡外人不可吃聖物；寄居在祭司家的，或是雇工人，都不可吃聖物；</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 17:13; 出埃及記 12:44; 民數記 18:11–13"> 倘若祭司買人，是他的錢買的，那人就可以吃聖物；生在他家的人也可以吃。</span>
<span className="v" id="v12" data-v="12" data-xref="以賽亞書 40:13; 利未記 21:3"> 祭司的女兒若嫁外人，就不可吃舉祭的聖物。</span>
<span className="v" id="v13" data-v="13" data-xref="利未記 10:14; 創世記 38:11; 民數記 18:11–19"> 但祭司的女兒若是寡婦，或是被休的，沒有孩子，又歸回父家，與她青年一樣，就可以吃她父親的食物；只是外人不可吃。</span>
<span className="v" id="v14" data-v="14" data-xref="利未記 27:15; 利未記 27:13; 利未記 5:15–19"> 若有人誤吃了聖物，要照聖物的原數加上五分之一交給祭司。</span>
<span className="v" id="v15" data-v="15" data-xref="民數記 18:32; 利未記 19:8; 以西結書 22:26"> 祭司不可褻瀆以色列人所獻給耶和華的聖物，</span>
<span className="v" id="v16" data-v="16" data-xref="利未記 22:9; 彼得前書 2:24; 以賽亞書 53:11–12"> 免得他們在吃聖物上自取罪孽，因為我是叫他們成聖的耶和華。」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17"> 耶和華對摩西說：</span>
<span className="v" id="v18" data-v="18" data-xref="利未記 1:2; 申命記 12:6; 民數記 15:3"> 「你曉諭亞倫和他子孫，並以色列眾人說：以色列家中的人，或在以色列中寄居的，凡獻供物，無論是所許的願，是甘心獻的，就是獻給耶和華作燔祭的，</span>
<span className="v" id="v19" data-v="19" data-xref="利未記 1:10; 利未記 1:3; 以弗所書 5:27"> 要將沒有殘疾的公牛，或是綿羊，或是山羊獻上，如此方蒙悅納。</span>
<span className="v" id="v20" data-v="20" data-xref="申命記 17:1; 瑪拉基書 1:8; 申命記 15:21"> 凡有殘疾的，你們不可獻上，因為這不蒙悅納。</span>
<span className="v" id="v21" data-v="21" data-xref="民數記 15:8; 民數記 15:3; 利未記 3:6"> 凡從牛群或是羊群中，將平安祭獻給耶和華，為要還特許的願，或是作甘心獻的，所獻的必純全無殘疾的才蒙悅納。</span>
<span className="v" id="v22" data-v="22" data-xref="利未記 22:20; 瑪拉基書 1:8; 利未記 1:9"> 瞎眼的、折傷的、殘廢的、有瘤子的、長癬的、長疥的都不可獻給耶和華，也不可在壇上作為火祭獻給耶和華。</span>
<span className="v" id="v23" data-v="23" data-xref="利未記 21:18"> 無論是公牛是綿羊羔，若肢體有餘的，或是缺少的，只可作甘心祭獻上；用以還願，卻不蒙悅納。</span>
<span className="v" id="v24" data-v="24" data-xref="利未記 22:20; 申命記 23:1; 利未記 21:20"> 腎子損傷的，或是壓碎的，或是破裂的，或是騸了的，不可獻給耶和華，在你們的地上也不可這樣行。</span>
<span className="v" id="v25" data-v="25" data-xref="利未記 21:8; 以斯拉記 6:8–10; 民數記 15:14–16"> 這類的物，你們從外人的手，一樣也不可接受作你們上帝的食物獻上；因為這些都有損壞，有殘疾，不蒙悅納。」</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26"> 耶和華曉諭摩西說：</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及記 22:30; 利未記 19:23–24; 利未記 22:25"> 「才生的公牛，或是綿羊或是山羊，七天當跟着母；從第八天以後，可以當供物蒙悅納，作為耶和華的火祭。</span>
<span className="v" id="v28" data-v="28" data-xref="申命記 22:6–7; 申命記 14:21; 出埃及記 34:26"> 無論是母牛是母羊，不可同日宰母和子。</span>
<span className="v" id="v29" data-v="29" data-xref="詩篇 116:17; 詩篇 107:22; 阿摩司書 4:5"> 你們獻感謝祭給耶和華，要獻得可蒙悅納。</span>
<span className="v" id="v30" data-v="30" data-xref="利未記 7:15–18; 出埃及記 16:19–20; 利未記 19:7"> 要當天吃，一點不可留到早晨。我是耶和華。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="申命記 4:40; 利未記 19:37; 民數記 15:40"> 「你們要謹守遵行我的誡命。我是耶和華。</span>
<span className="v" id="v32" data-v="32" data-xref="利未記 18:21; 路加福音 11:2; 馬太福音 6:9"> 你們不可褻瀆我的聖名；我在以色列人中，卻要被尊為聖。我是叫你們成聖的耶和華，</span>
<span className="v" id="v33" data-v="33" data-xref="利未記 11:45; 出埃及記 6:7; 利未記 25:38"> 把你們從埃及地領出來，作你們的上帝。我是耶和華。」</span>
</div>
</div>

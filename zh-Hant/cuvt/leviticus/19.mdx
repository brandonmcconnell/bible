## 聖潔和公正的法例

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華對摩西說：</span>
<span className="v" id="v2" data-v="2" data-xref="利未記 11:44–45; 利未記 20:7; 彼得前書 1:15–16"> 「你曉諭以色列全會眾說：你們要聖潔，因為我耶和華－你們的上帝是聖潔的。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及記 20:12; 出埃及記 20:8; 希伯來書 12:9"> 你們各人都當孝敬父母，也要守我的安息日。我是耶和華－你們的上帝。</span>
<span className="v" id="v4" data-v="4" data-xref="利未記 26:1; 出埃及記 20:23; 詩篇 115:4–7"> 你們不可偏向虛無的神，也不可為自己鑄造神像。我是耶和華－你們的上帝。</span>
<span className="v" id="v5" data-v="5" data-xref="利未記 22:19; 利未記 22:29; 利未記 7:16"> 你們獻平安祭給耶和華的時候，要獻得可蒙悅納。</span>
<span className="v" id="v6" data-v="6" data-xref="利未記 7:11–17"> 這祭物要在獻的那一天和第二天吃，若有剩到第三天的，就必用火焚燒。</span>
<span className="v" id="v7" data-v="7" data-xref="利未記 7:18–21; 利未記 22:25; 耶利米書 16:18"> 第三天若再吃，這就為可憎惡的，必不蒙悅納。</span>
<span className="v" id="v8" data-v="8" data-xref="利未記 22:15; 利未記 5:1"> 凡吃的人必擔當他的罪孽；因為他褻瀆了耶和華的聖物，那人必從民中剪除。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="利未記 23:22; 申命記 24:19–22; 路得記 2:2"> 「在你們的地收割莊稼，不可割盡田角，也不可拾取所遺落的。</span>
<span className="v" id="v10" data-v="10" data-xref="以賽亞書 17:6; 利未記 25:6; 以賽亞書 24:13"> 不可摘盡葡萄園的果子，也不可拾取葡萄園所掉的果子；要留給窮人和寄居的。我是耶和華－你們的上帝。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="詩篇 101:7; 以弗所書 4:25; 歌羅西書 3:9"> 「你們不可偷盜，不可欺騙，也不可彼此說謊。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及記 20:7; 申命記 5:11; 利未記 18:21"> 不可指着我的名起假誓，褻瀆你上帝的名。我是耶和華。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="雅各書 5:4; 瑪拉基書 3:5; 申命記 24:14–15"> 「不可欺壓你的鄰舍，也不可搶奪他的物。雇工人的工價，不可在你那裏過夜，留到早晨。</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 27:18; 利未記 19:32; 利未記 25:17"> 不可咒罵聾子，也不可將絆腳石放在瞎子面前，只要敬畏你的上帝。我是耶和華。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="申命記 1:17; 箴言 24:23; 申命記 27:19"> 「你們施行審判，不可行不義；不可偏護窮人，也不可重看有勢力的人，只要按着公義審判你的鄰舍。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 23:1; 出埃及記 23:7; 箴言 20:19"> 不可在民中往來搬弄是非，也不可與鄰舍為敵，置之於死<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是流他的血">a</a></sup>。我是耶和華。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="約翰一書 2:9; 約翰一書 2:11; 路加福音 17:3"> 「不可心裏恨你的弟兄；總要指摘你的鄰舍，免得因他擔罪。</span>
<span className="v" id="v18" data-v="18" data-xref="羅馬書 13:9; 馬太福音 22:39–40; 馬可福音 12:31–34"> 不可報仇，也不可埋怨你本國的子民，卻要愛人如己。我是耶和華。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="哥林多後書 6:14–17; 申命記 22:9–11; 馬太福音 9:16–17"> 「你們要守我的律例。不可叫你的牲畜與異類配合；不可用兩樣攙雜的種種你的地，也不可用兩樣攙雜的料做衣服穿在身上。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="申命記 22:23–24; 出埃及記 21:20–21"> 「婢女許配了丈夫，還沒有被贖、得釋放，人若與她行淫，二人要受刑罰，卻不把他們治死，因為婢女還沒有得自由。</span>
<span className="v" id="v21" data-v="21" data-xref="利未記 6:6–7; 利未記 5:1–6; 利未記 5:15"> 那人要把贖愆祭，就是一隻公綿羊牽到會幕門口、耶和華面前。</span>
<span className="v" id="v22" data-v="22" data-xref="利未記 4:26; 利未記 4:20"> 祭司要用贖愆祭的羊在耶和華面前贖他所犯的罪，他的罪就必蒙赦免。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="利未記 22:27; 使徒行傳 7:51; 耶利米書 9:25–26"> 「你們到了迦南地，栽種各樣結果子的樹木，就要以所結的果子如未受割禮的一樣。三年之久，你們要以這些果子，如未受割禮的，是不可吃的。</span>
<span className="v" id="v24" data-v="24" data-xref="箴言 3:9; 申命記 18:4; 民數記 18:12–13"> 但第四年所結的果子全要成為聖，用以讚美耶和華。</span>
<span className="v" id="v25" data-v="25" data-xref="哈該書 1:9–11; 瑪拉基書 3:8–10; 利未記 26:3–4"> 第五年，你們要吃那樹上的果子，好叫樹給你們結果子更多。我是耶和華－你們的上帝。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="申命記 18:10–14; 列王紀下 17:17; 歷代志下 33:6"> 「你們不可吃帶血的物；不可用法術，也不可觀兆。</span>
<span className="v" id="v27" data-v="27" data-xref="利未記 21:5; 申命記 14:1; 以西結書 44:20"> 頭的周圍<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或譯：兩鬢">b</a></sup>不可剃，鬍鬚的周圍也不可損壞。</span>
<span className="v" id="v28" data-v="28" data-xref="申命記 14:1; 利未記 21:5; 列王紀上 18:28"> 不可為死人用刀劃身，也不可在身上刺花紋。我是耶和華。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="申命記 23:17–18; 利未記 21:7; 何西阿書 4:12–14"> 「不可辱沒你的女兒，使她為娼妓，恐怕地上的人專向淫亂，地就滿了大惡。</span>
<span className="v" id="v30" data-v="30" data-xref="利未記 26:2; 利未記 19:3; 傳道書 5:1"> 你們要守我的安息日，敬我的聖所。我是耶和華。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="以賽亞書 8:19; 利未記 20:27; 利未記 20:6–7"> 「不可偏向那些交鬼的和行巫術的；不可求問他們，以致被他們玷污了。我是耶和華－你們的上帝。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="提摩太前書 5:1; 耶利米哀歌 5:12; 箴言 16:31"> 「在白髮的人面前，你要站起來；也要尊敬老人，又要敬畏你的上帝。我是耶和華。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="出埃及記 23:9; 出埃及記 22:21; 瑪拉基書 3:5"> 「若有外人在你們國中和你同居，就不可欺負他。</span>
<span className="v" id="v34" data-v="34" data-xref="申命記 10:19; 利未記 19:18; 出埃及記 12:48–49"> 和你們同居的外人，你們要看他如本地人一樣，並要愛他如己，因為你們在埃及地也作過寄居的。我是耶和華－你們的上帝。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="申命記 25:15; 申命記 25:13; 箴言 16:11"> 「你們施行審判，不可行不義；在尺、秤、升、斗上也是如此。</span>
<span className="v" id="v36" data-v="36" data-xref="箴言 11:1; 出埃及記 20:2; 申命記 25:13–15"> 要用公道天平、公道法碼、公道升斗、公道秤。我是耶和華－你們的上帝，曾把你們從埃及地領出來的。</span>
<span className="v" id="v37" data-v="37" data-xref="申命記 8:1; 利未記 18:4–5; 申命記 5:1"> 你們要謹守遵行我一切的律例典章。我是耶和華。」</span>
</div>
</div>

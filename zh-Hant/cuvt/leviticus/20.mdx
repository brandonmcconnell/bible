## 處罰悖逆的人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華對摩西說：</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 21:21; 利未記 18:21; 利未記 20:27"> 「你還要曉諭以色列人說：凡以色列人，或是在以色列中寄居的外人，把自己的兒女獻給摩洛的，總要治死他；本地人要用石頭把他打死。</span>
<span className="v" id="v3" data-v="3" data-xref="利未記 18:21; 以西結書 5:11; 以西結書 23:38–39"> 我也要向那人變臉，把他從民中剪除；因為他把兒女獻給摩洛，玷污我的聖所，褻瀆我的聖名。</span>
<span className="v" id="v4" data-v="4" data-xref="申命記 17:2–5; 使徒行傳 17:30; 列王紀上 20:42"> 那人把兒女獻給摩洛，本地人若佯為不見，不把他治死，</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 106:39; 何西阿書 2:13; 何西阿書 2:5"> 我就要向這人和他的家變臉，把他和一切隨他與摩洛行邪淫的人都從民中剪除。</span>
<span className="v" id="v6" data-v="6" data-xref="利未記 19:31; 以賽亞書 8:19; 利未記 20:27"> 「人偏向交鬼的和行巫術的，隨他們行邪淫，我要向那人變臉，把他從民中剪除。</span>
<span className="v" id="v7" data-v="7" data-xref="利未記 11:44; 利未記 19:2; 彼得前書 1:15–16"> 所以你們要自潔成聖，因為我是耶和華－你們的上帝。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及記 31:13; 雅各書 1:22; 帖撒羅尼迦前書 5:23"> 你們要謹守遵行我的律例；我是叫你們成聖的耶和華。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及記 21:17; 馬可福音 7:10; 申命記 27:16"> 凡咒罵父母的，總要治死他；他咒罵了父母，他的罪<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是血；本章同">a</a></sup>要歸到他身上。</span>
<span className="v" id="v10" data-v="10" data-xref="約翰福音 8:4–5; 申命記 22:22–24; 申命記 5:18"> 「與鄰舍之妻行淫的，姦夫淫婦都必治死。</span>
<span className="v" id="v11" data-v="11" data-xref="申命記 27:20; 申命記 27:23; 阿摩司書 2:7"> 與繼母行淫的，就是羞辱了他父親，總要把他們二人治死，罪要歸到他們身上。</span>
<span className="v" id="v12" data-v="12" data-xref="利未記 18:15; 利未記 18:23; 創世記 38:18"> 與兒婦同房的，總要把他們二人治死；他們行了逆倫的事，罪要歸到他們身上。</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多前書 6:9; 利未記 18:22; 猶大書 1:7"> 人若與男人苟合，像與女人一樣，他們二人行了可憎的事，總要把他們治死，罪要歸到他們身上。</span>
<span className="v" id="v14" data-v="14" data-xref="利未記 18:17; 申命記 27:23; 約書亞記 7:15"> 人若娶妻，並娶其母，便是大惡，要把這三人用火焚燒，使你們中間免去大惡。</span>
<span className="v" id="v15" data-v="15" data-xref="利未記 18:23; 申命記 27:21; 出埃及記 22:19"> 人若與獸淫合，總要治死他，也要殺那獸。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及記 21:32; 出埃及記 19:13; 希伯來書 12:20"> 女人若與獸親近，與牠淫合，你要殺那女人和那獸，總要把他們治死，罪要歸到他們身上。</span>
<span className="v" id="v17" data-v="17" data-xref="利未記 18:9; 申命記 27:22; 以西結書 22:11"> 「人若娶他的姊妹，無論是異母同父的，是異父同母的，彼此見了下體，這是可恥的事；他們必在本民的眼前被剪除。他露了姊妹的下體，必擔當自己的罪孽。</span>
<span className="v" id="v18" data-v="18" data-xref="利未記 15:24; 利未記 18:19; 以西結書 18:6"> 婦人有月經，若與她同房，露了她的下體，就是露了婦人的血源，婦人也露了自己的血源，二人必從民中剪除。</span>
<span className="v" id="v19" data-v="19" data-xref="利未記 18:6; 利未記 18:12–30; 出埃及記 6:20"> 不可露姨母或是姑母的下體，這是露了骨肉之親的下體；二人必擔當自己的罪孽。</span>
<span className="v" id="v20" data-v="20" data-xref="利未記 18:14; 約伯記 18:19; 路加福音 23:29"> 人若與伯叔之妻同房，就羞辱了他的伯叔；二人要擔當自己的罪，必無子女而死。</span>
<span className="v" id="v21" data-v="21" data-xref="利未記 18:16; 馬太福音 14:3–4"> 人若娶弟兄之妻，這本是污穢的事，羞辱了他的弟兄；二人必無子女。</span>
<span className="v" id="v22" data-v="22" data-xref="利未記 18:25–28; 以西結書 36:27; 利未記 18:4–5"> 「所以，你們要謹守遵行我一切的律例典章，免得我領你們去住的那地把你們吐出。</span>
<span className="v" id="v23" data-v="23" data-xref="申命記 9:5; 利未記 18:24; 利未記 18:30"> 我在你們面前所逐出的國民，你們不可隨從他們的風俗；因為他們行了這一切的事，所以我厭惡他們。</span>
<span className="v" id="v24" data-v="24" data-xref="申命記 14:2; 出埃及記 6:8; 申命記 7:6"> 但我對你們說過，你們要承受他們的地，就是我要賜給你們為業、流奶與蜜之地。我是耶和華－你們的上帝，使你們與萬民有分別的。</span>
<span className="v" id="v25" data-v="25" data-xref="申命記 14:3–21; 利未記 11:1–47; 使徒行傳 10:11–15"> 所以，你們要把潔淨和不潔淨的禽獸分別出來；不可因我給你們分為不潔淨的禽獸，或是滋生在地上的活物，使自己成為可憎惡的。</span>
<span className="v" id="v26" data-v="26" data-xref="彼得前書 1:15–16; 利未記 20:7; 利未記 20:24"> 你們要歸我為聖，因為我－耶和華是聖的，並叫你們與萬民有分別，使你們作我的民。</span>
<span className="v" id="v27" data-v="27" data-xref="利未記 19:31; 利未記 20:6; 撒母耳記上 28:7–9"> 「無論男女，是交鬼的或行巫術的，總要治死他們。人必用石頭把他們打死，罪要歸到他們身上。」</span>

## 遵行誡命者的福祉

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="利未記 19:4; 申命記 27:15; 民數記 33:52"> 「你們不可做甚麼虛無的神像，不可立雕刻的偶像或是柱像，也不可在你們的地上安甚麼鏨成的石像，向它跪拜，因為我是耶和華－你們的上帝。</span>
<span className="v" id="v2" data-v="2" data-xref="利未記 19:30"> 你們要守我的安息日，敬我的聖所。我是耶和華。</span>
<span className="v" id="v3" data-v="3" data-xref="以賽亞書 1:19; 申命記 11:13–15; 申命記 28:1–14"> 「你們若遵行我的律例，謹守我的誡命，</span>
<span className="v" id="v4" data-v="4" data-xref="撒迦利亞書 8:12; 詩篇 67:6; 利未記 25:21"> 我就給你們降下時雨，叫地生出土產，田野的樹木結果子。</span>
<span className="v" id="v5" data-v="5" data-xref="阿摩司書 9:13; 約珥書 2:26; 約珥書 2:19"> 你們打糧食要打到摘葡萄的時候，摘葡萄要摘到撒種的時候；並且要吃得飽足，在你們的地上安然居住。</span>
<span className="v" id="v6" data-v="6" data-xref="以賽亞書 35:9; 西番雅書 3:13; 詩篇 147:14"> 我要賜平安在你們的地上；你們躺臥，無人驚嚇。我要叫惡獸從你們的地上熄滅；刀劍也必不經過你們的地。</span>
<span className="v" id="v7" data-v="7"> 你們要追趕仇敵，他們必倒在你們刀下。</span>
<span className="v" id="v8" data-v="8" data-xref="約書亞記 23:10; 申命記 28:7; 申命記 32:30"> 你們五個人要追趕一百人，一百人要追趕一萬人；仇敵必倒在你們刀下。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 17:6–7; 尼希米記 9:23; 以西結書 16:62"> 我要眷顧你們，使你們生養眾多，也要與你們堅定所立的約。</span>
<span className="v" id="v10" data-v="10" data-xref="利未記 25:22; 列王紀下 19:29; 路加福音 12:17"> 你們要吃陳糧，又因新糧挪開陳糧。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及記 25:8; 啟示錄 21:3; 出埃及記 29:45"> 我要在你們中間立我的帳幕；我的心也不厭惡你們。</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多後書 6:16; 耶利米書 30:22; 耶利米書 7:23"> 我要在你們中間行走；我要作你們的上帝，你們要作我的子民。</span>
<span className="v" id="v13" data-v="13" data-xref="以西結書 34:27; 利未記 25:38; 詩篇 116:16"> 我是耶和華－你們的上帝，曾將你們從埃及地領出來，使你們不作埃及人的奴僕；我也折斷你們所負的軛，叫你們挺身而走。」</span>
</div>
</div>

## 違反誡命者受懲罰

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="申命記 28:15–68; 利未記 26:18; 耶利米書 17:27"> 「你們若不聽從我，不遵行我的誡命，</span>
<span className="v" id="v15" data-v="15" data-xref="列王紀下 17:15; 申命記 31:16; 撒迦利亞書 7:11–13"> 厭棄我的律例，厭惡我的典章，不遵行我一切的誡命，背棄我的約，</span>
<span className="v" id="v16" data-v="16" data-xref="約伯記 31:8; 耶利米書 5:17; 彌迦書 6:15"> 我待你們就要這樣：我必命定驚惶，叫眼目乾癟、精神消耗的癆病熱病轄制你們。你們也要白白地撒種，因為仇敵要吃你們所種的。</span>
<span className="v" id="v17" data-v="17" data-xref="利未記 17:10; 箴言 28:1; 詩篇 53:5"> 我要向你們變臉，你們就要敗在仇敵面前。恨惡你們的，必轄管你們；無人追趕，你們卻要逃跑。</span>
<span className="v" id="v18" data-v="18" data-xref="利未記 26:21; 利未記 26:28; 利未記 26:24"> 你們因這些事若還不聽從我，我就要為你們的罪加七倍懲罰你們。</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 28:23; 列王紀上 17:1; 但以理書 4:37"> 我必斷絕你們因勢力而有的驕傲，又要使覆你們的天如鐵，載你們的地如銅。</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 127:1; 申命記 11:17; 以賽亞書 49:4"> 你們要白白地勞力；因為你們的地不出土產，其上的樹木也不結果子。</span>
<span className="v" id="v21" data-v="21" data-xref="利未記 26:18; 利未記 26:27"> 「你們行事若與我反對，不肯聽從我，我就要按你們的罪加七倍降災與你們。</span>
<span className="v" id="v22" data-v="22" data-xref="以西結書 14:15; 申命記 32:24; 士師記 5:6"> 我也要打發野地的走獸到你們中間，搶吃你們的兒女，吞滅你們的牲畜，使你們的人數減少，道路荒涼。</span>
<span className="v" id="v23" data-v="23" data-xref="耶利米書 5:3; 耶利米書 2:30; 阿摩司書 4:6–12"> 「你們因這些事若仍不改正歸我，行事與我反對，</span>
<span className="v" id="v24" data-v="24" data-xref="詩篇 18:26; 撒母耳記下 22:27; 約伯記 9:4"> 我就要行事與你們反對，因你們的罪擊打你們七次。</span>
<span className="v" id="v25" data-v="25" data-xref="民數記 14:12; 以西結書 5:17; 耶利米書 29:17–18"> 我又要使刀劍臨到你們，報復你們背約的仇；聚集你們在各城內，降瘟疫在你們中間，也必將你們交在仇敵的手中。</span>
<span className="v" id="v26" data-v="26" data-xref="彌迦書 6:14; 以賽亞書 3:1; 詩篇 105:16"> 我要折斷你們的杖，就是斷絕你們的糧。那時，必有十個女人在一個爐子給你們烤餅，按分量秤給你們；你們要吃，也吃不飽。</span>
<span className="v" id="v27" data-v="27" data-xref="利未記 26:24; 利未記 26:21"> 「你們因這一切的事若不聽從我，卻行事與我反對，</span>
<span className="v" id="v28" data-v="28" data-xref="以賽亞書 59:18; 耶利米書 21:5; 以賽亞書 66:15"> 我就要發烈怒，行事與你們反對，又因你們的罪懲罰你們七次。</span>
<span className="v" id="v29" data-v="29" data-xref="以西結書 5:10; 耶利米哀歌 4:10; 馬太福音 24:19"> 並且你們要吃兒子的肉，也要吃女兒的肉。</span>
<span className="v" id="v30" data-v="30" data-xref="列王紀下 23:20; 以賽亞書 27:9; 以西結書 6:13"> 我又要毀壞你們的邱壇，砍下你們的日像，把你們的屍首扔在你們偶像的身上；我的心也必厭惡你們。</span>
<span className="v" id="v31" data-v="31" data-xref="尼希米記 2:3; 耶利米哀歌 1:10; 希伯來書 10:26"> 我要使你們的城邑變為荒涼，使你們的眾聖所成為荒場；我也不聞你們馨香的香氣。</span>
<span className="v" id="v32" data-v="32" data-xref="耶利米書 9:11; 耶利米書 19:8; 耶利米書 18:16"> 我要使地成為荒場，住在其上的仇敵就因此詫異。</span>
<span className="v" id="v33" data-v="33" data-xref="撒迦利亞書 7:14; 以西結書 20:23; 申命記 28:64–66"> 我要把你們散在列邦中；我也要拔刀追趕你們。你們的地要成為荒場；你們的城邑要變為荒涼。</span>
<span className="v" id="v34" data-v="34" data-xref="歷代志下 36:21; 利未記 26:43; 利未記 25:2–4"> 「你們在仇敵之地居住的時候，你們的地荒涼，要享受眾安息；正在那時候，地要歇息，享受安息。</span>
<span className="v" id="v35" data-v="35" data-xref="以賽亞書 24:5–6; 羅馬書 8:22"> 地多時為荒場，就要多時歇息；地這樣歇息，是你們住在其上的安息年所不能得的。</span>
<span className="v" id="v36" data-v="36" data-xref="以西結書 21:7; 以賽亞書 30:17; 利未記 26:17"> 至於你們剩下的人，我要使他們在仇敵之地心驚膽怯。葉子被風吹的響聲，要追趕他們；他們要逃避，像人逃避刀劍，無人追趕，卻要跌倒。</span>
<span className="v" id="v37" data-v="37" data-xref="約書亞記 7:12–13; 士師記 2:14; 耶利米書 37:10"> 無人追趕，他們要彼此撞跌，像在刀劍之前。你們在仇敵面前也必站立不住。</span>
<span className="v" id="v38" data-v="38" data-xref="申命記 28:48; 以賽亞書 27:13; 耶利米書 42:17–18"> 你們要在列邦中滅亡；仇敵之地要吞吃你們。</span>
<span className="v" id="v39" data-v="39" data-xref="以西結書 4:17; 以西結書 24:23; 以西結書 33:10"> 你們剩下的人必因自己的罪孽和祖宗的罪孽在仇敵之地消滅。</span>
<span className="v" id="v40" data-v="40" data-xref="箴言 28:13; 尼希米記 9:2–5; 約翰一書 1:8–10"> 「他們要承認自己的罪和他們祖宗的罪，就是干犯我的那罪，並且承認自己行事與我反對，</span>
<span className="v" id="v41" data-v="41" data-xref="以西結書 44:7; 歷代志下 32:26; 歷代志下 12:6–7"> 我所以行事與他們反對，把他們帶到仇敵之地。那時，他們未受割禮的心若謙卑了，他們也服了罪孽的刑罰，</span>
<span className="v" id="v42" data-v="42" data-xref="詩篇 106:45; 出埃及記 6:5; 以西結書 16:60"> 我就要記念我與雅各所立的約，與以撒所立的約，與亞伯拉罕所立的約，並要記念這地。</span>
<span className="v" id="v43" data-v="43" data-xref="羅馬書 8:7; 利未記 26:15; 約翰福音 7:7"> 他們離開這地，地在荒廢無人的時候就要享受安息。並且他們要服罪孽的刑罰；因為他們厭棄了我的典章，心中厭惡了我的律例。</span>
<span className="v" id="v44" data-v="44" data-xref="羅馬書 11:2; 尼希米記 9:31; 申命記 4:29–31"> 雖是這樣，他們在仇敵之地，我卻不厭棄他們，也不厭惡他們，將他們盡行滅絕，也不背棄我與他們所立的約，因為我是耶和華－他們的上帝。</span>
<span className="v" id="v45" data-v="45" data-xref="利未記 25:38; 以西結書 20:22; 以西結書 20:9"> 我卻要為他們的緣故記念我與他們先祖所立的約。他們的先祖是我在列邦人眼前、從埃及地領出來的，為要作他們的上帝。我是耶和華。」</span>
<span className="v" id="v46" data-v="46" data-xref="利未記 27:34; 申命記 12:1; 申命記 6:1"> 這些律例、典章，和法度是耶和華與以色列人在西奈山藉着摩西立的。</span>
</div>

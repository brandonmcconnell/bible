## 有關皮膚病的條例

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和華曉諭摩西、亞倫說：</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 24:8; 利未記 14:56; 利未記 14:3"> 「人的肉皮上若長了癤子，或長了癬，或長了火斑，在他肉皮上成了大痲瘋的災病，就要將他帶到祭司亞倫或亞倫作祭司的一個子孫面前。</span>
<span className="v" id="v3" data-v="3" data-xref="羅馬書 3:19–20; 使徒行傳 20:28; 瑪拉基書 2:7"> 祭司要察看肉皮上的災病，若災病處的毛已經變白，災病的現象深於肉上的皮，這便是大痲瘋的災病。祭司要察看他，定他為不潔淨。</span>
<span className="v" id="v4" data-v="4" data-xref="民數記 12:15; 哥林多前書 4:5; 提摩太前書 5:24"> 若火斑在他肉皮上是白的，現象不深於皮，其上的毛也沒有變白，祭司就要將有災病的人關鎖七天。</span>
<span className="v" id="v5" data-v="5"> 第七天，祭司要察看他，若看災病止住了，沒有在皮上發散，祭司還要將他關鎖七天。</span>
<span className="v" id="v6" data-v="6" data-xref="利未記 11:25; 利未記 14:8; 申命記 32:5"> 第七天，祭司要再察看他，若災病發暗，而且沒有在皮上發散，祭司要定他為潔淨，原來是癬；那人就要洗衣服，得為潔淨。</span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 38:3; 利未記 13:35–36; 提摩太後書 2:16–17"> 但他為得潔淨，將身體給祭司察看以後，癬若在皮上發散開了，他要再將身體給祭司察看。</span>
<span className="v" id="v8" data-v="8" data-xref="馬太福音 15:7–8; 腓立比書 3:18–19; 使徒行傳 8:21"> 祭司要察看，癬若在皮上發散，就要定他為不潔淨，是大痲瘋。</span>
<span className="v" id="v9" data-v="9"> 「人有了大痲瘋的災病，就要將他帶到祭司面前。</span>
<span className="v" id="v10" data-v="10" data-xref="列王紀下 5:27; 歷代志下 26:19–20; 利未記 13:14–15"> 祭司要察看，皮上若長了白癤，使毛變白，在長白癤之處有了紅瘀肉，</span>
<span className="v" id="v11" data-v="11"> 這是肉皮上的舊大痲瘋，祭司要定他為不潔淨，不用將他關鎖，因為他是不潔淨了。</span>
<span className="v" id="v12" data-v="12" data-xref="約翰一書 1:8–10; 約伯記 42:6; 羅馬書 7:14"> 大痲瘋若在皮上四外發散，長滿了患災病人的皮，據祭司察看，從頭到腳無處不有，</span>
<span className="v" id="v13" data-v="13" data-xref="約翰福音 9:41; 以賽亞書 64:6"> 祭司就要察看，全身的肉若長滿了大痲瘋，就要定那患災病的為潔淨；全身都變為白，他乃潔淨了。</span>
<span className="v" id="v14" data-v="14"> 但紅肉幾時顯在他的身上就幾時不潔淨。</span>
<span className="v" id="v15" data-v="15"> 祭司一看那紅肉就定他為不潔淨。紅肉本是不潔淨，是大痲瘋。</span>
<span className="v" id="v16" data-v="16" data-xref="加拉太書 1:14–16; 羅馬書 7:14–24; 腓立比書 3:6–8"> 紅肉若復原，又變白了，他就要來見祭司。</span>
<span className="v" id="v17" data-v="17"> 祭司要察看，災病處若變白了，祭司就要定那患災病的為潔淨，他乃潔淨了。</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及記 9:9; 以賽亞書 38:21; 詩篇 38:3–7"> 「人若在皮肉上長瘡，卻治好了，</span>
<span className="v" id="v19" data-v="19" data-xref="利未記 13:24"> 在長瘡之處又起了白癤，或是白中帶紅的火斑，就要給祭司察看。</span>
<span className="v" id="v20" data-v="20" data-xref="約翰福音 5:14; 利未記 13:3; 彼得後書 2:20"> 祭司要察看，若現象窪於皮，其上的毛也變白了，就要定他為不潔淨，是大痲瘋的災病發在瘡中。</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多前書 5:5"> 祭司若察看，其上沒有白毛，也沒有窪於皮，乃是發暗，就要將他關鎖七天。</span>
<span className="v" id="v22" data-v="22"> 若在皮上發散開了，祭司就要定他為不潔淨，是災病。</span>
<span className="v" id="v23" data-v="23" data-xref="加拉太書 6:1; 約伯記 34:31–32; 馬太福音 26:75"> 火斑若在原處止住，沒有發散，便是瘡的痕跡，祭司就要定他為潔淨。</span>
<span className="v" id="v24" data-v="24" data-xref="以賽亞書 3:24"> 「人的皮肉上若起了火毒，火毒的瘀肉成了火斑，或是白中帶紅的，或是全白的，</span>
<span className="v" id="v25" data-v="25" data-xref="利未記 13:18–20; 利未記 13:4"> 祭司就要察看，火斑中的毛若變白了，現象又深於皮，是大痲瘋在火毒中發出，就要定他為不潔淨，是大痲瘋的災病。</span>
<span className="v" id="v26" data-v="26" data-xref="利未記 13:23; 利未記 13:4–5"> 但是祭司察看，在火斑中若沒有白毛，也沒有窪於皮，乃是發暗，就要將他關鎖七天。</span>
<span className="v" id="v27" data-v="27"> 到第七天，祭司要察看他，火斑若在皮上發散開了，就要定他為不潔淨，是大痲瘋的災病。</span>
<span className="v" id="v28" data-v="28"> 火斑若在原處止住，沒有在皮上發散，乃是發暗，是起的火毒，祭司要定他為潔淨，不過是火毒的痕跡。</span>
<span className="v" id="v29" data-v="29" data-xref="以賽亞書 9:15; 馬太福音 13:14–15; 哥林多後書 4:3–4"> 「無論男女，若在頭上有災病，或是男人鬍鬚上有災病，</span>
<span className="v" id="v30" data-v="30" data-xref="利未記 13:34–37; 利未記 14:54"> 祭司就要察看；這災病現象若深於皮，其間有細黃毛，就要定他為不潔淨，這是頭疥，是頭上或是鬍鬚上的大痲瘋。</span>
<span className="v" id="v31" data-v="31"> 祭司若察看頭疥的災病，現象不深於皮，其間也沒有黑毛，就要將長頭疥災病的關鎖七天。</span>
<span className="v" id="v32" data-v="32" data-xref="利未記 13:30; 馬太福音 23:5; 路加福音 18:9–12"> 第七天，祭司要察看災病，若頭疥沒有發散，其間也沒有黃毛，頭疥的現象不深於皮，</span>
<span className="v" id="v33" data-v="33"> 那人就要剃去鬚髮，但他不可剃頭疥之處。祭司要將那長頭疥的，再關鎖七天。</span>
<span className="v" id="v34" data-v="34" data-xref="猶大書 1:22; 約翰一書 4:1; 啟示錄 2:2"> 第七天，祭司要察看頭疥，頭疥若沒有在皮上發散，現象也不深於皮，就要定他為潔淨，他要洗衣服，便成為潔淨。</span>
<span className="v" id="v35" data-v="35" data-xref="利未記 13:27; 提摩太後書 2:16–17; 利未記 13:7"> 但他得潔淨以後，頭疥若在皮上發散開了，</span>
<span className="v" id="v36" data-v="36"> 祭司就要察看他。頭疥若在皮上發散，就不必找那黃毛，他是不潔淨了。</span>
<span className="v" id="v37" data-v="37"> 祭司若看頭疥已經止住，其間也長了黑毛，頭疥已然痊癒，那人是潔淨了，就要定他為潔淨。</span>
<span className="v" id="v38" data-v="38"> 「無論男女，皮肉上若起了火斑，就是白火斑，</span>
<span className="v" id="v39" data-v="39" data-xref="羅馬書 7:22–25; 雅各書 3:2; 傳道書 7:20"> 祭司就要察看，他們肉皮上的火斑若白中帶黑，這是皮上發出的白癬，那人是潔淨了。</span>
<span className="v" id="v40" data-v="40" data-xref="加拉太書 4:13; 羅馬書 8:10; 雅歌 5:11"> 「人頭上的髮若掉了，他不過是頭禿，還是潔淨。</span>
<span className="v" id="v41" data-v="41"> 他頂前若掉了頭髮，他不過是頂門禿，還是潔淨。</span>
<span className="v" id="v42" data-v="42"> 頭禿處或是頂門禿處若有白中帶紅的災病，這就是大痲瘋發在他頭禿處或是頂門禿處，</span>
<span className="v" id="v43" data-v="43"> 祭司就要察看，他起的那災病若在頭禿處或是頂門禿處有白中帶紅的，像肉皮上大痲瘋的現象，</span>
<span className="v" id="v44" data-v="44" data-xref="彼得後書 2:1–2; 馬太福音 6:23; 以賽亞書 1:5"> 那人就是長大痲瘋，不潔淨的，祭司總要定他為不潔淨，他的災病是在頭上。</span>
<span className="v" id="v45" data-v="45" data-xref="彌迦書 3:7; 利未記 10:6; 以西結書 24:17"> 「身上有長大痲瘋災病的，他的衣服要撕裂，也要蓬頭散髮，蒙着上唇，喊叫說：『不潔淨了！不潔淨了！』</span>
<span className="v" id="v46" data-v="46" data-xref="列王紀下 7:3; 列王紀下 15:5; 歷代志下 26:21"> 災病在他身上的日子，他便是不潔淨；他既是不潔淨，就要獨居營外。」</span>
</div>

## 衣物發霉的條例

<div className="bt">
<div className="bp">
<span className="v" id="v47" data-v="47" data-xref="猶大書 1:23; 羅馬書 13:12; 以西結書 16:16"> 「染了大痲瘋災病的衣服，無論是羊毛衣服、是麻布衣服，</span>
<span className="v" id="v48" data-v="48" data-xref="利未記 13:51; 啟示錄 3:4; 申命記 8:11"> 無論是在經上、在緯上，是麻布的、是羊毛的，是在皮子上，或在皮子做的甚麼物件上，</span>
<span className="v" id="v49" data-v="49"> 或在衣服上、皮子上，經上、緯上，或在皮子做的甚麼物件上，這災病若是發綠，或是發紅，是大痲瘋的災病，要給祭司察看。</span>
<span className="v" id="v50" data-v="50" data-xref="以西結書 44:23"> 祭司就要察看那災病，把染了災病的物件關鎖七天。</span>
<span className="v" id="v51" data-v="51" data-xref="利未記 14:44"> 第七天，他要察看那災病，災病或在衣服上，經上、緯上，皮子上，若發散，這皮子無論當作何用，這災病是蠶食的大痲瘋，都是不潔淨了。</span>
<span className="v" id="v52" data-v="52" data-xref="利未記 11:35; 利未記 11:33; 利未記 14:44–45"> 那染了災病的衣服，或是經上、緯上，羊毛上，麻衣上，或是皮子做的甚麼物件上，他都要焚燒；因為這是蠶食的大痲瘋，必在火中焚燒。</span>
<span className="v" id="v53" data-v="53"> 「祭司要察看，若災病在衣服上，經上、緯上，或是皮子做的甚麼物件上，沒有發散，</span>
<span className="v" id="v54" data-v="54"> 祭司就要吩咐他們，把染了災病的物件洗了，再關鎖七天。</span>
<span className="v" id="v55" data-v="55" data-xref="以西結書 24:13; 希伯來書 6:4–8; 彼得後書 2:20–22"> 洗過以後，祭司要察看，那物件若沒有變色，災病也沒有消散，那物件就不潔淨，是透重的災病，無論正面反面，都要在火中焚燒。</span>
<span className="v" id="v56" data-v="56"> 洗過以後，祭司要察看，若見那災病發暗，他就要把那災病從衣服上，皮子上，經上、緯上，都撕去。</span>
<span className="v" id="v57" data-v="57" data-xref="馬太福音 22:7; 啟示錄 21:8; 馬太福音 3:12"> 若仍現在衣服上，或是經上、緯上、皮子做的甚麼物件上，這就是災病又發了，必用火焚燒那染災病的物件。</span>
<span className="v" id="v58" data-v="58" data-xref="列王紀下 5:14; 啟示錄 1:5; 詩篇 51:2"> 所洗的衣服，或是經，或是緯，或是皮子做的甚麼物件，若災病離開了，要再洗，就潔淨了。」</span>
<span className="v" id="v59" data-v="59"> 這就是大痲瘋災病的條例，無論是在羊毛衣服上，麻布衣服上，經上、緯上，和皮子做的甚麼物件上，可以定為潔淨或是不潔淨。</span>

<span className="v" id="v2" data-v="2" data-xref="ÖZDEYİŞLER 8:35; ELÇİLERİN İŞLERİ 11:24; MEZMURLAR 112:5"> <span className="pl pl-1">İyi insan Yahve'den lütuf bulur,</span><br /><span className="pl pl-2">ama O, kötü niyetleri olan insanı mahkûm eder.</span></span>

<span className="v" id="v4" data-v="4" data-xref="ÖZDEYİŞLER 14:30; ÖZDEYİŞLER 31:10–25; ÖZDEYİŞLER 14:1"> <span className="pl pl-1">Değerli kadın kocasının tacıdır,</span><br /><span className="pl pl-2">ama utandıran kadın onun kemiklerindeki çürük gibidir.</span></span>
<span className="v" id="v5" data-v="5" data-xref="MEZMURLAR 139:23; YEŞAYA 55:7; MEZMURLAR 140:1–3"> <span className="pl pl-1">Doğruların düşünceleri adildir,</span><br /><span className="pl pl-2">ama kötülerin öğüdü aldatıcıdır.</span></span>
<span className="v" id="v6" data-v="6" data-xref="ÖZDEYİŞLER 14:3; YEREMYA 5:26; ÖZDEYİŞLER 1:11–19"> <span className="pl pl-1">Kötülerin sözleri kan için pusuya yatmaktır,</span><br /><span className="pl pl-2">ama doğruların konuşması onları kurtarır.</span></span>
<span className="v" id="v7" data-v="7" data-xref="MATTA 7:24–27; ÖZDEYİŞLER 11:21; ÖZDEYİŞLER 10:25"> <span className="pl pl-1">Kötüler yıkılır ve yok olur,</span><br /><span className="pl pl-2">ama doğruların evi ayakta kalır.</span></span>
<span className="v" id="v8" data-v="8" data-xref="2. KORİNTLİLER 10:18; 1. KORİNTLİLER 4:5; 1. KORİNTLİLER 3:10–15"> <span className="pl pl-1">İnsan bilgeliğine göre övülür,</span><br /><span className="pl pl-2">ancak çarpık zihniyetli kişi küçümsenir.</span></span>
<span className="v" id="v9" data-v="9" data-xref="LUKA 14:11; ÖZDEYİŞLER 13:7"> <span className="pl pl-1">Az tanınıp bir hizmetçisi olan kişi,</span><br /><span className="pl pl-2">kendini onurlandırıp ekmeği olmayandan daha iyidir.</span></span>
<span className="v" id="v10" data-v="10" data-xref="YASA'NIN TEKRARI 25:4; YARATILIŞ 33:13–14; SAYILAR 22:28–32"> <span className="pl pl-1">Doğru kişi hayvanının canına saygı duyar,</span><br /><span className="pl pl-2">ama kötünün sevecen merhameti zalimdir.</span></span>
<span className="v" id="v11" data-v="11" data-xref="ÖZDEYİŞLER 28:19; ÖZDEYİŞLER 14:23; 1. SELANİKLİLER 4:11–12"> <span className="pl pl-1">Toprağını işleyenin bol ekmeği olur,</span><br /><span className="pl pl-2">ama hayaller peşinde koşan anlayıştan yoksundur.</span></span>
<span className="v" id="v12" data-v="12" data-xref="YEREMYA 17:7–8; YUHANNA 15:5; LUKA 8:13–15"> <span className="pl pl-1">Kötüler kötülerin ganimetini arzular,</span><br /><span className="pl pl-2">ama doğruların kökü gelişir.</span></span>
<span className="v" id="v13" data-v="13" data-xref="ÖZDEYİŞLER 21:23; ÖZDEYİŞLER 11:8; MEZMURLAR 64:8"> <span className="pl pl-1">Kötü kişi dudaklarının günahıyla kapana kıstırılır,</span><br /><span className="pl pl-2">ama doğru kişi sıkıntıdan kurtulur.</span></span>
<span className="v" id="v14" data-v="14" data-xref="ÖZDEYİŞLER 18:20–21; YEŞAYA 3:10–11; ÖZDEYİŞLER 13:2"> <span className="pl pl-1">İnsan ağzının meyvesiyle iyiliğe doyar.</span><br /><span className="pl pl-2">Ellerinin işine göre insan ödüllendirilir.</span></span>
<span className="v" id="v15" data-v="15" data-xref="ÖZDEYİŞLER 3:7; ÖZDEYİŞLER 26:12; ÖZDEYİŞLER 14:16"> <span className="pl pl-1">Akılsızın yolu kendi gözünde doğrudur,</span><br /><span className="pl pl-2">ama bilge kişi öğüdü dinler.</span></span>
<span className="v" id="v16" data-v="16" data-xref="ÖZDEYİŞLER 29:11; YAKOV 1:19; ÖZDEYİŞLER 10:12"> <span className="pl pl-1">Akılsız öfkesini aynı gün belli eder,</span><br /><span className="pl pl-2">ama hakareti görmezden gelen kişi sağduyuludur.</span></span>
<span className="v" id="v17" data-v="17" data-xref="ÖZDEYİŞLER 14:5; ÖZDEYİŞLER 14:25; ÖZDEYİŞLER 24:28"> <span className="pl pl-1">Doğru sözlü dürüstçe tanıklık eder,</span><br /><span className="pl pl-2">ama yalancı tanık yalan söyler.</span></span>
<span className="v" id="v18" data-v="18" data-xref="ÖZDEYİŞLER 16:24; ÖZDEYİŞLER 15:4; MEZMURLAR 57:4"> <span className="pl pl-1">İnsan var ki, düşünmeden delip geçen kılıç gibi konuşur,</span><br /><span className="pl pl-2">ama bilgelerin dili şifa verir.</span></span>
<span className="v" id="v19" data-v="19" data-xref="ÖZDEYİŞLER 19:9; MEZMURLAR 52:4–5; İYOV 20:5"> <span className="pl pl-1">Gerçeğin dudakları daima durur,</span><br /><span className="pl pl-2">ama yalancı dil yalnızca geçicidir.</span></span>
<span className="v" id="v20" data-v="20" data-xref="MATTA 5:9; 1. PETRUS 3:8–13; ÖZDEYİŞLER 12:12"> <span className="pl pl-1">Hile kötülük tasarlayanların yüreğindedir,</span><br /><span className="pl pl-2">ama esenliği destekleyene sevinç gelir.</span></span>
<span className="v" id="v21" data-v="21" data-xref="1. PETRUS 3:13; MEZMURLAR 91:10; ROMALILAR 8:28"> <span className="pl pl-1">Doğruya hiç zarar gelmez,</span><br /><span className="pl pl-2">ama kötüler kötülükle dolar.</span></span>
<span className="v" id="v22" data-v="22" data-xref="MEZMURLAR 5:6; ÖZDEYİŞLER 11:20; VAHİY 22:15"> <span className="pl pl-1">Yalancı dudaklar Yahve için iğrençtir,</span><br /><span className="pl pl-2">ama gerçeğe uyanlar O'nun sevincidir.</span></span>

<span className="v" id="v24" data-v="24" data-xref="ÖZDEYİŞLER 12:27; ÖZDEYİŞLER 10:4; ÖZDEYİŞLER 21:25–26"> <span className="pl pl-1">Çalışkanların elleri yönetir,</span><br /><span className="pl pl-2">ama tembellik kölelikle sonuçlanır.</span></span>
<span className="v" id="v25" data-v="25" data-xref="ÖZDEYİŞLER 16:24; ÖZDEYİŞLER 15:13; ÖZDEYİŞLER 17:22"> <span className="pl pl-1">Yüreğindeki kaygı insanı çökertir,</span><br /><span className="pl pl-2">ama hoş söz onun yüreğini sevindirir.</span></span>
<span className="v" id="v26" data-v="26" data-xref="1. YUHANNA 2:26; MATTA 5:46–48; ÖZDEYİŞLER 17:27"> <span className="pl pl-1">Doğru kişi dostluk konusunda dikkatlidir,</span><br /><span className="pl pl-2">ama kötülerin yolu onları saptırır.</span></span>
<span className="v" id="v27" data-v="27" data-xref="ÖZDEYİŞLER 13:4; ÖZDEYİŞLER 26:15; ÖZDEYİŞLER 15:16"> <span className="pl pl-1">Tembel kişi avını pişirmez,</span><br /><span className="pl pl-2">ama çalışkanların malları değerlidir.</span></span>
<span className="v" id="v28" data-v="28" data-xref="3. YUHANNA 1:11; ROMALILAR 5:21; HEZEKİEL 18:20–24"> <span className="pl pl-1">Doğruluğun yolu hayattır,</span><br /><span className="pl pl-2">onun yolunda ölüm yoktur.</span></span>

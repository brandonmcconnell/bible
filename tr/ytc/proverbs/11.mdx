<span className="v" id="v2" data-v="2" data-xref="ÖZDEYİŞLER 29:23; ÖZDEYİŞLER 15:33; ÖZDEYİŞLER 16:18–19"> <span className="pl pl-1">Gurur gelince ardından utanç gelir,</span><br /><span className="pl pl-2">ama alçakgönüllülükle bilgelik gelir.</span></span>
<span className="v" id="v3" data-v="3" data-xref="ÖZDEYİŞLER 13:6; ÖZDEYİŞLER 28:18; MEZMURLAR 26:1"> <span className="pl pl-1">Doğruların dürüstlüğü onlara yol gösterir,</span><br /><span className="pl pl-2">ama hainlerin sapkınlığı onları yok eder.</span></span>
<span className="v" id="v4" data-v="4" data-xref="SEFENYA 1:18; ÖZDEYİŞLER 10:2; YARATILIŞ 7:1"> <span className="pl pl-1">Gazap gününde zenginlik fayda getirmez,</span><br /><span className="pl pl-2">ama doğruluk ölümden kurtarır.</span></span>
<span className="v" id="v5" data-v="5" data-xref="ÖZDEYİŞLER 5:22; MEZMURLAR 9:15–16; ÖZDEYİŞLER 1:31–32"> <span className="pl pl-1">Masumun doğruluğu ona yol gösterir,</span><br /><span className="pl pl-2">ama kötü kişi kendi kötülüğüyle düşer.</span></span>
<span className="v" id="v6" data-v="6" data-xref="VAİZ 10:8; 1. KRALLAR 2:44; MEZMURLAR 7:15–16"> <span className="pl pl-1">Doğruların dürüstlüğü onları kurtarır,</span><br /><span className="pl pl-2">ama sadık olmayan kişi kötü arzular tarafından tuzağa düşürülür.</span></span>
<span className="v" id="v7" data-v="7" data-xref="ÖZDEYİŞLER 10:28; İYOV 8:13–14; İYOV 11:20"> <span className="pl pl-1">Kötü kişi öldüğünde umut yok olur,</span><br /><span className="pl pl-2">güç beklentisi ise boşa çıkar.</span></span>
<span className="v" id="v8" data-v="8" data-xref="DANİEL 6:23–24; ÖZDEYİŞLER 21:18; ESTER 7:9–10"> <span className="pl pl-1">Doğru kişi sıkıntıdan kurtulur,</span><br /><span className="pl pl-2">onun yerini kötüler alır.</span></span>
<span className="v" id="v9" data-v="9" data-xref="ÖZDEYİŞLER 2:10–16; ÖZDEYİŞLER 4:5–6; 1. YUHANNA 2:27"> <span className="pl pl-1">Tanrısız kişi ağzıyla komşusunu yok eder,</span><br /><span className="pl pl-2">ama doğrular bilgi sayesinde kurtulur.</span></span>
<span className="v" id="v10" data-v="10" data-xref="ÖZDEYİŞLER 28:12; ESTER 8:15–16; MEZMURLAR 58:10–11"> <span className="pl pl-1">Doğruların işi yolunda gittiğinde kent sevinir.</span><br /><span className="pl pl-2">Kötüler yok edilince bağrış vardır.</span></span>
<span className="v" id="v11" data-v="11" data-xref="ÖZDEYİŞLER 14:34; ÖZDEYİŞLER 29:8; YAKOV 3:6"> <span className="pl pl-1">Dürüstlerin bereketiyle kent yükselir,</span><br /><span className="pl pl-2">ama kötülerin ağzıyla kent yıkılır.</span></span>
<span className="v" id="v12" data-v="12" data-xref="ÖZDEYİŞLER 10:19; 1. PETRUS 2:23; LUKA 18:9"> <span className="pl pl-1">Komşusunu küçümseyen bilgelikten yoksundur,</span><br /><span className="pl pl-2">anlayışlı kişi esenliğini korur.</span></span>
<span className="v" id="v13" data-v="13" data-xref="ÖZDEYİŞLER 20:19; ÖZDEYİŞLER 25:9; LEVİLİLER 19:16"> <span className="pl pl-1">Dedikodu getiren kişi güvene ihanet eder,</span><br /><span className="pl pl-2">güvenilir ruhlu kişi sır saklayandır.</span></span>
<span className="v" id="v14" data-v="14" data-xref="ÖZDEYİŞLER 24:6; ÖZDEYİŞLER 15:22; ÖZDEYİŞLER 20:18"> <span className="pl pl-1">Bilgece rehberliğin olmadığı yerde ulus düşer,</span><br /><span className="pl pl-2">ama öğüt verenlerin çokluğunda zafer vardır.</span></span>
<span className="v" id="v15" data-v="15" data-xref="ÖZDEYİŞLER 17:18; ÖZDEYİŞLER 6:1–5; ÖZDEYİŞLER 22:26–27"> <span className="pl pl-1">Yabancı birine kefil olan kişi bunun acısını çeker,</span><br /><span className="pl pl-2">teminat vermeyi reddeden kişi güvendedir.</span></span>
<span className="v" id="v16" data-v="16" data-xref="ÖZDEYİŞLER 31:30–31; LUKA 10:42; ELÇİLERİN İŞLERİ 16:14–15"> <span className="pl pl-1">Merhametli kadın onur kazanır,</span><br /><span className="pl pl-2">ama zorba erkekler zenginlik kazanır.</span></span>
<span className="v" id="v17" data-v="17" data-xref="MATTA 5:7; MATTA 25:34–40; YAKOV 2:13"> <span className="pl pl-1">Merhametli kişi kendi canına iyilik eder,</span><br /><span className="pl pl-2">ama gaddar olan kendi bedenine sıkıntı verir.</span></span>
<span className="v" id="v18" data-v="18" data-xref="GALATYALILAR 6:8–9; VAİZ 10:8; HOŞEA 10:12–13"> <span className="pl pl-1">Kötü kişi aldatıcı ücret kazanır,</span><br /><span className="pl pl-2">ama doğruluk eken sağlam bir ödül biçer.</span></span>
<span className="v" id="v19" data-v="19" data-xref="ÖZDEYİŞLER 10:16; ROMALILAR 2:8–9; ÖZDEYİŞLER 12:28"> <span className="pl pl-1">İçtenlikle doğru olan yaşam elde eder.</span><br /><span className="pl pl-2">Kötülüğün peşinde olan ölüm elde eder.</span></span>
<span className="v" id="v20" data-v="20" data-xref="MEZMURLAR 119:1; ÖZDEYİŞLER 21:29; 1. TARİHLER 29:17"> <span className="pl pl-1">Yürekte sapkın olanlar Yahve için iğrençtir,</span><br /><span className="pl pl-2">ama yolları kusursuz olanlar O'nun sevincidir.</span></span>
<span className="v" id="v21" data-v="21" data-xref="MEZMURLAR 112:1–2; ELÇİLERİN İŞLERİ 2:39; YEREMYA 32:39"> <span className="pl pl-1">Kesinlikle kötü kişi cezasız kalmaz,</span><br /><span className="pl pl-2">ama doğruların soyu</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="veya tohum">a</a></sup><br /><span className="pl pl-2">kurtulur.</span></span>
<span className="v" id="v22" data-v="22" data-xref="1. PETRUS 3:3–4; ÖZDEYİŞLER 31:30; NAHUM 3:4–6"> <span className="pl pl-1">Domuzun burnunda altın halka neyse,</span><br /><span className="pl pl-2">sağduyudan yoksun olan güzel kadın da öyledir.</span></span>
<span className="v" id="v23" data-v="23" data-xref="MEZMURLAR 37:4; ROMALILAR 2:8–9; MATTA 5:6"> <span className="pl pl-1">Doğru insanın dileği yalnızca iyiliktir.</span><br /><span className="pl pl-2">Kötülerin beklentisi gazaptır.</span></span>
<span className="v" id="v24" data-v="24" data-xref="ÖZDEYİŞLER 19:17; LUKA 6:38; YASA'NIN TEKRARI 15:10"> <span className="pl pl-1">Dağıtan ve daha da artıran birisi vardır.</span><br /><span className="pl pl-2">Uygun olandan fazlasını alıkoyan ama yoksullaşan birisi vardır.</span></span>
<span className="v" id="v25" data-v="25" data-xref="MATTA 5:7; 2. KORİNTLİLER 9:6–9; YEŞAYA 58:7–11"> <span className="pl pl-1">Özgür can semiz olur.</span><br /><span className="pl pl-2">Sulayanın kendisi de sulanacaktır.</span></span>

<span className="v" id="v27" data-v="27" data-xref="MEZMURLAR 7:15–16; ÖZDEYİŞLER 17:11; MEZMURLAR 9:15–16"> <span className="pl pl-1">İyiliği özenle arayan lütuf arar,</span><br /><span className="pl pl-2">ama kötülüğü araştıranın kendisine kötülük gelir.</span></span>
<span className="v" id="v28" data-v="28" data-xref="1. TİMOTEOS 6:17; YEREMYA 17:8; MEZMURLAR 52:7–8"> <span className="pl pl-1">Zenginliğine güvenen düşer,</span><br /><span className="pl pl-2">ama doğrular yeşil yaprak gibi gelişir.</span></span>
<span className="v" id="v29" data-v="29" data-xref="VAİZ 5:16; ÖZDEYİŞLER 14:19; ÖZDEYİŞLER 15:27"> <span className="pl pl-1">Kendi evini sıkıntıya sokanın mirası yeldir.</span><br /><span className="pl pl-2">Akılsız kişi yüreği bilge olanın hizmetkârı olur.</span></span>
<span className="v" id="v30" data-v="30" data-xref="DANİEL 12:3; YAKOV 5:20; 1. KORİNTLİLER 9:19–23"> <span className="pl pl-1">Doğrunun meyvesi yaşam ağacıdır.</span><br /><span className="pl pl-2">Bilge kişi canlar kazanır.</span></span>
<span className="v" id="v31" data-v="31" data-xref="1. PETRUS 4:17–18; YEREMYA 25:29; 1. KORİNTLİLER 11:30–32"> <span className="pl pl-1">İşte, yeryüzünde doğrulardan hesabı soruluyor,</span><br /><span className="pl pl-2">kötülerle günahkarlardan ne kadar daha çok sorulacak!</span></span>

<span className="v" id="v1" data-v="1" data-xref="Efezským 4:24; Koloským 3:10; 1 Mojžíšova 1:26–27"> Tato jest kniha rodů Adamových. V ten den, v kterémž stvořil Bůh člověka, ku podobenství Božímu učinil ho.</span>
<span className="v" id="v2" data-v="2" data-xref="Matouš 19:4; Marek 10:6; 1 Mojžíšova 2:23"> Muže a ženu stvořil je a požehnal jim, a nazval jméno jejich Adam v ten den, když stvořeni jsou.</span>
<span className="v" id="v3" data-v="3" data-xref="1 Mojžíšova 4:25; Jób 25:4; Žalmy 51:5"> Byl pak Adam ve stu a třidcíti letech, když zplodil syna ku podobenství svému a k obrazu svému, a nazval jméno jeho Set.</span>
<span className="v" id="v4" data-v="4" data-xref="1 Letopisu 1:1–3; Lukáš 3:36–38; 1 Mojžíšova 5:26"> I bylo dnů Adamových po zplození Seta osm set let, a plodil syny a dcery.</span>
<span className="v" id="v5" data-v="5" data-xref="1 Mojžíšova 5:8; 1 Mojžíšova 5:11; 1 Mojžíšova 3:19"> A tak bylo všech dnů Adamových, v kterýchž byl živ, devět set a třidceti let, i umřel.</span>
<span className="v" id="v6" data-v="6" data-xref="1 Mojžíšova 4:26"> Set pak byl ve stu a pěti letech, když zplodil Enosa.</span>
<span className="v" id="v7" data-v="7"> A po zplození Enosa živ byl Set osm set a sedm let, a plodil syny a dcery.</span>
<span className="v" id="v8" data-v="8"> I bylo všech dnů Setových devět set a dvanácte let, i umřel.</span>
<span className="v" id="v9" data-v="9" data-xref="Lukáš 3:37; 1 Letopisu 1:2"> Byl pak Enos v devadesáti letech, když zplodil Kainana.</span>
<span className="v" id="v10" data-v="10"> A po zplození Kainana živ byl Enos osm set a patnácte let, a plodil syny a dcery.</span>
<span className="v" id="v11" data-v="11"> I bylo všech dnů Enosových devět set a pět let, i umřel.</span>
<span className="v" id="v12" data-v="12" data-xref="Lukáš 3:37"> Kainan pak byl v sedmdesáti letech, když zplodil Mahalaleele.</span>
<span className="v" id="v13" data-v="13"> A po zplození Mahalaleele živ byl Kainan osm set a čtyřidceti let, a plodil syny a dcery.</span>
<span className="v" id="v14" data-v="14"> I bylo všech dnů Kainanových devět set a deset let, i umřel.</span>
<span className="v" id="v15" data-v="15" data-xref="1 Letopisu 1:2"> Mahalaleel pak byl v šedesáti a pěti letech, když zplodil Járeda.</span>
<span className="v" id="v16" data-v="16"> A po zplození Járeda živ byl Mahalaleel osm set a třidceti let, a plodil syny a dcery.</span>
<span className="v" id="v17" data-v="17"> I bylo všech dnů Mahalaleelových osm set devadesáte a pět let, i umřel.</span>
<span className="v" id="v18" data-v="18" data-xref="1 Mojžíšova 4:17; 1 Letopisu 1:3; Judův 1:14–15"> Járed pak byl ve stu šedesáti a dvou letech, když zplodil Enocha.</span>
<span className="v" id="v19" data-v="19"> A po zplození Enocha živ byl Járed osm set let, a plodil syny a dcery.</span>
<span className="v" id="v20" data-v="20"> I bylo všech dnů Járedových devět set šedesáte a dvě létě, i umřel.</span>
<span className="v" id="v21" data-v="21" data-xref="Lukáš 3:37"> Enoch pak byl v šedesáti a pěti letech, když zplodil Matuzaléma.</span>
<span className="v" id="v22" data-v="22" data-xref="1 Tesalonickým 2:12; 1 Mojžíšova 17:1; 1 Mojžíšova 6:9"> A chodil Enoch stále s Bohem po zplození Matuzaléma tři sta let, a plodil syny a dcery.</span>
<span className="v" id="v23" data-v="23"> I bylo všech dnů Enochových tři sta šedesáte a pět let.</span>
<span className="v" id="v24" data-v="24" data-xref="Židům 11:5–6; 1 Janův 1:7; 1 Mojžíšova 5:22"> A chodil Enoch stále s Bohem a nebyl více vidín; nebo vzal ho Bůh.</span>
<span className="v" id="v25" data-v="25" data-xref="1 Mojžíšova 4:18"> Matuzalém pak byl ve stu osmdesáti sedmi letech, když zplodil Lámecha.</span>
<span className="v" id="v26" data-v="26"> A po zplození Lámecha živ byl Matuzalém sedm set osmdesáte a dvě létě, a plodil syny a dcery.</span>
<span className="v" id="v27" data-v="27"> I bylo všech dnů Matuzalémových devět set šedesáte a devět let, i umřel.</span>
<span className="v" id="v28" data-v="28"> Lámech pak byl ve stu osmdesáti a dvou letech, když zplodil syna,</span>
<span className="v" id="v29" data-v="29" data-xref="2 Petrův 2:5; Židům 11:7; Matouš 24:37"> Jehož jméno nazval Noé, řka: Tento nám odpočinutí způsobí od díla našeho, od práce rukou našich, kterouž máme s zemí, jížto zlořečil Hospodin.</span>
<span className="v" id="v30" data-v="30"> A živ byl Lámech potom, když zplodil Noé, pět set devadesáte a pět let, a plodil syny a dcery.</span>
<span className="v" id="v31" data-v="31"> I bylo všech dnů Lámechových sedm set sedmdesáte a sedm let, i umřel.</span>
<span className="v" id="v32" data-v="32" data-xref="1 Mojžíšova 6:10; 1 Mojžíšova 10:21; 1 Mojžíšova 9:18–19"> A když byl Noé v pěti stech letech, zplodil Sema, Chama a Jáfeta.</span>

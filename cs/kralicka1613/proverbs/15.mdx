<span className="v" id="v1" data-v="1" data-xref="Přísloví 10:12; Přísloví 25:15; Přísloví 15:18"> Odpověd měkká odvracuje hněv, ale řeč zpurná vzbuzuje prchlivost.</span>
<span className="v" id="v2" data-v="2" data-xref="Přísloví 12:23; Přísloví 15:28; Přísloví 13:16"> Jazyk moudrých ozdobuje umění, ale ústa bláznů vylévají bláznovství.</span>
<span className="v" id="v3" data-v="3" data-xref="Židům 4:13; Jeremjáš 16:17; Jeremjáš 23:24"> Na všelikém místě oči Hospodinovy spatřují zlé i dobré.</span>
<span className="v" id="v4" data-v="4" data-xref="Přísloví 12:18; Přísloví 16:24; Přísloví 18:8"> Zdravý jazyk jest strom života, převrácenost pak z něho ztroskotání od větru.</span>
<span className="v" id="v5" data-v="5" data-xref="Přísloví 15:31–32; Přísloví 13:1; Přísloví 13:18"> Blázen pohrdá cvičením otce svého, ale kdož ostříhá naučení, opatrnosti nabude.</span>
<span className="v" id="v6" data-v="6" data-xref="Přísloví 8:21; Přísloví 21:20; Přísloví 10:22"> V domě spravedlivého jest hojnost veliká, ale v úrodě bezbožného zmatek.</span>
<span className="v" id="v7" data-v="7" data-xref="Matouš 12:34; Jakubův 3:6; Efezským 4:29"> Rtové moudrých rozsívají umění, srdce pak bláznů ne tak.</span>
<span className="v" id="v8" data-v="8" data-xref="Přísloví 15:29; Přísloví 21:27; 1 Letopisu 29:17"> Obět bezbožných ohavností jest Hospodinu, ale modlitba upřímých líbí se jemu.</span>
<span className="v" id="v9" data-v="9" data-xref="1 Timoteovi 6:11; Přísloví 21:21; Matouš 7:13"> Ohavností jest Hospodinu cesta bezbožného, toho pak, kdož následuje spravedlnosti, miluje.</span>
<span className="v" id="v10" data-v="10" data-xref="Přísloví 12:1; Jan 3:20; Přísloví 13:1"> Trestání přísné opouštějícímu cestu, a kdož nenávidí domlouvání, umře.</span>
<span className="v" id="v11" data-v="11" data-xref="Žalmy 44:21; Židům 4:13; Žalmy 139:8"> Peklo i zatracení jest před Hospodinem, čím více srdce synů lidských?</span>
<span className="v" id="v12" data-v="12" data-xref="Ámos 5:10; Jób 21:14; Přísloví 9:7–8"> Nemiluje posměvač toho, kterýž ho tresce, aniž k moudrým přistoupí.</span>
<span className="v" id="v13" data-v="13" data-xref="Přísloví 17:22; Jan 14:1; Přísloví 18:14"> Srdce veselé obveseluje tvář, ale pro žalost srdce duch zkormoucen bývá.</span>
<span className="v" id="v14" data-v="14" data-xref="Přísloví 9:9; Izajáš 30:10; Přísloví 18:15"> Srdce rozumného hledá umění, ale ústa bláznů pasou se bláznovstvím.</span>
<span className="v" id="v15" data-v="15" data-xref="2 Korintským 6:10; Římanům 12:12; Přísloví 15:13"> Všickni dnové chudého zlí jsou, ale dobromyslného hody ustavičné.</span>
<span className="v" id="v16" data-v="16" data-xref="Přísloví 16:8; Žalmy 37:16; Kazatel 5:10–12"> Lepší jest maličko s bázní Hospodinovou než poklad veliký s nepokojem.</span>
<span className="v" id="v17" data-v="17" data-xref="Přísloví 17:1; Přísloví 21:19; 1 Janův 4:16"> Lepší jest krmě z zelí, kdež jest láska, nežli z krmného vola, kdež jest nenávist.</span>
<span className="v" id="v18" data-v="18" data-xref="Přísloví 15:1; Přísloví 26:21; Přísloví 29:22"> Muž hněvivý vzbuzuje sváry, ale zpozdilý k hněvu upokojuje svadu.</span>
<span className="v" id="v19" data-v="19" data-xref="Izajáš 35:8; Přísloví 22:5; Izajáš 30:21"> Cesta lenivého jest jako plot z trní, ale stezka upřímých jest vydlážená.</span>
<span className="v" id="v20" data-v="20" data-xref="Přísloví 29:3; Přísloví 10:1; Přísloví 23:15–16"> Syn moudrý obveseluje otce, bláznivý pak člověk pohrdá matkou svou.</span>
<span className="v" id="v21" data-v="21" data-xref="Efezským 5:15; Přísloví 10:23; Přísloví 14:16"> Bláznovství jest veselím bláznu, ale člověk rozumný upřímo kráčeti směřuje.</span>
<span className="v" id="v22" data-v="22" data-xref="Přísloví 11:14; Přísloví 20:18; Kazatel 8:6"> Kdež není rady, zmařena bývají usilování, ale množství rádců ostojí.</span>
<span className="v" id="v23" data-v="23" data-xref="Izajáš 50:4; Přísloví 25:11–12; Efezským 4:29"> Vesel bývá člověk z odpovědi úst svých; nebo slovo v čas příhodný ó jak jest dobré!</span>
<span className="v" id="v24" data-v="24" data-xref="Koloským 3:1–2; Žalmy 16:11; Matouš 7:14"> Cesta života vysoko jest rozumnému proto, aby se uchýlil od pekla dole.</span>
<span className="v" id="v25" data-v="25" data-xref="Žalmy 146:9; Žalmy 68:5–6; Přísloví 14:11"> Dům pyšných vyvrací Hospodin, meze pak vdovy upevňuje.</span>
<span className="v" id="v26" data-v="26" data-xref="Přísloví 6:16–19; Jeremjáš 4:14; Přísloví 15:23"> Ohavností jsou Hospodinu myšlení zlého, ale čistých řeči vzácné.</span>
<span className="v" id="v27" data-v="27" data-xref="2 Mojžíšova 23:8; Přísloví 1:19; Jeremjáš 17:11"> Kdož dychtí po lakomství, kormoutí dům svůj; ale kdož nenávidí darů, živ bude.</span>
<span className="v" id="v28" data-v="28" data-xref="1 Petrův 3:15; Přísloví 29:11; Kazatel 5:2"> Srdce spravedlivého přemyšluje, co má mluviti, ale ústa bezbožných vylévají všelijakou zlost.</span>
<span className="v" id="v29" data-v="29" data-xref="Jan 9:31; Žalmy 145:18–19; Přísloví 15:8"> Vzdálen jest Hospodin od bezbožných, ale modlitbu spravedlivých vyslýchá.</span>
<span className="v" id="v30" data-v="30" data-xref="Izajáš 58:11; Zjevení Janovo 22:5; Zjevení Janovo 21:23"> To, což se zraku naskýtá, obveseluje srdce; pověst dobrá tukem naplňuje kosti.</span>
<span className="v" id="v31" data-v="31" data-xref="Přísloví 15:5; Přísloví 25:12; Jan 15:3–4"> Ucho, kteréž poslouchá trestání života, u prostřed moudrých bydliti bude.</span>
<span className="v" id="v32" data-v="32" data-xref="Přísloví 1:24–33; Zjevení Janovo 3:19; Přísloví 1:7"> Kdo se vyhýbá cvičení, zanedbává duše své; ale kdož přijímá domlouvání, má rozum.</span>
<span className="v" id="v33" data-v="33" data-xref="1 Petrův 5:5; Přísloví 18:12; Přísloví 1:7"> Bázeň Hospodinova jest cvičení se moudrosti, a slávu předchází ponížení.</span>

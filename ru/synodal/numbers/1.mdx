<span className="v" id="v1" data-v="1" data-xref="Исход 25:22; Исход 19:1; Числа 10:11–12"> И сказал Господь Моисею в пустыне Синайской, в скинии собрания, в первый день второго месяца, во второй год по выходе их из земли Египетской, говоря:</span>
<span className="v" id="v2" data-v="2" data-xref="Исход 38:26; Исход 30:12; Числа 1:18"> исчислите все общество сынов Израилевых по родам их, по семействам их, по числу имен, всех мужеского пола поголовно:</span>
<span className="v" id="v3" data-v="3" data-xref="Исход 30:14; Числа 14:29; Числа 33:1"> от двадцати лет и выше, всех годных для войны у Израиля, по ополчениям их исчислите их - ты и Аарон;</span>
<span className="v" id="v4" data-v="4" data-xref="Числа 1:16; Исход 18:25; Числа 13:2–15"> с вами должны быть из каждого колена по одному человеку, который в роде своем есть главный.</span>
<span className="v" id="v5" data-v="5" data-xref="Числа 7:30; Бытие 30:5–20; Бытие 49:1–33"> И вот имена мужей, которые будут с вами: от Рувима Елицур, сын Шедеура;</span>
<span className="v" id="v6" data-v="6" data-xref="Числа 7:36; Числа 2:12"> от Симеона Шелумиил, сын Цуришаддая;</span>
<span className="v" id="v7" data-v="7" data-xref="Евангелие от Луки 3:32; Числа 10:14; Евангелие от Матфея 1:2–5"> от Иуды Наассон, сын Аминадава;</span>
<span className="v" id="v8" data-v="8" data-xref="Числа 7:18; Числа 10:15; Числа 2:5"> от Иссахара Нафанаил, сын Цуара;</span>
<span className="v" id="v9" data-v="9" data-xref="Числа 7:24; Числа 10:16; Числа 2:7"> от Завулона Елиав, сын Хелона;</span>
<span className="v" id="v10" data-v="10" data-xref="Числа 7:54; Числа 7:48; Первая книга Паралипоменон 7:26–27"> от сынов Иосифа: от Ефрема Елишама, сын Аммиуда; от Манассии Гамалиил, сын Педацура;</span>
<span className="v" id="v11" data-v="11" data-xref="Числа 7:60; Числа 10:24; Числа 2:22"> от Вениамина Авидан, сын Гидеония;</span>
<span className="v" id="v12" data-v="12" data-xref="Числа 7:66; Числа 2:25; Числа 10:25"> от Дана Ахиезер, сын Аммишаддая;</span>
<span className="v" id="v13" data-v="13" data-xref="Числа 7:72; Числа 10:26; Числа 2:27"> от Асира Пагиил, сын Охрана;</span>
<span className="v" id="v14" data-v="14" data-xref="Числа 2:14; Числа 7:42; Числа 10:20"> от Гада Елиасаф, сын Регуила;</span>
<span className="v" id="v15" data-v="15" data-xref="Числа 7:78; Числа 10:27; Числа 2:29"> от Неффалима Ахира, сын Енана.</span>
<span className="v" id="v16" data-v="16" data-xref="Числа 7:2; Исход 18:21; Исход 18:25"> Это - избранные мужи общества, начальники колен отцов своих, главы тысяч Израилевых.</span>
<span className="v" id="v17" data-v="17" data-xref="Евангелие от Иоанна 10:3; Откровение Иоанна Богослова 7:4–17; Числа 1:5–15"> И взял Моисей и Аарон мужей сих, которые названы поименно,</span>
<span className="v" id="v18" data-v="18" data-xref="Книга Ездры 2:59; Неемия 7:61; Послание к Евреям 7:3"> и собрали они все общество в первый день второго месяца. И объявили они родословия свои, по родам их, по семействам их, по числу имен, от двадцати лет и выше, поголовно,</span>
<span className="v" id="v19" data-v="19" data-xref="Числа 1:2; Числа 26:1–2; Вторая книга Царств 24:1–10"> как повелел Господь Моисею. И сделал он счисление им в пустыне Синайской.</span>
<span className="v" id="v20" data-v="20" data-xref="Числа 26:5–7; Числа 2:10–11; Бытие 46:9"> И было сынов Рувима, первенца Израилева, по родам их, по племенам их, по семействам их, по числу имен, поголовно, всех мужеского пола, от двадцати лет и выше, всех годных для войны,</span>
<span className="v" id="v21" data-v="21" data-xref="Числа 26:7; Числа 2:10–11"> исчислено в колене Рувимовом сорок шесть тысяч пятьсот.</span>
<span className="v" id="v22" data-v="22" data-xref="Числа 26:12–14; Бытие 34:25–30; Числа 2:12–13"> Сынов Симеона по родам их, по племенам их, по семействам их, по числу имен, поголовно, всех мужеского пола, от двадцати лет и выше, всех годных для войны,</span>
<span className="v" id="v23" data-v="23" data-xref="Числа 26:14; Числа 2:13; Числа 25:8–9"> исчислено в колене Симеоновом пятьдесят девять тысяч триста.</span>
<span className="v" id="v24" data-v="24" data-xref="Числа 26:15–18; Бытие 46:16; Числа 2:14–15"> Сынов Гада по родам их, по племенам их, по семействам их, по числу имен их, поголовно, всех мужеского пола, от двадцати лет и выше, всех годных для войны,</span>
<span className="v" id="v25" data-v="25" data-xref="Числа 26:18; Числа 2:15"> исчислено в колене Гадовом сорок пять тысяч шестьсот пятьдесят.</span>
<span className="v" id="v26" data-v="26" data-xref="Бытие 29:35; Числа 26:19–22; Вторая книга Царств 24:9"> Сынов Иуды по родам их, по племенам их, по семействам их, по числу имен их, поголовно, всех мужеского пола, от двадцати лет и выше, всех годных для войны,</span>
<span className="v" id="v27" data-v="27" data-xref="Вторая книга Царств 24:9; Числа 26:22; Вторая книга Паралипоменон 17:14–16"> исчислено в колене Иудином семьдесят четыре тысячи шестьсот.</span>
<span className="v" id="v28" data-v="28" data-xref="Бытие 46:13; Бытие 49:14–15; Бытие 30:18"> Сынов Иссахара по родам их, по племенам их, по семействам их, по числу имен их, поголовно, всех мужеского пола, от двадцати лет и выше, всех годных для войны,</span>
<span className="v" id="v29" data-v="29" data-xref="Числа 26:25; Числа 2:6"> исчислено в колене Иссахаровом пятьдесят четыре тысячи четыреста.</span>
<span className="v" id="v30" data-v="30" data-xref="Числа 26:26–27; Бытие 49:13; Бытие 30:20"> Сынов Завулона по родам их, по племенам их, по семействам их, по числу имен их, поголовно, всех мужеского пола, от двадцати лет и выше, всех годных для войны,</span>
<span className="v" id="v31" data-v="31" data-xref="Числа 26:27; Числа 2:8"> исчислено в колене Завулоновом пятьдесят семь тысяч четыреста.</span>
<span className="v" id="v32" data-v="32" data-xref="Числа 26:35–37; Второзаконие 33:17; Бытие 46:20"> Сынов Иосифа, сынов Ефрема по родам их, по племенам их, по семействам их, по числу имен их, поголовно, всех мужеского пола, от двадцати лет и выше, всех годных для войны,</span>
<span className="v" id="v33" data-v="33" data-xref="Числа 26:37; Второзаконие 33:17; Числа 2:19"> исчислено в колене Ефремовом сорок тысяч пятьсот.</span>
<span className="v" id="v34" data-v="34" data-xref="Числа 26:28–34"> Сынов Манассии по родам их, по племенам их, по семействам их, по числу имен их, поголовно, всех мужеского пола, от двадцати лет и выше, всех годных для войны,</span>
<span className="v" id="v35" data-v="35" data-xref="Числа 26:34; Бытие 48:19–20; Числа 2:21"> исчислено в колене Манассиином тридцать две тысячи двести.</span>
<span className="v" id="v36" data-v="36" data-xref="Бытие 49:27; Бытие 44:20; Откровение Иоанна Богослова 7:8"> Сынов Вениамина по родам их, по племенам их, по семействам их, по числу имен их, поголовно, всех мужеского пола, от двадцати лет и выше, всех годных для войны,</span>
<span className="v" id="v37" data-v="37" data-xref="Числа 26:41; Книга Судей Израилевых 20:44–46; Вторая книга Паралипоменон 17:17"> исчислено в колене Вениаминовом тридцать пять тысяч четыреста.</span>
<span className="v" id="v38" data-v="38" data-xref="Бытие 46:23; Бытие 30:5–6; Бытие 49:16–17"> Сынов Дана по родам их, по племенам их, по семействам их, по числу имен их, поголовно, всех мужеского пола, от двадцати лет и выше, всех годных для войны,</span>
<span className="v" id="v39" data-v="39" data-xref="Числа 26:43; Числа 2:26"> исчислено в колене Дановом шестьдесят две тысячи семьсот.</span>
<span className="v" id="v40" data-v="40" data-xref="Бытие 30:12–13; Бытие 46:27; Бытие 49:20"> Сынов Асира по родам их, по племенам их, по семействам их, по числу имен их, поголовно, всех мужеского пола, от двадцати лет и выше, всех годных для войны,</span>
<span className="v" id="v41" data-v="41" data-xref="Числа 26:47; Числа 2:28"> исчислено в колене Асировом сорок одна тысяча пятьсот.</span>
<span className="v" id="v42" data-v="42" data-xref="Бытие 49:21; Числа 26:48–50; Бытие 46:24"> Сынов Неффалима по родам их, по племенам их, по семействам их, по числу имен их, поголовно, всех мужеского пола, от двадцати лет и выше, всех годных для войны,</span>
<span className="v" id="v43" data-v="43" data-xref="Числа 26:50; Числа 2:30"> исчислено в колене Неффалимовом пятьдесят три тысячи четыреста.</span>
<span className="v" id="v44" data-v="44" data-xref="Числа 26:64; Числа 1:2–16"> Вот вошедшие в исчисление, которых исчислил Моисей и Аарон и начальники Израиля - двенадцать человек, по одному человеку из каждого племени.</span>
<span className="v" id="v45" data-v="45"> И было всех, вошедших в исчисление, сынов Израилевых, по семействам их, от двадцати лет и выше, всех годных для войны у Израиля,</span>
<span className="v" id="v46" data-v="46" data-xref="Исход 12:37; Числа 26:51; Исход 38:26"> и было всех вошедших в исчисление шестьсот три тысячи пятьсот пятьдесят.</span>
<span className="v" id="v47" data-v="47" data-xref="Числа 2:33; Числа 3:1–49; Числа 26:57–62"> А левиты по поколениям отцов их не были исчислены между ними.</span>
<span className="v" id="v48" data-v="48"> И сказал Господь Моисею, говоря:</span>
<span className="v" id="v49" data-v="49" data-xref="Числа 26:62; Числа 2:33"> только колена Левиина не вноси в перепись, и не исчисляй их вместе с сынами Израиля;</span>
<span className="v" id="v50" data-v="50" data-xref="Исход 38:21; Исход 31:18; Числа 4:15"> но поручи левитам скинию откровения и все принадлежности ее и все, что при ней; пусть они носят скинию и все принадлежности ее, и служат при ней, и около скинии пусть ставят стан свой;</span>
<span className="v" id="v51" data-v="51" data-xref="Числа 3:38; Числа 3:10; Первая книга Царств 6:19"> и когда надобно переносить скинию, пусть поднимают ее левиты, и когда надобно остановиться скинии, пусть ставят ее левиты; а если приступит кто посторонний, предан будет смерти.</span>
<span className="v" id="v52" data-v="52" data-xref="Числа 2:2; Числа 2:34; Числа 10:1–36"> Сыны Израилевы должны становиться каждый в стане своем и каждый при своем знамени, по ополчениям своим;</span>
<span className="v" id="v53" data-v="53" data-xref="Числа 16:46; Первая книга Паралипоменон 23:32; Левит 10:6"> а левиты должны ставить стан около скинии откровения, чтобы не было гнева на общество сынов Израилевых, и будут левиты стоять на страже у скинии откровения.</span>
<span className="v" id="v54" data-v="54" data-xref="Второзаконие 12:32; Исход 40:16; Исход 39:32"> И сделали сыны Израилевы; как повелел Господь Моисею, так они и сделали.</span>

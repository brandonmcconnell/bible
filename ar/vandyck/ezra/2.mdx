## قائمة بالعائدين من السبي

<div className="bt" dir="rtl">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="اَلْمُلُوكِ ٱلثَّانِي 25:11; اَلْمُلُوكِ ٱلثَّانِي 24:14–16; نَحَمْيَا 7:6–73"> وَهَؤُلَاءِ هُمْ بَنُو ٱلْكُورَةِ ٱلصَّاعِدُونَ مِنْ سَبْيِ ٱلْمَسْبِيِّينَ، ٱلَّذِينَ سَبَاهُمْ نَبُوخَذْنَاصَّرُ مَلِكُ بَابِلَ إِلَى بَابِلَ، وَرَجَعُوا إِلَى أُورُشَلِيمَ وَيَهُوذَا، كُلُّ وَاحِدٍ إِلَى مَدِينَتِهِ.</span>
<span className="v" id="v2" data-v="2" data-xref="حَجَّي 1:14; نَحَمْيَا 7:7; حَجَّي 2:4"> ٱلَّذِينَ جَاءُوا مَعَ زَرُبَّابِلَ، يَشُوعُ، نَحَمْيَا، سَرَايَا، رَعْلَايَا، مُرْدَخَايُ، بِلْشَانُ، مِسْفَارُ، بِغْوَايُ، رَحُومُ، بَعْنَةَ. عَدَدُ رِجَالِ شَعْبِ إِسْرَائِيلَ:</span>
<span className="v" id="v3" data-v="3" data-xref="عَزْرَا 8:3; عَزْرَا 10:25; نَحَمْيَا 7:8"> بَنُو فَرْعُوشَ أَلْفَانِ وَمِئَةٌ وَٱثْنَانِ وَسَبْعُونَ.</span>
<span className="v" id="v4" data-v="4" data-xref="نَحَمْيَا 7:9; عَزْرَا 8:8"> بَنُو شَفَطْيَا ثَلَاثُ مِئَةٍ وَٱثْنَانِ وَسَبْعُونَ.</span>
<span className="v" id="v5" data-v="5" data-xref="نَحَمْيَا 7:10; نَحَمْيَا 6:18"> بَنُو آرَحَ سَبْعُ مِئَةٍ وَخَمْسَةٌ وَسَبْعُونَ.</span>
<span className="v" id="v6" data-v="6" data-xref="نَحَمْيَا 7:11; عَزْرَا 10:30; عَزْرَا 8:9"> بَنُو فَحَثَ مُوآبَ مِنْ بَنِي يَشُوعَ وَيُوآبَ أَلْفَانِ وَثَمَانُ مِئَةٍ وَٱثْنَا عَشَرَ.</span>
<span className="v" id="v7" data-v="7" data-xref="عَزْرَا 10:26; عَزْرَا 2:31; نَحَمْيَا 7:12"> بَنُو عِيلَامَ أَلْفٌ وَمِئَتَانِ وَأَرْبَعَةٌ وَخَمْسُونَ.</span>
<span className="v" id="v8" data-v="8" data-xref="نَحَمْيَا 7:13; عَزْرَا 10:27"> بَنُو زَتُّو تِسْعُ مِئَةٍ وَخَمْسَةٌ وَأَرْبَعُونَ.</span>
<span className="v" id="v9" data-v="9" data-xref="نَحَمْيَا 7:14"> بَنُو زَكَّايَ سَبْعُ مِئَةٍ وَسِتُّونَ.</span>
<span className="v" id="v10" data-v="10" data-xref="عَزْرَا 10:34; نَحَمْيَا 7:15"> بَنُو بَانِي سِتُّ مِئَةٍ وَٱثْنَانِ وَأَرْبَعُونَ.</span>
<span className="v" id="v11" data-v="11" data-xref="عَزْرَا 10:28; نَحَمْيَا 7:16; عَزْرَا 8:11"> بَنُو بَابَايَ سِتُّ مِئَةٍ وَثَلَاثَةٌ وَعِشْرُونَ.</span>
<span className="v" id="v12" data-v="12" data-xref="نَحَمْيَا 7:17; عَزْرَا 8:12"> بَنُو عَرْجَدَ أَلْفٌ وَمِئَتَانِ وَٱثْنَانِ وَعِشْرُونَ.</span>
<span className="v" id="v13" data-v="13" data-xref="عَزْرَا 8:13; نَحَمْيَا 7:18"> بَنُو أَدُونِيقَامَ سِتُّ مِئَةٍ وَسِتَّةٌ وَسِتُّونَ.</span>
<span className="v" id="v14" data-v="14" data-xref="عَزْرَا 8:14; نَحَمْيَا 7:19"> بَنُو بِغْوَايَ أَلْفَانِ وَسِتَّةٌ وَخَمْسُونَ.</span>
<span className="v" id="v15" data-v="15" data-xref="نَحَمْيَا 7:20; عَزْرَا 8:6"> بَنُو عَادِينَ أَرْبَعُ مِئَةٍ وَأَرْبَعَةٌ وَخَمْسُونَ.</span>
<span className="v" id="v16" data-v="16" data-xref="نَحَمْيَا 7:21"> بَنُو آطِيرَ مِنْ يَحَزَقِيَّا ثَمَانِيَةٌ وَتِسْعُونَ.</span>
<span className="v" id="v17" data-v="17" data-xref="نَحَمْيَا 7:23"> بَنُو بِيصَايَ ثَلَاثُ مِئَةٍ وَثَلَاثَةٌ وَعِشْرُونَ.</span>
<span className="v" id="v18" data-v="18" data-xref="نَحَمْيَا 7:24"> بَنُو يُورَةَ مِئَةٌ وَٱثْنَا عَشَرَ.</span>
<span className="v" id="v19" data-v="19" data-xref="نَحَمْيَا 7:22; عَزْرَا 10:33"> بَنُو حَشُومَ مِئَتَانِ وَثَلَاثَةٌ وَعِشْرُونَ.</span>
<span className="v" id="v20" data-v="20" data-xref="نَحَمْيَا 7:25"> بَنُو جِبَّارَ خَمْسَةٌ وَتِسْعُونَ.</span>
<span className="v" id="v21" data-v="21" data-xref="أَخْبَارِ ٱلْأَيَّامِ ٱلْأَوَّلُ 2:50–52"> بَنُو بَيْتِ لَحْمٍ مِئَةٌ وَثَلَاثَةٌ وَعِشْرُونَ.</span>
<span className="v" id="v22" data-v="22" data-xref="نَحَمْيَا 7:26; صَمُوئِيلَ ٱلثَّانِي 23:28; إِرْمِيَا 40:8"> رِجَالُ نَطُوفَةَ سِتَّةٌ وَخَمْسُونَ.</span>
<span className="v" id="v23" data-v="23" data-xref="إِرْمِيَا 1:1; يَشُوع 21:18; إِرْمِيَا 11:21"> رِجَالُ عَنَاثُوثَ مِئَةٌ وَثَمَانِيَةٌ وَعِشْرُونَ.</span>
<span className="v" id="v24" data-v="24" data-xref="نَحَمْيَا 7:28"> بَنُو عَزْمُوتَ ٱثْنَانِ وَأَرْبَعُونَ.</span>
<span className="v" id="v25" data-v="25" data-xref="يَشُوع 9:17; نَحَمْيَا 7:29"> بَنُو قَرْيَةِ عَارِيمَ كَفِيرَةَ وَبَئِيرُوتَ سَبْعُ مِئَةٍ وَثَلَاثَةٌ وَأَرْبَعُونَ.</span>
<span className="v" id="v26" data-v="26" data-xref="يَشُوع 18:24–25; نَحَمْيَا 7:30"> بَنُو ٱلرَّامَةِ وَجَبَعَ سِتُّ مِئَةٍ وَوَاحِدٌ وَعِشْرُونَ.</span>
<span className="v" id="v27" data-v="27" data-xref="صَمُوئِيلَ ٱلْأَوَّلُ 13:23; صَمُوئِيلَ ٱلْأَوَّلُ 13:5; إِشَعْيَاءَ 10:28"> رِجَالُ مِخْمَاسَ مِئَةٌ وَٱثْنَانِ وَعِشْرُونَ.</span>
<span className="v" id="v28" data-v="28" data-xref="اَلتَّكْوِينُ 12:8; نَحَمْيَا 7:33; يَشُوع 8:9"> رِجَالُ بَيْتِ إِيلَ وَعَايَ مِئَتَانِ وَثَلَاثَةٌ وَعِشْرُونَ.</span>
<span className="v" id="v29" data-v="29" data-xref="إِرْمِيَا 48:1; اَلتَّثْنِيَة 32:49; نَحَمْيَا 7:33"> بَنُو نَبُو ٱثْنَانِ وَخَمْسُونَ.</span>
<span className="v" id="v30" data-v="30"> بَنُو مَغْبِيشَ مِئَةٌ وَسِتَّةٌ وَخَمْسُونَ.</span>
<span className="v" id="v31" data-v="31" data-xref="عَزْرَا 2:7; نَحَمْيَا 7:34"> بَنُو عِيلَامَ ٱلْآخَرِ أَلْفٌ وَمِئَتَانِ وَأَرْبَعَةٌ وَخَمْسُونَ.</span>
<span className="v" id="v32" data-v="32" data-xref="عَزْرَا 10:31; نَحَمْيَا 7:35"> بَنُو حَارِيمَ ثَلَاثُ مِئَةٍ وَعِشْرُونَ.</span>
<span className="v" id="v33" data-v="33" data-xref="نَحَمْيَا 11:34–35; نَحَمْيَا 6:2; أَخْبَارِ ٱلْأَيَّامِ ٱلْأَوَّلُ 8:12"> بَنُو لُودَ بَنُو حَادِيدَ وَأُونُو سَبْعُ مِئَةٍ وَخَمْسَةٌ وَعِشْرُونَ.</span>
<span className="v" id="v34" data-v="34" data-xref="اَلْمُلُوكِ ٱلْأَوَّلُ 16:34; أَخْبَارِ ٱلْأَيَّامِ ٱلثَّانِي 28:15; نَحَمْيَا 7:36"> بَنُو أَرِيحَا ثَلَاثُ مِئَةٍ وَخَمْسَةٌ وَأَرْبَعُونَ.</span>
<span className="v" id="v35" data-v="35" data-xref="نَحَمْيَا 7:38"> بَنُو سَنَاءَةَ ثَلَاثَةُ آلَافٍ وَسِتُّ مِئَةٍ وَثَلَاثُونَ.</span>
</div>

<span className="v" id="v36" data-v="36" data-xref="أَخْبَارِ ٱلْأَيَّامِ ٱلْأَوَّلُ 9:10; نَحَمْيَا 7:39; عَزْرَا 3:9"> أَمَّا ٱلْكَهَنَةُ: فَبَنُو يَدْعِيَا مِنْ بَيْتِ يَشُوعَ تِسْعُ مِئَةٍ وَثَلَاثَةٌ وَسَبْعُونَ.</span>

<span className="v" id="v39" data-v="39" data-xref="أَخْبَارِ ٱلْأَيَّامِ ٱلْأَوَّلُ 24:8; عَزْرَا 10:21; نَحَمْيَا 7:42"> بَنُو حَارِيمَ أَلْفٌ وَسَبْعَةَ عَشَرَ.</span>

<div className="bt" dir="rtl">
<div className="bp">
<span className="v" id="v1" data-v="1"> وَكَلَّمَ ٱلرَّبُّ مُوسَى وَهَارُونَ َقَائِلًا:</span>
<span className="v" id="v2" data-v="2" data-xref="رِسَالَةُ بُولُسَ ٱلرَّسُولِ ٱلأُولَى إِلَى أَهْلِ كُورِنْثُوسَ 14:40; اَلْعَدَد 10:22; اَلْعَدَد 1:50"> «يَنْزِلُ بَنُو إِسْرَائِيلَ كُلٌّ عِنْدَ رَايَتِهِ بِأَعْلَامٍ لِبُيُوتِ آبَائِهِمْ. قُبَالَةَ خَيْمَةِ ٱلِٱجْتِمَاعِ حَوْلَهَا يَنْزِلُونَ.</span>
<span className="v" id="v3" data-v="3" data-xref="أَخْبَارِ ٱلْأَيَّامِ ٱلْأَوَّلُ 2:10; رَاعُوث 4:20; إِنْجِيلُ لُوقَا 3:32–33"> فَٱلنَّازِلُونَ إِلَى ٱلشَّرْقِ، نَحْوَ ٱلشُّرُوقِ، رَايَةُ مَحَلَّةِ يَهُوذَا حَسَبَ أَجْنَادِهِمْ، وَٱلرَّئِيسُ لِبَنِي يَهُوذَا نَحْشُونُ بْنُ عَمِّينَادَابَ،</span>
<span className="v" id="v4" data-v="4" data-xref="اَلْعَدَد 26:22; اَلْعَدَد 1:27"> وَجُنْدُهُ ٱلْمَعْدُودُونَ مِنْهُمْ أَرْبَعَةٌ وَسَبْعُونَ أَلْفًا وَسِتُّ مِئَةٍ.</span>
<span className="v" id="v5" data-v="5" data-xref="اَلْعَدَد 1:8; اَلْعَدَد 7:18; اَلْعَدَد 7:23"> وَٱلنَّازِلُونَ مَعَهُ سِبْطُ يَسَّاكَرَ، وَٱلرَّئِيسُ لِبَنِي يَسَّاكَرَ نَثَنَائِيلُ بْنُ صُوغَرَ،</span>
<span className="v" id="v6" data-v="6" data-xref="اَلْعَدَد 26:25; اَلْعَدَد 1:29"> وَجُنْدُهُ ٱلْمَعْدُودُونَ مِنْهُ أَرْبَعَةٌ وَخَمْسُونَ أَلْفًا وَأَرْبَعُ مِئَةٍ.</span>
<span className="v" id="v7" data-v="7" data-xref="اَلْعَدَد 1:9; اَلْعَدَد 7:24; اَلْعَدَد 10:16"> وَسِبْطُ زَبُولُونَ، وَٱلرَّئِيسُ لِبَنِي زَبُولُونَ أَلِيآبُ بْنُ حِيلُونَ،</span>
<span className="v" id="v8" data-v="8" data-xref="اَلْعَدَد 26:26–27; اَلْعَدَد 1:31"> وَجُنْدُهُ ٱلْمَعْدُودُونَ مِنْهُ سَبْعَةٌ وَخَمْسُونَ أَلْفًا وَأَرْبَعُ مِئَةٍ.</span>
<span className="v" id="v9" data-v="9" data-xref="اَلْعَدَد 10:14"> جَمِيعُ ٱلْمَعْدُودِينَ لِمَحَلَّةِ يَهُوذَا مِئَةُ أَلْفٍ وَسِتَّةٌ وَثَمَانُونَ أَلْفًا وَأَرْبَعُ مِئَةٍ بِأَجْنَادِهِمْ. يَرْتَحِلُونَ أَوَّلًا.</span>
<span className="v" id="v10" data-v="10" data-xref="اَلْعَدَد 1:5; اَلتَّكْوِينُ 49:3–4; اَلْعَدَد 7:35"> «رَايَةُ مَحَلَّةِ رَأُوبَيْنَ إِلَى ٱلتَّيْمَنِ حَسَبَ أَجْنَادِهِمْ، وَٱلرَّئِيسُ لِبَنِي رَأُوبَيْنَ أَلِيصُورُ بْنُ شَدَيْئُورَ،</span>
<span className="v" id="v11" data-v="11" data-xref="اَلْعَدَد 26:7; اَلْعَدَد 1:21"> وَجُنْدُهُ ٱلْمَعْدُودُونَ مِنْهُ سِتَّةٌ وَأَرْبَعُونَ أَلْفًا وَخَمْسُ مِئَةٍ.</span>
<span className="v" id="v12" data-v="12" data-xref="اَلْعَدَد 1:6; اَلْعَدَد 10:19; اَلْعَدَد 7:41"> وَٱلنَّازِلُونَ مَعَهُ سِبْطُ شِمْعُونَ، وَٱلرَّئِيسُ لِبَنِي شِمْعُونَ شَلُومِيئِيلُ بْنُ صُورِيشَدَّاي،</span>
<span className="v" id="v13" data-v="13" data-xref="اَلْعَدَد 26:14; اَلْعَدَد 1:23"> وَجُنْدُهُ ٱلْمَعْدُودُونَ مِنْهُمْ تِسْعَةٌ وَخَمْسُونَ أَلْفًا وَثَلَاثُ مِئَةٍ.</span>
<span className="v" id="v14" data-v="14" data-xref="اَلْعَدَد 1:14; اَلْعَدَد 7:42; اَلْعَدَد 7:47"> وَسِبْطُ جَادَ، وَٱلرَّئِيسُ لِبَنِي جَادْ أَلِيَاسَافُ بْنُ رَعُوئِيلَ،</span>
<span className="v" id="v15" data-v="15" data-xref="اَلْعَدَد 26:18; اَلْعَدَد 1:25"> وَجُنْدُهُ ٱلْمَعْدُودُونَ مِنْهُمْ خَمْسَةٌ وَأَرْبَعُونَ أَلْفًا وَسِتُّ مِئَةٍ وَخَمْسُونَ.</span>
<span className="v" id="v16" data-v="16" data-xref="اَلْعَدَد 10:18; اَلْعَدَد 2:9; اَلْعَدَد 2:24"> جَمِيعُ ٱلْمَعْدُودِينَ لِمَحَلَّةِ رَأُوبَيْنَ مِئَةُ أَلْفٍ وَوَاحِدٌ وَخَمْسُونَ أَلْفًا وَأَرْبَعُ مِئَةٍ وَخَمْسُونَ بِأَجْنَادِهِمْ، وَيَرْتَحِلُونَ ثَانِيَةً.</span>
<span className="v" id="v17" data-v="17" data-xref="اَلْعَدَد 10:21; اَلْعَدَد 10:17; اَلْعَدَد 3:38"> «ثُمَّ تَرْتَحِلُ خَيْمَةُ ٱلِٱجْتِمَاعِ. مَحَلَّةُ ٱللَّاوِيِّينَ فِي وَسَطِ ٱلْمَحَلَّاتِ. كَمَا يَنْزِلُونَ كَذَلِكَ يَرْتَحِلُونَ. كُلٌّ فِي مَوْضِعِهِ بِرَايَاتِهِمْ.</span>
<span className="v" id="v18" data-v="18" data-xref="اَلْعَدَد 1:10; اَلْعَدَد 10:22; اَلتَّكْوِينُ 48:14–20"> «رَايَةُ مَحَلَّةِ أَفْرَايِمَ حَسَبَ أَجْنَادِهِمْ إِلَى ٱلْغَرْبِ، وَٱلرَّئِيسُ لِبَنِي أَفْرَايِمَ أَلِيشَمَعُ بْنُ عَمِّيهُودَ،</span>
<span className="v" id="v19" data-v="19" data-xref="اَلْعَدَد 1:33; اَلْعَدَد 26:37"> وَجُنْدُهُ ٱلْمَعْدُودُونَ مِنْهُمْ أَرْبَعُونَ أَلْفًا وَخَمْسُ مِئَةٍ.</span>
<span className="v" id="v20" data-v="20" data-xref="اَلْعَدَد 1:10; اَلْعَدَد 7:54; اَلْعَدَد 10:23"> وَمَعَهُ سِبْطُ مَنَسَّى، وَٱلرَّئِيسُ لِبَنِي مَنَسَّى جَمْلِيئِيلُ بْنُ فَدَهْصُورَ،</span>
<span className="v" id="v21" data-v="21" data-xref="اَلْعَدَد 26:34; اَلْعَدَد 1:35"> وَجُنْدُهُ ٱلْمَعْدُودُونَ مِنْهُمُ ٱثْنَانِ وَثَلَاثُونَ أَلْفًا وَمِئَتَانِ.</span>
<span className="v" id="v22" data-v="22" data-xref="اَلْعَدَد 1:11; اَلْعَدَد 7:60; اَلْعَدَد 10:24"> وَسِبْطُ بَنْيَامِينَ، وَٱلرَّئِيسُ لِبَنِي بَنْيَامِينَ أَبِيدَنُ بْنُ جِدْعُونِي،</span>
<span className="v" id="v23" data-v="23" data-xref="اَلْعَدَد 1:37; اَلْعَدَد 26:41"> وَجُنْدُهُ ٱلْمَعْدُودُونَ مِنْهُمْ خَمْسَةٌ وَثَلَاثُونَ أَلْفًا وَأَرْبَعُ مِئَةٍ.</span>
<span className="v" id="v24" data-v="24" data-xref="اَلْعَدَد 10:22; اَلْعَدَد 2:31; اَلْمَزَامِيرُ 80:2"> جَمِيعُ ٱلْمَعْدُودِينَ لِمَحَلَّةِ أَفْرَايِمَ مِئَةُ أَلْفٍ وَثَمَانِيَةُ آلَافٍ وَمِئَةٌ بِأَجْنَادِهِمْ، وَيَرْتَحِلُونَ ثَالِثَةً.</span>
<span className="v" id="v25" data-v="25" data-xref="اَلْعَدَد 1:12; اَلْعَدَد 7:66; اَلْعَدَد 10:25"> «رَايَةُ مَحَلَّةِ دَانَ إِلَى ٱلشِّمَالِ حَسَبَ أَجْنَادِهِمْ، وَٱلرَّئِيسُ لِبَنِي دَانَ أَخِيعَزَرُ بْنُ عَمِّيشَدَّاي،</span>
<span className="v" id="v26" data-v="26" data-xref="اَلْعَدَد 26:43; اَلْعَدَد 1:39"> وَجُنْدُهُ ٱلْمَعْدُودُونَ مِنْهُمُ ٱثْنَانِ وَسِتُّونَ أَلْفًا وَسَبْعُ مِئَةٍ.</span>
<span className="v" id="v27" data-v="27" data-xref="اَلْعَدَد 1:13; اَلْعَدَد 7:77; اَلْعَدَد 7:72"> وَٱلنَّازِلُونَ مَعَهُ سِبْطُ أَشِيرَ، وَٱلرَّئِيسُ لِبَنِي أَشِيرَ فَجْعِيئِيلُ بْنُ عُكْرَنَ،</span>
<span className="v" id="v28" data-v="28" data-xref="اَلْعَدَد 1:41; اَلْعَدَد 26:47"> وَجُنْدُهُ ٱلْمَعْدُودُونَ مِنْهُمْ وَاحِدٌ وَأَرْبَعُونَ أَلْفًا وَخَمْسُ مِئَةٍ.</span>
<span className="v" id="v29" data-v="29" data-xref="اَلْعَدَد 1:15; اَلْعَدَد 10:27; اَلْعَدَد 26:48–50"> وَسِبْطُ نَفْتَالِي، وَٱلرَّئِيسُ لِبَنِي نَفْتَالِي أَخِيرَعُ بْنُ عِينَنَ،</span>
<span className="v" id="v30" data-v="30" data-xref="اَلْعَدَد 1:42–43; اَلْعَدَد 26:50"> وَجُنْدُهُ ٱلْمَعْدُودُونَ مِنْهُمْ ثَلَاثَةٌ وَخَمْسُونَ أَلْفًا وَأَرْبَعُ مِئَةٍ.</span>
<span className="v" id="v31" data-v="31" data-xref="اَلْعَدَد 10:25; اَلْعَدَد 2:16; اَلْعَدَد 2:9"> جَمِيعُ ٱلْمَعْدُودِينَ لِمَحَلَّةِ دَانَ مِئَةُ أَلْفٍ وَسَبْعَةٌ وَخَمْسُونَ أَلْفًا وَسِتُّ مِئَةٍ. يَرْتَحِلُونَ أَخِيرًا بِرَايَاتِهِمْ».</span>
<span className="v" id="v32" data-v="32" data-xref="اَلْعَدَد 1:46; اَلْخُرُوجُ 38:26; اَلْعَدَد 2:9"> هَؤُلَاءِ هُمُ ٱلْمَعْدُودُونَ مِنْ بَنِي إِسْرَائِيلَ حَسَبَ بُيُوتِ آبَائِهِمْ. جَمِيعُ ٱلْمَعْدُودِينَ مِنَ ٱلْمَحَلَّاتِ بِأَجْنَادِهِمْ سِتُّ مِئَةِ أَلْفٍ وَثَلَاثَةُ آلَافٍ وَخَمْسُ مِئَةٍ وَخَمْسُونَ.</span>
<span className="v" id="v33" data-v="33" data-xref="اَلْعَدَد 26:57–62; اَلْعَدَد 1:47–49"> وَأَمَّا ٱللَّاوِيُّونَ فَلَمْ يُعَدُّوا بَيْنَ بَنِي إِسْرَائِيلَ، كَمَا أَمَرَ ٱلرَّبُّ مُوسَى.</span>
<span className="v" id="v34" data-v="34" data-xref="اَلْمَزَامِيرُ 119:6; اَلْعَدَد 24:2; اَلْعَدَد 24:5–6"> فَفَعَلَ بَنُو إِسْرَائِيلَ حَسَبَ كُلِّ مَا أَمَرَ بِهِ ٱلرَّبُّ مُوسَى. هَكَذَا نَزَلُوا بِرَايَاتِهِمْ، وَهَكَذَا ٱرْتَحَلُوا. كُلٌّ حَسَبَ عَشَائِرِهِ مَعَ بَيْتِ آبَائِهِ.</span>

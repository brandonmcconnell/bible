## نسب شاول البنياميني

<div className="bt" dir="rtl">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="اَلتَّكْوِينُ 46:21; أَخْبَارِ ٱلْأَيَّامِ ٱلْأَوَّلُ 7:6–12; اَلْعَدَد 26:38"> وَبَنْيَامِينُ وَلَدَ: بَالَعَ بِكْرَهُ، وَأَشْبِيلَ ٱلثَّانِي، وَأَخْرَخَ ٱلثَّالِثَ،</span>
<span className="v" id="v2" data-v="2"> وَنُوحَةَ ٱلرَّابِعَ، وَرَافَا ٱلْخَامِسَ.</span>
<span className="v" id="v3" data-v="3" data-xref="اَلتَّكْوِينُ 46:21; اَلْعَدَد 26:40"> وَكَانَ بَنُو بَالَعَ: أَدَّارَ وَجَيْرَا وَأَبِيهُودَ</span>
<span className="v" id="v4" data-v="4"> وَأَبِيشُوعَ وَنُعْمَانَ وَأَخُوخَ</span>
<span className="v" id="v5" data-v="5" data-xref="أَخْبَارِ ٱلْأَيَّامِ ٱلْأَوَّلُ 7:12; اَلْعَدَد 26:39; اَلْقُضَاة 3:15"> وَحَيْرَا وَشَفُوفَانَ وَحُورَامَ.</span>
<span className="v" id="v6" data-v="6" data-xref="أَخْبَارِ ٱلْأَيَّامِ ٱلْأَوَّلُ 2:54; اَلْقُضَاة 3:20–30; أَخْبَارِ ٱلْأَيَّامِ ٱلْأَوَّلُ 7:10"> وَهَؤُلَاءِ بَنُو آحُودَ. هَؤُلَاءِ رُؤُوسُ آبَاءِ سُكَّانِ جَبْعَ، وَنَقَلُوهُمْ إِلَى مَنَاحَةَ،</span>
<span className="v" id="v7" data-v="7"> أَيْ: نُعْمَانُ وَأَخِيَا. وَجَيْرَا هُوَ نَقَلَهُمْ، وَوَلَدَ: عُزَّا وَأَخِيحُودَ.</span>
<span className="v" id="v8" data-v="8" data-xref="رَاعُوث 1:1; اَلتَّكْوِينُ 25:6"> وَشَحْرَايِمُ وَلَدَ فِي بِلَادِ مُوآبَ بَعْدَ إِطْلَاقِهِ ٱمْرَأَتَيْهِ حُوشِيمَ وَبَعْرَا.</span>
<span className="v" id="v9" data-v="9"> وَوَلَدَ مِنْ خُودَشَ ٱمْرَأَتِهِ: يُوبَابَ وَظِبْيَا وَمَيْشَا وَمَلْكَامَ</span>
<span className="v" id="v10" data-v="10"> وَيَعُوصَ وَشَبْيَا وَمِرْمَةَ. هَؤُلَاءِ بَنُو رُؤُوسِ آبَاءٍ.</span>
<span className="v" id="v11" data-v="11"> وَمِنْ حُوشِيمَ وَلَدَ: أَبِيطُوبَ وَأَلْفَعَلَ.</span>
<span className="v" id="v12" data-v="12" data-xref="عَزْرَا 2:33; نَحَمْيَا 7:37; نَحَمْيَا 6:2"> وَبَنُو أَلْفَعَلَ: عَابِرُ وَمِشْعَامُ وَشَامِرُ، وَهُوَ بَنَى أُونُوَ وَلُودَ وَقُرَاهَا.</span>
<span className="v" id="v13" data-v="13" data-xref="أَخْبَارِ ٱلْأَيَّامِ ٱلْأَوَّلُ 2:52; يَشُوع 19:42; أَخْبَارِ ٱلْأَيَّامِ ٱلْأَوَّلُ 4:4"> وَبَرِيعَةُ وَشَمَعُ. هُمَا رَأْسَا آبَاءٍ لِسُكَّانِ أَيَّلُونَ، وَهُمَا طَرَدَا سُكَّانَ جَتَّ.</span>
<span className="v" id="v14" data-v="14"> وَأَخِيُو وَشَاشَقُ وَيَرِيمُوتُ</span>
<span className="v" id="v15" data-v="15"> وَزَبَدْيَا وَعَرَادُ وَعَادَرُ</span>
<span className="v" id="v16" data-v="16"> وَمِيخَائِيلُ وَيِشْفَةُ وَيُوخَا، أَبْنَاءُ بَرِيعَةَ.</span>
<span className="v" id="v17" data-v="17"> وَزَبَدْيَا وَمَشُلَّامُ وَحَزْقِي وَحَابِرُ</span>
<span className="v" id="v18" data-v="18"> وَيِشْمَرَايُ وَيَزَلْيَاهُ وَيُوبَابُ، أَبْنَاءُ أَلْفَعَلَ.</span>
<span className="v" id="v19" data-v="19"> وَيَاقِيمُ وَزِكْرِي وَزَبْدِي</span>
<span className="v" id="v20" data-v="20"> وَأَلِيعِينَايُ وَصِلَّتَايُ وَإِيلِيئِيلُ</span>
<span className="v" id="v21" data-v="21"> وَعَدَايَا وَبَرَايَا وَشِمْرَةُ، أَبْنَاءُ شِمْعِي.</span>
<span className="v" id="v22" data-v="22"> وَيِشْفَانُ وَعَابِرُ وَإِيلِيئِيلُ</span>
<span className="v" id="v23" data-v="23"> وَعَبْدُونُ وَزِكْرِي وَحَانَانُ</span>
<span className="v" id="v24" data-v="24"> وَحَنَنْيَا وَعِيلَامُ وَعَنَثُوثِيَا</span>
<span className="v" id="v25" data-v="25"> وَيَفَدْيَا وَفَنُوئِيلُ، أَبْنَاءُ شَاشَقَ.</span>
<span className="v" id="v26" data-v="26"> وَشِمْشَرَايُ وَشَحَرْيَا وَعَثَلْيَا</span>
<span className="v" id="v27" data-v="27"> وَيَعْرَشْيَا وَإِيلِيَّا وَزِكْرِي، أَبْنَاءُ يَرُوحَامَ.</span>
<span className="v" id="v28" data-v="28" data-xref="اَلْقُضَاة 1:21; يَشُوع 15:63; نَحَمْيَا 11:1"> هَؤُلَاءِ رُؤُوسُ آبَاءٍ. حَسَبَ مَوَالِيدِهِمْ رُؤُوسٌ. هَؤُلَاءِ سَكَنُوا فِي أُورُشَلِيمَ.</span>
<span className="v" id="v29" data-v="29" data-xref="أَخْبَارِ ٱلْأَيَّامِ ٱلْأَوَّلُ 9:35–38"> وَفِي جِبْعُونَ سَكَنَ أَبُو جِبْعُونَ، وَٱسْمُ ٱمْرَأَتِهِ مَعْكَةُ.</span>
<span className="v" id="v30" data-v="30" data-xref="أَخْبَارِ ٱلْأَيَّامِ ٱلْأَوَّلُ 9:36–37"> وَٱبْنُهُ ٱلْبِكْرُ عَبْدُونُ، ثُمَّ صُورُ وَقَيْسُ وَبَعَلُ وَنَادَابُ،</span>
<span className="v" id="v31" data-v="31" data-xref="أَخْبَارِ ٱلْأَيَّامِ ٱلْأَوَّلُ 9:37"> وَجَدُورُ وَأَخِيُو وَزَاكِرُ.</span>
<span className="v" id="v32" data-v="32" data-xref="أَخْبَارِ ٱلْأَيَّامِ ٱلْأَوَّلُ 9:38"> وَمِقْلُوثُ وَلَدَ شَمَاةَ. وَهُمْ أَيْضًا مَعَ إِخْوَتِهِمْ سَكَنُوا فِي أُورُشَلِيمَ مُقَابِلَ إِخْوَتِهِمْ.</span>
<span className="v" id="v33" data-v="33" data-xref="صَمُوئِيلَ ٱلْأَوَّلُ 9:1; صَمُوئِيلَ ٱلثَّانِي 2:8; صَمُوئِيلَ ٱلْأَوَّلُ 31:2"> وَنِيرُ وَلَدَ قَيْسَ، وَقَيْسُ وَلَدَ شَاوُلَ، وَشَاوُلُ وَلَدَ يَهُونَاثَانَ وَمَلْكِيشُوعَ وَأَبِينَادَابَ وَإِشْبَعَلَ.</span>
<span className="v" id="v34" data-v="34" data-xref="صَمُوئِيلَ ٱلثَّانِي 4:4; صَمُوئِيلَ ٱلثَّانِي 9:12; صَمُوئِيلَ ٱلثَّانِي 9:10"> وَٱبْنُ يَهُوُنَاثَانَ مَرِيبْبَعَلُ، وَمَرِيبْبَعَلُ وَلَدَ مِيخَا.</span>
<span className="v" id="v35" data-v="35" data-xref="أَخْبَارِ ٱلْأَيَّامِ ٱلْأَوَّلُ 9:41"> وَبَنُو مِيخَا: فِيثُونُ وَمَالِكُ وَتَارِيعُ وَآحَازُ.</span>
<span className="v" id="v36" data-v="36" data-xref="أَخْبَارِ ٱلْأَيَّامِ ٱلْأَوَّلُ 9:42"> وَآحَازُ وَلَدَ يَهُوعَدَّةَ، وَيَهُوعَدَّةُ وَلَدَ عَلْمَثَ وَعَزْمُوتَ وَزِمْرِيَ. وَزِمْرِيُ وَلَدَ مُوصَا،</span>
<span className="v" id="v37" data-v="37" data-xref="أَخْبَارِ ٱلْأَيَّامِ ٱلْأَوَّلُ 9:43"> وَمُوصَا وَلَدَ بِنْعَةَ، وَرَافَةَ ٱبْنَهُ، وَأَلِعَاسَةَ ٱبْنَهُ، وَآصِيلَ ٱبْنَهُ.</span>
<span className="v" id="v38" data-v="38"> وَلِآصِيلَ سِتَّةُ بَنِينَ وَهَذِهِ أَسْمَاؤُهُمْ: عَزْرِيقَامُ وَبُكْرُو وَإِسْمَاعِيلُ وَشَعَرْيَا وَعُوبَدْيَا وَحَانَانُ. كُلُّ هَؤُلَاءِ بَنُو آصِيلَ.</span>
<span className="v" id="v39" data-v="39"> وَبَنُو عَاشِقَ أَخِيهِ: أُولَامُ بِكْرُهُ، وَيَعُوشُ ٱلثَّانِي، وَأَلِيفَلَطُ ٱلثَّالِثُ.</span>
<span className="v" id="v40" data-v="40" data-xref="اَلْمَزَامِيرُ 128:3–6; أَخْبَارِ ٱلْأَيَّامِ ٱلثَّانِي 14:8; أَخْبَارِ ٱلْأَيَّامِ ٱلْأَوَّلُ 12:2"> وَكَانَ بَنُو أُولَامَ رِجَالًا جَبَابِرَةَ بَأْسٍ يُغْرِقُونَ فِي ٱلْقِسِيِّ، كَثِيرِي ٱلْبَنِينَ وَبَنِي ٱلْبَنِينَ مِئَةً وَخَمْسِينَ. كُلُّ هَؤُلَاءِ مِنْ بَنِي بَنْيَامِينَ.</span>

<div className="bt" dir="rtl">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="أَخْبَارِ ٱلْأَيَّامِ ٱلْأَوَّلُ 29:28; أَخْبَارِ ٱلْأَيَّامِ ٱلْأَوَّلُ 28:5; اَلْمُلُوكِ ٱلْأَوَّلُ 1:33–39"> وَلَمَّا شَاخَ دَاوُدُ وَشَبِعَ أَيَّامًا مَلَّكَ سُلَيْمَانَ ٱبْنَهُ عَلَى إِسْرَائِيلَ.</span>
<span className="v" id="v2" data-v="2" data-xref="يَشُوع 24:1; أَخْبَارِ ٱلْأَيَّامِ ٱلثَّانِي 34:29–30; أَخْبَارِ ٱلْأَيَّامِ ٱلْأَوَّلُ 13:1"> وَجَمَعَ كُلَّ رُؤَسَاءِ إِسْرَائِيلَ وَٱلْكَهَنَةِ وَٱللَّاوِيِّينَ،</span>
<span className="v" id="v3" data-v="3" data-xref="أَخْبَارِ ٱلْأَيَّامِ ٱلْأَوَّلُ 23:24; اَلْعَدَد 4:2–49"> فَعُدَّ ٱللَّاوِيُّونَ مِنِ ٱبْنِ ثَلَاثِينَ سَنَةً فَمَا فَوْقُ، فَكَانَ عَدَدُهُمْ حَسَبَ رُؤُوسِهِمْ مِنَ ٱلرِّجَالِ ثَمَانِيَةً وَثَلَاثِينَ أَلْفًا.</span>
<span className="v" id="v4" data-v="4" data-xref="أَخْبَارِ ٱلْأَيَّامِ ٱلثَّانِي 19:8; اَلتَّثْنِيَة 16:18; أَخْبَارِ ٱلْأَيَّامِ ٱلْأَوَّلُ 26:29–31"> مِنْ هَؤُلَاءِ لِلْمُنَاظَرَةِ عَلَى عَمَلِ بَيْتِ ٱلرَّبِّ أَرْبَعَةٌ وَعِشْرُونَ أَلْفًا. وَسِتَّةُ آلَافٍ عُرَفَاءُ وَقُضَاةٌ.</span>
<span className="v" id="v5" data-v="5" data-xref="أَخْبَارِ ٱلْأَيَّامِ ٱلثَّانِي 29:25–26; أَخْبَارِ ٱلْأَيَّامِ ٱلثَّانِي 8:14; اَلْمَزَامِيرُ 87:7"> وَأَرْبَعَةُ آلَافٍ بَوَّابُونَ، وَأَرْبَعَةُ آلَافٍ مُسَبِّحُونَ لِلرَّبِّ بِٱلْآلَاتِ ٱلَّتِي عُمِلَتْ لِلتَّسْبِيحِ.</span>
<span className="v" id="v6" data-v="6" data-xref="أَخْبَارِ ٱلْأَيَّامِ ٱلثَّانِي 8:14; أَخْبَارِ ٱلْأَيَّامِ ٱلْأَوَّلُ 6:1; أَخْبَارِ ٱلْأَيَّامِ ٱلْأَوَّلُ 6:16"> وَقَسَمَهُمْ دَاوُدُ فِرَقًا لِبَنِي لَاوِي: لِجَرْشُونَ وَقَهَاتَ وَمَرَارِي.</span>

## الجرشونيون

<div className="bt" dir="rtl">
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="أَخْبَارِ ٱلْأَيَّامِ ٱلْأَوَّلُ 26:21; اَلْخُرُوجُ 6:17; أَخْبَارِ ٱلْأَيَّامِ ٱلْأَوَّلُ 6:17–20"> مِنَ ٱلْجَرْشُونِيِّينَ: لَعْدَانُ وَشَمْعِي.</span>
<span className="v" id="v8" data-v="8" data-xref="أَخْبَارِ ٱلْأَيَّامِ ٱلْأَوَّلُ 6:33–34; أَخْبَارِ ٱلْأَيَّامِ ٱلْأَوَّلُ 15:20–21; أَخْبَارِ ٱلْأَيَّامِ ٱلْأَوَّلُ 15:7"> بَنُو لَعْدَانَ: ٱلرَّأْسُ يَحِيئِيلُ ثُمَّ زِيثَامُ وَيُوئِيلُ، ثَلَاثَةٌ.</span>
<span className="v" id="v9" data-v="9"> بَنُو شَمْعِي: شَلُومِيثُ وَحَزِيئِيلُ وَهَارَانُ، ثَلَاثَةٌ. هَؤُلَاءِ رُؤُوسُ آبَاءٍ لِلَعْدَانَ.</span>
<span className="v" id="v10" data-v="10"> وَبَنُو شَمْعِي: يَحَثُ وَزِينَا وَيَعُوشُ وَبَرِيعَةُ. هَؤُلَاءِ بَنُو شَمْعِي أَرْبَعَةٌ.</span>
<span className="v" id="v11" data-v="11"> وَكَانَ يَحَثُ ٱلرَّأْسَ وَزِيزَةُ ٱلثَّانِيَ. أَمَّا يَعُوشُ وَبَرِيعَةُ فَلَمْ يُكَثِّرَا ٱلْأَوْلَادَ، فَكَانُوا فِي ٱلْإِحْصَاءِ لِبَيْتِ أَبٍ وَاحِدٍ.</span>
</div>

## القهاتيون

<div className="bt" dir="rtl">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="اَلْخُرُوجُ 6:18; اَلْعَدَد 3:27; اَلْعَدَد 26:58"> بَنُو قَهَاتَ: عَمْرَامُ وَيِصْهَارُ وَحَبْرُونُ وَعُزِّيئِيلُ، أَرْبَعَةٌ.</span>
<span className="v" id="v13" data-v="13" data-xref="اَلتَّثْنِيَة 21:5; اَلْخُرُوجُ 6:20; صَمُوئِيلَ ٱلْأَوَّلُ 2:28"> اِبْنَا عَمْرَامَ: هَارُونُ وَمُوسَى، وَأُفْرِزَ هَارُونُ لِتَقْدِيسِهِ قُدْسَ أَقْدَاسٍ هُوَ وَبَنُوهُ إِلَى ٱلْأَبَدِ، لِيُوقِدَ أَمَامَ ٱلرَّبِّ وَيَخْدِمَهُ وَيُبَارِكَ بِٱسْمِهِ إِلَى ٱلْأَبَدِ.</span>
<span className="v" id="v14" data-v="14" data-xref="اَلتَّثْنِيَة 33:1; اَلْمَزَامِيرُ 90:1; أَخْبَارِ ٱلْأَيَّامِ ٱلْأَوَّلُ 26:23–25"> وَأَمَّا مُوسَى رَجُلُ ٱللهِ فَدُعِيَ بَنُوهُ مَعَ سِبْطِ لَاوِي.</span>
<span className="v" id="v15" data-v="15" data-xref="اَلْخُرُوجُ 18:3–4; اَلْخُرُوجُ 2:22; اَلْخُرُوجُ 4:20"> اِبْنَا مُوسَى: جَرْشُومُ وَأَلِيعَزَرُ.</span>
<span className="v" id="v16" data-v="16" data-xref="أَخْبَارِ ٱلْأَيَّامِ ٱلْأَوَّلُ 26:24; أَخْبَارِ ٱلْأَيَّامِ ٱلْأَوَّلُ 25:20; أَخْبَارِ ٱلْأَيَّامِ ٱلْأَوَّلُ 24:20"> بَنُو جَرْشُومَ: شَبُوئِيلُ ٱلرَّأْسُ.</span>
<span className="v" id="v17" data-v="17" data-xref="أَخْبَارِ ٱلْأَيَّامِ ٱلْأَوَّلُ 26:25"> وَكَانَ ٱبْنُ أَلِيعَزَرَ: رَحَبْيَا ٱلرَّأْسَ، وَلَمْ يَكُنْ لِأَلِيعَزَرَ بَنُونَ آخَرُونَ. وَأَمَّا بَنُو رَحَبْيَا فَكَانُوا كَثِيرِينَ جِدًّا.</span>
<span className="v" id="v18" data-v="18" data-xref="أَخْبَارِ ٱلْأَيَّامِ ٱلْأَوَّلُ 26:26; أَخْبَارِ ٱلْأَيَّامِ ٱلْأَوَّلُ 24:22"> بَنُو يِصْهَارَ: شَلُومِيثُ ٱلرَّأْسُ.</span>
<span className="v" id="v19" data-v="19" data-xref="أَخْبَارِ ٱلْأَيَّامِ ٱلْأَوَّلُ 24:23; أَخْبَارِ ٱلْأَيَّامِ ٱلْأَوَّلُ 15:9; أَخْبَارِ ٱلْأَيَّامِ ٱلْأَوَّلُ 23:12"> بَنُو حَبْرُونَ: يَرِيَّا ٱلرَّأْسُ وَأَمَرْيَا ٱلثَّانِي وَيَحْزِيئِيلُ ٱلثَّالِثُ وَيَقْمَعَامُ ٱلرَّابِعُ.</span>
<span className="v" id="v20" data-v="20"> اِبْنَا عُزِّيئِيلَ: مِيخَا ٱلرَّأْسُ وَيَشِّيَّا ٱلثَّانِي.</span>

## المراريون

<div className="bt" dir="rtl">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="اَلْخُرُوجُ 6:19; أَخْبَارِ ٱلْأَيَّامِ ٱلْأَوَّلُ 6:20; أَخْبَارِ ٱلْأَيَّامِ ٱلْأَوَّلُ 24:26–30"> اِبْنَا مَرَارِي: مَحْلِي وَمُوشِي. اِبْنَا مَحْلِي: أَلِعَازَارُ وَقَيْسُ.</span>
<span className="v" id="v22" data-v="22" data-xref="أَخْبَارِ ٱلْأَيَّامِ ٱلْأَوَّلُ 24:28; اَلْعَدَد 36:6–8"> وَمَاتَ أَلِعَازَارُ وَلَمْ يَكُنْ لَهُ بَنُونَ بَلْ بَنَاتٌ، فَأَخَذَهُنَّ بَنُو قَيْسَ إِخْوَتُهُنَّ.</span>
<span className="v" id="v23" data-v="23" data-xref="أَخْبَارِ ٱلْأَيَّامِ ٱلْأَوَّلُ 24:30"> بَنُو مُوشِي: مَحْلِي وَعَادِرُ وَيَرِيمُوثُ، ثَلَاثَةٌ.</span>
<span className="v" id="v24" data-v="24" data-xref="اَلْعَدَد 10:17; اَلْعَدَد 10:21; أَخْبَارِ ٱلْأَيَّامِ ٱلْأَوَّلُ 23:3"> هَؤُلَاءِ بَنُو لَاوِي حَسَبَ بُيُوتِ آبَائِهِمْ رُؤُوسُ ٱلْآبَاءِ حَسَبَ إِحْصَائِهِمْ فِي عَدَدِ ٱلْأَسْمَاءِ حَسَبَ رُؤُوسِهِمْ عَامِلُو ٱلْعَمَلِ لِخِدْمَةِ بَيْتِ ٱلرَّبِّ، مِنِ ٱبْنِ عِشْرِينَ سَنَةً فَمَا فَوْقُ.</span>
<span className="v" id="v25" data-v="25" data-xref="اَلْمَزَامِيرُ 132:13–14; أَخْبَارِ ٱلْأَيَّامِ ٱلْأَوَّلُ 22:18; صَمُوئِيلَ ٱلثَّانِي 7:11"> لِأَنَّ دَاوُدَ قَالَ: «قَدْ أَرَاحَ ٱلرَّبُّ إِلَهُ إِسْرَائِيلَ شَعْبَهُ فَسَكَنَ فِي أُورُشَلِيمَ إِلَى ٱلْأَبَدِ.</span>
<span className="v" id="v26" data-v="26" data-xref="اَلْعَدَد 4:5; اَلْعَدَد 7:9; اَلْعَدَد 4:15"> وَلَيْسَ لِلَّاوِيِّينَ بَعْدُ أَنْ يَحْمِلُوا ٱلْمَسْكَنَ وَكُلَّ آنِيَتِهِ لِخِدْمَتِهِ».</span>
<span className="v" id="v27" data-v="27" data-xref="أَخْبَارِ ٱلْأَيَّامِ ٱلْأَوَّلُ 23:24; اَلْمَزَامِيرُ 72:20; صَمُوئِيلَ ٱلثَّانِي 23:1"> لِأَنَّهُ حَسَبَ كَلَامِ دَاوُدَ ٱلْأَخِيرِ عُدَّ بَنُو لَاوِي مِنِ ٱبْنِ عِشْرِينَ سَنَةً فَمَا فَوْقُ.</span>
<span className="v" id="v28" data-v="28" data-xref="أَخْبَارِ ٱلْأَيَّامِ ٱلثَّانِي 35:3–6; أَخْبَارِ ٱلْأَيَّامِ ٱلثَّانِي 31:11; أَخْبَارِ ٱلْأَيَّامِ ٱلثَّانِي 35:11–14"> لِأَنَّهُمْ كَانُوا يَقِفُونَ بَيْنَ يَدَيْ بَنِي هَارُونَ عَلَى خِدْمَةِ بَيْتِ ٱلرَّبِّ فِي ٱلدُّورِ وَٱلْمَخَادِعِ، وَعَلَى تَطْهِيرِ كُلِّ قُدْسٍ وَعَمَلِ خِدْمَةِ بَيْتِ ٱللهِ،</span>
<span className="v" id="v29" data-v="29" data-xref="اَللَّاوِيِّينَ 19:35–36; اَلْخُرُوجُ 25:30; اَللَّاوِيِّينَ 6:20–23"> وَعَلَى خُبْزِ ٱلْوُجُوهِ وَدَقِيقِ ٱلتَّقْدِمَةِ وَرِقَاقِ ٱلْفَطِيرِ وَمَا يُعْمَلُ عَلَى ٱلصَّاجِ وَٱلْمَرْبُوكَاتِ وَعَلَى كُلِّ كَيْلٍ وَقِيَاسٍ،</span>
<span className="v" id="v30" data-v="30" data-xref="اَلْمَزَامِيرُ 92:1–3; عَزْرَا 3:10–11; أَخْبَارِ ٱلْأَيَّامِ ٱلْأَوَّلُ 9:33"> وَلِأَجْلِ ٱلْوُقُوفِ كُلَّ صَبَاحٍ لِحَمْدِ ٱلرَّبِّ وَتَسْبِيحِهِ وَكَذَلِكَ فِي ٱلْمَسَاءِ،</span>
<span className="v" id="v31" data-v="31" data-xref="إِشَعْيَاءَ 1:13–14; اَلْعَدَد 28:1–29; اَلْعَدَد 10:10"> وَلِكُلِّ إِصْعَادِ مُحْرَقَاتٍ لِلرَّبِّ فِي ٱلسُّبُوتِ وَٱلْأَهِلَّةِ وَٱلْمَوَاسِمِ بِٱلْعَدَدِ حَسَبَ ٱلْمَرْسُومِ عَلَيْهِمْ دَائِمًا أَمَامَ ٱلرَّبِّ،</span>
<span className="v" id="v32" data-v="32" data-xref="اَلْعَدَد 1:53; اَلْعَدَد 3:38; اَلْعَدَد 3:6–9"> وَلِيَحْرُسُوا حِرَاسَةَ خَيْمَةِ ٱلِٱجْتِمَاعِ، وَحِرَاسَةَ ٱلْقُدْسِ، وَحِرَاسَةَ بَنِي هَارُونَ إِخْوَتِهِمْ فِي خِدْمَةِ بَيْتِ ٱلرَّبِّ.</span>

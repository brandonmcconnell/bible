## الراجعون من سبي بابل

<div className="bt" dir="rtl">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="المُلُوكِ الثّانِي 25:11; المُلُوكِ الثّانِي 24:14–16; نَحَمْيا 7:6–73"> وخرَجَ مُعظَمُ المَسْبيِّينَ في إقليمِ بابِلَ، مِمَّنْ سَباهُم نَبوخَذنَصَّرُ مَلِكُ بابِلَ، ورَجَعوا إلى أورُشليمَ ويَهوذا، كُلُّ واحدٍ إلى مدينتِهِ.</span>
<span className="v" id="v2" data-v="2" data-xref="حَجَّي 1:14; نَحَمْيا 7:7; حَجَّي 2:4"> جاؤوا معَ زَرُبَّابِلَ ويشوعَ ونَحَميا وسَرايَا ورَعَلايَا ومَرْدَخايَ وبِلْشانَ ومِسفارَ وبِغْوايَ وَرَحومَ وبِعْنَةَ وهذا عَدَدُهُم:</span>
<span className="v" id="v3" data-v="3" data-xref="عَزْرا 8:3; عَزْرا 10:25; نَحَمْيا 7:8"> بَنو فَرْعُوشَ ألفانِ ومئَةٌ واَثنانِ وسَبعونَ.</span>
<span className="v" id="v4" data-v="4" data-xref="نَحَمْيا 7:9; عَزْرا 8:8"> وبَنو شَفَطْيا ثَلاثُ مئَةٍ واَثنانِ وسَبعُونَ.</span>
<span className="v" id="v5" data-v="5" data-xref="نَحَمْيا 7:10; نَحَمْيا 6:18"> وبَنو آرَحَ سَبْعُ مئَةٍ وخَمسةٌ وسَبعونَ.</span>
<span className="v" id="v6" data-v="6" data-xref="نَحَمْيا 7:11; عَزْرا 10:30; عَزْرا 8:9"> وبَنو فَحَثَ مُوآبَ أو بَنو يشوعَ ويُوآبَ ألفانِ وثَماني مئَةٍ واَثنا عشَرَ.</span>
<span className="v" id="v7" data-v="7" data-xref="عَزْرا 10:26; عَزْرا 2:31; نَحَمْيا 7:12"> وبَنو عِيلامَ ألفٌ ومئتانِ وأربَعةٌ وخَمسونَ</span>
<span className="v" id="v8" data-v="8" data-xref="نَحَمْيا 7:13; عَزْرا 10:27"> وبَنو زَتُّو تِسْعُ مئَةٍ وخَمسةٌ وأربَعونَ.</span>
<span className="v" id="v9" data-v="9" data-xref="نَحَمْيا 7:14"> وبَنو زكَّايَ سَبْعُ مئَةٍ وسِتُّونَ.</span>
<span className="v" id="v10" data-v="10" data-xref="عَزْرا 10:34; نَحَمْيا 7:15"> وبَنو باني سِتُّ مئَةٍ واَثنانِ وأربَعونَ.</span>
<span className="v" id="v11" data-v="11" data-xref="عَزْرا 10:28; نَحَمْيا 7:16; عَزْرا 8:11"> وبَنو بابايَ سِتُّ مئَةٍ وثلاثةٌ وعِشرونَ.</span>
<span className="v" id="v12" data-v="12" data-xref="نَحَمْيا 7:17; عَزْرا 8:12"> وبَنو عَزْجَدَ ألفٌ ومِئتانِ واَثنانِ وعِشرونَ.</span>
<span className="v" id="v13" data-v="13" data-xref="عَزْرا 8:13; نَحَمْيا 7:18"> وبَنو أدُونيقامَ سِتُّمئَةٍ وستَّةٌ وستُّونَ.</span>
<span className="v" id="v14" data-v="14" data-xref="عَزْرا 8:14; نَحَمْيا 7:19"> وبَنو بِغْوايَ ألفانِ وستَّةٌ وخمسونَ.</span>
<span className="v" id="v15" data-v="15" data-xref="نَحَمْيا 7:20; عَزْرا 8:6"> وبَنو عادينَ أربَعُ مئَةٍ وأربَعةٌ وخَمسونَ.</span>
<span className="v" id="v16" data-v="16" data-xref="نَحَمْيا 7:21"> وبَنو آطيرَ أو حِزقيَّا ثمانيَةٌ وتِسعونَ</span>
<span className="v" id="v17" data-v="17" data-xref="نَحَمْيا 7:23"> وبَنو بيصايَ ثَلاثُ مئَةٍ وثلاثَةٌ وعِشرونَ.</span>
<span className="v" id="v18" data-v="18" data-xref="نَحَمْيا 7:24"> وبَنو يورَةَ مئَةٌ واَثنا عشَرَ</span>
<span className="v" id="v19" data-v="19" data-xref="نَحَمْيا 7:22; عَزْرا 10:33"> وبَنو حَشومَ مِئتانِ وثلاثَةٌ وعِشرونَ.</span>
<span className="v" id="v20" data-v="20" data-xref="نَحَمْيا 7:25"> وبَنو جِبَّارَ خَمسةٌ وتِسعونَ.</span>
<span className="v" id="v21" data-v="21" data-xref="أخبارِ الأيّامِ الأوّلُ 2:50–52"> وبَنو بَيتَ لَحمَ مئَةٌ وثلاثَةٌ وعِشرونَ.</span>
<span className="v" id="v22" data-v="22" data-xref="نَحَمْيا 7:26; صموئيلَ الثّانِي 23:28; إرْمِيا 40:8"> ورِجالُ نَطُوفَةَ ستَّةٌ وخَمسونَ.</span>
<span className="v" id="v23" data-v="23" data-xref="إرْمِيا 1:1; يَشُوع 21:18; إرْمِيا 11:21"> ورِجالُ عناتُوتَ مئَةٌ وثمانيَةٌ وعِشرونَ.</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="نَحَمْيا 7:28"> وبَنو عَزمُوتَ اَثنانِ وأربَعونَ.</span>
<span className="v" id="v25" data-v="25" data-xref="يَشُوع 9:17; نَحَمْيا 7:29"> وبَنو قَريَةِ عاريمَ وكَفيرَةَ وبَئيروت سَبْعُ مئَةٍ وثلاثَةٌ وأربعونَ.</span>
<span className="v" id="v26" data-v="26" data-xref="يَشُوع 18:24–25; نَحَمْيا 7:30"> وبَنو الرَّامَةِ وجَبْعَ سِتُّ مئَةٍ وواحدٌ وعِشرونَ</span>
<span className="v" id="v27" data-v="27" data-xref="صَمُوئيلَ الأوَّلُ 13:23; صَمُوئيلَ الأوَّلُ 13:5; إشَعْياء 10:28"> ورِجالُ مِخْماسَ مئَةٌ واَثنانِ وعِشرونَ.</span>
<span className="v" id="v28" data-v="28" data-xref="التَّكوين 12:8; نَحَمْيا 7:33; يَشُوع 8:9"> ورِجالُ بَيتَ إيلَ وعايَ مِئتانِ وثلاثَةٌ وعِشرونَ.</span>
<span className="v" id="v29" data-v="29" data-xref="إرْمِيا 48:1; التَّثْنِيَة 32:49; نَحَمْيا 7:33"> وبَنو نَبو اَثنانِ وخَمسونَ.</span>
<span className="v" id="v30" data-v="30"> وبَنو مَغْبيشَ مئَةٌ وستَّةٌ وخَمسونَ.</span>
<span className="v" id="v31" data-v="31" data-xref="عَزْرا 2:7; نَحَمْيا 7:34"> وبَنو عيلامَ الآخرِ ألفٌ ومِئتانِ وأربَعةٌ وخَمسونَ</span>
<span className="v" id="v32" data-v="32" data-xref="عَزْرا 10:31; نَحَمْيا 7:35"> وبَنو حاريمَ ثَلاثُ مئَةٍ وعِشرونَ.</span>
<span className="v" id="v33" data-v="33" data-xref="نَحَمْيا 11:34–35; نَحَمْيا 6:2; أخبارِ الأيّامِ الأوّلُ 8:12"> وبَنو لُودَ وبَنو حاديدَ وأُونُو سَبْعُ مئَةٍ وخَمسةٌ وعِشرونَ.</span>
<span className="v" id="v34" data-v="34" data-xref="المُلُوكِ الأوَّلُ 16:34; أخبارِ الأيّامِ الثّانِي 28:15; نَحَمْيا 7:36"> وبَنو أريحا ثَلاثُ مئَةٍ وخَمسةٌ وأربَعونَ.</span>
<span className="v" id="v35" data-v="35" data-xref="نَحَمْيا 7:38"> وبَنو سَناءَةَ ثَلاثَةُ آلافٍ وسِتُّ مئَةٍ وثلاثونَ.</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="أخبارِ الأيّامِ الأوّلُ 9:10; نَحَمْيا 7:39; عَزْرا 3:9"> الكهَنةُ: بَنو يَدَعْيا مِنْ بَيتِ يَشوعَ: تِسْعُ مئَةٍ وثَلاثةٌ وسَبعونَ</span>
<span className="v" id="v37" data-v="37" data-xref="أخبارِ الأيّامِ الأوّلُ 24:14; عَزْرا 10:20; نَحَمْيا 7:40"> وبَنو أمِّيرَ ألفٌ واَثنانِ وخَمسونَ،</span>
<span className="v" id="v38" data-v="38" data-xref="أخبارِ الأيّامِ الأوّلُ 9:12; نَحَمْيا 7:41; عَزْرا 10:22"> وبَنو فَشْحورَ ألفٌ ومِئتانِ وسَبعةٌ وأربَعونَ</span>
<span className="v" id="v39" data-v="39" data-xref="أخبارِ الأيّامِ الأوّلُ 24:8; عَزْرا 10:21; نَحَمْيا 7:42"> وبَنو حاريمَ ألفٌ وسَبعةَ عشَرَ.</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="عَزْرا 3:9; نَحَمْيا 7:43"> اللَّاويُّونَ: بَنو يَشوعَ وقَدْميئيلَ مِنْ بَني هُودَوْيا أربَعةٌ وسَبعونَ،</span>
<span className="v" id="v41" data-v="41" data-xref="أخبارِ الأيّامِ الأوّلُ 6:39; أخبارِ الأيّامِ الأوّلُ 15:17; أخبارِ الأيّامِ الأوّلُ 25:1–2"> والمُغَنُّونَ: بَنو آسافَ مئَةٌ وثمانيَةٌ وعِشرونَ،</span>
<span className="v" id="v42" data-v="42" data-xref="نَحَمْيا 7:45; أخبارِ الأيّامِ الأوّلُ 9:17; أخبارِ الأيّامِ الأوّلُ 26:1–19"> والبَوَّابونَ: بَنو شَلُّومَ وبَنو آطيرَ وبَنو طَلْمُونَ وبَنو عقُّوبَ وبَنو حَطيطا وبَنو شُوبايَ جميعُهم مئَةٌ وتِسعَةٌ وثَلاثونَ.</span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="أخبارِ الأيّامِ الأوّلُ 9:2; نَحَمْيا 10:28; نَحَمْيا 7:46–56"> وخُدَّامُ الهَيكلِ: بَنو صِيحا وبَنو حَسوفا وبَنو طَباعوتَ</span>
<span className="v" id="v44" data-v="44" data-xref="نَحَمْيا 7:47"> وبَنو قيروسَ وبَنو سيعَها وبَنو فادونَ</span>
<span className="v" id="v45" data-v="45" data-xref="نَحَمْيا 7:48"> وبَنو لَبانَةَ وبَنو حَجابَةَ وبَنو عَقُّوبَ</span>

<span className="v" id="v47" data-v="47"> وبَنو جِدِّيلَ وبَنو جَحَرَ وبَنو رآيا</span>
<span className="v" id="v48" data-v="48"> وبَنو رَصينَ وبَنو نَقودا وبَنو جَزَّامَ</span>
<span className="v" id="v49" data-v="49" data-xref="نَحَمْيا 7:51"> وبَنو عُزَّا وبَنو فاسيحَ وبَنو بيسايَ</span>
<span className="v" id="v50" data-v="50" data-xref="نَحَمْيا 7:52"> وبَنو أسْنَةَ وبَنو مَعونيمَ وبَنو نَفوسيمَ</span>

<span className="v" id="v52" data-v="52" data-xref="نَحَمْيا 7:54"> وبَنو بَصْلوتَ وبَنو مَحيدا وبَنو حَرْشا</span>
<span className="v" id="v53" data-v="53" data-xref="نَحَمْيا 7:55"> وبَنو بَرْقوسَ وبَنو سيسَرا وبَنو تامَحَ</span>
<span className="v" id="v54" data-v="54"> وبَنو نَصيحَ وبَنو حَطيفا.</span>
</div>
<div className="bp">

<span className="v" id="v56" data-v="56" data-xref="نَحَمْيا 7:58"> وبَنو يَعْلَةَ وبَنو دَرْقونَ وبَنو جِدِّيلَ</span>
<span className="v" id="v57" data-v="57" data-xref="نَحَمْيا 7:59"> وبَنو شَفَطْيا وبَنو حَطِّيلَ وبَنو فوخَرَةَ مِنَ الصبائيمِ وبَنو آمي.</span>
<span className="v" id="v58" data-v="58" data-xref="أخبارِ الأيّامِ الأوّلُ 9:2; المُلُوكِ الأوَّلُ 9:21; يَشُوع 9:23"> وجميعُ خُدَّامِ الهَيكلِ وبَني عَبيدِ سليمانَ ثلاثُ مئَةٍ واَثنانِ وتِسعونَ.</span>
</div>
<div className="bp">

<span className="v" id="v60" data-v="60" data-xref="نَحَمْيا 7:62"> بَنو دَلايا وبَنو طُوبيَّا وبَنو نَقودا سِتُّ مئَةٍ واَثنانِ وخَمسونَ.</span>
<span className="v" id="v61" data-v="61" data-xref="صموئيلَ الثّانِي 17:27; المُلُوكِ الأوَّلُ 2:7; صموئيلَ الثّانِي 19:31–39"> ومِنْ بَينِ الكهَنةِ بَنو حبايا وبَنو هَقُّوصَ وبَنو بَرْزِلّايَ الّذي تَزَوَّجَ مِنْ بَناتِ بَرزِلَّايَ الجِلْعاديّ فَدُعيَ باَسمِهِ.</span>

<span className="v" id="v63" data-v="63" data-xref="اللّاويِّين 2:10; اللّاويِّين 2:3; الخُرُوج 28:30"> وأمَرَهُمُ الحاكِمُ أنْ لا يأكُلوا مِنَ الطَّعامِ المكَرَّسِ لِلرَّبِّ إلى أنْ يقومَ كاهنٌ يَفصِلُ في الأمرِ.</span>
</div>

<span className="v" id="v65" data-v="65" data-xref="صموئيلَ الثّانِي 19:35; نَحَمْيا 7:67; ﻣﺘﻰ 9:23"> فَضلًا عنْ عبيدِهِم وجواريهِم وهُم سَبعةُ آلافٍ وثَلاثُ مئَةٍ وسَبعةٌ وثلاثونَ، ولَهم مِئتانِ مِنَ المُغَنّينَ والمُغَنّياتِ.</span>

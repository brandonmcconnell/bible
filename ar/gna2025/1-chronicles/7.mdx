## مواليد يساكر

<div className="bt" dir="rtl">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="التَّكوين 46:13; العَدَد 26:23–24"> وبَنو يَسَّاكرَ أربَعةٌ: تُولاعُ وفوةُ وياشوبُ وشِمْرونُ.</span>
<span className="v" id="v2" data-v="2" data-xref="صموئيلَ الثّانِي 24:1–9; أخبارِ الأيّامِ الأوّلُ 27:23–24; أخبارِ الأيّامِ الأوّلُ 27:1"> وبَنو تولاعَ: عُزِّي ورفايا ويريئيلُ ويَحمايُ ويَبسامُ وشَموئيلُ، وكانوا رؤساءَ بيوتِ آبائِهِم ومُقاتِلينَ أشدَّاءَ. وكانَ عدَدُهُم في أيّامِ داوُدَ اَثنينِ وعِشرينَ ألفًا وستَّ مِئَةٍ.</span>
<span className="v" id="v3" data-v="3"> واَبنُ عُزِّي: يَزرَحْيا، وبَنو يَزرَحْيا أربَعةٌ: ميخائيلُ وعُوبَديا ويوئيلُ ويَشِّيَّا، وكانوا كُلُّهُم رؤساءَ بيوتِ آبائِهِم.</span>
<span className="v" id="v4" data-v="4" data-xref="أخبارِ الأيّامِ الأوّلُ 12:32"> وأكثروا مِنَ الزَّوجاتِ والبَنينَ، فكانَ لهُم مِنْ مَواليدِهِم سِتَّةٌ وثَلاثونَ ألفَ مُقاتلٍ.</span>
<span className="v" id="v5" data-v="5"> وأنسِباؤُهُم جميعًا، مِنْ كُلِّ عشائِرِ يَسَّاكَر، سبعةٌ وثمانونَ ألفَ مُقاتلٍ جَبارٍ.</span>
</div>
</div>

## مواليد بنيامين وجاد

<div className="bt" dir="rtl">
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="التَّكوين 46:21; أخبارِ الأيّامِ الأوّلُ 8:1–40; أخبارِ الأيّامِ الأوّلُ 7:10–11"> وبَنو بنيامينَ ثَلاثَةٌ، وهُم بالَعُ وباكَرُ ويَديعئيلُ.</span>
<span className="v" id="v7" data-v="7" data-xref="أخبارِ الأيّامِ الثّانِي 17:17–18; أخبارِ الأيّامِ الأوّلُ 21:1–5"> وبَنو بالَعَ خمسةٌ وهُم: أصبونُ وعُزِّي وعَزِّيئيلُ ويَريموثُ وعيري، وكُلُّهُم رؤساءُ عائلاتِهِم وجَبابِرَةٌ أشدَّاءُ. وكانَ عددُ أنسبائِهِم اَثنينِ وعشرينَ ألفًا وأربَعةً وثَلاثينَ.</span>
<span className="v" id="v8" data-v="8"> وبَنو باكرَ تِسعةٌ وهُم: زَميرةُ ويوعاشُ وأليعزَرُ وأليوعينايُ وعُمري ويَريموثُ وأبيَّا وعناتوتُ وعلامَثُ.</span>
<span className="v" id="v9" data-v="9"> وكانوا كُلُّهُم رؤساءَ عائلاتِهِم وجبابِرَةً أشدَّاءَ، ويَنتَسِبُ إليهِم عشرونَ ألفًا ومئتانِ.</span>
<span className="v" id="v10" data-v="10" data-xref="القُضاة 3:15–30"> واَبنُ يَديعئيلَ بَلهانُ، وبَنو بَلهانَ سبعةٌ وهُم: يَعيشُ وبنيامينُ وأهودُ وكنعَنَةُ وزيتانُ وترشيشُ وأخيشاحَرُ.</span>
<span className="v" id="v11" data-v="11" data-xref="أخبارِ الأيّامِ الثّانِي 17:13–19"> كُلُّ هؤلاءِ كانوا رؤساءَ عائلاتِهِم وجبابرَةً أشدَّاءَ، ويَنتَسِبُ إليهِم سبعةَ عشَرَ ألفًا ومئتا مُحاربٍ.</span>
<span className="v" id="v12" data-v="12" data-xref="العَدَد 26:38–39; التَّكوين 46:21; أخبارِ الأيّامِ الأوّلُ 7:15"> واَبنا عيرَ: شُفِّيمُ وحُفِّيمُ، واَبنُ أحيرَ حوشيمُ.</span>
</div>
</div>

## مواليد منسّى

<div className="bt" dir="rtl">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="العَدَد 32:30–42; القُضاة 5:14; التَّثْنِيَة 3:13–15"> واَبنا منَسَّى مِنْ جاريتِهِ الآراميَّةِ: إشريئيلُ وماكيرُ أبو جلعادَ.</span>
<span className="v" id="v15" data-v="15" data-xref="العَدَد 26:33; العَدَد 36:1–12; العَدَد 27:1–11"> واَتَّخَذَ ماكيرُ زوجةً لِكُلٍّ مِنْ حُفِّيمَ وشُفِّيمَ. اَسمُ أُختِهما مَعكةُ، واَسمُ اَبنِهِ الثَّاني صَلْفَحادُ. وكانَ لصَلْفَحادَ بناتٌ لا بَنينَ.</span>
<span className="v" id="v16" data-v="16"> ووَلَدت مَعكةُ اَمرأةُ ماكيرَ ولَدَينِ وسمَّتْهُما فرَشَ وشارشَ، واَبنا فرَشَ، أولامُ وراقَمُ.</span>
<span className="v" id="v17" data-v="17" data-xref="صَمُوئيلَ الأوَّلُ 12:11"> واَبنُ أولامَ: بَدانُ. هؤلاءِ بنو جلعادَ بنِ ماكيرَ بنِ منَسَّى.</span>
<span className="v" id="v18" data-v="18" data-xref="القُضاة 6:24; القُضاة 6:11; القُضاة 8:2"> وولَدت أختُ جلعادَ همُّولكةُ إيشَهودَ وأبيعزرَ ومَحلَةَ.</span>
<span className="v" id="v19" data-v="19"> وبَنو شميداعَ أربَعةٌ، وهُمُ: أخيانُ وشكيمُ ولِقْحي وأنيعامُ.</span>
</div>
</div>

## مواليد أفرايم

<div className="bt" dir="rtl">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="العَدَد 26:35–36"> واَبنُ أفرايمَ: شوتالَحُ. وشوتالَحُ ولَدَ برَدَ، وبرَدُ ولَدَ تحثَ، وتحثُ ولَدَ ألعادَةَ، وألعادَةُ ولَدَ تحثَ،</span>
<span className="v" id="v21" data-v="21"> وتحثُ ولَدَ زابادَ وزابادُ ولَدَ شوتالَحَ، وشوتالَحُ ولَدَ عزرَ وألعادَ. فقَتَلَهُم رجالُ جتَّ لأنَّ بَني أفرايمَ نزَلوا ليأخذوا ماشيتَهُم.</span>
<span className="v" id="v22" data-v="22" data-xref="أيُّوب 2:11; التَّكوين 37:34"> فناحَ أفرايمُ أبوهُم أيّامًا كثيرة، وجاءَ إخوتُهُ ليُعزُّوهُ.</span>
<span className="v" id="v23" data-v="23" data-xref="صموئيلَ الثّانِي 23:5"> ونامَ أفرايم معَ اَمرأتِهِ. فحَبِلَت وولَدَت اَبنًا سمَّاهُ بَريعةَ لأنَّ نَكبَةً نزَلَت في بَيتِهِ.</span>
<span className="v" id="v24" data-v="24" data-xref="يَشُوع 16:3; يَشُوع 16:5; أخبارِ الأيّامِ الثّانِي 8:5"> وكانَ لأفرايمَ اَبنَةٌ اَسمُها شيرَةُ، وهيَ بَنَتْ بَيتَ حُورونَ السُّفلى والعُليا وأزينَ شيرَةَ.</span>
<span className="v" id="v25" data-v="25"> وكانَ لَه أيضًا اَبنٌ اَسمُهُ رَفَحُ، وبَنوهُ: تاحَنُ بنُ تَلَحَ بنِ رَشَفَ،</span>
<span className="v" id="v26" data-v="26"> وأليشَمَعُ بنُ عَميهودَ بنِ لَعدانَ،</span>
<span className="v" id="v27" data-v="27" data-xref="العَدَد 13:8; العَدَد 13:16; الخُرُوج 17:9–14"> ويشوعُ بنُ نُونٍ.</span>
<span className="v" id="v28" data-v="28" data-xref="التَّكوين 28:19; يَشُوع 16:2–3; أخبارِ الأيّامِ الأوّلُ 6:66–67"> وأملاكُهُم ومساكِنهُم كانَت بيتَ بابلَ وتوابِعَها، وشرقًا نَعَرانَ، وغربًا جازَرَ وشكيمَ وتوابِعَهُما، إلى عَيَّا وتوابِعَها.</span>
<span className="v" id="v29" data-v="29" data-xref="القُضاة 1:22–29; زَكَريّا 12:11; المُلُوكِ الثّانِي 9:27"> ولِبَني منَسَّى بَيتُ شانَ وتوابِعُها، وتَعنَكُ وتوابِعُها، ومِجِدُّو وتوابِعُها، ودُورُ وتوابِعُها، هُناكَ كانَت مساكِنُ بَني يوسفَ بنِ يعقوبَ.</span>
</div>
</div>

## مواليد أشير

<div className="bt" dir="rtl">
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="التَّكوين 46:17; العَدَد 26:44–46"> وبَنو أشيرَ: يَمنَةُ ويِشوَةُ ويِشوي وبَريعةُ، وسارَحُ أختُهُم.</span>
<span className="v" id="v31" data-v="31"> واَبنا بَريعَةَ: حابِرُ وملكِئيلُ، وهوَ أبو بِرْزاوثَ.</span>
<span className="v" id="v32" data-v="32"> وحابِرُ ولَدَ يَفليطَ وشوميرَ وحوثامَ وشُوعَا أُختُهُم.</span>
<span className="v" id="v33" data-v="33"> وبَنو يَفليطَ: فاسكُ وبِمْهالُ وعَشوَةُ.</span>
<span className="v" id="v34" data-v="34"> وبَنو شامَرَ: آخي ورُهجَةُ ويَحَبَّةُ وأرامُ.</span>
<span className="v" id="v35" data-v="35"> وبَنو هيلامَ أخيهِ: صوفَحُ ويَمناعُ وشالَشُ وعامالُ.</span>
<span className="v" id="v36" data-v="36"> وبَنو صوفَحَ: سوحُ وحَرنفَرُ وشوعالُ وبيري ويَمرَةُ</span>
<span className="v" id="v37" data-v="37"> وباصِرُ وهُودُ وشَمَّا وشِلْشَةُ ويِثرانُ وبئيرا.</span>
<span className="v" id="v38" data-v="38"> وبَنو يَثَرَ: يَفُنَّةُ وفِسفَةُ وأرا.</span>
<span className="v" id="v39" data-v="39"> وبَنو عُلَّا: آراحُ وحَنيئيلُ ورصيا.</span>
<span className="v" id="v40" data-v="40" data-xref="أخبارِ الأيّامِ الأوّلُ 21:1–5; صموئيلَ الثّانِي 24:1–9"> كُلُّ هؤلاءِ بَنو أشيرَ. وكانوا رُؤساءَ بيوتِ آبائِهِم وجَبابِرةً أشدَّاءَ مَشهورينَ وقادةً بارِزينَ، والّذينَ يَنتَسبونَ إليهِم عدَدُهُم سِتَّةٌ وعشرونَ ألفَ مُحاربٍ.</span>
</div>

## أسماء العائدين من السبي

<div className="bt" dir="rtl">
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="ﻛﻮﺭﻧﺜﻮﺱ ﺍﻟﺜﺎﻧﻴﺔ 3:5; كُولُوسِي 1:29; عَزْرا 7:27"> فأوحى إليَّ إلهي أنْ أجمعَ الشَّعبَ ورؤساءَهُم ووُلاةَ أمرهِم لإحصائِهِم بحسَبِ اَنتسابِهِم. وكُنتُ وجَدتُ سِجلَّ نسَبِ الّذينَ رجَعوا مِنَ السَّبْي قَبلَ سِواهُم، وكانَ مكتوبًا فيهِ:</span>
<span className="v" id="v6" data-v="6" data-xref="عَزْرا 5:8; عَزْرا 2:1–70; إرْمِيا 52:1–34"> هؤلاءِ سكَّانُ بابلَ مِنْ شعبِ إِسرائيلَ الّذينَ سباهُم نَبوخذنَصَّرُ مَلِكُ بابِلَ ورجَعوا مِنَ السَّبْي إلى أورُشليمَ ويَهوذا، كُلُّ واحدٍ إلى مدينتِهِ،</span>
<span className="v" id="v7" data-v="7" data-xref="عَزْرا 2:2; حَجَّي 1:1; زَكَريّا 3:1–3"> معَ زرُبَّابِلَ ويشوعَ ونحَمْيا وعزَرْيا ورَعْميا ونحماني ومُرْدخاي وبِلْشانَ ومِسفارتَ وبِغوايَ ونَحومَ وبَعنةَ. وهذا عددُهُم:</span>
<span className="v" id="v8" data-v="8" data-xref="عَزْرا 2:3; عَزْرا 8:3; نَحَمْيا 10:14"> بَنو فَرعوشَ ألفانِ ومئَةٌ واَثنانِ وسبعونَ،</span>
<span className="v" id="v9" data-v="9" data-xref="عَزْرا 2:4; عَزْرا 8:8"> وبَنو شَفَطْيا ثلاثُ مئَةٍ واَثنانِ وسبعونَ،</span>
<span className="v" id="v10" data-v="10" data-xref="عَزْرا 2:5; نَحَمْيا 6:18"> وبَنو آرحَ ستُّ مئَةٍ واَثنانِ وخمسونَ،</span>
<span className="v" id="v11" data-v="11" data-xref="عَزْرا 2:6; نَحَمْيا 10:14; نَحَمْيا 8:4"> وبَنو فحَثَ موآبَ مِنْ بَني يشوعَ ويوآبَ ألفانِ وثماني مئَةٍ وثمانيةَ عشَرَ.</span>
<span className="v" id="v12" data-v="12" data-xref="عَزْرا 10:26; عَزْرا 2:7; عَزْرا 8:7"> وبَنو عيلامَ ألفٌ ومئتانِ وأربعةٌ وخمسونَ.</span>
<span className="v" id="v13" data-v="13" data-xref="عَزْرا 2:8"> وبَنو زتُّو ثماني مئَةٍ وخمسةٌ وأربعونَ،</span>
<span className="v" id="v14" data-v="14" data-xref="عَزْرا 2:9"> وبَنو زكَّايَ سَبْعُ مئَةٍ وستُّونَ،</span>
<span className="v" id="v15" data-v="15" data-xref="عَزْرا 2:10"> وبَنو بِنُّوي ستُّ مئةٍ وثمانيةٌ وأربعونَ،</span>
<span className="v" id="v16" data-v="16" data-xref="عَزْرا 2:11"> وبَنو بابايَ ستُّ مئَةٍ وثمانيةٌ وعشرونَ،</span>
<span className="v" id="v17" data-v="17" data-xref="عَزْرا 2:12"> وبَنو عَزْجدَ ألفانِ وثلاثُ مئَةٍ واَثنانِ وعِشرونَ.</span>
<span className="v" id="v18" data-v="18" data-xref="عَزْرا 2:13"> وبَنو أدونيقامَ ستُّ مئَةٍ وسبعةٌ وستُّونَ،</span>
<span className="v" id="v19" data-v="19" data-xref="عَزْرا 2:14"> وبَنو بغوايَ ألفانِ وسبعةٌ وستُّونَ،</span>
<span className="v" id="v20" data-v="20" data-xref="عَزْرا 2:15"> وبَنو عادينَ ستُّ مئَةٍ وخمسةٌ وخمسونَ،</span>
<span className="v" id="v21" data-v="21" data-xref="عَزْرا 2:16"> وبَنو أطِّيرَ لحَزْقِيَّا ثمانيةٌ وتسعونَ،</span>
<span className="v" id="v22" data-v="22" data-xref="عَزْرا 2:19"> وبَنو حَشُومَ ثلاثُ مئَةٍ وثمانيةٌ وعشرونَ،</span>
<span className="v" id="v23" data-v="23" data-xref="عَزْرا 2:17"> وبَنو بيصايَ ثلاثُ مئَةٍ وأربعةٌ وعشرونَ،</span>
<span className="v" id="v24" data-v="24" data-xref="عَزْرا 2:18"> وبَنو حاريفَ مئَةٌ واَثنا عشَرَ،</span>

<span className="v" id="v27" data-v="27" data-xref="إرْمِيا 11:21; إشَعْياء 10:30; عَزْرا 2:23"> ورجالُ عَناثوتَ مئَةٌ وثمانيةٌ وعشرونَ،</span>
<span className="v" id="v28" data-v="28" data-xref="عَزْرا 2:24"> ورجالُ بَيتَ عَزْموتَ اَثنانِ وأربعونَ،</span>

<span className="v" id="v30" data-v="30" data-xref="يَشُوع 18:24–25; عَزْرا 2:26"> ورجالُ الرَّامةِ وجبَعَ ستُّ مئَةٍ وواحدٌ وعشرونَ،</span>
<span className="v" id="v31" data-v="31" data-xref="صَمُوئيلَ الأوَّلُ 13:23; عَزْرا 2:27; صَمُوئيلَ الأوَّلُ 13:5"> ورجالُ مُخْماسَ مئَةٌ واَثنانِ وعشرونَ،</span>
<span className="v" id="v32" data-v="32" data-xref="عَزْرا 2:28; يَشُوع 8:9; يَشُوع 8:17"> ورجالُ بيتَ إيلَ وعايَ مئَةٌ وثلاثةٌ وعشرونَ،</span>

<span className="v" id="v35" data-v="35" data-xref="عَزْرا 2:32; عَزْرا 10:31"> وبَنو حاريمَ ثلاثُ مئَةٍ وعشرونَ،</span>
<span className="v" id="v36" data-v="36" data-xref="عَزْرا 2:34"> وبَنو أريحا ثلاثُ مئَةٍ وخمسَةٌ وأربعونَ،</span>

<span className="v" id="v42" data-v="42" data-xref="أخبارِ الأيّامِ الأوّلُ 24:8; عَزْرا 10:31; عَزْرا 2:39"> وبَنو حاريمَ ألفٌ وسبعةَ عشَرَ.</span>

<span className="v" id="v44" data-v="44" data-xref="عَزْرا 2:41; أخبارِ الأيّامِ الأوّلُ 25:2"> والمغنُّونَ بَنو آسافَ مئَةٌ وثمانيةٌ وأربعونَ،</span>

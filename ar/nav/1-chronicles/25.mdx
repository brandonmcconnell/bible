## المغنون

<div className="bt" dir="rtl">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ملوك الثاني 3:15; أخبار الأيام الأول 6:33; أخبار الأيام الأول 6:39"> وَاخْتَارَ دَاوُدُ وَرُؤَسَاءُ الْجَيْشِ بَعْضَ أَبْنَاءِ آسَافَ وَهَيْمَانَ وَيَدُوثُونَ، لِقِيَادَةِ خَدَمَاتِ القِيَادَةِ بِإِعْلانِ رِسَالَةِ اللهِ تَصْحَبُهُمْ مُوسِيقَى الْعِيدَانِ وَالرَّبَابِ وَالصُّنُوجِ. وَهَذِهِ أَسْمَاءُ الرِّجَالِ الَّذِينَ أَدَّوْا هَذِهِ الْخَدَمَاتِ وَوَاجِبَاتُهُمْ:</span>
<span className="v" id="v2" data-v="2" data-xref="أخبار الأيام الأول 25:6; أخبار الأيام الأول 16:5; أخبار الأيام الأول 25:1"> مِنْ أَبنَاءِ آسَافَ: زَكُّورُ وَيُوسُفُ وَنَثَنْيَا وَأَشَرْئِيلَةُ، وَهُمْ يَخْدُمُونَ تَحْتَ إِشْرَافِ آسَافَ الْمُتَنَبِّئِ فِيِ حَضْرَةِ الْمَلِكِ.</span>
<span className="v" id="v3" data-v="3" data-xref="أخبار الأيام الأول 16:41–42; أخبار الأيام الأول 9:16; أخبار الأيام الأول 15:18"> مِنْ أَبْنَاءِ يَدُوثُونَ سِتَّةٌ: جَدَلْيَا وَصَرِي وَيِشْعِيَا وَشِمْعِي وَحَشَبْيَا وَمَتَّثْيَا وَهُمْ يَخْدُمونَ تَحْتَ إِشْرَافِ أَبِيهِمْ يَدُوثُونَ الْمُتَنَبِّئِ بِالْعَزْفِ عَلَى الْعُودِ لِلتَّعْبِيرِ عَنِ الْحَمْدِ وَالتَّسْبِيحِ لِلرَّبِّ.</span>
<span className="v" id="v4" data-v="4" data-xref="المزامير 88:1; أخبار الأيام الأول 6:33; أخبار الأيام الأول 24:24"> مِنْ أَبْنَاءِ هَيْمَانَ: بُقِّيَّا، وَمَتَّنْيَا، وَعُزِّيئِيلُ، وَشَبُوئِيلُ، وَيَرِيمُوثُ وَحَنَنْيَا، وَحَنَانِي وَإِيلِيآثَةُ، وَجِدَّلْتِي، وَرُومَمْتِي عَزَرُ، وَيُشْبَقَاشَةُ، وَمَلُوثِي، وَهُوثِيرُ وَمَحْزِيُوثُ.</span>
<span className="v" id="v5" data-v="5" data-xref="أخبار الأيام الأول 21:9; المزامير 127:3; صموئيل الأول 9:9"> وَجَمِيعُ هَؤُلاءِ هُمْ أَبْنَاءُ هَيْمَانَ نَبِيِّ الْمَلِكِ، وَقَدْ رَزَقَهُ الرَّبُّ أَرْبَعَةَ عَشَرَ ابْناً وَثَلاثَ بَنَاتٍ، تَحْقِيقاً لِوَعْدِهِ، لِيَرْفَعَ مِنْ شَأْنِهِ.</span>
<span className="v" id="v6" data-v="6" data-xref="أخبار الأيام الأول 25:1–3; الرسالة إلى مؤمني كولوسي 3:16; أخبار الأيام الأول 23:5"> وكَانُوا جَمِيعُهُمْ يُجِيدُونَ الْعَزْفَ عَلَى الصُّنُوجِ وَالرَّبَابِ وَالْعِيدَانِ، بِقِيَادَةِ أَبِيهِمْ، لِلاشْتِرَاكِ فِي الْعِبَادَةِ بِالْهَيْكَلِ. وَكَانَ آسَافُ وَيَدُوثُونُ وَهَيْمَانُ يَتَلَقَّوْنَ تَعْلِيمَاتِهِمْ مِنَ الْمَلِكِ.</span>
<span className="v" id="v7" data-v="7" data-xref="أخبار الأيام الأول 23:5"> وَقَدْ بَلَغَ عَدَدُهُمْ مَعَ بَقِيَّةِ أَقْرِبَائِهِمْ مِئَتَيْنِ وَثَمَانِيَةً وَثَمَانِينَ لاوِيًّا، وَجَمِيعُهُمْ بَارِعُونَ فِي الْعَزْفِ وَالتَّرْتِيلِ لِلرَّبِّ.</span>
<span className="v" id="v8" data-v="8" data-xref="أخبار الأيام الأول 26:13; الأمثال 16:33; أخبار الأيام الأول 26:16"> وَقَدْ حَدَّدُوا مَسْؤولِيَّاتِ عَمَلِهِمْ عَنْ طَرِيقِ الْقُرْعَةِ، بِغَضِّ النَّظَرِ عَنِ الْعُمْرِ أَوِ الْكَفَاءَةِ.</span>
<span className="v" id="v9" data-v="9"> فَوَقَعَتِ الْقُرْعَةُ الأُولَى لِيُوسُفَ مِنْ عَائِلَةِ آسَافَ، وَالثَّانِيَةُ لِجَدَلْيَا وَأَقْرِبَائِهِ وَأَبْنَائِهِ، وَهُمُ اثْنَا عَشَرَ شَخْصاً،</span>
<span className="v" id="v10" data-v="10"> وَالثَّالِثَةُ لِزَكُّورَ، وَأَقْرِبَائِهِ وَأَبْنَائِهِ وَهُمُ اثْنَا عَشَرَ شَخْصاً.</span>
<span className="v" id="v11" data-v="11"> وَالرَّابِعَةُ لِيَصْرِي وَأَبْنَائِهِ وَأَقْرِبَائِهِ وَهُمُ اثْنَا عَشَرَ شَخْصاً.</span>
<span className="v" id="v12" data-v="12"> وَالخَامِسَةُ لِنَثَنْيَا وَأَبْنَائِهِ وَأَقْرِبَائِهِ وَهُمُ اثْنَا عَشَرَ شَخْصاً.</span>
<span className="v" id="v13" data-v="13"> وَالسَّادِسَةُ لِبُقِّيَّا وَأَبْنَائِهِ وَأَقْرِبَائِهِ وَهُمُ اثْنَا عَشَرَ شَخْصاً.</span>
<span className="v" id="v14" data-v="14"> وَالسَّابِعَةُ لِيَشَرِئِيلَةَ وَأَبْنَائِهِ وَأَقْرِبَائِهِ وَهُمُ اثْنَا عَشَرَ شَخْصاً.</span>
<span className="v" id="v15" data-v="15"> وَالثَّامِنَةُ لِيَشْعِيَا وَأَبْنَائِهِ وَأَقْرِبَائِهِ وَهُمُ اثْنَا عَشَرَ شَخْصاً.</span>
<span className="v" id="v16" data-v="16"> وَالتَّاسِعَةُ لِمَتَّنْيَا وَأَبْنَائِهِ وَأَقْرِبَائِهِ وَهُمُ اثْنَا عَشَرَ شَخْصاً.</span>
<span className="v" id="v17" data-v="17"> وَالعَاشِرَةُ لِشِمْعِي وَأَبْنَائِهِ وَأَقْرِبَائِهِ وَهُمُ اثْنَا عَشَرَ شَخْصاً.</span>
<span className="v" id="v18" data-v="18"> وَالْحَادِيَةُ عَشْرَةَ لِعَزَرْئِيلَ وَأَبْنَائِهِ وَأَقْرِبَائِهِ وَهُمُ اثْنَا عَشَرَ شَخْصاً.</span>
<span className="v" id="v19" data-v="19"> وَالثَّانِيَةُ عَشْرَةَ لِحَشَبْيَا وَأَبْنَائِهِ وَأَقْرِبَائِهِ وَهُمُ اثْنَا عَشَرَ شَخْصاً.</span>
<span className="v" id="v20" data-v="20"> وَالثَّالِثَةُ عَشْرَةَ لِشُوبَائِيلَ وَأَبْنَائِهِ وَأَقْرِبَائِهِ وَهُمُ اثْنَا عَشَرَ شَخْصاً.</span>
<span className="v" id="v21" data-v="21"> والرَّابِعَةُ عَشْرَةَ لِمَتَّثْيَا وَأَبْنَائِهِ وَأَقْرِبَائِهِ وَهُمُ اثْنَا عَشَرَ شَخْصاً.</span>
<span className="v" id="v22" data-v="22"> وَالخَامِسَةُ عَشْرَةَ لِيَرِيمُوثَ وَأَبْنَائِهِ وَأَقْرِبَائِهِ وَهُمُ اثْنَا عَشَرَ شَخْصاً.</span>
<span className="v" id="v23" data-v="23"> وَالسَّادِسَةُ عَشْرَةَ لِحَنَنْيَا وَأَبْنَائِهِ وَأَقْرِبَائِهِ وَهُمُ اثْنَا عَشَرَ شَخْصاً.</span>
<span className="v" id="v24" data-v="24"> وَالسَّابِعَةُ عَشْرَةَ لِيَشْبَقَاشَةَ وَأَبْنَائِهِ وَأَقْرِبَائِهِ وَهُمُ اثْنَا عَشَرَ شَخْصاً.</span>
<span className="v" id="v25" data-v="25"> وَالثَّامِنَةُ عَشْرَةَ لِحَنَانِي وَأَبْنَائِهِ وَأَقْرِبَائِهِ وَهُمُ اثْنَا عَشَرَ شَخْصاً.</span>
<span className="v" id="v26" data-v="26"> وَالتَّاسِعَةُ عَشْرَةَ لِمَلُّوثِي وَأَبْنَائِهِ وَأَقْرِبَائِهِ وَهُمُ اثْنَا عَشَرَ شَخْصاً.</span>
<span className="v" id="v27" data-v="27"> وَالعِشْرُونَ لإِيلِيَآثَةَ وَأَبْنَائِهِ وَأَقْرِبَائِهِ وَهُمُ اثْنَا عَشَرَ شَخْصاً.</span>
<span className="v" id="v28" data-v="28"> وَالحَادِيَةُ وَالعِشْرُونَ لِهُوثِيرَ وَأَبْنَائِهِ وَأَقْرِبَائِهِ وَهُمُ اثْنَا عَشَرَ شَخْصاً.</span>
<span className="v" id="v29" data-v="29"> وَالثَّانِيَةُ وَالعِشْرُونَ لِجِدَّلْتِي وَأَبْنَائِهِ وَأَقْرِبَائِهِ وَهُمُ اثْنَا عَشَرَ شَخْصاً.</span>
<span className="v" id="v30" data-v="30"> وَالثَّالِثَةُ وَالعِشْرُونَ لِمَحْزِيُوثَ وَأَبْنَائِهِ وَأَقْرِبَائِهِ وَهُمُ اثْنَا عَشَرَ شَخْصاً.</span>
<span className="v" id="v31" data-v="31"> وَالرَّابِعَةُ وَالعِشْرُونَ لِرُومَمْتِي عَزَرَ وَأَبْنَائِهِ وَأَقْرِبَائِهِ وَهُمُ اثْنَا عَشَرَ شَخْصاً.</span>

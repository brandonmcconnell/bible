## نسب شاول البنياميني

<div className="bt" dir="rtl">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="التكوين 46:21; أخبار الأيام الأول 7:6–12; العدد 26:38"> وَأَنْجَبَ بَنْيَامِينُ خَمْسَةَ أَبْنَاءٍ هُمْ عَلَى التَّوَالِي: بِكْرُهُ بَالَعُ، وَأَشْبِيلُ وَأَخْرَخُ،</span>
<span className="v" id="v2" data-v="2"> وَنُوحَةُ وَرَافَا.</span>
<span className="v" id="v3" data-v="3" data-xref="التكوين 46:21; العدد 26:40"> وَأَبْنَاءُ بَالَعَ: أَدَّارُ وَجَيْرَا وَأَبِيهُودُ،</span>
<span className="v" id="v4" data-v="4"> وَأَبِيشُوعُ وَنُعْمَانُ وَأَخُوخُ،</span>
<span className="v" id="v5" data-v="5" data-xref="أخبار الأيام الأول 7:12; العدد 26:39; القضاة 3:15"> وَحَيْرَا وَشَفُوفَانُ، وَحُورَامُ.</span>
<span className="v" id="v6" data-v="6" data-xref="أخبار الأيام الأول 2:54; القضاة 3:20–30; أخبار الأيام الأول 7:10"> وَهَذِهِ هِيَ أَسْمَاءُ أَبْنَاءِ آحُودَ الَّذِينَ كَانُوا رُؤَسَاءَ عَائِلاتٍ مِنْ أَهْلِ جَبْعَ الَّذِينَ طُرِدُوا فِي مَا بَعْدُ إِلَى مَنَاحَةَ،</span>
<span className="v" id="v7" data-v="7"> وَهُمْ: نُعْمَانُ وَأَخِيَّا وَجَيْرَا الَّذِي قَادَهُمْ إِلَى مَنَاحَةَ، وَقَدْ أَنْجَبَ عُزَّا وَأَخِيحُودَ.</span>
<span className="v" id="v8" data-v="8" data-xref="راعوث 1:1; التكوين 25:6"> وَأَنْجَبَ شَحْرَايِمُ فِي بِلادِ مُوآبَ، بَعْدَ أَنْ طَلَّقَ زَوْجَتَيْهِ حُوشِيمَ وَبَعْرَا،</span>
<span className="v" id="v9" data-v="9"> أَبْنَاءً مِنْ زَوْجَتِهِ الْجَدِيدَةِ خُودَشَ، هُمْ: يُوبَابُ وَظِبْيَا وَمَيْشَا وَمَلْكَامُ،</span>
<span className="v" id="v10" data-v="10"> وَيَعُوصُ وَشَبْيَا وَمِرْمَةُ. وَقَدْ أَصْبَحَ هَؤُلاءِ رُؤَسَاءَ بُيُوتَاتٍ.</span>
<span className="v" id="v11" data-v="11"> وَكَانَ قَدْ أَنْجَبَ مِنْ زَوْجَتِهِ حُوشِيمَ ابْنَيْنِ هُمَا: أَبِيطُوبُ وَأَلْفَعَلُ.</span>
<span className="v" id="v12" data-v="12" data-xref="عزرا 2:33; نحميا 7:37; نحميا 6:2"> أَمَّا أَبْنَاءُ أَلْفَعَلَ فَهُمْ: عَابِرُ وَمِشْعَامُ وَشَامِرُ الَّذِي بَنَى مَدِينَتَيْ أُونُوَ وَلُودَ وَضِيَاعَهُمَا،</span>
<span className="v" id="v13" data-v="13" data-xref="أخبار الأيام الأول 2:52; يشوع 19:42; أخبار الأيام الأول 4:4"> وَبَرِيعَةُ وَشَمَعُ وَهُمَا رَأْسَا عَائِلاتِ أَهْلِ أَيَّلُونَ، وَقَدْ قَامَا بِطَرْدِ سُكَّانِ جَتَّ مِنْهَا.</span>
<span className="v" id="v14" data-v="14"> أَمَّا أَخِيُو وَشَاشَقُ وَيَرِيمُوتُ،</span>
<span className="v" id="v15" data-v="15"> وَزَبَدْيَا وَعَدَادُ وَعَادَرُ،</span>
<span className="v" id="v16" data-v="16"> وَمِيخَائِيلُ وَيِشْفَةُ وَيُوخَا فَهُمْ أَبْنَاءُ بَرِيعَةَ.</span>
<span className="v" id="v17" data-v="17"> أَمَّا زَبَدْيَا وَمَشُلّامُ وَحَزْقِي وَحَابِرُ،</span>
<span className="v" id="v18" data-v="18"> وَيِشْمَرَايُ وَيَزَلْيَاهُ وَيُوبَابُ، فَهُمْ أَبْنَاءُ أَلْفَعَلَ.</span>
<span className="v" id="v19" data-v="19"> أَمَّا يَاقِيمُ وَزِكْرِي وَزَبْدِي،</span>
<span className="v" id="v20" data-v="20"> وَأَلِيعِينَايُ وَصِلَّتَايُ وَإِيلِيئِيلُ،</span>
<span className="v" id="v21" data-v="21"> وَعَدَايَا وَبَرَايَا وَشِمْرَةُ فَهُمْ أَبْنَاءُ شِمْعِي.</span>
<span className="v" id="v22" data-v="22"> وَأَمَّا يِشْفَانُ وَعَابِرُ وَإِيلِيئِيلُ،</span>
<span className="v" id="v23" data-v="23"> وَعَبْدُونُ وَزِكْرِي وَحَانَانُ،</span>
<span className="v" id="v24" data-v="24"> وَحَنَنْيَا وَعِيلامُ وَعَنَثُوثِيَا،</span>
<span className="v" id="v25" data-v="25"> وَيَفَدْيَا وَفَنُوئِيلُ فَهُمْ أَبْنَاءُ شَاشَقَ.</span>
<span className="v" id="v26" data-v="26"> أَمَّا شِمْشَرَايُ وَشَحَرْيَا وَعَثَلْيَا،</span>
<span className="v" id="v27" data-v="27"> وَيَعْرَشْيَا وَإِيلِيَّا وَزِكْرِي فَهُمْ أَبْنَاءُ يَرُوحَامَ.</span>
<span className="v" id="v28" data-v="28" data-xref="القضاة 1:21; يشوع 15:63; نحميا 11:1"> هَؤُلاءِ هُمْ رُؤَسَاءُ آبَاءِ بُيُوتَاتِهِمْ حَسَبَ سِجِلّاتِ مَوَالِيدِهِمْ، مِمَّنِ اسْتَوْطَنُوا فِي أُورُشَلِيمَ.</span>
<span className="v" id="v29" data-v="29" data-xref="أخبار الأيام الأول 9:35–38"> وَأَسَّسَ يَعُوئِيلُ مَدِينَةَ جِبْعُونَ وَأَقَامَ فِيهَا. وَأَنْجَبَتْ لَهُ زَوْجَتُهُ مَعْكَةُ</span>
<span className="v" id="v30" data-v="30" data-xref="أخبار الأيام الأول 9:36–37"> عَبْدُونَ الابْنَ الْبِكْرَ، ثُمَّ صُوراً وَقَيْساً وَبَعَلَ وَنَادَابَ،</span>
<span className="v" id="v31" data-v="31" data-xref="أخبار الأيام الأول 9:37"> وَجَدُورَ وَأَخِيُو وَزَاكِرَ.</span>
<span className="v" id="v32" data-v="32" data-xref="أخبار الأيام الأول 9:38"> وَمِقْلُوثَ الَّذِي أَنْجَبَ شَمَاةَ. وَهُمْ أَيْضاً أَقَامُوا فِي أُورُشَلِيمَ إِلَى جُوَارِ بَقِيَّةِ أَقَارِبِهِمْ.</span>
<span className="v" id="v33" data-v="33" data-xref="صموئيل الأول 9:1; صموئيل الثاني 2:8; صموئيل الأول 31:2"> وَأَنْجَبَ نِيرُ قَيْساً، وَقَيْسٌ وَلَدَ شَاوُلَ الَّذِي أَنْجَبَ يَهُونَاثَانَ وَمَلْكِيشُوعَ وَأَبِينَادَابَ وَإِشْبَعَلَ.</span>
<span className="v" id="v34" data-v="34" data-xref="صموئيل الثاني 4:4; صموئيل الثاني 9:12; صموئيل الثاني 9:10"> وَأَنْجَبَ يَهُونَاثَانُ مَرِيبْبَعَلَ، وَمَرِيبْبَعَلُ مِيخَا.</span>
<span className="v" id="v35" data-v="35" data-xref="أخبار الأيام الأول 9:41"> أَمَّا أَبْنَاءُ مِيخَا فَهُمْ: فِيثُونُ وَمَالِكُ وَتَارِيعُ وآحَازُ.</span>
<span className="v" id="v36" data-v="36" data-xref="أخبار الأيام الأول 9:42"> وَأَنْجَبَ آحَازُ يَهُوعَدَّةَ، وَيَهُوعَدَّةُ عَلْمَثَ وَعَزْمُوتَ وَزِمْرِي، وَزِمْرِي مُوصَا.</span>
<span className="v" id="v37" data-v="37" data-xref="أخبار الأيام الأول 9:43"> وَمُوصَا وَلَدَ بِنْعَةَ، وَبِنْعَةُ رَافَةَ، وَرَافَةُ أَلِعَاسَةَ، وَأَلِعَاسَةُ آصِيلَ.</span>
<span className="v" id="v38" data-v="38"> وَكَانَ لِآصِيلَ سِتَّةُ أَبْنَاءٍ هُمْ: عَزْرِيقَامُ وَبُكْرُو وَإِسْمعِيلُ وَشَعَرْيَا وَعُوبَدْيَا وَحَانَانُ. وَجَمِيعُ هَؤُلاءِ هُمْ أَبْنَاءُ آصِيلَ.</span>
<span className="v" id="v39" data-v="39"> أَمَّا أَخُوهُ عَاشِقُ فَقَدْ أَنْجَبَ بِكْرَهُ أُولامَ ثُمَّ يَعُوشَ، فَأَلِيفَلَطَ.</span>
<span className="v" id="v40" data-v="40" data-xref="المزامير 128:3–6; أخبار الأيام الثاني 14:8; أخبار الأيام الأول 12:2"> وَكَانَ أَبْنَاءُ أُولامَ مُحَارِبِينَ أَشِدَّاءَ بَارِعِينَ فِي الرِّمَايَةِ، أَكْثَرُوا مِنْ إِنْجَابِ الْبَنِينَ وَالأَحْفَادِ حَتَّى بَلَغَ عَدَدُهُمْ مِئَةً وَخَمْسِينَ. وَجَمِيعُ هَؤُلاءِ مِنْ سِبْطِ بِنْيَامِينَ.</span>

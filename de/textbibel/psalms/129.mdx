<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="Psalmen 124:1; Jeremia 2:2; Hosea 11:1"> Wallfahrtslieder. Sie haben mich viel bedrängt von meiner Jugend an - so spreche Israel! -</span>
<span className="v" id="v2" data-v="2" data-xref="Psalmen 34:19; Matthäus 16:18; 2. Korinther 4:8–9"> Sie haben mich viel bedrängt von meiner Jugend an und mich doch nicht überwältigt.</span>

<span className="v" id="v6" data-v="6" data-xref="Psalmen 37:2; Psalmen 92:7; 2. Könige 19:26"> Sie müssen wie das Gras auf den Dächern werden, das verdorrt, bevor man es herauszieht,</span>

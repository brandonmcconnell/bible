## Die Rechtssatzungen.

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="5. Mose 4:14; 5. Mose 6:20; 2. Mose 24:3–4"> Folgendes sind die Rechtssatzungen, die du ihnen vorlegen sollst:</span>
<span className="v" id="v2" data-v="2" data-xref="5. Mose 15:12–15; 2. Mose 12:44; 5. Mose 15:18"> Wenn du einen Sklaven hebräischen Stammes kaufst, so soll er sechs Jahre lang Sklavendienste verrichten; im siebenten Jahr aber soll er unentgeltlich freigelassen werden.</span>
<span className="v" id="v3" data-v="3" data-xref="5. Mose 15:12–14"> Wenn er allein eingetreten ist, so soll er auch allein entlassen werden; wenn er ein Weib gehabt hat, so soll auch sein Weib mit ihm zugleich entlassen werden.</span>
<span className="v" id="v4" data-v="4"> Wenn sein Herr ihm ein Weib gegeben und sie ihm Knaben oder Mädchen geboren hat, so soll das Weib nebst ihren Kindern ihrem Herrn gehören, und er soll allein entlassen werden.</span>
<span className="v" id="v5" data-v="5" data-xref="2. Korinther 5:14–15; 5. Mose 15:16–17; Jesaja 26:13"> Wenn jedoch der Sklave erklären sollte: Ich habe meinen Herrn, mein Weib und meine Kinder lieb und mag nicht frei werden,</span>
<span className="v" id="v6" data-v="6" data-xref="5. Mose 15:17; 3. Mose 25:40; 5. Mose 19:17–18"> so soll ihn sein Herr vor Gott führen und ihn an die Thüre oder den Thürpfosten stellen, und sein Herr soll ihm das Ohr mit einem Pfriemen durchbohren; so soll er dann für immer sein Sklave sein.</span>
<span className="v" id="v7" data-v="7" data-xref="Nehemia 5:5; 2. Mose 21:2–3"> Wenn jemand seine Tochter als Sklavin verkauft, so darf sie nicht entlassen werden, wie die Sklaven.</span>
<span className="v" id="v8" data-v="8" data-xref="1. Mose 28:8; 5. Mose 20:7; Maleachi 2:11–15"> Wenn sie ihrem Herrn, der sie für sich bestimmt hat, mißfällt, so soll er sie loskaufen lassen; aber an volksfremde Leute darf er sie nicht verkaufen, wenn er ihr sein Wort nicht hält.</span>
<span className="v" id="v9" data-v="9"> Wenn er sie für seinen Sohn bestimmt, so soll er sie wie seine eigene Tochter behandeln.</span>
<span className="v" id="v10" data-v="10" data-xref="1. Korinther 7:1–6"> Wenn er sich eine andere nimmt, darf er jener nichts von dem abbrechen, was sie an Fleischnahrung, Kleidung und Beiwohnung zu beanspruchen hat.</span>
<span className="v" id="v11" data-v="11"> Wenn er ihr diese drei Dinge nicht leistet, so soll sie umsonst, ohne Entgelt, frei werden.</span>
<span className="v" id="v12" data-v="12" data-xref="1. Mose 9:6; Matthäus 26:52; 3. Mose 24:17"> Wer einen anderen schlägt, so daß er stirbt, der soll mit dem Tode bestraft werden.</span>
<span className="v" id="v13" data-v="13" data-xref="Josua 20:2–9; 1. Samuel 24:18; 5. Mose 4:41–43"> Wenn er es aber nicht vorsätzlich gethan, sondern Gott es durch ihn so gefügt hat, so will ich dir eine Stätte bestimmen, wohin er flüchten kann.</span>
<span className="v" id="v14" data-v="14" data-xref="1. Könige 2:28–34; Hebräer 10:26; 4. Mose 15:30–31"> Wenn aber einer gegen den anderen eine offenbare Frevelthat begeht, indem er ihn auf hinterlistige Weise totschlägt, so sollst du ihn sogar von meinem Altare wegholen, damit er hingerichtet werde.</span>
<span className="v" id="v15" data-v="15" data-xref="5. Mose 21:18–21; Sprüche 30:17; 1. Timotheus 1:9"> Wer seinen Vater oder seine Mutter schlägt, soll mit dem Tode bestraft werden.</span>
<span className="v" id="v16" data-v="16" data-xref="5. Mose 24:7; 1. Timotheus 1:10; 2. Mose 22:4"> Wer einen Israeliten raubt, mag er ihn nun verkaufen, oder mag er noch bei ihm vorgefunden werden -, der soll mit dem Tode bestraft werden.</span>
<span className="v" id="v17" data-v="17" data-xref="Sprüche 20:20; Markus 7:10–11; 5. Mose 27:16"> Wer eine Verwünschung über seinen Vater oder seine Mutter ausspricht, soll mit dem Tode bestraft werden.</span>
<span className="v" id="v18" data-v="18" data-xref="2. Mose 21:20; 5. Mose 25:11; 2. Samuel 14:6"> Wenn ein paar Männer einen Streit haben, und einer den andern mit einem Stein oder mit einem Karst schlägt, so daß er zwar nicht stirbt, aber bettlägerig wird,</span>
<span className="v" id="v19" data-v="19" data-xref="2. Samuel 3:29; Sacharja 8:4"> so soll, wenn der Geschlagene wieder aufkommt und auf seinen Stock gestützt im Freien herumgehen kann, der Thäter frei ausgehen; bloß für die Zeit, wo er unthätig bleiben mußte, soll er ihn entschädigen und für seine Heilung Sorge tragen.</span>
<span className="v" id="v20" data-v="20" data-xref="Sprüche 29:19; 5. Mose 19:21; 4. Mose 35:19"> Wenn jemand seinen Sklaven oder seine Sklavin mit dem Stocke schlägt, so daß er ihm unter der Hand stirbt, so soll er bestraft werden.</span>
<span className="v" id="v21" data-v="21" data-xref="3. Mose 25:44–46"> Wenn er dagegen noch einen oder zwei Tage leben bleibt, so soll er nicht bestraft werden; denn er ist ja sein um Geld erkauftes Eigentum.</span>
<span className="v" id="v22" data-v="22" data-xref="5. Mose 22:18–19; 2. Mose 21:30; 5. Mose 16:18"> Wenn aber Leute einen Raufhandel haben und dabei ein schwangeres Weib stoßen, so daß eine Fehlgeburt erfolgt, ohne daß weiterer Schaden geschieht, so soll der Thäter eine Buße entrichten, wie sie ihm der Ehemann des Weibes auferlegt, und er soll sie bezahlen nach dem Ausspruch von Schiedsrichtern.</span>
<span className="v" id="v23" data-v="23" data-xref="5. Mose 19:21; 4. Mose 35:31; 3. Mose 24:19"> Geschieht aber ein Schaden, so soll einer lassen Leben um Leben,</span>
<span className="v" id="v24" data-v="24" data-xref="5. Mose 19:21; Matthäus 5:38–40; Matthäus 7:2"> Auge um Auge, Zahn um Zahn, Hand um Hand, Fuß um Fuß,</span>
<span className="v" id="v25" data-v="25"> Brandwunde um Brandwunde, Stichwunde um Stichwunde, Hiebwunde um Hiebwunde.</span>
<span className="v" id="v26" data-v="26" data-xref="2. Mose 21:20; Hiob 31:13–15; Psalmen 72:12–14"> Wenn jemand seinem Sklaven oder seiner Sklavin ins Auge schlägt so daß dasselbe unbrauchbar wird, so soll er ihn zur Entschädigung für das Auge freilassen.</span>
<span className="v" id="v27" data-v="27"> Und wenn er seinem Sklaven oder seiner Sklavin einen Zahn ausschlägt, so soll er ihn zur Entschädigung für den Zahn freilassen.</span>
<span className="v" id="v28" data-v="28" data-xref="2. Mose 21:32; 3. Mose 20:15–16; 1. Mose 9:5–6"> Wenn ein Rind einen Mann oder eine Frau totstößt, so soll das Rind gesteinigt und darf sein Fleisch nicht gegessen werden; der Besitzer des Rindes aber soll frei ausgehen.</span>
<span className="v" id="v29" data-v="29" data-xref="5. Mose 21:1–9"> Wenn aber das Rind schon längst stößig gewesen ist, und man dies seinem Besitzer vorgehalten, und er es trotzdem nicht sorgfältig gehütet hat, so soll das Rind, wenn es einen Mann oder eine Frau totstößt, gesteinigt, aber auch sein Besitzer mit dem Tode bestraft werden.</span>
<span className="v" id="v30" data-v="30" data-xref="2. Mose 21:22; 2. Mose 30:12; 4. Mose 35:31–33"> Wenn ihm ein Lösegeld auferlegt wird, soll er als Lösegeld für sein Leben so viel bezahlen, als ihm auferlegt wird.</span>
<span className="v" id="v31" data-v="31"> Wenn ein Knabe oder ein Mädchen gestoßen wird, so soll nach demselben Rechte mit ihm verfahren werden.</span>
<span className="v" id="v32" data-v="32" data-xref="Matthäus 26:15; Sacharja 11:12–13; Matthäus 27:3–9"> Wenn das Rind einen Sklaven oder eine Sklavin stößt, so sollen dem Eigentümer derselben dreißig Sekel Silber bezahlt, das Rind aber gesteinigt werden.</span>
<span className="v" id="v33" data-v="33" data-xref="Sprüche 28:10; Jeremia 18:20; Prediger 10:8"> Wenn jemand eine Cisterne offen läßt oder wenn jemand eine Cisterne gräbt, ohne sie zuzudecken, und ein Rind oder ein Esel hineinfällt,</span>
<span className="v" id="v34" data-v="34" data-xref="2. Mose 22:6; 2. Mose 21:29–30; 2. Mose 22:14"> so soll der Besitzer der Cisterne den Besitzer desselben mit Geld entschädigen; das tote Tier aber soll ihm selbst gehören.</span>
<span className="v" id="v35" data-v="35"> Wenn jemandes Rind das Rind eines andern totstößt, so sollen sie das lebende Rind verkaufen und den Erlös dafür unter sich teilen; auch das tote sollen sie unter sich teilen.</span>
<span className="v" id="v36" data-v="36"> Wenn es aber bekannt war, daß das Rind schon längst stößig war, und sein Besitzer es nicht sorgfältig gehütet hat, soll er als Ersatz für jenes Rind ein Rind hergeben, das tote aber soll ihm zufallen.</span>
<span className="v" id="v37" data-v="37"> Wenn jemand ein Rind oder ein Schaf stiehlt und es schlachtet oder verkauft, soll er fünf Stück Rinder für ein Rind und vier Stück Schafe für ein Schaf als Buße entrichten;</span>

<span className="v" id="v3" data-v="3" data-xref="1. Chonik 2:10; Ruth 4:20; Lukas 3:32–33"> Gegen Morgen soll sich lagern das Panier des Lagers von Juda, nach seinen Heeren und der Fürst der Kinder Juda, Nahasson, der Sohn Amminadabs;</span>

<span className="v" id="v6" data-v="6" data-xref="4. Mose 26:25; 4. Mose 1:29"> samt seinem Heer und ihren Gemusterten, 54400.</span>

<span className="v" id="v9" data-v="9" data-xref="4. Mose 10:14"> Alle, die zum Lager Judas gezählt werden, sind 186400, nach ihren Heerscharen geordnet; sie sollen voranziehen.</span>
<span className="v" id="v10" data-v="10" data-xref="4. Mose 1:5; 1. Mose 49:3–4; 4. Mose 7:35"> Gegen Mittag soll liegen das Panier Rubens mit seinem Heer; ihr Fürst Elizur, der Sohn Sedeurs,</span>
<span className="v" id="v11" data-v="11" data-xref="4. Mose 26:7; 4. Mose 1:21"> samt seinem Heer und seinen Gemusterten, 46500.</span>
<span className="v" id="v12" data-v="12" data-xref="4. Mose 1:6; 4. Mose 10:19; 4. Mose 7:41"> Neben ihm soll sich lagern der Stamm Simeon; ihr Fürst Selumiel, der Sohn Zuri-Schaddais,</span>
<span className="v" id="v13" data-v="13" data-xref="4. Mose 26:14; 4. Mose 1:23"> samt seinem Heer und seinen Gemusterten, 59300.</span>
<span className="v" id="v14" data-v="14" data-xref="4. Mose 1:14; 4. Mose 7:42; 4. Mose 7:47"> Dazu der Stamm Gad; ihr Fürst Eliphas, der Sohn Reguels,</span>
<span className="v" id="v15" data-v="15" data-xref="4. Mose 26:18; 4. Mose 1:25"> samt seinem Heer und seinen Gemusterten, 45650.</span>
<span className="v" id="v16" data-v="16" data-xref="4. Mose 10:18; 4. Mose 2:9; 4. Mose 2:24"> Alle, die zum Lager Rubens gezählt werden, sind 151450, nach ihren Heerscharen geordnet. Diese sollen in zweiter Linie ziehen.</span>
<span className="v" id="v17" data-v="17" data-xref="4. Mose 10:21; 4. Mose 10:17; 4. Mose 3:38"> Darnach soll die Stiftshütte ziehen mit den Lagern der Leviten, mitten unter den Lagern; wie sie sich lagern, also sollen sie auch ziehen, ein jeglicher auf seiner Seite, bei seinem Panier.</span>
<span className="v" id="v18" data-v="18" data-xref="4. Mose 1:10; 4. Mose 10:22; 1. Mose 48:14–20"> Gegen Abend soll liegen das Panier Ephraims mit seinem Heer; ihr Fürst Elischama, der Sohn Ammihuds,</span>
<span className="v" id="v19" data-v="19" data-xref="4. Mose 1:33; 4. Mose 26:37"> samt seinem Heer und seinen Gemusterten, 40500.</span>
<span className="v" id="v20" data-v="20" data-xref="4. Mose 1:10; 4. Mose 7:54; 4. Mose 10:23"> Neben ihm soll sich lagern der Stamm Manasse; ihr Fürst Gamliel, der Sohn Pedazurs;</span>
<span className="v" id="v21" data-v="21" data-xref="4. Mose 26:34; 4. Mose 1:35"> samt seinem Heer und seinen Gemusterten, 32200.</span>
<span className="v" id="v22" data-v="22" data-xref="4. Mose 1:11; 4. Mose 7:60; 4. Mose 10:24"> Dazu der Stamm Benjamin; ihr Fürst Abidan, der Sohn Gideonis,</span>

<span className="v" id="v27" data-v="27" data-xref="4. Mose 1:13; 4. Mose 7:77; 4. Mose 7:72"> Neben ihm soll sich lagern der Stamm Asser; ihr Fürst Pagiel, der Sohn Ochrans,</span>
<span className="v" id="v28" data-v="28" data-xref="4. Mose 1:41; 4. Mose 26:47"> samt seinem Heer und seinen Gemusterten, 41500.</span>
<span className="v" id="v29" data-v="29" data-xref="4. Mose 1:15; 4. Mose 10:27; 4. Mose 26:48–50"> Dazu der Stamm Naphtali, ihr Fürst Ahira, der Sohn Enans,</span>

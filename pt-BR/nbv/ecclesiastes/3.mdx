<span className="v" id="v1" data-v="1" data-xref="Eclesiastes 3:17; Mateus 16:3; Eclesiastes 8:5–6"> Há um tempo certo para cada coisa; há um tempo certo para cada propósito debaixo do céu:</span>
<span className="v" id="v2" data-v="2" data-xref="Hebreus 9:27; Jó 14:5; Mateus 15:13"> <span className="pl pl-1">Tempo para nascer e tempo para morrer;</span><br /><span className="pl pl-1">tempo para plantar e tempo para colher;</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="3.2 Ou “arrancar o que se plantou”.">a</a></sup><br /></span>
<span className="v" id="v3" data-v="3" data-xref="Oseias 6:1–2; 1 Samuel 2:6; Jeremias 45:4"> <span className="pl pl-1">tempo para matar e tempo para curar;</span><br /><span className="pl pl-1">tempo para destruir e tempo para construir de novo;</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="Romanos 12:15; Salmos 30:5; Tiago 4:9"> <span className="pl pl-1">tempo para chorar e tempo para rir;</span><br /><span className="pl pl-1">tempo para ficar triste e tempo para dançar de alegria;</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="2 Reis 3:25; Josué 10:27; Josué 4:3–9"> <span className="pl pl-1">tempo para espalhar pedras e tempo para ajuntar pedras;</span><br /><span className="pl pl-1">tempo para abraçar e tempo para deixar de abraçar;</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="Filipenses 3:7–8; Lucas 9:24–25; Marcos 8:35–37"> <span className="pl pl-1">tempo para procurar e tempo para perder;</span><br /><span className="pl pl-1">tempo para guardar e tempo para jogar fora;</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="Amós 5:13; Miqueias 7:5; Lamentações 3:28"> <span className="pl pl-1">tempo para rasgar e tempo para costurar;</span><br /><span className="pl pl-1">tempo para calar e tempo para falar;</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="Efésios 5:25; Efésios 5:28–29; Lucas 14:26"> <span className="pl pl-1">tempo para amar e tempo para odiar;</span><br /><span className="pl pl-1">tempo para lutar e tempo para viver em paz.</span></span>
<span className="v" id="v9" data-v="9" data-xref="Eclesiastes 1:3; Eclesiastes 5:16; Provérbios 14:23"> Que vantagem o homem tem com todo o trabalho pesado?</span>
<span className="v" id="v10" data-v="10" data-xref="Eclesiastes 1:13–14; Gênesis 3:19; Eclesiastes 2:26"> Tenho visto o trabalho que Deus deu aos filhos dos homens para afligi-los.</span>
<span className="v" id="v11" data-v="11" data-xref="Romanos 11:33; Romanos 1:19–20; Jó 11:7"> Todas as coisas têm seu valor quando são feitas na hora certa. Deus colocou o anseio pela eternidade no coração do homem, mas assim mesmo ele não consegue entender completamente os planos e as obras de Deus.</span>
<span className="v" id="v12" data-v="12" data-xref="Salmos 37:3; Eclesiastes 3:22; 1 Timóteo 6:18"> Por isso, concluí que não há nada melhor para o homem que se alegrar e praticar o bem enquanto viver;</span>
<span className="v" id="v13" data-v="13" data-xref="Salmos 128:2; Eclesiastes 9:7; Eclesiastes 2:24"> descobri também que ele deve comer e beber; aproveitar o resultado de seu trabalho, porque é um presente de Deus.</span>
<span className="v" id="v14" data-v="14" data-xref="Tiago 1:17; Salmos 33:11; Romanos 11:36"> Também aprendi que tudo o que Deus faz permanecerá para sempre — não se pode tirar nem pôr. O que Deus quer é que os homens o temam.</span>
<span className="v" id="v15" data-v="15" data-xref="Eclesiastes 1:9–10; Eclesiastes 6:10"> O que hoje existe, já existia no passado; o que vai surgir também já existiu antes. Deus faz aparecer de novo o que já tinha sido esquecido.</span>
<span className="v" id="v16" data-v="16" data-xref="Eclesiastes 4:1; Eclesiastes 5:8; Salmos 94:21–22"> Além disso, percebi também que debaixo do sol o crime toma o lugar da justiça; a impiedade, o lugar da honestidade.</span>
<span className="v" id="v17" data-v="17" data-xref="2 Coríntios 5:10; Eclesiastes 12:14; Mateus 16:27"> E falei comigo mesmo: Na hora certa, Deus vai julgar tanto o justo como o perverso; pois há um tempo para todo propósito, tudo que fazemos acontece na hora em que tem de acontecer.</span>
<span className="v" id="v18" data-v="18" data-xref="Salmos 73:22; Salmos 49:12; Hebreus 9:27"> Aí compreendi que Deus prova os homens para que vejam que não são melhores do que os animais.</span>
<span className="v" id="v19" data-v="19" data-xref="Salmos 49:12; Salmos 49:20; Salmos 89:47–48"> Os homens e os animais respiram o mesmo ar<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="3.19 Ou “tem o mesmo fôlego” ou “tem o mesmo espírito”.">b</a></sup>e morrem da mesma maneira. Assim, o homem não tem nenhuma vantagem sobre o animal. Tudo é ilusão!</span>
<span className="v" id="v20" data-v="20" data-xref="Gênesis 3:19; Jó 34:15; Eclesiastes 12:7"> Todos acabam indo para o mesmo lugar, voltam ao pó de onde vieram e para onde devem voltar.</span>
<span className="v" id="v21" data-v="21" data-xref="Eclesiastes 12:7; João 14:3; 2 Coríntios 5:1"> Quem pode provar que o espírito<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="3.21 Ou “fôlego”.">c</a></sup>do homem vai para cima e o espírito dos animais desce para a terra?</span>
<span className="v" id="v22" data-v="22" data-xref="Eclesiastes 2:24; Eclesiastes 3:11–12; Eclesiastes 10:14"> Foi assim que eu descobri que o melhor para o homem é se alegrar com o seu trabalho, porque esta é a sua recompensa. Ninguém pode fazer o homem voltar depois de morto para aproveitar aquilo que ainda vai acontecer.</span>

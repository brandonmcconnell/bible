<span className="v" id="v2" data-v="2" data-xref="מעשי השליחים 16:26; הבשורה על־פי יוחנן 20:12–13; הבשורה על־פי מרקוס 16:3–5"> לפתע התחוללה רעידת אדמה חזקה, ומלאך ירד מהשמים, הזיז את האבן שחסמה את הפתח וישב עליה.</span>
<span className="v" id="v3" data-v="3" data-xref="הבשורה על־פי מרקוס 9:3; מעשי השליחים 1:10; הבשורה על־פי מרקוס 16:5"> פניו האירו כברק, ובגדיו היו צחורים כשלג.</span>
<span className="v" id="v4" data-v="4" data-xref="התגלות 1:17; Daniel 10:7; הבשורה על־פי מתי 27:65–66"> כשראו השומרים את המלאך, הם התעלפו מרוב בהלה ונפלו על הארץ כמתים.</span>
<span className="v" id="v5" data-v="5" data-xref="התגלות 1:17–18; האיגרת אל־העברים 1:14; Isaiah 41:10"> ”אל תפחדנה“, פנה המלאך אל הנשים. ”אני יודע שאתן מחפשות את ישוע שנצלב.</span>
<span className="v" id="v6" data-v="6" data-xref="הבשורה על־פי מרקוס 16:6; הבשורה על־פי מתי 12:40; הבשורה על־פי לוקס 24:6–8"> אולם הוא אינו נמצא כאן. ישוע קם לתחייה בדיוק כפי שהבטיח. היכנסו, תראו את המקום שבו שכב.</span>
<span className="v" id="v7" data-v="7" data-xref="הבשורה על־פי מתי 26:32; הבשורה על־פי לוקס 24:22–24; הבשורה על־פי מתי 28:10"> עכשיו לכו מהר אל תלמידיו ותאמרו להם שישוע קם מן המתים, והולך לפניכם לגליל. אתם תראו אותו שם. זהו, אמרתי לכם!“</span>
<span className="v" id="v8" data-v="8" data-xref="Psalms 2:11; הבשורה על־פי מרקוס 16:8; הבשורה על־פי לוקס 24:36–41"> הנשים רצו מן הקבר מבוהלות מאוד, אך מלאות שמחה, ומיהרו למצוא את התלמידים ולמסור להם את בשורת המלאך.</span>
<span className="v" id="v9" data-v="9" data-xref="הבשורה על־פי מתי 28:17; הבשורה על־פי יוחנן 20:14–17; הבשורה על־פי מתי 14:33"> בשעה שרצו נגלה אליהן ישוע. ”שלום לכן“, אמר, והן נפלו לרגליו והשתחוו לפניו.</span>
<span className="v" id="v10" data-v="10" data-xref="אגרת פולוס השליח אל־הרומיים 8:29; הבשורה על־פי יוחנן 20:17; הבשורה על־פי מתי 28:7"> ”אל תפחדו“, הרגיע אותן ישוע. ”לכו ואמרו לאחי ללכת מיד לגליל כדי לפגוש אותי שם.“</span>
<span className="v" id="v11" data-v="11" data-xref="הבשורה על־פי מתי 27:65–66; הבשורה על־פי מתי 28:4"> כשהיו הנשים בדרכן העירה, באו השומרים אל ראשי הכוהנים וסיפרו להם מה שקרה,</span>
<span className="v" id="v12" data-v="12" data-xref="הבשורה על־פי מתי 26:3–4; מעשי השליחים 4:5–22; הבשורה על־פי מתי 27:1–2"> הזקנים התכנסו לאסיפת חרום והחליטו לשחד את השומרים, כדי שיספרו שגופת ישוע נגנבה בזמן שישנו.</span>
<span className="v" id="v14" data-v="14" data-xref="הבשורה על־פי מתי 27:2; מעשי השליחים 12:19"> ”אם יגיע הדבר הזה לאוזני המושל,“ הסבירו, ”נעמוד לצדכם ונפייס אותו.“</span>
<span className="v" id="v15" data-v="15" data-xref="אגרת פולוס הראשונה אל־טימותיוס 6:10; הבשורה על־פי מתי 27:8; הבשורה על־פי מתי 26:15"> וכך קיבלו אנשי המשמר את השוחד ואמרו מה שנתבקשו לומר. גרסתם הופצה בין היהודים, אשר עד היום מאמינים בה.</span>
<span className="v" id="v16" data-v="16" data-xref="הבשורה על־פי מתי 26:32; הבשורה על־פי מתי 28:10; הבשורה על־פי מתי 28:7"> בינתיים הלכו אחד־עשר התלמידים אל הגליל, כדי לפגוש את ישוע על אותו הר שאמר להם מראש.</span>
<span className="v" id="v17" data-v="17" data-xref="Psalms 45:11; Psalms 2:12; הבשורה על־פי יוחנן 5:23"> כשראו אותו התלמידים הם השתחוו לפניו, למרות שחלקם הטילו ספק שאכן היה זה ישוע.</span>
<span className="v" id="v18" data-v="18" data-xref="הבשורה על־פי יוחנן 3:35; אגרתו הראשונה של פטרוס השליח 3:22; הבשורה על־פי מתי 11:27"> ”ניתנה לי כל סמכות בשמים ובארץ“, אמר להם ישוע.</span>
<span className="v" id="v19" data-v="19" data-xref="הבשורה על־פי מרקוס 16:15–16; מעשי השליחים 2:38–39; מעשי השליחים 1:8"> ”משום כך לכו ועשו תלמידים בכל העולם. הטבילו אותם בשם האב, הבן ורוח הקודש,</span>
<span className="v" id="v20" data-v="20" data-xref="Isaiah 41:10; Joshua 1:5; מעשי השליחים 18:9–10"> ולמדו אותם לעשות את כל אשר ציוויתי אתכם. היו סמוכים ובטוחים שאהיה אתכם עד סוף העולם!“</span>

<span className="v" id="v1" data-v="1" data-xref="Eclesiastés 3:17; Mateo 16:3; Eclesiastés 8:5–6"> Para todo hay un tiempo fijo, y un tiempo para cada propósito bajo el cielo.</span>
<span className="v" id="v2" data-v="2" data-xref="Hebreos 9:27; Job 14:5; Mateo 15:13"> Un tiempo para el nacimiento y un tiempo para la muerte; un tiempo para plantar y un tiempo para arrancar de raíz;</span>
<span className="v" id="v3" data-v="3" data-xref="Oseas 6:1–2; 1 Samuel 2:6; Jeremías 45:4"> Un tiempo para dar muerte y un tiempo para sanar; un tiempo para derribar y un tiempo para construir;</span>
<span className="v" id="v4" data-v="4" data-xref="Romanos 12:15; Salmos 30:5; Santiago 4:9"> Un tiempo para llorar y un tiempo para reír; un tiempo para el dolor y un tiempo para bailar;</span>
<span className="v" id="v5" data-v="5" data-xref="2 Reyes 3:25; Josué 10:27; Josué 4:3–9"> Un tiempo para quitar piedras y un tiempo para juntar piedras; un tiempo para abrazar y un tiempo para no abrazar;</span>
<span className="v" id="v6" data-v="6" data-xref="Filipenses 3:7–8; Lucas 9:24–25; Marcos 8:35–37"> Un tiempo para la búsqueda y un tiempo para la pérdida; un tiempo para guardar y un tiempo para regalar;</span>
<span className="v" id="v7" data-v="7" data-xref="Amós 5:13; Miqueas 7:5; Lamentaciones 3:28"> Un tiempo para desgarrar y un tiempo para coser; un tiempo para guardar silencio y un tiempo para hablar;</span>
<span className="v" id="v8" data-v="8" data-xref="Efesios 5:25; Efesios 5:28–29; Lucas 14:26"> Un tiempo para el amor y un tiempo para el odio; un tiempo para la guerra y un tiempo para la paz.</span>
<span className="v" id="v9" data-v="9" data-xref="Eclesiastés 1:3; Eclesiastés 5:16; Proverbios 14:23"> ¿Qué beneficio tiene el trabajador en el trabajo que él hace?</span>
<span className="v" id="v10" data-v="10" data-xref="Eclesiastés 1:13–14; Génesis 3:19; Eclesiastés 2:26"> Vi la obra que Dios ha puesto sobre los hijos del hombre.</span>
<span className="v" id="v11" data-v="11" data-xref="Romanos 11:33; Romanos 1:19–20; Job 11:7"> Él hizo todo hermoso en su tiempo; y entregó el mundo a su voluntad, pero él ha hecho sus corazones sin conocimiento, de modo que el hombre no puede ver las obras de Dios, desde el principio hasta el fin.</span>
<span className="v" id="v12" data-v="12" data-xref="Salmos 37:3; Eclesiastés 3:22; 1 Timoteo 6:18"> Estoy seguro de que no hay nada mejor para un hombre que estar contento y hacer el bien mientras la vida está en él.</span>
<span className="v" id="v13" data-v="13" data-xref="Salmos 128:2; Eclesiastés 9:7; Eclesiastés 2:24"> Y para cada hombre que coma, beba y tenga gozo en toda su obra, es una recompensa de Dios.</span>
<span className="v" id="v14" data-v="14" data-xref="Santiago 1:17; Salmos 33:11; Romanos 11:36"> Estoy seguro de que todo lo que Dios haga será para siempre. No se le puede hacer ninguna adición, no se le puede quitar nada; y Dios lo ha hecho para que el hombre tenga reverencia ante él.</span>
<span className="v" id="v15" data-v="15" data-xref="Eclesiastés 1:9–10; Eclesiastés 6:10"> Lo que ha sido antes, ya es, y lo que debe ser, es ahora; Porque Dios hace la búsqueda de las cosas que son pasadas.</span>
<span className="v" id="v16" data-v="16" data-xref="Eclesiastés 4:1; Eclesiastés 5:8; Salmos 94:21–22"> Y otra vez, vi debajo del sol, en el lugar de los jueces, que el mal estaba allí; y en el lugar de la justicia, que el mal estaba allí.</span>
<span className="v" id="v17" data-v="17" data-xref="2 Corintios 5:10; Eclesiastés 12:14; Mateo 16:27"> Dije en mi corazón: Dios juzgará lo bueno y lo malo; porque ha fijado un tiempo para cada propósito y para cada trabajo.</span>
<span className="v" id="v18" data-v="18" data-xref="Salmos 73:22; Salmos 49:12; Hebreos 9:27"> Dije en mi corazón: Es por los hijos de los hombres, para que Dios los ponga a prueba y se vean a sí mismos como bestias.</span>
<span className="v" id="v19" data-v="19" data-xref="Salmos 49:12; Salmos 49:20; Salmos 89:47–48"> Porque el destino de los hijos de los hombres y el destino de las bestias es el mismo. Como la muerte de uno, así es la muerte del otro, y todos tienen un espíritu. El hombre no tiene ventaja sobre las bestias; porque todo es vanidad.</span>
<span className="v" id="v20" data-v="20" data-xref="Génesis 3:19; Job 34:15; Eclesiastés 12:7"> Todos van a un lugar, todos son del polvo, y todos serán convertidos en polvo nuevamente.</span>
<span className="v" id="v21" data-v="21" data-xref="Eclesiastés 12:7; Juan 14:3; 2 Corintios 5:1"> ¿Quién está seguro de que el espíritu de los hijos de los hombres sube al cielo, o que el espíritu de las bestias desciende a la tierra?</span>
<span className="v" id="v22" data-v="22" data-xref="Eclesiastés 2:24; Eclesiastés 3:11–12; Eclesiastés 10:14"> Entonces vi que no hay nada mejor que un hombre tenga gozo en su trabajo, porque esa es su recompensa. ¿Quién le hará ver lo que vendrá después de él?</span>

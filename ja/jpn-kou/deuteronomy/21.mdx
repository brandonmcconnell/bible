<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="イザヤ書 26:21; 詩篇 5:6; 箴言 28:17"> あなたの神、主が与えて獲させられる地で、殺されて野に倒れている人があって、だれが殺したのかわからない時は、</span>
<span className="v" id="v2" data-v="2" data-xref="ローマ人への手紙 13:3–4; 申命記 16:18–19"> 長老たちと、さばきびとたちが出てきて、その殺された者のある所から、周囲の町々までの距離をはからなければならない。</span>
<span className="v" id="v3" data-v="3" data-xref="民数記 19:2; マタイによる福音書 11:28–30; エレミヤ書 31:18"> そしてその殺された者のある所に最も近い町の長老たちは、まだ使わない、まだくびきを負わせて引いたことのない若い雌牛をとり、</span>
<span className="v" id="v4" data-v="4" data-xref="ペテロの第一の手紙 2:21–24; ペテロの第一の手紙 3:18"> その町の長老たちはその雌牛を、耕すことも、種まくこともしない、絶えず水の流れている谷へ引いていって、その谷で雌牛のくびを折らなければならない。</span>
<span className="v" id="v5" data-v="5" data-xref="歴代志上 23:13; マラキ書 2:7; 申命記 10:8"> その時レビの子孫である祭司たちは、そこに進み出なければならない。彼らはあなたの神、主が自分に仕えさせ、また主の名によって祝福させるために選ばれた者で、すべての論争と、すべての暴行は彼らの言葉によって解決されるからである。</span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 73:13; 詩篇 26:6; 詩篇 51:7"> そしてその殺された者のある所に最も近い町の長老たちは皆、彼らが谷でくびを折った雌牛の上で手を洗い、</span>
<span className="v" id="v7" data-v="7" data-xref="ヨブ記 21:21–23; ヨブ記 21:31–34; サムエル記下 16:8"> 証言して言わなければならない、『われわれの手はこの血を流さず、われわれの目もそれを見なかった。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨナ書 1:14; 列王紀下 24:4; エゼキエル書 23:24–25"> 主よ、あなたがあがなわれた民イスラエルをおゆるしください。罪のない者の血を流したとがを、あなたの民イスラエルのうちにとどめないでください。そして血を流したとがをおゆるしください』。</span>
<span className="v" id="v9" data-v="9" data-xref="申命記 19:12–13; 列王紀下 10:30–31; 申命記 13:18"> このようにして、あなたは主が正しいと見られる事をおこない、罪のない者の血を流したとがを、あなたがたのうちから除き去らなければならない。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="申命記 20:10–16; ヨシュア記 21:44"> あなたが出て敵と戦う際、あなたの神、主がそれをあなたの手にわたされ、あなたがそれを捕虜とした時、</span>
<span className="v" id="v11" data-v="11" data-xref="箴言 31:10; 創世記 34:3; 創世記 12:14–15"> もし捕虜のうちに美しい女のあるのを見て、それを好み、妻にめとろうとするならば、</span>
<span className="v" id="v12" data-v="12" data-xref="レビ記 14:9; 民数記 6:9; エペソ人への手紙 4:22"> その女をあなたの家に連れて帰らなければならない。女は髪をそり、つめを切り、</span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 45:10–11; ルカによる福音書 14:26–27"> また捕虜の着物を脱ぎすてて、あなたの家におり、自分の父母のために一か月のあいだ嘆かなければならない。そして後、あなたは彼女の所にはいって、その夫となり、彼女を妻とすることができる。</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 22:29; 創世記 34:2; 申命記 22:19"> その後あなたがもし彼女を好まなくなったならば、彼女を自由に去らせなければならない。決して金で売ってはならない。あなたはすでに彼女をはずかしめたのだから、彼女を奴隷のようにあしらってはならない。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="創世記 29:33; 創世記 29:20; 創世記 29:18"> 人がふたりの妻をもち、そのひとりは愛する者、ひとりは気にいらない者であって、その愛する者と気にいらない者のふたりが、ともに男の子を産み、もしその長子が、気にいらない女の産んだ者である時は、</span>
<span className="v" id="v16" data-v="16" data-xref="歴代志上 26:10; 歴代志上 5:2; 歴代志下 21:3"> その子たちに自分の財産を継がせる時、気にいらない女の産んだ長子をさしおいて、愛する女の産んだ子を長子とすることはできない。</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 49:3; 創世記 25:31–34; 詩篇 105:36"> 必ずその気にいらない者の産んだ子が長子であることを認め、自分の財産を分ける時には、これに二倍の分け前を与えなければならない。これは自分の力の初めであって、長子の特権を持っているからである。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="レビ記 19:3; 出エジプト記 20:12; アモス書 4:11–12"> もし、わがままで、手に負えない子があって、父の言葉にも、母の言葉にも従わず、父母がこれを懲らしてもきかない時は、</span>
<span className="v" id="v19" data-v="19" data-xref="ゼカリヤ書 13:3; 申命記 21:2; 申命記 16:18"> その父母はこれを捕えて、その町の門に行き、町の長老たちの前に出し、</span>
<span className="v" id="v20" data-v="20" data-xref="箴言 23:29–35; 箴言 20:1; 箴言 23:19–21"> 町の長老たちに言わなければならない、『わたしたちのこの子はわがままで、手に負えません。わたしたちの言葉に従わず、身持ちが悪く、大酒飲みです』。</span>
<span className="v" id="v21" data-v="21" data-xref="申命記 19:19–20; 申命記 13:10–11; レビ記 24:16"> そのとき、町の人は皆、彼を石で撃ち殺し、あなたがたのうちから悪を除き去らなければならない。そうすれば、イスラエルは皆聞いて恐れるであろう。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="ヨハネによる福音書 19:31–38; 使徒行伝 26:31; ルカによる福音書 23:33"> もし人が死にあたる罪を犯して殺され、あなたがそれを木の上にかける時は、</span>
<span className="v" id="v23" data-v="23" data-xref="ガラテヤ人への手紙 3:13; ヨハネによる福音書 19:31; コリント人への第二の手紙 5:21"> 翌朝までその死体を木の上に留めておいてはならない。必ずそれをその日のうちに埋めなければならない。木にかけられた者は神にのろわれた者だからである。あなたの神、主が嗣業として賜わる地を汚してはならない。</span>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命記 11:31; 申命記 4:38; 申命記 1:28"> イスラエルよ、聞きなさい。あなたは、きょう、ヨルダンを渡って行って、あなたよりも大きく、かつ強い国々を取ろうとしている。その町々は大きく、石がきは天に達している。</span>
<span className="v" id="v2" data-v="2" data-xref="民数記 13:22; ナホム書 1:6; 申命記 7:24"> その民は、あなたの知っているアナクびとの子孫であって、大きく、また背が高い。あなたはまた『アナクの子孫の前に、だれが立つことができようか』と人の言うのを聞いた。</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 4:24; ヘブル人への手紙 12:29; ローマ人への手紙 8:31"> それゆえ、あなたは、きょう、あなたの神、主は焼きつくす火であって、あなたの前に進まれることを知らなければならない。主は彼らを滅ぼし、彼らをあなたの前に屈伏させられるであろう。主があなたに言われたように、彼らを追い払い、すみやかに滅ぼさなければならない。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="申命記 8:17; 申命記 9:5; 申命記 18:9–14"> あなたの神、主があなたの前から彼らを追い払われた後に、あなたは心のなかで『わたしが正しいから主はわたしをこの地に導き入れてこれを獲させられた』と言ってはならない。この国々の民が悪いから、主はこれをあなたの前から追い払われるのである。</span>
<span className="v" id="v5" data-v="5" data-xref="テトスヘの手紙 3:5; 創世記 17:8; 創世記 26:4"> あなたが行ってその地を獲るのは、あなたが正しいからではなく、またあなたの心がまっすぐだからでもない。この国々の民が悪いから、あなたの神、主は彼らをあなたの前から追い払われるのである。これは主があなたの先祖アブラハム、イサク、ヤコブに誓われた言葉を行われるためである。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="申命記 10:16; 使徒行伝 7:51; 申命記 31:27"> それであなたは、あなたの神、主があなたにこの良い地を与えてこれを得させられるのは、あなたが正しいからではないことを知らなければならない。あなたは強情な民である。</span>
<span className="v" id="v7" data-v="7" data-xref="出エジプト記 16:2; 出エジプト記 14:11; 民数記 21:5"> あなたは荒野であなたの神、主を怒らせたことを覚え、それを忘れてはならない。あなたがたはエジプトの地を出た日からこの所に来るまで、いつも主にそむいた。</span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 106:19–22; 出エジプト記 32:16; 出エジプト記 32:7–10"> またホレブにおいてさえ、あなたがたが主を怒らせたので、主は怒ってあなたがたを滅ぼそうとされた。</span>
<span className="v" id="v9" data-v="9" data-xref="出エジプト記 34:28; 出エジプト記 24:18; 列王紀上 19:8"> わたしが石の板すなわち主があなたがたと結ばれた契約の板を受けるために山に登った時、わたしは四十日四十夜、山にいて、パンも食べず水も飲まなかった。</span>
<span className="v" id="v10" data-v="10" data-xref="出エジプト記 31:18; ヘブル人への手紙 8:10; 申命記 10:4"> 主は神の指をもって書きしるした石の板二枚をわたしに授けられた。その上には、集会の日に主が山で火の中から、あなたがたに告げられた言葉が、ことごとく書いてあった。</span>
<span className="v" id="v11" data-v="11" data-xref="申命記 9:9; 民数記 10:33; ヘブル人への手紙 8:6–10"> すなわち四十日四十夜が終った時、主はわたしにその契約の板である石の板二枚を授け、</span>
<span className="v" id="v12" data-v="12" data-xref="出エジプト記 32:7–8; 申命記 31:29; 士師記 2:17"> そして主はわたしに言われた、『おまえは立って、すみやかにこの所から降りなさい。おまえがエジプトから導き出した民は悪を行ったからである。彼らはわたしが命じた道を早くも離れて、鋳た像を自分たちのために造った』。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="申命記 9:6; 列王紀下 17:14; 申命記 10:16"> 主はまたわたしに言われた、『この民を見るのに、これは強情な民である。</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 29:20; 出エジプト記 32:10–13; 詩篇 9:5"> わたしを止めるな。わたしは彼らを滅ぼし、彼らの名を天の下から消し去り、おまえを彼らよりも強く、かつ大いなる国民としよう』。</span>
<span className="v" id="v15" data-v="15" data-xref="出エジプト記 19:18; 申命記 5:23; 申命記 4:11"> そこでわたしは身をめぐらして山を降りたが、山は火で焼けていた。契約の板二枚はわたしの両手にあった。</span>
<span className="v" id="v16" data-v="16" data-xref="出エジプト記 32:19; 使徒行伝 7:40–41"> そしてわたしが見ると、あなたがたは、あなたがたの神、主にむかって罪を犯し、自分たちのために鋳物の子牛を造って、主が命じられた道を早くも離れたので、</span>
<span className="v" id="v17" data-v="17"> わたしはその二枚の板をつかんで、両手から投げ出し、あなたがたの目の前でこれを砕いた。</span>
<span className="v" id="v18" data-v="18" data-xref="出エジプト記 34:28; 申命記 9:9; 詩篇 106:23"> そしてわたしは前のように四十日四十夜、主の前にひれ伏し、パンも食べず、水も飲まなかった。これはあなたがたが主の目の前に悪をおこない、罪を犯して主を怒らせたすべての罪によるのである。</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 10:10; 出エジプト記 32:14; ヤコブの手紙 5:16–17"> 主は怒りを発し、憤りを起し、あなたがたを怒って滅ぼそうとされたので、わたしは恐れたが、その時もまた主はわたしの願いを聞かれた。</span>
<span className="v" id="v20" data-v="20" data-xref="出エジプト記 32:35; 出エジプト記 32:21; ヘブル人への手紙 7:26–28"> 主はまた、はなはだしくアロンを怒って、彼を滅ぼそうとされたが、わたしはその時もまたアロンのために祈った。</span>
<span className="v" id="v21" data-v="21" data-xref="出エジプト記 32:20; イザヤ書 31:7; イザヤ書 2:18–21"> わたしはあなたがたが造って罪を得た子牛を取り、それを火で焼き、それを撃ち砕き、よくひいて細かいちりとし、そのちりを山から流れ下る谷川に投げ捨てた。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="民数記 11:34; 出エジプト記 17:7; 民数記 11:1–5"> あなたがたはタベラ、マッサおよびキブロテ・ハッタワにおいてもまた主を怒らせた。</span>
<span className="v" id="v23" data-v="23" data-xref="詩篇 106:24–25; ヘブル人への手紙 4:2; 詩篇 78:22"> また主はカデシ・バルネアから、あなたがたをつかわそうとされた時、『上って行って、わたしが与える地を占領せよ』と言われた。ところが、あなたがたはあなたがたの神、主の命令にそむき、彼を信ぜず、また彼の声に聞き従わなかった。</span>
<span className="v" id="v24" data-v="24" data-xref="申命記 31:27; 使徒行伝 7:51; 申命記 9:6–7"> わたしがあなたがたを知ったその日からこのかた、あなたがたはいつも主にそむいた。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="申命記 9:18; 申命記 9:16"> そしてわたしは、さきにひれ伏したように、四十日四十夜、主の前にひれ伏した。主があなたがたを滅ぼすと言われたからである。</span>
<span className="v" id="v26" data-v="26" data-xref="出エジプト記 32:11–13; テトスヘの手紙 2:14; 詩篇 107:2"> わたしは主に祈って言った、『主なる神よ、あなたが大いなる力をもってあがない、強い手をもってエジプトから導き出されたあなたの民、あなたの嗣業を滅ぼさないでください。</span>
<span className="v" id="v27" data-v="27" data-xref="エレミヤ書 14:21; ミカ書 7:18–19; サムエル記上 25:25"> あなたのしもべアブラハム、イサク、ヤコブを覚えてください。この民の強情と悪と罪とに目をとめないでください。</span>
<span className="v" id="v28" data-v="28" data-xref="民数記 14:16; 出エジプト記 32:12"> あなたがわれわれを導き出された国の人はおそらく、「主は、約束した地に彼らを導き入れることができず、また彼らを憎んだので、彼らを導き出して荒野で殺したのだ」と言うでしょう。</span>
<span className="v" id="v29" data-v="29" data-xref="ネヘミヤ書 1:10; 列王紀上 8:51; 申命記 9:26"> しかし彼らは、あなたの民、あなたの嗣業であって、あなたが大いなる力と伸ばした腕とをもって導き出されたのです』。</span>
</div>

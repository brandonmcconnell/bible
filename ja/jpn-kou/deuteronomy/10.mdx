<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出エジプト記 34:1–2; 出エジプト記 25:10–15; 申命記 10:3–4"> その時、主はわたしに言われた、『おまえは、前のような石の板二枚を切って作り、山に登って、わたしのもとにきなさい。また木の箱一つを作りなさい。</span>
<span className="v" id="v2" data-v="2" data-xref="列王紀上 8:9; 申命記 10:5; 申命記 4:13"> さきにおまえが砕いた二枚の板に書いてあった言葉を、わたしはその板に書きしるそう。おまえはそれをその箱におさめなければならない』。</span>
<span className="v" id="v3" data-v="3" data-xref="出エジプト記 34:4; 出エジプト記 37:1–9; 出エジプト記 25:10"> そこでわたしはアカシヤ材の箱一つを作り、また前のような石の板二枚を切って作り、その二枚の板を手に持って山に登った。</span>
<span className="v" id="v4" data-v="4" data-xref="申命記 9:10; 出エジプト記 34:28; ヘブル人への手紙 12:18–19"> 主はかつて、かの集会の日に山で火の中からあなたがたに告げられた十誡を書きしるされたように、その板に書きしるし、それを主はわたしに授けられた。</span>
<span className="v" id="v5" data-v="5" data-xref="出エジプト記 34:29; 出エジプト記 40:20; 申命記 10:2"> それでわたしは身をめぐらして山から降り、その板を、わたしが作った箱におさめた。今なおその中にある。主がわたしに命じられたとおりである。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="民数記 33:38; 民数記 20:23–28; 民数記 33:30–33"> （こうしてイスラエルの人々はベエロテ・ベネ・ヤカンを出立してモセラに着いた。アロンはその所で死んでそこに葬られ、その子エレアザルが彼に代って祭司となった。</span>
<span className="v" id="v7" data-v="7" data-xref="民数記 33:32–34"> またそこを出立してグデゴダに至り、グデゴダを出立してヨテバタに着いた。この地には多くの水の流れがあった。</span>
<span className="v" id="v8" data-v="8" data-xref="申命記 21:5; 申命記 18:5; 民数記 6:23–26"> その時、主はレビの部族を選んで、主の契約の箱をかつぎ、主の前に立って仕え、また主の名をもって祝福することをさせられた。この事は今日に及んでいる。</span>
<span className="v" id="v9" data-v="9" data-xref="エゼキエル書 44:28; 民数記 18:20–24; 申命記 18:1–2"> そのためレビは兄弟たちと一緒には分け前がなく、嗣業もない。あなたの神、主が彼に言われたとおり、主みずからが彼の嗣業であった。）</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="申命記 9:18–19; 申命記 9:25; 出エジプト記 34:28"> わたしは前の時のように四十日四十夜、山におったが、主はその時にもわたしの願いを聞かれた。主はあなたを滅ぼすことを望まれなかった。</span>
<span className="v" id="v11" data-v="11" data-xref="出エジプト記 33:1; 出エジプト記 32:34"> そして主はわたしに『おまえは立ちあがり、民に先立って進み行き、わたしが彼らに与えると、その先祖に誓った地に彼らをはいらせ、それを取らせよ』と言われた。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="ミカ書 6:8; 申命記 6:5; ルカによる福音書 10:27"> イスラエルよ、今、あなたの神、主があなたに求められる事はなんであるか。ただこれだけである。すなわちあなたの神、主を恐れ、そのすべての道に歩んで、彼を愛し、心をつくし、精神をつくしてあなたの神、主に仕え、</span>
<span className="v" id="v13" data-v="13" data-xref="エレミヤ書 32:39; 申命記 6:24; ヤコブの手紙 1:25"> また、わたしがきょうあなたに命じる主の命令と定めとを守って、さいわいを得ることである。</span>
<span className="v" id="v14" data-v="14" data-xref="出エジプト記 19:5; 詩篇 24:1; 詩篇 115:16"> 見よ、天と、もろもろの天の天、および地と、地にあるものとはみな、あなたの神、主のものである。</span>
<span className="v" id="v15" data-v="15" data-xref="申命記 4:37; 申命記 7:7–8; ローマ人への手紙 9:13–23"> そうであるのに、主はただあなたの先祖たちを喜び愛し、その後の子孫であるあなたがたを万民のうちから選ばれた。今日見るとおりである。</span>
<span className="v" id="v16" data-v="16" data-xref="エレミヤ書 4:4; 申命記 30:6; レビ記 26:41"> それゆえ、あなたがたは心に割礼をおこない、もはや強情であってはならない。</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行伝 10:34; ローマ人への手紙 2:11; ダニエル書 2:47"> あなたがたの神である主は、神の神、主の主、大いにして力ある恐るべき神にましまし、人をかたより見ず、また、まいないを取らず、</span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 146:9; 詩篇 68:5; エレミヤ書 49:11"> みなし子とやもめのために正しいさばきを行い、また寄留の他国人を愛して、食物と着物を与えられるからである。</span>
<span className="v" id="v19" data-v="19" data-xref="出エジプト記 22:21; レビ記 19:33–34; ルカによる福音書 17:18"> それゆえ、あなたがたは寄留の他国人を愛しなさい。あなたがたもエジプトの国で寄留の他国人であった。</span>
<span className="v" id="v20" data-v="20" data-xref="申命記 6:13; 申命記 13:4; ルカによる福音書 4:8"> あなたの神、主を恐れ、彼に仕え、彼に従い、その名をさして誓わなければならない。</span>
<span className="v" id="v21" data-v="21" data-xref="エレミヤ書 17:14; 詩篇 106:21–22; 出エジプト記 15:2"> 彼はあなたのさんびすべきもの、またあなたの神であって、あなたが目に見たこれらの大いなる恐るべき事を、あなたのために行われた。</span>
<span className="v" id="v22" data-v="22" data-xref="創世記 46:27; 出エジプト記 1:5; 創世記 15:5"> あなたの先祖たちは、わずか七十人でエジプトに下ったが、いま、あなたの神、主はあなたを天の星のように多くされた。</span>

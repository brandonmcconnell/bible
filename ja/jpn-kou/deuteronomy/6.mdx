<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命記 4:1; 申命記 12:1; 申命記 4:45"> これはあなたがたの神、主があなたがたに教えよと命じられた命令と、定めと、おきてであって、あなたがたは渡って行って獲る地で、これを行わなければならない。</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 4:40; 申命記 13:4; 出エジプト記 20:20"> これはあなたが子や孫と共に、あなたの生きながらえる日の間、つねにあなたの神、主を恐れて、わたしが命じるもろもろの定めと、命令とを守らせるため、またあなたが長く命を保つことのできるためである。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 22:17; 出エジプト記 3:8; 創世記 26:4"> それゆえ、イスラエルよ、聞いて、それを守り行え。そうすれば、あなたはさいわいを得、あなたの先祖の神、主があなたに言われたように、乳と蜜の流れる国で、あなたの数は大いに増すであろう。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="マルコによる福音書 12:29–32; イザヤ書 44:6; テモテヘの第一の手紙 2:5"> イスラエルよ聞け。われわれの神、主は唯一の主である。</span>
<span className="v" id="v5" data-v="5" data-xref="マルコによる福音書 12:30; マタイによる福音書 22:37; ルカによる福音書 10:27"> あなたは心をつくし、精神をつくし、力をつくして、あなたの神、主を愛さなければならない。</span>
<span className="v" id="v6" data-v="6" data-xref="コロサイ人への手紙 3:16; 箴言 7:3; エレミヤ書 31:33"> きょう、わたしがあなたに命じるこれらの言葉をあなたの心に留め、</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 11:19; エペソ人への手紙 6:4; 詩篇 78:4–6"> 努めてこれをあなたの子らに教え、あなたが家に座している時も、道を歩く時も、寝る時も、起きる時も、これについて語らなければならない。</span>
<span className="v" id="v8" data-v="8" data-xref="箴言 6:21; 箴言 3:3; 申命記 11:18"> またあなたはこれをあなたの手につけてしるしとし、あなたの目の間に置いて覚えとし、</span>
<span className="v" id="v9" data-v="9" data-xref="申命記 11:20; イザヤ書 30:8; イザヤ書 57:8"> またあなたの家の入口の柱と、あなたの門とに書きしるさなければならない。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="ヨシュア記 24:13; 詩篇 105:44; ネヘミヤ書 9:25"> あなたの神、主は、あなたの先祖アブラハム、イサク、ヤコブに向かって、あなたに与えると誓われた地に、あなたをはいらせられる時、あなたが建てたものでない大きな美しい町々を得させ、</span>
<span className="v" id="v11" data-v="11" data-xref="申命記 7:12–18; 申命記 8:10–20; エゼキエル書 16:10–20"> あなたが満たしたものでないもろもろの良い物を満たした家を得させ、あなたが掘ったものでない掘り井戸を得させ、あなたが植えたものでないぶどう畑とオリブの畑とを得させられるであろう。あなたは食べて飽きるであろう。</span>
<span className="v" id="v12" data-v="12"> その時、あなたはみずから慎み、エジプトの地、奴隷の家から導き出された主を忘れてはならない。</span>
<span className="v" id="v13" data-v="13" data-xref="ルカによる福音書 4:8; 申命記 10:20; マタイによる福音書 4:10"> あなたの神、主を恐れてこれに仕え、その名をさして誓わなければならない。</span>
<span className="v" id="v14" data-v="14" data-xref="エレミヤ書 25:6; ヨハネの第一の手紙 5:21; 申命記 13:7"> あなたがたは他の神々すなわち周囲の民の神々に従ってはならない。</span>
<span className="v" id="v15" data-v="15" data-xref="申命記 4:24; 出エジプト記 20:5; 申命記 7:4"> あなたのうちにおられるあなたの神、主はねたむ神であるから、おそらく、あなたに向かって怒りを発し、地のおもてからあなたを滅ぼし去られるであろう。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="出エジプト記 17:7; ルカによる福音書 4:12; マタイによる福音書 4:7"> あなたがたがマッサでしたように、あなたがたの神、主を試みてはならない。</span>
<span className="v" id="v17" data-v="17" data-xref="申命記 11:22; 詩篇 119:4; コリント人への第一の手紙 15:58"> あなたがたの神、主があなたがたに命じられた命令と、あかしと、定めとを、努めて守らなければならない。</span>
<span className="v" id="v18" data-v="18" data-xref="申命記 4:40; 申命記 12:25; ローマ人への手紙 12:2"> あなたは主が見て正しいとし、良いとされることを行わなければならない。そうすれば、あなたはさいわいを得、かつ主があなたの先祖に誓われた、あの良い地にはいって、自分のものとすることができるであろう。</span>
<span className="v" id="v19" data-v="19" data-xref="民数記 33:52–53; 出エジプト記 23:28–30; 士師記 3:1–4"> また主が仰せられたように、あなたの敵を皆あなたの前から追い払われるであろう。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="出エジプト記 13:14; 出エジプト記 12:26; ヨシュア記 4:6–7"> 後の日となって、あなたの子があなたに問うて言うであろう、『われわれの神、主があなたがたに命じられたこのあかしと、定めと、おきてとは、なんのためですか』。</span>
<span className="v" id="v21" data-v="21" data-xref="ローマ人への手紙 6:17–18; エペソ人への手紙 2:11–12; 申命記 15:15"> その時あなたはその子に言わなければならない。『われわれはエジプトでパロの奴隷であったが、主は強い手をもって、われわれをエジプトから導き出された。</span>
<span className="v" id="v22" data-v="22" data-xref="申命記 4:34; 詩篇 58:10–11; 申命記 7:19"> 主はわれわれの目の前で、大きな恐ろしいしるしと不思議とをエジプトと、パロとその全家とに示され、</span>
<span className="v" id="v23" data-v="23" data-xref="申命記 6:18; 申命記 6:10; 出エジプト記 13:5"> われわれをそこから導き出し、かつてわれわれの先祖に誓われた地にはいらせ、それをわれわれに賜わった。</span>
<span className="v" id="v24" data-v="24" data-xref="エレミヤ書 32:39; 詩篇 41:2; 申命記 10:12–13"> そして主はこのすべての定めを行えと、われわれに命じられた。これはわれわれの神、主を恐れて、われわれが、つねにさいわいであり、また今日のように、主がわれわれを守って命を保たせるためである。</span>
<span className="v" id="v25" data-v="25" data-xref="申命記 24:13; ローマ人への手紙 10:3; レビ記 18:5"> もしわれわれが、命じられたとおりに、このすべての命令をわれわれの神、主の前に守って行うならば、それはわれわれの義となるであろう』。</span>
</div>

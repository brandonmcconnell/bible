<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命記 31:10; 出エジプト記 23:10–11; レビ記 25:2–4"> あなたは七年の終りごとに、ゆるしを行わなければならない。</span>
<span className="v" id="v2" data-v="2" data-xref="ルカによる福音書 7:42; ヤコブの手紙 2:13; ルカによる福音書 6:34–38"> そのゆるしのしかたは次のとおりである。すべてその隣人に貸した貸主はそれをゆるさなければならない。その隣人または兄弟にそれを督促してはならない。主のゆるしが、ふれ示されたからである。</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 23:20; マタイによる福音書 17:25–26; コリント人への第一の手紙 6:6–7"> 外国人にはそれを督促することができるが、あなたの兄弟に貸した物はゆるさなければならない。</span>
<span className="v" id="v4" data-v="4" data-xref="イザヤ書 58:10–11; 箴言 28:27; 箴言 11:24–25"> しかしあなたがたのうちに貧しい者はなくなるであろう。（あなたの神、主が嗣業として与えられる地で、あなたを祝福されるからである。）</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 28:1–15; イザヤ書 1:19–20; ヨシュア記 1:7"> ただ、あなたの神、主の言葉に聞き従って、わたしが、きょう、あなたに命じることの戒めを、ことごとく守り行うとき、そのようになるであろう。</span>
<span className="v" id="v6" data-v="6" data-xref="申命記 28:12–13; ルカによる福音書 6:35; ネヘミヤ書 9:27"> あなたの神、主が約束されたようにあなたを祝福されるから、あなたは多くの国びとに貸すようになり、借りることはないであろう。またあなたは多くの国びとを治めるようになり、彼らがあなたを治めることはないであろう。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="ヨハネの第一の手紙 3:16–17; 申命記 15:9; 箴言 21:13"> あなたの神、主が賜わる地で、もしあなたの兄弟で貧しい者がひとりでも、町の内におるならば、その貧しい兄弟にむかって、心をかたくなにしてはならない。また手を閉じてはならない。</span>
<span className="v" id="v8" data-v="8" data-xref="ルカによる福音書 6:34; マタイによる福音書 5:42"> 必ず彼に手を開いて、その必要とする物を貸し与え、乏しいのを補わなければならない。</span>
<span className="v" id="v9" data-v="9" data-xref="申命記 24:15; マタイによる福音書 20:15; エレミヤ書 17:10"> あなたは心に邪念を起し、『第七年のゆるしの年が近づいた』と言って、貧しい兄弟に対し、物を惜しんで、何も与えないことのないように慎まなければならない。その人があなたを主に訴えるならば、あなたは罪を得るであろう。</span>
<span className="v" id="v10" data-v="10" data-xref="箴言 22:9; ヘブル人への手紙 13:16; イザヤ書 58:10"> あなたは心から彼に与えなければならない。彼に与える時は惜しんではならない。あなたの神、主はこの事のために、あなたをすべての事業と、手のすべての働きにおいて祝福されるからである。</span>
<span className="v" id="v11" data-v="11" data-xref="マルコによる福音書 14:7; マタイによる福音書 26:11; ヨハネによる福音書 12:8"> 貧しい者はいつまでも国のうちに絶えることがないから、わたしは命じて言う、『あなたは必ず国のうちにいるあなたの兄弟の乏しい者と、貧しい者とに、手を開かなければならない』。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="エレミヤ書 34:14; レビ記 25:39–41; 出エジプト記 21:2–6"> もしあなたの兄弟であるヘブルの男、またはヘブルの女が、あなたのところに売られてきて、六年仕えたならば、第七年には彼に自由を与えて去らせなければならない。</span>
<span className="v" id="v13" data-v="13" data-xref="マラキ書 3:5; エレミヤ書 22:13; 箴言 3:27–28"> 彼に自由を与えて去らせる時は、から手で去らせてはならない。</span>
<span className="v" id="v14" data-v="14" data-xref="コリント人への第一の手紙 16:2; 箴言 10:22; 詩篇 68:10"> 群れと、打ち場と、酒ぶねのうちから取って、惜しみなく彼に与えなければならない。すなわちあなたの神、主があなたを恵まれたように、彼に与えなければならない。</span>
<span className="v" id="v15" data-v="15" data-xref="申命記 16:12; マタイによる福音書 18:32–33; 申命記 5:14–15"> あなたはかつてエジプトの国で奴隷であったが、あなたの神、主があなたをあがない出された事を記憶しなければならない。このゆえにわたしは、きょう、この事を命じる。</span>
<span className="v" id="v16" data-v="16" data-xref="出エジプト記 21:5–6; 詩篇 40:8; 詩篇 40:6"> しかしその人があなたと、あなたの家族を愛し、あなたと一緒にいることを望み、『わたしはあなたを離れて去りたくありません』と言うならば、</span>
<span className="v" id="v17" data-v="17" data-xref="サムエル記上 1:22; レビ記 25:39–42"> あなたは、きりを取って彼の耳を戸に刺さなければならない。そうすれば、彼はいつまでもあなたの奴隷となるであろう。女奴隷にもそうしなければならない。</span>
<span className="v" id="v18" data-v="18" data-xref="ルカによる福音書 17:7–8; イザヤ書 16:14; イザヤ書 21:16"> 彼に自由を与えて去らせる時には、快く去らせなければならない。彼が六年間、賃銀を取る雇人の二倍あなたに仕えて働いたからである。あなたがそうするならば、あなたの神、主はあなたが行うすべての事にあなたを祝福されるであろう。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="出エジプト記 13:2; 出エジプト記 13:12; レビ記 27:26"> 牛、羊の産む雄のういごは皆あなたの神、主に聖別しなければならない。牛のういごを用いてなんの仕事をもしてはならない。また羊のういごの毛を切ってはならない。</span>
<span className="v" id="v20" data-v="20" data-xref="申命記 12:17; 申命記 14:23; 申命記 12:5–7"> あなたの神、主が選ばれる所で、主の前にあなたは家族と共に年ごとにそれを食べなければならない。</span>
<span className="v" id="v21" data-v="21" data-xref="申命記 17:1; マラキ書 1:7–8; レビ記 22:19–25"> しかし、その獣がもし傷のあるもの、すなわち足なえまたは、めくらなど、すべて悪い傷のあるものである時は、あなたの神、主にそれを犠牲としてささげてはならない。</span>
<span className="v" id="v22" data-v="22" data-xref="申命記 12:21–22; 申命記 12:15–16"> 町の内でそれを食べなければならない。汚れた人も、清い人も、かもしかや、雄じかと同様にそれを食べることができる。</span>
<span className="v" id="v23" data-v="23" data-xref="申命記 12:16; レビ記 7:26; 申命記 12:23"> ただし、その血は食べてはならない。水のようにそれを地にそそがなければならない。</span>
</div>

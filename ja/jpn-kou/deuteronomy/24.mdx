<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マタイによる福音書 19:7–9; マルコによる福音書 10:4–12; イザヤ書 50:1"> 人が妻をめとって、結婚したのちに、その女に恥ずべきことのあるのを見て、好まなくなったならば、離縁状を書いて彼女の手に渡し、家を去らせなければならない。</span>
<span className="v" id="v2" data-v="2" data-xref="マルコによる福音書 10:11; コリント人への第一の手紙 7:15; エゼキエル書 44:22"> 女がその家を出てのち、行って、ほかの人にとつぎ、</span>
<span className="v" id="v3" data-v="3"> 後の夫も彼女をきらって、離縁状を書き、その手に渡して家を去らせるか、または妻にめとった後の夫が死んだときは、</span>
<span className="v" id="v4" data-v="4" data-xref="エレミヤ書 3:1; ヨシュア記 22:17–18; レビ記 18:24–28"> 彼女はすでに身を汚したのちであるから、彼女を去らせた先の夫は、ふたたび彼女を妻にめとることはできない。これは主の前に憎むべき事だからである。あなたの神、主が嗣業としてあなたに与えられる地に罪を負わせてはならない。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="箴言 5:18; 申命記 20:7; 創世記 2:24"> 人が新たに妻をめとった時は、戦争に出してはならない。また何の務もこれに負わせてはならない。その人は一年の間、束縛なく家にいて、そのめとった妻を慰めなければならない。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="申命記 20:19; ルカによる福音書 12:15; ヨハネの黙示録 18:22"> ひきうす、またはその上石を質にとってはならない。これは命をつなぐものを質にとることだからである。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="出エジプト記 21:16; テモテヘの第一の手紙 1:10; 出エジプト記 22:1–4"> イスラエルの人々のうちの同胞のひとりをかどわかして、これを奴隷のようにあしらい、またはこれを売る者を見つけたならば、そのかどわかした者を殺して、あなたがたのうちから悪を除き去らなければならない。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="レビ記 14:2; マルコによる福音書 1:44; レビ記 13:1–46"> らい病の起った時は気をつけて、すべてレビびとたる祭司が教えることを、よく守って行わなければならない。すなわちわたしが彼らに命じたように、あなたがたはそれを守って行わなければならない。</span>
<span className="v" id="v9" data-v="9" data-xref="民数記 12:10–15; コリント人への第一の手紙 10:11; コリント人への第一の手紙 10:6"> あなたがたがエジプトから出てきたとき、道であなたの神、主がミリアムにされたことを記憶しなければならない。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="申命記 15:8; 出エジプト記 22:27"> あなたが隣人に物を貸すときは、自分でその家にはいって、質物を取ってはならない。</span>
<span className="v" id="v11" data-v="11"> あなたは外に立っていて、借りた人が質物を外にいるあなたのところへ持ち出さなければならない。</span>
<span className="v" id="v12" data-v="12" data-xref="申命記 24:17; ヨブ記 22:6; ヨブ記 24:3"> もしその人が貧しい人である時は、あなたはその質物を留めおいて寝てはならない。</span>
<span className="v" id="v13" data-v="13" data-xref="申命記 6:25; ダニエル書 4:27; 出エジプト記 22:26–27"> その質物は日の入るまでに、必ず返さなければならない。そうすれば彼は自分の上着をかけて寝ることができて、あなたを祝福するであろう。それはあなたの神、主の前にあなたの義となるであろう。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="マラキ書 3:5; 箴言 14:31; 箴言 22:16"> 貧しく乏しい雇人は、同胞であれ、またはあなたの国で、町のうちに寄留している他国人であれ、それを虐待してはならない。</span>
<span className="v" id="v15" data-v="15" data-xref="レビ記 19:13; 箴言 3:27–28; ヤコブの手紙 5:4"> 賃銀はその日のうちに払い、それを日の入るまで延ばしてはならない。彼は貧しい者で、その心をこれにかけているからである。そうしなければ彼はあなたを主に訴えて、あなたは罪を得るであろう。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="エゼキエル書 18:20; 歴代志下 25:4; エレミヤ書 31:29–30"> 父は子のゆえに殺さるべきではない。子は父のゆえに殺さるべきではない。おのおの自分の罪のゆえに殺さるべきである。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="申命記 16:19; 申命記 27:19; 出エジプト記 23:6"> 寄留の他国人または孤児のさばきを曲げてはならない。寡婦の着物を質に取ってはならない。</span>
<span className="v" id="v18" data-v="18" data-xref="申命記 5:15; 申命記 15:15; 申命記 16:12"> あなたはかつてエジプトで奴隷であったが、あなたの神、主がそこからあなたを救い出されたことを記憶しなければならない。それでわたしはあなたにこの事をせよと命じるのである。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="レビ記 23:22; レビ記 19:9–10; 申命記 14:29"> あなたが畑で穀物を刈る時、もしその一束を畑におき忘れたならば、それを取りに引き返してはならない。それは寄留の他国人と孤児と寡婦に取らせなければならない。そうすればあなたの神、主はすべてあなたがする事において、あなたを祝福されるであろう。</span>
<span className="v" id="v20" data-v="20" data-xref="レビ記 19:10"> あなたがオリブの実をうち落すときは、ふたたびその枝を捜してはならない。それを寄留の他国人と孤児と寡婦に取らせなければならない。</span>
<span className="v" id="v21" data-v="21" data-xref="レビ記 19:9–10; 申命記 24:19"> またぶどう畑のぶどうを摘み取るときは、その残ったものを、ふたたび捜してはならない。それを寄留の他国人と孤児と寡婦に取らせなければならない。</span>
<span className="v" id="v22" data-v="22" data-xref="申命記 24:18; ヨハネの第一の手紙 4:10–11; 申命記 5:14–15"> あなたはかつてエジプトの国で奴隷であったことを記憶しなければならない。それでわたしはあなたにこの事をせよと命じるのである。</span>
</div>

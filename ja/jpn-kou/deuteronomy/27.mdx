<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨハネによる福音書 15:14; ルカによる福音書 11:28; ヤコブの手紙 2:10"> モーセとイスラエルの長老たちとは民に命じて言った、「わたしが、きょう、あなたがたに命じるすべての戒めを守りなさい。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨシュア記 8:31; エゼキエル書 36:26; エゼキエル書 11:19"> あなたがたがヨルダンを渡ってあなたの神、主が賜わる国にはいる時、あなたは大きな石数個を立てて、それにしっくいを塗り、</span>
<span className="v" id="v3" data-v="3" data-xref="ヨシュア記 8:32; 申命記 26:9; コリント人への第二の手紙 3:2–3"> そしてあなたが渡って、あなたの先祖たちの神、主が約束されたようにあなたの神、主が賜わる地、すなわち乳と蜜の流れる地にはいる時、この律法のすべての言葉をその上に書きしるさなければならない。</span>
<span className="v" id="v4" data-v="4" data-xref="申命記 11:29–30; ヨシュア記 8:30–33"> すなわち、あなたがたが、ヨルダンを渡ったならば、わたしが、きょう、あなたがたに命じるそれらの石をエバル山に立て、それにしっくいを塗らなければならない。</span>
<span className="v" id="v5" data-v="5" data-xref="出エジプト記 20:25; 出エジプト記 24:4; ヨシュア記 8:30–31"> またそこにあなたの神、主のために、祭壇、すなわち石の祭壇を築かなければならない。鉄の器を石に当てず、</span>
<span className="v" id="v6" data-v="6" data-xref="エペソ人への手紙 5:2; レビ記 1:1–17"> 自然のままの石であなたの神、主のために祭壇を築き、その上であなたの神、主に燔祭をささげなければならない。</span>
<span className="v" id="v7" data-v="7" data-xref="レビ記 3:1–17; イザヤ書 12:3; 詩篇 100:1–2"> また酬恩祭の犠牲をささげて、その所で食べ、あなたの神、主の前で喜び楽しまなければならない。</span>
<span className="v" id="v8" data-v="8" data-xref="ハバクク書 2:2; ヨハネによる福音書 16:25; コリント人への第二の手紙 3:12"> あなたはこの律法のすべての言葉をその石の上に明らかに書きしるさなければならない」。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="ペテロの第一の手紙 2:10–11; 申命記 26:16–18; エペソ人への手紙 5:8–9"> またモーセとレビびとたる祭司たちとは、イスラエルのすべての人々に言った、「イスラエルよ、静かに聞きなさい。あなたは、きょう、あなたの神、主の民となった。</span>
<span className="v" id="v10" data-v="10" data-xref="申命記 11:1; ペテロの第一の手紙 1:14–16; マタイによる福音書 5:48"> それゆえ、あなたの神、主の声に聞き従い、わたしが、きょう、命じる戒めと定めとを行わなければならない」。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11"> その日またモーセは民に命じて言った、</span>
<span className="v" id="v12" data-v="12" data-xref="士師記 9:7; 創世記 30:24; 創世記 35:18"> 「あなたがたがヨルダンを渡った時、次の人たちはゲリジム山に立って民を祝福しなければならない。すなわちシメオン、レビ、ユダ、イッサカル、ヨセフおよびベニヤミン。</span>
<span className="v" id="v13" data-v="13" data-xref="申命記 27:4; 創世記 29:32; 創世記 30:20"> また次の人たちはエバル山に立ってのろわなければならない。すなわちルベン、ガド、アセル、ゼブルン、ダンおよびナフタリ。</span>
<span className="v" id="v14" data-v="14" data-xref="ダニエル書 9:11; 申命記 33:9–10; ヨシュア記 8:33"> そしてレビびとは大声でイスラエルのすべての人々に告げて言わなければならない。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="出エジプト記 34:17; 出エジプト記 20:4; 申命記 5:8"> 『工人の手の作である刻んだ像、または鋳た像は、主が憎まれるものであるから、それを造って、ひそかに安置する者はのろわれる』。民は、みな答えてアァメンと言わなければならない。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="レビ記 19:3; 出エジプト記 21:17; 申命記 21:18–21"> 『父や母を軽んずる者はのろわれる』。民はみなアァメンと言わなければならない。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="申命記 19:14; 箴言 22:28; 箴言 23:10–11"> 『隣人との土地の境を移す者はのろわれる』。民はみなアァメンと言わなければならない。</span>
</div>
<div className="bp">

</div>
<div className="bp">

</div>
<div className="bp">

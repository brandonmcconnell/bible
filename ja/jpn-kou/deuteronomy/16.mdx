<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出エジプト記 34:18; 出エジプト記 12:2–20; 出エジプト記 13:4"> あなたはアビブの月を守って、あなたの神、主のために過越の祭を行わなければならない。アビブの月に、あなたの神、主が夜の間にあなたをエジプトから導き出されたからである。</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 12:5; 申命記 12:26; ルカによる福音書 22:15"> 主がその名を置くために選ばれる場所で、羊または牛をあなたの神、主に過越の犠牲としてほふらなければならない。</span>
<span className="v" id="v3" data-v="3" data-xref="出エジプト記 12:39; 出エジプト記 34:18; 出エジプト記 12:19–20"> 種を入れたパンをそれと共に食べてはならない。七日のあいだ、種入れぬパンすなわち悩みのパンを、それと共に食べなければならない。あなたがエジプトの国から出るとき、急いで出たからである。こうして世に生きながらえる日の間、エジプトの国から出てきた日を常に覚えなければならない。</span>
<span className="v" id="v4" data-v="4" data-xref="出エジプト記 34:25; 出エジプト記 12:10; 出エジプト記 13:7"> その七日の間は、国の内どこにもパン種があってはならない。また初めの日の夕暮にほふるものの肉を、翌朝まで残しておいてはならない。</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 16:2; 申命記 12:5–6"> あなたの神、主が賜わる町の内で、過越の犠牲をほふってはならない。</span>
<span className="v" id="v6" data-v="6" data-xref="申命記 12:5; 出エジプト記 12:6–9; 民数記 9:11"> ただあなたの神、主がその名を置くために選ばれる場所で、夕暮の日の入るころ、あなたがエジプトから出た時刻に、過越の犠牲をほふらなければならない。</span>
<span className="v" id="v7" data-v="7" data-xref="歴代志下 35:13; 出エジプト記 12:8–9; ヨハネによる福音書 2:23"> そしてあなたの神、主が選ばれる場所で、それを焼いて食べ、朝になって天幕に帰らなければならない。</span>
<span className="v" id="v8" data-v="8" data-xref="出エジプト記 13:6–8; レビ記 23:6–8; レビ記 23:36"> 六日のあいだ種入れぬパンを食べ、七日目にあなたの神、主のために聖会を開かなければならない。なんの仕事もしてはならない。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="出エジプト記 34:22; 出エジプト記 23:16; 使徒行伝 2:1"> また七週間を数えなければならない。すなわち穀物に、かまを入れ始める時から七週間を数え始めなければならない。</span>
<span className="v" id="v10" data-v="10" data-xref="コリント人への第一の手紙 16:2; レビ記 12:8; マラキ書 3:10–11"> そしてあなたの神、主のために七週の祭を行い、あなたの神、主が賜わる祝福にしたがって、力に応じ、自発の供え物をささげなければならない。</span>
<span className="v" id="v11" data-v="11" data-xref="申命記 12:7; 申命記 12:12; 申命記 12:18"> こうしてあなたはむすこ、娘、しもべ、はしためおよび町の内におるレビびと、ならびにあなたがたのうちにおる寄留の他国人と孤児と寡婦と共に、あなたの神、主がその名を置くために選ばれる場所で、あなたの神、主の前に喜び楽しまなければならない。</span>
<span className="v" id="v12" data-v="12" data-xref="申命記 15:15; 哀歌 3:19–20; ローマ人への手紙 6:17–18"> あなたはかつてエジプトで奴隷であったことを覚え、これらの定めを守り行わなければならない。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="出エジプト記 23:16; ヨハネによる福音書 7:2; 歴代志下 5:3"> 打ち場と、酒ぶねから取入れをしたとき、七日のあいだ仮庵の祭を行わなければならない。</span>
<span className="v" id="v14" data-v="14" data-xref="ネヘミヤ書 8:9–12; 申命記 16:11; イザヤ書 30:29"> その祭の時には、あなたはむすこ、娘、しもべ、はしためおよび町の内におるレビびと、寄留の他国人、孤児、寡婦と共に喜び楽しまなければならない。</span>
<span className="v" id="v15" data-v="15" data-xref="レビ記 23:36–42; 申命記 30:16; 申命記 16:10"> 主が選ばれる場所で七日の間、あなたの神、主のために祭を行わなければならない。あなたの神、主はすべての産物と、手のすべてのわざとにおいて、あなたを祝福されるから、あなたは大いに喜び楽しまなければならない。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="箴言 3:9–10; 詩篇 96:8; ハガイ書 1:9"> あなたのうちの男子は皆あなたの神、主が選ばれる場所で、年に三度、すなわち種入れぬパンの祭と、七週の祭と、仮庵の祭に、主の前に出なければならない。ただし、から手で主の前に出てはならない。</span>
<span className="v" id="v17" data-v="17" data-xref="コリント人への第二の手紙 9:6–7; コリント人への第二の手紙 8:12; 申命記 16:10"> あなたの神、主が賜わる祝福にしたがい、おのおの力に応じて、ささげ物をしなければならない。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="歴代志上 23:4; 出エジプト記 18:25–26; ローマ人への手紙 13:1–6"> あなたの神、主が賜わるすべての町々の内に、部族にしたがって、さばきびとと、つかさびととを、立てなければならない。そして彼らは正しいさばきをもって民をさばかなければならない。</span>
<span className="v" id="v19" data-v="19" data-xref="レビ記 19:15; 出エジプト記 23:2; 箴言 17:23"> あなたはさばきを曲げてはならない。人をかたより見てはならない。また賄賂を取ってはならない。賄賂は賢い者の目をくらまし、正しい者の事件を曲げるからである。</span>
<span className="v" id="v20" data-v="20" data-xref="ピリピ人への手紙 4:8; エゼキエル書 18:9; エゼキエル書 18:5"> ただ公義をのみ求めなければならない。そうすればあなたは生きながらえて、あなたの神、主が賜わる地を所有するにいたるであろう。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="歴代志下 33:3; 列王紀下 17:16; 出エジプト記 34:13"> あなたの神、主のために築く祭壇のかたわらに、アシラの木像をも立ててはならない。</span>
<span className="v" id="v22" data-v="22" data-xref="レビ記 26:1; 出エジプト記 20:4; ゼカリヤ書 8:17"> またあなたの神、主が憎まれる柱を立ててはならない。</span>
</div>

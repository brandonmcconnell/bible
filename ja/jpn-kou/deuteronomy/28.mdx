<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="イザヤ書 1:19; 出エジプト記 23:22; レビ記 26:3–13"> もしあなたが、あなたの神、主の声によく聞き従い、わたしが、きょう、命じるすべての戒めを守り行うならば、あなたの神、主はあなたを地のもろもろの国民の上に立たせられるであろう。</span>
<span className="v" id="v2" data-v="2" data-xref="ゼカリヤ書 1:6; 申命記 28:15; テモテヘの第一の手紙 4:8"> もし、あなたがあなたの神、主の声に聞き従うならば、このもろもろの祝福はあなたに臨み、あなたに及ぶであろう。</span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 144:12–15; 創世記 39:5; ハガイ書 2:19"> あなたは町の内でも祝福され、畑でも祝福されるであろう。</span>
<span className="v" id="v4" data-v="4" data-xref="箴言 10:22; 創世記 49:25; 申命記 7:13"> またあなたの身から生れるもの、地に産する物、家畜の産むもの、すなわち牛の子、羊の子は祝福されるであろう。</span>
<span className="v" id="v5" data-v="5"> またあなたのかごと、こねばちは祝福されるであろう。</span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 121:8; 民数記 27:17; 歴代志下 1:10"> あなたは、はいるにも祝福され、出るにも祝福されるであろう。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="サムエル記下 22:38–41; レビ記 26:7–8; 詩篇 89:23"> 敵が起ってあなたを攻める時は、主はあなたにそれを撃ち敗らせられるであろう。彼らは一つの道から攻めて来るが、あなたの前で七つの道から逃げ去るであろう。</span>
<span className="v" id="v8" data-v="8" data-xref="申命記 15:10; レビ記 26:10; 箴言 3:9–10"> 主は命じて祝福をあなたの倉と、あなたの手のすべてのわざにくだし、あなたの神、主が賜わる地であなたを祝福されるであろう。</span>
<span className="v" id="v9" data-v="9" data-xref="出エジプト記 19:5–6; 申命記 7:6; 申命記 26:18–19"> もし、あなたの神、主の戒めを守り、その道を歩むならば、主は誓われたようにあなたを立てて、その聖なる民とされるであろう。</span>
<span className="v" id="v10" data-v="10" data-xref="歴代志下 7:14; 申命記 11:25; エレミヤ書 33:9"> そうすれば地のすべての民は皆あなたが主の名をもって唱えられるのを見てあなたを恐れるであろう。</span>
<span className="v" id="v11" data-v="11" data-xref="申命記 30:9; 箴言 10:22; レビ記 26:9"> 主があなたに与えると先祖に誓われた地で、主は良い物、すなわちあなたの身から生れる者、家畜の産むもの、地に産する物を豊かにされるであろう。</span>
<span className="v" id="v12" data-v="12" data-xref="申命記 15:6; ヨエル書 2:23–24; 申命記 15:10"> 主はその宝の蔵である天をあなたのために開いて、雨を季節にしたがってあなたの地に降らせ、あなたの手のすべてのわざを祝福されるであろう。あなたは多くの国民に貸すようになり、借りることはないであろう。</span>
<span className="v" id="v13" data-v="13" data-xref="申命記 28:1; 申命記 4:6–9; ピリピ人への手紙 1:27"> 主はあなたをかしらとならせ、尾とはならせられないであろう。あなたはただ栄えて衰えることはないであろう。きょう、わたしが命じるあなたの神、主の戒めに聞き従って、これを守り行うならば、あなたは必ずこのようになるであろう。</span>
<span className="v" id="v14" data-v="14" data-xref="イザヤ書 30:21; 申命記 5:32; 申命記 11:16"> きょう、わたしが命じるこのすべての言葉を離れて右または左に曲り、他の神々に従い、それに仕えてはならない。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="マラキ書 2:2; 申命記 28:2; 申命記 29:20"> しかし、あなたの神、主の声に聞き従わず、きょう、わたしが命じるすべての戒めと定めとを守り行わないならば、このもろもろののろいがあなたに臨み、あなたに及ぶであろう。</span>
<span className="v" id="v16" data-v="16" data-xref="マラキ書 3:9–12; 箴言 3:33; ヨエル書 1:4"> あなたは町のうちでものろわれ、畑でものろわれ、</span>
<span className="v" id="v17" data-v="17" data-xref="ハガイ書 1:6; 申命記 28:5; 詩篇 69:22"> あなたのかごも、こねばちものろわれ、</span>
<span className="v" id="v18" data-v="18" data-xref="レビ記 26:26; レビ記 26:19–20; ヨブ記 18:16–19"> あなたの身から生れるもの、地に産する物、牛の子、羊の子ものろわれるであろう。</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 28:6; 士師記 5:6–7; 歴代志下 15:5"> あなたは、はいるにものろわれ、出るにものろわれるであろう。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="イザヤ書 66:15; マラキ書 2:2; 申命記 4:26"> 主はあなたが手をくだすすべての働きにのろいと、混乱と、懲しめとを送られ、あなたはついに滅び、すみやかにうせ果てるであろう。これはあなたが悪をおこなってわたしを捨てたからである。</span>
<span className="v" id="v21" data-v="21" data-xref="レビ記 26:25; エレミヤ書 24:10; エレミヤ書 16:4"> 主は疫病をあなたの身につかせ、あなたが行って取る地から、ついにあなたを断ち滅ぼされるであろう。</span>
<span className="v" id="v22" data-v="22" data-xref="アモス書 4:9; レビ記 26:16; ハガイ書 2:17"> 主はまた肺病と熱病と炎症と間けつ熱と、かんばつと、立ち枯れと、腐り穂とをもってあなたを撃たれるであろう。これらのものはあなたを追い、ついにあなたを滅ぼすであろう。</span>
<span className="v" id="v23" data-v="23" data-xref="レビ記 26:19; エレミヤ書 14:1–6; 列王紀上 18:2"> あなたの頭の上の天は青銅となり、あなたの下の地は鉄となるであろう。</span>
<span className="v" id="v24" data-v="24" data-xref="申命記 28:12; イザヤ書 5:24; アモス書 4:11"> 主はあなたの地の雨を、ちりと、ほこりに変らせ、それが天からあなたの上にくだって、ついにあなたを滅ぼすであろう。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="イザヤ書 30:17; エゼキエル書 23:46; エレミヤ書 24:9"> 主はあなたを敵の前で敗れさせられるであろう。あなたは一つの道から彼らを攻めて行くが、彼らの前で七つの道から逃げ去るであろう。そしてあなたは地のもろもろの国に恐るべき見せしめとなるであろう。</span>
<span className="v" id="v26" data-v="26" data-xref="エレミヤ書 34:20; エレミヤ書 16:4; エレミヤ書 7:33"> またあなたの死体は空のもろもろの鳥と、地の獣とのえじきとなり、しかもそれを追い払う者はないであろう。</span>
<span className="v" id="v27" data-v="27" data-xref="サムエル記上 5:6; 申命記 28:35; レビ記 21:20"> 主はエジプトの腫物と潰瘍と壊血病とひぜんとをもってあなたを撃たれ、あなたはいやされることはないであろう。</span>
<span className="v" id="v28" data-v="28" data-xref="テサロニケ人への第二の手紙 2:9–11; イザヤ書 19:11–17; イザヤ書 6:9–10"> また主はあなたを撃って気を狂わせ、目を見えなくし、心を混乱させられるであろう。</span>
<span className="v" id="v29" data-v="29" data-xref="イザヤ書 59:10; ヨブ記 5:14; 士師記 6:1–6"> あなたは盲人が暗やみに手探りするように、真昼にも手探りするであろう。あなたは行く道で栄えることがなく、ただ常にしえたげられ、かすめられるだけで、あなたを救う者はないであろう。</span>
<span className="v" id="v30" data-v="30" data-xref="アモス書 5:11; エレミヤ書 8:10; ヨブ記 31:10"> あなたは妻をめとっても、ほかの人が彼女と寝るであろう。家を建てても、その中に住まないであろう。ぶどう畑を作っても、その実を摘み取ることがないであろう。</span>
<span className="v" id="v31" data-v="31" data-xref="ヨブ記 1:14–15; 士師記 6:1"> あなたの牛が目の前でほふられても、あなたはそれを食べることができず、あなたのろばが目の前で奪われても、返されないであろう。あなたの羊が敵のものになっても、それを救ってあなたに返す者はないであろう。</span>
<span className="v" id="v32" data-v="32" data-xref="ヨエル書 3:6; 申命記 28:41; ヨブ記 17:5"> あなたのむすこや娘は他国民にわたされる。あなたの目はそれを見、終日、彼らを慕って衰えるが、あなたは手を施すすべもないであろう。</span>
<span className="v" id="v33" data-v="33" data-xref="エレミヤ書 5:17; 申命記 28:29–30; イザヤ書 1:7"> あなたの地の産物およびあなたの労して獲た物はみなあなたの知らない民が食べるであろう。あなたは、ただ常にしえたげられ、苦しめられるのみであろう。</span>
<span className="v" id="v34" data-v="34" data-xref="ヨハネの黙示録 16:10–11; 申命記 28:68; イザヤ書 33:14"> こうしてあなたは目に見る事柄によって、気が狂うにいたるであろう。</span>
<span className="v" id="v35" data-v="35" data-xref="申命記 28:27; イザヤ書 3:24; イザヤ書 3:17"> 主はあなたのひざと、はぎとに悪い、いやし得ない腫物を生じさせて、足の裏から頭の頂にまで及ぼされるであろう。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="エレミヤ書 16:13; 申命記 4:28; 列王紀下 25:11"> 主はあなたとあなたが立てた王とを携えて、あなたもあなたの先祖も知らない国に移されるであろう。あなたはそこで木や石で造ったほかの神々に仕えるであろう。</span>
<span className="v" id="v37" data-v="37" data-xref="エレミヤ書 25:9; 列王紀上 9:7–8; エレミヤ書 24:9"> あなたは主があなたを追いやられるもろもろの民のなかで驚きとなり、ことわざとなり、笑い草となるであろう。</span>
<span className="v" id="v38" data-v="38" data-xref="ハガイ書 1:6; ミカ書 6:15; ヨエル書 1:4"> あなたが多くの種を畑に携えて出ても、その収穫は少ないであろう。いなごがそれを食いつくすからである。</span>
<span className="v" id="v39" data-v="39" data-xref="イザヤ書 17:10–11; ヨエル書 2:2–4; ヨナ書 4:7"> あなたがぶどう畑を作り、それにつちかっても、そのぶどう酒を飲むことができず、その実を集めることもないであろう。虫がそれを食べるからである。</span>
<span className="v" id="v40" data-v="40" data-xref="ミカ書 6:15; 詩篇 23:5; 詩篇 104:15"> あなたの国にはあまねくオリブの木があるであろう。しかし、あなたはその油を身に塗ることができないであろう。その実がみな落ちてしまうからである。</span>
<span className="v" id="v41" data-v="41" data-xref="申命記 28:32; 哀歌 1:5; 列王紀下 24:14"> むすこや、娘があなたに生れても、あなたのものにならないであろう。彼らは捕えられて行くからである。</span>
<span className="v" id="v42" data-v="42" data-xref="アモス書 7:1–2; 申命記 28:38–39"> あなたのもろもろの木、および地の産物は、いなごが取って食べるであろう。</span>
<span className="v" id="v43" data-v="43" data-xref="申命記 28:13; サムエル記上 13:19–23; 列王紀下 17:20"> あなたのうちに寄留する他国人は、ますます高くなり、あなたの上に出て、あなたはますます低くなるであろう。</span>
<span className="v" id="v44" data-v="44" data-xref="申命記 28:12–13; 哀歌 1:5"> 彼はあなたに貸し、あなたは彼に貸すことができない。彼はかしらとなり、あなたは尾となるであろう。</span>
<span className="v" id="v45" data-v="45" data-xref="申命記 28:15; イザヤ書 1:20; エレミヤ書 24:9–10"> このもろもろののろいが、あなたに臨み、あなたを追い、ついに追いついて、あなたを滅ぼすであろう。これはあなたの神、主の声に聞き従わず、あなたに命じられた戒めと定めとを、あなたが守らなかったからである。</span>
<span className="v" id="v46" data-v="46" data-xref="イザヤ書 8:18; 申命記 28:37; エゼキエル書 14:8"> これらの事は長くあなたとあなたの子孫のうえにあって、しるしとなり、また不思議となるであろう。</span>
</div>
<div className="bp">
<span className="v" id="v47" data-v="47" data-xref="申命記 16:11; 申命記 12:7–12; ネヘミヤ書 9:35–37"> あなたがすべての物に豊かになり、あなたの神、主に心から喜び楽しんで仕えないので、</span>
<span className="v" id="v48" data-v="48" data-xref="エレミヤ書 28:13–14; 哀歌 5:2–6; エゼキエル書 4:16–17"> あなたは飢え、かわき、裸になり、すべての物に乏しくなって、主があなたにつかわされる敵に仕えるであろう。敵は鉄のくびきをあなたのくびにかけ、ついにあなたを滅ぼすであろう。</span>
<span className="v" id="v49" data-v="49" data-xref="哀歌 4:19; エレミヤ書 49:22; エレミヤ書 48:40"> すなわち主は遠い所から、地のはてから一つの民を、はげたかが飛びかけるように、あなたに攻めきたらせられるであろう。これはあなたがその言葉を知らない民、</span>
<span className="v" id="v50" data-v="50" data-xref="イザヤ書 47:6; 歴代志下 36:17; ルカによる福音書 21:23–24"> 顔の恐ろしい民であって、彼らは老人の身を顧みず、幼い者をあわれまず、</span>
<span className="v" id="v51" data-v="51" data-xref="申命記 28:33; イザヤ書 62:8; レビ記 26:26"> あなたの家畜が産むものや、地の産物を食って、あなたを滅ぼし、穀物をも、酒をも、油をも、牛の子をも、羊の子をも、あなたの所に残さず、ついにあなたを全く滅ぼすであろう。</span>
<span className="v" id="v52" data-v="52" data-xref="エレミヤ書 52:4–7; エゼキエル書 4:1–8; マタイによる福音書 24:15–16"> その民は全国ですべての町を攻め囲み、ついにあなたが頼みとする、堅固な高い石がきをことごとく撃ちくずし、あなたの神、主が賜わった国のうちのすべての町々を攻め囲むであろう。</span>
<span className="v" id="v53" data-v="53" data-xref="哀歌 4:10; エレミヤ書 19:9; レビ記 26:29"> あなたは敵に囲まれ、激しく攻めなやまされて、ついにあなたの神、主が賜わったあなたの身から生れた者、むすこ、娘の肉を食べるに至るであろう。</span>
<span className="v" id="v54" data-v="54" data-xref="申命記 15:9; マタイによる福音書 20:15; 申命記 13:6"> あなたがたのうちのやさしい、温和な男でさえも、自分の兄弟、自分のふところの妻、最後に残っている子供にも食物を惜しんで与えず、</span>
<span className="v" id="v55" data-v="55" data-xref="エレミヤ書 34:2; エレミヤ書 52:6; エレミヤ書 5:10"> 自分が自分の子供を食べ、その肉を少しでも、この人々のだれにも与えようとはしないであろう。これは敵があなたのすべての町々を囲み、激しく攻め悩まして、何をもその人に残さないからである。</span>
<span className="v" id="v56" data-v="56" data-xref="申命記 28:54; イザヤ書 3:16; 哀歌 4:3–6"> またあなたがたのうちのやさしい、柔和な女、すなわち柔和で、やさしく、足の裏を土に付けようともしない者でも、自分のふところの夫や、むすこ、娘にもかくして、</span>
<span className="v" id="v57" data-v="57" data-xref="イザヤ書 49:15; 創世記 49:10"> 自分の足の間からでる後産や、自分の産む子をひそかに食べるであろう。敵があなたの町々を囲み、激しく攻めなやまして、すべての物が欠乏するからである。</span>
</div>
<div className="bp">
<span className="v" id="v58" data-v="58" data-xref="イザヤ書 42:8; エレミヤ書 7:9–10; マラキ書 1:14"> もしあなたが、この書物にしるされているこの律法のすべての言葉を守り行わず、あなたの神、主というこの栄えある恐るべき名を恐れないならば、</span>
<span className="v" id="v59" data-v="59" data-xref="マルコによる福音書 13:19; 申命記 28:46; ダニエル書 9:12"> 主はあなたとその子孫の上に激しい災を下されるであろう。その災はきびしく、かつ久しく、その病気は重く、かつ久しいであろう。</span>
<span className="v" id="v60" data-v="60" data-xref="申命記 7:15; 出エジプト記 15:26; 申命記 28:27"> 主はまた、あなたが恐れた病気、すなわちエジプトのもろもろの病気を再び臨ませて、あなたの身につかせられるであろう。</span>
<span className="v" id="v61" data-v="61" data-xref="申命記 4:25–26"> またこの律法の書にのせてないもろもろの病気と、もろもろの災とを、主はあなたが滅びるまで、あなたの上に下されるであろう。</span>
<span className="v" id="v62" data-v="62" data-xref="申命記 10:22; ネヘミヤ書 9:23; 申命記 4:27"> あなたがたは天の星のように多かったが、あなたの神、主の声に聞き従わなかったから、残る者が少なくなるであろう。</span>
<span className="v" id="v63" data-v="63" data-xref="箴言 1:26; エレミヤ書 32:41; 申命記 30:9"> さきに主があなたがたを良くあしらい、あなたがたを多くするのを喜ばれたように、主は今あなたがたを滅ぼし絶やすのを喜ばれるであろう。あなたがたは、はいって取る地から抜き去られるであろう。</span>
<span className="v" id="v64" data-v="64" data-xref="申命記 4:27–28; レビ記 26:33; エレミヤ書 16:13"> 主は地のこのはてから、かのはてまでのもろもろの民のうちにあなたがたを散らされるであろう。その所で、あなたもあなたの先祖たちも知らなかった木や石で造ったほかの神々にあなたは仕えるであろう。</span>

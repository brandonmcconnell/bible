<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命記 15:21; マラキ書 1:8; 申命記 23:18"> すべて傷があり、欠けた所のある牛または羊はあなたの神、主にささげてはならない。そのようなものはあなたの神、主の忌みきらわれるものだからである。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="士師記 2:20; ホセア書 8:1; ヨシュア記 7:11"> あなたの神、主が賜わる町で、あなたがたのうちに、もし男子または女子があなたの神、主の前に悪事をおこなって、契約にそむき、</span>
<span className="v" id="v3" data-v="3" data-xref="エレミヤ書 7:31; 申命記 4:19; ヨブ記 31:26–27"> 行って他の神々に仕え、それを拝み、わたしの禁じる、日や月やその他の天の万象を拝むことがあり、</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネによる福音書 7:51; 申命記 13:12–14; 申命記 19:18"> その事を知らせる者があって、あなたがそれを聞くならば、あなたはそれをよく調べなければならない。そしてその事が真実であり、そのような憎むべき事が確かにイスラエルのうちに行われていたならば、</span>
<span className="v" id="v5" data-v="5" data-xref="レビ記 24:14; ヨシュア記 7:25; レビ記 24:16"> あなたはその悪事をおこなった男子または女子を町の門にひき出し、その男子または女子を石で撃ち殺さなければならない。</span>
<span className="v" id="v6" data-v="6" data-xref="民数記 35:30; ヘブル人への手紙 10:28; テモテヘの第一の手紙 5:19"> ふたりの証人または三人の証人の証言によって殺すべき者を殺さなければならない。ただひとりの証人の証言によって殺してはならない。</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 13:9; コリント人への第一の手紙 5:13; 申命記 17:12"> そのような者を殺すには、証人がまず手を下し、それから民が皆、手を下さなければならない。こうしてあなたのうちから悪を除き去らなければならない。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="申命記 12:5; ハガイ書 2:11; 申命記 1:17"> 町の内に訴え事が起り、その事件がもし血を流す事、または権利を争う事、または人を撃った事などであって、あなたが、さばきかねるものである時は、立ってあなたの神、主が選ばれる場所にのぼり、</span>
<span className="v" id="v9" data-v="9" data-xref="エゼキエル書 44:24; ハガイ書 2:11; マラキ書 2:7"> レビびとである祭司と、その時の裁判人とに行って尋ねなければならない。彼らはあなたに判決の言葉を告げるであろう。</span>
<span className="v" id="v10" data-v="10" data-xref="マタイによる福音書 22:2–3"> あなたは、主が選ばれるその場所で、彼らが告げる言葉に従っておこない、すべて彼らが教えるように守り行わなければならない。</span>
<span className="v" id="v11" data-v="11" data-xref="ヨシュア記 1:7; 申命記 5:32; ローマ人への手紙 13:1–6"> すなわち彼らが教える律法と、彼らが告げる判決とに従って行わなければならない。彼らが告げる言葉にそむいて、右にも左にもかたよってはならない。</span>
<span className="v" id="v12" data-v="12" data-xref="民数記 15:30; 申命記 13:5; 申命記 18:5"> もし人がほしいままにふるまい、あなたの神、主の前に立って仕える祭司または裁判人に聞き従わないならば、その人を殺して、イスラエルのうちから悪を除かなければならない。</span>
<span className="v" id="v13" data-v="13" data-xref="申命記 13:11; 申命記 19:20; 民数記 15:30–31"> そうすれば民は皆、聞いて恐れ、重ねてほしいままにふるまうことをしないであろう。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="サムエル記上 8:19–20; サムエル記上 12:19; ヨシュア記 1:13"> あなたの神、主が賜わる地に行き、それを獲てそこに住むようになる時、もしあなたが『わたしも周囲のすべての国びとのように、わたしの上に王を立てよう』と言うならば、</span>
<span className="v" id="v15" data-v="15" data-xref="エレミヤ書 30:21; 歴代志上 22:10; 歴代志上 12:23"> 必ずあなたの神、主が選ばれる者を、あなたの上に立てて王としなければならない。同胞のひとりを、あなたの上に立てて王としなければならない。同胞でない外国人をあなたの上に立ててはならない。</span>
<span className="v" id="v16" data-v="16" data-xref="イザヤ書 31:1–3; エゼキエル書 17:15; 申命記 28:68"> 王となる人は自分のために馬を多く獲ようとしてはならない。また馬を多く獲るために民をエジプトに帰らせてはならない。主はあなたがたにむかって、『この後かさねてこの道に帰ってはならない』と仰せられたからである。</span>
<span className="v" id="v17" data-v="17" data-xref="ネヘミヤ書 13:26; マタイによる福音書 19:5; 箴言 30:8–9"> また妻を多く持って心を、迷わしてはならない。また自分のために金銀を多くたくわえてはならない。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="申命記 31:9; 列王紀下 22:8; 歴代志下 34:15"> 彼が国の王位につくようになったら、レビびとである祭司の保管する書物から、この律法の写しを一つの書物に書きしるさせ、</span>
<span className="v" id="v19" data-v="19" data-xref="ヨシュア記 1:8; 詩篇 119:97–100; 詩篇 1:2"> 世に生きながらえる日の間、常にそれを自分のもとに置いて読み、こうしてその神、主を恐れることを学び、この律法のすべての言葉と、これらの定めとを守って行わなければならない。</span>
<span className="v" id="v20" data-v="20" data-xref="申命記 5:32; 列王紀上 15:5; 詩篇 131:1–2"> そうすれば彼の心が同胞を見くだして、高ぶることなく、また戒めを離れて、右にも左にも曲ることなく、その子孫と共にイスラエルにおいて、長くその位にとどまることができるであろう。</span>
</div>

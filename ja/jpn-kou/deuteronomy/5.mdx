<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命記 4:1; マタイによる福音書 23:3; 申命記 29:10"> さてモーセはイスラエルのすべての人を召し寄せて言った、「イスラエルよ、きょう、わたしがあなたがたの耳に語る定めと、おきてを聞き、これを学び、これを守って行え。</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 4:23; 出エジプト記 19:5–8; 出エジプト記 24:8"> われわれの神、主はホレブで、われわれと契約を結ばれた。</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 29:10–15; 創世記 17:21; 創世記 17:7"> 主はこの契約をわれわれの先祖たちとは結ばず、きょう、ここに生きながらえているわれわれすべての者と結ばれた。</span>
<span className="v" id="v4" data-v="4" data-xref="出エジプト記 19:18–19; 申命記 34:10; 出エジプト記 19:9"> 主は山で火の中から、あなたがたと顔を合わせて語られた。</span>
<span className="v" id="v5" data-v="5" data-xref="ガラテヤ人への手紙 3:19; 出エジプト記 19:16; 出エジプト記 20:18–21"> その時、わたしは主とあなたがたとの間に立って主の言葉をあなたがたに伝えた。あなたがたは火のゆえに恐れて山に登ることができなかったからである。主は言われた、</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="出エジプト記 20:2–17; 詩篇 81:5–10; レビ記 26:1–2"> 『わたしはあなたの神、主であって、あなたをエジプトの地、奴隷の家から導き出した者である。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="出エジプト記 20:3; マタイによる福音書 4:10; ヨハネの第一の手紙 5:21"> あなたはわたしのほかに何ものをも神としてはならない。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="出エジプト記 20:4; 申命記 4:15–19"> あなたは自分のために刻んだ像を造ってはならない。上は天にあるもの、下は地にあるもの、また地の下の水の中にあるものの、どのような形をも造ってはならない。</span>
<span className="v" id="v9" data-v="9" data-xref="出エジプト記 20:4–6; 出エジプト記 34:7; ダニエル書 9:4–9"> それを拝んではならない。またそれに仕えてはならない。あなたの神、主であるわたしは、ねたむ神であるから、わたしを憎むものには、父の罪を子に報いて三、四代に及ぼし、</span>
<span className="v" id="v10" data-v="10" data-xref="ローマ人への手紙 8:28; ヨハネの第一の手紙 1:7; エレミヤ書 32:18"> わたしを愛し、わたしの戒めを守る者には恵みを施して千代に至るであろう。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="出エジプト記 20:7; レビ記 19:12; 申命記 6:13"> あなたの神、主の名をみだりに唱えてはならない。主はその名をみだりに唱える者を罰しないではおかないであろう。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="出エジプト記 20:8–11; イザヤ書 58:13; イザヤ書 56:6"> 安息日を守ってこれを聖とし、あなたの神、主があなたに命じられたようにせよ。</span>
<span className="v" id="v13" data-v="13" data-xref="エゼキエル書 20:12; ルカによる福音書 13:14–16; 出エジプト記 23:12"> 六日のあいだ働いて、あなたのすべてのわざをしなければならない。</span>
<span className="v" id="v14" data-v="14" data-xref="ヘブル人への手紙 4:4; 創世記 2:2; 出エジプト記 23:12"> 七日目はあなたの神、主の安息であるから、なんのわざをもしてはならない。あなたも、あなたのむすこ、娘、しもべ、はしため、牛、ろば、もろもろの家畜も、あなたの門のうちにおる他国の人も同じである。こうしてあなたのしもべ、はしためを、あなたと同じように休ませなければならない。</span>
<span className="v" id="v15" data-v="15" data-xref="申命記 5:6; 申命記 15:15; 申命記 16:12"> あなたはかつてエジプトの地で奴隷であったが、あなたの神、主が強い手と、伸ばした腕とをもって、そこからあなたを導き出されたことを覚えなければならない。それゆえ、あなたの神、主は安息日を守ることを命じられるのである。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="出エジプト記 20:12; エペソ人への手紙 6:1–3; コロサイ人への手紙 3:20"> あなたの神、主が命じられたように、あなたの父と母とを敬え。あなたの神、主が賜わる地で、あなたが長く命を保ち、さいわいを得ることのできるためである。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="出エジプト記 20:13; ローマ人への手紙 13:9; マタイによる福音書 5:21–22"> あなたは殺してはならない。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="出エジプト記 20:14; ルカによる福音書 18:20; レビ記 20:10"> あなたは姦淫してはならない。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="出エジプト記 20:15; ローマ人への手紙 13:9; エペソ人への手紙 4:28"> あなたは盗んではならない。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="出エジプト記 20:16; 出エジプト記 23:1; 箴言 19:9"> あなたは隣人について偽証してはならない。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="出エジプト記 20:17; ローマ人への手紙 13:9; ルカによる福音書 12:15"> あなたは隣人の妻をむさぼってはならない。また隣人の家、畑、しもべ、はしため、牛、ろば、またすべて隣人のものをほしがってはならない』。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="出エジプト記 24:12; 出エジプト記 31:18; 申命記 4:12–15"> 主はこれらの言葉を山で火の中、雲の中、濃い雲の中から、大いなる声をもって、あなたがたの全会衆にお告げになったが、このほかのことは言われず、二枚の石の板にこれを書きしるして、わたしに授けられた。</span>
<span className="v" id="v23" data-v="23" data-xref="出エジプト記 20:18–19; ヘブル人への手紙 12:18–21"> 時に山は火で燃えていたが、あなたがたが暗黒のうちから聞える声を聞くに及んで、あなたがたの部族のすべてのかしらと長老たちは、わたしに近寄って、</span>
<span className="v" id="v24" data-v="24" data-xref="申命記 4:33; 出エジプト記 19:19; 出エジプト記 33:20"> 言った、『われわれの神、主がその栄光と、その大いなることとを、われわれに示されて、われわれは火の中から出るその声を聞きました。きょう、われわれは神が人と語られ、しかもなおその人が生きているのを見ました。</span>
<span className="v" id="v25" data-v="25" data-xref="申命記 18:16; ガラテヤ人への手紙 3:10; コリント人への第二の手紙 3:7–9"> われわれはなぜ死ななければならないでしょうか。この大いなる火はわれわれを焼き滅ぼそうとしています。もしこの上なおわれわれの神、主の声を聞くならば、われわれは死んでしまうでしょう。</span>
<span className="v" id="v26" data-v="26" data-xref="申命記 4:33; ローマ人への手紙 3:20; マタイによる福音書 26:63"> およそ肉なる者のうち、だれが、火の中から語られる生ける神の声を、われわれのように聞いてなお生きている者がありましょうか。</span>
<span className="v" id="v27" data-v="27" data-xref="出エジプト記 20:19; ヘブル人への手紙 12:19"> あなたはどうぞ近く進んで行って、われわれの神、主が言われることをみな聞き、われわれの神、主があなたにお告げになることをすべてわれわれに告げてください。われわれは聞いて行います』。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="申命記 18:17; 民数記 36:5; 民数記 27:7"> あなたがたがわたしに語っている時、主はあなたがたの言葉を聞いて、わたしに言われた、『わたしはこの民がおまえに語っている言葉を聞いた。彼らの言ったことはみな良い。</span>
<span className="v" id="v29" data-v="29" data-xref="イザヤ書 48:18; エゼキエル書 33:31–32; 申命記 11:1"> ただ願わしいことは、彼らがつねにこのような心をもってわたしを恐れ、わたしのすべての命令を守って、彼らもその子孫も永久にさいわいを得るにいたることである。</span>
<span className="v" id="v30" data-v="30"> おまえは行って彼らに、「あなたがたはおのおのその天幕に帰れ」と言え。</span>
<span className="v" id="v31" data-v="31" data-xref="ガラテヤ人への手紙 3:19; エゼキエル書 20:11; 申命記 5:1"> しかし、おまえはこの所でわたしのそばに立て。わたしはすべての命令と、定めと、おきてとをおまえに告げ示すであろう。おまえはこれを彼らに教え、わたしが彼らに与えて獲させる地において、これを行わせなければならない』。</span>
<span className="v" id="v32" data-v="32" data-xref="ヨシュア記 23:6; 箴言 4:27; ヨシュア記 1:7"> それゆえ、あなたがたの神、主が命じられたとおりに、慎んで行わなければならない。そして左にも右にも曲ってはならない。</span>
<span className="v" id="v33" data-v="33" data-xref="エレミヤ書 7:23; 申命記 4:40; ルカによる福音書 1:6"> あなたがたの神、主が命じられた道に歩まなければならない。そうすればあなたがたは生きることができ、かつさいわいを得て、あなたがたの獲る地において、長く命を保つことができるであろう。</span>
</div>

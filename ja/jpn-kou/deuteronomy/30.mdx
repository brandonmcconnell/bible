<span className="v" id="v1" data-v="1" data-xref="申命記 30:15; 列王紀上 8:47–48; 申命記 30:19"> わたしがあなたがたの前に述べたこのもろもろの祝福と、のろいの事があなたに臨み、あなたがあなたの神、主に追いやられたもろもろの国民のなかでこの事を心に考えて、</span>
<span className="v" id="v2" data-v="2" data-xref="ヨエル書 2:12–13; ネヘミヤ書 1:9; 申命記 4:28–31"> あなたもあなたの子供も共にあなたの神、主に立ち帰り、わたしが、きょう、命じるすべてのことにおいて、心をつくし、精神をつくして、主の声に聞き従うならば、</span>
<span className="v" id="v3" data-v="3" data-xref="エレミヤ書 29:14; エゼキエル書 36:24; 詩篇 147:2"> あなたの神、主はあなたを再び栄えさせ、あなたをあわれみ、あなたの神、主はあなたを散らされた国々から再び集められるであろう。</span>
<span className="v" id="v4" data-v="4" data-xref="ネヘミヤ書 1:9; エゼキエル書 39:25–29; 申命記 28:64"> たといあなたが天のはてに追いやられても、あなたの神、主はそこからあなたを集め、そこからあなたを連れ帰られるであろう。</span>
<span className="v" id="v5" data-v="5" data-xref="エレミヤ書 29:14"> あなたの神、主はあなたの先祖が所有した地にあなたを帰らせ、あなたはそれを所有するに至るであろう。主はまたあなたを栄えさせ、数を増して先祖たちよりも多くされるであろう。</span>
<span className="v" id="v6" data-v="6" data-xref="申命記 10:16; エゼキエル書 36:26–27; エレミヤ書 32:39"> そしてあなたの神、主はあなたの心とあなたの子孫の心に割礼を施し、あなたをして、心をつくし、精神をつくしてあなたの神、主を愛させ、こうしてあなたに命を得させられるであろう。</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 7:15; 哀歌 4:21–22; エレミヤ書 51:24–26"> あなたの神、主はまた、あなたを迫害する敵と、あなたを憎む者とに、このもろもろののろいをこうむらせられるであろう。</span>
<span className="v" id="v8" data-v="8" data-xref="エペソ人への手紙 2:16; エゼキエル書 36:27; エゼキエル書 11:19–20"> しかし、あなたは再び主の声に聞き従い、わたしが、きょう、あなたに命じるすべての戒めを守るであろう。</span>
<span className="v" id="v9" data-v="9" data-xref="申命記 28:11–14; エレミヤ書 32:41; エレミヤ書 33:9"> そうすればあなたの神、主はあなたのするすべてのことと、あなたの身から生れる者と、家畜の産むものと、地に産する物を豊かに与えて、あなたを栄えさせられるであろう。すなわち主はあなたの先祖たちを喜ばれたように再びあなたを喜んで、あなたを栄えさせられるであろう。</span>
<span className="v" id="v10" data-v="10" data-xref="哀歌 3:40–41; 申命記 4:29; ネヘミヤ書 1:9"> これはあなたが、あなたの神、主の声に聞きしたがい、この律法の書にしるされた戒めと定めとを守り、心をつくし、精神をつくしてあなたの神、主に帰するからである。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="イザヤ書 45:19; 詩篇 147:19–20; ローマ人への手紙 16:25–26"> わたしが、きょう、あなたに命じるこの戒めは、むずかしいものではなく、また遠いものでもない。</span>
<span className="v" id="v12" data-v="12" data-xref="ローマ人への手紙 10:6–8; 箴言 30:4; ヨハネによる福音書 3:13"> これは天にあるのではないから、『だれがわれわれのために天に上り、それをわれわれのところへ持ってきて、われわれに聞かせ、行わせるであろうか』と言うに及ばない。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行伝 10:33; マタイによる福音書 12:42; 箴言 2:1–5"> またこれは海のかなたにあるのではないから、『だれがわれわれのために海を渡って行き、それをわれわれのところへ携えてきて、われわれに聞かせ、行わせるであろうか』と言うに及ばない。</span>
<span className="v" id="v14" data-v="14" data-xref="ローマ人への手紙 10:8–10; エレミヤ書 12:2; マタイによる福音書 7:21"> この言葉はあなたに、はなはだ近くあってあなたの口にあり、またあなたの心にあるから、あなたはこれを行うことができる。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="申命記 11:26; 申命記 30:19; ヨハネの第一の手紙 5:11–12"> 見よ、わたしは、きょう、命とさいわい、および死と災をあなたの前に置いた。</span>
<span className="v" id="v16" data-v="16" data-xref="申命記 30:6; マタイによる福音書 22:37–38; ヨハネの第一の手紙 5:2–3"> すなわちわたしは、きょう、あなたにあなたの神、主を愛し、その道に歩み、その戒めと定めと、おきてとを守ることを命じる。それに従うならば、あなたは生きながらえ、その数は多くなるであろう。またあなたの神、主はあなたが行って取る地であなたを祝福されるであろう。</span>
<span className="v" id="v17" data-v="17" data-xref="テモテヘの第二の手紙 4:4; ヘブル人への手紙 3:12; 箴言 1:32"> しかし、もしあなたが心をそむけて聞き従わず、誘われて他の神々を拝み、それに仕えるならば、</span>
<span className="v" id="v18" data-v="18" data-xref="申命記 8:19–20; イザヤ書 63:17–18; 申命記 4:26"> わたしは、きょう、あなたがたに告げる。あなたがたは必ず滅びるであろう。あなたがたはヨルダンを渡り、はいって行って取る地でながく命を保つことができないであろう。</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 30:15; 申命記 11:26; 詩篇 119:30"> わたしは、きょう、天と地を呼んであなたがたに対する証人とする。わたしは命と死および祝福とのろいをあなたの前に置いた。あなたは命を選ばなければならない。そうすればあなたとあなたの子孫は生きながらえることができるであろう。</span>
<span className="v" id="v20" data-v="20" data-xref="ヨハネによる福音書 11:25–26; 申命記 10:20; ヨハネによる福音書 17:3"> すなわちあなたの神、主を愛して、その声を聞き、主につき従わなければならない。そうすればあなたは命を得、かつ長く命を保つことができ、主が先祖アブラハム、イサク、ヤコブに与えると誓われた地に住むことができるであろう」。</span>

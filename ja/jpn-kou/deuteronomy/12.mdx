<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀上 8:40; ヨブ記 7:1; 申命記 4:19"> これはあなたの先祖たちの神、主が所有として賜わる地で、あなたがたが世に生きながらえている間、守り行わなければならない定めと、おきてである。</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 7:5; 列王紀下 16:4; 民数記 33:51–52"> あなたがたの追い払う国々の民が、その神々に仕えた所は、高い山にあるものも、丘にあるものも、青木の下にあるものも、ことごとくこわし、</span>
<span className="v" id="v3" data-v="3" data-xref="士師記 2:2; ゼカリヤ書 13:2; 民数記 33:52"> その祭壇をこぼち、柱を砕き、アシラ像を火で焼き、また刻んだ神々の像を切り倒して、その名をその所から消し去らなければならない。</span>
<span className="v" id="v4" data-v="4" data-xref="レビ記 20:23; 申命記 20:18; 申命記 16:21–22"> ただし、あなたがたの神、主にはそのようにしてはならない。</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 12:11; 申命記 26:2; 歴代志下 7:12"> あなたがたの神、主がその名を置くために、あなたがたの全部族のうちから選ばれる場所、すなわち主のすまいを尋ね求めて、そこに行き、</span>
<span className="v" id="v6" data-v="6" data-xref="申命記 15:19–20; マラキ書 3:10; レビ記 27:32–33"> あなたがたの燔祭と、犠牲と、十分の一と、ささげ物と、誓願の供え物と、自発の供え物および牛、羊のういごをそこに携えて行って、</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 12:18; レビ記 23:40; 申命記 14:26"> そこであなたがたの神、主の前で食べ、あなたがたも、家族も皆、手を労して獲るすべての物を喜び楽しまなければならない。これはあなたの神、主の恵みによって獲るものだからである。</span>
<span className="v" id="v8" data-v="8" data-xref="士師記 21:25; 士師記 17:6; 箴言 21:2"> そこでは、われわれがきょうここでしているように、めいめいで正しいと思うようにふるまってはならない。</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀上 8:56; 詩篇 95:11; 申命記 25:19"> あなたがたはまだ、あなたがたの神、主から賜わる安息と嗣業の地に、はいっていないのである。</span>
<span className="v" id="v10" data-v="10" data-xref="エレミヤ書 33:11; エゼキエル書 34:28; 申命記 3:27"> しかし、あなたがたがヨルダンを渡り、あなたがたの神、主が嗣業として賜わる地に住むようになり、さらに主があなたがたの周囲の敵をことごとく除いて、安息を与え、あなたがたが安らかに住むようになる時、</span>
<span className="v" id="v11" data-v="11" data-xref="申命記 12:5; 申命記 15:20; 申命記 17:8"> あなたがたの神、主はその名を置くために、一つの場所を選ばれるであろう。あなたがたはそこにわたしの命じる物をすべて携えて行かなければならない。すなわち、あなたがたの燔祭と、犠牲と、十分の一と、ささげ物およびあなたがたが主に誓ったすべての誓願の供え物とを携えて行かなければならない。</span>
<span className="v" id="v12" data-v="12" data-xref="申命記 12:7; 申命記 10:9; 申命記 26:12"> そしてあなたがたのむすこ、娘、しもべ、はしためと共にあなたがたの神、主の前に喜び楽しまなければならない。また町の内におるレビびととも、そうしなければならない。彼はあなたがたのうちに分け前がなく、嗣業を持たないからである。</span>
<span className="v" id="v13" data-v="13" data-xref="列王紀上 12:28–32; 列王紀上 15:34; 歴代志下 15:17"> 慎んで、すべてあなたがよいと思う場所で、みだりに燔祭をささげないようにしなければならない。</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 12:11; コリント人への第二の手紙 5:19; 申命記 12:5"> ただあなたの部族の一つのうちに、主が選ばれるその場所で、燔祭をささげ、またわたしが命じるすべての事をしなければならない。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="申命記 14:5; 申命記 15:22–23; 申命記 14:26"> しかし、あなたの神、主が賜わる恵みにしたがって、すべて心に好む獣を、どの町ででも殺して、その肉を食べることができる。すなわち、かもしかや雄じかの肉と同様にそれを、汚れた人も、清い人も、食べることができる。</span>
<span className="v" id="v16" data-v="16" data-xref="創世記 9:4; 申命記 15:23; 申命記 12:23–24"> ただし、その血は食べてはならない。水のようにそれを地に注がなければならない。</span>
<span className="v" id="v17" data-v="17" data-xref="申命記 26:14; 申命記 12:6; 申命記 14:22–29"> あなたの穀物と、ぶどう酒と、油との十分の一および牛、羊のういご、ならびにあなたが立てる誓願の供え物と、自発の供え物およびささげ物は、町の内で食べることはできない。</span>
<span className="v" id="v18" data-v="18" data-xref="申命記 12:7; 申命記 14:23; 申命記 12:5"> あなたの神、主が選ばれる場所で、あなたの神、主の前でそれを食べなければならない。すなわちあなたのむすこ、娘、しもべ、はしため、および町の内におるレビびとと共にそれを食べ、手を労して獲るすべての物を、あなたの神、主の前に喜び楽しまなければならない。</span>
<span className="v" id="v19" data-v="19" data-xref="歴代志下 31:4–21; ネヘミヤ書 10:34–39; 申命記 14:27–29"> 慎んで、あなたが世に生きながらえている間、レビびとを捨てないようにしなければならない。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="申命記 19:8; 申命記 11:24; 出エジプト記 34:24"> あなたの神、主が約束されたように、あなたの領域を広くされるとき、あなたは肉を食べたいと願って、『わたしは肉を食べよう』と言うであろう。その時、あなたはほしいだけ肉を食べることができる。</span>
<span className="v" id="v21" data-v="21" data-xref="申命記 12:5; 列王紀上 14:21; 申命記 16:11"> もしあなたの神、主がその名を置くために選ばれる場所が、遠く離れているならば、わたしが命じるように、主が賜わる牛、羊をほふり、門の内で、ほしいだけ食べることができる。</span>
<span className="v" id="v22" data-v="22" data-xref="申命記 12:15–16"> かもしかや、雄じかを食べるように、それを食べることができる。すなわち汚れた人も、清い人も一様にそれを食べることができる。</span>
<span className="v" id="v23" data-v="23" data-xref="レビ記 17:11; 創世記 9:4; レビ記 17:13–14"> ただ堅く慎んで、その血を食べないようにしなければならない。血は命だからである。その命を肉と一緒に食べてはならない。</span>
<span className="v" id="v24" data-v="24" data-xref="申命記 12:16; 申命記 15:23"> あなたはそれを食べてはならない。水のようにそれを地に注がなければならない。</span>
<span className="v" id="v25" data-v="25" data-xref="列王紀上 11:38; 申命記 4:40; イザヤ書 3:10"> あなたはそれを食べてはならない。こうして、主が正しいと見られる事を行うならば、あなたにも後の子孫にも、さいわいがあるであろう。</span>
<span className="v" id="v26" data-v="26" data-xref="民数記 18:19; 民数記 5:9–10; 申命記 12:11"> ただあなたのささげる聖なる物と、誓願の物とは、主が選ばれる場所へ携えて行かなければならない。</span>
<span className="v" id="v27" data-v="27" data-xref="レビ記 1:13; レビ記 17:11; レビ記 1:9"> そして燔祭をささげる時は、肉と血とをあなたの神、主の祭壇の上にささげなければならない。犠牲をささげる時は、血をあなたの神、主の祭壇にそそぎかけ、肉はみずから食べることができる。</span>
<span className="v" id="v28" data-v="28" data-xref="申命記 4:40; ヨハネによる福音書 15:14; ヨハネによる福音書 15:10"> あなたはわたしが命じるこれらの事を、ことごとく聞いて守らなければならない。こうしてあなたの神、主が見て良いとし、正しいとされる事を行うならば、あなたにも後の子孫にも、長くさいわいがあるであろう。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="ヨシュア記 23:4; 申命記 19:1; 申命記 9:3"> あなたの神、主が、あなたの行って追い払おうとする国々の民を、あなたの前から断ち滅ぼされ、あなたがついにその国々を獲て、その地に住むようになる時、</span>
<span className="v" id="v30" data-v="30" data-xref="エレミヤ書 10:2; エゼキエル書 20:32; 申命記 7:16"> あなたはみずから慎み、彼らがあなたの前から滅ぼされた後、彼らにならって、わなにかかってはならない。また彼らの神々を尋ね求めて、『これらの国々の民はどのようにその神々に仕えたのか、わたしもそのようにしよう』と言ってはならない。</span>
<span className="v" id="v31" data-v="31" data-xref="エレミヤ書 32:35; 申命記 18:9–10; 列王紀下 17:15–17"> あなたの神、主に対しては、そのようにしてはならない。彼らは主の憎まれるもろもろの忌むべき事を、その神々にむかって行い、むすこ、娘をさえ火に焼いて、神々にささげたからである。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="申命記 4:2; ヨハネの黙示録 22:18–19; ヨシュア記 1:7"> あなたがたはわたしが命じるこのすべての事を守って行わなければならない。これにつけ加えてはならない。また減らしてはならない。</span>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="エレミヤ書 23:25–28; ヨハネの第一の手紙 4:1; エレミヤ書 29:8"> あなたがたのうちに預言者または夢みる者が起って、しるしや奇跡を示し、</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 13:6; マタイによる福音書 7:22–23; ヨハネの黙示録 13:13–14"> あなたに告げるそのしるしや奇跡が実現して、あなたがこれまで知らなかった『ほかの神々に、われわれは従い仕えよう』と言っても、</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 8:2; コリント人への第一の手紙 11:19; 詩篇 66:10"> あなたはその預言者または夢みる者の言葉に聞き従ってはならない。あなたがたの神、主はあなたがたが心をつくし、精神をつくして、あなたがたの神、主を愛するか、どうかを知ろうと、このようにあなたがたを試みられるからである。</span>
<span className="v" id="v4" data-v="4" data-xref="コロサイ人への手紙 1:10; 申命記 10:20; コリント人への第一の手紙 6:17"> あなたがたの神、主に従って歩み、彼を恐れ、その戒めを守り、その言葉に聞き従い、彼に仕え、彼につき従わなければならない。</span>
<span className="v" id="v5" data-v="5" data-xref="コリント人への第一の手紙 5:13; 申命記 18:20; エレミヤ書 14:15"> その預言者または夢みる者を殺さなければならない。あなたがたをエジプトの国から導き出し、奴隷の家からあがなわれたあなたがたの神、主にあなたがたをそむかせ、あなたの神、主が歩めと命じられた道を離れさせようとして語るゆえである。こうしてあなたがたのうちから悪を除き去らなければならない。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="申命記 17:2–7; ペテロの第二の手紙 2:1; エペソ人への手紙 4:14"> 同じ母に生れたあなたの兄弟、またはあなたのむすこ、娘、またはあなたのふところの妻、またはあなたと身命を共にする友が、ひそかに誘って『われわれは行って他の神々に仕えよう』と言うかも知れない。これはあなたも先祖たちも知らなかった神々、</span>
<span className="v" id="v7" data-v="7"> すなわち地のこのはてから、地のかのはてまで、あるいは近く、あるいは遠く、あなたの周囲にある民の神々である。</span>
<span className="v" id="v8" data-v="8" data-xref="申命記 19:13; 箴言 1:10; 申命記 7:16"> しかし、あなたはその人に従ってはならない。その人の言うことを聞いてはならない。その人をあわれんではならない。その人を惜しんではならない。その人をかばってはならない。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行伝 7:58; ルカによる福音書 14:26; マタイによる福音書 10:37"> 必ず彼を殺さなければならない。彼を殺すには、あなたがまず彼に手を下し、その後、民がみな手を下さなければならない。</span>
<span className="v" id="v10" data-v="10" data-xref="ヨシュア記 7:25; レビ記 24:14–16; 出エジプト記 20:2"> 彼はエジプトの国、奴隷の家からあなたを導き出されたあなたの神、主からあなたを離れさせようとしたのであるから、あなたは石をもって彼を撃ち殺さなければならない。</span>
<span className="v" id="v11" data-v="11" data-xref="申命記 19:20; 申命記 17:13; テモテヘの第一の手紙 5:20"> そうすればイスラエルは皆聞いて恐れ、重ねてこのような悪い事を、あなたがたのうちに行わないであろう。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="士師記 20:1–17; ヨシュア記 22:11–34"> あなたの神、主があなたに与えて住まわせられる町の一つで、</span>
<span className="v" id="v13" data-v="13" data-xref="ヨハネの第一の手紙 2:19; 申命記 13:2; コリント人への第二の手紙 6:15"> よこしまな人々があなたがたのうちに起って、あなたがたの知らなかった『ほかの神々に、われわれは行って仕えよう』と言って、その町に住む人々を誘惑したことを聞くならば、</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 17:4; イザヤ書 11:3–4; ヨハネによる福音書 7:24"> あなたはそれを尋ね、探り、よく問いたださなければならない。そして、そのような憎むべき事があなたがたのうちに行われた事が、真実で、確かならば、</span>
<span className="v" id="v15" data-v="15" data-xref="出エジプト記 22:20; レビ記 27:28; 申命記 7:2"> あなたは必ず、その町に住む者をつるぎの刃にかけて撃ち殺し、その町と、そのうちにおるすべての者、およびその家畜をつるぎの刃にかけて、ことごとく滅ぼさなければならない。</span>
<span className="v" id="v16" data-v="16" data-xref="エレミヤ書 49:2; ヨシュア記 8:28; イザヤ書 25:2"> またそのすべてのぶんどり物は、町の広場の中央に集め、火をもってその町と、すべてのぶんどり物とを、ことごとく焼いて、あなたの神、主にささげなければならない。これはながく荒塚となって、再び建て直されないであろう。</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 26:4; 申命記 7:26; ヨシュア記 7:26"> そののろわれた物は一つもあなたの手に留めおいてはならない。主が激しい怒りをやめ、あなたに慈悲を施して、あなたをあわれみ、先祖たちに誓われたように、あなたの数を多くされるためである。</span>
<span className="v" id="v18" data-v="18" data-xref="申命記 12:28; マタイによる福音書 7:21; 申命記 12:25"> あなたの神、主の言葉に聞き従い、わたしが、きょう、命じるすべての戒めを守り、あなたの神、主が正しいと見られる事を行うならば、このようになるであろう。</span>
</div>

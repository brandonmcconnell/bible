<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歴代志下 32:7–8; 申命記 31:8; 詩篇 20:7"> あなたが敵と戦うために出る時、馬と戦車と、あなたよりも大ぜいの軍隊を見ても、彼らを恐れてはならない。あなたをエジプトの国から導きのぼられたあなたの神、主が共におられるからである。</span>
<span className="v" id="v2" data-v="2" data-xref="民数記 31:6; 歴代志下 13:12; 民数記 10:8–9"> あなたがたが戦いに臨むとき、祭司は進み出て民に告げて、</span>
<span className="v" id="v3" data-v="3" data-xref="ヘブル人への手紙 13:6; 詩篇 3:6; ヨハネの黙示録 2:10"> 彼らに言わなければならない、『イスラエルよ聞け。あなたがたは、きょう、敵と戦おうとしている。気おくれしてはならない。恐れてはならない。あわててはならない。彼らに驚いてはならない。</span>
<span className="v" id="v4" data-v="4" data-xref="出エジプト記 14:14; 申命記 3:22; 申命記 1:30"> あなたがたの神、主が共に行かれ、あなたがたのために敵と戦って、あなたがたを救われるからである』。</span>
<span className="v" id="v5" data-v="5" data-xref="ネヘミヤ書 12:27; 民数記 31:14; 申命記 16:18"> 次につかさたちは民に告げて言わなければならない。『新しい家を建てて、まだそれをささげていない者があれば、その人を家に帰らせなければならない。そうしなければ、彼が戦いに死んだとき、ほかの人がそれをささげるようになるであろう。</span>
<span className="v" id="v6" data-v="6" data-xref="レビ記 19:23–25; 申命記 28:1–30; エレミヤ書 31:5"> ぶどう畑を作って、まだその実を食べていない者があれば、その人を家に帰らせなければならない。そうしなければ彼が戦いに死んだとき、ほかの人がそれを食べるようになるであろう。</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 24:5; 申命記 28:30; ルカによる福音書 14:18–20"> 女と婚約して、まだその女をめとっていない者があれば、その人を家に帰らせなければならない。そうしなければ彼が戦いに死んだとき、ほかの人が彼女をめとるようになるであろう』。</span>
<span className="v" id="v8" data-v="8" data-xref="士師記 7:3; 申命記 1:28; ヨハネの黙示録 21:8"> つかさたちは、また民に告げて言わなければならない。『恐れて気おくれする者があるならば、その人を家に帰らせなければならない。そうしなければ、兄弟たちの心が彼の心のようにくじけるであろう』。</span>
<span className="v" id="v9" data-v="9"> つかさたちがこのように民に告げ終ったならば、軍勢のかしらたちを立てて民を率いさせなければならない。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="ルカによる福音書 10:5–6; コリント人への第二の手紙 5:18–1; エペソ人への手紙 2:17"> 一つの町へ進んで行って、それを攻めようとする時は、まず穏やかに降服することを勧めなければならない。</span>
<span className="v" id="v11" data-v="11" data-xref="ルカによる福音書 19:14; ヨシュア記 11:19–20; ヨシュア記 16:10"> もしその町が穏やかに降服しようと答えて、門を開くならば、そこにいるすべての民に、みつぎを納めさせ、あなたに仕えさせなければならない。</span>
<span className="v" id="v12" data-v="12"> もし穏やかに降服せず、戦おうとするならば、あなたはそれを攻めなければならない。</span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 2:6–12; 列王紀上 11:15–16; 詩篇 110:1"> そしてあなたの神、主がそれをあなたの手にわたされる時、つるぎをもってそのうちの男をみな撃ち殺さなければならない。</span>
<span className="v" id="v14" data-v="14" data-xref="ヨシュア記 8:2; ヨシュア記 22:8; 民数記 31:9"> ただし女、子供、家畜およびすべて町のうちにあるもの、すなわちぶんどり物は皆、戦利品として取ることができる。また敵からぶんどった物はあなたの神、主が賜わったものだから、あなたはそれを用いることができる。</span>
<span className="v" id="v15" data-v="15"> 遠く離れている町々、すなわちこれらの国々に属さない町々には、すべてこのようにしなければならない。</span>
<span className="v" id="v16" data-v="16" data-xref="ヨシュア記 11:14; 民数記 21:2–3; 民数記 33:52"> ただし、あなたの神、主が嗣業として与えられるこれらの民の町々では、息のある者をひとりも生かしておいてはならない。</span>
<span className="v" id="v17" data-v="17" data-xref="イザヤ書 34:5–6; エレミヤ書 50:35–40; 申命記 7:1–2"> すなわちヘテびと、アモリびと、カナンびと、ペリジびと、ヒビびと、エブスびとはみな滅ぼして、あなたの神、主が命じられたとおりにしなければならない。</span>
<span className="v" id="v18" data-v="18" data-xref="申命記 12:30–31; 出エジプト記 23:33; エペソ人への手紙 5:11"> これは彼らがその神々を拝んでおこなったすべての憎むべき事を、あなたがたに教えて、それを行わせ、あなたがたの神、主に罪を犯させることのないためである。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="マタイによる福音書 3:10; ヨハネによる福音書 15:2–8; 申命記 26:6"> 長く町を攻め囲んで、それを取ろうとする時でも、おのをふるって、そこの木を切り枯らしてはならない。それはあなたの食となるものだから、切り倒してはならない。あなたは田野の木までも、人のように攻めなければならないであろうか。</span>
<span className="v" id="v20" data-v="20" data-xref="歴代志下 26:15; エレミヤ書 33:4; 伝道の書 9:14"> ただし実を結ばない木とわかっている木は切り倒して、あなたと戦っている町にむかい、それをもってとりでを築き、陥落するまで、それを攻めることができる。</span>
</div>

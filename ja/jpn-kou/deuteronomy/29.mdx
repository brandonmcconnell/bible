<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命記 5:2–3; ヘブル人への手紙 8:9; 出エジプト記 24:2–8"> これは主がモーセに命じて、モアブの地でイスラエルの人々と結ばせられた契約の言葉であって、ホレブで彼らと結ばれた契約のほかのものである。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="出エジプト記 19:4; 出エジプト記 8:12; ヨシュア記 24:5–6"> モーセはイスラエルのすべての人を呼び集めて言った、「あなたがたは主がエジプトの地で、パロと、そのすべての家来と、その全地とにせられたすべての事をまのあたり見た。</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 4:32–35; ネヘミヤ書 9:9–11; 申命記 7:18–19"> すなわちその大きな試みと、しるしと、大きな不思議とをまのあたり見たのである。</span>
<span className="v" id="v4" data-v="4" data-xref="エペソ人への手紙 4:18; イザヤ書 6:9–10; 箴言 20:12"> しかし、今日まで主はあなたがたの心に悟らせず、目に見させず、耳に聞かせられなかった。</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 8:4; ネヘミヤ書 9:21; 申命記 8:2"> わたしは四十年の間、あなたがたを導いて荒野を通らせたが、あなたがたの身につけた着物は古びず、足のくつは古びなかった。</span>
<span className="v" id="v6" data-v="6" data-xref="申命記 8:3; エペソ人への手紙 5:18; コリント人への第一の手紙 9:25"> あなたがたはまたパンも食べず、ぶどう酒も濃い酒も飲まなかった。こうしてあなたがたは、わたしがあなたがたの神、主であることを知るに至った。</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 2:24–17; 民数記 32:33–42; 詩篇 135:10–12"> あなたがたがこの所にきたとき、ヘシボンの王シホンと、バシャンの王オグがわれわれを迎えて戦ったが、われわれは彼らを撃ち敗って、</span>
<span className="v" id="v8" data-v="8" data-xref="申命記 3:12–13; 民数記 32:33"> その地を取り、これをルベンびとと、ガドびとと、マナセびとの半ばとに、嗣業として与えた。</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀上 2:3; 申命記 4:6; ルカによる福音書 11:28"> それゆえ、あなたがたはこの契約の言葉を守って、それを行わなければならない。そうすればあなたがたのするすべての事は栄えるであろう。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="ヨエル書 2:16–17; ヨハネの黙示録 20:12; 申命記 31:12–13"> あなたがたは皆、きょう、あなたがたの神、主の前に立っている。すなわちあなたがたの部族のかしらたち、長老たち、つかさたちなど、イスラエルのすべての人々、</span>
<span className="v" id="v11" data-v="11" data-xref="出エジプト記 12:38; ヨシュア記 9:21–27; 出エジプト記 12:48–49"> あなたがたの小さい者たちも、妻たちも、宿営のうちに寄留している他国人も、あなたのために、たきぎを割る者も、水をくむ者も、みな主の前に立って、</span>
<span className="v" id="v12" data-v="12" data-xref="歴代志下 15:12–15; 列王紀下 11:17; 申命記 5:2–3"> あなたの神、主が、きょう、あなたと結ばれるあなたの神、主の契約と誓いとに、はいろうとしている。</span>
<span className="v" id="v13" data-v="13" data-xref="出エジプト記 6:7; 創世記 17:7; 申命記 28:9"> これは主がさきにあなたに約束されたように、またあなたの先祖アブラハム、イサク、ヤコブに誓われたように、きょう、あなたを立てて自分の民とし、またみずからあなたの神となられるためである。</span>
<span className="v" id="v14" data-v="14" data-xref="エレミヤ書 31:31–34; ヘブル人への手紙 8:7–12"> わたしはただあなたがたとだけ、この契約と誓いとを結ぶのではない。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行伝 2:39; コリント人への第一の手紙 7:14; エレミヤ書 50:5"> きょう、ここで、われわれの神、主の前にわれわれと共に立っている者ならびに、きょう、ここにわれわれと共にいない者とも結ぶのである。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="申命記 2:19; 申命記 2:9; 申命記 2:4"> われわれがどのようにエジプトの国に住んでいたか、どのように国々の民の中を通ってきたか、それはあなたがたが知っている。</span>
<span className="v" id="v17" data-v="17" data-xref="申命記 28:36"> またあなたがたは木や石や銀や金で造った憎むべき物と偶像とが、彼らのうちにあるのを見た。</span>
<span className="v" id="v18" data-v="18" data-xref="ヘブル人への手紙 12:15; 申命記 11:16–17; 申命記 13:1–15"> それゆえ、あなたがたのうちに、きょう、その心にわれわれの神、主を離れてそれらの国民の神々に行って仕える男や女、氏族や部族があってはならない。またあなたがたのうちに、毒草や、にがよもぎを生ずる根があってはならない。</span>
<span className="v" id="v19" data-v="19" data-xref="エレミヤ書 7:24; 民数記 15:30; 民数記 15:39"> そのような人はこの誓いの言葉を聞いても、心に自分を祝福して『心をかたくなにして歩んでもわたしには平安がある』と言うであろう。そうすれば潤った者も、かわいた者もひとしく滅びるであろう。</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 74:1; 詩篇 79:5; 申命記 9:14"> 主はそのような人をゆるすことを好まれない。かえって主はその人に怒りとねたみを発し、この書物にしるされたすべてののろいを彼の上に加え、主はついにその人の名を天の下から消し去られるであろう。</span>
<span className="v" id="v21" data-v="21" data-xref="マタイによる福音書 25:41; ヨシュア記 7:1–26; エゼキエル書 13:9"> 主はイスラエルのすべての部族のうちからその人を区別して災をくだし、この律法の書にしるされた契約の中のもろもろののろいのようにされるであろう。</span>
<span className="v" id="v22" data-v="22" data-xref="エレミヤ書 19:8"> 後の代の人、すなわちあなたがたののちに起るあなたがたの子孫および遠い国から来る外国人は、この地の災を見、主がこの地にくだされた病気を見て言うであろう。</span>
<span className="v" id="v23" data-v="23" data-xref="ゼパニヤ書 2:9; エレミヤ書 17:6; イザヤ書 34:9"> ――全地は硫黄となり、塩となり、焼け土となって、種もまかれず、実も結ばず、なんの草も生じなくなって、むかし主が怒りと憤りをもって滅ぼされたソドム、ゴモラ、アデマ、ゼボイムの破滅のようである。――</span>
<span className="v" id="v24" data-v="24" data-xref="エレミヤ書 22:8–9; 列王紀上 9:8–9; ローマ人への手紙 2:5"> すなわち、もろもろの国民は言うであろう、『なぜ、主はこの地にこのようなことをされたのか。この激しい大いなる怒りは何ゆえか』。</span>
<span className="v" id="v25" data-v="25" data-xref="ヘブル人への手紙 8:9; イザヤ書 47:6; エレミヤ書 50:7"> そのとき人々は言うであろう、『彼らはその先祖の神、主がエジプトの国から彼らを導き出して彼らと結ばれた契約をすて、</span>
<span className="v" id="v26" data-v="26" data-xref="申命記 28:64; 士師記 2:12–13; 士師記 5:8"> 行って彼らの知らない、また授からない、ほかの神々に仕えて、それを拝んだからである。</span>
<span className="v" id="v27" data-v="27" data-xref="ダニエル書 9:11–14; 申命記 28:15–68; 申命記 27:15–26"> それゆえ主はこの地にむかって怒りを発し、この書物にしるされたもろもろののろいをこれにくだし、</span>
<span className="v" id="v28" data-v="28" data-xref="歴代志下 7:20; 列王紀上 14:15; 詩篇 52:5"> そして主は怒りと、はげしい怒りと大いなる憤りとをもって彼らをこの地から抜き取って、ほかの国に投げやられた。今日見るとおりである』。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="ダニエル書 2:22; 使徒行伝 1:7; ローマ人への手紙 11:33–34"> 隠れた事はわれわれの神、主に属するものである。しかし表わされたことは長くわれわれとわれわれの子孫に属し、われわれにこの律法のすべての言葉を行わせるのである。</span>
</div>

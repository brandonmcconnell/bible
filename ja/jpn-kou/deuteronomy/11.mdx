<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命記 6:5; 申命記 10:12; ルカによる福音書 1:74–75"> それゆえ、あなたの神、主を愛し、常にそのさとしと、定めと、おきてと、戒めとを守らなければならない。</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 8:2–5; 申命記 29:10; 使徒行伝 26:22"> あなたがたは、きょう、次のことを知らなければならない。わたしが語るのは、あなたがたの子供たちに対してではない。彼らはあなたがたの神、主の訓練と、主の大いなる事と、その強い手と、伸べた腕とを知らず、また見なかった。</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 7:19; 申命記 4:34; 詩篇 105:27–45"> また彼らは主がエジプトで、エジプト王パロとその全国に対して行われたしるしと、わざ、</span>
<span className="v" id="v4" data-v="4" data-xref="詩篇 106:11; 出エジプト記 14:23–31; 出エジプト記 15:19"> また主がエジプトの軍勢とその馬と戦車とに行われた事、すなわち彼らがあなたがたのあとを追ってきた時に、紅海の水を彼らの上にあふれさせ、彼らを滅ぼされて、今日に至った事、</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 77:20; 詩篇 106:12–48; 詩篇 78:14–72"> またあなたがたがこの所に来るまで、主が荒野で、あなたがたに行われた事、</span>
<span className="v" id="v6" data-v="6" data-xref="民数記 26:9–10; 詩篇 106:17; 民数記 16:1–35"> およびルベンの子のエリアブの子、ダタンとアビラムとにされた事、すなわちイスラエルのすべての人々の中で、地が口を開き、彼らと、その家族と、天幕と、彼らに従うすべてのものを、のみつくした事などを彼らは知らず、また見なかった。</span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 145:4–6; 詩篇 145:12; 詩篇 150:2"> しかし、あなたがたは主が行われたこれらの大いなる事を、ことごとく目に見たのである。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="エペソ人への手紙 6:10; ヨシュア記 1:6–7; エペソ人への手紙 3:16"> ゆえに、わたしが、きょう、あなたがたに命じる戒めを、ことごとく守らなければならない。そうすればあなたがたは強くなり、渡って行って取ろうとする地にはいって、それを取ることができ、</span>
<span className="v" id="v9" data-v="9" data-xref="出エジプト記 3:8; 申命記 4:40; 申命記 6:2"> かつ、主が先祖たちに誓って彼らとその子孫とに与えようと言われた地、乳と蜜の流れる国において、長く生きることができるであろう。</span>
<span className="v" id="v10" data-v="10" data-xref="ゼカリヤ書 14:18"> あなたがたが行って取ろうとする地は、あなたがたが出てきたエジプトの地のようではない。あそこでは、青物畑でするように、あなたがたは種をまき、足でそれに水を注いだ。</span>
<span className="v" id="v11" data-v="11" data-xref="ヘブル人への手紙 6:7; 申命記 8:7–9; 詩篇 65:12–13"> しかし、あなたがたが渡って行って取る地は、山と谷の多い地で、天から降る雨で潤っている。</span>
<span className="v" id="v12" data-v="12" data-xref="エレミヤ書 24:6; 詩篇 33:18; 列王紀上 9:3"> その地は、あなたの神、主が顧みられる所で、年の始めから年の終りまで、あなたの神、主の目が常にその上にある。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="申命記 10:12; 申命記 4:29; 申命記 6:17"> もし、きょう、あなたがたに命じるわたしの命令によく聞き従って、あなたがたの神、主を愛し、心をつくし、精神をつくして仕えるならば、</span>
<span className="v" id="v14" data-v="14" data-xref="ヤコブの手紙 5:7; レビ記 26:4; エゼキエル書 34:26"> 主はあなたがたの地に雨を、秋の雨、春の雨ともに、時にしたがって降らせ、穀物と、ぶどう酒と、油を取り入れさせ、</span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 104:14; 申命記 6:11; ヨエル書 2:19"> また家畜のために野に草を生えさせられるであろう。あなたは飽きるほど食べることができるであろう。</span>
<span className="v" id="v16" data-v="16" data-xref="ヨブ記 31:27; ヘブル人への手紙 3:12; ヘブル人への手紙 2:1"> あなたがたは心が迷い、離れ去って、他の神々に仕え、それを拝むことのないよう、慎まなければならない。</span>
<span className="v" id="v17" data-v="17" data-xref="列王紀上 8:35; 申命記 6:15; 歴代志下 6:26"> おそらく主はあなたがたにむかい怒りを発して、天を閉ざされるであろう。そのため雨は降らず、地は産物を出さず、あなたがたは主が賜わる良い地から、すみやかに滅びうせるであろう。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="コロサイ人への手紙 3:16; 申命記 6:6–9; 箴言 3:1"> それゆえ、これらのわたしの言葉を心と魂におさめ、またそれを手につけて、しるしとし、目の間に置いて覚えとし、</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 6:7; イザヤ書 38:19; 申命記 4:9–10"> これを子供たちに教え、家に座している時も、道を歩く時も、寝る時も、起きる時も、それについて語り、</span>
<span className="v" id="v20" data-v="20" data-xref="申命記 6:9"> また家の入口の柱と、門にそれを書きしるさなければならない。</span>
<span className="v" id="v21" data-v="21" data-xref="箴言 4:10; 箴言 3:2; 箴言 9:11"> そうすれば、主が先祖たちに与えようと誓われた地に、あなたがたの住む日数およびあなたがたの子供たちの住む日数は、天が地をおおう日数のように多いであろう。</span>
<span className="v" id="v22" data-v="22" data-xref="申命記 6:17; 申命記 11:13; 申命記 10:20"> もしわたしがあなたがたに命じるこのすべての命令をよく守って行い、あなたがたの神、主を愛し、そのすべての道に歩み、主につき従うならば、</span>
<span className="v" id="v23" data-v="23" data-xref="申命記 4:38; 申命記 9:1; 申命記 7:1–2"> 主はこの国々の民を皆、あなたがたの前から追い払われ、あなたがたはあなたがたよりも大きく、かつ強い国々を取るに至るであろう。</span>
<span className="v" id="v24" data-v="24" data-xref="ヨシュア記 14:9; 出エジプト記 23:31; 創世記 15:18–21"> あなたがたが足の裏で踏む所は皆、あなたがたのものとなり、あなたがたの領域は荒野からレバノンに及び、また大川ユフラテから西の海に及ぶであろう。</span>
<span className="v" id="v25" data-v="25" data-xref="申命記 7:24; 出エジプト記 23:27; ヨシュア記 1:5"> だれもあなたがたに立ち向かうことのできる者はないであろう。あなたがたの神、主は、かつて言われたように、あなたがたの踏み入る地の人々が、あなたがたを恐れおののくようにされるであろう。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="申命記 30:1; 申命記 30:15–20; ガラテヤ人への手紙 3:10"> 見よ、わたしは、きょう、あなたがたの前に祝福と、のろいとを置く。</span>
<span className="v" id="v27" data-v="27" data-xref="イザヤ書 1:19; 申命記 28:1–14; イザヤ書 3:10"> もし、きょう、わたしがあなたがたに命じるあなたがたの神、主の命令に聞き従うならば、祝福を受けるであろう。</span>
<span className="v" id="v28" data-v="28" data-xref="申命記 28:15–68; ローマ人への手紙 2:8–9; ガラテヤ人への手紙 3:10"> もしあなたがたの神、主の命令に聞き従わず、わたしが、きょう、あなたがたに命じる道を離れ、あなたがたの知らなかった他の神々に従うならば、のろいを受けるであろう。</span>
<span className="v" id="v29" data-v="29" data-xref="申命記 27:12–26; ヨシュア記 8:30–35"> あなたの神、主が、あなたの行って占領する地にあなたを導き入れられる時、あなたはゲリジム山に祝福を置き、エバル山にのろいを置かなければならない。</span>
<span className="v" id="v30" data-v="30" data-xref="創世記 12:6; 士師記 7:1; ヨシュア記 4:19"> これらの山はヨルダンの向こう側、アラバに住んでいるカナンびとの地で、日の入る方の道の西側にあり、ギルガルに向かいあって、モレのテレビンの木の近くにあるではないか。</span>
<span className="v" id="v31" data-v="31" data-xref="ヨシュア記 1:11; 申命記 9:1; ヨシュア記 3:13–17"> あなたがたはヨルダンを渡り、あなたがたの神、主が賜わる地にはいって、それを占領しようとしている。あなたがたはそれを占領して、そこに住むであろう。</span>
<span className="v" id="v32" data-v="32" data-xref="マタイによる福音書 28:20; 申命記 12:32; テサロニケ人への第一の手紙 4:1–2"> それゆえ、わたしが、きょう、あなたがたに授ける定めと、おきてをことごとく守って行わなければならない。</span>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="レビ記 21:5; ローマ人への手紙 9:8; ガラテヤ人への手紙 3:26"> あなたがたはあなたがたの神、主の子供である。死んだ人のために自分の身に傷をつけてはならない。また額の髪をそってはならない。</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 7:6; レビ記 20:26; 出エジプト記 19:5–6"> あなたはあなたの神、主の聖なる民だからである。主は地のおもてのすべての民のうちからあなたを選んで、自分の宝の民とされた。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="エゼキエル書 4:14; ローマ人への手紙 14:14; レビ記 20:25"> 忌むべき物は、どんなものでも食べてはならない。</span>
<span className="v" id="v4" data-v="4" data-xref="レビ記 11:2–45; 使徒行伝 10:14; 列王紀上 4:23"> あなたがたの食べることができる獣は次のとおりである。すなわち牛、羊、やぎ、</span>
<span className="v" id="v5" data-v="5"> 雄じか、かもしか、こじか、野やぎ、くじか、おおじか、野羊など、</span>
<span className="v" id="v6" data-v="6" data-xref="箴言 18:1; コリント人への第二の手紙 6:17; 詩篇 1:1–2"> 獣のうち、すべて、ひずめの分れたもの、ひずめが二つに切れたもので、反芻するものは食べることができる。</span>
<span className="v" id="v7" data-v="7" data-xref="マタイによる福音書 7:22–23; テトスヘの手紙 1:16; テモテヘの第二の手紙 3:5"> ただし、反芻するものと、ひずめの分れたもののうち、次のものは食べてはならない。すなわち、らくだ、野うさぎ、および岩だぬき、これらは反芻するけれども、ひずめが分れていないから汚れたものである。</span>
<span className="v" id="v8" data-v="8" data-xref="レビ記 11:26–27; イザヤ書 66:3; ペテロの第二の手紙 2:22"> また豚、これは、ひずめが分れているけれども、反芻しないから、汚れたものである。その肉を食べてはならない。またその死体に触れてはならない。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="レビ記 11:9–12"> 水の中にいるすべての物のうち、次のものは食べることができる。すなわち、すべて、ひれと、うろこのあるものは、食べることができる。</span>
<span className="v" id="v10" data-v="10"> すべて、ひれと、うろこのないものは、食べてはならない。これは汚れたものである。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11"> すべて清い鳥は食べることができる。</span>
<span className="v" id="v12" data-v="12" data-xref="レビ記 11:13–19"> ただし、次のものは食べてはならない。すなわち、はげわし、ひげはげわし、みさご、</span>
<span className="v" id="v13" data-v="13"> 黒とび、はやぶさ、とびの類。</span>
<span className="v" id="v14" data-v="14"> 各種のからすの類。</span>
<span className="v" id="v15" data-v="15" data-xref="ヨブ記 30:29"> だちょう、夜たか、かもめ、たかの類。</span>
<span className="v" id="v16" data-v="16"> ふくろう、みみずく、むらさきばん、</span>
<span className="v" id="v17" data-v="17"> ペリカン、はげたか、う、</span>
<span className="v" id="v18" data-v="18"> こうのとり、さぎの類。やつがしら、こうもり。</span>
<span className="v" id="v19" data-v="19" data-xref="ピリピ人への手紙 3:19; レビ記 11:20–23"> またすべて羽があって這うものは汚れたものである。それを食べてはならない。</span>
<span className="v" id="v20" data-v="20"> すべて翼のある清いものは食べることができる。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="出エジプト記 23:19; 出エジプト記 34:26; レビ記 22:8"> すべて自然に死んだものは食べてはならない。町の内におる寄留の他国人に、それを与えて食べさせることができる。またそれを外国人に売ってもよい。あなたはあなたの神、主の聖なる民だからである。<br />子やぎをその母の乳で煮てはならない。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="ネヘミヤ書 10:37; 申命記 12:17; 申命記 26:12–15"> あなたは毎年、畑に種をまいて獲るすべての産物の十分の一を必ず取り分けなければならない。</span>
<span className="v" id="v23" data-v="23" data-xref="申命記 12:5–7; 申命記 4:10; 申命記 12:17–18"> そしてあなたの神、主の前、すなわち主がその名を置くために選ばれる場所で、穀物と、ぶどう酒と、油との十分の一と、牛、羊のういごを食べ、こうして常にあなたの神、主を恐れることを学ばなければならない。</span>
<span className="v" id="v24" data-v="24" data-xref="申命記 12:21; 申命記 12:5; 申命記 11:24"> ただし、その道があまりに遠く、あなたの神、主がその名を置くために選ばれる場所が、非常に遠く離れていて、あなたの神、主があなたを恵まれるとき、それを携えて行くことができないならば、</span>
<span className="v" id="v25" data-v="25"> あなたはその物を金に換え、その金を包んで手に取り、あなたの神、主が選ばれる場所に行き、</span>
<span className="v" id="v26" data-v="26" data-xref="伝道の書 9:7; 申命記 12:7; マタイによる福音書 21:12"> その金をすべてあなたの好む物に換えなければならない。すなわち牛、羊、ぶどう酒、濃い酒など、すべてあなたの欲する物に換え、その所であなたの神、主の前でそれを食べ、家族と共に楽しまなければならない。</span>
<span className="v" id="v27" data-v="27" data-xref="民数記 18:20; 申命記 14:29; 申命記 12:12"> 町の内におるレビびとを捨ててはならない。彼はあなたがたのうちに分がなく、嗣業を持たない者だからである。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="申命記 14:22; アモス書 4:4; 申命記 26:12–15"> 三年の終りごとに、その年の産物の十分の一を、ことごとく持ち出して、町の内にたくわえ、</span>
<span className="v" id="v29" data-v="29" data-xref="申命記 15:10; 申命記 14:27; 箴言 19:17"> あなたがたのうちに分け前がなく、嗣業を持たないレビびと、および町の内におる寄留の他国人と、孤児と、寡婦を呼んで、それを食べさせ、満足させなければならない。そうすれば、あなたの神、主はあなたが手で行うすべての事にあなたを祝福されるであろう。</span>
</div>

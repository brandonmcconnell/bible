<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数記 18:8–9; 申命記 10:9; コリント人への第一の手紙 9:13–14"> レビびとである祭司すなわちレビの全部族はイスラエルのうちに、分も嗣業も持たない。彼らは主にささげられる火祭の物と、その他のささげ物とを食べなければならない。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネの黙示録 1:5–6; 詩篇 84:11; ペテロの第一の手紙 2:5"> 彼らはその兄弟のうちに嗣業を持たない。かつて彼らに約束されたとおり主が彼らの嗣業である。</span>
<span className="v" id="v3" data-v="3" data-xref="レビ記 7:30–34; 申命記 12:27"> 祭司が民から受ける分は次のとおりである。すなわち犠牲をささげる者は、牛でも、羊でも、その肩と、両方のほおと、胃とを祭司に与えなければならない。</span>
<span className="v" id="v4" data-v="4" data-xref="ネヘミヤ書 12:44–47; 民数記 18:12–24; 歴代志下 31:4–10"> また穀物と、ぶどう酒と、油の初物および羊の毛の初物をも彼に与えなければならない。</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 10:8; 民数記 3:10; 出エジプト記 28:1–14"> あなたの神、主がすべての部族のうちから彼を選び出して、彼とその子孫を長く主の名によって立って仕えさせられるからである。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="民数記 35:2–3; 申命記 12:5; 申命記 16:2"> レビびとはイスラエルの全地のうち、どこにいる者でも、彼が宿っている町を出て、主が選ばれる場所に行くならば、</span>
<span className="v" id="v7" data-v="7" data-xref="歴代志下 31:2–4"> 彼は主の前に立っているすべての兄弟レビびとと同じように、その神、主の名によって仕えることができる。</span>
<span className="v" id="v8" data-v="8" data-xref="ネヘミヤ書 12:44; ネヘミヤ書 12:47; 歴代志下 31:4"> 彼が食べる分は彼らと同じである。ただし彼はこのほかに父の遺産を売って獲た物を持つことができる。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="申命記 12:29–31; レビ記 18:26–27; レビ記 18:30"> あなたの神、主が賜わる地にはいったならば、その国々の民の憎むべき事を習いおこなってはならない。</span>
<span className="v" id="v10" data-v="10" data-xref="レビ記 19:31; 出エジプト記 22:18; レビ記 19:26"> あなたがたのうちに、自分のむすこ、娘を火に焼いてささげる者があってはならない。また占いをする者、卜者、易者、魔法使、</span>
<span className="v" id="v11" data-v="11" data-xref="レビ記 19:31; サムエル記上 28:11–14"> 呪文を唱える者、口寄せ、かんなぎ、死人に問うことをする者があってはならない。</span>
<span className="v" id="v12" data-v="12" data-xref="レビ記 18:24; 申命記 9:4; レビ記 18:27"> 主はすべてこれらの事をする者を憎まれるからである。そしてこれらの憎むべき事のゆえにあなたの神、主は彼らをあなたの前から追い払われるのである。</span>
<span className="v" id="v13" data-v="13" data-xref="マタイによる福音書 5:48; 創世記 17:1; 創世記 6:9"> あなたの神、主の前にあなたは全き者でなければならない。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行伝 14:16; 申命記 18:10; 創世記 20:6"> あなたが追い払うかの国々の民は卜者、占いをする者に聞き従うからである。しかし、あなたには、あなたの神、主はそうする事を許されない。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="使徒行伝 3:22–23; 使徒行伝 7:37; ヨハネによる福音書 1:45"> あなたの神、主はあなたのうちから、あなたの同胞のうちから、わたしのようなひとりの預言者をあなたのために起されるであろう。あなたがたは彼に聞き従わなければならない。</span>
<span className="v" id="v16" data-v="16" data-xref="出エジプト記 20:19; 申命記 5:23–28; 申命記 9:10"> これはあなたが集会の日にホレブであなたの神、主に求めたことである。すなわちあなたは『わたしが死ぬことのないようにわたしの神、主の声を二度とわたしに聞かせないでください。またこの大いなる火を二度と見させないでください』と言った。</span>
<span className="v" id="v17" data-v="17" data-xref="申命記 5:28"> 主はわたしに言われた、『彼らが言ったことは正しい。</span>
<span className="v" id="v18" data-v="18" data-xref="申命記 18:15; ヨハネによる福音書 8:28; ヨハネによる福音書 12:49–50"> わたしは彼らの同胞のうちから、おまえのようなひとりの預言者を彼らのために起して、わたしの言葉をその口に授けよう。彼はわたしが命じることを、ことごとく彼らに告げるであろう。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行伝 3:22–23; ヘブル人への手紙 2:3; ヘブル人への手紙 10:26"> 彼がわたしの名によって、わたしの言葉を語るのに、もしこれに聞き従わない者があるならば、わたしはそれを罰するであろう。</span>
<span className="v" id="v20" data-v="20" data-xref="申命記 13:1–5; エレミヤ書 27:15; エレミヤ書 23:13–15"> ただし預言者が、わたしが語れと命じないことを、わたしの名によってほしいままに語り、あるいは他の神々の名によって語るならば、その預言者は殺さなければならない』。</span>
<span className="v" id="v21" data-v="21" data-xref="ヨハネの第一の手紙 4:1–3; テサロニケ人への第一の手紙 5:24; ヨハネの黙示録 2:2"> あなたは心のうちに『われわれは、その言葉が主の言われたものでないと、どうして知り得ようか』と言うであろう。</span>
<span className="v" id="v22" data-v="22" data-xref="申命記 18:20; 列王紀下 20:1; エレミヤ書 28:1–17"> もし預言者があって、主の名によって語っても、その言葉が成就せず、またその事が起らない時は、それは主が語られた言葉ではなく、その預言者がほしいままに語ったのである。その預言者を恐れるに及ばない。</span>

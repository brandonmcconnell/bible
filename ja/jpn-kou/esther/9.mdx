<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="エステル記 3:13; エステル記 8:12; 詩篇 30:11"> 十二月すなわちアダルの月の十三日、王の命令と詔の行われる時が近づいたとき、すなわちユダヤ人の敵が、ユダヤ人を打ち伏せようと望んでいたのに、かえってユダヤ人が自分たちを憎む者を打ち伏せることとなったその日に、</span>
<span className="v" id="v2" data-v="2" data-xref="エステル記 8:17; エステル記 8:11; 詩篇 71:13"> ユダヤ人はアハシュエロス王の各州にある自分たちの町々に集まり、自分たちに害を加えようとする者を殺そうとしたが、だれもユダヤ人に逆らうことのできるものはなかった。すべての民がユダヤ人を恐れたからである。</span>
<span className="v" id="v3" data-v="3" data-xref="エズラ記 8:36; エステル記 8:5; ダニエル書 6:1–2"> 諸州の大臣、総督、知事および王の事をつかさどる者は皆ユダヤ人を助けた。彼らはモルデカイを恐れたからである。</span>
<span className="v" id="v4" data-v="4" data-xref="サムエル記下 3:1; 歴代志上 11:9; サムエル記上 2:30"> モルデカイは王の家で大いなる者となり、その名声は各州に聞えわたった。この人モルデカイがますます勢力ある者となったからである。</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 18:34–40; 詩篇 20:7–8; 詩篇 149:6–9"> そこでユダヤ人はつるぎをもってすべての敵を撃って殺し、滅ぼし、自分たちを憎む者に対し心のままに行った。</span>
<span className="v" id="v6" data-v="6" data-xref="エステル記 3:15"> ユダヤ人はまた首都スサにおいても五百人を殺し、滅ぼした。</span>
<span className="v" id="v7" data-v="7"> またパルシャンダタ、ダルポン、アスパタ、</span>
<span className="v" id="v8" data-v="8"> ポラタ、アダリヤ、アリダタ、</span>
<span className="v" id="v9" data-v="9"> パルマシタ、アリサイ、アリダイ、ワエザタ、</span>
<span className="v" id="v10" data-v="10" data-xref="エステル記 5:11; エステル記 8:11; 創世記 14:23"> すなわちハンメダタの子で、ユダヤ人の敵であるハマンの十人の子をも殺した。しかし、そのぶんどり物には手をかけなかった。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11"> その日、首都スサで殺された者の数が王に報告されると、</span>
<span className="v" id="v12" data-v="12" data-xref="エステル記 7:2; エステル記 5:6"> 王は王妃エステルに言った、「ユダヤ人は首都スサで五百人を殺し、またハマンの十人の子を殺した。王のその他の諸州ではどんなに彼らは殺したことであろう。さてあなたの求めることは何か。必ず聞かれる。更にあなたの願いは何か。必ず聞きとどけられる」。</span>
<span className="v" id="v13" data-v="13" data-xref="エステル記 8:11; 申命記 21:23; エステル記 9:15"> エステルは言った、「もし王がよしとされるならば、どうぞスサにいるユダヤ人にあすも、きょうの詔のように行うことをゆるしてください。かつハマンの十人の子を木に掛けさせてください」。</span>
<span className="v" id="v14" data-v="14"> 王はそうせよと命じたので、スサにおいて詔が出て、ハマンの十人の子は木に掛けられた。</span>
<span className="v" id="v15" data-v="15" data-xref="エステル記 8:11; エステル記 9:10; エステル記 9:16"> アダルの月の十四日にまたスサにいるユダヤ人が集まり、スサで三百人を殺した。しかし、そのぶんどり物には手をかけなかった。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="エステル記 8:11; エステル記 9:2; レビ記 26:7–8"> 王の諸州にいる他のユダヤ人もまた集まって、自分たちの生命を保護し、その敵に勝って平安を得、自分たちを憎む者七万五千人を殺した。しかし、そのぶんどり物には手をかけなかった。</span>
<span className="v" id="v17" data-v="17" data-xref="エステル記 9:21; エステル記 9:1; エステル記 8:9"> これはアダルの月の十三日であって、その十四日に休んで、その日を酒宴と喜びの日とした。</span>
<span className="v" id="v18" data-v="18" data-xref="エステル記 9:21; エステル記 9:1; エステル記 9:15"> しかしスサにいるユダヤ人は十三日と十四日に集まり、十五日に休んで、その日を酒宴と喜びの日とした。</span>
<span className="v" id="v19" data-v="19" data-xref="エステル記 8:17; ヨハネの黙示録 11:10; ネヘミヤ書 8:10–12"> それゆえ村々のユダヤ人すなわち城壁のない町々に住む者はアダルの月の十四日を喜びの日、酒宴の日、祝日とし、互に食べ物を贈る日とした。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="申命記 31:19–22; コリント人への第二の手紙 1:10–11; 詩篇 145:4–12"> モルデカイはこれらのことを書きしるしてアハシュエロス王の諸州にいるすべてのユダヤ人に、近い者にも遠い者にも書を送り、</span>
<span className="v" id="v21" data-v="21"> アダルの月の十四日と十五日とを年々祝うことを命じた。</span>
<span className="v" id="v22" data-v="22" data-xref="詩篇 30:11; イザヤ書 14:3; エステル記 9:19"> すなわちこの両日にユダヤ人がその敵に勝って平安を得、またこの月は彼らのために憂いから喜びに変り、悲しみから祝日に変ったので、これらを酒宴と喜びの日として、互に食べ物を贈り、貧しい者に施しをする日とせよとさとした。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23"> そこでユダヤ人は彼らがすでに始めたように、またモルデカイが彼らに書き送ったように、行うことを約束した。</span>
<span className="v" id="v24" data-v="24" data-xref="エステル記 3:5–13; エステル記 9:10"> これはアガグびとハンメダタの子ハマン、すなわちすべてのユダヤ人の敵がユダヤ人を滅ぼそうとはかり、プルすなわちくじを投げて彼らを絶やし、滅ぼそうとしたが、</span>
<span className="v" id="v25" data-v="25" data-xref="詩篇 7:16; 詩篇 140:9; 詩篇 141:10"> エステルが王の前にきたとき、王は書を送って命じ、ハマンがユダヤ人に対して企てたその悪い計画をハマンの頭上に臨ませ、彼とその子らを木に掛けさせたからである。</span>
<span className="v" id="v26" data-v="26" data-xref="エステル記 9:20; 民数記 16:40; エゼキエル書 39:11"> このゆえに、この両日をプルの名にしたがってプリムと名づけた。そしてこの書のすべての言葉により、またこの事について見たところ、自分たちの会ったところによって、</span>
<span className="v" id="v27" data-v="27" data-xref="ゼカリヤ書 2:11; イザヤ書 56:6; エステル記 8:17"> ユダヤ人は相定め、年々その書かれているところにしたがい、その定められた時にしたがって、この両日を守り、自分たちと、その子孫およびすべて自分たちにつらなる者はこれを行い続けて廃することなく、</span>
<span className="v" id="v28" data-v="28" data-xref="出エジプト記 13:8–9; ヨシュア記 4:7; 詩篇 103:2"> この両日を、代々、家々、州々、町々において必ず覚えて守るべきものとし、これらのプリムの日がユダヤ人のうちに廃せられることのないようにし、またこの記念がその子孫の中に絶えることのないようにした。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="エステル記 9:20; エステル記 2:15; エステル記 8:10"> さらにアビハイルの娘である王妃エステルとユダヤ人モルデカイは、権威をもってこのプリムの第二の書を書き、それを確かめた。</span>
<span className="v" id="v30" data-v="30" data-xref="エステル記 1:1; エステル記 8:9; ゼカリヤ書 8:19"> そしてアハシュエロスの国の百二十七州にいるすべてのユダヤ人に、平和と真実の言葉をもって書を送り、</span>
<span className="v" id="v31" data-v="31" data-xref="エステル記 4:3; エステル記 4:16; ヨナ書 3:2–9"> 断食と悲しみのことについて、ユダヤ人モルデカイと王妃エステルが、かつてユダヤ人に命じたように、またユダヤ人たちが、かつて自分たちとその子孫のために定めたように、プリムのこれらの日をその定めた時に守らせた。</span>
<span className="v" id="v32" data-v="32" data-xref="エステル記 9:26"> エステルの命令はプリムに関するこれらの事を確定した。またこれは書にしるされた。</span>
</div>

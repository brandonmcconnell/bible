<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ダニエル書 9:1; エステル記 8:9; ダニエル書 6:1"> アハシュエロスすなわちインドからエチオピヤまで百二十七州を治めたアハシュエロスの世、</span>
<span className="v" id="v2" data-v="2" data-xref="ネヘミヤ書 1:1; サムエル記下 7:1; ダニエル書 8:2"> アハシュエロス王が首都スサで、その国の位に座していたころ、</span>
<span className="v" id="v3" data-v="3" data-xref="マルコによる福音書 6:21; エステル記 2:18; ダニエル書 5:1"> その治世の第三年に、彼はその大臣および侍臣たちのために酒宴を設けた。ペルシャとメデアの将軍および貴族ならびに諸州の大臣たちがその前にいた。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨブ記 40:10; エペソ人への手紙 1:18; 詩篇 76:1–4"> その時、王はその盛んな国の富と、その王威の輝きと、はなやかさを示して多くの日を重ね、百八十日に及んだ。</span>
<span className="v" id="v5" data-v="5" data-xref="エステル記 7:7–8; 歴代志下 30:21–25; 歴代志下 7:8–9"> これらの日が終った時、王は王の宮殿の園の庭で、首都スサにいる大小のすべての民のために七日の間、酒宴を設けた。</span>
<span className="v" id="v6" data-v="6" data-xref="アモス書 6:4; エゼキエル書 23:41; アモス書 2:8"> そこには白綿布の垂幕と青色のとばりとがあって、紫色の細布のひもで銀の輪および大理石の柱につながれていた。また長いすは金銀で作られ、石膏と大理石と真珠貝および宝石の切りはめ細工の床の上に置かれていた。</span>
<span className="v" id="v7" data-v="7" data-xref="ダニエル書 5:2–4; 歴代志下 9:20; エステル記 2:18"> 酒は金の杯で賜わり、その杯はそれぞれ違ったもので、王の大きな度量にふさわしく、王の用いる酒を惜しみなく賜わった。</span>
<span className="v" id="v8" data-v="8" data-xref="ハバクク書 2:15–16; エレミヤ書 51:7; エレミヤ書 35:8"> その飲むことは法にかない、だれもしいられることはなかった。これは王が人々におのおの自分の好むようにさせよと宮廷のすべての役人に命じておいたからである。</span>
<span className="v" id="v9" data-v="9" data-xref="エステル記 5:8; エステル記 5:4"> 王妃ワシテもまたアハシュエロス王に属する王宮の内で女たちのために酒宴を設けた。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="士師記 16:25; エステル記 7:9; 箴言 20:1"> 七日目にアハシュエロス王は酒のために心が楽しくなり、王の前に仕える七人の侍従メホマン、ビズタ、ハルボナ、ビグタ、アバグタ、ゼタルおよびカルカスに命じて、</span>
<span className="v" id="v11" data-v="11" data-xref="箴言 31:30; マルコによる福音書 6:21–22; 箴言 16:9"> 王妃ワシテに王妃の冠をかぶらせて王の前にこさせよと言った。これは彼女が美しかったので、その美しさを民らと大臣たちに見せるためであった。</span>
<span className="v" id="v12" data-v="12" data-xref="箴言 19:12; 箴言 20:2; ペテロの第一の手紙 3:1"> ところが、王妃ワシテは侍従が伝えた王の命令に従って来ることを拒んだので、王は大いに憤り、その怒りが彼の内に燃えた。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="歴代志上 12:32; ダニエル書 2:2; エレミヤ書 10:7"> そこで王は時を知っている知者に言った、――王はすべて法律と審判に通じている者に相談するのを常とした。</span>
<span className="v" id="v14" data-v="14" data-xref="列王紀下 25:19; エズラ記 7:14; マタイによる福音書 18:10"> 時に王の次にいた人々はペルシャおよびメデアの七人の大臣カルシナ、セタル、アデマタ、タルシシ、メレス、マルセナ、メムカンであった。彼らは皆王の顔を見る者で、国の首位に座する人々であった――</span>
<span className="v" id="v15" data-v="15" data-xref="エステル記 6:6"> 「王妃ワシテは、アハシュエロス王が侍従をもって伝えた命令を行わないゆえ、法律に従って彼女にどうしたらよかろうか」。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行伝 18:14; コリント人への第一の手紙 6:7–8; 使徒行伝 25:10"> メムカンは王と大臣たちの前で言った、「王妃ワシテはただ王にむかって悪い事をしたばかりでなく、すべての大臣およびアハシュエロス王の各州のすべての民にむかってもしたのです。</span>
<span className="v" id="v17" data-v="17" data-xref="サムエル記下 6:16; エペソ人への手紙 5:33"> 王妃のこの行いはあまねくすべての女たちに聞えて、彼らはついにその目に夫を卑しめ、『アハシュエロス王は王妃ワシテに、彼の前に来るように命じたがこなかった』と言うでしょう。</span>
<span className="v" id="v18" data-v="18" data-xref="列王紀上 11:3; 士師記 5:29"> 王妃のこの行いを聞いたペルシャとメデアの大臣の夫人たちもまた、今日、王のすべての大臣たちにこのように言うでしょう。そうすれば必ず卑しめと怒りが多く起ります。</span>
<span className="v" id="v19" data-v="19" data-xref="サムエル記上 15:28; エステル記 8:8; エステル記 3:9"> もし王がよしとされるならば、ワシテはこの後、再びアハシュエロス王の前にきてはならないという王の命令を下し、これをペルシャとメデアの法律の中に書きいれて変ることのないようにし、そして王妃の位を彼女にまさる他の者に与えなさい。</span>
<span className="v" id="v20" data-v="20" data-xref="コロサイ人への手紙 3:18; エペソ人への手紙 5:22; エペソ人への手紙 5:33"> 王の下される詔がこの大きな国にあまねく告げ示されるとき、妻たる者はことごとく、その夫を高下の別なく共に敬うようになるでしょう」。</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 41:37; エステル記 2:4; エステル記 1:19"> 王と大臣たちはこの言葉をよしとしたので、王はメムカンの言葉のとおりに行った。</span>
<span className="v" id="v22" data-v="22" data-xref="エステル記 3:12; エステル記 8:9; エペソ人への手紙 5:22–24"> 王は王の諸州にあまねく書を送り、各州にはその文字にしたがい、各民族にはその言語にしたがって書き送り、すべて男子たる者はその家の主となるべきこと、また自分の民の言語を用いて語るべきことをさとした。</span>

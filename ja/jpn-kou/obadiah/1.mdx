<span className="v" id="v2" data-v="2" data-xref="民数記 24:18; イザヤ書 23:9; ミカ書 7:10"> <span className="pl pl-1">見よ、わたしはあなたを国々のうちで</span><br /><span className="pl pl-1">小さい者とする。</span><br /><span className="pl pl-1">あなたはひどく卑しめられる。</span></span>

<span className="v" id="v6" data-v="6" data-xref="エレミヤ書 49:10; 詩篇 139:1; イザヤ書 45:3"> <span className="pl pl-1">ああ、エサウはかすめられ、</span><br /><span className="pl pl-1">その隠しておいた宝は探り出される。</span></span>

<span className="v" id="v11" data-v="11" data-xref="詩篇 137:7; ナホム書 3:10; ヨエル書 3:3"> <span className="pl pl-1">あなたが離れて立っていた日、</span><br /><span className="pl pl-1">すなわち異邦人がその財宝を持ち去り、</span><br /><span className="pl pl-1">外国人がその門におし入り、</span><br /><span className="pl pl-1">エルサレムをくじ引きにした日、</span><br /><span className="pl pl-1">あなたも彼らのひとりのようであった。</span></span>

<span className="v" id="v13" data-v="13" data-xref="ゼカリヤ書 1:15; エゼキエル書 35:5; エゼキエル書 35:10"> <span className="pl pl-1">あなたはわが民の災の日に、</span><br /><span className="pl pl-1">その門にはいってはならず、</span><br /><span className="pl pl-1">その災の日にその苦しみをながめてはならなかった。</span><br /><span className="pl pl-1">またその災の日に、</span><br /><span className="pl pl-1">その財宝に手をかけてはならなかった。</span></span>
<span className="v" id="v14" data-v="14" data-xref="アモス書 1:6; 詩篇 31:8; オバデヤ書 1:12"> <span className="pl pl-1">あなたは分れ道に立って、</span><br /><span className="pl pl-1">そののがれる者を切ってはならなかった。</span><br /><span className="pl pl-1">あなたは悩みの日にその残った者を</span><br /><span className="pl pl-1">敵にわたしてはならなかった。</span></span>
<span className="v" id="v15" data-v="15" data-xref="ヤコブの手紙 2:13; ハバクク書 2:8; エゼキエル書 30:3"> <span className="pl pl-1">主の日が万国の民に臨むのは近い。</span><br /><span className="pl pl-1">あなたがしたようにあなたもされる。</span><br /><span className="pl pl-1">あなたの報いはあなたのこうべに帰する。</span></span>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="エペソ人への手紙 6:8–20; ヤコブの手紙 2:13; 申命記 24:14–15"> 主人たる者よ、僕を正しく公平に扱いなさい。あなたがたにも主が天にいますことが、わかっているのだから。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="テサロニケ人への第一の手紙 5:17–18; ピリピ人への手紙 4:6; エペソ人への手紙 6:18"> 目をさまして、感謝のうちに祈り、ひたすら祈り続けなさい。</span>
<span className="v" id="v3" data-v="3" data-xref="エペソ人への手紙 6:19–20; 使徒行伝 14:27; テサロニケ人への第二の手紙 3:1–2"> 同時にわたしたちのためにも、神が御言のために門を開いて下さって、わたしたちがキリストの奥義を語れるように（わたしは、実は、そのために獄につながれているのである）、</span>
<span className="v" id="v4" data-v="4" data-xref="コリント人への第二の手紙 4:1–4; エペソ人への手紙 6:20; コロサイ人への手紙 4:6"> また、わたしが語るべきことをはっきりと語れるように、祈ってほしい。</span>
<span className="v" id="v5" data-v="5" data-xref="エペソ人への手紙 5:15–17; テサロニケ人への第一の手紙 4:12; ヤコブの手紙 3:13"> 今の時を生かして用い、そとの人に対して賢く行動しなさい。</span>
<span className="v" id="v6" data-v="6" data-xref="エペソ人への手紙 4:29; ペテロの第一の手紙 3:15; 伝道の書 10:12"> いつも、塩で味つけられた、やさしい言葉を使いなさい。そうすれば、ひとりびとりに対してどう答えるべきか、わかるであろう。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="エペソ人への手紙 6:21–23; 使徒行伝 20:4; テモテヘの第二の手紙 4:12"> わたしの様子については、主にあって共に僕であり、また忠実に仕えている愛する兄弟テキコが、あなたがたにいっさいのことを報告するであろう。</span>
<span className="v" id="v8" data-v="8" data-xref="エペソ人への手紙 6:22; コロサイ人への手紙 2:2; ピリピ人への手紙 2:28"> わたしが彼をあなたがたのもとに送るのは、わたしたちの様子を知り、また彼によって心に励ましを受けるためなのである。</span>
<span className="v" id="v9" data-v="9" data-xref="ピレモンヘの手紙 1:10–19; コロサイ人への手紙 4:7"> あなたがたのひとり、忠実な愛する兄弟オネシモをも、彼と共に送る。彼らはあなたがたに、こちらのいっさいの事情を知らせるであろう。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="ピレモンヘの手紙 1:24; テモテヘの第二の手紙 4:11; 使徒行伝 19:29"> わたしと一緒に捕われの身となっているアリスタルコと、バルナバのいとこマルコとが、あなたがたによろしくと言っている。このマルコについては、もし彼があなたがたのもとに行くなら、迎えてやるようにとのさしずを、あなたがたはすでに受けているはずである。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行伝 11:2; コリント人への第二の手紙 6:1; 使徒行伝 10:45"> また、ユストと呼ばれているイエスからもよろしく。割礼の者の中で、この三人だけが神の国のために働く同労者であって、わたしの慰めとなった者である。</span>
<span className="v" id="v12" data-v="12" data-xref="ローマ人への手紙 15:30; コロサイ人への手紙 1:9; コロサイ人への手紙 1:7"> あなたがたのうちのひとり、キリスト・イエスの僕エパフラスから、よろしく。彼はいつも、祈のうちであなたがたを覚え、あなたがたが全き人となり、神の御旨をことごとく確信して立つようにと、熱心に祈っている。</span>
<span className="v" id="v13" data-v="13" data-xref="コロサイ人への手紙 2:1; ローマ人への手紙 10:2; ヨハネの黙示録 1:11"> わたしは、彼があなたがたのため、またラオデキヤとヒエラポリスの人々のために、ひじょうに心労していることを、証言する。</span>
<span className="v" id="v14" data-v="14" data-xref="ピレモンヘの手紙 1:24; テモテヘの第二の手紙 4:10–11"> 愛する医者ルカとデマスとが、あなたがたによろしく。</span>
<span className="v" id="v15" data-v="15" data-xref="ローマ人への手紙 16:5; ピレモンヘの手紙 1:2; コリント人への第一の手紙 16:9"> ラオデキヤの兄弟たちに、またヌンパとその家にある教会とに、よろしく。</span>
<span className="v" id="v16" data-v="16" data-xref="テサロニケ人への第一の手紙 5:27; テサロニケ人への第二の手紙 3:14"> この手紙があなたがたの所で朗読されたら、ラオデキヤの教会でも朗読されるように、取り計らってほしい。またラオデキヤからまわって来る手紙を、あなたがたも朗読してほしい。</span>
<span className="v" id="v17" data-v="17" data-xref="ピレモンヘの手紙 1:2; 使徒行伝 1:17; エゼキエル書 44:23–24"> アルキポに、「主にあって受けた務をよく果すように」と伝えてほしい。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="ヘブル人への手紙 13:3; テモテヘの第二の手紙 4:22; テモテヘの第一の手紙 6:21"> パウロ自身が、手ずからこのあいさつを書く。わたしが獄につながれていることを、覚えていてほしい。恵みが、あなたがたと共にあるように。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="コロサイ人への手紙 1:29; ピリピ人への手紙 1:30; ヨハネの黙示録 3:14–22"> わたしが、あなたがたとラオデキヤにいる人たちのため、また、直接にはまだ会ったことのない人々のために、どんなに苦闘しているか、わかってもらいたい。</span>
<span className="v" id="v2" data-v="2" data-xref="コロサイ人への手紙 1:27; コロサイ人への手紙 4:8; エペソ人への手紙 6:22"> それは彼らが、心を励まされ、愛によって結び合わされ、豊かな理解力を十分に与えられ、神の奥義なるキリストを知るに至るためである。</span>
<span className="v" id="v3" data-v="3" data-xref="コリント人への第一の手紙 1:24; コリント人への第一の手紙 1:30; ローマ人への手紙 11:33"> キリストのうちには、知恵と知識との宝が、いっさい隠されている。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネの第一の手紙 4:1; エペソ人への手紙 4:14; ローマ人への手紙 16:18–19"> わたしがこう言うのは、あなたがたが、だれにも巧みな言葉で迷わされることのないためである。</span>
<span className="v" id="v5" data-v="5" data-xref="コリント人への第一の手紙 5:3–4; テサロニケ人への第一の手紙 2:17; コリント人への第一の手紙 16:13"> たとい、わたしは肉体においては離れていても、霊においてはあなたがたと一緒にいて、あなたがたの秩序正しい様子とキリストに対するあなたがたの強固な信仰とを見て、喜んでいる。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="コロサイ人への手紙 1:10; ヨハネの第一の手紙 2:6; テサロニケ人への第一の手紙 4:1"> このように、あなたがたは主キリスト・イエスを受けいれたのだから、彼にあって歩きなさい。</span>
<span className="v" id="v7" data-v="7" data-xref="エペソ人への手紙 3:17; エレミヤ書 17:8; エペソ人への手紙 2:20–22"> また、彼に根ざし、彼にあって建てられ、そして教えられたように、信仰が確立されて、あふれるばかり感謝しなさい。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="テモテヘの第一の手紙 6:20; エペソ人への手紙 5:6; マタイによる福音書 7:15"> あなたがたは、むなしいだましごとの哲学で、人のとりこにされないように、気をつけなさい。それはキリストに従わず、世のもろもろの霊力に従う人間の言伝えに基くものにすぎない。</span>
<span className="v" id="v9" data-v="9" data-xref="コロサイ人への手紙 1:19; ヨハネによる福音書 10:30; ヨハネによる福音書 1:14"> キリストにこそ、満ちみちているいっさいの神の徳が、かたちをとって宿っており、</span>
<span className="v" id="v10" data-v="10" data-xref="エペソ人への手紙 3:19; コロサイ人への手紙 1:16–18; エペソ人への手紙 1:20–23"> そしてあなたがたは、キリストにあって、それに満たされているのである。彼はすべての支配と権威とのかしらであり、</span>
<span className="v" id="v11" data-v="11" data-xref="ローマ人への手紙 2:29; ピリピ人への手紙 3:3; ローマ人への手紙 6:6"> あなたがたはまた、彼にあって、手によらない割礼、すなわち、キリストの割礼を受けて、肉のからだを脱ぎ捨てたのである。</span>
<span className="v" id="v12" data-v="12" data-xref="ローマ人への手紙 6:3–5; ペテロの第一の手紙 3:21; ガラテヤ人への手紙 3:27"> あなたがたはバプテスマを受けて彼と共に葬られ、同時に、彼を死人の中からよみがえらせた神の力を信じる信仰によって、彼と共によみがえらされたのである。</span>
<span className="v" id="v13" data-v="13" data-xref="エペソ人への手紙 2:5–6; ローマ人への手紙 8:11; エペソ人への手紙 2:1"> あなたがたは、先には罪の中にあり、かつ肉の割礼がないままで死んでいた者であるが、神は、あなたがたをキリストと共に生かし、わたしたちのいっさいの罪をゆるして下さった。</span>
<span className="v" id="v14" data-v="14" data-xref="イザヤ書 44:22; エペソ人への手紙 2:14–16; イザヤ書 43:25"> 神は、わたしたちを責めて不利におとしいれる証書を、その規定もろともぬり消し、これを取り除いて、十字架につけてしまわれた。</span>
<span className="v" id="v15" data-v="15" data-xref="ヘブル人への手紙 2:14; エペソ人への手紙 4:8; マタイによる福音書 12:29"> そして、もろもろの支配と権威との武装を解除し、キリストにあって凱旋し、彼らをその行列に加えて、さらしものとされたのである。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="ローマ人への手紙 14:5–6; ローマ人への手紙 14:10; ガラテヤ人への手紙 4:10"> だから、あなたがたは、食物と飲み物とにつき、あるいは祭や新月や安息日などについて、だれにも批評されてはならない。</span>
<span className="v" id="v17" data-v="17" data-xref="ヘブル人への手紙 10:1; ヘブル人への手紙 8:5; ヨハネによる福音書 1:17"> これらは、きたるべきものの影であって、その本体はキリストにある。</span>
<span className="v" id="v18" data-v="18" data-xref="コロサイ人への手紙 2:8; ヨハネの第一の手紙 4:1–2; コロサイ人への手紙 2:23"> あなたがたは、わざとらしい謙そんと天使礼拝とにおぼれている人々から、いろいろと悪評されてはならない。彼らは幻を見たことを重んじ、肉の思いによっていたずらに誇るだけで、</span>
<span className="v" id="v19" data-v="19" data-xref="エペソ人への手紙 4:15–16; ヨハネによる福音書 15:4–6; ペテロの第二の手紙 3:18"> キリストなるかしらに、しっかりと着くことをしない。このかしらから出て、からだ全体は、節と節、筋と筋とによって強められ結び合わされ、神に育てられて成長していくのである。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="コロサイ人への手紙 2:8; コロサイ人への手紙 2:16; ガラテヤ人への手紙 4:3"> もしあなたがたが、キリストと共に死んで世のもろもろの霊力から離れたのなら、なぜ、なおこの世に生きているもののように、</span>
<span className="v" id="v21" data-v="21" data-xref="テモテヘの第一の手紙 4:3; 創世記 3:3; イザヤ書 52:11"> 「さわるな、味わうな、触れるな」などという規定に縛られているのか。</span>
<span className="v" id="v22" data-v="22" data-xref="イザヤ書 29:13; テトスヘの手紙 1:14; コリント人への第一の手紙 6:13"> これらは皆、使えば尽きてしまうもの、人間の規定や教によっているものである。</span>
<span className="v" id="v23" data-v="23" data-xref="テモテヘの第一の手紙 4:8; コロサイ人への手紙 2:18; コロサイ人への手紙 2:8"> これらのことは、ひとりよがりの礼拝とわざとらしい謙そんと、からだの苦行とをともなうので、知恵のあるしわざらしく見えるが、実は、ほしいままな肉欲を防ぐのに、なんの役にも立つものではない。</span>
</div>

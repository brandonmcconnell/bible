<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="コリント人への第二の手紙 1:1; コリント人への第一の手紙 1:1; ピレモンヘの手紙 1:1"> 神の御旨によるキリスト・イエスの使徒パウロと兄弟テモテから、</span>
<span className="v" id="v2" data-v="2" data-xref="ペテロの第二の手紙 1:2; エペソ人への手紙 1:1; ローマ人への手紙 1:7"> コロサイにいる、キリストにある聖徒たち、忠実な兄弟たちへ。<br />わたしたちの父なる神から、恵みと平安とが、あなたがたにあるように。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="テサロニケ人への第一の手紙 1:2; コロサイ人への手紙 1:9; テモテヘの第二の手紙 1:3"> わたしたちは、いつもあなたがたのために祈り、わたしたちの主イエス・キリストの父なる神に感謝している。</span>
<span className="v" id="v4" data-v="4" data-xref="エペソ人への手紙 1:15; テサロニケ人への第二の手紙 1:3; テサロニケ人への第一の手紙 1:3"> これは、キリスト・イエスに対するあなたがたの信仰と、すべての聖徒に対していだいているあなたがたの愛とを、耳にしたからである。</span>
<span className="v" id="v5" data-v="5" data-xref="ペテロの第一の手紙 1:3–4; エペソ人への手紙 1:13; テモテヘの第二の手紙 4:8"> この愛は、あなたがたのために天にたくわえられている望みに基くものであり、その望みについては、あなたがたはすでに、あなたがたのところまで伝えられた福音の真理の言葉によって聞いている。</span>
<span className="v" id="v6" data-v="6" data-xref="ヨハネによる福音書 15:16; ピリピ人への手紙 1:11; コロサイ人への手紙 1:23"> そして、この福音は、世界中いたる所でそうであるように、あなたがたのところでも、これを聞いて神の恵みを知ったとき以来、実を結んで成長しているのである。</span>
<span className="v" id="v7" data-v="7" data-xref="コロサイ人への手紙 4:12; ピレモンヘの手紙 1:23; コロサイ人への手紙 4:7"> あなたがたはこの福音を、わたしたちと同じ僕である、愛するエペフラスから学んだのであった。彼はあなたがたのためのキリストの忠実な奉仕者であって、</span>
<span className="v" id="v8" data-v="8" data-xref="ローマ人への手紙 15:30; テモテヘの第二の手紙 1:7; ガラテヤ人への手紙 5:22"> あなたがたが御霊によっていだいている愛を、わたしたちに知らせてくれたのである。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="ヤコブの手紙 3:17; ピリピ人への手紙 1:9–11; ヤコブの手紙 1:5"> そういうわけで、これらの事を耳にして以来、わたしたちも絶えずあなたがたのために祈り求めているのは、あなたがたがあらゆる霊的な知恵と理解力とをもって、神の御旨を深く知り、</span>
<span className="v" id="v10" data-v="10" data-xref="エペソ人への手紙 4:1; ヘブル人への手紙 13:21; ペテロの第二の手紙 1:2–3"> 主のみこころにかなった生活をして真に主を喜ばせ、あらゆる良いわざを行って実を結び、神を知る知識をいよいよ増し加えるに至ることである。</span>
<span className="v" id="v11" data-v="11" data-xref="エペソ人への手紙 3:16; ピリピ人への手紙 4:13; エペソ人への手紙 4:2"> 更にまた祈るのは、あなたがたが、神の栄光の勢いにしたがって賜わるすべての力によって強くされ、何事も喜んで耐えかつ忍び、</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行伝 20:32; エペソ人への手紙 1:11; エペソ人への手紙 1:18"> 光のうちにある聖徒たちの特権にあずかるに足る者とならせて下さった父なる神に、感謝することである。</span>
<span className="v" id="v13" data-v="13" data-xref="エペソ人への手紙 5:8; 使徒行伝 26:18; ペテロの第一の手紙 2:9"> 神は、わたしたちをやみの力から救い出して、その愛する御子の支配下に移して下さった。</span>
<span className="v" id="v14" data-v="14" data-xref="エペソ人への手紙 1:7; ローマ人への手紙 3:24–25; ペテロの第一の手紙 1:19–20"> わたしたちは、この御子によってあがない、すなわち、罪のゆるしを受けているのである。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="ヘブル人への手紙 1:3; ヨハネによる福音書 14:9; ヨハネによる福音書 1:1"> 御子は、見えない神のかたちであって、すべての造られたものに先だって生れたかたである。</span>
<span className="v" id="v16" data-v="16" data-xref="ローマ人への手紙 11:36; ヨハネによる福音書 1:3; コリント人への第一の手紙 8:6"> 万物は、天にあるものも地にあるものも、見えるものも見えないものも、位も主権も、支配も権威も、みな御子にあって造られたからである。これらいっさいのものは、御子によって造られ、御子のために造られたのである。</span>
<span className="v" id="v17" data-v="17" data-xref="ヘブル人への手紙 1:3; コリント人への第一の手紙 8:6; 使徒行伝 17:28"> 彼は万物よりも先にあり、万物は彼にあって成り立っている。</span>
<span className="v" id="v18" data-v="18" data-xref="エペソ人への手紙 1:22–23; ヨハネの黙示録 1:5; エペソ人への手紙 4:15–16"> そして自らは、そのからだなる教会のかしらである。彼は初めの者であり、死人の中から最初に生れたかたである。それは、ご自身がすべてのことにおいて第一の者となるためである。</span>
<span className="v" id="v19" data-v="19" data-xref="コロサイ人への手紙 2:9; ヨハネによる福音書 1:16; エペソ人への手紙 1:23"> 神は、御旨によって、御子のうちにすべての満ちみちた徳を宿らせ、</span>
<span className="v" id="v20" data-v="20" data-xref="コリント人への第二の手紙 5:18–21; エペソ人への手紙 1:10; ヨハネの第一の手紙 4:9–10"> そして、その十字架の血によって平和をつくり、万物、すなわち、地にあるもの、天にあるものを、ことごとく、彼によってご自分と和解させて下さったのである。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="エペソ人への手紙 2:12; テトスヘの手紙 3:3–7; エペソ人への手紙 2:1–3"> あなたがたも、かつては悪い行いをして神から離れ、心の中で神に敵対していた。</span>
<span className="v" id="v22" data-v="22" data-xref="エペソ人への手紙 5:27; ユダの手紙 1:24; エペソ人への手紙 1:4"> しかし今では、御子はその肉のからだにより、その死をとおして、あなたがたを神と和解させ、あなたがたを聖なる、傷のない、責められるところのない者として、みまえに立たせて下さったのである。</span>
<span className="v" id="v23" data-v="23" data-xref="ヘブル人への手紙 3:14; ヘブル人への手紙 3:6; マタイによる福音書 24:13–14"> ただし、あなたがたは、ゆるぐことがなく、しっかりと信仰にふみとどまり、すでに聞いている福音の望みから移り行くことのないようにすべきである。この福音は、天の下にあるすべての造られたものに対して宣べ伝えられたものであって、それにこのパウロが奉仕しているのである。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="ローマ人への手紙 5:3; テモテヘの第二の手紙 1:8; コリント人への第二の手紙 1:5–8"> 今わたしは、あなたがたのための苦難を喜んで受けており、キリストのからだなる教会のために、キリストの苦しみのなお足りないところを、わたしの肉体をもって補っている。</span>
<span className="v" id="v25" data-v="25" data-xref="エペソ人への手紙 3:2; コロサイ人への手紙 1:23; ガラテヤ人への手紙 2:7–8"> わたしは、神の言を告げひろめる務を、あなたがたのために神から与えられているが、そのために教会に奉仕する者になっているのである。</span>
<span className="v" id="v26" data-v="26" data-xref="ルカによる福音書 8:10; ローマ人への手紙 16:25–26; エペソ人への手紙 3:3–10"> その言の奥義は、代々にわたってこの世から隠されていたが、今や神の聖徒たちに明らかにされたのである。</span>
<span className="v" id="v27" data-v="27" data-xref="ヨハネによる福音書 14:20; ローマ人への手紙 8:10; エペソ人への手紙 3:16–17"> 神は彼らに、異邦人の受くべきこの奥義が、いかに栄光に富んだものであるかを、知らせようとされたのである。この奥義は、あなたがたのうちにいますキリストであり、栄光の望みである。</span>
<span className="v" id="v28" data-v="28" data-xref="エペソ人への手紙 5:27; エレミヤ書 3:15; エペソ人への手紙 4:11–13"> わたしたちはこのキリストを宣べ伝え、知恵をつくしてすべての人を訓戒し、また、すべての人を教えている。それは、彼らがキリストにあって全き者として立つようになるためである。</span>
<span className="v" id="v29" data-v="29" data-xref="コリント人への第一の手紙 15:10; エペソ人への手紙 1:19; コリント人への第一の手紙 9:25–27"> わたしはこのために、わたしのうちに力強く働いておられるかたの力により、苦闘しながら努力しているのである。</span>
</div>

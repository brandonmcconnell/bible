<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ローマ人への手紙 8:6; マタイによる福音書 6:33; コリント人への第二の手紙 4:18"> このように、あなたがたはキリストと共によみがえらされたのだから、上にあるものを求めなさい。そこではキリストが神の右に座しておられるのである。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネの第一の手紙 2:15–17; 歴代志上 22:19; コロサイ人への手紙 3:1"> あなたがたは上にあるものを思うべきであって、地上のものに心を引かれてはならない。</span>
<span className="v" id="v3" data-v="3" data-xref="ガラテヤ人への手紙 2:20; ローマ人への手紙 6:2; コロサイ人への手紙 2:20"> あなたがたはすでに死んだものであって、あなたがたのいのちは、キリストと共に神のうちに隠されているのである。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネによる福音書 11:25; ヨハネの第一の手紙 3:2; ガラテヤ人への手紙 2:20"> わたしたちのいのちなるキリストが現れる時には、あなたがたも、キリストと共に栄光のうちに現れるであろう。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="ローマ人への手紙 8:13; ガラテヤ人への手紙 5:19–21; ガラテヤ人への手紙 5:24"> だから、地上の肢体、すなわち、不品行、汚れ、情欲、悪欲、また貪欲を殺してしまいなさい。貪欲は偶像礼拝にほかならない。</span>
<span className="v" id="v6" data-v="6" data-xref="エペソ人への手紙 5:6; ローマ人への手紙 1:18; ペテロの第一の手紙 1:14"> これらのことのために、神の怒りが下るのである。</span>
<span className="v" id="v7" data-v="7" data-xref="エペソ人への手紙 2:2; ペテロの第一の手紙 4:3–4; ローマ人への手紙 6:19–20"> あなたがたも、以前これらのうちに日を過ごしていた時には、これらのことをして歩いていた。</span>
<span className="v" id="v8" data-v="8" data-xref="エペソ人への手紙 4:29; エペソ人への手紙 4:22; ヤコブの手紙 1:20–21"> しかし今は、これらいっさいのことを捨て、怒り、憤り、悪意、そしり、口から出る恥ずべき言葉を、捨ててしまいなさい。</span>
<span className="v" id="v9" data-v="9" data-xref="エペソ人への手紙 4:22; エペソ人への手紙 4:25; レビ記 19:11"> 互にうそを言ってはならない。あなたがたは、古き人をその行いと一緒に脱ぎ捨て、</span>
<span className="v" id="v10" data-v="10" data-xref="エペソ人への手紙 4:23–24; ローマ人への手紙 12:2; エペソ人への手紙 2:10"> 造り主のかたちに従って新しくされ、真の知識に至る新しき人を着たのである。</span>
<span className="v" id="v11" data-v="11" data-xref="ガラテヤ人への手紙 3:28–29; コリント人への第一の手紙 12:13; ローマ人への手紙 10:12"> そこには、もはやギリシヤ人とユダヤ人、割礼と無割礼、未開の人、スクテヤ人、奴隷、自由人の差別はない。キリストがすべてであり、すべてのもののうちにいますのである。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="エペソ人への手紙 4:32; エペソ人への手紙 4:2; ヨハネの第一の手紙 4:19"> だから、あなたがたは、神に選ばれた者、聖なる、愛されている者であるから、あわれみの心、慈愛、謙そん、柔和、寛容を身に着けなさい。</span>
<span className="v" id="v13" data-v="13" data-xref="エペソ人への手紙 4:32; マルコによる福音書 11:25; ヤコブの手紙 2:13"> 互に忍びあい、もし互に責むべきことがあれば、ゆるし合いなさい。主もあなたがたをゆるして下さったのだから、そのように、あなたがたもゆるし合いなさい。</span>
<span className="v" id="v14" data-v="14" data-xref="ペテロの第一の手紙 4:8; エペソ人への手紙 5:2; コリント人への第一の手紙 13:1–13"> これらいっさいのものの上に、愛を加えなさい。愛は、すべてを完全に結ぶ帯である。</span>
<span className="v" id="v15" data-v="15" data-xref="ピリピ人への手紙 4:6–7; ヨハネによる福音書 14:27; イザヤ書 26:3"> キリストの平和が、あなたがたの心を支配するようにしなさい。あなたがたが召されて一体となったのは、このためでもある。いつも感謝していなさい。</span>
<span className="v" id="v16" data-v="16" data-xref="詩篇 119:11; エペソ人への手紙 5:19; ヨハネによる福音書 15:7"> キリストの言葉を、あなたがたのうちに豊かに宿らせなさい。そして、知恵をつくして互に教えまた訓戒し、詩とさんびと霊の歌とによって、感謝して心から神をほめたたえなさい。</span>
<span className="v" id="v17" data-v="17" data-xref="コリント人への第一の手紙 10:31; コロサイ人への手紙 3:23; 箴言 3:6"> そして、あなたのすることはすべて、言葉によるとわざによるとを問わず、いっさい主イエスの名によってなし、彼によって父なる神に感謝しなさい。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="エペソ人への手紙 5:22–9; テトスヘの手紙 2:4–5; コリント人への第一の手紙 11:3"> 妻たる者よ、夫に仕えなさい。それが、主にある者にふさわしいことである。</span>
<span className="v" id="v19" data-v="19" data-xref="ペテロの第一の手紙 3:7; 創世記 2:23–24; コロサイ人への手紙 3:21"> 夫たる者よ、妻を愛しなさい。つらくあたってはいけない。</span>
<span className="v" id="v20" data-v="20" data-xref="出エジプト記 20:12; エペソ人への手紙 6:1–3; 箴言 6:20"> 子たる者よ、何事についても両親に従いなさい。これが主に喜ばれることである。</span>
<span className="v" id="v21" data-v="21" data-xref="箴言 4:1–4; エペソ人への手紙 6:4; 詩篇 103:13"> 父たる者よ、子供をいらだたせてはいけない。心がいじけるかも知れないから。</span>
<span className="v" id="v22" data-v="22" data-xref="エペソ人への手紙 6:5–7; テモテヘの第一の手紙 6:1–2; ガラテヤ人への手紙 1:10"> 僕たる者よ、何事についても、肉による主人に従いなさい。人にへつらおうとして、目先だけの勤めをするのではなく、真心をこめて主を恐れつつ、従いなさい。</span>
<span className="v" id="v23" data-v="23" data-xref="コロサイ人への手紙 3:17; エペソ人への手紙 6:6–7; ローマ人への手紙 14:8"> 何をするにも、人に対してではなく、主に対してするように、心から働きなさい。</span>
<span className="v" id="v24" data-v="24" data-xref="エペソ人への手紙 6:8; ガラテヤ人への手紙 1:10; 使徒行伝 20:32"> あなたがたが知っているとおり、あなたがたは御国をつぐことを、報いとして主から受けるであろう。あなたがたは、主キリストに仕えているのである。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行伝 10:34; ローマ人への手紙 2:11; コリント人への第二の手紙 5:10"> 不正を行う者は、自分の行った不正に対して報いを受けるであろう。それには差別扱いはない。</span>
</div>

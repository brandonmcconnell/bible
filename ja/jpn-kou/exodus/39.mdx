<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出エジプト記 31:10; 出エジプト記 35:23; 出エジプト記 35:19"> 彼らは青糸、紫糸、緋糸で、聖所の務のための編物の服を作った。またアロンのために聖なる服を作った。主がモーセに命じられたとおりである。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="出エジプト記 28:6–12; レビ記 8:7; 出エジプト記 25:7"> また金糸、青糸、紫糸、緋糸、亜麻の撚糸でエポデを作った。</span>
<span className="v" id="v3" data-v="3" data-xref="出エジプト記 36:8; 出エジプト記 26:1"> また金を打ち延べて板とし、これを切って糸とし、青糸、紫糸、緋糸、亜麻の撚糸に交えて、巧みな細工とした。</span>
<span className="v" id="v4" data-v="4"> また、これがために肩ひもを作ってこれにつけ、その両端でこれにつけた。</span>
<span className="v" id="v5" data-v="5" data-xref="ヨハネの黙示録 1:13; マタイによる福音書 28:20; イザヤ書 11:5"> エポデの上で、これをつかねる帯は、同じきれで、同じように、金糸、青糸、紫糸、緋糸、亜麻の撚糸で作った。主がモーセに命じられたとおりである。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="出エジプト記 28:9; エゼキエル書 28:13; ヨブ記 28:16"> また、縞めのうを細工して、金糸の編細工にはめ、これに印を彫刻するように、イスラエルの子たちの名を刻み、</span>
<span className="v" id="v7" data-v="7" data-xref="ヨシュア記 4:7; 出エジプト記 28:12; 出エジプト記 28:29"> これをエポデの肩ひもにつけて、イスラエルの子たちの記念の石とした。主がモーセに命じられたとおりである。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="出エジプト記 28:4; レビ記 8:8–9; イザヤ書 59:17"> また胸当を巧みなわざをもって、エポデの作りのように作った。すなわち金糸、青糸、紫糸、緋糸、亜麻の撚糸で作った。</span>
<span className="v" id="v9" data-v="9"> 胸当は二つに折って四角にした。すなわち二つに折って、長さを一指当りとし、幅も一指当りとした。</span>
<span className="v" id="v10" data-v="10" data-xref="出エジプト記 28:21; 出エジプト記 28:16–17; ヨハネの黙示録 21:19–21"> その中に宝石四列をはめた。すなわち、紅玉髄、貴かんらん石、水晶の列を第一列とし、</span>
<span className="v" id="v11" data-v="11" data-xref="出エジプト記 28:18; エゼキエル書 28:13"> 第二列は、ざくろ石、るり、赤縞めのう、</span>
<span className="v" id="v12" data-v="12"> 第三列は黄水晶、めのう、紫水晶、</span>
<span className="v" id="v13" data-v="13"> 第四列は黄碧玉、縞めのう、碧玉であって、これらを金の編細工の中にはめ込んだ。</span>
<span className="v" id="v14" data-v="14" data-xref="ヨハネの黙示録 21:12"> その宝石はイスラエルの子たちの名にしたがい、その名と等しく十二とし、おのおの印の彫刻のように、十二部族のためにその名を刻んだ。</span>
<span className="v" id="v15" data-v="15" data-xref="ヨハネによる福音書 10:28; ヨハネによる福音書 17:12; ペテロの第一の手紙 1:5"> またひも細工にねじた純金のくさりを胸当につけた。</span>
<span className="v" id="v16" data-v="16" data-xref="出エジプト記 25:12"> また金の二つの編細工と、二つの金の環とを作り、その二つの環を胸当の両端につけた。</span>
<span className="v" id="v17" data-v="17"> かの二筋の金のひもを胸当の端の二つの環につけた。</span>
<span className="v" id="v18" data-v="18" data-xref="出エジプト記 28:14; 雅歌 1:10"> ただし、その二筋のひもの他の両端を、かの二つの編細工につけ、エポデの肩ひもにつけて前にくるようにした。</span>
<span className="v" id="v19" data-v="19"> また二つの金の環を作って、これを胸当の両端につけた。すなわちエポデに接する内側の縁にこれをつけた。</span>
<span className="v" id="v20" data-v="20" data-xref="出エジプト記 26:3"> また金の環二つを作って、これをエポデの二つの肩ひもの下の部分につけ、前の方で、そのつなぎ目に近く、エポデの帯の上の方にくるようにした。</span>
<span className="v" id="v21" data-v="21" data-xref="マタイによる福音書 16:24; コリント人への第一の手紙 1:25; コリント人への第一の手紙 1:27"> 胸当は青ひもをもって、その環をエポデの環に結びつけ、エポデの帯の上の方にくるようにした。こうして、胸当がエポデから離れないようにした。主がモーセに命じられたとおりである。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="出エジプト記 28:31–35"> またエポデに属する上服は、すべて青地の織物で作った。</span>
<span className="v" id="v23" data-v="23"> 上服の口はそのまん中にあって、その口の周囲には、よろいのえりのように縁をつけて、ほころびないようにした。</span>
<span className="v" id="v24" data-v="24" data-xref="出エジプト記 28:33; ガラテヤ人への手紙 5:22"> 上服のすそには青糸、紫糸、緋糸、亜麻の撚糸で、ざくろを作りつけ、</span>
<span className="v" id="v25" data-v="25" data-xref="出エジプト記 28:33–34; 雅歌 4:13; 詩篇 89:15"> また純金で鈴を作り、その鈴を上服のすその周囲の、ざくろとざくろとの間につけた。</span>
<span className="v" id="v26" data-v="26" data-xref="出エジプト記 28:34; 雅歌 4:13; 雅歌 6:7"> すなわち鈴にざくろ、鈴にざくろと、務の上服のすその周囲につけた。主がモーセに命じられたとおりである。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="エゼキエル書 44:18; ペテロの第一の手紙 1:13; イザヤ書 61:10"> またアロンとその子たちのために、亜麻糸で織った下服を作り、</span>
<span className="v" id="v28" data-v="28" data-xref="出エジプト記 28:4; エゼキエル書 44:18; 出エジプト記 28:39"> 亜麻布で帽子を作り、亜麻布で麗しい頭布を作り、亜麻の撚糸の布で、下ばきを作り、</span>
<span className="v" id="v29" data-v="29" data-xref="出エジプト記 28:39"> 亜麻の撚糸および青糸、紫糸、緋糸で、色とりどりに織った帯を作った。主がモーセに命じられたとおりである。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="ヨハネの黙示録 5:10; ヘブル人への手紙 7:26; ヘブル人への手紙 1:3"> また純金をもって、聖なる冠の前板を作り、印の彫刻のように、その上に「主に聖なる者」という文字を書き、</span>
<span className="v" id="v31" data-v="31"> これに青ひもをつけて、それを帽子の上に結びつけた。主がモーセに命じられたとおりである。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="出エジプト記 39:42–43; マタイによる福音書 28:20; 出エジプト記 25:40"> こうして会見の天幕なる幕屋の、もろもろの工事が終った。イスラエルの人々はすべて主がモーセに命じられたようにおこなった。</span>
<span className="v" id="v33" data-v="33" data-xref="出エジプト記 35:11–19; 出エジプト記 31:7–11; 出エジプト記 36:1–38"> 彼らは幕屋と天幕およびそのもろもろの器をモーセのもとに携えてきた。すなわち、その鉤、その枠、その横木、その柱、その座、</span>
<span className="v" id="v34" data-v="34"> あかね染めの雄羊の皮のおおい、じゅごんの皮のおおい、隔ての垂幕、</span>
<span className="v" id="v35" data-v="35" data-xref="ヘブル人への手紙 9:5; 出エジプト記 25:17; ヘブル人への手紙 9:8"> あかしの箱と、そのさお、贖罪所、</span>
<span className="v" id="v36" data-v="36" data-xref="出エジプト記 25:30; 列王紀上 7:48"> 机と、そのもろもろの器、供えのパン、</span>
<span className="v" id="v37" data-v="37" data-xref="ピリピ人への手紙 2:15; 出エジプト記 27:21; マタイによる福音書 5:14–16"> 純金の燭台と、そのともしび皿、すなわち列に並べるともしび皿と、そのもろもろの器、およびそのともし油、</span>
<span className="v" id="v38" data-v="38" data-xref="出エジプト記 30:7; 出エジプト記 37:29; 出エジプト記 30:3"> 金の祭壇、注ぎ油、香ばしい薫香、幕屋の入口のとばり、</span>
<span className="v" id="v39" data-v="39" data-xref="列王紀上 8:64; 出エジプト記 38:30"> 青銅の祭壇、その青銅の格子と、そのさお、およびそのもろもろの器、洗盤とその台、</span>
<span className="v" id="v40" data-v="40" data-xref="出エジプト記 27:9–16"> 庭のあげばり、その柱とその座、庭の門のとばり、そのひもとその釘、また会見の天幕の幕屋に用いるもろもろの器、</span>
<span className="v" id="v41" data-v="41" data-xref="出エジプト記 28:2; 出エジプト記 31:10; 出エジプト記 39:1"> 聖所で務をなす編物の服、すなわち祭司の務をなすための祭司アロンの聖なる服およびその子たちの服。</span>
<span className="v" id="v42" data-v="42" data-xref="出エジプト記 35:10; 出エジプト記 23:21–22; テモテヘの第二の手紙 2:15"> イスラエルの人々は、すべて主がモーセに命じられたように、そのすべての工事をした。</span>
<span className="v" id="v43" data-v="43" data-xref="民数記 6:23–27; レビ記 9:22–23; サムエル記下 6:18"> モーセがそのすべての工事を見ると、彼らは主が命じられたとおりに、それをなしとげていたので、モーセは彼らを祝福した。</span>
</div>

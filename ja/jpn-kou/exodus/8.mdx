<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出エジプト記 3:18; 出エジプト記 3:12; 出エジプト記 5:1"> 主はモーセに言われた、「あなたはパロのところに行って言いなさい、『主はこう仰せられます、「わたしの民を去らせて、わたしに仕えさせなさい。</span>
<span className="v" id="v2" data-v="2" data-xref="詩篇 78:45; 出エジプト記 9:2; 出エジプト記 7:14"> しかし、去らせることを拒むならば、見よ、わたしは、かえるをもって、あなたの領土を、ことごとく撃つであろう。</span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 105:30; 出エジプト記 12:34"> ナイル川にかえるが群がり、のぼって、あなたの家、あなたの寝室にはいり、寝台にのぼり、あなたの家来と民の家にはいり、またあなたのかまどや、こね鉢にはいり、</span>
<span className="v" id="v4" data-v="4" data-xref="イザヤ書 19:11; ダニエル書 4:37; 使徒行伝 12:22–23"> あなたと、あなたの民と、すべての家来のからだに、はい上がるであろう」と』」。</span>
<span className="v" id="v5" data-v="5" data-xref="出エジプト記 7:19"> 主はモーセに言われた、「あなたはアロンに言いなさい、『つえを持って、手を川の上、流れの上、、池の上にさし伸べ、かえるをエジプトの地にのぼらせなさい』と」。</span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 105:30; 詩篇 78:45; ヨハネの黙示録 16:13"> アロンが手をエジプトの水の上にさし伸べたので、かえるはのぼってエジプトの地をおおった。</span>
<span className="v" id="v7" data-v="7" data-xref="出エジプト記 7:11; 出エジプト記 7:22; 申命記 13:1–3"> 魔術師らも秘術をもって同じように行い、かえるをエジプトの地にのぼらせた。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="出エジプト記 10:17; 出エジプト記 9:28; 出エジプト記 8:25–28"> パロはモーセとアロンを召して言った、「かえるをわたしと、わたしの民から取り去るように主に願ってください。そのときわたしはこの民を去らせて、主に犠牲をささげさせるでしょう」。</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀上 18:25; イザヤ書 10:15; 士師記 7:2"> モーセはパロに言った、「あなたと、あなたの家来と、あなたの民のために、わたしがいつ願って、このかえるを、あなたとあなたの家から断って、ナイル川だけにとどまらせるべきか、きめてください」。</span>
<span className="v" id="v10" data-v="10" data-xref="イザヤ書 46:9; 詩篇 86:8; 歴代志上 17:20"> パロは言った、「明日」。モーセは言った、「仰せのとおりになって、わたしたちの神、主に並ぶもののないことを、あなたが知られますように。</span>
<span className="v" id="v11" data-v="11" data-xref="出エジプト記 8:3; 出エジプト記 8:9"> そして、かえるはあなたと、あなたの家と、あなたの家来と、あなたの民を離れてナイル川にだけとどまるでしょう」。</span>
<span className="v" id="v12" data-v="12" data-xref="ヤコブの手紙 5:16–18; 出エジプト記 8:30; 出エジプト記 10:18"> こうしてモーセとアロンはパロを離れて出た。モーセは主がパロにつかわされたかえるの事について、主に呼び求めたので、</span>
<span className="v" id="v13" data-v="13" data-xref="申命記 34:10–12"> 主はモーセのことばのようにされ、かえるは家から、庭から、また畑から死に絶えた。</span>
<span className="v" id="v14" data-v="14" data-xref="出エジプト記 8:24; 出エジプト記 7:21; ヨエル書 2:20"> これをひと山ひと山に積んだので、地は臭くなった。</span>
<span className="v" id="v15" data-v="15" data-xref="イザヤ書 26:10; 伝道の書 8:11; ヘブル人への手紙 3:8"> ところがパロは息つくひまのできたのを見て、主が言われたように、その心をかたくなにして彼らの言うことを聞かなかった。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="出エジプト記 8:5; 出エジプト記 8:17"> 主はモーセに言われた、「あなたはアロンに言いなさい、『あなたのつえをさし伸べて地のちりを打ち、それをエジプトの全国にわたって、ぶよとならせなさい』と」。</span>
<span className="v" id="v17" data-v="17" data-xref="詩篇 105:31; イザヤ書 23:9; 使徒行伝 12:23"> 彼らはそのように行った。すなわちアロンはそのつえをとって手をさし伸べ、地のちりを打ったので、ぶよは人と家畜についた。すなわち、地のちりはみなエジプトの全国にわたって、ぶよとなった。</span>
<span className="v" id="v18" data-v="18" data-xref="出エジプト記 7:11; 出エジプト記 9:11; ダニエル書 5:8"> 魔術師らも秘術をもって同じように行い、ぶよを出そうとしたが、彼らにはできなかった。ぶよが人と家畜についたので、</span>
<span className="v" id="v19" data-v="19" data-xref="ルカによる福音書 11:20; 詩篇 8:3; 出エジプト記 7:5"> 魔術師らはパロに言った、「これは神の指です」。しかし主の言われたように、パロの心はかたくなになって、彼らのいうことを聞かなかった。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="出エジプト記 7:15; 出エジプト記 9:13; 出エジプト記 8:1"> 主はモーセに言われた、「あなたは朝早く起きてパロの前に立ちなさい。ちょうど彼は水のところに出ているから彼に言いなさい、『主はこう仰せられる、「わたしの民を去らせて、わたしに仕えさせなさい。</span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 78:45; イザヤ書 7:18; 詩篇 105:31"> あなたがわたしの民を去らせないならば、わたしは、あなたとあなたの家来と、あなたの民とあなたの家とに、あぶの群れをつかわすであろう。エジプトびとの家々は、あぶの群れで満ち、彼らの踏む地もまた、そうなるであろう。</span>
<span className="v" id="v22" data-v="22" data-xref="出エジプト記 9:4; マラキ書 3:18; 出エジプト記 10:23"> その日わたしは、わたしの民の住むゴセンの地を区別して、そこにあぶの群れを入れないであろう。国の中でわたしが主であることをあなたが知るためである。</span>
<span className="v" id="v23" data-v="23"> わたしはわたしの民とあなたの民の間に区別をおく。このしるしは、あす起るであろう」と』」。</span>
<span className="v" id="v24" data-v="24" data-xref="詩篇 105:31; 詩篇 78:45; 出エジプト記 8:21"> 主はそのようにされたので、おびただしいあぶが、パロの家と、その家来の家と、エジプトの全国にはいってきて、地はあぶの群れのために害をうけた。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="出エジプト記 8:8; 出エジプト記 9:27; 出エジプト記 10:16"> そこで、パロはモーセとアロンを召して言った、「あなたがたは行ってこの国の内で、あなたがたの神に犠牲をささげなさい」。</span>
<span className="v" id="v26" data-v="26" data-xref="創世記 43:32; 創世記 46:34; 申命記 7:25–26"> モーセは言った、「そうすることはできません。わたしたちはエジプトびとの忌むものを犠牲として、わたしたちの神、主にささげるからです。もし、エジプトびとの目の前で、彼らの忌むものを犠牲にささげるならば、彼らはわたしたちを石で打たないでしょうか。</span>
<span className="v" id="v27" data-v="27" data-xref="出エジプト記 3:18; 出エジプト記 3:12; 出エジプト記 34:11"> わたしたちは三日の道のりほど、荒野にはいって、わたしたちの神、主に犠牲をささげ、主がわたしたちに命じられるようにしなければなりません」。</span>
<span className="v" id="v28" data-v="28" data-xref="出エジプト記 8:8; 出エジプト記 9:28; 列王紀上 13:6"> パロは言った、「わたしはあなたがたを去らせ、荒野で、あなたがたの神、主に犠牲をささげさせよう。ただあまり遠くへ行ってはならない。わたしのために祈願しなさい」。</span>
<span className="v" id="v29" data-v="29" data-xref="出エジプト記 8:15; エレミヤ書 42:20–21; 出エジプト記 8:8"> モーセは言った、「わたしはあなたのもとから出て行って主に祈願しましょう。あすあぶの群れがパロと、その家来と、その民から離れるでしょう。ただパロはまた欺いて、民が主に犠牲をささげに行くのをとめないようにしてください」。</span>
<span className="v" id="v30" data-v="30" data-xref="出エジプト記 8:12; 出エジプト記 9:33; ヤコブの手紙 5:16"> こうしてモーセはパロのもとを出て、主に祈願したので、</span>
<span className="v" id="v31" data-v="31"> 主はモーセの言葉のようにされた。すなわち、あぶの群れをパロと、その家来と、その民から取り去られたので、一つも残らなかった。</span>
<span className="v" id="v32" data-v="32" data-xref="出エジプト記 8:15; 出エジプト記 4:21; ローマ人への手紙 2:5"> しかしパロはこんどもまた、その心をかたくなにして民を去らせなかった。</span>
</div>

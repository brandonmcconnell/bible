<span className="v" id="v4" data-v="4" data-xref="出エジプト記 14:13–28; 出エジプト記 14:6–7"> <span className="pl pl-1">彼はパロの戦車とその軍勢とを海に投げ込まれた、</span><br /><span className="pl pl-1">そのすぐれた指揮者たちは紅海に沈んだ。</span></span>
<span className="v" id="v5" data-v="5" data-xref="ネヘミヤ書 9:11; 出エジプト記 15:10; 出エジプト記 14:28"> <span className="pl pl-1">大水は彼らをおおい、彼らは石のように淵に下った。</span></span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 118:15–16; イザヤ書 51:9; ヨハネの黙示録 2:27"> <span className="pl pl-1">主よ、あなたの右の手は力をもって栄光にかがやく、</span><br /><span className="pl pl-1">主よ、あなたの右の手は敵を打ち砕く。</span></span>

<span className="v" id="v9" data-v="9" data-xref="士師記 5:30; 出エジプト記 14:5; イザヤ書 53:12"> <span className="pl pl-1">敵は言った、『わたしは追い行き、追い着いて、</span><br /><span className="pl pl-1">分捕物を分かち取ろう、</span><br /><span className="pl pl-1">わたしの欲望を彼らによって満たそう、</span><br /><span className="pl pl-1">つるぎを抜こう、わたしの手は彼らを滅ぼそう』。</span></span>

<span className="v" id="v11" data-v="11" data-xref="列王紀上 8:23; 詩篇 89:5–8; サムエル記上 2:2"> <span className="pl pl-1">主よ、神々のうち、だれがあなたに比べられようか、</span><br /><span className="pl pl-1">だれがあなたのように、聖にして栄えあるもの、</span><br /><span className="pl pl-1">ほむべくして恐るべきもの、</span><br /><span className="pl pl-1">くすしきわざを行うものであろうか。</span></span>

<span className="v" id="v13" data-v="13" data-xref="詩篇 77:20; ペテロの第一の手紙 1:5; 詩篇 77:14–15"> <span className="pl pl-1">あなたは、あがなわれた民を恵みをもって導き、</span><br /><span className="pl pl-1">み力をもって、あなたの聖なるすまいに伴われた。</span></span>
<span className="v" id="v14" data-v="14" data-xref="申命記 2:25; ヨシュア記 2:9–10; 詩篇 48:6"> <span className="pl pl-1">もろもろの民は聞いて震え、</span><br /><span className="pl pl-1">ペリシテの住民は苦しみに襲われた。</span></span>

<span className="v" id="v17" data-v="17" data-xref="詩篇 44:2; 詩篇 80:8; 詩篇 78:54–55"> <span className="pl pl-1">あなたは彼らを導いて、</span><br /><span className="pl pl-1">あなたの嗣業の山に植えられる。</span><br /><span className="pl pl-1">主よ、これこそあなたのすまいとして、</span><br /><span className="pl pl-1">みずから造られた所、</span><br /><span className="pl pl-1">主よ、み手によって建てられた聖所。</span></span>

<span className="v" id="v20" data-v="20" data-xref="詩篇 150:4; サムエル記上 18:6; 詩篇 68:25"> <span className="pl pl-1">そのとき、アロンの姉、女預言者ミリアムはタンバリンを手に取り、女たちも皆タンバリンを取って、踊りながら、そのあとに従って出てきた。</span></span>

<span className="v" id="v22" data-v="22" data-xref="創世記 16:7; サムエル記上 15:7; 創世記 25:18"> さて、モーセはイスラエルを紅海から旅立たせた。彼らはシュルの荒野に入り、三日のあいだ荒野を歩いたが、水を得なかった。</span>
<span className="v" id="v23" data-v="23" data-xref="ルツ記 1:20; 民数記 33:8"> 彼らはメラに着いたが、メラの水は苦くて飲むことができなかった。それで、その所の名はメラと呼ばれた。</span>
<span className="v" id="v24" data-v="24" data-xref="出エジプト記 16:2; 出エジプト記 14:11; 民数記 20:2–5"> ときに、民はモーセにつぶやいて言った、「わたしたちは何を飲むのですか」。</span>
<span className="v" id="v25" data-v="25" data-xref="申命記 8:2; 詩篇 66:10; 士師記 3:1"> モーセは主に叫んだ。主は彼に一本の木を示されたので、それを水に投げ入れると、水は甘くなった。<br />その所で主は民のために定めと、おきてを立てられ、彼らを試みて、</span>
<span className="v" id="v26" data-v="26" data-xref="詩篇 103:3; 申命記 7:15; 出エジプト記 23:25"> 言われた、「あなたが、もしあなたの神、主の声に良く聞き従い、その目に正しいと見られることを行い、その戒めに耳を傾け、すべての定めを守るならば、わたしは、かつてエジプトびとに下した病を一つもあなたに下さないであろう。わたしは主であって、あなたをいやすものである」。</span>

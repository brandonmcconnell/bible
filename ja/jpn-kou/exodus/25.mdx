<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 主はモーセに言われた、</span>
<span className="v" id="v2" data-v="2" data-xref="コリント人への第二の手紙 9:7; ネヘミヤ書 11:2; エズラ記 2:68"> 「イスラエルの人々に告げて、わたしのためにささげ物を携えてこさせなさい。すべて、心から喜んでする者から、わたしにささげる物を受け取りなさい。</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 8:9; ヨブ記 28:2"> あなたがたが彼らから受け取るべきささげ物はこれである。すなわち金、銀、青銅、</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネの黙示録 19:8; 創世記 41:42; エゼキエル書 16:10"> 青糸、紫糸、緋糸、亜麻の撚糸、やぎの毛糸、</span>
<span className="v" id="v5" data-v="5" data-xref="出エジプト記 26:37–1; 出エジプト記 26:14–15; 出エジプト記 36:20"> あかね染の雄羊の皮、じゅごんの皮、アカシヤ材、</span>
<span className="v" id="v6" data-v="6" data-xref="出エジプト記 27:20; 出エジプト記 25:37; 出エジプト記 40:24–25"> ともし油、注ぎ油と香ばしい薫香のための香料、</span>
<span className="v" id="v7" data-v="7" data-xref="出エジプト記 28:4; 出エジプト記 28:6–30"> 縞めのう、エポデと胸当にはめる宝石。</span>
<span className="v" id="v8" data-v="8" data-xref="コリント人への第二の手紙 6:16; 列王紀上 6:13; ヨハネの黙示録 21:3"> また、彼らにわたしのために聖所を造らせなさい。わたしが彼らのうちに住むためである。</span>
<span className="v" id="v9" data-v="9" data-xref="出エジプト記 25:40; ヘブル人への手紙 8:5; 使徒行伝 7:44"> すべてあなたに示す幕屋の型および、そのもろもろの器の型に従って、これを造らなければならない。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="ヘブル人への手紙 9:4; 出エジプト記 37:1–3; 申命記 10:1–3"> 彼らはアカシヤ材で箱を造らなければならない。長さは二キュビト半、幅は一キュビト半、高さは一キュビト半。</span>
<span className="v" id="v11" data-v="11" data-xref="出エジプト記 25:24; 出エジプト記 30:3; 歴代志下 3:4"> あなたは純金でこれをおおわなければならない。すなわち内外ともにこれをおおい、その上の周囲に金の飾り縁を造らなければならない。</span>
<span className="v" id="v12" data-v="12" data-xref="出エジプト記 27:7; 出エジプト記 25:26; 出エジプト記 25:15"> また金の環四つを鋳て、その四すみに取り付けなければならない。すなわち二つの環をこちら側に、二つの環をあちら側に付けなければならない。</span>
<span className="v" id="v13" data-v="13" data-xref="歴代志上 15:15; 民数記 4:11; 出エジプト記 27:6"> またアカシヤ材のさおを造り、金でこれをおおわなければならない。</span>
<span className="v" id="v14" data-v="14"> そしてそのさおを箱の側面の環に通し、それで箱をかつがなければならない。</span>
<span className="v" id="v15" data-v="15" data-xref="列王紀上 8:8; 歴代志下 5:9"> さおは箱の環に差して置き、それを抜き放してはならない。</span>
<span className="v" id="v16" data-v="16" data-xref="申命記 31:26; 列王紀上 8:9; ヘブル人への手紙 9:4"> そしてその箱に、わたしがあなたに与えるあかしの板を納めなければならない。</span>
<span className="v" id="v17" data-v="17" data-xref="ヘブル人への手紙 9:5; 出エジプト記 37:6; ヘブル人への手紙 4:16"> また純金の贖罪所を造らなければならない。長さは二キュビト半、幅は一キュビト半。</span>
<span className="v" id="v18" data-v="18" data-xref="エゼキエル書 10:20; ヘブル人への手紙 9:5; 列王紀上 8:6–7"> また二つの金のケルビムを造らなければならない。これを打物造りとし、贖罪所の両端に置かなければならない。</span>
<span className="v" id="v19" data-v="19"> 一つのケルブをこの端に、一つのケルブをかの端に造り、ケルビムを贖罪所の一部としてその両端に造らなければならない。</span>
<span className="v" id="v20" data-v="20" data-xref="歴代志上 28:18; 列王紀上 8:7; ヘブル人への手紙 9:5"> ケルビムは翼を高く伸べ、その翼をもって贖罪所をおおい、顔は互にむかい合い、ケルビムの顔は贖罪所にむかわなければならない。</span>
<span className="v" id="v21" data-v="21" data-xref="出エジプト記 26:34; ローマ人への手紙 10:4; 出エジプト記 25:16–17"> あなたは贖罪所を箱の上に置き、箱の中にはわたしが授けるあかしの板を納めなければならない。</span>
<span className="v" id="v22" data-v="22" data-xref="出エジプト記 29:42–43; 民数記 7:89; イザヤ書 37:16"> その所でわたしはあなたに会い、贖罪所の上から、あかしの箱の上にある二つのケルビムの間から、イスラエルの人々のために、わたしが命じようとするもろもろの事を、あなたに語るであろう。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="ヘブル人への手紙 9:2; 出エジプト記 37:10–16; 列王紀上 7:48"> あなたはまたアカシヤ材の机を造らなければならない。長さは二キュビト、幅は一キュビト、高さは一キュビト半。</span>
<span className="v" id="v24" data-v="24" data-xref="出エジプト記 25:11; 列王紀上 6:20–22"> 純金でこれをおおい、周囲に金の飾り縁を造り、</span>
<span className="v" id="v25" data-v="25" data-xref="出エジプト記 37:2; 出エジプト記 30:3"> またその周囲に手幅の棧を造り、その棧の周囲に金の飾り縁を造らなければならない。</span>
<span className="v" id="v26" data-v="26"> また、そのために金の環四つを造り、その四つの足のすみ四か所にその環を取り付けなければならない。</span>
<span className="v" id="v27" data-v="27" data-xref="出エジプト記 25:14; 出エジプト記 25:28"> 環は棧のわきに付けて、机をかつぐさおを入れる所としなければならない。</span>
<span className="v" id="v28" data-v="28" data-xref="出エジプト記 25:14; 使徒行伝 9:15; 民数記 10:17"> またアカシヤ材のさおを造り、金でこれをおおい、それをもって、机をかつがなければならない。</span>
<span className="v" id="v29" data-v="29" data-xref="民数記 4:7; 出エジプト記 37:16; ヨハネの黙示録 3:20"> また、その皿、乳香を盛る杯および灌祭を注ぐための瓶と鉢を造り、これらは純金で造らなければならない。</span>
<span className="v" id="v30" data-v="30" data-xref="レビ記 24:5–9; マタイによる福音書 12:4; 出エジプト記 39:36"> そして机の上には供えのパンを置いて、常にわたしの前にあるようにしなければならない。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="列王紀上 7:49; ゼカリヤ書 4:2; 出エジプト記 37:17–24"> また純金の燭台を造らなければならない。燭台は打物造りとし、その台、幹、萼、節、花を一つに連ならせなければならない。</span>
<span className="v" id="v32" data-v="32"> また六つの枝をそのわきから出させ、燭台の三つの枝をこの側から、燭台の三つの枝をかの側から出させなければならない。</span>
<span className="v" id="v33" data-v="33" data-xref="民数記 17:4–8; エレミヤ書 1:11–12; ゼカリヤ書 4:3"> あめんどうの花の形をした三つの萼が、それぞれ節と花をもって一つの枝にあり、また、あめんどうの花の形をした三つの萼が、それぞれ節と花をもってほかの枝にあるようにし、燭台から出る六つの枝を、みなそのようにしなければならない。</span>
<span className="v" id="v34" data-v="34"> また、燭台の幹には、あめんどうの花の形をした四つの萼を付け、その萼にはそれぞれ節と花をもたせなさい。</span>
<span className="v" id="v35" data-v="35"> すなわち二つの枝の下に一つの節を取り付け、次の二つの枝の下に一つの節を取り付け、更に次の二つの枝の下に一つの節を取り付け、燭台の幹から出る六つの枝に、みなそのようにしなければならない。</span>
<span className="v" id="v36" data-v="36" data-xref="出エジプト記 25:18; 列王紀上 10:16–17; 歴代志下 9:15"> それらの節と枝を一つに連ね、ことごとく純金の打物造りにしなければならない。</span>
<span className="v" id="v37" data-v="37" data-xref="民数記 8:2; ヨハネの黙示録 1:20–1; レビ記 24:2–4"> また、それのともしび皿を七つ造り、そのともしび皿に火をともして、その前方を照させなければならない。</span>
<span className="v" id="v38" data-v="38" data-xref="列王紀下 12:13; エレミヤ書 52:18; 列王紀下 25:14"> その芯切りばさみと、芯取り皿は純金で造らなければならない。</span>
<span className="v" id="v39" data-v="39"> すなわち純金一タラントで燭台と、これらのもろもろの器とが造られなければならない。</span>
<span className="v" id="v40" data-v="40" data-xref="ヘブル人への手紙 8:5; 出エジプト記 26:30; 使徒行伝 7:44"> そしてあなたが山で示された型に従い、注意してこれを造らなければならない。</span>
</div>

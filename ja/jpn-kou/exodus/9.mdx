<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出エジプト記 8:1; 出エジプト記 10:3; 出エジプト記 8:20"> 主はモーセに言われた、「パロのもとに行って、彼に言いなさい、『ヘブルびとの神、主はこう仰せられる、「わたしの民を去らせて、わたしに仕えさせなさい。</span>
<span className="v" id="v2" data-v="2" data-xref="出エジプト記 8:2; 出エジプト記 4:23; レビ記 26:27–28"> あなたがもし彼らを去らせることを拒んで、なお彼らを留めおくならば、</span>
<span className="v" id="v3" data-v="3" data-xref="出エジプト記 7:4; 使徒行伝 13:11; サムエル記上 6:9"> 主の手は最も激しい疫病をもって、野にいるあなたの家畜、すなわち馬、ろば、らくだ、牛、羊の上に臨むであろう。</span>
<span className="v" id="v4" data-v="4" data-xref="出エジプト記 8:22; 出エジプト記 10:23; マラキ書 3:18"> しかし、主はイスラエルの家畜と、エジプトの家畜を区別され、すべてイスラエルの人々に属するものには一頭も死ぬものがないであろう」と』」。</span>
<span className="v" id="v5" data-v="5" data-xref="出エジプト記 8:23; 出エジプト記 10:4; エレミヤ書 28:16–17"> 主は、また、時を定めて仰せられた、「あす、主はこのことを国に行うであろう」。</span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 78:48; 出エジプト記 9:25; 詩篇 78:50"> あくる日、主はこのことを行われたので、エジプトびとの家畜はみな死んだ。しかし、イスラエルの人々の家畜は一頭も死ななかった。</span>
<span className="v" id="v7" data-v="7" data-xref="出エジプト記 7:14; 出エジプト記 8:32; イザヤ書 48:4"> パロは人をつかわして見させたが、イスラエルの家畜は一頭も死んでいなかった。それでもパロの心はかたくなで、民を去らせなかった。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="出エジプト記 8:16"> 主はモーセとアロンに言われた、「あなたがたは、かまどのすすを両手いっぱい取り、それをモーセはパロの目の前で天にむかって、まき散らしなさい。</span>
<span className="v" id="v9" data-v="9" data-xref="ヨハネの黙示録 16:2; 申命記 28:27; ヨブ記 2:7"> それはエジプトの全国にわたって、細かいちりとなり、エジプト全国で人と獣に付いて、うみの出るはれものとなるであろう」。</span>
<span className="v" id="v10" data-v="10" data-xref="申命記 28:27"> そこで彼らは、かまどのすすを取ってパロの前に立ち、モーセは天にむかってこれをまき散らしたので、人と獣に付いて、うみの出るはれものとなった。</span>
<span className="v" id="v11" data-v="11" data-xref="出エジプト記 7:11–12; 出エジプト記 8:18–19; ヨハネの黙示録 16:2"> 魔術師らは、はれもののためにモーセの前に立つことができなかった。はれものが魔術師らと、すべてのエジプトびとに生じたからである。</span>
<span className="v" id="v12" data-v="12" data-xref="出エジプト記 4:21; 出エジプト記 7:13–14; 詩篇 81:11–12"> しかし、主はパロの心をかたくなにされたので、彼は主がモーセに語られたように、彼らの言うことを聞かなかった。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="出エジプト記 8:20; 出エジプト記 7:15; 出エジプト記 9:1"> 主はまたモーセに言われた、「朝早く起き、パロの前に立って、彼に言いなさい、『ヘブルびとの神、主はこう仰せられる、「わたしの民を去らせて、わたしに仕えさせなさい。</span>
<span className="v" id="v14" data-v="14" data-xref="出エジプト記 8:10; レビ記 26:28; 歴代志上 17:20"> わたしは、こんどは、もろもろの災を、あなたと、あなたの家来と、あなたの民にくだし、わたしに並ぶものが全地にないことを知らせるであろう。</span>
<span className="v" id="v15" data-v="15" data-xref="出エジプト記 3:20; 出エジプト記 9:3; 出エジプト記 9:16"> わたしがもし、手をさし伸べ、疫病をもって、あなたと、あなたの民を打っていたならば、あなたは地から断ち滅ぼされていたであろう。</span>
<span className="v" id="v16" data-v="16" data-xref="ローマ人への手紙 9:17; 箴言 16:4; 詩篇 83:17–18"> しかし、わたしがあなたをながらえさせたのは、あなたにわたしの力を見させるため、そして、わたしの名が全地に宣べ伝えられるためにほかならない。</span>
<span className="v" id="v17" data-v="17" data-xref="イザヤ書 37:29; イザヤ書 10:15; イザヤ書 37:23–24"> それに、あなたはなお、わたしの民にむかって、おのれを高くし、彼らを去らせようとしない。</span>
<span className="v" id="v18" data-v="18" data-xref="列王紀上 20:6; 詩篇 83:15; 出エジプト記 9:22–25"> ゆえに、あすの今ごろ、わたしは恐ろしく大きな雹を降らせるであろう。それはエジプトの国が始まった日から今まで、かつてなかったほどのものである。</span>
<span className="v" id="v19" data-v="19" data-xref="ハバクク書 3:2"> それゆえ、いま、人をやって、あなたの家畜と、あなたが野にもっているすべてのものを、のがれさせなさい。人も獣も、すべて野にあって家に帰らないものは降る雹に打たれて死ぬであろう」と』」。</span>
<span className="v" id="v20" data-v="20" data-xref="箴言 13:13; 箴言 22:3; ヘブル人への手紙 11:7"> パロの家来のうち、主の言葉をおそれる者は、そのしもべと家畜を家にのがれさせたが、</span>
<span className="v" id="v21" data-v="21" data-xref="エゼキエル書 40:4; ヨブ記 34:14; 歴代志上 22:19"> 主の言葉を意にとめないものは、そのしもべと家畜を野に残しておいた。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="ヨハネの黙示録 16:21; 出エジプト記 7:19; 出エジプト記 8:5"> 主はモーセに言われた、「あなたの手を天にむかってさし伸べ、エジプトの全国にわたって、エジプトの地にいる人と獣と畑のすべての青物の上に雹を降らせなさい」。</span>
<span className="v" id="v23" data-v="23" data-xref="詩篇 18:13; ヨシュア記 10:11; イザヤ書 30:30"> モーセが天にむかってつえをさし伸べると、主は雷と雹をおくられ、火は地にむかって、はせ下った。こうして主は、雹をエジプトの地に降らされた。</span>
<span className="v" id="v24" data-v="24" data-xref="出エジプト記 9:23; マタイによる福音書 24:21; 出エジプト記 10:6"> そして雹が降り、雹の間に火がひらめき渡った。雹は恐ろしく大きく、エジプト全国には、国をなしてこのかた、かつてないものであった。</span>
<span className="v" id="v25" data-v="25" data-xref="詩篇 78:47; 詩篇 105:32–33"> 雹はエジプト全国にわたって、すべて畑にいる人と獣を打った。雹はまた畑のすべての青物を打ち、野のもろもろの木を折り砕いた。</span>
<span className="v" id="v26" data-v="26" data-xref="出エジプト記 11:7; 出エジプト記 9:4; 出エジプト記 10:23"> ただイスラエルの人々のいたゴセンの地には、雹が降らなかった。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="哀歌 1:18; 詩篇 129:4; 出エジプト記 10:16"> そこで、パロは人をつかわし、モーセとアロンを召して言った、「わたしはこんどは罪を犯した。主は正しく、わたしと、わたしの民は悪い。</span>
<span className="v" id="v28" data-v="28" data-xref="出エジプト記 8:8; 出エジプト記 10:17; 出エジプト記 8:28"> 主に祈願してください。この雷と雹はもうじゅうぶんです。わたしはあなたがたを去らせます。もはやとどまらなくてもよろしい」。</span>
<span className="v" id="v29" data-v="29" data-xref="コリント人への第一の手紙 10:26; 列王紀上 8:38; イザヤ書 1:15"> モーセは彼に言った、「わたしは町を出ると、すぐ、主にむかってわたしの手を伸べひろげます。すると雷はやみ、雹はもはや降らなくなり、あなたは、地が主のものであることを知られましょう。</span>
<span className="v" id="v30" data-v="30" data-xref="イザヤ書 26:10; 箴言 16:6; イザヤ書 63:17"> しかし、あなたとあなたの家来たちは、なお、神なる主を恐れないことを、わたしは知っています」。</span>
<span className="v" id="v31" data-v="31" data-xref="ルツ記 1:22; ルツ記 2:23; ハバクク書 3:17"> ――亜麻と大麦は打ち倒された。大麦は穂を出し、亜麻は花が咲いていたからである。</span>
<span className="v" id="v32" data-v="32" data-xref="出エジプト記 10:22"> 小麦とスペルタ麦はおくてであるため打ち倒されなかった。――</span>
<span className="v" id="v33" data-v="33" data-xref="出エジプト記 9:29; 出エジプト記 8:12; ヤコブの手紙 5:17–18"> モーセはパロのもとを去り、町を出て、主にむかって手を伸べひろげたので、雷と雹はやみ、雨は地に降らなくなった。</span>
<span className="v" id="v34" data-v="34" data-xref="出エジプト記 7:14; 歴代志下 36:13; 出エジプト記 4:21"> ところがパロは雨と雹と雷がやんだのを見て、またも罪を犯し、心をかたくなにした。彼も家来も、そうであった。</span>
<span className="v" id="v35" data-v="35" data-xref="出エジプト記 4:21"> すなわちパロは心をかたくなにし、主がモーセによって語られたように、イスラエルの人々を去らせなかった。</span>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出エジプト記 34:32; 出エジプト記 31:1–11; ローマ人への手紙 2:13"> モーセはイスラエルの人々の全会衆を集めて言った、「これは主が行えと命じられた言葉である。</span>
<span className="v" id="v2" data-v="2" data-xref="レビ記 23:3; ルカによる福音書 13:14–15; 出エジプト記 20:9–10"> 六日の間は仕事をしなさい。七日目はあなたがたの聖日で、主の全き休みの安息日であるから、この日に仕事をする者はだれでも殺されなければならない。</span>
<span className="v" id="v3" data-v="3" data-xref="出エジプト記 16:23; 民数記 15:32–36; 出エジプト記 12:16"> 安息日にはあなたがたのすまいのどこでも火をたいてはならない」。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="出エジプト記 25:1–2"> モーセはイスラエルの人々の全会衆に言った、「これは主が命じられたことである。</span>
<span className="v" id="v5" data-v="5" data-xref="コリント人への第二の手紙 9:7; 詩篇 110:3; 出エジプト記 25:2–7"> あなたがたの持ち物のうちから、主にささげる物を取りなさい。すべて、心から喜んでする者は、主にささげる物を持ってきなさい。すなわち金、銀、青銅。</span>
<span className="v" id="v6" data-v="6" data-xref="出エジプト記 26:7–14; 出エジプト記 26:31; 出エジプト記 28:15"> 青糸、紫糸、緋糸、亜麻糸、やぎの毛糸。</span>
<span className="v" id="v7" data-v="7"> あかね染めの雄羊の皮、じゅごんの皮、アカシヤ材、</span>
<span className="v" id="v8" data-v="8" data-xref="出エジプト記 27:20; 出エジプト記 25:1–40; 出エジプト記 30:23"> ともし油、注ぎ油と香ばしい薫香とのための香料、</span>
<span className="v" id="v9" data-v="9" data-xref="出エジプト記 39:6–14; 出エジプト記 28:9; 出エジプト記 25:5"> 縞めのう、エポデと胸当とにはめる宝石。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="出エジプト記 31:1–6; 出エジプト記 36:1–4"> すべてあなたがたのうち、心に知恵ある者はきて、主の命じられたものをみな造りなさい。</span>
<span className="v" id="v11" data-v="11" data-xref="出エジプト記 26:1–37; 出エジプト記 36:8–34; 出エジプト記 31:7–9"> すなわち幕屋、その天幕と、そのおおい、その鉤と、その枠、その横木、その柱と、その座、</span>
<span className="v" id="v12" data-v="12" data-xref="出エジプト記 25:10–22; 出エジプト記 26:31–33; 出エジプト記 37:1–9"> 箱と、そのさお、贖罪所、隔ての垂幕、</span>
<span className="v" id="v13" data-v="13" data-xref="出エジプト記 25:23–30; レビ記 24:5–6; 出エジプト記 37:10–16"> 机と、そのさお、およびそのもろもろの器、供えのパン、</span>
<span className="v" id="v14" data-v="14" data-xref="出エジプト記 25:31–39; マタイによる福音書 5:14–15; 出エジプト記 37:17–24"> また、ともしびのための燭台と、その器、ともしび皿と、ともし油、</span>
<span className="v" id="v15" data-v="15" data-xref="出エジプト記 30:1–10; 出エジプト記 30:22–38; 出エジプト記 37:25–28"> 香の祭壇と、そのさお、注ぎ油、香ばしい薫香、幕屋の入口のとばり、</span>
<span className="v" id="v16" data-v="16" data-xref="出エジプト記 27:1–8; 出エジプト記 30:18–21; 出エジプト記 38:1–8"> 燔祭の祭壇およびその青銅の網、そのさおと、そのもろもろの器、洗盤と、その台、</span>
<span className="v" id="v17" data-v="17" data-xref="サムエル記下 7:2; 出エジプト記 38:9–20; 出エジプト記 27:9–19"> 庭のあげばり、その柱とその座、庭の門のとばり、</span>
<span className="v" id="v18" data-v="18" data-xref="出エジプト記 27:19"> 幕屋の釘、庭の釘およびそのひも、</span>
<span className="v" id="v19" data-v="19" data-xref="出エジプト記 31:10; 民数記 4:5–15; 出エジプト記 28:1–43"> 聖所における務のための編物の服、すなわち祭司の務をなすための祭司アロンの聖なる服およびその子たちの服」。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20"> イスラエルの人々の全会衆はモーセの前を去り、</span>
<span className="v" id="v21" data-v="21" data-xref="出エジプト記 25:2; 出エジプト記 35:26; 歴代志上 29:14"> すべて心に感じた者、すべて心から喜んでする者は、会見の幕屋の作業と、そのもろもろの奉仕と、聖なる服とのために、主にささげる物を携えてきた。</span>
<span className="v" id="v22" data-v="22" data-xref="ネヘミヤ書 7:70–72; マタイによる福音書 2:11; エズラ記 2:68–69"> すなわち、すべて心から喜んでする男女は、鼻輪、耳輪、指輪、首飾り、およびすべての金の飾りを携えてきた。すべて金のささげ物を主にささげる者はそのようにした。</span>
<span className="v" id="v23" data-v="23" data-xref="歴代志上 29:8; 出エジプト記 25:2–7; 出エジプト記 35:6–10"> すべて青糸、紫糸、緋糸、亜麻糸、やぎの毛糸、あかね染めの雄羊の皮、じゅごんの皮を持っている者は、それを携えてきた。</span>
<span className="v" id="v24" data-v="24" data-xref="コリント人への第二の手紙 8:12"> すべて銀、青銅のささげ物をささげることのできる者は、それを主にささげる物として携えてきた。また、すべて組立ての工事に用いるアカシヤ材を持っている者は、それを携えてきた。</span>
<span className="v" id="v25" data-v="25" data-xref="ローマ人への手紙 16:12; ルカによる福音書 8:2–3; 箴言 14:1"> また、すべて心に知恵ある女たちは、その手をもって紡ぎ、その紡いだ青糸、紫糸、緋糸、亜麻糸を携えてきた。</span>
<span className="v" id="v26" data-v="26" data-xref="出エジプト記 35:21; 出エジプト記 36:8; 出エジプト記 35:29"> すべて知恵があって、心に感じた女たちは、やぎの毛を紡いだ。</span>
<span className="v" id="v27" data-v="27" data-xref="エズラ記 2:68; 歴代志上 29:6; 出エジプト記 35:9"> また、かしらたちは縞めのう、およびエポデと胸当にはめる宝石を携えてきた。</span>
<span className="v" id="v28" data-v="28" data-xref="出エジプト記 30:23–38; 出エジプト記 35:8"> また、ともしびと、注ぎ油と、香ばしい薫香のための香料と、油とを携えてきた。</span>
<span className="v" id="v29" data-v="29" data-xref="コリント人への第二の手紙 9:7; 出エジプト記 35:21–22; 出エジプト記 35:4"> このようにイスラエルの人々は自発のささげ物を主に携えてきた。すなわち主がモーセによって、なせと命じられたすべての工作のために、物を携えてこようと、心から喜んでする男女はみな、そのようにした。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="出エジプト記 31:1–6; ヤコブの手紙 1:17; コリント人への第一の手紙 12:11"> モーセはイスラエルの人々に言った、「見よ、主はユダの部族に属するホルの子なるウリの子ベザレルを名ざして召し、</span>
<span className="v" id="v31" data-v="31" data-xref="ヤコブの手紙 1:17; イザヤ書 11:2–5; イザヤ書 61:1–3"> 彼に神の霊を満たして、知恵と悟りと知識と諸種の工作に長ぜしめ、</span>
<span className="v" id="v32" data-v="32"> 工夫を凝らして金、銀、青銅の細工をさせ、</span>
<span className="v" id="v33" data-v="33"> また宝石を切りはめ、木を彫刻するなど、諸種の工作をさせ、</span>
<span className="v" id="v34" data-v="34" data-xref="出エジプト記 31:6; 歴代志下 2:14; エズラ記 7:27"> また人を教えうる力を、彼の心に授けられた。彼とダンの部族に属するアヒサマクの子アホリアブとが、それである。</span>
<span className="v" id="v35" data-v="35" data-xref="出エジプト記 35:31; 列王紀上 7:14; イザヤ書 28:26"> 主は彼らに知恵の心を満たして、諸種の工作をさせられた。すなわち彫刻、浮き織および青糸、紫糸、緋糸、亜麻糸の縫取り、また機織など諸種の工作をさせ、工夫を凝らして巧みなわざをさせられた。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出エジプト記 28:3; 出エジプト記 35:30–35; 出エジプト記 31:1–6"> ベザレルとアホリアブおよびすべて心に知恵ある者、すなわち主が知恵と悟りとを授けて、聖所の組立ての諸種の工事を、いかになすかを知らせられた者は、すべて主が命じられたようにしなければならない」。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="コロサイ人への手紙 4:17; ヘブル人への手紙 5:4; 出エジプト記 31:6"> そこで、モーセはベザレルとアホリアブおよびすべて心に知恵ある者、すなわち、その心に主が知恵を授けられた者、またきて、その工事をなそうと心に望むすべての者を召し寄せた。</span>
<span className="v" id="v3" data-v="3" data-xref="出エジプト記 35:29; 出エジプト記 35:27; 出エジプト記 35:5–21"> 彼らは聖所の組立ての工事をするために、イスラエルの人々が携えてきたもろもろのささげ物を、モーセから受け取ったが、民はなおも朝ごとに、自発のささげ物を彼のもとに携えてきた。</span>
<span className="v" id="v4" data-v="4" data-xref="コリント人への第一の手紙 3:10; ルカによる福音書 12:42; マタイによる福音書 24:45"> そこで聖所のもろもろの工事をする賢い人々はみな、おのおのしていた工事をやめて、</span>
<span className="v" id="v5" data-v="5" data-xref="歴代志下 31:6–10; コリント人への第二の手紙 8:2–3; 歴代志下 24:14"> モーセに言った「民があまりに多く携えて来るので、主がせよと命じられた組立ての工事には余ります」。</span>
<span className="v" id="v6" data-v="6"> モーセは命令を発し、宿営中にふれさせて言った、「男も女も、もはや聖所のために、ささげ物をするに及ばない」。それで民は携えて来ることをやめた。</span>
<span className="v" id="v7" data-v="7" data-xref="歴代志下 31:10"> 材料はすべての工事をするのにじゅうぶんで、かつ余るからである。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="列王紀上 6:23; 出エジプト記 26:1–37; エゼキエル書 1:5–28"> すべて工作をする者のうちの心に知恵ある者は、十枚の幕で幕屋を造った。すなわち亜麻の撚糸、青糸、紫糸、緋糸で造り、巧みなわざをもって、それにケルビムを織り出した。</span>
<span className="v" id="v9" data-v="9"> 幕の長さは、おのおの二十八キュビト、幕の幅は、おのおの四キュビトで、幕はみな同じ寸法である。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="コリント人への第一の手紙 12:27; 出エジプト記 26:3; 詩篇 122:3"> その幕五枚を互に連ね合わせ、また他の五枚の幕をも互に連ね合わせ、</span>
<span className="v" id="v11" data-v="11" data-xref="出エジプト記 26:4"> その一連の端にある幕の縁に青色の乳をつけ、他の一連の端にある幕の縁にも、そのようにした。</span>
<span className="v" id="v12" data-v="12" data-xref="出エジプト記 26:5; 出エジプト記 26:10"> その一枚の幕に乳五十をつけ、他の一連の幕の端にも、乳五十をつけた。その乳を互に相向かわせた。</span>
<span className="v" id="v13" data-v="13" data-xref="ペテロの第一の手紙 2:4–5; エペソ人への手紙 2:20–22; コリント人への第一の手紙 12:20"> そして金の輪五十を作り、その輪で、幕を互に連ね合わせたので、一つの幕屋になった。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="出エジプト記 26:7–13"> また、やぎの毛糸で幕を作り、幕屋をおおう天幕にした。すなわち幕十一枚を作った。</span>
<span className="v" id="v15" data-v="15"> おのおのの幕の長さは三十キュビト、おのおのの幕の幅は四キュビトで、その十一枚の幕は同じ寸法である。</span>
<span className="v" id="v16" data-v="16"> そして、その幕五枚を一つに連ね合わせ、また、その幕六枚を一つに連ね合わせ、</span>
<span className="v" id="v17" data-v="17"> その一連の端にある幕の縁に、乳五十をつけ、他の一連の幕の縁にも、乳五十をつけた。</span>
<span className="v" id="v18" data-v="18"> そして、青銅の輪五十を作り、その天幕を連ね合わせて一つにした。</span>
<span className="v" id="v19" data-v="19" data-xref="出エジプト記 26:14"> また、あかね染めの雄羊の皮で、天幕のおおいと、じゅごんの皮で、その上にかけるおおいとを作った。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="出エジプト記 25:5; 民数記 25:1; 出エジプト記 40:18–19"> また幕屋のためにアカシヤ材をもって、立枠を造った。</span>
<span className="v" id="v21" data-v="21"> 枠の長さは十キュビト、枠の幅は、おのおの一キュビト半とし、</span>
<span className="v" id="v22" data-v="22"> 枠ごとに二つの柄を造って、かれとこれとをくい合わせ、幕屋のすべての枠にこのようにした。</span>
<span className="v" id="v23" data-v="23"> 幕屋のために枠を造った。すなわち南側のために枠二十を造った。</span>
<span className="v" id="v24" data-v="24"> その二十の枠の下に銀の座四十を造って、この枠の下に、その二つの柄のために二つの座を置き、かの枠の下にも、その二つの柄のために二つの座を置いた。</span>
<span className="v" id="v25" data-v="25"> また幕屋の他の側、すなわち北側のためにも枠二十を造った。</span>
<span className="v" id="v26" data-v="26"> その銀の座四十を造って、この枠の下にも二つの座を置き、かの枠の下にも二つの座を置いた。</span>
<span className="v" id="v27" data-v="27" data-xref="出エジプト記 26:22; 出エジプト記 26:27"> また幕屋のうしろ、西側のために枠六つを造り、</span>
<span className="v" id="v28" data-v="28"> 幕屋のうしろの二つのすみのために枠二つを造った。</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行伝 4:32; エペソ人への手紙 3:18–19; コリント人への第一の手紙 1:10"> これらは、下で重なり合い、同じくその頂でも第一の環まで重なり合うようにし、その二つとも二つのすみのために、そのように造った。</span>
<span className="v" id="v30" data-v="30" data-xref="出エジプト記 26:25"> こうして、その枠は八つ、その銀の座は十六、おのおのの枠の下に、二つずつ座があった。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="出エジプト記 26:26–29; 出エジプト記 25:28; 出エジプト記 30:5"> またアカシヤ材の横木を造った。すなわち幕屋のこの側の枠のために五つ、</span>
<span className="v" id="v32" data-v="32" data-xref="出エジプト記 26:26"> また幕屋のかの側の枠のために横木五つ、幕屋のうしろの西側の枠のために横木五つを造った。</span>
<span className="v" id="v33" data-v="33"> 枠のまん中にある中央の横木は、端から端まで通るようにした。</span>
<span className="v" id="v34" data-v="34"> そして、その枠を金でおおい、また横木を通すその環を金で造り、またその横木を金でおおった。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="マタイによる福音書 27:51; ヘブル人への手紙 10:20; 出エジプト記 40:21"> また青糸、紫糸、緋糸、亜麻の撚糸で、垂幕を作り、巧みなわざをもって、それにケルビムを織り出した。</span>
<span className="v" id="v36" data-v="36" data-xref="エレミヤ書 1:18"> また、これがためにアカシヤ材の柱四本を作り、金でこれをおおい、その鉤を金にし、その柱のために銀の座四つを鋳た。</span>
<span className="v" id="v37" data-v="37" data-xref="出エジプト記 26:36–37; 出エジプト記 40:28"> また幕屋の入口のために青糸、紫糸、緋糸、亜麻の撚糸で、色とりどりに織ったとばりを作った。</span>
<span className="v" id="v38" data-v="38" data-xref="出エジプト記 27:10"> その柱五本と、その鉤とを造り、その柱の頭と桁とを金でおおった。ただし、その五つの座は青銅であった。</span>
</div>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出エジプト記 16:1; 出エジプト記 12:6; レビ記 23:16–18"> イスラエルの人々は、エジプトの地を出て後三月目のその日に、シナイの荒野にはいった。</span>
<span className="v" id="v2" data-v="2" data-xref="出エジプト記 3:1; 出エジプト記 17:1; 出エジプト記 3:12"> すなわち彼らはレピデムを出立してシナイの荒野に入り、荒野に宿営した。イスラエルはその所で山の前に宿営した。</span>
<span className="v" id="v3" data-v="3" data-xref="出エジプト記 3:4; 使徒行伝 7:38; 出エジプト記 20:21"> さて、モーセが神のもとに登ると、主は山から彼を呼んで言われた、「このように、ヤコブの家に言い、イスラエルの人々に告げなさい、</span>
<span className="v" id="v4" data-v="4" data-xref="申命記 32:11–12; イザヤ書 63:9; イザヤ書 40:31"> 『あなたがたは、わたしがエジプトびとにした事と、あなたがたを鷲の翼に載せてわたしの所にこさせたことを見た。</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 14:2; 申命記 7:6; 申命記 26:18"> それで、もしあなたがたが、まことにわたしの声に聞き従い、わたしの契約を守るならば、あなたがたはすべての民にまさって、わたしの宝となるであろう。全地はわたしの所有だからである。</span>
<span className="v" id="v6" data-v="6" data-xref="ヨハネの黙示録 5:10; ペテロの第一の手紙 2:9; ペテロの第一の手紙 2:5"> あなたがたはわたしに対して祭司の国となり、また聖なる民となるであろう』。これがあなたのイスラエルの人々に語るべき言葉である」。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="出エジプト記 4:29–30; 出エジプト記 3:16; コリント人への第一の手紙 15:1"> それでモーセは行って民の長老たちを呼び、主が命じられたこれらの言葉を、すべてその前に述べたので、</span>
<span className="v" id="v8" data-v="8" data-xref="出エジプト記 24:7; 出エジプト記 24:3; ヨシュア記 24:24"> 民はみな共に答えて言った、「われわれは主が言われたことを、みな行います」。モーセは民の言葉を主に告げた。</span>
<span className="v" id="v9" data-v="9" data-xref="申命記 4:36; 出エジプト記 19:16; 出エジプト記 24:15–16"> 主はモーセに言われた、「見よ、わたしは濃い雲のうちにあって、あなたに臨むであろう。それはわたしがあなたと語るのを民に聞かせて、彼らに長くあなたを信じさせるためである」。<br />モーセは民の言葉を主に告げた。</span>
<span className="v" id="v10" data-v="10" data-xref="ヘブル人への手紙 10:22; 創世記 35:2; レビ記 11:44–45"> 主はモーセに言われた、「あなたは民のところに行って、きょうとあす、彼らをきよめ、彼らにその衣服を洗わせ、</span>
<span className="v" id="v11" data-v="11" data-xref="出エジプト記 19:16; 出エジプト記 34:5; 申命記 33:2"> 三日目までに備えさせなさい。三日目に主が、すべての民の目の前で、シナイ山に下るからである。</span>
<span className="v" id="v12" data-v="12" data-xref="ヘブル人への手紙 12:20–21; ヨシュア記 3:4; 出エジプト記 19:21"> あなたは民のために、周囲に境を設けて言いなさい、『あなたがたは注意して、山に上らず、また、その境界に触れないようにしなさい。山に触れる者は必ず殺されるであろう。</span>
<span className="v" id="v13" data-v="13" data-xref="テサロニケ人への第一の手紙 4:16; ヘブル人への手紙 12:20; 出エジプト記 19:16"> 手をそれに触れてはならない。触れる者は必ず石で打ち殺されるか、射殺されるであろう。獣でも人でも生きることはできない』。ラッパが長く響いた時、彼らは山に登ることができる」と。</span>
<span className="v" id="v14" data-v="14" data-xref="出エジプト記 19:10"> そこでモーセは山から民のところに下り、民をきよめた。彼らはその衣服を洗った。</span>
<span className="v" id="v15" data-v="15" data-xref="コリント人への第一の手紙 7:5; サムエル記上 21:4–5; 出エジプト記 19:11"> モーセは民に言った、「三日目までに備えをしなさい。女に近づいてはならない」。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="ヘブル人への手紙 12:18–19; 詩篇 18:11–14; ヘブル人への手紙 12:21"> 三日目の朝となって、かみなりと、いなずまと厚い雲とが、山の上にあり、ラッパの音が、はなはだ高く響いたので、宿営におる民はみな震えた。</span>
<span className="v" id="v17" data-v="17" data-xref="申命記 4:10; 申命記 5:5"> モーセが民を神に会わせるために、宿営から導き出したので、彼らは山のふもとに立った。</span>
<span className="v" id="v18" data-v="18" data-xref="士師記 5:5; 出エジプト記 3:2; 詩篇 144:5"> シナイ山は全山煙った。主が火のなかにあって、その上に下られたからである。その煙は、かまどの煙のように立ち上り、全山はげしく震えた。</span>
<span className="v" id="v19" data-v="19" data-xref="詩篇 81:7; 出エジプト記 19:16; ネヘミヤ書 9:13"> ラッパの音が、いよいよ高くなったとき、モーセは語り、神は、かみなりをもって、彼に答えられた。</span>
<span className="v" id="v20" data-v="20" data-xref="ネヘミヤ書 9:13; 出エジプト記 34:2; 出エジプト記 19:11"> 主はシナイ山の頂に下られた。そして主がモーセを山の頂に召されたので、モーセは登った。</span>
<span className="v" id="v21" data-v="21" data-xref="サムエル記上 6:19; 出エジプト記 3:5; ヘブル人への手紙 12:28–29"> 主はモーセに言われた、「下って行って民を戒めなさい。民が押し破って、主のところにきて、見ようとし、多くのものが死ぬことのないようにするためである。</span>
<span className="v" id="v22" data-v="22" data-xref="出エジプト記 24:5; 使徒行伝 5:10; 歴代志上 13:9–11"> 主に近づく祭司たちにもまた、その身をきよめさせなさい。主が彼らを打つことのないようにするためである」。</span>
<span className="v" id="v23" data-v="23" data-xref="出エジプト記 19:12; ヨシュア記 3:4–5"> モーセは主に言った、「民はシナイ山に登ることはできないでしょう。あなたがわたしたちを戒めて『山のまわりに境を設け、それをきよめよ』と言われたからです」。</span>
<span className="v" id="v24" data-v="24" data-xref="ヘブル人への手紙 4:16; ヘブル人への手紙 12:18–25; ヘブル人への手紙 12:29"> 主は彼に言われた、「行け、下れ。そしてあなたはアロンと共に登ってきなさい。ただし、祭司たちと民とが、押し破って主のところに登ることのないようにしなさい。主が彼らを打つことのないようにするためである」。</span>
<span className="v" id="v25" data-v="25"> モーセは民の所に下って行って彼らに告げた。</span>

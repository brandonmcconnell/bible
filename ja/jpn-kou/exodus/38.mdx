<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出エジプト記 27:1–8; エゼキエル書 43:13–17; 出エジプト記 40:6"> またアカシヤ材で燔祭の祭壇を造った。長さ五キュビト、幅五キュビトの四角で、高さは三キュビトである。</span>
<span className="v" id="v2" data-v="2" data-xref="出エジプト記 27:2; ヨブ記 6:12"> その四すみの上に、その一部とし、それの角を造り、青銅で祭壇をおおった。</span>
<span className="v" id="v3" data-v="3" data-xref="出エジプト記 27:3; サムエル記上 2:13"> また祭壇のもろもろの器、すなわち、つぼ、十能、鉢、肉叉、火皿を造った。そのすべての器を青銅で造った。</span>
<span className="v" id="v4" data-v="4"> また祭壇のために、青銅の網細工の格子を造り、これを祭壇の出張りの下に取りつけて、祭壇の高さの半ばに達するようにした。</span>
<span className="v" id="v5" data-v="5" data-xref="出エジプト記 27:4"> また青銅の格子の四すみのために、環四つを鋳て、さおを通す所とした。</span>
<span className="v" id="v6" data-v="6" data-xref="申命記 10:3; 出エジプト記 25:6"> アカシヤ材で、そのさおを造り、青銅でこれをおおい、</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行伝 9:15; コリント人への第一の手紙 2:2; コリント人への第一の手紙 1:24"> そのさおを祭壇の両側にある環に通して、それをかつぐようにした。祭壇は板をもって、空洞に造った。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="サムエル記上 2:22; ルカによる福音書 2:37; 出エジプト記 40:7"> また洗盤と、その台を青銅で造った。すなわち会見の幕屋の入口で務をなす女たちの鏡をもって造った。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="出エジプト記 27:9–19; 詩篇 89:7; 列王紀上 6:36"> また庭を造った。その南側のために百キュビトの亜麻の撚糸の庭のあげばりを設けた。</span>
<span className="v" id="v10" data-v="10"> その柱は二十、その柱の二十の座は青銅で、その柱の鉤と桁は銀とした。</span>
<span className="v" id="v11" data-v="11"> また北側のためにも百キュビトのあげばりを設けた。その柱二十、その柱の二十の座は青銅で、その柱の鉤と桁は銀とした。</span>
<span className="v" id="v12" data-v="12"> また西側のために、五十キュビトのあげばりを設けた。その柱は十、その座も十で、その柱の鉤と桁は銀とした。</span>
<span className="v" id="v13" data-v="13"> また東側のためにも、五十キュビトのあげばりを設けた。</span>
<span className="v" id="v14" data-v="14" data-xref="出エジプト記 27:14"> その一方に十五キュビトのあげばりを設けた。その柱は三つ、その座も三つ。</span>
<span className="v" id="v15" data-v="15"> また他の一方にも、同じようにした。すなわち庭の門のこなたかなたともに、十五キュビトのあげばりを設けた。その柱は三つ、その座も三つ。</span>
<span className="v" id="v16" data-v="16"> 庭の周囲のあげばりはみな亜麻の撚糸である。</span>
<span className="v" id="v17" data-v="17"> 柱の座は青銅、柱の鉤と桁とは銀、柱の頭のおおいも銀である。庭の柱はみな銀の桁で連ねた。</span>
<span className="v" id="v18" data-v="18" data-xref="歴代志下 3:14"> 庭の門のとばりは青糸、紫糸、緋糸、亜麻の撚糸で、色とりどりに織ったものであった。長さは二十キュビト、幅なる高さは五キュビトで、庭のあげばりと等しかった。</span>
<span className="v" id="v19" data-v="19"> その柱は四つ、その座も四つで、ともに青銅。その鉤は銀、柱の頭のおおいと桁は銀である。</span>
<span className="v" id="v20" data-v="20" data-xref="歴代志下 3:9; 出エジプト記 27:19; エペソ人への手紙 2:21–22"> ただし、幕屋および、その周囲の庭の釘はみな青銅であった。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="使徒行伝 7:44; 民数記 9:15; 歴代志下 24:6"> 幕屋、すなわちあかしの幕屋に用いた物の総計は次のとおりである。すなわちモーセの命に従い、祭司アロンの子イタマルがレビびとを用いて量ったものである。</span>
<span className="v" id="v22" data-v="22" data-xref="出エジプト記 35:30–3; 出エジプト記 31:1–5; 詩篇 119:6"> ユダの部族に属するホルの子なるウリの子ベザレルは、主がモーセに命じられた事をことごとくした。</span>
<span className="v" id="v23" data-v="23" data-xref="出エジプト記 35:34; 出エジプト記 31:6"> ダンの部族に属するアヒサマクの子アホリアブは彼と共にあって彫刻、浮き織をなし、また青糸、紫糸、緋糸、亜麻糸で、縫取りをする者であった。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="民数記 18:16; 民数記 3:47; レビ記 27:25"> 聖所のもろもろの工作に用いたすべての金、すなわち、ささげ物なる金は聖所のシケルで、二十九タラント七百三十シケルであった。</span>
<span className="v" id="v25" data-v="25" data-xref="出エジプト記 30:12"> 会衆のうちの数えられた者のささげた銀は聖所のシケルで、百タラント千七百七十五シケルであった。</span>
<span className="v" id="v26" data-v="26" data-xref="民数記 1:46; 出エジプト記 30:13; 出エジプト記 12:37"> これはひとり当り一ベカ、すなわち聖所のシケルの半シケルであって、すべて二十歳以上で数えられた者が六十万三千五百五十人であったからである。</span>
<span className="v" id="v27" data-v="27" data-xref="出エジプト記 26:19; 出エジプト記 26:25; 出エジプト記 26:21"> 聖所の座と垂幕の座とを鋳るために用いた銀は百タラントであった。すなわち百座につき百タラント、一座につき一タラントである。</span>
<span className="v" id="v28" data-v="28" data-xref="出エジプト記 27:17"> また千七百七十五シケルで柱の鉤を造り、また柱の頭をおおい、柱のために桁を造った。</span>
<span className="v" id="v29" data-v="29"> ささげ物なる青銅は七十タラント二千四百シケルであった。</span>
<span className="v" id="v30" data-v="30" data-xref="出エジプト記 26:37; 出エジプト記 27:17; 出エジプト記 27:10"> これを用いて会見の幕屋の入口の座、青銅の祭壇と、それにつく青銅の格子、および祭壇のもろもろの器を造った。</span>
<span className="v" id="v31" data-v="31"> また庭の周囲の座、庭の門の座、および幕屋のもろもろの釘と、庭の周囲のもろもろの釘を造った。</span>
</div>

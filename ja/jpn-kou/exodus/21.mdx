<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命記 4:14; 申命記 6:20; 出エジプト記 24:3–4"> これはあなたが彼らの前に示すべきおきてである。</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 15:12–15; 出エジプト記 12:44; 申命記 15:18"> あなたがヘブルびとである奴隷を買う時は、六年のあいだ仕えさせ、七年目には無償で自由の身として去らせなければならない。</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 15:12–14"> 彼がもし独身できたならば、独身で去らなければならない。もし妻を持っていたならば、その妻は彼と共に去らなければならない。</span>
<span className="v" id="v4" data-v="4"> もしその主人が彼に妻を与えて、彼に男の子また女の子を産んだならば、妻とその子供は主人のものとなり、彼は独身で去らなければならない。</span>
<span className="v" id="v5" data-v="5" data-xref="コリント人への第二の手紙 5:14–15; 申命記 15:16–17; イザヤ書 26:13"> 奴隷がもし『わたしは、わたしの主人と、わたしの妻と子供を愛します。わたしは自由の身となって去ることを好みません』と明言するならば、</span>
<span className="v" id="v6" data-v="6" data-xref="申命記 15:17; レビ記 25:40; 申命記 19:17–18"> その主人は彼を神のもとに連れて行き、戸あるいは柱のところに連れて行って、主人は、きりで彼の耳を刺し通さなければならない。そうすれば彼はいつまでもこれに仕えるであろう。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="ネヘミヤ書 5:5; 出エジプト記 21:2–3"> もし人がその娘を女奴隷として売るならば、その娘は男奴隷が去るように去ってはならない。</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 28:8; 申命記 20:7; マラキ書 2:11–15"> 彼女がもし彼女を自分のものと定めた主人の気にいらない時は、その主人は彼女が、あがなわれることを、これに許さなければならない。彼はこれを欺いたのであるから、これを他国の民に売る権利はない。</span>
<span className="v" id="v9" data-v="9"> 彼がもし彼女を自分の子のものと定めるならば、これを娘のように扱わなければならない。</span>
<span className="v" id="v10" data-v="10" data-xref="コリント人への第一の手紙 7:1–6"> 彼が、たとい、ほかに女をめとることがあっても、前の女に食物と衣服を与えることと、その夫婦の道とを絶えさせてはならない。</span>
<span className="v" id="v11" data-v="11"> 彼がもしこの三つを行わないならば、彼女は金を償わずに去ることができる。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="創世記 9:6; マタイによる福音書 26:52; レビ記 24:17"> 人を撃って死なせた者は、必ず殺されなければならない。</span>
<span className="v" id="v13" data-v="13" data-xref="ヨシュア記 20:2–9; サムエル記上 24:18; 申命記 4:41–43"> しかし、人がたくむことをしないのに、神が彼の手に人をわたされることのある時は、わたしはあなたのために一つの所を定めよう。彼はその所へのがれることができる。</span>
<span className="v" id="v14" data-v="14" data-xref="列王紀上 2:28–34; ヘブル人への手紙 10:26; 民数記 15:30–31"> しかし人がもし、ことさらにその隣人を欺いて殺す時は、その者をわたしの祭壇からでも、捕えて行って殺さなければならない。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="申命記 21:18–21; 箴言 30:17; テモテヘの第一の手紙 1:9"> 自分の父または母を撃つ者は、必ず殺されなければならない。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="申命記 24:7; テモテヘの第一の手紙 1:10; 出エジプト記 22:4"> 人をかどわかした者は、これを売っていても、なお彼の手にあっても、必ず殺されなければならない。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="箴言 20:20; マルコによる福音書 7:10–11; 申命記 27:16"> 自分の父または母をのろう者は、必ず殺されなければならない。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="出エジプト記 21:20; 申命記 25:11; サムエル記下 14:6"> 人が互に争い、そのひとりが石または、こぶしで相手を撃った時、これが死なないで床につき、</span>
<span className="v" id="v19" data-v="19" data-xref="サムエル記下 3:29; ゼカリヤ書 8:4"> 再び起きあがって、つえにすがり、外を歩くようになるならば、これを撃った者は、ゆるされるであろう。ただその仕事を休んだ損失を償い、かつこれにじゅうぶん治療させなければならない。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="箴言 29:19; 申命記 19:21; 民数記 35:19"> もし人がつえをもって、自分の男奴隷または女奴隷を撃ち、その手の下に死ぬならば、必ず罰せられなければならない。</span>
<span className="v" id="v21" data-v="21" data-xref="レビ記 25:44–46"> しかし、彼がもし一日か、ふつか生き延びるならば、その人は罰せられない。奴隷は彼の財産だからである。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="申命記 22:18–19; 出エジプト記 21:30; 申命記 16:18"> もし人が互に争って、身ごもった女を撃ち、これに流産させるならば、ほかの害がなくとも、彼は必ずその女の夫の求める罰金を課せられ、裁判人の定めるとおりに支払わなければならない。</span>
<span className="v" id="v23" data-v="23" data-xref="申命記 19:21; 民数記 35:31; レビ記 24:19"> しかし、ほかの害がある時は、命には命、</span>
<span className="v" id="v24" data-v="24" data-xref="申命記 19:21; マタイによる福音書 5:38–40; マタイによる福音書 7:2"> 目には目、歯には歯、手には手、足には足、</span>
<span className="v" id="v25" data-v="25"> 焼き傷には焼き傷、傷には傷、打ち傷には打ち傷をもって償わなければならない。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="出エジプト記 21:20; ヨブ記 31:13–15; 詩篇 72:12–14"> もし人が自分の男奴隷の片目、または女奴隷の片目を撃ち、これをつぶすならば、その目のためにこれを自由の身として去らせなければならない。</span>
<span className="v" id="v27" data-v="27"> また、もしその男奴隷の一本の歯、またはその女奴隷の一本の歯を撃ち落すならば、その歯のためにこれを自由の身として去らせなければならない。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="出エジプト記 21:32; レビ記 20:15–16; 創世記 9:5–6"> もし牛が男または女を突いて殺すならば、その牛は必ず石で撃ち殺されなければならない。その肉は食べてはならない。しかし、その牛の持ち主は罪がない。</span>
<span className="v" id="v29" data-v="29" data-xref="申命記 21:1–9"> 牛がもし以前から突く癖があって、その持ち主が注意されても、これを守りおかなかったために、男または女を殺したならば、その牛は石で撃ち殺され、その持ち主もまた殺されなければならない。</span>
<span className="v" id="v30" data-v="30" data-xref="出エジプト記 21:22; 出エジプト記 30:12; 民数記 35:31–33"> 彼がもし、あがないの金を課せられたならば、すべて課せられたほどのものを、命の償いに支払わなければならない。</span>
<span className="v" id="v31" data-v="31"> 男の子を突いても、女の子を突いても、この定めに従って処置されなければならない。</span>
<span className="v" id="v32" data-v="32" data-xref="マタイによる福音書 26:15; ゼカリヤ書 11:12–13; マタイによる福音書 27:3–9"> 牛がもし男奴隷または女奴隷を突くならば、その主人に銀三十シケルを支払わなければならない。またその牛は石で撃ち殺されなければならない。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="箴言 28:10; エレミヤ書 18:20; 伝道の書 10:8"> もし人が穴をあけたままに置き、あるいは穴を掘ってこれにおおいをしないために、牛または、ろばがこれに落ち込むことがあれば、</span>
<span className="v" id="v34" data-v="34" data-xref="出エジプト記 22:6; 出エジプト記 21:29–30; 出エジプト記 22:14"> 穴の持ち主はこれを償い、金をその持ち主に支払わなければならない。しかし、その死んだ獣は彼のものとなるであろう。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35"> ある人の牛が、もし他人の牛を突いて殺すならば、彼らはその生きている牛を売って、その価を分け、またその死んだものをも分けなければならない。</span>
<span className="v" id="v36" data-v="36"> あるいはその牛が以前から突く癖のあることが知られているのに、その持ち主がこれを守りおかなかったならば、その人は必ずその牛のために牛をもって償わなければならない。しかし、その死んだ獣は彼のものとなるであろう。</span>
</div>
</div>

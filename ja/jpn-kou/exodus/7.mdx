<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出エジプト記 4:15–16; 詩篇 82:6; ヨハネによる福音書 10:35–36"> 主はモーセに言われた、「見よ、わたしはあなたをパロに対して神のごときものとする。あなたの兄弟アロンはあなたの預言者となるであろう。</span>
<span className="v" id="v2" data-v="2" data-xref="出エジプト記 4:15; 出エジプト記 6:29; 申命記 4:2"> あなたはわたしが命じることを、ことごとく彼に告げなければならない。そしてあなたの兄弟アロンはパロに告げて、イスラエルの人々をその国から去らせるようにさせなければならない。</span>
<span className="v" id="v3" data-v="3" data-xref="出エジプト記 4:21; 出エジプト記 11:9; 詩篇 105:27–36"> しかし、わたしはパロの心をかたくなにするので、わたしのしるしと不思議をエジプトの国に多く行っても、</span>
<span className="v" id="v4" data-v="4" data-xref="出エジプト記 11:9; 出エジプト記 6:6; 出エジプト記 12:51"> パロはあなたがたの言うことを聞かないであろう。それでわたしは手をエジプトの上に加え、大いなるさばきをくだして、わたしの軍団、わたしの民イスラエルの人々を、エジプトの国から導き出すであろう。</span>
<span className="v" id="v5" data-v="5" data-xref="出エジプト記 14:18; 出エジプト記 7:17; 出エジプト記 8:22"> わたしが手をエジプトの上にさし伸べて、イスラエルの人々を彼らのうちから導き出す時、エジプトびとはわたしが主であることを知るようになるであろう」。</span>
<span className="v" id="v6" data-v="6" data-xref="出エジプト記 7:2; 創世記 6:22; 出エジプト記 7:10"> モーセとアロンはそのように行った。すなわち主が彼らに命じられたように行った。</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 34:7; 使徒行伝 7:30; 申命記 31:2"> 彼らがパロと語った時、モーセは八十歳、アロンは八十三歳であった。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8"> 主はモーセとアロンに言われた、</span>
<span className="v" id="v9" data-v="9" data-xref="出エジプト記 4:2; ヨハネによる福音書 2:18; イザヤ書 7:11"> 「パロがあなたがたに、『不思議をおこなって証拠を示せ』と言う時、あなたはアロンに言いなさい、『あなたのつえを取って、パロの前に投げなさい』と。するとそれはへびになるであろう」。</span>
<span className="v" id="v10" data-v="10" data-xref="出エジプト記 4:3; ルカによる福音書 10:19; アモス書 9:3"> それで、モーセとアロンはパロのところに行き、主の命じられたとおりにおこなった。すなわちアロンはそのつえを、パロとその家来たちの前に投げると、それはへびになった。</span>
<span className="v" id="v11" data-v="11" data-xref="出エジプト記 7:22; テモテヘの第二の手紙 3:8; 出エジプト記 8:18"> そこでパロもまた知者と魔法使を召し寄せた。これらのエジプトの魔術師らもまた、その秘術をもって同じように行った。</span>
<span className="v" id="v12" data-v="12" data-xref="ヨハネの第一の手紙 4:4; 出エジプト記 9:11; 出エジプト記 8:18–19"> すなわち彼らは、おのおのそのつえを投げたが、それらはへびになった。しかし、アロンのつえは彼らのつえを、のみつくした。</span>
<span className="v" id="v13" data-v="13" data-xref="出エジプト記 4:21; 出エジプト記 8:15; ゼカリヤ書 7:11–12"> けれども、パロの心はかたくなになって、主の言われたように、彼らの言うことを聞かなかった。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="出エジプト記 10:20; 出エジプト記 8:15; 出エジプト記 10:1"> 主はモーセに言われた、「パロの心はかたくなで、彼は民を去らせることを拒んでいる。</span>
<span className="v" id="v15" data-v="15" data-xref="出エジプト記 8:20; 出エジプト記 2:5; 出エジプト記 7:10"> あなたは、あすの朝、パロのところに行きなさい。見よ、彼は水のところに出ている。あなたは、へびに変ったあのつえを手に執り、ナイル川の岸に立って彼に会い、</span>
<span className="v" id="v16" data-v="16" data-xref="出エジプト記 3:18; 出エジプト記 9:1; 出エジプト記 9:13"> そして彼に言いなさい、『ヘブルびとの神、主がわたしをあなたにつかわして言われます、「わたしの民を去らせ、荒野で、わたしに仕えるようにさせよ」と。しかし今もなお、あなたが聞きいれようとされないので、</span>
<span className="v" id="v17" data-v="17" data-xref="出エジプト記 4:9; 出エジプト記 5:2; 出エジプト記 7:5"> 主はこう仰せられます、「これによってわたしが主であることを、あなたは知るでしょう。見よ、わたしが手にあるつえでナイル川の水を打つと、それは血に変るであろう。</span>
<span className="v" id="v18" data-v="18" data-xref="出エジプト記 7:24; 出エジプト記 7:21; 民数記 11:20"> そして川の魚は死に、川は臭くなり、エジプトびとは川の水を飲むことをいとうであろう」』と」。</span>
<span className="v" id="v19" data-v="19" data-xref="出エジプト記 14:21; 出エジプト記 10:12; 出エジプト記 8:5–6"> 主はまたモーセに言われた、「あなたはアロンに言いなさい、『あなたのつえを執って、手をエジプトの水の上、川の上、流れの上、池の上、またそのすべての水たまりの上にさし伸べて、それを血にならせなさい。エジプト全国にわたって、木の器、石の器にも、血があるようになるでしょう』と」。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="詩篇 78:44; 詩篇 105:29; 出エジプト記 7:17–18"> モーセとアロンは主の命じられたようにおこなった。すなわち、彼はパロとその家来たちの目の前で、つえをあげてナイル川の水を打つと、川の水は、ことごとく血に変った。</span>
<span className="v" id="v21" data-v="21" data-xref="出エジプト記 7:18; ヨハネの黙示録 8:9"> それで川の魚は死に、川は臭くなり、エジプトびとは川の水を飲むことができなくなった。そしてエジプト全国にわたって血があった。</span>
<span className="v" id="v22" data-v="22" data-xref="出エジプト記 7:11; テモテヘの第二の手紙 3:8; エレミヤ書 27:18"> エジプトの魔術師らも秘術をもって同じようにおこなった。しかし、主の言われたように、パロの心はかたくなになり、彼らの言うことを聞かなかった。</span>
<span className="v" id="v23" data-v="23" data-xref="エレミヤ書 36:24; エゼキエル書 40:4; マラキ書 2:2"> パロは身をめぐらして家に入り、またこのことをも心に留めなかった。</span>
<span className="v" id="v24" data-v="24"> すべてのエジプトびとはナイル川の水が飲めなかったので、飲む水を得ようと、川のまわりを掘った。</span>
<span className="v" id="v25" data-v="25" data-xref="出エジプト記 10:23; 出エジプト記 8:9–10; サムエル記下 24:13"> 主がナイル川を打たれてのち七日を経た。</span>
</div>

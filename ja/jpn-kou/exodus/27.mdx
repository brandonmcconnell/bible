<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出エジプト記 38:1–7; 出エジプト記 20:24–26; 出エジプト記 40:10"> あなたはまたアカシヤ材で祭壇を造らなければならない。長さ五キュビト、幅五キュビトの四角で、高さは三キュビトである。</span>
<span className="v" id="v2" data-v="2" data-xref="詩篇 118:27; 出エジプト記 29:12; レビ記 4:7"> その四すみの上にその一部としてそれの角を造り、青銅で祭壇をおおわなければならない。</span>
<span className="v" id="v3" data-v="3" data-xref="列王紀上 7:45; 民数記 4:14; 歴代志上 28:17"> また灰を取るつぼ、十能、鉢、肉叉、火皿を造り、その器はみな青銅で造らなければならない。</span>
<span className="v" id="v4" data-v="4" data-xref="出エジプト記 35:16; 出エジプト記 25:12; 出エジプト記 38:4–5"> また祭壇のために青銅の網細工の格子を造り、その四すみで、網の上に青銅の環を四つ取り付けなければならない。</span>
<span className="v" id="v5" data-v="5" data-xref="出エジプト記 38:4"> その網を祭壇の出張りの下に取り付け、これを祭壇の高さの半ばに達するようにしなければならない。</span>
<span className="v" id="v6" data-v="6" data-xref="出エジプト記 35:13–15; 民数記 4:44; 出エジプト記 30:4"> また祭壇のために、さおを造らなければならない。すなわちアカシヤ材で、さおを造り、青銅で、これをおおわなければならない。</span>
<span className="v" id="v7" data-v="7" data-xref="出エジプト記 25:28; 出エジプト記 30:4; 民数記 4:13–14"> そのさおを環に通し、さおを祭壇の両側にして、これをかつがなければならない。</span>
<span className="v" id="v8" data-v="8" data-xref="出エジプト記 25:40; 出エジプト記 25:9; ヘブル人への手紙 8:5"> 祭壇は板で空洞に造り、山で示されたように、これを造らなければならない。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="出エジプト記 38:9–20; エゼキエル書 40:32; エゼキエル書 42:3"> あなたはまた幕屋の庭を造り、両側では庭のために長さ百キュビトの亜麻の撚糸のあげばりを設け、その一方に当てなければならない。</span>
<span className="v" id="v10" data-v="10" data-xref="出エジプト記 26:19–21; エレミヤ書 52:21; 出エジプト記 36:38"> その柱は二十、その柱の二十の座は青銅にし、その柱の鉤と桁とは銀にしなければならない。</span>
<span className="v" id="v11" data-v="11"> また同じく北側のために、長さ百キュビトのあげばりを設けなければならない。その柱は二十、その柱の二十の座は青銅にし、その柱の鉤と桁とは銀にしなければならない。</span>
<span className="v" id="v12" data-v="12"> また庭の西側の幅のために五十キュビトのあげばりを設けなければならない。その柱は十、その座も十。</span>
<span className="v" id="v13" data-v="13"> また東側でも庭の幅を五十キュビトにしなければならない。</span>
<span className="v" id="v14" data-v="14" data-xref="出エジプト記 27:9; 出エジプト記 26:36"> そしてその一方に十五キュビトのあげばりを設けなければならない。その柱は三つ、その座も三つ。</span>
<span className="v" id="v15" data-v="15"> また他の一方にも十五キュビトのあげばりを設けなければならない。その柱は三つ、その座も三つ。</span>
<span className="v" id="v16" data-v="16" data-xref="出エジプト記 26:36; 士師記 5:30; 出エジプト記 28:39"> 庭の門のために青糸、紫糸、緋糸、亜麻の撚糸で、色とりどりに織った長さ二十キュビトのとばりを設けなければならない。その柱は四つ、その座も四つ。</span>
<span className="v" id="v17" data-v="17"> 庭の周囲の柱はみな銀の桁でつなぎ、その鉤は銀、その座は青銅にしなければならない。</span>
<span className="v" id="v18" data-v="18"> 庭の長さは百キュビト、その幅は五十キュビト、その高さは五キュビトで、亜麻の撚糸の布を掛けめぐらし、その座を青銅にしなければならない。</span>
<span className="v" id="v19" data-v="19" data-xref="出エジプト記 35:18; イザヤ書 22:23–25; 民数記 4:32"> すべて幕屋に用いるもろもろの器、およびそのすべての釘、また庭のすべての釘は青銅で造らなければならない。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="レビ記 24:1–4; ゼカリヤ書 4:11–14; 詩篇 23:5"> あなたはまたイスラエルの人々に命じて、オリブをつぶして採った純粋の油を、ともし火のために持ってこさせ、絶えずともし火をともさなければならない。</span>
<span className="v" id="v21" data-v="21" data-xref="民数記 19:21; 民数記 18:23; サムエル記上 3:3"> アロンとその子たちとは、会見の幕屋の中のあかしの箱の前にある垂幕の外で、夕から朝まで主の前に、そのともし火を整えなければならない。これはイスラエルの人々の守るべき世々変らざる定めでなければならない。</span>
</div>

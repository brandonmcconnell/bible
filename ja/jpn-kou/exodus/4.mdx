<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出エジプト記 3:18; 出エジプト記 2:14; エレミヤ書 1:6"> モーセは言った、「しかし、彼らはわたしを信ぜず、またわたしの声に聞き従わないで言うでしょう、『主はあなたに現れなかった』と」。</span>
<span className="v" id="v2" data-v="2" data-xref="出エジプト記 4:17; 出エジプト記 4:20; イザヤ書 11:4"> 主は彼に言われた、「あなたの手にあるそれは何か」。彼は言った、「つえです」。</span>
<span className="v" id="v3" data-v="3" data-xref="出エジプト記 7:10–15; アモス書 5:19; 出エジプト記 4:17"> また言われた、「それを地に投げなさい」。彼がそれを地に投げると、へびになったので、モーセはその前から身を避けた。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行伝 28:3–6; 創世記 22:1–2; 詩篇 91:13"> 主はモーセに言われた、「あなたの手を伸ばして、その尾を取りなさい。――そこで手を伸ばしてそれを取ると、手のなかでつえとなった。――</span>
<span className="v" id="v5" data-v="5" data-xref="出エジプト記 19:9; 創世記 48:3; 出エジプト記 3:15"> これは、彼らの先祖たちの神、アブラハムの神、イサクの神、ヤコブの神である主が、あなたに現れたのを、彼らに信じさせるためである」。</span>
<span className="v" id="v6" data-v="6" data-xref="列王紀下 5:27; 民数記 12:10"> 主はまた彼に言われた、「あなたの手をふところに入れなさい」。彼が手をふところに入れ、それを出すと、手は、らい病にかかって、雪のように白くなっていた。</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀下 5:14; 申命記 32:39; マタイによる福音書 8:3"> 主は言われた、「手をふところにもどしなさい」。彼は手をふところにもどし、それをふところから出して見ると、回復して、もとの肉のようになっていた。</span>
<span className="v" id="v8" data-v="8" data-xref="イザヤ書 28:10; 申命記 32:39; 出エジプト記 4:30–31"> 主は言われた、「彼らがもしあなたを信ぜず、また初めのしるしを認めないならば、後のしるしは信じるであろう。</span>
<span className="v" id="v9" data-v="9" data-xref="出エジプト記 7:19–25; 出エジプト記 1:22; マタイによる福音書 7:2"> 彼らがもしこの二つのしるしをも信ぜず、あなたの声に聞き従わないならば、あなたはナイル川の水を取って、かわいた地に注ぎなさい。あなたがナイル川から取った水は、かわいた地で血となるであろう」。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="エレミヤ書 1:6; 出エジプト記 6:12; 使徒行伝 7:22"> モーセは主に言った、「ああ主よ、わたしは以前にも、またあなたが、しもべに語られてから後も、言葉の人ではありません。わたしは口も重く、舌も重いのです」。</span>
<span className="v" id="v11" data-v="11" data-xref="アモス書 3:6; 詩篇 146:8; エゼキエル書 3:26–27"> 主は彼に言われた、「だれが人に口を授けたのか。おし、耳しい、目あき、目しいにだれがするのか。主なるわたしではないか。</span>
<span className="v" id="v12" data-v="12" data-xref="エレミヤ書 1:9; ルカによる福音書 12:11–12; マタイによる福音書 10:19–20"> それゆえ行きなさい。わたしはあなたの口と共にあって、あなたの言うべきことを教えるであろう」。</span>
<span className="v" id="v13" data-v="13" data-xref="ヨナ書 1:3; 出エジプト記 4:1; マタイによる福音書 13:41"> モーセは言った、「ああ、主よ、どうか、ほかの適当な人をおつかわしください」。</span>
<span className="v" id="v14" data-v="14" data-xref="マルコによる福音書 14:13–15; 出エジプト記 4:27; 歴代志上 21:7"> そこで、主はモーセにむかって怒りを発して言われた、「あなたの兄弟レビびとアロンがいるではないか。わたしは彼が言葉にすぐれているのを知っている。見よ、彼はあなたに会おうとして出てきている。彼はあなたを見て心に喜ぶであろう。</span>
<span className="v" id="v15" data-v="15" data-xref="イザヤ書 51:16; 申命記 18:18; ルカによる福音書 21:15"> あなたは彼に語って言葉をその口に授けなさい。わたしはあなたの口と共にあり、彼の口と共にあって、あなたがたのなすべきことを教え、</span>
<span className="v" id="v16" data-v="16" data-xref="出エジプト記 7:1–2; 詩篇 82:6; ヨハネによる福音書 10:34–35"> 彼はあなたに代って民に語るであろう。彼はあなたの口となり、あなたは彼のために、神に代るであろう。</span>
<span className="v" id="v17" data-v="17" data-xref="出エジプト記 4:2; コリント人への第一の手紙 1:27; 出エジプト記 7:9–20"> あなたはそのつえを手に執り、それをもって、しるしを行いなさい」。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="出エジプト記 3:1; サムエル記上 1:17; テモテヘの第一の手紙 6:1"> モーセは妻の父エテロのところに帰って彼に言った、「どうかわたしを、エジプトにいる身うちの者のところに帰らせ、彼らがまだ生きながらえているか、どうかを見させてください」。エテロはモーセに言った、「安んじて行きなさい」。</span>
<span className="v" id="v19" data-v="19" data-xref="マタイによる福音書 2:20; 出エジプト記 2:23; 出エジプト記 2:15"> 主はミデヤンでモーセに言われた、「エジプトに帰って行きなさい。あなたの命を求めた人々はみな死んだ」。</span>
<span className="v" id="v20" data-v="20" data-xref="出エジプト記 17:9; 民数記 20:8–9; 出エジプト記 18:3–4"> そこでモーセは妻と子供たちをとり、ろばに乗せて、エジプトの地に帰った。モーセは手に神のつえを執った。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="ローマ人への手紙 9:18; イザヤ書 63:17; 出エジプト記 14:8"> 主はモーセに言われた、「あなたがエジプトに帰ったとき、わたしがあなたの手に授けた不思議を、みなパロの前で行いなさい。しかし、わたしが彼の心をかたくなにするので、彼は民を去らせないであろう。</span>
<span className="v" id="v22" data-v="22" data-xref="ホセア書 11:1; ローマ人への手紙 9:4; エレミヤ書 31:9"> あなたはパロに言いなさい、『主はこう仰せられる。イスラエルはわたしの子、わたしの長子である。</span>
<span className="v" id="v23" data-v="23" data-xref="出エジプト記 11:5; 出エジプト記 12:29; 詩篇 135:8"> わたしはあなたに言う。わたしの子を去らせて、わたしに仕えさせなさい。もし彼を去らせるのを拒むならば、わたしはあなたの子、あなたの長子を殺すであろう』と」。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="創世記 17:14; 民数記 22:22–23; ホセア書 13:8"> さてモーセが途中で宿っている時、主は彼に会って彼を殺そうとされた。</span>
<span className="v" id="v25" data-v="25" data-xref="ヨシュア記 5:2–3; 創世記 17:14; サムエル記下 16:7"> その時チッポラは火打ち石の小刀を取って、その男の子の前の皮を切り、それをモーセの足につけて言った、「あなたはまことに、わたしにとって血の花婿です」。</span>
<span className="v" id="v26" data-v="26"> そこで、主はモーセをゆるされた。この時「血の花婿です」とチッポラが言ったのは割礼のゆえである。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="出エジプト記 3:1; 出エジプト記 4:14–16; 列王紀上 19:8"> 主はアロンに言われた、「荒野に行ってモーセに会いなさい」。彼は行って神の山でモーセに会い、これに口づけした。</span>
<span className="v" id="v28" data-v="28" data-xref="出エジプト記 4:8–9; 出エジプト記 4:15–16; マタイによる福音書 21:29"> モーセは自分をつかわされた主のすべての言葉と、命じられたすべてのしるしをアロンに告げた。</span>
<span className="v" id="v29" data-v="29" data-xref="出エジプト記 3:16; 出エジプト記 24:11; 出エジプト記 24:1"> そこでモーセとアロンは行ってイスラエルの人々の長老たちをみな集めた。</span>
<span className="v" id="v30" data-v="30" data-xref="出エジプト記 4:16"> そしてアロンは主がモーセに語られた言葉を、ことごとく告げた。また彼は民の前でしるしを行ったので、</span>
<span className="v" id="v31" data-v="31" data-xref="出エジプト記 3:18; 出エジプト記 2:25; 詩篇 106:12–13"> 民は信じた。彼らは主がイスラエルの人々を顧み、その苦しみを見られたのを聞き、伏して礼拝した。</span>
</div>

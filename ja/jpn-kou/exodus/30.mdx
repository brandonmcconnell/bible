<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨハネの黙示録 8:3; 出エジプト記 37:25–28; 出エジプト記 40:5"> あなたはまた香をたく祭壇を造らなければならない。アカシヤ材でこれを造り、</span>
<span className="v" id="v2" data-v="2" data-xref="出エジプト記 27:2"> 長さ一キュビト、幅一キュビトの四角にし、高さ二キュビトで、これにその一部として角をつけなければならない。</span>
<span className="v" id="v3" data-v="3" data-xref="出エジプト記 25:11; 出エジプト記 25:24"> その頂、その四つの側面、およびその角を純金でおおい、その周囲に金の飾り縁を造り、</span>
<span className="v" id="v4" data-v="4" data-xref="出エジプト記 25:27; 出エジプト記 26:29; 出エジプト記 27:7"> また、その両側に、飾り縁の下に金の環二つをこれのために造らなければならない。すなわち、その二つの側にこれを造らなければならない。これはそれをかつぐさおを通すところである。</span>
<span className="v" id="v5" data-v="5" data-xref="出エジプト記 25:13; 出エジプト記 25:27"> そのさおはアカシヤ材で造り、金でおおわなければならない。</span>
<span className="v" id="v6" data-v="6" data-xref="出エジプト記 25:21–22; 出エジプト記 30:36; レビ記 16:13"> あなたはそれを、あかしの箱の前にある垂幕の前に置いて、わたしがあなたと会うあかしの箱の上にある贖罪所に向かわせなければならない。</span>
<span className="v" id="v7" data-v="7" data-xref="サムエル記上 2:28; 歴代志上 23:13; 出エジプト記 27:20–21"> アロンはその上で香ばしい薫香をたかなければならない。朝ごとに、ともしびを整える時、これをたかなければならない。</span>
<span className="v" id="v8" data-v="8" data-xref="ヘブル人への手紙 9:24; テサロニケ人への第一の手紙 5:17; ヘブル人への手紙 7:25"> アロンはまた夕べにともしびをともす時にも、これをたかなければならない。これは主の前にあなたがたが代々に絶やすことなく、ささぐべき薫香である。</span>
<span className="v" id="v9" data-v="9" data-xref="レビ記 10:1"> あなたがたはその上で異なる香をささげてはならない。燔祭をも素祭をもその上でささげてはならない。また、その上に灌祭を注いではならない。</span>
<span className="v" id="v10" data-v="10" data-xref="レビ記 16:18; ヘブル人への手紙 9:22–23; レビ記 16:29–30"> アロンは年に一度その角に血をつけてあがないをしなければならない。すなわち、あがないの罪祭の血をもって代々にわたり、年に一度これがために、あがないをしなければならない。これは主に最も聖なるものである」。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11"> 主はモーセに言われた、</span>
<span className="v" id="v12" data-v="12" data-xref="民数記 31:50; 歴代志上 27:24; 出エジプト記 38:25–26"> 「あなたがイスラエルの人々の数の総計をとるに当り、おのおのその数えられる時、その命のあがないを主にささげなければならない。これは数えられる時、彼らのうちに災の起らないためである。</span>
<span className="v" id="v13" data-v="13" data-xref="レビ記 27:25; 民数記 3:47; エゼキエル書 45:12"> すべて数に入る者は聖所のシケルで、半シケルを払わなければならない。一シケルは二十ゲラであって、おのおの半シケルを主にささげ物としなければならない。</span>
<span className="v" id="v14" data-v="14" data-xref="民数記 1:20; 民数記 1:18; 民数記 1:3"> すべて数に入る二十歳以上の者は、主にささげ物をしなければならない。</span>
<span className="v" id="v15" data-v="15" data-xref="民数記 31:50; レビ記 17:11; 出エジプト記 30:12"> あなたがたの命をあがなうために、主にささげ物をする時、富める者も半シケルより多く出してはならず、貧しい者もそれより少なく出してはならない。</span>
<span className="v" id="v16" data-v="16" data-xref="ネヘミヤ書 10:32–33; 民数記 16:40; 出エジプト記 38:25–31"> あなたはイスラエルの人々から、あがないの銀を取って、これを会見の幕屋の用に当てなければならない。これは主の前にイスラエルの人々のため記念となって、あなたがたの命をあがなうであろう」。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17"> 主はモーセに言われた、</span>
<span className="v" id="v18" data-v="18" data-xref="出エジプト記 40:7; 出エジプト記 38:8; 列王紀上 7:23"> 「あなたはまた洗うために洗盤と、その台を青銅で造り、それを会見の幕屋と祭壇との間に置いて、その中に水を入れ、</span>
<span className="v" id="v19" data-v="19" data-xref="イザヤ書 52:11; 出エジプト記 40:31–32; 詩篇 26:6"> アロンとその子たちは、それで手と足とを洗わなければならない。</span>
<span className="v" id="v20" data-v="20" data-xref="レビ記 10:1–3; ヘブル人への手紙 12:28–29; 歴代志上 13:10"> 彼らは会見の幕屋にはいる時、水で洗って、死なないようにしなければならない。また祭壇に近づいて、その務をなし、火祭を主にささげる時にも、そうしなければならない。</span>
<span className="v" id="v21" data-v="21" data-xref="出エジプト記 28:43; 出エジプト記 27:21"> すなわち、その手、その足を洗って、死なないようにしなければならない。これは彼とその子孫の代々にわたる永久の定めでなければならない」。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22"> 主はまたモーセに言われた、</span>
<span className="v" id="v23" data-v="23" data-xref="エゼキエル書 27:19; 雅歌 4:14; エゼキエル書 27:22"> 「あなたはまた最も良い香料を取りなさい。すなわち液体の没薬五百シケル、香ばしい肉桂をその半ば、すなわち二百五十シケル、におい菖蒲二百五十シケル、</span>
<span className="v" id="v24" data-v="24" data-xref="詩篇 45:8; 出エジプト記 29:40; 民数記 3:47"> 桂枝五百シケルを聖所のシケルで取り、また、オリブの油一ヒンを取りなさい。</span>
<span className="v" id="v25" data-v="25" data-xref="出エジプト記 37:29; 歴代志上 9:30; 出エジプト記 40:9"> あなたはこれを聖なる注ぎ油、すなわち香油を造るわざにしたがい、まぜ合わせて、におい油に造らなければならない。これは聖なる注ぎ油である。</span>
<span className="v" id="v26" data-v="26" data-xref="民数記 7:1; ヨハネの第一の手紙 2:20; イザヤ書 61:1"> あなたはこの油を会見の幕屋と、あかしの箱とに注ぎ、</span>
<span className="v" id="v27" data-v="27"> 机と、そのもろもろの器、燭台と、そのもろもろの器、香の祭壇、</span>
<span className="v" id="v28" data-v="28"> 燔祭の祭壇と、そのもろもろの器、洗盤と、その台とに油を注ぎ、</span>
<span className="v" id="v29" data-v="29" data-xref="マタイによる福音書 23:19; 出エジプト記 29:37; レビ記 6:18"> これらをきよめて最も聖なる物としなければならない。すべてこれに触れる者は聖となるであろう。</span>
<span className="v" id="v30" data-v="30" data-xref="レビ記 8:12; 出エジプト記 28:3; レビ記 8:30"> あなたはアロンとその子たちに油を注いで、彼らを聖別し、祭司としてわたしに仕えさせなければならない。</span>
<span className="v" id="v31" data-v="31" data-xref="出エジプト記 37:29; レビ記 21:10; 詩篇 89:20"> そしてあなたはイスラエルの人々に言わなければならない、『これはあなたがたの代々にわたる、わたしの聖なる注ぎ油であって、</span>
<span className="v" id="v32" data-v="32" data-xref="出エジプト記 30:25; 出エジプト記 30:37–38; レビ記 21:10"> 常の人の身にこれを注いではならない。またこの割合をもって、これと等しいものを造ってはならない。これは聖なるものであるから、あなたがたにとっても聖なる物でなければならない。</span>
<span className="v" id="v33" data-v="33" data-xref="出エジプト記 30:38; 創世記 17:14; 出エジプト記 12:15"> すべてこれと等しい物を造る者、あるいはこれを祭司以外の人につける者は、民のうちから断たれるであろう』」。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="出エジプト記 37:29; 出エジプト記 25:6; 出エジプト記 30:23"> 主はまた、モーセに言われた、「あなたは香料、すなわち蘇合香、シケレテ香、楓子香、純粋の乳香の香料を取りなさい。おのおの同じ量でなければならない。</span>
<span className="v" id="v35" data-v="35" data-xref="レビ記 2:13; 出エジプト記 30:25; ヨハネによる福音書 12:3"> あなたはこれをもって香、すなわち香料をつくるわざにしたがって薫香を造り、塩を加え、純にして聖なる物としなさい。</span>
<span className="v" id="v36" data-v="36" data-xref="出エジプト記 25:22; 出エジプト記 30:6; 出エジプト記 16:34"> また、その幾ぶんを細かに砕き、わたしがあなたと会う会見の幕屋にある、あかしの箱の前にこれを供えなければならない。これはあなたがたに最も聖なるものである。</span>
<span className="v" id="v37" data-v="37" data-xref="レビ記 2:3; 出エジプト記 29:37; 出エジプト記 30:32–33"> あなたが造る香の同じ割合をもって、それを自分のために造ってはならない。これはあなたにとって主に聖なるものでなければならない。</span>
<span className="v" id="v38" data-v="38" data-xref="出エジプト記 30:33"> すべてこれと等しいものを造って、これをかぐ者は民のうちから断たれるであろう」。</span>
</div>

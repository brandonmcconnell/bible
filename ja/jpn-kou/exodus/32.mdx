<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行伝 7:40; 申命記 9:9; 出エジプト記 24:18"> 民はモーセが山を下ることのおそいのを見て、アロンのもとに集まって彼に言った、「さあ、わたしたちに先立って行く神を、わたしたちのために造ってください。わたしたちをエジプトの国から導きのぼった人、あのモーセはどうなったのかわからないからです」。</span>
<span className="v" id="v2" data-v="2" data-xref="士師記 8:24–27; 出エジプト記 12:35–36; エゼキエル書 16:17"> アロンは彼らに言った、「あなたがたの妻、むすこ、娘らの金の耳輪をはずしてわたしに持ってきなさい」。</span>
<span className="v" id="v3" data-v="3" data-xref="イザヤ書 46:6; イザヤ書 40:19–20; エレミヤ書 10:9"> そこで民は皆その金の耳輪をはずしてアロンのもとに持ってきた。</span>
<span className="v" id="v4" data-v="4" data-xref="ネヘミヤ書 9:18; 申命記 9:16; 列王紀上 12:28"> アロンがこれを彼らの手から受け取り、工具で型を造り、鋳て子牛としたので、彼らは言った、「イスラエルよ、これはあなたをエジプトの国から導きのぼったあなたの神である」。</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀下 10:20; レビ記 23:2; レビ記 23:37"> アロンはこれを見て、その前に祭壇を築いた。そしてアロンは布告して言った、「あすは主の祭である」。</span>
<span className="v" id="v6" data-v="6" data-xref="コリント人への第一の手紙 10:7; 民数記 25:2; 使徒行伝 7:41–42"> そこで人々はあくる朝早く起きて燔祭をささげ、酬恩祭を供えた。民は座して食い飲みし、立って戯れた。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="出エジプト記 32:11; ホセア書 9:9; 士師記 2:19"> 主はモーセに言われた、「急いで下りなさい。あなたがエジプトの国から導きのぼったあなたの民は悪いことをした。</span>
<span className="v" id="v8" data-v="8" data-xref="列王紀上 12:28; 出エジプト記 20:23; 出エジプト記 20:3–4"> 彼らは早くもわたしが命じた道を離れ、自分のために鋳物の子牛を造り、これを拝み、これに犠牲をささげて、『イスラエルよ、これはあなたをエジプトの国から導きのぼったあなたの神である』と言っている」。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行伝 7:51; 申命記 9:13; イザヤ書 48:4"> 主はまたモーセに言われた、「わたしはこの民を見た。これはかたくなな民である。</span>
<span className="v" id="v10" data-v="10" data-xref="申命記 9:14; 民数記 14:12; 申命記 9:19"> それで、わたしをとめるな。わたしの怒りは彼らにむかって燃え、彼らを滅ぼしつくすであろう。しかし、わたしはあなたを大いなる国民とするであろう」。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="申命記 9:18–20; 申命記 9:26–29; 詩篇 106:23"> モーセはその神、主をなだめて言った、「主よ、大いなる力と強き手をもって、エジプトの国から導き出されたあなたの民にむかって、なぜあなたの怒りが燃えるのでしょうか。</span>
<span className="v" id="v12" data-v="12" data-xref="民数記 14:13–16; 申命記 9:28; ヨシュア記 7:9"> どうしてエジプトびとに『彼は悪意をもって彼らを導き出し、彼らを山地で殺し、地の面から断ち滅ぼすのだ』と言わせてよいでしょうか。どうかあなたの激しい怒りをやめ、あなたの民に下そうとされるこの災を思い直し、</span>
<span className="v" id="v13" data-v="13" data-xref="ヘブル人への手紙 6:13; 創世記 12:7; 創世記 22:16"> あなたのしもべアブラハム、イサク、イスラエルに、あなたが御自身をさして誓い、『わたしは天の星のように、あなたがたの子孫を増し、わたしが約束したこの地を皆あなたがたの子孫に与えて、長くこれを所有させるであろう』と彼らに仰せられたことを覚えてください」。</span>
<span className="v" id="v14" data-v="14" data-xref="ヨナ書 3:10; 詩篇 106:45; エレミヤ書 26:13"> それで、主はその民に下すと言われた災について思い直された。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="申命記 9:15; 出エジプト記 40:20; 申命記 5:22"> モーセは身を転じて山を下った。彼の手には、かの二枚のあかしの板があった。板はその両面に文字があった。すなわち、この面にも、かの面にも文字があった。</span>
<span className="v" id="v16" data-v="16" data-xref="出エジプト記 31:18; ヘブル人への手紙 8:10; 申命記 10:1"> その板は神の作、その文字は神の文字であって、板に彫ったものである。</span>
<span className="v" id="v17" data-v="17" data-xref="出エジプト記 24:13; 出エジプト記 17:9; ヨシュア記 6:20"> ヨシュアは民の呼ばわる声を聞いて、モーセに言った、「宿営の中に戦いの声がします」。</span>
<span className="v" id="v18" data-v="18" data-xref="出エジプト記 15:1–18; ダニエル書 5:4; ダニエル書 5:23"> しかし、モーセは言った、「勝どきの声でなく、敗北の叫び声でもない。わたしの聞くのは歌の声である」。</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 9:16–17; エレミヤ書 31:32; 哀歌 5:15"> モーセが宿営に近づくと、子牛と踊りとを見たので、彼は怒りに燃え、手からかの板を投げうち、これを山のふもとで砕いた。</span>
<span className="v" id="v20" data-v="20" data-xref="申命記 9:21; 列王紀下 23:6; 列王紀下 23:15"> また彼らが造った子牛を取って火に焼き、こなごなに砕き、これを水の上にまいて、イスラエルの人々に飲ませた。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="創世記 20:9; ヨシュア記 7:19–26; 列王紀上 21:22"> モーセはアロンに言った、「この民があなたに何をしたので、あなたは彼らに大いなる罪を犯させたのですか」。</span>
<span className="v" id="v22" data-v="22" data-xref="申命記 9:24; 出エジプト記 15:24; 出エジプト記 16:20"> アロンは言った、「わが主よ、激しく怒らないでください。この民の悪いのは、あなたがごぞんじです。</span>
<span className="v" id="v23" data-v="23" data-xref="出エジプト記 32:1–4; 出エジプト記 32:8"> 彼らはわたしに言いました、『わたしたちに先立って行く神を、わたしたちのために造ってください。わたしたちをエジプトの国から導きのぼった人、あのモーセは、どうなったのかわからないからです』。</span>
<span className="v" id="v24" data-v="24" data-xref="出エジプト記 32:4; ルカによる福音書 10:29; ローマ人への手紙 3:10"> そこでわたしは『だれでも、金を持っている者は、それを取りはずしなさい』と彼らに言いました。彼らがそれをわたしに渡したので、わたしがこれを火に投げ入れると、この子牛が出てきたのです」。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="イザヤ書 47:3; ミカ書 1:11; ヨハネの黙示録 16:15"> モーセは民がほしいままにふるまったのを見た。アロンは彼らがほしいままにふるまうに任せ、敵の中に物笑いとなったからである。</span>
<span className="v" id="v26" data-v="26" data-xref="列王紀下 9:32; マタイによる福音書 12:30; サムエル記下 20:11"> モーセは宿営の門に立って言った、「すべて主につく者はわたしのもとにきなさい」。レビの子たちはみな彼のもとに集まった。</span>
<span className="v" id="v27" data-v="27" data-xref="民数記 25:5; ルカによる福音書 14:26; 申命記 33:8–9"> そこでモーセは彼らに言った、「イスラエルの神、主はこう言われる、『あなたがたは、おのおの腰につるぎを帯び、宿営の中を門から門へ行き巡って、おのおのその兄弟、その友、その隣人を殺せ』」。</span>
<span className="v" id="v28" data-v="28" data-xref="申命記 33:9; マラキ書 2:4–6; コリント人への第一の手紙 10:8"> レビの子たちはモーセの言葉どおりにしたので、その日、民のうち、おおよそ三千人が倒れた。</span>
<span className="v" id="v29" data-v="29" data-xref="民数記 25:11–13; マタイによる福音書 10:37; ゼカリヤ書 13:3"> そこで、モーセは言った、「あなたがたは、おのおのその子、その兄弟に逆らって、きょう、主に身をささげた。それで主は、きょう、あなたがたに祝福を与えられるであろう」。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="サムエル記上 12:20; 民数記 25:13; 列王紀下 17:21"> あくる日、モーセは民に言った、「あなたがたは大いなる罪を犯した。それで今、わたしは主のもとに上って行く。あなたがたの罪を償うことが、できるかも知れない」。</span>
<span className="v" id="v31" data-v="31" data-xref="出エジプト記 20:23; ダニエル書 9:11; ダニエル書 9:8"> モーセは主のもとに帰って、そして言った、「ああ、この民は大いなる罪を犯し、自分のために金の神を造りました。</span>
<span className="v" id="v32" data-v="32" data-xref="詩篇 69:28; ローマ人への手紙 9:3; ヨハネの黙示録 21:27"> 今もしあなたが、彼らの罪をゆるされますならば――。しかし、もしかなわなければ、どうぞあなたが書きしるされたふみから、わたしの名を消し去ってください」。</span>
<span className="v" id="v33" data-v="33" data-xref="申命記 29:20; エゼキエル書 18:4; ヨハネの黙示録 20:12"> 主はモーセに言われた、「すべてわたしに罪を犯した者は、これをわたしのふみから消し去るであろう。</span>
<span className="v" id="v34" data-v="34" data-xref="出エジプト記 23:20; 申命記 32:35; マタイによる福音書 23:35"> しかし、今あなたは行って、わたしがあなたに告げたところに民を導きなさい。見よ、わたしの使はあなたに先立って行くであろう。ただし刑罰の日に、わたしは彼らの罪を罰するであろう」。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="使徒行伝 7:41; 出エジプト記 32:25; サムエル記下 12:9–10"> そして主は民を撃たれた。彼らが子牛を造ったからである。それはアロンが造ったのである。</span>
</div>
</div>

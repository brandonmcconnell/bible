<div className="bp">
<span className="v" id="v1" data-v="1"> 主はエジプトの国で、モーセとアロンに告げて言われた、</span>
<span className="v" id="v2" data-v="2" data-xref="出エジプト記 13:4; 申命記 16:1; 出エジプト記 34:18"> 「この月をあなたがたの初めの月とし、これを年の正月としなさい。</span>
<span className="v" id="v3" data-v="3" data-xref="レビ記 1:2; コリント人への第一の手紙 5:7; ヨハネによる福音書 1:29"> あなたがたはイスラエルの全会衆に言いなさい、『この月の十日におのおの、その父の家ごとに小羊を取らなければならない。すなわち、一家族に小羊一頭を取らなければならない。</span>
<span className="v" id="v4" data-v="4"> もし家族が少なくて一頭の小羊を食べきれないときは、家のすぐ隣の人と共に、人数に従って一頭を取り、おのおの食べるところに応じて、小羊を見計らわなければならない。</span>
<span className="v" id="v5" data-v="5" data-xref="ペテロの第一の手紙 1:18–19; ヘブル人への手紙 9:13–14; マラキ書 1:14"> 小羊は傷のないもので、一歳の雄でなければならない。羊またはやぎのうちから、これを取らなければならない。</span>
<span className="v" id="v6" data-v="6" data-xref="レビ記 23:5; 歴代志下 30:15–18; 民数記 28:16"> そしてこの月の十四日まで、これを守って置き、イスラエルの会衆はみな、夕暮にこれをほふり、</span>
<span className="v" id="v7" data-v="7" data-xref="ヘブル人への手紙 11:28; 出エジプト記 12:22–23; ヘブル人への手紙 9:22"> その血を取り、小羊を食する家の入口の二つの柱と、かもいにそれを塗らなければならない。</span>
<span className="v" id="v8" data-v="8" data-xref="出エジプト記 34:25; 申命記 16:7; 出エジプト記 13:3"> そしてその夜、その肉を火に焼いて食べ、種入れぬパンと苦菜を添えて食べなければならない。</span>
<span className="v" id="v9" data-v="9" data-xref="出エジプト記 12:8; 申命記 16:7; 哀歌 1:13"> 生でも、水で煮ても、食べてはならない。火に焼いて、その頭を足と内臓と共に食べなければならない。</span>
<span className="v" id="v10" data-v="10" data-xref="出エジプト記 23:18; 出エジプト記 34:25; 出エジプト記 29:34"> 朝までそれを残しておいてはならない。朝まで残るものは火で焼きつくさなければならない。</span>
<span className="v" id="v11" data-v="11" data-xref="出エジプト記 12:27; エペソ人への手紙 6:15; コリント人への第一の手紙 5:7"> あなたがたは、こうして、それを食べなければならない。すなわち腰を引きからげ、足にくつをはき、手につえを取って、急いでそれを食べなければならない。これは主の過越である。</span>
<span className="v" id="v12" data-v="12" data-xref="民数記 33:4; 出エジプト記 12:23; 詩篇 82:6"> その夜わたしはエジプトの国を巡って、エジプトの国におる人と獣との、すべてのういごを打ち、またエジプトのすべての神々に審判を行うであろう。わたしは主である。</span>
<span className="v" id="v13" data-v="13" data-xref="ヘブル人への手紙 11:28; 出エジプト記 12:23; ヨハネの第一の手紙 1:7"> その血はあなたがたのおる家々で、あなたがたのために、しるしとなり、わたしはその血を見て、あなたがたの所を過ぎ越すであろう。わたしがエジプトの国を撃つ時、災が臨んで、あなたがたを滅ぼすことはないであろう。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="列王紀下 23:21; 出エジプト記 12:24; 出エジプト記 13:9–10"> この日はあなたがたに記念となり、あなたがたは主の祭としてこれを守り、代々、永久の定めとしてこれを守らなければならない。</span>
<span className="v" id="v15" data-v="15" data-xref="創世記 17:14; 申命記 16:3; 出エジプト記 23:15"> 七日の間あなたがたは種入れぬパンを食べなければならない。その初めの日に家からパン種を取り除かなければならない。第一日から第七日までに、種を入れたパンを食べる人はみなイスラエルから断たれるであろう。</span>
<span className="v" id="v16" data-v="16" data-xref="レビ記 23:7–8; 民数記 28:18; 出エジプト記 16:23"> かつ、あなたがたは第一日に聖会を、また第七日に聖会を開かなければならない。これらの日には、なんの仕事もしてはならない。ただ、おのおのの食べものだけは作ることができる。</span>
<span className="v" id="v17" data-v="17" data-xref="出エジプト記 7:5; 出エジプト記 13:3; 出エジプト記 12:41"> あなたがたは、種入れぬパンの祭を守らなければならない。ちょうど、この日、わたしがあなたがたの軍勢をエジプトの国から導き出したからである。それゆえ、あなたがたは代々、永久の定めとして、その日を守らなければならない。</span>
<span className="v" id="v18" data-v="18" data-xref="レビ記 23:5–8; 出エジプト記 12:15; 出エジプト記 12:1–2"> 正月に、その月の十四日の夕方に、あなたがたは種入れぬパンを食べ、その月の二十一日の夕方まで続けなければならない。</span>
<span className="v" id="v19" data-v="19" data-xref="出エジプト記 12:15; 出エジプト記 23:15; 申命記 16:3"> 七日の間、家にパン種を置いてはならない。種を入れたものを食べる者は、寄留の他国人であれ、国に生れた者であれ、すべて、イスラエルの会衆から断たれるであろう。</span>
<span className="v" id="v20" data-v="20"> あなたがたは種を入れたものは何も食べてはならない。すべてあなたがたのすまいにおいて種入れぬパンを食べなければならない』」。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="出エジプト記 12:3; ルカによる福音書 22:7–13; 歴代志下 35:5–6"> そこでモーセはイスラエルの長老をみな呼び寄せて言った、「あなたがたは急いで家族ごとに一つの小羊を取り、その過越の獣をほふらなければならない。</span>
<span className="v" id="v22" data-v="22" data-xref="ヘブル人への手紙 11:28; 民数記 19:18; 詩篇 51:7"> また一束のヒソプを取って鉢の血に浸し、鉢の血を、かもいと入口の二つの柱につけなければならない。朝まであなたがたは、ひとりも家の戸の外に出てはならない。</span>
<span className="v" id="v23" data-v="23" data-xref="ヨハネの黙示録 7:3; ヨハネの黙示録 9:4; ヘブル人への手紙 11:28"> 主が行き巡ってエジプトびとを撃たれるとき、かもいと入口の二つの柱にある血を見て、主はその入口を過ぎ越し、滅ぼす者が、あなたがたの家にはいって、撃つのを許されないであろう。</span>
<span className="v" id="v24" data-v="24" data-xref="出エジプト記 12:14; 創世記 17:8–10"> あなたがたはこの事を、あなたと子孫のための定めとして、永久に守らなければならない。</span>
<span className="v" id="v25" data-v="25" data-xref="出エジプト記 3:17; 出エジプト記 3:8; 申命記 12:8–9"> あなたがたは、主が約束されたように、あなたがたに賜る地に至るとき、この儀式を守らなければならない。</span>
<span className="v" id="v26" data-v="26" data-xref="出エジプト記 13:14–15; 申命記 32:7; 詩篇 145:4"> もし、あなたがたの子供たちが『この儀式はどんな意味ですか』と問うならば、</span>
<span className="v" id="v27" data-v="27" data-xref="出エジプト記 4:31; 出エジプト記 12:11; コリント人への第一の手紙 5:7"> あなたがたは言いなさい、『これは主の過越の犠牲である。エジプトびとを撃たれたとき、エジプトにいたイスラエルの人々の家を過ぎ越して、われわれの家を救われたのである』」。民はこのとき、伏して礼拝した。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="ヘブル人への手紙 11:28"> イスラエルの人々は行ってそのようにした。すなわち主がモーセとアロンに命じられたようにした。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="詩篇 78:51; 出エジプト記 4:23; 詩篇 105:36"> 夜中になって主はエジプトの国の、すべてのういご、すなわち位に座するパロのういごから、地下のひとやにおる捕虜のういごにいたるまで、また、すべての家畜のういごを撃たれた。</span>
<span className="v" id="v30" data-v="30" data-xref="出エジプト記 11:6; アモス書 5:17; 箴言 21:13"> それでパロとその家来およびエジプトびとはみな夜のうちに起きあがり、エジプトに大いなる叫びがあった。死人のない家がなかったからである。</span>
<span className="v" id="v31" data-v="31" data-xref="出エジプト記 6:1; 出エジプト記 10:9; 出エジプト記 3:19–20"> そこでパロは夜のうちにモーセとアロンを呼び寄せて言った、「あなたがたとイスラエルの人々は立って、わたしの民の中から出て行くがよい。そしてあなたがたの言うように、行って主に仕えなさい。</span>
<span className="v" id="v32" data-v="32" data-xref="出エジプト記 10:26; 創世記 27:34; 創世記 27:38"> あなたがたの言うように羊と牛とを取って行きなさい。また、わたしを祝福しなさい」。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="詩篇 105:38; 出エジプト記 11:1; 創世記 20:3"> こうしてエジプトびとは民をせき立てて、すみやかに国を去らせようとした。彼らは「われわれはみな死ぬ」と思ったからである。</span>
<span className="v" id="v34" data-v="34" data-xref="出エジプト記 8:3"> 民はまだパン種を入れない練り粉を、こばちのまま着物に包んで肩に負った。</span>
<span className="v" id="v35" data-v="35" data-xref="出エジプト記 3:21–22; 出エジプト記 11:2–3; 創世記 15:14"> そしてイスラエルの人々はモーセの言葉のようにして、エジプトびとから銀の飾り、金の飾り、また衣服を請い求めた。</span>
<span className="v" id="v36" data-v="36" data-xref="創世記 15:14; 使徒行伝 7:10; 出エジプト記 3:21–22"> 主は民にエジプトびとの情を得させ、彼らの請い求めたものを与えさせられた。こうして彼らはエジプトびとのものを奪い取った。</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="民数記 1:46; 出エジプト記 38:26; 民数記 33:3"> さて、イスラエルの人々はラメセスを出立してスコテに向かった。女と子供を除いて徒歩の男子は約六十万人であった。</span>
<span className="v" id="v38" data-v="38" data-xref="民数記 11:4; ゼカリヤ書 8:23"> また多くの入り混じった群衆および羊、牛など非常に多くの家畜も彼らと共に上った。</span>
<span className="v" id="v39" data-v="39" data-xref="出エジプト記 11:1; 出エジプト記 6:1; 出エジプト記 12:31–33"> そして彼らはエジプトから携えて出た練り粉をもって、種入れぬパンの菓子を焼いた。まだパン種を入れていなかったからである。それは彼らがエジプトから追い出されて滞ることができず、また、何の食料をも整えていなかったからである。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="創世記 15:13; 使徒行伝 7:6; 使徒行伝 13:17"> イスラエルの人々がエジプトに住んでいた間は、四百三十年であった。</span>
<span className="v" id="v41" data-v="41" data-xref="ハバクク書 2:3; ヨハネによる福音書 7:8; 使徒行伝 1:7"> 四百三十年の終りとなって、ちょうどその日に、主の全軍はエジプトの国を出た。</span>
<span className="v" id="v42" data-v="42" data-xref="申命記 16:1–6; 出エジプト記 12:14; 出エジプト記 13:10"> これは彼らをエジプトの国から導き出すために主が寝ずの番をされた夜であった。ゆえにこの夜、すべてのイスラエルの人々は代々、主のために寝ずの番をしなければならない。</span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="出エジプト記 12:48; 民数記 9:14; 出エジプト記 12:11"> 主はモーセとアロンとに言われた、「過越の祭の定めは次のとおりである。すなわち、異邦人はだれもこれを食べてはならない。</span>
<span className="v" id="v44" data-v="44" data-xref="創世記 17:12–13; 創世記 17:23"> しかし、おのおのが金で買ったしもべは、これに割礼を行ってのち、これを食べさせることができる。</span>
<span className="v" id="v45" data-v="45" data-xref="レビ記 22:10; エペソ人への手紙 2:12"> 仮ずまいの者と、雇人とは、これを食べてはならない。</span>
<span className="v" id="v46" data-v="46" data-xref="民数記 9:12; ヨハネによる福音書 19:36; ヨハネによる福音書 19:33"> ひとつの家でこれを食べなければならない。その肉を少しも家の外に持ち出してはならない。また、その骨を折ってはならない。</span>
<span className="v" id="v47" data-v="47" data-xref="出エジプト記 12:6; 民数記 9:13; 出エジプト記 12:3"> イスラエルの全会衆はこれを守らなければならない。</span>
<span className="v" id="v48" data-v="48" data-xref="民数記 9:14; コロサイ人への手紙 3:11; ガラテヤ人への手紙 3:28"> 寄留の外国人があなたのもとにとどまっていて、主に過越の祭を守ろうとするときは、その男子はみな割礼を受けてのち、近づいてこれを守ることができる。そうすれば彼は国に生れた者のようになるであろう。しかし、無割礼の者はだれもこれを食べてはならない。</span>
<span className="v" id="v49" data-v="49" data-xref="民数記 15:15–16; 民数記 15:29; レビ記 24:22"> この律法は国に生れたものにも、あなたがたのうちに寄留している外国人にも同一である」。</span>
</div>
<div className="bp">
<span className="v" id="v50" data-v="50" data-xref="マタイによる福音書 7:24–25; 出エジプト記 6:26; 出エジプト記 7:4"> イスラエルの人々は、みなこのようにし、主がモーセとアロンに命じられたようにした。</span>
<span className="v" id="v51" data-v="51" data-xref="出エジプト記 12:41; 出エジプト記 6:26"> ちょうどその日に、主はイスラエルの人々を、その軍団に従ってエジプトの国から導き出された。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出エジプト記 12:1; 出エジプト記 13:1"> 主はモーセに言われた、</span>
<span className="v" id="v2" data-v="2" data-xref="民数記 33:7–8; エレミヤ書 44:1; 出エジプト記 13:17–18"> 「イスラエルの人々に告げ、引き返して、ミグドルと海との間にあるピハヒロテの前、バアルゼポンの前に宿営させなさい。あなたがたはそれにむかって、海のかたわらに宿営しなければならない。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行伝 4:28; サムエル記上 23:23; 詩篇 71:11"> パロはイスラエルの人々について、『彼らはその地で迷っている。荒野は彼らを閉じ込めてしまった』と言うであろう。</span>
<span className="v" id="v4" data-v="4" data-xref="ローマ人への手紙 9:22–23; 出エジプト記 7:5; ローマ人への手紙 9:17"> わたしがパロの心をかたくなにするから、パロは彼らのあとを追うであろう。わたしはパロとそのすべての軍勢を破って誉を得、エジプトびとにわたしが主であることを知らせるであろう」。彼らはそのようにした。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="詩篇 105:25; 出エジプト記 12:33; ルカによる福音書 11:24–26"> 民の逃げ去ったことが、エジプトの王に伝えられたので、パロとその家来たちとは、民に対する考えを変えて言った、「われわれはなぜこのようにイスラエルを去らせて、われわれに仕えさせないようにしたのであろう」。</span>
<span className="v" id="v6" data-v="6"> それでパロは戦車を整え、みずからその民を率い、</span>
<span className="v" id="v7" data-v="7" data-xref="出エジプト記 15:4; 士師記 4:3; 詩篇 68:17"> また、えり抜きの戦車六百と、エジプトのすべての戦車およびすべての指揮者たちを率いた。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行伝 13:17; 民数記 33:3; 申命記 26:8"> 主がエジプトの王パロの心をかたくなにされたので、彼はイスラエルの人々のあとを追った。イスラエルの人々は意気揚々と出たのである。</span>
<span className="v" id="v9" data-v="9" data-xref="出エジプト記 15:9; ヨシュア記 24:6; 出エジプト記 14:2"> エジプトびとは彼らのあとを追い、パロのすべての馬と戦車およびその騎兵と軍勢とは、バアルゼポンの前にあるピハヒロテのあたりで、海のかたわらに宿営している彼らに追いついた。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="ヨシュア記 24:7; 詩篇 34:17; ネヘミヤ書 9:9"> パロが近寄った時、イスラエルの人々は目を上げてエジプトびとが彼らのあとに進んできているのを見て、非常に恐れた。そしてイスラエルの人々は主にむかって叫び、</span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 106:7–8; 民数記 14:1–4; 出エジプト記 15:23–24"> かつモーセに言った、「エジプトに墓がないので、荒野で死なせるために、わたしたちを携え出したのですか。なぜわたしたちをエジプトから導き出して、こんなにするのですか。</span>
<span className="v" id="v12" data-v="12" data-xref="ヨナ書 4:3; 出エジプト記 6:9; ヨナ書 4:8"> わたしたちがエジプトであなたに告げて、『わたしたちを捨てておいて、エジプトびとに仕えさせてください』と言ったのは、このことではありませんか。荒野で死ぬよりもエジプトびとに仕える方が、わたしたちにはよかったのです」。</span>
<span className="v" id="v13" data-v="13" data-xref="歴代志下 20:17; 歴代志下 20:15; 出エジプト記 14:30"> モーセは民に言った、「あなたがたは恐れてはならない。かたく立って、主がきょう、あなたがたのためになされる救を見なさい。きょう、あなたがたはエジプトびとを見るが、もはや永久に、二度と彼らを見ないであろう。</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 3:22; 申命記 20:4; 歴代志下 20:17"> 主があなたがたのために戦われるから、あなたがたは黙していなさい」。</span>
<span className="v" id="v15" data-v="15" data-xref="ヨシュア記 7:10; エズラ記 10:4–5; ネヘミヤ書 9:9"> 主はモーセに言われた、「あなたは、なぜわたしにむかって叫ぶのか。イスラエルの人々に語って彼らを進み行かせなさい。</span>
<span className="v" id="v16" data-v="16" data-xref="出エジプト記 7:19; 出エジプト記 4:20; 出エジプト記 4:2"> あなたはつえを上げ、手を海の上にさし伸べてそれを分け、イスラエルの人々に海の中のかわいた地を行かせなさい。</span>
<span className="v" id="v17" data-v="17" data-xref="出エジプト記 14:8; 出エジプト記 14:4; エゼキエル書 34:11"> わたしがエジプトびとの心をかたくなにするから、彼らはそのあとを追ってはいるであろう。こうしてわたしはパロとそのすべての軍勢および戦車と騎兵とを打ち破って誉を得よう。</span>
<span className="v" id="v18" data-v="18" data-xref="出エジプト記 7:5; 出エジプト記 14:4; 出エジプト記 7:17"> わたしがパロとその戦車とその騎兵とを打ち破って誉を得るとき、エジプトびとはわたしが主であることを知るであろう」。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="イザヤ書 63:9; 出エジプト記 32:34; 出エジプト記 23:20–21"> このとき、イスラエルの部隊の前に行く神の使は移って彼らのうしろに行った。雲の柱も彼らの前から移って彼らのうしろに立ち、</span>
<span className="v" id="v20" data-v="20" data-xref="イザヤ書 8:14; コリント人への第二の手紙 2:15–16; 箴言 4:18–19"> エジプトびとの部隊とイスラエルびとの部隊との間にきたので、そこに雲とやみがあり夜もすがら、かれとこれと近づくことなく、夜がすぎた。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="イザヤ書 63:12; 出エジプト記 15:8; 詩篇 66:6"> モーセが手を海の上にさし伸べたので、主は夜もすがら強い東風をもって海を退かせ、海を陸地とされ、水は分かれた。</span>
<span className="v" id="v22" data-v="22" data-xref="ヘブル人への手紙 11:29; 詩篇 66:6; 出エジプト記 15:19"> イスラエルの人々は海の中のかわいた地を行ったが、水は彼らの右と左に、かきとなった。</span>
<span className="v" id="v23" data-v="23" data-xref="出エジプト記 15:19; 出エジプト記 14:17; 出エジプト記 15:9"> エジプトびとは追ってきて、パロのすべての馬と戦車と騎兵とは、彼らのあとについて海の中にはいった。</span>
<span className="v" id="v24" data-v="24" data-xref="出エジプト記 13:21; 詩篇 77:16–19; 出エジプト記 14:25"> 暁の更に、主は火と雲の柱のうちからエジプトびとの軍勢を見おろして、エジプトびとの軍勢を乱し、</span>
<span className="v" id="v25" data-v="25" data-xref="出エジプト記 14:14; 申命記 3:22; ヨブ記 20:24"> その戦車の輪をきしらせて、進むのに重くされたので、エジプトびとは言った、「われわれはイスラエルを離れて逃げよう。主が彼らのためにエジプトびとと戦う」。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="出エジプト記 14:16; 出エジプト記 8:5; ヤコブの手紙 2:13"> そのとき主はモーセに言われた、「あなたの手を海の上にさし伸べて、水をエジプトびとと、その戦車と騎兵との上に流れ返らせなさい」。</span>
<span className="v" id="v27" data-v="27" data-xref="ヨシュア記 4:18; 詩篇 78:53; ヘブル人への手紙 11:29"> モーセが手を海の上にさし伸べると、夜明けになって海はいつもの流れに返り、エジプトびとはこれにむかって逃げたが、主はエジプトびとを海の中に投げ込まれた。</span>
<span className="v" id="v28" data-v="28" data-xref="詩篇 78:53; 詩篇 106:9–11; ハバクク書 3:13"> 水は流れ返り、イスラエルのあとを追って海にはいった戦車と騎兵およびパロのすべての軍勢をおおい、ひとりも残らなかった。</span>
<span className="v" id="v29" data-v="29" data-xref="出エジプト記 14:22; 詩篇 77:19–20; イザヤ書 43:2"> しかし、イスラエルの人々は海の中のかわいた地を行ったが、水は彼らの右と左に、かきとなった。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="詩篇 106:8; 詩篇 106:10; 詩篇 92:9–11"> このように、主はこの日イスラエルをエジプトびとの手から救われた。イスラエルはエジプトびとが海べに死んでいるのを見た。</span>
<span className="v" id="v31" data-v="31" data-xref="ヨハネによる福音書 2:11; ヨハネによる福音書 11:45; ヨハネによる福音書 2:23–25"> イスラエルはまた、主がエジプトびとに行われた大いなるみわざを見た。それで民は主を恐れ、主とそのしもべモーセとを信じた。</span>
</div>

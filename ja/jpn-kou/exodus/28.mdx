<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数記 18:7; ヘブル人への手紙 5:1–5; 民数記 17:2–9"> またイスラエルの人々のうちから、あなたの兄弟アロンとその子たち、すなわちアロンとアロンの子ナダブ、アビウ、エレアザル、イタマルとをあなたのもとにこさせ、祭司としてわたしに仕えさせ、</span>
<span className="v" id="v2" data-v="2" data-xref="レビ記 8:30; 出エジプト記 31:10; ヨハネの黙示録 19:8"> またあなたの兄弟アロンのために聖なる衣服を作って、彼に栄えと麗しきをもたせなければならない。</span>
<span className="v" id="v3" data-v="3" data-xref="エペソ人への手紙 1:17; コリント人への第一の手紙 12:7–11; イザヤ書 11:2"> あなたはすべて心に知恵ある者、すなわち、わたしが知恵の霊を満たした者たちに語って、アロンの衣服を作らせ、アロンを聖別し、祭司としてわたしに仕えさせなければならない。</span>
<span className="v" id="v4" data-v="4" data-xref="エペソ人への手紙 6:14; ヨハネの黙示録 9:17; イザヤ書 59:17"> 彼らの作るべき衣服は次のとおりである。すなわち胸当、エポデ、衣、市松模様の服、帽子、帯である。彼らはあなたの兄弟アロンとその子たちとのために聖なる衣服を作り、祭司としてわたしに仕えさせなければならない。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="出エジプト記 25:3–4; 出エジプト記 39:2–3"> 彼らは金糸、青糸、紫糸、緋糸、亜麻の撚糸を受け取らなければならない。</span>
<span className="v" id="v6" data-v="6" data-xref="出エジプト記 39:2–7; 出エジプト記 26:1"> そして彼らは金糸、青糸、紫糸、緋糸、亜麻の撚糸を用い、巧みなわざをもってエポデを作らなければならない。</span>
<span className="v" id="v7" data-v="7" data-xref="出エジプト記 39:4"> これに二つの肩ひもを付け、その両端を、これに付けなければならない。</span>
<span className="v" id="v8" data-v="8" data-xref="出エジプト記 28:27–28; レビ記 8:7; 出エジプト記 29:5"> エポデの上で、これをつかねる帯は、同じきれでエポデの作りのように、金糸、青糸、紫糸、緋糸、亜麻の撚糸で作らなければならない。</span>
<span className="v" id="v9" data-v="9" data-xref="エゼキエル書 28:13; 歴代志下 2:7; イザヤ書 49:16"> あなたは二つの縞めのうを取って、その上にイスラエルの子たちの名を刻まなければならない。</span>
<span className="v" id="v10" data-v="10" data-xref="出エジプト記 1:1–4; 創世記 43:33"> すなわち、その名六つを一つの石に、残りの名六つを他の石に、彼らの生れた順に刻まなければならない。</span>
<span className="v" id="v11" data-v="11" data-xref="テモテヘの第二の手紙 2:19; ヨハネの黙示録 7:2; エレミヤ書 22:24"> 宝石に彫刻する人が印を彫刻するように、イスラエルの子たちの名をその二つの石に刻み、それを金の編細工にはめ、</span>
<span className="v" id="v12" data-v="12" data-xref="出エジプト記 28:29; ヨシュア記 4:7; 出エジプト記 39:6–7"> この二つの石をエポデの肩ひもにつけて、イスラエルの子たちの記念の石としなければならない。こうしてアロンは主の前でその両肩に彼らの名を負うて記念としなければならない。</span>
<span className="v" id="v13" data-v="13"> あなたはまた金の編細工を作らなければならない。</span>
<span className="v" id="v14" data-v="14" data-xref="出エジプト記 39:15; 出エジプト記 39:17–18; 列王紀上 7:17"> そして二つの純金の鎖を、ひも細工にねじて作り、そのひもの鎖をかの編細工につけなければならない。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="出エジプト記 28:30; 出エジプト記 26:1; 出エジプト記 28:4"> あなたはまたさばきの胸当を巧みなわざをもって作り、これをエポデの作りのように作らなければならない。すなわち金糸、青糸、紫糸、緋糸、亜麻の撚糸で、これを作らなければならない。</span>
<span className="v" id="v16" data-v="16"> これは二つに折って四角にし、長さは一指当り、幅も一指当りとしなければならない。</span>
<span className="v" id="v17" data-v="17" data-xref="エゼキエル書 28:13; 出エジプト記 39:10–21; 箴言 8:11"> またその中に宝石を四列にはめ込まなければならない。すなわち紅玉髄、貴かんらん石、水晶の列を第一列とし、</span>
<span className="v" id="v18" data-v="18" data-xref="エゼキエル書 27:16; ヨブ記 28:6; 雅歌 5:14"> 第二列は、ざくろ石、るり、赤縞めのう。</span>
<span className="v" id="v19" data-v="19" data-xref="イザヤ書 54:12; 出エジプト記 39:12"> 第三列は黄水晶、めのう、紫水晶。</span>
<span className="v" id="v20" data-v="20" data-xref="エゼキエル書 1:16; ヨハネの黙示録 4:3; ダニエル書 10:6"> 第四列は黄碧玉、縞めのう、碧玉であって、これらを金の編細工の中にはめ込まなければならない。</span>
<span className="v" id="v21" data-v="21" data-xref="ヨハネの黙示録 21:12; ヨハネの黙示録 7:4–8; 列王紀上 18:31"> その宝石はイスラエルの子らの名に従い、その名とひとしく十二とし、おのおの印の彫刻のように十二の部族のためにその名を刻まなければならない。</span>
<span className="v" id="v22" data-v="22"> またひも細工にねじた純金の鎖を胸当につけなければならない。</span>
<span className="v" id="v23" data-v="23" data-xref="出エジプト記 25:11–15"> また、胸当のために金の環二つを作り、胸当の両端にその二つの環をつけ、</span>
<span className="v" id="v24" data-v="24"> かの二筋の金のひもを胸当の端の二つの環につけなければならない。</span>
<span className="v" id="v25" data-v="25" data-xref="出エジプト記 39:15; 出エジプト記 39:4; 出エジプト記 28:14"> ただし、その二筋のひもの他の両端をかの二つの編細工につけ、エポデの肩ひもにつけて、前にくるようにしなければならない。</span>
<span className="v" id="v26" data-v="26"> あなたはまた二つの金の環を作って、これを胸当の両端につけなければならない。すなわちエポデに接する内側の縁にこれをつけなければならない。</span>
<span className="v" id="v27" data-v="27"> また二つの金の環を作って、これをエポデの二つの肩ひもの下の部分につけ、前の方で、そのつなぎ目に近く、エポデの帯の上の方にあるようにしなければならない。</span>
<span className="v" id="v28" data-v="28" data-xref="民数記 15:38; 出エジプト記 28:31; 出エジプト記 39:30–31"> 胸当は青ひもをもって、その環をエポデの環に結びつけ、エポデの帯の上の方にあるようにしなければならない。こうして胸当がエポデから離れないようにしなければならない。</span>
<span className="v" id="v29" data-v="29" data-xref="出エジプト記 28:12; 出エジプト記 28:30; エレミヤ書 30:21"> アロンが聖所にはいる時は、さばきの胸当にあるイスラエルの子たちの名をその胸に置き、主の前に常に覚えとしなければならない。</span>
<span className="v" id="v30" data-v="30" data-xref="ネヘミヤ書 7:65; エズラ記 2:63; 民数記 27:21"> あなたはさばきの胸当にウリムとトンミムを入れて、アロンが主の前にいたる時、その胸の上にあるようにしなければならない。こうしてアロンは主の前に常にイスラエルの子たちのさばきを、その胸に置かなければならない。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="レビ記 8:7; 出エジプト記 28:4; 出エジプト記 39:22–26"> あなたはまた、エポデに属する上服をすべて青地で作らなければならない。</span>
<span className="v" id="v32" data-v="32" data-xref="ネヘミヤ書 4:16; ヨハネによる福音書 19:23–24; 出エジプト記 39:28"> 頭を通す口を、そのまん中に設け、その口の周囲には、よろいのえりのように織物の縁をつけて、ほころびないようにし、</span>
<span className="v" id="v33" data-v="33" data-xref="出エジプト記 39:24–26; ゼカリヤ書 14:20; 列王紀上 7:18"> そのすそには青糸、紫糸、緋糸で、ざくろを作り、そのすその周囲につけ、また周囲に金の鈴をざくろの間々につけなければならない。</span>
<span className="v" id="v34" data-v="34" data-xref="雅歌 8:2; ヨハネによる福音書 15:4–8; コロサイ人への手紙 1:10"> すなわち金の鈴にざくろ、また金の鈴にざくろと、上服のすその周囲につけなければならない。</span>
<span className="v" id="v35" data-v="35" data-xref="ヘブル人への手紙 9:12; レビ記 16:2"> アロンは務の時、これを着なければならない。彼が聖所にはいって主の前にいたる時、また出る時、その音が聞えて、彼は死を免れるであろう。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="ゼカリヤ書 14:20; レビ記 8:9; 出エジプト記 39:30"> あなたはまた純金の板を造り、印の彫刻のように、その上に『主に聖なる者』と刻み、</span>
<span className="v" id="v37" data-v="37" data-xref="出エジプト記 29:6; 出エジプト記 28:4; ゼカリヤ書 3:5"> これを青ひもで帽子に付け、それが帽子の前の方に来るようにしなければならない。</span>
<span className="v" id="v38" data-v="38" data-xref="ペテロの第一の手紙 2:24; 民数記 18:1; レビ記 10:17"> これはアロンの額にあり、そしてアロンはイスラエルの人々がささげる聖なる物、すなわち彼らのもろもろの聖なる供え物についての罪の責めを負うであろう。これは主の前にそれらの受けいれられるため、常にアロンの額になければならない。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="詩篇 45:14"> あなたは亜麻糸で市松模様に下服を織り、亜麻布で、ずきんを作り、また、帯を色とりどりに織って作らなければならない。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="出エジプト記 39:41; 出エジプト記 28:4; 出エジプト記 28:2"> あなたはまたアロンの子たちのために下服を作り、彼らのために帯を作り、彼らのために、ずきんを作って、彼らに栄えと麗しきをもたせなければならない。</span>
<span className="v" id="v41" data-v="41" data-xref="出エジプト記 29:7; レビ記 8:1–36; 出エジプト記 40:15"> そしてあなたはこれをあなたの兄弟アロンおよび彼と共にいるその子たちに着せ、彼らに油を注ぎ、彼らを職に任じ、彼らを聖別し、祭司として、わたしに仕えさせなければならない。</span>
<span className="v" id="v42" data-v="42" data-xref="エゼキエル書 44:18; レビ記 6:10; レビ記 16:4"> また、彼らのために、その隠し所をおおう亜麻布のしたばきを作り、腰からももに届くようにしなければならない。</span>
<span className="v" id="v43" data-v="43" data-xref="出エジプト記 27:21; 出エジプト記 20:26; レビ記 5:17"> アロンとその子たちは会見の幕屋にはいる時、あるいは聖所で務をするために祭壇に近づく時に、これを着なければならない。そうすれば、彼らは罪を得て死ぬことはないであろう。これは彼と彼の後の子孫とのための永久の定めでなければならない。</span>
</div>
</div>

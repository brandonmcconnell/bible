<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="レビ記 4:3; マラキ書 1:13–14; 出エジプト記 12:5"> あなたは彼らを聖別し、祭司としてわたしに仕えさせるために、次の事を彼らにしなければならない。すなわち若い雄牛一頭と、きずのない雄羊二頭とを取り、</span>
<span className="v" id="v2" data-v="2" data-xref="民数記 6:15; レビ記 2:15; レビ記 7:12"> また種入れぬパンと、油を混ぜた種入れぬ菓子と、油を塗った種入れぬせんべいとを取りなさい。これらは小麦粉で作らなければならない。</span>
<span className="v" id="v3" data-v="3" data-xref="民数記 6:17; レビ記 8:26; レビ記 8:2"> そしてこれを一つのかごに入れ、そのかごに入れたまま、かの一頭の雄牛および二頭の雄羊と共に携えてこなければならない。</span>
<span className="v" id="v4" data-v="4" data-xref="出エジプト記 40:12; ヘブル人への手紙 10:22; 出エジプト記 26:36"> あなたはまたアロンとその子たちを会見の幕屋の入口に連れてきて、水で彼らを洗い清め、</span>
<span className="v" id="v5" data-v="5" data-xref="出エジプト記 28:2–8; レビ記 8:7–8"> また衣服を取り、下服とエポデに属する上服と、エポデと胸当とをアロンに着せ、エポデの帯を締めさせなければならない。</span>
<span className="v" id="v6" data-v="6" data-xref="レビ記 8:9; 出エジプト記 28:36–39"> そして彼の頭に帽子をかぶらせ、その帽子の上にかの聖なる冠をいただかせ、</span>
<span className="v" id="v7" data-v="7" data-xref="民数記 35:25; レビ記 21:10; ヨハネによる福音書 3:34"> 注ぎ油を取って彼の頭にかけ、彼に油注ぎをしなければならない。</span>
<span className="v" id="v8" data-v="8" data-xref="レビ記 8:13; 出エジプト記 28:40"> あなたはまた彼の子たちを連れてきて下服を着せ、</span>
<span className="v" id="v9" data-v="9" data-xref="民数記 18:7; レビ記 8:22–28; 申命記 18:5"> 彼ら、すなわちアロンとその子たちに帯を締めさせ、ずきんをかぶらせなければならない。祭司の職は永久の定めによって彼らに帰するであろう。あなたはこうして、アロンとその子たちを職に任じなければならない。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="レビ記 1:4; レビ記 8:14; 出エジプト記 29:15"> あなたは会見の幕屋の前に雄牛を引いてきて、アロンとその子たちは、その雄羊の頭に手を置かなければならない。</span>
<span className="v" id="v11" data-v="11" data-xref="レビ記 9:8; レビ記 9:12; 出エジプト記 29:4"> そして会見の幕屋の入口で、主の前にその雄牛をほふり、</span>
<span className="v" id="v12" data-v="12" data-xref="出エジプト記 27:2; レビ記 9:9; レビ記 8:15"> その雄牛の血を取り、指をもって、これを祭壇の角につけ、その残りの血を祭壇の基に注ぎかけなさい。</span>
<span className="v" id="v13" data-v="13" data-xref="レビ記 3:3–4; サムエル記上 2:16; レビ記 9:10"> また、その内臓をおおうすべての脂肪と肝臓の小葉と、二つの腎臓と、その上の脂肪とを取って、これを祭壇の上で焼かなければならない。</span>
<span className="v" id="v14" data-v="14" data-xref="レビ記 4:11–12; レビ記 4:21; 出エジプト記 30:10"> ただし、その雄牛の肉と皮と汚物とは、宿営の外で火で焼き捨てなければならない。これは罪祭である。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="出エジプト記 29:19; 出エジプト記 29:3; レビ記 8:18–21"> あなたはまた、かの雄羊の一頭を取り、そしてアロンとその子たちは、その雄羊の頭に手を置かなければならない。</span>
<span className="v" id="v16" data-v="16" data-xref="出エジプト記 29:11–12"> あなたはその雄羊をほふり、その血を取って、祭壇の四つの側面に注ぎかけなければならない。</span>
<span className="v" id="v17" data-v="17" data-xref="エレミヤ書 4:14; レビ記 1:13; レビ記 1:9"> またその雄羊を切り裂き、その内臓と、その足とを洗って、これをその肉の切れ、および頭と共に置き、</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 8:21; ピリピ人への手紙 4:18; 創世記 22:7"> その雄羊をみな祭壇の上で焼かなければならない。これは主にささげる燔祭である。すなわち、これは香ばしいかおりであって、主にささげる火祭である。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="出エジプト記 29:3; レビ記 8:22–29"> あなたはまた雄羊の他の一頭を取り、アロンとその子たちは、その雄羊の頭に手を置かなければならない。</span>
<span className="v" id="v20" data-v="20" data-xref="イザヤ書 50:5; ヘブル人への手紙 10:22; レビ記 14:16"> そしてあなたはその雄羊をほふり、その血を取って、アロンの右の耳たぶと、その子たちの右の耳たぶとにつけ、また彼らの右の手の親指と、右の足の親指とにつけ、その残りの血を祭壇の四つの側面に注ぎかけなければならない。</span>
<span className="v" id="v21" data-v="21" data-xref="ヘブル人への手紙 9:22; 出エジプト記 29:7; 出エジプト記 29:1"> また祭壇の上の血および注ぎ油を取って、アロンとその衣服、およびその子たちと、その子たちの衣服とに注がなければならない。彼とその衣服、およびその子らと、その衣服とは聖別されるであろう。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="出エジプト記 29:13; レビ記 9:21; レビ記 9:19"> あなたはまた、その雄羊の脂肪、脂尾、内臓をおおう脂肪、肝臓の小葉、二つの腎臓、その上の脂肪、および右のももを取らなければならない。これは任職の雄羊である。</span>
<span className="v" id="v23" data-v="23" data-xref="出エジプト記 29:2–3; レビ記 8:26"> また主の前にある種入れぬパンのかごの中からパン一個と、油菓子一個と、せんべい一個とを取り、</span>
<span className="v" id="v24" data-v="24" data-xref="レビ記 7:30; レビ記 8:27; レビ記 9:21"> これをみなアロンの手と、その子たちの手に置き、これを主の前に揺り動かして、揺祭としなければならない。</span>
<span className="v" id="v25" data-v="25" data-xref="レビ記 8:28; 出エジプト記 29:41; レビ記 3:16"> そしてあなたはこれを彼らの手から受け取り、燔祭に加えて祭壇の上で焼き、主の前に香ばしいかおりとしなければならない。これは主にささげる火祭である。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="レビ記 8:29; レビ記 7:31; レビ記 7:34"> あなたはまた、アロンの任職の雄羊の胸を取り、これを主の前に揺り動かして、揺祭としなければならない。これはあなたの受ける分となるであろう。</span>
<span className="v" id="v27" data-v="27" data-xref="レビ記 10:15; 民数記 18:11; 申命記 18:3"> あなたはアロンとその子たちの任職の雄羊の胸ともも、すなわち揺り動かした揺祭の胸と、ささげたももとを聖別しなければならない。</span>
<span className="v" id="v28" data-v="28" data-xref="民数記 15:19–20; レビ記 7:11–38; レビ記 10:14–15"> これはイスラエルの人々から永久に、アロンとその子たちの受くべきささげ物であって、イスラエルの人々の酬恩祭の犠牲の中から受くべきもの、すなわち主にささげるささげ物である。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="民数記 18:8; 出エジプト記 28:3–4; 出エジプト記 30:30"> アロンの聖なる衣服は彼の後の子孫に帰すべきである。彼らはこれを着て、油注がれ、職に任ぜられなければならない。</span>
<span className="v" id="v30" data-v="30" data-xref="民数記 20:28; レビ記 13:5; 使徒行伝 20:6–7"> その子たちのうち、彼に代って祭司となり、聖所で仕えるために会見の幕屋にはいる者は、七日の間これを着なければならない。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="レビ記 8:31; サムエル記上 2:13; エゼキエル書 46:20–24"> あなたは任職の雄羊を取り、聖なる場所でその肉を煮なければならない。</span>
<span className="v" id="v32" data-v="32" data-xref="マタイによる福音書 12:4; 出エジプト記 29:23; 出エジプト記 29:2–3"> アロンとその子たちは会見の幕屋の入口で、その雄羊の肉と、かごの中のパンとを食べなければならない。</span>
<span className="v" id="v33" data-v="33" data-xref="民数記 18:4; レビ記 10:13–18; 詩篇 22:26"> 彼らを職に任じ、聖別するため、あがないに用いたこれらのものを、彼らは食べなければならない。他の人はこれを食べてはならない。これは聖なる物だからである。</span>
<span className="v" id="v34" data-v="34" data-xref="出エジプト記 12:10; レビ記 8:32; 出エジプト記 29:22"> もし任職の肉、あるいはパンのうち、朝まで残るものがあれば、その残りは火で焼かなければならない。これは聖なる物だから食べてはならない。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="出エジプト記 29:30; レビ記 14:8–11; レビ記 8:4–36"> あなたはわたしがすべて命じるように、アロンとその子たちにしなければならない。すなわち彼らのために七日のあいだ、任職の式を行わなければならない。</span>
<span className="v" id="v36" data-v="36" data-xref="ヘブル人への手紙 10:11; ヘブル人への手紙 9:22–23; 出エジプト記 30:28–29"> あなたは毎日、あがないのために、罪祭の雄牛一頭をささげなければならない。また祭壇のために、あがないをなす時、そのために罪祭をささげ、また、これに油を注いで聖別しなさい。</span>
<span className="v" id="v37" data-v="37" data-xref="出エジプト記 40:10; マタイによる福音書 23:19; 出エジプト記 30:28–29"> あなたは七日の間、祭壇のために、あがないをして、これを聖別しなければならない。こうして祭壇は、いと聖なる物となり、すべて祭壇に触れる者は聖となるであろう。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="歴代志下 2:4; 歴代志上 16:40; 民数記 28:3–8"> あなたが祭壇の上にささぐべき物は次のとおりである。すなわち当歳の小羊二頭を毎日絶やすことなくささげなければならない。</span>
<span className="v" id="v39" data-v="39" data-xref="エゼキエル書 46:13–15; 列王紀下 16:15; 詩篇 5:3"> その一頭の小羊は朝にこれをささげ、他の一頭の小羊は夕にこれをささげなければならない。</span>
<span className="v" id="v40" data-v="40" data-xref="ピリピ人への手紙 2:17; エゼキエル書 46:14; ヨエル書 2:14"> 一頭の小羊には、つぶして取った油一ヒンの四分の一をまぜた麦粉十分の一エパを添え、また灌祭として、ぶどう酒一ヒンの四分の一を添えなければならない。</span>
<span className="v" id="v41" data-v="41" data-xref="エゼキエル書 46:13–15; 列王紀上 18:29; 詩篇 141:2"> 他の一頭の小羊は夕にこれをささげ、朝の素祭および灌祭と同じものをこれに添えてささげ、香ばしいかおりのために主にささげる火祭としなければならない。</span>
<span className="v" id="v42" data-v="42" data-xref="出エジプト記 25:22"> これはあなたがたが代々会見の幕屋の入口で、主の前に絶やすことなく、ささぐべき燔祭である。わたしはその所であなたに会い、あなたと語るであろう。</span>
<span className="v" id="v43" data-v="43" data-xref="列王紀上 8:11; 歴代志下 7:1–3; マラキ書 3:1"> また、その所でわたしはイスラエルの人々に会うであろう。幕屋はわたしの栄光によって聖別されるであろう。</span>
<span className="v" id="v44" data-v="44" data-xref="レビ記 21:15; レビ記 22:9; レビ記 22:16"> わたしは会見の幕屋と祭壇とを聖別するであろう。またアロンとその子たちを聖別し、祭司としてわたしに仕えさせるであろう。</span>
<span className="v" id="v45" data-v="45" data-xref="レビ記 26:12; コリント人への第二の手紙 6:16; 出エジプト記 25:8"> わたしはイスラエルの人々のうちに住んで、彼らの神となるであろう。</span>
<span className="v" id="v46" data-v="46" data-xref="出エジプト記 20:2; エレミヤ書 31:33; エゼキエル書 20:5"> わたしが彼らのうちに住むために、彼らをエジプトの国から導き出した彼らの神、主であることを彼らは知るであろう。わたしは彼らの神、主である。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数記 33:10–12; 出エジプト記 15:27; 出エジプト記 17:1"> イスラエルの人々の全会衆はエリムを出発し、エジプトの地を出て二か月目の十五日に、エリムとシナイとの間にあるシンの荒野にきたが、</span>
<span className="v" id="v2" data-v="2" data-xref="コリント人への第一の手紙 10:10; 出エジプト記 15:24; 詩篇 106:25"> その荒野でイスラエルの人々の全会衆は、モーセとアロンにつぶやいた。</span>
<span className="v" id="v3" data-v="3" data-xref="民数記 11:4–5; 民数記 20:3–5; 出エジプト記 17:3"> イスラエルの人々は彼らに言った、「われわれはエジプトの地で、肉のなべのかたわらに座し、飽きるほどパンを食べていた時に、主の手にかかって死んでいたら良かった。あなたがたは、われわれをこの荒野に導き出して、全会衆を餓死させようとしている」。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="コリント人への第一の手紙 10:3; 詩篇 78:24–25; 申命記 8:2"> そのとき主はモーセに言われた、「見よ、わたしはあなたがたのために、天からパンを降らせよう。民は出て日々の分を日ごとに集めなければならない。こうして彼らがわたしの律法に従うかどうかを試みよう。</span>
<span className="v" id="v5" data-v="5" data-xref="出エジプト記 16:22–23; 出エジプト記 35:2–3; レビ記 25:21–22"> 六日目には、彼らが取り入れたものを調理すると、それは日ごとに集めるものの二倍あるであろう」。</span>
<span className="v" id="v6" data-v="6" data-xref="出エジプト記 6:7; 民数記 16:28; 出エジプト記 16:12–13"> モーセとアロンは、イスラエルのすべての人々に言った、「夕暮には、あなたがたは、エジプトの地からあなたがたを導き出されたのが、主であることを知るであろう。</span>
<span className="v" id="v7" data-v="7" data-xref="イザヤ書 40:5; 民数記 16:11; ヨハネによる福音書 11:40"> また、朝には、あなたがたは主の栄光を見るであろう。主はあなたがたが主にむかってつぶやくのを聞かれたからである。あなたがたは、いったいわれわれを何者として、われわれにむかってつぶやくのか」。</span>
<span className="v" id="v8" data-v="8" data-xref="ローマ人への手紙 13:2; サムエル記上 8:7; テサロニケ人への第一の手紙 4:8"> モーセはまた言った、「主は夕暮にはあなたがたに肉を与えて食べさせ、朝にはパンを与えて飽き足らせられるであろう。主はあなたがたが、主にむかってつぶやくつぶやきを聞かれたからである。いったいわれわれは何者なのか。あなたがたのつぶやくのは、われわれにむかってでなく、主にむかってである」。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="民数記 16:16; 出エジプト記 16:2; 出エジプト記 16:8"> モーセはアロンに言った、「イスラエルの人々の全会衆に言いなさい、『あなたがたは主の前に近づきなさい。主があなたがたのつぶやきを聞かれたからである』と」。</span>
<span className="v" id="v10" data-v="10" data-xref="出エジプト記 16:7; 民数記 16:19; 民数記 16:42"> それでアロンがイスラエルの人々の全会衆に語ったとき、彼らが荒野の方を望むと、見よ、主の栄光が雲のうちに現れていた。</span>
<span className="v" id="v11" data-v="11"> 主はモーセに言われた、</span>
<span className="v" id="v12" data-v="12" data-xref="ヨエル書 3:17; エゼキエル書 39:22; 出エジプト記 6:7"> 「わたしはイスラエルの人々のつぶやきを聞いた。彼らに言いなさい、『あなたがたは夕には肉を食べ、朝にはパンに飽き足りるであろう。そうしてわたしがあなたがたの神、主であることを知るであろう』と」。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="民数記 11:9; 詩篇 105:40; 詩篇 78:27–28"> 夕べになると、うずらが飛んできて宿営をおおった。また、朝になると、宿営の周囲に露が降りた。</span>
<span className="v" id="v14" data-v="14" data-xref="民数記 11:7–9; 詩篇 105:40; 詩篇 78:24"> その降りた露がかわくと、荒野の面には、薄いうろこのようなものがあり、ちょうど地に結ぶ薄い霜のようであった。</span>
<span className="v" id="v15" data-v="15" data-xref="出エジプト記 16:4; ヨハネによる福音書 6:58; 出エジプト記 16:31"> イスラエルの人々はそれを見て互に言った、「これはなんであろう」。彼らはそれがなんであるのか知らなかったからである。モーセは彼らに言った、「これは主があなたがたの食物として賜わるパンである。</span>
<span className="v" id="v16" data-v="16" data-xref="出エジプト記 16:36; 出エジプト記 16:18; 出エジプト記 16:32–33"> 主が命じられるのはこうである、『あなたがたは、おのおのその食べるところに従ってそれを集め、あなたがたの人数に従って、ひとり一オメルずつ、おのおのその天幕におるもののためにそれを取りなさい』と」。</span>
<span className="v" id="v17" data-v="17"> イスラエルの人々はそのようにして、ある者は多く、ある者は少なく集めた。</span>
<span className="v" id="v18" data-v="18" data-xref="コリント人への第二の手紙 8:14–15"> しかし、オメルでそれを計ってみると、多く集めた者にも余らず、少なく集めた者にも不足しなかった。おのおのその食べるところに従って集めていた。</span>
<span className="v" id="v19" data-v="19" data-xref="出エジプト記 12:10; 出エジプト記 23:18; マタイによる福音書 6:34"> モーセは彼らに言った、「だれも朝までそれを残しておいてはならない」。</span>
<span className="v" id="v20" data-v="20" data-xref="マルコによる福音書 10:14; 民数記 16:15; エペソ人への手紙 4:26"> しかし彼らはモーセに聞き従わないで、ある者は朝までそれを残しておいたが、虫がついて臭くなった。モーセは彼らにむかって怒った。</span>
<span className="v" id="v21" data-v="21" data-xref="箴言 6:6–11; 伝道の書 12:1; コリント人への第二の手紙 6:2"> 彼らは、おのおのその食べるところに従って、朝ごとにそれを集めたが、日が熱くなるとそれは溶けた。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="出エジプト記 16:5; レビ記 25:22; 出エジプト記 16:16"> 六日目には、彼らは二倍のパン、すなわちひとりに二オメルを集めた。そこで、会衆の長たちは皆きて、モーセに告げたが、</span>
<span className="v" id="v23" data-v="23" data-xref="レビ記 23:3; 出エジプト記 31:15; 出エジプト記 20:8–11"> モーセは彼らに言った、「主の語られたのはこうである、『あすは主の聖安息日で休みである。きょう、焼こうとするものを焼き、煮ようとするものを煮なさい。残ったものはみな朝までたくわえて保存しなさい』と」。</span>
<span className="v" id="v24" data-v="24" data-xref="出エジプト記 16:20; 出エジプト記 16:33"> 彼らはモーセの命じたように、それを朝まで保存したが、臭くならず、また虫もつかなかった。</span>
<span className="v" id="v25" data-v="25" data-xref="出エジプト記 16:23; 出エジプト記 16:29; ネヘミヤ書 9:14"> モーセは言った、「きょう、それを食べなさい。きょうは主の安息日であるから、きょうは野でそれを獲られないであろう。</span>
<span className="v" id="v26" data-v="26" data-xref="申命記 5:13; 出エジプト記 20:9–11; エゼキエル書 46:1"> 六日の間はそれを集めなければならない。七日目は安息日であるから、その日には無いであろう」。</span>
<span className="v" id="v27" data-v="27" data-xref="箴言 20:4"> ところが民のうちには、七日目に出て集めようとした者があったが、獲られなかった。</span>
<span className="v" id="v28" data-v="28" data-xref="詩篇 78:10; 詩篇 106:13; 民数記 14:11"> そこで主はモーセに言われた、「あなたがたは、いつまでわたしの戒めと、律法とを守ることを拒むのか。</span>
<span className="v" id="v29" data-v="29" data-xref="出エジプト記 31:13; イザヤ書 58:13–14; エゼキエル書 20:12"> 見よ、主はあなたがたに安息日を与えられた。ゆえに六日目には、ふつか分のパンをあなたがたに賜わるのである。おのおのその所にとどまり、七日目にはその所から出てはならない」。</span>
<span className="v" id="v30" data-v="30" data-xref="申命記 5:12–14; レビ記 23:3; ヘブル人への手紙 4:9"> こうして民は七日目に休んだ。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="雅歌 2:3; 民数記 11:6–9; 出エジプト記 16:15"> イスラエルの家はその物の名をマナと呼んだ。それはコエンドロの実のようで白く、その味は蜜を入れたせんべいのようであった。</span>
<span className="v" id="v32" data-v="32" data-xref="詩篇 105:5; ルカによる福音書 22:19; 詩篇 111:4–5"> モーセは言った、「主の命じられることはこうである、『それを一オメルあなたがたの子孫のためにたくわえておきなさい。それはわたしが、あなたがたをエジプトの地から導き出した時、荒野であなたがたに食べさせたパンを彼らに見させるためである』と」。</span>
<span className="v" id="v33" data-v="33" data-xref="ヘブル人への手紙 9:4"> そしてモーセはアロンに言った「一つのつぼを取り、マナ一オメルをその中に入れ、それを主の前に置いて、子孫のためにたくわえなさい」。</span>
<span className="v" id="v34" data-v="34" data-xref="出エジプト記 27:21; 出エジプト記 25:21; 出エジプト記 25:16"> そこで主がモーセに命じられたように、アロンはそれをあかしの箱の前に置いてたくわえた。</span>
<span className="v" id="v35" data-v="35" data-xref="ネヘミヤ書 9:20–21; ヨシュア記 5:12; 申命記 8:2–3"> イスラエルの人々は人の住む地に着くまで四十年の間マナを食べた。すなわち、彼らはカナンの地の境に至るまでマナを食べた。</span>
<span className="v" id="v36" data-v="36" data-xref="出エジプト記 16:16; 出エジプト記 16:32–33"> 一オメルは一エパの十分の一である。</span>
</div>

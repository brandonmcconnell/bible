<span className="v" id="v1" data-v="1"> 主はモーセに言われた。</span>
<span className="v" id="v2" data-v="2" data-xref="出エジプト記 26:30; 出エジプト記 13:4; 民数記 7:1"> 「正月の元日にあなたは会見の天幕なる幕屋を建てなければならない。</span>
<span className="v" id="v3" data-v="3" data-xref="出エジプト記 35:12; 民数記 4:5; ヨハネの黙示録 11:19"> そして、その中にあかしの箱を置き、垂幕で、箱を隔て隠し、</span>
<span className="v" id="v4" data-v="4" data-xref="レビ記 24:8; 出エジプト記 40:22–25; 出エジプト記 37:10–24"> また、机を携え入れ、それに並べるものを並べ、燭台を携え入れて、そのともしびをともさなければならない。</span>
<span className="v" id="v5" data-v="5" data-xref="ヘブル人への手紙 10:19–22; ヘブル人への手紙 9:24; ヨハネの第一の手紙 2:1–2"> あなたはまた金の香の祭壇を、あかしの箱の前にすえ、とばりを幕屋の入口にかけなければならない。</span>
<span className="v" id="v6" data-v="6" data-xref="出エジプト記 40:29; ヨハネの第一の手紙 4:9–10; ヘブル人への手紙 13:10"> また燔祭の祭壇を会見の天幕なる幕屋の入口の前にすえ、</span>
<span className="v" id="v7" data-v="7" data-xref="ゼカリヤ書 13:1; ヨハネの第一の手紙 1:7; 詩篇 26:6"> 洗盤を会見の天幕と祭壇との間にすえて、これに水を入れなければならない。</span>
<span className="v" id="v8" data-v="8" data-xref="出エジプト記 40:33; エペソ人への手紙 4:11–12; マタイによる福音書 16:18"> また周囲に庭を設け、庭の門にとばりをかけなければならない。</span>
<span className="v" id="v9" data-v="9" data-xref="レビ記 8:10; 民数記 7:1; マタイによる福音書 3:16"> そして注ぎ油をとって、幕屋とその中のすべてのものに注ぎ、それとそのもろもろの器とを聖別しなければならない、こうして、それは聖となるであろう。</span>
<span className="v" id="v10" data-v="10" data-xref="出エジプト記 29:36–37; ルカによる福音書 1:35; イザヤ書 61:1"> あなたはまた燔祭の祭壇と、そのすべての器に油を注いで、その祭壇を聖別しなければならない。こうして祭壇は、いと聖なるものとなるであろう。</span>
<span className="v" id="v11" data-v="11"> また洗盤と、その台とに油を注いで、これを聖別し、</span>
<span className="v" id="v12" data-v="12" data-xref="レビ記 8:1–13; レビ記 9:1–24; 出エジプト記 29:1–35"> アロンとその子たちを会見の幕屋の入口に連れてきて、水で彼らを洗い、</span>
<span className="v" id="v13" data-v="13" data-xref="出エジプト記 28:41; ヨハネの第一の手紙 2:20; ヨハネの第一の手紙 2:27"> アロンに聖なる服を着せ、これに油を注いで聖別し、祭司の務をさせなければならない。</span>
<span className="v" id="v14" data-v="14" data-xref="イザヤ書 61:10; ローマ人への手紙 8:30; コリント人への第一の手紙 1:30"> また彼の子たちを連れてきて、これに服を着せ、</span>
<span className="v" id="v15" data-v="15" data-xref="民数記 25:13; ヘブル人への手紙 5:1–14; ヘブル人への手紙 8:1–10"> その父に油を注いだように、彼らにも油を注いで、祭司の務をさせなければならない。彼らが油そそがれることは、代々ながく祭司職のためになすべきことである」。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="申命記 4:1; 出エジプト記 40:17–32; 申命記 12:32"> モーセはそのように行った。すなわち主が彼に命じられたように行った。</span>
<span className="v" id="v17" data-v="17" data-xref="民数記 7:1; 出エジプト記 40:1–2; 民数記 9:1"> 第二年の正月になって、その月の元日に幕屋は建った。</span>
<span className="v" id="v18" data-v="18" data-xref="エゼキエル書 37:27–28; ペテロの第一の手紙 1:5; レビ記 26:11"> すなわちモーセは幕屋を建て、その座をすえ、その枠を立て、その横木をさし込み、その柱を立て、</span>
<span className="v" id="v19" data-v="19" data-xref="出エジプト記 26:1–14; 出エジプト記 36:8–19"> 幕屋の上に天幕をひろげ、その上に天幕のおおいをかけた。主がモーセに命じられたとおりである。</span>
<span className="v" id="v20" data-v="20" data-xref="出エジプト記 16:34; 申命記 10:5; ヘブル人への手紙 10:19–21"> 彼はまたあかしの板をとって箱に納め、さおを箱につけ、贖罪所を箱の上に置き、</span>
<span className="v" id="v21" data-v="21" data-xref="出エジプト記 26:33; 出エジプト記 40:3; 出エジプト記 35:12"> 箱を幕屋に携え入れ、隔ての垂幕をかけて、あかしの箱を隠した。主がモーセに命じられたとおりである。</span>
<span className="v" id="v22" data-v="22" data-xref="出エジプト記 26:35; ヨハネによる福音書 6:53–57; エペソ人への手紙 3:8"> 彼はまた会見の天幕なる幕屋の内部の北側、垂幕の外に机をすえ、</span>
<span className="v" id="v23" data-v="23" data-xref="出エジプト記 25:30; 出エジプト記 40:4; ヘブル人への手紙 9:2"> その上にパンを列に並べて、主の前に供えた。主がモーセに命じられたとおりである。</span>
<span className="v" id="v24" data-v="24" data-xref="出エジプト記 26:35; ヨハネの黙示録 2:5; ヨハネによる福音書 1:1"> 彼はまた会見の天幕なる幕屋の内部の南側に、机にむかい合わせて燭台をすえ、</span>
<span className="v" id="v25" data-v="25" data-xref="出エジプト記 40:4; 出エジプト記 25:37; ヨハネの黙示録 4:5"> 主の前にともしびをともした。主がモーセに命じられたとおりである。</span>
<span className="v" id="v26" data-v="26" data-xref="出エジプト記 40:5; ヘブル人への手紙 7:25; ヨハネによる福音書 11:42"> 彼は会見の幕屋の中、垂幕の前に金の祭壇をすえ、</span>
<span className="v" id="v27" data-v="27" data-xref="出エジプト記 30:7"> その上に香ばしい薫香をたいた。主がモーセに命じられたとおりである。</span>
<span className="v" id="v28" data-v="28" data-xref="出エジプト記 40:5; ヘブル人への手紙 10:19–20; エペソ人への手紙 2:18"> 彼はまた幕屋の入口にとばりをかけ、</span>
<span className="v" id="v29" data-v="29" data-xref="出エジプト記 40:6; ヘブル人への手紙 13:5–6; ヘブル人への手紙 13:10"> 燔祭の祭壇を会見の天幕なる幕屋の入口にすえ、その上に燔祭と素祭をささげた。主がモーセに命じられたとおりである。</span>
<span className="v" id="v30" data-v="30" data-xref="出エジプト記 40:7; 出エジプト記 38:8; エゼキエル書 36:25"> 彼はまた会見の天幕と祭壇との間に洗盤を置き、洗うためにそれに水を入れた。</span>
<span className="v" id="v31" data-v="31" data-xref="出エジプト記 30:19–20; 詩篇 26:6; ヨハネによる福音書 13:10"> モーセとアロンおよびその子たちは、それで手と足を洗った。</span>
<span className="v" id="v32" data-v="32" data-xref="詩篇 73:19; 出エジプト記 30:19–20; 出エジプト記 40:19"> すなわち会見の天幕にはいるとき、また祭壇に近づくとき、そこで洗った。主がモーセに命じられたとおりである。</span>
<span className="v" id="v33" data-v="33" data-xref="出エジプト記 40:8; 出エジプト記 27:9–16; ヨハネによる福音書 17:4"> また幕屋と祭壇の周囲に庭を設け、庭の門にとばりをかけた。このようにしてモーセはその工事を終えた。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="ヨハネの黙示録 15:8; 民数記 9:15–23; 歴代志下 7:2"> そのとき、雲は会見の天幕をおおい、主の栄光が幕屋に満ちた。</span>
<span className="v" id="v35" data-v="35" data-xref="列王紀上 8:11; レビ記 16:2; 歴代志下 7:2"> モーセは会見の幕屋に、はいることができなかった。雲がその上にとどまり、主の栄光が幕屋に満ちていたからである。</span>
<span className="v" id="v36" data-v="36" data-xref="ネヘミヤ書 9:19; 民数記 9:17; 出エジプト記 13:21–22"> 雲が幕屋の上からのぼる時、イスラエルの人々は道に進んだ。彼らはその旅路において常にそうした。</span>
<span className="v" id="v37" data-v="37" data-xref="民数記 9:19–22; 詩篇 31:15"> しかし、雲がのぼらない時は、そののぼる日まで道に進まなかった。</span>
<span className="v" id="v38" data-v="38" data-xref="詩篇 78:14; 民数記 9:15; 出エジプト記 13:21"> すなわちイスラエルの家のすべての者の前に、昼は幕屋の上に主の雲があり、夜は雲の中に火があった。彼らの旅路において常にそうであった。</span>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ルカによる福音書 19:8; サムエル記下 12:6; 箴言 6:31"> もし人が牛または羊を盗んで、これを殺し、あるいはこれを売るならば、彼は一頭の牛のために五頭の牛をもって、一頭の羊のために四頭の羊をもって償わなければならない。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="マタイによる福音書 24:43; マタイによる福音書 6:19–20; 民数記 35:27"> もし盗びとが穴をあけてはいるのを見て、これを撃って殺したときは、その人には血を流した罪はない。</span>
<span className="v" id="v3" data-v="3" data-xref="出エジプト記 21:2; イザヤ書 50:1; マタイによる福音書 18:25"> しかし日がのぼって後ならば、その人に血を流した罪がある。彼は必ず償わなければならない。もし彼に何もない時は、彼はその盗んだ物のために身を売られるであろう。</span>
<span className="v" id="v4" data-v="4" data-xref="出エジプト記 22:7; 出エジプト記 22:1; 出エジプト記 22:9"> もしその盗んだ物がなお生きて、彼の手もとにあれば、それは牛、ろば、羊のいずれにせよ、これを二倍にして償わなければならない。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="出エジプト記 22:3; 出エジプト記 22:12; ヨブ記 20:18"> もし人が畑またはぶどう畑のものを食わせ、その家畜を放って他人の畑のものを食わせた時は、自分の畑の最も良い物と、ぶどう畑の最も良い物をもって、これを償わなければならない。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="出エジプト記 22:9; 出エジプト記 21:33–34; サムエル記下 14:30–31"> もし火が出て、いばらに移り、積みあげた麦束、または立穂、または畑を焼いたならば、その火を燃やした者は、必ずこれを償わなければならない。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="出エジプト記 22:4; 箴言 6:30–31; エレミヤ書 2:26"> もし人が金銭または物品の保管を隣人に託し、それが隣人の家から盗まれた時、その盗びとが見つけられたならば、これを二倍にして償わせなければならない。</span>
<span className="v" id="v8" data-v="8" data-xref="出エジプト記 22:28; 申命記 16:18; 出エジプト記 21:6"> もし盗びとが見つけられなければ、家の主人を神の前に連れてきて、彼が隣人の持ち物に手をかけたかどうかを、確かめなければならない。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="申命記 25:1; 出エジプト記 22:4; 民数記 5:6–7"> 牛であれ、ろばであれ、羊であれ、衣服であれ、あるいはどんな失った物であれ、それについて言い争いが起り『これがそれです』と言う者があれば、その双方の言い分を、神の前に持ち出さなければならない。そして神が有罪と定められる者は、それを二倍にしてその相手に償わなければならない。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="ルカによる福音書 12:48; テモテヘの第二の手紙 1:12; ルカによる福音書 16:11"> もし人が、ろば、または牛、または羊、またはどんな家畜でも、それを隣人に預けて、それが死ぬか、傷つくか、あるいは奪い去られても、それを見た者がなければ、</span>
<span className="v" id="v11" data-v="11" data-xref="ヘブル人への手紙 6:16; レビ記 5:1; 列王紀上 2:42–43"> 双方の間に、隣人の持ち物に手をかけなかったという誓いが、主の前になされなければならない。そうすれば、持ち主はこれを受け入れ、隣人は償うに及ばない。</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 31:39; 出エジプト記 22:7"> けれども、それがまさしく自分の所から盗まれた時は、その持ち主に償わなければならない。</span>
<span className="v" id="v13" data-v="13" data-xref="ナホム書 2:12; ミカ書 5:8; エゼキエル書 4:14"> もしそれが裂き殺された時は、それを証拠として持って来るならば、その裂き殺されたものは償うに及ばない。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="申命記 23:19–20; 出エジプト記 21:34; 申命記 15:2"> もし人が隣人から家畜を借りて、それが傷つき、または死ぬ場合、その持ち主がそれと共にいない時は、必ずこれを償わなければならない。</span>
<span className="v" id="v15" data-v="15" data-xref="ゼカリヤ書 8:10"> もしその持ち主がそれと共におれば、それを償うに及ばない。もしそれが賃借りしたものならば、その借賃をそれに当てなければならない。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="申命記 22:28–29; 創世記 34:2–4"> もし人がまだ婚約しない処女を誘って、これと寝たならば、彼は必ずこれに花嫁料を払って、妻としなければならない。</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 34:12; サムエル記上 18:25; 申命記 22:29"> もしその父がこれをその人に与えることをかたく拒むならば、彼は処女の花嫁料に当るほどの金を払わなければならない。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="レビ記 20:27; 申命記 18:10–11; サムエル記上 28:3"> 魔法使の女は、これを生かしておいてはならない。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="レビ記 18:23; 申命記 27:21; レビ記 20:15–16"> すべて獣を犯す者は、必ず殺されなければならない。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="申命記 17:2–5; 民数記 25:7–8; 申命記 18:20"> 主のほか、他の神々に犠牲をささげる者は、断ち滅ぼされなければならない。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="出エジプト記 23:9; 申命記 10:19; レビ記 19:33"> あなたは寄留の他国人を苦しめてはならない。また、これをしえたげてはならない。あなたがたも、かつてエジプトの国で、寄留の他国人であったからである。</span>
<span className="v" id="v22" data-v="22" data-xref="申命記 24:17; イザヤ書 1:17; イザヤ書 1:23"> あなたがたはすべて寡婦、または孤児を悩ましてはならない。</span>
<span className="v" id="v23" data-v="23" data-xref="詩篇 18:6; 詩篇 10:17–18; ルカによる福音書 18:7"> もしあなたが彼らを悩まして、彼らがわたしにむかって叫ぶならば、わたしは必ずその叫びを聞くであろう。</span>
<span className="v" id="v24" data-v="24" data-xref="詩篇 109:9; エレミヤ書 15:8; 詩篇 76:7"> そしてわたしの怒りは燃えたち、つるぎをもってあなたがたを殺すであろう。あなたがたの妻は寡婦となり、あなたがたの子供たちは孤児となるであろう。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="詩篇 15:5; レビ記 25:35–37; 申命記 23:19–20"> あなたが、共におるわたしの民の貧しい者に金を貸す時は、これに対して金貸しのようになってはならない。これから利子を取ってはならない。</span>
<span className="v" id="v26" data-v="26" data-xref="箴言 20:16; アモス書 2:8; 申命記 24:6"> もし隣人の上着を質に取るならば、日の入るまでにそれを返さなければならない。</span>
<span className="v" id="v27" data-v="27" data-xref="出エジプト記 34:6; 歴代志下 30:9; 詩篇 136:10–11"> これは彼の身をおおう、ただ一つの物、彼の膚のための着物だからである。彼は何を着て寝ることができよう。彼がわたしにむかって叫ぶならば、わたしはこれに聞くであろう。わたしはあわれみ深いからである。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="使徒行伝 23:5; 伝道の書 10:20; 出エジプト記 22:8–9"> あなたは神をののしってはならない。また民の司をのろってはならない。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="出エジプト記 23:16; 出エジプト記 13:2; ヤコブの手紙 1:18"> あなたの豊かな穀物と、あふれる酒とをささげるに、ためらってはならない。<br />あなたのういごを、わたしにささげなければならない。</span>
<span className="v" id="v30" data-v="30" data-xref="レビ記 22:27; 申命記 15:19; 出エジプト記 13:12"> あなたはまた、あなたの牛と羊をも同様にしなければならない。七日の間その母と共に置いて、八日目にそれをわたしに、ささげなければならない。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="エゼキエル書 4:14; レビ記 19:2; 申命記 14:21"> あなたがたは、わたしに対して聖なる民とならなければならない。あなたがたは、野で裂き殺されたものの肉を食べてはならない。それは犬に投げ与えなければならない。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出エジプト記 4:21; 出エジプト記 7:13–14; 出エジプト記 3:20"> そこで、主はモーセに言われた、「パロのもとに行きなさい。わたしは彼の心とその家来たちの心をかたくなにした。これは、わたしがこれらのしるしを、彼らの中に行うためである。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨエル書 1:3; 申命記 4:9; 申命記 6:20–22"> また、わたしがエジプトびとをあしらったこと、また彼らの中にわたしが行ったしるしを、あなたがたが、子や孫の耳に語り伝えるためである。そしてあなたがたは、わたしが主であることを知るであろう」。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="ペテロの第一の手紙 5:6; 列王紀上 21:29; ヤコブの手紙 4:10"> モーセとアロンはパロのもとに行って彼に言った、「ヘブルびとの神、主はこう仰せられる、『いつまで、あなたは、わたしに屈伏することを拒むのですか。民を去らせて、わたしに仕えさせなさい。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネの黙示録 9:3; ヨエル書 2:25; 出エジプト記 11:4–5"> もし、わたしの民を去らせることを拒むならば、見よ、あす、わたしはいなごを、あなたの領土にはいらせるであろう。</span>
<span className="v" id="v5" data-v="5" data-xref="ヨエル書 1:4; 出エジプト記 9:32; ヨエル書 2:25"> それは地のおもてをおおい、人が地を見ることもできないほどになるであろう。そして雹を免れて、残されているものを食い尽し、野にはえているあなたがたの木をみな食い尽すであろう。</span>
<span className="v" id="v6" data-v="6" data-xref="出エジプト記 8:21; 出エジプト記 8:3; 出エジプト記 11:6"> またそれはあなたの家とあなたのすべての家来の家、および、すべてのエジプトびとの家に満ちるであろう。このようなことは、あなたの父たちも、また、祖父たちも、彼らが地上にあった日から今日に至るまで、かつて見たことのないものである』と」。そして彼は身をめぐらして、パロのもとを出て行った。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="サムエル記上 18:21; 出エジプト記 23:33; ヨシュア記 23:13"> パロの家来たちは王に言った、「いつまで、この人はわれわれのわなとなるのでしょう。この人々を去らせ、彼らの神なる主に仕えさせては、どうでしょう。エジプトが滅びてしまうことに、まだ気づかれないのですか」。</span>
<span className="v" id="v8" data-v="8" data-xref="出エジプト記 10:24; 出エジプト記 12:31; 出エジプト記 8:8"> そこで、モーセとアロンは、また、パロのもとに召し出された。パロは彼らに言った、「行って、あなたがたの神、主に仕えなさい。しかし、行くものはだれだれか」。</span>
<span className="v" id="v9" data-v="9" data-xref="出エジプト記 5:1; コリント人への第一の手紙 5:7–8; 申命記 31:12–13"> モーセは言った、「わたしたちは幼い者も、老いた者も行きます。むすこも娘も携え、羊も牛も連れて行きます。わたしたちは主の祭を執り行わなければならないのですから」。</span>
<span className="v" id="v10" data-v="10" data-xref="出エジプト記 13:21; 歴代志下 32:15; 出エジプト記 12:30–31"> パロは彼らに言った、「万一、わたしが、あなたがたに子供を連れてまで去らせるようなことがあれば、主があなたがたと共にいますがよい。あなたがたは悪いたくらみをしている。</span>
<span className="v" id="v11" data-v="11" data-xref="出エジプト記 10:28; 詩篇 119:69; 出エジプト記 5:4"> それはいけない。あなたがたは男だけ行って主に仕えるがよい。それが、あなたがたの要求であった」。彼らは、ついにパロの前から追い出された。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="出エジプト記 7:19; 出エジプト記 10:4–5"> 主はモーセに言われた、「あなたの手をエジプトの地の上にさし伸べて、エジプトの地にいなごをのぼらせ、地のすべての青物、すなわち、雹が打ち残したものを、ことごとく食べさせなさい」。</span>
<span className="v" id="v13" data-v="13" data-xref="ヨナ書 1:4; 詩篇 78:26; 詩篇 148:8"> そこでモーセはエジプトの地の上に、つえをさし伸べたので、主は終日、終夜、東風を地に吹かせられた。朝となって、東風は、いなごを運んできた。</span>
<span className="v" id="v14" data-v="14" data-xref="詩篇 78:46; ヨエル書 1:2–4; 詩篇 105:34–35"> いなごはエジプト全国にのぞみ、エジプトの全領土にとどまり、その数がはなはだ多く、このようないなごは前にもなく、また後にもないであろう。</span>
<span className="v" id="v15" data-v="15" data-xref="出エジプト記 10:5; 詩篇 78:46; ヨエル書 1:6–7"> いなごは地の全面をおおったので、地は暗くなった。そして地のすべての青物と、雹の打ち残した木の実を、ことごとく食べたので、エジプト全国にわたって、木にも畑の青物にも、緑の物とては何も残らなかった。</span>
<span className="v" id="v16" data-v="16" data-xref="出エジプト記 9:27; サムエル記下 19:20; サムエル記上 15:30"> そこで、パロは、急いでモーセとアロンを召して言った、「わたしは、あなたがたの神、主に対し、また、あなたがたに対して罪を犯しました。</span>
<span className="v" id="v17" data-v="17" data-xref="出エジプト記 8:8; 出エジプト記 9:28; 列王紀上 13:6"> それで、どうか、もう一度だけ、わたしの罪をゆるしてください。そしてあなたがたの神、主に祈願して、ただ、この死をわたしから離れさせてください」。</span>
<span className="v" id="v18" data-v="18" data-xref="ルカによる福音書 6:28; 出エジプト記 8:28–30; 出エジプト記 8:9"> そこで彼はパロのところから出て、主に祈願したので、</span>
<span className="v" id="v19" data-v="19" data-xref="ヨエル書 2:20; 出エジプト記 13:18; 出エジプト記 15:4"> 主は、はなはだ強い西風に変らせ、いなごを吹き上げて、これを紅海に追いやられたので、エジプト全土には一つのいなごも残らなかった。</span>
<span className="v" id="v20" data-v="20" data-xref="出エジプト記 4:21; 出エジプト記 11:10; 申命記 2:30"> しかし、主がパロの心をかたくなにされたので、彼はイスラエルの人々を去らせなかった。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="ヨハネの黙示録 16:10–11; ユダの手紙 1:6; ルカによる福音書 23:44"> 主はまたモーセに言われた、「天にむかってあなたの手をさし伸べ、エジプトの国に、くらやみをこさせなさい。そのくらやみは、さわれるほどである」。</span>
<span className="v" id="v22" data-v="22" data-xref="詩篇 105:28; ヨハネの黙示録 16:10; 出エジプト記 20:21"> モーセが天にむかって手をさし伸べたので、濃いくらやみは、エジプト全国に臨み三日に及んだ。</span>
<span className="v" id="v23" data-v="23" data-xref="出エジプト記 8:22; イザヤ書 42:16; ペテロの第一の手紙 2:9"> 三日の間、人々は互に見ることもできず、まただれもその所から立つ者もなかった。しかし、イスラエルの人々には、みな、その住む所に光があった。</span>
<span className="v" id="v24" data-v="24" data-xref="出エジプト記 10:8–10; 出エジプト記 8:28; 創世記 34:23"> そこでパロはモーセを召して言った、「あなたがたは行って主に仕えなさい。あなたがたの子供も連れて行ってもよろしい。ただ、あなたがたの羊と牛は残して置きなさい」。</span>
<span className="v" id="v25" data-v="25" data-xref="レビ記 9:22; レビ記 16:9; 出エジプト記 29:1–46"> しかし、モーセは言った、「あなたは、また、わたしたちの神、主にささげる犠牲と燔祭の物をも、わたしたちにくださらなければなりません。</span>
<span className="v" id="v26" data-v="26" data-xref="イザヤ書 23:18; 使徒行伝 2:44–45; 箴言 3:9"> わたしたちは家畜も連れて行きます。ひずめ一つも残しません。わたしたちは、そのうちから取って、わたしたちの神、主に仕えねばなりません。またわたしたちは、その場所に行くまでは、何をもって、主に仕えるべきかを知らないからです」。</span>
<span className="v" id="v27" data-v="27" data-xref="出エジプト記 10:20; 出エジプト記 4:21; 出エジプト記 14:8"> けれども、主がパロの心をかたくなにされたので、パロは彼らを去らせようとしなかった。</span>
<span className="v" id="v28" data-v="28" data-xref="歴代志下 25:16; 歴代志下 16:10; アモス書 7:13"> それでパロはモーセに言った、「わたしの所から去りなさい。心して、わたしの顔は二度と見てはならない。わたしの顔を見る日には、あなたの命はないであろう」。</span>
<span className="v" id="v29" data-v="29" data-xref="ヘブル人への手紙 11:27; 出エジプト記 12:30–31; 出エジプト記 11:4–8"> モーセは言った、「よくぞ仰せられました。わたしは、二度と、あなたの顔を見ないでしょう」。</span>
</div>

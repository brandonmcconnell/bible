<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出エジプト記 36:8–19; 出エジプト記 26:36; 出エジプト記 26:31"> あなたはまた十枚の幕をもって幕屋を造らなければならない。すなわち亜麻の撚糸、青糸、紫糸、緋糸で幕を作り、巧みなわざをもって、それにケルビムを織り出さなければならない。</span>
<span className="v" id="v2" data-v="2" data-xref="サムエル記下 7:2; 民数記 4:25; 歴代志上 17:1"> 幕の長さは、おのおの二十八キュビト、幕の幅は、おのおの四キュビトで、幕は皆同じ寸法でなければならない。</span>
<span className="v" id="v3" data-v="3" data-xref="出エジプト記 36:10; コロサイ人への手紙 2:2; エペソ人への手紙 2:21–22"> その幕五枚を互に連ね合わせ、また他の五枚の幕をも互に連ね合わせなければならない。</span>
<span className="v" id="v4" data-v="4" data-xref="出エジプト記 36:11–12; 出エジプト記 36:17; 出エジプト記 26:10–11"> その一連の端にある幕の縁に青色の乳をつけ、また他の一連の端にある幕の縁にもそのようにしなければならない。</span>
<span className="v" id="v5" data-v="5"> あなたは、その一枚の幕に乳五十をつけ、また他の一連の幕の端にも乳五十をつけ、その乳を互に相向かわせなければならない。</span>
<span className="v" id="v6" data-v="6" data-xref="出エジプト記 36:13; 出エジプト記 26:11; 出エジプト記 26:33"> あなたはまた金の輪五十を作り、その輪で幕を互に連ね合わせて一つの幕屋にしなければならない。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="出エジプト記 26:14; 詩篇 45:13; 出エジプト記 26:9"> また幕屋をおおう天幕のためにやぎの毛糸で幕を作らなければならない。すなわち幕十一枚を作り、</span>
<span className="v" id="v8" data-v="8" data-xref="出エジプト記 26:13; 出エジプト記 26:2"> その一枚の幕の長さは三十キュビト、その一枚の幕の幅は四キュビトで、その十一枚の幕は同じ寸法でなければならない。</span>
<span className="v" id="v9" data-v="9"> そして、その幕五枚を一つに連ね合わせ、またその幕六枚を一つに連ね合わせて、その六枚目の幕を天幕の前で折り重ねなければならない。</span>
<span className="v" id="v10" data-v="10"> またその一連の端にある幕の縁に乳五十をつけ、他の一連の幕の縁にも乳五十をつけなさい。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="出エジプト記 26:3; 出エジプト記 26:6"> そして青銅の輪五十を作り、その輪を乳に掛け、その天幕を連ね合わせて一つにし、</span>
<span className="v" id="v12" data-v="12"> その天幕の幕の残りの垂れる部分、すなわちその残りの半幕を幕屋のうしろに垂れさせなければならない。</span>
<span className="v" id="v13" data-v="13" data-xref="出エジプト記 26:2; 出エジプト記 26:8"> そして天幕の幕のたけで余るものの、こちらのキュビトと、あちらのキュビトとは、幕屋をおおうように、その両側のこちらとあちらとに垂れさせなければならない。</span>
<span className="v" id="v14" data-v="14" data-xref="出エジプト記 36:19; 出エジプト記 25:5; 出エジプト記 35:23"> また、あかね染めの雄羊の皮で天幕のおおいと、じゅごんの皮でその上にかけるおおいとを造らなければならない。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="出エジプト記 36:20–33; 民数記 4:31–32; 出エジプト記 40:17–18"> あなたは幕屋のために、アカシヤ材で立枠を造らなければならない。</span>
<span className="v" id="v16" data-v="16"> 枠の長さを十キュビト、枠の幅を一キュビト半とし、</span>
<span className="v" id="v17" data-v="17" data-xref="出エジプト記 36:22; 出エジプト記 26:19; 出エジプト記 36:24"> 枠ごとに二つの柄を造って、かれとこれとを食い合わさせ、幕屋のすべての枠にこのようにしなければならない。</span>
<span className="v" id="v18" data-v="18"> あなたは幕屋のために枠を造り、南側のために枠二十とし、</span>
<span className="v" id="v19" data-v="19" data-xref="出エジプト記 38:27; 出エジプト記 38:30–31; 出エジプト記 26:37"> その二十の枠の下に銀の座四十を造って、この枠の下に、その二つの柄のために二つの座を置き、かの枠の下にもその二つの柄のために二つの座を置かなければならない。</span>
<span className="v" id="v20" data-v="20"> また幕屋の他の側、すなわち北側のためにも枠二十を造り、</span>
<span className="v" id="v21" data-v="21"> その銀の座四十を造って、この枠の下に、二つの座を置き、かの枠の下にも二つの座を置かなければならない。</span>
<span className="v" id="v22" data-v="22"> また幕屋のうしろ、すなわち西側のために枠六つを造り、</span>
<span className="v" id="v23" data-v="23"> 幕屋のうしろの二つのすみのために枠二つを造らなければならない。</span>
<span className="v" id="v24" data-v="24" data-xref="出エジプト記 36:29–30; 詩篇 133:1–3; コリント人への第一の手紙 1:10"> これらは下で重なり合い、同じくその頂でも第一の環まで重なり合うようにし、その二つともそのようにしなければならない。それらは二つのすみのために設けるものである。</span>
<span className="v" id="v25" data-v="25"> こうしてその枠は八つ、その銀の座は十六、この枠の下に二つの座、かの枠の下にも二つの座を置かなければならない。</span>
<span className="v" id="v26" data-v="26" data-xref="ローマ人への手紙 15:1; 民数記 4:31; ガラテヤ人への手紙 6:1–2"> またアカシヤ材で横木を造らなければならない。すなわち幕屋のこの側の枠のために五つ、</span>
<span className="v" id="v27" data-v="27"> また幕屋のかの側の枠のために横木五つ、幕屋のうしろの西側の枠のために横木五つを造り、</span>
<span className="v" id="v28" data-v="28"> 枠のまん中にある中央の横木は端から端まで通るようにしなければならない。</span>
<span className="v" id="v29" data-v="29" data-xref="出エジプト記 25:11–12"> そしてその枠を金でおおい、また横木を通すその環を金で造り、また、その横木を金でおおわなければならない。</span>
<span className="v" id="v30" data-v="30" data-xref="出エジプト記 25:40; ヘブル人への手紙 8:5; 出エジプト記 25:9"> こうしてあなたは山で示された様式に従って幕屋を建てなければならない。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="マタイによる福音書 27:51; 歴代志下 3:14; 出エジプト記 36:35"> また青糸、紫糸、緋糸、亜麻の撚糸で垂幕を作り、巧みなわざをもって、それにケルビムを織り出さなければならない。</span>
<span className="v" id="v32" data-v="32" data-xref="出エジプト記 26:37; 出エジプト記 36:38; エステル記 1:6"> そして金でおおった四つのアカシヤ材の柱の金の鉤にこれを掛け、その柱は四つの銀の座の上にすえなければならない。</span>
<span className="v" id="v33" data-v="33" data-xref="ヘブル人への手紙 9:2–3; レビ記 16:2; 出エジプト記 40:21"> その垂幕の輪を鉤に掛け、その垂幕の内にあかしの箱を納めなさい。その垂幕はあなたがたのために聖所と至聖所とを隔て分けるであろう。</span>
<span className="v" id="v34" data-v="34" data-xref="出エジプト記 40:20; 出エジプト記 25:21; ヘブル人への手紙 9:5"> また至聖所にあるあかしの箱の上に贖罪所を置かなければならない。</span>
<span className="v" id="v35" data-v="35" data-xref="出エジプト記 40:24; 出エジプト記 40:22; ヘブル人への手紙 9:2"> そしてその垂幕の外に机を置き、幕屋の南側に、机に向かい合わせて燭台を置かなければならない。ただし机は北側に置かなければならない。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="出エジプト記 36:37; 民数記 9:15; 出エジプト記 26:31"> あなたはまた天幕の入口のために青糸、紫糸、緋糸、亜麻の撚糸で、色とりどりに織ったとばりを作らなければならない。</span>
<span className="v" id="v37" data-v="37" data-xref="出エジプト記 36:38"> あなたはそのとばりのためにアカシヤ材の柱五つを造り、これを金でおおい、その鉤を金で造り、またその柱のために青銅の座五つを鋳て造らなければならない。</span>
</div>
</div>

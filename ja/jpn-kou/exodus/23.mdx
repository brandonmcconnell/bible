<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="詩篇 101:5; 箴言 19:5; 申命記 19:16–21"> あなたは偽りのうわさを言いふらしてはならない。あなたは悪人と手を携えて、悪意のある証人になってはならない。</span>
<span className="v" id="v2" data-v="2" data-xref="箴言 1:10–11; 箴言 1:15; ルカによる福音書 23:23–24"> あなたは多数に従って悪をおこなってはならない。あなたは訴訟において、多数に従って片寄り、正義を曲げるような証言をしてはならない。</span>
<span className="v" id="v3" data-v="3" data-xref="ヤコブの手紙 3:17; レビ記 19:15; 詩篇 82:2–3"> また貧しい人をその訴訟において、曲げてかばってはならない。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="申命記 22:1–4; テサロニケ人への第一の手紙 5:15; マタイによる福音書 5:44"> もし、あなたが敵の牛または、ろばの迷っているのに会う時は、必ずこれを彼の所に連れて行って、帰さなければならない。</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 22:4"> もしあなたを憎む者のろばが、その荷物の下に倒れ伏しているのを見る時は、これを見捨てて置かないように気をつけ、必ずその人に手を貸して、これを起さなければならない。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="マラキ書 3:5; エレミヤ書 5:28; レビ記 19:15"> あなたは貧しい者の訴訟において、裁判を曲げてはならない。</span>
<span className="v" id="v7" data-v="7" data-xref="エペソ人への手紙 4:25; 出エジプト記 34:7; 出エジプト記 23:1"> あなたは偽り事に遠ざからなければならない。あなたは罪のない者と正しい者とを殺してはならない。わたしは悪人を義とすることはないからである。</span>
<span className="v" id="v8" data-v="8" data-xref="申命記 16:19; 箴言 17:23; イザヤ書 5:23"> あなたは賄賂を取ってはならない。賄賂は人の目をくらまし、正しい者の事件をも曲げさせるからである。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="申命記 27:19; 出エジプト記 22:21; 申命記 24:14–18"> あなたは寄留の他国人をしえたげてはならない。あなたがたはエジプトの国で寄留の他国人であったので、寄留の他国人の心を知っているからである。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="レビ記 25:3–4"> あなたは六年のあいだ、地に種をまき、その産物を取り入れることができる。</span>
<span className="v" id="v11" data-v="11" data-xref="レビ記 26:34–35; レビ記 25:2–7; レビ記 25:11–12"> しかし、七年目には、これを休ませて、耕さずに置かなければならない。そうすれば、あなたの民の貧しい者がこれを食べ、その残りは野の獣が食べることができる。あなたのぶどう畑も、オリブ畑も同様にしなければならない。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="ルカによる福音書 13:14; 出エジプト記 34:21; 出エジプト記 35:3"> あなたは六日のあいだ、仕事をし、七日目には休まなければならない。これはあなたの牛および、ろばが休みを得、またあなたのはしための子および寄留の他国人を休ませるためである。</span>
<span className="v" id="v13" data-v="13" data-xref="ヨシュア記 23:7; ゼカリヤ書 13:2; テモテヘの第一の手紙 4:16"> わたしが、あなたがたに言ったすべての事に心を留めなさい。他の神々の名を唱えてはならない。また、これをあなたのくちびるから聞えさせてはならない。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="申命記 16:16; 出エジプト記 34:22–24; レビ記 23:34"> あなたは年に三度、わたしのために祭を行わなければならない。</span>
<span className="v" id="v15" data-v="15" data-xref="ルカによる福音書 22:7; 出エジプト記 34:20; 民数記 28:16–25"> あなたは種入れぬパンの祭を守らなければならない。わたしが、あなたに命じたように、アビブの月の定めの時に七日のあいだ、種入れぬパンを食べなければならない。それはその月にあなたがエジプトから出たからである。だれも、むなし手でわたしの前に出てはならない。</span>
<span className="v" id="v16" data-v="16" data-xref="出エジプト記 34:22; 出エジプト記 22:29; レビ記 23:9–21"> また、あなたが畑にまいて獲た物の勤労の初穂をささげる刈入れの祭と、あなたの勤労の実を畑から取り入れる年の終りに、取入れの祭を行わなければならない。</span>
<span className="v" id="v17" data-v="17" data-xref="申命記 16:16; 出エジプト記 34:23; 出エジプト記 23:14"> 男子はみな、年に三度、主なる神の前に出なければならない。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="出エジプト記 34:25; レビ記 2:11; 申命記 16:4"> あなたはわたしの犠牲の血を、種を入れたパンと共にささげてはならない。また、わたしの祭の脂肪を翌朝まで残して置いてはならない。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="出エジプト記 34:26; 申命記 14:21; 申命記 26:10"> あなたの土地の初穂の最も良い物を、あなたの神、主の家に携えてこなければならない。あなたは子やぎを、その母の乳で煮てはならない。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="出エジプト記 33:14; 詩篇 91:11; 出エジプト記 32:34"> 見よ、わたしは使をあなたの前につかわし、あなたを道で守らせ、わたしが備えた所に導かせるであろう。</span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 78:56; 詩篇 78:40; ヘブル人への手紙 12:25"> あなたはその前に慎み、その言葉に聞き従い、彼にそむいてはならない。わたしの名が彼のうちにあるゆえに、彼はあなたがたのとがをゆるさないであろう。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="創世記 12:3; 申命記 30:7; ゼカリヤ書 2:8"> しかし、もしあなたが彼の声によく聞き従い、すべてわたしが語ることを行うならば、わたしはあなたの敵を敵とし、あなたのあだをあだとするであろう。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="出エジプト記 23:20; イザヤ書 5:13; 創世記 15:19–21"> わたしの使はあなたの前に行って、あなたをアモリびと、ヘテびと、ペリジびと、カナンびと、ヒビびと、およびエブスびとの所に導き、わたしは彼らを滅ぼすであろう。</span>
<span className="v" id="v24" data-v="24" data-xref="出エジプト記 20:5; 申命記 12:30–31; 民数記 33:52"> あなたは彼らの神々を拝んではならない。これに仕えてはならない。また彼らのおこないにならってはならない。あなたは彼らを全く打ち倒し、その石の柱を打ち砕かなければならない。</span>
<span className="v" id="v25" data-v="25" data-xref="申命記 7:15; 出エジプト記 15:26; ヨシュア記 22:5"> あなたがたの神、主に仕えなければならない。そうすれば、わたしはあなたがたのパンと水を祝し、あなたがたのうちから病を除き去るであろう。</span>
<span className="v" id="v26" data-v="26" data-xref="申命記 7:14; ヨブ記 5:26; 申命記 28:4"> あなたの国のうちには流産する女もなく、不妊の女もなく、わたしはあなたの日の数を満ち足らせるであろう。</span>
<span className="v" id="v27" data-v="27" data-xref="申命記 2:25; 創世記 35:5; 申命記 11:25"> わたしはあなたの先に、わたしの恐れをつかわし、あなたが行く所の民を、ことごとく打ち敗り、すべての敵に、その背をあなたの方へ向けさせるであろう。</span>
<span className="v" id="v28" data-v="28" data-xref="申命記 7:20; ヨシュア記 24:11–12"> わたしはまた、くまばちをあなたの先につかわすであろう。これはヒビびと、カナンびと、およびヘテびとをあなたの前から追い払うであろう。</span>
<span className="v" id="v29" data-v="29" data-xref="申命記 7:22; ヨシュア記 17:12–13; 士師記 3:1–4"> しかし、わたしは彼らを一年のうちには、あなたの前から追い払わないであろう。土地が荒れすたれ、野の獣が増して、あなたを害することのないためである。</span>
<span className="v" id="v30" data-v="30"> わたしは徐々に彼らをあなたの前から追い払うであろう。あなたは、ついにふえひろがって、この地を継ぐようになるであろう。</span>
<span className="v" id="v31" data-v="31" data-xref="創世記 15:18; 申命記 11:24; ヨシュア記 21:44"> わたしは紅海からペリシテびとの海に至るまでと、荒野からユフラテ川に至るまでを、あなたの領域とし、この地に住んでいる者をあなたの手にわたすであろう。あなたは彼らをあなたの前から追い払うであろう。</span>
<span className="v" id="v32" data-v="32" data-xref="申命記 7:2; 出エジプト記 34:12; 出エジプト記 34:15"> あなたは彼ら、および彼らの神々と契約を結んではならない。</span>
<span className="v" id="v33" data-v="33" data-xref="詩篇 106:36; 申命記 7:16; 出エジプト記 34:12"> 彼らはあなたの国に住んではならない。彼らがあなたをいざなって、わたしに対して罪を犯させることのないためである。もし、あなたが彼らの神に仕えるならば、それは必ずあなたのわなとなるであろう」。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 主はモーセに言われた、</span>
<span className="v" id="v2" data-v="2" data-xref="ルカによる福音書 2:23; 民数記 3:13; 申命記 15:19"> 「イスラエルの人々のうちで、すべてのういご、すなわちすべて初めに胎を開いたものを、人であれ、獣であれ、みな、わたしのために聖別しなければならない。それはわたしのものである」。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="申命記 24:18; 申命記 5:15; 出エジプト記 20:2"> モーセは民に言った、「あなたがたは、エジプトから、奴隷の家から出るこの日を覚えなさい。主が強い手をもって、あなたがたをここから導き出されるからである。種を入れたパンを食べてはならない。</span>
<span className="v" id="v4" data-v="4" data-xref="出エジプト記 34:18; 出エジプト記 23:15; 出エジプト記 12:2"> あなたがたはアビブの月のこの日に出るのである。</span>
<span className="v" id="v5" data-v="5" data-xref="出エジプト記 3:8; ヨシュア記 24:11; 出エジプト記 12:25–26"> 主があなたに与えると、あなたの先祖たちに誓われたカナンびと、ヘテびと、アモリびと、ヒビびと、エブスびとの地、乳と蜜との流れる地に、導き入れられる時、あなたはこの月にこの儀式を守らなければならない。</span>
<span className="v" id="v6" data-v="6" data-xref="出エジプト記 12:15–20; 出エジプト記 34:18; レビ記 23:8"> 七日のあいだ種入れぬパンを食べ、七日目には主に祭をしなければならない。</span>
<span className="v" id="v7" data-v="7" data-xref="出エジプト記 12:19; マタイによる福音書 16:6"> 種入れぬパンを七日のあいだ食べなければならない。種を入れたパンをあなたの所に置いてはならない。また、あなたの地区のどこでも、あなたの所にパン種を置いてはならない。</span>
<span className="v" id="v8" data-v="8" data-xref="出エジプト記 13:14; 出エジプト記 12:26–27; 詩篇 44:1"> その日、あなたの子に告げて言いなさい、『これはわたしがエジプトから出るときに、主がわたしになされたことのためである』。</span>
<span className="v" id="v9" data-v="9" data-xref="申命記 6:8; 申命記 11:18–19; 民数記 15:39"> そして、これを、手につけて、しるしとし、目の間に置いて記念とし、主の律法をあなたの口に置かなければならない。主が強い手をもって、あなたをエジプトから導き出されるからである。</span>
<span className="v" id="v10" data-v="10" data-xref="出エジプト記 12:14; 出エジプト記 12:24–25; 出エジプト記 23:15"> それゆえ、あなたはこの定めを年々その期節に守らなければならない。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="出エジプト記 13:5"> 主があなたとあなたの先祖たちに誓われたように、あなたをカナンびとの地に導いて、それをあなたに賜わる時、</span>
<span className="v" id="v12" data-v="12" data-xref="民数記 18:15; レビ記 27:26; 出エジプト記 34:19"> あなたは、すべて初めに胎を開いた者、およびあなたの家畜の産むういごは、ことごとく主にささげなければならない。すなわち、それらの男性のものは主に帰せしめなければならない。</span>
<span className="v" id="v13" data-v="13" data-xref="出エジプト記 34:20; 民数記 18:15–17; ヨハネの黙示録 14:4"> また、すべて、ろばの、初めて胎を開いたものは、小羊をもって、あがなわなければならない。もし、あがなわないならば、その首を折らなければならない。あなたの子らのうち、すべて、男のういごは、あがなわなければならない。</span>
<span className="v" id="v14" data-v="14" data-xref="出エジプト記 13:3; ヨシュア記 4:6; 詩篇 145:4"> 後になって、あなたの子が『これはどんな意味ですか』と問うならば、これに言わなければならない、『主が強い手をもって、われわれをエジプトから、奴隷の家から導き出された。</span>
<span className="v" id="v15" data-v="15" data-xref="出エジプト記 12:29"> そのときパロが、かたくなで、われわれを去らせなかったため、主はエジプトの国のういごを、人のういごも家畜のういごも、ことごとく殺された。それゆえ、初めて胎を開く男性のものはみな、主に犠牲としてささげるが、わたしの子供のうちのういごは、すべてあがなうのである』。</span>
<span className="v" id="v16" data-v="16" data-xref="出エジプト記 13:9; 申命記 11:18; 申命記 6:7–9"> そして、これを手につけて、しるしとし、目の間に置いて覚えとしなければならない。主が強い手をもって、われわれをエジプトから導き出されたからである」。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="出エジプト記 14:11–12; ネヘミヤ書 9:17; 民数記 14:1–4"> さて、パロが民を去らせた時、ペリシテびとの国の道は近かったが、神は彼らをそれに導かれなかった。民が戦いを見れば悔いてエジプトに帰るであろうと、神は思われたからである。</span>
<span className="v" id="v18" data-v="18" data-xref="出エジプト記 14:2; 申命記 32:10; 民数記 33:6–8"> 神は紅海に沿う荒野の道に、民を回らされた。イスラエルの人々は武装してエジプトの国を出て、上った。</span>
<span className="v" id="v19" data-v="19" data-xref="創世記 50:24–25; ヨシュア記 24:32; 使徒行伝 7:16"> そのときモーセはヨセフの遺骸を携えていた。ヨセフが、「神は必ずあなたがたを顧みられるであろう。そのとき、あなたがたは、わたしの遺骸を携えて、ここから上って行かなければならない」と言って、イスラエルの人々に固く誓わせたからである。</span>
<span className="v" id="v20" data-v="20" data-xref="民数記 33:5–6; 出エジプト記 12:37"> こうして彼らは更にスコテから進んで、荒野の端にあるエタムに宿営した。</span>
<span className="v" id="v21" data-v="21" data-xref="コリント人への第一の手紙 10:1–2; ネヘミヤ書 9:12; 申命記 1:33"> 主は彼らの前に行かれ、昼は雲の柱をもって彼らを導き、夜は火の柱をもって彼らを照し、昼も夜も彼らを進み行かせられた。</span>
<span className="v" id="v22" data-v="22" data-xref="詩篇 121:5–8; ヨハネの黙示録 10:1"> 昼は雲の柱、夜は火の柱が、民の前から離れなかった。</span>

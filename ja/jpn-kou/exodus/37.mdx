<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出エジプト記 25:10–20; 出エジプト記 26:33; 民数記 10:33–36"> ベザレルはアカシヤ材の箱を造った。長さは二キュビト半、幅は一キュビト半、高さは一キュビト半である。</span>
<span className="v" id="v2" data-v="2" data-xref="出エジプト記 30:3"> 純金で、内そとをおおい、その周囲に金の飾り縁を造った。</span>
<span className="v" id="v3" data-v="3"> また金の環四つを鋳て、その四すみに取りつけた。すなわち二つの環をこちら側に、二つの環をあちら側に取りつけた。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行伝 9:15; ペテロの第一の手紙 1:7; 民数記 4:14–15"> またアカシヤ材のさおを造り、金でこれをおおい、</span>
<span className="v" id="v5" data-v="5" data-xref="民数記 4:15; サムエル記下 6:3–7; 民数記 1:50"> そのさおを箱の側面の環に通して、箱をかつぐようにした。</span>
<span className="v" id="v6" data-v="6" data-xref="ヘブル人への手紙 9:5; テトスヘの手紙 2:14; ローマ人への手紙 3:25"> また純金で贖罪所を造った。長さは二キュビト半、幅は一キュビト半である。</span>
<span className="v" id="v7" data-v="7" data-xref="エゼキエル書 10:2; 詩篇 104:4; 詩篇 80:1"> また金で、二つのケルビムを造った。すなわち、これを打物造りとし、贖罪所の両端に置いた。</span>
<span className="v" id="v8" data-v="8"> 一つのケルブをこの端に、一つのケルブをかの端に置いた。すなわちケルビムを贖罪所の一部として、その両端に造った。</span>
<span className="v" id="v9" data-v="9" data-xref="ヨハネによる福音書 1:51; ヘブル人への手紙 1:14; 創世記 28:12"> ケルビムは翼を高く伸べ、その翼で贖罪所をおおい、顔は互に向かい合った。すなわちケルビムの顔は贖罪所に向かっていた。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="ヨハネによる福音書 1:14; エゼキエル書 40:39–42; マラキ書 1:12"> またアカシヤ材で、机を造った。長さは二キュビト、幅は一キュビト、高さは一キュビト半である。</span>
<span className="v" id="v11" data-v="11"> 純金でこれをおおい、その周囲に金の飾り縁を造った。</span>
<span className="v" id="v12" data-v="12"> またその周囲に手幅の棧を造り、その周囲の棧に金の飾り縁を造った。</span>
<span className="v" id="v13" data-v="13"> またこれがために金の環四つを鋳て、その四つの足のすみ四か所にその環を取りつけた。</span>
<span className="v" id="v14" data-v="14"> その環は棧のわきにあって、机をかつぐさおを入れる所とした。</span>
<span className="v" id="v15" data-v="15"> またアカシヤ材で、机をかつぐさおを造り、金でこれをおおった。</span>
<span className="v" id="v16" data-v="16" data-xref="出エジプト記 25:29; 列王紀上 7:50; 列王紀下 12:13"> また机の上の器、すなわちその皿、乳香を盛る杯および灌祭を注ぐための鉢と瓶とを純金で造った。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="出エジプト記 25:31–39; ヘブル人への手紙 9:2; 歴代志下 13:11"> また純金の燭台を造った。すなわち打物造りで燭台を造り、その台、幹、萼、節、花を一つに連ねた。</span>
<span className="v" id="v18" data-v="18"> また六つの枝をそのわきから出させた。すなわち燭台の三つの枝をこの側から、燭台の三つの枝をかの側から出させた。</span>
<span className="v" id="v19" data-v="19"> あめんどうの花の形をした三つの萼が、節と花とをもって、この枝にあり、また、あめんどうの花の形をした三つの萼が、節と花とをもって、かの枝にあり、燭台から出る六つの枝をみなそのようにした。</span>
<span className="v" id="v20" data-v="20" data-xref="伝道の書 12:5; エレミヤ書 1:11; 出エジプト記 25:33"> また燭台の幹には、あめんどうの花の形をした四つの萼を、その節と花とをもたせて取りつけた。</span>
<span className="v" id="v21" data-v="21" data-xref="出エジプト記 25:35"> また二つの枝の下に一つの節を取りつけ、次の二つの枝の下に一つの節を取りつけ、さらに次の二つの枝の下に一つの節を取りつけ、燭台の幹から出る六つの枝に、みなそのようにした。</span>
<span className="v" id="v22" data-v="22" data-xref="コロサイ人への手紙 3:5; 出エジプト記 25:31; 詩篇 51:17"> それらの節と枝を一つに連ね、ことごとく純金の打物造りとした。</span>
<span className="v" id="v23" data-v="23" data-xref="ヨハネの黙示録 1:12; 出エジプト記 25:37; ヨハネの黙示録 1:20–1"> また、それのともしび皿七つと、その芯切りばさみと、芯取り皿とを純金で造った。</span>
<span className="v" id="v24" data-v="24"> すなわち純金一タラントをもって、燭台とそのすべての器とを造った。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="出エジプト記 30:1–5; ヘブル人への手紙 7:25; ヨハネの黙示録 8:3–4"> またアカシヤ材で香の祭壇を造った。長さ一キュビト、幅一キュビトの四角にし、高さ二キュビトで、これにその一部として角をつけた。</span>
<span className="v" id="v26" data-v="26"> そして、その頂、その周囲の側面、その角を純金でおおい、その周囲に金の飾り縁を造った。</span>
<span className="v" id="v27" data-v="27"> また、その両側に、飾り縁の下に金の環二つを、そのために造った。すなわちその二つの側にこれを造った。これはそれをかつぐさおを通す所である。</span>
<span className="v" id="v28" data-v="28"> そのさおはアカシヤ材で造り、金でこれをおおった。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="詩篇 141:2; ヘブル人への手紙 7:25; ヨハネの第一の手紙 2:20"> また香料を造るわざにしたがって、聖なる注ぎ油と純粋の香料の薫香とを造った。</span>
</div>

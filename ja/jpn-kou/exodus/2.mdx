<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数記 26:59; 歴代志上 23:12–14; 出エジプト記 6:16–20"> さて、レビの家のひとりの人が行ってレビの娘をめとった。</span>
<span className="v" id="v2" data-v="2" data-xref="ヘブル人への手紙 11:23; 使徒行伝 7:20; 詩篇 112:5"> 女はみごもって、男の子を産んだが、その麗しいのを見て、三月のあいだ隠していた。</span>
<span className="v" id="v3" data-v="3" data-xref="出エジプト記 1:22; 使徒行伝 7:19; 創世記 6:14"> しかし、もう隠しきれなくなったので、パピルスで編んだかごを取り、それにアスファルトと樹脂とを塗って、子をその中に入れ、これをナイル川の岸の葦の中においた。</span>
<span className="v" id="v4" data-v="4" data-xref="民数記 26:59; 出エジプト記 15:20; ミカ書 6:4"> その姉は、彼がどうされるかを知ろうと、遠く離れて立っていた。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行伝 7:21; 詩篇 12:5; 詩篇 9:9"> ときにパロの娘が身を洗おうと、川に降りてきた。侍女たちは川べを歩いていたが、彼女は、葦の中にかごのあるのを見て、つかえめをやり、それを取ってこさせ、</span>
<span className="v" id="v6" data-v="6" data-xref="列王紀上 8:50; ペテロの第一の手紙 3:8; 使徒行伝 7:21"> あけて見ると子供がいた。見よ、幼な子は泣いていた。彼女はかわいそうに思って言った、「これはヘブルびとの子供です」。</span>
<span className="v" id="v7" data-v="7" data-xref="出エジプト記 2:4; 民数記 26:59; 民数記 12:1"> そのとき幼な子の姉はパロの娘に言った、「わたしが行ってヘブルの女のうちから、あなたのために、この子に乳を飲ませるうばを呼んでまいりましょうか」。</span>
<span className="v" id="v8" data-v="8" data-xref="イザヤ書 46:3–4; 詩篇 27:10; 出エジプト記 6:20"> パロの娘が「行ってきてください」と言うと、少女は行ってその子の母を呼んできた。</span>
<span className="v" id="v9" data-v="9"> パロの娘は彼女に言った、「この子を連れて行って、わたしに代り、乳を飲ませてください。わたしはその報酬をさしあげます」。女はその子を引き取って、これに乳を与えた。</span>
<span className="v" id="v10" data-v="10" data-xref="ヘブル人への手紙 11:24; 創世記 16:11; サムエル記上 1:20"> その子が成長したので、彼女はこれをパロの娘のところに連れて行った。そして彼はその子となった。彼女はその名をモーセと名づけて言った、「水の中からわたしが引き出したからです」。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="ヘブル人への手紙 11:24–26; 使徒行伝 7:22–24; 出エジプト記 1:11"> モーセが成長して後、ある日のこと、同胞の所に出て行って、そのはげしい労役を見た。彼はひとりのエジプトびとが、同胞のひとりであるヘブルびとを打つのを見たので、</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行伝 7:24–26"> 左右を見まわし、人のいないのを見て、そのエジプトびとを打ち殺し、これを砂の中に隠した。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行伝 7:26–28; コリント人への第一の手紙 6:7–8"> 次の日また出て行って、ふたりのヘブルびとが互に争っているのを見、悪い方の男に言った、「あなたはなぜ、あなたの友を打つのですか」。</span>
<span className="v" id="v14" data-v="14" data-xref="ルカによる福音書 12:14; マタイによる福音書 21:23; 創世記 19:9"> 彼は言った、「だれがあなたを立てて、われわれのつかさ、また裁判人としたのですか。エジプトびとを殺したように、あなたはわたしを殺そうと思うのですか」。モーセは恐れた。そしてあの事がきっと知れたのだと思った。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行伝 7:29; ヘブル人への手紙 11:27; 創世記 24:11"> パロはこの事を聞いて、モーセを殺そうとした。<br />しかしモーセはパロの前をのがれて、ミデヤンの地に行き、井戸のかたわらに座していた。</span>
<span className="v" id="v16" data-v="16" data-xref="創世記 24:11; 出エジプト記 3:1; サムエル記上 9:11"> さて、ミデヤンの祭司に七人の娘があった。彼女たちはきて水をくみ、水槽にみたして父の羊の群れに飲ませようとしたが、</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 29:10; 創世記 21:25; 創世記 26:15–22"> 羊飼たちがきて彼女らを追い払ったので、モーセは立ち上がって彼女たちを助け、その羊の群れに水を飲ませた。</span>
<span className="v" id="v18" data-v="18" data-xref="出エジプト記 3:1; 民数記 10:29; 出エジプト記 4:18"> 彼女たちが父リウエルのところに帰った時、父は言った、「きょうは、どうして、こんなに早く帰ってきたのか」。</span>
<span className="v" id="v19" data-v="19" data-xref="創世記 50:11; 創世記 29:10"> 彼女たちは言った、「ひとりのエジプトびとが、わたしたちを羊飼たちの手から助け出し、そのうえ、水をたくさんくんで、羊の群れに飲ませてくれたのです」。</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 31:54; 創世記 43:25; ヘブル人への手紙 13:2"> 彼は娘たちに言った、「そのかたはどこにおられるか。なぜ、そのかたをおいてきたのか。呼んできて、食事をさしあげなさい」。</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 31:38–40; ヘブル人への手紙 13:5; ヘブル人への手紙 11:25"> モーセがこの人と共におることを好んだので、彼は娘のチッポラを妻としてモーセに与えた。</span>
<span className="v" id="v22" data-v="22" data-xref="ヘブル人への手紙 11:13–14; 使徒行伝 7:29; 出エジプト記 22:21"> 彼女が男の子を産んだので、モーセはその名をゲルショムと名づけた。「わたしは外国に寄留者となっている」と言ったからである。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="創世記 18:20–21; ヤコブの手紙 5:4; 出エジプト記 3:7–9"> 多くの日を経て、エジプトの王は死んだ。イスラエルの人々は、その苦役の務のゆえにうめき、また叫んだが、その苦役のゆえの叫びは神に届いた。</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 26:3; 詩篇 105:42; 出エジプト記 6:5"> 神は彼らのうめきを聞き、神はアブラハム、イサク、ヤコブとの契約を覚え、</span>
<span className="v" id="v25" data-v="25" data-xref="出エジプト記 4:31; 詩篇 55:22; 出エジプト記 3:7–8"> 神はイスラエルの人々を顧み、神は彼らをしろしめされた。</span>
</div>

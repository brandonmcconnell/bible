<span className="v" id="v1" data-v="1"> 主はモーセに言われた、</span>
<span className="v" id="v2" data-v="2" data-xref="出エジプト記 36:1; 出エジプト記 35:30; ヨハネによる福音書 3:27"> 「見よ、わたしはユダの部族に属するホルの子なるウリの子ベザレルを名ざして召し、</span>
<span className="v" id="v3" data-v="3" data-xref="出エジプト記 35:31; イザヤ書 28:26; 列王紀上 7:14"> これに神の霊を満たして、知恵と悟りと知識と諸種の工作に長ぜしめ、</span>
<span className="v" id="v4" data-v="4" data-xref="出エジプト記 26:1; 出エジプト記 25:32–35; 歴代志下 2:13–14"> 工夫を凝らして金、銀、青銅の細工をさせ、</span>
<span className="v" id="v5" data-v="5" data-xref="出エジプト記 28:9–21"> また宝石を切りはめ、木を彫刻するなど、諸種の工作をさせるであろう。</span>
<span className="v" id="v6" data-v="6" data-xref="出エジプト記 35:10; 出エジプト記 35:34–1; 出エジプト記 28:3"> 見よ、わたしはまたダンの部族に属するアヒサマクの子アホリアブを彼と共ならせ、そしてすべて賢い者の心に知恵を授け、わたしがあなたに命じたものを、ことごとく彼らに造らせるであろう。</span>
<span className="v" id="v7" data-v="7" data-xref="出エジプト記 36:8–9; 出エジプト記 25:10–22; 出エジプト記 26:1–37"> すなわち会見の幕屋、あかしの箱、その上にある贖罪所、幕屋のもろもろの器、</span>
<span className="v" id="v8" data-v="8" data-xref="出エジプト記 37:10–28; 出エジプト記 30:1–10; 出エジプト記 25:23–40"> 机とその器、純金の燭台と、そのもろもろの器、香の祭壇、</span>
<span className="v" id="v9" data-v="9" data-xref="出エジプト記 38:1–8; 出エジプト記 27:1–8; 出エジプト記 40:11"> 燔祭の祭壇とそのもろもろの器、洗盤とその台、</span>
<span className="v" id="v10" data-v="10" data-xref="民数記 4:5–14; 出エジプト記 28:1–43; 出エジプト記 39:1–43"> 編物の服、すなわち祭司の務をするための祭司アロンの聖なる服、およびその子たちの服、</span>
<span className="v" id="v11" data-v="11" data-xref="出エジプト記 37:29; 出エジプト記 30:23–38"> 注ぎ油、聖所のための香ばしい香などを、すべてわたしがあなたに命じたように造らせるであろう」。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12"> 主はまたモーセに言われた、</span>
<span className="v" id="v13" data-v="13" data-xref="エゼキエル書 20:12; エゼキエル書 20:20; レビ記 19:30"> 「あなたはイスラエルの人々に言いなさい、『あなたがたは必ずわたしの安息日を守らなければならない。これはわたしとあなたがたとの間の、代々にわたるしるしであって、わたしがあなたがたを聖別する主であることを、知らせるためのものである。</span>
<span className="v" id="v14" data-v="14" data-xref="出エジプト記 35:2–3; 民数記 15:32–36; エゼキエル書 20:21"> それゆえ、あなたがたは安息日を守らなければならない。これはあなたがたに聖なる日である。すべてこれを汚す者は必ず殺され、すべてこの日に仕事をする者は、民のうちから断たれるであろう。</span>
<span className="v" id="v15" data-v="15" data-xref="創世記 2:2; 出エジプト記 16:23; レビ記 23:3"> 六日のあいだは仕事をしなさい。七日目は全き休みの安息日で、主のために聖である。すべて安息日に仕事をする者は必ず殺されるであろう。</span>
<span className="v" id="v16" data-v="16" data-xref="エレミヤ書 50:5; 創世記 9:13; 創世記 17:11"> ゆえに、イスラエルの人々は安息日を覚え、永遠の契約として、代々安息日を守らなければならない。</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 1:31; 出エジプト記 31:13; 創世記 2:2–3"> これは永遠にわたしとイスラエルの人々との間のしるしである。それは主が六日のあいだに天地を造り、七日目に休み、かつ、いこわれたからである』」。</span>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出エジプト記 2:16; 詩篇 77:14–15; 出エジプト記 3:1"> さて、モーセのしゅうと、ミデアンの祭司エテロは、神がモーセと、み民イスラエルとにされたすべての事、主がイスラエルをエジプトから導き出されたことを聞いた。</span>
<span className="v" id="v2" data-v="2" data-xref="出エジプト記 2:21; 出エジプト記 4:25–26"> それでモーセのしゅうと、エテロは、さきに送り返されていたモーセの妻チッポラと、</span>
<span className="v" id="v3" data-v="3" data-xref="出エジプト記 2:22; 使徒行伝 7:29; 詩篇 39:12"> そのふたりの子とを連れてきた。そのひとりの名はゲルショムといった。モーセが、「わたしは外国で寄留者となっている」と言ったからである。</span>
<span className="v" id="v4" data-v="4" data-xref="ヘブル人への手紙 13:6; テモテヘの第二の手紙 4:17; コリント人への第二の手紙 1:8–10"> ほかのひとりの名はエリエゼルといった。「わたしの父の神はわたしの助けであって、パロのつるぎからわたしを救われた」と言ったからである。</span>
<span className="v" id="v5" data-v="5" data-xref="出エジプト記 3:1; 出エジプト記 3:12; 出エジプト記 24:16–17"> こうしてモーセのしゅうと、エテロは、モーセの妻子を伴って、荒野に行き、神の山に宿営しているモーセの所にきた。</span>
<span className="v" id="v6" data-v="6"> その時、ある人がモーセに言った、「ごらんなさい。あなたのしゅうと、エテロは、あなたの妻とそのふたりの子を連れて、あなたの所にこられます」。</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 29:13; 創世記 14:17; サムエル記下 11:7"> そこでモーセはしゅうとを出迎えて、身をかがめ、彼に口づけして、互に安否を問い、共に天幕にはいった。</span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 145:4–12; ネヘミヤ書 9:9–15; 詩篇 107:2"> そしてモーセは、主がイスラエルのために、パロとエジプトびととにされたすべての事、道で出会ったすべての苦しみ、また主が彼らを救われたことを、しゅうとに物語ったので、</span>
<span className="v" id="v9" data-v="9" data-xref="コリント人への第一の手紙 12:26; ローマ人への手紙 12:15; イザヤ書 66:10"> エテロは主がイスラエルをエジプトびとの手から救い出して、もろもろの恵みを賜わったことを喜んだ。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="創世記 14:20; サムエル記下 18:28; ルカによる福音書 1:68"> そしてエテロは言った、「主はほむべきかな。主はあなたがたをエジプトびとの手と、パロの手から救い出し、民をエジプトびとの手の下から救い出された。</span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 95:3; 出エジプト記 15:11; 歴代志下 2:5"> 今こそわたしは知った。実に彼らはイスラエルびとにむかって高慢にふるまったが、主はあらゆる神々にまさって大いにいますことを」。</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 31:54; 申命記 12:7; 出エジプト記 24:11"> そしてモーセのしゅうとエテロは燔祭と犠牲を神に供え、アロンとイスラエルの長老たちもみなきて、モーセのしゅうとと共に神の前で食事をした。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="イザヤ書 16:5; ヨブ記 29:7; 士師記 5:10"> あくる日モーセは座して民をさばいたが、民は朝から晩まで、モーセのまわりに立っていた。</span>
<span className="v" id="v14" data-v="14"> モーセのしゅうとは、彼がすべて民にしていることを見て、言った、「あなたが民にしているこのことはなんですか。あなたひとりが座し、民はみな朝から晩まで、あなたのまわりに立っているのはなぜですか」。</span>
<span className="v" id="v15" data-v="15" data-xref="民数記 15:34; 民数記 27:5; 民数記 9:8"> モーセはしゅうとに言った、「民が神に伺おうとして、わたしの所に来るからです。</span>
<span className="v" id="v16" data-v="16" data-xref="出エジプト記 24:14; コリント人への第一の手紙 6:1; サムエル記下 15:3"> 彼らは事があれば、わたしの所にきます。わたしは相互の間をさばいて、神の定めと判決を知らせるのです」。</span>
<span className="v" id="v17" data-v="17"> モーセのしゅうとは彼に言った、「あなたのしていることは良くない。</span>
<span className="v" id="v18" data-v="18" data-xref="民数記 11:14–17; 使徒行伝 6:1–4; コリント人への第二の手紙 12:15"> あなたも、あなたと一緒にいるこの民も、必ず疲れ果てるであろう。このことはあなたに重過ぎるから、ひとりですることができない。</span>
<span className="v" id="v19" data-v="19" data-xref="民数記 27:5; 申命記 5:5; 出エジプト記 20:19"> 今わたしの言うことを聞きなさい。わたしはあなたに助言する。どうか神があなたと共にいますように。あなたは民のために神の前にいて、事件を神に述べなさい。</span>
<span className="v" id="v20" data-v="20" data-xref="申命記 5:1; 詩篇 143:8; 申命記 1:18"> あなたは彼らに定めと判決を教え、彼らの歩むべき道と、なすべき事を彼らに知らせなさい。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行伝 6:3; 申命記 1:13–17; 歴代志下 19:5–10"> また、すべての民のうちから、有能な人で、神を恐れ、誠実で不義の利を憎む人を選び、それを民の上に立てて、千人の長、百人の長、五十人の長、十人の長としなさい。</span>
<span className="v" id="v22" data-v="22" data-xref="民数記 11:17; 民数記 27:2; 民数記 15:33"> 平素は彼らに民をさばかせ、大事件はすべてあなたの所に持ってこさせ、小事件はすべて彼らにさばかせなさい。こうしてあなたを身軽にし、あなたと共に彼らに、荷を負わせなさい。</span>
<span className="v" id="v23" data-v="23" data-xref="サムエル記上 8:6–7; 出エジプト記 18:18; サムエル記上 8:22"> あなたが、もしこの事を行い、神もまたあなたに命じられるならば、あなたは耐えることができ、この民もまた、みな安んじてその所に帰ることができよう」。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="エズラ記 10:2; 出エジプト記 18:19; 出エジプト記 18:2–5"> モーセはしゅうとの言葉に従い、すべて言われたようにした。</span>
<span className="v" id="v25" data-v="25" data-xref="申命記 1:15; 出エジプト記 18:21; 使徒行伝 6:5"> すなわち、モーセはすべてのイスラエルのうちから有能な人を選んで、民の上に長として立て、千人の長、百人の長、五十人の長、十人の長とした。</span>
<span className="v" id="v26" data-v="26" data-xref="出エジプト記 18:22; 出エジプト記 18:14–15; 申命記 17:8"> 平素は彼らが民をさばき、むずかしい事件はモーセに持ってきたが、小さい事件はすべて彼らみずからさばいた。</span>
<span className="v" id="v27" data-v="27" data-xref="民数記 10:29–30; 士師記 19:9; 創世記 31:55"> こうしてモーセはしゅうとを送り返したので、その国に帰って行った。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出エジプト記 12:33; 出エジプト記 12:31; 出エジプト記 3:19–20"> 主はモーセに言われた、「今、あなたは、わたしがパロに何をしようとしているかを見るであろう。すなわちパロは強い手にしいられて、彼らを去らせるであろう。否、彼は強い手にしいられて、彼らを国から追い出すであろう」。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="エレミヤ書 9:24; マラキ書 3:6; 使徒行伝 17:24–25"> 神はモーセに言われた、「わたしは主である。</span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 83:18; 詩篇 68:4; 創世記 17:1"> わたしはアブラハム、イサク、ヤコブには全能の神として現れたが、主という名では、自分を彼らに知らせなかった。</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 28:4; 創世記 15:18; 創世記 17:7–8"> わたしはまたカナンの地、すなわち彼らが寄留したその寄留の地を、彼らに与えるという契約を彼らと立てた。</span>
<span className="v" id="v5" data-v="5" data-xref="出エジプト記 2:24; 詩篇 106:44–45; イザヤ書 63:9"> わたしはまた、エジプトびとが奴隷としているイスラエルの人々のうめきを聞いて、わたしの契約を思い出した。</span>
<span className="v" id="v6" data-v="6" data-xref="申命記 26:8; 歴代志上 17:21; 出エジプト記 7:4"> それゆえ、イスラエルの人々に言いなさい、『わたしは主である。わたしはあなたがたをエジプトびとの労役の下から導き出し、奴隷の務から救い、また伸べた腕と大いなるさばきをもって、あなたがたをあがなうであろう。</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 7:6; 申命記 29:13; 申命記 4:20"> わたしはあなたがたを取ってわたしの民とし、わたしはあなたがたの神となる。わたしがエジプトびとの労役の下からあなたがたを導き出すあなたがたの神、主であることを、あなたがたは知るであろう。</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 26:3; 創世記 15:18; エゼキエル書 20:42"> わたしはアブラハム、イサク、ヤコブに与えると手を挙げて誓ったその地にあなたがたをはいらせ、それを所有として、与えるであろう。わたしは主である』と」。</span>
<span className="v" id="v9" data-v="9" data-xref="出エジプト記 5:21; ヨブ記 21:4; 出エジプト記 14:12"> モーセはこのようにイスラエルの人々に語ったが、彼らは心の痛みと、きびしい奴隷の務のゆえに、モーセに聞き従わなかった。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10"> さて主はモーセに言われた、</span>
<span className="v" id="v11" data-v="11" data-xref="出エジプト記 6:29; 出エジプト記 5:23; 出エジプト記 3:10"> 「エジプトの王パロのところに行って、彼がイスラエルの人々をその国から去らせるように話しなさい」。</span>
<span className="v" id="v12" data-v="12" data-xref="出エジプト記 4:10; エレミヤ書 1:6; 出エジプト記 6:30"> モーセは主にむかって言った、「イスラエルの人々でさえ、わたしの言うことを聞かなかったのに、どうして、くちびるに割礼のないわたしの言うことを、パロが聞き入れましょうか」。</span>
<span className="v" id="v13" data-v="13" data-xref="民数記 27:23; テモテヘの第一の手紙 6:13; 詩篇 91:11"> しかし、主はモーセとアロンに語って、イスラエルの人々と、エジプトの王パロのもとに行かせ、イスラエルの人々をエジプトの地から導き出せと命じられた。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="創世記 46:9; 歴代志上 5:3; 民数記 26:5–7"> 彼らの先祖の家の首長たちは次のとおりである。すなわちイスラエルの長子ルベンの子らはハノク、パル、ヘヅロン、カルミで、これらはルベンの一族である。</span>
<span className="v" id="v15" data-v="15" data-xref="歴代志上 4:24; 創世記 46:10; 民数記 26:12–13"> シメオンの子らはエムエル、ヤミン、オハデ、ヤキン、ゾハル、およびカナンの女から生れたシャウルで、これらはシメオンの一族である。</span>
<span className="v" id="v16" data-v="16" data-xref="民数記 3:17; 創世記 46:11; 歴代志上 6:1"> レビの子らの名は、その世代に従えば、ゲルション、コハテ、メラリで、レビの一生は百三十七年であった。</span>
<span className="v" id="v17" data-v="17" data-xref="歴代志上 6:17; 民数記 3:18; 歴代志上 23:7"> ゲルションの子らの一族はリブニとシメイである。</span>
<span className="v" id="v18" data-v="18" data-xref="歴代志上 6:18; 歴代志上 6:2; 民数記 3:19"> コハテの子らはアムラム、イヅハル、ヘブロン、ウジエルで、コハテの一生は百三十三年であった。</span>
<span className="v" id="v19" data-v="19" data-xref="民数記 3:20; 歴代志上 23:21; 歴代志上 6:19"> メラリの子らはマヘリとムシである。これらはその世代によるレビの一族である。</span>
<span className="v" id="v20" data-v="20" data-xref="民数記 26:59; 出エジプト記 2:1–2; 出エジプト記 6:18"> アムラムは父の妹ヨケベデを妻としたが、彼女はアロンとモーセを彼に産んだ。アムラムの一生は百三十七年であった。</span>
<span className="v" id="v21" data-v="21" data-xref="民数記 16:1; 歴代志上 6:37–38; 民数記 16:32"> イヅハルの子らはコラ、ネペグ、ジクリである。</span>
<span className="v" id="v22" data-v="22" data-xref="レビ記 10:4; 民数記 3:30; ネヘミヤ書 3:20"> ウジエルの子らはミサエル、エルザパン、シテリである。</span>
<span className="v" id="v23" data-v="23" data-xref="ルツ記 4:19–20; 民数記 2:3; 民数記 1:7"> アロンはナションの姉妹、アミナダブの娘エリセバを妻とした。エリセバは彼にナダブ、アビウ、エレアザル、イタマルを産んだ。</span>
<span className="v" id="v24" data-v="24" data-xref="歴代志上 6:22–23; 民数記 16:1; サムエル記上 1:1"> コラの子らはアッシル、エルカナ、アビアサフで、これらはコラびとの一族である。</span>
<span className="v" id="v25" data-v="25" data-xref="ヨシュア記 24:33; 民数記 25:7–13; ヨシュア記 22:31–32"> アロンの子エレアザルはプテエルの娘のひとりを妻とした。彼女はピネハスを彼に産んだ。これらは、その一族によるレビびとの先祖の家の首長たちである。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="出エジプト記 12:51; 出エジプト記 12:17; 出エジプト記 7:4"> 主が、「イスラエルの人々をその軍団に従って、エジプトの地から導き出しなさい」と言われたのは、このアロンとモーセである。</span>
<span className="v" id="v27" data-v="27" data-xref="出エジプト記 6:26; 出エジプト記 7:10; 詩篇 77:20"> 彼らはイスラエルの人々をエジプトから導き出すことについて、エジプトの王パロに語ったもので、すなわちこのモーセとアロンである。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28"> 主がエジプトの地でモーセに語られた日に、</span>
<span className="v" id="v29" data-v="29" data-xref="出エジプト記 6:11; 出エジプト記 7:2; 出エジプト記 6:2"> 主はモーセに言われた、「わたしは主である。わたしがあなたに語ることは、みなエジプトの王パロに語りなさい」。</span>
<span className="v" id="v30" data-v="30" data-xref="出エジプト記 6:12; 出エジプト記 4:10; コリント人への第一の手紙 9:16–17"> しかしモーセは主にむかって言った、「ごらんのとおり、わたしは、くちびるに割礼のない者です。パロがどうしてわたしの言うことを聞きいれましょうか」。</span>
</div>

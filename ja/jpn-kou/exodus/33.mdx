<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 12:7; 出エジプト記 32:13; 出エジプト記 32:7"> さて、主はモーセに言われた、「あなたと、あなたがエジプトの国から導きのぼった民とは、ここを立ってわたしがアブラハム、イサク、ヤコブに誓って、『これをあなたの子孫に与える』と言った地にのぼりなさい。</span>
<span className="v" id="v2" data-v="2" data-xref="出エジプト記 32:34; ヨシュア記 24:11; 出エジプト記 23:27–31"> わたしはひとりの使をつかわしてあなたに先立たせ、カナンびと、アモリびと、ヘテびと、ペリジびと、ヒビびと、エブスびとを追い払うであろう。</span>
<span className="v" id="v3" data-v="3" data-xref="出エジプト記 32:9–10; 出エジプト記 3:8; 使徒行伝 7:51"> あなたがたは乳と蜜の流れる地にのぼりなさい。しかし、あなたがたは、かたくなな民であるから、わたしが道であなたがたを滅ぼすことのないように、あなたがたのうちにあって一緒にはのぼらないであろう」。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="民数記 14:39; 民数記 14:1; エゼキエル書 26:16"> 民はこの悪い知らせを聞いて憂い、ひとりもその飾りを身に着ける者はなかった。</span>
<span className="v" id="v5" data-v="5" data-xref="民数記 16:21; 民数記 16:45–46; 出エジプト記 33:3–4"> 主はモーセに言われた、「イスラエルの人々に言いなさい、『あなたがたは、かたくなな民である。もしわたしが一刻でも、あなたがたのうちにあって、一緒にのぼって行くならば、あなたがたを滅ぼすであろう。ゆえに、今、あなたがたの飾りを身から取り去りなさい。そうすればわたしはあなたがたになすべきことを知るであろう』」。</span>
<span className="v" id="v6" data-v="6" data-xref="出エジプト記 33:4; 出エジプト記 32:3; エレミヤ書 2:19"> それで、イスラエルの人々はホレブ山以来その飾りを取り除いていた。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="イザヤ書 55:6–7; 出エジプト記 29:42–43; 箴言 15:29"> モーセは幕屋を取って、これを宿営の外に、宿営を離れて張り、これを会見の幕屋と名づけた。すべて主に伺い事のある者は出て、宿営の外にある会見の幕屋に行った。</span>
<span className="v" id="v8" data-v="8" data-xref="民数記 16:27"> モーセが出て、幕屋に行く時には、民はみな立ちあがり、モーセが幕屋にはいるまで、おのおのその天幕の入口に立って彼を見送った。</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 99:7; 出エジプト記 31:18; 出エジプト記 13:21–22"> モーセが幕屋にはいると、雲の柱が下って幕屋の入口に立った。そして主はモーセと語られた。</span>
<span className="v" id="v10" data-v="10" data-xref="列王紀上 8:22; 列王紀上 8:14; 出エジプト記 4:31"> 民はみな幕屋の入口に雲の柱が立つのを見ると、立っておのおの自分の天幕の入口で礼拝した。</span>
<span className="v" id="v11" data-v="11" data-xref="民数記 12:8; 申命記 34:10; 出エジプト記 24:13"> 人がその友と語るように、主はモーセと顔を合わせて語られた。こうしてモーセは宿営に帰ったが、その従者なる若者、ヌンの子ヨシュアは幕屋を離れなかった。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="出エジプト記 33:17; エレミヤ書 1:5; ヨハネによる福音書 10:14–15"> モーセは主に言った、「ごらんください。あなたは『この民を導きのぼれ』とわたしに言いながら、わたしと一緒につかわされる者を知らせてくださいません。しかも、あなたはかつて『わたしはお前を選んだ。お前はまたわたしの前に恵みを得た』と仰せになりました。</span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 119:33; 詩篇 25:4; 詩篇 27:11"> それで今、わたしがもし、あなたの前に恵みを得ますならば、どうか、あなたの道を示し、あなたをわたしに知らせ、あなたの前に恵みを得させてください。また、この国民があなたの民であることを覚えてください」。</span>
<span className="v" id="v14" data-v="14" data-xref="ヨシュア記 21:44; マタイによる福音書 11:28; ヨシュア記 1:5"> 主は言われた「わたし自身が一緒に行くであろう。そしてあなたに安息を与えるであろう」。</span>
<span className="v" id="v15" data-v="15" data-xref="出エジプト記 34:9; 詩篇 4:6; 出エジプト記 33:3"> モーセは主に言った「もしあなた自身が一緒に行かれないならば、わたしたちをここからのぼらせないでください。</span>
<span className="v" id="v16" data-v="16" data-xref="申命記 4:7; 民数記 14:14; 列王紀上 8:53"> わたしとあなたの民とが、あなたの前に恵みを得ることは、何によって知られましょうか。それはあなたがわたしたちと一緒に行かれて、わたしとあなたの民とが、地の面にある諸民と異なるものになるからではありませんか」。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="イザヤ書 65:24; ヨハネの第一の手紙 5:14–15; 出エジプト記 33:12"> 主はモーセに言われた、「あなたはわたしの前に恵みを得、またわたしは名をもってあなたを知るから、あなたの言ったこの事をもするであろう」。</span>
<span className="v" id="v18" data-v="18" data-xref="ヨハネの黙示録 21:23; 出エジプト記 33:20; テトスヘの手紙 2:13"> モーセは言った、「どうぞ、あなたの栄光をわたしにお示しください」。</span>
<span className="v" id="v19" data-v="19" data-xref="ローマ人への手紙 9:15–18; エペソ人への手紙 1:6–8; エレミヤ書 31:14"> 主は言われた、「わたしはわたしのもろもろの善をあなたの前に通らせ、主の名をあなたの前にのべるであろう。わたしは恵もうとする者を恵み、あわれもうとする者をあわれむ」。</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 32:30; ヨハネによる福音書 1:18; テモテヘの第一の手紙 6:16"> また言われた、「しかし、あなたはわたしの顔を見ることはできない。わたしを見て、なお生きている人はないからである」。</span>
<span className="v" id="v21" data-v="21" data-xref="申命記 5:31; ゼカリヤ書 3:7; ヨシュア記 20:4"> そして主は言われた、「見よ、わたしのかたわらに一つの所がある。あなたは岩の上に立ちなさい。</span>
<span className="v" id="v22" data-v="22" data-xref="詩篇 91:1; イザヤ書 2:21; 詩篇 91:4"> わたしの栄光がそこを通り過ぎるとき、わたしはあなたを岩の裂け目に入れて、わたしが通り過ぎるまで、手であなたをおおうであろう。</span>
<span className="v" id="v23" data-v="23" data-xref="出エジプト記 33:20; ヨハネによる福音書 1:18; テモテヘの第一の手紙 6:16"> そしてわたしが手をのけるとき、あなたはわたしのうしろを見るが、わたしの顔は見ないであろう」。</span>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出エジプト記 10:9; 使徒行伝 4:29; マタイによる福音書 10:28"> その後、モーセとアロンは行ってパロに言った、「イスラエルの神、主はこう言われる、『わたしの民を去らせ、荒野で、わたしのために祭をさせなさい』と」。</span>
<span className="v" id="v2" data-v="2" data-xref="出エジプト記 3:19; ヨブ記 21:15; 列王紀下 18:35"> パロは言った、「主とはいったい何者か。わたしがその声に聞き従ってイスラエルを去らせなければならないのか。わたしは主を知らない。またイスラエルを去らせはしない」。</span>
<span className="v" id="v3" data-v="3" data-xref="出エジプト記 3:18; ゼカリヤ書 14:16–19; エゼキエル書 6:11"> 彼らは言った、「ヘブルびとの神がわたしたちに現れました。どうか、わたしたちを三日の道のりほど荒野に行かせ、わたしたちの神、主に犠牲をささげさせてください。そうしなければ主は疫病か、つるぎをもって、わたしたちを悩まされるからです」。</span>
<span className="v" id="v4" data-v="4" data-xref="出エジプト記 1:11; 使徒行伝 24:5; アモス書 7:10"> エジプトの王は彼らに言った、「モーセとアロンよ、あなたがたは、なぜ民に働きをやめさせようとするのか。自分の労役につくがよい」。</span>
<span className="v" id="v5" data-v="5" data-xref="出エジプト記 1:7–11; 箴言 14:28"> パロはまた言った、「見よ、今や土民の数は多い。しかも、あなたがたは彼らに労役を休ませようとするのか」。</span>
<span className="v" id="v6" data-v="6" data-xref="出エジプト記 5:10; 出エジプト記 5:19; 申命記 16:18"> その日、パロは民を追い使う者と、民のかしらたちに命じて言った、</span>
<span className="v" id="v7" data-v="7" data-xref="士師記 19:19; 創世記 24:25"> 「あなたがたは、れんがを作るためのわらを、もはや、今までのように、この民に与えてはならない。彼らに自分で行って、わらを集めさせなさい。</span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 106:41"> また前に作っていた、れんがの数どおりに彼らに作らせ、それを減らしてはならない。彼らはなまけ者だ。それだから、彼らは叫んで、『行ってわたしたちの神に犠牲をささげさせよ』と言うのだ。</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀下 18:20; エレミヤ書 43:2; ヨブ記 16:3"> この人々の労役を重くして、働かせ、偽りの言葉に心を寄せさせぬようにしなさい」。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="出エジプト記 1:11; 出エジプト記 3:7; 箴言 29:12"> そこで民を追い使う者たちと、民のかしらたちは出て行って、民に言った、「パロはこう仰せられる、『あなたがたに、わらは与えない。</span>
<span className="v" id="v11" data-v="11" data-xref="出エジプト記 5:13–14"> 自分で行って、見つかる所から、わらを取って来るがよい。しかし働きは少しも減らしてはならない』と」。</span>
<span className="v" id="v12" data-v="12" data-xref="出エジプト記 15:7; イザヤ書 5:24; イザヤ書 47:14"> そこで民はエジプトの全地に散って、わらのかわりに、刈り株を集めた。</span>
<span className="v" id="v13" data-v="13"> 追い使う者たちは、彼らをせき立てて言った、「わらがあった時と同じように、あなたがたの働きの、日ごとの分を仕上げなければならない」。</span>
<span className="v" id="v14" data-v="14" data-xref="イザヤ書 10:24"> パロの追い使う者たちがイスラエルの人々の上に立てたかしらたちは、打たれて、「なぜ、あなたがたは、れんが作りの仕事を、きょうも、前のように仕上げないのか」と言われた。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15"> そこで、イスラエルの人々のかしらたちはパロのところに行き、叫んで言った、「あなたはなぜ、しもべどもにこんなことをなさるのですか。</span>
<span className="v" id="v16" data-v="16"> しもべどもは、わらを与えられず、しかも彼らはわたしたちに、『れんがは作れ』と言うのです。その上、しもべどもは打たれています。罪はあなたの民にあるのです」。</span>
<span className="v" id="v17" data-v="17" data-xref="マタイによる福音書 26:8; ヨハネによる福音書 6:27; 出エジプト記 5:8"> パロは言った、「あなたがたは、なまけ者だ、なまけ者だ。それだから、『行って、主に犠牲をささげさせよ』と言うのだ。</span>
<span className="v" id="v18" data-v="18" data-xref="エゼキエル書 18:18; ダニエル書 2:9–13"> さあ、行って働きなさい。わらは与えないが、なおあなたがたは定めた数のれんがを納めなければならない」。</span>
<span className="v" id="v19" data-v="19" data-xref="伝道の書 5:8; 伝道の書 4:1; 申命記 32:36"> イスラエルの人々のかしらたちは、「れんがの日ごとの分を減らしてはならない」と言われたので、悪い事態になったことを知った。</span>
<span className="v" id="v20" data-v="20"> 彼らがパロを離れて出てきた時、彼らに会おうとして立っていたモーセとアロンに会ったので、</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 34:30; サムエル記上 13:4; 歴代志上 19:6"> 彼らに言った、「主があなたがたをごらんになって、さばかれますように。あなたがたは、わたしたちをパロとその家来たちにきらわせ、つるぎを彼らの手に渡して、殺させようとしておられるのです」。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="エレミヤ書 20:7; 列王紀上 19:10; 民数記 11:14–15"> モーセは主のもとに帰って言った、「主よ、あなたは、なぜこの民をひどい目にあわされるのですか。なんのためにわたしをつかわされたのですか。</span>
<span className="v" id="v23" data-v="23" data-xref="エレミヤ書 11:21; ヘブル人への手紙 10:36–37; イザヤ書 28:16"> わたしがパロのもとに行って、あなたの名によって語ってからこのかた、彼はこの民をひどい目にあわせるばかりです。また、あなたは、すこしもあなたの民を救おうとなさいません」。</span>
</div>

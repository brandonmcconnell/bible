<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="テサロニケ人への第一の手紙 4:14–17; マルコによる福音書 13:27; マタイによる福音書 24:31"> さて兄弟たちよ。わたしたちの主イエス・キリストの来臨と、わたしたちがみもとに集められることとについて、あなたがたにお願いすることがある。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネの第一の手紙 4:1–2; マルコによる福音書 13:7; マタイによる福音書 24:4–6"> 霊により、あるいは言葉により、あるいはわたしたちから出たという手紙によって、主の日はすでにきたとふれまわる者があっても、すぐさま心を動かされたり、あわてたりしてはいけない。</span>
<span className="v" id="v3" data-v="3" data-xref="マタイによる福音書 24:4–6; ヨハネの第一の手紙 2:18; エペソ人への手紙 5:6"> だれがどんな事をしても、それにだまされてはならない。まず背教のことが起り、不法の者、すなわち、滅びの子が現れるにちがいない。</span>
<span className="v" id="v4" data-v="4" data-xref="エゼキエル書 28:2; ダニエル書 7:25; ヨハネの黙示録 13:6–7"> 彼は、すべて神と呼ばれたり拝まれたりするものに反抗して立ち上がり、自ら神の宮に座して、自分は神だと宣言する。</span>
<span className="v" id="v5" data-v="5" data-xref="ペテロの第二の手紙 1:15; ガラテヤ人への手紙 5:21; マタイによる福音書 16:9"> わたしがまだあなたがたの所にいた時、これらの事をくり返して言ったのを思い出さないのか。</span>
<span className="v" id="v6" data-v="6" data-xref="テサロニケ人への第二の手紙 2:3; テサロニケ人への第二の手紙 2:8"> そして、あなたがたが知っているとおり、彼が自分に定められた時になってから現れるように、いま彼を阻止しているものがある。</span>
<span className="v" id="v7" data-v="7" data-xref="ヨハネの第一の手紙 4:3; ヨハネの黙示録 17:7; テモテヘの第二の手紙 2:17–18"> 不法の秘密の力が、すでに働いているのである。ただそれは、いま阻止している者が取り除かれる時までのことである。</span>
<span className="v" id="v8" data-v="8" data-xref="テサロニケ人への第二の手紙 2:3; ヨハネの黙示録 19:20–21; イザヤ書 11:4"> その時になると、不法の者が現れる。この者を、主イエスは口の息をもって殺し、来臨の輝きによって滅ぼすであろう。</span>
<span className="v" id="v9" data-v="9" data-xref="マタイによる福音書 24:24; ヨハネの黙示録 19:20; エペソ人への手紙 2:2"> 不法の者が来るのは、サタンの働きによるのであって、あらゆる偽りの力と、しるしと、不思議と、</span>
<span className="v" id="v10" data-v="10" data-xref="コリント人への第一の手紙 1:18; 箴言 1:7; コリント人への第二の手紙 4:2–3"> また、あらゆる不義の惑わしとを、滅ぶべき者どもに対して行うためである。彼らが滅びるのは、自分らの救となるべき真理に対する愛を受けいれなかった報いである。</span>
<span className="v" id="v11" data-v="11" data-xref="ローマ人への手紙 1:28; ヨハネによる福音書 12:39–43; テモテヘの第一の手紙 4:1"> そこで神は、彼らが偽りを信じるように、迷わす力を送り、</span>
<span className="v" id="v12" data-v="12" data-xref="ローマ人への手紙 1:32; ローマ人への手紙 8:7–8; マルコによる福音書 16:16"> こうして、真理を信じないで不義を喜んでいたすべての人を、さばくのである。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="テモテヘの第二の手紙 1:9; エペソ人への手紙 1:4–5; テサロニケ人への第一の手紙 1:4"> しかし、主に愛されている兄弟たちよ。わたしたちはいつもあなたがたのことを、神に感謝せずにはおられない。それは、神があなたがたを初めから選んで、御霊によるきよめと、真理に対する信仰とによって、救を得させようとし、</span>
<span className="v" id="v14" data-v="14" data-xref="テサロニケ人への第一の手紙 2:12; ペテロの第一の手紙 5:10; テサロニケ人への第一の手紙 1:5"> そのために、わたしたちの福音によりあなたがたを召して、わたしたちの主イエス・キリストの栄光にあずからせて下さるからである。</span>
<span className="v" id="v15" data-v="15" data-xref="コリント人への第一の手紙 11:2; テサロニケ人への第二の手紙 3:6; テサロニケ人への第二の手紙 2:2"> そこで、兄弟たちよ。堅く立って、わたしたちの言葉や手紙で教えられた言伝えを、しっかりと守り続けなさい。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="ローマ人への手紙 5:2–5; ヨハネによる福音書 3:16; ペテロの第一の手紙 1:3–8"> どうか、わたしたちの主イエス・キリストご自身と、わたしたちを愛し、恵みをもって永遠の慰めと確かな望みとを賜わるわたしたちの父なる神とが、</span>
<span className="v" id="v17" data-v="17" data-xref="テサロニケ人への第二の手紙 3:3; テサロニケ人への第一の手紙 3:13; テサロニケ人への第一の手紙 3:2"> あなたがたの心を励まし、あなたがたを強めて、すべての良いわざを行い、正しい言葉を語る者として下さるように。</span>
</div>

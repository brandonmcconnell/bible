<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="テサロニケ人への第一の手紙 5:25; コロサイ人への手紙 4:3; コリント人への第一の手紙 16:9"> 最後に、兄弟たちよ。わたしたちのために祈ってほしい。どうか主の言葉が、あなたがたの所と同じように、ここでも早く広まり、また、あがめられるように。</span>
<span className="v" id="v2" data-v="2" data-xref="コリント人への第二の手紙 4:3–4; ローマ人への手紙 15:31; 申命記 32:20"> また、どうか、わたしたちが不都合な悪人から救われるように。事実、すべての人が信仰を持っているわけではない。</span>
<span className="v" id="v3" data-v="3" data-xref="テモテヘの第二の手紙 4:18; テサロニケ人への第一の手紙 5:24; コリント人への第一の手紙 10:13"> しかし、主は真実なかたであるから、あなたがたを強め、悪しき者から守って下さるであろう。</span>
<span className="v" id="v4" data-v="4" data-xref="ピリピ人への手紙 1:6; ピレモンヘの手紙 1:21; テサロニケ人への第一の手紙 4:10"> わたしたちが命じる事を、あなたがたは現に実行しており、また、実行するであろうと、わたしたちは、主にあって確信している。</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 119:36; 歴代志上 29:18; 申命記 30:6"> どうか、主があなたがたの心を導いて、神の愛とキリストの忍耐とを持たせて下さるように。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="テサロニケ人への第二の手紙 3:10–11; テサロニケ人への第二の手紙 3:7; ローマ人への手紙 16:17"> 兄弟たちよ。主イエス・キリストの名によってあなたがたに命じる。怠惰な生活をして、わたしたちから受けた言伝えに従わないすべての兄弟たちから、遠ざかりなさい。</span>
<span className="v" id="v7" data-v="7" data-xref="テサロニケ人への第二の手紙 3:6; テサロニケ人への第二の手紙 3:9; コリント人への第一の手紙 4:16"> わたしたちに、どうならうべきであるかは、あなたがた自身が知っているはずである。あなたがたの所にいた時には、わたしたちは怠惰な生活をしなかったし、</span>
<span className="v" id="v8" data-v="8" data-xref="マタイによる福音書 6:11; テサロニケ人への第一の手紙 2:9; エペソ人への手紙 4:28"> 人からパンをもらって食べることもしなかった。それどころか、あなたがたのだれにも負担をかけまいと、日夜、労苦し努力して働き続けた。</span>
<span className="v" id="v9" data-v="9" data-xref="テサロニケ人への第二の手紙 3:7; テサロニケ人への第一の手紙 2:6; コリント人への第一の手紙 9:4–14"> それは、わたしたちにその権利がないからではなく、ただわたしたちにあなたがたが見習うように、身をもって模範を示したのである。</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 3:19; 箴言 13:4; 箴言 20:4"> また、あなたがたの所にいた時に、「働こうとしない者は、食べることもしてはならない」と命じておいた。</span>
<span className="v" id="v11" data-v="11" data-xref="テモテヘの第一の手紙 5:13; テサロニケ人への第二の手紙 3:6; テサロニケ人への第一の手紙 4:11"> ところが、聞くところによると、あなたがたのうちのある者は怠惰な生活を送り、働かないで、ただいたずらに動きまわっているとのことである。</span>
<span className="v" id="v12" data-v="12" data-xref="エペソ人への手紙 4:28; テサロニケ人への第一の手紙 4:11; テサロニケ人への第二の手紙 3:8"> こうした人々に対しては、静かに働いて自分で得たパンを食べるように、主イエス・キリストによって命じまた勧める。</span>
<span className="v" id="v13" data-v="13" data-xref="ガラテヤ人への手紙 6:9–10; ヘブル人への手紙 12:3; コリント人への第二の手紙 4:1"> 兄弟たちよ。あなたがたは、たゆまずに良い働きをしなさい。</span>
<span className="v" id="v14" data-v="14" data-xref="テトスヘの手紙 3:10; テサロニケ人への第二の手紙 3:6; コリント人への第一の手紙 5:11"> もしこの手紙にしるしたわたしたちの言葉に聞き従わない人があれば、そのような人には注意をして、交際しないがよい。彼が自ら恥じるようになるためである。</span>
<span className="v" id="v15" data-v="15" data-xref="テトスヘの手紙 3:10; テサロニケ人への第一の手紙 5:14; コリント人への第一の手紙 5:5"> しかし、彼を敵のように思わないで、兄弟として訓戒しなさい。</span>
<span className="v" id="v16" data-v="16" data-xref="詩篇 29:11; ヨハネによる福音書 16:33; マタイによる福音書 1:23"> どうか、平和の主ご自身が、いついかなる場合にも、あなたがたに平和を与えて下さるように。主があなたがた一同と共におられるように。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="コリント人への第一の手紙 16:21; テサロニケ人への第二の手紙 1:5; コロサイ人への手紙 4:18"> ここでパウロ自身が、手ずからあいさつを書く。これは、わたしのどの手紙にも書く印である。わたしは、このように書く。</span>
<span className="v" id="v18" data-v="18" data-xref="ローマ人への手紙 16:20; ローマ人への手紙 16:23"> どうか、わたしたちの主イエス・キリストの恵みが、あなたがた一同と共にあるように。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="コリント人への第二の手紙 11:4; コリント人への第一の手紙 1:21; コリント人への第二の手紙 11:19"> わたしが少しばかり愚かなことを言うのを、どうか、忍んでほしい。もちろん忍んでくれるのだ。</span>
<span className="v" id="v2" data-v="2" data-xref="ホセア書 2:19–20; エペソ人への手紙 5:26–27; イザヤ書 54:5"> わたしは神の熱情をもって、あなたがたを熱愛している。あなたがたを、きよいおとめとして、ただひとりの男子キリストにささげるために、婚約させたのである。</span>
<span className="v" id="v3" data-v="3" data-xref="コロサイ人への手紙 2:8; ガラテヤ人への手紙 1:6; エペソ人への手紙 4:14"> ただ恐れるのは、エバがへびの悪巧みで誘惑されたように、あなたがたの思いが汚されて、キリストに対する純情と貞操とを失いはしないかということである。</span>
<span className="v" id="v4" data-v="4" data-xref="ガラテヤ人への手紙 1:6–8; コリント人への第一の手紙 3:11; テモテヘの第一の手紙 2:5"> というのは、もしある人がきて、わたしたちが宣べ伝えもしなかったような異なるイエスを宣べ伝え、あるいは、あなたがたが受けたことのない違った霊を受け、あるいは、受けいれたことのない違った福音を聞く場合に、あなたがたはよくもそれを忍んでいる。</span>
<span className="v" id="v5" data-v="5" data-xref="コリント人への第二の手紙 12:11–12; コリント人への第一の手紙 15:10; ガラテヤ人への手紙 2:6–9"> 事実、わたしは、あの大使徒たちにいささかも劣ってはいないと思う。</span>
<span className="v" id="v6" data-v="6" data-xref="エペソ人への手紙 3:4; コリント人への第一の手紙 1:17; コリント人への第二の手紙 4:2"> たとい弁舌はつたなくても、知識はそうでない。わたしは、事ごとに、いろいろの場合に、あなたがたに対してそれを明らかにした。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="コリント人への第二の手紙 12:13; テサロニケ人への第一の手紙 2:9; コリント人への第二の手紙 10:1"> それとも、あなたがたを高めるために自分を低くして、神の福音を価なしにあなたがたに宣べ伝えたことが、罪になるのだろうか。</span>
<span className="v" id="v8" data-v="8" data-xref="ピリピ人への手紙 4:18; コリント人への第二の手紙 11:9; ピリピ人への手紙 4:14–16"> わたしは他の諸教会をかすめたと言われながら得た金で、あなたがたに奉仕し、</span>
<span className="v" id="v9" data-v="9" data-xref="テサロニケ人への第二の手紙 3:8–9; テサロニケ人への第一の手紙 2:9; テサロニケ人への第一の手紙 2:6"> あなたがたの所にいて貧乏をした時にも、だれにも負担をかけたことはなかった。わたしの欠乏は、マケドニヤからきた兄弟たちが、補ってくれた。こうして、わたしはすべての事につき、あなたがたに重荷を負わせまいと努めてきたし、今後も努めよう。</span>
<span className="v" id="v10" data-v="10" data-xref="ローマ人への手紙 9:1; ローマ人への手紙 1:9; 使徒行伝 18:12"> わたしの内にあるキリストの真実にかけて言う、この誇がアカヤ地方で封じられるようなことは、決してない。</span>
<span className="v" id="v11" data-v="11" data-xref="コリント人への第二の手紙 12:15; コリント人への第二の手紙 6:11–12; コリント人への第二の手紙 7:3"> なぜであるか。わたしがあなたがたを愛していないからか。それは、神がご存じである。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="コリント人への第一の手紙 9:12; コリント人への第一の手紙 5:6; コリント人への第二の手紙 5:12"> しかし、わたしは、現在していることを今後もしていこう。それは、わたしたちと同じように誇りうる立ち場を得ようと機会をねらっている者どもから、その機会を断ち切ってしまうためである。</span>
<span className="v" id="v13" data-v="13" data-xref="ガラテヤ人への手紙 1:7; ヨハネの黙示録 2:2; ヨハネの第一の手紙 4:1"> こういう人々はにせ使徒、人をだます働き人であって、キリストの使徒に擬装しているにすぎないからである。</span>
<span className="v" id="v14" data-v="14" data-xref="ガラテヤ人への手紙 1:8; コリント人への第二の手紙 2:11; コリント人への第二の手紙 11:3"> しかし、驚くには及ばない。サタンも光の天使に擬装するのだから。</span>
<span className="v" id="v15" data-v="15" data-xref="ピリピ人への手紙 3:19; ヨハネの黙示録 9:11; イザヤ書 9:14–15"> だから、たといサタンの手下どもが、義の奉仕者のように擬装したとしても、不思議ではない。彼らの最期は、そのしわざに合ったものとなろう。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="コリント人への第二の手紙 11:1; コリント人への第二の手紙 12:6; コリント人への第二の手紙 12:11"> 繰り返して言うが、だれも、わたしを愚か者と思わないでほしい。もしそう思うなら、愚か者あつかいにされてもよいから、わたしにも、少し誇らせてほしい。</span>
<span className="v" id="v17" data-v="17" data-xref="コリント人への第一の手紙 7:12; ピリピ人への手紙 3:3–6; コリント人への第二の手紙 9:4"> いま言うことは、主によって言うのではなく、愚か者のように、自分の誇とするところを信じきって言うのである。</span>
<span className="v" id="v18" data-v="18" data-xref="コリント人への第一の手紙 4:10; コリント人への第二の手紙 11:21–23; コリント人への第二の手紙 10:12–18"> 多くの人が肉によって誇っているから、わたしも誇ろう。</span>
<span className="v" id="v19" data-v="19" data-xref="コリント人への第一の手紙 4:10; コリント人への第一の手紙 10:15; コリント人への第一の手紙 8:1"> あなたがたは賢い人たちなのだから、喜んで愚か者を忍んでくれるだろう。</span>
<span className="v" id="v20" data-v="20" data-xref="ガラテヤ人への手紙 2:4; ガラテヤ人への手紙 4:3; ガラテヤ人への手紙 5:1"> 実際、あなたがたは奴隷にされても、食い倒されても、略奪されても、いばられても、顔をたたかれても、それを忍んでいる。</span>
<span className="v" id="v21" data-v="21" data-xref="コリント人への第二の手紙 10:10; コリント人への第二の手紙 11:17; コリント人への第二の手紙 10:1–2"> 言うのも恥ずかしいことだが、わたしたちは弱すぎたのだ。もしある人があえて誇るなら、わたしは愚か者になって言うが、わたしもあえて誇ろう。</span>
<span className="v" id="v22" data-v="22" data-xref="ピリピ人への手紙 3:5; ローマ人への手紙 11:1; ローマ人への手紙 9:4"> 彼らはヘブル人なのか。わたしもそうである。彼らはイスラエル人なのか。わたしもそうである。彼らはアブラハムの子孫なのか。わたしもそうである。</span>
<span className="v" id="v23" data-v="23" data-xref="コリント人への第二の手紙 6:4–5; コリント人への第二の手紙 1:9–10; コリント人への第二の手紙 6:9"> 彼らはキリストの僕なのか。わたしは気が狂ったようになって言う、わたしは彼ら以上にそうである。苦労したことはもっと多く、投獄されたことももっと多く、むち打たれたことは、はるかにおびただしく、死に面したこともしばしばあった。</span>
<span className="v" id="v24" data-v="24" data-xref="マルコによる福音書 13:9; 申命記 25:2–3; マタイによる福音書 10:17"> ユダヤ人から四十に一つ足りないむちを受けたことが五度、</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行伝 14:19; 使徒行伝 16:37; ヘブル人への手紙 11:37"> ローマ人にむちで打たれたことが三度、石で打たれたことが一度、難船したことが三度、そして、一昼夜、海の上を漂ったこともある。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行伝 14:5; 使徒行伝 17:5; 使徒行伝 13:50"> 幾たびも旅をし、川の難、盗賊の難、同国民の難、異邦人の難、都会の難、荒野の難、海上の難、にせ兄弟の難に会い、</span>
<span className="v" id="v27" data-v="27" data-xref="ピリピ人への手紙 4:12; コリント人への第二の手紙 6:5; テサロニケ人への第一の手紙 2:9"> 労し苦しみ、たびたび眠られぬ夜を過ごし、飢えかわき、しばしば食物がなく、寒さに凍え、裸でいたこともあった。</span>
<span className="v" id="v28" data-v="28" data-xref="コリント人への第一の手紙 7:17; ローマ人への手紙 15:16; 使徒行伝 20:18–35"> なおいろいろの事があった外に、日々わたしに迫って来る諸教会の心配ごとがある。</span>
<span className="v" id="v29" data-v="29" data-xref="コリント人への第一の手紙 8:13; コリント人への第一の手紙 9:22; ガラテヤ人への手紙 4:8–20"> だれかが弱っているのに、わたしも弱らないでおれようか。だれかが罪を犯しているのに、わたしの心が燃えないでおれようか。</span>
<span className="v" id="v30" data-v="30" data-xref="コリント人への第二の手紙 12:5–11; 箴言 25:27; コリント人への第一の手紙 2:3"> もし誇らねばならないのなら、わたしは自分の弱さを誇ろう。</span>
<span className="v" id="v31" data-v="31" data-xref="ローマ人への手紙 9:5; エペソ人への手紙 1:3; ヨハネによる福音書 10:30"> 永遠にほむべき、主イエス・キリストの父なる神は、わたしが偽りを言っていないことを、ご存じである。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="使徒行伝 9:24–25; コリント人への第二の手紙 11:26"> ダマスコでアレタ王の代官が、わたしを捕えるためにダマスコ人の町を監視したことがあったが、</span>
<span className="v" id="v33" data-v="33" data-xref="使徒行伝 9:25; サムエル記上 19:12; ヨシュア記 2:18"> その時わたしは窓から町の城壁づたいに、かごでつり降ろされて、彼の手からのがれた。</span>
</div>

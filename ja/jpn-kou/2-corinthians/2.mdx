<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="コリント人への第二の手紙 1:23; コリント人への第二の手紙 12:20–21; コリント人への第二の手紙 13:10"> そこでわたしは、あなたがたの所に再び悲しみをもって行くことはすまいと、決心したのである。</span>
<span className="v" id="v2" data-v="2" data-xref="コリント人への第二の手紙 7:8; コリント人への第二の手紙 1:14; コリント人への第一の手紙 12:26"> もしあなたがたを悲しませるとすれば、わたしが悲しませているその人以外に、だれがわたしを喜ばせてくれるのか。</span>
<span className="v" id="v3" data-v="3" data-xref="ガラテヤ人への手紙 5:10; コリント人への第二の手紙 8:22; ピレモンヘの手紙 1:21"> このような事を書いたのは、わたしが行く時、わたしを喜ばせてくれるはずの人々から、悲しい思いをさせられたくないためである。わたし自身の喜びはあなたがた全体の喜びであることを、あなたがたすべてについて確信しているからである。</span>
<span className="v" id="v4" data-v="4" data-xref="コリント人への第二の手紙 7:12; 箴言 27:5–6; レビ記 19:17–18"> わたしは大きな患難と心の憂いの中から、多くの涙をもってあなたがたに書きおくった。それは、あなたがたを悲しませるためではなく、あなたがたに対してあふれるばかりにいだいているわたしの愛を、知ってもらうためであった。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="コリント人への第一の手紙 5:12–13; ガラテヤ人への手紙 4:12; 箴言 17:25"> しかし、もしだれかが人を悲しませたとすれば、それはわたしを悲しませたのではなく、控え目に言うが、ある程度、あなたがた一同を悲しませたのである。</span>
<span className="v" id="v6" data-v="6" data-xref="コリント人への第一の手紙 5:4–5; テモテヘの第一の手紙 5:20; コリント人への第二の手紙 7:11"> その人にとっては、多数の者から受けたあの処罰でもう十分なのだから、</span>
<span className="v" id="v7" data-v="7" data-xref="エペソ人への手紙 4:32; ガラテヤ人への手紙 6:1–2; コロサイ人への手紙 3:13"> あなたがたはむしろ彼をゆるし、また慰めてやるべきである。そうしないと、その人はますます深い悲しみに沈むかも知れない。</span>
<span className="v" id="v8" data-v="8" data-xref="ユダの手紙 1:22–23; ガラテヤ人への手紙 6:1–2; ガラテヤ人への手紙 6:10"> そこでわたしは、彼に対して愛を示すように、あなたがたに勧める。</span>
<span className="v" id="v9" data-v="9" data-xref="コリント人への第二の手紙 10:6; ピレモンヘの手紙 1:21; ピリピ人への手紙 2:22"> わたしが書きおくったのも、あなたがたがすべての事について従順であるかどうかを、ためすためにほかならなかった。</span>
<span className="v" id="v10" data-v="10" data-xref="ヨハネによる福音書 20:23; マタイによる福音書 18:18; コリント人への第二の手紙 5:20"> もしあなたがたが、何かのことについて人をゆるすなら、わたしもまたゆるそう。そして、もしわたしが何かのことでゆるしたとすれば、それは、あなたがたのためにキリストのみまえでゆるしたのである。</span>
<span className="v" id="v11" data-v="11" data-xref="ペテロの第一の手紙 5:8; エペソ人への手紙 6:11–12; コリント人への第二の手紙 11:3"> そうするのは、サタンに欺かれることのないためである。わたしたちは、彼の策略を知らないわけではない。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="使徒行伝 16:8; 使徒行伝 14:27; コロサイ人への手紙 4:3"> さて、キリストの福音のためにトロアスに行ったとき、わたしのために主の門が開かれたにもかかわらず、</span>
<span className="v" id="v13" data-v="13" data-xref="コリント人への第二の手紙 7:5–6; コリント人への第二の手紙 12:18; テトスヘの手紙 1:4"> 兄弟テトスに会えなかったので、わたしは気が気でなく、人々に別れて、マケドニヤに出かけて行った。</span>
<span className="v" id="v14" data-v="14" data-xref="エペソ人への手紙 5:2; ローマ人への手紙 8:37; コリント人への第二の手紙 2:15–16"> しかるに、神は感謝すべきかな。神はいつもわたしたちをキリストの凱旋に伴い行き、わたしたちをとおしてキリストを知る知識のかおりを、至る所に放って下さるのである。</span>
<span className="v" id="v15" data-v="15" data-xref="エペソ人への手紙 5:2; コリント人への第一の手紙 1:18; エゼキエル書 20:41"> わたしたちは、救われる者にとっても滅びる者にとっても、神に対するキリストのかおりである。</span>
<span className="v" id="v16" data-v="16" data-xref="コリント人への第二の手紙 3:5–6; ヨハネによる福音書 9:39; ペテロの第一の手紙 2:7–8"> 後者にとっては、死から死に至らせるかおりであり、前者にとっては、いのちからいのちに至らせるかおりである。いったい、このような任務に、だれが耐え得ようか。</span>
<span className="v" id="v17" data-v="17" data-xref="コリント人への第二の手紙 4:2; コリント人への第二の手紙 1:12; ペテロの第二の手紙 2:1–3"> しかし、わたしたちは、多くの人のように神の言を売物にせず、真心をこめて、神につかわされた者として神のみまえで、キリストにあって語るのである。</span>
</div>

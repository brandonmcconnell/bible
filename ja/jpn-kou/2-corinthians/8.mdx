<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行伝 16:9; コリント人への第二の手紙 9:2; コリント人への第二の手紙 9:4"> 兄弟たちよ。わたしたちはここで、マケドニヤの諸教会に与えられた神の恵みを、あなたがたに知らせよう。</span>
<span className="v" id="v2" data-v="2" data-xref="ヤコブの手紙 2:5; 箴言 11:25; コリント人への第二の手紙 6:10"> すなわち、彼らは、患難のために激しい試錬をうけたが、その満ちあふれる喜びは、極度の貧しさにもかかわらず、あふれ出て惜しみなく施す富となったのである。</span>
<span className="v" id="v3" data-v="3" data-xref="出エジプト記 35:29; 出エジプト記 35:5; 出エジプト記 35:21–22"> わたしはあかしするが、彼らは力に応じて、否、力以上に施しをした。すなわち、自ら進んで、</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行伝 24:17; ガラテヤ人への手紙 6:10; コリント人への第二の手紙 9:1"> 聖徒たちへの奉仕に加わる恵みにあずかりたいと、わたしたちに熱心に願い出て、</span>
<span className="v" id="v5" data-v="5" data-xref="ローマ人への手紙 12:1; ローマ人への手紙 14:7–9; 歴代志下 30:12"> わたしたちの希望どおりにしたばかりか、自分自身をまず、神のみこころにしたがって、主にささげ、また、わたしたちにもささげたのである。</span>
<span className="v" id="v6" data-v="6" data-xref="コリント人への第二の手紙 12:18; コリント人への第二の手紙 8:19; コリント人への第二の手紙 8:4"> そこで、この募金をテトスがあなたがたの所で、すでに始めた以上、またそれを完成するようにと、わたしたちは彼に勧めたのである。</span>
<span className="v" id="v7" data-v="7" data-xref="コリント人への第二の手紙 9:8; ペテロの第二の手紙 1:5–8; テサロニケ人への第二の手紙 1:3"> さて、あなたがたがあらゆる事がらについて富んでいるように、すなわち、信仰にも言葉にも知識にも、あらゆる熱情にも、また、あなたがたに対するわたしたちの愛にも富んでいるように、この恵みのわざにも富んでほしい。</span>
<span className="v" id="v8" data-v="8" data-xref="コリント人への第一の手紙 7:6; ヨハネの第一の手紙 3:17–19; ヤコブの手紙 2:14–16"> こう言っても、わたしは命令するのではない。ただ、他の人たちの熱情によって、あなたがたの愛の純真さをためそうとするのである。</span>
<span className="v" id="v9" data-v="9" data-xref="ローマ人への手紙 8:32; ピリピ人への手紙 2:6–8; マタイによる福音書 20:28"> あなたがたは、わたしたちの主イエス・キリストの恵みを知っている。すなわち、主は富んでおられたのに、あなたがたのために貧しくなられた。それは、あなたがたが、彼の貧しさによって富む者になるためである。</span>
<span className="v" id="v10" data-v="10" data-xref="テモテヘの第一の手紙 6:18–19; ヘブル人への手紙 13:16; コリント人への第二の手紙 9:2"> そこで、わたしは、この恵みのわざについて意見を述べよう。それがあなたがたの益になるからである。あなたがたはこの事を、昨年以来、他に先んじて実行したばかりではなく、それを願っていた。</span>
<span className="v" id="v11" data-v="11" data-xref="コリント人への第二の手紙 9:2"> だから今、それをやりとげなさい。あなたがたが心から願っているように、持っているところに応じて、それをやりとげなさい。</span>
<span className="v" id="v12" data-v="12" data-xref="マルコによる福音書 12:42–44; コリント人への第二の手紙 9:7; ルカによる福音書 21:1–4"> もし心から願ってそうするなら、持たないところによらず、持っているところによって、神に受けいれられるのである。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行伝 4:34; ローマ人への手紙 15:26–27"> それは、ほかの人々に楽をさせて、あなたがたに苦労をさせようとするのではなく、持ち物を等しくするためである。</span>
<span className="v" id="v14" data-v="14" data-xref="コリント人への第二の手紙 9:12; 使徒行伝 4:34"> すなわち、今の場合は、あなたがたの余裕があの人たちの欠乏を補い、後には、彼らの余裕があなたがたの欠乏を補い、こうして等しくなるようにするのである。</span>
<span className="v" id="v15" data-v="15" data-xref="出エジプト記 16:18; ルカによる福音書 22:35"> それは「多く得た者も余ることがなく、少ししか得なかった者も足りないことはなかった」と書いてあるとおりである。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="ヨハネの黙示録 17:17; エレミヤ書 32:40; コリント人への第二の手紙 2:13–14"> わたしがあなたがたに対して持っている同じ熱情を、テトスの心にも与えて下さった神に感謝する。</span>
<span className="v" id="v17" data-v="17" data-xref="コリント人への第二の手紙 8:6; ヘブル人への手紙 13:22; コリント人への第二の手紙 8:10"> 彼はわたしの勧めを受けいれ、そして更に熱心になって、自分から進んであなたがたのところに行った。</span>
<span className="v" id="v18" data-v="18" data-xref="コリント人への第二の手紙 12:18; コリント人への第二の手紙 8:19; コリント人への第一の手紙 7:17"> わたしたちはまた、テトスと一緒に、ひとりの兄弟を送る。この兄弟が福音宣伝の上で得たほまれは、すべての教会に聞えているが、</span>
<span className="v" id="v19" data-v="19" data-xref="コリント人への第一の手紙 16:3–4; コリント人への第二の手紙 4:15; コリント人への第二の手紙 9:8"> そのうえ、彼は、主ご自身の栄光があらわれるため、また、わたしたちの好意を示すために、骨を折って贈り物を集めているわたしたちの同伴者として、諸教会から選ばれたのである。</span>
<span className="v" id="v20" data-v="20" data-xref="テサロニケ人への第一の手紙 5:22; ローマ人への手紙 14:16; エペソ人への手紙 5:15"> そうしたのは、わたしたちが集めているこの寄附金のことについて、人にかれこれ言われるのを避けるためである。</span>
<span className="v" id="v21" data-v="21" data-xref="ローマ人への手紙 12:17; ペテロの第一の手紙 2:12; ピリピ人への手紙 4:8"> わたしたちは、主のみまえばかりではなく、人の前でも公正であるように、気を配っているのである。</span>
<span className="v" id="v22" data-v="22" data-xref="ピリピ人への手紙 2:20–22"> また、もうひとりの兄弟を彼らと一緒に送る。わたしたちは、多くの事について彼が熱心であったことを、たびたび認めた。彼は今、あなたがたを非常に信頼して、ますます熱心になっている。</span>
<span className="v" id="v23" data-v="23" data-xref="ピリピ人への手紙 2:25; ピレモンヘの手紙 1:17; コリント人への第二の手紙 8:6"> テトスについて言えば、彼はわたしの仲間であり、あなたがたに対するわたしの協力者である。この兄弟たちについて言えば、彼らは諸教会の使者、キリストの栄光である。</span>
<span className="v" id="v24" data-v="24" data-xref="コリント人への第二の手紙 7:14; コリント人への第二の手紙 7:4; コリント人への第二の手紙 9:2–4"> だから、あなたがたの愛と、また、あなたがたについてわたしたちがいだいている誇とが、真実であることを、諸教会の前で彼らにあかししていただきたい。</span>

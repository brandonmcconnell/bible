<span className="v" id="v1" data-v="1" data-xref="テサロニケ人への第一の手紙 4:7; ペテロの第一の手紙 2:11; 箴言 8:13"> 愛する者たちよ。わたしたちは、このような約束を与えられているのだから、肉と霊とのいっさいの汚れから自分をきよめ、神をおそれて全く清くなろうではないか。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="使徒行伝 20:33; コリント人への第二の手紙 6:12–13; コリント人への第二の手紙 11:9"> どうか、わたしたちに心を開いてほしい。わたしたちは、だれにも不義をしたことがなく、だれをも破滅におとしいれたことがなく、だれからもだまし取ったことがない。</span>
<span className="v" id="v3" data-v="3" data-xref="コリント人への第二の手紙 6:11–12; テサロニケ人への第一の手紙 2:8; コリント人への第二の手紙 11:11"> わたしは、責めるつもりでこう言うのではない。前にも言ったように、あなたがたはわたしの心のうちにいて、わたしたちと生死を共にしているのである。</span>
<span className="v" id="v4" data-v="4" data-xref="コリント人への第二の手紙 1:4; コリント人への第二の手紙 3:12; ヤコブの手紙 1:2"> わたしはあなたがたを大いに信頼し、大いに誇っている。また、あふれるばかり慰めを受け、あらゆる患難の中にあって喜びに満ちあふれている。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="コリント人への第二の手紙 2:13; 申命記 32:25; 使徒行伝 20:1"> さて、マケドニヤに着いたとき、わたしたちの身に少しの休みもなく、さまざまの患難に会い、外には戦い、内には恐れがあった。</span>
<span className="v" id="v6" data-v="6" data-xref="コリント人への第二の手紙 1:3–4; テサロニケ人への第二の手紙 2:16–17; コリント人への第二の手紙 7:13"> しかるに、うちしおれている者を慰める神は、テトスの到来によって、わたしたちを慰めて下さった。</span>
<span className="v" id="v7" data-v="7" data-xref="コリント人への第二の手紙 5:2; ユダの手紙 1:3; コリント人への第二の手紙 8:16"> ただ彼の到来によるばかりではなく、彼があなたがたから受けたその慰めをもって、慰めて下さった。すなわち、あなたがたがわたしを慕っていること、嘆いていること、またわたしに対して熱心であることを知らせてくれたので、わたしの喜びはいよいよ増し加わったのである。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨハネの黙示録 3:19; エレミヤ書 20:7–9; マタイによる福音書 26:21–22"> そこで、たとい、あの手紙であなたがたを悲しませたとしても、わたしはそれを悔いていない。あの手紙がしばらくの間ではあるが、あなたがたを悲しませたのを見て悔いたとしても、</span>
<span className="v" id="v9" data-v="9" data-xref="ルカによる福音書 15:7; エレミヤ書 31:18–20; コリント人への第二の手紙 7:10–11"> 今は喜んでいる。それは、あなたがたが悲しんだからではなく、悲しんで悔い改めるに至ったからである。あなたがたがそのように悲しんだのは、神のみこころに添うたことであって、わたしたちからはなんの損害も受けなかったのである。</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行伝 3:19; 使徒行伝 11:18; テモテヘの第二の手紙 2:25–26"> 神のみこころに添うた悲しみは、悔いのない救を得させる悔改めに導き、この世の悲しみは死をきたらせる。</span>
<span className="v" id="v11" data-v="11" data-xref="ローマ人への手紙 14:18; テモテヘの第一の手紙 5:21–22; テモテヘの第二の手紙 2:15"> 見よ、神のみこころに添うたその悲しみが、どんなにか熱情をあなたがたに起させたことか。また、弁明、義憤、恐れ、愛慕、熱意、それから処罰に至らせたことか。あなたがたはあの問題については、すべての点において潔白であることを証明したのである。</span>
<span className="v" id="v12" data-v="12" data-xref="コリント人への第二の手紙 2:9; テモテヘの第一の手紙 3:5; コリント人への第二の手紙 2:17"> だから、わたしがあなたがたに書きおくったのは、不義をした人のためでも、不義を受けた人のためでもなく、わたしたちに対するあなたがたの熱情が、神の前にあなたがたの間で明らかになるためである。</span>
<span className="v" id="v13" data-v="13" data-xref="コリント人への第二の手紙 7:6; コリント人への第一の手紙 12:26; コリント人への第一の手紙 16:13"> こういうわけで、わたしたちは慰められたのである。これらの慰めの上にテトスの喜びが加わって、わたしたちはなおいっそう喜んだ。彼があなたがた一同によって安心させられたからである。</span>
<span className="v" id="v14" data-v="14" data-xref="コリント人への第二の手紙 7:4; テサロニケ人への第二の手紙 1:4; コリント人への第二の手紙 1:18–20"> そして、わたしは彼に対してあなたがたのことを少しく誇ったが、それはわたしの恥にならないですんだ。あなたがたにいっさいのことを真実に語ったように、テトスに対して誇ったことも真実となってきたのである。</span>
<span className="v" id="v15" data-v="15" data-xref="ピリピ人への手紙 2:12; コリント人への第二の手紙 2:9; ヨハネの第一の手紙 3:17"> また彼は、あなたがた一同が従順であって、おそれおののきつつ自分を迎えてくれたことを思い出して、ますます心をあなたがたの方に寄せている。</span>
<span className="v" id="v16" data-v="16" data-xref="コリント人への第二の手紙 2:3; ピレモンヘの手紙 1:8; ピレモンヘの手紙 1:21"> わたしは、あなたがたに全く信頼することができて、喜んでいる。</span>

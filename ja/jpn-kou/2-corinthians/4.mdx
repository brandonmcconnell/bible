<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="テサロニケ人への第二の手紙 3:13; ガラテヤ人への手紙 6:9; エペソ人への手紙 3:13"> このようにわたしたちは、あわれみを受けてこの務についているのだから、落胆せずに、</span>
<span className="v" id="v2" data-v="2" data-xref="コリント人への第二の手紙 2:17; テサロニケ人への第一の手紙 2:3–5; コリント人への第二の手紙 5:11"> 恥ずべき隠れたことを捨て去り、悪巧みによって歩かず、神の言を曲げず、真理を明らかにし、神のみまえに、すべての人の良心に自分を推薦するのである。</span>
<span className="v" id="v3" data-v="3" data-xref="コリント人への第二の手紙 3:14; コリント人への第一の手紙 1:18; テサロニケ人への第二の手紙 2:9–11"> もしわたしたちの福音がおおわれているなら、滅びる者どもにとっておおわれているのである。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネによる福音書 12:40; コリント人への第二の手紙 3:14; 使徒行伝 26:18"> 彼らの場合、この世の神が不信の者たちの思いをくらませて、神のかたちであるキリストの栄光の福音の輝きを、見えなくしているのである。</span>
<span className="v" id="v5" data-v="5" data-xref="コリント人への第二の手紙 1:24; コリント人への第一の手紙 1:23; テサロニケ人への第一の手紙 2:5–6"> しかし、わたしたちは自分自身を宣べ伝えるのではなく、主なるキリスト・イエスを宣べ伝える。わたしたち自身は、ただイエスのために働くあなたがたの僕にすぎない。</span>
<span className="v" id="v6" data-v="6" data-xref="イザヤ書 60:2; 創世記 1:3; ペテロの第一の手紙 2:9"> 「やみの中から光が照りいでよ」と仰せになった神は、キリストの顔に輝く神の栄光の知識を明らかにするために、わたしたちの心を照して下さったのである。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="コリント人への第二の手紙 3:5–6; コリント人への第二の手紙 5:1; エペソ人への手紙 2:8–9"> しかしわたしたちは、この宝を土の器の中に持っている。その測り知れない力は神のものであって、わたしたちから出たものでないことが、あらわれるためである。</span>
<span className="v" id="v8" data-v="8" data-xref="ヤコブの手紙 1:2–4; ローマ人への手紙 8:35–37; ペテロの第一の手紙 4:12–14"> わたしたちは、四方から患難を受けても窮しない。途方にくれても行き詰まらない。</span>
<span className="v" id="v9" data-v="9" data-xref="イザヤ書 43:2; ミカ書 7:8; 詩篇 37:24–25"> 迫害に会っても見捨てられない。倒されても滅びない。</span>
<span className="v" id="v10" data-v="10" data-xref="ローマ人への手紙 6:5; テモテヘの第二の手紙 2:11; ペテロの第一の手紙 4:13"> いつもイエスの死をこの身に負うている。それはまた、イエスのいのちが、この身に現れるためである。</span>
<span className="v" id="v11" data-v="11" data-xref="コリント人への第一の手紙 15:49; ローマ人への手紙 8:36; 詩篇 44:22"> わたしたち生きている者は、イエスのために絶えず死に渡されているのである。それはイエスのいのちが、わたしたちの死ぬべき肉体に現れるためである。</span>
<span className="v" id="v12" data-v="12" data-xref="コリント人への第二の手紙 13:9; コリント人への第一の手紙 4:10; 使徒行伝 20:24"> こうして、死はわたしたちのうちに働き、いのちはあなたがたのうちに働くのである。</span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 116:10; ヘブル人への手紙 11:1–40; コリント人への第二の手紙 3:12"> 「わたしは信じた。それゆえに語った」としるしてあるとおり、それと同じ信仰の霊を持っているので、わたしたちも信じている。それゆえに語るのである。</span>
<span className="v" id="v14" data-v="14" data-xref="テサロニケ人への第一の手紙 4:14; ローマ人への手紙 8:11; ユダの手紙 1:24"> それは、主イエスをよみがえらせたかたが、わたしたちをもイエスと共によみがえらせ、そして、あなたがたと共にみまえに立たせて下さることを、知っているからである。</span>
<span className="v" id="v15" data-v="15" data-xref="ローマ人への手紙 8:28; エペソ人への手紙 3:20–21; コリント人への第二の手紙 9:11–12"> すべてのことは、あなたがたの益であって、恵みがますます多くの人に増し加わるにつれ、感謝が満ちあふれて、神の栄光となるのである。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="イザヤ書 40:31; コロサイ人への手紙 3:10; イザヤ書 40:29"> だから、わたしたちは落胆しない。たといわたしたちの外なる人は滅びても、内なる人は日ごとに新しくされていく。</span>
<span className="v" id="v17" data-v="17" data-xref="ローマ人への手紙 8:18; ペテロの第一の手紙 5:10; ローマ人への手紙 5:3–5"> なぜなら、このしばらくの軽い患難は働いて、永遠の重い栄光を、あふれるばかりにわたしたちに得させるからである。</span>
<span className="v" id="v18" data-v="18" data-xref="コリント人への第二の手紙 5:7; ローマ人への手紙 8:24–25; ヘブル人への手紙 11:1"> わたしたちは、見えるものにではなく、見えないものに目を注ぐ。見えるものは一時的であり、見えないものは永遠につづくのである。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨブ記 19:25–26; ヨハネの第一の手紙 3:2; ペテロの第二の手紙 1:13–14"> わたしたちの住んでいる地上の幕屋がこわれると、神からいただく建物、すなわち天にある、人の手によらない永遠の家が備えてあることを、わたしたちは知っている。</span>
<span className="v" id="v2" data-v="2" data-xref="ローマ人への手紙 8:23; コリント人への第一の手紙 15:53–54; コリント人への第二の手紙 5:3–4"> そして、天から賜わるそのすみかを、上に着ようと切に望みながら、この幕屋の中で苦しみもだえている。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 3:7–11; ヨハネの黙示録 16:15; ヨハネの黙示録 3:18"> それを着たなら、裸のままではいないことになろう。</span>
<span className="v" id="v4" data-v="4" data-xref="コリント人への第一の手紙 15:53–54; コリント人への第二の手紙 5:2; イザヤ書 25:8"> この幕屋の中にいるわたしたちは、重荷を負って苦しみもだえている。それを脱ごうと願うからではなく、その上に着ようと願うからであり、それによって、死ぬべきものがいのちにのまれてしまうためである。</span>
<span className="v" id="v5" data-v="5" data-xref="コリント人への第二の手紙 1:22; エペソ人への手紙 1:13–14; ローマ人への手紙 8:23"> わたしたちを、この事にかなう者にして下さったのは、神である。そして、神はその保証として御霊をわたしたちに賜わったのである。</span>
<span className="v" id="v6" data-v="6" data-xref="コリント人への第二の手紙 5:1; ピリピ人への手紙 3:20–21; ヘブル人への手紙 11:13"> だから、わたしたちはいつも心強い。そして、肉体を宿としている間は主から離れていることを、よく知っている。</span>
<span className="v" id="v7" data-v="7" data-xref="ヘブル人への手紙 11:1–27; コリント人への第二の手紙 4:18; ローマ人への手紙 8:24–25"> わたしたちは、見えるものによらないで、信仰によって歩いているのである。</span>
<span className="v" id="v8" data-v="8" data-xref="ピリピ人への手紙 1:20–24; コリント人への第二の手紙 5:6; ヨハネによる福音書 14:3"> それで、わたしたちは心強い。そして、むしろ肉体から離れて主と共に住むことが、願わしいと思っている。</span>
<span className="v" id="v9" data-v="9" data-xref="コロサイ人への手紙 1:10; ペテロの第二の手紙 3:14; ローマ人への手紙 14:18"> そういうわけだから、肉体を宿としているにしても、それから離れているにしても、ただ主に喜ばれる者となるのが、心からの願いである。</span>
<span className="v" id="v10" data-v="10" data-xref="マタイによる福音書 16:27; ヨハネの黙示録 22:12; エペソ人への手紙 6:8"> なぜなら、わたしたちは皆、キリストのさばきの座の前にあらわれ、善であれ悪であれ、自分の行ったことに応じて、それぞれ報いを受けねばならないからである。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="ユダの手紙 1:23; ヘブル人への手紙 10:31; テモテヘの第二の手紙 2:24–26"> このようにわたしたちは、主の恐るべきことを知っているので、人々に説き勧める。わたしたちのことは、神のみまえには明らかになっている。さらに、あなたがたの良心にも明らかになるようにと望む。</span>
<span className="v" id="v12" data-v="12" data-xref="コリント人への第二の手紙 3:1; コリント人への第二の手紙 1:14; ガラテヤ人への手紙 6:12–14"> わたしたちは、あなたがたに対して、またもや自己推薦をしようとするのではない。ただわたしたちを誇る機会を、あなたがたに持たせ、心を誇るのではなくうわべだけを誇る人々に答えうるようにさせたいのである。</span>
<span className="v" id="v13" data-v="13" data-xref="コリント人への第二の手紙 11:16–17; コリント人への第二の手紙 11:1; コリント人への第二の手紙 12:6"> もしわたしたちが、気が狂っているのなら、それは神のためであり、気が確かであるのなら、それはあなたがたのためである。</span>
<span className="v" id="v14" data-v="14" data-xref="ガラテヤ人への手紙 2:20; ローマ人への手紙 14:7–9; マタイによる福音書 10:37–38"> なぜなら、キリストの愛がわたしたちに強く迫っているからである。わたしたちはこう考えている。ひとりの人がすべての人のために死んだ以上、すべての人が死んだのである。</span>
<span className="v" id="v15" data-v="15" data-xref="ローマ人への手紙 14:7–9; ペテロの第一の手紙 4:2–4; ペテロの第一の手紙 1:14–15"> そして、彼がすべての人のために死んだのは、生きている者がもはや自分のためにではなく、自分のために死んでよみがえったかたのために、生きるためである。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="コロサイ人への手紙 3:11; ピリピ人への手紙 3:7–8; ヨハネによる福音書 6:63"> それだから、わたしたちは今後、だれをも肉によって知ることはすまい。かつてはキリストを肉によって知っていたとしても、今はもうそのような知り方をすまい。</span>
<span className="v" id="v17" data-v="17" data-xref="エゼキエル書 36:26; エペソ人への手紙 4:22–24; イザヤ書 43:18–19"> だれでもキリストにあるならば、その人は新しく造られた者である。古いものは過ぎ去った、見よ、すべてが新しくなったのである。</span>
<span className="v" id="v18" data-v="18" data-xref="コロサイ人への手紙 1:20–21; コリント人への第二の手紙 5:19–20; ローマ人への手紙 5:10–11"> しかし、すべてこれらの事は、神から出ている。神はキリストによって、わたしたちをご自分に和解させ、かつ和解の務をわたしたちに授けて下さった。</span>
<span className="v" id="v19" data-v="19" data-xref="イザヤ書 43:25; イザヤ書 44:22; ヨハネの第一の手紙 2:1–2"> すなわち、神はキリストにおいて世をご自分に和解させ、その罪過の責任をこれに負わせることをしないで、わたしたちに和解の福音をゆだねられたのである。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="エペソ人への手紙 6:20; ルカによる福音書 14:23; マラキ書 2:7"> 神がわたしたちをとおして勧めをなさるのであるから、わたしたちはキリストの使者なのである。そこで、キリストに代って願う、神の和解を受けなさい。</span>
<span className="v" id="v21" data-v="21" data-xref="ペテロの第一の手紙 2:22–24; ペテロの第一の手紙 3:18; ローマ人への手紙 5:19"> 神はわたしたちの罪のために、罪を知らないかたを罪とされた。それは、わたしたちが、彼にあって神の義となるためなのである。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="コリント人への第二の手紙 12:11; コリント人への第二の手紙 10:12; コリント人への第二の手紙 5:12"> わたしたちは、またもや、自己推薦をし始めているのだろうか。それとも、ある人々のように、あなたがたにあてた、あるいは、あなたがたからの推薦状が必要なのだろうか。</span>
<span className="v" id="v2" data-v="2" data-xref="コリント人への第一の手紙 9:1–2; テサロニケ人への第一の手紙 1:8; ローマ人への手紙 1:8"> わたしたちの推薦状は、あなたがたなのである。それは、わたしたちの心にしるされていて、すべての人に知られ、かつ読まれている。</span>
<span className="v" id="v3" data-v="3" data-xref="エゼキエル書 11:19; エレミヤ書 31:33; ヘブル人への手紙 8:10"> そして、あなたがたは自分自身が、わたしたちから送られたキリストの手紙であって、墨によらず生ける神の霊によって書かれ、石の板にではなく人の心の板に書かれたものであることを、はっきりとあらわしている。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="ピリピ人への手紙 1:6; エペソ人への手紙 3:12; コリント人への第二の手紙 2:14"> こうした確信を、わたしたちはキリストにより神に対していだいている。</span>
<span className="v" id="v5" data-v="5" data-xref="コリント人への第二の手紙 12:9; ピリピ人への手紙 4:13; コリント人への第一の手紙 15:10"> もちろん、自分自身で事を定める力が自分にある、と言うのではない。わたしたちのこうした力は、神からきている。</span>
<span className="v" id="v6" data-v="6" data-xref="ヨハネによる福音書 6:63; ローマ人への手紙 7:6; エレミヤ書 31:31"> 神はわたしたちに力を与えて、新しい契約に仕える者とされたのである。それは、文字に仕える者ではなく、霊に仕える者である。文字は人を殺し、霊は人を生かす。</span>
<span className="v" id="v7" data-v="7" data-xref="コリント人への第二の手紙 3:9–11; ローマ人への手紙 10:4; 出エジプト記 31:18"> もし石に彫りつけた文字による死の務が栄光のうちに行われ、そのためイスラエルの子らは、モーセの顔の消え去るべき栄光のゆえに、その顔を見つめることができなかったとすれば、</span>
<span className="v" id="v8" data-v="8" data-xref="コリント人への第一の手紙 3:16; エペソ人への手紙 2:18; ガラテヤ人への手紙 3:14"> まして霊の務は、はるかに栄光あるものではなかろうか。</span>
<span className="v" id="v9" data-v="9" data-xref="ローマ人への手紙 3:21–22; ヘブル人への手紙 12:18–21; コリント人への第二の手紙 5:21"> もし罪を宣告する務が栄光あるものだとすれば、義を宣告する務は、はるかに栄光に満ちたものである。</span>
<span className="v" id="v10" data-v="10" data-xref="ペテロの第二の手紙 1:17; ハガイ書 2:7–9; 使徒行伝 26:13"> そして、すでに栄光を受けたものも、この場合、はるかにまさった栄光のまえに、その栄光を失ったのである。</span>
<span className="v" id="v11" data-v="11" data-xref="ローマ人への手紙 5:20–21; ヘブル人への手紙 8:13; ヘブル人への手紙 7:21–25"> もし消え去るべきものが栄光をもって現れたのなら、まして永存すべきものは、もっと栄光のあるべきものである。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="コリント人への第二の手紙 7:4; 使徒行伝 4:13; ピリピ人への手紙 1:20"> こうした望みをいだいているので、わたしたちは思いきって大胆に語り、</span>
<span className="v" id="v13" data-v="13" data-xref="出エジプト記 34:33–35; ヘブル人への手紙 10:1–9; エペソ人への手紙 2:14–15"> そしてモーセが、消え去っていくものの最後をイスラエルの子らに見られまいとして、顔におおいをかけたようなことはしない。</span>
<span className="v" id="v14" data-v="14" data-xref="コリント人への第二の手紙 4:3–4; 使徒行伝 26:18; ローマ人への手紙 11:25"> 実際、彼らの思いは鈍くなっていた。今日に至るまで、彼らが古い契約を朗読する場合、その同じおおいが取り去られないままで残っている。それは、キリストにあってはじめて取り除かれるのである。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行伝 13:27–29"> 今日に至るもなお、モーセの書が朗読されるたびに、おおいが彼らの心にかかっている。</span>
<span className="v" id="v16" data-v="16" data-xref="出エジプト記 34:34; イザヤ書 29:18; イザヤ書 25:7"> しかし主に向く時には、そのおおいは取り除かれる。</span>
<span className="v" id="v17" data-v="17" data-xref="ローマ人への手紙 8:2; ガラテヤ人への手紙 5:13; ヨハネによる福音書 8:32"> 主は霊である。そして、主の霊のあるところには、自由がある。</span>
<span className="v" id="v18" data-v="18" data-xref="コリント人への第二の手紙 4:6; エペソ人への手紙 4:22–24; ローマ人への手紙 12:2"> わたしたちはみな、顔おおいなしに、主の栄光を鏡に映すように見つつ、栄光から栄光へと、主と同じ姿に変えられていく。これは霊なる主の働きによるのである。</span>
</div>

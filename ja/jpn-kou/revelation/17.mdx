<span className="v" id="v1" data-v="1" data-xref="ヨハネの黙示録 19:2; ヨハネの黙示録 17:1–17; エレミヤ書 51:13"> それから、七つの鉢を持つ七人の御使のひとりがきて、わたしに語って言った、「さあ、きなさい。多くの水の上にすわっている大淫婦に対するさばきを、見せよう。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネの黙示録 14:8; エレミヤ書 51:7; ヨハネの黙示録 18:3"> 地の王たちはこの女と姦淫を行い、地に住む人々はこの女の姦淫のぶどう酒に酔いしれている」。</span>
<span className="v" id="v3" data-v="3" data-xref="ヨハネの黙示録 12:3; ヨハネの黙示録 13:1–6; ヨハネの黙示録 12:6"> 御使は、わたしを御霊に感じたまま、荒野へ連れて行った。わたしは、そこでひとりの女が赤い獣に乗っているのを見た。その獣は神を汚すかずかずの名でおおわれ、また、それに七つの頭と十の角とがあった。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネの黙示録 18:16; エレミヤ書 51:7; ヨハネの黙示録 19:2"> この女は紫と赤の衣をまとい、金と宝石と真珠とで身を飾り、憎むべきものと自分の姦淫の汚れとで満ちている金の杯を手に持ち、</span>
<span className="v" id="v5" data-v="5" data-xref="ヨハネの黙示録 14:8; ヨハネの黙示録 18:2; ヨハネの黙示録 17:7"> その額には、一つの名がしるされていた。それは奥義であって、「大いなるバビロン、淫婦どもと地の憎むべきものらとの母」というのであった。</span>
<span className="v" id="v6" data-v="6" data-xref="ヨハネの黙示録 16:6; ヨハネの黙示録 13:15; ヨハネの黙示録 2:13"> わたしは、この女が聖徒の血とイエスの証人の血に酔いしれているのを見た。<br />この女を見た時、わたしは非常に驚きあやしんだ。</span>
<span className="v" id="v7" data-v="7" data-xref="ヨハネの黙示録 17:1–6; ヨハネの黙示録 17:8"> すると、御使はわたしに言った、「なぜそんなに驚くのか。この女の奥義と、女を乗せている七つの頭と十の角のある獣の奥義とを、話してあげよう。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨハネの黙示録 17:11; ヨハネの黙示録 11:7; ヨハネの黙示録 3:10"> あなたの見た獣は、昔はいたが、今はおらず、そして、やがて底知れぬ所から上ってきて、ついには滅びに至るものである。地に住む者のうち、世の初めからいのちの書に名をしるされていない者たちは、この獣が、昔はいたが今はおらず、やがて来るのを見て、驚きあやしむであろう。</span>
<span className="v" id="v9" data-v="9" data-xref="ヨハネの黙示録 13:18; ヨハネの黙示録 17:7; マタイによる福音書 13:11"> ここに、知恵のある心が必要である。七つの頭は、この女のすわっている七つの山であり、また、七人の王のことである。</span>
<span className="v" id="v10" data-v="10"> そのうちの五人はすでに倒れ、ひとりは今おり、もうひとりは、まだきていない。それが来れば、しばらくの間だけおることになっている。</span>
<span className="v" id="v11" data-v="11" data-xref="ヨハネの黙示録 17:8"> 昔はいたが今はいないという獣は、すなわち第八のものであるが、またそれは、かの七人の中のひとりであって、ついには滅びに至るものである。</span>
<span className="v" id="v12" data-v="12" data-xref="ヨハネの黙示録 12:3; ヨハネの黙示録 13:1; ダニエル書 7:24"> あなたの見た十の角は、十人の王のことであって、彼らはまだ国を受けてはいないが、獣と共に、一時だけ王としての権威を受ける。</span>
<span className="v" id="v13" data-v="13" data-xref="ヨハネの黙示録 17:17; エゼキエル書 38:10; イザヤ書 10:5–7"> 彼らは心をひとつにしている。そして、自分たちの力と権威とを獣に与える。</span>
<span className="v" id="v14" data-v="14" data-xref="ローマ人への手紙 8:30; テモテヘの第一の手紙 6:15; マタイによる福音書 22:14"> 彼らは小羊に戦いをいどんでくるが、小羊は、主の主、王の王であるから、彼らにうち勝つ。また、小羊と共にいる召された、選ばれた、忠実な者たちも、勝利を得る」。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="ヨハネの黙示録 17:1; エレミヤ書 51:13; エレミヤ書 51:55"> 御使はまた、わたしに言った、「あなたの見た水、すなわち、淫婦のすわっている所は、あらゆる民族、群衆、国民、国語である。</span>
<span className="v" id="v16" data-v="16" data-xref="ヨハネの黙示録 18:8; エゼキエル書 16:37–44; レビ記 21:9"> あなたの見た十の角と獣とは、この淫婦を憎み、みじめな者にし、裸にし、彼女の肉を食い、火で焼き尽すであろう。</span>
<span className="v" id="v17" data-v="17" data-xref="テサロニケ人への第二の手紙 2:10–12; 箴言 21:1; ヨハネの黙示録 10:7"> 神は、御言が成就する時まで、彼らの心の中に、御旨を行い、思いをひとつにし、彼らの支配権を獣に与える思いを持つようにされたからである。</span>
<span className="v" id="v18" data-v="18" data-xref="ヨハネの黙示録 16:19; ヨハネの黙示録 18:2; ダニエル書 7:23"> あなたの見たかの女は、地の王たちを支配する大いなる都のことである」。</span>

<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="ヨハネの黙示録 7:10–12; 歴代志上 29:11; ヨハネの黙示録 11:15"> この後、わたしは天の大群衆が大声で唱えるような声を聞いた、<br /><span className="pl pl-1">「ハレルヤ、救と栄光と力とは、</span><br /><span className="pl pl-1">われらの神のものであり、</span></span>
<span className="v" id="v2" data-v="2" data-xref="申命記 32:43; ヨハネの黙示録 6:10; ヨハネの黙示録 18:20"> <span className="pl pl-1">そのさばきは、真実で正しい。</span><br /><span className="pl pl-1">神は、姦淫で地を汚した大淫婦をさばき、</span><br /><span className="pl pl-1">神の僕たちの血の報復を</span><br /><span className="pl pl-1">彼女になさったからである」。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v3" data-v="3" data-xref="イザヤ書 34:10; ヨハネの黙示録 18:18; ヨハネの黙示録 14:11"> 再び声があって、「ハレルヤ、彼女が焼かれる火の煙は、世々限りなく立ちのぼる」と言った。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネの黙示録 5:14; ネヘミヤ書 8:6; 詩篇 106:48"> すると、二十四人の長老と四つの生き物とがひれ伏し、御座にいます神を拝して言った、「アァメン、ハレルヤ」。</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 134:1; 詩篇 148:11–13; 詩篇 150:6"> その時、御座から声が出て言った、<br /><span className="pl pl-1">「すべての神の僕たちよ、神をおそれる者たちよ。</span><br /><span className="pl pl-1">小さき者も大いなる者も、</span><br /><span className="pl pl-1">共に、われらの神をさんびせよ」。</span></span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 97:1; ヨハネの黙示録 14:2; 詩篇 93:1"> <span className="pl pl-1">わたしはまた、大群衆の声、多くの水の音、また激しい雷鳴のようなものを聞いた。それはこう言った、</span><br /><span className="pl pl-1">「ハレルヤ、全能者にして主なるわれらの神は、</span><br /><span className="pl pl-1">王なる支配者であられる。</span></span>
<span className="v" id="v7" data-v="7" data-xref="ヨハネの黙示録 21:9; ヨハネの黙示録 21:2; ヨハネの黙示録 19:9"> <span className="pl pl-1">わたしたちは喜び楽しみ、神をあがめまつろう。</span><br /><span className="pl pl-1">小羊の婚姻の時がきて、</span><br /><span className="pl pl-1">花嫁はその用意をしたからである。</span></span>
<span className="v" id="v8" data-v="8" data-xref="イザヤ書 61:10; ヨハネの黙示録 7:13–14; 詩篇 132:9"> <span className="pl pl-1">彼女は、光り輝く、</span><br /><span className="pl pl-1">汚れのない麻布の衣を着ることを許された。</span><br /><span className="pl pl-1">この麻布の衣は、聖徒たちの正しい行いである」。</span></span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="ヨハネの黙示録 22:6; マタイによる福音書 22:2–4; ルカによる福音書 14:15–16"> それから、御使はわたしに言った、「書きしるせ。小羊の婚宴に招かれた者は、さいわいである」。またわたしに言った、「これらは、神の真実の言葉である」。</span>
<span className="v" id="v10" data-v="10" data-xref="ヨハネの黙示録 22:8–9; 使徒行伝 10:25–26; ヨハネによる福音書 5:39"> そこで、わたしは彼の足もとにひれ伏して、彼を拝そうとした。すると、彼は言った、「そのようなことをしてはいけない。わたしは、あなたと同じ僕仲間であり、またイエスのあかしびとであるあなたの兄弟たちと同じ僕仲間である。ただ神だけを拝しなさい。イエスのあかしは、すなわち預言の霊である」。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="詩篇 96:13; イザヤ書 11:3–5; 詩篇 98:9"> またわたしが見ていると、天が開かれ、見よ、そこに白い馬がいた。それに乗っているかたは、「忠実で真実な者」と呼ばれ、義によってさばき、また、戦うかたである。</span>
<span className="v" id="v12" data-v="12" data-xref="ヨハネの黙示録 19:16; ルカによる福音書 10:22; ヨハネの黙示録 2:17–18"> その目は燃える炎であり、その頭には多くの冠があった。また、彼以外にはだれも知らない名がその身にしるされていた。</span>
<span className="v" id="v13" data-v="13" data-xref="ヨハネによる福音書 1:1; イザヤ書 63:1–6; ヨハネによる福音書 1:14"> 彼は血染めの衣をまとい、その名は「神の言」と呼ばれた。</span>
<span className="v" id="v14" data-v="14" data-xref="ユダの手紙 1:14; ヨハネの黙示録 7:9; ヨハネの黙示録 19:8"> そして、天の軍勢が、純白で、汚れのない麻布の衣を着て、白い馬に乗り、彼に従った。</span>
<span className="v" id="v15" data-v="15" data-xref="イザヤ書 63:2–6; ヨハネの黙示録 1:16; ヨハネの黙示録 2:27"> その口からは、諸国民を打つために、鋭いつるぎが出ていた。彼は、鉄のつえをもって諸国民を治め、また、全能者なる神の激しい怒りの酒ぶねを踏む。</span>
<span className="v" id="v16" data-v="16" data-xref="ヨハネの黙示録 17:14; テモテヘの第一の手紙 6:15; ダニエル書 2:47"> その着物にも、そのももにも、「王の王、主の主」という名がしるされていた。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="ヨハネの黙示録 19:21; ヨハネの黙示録 8:13; エゼキエル書 39:17–20"> また見ていると、ひとりの御使が太陽の中に立っていた。彼は、中空を飛んでいるすべての鳥にむかって、大声で叫んだ、「さあ、神の大宴会に集まってこい。</span>
<span className="v" id="v18" data-v="18" data-xref="エゼキエル書 39:18–20; ヨハネの黙示録 6:15; サムエル記上 17:44"> そして、王たちの肉、将軍の肉、勇者の肉、馬の肉、馬に乗っている者の肉、また、すべての自由人と奴隷との肉、小さき者と大いなる者との肉をくらえ」。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="ヨハネの黙示録 16:16; ヨハネの黙示録 16:14; ヨハネの黙示録 17:12–14"> なお見ていると、獣と地の王たちと彼らの軍勢とが集まり、馬に乗っているかたとその軍勢とに対して、戦いをいどんだ。</span>
<span className="v" id="v20" data-v="20" data-xref="ヨハネの黙示録 20:10; ヨハネの黙示録 21:8; テサロニケ人への第二の手紙 2:8–11"> しかし、獣は捕えられ、また、この獣の前でしるしを行って、獣の刻印を受けた者とその像を拝む者とを惑わしたにせ預言者も、獣と共に捕えられた。そして、この両者とも、生きながら、硫黄の燃えている火の池に投げ込まれた。</span>
<span className="v" id="v21" data-v="21" data-xref="ヨハネの黙示録 19:11–15; ヨハネの黙示録 1:16; ヨハネの黙示録 19:17–19"> それ以外の者たちは、馬に乗っておられるかたの口から出るつるぎで切り殺され、その肉を、すべての鳥が飽きるまで食べた。</span>
</div>

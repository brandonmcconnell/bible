<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="エゼキエル書 43:2; ルカによる福音書 17:24; テサロニケ人への第二の手紙 2:8"> この後、わたしは、もうひとりの御使が、大いなる権威を持って、天から降りて来るのを見た。地は彼の栄光によって明るくされた。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネの黙示録 14:8; エレミヤ書 51:8; エレミヤ書 51:37"> 彼は力強い声で叫んで言った、「倒れた、大いなるバビロンは倒れた。そして、それは悪魔の住む所、あらゆる汚れた霊の巣くつ、また、あらゆる汚れた憎むべき鳥の巣くつとなった。</span>
<span className="v" id="v3" data-v="3" data-xref="ヨハネの黙示録 14:8; ヨハネの黙示録 17:2; ヨハネの黙示録 18:9"> すべての国民は、彼女の姦淫に対する激しい怒りのぶどう酒を飲み、地の王たちは彼女と姦淫を行い、地上の商人たちは、彼女の極度のぜいたくによって富を得たからである」。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="イザヤ書 52:11; コリント人への第二の手紙 6:17; エレミヤ書 51:6"> わたしはまた、もうひとつの声が天から出るのを聞いた、「わたしの民よ。彼女から離れ去って、その罪にあずからないようにし、その災害に巻き込まれないようにせよ。</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 18:20–21; エズラ記 9:6; ヨハネの黙示録 16:19"> 彼女の罪は積り積って天に達しており、神はその不義の行いを覚えておられる。</span>
<span className="v" id="v6" data-v="6" data-xref="エレミヤ書 50:29; 詩篇 137:8; エレミヤ書 51:24"> 彼女がしたとおりに彼女にし返し、そのしわざに応じて二倍に報復をし、彼女が混ぜて入れた杯の中に、その倍の量を、入れてやれ。</span>
<span className="v" id="v7" data-v="7" data-xref="イザヤ書 47:7–9; ゼパニヤ書 2:15; 哀歌 1:1"> 彼女が自ら高ぶり、ぜいたくをほしいままにしたので、それに対して、同じほどの苦しみと悲しみとを味わわせてやれ。彼女は心の中で『わたしは女王の位についている者であって、やもめではないのだから、悲しみを知らない』と言っている。</span>
<span className="v" id="v8" data-v="8" data-xref="エレミヤ書 50:34; エレミヤ書 50:31; ヨハネの黙示録 17:16"> それゆえ、さまざまの災害が、死と悲しみとききんとが、一日のうちに彼女を襲い、そして、彼女は火で焼かれてしまう。彼女をさばく主なる神は、力強いかたなのである。</span>
<span className="v" id="v9" data-v="9" data-xref="ヨハネの黙示録 19:3; ヨハネの黙示録 18:3; ヨハネの黙示録 17:2"> 彼女と姦淫を行い、ぜいたくをほしいままにしていた地の王たちは、彼女が焼かれる火の煙を見て、彼女のために胸を打って泣き悲しみ、</span>
<span className="v" id="v10" data-v="10" data-xref="ヨハネの黙示録 18:19; ヨハネの黙示録 18:8; ヨハネの黙示録 18:15–17"> 彼女の苦しみに恐れをいだき、遠くに立って言うであろう、『ああ、わざわいだ、大いなる都、不落の都、バビロンは、わざわいだ。おまえに対するさばきは、一瞬にしてきた』。</span>
<span className="v" id="v11" data-v="11" data-xref="ヨハネの黙示録 18:3; ヨハネの黙示録 18:23; エゼキエル書 27:27–36"> また、地の商人たちも彼女のために泣き悲しむ。もはや、彼らの商品を買う者が、ひとりもないからである。</span>
<span className="v" id="v12" data-v="12" data-xref="ヨハネの黙示録 17:4; エゼキエル書 27:5–25; 箴言 8:10–11"> その商品は、金、銀、宝石、真珠、麻布、紫布、絹、緋布、各種の香木、各種の象牙細工、高価な木材、銅、鉄、大理石などの器、</span>
<span className="v" id="v13" data-v="13" data-xref="エゼキエル書 27:13; アモス書 2:6; ペテロの第二の手紙 2:3"> 肉桂、香料、香、におい油、乳香、ぶどう酒、オリブ油、麦粉、麦、牛、羊、馬、車、奴隷、そして人身などである。</span>
<span className="v" id="v14" data-v="14" data-xref="コリント人への第一の手紙 10:6; 詩篇 106:14; ルカによる福音書 16:25"> おまえの心の喜びであったくだものはなくなり、あらゆるはでな、はなやかな物はおまえから消え去った。それらのものはもはや見られない。</span>
<span className="v" id="v15" data-v="15" data-xref="ヨハネの黙示録 18:3; 使徒行伝 19:24–27; エゼキエル書 27:31"> これらの品々を売って、彼女から富を得た商人は、彼女の苦しみに恐れをいだいて遠くに立ち、泣き悲しんで言う、</span>
<span className="v" id="v16" data-v="16" data-xref="ヨハネの黙示録 17:4; ルカによる福音書 16:19–31; ヨハネの黙示録 18:10–11"> 『ああ、わざわいだ、麻布と紫布と緋布をまとい、金や宝石や真珠で身を飾っていた大いなる都は、わざわいだ。</span>
<span className="v" id="v17" data-v="17" data-xref="エゼキエル書 27:27–36; ヨハネの黙示録 17:16; イザヤ書 23:14"> これほどの富が、一瞬にして無に帰してしまうとは』。また、すべての船長、航海者、水夫、すべて海で働いている人たちは、遠くに立ち、</span>
<span className="v" id="v18" data-v="18" data-xref="ヨハネの黙示録 13:4; エゼキエル書 27:30–32; ヨハネの黙示録 18:9–10"> 彼女が焼かれる火の煙を見て、叫んで言う、『これほどの大いなる都は、どこにあろう』。</span>
<span className="v" id="v19" data-v="19" data-xref="ヨハネの黙示録 18:10; ヨシュア記 7:6; エゼキエル書 27:30"> 彼らは頭にちりをかぶり、泣き悲しんで叫ぶ、『ああ、わざわいだ、この大いなる都は、わざわいだ。そのおごりによって、海に舟を持つすべての人が富を得ていたのに、この都も一瞬にして無に帰してしまった』。</span>
<span className="v" id="v20" data-v="20" data-xref="ヨハネの黙示録 6:10; ヨハネの黙示録 19:1–3; ルカによる福音書 18:7–8"> 天よ、聖徒たちよ、使徒たちよ、預言者たちよ。この都について大いに喜べ。神は、あなたがたのために、この都をさばかれたのである」。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="エレミヤ書 51:63–64; エゼキエル書 26:21; ヨハネの黙示録 5:2"> すると、ひとりの力強い御使が、大きなひきうすのような石を持ちあげ、それを海に投げ込んで言った、「大いなる都バビロンは、このように激しく打ち倒され、そして、全く姿を消してしまう。</span>
<span className="v" id="v22" data-v="22" data-xref="エゼキエル書 26:13; エレミヤ書 25:10; エレミヤ書 7:34"> また、おまえの中では、立琴をひく者、歌を歌う者、笛を吹く者、ラッパを吹き鳴らす者の楽の音は全く聞かれず、あらゆる仕事の職人たちも全く姿を消し、また、ひきうすの音も、全く聞かれない。</span>
<span className="v" id="v23" data-v="23" data-xref="ヨハネの黙示録 18:3; イザヤ書 23:8; ナホム書 3:4"> また、おまえの中では、あかりもともされず、花婿、花嫁の声も聞かれない。というのは、おまえの商人たちは地上で勢力を張る者となり、すべての国民はおまえのまじないでだまされ、</span>
<span className="v" id="v24" data-v="24" data-xref="ヨハネの黙示録 17:6; ヨハネの黙示録 16:6; エレミヤ書 51:49"> また、預言者や聖徒の血、さらに、地上で殺されたすべての者の血が、この都で流されたからである」。</span>
</div>

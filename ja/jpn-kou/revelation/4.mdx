<span className="v" id="v1" data-v="1" data-xref="ヨハネの黙示録 11:12; 出エジプト記 24:12; ヨハネの黙示録 1:19"> その後、わたしが見ていると、見よ、開いた門が天にあった。そして、さきにラッパのような声でわたしに呼びかけるのを聞いた初めの声が、「ここに上ってきなさい。そうしたら、これから後に起るべきことを、見せてあげよう」と言った。</span>
<span className="v" id="v2" data-v="2" data-xref="列王紀上 22:19; ヨハネの黙示録 1:10; イザヤ書 6:1"> すると、たちまち、わたしは御霊に感じた。見よ、御座が天に設けられており、その御座にいますかたがあった。</span>
<span className="v" id="v3" data-v="3" data-xref="エゼキエル書 1:28; ヨハネの黙示録 21:11; 創世記 9:13–16"> その座にいますかたは、碧玉や赤めのうのように見え、また、御座のまわりには、緑玉のように見えるにじが現れていた。</span>
<span className="v" id="v4" data-v="4" data-xref="マタイによる福音書 19:28; ヨハネの黙示録 11:16; ヨハネの黙示録 4:10"> また、御座のまわりには二十四の座があって、二十四人の長老が白い衣を身にまとい、頭に金の冠をかぶって、それらの座についていた。</span>
<span className="v" id="v5" data-v="5" data-xref="ヨハネの黙示録 11:19; ヨハネの黙示録 8:5; ヨハネの黙示録 1:4"> 御座からは、いなずまと、もろもろの声と、雷鳴とが、発していた。また、七つのともし火が、御座の前で燃えていた。これらは、神の七つの霊である。</span>
<span className="v" id="v6" data-v="6" data-xref="ヨハネの黙示録 15:2; ヨハネの黙示録 5:6; ヨハネの黙示録 14:3"> 御座の前は、水晶に似たガラスの海のようであった。御座のそば近くそのまわりには、四つの生き物がいたが、その前にも後にも、一面に目がついていた。</span>
<span className="v" id="v7" data-v="7" data-xref="エゼキエル書 10:14; エゼキエル書 1:10; エゼキエル書 10:21"> 第一の生き物はししのようであり、第二の生き物は雄牛のようであり、第三の生き物は人のような顔をしており、第四の生き物は飛ぶわしのようであった。</span>
<span className="v" id="v8" data-v="8" data-xref="イザヤ書 6:2–13; ヨハネの黙示録 1:8; ヘブル人への手紙 13:8"> この四つの生き物には、それぞれ六つの翼があり、その翼のまわりも内側も目で満ちていた。そして、昼も夜も、絶え間なくこう叫びつづけていた、<br /><span className="pl pl-1">「聖なるかな、聖なるかな、聖なるかな、</span><br /><span className="pl pl-1">全能者にして主なる神。</span><br /><span className="pl pl-1">昔いまし、今いまし、やがてきたるべき者」。</span></span>
<span className="v" id="v9" data-v="9" data-xref="ヨハネの黙示録 5:13–14; ヨハネの黙示録 7:11–12; ヨハネの黙示録 10:6"> <span className="pl pl-1">これらの生き物が、御座にいまし、かつ、世々限りなく生きておられるかたに、栄光とほまれとを帰し、また、感謝をささげている時、</span></span>
<span className="v" id="v10" data-v="10" data-xref="ヨハネの黙示録 5:8; ヨハネの黙示録 19:4; 詩篇 95:6"> <span className="pl pl-1">二十四人の長老は、御座にいますかたのみまえにひれ伏し、世々限りなく生きておられるかたを拝み、彼らの冠を御座のまえに、投げ出して言った、</span></span>
<span className="v" id="v11" data-v="11" data-xref="コロサイ人への手紙 1:16–17; ヨハネの黙示録 5:12; イザヤ書 40:28"> <span className="pl pl-1">「われらの主なる神よ、</span><br /><span className="pl pl-1">あなたこそは、</span><br /><span className="pl pl-1">栄光とほまれと力とを受けるにふさわしいかた。</span><br /><span className="pl pl-1">あなたは万物を造られました。</span><br /><span className="pl pl-1">御旨によって、万物は存在し、</span><br /><span className="pl pl-1">また造られたのであります」。</span></span>

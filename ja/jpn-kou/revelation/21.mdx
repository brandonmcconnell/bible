<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="イザヤ書 65:17–19; ペテロの第二の手紙 3:13; イザヤ書 66:22"> わたしはまた、新しい天と新しい地とを見た。先の天と地とは消え去り、海もなくなってしまった。</span>
<span className="v" id="v2" data-v="2" data-xref="ヘブル人への手紙 11:10; ヨハネの黙示録 3:12; ヨハネの黙示録 21:10"> また、聖なる都、新しいエルサレムが、夫のために着飾った花嫁のように用意をととのえて、神のもとを出て、天から下って来るのを見た。</span>
<span className="v" id="v3" data-v="3" data-xref="エゼキエル書 37:27; コリント人への第二の手紙 6:16; ヨハネによる福音書 14:23"> また、御座から大きな声が叫ぶのを聞いた、「見よ、神の幕屋が人と共にあり、神が人と共に住み、人は神の民となり、神自ら人と共にいまして、</span>
<span className="v" id="v4" data-v="4" data-xref="イザヤ書 25:8; ヨハネの黙示録 7:17; コリント人への第一の手紙 15:26"> 人の目から涙を全くぬぐいとって下さる。もはや、死もなく、悲しみも、叫びも、痛みもない。先のものが、すでに過ぎ去ったからである」。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="コリント人への第二の手紙 5:17; イザヤ書 42:9; イザヤ書 43:19"> すると、御座にいますかたが言われた、「見よ、わたしはすべてのものを新たにする」。また言われた、「書きしるせ。これらの言葉は、信ずべきであり、まことである」。</span>
<span className="v" id="v6" data-v="6" data-xref="ヨハネによる福音書 7:37–38; ヨハネによる福音書 4:10; ヨハネの黙示録 7:17"> そして、わたしに仰せられた、「事はすでに成った。わたしは、アルパでありオメガである。初めであり終りである。かわいている者には、いのちの水の泉から価なしに飲ませよう。</span>
<span className="v" id="v7" data-v="7" data-xref="コリント人への第二の手紙 6:18; ヘブル人への手紙 8:10; ヨハネの黙示録 2:11"> 勝利を得る者は、これらのものを受け継ぐであろう。わたしは彼の神となり、彼はわたしの子となる。</span>
<span className="v" id="v8" data-v="8" data-xref="コリント人への第一の手紙 6:9–10; ヨハネの黙示録 2:11; エペソ人への手紙 5:5–6"> しかし、おくびょうな者、信じない者、忌むべき者、人殺し、姦淫を行う者、まじないをする者、偶像を拝む者、すべて偽りを言う者には、火と硫黄の燃えている池が、彼らの受くべき報いである。これが第二の死である」。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="ヨハネの黙示録 21:2; ヨハネの黙示録 19:7; ヨハネの黙示録 16:1–17"> 最後の七つの災害が満ちている七つの鉢を持っていた七人の御使のひとりがきて、わたしに語って言った、「さあ、きなさい。小羊の妻なる花嫁を見せよう」。</span>
<span className="v" id="v10" data-v="10" data-xref="ヨハネの黙示録 21:2; エゼキエル書 11:24; エゼキエル書 40:1–49"> この御使は、わたしを御霊に感じたまま、大きな高い山に連れて行き、聖都エルサレムが、神の栄光のうちに、神のみもとを出て天から下って来るのを見せてくれた。</span>
<span className="v" id="v11" data-v="11" data-xref="ヨハネの黙示録 4:6; ヨハネの黙示録 22:5; ヨハネの黙示録 22:1"> その都の輝きは、高価な宝石のようであり、透明な碧玉のようであった。</span>
<span className="v" id="v12" data-v="12" data-xref="エゼキエル書 48:31–34; ヨハネの黙示録 7:4–8; ヨハネの黙示録 21:17–21"> それには大きな、高い城壁があって、十二の門があり、それらの門には、十二の御使がおり、イスラエルの子らの十二部族の名が、それに書いてあった。</span>
<span className="v" id="v13" data-v="13" data-xref="エゼキエル書 48:31–34"> 東に三つの門、北に三つの門、南に三つの門、西に三つの門があった。</span>
<span className="v" id="v14" data-v="14" data-xref="ヘブル人への手紙 11:10; エペソ人への手紙 2:20; イザヤ書 54:11"> また都の城壁には十二の土台があり、それには小羊の十二使徒の十二の名が書いてあった。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="ゼカリヤ書 2:1; ヨハネの黙示録 11:1–2; エゼキエル書 41:1–5"> わたしに語っていた者は、都とその門と城壁とを測るために、金の測りざおを持っていた。</span>
<span className="v" id="v16" data-v="16" data-xref="エゼキエル書 48:35; エゼキエル書 48:8–20"> 都は方形であって、その長さと幅とは同じである。彼がその測りざおで都を測ると、一万二千丁であった。長さと幅と高さとは、いずれも同じである。</span>
<span className="v" id="v17" data-v="17" data-xref="ヨハネの黙示録 7:4; 申命記 3:11; ヨハネの黙示録 13:18"> また城壁を測ると、百四十四キュビトであった。これは人間の、すなわち、御使の尺度によるのである。</span>
<span className="v" id="v18" data-v="18" data-xref="ヨハネの黙示録 21:11; ヨハネの黙示録 21:21; ヨハネの黙示録 21:19"> 城壁は碧玉で築かれ、都はすきとおったガラスのような純金で造られていた。</span>
<span className="v" id="v19" data-v="19" data-xref="イザヤ書 54:11–12; 出エジプト記 28:17–21; ヨブ記 28:16–19"> 都の城壁の土台は、さまざまな宝石で飾られていた。第一の土台は碧玉、第二はサファイヤ、第三はめのう、第四は緑玉、</span>
<span className="v" id="v20" data-v="20" data-xref="ヨハネの黙示録 4:3"> 第五は縞めのう、第六は赤めのう、第七はかんらん石、第八は緑柱石、第九は黄玉石、第十はひすい、第十一は青玉、第十二は紫水晶であった。</span>
<span className="v" id="v21" data-v="21" data-xref="ヨハネの黙示録 21:18; ヨハネの黙示録 17:4; ヨハネの黙示録 22:2"> 十二の門は十二の真珠であり、門はそれぞれ一つの真珠で造られ、都の大通りは、すきとおったガラスのような純金であった。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="ヨハネによる福音書 4:23; 列王紀上 8:27; 歴代志下 2:6"> わたしは、この都の中には聖所を見なかった。全能者にして主なる神と小羊とが、その聖所なのである。</span>
<span className="v" id="v23" data-v="23" data-xref="イザヤ書 60:19–20; ヨハネの黙示録 22:5; ヨハネの黙示録 21:11"> 都は、日や月がそれを照す必要がない。神の栄光が都を明るくし、小羊が都のあかりだからである。</span>
<span className="v" id="v24" data-v="24" data-xref="ヨハネの黙示録 21:26; ヨハネの黙示録 22:2; ゼカリヤ書 8:22–23"> 諸国民は都の光の中を歩き、地の王たちは、自分たちの光栄をそこに携えて来る。</span>
<span className="v" id="v25" data-v="25" data-xref="イザヤ書 60:11; ゼカリヤ書 14:7; ヨハネの黙示録 22:5"> 都の門は、終日、閉ざされることはない。そこには夜がないからである。</span>
<span className="v" id="v26" data-v="26" data-xref="ヨハネの黙示録 21:24"> 人々は、諸国民の光栄とほまれとをそこに携えて来る。</span>
<span className="v" id="v27" data-v="27" data-xref="ヨハネの黙示録 22:14–15; イザヤ書 52:1; ヨハネの黙示録 20:15"> しかし、汚れた者や、忌むべきこと及び偽りを行う者は、その中に決してはいれない。はいれる者は、小羊のいのちの書に名をしるされている者だけである。</span>
</div>

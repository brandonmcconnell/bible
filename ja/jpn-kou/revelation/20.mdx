<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨハネの黙示録 1:18; ペテロの第二の手紙 2:4; ユダの手紙 1:6"> またわたしが見ていると、ひとりの御使が、底知れぬ所のかぎと大きな鎖とを手に持って、天から降りてきた。</span>
<span className="v" id="v2" data-v="2" data-xref="ペテロの第二の手紙 2:4; ヨハネの黙示録 12:9; イザヤ書 27:1"> 彼は、悪魔でありサタンである龍、すなわち、かの年を経たへびを捕えて千年の間つなぎおき、</span>
<span className="v" id="v3" data-v="3" data-xref="ヨハネの黙示録 20:1; ヨハネの黙示録 17:8; テサロニケ人への第二の手紙 2:9–11"> そして、底知れぬ所に投げ込み、入口を閉じてその上に封印し、千年の期間が終るまで、諸国民を惑わすことがないようにしておいた。その後、しばらくの間だけ解放されることになっていた。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="ダニエル書 7:27; ダニエル書 7:18; マタイによる福音書 19:28"> また見ていると、かず多くの座があり、その上に人々がすわっていた。そして、彼らにさばきの権が与えられていた。また、イエスのあかしをし神の言を伝えたために首を切られた人々の霊がそこにおり、また、獣をもその像をも拝まず、その刻印を額や手に受けることをしなかった人々がいた。彼らは生きかえって、キリストと共に千年の間、支配した。</span>
<span className="v" id="v5" data-v="5" data-xref="ピリピ人への手紙 3:11; ヨハネの黙示録 11:15; ルカによる福音書 14:14"> （それ以外の死人は、千年の期間が終るまで生きかえらなかった。）これが第一の復活である。</span>
<span className="v" id="v6" data-v="6" data-xref="ヨハネの黙示録 2:11; ヨハネの黙示録 1:6; テモテヘの第二の手紙 2:12"> この第一の復活にあずかる者は、さいわいな者であり、また聖なる者である。この人たちに対しては、第二の死はなんの力もない。彼らは神とキリストとの祭司となり、キリストと共に千年の間、支配する。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="ヨハネの黙示録 20:2"> 千年の期間が終ると、サタンはその獄から解放される。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨハネの黙示録 16:14; エゼキエル書 38:1; ヨハネの黙示録 20:10"> そして、出て行き、地の四方にいる諸国民、すなわちゴグ、マゴグを惑わし、彼らを戦いのために召集する。その数は、海の砂のように多い。</span>
<span className="v" id="v9" data-v="9" data-xref="エゼキエル書 38:16; エゼキエル書 39:6; エゼキエル書 38:9"> 彼らは地上の広い所に上ってきて、聖徒たちの陣営と愛されていた都とを包囲した。すると、天から火が下ってきて、彼らを焼き尽した。</span>
<span className="v" id="v10" data-v="10" data-xref="マタイによる福音書 25:41; ヨハネの黙示録 19:20; マタイによる福音書 25:46"> そして、彼らを惑わした悪魔は、火と硫黄との池に投げ込まれた。そこには、獣もにせ預言者もいて、彼らは世々限りなく日夜、苦しめられるのである。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="ヨハネの黙示録 21:1; ペテロの第二の手紙 3:7; マタイによる福音書 25:31"> また見ていると、大きな白い御座があり、そこにいますかたがあった。天も地も御顔の前から逃げ去って、あとかたもなくなった。</span>
<span className="v" id="v12" data-v="12" data-xref="コリント人への第二の手紙 5:10; マタイによる福音書 16:27; ダニエル書 7:10"> また、死んでいた者が、大いなる者も小さき者も共に、御座の前に立っているのが見えた。かずかずの書物が開かれたが、もう一つの書物が開かれた。これはいのちの書であった。死人はそのしわざに応じ、この書物に書かれていることにしたがって、さばかれた。</span>
<span className="v" id="v13" data-v="13" data-xref="ヨハネによる福音書 5:28–29; ヨハネの黙示録 6:8; ホセア書 13:14"> 海はその中にいる死人を出し、死も黄泉もその中にいる死人を出し、そして、おのおのそのしわざに応じて、さばきを受けた。</span>
<span className="v" id="v14" data-v="14" data-xref="コリント人への第一の手紙 15:26; ヨハネの黙示録 20:6; ヨハネの黙示録 21:8"> それから、死も黄泉も火の池に投げ込まれた。この火の池が第二の死である。</span>
<span className="v" id="v15" data-v="15" data-xref="ヨハネによる福音書 3:36; マタイによる福音書 13:50; マタイによる福音書 25:41"> このいのちの書に名がしるされていない者はみな、火の池に投げ込まれた。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="テモテヘの第一の手紙 5:6; ヤコブの手紙 2:26; ヨハネの黙示録 1:4"> サルデスにある教会の御使に、こう書きおくりなさい。<br />『神の七つの霊と七つの星とを持つかたが、次のように言われる。わたしはあなたのわざを知っている。すなわち、あなたは、生きているというのは名だけで、実は死んでいる。</span>
<span className="v" id="v2" data-v="2" data-xref="ペテロの第一の手紙 5:8; テモテヘの第二の手紙 4:1–4; ヨハネの黙示録 16:15"> 目をさましていて、死にかけている残りの者たちを力づけなさい。わたしは、あなたのわざが、わたしの神のみまえに完全であるとは見ていない。</span>
<span className="v" id="v3" data-v="3" data-xref="ヨハネの黙示録 2:5; ペテロの第二の手紙 3:10; テサロニケ人への第一の手紙 5:2"> だから、あなたが、どのようにして受けたか、また聞いたかを思い起して、それを守りとおし、かつ悔い改めなさい。もし目をさましていないなら、わたしは盗人のように来るであろう。どんな時にあなたのところに来るか、あなたには決してわからない。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネの黙示録 3:5; ヨハネの黙示録 7:9; 伝道の書 9:8"> しかし、サルデスにはその衣を汚さない人が、数人いる。彼らは白い衣を着て、わたしと共に歩みを続けるであろう。彼らは、それにふさわしい者である。</span>
<span className="v" id="v5" data-v="5" data-xref="マタイによる福音書 10:32; ルカによる福音書 12:8; ヨハネの黙示録 21:27"> 勝利を得る者は、このように白い衣を着せられるのである。わたしは、その名をいのちの書から消すようなことを、決してしない。また、わたしの父と御使たちの前で、その名を言いあらわそう。</span>
<span className="v" id="v6" data-v="6" data-xref="ヨハネの黙示録 2:7"> 耳のある者は、御霊が諸教会に言うことを聞くがよい』。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="イザヤ書 22:22; マタイによる福音書 16:19; ヨハネの黙示録 1:18"> ヒラデルヒヤにある教会の御使に、こう書きおくりなさい。<br />『聖なる者、まことなる者、ダビデのかぎを持つ者、開けばだれにも閉じられることがなく、閉じればだれにも開かれることのない者が、次のように言われる。</span>
<span className="v" id="v8" data-v="8" data-xref="コリント人への第一の手紙 16:9; コロサイ人への手紙 4:3; ヨハネの黙示録 3:7"> わたしは、あなたのわざを知っている。見よ、わたしは、あなたの前に、だれも閉じることのできない門を開いておいた。なぜなら、あなたには少ししか力がなかったにもかかわらず、わたしの言葉を守り、わたしの名を否まなかったからである。</span>
<span className="v" id="v9" data-v="9" data-xref="イザヤ書 60:14; ヨハネの黙示録 2:9; イザヤ書 49:23"> 見よ、サタンの会堂に属する者、すなわち、ユダヤ人と自称してはいるが、その実ユダヤ人でなくて、偽る者たちに、こうしよう。見よ、彼らがあなたの足もとにきて平伏するようにし、そして、わたしがあなたを愛していることを、彼らに知らせよう。</span>
<span className="v" id="v10" data-v="10" data-xref="ペテロの第二の手紙 2:9; ヨハネの黙示録 14:12; ゼカリヤ書 13:9"> 忍耐についてのわたしの言葉をあなたが守ったから、わたしも、地上に住む者たちをためすために、全世界に臨もうとしている試錬の時に、あなたを防ぎ守ろう。</span>
<span className="v" id="v11" data-v="11" data-xref="ヤコブの手紙 1:12; ヨハネの黙示録 22:12; ヨハネの黙示録 2:10"> わたしは、すぐに来る。あなたの冠がだれにも奪われないように、自分の持っているものを堅く守っていなさい。</span>
<span className="v" id="v12" data-v="12" data-xref="ヨハネの黙示録 22:4; ヨハネの黙示録 21:2; ヨハネの黙示録 14:1"> 勝利を得る者を、わたしの神の聖所における柱にしよう。彼は決して二度と外へ出ることはない。そして彼の上に、わたしの神の御名と、わたしの神の都、すなわち、天とわたしの神のみもとから下ってくる新しいエルサレムの名と、わたしの新しい名とを、書きつけよう。</span>
<span className="v" id="v13" data-v="13" data-xref="ヨハネの黙示録 2:7"> 耳のある者は、御霊が諸教会に言うことを聞くがよい』。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="コロサイ人への手紙 1:15; ヨハネの黙示録 1:5; コリント人への第二の手紙 1:20"> ラオデキヤにある教会の御使に、こう書きおくりなさい。<br />『アァメンたる者、忠実な、まことの証人、神に造られたものの根源であるかたが、次のように言われる。</span>
<span className="v" id="v15" data-v="15" data-xref="ローマ人への手紙 12:11; マタイによる福音書 6:24; 列王紀上 18:21"> わたしはあなたのわざを知っている。あなたは冷たくもなく、熱くもない。むしろ、冷たいか熱いかであってほしい。</span>
<span className="v" id="v16" data-v="16" data-xref="ヨハネの黙示録 2:5; ゼカリヤ書 11:8–9; エレミヤ書 14:19"> このように、熱くもなく、冷たくもなく、なまぬるいので、あなたを口から吐き出そう。</span>
<span className="v" id="v17" data-v="17" data-xref="箴言 13:7; ホセア書 12:8; ローマ人への手紙 7:24"> あなたは、自分は富んでいる、豊かになった、なんの不自由もないと言っているが、実は、あなた自身がみじめな者、あわれむべき者、貧しい者、目の見えない者、裸な者であることに気がついていない。</span>
<span className="v" id="v18" data-v="18" data-xref="ヨハネの黙示録 16:15; ペテロの第一の手紙 1:7; イザヤ書 55:1"> そこで、あなたに勧める。富む者となるために、わたしから火で精錬された金を買い、また、あなたの裸の恥をさらさないため身に着けるように、白い衣を買いなさい。また、見えるようになるため、目にぬる目薬を買いなさい。</span>
<span className="v" id="v19" data-v="19" data-xref="箴言 3:11–12; コリント人への第一の手紙 11:32; ヘブル人への手紙 12:5–11"> すべてわたしの愛している者を、わたしはしかったり、懲らしめたりする。だから、熱心になって悔い改めなさい。</span>
<span className="v" id="v20" data-v="20" data-xref="ルカによる福音書 12:36–37; ヨハネの黙示録 19:9; ヨハネによる福音書 14:21–23"> 見よ、わたしは戸の外に立って、たたいている。だれでもわたしの声を聞いて戸をあけるなら、わたしはその中にはいって彼と食を共にし、彼もまたわたしと食を共にするであろう。</span>
<span className="v" id="v21" data-v="21" data-xref="テモテヘの第二の手紙 2:12; マタイによる福音書 19:28; ヨハネの黙示録 2:26–27"> 勝利を得る者には、わたしと共にわたしの座につかせよう。それはちょうど、わたしが勝利を得てわたしの父と共にその御座についたのと同様である。</span>
<span className="v" id="v22" data-v="22" data-xref="ヨハネの黙示録 2:7; ヨハネの黙示録 2:11; ヨハネの黙示録 2:17"> 耳のある者は、御霊が諸教会に言うことを聞くがよい』」。</span>
</div>

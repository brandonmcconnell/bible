<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨハネの黙示録 7:17; ヨハネによる福音書 4:14; 詩篇 36:8–9"> 御使はまた、水晶のように輝いているいのちの水の川をわたしに見せてくれた。この川は、神と小羊との御座から出て、</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネの黙示録 22:1; ペテロの第一の手紙 2:24; ヨハネの黙示録 2:7"> 都の大通りの中央を流れている。川の両側にはいのちの木があって、十二種の実を結び、その実は毎月みのり、その木の葉は諸国民をいやす。</span>
<span className="v" id="v3" data-v="3" data-xref="マタイによる福音書 25:21; ヨハネの黙示録 21:3–4; ヨハネによる福音書 12:26"> のろわるべきものは、もはや何ひとつない。神と小羊との御座は都の中にあり、その僕たちは彼を礼拝し、</span>
<span className="v" id="v4" data-v="4" data-xref="マタイによる福音書 5:8; ヨハネの黙示録 14:1; ヨハネの黙示録 3:12"> 御顔を仰ぎ見るのである。彼らの額には、御名がしるされている。</span>
<span className="v" id="v5" data-v="5" data-xref="イザヤ書 60:19–20; ダニエル書 7:18; ヨハネの黙示録 20:4"> 夜は、もはやない。あかりも太陽の光も、いらない。主なる神が彼らを照し、そして、彼らは世々限りなく支配する。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="ヨハネの黙示録 1:1; ヨハネの黙示録 21:5; ヨハネの黙示録 19:9"> 彼はまた、わたしに言った、「これらの言葉は信ずべきであり、まことである。預言者たちのたましいの神なる主は、すぐにも起るべきことをその僕たちに示そうとして、御使をつかわされたのである。</span>
<span className="v" id="v7" data-v="7" data-xref="ヨハネの黙示録 1:3; ヨハネの黙示録 3:11; ヨハネの黙示録 22:20"> 見よ、わたしは、すぐに来る。この書の預言の言葉を守る者は、さいわいである」。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="ヨハネの黙示録 19:10; ヨハネの黙示録 1:1; ヨハネの黙示録 19:19"> これらのことを見聞きした者は、このヨハネである。わたしが見聞きした時、それらのことを示してくれた御使の足もとにひれ伏して拝そうとすると、</span>
<span className="v" id="v9" data-v="9" data-xref="ヨハネの黙示録 19:10; コロサイ人への手紙 2:18–19; ヨハネの黙示録 14:7"> 彼は言った、「そのようなことをしてはいけない。わたしは、あなたや、あなたの兄弟である預言者たちや、この書の言葉を守る者たちと、同じ僕仲間である。ただ神だけを拝しなさい」。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="ダニエル書 8:26; ヨハネの黙示録 1:3; ペテロの第一の手紙 4:7"> またわたしに言った、「この書の預言の言葉を封じてはならない。時が近づいているからである。</span>
<span className="v" id="v11" data-v="11" data-xref="ダニエル書 12:10; 箴言 4:18; エゼキエル書 3:27"> 不義な者はさらに不義を行い、汚れた者はさらに汚れたことを行い、義なる者はさらに義を行い、聖なる者はさらに聖なることを行うままにさせよ」。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="マタイによる福音書 16:27; イザヤ書 62:11; イザヤ書 40:10"> 「見よ、わたしはすぐに来る。報いを携えてきて、それぞれのしわざに応じて報いよう。</span>
<span className="v" id="v13" data-v="13" data-xref="ヨハネの黙示録 1:8; ヨハネの黙示録 21:6; イザヤ書 44:6"> わたしはアルパであり、オメガである。最初の者であり、最後の者である。初めであり、終りである。</span>
<span className="v" id="v14" data-v="14" data-xref="ヨハネの黙示録 21:27; ヨハネの第一の手紙 5:3; ヨハネの黙示録 22:7"> いのちの木にあずかる特権を与えられ、また門をとおって都にはいるために、自分の着物を洗う者たちは、さいわいである。</span>
<span className="v" id="v15" data-v="15" data-xref="ヨハネの黙示録 21:8; ガラテヤ人への手紙 5:19–21; ピリピ人への手紙 3:2"> 犬ども、まじないをする者、姦淫を行う者、人殺し、偶像を拝む者、また、偽りを好みかつこれを行う者はみな、外に出されている。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="ヨハネの黙示録 5:5; ペテロの第二の手紙 1:19; イザヤ書 11:1"> わたしイエスは、使をつかわして、諸教会のために、これらのことをあなたがたにあかしした。わたしは、ダビデの若枝また子孫であり、輝く明けの明星である」。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="ヨハネによる福音書 4:14; ヨハネの黙示録 21:6; イザヤ書 55:1–3"> 御霊も花嫁も共に言った、「きたりませ」。また、聞く者も「きたりませ」と言いなさい。かわいている者はここに来るがよい。いのちの水がほしい者は、価なしにそれを受けるがよい。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="申命記 12:32; 申命記 4:2; 箴言 30:6"> この書の預言の言葉を聞くすべての人々に対して、わたしは警告する。もしこれに書き加える者があれば、神はその人に、この書に書かれている災害を加えられる。</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 4:2; ルカによる福音書 11:52; ヨハネの黙示録 22:2"> また、もしこの預言の書の言葉をとり除く者があれば、神はその人の受くべき分を、この書に書かれているいのちの木と聖なる都から、とり除かれる。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="ヨハネの黙示録 22:7; ヘブル人への手紙 9:28; ヨハネの黙示録 22:12"> これらのことをあかしするかたが仰せになる、「しかり、わたしはすぐに来る」。アァメン、主イエスよ、きたりませ。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="テサロニケ人への第二の手紙 3:18; ローマ人への手紙 16:20; コリント人への第二の手紙 13:14"> 主イエスの恵みが、一同の者と共にあるように。</span>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨハネの黙示録 8:10; ローマ人への手紙 10:7; ヨハネの黙示録 9:2"> 第五の御使が、ラッパを吹き鳴らした。するとわたしは、一つの星が天から地に落ちて来るのを見た。この星に、底知れぬ所の穴を開くかぎが与えられた。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨエル書 2:10; 創世記 19:28; ヨエル書 2:2"> そして、この底知れぬ所の穴が開かれた。すると、その穴から煙が大きな炉の煙のように立ちのぼり、その穴の煙で、太陽も空気も暗くなった。</span>
<span className="v" id="v3" data-v="3" data-xref="ヨエル書 1:4; ヨハネの黙示録 9:5; ヨエル書 2:25"> その煙の中から、いなごが地上に出てきたが、地のさそりが持っているような力が、彼らに与えられた。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネの黙示録 7:2–4; エゼキエル書 9:4; ヨハネの黙示録 14:1"> 彼らは、地の草やすべての青草、またすべての木をそこなってはならないが、額に神の印がない人たちには害を加えてもよいと、言い渡された。</span>
<span className="v" id="v5" data-v="5" data-xref="ヨハネの黙示録 9:10; ヨブ記 2:6; ヨハネの黙示録 9:3"> 彼らは、人間を殺すことはしないで、五か月のあいだ苦しめることだけが許された。彼らの与える苦痛は、人がさそりにさされる時のような苦痛であった。</span>
<span className="v" id="v6" data-v="6" data-xref="ルカによる福音書 23:30; エレミヤ書 8:3; ヨハネの黙示録 6:16"> その時には、人々は死を求めても与えられず、死にたいと願っても、死は逃げて行くのである。</span>
<span className="v" id="v7" data-v="7" data-xref="ダニエル書 7:8; ナホム書 3:17; ヨエル書 2:4–5"> これらのいなごは、出陣の用意のととのえられた馬によく似ており、その頭には金の冠のようなものをつけ、その顔は人間の顔のようであり、</span>
<span className="v" id="v8" data-v="8" data-xref="ヨエル書 1:6; コリント人への第一の手紙 11:14–15; ペテロの第一の手紙 3:3"> また、そのかみの毛は女のかみのようであり、その歯はししの歯のようであった。</span>
<span className="v" id="v9" data-v="9" data-xref="ヨエル書 2:5–8; ナホム書 2:4–5; ヨブ記 39:25"> また、鉄の胸当のような胸当をつけており、その羽の音は、馬に引かれて戦場に急ぐ多くの戦車の響きのようであった。</span>
<span className="v" id="v10" data-v="10" data-xref="ヨハネの黙示録 9:5; ヨハネの黙示録 9:3; ヨハネの黙示録 9:19"> その上、さそりのような尾と針とを持っている。その尾には、五か月のあいだ人間をそこなう力がある。</span>
<span className="v" id="v11" data-v="11" data-xref="ヨブ記 26:6; ヨハネの黙示録 9:1–2; エペソ人への手紙 2:2"> 彼らは、底知れぬ所の使を王にいただいており、その名をヘブル語でアバドンと言い、ギリシヤ語ではアポルオンと言う。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="ヨハネの黙示録 11:14; ヨハネの黙示録 8:13–2; ヨハネの黙示録 9:13–21"> 第一のわざわいは、過ぎ去った。見よ、この後、なお二つのわざわいが来る。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="ヨハネの黙示録 8:3–5; 出エジプト記 30:2–3; ヨハネの黙示録 9:1"> 第六の御使が、ラッパを吹き鳴らした。すると、一つの声が、神のみまえにある金の祭壇の四つの角から出て、</span>
<span className="v" id="v14" data-v="14" data-xref="ヨハネの黙示録 16:12; ヨハネの黙示録 9:15; サムエル記下 8:3"> ラッパを持っている第六の御使にこう呼びかけるのを、わたしは聞いた。「大ユウフラテ川のほとりにつながれている四人の御使を、解いてやれ」。</span>
<span className="v" id="v15" data-v="15" data-xref="ヨハネの黙示録 9:18; ヨハネの黙示録 8:7; ヨハネの黙示録 8:9"> すると、その時、その日、その月、その年に備えておかれた四人の御使が、人間の三分の一を殺すために、解き放たれた。</span>
<span className="v" id="v16" data-v="16" data-xref="ヨハネの黙示録 7:4; 詩篇 68:17; ダニエル書 7:10"> 騎兵隊の数は二億であった。わたしはその数を聞いた。</span>
<span className="v" id="v17" data-v="17" data-xref="ヨハネの黙示録 9:18; ヨハネの黙示録 14:10; 歴代志上 12:8"> そして、まぼろしの中で、それらの馬とそれに乗っている者たちとを見ると、乗っている者たちは、火の色と青玉色と硫黄の色の胸当をつけていた。そして、それらの馬の頭はししの頭のようであって、その口から火と煙と硫黄とが、出ていた。</span>
<span className="v" id="v18" data-v="18" data-xref="ヨハネの黙示録 9:17; ヨハネの黙示録 9:15"> この三つの災害、すなわち、彼らの口から出て来る火と煙と硫黄とによって、人間の三分の一は殺されてしまった。</span>
<span className="v" id="v19" data-v="19" data-xref="イザヤ書 9:15; ヨハネの黙示録 9:10; エペソ人への手紙 4:14"> 馬の力はその口と尾とにある。その尾はへびに似ていて、それに頭があり、その頭で人に害を加えるのである。</span>
<span className="v" id="v20" data-v="20" data-xref="ダニエル書 5:23; 申命記 31:29; テモテヘの第一の手紙 4:1"> これらの災害で殺されずに残った人々は、自分の手で造ったものについて、悔い改めようとせず、また悪霊のたぐいや、金、銀、銅、石、木で造られ、見ることも聞くことも歩くこともできない偶像を礼拝して、やめようともしなかった。</span>
<span className="v" id="v21" data-v="21" data-xref="ヨハネの黙示録 21:8; コリント人への第二の手紙 12:21; ヨハネの黙示録 17:5"> また、彼らは、その犯した殺人や、まじないや、不品行や、盗みを悔い改めようとしなかった。</span>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨハネの黙示録 22:16; ヨハネの黙示録 22:6; ガラテヤ人への手紙 1:12"> イエス・キリストの黙示。この黙示は、神が、すぐにも起るべきことをその僕たちに示すためキリストに与え、そして、キリストが、御使をつかわして、僕ヨハネに伝えられたものである。</span>
<span className="v" id="v2" data-v="2" data-xref="コリント人への第一の手紙 1:6; ヨハネによる福音書 19:35; ヨハネの第一の手紙 1:1"> ヨハネは、神の言とイエス・キリストのあかしと、すなわち、自分が見たすべてのことをあかしした。</span>
<span className="v" id="v3" data-v="3" data-xref="ルカによる福音書 11:28; ヨハネの黙示録 22:10; ローマ人への手紙 13:11"> この預言の言葉を朗読する者と、これを聞いて、その中に書かれていることを守る者たちとは、さいわいである。時が近づいているからである。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="イザヤ書 11:2; ヨハネによる福音書 1:1; ヘブル人への手紙 13:8"> ヨハネからアジヤにある七つの教会へ。今いまし、昔いまし、やがてきたるべきかたから、また、その御座の前にある七つの霊から、</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 89:27; ヘブル人への手紙 9:14; ヨハネの第一の手紙 1:7"> また、忠実な証人、死人の中から最初に生れた者、地上の諸王の支配者であるイエス・キリストから、恵みと平安とが、あなたがたにあるように。わたしたちを愛し、その血によってわたしたちを罪から解放し、</span>
<span className="v" id="v6" data-v="6" data-xref="ヨハネの黙示録 5:10; ヨハネの黙示録 20:6; 出エジプト記 19:6"> わたしたちを、その父なる神のために、御国の民とし、祭司として下さったかたに、世々限りなく栄光と権力とがあるように、アァメン。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="マタイによる福音書 24:30; ゼカリヤ書 12:10; ダニエル書 7:13"> 見よ、彼は、雲に乗ってこられる。すべての人の目、ことに、彼を刺しとおした者たちは、彼を仰ぎ見るであろう。また地上の諸族はみな、彼のゆえに胸を打って嘆くであろう。しかり、アァメン。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="イザヤ書 44:6; ヨハネの黙示録 22:13; イザヤ書 43:10"> 今いまし、昔いまし、やがてきたるべき者、全能者にして主なる神が仰せになる、「わたしはアルパであり、オメガである」。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="使徒行伝 14:22; ヨハネの黙示録 3:10; ヨハネによる福音書 16:33"> あなたがたの兄弟であり、共にイエスの苦難と御国と忍耐とにあずかっている、わたしヨハネは、神の言とイエスのあかしとのゆえに、パトモスという島にいた。</span>
<span className="v" id="v10" data-v="10" data-xref="ヨハネの黙示録 21:10; コリント人への第二の手紙 12:2–4; ヨハネの黙示録 4:1–2"> ところが、わたしは、主の日に御霊に感じた。そして、わたしのうしろの方で、ラッパのような大きな声がするのを聞いた。</span>
<span className="v" id="v11" data-v="11" data-xref="ヨハネの黙示録 3:1; エレミヤ書 30:2; ハバクク書 2:2"> その声はこう言った、「あなたが見ていることを書きものにして、それをエペソ、スミルナ、ペルガモ、テアテラ、サルデス、ヒラデルヒヤ、ラオデキヤにある七つの教会に送りなさい」。</span>
<span className="v" id="v12" data-v="12" data-xref="ゼカリヤ書 4:2; 出エジプト記 25:37; ヨハネの黙示録 1:20–1"> そこでわたしは、わたしに呼びかけたその声を見ようとしてふりむいた。ふりむくと、七つの金の燭台が目についた。</span>
<span className="v" id="v13" data-v="13" data-xref="ダニエル書 7:13; ダニエル書 10:5–6; ダニエル書 10:16"> それらの燭台の間に、足までたれた上着を着、胸に金の帯をしめている人の子のような者がいた。</span>
<span className="v" id="v14" data-v="14" data-xref="ダニエル書 10:6; ダニエル書 7:9; ヨハネの黙示録 19:12"> そのかしらと髪の毛とは、雪のように白い羊毛に似て真白であり、目は燃える炎のようであった。</span>
<span className="v" id="v15" data-v="15" data-xref="エゼキエル書 43:2; ダニエル書 10:6; ヨハネの黙示録 14:2"> その足は、炉で精錬されて光り輝くしんちゅうのようであり、声は大水のとどろきのようであった。</span>
<span className="v" id="v16" data-v="16" data-xref="ヘブル人への手紙 4:12; ヨハネの黙示録 19:15; ヨハネの黙示録 2:12"> その右手に七つの星を持ち、口からは、鋭いもろ刃のつるぎがつき出ており、顔は、強く照り輝く太陽のようであった。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="イザヤ書 44:6; ヨハネの黙示録 22:13; ダニエル書 10:8–10"> わたしは彼を見たとき、その足もとに倒れて死人のようになった。すると、彼は右手をわたしの上において言った、「恐れるな。わたしは初めであり、終りであり、</span>
<span className="v" id="v18" data-v="18" data-xref="ローマ人への手紙 6:9; ヘブル人への手紙 7:25; ローマ人への手紙 14:8–9"> また、生きている者である。わたしは死んだことはあるが、見よ、世々限りなく生きている者である。そして、死と黄泉とのかぎを持っている。</span>
<span className="v" id="v19" data-v="19" data-xref="ヨハネの黙示録 4:1–11; ヨハネの黙示録 1:11–3"> そこで、あなたの見たこと、現在のこと、今後起ろうとすることを、書きとめなさい。</span>
<span className="v" id="v20" data-v="20" data-xref="ヨハネの黙示録 2:1; ヨハネの黙示録 3:1; ヨハネの黙示録 1:16"> あなたがわたしの右手に見た七つの星と、七つの金の燭台との奥義は、こうである。すなわち、七つの星は七つの教会の御使であり、七つの燭台は七つの教会である。</span>
</div>

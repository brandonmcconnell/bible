<div className="bible-chapter" lang="ja" dir="ltr" data-lang="ja" data-translation="jpn-kou" data-translation-id="jpn_kou" data-translation-label="口語訳" data-book="REV" data-book-slug="revelation" data-book-name="ヨハネの黙示録" data-chapter="2" data-verses="29">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨハネの黙示録 1:20; ヨハネの黙示録 1:16; ヨハネの黙示録 1:11–13"> エペソにある教会の御使に、こう書きおくりなさい。<br />『右の手に七つの星を持つ者、七つの金の燭台の間を歩く者が、次のように言われる。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネの第一の手紙 4:1; ペテロの第二の手紙 2:1–3; テサロニケ人への第一の手紙 5:21"> わたしは、あなたのわざと労苦と忍耐とを知っている。また、あなたが、悪い者たちをゆるしておくことができず、使徒と自称してはいるが、その実、使徒でない者たちをためしてみて、にせ者であると見抜いたことも、知っている。</span>
<span className="v" id="v3" data-v="3" data-xref="ヘブル人への手紙 10:36; ガラテヤ人への手紙 6:9; ヤコブの手紙 5:7–11"> あなたは忍耐をし続け、わたしの名のために忍びとおして、弱り果てることがなかった。</span>
<span className="v" id="v4" data-v="4" data-xref="マタイによる福音書 24:12–13; エレミヤ書 2:2–5; ヘブル人への手紙 6:10–11"> しかし、あなたに対して責むべきことがある。あなたは初めの愛から離れてしまった。</span>
<span className="v" id="v5" data-v="5" data-xref="ヨハネの黙示録 3:2–3; ヨハネの黙示録 3:19; ヨハネの黙示録 2:16"> そこで、あなたはどこから落ちたかを思い起し、悔い改めて初めのわざを行いなさい。もし、そうしないで悔い改めなければ、わたしはあなたのところにきて、あなたの燭台をその場所から取りのけよう。</span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 101:3; ヨハネの第二の手紙 1:9–10; 詩篇 26:5"> しかし、こういうことはある、あなたはニコライ宗の人々のわざを憎んでおり、わたしもそれを憎んでいる。</span>
<span className="v" id="v7" data-v="7" data-xref="ヨハネの黙示録 2:17; ヨハネの黙示録 2:11; マタイによる福音書 11:15"> 耳のある者は、御霊が諸教会に言うことを聞くがよい。勝利を得る者には、神のパラダイスにあるいのちの木の実を食べることをゆるそう』。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="ヨハネの黙示録 1:17–18; ヨハネの黙示録 1:8; ヨハネの黙示録 1:11"> スミルナにある教会の御使に、こう書きおくりなさい。<br />『初めであり、終りである者、死んだことはあるが生き返った者が、次のように言われる。</span>
<span className="v" id="v9" data-v="9" data-xref="ヨハネの黙示録 3:9; コリント人への第二の手紙 8:9; ヤコブの手紙 2:5–6"> わたしは、あなたの苦難や、貧しさを知っている（しかし実際は、あなたは富んでいるのだ）。また、ユダヤ人と自称してはいるが、その実ユダヤ人でなくてサタンの会堂に属する者たちにそしられていることも、わたしは知っている。</span>
<span className="v" id="v10" data-v="10" data-xref="ヤコブの手紙 1:12; マタイによる福音書 10:22; ヨハネの黙示録 3:10–11"> あなたの受けようとする苦しみを恐れてはならない。見よ、悪魔が、あなたがたのうちのある者をためすために、獄に入れようとしている。あなたがたは十日の間、苦難にあうであろう。死に至るまで忠実であれ。そうすれば、いのちの冠を与えよう。</span>
<span className="v" id="v11" data-v="11" data-xref="ヨハネの黙示録 20:6; ヨハネの黙示録 20:14; ヨハネの黙示録 21:8"> 耳のある者は、御霊が諸教会に言うことを聞くがよい。勝利を得る者は、第二の死によって滅ぼされることはない』。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="ヨハネの黙示録 2:16; ヘブル人への手紙 4:12; ヨハネの黙示録 1:16"> ペルガモにある教会の御使に、こう書きおくりなさい。<br />『鋭いもろ刃のつるぎを持っているかたが、次のように言われる。</span>
<span className="v" id="v13" data-v="13" data-xref="ヨハネの黙示録 2:9–10; テモテヘの第一の手紙 5:8; ヨハネの黙示録 3:8–9"> わたしはあなたの住んでいる所を知っている。そこにはサタンの座がある。あなたは、わたしの名を堅く持ちつづけ、わたしの忠実な証人アンテパスがサタンの住んでいるあなたがたの所で殺された時でさえ、わたしに対する信仰を捨てなかった。</span>
<span className="v" id="v14" data-v="14" data-xref="民数記 31:16; ペテロの第二の手紙 2:15; ヨハネの黙示録 2:20"> しかし、あなたに対して責むべきことが、少しばかりある。あなたがたの中には、現にバラムの教を奉じている者がある。バラムは、バラクに教え込み、イスラエルの子らの前に、つまずきになるものを置かせて、偶像にささげたものを食べさせ、また不品行をさせたのである。</span>
<span className="v" id="v15" data-v="15" data-xref="ヨハネの黙示録 2:6"> 同じように、あなたがたの中には、ニコライ宗の教を奉じている者もいる。</span>
<span className="v" id="v16" data-v="16" data-xref="テサロニケ人への第二の手紙 2:8; ヨハネの黙示録 1:16; ヨハネの黙示録 2:5"> だから、悔い改めなさい。そうしないと、わたしはすぐにあなたのところに行き、わたしの口のつるぎをもって彼らと戦おう。</span>
<span className="v" id="v17" data-v="17" data-xref="イザヤ書 62:2; イザヤ書 65:15; ヨハネの黙示録 19:12–13"> 耳のある者は、御霊が諸教会に言うことを聞くがよい。勝利を得る者には、隠されているマナを与えよう。また、白い石を与えよう。この石の上には、これを受ける者のほかだれも知らない新しい名が書いてある』。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="ヨハネの黙示録 1:14–15; ヨハネの黙示録 1:11; ヨハネによる福音書 3:35–36"> テアテラにある教会の御使に、こう書きおくりなさい。<br />『燃える炎のような目と光り輝くしんちゅうのような足とを持った神の子が、次のように言われる。</span>
<span className="v" id="v19" data-v="19" data-xref="テモテヘの第一の手紙 1:5; ペテロの第二の手紙 1:7; ヨハネによる福音書 15:2"> わたしは、あなたのわざと、あなたの愛と信仰と奉仕と忍耐とを知っている。また、あなたの後のわざが、初めのよりもまさっていることを知っている。</span>
<span className="v" id="v20" data-v="20" data-xref="ヨハネの黙示録 2:14; 列王紀上 16:31; コリント人への第一の手紙 10:18–21"> しかし、あなたに対して責むべきことがある。あなたは、あのイゼベルという女を、そのなすがままにさせている。この女は女預言者と自称し、わたしの僕たちを教え、惑わして、不品行をさせ、偶像にささげたものを食べさせている。</span>
<span className="v" id="v21" data-v="21" data-xref="ペテロの第二の手紙 3:9; ローマ人への手紙 2:4–5; ヨハネの黙示録 9:20–21"> わたしは、この女に悔い改めるおりを与えたが、悔い改めてその不品行をやめようとはしない。</span>
<span className="v" id="v22" data-v="22" data-xref="ヨハネの黙示録 17:2; ルカによる福音書 13:5; エゼキエル書 16:37–41"> 見よ、わたしはこの女を病の床に投げ入れる。この女と姦淫する者をも、悔い改めて彼女のわざから離れなければ、大きな患難の中に投げ入れる。</span>
<span className="v" id="v23" data-v="23" data-xref="マタイによる福音書 16:27; ローマ人への手紙 8:27; 詩篇 7:9"> また、この女の子供たちをも打ち殺そう。こうしてすべての教会は、わたしが人の心の奥底までも探り知る者であることを悟るであろう。そしてわたしは、あなたがたひとりびとりのわざに応じて報いよう。</span>
<span className="v" id="v24" data-v="24" data-xref="コリント人への第二の手紙 2:11; ヨハネの黙示録 12:9; コリント人への第二の手紙 11:3"> また、テアテラにいるほかの人たちで、まだあの女の教を受けておらず、サタンの、いわゆる「深み」を知らないあなたがたに言う。わたしは別にほかの重荷を、あなたがたに負わせることはしない。</span>
<span className="v" id="v25" data-v="25" data-xref="ヨハネの黙示録 3:11; ヨハネの黙示録 3:3; ヘブル人への手紙 10:23"> ただ、わたしが来る時まで、自分の持っているものを堅く保っていなさい。</span>
<span className="v" id="v26" data-v="26" data-xref="ヨハネの黙示録 3:21; ダニエル書 7:27; ヨハネの黙示録 2:7"> 勝利を得る者、わたしのわざを最後まで持ち続ける者には、諸国民を支配する権威を授ける。</span>
<span className="v" id="v27" data-v="27" data-xref="詩篇 2:8–9; ヨハネの黙示録 12:5; ヨハネの黙示録 19:15"> 彼は鉄のつえをもって、ちょうど土の器を砕くように、彼らを治めるであろう。それは、わたし自身が父から権威を受けて治めるのと同様である。</span>
<span className="v" id="v28" data-v="28" data-xref="ヨハネの黙示録 22:16; ペテロの第二の手紙 1:19; ルカによる福音書 1:78–79"> わたしはまた、彼に明けの明星を与える。</span>
<span className="v" id="v29" data-v="29" data-xref="ヨハネの黙示録 2:7"> 耳のある者は、御霊が諸教会に言うことを聞くがよい』。</span>
</div>

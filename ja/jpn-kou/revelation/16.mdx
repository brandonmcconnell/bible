<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ゼパニヤ書 3:8; エレミヤ書 10:25; ヨハネの黙示録 15:1"> それから、大きな声が聖所から出て、七人の御使にむかい、「さあ行って、神の激しい怒りの七つの鉢を、地に傾けよ」と言うのを聞いた。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="ヨハネの黙示録 8:7; ヨハネの黙示録 16:11; ヨハネの黙示録 13:15–18"> そして、第一の者が出て行って、その鉢を地に傾けた。すると、獣の刻印を持つ人々と、その像を拝む人々とのからだに、ひどい悪性のでき物ができた。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="出エジプト記 7:17–21; ヨハネの黙示録 8:8–9; ヨハネの黙示録 11:6"> 第二の者が、その鉢を海に傾けた。すると、海は死人の血のようになって、その中の生き物がみな死んでしまった。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="出エジプト記 7:17–20; ヨハネの黙示録 8:10–11; ホセア書 13:15"> 第三の者がその鉢を川と水の源とに傾けた。すると、みな血になった。</span>
<span className="v" id="v5" data-v="5" data-xref="ヨハネの黙示録 1:8; ヨハネの黙示録 11:17; ヨハネの黙示録 1:4"> それから、水をつかさどる御使がこう言うのを、聞いた、「今いまし、昔いませる聖なる者よ。このようにお定めになったあなたは、正しいかたであります。</span>
<span className="v" id="v6" data-v="6" data-xref="イザヤ書 49:26; ヨハネの黙示録 11:18; ヨハネの黙示録 6:10–11"> 聖徒と預言者との血を流した者たちに、血をお飲ませになりましたが、それは当然のことであります」。</span>
<span className="v" id="v7" data-v="7" data-xref="ヨハネの黙示録 19:2; ヨハネの黙示録 6:9; ヨハネの黙示録 15:3–4"> わたしはまた祭壇がこう言うのを聞いた、「全能者にして主なる神よ。しかり、あなたのさばきは真実で、かつ正しいさばきであります」。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="使徒行伝 2:20; ヨハネの黙示録 14:18; ヨナ書 4:8"> 第四の者が、その鉢を太陽に傾けた。すると、太陽は火で人々を焼くことを許された。</span>
<span className="v" id="v9" data-v="9" data-xref="ヨハネの黙示録 2:21; ヨハネの黙示録 16:21; ヨハネの黙示録 11:13"> 人々は、激しい炎熱で焼かれたが、これらの災害を支配する神の御名を汚し、悔い改めて神に栄光を帰することをしなかった。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="ヨハネの黙示録 9:2; マタイによる福音書 8:12; イザヤ書 8:21–22"> 第五の者が、その鉢を獣の座に傾けた。すると、獣の国は暗くなり、人々は苦痛のあまり舌をかみ、</span>
<span className="v" id="v11" data-v="11" data-xref="ヨハネの黙示録 16:9; ヨハネの黙示録 16:2; ヨハネの黙示録 16:21"> その苦痛とでき物とのゆえに、天の神をのろった。そして、自分の行いを悔い改めなかった。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="ヨハネの黙示録 9:14; エレミヤ書 51:36; イザヤ書 44:27"> 第六の者が、その鉢を大ユウフラテ川に傾けた。すると、その水は、日の出る方から来る王たちに対し道を備えるために、かれてしまった。</span>
<span className="v" id="v13" data-v="13" data-xref="ヨハネの黙示録 19:20; テサロニケ人への第二の手紙 2:9–11; ヨハネの黙示録 20:10"> また見ると、龍の口から、獣の口から、にせ預言者の口から、かえるのような三つの汚れた霊が出てきた。</span>
<span className="v" id="v14" data-v="14" data-xref="ヨハネの黙示録 17:14; テモテヘの第一の手紙 4:1; ヨハネの黙示録 20:8"> これらは、しるしを行う悪霊の霊であって、全世界の王たちのところに行き、彼らを召集したが、それは、全能なる神の大いなる日に、戦いをするためであった。</span>
<span className="v" id="v15" data-v="15" data-xref="テサロニケ人への第一の手紙 5:2–3; マタイによる福音書 24:42–43; ペテロの第二の手紙 3:10"> （見よ、わたしは盗人のように来る。裸のままで歩かないように、また、裸の恥を見られないように、目をさまし着物を身に着けている者は、さいわいである。）</span>
<span className="v" id="v16" data-v="16" data-xref="ゼカリヤ書 12:11; 士師記 5:19; ヨエル書 3:9–14"> 三つの霊は、ヘブル語でハルマゲドンという所に、王たちを召集した。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="ヨハネによる福音書 19:30; ヨハネの黙示録 21:6; エペソ人への手紙 6:12"> 第七の者が、その鉢を空中に傾けた。すると、大きな声が聖所の中から、御座から出て、「事はすでに成った」と言った。</span>
<span className="v" id="v18" data-v="18" data-xref="ダニエル書 12:1; ヨハネの黙示録 4:5; ヨハネの黙示録 11:19"> すると、いなずまと、もろもろの声と、雷鳴とが起り、また激しい地震があった。それは人間が地上にあらわれて以来、かつてなかったようなもので、それほどに激しい地震であった。</span>
<span className="v" id="v19" data-v="19" data-xref="ヨハネの黙示録 18:5; ヨハネの黙示録 17:18; ヨハネの黙示録 18:21"> 大いなる都は三つに裂かれ、諸国民の町々は倒れた。神は大いなるバビロンを思い起し、これに神の激しい怒りのぶどう酒の杯を与えられた。</span>
<span className="v" id="v20" data-v="20" data-xref="ヨハネの黙示録 6:14; ヨハネの黙示録 20:11; エレミヤ書 4:23–25"> 島々はみな逃げ去り、山々は見えなくなった。</span>
<span className="v" id="v21" data-v="21" data-xref="ヨハネの黙示録 11:19; ヨシュア記 10:11; ヨハネの黙示録 16:9"> また一タラントの重さほどの大きな雹が、天から人々の上に降ってきた。人々は、この雹の災害のゆえに神をのろった。その災害が、非常に大きかったからである。</span>
</div>

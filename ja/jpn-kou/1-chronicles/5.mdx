<span className="v" id="v1" data-v="1" data-xref="創世記 35:22; 創世記 29:32; 創世記 48:15–22"> イスラエルの長子ルベンの子らは次のとおりである。――ルベンは長子であったが父の床を汚したので、長子の権はイスラエルの子ヨセフの子らに与えられた。それで長子の権による系図にしるされていない。</span>
<span className="v" id="v2" data-v="2" data-xref="マタイによる福音書 2:6; ミカ書 5:2; ヘブル人への手紙 7:14"> またユダは兄弟たちにまさる者となり、その中から君たる者がでたが長子の権はヨセフのものとなったのである。――</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 46:9; 出エジプト記 6:14; 民数記 26:5–9"> すなわちイスラエルの長子ルベンの子らはハノク、パル、ヘヅロン、カルミ。</span>
<span className="v" id="v4" data-v="4"> ヨエルの子らはその子はシマヤ、その子はゴグ、その子はシメイ、</span>
<span className="v" id="v5" data-v="5"> その子はミカ、その子はレアヤ、その子はバアル、</span>
<span className="v" id="v6" data-v="6" data-xref="歴代志上 5:26; 列王紀下 15:29; 歴代志下 28:20"> その子はベエラである。このベエラはアッスリヤの王テルガテ・ピルネセルが捕え移した者である。彼はルベンびとのつかさであった。</span>
<span className="v" id="v7" data-v="7" data-xref="歴代志上 5:17"> 彼の兄弟たちは、その氏族により、その歴代の系図によれば、かしらエイエルおよびゼカリヤ、</span>
<span className="v" id="v8" data-v="8" data-xref="歴代志上 5:4; 民数記 32:34; 民数記 32:38"> ベラなどである。ベラはアザズの子、シマの孫、ヨエルのひこである。彼はアロエルに住み、ネボおよびバアル・メオンまで及んでいたが、</span>
<span className="v" id="v9" data-v="9" data-xref="ヨシュア記 22:8–9"> ギレアデの地で彼の家畜がふえ増したので、彼は東の方ユフラテ川のこなたの荒野の入口にまで住んだ。</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 21:9; 歴代志上 5:18–21; 詩篇 83:6"> またサウルの時、彼らはハガルびとと戦って、これを撃ち倒し、ギレアデの東の全部にわたって彼らの天幕に住んだ。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="ヨシュア記 13:11; ヨシュア記 13:24–28; 申命記 3:10–17"> ガドの子孫はこれと相対してバシャンの地に住み、サルカまで及んでいた。</span>
<span className="v" id="v12" data-v="12"> そのかしらはヨエル、次はシャパム、ヤアナイ、シャパテで、ともにバシャンに住んだ。</span>
<span className="v" id="v13" data-v="13"> 彼らの兄弟たちは、その氏族によればミカエル、メシュラム、シバ、ヨライ、ヤカン、ジア、エベルの七人である。</span>
<span className="v" id="v14" data-v="14"> これらはホリの子アビハイルの子らである。ホリはヤロアの子、ヤロアはギレアデの子、ギレアデはミカエルの子、ミカエルはエシサイの子、エシサイはヤドの子、ヤドはブズの子である。</span>
<span className="v" id="v15" data-v="15"> アヒはアブデルの子、アブデルはグニの子、グニはその氏族の長である。</span>
<span className="v" id="v16" data-v="16" data-xref="歴代志上 27:29; 雅歌 2:1; イザヤ書 35:2"> 彼らはギレアデとバシャンとその村里とシャロンのすべての放牧地に住んで、その四方の境にまで及んでいた。</span>
<span className="v" id="v17" data-v="17" data-xref="列王紀下 14:16; 列王紀下 14:28; 列王紀下 15:32"> これらはみなユダの王ヨタムの世とイスラエルの王ヤラベアムの世に系図にのせられた。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="民数記 1:3; ヨシュア記 4:12–13"> ルベンびとと、ガドびとと、マナセの半部族には出て戦いうる者四万四千七百六十人あり、皆勇士で、盾とつるぎをとり、弓をひき、戦いに巧みな人々であった。</span>
<span className="v" id="v19" data-v="19" data-xref="創世記 25:15; 歴代志上 1:31; 歴代志上 5:10"> 彼らはハガルびとおよびエトル、ネフシ、ノダブなどと戦ったが、</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 22:4–5; 詩篇 9:10; 歴代志下 18:31"> 助けを得てこれを攻めたので、ハガルびとおよびこれとともにいた者は皆、彼らの手にわたされた。これは彼らが戦いにあたって神に呼ばわり、神に寄り頼んだので神はその願いを聞かれたからである。</span>
<span className="v" id="v21" data-v="21" data-xref="ヨハネの黙示録 18:13; 民数記 31:35"> 彼らはその家畜を奪い取ったが、らくだ五万、羊二十五万、ろば二千あり、また人は十万人あった。</span>
<span className="v" id="v22" data-v="22" data-xref="歴代志下 32:8; ローマ人への手紙 8:31; ヨシュア記 23:10"> これはその戦いが神によったので、多くの者が殺されて倒れたからである。そして彼らは捕え移される時まで、これに代ってその所に住んだ。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="申命記 3:8–9; 雅歌 4:8; 詩篇 133:3"> マナセの半部族の人々はこの地に住み、ふえ広がって、ついにバシャンからバアル・ヘルモン、セニルおよびヘルモン山にまで及んだ。</span>
<span className="v" id="v24" data-v="24" data-xref="歴代志上 4:38"> その氏族の長たちは次のとおりである。すなわち、エペル、イシ、エリエル、アズリエル、エレミヤ、ホダヤ、ヤデエル。これらは皆その氏族の長で名高い大勇士であった。</span>
<span className="v" id="v25" data-v="25" data-xref="ヨハネの黙示録 17:5; 詩篇 106:34–39; 出エジプト記 34:15"> 彼らは先祖たちの神にむかって罪を犯し、神が、かつて彼らの前から滅ぼされた国の民の神々を慕って、これと姦淫したので、</span>
<span className="v" id="v26" data-v="26" data-xref="列王紀下 15:19; 列王紀下 17:6; 列王紀下 15:29"> イスラエルの神は、アッスリヤの王プルの心を奮い起し、またアッスリヤの王テルガテ・ピルネセルの心を奮い起されたので、彼はついにルベンびとと、ガドびとと、マナセの半部族を捕えて行き、ハウラとハボルとハラとゴザン川のほとりに移して今日に至っている。</span>
</div>

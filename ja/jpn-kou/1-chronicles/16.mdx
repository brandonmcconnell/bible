<span className="v" id="v2" data-v="2" data-xref="創世記 47:10; 創世記 14:19; レビ記 1:3"> ダビデは燔祭と酬恩祭をささげ終えたとき、主の名をもって民を祝福し、</span>

</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="歴代志上 23:27–32; 詩篇 72:18; 詩篇 103:2"> ダビデはまたレビびとのうちから主の箱の前に仕える者を立てて、イスラエルの神、主をあがめ、感謝し、ほめたたえさせた。</span>
<span className="v" id="v5" data-v="5" data-xref="歴代志上 6:39; 歴代志下 29:25; 歴代志上 15:16–24"> 楽長はアサフ、その次はゼカリヤ、エイエル、セミラモテ、エヒエル、マッタテヤ、エリアブ、ベナヤ、オベデ・エドム、エイエルで、彼らは立琴と琴を弾じ、アサフはシンバルを打ち鳴らし、</span>
<span className="v" id="v6" data-v="6" data-xref="歴代志下 13:12; 歴代志下 29:26–28; 歴代志下 5:12–13"> 祭司ベナヤとヤハジエルは神の契約の箱の前でつねにラッパを吹いた。</span>
</div>
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="サムエル記下 22:1; 詩篇 18:1; サムエル記下 23:1–2"> その日ダビデは初めてアサフと彼の兄弟たちを立てて、主に感謝をささげさせた。</span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 105:1–15; イザヤ書 12:4; 列王紀下 19:19"> <span className="pl pl-1">主に感謝し、そのみ名を呼び、</span><br /><span className="pl pl-1">そのみわざをもろもろの民の中に知らせよ。</span></span>
<span className="v" id="v9" data-v="9" data-xref="コロサイ人への手紙 3:16; 詩篇 96:1–3; 詩篇 98:1–4"> <span className="pl pl-1">主にむかって歌え、主をほめ歌え。</span><br /><span className="pl pl-1">そのもろもろのくすしきみわざを語れ。</span></span>
<span className="v" id="v10" data-v="10" data-xref="マタイによる福音書 7:7–8; エレミヤ書 29:13; 詩篇 34:2"> <span className="pl pl-1">その聖なるみ名を誇れ。</span><br /><span className="pl pl-1">どうか主を求める者の心が喜ぶように。</span></span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 27:8–9; ゼパニヤ書 2:2–3; 詩篇 68:35"> <span className="pl pl-1">主とそのみ力とを求めよ。</span><br /><span className="pl pl-1">つねにそのみ顔をたずねよ。</span></span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 111:4; 詩篇 119:20; 詩篇 103:2"> <span className="pl pl-1">そのしもべアブラハムのすえよ、</span><br /><span className="pl pl-1">その選ばれたヤコブの子らよ。</span><br /><span className="pl pl-1">主のなされたくすしきみわざと、その奇跡と、</span><br /><span className="pl pl-1">そのみ口のさばきとを心にとめよ。</span></span>
<span className="v" id="v14" data-v="14" data-xref="詩篇 48:10–11; イザヤ書 26:9; 出エジプト記 15:2"> <span className="pl pl-1">彼はわれわれの神、主にいます。</span><br /><span className="pl pl-1">そのさばきは全地にある。</span></span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 105:8; マラキ書 4:4; 申命記 7:9"> <span className="pl pl-1">主はとこしえにその契約をみこころにとめられる。</span><br /><span className="pl pl-1">これはよろずよに命じられたみ言葉であって、</span></span>
<span className="v" id="v16" data-v="16" data-xref="創世記 26:3; 創世記 17:2; 創世記 35:11"> <span className="pl pl-1">アブラハムと結ばれた契約、</span><br /><span className="pl pl-1">イサクに誓われた約束である。</span></span>
<span className="v" id="v17" data-v="17" data-xref="創世記 17:7–8; 創世記 35:11–12; ヨシュア記 24:11–13"> <span className="pl pl-1">主はこれを堅く立ててヤコブのために定めとし、</span><br /><span className="pl pl-1">イスラエルのためにとこしえの契約として、</span></span>
<span className="v" id="v18" data-v="18" data-xref="創世記 13:15; ミカ書 2:5; 創世記 17:8"> <span className="pl pl-1">言われた、「あなたにカナンの地を与えて、</span><br /><span className="pl pl-1">あなたがたの受ける嗣業の分け前とする」と。</span></span>
<span className="v" id="v19" data-v="19" data-xref="創世記 34:30; 申命記 7:7; 使徒行伝 7:5"> <span className="pl pl-1">その時、彼らの数は少なくて、</span><br /><span className="pl pl-1">数えるに足らず、かの国で旅びととなり、</span></span>
<span className="v" id="v20" data-v="20" data-xref="創世記 46:6; 創世記 20:1; 創世記 46:3"> <span className="pl pl-1">国から国へ行き、</span><br /><span className="pl pl-1">この国からほかの民へ行った。</span></span>
<span className="v" id="v21" data-v="21" data-xref="創世記 12:17; 創世記 20:3; 出エジプト記 7:15–18"> <span className="pl pl-1">主は人の彼らをしえたげるのをゆるされず、</span><br /><span className="pl pl-1">彼らのために王たちを懲しめて、</span></span>
<span className="v" id="v22" data-v="22" data-xref="創世記 20:7; 詩篇 105:15; 創世記 49:8–10"> <span className="pl pl-1">言われた、「わが油そそがれた者たちに</span><br /><span className="pl pl-1">さわってはならない。</span><br /><span className="pl pl-1">わが預言者たちに害を加えてはならない」と。</span></span>
<span className="v" id="v23" data-v="23" data-xref="詩篇 96:1–13; 詩篇 71:15; イザヤ書 51:6–8"> <span className="pl pl-1">全地よ、主に向かって歌え。</span><br /><span className="pl pl-1">日ごとにその救を宣べ伝えよ。</span></span>
<span className="v" id="v24" data-v="24" data-xref="イザヤ書 12:2–6; ダニエル書 4:1–3; 詩篇 22:27"> <span className="pl pl-1">もろもろの国の中にその栄光をあらわし、</span><br /><span className="pl pl-1">もろもろの民の中にくすしきみわざをあらわせ。</span></span>
<span className="v" id="v25" data-v="25" data-xref="詩篇 89:7; 詩篇 76:7; 詩篇 66:3–5"> <span className="pl pl-1">主は大いなるかたにいまして、</span><br /><span className="pl pl-1">いとほめたたうべき者、</span><br /><span className="pl pl-1">もろもろの神にまさって、恐るべき者だからである。</span></span>
<span className="v" id="v26" data-v="26" data-xref="詩篇 102:25; レビ記 19:4; イザヤ書 42:5"> <span className="pl pl-1">もろもろの民のすべての神はむなしい。</span><br /><span className="pl pl-1">しかし主は天を造られた。</span></span>
<span className="v" id="v27" data-v="27" data-xref="詩篇 16:11; 詩篇 96:6; 詩篇 28:7–8"> <span className="pl pl-1">誉と威厳とはそのみ前にあり、</span><br /><span className="pl pl-1">力と喜びとはその聖所にある。</span></span>
<span className="v" id="v28" data-v="28" data-xref="コリント人への第一の手紙 15:10; ピリピ人への手紙 4:13; 詩篇 100:1–2"> <span className="pl pl-1">もろもろの民のやからよ、主に帰せよ、</span><br /><span className="pl pl-1">栄光と力とを主に帰せよ。</span></span>
<span className="v" id="v29" data-v="29" data-xref="詩篇 100:4; 詩篇 96:9; イザヤ書 6:3"> <span className="pl pl-1">そのみ名にふさわしい栄光を主に帰せよ。</span><br /><span className="pl pl-1">供え物を携えて主のみ前にきたれ。</span><br /><span className="pl pl-1">聖なる装いをして主を拝め。</span></span>
<span className="v" id="v30" data-v="30" data-xref="詩篇 33:9; 詩篇 148:5–6; ヘブル人への手紙 1:3"> <span className="pl pl-1">全地よ、そのみ前におののけ。</span><br /><span className="pl pl-1">世界は堅く立って、動かされることはない。</span></span>
<span className="v" id="v31" data-v="31" data-xref="詩篇 96:10; ヨハネの黙示録 19:6; 詩篇 97:1"> <span className="pl pl-1">天は喜び、地はたのしみ、</span><br /><span className="pl pl-1">もろもろの国民の中に言え、「主は王であられる」と。</span></span>
<span className="v" id="v32" data-v="32" data-xref="詩篇 148:9–10; イザヤ書 44:23; 詩篇 98:7–8"> <span className="pl pl-1">海とその中に満つるものとは鳴りどよめき、</span><br /><span className="pl pl-1">田畑とその中のすべての物は喜べ。</span></span>
<span className="v" id="v33" data-v="33" data-xref="詩篇 98:9; 詩篇 96:12–13; ヨハネの黙示録 11:17–18"> <span className="pl pl-1">そのとき林のもろもろの木も主のみ前に喜び歌う。</span><br /><span className="pl pl-1">主は地をさばくためにこられるからである。</span></span>
<span className="v" id="v34" data-v="34" data-xref="詩篇 106:1; 歴代志下 7:3; 詩篇 107:1"> <span className="pl pl-1">主に感謝せよ、主は恵みふかく、</span><br /><span className="pl pl-1">そのいつくしみはとこしえに絶えることがない。</span></span>
<span className="v" id="v35" data-v="35" data-xref="詩篇 106:47–48; ペテロの第一の手紙 2:9; 詩篇 14:7"> <span className="pl pl-1">また言え、「われわれの救の神よ、われわれを救い、</span><br /><span className="pl pl-1">もろもろの国民の中から</span><br /><span className="pl pl-1">われわれを集めてお救いください。</span><br /><span className="pl pl-1">そうすればあなたの聖なるみ名に感謝し、</span><br /><span className="pl pl-1">あなたの誉を誇るでしょう。</span></span>
<span className="v" id="v36" data-v="36" data-xref="列王紀上 8:15; 詩篇 72:18–19; 列王紀上 8:56"> <span className="pl pl-1">イスラエルの神、主は、</span><br /><span className="pl pl-1">とこしえからとこしえまでほむべきかな」と。</span><br />その時すべての民は「アァメン」と言って主をほめたたえた。</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="歴代志下 8:14; エズラ記 3:4; 歴代志上 16:4–6"> ダビデはアサフとその兄弟たちを主の契約の箱の前にとめおいて、常に箱の前に仕え、日々のわざを行わせた。</span>
<span className="v" id="v38" data-v="38" data-xref="歴代志上 26:10; 歴代志上 13:14; 歴代志上 25:3"> オベデ・エドムとその兄弟たちは合わせて六十八人である。またエドトンの子オベデ・エドムおよびホサは門守であった。</span>
<span className="v" id="v39" data-v="39" data-xref="列王紀上 3:4; 歴代志上 15:11; 歴代志下 1:3–4"> 祭司ザドクとその兄弟である祭司たちはギベオンにある高き所で主の幕屋の前に仕え、</span>
<span className="v" id="v40" data-v="40" data-xref="民数記 28:3–8; 出エジプト記 29:38–42; 歴代志下 31:3"> 主がイスラエルに命じられた律法にしるされたすべてのことにしたがって燔祭の壇の上に朝夕たえず燔祭を主にささげた。</span>
<span className="v" id="v41" data-v="41" data-xref="歴代志下 5:13; 歴代志上 25:1–6; 歴代志下 20:21"> また彼らとともにヘマン、エドトンおよびほかの選ばれて名をしるされた者どもがいて、主のいつくしみの世々限りなきことについて主に感謝した。</span>
<span className="v" id="v42" data-v="42" data-xref="詩篇 150:3–6; 歴代志上 25:6–7; 歴代志下 29:25–28"> すなわちヘマンおよびエドトンは彼らとともにいて、ラッパ、シンバルおよびその他の聖歌のための楽器をとって音楽を奏し、エドトンの子らは門を守った。</span>
</div>

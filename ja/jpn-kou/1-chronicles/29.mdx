<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歴代志上 22:5; 列王紀上 3:7; 歴代志下 13:7"> ダビデ王はまた全会衆に言った、「わが子ソロモンは神がただひとりを選ばれた者であるが、まだ若くて経験がなく、この事業は大きい。この宮は人のためではなく、主なる神のためだからである。</span>
<span className="v" id="v2" data-v="2" data-xref="歴代志上 22:3–5; コリント人への第二の手紙 8:3; イザヤ書 54:11–12"> そこでわたしは力をつくして神の宮のために備えた。すなわち金の物を造るために金、銀の物のために銀、青銅の物のために青銅、鉄の物のために鉄、木の物のために木を備えた。その他縞めのう、はめ石、アンチモニイ、色のついた石、さまざまの宝石、大理石などおびただしい。</span>
<span className="v" id="v3" data-v="3" data-xref="歴代志上 21:24; 詩篇 27:4; 詩篇 26:8"> なおわたしはわが神の宮に熱心なるがゆえに、聖なる家のために備えたすべての物に加えて、わたしの持っている金銀の財宝をわが神の宮にささげる。</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀上 9:28; 歴代志上 22:14; ヨブ記 28:16"> すなわちオフルの金三千タラント、精銀七千タラントをそのもろもろの建物の壁をおおうためにささげる。</span>
<span className="v" id="v5" data-v="5" data-xref="民数記 7:2–3; 出エジプト記 35:5–9; エズラ記 7:15–16"> 金は金の物のために、銀は銀の物のために、すべて工人によって造られるもののために用いる。だれかきょう、主にその身をささげる者のように喜んでささげ物をするだろうか」。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="コリント人への第二の手紙 9:7; 歴代志上 27:25–1; イザヤ書 60:3–10"> そこで氏族の長たち、イスラエルの部族のつかさたち、千人の長、百人の長および王の工事をつかさどる者たちは喜んでささげ物をした。</span>
<span className="v" id="v7" data-v="7" data-xref="ネヘミヤ書 7:70–71; エズラ記 2:69"> こうして彼らは神の宮の務のために金五千タラント一万ダリク、銀一万タラント、青銅一万八千タラント、鉄十万タラントをささげた。</span>
<span className="v" id="v8" data-v="8" data-xref="歴代志上 23:8; 歴代志上 26:21–22"> 宝石を持っている者はそれをゲルションびとエヒエルの手によって神の宮の倉に納めた。</span>
<span className="v" id="v9" data-v="9" data-xref="コリント人への第二の手紙 9:7–8; コリント人への第二の手紙 8:3; 列王紀上 8:61"> 彼らがこのように真心からみずから進んで主にささげたので、民はそのみずから進んでささげたのを喜んだ。ダビデ王もまた大いに喜んだ。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="エペソ人への手紙 1:3; ペテロの第一の手紙 1:3; ローマ人への手紙 1:7"> そこでダビデは全会衆の前で主をほめたたえた。ダビデは言った、「われわれの先祖イスラエルの神、主よ、あなたはとこしえにほむべきかたです。</span>
<span className="v" id="v11" data-v="11" data-xref="ヘブル人への手紙 1:3; ダニエル書 4:34–35; テモテヘの第一の手紙 1:17"> 主よ、大いなることと、力と、栄光と、勝利と、威光とはあなたのものです。天にあるもの、地にあるものも皆あなたのものです。主よ、国もまたあなたのものです。あなたは万有のかしらとして、あがめられます。</span>
<span className="v" id="v12" data-v="12" data-xref="エペソ人への手紙 3:16; 歴代志下 20:6; 申命記 8:18"> 富と誉とはあなたから出ます。あなたは万有をつかさどられます。あなたの手には勢いと力があります。あなたの手はすべてのものを大いならしめ、強くされます。</span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 106:1; コリント人への第二の手紙 9:15; コリント人への第二の手紙 8:16"> われわれの神よ、われわれは、いま、あなたに感謝し、あなたの光栄ある名をたたえます。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="ヤコブの手紙 1:17; コリント人への第二の手紙 3:5; ローマ人への手紙 11:36"> しかしわれわれがこのように喜んでささげることができても、わたしは何者でしょう。わたしの民は何でしょう。すべての物はあなたから出ます。われわれはあなたから受けて、あなたにささげたのです。</span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 144:4; レビ記 25:23; 詩篇 102:11"> われわれはあなたの前ではすべての先祖たちのように、旅びとです、寄留者です。われわれの世にある日は影のようで、長くとどまることはできません。</span>
<span className="v" id="v16" data-v="16" data-xref="歴代志上 29:14; 詩篇 24:1; 歴代志下 31:10"> われわれの神、主よ、あなたの聖なる名のために、あなたに家を建てようとしてわれわれが備えたこの多くの物は皆あなたの手から出たもの、また皆あなたのものです。</span>
<span className="v" id="v17" data-v="17" data-xref="エレミヤ書 17:10; 箴言 11:20; 歴代志上 28:9"> わが神よ、あなたは心をためし、また正直を喜ばれることを、わたしは知っています。わたしは正しい心で、このすべての物を喜んでささげました。今わたしはまた、ここにおるあなたの民が喜んで、みずから進んであなたにささげ物をするのを見ました。</span>
<span className="v" id="v18" data-v="18" data-xref="エレミヤ書 32:39; エレミヤ書 10:23; ヘブル人への手紙 13:21"> われわれの先祖アブラハム、イサク、イスラエルの神、主よ、あなたの民の心にこの意志と精神とをいつまでも保たせ、その心をあなたに向けさせてください。</span>
<span className="v" id="v19" data-v="19" data-xref="詩篇 72:1; 歴代志上 28:9; ヤコブの手紙 1:17"> またわが子ソロモンに心をつくしてあなたの命令と、あなたのあかしと、あなたのさだめとを守らせて、これをことごとく行わせ、わたしが備えをした宮を建てさせてください」。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="詩篇 95:6; 出エジプト記 4:31; 詩篇 135:19–21"> そしてダビデが全会衆にむかって、「あなたがたの神、主をほめたたえよ」と言ったので、全会衆は先祖たちの神、主をほめたたえ、伏して主を拝し、王に敬礼した。</span>
<span className="v" id="v21" data-v="21" data-xref="歴代志下 7:4–9; 民数記 15:7; エズラ記 6:17"> そしてその翌日彼らは全イスラエルのために主に犠牲をささげた。すなわち燔祭として雄牛一千、雄羊一千、小羊一千をその灌祭と共に主にささげ、おびただしい犠牲をささげた。</span>
<span className="v" id="v22" data-v="22" data-xref="列王紀上 2:35; 歴代志上 23:1; 出エジプト記 24:11"> そしてその日、彼らは大いなる喜びをもって主の前に食い飲みした。<br />彼らはさらに改めてダビデの子ソロモンを王となし、これに油を注いで主の君となし、またザドクを祭司とした。</span>
<span className="v" id="v23" data-v="23" data-xref="列王紀上 2:12; 歴代志上 28:5; ローマ人への手紙 13:1"> こうしてソロモンはその父ダビデに代り、王として主の位に座した。彼は栄え、イスラエルは皆彼に従った。</span>
<span className="v" id="v24" data-v="24" data-xref="歴代志上 2:3–9; エゼキエル書 17:18; 創世記 24:2"> またすべてのつかさたち、勇士たち、およびダビデ王の王子たちも皆ソロモン王に忠誠を誓った。</span>
<span className="v" id="v25" data-v="25" data-xref="歴代志下 1:12; 歴代志下 1:1; 伝道の書 2:9"> 主は全イスラエルの目の前でソロモンを非常に大いならしめ、彼より前のイスラエルのどの王も得たことのない王威を彼に与えられた。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="歴代志上 18:14; 詩篇 78:71–72"> このようにエッサイの子ダビデは全イスラエルを治めた。</span>
<span className="v" id="v27" data-v="27" data-xref="列王紀上 2:11; サムエル記下 5:4–5; 歴代志上 3:4"> 彼がイスラエルを治めた期間は四十年であった。すなわちヘブロンで七年世を治め、エルサレムで三十三年世を治めた。</span>
<span className="v" id="v28" data-v="28" data-xref="創世記 15:15; 使徒行伝 13:36; 歴代志上 23:1"> 彼は高齢に達し、年も富も誉も満ち足りて死んだ。その子ソロモンが彼に代って王となった。</span>
<span className="v" id="v29" data-v="29" data-xref="サムエル記上 9:9; サムエル記下 12:1–7; 歴代志上 21:9–11"> ダビデ王の始終の行為は、先見者サムエルの書、預言者ナタンの書および先見者ガドの書にしるされている。</span>
<span className="v" id="v30" data-v="30" data-xref="ダニエル書 4:25; ダニエル書 4:23; ダニエル書 2:21"> そのうちには彼のすべての政と、その力および彼とイスラエルと他のすべての国々に臨んだ事どもをしるしている。</span>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 32:28; 創世記 35:22–26; ヨハネの黙示録 7:5–8"> イスラエルの子らは次のとおりである。ルベン、シメオン、レビ、ユダ、イッサカル、ゼブルン、</span>
<span className="v" id="v2" data-v="2"> ダン、ヨセフ、ベニヤミン、ナフタリ、ガド、アセル。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 38:2–10; 創世記 46:12; 民数記 26:19"> ユダの子らはエル、オナン、シラである。この三人はカナンの女バテシュアがユダによって産んだ者である。ユダの長子エルは主の前に悪を行ったので、主は彼を殺された。</span>
<span className="v" id="v4" data-v="4" data-xref="マタイによる福音書 1:3; 創世記 38:13–30; ネヘミヤ書 11:4"> ユダの嫁タマルはユダによってペレヅとゼラを産んだ。ユダの子らは合わせて五人である。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="創世記 46:12; ルツ記 4:18; 民数記 26:21"> ペレヅの子らはヘヅロンとハムル。</span>
<span className="v" id="v6" data-v="6" data-xref="列王紀上 4:31; ヨシュア記 7:17–18; ヨシュア記 7:1"> ゼラの子らはジムリ、エタン、ヘマン、カルコル、ダラで、合わせて五人である。</span>
<span className="v" id="v7" data-v="7" data-xref="ヨシュア記 6:18; 申命記 7:26; ヨシュア記 7:25"> カルミの子はアカル。アカルは奉納物について罪を犯し、イスラエルを悩ました者である。</span>
<span className="v" id="v8" data-v="8"> エタンの子はアザリヤである。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="歴代志上 2:42; マタイによる福音書 1:3; ルツ記 4:19"> ヘヅロンに生れた子らはエラメル、ラム、ケルバイである。</span>
<span className="v" id="v10" data-v="10" data-xref="マタイによる福音書 1:4; 民数記 1:7; 民数記 2:3"> ラムはアミナダブを生み、アミナダブはユダの子孫のつかさナションを生んだ。</span>
<span className="v" id="v11" data-v="11" data-xref="ルツ記 4:21; マタイによる福音書 1:4–5; ルカによる福音書 3:32"> ナションはサルマを生み、サルマはボアズを生み、</span>
<span className="v" id="v12" data-v="12" data-xref="ローマ人への手紙 15:12; 歴代志上 10:14; イザヤ書 11:10"> ボアズはオベデを生み、オベデはエッサイを生んだ。</span>
<span className="v" id="v13" data-v="13" data-xref="サムエル記上 17:13; サムエル記上 17:28; 歴代志上 20:7"> エッサイは長子エリアブ、次にアビナダブ、第三にシメア、</span>
<span className="v" id="v14" data-v="14"> 第四にネタンエル、第五にラダイ、</span>
<span className="v" id="v15" data-v="15" data-xref="サムエル記上 16:10–11; サムエル記上 17:12–14"> 第六にオゼム、第七にダビデを生んだ。</span>
<span className="v" id="v16" data-v="16" data-xref="サムエル記上 26:6; サムエル記下 3:39; サムエル記下 2:18–23"> 彼らの姉妹はゼルヤとアビガイルである。ゼルヤの産んだ子はアビシャイ、ヨアブ、アサヘルの三人である。</span>
<span className="v" id="v17" data-v="17" data-xref="サムエル記下 17:25; 列王紀上 2:32; サムエル記下 20:4–12"> アビガイルはアマサを産んだ。アマサの父はイシマエルびとエテルである。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18"> ヘヅロンの子カレブはその妻アズバおよびエリオテによって子をもうけた。その子らはエシル、ショバブ、アルドンである。</span>
<span className="v" id="v19" data-v="19" data-xref="歴代志上 2:50; 歴代志上 2:24; 歴代志上 4:4"> カレブはアズバが死んだのでエフラタをめとった。エフラタはカレブによってホルを産んだ。</span>
<span className="v" id="v20" data-v="20" data-xref="出エジプト記 31:2; 出エジプト記 36:1–2; 出エジプト記 37:1"> ホルはウリを生み、ウリはベザレルを生んだ。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="民数記 27:1; 申命記 3:15; 民数記 26:29"> そののちヘヅロンはギレアデの父マキルの娘の所にはいった。彼が彼女をめとったときは六十歳であった。彼女はヘヅロンによってセグブを産んだ。</span>
<span className="v" id="v22" data-v="22" data-xref="ヨシュア記 13:30; 申命記 3:14; 民数記 32:41"> セグブはヤイルを生んだ。ヤイルはギレアデの地に二十三の町をもっていた。</span>
<span className="v" id="v23" data-v="23" data-xref="ヨシュア記 13:30; 申命記 3:14; 民数記 32:41–42"> しかしゲシュルとアラムは彼らからハボテ・ヤイルおよびケナテとその村里など合わせて六十の町を取った。これらはみなギレアデの父マキルの子孫であった。</span>
<span className="v" id="v24" data-v="24" data-xref="歴代志上 4:5; 歴代志上 2:9; サムエル記上 30:14"> ヘヅロンが死んだのち、カレブは父ヘヅロンの妻エフラタの所にはいった。彼女は彼にテコアの父アシュルを産んだ。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25"> ヘヅロンの長子エラメルの子らは長子ラム、次はブナ、オレン、オゼム、アヒヤである。</span>
<span className="v" id="v26" data-v="26"> エラメルはまたほかの妻をもっていた。名をアタラといって、オナムの母である。</span>
<span className="v" id="v27" data-v="27"> エラメルの長子ラムの子らはマアツ、ヤミン、エケルである。</span>
<span className="v" id="v28" data-v="28"> オナムの子らはシャンマイとヤダである。シャンマイの子らはナダブとアビシュルである。</span>
<span className="v" id="v29" data-v="29"> アビシュルの妻の名はアビハイルといって、アバンとモリデを産んだ。</span>
<span className="v" id="v30" data-v="30"> ナダブの子らはセレデとアッパイムである。セレデは子をもたずに死んだ。</span>
<span className="v" id="v31" data-v="31" data-xref="歴代志上 2:34–35"> アッパイムの子はイシ、イシの子はセシャン、セシャンの子はアヘライである。</span>
<span className="v" id="v32" data-v="32"> シャンマイの兄弟ヤダの子らはエテルとヨナタンである。エテルは子をもたずに死んだ。</span>
<span className="v" id="v33" data-v="33"> ヨナタンの子らはペレテとザザである。以上はエラメルの子孫である。</span>
<span className="v" id="v34" data-v="34"> セシャンには男の子はなく、ただ女の子のみであったが、彼はヤルハと呼ぶエジプトびとの奴隷をもっていたので、</span>
<span className="v" id="v35" data-v="35"> セシャンは娘を奴隷ヤルハに与えてその妻とさせた。彼女はヤルハによってアッタイを産んだ。</span>
<span className="v" id="v36" data-v="36" data-xref="歴代志上 11:41"> アッタイはナタンを生み、ナタンはザバデを生み、</span>
<span className="v" id="v37" data-v="37"> ザバデはエフラルを生み、エフラルはオベデを生み、</span>
<span className="v" id="v38" data-v="38"> オベデはエヒウを生み、エヒウはアザリヤを生み、</span>
<span className="v" id="v39" data-v="39"> アザリヤはヘレヅを生み、ヘレヅはエレアサを生み、</span>
<span className="v" id="v40" data-v="40"> エレアサはシスマイを生み、シスマイはシャルムを生み、</span>
<span className="v" id="v41" data-v="41"> シャルムはエカミヤを生み、エカミヤはエリシャマを生んだ。</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="歴代志上 2:23–24; ヘブル人への手紙 12:23; ローマ人への手紙 8:29"> エラメルの兄弟であるカレブの子らは長子をマレシャといってジフの父である。マレシャの子はヘブロン。</span>
<span className="v" id="v43" data-v="43"> ヘブロンの子らはコラ、タップア、レケム、シマである。</span>
<span className="v" id="v44" data-v="44"> シマはラハムを生んだ。ラハムはヨルカムの父である。またレケムはシャンマイを生んだ。</span>
<span className="v" id="v45" data-v="45" data-xref="ヨシュア記 15:58"> シャンマイの子はマオン。マオンはベテヅルの父である。</span>
<span className="v" id="v46" data-v="46" data-xref="歴代志上 2:18–19; 歴代志上 2:48"> カレブのそばめエパはハラン、モザ、ガゼズを産んだ。ハランはガゼズを生んだ。</span>
<span className="v" id="v47" data-v="47"> エダイの子らはレゲム、ヨタム、ゲシャン、ペレテ、エパ、シャフである。</span>
<span className="v" id="v48" data-v="48" data-xref="創世記 25:5–6; 歴代志上 2:46"> カレブのそばめマアカはシベルとテルハナを産み、</span>
<span className="v" id="v49" data-v="49" data-xref="ヨシュア記 15:31; 歴代志上 2:42; イザヤ書 10:31"> またマデマンナの父シャフおよびマクベナとギベアの父シワを産んだ。カレブの娘はアクサである。</span>
<span className="v" id="v50" data-v="50" data-xref="サムエル記上 7:1; ヨシュア記 15:60; 歴代志上 2:53"> これらはカレブの子孫であった。<br />エフラタの長子ホルの子らはキリアテ・ヤリムの父ショバル、</span>
<span className="v" id="v51" data-v="51" data-xref="歴代志上 4:4; ヨハネによる福音書 7:42; マタイによる福音書 2:6"> ベツレヘムの父サルマおよびベテガデルの父ハレフである。</span>
<span className="v" id="v52" data-v="52" data-xref="歴代志上 4:2"> キリアテ・ヤリムの父ショバル子らはハロエとメヌコテびとの半ばである。</span>
<span className="v" id="v53" data-v="53" data-xref="サムエル記下 23:38; 士師記 13:25; 士師記 13:2"> キリアテ・ヤリムの氏族はイテルびと、プテびと、シュマびと、ミシラびとであって、これらからザレアびとおよびエシタオルびとが出た。</span>
<span className="v" id="v54" data-v="54" data-xref="ネヘミヤ書 7:26; エズラ記 2:22; ネヘミヤ書 12:28"> サルマの子らはベツレヘム、ネトパびと、アタロテ・ベテ・ヨアブ、マナハテびとの半ばおよびゾリびとである。</span>
<span className="v" id="v55" data-v="55" data-xref="列王紀下 10:15; 士師記 1:16; エレミヤ書 35:19"> またヤベヅに住んでいた書記の氏族テラテびと、シメアテびと、スカテびとである。これらはケニびとであってレカブの家の先祖ハマテから出た者である。</span>
</div>

<span className="v" id="v3" data-v="3" data-xref="出エジプト記 6:20; レビ記 10:1; レビ記 10:12"> アムラムの子らはアロン、モーセ、ミリアム。アロンの子らはナダブ、アビウ、エレアザル、イタマル。</span>

<span className="v" id="v11" data-v="11" data-xref="エズラ記 7:3"> アザリヤはアマリヤを生み、アマリヤはアヒトブを生み、</span>
<span className="v" id="v12" data-v="12" data-xref="ネヘミヤ書 11:11; 歴代志上 9:11"> アヒトブはザトクを生み、ザトクはシャルムを生み、</span>
<span className="v" id="v13" data-v="13" data-xref="歴代志下 35:8; 列王紀下 22:12–14; 列王紀下 22:4"> シャルムはヒルキヤを生み、ヒルキヤはアザリヤを生み、</span>
<span className="v" id="v14" data-v="14" data-xref="列王紀下 25:18; ネヘミヤ書 11:11; ゼカリヤ書 6:11"> アザリヤはセラヤを生み、セラヤはヨザダクを生んだ。</span>
<span className="v" id="v15" data-v="15" data-xref="ハガイ書 2:2; 列王紀下 25:18; ハガイ書 1:1"> ヨザダクは主がネブカデネザルの手によってユダとエルサレムの人を捕え移された時に捕えられて行った。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="出エジプト記 6:16; 歴代志上 6:1"> レビの子らはゲルション、コハテおよびメラリ。</span>
<span className="v" id="v17" data-v="17" data-xref="歴代志上 23:7; 民数記 3:18; 民数記 3:21"> ゲルションの子らの名はリブニとシメイ。</span>
<span className="v" id="v18" data-v="18" data-xref="歴代志上 23:12; 歴代志上 6:2–3"> コハテの子らはアムラム、イヅハル、ヘブロン、ウジエルである。</span>
<span className="v" id="v19" data-v="19" data-xref="歴代志上 23:21; 歴代志上 24:26; 出エジプト記 6:19"> メラリの子らはマヘリとムシ。これらはレビびとのその家筋による氏族である。</span>
<span className="v" id="v20" data-v="20" data-xref="歴代志上 6:43"> ゲルションの子はリブニ、その子はヤハテ、その子はジンマ、</span>
<span className="v" id="v21" data-v="21"> その子はヨア、その子はイド、その子はゼラ、その子はヤテライ。</span>
<span className="v" id="v22" data-v="22" data-xref="出エジプト記 6:24; 歴代志上 6:18; 歴代志上 6:2"> コハテの子はアミナダブ、その子はコラ、その子はアシル、</span>
<span className="v" id="v23" data-v="23"> その子はエルカナ、その子はエビアサフ、その子はアシル、</span>
<span className="v" id="v24" data-v="24"> その子はタハテ、その子はウリエル、その子はウジヤ、その子はシャウル。</span>
<span className="v" id="v25" data-v="25" data-xref="出エジプト記 6:24; 歴代志上 6:35–36"> エルカナの子らはアマサイとアヒモテ、</span>
<span className="v" id="v26" data-v="26" data-xref="サムエル記上 1:1; 歴代志上 6:35"> その子はエルカナ、その子はゾパイ、その子はナハテ、</span>
<span className="v" id="v27" data-v="27" data-xref="サムエル記上 1:1; サムエル記上 1:19–20"> その子はエリアブ、その子はエロハム、その子はエルカナ。</span>
<span className="v" id="v28" data-v="28" data-xref="歴代志上 6:33; サムエル記上 8:2"> サムエルの子らは、長子はヨエル、次はアビヤ。</span>
<span className="v" id="v29" data-v="29" data-xref="歴代志上 6:19; 民数記 3:33"> メラリの子はマヘリ、その子はリブニ、その子はシメイ、その子はウザ、</span>
<span className="v" id="v30" data-v="30"> その子はシメア、その子はハギヤ、その子はアサヤである。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="サムエル記下 6:17; 歴代志上 15:25–1; 歴代志上 15:16–22"> 契約の箱を安置したのち、ダビデが主の宮で歌をうたう事をつかさどらせた人々は次のとおりである。</span>
<span className="v" id="v32" data-v="32" data-xref="詩篇 135:1–3; 列王紀上 8:6–13; エズラ記 6:18"> 彼らは会見の幕屋の前で歌をもって仕えたが、ソロモンがエルサレムに主の宮を建ててからは、一定の秩序に従って務を行った。</span>
<span className="v" id="v33" data-v="33" data-xref="歴代志上 6:28; 歴代志上 15:17; 歴代志上 25:1–5"> その務をしたもの、およびその子らは次のとおりである。コハテびとの子らのうちヘマンは歌をうたう者、ヘマンはヨエルの子、ヨエルはサムエルの子、</span>
<span className="v" id="v34" data-v="34"> サムエルはエルカナの子、エルカナはエロハムの子、エロハムはエリエルの子、エリエルはトアの子、</span>
<span className="v" id="v35" data-v="35"> トアはヅフの子、ヅフはエルカナの子、エルカナはマハテの子、マハテはアマサイの子、</span>
<span className="v" id="v36" data-v="36"> アマサイはエルカナの子、エルカナはヨエルの子、ヨエルはアザリヤの子、アザリヤはゼパニヤの子、</span>
<span className="v" id="v37" data-v="37" data-xref="詩篇 45:1; 民数記 26:10–11; 出エジプト記 6:21–24"> ゼパニヤはタハテの子、タハテはアシルの子、アシルはエビアサフの子、エビアサフはコラの子、</span>
<span className="v" id="v38" data-v="38" data-xref="民数記 3:19; 歴代志上 16:1"> コラはイヅハルの子、イヅハルはコハテの子、コハテはレビの子、レビはイスラエルの子である。</span>
<span className="v" id="v39" data-v="39" data-xref="ネヘミヤ書 7:44; エズラ記 2:41; 詩篇 75:1"> ヘマンの兄弟アサフはヘマンの右に立った。アサフはベレキヤの子、ベレキヤはシメアの子、</span>
<span className="v" id="v40" data-v="40"> シメアはミカエルの子、ミカエルはバアセヤの子、バアセヤはマルキヤの子、</span>
<span className="v" id="v41" data-v="41"> マルキヤはエテニの子、エテニはゼラの子、ゼラはアダヤの子、</span>
<span className="v" id="v42" data-v="42"> アダヤはエタンの子、エタンはジンマの子、ジンマはシメイの子、</span>
<span className="v" id="v43" data-v="43" data-xref="出エジプト記 6:16; 歴代志上 6:16–17; 創世記 46:11"> シメイはヤハテの子、ヤハテはゲルションの子、ゲルションはレビの子である。</span>
<span className="v" id="v44" data-v="44" data-xref="詩篇 89:1; 歴代志上 15:17; 歴代志上 25:1"> また彼らの兄弟であるメラリの子らが左に立った。そのうちのエタンはキシの子、キシはアブデの子、アブデはマルクの子、</span>
<span className="v" id="v45" data-v="45"> マルクはハシャビヤの子、ハシャビヤはアマジヤの子、アマジヤはヒルキヤの子、</span>
<span className="v" id="v46" data-v="46"> ヒルキヤはアムジの子、アムジはバニの子、バニはセメルの子、</span>
<span className="v" id="v47" data-v="47" data-xref="ヨシュア記 21:7; 出エジプト記 6:19; 歴代志上 23:21"> セメルはマヘリの子、マヘリはムシの子、ムシはメラリの子、メラリはレビの子である。</span>
<span className="v" id="v48" data-v="48" data-xref="歴代志上 23:2; 民数記 3:1–4; 民数記 18:1–32"> 彼らの兄弟であるレビびとたちは、神の宮の幕屋のもろもろの務に任じられた。</span>
</div>
<div className="bp">

<span className="v" id="v50" data-v="50" data-xref="レビ記 10:16; 歴代志上 24:1; 民数記 20:26–28"> アロンの子孫は次のとおりである。アロンの子はエレアザル、その子はピネハス、その子はアビシュア、</span>
<span className="v" id="v51" data-v="51"> その子はブッキ、その子はウジ、その子はゼラヒヤ、</span>
<span className="v" id="v52" data-v="52"> その子はメラヨテ、その子はアマリヤ、その子はアヒトブ、</span>
<span className="v" id="v53" data-v="53" data-xref="サムエル記下 8:17; エゼキエル書 44:15; サムエル記下 15:35–36"> その子はザドク、その子はアヒマアズである。</span>
</div>
<div className="bp">
<span className="v" id="v54" data-v="54" data-xref="創世記 25:16; ヨシュア記 21:10; ヨシュア記 21:3–8"> アロンの子孫の住む所はその境のうちにある宿営によっていえば次のとおりである。まずコハテびとの氏族がくじによって得たところ、</span>
<span className="v" id="v55" data-v="55" data-xref="ヨシュア記 14:13; ヨシュア記 21:11–13; ヨシュア記 15:13"> すなわち彼らが与えられたところは、ユダの地にあるヘブロンとその周囲の放牧地である。</span>
<span className="v" id="v56" data-v="56" data-xref="ヨシュア記 15:13; ヨシュア記 14:13"> ただし、その町の田畑とその村々は、エフンネの子カレブに与えられた。</span>
<span className="v" id="v57" data-v="57" data-xref="ヨシュア記 21:13–14; ヨシュア記 15:48; ヨシュア記 10:29"> そしてアロンの子孫に与えられたものは、のがれの町であるヘブロンおよびリブナとその放牧地、ヤッテルおよびエシテモアとその放牧地、</span>
<span className="v" id="v58" data-v="58" data-xref="ヨシュア記 10:3; ヨシュア記 15:49; ヨシュア記 12:13"> ヒレンとその放牧地、デビルとその放牧地、</span>
<span className="v" id="v59" data-v="59" data-xref="ヨシュア記 21:16; ヨシュア記 15:42; サムエル記上 6:12–19"> アシャンとその放牧地、ベテシメシとその放牧地である。</span>
<span className="v" id="v60" data-v="60" data-xref="エレミヤ書 1:1; 列王紀上 2:26; エレミヤ書 11:23"> またベニヤミンの部族のうちからはゲバとその放牧地、アレメテとその放牧地、アナトテとその放牧地を与えられた。彼らの町は、すべてその氏族のうちに十三あった。</span>
</div>
<div className="bp">
<span className="v" id="v61" data-v="61" data-xref="ヨシュア記 21:4–5; 歴代志上 6:18; ヨシュア記 21:20–26"> またコハテの子孫の残りの者は部族の氏族のうちからと、半部族すなわちマナセの半部族のうちからくじによって十の町を与えられた。</span>
<span className="v" id="v62" data-v="62" data-xref="ヨシュア記 21:27–33; 歴代志上 6:71–76; 出エジプト記 2:22"> またゲルションの子孫はその氏族によってイッサカルの部族、アセルの部族、ナフタリの部族、およびバシャンのマナセの部族のうちから十三の町が与えられた。</span>
<span className="v" id="v63" data-v="63" data-xref="ヨシュア記 21:7; ヨシュア記 21:34–40; 民数記 3:20"> メラリの子孫はその氏族によってルベンの部族、ガドの部族、およびゼブルンの部族のうちからくじによって十二の町が与えられた。</span>
<span className="v" id="v64" data-v="64" data-xref="ヨシュア記 21:41–42; ヨシュア記 21:3; 民数記 35:1–8"> このようにイスラエルの人々はレビびとに町々とその放牧地とを与えた。</span>
<span className="v" id="v65" data-v="65" data-xref="歴代志上 6:57–60"> すなわちユダの子孫の部族とシメオンの部族の子孫と、ベニヤミンの子孫の部族のうちからここに名をあげたこれらの町をくじによって与えた。</span>
</div>
<div className="bp">

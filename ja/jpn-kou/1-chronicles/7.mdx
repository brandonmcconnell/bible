<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 46:13; 民数記 26:23–24"> イッサカルの子らはトラ、プワ、ヤシュブ、シムロムの四人。</span>
<span className="v" id="v2" data-v="2" data-xref="サムエル記下 24:1–9; 歴代志上 27:23–24; 歴代志上 27:1"> トラの子らはウジ、レパヤ、エリエル、ヤマイ、エブサム、サムエル。これは皆トラの子で、その氏族の長である。その子孫の大勇士たる者はダビデの世にはその数二万二千六百人であった。</span>
<span className="v" id="v3" data-v="3"> ウジの子はイズラヒヤ、イズラヒヤの子らはミカエル、オバデヤ、ヨエル、イシアの五人で、みな長たる者であった。</span>
<span className="v" id="v4" data-v="4" data-xref="歴代志上 12:32"> その子孫のうちに、その氏族に従えば軍勢の士卒三万六千人あった。これは彼らが妻子を多くもっていたからである。</span>
<span className="v" id="v5" data-v="5"> イッサカルのすべての氏族のうちの兄弟たちで系図によって数えられた大勇士は合わせて八万七千人あった。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="創世記 46:21; 歴代志上 8:1–40; 歴代志上 7:10–11"> ベニヤミンの子らはベラ、ベケル、エデアエルの三人。</span>
<span className="v" id="v7" data-v="7" data-xref="歴代志下 17:17–18; 歴代志上 21:1–5"> ベラの子らはエヅボン、ウジ、ウジエル、エレモテ、イリの五人で、皆その氏族の長である。その系図によって数えられた大勇士は二万二千三十四人あった。</span>
<span className="v" id="v8" data-v="8"> ベケルの子らはゼミラ、ヨアシ、エリエゼル、エリオエナイ、オムリ、エレモテ、アビヤ、アナトテ、アラメテで皆ベケルの子らである。</span>
<span className="v" id="v9" data-v="9"> その子孫のうち、その氏族の長として系図によって数えられた大勇士は二万二百人あった。</span>
<span className="v" id="v10" data-v="10" data-xref="士師記 3:15–30"> エデアエルの子はビルハン。ビルハンの子らはエウシ、ベニヤミン、エホデ、ケナアナ、ゼタン、タルシシ、アヒシャハル。</span>
<span className="v" id="v11" data-v="11" data-xref="歴代志下 17:13–19"> 皆エデアエルの子らで氏族の長であった。その子孫のうちには、いくさに出てよく戦う大勇士が一万七千二百人あった。</span>
<span className="v" id="v12" data-v="12" data-xref="民数記 26:38–39; 創世記 46:21; 歴代志上 7:15"> またイルの子らはシュパムとホパム。アヘルの子はホシムである。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="民数記 26:48–49; 創世記 30:3–8; 創世記 35:22"> ナフタリの子らはヤハジエル、グニ、エゼル、シャルムで皆ビルハの産んだ子である。</span>
<span className="v" id="v14" data-v="14" data-xref="民数記 32:30–42; 士師記 5:14; 申命記 3:13–15"> マナセの子らはそのそばめであるスリヤの女の産んだアスリエル。彼女はまたギレアデの父マキルを産んだ。</span>
<span className="v" id="v15" data-v="15" data-xref="民数記 26:33; 民数記 36:1–12; 民数記 27:1–11"> マキルはホパムとシュパムの妹マアカという者を妻にめとった。二番目の子はゼロペハデという。ゼロペハデには女の子だけがあった。</span>
<span className="v" id="v16" data-v="16"> マキルの妻マアカは男の子を産んで名をペレシと名づけた。その弟の名はシャレシ。シャレシの子らはウラムとラケムである。</span>
<span className="v" id="v17" data-v="17" data-xref="サムエル記上 12:11"> ウラムの子はベダン。これらはマナセの子マキルの子であるギレアデの子らである。</span>
<span className="v" id="v18" data-v="18" data-xref="士師記 6:24; 士師記 6:11; 士師記 8:2"> その妹ハンモレケテはイシホデ、アビエゼル、マヘラを産んだ。</span>
<span className="v" id="v19" data-v="19"> セミダの子らはアヒアン、シケム、リキ、アニアムである。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="民数記 26:35–36"> エフライムの子はシュテラ、その子はベレデ、その子はタハテ、その子はエラダ、その子はタハテ、</span>
<span className="v" id="v21" data-v="21"> その子はザバデ、その子はシュテラである。エゼルとエレアデはガテの土人らに殺された。これは彼らが下って行ってその家畜を奪おうとしたからである。</span>
<span className="v" id="v22" data-v="22" data-xref="ヨブ記 2:11; 創世記 37:34"> 父エフライムが日久しくこのために悲しんだので、その兄弟たちが来て彼を慰めた。</span>
<span className="v" id="v23" data-v="23" data-xref="サムエル記下 23:5"> そののち、エフライムは妻のところにはいった。妻ははらんで男の子を産み、その名をベリアと名づけた。その家に災があったからである。</span>
<span className="v" id="v24" data-v="24" data-xref="ヨシュア記 16:3; ヨシュア記 16:5; 歴代志下 8:5"> エフライムの娘セラは上と下のベテホロンおよびウゼン・セラを建てた。</span>
<span className="v" id="v25" data-v="25"> ベリアの子はレパ、その子はレセフ、その子はテラ、その子はタハン、</span>
<span className="v" id="v26" data-v="26"> その子はラダン、その子はアミホデ、その子はエリシャマ、</span>
<span className="v" id="v27" data-v="27" data-xref="民数記 13:8; 民数記 13:16; 出エジプト記 17:9–14"> その子はヌン、その子はヨシュア。</span>
<span className="v" id="v28" data-v="28" data-xref="創世記 28:19; ヨシュア記 16:2–3; 歴代志上 6:66–67"> エフライムの子孫の領地と住所はベテルとその村々、また東の方ではナアラン、西の方ではゲゼルとその村々、またシケムとその村々、アワとその村々。</span>
<span className="v" id="v29" data-v="29" data-xref="士師記 1:22–29; ゼカリヤ書 12:11; 列王紀下 9:27"> またマナセの子孫の国境に沿って、ベテシャンとその村々、タアナクとその村々、メギドンとその村々、ドルとその村々で、イスラエルの子ヨセフの子孫はこれらの所に住んだ。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="創世記 46:17; 民数記 26:44–46"> アセルの子らはイムナ、イシワ、エスイ、ベリアおよびその姉妹セラ。</span>
<span className="v" id="v31" data-v="31"> ベリアの子らはヘベルとマルキエル。マルキエルはビルザヒテの父である。</span>
<span className="v" id="v32" data-v="32"> ヘベルはヤフレテ、ショメル、ホタムおよびその姉妹シュアを生んだ。</span>
<span className="v" id="v33" data-v="33"> ヤフレテの子らはパサク、ビムハル、アシワテ。これらはヤレフテの子らである。</span>
<span className="v" id="v34" data-v="34"> 彼の兄弟ショメルの子らはロガ、ホバおよびアラム。</span>
<span className="v" id="v35" data-v="35"> ショメルの兄弟ヘレムの子らはゾパ、イムナ、シレシ、アマル。</span>
<span className="v" id="v36" data-v="36"> ゾパの子らはスア、ハルネペル、シュアル、ベリ、イムラ、</span>
<span className="v" id="v37" data-v="37"> ベゼル、ホド、シャンマ、シルシャ、イテラン、ベエラ。</span>
<span className="v" id="v38" data-v="38"> エテルの子らはエフンネ、ピスパおよびアラ。</span>
<span className="v" id="v39" data-v="39"> ウラの子らはアラ、ハニエル、およびリヂア。</span>
<span className="v" id="v40" data-v="40" data-xref="歴代志上 21:1–5; サムエル記下 24:1–9"> これらは皆アセルの子孫であって、その氏族の長、えりぬきの大勇士、つかさたちのかしらであった。その系図によって数えられた者で、いくさに出てよく戦う者の数は二万六千人であった。</span>
</div>

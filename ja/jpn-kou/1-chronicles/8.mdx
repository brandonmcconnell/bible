<span className="v" id="v1" data-v="1" data-xref="創世記 46:21; 歴代志上 7:6–12; 民数記 26:38"> ベニヤミンの生んだ者は長子はベラ、その次はアシベル、第三はアハラ、</span>
<span className="v" id="v2" data-v="2"> 第四はノハ、第五はラパ。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 46:21; 民数記 26:40"> ベラの子らはアダル、ゲラ、アビウデ、</span>
<span className="v" id="v4" data-v="4"> アビシュア、ナアマン、アホア、</span>
<span className="v" id="v5" data-v="5" data-xref="歴代志上 7:12; 民数記 26:39; 士師記 3:15"> ゲラ、シフパム、ヒラム。</span>
<span className="v" id="v6" data-v="6" data-xref="歴代志上 2:54; 士師記 3:20–30; 歴代志上 7:10"> エホデの子らは次のとおりである。（これらはゲバの住民の氏族の長であって、マナハテに捕え移されたものである。）</span>
<span className="v" id="v7" data-v="7"> すなわちナアマン、アヒヤ、ゲラすなわちヘグラム。ゲラはウザとアヒフデの父であった。</span>
<span className="v" id="v8" data-v="8" data-xref="ルツ記 1:1; 創世記 25:6"> シャハライムは妻ホシムとバアラを離別してのち、モアブの国で子らをもうけた。</span>
<span className="v" id="v9" data-v="9"> 彼が妻ホデシによってもうけた子らはヨバブ、ヂビア、メシャ、マルカム、</span>
<span className="v" id="v10" data-v="10"> エウヅ、シャキヤ、ミルマ。これらはその子らであって氏族の長である。</span>
<span className="v" id="v11" data-v="11"> 彼はまたホシムによってアビトブとエルパアルをもうけた。</span>
<span className="v" id="v12" data-v="12" data-xref="エズラ記 2:33; ネヘミヤ書 7:37; ネヘミヤ書 6:2"> エルパアルの子らはエベル、ミシャムおよびセメド。彼はオノとロドとその村々を建てた者である。</span>
<span className="v" id="v13" data-v="13" data-xref="歴代志上 2:52; ヨシュア記 19:42; 歴代志上 4:4"> またベリアとシマがあった。（これはアヤロンの住民の氏族の長であって、ガテの住民を追い払ったものである。）</span>
<span className="v" id="v14" data-v="14"> またアヒオ、シャシャク、エレモテ。</span>
<span className="v" id="v15" data-v="15"> ゼバデヤ、アラデ、アデル、</span>
<span className="v" id="v16" data-v="16"> ミカエル、イシパおよびヨハはベリアの子らであった。</span>
<span className="v" id="v17" data-v="17"> ゼバデヤ、メシュラム、ヘゼキ、ヘベル、</span>
<span className="v" id="v18" data-v="18"> イシメライ、エズリアおよびヨバブはエルパアルの子らであった。</span>
<span className="v" id="v19" data-v="19"> ヤキン、ジクリ、ザベデ、</span>
<span className="v" id="v20" data-v="20"> エリエナイ、チルタイ、エリエル、</span>
<span className="v" id="v21" data-v="21"> アダヤ、ベラヤおよびシムラテはシマの子らであった。</span>
<span className="v" id="v22" data-v="22"> イシパン、ヘベル、エリエル、</span>
<span className="v" id="v23" data-v="23"> アブドン、ジクリ、ハナン、</span>
<span className="v" id="v24" data-v="24"> ハナニヤ、エラム、アントテヤ、</span>
<span className="v" id="v25" data-v="25"> イペデヤおよびペヌエルはシャシャクの子らであった。</span>
<span className="v" id="v26" data-v="26"> シャムセライ、シハリア、アタリヤ、</span>
<span className="v" id="v27" data-v="27"> ヤレシャ、エリヤおよびジクリはエロハムの子らであった。</span>
<span className="v" id="v28" data-v="28" data-xref="士師記 1:21; ヨシュア記 15:63; ネヘミヤ書 11:1"> これらは歴代の氏族の長であり、またかしらであって、エルサレムに住んだ。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="歴代志上 9:35–38"> ギベオンの父エイエルはギベオンに住み、その妻の名はマアカといった。</span>
<span className="v" id="v30" data-v="30" data-xref="歴代志上 9:36–37"> その長子はアブドンで、次はツル、キシ、バアル、ナダブ、</span>
<span className="v" id="v31" data-v="31" data-xref="歴代志上 9:37"> ゲドル、アヒオ、ザケル、</span>
<span className="v" id="v32" data-v="32" data-xref="歴代志上 9:38"> およびミクロテ。ミクロテはシメアを生んだ。これらもまた兄弟たちと向かいあってエルサレムに住んだ。</span>
<span className="v" id="v33" data-v="33" data-xref="サムエル記上 9:1; サムエル記下 2:8; サムエル記上 31:2"> ネルはキシを生み、キシはサウルを生み、サウルはヨナタン、マルキシュア、アビナダブ、エシバアルを生んだ。</span>
<span className="v" id="v34" data-v="34" data-xref="サムエル記下 4:4; サムエル記下 9:12; サムエル記下 9:10"> ヨナタンの子はメリバアルで、メリバアルはミカエルを生んだ。</span>
<span className="v" id="v35" data-v="35" data-xref="歴代志上 9:41"> ミカの子らはピトン、メレク、タレア、アハズである。</span>
<span className="v" id="v36" data-v="36" data-xref="歴代志上 9:42"> アハズはエホアダを生み、エホアダはアレメテ、アズマウテ、ジムリを生み、ジムリはモザを生み、</span>
<span className="v" id="v37" data-v="37" data-xref="歴代志上 9:43"> モザはビネアを生んだ。ビネアの子はラパ、ラパの子はエレアサ、エレアサの子はアゼルである。</span>
<span className="v" id="v38" data-v="38"> アゼルには六人の子があり、その名はアズリカム、ボケル、イシマエル、シャリヤ、オバデヤ、ハナンで、皆アゼルの子である。</span>
<span className="v" id="v39" data-v="39"> その兄弟エセクの子らは、長子はウラム、次はエウシ、第三はエリペレテである。</span>
<span className="v" id="v40" data-v="40" data-xref="詩篇 128:3–6; 歴代志下 14:8; 歴代志上 12:2"> ウラムの子らは大勇士で、よく弓を射る者であった。彼は多くの子と孫をもち、百五十人もあった。これらは皆ベニヤミンの子孫である。</span>

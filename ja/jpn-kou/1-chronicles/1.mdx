<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ルカによる福音書 3:38; 創世記 4:25–32"> アダム、セツ、エノス、</span>
<span className="v" id="v2" data-v="2" data-xref="ルカによる福音書 3:37; 創世記 5:12–20; 創世記 5:9"> ケナン、マハラレル、ヤレド、</span>
<span className="v" id="v3" data-v="3" data-xref="ユダの手紙 1:14; 創世記 5:21–31; ルカによる福音書 3:36–37"> エノク、メトセラ、ラメク、</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 5:32; 創世記 9:18; ルカによる福音書 17:26"> ノア、セム、ハム、ヤペテ。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="創世記 10:1–5; エゼキエル書 38:6; エゼキエル書 27:13"> ヤペテの子らはゴメル、マゴグ、マダイ、ヤワン、トバル、メセク、テラス。</span>
<span className="v" id="v6" data-v="6" data-xref="創世記 10:3"> ゴメルの子らはアシケナズ、デパテ、トガルマ。</span>
<span className="v" id="v7" data-v="7" data-xref="エレミヤ書 2:10; 民数記 24:24; イザヤ書 66:19"> ヤワンの子らはエリシャ、タルシシ、キッテム、ロダニム。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="創世記 10:6–7"> ハムの子らはクシ、エジプト、プテ、カナン。</span>
<span className="v" id="v9" data-v="9"> クシの子らはセバ、ハビラ、サブタ、ラアマ、サブテカ。ラアマの子らはシバとデダン。</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 10:8–12; ミカ書 5:6"> クシはニムロデを生んだ。ニムロデは初めて世の権力ある者となった。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="創世記 10:13–18"> エジプトはルデびと、アナムびと、レハブびと、ナフトびと、</span>
<span className="v" id="v12" data-v="12" data-xref="申命記 2:23; エレミヤ書 47:4; アモス書 9:7"> パテロスびと、カスルびと、カフトルびとを生んだ。カフトルびとからペリシテびとが出た。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="創世記 9:22; 創世記 23:20; 創世記 10:15–19"> カナンは長子シドンとヘテを生んだ。</span>
<span className="v" id="v14" data-v="14" data-xref="創世記 15:21; ヨシュア記 3:10; 出エジプト記 33:2"> またエブスびと、アモリびと、ギルガシびと、</span>
<span className="v" id="v15" data-v="15" data-xref="出エジプト記 3:8; 列王紀上 9:20; 出エジプト記 13:5"> ヒビびと、アルキびと、セニびと、</span>
<span className="v" id="v16" data-v="16" data-xref="民数記 34:8; 列王紀上 8:65"> アルワデびと、ゼマリびと、ハマテびとを生んだ。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="創世記 10:22–32; エズラ記 4:2; エゼキエル書 32:24"> セムの子らはエラム、アシュル、アルパクサデ、ルデ、アラム、ウズ、ホル、ゲテル、メセクである。</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 11:12–15; 創世記 10:24"> アルパクサデはシラを生み、シラはエベルを生んだ。</span>
<span className="v" id="v19" data-v="19" data-xref="創世記 10:21; 創世記 11:16–17; 創世記 10:25"> エベルにふたりの子が生れた。ひとりの名はペレグ――彼の代に地の民が散り分れたからである――その弟の名はヨクタンといった。</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 10:26–27"> ヨクタンはアルモダデ、シャレフ、ハザル・マウテ、エラ、</span>
<span className="v" id="v21" data-v="21"> ハドラム、ウザル、デクラ、</span>
<span className="v" id="v22" data-v="22" data-xref="創世記 10:28"> エバル、アビマエル、シバ、</span>
<span className="v" id="v23" data-v="23" data-xref="列王紀上 10:11; 創世記 25:18; サムエル記上 15:7"> オフル、ハビラ、ヨバブを生んだ。これらはみなヨクタンの子である。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="創世記 11:10–26; ルカによる福音書 3:34–36"> セム、アルパクサデ、シラ、</span>
<span className="v" id="v25" data-v="25" data-xref="ルカによる福音書 3:35"> エベル、ペレグ、リウ、</span>
<span className="v" id="v26" data-v="26" data-xref="ルカによる福音書 3:34–35"> セルグ、ナホル、テラ、</span>
<span className="v" id="v27" data-v="27" data-xref="創世記 11:27–32; ネヘミヤ書 9:7; ヨシュア記 24:2"> アブラムすなわちアブラハムである。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="創世記 17:19–21; 創世記 21:2–5; 創世記 21:9–10"> アブラハムの子らはイサクとイシマエルである。</span>
<span className="v" id="v29" data-v="29" data-xref="イザヤ書 60:7; 創世記 25:12–16; 雅歌 1:5"> 彼らの子孫は次のとおりである。イシマエルの長子はネバヨテ、次はケダル、アデビエル、ミブサム、</span>
<span className="v" id="v30" data-v="30" data-xref="イザヤ書 21:11; 創世記 25:15"> ミシマ、ドマ、マッサ、ハダデ、テマ、</span>
<span className="v" id="v31" data-v="31"> エトル、ネフシ、ケデマ。これらはイシマエルの子孫である。</span>
<span className="v" id="v32" data-v="32" data-xref="創世記 25:1–4; エレミヤ書 25:23; 士師記 6:1–6"> アブラハムのそばめケトラの子孫は次のとおりである。彼女はジムラン、ヨクシャン、メダン、ミデアン、イシバク、シュワを産んだ。ヨクシャンの子らはシバとデダンである。</span>
<span className="v" id="v33" data-v="33" data-xref="イザヤ書 60:6"> ミデアンの子らはエパ、エペル、ヘノク、アビダ、エルダア。これらはみなケトラの子孫である。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="創世記 32:28; 使徒行伝 7:8; マタイによる福音書 1:2"> アブラハムはイサクを生んだ。イサクの子らはエサウとイスラエル。</span>
<span className="v" id="v35" data-v="35" data-xref="創世記 36:9–10; 創世記 36:4–5"> エサウの子らはエリパズ、リウエル、エウシ、ヤラム、コラ。</span>
<span className="v" id="v36" data-v="36" data-xref="エレミヤ書 49:20; アモス書 1:12; オバデヤ書 1:9"> エリパズの子らはテマン、オマル、ゼピ、ガタム、ケナズ、テムナ、アマレク。</span>
<span className="v" id="v37" data-v="37"> リウエルの子らはナハテ、ゼラ、シャンマ、ミッザ。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="創世記 36:20–30"> セイルの子らはロタン、ショバル、ヂベオン、アナ、デション、エゼル、デシャン。</span>
<span className="v" id="v39" data-v="39" data-xref="申命記 2:12; 創世記 36:22; 申命記 2:22"> ロタンの子らはホリとホマム。ロタンの妹はテムナ。</span>
<span className="v" id="v40" data-v="40" data-xref="創世記 36:23–24"> ショバルの子らはアルヤン、マナハテ、エバル、シピ、オナム。ヂベオンの子らはアヤとアナ。</span>
<span className="v" id="v41" data-v="41" data-xref="創世記 36:25–26"> アナの子はデション。デションの子らはハムラン、エシバン、イテラン、ケラン。</span>
<span className="v" id="v42" data-v="42" data-xref="哀歌 4:21; 創世記 36:27–28"> エゼルの子らはビルハン、ザワン、ヤカン。デシャンの子らはウズとアラン。</span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="創世記 36:31–43; 民数記 24:17–19; 創世記 49:10"> イスラエルの人々を治める王がまだなかった時、エドムの地を治めた王たちは次のとおりである。ベオルの子ベラ。その都の名はデナバといった。</span>
<span className="v" id="v44" data-v="44" data-xref="イザヤ書 34:6; イザヤ書 63:1; アモス書 1:12"> ベラが死んで、ボズラのゼラの子ヨバブが代って王となった。</span>
<span className="v" id="v45" data-v="45" data-xref="創世記 36:11; ヨブ記 2:11"> ヨバブが死んで、テマンびとの地のホシャムが代って王となった。</span>
<span className="v" id="v46" data-v="46"> ホシャムが死んで、ベダテの子ハダデが代って王となった。彼はモアブの野でミデアンを撃った。彼の都の名はアビテといった。</span>
<span className="v" id="v47" data-v="47" data-xref="創世記 36:36"> ハダデが死んで、マスレカのサムラが代って王となった。</span>
<span className="v" id="v48" data-v="48" data-xref="創世記 36:37"> サムラが死んで、ユフラテ川のほとりのレホボテのサウルが代って王となった。</span>
<span className="v" id="v49" data-v="49"> サウルが死んで、アクボルの子バアル・ハナンが代って王となった。</span>
<span className="v" id="v50" data-v="50" data-xref="創世記 36:39"> バアル・ハナンが死んで、ハダデが代って王となった。彼の都の名はパイといった。彼の妻はマテレデの娘であって、名をメヘタベルといった。マテレデはメザハブの娘である。</span>
<span className="v" id="v51" data-v="51" data-xref="創世記 36:40"> ハダデも死んだ。<br />エドムの族長は、テムナ侯、アルヤ侯、エテテ侯、</span>
<span className="v" id="v52" data-v="52"> アホリバマ侯、エラ侯、ピノン侯、</span>
<span className="v" id="v53" data-v="53"> ケナズ侯、テマン侯、ミブザル侯、</span>
<span className="v" id="v54" data-v="54" data-xref="創世記 36:41–43"> マグデエル侯、イラム侯。これらはエドムの族長である。</span>
</div>

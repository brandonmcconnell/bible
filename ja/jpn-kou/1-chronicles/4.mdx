<span className="v" id="v1" data-v="1" data-xref="創世記 46:12; 創世記 38:29; 民数記 26:20–21"> ユダの子らはペレヅ、ヘヅロン、カルミ、ホル、ショバルである。</span>
<span className="v" id="v2" data-v="2" data-xref="士師記 13:25; 歴代志上 2:52–54; ヨシュア記 15:33"> ショバルの子レアヤはヤハテを生み、ヤハテはアホマイとラハデを生んだ。これらはザレアびとの一族である。</span>
<span className="v" id="v3" data-v="3" data-xref="士師記 15:11; 歴代志下 11:6"> エタムの子らはエズレル、イシマおよびイデバシ、彼らの姉妹の名はハゼレルポニである。</span>
<span className="v" id="v4" data-v="4" data-xref="歴代志上 4:18; 歴代志上 2:50; 歴代志上 4:39"> ゲドルの父はペヌエル、ホシャの父はエゼルである。これらはベツレヘムの父エフラタの長子ホルの子らである。</span>
<span className="v" id="v5" data-v="5" data-xref="歴代志上 2:24"> テコアの父アシュルにはふたりの妻ヘラとナアラとがあった。</span>
<span className="v" id="v6" data-v="6"> ナアラはアシュルによってアホザム、ヘペル、テメニおよびアハシタリを産んだ。これらはナアラの子である。</span>
<span className="v" id="v7" data-v="7"> ヘラの子らはゼレテ、エゾアル、エテナンである。</span>
<span className="v" id="v8" data-v="8"> コヅはアヌブとゾベバを生んだ。またハルムの子アハルヘルの氏族も彼から出た。</span>
<span className="v" id="v9" data-v="9" data-xref="サムエル記上 4:21; 歴代志上 7:23; 創世記 35:18"> ヤベヅはその兄弟のうちで最も尊ばれた者であった。その母が「わたしは苦しんでこの子を産んだから」と言ってその名をヤベヅと名づけたのである。</span>
<span className="v" id="v10" data-v="10" data-xref="マタイによる福音書 7:7–11; 詩篇 116:1–4; 箴言 10:22"> ヤベヅはイスラエルの神に呼ばわって言った、「どうか、あなたが豊かにわたしを恵み、わたしの国境を広げ、あなたの手がわたしとともにあって、わたしを災から免れさせ、苦しみをうけさせられないように」。神は彼の求めるところをゆるされた。</span>
<span className="v" id="v11" data-v="11"> シュワの兄弟ケルブはメヒルを生んだ。メヒルはエシトンの父、</span>
<span className="v" id="v12" data-v="12"> エシトンはベテラパ、パセアおよびイルナハシの父テヒンナを生んだ。これらはレカの人々である。</span>
<span className="v" id="v13" data-v="13" data-xref="ヨシュア記 15:17; 士師記 1:13; 士師記 3:9–11"> ケナズの子らはオテニエルとセラヤ。オテニエルの子らはハタテとメオノタイ。</span>
<span className="v" id="v14" data-v="14" data-xref="ネヘミヤ書 11:35; 列王紀下 24:14"> メオノタイはオフラを生み、セラヤはゲハラシムの父ヨアブを生んだ。彼らは工人であったのでゲハラシムと呼ばれたのである。</span>
<span className="v" id="v15" data-v="15" data-xref="民数記 13:6; 民数記 14:6–10; ヨシュア記 15:13–20"> エフンネの子カレブの子らはイル、エラおよびナアム。エラの子はケナズ。</span>
<span className="v" id="v16" data-v="16"> エハレレルの子らはジフ、ジバ、テリア、アサレルである。</span>
<span className="v" id="v17" data-v="17" data-xref="歴代志上 4:19; 歴代志上 6:57; ヨシュア記 15:50"> エズラの子らはエテル、メレデ、エペル、ヤロン。次のものはメレデがめとったパロの娘ビテヤの子らである。すなわち彼女はみごもってミリアム、シャンマイおよびイシバを産んだ。イシバはエシテモアの父である。</span>
<span className="v" id="v18" data-v="18" data-xref="歴代志上 2:42; 歴代志上 4:39; ヨシュア記 15:58"> 彼の妻はユダヤ人で、ゲドルの父エレデとソコの父ヘベルとザノアの父エクテエルを産んだ。</span>
<span className="v" id="v19" data-v="19" data-xref="ヨシュア記 15:44; サムエル記上 23:1–13"> ナハムの姉妹であるホデヤの妻の子らはガルムびとケイラの父およびマアカびとエシテモアである。</span>
<span className="v" id="v20" data-v="20"> シモンの子らはアムノン、リンナ、ベネハナン、テロンである。イシの子らはゾヘテとベネゾヘテである。</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 38:5; 歴代志上 2:3; 民数記 26:20"> ユダの子シラの子らはレカの父エル、マレシャの父ラダおよびベテアシベアの亜麻布織の家の一族、</span>
<span className="v" id="v22" data-v="22"> ならびにモアブを治めてレヘムに帰ったヨキム、コゼバの人々、ヨアシおよびサラフである。その記録は古い。</span>
<span className="v" id="v23" data-v="23" data-xref="詩篇 81:6; 歴代志上 4:14"> これらの者は陶器を造る人で、ネタイムおよびゲデラに住み、王の用をするため、王とともに、そこに住んだ。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="創世記 46:10; 出エジプト記 6:15; 民数記 26:12–14"> シメオンの子らはネムエル、ヤミン、ヤリブ、ゼラ、シャウル。</span>
<span className="v" id="v25" data-v="25"> シャウルの子はシャルム、その子はミブサム、その子はミシマ。</span>
<span className="v" id="v26" data-v="26"> ミシマの子孫は、その子はハムエル、その子はザックル、その子はシメイ。</span>
<span className="v" id="v27" data-v="27" data-xref="民数記 26:14; 民数記 26:22; 民数記 2:13"> シメイには男の子十六人、女の子六人あったが、その兄弟たちには多くの子はなかった。またその氏族の者はすべてユダの子孫ほどにはふえなかった。</span>
<span className="v" id="v28" data-v="28" data-xref="ヨシュア記 19:2–3; ヨシュア記 15:28–29; ヨシュア記 19:9"> 彼らの住んだ所はベエルシバ、モラダ、ハザル・シュアル、</span>
<span className="v" id="v29" data-v="29" data-xref="ヨシュア記 19:3–4"> ビルハ、エゼム、トラデ、</span>
<span className="v" id="v30" data-v="30" data-xref="ネヘミヤ書 11:28; ヨシュア記 19:4–5; サムエル記上 30:1"> ベトエル、ホルマ、チクラグ、</span>
<span className="v" id="v31" data-v="31" data-xref="ヨシュア記 19:5–6"> ベテ・マルカボテ、ハザル・スシム、ベテ・ビリ、およびシャライムである。これらはダビデの世に至るまで彼らの町であった。</span>
<span className="v" id="v32" data-v="32" data-xref="ヨシュア記 19:7"> その村里はエタム、アイン、リンモン、トケン、アシャンの五つの町である。</span>
<span className="v" id="v33" data-v="33" data-xref="ヨシュア記 19:8"> またこれらの町々の周囲に多くの村があって、バアルまでおよんだ。彼らのすみかは以上のとおりで、彼らはおのおの系図をもっていた。</span>
<span className="v" id="v34" data-v="34"> メショバブ、ヤムレク、アマジヤの子ヨシャ、</span>
<span className="v" id="v35" data-v="35"> ヨエル、アシエルのひこ、セラヤの孫、ヨシビアの子エヒウ。</span>
<span className="v" id="v36" data-v="36"> エリオエナイ、ヤコバ、エショハヤ、アサヤ、アデエル、エシミエル、ベナヤ、</span>
<span className="v" id="v37" data-v="37"> およびシピの子ジザ。シピはアロンの子、アロンはエダヤの子、エダヤはシムリの子、シムリはシマヤの子である。</span>
<span className="v" id="v38" data-v="38" data-xref="歴代志上 5:24; 創世記 6:4"> ここに名をあげた者どもはその氏族の長であって、それらの氏族は大いにふえ広がった。</span>
<span className="v" id="v39" data-v="39" data-xref="歴代志上 4:4; 歴代志上 4:18; ヨシュア記 15:58"> 彼らは群れのために牧場を求めてゲドルの入口に行き、谷の東の方まで進み、</span>
<span className="v" id="v40" data-v="40" data-xref="士師記 18:7–10; 詩篇 105:23; 詩篇 78:51"> ついに豊かな良い牧場を見いだした。その地は広く穏やかで、安らかであった。その地の前の住民はハムびとであったからである。</span>
<span className="v" id="v41" data-v="41" data-xref="イザヤ書 14:28–32; 列王紀下 18:8–12; 歴代志上 4:34–38"> これらの名をしるした者どもはユダの王ヒゼキヤの世に行って、彼らの天幕と、そこにいたメウニびとを撃ち破り、彼らをことごとく滅ぼして今日に至っている。そこには、群れのための牧場があったので、彼らはそこに住んだ。</span>
<span className="v" id="v42" data-v="42" data-xref="創世記 36:8–9; 申命記 1:2"> またシメオンびとのうちの五百人はイシの子らペラテヤ、ネアリヤ、レパヤ、ウジエルをかしらとしてセイル山に行き、</span>
<span className="v" id="v43" data-v="43" data-xref="サムエル記上 30:17; サムエル記上 15:7–8; サムエル記下 8:12"> アマレクびとで、のがれて残っていた者を撃ち滅ぼして、今日までそこに住んでいる。</span>
</div>

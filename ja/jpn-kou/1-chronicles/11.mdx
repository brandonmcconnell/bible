<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="サムエル記下 5:1–16; 歴代志上 12:23–40; 士師記 9:2"> ここにイスラエルの人は皆ヘブロンにいるダビデのもとに集まって来て言った、「われわれは、あなたの骨肉です。</span>
<span className="v" id="v2" data-v="2" data-xref="サムエル記下 5:2; ヨハネによる福音書 10:4; 詩篇 78:71"> 先にサウルが王であった時にも、あなたはイスラエルを率いて出入りされました。そしてあなたの神、主はあなたに『あなたはわが民イスラエルを牧する者となり、わが民イスラエルの君となるであろう』と言われました」。</span>
<span className="v" id="v3" data-v="3" data-xref="サムエル記上 16:12–13; サムエル記上 16:1; サムエル記下 5:3"> このようにイスラエルの長老が皆ヘブロンにいる王のもとに来たので、ダビデはヘブロンで主の前に彼らと契約を結んだ。そして彼らは、サムエルによって語られた主の言葉に従ってダビデに油を注ぎ、イスラエルの王とした。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="士師記 1:21; 創世記 15:21; ヨシュア記 15:8"> ダビデとすべてのイスラエルはエルサレムへ行った。エルサレムはすなわちエブスであって、そこにはその地の住民であるエブスびとがいた。</span>
<span className="v" id="v5" data-v="5" data-xref="歴代志下 5:2; 列王紀上 8:1; 詩篇 87:2"> エブスの住民はダビデに言った、「あなたはここにはいってはならない」。しかし、ダビデはシオンの要害を取った。これがすなわちダビデの町である。</span>
<span className="v" id="v6" data-v="6" data-xref="サムエル記下 8:16; サムエル記下 20:23; サムエル記下 3:27"> この時ダビデは言った、「だれでも第一にエブスびとを撃つ者を、かしらとし、将とする」。ゼルヤの子ヨアブが第一にのぼっていったので、かしらとなった。</span>
<span className="v" id="v7" data-v="7" data-xref="歴代志上 11:5; サムエル記下 5:7; 詩篇 2:6"> そしてダビデがその要害に住んだので人々はこれをダビデの町と名づけた。</span>
<span className="v" id="v8" data-v="8" data-xref="士師記 9:6; 列王紀上 11:27; 列王紀下 12:20"> ダビデはまたその町の周囲すなわちミロから四方に石がきを築き、ヨアブは町のほかの部分を繕った。</span>
<span className="v" id="v9" data-v="9" data-xref="サムエル記下 3:1; イザヤ書 41:10; 歴代志上 9:20"> こうしてダビデはますます大いなる者となった。万軍の主が彼とともにおられたからである。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="歴代志上 11:3; サムエル記上 16:1; 歴代志上 12:38"> ダビデの勇士のおもなものは次のとおりである。彼らはイスラエルのすべての人とともにダビデに力をそえて国を得させ、主がイスラエルについて言われた言葉にしたがって、彼を王とした人々である。</span>
<span className="v" id="v11" data-v="11" data-xref="サムエル記下 23:8; 歴代志上 27:2; 歴代志上 12:18"> ダビデの勇士の数は次のとおりである。すなわち三人の長であるハクモニびとの子ヤショベアム、彼はやりをふるって三百人に向かい、一度にこれを殺した者である。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="歴代志上 27:4; サムエル記下 23:17–19; サムエル記下 23:23"> 彼の次はアホアびとドドの子エレアザルで、三勇士のひとりである。</span>
<span className="v" id="v13" data-v="13" data-xref="サムエル記下 23:11–12; サムエル記上 17:1"> 彼はダビデとともにパスダミムにいたが、ペリシテびとがそこに集まって来て戦った。そこに一面に大麦のはえた地所があった。民はペリシテびとの前から逃げた。</span>
<span className="v" id="v14" data-v="14" data-xref="詩篇 144:10; 列王紀下 5:1; サムエル記上 14:23"> しかし彼は地所の中に立ってこれを防ぎ、ペリシテびとを殺した。そして主は大いなる勝利を与えて彼らを救われた。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="歴代志上 14:9; サムエル記下 5:18; イザヤ書 17:5"> 三十人の長たちのうちの三人は下っていってアドラムのほらあなの岩の所にいるダビデのもとへ行った。時にペリシテびとの軍勢はレパイムの谷に陣を取っていた。</span>
<span className="v" id="v16" data-v="16" data-xref="サムエル記上 10:5; サムエル記上 13:4; サムエル記上 13:23"> その時ダビデは要害におり、ペリシテびとの先陣はベツレヘムにあったが、</span>
<span className="v" id="v17" data-v="17" data-xref="ヨハネによる福音書 4:14; イザヤ書 12:3; サムエル記下 23:15–16"> ダビデはせつに望んで、「だれかベツレヘムの門のかたわらにある井戸の水をわたしに飲ませてくれるとよいのだが」と言った。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行伝 21:13; サムエル記上 19:5; 使徒行伝 20:24"> そこでその三人はペリシテびとの陣を突き通って、ベツレヘムの門のかたわらにある井戸の水をくみ取って、ダビデのもとに携えて来た。しかしダビデはそれを飲もうとはせず、それを主の前に注いで、</span>
<span className="v" id="v19" data-v="19" data-xref="サムエル記下 23:17; 詩篇 72:14; 士師記 9:17"> 言った、「わが神よ、わたしは断じてこれをいたしません。命をかけて行ったこの人たちの血をどうしてわたしは飲むことができましょう。彼らは命をかけてこの水をとって来たのです」。それゆえ、ダビデはこの水を飲もうとはしなかった。三勇士はこのことをおこなった。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="サムエル記上 26:6; 歴代志上 2:16; サムエル記下 20:6"> ヨアブの兄弟アビシャイは三十人の長であった。彼はやりをふるって三百人に立ち向かい、これを殺して三人のほかに名を得た。</span>
<span className="v" id="v21" data-v="21" data-xref="コリント人への第一の手紙 15:41; マタイによる福音書 13:8"> 彼は三十人のうち、最も尊ばれた者で、彼らのかしらとなった。しかし、かの三人には及ばなかった。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="サムエル記下 23:20–23; サムエル記下 8:18; ヨシュア記 15:21"> エホヤダの子ベナヤは、カブジエル出身の勇士であって、多くのてがらを立てた。彼はモアブのアリエルのふたりの子を撃ち殺した。彼はまた雪の日に下っていって、穴の中でししを撃ち殺した。</span>
<span className="v" id="v23" data-v="23" data-xref="サムエル記上 17:7; サムエル記上 17:4; 申命記 3:11"> 彼はまた身のたけ五キュビトばかりのエジプトびとを撃ち殺した。そのエジプトびとは手に機の巻棒ほどのやりを持っていたが、ベナヤはつえをとって彼の所へ下って行き、エジプトびとの手から、やりをもぎとり、そのやりをもって彼を殺した。</span>
<span className="v" id="v24" data-v="24"> エホヤダの子ベナヤは、これらの事を行って三勇士のほかに名を得た。</span>
<span className="v" id="v25" data-v="25" data-xref="サムエル記下 20:23"> 彼は三十人のうちに有名であったが、かの三人には及ばなかった。ダビデは彼を侍衛の長とした。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="歴代志上 27:7; サムエル記下 21:19; サムエル記下 2:18–23"> 軍団のうちの勇士はヨアブの兄弟アサヘル。ベツレヘム出身のドドの子エルハナン。</span>
<span className="v" id="v27" data-v="27" data-xref="サムエル記下 23:25–26"> ハロデ出身のシャンマ。ペロンびとヘレヅ。</span>
<span className="v" id="v28" data-v="28" data-xref="歴代志上 27:12; 歴代志上 27:9; サムエル記下 23:27"> テコア出身のイッケシの子イラ。アナトテ出身のアビエゼル。</span>
<span className="v" id="v29" data-v="29" data-xref="サムエル記下 23:27–28; 歴代志上 27:11"> ホシャテびとシベカイ。アホアびとイライ。</span>
<span className="v" id="v30" data-v="30" data-xref="歴代志上 27:13; 歴代志上 27:15; サムエル記下 23:29"> ネトパ出身のマハライ。ネトパ出身のバアナの子ヘレデ。</span>
<span className="v" id="v31" data-v="31" data-xref="サムエル記下 23:29"> ベニヤミンびとのギベアから出たリバイの子イタイ。ピラトンのベナヤ。</span>
<span className="v" id="v32" data-v="32" data-xref="サムエル記下 23:30–31"> ガアシの谷のホライ。アルバテびとアビエル。</span>
<span className="v" id="v33" data-v="33"> バハルム出身のアズマウテ。シャルボン出身のエリヤバ。</span>
<span className="v" id="v34" data-v="34" data-xref="サムエル記下 23:32–33"> ギゾンびとハセム。ハラルびとシャゲの子ヨナタン。</span>
<span className="v" id="v35" data-v="35" data-xref="サムエル記下 23:33–34"> ハラルびとサカルの子アヒアム。ウルの子エリパル。</span>
<span className="v" id="v36" data-v="36"> メケラテびとヘペル。ペロンびとアヒヤ。</span>
<span className="v" id="v37" data-v="37" data-xref="サムエル記下 23:35"> カルメル出身のヘズロ。エズバイの子ナアライ。</span>
<span className="v" id="v38" data-v="38" data-xref="サムエル記下 23:36"> ナタンの兄弟ヨエル。ハグリの子ミブハル。</span>
<span className="v" id="v39" data-v="39"> アンモンびとゼレク。ゼルヤの子ヨアブの武器を執るもの、ベエロテ出身のナハライ。</span>
<span className="v" id="v40" data-v="40" data-xref="サムエル記下 20:26"> イテルびとイラ。イテルびとガレブ。</span>
<span className="v" id="v41" data-v="41" data-xref="歴代志上 2:36; サムエル記下 23:39; サムエル記下 11:6–27"> ヘテびとウリヤ。アハライの子ザバデ。</span>
<span className="v" id="v42" data-v="42"> ルベンびとシザの子アデナ。彼はルベンびとの長であって、三十人を率いた。</span>
<span className="v" id="v43" data-v="43"> またマアカの子ハナン。ミテニびとヨシャパテ。</span>
<span className="v" id="v44" data-v="44"> アシテラテびとウジヤ。アロエルびとホタムの子らシャマとエイエル。</span>
<span className="v" id="v45" data-v="45"> テジびとシムリの子エデアエルおよびその兄弟ヨハ。</span>
<span className="v" id="v46" data-v="46"> マハブびとエリエル。エルナアムの子らエリバイおよびヨシャビヤ。モアブびとイテマ。</span>
<span className="v" id="v47" data-v="47"> エリエル、オベデおよびメゾバびとヤシエルである。</span>
</div>

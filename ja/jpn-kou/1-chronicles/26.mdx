<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歴代志下 23:19; 民数記 26:9–11; 詩篇 44:1"> 門を守る者の組は次のとおりである。すなわちコラびとのうちでは、アサフの子孫のうちのコレの子メシレミヤ。</span>
<span className="v" id="v2" data-v="2" data-xref="歴代志上 9:21"> メシレミヤの子たちは、長子はゼカリヤ、次はエデアエル、第三はゼバデヤ、第四はヤテニエル、</span>
<span className="v" id="v3" data-v="3"> 第五はエラム、第六はヨハナン、第七はエリヨエナイである。</span>
<span className="v" id="v4" data-v="4" data-xref="歴代志上 16:38; 歴代志上 15:24; 歴代志上 15:18"> オベデ・エドムの子たちは、長子はシマヤ、次はヨザバデ、第三はヨア、第四はサカル、第五はネタネル、</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 128:1"> 第六はアンミエル、第七はイッサカル、第八はピウレタイである。神が彼を祝福されたからである。</span>
<span className="v" id="v6" data-v="6" data-xref="歴代志上 12:28; テモテヘの第一の手紙 6:12; 士師記 6:12"> 彼の子シマヤにも数人の子が生れ、有能な人々であったので、その父の家を治める者となった。</span>
<span className="v" id="v7" data-v="7"> すなわちシマヤの子たちはオテニ、レパエル、オベデ、エルザバデで、エルザバデの兄弟エリウとセマキヤは力ある人々であった。</span>
<span className="v" id="v8" data-v="8" data-xref="コリント人への第二の手紙 3:6; ペテロの第一の手紙 4:11; コリント人への第一の手紙 12:4–11"> これらは皆オベデ・エドムの子孫である。彼らはその子たちおよびその兄弟たちと共にその勤めに適した力ある人々で、合わせて六十二人、みなオベデ・エドムに属する者である。</span>
<span className="v" id="v9" data-v="9" data-xref="歴代志上 26:14; 歴代志上 26:1"> メシレミヤにも子たちと兄弟たち合わせて十八人あって、皆力ある人々であった。</span>
<span className="v" id="v10" data-v="10" data-xref="歴代志上 16:38; 歴代志上 5:1–2"> メラリの子孫ホサにも子たちがあった。そのかしらはシムリ、これは長子ではなかったが、父はこれをかしらにしたのであった。</span>
<span className="v" id="v11" data-v="11"> 次はヒルキヤ、第三はテバリヤ、第四はゼカリヤである。ホサの子たちと兄弟たちは合わせて十三人である。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="歴代志上 25:8"> これらは門を守る者の組の長たる人々であって、その兄弟たちと同様に務をなして、主の宮に仕えた。</span>
<span className="v" id="v13" data-v="13" data-xref="歴代志上 25:8; 歴代志上 24:31; 歴代志上 24:5"> 彼らはそれぞれ門のために小なる者も、大なる者も等しく、その氏族にしたがってくじを引いた。</span>
<span className="v" id="v14" data-v="14"> 東の門のくじはシレミヤに当った。また彼の子で思慮深い議士ゼカリヤのためにくじを引いたが、北の門のくじがこれに当った。</span>
<span className="v" id="v15" data-v="15" data-xref="歴代志下 25:24; 歴代志上 26:17"> オベデ・エドムには南の門のくじ、その子たちには倉のくじ、</span>
<span className="v" id="v16" data-v="16" data-xref="ネヘミヤ書 12:24; 歴代志上 26:10–12; 列王紀上 10:5"> シュパムとホサには西の門のくじが当った。これは坂の大路にあるシャレケテの門のかたわらにあった。守る者と守る者とが相対していた。</span>
<span className="v" id="v17" data-v="17" data-xref="歴代志下 8:14; 歴代志上 9:24"> 東の方には毎日六人、北の方には毎日四人、南の方には毎日四人、倉には二人と二人、</span>
<span className="v" id="v18" data-v="18" data-xref="列王紀下 23:11"> 西の方パルバルには大路に四人、パルバルに二人。</span>
<span className="v" id="v19" data-v="19" data-xref="民数記 16:11"> 門を守る者の組は以上のとおりで、コラの子孫とメラリの子孫であった。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="歴代志上 26:22; 歴代志上 28:12–19; 歴代志上 22:14–16"> レビびとのうちアヒヤは神の宮の倉および聖なる物の倉をつかさどった。</span>
<span className="v" id="v21" data-v="21" data-xref="歴代志上 23:7; 歴代志上 6:17; 歴代志上 29:8"> ラダンの子孫すなわちラダンから出たゲルションびとの子孫で、ゲルションびとの氏族の長はエヒエリである。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="歴代志上 23:8; ネヘミヤ書 10:38; 歴代志上 26:20"> エヒエリ、ゼタムおよびその兄弟ヨエルの子たちは主の宮の倉をつかさどった。</span>
<span className="v" id="v23" data-v="23" data-xref="民数記 3:27; 歴代志上 23:12; 民数記 3:19"> アムラムびと、イヅハルびと、ヘブロンびと、ウジエルびとのうちでは次のとおりであった。</span>
<span className="v" id="v24" data-v="24" data-xref="歴代志上 24:20; 歴代志上 23:15–16"> すなわちモーセの子ゲルショムの子シブエルは倉のつかさであった。</span>
<span className="v" id="v25" data-v="25" data-xref="歴代志上 23:17–18; 歴代志上 23:15; 出エジプト記 18:4"> その兄弟でエリエゼルから出た者は、その子はレハビヤ、その子はエサヤ、その子はヨラム、その子はジクリ、その子はシロミテである。</span>
<span className="v" id="v26" data-v="26" data-xref="サムエル記下 8:11; 歴代志上 29:2–9; 歴代志上 22:14"> このシロミテとその兄弟たちはすべての聖なる物の倉をつかさどった。これはダビデ王と、氏族の長と、千人の長と、百人の長と、軍の長たちのささげたものである。</span>
<span className="v" id="v27" data-v="27" data-xref="列王紀下 12:14; ヨシュア記 6:19; ネヘミヤ書 10:32–34"> すなわち彼らが戦いで獲たぶんどり物のうちから主の宮の修繕のためにささげたものである。</span>
<span className="v" id="v28" data-v="28" data-xref="サムエル記上 9:9; サムエル記上 17:55; サムエル記下 10:9–14"> またすべて先見者サムエル、キシの子サウル、ネルの子アブネル、ゼルヤの子ヨアブなどがささげた物。すべてこれらのささげ物はシロミテとその兄弟たちが管理した。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="歴代志上 23:4; ネヘミヤ書 11:16; 歴代志下 34:13"> イヅハルびとのうちでは、ケナニヤとその子たちが、つかさおよびさばきびととしてイスラエルの外事のために選ばれた。</span>
<span className="v" id="v30" data-v="30" data-xref="歴代志上 27:17; 歴代志上 23:19; 歴代志上 23:12"> ヘブロンびとのうちでは、ハシャビヤおよびその兄弟など勇士千七百人があって、ヨルダンのこなた、すなわち西の方でイスラエルの監督となり、主のすべての事を行い、王に奉仕した。</span>
<span className="v" id="v31" data-v="31" data-xref="歴代志上 23:19; ヨシュア記 21:39; 歴代志上 29:27"> ヘブロンびとのうちでは、系図と氏族によってエリヤがヘブロンびとの長であったが、ダビデの治世の第四十年に彼らを尋ね求め、ギレアデのヤゼルで彼らのうちから大勇士を得た。</span>
<span className="v" id="v32" data-v="32" data-xref="歴代志下 19:11; 歴代志上 12:37; 歴代志上 23:24"> ダビデ王は彼とその兄弟など氏族の長たち二千七百人の勇士をルベンびと、ガドびと、マナセびとの半部族の監督となし、すべて神につける事と王の事とをつかさどらせた。</span>

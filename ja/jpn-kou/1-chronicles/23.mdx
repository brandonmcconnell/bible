<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歴代志上 29:28; 歴代志上 28:5; 列王紀上 1:33–39"> ダビデは老い、その日が満ちたので、その子ソロモンをイスラエルの王とした。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="ヨシュア記 24:1; 歴代志下 34:29–30; 歴代志上 13:1"> ダビデはイスラエルのすべてのつかさおよび祭司とレビびとを集めた。</span>
<span className="v" id="v3" data-v="3" data-xref="歴代志上 23:24; 民数記 4:2–49"> レビびとの三十歳以上のものを数えると、その男の数が三万八千人あった。</span>
<span className="v" id="v4" data-v="4" data-xref="歴代志下 19:8; 申命記 16:18; 歴代志上 26:29–31"> ダビデは言った、「そのうち二万四千人は主の家の仕事をつかさどり、六千人はつかさびと、およびさばきびととなり、</span>
<span className="v" id="v5" data-v="5" data-xref="歴代志下 29:25–26; 歴代志下 8:14; 詩篇 87:7"> 四千人は門を守る者となり、また四千人はさんびのためにわたしの造った楽器で主をたたえよ」。</span>
<span className="v" id="v6" data-v="6" data-xref="歴代志下 8:14; 歴代志上 6:1; 歴代志上 6:16"> そしてダビデは彼らをレビの子らにしたがってゲルション、コハテ、メラリの組に分けた。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="歴代志上 26:21; 出エジプト記 6:17; 歴代志上 6:17–20"> ゲルションの子らはラダンとシメイ。</span>
<span className="v" id="v8" data-v="8" data-xref="歴代志上 6:33–34; 歴代志上 15:20–21; 歴代志上 15:7"> ラダンの子らは、かしらのエヒエルとゼタムとヨエルの三人。</span>
<span className="v" id="v9" data-v="9"> シメイの子らはシロミテ、ハジエル、ハランの三人。これらはラダンの氏族の長であった。</span>
<span className="v" id="v10" data-v="10"> シメイの子らはヤハテ、ジナ、エウシ、ベリアの四人。皆シメイの子で、</span>
<span className="v" id="v11" data-v="11"> ヤハテはかしら、ジザはその次、エウシとベリアは子が多くなかったので、ともに数えられて一つの氏族となった。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="出エジプト記 6:18; 民数記 3:27; 民数記 26:58"> コハテの子らはアムラム、イヅハル、ヘブロン、ウジエルの四人。</span>
<span className="v" id="v13" data-v="13" data-xref="申命記 21:5; 出エジプト記 6:20; サムエル記上 2:28"> アムラムの子らはアロンとモーセである。アロンはその子らとともに、ながくいと聖なるものを聖別するために分かたれて、主の前に香をたき、主に仕え、常に主の名をもって祝福することをなした。</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 33:1; 詩篇 90:1; 歴代志上 26:23–25"> 神の人モーセの子らはレビの部族のうちに数えられた。</span>
<span className="v" id="v15" data-v="15" data-xref="出エジプト記 18:3–4; 出エジプト記 2:22; 出エジプト記 4:20"> モーセの子らはゲルションとエリエゼル。</span>
<span className="v" id="v16" data-v="16" data-xref="歴代志上 26:24; 歴代志上 25:20; 歴代志上 24:20"> ゲルションの子らは、かしらはシブエル。</span>
<span className="v" id="v17" data-v="17" data-xref="歴代志上 26:25"> エリエゼルの子らは、かしらはレハビヤ。エリエゼルにはこのほかに子がなかった。しかしレハビヤの子らは非常に多かった。</span>
<span className="v" id="v18" data-v="18" data-xref="歴代志上 26:26; 歴代志上 24:22"> イヅハルの子らは、かしらはシロミテ。</span>
<span className="v" id="v19" data-v="19" data-xref="歴代志上 24:23; 歴代志上 15:9; 歴代志上 23:12"> ヘブロンの子らは長子はエリヤ、次はアマリヤ、第三はヤハジエル、第四はエカメアム。</span>
<span className="v" id="v20" data-v="20"> ウジエルの子らは、かしらはミカ、次はイシアである。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="出エジプト記 6:19; 歴代志上 6:20; 歴代志上 24:26–30"> メラリの子らはマヘリとムシ。マヘリの子らはエレアザルとキシ。</span>
<span className="v" id="v22" data-v="22" data-xref="歴代志上 24:28; 民数記 36:6–8"> エレアザルは男の子がなくて死に、ただ娘たちだけであったが、キシの子であるその身内の男たちが彼女たちをめとった。</span>
<span className="v" id="v23" data-v="23" data-xref="歴代志上 24:30"> ムシの子らはマヘリ、エデル、エレモテの三人である。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="民数記 10:17; 民数記 10:21; 歴代志上 23:3"> これらはその氏族によるレビの子孫であって、その人数が数えられ、その名がしるされて、主の家の務をなした二十歳以上の者で、氏族の長であった。</span>
<span className="v" id="v25" data-v="25" data-xref="詩篇 132:13–14; 歴代志上 22:18; サムエル記下 7:11"> ダビデは言った、「イスラエルの神、主はその民に平安を与え、ながくエルサレムに住まわれる。</span>
<span className="v" id="v26" data-v="26" data-xref="民数記 4:5; 民数記 7:9; 民数記 4:15"> レビびとは重ねて幕屋およびその勤めの器物をかつぐことはない。</span>
<span className="v" id="v27" data-v="27" data-xref="歴代志上 23:24; 詩篇 72:20; サムエル記下 23:1"> ――ダビデの最後の言葉によって、レビびとは二十歳以上の者が数えられた――</span>
<span className="v" id="v28" data-v="28" data-xref="歴代志下 35:3–6; 歴代志下 31:11; 歴代志下 35:11–14"> 彼らの務はアロンの子孫を助けて主の家の働きをし、庭とへやの仕事およびすべての聖なるものを清めること、そのほか、すべて神の家の働きをすることである。</span>
<span className="v" id="v29" data-v="29" data-xref="レビ記 19:35–36; 出エジプト記 25:30; レビ記 6:20–23"> また供えのパン、素祭の麦粉、種入れぬ菓子、焼いた供え物、油をまぜた供え物をつかさどり、またすべて分量および大きさを量ることをつかさどり、</span>
<span className="v" id="v30" data-v="30" data-xref="詩篇 92:1–3; エズラ記 3:10–11; 歴代志上 9:33"> また朝ごとに立って主に感謝し、さんびし、夕にもまたそのようにし、</span>
<span className="v" id="v31" data-v="31" data-xref="イザヤ書 1:13–14; 民数記 28:1–29; 民数記 10:10"> また安息日と新月と祭日に、主にもろもろの燔祭をささげるときは、絶えず主の前にその命じられた数にしたがってささげなければならない。</span>
<span className="v" id="v32" data-v="32" data-xref="民数記 1:53; 民数記 3:38; 民数記 3:6–9"> このようにして彼らは会見の幕屋と聖所の務を守り、主の家の働きのためにその兄弟であるアロンの子らに仕えなければならない」。</span>
</div>
</div>

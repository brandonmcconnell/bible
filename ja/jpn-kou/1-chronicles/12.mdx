<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="サムエル記上 27:2–6; 歴代志上 11:24–25; 歴代志上 8:33"> ダビデがキシの子サウルにしりぞけられて、なおチクラグにいた時、次の人々が彼のもとに来た。彼らはダビデを助けて戦った勇士たちのうちにあり、</span>
<span className="v" id="v2" data-v="2" data-xref="士師記 3:15; 士師記 20:16; サムエル記上 17:49"> 弓をよくする者、左右いずれの手をもってもよく矢を射、石を投げる者で、ともにベニヤミンびとで、サウルの同族である。</span>
<span className="v" id="v3" data-v="3" data-xref="歴代志上 11:28; サムエル記下 21:6; 歴代志上 11:33"> そのかしらはアヒエゼル、次はヨアシで、ともにギベア出身のシマアの子たちである。またエジエルとペレテで、ともにアズマウテの子たちである。またベラカおよびアナトテ出身のエヒウ。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨシュア記 9:3; ヨシュア記 15:36; 歴代志上 11:15"> またギベオン出身のイシマヤ、彼は三十人のうちの勇士で、その三十人の長である。またエレミヤ、ヤハジエル、ヨハナン、ゲデラ出身のヨザバデ、</span>
<span className="v" id="v5" data-v="5"> エルザイ、エリモテ、ベアリヤ、シマリヤ、ハリフびとシパテヤ、</span>
<span className="v" id="v6" data-v="6"> エルカナ、イシア、アザリエル、ヨエゼル、ヤショベアムで、これらはコラびとである。</span>
<span className="v" id="v7" data-v="7" data-xref="ヨシュア記 15:58; 歴代志上 4:18; 歴代志上 4:39"> またゲドルのエロハムの子たちであるヨエラおよびゼバデヤである。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="サムエル記下 2:18; サムエル記下 17:10; サムエル記下 23:20"> ガドびとのうちから荒野の要害に来て、ダビデについた者は皆勇士で、よく戦う軍人、よく盾とやりをつかう者、その顔はししの顔のようで、その速いことは山にいるしかのようであった。</span>
<span className="v" id="v9" data-v="9"> 彼らのかしらはエゼル、次はオバデヤ、第三はエリアブ、</span>
<span className="v" id="v10" data-v="10"> 第四はミシマンナ、第五はエレミヤ、</span>
<span className="v" id="v11" data-v="11"> 第六はアッタイ、第七はエリエル、</span>
<span className="v" id="v12" data-v="12"> 第八はヨナハン、第九はエルザバデ、</span>
<span className="v" id="v13" data-v="13"> 第十はエレミヤ、第十一はマクバナイである。</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 32:30; レビ記 26:8"> これらはガドの子孫で軍勢の長たる者、その最も小さい者でも百人に当り、その最も大いなる者は千人に当った。</span>
<span className="v" id="v15" data-v="15" data-xref="ヨシュア記 3:15; ヨシュア記 4:18; エレミヤ書 49:19"> 正月、ヨルダンがその全岸にあふれたとき、彼らはこれを渡って、谷々にいる者をことごとく東に西に逃げ走らせた。</span>
</div>
<div className="bp poetry">
<span className="v" id="v16" data-v="16"> ベニヤミンとユダの子孫のうちの人々が要害に来て、ダビデについた。</span>
<span className="v" id="v17" data-v="17" data-xref="ペテロの第一の手紙 2:23; ユダの手紙 1:9; コリント人への第二の手紙 13:11"> ダビデは出て彼らを迎えて言った、「あなたがたが好意をもって、わたしを助けるために来たのならば、わたしの心もあなたがたと、ひとつになりましょう。しかし、わたしの手になんの悪事もないのに、もしあなたがたが、わたしを欺いて、敵に渡すためであるならば、われわれの先祖の神がどうぞみそなわして、あなたがたを責められますように」。</span>
<span className="v" id="v18" data-v="18" data-xref="士師記 6:34; 士師記 3:10; サムエル記下 17:25"> 時に霊が三十人の長アマサイに臨み、アマサイは言った、<br /><span className="pl pl-1">「ダビデよ、われわれはあなたのもの。</span><br /><span className="pl pl-1">エッサイの子よ、われわれはあなたと共にある。</span><br /><span className="pl pl-1">平安あれ、あなたに平安あれ。</span><br /><span className="pl pl-1">あなたを助ける者に平安あれ。</span><br /><span className="pl pl-1">あなたの神があなたを助けられる」。</span><br />そこでダビデは彼らを受けいれて部隊の長とした。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="サムエル記上 29:2–9"> さきにダビデがペリシテびとと共にサウルと戦おうと攻めて来たとき、マナセびと数人がダビデについた。（ただしダビデはついにペリシテびとを助けなかった。それはペリシテびとの君たちが相はかって、「彼はわれわれの首をとって、その主君サウルのもとに帰るであろう」と言って、彼を去らせたからである。）</span>
<span className="v" id="v20" data-v="20" data-xref="申命記 33:17; 申命記 1:15; サムエル記上 29:11"> ダビデがチクラグへ行ったとき、マナセびとアデナ、ヨザバデ、エデアエル、ミカエル、ヨザバデ、エリウ、ヂルタイが彼についた。皆マナセびとの千人の長であった。</span>
<span className="v" id="v21" data-v="21" data-xref="サムエル記上 30:1–17; 歴代志上 12:20; 歴代志上 5:24"> 彼らはダビデを助けて敵軍に当った。彼らは皆大勇士で軍勢の長であった。</span>
<span className="v" id="v22" data-v="22" data-xref="サムエル記下 3:1; ヨブ記 17:9; 創世記 32:2"> ダビデを助ける者が日に日に加わって、ついに大軍となり、神の軍勢のようになった。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="サムエル記下 2:3–4; 歴代志上 11:10; サムエル記上 16:1"> 主の言葉に従い、サウルの国をダビデに与えようとして、ヘブロンにいるダビデのもとに来た武装した軍隊の数は、次のとおりである。</span>
<span className="v" id="v24" data-v="24"> ユダの子孫で盾とやりをとり、武装した者六千八百人、</span>
<span className="v" id="v25" data-v="25"> シメオンの子孫で、よく戦う勇士七千百人、</span>
<span className="v" id="v26" data-v="26"> レビの子孫からは四千六百人。</span>
<span className="v" id="v27" data-v="27" data-xref="列王紀下 11:9; 列王紀下 25:18; 歴代志上 6:49–57"> エホヤダはアロンの家のつかさで、彼に属する者は三千七百人。</span>
<span className="v" id="v28" data-v="28" data-xref="サムエル記下 8:17; 歴代志上 6:8; 歴代志上 6:53"> ザドクは年若い勇士で、彼の氏族から出た将軍は二十二人。</span>
<span className="v" id="v29" data-v="29" data-xref="サムエル記下 2:8–9; 歴代志上 12:2; 創世記 31:23"> サウルの同族、ベニヤミンの子孫からは三千人、ベニヤミンびとの多くはなおサウルの家に忠義をつくしていた。</span>
<span className="v" id="v30" data-v="30" data-xref="創世記 6:4"> エフライムの子孫からは二万八百人、皆勇士で、その氏族の名ある人々であった。</span>
<span className="v" id="v31" data-v="31" data-xref="ヨシュア記 17:1–18"> マナセの半部族からは一万八千人、皆ダビデを王に立てようとして上って来て、名をつらねた者である。</span>
<span className="v" id="v32" data-v="32" data-xref="エペソ人への手紙 5:17; ルカによる福音書 12:56–57; エステル記 1:13"> イッサカルの子孫からはよく時勢に通じ、イスラエルのなすべきことをわきまえた人々が来た。その長たる者が二百人あって、その兄弟たちは皆その指揮に従った。</span>
<span className="v" id="v33" data-v="33" data-xref="詩篇 12:2; ヨハネによる福音書 1:47"> ゼブルンからは五万人、皆訓練を経た軍隊で、もろもろの武具で身をよろい、一心にダビデを助けた者である。</span>
<span className="v" id="v34" data-v="34"> ナフタリからは将たる者一千人および盾とやりをとってこれに従う者三万七千人。</span>
<span className="v" id="v35" data-v="35"> ダンびとからは武装した者二万八千六百人。</span>
<span className="v" id="v36" data-v="36" data-xref="歴代志上 12:33; ヨエル書 2:7"> アセルからは戦いの備えをした熟練の者四万人。</span>
<span className="v" id="v37" data-v="37" data-xref="ヨシュア記 14:3; 申命記 3:12–16; ヨシュア記 13:7–32"> またヨルダンのかなたルベンびと、ガドびと、マナセの半部族からはもろもろの武具で身をよろった者十二万人であった。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="創世記 49:8–10; 列王紀上 8:61; 詩篇 101:2"> すべてこれらの戦いの備えをしたいくさびとらは真心をもってヘブロンに来て、ダビデを全イスラエルの王にしようとした。このほかのイスラエルびともまた、心をひとつにしてダビデを王にしようとした。</span>
<span className="v" id="v39" data-v="39" data-xref="創世記 31:54; サムエル記下 19:42; 創世記 26:30"> 彼らはヘブロンにダビデとともに三日いて、食い飲みした。その兄弟たちは彼らのために備えをしたからである。</span>
<span className="v" id="v40" data-v="40" data-xref="サムエル記上 25:18; サムエル記下 16:1; エレミヤ書 23:5–6"> また彼らに近い人々はイッサカル、ゼブルン、ナフタリなどの遠い所の者まで、ろば、らくだ、騾馬、牛などに食物を負わせて来た。すなわち麦粉の食物、干いちじく、干ぶどう、ぶどう酒、油、牛、羊などを多く携えて来た。これはイスラエルに喜びがあったからである。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="サムエル記下 24:1–25; ゼカリヤ書 3:1; ヨブ記 2:4–6"> 時にサタンが起ってイスラエルに敵し、ダビデを動かしてイスラエルを数えさせようとした。</span>
<span className="v" id="v2" data-v="2" data-xref="歴代志上 27:23–24; サムエル記下 3:10; サムエル記下 24:15"> ダビデはヨアブと軍の将校たちに言った、「あなたがたは行って、ベエルシバからダンまでのイスラエルを数え、その数を調べてわたしに知らせなさい」。</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 1:11; イザヤ書 26:15; 歴代志上 19:13"> ヨアブは言った、「それがどのくらいあっても、どうか主がその民を百倍に増されるように。しかし王わが主よ、彼らは皆あなたのしもべではありませんか。どうしてわが主はこの事を求められるのですか。どうしてイスラエルに罪を得させられるのですか」。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行伝 5:29; 出エジプト記 1:17; ダニエル書 3:18"> しかし王の言葉がヨアブに勝ったので、ヨアブは出て行って、イスラエルをあまねく行き巡り、エルサレムに帰って来た。</span>
<span className="v" id="v5" data-v="5" data-xref="サムエル記下 24:9; 歴代志上 27:23"> そしてヨアブは民の総数をダビデに告げた。すなわちイスラエルにはつるぎを抜く者が百十万人、ユダにはつるぎを抜く者が四十七万人あった。</span>
<span className="v" id="v6" data-v="6" data-xref="歴代志上 27:24; 民数記 1:47–49; サムエル記下 20:9–10"> しかしヨアブは王の命令を快しとしなかったので、レビとベニヤミンとはその中に数えなかった。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="列王紀上 15:5; ヨシュア記 7:5; サムエル記下 21:14"> この事が神の目に悪かったので、神はイスラエルを撃たれた。</span>
<span className="v" id="v8" data-v="8" data-xref="サムエル記下 12:13; ヨハネの第一の手紙 1:9; 創世記 34:7"> そこでダビデは神に言った、「わたしはこの事を行って大いに罪を犯しました。しかし今どうか、しもべの罪を除いてください。わたしは非常に愚かなことをいたしました」。</span>
<span className="v" id="v9" data-v="9" data-xref="サムエル記上 9:9; サムエル記下 24:11; 歴代志上 29:29"> 主はダビデの先見者ガデに告げて言われた、</span>
<span className="v" id="v10" data-v="10" data-xref="列王紀上 13:21–22; ヨハネの黙示録 3:19; 箴言 1:29–31"> 「行ってダビデに言いなさい、『主はこう仰せられる、わたしは三つの事を示す。あなたはその一つを選びなさい。わたしはそれをあなたに行おう』と」。</span>
<span className="v" id="v11" data-v="11" data-xref="箴言 19:20"> ガデはダビデのもとに来て言った、「主はこう仰せられます、『あなたは選びなさい。</span>
<span className="v" id="v12" data-v="12" data-xref="申命記 28:27; 使徒行伝 12:23; エゼキエル書 14:19–21"> すなわち三年のききんか、あるいは三月の間、あなたのあだの前に敗れて、敵のつるぎに追いつかれるか、あるいは三日の間、主のつるぎすなわち疫病がこの国にあって、主の使がイスラエルの全領域にわたって滅ぼすことをするか』。いま、わたしがどういう答をわたしをつかわしたものになすべきか決めなさい」。</span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 130:7; イザヤ書 55:7; ピリピ人への手紙 1:23"> ダビデはガデに言った、「わたしは非常に悩んでいるが、主のあわれみは大きいゆえ、わたしを主の手に陥らせてください。しかしわたしを人の手に陥らせないでください」。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="出エジプト記 12:30; 歴代志上 27:24; 列王紀下 19:35"> そこで主はイスラエルに疫病を下されたので、イスラエルびとのうち七万人が倒れた。</span>
<span className="v" id="v15" data-v="15" data-xref="創世記 6:6; 出エジプト記 32:14; エレミヤ書 26:18"> 神はまたみ使をエルサレムにつかわして、これを滅ぼそうとされたが、み使がまさに滅ぼそうとしたとき、主は見られて、この災を悔い、その滅ぼすみ使に言われた、「もうじゅうぶんだ。今あなたの手をとどめよ」。そのとき主の使はエブスびとオルナンの打ち場のかたわらに立っていた。</span>
<span className="v" id="v16" data-v="16" data-xref="民数記 14:5; 列王紀上 21:27; 列王紀下 6:17"> ダビデが目をあげて見ると、主の使が地と天の間に立って、手に抜いたつるぎをもち、エルサレムの上にさし伸べていたので、ダビデと長老たちは荒布を着て、ひれ伏した。</span>
<span className="v" id="v17" data-v="17" data-xref="エゼキエル書 16:63; サムエル記下 24:17; ヨハネによる福音書 10:11–12"> そしてダビデは神に言った、「民を数えよと命じたのはわたしではありませんか。罪を犯し、悪い事をしたのはわたしです。しかしこれらの羊は何をしましたか。わが神、主よ、どうぞあなたの手をわたしと、わたしの父の家にむけてください。しかし災をあなたの民に下さないでください」。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="歴代志下 3:1; サムエル記下 24:18; 歴代志上 21:11"> 時に主の使はガデに命じ、ダビデが上って行って、エブスびとオルナンの打ち場で主のために一つの祭壇を築くように告げさせた。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行伝 9:6; ヨハネによる福音書 2:5; 列王紀下 5:10–14"> そこでダビデはガデが主の名をもって告げた言葉に従って上って行った。</span>
<span className="v" id="v20" data-v="20" data-xref="士師記 6:11"> そのときオルナンは麦を打っていたが、ふりかえってみ使を見たので、ともにいた彼の四人の子は身をかくした。</span>
<span className="v" id="v21" data-v="21" data-xref="サムエル記上 25:23; サムエル記下 24:18–20"> ダビデがオルナンに近づくと、オルナンは目を上げてダビデを見、打ち場から出て来て地にひれ伏してダビデを拝した。</span>
<span className="v" id="v22" data-v="22" data-xref="サムエル記下 24:21; 列王紀上 21:2; 民数記 25:8"> ダビデはオルナンに言った、「この打ち場の所をわたしに与えなさい。わたしは災が民に下るのをとどめるため、そこに主のために一つの祭壇を築きます。あなたは、そのじゅうぶんな価をとってこれをわたしに与えなさい」。</span>
<span className="v" id="v23" data-v="23" data-xref="サムエル記下 24:22–23; サムエル記上 6:14; 創世記 23:4–6"> オルナンはダビデに言った、「どうぞこれをお取りなさい。そして王わが主の良しと見られるところを行いなさい。わたしは牛を燔祭のために、打穀機をたきぎのために、麦を素祭のためにささげます。わたしは皆これをささげます」。</span>
<span className="v" id="v24" data-v="24" data-xref="申命記 16:16–17; 創世記 14:23; 創世記 23:13"> ダビデ王はオルナンに言った、「いいえ、わたしはじゅうぶんな代価を払ってこれを買います。わたしは主のためにあなたのものを取ることをしません。また、費えなしに燔祭をささげることをいたしません」。</span>
<span className="v" id="v25" data-v="25" data-xref="サムエル記下 24:24–25"> それでダビデはその所のために金六百シケルをはかって、オルナンに払った。</span>
<span className="v" id="v26" data-v="26" data-xref="レビ記 9:24; 士師記 6:21; 箴言 15:8"> こうしてダビデは主のために、その所に一つの祭壇を築き、燔祭と酬恩祭をささげて、主を呼んだ。主は燔祭の祭壇の上に天から火を下して答えられた。</span>
<span className="v" id="v27" data-v="27" data-xref="ヨハネによる福音書 18:11; 詩篇 103:20; 歴代志上 21:15–16"> また主がみ使に命じられたので、彼はつるぎをさやにおさめた。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28"> その時ダビデは主がエブスびとオルナンの打ち場で自分に答えられたのを見たので、その所で犠牲をささげた。</span>
<span className="v" id="v29" data-v="29" data-xref="歴代志上 16:39; 歴代志下 1:3; 歴代志下 1:13"> モーセが荒野で造った主の幕屋と燔祭の祭壇とは、その時ギベオンの高き所にあったからである。</span>
<span className="v" id="v30" data-v="30" data-xref="ヨハネの黙示録 1:17; ヘブル人への手紙 12:28–29; ヨハネの黙示録 15:4"> しかしダビデはその前へ行って神に求めることができなかった。彼が主の使のつるぎを恐れたからである。</span>
</div>

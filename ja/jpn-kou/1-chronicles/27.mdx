<span className="v" id="v1" data-v="1" data-xref="列王紀上 4:27; 歴代志下 26:11–13; 申命記 1:15"> イスラエルの子孫のうちで氏族の長、千人の長、百人の長、およびつかさたちは年のすべての月の間、月ごとに交替して組のすべての事をなして王に仕えたが、その数にしたがえば各組二万四千人あった。</span>
<span className="v" id="v2" data-v="2" data-xref="歴代志上 11:11; サムエル記下 23:8"> まず第一の組すなわち正月の分はザブデエルの子ヤショベアムがこれを率いた。その組には二万四千人あった。</span>
<span className="v" id="v3" data-v="3" data-xref="民数記 26:20; 民数記 10:14; 創世記 49:8–10"> 彼はペレヅの子孫で、正月の軍団のすべての将たちのかしらであった。</span>
<span className="v" id="v4" data-v="4" data-xref="サムエル記下 23:9; 歴代志上 11:12"> 二月の組はアホアびとドダイがこれを率いた。その組には二万四千人あった。</span>
<span className="v" id="v5" data-v="5" data-xref="歴代志上 18:17; 列王紀上 4:4–5"> 三月の第三の将は祭司エホヤダの子ベナヤが長であって、その組には二万四千人あった。</span>
<span className="v" id="v6" data-v="6" data-xref="サムエル記下 23:20–23; 歴代志上 11:22–25; サムエル記下 22:20–23"> このベナヤはかの三十人のうちの勇士であって三十人を率い、その子アミザバデがその組にあった。</span>
<span className="v" id="v7" data-v="7" data-xref="歴代志上 11:26; サムエル記下 23:24; サムエル記下 2:18–23"> 四月の第四の将はヨアブの兄弟アサヘルであって、その子ゼバデヤがこれに次いだ。その組には二万四千人あった。</span>
<span className="v" id="v8" data-v="8" data-xref="歴代志上 11:27; サムエル記下 23:25; 歴代志上 26:29"> 五月の第五の将はイズラヒびとシャンモテであって、その組には二万四千人あった。</span>
<span className="v" id="v9" data-v="9" data-xref="歴代志上 11:28; サムエル記下 23:26"> 六月の第六の将はテコアびとイッケシの子イラであって、その組には二万四千人あった。</span>
<span className="v" id="v10" data-v="10" data-xref="歴代志上 11:27; サムエル記下 23:26"> 七月の第七の将はエフライムの子孫であるペロンびとヘレヅであって、その組には二万四千人あった。</span>
<span className="v" id="v11" data-v="11" data-xref="サムエル記下 21:18; 歴代志上 11:29; 民数記 26:20"> 八月の第八の将はゼラびとの子孫であるホシャびとシベカイであって、その組には二万四千人あった。</span>
<span className="v" id="v12" data-v="12" data-xref="歴代志上 11:28; サムエル記下 23:27"> 九月の第九の将はベニヤミンの子孫であるアナトテびとアビエゼルであって、その組には二万四千人あった。</span>
<span className="v" id="v13" data-v="13" data-xref="歴代志上 11:30; サムエル記下 23:28"> 十月の第十の将はゼラびとの子孫であるネトパびとマハライであって、その組には二万四千人あった。</span>
<span className="v" id="v14" data-v="14" data-xref="歴代志上 11:31; サムエル記下 23:30"> 十一月の第十一の将はエフライムの子孫であるピラトンびとベナヤであって、その組には二万四千人あった。</span>
<span className="v" id="v15" data-v="15" data-xref="サムエル記下 23:29; 歴代志上 4:13; 士師記 3:9"> 十二月の第十二の将はオテニエルの子孫であるネトパびとヘルダイであって、その組には二万四千人あった。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16"> なおイスラエルの部族を治める者たちは次のとおりである。ルベンびとのつかさはヂクリの子エリエゼル。シメオンびとのつかさはマアカの子シパテヤ。</span>
<span className="v" id="v17" data-v="17" data-xref="歴代志上 26:30; 歴代志上 24:31; 歴代志上 12:27–28"> レビびとのつかさはケムエルの子ハシャビヤ。アロンびとのつかさはザドク。</span>
<span className="v" id="v18" data-v="18" data-xref="サムエル記上 16:6; サムエル記上 17:29; サムエル記上 17:13"> ユダのつかさはダビデの兄弟のひとりエリウ。イッサカルのつかさはミカエルの子オムリ。</span>
<span className="v" id="v19" data-v="19"> ゼブルンのつかさはオバデヤの子イシマヤ。ナフタリのつかさはアズリエルの子エレモテ。</span>
<span className="v" id="v20" data-v="20"> エフライムの子孫のつかさはアザジヤの子ホセア。マナセの半部族のつかさはペダヤの子ヨエル。</span>
<span className="v" id="v21" data-v="21" data-xref="サムエル記下 3:27; サムエル記上 14:50–51; サムエル記下 3:37"> ギレアデにあるマナセの半部族のつかさはゼカリヤの子イド。ベニヤミンのつかさはアブネルの子ヤシエル。</span>
<span className="v" id="v22" data-v="22" data-xref="歴代志上 28:1"> ダンのつかさはエロハムの子アザリエル。これらはイスラエルの部族のつかさたちであった。</span>
<span className="v" id="v23" data-v="23" data-xref="創世記 15:5; 歴代志上 21:2–5; ヘブル人への手紙 11:12"> しかしダビデは二十歳以下の者は数えなかった。主がかつてイスラエルを天の星のように多くすると言われたからである。</span>
<span className="v" id="v24" data-v="24" data-xref="歴代志上 21:1–17; サムエル記下 24:1–15"> ゼルヤの子ヨアブは数え始めたが、これをなし終えなかった。その数えることによって怒りがイスラエルの上に臨んだ。またその数はダビデ王の歴代志に載せなかった。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="歴代志下 16:2; 出エジプト記 1:11; 歴代志下 26:10"> アデエルの子アズマウテは王の倉をつかさどり、ウジヤの子ヨナタンは田野、町々、村々、もろもろの塔にある倉をつかさどり、</span>
<span className="v" id="v26" data-v="26"> ケルブの子エズリは地を耕す農夫をつかさどり、</span>
<span className="v" id="v27" data-v="27"> ラマテびとシメイはぶどう畑をつかさどり、シプミびとザブデはぶどう畑から取ったぶどう酒の倉をつかさどり、</span>
<span className="v" id="v28" data-v="28" data-xref="列王紀上 10:27; 歴代志下 1:15; 列王紀上 4:7"> ゲデルびとバアル・ハナンは平野のオリブの木といちじく桑の木をつかさどり、ヨアシは油の倉をつかさどり、</span>
<span className="v" id="v29" data-v="29" data-xref="歴代志上 5:16; イザヤ書 65:10"> シャロンびとシテライはシャロンで飼う牛の群れをつかさどり、アデライの子シャパテはもろもろの谷におる牛の群れをつかさどり、</span>
<span className="v" id="v30" data-v="30" data-xref="創世記 47:6; ヨブ記 1:3"> イシマエルびとオビルはらくだをつかさどり、メロノテびとエデヤはろばをつかさどり、</span>
<span className="v" id="v31" data-v="31" data-xref="歴代志上 5:10"> ハガルびとヤジズは羊の群れをつかさどった。彼らは皆ダビデ王の財産のつかさであった。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="サムエル記下 21:21; サムエル記下 13:3; 歴代志上 11:11"> またダビデのおじヨナタンは議官で、知恵ある人であり、学者であった。また彼とハクモニの子エヒエルは王の子たちの補佐であった。</span>
<span className="v" id="v33" data-v="33" data-xref="サムエル記下 15:12; サムエル記下 15:37; サムエル記下 15:32"> アヒトペルは王の議官。アルキびとホシャイは王の友であった。</span>
<span className="v" id="v34" data-v="34" data-xref="歴代志上 11:6; 列王紀上 1:7; 歴代志上 27:5"> アヒトペルに次ぐ者はベナヤの子エホヤダおよびアビヤタル。王の軍の長はヨアブであった。</span>
</div>

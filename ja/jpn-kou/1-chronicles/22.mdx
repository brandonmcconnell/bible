<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歴代志下 3:1; 歴代志上 21:18–28; 創世記 28:17"> それでダビデは言った、「主なる神の家はこれである、イスラエルのための燔祭の祭壇はこれである」と。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="歴代志下 2:17; 列王紀上 9:20–21; 列王紀上 5:17–18"> ダビデは命じてイスラエルの地にいる他国人を集めさせ、また神の家を建てるのに用いる石を切るために石工を定めた。</span>
<span className="v" id="v3" data-v="3" data-xref="歴代志上 22:14; 歴代志上 29:2; 列王紀上 7:47"> ダビデはまた門のとびらのくぎ、およびかすがいに用いる鉄をおびただしく備えた。また青銅を量ることもできないほどおびただしく備えた。</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀上 5:6–10; エズラ記 3:7; 歴代志下 2:3"> また香柏を数えきれぬほど備えた。これはシドンびととツロの人々がおびただしく香柏をダビデの所に持って来たからである。</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀上 3:7; 歴代志上 29:1; ヨハネによる福音書 3:30"> ダビデは言った、「わが子ソロモンは若く、かつ経験がない。また主のために建てる家はきわめて壮大で、万国に名を得、栄えを得るものでなければならない。それゆえ、わたしはその準備をしておこう」と。こうしてダビデは死ぬ前に多くの物資を準備した。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="民数記 27:23; 使徒行伝 20:25–31; 使徒行伝 1:2"> そして彼はその子ソロモンを召して、イスラエルの神、主のために家を建てることを命じた。</span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 132:5; 列王紀上 8:16–20; 歴代志下 6:7–9"> すなわちダビデはソロモンに言った、「わが子よ、わたしはわが神、主の名のために家を建てようと志していた。</span>
<span className="v" id="v8" data-v="8" data-xref="列王紀上 5:3; 歴代志上 28:3; 歴代志上 17:4–10"> ところが主の言葉がわたしに臨んで言われた、『おまえは多くの血を流し、大いなる戦争をした。おまえはわたしの前で多くの血を地に流したから、わが名のために家を建ててはならない。</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀上 4:25; 列王紀上 5:4; 列王紀上 4:20"> 見よ、男の子がおまえに生れる。彼は平和の人である。わたしは彼に平安を与えて、周囲のもろもろの敵に煩わされないようにしよう。彼の名はソロモンと呼ばれ、彼の世にわたしはイスラエルに平安と静穏とを与える。</span>
<span className="v" id="v10" data-v="10" data-xref="ヘブル人への手紙 1:5; サムエル記下 7:13–14; 歴代志上 17:12–14"> 彼はわが名のために家を建てるであろう。彼はわが子となり、わたしは彼の父となる。わたしは彼の王位をながくイスラエルの上に堅くするであろう』。</span>
<span className="v" id="v11" data-v="11" data-xref="歴代志上 22:16; 歴代志上 28:20; テモテヘの第二の手紙 4:22"> それでわが子よ、どうか主があなたと共にいまし、あなたを栄えさせて、主があなたについて言われたように、あなたの神、主の家を建てさせてくださるように。</span>
<span className="v" id="v12" data-v="12" data-xref="ヤコブの手紙 1:5; 箴言 14:8; 列王紀上 3:9–12"> ただ、どうか主があなたに分別と知恵を賜い、あなたをイスラエルの上に立たせられるとき、あなたの神、主の律法を、あなたに守らせてくださるように。</span>
<span className="v" id="v13" data-v="13" data-xref="ヨシュア記 1:6–9; 歴代志上 28:20; 歴代志上 28:7"> あなたがもし、主がイスラエルについてモーセに命じられた定めとおきてとを慎んで守るならば、あなたは栄えるであろう。心を強くし、勇め。恐れてはならない、おののいてはならない。</span>
<span className="v" id="v14" data-v="14" data-xref="歴代志上 22:3; 列王紀下 25:16; 歴代志上 29:4–7"> 見よ、わたしは苦難のうちにあって主の家のために金十万タラント、銀百万タラントを備え、また青銅と鉄を量ることもできないほどおびただしく備えた。また材木と石をも備えた。あなたはまたこれに加えなければならない。</span>
<span className="v" id="v15" data-v="15" data-xref="出エジプト記 28:6; 出エジプト記 35:32; 列王紀上 7:14"> あなたにはまた多数の職人、すなわち石や木を切り刻む者、工作に巧みな各種の者がある。</span>
<span className="v" id="v16" data-v="16" data-xref="歴代志上 22:11; ピリピ人への手紙 4:13; エペソ人への手紙 5:14"> 金、銀、青銅、鉄もおびただしくある。たって行いなさい。どうか主があなたと共におられるように」。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="歴代志上 28:1–6; ヨハネの第三の手紙 1:8; 歴代志上 29:6"> ダビデはまたイスラエルのすべてのつかさたちにその子ソロモンを助けるように命じて言った、</span>
<span className="v" id="v18" data-v="18" data-xref="歴代志上 22:9; 歴代志上 23:25; サムエル記下 7:1"> 「あなたがたの神、主はあなたがたとともにおられるではないか。四方に泰平を賜わったではないか。主はこの地の民をわたしの手にわたされたので、この地は主の前とその民の前に服している。</span>
<span className="v" id="v19" data-v="19" data-xref="歴代志上 28:9; 申命記 4:29; 歴代志上 16:11"> それであなたがたは心をつくし、精神をつくしてあなたがたの神、主を求めなさい。たって主なる神の聖所を建て、主の名のために建てるその家に、主の契約の箱と神の聖なるもろもろの器を携え入れなさい」。</span>
</div>

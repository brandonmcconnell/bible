<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歴代志上 16:1; 歴代志上 17:1–5; 詩篇 132:5"> ダビデはダビデの町のうちに自分のために家を建て、また神の箱のために所を備え、これがために幕屋を張った。</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 10:8; 申命記 31:9; 民数記 18:1–8"> ダビデは言った、「神の箱をかくべき者はただレビびとのみである。主が主の箱をかかせ、また主に長く仕えさせるために彼らを選ばれたからである」。</span>
<span className="v" id="v3" data-v="3" data-xref="列王紀上 8:1; 歴代志上 13:5; 歴代志上 15:1"> ダビデは主の箱をこれがために備えた所にかき上るため、イスラエルをことごとくエルサレムに集めた。</span>
<span className="v" id="v4" data-v="4" data-xref="出エジプト記 6:16–22; 歴代志上 12:26–28; 歴代志上 6:16–30"> ダビデはまたアロンの子孫とレビびとを集めた。</span>
<span className="v" id="v5" data-v="5" data-xref="歴代志上 6:22–24"> すなわち、コハテの子孫のうちからはウリエルを長としてその兄弟百二十人、</span>
<span className="v" id="v6" data-v="6" data-xref="歴代志上 6:29–30"> メラリの子孫のうちからはアサヤを長としてその兄弟二百二十人、</span>
<span className="v" id="v7" data-v="7" data-xref="歴代志上 15:11; 歴代志上 23:8"> ゲルショムの子孫のうちからはヨエルを長としてその兄弟百三十人、</span>
<span className="v" id="v8" data-v="8" data-xref="出エジプト記 6:22"> エリザパンの子孫のうちからはシマヤを長としてその兄弟二百人、</span>
<span className="v" id="v9" data-v="9" data-xref="出エジプト記 6:18; 歴代志上 23:19; 歴代志上 26:30–31"> ヘブロンの子孫のうちからはエリエルを長としてその兄弟八十人、</span>
<span className="v" id="v10" data-v="10" data-xref="出エジプト記 6:18; 歴代志上 6:18; 歴代志上 23:12"> ウジエルの子孫のうちからはアミナダブを長としてその兄弟百十二人である。</span>
<span className="v" id="v11" data-v="11" data-xref="歴代志上 12:28; 列王紀上 2:35; サムエル記上 22:20–23"> ダビデは祭司ザドクとアビヤタル、およびレビびとウリエル、アサヤ、ヨエル、シマヤ、エリエル、アミナダブを召し、</span>
<span className="v" id="v12" data-v="12" data-xref="歴代志下 35:6; 出エジプト記 19:14–15; 歴代志上 15:14"> 彼らに言った、「あなたがたはレビびとの氏族の長である。あなたがたとあなたがたの兄弟はともに身を清め、イスラエルの神、主の箱をわたしがそのために備えた所にかき上りなさい。</span>
<span className="v" id="v13" data-v="13" data-xref="サムエル記下 6:3; コリント人への第一の手紙 14:40; ヨハネの第一の手紙 1:8–10"> さきにこれをかいた者があなたがたでなかったので、われわれの神、主はわれわれを撃たれました。これはわれわれがその定めにしたがってそれを扱わなかったからです」。</span>
<span className="v" id="v14" data-v="14" data-xref="歴代志下 29:15; ヨエル書 2:16–17; 歴代志下 29:34"> そこで祭司たちとレビびとたちはイスラエルの神、主の箱をかき上るために身を清め、</span>
<span className="v" id="v15" data-v="15" data-xref="民数記 4:15; 民数記 7:9; 歴代志下 5:9"> レビびとたちはモーセが主の言葉にしたがって命じたように、神の箱をさおをもって肩にになった。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="歴代志上 13:8; 歴代志下 5:13; 歴代志上 16:42"> ダビデはまたレビびとの長たちに、その兄弟たちを選んで歌うたう者となし、立琴と琴とシンバルなどの楽器を打ちはやし、喜びの声をあげることを命じた。</span>
<span className="v" id="v17" data-v="17" data-xref="歴代志上 6:39; 歴代志上 6:44; 歴代志上 6:33"> そこでレビびとはヨエルの子ヘマンと、その兄弟ベレキヤの子アサフおよびメラリの子孫である彼らの兄弟クシャヤの子エタンを選んだ。</span>
<span className="v" id="v18" data-v="18" data-xref="歴代志上 26:4; 歴代志上 26:8; 歴代志上 13:14"> またこれに次ぐその兄弟たちがこれと共にいた。すなわちゼカリヤ、ヤジエル、セミラモテ、エイエル、ウンニ、エリアブ、ベナヤ、マアセヤ、マッタテヤ、エリペレホ、ミクネヤおよび門を守る者オベデ・エドムとエイエル。</span>
<span className="v" id="v19" data-v="19" data-xref="歴代志上 25:6; 歴代志上 16:5; 歴代志上 13:8"> 歌うたう者ヘマン、アサフおよびエタンは青銅のシンバルを打ちはやす者であった。</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 46:1–11"> ゼカリヤ、アジエル、セミラモテ、エイエル、ウンニ、エリアブ、マアセヤ、ベナヤはアラモテにしたがって立琴を奏する者であった。</span>
<span className="v" id="v21" data-v="21" data-xref="サムエル記上 10:5; 歴代志上 25:6–7; 詩篇 81:1–2"> しかしマッタテヤ、エリペレホ、ミクネヤ、オベデ・エドム、エイエル、アザジヤはセミニテにしたがって琴をもって指揮する者であった。</span>
<span className="v" id="v22" data-v="22" data-xref="歴代志上 15:27; 歴代志上 15:16; 歴代志上 25:7–8"> ケナニヤはレビびとの楽長で、音楽に通じていたので、これを指揮した。</span>
<span className="v" id="v23" data-v="23" data-xref="詩篇 84:10; 列王紀下 22:4; 歴代志上 9:21–23"> ベレキヤとエルカナは箱のために門を守る者であった。</span>
<span className="v" id="v24" data-v="24" data-xref="歴代志上 16:6; 民数記 10:8; 歴代志上 15:28"> 祭司シバニヤ、ヨシャパテ、ネタネル、アマサイ、ゼカリヤ、ベナヤ、エリエゼルらは神の箱の前でラッパを吹き、オベデ・エドムとエヒアは箱のために門を守る者であった。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="サムエル記下 6:12–23; ミカ書 5:2; ピリピ人への手紙 3:3"> ダビデとイスラエルの長老たちおよび千人の長たちは行って、オベデ・エドムの家から主の契約の箱を喜び勇んでかき上った。</span>
<span className="v" id="v26" data-v="26" data-xref="民数記 23:29; 歴代志上 29:14; 詩篇 66:13–15"> 神が主の契約の箱をかくレビびとを助けられたので、彼らは雄牛七頭、雄羊七頭をささげた。</span>
<span className="v" id="v27" data-v="27" data-xref="サムエル記上 2:18; サムエル記下 6:14"> ダビデは亜麻布の衣服を着ていた。箱をかくすべてのレビびとは、歌うたう者、音楽をつかさどるケナニヤも同様である。ダビデはまた亜麻布のエポデを着ていた。</span>
<span className="v" id="v28" data-v="28" data-xref="歴代志上 13:8; 歴代志上 15:16; 歴代志下 5:12–13"> こうしてイスラエルは皆、声をあげ、角笛を吹きならし、ラッパと、シンバルと、立琴と琴をもって打ちはやして主の契約の箱をかき上った。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="サムエル記下 6:20–23; サムエル記下 6:16; 申命記 31:26"> 主の契約の箱がダビデの町にはいったとき、サウルの娘ミカルが窓からながめ、ダビデ王の舞い踊るのを見て、心のうちに彼をいやしめた。</span>
</div>

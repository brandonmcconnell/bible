<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ネヘミヤ書 7:64; 歴代志上 5:25–26; エレミヤ書 52:14–15"> このようにすべてのイスラエルびとは系図によって数えられた。これらはイスラエルの列王紀にしるされている。ユダはその不信のゆえにバビロンに捕囚となった。</span>
<span className="v" id="v2" data-v="2" data-xref="ネヘミヤ書 7:73; エズラ記 2:58; エズラ記 2:70"> その領地の町々に最初に住んだものはイスラエルびと、祭司、レビびとおよび宮に仕えるしもべたちであった。</span>
<span className="v" id="v3" data-v="3" data-xref="ネヘミヤ書 11:1; 歴代志下 11:16; ネヘミヤ書 11:4–9"> またエルサレムにはユダの子孫、ベニヤミンの子孫およびエフライムとマナセの子孫が住んでいた。</span>
<span className="v" id="v4" data-v="4" data-xref="歴代志上 2:5; 創世記 46:12; 民数記 26:20"> すなわちユダの子ペレヅの子孫のうちではアミホデの子ウタイ。アミホデはオムリの子、オムリはイムリの子、イムリはバニの子である。</span>
<span className="v" id="v5" data-v="5" data-xref="民数記 26:20; ネヘミヤ書 11:5"> シロびとのうちでは長子アサヤとそのほかの子たち。</span>
<span className="v" id="v6" data-v="6" data-xref="民数記 26:20; 歴代志上 2:6; 創世記 38:30"> ゼラの子孫のうちではユエルとその兄弟六百九十人。</span>
<span className="v" id="v7" data-v="7" data-xref="ネヘミヤ書 10:20; ネヘミヤ書 11:7; ネヘミヤ書 8:4"> ベニヤミンの子孫のうちではハセヌアの子ホダビヤの子であるメシュラムの子サル、</span>
<span className="v" id="v8" data-v="8"> エロハムの子イブニヤ、ミクリの子であるウジの子エラおよびイブニヤの子リウエルの子であるシパテヤの子メシュラム、</span>
<span className="v" id="v9" data-v="9" data-xref="ネヘミヤ書 11:8"> ならびに彼らの兄弟たちで、その系図によれば合わせて九百五十六人。これらの人々は皆その氏族の長であった。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="ネヘミヤ書 12:19; ネヘミヤ書 11:10–24"> 祭司のうちではエダヤ、ヨアリブ、ヤキン、</span>
<span className="v" id="v11" data-v="11" data-xref="ネヘミヤ書 11:11; 列王紀下 25:18; 民数記 4:33"> およびヒルキヤの子アザリヤ、ヒルキヤはメシュラムの子、メシュラムはザドクの子、ザドクはメラヨテの子、メラヨテはアヒトブの子である。アザリヤは神の宮のつかさである。</span>
<span className="v" id="v12" data-v="12" data-xref="ネヘミヤ書 7:40; エズラ記 2:37; ネヘミヤ書 11:12–13"> またエロハムの子アダヤ、エロハムはパシュルの子、パシュルはマルキヤの子である。またアデエルの子はマアセヤ、アデエルはヤゼラの子、ヤゼラはメシュラムの子、メシュラムはメシレモテの子、メシレモテはインメルの子である。</span>
<span className="v" id="v13" data-v="13" data-xref="ネヘミヤ書 11:14; 歴代志上 26:30; 歴代志上 26:32"> そのほかに彼らの兄弟たちもあった。これらはその氏族の長で、合わせて一千七百六十人、みな神の宮の務をするのに、はなはだ力のある人々であった。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="民数記 26:57; ネヘミヤ書 10:11; 歴代志上 6:29"> レビびとのうちではハシュブの子シマヤ、ハシュブはアズリカムの子、アズリカムはハシャビヤの子で、これらはメラリの子孫である。</span>
<span className="v" id="v15" data-v="15" data-xref="ネヘミヤ書 11:22; ネヘミヤ書 11:17; 歴代志上 11:17"> またバクバッカル、ヘレシ、ガラル、およびアサフの子ジクリの子であるミカの子マッタニヤ、</span>
<span className="v" id="v16" data-v="16" data-xref="歴代志上 25:1; 歴代志下 35:15; 歴代志上 12:25"> ならびにエドトンの子ガラルの子であるシマヤの子オバデヤおよびエルカナの子であるアサの子ベレキヤ、エルカナはネトパびとの村里に住んだ者である。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="歴代志上 26:1–32; 歴代志上 23:5; ネヘミヤ書 11:19"> 門を守るものはシャルム、アックブ、タルモン、アヒマンおよびその兄弟たちで、シャルムはその長であった。</span>
<span className="v" id="v18" data-v="18" data-xref="エゼキエル書 46:1–2; エゼキエル書 44:2–3; 列王紀上 10:5"> 彼は今日まで東の方にある王の門を守っている。これらはレビの子孫で営の門を守る者である。</span>
<span className="v" id="v19" data-v="19" data-xref="民数記 26:9–11; 詩篇 44:1; 列王紀下 11:15"> コラの子エビヤサフの子であるコレの子シャルムおよびその氏族の兄弟たちなどのコラびとは幕屋のもろもろの門を守る務をつかさどった。その先祖たちは主の営をつかさどり、その入口を守る者であった。</span>
<span className="v" id="v20" data-v="20" data-xref="民数記 31:6; 民数記 3:32; 民数記 4:33"> エレアザルの子ピネハスが、むかし彼らのつかさであった。主は彼とともにおられた。</span>
<span className="v" id="v21" data-v="21" data-xref="歴代志上 26:14; 歴代志上 26:2"> メシレミヤの子ゼカリヤは会見の幕屋の門を守る者であった。</span>
<span className="v" id="v22" data-v="22" data-xref="サムエル記上 9:9; 歴代志上 28:13; 歴代志上 23:1–32"> これらは皆選ばれて門を守る者で、合わせて二百十二人あった。彼らはその村々で系図によって数えられた者で、ダビデと先見者サムエルが彼らを職に任じたのである。</span>
<span className="v" id="v23" data-v="23" data-xref="エゼキエル書 44:14; 歴代志下 23:19; エゼキエル書 44:10–11"> こうして彼らとその子孫は監守人として、主の家である幕屋の家の門をつかさどった。</span>
<span className="v" id="v24" data-v="24" data-xref="歴代志上 26:14–18"> 門を守る者は東西南北の四方にいた。</span>
<span className="v" id="v25" data-v="25" data-xref="列王紀下 11:5; 歴代志下 23:8; 列王紀下 11:7"> またその村々にいる兄弟たちは七日ごとに代り、来て彼らを助けた。</span>
<span className="v" id="v26" data-v="26" data-xref="ネヘミヤ書 13:5; ネヘミヤ書 10:38–39; 歴代志上 26:20–27"> 門を守る者の長である四人のレビびとは神の家のもろもろの室と宝とをつかさどった。</span>
<span className="v" id="v27" data-v="27" data-xref="歴代志上 23:30–32; マラキ書 1:10; サムエル記上 3:15"> 彼らは神の家を守る身であるから、そのまわりに宿った。そして朝ごとにこれを開くことをした。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="ネヘミヤ書 13:4–5; ネヘミヤ書 12:44; 歴代志上 26:22–26"> そのうちに務の器をつかさどる者があった。彼らはその数を調べて携え入り、またその数を調べて携え出した。</span>
<span className="v" id="v29" data-v="29" data-xref="歴代志上 23:29; 出エジプト記 30:23–38; 出エジプト記 27:20"> またそのほかの品、すべての聖なる器および麦粉、ぶどう酒、油、乳香、香料をつかさどる者があった。</span>
<span className="v" id="v30" data-v="30" data-xref="出エジプト記 30:23–25; 出エジプト記 37:29; 出エジプト記 30:35–38"> また祭司のともがらのうちに香料を混ぜる者があった。</span>
<span className="v" id="v31" data-v="31" data-xref="歴代志上 9:19; 歴代志上 9:22; レビ記 6:21"> コラびとシャルムの長子でレビびとのひとりであるマタテヤはせんべいを造る勤めをつかさどった。</span>
<span className="v" id="v32" data-v="32" data-xref="レビ記 24:5–8; 歴代志上 6:33–48; 出エジプト記 25:30"> またコハテびとの子孫であるその兄弟たちのうちに供えのパンをつかさどって、安息日ごとにこれを整える者どもがあった。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="歴代志上 6:31–33; 詩篇 134:1–2; 歴代志上 16:4–6"> レビびとの氏族の長であるこれらの者は歌うたう者であって、宮のもろもろの室に住み、ほかの務はしなかった。彼らは日夜自分の務に従ったからである。</span>
<span className="v" id="v34" data-v="34" data-xref="ネヘミヤ書 11:1–15; 歴代志上 9:13"> これらはレビびとの歴代の氏族の長であって、かしらたる人々であった。彼らはエルサレムに住んだ。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="歴代志上 2:23–24; 歴代志上 2:50–52; 歴代志上 8:29–40"> ギベオンの父エヒエルはギベオンに住んでいた。その妻の名はマアカといった。</span>
<span className="v" id="v36" data-v="36" data-xref="歴代志上 9:39; 歴代志上 8:33"> 彼の長子はアブドン、次はツル、キシ、バアル、ネル、ナダブ、</span>
<span className="v" id="v37" data-v="37" data-xref="歴代志上 8:31"> ゲドル、アヒオ、ゼカリヤ、ミクロテである。</span>
<span className="v" id="v38" data-v="38" data-xref="歴代志上 8:32"> ミクロテはシメアムを生んだ。彼らもその兄弟たちとともにエルサレムに住んで、その兄弟たちと向かいあっていた。</span>
<span className="v" id="v39" data-v="39" data-xref="サムエル記上 13:22; 歴代志上 8:33–38; 歴代志上 10:2"> ネルはキシを生み、キシはサウルを生み、サウルはヨナタン、マルキシュア、アビナダブ、エシバアルを生んだ。</span>
<span className="v" id="v40" data-v="40" data-xref="サムエル記下 4:4; 歴代志上 8:34–36"> ヨナタンの子はメリバアルで、メリバアルはミカを生んだ。</span>
<span className="v" id="v41" data-v="41" data-xref="歴代志上 8:35"> ミカの子らはピトン、メレク、タレアおよびアハズである。</span>
<span className="v" id="v42" data-v="42" data-xref="歴代志上 8:36"> アハズはヤラを生み、ヤラはアレメテ、アズマウテおよびジムリを生み、ジムリはモザを生み、</span>
<span className="v" id="v43" data-v="43" data-xref="歴代志上 8:37"> モザはビネアを生んだ。ビネアの子はレパヤ、その子はエレアサ、その子はアゼルである。</span>
<span className="v" id="v44" data-v="44"> アゼルに六人の男の子があった。その名はアズリカム、ボケル、イシマエル、シャリヤ、オバデヤ、ハナン。これらはみなアゼルの子らであった。</span>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歴代志上 12:20; 歴代志下 34:29–30; 歴代志下 29:20"> ここにダビデは千人の長、百人の長などの諸将と相はかり、</span>
<span className="v" id="v2" data-v="2" data-xref="民数記 4:4–20; サムエル記上 31:1; 歴代志上 10:7"> そしてダビデはイスラエルの全会衆に言った、「もし、このことをあなたがたがよしとし、われわれの神、主がこれを許されるならば、われわれは、イスラエルの各地に残っているわれわれの兄弟ならびに、放牧地の付いている町々にいる祭司とレビびとに、使をつかわし、われわれの所に呼び集めましょう。</span>
<span className="v" id="v3" data-v="3" data-xref="サムエル記上 7:1–2; サムエル記上 23:2; サムエル記上 14:18"> また神の箱をわれわれの所に移しましょう。われわれはサウルの世にはこれをおろそかにしたからです」。</span>
<span className="v" id="v4" data-v="4" data-xref="エステル記 8:5; サムエル記下 3:36; サムエル記上 18:20"> 会衆は一同「そうしましょう」と言った。このことがすべての民の目に正しかったからである。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="サムエル記上 6:21–1; 列王紀上 8:65; サムエル記下 6:1"> そこでダビデはキリアテ・ヤリムから神の箱を運んでくるため、エジプトのシホルからハマテの入口までのイスラエルをことごとく呼び集めた。</span>
<span className="v" id="v6" data-v="6" data-xref="出エジプト記 25:22; ヨシュア記 15:9; 列王紀下 19:15"> そしてダビデとすべてのイスラエルはバアラすなわちユダのキリアテ・ヤリムに上り、ケルビムの上に座しておられる主の名をもって呼ばれている神の箱をそこからかき上ろうと、</span>
<span className="v" id="v7" data-v="7" data-xref="民数記 4:15; サムエル記上 6:7; 歴代志上 15:2"> 神の箱を新しい車にのせて、アビナダブの家からひきだし、ウザとアヒヨがその車を御した。</span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 150:3–5; 詩篇 68:25–27; アモス書 6:5"> ダビデおよびすべてのイスラエルは歌と琴と立琴と、手鼓と、シンバルと、ラッパをもって、力をきわめて神の前に踊った。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="サムエル記下 6:6"> 彼らがキドンの打ち場に来た時、ウザは手を伸べて箱を押えた。牛がつまずいたからである。</span>
<span className="v" id="v10" data-v="10" data-xref="歴代志上 15:15; 歴代志上 15:13; 民数記 4:15"> ウザが手を箱につけたことによって、主は彼に向かって怒りを発し、彼を撃たれたので、彼はその所で神の前に死んだ。</span>
<span className="v" id="v11" data-v="11" data-xref="サムエル記下 6:7; サムエル記下 6:9; 創世記 32:32"> 主がウザを撃たれたので、ダビデは怒った。その所は今日までペレヅ・ウザと呼ばれている。</span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 119:120; 列王紀上 8:27; ヨブ記 25:5–6"> その日ダビデは神を恐れて言った、「どうして神の箱を、わたしの所へかいて行けようか」。</span>
<span className="v" id="v13" data-v="13" data-xref="歴代志上 26:4; 歴代志上 15:18; サムエル記下 4:3"> それでダビデはその箱を自分の所ダビデの町へは移さず、これを転じてガテびとオベデ・エドムの家に運ばせた。</span>
<span className="v" id="v14" data-v="14" data-xref="歴代志上 26:4–5; 箴言 10:22; 箴言 3:9–10"> 神の箱は三か月の間、オベデ・エドムの家に、その家族とともにとどまった。主はオベデ・エドムの家族とそのすべての持ち物を祝福された。</span>
</div>

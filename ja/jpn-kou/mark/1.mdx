<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨハネの第一の手紙 5:11–12; マタイによる福音書 4:3; マタイによる福音書 3:17"> 神の子イエス・キリストの福音のはじめ。</span>
</div>
<div className="bp poetry">
<span className="v" id="v2" data-v="2" data-xref="マラキ書 3:1; マタイによる福音書 11:10; ルカによる福音書 1:76"> 預言者イザヤの書に、<br /><span className="pl pl-1">「見よ、わたしは使をあなたの先につかわし、</span><br /><span className="pl pl-1">あなたの道を整えさせるであろう。</span></span>
<span className="v" id="v3" data-v="3" data-xref="イザヤ書 40:3–5; マタイによる福音書 3:3; ルカによる福音書 3:4–6"> <span className="pl pl-1">荒野で呼ばわる者の声がする、</span><br /><span className="pl pl-1">『主の道を備えよ、</span><br /><span className="pl pl-1">その道筋をまっすぐにせよ』」</span><br />と書いてあるように、</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行伝 19:3–4; マタイによる福音書 3:6; 使徒行伝 13:24–25"> バプテスマのヨハネが荒野に現れて、罪のゆるしを得させる悔改めのバプテスマを宣べ伝えていた。</span>
<span className="v" id="v5" data-v="5" data-xref="レビ記 26:40–42; 使徒行伝 19:18; マタイによる福音書 3:5–6"> そこで、ユダヤ全土とエルサレムの全住民とが、彼のもとにぞくぞくと出て行って、自分の罪を告白し、ヨルダン川でヨハネからバプテスマを受けた。</span>
<span className="v" id="v6" data-v="6" data-xref="列王紀下 1:8; レビ記 11:22; マタイによる福音書 3:4"> このヨハネは、らくだの毛ごろもを身にまとい、腰に皮の帯をしめ、いなごと野蜜とを食物としていた。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行伝 13:25; ルカによる福音書 3:16; ヨハネによる福音書 1:27"> 彼は宣べ伝えて言った、「わたしよりも力のあるかたが、あとからおいでになる。わたしはかがんで、そのくつのひもを解く値うちもない。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行伝 1:5; コリント人への第一の手紙 12:13; 使徒行伝 19:4–6"> わたしは水でバプテスマを授けたが、このかたは、聖霊によってバプテスマをお授けになるであろう」。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="マタイによる福音書 3:13–17; マタイによる福音書 2:23; ルカによる福音書 3:21–22"> そのころ、イエスはガリラヤのナザレから出てきて、ヨルダン川で、ヨハネからバプテスマをお受けになった。</span>
<span className="v" id="v10" data-v="10" data-xref="ヨハネによる福音書 1:31–34; ルカによる福音書 3:22; イザヤ書 42:1"> そして、水の中から上がられるとすぐ、天が裂けて、聖霊がはとのように自分に下って来るのを、ごらんになった。</span>
<span className="v" id="v11" data-v="11" data-xref="イザヤ書 42:1; マルコによる福音書 9:7; マタイによる福音書 3:17"> すると天から声があった、「あなたはわたしの愛する子、わたしの心にかなう者である」。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="マタイによる福音書 4:1–11; ルカによる福音書 4:1–13"> それからすぐに、御霊がイエスを荒野に追いやった。</span>
<span className="v" id="v13" data-v="13" data-xref="ヘブル人への手紙 2:17–18; ヘブル人への手紙 4:15; 出エジプト記 34:28"> イエスは四十日のあいだ荒野にいて、サタンの試みにあわれた。そして獣もそこにいたが、御使たちはイエスに仕えていた。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="マタイによる福音書 4:23; マタイによる福音書 4:12; ルカによる福音書 8:1"> ヨハネが捕えられた後、イエスはガリラヤに行き、神の福音を宣べ伝えて言われた、</span>
<span className="v" id="v15" data-v="15" data-xref="マタイによる福音書 3:2; 使徒行伝 2:36–38; マタイによる福音書 4:17"> 「時は満ちた、神の国は近づいた。悔い改めて福音を信ぜよ」。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="マタイによる福音書 4:18–22; ヨハネによる福音書 1:40–42; ヨハネによる福音書 6:8"> さて、イエスはガリラヤの海べを歩いて行かれ、シモンとシモンの兄弟アンデレとが、海で網を打っているのをごらんになった。彼らは漁師であった。</span>
<span className="v" id="v17" data-v="17" data-xref="ルカによる福音書 5:10; マタイによる福音書 4:19–20; 使徒行伝 2:38–41"> イエスは彼らに言われた、「わたしについてきなさい。あなたがたを、人間をとる漁師にしてあげよう」。</span>
<span className="v" id="v18" data-v="18" data-xref="ルカによる福音書 18:28–30; ルカによる福音書 5:11; マルコによる福音書 10:28–31"> すると、彼らはすぐに網を捨てて、イエスに従った。</span>
<span className="v" id="v19" data-v="19" data-xref="マルコによる福音書 5:37; 使徒行伝 1:13; マルコによる福音書 10:35"> また少し進んで行かれると、ゼベダイの子ヤコブとその兄弟ヨハネとが、舟の中で網を繕っているのをごらんになった。</span>
<span className="v" id="v20" data-v="20" data-xref="マタイによる福音書 10:37; ルカによる福音書 14:26; マルコによる福音書 10:29"> そこで、すぐ彼らをお招きになると、父ゼベダイを雇人たちと一緒に舟において、イエスのあとについて行った。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="マルコによる福音書 6:2; マルコによる福音書 1:39; マタイによる福音書 4:23"> それから、彼らはカペナウムに行った。そして安息日にすぐ、イエスは会堂にはいって教えられた。</span>
<span className="v" id="v22" data-v="22" data-xref="マタイによる福音書 7:28–29; マタイによる福音書 13:54; ルカによる福音書 4:32"> 人々は、その教に驚いた。律法学者たちのようにではなく、権威ある者のように、教えられたからである。</span>
<span className="v" id="v23" data-v="23" data-xref="マルコによる福音書 9:25; マルコによる福音書 7:25; マルコによる福音書 1:34"> ちょうどその時、けがれた霊につかれた者が会堂にいて、叫んで言った、</span>
<span className="v" id="v24" data-v="24" data-xref="マタイによる福音書 8:29; ヤコブの手紙 2:19; 使徒行伝 3:14"> 「ナザレのイエスよ、あなたはわたしたちとなんの係わりがあるのです。わたしたちを滅ぼしにこられたのですか。あなたがどなたであるか、わかっています。神の聖者です」。</span>
<span className="v" id="v25" data-v="25" data-xref="マルコによる福音書 1:34; ルカによる福音書 4:41; 使徒行伝 16:17"> イエスはこれをしかって、「黙れ、この人から出て行け」と言われた。</span>
<span className="v" id="v26" data-v="26" data-xref="マルコによる福音書 9:26; マルコによる福音書 9:20; ルカによる福音書 11:22"> すると、けがれた霊は彼をひきつけさせ、大声をあげて、その人から出て行った。</span>
<span className="v" id="v27" data-v="27" data-xref="マタイによる福音書 15:31; マルコによる福音書 7:37; ルカによる福音書 9:1"> 人々はみな驚きのあまり、互に論じて言った、「これは、いったい何事か。権威ある新しい教だ。けがれた霊にさえ命じられると、彼らは従うのだ」。</span>
<span className="v" id="v28" data-v="28" data-xref="マタイによる福音書 9:31; ルカによる福音書 4:37; マルコによる福音書 1:45"> こうしてイエスのうわさは、たちまちガリラヤの全地方、いたる所にひろまった。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="ルカによる福音書 4:38–39; マタイによる福音書 8:14–15; マルコによる福音書 1:21"> それから会堂を出るとすぐ、ヤコブとヨハネとを連れて、シモンとアンデレとの家にはいって行かれた。</span>
<span className="v" id="v30" data-v="30" data-xref="コリント人への第一の手紙 9:5; マルコによる福音書 5:23; ヨハネによる福音書 11:3"> ところが、シモンのしゅうとめが熱病で床についていたので、人々はさっそく、そのことをイエスに知らせた。</span>
<span className="v" id="v31" data-v="31" data-xref="使徒行伝 9:41; 詩篇 116:12; マルコによる福音書 5:41"> イエスは近寄り、その手をとって起されると、熱が引き、女は彼らをもてなした。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="マタイによる福音書 8:16; マルコによる福音書 3:2; ルカによる福音書 4:40"> 夕暮になり日が沈むと、人々は病人や悪霊につかれた者をみな、イエスのところに連れてきた。</span>
<span className="v" id="v33" data-v="33" data-xref="マルコによる福音書 1:5; 使徒行伝 13:44"> こうして、町中の者が戸口に集まった。</span>
<span className="v" id="v34" data-v="34" data-xref="ルカによる福音書 4:41; マルコによる福音書 3:12; マタイによる福音書 4:23"> イエスは、さまざまの病をわずらっている多くの人々をいやし、また多くの悪霊を追い出された。また、悪霊どもに、物言うことをお許しにならなかった。彼らがイエスを知っていたからである。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="ルカによる福音書 6:12; ルカによる福音書 5:16; ルカによる福音書 22:39–46"> 朝はやく、夜の明けるよほど前に、イエスは起きて寂しい所へ出て行き、そこで祈っておられた。</span>
<span className="v" id="v36" data-v="36"> すると、シモンとその仲間とが、あとを追ってきた。</span>
<span className="v" id="v37" data-v="37" data-xref="ヨハネによる福音書 12:19; マルコによる福音書 1:5; ゼカリヤ書 11:11"> そしてイエスを見つけて、「みんなが、あなたを捜しています」と言った。</span>
<span className="v" id="v38" data-v="38" data-xref="ルカによる福音書 4:43; ヨハネによる福音書 17:8; イザヤ書 61:1–3"> イエスは彼らに言われた、「ほかの、附近の町々にみんなで行って、そこでも教を宣べ伝えよう。わたしはこのために出てきたのだから」。</span>
<span className="v" id="v39" data-v="39" data-xref="マタイによる福音書 4:23; マルコによる福音書 1:21; ルカによる福音書 4:43–44"> そして、ガリラヤ全地を巡りあるいて、諸会堂で教を宣べ伝え、また悪霊を追い出された。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="ルカによる福音書 5:12–14; マタイによる福音書 8:2–4; レビ記 13:1–14"> ひとりのらい病人が、イエスのところに願いにきて、ひざまずいて言った、「みこころでしたら、きよめていただけるのですが」。</span>
<span className="v" id="v41" data-v="41" data-xref="マタイによる福音書 9:36; ヘブル人への手紙 2:17; ヘブル人への手紙 4:15"> イエスは深くあわれみ、手を伸ばして彼にさわり、「そうしてあげよう、きよくなれ」と言われた。</span>
<span className="v" id="v42" data-v="42" data-xref="ヨハネによる福音書 15:3; マルコによる福音書 5:29; ヨハネによる福音書 4:50–53"> すると、らい病が直ちに去って、その人はきよくなった。</span>
<span className="v" id="v43" data-v="43" data-xref="マタイによる福音書 9:30; マルコによる福音書 7:36; ルカによる福音書 8:56"> イエスは彼をきびしく戒めて、すぐにそこを去らせ、こう言い聞かせられた、</span>
<span className="v" id="v44" data-v="44" data-xref="レビ記 14:1–32; ルカによる福音書 17:14; マタイによる福音書 8:4"> 「何も人に話さないように、注意しなさい。ただ行って、自分のからだを祭司に見せ、それから、モーセが命じた物をあなたのきよめのためにささげて、人々に証明しなさい」。</span>
<span className="v" id="v45" data-v="45" data-xref="マルコによる福音書 2:13; マタイによる福音書 9:31; ヨハネによる福音書 6:2"> しかし、彼は出て行って、自分の身に起ったことを盛んに語り、また言いひろめはじめたので、イエスはもはや表立っては町に、はいることができなくなり、外の寂しい所にとどまっておられた。しかし、人々は方々から、イエスのところにぞくぞくと集まってきた。</span>
</div>
</div>

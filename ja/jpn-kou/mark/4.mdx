<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ルカによる福音書 5:1–3; マルコによる福音書 2:13; ルカによる福音書 8:4–10"> イエスはまたも、海べで教えはじめられた。おびただしい群衆がみもとに集まったので、イエスは舟に乗ってすわったまま、海上におられ、群衆はみな海に沿って陸地にいた。</span>
<span className="v" id="v2" data-v="2" data-xref="マタイによる福音書 13:34–35; マルコによる福音書 3:23; マルコによる福音書 4:11"> イエスは譬で多くの事を教えられたが、その教の中で彼らにこう言われた、</span>
<span className="v" id="v3" data-v="3" data-xref="ヤコブの手紙 2:5; マタイによる福音書 13:26; マルコによる福音書 4:26–29"> 「聞きなさい、種まきが種をまきに出て行った。</span>
<span className="v" id="v4" data-v="4" data-xref="マタイによる福音書 13:19; マルコによる福音書 4:15; マタイによる福音書 13:4"> まいているうちに、道ばたに落ちた種があった。すると、鳥がきて食べてしまった。</span>
<span className="v" id="v5" data-v="5" data-xref="エゼキエル書 36:26; ルカによる福音書 8:6; ルカによる福音書 8:13"> ほかの種は土の薄い石地に落ちた。そこは土が深くないので、すぐ芽を出したが、</span>
<span className="v" id="v6" data-v="6" data-xref="ヤコブの手紙 1:11; エレミヤ書 17:5–8; ヨナ書 4:8"> 日が上ると焼けて、根がないために枯れてしまった。</span>
<span className="v" id="v7" data-v="7" data-xref="エレミヤ書 4:3; ルカによる福音書 8:14; 創世記 3:17–18"> ほかの種はいばらの中に落ちた。すると、いばらが伸びて、ふさいでしまったので、実を結ばなかった。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨハネによる福音書 15:5; コロサイ人への手紙 1:6; マルコによる福音書 4:20"> ほかの種は良い地に落ちた。そしてはえて、育って、ますます実を結び、三十倍、六十倍、百倍にもなった」。</span>
<span className="v" id="v9" data-v="9" data-xref="マタイによる福音書 11:15; マルコによる福音書 4:23–24; ヨハネの黙示録 3:22"> そして言われた、「聞く耳のある者は聞くがよい」。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="マタイによる福音書 13:10–17; マルコによる福音書 4:34; 箴言 13:20"> イエスがひとりになられた時、そばにいた者たちが、十二弟子と共に、これらの譬について尋ねた。</span>
<span className="v" id="v11" data-v="11" data-xref="マタイによる福音書 11:25; ルカによる福音書 8:10; ヨハネの第一の手紙 5:20"> そこでイエスは言われた、「あなたがたには神の国の奥義が授けられているが、ほかの者たちには、すべてが譬で語られる。</span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="イザヤ書 6:9–10; イザヤ書 44:18; マタイによる福音書 13:14–15"> それは<br /><span className="pl pl-1">『彼らは見るには見るが、認めず、</span><br /><span className="pl pl-1">聞くには聞くが、悟らず、</span><br /><span className="pl pl-1">悔い改めてゆるされることがない』ためである」。</span></span>
<span className="v" id="v13" data-v="13" data-xref="ヨハネの黙示録 3:19; マタイによる福音書 13:51–52; マルコによる福音書 7:17–18"> <span className="pl pl-1">また彼らに言われた、「あなたがたはこの譬がわからないのか。それでは、どうしてすべての譬がわかるだろうか。</span></span>
<span className="v" id="v14" data-v="14" data-xref="使徒行伝 8:4; マタイによる福音書 13:19; マタイによる福音書 13:37"> <span className="pl pl-1">種まきは御言をまくのである。</span></span>
<span className="v" id="v15" data-v="15" data-xref="ペテロの第一の手紙 5:8; マタイによる福音書 13:19; コリント人への第二の手紙 2:11"> <span className="pl pl-1">道ばたに御言がまかれたとは、こういう人たちのことである。すなわち、御言を聞くと、すぐにサタンがきて、彼らの中にまかれた御言を、奪って行くのである。</span></span>
<span className="v" id="v16" data-v="16" data-xref="マルコによる福音書 6:20; ルカによる福音書 8:13; マタイによる福音書 13:20–21"> <span className="pl pl-1">同じように、石地にまかれたものとは、こういう人たちのことである。御言を聞くと、すぐに喜んで受けるが、</span></span>
<span className="v" id="v17" data-v="17" data-xref="マタイによる福音書 11:6; テサロニケ人への第一の手紙 3:3–5; マタイによる福音書 12:31"> <span className="pl pl-1">自分の中に根がないので、しばらく続くだけである。そののち、御言のために困難や迫害が起ってくると、すぐつまずいてしまう。</span></span>
<span className="v" id="v18" data-v="18" data-xref="ルカによる福音書 8:14; エレミヤ書 4:3; マタイによる福音書 13:22"> <span className="pl pl-1">また、いばらの中にまかれたものとは、こういう人たちのことである。御言を聞くが、</span></span>
<span className="v" id="v19" data-v="19" data-xref="ヨハネの第一の手紙 2:15–17; テモテヘの第一の手紙 6:9–10; テモテヘの第一の手紙 6:17"> <span className="pl pl-1">世の心づかいと、富の惑わしと、その他いろいろな欲とがはいってきて、御言をふさぐので、実を結ばなくなる。</span></span>
<span className="v" id="v20" data-v="20" data-xref="コロサイ人への手紙 1:10; ルカによる福音書 8:15; ヨハネによる福音書 15:4–5"> <span className="pl pl-1">また、良い地にまかれたものとは、こういう人たちのことである。御言を聞いて受けいれ、三十倍、六十倍、百倍の実を結ぶのである」。</span></span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="マタイによる福音書 5:15; ルカによる福音書 11:33; ルカによる福音書 8:16"> また彼らに言われた、「ますの下や寝台の下に置くために、あかりを持ってくることがあろうか。燭台の上に置くためではないか。</span>
<span className="v" id="v22" data-v="22" data-xref="ルカによる福音書 8:17; 伝道の書 12:14; マタイによる福音書 10:26–27"> なんでも、隠されているもので、現れないものはなく、秘密にされているもので、明るみに出ないものはない。</span>
<span className="v" id="v23" data-v="23" data-xref="マルコによる福音書 4:9; マタイによる福音書 11:15; ヨハネの黙示録 2:29"> 聞く耳のある者は聞くがよい」。</span>
<span className="v" id="v24" data-v="24" data-xref="ヘブル人への手紙 2:1; ルカによる福音書 8:18; マタイによる福音書 7:2"> また彼らに言われた、「聞くことがらに注意しなさい。あなたがたの量るそのはかりで、自分にも量り与えられ、その上になお増し加えられるであろう。</span>
<span className="v" id="v25" data-v="25" data-xref="マタイによる福音書 13:12; ルカによる福音書 8:18; マタイによる福音書 25:28–29"> だれでも、持っている人は更に与えられ、持っていない人は、持っているものまでも取り上げられるであろう」。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="マタイによる福音書 13:24; コリント人への第一の手紙 3:6–9; ルカによる福音書 8:11"> また言われた、「神の国は、ある人が地に種をまくようなものである。</span>
<span className="v" id="v27" data-v="27" data-xref="伝道の書 11:5; テサロニケ人への第二の手紙 1:3; コリント人への第一の手紙 15:37–38"> 夜昼、寝起きしている間に、種は芽を出して育って行くが、どうしてそうなるのか、その人は知らない。</span>
<span className="v" id="v28" data-v="28" data-xref="マルコによる福音書 4:31–32; ホセア書 6:3; ピリピ人への手紙 1:9–11"> 地はおのずから実を結ばせるもので、初めに芽、つぎに穂、つぎに穂の中に豊かな実ができる。</span>
<span className="v" id="v29" data-v="29" data-xref="ヨエル書 3:13; マタイによる福音書 13:30; マタイによる福音書 13:40–43"> 実がいると、すぐにかまを入れる。刈入れ時がきたからである」。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="マタイによる福音書 13:31–32; ルカによる福音書 13:18–21; 哀歌 2:13"> また言われた、「神の国を何に比べようか。また、どんな譬で言いあらわそうか。</span>
<span className="v" id="v31" data-v="31" data-xref="使徒行伝 19:20; ルカによる福音書 13:18–19; ダニエル書 2:44–45"> それは一粒のからし種のようなものである。地にまかれる時には、地上のどんな種よりも小さいが、</span>
<span className="v" id="v32" data-v="32" data-xref="ダニエル書 4:20–22; ダニエル書 4:10–14; エゼキエル書 31:3–10"> まかれると、成長してどんな野菜よりも大きくなり、大きな枝を張り、その陰に空の鳥が宿るほどになる」。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="マタイによる福音書 13:34–35; ヨハネによる福音書 16:12; ヘブル人への手紙 5:11–14"> イエスはこのような多くの譬で、人々の聞く力にしたがって、御言を語られた。</span>
<span className="v" id="v34" data-v="34" data-xref="ヨハネによる福音書 16:25; マルコによる福音書 4:10; マタイによる福音書 15:15–20"> 譬によらないでは語られなかったが、自分の弟子たちには、ひそかにすべてのことを解き明かされた。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="マタイによる福音書 8:18; ルカによる福音書 8:22; ルカによる福音書 8:25"> さてその日、夕方になると、イエスは弟子たちに、「向こう岸へ渡ろう」と言われた。</span>
<span className="v" id="v36" data-v="36" data-xref="マルコによる福音書 3:9; マルコによる福音書 4:1; マルコによる福音書 5:2"> そこで、彼らは群衆をあとに残し、イエスが舟に乗っておられるまま、乗り出した。ほかの舟も一緒に行った。</span>
<span className="v" id="v37" data-v="37" data-xref="マタイによる福音書 8:23–24; ヨブ記 1:19; ルカによる福音書 8:22–23"> すると、激しい突風が起り、波が舟の中に打ち込んできて、舟に満ちそうになった。</span>
<span className="v" id="v38" data-v="38" data-xref="ペテロの第一の手紙 5:7; ヘブル人への手紙 4:15; イザヤ書 54:6–8"> ところがイエス自身は、舳の方でまくらをして、眠っておられた。そこで、弟子たちはイエスをおこして、「先生、わたしどもがおぼれ死んでも、おかまいにならないのですか」と言った。</span>
<span className="v" id="v39" data-v="39" data-xref="詩篇 107:29; 詩篇 89:9; 詩篇 65:7"> イエスは起きあがって風をしかり、海にむかって、「静まれ、黙れ」と言われると、風はやんで、大なぎになった。</span>
<span className="v" id="v40" data-v="40" data-xref="ルカによる福音書 8:25; マタイによる福音書 8:26; マタイによる福音書 14:31"> イエスは彼らに言われた、「なぜ、そんなにこわがるのか。どうして信仰がないのか」。</span>
<span className="v" id="v41" data-v="41" data-xref="ルカによる福音書 8:25; ヨブ記 38:11; 詩篇 89:7"> 彼らは恐れおののいて、互に言った、「いったい、この方はだれだろう。風も海も従わせるとは」。</span>
</div>

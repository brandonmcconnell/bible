<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ルカによる福音書 4:16–30; マタイによる福音書 13:54–58; マタイによる福音書 2:23"> イエスはそこを去って、郷里に行かれたが、弟子たちも従って行った。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネによる福音書 7:15; ヨハネによる福音書 6:42; 使徒行伝 4:13–14"> そして、安息日になったので、会堂で教えはじめられた。それを聞いた多くの人々は、驚いて言った、「この人は、これらのことをどこで習ってきたのか。また、この人の授かった知恵はどうだろう。このような力あるわざがその手で行われているのは、どうしてか。</span>
<span className="v" id="v3" data-v="3" data-xref="マタイによる福音書 12:46; マタイによる福音書 13:55–57; ヨハネによる福音書 6:42"> この人は大工ではないか。マリヤのむすこで、ヤコブ、ヨセ、ユダ、シモンの兄弟ではないか。またその姉妹たちも、ここにわたしたちと一緒にいるではないか」。こうして彼らはイエスにつまずいた。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネによる福音書 4:44; ルカによる福音書 4:24; マタイによる福音書 13:57"> イエスは言われた、「預言者は、自分の郷里、親族、家以外では、どこででも敬われないことはない」。</span>
<span className="v" id="v5" data-v="5" data-xref="マタイによる福音書 13:58; マルコによる福音書 9:23; マルコによる福音書 5:23"> そして、そこでは力あるわざを一つもすることができず、ただ少数の病人に手をおいていやされただけであった。</span>
<span className="v" id="v6" data-v="6" data-xref="マタイによる福音書 9:35; マタイによる福音書 8:10; ルカによる福音書 13:22"> そして、彼らの不信仰を驚き怪しまれた。<br />それからイエスは、附近の村々を巡りあるいて教えられた。</span>
<span className="v" id="v7" data-v="7" data-xref="伝道の書 4:9–10; ルカによる福音書 10:17–20; マタイによる福音書 10:1–5"> また十二弟子を呼び寄せ、ふたりずつつかわすことにして、彼らにけがれた霊を制する権威を与え、</span>
<span className="v" id="v8" data-v="8" data-xref="ルカによる福音書 9:3; マタイによる福音書 10:9–10; ルカによる福音書 10:4"> また旅のために、つえ一本のほかには何も持たないように、パンも、袋も、帯の中に銭も持たず、</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行伝 12:8; エペソ人への手紙 6:15"> ただわらじをはくだけで、下着も二枚は着ないように命じられた。</span>
<span className="v" id="v10" data-v="10" data-xref="ルカによる福音書 10:7–8; ルカによる福音書 9:4; マタイによる福音書 10:11–13"> そして彼らに言われた、「どこへ行っても、家にはいったなら、その土地を去るまでは、そこにとどまっていなさい。</span>
<span className="v" id="v11" data-v="11" data-xref="マタイによる福音書 10:14–15; 使徒行伝 18:6; ルカによる福音書 10:10–15"> また、あなたがたを迎えず、あなたがたの話を聞きもしない所があったなら、そこから出て行くとき、彼らに対する抗議のしるしに、足の裏のちりを払い落しなさい」。</span>
<span className="v" id="v12" data-v="12" data-xref="マタイによる福音書 4:17; ルカによる福音書 13:3; 使徒行伝 20:21"> そこで、彼らは出て行って、悔改めを宣べ伝え、</span>
<span className="v" id="v13" data-v="13" data-xref="ヤコブの手紙 5:14–15; マルコによる福音書 6:7; ルカによる福音書 10:17"> 多くの悪霊を追い出し、大ぜいの病人に油をぬっていやした。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="ルカによる福音書 9:7–9; マルコによる福音書 6:14–29; ルカによる福音書 23:7–12"> さて、イエスの名が知れわたって、ヘロデ王の耳にはいった。ある人々は「バプテスマのヨハネが、死人の中からよみがえってきたのだ。それで、あのような力が彼のうちに働いているのだ」と言い、</span>
<span className="v" id="v15" data-v="15" data-xref="マタイによる福音書 16:14; マラキ書 4:5; マタイによる福音書 21:11"> 他の人々は「彼はエリヤだ」と言い、また他の人々は「昔の預言者のような預言者だ」と言った。</span>
<span className="v" id="v16" data-v="16" data-xref="ヨハネの黙示録 11:10–13; マタイによる福音書 27:4; ルカによる福音書 9:9"> ところが、ヘロデはこれを聞いて、「わたしが首を切ったあのヨハネがよみがえったのだ」と言った。</span>
<span className="v" id="v17" data-v="17" data-xref="ルカによる福音書 3:19–20; マタイによる福音書 11:2; ルカによる福音書 3:1"> このヘロデは、自分の兄弟ピリポの妻ヘロデヤをめとったが、そのことで、人をつかわし、ヨハネを捕えて獄につないだ。</span>
<span className="v" id="v18" data-v="18" data-xref="レビ記 20:21; レビ記 18:16; 列王紀上 22:14"> それは、ヨハネがヘロデに、「兄弟の妻をめとるのは、よろしくない」と言ったからである。</span>
<span className="v" id="v19" data-v="19" data-xref="伝道の書 7:9; エペソ人への手紙 4:26–27; 創世記 39:17–20"> そこで、ヘロデヤはヨハネを恨み、彼を殺そうと思っていたが、できないでいた。</span>
<span className="v" id="v20" data-v="20" data-xref="マタイによる福音書 21:26; マタイによる福音書 14:5; 歴代志下 24:15–22"> それはヘロデが、ヨハネは正しくて聖なる人であることを知って、彼を恐れ、彼に保護を加え、またその教を聞いて非常に悩みながらも、なお喜んで聞いていたからである。</span>
<span className="v" id="v21" data-v="21" data-xref="エステル記 2:18; 創世記 40:20; ペテロの第一の手紙 4:3"> ところが、よい機会がきた。ヘロデは自分の誕生日の祝に、高官や将校やガリラヤの重立った人たちを招いて宴会を催したが、</span>
<span className="v" id="v22" data-v="22" data-xref="エステル記 1:10–12; マタイによる福音書 14:6; ダニエル書 5:2"> そこへ、このヘロデヤの娘がはいってきて舞をまい、ヘロデをはじめ列座の人たちを喜ばせた。そこで王はこの少女に「ほしいものはなんでも言いなさい。あなたにあげるから」と言い、</span>
<span className="v" id="v23" data-v="23" data-xref="エステル記 7:2; エステル記 5:3; エステル記 5:6"> さらに「ほしければ、この国の半分でもあげよう」と誓って言った。</span>
<span className="v" id="v24" data-v="24" data-xref="ヨブ記 31:31; エゼキエル書 19:2–3; 創世記 27:8–11"> そこで少女は座をはずして、母に「何をお願いしましょうか」と尋ねると、母は「バプテスマのヨハネの首を」と答えた。</span>
<span className="v" id="v25" data-v="25" data-xref="ローマ人への手紙 3:15; 民数記 7:19–89; 民数記 7:13"> するとすぐ、少女は急いで王のところに行って願った、「今すぐに、バプテスマのヨハネの首を盆にのせて、それをいただきとうございます」。</span>
<span className="v" id="v26" data-v="26" data-xref="マタイによる福音書 27:24–25; マタイによる福音書 14:9; マタイによる福音書 27:3–5"> 王は非常に困ったが、いったん誓ったのと、また列座の人たちの手前、少女の願いを退けることを好まなかった。</span>
<span className="v" id="v27" data-v="27" data-xref="マタイによる福音書 14:10–11"> そこで、王はすぐに衛兵をつかわし、ヨハネの首を持って来るように命じた。衛兵は出て行き、獄中でヨハネの首を切り、</span>
<span className="v" id="v28" data-v="28"> 盆にのせて持ってきて少女に与え、少女はそれを母にわたした。</span>
<span className="v" id="v29" data-v="29" data-xref="マタイによる福音書 14:12; 歴代志下 24:16; マタイによる福音書 27:57–60"> ヨハネの弟子たちはこのことを聞き、その死体を引き取りにきて、墓に納めた。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="ルカによる福音書 9:10; ルカによる福音書 10:17; マタイによる福音書 10:2"> さて、使徒たちはイエスのもとに集まってきて、自分たちがしたことや教えたことを、みな報告した。</span>
<span className="v" id="v31" data-v="31" data-xref="マルコによる福音書 3:20; ヨハネによる福音書 6:1; マルコによる福音書 1:45"> するとイエスは彼らに言われた、「さあ、あなたがたは、人を避けて寂しい所へ行って、しばらく休むがよい」。それは、出入りする人が多くて、食事をする暇もなかったからである。</span>
<span className="v" id="v32" data-v="32" data-xref="マルコによる福音書 8:2–9; マルコによる福音書 6:45; マルコによる福音書 4:36"> そこで彼らは人を避け、舟に乗って寂しい所へ行った。</span>
<span className="v" id="v33" data-v="33" data-xref="ヨハネによる福音書 6:2; マタイによる福音書 15:29–31; マルコによる福音書 6:54–55"> ところが、多くの人々は彼らが出かけて行くのを見、それと気づいて、方々の町々からそこへ、一せいに駆けつけ、彼らより先に着いた。</span>
<span className="v" id="v34" data-v="34" data-xref="マタイによる福音書 9:36; ルカによる福音書 9:11; 民数記 27:17"> イエスは舟から上がって大ぜいの群衆をごらんになり、飼う者のない羊のようなその有様を深くあわれんで、いろいろと教えはじめられた。</span>
<span className="v" id="v35" data-v="35" data-xref="ヨハネによる福音書 6:5–15; ルカによる福音書 9:12–17; マタイによる福音書 14:15–21"> ところが、はや時もおそくなったので、弟子たちはイエスのもとにきて言った、「ここは寂しい所でもあり、もう時もおそくなりました。</span>
<span className="v" id="v36" data-v="36" data-xref="マタイによる福音書 15:23; マルコによる福音書 3:21; マルコによる福音書 5:31"> みんなを解散させ、めいめいで何か食べる物を買いに、まわりの部落や村々へ行かせてください」。</span>
<span className="v" id="v37" data-v="37" data-xref="列王紀下 4:42–44; マタイによる福音書 15:32–33; マルコによる福音書 8:2–3"> イエスは答えて言われた、「あなたがたの手で食物をやりなさい」。弟子たちは言った、「わたしたちが二百デナリものパンを買ってきて、みんなに食べさせるのですか」。</span>
<span className="v" id="v38" data-v="38" data-xref="マタイによる福音書 15:34; マルコによる福音書 8:5; ヨハネによる福音書 6:9"> するとイエスは言われた、「パンは幾つあるか。見てきなさい」。彼らは確かめてきて、「五つあります。それに魚が二ひき」と言った。</span>
<span className="v" id="v39" data-v="39" data-xref="コリント人への第一の手紙 14:40; コリント人への第一の手紙 14:33; マタイによる福音書 15:35"> そこでイエスは、みんなを組々に分けて、青草の上にすわらせるように命じられた。</span>
<span className="v" id="v40" data-v="40" data-xref="ルカによる福音書 9:14–15"> 人々は、あるいは百人ずつ、あるいは五十人ずつ、列をつくってすわった。</span>
<span className="v" id="v41" data-v="41" data-xref="マタイによる福音書 14:19; マルコによる福音書 7:34; ルカによる福音書 9:16"> それから、イエスは五つのパンと二ひきの魚とを手に取り、天を仰いでそれを祝福し、パンをさき、弟子たちにわたして配らせ、また、二ひきの魚もみんなにお分けになった。</span>
<span className="v" id="v42" data-v="42" data-xref="ルカによる福音書 9:17; マルコによる福音書 8:8–9; マタイによる福音書 15:37–38"> みんなの者は食べて満腹した。</span>
<span className="v" id="v43" data-v="43" data-xref="マルコによる福音書 8:19–20"> そこで、パンくずや魚の残りを集めると、十二のかごにいっぱいになった。</span>
<span className="v" id="v44" data-v="44"> パンを食べた者は男五千人であった。</span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="マタイによる福音書 14:22–33; ヨハネによる福音書 6:15–21; マルコによる福音書 6:32"> それからすぐ、イエスは自分で群衆を解散させておられる間に、しいて弟子たちを舟に乗り込ませ、向こう岸のベツサイダへ先におやりになった。</span>
<span className="v" id="v46" data-v="46" data-xref="マルコによる福音書 1:35; マタイによる福音書 6:6; ルカによる福音書 6:12"> そして群衆に別れてから、祈るために山へ退かれた。</span>
<span className="v" id="v47" data-v="47" data-xref="マタイによる福音書 14:23; ヨハネによる福音書 6:16–17"> 夕方になったとき、舟は海のまん中に出ており、イエスだけが陸地におられた。</span>
<span className="v" id="v48" data-v="48" data-xref="ルカによる福音書 24:28; ルカによる福音書 12:38; ヨブ記 9:8"> ところが逆風が吹いていたために、弟子たちがこぎ悩んでいるのをごらんになって、夜明けの四時ごろ、海の上を歩いて彼らに近づき、そのそばを通り過ぎようとされた。</span>
<span className="v" id="v49" data-v="49" data-xref="マタイによる福音書 14:25–26; ルカによる福音書 24:37; ヨブ記 9:8"> 彼らはイエスが海の上を歩いておられるのを見て、幽霊だと思い、大声で叫んだ。</span>
<span className="v" id="v50" data-v="50" data-xref="マタイによる福音書 14:27; ヨハネによる福音書 6:19–20; イザヤ書 43:2"> みんなの者がそれを見て、おじ恐れたからである。しかし、イエスはすぐ彼らに声をかけ、「しっかりするのだ。わたしである。恐れることはない」と言われた。</span>
<span className="v" id="v51" data-v="51" data-xref="詩篇 93:3–4; マルコによる福音書 4:39; ヨハネによる福音書 6:21"> そして、彼らの舟に乗り込まれると、風はやんだ。彼らは心の中で、非常に驚いた。</span>
<span className="v" id="v52" data-v="52" data-xref="マルコによる福音書 8:17–21; ルカによる福音書 24:25; イザヤ書 63:17"> 先のパンのことを悟らず、その心が鈍くなっていたからである。</span>
</div>
<div className="bp">
<span className="v" id="v53" data-v="53" data-xref="マタイによる福音書 14:34–36; ヨハネによる福音書 6:24–25; ルカによる福音書 5:1"> 彼らは海を渡り、ゲネサレの地に着いて舟をつないだ。</span>
<span className="v" id="v54" data-v="54" data-xref="詩篇 9:10; ピリピ人への手紙 3:10"> そして舟からあがると、人々はすぐイエスと知って、</span>
<span className="v" id="v55" data-v="55" data-xref="マタイによる福音書 4:24; マルコによる福音書 2:1–3; マルコによる福音書 3:7–11"> その地方をあまねく駆けめぐり、イエスがおられると聞けば、どこへでも病人を床にのせて運びはじめた。</span>
<span className="v" id="v56" data-v="56" data-xref="マタイによる福音書 9:20; ルカによる福音書 6:19; 民数記 15:38–39"> そして、村でも町でも部落でも、イエスがはいって行かれる所では、病人たちをその広場におき、せめてその上着のふさにでも、さわらせてやっていただきたいと、お願いした。そしてさわった者は皆いやされた。</span>
</div>

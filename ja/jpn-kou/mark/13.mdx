<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マタイによる福音書 24:1–51; エゼキエル書 11:22–23; エゼキエル書 10:19"> イエスが宮から出て行かれるとき、弟子のひとりが言った、「先生、ごらんなさい。なんという見事な石、なんという立派な建物でしょう」。</span>
<span className="v" id="v2" data-v="2" data-xref="ルカによる福音書 21:6; マタイによる福音書 24:2; 列王紀上 9:7–8"> イエスは言われた、「あなたは、これらの大きな建物をながめているのか。その石一つでもくずされないままで、他の石の上に残ることもなくなるであろう」。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="マタイによる福音書 21:1; マルコによる福音書 4:34; マルコによる福音書 14:33"> またオリブ山で、宮にむかってすわっておられると、ペテロ、ヤコブ、ヨハネ、アンデレが、ひそかにお尋ねした。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行伝 1:6–7; マタイによる福音書 24:3; ダニエル書 12:6"> 「わたしたちにお話しください。いつ、そんなことが起るのでしょうか。またそんなことがことごとく成就するような場合には、どんな前兆がありますか」。</span>
<span className="v" id="v5" data-v="5" data-xref="コロサイ人への手紙 2:8; エペソ人への手紙 5:6; エレミヤ書 29:8"> そこで、イエスは話しはじめられた、「人に惑わされないように気をつけなさい。</span>
<span className="v" id="v6" data-v="6" data-xref="マルコによる福音書 13:22; エレミヤ書 23:21–25; ヨハネによる福音書 8:24"> 多くの者がわたしの名を名のって現れ、自分がそれだと言って、多くの人を惑わすであろう。</span>
<span className="v" id="v7" data-v="7" data-xref="ルカによる福音書 21:9–11; ヨハネによる福音書 14:27; マタイによる福音書 24:6–7"> また、戦争と戦争のうわさとを聞くときにも、あわてるな。それは起らねばならないが、まだ終りではない。</span>
<span className="v" id="v8" data-v="8" data-xref="マタイによる福音書 24:8; イザヤ書 37:3; 詩篇 48:6"> 民は民に、国は国に敵対して立ち上がるであろう。またあちこちに地震があり、またききんが起るであろう。これらは産みの苦しみの初めである。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="マタイによる福音書 10:17–18; ヨハネによる福音書 16:2; ピリピ人への手紙 1:29"> あなたがたは自分で気をつけていなさい。あなたがたは、わたしのために、衆議所に引きわたされ、会堂で打たれ、長官たちや王たちの前に立たされ、彼らに対してあかしをさせられるであろう。</span>
<span className="v" id="v10" data-v="10" data-xref="マタイによる福音書 24:14; コロサイ人への手紙 1:23; ローマ人への手紙 10:18"> こうして、福音はまずすべての民に宣べ伝えられねばならない。</span>
<span className="v" id="v11" data-v="11" data-xref="ルカによる福音書 21:14–15; ルカによる福音書 12:11–12; マタイによる福音書 10:19–21"> そして、人々があなたがたを連れて行って引きわたすとき、何を言おうかと、前もって心配するな。その場合、自分に示されることを語るがよい。語る者はあなたがた自身ではなくて、聖霊である。</span>
<span className="v" id="v12" data-v="12" data-xref="マタイによる福音書 10:21; ルカによる福音書 12:52–53; ルカによる福音書 21:16"> また兄弟は兄弟を、父は子を殺すために渡し、子は両親に逆らって立ち、彼らを殺させるであろう。</span>
<span className="v" id="v13" data-v="13" data-xref="ヨハネによる福音書 15:18–19; マタイによる福音書 10:22; マタイによる福音書 24:13"> また、あなたがたはわたしの名のゆえに、すべての人に憎まれるであろう。しかし、最後まで耐え忍ぶ者は救われる。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="ダニエル書 9:27; ダニエル書 12:11; ダニエル書 11:31"> 荒らす憎むべきものが、立ってはならぬ所に立つのを見たならば（読者よ、悟れ）、そのとき、ユダヤにいる人々は山へ逃げよ。</span>
<span className="v" id="v15" data-v="15" data-xref="ルカによる福音書 17:31–33; ヘブル人への手紙 11:7; ピリピ人への手紙 3:7–8"> 屋上にいる者は、下におりるな。また家から物を取り出そうとして内にはいるな。</span>
<span className="v" id="v16" data-v="16"> 畑にいる者は、上着を取りにあとへもどるな。</span>
<span className="v" id="v17" data-v="17" data-xref="哀歌 4:10; ルカによる福音書 23:29; ホセア書 9:14"> その日には、身重の女と乳飲み子をもつ女とは、不幸である。</span>
<span className="v" id="v18" data-v="18"> この事が冬おこらぬように祈れ。</span>
<span className="v" id="v19" data-v="19" data-xref="ダニエル書 12:1; ヨエル書 2:2; マタイによる福音書 24:21"> その日には、神が万物を造られた創造の初めから現在に至るまで、かつてなく今後もないような患難が起るからである。</span>
<span className="v" id="v20" data-v="20" data-xref="マタイによる福音書 24:22; ゼカリヤ書 13:8–9; イザヤ書 65:8–9"> もし主がその期間を縮めてくださらないなら、救われる者はひとりもないであろう。しかし、選ばれた選民のために、その期間を縮めてくださったのである。</span>
<span className="v" id="v21" data-v="21" data-xref="ルカによる福音書 21:8; マタイによる福音書 24:23–25; マタイによる福音書 24:5"> そのとき、だれかがあなたがたに『見よ、ここにキリストがいる』、『見よ、あそこにいる』と言っても、それを信じるな。</span>
<span className="v" id="v22" data-v="22" data-xref="マタイによる福音書 24:24; テサロニケ人への第二の手紙 2:8–14; マルコによる福音書 13:6"> にせキリストたちや、にせ預言者たちが起って、しるしと奇跡とを行い、できれば、選民をも惑わそうとするであろう。</span>
<span className="v" id="v23" data-v="23" data-xref="ペテロの第二の手紙 3:17; マルコによる福音書 13:5; ヨハネによる福音書 14:29"> だから、気をつけていなさい。いっさいの事を、あなたがたに前もって言っておく。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="イザヤ書 13:10; 使徒行伝 2:19–20; ヨハネの黙示録 6:12–14"> その日には、この患難の後、日は暗くなり、月はその光を放つことをやめ、</span>
<span className="v" id="v25" data-v="25" data-xref="イザヤ書 34:4; ヨハネの黙示録 6:13"> 星は空から落ち、天体は揺り動かされるであろう。</span>
<span className="v" id="v26" data-v="26" data-xref="ヨハネの黙示録 1:7; マタイによる福音書 16:27; マタイによる福音書 24:30"> そのとき、大いなる力と栄光とをもって、人の子が雲に乗って来るのを、人々は見るであろう。</span>
<span className="v" id="v27" data-v="27" data-xref="ゼカリヤ書 2:6; マタイによる福音書 24:31; 申命記 30:4"> そのとき、彼は御使たちをつかわして、地のはてから天のはてまで、四方からその選民を呼び集めるであろう。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="ルカによる福音書 21:29–31; マタイによる福音書 24:32–33"> いちじくの木からこの譬を学びなさい。その枝が柔らかになり、葉が出るようになると、夏の近いことがわかる。</span>
<span className="v" id="v29" data-v="29" data-xref="ペテロの第一の手紙 4:17–18; ヤコブの手紙 5:9; エゼキエル書 12:25–28"> そのように、これらの事が起るのを見たならば、人の子が戸口まで近づいていると知りなさい。</span>
<span className="v" id="v30" data-v="30" data-xref="マタイによる福音書 24:34; ルカによる福音書 21:32; マタイによる福音書 16:28"> よく聞いておきなさい。これらの事が、ことごとく起るまでは、この時代は滅びることがない。</span>
<span className="v" id="v31" data-v="31" data-xref="イザヤ書 40:8; イザヤ書 51:6; マタイによる福音書 24:35"> 天地は滅びるであろう。しかしわたしの言葉は滅びることがない。</span>
<span className="v" id="v32" data-v="32" data-xref="使徒行伝 1:7; マタイによる福音書 24:36–42; マタイによる福音書 25:13"> その日、その時は、だれも知らない。天にいる御使たちも、また子も知らない、ただ父だけが知っておられる。</span>
<span className="v" id="v33" data-v="33" data-xref="エペソ人への手紙 6:18; ルカによる福音書 12:40; ローマ人への手紙 13:11–12"> 気をつけて、目をさましていなさい。その時がいつであるか、あなたがたにはわからないからである。</span>
<span className="v" id="v34" data-v="34" data-xref="マタイによる福音書 25:14–30; ヨハネによる福音書 10:3; ルカによる福音書 12:36–40"> それはちょうど、旅に立つ人が家を出るに当り、その僕たちに、それぞれ仕事を割り当てて責任をもたせ、門番には目をさましておれと、命じるようなものである。</span>
<span className="v" id="v35" data-v="35" data-xref="マルコによる福音書 13:33; マタイによる福音書 24:42; マタイによる福音書 24:44"> だから、目をさましていなさい。いつ、家の主人が帰って来るのか、夕方か、夜中か、にわとりの鳴くころか、明け方か、わからないからである。</span>
<span className="v" id="v36" data-v="36" data-xref="テサロニケ人への第一の手紙 5:6–7; ローマ人への手紙 13:11–14; マタイによる福音書 24:48–51"> あるいは急に帰ってきて、あなたがたの眠っているところを見つけるかも知れない。</span>
<span className="v" id="v37" data-v="37" data-xref="マルコによる福音書 13:33; ルカによる福音書 12:41–46; マルコによる福音書 13:35"> 目をさましていなさい。わたしがあなたがたに言うこの言葉は、すべての人々に言うのである」。</span>
</div>

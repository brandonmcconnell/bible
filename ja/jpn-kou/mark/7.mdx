<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="マタイによる福音書 15:1–20; マルコによる福音書 3:22; ルカによる福音書 5:17"> さて、パリサイ人と、ある律法学者たちとが、エルサレムからきて、イエスのもとに集まった。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行伝 10:28; マタイによる福音書 7:3–5; ローマ人への手紙 14:14"> そして弟子たちのうちに、不浄な手、すなわち洗わない手で、パンを食べている者があるのを見た。</span>
<span className="v" id="v3" data-v="3" data-xref="ガラテヤ人への手紙 1:14; マルコによる福音書 7:13; コロサイ人への手紙 2:8"> もともと、パリサイ人をはじめユダヤ人はみな、昔の人の言伝えをかたく守って、念入りに手を洗ってからでないと、食事をしない。</span>
<span className="v" id="v4" data-v="4" data-xref="ヘブル人への手紙 9:10; マタイによる福音書 23:25; ルカによる福音書 11:38–39"> また市場から帰ったときには、身を清めてからでないと、食事をせず、なおそのほかにも、杯、鉢、銅器を洗うことなど、昔から受けついでかたく守っている事が、たくさんあった。</span>
<span className="v" id="v5" data-v="5" data-xref="テサロニケ人への第二の手紙 3:6; 使徒行伝 21:21; マタイによる福音書 15:2"> そこで、パリサイ人と律法学者たちとは、イエスに尋ねた、「なぜ、あなたの弟子たちは、昔の人の言伝えに従って歩まないで、不浄な手でパンを食べるのですか」。</span>
<span className="v" id="v6" data-v="6" data-xref="イザヤ書 29:13; テトスヘの手紙 1:16; マタイによる福音書 15:7–9"> イエスは言われた、「イザヤは、あなたがた偽善者について、こう書いているが、それは適切な預言である、<br /><span className="pl pl-1">『この民は、口さきではわたしを敬うが、</span><br /><span className="pl pl-1">その心はわたしから遠く離れている。</span></span>
<span className="v" id="v7" data-v="7" data-xref="イザヤ書 29:13; マタイによる福音書 15:9; ヤコブの手紙 1:26"> <span className="pl pl-1">人間のいましめを教として教え、</span><br /><span className="pl pl-1">無意味にわたしを拝んでいる』。</span></span>
<span className="v" id="v8" data-v="8" data-xref="マルコによる福音書 7:3–4; イザヤ書 1:12"> <span className="pl pl-1">あなたがたは、神のいましめをさしおいて、人間の言伝えを固執している」。</span></span>
<span className="v" id="v9" data-v="9" data-xref="エレミヤ書 44:16–17; ガラテヤ人への手紙 2:21; イザヤ書 29:13"> <span className="pl pl-1">また、言われた、「あなたがたは、自分たちの言伝えを守るために、よくも神のいましめを捨てたものだ。</span></span>
<span className="v" id="v10" data-v="10" data-xref="出エジプト記 21:17; 出エジプト記 20:12; 申命記 5:16"> <span className="pl pl-1">モーセは言ったではないか、『父と母とを敬え』、また『父または母をののしる者は、必ず死に定められる』と。</span></span>
<span className="v" id="v11" data-v="11" data-xref="マタイによる福音書 23:18; テモテヘの第一の手紙 5:4–8; マタイによる福音書 15:5"> <span className="pl pl-1">それだのに、あなたがたは、もし人が父または母にむかって、あなたに差上げるはずのこのものはコルバン、すなわち、供え物ですと言えば、それでよいとして、</span></span>
<span className="v" id="v12" data-v="12"> <span className="pl pl-1">その人は父母に対して、もう何もしないで済むのだと言っている。</span></span>
<span className="v" id="v13" data-v="13" data-xref="マルコによる福音書 7:9; テトスヘの手紙 1:14; マタイによる福音書 5:17–20"> <span className="pl pl-1">こうしてあなたがたは、自分たちが受けついだ言伝えによって、神の言を無にしている。また、このような事をしばしばおこなっている」。</span></span>
<span className="v" id="v14" data-v="14" data-xref="マタイによる福音書 15:10; イザヤ書 6:9; 箴言 8:5"> <span className="pl pl-1">それから、イエスは再び群衆を呼び寄せて言われた、「あなたがたはみんな、わたしの言うことを聞いて悟るがよい。</span></span>
<span className="v" id="v15" data-v="15" data-xref="箴言 4:23; レビ記 11:42–47; テトスヘの手紙 1:15"> <span className="pl pl-1">すべて外から人の中にはいって、人をけがしうるものはない。かえって、人の中から出てくるものが、人をけがすのである。〔</span></span>
<span className="v" id="v16" data-v="16"> <span className="pl pl-1">聞く耳のある者は聞くがよい〕」。</span></span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="マタイによる福音書 15:15; マタイによる福音書 13:36; マルコによる福音書 9:28"> イエスが群衆を離れて家にはいられると、弟子たちはこの譬について尋ねた。</span>
<span className="v" id="v18" data-v="18" data-xref="マタイによる福音書 15:16–17; ヘブル人への手紙 5:11; イザヤ書 28:9–10"> すると、言われた、「あなたがたも、そんなに鈍いのか。すべて、外から人の中にはいって来るものは、人を汚し得ないことが、わからないのか。</span>
<span className="v" id="v19" data-v="19" data-xref="マタイによる福音書 15:17; コリント人への第一の手紙 6:13; コロサイ人への手紙 2:21–22"> それは人の心の中にはいるのではなく、腹の中にはいり、そして、外に出て行くだけである」。イエスはこのように、どんな食物でもきよいものとされた。</span>
<span className="v" id="v20" data-v="20" data-xref="ヤコブの手紙 3:6; ヤコブの手紙 1:14–15; ヤコブの手紙 4:1"> さらに言われた、「人から出て来るもの、それが人をけがすのである。</span>
<span className="v" id="v21" data-v="21" data-xref="エレミヤ書 17:9; ローマ人への手紙 8:7–8; ヤコブの手紙 4:1–3"> すなわち内部から、人の心の中から、悪い思いが出て来る。不品行、盗み、殺人、</span>
<span className="v" id="v22" data-v="22" data-xref="マタイによる福音書 20:15; マタイによる福音書 6:23; ペテロの第一の手紙 2:15"> 姦淫、貪欲、邪悪、欺き、好色、妬み、誹り、高慢、愚痴。</span>
<span className="v" id="v23" data-v="23" data-xref="マルコによる福音書 7:15; テトスヘの手紙 1:15; コリント人への第一の手紙 3:17"> これらの悪はすべて内部から出てきて、人をけがすのである」。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="マタイによる福音書 15:21–28; マタイによる福音書 11:21; エゼキエル書 28:2"> さて、イエスは、そこを立ち去って、ツロの地方に行かれた。そして、だれにも知れないように、家の中にはいられたが、隠れていることができなかった。</span>
<span className="v" id="v25" data-v="25" data-xref="マタイによる福音書 15:22; マルコによる福音書 9:17–23; 使徒行伝 10:25–26"> そして、けがれた霊につかれた幼い娘をもつ女が、イエスのことをすぐ聞きつけてきて、その足もとにひれ伏した。</span>
<span className="v" id="v26" data-v="26" data-xref="マタイによる福音書 15:22; イザヤ書 49:12; ガラテヤ人への手紙 3:28"> この女はギリシヤ人で、スロ・フェニキヤの生れであった。そして、娘から悪霊を追い出してくださいとお願いした。</span>
<span className="v" id="v27" data-v="27" data-xref="マタイによる福音書 15:23–28; マタイによる福音書 7:6; 使徒行伝 22:21"> イエスは女に言われた、「まず子供たちに十分食べさすべきである。子供たちのパンを取って小犬に投げてやるのは、よろしくない」。</span>
<span className="v" id="v28" data-v="28" data-xref="ローマ人への手紙 10:12; ローマ人への手紙 3:29; 使徒行伝 11:17–18"> すると、女は答えて言った、「主よ、お言葉どおりです。でも、食卓の下にいる小犬も、子供たちのパンくずは、いただきます」。</span>
<span className="v" id="v29" data-v="29" data-xref="イザヤ書 66:2; マタイによる福音書 5:3; ヨハネの第一の手紙 3:8"> そこでイエスは言われた、「その言葉で、じゅうぶんである。お帰りなさい。悪霊は娘から出てしまった」。</span>
<span className="v" id="v30" data-v="30" data-xref="ヨハネの第一の手紙 3:8; ヨハネによる福音書 4:50–52"> そこで、女が家に帰ってみると、その子は床の上に寝ており、悪霊は出てしまっていた。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="マルコによる福音書 5:20; マタイによる福音書 15:29–31; マタイによる福音書 4:25"> それから、イエスはまたツロの地方を去り、シドンを経てデカポリス地方を通りぬけ、ガリラヤの海べにこられた。</span>
<span className="v" id="v32" data-v="32" data-xref="ルカによる福音書 11:14; マルコによる福音書 5:23; マタイによる福音書 9:32–33"> すると人々は、耳が聞えず口のきけない人を、みもとに連れてきて、手を置いてやっていただきたいとお願いした。</span>
<span className="v" id="v33" data-v="33" data-xref="マルコによる福音書 8:23; ヨハネによる福音書 9:6–7; マルコによる福音書 5:40"> そこで、イエスは彼ひとりを群衆の中から連れ出し、その両耳に指をさし入れ、それから、つばきでその舌を潤し、</span>
<span className="v" id="v34" data-v="34" data-xref="ヨハネによる福音書 11:41; マルコによる福音書 5:41; マルコによる福音書 6:41"> 天を仰いでため息をつき、その人に「エパタ」と言われた。これは「開けよ」という意味である。</span>
<span className="v" id="v35" data-v="35" data-xref="イザヤ書 35:5–6; 詩篇 33:9; マルコによる福音書 2:12"> すると彼の耳が開け、その舌のもつれもすぐ解けて、はっきりと話すようになった。</span>
<span className="v" id="v36" data-v="36" data-xref="マタイによる福音書 8:4; マルコによる福音書 8:26; マルコによる福音書 3:12"> イエスは、この事をだれにも言ってはならぬと、人々に口止めをされたが、口止めをすればするほど、かえって、ますます言いひろめた。</span>
<span className="v" id="v37" data-v="37" data-xref="マルコによる福音書 6:51; マルコによる福音書 5:42; 出エジプト記 4:10–11"> 彼らは、ひとかたならず驚いて言った、「このかたのなさった事は、何もかも、すばらしい。耳の聞えない者を聞えるようにしてやり、口のきけない者をきけるようにしておやりになった」。</span>
</div>

<div className="bible-chapter" lang="ja" dir="ltr" data-lang="ja" data-translation="jpn-kou" data-translation-id="jpn_kou" data-translation-label="口語訳" data-book="MRK" data-book-slug="mark" data-book-name="マルコによる福音書" data-chapter="15" data-verses="47">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マタイによる福音書 27:1–2; ルカによる福音書 23:1–5; ルカによる福音書 22:66"> 夜が明けるとすぐ、祭司長たちは長老、律法学者たち、および全議会と協議をこらした末、イエスを縛って引き出し、ピラトに渡した。</span>
<span className="v" id="v2" data-v="2" data-xref="マタイによる福音書 2:2; マタイによる福音書 27:11–14; テモテヘの第一の手紙 6:13"> ピラトはイエスに尋ねた、「あなたがユダヤ人の王であるか」。イエスは、「そのとおりである」とお答えになった。</span>
<span className="v" id="v3" data-v="3" data-xref="イザヤ書 53:7; マルコによる福音書 15:5; ヨハネによる福音書 18:29–31"> そこで祭司長たちは、イエスのことをいろいろと訴えた。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネによる福音書 19:10; マタイによる福音書 27:13; マタイによる福音書 26:62"> ピラトはもう一度イエスに尋ねた、「何も答えないのか。見よ、あなたに対してあんなにまで次々に訴えているではないか」。</span>
<span className="v" id="v5" data-v="5" data-xref="イザヤ書 53:7; ゼカリヤ書 3:8; 詩篇 71:7"> しかし、イエスはピラトが不思議に思うほどに、もう何もお答えにならなかった。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="ヨハネによる福音書 18:39–40; 使徒行伝 25:9; 使徒行伝 24:27"> さて、祭のたびごとに、ピラトは人々が願い出る囚人ひとりを、ゆるしてやることにしていた。</span>
<span className="v" id="v7" data-v="7" data-xref="ルカによる福音書 23:18–19; マタイによる福音書 27:16; ルカによる福音書 23:25"> ここに、暴動を起し人殺しをしてつながれていた暴徒の中に、バラバという者がいた。</span>
<span className="v" id="v8" data-v="8"> 群衆が押しかけてきて、いつものとおりにしてほしいと要求しはじめたので、</span>
<span className="v" id="v9" data-v="9" data-xref="ヨハネによる福音書 19:14–16; ヨハネによる福音書 19:4–5; ヨハネによる福音書 18:39"> ピラトは彼らにむかって、「おまえたちはユダヤ人の王をゆるしてもらいたいのか」と言った。</span>
<span className="v" id="v10" data-v="10" data-xref="箴言 27:4; テトスヘの手紙 3:3; 創世記 4:4–6"> それは、祭司長たちがイエスを引きわたしたのは、ねたみのためであることが、ピラトにわかっていたからである。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行伝 3:14; ヨハネによる福音書 18:40; ホセア書 5:1"> しかし祭司長たちは、バラバの方をゆるしてもらうように、群衆を煽動した。</span>
<span className="v" id="v12" data-v="12" data-xref="エレミヤ書 23:5–6; イザヤ書 9:6–7; ゼカリヤ書 9:9"> そこでピラトはまた彼らに言った、「それでは、おまえたちがユダヤ人の王と呼んでいるあの人は、どうしたらよいか」。</span>
<span className="v" id="v13" data-v="13"> 彼らは、また叫んだ、「十字架につけよ」。</span>
<span className="v" id="v14" data-v="14" data-xref="ルカによる福音書 23:41; ルカによる福音書 23:23–24; イザヤ書 53:3"> ピラトは言った、「あの人は、いったい、どんな悪事をしたのか」。すると、彼らは一そう激しく叫んで、「十字架につけよ」と言った。</span>
<span className="v" id="v15" data-v="15" data-xref="ヨハネによる福音書 19:1; マタイによる福音書 27:26; イザヤ書 50:6"> それで、ピラトは群衆を満足させようと思って、バラバをゆるしてやり、イエスをむち打ったのち、十字架につけるために引きわたした。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="ヨハネによる福音書 19:9; マタイによる福音書 27:27–31; ヨハネによる福音書 18:28"> 兵士たちはイエスを、邸宅、すなわち総督官邸の内に連れて行き、全部隊を呼び集めた。</span>
<span className="v" id="v17" data-v="17" data-xref="マタイによる福音書 27:28–30; ヨハネによる福音書 19:2–5; ルカによる福音書 23:11"> そしてイエスに紫の衣を着せ、いばらの冠を編んでかぶらせ、</span>
<span className="v" id="v18" data-v="18" data-xref="マタイによる福音書 27:42–43; マルコによる福音書 15:2; 創世記 37:10"> 「ユダヤ人の王、ばんざい」と言って敬礼をしはじめた。</span>
<span className="v" id="v19" data-v="19" data-xref="マルコによる福音書 14:65; イザヤ書 53:3–5; ルカによる福音書 23:11"> また、葦の棒でその頭をたたき、つばきをかけ、ひざまずいて拝んだりした。</span>
<span className="v" id="v20" data-v="20" data-xref="ヨハネによる福音書 19:16; マタイによる福音書 27:31"> こうして、イエスを嘲弄したあげく、紫の衣をはぎとり、元の上着を着せた。それから、彼らはイエスを十字架につけるために引き出した。</span>
<span className="v" id="v21" data-v="21" data-xref="マタイによる福音書 27:32; ルカによる福音書 23:26; ローマ人への手紙 16:13"> そこへ、アレキサンデルとルポスとの父シモンというクレネ人が、郊外からきて通りかかったので、人々はイエスの十字架を無理に負わせた。</span>
<span className="v" id="v22" data-v="22" data-xref="マタイによる福音書 27:33–44; ヨハネによる福音書 19:17–27; ルカによる福音書 23:27–38"> そしてイエスをゴルゴタ、その意味は、されこうべ、という所に連れて行った。</span>
<span className="v" id="v23" data-v="23" data-xref="マタイによる福音書 27:34; ヨハネによる福音書 19:28–30; ルカによる福音書 23:36"> そしてイエスに、没薬をまぜたぶどう酒をさし出したが、お受けにならなかった。</span>
<span className="v" id="v24" data-v="24" data-xref="ルカによる福音書 23:34; ヨハネによる福音書 19:23–24; マタイによる福音書 27:35–36"> それから、イエスを十字架につけた。そしてくじを引いて、だれが何を取るかを定めたうえ、イエスの着物を分けた。</span>
<span className="v" id="v25" data-v="25" data-xref="ヨハネによる福音書 19:14; マルコによる福音書 15:33; マタイによる福音書 27:45"> イエスを十字架につけたのは、朝の九時ごろであった。</span>
<span className="v" id="v26" data-v="26" data-xref="マタイによる福音書 27:37; マタイによる福音書 2:2; ヨハネによる福音書 19:18–22"> イエスの罪状書きには「ユダヤ人の王」と、しるしてあった。</span>
<span className="v" id="v27" data-v="27" data-xref="ルカによる福音書 23:32–33; マタイによる福音書 27:38; ヨハネによる福音書 19:18"> また、イエスと共にふたりの強盗を、ひとりを右に、ひとりを左に、十字架につけた。〔</span>
<span className="v" id="v28" data-v="28"> こうして「彼は罪人たちのひとりに数えられた」と書いてある言葉が成就したのである。〕</span>
<span className="v" id="v29" data-v="29" data-xref="マルコによる福音書 14:58; 詩篇 109:25; 哀歌 1:12"> そこを通りかかった者たちは、頭を振りながら、イエスをののしって言った、「ああ、神殿を打ちこわして三日のうちに建てる者よ、</span>
<span className="v" id="v30" data-v="30"> 十字架からおりてきて自分を救え」。</span>
<span className="v" id="v31" data-v="31" data-xref="ヨハネによる福音書 12:23–24; マタイによる福音書 27:41–43; ルカによる福音書 23:35–37"> 祭司長たちも同じように、律法学者たちと一緒になって、かわるがわる嘲弄して言った、「他人を救ったが、自分自身を救うことができない。</span>
<span className="v" id="v32" data-v="32" data-xref="マタイによる福音書 27:44; ルカによる福音書 23:39–43; ゼカリヤ書 9:9"> イスラエルの王キリスト、いま十字架からおりてみるがよい。それを見たら信じよう」。また、一緒に十字架につけられた者たちも、イエスをののしった。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="マタイによる福音書 27:45; ルカによる福音書 23:44–45; アモス書 8:9–10"> 昼の十二時になると、全地は暗くなって、三時に及んだ。</span>
<span className="v" id="v34" data-v="34" data-xref="詩篇 22:1; マタイによる福音書 27:46; ヘブル人への手紙 5:7"> そして三時に、イエスは大声で、「エロイ、エロイ、ラマ、サバクタニ」と叫ばれた。それは「わが神、わが神、どうしてわたしをお見捨てになったのですか」という意味である。</span>
<span className="v" id="v35" data-v="35" data-xref="マタイによる福音書 27:47–49; マルコによる福音書 9:11–13; マタイによる福音書 17:11–13"> すると、そばに立っていたある人々が、これを聞いて言った、「そら、エリヤを呼んでいる」。</span>
<span className="v" id="v36" data-v="36" data-xref="詩篇 69:21; マルコによる福音書 15:23; ヨハネによる福音書 19:28–30"> ひとりの人が走って行き、海綿に酢いぶどう酒を含ませて葦の棒につけ、イエスに飲ませようとして言った、「待て、エリヤが彼をおろしに来るかどうか、見ていよう」。</span>
<span className="v" id="v37" data-v="37" data-xref="ヨハネによる福音書 19:30; ルカによる福音書 23:46; マタイによる福音書 27:50"> イエスは声高く叫んで、ついに息をひきとられた。</span>
<span className="v" id="v38" data-v="38" data-xref="ヘブル人への手紙 10:19–23; ルカによる福音書 23:45; ヘブル人への手紙 9:3–12"> そのとき、神殿の幕が上から下まで真二つに裂けた。</span>
<span className="v" id="v39" data-v="39" data-xref="マタイによる福音書 27:54; ルカによる福音書 23:47–48; マタイによる福音書 27:43"> イエスにむかって立っていた百卒長は、このようにして息をひきとられたのを見て言った、「まことに、この人は神の子であった」。</span>
<span className="v" id="v40" data-v="40" data-xref="ルカによる福音書 23:49; ルカによる福音書 8:2–3; マタイによる福音書 27:55–56"> また、遠くの方から見ている女たちもいた。その中には、マグダラのマリヤ、小ヤコブとヨセとの母マリヤ、またサロメがいた。</span>
<span className="v" id="v41" data-v="41" data-xref="ルカによる福音書 8:2–3; マタイによる福音書 27:55–56"> 彼らはイエスがガリラヤにおられたとき、そのあとに従って仕えた女たちであった。なおそのほか、イエスと共にエルサレムに上ってきた多くの女たちもいた。</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="ルカによる福音書 23:50–56; ヨハネによる福音書 19:38–42; ヨハネによる福音書 19:31"> さて、すでに夕がたになったが、その日は準備の日、すなわち安息日の前日であったので、</span>
<span className="v" id="v43" data-v="43" data-xref="ルカによる福音書 2:38; ルカによる福音書 2:25; ルカによる福音書 23:51"> アリマタヤのヨセフが大胆にもピラトの所へ行き、イエスのからだの引取りかたを願った。彼は地位の高い議員であって、彼自身、神の国を待ち望んでいる人であった。</span>
<span className="v" id="v44" data-v="44" data-xref="ヨハネによる福音書 19:31–37"> ピラトは、イエスがもはや死んでしまったのかと不審に思い、百卒長を呼んで、もう死んだのかと尋ねた。</span>
<span className="v" id="v45" data-v="45" data-xref="マタイによる福音書 27:58; ヨハネによる福音書 19:38; マルコによる福音書 15:39"> そして、百卒長から確かめた上、死体をヨセフに渡した。</span>
<span className="v" id="v46" data-v="46" data-xref="イザヤ書 53:9; マタイによる福音書 27:59–60; イザヤ書 22:16"> そこで、ヨセフは亜麻布を買い求め、イエスをとりおろして、その亜麻布に包み、岩を掘って造った墓に納め、墓の入口に石をころがしておいた。</span>
<span className="v" id="v47" data-v="47" data-xref="マルコによる福音書 15:40; マルコによる福音書 16:1; ルカによる福音書 23:55–2"> マグダラのマリヤとヨセの母マリヤとは、イエスが納められた場所を見とどけた。</span>
</div>

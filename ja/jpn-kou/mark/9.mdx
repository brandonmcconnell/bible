<div className="bible-chapter" lang="ja" dir="ltr" data-lang="ja" data-translation="jpn-kou" data-translation-id="jpn_kou" data-translation-label="口語訳" data-book="MRK" data-book-slug="mark" data-book-name="マルコによる福音書" data-chapter="9" data-verses="50">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ルカによる福音書 9:27; ヘブル人への手紙 2:9; ルカによる福音書 22:30"> また、彼らに言われた、「よく聞いておくがよい。神の国が力をもって来るのを見るまでは、決して死を味わわない者が、ここに立っている者の中にいる」。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="ルカによる福音書 9:28–36; イザヤ書 33:17; マタイによる福音書 17:1–8"> 六日の後、イエスは、ただペテロ、ヤコブ、ヨハネだけを連れて、高い山に登られた。ところが、彼らの目の前でイエスの姿が変り、</span>
<span className="v" id="v3" data-v="3" data-xref="マタイによる福音書 28:3; ダニエル書 7:9; ヨハネの黙示録 7:14"> その衣は真白く輝き、どんな布さらしでも、それほどに白くすることはできないくらいになった。</span>
<span className="v" id="v4" data-v="4" data-xref="ルカによる福音書 9:30–31; マタイによる福音書 17:3–4; 使徒行伝 3:21–24"> すると、エリヤがモーセと共に彼らに現れて、イエスと語り合っていた。</span>
<span className="v" id="v5" data-v="5" data-xref="ピリピ人への手紙 1:23; ヨハネによる福音書 14:8–9; ヨハネの黙示録 22:3–4"> ペテロはイエスにむかって言った、「先生、わたしたちがここにいるのは、すばらしいことです。それで、わたしたちは小屋を三つ建てましょう。一つはあなたのために、一つはモーセのために、一つはエリヤのために」。</span>
<span className="v" id="v6" data-v="6" data-xref="ヨハネの黙示録 1:17; ダニエル書 10:15–19; マルコによる福音書 16:5–8"> そう言ったのは、みんなの者が非常に恐れていたので、ペテロは何を言ってよいか、わからなかったからである。</span>
<span className="v" id="v7" data-v="7" data-xref="ペテロの第二の手紙 1:17; マタイによる福音書 3:17; マルコによる福音書 1:11"> すると、雲がわき起って彼らをおおった。そして、その雲の中から声があった、「これはわたしの愛する子である。これに聞け」。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行伝 10:16; 使徒行伝 8:39–40; ルカによる福音書 24:31"> 彼らは急いで見まわしたが、もはやだれも見えず、ただイエスだけが、自分たちと一緒におられた。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="マタイによる福音書 12:40; マタイによる福音書 17:9–13; マルコによる福音書 5:43"> 一同が山を下って来るとき、イエスは「人の子が死人の中からよみがえるまでは、いま見たことをだれにも話してはならない」と、彼らに命じられた。</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行伝 17:18; ルカによる福音書 24:7–8; ルカによる福音書 18:33–34"> 彼らはこの言葉を心にとめ、死人の中からよみがえるとはどういうことかと、互に論じ合った。</span>
<span className="v" id="v11" data-v="11" data-xref="マラキ書 4:5; マラキ書 3:1; マタイによる福音書 11:14"> そしてイエスに尋ねた、「なぜ、律法学者たちは、エリヤが先に来るはずだと言っているのですか」。</span>
<span className="v" id="v12" data-v="12" data-xref="イザヤ書 53:1–12; イザヤ書 50:6; イザヤ書 52:14"> イエスは言われた、「確かに、エリヤが先にきて、万事を元どおりに改める。しかし、人の子について、彼が多くの苦しみを受け、かつ恥ずかしめられると、書いてあるのはなぜか。</span>
<span className="v" id="v13" data-v="13" data-xref="マタイによる福音書 14:3–11; マタイによる福音書 17:12–13; マタイによる福音書 11:14"> しかしあなたがたに言っておく、エリヤはすでにきたのだ。そして彼について書いてあるように、人々は自分かってに彼をあしらった」。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="ルカによる福音書 9:37–42; マタイによる福音書 17:14–20; ルカによる福音書 11:53–54"> さて、彼らがほかの弟子たちの所にきて見ると、大ぜいの群衆が弟子たちを取り囲み、そして律法学者たちが彼らと論じ合っていた。</span>
<span className="v" id="v15" data-v="15" data-xref="出エジプト記 34:30; マルコによる福音書 9:2–3"> 群衆はみな、すぐイエスを見つけて、非常に驚き、駆け寄ってきて、あいさつをした。</span>
<span className="v" id="v16" data-v="16" data-xref="ルカによる福音書 5:30–32; マルコによる福音書 8:11"> イエスが彼らに、「あなたがたは彼らと何を論じているのか」と尋ねられると、</span>
<span className="v" id="v17" data-v="17" data-xref="マルコによる福音書 9:25; ルカによる福音書 11:14; ヨハネによる福音書 4:47"> 群衆のひとりが答えた、「先生、おしの霊につかれているわたしのむすこを、こちらに連れて参りました。</span>
<span className="v" id="v18" data-v="18" data-xref="マタイによる福音書 17:19–20; マルコによる福音書 11:23; マタイによる福音書 17:16"> 霊がこのむすこにとりつきますと、どこででも彼を引き倒し、それから彼はあわを吹き、歯をくいしばり、からだをこわばらせてしまいます。それでお弟子たちに、この霊を追い出してくださるように願いましたが、できませんでした」。</span>
<span className="v" id="v19" data-v="19" data-xref="民数記 14:11; ヨハネによる福音書 20:27; 民数記 14:27"> イエスは答えて言われた、「ああ、なんという不信仰な時代であろう。いつまで、わたしはあなたがたと一緒におられようか。いつまで、あなたがたに我慢ができようか。その子をわたしの所に連れてきなさい」。</span>
<span className="v" id="v20" data-v="20" data-xref="マルコによる福音書 1:26; ルカによる福音書 4:35; ヨハネによる福音書 8:44"> そこで人々は、その子をみもとに連れてきた。霊がイエスを見るや否や、その子をひきつけさせたので、子は地に倒れ、あわを吹きながらころげまわった。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行伝 9:33; 使徒行伝 4:22; マルコによる福音書 5:25"> そこで、イエスが父親に「いつごろから、こんなになったのか」と尋ねられると、父親は答えた、「幼い時からです。</span>
<span className="v" id="v22" data-v="22" data-xref="マタイによる福音書 15:22–28; マルコによる福音書 5:19; マタイによる福音書 20:34"> 霊はたびたび、この子を火の中、水の中に投げ入れて、殺そうとしました。しかしできますれば、わたしどもをあわれんでお助けください」。</span>
<span className="v" id="v23" data-v="23" data-xref="ヨハネによる福音書 11:40; ヘブル人への手紙 11:6; マルコによる福音書 11:23"> イエスは彼に言われた、「もしできれば、と言うのか。信ずる者には、どんな事でもできる」。</span>
<span className="v" id="v24" data-v="24" data-xref="ルカによる福音書 17:5; ヘブル人への手紙 12:2; エペソ人への手紙 2:8"> その子の父親はすぐ叫んで言った、「信じます。不信仰なわたしを、お助けください」。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行伝 16:18; ルカによる福音書 9:42; マルコによる福音書 9:15"> イエスは群衆が駆け寄って来るのをごらんになって、けがれた霊をしかって言われた、「おしとつんぼの霊よ、わたしがおまえに命じる。この子から出て行け。二度と、はいって来るな」。</span>
<span className="v" id="v26" data-v="26" data-xref="マルコによる福音書 9:20; マルコによる福音書 1:26; マルコによる福音書 9:18"> すると霊は叫び声をあげ、激しく引きつけさせて出て行った。その子は死人のようになったので、多くの人は、死んだのだと言った。</span>
<span className="v" id="v27" data-v="27" data-xref="マルコによる福音書 1:31; 使徒行伝 3:7; マルコによる福音書 1:41"> しかし、イエスが手を取って起されると、その子は立ち上がった。</span>
<span className="v" id="v28" data-v="28" data-xref="マタイによる福音書 17:19–20; マルコによる福音書 7:17; マタイによる福音書 15:15"> 家にはいられたとき、弟子たちはひそかにお尋ねした、「わたしたちは、どうして霊を追い出せなかったのですか」。</span>
<span className="v" id="v29" data-v="29" data-xref="ヤコブの手紙 5:15; ダニエル書 9:3; マタイによる福音書 17:20"> すると、イエスは言われた、「このたぐいは、祈によらなければ、どうしても追い出すことはできない」。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="マタイによる福音書 17:22–23; ルカによる福音書 9:43–45; マルコによる福音書 6:31–32"> それから彼らはそこを立ち去り、ガリラヤをとおって行ったが、イエスは人に気づかれるのを好まれなかった。</span>
<span className="v" id="v31" data-v="31" data-xref="マタイによる福音書 16:21; マルコによる福音書 9:12; ルカによる福音書 24:44–46"> それは、イエスが弟子たちに教えて、「人の子は人々の手にわたされ、彼らに殺され、殺されてから三日の後によみがえるであろう」と言っておられたからである。</span>
<span className="v" id="v32" data-v="32" data-xref="ルカによる福音書 2:50; ルカによる福音書 9:45; ルカによる福音書 18:34"> しかし、彼らはイエスの言われたことを悟らず、また尋ねるのを恐れていた。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="マタイによる福音書 18:1–5; ヘブル人への手紙 4:13; ルカによる福音書 9:46–48"> それから彼らはカペナウムにきた。そして家におられるとき、イエスは弟子たちに尋ねられた、「あなたがたは途中で何を論じていたのか」。</span>
<span className="v" id="v34" data-v="34" data-xref="マルコによる福音書 9:50; マタイによる福音書 20:21–24; マタイによる福音書 18:1–5"> 彼らは黙っていた。それは途中で、だれが一ばん偉いかと、互に論じ合っていたからである。</span>
<span className="v" id="v35" data-v="35" data-xref="マタイによる福音書 20:25–28; マルコによる福音書 10:42–45; ルカによる福音書 22:26"> そこで、イエスはすわって十二弟子を呼び、そして言われた、「だれでも一ばん先になろうと思うならば、一ばんあとになり、みんなに仕える者とならねばならない」。</span>
<span className="v" id="v36" data-v="36" data-xref="マルコによる福音書 10:16; マタイによる福音書 19:14–15; マタイによる福音書 18:2"> そして、ひとりの幼な子をとりあげて、彼らのまん中に立たせ、それを抱いて言われた。</span>
<span className="v" id="v37" data-v="37" data-xref="マタイによる福音書 18:3–5; ルカによる福音書 10:16; マタイによる福音書 10:40–42"> 「だれでも、このような幼な子のひとりを、わたしの名のゆえに受けいれる者は、わたしを受けいれるのである。そして、わたしを受けいれる者は、わたしを受けいれるのではなく、わたしをおつかわしになったかたを受けいれるのである」。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="ルカによる福音書 9:49–50; 民数記 11:26–29; ルカによる福音書 11:19"> ヨハネがイエスに言った、「先生、わたしたちについてこない者が、あなたの名を使って悪霊を追い出しているのを見ましたが、その人はわたしたちについてこなかったので、やめさせました」。</span>
<span className="v" id="v39" data-v="39" data-xref="コリント人への第一の手紙 12:3; コリント人への第一の手紙 13:1–2; マタイによる福音書 13:28–29"> イエスは言われた、「やめさせないがよい。だれでもわたしの名で力あるわざを行いながら、すぐそのあとで、わたしをそしることはできない。</span>
<span className="v" id="v40" data-v="40" data-xref="マタイによる福音書 12:30; ルカによる福音書 11:23"> わたしたちに反対しない者は、わたしたちの味方である。</span>
<span className="v" id="v41" data-v="41" data-xref="マタイによる福音書 10:42; マタイによる福音書 25:40; コリント人への第一の手紙 15:23"> だれでも、キリストについている者だというので、あなたがたに水一杯でも飲ませてくれるものは、よく言っておくが、決してその報いからもれることはないであろう。</span>
<span className="v" id="v42" data-v="42" data-xref="マタイによる福音書 18:6; ルカによる福音書 17:1–2; マタイによる福音書 18:10"> また、わたしを信じるこれらの小さい者のひとりをつまずかせる者は、大きなひきうすを首にかけられて海に投げ込まれた方が、はるかによい。</span>
<span className="v" id="v43" data-v="43" data-xref="マタイによる福音書 5:29–30; マタイによる福音書 18:8–9; マタイによる福音書 25:41"> もし、あなたの片手が罪を犯させるなら、それを切り捨てなさい。両手がそろったままで地獄の消えない火の中に落ち込むよりは、かたわになって命に入る方がよい。〔</span>
<span className="v" id="v44" data-v="44"> 地獄では、うじがつきず、火も消えることがない。〕</span>
<span className="v" id="v45" data-v="45" data-xref="マタイによる福音書 18:8; マタイによる福音書 5:22; マルコによる福音書 9:43"> もし、あなたの片足が罪を犯させるなら、それを切り捨てなさい。両足がそろったままで地獄に投げ入れられるよりは、片足で命に入る方がよい。〔</span>
<span className="v" id="v46" data-v="46"> 地獄では、うじがつきず、火も消えることがない。〕</span>
<span className="v" id="v47" data-v="47" data-xref="マタイによる福音書 18:9; マルコによる福音書 9:43; マタイによる福音書 5:22"> もし、あなたの片目が罪を犯させるなら、それを抜き出しなさい。両眼がそろったままで地獄に投げ入れられるよりは、片目になって神の国に入る方がよい。</span>
<span className="v" id="v48" data-v="48" data-xref="イザヤ書 66:24; マルコによる福音書 9:43–45; マタイによる福音書 25:41"> 地獄では、うじがつきず、火も消えることがない。</span>
<span className="v" id="v49" data-v="49" data-xref="レビ記 2:13; エゼキエル書 43:24"> 人はすべて火で塩づけられねばならない。</span>
<span className="v" id="v50" data-v="50" data-xref="コロサイ人への手紙 4:6; ローマ人への手紙 12:18; マタイによる福音書 5:13"> 塩はよいものである。しかし、もしその塩の味がぬけたら、何によってその味が取りもどされようか。あなたがた自身の内に塩を持ちなさい。そして、互に和らぎなさい」。</span>
</div>

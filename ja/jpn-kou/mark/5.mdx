<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ルカによる福音書 8:26–39; マタイによる福音書 8:28–34; マルコによる福音書 4:35"> こうして彼らは海の向こう岸、ゲラサ人の地に着いた。</span>
<span className="v" id="v2" data-v="2" data-xref="マルコによる福音書 1:23; イザヤ書 65:4; マルコによる福音書 5:8"> それから、イエスが舟からあがられるとすぐに、けがれた霊につかれた人が墓場から出てきて、イエスに出会った。</span>
<span className="v" id="v3" data-v="3" data-xref="イザヤ書 65:4; ルカによる福音書 8:29; ダニエル書 4:32–33"> この人は墓場をすみかとしており、もはやだれも、鎖でさえも彼をつなぎとめて置けなかった。</span>
<span className="v" id="v4" data-v="4" data-xref="ヤコブの手紙 3:7–8"> 彼はたびたび足かせや鎖でつながれたが、鎖を引きちぎり、足かせを砕くので、だれも彼を押えつけることができなかったからである。</span>
<span className="v" id="v5" data-v="5" data-xref="ヨブ記 2:7–8; 列王紀上 18:28; ヨハネによる福音書 8:44"> そして、夜昼たえまなく墓場や山で叫びつづけて、石で自分のからだを傷つけていた。</span>
<span className="v" id="v6" data-v="6" data-xref="ヤコブの手紙 2:19; 詩篇 66:3; ルカによる福音書 4:41"> ところが、この人がイエスを遠くから見て、走り寄って拝し、</span>
<span className="v" id="v7" data-v="7" data-xref="マタイによる福音書 8:29; 使徒行伝 16:17; マタイによる福音書 26:63"> 大声で叫んで言った、「いと高き神の子イエスよ、あなたはわたしとなんの係わりがあるのです。神に誓ってお願いします。どうぞ、わたしを苦しめないでください」。</span>
<span className="v" id="v8" data-v="8" data-xref="マルコによる福音書 1:25; マルコによる福音書 9:25–26; 使徒行伝 16:18"> それは、イエスが、「けがれた霊よ、この人から出て行け」と言われたからである。</span>
<span className="v" id="v9" data-v="9" data-xref="ルカによる福音書 8:30; マルコによる福音書 5:15; マタイによる福音書 26:53"> また彼に、「なんという名前か」と尋ねられると、「レギオンと言います。大ぜいなのですから」と答えた。</span>
<span className="v" id="v10" data-v="10" data-xref="マルコによる福音書 3:22; マルコによる福音書 5:13"> そして、自分たちをこの土地から追い出さないようにと、しきりに願いつづけた。</span>
<span className="v" id="v11" data-v="11" data-xref="レビ記 11:7–8; イザヤ書 65:4; イザヤ書 66:3"> さて、そこの山の中腹に、豚の大群が飼ってあった。</span>
<span className="v" id="v12" data-v="12" data-xref="コリント人への第二の手紙 2:11; ヨブ記 1:10–12; ルカによる福音書 22:31–32"> 霊はイエスに願って言った、「わたしどもを、豚にはいらせてください。その中へ送ってください」。</span>
<span className="v" id="v13" data-v="13" data-xref="列王紀上 22:22; ペテロの第一の手紙 3:22; ヨブ記 2:6"> イエスがお許しになったので、けがれた霊どもは出て行って、豚の中へはいり込んだ。すると、その群れは二千匹ばかりであったが、がけから海へなだれを打って駆け下り、海の中でおぼれ死んでしまった。</span>
<span className="v" id="v14" data-v="14" data-xref="ルカによる福音書 8:34; マタイによる福音書 8:33"> 豚を飼う者たちが逃げ出して、町や村にふれまわったので、人々は何事が起ったのかと見にきた。</span>
<span className="v" id="v15" data-v="15" data-xref="コロサイ人への手紙 1:13; テモテヘの第二の手紙 1:7; サムエル記上 6:20–21"> そして、イエスのところにきて、悪霊につかれた人が着物を着て、正気になってすわっており、それがレギオンを宿していた者であるのを見て、恐れた。</span>
<span className="v" id="v16" data-v="16"> また、それを見た人たちは、悪霊につかれた人の身に起った事と豚のこととを、彼らに話して聞かせた。</span>
<span className="v" id="v17" data-v="17" data-xref="マタイによる福音書 8:34; マルコによる福音書 1:24; ルカによる福音書 8:37"> そこで、人々はイエスに、この地方から出て行っていただきたいと、頼みはじめた。</span>
<span className="v" id="v18" data-v="18" data-xref="ルカによる福音書 8:38–39; ピリピ人への手紙 1:23–24; マルコによる福音書 5:17"> イエスが舟に乗ろうとされると、悪霊につかれていた人がお供をしたいと願い出た。</span>
<span className="v" id="v19" data-v="19" data-xref="詩篇 66:16; ヨハネによる福音書 4:29; イザヤ書 38:9–20"> しかし、イエスはお許しにならないで、彼に言われた、「あなたの家族のもとに帰って、主がどんなに大きなことをしてくださったか、またどんなにあわれんでくださったか、それを知らせなさい」。</span>
<span className="v" id="v20" data-v="20" data-xref="マルコによる福音書 7:31; マタイによる福音書 4:25"> そこで、彼は立ち去り、そして自分にイエスがしてくださったことを、ことごとくデカポリスの地方に言いひろめ出したので、人々はみな驚き怪しんだ。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="マタイによる福音書 9:1; マルコによる福音書 4:1; ルカによる福音書 8:40"> イエスがまた舟で向こう岸へ渡られると、大ぜいの群衆がみもとに集まってきた。イエスは海べにおられた。</span>
<span className="v" id="v22" data-v="22" data-xref="ルカによる福音書 13:14; 使徒行伝 18:8; マルコによる福音書 5:35–36"> そこへ、会堂司のひとりであるヤイロという者がきて、イエスを見かけるとその足もとにひれ伏し、</span>
<span className="v" id="v23" data-v="23" data-xref="ルカによる福音書 13:13; ルカによる福音書 4:40; マルコによる福音書 16:18"> しきりに願って言った、「わたしの幼い娘が死にかかっています。どうぞ、その子がなおって助かりますように、おいでになって、手をおいてやってください」。</span>
<span className="v" id="v24" data-v="24" data-xref="マルコによる福音書 5:31; マルコによる福音書 3:20; ルカによる福音書 7:6"> そこで、イエスは彼と一緒に出かけられた。大ぜいの群衆もイエスに押し迫りながら、ついて行った。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="レビ記 15:25–27; ルカによる福音書 8:43–44; マタイによる福音書 9:20–22"> さてここに、十二年間も長血をわずらっている女がいた。</span>
<span className="v" id="v26" data-v="26" data-xref="エレミヤ書 30:12–13; エレミヤ書 8:22; 詩篇 108:12"> 多くの医者にかかって、さんざん苦しめられ、その持ち物をみな費してしまったが、なんのかいもないばかりか、かえってますます悪くなる一方であった。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行伝 19:12; マタイによる福音書 14:36; 使徒行伝 5:15"> この女がイエスのことを聞いて、群衆の中にまぎれ込み、うしろから、み衣にさわった。</span>
<span className="v" id="v28" data-v="28"> それは、せめて、み衣にでもさわれば、なおしていただけるだろうと、思っていたからである。</span>
<span className="v" id="v29" data-v="29" data-xref="マルコによる福音書 5:34; 詩篇 30:2; マルコによる福音書 3:10"> すると、血の元がすぐにかわき、女は病気がなおったことを、その身に感じた。</span>
<span className="v" id="v30" data-v="30" data-xref="ルカによる福音書 6:19; ルカによる福音書 8:46; ルカによる福音書 5:17"> イエスはすぐ、自分の内から力が出て行ったことに気づかれて、群衆の中で振り向き、「わたしの着物にさわったのはだれか」と言われた。</span>
<span className="v" id="v31" data-v="31" data-xref="ルカによる福音書 8:45; ルカによる福音書 9:12"> そこで弟子たちが言った、「ごらんのとおり、群衆があなたに押し迫っていますのに、だれがさわったかと、おっしゃるのですか」。</span>
<span className="v" id="v32" data-v="32"> しかし、イエスはさわった者を見つけようとして、見まわしておられた。</span>
<span className="v" id="v33" data-v="33" data-xref="ルカによる福音書 8:47; ルカによる福音書 1:29; ルカによる福音書 1:12"> その女は自分の身に起ったことを知って、恐れおののきながら進み出て、みまえにひれ伏して、すべてありのままを申し上げた。</span>
<span className="v" id="v34" data-v="34" data-xref="ルカによる福音書 8:48; マタイによる福音書 9:22; ルカによる福音書 7:50"> イエスはその女に言われた、「娘よ、あなたの信仰があなたを救ったのです。安心して行きなさい。すっかりなおって、達者でいなさい」。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="ルカによる福音書 8:49; ヨハネによる福音書 11:39; マルコによる福音書 5:22"> イエスが、まだ話しておられるうちに、会堂司の家から人々がきて言った、「あなたの娘はなくなりました。このうえ、先生を煩わすには及びますまい」。</span>
<span className="v" id="v36" data-v="36" data-xref="ルカによる福音書 8:50; マタイによる福音書 9:28–29; ヨハネによる福音書 11:40"> イエスはその話している言葉を聞き流して、会堂司に言われた、「恐れることはない。ただ信じなさい」。</span>
<span className="v" id="v37" data-v="37" data-xref="使徒行伝 9:40; マルコによる福音書 14:33; コリント人への第二の手紙 13:1"> そしてペテロ、ヤコブ、ヤコブの兄弟ヨハネのほかは、ついて来ることを、だれにもお許しにならなかった。</span>
<span className="v" id="v38" data-v="38" data-xref="マタイによる福音書 9:23–24; ルカによる福音書 8:52–53; マルコによる福音書 5:22"> 彼らが会堂司の家に着くと、イエスは人々が大声で泣いたり、叫んだりして、騒いでいるのをごらんになり、</span>
<span className="v" id="v39" data-v="39" data-xref="使徒行伝 20:10; テサロニケ人への第一の手紙 5:10; テサロニケ人への第一の手紙 4:13–14"> 内にはいって、彼らに言われた、「なぜ泣き騒いでいるのか。子供は死んだのではない。眠っているだけである」。</span>
<span className="v" id="v40" data-v="40" data-xref="ネヘミヤ書 2:19; 列王紀下 4:33; マタイによる福音書 9:24–25"> 人々はイエスをあざ笑った。しかし、イエスはみんなの者を外に出し、子供の父母と供の者たちだけを連れて、子供のいる所にはいって行かれた。</span>
<span className="v" id="v41" data-v="41" data-xref="マルコによる福音書 1:31; ルカによる福音書 7:14–15; ルカによる福音書 8:54–55"> そして子供の手を取って、「タリタ、クミ」と言われた。それは、「少女よ、さあ、起きなさい」という意味である。</span>
<span className="v" id="v42" data-v="42" data-xref="マルコによる福音書 4:41; 使徒行伝 3:10–13; マルコによる福音書 7:37"> すると、少女はすぐに起き上がって、歩き出した。十二歳にもなっていたからである。彼らはたちまち非常な驚きに打たれた。</span>
<span className="v" id="v43" data-v="43" data-xref="マタイによる福音書 8:4; マタイによる福音書 9:30; マルコによる福音書 1:43"> イエスは、だれにもこの事を知らすなと、きびしく彼らに命じ、また、少女に食物を与えるようにと言われた。</span>
</div>

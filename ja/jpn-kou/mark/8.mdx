<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マタイによる福音書 15:32–39; マルコによる福音書 6:34–44"> そのころ、また大ぜいの群衆が集まっていたが、何も食べるものがなかったので、イエスは弟子たちを呼び寄せて言われた、</span>
<span className="v" id="v2" data-v="2" data-xref="マタイによる福音書 9:36; ミカ書 7:19; 詩篇 103:13"> 「この群衆がかわいそうである。もう三日間もわたしと一緒にいるのに、何も食べるものがない。</span>
<span className="v" id="v3" data-v="3" data-xref="イザヤ書 40:31; 士師記 8:4–6; サムエル記上 30:10–12"> もし、彼らを空腹のまま家に帰らせるなら、途中で弱り切ってしまうであろう。それに、なかには遠くからきている者もある」。</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀下 4:42–44; 列王紀下 7:2; マルコによる福音書 6:52"> 弟子たちは答えた、「こんな荒野で、どこからパンを手に入れて、これらの人々にじゅうぶん食べさせることができましょうか」。</span>
<span className="v" id="v5" data-v="5" data-xref="マタイによる福音書 14:15–17; マタイによる福音書 15:34; ルカによる福音書 9:13"> イエスが弟子たちに、「パンはいくつあるか」と尋ねられると、「七つあります」と答えた。</span>
<span className="v" id="v6" data-v="6" data-xref="コロサイ人への手紙 3:17; マタイによる福音書 15:35–36; ヨハネによる福音書 6:10–11"> そこでイエスは群衆に地にすわるように命じられた。そして七つのパンを取り、感謝してこれをさき、人々に配るように弟子たちに渡されると、弟子たちはそれを群衆に配った。</span>
<span className="v" id="v7" data-v="7" data-xref="マタイによる福音書 14:19; ヨハネによる福音書 21:5; ルカによる福音書 24:41–42"> また小さい魚が少しばかりあったので、祝福して、それをも人々に配るようにと言われた。</span>
<span className="v" id="v8" data-v="8" data-xref="列王紀下 4:42–44; 詩篇 145:16; マタイによる福音書 16:10"> 彼らは食べて満腹した。そして残ったパンくずを集めると、七かごになった。</span>
<span className="v" id="v9" data-v="9"> 人々の数はおよそ四千人であった。それからイエスは彼らを解散させ、</span>
<span className="v" id="v10" data-v="10" data-xref="マタイによる福音書 15:39"> すぐ弟子たちと共に舟に乗って、ダルマヌタの地方へ行かれた。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="コリント人への第一の手紙 10:9; マタイによる福音書 12:38; 申命記 6:16"> パリサイ人たちが出てきて、イエスを試みようとして議論をしかけ、天からのしるしを求めた。</span>
<span className="v" id="v12" data-v="12" data-xref="マタイによる福音書 12:39–40; マルコによる福音書 7:34; マタイによる福音書 16:4"> イエスは、心の中で深く嘆息して言われた、「なぜ、今の時代はしるしを求めるのだろう。よく言い聞かせておくが、しるしは今の時代には決して与えられない」。</span>
<span className="v" id="v13" data-v="13" data-xref="ヨハネによる福音書 12:36; 使徒行伝 13:45–46; 詩篇 81:12"> そして、イエスは彼らをあとに残し、また舟に乗って向こう岸へ行かれた。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="マタイによる福音書 16:5"> 弟子たちはパンを持って来るのを忘れていたので、舟の中にはパン一つしか持ち合わせがなかった。</span>
<span className="v" id="v15" data-v="15" data-xref="コリント人への第一の手紙 5:6–8; マタイによる福音書 16:6; マタイによる福音書 16:11–12"> そのとき、イエスは彼らを戒めて、「パリサイ人のパン種とヘロデのパン種とを、よくよく警戒せよ」と言われた。</span>
<span className="v" id="v16" data-v="16" data-xref="ルカによる福音書 9:46; ルカによる福音書 20:5; マタイによる福音書 16:7–8"> 弟子たちは、これは自分たちがパンを持っていないためであろうと、互に論じ合った。</span>
<span className="v" id="v17" data-v="17" data-xref="マルコによる福音書 6:52; イザヤ書 63:17; マルコによる福音書 2:8"> イエスはそれと知って、彼らに言われた、「なぜ、パンがないからだと論じ合っているのか。まだわからないのか、悟らないのか。あなたがたの心は鈍くなっているのか。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行伝 28:26–27; マタイによる福音書 13:14–15; エレミヤ書 5:21"> 目があっても見えないのか。耳があっても聞えないのか。まだ思い出さないのか。</span>
<span className="v" id="v19" data-v="19" data-xref="ルカによる福音書 9:12–17; マタイによる福音書 14:17–21; ヨハネによる福音書 6:5–13"> 五つのパンをさいて五千人に分けたとき、拾い集めたパンくずは、幾つのかごになったか」。弟子たちは答えた、「十二かごです」。</span>
<span className="v" id="v20" data-v="20" data-xref="マタイによる福音書 15:34–38; マルコによる福音書 8:1–9"> 「七つのパンを四千人に分けたときには、パンくずを幾つのかごに拾い集めたか」。「七かごです」と答えた。</span>
<span className="v" id="v21" data-v="21" data-xref="マルコによる福音書 6:52; マタイによる福音書 16:11–12; マルコによる福音書 8:12"> そこでイエスは彼らに言われた、「まだ悟らないのか」。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="マタイによる福音書 11:21; マルコによる福音書 6:45; ルカによる福音書 10:13"> そのうちに、彼らはベツサイダに着いた。すると人々が、ひとりの盲人を連れてきて、さわってやっていただきたいとお願いした。</span>
<span className="v" id="v23" data-v="23" data-xref="マルコによる福音書 7:33; ヨハネによる福音書 9:6–7; マルコによる福音書 5:23"> イエスはこの盲人の手をとって、村の外に連れ出し、その両方の目につばきをつけ、両手を彼に当てて、「何か見えるか」と尋ねられた。</span>
<span className="v" id="v24" data-v="24" data-xref="イザヤ書 32:3; イザヤ書 29:18; コリント人への第一の手紙 13:9–12"> すると彼は顔を上げて言った、「人が見えます。木のように見えます。歩いているようです」。</span>
<span className="v" id="v25" data-v="25" data-xref="ペテロの第一の手紙 2:9; ペテロの第二の手紙 3:18; 箴言 4:18"> それから、イエスが再び目の上に両手を当てられると、盲人は見つめているうちに、なおってきて、すべてのものがはっきりと見えだした。</span>
<span className="v" id="v26" data-v="26" data-xref="マタイによる福音書 8:4; マルコによる福音書 8:23; マルコによる福音書 5:43"> そこでイエスは、「村にはいってはいけない」と言って、彼を家に帰された。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="マタイによる福音書 16:13–20; ルカによる福音書 9:18–20"> さて、イエスは弟子たちとピリポ・カイザリヤの村々へ出かけられたが、その途中で、弟子たちに尋ねて言われた、「人々は、わたしをだれと言っているか」。</span>
<span className="v" id="v28" data-v="28" data-xref="ヨハネによる福音書 1:21; マタイによる福音書 14:2; マラキ書 4:5"> 彼らは答えて言った、「バプテスマのヨハネだと、言っています。また、エリヤだと言い、また、預言者のひとりだと言っている者もあります」。</span>
<span className="v" id="v29" data-v="29" data-xref="ヨハネの第一の手紙 4:15; マタイによる福音書 16:15–16; ヨハネの第一の手紙 5:1"> そこでイエスは彼らに尋ねられた、「それでは、あなたがたはわたしをだれと言うか」。ペテロが答えて言った、「あなたこそキリストです」。</span>
<span className="v" id="v30" data-v="30" data-xref="ルカによる福音書 9:21; マタイによる福音書 16:20; マルコによる福音書 9:9"> するとイエスは、自分のことをだれにも言ってはいけないと、彼らを戒められた。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="マルコによる福音書 10:33–34; ヨハネによる福音書 2:19; ルカによる福音書 24:26"> それから、人の子は必ず多くの苦しみを受け、長老、祭司長、律法学者たちに捨てられ、また殺され、そして三日の後によみがえるべきことを、彼らに教えはじめ、</span>
<span className="v" id="v32" data-v="32" data-xref="マタイによる福音書 16:22; ヨハネによる福音書 16:25; ヨハネによる福音書 16:29"> しかもあからさまに、この事を話された。すると、ペテロはイエスをわきへ引き寄せて、いさめはじめたので、</span>
<span className="v" id="v33" data-v="33" data-xref="マタイによる福音書 4:10; ピリピ人への手紙 3:19; ヨハネの第一の手紙 2:15"> イエスは振り返って、弟子たちを見ながら、ペテロをしかって言われた、「サタンよ、引きさがれ。あなたは神のことを思わないで、人のことを思っている」。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="マタイによる福音書 10:38; ルカによる福音書 14:26–27; ヨハネによる福音書 10:27"> それから群衆を弟子たちと一緒に呼び寄せて、彼らに言われた、「だれでもわたしについてきたいと思うなら、自分を捨て、自分の十字架を負うて、わたしに従ってきなさい。</span>
<span className="v" id="v35" data-v="35" data-xref="テモテヘの第二の手紙 2:11–13; コリント人への第一の手紙 9:23; ルカによる福音書 17:33"> 自分の命を救おうと思う者はそれを失い、わたしのため、また福音のために、自分の命を失う者は、それを救うであろう。</span>
<span className="v" id="v36" data-v="36" data-xref="マタイによる福音書 16:26; ルカによる福音書 9:25; 詩篇 49:17"> 人が全世界をもうけても、自分の命を損したら、なんの得になろうか。</span>
<span className="v" id="v37" data-v="37" data-xref="詩篇 49:7–8; ペテロの第一の手紙 1:18–19"> また、人はどんな代価を払って、その命を買いもどすことができようか。</span>
<span className="v" id="v38" data-v="38" data-xref="ルカによる福音書 12:8–9; ローマ人への手紙 1:16; ヨハネの第一の手紙 2:23"> 邪悪で罪深いこの時代にあって、わたしとわたしの言葉とを恥じる者に対しては、人の子もまた、父の栄光のうちに聖なる御使たちと共に来るときに、その者を恥じるであろう」。</span>
</div>
</div>

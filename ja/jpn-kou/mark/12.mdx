<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="イザヤ書 5:1–4; マルコによる福音書 13:34; 雅歌 8:11–12"> そこでイエスは譬で彼らに語り出された、「ある人がぶどう園を造り、垣をめぐらし、また酒ぶねの穴を掘り、やぐらを立て、それを農夫たちに貸して、旅に出かけた。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネによる福音書 15:1–8; ヘブル人への手紙 1:1; エレミヤ書 44:4"> 季節になったので、農夫たちのところへ、ひとりの僕を送って、ぶどう園の収穫の分け前を取り立てさせようとした。</span>
<span className="v" id="v3" data-v="3" data-xref="テサロニケ人への第一の手紙 2:15; ネヘミヤ書 9:26; エレミヤ書 29:26"> すると、彼らはその僕をつかまえて、袋だたきにし、から手で帰らせた。</span>
<span className="v" id="v4" data-v="4"> また他の僕を送ったが、その頭をなぐって侮辱した。</span>
<span className="v" id="v5" data-v="5" data-xref="マタイによる福音書 22:6; マタイによる福音書 23:37; ネヘミヤ書 9:30"> そこでまた他の者を送ったが、今度はそれを殺してしまった。そのほか、なお大ぜいの者を送ったが、彼らを打ったり、殺したりした。</span>
<span className="v" id="v6" data-v="6" data-xref="ヘブル人への手紙 1:1–2; マタイによる福音書 3:17; ヨハネによる福音書 1:34"> ここに、もうひとりの者がいた。それは彼の愛子であった。自分の子は敬ってくれるだろうと思って、最後に彼をつかわした。</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 37:20; マタイによる福音書 2:16; 使徒行伝 2:23"> すると、農夫たちは『あれはあと取りだ。さあ、これを殺してしまおう。そうしたら、その財産はわれわれのものになるのだ』と話し合い、</span>
<span className="v" id="v8" data-v="8" data-xref="マタイによる福音書 21:39; ルカによる福音書 20:15; マタイによる福音書 21:33"> 彼をつかまえて殺し、ぶどう園の外に投げ捨てた。</span>
<span className="v" id="v9" data-v="9" data-xref="ローマ人への手紙 10:20–12; マタイによる福音書 21:43; ルカによる福音書 19:27"> このぶどう園の主人は、どうするだろうか。彼は出てきて、農夫たちを殺し、ぶどう園を他の人々に与えるであろう。</span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 118:22–23; ペテロの第一の手紙 2:7–8; イザヤ書 28:16"> あなたがたは、この聖書の句を読んだことがないのか。<br /><span className="pl pl-1">『家造りらの捨てた石が</span><br /><span className="pl pl-1">隅のかしら石になった。</span></span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 118:23; 使徒行伝 3:12–16; ハバクク書 1:5"> <span className="pl pl-1">これは主がなされたことで、</span><br /><span className="pl pl-1">わたしたちの目には不思議に見える』」。</span></span>
<span className="v" id="v12" data-v="12" data-xref="マルコによる福音書 11:18; マタイによる福音書 22:22; ヨハネによる福音書 7:44"> <span className="pl pl-1">彼らはいまの譬が、自分たちに当てて語られたことを悟ったので、イエスを捕えようとしたが、群衆を恐れた。そしてイエスをそこに残して立ち去った。</span></span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="ルカによる福音書 20:20–26; ルカによる福音書 11:54; マルコによる福音書 3:6"> さて、人々はパリサイ人やヘロデ党の者を数人、イエスのもとにつかわして、その言葉じりを捕えようとした。</span>
<span className="v" id="v14" data-v="14" data-xref="テサロニケ人への第一の手紙 2:4; ルカによる福音書 20:22; ヨハネによる福音書 7:18"> 彼らはきてイエスに言った、「先生、わたしたちはあなたが真実なかたで、だれをも、はばかられないことを知っています。あなたは人に分け隔てをなさらないで、真理に基いて神の道を教えてくださいます。ところで、カイザルに税金を納めてよいでしょうか、いけないでしょうか。納めるべきでしょうか、納めてはならないのでしょうか」。</span>
<span className="v" id="v15" data-v="15" data-xref="エゼキエル書 17:2; ヨハネの黙示録 2:23; マルコによる福音書 10:2"> イエスは彼らの偽善を見抜いて言われた、「なぜわたしをためそうとするのか。デナリを持ってきて見せなさい」。</span>
<span className="v" id="v16" data-v="16" data-xref="ルカによる福音書 20:24–26; ヨハネの黙示録 3:12; マタイによる福音書 22:19–22"> 彼らはそれを持ってきた。そこでイエスは言われた、「これは、だれの肖像、だれの記号か」。彼らは「カイザルのです」と答えた。</span>
<span className="v" id="v17" data-v="17" data-xref="ローマ人への手紙 13:7; ペテロの第一の手紙 2:17; コリント人への第二の手紙 5:14–15"> するとイエスは言われた、「カイザルのものはカイザルに、神のものは神に返しなさい」。彼らはイエスに驚嘆した。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="マタイによる福音書 22:23–33; 使徒行伝 4:1–2; 使徒行伝 23:6–9"> 復活ということはないと主張していたサドカイ人たちが、イエスのもとにきて質問した、</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 25:5–10; ルツ記 4:5; ルツ記 1:11–13"> 「先生、モーセは、わたしたちのためにこう書いています、『もし、ある人の兄が死んで、その残された妻に、子がない場合には、弟はこの女をめとって、兄のために子をもうけねばならない』。</span>
<span className="v" id="v20" data-v="20" data-xref="マタイによる福音書 22:25–28; ルカによる福音書 20:29–33"> ここに、七人の兄弟がいました。長男は妻をめとりましたが、子がなくて死に、</span>
<span className="v" id="v21" data-v="21"> 次男がその女をめとって、また子をもうけずに死に、三男も同様でした。</span>
<span className="v" id="v22" data-v="22"> こうして、七人ともみな子孫を残しませんでした。最後にその女も死にました。</span>
<span className="v" id="v23" data-v="23"> 復活のとき、彼らが皆よみがえった場合、この女はだれの妻なのでしょうか。七人とも彼女を妻にしたのですが」。</span>
<span className="v" id="v24" data-v="24" data-xref="ヨハネによる福音書 20:9; テモテヘの第二の手紙 3:15–17; マタイによる福音書 22:29"> イエスは言われた、「あなたがたがそんな思い違いをしているのは、聖書も神の力も知らないからではないか。</span>
<span className="v" id="v25" data-v="25" data-xref="ルカによる福音書 20:35–36; マタイによる福音書 22:30; ヨハネの第一の手紙 3:2"> 彼らが死人の中からよみがえるときには、めとったり、とついだりすることはない。彼らは天にいる御使のようなものである。</span>
<span className="v" id="v26" data-v="26" data-xref="出エジプト記 3:2–6; ルカによる福音書 20:37; 創世記 17:7–8"> 死人がよみがえることについては、モーセの書の柴の篇で、神がモーセに仰せられた言葉を読んだことがないのか。『わたしはアブラハムの神、イサクの神、ヤコブの神である』とあるではないか。</span>
<span className="v" id="v27" data-v="27" data-xref="ローマ人への手紙 14:9; ローマ人への手紙 4:17; マルコによる福音書 12:24"> 神は死んだ者の神ではなく、生きている者の神である。あなたがたは非常な思い違いをしている」。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="マタイによる福音書 22:34–40; ルカによる福音書 10:25–28; ルカによる福音書 20:39"> ひとりの律法学者がきて、彼らが互に論じ合っているのを聞き、またイエスが巧みに答えられたのを認めて、イエスに質問した、「すべてのいましめの中で、どれが第一のものですか」。</span>
<span className="v" id="v29" data-v="29" data-xref="申命記 6:4; ルカによる福音書 10:27; ガラテヤ人への手紙 3:20"> イエスは答えられた、「第一のいましめはこれである、『イスラエルよ、聞け。主なるわたしたちの神は、ただひとりの主である。</span>
<span className="v" id="v30" data-v="30" data-xref="申命記 6:5"> 心をつくし、精神をつくし、思いをつくし、力をつくして、主なるあなたの神を愛せよ』。</span>
<span className="v" id="v31" data-v="31" data-xref="ローマ人への手紙 13:8–9; マタイによる福音書 22:39; レビ記 19:18"> 第二はこれである、『自分を愛するようにあなたの隣り人を愛せよ』。これより大事ないましめは、ほかにない」。</span>
<span className="v" id="v32" data-v="32" data-xref="申命記 4:39; 申命記 4:35; イザヤ書 46:9"> そこで、この律法学者はイエスに言った、「先生、仰せのとおりです、『神はひとりであって、そのほかに神はない』と言われたのは、ほんとうです。</span>
<span className="v" id="v33" data-v="33" data-xref="ホセア書 6:6; ミカ書 6:6–8; サムエル記上 15:22"> また『心をつくし、知恵をつくし、力をつくして神を愛し、また自分を愛するように隣り人を愛する』ということは、すべての燔祭や犠牲よりも、はるかに大事なことです」。</span>
<span className="v" id="v34" data-v="34" data-xref="コロサイ人への手紙 4:6; ルカによる福音書 20:40; マタイによる福音書 22:46"> イエスは、彼が適切な答をしたのを見て言われた、「あなたは神の国から遠くない」。それから後は、イエスにあえて問う者はなかった。</span>
</div>
<div className="bp poetry">
<span className="v" id="v35" data-v="35" data-xref="ルカによる福音書 20:41–44; マタイによる福音書 22:41–45; マタイによる福音書 26:55"> イエスが宮で教えておられたとき、こう言われた、「律法学者たちは、どうしてキリストをダビデの子だと言うのか。</span>
<span className="v" id="v36" data-v="36" data-xref="詩篇 110:1; ヘブル人への手紙 1:13; マタイによる福音書 22:43–45"> ダビデ自身が聖霊に感じて言った、<br /><span className="pl pl-1">『主はわが主に仰せになった、</span><br /><span className="pl pl-1">あなたの敵をあなたの足もとに置くときまでは、</span><br /><span className="pl pl-1">わたしの右に座していなさい』。</span></span>
<span className="v" id="v37" data-v="37" data-xref="ローマ人への手紙 1:3–4; マタイによる福音書 11:25; マタイによる福音書 1:23"> <span className="pl pl-1">このように、ダビデ自身がキリストを主と呼んでいる。それなら、どうしてキリストはダビデの子であろうか」。</span><br />大ぜいの群衆は、喜んでイエスに耳を傾けていた。</span>
<span className="v" id="v38" data-v="38" data-xref="マタイによる福音書 23:1–7; ルカによる福音書 20:45–47; ルカによる福音書 11:43"> イエスはその教の中で言われた、「律法学者に気をつけなさい。彼らは長い衣を着て歩くことや、広場であいさつされることや、</span>
<span className="v" id="v39" data-v="39" data-xref="ヤコブの手紙 2:2–3"> また会堂の上席、宴会の上座を好んでいる。</span>
<span className="v" id="v40" data-v="40" data-xref="マタイによる福音書 23:13; ルカによる福音書 20:47; マタイによる福音書 23:33"> また、やもめたちの家を食い倒し、見えのために長い祈をする。彼らはもっときびしいさばきを受けるであろう」。</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="ルカによる福音書 21:1–4; 列王紀下 12:9; ヨハネによる福音書 8:20"> イエスは、さいせん箱にむかってすわり、群衆がその箱に金を投げ入れる様子を見ておられた。多くの金持は、たくさんの金を投げ入れていた。</span>
<span className="v" id="v42" data-v="42"> ところが、ひとりの貧しいやもめがきて、レプタ二つを入れた。それは一コドラントに当る。</span>
<span className="v" id="v43" data-v="43" data-xref="コリント人への第二の手紙 9:6–8; コリント人への第二の手紙 8:2; 使徒行伝 11:29"> そこで、イエスは弟子たちを呼び寄せて言われた、「よく聞きなさい。あの貧しいやもめは、さいせん箱に投げ入れている人たちの中で、だれよりもたくさん入れたのだ。</span>
<span className="v" id="v44" data-v="44" data-xref="コリント人への第二の手紙 8:2–3; ヨハネの第一の手紙 3:17; エズラ記 2:68–69"> みんなの者はありあまる中から投げ入れたが、あの婦人はその乏しい中から、あらゆる持ち物、その生活費全部を入れたからである」。</span>
</div>

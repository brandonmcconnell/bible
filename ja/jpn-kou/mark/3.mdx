<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マタイによる福音書 12:9–14; ルカによる福音書 6:6–11; マルコによる福音書 1:21"> イエスがまた会堂にはいられると、そこに片手のなえた人がいた。</span>
<span className="v" id="v2" data-v="2" data-xref="詩篇 37:32; ルカによる福音書 14:1; ルカによる福音書 6:7"> 人々はイエスを訴えようと思って、安息日にその人をいやされるかどうかをうかがっていた。</span>
<span className="v" id="v3" data-v="3" data-xref="ピリピ人への手紙 1:28–30; イザヤ書 42:4; ルカによる福音書 6:8"> すると、イエスは片手のなえたその人に、「立って、中へ出てきなさい」と言い、</span>
<span className="v" id="v4" data-v="4" data-xref="ルカによる福音書 6:9; マタイによる福音書 12:10–12; ホセア書 6:6"> 人々にむかって、「安息日に善を行うのと悪を行うのと、命を救うのと殺すのと、どちらがよいか」と言われた。彼らは黙っていた。</span>
<span className="v" id="v5" data-v="5" data-xref="ルカによる福音書 6:10; エペソ人への手紙 4:18; ローマ人への手紙 11:25"> イエスは怒りを含んで彼らを見まわし、その心のかたくななのを嘆いて、その人に「手を伸ばしなさい」と言われた。そこで手を伸ばすと、その手は元どおりになった。</span>
<span className="v" id="v6" data-v="6" data-xref="マタイによる福音書 22:16; マルコによる福音書 12:13; マタイによる福音書 12:14"> パリサイ人たちは出て行って、すぐにヘロデ党の者たちと、なんとかしてイエスを殺そうと相談しはじめた。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="マタイによる福音書 4:25; ルカによる福音書 6:17; マタイによる福音書 12:15"> それから、イエスは弟子たちと共に海べに退かれたが、ガリラヤからきたおびただしい群衆がついて行った。またユダヤから、</span>
<span className="v" id="v8" data-v="8" data-xref="エゼキエル書 35:15; イザヤ書 34:5; マタイによる福音書 11:21"> エルサレムから、イドマヤから、更にヨルダンの向こうから、ツロ、シドンのあたりからも、おびただしい群衆が、そのなさっていることを聞いて、みもとにきた。</span>
<span className="v" id="v9" data-v="9" data-xref="マルコによる福音書 5:30; ヨハネによる福音書 6:15"> イエスは群衆が自分に押し迫るのを避けるために、小舟を用意しておけと、弟子たちに命じられた。</span>
<span className="v" id="v10" data-v="10" data-xref="マタイによる福音書 14:36; マルコによる福音書 6:56; マタイによる福音書 4:23"> それは、多くの人をいやされたので、病苦に悩む者は皆イエスにさわろうとして、押し寄せてきたからである。</span>
<span className="v" id="v11" data-v="11" data-xref="ルカによる福音書 4:41; マルコによる福音書 1:23–24; ルカによる福音書 8:28"> また、けがれた霊どもはイエスを見るごとに、みまえにひれ伏し、叫んで、「あなたこそ神の子です」と言った。</span>
<span className="v" id="v12" data-v="12" data-xref="マタイによる福音書 12:16; マルコによる福音書 1:25; マルコによる福音書 1:34"> イエスは御自身のことを人にあらわさないようにと、彼らをきびしく戒められた。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="ルカによる福音書 9:1; ルカによる福音書 6:12–16; マタイによる福音書 10:1–4"> さてイエスは山に登り、みこころにかなった者たちを呼び寄せられたので、彼らはみもとにきた。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行伝 1:8; ルカによる福音書 9:1–6; ヨハネによる福音書 15:16"> そこで十二人をお立てになった。彼らを自分のそばに置くためであり、さらに宣教につかわし、</span>
<span className="v" id="v15" data-v="15"> また悪霊を追い出す権威を持たせるためであった。</span>
<span className="v" id="v16" data-v="16" data-xref="ヨハネによる福音書 1:42; 使徒行伝 1:13; マタイによる福音書 16:16–18"> こうして、この十二人をお立てになった。そしてシモンにペテロという名をつけ、</span>
<span className="v" id="v17" data-v="17" data-xref="ヘブル人への手紙 4:12; マルコによる福音書 14:33; エレミヤ書 23:29"> またゼベダイの子ヤコブと、ヤコブの兄弟ヨハネ、彼らにはボアネルゲ、すなわち、雷の子という名をつけられた。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行伝 1:13; マルコによる福音書 2:14; マタイによる福音書 9:9"> つぎにアンデレ、ピリポ、バルトロマイ、マタイ、トマス、アルパヨの子ヤコブ、タダイ、熱心党のシモン、</span>
<span className="v" id="v19" data-v="19" data-xref="ヨハネによる福音書 6:71; ヨハネによる福音書 13:2; 使徒行伝 1:16–25"> それからイスカリオテのユダ。このユダがイエスを裏切ったのである。<br />イエスが家にはいられると、</span>
<span className="v" id="v20" data-v="20" data-xref="マルコによる福音書 6:31; ヨハネによる福音書 4:31–34; マルコによる福音書 9:28"> 群衆がまた集まってきたので、一同は食事をする暇もないほどであった。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行伝 26:24; ヨハネによる福音書 10:20; マルコによる福音書 3:31"> 身内の者たちはこの事を聞いて、イエスを取押えに出てきた。気が狂ったと思ったからである。</span>
<span className="v" id="v22" data-v="22" data-xref="マタイによる福音書 15:1; マタイによる福音書 10:25; マタイによる福音書 9:34"> また、エルサレムから下ってきた律法学者たちも、「彼はベルゼブルにとりつかれている」と言い、「悪霊どものかしらによって、悪霊どもを追い出しているのだ」とも言った。</span>
<span className="v" id="v23" data-v="23" data-xref="ルカによる福音書 11:17–23; マタイによる福音書 12:25–30; マタイによる福音書 13:34"> そこでイエスは彼らを呼び寄せ、譬をもって言われた、「どうして、サタンがサタンを追い出すことができようか。</span>
<span className="v" id="v24" data-v="24" data-xref="ゼカリヤ書 11:14; イザヤ書 19:2–3; サムエル記下 20:6"> もし国が内部で分れ争うなら、その国は立ち行かない。</span>
<span className="v" id="v25" data-v="25" data-xref="ヤコブの手紙 3:16; 詩篇 133:1; ガラテヤ人への手紙 5:15"> また、もし家が内わで分れ争うなら、その家は立ち行かないであろう。</span>
<span className="v" id="v26" data-v="26"> もしサタンが内部で対立し分争するなら、彼は立ち行けず、滅んでしまう。</span>
<span className="v" id="v27" data-v="27" data-xref="イザヤ書 49:24–26; マタイによる福音書 12:29; ルカによる福音書 11:21–23"> だれでも、まず強い人を縛りあげなければ、その人の家に押し入って家財を奪い取ることはできない。縛ってからはじめて、その家を略奪することができる。</span>
<span className="v" id="v28" data-v="28" data-xref="ルカによる福音書 12:10; マタイによる福音書 12:31–32; ヨハネの第一の手紙 5:16"> よく言い聞かせておくが、人の子らには、その犯すすべての罪も神をけがす言葉も、ゆるされる。</span>
<span className="v" id="v29" data-v="29" data-xref="マタイによる福音書 12:31–32; ルカによる福音書 12:10; テサロニケ人への第二の手紙 1:9"> しかし、聖霊をけがす者は、いつまでもゆるされず、永遠の罪に定められる」。</span>
<span className="v" id="v30" data-v="30" data-xref="ヨハネによる福音書 10:20; マルコによる福音書 3:22"> そう言われたのは、彼らが「イエスはけがれた霊につかれている」と言っていたからである。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="ルカによる福音書 8:19–21; マタイによる福音書 12:46–50"> さて、イエスの母と兄弟たちとがきて、外に立ち、人をやってイエスを呼ばせた。</span>
<span className="v" id="v32" data-v="32"> ときに、群衆はイエスを囲んですわっていたが、「ごらんなさい。あなたの母上と兄弟、姉妹たちが、外であなたを尋ねておられます」と言った。</span>
<span className="v" id="v33" data-v="33" data-xref="マルコによる福音書 3:21; 申命記 33:9; マルコによる福音書 6:3"> すると、イエスは彼らに答えて言われた、「わたしの母、わたしの兄弟とは、だれのことか」。</span>
<span className="v" id="v34" data-v="34" data-xref="マタイによる福音書 12:49–50; ルカによる福音書 11:27–28; ローマ人への手紙 8:29"> そして、自分をとりかこんで、すわっている人々を見まわして、言われた、「ごらんなさい、ここにわたしの母、わたしの兄弟がいる。</span>
<span className="v" id="v35" data-v="35" data-xref="ヨハネの第一の手紙 2:17; マタイによる福音書 7:21; ヨハネの第一の手紙 3:22–23"> 神のみこころを行う者はだれでも、わたしの兄弟、また姉妹、また母なのである」。</span>
</div>

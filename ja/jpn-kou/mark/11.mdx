<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="マタイによる福音書 21:1–11; ヨハネによる福音書 12:14–19; ルカによる福音書 19:29–40"> さて、彼らがエルサレムに近づき、オリブの山に沿ったベテパゲ、ベタニヤの附近にきた時、イエスはふたりの弟子をつかわして言われた、</span>
<span className="v" id="v2" data-v="2" data-xref="マタイによる福音書 21:2–3; ルカによる福音書 19:30–31"> 「むこうの村へ行きなさい。そこにはいるとすぐ、まだだれも乗ったことのないろばの子が、つないであるのを見るであろう。それを解いて引いてきなさい。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行伝 10:36; マルコによる福音書 14:15; 詩篇 110:3"> もし、だれかがあなたがたに、なぜそんな事をするのかと言ったなら、主がお入り用なのです。またすぐ、ここへ返してくださいますと、言いなさい」。</span>
<span className="v" id="v4" data-v="4" data-xref="マタイによる福音書 26:19; ルカによる福音書 19:32–34; マタイによる福音書 21:6–7"> そこで、彼らは出かけて行き、そして表通りの戸口に、ろばの子がつないであるのを見たので、それを解いた。</span>
<span className="v" id="v5" data-v="5"> すると、そこに立っていた人々が言った、「そのろばの子を解いて、どうするのか」。</span>
<span className="v" id="v6" data-v="6"> 弟子たちは、イエスが言われたとおり彼らに話したので、ゆるしてくれた。</span>
<span className="v" id="v7" data-v="7" data-xref="ゼカリヤ書 9:9; ルカによる福音書 19:35–36; マタイによる福音書 21:7–8"> そこで、弟子たちは、そのろばの子をイエスのところに引いてきて、自分たちの上着をそれに投げかけると、イエスはその上にお乗りになった。</span>
<span className="v" id="v8" data-v="8" data-xref="レビ記 23:40"> すると多くの人々は自分たちの上着を道に敷き、また他の人々は葉のついた枝を野原から切ってきて敷いた。</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 118:25–26; マタイによる福音書 21:9; マタイによる福音書 23:39"> そして、前に行く者も、あとに従う者も共に叫びつづけた、<br /><span className="pl pl-1">「ホサナ、</span><br /><span className="pl pl-1">主の御名によってきたる者に、祝福あれ。</span></span>
<span className="v" id="v10" data-v="10" data-xref="エゼキエル書 37:24–25; ルカによる福音書 2:14; ルカによる福音書 19:38–40"> <span className="pl pl-1">今きたる、われらの父ダビデの国に、祝福あれ。</span><br /><span className="pl pl-1">いと高き所に、ホサナ」。</span></span>
<span className="v" id="v11" data-v="11" data-xref="ヨハネによる福音書 8:1–2; ルカによる福音書 19:41–45; ルカによる福音書 21:37–38"> <span className="pl pl-1">こうしてイエスはエルサレムに着き、宮にはいられた。そして、すべてのものを見まわった後、もはや時もおそくなっていたので、十二弟子と共にベタニヤに出て行かれた。</span></span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="マタイによる福音書 21:18–22; マタイによる福音書 4:2; ヨハネによる福音書 19:28"> 翌日、彼らがベタニヤから出かけてきたとき、イエスは空腹をおぼえられた。</span>
<span className="v" id="v13" data-v="13" data-xref="マタイによる福音書 21:19; ルカによる福音書 13:6–9; イザヤ書 5:7"> そして、葉の茂ったいちじくの木を遠くからごらんになって、その木に何かありはしないかと近寄られたが、葉のほかは何も見当らなかった。いちじくの季節でなかったからである。</span>
<span className="v" id="v14" data-v="14" data-xref="マタイによる福音書 21:19; マタイによる福音書 7:19; マタイによる福音書 3:10"> そこで、イエスはその木にむかって、「今から後いつまでも、おまえの実を食べる者がないように」と言われた。弟子たちはこれを聞いていた。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="ヨハネによる福音書 2:13–17; マタイによる福音書 21:12–16; ルカによる福音書 19:45–47"> それから、彼らはエルサレムにきた。イエスは宮に入り、宮の庭で売り買いしていた人々を追い出しはじめ、両替人の台や、はとを売る者の腰掛をくつがえし、</span>
<span className="v" id="v16" data-v="16"> また器ものを持って宮の庭を通り抜けるのをお許しにならなかった。</span>
<span className="v" id="v17" data-v="17" data-xref="イザヤ書 56:7; エレミヤ書 7:11; ルカによる福音書 19:46"> そして、彼らに教えて言われた、「『わたしの家は、すべての国民の祈の家ととなえらるべきである』と書いてあるではないか。それだのに、あなたがたはそれを強盗の巣にしてしまった」。</span>
<span className="v" id="v18" data-v="18" data-xref="マタイによる福音書 7:28; マルコによる福音書 12:12; マルコによる福音書 14:1–2"> 祭司長、律法学者たちはこれを聞いて、どうかしてイエスを殺そうと計った。彼らは、群衆がみなその教に感動していたので、イエスを恐れていたからである。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="ルカによる福音書 21:37; マルコによる福音書 11:11; ヨハネによる福音書 12:36"> 夕方になると、イエスと弟子たちとは、いつものように都の外に出て行った。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="マタイによる福音書 15:13; マルコによる福音書 11:14; ヨハネによる福音書 15:6"> 朝はやく道をとおっていると、彼らは先のいちじくが根元から枯れているのを見た。</span>
<span className="v" id="v21" data-v="21" data-xref="箴言 3:33; マタイによる福音書 23:7; マタイによる福音書 25:41"> そこで、ペテロは思い出してイエスに言った、「先生、ごらんなさい。あなたがのろわれたいちじくが、枯れています」。</span>
<span className="v" id="v22" data-v="22" data-xref="詩篇 62:8; ヨハネによる福音書 14:1; マルコによる福音書 9:23"> イエスは答えて言われた、「神を信じなさい。</span>
<span className="v" id="v23" data-v="23" data-xref="マタイによる福音書 17:20; ヨハネによる福音書 15:7; マタイによる福音書 21:21"> よく聞いておくがよい。だれでもこの山に、動き出して、海の中にはいれと言い、その言ったことは必ず成ると、心に疑わないで信じるなら、そのとおりに成るであろう。</span>
<span className="v" id="v24" data-v="24" data-xref="マタイによる福音書 21:22; ヨハネの第一の手紙 5:14–15; ヨハネの第一の手紙 3:22"> そこで、あなたがたに言うが、なんでも祈り求めることは、すでにかなえられたと信じなさい。そうすれば、そのとおりになるであろう。</span>
<span className="v" id="v25" data-v="25" data-xref="マタイによる福音書 6:14–15; コロサイ人への手紙 3:13; エペソ人への手紙 4:32"> また立って祈るとき、だれかに対して、何か恨み事があるならば、ゆるしてやりなさい。そうすれば、天にいますあなたがたの父も、あなたがたのあやまちを、ゆるしてくださるであろう。〔</span>
<span className="v" id="v26" data-v="26"> もしゆるさないならば、天にいますあなたがたの父も、あなたがたのあやまちを、ゆるしてくださらないであろう〕」。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="ルカによる福音書 20:1–8; マタイによる福音書 21:23–27; 詩篇 2:1–5"> 彼らはまたエルサレムにきた。そして、イエスが宮の内を歩いておられると、祭司長、律法学者、長老たちが、みもとにきて言った、</span>
<span className="v" id="v28" data-v="28" data-xref="出エジプト記 2:14; 使徒行伝 7:38–39; 民数記 16:3"> 「何の権威によってこれらの事をするのですか。だれが、そうする権威を授けたのですか」。</span>
<span className="v" id="v29" data-v="29" data-xref="ルカによる福音書 20:3–8; マタイによる福音書 21:24; イザヤ書 52:13"> そこで、イエスは彼らに言われた、「一つだけ尋ねよう。それに答えてほしい。そうしたら、何の権威によって、わたしがこれらの事をするのか、あなたがたに言おう。</span>
<span className="v" id="v30" data-v="30" data-xref="ルカによる福音書 3:1–20; ヨハネによる福音書 3:25–36; マルコによる福音書 1:1–11"> ヨハネのバプテスマは天からであったか、人からであったか、答えなさい」。</span>
<span className="v" id="v31" data-v="31" data-xref="ヨハネによる福音書 1:29; ヨハネによる福音書 1:34; マタイによる福音書 21:31–32"> すると、彼らは互に論じて言った、「もし天からだと言えば、では、なぜ彼を信じなかったのか、とイエスは言うだろう。</span>
<span className="v" id="v32" data-v="32" data-xref="マタイによる福音書 21:46; マルコによる福音書 12:12; マタイによる福音書 14:5"> しかし、人からだと言えば……」。彼らは群衆を恐れていた。人々が皆、ヨハネを預言者だとほんとうに思っていたからである。</span>
<span className="v" id="v33" data-v="33" data-xref="イザヤ書 6:9–10; コリント人への第二の手紙 4:3–4; テサロニケ人への第二の手紙 2:10–12"> それで彼らは「わたしたちにはわかりません」と答えた。するとイエスは言われた、「わたしも何の権威によってこれらの事をするのか、あなたがたに言うまい」。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨハネによる福音書 4:47; ルカによる福音書 5:18; ルカによる福音書 18:35–38"> 幾日かたって、イエスがまたカペナウムにお帰りになったとき、家におられるといううわさが立ったので、</span>
<span className="v" id="v2" data-v="2" data-xref="マルコによる福音書 2:13; マルコによる福音書 1:45; 詩篇 40:9"> 多くの人々が集まってきて、もはや戸口のあたりまでも、すきまが無いほどになった。そして、イエスは御言を彼らに語っておられた。</span>
<span className="v" id="v3" data-v="3" data-xref="ルカによる福音書 5:18–26; マタイによる福音書 9:1–8; マタイによる福音書 4:24"> すると、人々がひとりの中風の者を四人の人に運ばせて、イエスのところに連れてきた。</span>
<span className="v" id="v4" data-v="4" data-xref="ルカによる福音書 5:19; 申命記 22:8"> ところが、群衆のために近寄ることができないので、イエスのおられるあたりの屋根をはぎ、穴をあけて、中風の者を寝かせたまま、床をつりおろした。</span>
<span className="v" id="v5" data-v="5" data-xref="マタイによる福音書 9:2; ヤコブの手紙 5:15; マルコによる福音書 2:9–10"> イエスは彼らの信仰を見て、中風の者に、「子よ、あなたの罪はゆるされた」と言われた。</span>
<span className="v" id="v6" data-v="6" data-xref="ルカによる福音書 5:21–22; マルコによる福音書 8:17; コリント人への第二の手紙 10:5"> ところが、そこに幾人かの律法学者がすわっていて、心の中で論じた、</span>
<span className="v" id="v7" data-v="7" data-xref="イザヤ書 43:25; ルカによる福音書 5:21; ミカ書 7:18"> 「この人は、なぜあんなことを言うのか。それは神をけがすことだ。神ひとりのほかに、だれが罪をゆるすことができるか」。</span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 139:2; 使徒行伝 8:22; ルカによる福音書 5:22"> イエスは、彼らが内心このように論じているのを、自分の心ですぐ見ぬいて、「なぜ、あなたがたは心の中でそんなことを論じているのか。</span>
<span className="v" id="v9" data-v="9" data-xref="ルカによる福音書 5:22–25; マタイによる福音書 9:5"> 中風の者に、あなたの罪はゆるされた、と言うのと、起きよ、床を取りあげて歩け、と言うのと、どちらがたやすいか。</span>
<span className="v" id="v10" data-v="10" data-xref="ダニエル書 7:13–14; マタイによる福音書 9:6–8; ヨハネによる福音書 5:20–27"> しかし、人の子は地上で罪をゆるす権威をもっていることが、あなたがたにわかるために」と彼らに言い、中風の者にむかって、</span>
<span className="v" id="v11" data-v="11" data-xref="マルコによる福音書 1:41; ヨハネによる福音書 5:8–10; ヨハネによる福音書 6:63"> 「あなたに命じる。起きよ、床を取りあげて家に帰れ」と言われた。</span>
<span className="v" id="v12" data-v="12" data-xref="マタイによる福音書 9:33; マタイによる福音書 9:8; ルカによる福音書 7:16"> すると彼は起きあがり、すぐに床を取りあげて、みんなの前を出て行ったので、一同は大いに驚き、神をあがめて、「こんな事は、まだ一度も見たことがない」と言った。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="マルコによる福音書 4:1; 箴言 1:20–22; ルカによる福音書 19:48"> イエスはまた海べに出て行かれると、多くの人々がみもとに集まってきたので、彼らを教えられた。</span>
<span className="v" id="v14" data-v="14" data-xref="ルカによる福音書 5:27–32; ルカによる福音書 6:15; マタイによる福音書 9:9–13"> また途中で、アルパヨの子レビが収税所にすわっているのをごらんになって、「わたしに従ってきなさい」と言われた。すると彼は立ちあがって、イエスに従った。</span>
<span className="v" id="v15" data-v="15" data-xref="ルカによる福音書 15:1; ルカによる福音書 5:29–30; マタイによる福音書 9:10–11"> それから彼の家で、食事の席についておられたときのことである。多くの取税人や罪人たちも、イエスや弟子たちと共にその席に着いていた。こんな人たちが大ぜいいて、イエスに従ってきたのである。</span>
<span className="v" id="v16" data-v="16" data-xref="ルカによる福音書 19:10; ルカによる福音書 19:7; ルカによる福音書 18:11"> パリサイ派の律法学者たちは、イエスが罪人や取税人たちと食事を共にしておられるのを見て、弟子たちに言った、「なぜ、彼は取税人や罪人などと食事を共にするのか」。</span>
<span className="v" id="v17" data-v="17" data-xref="マタイによる福音書 9:12–13; ルカによる福音書 15:7; ルカによる福音書 5:31–32"> イエスはこれを聞いて言われた、「丈夫な人には医者はいらない。いるのは病人である。わたしがきたのは、義人を招くためではなく、罪人を招くためである」。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="ルカによる福音書 18:12; マタイによる福音書 6:18; マタイによる福音書 9:14–17"> ヨハネの弟子とパリサイ人とは、断食をしていた。そこで人々がきて、イエスに言った、「ヨハネの弟子たちとパリサイ人の弟子たちとが断食をしているのに、あなたの弟子たちは、なぜ断食をしないのですか」。</span>
<span className="v" id="v19" data-v="19" data-xref="マタイによる福音書 25:1–10; 創世記 29:22; 士師記 14:10–11"> するとイエスは言われた、「婚礼の客は、花婿が一緒にいるのに、断食ができるであろうか。花婿と一緒にいる間は、断食はできない。</span>
<span className="v" id="v20" data-v="20" data-xref="ルカによる福音書 17:22; ヨハネの黙示録 21:9; イザヤ書 54:5"> しかし、花婿が奪い去られる日が来る。その日には断食をするであろう。</span>
<span className="v" id="v21" data-v="21" data-xref="マタイによる福音書 9:16; コリント人への第一の手紙 10:13; イザヤ書 57:16"> だれも、真新しい布ぎれを、古い着物に縫いつけはしない。もしそうすれば、新しいつぎは古い着物を引き破り、そして、破れがもっとひどくなる。</span>
<span className="v" id="v22" data-v="22" data-xref="マタイによる福音書 9:17; 詩篇 119:83; ルカによる福音書 5:37–38"> まただれも、新しいぶどう酒を古い皮袋に入れはしない。もしそうすれば、ぶどう酒は皮袋をはり裂き、そして、ぶどう酒も皮袋もむだになってしまう。〔だから、新しいぶどう酒は新しい皮袋に入れるべきである〕」。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="マタイによる福音書 12:1–8; 申命記 23:24–25; ルカによる福音書 6:1–5"> ある安息日に、イエスは麦畑の中をとおって行かれた。そのとき弟子たちが、歩きながら穂をつみはじめた。</span>
<span className="v" id="v24" data-v="24" data-xref="出エジプト記 20:10; ヘブル人への手紙 12:3; マタイによる福音書 12:2"> すると、パリサイ人たちがイエスに言った、「いったい、彼らはなぜ、安息日にしてはならぬことをするのですか」。</span>
<span className="v" id="v25" data-v="25" data-xref="サムエル記上 21:3–6; ルカによる福音書 10:26; マタイによる福音書 22:31"> そこで彼らに言われた、「あなたがたは、ダビデとその供の者たちとが食物がなくて飢えたとき、ダビデが何をしたか、まだ読んだことがないのか。</span>
<span className="v" id="v26" data-v="26" data-xref="サムエル記下 8:17; レビ記 24:5–9; サムエル記上 21:1"> すなわち、大祭司アビアタルの時、神の家にはいって、祭司たちのほか食べてはならぬ供えのパンを、自分も食べ、また供の者たちにも与えたではないか」。</span>
<span className="v" id="v27" data-v="27" data-xref="コロサイ人への手紙 2:16; ルカによる福音書 6:9; 申命記 5:14"> また彼らに言われた、「安息日は人のためにあるもので、人が安息日のためにあるのではない。</span>
<span className="v" id="v28" data-v="28" data-xref="マタイによる福音書 12:8; ヨハネの黙示録 1:10; ヨハネによる福音書 5:17"> それだから、人の子は、安息日にもまた主なのである」。</span>
</div>

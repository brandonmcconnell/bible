<div className="bible-chapter" lang="ja" dir="ltr" data-lang="ja" data-translation="jpn-kou" data-translation-id="jpn_kou" data-translation-label="口語訳" data-book="MRK" data-book-slug="mark" data-book-name="マルコによる福音書" data-chapter="14" data-verses="72">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ルカによる福音書 22:1–2; 出エジプト記 12:6–20; ヨハネによる福音書 13:1"> さて、過越と除酵との祭の二日前になった。祭司長たちや律法学者たちは、策略をもってイエスを捕えたうえ、なんとかして殺そうと計っていた。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネによる福音書 7:40; 箴言 21:30; ヨハネによる福音書 12:19"> 彼らは、「祭の間はいけない。民衆が騒ぎを起すかも知れない」と言っていた。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="ルカによる福音書 7:37–39; ヨハネによる福音書 12:1–8; ヨハネによる福音書 11:2"> イエスがベタニヤで、らい病人シモンの家にいて、食卓についておられたとき、ひとりの女が、非常に高価で純粋なナルドの香油が入れてある石膏のつぼを持ってきて、それをこわし、香油をイエスの頭に注ぎかけた。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネによる福音書 12:4–5; マタイによる福音書 26:8–9; マラキ書 1:12–13"> すると、ある人々が憤って互に言った、「なんのために香油をこんなにむだにするのか。</span>
<span className="v" id="v5" data-v="5" data-xref="ヨハネによる福音書 13:29; エペソ人への手紙 4:28; コリント人への第一の手紙 10:10"> この香油を三百デナリ以上にでも売って、貧しい人たちに施すことができたのに」。そして女をきびしくとがめた。</span>
<span className="v" id="v6" data-v="6" data-xref="テトスヘの手紙 3:14; ヘブル人への手紙 10:24; ヘブル人への手紙 13:21"> するとイエスは言われた、「するままにさせておきなさい。なぜ女を困らせるのか。わたしによい事をしてくれたのだ。</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 15:11; マタイによる福音書 26:11; ヤコブの手紙 2:14–16"> 貧しい人たちはいつもあなたがたと一緒にいるから、したいときにはいつでも、よい事をしてやれる。しかし、わたしはあなたがたといつも一緒にいるわけではない。</span>
<span className="v" id="v8" data-v="8" data-xref="コリント人への第二の手紙 8:12; ヨハネによる福音書 12:7; マルコによる福音書 15:42–1"> この女はできる限りの事をしたのだ。すなわち、わたしのからだに油を注いで、あらかじめ葬りの用意をしてくれたのである。</span>
<span className="v" id="v9" data-v="9" data-xref="マタイによる福音書 26:12–13; マルコによる福音書 16:15; マタイによる福音書 24:14"> よく聞きなさい。全世界のどこででも、福音が宣べ伝えられる所では、この女のした事も記念として語られるであろう」。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="ルカによる福音書 22:3–6; マタイによる福音書 26:14–16; ヨハネによる福音書 13:2"> ときに、十二弟子のひとりイスカリオテのユダは、イエスを祭司長たちに引きわたそうとして、彼らの所へ行った。</span>
<span className="v" id="v11" data-v="11" data-xref="テモテヘの第一の手紙 6:10; ホセア書 7:3; ユダの手紙 1:11"> 彼らはこれを聞いて喜び、金を与えることを約束した。そこでユダは、どうかしてイエスを引きわたそうと、機会をねらっていた。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="出エジプト記 12:6; 出エジプト記 12:18; マタイによる福音書 26:17–19"> 除酵祭の第一日、すなわち過越の小羊をほふる日に、弟子たちがイエスに尋ねた、「わたしたちは、過越の食事をなさる用意を、どこへ行ってしたらよいでしょうか」。</span>
<span className="v" id="v13" data-v="13" data-xref="ルカによる福音書 22:10–13; マタイによる福音書 26:18–19; ルカによる福音書 19:30–33"> そこで、イエスはふたりの弟子を使いに出して言われた、「市内に行くと、水がめを持っている男に出会うであろう。その人について行きなさい。</span>
<span className="v" id="v14" data-v="14" data-xref="ヨハネの黙示録 3:20; マルコによる福音書 11:3; ヨハネによる福音書 13:13"> そして、その人がはいって行く家の主人に言いなさい、『弟子たちと一緒に過越の食事をする座敷はどこか、と先生が言っておられます』。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行伝 1:13; 詩篇 110:3; 箴言 21:1–2"> するとその主人は、席を整えて用意された二階の広間を見せてくれるから、そこにわたしたちのために用意をしなさい」。</span>
<span className="v" id="v16" data-v="16" data-xref="ヨハネによる福音書 16:4; ルカによる福音書 22:13; ルカによる福音書 22:35"> 弟子たちは出かけて市内に行って見ると、イエスが言われたとおりであったので、過越の食事の用意をした。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="ルカによる福音書 22:14; ヨハネによる福音書 13:21–26; マタイによる福音書 26:20–24"> 夕方になって、イエスは十二弟子と一緒にそこに行かれた。</span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 41:9; ヨハネによる福音書 6:47; ヨハネによる福音書 6:70"> そして、一同が席について食事をしているとき言われた、「特にあなたがたに言っておくが、あなたがたの中のひとりで、わたしと一緒に食事をしている者が、わたしを裏切ろうとしている」。</span>
<span className="v" id="v19" data-v="19" data-xref="ルカによる福音書 22:21–23; マタイによる福音書 26:22; ヨハネによる福音書 13:22"> 弟子たちは心配して、ひとりびとり「まさか、わたしではないでしょう」と言い出した。</span>
<span className="v" id="v20" data-v="20" data-xref="ヨハネによる福音書 13:26; マタイによる福音書 26:23; ヨハネによる福音書 6:71"> イエスは言われた、「十二人の中のひとりで、わたしと一緒に同じ鉢にパンをひたしている者が、それである。</span>
<span className="v" id="v21" data-v="21" data-xref="マタイによる福音書 26:24–25; イザヤ書 53:1–12; ヨハネによる福音書 19:28"> たしかに人の子は、自分について書いてあるとおりに去って行く。しかし、人の子を裏切るその人は、わざわいである。その人は生れなかった方が、彼のためによかったであろう」。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="マタイによる福音書 26:26–29; マルコによる福音書 14:24; コリント人への第一の手紙 10:16–17"> 一同が食事をしているとき、イエスはパンを取り、祝福してこれをさき、弟子たちに与えて言われた、「取れ、これはわたしのからだである」。</span>
<span className="v" id="v23" data-v="23" data-xref="マルコによる福音書 14:22; マタイによる福音書 26:27; コリント人への第一の手紙 10:16"> また杯を取り、感謝して彼らに与えられると、一同はその杯から飲んだ。</span>
<span className="v" id="v24" data-v="24" data-xref="ゼカリヤ書 9:11; 出エジプト記 24:8; ヨハネの黙示録 7:9–17"> イエスはまた言われた、「これは、多くの人のために流すわたしの契約の血である。</span>
<span className="v" id="v25" data-v="25" data-xref="マタイによる福音書 26:29; 詩篇 104:15; ルカによる福音書 22:16–18"> あなたがたによく言っておく。神の国で新しく飲むその日までは、わたしは決して二度と、ぶどうの実から造ったものを飲むことをしない」。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="マタイによる福音書 26:30; ルカによる福音書 22:39; 使徒行伝 16:25"> 彼らは、さんびを歌った後、オリブ山へ出かけて行った。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="ゼカリヤ書 13:7; ヨハネによる福音書 16:32; マタイによる福音書 26:31"> そのとき、イエスは弟子たちに言われた、「あなたがたは皆、わたしにつまずくであろう。『わたしは羊飼を打つ。そして、羊は散らされるであろう』と書いてあるからである。</span>
<span className="v" id="v28" data-v="28" data-xref="マタイによる福音書 28:16; マルコによる福音書 16:7; マタイによる福音書 28:7"> しかしわたしは、よみがえってから、あなたがたより先にガリラヤへ行くであろう」。</span>
<span className="v" id="v29" data-v="29" data-xref="マタイによる福音書 26:33–35; ルカによる福音書 22:33–34; ヨハネによる福音書 13:36–38"> するとペテロはイエスに言った、「たとい、みんなの者がつまずいても、わたしはつまずきません」。</span>
<span className="v" id="v30" data-v="30" data-xref="ヨハネによる福音書 13:38; マルコによる福音書 14:66–72; 創世記 1:5"> イエスは言われた、「あなたによく言っておく。きょう、今夜、にわとりが二度鳴く前に、そう言うあなたが、三度わたしを知らないと言うだろう」。</span>
<span className="v" id="v31" data-v="31" data-xref="出エジプト記 19:8; ヨハネによる福音書 13:37; 箴言 16:18"> ペテロは力をこめて言った、「たといあなたと一緒に死なねばならなくなっても、あなたを知らないなどとは、決して申しません」。みんなの者もまた、同じようなことを言った。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="マルコによる福音書 14:36; マルコによる福音書 14:39; 詩篇 18:5–6"> さて、一同はゲツセマネという所にきた。そしてイエスは弟子たちに言われた、「わたしが祈っている間、ここにすわっていなさい」。</span>
<span className="v" id="v33" data-v="33" data-xref="ルカによる福音書 22:44; ヘブル人への手紙 5:7; マルコによる福音書 5:37"> そしてペテロ、ヤコブ、ヨハネを一緒に連れて行かれたが、恐れおののき、また悩みはじめて、彼らに言われた、</span>
<span className="v" id="v34" data-v="34" data-xref="ヨハネによる福音書 12:27; マルコによる福音書 13:35–37; ペテロの第一の手紙 5:8"> 「わたしは悲しみのあまり死ぬほどである。ここに待っていて、目をさましていなさい」。</span>
<span className="v" id="v35" data-v="35" data-xref="マルコによる福音書 14:41; 申命記 9:18; ヘブル人への手紙 5:7"> そして少し進んで行き、地にひれ伏し、もしできることなら、この時を過ぎ去らせてくださるようにと祈りつづけ、そして言われた、</span>
<span className="v" id="v36" data-v="36" data-xref="ガラテヤ人への手紙 4:6; ローマ人への手紙 8:15–16; ヨハネによる福音書 5:30"> 「アバ、父よ、あなたには、できないことはありません。どうか、この杯をわたしから取りのけてください。しかし、わたしの思いではなく、みこころのままになさってください」。</span>
<span className="v" id="v37" data-v="37" data-xref="マタイによる福音書 26:40; マルコによる福音書 14:29–31; ヘブル人への手紙 12:3"> それから、きてごらんになると、弟子たちが眠っていたので、ペテロに言われた、「シモンよ、眠っているのか、ひと時も目をさましていることができなかったのか。</span>
<span className="v" id="v38" data-v="38" data-xref="マタイによる福音書 26:41; マタイによる福音書 24:42; ルカによる福音書 21:36"> 誘惑に陥らないように、目をさまして祈っていなさい。心は熱しているが、肉体が弱いのである」。</span>
<span className="v" id="v39" data-v="39" data-xref="マタイによる福音書 26:42–44; コリント人への第二の手紙 12:8; マタイによる福音書 6:7"> また離れて行って同じ言葉で祈られた。</span>
<span className="v" id="v40" data-v="40" data-xref="マルコによる福音書 9:33–34; ローマ人への手紙 3:19; 創世記 44:16"> またきてごらんになると、彼らはまだ眠っていた。その目が重くなっていたのである。そして、彼らはどうお答えしてよいか、わからなかった。</span>
<span className="v" id="v41" data-v="41" data-xref="マルコによる福音書 14:35; マルコによる福音書 9:31; ヨハネによる福音書 17:1"> 三度目にきて言われた、「まだ眠っているのか、休んでいるのか。もうそれでよかろう。時がきた。見よ、人の子は罪人らの手に渡されるのだ。</span>
<span className="v" id="v42" data-v="42" data-xref="マタイによる福音書 26:46; ヨハネによる福音書 18:1–2"> 立て、さあ行こう。見よ、わたしを裏切る者が近づいてきた」。</span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="ヨハネによる福音書 18:3–11; ルカによる福音書 22:47–53; マタイによる福音書 26:47–56"> そしてすぐ、イエスがまだ話しておられるうちに、十二弟子のひとりのユダが進みよってきた。また祭司長、律法学者、長老たちから送られた群衆も、剣と棒とを持って彼についてきた。</span>
<span className="v" id="v44" data-v="44" data-xref="マタイによる福音書 26:48–50; 箴言 27:6; 詩篇 55:20–21"> イエスを裏切る者は、あらかじめ彼らに合図をしておいた、「わたしの接吻する者が、その人だ。その人をつかまえて、まちがいなく引ひっぱって行け」。</span>
<span className="v" id="v45" data-v="45" data-xref="マタイによる福音書 23:7–10; マラキ書 1:6; マルコによる福音書 12:14"> 彼は来るとすぐ、イエスに近寄り、「先生」と言って接吻した。</span>
<span className="v" id="v46" data-v="46" data-xref="ヨハネによる福音書 18:12; 哀歌 4:20; 使徒行伝 2:23"> 人々はイエスに手をかけてつかまえた。</span>
<span className="v" id="v47" data-v="47" data-xref="ヨハネによる福音書 18:10–11; マタイによる福音書 26:51–54; ルカによる福音書 22:49–51"> すると、イエスのそばに立っていた者のひとりが、剣を抜いて大祭司の僕に切りかかり、その片耳を切り落した。</span>
<span className="v" id="v48" data-v="48" data-xref="ルカによる福音書 22:52–53; サムエル記上 26:18; サムエル記上 24:14–15"> イエスは彼らにむかって言われた、「あなたがたは強盗にむかうように、剣や棒を持ってわたしを捕えにきたのか。</span>
<span className="v" id="v49" data-v="49" data-xref="ヨハネによる福音書 18:20; ヨハネによる福音書 8:2; ルカによる福音書 22:37"> わたしは毎日あなたがたと一緒に宮にいて教えていたのに、わたしをつかまえはしなかった。しかし聖書の言葉は成就されねばならない」。</span>
<span className="v" id="v50" data-v="50" data-xref="マルコによる福音書 14:27; ヨハネによる福音書 16:32; 詩篇 88:18"> 弟子たちは皆イエスを見捨てて逃げ去った。</span>
</div>
<div className="bp">
<span className="v" id="v51" data-v="51"> ときに、ある若者が身に亜麻布をまとって、イエスのあとについて行ったが、人々が彼をつかまえようとしたので、</span>
<span className="v" id="v52" data-v="52" data-xref="マルコによる福音書 13:14–16; 創世記 39:12; ヨブ記 2:4"> その亜麻布を捨てて、裸で逃げて行った。</span>
</div>
<div className="bp">
<span className="v" id="v53" data-v="53" data-xref="マタイによる福音書 26:57–68; ヨハネによる福音書 18:12–14; ルカによる福音書 22:54–62"> それから、イエスを大祭司のところに連れて行くと、祭司長、長老、律法学者たちがみな集まってきた。</span>
<span className="v" id="v54" data-v="54" data-xref="ヨハネによる福音書 18:18; マタイによる福音書 26:3; ヨハネによる福音書 18:25"> ペテロは遠くからイエスについて行って、大祭司の中庭まではいり込み、その下役どもにまじってすわり、火にあたっていた。</span>
</div>
<div className="bp">
<span className="v" id="v55" data-v="55" data-xref="ペテロの第一の手紙 3:16–18; マタイによる福音書 26:59–60; マタイによる福音書 5:22"> さて、祭司長たちと全議会とは、イエスを死刑にするために、イエスに不利な証拠を見つけようとしたが、得られなかった。</span>
<span className="v" id="v56" data-v="56"> 多くの者がイエスに対して偽証を立てたが、その証言が合わなかったからである。</span>
<span className="v" id="v57" data-v="57" data-xref="使徒行伝 6:13–14; マタイによる福音書 26:60–61; ヨハネによる福音書 2:18–21"> ついに、ある人々が立ちあがり、イエスに対して偽証を立てて言った、</span>
<span className="v" id="v58" data-v="58" data-xref="ヨハネによる福音書 2:19; ヘブル人への手紙 9:11; コリント人への第二の手紙 5:1"> 「わたしたちはこの人が『わたしは手で造ったこの神殿を打ちこわし、三日の後に手で造られない別の神殿を建てるのだ』と言うのを聞きました」。</span>
<span className="v" id="v59" data-v="59"> しかし、このような証言も互に合わなかった。</span>
<span className="v" id="v60" data-v="60" data-xref="ヨハネによる福音書 19:9–10; マタイによる福音書 26:62–63; マルコによる福音書 15:3–5"> そこで大祭司が立ちあがって、まん中に進み、イエスに聞きただして言った、「何も答えないのか。これらの人々があなたに対して不利な証言を申し立てているが、どうなのか」。</span>
<span className="v" id="v61" data-v="61" data-xref="マタイによる福音書 26:63–64; マルコによる福音書 15:2; イザヤ書 53:7"> しかし、イエスは黙っていて、何もお答えにならなかった。大祭司は再び聞きただして言った、「あなたは、ほむべき者の子、キリストであるか」。</span>
<span className="v" id="v62" data-v="62" data-xref="ダニエル書 7:13–14; 詩篇 110:1; ヘブル人への手紙 1:3"> イエスは言われた、「わたしがそれである。あなたがたは人の子が力ある者の右に座し、天の雲に乗って来るのを見るであろう」。</span>
<span className="v" id="v63" data-v="63" data-xref="マタイによる福音書 26:65; イザヤ書 36:22–1; 民数記 14:6"> すると、大祭司はその衣を引き裂いて言った、「どうして、これ以上、証人の必要があろう。</span>
<span className="v" id="v64" data-v="64" data-xref="レビ記 24:16; ヨハネによる福音書 10:31–33; ヨハネによる福音書 19:7"> あなたがたはこのけがし言を聞いた。あなたがたの意見はどうか」。すると、彼らは皆、イエスを死に当るものと断定した。</span>
<span className="v" id="v65" data-v="65" data-xref="マタイによる福音書 26:67–68; 使徒行伝 23:2; イザヤ書 50:6"> そして、ある者はイエスにつばきをかけ、目隠しをし、こぶしでたたいて、「言いあててみよ」と言いはじめた。また下役どもはイエスを引きとって、手のひらでたたいた。</span>
</div>
<div className="bp">
<span className="v" id="v66" data-v="66" data-xref="マルコによる福音書 14:54; マタイによる福音書 26:69–75; ヨハネによる福音書 18:25–27"> ペテロは下で中庭にいたが、大祭司の女中のひとりがきて、</span>
<span className="v" id="v67" data-v="67" data-xref="マルコによる福音書 14:54; マルコによる福音書 10:47; マタイによる福音書 2:23"> ペテロが火にあたっているのを見ると、彼を見つめて、「あなたもあのナザレ人イエスと一緒だった」と言った。</span>
<span className="v" id="v68" data-v="68" data-xref="マルコによる福音書 14:29–31; マタイによる福音書 26:71–72; ヨハネによる福音書 13:36–38"> するとペテロはそれを打ち消して、「わたしは知らない。あなたの言うことがなんの事か、わからない」と言って、庭口の方に出て行った。</span>
<span className="v" id="v69" data-v="69" data-xref="ルカによる福音書 22:58; マルコによる福音書 14:38; ガラテヤ人への手紙 6:1"> ところが、先の女中が彼を見て、そばに立っていた人々に、またもや「この人はあの仲間のひとりです」と言いだした。</span>
<span className="v" id="v70" data-v="70" data-xref="ルカによる福音書 22:59–60; マタイによる福音書 26:73–74; 使徒行伝 2:7"> ペテロは再びそれを打ち消した。しばらくして、そばに立っていた人たちがまたペテロに言った、「確かにあなたは彼らの仲間だ。あなたもガリラヤ人だから」。</span>
<span className="v" id="v71" data-v="71" data-xref="エレミヤ書 17:9; コリント人への第一の手紙 10:12; 列王紀下 10:32"> しかし、彼は、「あなたがたの話しているその人のことは何も知らない」と言い張って、激しく誓いはじめた。</span>
<span className="v" id="v72" data-v="72" data-xref="マルコによる福音書 14:30; マルコによる福音書 14:68; エゼキエル書 7:16"> するとすぐ、にわとりが二度目に鳴いた。ペテロは、「にわとりが二度鳴く前に、三度わたしを知らないと言うであろう」と言われたイエスの言葉を思い出し、そして思いかえして泣きつづけた。</span>

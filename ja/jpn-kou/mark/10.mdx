<div className="bible-chapter" lang="ja" dir="ltr" data-lang="ja" data-translation="jpn-kou" data-translation-id="jpn_kou" data-translation-label="口語訳" data-book="MRK" data-book-slug="mark" data-book-name="マルコによる福音書" data-chapter="10" data-verses="52">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨハネによる福音書 10:40; マルコによる福音書 4:2; ヨハネによる福音書 11:7"> それから、イエスはそこを去って、ユダヤの地方とヨルダンの向こう側へ行かれたが、群衆がまた寄り集まったので、いつものように、また教えておられた。</span>
<span className="v" id="v2" data-v="2" data-xref="コリント人への第一の手紙 7:10–11; ルカによる福音書 11:53–54; ヨハネによる福音書 8:6"> そのとき、パリサイ人たちが近づいてきて、イエスを試みようとして質問した、「夫はその妻を出しても差しつかえないでしょうか」。</span>
<span className="v" id="v3" data-v="3" data-xref="イザヤ書 8:20; ガラテヤ人への手紙 4:21; ルカによる福音書 10:25"> イエスは答えて言われた、「モーセはあなたがたになんと命じたか」。</span>
<span className="v" id="v4" data-v="4" data-xref="申命記 24:1–4; マタイによる福音書 5:31–32; イザヤ書 50:1"> 彼らは言った、「モーセは、離縁状を書いて妻を出すことを許しました」。</span>
<span className="v" id="v5" data-v="5" data-xref="マタイによる福音書 19:8; ネヘミヤ書 9:26; 使徒行伝 7:51"> そこでイエスは言われた、「モーセはあなたがたの心が、かたくななので、あなたがたのためにこの定めを書いたのである。</span>
<span className="v" id="v6" data-v="6" data-xref="創世記 1:27; 創世記 5:2; 創世記 1:1"> しかし、天地創造の初めから、『神は人を男と女とに造られた。</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 2:24; マタイによる福音書 19:5–6; エペソ人への手紙 5:31"> それゆえに、人はその父母を離れ、</span>
<span className="v" id="v8" data-v="8" data-xref="エペソ人への手紙 5:28; 創世記 2:24; コリント人への第一の手紙 6:16"> ふたりの者は一体となるべきである』。彼らはもはや、ふたりではなく一体である。</span>
<span className="v" id="v9" data-v="9" data-xref="ローマ人への手紙 7:1–3; 歴代志上 7:10–13"> だから、神が合わせられたものを、人は離してはならない」。</span>
<span className="v" id="v10" data-v="10" data-xref="マルコによる福音書 9:33; マルコによる福音書 9:28; マルコによる福音書 4:10"> 家にはいってから、弟子たちはまたこのことについて尋ねた。</span>
<span className="v" id="v11" data-v="11" data-xref="マタイによる福音書 5:31–32; マタイによる福音書 19:9; コリント人への第一の手紙 7:10–11"> そこで、イエスは言われた、「だれでも、自分の妻を出して他の女をめとる者は、その妻に対して姦淫を行うのである。</span>
<span className="v" id="v12" data-v="12" data-xref="コリント人への第一の手紙 7:11; コリント人への第一の手紙 7:13"> また妻が、その夫と別れて他の男にとつぐならば、姦淫を行うのである」。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="マタイによる福音書 19:13–15; ルカによる福音書 18:15–17; 出エジプト記 10:9–11"> イエスにさわっていただくために、人々が幼な子らをみもとに連れてきた。ところが、弟子たちは彼らをたしなめた。</span>
<span className="v" id="v14" data-v="14" data-xref="マタイによる福音書 19:14; マタイによる福音書 18:10; マタイによる福音書 18:4"> それを見てイエスは憤り、彼らに言われた、「幼な子らをわたしの所に来るままにしておきなさい。止めてはならない。神の国はこのような者の国である。</span>
<span className="v" id="v15" data-v="15" data-xref="マタイによる福音書 18:3; ルカによる福音書 18:17; ヨハネによる福音書 3:3–6"> よく聞いておくがよい。だれでも幼な子のように神の国を受けいれる者でなければ、そこにはいることは決してできない」。</span>
<span className="v" id="v16" data-v="16" data-xref="マルコによる福音書 9:36; イザヤ書 40:11; ヨハネによる福音書 21:15–17"> そして彼らを抱き、手をその上において祝福された。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="マタイによる福音書 19:16–30; ルカによる福音書 18:18–30; ローマ人への手紙 2:7"> イエスが道に出て行かれると、ひとりの人が走り寄り、みまえにひざまずいて尋ねた、「よき師よ、永遠の生命を受けるために、何をしたらよいでしょうか」。</span>
<span className="v" id="v18" data-v="18" data-xref="ルカによる福音書 18:19; マタイによる福音書 19:17; ローマ人への手紙 3:12"> イエスは言われた、「なぜわたしをよき者と言うのか。神ひとりのほかによい者はいない。</span>
<span className="v" id="v19" data-v="19" data-xref="出エジプト記 20:12–17; ローマ人への手紙 13:9; ヤコブの手紙 2:11"> いましめはあなたの知っているとおりである。『殺すな、姦淫するな、盗むな、偽証を立てるな。欺き取るな。父と母とを敬え』」。</span>
<span className="v" id="v20" data-v="20" data-xref="エゼキエル書 33:31–32; テモテヘの第二の手紙 3:5; ピリピ人への手紙 3:6"> すると、彼は言った、「先生、それらの事はみな、小さい時から守っております」。</span>
<span className="v" id="v21" data-v="21" data-xref="マタイによる福音書 6:19–21; ヨハネの黙示録 2:4; ルカによる福音書 18:22"> イエスは彼に目をとめ、いつくしんで言われた、「あなたに足りないことが一つある。帰って、持っているものをみな売り払って、貧しい人々に施しなさい。そうすれば、天に宝を持つようになろう。そして、わたしに従ってきなさい」。</span>
<span className="v" id="v22" data-v="22" data-xref="ヨハネの第一の手紙 2:15–16; テモテヘの第一の手紙 6:9–10; ルカによる福音書 12:15"> すると、彼はこの言葉を聞いて、顔を曇らせ、悲しみながら立ち去った。たくさんの資産を持っていたからである。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="コリント人への第一の手紙 1:26; ルカによる福音書 18:24; マルコによる福音書 3:5"> それから、イエスは見まわして、弟子たちに言われた、「財産のある者が神の国にはいるのは、なんとむずかしいことであろう」。</span>
<span className="v" id="v24" data-v="24" data-xref="ヤコブの手紙 5:1–3; 箴言 11:28; 詩篇 52:7"> 弟子たちはこの言葉に驚き怪しんだ。イエスは更に言われた、「子たちよ、神の国にはいるのは、なんとむずかしいことであろう。</span>
<span className="v" id="v25" data-v="25" data-xref="マタイによる福音書 19:24–25; ルカによる福音書 18:25; マタイによる福音書 23:24"> 富んでいる者が神の国にはいるよりは、らくだが針の穴を通る方が、もっとやさしい」。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行伝 16:31; コリント人への第二の手紙 11:23; ローマ人への手紙 10:9–13"> すると彼らはますます驚いて、互に言った、「それでは、だれが救われることができるのだろう」。</span>
<span className="v" id="v27" data-v="27" data-xref="マタイによる福音書 19:26; エレミヤ書 32:27; ヨブ記 42:2"> イエスは彼らを見つめて言われた、「人にはできないが、神にはできる。神はなんでもできるからである」。</span>
<span className="v" id="v28" data-v="28" data-xref="マタイによる福音書 19:27–30; ルカによる福音書 18:28–30; ルカによる福音書 14:33"> ペテロがイエスに言い出した、「ごらんなさい、わたしたちはいっさいを捨てて、あなたに従って参りました」。</span>
<span className="v" id="v29" data-v="29" data-xref="コリント人への第一の手紙 9:23; マタイによる福音書 5:10–11; マルコによる福音書 8:35"> イエスは言われた、「よく聞いておくがよい。だれでもわたしのために、また福音のために、家、兄弟、姉妹、母、父、子、もしくは畑を捨てた者は、</span>
<span className="v" id="v30" data-v="30" data-xref="ルカによる福音書 18:30; ピリピ人への手紙 3:8; コリント人への第二の手紙 6:10"> 必ずその百倍を受ける。すなわち、今この時代では家、兄弟、姉妹、母、子および畑を迫害と共に受け、また、きたるべき世では永遠の生命を受ける。</span>
<span className="v" id="v31" data-v="31" data-xref="マタイによる福音書 19:30; ルカによる福音書 13:30; マタイによる福音書 20:16"> しかし、多くの先の者はあとになり、あとの者は先になるであろう」。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="マタイによる福音書 20:17–19; ルカによる福音書 18:31–34; ルカによる福音書 9:51"> さて、一同はエルサレムへ上る途上にあったが、イエスが先頭に立って行かれたので、彼らは驚き怪しみ、従う者たちは恐れた。するとイエスはまた十二弟子を呼び寄せて、自分の身に起ろうとすることについて語りはじめられた、</span>
<span className="v" id="v33" data-v="33" data-xref="マタイによる福音書 27:2; マタイによる福音書 20:17–19; マルコによる福音書 8:31"> 「見よ、わたしたちはエルサレムへ上って行くが、人の子は祭司長、律法学者たちの手に引きわたされる。そして彼らは死刑を宣告した上、彼を異邦人に引きわたすであろう。</span>
<span className="v" id="v34" data-v="34" data-xref="マタイによる福音書 26:67; マタイによる福音書 16:21; マルコによる福音書 14:65"> また彼をあざけり、つばきをかけ、むち打ち、ついに殺してしまう。そして彼は三日の後によみがえるであろう」。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="マタイによる福音書 20:20–28; サムエル記下 14:4–11; 列王紀上 2:20"> さて、ゼベダイの子のヤコブとヨハネとがイエスのもとにきて言った、「先生、わたしたちがお頼みすることは、なんでもかなえてくださるようにお願いします」。</span>
<span className="v" id="v36" data-v="36" data-xref="ヨハネによる福音書 15:7; 列王紀上 3:5–15; マルコによる福音書 10:51"> イエスは彼らに「何をしてほしいと、願うのか」と言われた。</span>
<span className="v" id="v37" data-v="37" data-xref="マタイによる福音書 19:28; マルコによる福音書 16:19; ルカによる福音書 24:26"> すると彼らは言った、「栄光をお受けになるとき、ひとりをあなたの右に、ひとりを左にすわるようにしてください」。</span>
<span className="v" id="v38" data-v="38" data-xref="ルカによる福音書 12:50; マタイによる福音書 20:21–22; 詩篇 75:8"> イエスは言われた、「あなたがたは自分が何を求めているのか、わかっていない。あなたがたは、わたしが飲む杯を飲み、わたしが受けるバプテスマを受けることができるか」。</span>
<span className="v" id="v39" data-v="39" data-xref="使徒行伝 12:2; ヨハネの黙示録 1:9; ヨハネによる福音書 17:14"> 彼らは「できます」と答えた。するとイエスは言われた、「あなたがたは、わたしが飲む杯を飲み、わたしが受けるバプテスマを受けるであろう。</span>
<span className="v" id="v40" data-v="40" data-xref="マタイによる福音書 20:23; マタイによる福音書 25:34; ヨハネによる福音書 17:24"> しかし、わたしの右、左にすわらせることは、わたしのすることではなく、ただ備えられている人々だけに許されることである」。</span>
<span className="v" id="v41" data-v="41" data-xref="マタイによる福音書 20:24; 箴言 13:10; ローマ人への手紙 12:10"> 十人の者はこれを聞いて、ヤコブとヨハネとのことで憤慨し出した。</span>
<span className="v" id="v42" data-v="42" data-xref="ペテロの第一の手紙 5:3; ルカによる福音書 22:25; マタイによる福音書 20:25"> そこで、イエスは彼らを呼び寄せて言われた、「あなたがたの知っているとおり、異邦人の支配者と見られている人々は、その民を治め、また偉い人たちは、その民の上に権力をふるっている。</span>
<span className="v" id="v43" data-v="43" data-xref="マタイによる福音書 23:8–12; ルカによる福音書 14:11; マルコによる福音書 9:35"> しかし、あなたがたの間では、そうであってはならない。かえって、あなたがたの間で偉くなりたいと思う者は、仕える人となり、</span>
<span className="v" id="v44" data-v="44"> あなたがたの間でかしらになりたいと思う者は、すべての人の僕とならねばならない。</span>
<span className="v" id="v45" data-v="45" data-xref="マタイによる福音書 20:28; ピリピ人への手紙 2:5–8; コリント人への第二の手紙 8:9"> 人の子がきたのも、仕えられるためではなく、仕えるためであり、また多くの人のあがないとして、自分の命を与えるためである」。</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="ルカによる福音書 18:35–1; マタイによる福音書 20:29–34; ヨハネによる福音書 9:8"> それから、彼らはエリコにきた。そして、イエスが弟子たちや大ぜいの群衆と共にエリコから出かけられたとき、テマイの子、バルテマイという盲人のこじきが、道ばたにすわっていた。</span>
<span className="v" id="v47" data-v="47" data-xref="マルコによる福音書 1:24; マタイによる福音書 9:27; ヨハネの黙示録 22:16"> ところが、ナザレのイエスだと聞いて、彼は「ダビデの子イエスよ、わたしをあわれんでください」と叫び出した。</span>
<span className="v" id="v48" data-v="48" data-xref="エレミヤ書 29:13; マルコによる福音書 7:26–29; ヘブル人への手紙 5:7"> 多くの人々は彼をしかって黙らせようとしたが、彼はますます激しく叫びつづけた、「ダビデの子イエスよ、わたしをあわれんでください」。</span>
<span className="v" id="v49" data-v="49" data-xref="ルカによる福音書 18:40; マタイによる福音書 20:32–34; ヨハネによる福音書 11:28"> イエスは立ちどまって「彼を呼べ」と命じられた。そこで、人々はその盲人を呼んで言った、「喜べ、立て、おまえを呼んでおられる」。</span>
<span className="v" id="v50" data-v="50" data-xref="ピリピ人への手紙 3:7–9; ヘブル人への手紙 12:1"> そこで彼は上着を脱ぎ捨て、踊りあがってイエスのもとにきた。</span>
<span className="v" id="v51" data-v="51" data-xref="ルカによる福音書 18:41–43; マルコによる福音書 10:36; マタイによる福音書 7:7"> イエスは彼にむかって言われた、「わたしに何をしてほしいのか」。その盲人は言った、「先生、見えるようになることです」。</span>
<span className="v" id="v52" data-v="52" data-xref="マタイによる福音書 9:22; 使徒行伝 26:18; マルコによる福音書 8:25"> そこでイエスは言われた、「行け、あなたの信仰があなたを救った」。すると彼は、たちまち見えるようになり、イエスに従って行った。</span>
</div>

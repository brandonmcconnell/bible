<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ルカによる福音書 23:56–12; ヨハネによる福音書 20:1–10; マタイによる福音書 28:1–10"> さて、安息日が終ったので、マグダラのマリヤとヤコブの母マリヤとサロメとが、行ってイエスに塗るために、香料を買い求めた。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネによる福音書 20:1; ルカによる福音書 24:1; マタイによる福音書 28:1"> そして週の初めの日に、早朝、日の出のころ墓に行った。</span>
<span className="v" id="v3" data-v="3" data-xref="マルコによる福音書 15:46–47; マタイによる福音書 27:60–66"> そして、彼らは「だれが、わたしたちのために、墓の入口から石をころがしてくれるのでしょうか」と話し合っていた。</span>
<span className="v" id="v4" data-v="4" data-xref="マタイによる福音書 28:2–4; ルカによる福音書 24:2; ヨハネによる福音書 20:1"> ところが、目をあげて見ると、石はすでにころがしてあった。この石は非常に大きかった。</span>
<span className="v" id="v5" data-v="5" data-xref="ヨハネによる福音書 20:11–12; ルカによる福音書 24:3–5; ヨハネによる福音書 20:8"> 墓の中にはいると、右手に真白な長い衣を着た若者がすわっているのを見て、非常に驚いた。</span>
<span className="v" id="v6" data-v="6" data-xref="ヨハネの黙示録 1:17–18; コリント人への第一の手紙 15:3–7; ルカによる福音書 24:46"> するとこの若者は言った、「驚くことはない。あなたがたは十字架につけられたナザレ人イエスを捜しているのであろうが、イエスはよみがえって、ここにはおられない。ごらんなさい、ここがお納めした場所である。</span>
<span className="v" id="v7" data-v="7" data-xref="マルコによる福音書 14:28; マタイによる福音書 26:32; マタイによる福音書 28:10"> 今から弟子たちとペテロとの所へ行って、こう伝えなさい。イエスはあなたがたより先にガリラヤへ行かれる。かねて、あなたがたに言われたとおり、そこでお会いできるであろう、と」。</span>
<span className="v" id="v8" data-v="8" data-xref="ルカによる福音書 24:22–24; ルカによる福音書 24:9–11; マルコによる福音書 16:5–6"> 女たちはおののき恐れながら、墓から出て逃げ去った。そして、人には何も言わなかった。恐ろしかったからである。<br />〔</span>
<span className="v" id="v9" data-v="9" data-xref="ヨハネによる福音書 20:14–19; ルカによる福音書 8:2; ヨハネによる福音書 20:12"> 週の初めの日の朝早く、イエスはよみがえって、まずマグダラのマリヤに御自身をあらわされた。イエスは以前に、この女から七つの悪霊を追い出されたことがある。</span>
<span className="v" id="v10" data-v="10" data-xref="ヨハネによる福音書 20:18; ルカによる福音書 24:17; ヨハネによる福音書 16:6"> マリヤは、イエスと一緒にいた人々が泣き悲しんでいる所に行って、それを知らせた。</span>
<span className="v" id="v11" data-v="11" data-xref="ルカによる福音書 24:11; マルコによる福音書 16:13–14; マルコによる福音書 9:19"> 彼らは、イエスが生きておられる事と、彼女に御自身をあらわされた事とを聞いたが、信じなかった。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="ルカによる福音書 24:13–32; ヨハネによる福音書 21:14; ヨハネによる福音書 21:1"> この後、そのうちのふたりが、いなかの方へ歩いていると、イエスはちがった姿で御自身をあらわされた。</span>
<span className="v" id="v13" data-v="13" data-xref="ヨハネによる福音書 20:25; ルカによる福音書 24:33–35; ヨハネによる福音書 20:8"> このふたりも、ほかの人々の所に行って話したが、彼らはその話を信じなかった。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="コリント人への第一の手紙 15:5; ルカによる福音書 24:36–43; ヘブル人への手紙 3:7–8"> その後、イエスは十一弟子が食卓についているところに現れ、彼らの不信仰と、心のかたくななことをお責めになった。彼らは、よみがえられたイエスを見た人々の言うことを、信じなかったからである。</span>
<span className="v" id="v15" data-v="15" data-xref="マタイによる福音書 28:19; マルコによる福音書 13:10; 使徒行伝 1:8"> そして彼らに言われた、「全世界に出て行って、すべての造られたものに福音を宣べ伝えよ。</span>
<span className="v" id="v16" data-v="16" data-xref="ヨハネによる福音書 11:25–26; ヨハネによる福音書 3:36; ローマ人への手紙 10:9–14"> 信じてバプテスマを受ける者は救われる。しかし、不信仰の者は罪に定められる。</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行伝 5:16; コリント人への第一の手紙 12:28; 使徒行伝 8:7"> 信じる者には、このようなしるしが伴う。すなわち、彼らはわたしの名で悪霊を追い出し、新しい言葉を語り、</span>
<span className="v" id="v18" data-v="18" data-xref="ルカによる福音書 10:19; ヤコブの手紙 5:14–15; 使徒行伝 28:3–6"> へびをつかむであろう。また、毒を飲んでも、決して害を受けない。病人に手をおけば、いやされる」。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="ペテロの第一の手紙 3:22; ヘブル人への手紙 1:3; ヘブル人への手紙 12:2"> 主イエスは彼らに語り終ってから、天にあげられ、神の右にすわられた。</span>
<span className="v" id="v20" data-v="20" data-xref="コリント人への第一の手紙 2:4–5; 使徒行伝 14:3; ローマ人への手紙 15:19"> 弟子たちは出て行って、至る所で福音を宣べ伝えた。主も彼らと共に働き、御言に伴うしるしをもって、その確かなことをお示しになった。〕</span>
</div>

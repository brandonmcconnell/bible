<span className="v" id="v1" data-v="1" data-xref="箴言 19:10; 箴言 28:16; エステル記 4:6"> <span className="pl pl-1">誉が愚かな者にふさわしくないのは、</span><br /><span className="pl pl-1">夏に雪が降り、刈入れの時に雨が降るようなものだ。</span></span>
<span className="v" id="v2" data-v="2" data-xref="民数記 23:8; ネヘミヤ書 13:2; 詩篇 109:28"> <span className="pl pl-1">いわれのないのろいは、飛びまわるすずめや、</span><br /><span className="pl pl-1">飛びかけるつばめのようなもので、止まらない。</span></span>
<span className="v" id="v3" data-v="3" data-xref="箴言 10:13; 詩篇 32:9; コリント人への第一の手紙 4:21"> <span className="pl pl-1">馬のためにはむちがあり、</span><br /><span className="pl pl-1">ろばのためにはくつわがあり、</span><br /><span className="pl pl-1">愚かな者の背のためにはつえがある。</span></span>
<span className="v" id="v4" data-v="4" data-xref="箴言 26:5; ペテロの第一の手紙 3:9; ユダの手紙 1:9"> <span className="pl pl-1">愚かな者にその愚かさにしたがって答をするな、</span><br /><span className="pl pl-1">自分も彼と同じようにならないためだ。</span></span>
<span className="v" id="v5" data-v="5" data-xref="ローマ人への手紙 12:16; マタイによる福音書 16:1–4; 箴言 28:11"> <span className="pl pl-1">愚かな者にその愚かさにしたがって答をせよ、</span><br /><span className="pl pl-1">彼が自分の目に自らを知恵ある者と見ないためだ。</span></span>
<span className="v" id="v6" data-v="6" data-xref="箴言 10:26; 箴言 25:13; 箴言 13:17"> <span className="pl pl-1">愚かな者に託して事を言い送る者は、</span><br /><span className="pl pl-1">自分の足を切り去り、身に害をうける。</span></span>
<span className="v" id="v7" data-v="7" data-xref="箴言 26:9; 詩篇 64:8; 箴言 17:7"> <span className="pl pl-1">あしなえの足は用がない、</span><br /><span className="pl pl-1">愚かな者の口には箴言もそれにひとしい。</span></span>
<span className="v" id="v8" data-v="8" data-xref="箴言 26:1; 箴言 30:22; 箴言 19:10"> <span className="pl pl-1">誉を愚かな者に与えるのは、</span><br /><span className="pl pl-1">石を石投げにつなぐようだ。</span></span>
<span className="v" id="v9" data-v="9" data-xref="箴言 23:35"> <span className="pl pl-1">愚かな者の口に箴言があるのは、</span><br /><span className="pl pl-1">酔った者が、とげのあるつえを手で振り上げるようだ。</span></span>
<span className="v" id="v10" data-v="10" data-xref="ローマ人への手紙 2:6; 箴言 11:31"> <span className="pl pl-1">通りがかりの愚か者や、酔った者を雇う者は、</span><br /><span className="pl pl-1">すべての人を傷つける射手のようだ。</span></span>
<span className="v" id="v11" data-v="11" data-xref="ペテロの第二の手紙 2:22; マタイによる福音書 12:45; 出エジプト記 8:15"> <span className="pl pl-1">犬が帰って来てその吐いた物を食べるように、</span><br /><span className="pl pl-1">愚かな者はその愚かさをくり返す。</span></span>
<span className="v" id="v12" data-v="12" data-xref="箴言 29:20; コリント人への第一の手紙 3:18–19; 箴言 26:5"> <span className="pl pl-1">自分の目に自らを知恵ある者とする人を、</span><br /><span className="pl pl-1">あなたは見るか、</span><br /><span className="pl pl-1">彼よりもかえって愚かな人に望みがある。</span></span>
<span className="v" id="v13" data-v="13" data-xref="箴言 22:13; 箴言 19:15; 箴言 15:19"> <span className="pl pl-1">なまけ者は、「道にししがいる、</span><br /><span className="pl pl-1">ちまたにししがいる」という。</span></span>
<span className="v" id="v14" data-v="14" data-xref="ヘブル人への手紙 6:12; 箴言 12:27; 箴言 12:24"> <span className="pl pl-1">戸がちょうつがいによって回るように、</span><br /><span className="pl pl-1">なまけ者はその寝床で寝返りをする。</span></span>
<span className="v" id="v15" data-v="15" data-xref="箴言 19:24"> <span className="pl pl-1">なまけ者は手を皿に入れても、</span><br /><span className="pl pl-1">それを口に持ってゆくことをいとう。</span></span>
<span className="v" id="v16" data-v="16" data-xref="箴言 26:12; ペテロの第一の手紙 3:15; 箴言 12:15"> <span className="pl pl-1">なまけ者は自分の目に、</span><br /><span className="pl pl-1">良く答えることのできる七人の者よりも、</span><br /><span className="pl pl-1">自らを知恵ありとする。</span></span>
<span className="v" id="v17" data-v="17" data-xref="箴言 20:3; テモテヘの第二の手紙 2:23–24; ルカによる福音書 12:14"> <span className="pl pl-1">自分に関係のない争いにたずさわる者は、</span><br /><span className="pl pl-1">通りすぎる犬の耳をとらえる者のようだ。</span></span>
<span className="v" id="v18" data-v="18" data-xref="箴言 25:18; イザヤ書 50:11; 箴言 7:23"> <span className="pl pl-1">隣り人を欺いて、</span><br /><span className="pl pl-1">「わたしはただ戯れにした」という者は、</span><br /><span className="pl pl-1">燃え木または矢、または死を、</span><br /><span className="pl pl-1">投げつける気違いのようだ。</span></span>
<span className="v" id="v20" data-v="20" data-xref="箴言 22:10; ヤコブの手紙 3:6; 箴言 16:28"> <span className="pl pl-1">たきぎがなければ火は消え、</span><br /><span className="pl pl-1">人のよしあしを言う者がなければ争いはやむ。</span></span>
<span className="v" id="v21" data-v="21" data-xref="箴言 15:18; 箴言 29:22; サムエル記下 20:1"> <span className="pl pl-1">おき火に炭をつぎ、火にたきぎをくべるように、</span><br /><span className="pl pl-1">争いを好む人は争いの火をおこす。</span></span>
<span className="v" id="v22" data-v="22" data-xref="箴言 18:8; 箴言 20:19; エゼキエル書 22:9"> <span className="pl pl-1">人のよしあしをいう者の言葉は</span><br /><span className="pl pl-1">おいしい食物のようで、腹の奥にしみこむ。</span></span>
<span className="v" id="v23" data-v="23" data-xref="ルカによる福音書 22:47–48; ルカによる福音書 11:39; 箴言 10:18"> <span className="pl pl-1">くちびるはなめらかであっても、心の悪いのは</span><br /><span className="pl pl-1">上ぐすりをかけた土の器のようだ。</span></span>
<span className="v" id="v24" data-v="24" data-xref="箴言 12:20; 箴言 10:18; 詩篇 41:6"> <span className="pl pl-1">憎む者はくちびるをもって自ら飾るけれども、</span><br /><span className="pl pl-1">心のうちには偽りをいだく。</span></span>
<span className="v" id="v25" data-v="25" data-xref="箴言 6:16–19; エレミヤ書 12:6; 詩篇 28:3"> <span className="pl pl-1">彼が声をやわらげて語っても、信じてはならない。</span><br /><span className="pl pl-1">その心に七つの憎むべきものがあるからだ。</span></span>
<span className="v" id="v26" data-v="26" data-xref="詩篇 55:21–23; サムエル記上 18:17; サムエル記上 18:21"> <span className="pl pl-1">たとい偽りをもってその憎しみをかくしても、</span><br /><span className="pl pl-1">彼の悪は会衆の中に現れる。</span></span>
<span className="v" id="v27" data-v="27" data-xref="箴言 28:10; 詩篇 9:15; 詩篇 7:15–16"> <span className="pl pl-1">穴を掘る者は自らその中に陥る、</span><br /><span className="pl pl-1">石をまろばしあげる者の上に、その石はまろびかえる。</span></span>
<span className="v" id="v28" data-v="28" data-xref="ヨハネによる福音書 8:44–49; ルカによる福音書 20:20–21; ヨハネによる福音書 10:32–33"> <span className="pl pl-1">偽りの舌は自分が傷つけた者を憎み、</span><br /><span className="pl pl-1">へつらう口は滅びをきたらせる。</span></span>

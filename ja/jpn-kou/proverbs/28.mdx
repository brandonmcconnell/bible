<span className="v" id="v1" data-v="1" data-xref="申命記 28:7; 詩篇 53:5; イザヤ書 26:3–4"> <span className="pl pl-1">悪しき者は追う人もないのに逃げる、</span><br /><span className="pl pl-1">正しい人はししのように勇ましい。</span></span>

<span className="v" id="v3" data-v="3" data-xref="マタイによる福音書 18:28–30"> <span className="pl pl-1">貧しい者をしえたげる貧しい人は、</span><br /><span className="pl pl-1">糧食を残さない激しい雨のようだ。</span></span>
<span className="v" id="v4" data-v="4" data-xref="ローマ人への手紙 1:32; エペソ人への手紙 5:11; マタイによる福音書 14:4"> <span className="pl pl-1">律法を捨てる者は悪しき者をほめる、</span><br /><span className="pl pl-1">律法を守る者はこれに敵対する。</span></span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 92:6; ヤコブの手紙 1:5; ヨハネの第一の手紙 2:27"> <span className="pl pl-1">悪人は正しいことを悟らない、</span><br /><span className="pl pl-1">主を求める者はこれをことごとく悟る。</span></span>
<span className="v" id="v6" data-v="6" data-xref="箴言 19:1; 箴言 28:18; ルカによる福音書 16:19–23"> <span className="pl pl-1">正しく歩む貧しい者は、</span><br /><span className="pl pl-1">曲った道を歩む富める者にまさる。</span></span>
<span className="v" id="v7" data-v="7" data-xref="ペテロの第一の手紙 4:3–4; 箴言 29:3; 箴言 3:1–35"> <span className="pl pl-1">律法を守る者は賢い子である、</span><br /><span className="pl pl-1">不品行な者と交わるものは、父をはずかしめる。</span></span>
<span className="v" id="v8" data-v="8" data-xref="ヨブ記 27:16–17; 箴言 13:22; 伝道の書 2:26"> <span className="pl pl-1">利息と高利とによってその富をます者は、</span><br /><span className="pl pl-1">貧しい者を恵む者のために、それをたくわえる。</span></span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 66:18; テモテヘの第二の手紙 4:3–4; ゼカリヤ書 7:11–13"> <span className="pl pl-1">耳をそむけて律法を聞かない者は、</span><br /><span className="pl pl-1">その祈でさえも憎まれる。</span></span>
<span className="v" id="v10" data-v="10" data-xref="箴言 26:27; 詩篇 37:25–26; ガラテヤ人への手紙 2:4"> <span className="pl pl-1">正しい者を悪い道に惑わす者は、</span><br /><span className="pl pl-1">みずから自分の穴に陥る、</span><br /><span className="pl pl-1">しかし誠実な人は幸福を継ぐ。</span></span>
<span className="v" id="v11" data-v="11" data-xref="箴言 18:17; 伝道の書 9:15–17; 箴言 26:16"> <span className="pl pl-1">富める人は自分の目に自らを知恵ある者と見る、</span><br /><span className="pl pl-1">しかし悟りのある貧しい者は彼を見やぶる。</span></span>
<span className="v" id="v12" data-v="12" data-xref="箴言 29:2; 箴言 11:10; 箴言 28:28"> <span className="pl pl-1">正しい者が勝つときは、大いなる栄えがある、</span><br /><span className="pl pl-1">悪しき者が起るときは、民は身をかくす。</span></span>
<span className="v" id="v13" data-v="13" data-xref="ヨハネの第一の手紙 1:8–10; 詩篇 32:3–5; ヨブ記 31:33"> <span className="pl pl-1">その罪を隠す者は栄えることがない、</span><br /><span className="pl pl-1">言い表わしてこれを離れる者は、あわれみをうける。</span></span>
<span className="v" id="v14" data-v="14" data-xref="箴言 23:17; 詩篇 2:11; イザヤ書 66:2"> <span className="pl pl-1">常に主を恐れる人はさいわいである、</span><br /><span className="pl pl-1">心をかたくなにする者は災に陥る。</span></span>
<span className="v" id="v15" data-v="15" data-xref="ペテロの第一の手紙 5:8; マタイによる福音書 2:16; 箴言 19:12"> <span className="pl pl-1">貧しい民を治める悪いつかさは、</span><br /><span className="pl pl-1">ほえるしし、または飢えたくまのようだ。</span></span>
<span className="v" id="v16" data-v="16" data-xref="出エジプト記 18:21; エレミヤ書 22:15–17; 伝道の書 4:1"> <span className="pl pl-1">悟りのないつかさは残忍な圧制者である、</span><br /><span className="pl pl-1">不正の利を憎む者は長命を得る。</span></span>
<span className="v" id="v17" data-v="17" data-xref="創世記 9:6; 列王紀上 21:19; 出エジプト記 21:14"> <span className="pl pl-1">人を殺してその血を身に負う者は</span><br /><span className="pl pl-1">死ぬまで、のがれびとである、</span><br /><span className="pl pl-1">だれもこれを助けてはならない。</span></span>
<span className="v" id="v18" data-v="18" data-xref="箴言 10:9; 箴言 28:6; ヨハネの黙示録 3:3"> <span className="pl pl-1">正しく歩む者は救を得、</span><br /><span className="pl pl-1">曲った道に歩む者は穴に陥る。</span></span>
<span className="v" id="v19" data-v="19" data-xref="箴言 12:11; 士師記 9:4; 箴言 27:23–27"> <span className="pl pl-1">自分の田地を耕す者は食糧に飽き、</span><br /><span className="pl pl-1">無益な事に従う者は貧乏に飽きる。</span></span>
<span className="v" id="v20" data-v="20" data-xref="ルカによる福音書 16:10–12; 箴言 13:11; ヨハネの黙示録 2:10"> <span className="pl pl-1">忠実な人は多くの祝福を得る、</span><br /><span className="pl pl-1">急いで富を得ようとする者は罰を免れない。</span></span>

<span className="v" id="v22" data-v="22" data-xref="箴言 23:6; テモテヘの第一の手紙 6:9; 箴言 28:20"> <span className="pl pl-1">欲の深い人は急いで富を得ようとする、</span><br /><span className="pl pl-1">かえって欠乏が自分の所に来ることを知らない。</span></span>
<span className="v" id="v23" data-v="23" data-xref="箴言 27:5–6; マタイによる福音書 18:15; 詩篇 141:5"> <span className="pl pl-1">人を戒める者は舌をもってへつらう者よりも、</span><br /><span className="pl pl-1">大いなる感謝をうける。</span></span>
<span className="v" id="v24" data-v="24" data-xref="マタイによる福音書 15:4–6; 箴言 18:9; 箴言 19:26"> <span className="pl pl-1">父や母の物を盗んで「これは罪ではない」と言う者は、</span><br /><span className="pl pl-1">滅ぼす者の友である。</span></span>
<span className="v" id="v25" data-v="25" data-xref="箴言 11:25; テモテヘの第一の手紙 6:6; 箴言 13:10"> <span className="pl pl-1">むさぼる者は争いを起し、</span><br /><span className="pl pl-1">主に信頼する者は豊かになる。</span></span>
<span className="v" id="v26" data-v="26" data-xref="箴言 3:5; エレミヤ書 17:9; ヨブ記 28:28"> <span className="pl pl-1">自分の心を頼む者は愚かである、</span><br /><span className="pl pl-1">知恵をもって歩む者は救を得る。</span></span>
<span className="v" id="v27" data-v="27" data-xref="箴言 19:17; 申命記 15:7; 詩篇 41:1–3"> <span className="pl pl-1">貧しい者に施す者は物に不足しない、</span><br /><span className="pl pl-1">目をおおって見ない人は多くののろいをうける。</span></span>
<span className="v" id="v28" data-v="28" data-xref="箴言 29:2; ヨブ記 24:4; 使徒行伝 12:23–24"> <span className="pl pl-1">悪しき者が起るときは、民は身をかくす、</span><br /><span className="pl pl-1">その滅びるときは、正しい人が増す。</span></span>

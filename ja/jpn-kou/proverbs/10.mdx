<span className="v" id="v1" data-v="1" data-xref="箴言 1:1; 箴言 29:15; 箴言 17:25"> <span className="pl pl-1">ソロモンの箴言。</span><br /><span className="pl pl-1">知恵ある子は父を喜ばせ、</span><br /><span className="pl pl-1">愚かな子は母の悲しみとなる。</span></span>
<span className="v" id="v2" data-v="2" data-xref="箴言 11:4; 箴言 12:28; 詩篇 49:6–10"> <span className="pl pl-1">不義の宝は益なく、</span><br /><span className="pl pl-1">正義は人を救い出して、死を免れさせる。</span></span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 37:3; マタイによる福音書 6:30–33; 詩篇 37:25"> <span className="pl pl-1">主は正しい人を飢えさせず、</span><br /><span className="pl pl-1">悪しき者の欲望をくじかれる。</span></span>
<span className="v" id="v4" data-v="4" data-xref="箴言 21:5; 箴言 20:4; 箴言 19:15"> <span className="pl pl-1">手を動かすことを怠る者は貧しくなり、</span><br /><span className="pl pl-1">勤め働く者の手は富を得る。</span></span>
<span className="v" id="v5" data-v="5" data-xref="箴言 6:8; 箴言 30:25; 箴言 17:2"> <span className="pl pl-1">夏のうちに集める者は賢い子であり、</span><br /><span className="pl pl-1">刈入れの時に眠る者は恥をきたらせる子である。</span></span>
<span className="v" id="v6" data-v="6" data-xref="申命記 28:2; 箴言 28:20; ヨブ記 29:13"> <span className="pl pl-1">正しい者のこうべには祝福があり、</span><br /><span className="pl pl-1">悪しき者の口は暴虐を隠す。</span></span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 112:6; ルカによる福音書 1:48; マルコによる福音書 14:9"> <span className="pl pl-1">正しい者の名はほめられ、</span><br /><span className="pl pl-1">悪しき者の名は朽ちる。</span></span>
<span className="v" id="v8" data-v="8" data-xref="マタイによる福音書 7:24–25; 箴言 12:1; ヤコブの手紙 3:13"> <span className="pl pl-1">心のさとき者は戒めを受ける、</span><br /><span className="pl pl-1">むだ口をたたく愚かな者は滅ぼされる。</span></span>
<span className="v" id="v9" data-v="9" data-xref="箴言 28:18; マタイによる福音書 10:26; 詩篇 26:11–12"> <span className="pl pl-1">まっすぐに歩む者の歩みは安全である、</span><br /><span className="pl pl-1">しかし、その道を曲げる者は災にあう。</span></span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 35:19; 箴言 6:13; ヨハネの第三の手紙 1:10"> <span className="pl pl-1">目で、めくばせする者は憂いをおこし、</span><br /><span className="pl pl-1">あからさまに、戒める者は平和をきたらせる。</span></span>
<span className="v" id="v11" data-v="11" data-xref="箴言 13:14; エペソ人への手紙 4:29; 箴言 10:6"> <span className="pl pl-1">正しい者の口は命の泉である、</span><br /><span className="pl pl-1">悪しき者の口は暴虐を隠す。</span></span>
<span className="v" id="v12" data-v="12" data-xref="ペテロの第一の手紙 4:8; コリント人への第一の手紙 13:4–7; 箴言 17:9"> <span className="pl pl-1">憎しみは、争いを起し、</span><br /><span className="pl pl-1">愛はすべてのとがをおおう。</span></span>
<span className="v" id="v13" data-v="13" data-xref="箴言 26:3; 箴言 6:32; イザヤ書 50:4"> <span className="pl pl-1">さとき者のくちびるには知恵があり、</span><br /><span className="pl pl-1">知恵のない者の背にはむちがある。</span></span>
<span className="v" id="v14" data-v="14" data-xref="箴言 18:7; 箴言 10:8; 箴言 13:3"> <span className="pl pl-1">知恵ある者は知識をたくわえる、</span><br /><span className="pl pl-1">愚かな者のむだ口は、今にも滅びをきたらせる。</span></span>
<span className="v" id="v15" data-v="15" data-xref="箴言 18:11; 箴言 19:7; 詩篇 52:7"> <span className="pl pl-1">富める者の宝は、その堅き城であり、</span><br /><span className="pl pl-1">貧しい者の乏しきは、その滅びである。</span></span>
<span className="v" id="v16" data-v="16" data-xref="ローマ人への手紙 6:23; イザヤ書 3:10–11; ヘブル人への手紙 6:10"> <span className="pl pl-1">正しい者の受ける賃銀は命に導き、</span><br /><span className="pl pl-1">悪しき者の利得は罪に至る。</span></span>
<span className="v" id="v17" data-v="17" data-xref="ペテロの第二の手紙 1:5–11; ルカによる福音書 11:28; 箴言 6:23"> <span className="pl pl-1">教訓を守る者は命の道にあり、</span><br /><span className="pl pl-1">懲しめを捨てる者は道をふみ迷う。</span></span>
<span className="v" id="v18" data-v="18" data-xref="箴言 26:24–26; 詩篇 55:21; サムエル記下 3:27"> <span className="pl pl-1">憎しみを隠す者には偽りのくちびるがあり、</span><br /><span className="pl pl-1">そしりを口に出す者は愚かな者である。</span></span>
<span className="v" id="v19" data-v="19" data-xref="ヤコブの手紙 1:19; ヤコブの手紙 3:2; 箴言 17:27–28"> <span className="pl pl-1">言葉が多ければ、とがを免れない、</span><br /><span className="pl pl-1">自分のくちびるを制する者は知恵がある。</span></span>
<span className="v" id="v20" data-v="20" data-xref="エレミヤ書 17:9; 箴言 12:18; 創世記 6:5"> <span className="pl pl-1">正しい者の舌は精銀である、</span><br /><span className="pl pl-1">悪しき者の心は価値が少ない。</span></span>
<span className="v" id="v21" data-v="21" data-xref="ホセア書 4:6; 箴言 17:16; 箴言 1:29"> <span className="pl pl-1">正しい者のくちびるは多くの人を養い、</span><br /><span className="pl pl-1">愚かな者は知恵がなくて死ぬ。</span></span>
<span className="v" id="v22" data-v="22" data-xref="詩篇 107:38; 創世記 26:12; サムエル記上 2:7–8"> <span className="pl pl-1">主の祝福は人を富ませる、</span><br /><span className="pl pl-1">主はこれになんの悲しみをも加えない。</span></span>
<span className="v" id="v23" data-v="23" data-xref="箴言 15:21; 箴言 2:14; 箴言 14:9"> <span className="pl pl-1">愚かな者は、戯れ事のように悪を行う、</span><br /><span className="pl pl-1">さとき人には賢い行いが楽しみである。</span></span>
<span className="v" id="v24" data-v="24" data-xref="詩篇 145:19; イザヤ書 66:4; マタイによる福音書 5:6"> <span className="pl pl-1">悪しき者の恐れることは自分に来り、</span><br /><span className="pl pl-1">正しい者の願うことは与えられる。</span></span>
<span className="v" id="v25" data-v="25" data-xref="詩篇 15:5; 詩篇 58:9; マタイによる福音書 7:24–27"> <span className="pl pl-1">あらしが通りすぎる時、</span><br /><span className="pl pl-1">悪しき者は、もはや、いなくなり、</span><br /><span className="pl pl-1">正しい者は永久に堅く立てられる。</span></span>
<span className="v" id="v26" data-v="26" data-xref="箴言 25:13; 箴言 26:6; マタイによる福音書 25:26"> <span className="pl pl-1">なまけ者は、これをつかわす者にとっては、</span><br /><span className="pl pl-1">酢が歯をいため、煙が目を悩ますようなものだ。</span></span>
<span className="v" id="v27" data-v="27" data-xref="箴言 9:11; 箴言 3:2; 詩篇 91:16"> <span className="pl pl-1">主を恐れることは人の命の日を多くする、</span><br /><span className="pl pl-1">悪しき者の年は縮められる。</span></span>
<span className="v" id="v28" data-v="28" data-xref="ヨブ記 8:13; ローマ人への手紙 15:13; 詩篇 73:24–26"> <span className="pl pl-1">正しい者の望みは喜びに終り、</span><br /><span className="pl pl-1">悪しき者の望みは絶える。</span></span>
<span className="v" id="v29" data-v="29" data-xref="箴言 21:15; ローマ人への手紙 2:8–9; ピリピ人への手紙 4:13"> <span className="pl pl-1">主は、まっすぐに歩む者には城であり、</span><br /><span className="pl pl-1">悪を行う者には滅びである。</span></span>
<span className="v" id="v30" data-v="30" data-xref="詩篇 37:22; 詩篇 125:1; 詩篇 37:9–10"> <span className="pl pl-1">正しい者はいつまでも動かされることはない、</span><br /><span className="pl pl-1">悪しき者は、地に住むことができない。</span></span>
<span className="v" id="v31" data-v="31" data-xref="詩篇 37:30; 箴言 10:13; 箴言 10:20–21"> <span className="pl pl-1">正しい者の口は知恵をいだし、</span><br /><span className="pl pl-1">偽りの舌は抜かれる。</span></span>
<span className="v" id="v32" data-v="32" data-xref="箴言 15:28; 箴言 12:6; 箴言 11:11"> <span className="pl pl-1">正しい者のくちびるは喜ばるべきことをわきまえ、</span><br /><span className="pl pl-1">悪しき者の口は偽りを語る。</span></span>

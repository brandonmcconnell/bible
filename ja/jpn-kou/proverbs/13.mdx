<span className="v" id="v1" data-v="1" data-xref="箴言 15:5; 箴言 9:7–8; 箴言 15:20"> <span className="pl pl-1">知恵ある子は父の教訓をきく、</span><br /><span className="pl pl-1">あざける者は、懲しめをきかない。</span></span>
<span className="v" id="v2" data-v="2" data-xref="箴言 12:14; 箴言 18:20; 箴言 10:11"> <span className="pl pl-1">善良な人はその口の実によって、幸福を得る、</span><br /><span className="pl pl-1">不信実な者の願いは、暴虐である。</span></span>
<span className="v" id="v3" data-v="3" data-xref="箴言 21:23; 箴言 18:21; 箴言 18:7"> <span className="pl pl-1">口を守る者はその命を守る、</span><br /><span className="pl pl-1">くちびるを大きく開く者には滅びが来る。</span></span>
<span className="v" id="v4" data-v="4" data-xref="箴言 12:24; 箴言 12:11; ペテロの第二の手紙 1:5–11"> <span className="pl pl-1">なまけ者の心は、願い求めても、何も得ない、</span><br /><span className="pl pl-1">しかし勤め働く者の心は豊かに満たされる。</span></span>
<span className="v" id="v5" data-v="5" data-xref="コロサイ人への手紙 3:9; エペソ人への手紙 4:25; 詩篇 119:163"> <span className="pl pl-1">正しい人は偽りを憎む、</span><br /><span className="pl pl-1">しかし悪しき人は恥ずべく、忌まわしくふるまう。</span></span>
<span className="v" id="v6" data-v="6" data-xref="箴言 11:3; 箴言 11:5–6; 詩篇 140:11"> <span className="pl pl-1">正義は道をまっすぐ歩む者を守り、</span><br /><span className="pl pl-1">罪は悪しき者を倒す。</span></span>
<span className="v" id="v7" data-v="7" data-xref="ルカによる福音書 18:11–14; ヨハネの黙示録 3:17; 箴言 11:24"> <span className="pl pl-1">富んでいると偽って、何も持たない者がいる、</span><br /><span className="pl pl-1">貧しいと偽って、多くの富を持つ者がいる。</span></span>
<span className="v" id="v8" data-v="8" data-xref="マタイによる福音書 16:26; ペテロの第一の手紙 1:18–19; 詩篇 49:6–10"> <span className="pl pl-1">人の富はその命をあがなう、</span><br /><span className="pl pl-1">しかし貧しい者にはあがなうべき富がない。</span></span>
<span className="v" id="v9" data-v="9" data-xref="箴言 4:18; 箴言 24:20; 箴言 20:20"> <span className="pl pl-1">正しい者の光は輝き、</span><br /><span className="pl pl-1">悪しき者のともしびは消される。</span></span>
<span className="v" id="v10" data-v="10" data-xref="箴言 19:20; 箴言 12:15–16; 箴言 17:14"> <span className="pl pl-1">高ぶりはただ争いを生じる、</span><br /><span className="pl pl-1">勧告をきく者は知恵がある。</span></span>
<span className="v" id="v11" data-v="11" data-xref="箴言 20:21; 箴言 10:2; ヤコブの手紙 5:1–5"> <span className="pl pl-1">急いで得た富は減る、</span><br /><span className="pl pl-1">少しずつたくわえる者はそれを増すことができる。</span></span>
<span className="v" id="v12" data-v="12" data-xref="ヨハネによる福音書 16:22; 箴言 13:19; 詩篇 119:81–83"> <span className="pl pl-1">望みを得ることが長びくときは、心を悩ます、</span><br /><span className="pl pl-1">願いがかなうときは、命の木を得たようだ。</span></span>
<span className="v" id="v13" data-v="13" data-xref="民数記 15:31; 歴代志下 36:16; ヨハネの第二の手紙 1:8"> <span className="pl pl-1">み言葉を軽んじる者は滅ぼされ、</span><br /><span className="pl pl-1">戒めを重んじる者は報いを得る。</span></span>
<span className="v" id="v14" data-v="14" data-xref="詩篇 18:5; 箴言 10:11; 箴言 14:27"> <span className="pl pl-1">知恵ある人の教は命の泉である、</span><br /><span className="pl pl-1">これによって死のわなをのがれることができる。</span></span>
<span className="v" id="v15" data-v="15" data-xref="エレミヤ書 2:19; 箴言 4:19; 使徒行伝 7:10"> <span className="pl pl-1">善良な賢い者は恵みを得る、</span><br /><span className="pl pl-1">しかし、不信実な者の道は滅びである。</span></span>
<span className="v" id="v16" data-v="16" data-xref="箴言 15:2; 箴言 12:22–23; エペソ人への手紙 5:17"> <span className="pl pl-1">おおよそ、さとき者は知識によって事をおこない、</span><br /><span className="pl pl-1">愚かな者は自分の愚を見せびらかす。</span></span>
<span className="v" id="v17" data-v="17" data-xref="箴言 25:13; コリント人への第一の手紙 4:2; コリント人への第二の手紙 5:20"> <span className="pl pl-1">悪しき使者は人を災におとしいれる、</span><br /><span className="pl pl-1">しかし忠実な使者は人を救う。</span></span>
<span className="v" id="v18" data-v="18" data-xref="箴言 15:5; 箴言 12:1; 箴言 15:31–32"> <span className="pl pl-1">貧乏と、はずかしめとは教訓を捨てる者に来る、</span><br /><span className="pl pl-1">しかし戒めを守る者は尊ばれる。</span></span>
<span className="v" id="v19" data-v="19" data-xref="ヨハネの黙示録 7:14–17; 箴言 13:12; 箴言 29:27"> <span className="pl pl-1">願いがかなえば、心は楽しい、</span><br /><span className="pl pl-1">愚かな者は悪を捨てることをきらう。</span></span>
<span className="v" id="v20" data-v="20" data-xref="コリント人への第一の手紙 15:33–34; 箴言 15:31; 箴言 9:6"> <span className="pl pl-1">知恵ある者とともに歩む者は知恵を得る。</span><br /><span className="pl pl-1">愚かな者の友となる者は害をうける。</span></span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 32:10; イザヤ書 3:10–11; ローマ人への手紙 2:7–10"> <span className="pl pl-1">災は罪びとを追い、</span><br /><span className="pl pl-1">正しい者は良い報いを受ける。</span></span>
<span className="v" id="v22" data-v="22" data-xref="伝道の書 2:26; ヨブ記 27:16–17; 箴言 28:8"> <span className="pl pl-1">善良な人はその嗣業を子孫にのこす、</span><br /><span className="pl pl-1">しかし罪びとの富は正しい人のためにたくわえられる。</span></span>
<span className="v" id="v23" data-v="23" data-xref="箴言 12:11; 箴言 28:19; 伝道の書 5:9"> <span className="pl pl-1">貧しい人の新田は多くの食糧を産する、</span><br /><span className="pl pl-1">しかし不正によれば押し流される。</span></span>
<span className="v" id="v24" data-v="24" data-xref="箴言 29:17; 箴言 23:13–14; 箴言 29:15"> <span className="pl pl-1">むちを加えない者はその子を憎むのである、</span><br /><span className="pl pl-1">子を愛する者は、つとめてこれを懲らしめる。</span></span>
<span className="v" id="v25" data-v="25" data-xref="詩篇 34:10; 箴言 10:3; ヘブル人への手紙 13:5"> <span className="pl pl-1">正しい者は食べてその食欲を満たす、</span><br /><span className="pl pl-1">しかし悪しき者の腹は満たされない。</span></span>

<span className="v" id="v1" data-v="1" data-xref="箴言 4:5; ヨハネによる福音書 14:21–24; 申命記 6:6–9"> <span className="pl pl-1">わが子よ、わたしの教を忘れず、</span><br /><span className="pl pl-1">わたしの戒めを心にとめよ。</span></span>
<span className="v" id="v2" data-v="2" data-xref="エペソ人への手紙 6:1–3; 箴言 4:10; 詩篇 91:16"> <span className="pl pl-1">そうすれば、これはあなたの日を長くし、</span><br /><span className="pl pl-1">命の年を延べ、あなたに平安を増し加える。</span></span>
<span className="v" id="v3" data-v="3" data-xref="箴言 7:3; コリント人への第二の手紙 3:3; ヘブル人への手紙 10:16"> <span className="pl pl-1">いつくしみと、まこととを捨ててはならない、</span><br /><span className="pl pl-1">それをあなたの首に結び、心の碑にしるせ。</span></span>
<span className="v" id="v4" data-v="4" data-xref="ルカによる福音書 2:52; サムエル記上 2:26; ローマ人への手紙 14:18"> <span className="pl pl-1">そうすれば、あなたは神と人との前に</span><br /><span className="pl pl-1">恵みと、誉とを得る。</span></span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 37:5; エレミヤ書 17:7–8; 箴言 28:26"> <span className="pl pl-1">心をつくして主に信頼せよ、</span><br /><span className="pl pl-1">自分の知識にたよってはならない。</span></span>
<span className="v" id="v6" data-v="6" data-xref="箴言 16:3; 詩篇 32:8; ピリピ人への手紙 4:6"> <span className="pl pl-1">すべての道で主を認めよ、</span><br /><span className="pl pl-1">そうすれば、主はあなたの道をまっすぐにされる。</span></span>
<span className="v" id="v7" data-v="7" data-xref="ヨブ記 28:28; ローマ人への手紙 12:16; 箴言 26:12"> <span className="pl pl-1">自分を見て賢いと思ってはならない、</span><br /><span className="pl pl-1">主を恐れて、悪を離れよ。</span></span>
<span className="v" id="v8" data-v="8" data-xref="箴言 4:22; 詩篇 147:3; 箴言 16:24"> <span className="pl pl-1">そうすれば、あなたの身を健やかにし、</span><br /><span className="pl pl-1">あなたの骨に元気を与える。</span></span>
<span className="v" id="v9" data-v="9" data-xref="申命記 26:2–15; コリント人への第一の手紙 16:2; 出エジプト記 23:19"> <span className="pl pl-1">あなたの財産と、</span><br /><span className="pl pl-1">すべての産物の初なりをもって主をあがめよ。</span></span>
<span className="v" id="v10" data-v="10" data-xref="箴言 19:17; 申命記 28:8; 箴言 22:9"> <span className="pl pl-1">そうすれば、あなたの倉は満ちて余り、</span><br /><span className="pl pl-1">あなたの酒ぶねは新しい酒であふれる。</span></span>
<span className="v" id="v11" data-v="11" data-xref="ヨブ記 5:17; ヨハネの黙示録 3:19; ヘブル人への手紙 12:5–12"> <span className="pl pl-1">わが子よ、主の懲しめを軽んじてはならない、</span><br /><span className="pl pl-1">その戒めをきらってはならない。</span></span>
<span className="v" id="v12" data-v="12" data-xref="申命記 8:5; ヨハネの黙示録 3:19; 箴言 29:17"> <span className="pl pl-1">主は、愛する者を、戒められるからである、</span><br /><span className="pl pl-1">あたかも父がその愛する子を戒めるように。</span></span>
<span className="v" id="v13" data-v="13" data-xref="箴言 8:32–35; 箴言 4:5–9; 伝道の書 9:15–18"> <span className="pl pl-1">知恵を求めて得る人、</span><br /><span className="pl pl-1">悟りを得る人はさいわいである。</span></span>
<span className="v" id="v14" data-v="14" data-xref="箴言 16:16; 箴言 8:19; ヨブ記 28:13–19"> <span className="pl pl-1">知恵によって得るものは、</span><br /><span className="pl pl-1">銀によって得るものにまさり、</span><br /><span className="pl pl-1">その利益は精金よりも良いからである。</span></span>
<span className="v" id="v15" data-v="15" data-xref="箴言 8:11; ヨブ記 28:18; 詩篇 73:25–26"> <span className="pl pl-1">知恵は宝石よりも尊く、</span><br /><span className="pl pl-1">あなたの望む何物も、これと比べるに足りない。</span></span>
<span className="v" id="v16" data-v="16" data-xref="箴言 3:2; コリント人への第二の手紙 6:10; 箴言 22:4"> <span className="pl pl-1">その右の手には長寿があり、</span><br /><span className="pl pl-1">左の手には富と、誉がある。</span></span>
<span className="v" id="v17" data-v="17" data-xref="ルカによる福音書 1:79; イザヤ書 26:3; ピリピ人への手紙 4:8–9"> <span className="pl pl-1">その道は楽しい道であり、</span><br /><span className="pl pl-1">その道筋はみな平安である。</span></span>
<span className="v" id="v18" data-v="18" data-xref="箴言 11:30; ヨハネの黙示録 2:7; 箴言 15:4"> <span className="pl pl-1">知恵は、これを捕える者には命の木である、</span><br /><span className="pl pl-1">これをしっかり捕える人はさいわいである。</span></span>
<span className="v" id="v19" data-v="19" data-xref="詩篇 104:24; エレミヤ書 10:12; ヨハネによる福音書 1:3"> <span className="pl pl-1">主は知恵をもって地の基をすえ、</span><br /><span className="pl pl-1">悟りをもって天を定められた。</span></span>
<span className="v" id="v20" data-v="20" data-xref="創世記 7:11; 詩篇 65:9–12; ヨブ記 36:27–28"> <span className="pl pl-1">その知識によって海はわきいで、雲は露をそそぐ。</span></span>
<span className="v" id="v21" data-v="21" data-xref="ヨシュア記 1:8; 申命記 6:6–9; 申命記 32:46–47"> <span className="pl pl-1">わが子よ、確かな知恵と、慎みとを守って、</span><br /><span className="pl pl-1">それをあなたの目から離してはならない。</span></span>
<span className="v" id="v22" data-v="22" data-xref="箴言 4:22; 箴言 1:9; イザヤ書 38:16"> <span className="pl pl-1">それはあなたの魂の命となり</span><br /><span className="pl pl-1">あなたの首の飾りとなる。</span></span>
<span className="v" id="v23" data-v="23" data-xref="箴言 4:12; 箴言 10:9; 詩篇 121:3"> <span className="pl pl-1">こうして、あなたは安らかに自分の道を行き、</span><br /><span className="pl pl-1">あなたの足はつまずくことがない。</span></span>
<span className="v" id="v24" data-v="24" data-xref="詩篇 3:5; 詩篇 4:8; 箴言 6:22"> <span className="pl pl-1">あなたは座しているとき、恐れることはなく、</span><br /><span className="pl pl-1">伏すとき、あなたの眠りはここちよい。</span></span>
<span className="v" id="v25" data-v="25" data-xref="イザヤ書 41:10–14; 詩篇 112:7; ペテロの第一の手紙 3:14"> <span className="pl pl-1">あなたはにわかに起る恐怖を恐れることなく、</span><br /><span className="pl pl-1">悪しき者の滅びが来ても、それを恐れることはない。</span></span>
<span className="v" id="v26" data-v="26" data-xref="詩篇 91:3; サムエル記上 2:9; 箴言 14:26"> <span className="pl pl-1">これは、主があなたの信頼する者であり、</span><br /><span className="pl pl-1">あなたの足を守って、</span><br /><span className="pl pl-1">わなに捕われさせられないからである。</span></span>
<span className="v" id="v27" data-v="27" data-xref="ガラテヤ人への手紙 6:10; ヤコブの手紙 2:15–16; ローマ人への手紙 13:7"> <span className="pl pl-1">あなたの手に善をなす力があるならば、</span><br /><span className="pl pl-1">これをなすべき人になすことを</span><br /><span className="pl pl-1">さし控えてはならない。</span></span>
<span className="v" id="v28" data-v="28" data-xref="レビ記 19:13; 申命記 24:12–15; コリント人への第二の手紙 8:11"> <span className="pl pl-1">あなたが物を持っている時、その隣り人に向かい、</span><br /><span className="pl pl-1">「去って、また来なさい。</span><br /><span className="pl pl-1">あす、それをあげよう」と言ってはならない。</span></span>
<span className="v" id="v29" data-v="29" data-xref="箴言 6:14; 箴言 16:29–30; 詩篇 55:20"> <span className="pl pl-1">あなたの隣り人がかたわらに安らかに住んでいる時、</span><br /><span className="pl pl-1">これに向かって、悪を計ってはならない。</span></span>
<span className="v" id="v30" data-v="30" data-xref="テモテヘの第二の手紙 2:24; 箴言 29:22; ローマ人への手紙 12:18–21"> <span className="pl pl-1">もし人があなたに悪を行ったのでなければ、</span><br /><span className="pl pl-1">ゆえなく、これと争ってはならない。</span></span>
<span className="v" id="v31" data-v="31" data-xref="箴言 24:1; 詩篇 37:1; ガラテヤ人への手紙 5:21"> <span className="pl pl-1">暴虐な人を、うらやんではならない、</span><br /><span className="pl pl-1">そのすべての道を選んではならない。</span></span>
<span className="v" id="v32" data-v="32" data-xref="詩篇 25:14; ヨハネによる福音書 15:15; 箴言 11:20"> <span className="pl pl-1">よこしまな者は主に憎まれるからである、</span><br /><span className="pl pl-1">しかし、正しい者は主に信任される。</span></span>
<span className="v" id="v33" data-v="33" data-xref="詩篇 37:22; レビ記 26:14–46; ヨブ記 8:6–7"> <span className="pl pl-1">主の、のろいは悪しき者の家にある、</span><br /><span className="pl pl-1">しかし、正しい人のすまいは主に恵まれる。</span></span>
<span className="v" id="v34" data-v="34" data-xref="ヤコブの手紙 4:6; ペテロの第一の手紙 5:5; 詩篇 138:6"> <span className="pl pl-1">彼はあざける者をあざけり、</span><br /><span className="pl pl-1">へりくだる者に恵みを与えられる。</span></span>
<span className="v" id="v35" data-v="35" data-xref="詩篇 132:18; イザヤ書 65:13–15; 詩篇 73:24"> <span className="pl pl-1">知恵ある者は、誉を得る、</span><br /><span className="pl pl-1">しかし、愚かな者ははずかしめを得る。</span></span>

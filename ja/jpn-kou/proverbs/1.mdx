<span className="v" id="v1" data-v="1" data-xref="箴言 10:1; 歴代志上 22:9; 歴代志上 28:5"> <span className="pl pl-1">ダビデの子、イスラエルの王ソロモンの箴言。</span></span>
<span className="v" id="v2" data-v="2" data-xref="箴言 7:4; 申命記 4:5–6; テモテヘの第二の手紙 3:15–17"> <span className="pl pl-1">これは人に知恵と教訓とを知らせ、</span><br /><span className="pl pl-1">悟りの言葉をさとらせ、</span></span>
<span className="v" id="v3" data-v="3" data-xref="箴言 2:1–9; ヨブ記 22:22; 箴言 8:10–11"> <span className="pl pl-1">賢い行いと、正義と公正と</span><br /><span className="pl pl-1">公平の教訓をうけさせ、</span></span>
<span className="v" id="v4" data-v="4" data-xref="箴言 8:5; 箴言 8:17; 詩篇 119:9"> <span className="pl pl-1">思慮のない者に悟りを与え、</span><br /><span className="pl pl-1">若い者に知識と慎みを得させるためである。</span></span>
<span className="v" id="v5" data-v="5" data-xref="箴言 12:1; 箴言 9:9; コリント人への第一の手紙 10:15"> <span className="pl pl-1">賢い者はこれを聞いて学に進み、</span><br /><span className="pl pl-1">さとい者は指導を得る。</span></span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 78:2; マルコによる福音書 4:11; 詩篇 49:4"> <span className="pl pl-1">人はこれによって箴言と、たとえと、</span><br /><span className="pl pl-1">賢い者の言葉と、そのなぞとを悟る。</span></span>
<span className="v" id="v7" data-v="7" data-xref="ヨブ記 28:28; 詩篇 111:10–1; 伝道の書 12:13"> <span className="pl pl-1">主を恐れることは知識のはじめである、</span><br /><span className="pl pl-1">愚かな者は知恵と教訓を軽んじる。</span></span>
<span className="v" id="v8" data-v="8" data-xref="箴言 6:20; 箴言 30:17; 箴言 5:1–2"> <span className="pl pl-1">わが子よ、あなたは父の教訓を聞き、</span><br /><span className="pl pl-1">母の教を捨ててはならない。</span></span>
<span className="v" id="v9" data-v="9" data-xref="ダニエル書 5:29; 箴言 4:9; 創世記 41:42"> <span className="pl pl-1">それらは、あなたの頭の麗しい冠となり、</span><br /><span className="pl pl-1">あなたの首の飾りとなるからである。</span></span>
<span className="v" id="v10" data-v="10" data-xref="エペソ人への手紙 5:11; 箴言 16:29; 詩篇 1:1"> <span className="pl pl-1">わが子よ、悪者があなたを誘っても、</span><br /><span className="pl pl-1">それに従ってはならない。</span></span>
<span className="v" id="v11" data-v="11" data-xref="エレミヤ書 5:26; 箴言 1:18; 箴言 12:6"> <span className="pl pl-1">彼らがあなたに向かって、「一緒に来なさい。</span><br /><span className="pl pl-1">われわれは待ち伏せして、人の血を流し、</span><br /><span className="pl pl-1">罪のない者を、ゆえなく伏してねらい、</span></span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 124:3; 詩篇 28:1; ローマ人への手紙 3:13"> <span className="pl pl-1">陰府のように、彼らを生きたままで、のみ尽し、</span><br /><span className="pl pl-1">健やかな者を、墓に下る者のようにしよう。</span></span>
<span className="v" id="v13" data-v="13" data-xref="テモテヘの第一の手紙 6:9–10; ルカによる福音書 12:15; ヨブ記 24:2–3"> <span className="pl pl-1">われわれは、さまざまの尊い貨財を得、</span><br /><span className="pl pl-1">奪い取った物で、われわれの家を満たそう。</span></span>
<span className="v" id="v14" data-v="14"> <span className="pl pl-1">あなたもわれわれの仲間に加わりなさい、</span><br /><span className="pl pl-1">われわれは共に一つの金袋を持とう」と言っても、</span></span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 119:101; 詩篇 1:1; 箴言 4:14–15"> <span className="pl pl-1">わが子よ、彼らの仲間になってはならない、</span><br /><span className="pl pl-1">あなたの足をとどめて、彼らの道に行ってはならない。</span></span>
<span className="v" id="v16" data-v="16" data-xref="イザヤ書 59:7; 箴言 6:18; 箴言 4:16"> <span className="pl pl-1">彼らの足は悪に走り、</span><br /><span className="pl pl-1">血を流すことに速いからだ。</span></span>
<span className="v" id="v17" data-v="17" data-xref="ヨブ記 35:11; 箴言 7:23; エレミヤ書 8:7"> <span className="pl pl-1">すべて鳥の目の前で</span><br /><span className="pl pl-1">網を張るのは、むだである。</span></span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 9:16; エステル記 7:10; 箴言 5:22–23"> <span className="pl pl-1">彼らは自分の血を待ち伏せし、</span><br /><span className="pl pl-1">自分の命を伏してねらうのだ。</span></span>
<span className="v" id="v19" data-v="19" data-xref="箴言 15:27; ペテロの第二の手紙 2:3; ヤコブの手紙 5:1–4"> <span className="pl pl-1">すべて利をむさぼる者の道はこのようなものである。</span><br /><span className="pl pl-1">これはその持ち主の命を取り去るのだ。</span></span>
<span className="v" id="v20" data-v="20" data-xref="箴言 9:3; コロサイ人への手紙 2:3; ルカによる福音書 11:49"> <span className="pl pl-1">知恵は、ちまたに呼ばわり、</span><br /><span className="pl pl-1">市場にその声をあげ、</span></span>
<span className="v" id="v21" data-v="21" data-xref="使徒行伝 5:20; 箴言 9:3; マタイによる福音書 13:2"> <span className="pl pl-1">城壁の頂で叫び、町の門の入口で語る。</span></span>
<span className="v" id="v22" data-v="22" data-xref="箴言 1:29; 詩篇 1:1; 箴言 5:12"> <span className="pl pl-1">「思慮のない者たちよ、あなたがたは、いつまで思慮のないことを好むのか。</span><br /><span className="pl pl-1">あざける者は、いつまで、あざけり楽しみ、</span><br /><span className="pl pl-1">愚かな者は、いつまで、知識を憎むのか。</span></span>
<span className="v" id="v23" data-v="23" data-xref="使徒行伝 3:19; エゼキエル書 33:11; エゼキエル書 18:27–30"> <span className="pl pl-1">わたしの戒めに心をとめよ、</span><br /><span className="pl pl-1">見よ、わたしは自分の思いを、あなたがたに告げ、</span><br /><span className="pl pl-1">わたしの言葉を、あなたがたに知らせる。</span></span>
<span className="v" id="v24" data-v="24" data-xref="イザヤ書 65:12; ローマ人への手紙 10:21; エレミヤ書 7:13"> <span className="pl pl-1">わたしは呼んだが、あなたがたは聞くことを拒み、</span><br /><span className="pl pl-1">手を伸べたが、顧みる者はなく、</span></span>
<span className="v" id="v25" data-v="25" data-xref="詩篇 81:11; ルカによる福音書 7:30; 箴言 1:30"> <span className="pl pl-1">かえって、あなたがたはわたしのすべての勧めを捨て、</span><br /><span className="pl pl-1">わたしの戒めを受けなかったので、</span></span>
<span className="v" id="v26" data-v="26" data-xref="詩篇 2:4; 箴言 10:24; 詩篇 37:13"> <span className="pl pl-1">わたしもまた、あなたがたが災にあう時に、笑い、</span><br /><span className="pl pl-1">あなたがたが恐慌にあう時、あざけるであろう。</span></span>
<span className="v" id="v27" data-v="27" data-xref="箴言 3:25–26; ルカによる福音書 21:34–35; 詩篇 58:9"> <span className="pl pl-1">これは恐慌が、あらしのようにあなたがたに臨み、</span><br /><span className="pl pl-1">災が、つむじ風のように臨み、</span><br /><span className="pl pl-1">悩みと悲しみとが、あなたがたに臨む時である。</span></span>
<span className="v" id="v28" data-v="28" data-xref="ミカ書 3:4; ヤコブの手紙 4:3; エレミヤ書 11:11"> <span className="pl pl-1">その時、彼らはわたしを呼ぶであろう、</span><br /><span className="pl pl-1">しかし、わたしは答えない。</span><br /><span className="pl pl-1">ひたすら、わたしを求めるであろう、</span><br /><span className="pl pl-1">しかし、わたしに会えない。</span></span>
<span className="v" id="v29" data-v="29" data-xref="箴言 1:22; ヨブ記 21:14–15; 箴言 6:23"> <span className="pl pl-1">彼らは知識を憎み、主を恐れることを選ばず、</span></span>
<span className="v" id="v30" data-v="30" data-xref="詩篇 81:11; 箴言 1:25; ルカによる福音書 14:18–20"> <span className="pl pl-1">わたしの勧めに従わず、</span><br /><span className="pl pl-1">すべての戒めを軽んじたゆえ、</span></span>
<span className="v" id="v31" data-v="31" data-xref="箴言 14:14; エレミヤ書 6:19; 箴言 22:8"> <span className="pl pl-1">自分の行いの実を食らい、</span><br /><span className="pl pl-1">自分の計りごとに飽きる。</span></span>
<span className="v" id="v32" data-v="32" data-xref="箴言 8:36; エレミヤ書 2:19; ヨハネによる福音書 3:36"> <span className="pl pl-1">思慮のない者の不従順はおのれを殺し、</span><br /><span className="pl pl-1">愚かな者の安楽はおのれを滅ぼす。</span></span>
<span className="v" id="v33" data-v="33" data-xref="詩篇 25:12–13; 詩篇 112:7–8; イザヤ書 26:3"> <span className="pl pl-1">しかし、わたしに聞き従う者は安らかに住まい、</span><br /><span className="pl pl-1">災に会う恐れもなく、安全である」。</span></span>

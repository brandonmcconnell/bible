<span className="v" id="v3" data-v="3" data-xref="箴言 2:16; 箴言 6:24; 箴言 7:5"> <span className="pl pl-1">遊女のくちびるは蜜をしたたらせ、</span><br /><span className="pl pl-1">その言葉は油よりもなめらかである。</span></span>

<span className="v" id="v9" data-v="9" data-xref="ネヘミヤ書 13:26; ホセア書 4:13–14; 創世記 38:23–26"> <span className="pl pl-1">おそらくはあなたの誉を他人にわたし、</span><br /><span className="pl pl-1">あなたの年を無慈悲な者にわたすに至る。</span></span>

<span className="v" id="v11" data-v="11" data-xref="ローマ人への手紙 6:21; ヨハネの黙示録 22:15; ヘブル人への手紙 13:4"> <span className="pl pl-1">そしてあなたの終りが来て、</span><br /><span className="pl pl-1">あなたの身と、からだが滅びるとき、泣き悲しんで、</span></span>
<span className="v" id="v12" data-v="12" data-xref="箴言 12:1; 箴言 1:7; 箴言 15:5"> <span className="pl pl-1">言うであろう、「わたしは教訓をいとい、</span><br /><span className="pl pl-1">心に戒めを軽んじ、</span></span>
<span className="v" id="v13" data-v="13" data-xref="テサロニケ人への第一の手紙 4:8; ルカによる福音書 15:18; ヘブル人への手紙 13:7"> <span className="pl pl-1">教師の声に聞き従わず、</span><br /><span className="pl pl-1">わたしを教える者に耳を傾けず、</span></span>

<span className="v" id="v15" data-v="15" data-xref="コリント人への第一の手紙 7:2–5; ヘブル人への手紙 13:4; 箴言 5:18–19"> <span className="pl pl-1">あなたは自分の水ためから水を飲み、</span><br /><span className="pl pl-1">自分の井戸から、わき出す水を飲むがよい。</span></span>

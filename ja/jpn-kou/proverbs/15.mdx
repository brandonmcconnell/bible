<span className="v" id="v5" data-v="5" data-xref="箴言 15:31–32; 箴言 13:1; 箴言 13:18"> <span className="pl pl-1">愚かな者は父の教訓を軽んじる、</span><br /><span className="pl pl-1">戒めを守る者は賢い者である。</span></span>

<span className="v" id="v7" data-v="7" data-xref="マタイによる福音書 12:34; ヤコブの手紙 3:6; エペソ人への手紙 4:29"> <span className="pl pl-1">知恵ある者のくちびるは知識をひろめる、</span><br /><span className="pl pl-1">愚かな者の心はそうでない。</span></span>

<span className="v" id="v14" data-v="14" data-xref="箴言 9:9; イザヤ書 30:10; 箴言 18:15"> <span className="pl pl-1">さとき者の心は知識をたずね、</span><br /><span className="pl pl-1">愚かな者の口は愚かさを食物とする。</span></span>

<span className="v" id="v18" data-v="18" data-xref="箴言 15:1; 箴言 26:21; 箴言 29:22"> <span className="pl pl-1">憤りやすい者は争いをおこし、</span><br /><span className="pl pl-1">怒りをおそくする者は争いをとどめる。</span></span>
<span className="v" id="v19" data-v="19" data-xref="イザヤ書 35:8; 箴言 22:5; イザヤ書 30:21"> <span className="pl pl-1">なまけ者の道には、いばらがはえしげり、</span><br /><span className="pl pl-1">正しい者の道は平らかである。</span></span>
<span className="v" id="v20" data-v="20" data-xref="箴言 29:3; 箴言 10:1; 箴言 23:15–16"> <span className="pl pl-1">知恵ある子は父を喜ばせる、</span><br /><span className="pl pl-1">愚かな人はその母を軽んじる。</span></span>
<span className="v" id="v21" data-v="21" data-xref="エペソ人への手紙 5:15; 箴言 10:23; 箴言 14:16"> <span className="pl pl-1">無知な者は愚かなことを喜び、</span><br /><span className="pl pl-1">さとき者はまっすぐに歩む。</span></span>
<span className="v" id="v22" data-v="22" data-xref="箴言 11:14; 箴言 20:18; 伝道の書 8:6"> <span className="pl pl-1">相はかることがなければ、計画は破れる、</span><br /><span className="pl pl-1">はかる者が多ければ、それは必ず成る。</span></span>

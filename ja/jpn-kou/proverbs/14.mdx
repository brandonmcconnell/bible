<span className="v" id="v6" data-v="6" data-xref="ヤコブの手紙 1:5; マタイによる福音書 13:11–12; マタイによる福音書 11:25–27"> <span className="pl pl-1">あざける者は知恵を求めても得られない、</span><br /><span className="pl pl-1">さとき者は知識を得ることがたやすい。</span></span>
<span className="v" id="v7" data-v="7" data-xref="箴言 13:20; エペソ人への手紙 5:11; コリント人への第一の手紙 5:11"> <span className="pl pl-1">愚かな者の前を離れ去れ、</span><br /><span className="pl pl-1">そこには知識の言葉がないからである。</span></span>
<span className="v" id="v8" data-v="8" data-xref="エペソ人への手紙 5:17; テモテヘの第二の手紙 3:13; ヤコブの手紙 3:13"> <span className="pl pl-1">さとき者の知恵は自分の道をわきまえることにあり、</span><br /><span className="pl pl-1">愚かな者の愚かは、欺くことにある。</span></span>

<span className="v" id="v10" data-v="10" data-xref="ピリピ人への手紙 4:7; 箴言 18:14; 箴言 15:13"> <span className="pl pl-1">心の苦しみは心みずからが知る、</span><br /><span className="pl pl-1">その喜びには他人はあずからない。</span></span>
<span className="v" id="v11" data-v="11" data-xref="箴言 3:33; 箴言 12:7; マタイによる福音書 7:26–27"> <span className="pl pl-1">悪しき者の家は滅ぼされ、</span><br /><span className="pl pl-1">正しい者の幕屋は栄える。</span></span>
<span className="v" id="v12" data-v="12" data-xref="箴言 16:25; マタイによる福音書 7:13–14; 箴言 12:15"> <span className="pl pl-1">人が見て自ら正しいとする道でも、</span><br /><span className="pl pl-1">その終りはついに死に至る道となるものがある。</span></span>
<span className="v" id="v13" data-v="13" data-xref="伝道の書 2:2; ヤコブの手紙 4:9; 伝道の書 2:10–11"> <span className="pl pl-1">笑う時にも心に悲しみがあり、</span><br /><span className="pl pl-1">喜びのはてに憂いがある。</span></span>
<span className="v" id="v14" data-v="14" data-xref="ガラテヤ人への手紙 6:8; 箴言 12:14; ヘブル人への手紙 3:12"> <span className="pl pl-1">心のもとれる者はそのしわざの実を刈り取り、</span><br /><span className="pl pl-1">善良な人もまたその行いの実を刈り取る。</span></span>
<span className="v" id="v15" data-v="15" data-xref="エペソ人への手紙 5:17; 箴言 14:8; ヨハネの第一の手紙 4:1"> <span className="pl pl-1">思慮のない者はすべてのことを信じる、</span><br /><span className="pl pl-1">さとき者は自分の歩みを慎む。</span></span>
<span className="v" id="v16" data-v="16" data-xref="箴言 22:3; 箴言 3:7; テサロニケ人への第一の手紙 5:22"> <span className="pl pl-1">知恵ある者は用心ぶかく、悪を離れる、</span><br /><span className="pl pl-1">愚かな者は高ぶって用心しない。</span></span>
<span className="v" id="v17" data-v="17" data-xref="箴言 14:29; ヤコブの手紙 1:19; 伝道の書 7:9"> <span className="pl pl-1">怒りやすい者は愚かなことを行い、</span><br /><span className="pl pl-1">賢い者は忍耐強い。</span></span>

<span className="v" id="v19" data-v="19" data-xref="創世記 42:6; マラキ書 4:3; 出エジプト記 8:8"> <span className="pl pl-1">悪人は善人の前にひれ伏し、</span><br /><span className="pl pl-1">悪しき者は正しい者の門にひれ伏す。</span></span>
<span className="v" id="v20" data-v="20" data-xref="箴言 19:4; 箴言 10:15; 箴言 19:6–7"> <span className="pl pl-1">貧しい者はその隣にさえも憎まれる、</span><br /><span className="pl pl-1">しかし富める者は多くの友をもつ。</span></span>
<span className="v" id="v21" data-v="21" data-xref="箴言 19:17; 箴言 28:27; 箴言 11:12"> <span className="pl pl-1">隣り人を卑しめる者は罪びとである、</span><br /><span className="pl pl-1">貧しい人をあわれむ者はさいわいである。</span></span>
<span className="v" id="v22" data-v="22" data-xref="箴言 12:2; ヨハネによる福音書 1:17; 詩篇 61:7"> <span className="pl pl-1">悪を計る者はおのれを誤るではないか、</span><br /><span className="pl pl-1">善を計る者にはいつくしみと、まこととがある。</span></span>

<span className="v" id="v24" data-v="24" data-xref="伝道の書 7:11–12; ルカによる福音書 12:19–20; ルカによる福音書 16:19–25"> <span className="pl pl-1">知恵ある者の冠はその知恵である、</span><br /><span className="pl pl-1">愚かな者の花の冠はただ愚かさである。</span></span>
<span className="v" id="v25" data-v="25" data-xref="箴言 14:5; 使徒行伝 26:16–20; ペテロの第二の手紙 3:3"> <span className="pl pl-1">まことの証人は人の命を救う、</span><br /><span className="pl pl-1">偽りを吐く者は裏切者である。</span></span>

<span className="v" id="v30" data-v="30" data-xref="箴言 17:22; 箴言 4:23; 箴言 3:8"> <span className="pl pl-1">穏やかな心は身の命である、</span><br /><span className="pl pl-1">しかし興奮は骨を腐らせる。</span></span>

<span className="v" id="v1" data-v="1" data-xref="箴言 31:1; ペテロの第二の手紙 1:19–21"> <span className="pl pl-1">マッサの人ヤケの子アグルの言葉。</span><br /><span className="pl pl-1">その人はイテエルに向かって言った、</span><br /><span className="pl pl-1">すなわちイテエルと、ウカルとに向かって言った、</span></span>
<span className="v" id="v2" data-v="2" data-xref="詩篇 73:22; コリント人への第一の手紙 3:18; イザヤ書 6:5"> <span className="pl pl-1">わたしは確かに人よりも愚かであり、</span><br /><span className="pl pl-1">わたしには人の悟りがない。</span></span>
<span className="v" id="v3" data-v="3" data-xref="ヨハネの黙示録 3:7; エペソ人への手紙 3:18–19; ローマ人への手紙 11:33"> <span className="pl pl-1">わたしはまだ知恵をならうことができず、</span><br /><span className="pl pl-1">また、聖なる者を悟ることもできない。</span></span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネによる福音書 3:13; エペソ人への手紙 4:8–10; ヨブ記 26:8"> <span className="pl pl-1">天にのぼったり、下ったりしたのはだれか、</span><br /><span className="pl pl-1">風をこぶしの中に集めたのはだれか、</span><br /><span className="pl pl-1">水を着物に包んだのはだれか、</span><br /><span className="pl pl-1">地のすべての限界を定めた者はだれか、</span><br /><span className="pl pl-1">その名は何か、その子の名は何か、</span><br /><span className="pl pl-1">あなたは確かにそれを知っている。</span></span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 18:30; ヤコブの手紙 3:17; 詩篇 12:6"> <span className="pl pl-1">神の言葉はみな真実である、</span><br /><span className="pl pl-1">神は彼に寄り頼む者の盾である。</span></span>
<span className="v" id="v6" data-v="6" data-xref="申命記 12:32; 申命記 4:2; ヨハネの黙示録 22:18–19"> <span className="pl pl-1">その言葉に付け加えてはならない、</span><br /><span className="pl pl-1">彼があなたを責め、あなたを偽り者とされないためだ。</span></span>
<span className="v" id="v7" data-v="7" data-xref="ルカによる福音書 10:42; 列王紀下 2:9; 詩篇 27:4"> <span className="pl pl-1">わたしは二つのことをあなたに求めます、</span><br /><span className="pl pl-1">わたしの死なないうちに、これをかなえてください。</span></span>
<span className="v" id="v8" data-v="8" data-xref="テモテヘの第一の手紙 6:6–8; 詩篇 62:9–10; 詩篇 119:37"> <span className="pl pl-1">うそ、偽りをわたしから遠ざけ、</span><br /><span className="pl pl-1">貧しくもなく、また富みもせず、</span><br /><span className="pl pl-1">ただなくてならぬ食物でわたしを養ってください。</span></span>
<span className="v" id="v9" data-v="9" data-xref="ホセア書 13:6; 申命記 31:20; エゼキエル書 16:49–50"> <span className="pl pl-1">飽き足りて、あなたを知らないといい、</span><br /><span className="pl pl-1">「主とはだれか」と言うことのないため、</span><br /><span className="pl pl-1">また貧しくて盗みをし、</span><br /><span className="pl pl-1">わたしの神の名を汚すことのないためです。</span></span>
<span className="v" id="v10" data-v="10" data-xref="ローマ人への手紙 14:4; 伝道の書 7:21; 申命記 23:15"> <span className="pl pl-1">あなたは、しもべのことをその主人に、</span><br /><span className="pl pl-1">あしざまにいってはならない、</span><br /><span className="pl pl-1">そうでないと彼はあなたをのろい、</span><br /><span className="pl pl-1">あなたは罪をきせられる。</span></span>
<span className="v" id="v11" data-v="11" data-xref="箴言 20:20; 箴言 30:17; 出エジプト記 21:17"> <span className="pl pl-1">世には父をのろったり、母を祝福しない者がある。</span></span>
<span className="v" id="v12" data-v="12" data-xref="ルカによる福音書 18:11; 箴言 16:2; テモテヘの第二の手紙 3:5"> <span className="pl pl-1">世には自分の目にみずからを清い者として、</span><br /><span className="pl pl-1">なおその汚れを洗われないものがある。</span></span>
<span className="v" id="v13" data-v="13" data-xref="箴言 6:17; イザヤ書 2:11; 詩篇 101:5"> <span className="pl pl-1">世にはまた、このような人がある――</span><br /><span className="pl pl-1">ああ、その目のいかに高きことよ、</span><br /><span className="pl pl-1">またそのまぶたのいかにつりあがっていることよ。</span></span>
<span className="v" id="v14" data-v="14" data-xref="詩篇 57:4; 詩篇 3:7; 詩篇 14:4"> <span className="pl pl-1">世にはまたつるぎのような歯をもち、</span><br /><span className="pl pl-1">刀のようなきばをもって、</span><br /><span className="pl pl-1">貧しい者を地の上から、</span><br /><span className="pl pl-1">乏しい者を人の中から食い滅ぼすものがある。</span></span>
<span className="v" id="v15" data-v="15" data-xref="箴言 30:21; 箴言 30:29; 箴言 6:16"> <span className="pl pl-1">蛭にふたりの娘があって、</span><br /><span className="pl pl-1">「与えよ、与えよ」という。</span><br /><span className="pl pl-1">飽くことを知らないものが三つある、</span><br /><span className="pl pl-1">いや、四つあって、</span><br /><span className="pl pl-1">皆「もう、たくさんです」と言わない。</span></span>
<span className="v" id="v16" data-v="16" data-xref="箴言 27:20; ハバクク書 2:5; 創世記 30:1"> <span className="pl pl-1">すなわち陰府、不妊の胎、水にかわく地、</span><br /><span className="pl pl-1">「もう、たくさんだ」といわない火がそれである。</span></span>
<span className="v" id="v17" data-v="17" data-xref="箴言 23:22; 申命記 21:18–21; 箴言 30:11"> <span className="pl pl-1">自分の父をあざけり、</span><br /><span className="pl pl-1">母に従うのを卑しいこととする目は、</span><br /><span className="pl pl-1">谷のからすがこれをつつき出し、</span><br /><span className="pl pl-1">はげたかがこれを食べる。</span></span>
<span className="v" id="v18" data-v="18" data-xref="ヨブ記 42:3; 詩篇 139:6"> <span className="pl pl-1">わたしにとって不思議にたえないことが三つある、</span><br /><span className="pl pl-1">いや、四つあって、わたしには悟ることができない。</span></span>
<span className="v" id="v19" data-v="19" data-xref="イザヤ書 40:31; ヨブ記 39:27; 出エジプト記 22:16"> <span className="pl pl-1">すなわち空を飛ぶはげたかの道、</span><br /><span className="pl pl-1">岩の上を這うへびの道、</span><br /><span className="pl pl-1">海をはしる舟の道、</span><br /><span className="pl pl-1">男の女にあう道がそれである。</span></span>
<span className="v" id="v20" data-v="20" data-xref="箴言 5:6; 箴言 7:13–23; 民数記 5:11–30"> <span className="pl pl-1">遊女の道もまたそうだ、</span><br /><span className="pl pl-1">彼女は食べて、その口をぬぐって、</span><br /><span className="pl pl-1">「わたしは何もわるいことはしない」と言う。</span></span>
<span className="v" id="v21" data-v="21"> <span className="pl pl-1">地は三つのことによって震う、</span><br /><span className="pl pl-1">いや、四つのことによって、耐えることができない。</span></span>
<span className="v" id="v22" data-v="22" data-xref="箴言 19:10; 伝道の書 10:7; サムエル記上 25:10–11"> <span className="pl pl-1">すなわち奴隷たる者が王となり、</span><br /><span className="pl pl-1">愚かな者が食物に飽き、</span></span>
<span className="v" id="v23" data-v="23" data-xref="箴言 21:19; 箴言 27:15; 箴言 29:21"> <span className="pl pl-1">忌みきらわれた女が嫁に行き、</span><br /><span className="pl pl-1">はしためが女主人のあとにすわることである。</span></span>
<span className="v" id="v24" data-v="24" data-xref="ヨブ記 12:7"> <span className="pl pl-1">この地上に、小さいけれども、</span><br /><span className="pl pl-1">非常に賢いものが四つある。</span></span>
<span className="v" id="v25" data-v="25" data-xref="箴言 6:6–8"> <span className="pl pl-1">ありは力のない種類だが、</span><br /><span className="pl pl-1">その食糧を夏のうちに備える。</span></span>
<span className="v" id="v26" data-v="26" data-xref="詩篇 104:18; レビ記 11:5"> <span className="pl pl-1">岩だぬきは強くない種類だが、</span><br /><span className="pl pl-1">その家を岩につくる。</span></span>
<span className="v" id="v27" data-v="27" data-xref="ヨエル書 2:25; ヨエル書 1:6–7; ヨエル書 2:7–11"> <span className="pl pl-1">いなごは王がないけれども、</span><br /><span className="pl pl-1">みな隊を組んでいで立つ。</span></span>
<span className="v" id="v28" data-v="28"> <span className="pl pl-1">やもりは手でつかまえられるが、</span><br /><span className="pl pl-1">王の宮殿におる。</span></span>
<span className="v" id="v29" data-v="29"> <span className="pl pl-1">歩きぶりの堂々たる者が三つある、</span><br /><span className="pl pl-1">いや、四つあって、みな堂々と歩く。</span></span>
<span className="v" id="v30" data-v="30" data-xref="民数記 23:24; 士師記 14:18"> <span className="pl pl-1">すなわち獣のうちでもっとも強く、</span><br /><span className="pl pl-1">何ものの前にも退かない、しし、</span></span>
<span className="v" id="v31" data-v="31" data-xref="ダニエル書 3:15–18; 箴言 20:2; 箴言 16:14"> <span className="pl pl-1">尾を立てて歩くおんどり、雄やぎ、</span><br /><span className="pl pl-1">その民の前をいばって歩く王がそれである。</span></span>
<span className="v" id="v32" data-v="32" data-xref="ヨブ記 21:5; ヨブ記 40:4; 箴言 26:12"> <span className="pl pl-1">あなたがもし愚かであって自ら高ぶり、</span><br /><span className="pl pl-1">あるいは悪事を計ったならば、</span><br /><span className="pl pl-1">あなたの手を口に当てるがよい。</span></span>
<span className="v" id="v33" data-v="33" data-xref="箴言 17:14; 箴言 29:22; 箴言 28:25"> <span className="pl pl-1">乳をしめれば凝乳が出る、</span><br /><span className="pl pl-1">鼻をしめれば血がでる、</span><br /><span className="pl pl-1">怒りをしめれば争いが起る。</span></span>

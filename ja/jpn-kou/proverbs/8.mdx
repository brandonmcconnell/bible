<span className="v" id="v7" data-v="7" data-xref="詩篇 37:30; ヨハネによる福音書 8:14; ヨハネによる福音書 17:17"> <span className="pl pl-1">わが口は真実を述べ、</span><br /><span className="pl pl-1">わがくちびるは悪しき事を憎む。</span></span>

<span className="v" id="v11" data-v="11" data-xref="箴言 3:14–15; 箴言 4:5–7; 箴言 16:16"> <span className="pl pl-1">知恵は宝石にまさり、</span><br /><span className="pl pl-1">あなたがたの望むすべての物は、</span><br /><span className="pl pl-1">これと比べるにたりない。</span></span>

<span className="v" id="v17" data-v="17" data-xref="ヨハネによる福音書 14:23; ヨハネによる福音書 14:21; 詩篇 91:14"> <span className="pl pl-1">わたしは、わたしを愛する者を愛する、</span><br /><span className="pl pl-1">わたしをせつに求める者は、わたしに出会う。</span></span>
<span className="v" id="v18" data-v="18" data-xref="箴言 3:16; マタイによる福音書 6:33; ルカによる福音書 16:11–12"> <span className="pl pl-1">富と誉とはわたしにあり、</span><br /><span className="pl pl-1">すぐれた宝と繁栄もまたそうである。</span></span>
<span className="v" id="v19" data-v="19" data-xref="箴言 3:14; 箴言 10:20; 伝道の書 7:12"> <span className="pl pl-1">わたしの実は金よりも精金よりも良く、</span><br /><span className="pl pl-1">わたしの産物は精銀にまさる。</span></span>
<span className="v" id="v20" data-v="20" data-xref="申命記 5:32; ヨハネによる福音書 10:27–28; 詩篇 32:8"> <span className="pl pl-1">わたしは正義の道、公正な道筋の中を歩み、</span></span>
<span className="v" id="v21" data-v="21" data-xref="ペテロの第一の手紙 1:4; 箴言 24:4; マタイによる福音書 25:46"> <span className="pl pl-1">わたしを愛する者に宝を得させ、</span><br /><span className="pl pl-1">またその倉を満ちさせる。</span></span>
<span className="v" id="v22" data-v="22" data-xref="コロサイ人への手紙 1:17; ヨハネによる福音書 1:1–2; 箴言 3:19"> <span className="pl pl-1">主が昔そのわざをなし始められるとき、</span><br /><span className="pl pl-1">そのわざの初めとして、わたしを造られた。</span></span>

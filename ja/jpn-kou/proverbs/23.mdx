<span className="v" id="v1" data-v="1" data-xref="ユダの手紙 1:12; 創世記 43:32–34"> <span className="pl pl-1">治める人と共に座して食事するとき、</span><br /><span className="pl pl-1">あなたの前にあるものを、よくわきまえ、</span></span>
<span className="v" id="v2" data-v="2" data-xref="ピリピ人への手紙 3:19; マタイによる福音書 18:8–9; コリント人への第一の手紙 9:27"> <span className="pl pl-1">あなたがもし食をたしなむ者であるならば、</span><br /><span className="pl pl-1">あなたののどに刀をあてよ。</span></span>
<span className="v" id="v3" data-v="3" data-xref="箴言 23:6; 詩篇 141:4; エペソ人への手紙 4:22"> <span className="pl pl-1">そのごちそうをむさぼり食べてはならない、</span><br /><span className="pl pl-1">これは人を欺く食物だからである。</span></span>
<span className="v" id="v4" data-v="4" data-xref="ヘブル人への手紙 13:5; 箴言 28:20; マタイによる福音書 6:19"> <span className="pl pl-1">富を得ようと苦労してはならない、</span><br /><span className="pl pl-1">かしこく思いとどまるがよい。</span></span>
<span className="v" id="v5" data-v="5" data-xref="箴言 27:24; ヨハネの第一の手紙 2:16; ヤコブの手紙 5:1–2"> <span className="pl pl-1">あなたの目をそれにとめると、それはない、</span><br /><span className="pl pl-1">富はたちまち自ら翼を生じて、</span><br /><span className="pl pl-1">わしのように天に飛び去るからだ。</span></span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 141:4; 箴言 23:3; ダニエル書 1:8–10"> <span className="pl pl-1">物惜しみする人のパンを食べてはならない、</span><br /><span className="pl pl-1">そのごちそうをむさぼり願ってはならない。</span></span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 12:2; 詩篇 55:21; 士師記 16:15"> <span className="pl pl-1">彼は心のうちで勘定する人のように、</span><br /><span className="pl pl-1">「食え、飲め」とあなたに言うけれども、</span><br /><span className="pl pl-1">その心はあなたに真実ではない。</span></span>
<span className="v" id="v8" data-v="8"> <span className="pl pl-1">あなたはついにその食べた物を吐き出すようになり、</span><br /><span className="pl pl-1">あなたのねんごろな言葉もむだになる。</span></span>
<span className="v" id="v9" data-v="9" data-xref="箴言 9:7–8; マタイによる福音書 7:6; 箴言 26:4–5"> <span className="pl pl-1">愚かな者の耳に語ってはならない、</span><br /><span className="pl pl-1">彼はあなたの言葉が示す知恵をいやしめるからだ。</span></span>
<span className="v" id="v10" data-v="10" data-xref="箴言 22:28; ゼカリヤ書 7:10; 申命記 27:17"> <span className="pl pl-1">古い地境を移してはならない、</span><br /><span className="pl pl-1">みなしごの畑を侵してはならない。</span></span>
<span className="v" id="v11" data-v="11" data-xref="箴言 22:23; ヨブ記 19:25; エレミヤ書 51:36"> <span className="pl pl-1">彼らのあがない主は強くいらせられ、</span><br /><span className="pl pl-1">あなたに逆らって彼らの訴えを弁護されるからだ。</span></span>
<span className="v" id="v12" data-v="12" data-xref="箴言 5:1–2; 箴言 2:2–6; 箴言 23:19"> <span className="pl pl-1">あなたの心を教訓に用い、</span><br /><span className="pl pl-1">あなたの耳を知識の言葉に傾けよ。</span></span>
<span className="v" id="v13" data-v="13" data-xref="箴言 13:24; 箴言 19:18; 箴言 29:15"> <span className="pl pl-1">子を懲らすことを、さし控えてはならない、</span><br /><span className="pl pl-1">むちで彼を打っても死ぬことはない。</span></span>
<span className="v" id="v14" data-v="14" data-xref="コリント人への第一の手紙 5:5; 箴言 22:15; コリント人への第一の手紙 11:32"> <span className="pl pl-1">もし、むちで彼を打つならば、</span><br /><span className="pl pl-1">その命を陰府から救うことができる。</span></span>
<span className="v" id="v15" data-v="15" data-xref="箴言 23:24–25; ヨハネの第二の手紙 1:4; 箴言 29:3"> <span className="pl pl-1">わが子よ、もしあなたの心が賢くあれば、</span><br /><span className="pl pl-1">わたしの心もまた喜び、</span></span>
<span className="v" id="v16" data-v="16" data-xref="箴言 8:6; エペソ人への手紙 5:4; ヤコブの手紙 3:2"> <span className="pl pl-1">もしあなたのくちびるが正しい事を言うならば、</span><br /><span className="pl pl-1">わたしの心も喜ぶ。</span></span>
<span className="v" id="v17" data-v="17" data-xref="箴言 28:14; コリント人への第二の手紙 7:1; ペテロの第一の手紙 1:17"> <span className="pl pl-1">心に罪びとをうらやんではならない、</span><br /><span className="pl pl-1">ただ、ひねもす主を恐れよ。</span></span>
<span className="v" id="v18" data-v="18" data-xref="ヘブル人への手紙 10:35; エレミヤ書 29:11; 詩篇 9:18"> <span className="pl pl-1">かならず後のよい報いがあって、</span><br /><span className="pl pl-1">あなたの望みは、すたらない。</span></span>
<span className="v" id="v19" data-v="19" data-xref="箴言 23:26; 箴言 23:12; 箴言 4:10–23"> <span className="pl pl-1">わが子よ、よく聞いて、知恵を得よ、</span><br /><span className="pl pl-1">かつ、あなたの心を道に向けよ。</span></span>
<span className="v" id="v20" data-v="20" data-xref="ルカによる福音書 21:34; エペソ人への手紙 5:18; イザヤ書 5:22"> <span className="pl pl-1">酒にふけり、</span><br /><span className="pl pl-1">肉をたしなむ者と交わってはならない。</span></span>
<span className="v" id="v21" data-v="21" data-xref="箴言 21:17; 箴言 19:15; 申命記 21:20"> <span className="pl pl-1">酒にふける者と、肉をたしなむ者とは貧しくなり、</span><br /><span className="pl pl-1">眠りをむさぼる者は、ぼろを身にまとうようになる。</span></span>
<span className="v" id="v22" data-v="22" data-xref="箴言 30:17; 箴言 1:8; ヨハネによる福音書 19:26–27"> <span className="pl pl-1">あなたを生んだ父のいうことを聞き、</span><br /><span className="pl pl-1">年老いた母を軽んじてはならない。</span></span>
<span className="v" id="v23" data-v="23" data-xref="箴言 18:15; マタイによる福音書 13:44; 詩篇 119:72"> <span className="pl pl-1">真理を買え、これを売ってはならない、</span><br /><span className="pl pl-1">知恵と教訓と悟りをも買え。</span></span>
<span className="v" id="v24" data-v="24" data-xref="箴言 10:1; 箴言 15:20; 箴言 23:15–16"> <span className="pl pl-1">正しい人の父は大いによろこび、</span><br /><span className="pl pl-1">知恵ある子を生む者は子のために楽しむ。</span></span>
<span className="v" id="v25" data-v="25" data-xref="箴言 17:25; ルカによる福音書 11:27–28; ルカによる福音書 1:58"> <span className="pl pl-1">あなたの父母を楽しませ、</span><br /><span className="pl pl-1">あなたを産んだ母を喜ばせよ。</span></span>
<span className="v" id="v26" data-v="26" data-xref="詩篇 119:2; 詩篇 119:9–11; 申命記 6:5"> <span className="pl pl-1">わが子よ、あなたの心をわたしに与え、</span><br /><span className="pl pl-1">あなたの目をわたしの道に注げ。</span></span>
<span className="v" id="v27" data-v="27" data-xref="箴言 22:14"> <span className="pl pl-1">遊女は深い穴のごとく、</span><br /><span className="pl pl-1">みだらな女は狭い井戸のようだ。</span></span>
<span className="v" id="v28" data-v="28" data-xref="伝道の書 7:26; 箴言 7:12; 箴言 22:14"> <span className="pl pl-1">彼女は盗びとのように人をうかがい、</span><br /><span className="pl pl-1">かつ世の人のうちに、不信実な者を多くする。</span></span>
<span className="v" id="v29" data-v="29" data-xref="エペソ人への手紙 5:18; イザヤ書 5:11; 箴言 23:21"> <span className="pl pl-1">災ある者はだれか、憂いある者はだれか、</span><br /><span className="pl pl-1">争いをする者はだれか、煩いある者はだれか、</span><br /><span className="pl pl-1">ゆえなく傷をうける者はだれか、</span><br /><span className="pl pl-1">赤い目をしている者はだれか。</span></span>
<span className="v" id="v30" data-v="30" data-xref="エペソ人への手紙 5:18; イザヤ書 5:11; 箴言 20:1"> <span className="pl pl-1">酒に夜をふかす者、</span><br /><span className="pl pl-1">行って、混ぜ合わせた酒を味わう者である。</span></span>
<span className="v" id="v31" data-v="31" data-xref="ヨハネの第一の手紙 2:16; サムエル記下 11:2; 詩篇 119:37"> <span className="pl pl-1">酒はあかく、杯の中にあわだち、なめらかにくだる、</span><br /><span className="pl pl-1">あなたはこれを見てはならない。</span></span>
<span className="v" id="v32" data-v="32" data-xref="伝道の書 10:8; イザヤ書 28:7–8; アモス書 9:3"> <span className="pl pl-1">これはついに、へびのようにかみ、</span><br /><span className="pl pl-1">まむしのように刺す。</span></span>
<span className="v" id="v33" data-v="33" data-xref="ユダの手紙 1:12–13; 詩篇 69:12; ダニエル書 5:4"> <span className="pl pl-1">あなたの目は怪しいものを見、</span><br /><span className="pl pl-1">あなたの心は偽りを言う。</span></span>
<span className="v" id="v34" data-v="34" data-xref="テサロニケ人への第一の手紙 5:2–7; 列王紀上 20:16–22; サムエル記上 30:16–17"> <span className="pl pl-1">あなたは海の中に寝ている人のように、</span><br /><span className="pl pl-1">帆柱の上に寝ている人のようになる。</span></span>

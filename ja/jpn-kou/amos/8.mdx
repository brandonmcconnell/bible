<span className="v" id="v1" data-v="1" data-xref="アモス書 7:1; アモス書 7:7; アモス書 7:4"> 主なる神は、このようにわたしに示された。見よ、ひとかごの夏のくだものがある。</span>
<span className="v" id="v2" data-v="2" data-xref="アモス書 7:8; 哀歌 4:18; エレミヤ書 24:1–3"> 主は言われた、「アモスよ、あなたは何を見るか」。わたしは「ひとかごの夏のくだもの」と答えた。すると主はわたしに言われた、<br /><span className="pl pl-1">「わが民イスラエルの終りがきた。</span><br /><span className="pl pl-1">わたしは再び彼らを見過しにしない。</span></span>
<span className="v" id="v3" data-v="3" data-xref="アモス書 5:23; アモス書 6:9–10; エレミヤ書 9:21–22"> <span className="pl pl-1">その日には宮の歌は嘆きに変り、</span><br /><span className="pl pl-1">しかばねがおびただしく、</span><br /><span className="pl pl-1">人々は無言でこれを至る所に投げ捨てる」と</span><br /><span className="pl pl-1">主なる神は言われる。</span></span>
<span className="v" id="v4" data-v="4" data-xref="箴言 30:14; 詩篇 14:4; アモス書 5:11"> <span className="pl pl-1">あなたがた、貧しい者を踏みつけ、</span><br /><span className="pl pl-1">また国の乏しい者を滅ぼす者よ、</span><br /><span className="pl pl-1">これを聞け。</span></span>
<span className="v" id="v5" data-v="5" data-xref="ネヘミヤ書 13:15–21; ミカ書 6:10–11; ホセア書 12:7"> <span className="pl pl-1">あなたがたは言う、</span><br /><span className="pl pl-1">「新月はいつ過ぎ去るだろう、</span><br /><span className="pl pl-1">そうしたら、われわれは穀物を売ろう。</span><br /><span className="pl pl-1">安息日はいつ過ぎ去るだろう、</span><br /><span className="pl pl-1">そうしたら、われわれは麦を売り出そう。</span><br /><span className="pl pl-1">われわれはエパを小さくし、シケルを大きくし、</span><br /><span className="pl pl-1">偽りのはかりをもって欺き、</span></span>
<span className="v" id="v6" data-v="6" data-xref="アモス書 2:6; レビ記 25:39–42; ネヘミヤ書 5:8"> <span className="pl pl-1">乏しい者を金で買い、</span><br /><span className="pl pl-1">貧しい者をくつ一足で買いとり、</span><br /><span className="pl pl-1">また、くず麦を売ろう」。</span></span>
<span className="v" id="v7" data-v="7" data-xref="アモス書 6:8; ホセア書 9:9; ホセア書 8:13"> <span className="pl pl-1">主はヤコブの誇をさして誓われた、</span><br /><span className="pl pl-1">「わたしは必ず彼らのすべてのわざを</span><br /><span className="pl pl-1">いつまでも忘れない。</span></span>
<span className="v" id="v8" data-v="8" data-xref="アモス書 9:5; ホセア書 4:3; エレミヤ書 46:8"> <span className="pl pl-1">これがために地は震わないであろうか。</span><br /><span className="pl pl-1">地に住む者はみな嘆かないであろうか。</span><br /><span className="pl pl-1">地はみなナイル川のようにわきあがり、</span><br /><span className="pl pl-1">エジプトのナイル川のようにみなぎって、また沈まないであろうか」。</span></span>
<span className="v" id="v9" data-v="9" data-xref="マルコによる福音書 15:33; マタイによる福音書 27:45; エレミヤ書 15:9"> <span className="pl pl-1">主なる神は言われる、</span><br /><span className="pl pl-1">「その日には、</span><br /><span className="pl pl-1">わたしは真昼に太陽を沈ませ、</span><br /><span className="pl pl-1">白昼に地を暗くし、</span></span>
<span className="v" id="v10" data-v="10" data-xref="エレミヤ書 6:26; ゼカリヤ書 12:10; ヨブ記 20:23"> <span className="pl pl-1">あなたがたの祭を嘆きに変らせ、</span><br /><span className="pl pl-1">あなたがたの歌をことごとく悲しみの歌に変らせ、</span><br /><span className="pl pl-1">すべての人に荒布を腰にまとわせ、</span><br /><span className="pl pl-1">すべての人に髪をそり落させ、</span><br /><span className="pl pl-1">その日を、ひとり子を失った喪中のようにし、</span><br /><span className="pl pl-1">その終りを、苦い日のようにする」。</span></span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 74:9; サムエル記上 3:1; 歴代志下 15:3"> <span className="pl pl-1">主なる神は言われる、</span><br /><span className="pl pl-1">「見よ、わたしがききんをこの国に送る日が来る、</span><br /><span className="pl pl-1">それはパンのききんではない、</span><br /><span className="pl pl-1">水にかわくのでもない、</span><br /><span className="pl pl-1">主の言葉を聞くことのききんである。</span></span>
<span className="v" id="v12" data-v="12" data-xref="ローマ人への手紙 11:7–10; マタイによる福音書 24:23–26; ダニエル書 12:4"> <span className="pl pl-1">彼らは海から海へさまよい歩き、</span><br /><span className="pl pl-1">主の言葉を求めて、こなたかなたへはせまわる、</span><br /><span className="pl pl-1">しかしこれを得ないであろう。</span></span>
<span className="v" id="v13" data-v="13" data-xref="ホセア書 2:3; 哀歌 1:18; 哀歌 2:21"> <span className="pl pl-1">その日には美しいおとめも、</span><br /><span className="pl pl-1">若い男もかわきのために気を失う。</span></span>
<span className="v" id="v14" data-v="14" data-xref="アモス書 5:5; 列王紀上 12:28–29; 申命記 9:21"> <span className="pl pl-1">かのサマリヤのアシマをさして誓い、</span><br /><span className="pl pl-1">『ダンよ、あなたの神は生きている』と言い、また</span><br /><span className="pl pl-1">『ベエルシバの道は生きている』と言う者どもは</span><br /><span className="pl pl-1">必ず倒れる。再び起きあがることはない」。</span></span>

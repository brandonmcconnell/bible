<span className="v" id="v2" data-v="2" data-xref="エゼキエル書 11:13; イザヤ書 37:4; エレミヤ書 42:2"> そのいなごが地の青草を食い尽した時、わたしは言った、<br /><span className="pl pl-1">「主なる神よ、どうぞ、ゆるしてください。</span><br /><span className="pl pl-1">ヤコブは小さい者です、</span><br /><span className="pl pl-1">どうして立つことができましょう」。</span></span>
<span className="v" id="v3" data-v="3" data-xref="申命記 32:36; ヨナ書 3:10; ホセア書 11:8"> <span className="pl pl-1">主はこのことについて思いかえされ、</span><br /><span className="pl pl-1">「このことは起さない」と主は言われた。</span></span>
<span className="v" id="v4" data-v="4" data-xref="アモス書 7:1; イザヤ書 66:15–16; ヘブル人への手紙 1:7"> <span className="pl pl-1">主なる神はこのようにわたしに示された。見よ、主なる神はさばきのために火を呼ばれた。火は大淵を焼き、また地を焼こうとした。</span></span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 85:4; イザヤ書 1:9; エレミヤ書 30:19"> <span className="pl pl-1">その時わたしは言った、</span><br /><span className="pl pl-1">「主なる神よ、どうぞ、やめてください。</span><br /><span className="pl pl-1">ヤコブは小さい者です、</span><br /><span className="pl pl-1">どうして立つことができましょう」。</span></span>
<span className="v" id="v6" data-v="6" data-xref="アモス書 7:3; 士師記 2:18; 詩篇 90:13"> <span className="pl pl-1">主はこのことについて思いかえされ、</span><br /><span className="pl pl-1">「このこともまた起さない」と主なる神は言われた。</span></span>
<span className="v" id="v7" data-v="7" data-xref="列王紀下 21:13; ヨハネの黙示録 21:15; イザヤ書 28:17"> <span className="pl pl-1">また主はわたしに示された。見よ、主は測りなわをもって築いた石がきの上に立ち、その手に測りなわをもっておられた。</span></span>
<span className="v" id="v8" data-v="8" data-xref="アモス書 8:2; 哀歌 2:8; エゼキエル書 7:2–9"> <span className="pl pl-1">そして主はわたしに言われた、「アモスよ、あなたは何を見るか」。「測りなわ」とわたしが答えると、主はまた言われた、</span><br /><span className="pl pl-1">「見よ、わたしは測りなわを</span><br /><span className="pl pl-1">わが民イスラエルの中に置く。</span><br /><span className="pl pl-1">わたしはもはや彼らを見過しにしない。</span></span>
<span className="v" id="v9" data-v="9" data-xref="列王紀下 15:8–10; 創世記 46:1; アモス書 8:14"> <span className="pl pl-1">イサクの高き所は荒され、</span><br /><span className="pl pl-1">イスラエルの聖所は荒れはてる。</span><br /><span className="pl pl-1">わたしはつるぎをもってヤラベアムの家に立ち向かう」。</span></span>
<span className="v" id="v10" data-v="10" data-xref="エレミヤ書 38:4; 列王紀上 12:31–32; エレミヤ書 26:8–11"> <span className="pl pl-1">時にベテルの祭司アマジヤは、イスラエルの王ヤラベアムに人をつかわして言う、「イスラエルの家のただ中で、アモスはあなたにそむきました。この地は彼のもろもろの言葉に耐えることができません。</span></span>
<span className="v" id="v11" data-v="11" data-xref="列王紀下 17:6; 詩篇 56:5; アモス書 6:7–8"> <span className="pl pl-1">アモスはこのように言っています、</span><br /><span className="pl pl-1">『ヤラベアムはつるぎによって死ぬ、</span><br /><span className="pl pl-1">イスラエルは必ず捕えられて行って、</span><br /><span className="pl pl-1">その国を離れる』と」。</span></span>
<span className="v" id="v12" data-v="12" data-xref="コリント人への第一の手紙 2:14; マタイによる福音書 8:34; サムエル記上 9:9"> <span className="pl pl-1">それからアマジヤはアモスに言った、「先見者よ、行ってユダの地にのがれ、かの地でパンを食べ、かの地で預言せよ。</span></span>
<span className="v" id="v13" data-v="13" data-xref="列王紀上 12:32; アモス書 2:12; 列王紀上 12:29"> <span className="pl pl-1">しかしベテルでは二度と預言してはならない。ここは王の聖所、国の宮だから」。</span></span>

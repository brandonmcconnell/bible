<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヤコブの手紙 1:1; 使徒行伝 2:5–11; ヘブル人への手紙 11:13"> イエス・キリストの使徒ペテロから、ポント、ガラテヤ、カパドキヤ、アジヤおよびビテニヤに離散し寄留している人たち、</span>
<span className="v" id="v2" data-v="2" data-xref="テサロニケ人への第二の手紙 2:13; エペソ人への手紙 1:4–5; ヘブル人への手紙 12:24"> すなわち、イエス・キリストに従い、かつ、その血のそそぎを受けるために、父なる神の予知されたところによって選ばれ、御霊のきよめにあずかっている人たちへ。<br />恵みと平安とが、あなたがたに豊かに加わるように。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="ペテロの第一の手紙 1:23; ヨハネの第一の手紙 5:4; ローマ人への手紙 15:13"> ほむべきかな、わたしたちの主イエス・キリストの父なる神。神は、その豊かなあわれみにより、イエス・キリストを死人の中からよみがえらせ、それにより、わたしたちを新たに生れさせて生ける望みをいだかせ、</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネの黙示録 21:27; ヘブル人への手紙 9:15; ペテロの第一の手紙 5:4"> あなたがたのために天にたくわえてある、朽ちず汚れず、しぼむことのない資産を受け継ぐ者として下さったのである。</span>
<span className="v" id="v5" data-v="5" data-xref="ピリピ人への手紙 1:6; エペソ人への手紙 2:8; テサロニケ人への第二の手紙 2:13–14"> あなたがたは、終りの時に啓示さるべき救にあずかるために、信仰により神の御力に守られているのである。</span>
<span className="v" id="v6" data-v="6" data-xref="ヤコブの手紙 1:2; ペテロの第一の手紙 5:10; ローマ人への手紙 12:12"> そのことを思って、今しばらくのあいだは、さまざまな試錬で悩まねばならないかも知れないが、あなたがたは大いに喜んでいる。</span>
<span className="v" id="v7" data-v="7" data-xref="ヨブ記 23:10; イザヤ書 48:10; ペテロの第一の手紙 4:12"> こうして、あなたがたの信仰はためされて、火で精錬されても朽ちる外はない金よりもはるかに尊いことが明らかにされ、イエス・キリストの現れるとき、さんびと栄光とほまれとに変るであろう。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨハネによる福音書 20:29; コリント人への第二の手紙 5:7; ローマ人への手紙 15:13"> あなたがたは、イエス・キリストを見たことはないが、彼を愛している。現在、見てはいないけれども、信じて、言葉につくせない、輝きにみちた喜びにあふれている。</span>
<span className="v" id="v9" data-v="9" data-xref="ローマ人への手紙 6:22; ヤコブの手紙 1:21; ヘブル人への手紙 11:13"> それは、信仰の結果なるたましいの救を得ているからである。</span>
<span className="v" id="v10" data-v="10" data-xref="マタイによる福音書 13:17; ルカによる福音書 10:24; ルカによる福音書 24:25–27"> この救については、あなたがたに対する恵みのことを預言した預言者たちも、たずね求め、かつ、つぶさに調べた。</span>
<span className="v" id="v11" data-v="11" data-xref="イザヤ書 52:13–14; ペテロの第二の手紙 1:21; ルカによる福音書 24:25–27"> 彼らは、自分たちのうちにいますキリストの霊が、キリストの苦難とそれに続く栄光とを、あらかじめあかしした時、それは、いつの時、どんな場合をさしたのかを、調べたのである。</span>
<span className="v" id="v12" data-v="12" data-xref="ヨハネによる福音書 15:26; コリント人への第一の手紙 2:10; エペソ人への手紙 3:10"> そして、それらについて調べたのは、自分たちのためではなくて、あなたがたのための奉仕であることを示された。それらの事は、天からつかわされた聖霊に感じて福音をあなたがたに宣べ伝えた人々によって、今や、あなたがたに告げ知らされたのであるが、これは、御使たちも、うかがい見たいと願っている事である。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="ペテロの第一の手紙 5:8; ルカによる福音書 12:35; ペテロの第一の手紙 4:7"> それだから、心の腰に帯を締め、身を慎み、イエス・キリストの現れる時に与えられる恵みを、いささかも疑わずに待ち望んでいなさい。</span>
<span className="v" id="v14" data-v="14" data-xref="ローマ人への手紙 12:2; テトスヘの手紙 3:3–5; ペテロの第一の手紙 4:2–3"> 従順な子供として、無知であった時代の欲情に従わず、</span>
<span className="v" id="v15" data-v="15" data-xref="マタイによる福音書 5:48; コリント人への第二の手紙 7:1; ヘブル人への手紙 12:14"> むしろ、あなたがたを召して下さった聖なるかたにならって、あなたがた自身も、あらゆる行いにおいて聖なる者となりなさい。</span>
<span className="v" id="v16" data-v="16" data-xref="レビ記 11:44; レビ記 19:2; レビ記 20:7"> 聖書に、「わたしが聖なる者であるから、あなたがたも聖なる者になるべきである」と書いてあるからである。</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行伝 10:34–35; 歴代志下 19:7; マタイによる福音書 6:9"> あなたがたは、人をそれぞれのしわざに応じて、公平にさばくかたを、父と呼んでいるからには、地上に宿っている間を、おそれの心をもって過ごすべきである。</span>
<span className="v" id="v18" data-v="18" data-xref="コリント人への第一の手紙 6:20; テトスヘの手紙 2:14; 詩篇 49:7–8"> あなたがたのよく知っているとおり、あなたがたが先祖伝来の空疎な生活からあがない出されたのは、銀や金のような朽ちる物によったのではなく、</span>
<span className="v" id="v19" data-v="19" data-xref="ヨハネの第一の手紙 1:7; ペテロの第一の手紙 2:22–24; ヨハネによる福音書 1:29"> きずも、しみもない小羊のようなキリストの尊い血によったのである。</span>
<span className="v" id="v20" data-v="20" data-xref="エペソ人への手紙 1:4; テモテヘの第二の手紙 1:9–10; ヘブル人への手紙 9:26"> キリストは、天地が造られる前から、あらかじめ知られていたのであるが、この終りの時に至って、あなたがたのために現れたのである。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行伝 2:24; ヘブル人への手紙 2:9; ヨハネによる福音書 12:44"> あなたがたは、このキリストによって、彼を死人の中からよみがえらせて、栄光をお与えになった神を信じる者となったのであり、したがって、あなたがたの信仰と望みとは、神にかかっているのである。</span>
</div>
<div className="bp poetry">
<span className="v" id="v22" data-v="22" data-xref="テモテヘの第一の手紙 1:5; ヘブル人への手紙 13:1; ローマ人への手紙 12:9–10"> あなたがたは、真理に従うことによって、たましいをきよめ、偽りのない兄弟愛をいだくに至ったのであるから、互に心から熱く愛し合いなさい。</span>
<span className="v" id="v23" data-v="23" data-xref="ペテロの第一の手紙 1:3; ヘブル人への手紙 4:12; ヨハネによる福音書 1:13"> あなたがたが新たに生れたのは、朽ちる種からではなく、朽ちない種から、すなわち、神の変ることのない生ける御言によったのである。</span>
<span className="v" id="v24" data-v="24" data-xref="イザヤ書 40:6–8; 詩篇 103:15; ヤコブの手紙 4:14"> <span className="pl pl-1">「人はみな草のごとく、</span><br /><span className="pl pl-1">その栄華はみな草の花に似ている。</span><br /><span className="pl pl-1">草は枯れ、</span><br /><span className="pl pl-1">花は散る。</span><br /><span className="pl pl-1">しかし、主の言葉は、とこしえに残る」。</span></span>
<span className="v" id="v25" data-v="25" data-xref="イザヤ書 40:8; マタイによる福音書 5:18; 詩篇 119:89"> <span className="pl pl-1">これが、あなたがたに宣べ伝えられた御言葉である。</span></span>
</div>

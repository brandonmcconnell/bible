<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="エペソ人への手紙 4:31; ヤコブの手紙 1:21; ヤコブの手紙 4:11"> だから、あらゆる悪意、あらゆる偽り、偽善、そねみ、いっさいの悪口を捨てて、</span>
<span className="v" id="v2" data-v="2" data-xref="ヘブル人への手紙 5:12–13; エペソ人への手紙 4:15; ペテロの第二の手紙 3:18"> 今生れたばかりの乳飲み子のように、混じりけのない霊の乳を慕い求めなさい。それによっておい育ち、救に入るようになるためである。</span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 34:8; ヘブル人への手紙 6:5–6; 詩篇 63:5"> あなたがたは、主が恵み深いかたであることを、すでに味わい知ったはずである。</span>
<span className="v" id="v4" data-v="4" data-xref="詩篇 118:22–23; 使徒行伝 4:11–12; ペテロの第一の手紙 2:7"> 主は、人には捨てられたが、神にとっては選ばれた尊い生ける石である。</span>
<span className="v" id="v5" data-v="5" data-xref="エペソ人への手紙 2:20–22; ペテロの第一の手紙 2:9; コリント人への第一の手紙 3:9"> この主のみもとにきて、あなたがたも、それぞれ生ける石となって、霊の家に築き上げられ、聖なる祭司となって、イエス・キリストにより、神によろこばれる霊のいけにえを、ささげなさい。</span>
<span className="v" id="v6" data-v="6" data-xref="イザヤ書 28:16; ローマ人への手紙 9:32–33; ペテロの第一の手紙 2:4"> 聖書にこう書いてある、<br /><span className="pl pl-1">「見よ、わたしはシオンに、</span><br /><span className="pl pl-1">選ばれた尊い石、隅のかしら石を置く。</span><br /><span className="pl pl-1">それにより頼む者は、</span><br /><span className="pl pl-1">決して、失望に終ることがない」。</span></span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 118:22–23; マルコによる福音書 12:10–11; 使徒行伝 4:11–12"> <span className="pl pl-1">この石は、より頼んでいるあなたがたには尊いものであるが、不信仰な人々には「家造りらの捨てた石で、隅のかしら石となったもの」、</span></span>
<span className="v" id="v8" data-v="8" data-xref="イザヤ書 8:14; コリント人への第一の手紙 1:23; ローマ人への手紙 9:32–33"> <span className="pl pl-1">また「つまずきの石、妨げの岩」である。しかし、彼らがつまずくのは、御言に従わないからであって、彼らは、実は、そうなるように定められていたのである。</span></span>
<span className="v" id="v9" data-v="9" data-xref="出エジプト記 19:5–6; 申命記 7:6; ヨハネの黙示録 1:6"> <span className="pl pl-1">しかし、あなたがたは、選ばれた種族、祭司の国、聖なる国民、神につける民である。それによって、暗やみから驚くべきみ光に招き入れて下さったかたのみわざを、あなたがたが語り伝えるためである。</span></span>
<span className="v" id="v10" data-v="10" data-xref="ホセア書 2:23; ヘブル人への手紙 4:16; ホセア書 1:9–10"> <span className="pl pl-1">あなたがたは、以前は神の民でなかったが、いまは神の民であり、以前は、あわれみを受けたことのない者であったが、いまは、あわれみを受けた者となっている。</span></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="ヨハネの第一の手紙 2:15–17; ガラテヤ人への手紙 5:24; ペテロの第一の手紙 4:2"> 愛する者たちよ。あなたがたに勧める。あなたがたは、この世の旅人であり寄留者であるから、たましいに戦いをいどむ肉の欲を避けなさい。</span>
<span className="v" id="v12" data-v="12" data-xref="ペテロの第一の手紙 3:16; マタイによる福音書 5:16; テトスヘの手紙 2:7–8"> 異邦人の中にあって、りっぱな行いをしなさい。そうすれば、彼らは、あなたがたを悪人呼ばわりしていても、あなたがたのりっぱなわざを見て、かえって、おとずれの日に神をあがめるようになろう。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="テトスヘの手紙 3:1; ローマ人への手紙 13:1–7; テモテヘの第一の手紙 2:1–2"> あなたがたは、すべて人の立てた制度に、主のゆえに従いなさい。主権者としての王であろうと、</span>
<span className="v" id="v14" data-v="14" data-xref="ローマ人への手紙 13:3–4"> あるいは、悪を行う者を罰し善を行う者を賞するために、王からつかわされた長官であろうと、これに従いなさい。</span>
<span className="v" id="v15" data-v="15" data-xref="ペテロの第一の手紙 3:17; テトスヘの手紙 2:8; マタイによる福音書 7:26"> 善を行うことによって、愚かな人々の無知な発言を封じるのは、神の御旨なのである。</span>
<span className="v" id="v16" data-v="16" data-xref="ガラテヤ人への手紙 5:13; ローマ人への手紙 6:22; ローマ人への手紙 6:18"> 自由人にふさわしく行動しなさい。ただし、自由をば悪を行う口実として用いず、神の僕にふさわしく行動しなさい。</span>
<span className="v" id="v17" data-v="17" data-xref="箴言 24:21; ローマ人への手紙 12:10; ローマ人への手紙 13:7"> すべての人をうやまい、兄弟たちを愛し、神をおそれ、王を尊びなさい。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="テトスヘの手紙 2:9–10; エペソ人への手紙 6:5–7; コロサイ人への手紙 3:22–25"> 僕たる者よ。心からのおそれをもって、主人に仕えなさい。善良で寛容な主人だけにでなく、気むずかしい主人にも、そうしなさい。</span>
<span className="v" id="v19" data-v="19" data-xref="マタイによる福音書 5:10–12; ペテロの第一の手紙 3:14–17; ペテロの第一の手紙 2:20"> もしだれかが、不当な苦しみを受けても、神を仰いでその苦痛を耐え忍ぶなら、それはよみせられることである。</span>
<span className="v" id="v20" data-v="20" data-xref="ペテロの第一の手紙 2:19; ペテロの第一の手紙 3:17; マタイによる福音書 5:10–12"> 悪いことをして打ちたたかれ、それを忍んだとしても、なんの手柄になるのか。しかし善を行って苦しみを受け、しかもそれを耐え忍んでいるとすれば、これこそ神によみせられることである。</span>
<span className="v" id="v21" data-v="21" data-xref="ヨハネの第一の手紙 2:6; マタイによる福音書 16:24; ヨハネによる福音書 13:15"> あなたがたは、実に、そうするようにと召されたのである。キリストも、あなたがたのために苦しみを受け、御足の跡を踏み従うようにと、模範を残されたのである。</span>
<span className="v" id="v22" data-v="22" data-xref="イザヤ書 53:9; コリント人への第二の手紙 5:21; ヘブル人への手紙 4:15"> キリストは罪を犯さず、その口には偽りがなかった。</span>
<span className="v" id="v23" data-v="23" data-xref="イザヤ書 53:7; ペテロの第一の手紙 4:19; ヘブル人への手紙 12:3"> ののしられても、ののしりかえさず、苦しめられても、おびやかすことをせず、正しいさばきをするかたに、いっさいをゆだねておられた。</span>
<span className="v" id="v24" data-v="24" data-xref="イザヤ書 53:4–6; マタイによる福音書 8:17; ローマ人への手紙 6:11"> さらに、わたしたちが罪に死に、義に生きるために、十字架にかかって、わたしたちの罪をご自分の身に負われた。その傷によって、あなたがたは、いやされたのである。</span>
<span className="v" id="v25" data-v="25" data-xref="イザヤ書 53:6; エゼキエル書 34:6; ルカによる福音書 15:4–6"> あなたがたは、羊のようにさ迷っていたが、今は、たましいの牧者であり監督であるかたのもとに、たち帰ったのである。</span>
</div>

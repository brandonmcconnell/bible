<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ガラテヤ人への手紙 5:24; ペテロの第一の手紙 3:18; コロサイ人への手紙 3:3–5"> このように、キリストは肉において苦しまれたのであるから、あなたがたも同じ覚悟で心の武装をしなさい。肉において苦しんだ人は、それによって罪からのがれたのである。</span>
<span className="v" id="v2" data-v="2" data-xref="エペソ人への手紙 4:22–24; ペテロの第一の手紙 1:14; テトスヘの手紙 3:3–8"> それは、肉における残りの生涯を、もはや人間の欲情によらず、神の御旨によって過ごすためである。</span>
<span className="v" id="v3" data-v="3" data-xref="コリント人への第一の手紙 6:11; エペソ人への手紙 5:18; テサロニケ人への第一の手紙 4:5"> 過ぎ去った時代には、あなたがたは、異邦人の好みにまかせて、好色、欲情、酔酒、宴楽、暴飲、気ままな偶像礼拝などにふけってきたが、もうそれで十分であろう。</span>
<span className="v" id="v4" data-v="4" data-xref="ペテロの第一の手紙 3:16; ペテロの第一の手紙 2:12; ユダの手紙 1:10"> 今はあなたがたが、そうした度を過ごした乱行に加わらないので、彼らは驚きあやしみ、かつ、ののしっている。</span>
<span className="v" id="v5" data-v="5" data-xref="ヤコブの手紙 5:9; 使徒行伝 10:42; テモテヘの第二の手紙 4:1"> 彼らは、やがて生ける者と死ねる者とをさばくかたに、申し開きをしなくてはならない。</span>
<span className="v" id="v6" data-v="6" data-xref="ローマ人への手紙 8:2; ペテロの第一の手紙 3:19; ローマ人への手紙 8:9–11"> 死人にさえ福音が宣べ伝えられたのは、彼らは肉においては人間としてさばきを受けるが、霊においては神に従って生きるようになるためである。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="ヤコブの手紙 5:8–9; ペテロの第一の手紙 1:13; ペテロの第一の手紙 5:8"> 万物の終りが近づいている。だから、心を確かにし、身を慎んで、努めて祈りなさい。</span>
<span className="v" id="v8" data-v="8" data-xref="箴言 10:12; コロサイ人への手紙 3:14; 箴言 17:9"> 何よりもまず、互の愛を熱く保ちなさい。愛は多くの罪をおおうものである。</span>
<span className="v" id="v9" data-v="9" data-xref="ヘブル人への手紙 13:2; ローマ人への手紙 12:13; ピリピ人への手紙 2:14"> 不平を言わずに、互にもてなし合いなさい。</span>
<span className="v" id="v10" data-v="10" data-xref="ローマ人への手紙 12:6–8; コリント人への第一の手紙 12:4–11; コリント人への第一の手紙 4:1–2"> あなたがたは、それぞれ賜物をいただいているのだから、神のさまざまな恵みの良き管理人として、それをお互のために役立てるべきである。</span>
<span className="v" id="v11" data-v="11" data-xref="コリント人への第一の手紙 10:31; エペソ人への手紙 6:10; ペテロの第一の手紙 4:10"> 語る者は、神の御言を語る者にふさわしく語り、奉仕する者は、神から賜わる力による者にふさわしく奉仕すべきである。それは、すべてのことにおいてイエス・キリストによって、神があがめられるためである。栄光と力とが世々限りなく、彼にあるように、アァメン。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="テモテヘの第二の手紙 3:12; ペテロの第一の手紙 1:6–7; ペテロの第一の手紙 5:9"> 愛する者たちよ。あなたがたを試みるために降りかかって来る火のような試錬を、何か思いがけないことが起ったかのように驚きあやしむことなく、</span>
<span className="v" id="v13" data-v="13" data-xref="ローマ人への手紙 8:17; ヤコブの手紙 1:2–3; ローマ人への手紙 5:3"> むしろ、キリストの苦しみにあずかればあずかるほど、喜ぶがよい。それは、キリストの栄光が現れる際に、よろこびにあふれるためである。</span>
<span className="v" id="v14" data-v="14" data-xref="ペテロの第一の手紙 3:14; ルカによる福音書 6:22; マタイによる福音書 5:11"> キリストの名のためにそしられるなら、あなたがたはさいわいである。その時には、栄光の霊、神の霊が、あなたがたに宿るからである。</span>
<span className="v" id="v15" data-v="15" data-xref="テサロニケ人への第二の手紙 3:11; テサロニケ人への第一の手紙 4:11; テモテヘの第一の手紙 5:13"> あなたがたのうち、だれも、人殺し、盗人、悪を行う者、あるいは、他人に干渉する者として苦しみに会うことのないようにしなさい。</span>
<span className="v" id="v16" data-v="16" data-xref="ペテロの第一の手紙 3:17–18; ピリピ人への手紙 1:29; ペテロの第一の手紙 4:19"> しかし、クリスチャンとして苦しみを受けるのであれば、恥じることはない。かえって、この名によって神をあがめなさい。</span>
<span className="v" id="v17" data-v="17" data-xref="エレミヤ書 25:29; テサロニケ人への第二の手紙 1:8; ローマ人への手紙 2:9"> さばきが神の家から始められる時がきた。それが、わたしたちからまず始められるとしたら、神の福音に従わない人々の行く末は、どんなであろうか。</span>
<span className="v" id="v18" data-v="18" data-xref="箴言 11:31; エゼキエル書 18:24; ルカによる福音書 23:31"> また義人でさえ、かろうじて救われるのだとすれば、不信なる者や罪人は、どうなるであろうか。</span>
<span className="v" id="v19" data-v="19" data-xref="詩篇 37:5; テモテヘの第二の手紙 1:12; ペテロの第一の手紙 3:17"> だから、神の御旨に従って苦しみを受ける人々は、善をおこない、そして、真実であられる創造者に、自分のたましいをゆだねるがよい。</span>

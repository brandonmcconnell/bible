<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="コロサイ人への手紙 3:18; エペソ人への手紙 5:33; エペソ人への手紙 5:22–24"> 同じように、妻たる者よ。夫に仕えなさい。そうすれば、たとい御言に従わない夫であっても、</span>
<span className="v" id="v2" data-v="2" data-xref="ペテロの第一の手紙 2:12; ペテロの第一の手紙 1:15; ピリピ人への手紙 1:27"> あなたがたのうやうやしく清い行いを見て、その妻の無言の行いによって、救に入れられるようになるであろう。</span>
<span className="v" id="v3" data-v="3" data-xref="テモテヘの第一の手紙 2:9–10; ローマ人への手紙 12:2; イザヤ書 3:18–24"> あなたがたは、髪を編み、金の飾りをつけ、服装をととのえるような外面の飾りではなく、</span>
<span className="v" id="v4" data-v="4" data-xref="コロサイ人への手紙 3:12; サムエル記上 16:7; ローマ人への手紙 2:29"> かくれた内なる人、柔和で、しとやかな霊という朽ちることのない飾りを、身につけるべきである。これこそ、神のみまえに、きわめて尊いものである。</span>
<span className="v" id="v5" data-v="5" data-xref="テトスヘの手紙 2:3–4; テモテヘの第一の手紙 5:5; ルカによる福音書 2:37"> むかし、神を仰ぎ望んでいた聖なる女たちも、このように身を飾って、その夫に仕えたのである。</span>
<span className="v" id="v6" data-v="6" data-xref="創世記 18:12; ローマ人への手紙 9:7–9; イザヤ書 57:11"> たとえば、サラはアブラハムに仕えて、彼を主と呼んだ。あなたがたも、何事にもおびえ臆することなく善を行えば、サラの娘たちとなるのである。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="コロサイ人への手紙 3:19; 創世記 2:23–24; マタイによる福音書 19:3–9"> 夫たる者よ。あなたがたも同じように、女は自分よりも弱い器であることを認めて、知識に従って妻と共に住み、いのちの恵みを共どもに受け継ぐ者として、尊びなさい。それは、あなたがたの祈が妨げられないためである。</span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="ローマ人への手紙 12:10; エペソ人への手紙 4:31–2; ペテロの第一の手紙 1:22"> 最後に言う。あなたがたは皆、心をひとつにし、同情し合い、兄弟愛をもち、あわれみ深くあり、謙虚でありなさい。</span>
<span className="v" id="v9" data-v="9" data-xref="箴言 20:22; ローマ人への手紙 12:17; ローマ人への手紙 12:14"> 悪をもって悪に報いず、悪口をもって悪口に報いず、かえって、祝福をもって報いなさい。あなたがたが召されたのは、祝福を受け継ぐためなのである。</span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 34:12–16; ヤコブの手紙 1:26; ペテロの第一の手紙 2:1"> <span className="pl pl-1">「いのちを愛し、</span><br /><span className="pl pl-1">さいわいな日々を過ごそうと願う人は、</span><br /><span className="pl pl-1">舌を制して悪を言わず、</span><br /><span className="pl pl-1">くちびるを閉じて偽りを語らず、</span></span>
<span className="v" id="v11" data-v="11" data-xref="マタイによる福音書 5:9; 詩篇 34:14; ヘブル人への手紙 12:14"> <span className="pl pl-1">悪を避けて善を行い、</span><br /><span className="pl pl-1">平和を求めて、これを追え。</span></span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 34:15–16; ヨハネによる福音書 9:31; 箴言 15:29"> <span className="pl pl-1">主の目は義人たちに注がれ、</span><br /><span className="pl pl-1">主の耳は彼らの祈にかたむく。</span><br /><span className="pl pl-1">しかし主の御顔は、悪を行う者に対して向かう」。</span></span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="箴言 16:7; ローマ人への手紙 8:28; テサロニケ人への第一の手紙 5:15"> そこで、もしあなたがたが善に熱心であれば、だれが、あなたがたに危害を加えようか。</span>
<span className="v" id="v14" data-v="14" data-xref="マタイによる福音書 10:28; ペテロの第一の手紙 2:19–20; マタイによる福音書 5:10–12"> しかし、万一義のために苦しむようなことがあっても、あなたがたはさいわいである。彼らを恐れたり、心を乱したりしてはならない。</span>
<span className="v" id="v15" data-v="15" data-xref="コロサイ人への手紙 4:6; テモテヘの第二の手紙 2:25–26; ルカによる福音書 21:14–15"> ただ、心の中でキリストを主とあがめなさい。また、あなたがたのうちにある望みについて説明を求める人には、いつでも弁明のできる用意をしていなさい。</span>
<span className="v" id="v16" data-v="16" data-xref="ペテロの第一の手紙 2:12; ヘブル人への手紙 13:18; ペテロの第一の手紙 2:15"> しかし、やさしく、慎み深く、明らかな良心をもって、弁明しなさい。そうすれば、あなたがたがキリストにあって営んでいる良い生活をそしる人々も、そのようにののしったことを恥じいるであろう。</span>
<span className="v" id="v17" data-v="17" data-xref="ペテロの第一の手紙 3:14; ペテロの第一の手紙 4:19; マタイによる福音書 26:39"> 善をおこなって苦しむことは――それが神の御旨であれば――悪をおこなって苦しむよりも、まさっている。</span>
<span className="v" id="v18" data-v="18" data-xref="ヘブル人への手紙 9:28; ヘブル人への手紙 9:26; コリント人への第二の手紙 5:21"> キリストも、あなたがたを神に近づけようとして、自らは義なるかたであるのに、不義なる人々のために、ひとたび罪のゆえに死なれた。ただし、肉においては殺されたが、霊においては生かされたのである。</span>
<span className="v" id="v19" data-v="19" data-xref="ペテロの第一の手紙 4:6; イザヤ書 61:1; イザヤ書 42:7"> こうして、彼は獄に捕われている霊どものところに下って行き、宣べ伝えることをされた。</span>
<span className="v" id="v20" data-v="20" data-xref="ヘブル人への手紙 11:7; ペテロの第二の手紙 2:5; 創世記 6:3"> これらの霊というのは、むかしノアの箱舟が造られていた間、神が寛容をもって待っておられたのに従わなかった者どものことである。その箱舟に乗り込み、水を経て救われたのは、わずかに八名だけであった。</span>
<span className="v" id="v21" data-v="21" data-xref="マルコによる福音書 16:16; エゼキエル書 36:25–26; 使徒行伝 2:38"> この水はバプテスマを象徴するものであって、今やあなたがたをも救うのである。それは、イエス・キリストの復活によるのであって、からだの汚れを除くことではなく、明らかな良心を神に願い求めることである。</span>
<span className="v" id="v22" data-v="22" data-xref="ヘブル人への手紙 9:24; ヘブル人への手紙 12:2; ヘブル人への手紙 10:12"> キリストは天に上って神の右に座し、天使たちともろもろの権威、権力を従えておられるのである。</span>

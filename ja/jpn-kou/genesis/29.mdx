<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士師記 6:3; 士師記 6:33; ホセア書 12:12"> ヤコブはその旅を続けて東の民の地へ行った。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネによる福音書 4:14; イザヤ書 49:10; ヨハネによる福音書 4:6"> 見ると野に一つの井戸があって、そのかたわらに羊の三つの群れが伏していた。人々はその井戸から群れに水を飲ませるのであったが、井戸の口には大きな石があった。</span>
<span className="v" id="v3" data-v="3"> 群れが皆そこに集まると、人々は井戸の口から石をころがして羊に水を飲ませ、その石をまた井戸の口の元のところに返しておくのである。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="創世記 28:10; 創世記 27:43; 使徒行伝 7:2"> ヤコブは人々に言った、「兄弟たちよ、あなたがたはどこからこられたのですか」。彼らは言った、「わたしたちはハランからです」。</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 24:24; 創世記 24:29; 創世記 31:53"> ヤコブは彼らに言った、「あなたがたはナホルの子ラバンを知っていますか」。彼らは言った、「知っています」。</span>
<span className="v" id="v6" data-v="6" data-xref="サムエル記下 20:9; 創世記 37:14; 出エジプト記 18:7"> ヤコブはまた彼らに言った、「彼は無事ですか」。彼らは言った、「無事です。御覧なさい。彼の娘ラケルはいま羊と一緒にここへきます」。</span>
<span className="v" id="v7" data-v="7" data-xref="エペソ人への手紙 5:16; ガラテヤ人への手紙 6:9–10"> ヤコブは言った、「日はまだ高いし、家畜を集める時でもない。あなたがたは羊に水を飲ませてから、また行って飼いなさい」。</span>
<span className="v" id="v8" data-v="8" data-xref="マルコによる福音書 16:3; ルカによる福音書 24:2; 創世記 34:14"> 彼らは言った、「わたしたちはそれはできないのです。群れがみな集まった上で、井戸の口から石をころがし、それから羊に水を飲ませるのです」。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="出エジプト記 2:21; 雅歌 1:7–8; 出エジプト記 2:15–16"> ヤコブがなお彼らと語っている時に、ラケルは父の羊と一緒にきた。彼女は羊を飼っていたからである。</span>
<span className="v" id="v10" data-v="10" data-xref="出エジプト記 2:17"> ヤコブは母の兄ラバンの娘ラケルと母の兄ラバンの羊とを見た。そしてヤコブは進み寄って井戸の口から石をころがし、母の兄ラバンの羊に水を飲ませた。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 33:4; 創世記 45:14–15; 創世記 45:2"> ヤコブはラケルに口づけし、声をあげて泣いた。</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 24:28; 創世記 13:8; 創世記 14:14–16"> ヤコブはラケルに、自分がラケルの父のおいであり、リベカの子であることを告げたので、彼女は走って行って父に話した。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="創世記 24:29; 使徒行伝 20:37; ローマ人への手紙 16:16"> ラバンは妹の子ヤコブがきたという知らせを聞くとすぐ、走って行ってヤコブを迎え、これを抱いて口づけし、家に連れてきた。そこでヤコブはすべての事をラバンに話した。</span>
<span className="v" id="v14" data-v="14" data-xref="サムエル記下 19:12–13; 創世記 2:23; 士師記 9:2"> ラバンは彼に言った、「あなたはほんとうにわたしの骨肉です」。ヤコブは一か月の間彼と共にいた。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="創世記 30:28; 創世記 31:7"> 時にラバンはヤコブに言った、「あなたはわたしのおいだからといって、ただでわたしのために働くこともないでしょう。どんな報酬を望みますか、わたしに言ってください」。</span>
<span className="v" id="v16" data-v="16" data-xref="ルツ記 4:11; 創世記 49:31; 創世記 31:4"> さてラバンにはふたりの娘があった。姉の名はレアといい、妹の名はラケルといった。</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 12:11; 創世記 46:19–22; 創世記 24:16"> レアは目が弱かったが、ラケルは美しくて愛らしかった。</span>
<span className="v" id="v18" data-v="18" data-xref="ホセア書 12:12; 出エジプト記 22:16–17; 創世記 34:12"> ヤコブはラケルを愛したので、「わたしは、あなたの妹娘ラケルのために七年あなたに仕えましょう」と言った。</span>
<span className="v" id="v19" data-v="19" data-xref="イザヤ書 6:11; イザヤ書 6:5; 詩篇 12:2"> ラバンは言った、「彼女を他人にやるよりもあなたにやる方がよい。わたしと一緒にいなさい」。</span>
<span className="v" id="v20" data-v="20" data-xref="コリント人への第一の手紙 13:7; エペソ人への手紙 5:2; ホセア書 12:12"> こうして、ヤコブは七年の間ラケルのために働いたが、彼女を愛したので、ただ数日のように思われた。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="士師記 15:1; 創世記 29:20; 創世記 4:1"> ヤコブはラバンに言った、「期日が満ちたから、わたしの妻を与えて、妻の所にはいらせてください」。</span>
<span className="v" id="v22" data-v="22" data-xref="ヨハネの黙示録 19:9; ルツ記 4:10–13; 士師記 14:10–18"> そこでラバンはその所の人々をみな集めて、ふるまいを設けた。</span>
<span className="v" id="v23" data-v="23" data-xref="ミカ書 7:5; 創世記 38:14–15; 創世記 24:65"> 夕暮となったとき、娘レアをヤコブのもとに連れてきたので、ヤコブは彼女の所にはいった。</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 16:1; 創世記 30:9–12; 創世記 46:18"> ラバンはまた自分のつかえめジルパを娘レアにつかえめとして与えた。</span>
<span className="v" id="v25" data-v="25" data-xref="マタイによる福音書 7:2; 箴言 11:31; コリント人への第一の手紙 3:13"> 朝になって、見ると、それはレアであったので、ヤコブはラバンに言った、「あなたはどうしてこんな事をわたしにされたのですか。わたしはラケルのために働いたのではありませんか。どうしてあなたはわたしを欺いたのですか」。</span>
<span className="v" id="v26" data-v="26"> ラバンは言った、「妹を姉より先にとつがせる事はわれわれの国ではしません。</span>
<span className="v" id="v27" data-v="27" data-xref="レビ記 18:18; 士師記 14:12; 創世記 2:2–3"> まずこの娘のために一週間を過ごしなさい。そうすればあの娘もあなたにあげよう。あなたは、そのため更に七年わたしに仕えなければならない」。</span>
<span className="v" id="v28" data-v="28"> ヤコブはそのとおりにして、その一週間が終ったので、ラバンは娘ラケルをも妻として彼に与えた。</span>
<span className="v" id="v29" data-v="29" data-xref="創世記 35:22; 創世記 29:24; 創世記 30:3–8"> ラバンはまた自分のつかえめビルハを娘ラケルにつかえめとして与えた。</span>
<span className="v" id="v30" data-v="30" data-xref="創世記 31:41; 創世記 29:20; 創世記 31:15"> ヤコブはまたラケルの所にはいった。彼はレアよりもラケルを愛して、更に七年ラバンに仕えた。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="サムエル記上 2:21; マタイによる福音書 10:37; 申命記 21:15"> 主はレアがきらわれるのを見て、その胎を開かれたが、ラケルは、みごもらなかった。</span>
<span className="v" id="v32" data-v="32" data-xref="申命記 26:7; 出エジプト記 4:31; 出エジプト記 3:7"> レアは、みごもって子を産み、名をルベンと名づけて、言った、「主がわたしの悩みを顧みられたから、今は夫もわたしを愛するだろう」。</span>
<span className="v" id="v33" data-v="33" data-xref="創世記 34:25; 創世記 49:5–6; 創世記 34:30"> 彼女はまた、みごもって子を産み、「主はわたしが嫌われるのをお聞きになって、わたしにこの子をも賜わった」と言って、名をシメオンと名づけた。</span>
<span className="v" id="v34" data-v="34" data-xref="出エジプト記 32:26–29; 創世記 49:5–7; 創世記 46:11"> 彼女はまた、みごもって子を産み、「わたしは彼に三人の子を産んだから、こんどこそは夫もわたしに親しむだろう」と言って、名をレビと名づけた。</span>
<span className="v" id="v35" data-v="35" data-xref="マタイによる福音書 1:2; 歴代志上 5:2; 創世記 49:8–12"> 彼女はまた、みごもって子を産み、「わたしは今、主をほめたたえる」と言って名をユダと名づけた。そこで彼女の、子を産むことはやんだ。</span>
</div>

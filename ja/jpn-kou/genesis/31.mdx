<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="伝道の書 4:4; 詩篇 49:16–17; ヨブ記 31:31"> さてヤコブはラバンの子らが、「ヤコブはわれわれの父の物をことごとく奪い、父の物によってあのすべての富を獲たのだ」と言っているのを聞いた。</span>
<span className="v" id="v2" data-v="2" data-xref="ダニエル書 3:19; サムエル記上 18:9–11; 創世記 4:5"> またヤコブがラバンの顔を見るのに、それは自分に対して以前のようではなかった。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 28:15; 創世記 32:9; ヘブル人への手紙 13:5"> 主はヤコブに言われた、「あなたの先祖の国へ帰り、親族のもとに行きなさい。わたしはあなたと共にいるであろう」。</span>
<span className="v" id="v4" data-v="4"> そこでヤコブは人をやって、ラケルとレアとを、野にいる自分の群れのところに招き、</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 31:2–3; 創世記 31:53; 創世記 48:15"> 彼女らに言った、「わたしがあなたがたの父の顔を見るのに、わたしに対して以前のようではない。しかし、わたしの父の神はわたしと共におられる。</span>
<span className="v" id="v6" data-v="6" data-xref="創世記 30:29; エペソ人への手紙 6:5–8; テトスヘの手紙 2:9–10"> あなたがたが知っているように、わたしは力のかぎり、あなたがたの父に仕えてきた。</span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 37:28; 創世記 31:29; 民数記 14:22"> しかし、あなたがたの父はわたしを欺いて、十度もわたしの報酬を変えた。けれども神は彼がわたしに害を加えることをお許しにならなかった。</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 30:32"> もし彼が、『ぶちのものはあなたの報酬だ』と言えば、群れは皆ぶちのものを産んだ。もし彼が、『しまのあるものはあなたの報酬だ』と言えば、群れは皆しまのあるものを産んだ。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 31:1; 創世記 31:16; 箴言 13:22"> こうして神はあなたがたの父の家畜をとってわたしに与えられた。</span>
<span className="v" id="v10" data-v="10" data-xref="申命記 13:1; 創世記 30:39; 創世記 20:6"> また群れが発情した時、わたしが夢に目をあげて見ると、群れの上に乗っている雄やぎは皆しまのあるもの、ぶちのもの、霜ふりのものであった。</span>
<span className="v" id="v11" data-v="11" data-xref="イザヤ書 58:9; 創世記 31:13; サムエル記上 3:6"> その時、神の使が夢の中でわたしに言った、『ヤコブよ』。わたしは答えた、『ここにおります』。</span>
<span className="v" id="v12" data-v="12" data-xref="出エジプト記 3:7; 申命記 24:15; 創世記 31:42"> 神の使は言った、『目を上げて見てごらん。群れの上に乗っている雄やぎは皆しまのあるもの、ぶちのもの、霜ふりのものです。わたしはラバンがあなたにしたことをみな見ています。</span>
<span className="v" id="v13" data-v="13" data-xref="創世記 31:3; 創世記 32:9; 創世記 28:12–22"> わたしはベテルの神です。かつてあなたはあそこで柱に油を注いで、わたしに誓いを立てましたが、いま立ってこの地を出て、あなたの生れた国へ帰りなさい』」。</span>
<span className="v" id="v14" data-v="14" data-xref="ルツ記 4:11; 創世記 2:24; 創世記 29:24"> ラケルとレアは答えて言った、「わたしたちの父の家に、なおわたしたちの受くべき分、また嗣業がありましょうか。</span>
<span className="v" id="v15" data-v="15" data-xref="創世記 29:15–20; 創世記 31:41; 創世記 29:27–30"> わたしたちは父に他人のように思われているではありませんか。彼はわたしたちを売ったばかりでなく、わたしたちのその金をさえ使い果たしたのです。</span>
<span className="v" id="v16" data-v="16" data-xref="創世記 30:35–1; 創世記 31:9; 詩篇 45:10"> 神がわたしたちの父から取りあげられた富は、みなわたしたちとわたしたちの子どものものです。だから何事でも神があなたにお告げになった事をしてください」。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="サムエル記上 30:17; 創世記 24:61; 創世記 24:10"> そこでヤコブは立って、子らと妻たちをらくだに乗せ、</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 27:1–2; 創世記 27:41; 創世記 35:27–29"> またすべての家畜、すなわち彼がパダンアラムで獲た家畜と、すべての財産を携えて、カナンの地におる父イサクのもとへ赴いた。</span>
<span className="v" id="v19" data-v="19" data-xref="サムエル記上 19:13; 創世記 31:30; ホセア書 3:4"> その時ラバンは羊の毛を切るために出ていたので、ラケルは父の所有のテラピムを盗み出した。</span>
<span className="v" id="v20" data-v="20"> またヤコブはアラムびとラバンを欺き、自分の逃げ去るのを彼に告げなかった。</span>
<span className="v" id="v21" data-v="21" data-xref="列王紀下 12:17; 創世記 37:25; 創世記 46:28"> こうして彼はすべての持ち物を携えて逃げ、立って川を渡り、ギレアデの山地へ向かった。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="ヨブ記 5:12–13; 創世記 30:36; 出エジプト記 14:5–31"> 三日目になって、ヤコブの逃げ去ったことが、ラバンに聞えたので、</span>
<span className="v" id="v23" data-v="23" data-xref="創世記 13:8; 創世記 24:27; 出エジプト記 2:11"> 彼は一族を率いて、七日の間そのあとを追い、ギレアデの山地で追いついた。</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 24:50; 創世記 31:29; 創世記 20:3"> しかし、神は夜の夢にアラムびとラバンに現れて言われた、「あなたは心してヤコブに、よしあしを言ってはなりません」。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="創世記 12:8; 創世記 33:18; ヘブル人への手紙 11:9"> ラバンはついにヤコブに追いついたが、ヤコブが山に天幕を張っていたので、ラバンも一族と共にギレアデの山に天幕を張った。</span>
<span className="v" id="v26" data-v="26" data-xref="サムエル記上 30:2; 創世記 12:18; 創世記 20:9–10"> ラバンはヤコブに言った、「あなたはなんという事をしたのですか。あなたはわたしを欺いてわたしの娘たちをいくさのとりこのように引いて行きました。</span>
<span className="v" id="v27" data-v="27" data-xref="出エジプト記 15:20; 箴言 26:23–26; 創世記 31:3–5"> なぜあなたはわたしに告げずに、ひそかに逃げ去ってわたしを欺いたのですか。わたしは手鼓や琴で喜び歌ってあなたを送りだそうとしていたのに。</span>
<span className="v" id="v28" data-v="28" data-xref="創世記 31:55; ルツ記 1:14; 使徒行伝 20:37"> なぜわたしの孫や娘にわたしが口づけするのを許さなかったのですか。あなたは愚かな事をしました。</span>
<span className="v" id="v29" data-v="29" data-xref="創世記 31:53; 創世記 31:42; 創世記 31:24"> わたしはあなたがたに害を加える力をもっているが、あなたがたの父の神が昨夜わたしに告げて、『おまえは心して、ヤコブによしあしを言うな』と言われました。</span>
<span className="v" id="v30" data-v="30" data-xref="エレミヤ書 10:11; 創世記 31:19; 士師記 18:24"> 今あなたが逃げ出したのは父の家が非常に恋しくなったからでしょうが、なぜあなたはわたしの神を盗んだのですか」。</span>
<span className="v" id="v31" data-v="31" data-xref="箴言 29:25; 創世記 31:26–27; 創世記 20:11"> ヤコブはラバンに答えた、「たぶんあなたが娘たちをわたしから奪いとるだろうと思ってわたしは恐れたからです。</span>
<span className="v" id="v32" data-v="32" data-xref="サムエル記上 12:3–5; 創世記 31:30; 創世記 31:19"> だれの所にでもあなたの神が見つかったら、その者を生かしてはおきません。何かあなたの物がわたしのところにあるか、われわれの一族の前で、調べてみて、それをお取りください」。ラケルが神を盗んだことをヤコブは知らなかったからである。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="創世記 24:67; 創世記 24:28"> そこでラバンはヤコブの天幕にはいり、またレアの天幕にはいり、更にふたりのはしための天幕にはいってみたが、見つからなかったので、レアの天幕を出てラケルの天幕にはいった。</span>
<span className="v" id="v34" data-v="34" data-xref="創世記 31:19; 創世記 31:17"> しかし、ラケルはすでにテラピムを取って、らくだのくらの下に入れ、その上にすわっていたので、ラバンは、くまなく天幕の中を捜したが、見つからなかった。</span>
<span className="v" id="v35" data-v="35" data-xref="レビ記 19:32; 出エジプト記 20:12; ペテロの第一の手紙 2:18"> その時ラケルは父に言った、「わたしは女の常のことがあって、あなたの前に立ち上がることができません。わが主よ、どうかお怒りにならぬよう」。彼は捜したがテラピムは見つからなかった。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="エペソ人への手紙 4:26; 創世記 49:7; 民数記 16:15"> そこでヤコブは怒ってラバンを責めた。そしてヤコブはラバンに言った、「わたしにどんなあやまちがあり、どんな罪があって、あなたはわたしのあとを激しく追ったのですか。</span>
<span className="v" id="v37" data-v="37" data-xref="ペテロの第一の手紙 2:12; コリント人への第一の手紙 6:4–5; サムエル記上 12:3–4"> あなたはわたしの物をことごとく探られたが、何かあなたの家の物が見つかりましたか。それを、ここに、わたしの一族と、あなたの一族の前に置いて、われわれふたりの間をさばかせましょう。</span>
<span className="v" id="v38" data-v="38" data-xref="創世記 30:27; 申命記 28:4; エゼキエル書 34:2–4"> わたしはこの二十年、あなたと一緒にいましたが、その間あなたの雌羊も雌やぎも子を産みそこねたことはなく、またわたしはあなたの群れの雄羊を食べたこともありませんでした。</span>
<span className="v" id="v39" data-v="39" data-xref="出エジプト記 22:31; 出エジプト記 22:10–13; レビ記 22:8"> また野獣が、かみ裂いたものは、あなたのもとに持ってこないで、自分でそれを償いました。また昼盗まれたものも、夜盗まれたものも、あなたはわたしにその償いを求められました。</span>
<span className="v" id="v40" data-v="40" data-xref="ルカによる福音書 2:8; 出エジプト記 2:19–22; ペテロの第一の手紙 5:2–4"> わたしのことを言えば、昼は暑さに、夜は寒さに悩まされて、眠ることもできませんでした。</span>
<span className="v" id="v41" data-v="41" data-xref="創世記 31:7; コリント人への第一の手紙 15:10; コリント人への第二の手紙 11:26"> わたしはこの二十年あなたの家族のひとりでありました。わたしはあなたのふたりの娘のために十四年、またあなたの群れのために六年、あなたに仕えましたが、あなたは十度もわたしの報酬を変えられました。</span>
<span className="v" id="v42" data-v="42" data-xref="詩篇 31:7; 創世記 31:53; イザヤ書 8:13"> もし、わたしの父の神、アブラハムの神、イサクのかしこむ者がわたしと共におられなかったなら、あなたはきっとわたしを、から手で去らせたでしょう。神はわたしの悩みと、わたしの労苦とを顧みられて昨夜あなたを戒められたのです」。</span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43"> ラバンは答えてヤコブに言った、「娘たちはわたしの娘、子どもたちはわたしの孫です。また群れはわたしの群れ、あなたの見るものはみなわたしのものです。これらのわたしの娘たちのため、また彼らが産んだ子どもたちのため、きょうわたしは何をすることができましょうか。</span>
<span className="v" id="v44" data-v="44" data-xref="創世記 31:52; ヨシュア記 24:25–27; ヨシュア記 22:27"> さあ、それではわたしとあなたと契約を結んで、これをわたしとあなたとの間の証拠としましょう」。</span>
<span className="v" id="v45" data-v="45" data-xref="創世記 28:18–22"> そこでヤコブは石を取り、それを立てて柱とした。</span>
<span className="v" id="v46" data-v="46" data-xref="伝道の書 3:5; 創世記 31:23; 創世記 31:54"> ヤコブはまた一族の者に言った、「石を集めてください」。彼らは石を取って、一つの石塚を造った。こうして彼らはその石塚のかたわらで食事をした。</span>
<span className="v" id="v47" data-v="47" data-xref="ヘブル人への手紙 12:1"> ラバンはこれをエガル・サハドタと名づけ、ヤコブはこれをガルエドと名づけた。</span>
<span className="v" id="v48" data-v="48" data-xref="ヨシュア記 24:27; ヨシュア記 13:8–9; 創世記 31:23"> そしてラバンは言った、「この石塚はきょうわたしとあなたとの間の証拠となります」。それでその名はガルエドと呼ばれた。</span>
<span className="v" id="v49" data-v="49" data-xref="士師記 11:29; 士師記 10:17; サムエル記上 7:5–6"> またミズパとも呼ばれた。彼がこう言ったからである、「われわれが互に別れたのちも、どうか主がわたしとあなたとの間を見守られるように。</span>
<span className="v" id="v50" data-v="50" data-xref="エレミヤ書 42:5; エレミヤ書 29:23; ミカ書 1:2"> もしあなたがわたしの娘を虐待したり、わたしの娘のほかに妻をめとることがあれば、たといそこにだれひとりいなくても、神はわたしとあなたとの間の証人でいらせられる」。</span>
</div>
<div className="bp">
<span className="v" id="v51" data-v="51"> 更にラバンはヤコブに言った、「あなたとわたしとの間にわたしが建てたこの石塚をごらんなさい、この柱をごらんなさい。</span>
<span className="v" id="v52" data-v="52" data-xref="創世記 31:48; 創世記 31:44–45"> この石塚を越えてわたしがあなたに害を加えず、またこの石塚とこの柱を越えてあなたがわたしに害を加えないように、どうかこの石塚があかしとなり、この柱があかしとなるように。</span>
<span className="v" id="v53" data-v="53" data-xref="創世記 31:42; 創世記 16:5; ヨシュア記 24:2"> どうかアブラハムの神、ナホルの神、彼らの父の神がわれわれの間をさばかれるように」。ヤコブは父イサクのかしこむ者によって誓った。</span>
<span className="v" id="v54" data-v="54" data-xref="出エジプト記 18:12; 創世記 37:25; 創世記 26:30"> そしてヤコブは山で犠牲をささげ、一族を招いて、食事をした。彼らは食事をして山に宿った。</span>
</div>
<div className="bp">
<span className="v" id="v55" data-v="55" data-xref="創世記 31:28; 申命記 23:5; 創世記 18:33"> あくる朝ラバンは早く起き、孫と娘たちに口づけして彼らを祝福し、去って家に帰った。</span>
</div>

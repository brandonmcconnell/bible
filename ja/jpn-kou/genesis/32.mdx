<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="詩篇 91:11; 詩篇 34:7; ヘブル人への手紙 1:4"> さて、ヤコブが旅路に進んだとき、神の使たちが彼に会った。</span>
<span className="v" id="v2" data-v="2" data-xref="サムエル記下 2:8; ヨシュア記 5:14; ヨシュア記 21:38"> ヤコブは彼らを見て、「これは神の陣営です」と言って、その所の名をマハナイムと名づけた。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="創世記 25:30; ヨシュア記 24:4; 申命記 2:5"> ヤコブはセイルの地、エドムの野に住む兄エサウのもとに、さきだって使者をつかわした。</span>
<span className="v" id="v4" data-v="4" data-xref="ペテロの第一の手紙 3:6; ルカによる福音書 14:11; 創世記 33:8"> すなわちそれに命じて言った、「あなたがたはわたしの主人エサウにこう言いなさい、『あなたのしもべヤコブはこう言いました。わたしはラバンのもとに寄留して今までとどまりました。</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 33:8; 創世記 33:15; 創世記 33:11"> わたしは牛、ろば、羊、男女の奴隷を持っています。それでわが主に申し上げて、あなたの前に恵みを得ようと人をつかわしたのです』」。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="創世記 33:1; 創世記 32:8; 創世記 32:11"> 使者はヤコブのもとに帰って言った、「わたしたちはあなたの兄エサウのもとへ行きました。彼もまたあなたを迎えようと四百人を率いてきます」。</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 35:3; コリント人への第二の手紙 1:8–10; 出エジプト記 14:10"> そこでヤコブは大いに恐れ、苦しみ、共にいる民および羊、牛、らくだを二つの組に分けて、</span>
<span className="v" id="v8" data-v="8" data-xref="マタイによる福音書 10:16; 創世記 33:1–3"> 言った、「たとい、エサウがきて、一つの組を撃っても、残りの組はのがれるであろう」。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="創世記 31:42; 詩篇 34:4–6; 創世記 31:3"> ヤコブはまた言った、「父アブラハムの神、父イサクの神よ、かつてわたしに『おまえの国へ帰り、おまえの親族に行け。わたしはおまえを恵もう』と言われた主よ、</span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 18:35; 創世記 24:27; サムエル記下 7:18"> あなたがしもべに施されたすべての恵みとまことをわたしは受けるに足りない者です。わたしは、つえのほか何も持たないでこのヨルダンを渡りましたが、今は二つの組にもなりました。</span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 59:1–2; 箴言 18:19; マタイによる福音書 6:13"> どうぞ、兄エサウの手からわたしをお救いください。わたしは彼がきて、わたしを撃ち、母や子供たちにまで及ぶのを恐れます。</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 28:13–15; ヘブル人への手紙 6:17; テトスヘの手紙 1:2"> あなたは、かつて、『わたしは必ずおまえを恵み、おまえの子孫を海の砂の数えがたいほど多くしよう』と言われました」。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="箴言 18:16; 創世記 43:11; 箴言 19:6"> 彼はその夜そこに宿り、持ち物のうちから兄エサウへの贈り物を選んだ。</span>
<span className="v" id="v14" data-v="14" data-xref="ヨブ記 1:3; 申命記 8:18; ヨブ記 42:12"> すなわち雌やぎ二百、雄やぎ二十、雌羊二百、雄羊二十、</span>
<span className="v" id="v15" data-v="15"> 乳らくだ三十とその子、雌牛四十、雄牛十、雌ろば二十、雄ろば十。</span>
<span className="v" id="v16" data-v="16" data-xref="創世記 33:8–9; 創世記 32:20; 箴言 2:11"> 彼はこれらをそれぞれの群れに分けて、しもべたちの手にわたし、しもべたちに言った、「あなたがたはわたしの先に進みなさい、そして群れと群れとの間には隔たりをおきなさい」。</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 33:3"> また先頭の者に命じて言った、「もし、兄エサウがあなたに会って『だれのしもべで、どこへ行くのか。あなたの前にあるこれらのものはだれの物か』と尋ねたら、</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 32:4–5"> 『あなたのしもべヤコブの物で、わが主エサウにおくる贈り物です。彼もわたしたちのうしろにおります』と言いなさい」。</span>
<span className="v" id="v19" data-v="19"> 彼は第二の者にも、第三の者にも、また群れ群れについて行くすべての者にも命じて言った、「あなたがたがエサウに会うときは、同じように彼に告げて、</span>
<span className="v" id="v20" data-v="20" data-xref="ヨブ記 42:8–9; 箴言 21:14; 創世記 43:11"> 『あなたのしもべヤコブもわれわれのうしろにおります』と言いなさい」。ヤコブは、「わたしがさきに送る贈り物をもってまず彼をなだめ、それから、彼の顔を見よう。そうすれば、彼はわたしを迎えてくれるであろう」と思ったからである。</span>
<span className="v" id="v21" data-v="21"> こうして贈り物は彼に先立って渡り、彼はその夜、宿営にやどった。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="申命記 3:16; 申命記 2:37; テモテヘの第一の手紙 5:8"> 彼はその夜起きて、ふたりの妻とふたりのつかえめと十一人の子どもとを連れてヤボクの渡しをわたった。</span>
<span className="v" id="v23" data-v="23"> すなわち彼らを導いて川を渡らせ、また彼の持ち物を渡らせた。</span>
<span className="v" id="v24" data-v="24" data-xref="ホセア書 12:3–5; エペソ人への手紙 6:12; ルカによる福音書 13:24"> ヤコブはひとりあとに残ったが、ひとりの人が、夜明けまで彼と組打ちした。</span>
<span className="v" id="v25" data-v="25" data-xref="コリント人への第二の手紙 12:7–9; ホセア書 12:3–4; マタイによる福音書 26:41"> ところでその人はヤコブに勝てないのを見て、ヤコブのもものつがいにさわったので、ヤコブのもものつがいが、その人と組打ちするあいだにはずれた。</span>
<span className="v" id="v26" data-v="26" data-xref="ホセア書 12:4; 詩篇 115:12–13; コリント人への第二の手紙 12:8–9"> その人は言った、「夜が明けるからわたしを去らせてください」。ヤコブは答えた、「わたしを祝福してくださらないなら、あなたを去らせません」。</span>
<span className="v" id="v27" data-v="27"> その人は彼に言った、「あなたの名はなんと言いますか」。彼は答えた、「ヤコブです」。</span>
<span className="v" id="v28" data-v="28" data-xref="ヨハネの黙示録 2:17; 創世記 35:10; イザヤ書 62:2–4"> その人は言った、「あなたはもはや名をヤコブと言わず、イスラエルと言いなさい。あなたが神と人とに、力を争って勝ったからです」。</span>
<span className="v" id="v29" data-v="29" data-xref="イザヤ書 9:6; 士師記 13:16–18; ヨブ記 11:7"> ヤコブは尋ねて言った、「どうかわたしにあなたの名を知らせてください」。するとその人は、「なぜあなたはわたしの名をきくのですか」と言ったが、その所で彼を祝福した。</span>
<span className="v" id="v30" data-v="30" data-xref="出エジプト記 24:10–11; 民数記 12:8; イザヤ書 6:5"> そこでヤコブはその所の名をペニエルと名づけて言った、「わたしは顔と顔をあわせて神を見たが、なお生きている」。</span>
<span className="v" id="v31" data-v="31" data-xref="コリント人への第二の手紙 12:7; 創世記 19:15; 士師記 8:8"> こうして彼がペニエルを過ぎる時、日は彼の上にのぼったが、彼はそのもものゆえにびっこを引いていた。</span>
<span className="v" id="v32" data-v="32" data-xref="サムエル記上 5:5"> そのため、イスラエルの子らは今日まで、もものつがいの上にある腰の筋を食べない。かの人がヤコブのもものつがい、すなわち腰の筋にさわったからである。</span>
</div>

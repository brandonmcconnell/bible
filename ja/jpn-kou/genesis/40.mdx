<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 40:13; 創世記 39:20–23; エステル記 6:1"> これらの事の後、エジプト王の給仕役と料理役とがその主君エジプト王に罪を犯した。</span>
<span className="v" id="v2" data-v="2" data-xref="箴言 16:14; 箴言 19:12; 詩篇 76:10"> パロはふたりの役人、すなわち給仕役の長と料理役の長に向かって憤り、</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 39:20; 創世記 39:23"> 侍衛長の家の監禁所、すなわちヨセフがつながれている獄屋に入れた。</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 39:1; 詩篇 37:5; 創世記 37:36"> 侍衛長はヨセフに命じて彼らと共におらせたので、ヨセフは彼らに仕えた。こうして彼らは監禁所で幾日かを過ごした。</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 41:11; 創世記 40:8; 創世記 37:5–10"> さて獄屋につながれたエジプト王の給仕役と料理役のふたりは一夜のうちにそれぞれ意味のある夢を見た。</span>
<span className="v" id="v6" data-v="6" data-xref="創世記 41:8; ダニエル書 2:1–3; 創世記 40:8"> ヨセフが朝、彼らのところへ行って見ると、彼らは悲しみに沈んでいた。</span>
<span className="v" id="v7" data-v="7" data-xref="ネヘミヤ書 2:2; サムエル記上 1:8; ルカによる福音書 24:17"> そこでヨセフは自分と一緒に主人の家の監禁所にいるパロの役人たちに尋ねて言った、「どうして、きょう、あなたがたの顔色が悪いのですか」。</span>
<span className="v" id="v8" data-v="8" data-xref="ダニエル書 2:47; 創世記 41:15–16; ダニエル書 2:28"> 彼らは言った、「わたしたちは夢を見ましたが、解いてくれる者がいません」。ヨセフは彼らに言った、「解くことは神によるのではありませんか。どうぞ、わたしに話してください」。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="士師記 7:13–15; 創世記 37:5–10; ダニエル書 4:8"> 給仕役の長はその夢をヨセフに話して言った、「わたしが見た夢で、わたしの前に一本のぶどうの木がありました。</span>
<span className="v" id="v10" data-v="10"> そのぶどうの木に三つの枝があって、芽を出し、花が咲き、ぶどうのふさが熟しました。</span>
<span className="v" id="v11" data-v="11" data-xref="ネヘミヤ書 1:11–1; 列王紀上 10:5; 歴代志下 9:4"> 時にわたしの手に、パロの杯があって、わたしはそのぶどうを取り、それをパロの杯にしぼり、その杯をパロの手にささげました」。</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 41:12; 士師記 7:14; 創世記 41:25–26"> ヨセフは言った、「その解き明かしはこうです。三つの枝は三日です。</span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 3:3; エレミヤ書 52:31; 列王紀下 25:27"> 今から三日のうちにパロはあなたの頭を上げて、あなたを元の役目に返すでしょう。あなたはさきに給仕役だった時にされたように、パロの手に杯をささげられるでしょう。</span>
<span className="v" id="v14" data-v="14" data-xref="ヨシュア記 2:12; ルカによる福音書 23:42; サムエル記上 20:14–15"> それで、あなたがしあわせになられたら、わたしを覚えていて、どうかわたしに恵みを施し、わたしの事をパロに話して、この家からわたしを出してください。</span>
<span className="v" id="v15" data-v="15" data-xref="ペテロの第一の手紙 3:17–18; 創世記 39:20; テモテヘの第一の手紙 1:10"> わたしは、実はヘブルびとの地からさらわれてきた者です。またここでもわたしは地下の獄屋に入れられるような事はしなかったのです」。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="創世記 40:1–2"> 料理役の長はその解き明かしの良かったのを見て、ヨセフに言った、「わたしも夢を見たが、白いパンのかごが三つ、わたしの頭の上にあった。</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 49:20; 歴代志上 12:20"> 一番上のかごには料理役がパロのために作ったさまざまの食物があったが、鳥がわたしの頭の上のかごからそれを食べていた」。</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 40:12; 創世記 41:26; コリント人への第一の手紙 11:24"> ヨセフは答えて言った、「その解き明かしはこうです。三つのかごは三日です。</span>
<span className="v" id="v19" data-v="19" data-xref="創世記 40:22; 使徒行伝 20:27; サムエル記下 21:6"> 今から三日のうちにパロはあなたの頭を上げ離して、あなたを木に掛けるでしょう。そして鳥があなたの肉を食い取るでしょう」。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="創世記 40:19; 創世記 40:13; マタイによる福音書 14:6"> さて三日目はパロの誕生日であったので、パロはすべての家来のためにふるまいを設け、家来のうちの給仕役の長の頭と、料理役の長の頭を上げた。</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 40:13; ネヘミヤ書 2:1"> すなわちパロは給仕役の長を給仕役の職に返したので、彼はパロの手に杯をささげた。</span>
<span className="v" id="v22" data-v="22" data-xref="創世記 40:19; 創世記 41:16; ダニエル書 2:30"> しかしパロは料理役の長を木に掛けた。ヨセフが彼らに解き明かしたとおりである。</span>
<span className="v" id="v23" data-v="23" data-xref="詩篇 31:12; ヨブ記 19:14; 詩篇 105:19"> ところが、給仕役の長はヨセフを思い出さず、忘れてしまった。</span>
</div>

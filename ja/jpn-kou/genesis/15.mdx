<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="イザヤ書 41:10; 詩篇 119:114; 詩篇 84:11"> これらの事の後、主の言葉が幻のうちにアブラムに臨んだ、<br /><span className="pl pl-1">「アブラムよ恐れてはならない、</span><br /><span className="pl pl-1">わたしはあなたの盾である。</span><br /><span className="pl pl-1">あなたの受ける報いは、</span><br /><span className="pl pl-1">はなはだ大きいであろう」。</span></span>
<span className="v" id="v2" data-v="2" data-xref="創世記 25:21; 使徒行伝 7:5; 創世記 12:1–3"> <span className="pl pl-1">アブラムは言った、「主なる神よ、わたしには子がなく、わたしの家を継ぐ者はダマスコのエリエゼルであるのに、あなたはわたしに何をくださろうとするのですか」。</span></span>
<span className="v" id="v3" data-v="3" data-xref="創世記 14:14; 箴言 29:21; 伝道の書 2:7"> <span className="pl pl-1">アブラムはまた言った、「あなたはわたしに子を賜わらないので、わたしの家に生れたしもべが、あとつぎとなるでしょう」。</span></span>
<span className="v" id="v4" data-v="4" data-xref="創世記 17:16; ガラテヤ人への手紙 4:28; サムエル記下 7:12"> <span className="pl pl-1">この時、主の言葉が彼に臨んだ、「この者はあなたのあとつぎとなるべきではありません。あなたの身から出る者があとつぎとなるべきです」。</span></span>
<span className="v" id="v5" data-v="5" data-xref="ヘブル人への手紙 11:12; ローマ人への手紙 4:18; 申命記 1:10"> <span className="pl pl-1">そして主は彼を外に連れ出して言われた、「天を仰いで、星を数えることができるなら、数えてみなさい」。また彼に言われた、「あなたの子孫はあのようになるでしょう」。</span></span>
<span className="v" id="v6" data-v="6" data-xref="ヤコブの手紙 2:23; ガラテヤ人への手紙 3:6–14; ローマ人への手紙 4:9"> <span className="pl pl-1">アブラムは主を信じた。主はこれを彼の義と認められた。</span></span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="創世記 12:1; 使徒行伝 7:2–4; ローマ人への手紙 4:13"> また主は彼に言われた、「わたしはこの地をあなたに与えて、これを継がせようと、あなたをカルデヤのウルから導き出した主です」。</span>
<span className="v" id="v8" data-v="8" data-xref="ルカによる福音書 1:18; ルカによる福音書 1:34; イザヤ書 7:11"> 彼は言った、「主なる神よ、わたしがこれを継ぐのをどうして知ることができますか」。</span>
<span className="v" id="v9" data-v="9" data-xref="ルカによる福音書 2:24; レビ記 14:30; レビ記 14:22"> 主は彼に言われた、「三歳の雌牛と、三歳の雌やぎと、三歳の雄羊と、山ばとと、家ばとのひなとをわたしの所に連れてきなさい」。</span>
<span className="v" id="v10" data-v="10" data-xref="エレミヤ書 34:18–19; レビ記 1:17; 創世記 15:17"> 彼はこれらをみな連れてきて、二つに裂き、裂いたものを互に向かい合わせて置いた。ただし、鳥は裂かなかった。</span>
<span className="v" id="v11" data-v="11" data-xref="マタイによる福音書 13:4; 詩篇 119:13; エゼキエル書 17:3"> 荒い鳥が死体の上に降りるとき、アブラムはこれを追い払った。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="創世記 2:21; ヨブ記 33:15; ダニエル書 10:8–9"> 日の入るころ、アブラムが深い眠りにおそわれた時、大きな恐ろしい暗やみが彼に臨んだ。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行伝 7:6–7; 出エジプト記 1:11; 出エジプト記 12:40–41"> 時に主はアブラムに言われた、「あなたはよく心にとめておきなさい。あなたの子孫は他の国に旅びととなって、その人々に仕え、その人々は彼らを四百年の間、悩ますでしょう。</span>
<span className="v" id="v14" data-v="14" data-xref="ネヘミヤ書 9:9–11; 出エジプト記 6:5–6; 出エジプト記 12:32–38"> しかし、わたしは彼らが仕えたその国民をさばきます。その後かれらは多くの財産を携えて出て来るでしょう。</span>
<span className="v" id="v15" data-v="15" data-xref="ヨブ記 5:26; 創世記 25:7–9; 歴代志下 34:28"> あなたは安らかに先祖のもとに行きます。そして高齢に達して葬られるでしょう。</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀上 21:26; ダニエル書 8:23; 出エジプト記 12:40"> 四代目になって彼らはここに帰って来るでしょう。アモリびとの悪がまだ満ちないからです」。</span>
</div>
<div className="bp poetry">
<span className="v" id="v17" data-v="17" data-xref="エレミヤ書 34:18–19; 士師記 6:21; エレミヤ書 11:4"> やがて日は入り、暗やみになった時、煙の立つかまど、炎の出るたいまつが、裂いたものの間を通り過ぎた。</span>
<span className="v" id="v18" data-v="18" data-xref="ヨシュア記 1:3–4; 創世記 12:7; 創世記 24:7"> その日、主はアブラムと契約を結んで言われた、<br /><span className="pl pl-1">「わたしはこの地をあなたの子孫に与える。</span><br /><span className="pl pl-1">エジプトの川から、かの大川ユフラテまで。</span></span>
<span className="v" id="v19" data-v="19" data-xref="民数記 24:21–22"> <span className="pl pl-1">すなわちケニびと、ケニジびと、カドモニびと、</span></span>
<span className="v" id="v20" data-v="20" data-xref="イザヤ書 17:5; 創世記 14:5"> <span className="pl pl-1">ヘテびと、ペリジびと、レパイムびと、</span></span>
<span className="v" id="v21" data-v="21" data-xref="創世記 10:15–19; 出エジプト記 23:23–28; 申命記 7:1"> <span className="pl pl-1">アモリびと、カナンびと、ギルガシびと、エブスびとの地を与える」。</span></span>

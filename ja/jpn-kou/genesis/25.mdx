<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歴代志上 1:32–33; 創世記 23:1–2; 創世記 28:1"> アブラハムは再び妻をめとった。名をケトラという。</span>
<span className="v" id="v2" data-v="2" data-xref="歴代志上 1:32–33; 民数記 25:17–18; ヨブ記 2:11"> 彼女はジムラン、ヨクシャン、メダン、ミデアン、イシバクおよびシュワを産んだ。</span>
<span className="v" id="v3" data-v="3" data-xref="エゼキエル書 25:13; エレミヤ書 49:8; エゼキエル書 27:20"> ヨクシャンの子はシバとデダン。デダンの子孫はアシュリびと、レトシびと、レウミびとである。</span>
<span className="v" id="v4" data-v="4" data-xref="イザヤ書 60:6"> ミデアンの子孫はエパ、エペル、ヘノク、アビダ、エルダアであって、これらは皆ケトラの子孫であった。</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 24:36; ヘブル人への手紙 1:2; ガラテヤ人への手紙 3:29"> アブラハムはその所有をことごとくイサクに与えた。</span>
<span className="v" id="v6" data-v="6" data-xref="創世記 21:14; 士師記 6:3; 使徒行伝 14:17"> またそのそばめたちの子らにもアブラハムは物を与え、なお生きている間に彼らをその子イサクから離して、東の方、東の国に移らせた。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="創世記 12:4"> アブラハムの生きながらえた年は百七十五年である。</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 35:28–29; 創世記 15:15; 歴代志上 29:28"> アブラハムは高齢に達し、老人となり、年が満ちて息絶え、死んでその民に加えられた。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 50:13; 創世記 35:29; 創世記 49:29–30"> その子イサクとイシマエルは彼をヘテびとゾハルの子エフロンの畑にあるマクペラのほら穴に葬った。これはマムレの向かいにあり、</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 23:16; 創世記 49:31"> アブラハムがヘテの人々から、買い取った畑であって、そこにアブラハムとその妻サラが葬られた。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 22:17; 創世記 16:14; 創世記 24:62"> アブラハムが死んだ後、神はその子イサクを祝福された。イサクはベエル・ラハイ・ロイのほとりに住んだ。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="詩篇 83:6; 創世記 17:20; 創世記 21:13"> サラのつかえめエジプトびとハガルがアブラハムに産んだアブラハムの子イシマエルの系図は次のとおりである。</span>
<span className="v" id="v13" data-v="13" data-xref="歴代志上 1:29–31; イザヤ書 60:7; 雅歌 1:5"> イシマエルの子らの名を世代にしたがって、その名をいえば次のとおりである。すなわちイシマエルの長子はネバヨテ、次はケダル、アデビエル、ミブサム、</span>
<span className="v" id="v14" data-v="14" data-xref="イザヤ書 21:11; イザヤ書 21:16"> ミシマ、ドマ、マッサ、</span>
<span className="v" id="v15" data-v="15" data-xref="歴代志上 5:19; ヨブ記 2:11"> ハダデ、テマ、エトル、ネフシ、ケデマ。</span>
<span className="v" id="v16" data-v="16" data-xref="創世記 17:20; 創世記 17:23"> これはイシマエルの子らであり、村と宿営とによる名であって、その氏族による十二人の君たちである。</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 15:15; 創世記 25:7–8"> イシマエルのよわいは百三十七年である。彼は息絶えて死に、その民に加えられた。</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 16:12; 創世記 20:1; 列王紀下 23:29"> イシマエルの子らはハビラからエジプトの東、シュルまでの間に住んで、アシュルに及んだ。イシマエルはすべての兄弟の東に住んだ。</span>
</div>
<div className="bp poetry">
<span className="v" id="v19" data-v="19" data-xref="マタイによる福音書 1:2; ルカによる福音書 3:34; 使徒行伝 7:8"> アブラハムの子イサクの系図は次のとおりである。アブラハムの子はイサクであって、</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 24:29; 創世記 24:67; 創世記 22:23"> イサクは四十歳の時、パダンアラムのアラムびとベトエルの娘で、アラムびとラバンの妹リベカを妻にめとった。</span>
<span className="v" id="v21" data-v="21" data-xref="ルカによる福音書 1:13; イザヤ書 58:9; エズラ記 8:23"> イサクは妻が子を産まなかったので、妻のために主に祈り願った。主はその願いを聞かれ、妻リベカはみごもった。</span>
<span className="v" id="v22" data-v="22" data-xref="サムエル記上 9:9; サムエル記上 28:6; サムエル記上 30:8"> ところがその子らが胎内で押し合ったので、リベカは言った、「こんなことでは、わたしはどうなるでしょう」。彼女は行って主に尋ねた。</span>
<span className="v" id="v23" data-v="23" data-xref="ローマ人への手紙 9:10–13; 創世記 27:40; 創世記 27:29"> 主は彼女に言われた、<br /><span className="pl pl-1">「二つの国民があなたの胎内にあり、</span><br /><span className="pl pl-1">二つの民があなたの腹から別れて出る。</span><br /><span className="pl pl-1">一つの民は他の民よりも強く、</span><br /><span className="pl pl-1">兄は弟に仕えるであろう」。</span></span>
<span className="v" id="v24" data-v="24"> <span className="pl pl-1">彼女の出産の日がきたとき、胎内にはふたごがあった。</span></span>
<span className="v" id="v25" data-v="25" data-xref="創世記 27:11; 創世記 27:16; 創世記 27:23"> <span className="pl pl-1">さきに出たのは赤くて全身毛ごろものようであった。それで名をエサウと名づけた。</span></span>
<span className="v" id="v26" data-v="26" data-xref="創世記 27:36; ホセア書 12:3; 創世記 38:28–30"> <span className="pl pl-1">その後に弟が出た。その手はエサウのかかとをつかんでいた。それで名をヤコブと名づけた。リベカが彼らを産んだ時、イサクは六十歳であった。</span></span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="ヘブル人への手紙 11:9; 創世記 21:20; 創世記 10:9"> さてその子らは成長し、エサウは巧みな狩猟者となり、野の人となったが、ヤコブは穏やかな人で、天幕に住んでいた。</span>
<span className="v" id="v28" data-v="28" data-xref="創世記 27:19; 創世記 27:31; 創世記 27:4"> イサクは、しかの肉が好きだったので、エサウを愛したが、リベカはヤコブを愛した。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="箴言 13:25; イザヤ書 40:30–31; サムエル記上 14:28"> ある日ヤコブが、あつものを煮ていた時、エサウは飢え疲れて野から帰ってきた。</span>
<span className="v" id="v30" data-v="30" data-xref="創世記 36:1; 出エジプト記 15:15; 創世記 36:9"> エサウはヤコブに言った、「わたしは飢え疲れた。お願いだ。赤いもの、その赤いものをわたしに食べさせてくれ」。彼が名をエドムと呼ばれたのはこのためである。</span>
<span className="v" id="v31" data-v="31"> ヤコブは言った、「まずあなたの長子の特権をわたしに売りなさい」。</span>
<span className="v" id="v32" data-v="32" data-xref="マラキ書 3:14; ヨブ記 21:15; ヨブ記 22:17"> エサウは言った、「わたしは死にそうだ。長子の特権などわたしに何になろう」。</span>
<span className="v" id="v33" data-v="33" data-xref="ヘブル人への手紙 12:16; 創世記 27:36; ヘブル人への手紙 6:16"> ヤコブはまた言った、「まずわたしに誓いなさい」。彼は誓って長子の特権をヤコブに売った。</span>
<span className="v" id="v34" data-v="34" data-xref="ピリピ人への手紙 3:18–19; ヘブル人への手紙 12:16–17; コリント人への第一の手紙 15:32"> そこでヤコブはパンとレンズ豆のあつものとをエサウに与えたので、彼は飲み食いして、立ち去った。このようにしてエサウは長子の特権を軽んじた。</span>
</div>

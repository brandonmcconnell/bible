<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="詩篇 112:1–3; ガラテヤ人への手紙 3:9; マタイによる福音書 6:33"> アブラハムは年が進んで老人となった。主はすべての事にアブラハムを恵まれた。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 47:29; 創世記 39:4–6; 創世記 15:2"> さてアブラハムは所有のすべてを管理させていた家の年長のしもべに言った、「あなたの手をわたしのももの下に入れなさい。</span>
<span className="v" id="v3" data-v="3" data-xref="コリント人への第二の手紙 6:14–17; 創世記 26:34–35; 創世記 28:8"> わたしはあなたに天地の神、主をさして誓わせる。あなたはわたしが今一緒に住んでいるカナンびとのうちから、娘をわたしの子の妻にめとってはならない。</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 28:2; 創世記 22:20–23; 創世記 12:7"> あなたはわたしの国へ行き、親族の所へ行って、わたしの子イサクのために妻をめとらなければならない」。</span>
<span className="v" id="v5" data-v="5" data-xref="エレミヤ書 4:2; 出エジプト記 9:2; 出エジプト記 20:7"> しもべは彼に言った、「もしその女がわたしについてこの地に来ることを好まない時は、わたしはあなたの子をあなたの出身地に連れ帰るべきでしょうか」。</span>
<span className="v" id="v6" data-v="6" data-xref="ガラテヤ人への手紙 5:1; ペテロの第二の手紙 2:20–22; ヘブル人への手紙 10:39"> アブラハムは彼に言った、「わたしの子は決して向こうへ連れ帰ってはならない。</span>
<span className="v" id="v7" data-v="7" data-xref="出エジプト記 33:2; 創世記 13:15; ヘブル人への手紙 1:14"> 天の神、主はわたしを父の家、親族の地から導き出してわたしに語り、わたしに誓って、おまえの子孫にこの地を与えると言われた。主は、み使をあなたの前につかわされるであろう。あなたはあそこからわたしの子に妻をめとらねばならない。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨシュア記 2:17–20; 民数記 30:5; 民数記 30:8"> けれどもその女があなたについて来ることを好まないなら、あなたはこの誓いを解かれる。ただわたしの子を向こうへ連れ帰ってはならない」。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 24:2"> そこでしもべは手を主人アブラハムのももの下に入れ、この事について彼に誓った。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="創世記 11:31; 申命記 23:4; 創世記 27:43"> しもべは主人のらくだのうちから十頭のらくだを取って出かけた。すなわち主人のさまざまの良い物を携え、立ってアラム・ナハライムにむかい、ナホルの町へ行った。</span>
<span className="v" id="v11" data-v="11" data-xref="サムエル記上 9:11; 出エジプト記 2:16; ヨハネによる福音書 4:7"> 彼はらくだを町の外の、水の井戸のそばに伏させた。時は夕暮で、女たちが水をくみに出る時刻であった。</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 24:27; 出エジプト記 3:6; 創世記 26:24"> 彼は言った、「主人アブラハムの神、主よ、どうか、きょう、わたしにしあわせを授け、主人アブラハムに恵みを施してください。</span>
<span className="v" id="v13" data-v="13" data-xref="創世記 24:43; 詩篇 37:5; 出エジプト記 2:16"> わたしは泉のそばに立っています。町の人々の娘たちが水をくみに出てきたとき、</span>
<span className="v" id="v14" data-v="14" data-xref="士師記 6:37; 士師記 6:17; 創世記 15:8"> 娘に向かって『お願いです、あなたの水がめを傾けてわたしに飲ませてください』と言い、娘が答えて、『お飲みください。あなたのらくだにも飲ませましょう』と言ったなら、その者こそ、あなたがしもべイサクのために定められた者ということにしてください。わたしはこれによって、あなたがわたしの主人に恵みを施されることを知りましょう」。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="創世記 11:29; 創世記 24:45; イザヤ書 65:24"> 彼がまだ言い終らないうちに、アブラハムの兄弟ナホルの妻ミルカの子ベトエルの娘リベカが、水がめを肩に載せて出てきた。</span>
<span className="v" id="v16" data-v="16" data-xref="創世記 26:7; 民数記 31:17–18; 創世記 39:6"> その娘は非常に美しく、男を知らぬ処女であった。彼女が泉に降りて、水がめを満たし、上がってきた時、</span>
<span className="v" id="v17" data-v="17" data-xref="ヨハネによる福音書 4:7; イザヤ書 21:14; 創世記 26:1–35"> しもべは走り寄って、彼女に会って言った、「お願いです。あなたの水がめの水を少し飲ませてください」。</span>
<span className="v" id="v18" data-v="18" data-xref="箴言 31:26; ペテロの第一の手紙 3:8; 創世記 24:14"> すると彼女は「わが主よ、お飲みください」と言って、急いで水がめを自分の手に取りおろして彼に飲ませた。</span>
<span className="v" id="v19" data-v="19" data-xref="創世記 24:14; ペテロの第一の手紙 4:9; 創世記 24:45–46"> 飲ませ終って、彼女は言った、「あなたのらくだもみな飲み終るまで、わたしは水をくみましょう」。</span>
<span className="v" id="v20" data-v="20"> 彼女は急いでかめの水を水ぶねにあけ、再び水をくみに井戸に走って行って、すべてのらくだのために水をくんだ。</span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 107:43; 創世記 24:12; サムエル記下 7:18–20"> その間その人は主が彼の旅の祝福されるか、どうかを知ろうと、黙って彼女を見つめていた。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="エゼキエル書 16:11–12; 出エジプト記 32:2–3; 創世記 23:15–16"> らくだが飲み終ったとき、その人は重さ半シケルの金の鼻輪一つと、重さ十シケルの金の腕輪二つを取って、</span>
<span className="v" id="v23" data-v="23"> 言った、「あなたはだれの娘か、わたしに話してください。あなたの父の家にわたしどもの泊まる場所がありましょうか」。</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 24:15; 創世記 22:23; 創世記 22:20"> 彼女は彼に言った、「わたしはナホルの妻ミルカの子ベトエルの娘です」。</span>
<span className="v" id="v25" data-v="25" data-xref="イザヤ書 32:8; ペテロの第一の手紙 4:9; 士師記 19:19–21"> また彼に言った、「わたしどもには、わらも、飼葉もたくさんあります。また泊まる場所もあります」。</span>
<span className="v" id="v26" data-v="26" data-xref="創世記 24:48; 出エジプト記 4:31; 創世記 24:52"> その人は頭を下げ、主を拝して、</span>
<span className="v" id="v27" data-v="27" data-xref="創世記 24:48; 創世記 24:12; 詩篇 98:3"> 言った、「主人アブラハムの神、主はほむべきかな。主はわたしの主人にいつくしみと、まこととを惜しまれなかった。そして主は旅にあるわたしを主人の兄弟の家に導かれた」。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="創世記 24:67; 創世記 24:55; 創世記 31:33"> 娘は走って行って、母の家のものにこれらの事を告げた。</span>
<span className="v" id="v29" data-v="29" data-xref="創世記 29:5; 創世記 29:13; 創世記 24:55"> リベカにひとりの兄があって、名をラバンといった。ラバンは泉のそばにいるその人の所へ走って行った。</span>
<span className="v" id="v30" data-v="30"> 彼は鼻輪と妹の手にある腕輪とを見、また妹リベカが「その人はわたしにこう言った」というのを聞いて、その人の所へ行ってみると、その人は泉のほとりで、らくだのそばに立っていた。</span>
<span className="v" id="v31" data-v="31" data-xref="ルツ記 3:10; 創世記 26:29; 詩篇 115:15"> そこでその人に言った、「主に祝福された人よ、おはいりください。なぜ外に立っておられますか。わたしは家を準備し、らくだのためにも場所を準備しておきました」。</span>
<span className="v" id="v32" data-v="32" data-xref="士師記 19:21; 創世記 43:24; 創世記 18:4"> その人は家にはいった。ラバンはらくだの荷を解いて、わらと飼葉をらくだに与え、また水を与えてその人の足と、その従者たちの足を洗わせた。</span>
<span className="v" id="v33" data-v="33" data-xref="詩篇 132:3–5; テモテヘの第一の手紙 6:2; エペソ人への手紙 6:5–8"> そして彼の前に食物を供えたが、彼は言った、「わたしは用向きを話すまでは食べません」。ラバンは言った、「お話しください」。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34"> そこで彼は言った、「わたしはアブラハムのしもべです。</span>
<span className="v" id="v35" data-v="35" data-xref="創世記 24:1; 創世記 13:2; 箴言 10:22"> 主はわたしの主人を大いに祝福して、大いなる者とされました。主はまた彼に羊、牛、銀、金、男女の奴隷、らくだ、ろばを与えられました。</span>
<span className="v" id="v36" data-v="36" data-xref="創世記 25:5; 創世記 21:10; 創世記 21:1–7"> 主人の妻サラは年老いてから、主人に男の子を産みました。主人はその所有を皆これに与えました。</span>
<span className="v" id="v37" data-v="37" data-xref="創世記 27:46; エズラ記 9:1–3; 創世記 24:2–9"> ところで主人はわたしに誓わせて言いました、『わたしの住んでいる地のカナンびとの娘を、わたしの子の妻にめとってはならない。</span>
<span className="v" id="v38" data-v="38" data-xref="創世記 24:4; 創世記 31:19; 創世記 12:1"> おまえはわたしの父の家、親族の所へ行って、わたしの子に妻をめとらなければならない』。</span>
<span className="v" id="v39" data-v="39" data-xref="創世記 24:5"> わたしは主人に言いました、『もしその女がわたしについてこない時はどういたしましょうか』。</span>
<span className="v" id="v40" data-v="40" data-xref="出エジプト記 23:20; 詩篇 16:8; 創世記 5:24"> 主人はわたしに言いました、『わたしの仕えている主は、み使をおまえと一緒につかわして、おまえの旅にさいわいを与えられるであろう。おまえはわたしの親族、わたしの父の家からわたしの子に妻をめとらなければならない。</span>
<span className="v" id="v41" data-v="41" data-xref="創世記 24:8; 申命記 29:12"> そのとき、おまえはわたしにした誓いから解かれるであろう。またおまえがわたしの親族に行く時、彼らがおまえにその娘を与えないなら、おまえはわたしにした誓いから解かれるであろう』。</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="ネヘミヤ書 1:11; 創世記 24:12–14; エズラ記 8:21"> わたしはきょう、泉のところにきて言いました、『主人アブラハムの神、主よ、どうか今わたしのゆく道にさいわいを与えてください。</span>
<span className="v" id="v43" data-v="43" data-xref="創世記 24:13–14"> わたしはこの泉のそばに立っていますが、水をくみに出てくる娘に向かって、「お願いです。あなたの水がめの水を少し飲ませてください」と言い、</span>
<span className="v" id="v44" data-v="44" data-xref="創世記 24:14; ペテロの第一の手紙 3:8; 創世記 2:22"> 「お飲みください。あなたのらくだのためにも、くみましょう」とわたしに言うなら、その娘こそ、主がわたしの主人の子のために定められた女ということにしてください』。</span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="マタイによる福音書 7:7; 使徒行伝 12:12–17; 創世記 24:15–20"> わたしが心のうちでそう言い終らないうちに、リベカが水がめを肩に載せて出てきて、水をくみに泉に降りたので、わたしは『お願いです、飲ませてください』と言いますと、</span>
<span className="v" id="v46" data-v="46" data-xref="創世記 24:18–19"> 彼女は急いで水がめを肩からおろし、『お飲みください。わたしはあなたのらくだにも飲ませましょう』と言いました。それでわたしは飲みましたが、彼女はらくだにも飲ませました。</span>
<span className="v" id="v47" data-v="47" data-xref="詩篇 45:13–14; 創世記 24:22–24; イザヤ書 62:3–5"> わたしは彼女に尋ねて、『あなたはだれの娘ですか』と言いますと、『ナホルとその妻ミルカの子ベトエルの娘です』と答えました。そこでわたしは彼女の鼻に鼻輪をつけ、手に腕輪をつけました。</span>
<span className="v" id="v48" data-v="48" data-xref="箴言 3:5–6; 創世記 24:26–27; 詩篇 48:14"> そしてわたしは頭をさげて主を拝し、主人アブラハムの神、主をほめたたえました。主は主人の兄弟の娘を子にめとらせようと、わたしを正しい道に導かれたからです。</span>
<span className="v" id="v49" data-v="49" data-xref="創世記 47:29; ヨシュア記 2:14; 箴言 3:3"> あなたがたが、もしわたしの主人にいつくしみと、まことを尽そうと思われるなら、そうとわたしにお話しください。そうでなければ、そうでないとお話しください。それによってわたしは右か左に決めましょう」。</span>
</div>
<div className="bp">
<span className="v" id="v50" data-v="50" data-xref="詩篇 118:23; 創世記 31:24; 創世記 31:29"> ラバンとベトエルは答えて言った、「この事は主から出たことですから、わたしどもはあなたによしあしを言うことができません。</span>
<span className="v" id="v51" data-v="51" data-xref="創世記 20:15; 創世記 24:15; サムエル記下 16:10"> リベカがここにおりますから連れて行って、主が言われたように、あなたの主人の子の妻にしてください」。</span>
</div>
<div className="bp poetry">
<span className="v" id="v52" data-v="52" data-xref="創世記 24:26; 創世記 24:48; 詩篇 116:1–2"> アブラハムのしもべは彼らの言葉を聞いて、地に伏し、主を拝した。</span>
<span className="v" id="v53" data-v="53" data-xref="創世記 24:22; 創世記 24:10; 出エジプト記 12:35"> そしてしもべは銀の飾りと、金の飾り、および衣服を取り出してリベカに与え、その兄と母とにも価の高い品々を与えた。</span>
<span className="v" id="v54" data-v="54" data-xref="創世記 24:56; 創世記 24:59; 創世記 28:5–6"> 彼と従者たちは飲み食いして宿ったが、あくる朝彼らが起きた時、しもべは言った、「わたしを主人のもとに帰らせてください」。</span>
<span className="v" id="v55" data-v="55" data-xref="創世記 4:3; レビ記 25:29; 士師記 14:8"> リベカの兄と母とは言った、「娘は数日、少なくとも十日、わたしどもと共にいて、それから行かせましょう」。</span>
<span className="v" id="v56" data-v="56" data-xref="箴言 25:25; ヨシュア記 1:8; イザヤ書 48:15"> しもべは彼らに言った、「主はわたしの道にさいわいを与えられましたから、わたしを引きとめずに、主人のもとに帰らせてください」。</span>
<span className="v" id="v57" data-v="57"> 彼らは言った、「娘を呼んで聞いてみましょう」。</span>
<span className="v" id="v58" data-v="58" data-xref="ルカによる福音書 1:38; 詩篇 45:10–11"> 彼らはリベカを呼んで言った、「あなたはこの人と一緒に行きますか」。彼女は言った、「行きます」。</span>
<span className="v" id="v59" data-v="59" data-xref="創世記 35:8; 民数記 11:12; 創世記 24:50"> そこで彼らは妹リベカと、そのうばと、アブラハムのしもべと、その従者とを送り去らせた。</span>
<span className="v" id="v60" data-v="60" data-xref="創世記 22:17; 創世記 17:16; ルツ記 4:11–12"> 彼らはリベカを祝福して彼女に言った、<br /><span className="pl pl-1">「妹よ、あなたは、ちよろずの人の母となれ。</span><br /><span className="pl pl-1">あなたの子孫はその敵の門を打ち取れ」。</span></span>
<span className="v" id="v61" data-v="61" data-xref="詩篇 45:10; 創世記 2:24; エステル記 8:14"> <span className="pl pl-1">リベカは立って侍女たちと共にらくだに乗り、その人に従って行った。しもべはリベカを連れて立ち去った。</span></span>
</div>
<div className="bp">
<span className="v" id="v62" data-v="62" data-xref="創世記 25:11; 創世記 16:14; 創世記 12:9"> さてイサクはベエル・ラハイ・ロイからきて、ネゲブの地に住んでいた。</span>
<span className="v" id="v63" data-v="63" data-xref="詩篇 119:15; 詩篇 1:2; 詩篇 104:34"> イサクは夕暮、野に出て歩いていたが、目をあげて、らくだの来るのを見た。</span>
<span className="v" id="v64" data-v="64" data-xref="士師記 1:14; ヨシュア記 15:18"> リベカは目をあげてイサクを見、らくだからおりて、</span>
<span className="v" id="v65" data-v="65" data-xref="テモテヘの第一の手紙 2:9; コリント人への第一の手紙 11:5–6; コリント人への第一の手紙 11:10"> しもべに言った、「わたしたちに向かって、野を歩いて来るあの人はだれでしょう」。しもべは言った、「あれはわたしの主人です」。するとリベカは、被衣で身をおおった。</span>
<span className="v" id="v66" data-v="66" data-xref="マルコによる福音書 6:30"> しもべは自分がしたことのすべてをイサクに話した。</span>
<span className="v" id="v67" data-v="67" data-xref="雅歌 8:2; エペソ人への手紙 5:22–33; 創世記 23:1–2"> イサクはリベカを天幕に連れて行き、リベカをめとって妻とし、彼女を愛した。こうしてイサクは母の死後、慰めを得た。</span>
</div>

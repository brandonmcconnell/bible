<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨハネによる福音書 1:1–3; ヘブル人への手紙 11:3; イザヤ書 45:18"> はじめに神は天と地とを創造された。</span>
<span className="v" id="v2" data-v="2" data-xref="エレミヤ書 4:23; 詩篇 104:30; イザヤ書 45:18"> 地は形なく、むなしく、やみが淵のおもてにあり、神の霊が水のおもてをおおっていた。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="コリント人への第二の手紙 4:6; ヨハネによる福音書 1:5; イザヤ書 45:7"> 神は「光あれ」と言われた。すると光があった。</span>
<span className="v" id="v4" data-v="4" data-xref="伝道の書 2:13; 創世記 1:18; 伝道の書 11:7"> 神はその光を見て、良しとされた。神はその光とやみとを分けられた。</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 74:16; イザヤ書 45:7; テサロニケ人への第一の手紙 5:5"> 神は光を昼と名づけ、やみを夜と名づけられた。夕となり、また朝となった。第一日である。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="エレミヤ書 51:15; 詩篇 33:6; ヨブ記 37:18"> 神はまた言われた、「水の間におおぞらがあって、水と水とを分けよ」。</span>
<span className="v" id="v7" data-v="7" data-xref="箴言 8:28–29; 詩篇 148:4; マタイによる福音書 8:27"> そのようになった。神はおおぞらを造って、おおぞらの下の水とおおぞらの上の水とを分けられた。</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 1:5; 創世記 1:19; 創世記 1:10"> 神はそのおおぞらを天と名づけられた。夕となり、また朝となった。第二日である。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="ペテロの第二の手紙 3:5; ヨナ書 1:9; エレミヤ書 5:22"> 神はまた言われた、「天の下の水は一つ所に集まり、かわいた地が現れよ」。そのようになった。</span>
<span className="v" id="v10" data-v="10" data-xref="申命記 32:4; 詩篇 104:31; 創世記 1:4"> 神はそのかわいた地を陸と名づけ、水の集まった所を海と名づけられた。神は見て、良しとされた。</span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 104:14–17; ヘブル人への手紙 6:7; 詩篇 147:8"> 神はまた言われた、「地は青草と、種をもつ草と、種類にしたがって種のある実を結ぶ果樹とを地の上にはえさせよ」。そのようになった。</span>
<span className="v" id="v12" data-v="12" data-xref="マルコによる福音書 4:28; イザヤ書 55:10–11; マタイによる福音書 13:24–26"> 地は青草と、種類にしたがって種をもつ草と、種類にしたがって種のある実を結ぶ木とをはえさせた。神は見て、良しとされた。</span>
<span className="v" id="v13" data-v="13"> 夕となり、また朝となった。第三日である。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="詩篇 104:19–20; 申命記 4:19; エレミヤ書 31:35"> 神はまた言われた、「天のおおぞらに光があって昼と夜とを分け、しるしのため、季節のため、日のため、年のためになり、</span>
<span className="v" id="v15" data-v="15"> 天のおおぞらにあって地を照らす光となれ」。そのようになった。</span>
<span className="v" id="v16" data-v="16" data-xref="詩篇 136:7–9; 申命記 4:19; 詩篇 8:3"> 神は二つの大きな光を造り、大きい光に昼をつかさどらせ、小さい光に夜をつかさどらせ、また星を造られた。</span>
<span className="v" id="v17" data-v="17" data-xref="詩篇 8:3; 詩篇 8:1; ヨブ記 38:12"> 神はこれらを天のおおぞらに置いて地を照らさせ、</span>
<span className="v" id="v18" data-v="18" data-xref="エレミヤ書 31:35; 詩篇 19:6"> 昼と夜とをつかさどらせ、光とやみとを分けさせられた。神は見て、良しとされた。</span>
<span className="v" id="v19" data-v="19"> 夕となり、また朝となった。第四日である。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="創世記 2:19; 詩篇 104:24–25; 列王紀上 4:33"> 神はまた言われた、「水は生き物の群れで満ち、鳥は地の上、天のおおぞらを飛べ」。</span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 104:24–26; 創世記 1:25; 創世記 8:19"> 神は海の大いなる獣と、水に群がるすべての動く生き物とを、種類にしたがって創造し、また翼のあるすべての鳥を、種類にしたがって創造された。神は見て、良しとされた。</span>
<span className="v" id="v22" data-v="22" data-xref="ヨブ記 40:15; 創世記 8:17; 詩篇 107:38"> 神はこれらを祝福して言われた、「生めよ、ふえよ、海の水に満ちよ、また鳥は地にふえよ」。</span>
<span className="v" id="v23" data-v="23"> 夕となり、また朝となった。第五日である。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="詩篇 50:9–10; 創世記 6:20; 創世記 8:19"> 神はまた言われた、「地は生き物を種類にしたがっていだせ。家畜と、這うものと、地の獣とを種類にしたがっていだせ」。そのようになった。</span>
<span className="v" id="v25" data-v="25" data-xref="エレミヤ書 27:5; ヨブ記 12:8–10; 創世記 2:19–20"> 神は地の獣を種類にしたがい、家畜を種類にしたがい、また地に這うすべての物を種類にしたがって造られた。神は見て、良しとされた。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="コロサイ人への手紙 3:10; エペソ人への手紙 4:24; 詩篇 8:4–8"> 神はまた言われた、「われわれのかたちに、われわれにかたどって人を造り、これに海の魚と、空の鳥と、家畜と、地のすべての獣と、地のすべての這うものとを治めさせよう」。</span>
<span className="v" id="v27" data-v="27" data-xref="マタイによる福音書 19:4; エペソ人への手紙 2:10; 創世記 5:1–2"> 神は自分のかたちに人を創造された。すなわち、神のかたちに創造し、男と女とに創造された。</span>
<span className="v" id="v28" data-v="28" data-xref="創世記 9:1; 創世記 9:7; レビ記 26:9"> 神は彼らを祝福して言われた、「生めよ、ふえよ、地に満ちよ、地を従わせよ。また海の魚と、空の鳥と、地に動くすべての生き物とを治めよ」。</span>
<span className="v" id="v29" data-v="29" data-xref="創世記 9:3; 詩篇 104:14–15; 詩篇 145:15–16"> 神はまた言われた、「わたしは全地のおもてにある種をもつすべての草と、種のある実を結ぶすべての木とをあなたがたに与える。これはあなたがたの食物となるであろう。</span>
<span className="v" id="v30" data-v="30" data-xref="詩篇 104:14; 詩篇 145:15–16; 詩篇 147:9"> また地のすべての獣、空のすべての鳥、地を這うすべてのもの、すなわち命あるものには、食物としてすべての青草を与える」。そのようになった。</span>
<span className="v" id="v31" data-v="31" data-xref="テモテヘの第一の手紙 4:4; 詩篇 104:24; 詩篇 19:1–2"> 神が造ったすべての物を見られたところ、それは、はなはだ良かった。夕となり、また朝となった。第六日である。</span>
</div>
</div>

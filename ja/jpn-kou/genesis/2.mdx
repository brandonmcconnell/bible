<span className="v" id="v1" data-v="1" data-xref="出エジプト記 31:17; 出エジプト記 20:11; 詩篇 33:6"> こうして天と地と、その万象とが完成した。</span>
<span className="v" id="v2" data-v="2" data-xref="ヘブル人への手紙 4:4; 出エジプト記 31:17; 申命記 5:14"> 神は第七日にその作業を終えられた。すなわち、そのすべての作業を終って第七日に休まれた。</span>
<span className="v" id="v3" data-v="3" data-xref="エゼキエル書 20:12; マルコによる福音書 2:27; レビ記 23:3"> 神はその第七日を祝福して、これを聖別された。神がこの日に、そのすべての創造のわざを終って休まれたからである。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="創世記 5:1; ヨハネの黙示録 1:8; 創世記 1:4"> これが天地創造の由来である。<br />主なる神が地と天とを造られた時、</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 3:23; ヘブル人への手紙 6:7; ヨブ記 5:10"> 地にはまだ野の木もなく、また野の草もはえていなかった。主なる神が地に雨を降らせず、また土を耕す人もなかったからである。</span>
<span className="v" id="v6" data-v="6"> しかし地から泉がわきあがって土の全面を潤していた。</span>
<span className="v" id="v7" data-v="7" data-xref="伝道の書 12:7; ヨブ記 33:4; コリント人への第一の手紙 15:45"> 主なる神は土のちりで人を造り、命の息をその鼻に吹きいれられた。そこで人は生きた者となった。</span>
<span className="v" id="v8" data-v="8" data-xref="エゼキエル書 28:13; 創世記 3:24; 創世記 13:10"> 主なる神は東のかた、エデンに一つの園を設けて、その造った人をそこに置かれた。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 3:22; ヨハネの黙示録 2:7; ヨハネの黙示録 22:14"> また主なる神は、見て美しく、食べるに良いすべての木を土からはえさせ、更に園の中央に命の木と、善悪を知る木とをはえさせられた。</span>
<span className="v" id="v10" data-v="10" data-xref="ヨハネの黙示録 22:1; 詩篇 46:4"> また一つの川がエデンから流れ出て園を潤し、そこから分れて四つの川となった。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 25:18; 創世記 10:29; サムエル記上 15:7"> その第一の名はピソンといい、金のあるハビラの全地をめぐるもので、</span>
<span className="v" id="v12" data-v="12" data-xref="出エジプト記 28:20; 民数記 11:7; エゼキエル書 28:13"> その地の金は良く、またそこはブドラクと、しまめのうとを産した。</span>
<span className="v" id="v13" data-v="13" data-xref="創世記 10:6; イザヤ書 11:11"> 第二の川の名はギホンといい、クシの全地をめぐるもの。</span>
<span className="v" id="v14" data-v="14" data-xref="ダニエル書 10:4; 創世記 15:18; 申命記 1:7"> 第三の川の名はヒデケルといい、アッスリヤの東を流れるもの。第四の川はユフラテである。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="詩篇 128:2; 創世記 2:8; エペソ人への手紙 4:28"> 主なる神は人を連れて行ってエデンの園に置き、これを耕させ、これを守らせられた。</span>
<span className="v" id="v16" data-v="16" data-xref="サムエル記上 15:22; テモテヘの第一の手紙 4:4; テモテヘの第一の手紙 6:17"> 主なる神はその人に命じて言われた、「あなたは園のどの木からでも心のままに取って食べてよろしい。</span>
<span className="v" id="v17" data-v="17" data-xref="ローマ人への手紙 6:23; ヤコブの手紙 1:15; 創世記 3:19"> しかし善悪を知る木からは取って食べてはならない。それを取って食べると、きっと死ぬであろう」。</span>
</div>
<div className="bp poetry">
<span className="v" id="v18" data-v="18" data-xref="伝道の書 4:9–12; コリント人への第一の手紙 11:7–12; 箴言 18:22"> また主なる神は言われた、「人がひとりでいるのは良くない。彼のために、ふさわしい助け手を造ろう」。</span>
<span className="v" id="v19" data-v="19" data-xref="詩篇 8:4–8; 創世記 1:28; 創世記 9:2"> そして主なる神は野のすべての獣と、空のすべての鳥とを土で造り、人のところへ連れてきて、彼がそれにどんな名をつけるかを見られた。人がすべて生き物に与える名は、その名となるのであった。</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 2:18"> それで人は、すべての家畜と、空の鳥と、野のすべての獣とに名をつけたが、人にはふさわしい助け手が見つからなかった。</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 15:12; ヨブ記 4:13; サムエル記上 26:12"> そこで主なる神は人を深く眠らせ、眠った時に、そのあばら骨の一つを取って、その所を肉でふさがれた。</span>
<span className="v" id="v22" data-v="22" data-xref="コリント人への第一の手紙 11:8–9; テモテヘの第一の手紙 2:13; ヘブル人への手紙 13:4"> 主なる神は人から取ったあばら骨でひとりの女を造り、人のところへ連れてこられた。</span>
<span className="v" id="v23" data-v="23" data-xref="エペソ人への手紙 5:28–30; コリント人への第一の手紙 11:8–9; サムエル記下 5:1"> そのとき、人は言った。<br /><span className="pl pl-1">「これこそ、ついにわたしの骨の骨、</span><br /><span className="pl pl-1">わたしの肉の肉。</span><br /><span className="pl pl-1">男から取ったものだから、</span><br /><span className="pl pl-1">これを女と名づけよう」。</span></span>
<span className="v" id="v24" data-v="24" data-xref="マタイによる福音書 19:3–9; エペソ人への手紙 5:28–31; マルコによる福音書 10:6–12"> <span className="pl pl-1">それで人はその父と母を離れて、妻と結び合い、一体となるのである。</span></span>
<span className="v" id="v25" data-v="25" data-xref="創世記 3:7; 創世記 3:10–11; ローマ人への手紙 10:11"> <span className="pl pl-1">人とその妻とは、ふたりとも裸であったが、恥ずかしいとは思わなかった。</span></span>

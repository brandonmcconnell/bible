<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="サムエル記上 22:1; 列王紀下 4:8; 箴言 13:20"> そのころユダは兄弟たちを離れて下り、アドラムびとで、名をヒラという者の所へ行った。</span>
<span className="v" id="v2" data-v="2" data-xref="歴代志上 2:3; 創世記 24:3; 創世記 6:2"> ユダはその所で、名をシュアというカナンびとの娘を見て、これをめとり、その所にはいった。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 46:12; 民数記 26:19"> 彼女はみごもって男の子を産んだので、ユダは名をエルと名づけた。</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 46:12; 民数記 26:19"> 彼女は再びみごもって男の子を産み、名をオナンと名づけた。</span>
<span className="v" id="v5" data-v="5" data-xref="民数記 26:20; 創世記 38:26; 創世記 46:12"> また重ねて、男の子を産み、名をシラと名づけた。彼女はこの男の子を産んだとき、クジブにおった。</span>
<span className="v" id="v6" data-v="6" data-xref="創世記 24:3; 創世記 21:21; マタイによる福音書 1:3"> ユダは長子エルのために、名をタマルという妻を迎えた。</span>
<span className="v" id="v7" data-v="7" data-xref="歴代志上 2:3; 創世記 46:12; 民数記 26:19"> しかしユダの長子エルは主の前に悪い者であったので、主は彼を殺された。</span>
<span className="v" id="v8" data-v="8" data-xref="申命記 25:5–10; マタイによる福音書 22:23–27; ルツ記 4:5–11"> そこでユダはオナンに言った、「兄の妻の所にはいって、彼女をめとり、兄に子供を得させなさい」。</span>
<span className="v" id="v9" data-v="9" data-xref="テトスヘの手紙 3:3; 申命記 25:6; ヤコブの手紙 3:16"> しかしオナンはその子が自分のものとならないのを知っていたので、兄の妻の所にはいった時、兄に子を得させないために地に洩らした。</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 46:12; 民数記 11:1; 歴代志上 21:7"> 彼のした事は主の前に悪かったので、主は彼をも殺された。</span>
<span className="v" id="v11" data-v="11" data-xref="レビ記 22:13; ルツ記 1:11–13"> そこでユダはその子の妻タマルに言った、「わたしの子シラが成人するまで、寡婦のままで、あなたの父の家にいなさい」。彼は、シラもまた兄弟たちのように死ぬかもしれないと、思ったからである。それでタマルは行って父の家におった。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="ヨシュア記 15:10; サムエル記下 13:39; 士師記 14:1"> 日がたってシュアの娘ユダの妻は死んだ。その後、ユダは喪を終ってその友アドラムびとヒラと共にテムナに上り、自分の羊の毛を切る者のところへ行った。</span>
<span className="v" id="v13" data-v="13"> 時に、ひとりの人がタマルに告げて、「あなたのしゅうとが羊の毛を切るためにテムナに上って来る」と言ったので、</span>
<span className="v" id="v14" data-v="14" data-xref="創世記 38:26; 創世記 38:11–13; エレミヤ書 3:2"> 彼女は寡婦の衣服を脱ぎすて、被衣で身をおおい隠して、テムナへ行く道のかたわらにあるエナイムの入口にすわっていた。彼女はシラが成人したのに、自分がその妻にされないのを知ったからである。</span>
<span className="v" id="v15" data-v="15"> ユダは彼女を見たとき、彼女が顔をおおっていたため、遊女だと思い、</span>
<span className="v" id="v16" data-v="16" data-xref="テモテヘの第一の手紙 6:10; マタイによる福音書 26:15; サムエル記下 13:11"> 道のかたわらで彼女に向かって言った、「さあ、あなたの所にはいらせておくれ」。彼はこの女がわが子の妻であることを知らなかったからである。彼女は言った、「わたしの所にはいるため、何をくださいますか」。</span>
<span className="v" id="v17" data-v="17" data-xref="エゼキエル書 16:33; 創世記 38:20; 箴言 20:16"> ユダは言った、「群れのうちのやぎの子をあなたにあげよう」。彼女は言った、「それをくださるまで、しるしをわたしにくださいますか」。</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 38:25–26; ホセア書 4:11; エレミヤ書 22:24"> ユダは言った、「どんなしるしをあげようか」。彼女は言った、「あなたの印と紐と、あなたの手にあるつえとを」。彼はこれらを与えて彼女の所にはいった。彼女はユダによってみごもった。</span>
<span className="v" id="v19" data-v="19" data-xref="創世記 38:14; サムエル記下 14:5; サムエル記下 14:2"> 彼女は起きて去り、被衣を脱いで寡婦の衣服を着た。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="創世記 20:9; レビ記 19:17; サムエル記下 13:3"> やがてユダはその女からしるしを取りもどそうと、その友アドラムびとに託してやぎの子を送ったけれども、その女を見いだせなかった。</span>
<span className="v" id="v21" data-v="21"> そこで彼はその所の人々に尋ねて言った、「エナイムで道のかたわらにいた遊女はどこにいますか」。彼らは言った、「ここには遊女はいません」。</span>
<span className="v" id="v22" data-v="22"> 彼はユダのもとに帰って言った、「わたしは彼女を見いだせませんでした。またその所の人々は、『ここには遊女はいない』と言いました」。</span>
<span className="v" id="v23" data-v="23" data-xref="エペソ人への手紙 5:12; 箴言 6:33; ヨハネの黙示録 16:15"> そこでユダは言った、「女に持たせておこう。わたしたちは恥をかくといけないから。とにかく、わたしはこのやぎの子を送ったが、あなたは彼女を見いだせなかったのだ」。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="レビ記 21:9; エゼキエル書 23:19; 士師記 19:2"> ところが三月ほどたって、ひとりの人がユダに言った、「あなたの嫁タマルは姦淫しました。そのうえ、彼女は姦淫によってみごもりました」。ユダは言った、「彼女を引き出して焼いてしまえ」。</span>
<span className="v" id="v25" data-v="25" data-xref="創世記 37:32; 創世記 38:18; コリント人への第一の手紙 4:5"> 彼女は引き出された時、そのしゅうとに人をつかわして言った、「わたしはこれをもっている人によって、みごもりました」。彼女はまた言った、「どうか、この印と、紐と、つえとはだれのものか、見定めてください」。</span>
<span className="v" id="v26" data-v="26" data-xref="サムエル記上 24:17; ヨハネによる福音書 8:9; テトスヘの手紙 2:11–12"> ユダはこれを見定めて言った、「彼女はわたしよりも正しい。わたしが彼女をわが子シラに与えなかったためである」。彼は再び彼女を知らなかった。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="創世記 25:24"> さて彼女の出産の時がきたが、胎内には、ふたごがあった。</span>
<span className="v" id="v28" data-v="28"> 出産の時に、ひとりの子が手を出したので、産婆は、「これがさきに出た」と言い、緋の糸を取って、その手に結んだ。</span>
<span className="v" id="v29" data-v="29" data-xref="歴代志上 2:4; マタイによる福音書 1:3; 創世記 46:12"> そして、その子が手をひっこめると、その弟が出たので、「どうしてあなたは自分で破って出るのか」と言った。これによって名はペレヅと呼ばれた。</span>
<span className="v" id="v30" data-v="30" data-xref="歴代志上 9:6; 歴代志上 2:4; マタイによる福音書 1:3"> その後、手に緋の糸のある兄が出たので、名はゼラと呼ばれた。</span>
</div>

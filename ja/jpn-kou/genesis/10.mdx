<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 2:4; 創世記 9:7; 創世記 5:1"> ノアの子セム、ハム、ヤペテの系図は次のとおりである。洪水の後、彼らに子が生れた。</span>
<span className="v" id="v2" data-v="2" data-xref="エゼキエル書 38:2; エゼキエル書 38:6; ヨハネの黙示録 20:8"> ヤペテの子孫はゴメル、マゴグ、マダイ、ヤワン、トバル、メセク、テラスであった。</span>
<span className="v" id="v3" data-v="3" data-xref="エゼキエル書 27:14; エレミヤ書 51:27"> ゴメルの子孫はアシケナズ、リパテ、トガルマ。</span>
<span className="v" id="v4" data-v="4" data-xref="ダニエル書 11:30; イザヤ書 23:12; 民数記 24:24"> ヤワンの子孫はエリシャ、タルシシ、キッテム、ドダニムであった。</span>
<span className="v" id="v5" data-v="5" data-xref="ゼパニヤ書 2:11; イザヤ書 42:4; エレミヤ書 2:10"> これらから海沿いの地の国民が分れて、おのおのその土地におり、その言語にしたがい、その氏族にしたがって、その国々に住んだ。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="歴代志上 1:8–16; エゼキエル書 27:10; 詩篇 105:23"> ハムの子孫はクシ、ミツライム、プテ、カナンであった。</span>
<span className="v" id="v7" data-v="7" data-xref="エゼキエル書 27:22; エゼキエル書 27:15; イザヤ書 21:13"> クシの子孫はセバ、ハビラ、サブタ、ラアマ、サブテカであり、ラアマの子孫はシバとデダンであった。</span>
<span className="v" id="v8" data-v="8" data-xref="ミカ書 5:6"> クシの子はニムロデであって、このニムロデは世の権力者となった最初の人である。</span>
<span className="v" id="v9" data-v="9" data-xref="歴代志下 28:22; 創世記 6:11; 創世記 25:27"> 彼は主の前に力ある狩猟者であった。これから「主の前に力ある狩猟者ニムロデのごとし」ということわざが起った。</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 11:9; 創世記 11:2; 創世記 14:1"> 彼の国は最初シナルの地にあるバベル、エレク、アカデ、カルネであった。</span>
<span className="v" id="v11" data-v="11" data-xref="ミカ書 5:6; 詩篇 83:8; ナホム書 1:1"> 彼はその地からアッスリヤに出て、ニネベ、レホボテイリ、カラ、</span>
<span className="v" id="v12" data-v="12"> およびニネベとカラとの間にある大いなる町レセンを建てた。</span>
<span className="v" id="v13" data-v="13" data-xref="歴代志上 1:11–12; エレミヤ書 46:9; エゼキエル書 30:5"> ミツライムからルデ族、アナミ族、レハビ族、ナフト族、</span>
<span className="v" id="v14" data-v="14" data-xref="エレミヤ書 47:4; 歴代志上 1:12; 申命記 2:23"> パテロス族、カスル族、カフトリ族が出た。カフトリ族からペリシテ族が出た。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="民数記 34:2–15; 出エジプト記 34:11; 創世記 23:3"> カナンからその長子シドンが出て、またヘテが出た。</span>
<span className="v" id="v16" data-v="16" data-xref="サムエル記下 24:18; 士師記 1:21; ゼカリヤ書 9:7"> その他エブスびと、アモリびと、ギルガシびと、</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 34:2"> ヒビびと、アルキびと、セニびと、</span>
<span className="v" id="v18" data-v="18" data-xref="ヨシュア記 18:22; サムエル記下 8:9; エゼキエル書 27:8"> アルワデびと、ゼマリびと、ハマテびとが出た。後になってカナンびとの氏族がひろがった。</span>
<span className="v" id="v19" data-v="19" data-xref="創世記 14:2; 創世記 19:24–25; ヨシュア記 12:7–8"> カナンびとの境はシドンからゲラルを経てガザに至り、ソドム、ゴモラ、アデマ、ゼボイムを経て、レシャに及んだ。</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 10:6; 創世記 11:1–9"> これらはハムの子孫であって、その氏族とその言語とにしたがって、その土地と、その国々にいた。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="民数記 24:24; 創世記 11:10–26"> セムにも子が生れた。セムはエベルのすべての子孫の先祖であって、ヤペテの兄であった。</span>
<span className="v" id="v22" data-v="22" data-xref="イザヤ書 66:19; エレミヤ書 25:25; 創世記 14:1–9"> セムの子孫はエラム、アシュル、アルパクサデ、ルデ、アラムであった。</span>
<span className="v" id="v23" data-v="23" data-xref="ヨブ記 1:1; エレミヤ書 25:20"> アラムの子孫はウヅ、ホル、ゲテル、マシであった。</span>
<span className="v" id="v24" data-v="24" data-xref="ルカによる福音書 3:35; 創世記 11:12–15"> アルパクサデの子はシラ、シラの子はエベルである。</span>
<span className="v" id="v25" data-v="25" data-xref="歴代志上 1:19; 創世記 10:32; 申命記 32:8"> エベルにふたりの子が生れた。そのひとりの名をペレグといった。これは彼の代に地の民が分れたからである。その弟の名をヨクタンといった。</span>
<span className="v" id="v26" data-v="26" data-xref="歴代志上 1:20–28"> ヨクタンにアルモダデ、シャレフ、ハザルマウテ、エラ、</span>
<span className="v" id="v27" data-v="27" data-xref="歴代志上 1:20–28"> ハドラム、ウザル、デクラ、</span>
<span className="v" id="v28" data-v="28" data-xref="歴代志上 1:20–28; 列王紀上 10:1; 創世記 25:3"> オバル、アビマエル、シバ、</span>
<span className="v" id="v29" data-v="29" data-xref="列王紀上 9:28; 歴代志上 9:13; 創世記 2:11"> オフル、ハビラ、ヨバブが生れた。これらは皆ヨクタンの子であった。</span>
<span className="v" id="v30" data-v="30" data-xref="民数記 23:7"> 彼らが住んだ所はメシャから東の山地セパルに及んだ。</span>
<span className="v" id="v31" data-v="31" data-xref="創世記 10:5; 創世記 10:20; 使徒行伝 17:26"> これらはセムの子孫であって、その氏族とその言語とにしたがって、その土地と、その国々にいた。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="創世記 9:19; 使徒行伝 17:26; 創世記 10:1"> これらはノアの子らの氏族であって、血統にしたがって国々に住んでいたが、洪水の後、これらから地上の諸国民が分れたのである。</span>
</div>

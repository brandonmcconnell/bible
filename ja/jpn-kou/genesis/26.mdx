<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 12:10; 創世記 25:11; 創世記 21:22–32"> アブラハムの時にあった初めのききんのほか、またききんがその国にあったので、イサクはゲラルにいるペリシテびとの王アビメレクの所へ行った。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 12:7; 詩篇 37:3; 創世記 17:1"> その時、主は彼に現れて言われた、「エジプトへ下ってはならない。わたしがあなたに示す地にとどまりなさい。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 28:15; 詩篇 105:9; 創世記 17:8"> あなたがこの地にとどまるなら、わたしはあなたと共にいて、あなたを祝福し、これらの国をことごとくあなたと、あなたの子孫とに与え、わたしがあなたの父アブラハムに誓った誓いを果そう。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行伝 3:25; 創世記 15:5; 創世記 22:17–18"> またわたしはあなたの子孫を増して天の星のようにし、あなたの子孫にこれらの地をみな与えよう。そして地のすべての国民はあなたの子孫によって祝福をえるであろう。</span>
<span className="v" id="v5" data-v="5" data-xref="マタイによる福音書 7:24; 創世記 22:18; 創世記 22:16"> アブラハムがわたしの言葉にしたがってわたしのさとしと、いましめと、さだめと、おきてとを守ったからである」。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="創世記 20:1"> こうしてイサクはゲラルに住んだ。</span>
<span className="v" id="v7" data-v="7" data-xref="箴言 29:25; 創世記 12:13; 創世記 20:2"> その所の人々が彼の妻のことを尋ねたとき、「彼女はわたしの妹です」と彼は言った。リベカは美しかったので、その所の人々がリベカのゆえに自分を殺すかもしれないと思って、「わたしの妻です」と言うのを恐れたからである。</span>
<span className="v" id="v8" data-v="8" data-xref="イザヤ書 62:5; 箴言 5:18–19; 箴言 7:6"> イサクは長らくそこにいたが、ある日ペリシテびとの王アビメレクは窓から外をながめていて、イサクがその妻リベカと戯れているのを見た。</span>
<span className="v" id="v9" data-v="9"> そこでアビメレクはイサクを召して言った、「彼女は確かにあなたの妻です。あなたはどうして『彼女はわたしの妹です』と言われたのですか」。イサクは彼に言った、「わたしは彼女のゆえに殺されるかもしれないと思ったからです」。</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 20:9–10; 創世記 12:18–19"> アビメレクは言った、「あなたはどうしてこんな事をわれわれにされたのですか。民のひとりが軽々しくあなたの妻と寝るような事があれば、その時あなたはわれわれに罪を負わせるでしょう」。</span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 105:15; 創世記 20:6; 箴言 6:29"> それでアビメレクはすべての民に命じて言った、「この人、またはその妻にさわる者は必ず死ななければならない」。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="マルコによる福音書 4:8; 創世記 24:1; 創世記 26:3"> イサクはその地に種をまいて、その年に百倍の収穫を得た。このように主が彼を祝福されたので、</span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 112:3; 箴言 10:22; 創世記 24:35"> 彼は富み、またますます栄えて非常に裕福になり、</span>
<span className="v" id="v14" data-v="14" data-xref="創世記 37:11; 創世記 13:2; 箴言 27:4"> 羊の群れ、牛の群れ及び多くのしもべを持つようになったので、ペリシテびとは彼をねたんだ。</span>
<span className="v" id="v15" data-v="15" data-xref="創世記 21:30; 創世記 21:25"> またペリシテびとは彼の父アブラハムの時に、父のしもべたちが掘ったすべての井戸をふさぎ、土で埋めた。</span>
<span className="v" id="v16" data-v="16" data-xref="出エジプト記 1:9"> アビメレクはイサクに言った、「あなたはわれわれよりも、はるかに強くなられたから、われわれの所を去ってください」。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17"> イサクはそこを去り、ゲラルの谷に天幕を張ってその所に住んだ。</span>
<span className="v" id="v18" data-v="18" data-xref="ゼカリヤ書 13:2; ホセア書 2:17; 民数記 32:38"> そしてイサクは父アブラハムの時に人々の掘った水の井戸を再び掘った。アブラハムの死後、ペリシテびとがふさいだからである。イサクは父がつけた名にしたがってそれらに名をつけた。</span>
<span className="v" id="v19" data-v="19" data-xref="ヨハネによる福音書 4:10–11; ヨハネによる福音書 7:38; 雅歌 4:15"> しかしイサクのしもべたちが谷の中を掘って、そこにわき出る水の井戸を見つけたとき、</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 21:25"> ゲラルの羊飼たちは、「この水はわれわれのものだ」と言って、イサクの羊飼たちと争ったので、イサクはその井戸の名をエセクと名づけた。彼らが彼と争ったからである。</span>
<span className="v" id="v21" data-v="21" data-xref="エズラ記 4:6"> 彼らはまた一つの井戸を掘ったが、これをも争ったので、名をシテナと名づけた。</span>
<span className="v" id="v22" data-v="22" data-xref="創世記 17:6; 出エジプト記 1:7; 詩篇 118:5"> イサクはそこから移ってまた一つの井戸を掘ったが、彼らはこれを争わなかったので、その名をレホボテと名づけて言った、「いま主がわれわれの場所を広げられたから、われわれはこの地にふえるであろう」。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="士師記 20:1; 創世記 21:31; 創世記 46:1"> 彼はそこからベエルシバに上った。</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 15:1; 出エジプト記 3:6; イザヤ書 43:1–2"> その夜、主は彼に現れて言われた、「わたしはあなたの父アブラハムの神である。あなたは恐れてはならない。わたしはあなたと共におって、あなたを祝福し、わたしのしもべアブラハムのゆえにあなたの子孫を増すであろう」。</span>
<span className="v" id="v25" data-v="25" data-xref="創世記 13:18; 詩篇 116:17; 創世記 12:7–8"> それで彼はその所に祭壇を築いて、主の名を呼び、そこに天幕を張った。またイサクのしもべたちはそこに一つの井戸を掘った。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="創世記 21:22–32; 創世記 20:3"> 時にアビメレクがその友アホザテと、軍勢の長ピコルと共にゲラルからイサクのもとにきたので、</span>
<span className="v" id="v27" data-v="27" data-xref="創世記 26:16; 士師記 11:7; 使徒行伝 7:14"> イサクは彼らに言った、「あなたがたはわたしを憎んで、あなたがたの中からわたしを追い出されたのに、どうしてわたしの所にこられたのですか」。</span>
<span className="v" id="v28" data-v="28" data-xref="創世記 21:22–23; イザヤ書 45:14; イザヤ書 61:9"> 彼らは言った、「われわれは主があなたと共におられるのを、はっきり見ましたので、いまわれわれの間、すなわちわれわれとあなたとの間に一つの誓いを立てて、あなたと契約を結ぼうと思います。</span>
<span className="v" id="v29" data-v="29" data-xref="創世記 24:31; 創世記 21:22; 創世記 22:17"> われわれはあなたに害を加えたことはなく、ただ良い事だけをして、安らかに去らせたのですから、あなたはわれわれに悪い事をしてはなりません。まことにあなたは主に祝福されたかたです」。</span>
<span className="v" id="v30" data-v="30" data-xref="創世記 19:3; ローマ人への手紙 12:18; ヘブル人への手紙 12:14"> そこでイサクは彼らのためにふるまいを設けた。彼らは飲み食いし、</span>
<span className="v" id="v31" data-v="31" data-xref="サムエル記上 20:16–17; ヘブル人への手紙 6:16; 創世記 25:33"> あくる朝、はやく起きて互に誓った。こうしてイサクは彼らを去らせたので、彼らはイサクのもとから穏やかに去った。</span>
<span className="v" id="v32" data-v="32" data-xref="箴言 10:4; 箴言 13:4; 箴言 2:4–5"> その日、イサクのしもべたちがきて、自分たちが掘った井戸について彼に告げて言った、「わたしたちは水を見つけました」。</span>
<span className="v" id="v33" data-v="33" data-xref="創世記 21:31; 創世記 26:28"> イサクはそれをシバと名づけた。これによってその町の名は今日にいたるまでベエルシバといわれている。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="創世記 36:2; 創世記 36:13; 出エジプト記 34:16"> エサウは四十歳の時、ヘテびとベエリの娘ユデテとヘテびとエロンの娘バスマテとを妻にめとった。</span>
<span className="v" id="v35" data-v="35" data-xref="創世記 27:46–2; 創世記 28:8; 創世記 6:2"> 彼女たちはイサクとリベカにとって心の痛みとなった。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 18:22; 創世記 18:1–5; ヘブル人への手紙 13:2"> そのふたりのみ使は夕暮にソドムに着いた。そのときロトはソドムの門にすわっていた。ロトは彼らを見て、立って迎え、地に伏して、</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 18:4; ルカによる福音書 24:28–29; ヘブル人への手紙 13:2"> 言った、「わが主よ、どうぞしもべの家に立寄って足を洗い、お泊まりください。そして朝早く起きてお立ちください」。彼らは言った、「いや、われわれは広場で夜を過ごします」。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 18:6–8; 士師記 6:19; サムエル記上 28:24"> しかしロトがしいて勧めたので、彼らはついに彼の所に寄り、家にはいった。ロトは彼らのためにふるまいを設け、種入れぬパンを焼いて食べさせた。</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 13:13; 箴言 4:16; 出エジプト記 23:2"> ところが彼らの寝ないうちに、ソドムの町の人々は、若い者も老人も、民がみな四方からきて、その家を囲み、</span>
<span className="v" id="v5" data-v="5" data-xref="士師記 19:22; イザヤ書 3:9; ユダの手紙 1:7"> ロトに叫んで言った、「今夜おまえの所にきた人々はどこにいるか。それをここに出しなさい。われわれは彼らを知るであろう」。</span>
<span className="v" id="v6" data-v="6" data-xref="士師記 19:23"> ロトは入口におる彼らの所に出て行き、うしろの戸を閉じて、</span>
<span className="v" id="v7" data-v="7" data-xref="コリント人への第一の手紙 6:9–11; 士師記 19:23; レビ記 20:13"> 言った、「兄弟たちよ、どうか悪い事はしないでください。</span>
<span className="v" id="v8" data-v="8" data-xref="士師記 19:24; 創世記 19:31–38; 士師記 9:15"> わたしにまだ男を知らない娘がふたりあります。わたしはこれをあなたがたに、さし出しますから、好きなようにしてください。ただ、わたしの屋根の下にはいったこの人たちには、何もしないでください」。</span>
<span className="v" id="v9" data-v="9" data-xref="出エジプト記 2:14; ペテロの第二の手紙 2:7–8; 創世記 13:12"> 彼らは言った、「退け」。また言った、「この男は渡ってきたよそ者であるのに、いつも、さばきびとになろうとする。それで、われわれは彼らに加えるよりも、おまえに多くの害を加えよう」。彼らはロトの身に激しく迫り、進み寄って戸を破ろうとした。</span>
<span className="v" id="v10" data-v="10"> その時、かのふたりは手を伸べてロトを家の内に引き入れ、戸を閉じた。</span>
<span className="v" id="v11" data-v="11" data-xref="列王紀下 6:18; 使徒行伝 13:11; 申命記 28:28–29"> そして家の入口におる人々を、老若の別なく打って目をくらましたので、彼らは入口を捜すのに疲れた。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="創世記 7:1; ペテロの第二の手紙 2:7; ヨハネの黙示録 18:4"> ふたりはロトに言った、「ほかにあなたの身内の者がここにおりますか。あなたのむこ、むすこ、娘およびこの町におるあなたの身内の者を、皆ここから連れ出しなさい。</span>
<span className="v" id="v13" data-v="13" data-xref="創世記 18:20; マタイによる福音書 13:49–50; ユダの手紙 1:7"> われわれがこの所を滅ぼそうとしているからです。人々の叫びが主の前に大きくなり、主はこの所を滅ぼすために、われわれをつかわされたのです」。</span>
<span className="v" id="v14" data-v="14" data-xref="民数記 16:21; エレミヤ書 51:6; 民数記 16:45"> そこでロトは出て行って、その娘たちをめとるむこたちに告げて言った、「立ってこの所から出なさい。主がこの町を滅ぼされます」。しかしそれはむこたちには戯むれごとに思えた。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="民数記 16:24–27; ヨハネの黙示録 18:4; 創世記 19:22"> 夜が明けて、み使たちはロトを促して言った　　「立って、ここにいるあなたの妻とふたりの娘とを連れ出しなさい。そうしなければ、あなたもこの町の不義のために滅ぼされるでしょう」。</span>
<span className="v" id="v16" data-v="16" data-xref="ローマ人への手紙 9:15–16; テトスヘの手紙 3:5; ヨハネによる福音書 6:44"> 彼はためらっていたが、主は彼にあわれみを施されたので、かのふたりは彼の手と、その妻の手と、ふたりの娘の手を取って連れ出し、町の外に置いた。</span>
<span className="v" id="v17" data-v="17" data-xref="マタイによる福音書 24:16–18; ルカによる福音書 9:62; ピリピ人への手紙 3:13–14"> 彼らを外に連れ出した時そのひとりは言った、「のがれて、自分の命を救いなさい。うしろをふりかえって見てはならない。低地にはどこにも立ち止まってはならない。山にのがれなさい。そうしなければ、あなたは滅びます」。</span>
<span className="v" id="v18" data-v="18" data-xref="ヨハネによる福音書 13:6–8; 使徒行伝 10:14; 創世記 32:26"> ロトは彼らに言った、「わが主よ、どうか、そうさせないでください。</span>
<span className="v" id="v19" data-v="19" data-xref="サムエル記上 27:1; 詩篇 103:1–22; テモテヘの第一の手紙 1:14–16"> しもべはすでにあなたの前に恵みを得ました。あなたはわたしの命を救って、大いなるいつくしみを施されました。しかしわたしは山まではのがれる事ができません。災が身に追い迫ってわたしは死ぬでしょう。</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 119:175; 箴言 3:5–7; 創世記 19:30"> あの町をごらんなさい。逃げていくのに近く、また小さい町です。どうかわたしをそこにのがれさせてください。それは小さいではありませんか。そうすればわたしの命は助かるでしょう」。</span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 145:19; 詩篇 34:15; 詩篇 102:17"> み使は彼に言った、「わたしはこの事でもあなたの願いをいれて、あなたの言うその町は滅ぼしません。</span>
<span className="v" id="v22" data-v="22" data-xref="創世記 13:10; 創世記 14:2; 創世記 32:25–28"> 急いでそこへのがれなさい。あなたがそこに着くまでは、わたしは何事もすることができません」。これによって、その町の名はゾアルと呼ばれた。</span>
<span className="v" id="v23" data-v="23"> ロトがゾアルに着いた時、日は地の上にのぼった。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="申命記 29:23; イザヤ書 13:19; アモス書 4:11"> 主は硫黄と火とを主の所すなわち天からソドムとゴモラの上に降らせて、</span>
<span className="v" id="v25" data-v="25" data-xref="詩篇 107:34; 創世記 14:3; 創世記 13:10"> これらの町と、すべての低地と、その町々のすべての住民と、その地にはえている物を、ことごとく滅ぼされた。</span>
<span className="v" id="v26" data-v="26" data-xref="ルカによる福音書 17:31–32; 創世記 19:17; 箴言 14:14"> しかしロトの妻はうしろを顧みたので塩の柱になった。</span>
<span className="v" id="v27" data-v="27" data-xref="ハバクク書 2:1; 詩篇 5:3; ヘブル人への手紙 2:1"> アブラハムは朝早く起き、さきに主の前に立った所に行って、</span>
<span className="v" id="v28" data-v="28" data-xref="ヨハネの黙示録 18:9; ヨハネの黙示録 9:2; ヨハネの黙示録 21:8"> ソドムとゴモラの方、および低地の全面をながめると、その地の煙が、かまどの煙のように立ちのぼっていた。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="創世記 8:1; 申命記 9:5; 創世記 18:23–33"> こうして神が低地の町々をこぼたれた時、すなわちロトの住んでいた町々を滅ぼされた時、神はアブラハムを覚えて、その滅びの中からロトを救い出された。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="創世記 19:19; イザヤ書 15:5; ヤコブの手紙 1:8"> ロトはゾアルを出て上り、ふたりの娘と共に山に住んだ。ゾアルに住むのを恐れたからである。彼はふたりの娘と共に、ほら穴の中に住んだ。</span>
<span className="v" id="v31" data-v="31" data-xref="申命記 25:5; イザヤ書 4:1; 創世記 16:2"> 時に姉が妹に言った、「わたしたちの父は老い、またこの地には世のならわしのように、わたしたちの所に来る男はいません。</span>
<span className="v" id="v32" data-v="32" data-xref="レビ記 18:6–7; 創世記 11:3; 創世記 9:21"> さあ、父に酒を飲ませ、共に寝て、父によって子を残しましょう」。</span>
<span className="v" id="v33" data-v="33" data-xref="ハバクク書 2:15–16; 箴言 23:29–35; 箴言 20:1"> 彼女たちはその夜、父に酒を飲ませ、姉がはいって父と共に寝た。ロトは娘が寝たのも、起きたのも知らなかった。</span>
<span className="v" id="v34" data-v="34" data-xref="エレミヤ書 8:12; エレミヤ書 6:15; イザヤ書 3:9"> あくる日、姉は妹に言った、「わたしは昨夜、父と寝ました。わたしたちは今夜もまた父に酒を飲ませましょう。そしてあなたがはいって共に寝なさい。わたしたちは父によって子を残しましょう」。</span>
<span className="v" id="v35" data-v="35" data-xref="箴言 24:16; 詩篇 8:4; ペテロの第一の手紙 4:7"> 彼らはその夜もまた父に酒を飲ませ、妹が行って父と共に寝た。ロトは娘の寝たのも、起きたのも知らなかった。</span>
<span className="v" id="v36" data-v="36" data-xref="ハバクク書 2:15; 士師記 1:7; マタイによる福音書 7:2"> こうしてロトのふたりの娘たちは父によってはらんだ。</span>
<span className="v" id="v37" data-v="37" data-xref="申命記 2:9; 列王紀下 3:1–27; 民数記 21:29"> 姉娘は子を産み、その名をモアブと名づけた。これは今のモアブびとの先祖である。</span>
<span className="v" id="v38" data-v="38" data-xref="申命記 2:19; 士師記 10:6–40; 詩篇 83:4–8"> 妹もまた子を産んで、その名をベニアンミと名づけた。これは今のアンモンびとの先祖である。</span>
</div>

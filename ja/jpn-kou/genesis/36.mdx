<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 22:17; 歴代志上 1:35; 申命記 23:7"> エサウ、すなわちエドムの系図は次のとおりである。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 36:25; 創世記 28:9; 創世記 9:25"> エサウはカナンの娘たちのうちから妻をめとった。すなわちヘテびとエロンの娘アダと、ヒビびとヂベオンの子アナの娘アホリバマとである。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 28:9; 創世記 25:13"> また、イシマエルの娘ネバヨテの妹バスマテをめとった。</span>
<span className="v" id="v4" data-v="4" data-xref="歴代志上 1:35; 出エジプト記 2:18; ヨブ記 2:11"> アダはエリパズをエサウに産み、バスマテはリウエルを産み、</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 35:29"> アホリバマはエウシ、ヤラム、コラを産んだ。これらはエサウの子であって、カナンの地で彼に生れた者である。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="創世記 32:3; 創世記 12:5; 創世記 17:8"> エサウは妻と子と娘と家のすべての人、家畜とすべての獣、またカナンの地で獲たすべての財産を携え、兄弟ヤコブを離れてほかの地へ行った。</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 13:6; 創世記 17:8; 創世記 28:4"> 彼らの財産が多くて、一緒にいることができなかったからである。すなわち彼らが寄留した地は彼らの家畜のゆえに、彼らをささえることができなかったのである。</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 32:3; マラキ書 1:3; エゼキエル書 35:2–7"> こうしてエサウはセイルの山地に住んだ。エサウはすなわちエドムである。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="創世記 19:37"> セイルの山地におったエドムびとの先祖エサウの系図は次のとおりである。</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 36:3–4; 歴代志上 1:35–54"> エサウの子らの名は次のとおりである。すなわちエサウの妻アダの子はエリパズ。エサウの妻バスマテの子はリウエル。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 36:15–16; 歴代志上 1:35–36"> エリパズの子らはテマン、オマル、ゼポ、ガタム、ケナズである。</span>
<span className="v" id="v12" data-v="12" data-xref="出エジプト記 17:8–16; 申命記 25:17–19; サムエル記上 15:2–9"> テムナはエサウの子エリパズのそばめで、アマレクをエリパズに産んだ。これらはエサウの妻アダの子らである。</span>
<span className="v" id="v13" data-v="13" data-xref="歴代志上 1:37; 創世記 36:17"> リウエルの子らは次のとおりである。すなわちナハテ、ゼラ、シャンマ、ミザであって、これらはエサウの妻バスマテの子らである。</span>
<span className="v" id="v14" data-v="14" data-xref="創世記 36:2; 創世記 36:18; 歴代志上 1:35"> ヂベオンの子アナの娘で、エサウの妻アホリバマの子らは次のとおりである。すなわち彼女はエウシ、ヤラム、コラをエサウに産んだ。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="オバデヤ書 1:9; ヨブ記 2:11; 創世記 36:11–12"> エサウの子らの中で、族長たる者は次のとおりである。すなわちエサウの長子エリパズの子らはテマンの族長、オマルの族長、ゼポの族長、ケナズの族長、</span>
<span className="v" id="v16" data-v="16" data-xref="出エジプト記 15:15"> コラの族長、ガタムの族長、アマレクの族長である。これらはエリパズから出た族長で、エドムの地におった。これらはアダの子らである。</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 36:13; 歴代志上 1:37; 創世記 36:4"> エサウの子リウエルの子らは次のとおりである。すなわちナハテの族長、ゼラの族長、シャンマの族長、ミザの族長。これらはリウエルから出た族長で、エドムの地におった。これらはエサウの妻バスマテの子らである。</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 36:14; 歴代志上 1:35; 創世記 36:5"> エサウの妻アホリバマの子らは次のとおりである。すなわちエウシの族長、ヤラムの族長、コラの族長。これらはアナの娘で、エサウの妻アホリバマから出た族長である。</span>
<span className="v" id="v19" data-v="19"> これらはエサウすなわちエドムの子らで、族長たる者である。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="申命記 2:12; 申命記 2:22; 創世記 14:6"> この地の住民ホリびとセイルの子らは次のとおりである。すなわちロタン、ショバル、ヂベオン、アナ、</span>
<span className="v" id="v21" data-v="21"> デション、エゼル、デシャン。これらはセイルの子ホリびとから出た族長で、エドムの地におった。</span>
<span className="v" id="v22" data-v="22" data-xref="歴代志上 1:39"> ロタンの子らはホリ、ヘマムであり、ロタンの妹はテムナであった。</span>
<span className="v" id="v23" data-v="23" data-xref="歴代志上 1:40"> ショバルの子らは次のとおりである。すなわちアルワン、マナハテ、エバル、シポ、オナム。</span>
<span className="v" id="v24" data-v="24" data-xref="申命記 2:10; サムエル記下 18:9; 列王紀上 4:28"> ヂベオンの子らは次のとおりである。すなわちアヤとアナ。このアナは父ヂベオンのろばを飼っていた時、荒野で温泉を発見した者である。</span>
<span className="v" id="v25" data-v="25" data-xref="創世記 36:2; 創世記 36:18; 歴代志上 1:41"> アナの子らは次のとおりである。すなわちデションとアホリバマ。アホリバマはアナの娘である。</span>
<span className="v" id="v26" data-v="26" data-xref="歴代志上 1:41"> デションの子らは次のとおりである。すなわちヘムダン、エシバン、イテラン、ケラン。</span>
<span className="v" id="v27" data-v="27" data-xref="歴代志上 1:42; 創世記 36:21; 歴代志上 1:38"> エゼルの子らは次のとおりである。すなわちビルハン、ザワン、アカン。</span>
<span className="v" id="v28" data-v="28" data-xref="哀歌 4:21; ヨブ記 1:1; エレミヤ書 25:20"> デシャンの子らは次のとおりである。すなわちウズとアラン。</span>
<span className="v" id="v29" data-v="29" data-xref="創世記 36:20; 創世記 36:28; 歴代志上 1:41–42"> ホリびとから出た族長は次のとおりである。すなわちロタンの族長、ショバルの族長、ヂベオンの族長、アナの族長、</span>
<span className="v" id="v30" data-v="30" data-xref="ダニエル書 7:23; イザヤ書 23:15; 列王紀下 11:19"> デションの族長、エゼルの族長、デシャンの族長。これらはホリびとから出た族長であって、その氏族に従ってセイルの地におった者である。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="創世記 17:6; 歴代志上 1:43–50; 創世記 17:16"> イスラエルの人々を治める王がまだなかった時、エドムの地を治めた王たちは次のとおりである。</span>
<span className="v" id="v32" data-v="32"> ベオルの子ベラはエドムを治め、その都の名はデナバであった。</span>
<span className="v" id="v33" data-v="33" data-xref="エレミヤ書 49:13; エレミヤ書 49:22; アモス書 1:12"> ベラが死んで、ボズラのゼラの子ヨバブがこれに代って王となった。</span>
<span className="v" id="v34" data-v="34" data-xref="創世記 36:11; ヨブ記 2:11; 創世記 36:15"> ヨバブが死んで、テマンびとの地のホシャムがこれに代って王となった。</span>
<span className="v" id="v35" data-v="35"> ホシャムが死んで、ベダデの子ハダデがこれに代って王となった。彼はモアブの野でミデアンを撃った者である。その都の名はアビテであった。</span>
<span className="v" id="v36" data-v="36" data-xref="歴代志上 1:47"> ハダデが死んで、マスレカのサムラがこれに代って王となった。</span>
<span className="v" id="v37" data-v="37" data-xref="歴代志上 1:48; 創世記 10:11"> サムラが死んでユフラテ川のほとりにあるレホボテのサウルがこれに代って王となった。</span>
<span className="v" id="v38" data-v="38"> サウルが死んでアクボルの子バアル・ハナンがこれに代って王となった。</span>
<span className="v" id="v39" data-v="39" data-xref="出エジプト記 15:15; 歴代志上 1:50"> アクボルの子バアル・ハナンが死んで、ハダルがこれに代って王となった。その都の名はパウであった。その妻の名はメヘタベルといって、メザハブの娘マテレデの娘であった。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="歴代志上 1:51–54; 出エジプト記 15:15; 創世記 36:31"> エサウから出た族長の名は、その氏族と住所と名に従って言えば次のとおりである。すなわちテムナの族長、アルワの族長、エテテの族長、</span>
<span className="v" id="v41" data-v="41"> アホリバマの族長、エラの族長、ピノンの族長、</span>
<span className="v" id="v42" data-v="42"> ケナズの族長、テマンの族長、ミブザルの族長、</span>
<span className="v" id="v43" data-v="43" data-xref="創世記 45:8; 歴代志上 4:14; 創世記 25:30"> マグデエルの族長、イラムの族長。これらはエドムの族長たちであって、その領地内の住所に従っていったものである。エドムびとの先祖はエサウである。</span>
</div>

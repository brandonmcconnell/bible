<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="創世記 9:7; 創世記 1:28; 創世記 8:17"> 神はノアとその子らとを祝福して彼らに言われた、「生めよ、ふえよ、地に満ちよ。</span>
<span className="v" id="v2" data-v="2" data-xref="詩篇 8:4–8; 創世記 1:28; ヤコブの手紙 3:7"> 地のすべての獣、空のすべての鳥、地に這うすべてのもの、海のすべての魚は恐れおののいて、あなたがたの支配に服し、</span>
<span className="v" id="v3" data-v="3" data-xref="ローマ人への手紙 14:14; コロサイ人への手紙 2:21–22; コリント人への第一の手紙 10:31"> すべて生きて動くものはあなたがたの食物となるであろう。さきに青草をあなたがたに与えたように、わたしはこれらのものを皆あなたがたに与える。</span>
<span className="v" id="v4" data-v="4" data-xref="申命記 12:23; 申命記 15:23; 申命記 12:16"> しかし肉を、その命である血のままで、食べてはならない。</span>
<span className="v" id="v5" data-v="5" data-xref="出エジプト記 21:28–29; 出エジプト記 21:12; 創世記 4:9–10"> あなたがたの命の血を流すものには、わたしは必ず報復するであろう。いかなる獣にも報復する。兄弟である人にも、わたしは人の命のために、報復するであろう。</span>
<span className="v" id="v6" data-v="6" data-xref="レビ記 24:17; マタイによる福音書 26:52; ヨハネの黙示録 13:10"> <span className="pl pl-1">人の血を流すものは、人に血を流される、</span><br /><span className="pl pl-1">神が自分のかたちに人を造られたゆえに。</span></span>
<span className="v" id="v7" data-v="7" data-xref="創世記 1:28; 創世記 9:1; 創世記 9:19"> <span className="pl pl-1">あなたがたは、生めよ、ふえよ、</span><br /><span className="pl pl-1">地に群がり、地の上にふえよ」。</span></span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8"> 神はノアおよび共にいる子らに言われた、</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 6:18; イザヤ書 54:9–10; ローマ人への手紙 1:3"> 「わたしはあなたがた及びあなたがたの後の子孫と契約を立てる。</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 8:1; 創世記 9:15–16; 詩篇 36:5–6"> またあなたがたと共にいるすべての生き物、あなたがたと共にいる鳥、家畜、地のすべての獣、すなわち、すべて箱舟から出たものは、地のすべての獣にいたるまで、わたしはそれと契約を立てよう。</span>
<span className="v" id="v11" data-v="11" data-xref="イザヤ書 54:9; 創世記 8:21–22; 創世記 7:21–23"> わたしがあなたがたと立てるこの契約により、すべて肉なる者は、もはや洪水によって滅ぼされることはなく、また地を滅ぼす洪水は、再び起らないであろう」。</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 17:11; マタイによる福音書 26:26–28; 出エジプト記 12:13"> さらに神は言われた、「これはわたしと、あなたがた及びあなたがたと共にいるすべての生き物との間に代々かぎりなく、わたしが立てる契約のしるしである。</span>
<span className="v" id="v13" data-v="13" data-xref="エゼキエル書 1:28; ヨハネの黙示録 4:3; ヨハネの黙示録 10:1"> すなわち、わたしは雲の中に、にじを置く。これがわたしと地との間の契約のしるしとなる。</span>
<span className="v" id="v14" data-v="14"> わたしが雲を地の上に起すとき、にじは雲の中に現れる。</span>
<span className="v" id="v15" data-v="15" data-xref="申命記 7:9; エゼキエル書 16:60; イザヤ書 54:8–10"> こうして、わたしは、わたしとあなたがた、及びすべて肉なるあらゆる生き物との間に立てた契約を思いおこすゆえ、水はふたたび、すべて肉なる者を滅ぼす洪水とはならない。</span>
<span className="v" id="v16" data-v="16" data-xref="イザヤ書 54:8–10; エレミヤ書 32:40; サムエル記下 23:5"> にじが雲の中に現れるとき、わたしはこれを見て、神が地上にあるすべて肉なるあらゆる生き物との間に立てた永遠の契約を思いおこすであろう」。</span>
<span className="v" id="v17" data-v="17"> そして神はノアに言われた、「これがわたしと地にあるすべて肉なるものとの間に、わたしが立てた契約のしるしである」。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="創世記 10:1; 創世記 10:6; 創世記 9:25–27"> 箱舟から出たノアの子らはセム、ハム、ヤペテであった。ハムはカナンの父である。</span>
<span className="v" id="v19" data-v="19" data-xref="歴代志上 1:4–28; 創世記 8:17; 創世記 5:32"> この三人はノアの子らで、全地の民は彼らから出て、広がったのである。</span>
</div>
<div className="bp poetry">
<span className="v" id="v20" data-v="20" data-xref="申命記 20:6; 箴言 10:11; イザヤ書 28:24–26"> さてノアは農夫となり、ぶどう畑をつくり始めたが、</span>
<span className="v" id="v21" data-v="21" data-xref="箴言 20:1; ハバクク書 2:15–16; 箴言 23:31–32"> 彼はぶどう酒を飲んで酔い、天幕の中で裸になっていた。</span>
<span className="v" id="v22" data-v="22" data-xref="箴言 30:17; ガラテヤ人への手紙 6:1; マタイによる福音書 18:15"> カナンの父ハムは父の裸を見て、外にいるふたりの兄弟に告げた。</span>
<span className="v" id="v23" data-v="23" data-xref="ガラテヤ人への手紙 6:1; 出エジプト記 20:12; テモテヘの第一の手紙 5:17"> セムとヤペテとは着物を取って、肩にかけ、うしろ向きに歩み寄って、父の裸をおおい、顔をそむけて父の裸を見なかった。</span>
<span className="v" id="v24" data-v="24"> やがてノアは酔いがさめて、末の子が彼にした事を知ったとき、</span>
<span className="v" id="v25" data-v="25" data-xref="ヨシュア記 9:23; 申命記 27:16; 士師記 1:28–30"> 彼は言った、<br /><span className="pl pl-1">「カナンはのろわれよ。</span><br /><span className="pl pl-1">彼はしもべのしもべとなって、</span><br /><span className="pl pl-1">その兄弟たちに仕える」。</span></span>
<span className="v" id="v26" data-v="26" data-xref="詩篇 144:15; 創世記 12:1–3; ルカによる福音書 3:23–36"> <span className="pl pl-1">また言った、</span><br /><span className="pl pl-1">「セムの神、主はほむべきかな、</span><br /><span className="pl pl-1">カナンはそのしもべとなれ。</span></span>
<span className="v" id="v27" data-v="27" data-xref="ローマ人への手紙 11:12; ローマ人への手紙 15:12; ヘブル人への手紙 11:9–10"> <span className="pl pl-1">神はヤペテを大いならしめ、</span><br /><span className="pl pl-1">セムの天幕に彼を住まわせられるように。</span><br /><span className="pl pl-1">カナンはそのしもべとなれ」。</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28"> ノアは洪水の後、なお三百五十年生きた。</span>
<span className="v" id="v29" data-v="29" data-xref="創世記 5:27; 詩篇 90:10; 創世記 5:32"> ノアの年は合わせて九百五十歳であった。そして彼は死んだ。</span>
</div>

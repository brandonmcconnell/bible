<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="詩篇 12:6; 創世記 18:10; 創世記 18:14"> 主は、さきに言われたようにサラを顧み、告げられたようにサラに行われた。</span>
<span className="v" id="v2" data-v="2" data-xref="ガラテヤ人への手紙 4:22; ヘブル人への手紙 11:11; 創世記 18:10"> サラはみごもり、神がアブラハムに告げられた時になって、年老いたアブラハムに男の子を産んだ。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 17:19; ローマ人への手紙 9:7; 創世記 21:6"> アブラハムは生れた子、サラが産んだ男の子の名をイサクと名づけた。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行伝 7:8; 申命記 12:32; ヨハネによる福音書 7:22–23"> アブラハムは神が命じられたように八日目にその子イサクに割礼を施した。</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 17:17; ローマ人への手紙 4:19; 創世記 17:1"> アブラハムはその子イサクが生れた時百歳であった。</span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 126:2; イザヤ書 54:1; 創世記 17:17"> そしてサラは言った、「神はわたしを笑わせてくださった。聞く者は皆わたしのことで笑うでしょう」。</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 18:11–12; イザヤ書 66:8; テサロニケ人への第二の手紙 1:10"> また言った、「サラが子に乳を飲ませるだろうと、だれがアブラハムに言い得たであろう。それなのに、わたしは彼が年とってから、子を産んだ」。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="サムエル記上 1:22; ホセア書 1:8; 創世記 40:20"> さて、おさなごは育って乳離れした。イサクが乳離れした日にアブラハムは盛んなふるまいを設けた。</span>
<span className="v" id="v9" data-v="9" data-xref="ガラテヤ人への手紙 4:29; 創世記 16:15; ガラテヤ人への手紙 4:22"> サラはエジプトの女ハガルのアブラハムに産んだ子が、自分の子イサクと遊ぶのを見て、</span>
<span className="v" id="v10" data-v="10" data-xref="ヨハネによる福音書 8:35; ヨハネの第一の手紙 2:19; ガラテヤ人への手紙 4:22–31"> アブラハムに言った、「このはしためとその子を追い出してください。このはしための子はわたしの子イサクと共に、世継となるべき者ではありません」。</span>
<span className="v" id="v11" data-v="11" data-xref="ヘブル人への手紙 12:11; 創世記 17:18; マタイによる福音書 10:37"> この事で、アブラハムはその子のために非常に心配した。</span>
<span className="v" id="v12" data-v="12" data-xref="ヘブル人への手紙 11:18; ローマ人への手紙 9:7–8; 創世記 17:19"> 神はアブラハムに言われた、「あのわらべのため、またあなたのはしためのために心配することはない。サラがあなたに言うことはすべて聞きいれなさい。イサクに生れる者が、あなたの子孫と唱えられるからです。</span>
<span className="v" id="v13" data-v="13" data-xref="創世記 16:10; 創世記 17:20; 創世記 21:18"> しかし、はしための子もあなたの子ですから、これをも、一つの国民とします」。</span>
<span className="v" id="v14" data-v="14" data-xref="伝道の書 9:10; 詩篇 119:60; 創世記 16:7"> そこでアブラハムは明くる朝はやく起きて、パンと水の皮袋とを取り、ハガルに与えて、肩に負わせ、その子を連れて去らせた。ハガルは去ってベエルシバの荒野にさまよった。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="列王紀下 3:9; 詩篇 63:1; エレミヤ書 14:3"> やがて皮袋の水が尽きたので、彼女はその子を木の下におき、</span>
<span className="v" id="v16" data-v="16" data-xref="イザヤ書 49:15; 創世記 29:11; サムエル記上 24:16"> 「わたしはこの子の死ぬのを見るに忍びない」と言って、矢の届くほど離れて行き、子供の方に向いてすわった。彼女が子供の方に向いてすわったとき、子供は声をあげて泣いた。</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 16:11; 詩篇 50:15; 出エジプト記 3:7"> 神はわらべの声を聞かれ、神の使は天からハガルを呼んで言った、「ハガルよ、どうしたのか。恐れてはいけない。神はあそこにいるわらべの声を聞かれた。</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 21:13; 創世記 16:10; 創世記 17:20"> 立って行き、わらべを取り上げてあなたの手に抱きなさい。わたしは彼を大いなる国民とするであろう」。</span>
<span className="v" id="v19" data-v="19" data-xref="民数記 22:31; 列王紀下 6:17–20; イザヤ書 35:5–6"> 神がハガルの目を開かれたので、彼女は水の井戸のあるのを見た。彼女は行って皮袋に水を満たし、わらべに飲ませた。</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 28:15; 創世記 39:21; 創世記 16:12"> 神はわらべと共にいまし、わらべは成長した。彼は荒野に住んで弓を射る者となった。</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 26:34–35; 創世記 24:3–4; 民数記 12:16"> 彼はパランの荒野に住んだ。母は彼のためにエジプトの国から妻を迎えた。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="ヨシュア記 3:7; 創世記 26:26; 創世記 26:28"> そのころアビメレクとその軍勢の長ピコルはアブラハムに言った、「あなたが何事をなさっても、神はあなたと共におられる。</span>
<span className="v" id="v23" data-v="23" data-xref="ヨシュア記 2:12; 創世記 20:14; ヘブル人への手紙 6:16"> それゆえ、今ここでわたしをも、わたしの子をも、孫をも欺かないと、神をさしてわたしに誓ってください。わたしがあなたに親切にしたように、あなたもわたしと、このあなたの寄留の地とに、しなければなりません」。</span>
<span className="v" id="v24" data-v="24" data-xref="ヘブル人への手紙 6:16; 創世記 14:13; ローマ人への手紙 12:18"> アブラハムは言った、「わたしは誓います」。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="創世記 26:15–22; 創世記 29:8; 箴言 25:9"> アブラハムはアビメレクの家来たちが、水の井戸を奪い取ったことについてアビメルクを責めた。</span>
<span className="v" id="v26" data-v="26" data-xref="創世記 13:7; 列王紀下 5:20–24"> しかしアビメレクは言った、「だれがこの事をしたかわたしは知りません。あなたもわたしに告げたことはなく、わたしもきょうまで聞きませんでした」。</span>
<span className="v" id="v27" data-v="27" data-xref="創世記 14:22–23; イザヤ書 32:8; ローマ人への手紙 1:31"> そこでアブラハムは羊と牛とを取ってアビメレクに与え、ふたりは契約を結んだ。</span>
<span className="v" id="v28" data-v="28"> アブラハムが雌の小羊七頭を分けて置いたところ、</span>
<span className="v" id="v29" data-v="29" data-xref="サムエル記上 15:14; 創世記 33:8; 出エジプト記 12:26"> アビメレクはアブラハムに言った、「あなたがこれらの雌の小羊七頭を分けて置いたのは、なんのためですか」。</span>
<span className="v" id="v30" data-v="30" data-xref="創世記 31:52; ヨシュア記 24:27; ヨシュア記 22:27–28"> アブラハムは言った、「あなたはわたしの手からこれらの雌の小羊七頭を受け取って、わたしがこの井戸を掘ったことの証拠としてください」。</span>
<span className="v" id="v31" data-v="31" data-xref="創世記 26:33; 創世記 21:14; 列王紀上 4:25"> これによってその所をベエルシバと名づけた。彼らがふたりそこで誓いをしたからである。</span>
<span className="v" id="v32" data-v="32" data-xref="出エジプト記 13:17; 創世記 21:27; 士師記 13:1"> このように彼らはベエルシバで契約を結び、アビメレクとその軍勢の長ピコルは立ってペリシテの地に帰った。</span>
<span className="v" id="v33" data-v="33" data-xref="テモテヘの第一の手紙 1:17; イザヤ書 40:28; 詩篇 90:2"> アブラハムはベエルシバに一本のぎょりゅうの木を植え、その所で永遠の神、主の名を呼んだ。</span>
<span className="v" id="v34" data-v="34" data-xref="歴代志上 29:15; ペテロの第一の手紙 2:11; ヘブル人への手紙 11:9"> こうしてアブラハムは長い間ペリシテびとの地にとどまった。</span>
</div>

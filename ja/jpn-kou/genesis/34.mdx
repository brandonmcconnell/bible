<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 30:21; エレミヤ書 2:36; 創世記 30:13"> レアがヤコブに産んだ娘デナはその地の女たちに会おうと出かけて行ったが、</span>
<span className="v" id="v2" data-v="2" data-xref="マタイによる福音書 5:28; ヨブ記 31:1; ヨブ記 31:9"> その地のつかさ、ヒビびとハモルの子シケムが彼女を見て、引き入れ、これと寝てはずかしめた。</span>
<span className="v" id="v3" data-v="3" data-xref="ホセア書 2:14; イザヤ書 40:2; 歴代志下 30:22"> 彼は深くヤコブの娘デナを慕い、この娘を愛して、ねんごろに娘に語った。</span>
<span className="v" id="v4" data-v="4" data-xref="士師記 14:2; サムエル記下 13:13; 創世記 21:21"> シケムは父ハモルに言った、「この娘をわたしの妻にめとってください」。</span>
<span className="v" id="v5" data-v="5" data-xref="サムエル記下 13:22; レビ記 10:3; サムエル記上 10:27"> さてヤコブはシケムが、娘デナを汚したことを聞いたけれども、その子らが家畜を連れて野にいたので、彼らの帰るまで黙っていた。</span>
<span className="v" id="v6" data-v="6"> シケムの父ハモルはヤコブと話し合おうと、ヤコブの所に出てきた。</span>
<span className="v" id="v7" data-v="7" data-xref="ヨシュア記 7:15; 士師記 20:6; 申命記 22:21"> ヤコブの子らは野から帰り、この事を聞いて、悲しみ、かつ非常に怒った。シケムがヤコブの娘と寝て、イスラエルに愚かなことをしたためで、こんなことは、してはならぬ事だからである。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="列王紀上 11:2; 詩篇 119:20; 詩篇 84:2"> ハモルは彼らと語って言った、「わたしの子シケムはあなたがたの娘を心に慕っています。どうか彼女を彼の妻にください。</span>
<span className="v" id="v9" data-v="9" data-xref="申命記 7:3; 創世記 26:34–35; 創世記 19:14"> あなたがたはわたしたちと婚姻し、あなたがたの娘をわたしたちに与え、わたしたちの娘をあなたがたにめとってください。</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 20:15; 創世記 47:27; 創世記 42:34"> こうしてあなたがたとわたしたちとは一緒に住みましょう。地はあなたがたの前にあります。ここに住んで取引し、ここで財産を獲なさい」。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 33:15; 創世記 18:3"> シケムはまたデナの父と兄弟たちとに言った、「あなたがたの前に恵みを得させてください。あなたがたがわたしに言われるものは、なんでもさしあげましょう。</span>
<span className="v" id="v12" data-v="12" data-xref="出エジプト記 22:16–17; 申命記 22:28–29; サムエル記上 18:25–27"> たくさんの結納金と贈り物とをお求めになっても、あなたがたの言われるとおりさしあげます。ただこの娘はわたしの妻にください」。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="創世記 25:27–34; イザヤ書 59:13; ヨブ記 13:4"> しかし、ヤコブの子らはシケムが彼らの妹デナを汚したので、シケムとその父ハモルに偽って答え、</span>
<span className="v" id="v14" data-v="14" data-xref="マタイによる福音書 23:1–39; サムエル記下 15:7; 創世記 17:11"> 彼らに言った、「われわれは割礼を受けない者に妹をやる事はできません。それはわれわれの恥とするところですから。</span>
<span className="v" id="v15" data-v="15" data-xref="ガラテヤ人への手紙 4:12"> ただ、こうなさればわれわれはあなたがたに同意します。もしあなたがたのうち男子がみな割礼を受けて、われわれのようになるなら、</span>
<span className="v" id="v16" data-v="16"> われわれの娘をあなたがたに与え、あなたがたの娘をわれわれにめとりましょう。そしてわれわれはあなたがたと一緒に住んで一つの民となりましょう。</span>
<span className="v" id="v17" data-v="17"> けれども、もしあなたがたがわれわれに聞かず、割礼を受けないなら、われわれは娘を連れて行きます」。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18"> 彼らの言葉がハモルとハモルの子シケムとの心にかなったので、</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行伝 17:12; 使徒行伝 13:50; サムエル記上 22:14"> 若者は、ためらわずにこの事をした。彼がヤコブの娘を愛したからである。また彼は父の家のうちで一番重んじられた者であった。</span>
<span className="v" id="v20" data-v="20" data-xref="ルツ記 4:1; 箴言 31:23; アモス書 5:12"> そこでハモルとその子シケムとは町の門に行き、町の人々に語って言った、</span>
<span className="v" id="v21" data-v="21"> 「この人々はわれわれと親しいから、この地に住まわせて、ここで取引をさせよう。地は広く、彼らをいれるにじゅうぶんである。そしてわれわれは彼らの娘を妻にめとり、われわれの娘を彼らに与えよう。</span>
<span className="v" id="v22" data-v="22"> 彼らが割礼を受けているように、もしわれわれのうちの男子が皆、割礼を受けるなら、ただこの事だけで、この人々はわれわれに同意し、われわれと一緒に住んで一つの民となるのだ。</span>
<span className="v" id="v23" data-v="23" data-xref="箴言 1:12–13; ヨハネによる福音書 6:26–27; ヨハネによる福音書 2:16"> そうすれば彼らの家畜と財産とすべての獣とは、われわれのものとなるではないか。ただわれわれが彼らに同意すれば、彼らはわれわれと一緒に住むであろう」。</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 23:10; コリント人への第一の手紙 7:19; イザヤ書 1:10–16"> そこで町の門に出入りする者はみなハモルとその子シケムとに聞き従って、町の門に出入りするすべての男子は割礼を受けた。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="創世記 49:5–7; 創世記 29:33–34; 民数記 31:7"> 三日目になって彼らが痛みを覚えている時、ヤコブのふたりの子、すなわちデナの兄弟シメオンとレビとは、おのおのつるぎを取って、不意に町を襲い、男子をことごとく殺し、</span>
<span className="v" id="v26" data-v="26" data-xref="サムエル記下 2:26; 申命記 32:42; イザヤ書 31:8"> またつるぎの刃にかけてハモルとその子シケムとを殺し、シケムの家からデナを連れ出した。</span>
<span className="v" id="v27" data-v="27" data-xref="ヨシュア記 7:13; ヨシュア記 7:21; 出エジプト記 2:14"> そしてヤコブの子らは殺された人々をはぎ、町をかすめた。彼らが妹を汚したからである。</span>
<span className="v" id="v28" data-v="28" data-xref="ヨブ記 1:15–16; 申命記 8:17–18; ヨブ記 20:5"> すなわち羊、牛、ろば及び町にあるものと、野にあるもの、</span>
<span className="v" id="v29" data-v="29"> 並びにすべての貨財を奪い、その子女と妻たちを皆とりこにし、家の中にある物をことごとくかすめた。</span>
<span className="v" id="v30" data-v="30" data-xref="詩篇 105:12; ヨシュア記 7:25; 出エジプト記 5:21"> そこでヤコブはシメオンとレビとに言った、「あなたがたはわたしをこの地の住民、カナンびととペリジびとに忌みきらわせ、わたしに迷惑をかけた。わたしは、人数が少ないから、彼らが集まってわたしを攻め撃つならば、わたしも家族も滅ぼされるであろう」。</span>
<span className="v" id="v31" data-v="31" data-xref="箴言 6:34; 創世記 34:13; 創世記 49:7"> 彼らは言った、「わたしたちの妹を遊女のように彼が扱ってよいのですか」。</span>
</div>

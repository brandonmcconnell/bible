<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ガラテヤ人への手紙 4:24; 創世記 12:16; 創世記 15:2–3"> アブラムの妻サライは子を産まなかった。彼女にひとりのつかえめがあった。エジプトの女で名をハガルといった。</span>
<span className="v" id="v2" data-v="2" data-xref="出エジプト記 21:4; 創世記 18:10; 創世記 3:17"> サライはアブラムに言った、「主はわたしに子をお授けになりません。どうぞ、わたしのつかえめの所におはいりください。彼女によってわたしは子をもつことになるでしょう」。アブラムはサライの言葉を聞きいれた。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 16:5; 創世記 12:4–5; サムエル記下 5:13"> アブラムの妻サライはそのつかえめエジプトの女ハガルをとって、夫アブラムに妻として与えた。これはアブラムがカナンの地に十年住んだ後であった。</span>
<span className="v" id="v4" data-v="4" data-xref="箴言 30:23; サムエル記下 6:16; コリント人への第一の手紙 13:4–5"> 彼はハガルの所にはいり、ハガルは子をはらんだ。彼女は自分のはらんだのを見て、女主人を見下げるようになった。</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 31:53; 出エジプト記 5:21; 詩篇 7:8"> そこでサライはアブラムに言った、「わたしが受けた害はあなたの責任です。わたしのつかえめをあなたのふところに与えたのに、彼女は自分のはらんだのを見て、わたしを見下さげます。どうか、主があなたとわたしの間をおさばきになるように」。</span>
<span className="v" id="v6" data-v="6" data-xref="エレミヤ書 38:5; 箴言 14:29; ペテロの第一の手紙 3:7"> アブラムはサライに言った、「あなたのつかえめはあなたの手のうちにある。あなたの好きなように彼女にしなさい」。そしてサライが彼女を苦しめたので、彼女はサライの顔を避けて逃げた。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="創世記 25:18; 出エジプト記 15:22; 創世記 21:17"> 主の使は荒野にある泉のほとり、すなわちシュルの道にある泉のほとりで、彼女に会い、</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 3:9; 創世記 4:10; 伝道の書 10:4"> そして言った、「サライのつかえめハガルよ、あなたはどこからきたのですか、またどこへ行くのですか」。彼女は言った、「わたしは女主人サライの顔を避けて逃げているのです」。</span>
<span className="v" id="v9" data-v="9" data-xref="ペテロの第一の手紙 5:5–6; 伝道の書 10:4; テトスヘの手紙 2:9"> 主の使は彼女に言った、「あなたは女主人のもとに帰って、その手に身を任せなさい」。</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 17:20; 詩篇 83:6–7; 創世記 25:12–18"> 主の使はまた彼女に言った、「わたしは大いにあなたの子孫を増して、数えきれないほどに多くしましょう」。</span>
<span className="v" id="v11" data-v="11" data-xref="出エジプト記 2:23–24; 出エジプト記 3:7; イザヤ書 7:14"> 主の使はまた彼女に言った、「あなたは、みごもっています。あなたは男の子を産むでしょう。名をイシマエルと名づけなさい。主があなたの苦しみを聞かれたのです。</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 25:18; 創世記 21:20; ヨブ記 39:5–8"> 彼は野ろばのような人となり、その手はすべての人に逆らい、すべての人の手は彼に逆らい、彼はすべての兄弟に敵して住むでしょう」。</span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 139:1–12; 創世記 32:30; 箴言 5:21"> そこで、ハガルは自分に語られた主の名を呼んで、「あなたはエル・ロイです」と言った。彼女が「ここでも、わたしを見ていられるかたのうしろを拝めたのか」と言ったことによる。</span>
<span className="v" id="v14" data-v="14" data-xref="創世記 24:62; 創世記 25:11; 創世記 21:31"> それでその井戸は「ベエル・ラハイ・ロイ」と呼ばれた。これはカデシとベレデの間にある。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="創世記 25:12; 創世記 21:9–21; 創世記 17:25–26"> ハガルはアブラムに男の子を産んだ。アブラムはハガルが産んだ子の名をイシマエルと名づけた。</span>
<span className="v" id="v16" data-v="16"> ハガルがイシマエルをアブラムに産んだ時、アブラムは八十六歳であった。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 12:9–20; ヨシュア記 10:40; サムエル記下 24:7"> アブラムは妻とすべての持ち物を携え、エジプトを出て、ネゲブに上った。ロトも彼と共に上った。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="創世記 24:35; 詩篇 112:1–3; 創世記 26:12–13"> アブラムは家畜と金銀に非常に富んでいた。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 12:8–9; 創世記 12:6"> 彼はネゲブから旅路を進めてベテルに向かい、ベテルとアイの間の、さきに天幕を張った所に行った。</span>
<span className="v" id="v4" data-v="4" data-xref="エレミヤ書 29:12; 創世記 12:7–8; イザヤ書 58:9"> すなわち彼が初めに築いた祭壇の所に行き、その所でアブラムは主の名を呼んだ。</span>
<span className="v" id="v5" data-v="5" data-xref="エレミヤ書 49:29; 創世記 25:27; 創世記 4:20"> アブラムと共に行ったロトも羊、牛および天幕を持っていた。</span>
<span className="v" id="v6" data-v="6" data-xref="創世記 36:6–7; 伝道の書 5:10–11; テモテヘの第一の手紙 6:9"> その地は彼らをささえて共に住ませることができなかった。彼らの財産が多かったため、共に住めなかったのである。</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 26:20; 創世記 12:6; ヤコブの手紙 3:16"> アブラムの家畜の牧者たちとロトの家畜の牧者たちの間に争いがあった。そのころカナンびととペリジびとがその地に住んでいた。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="コリント人への第一の手紙 6:6–7; 使徒行伝 7:26; 詩篇 133:1"> アブラムはロトに言った、「わたしたちは身内の者です。わたしとあなたの間にも、わたしの牧者たちとあなたの牧者たちの間にも争いがないようにしましょう。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 20:15; 創世記 34:10; ペテロの第一の手紙 3:8–12"> 全地はあなたの前にあるではありませんか。どうかわたしと別れてください。あなたが左に行けばわたしは右に行きます。あなたが右に行けばわたしは左に行きましょう」。</span>
<span className="v" id="v10" data-v="10" data-xref="申命記 34:3; イザヤ書 51:3; 創世記 14:8"> ロトが目を上げてヨルダンの低地をあまねく見わたすと、主がソドムとゴモラを滅ぼされる前であったから、ゾアルまで主の園のように、またエジプトの地のように、すみずみまでよく潤っていた。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 13:9; ペテロの第一の手紙 2:17; ヘブル人への手紙 10:25"> そこでロトはヨルダンの低地をことごとく選びとって東に移った。こうして彼らは互に別れた。</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 19:29; 創世記 14:12; 創世記 19:1"> アブラムはカナンの地に住んだが、ロトは低地の町々に住み、天幕をソドムに移した。</span>
<span className="v" id="v13" data-v="13" data-xref="ペテロの第二の手紙 2:10; ペテロの第二の手紙 2:6–8; ユダの手紙 1:7"> ソドムの人々はわるく、主に対して、はなはだしい罪びとであった。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="イザヤ書 49:18; 申命記 3:27; 創世記 28:14"> ロトがアブラムに別れた後に、主はアブラムに言われた、「目をあげてあなたのいる所から北、南、東、西を見わたしなさい。</span>
<span className="v" id="v15" data-v="15" data-xref="歴代志下 20:7; 創世記 35:12; 創世記 15:18"> すべてあなたが見わたす地は、永久にあなたとあなたの子孫に与えます。</span>
<span className="v" id="v16" data-v="16" data-xref="創世記 28:14; 民数記 23:10; 創世記 32:12"> わたしはあなたの子孫を地のちりのように多くします。もし人が地のちりを数えることができるなら、あなたの子孫も数えられることができましょう。</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 13:15; 民数記 13:17–24"> あなたは立って、その地をたてよこに行き巡りなさい。わたしはそれをあなたに与えます」。</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 18:1; 創世記 8:20; 創世記 35:27"> アブラムは天幕を移してヘブロンにあるマムレのテレビンの木のかたわらに住み、その所で主に祭壇を築いた。</span>
</div>

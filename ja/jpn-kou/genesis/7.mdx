<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マタイによる福音書 24:37–39; ペテロの第二の手紙 2:5–9; 創世記 6:9"> 主はノアに言われた、「あなたと家族とはみな箱舟にはいりなさい。あなたがこの時代の人々の中で、わたしの前に正しい人であるとわたしは認めたからである。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 8:20; レビ記 10:10; レビ記 11:1–47"> あなたはすべての清い獣の中から雄と雌とを七つずつ取り、清くない獣の中から雄と雌とを二つずつ取り、</span>
<span className="v" id="v3" data-v="3"> また空の鳥の中から雄と雌とを七つずつ取って、その種類が全地のおもてに生き残るようにしなさい。</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 6:13; 創世記 7:12; 創世記 7:17"> 七日の後、わたしは四十日四十夜、地に雨を降らせて、わたしの造ったすべての生き物を、地のおもてからぬぐい去ります」。</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 6:22; ルカによる福音書 8:21; 出エジプト記 39:32"> ノアはすべて主が命じられたようにした。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="創世記 5:32; 創世記 8:13"> さて洪水が地に起った時、ノアは六百歳であった。</span>
<span className="v" id="v7" data-v="7" data-xref="ルカによる福音書 17:27; 創世記 6:18; マタイによる福音書 24:38"> ノアは子らと、妻と、子らの妻たちと共に洪水を避けて箱舟にはいった。</span>
<span className="v" id="v8" data-v="8"> また清い獣と、清くない獣と、鳥と、地に這うすべてのものとの、</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 7:16; 創世記 2:19; エレミヤ書 8:7"> 雄と雌とが、二つずつノアのもとにきて、神がノアに命じられたように箱舟にはいった。</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 6:17; 創世記 7:4; ルカによる福音書 17:27"> こうして七日の後、洪水が地に起った。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="創世記 8:2; マラキ書 3:10; 箴言 8:28–29"> それはノアの六百歳の二月十七日であって、その日に大いなる淵の源は、ことごとく破れ、天の窓が開けて、</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 7:4; マタイによる福音書 4:2; 創世記 7:17"> 雨は四十日四十夜、地に降り注いだ。</span>
<span className="v" id="v13" data-v="13" data-xref="創世記 6:18; 創世記 7:1; 創世記 6:10"> その同じ日に、ノアと、ノアの子セム、ハム、ヤペテと、ノアの妻と、その子らの三人の妻とは共に箱舟にはいった。</span>
<span className="v" id="v14" data-v="14" data-xref="創世記 7:8–9; 創世記 7:2–3"> またすべての種類の獣も、すべての種類の家畜も、地のすべての種類の這うものも、すべての種類の鳥も、すべての翼あるものも、皆はいった。</span>
<span className="v" id="v15" data-v="15" data-xref="創世記 6:19–20; イザヤ書 11:6"> すなわち命の息のあるすべての肉なるものが、二つずつノアのもとにきて、箱舟にはいった。</span>
<span className="v" id="v16" data-v="16" data-xref="マタイによる福音書 25:10; ルカによる福音書 13:25; 詩篇 91:1–10"> そのはいったものは、すべて肉なるものの雄と雌とであって、神が彼に命じられたようにはいった。そこで主は彼のうしろの戸を閉ざされた。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="創世記 7:4; 創世記 7:12"> 洪水は四十日のあいだ地上にあった。水が増して箱舟を浮べたので、箱舟は地から高く上がった。</span>
<span className="v" id="v18" data-v="18" data-xref="出エジプト記 14:28; 詩篇 69:15; ヨブ記 22:16"> また水がみなぎり、地に増したので、箱舟は水のおもてに漂った。</span>
<span className="v" id="v19" data-v="19" data-xref="詩篇 104:6–9; 詩篇 46:2–3; ペテロの第二の手紙 3:6"> 水はまた、ますます地にみなぎり、天の下の高い山々は皆おおわれた。</span>
<span className="v" id="v20" data-v="20" data-xref="エレミヤ書 3:23; 詩篇 104:6"> 水はその上、さらに十五キュビトみなぎって、山々は全くおおわれた。</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 6:13; 創世記 7:4; 創世記 6:17"> 地の上に動くすべて肉なるものは、鳥も家畜も獣も、地に群がるすべての這うものも、すべての人もみな滅びた。</span>
<span className="v" id="v22" data-v="22" data-xref="創世記 2:7; 創世記 6:17"> すなわち鼻に命の息のあるすべてのもの、陸にいたすべてのものは死んだ。</span>
<span className="v" id="v23" data-v="23" data-xref="ペテロの第二の手紙 2:5; ペテロの第一の手紙 3:20; ヘブル人への手紙 11:7"> 地のおもてにいたすべての生き物は、人も家畜も、這うものも、空の鳥もみな地からぬぐい去られて、ただノアと、彼と共に箱舟にいたものだけが残った。</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 8:3–4"> 水は百五十日のあいだ地上にみなぎった。</span>
</div>

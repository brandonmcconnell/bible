<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="コリント人への第二の手紙 11:3; コリント人への第二の手紙 11:14; ヨハネの黙示録 12:9"> さて主なる神が造られた野の生き物のうちで、へびが最も狡猾であった。へびは女に言った、「園にあるどの木からも取って食べるなと、ほんとうに神が言われたのですか」。</span>
<span className="v" id="v2" data-v="2" data-xref="詩篇 58:4"> 女はへびに言った、「わたしたちは園の木の実を食べることは許されていますが、</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 2:16–17; コリント人への第二の手紙 6:17; 出エジプト記 19:12–13"> ただ園の中央にある木の実については、これを取って食べるな、これに触れるな、死んではいけないからと、神は言われました」。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネによる福音書 8:44; コリント人への第二の手紙 11:3; テモテヘの第一の手紙 2:14"> へびは女に言った、「あなたがたは決して死ぬことはないでしょう。</span>
<span className="v" id="v5" data-v="5" data-xref="エゼキエル書 28:2; テサロニケ人への第二の手紙 2:4; コリント人への第二の手紙 11:13–15"> それを食べると、あなたがたの目が開け、神のように善悪を知る者となることを、神は知っておられるのです」。</span>
<span className="v" id="v6" data-v="6" data-xref="ヨハネの第一の手紙 2:16; ヤコブの手紙 1:14–15; テモテヘの第一の手紙 2:14"> 女がその木を見ると、それは食べるに良く、目には美しく、賢くなるには好ましいと思われたから、その実を取って食べ、また共にいた夫にも与えたので、彼も食べた。</span>
<span className="v" id="v7" data-v="7" data-xref="イザヤ書 59:6; 創世記 2:25; 創世記 3:5"> すると、ふたりの目が開け、自分たちの裸であることがわかったので、いちじくの葉をつづり合わせて、腰に巻いた。</span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="エレミヤ書 23:24; 箴言 15:3; ヘブル人への手紙 4:13"> 彼らは、日の涼しい風の吹くころ、園の中に主なる神の歩まれる音を聞いた。そこで、人とその妻とは主なる神の顔を避けて、園の木の間に身を隠した。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 4:9; 創世記 16:8; 創世記 18:20–21"> 主なる神は人に呼びかけて言われた、「あなたはどこにいるのか」。</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 2:25; 詩篇 119:120; イザヤ書 47:3"> 彼は答えた、「園の中であなたの歩まれる音を聞き、わたしは裸だったので、恐れて身を隠したのです」。</span>
<span className="v" id="v11" data-v="11" data-xref="ローマ人への手紙 3:20; 創世記 4:10; 詩篇 50:21"> 神は言われた、「あなたが裸であるのを、だれが知らせたのか。食べるなと、命じておいた木から、あなたは取って食べたのか」。</span>
<span className="v" id="v12" data-v="12" data-xref="箴言 28:13; ヤコブの手紙 1:13–15; ヨブ記 31:33"> 人は答えた、「わたしと一緒にしてくださったあの女が、木から取ってくれたので、わたしは食べたのです」。</span>
<span className="v" id="v13" data-v="13" data-xref="コリント人への第二の手紙 11:3; テモテヘの第一の手紙 2:14; 創世記 4:10–12"> そこで主なる神は女に言われた、「あなたは、なんということをしたのです」。女は答えた、「へびがわたしをだましたのです。それでわたしは食べました」。</span>
<span className="v" id="v14" data-v="14" data-xref="ミカ書 7:17; イザヤ書 65:25; 詩篇 72:9"> 主なる神はへびに言われた、<br /><span className="pl pl-1">「おまえは、この事を、したので、</span><br /><span className="pl pl-1">すべての家畜、野のすべての獣のうち、</span><br /><span className="pl pl-1">最ものろわれる。</span><br /><span className="pl pl-1">おまえは腹で、這いあるき、</span><br /><span className="pl pl-1">一生、ちりを食べるであろう。</span></span>
<span className="v" id="v15" data-v="15" data-xref="ローマ人への手紙 16:20; ヨハネの第一の手紙 3:8; ヨハネの黙示録 12:17"> <span className="pl pl-1">わたしは恨みをおく、</span><br /><span className="pl pl-1">おまえと女とのあいだに、</span><br /><span className="pl pl-1">おまえのすえと女のすえとの間に。</span><br /><span className="pl pl-1">彼はおまえのかしらを砕き、</span><br /><span className="pl pl-1">おまえは彼のかかとを砕くであろう」。</span></span>
<span className="v" id="v16" data-v="16" data-xref="テトスヘの手紙 2:5; コロサイ人への手紙 3:18; コリント人への第一の手紙 11:3"> <span className="pl pl-1">つぎに女に言われた、</span><br /><span className="pl pl-1">「わたしはあなたの産みの苦しみを大いに増す。</span><br /><span className="pl pl-1">あなたは苦しんで子を産む。</span><br /><span className="pl pl-1">それでもなお、あなたは夫を慕い、</span><br /><span className="pl pl-1">彼はあなたを治めるであろう」。</span></span>
<span className="v" id="v17" data-v="17" data-xref="ローマ人への手紙 8:20–22; 創世記 5:29; イザヤ書 24:5–6"> <span className="pl pl-1">更に人に言われた、「あなたが妻の言葉を聞いて、食べるなと、わたしが命じた木から取って食べたので、</span><br /><span className="pl pl-1">地はあなたのためにのろわれ、</span><br /><span className="pl pl-1">あなたは一生、苦しんで地から食物を取る。</span></span>
<span className="v" id="v18" data-v="18" data-xref="マタイによる福音書 13:7; ヨブ記 5:5; イザヤ書 7:23"> <span className="pl pl-1">地はあなたのために、いばらとあざみとを生じ、</span><br /><span className="pl pl-1">あなたは野の草を食べるであろう。</span></span>
<span className="v" id="v19" data-v="19" data-xref="伝道の書 12:7; ヨブ記 34:15; 詩篇 104:29"> <span className="pl pl-1">あなたは顔に汗してパンを食べ、ついに土に帰る、</span><br /><span className="pl pl-1">あなたは土から取られたのだから。</span><br /><span className="pl pl-1">あなたは、ちりだから、ちりに帰る」。</span></span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="創世記 2:23; マタイによる福音書 1:23; 創世記 5:29"> さて、人はその妻の名をエバと名づけた。彼女がすべて生きた者の母だからである。</span>
<span className="v" id="v21" data-v="21" data-xref="イザヤ書 61:10; コリント人への第二の手紙 5:21; コリント人への第二の手紙 5:2–3"> 主なる神は人とその妻とのために皮の着物を造って、彼らに着せられた。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="ヨハネの黙示録 2:7; ヨハネの黙示録 22:14; 箴言 3:18"> 主なる神は言われた、「見よ、人はわれわれのひとりのようになり、善悪を知るものとなった。彼は手を伸べ、命の木からも取って食べ、永久に生きるかも知れない」。</span>
<span className="v" id="v23" data-v="23" data-xref="創世記 4:2; 創世記 3:19; 創世記 4:12"> そこで主なる神は彼をエデンの園から追い出して、人が造られたその土を耕させられた。</span>
<span className="v" id="v24" data-v="24" data-xref="ヘブル人への手紙 1:7; 詩篇 104:4; 出エジプト記 25:18–22"> 神は人を追い出し、エデンの園の東に、ケルビムと、回る炎のつるぎとを置いて、命の木の道を守らせられた。</span>
</div>

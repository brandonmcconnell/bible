<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 31:13; ホセア書 12:4; 詩篇 91:15"> ときに神はヤコブに言われた、「あなたは立ってベテルに上り、そこに住んで、あなたがさきに兄エサウの顔を避けてのがれる時、あなたに現れた神に祭壇を造りなさい」。</span>
<span className="v" id="v2" data-v="2" data-xref="出エジプト記 19:14; 出エジプト記 19:10; エゼキエル書 18:31"> ヤコブは、その家族および共にいるすべての者に言った、「あなたがたのうちにある異なる神々を捨て、身を清めて着物を着替えなさい。</span>
<span className="v" id="v3" data-v="3" data-xref="イザヤ書 43:2; 創世記 32:7; 創世記 31:3"> われわれは立ってベテルに上り、その所でわたしの苦難の日にわたしにこたえ、かつわたしの行く道で共におられた神に祭壇を造ろう」。</span>
<span className="v" id="v4" data-v="4" data-xref="士師記 9:6; 申命記 7:25; 出エジプト記 32:20"> そこで彼らは持っている異なる神々と、耳につけている耳輪をことごとくヤコブに与えたので、ヤコブはこれをシケムのほとりにあるテレビンの木の下に埋めた。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="出エジプト記 23:27; 歴代志下 17:10; ヨシュア記 5:1"> そして彼らは、いで立ったが、大いなる恐れが周囲の町々に起ったので、ヤコブの子らのあとを追う者はなかった。</span>
<span className="v" id="v6" data-v="6" data-xref="創世記 28:19; 創世記 28:22; 創世記 12:8"> こうしてヤコブは共にいたすべての人々と一緒にカナンの地にあるルズ、すなわちベテルにきた。</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 35:3; 創世記 35:1; 創世記 28:13"> 彼はそこに祭壇を築き、その所をエル・ベテルと名づけた。彼が兄の顔を避けてのがれる時、神がそこで彼に現れたからである。</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 24:59; サムエル記上 31:13; 士師記 2:5"> 時にリベカのうばデボラが死んで、ベテルのしもの、かしの木の下に葬られた。これによってその木の名をアロン・バクテと呼ばれた。</span>
</div>
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="創世記 35:1; 創世記 18:1; 創世記 26:2"> さてヤコブがパダンアラムから帰ってきた時、神は再び彼に現れて彼を祝福された。</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 17:5; 創世記 32:27–28; 創世記 17:15"> 神は彼に言われた、「あなたの名はヤコブである。しかしあなたの名をもはやヤコブと呼んではならない。あなたの名をイスラエルとしなさい」。こうして彼をイスラエルと名づけられた。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 17:1; 創世記 9:1; 創世記 22:17"> 神はまた彼に言われた、<br /><span className="pl pl-1">「わたしは全能の神である。</span><br /><span className="pl pl-1">あなたは生めよ、またふえよ。</span><br /><span className="pl pl-1">一つの国民、また多くの国民があなたから出て、</span><br /><span className="pl pl-1">王たちがあなたの身から出るであろう。</span></span>
<span className="v" id="v12" data-v="12" data-xref="創世記 12:7; 創世記 28:13; 創世記 26:3–4"> <span className="pl pl-1">わたしはアブラハムとイサクとに与えた地を、</span><br /><span className="pl pl-1">あなたに与えよう。</span><br /><span className="pl pl-1">またあなたの後の子孫にその地を与えよう」。</span></span>
<span className="v" id="v13" data-v="13" data-xref="創世記 17:22; 創世記 18:33; 士師記 6:21"> <span className="pl pl-1">神は彼と語っておられたその場所から彼を離れてのぼられた。</span></span>
<span className="v" id="v14" data-v="14" data-xref="創世記 28:18–19; サムエル記上 7:12; 出エジプト記 17:15"> <span className="pl pl-1">そこでヤコブは神が自分と語られたその場所に、一本の石の柱を立て、その上に灌祭をささげ、また油を注いだ。</span></span>
<span className="v" id="v15" data-v="15" data-xref="創世記 28:19"> <span className="pl pl-1">そしてヤコブは神が自分と語られたその場所をベテルと名づけた。</span></span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="ミカ書 5:2; 創世記 48:7; 列王紀下 5:19"> こうして彼らはベテルを立ったが、エフラタに行き着くまでに、なお隔たりのある所でラケルは産気づき、その産は重かった。</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 30:24; サムエル記上 4:19–21"> その難産に当って、産婆は彼女に言った、「心配することはありません。今度も男の子です」。</span>
<span className="v" id="v18" data-v="18" data-xref="ルカによる福音書 12:20; 使徒行伝 7:59; ルカによる福音書 23:46"> 彼女は死にのぞみ、魂の去ろうとする時、子の名をベノニと呼んだ。しかし、父はこれをベニヤミンと名づけた。</span>
<span className="v" id="v19" data-v="19" data-xref="ミカ書 5:2; 創世記 48:7; ルツ記 4:11"> ラケルは死んでエフラタ、すなわちベツレヘムの道に葬られた。</span>
<span className="v" id="v20" data-v="20" data-xref="サムエル記上 10:2; 創世記 35:14; サムエル記下 18:17–18"> ヤコブはその墓に柱を立てた。これはラケルの墓の柱であって、今日に至っている。</span>
<span className="v" id="v21" data-v="21" data-xref="ミカ書 4:8; ルカによる福音書 2:8"> イスラエルはまた、いで立ってミグダル・エダルの向こうに天幕を張った。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="歴代志上 5:1; レビ記 18:8; サムエル記下 20:3"> イスラエルがその地に住んでいた時、ルベンは父のそばめビルハのところへ行って、これと寝た。イスラエルはこれを聞いた。<br />さてヤコブの子らは十二人であった。</span>
<span className="v" id="v23" data-v="23" data-xref="創世記 30:18–20; 創世記 46:8–15; 創世記 29:32–35"> すなわちレアの子らはヤコブの長子ルベンとシメオン、レビ、ユダ、イッサカル、ゼブルン。</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 30:22–24; 創世記 46:19–22; 創世記 35:16–18"> ラケルの子らはヨセフとベニヤミン。</span>
<span className="v" id="v25" data-v="25" data-xref="創世記 46:23–25; 創世記 37:2; 創世記 30:4–8"> ラケルのつかえめビルハの子らはダンとナフタリ。</span>
<span className="v" id="v26" data-v="26" data-xref="創世記 30:9–13; 創世記 46:16–18; 創世記 25:20"> レアのつかえめジルパの子らはガドとアセル。これらはヤコブの子らであって、パダンアラムで彼に生れた者である。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="創世記 13:18; 創世記 23:19; 創世記 18:1"> ヤコブはキリアテ・アルバ、すなわちヘブロンのマムレにいる父イサクのもとへ行った。ここはアブラハムとイサクとが寄留した所である。</span>
<span className="v" id="v28" data-v="28" data-xref="創世記 25:7; 創世記 50:26; 創世記 47:28"> イサクの年は百八十歳であった。</span>
<span className="v" id="v29" data-v="29" data-xref="創世記 15:15; 創世記 49:33; 創世記 49:31"> イサクは年老い、日満ちて息絶え、死んで、その民に加えられた。その子エサウとヤコブとは、これを葬った。</span>
</div>

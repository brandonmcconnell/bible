<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="ピリピ人への手紙 4:13; エペソ人への手紙 3:20; ルカによる福音書 1:6"> アブラムの九十九歳の時、主はアブラムに現れて言われた、<br /><span className="pl pl-1">「わたしは全能の神である。</span><br /><span className="pl pl-1">あなたはわたしの前に歩み、全き者であれ。</span></span>
<span className="v" id="v2" data-v="2" data-xref="創世記 17:4–6; 創世記 12:2; 詩篇 105:8–11"> <span className="pl pl-1">わたしはあなたと契約を結び、</span><br /><span className="pl pl-1">大いにあなたの子孫を増すであろう」。</span></span>
<span className="v" id="v3" data-v="3" data-xref="士師記 13:20; 創世記 17:17; 民数記 16:45"> <span className="pl pl-1">アブラムは、ひれ伏した。神はまた彼に言われた、</span></span>
<span className="v" id="v4" data-v="4" data-xref="創世記 35:11; ガラテヤ人への手紙 3:28–29; 創世記 12:2"> <span className="pl pl-1">「わたしはあなたと契約を結ぶ。</span><br /><span className="pl pl-1">あなたは多くの国民の父となるであろう。</span></span>
<span className="v" id="v5" data-v="5" data-xref="マタイによる福音書 1:21–23; ネヘミヤ書 9:7; 創世記 17:15"> <span className="pl pl-1">あなたの名は、もはやアブラムとは言われず、</span><br /><span className="pl pl-1">あなたの名はアブラハムと呼ばれるであろう。</span><br /><span className="pl pl-1">わたしはあなたを多くの国民の</span><br /><span className="pl pl-1">父とするからである。</span></span>
<span className="v" id="v6" data-v="6" data-xref="創世記 17:4; マタイによる福音書 1:6–17; 創世記 35:11"> <span className="pl pl-1">わたしはあなたに多くの子孫を得させ、国々の民をあなたから起そう。また、王たちもあなたから出るであろう。</span></span>
<span className="v" id="v7" data-v="7" data-xref="ローマ人への手紙 9:7–9; 使徒行伝 2:39; 創世記 26:24"> <span className="pl pl-1">わたしはあなた及び後の代々の子孫と契約を立てて、永遠の契約とし、あなたと後の子孫との神となるであろう。</span></span>
<span className="v" id="v8" data-v="8" data-xref="レビ記 26:12; 詩篇 105:11; 出エジプト記 6:7"> <span className="pl pl-1">わたしはあなたと後の子孫とにあなたの宿っているこの地、すなわちカナンの全地を永久の所有として与える。そしてわたしは彼らの神となるであろう」。</span></span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="イザヤ書 56:4–5; 詩篇 25:10; 詩篇 103:18"> 神はまたアブラハムに言われた、「あなたと後の子孫とは共に代々わたしの契約を守らなければならない。あなたがたのうち</span>
<span className="v" id="v10" data-v="10" data-xref="コロサイ人への手紙 2:11–12; ローマ人への手紙 4:9–11; 使徒行伝 7:8"> 男子はみな割礼をうけなければならない。これはわたしとあなたがた及び後の子孫との間のわたしの契約であって、あなたがたの守るべきものである。</span>
<span className="v" id="v11" data-v="11" data-xref="ローマ人への手紙 4:11; 使徒行伝 7:8; 申命記 10:16"> あなたがたは前の皮に割礼を受けなければならない。それがわたしとあなたがたとの間の契約のしるしとなるであろう。</span>
<span className="v" id="v12" data-v="12" data-xref="レビ記 12:3; ルカによる福音書 2:21; 出エジプト記 12:48–49"> あなたがたのうちの男子はみな代々、家に生れた者も、また異邦人から銀で買い取った、あなたの子孫でない者も、生れて八日目に割礼を受けなければならない。</span>
<span className="v" id="v13" data-v="13" data-xref="出エジプト記 12:44; 創世記 37:36; ネヘミヤ書 5:8"> あなたの家に生れた者も、あなたが銀で買い取った者も必ず割礼を受けなければならない。こうしてわたしの契約はあなたがたの身にあって永遠の契約となるであろう。</span>
<span className="v" id="v14" data-v="14" data-xref="出エジプト記 4:24–26; 民数記 15:30–31; 出エジプト記 12:19"> 割礼を受けない男子、すなわち前の皮を切らない者はわたしの契約を破るゆえ、その人は民のうちから断たれるであろう」。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="サムエル記下 12:25; 創世記 32:28; 創世記 17:5"> 神はまたアブラハムに言われた、「あなたの妻サライは、もはや名をサライといわず、名をサラと言いなさい。</span>
<span className="v" id="v16" data-v="16" data-xref="創世記 35:11; 創世記 17:6; イザヤ書 49:23"> わたしは彼女を祝福し、また彼女によって、あなたにひとりの男の子を授けよう。わたしは彼女を祝福し、彼女を国々の民の母としよう。彼女から、もろもろの民の王たちが出るであろう」。</span>
<span className="v" id="v17" data-v="17" data-xref="ヨハネの黙示録 11:16; 創世記 21:6; 創世記 18:12"> アブラハムはひれ伏して笑い、心の中で言った、「百歳の者にどうして子が生れよう。サラはまた九十歳にもなって、どうして産むことができようか」。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行伝 2:39; 詩篇 41:12; 詩篇 4:6"> そしてアブラハムは神に言った、「どうかイシマエルがあなたの前に生きながらえますように」。</span>
<span className="v" id="v19" data-v="19" data-xref="ルカによる福音書 1:13–20; 創世記 21:2–3; 列王紀下 4:16–17"> 神は言われた、「いや、あなたの妻サラはあなたに男の子を産むでしょう。名をイサクと名づけなさい。わたしは彼と契約を立てて、後の子孫のために永遠の契約としよう。</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 21:18; 創世記 21:13; 創世記 25:12–18"> またイシマエルについてはあなたの願いを聞いた。わたしは彼を祝福して多くの子孫を得させ、大いにそれを増すであろう。彼は十二人の君たちを生むであろう。わたしは彼を大いなる国民としよう。</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 21:2–3; 創世記 26:2–5; ガラテヤ人への手紙 3:29"> しかしわたしは来年の今ごろサラがあなたに産むイサクと、わたしの契約を立てるであろう」。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="創世記 18:33; 創世記 35:9–15; 士師記 6:21"> 神はアブラハムと語り終え、彼を離れて、のぼられた。</span>
<span className="v" id="v23" data-v="23" data-xref="詩篇 119:60; 創世記 18:19; 創世記 17:10–14"> アブラハムは神が自分に言われたように、この日その子イシマエルと、すべて家に生れた者およびすべて銀で買い取った者、すなわちアブラハムの家の人々のうち、すべての男子を連れてきて、前の皮に割礼を施した。</span>
<span className="v" id="v24" data-v="24" data-xref="ローマ人への手紙 4:11; 創世記 17:17; ローマ人への手紙 4:19–20"> アブラハムが前の皮に割礼を受けた時は九十九歳、</span>
<span className="v" id="v25" data-v="25"> その子イシマエルが前の皮に割礼を受けた時は十三歳であった。</span>
<span className="v" id="v26" data-v="26" data-xref="詩篇 119:60; 創世記 22:3–4; 創世記 12:4"> この日アブラハムとその子イシマエルは割礼を受けた。</span>
<span className="v" id="v27" data-v="27" data-xref="創世記 18:19"> またその家の人々は家に生れた者も、銀で異邦人から買い取った者も皆、彼と共に割礼を受けた。</span>

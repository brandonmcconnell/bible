<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 20:3; 創世記 29:14; 出エジプト記 4:9"> 二年の後パロは夢を見た。夢に、彼はナイル川のほとりに立っていた。</span>
<span className="v" id="v2" data-v="2" data-xref="イザヤ書 19:6"> すると、その川から美しい、肥え太った七頭の雌牛が上がってきて葦を食っていた。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 41:20–21; 創世記 41:4"> その後、また醜い、やせ細った他の七頭の雌牛が川から上がってきて、川の岸にいた雌牛のそばに立ち、</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀上 3:15"> その醜い、やせ細った雌牛が、あの美しい、肥えた七頭の雌牛を食いつくした。ここでパロは目が覚めた。</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 32:14"> 彼はまた眠って、再び夢を見た。夢に、一本の茎に太った良い七つの穂が出てきた。</span>
<span className="v" id="v6" data-v="6" data-xref="エゼキエル書 17:10; ホセア書 13:15; エゼキエル書 19:12"> その後また、やせて、東風に焼けた七つの穂が出てきて、</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 37:5; 創世記 20:3"> そのやせた穂が、あの太って実った七つの穂をのみつくした。ここでパロは目が覚めたが、それは夢であった。</span>
<span className="v" id="v8" data-v="8" data-xref="ダニエル書 4:7; 出エジプト記 7:22; マタイによる福音書 2:1"> 朝になって、パロは心が騒ぎ、人をつかわして、エジプトのすべての魔術師とすべての知者とを呼び寄せ、彼らに夢を告げたが、これをパロに解き明かしうる者がなかった。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="創世記 40:14; 創世記 40:23; 創世記 40:1–3"> そのとき給仕役の長はパロに告げて言った、「わたしはきょう、自分のあやまちを思い出しました。</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 39:20; 創世記 40:2–3; 創世記 37:36"> かつてパロがしもべらに向かって憤り、わたしと料理役の長とを侍衛長の家の監禁所にお入れになった時、</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 40:5–8"> わたしも彼も一夜のうちに夢を見、それぞれ意味のある夢を見ましたが、</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 40:12–19; 創世記 37:36; 創世記 39:1"> そこに侍衛長のしもべで、ひとりの若いヘブルびとがわれわれと共にいたので、彼に話したところ、彼はわれわれの夢を解き明かし、その夢によって、それぞれ解き明かしをしました。</span>
<span className="v" id="v13" data-v="13" data-xref="エゼキエル書 43:3; 創世記 40:20–22; 創世記 40:12"> そして彼が解き明かしたとおりになって、パロはわたしを職に返し、彼を木に掛けられました」。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="ダニエル書 2:25; 詩篇 113:7–8; 詩篇 105:19–22"> そこでパロは人をつかわしてヨセフを呼んだ。人々は急いで彼を地下の獄屋から出した。ヨセフは、ひげをそり、着物を着替えてパロのもとに行った。</span>
<span className="v" id="v15" data-v="15" data-xref="ダニエル書 5:16; ダニエル書 5:12; 詩篇 25:14"> パロはヨセフに言った、「わたしは夢を見たが、これを解き明かす者がない。聞くところによると、あなたは夢を聞いて、解き明かしができるそうだ」。</span>
<span className="v" id="v16" data-v="16" data-xref="コリント人への第二の手紙 3:5; 創世記 40:8; ダニエル書 2:47"> ヨセフはパロに答えて言った、「いいえ、わたしではありません。神がパロに平安をお告げになりましょう」。</span>
<span className="v" id="v17" data-v="17"> パロはヨセフに言った、「夢にわたしは川の岸に立っていた。</span>
<span className="v" id="v18" data-v="18" data-xref="エレミヤ書 24:8; エレミヤ書 24:1–3; エレミヤ書 24:5"> その川から肥え太った、美しい七頭の雌牛が上がってきて葦を食っていた。</span>
<span className="v" id="v19" data-v="19"> その後、弱く、非常に醜い、やせ細った他の七頭の雌牛がまた上がってきた。わたしはエジプト全国で、このような醜いものをまだ見たことがない。</span>
<span className="v" id="v20" data-v="20"> ところがそのやせた醜い雌牛が、初めの七頭の肥えた雌牛を食いつくしたが、</span>
<span className="v" id="v21" data-v="21" data-xref="エゼキエル書 3:3; 詩篇 37:19; ヨハネの黙示録 10:9–10"> 腹にはいっても、腹にはいった事が知れず、やはり初めのように醜かった。ここでわたしは目が覚めた。</span>
<span className="v" id="v22" data-v="22"> わたしはまた夢をみた。一本の茎に七つの実った良い穂が出てきた。</span>
<span className="v" id="v23" data-v="23" data-xref="詩篇 129:6–7; ホセア書 13:15; 列王紀下 19:26"> その後、やせ衰えて、東風に焼けた七つの穂が出てきたが、</span>
<span className="v" id="v24" data-v="24" data-xref="ダニエル書 4:7; 創世記 41:8; 出エジプト記 8:19"> そのやせた穂が、あの七つの良い穂をのみつくした。わたしは魔術師に話したが、わたしにそのわけを示しうる者はなかった」。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="ダニエル書 2:45; ヨハネの黙示録 4:1; エペソ人への手紙 1:17"> ヨセフはパロに言った、「パロの夢は一つです。神がこれからしようとすることをパロに示されたのです。</span>
<span className="v" id="v26" data-v="26" data-xref="創世記 41:47; 創世記 41:2; 創世記 41:53"> 七頭の良い雌牛は七年です。七つの良い穂も七年で、夢は一つです。</span>
<span className="v" id="v27" data-v="27" data-xref="列王紀下 8:1; サムエル記下 24:19"> あとに続いて、上がってきた七頭のやせた醜い雌牛は七年で、東風に焼けた実の入らない七つの穂は七年のききんです。</span>
<span className="v" id="v28" data-v="28" data-xref="創世記 41:25; 創世記 41:16"> わたしがパロに申し上げたように、神がこれからしようとすることをパロに示されたのです。</span>
<span className="v" id="v29" data-v="29" data-xref="創世記 41:26; 創世記 41:46–47; 創世記 41:49"> エジプト全国に七年の大豊作があり、</span>
<span className="v" id="v30" data-v="30" data-xref="創世記 47:13; 創世記 41:54; ヤコブの手紙 5:17"> その後七年のききんが起り、その豊作はみなエジプトの国で忘れられて、そのききんは国を滅ぼすでしょう。</span>
<span className="v" id="v31" data-v="31" data-xref="イザヤ書 24:20; サムエル記上 5:6"> 後に来るそのききんが、非常に激しいから、その豊作は国のうちで記憶されなくなるでしょう。</span>
<span className="v" id="v32" data-v="32" data-xref="民数記 23:19; イザヤ書 46:10–11; イザヤ書 14:24–27"> パロが二度重ねて夢を見られたのは、この事が神によって定められ、神がすみやかにこれをされるからです。</span>
<span className="v" id="v33" data-v="33" data-xref="創世記 41:39; 使徒行伝 6:3; 申命記 1:13"> それゆえパロは今、さとく、かつ賢い人を尋ね出してエジプトの国を治めさせなさい。</span>
<span className="v" id="v34" data-v="34" data-xref="箴言 22:3; ルカによる福音書 16:5; 箴言 6:6–8"> パロはこうして国中に監督を置き、その七年の豊作のうちに、エジプトの国の産物の五分の一を取り、</span>
<span className="v" id="v35" data-v="35" data-xref="創世記 45:6–7; 創世記 41:56; 出エジプト記 4:13"> 続いて来る良い年々のすべての食糧を彼らに集めさせ、穀物を食糧として、パロの手で町々にたくわえ守らせなさい。</span>
<span className="v" id="v36" data-v="36" data-xref="創世記 47:13–25"> こうすれば食糧は、エジプトの国に臨む七年のききんに備えて、この国のためにたくわえとなり、この国はききんによって滅びることがないでしょう」。</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="使徒行伝 7:10; 列王紀上 21:2; サムエル記下 3:36"> この事はパロとそのすべての家来たちの目にかなった。</span>
<span className="v" id="v38" data-v="38" data-xref="ヨブ記 32:8; ダニエル書 5:14; 民数記 27:18"> そこでパロは家来たちに言った、「われわれは神の霊をもつこのような人を、ほかに見いだし得ようか」。</span>
<span className="v" id="v39" data-v="39" data-xref="創世記 41:33; 創世記 41:28; 創世記 41:25"> またパロはヨセフに言った、「神がこれを皆あなたに示された。あなたのようにさとく賢い者はない。</span>
<span className="v" id="v40" data-v="40" data-xref="箴言 22:29; 使徒行伝 7:10; 詩篇 105:21–22"> あなたはわたしの家を治めてください。わたしの民はみなあなたの言葉に従うでしょう。わたしはただ王の位でだけあなたにまさる」。</span>
<span className="v" id="v41" data-v="41" data-xref="マタイによる福音書 28:18; ピリピ人への手紙 2:9–11; 創世記 42:6"> パロは更にヨセフに言った、「わたしはあなたをエジプト全国のつかさとする」。</span>
<span className="v" id="v42" data-v="42" data-xref="ダニエル書 5:29; ダニエル書 5:7; エステル記 3:10"> そしてパロは指輪を手からはずして、ヨセフの手にはめ、亜麻布の衣服を着せ、金の鎖をくびにかけ、</span>
<span className="v" id="v43" data-v="43" data-xref="使徒行伝 7:10; 創世記 45:8; 創世記 45:26"> 自分の第二の車に彼を乗せ、「ひざまずけ」とその前に呼ばわらせ、こうして彼をエジプト全国のつかさとした。</span>
<span className="v" id="v44" data-v="44" data-xref="詩篇 105:22; 出エジプト記 11:7"> ついでパロはヨセフに言った、「わたしはパロである。あなたの許しがなければエジプト全国で、だれも手足を上げることはできない」。</span>
<span className="v" id="v45" data-v="45" data-xref="創世記 46:20; エゼキエル書 30:17; 出エジプト記 2:16"> パロはヨセフの名をザフナテ・パネアと呼び、オンの祭司ポテペラの娘アセナテを妻として彼に与えた。ヨセフはエジプトの国を巡った。</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="ダニエル書 1:19; 列王紀上 12:6; サムエル記上 16:21"> ヨセフがエジプトの王パロの前に立った時は三十歳であった。ヨセフはパロの前を出て、エジプト全国をあまねく巡った。</span>
<span className="v" id="v47" data-v="47" data-xref="創世記 26:12; 詩篇 72:16"> さて七年の豊作のうちに地は豊かに物を産した。</span>
<span className="v" id="v48" data-v="48" data-xref="創世記 41:34–36; 創世記 47:21"> そこでヨセフはエジプトの国にできたその七年間の食糧をことごとく集め、その食糧を町々に納めさせた。すなわち町の周囲にある畑の食糧をその町の中に納めさせた。</span>
<span className="v" id="v49" data-v="49" data-xref="詩篇 78:27; 士師記 6:5; 創世記 22:17"> ヨセフは穀物を海の砂のように、非常に多くたくわえ、量りきれなくなったので、ついに量ることをやめた。</span>
</div>
<div className="bp">
<span className="v" id="v50" data-v="50" data-xref="創世記 46:20; 創世記 48:5; サムエル記下 8:18"> ききんの年の来る前にヨセフにふたりの子が生れた。これらはオンの祭司ポテペラの娘アセナテが産んだのである。</span>
<span className="v" id="v51" data-v="51" data-xref="詩篇 30:5; 箴言 31:7; 申命記 33:17"> ヨセフは長子の名をマナセと名づけて言った、「神がわたしにすべての苦難と父の家のすべての事を忘れさせられた」。</span>
<span className="v" id="v52" data-v="52" data-xref="創世記 49:22; 創世記 50:23; 創世記 17:6"> また次の子の名をエフライムと名づけて言った、「神がわたしを悩みの地で豊かにせられた」。</span>
</div>
<div className="bp">
<span className="v" id="v53" data-v="53" data-xref="創世記 41:29–31; 詩篇 73:20; ルカによる福音書 16:25"> エジプトの国にあった七年の豊作が終り、</span>
<span className="v" id="v54" data-v="54" data-xref="創世記 45:11; 使徒行伝 7:11; 詩篇 105:16"> ヨセフの言ったように七年のききんが始まった。そのききんはすべての国にあったが、エジプト全国には食物があった。</span>
<span className="v" id="v55" data-v="55" data-xref="マタイによる福音書 17:5; マタイによる福音書 3:17; エレミヤ書 14:1–6"> やがてエジプト全国が飢えた時、民はパロに食物を叫び求めた。そこでパロはすべてのエジプトびとに言った、「ヨセフのもとに行き、彼の言うようにせよ」。</span>
<span className="v" id="v56" data-v="56" data-xref="創世記 42:6; ゼカリヤ書 5:3; ルカによる福音書 21:35"> ききんが地の全面にあったので、ヨセフはすべての穀倉を開いて、エジプトびとに売った。ききんはますますエジプトの国に激しくなった。</span>
<span className="v" id="v57" data-v="57" data-xref="創世記 41:54; 創世記 42:5; 創世記 41:56"> ききんが全地に激しくなったので、諸国の人々がエジプトのヨセフのもとに穀物を買うためにきた。</span>
</div>
</div>

<span className="v" id="v1" data-v="1" data-xref="創世記 37:28; 詩篇 105:17; 創世記 37:36"> さてヨセフは連れられてエジプトに下ったが、パロの役人で侍衛長であったエジプトびとポテパルは、彼をそこに連れ下ったイシマエルびとらの手から買い取った。</span>
<span className="v" id="v2" data-v="2" data-xref="サムエル記上 18:14; 詩篇 91:15; エレミヤ書 15:20"> 主がヨセフと共におられたので、彼は幸運な者となり、その主人エジプトびとの家におった。</span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 1:3; 創世記 30:27; マタイによる福音書 5:16"> その主人は主が彼とともにおられることと、主が彼の手のすることをすべて栄えさせられるのを見た。</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 39:21–22; 箴言 27:18; 創世記 19:19"> そこで、ヨセフは彼の前に恵みを得、そのそば近く仕えた。彼はヨセフに家をつかさどらせ、持ち物をみな彼の手にゆだねた。</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 30:27; サムエル記下 6:11–12; 使徒行伝 27:24"> 彼がヨセフに家とすべての持ち物をつかさどらせた時から、主はヨセフのゆえにそのエジプトびとの家を恵まれたので、主の恵みは彼の家と畑とにあるすべての持ち物に及んだ。</span>
<span className="v" id="v6" data-v="6" data-xref="サムエル記上 16:12; ルカによる福音書 19:17; 箴言 31:11"> そこで彼は持ち物をみなヨセフの手にゆだねて、自分が食べる物のほかは、何をも顧みなかった。<br />さてヨセフは姿がよく、顔が美しかった。</span>
<span className="v" id="v7" data-v="7" data-xref="サムエル記下 13:11; エゼキエル書 16:34; ペテロの第二の手紙 2:14"> これらの事の後、主人の妻はヨセフに目をつけて言った、「わたしと寝なさい」。</span>
<span className="v" id="v8" data-v="8" data-xref="箴言 23:26–28; 箴言 22:14; 箴言 9:13–18"> ヨセフは拒んで、主人の妻に言った、「御主人はわたしがいるので家の中の何をも顧みず、その持ち物をみなわたしの手にゆだねられました。</span>
<span className="v" id="v9" data-v="9" data-xref="サムエル記下 12:13; 創世記 20:6; 創世記 42:18"> この家にはわたしよりも大いなる者はありません。また御主人はあなたを除いては、何をもわたしに禁じられませんでした。あなたが御主人の妻であるからです。どうしてわたしはこの大きな悪をおこなって、神に罪を犯すことができましょう」。</span>
<span className="v" id="v10" data-v="10" data-xref="ペテロの第一の手紙 2:11; 創世記 39:8; テサロニケ人への第一の手紙 5:22"> 彼女は毎日ヨセフに言い寄ったけれども、ヨセフは聞きいれず、彼女と寝なかった。また共にいなかった。</span>
<span className="v" id="v11" data-v="11" data-xref="エペソ人への手紙 5:12; エペソ人への手紙 5:3; マラキ書 3:5"> ある日ヨセフが務をするために家にはいった時、家の者がひとりもそこにいなかったので、</span>
<span className="v" id="v12" data-v="12" data-xref="テモテヘの第二の手紙 2:22; 箴言 7:13–27; 伝道の書 7:26"> 彼女はヨセフの着物を捕えて、「わたしと寝なさい」と言った。ヨセフは着物を彼女の手に残して外にのがれ出た。</span>
<span className="v" id="v13" data-v="13"> 彼女はヨセフが着物を自分の手に残して外にのがれたのを見て、</span>
<span className="v" id="v14" data-v="14" data-xref="創世記 10:21; ペテロの第一の手紙 2:20; 詩篇 35:11"> その家の者どもを呼び、彼らに告げて言った、「主人がわたしたちの所に連れてきたヘブルびとは、わたしたちに戯れます。彼はわたしと寝ようとして、わたしの所にはいったので、わたしは大声で叫びました。</span>
<span className="v" id="v15" data-v="15"> 彼はわたしが声をあげて叫ぶのを聞くと、着物をわたしの所に残して外にのがれ出ました」。</span>
<span className="v" id="v16" data-v="16" data-xref="詩篇 37:32; エレミヤ書 4:22; エレミヤ書 9:3–5"> 彼女はその着物をかたわらに置いて、主人の帰って来るのを待った。</span>
<span className="v" id="v17" data-v="17" data-xref="出エジプト記 23:1; 列王紀上 18:17; 詩篇 37:14"> そして彼女は次のように主人に告げた、「あなたがわたしたちに連れてこられたヘブルのしもべはわたしに戯れようとして、わたしの所にはいってきました。</span>
<span className="v" id="v18" data-v="18"> わたしが声をあげて叫んだので、彼は着物をわたしの所に残して外にのがれました」。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="創世記 4:5–6; 箴言 18:17; 箴言 6:34–35"> 主人はその妻が「あなたのしもべは、わたしにこんな事をした」と告げる言葉を聞いて、激しく怒った。</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 40:15; テモテヘの第二の手紙 2:9; 詩篇 105:18–19"> そしてヨセフの主人は彼を捕えて、王の囚人をつなぐ獄屋に投げ入れた。こうしてヨセフは獄屋の中におったが、</span>
<span className="v" id="v21" data-v="21" data-xref="出エジプト記 3:21; イザヤ書 41:10; ペテロの第一の手紙 3:17"> 主はヨセフと共におられて彼にいつくしみを垂れ、獄屋番の恵みをうけさせられた。</span>
<span className="v" id="v22" data-v="22" data-xref="創世記 40:3–4; 創世記 39:4; サムエル記上 2:30"> 獄屋番は獄屋におるすべての囚人をヨセフの手にゆだねたので、彼はそこでするすべての事をおこなった。</span>
<span className="v" id="v23" data-v="23" data-xref="イザヤ書 43:2; 創世記 39:2–3; 詩篇 1:3"> 獄屋番は彼の手にゆだねた事はいっさい顧みなかった。主がヨセフと共におられたからである。主は彼のなす事を栄えさせられた。</span>

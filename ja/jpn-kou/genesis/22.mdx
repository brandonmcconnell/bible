<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヘブル人への手紙 11:17; ヤコブの手紙 2:21; 申命記 8:2"> これらの事の後、神はアブラハムを試みて彼に言われた、「アブラハムよ」。彼は言った、「ここにおります」。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネによる福音書 3:16; ローマ人への手紙 8:32; ヘブル人への手紙 11:17"> 神は言われた、「あなたの子、あなたの愛するひとり子イサクを連れてモリヤの地に行き、わたしが示す山で彼を燔祭としてささげなさい」。</span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 119:60; マタイによる福音書 10:37; ルカによる福音書 14:26"> アブラハムは朝はやく起きて、ろばにくらを置き、ふたりの若者と、その子イサクとを連れ、また燔祭のたきぎを割り、立って神が示された所に出かけた。</span>
<span className="v" id="v4" data-v="4" data-xref="ルカによる福音書 13:32; マタイによる福音書 17:23; ホセア書 6:2"> 三日目に、アブラハムは目をあげて、はるかにその場所を見た。</span>
<span className="v" id="v5" data-v="5" data-xref="ヘブル人への手紙 11:19; ヘブル人への手紙 12:1"> そこでアブラハムは若者たちに言った、「あなたがたは、ろばと一緒にここにいなさい。わたしとわらべは向こうへ行って礼拝し、そののち、あなたがたの所に帰ってきます」。</span>
<span className="v" id="v6" data-v="6" data-xref="ヨハネによる福音書 19:17; ペテロの第一の手紙 2:24; イザヤ書 53:6"> アブラハムは燔祭のたきぎを取って、その子イサクに負わせ、手に火と刃物とを執って、ふたり一緒に行った。</span>
<span className="v" id="v7" data-v="7" data-xref="ローマ人への手紙 8:15; マタイによる福音書 26:39; 創世記 8:20"> やがてイサクは父アブラハムに言った、「父よ」。彼は答えた、「子よ、わたしはここにいます」。イサクは言った、「火とたきぎとはありますが、燔祭の小羊はどこにありますか」。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨハネによる福音書 1:36; ヨハネによる福音書 1:29; ヨハネの黙示録 5:12"> アブラハムは言った、「子よ、神みずから燔祭の小羊を備えてくださるであろう」。こうしてふたりは一緒に行った。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="ヤコブの手紙 2:21; ヘブル人への手紙 11:17–19; ピリピ人への手紙 2:7–8"> 彼らが神の示された場所にきたとき、アブラハムはそこに祭壇を築き、たきぎを並べ、その子イサクを縛って祭壇のたきぎの上に載せた。</span>
<span className="v" id="v10" data-v="10" data-xref="ヤコブの手紙 2:21–23; ヘブル人への手紙 11:17–19; イザヤ書 53:6–12"> そしてアブラハムが手を差し伸べ、刃物を執ってその子を殺そうとした時、</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 21:17; 出エジプト記 3:4; 創世記 16:9–10"> 主の使が天から彼を呼んで言った、「アブラハムよ、アブラハムよ」。彼は答えた、「はい、ここにおります」。</span>
<span className="v" id="v12" data-v="12" data-xref="ヤコブの手紙 2:21–22; ヤコブの手紙 2:18; サムエル記上 15:22"> み使が言った、「わらべを手にかけてはならない。また何も彼にしてはならない。あなたの子、あなたのひとり子をさえ、わたしのために惜しまないので、あなたが神を恐れる者であることをわたしは今知った」。</span>
<span className="v" id="v13" data-v="13" data-xref="コリント人への第一の手紙 10:13; 詩篇 40:6–8; コリント人への第二の手紙 1:9–10"> この時アブラハムが目をあげて見ると、うしろに、角をやぶに掛けている一頭の雄羊がいた。アブラハムは行ってその雄羊を捕え、それをその子のかわりに燔祭としてささげた。</span>
<span className="v" id="v14" data-v="14" data-xref="創世記 22:13; 出エジプト記 17:15; 創世記 22:8"> それでアブラハムはその所の名をアドナイ・エレと呼んだ。これにより、人々は今日もなお「主の山に備えあり」と言う。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15"> 主の使は再び天からアブラハムを呼んで、</span>
<span className="v" id="v16" data-v="16" data-xref="ヘブル人への手紙 6:13–14; ルカによる福音書 1:73; 詩篇 105:9"> 言った、「主は言われた、『わたしは自分をさして誓う。あなたがこの事をし、あなたの子、あなたのひとり子をも惜しまなかったので、</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 15:5; 創世記 24:60; エレミヤ書 33:22"> わたしは大いにあなたを祝福し、大いにあなたの子孫をふやして、天の星のように、浜べの砂のようにする。あなたの子孫は敵の門を打ち取り、</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行伝 3:25; 創世記 12:3; ガラテヤ人への手紙 3:16"> また地のもろもろの国民はあなたの子孫によって祝福を得るであろう。あなたがわたしの言葉に従ったからである』」。</span>
<span className="v" id="v19" data-v="19" data-xref="創世記 21:31; 士師記 20:1; ヨシュア記 15:28"> アブラハムは若者たちの所に帰り、みな立って、共にベエルシバへ行った。そしてアブラハムはベエルシバに住んだ。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="創世記 11:29; 創世記 24:24; 箴言 25:25"> これらの事の後、ある人がアブラハムに告げて言った、「ミルカもまたあなたの兄弟ナホルに子どもを産みました。</span>
<span className="v" id="v21" data-v="21" data-xref="ヨブ記 1:1; ヨブ記 32:2; 詩篇 60:1–12"> 長男はウヅ、弟はブズ、次はアラムの父ケムエル、</span>
<span className="v" id="v22" data-v="22"> 次はケセデ、ハゾ、ピルダシ、エデラフ、ベトエルです」。</span>
<span className="v" id="v23" data-v="23" data-xref="創世記 24:15; 創世記 28:5; 創世記 24:51"> ベトエルの子はリベカであって、これら八人はミルカがアブラハムの兄弟ナホルに産んだのである。</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 16:3; 創世記 25:6; 箴言 15:25"> ナホルのそばめで、名をルマという女もまたテバ、ガハム、タハシおよびマアカを産んだ。</span>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 1:28"> 人が地のおもてにふえ始めて、娘たちが彼らに生れた時、</span>
<span className="v" id="v2" data-v="2" data-xref="詩篇 82:6–7; ヨハネの第一の手紙 2:16; ペテロの第二の手紙 2:14"> 神の子たちは人の娘たちの美しいのを見て、自分の好む者を妻にめとった。</span>
<span className="v" id="v3" data-v="3" data-xref="ネヘミヤ書 9:30; イザヤ書 63:10; エレミヤ書 11:11"> そこで主は言われた、「わたしの霊はながく人の中にとどまらない。彼は肉にすぎないのだ。しかし、彼の年は百二十年であろう」。</span>
<span className="v" id="v4" data-v="4" data-xref="民数記 13:33; サムエル記下 21:15–22; サムエル記上 17:4"> そのころ、またその後にも、地にネピリムがいた。これは神の子たちが人の娘たちのところにはいって、娘たちに産ませたものである。彼らは昔の勇士であり、有名な人々であった。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="マタイによる福音書 15:19; ローマ人への手紙 1:28–31; マルコによる福音書 7:21–23"> 主は人の悪が地にはびこり、すべてその心に思いはかることが、いつも悪い事ばかりであるのを見られた。</span>
<span className="v" id="v6" data-v="6" data-xref="イザヤ書 63:10; サムエル記上 15:11; エペソ人への手紙 4:30"> 主は地の上に人を造ったのを悔いて、心を痛め、</span>
<span className="v" id="v7" data-v="7" data-xref="ゼパニヤ書 1:3; 詩篇 37:20; エレミヤ書 12:3–4"> 「わたしが創造した人を地のおもてからぬぐい去ろう。人も獣も、這うものも、空の鳥までも。わたしは、これらを造ったことを悔いる」と言われた。</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 19:19; ヘブル人への手紙 4:16; ルカによる福音書 1:30"> しかし、ノアは主の前に恵みを得た。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="ルカによる福音書 1:6; ヘブル人への手紙 11:7; ペテロの第二の手紙 2:5"> ノアの系図は次のとおりである。ノアはその時代の人々の中で正しく、かつ全き人であった。ノアは神とともに歩んだ。</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 5:32"> ノアはセム、ハム、ヤペテの三人の子を生んだ。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="エゼキエル書 8:17; ホセア書 4:1–2; ハバクク書 2:8"> 時に世は神の前に乱れて、暴虐が地に満ちた。</span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 53:2–3; 箴言 15:3; 詩篇 14:1–3"> 神が地を見られると、それは乱れていた。すべての人が地の上でその道を乱したからである。</span>
<span className="v" id="v13" data-v="13" data-xref="ホセア書 4:1–2; ペテロの第一の手紙 4:7; エゼキエル書 7:2–6"> そこで神はノアに言われた、「わたしは、すべての人を絶やそうと決心した。彼らは地を暴虐で満たしたから、わたしは彼らを地とともに滅ぼそう。</span>
<span className="v" id="v14" data-v="14" data-xref="ペテロの第一の手紙 3:20; ルカによる福音書 17:27; マタイによる福音書 24:38"> あなたは、いとすぎの木で箱舟を造り、箱舟の中にへやを設け、アスファルトでそのうちそとを塗りなさい。</span>
<span className="v" id="v15" data-v="15" data-xref="申命記 3:11; 創世記 7:20"> その造り方は次のとおりである。すなわち箱舟の長さは三百キュビト、幅は五十キュビト、高さは三十キュビトとし、</span>
<span className="v" id="v16" data-v="16" data-xref="創世記 8:6; 創世記 7:16; エゼキエル書 41:16"> 箱舟に屋根を造り、上へ一キュビトにそれを仕上げ、また箱舟の戸口をその横に設けて、一階と二階と三階のある箱舟を造りなさい。</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 7:4; ペテロの第二の手紙 2:5; 創世記 7:21–23"> わたしは地の上に洪水を送って、命の息のある肉なるものを、みな天の下から滅ぼし去る。地にあるものは、みな死に絶えるであろう。</span>
<span className="v" id="v18" data-v="18" data-xref="ヘブル人への手紙 11:7; 創世記 7:7; 創世記 17:7"> ただし、わたしはあなたと契約を結ぼう。あなたは子らと、妻と、子らの妻たちと共に箱舟にはいりなさい。</span>
<span className="v" id="v19" data-v="19" data-xref="創世記 7:15–16; 創世記 7:8–9; 創世記 8:17"> またすべての生き物、すべての肉なるものの中から、それぞれ二つずつを箱舟に入れて、あなたと共にその命を保たせなさい。それらは雄と雌とでなければならない。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行伝 10:11–12; 創世記 2:19; 創世記 7:8–16"> すなわち、鳥はその種類にしたがい獣はその種類にしたがい、また地のすべての這うものも、その種類にしたがって、それぞれ二つずつ、あなたのところに入れて、命を保たせなさい。</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 1:29–30; 詩篇 145:16; 詩篇 136:25"> また、すべての食物となるものをとって、あなたのところにたくわえ、あなたとこれらのものとの食物としなさい」。</span>
<span className="v" id="v22" data-v="22" data-xref="出エジプト記 40:16; ヨハネによる福音書 15:14; マタイによる福音書 7:24–27"> ノアはすべて神の命じられたようにした。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 17:8; 創世記 23:4; 創世記 36:7"> ヤコブは父の寄留の地、すなわちカナンの地に住んだ。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 35:25–26; 創世記 35:22; サムエル記上 2:22–24"> ヤコブの子孫は次のとおりである。<br />ヨセフは十七歳の時、兄弟たちと共に羊の群れを飼っていた。彼はまだ子供で、父の妻たちビルハとジルパとの子らと共にいたが、ヨセフは彼らの悪いうわさを父に告げた。</span>
<span className="v" id="v3" data-v="3" data-xref="ヨハネによる福音書 3:35; 創世記 37:32; サムエル記下 13:18"> ヨセフは年寄り子であったから、イスラエルは他のどの子よりも彼を愛して、彼のために長そでの着物をつくった。</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 27:41; ヨハネの第一の手紙 3:12; ヨハネの第一の手紙 4:20"> 兄弟たちは父がどの兄弟よりも彼を愛するのを見て、彼を憎み、穏やかに彼に語ることができなかった。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="創世記 28:12; 創世記 42:9; ヨハネによる福音書 17:14"> ある時、ヨセフは夢を見て、それを兄弟たちに話したので、彼らは、ますます彼を憎んだ。</span>
<span className="v" id="v6" data-v="6" data-xref="創世記 44:18; 士師記 9:7"> ヨセフは彼らに言った、「どうぞわたしが見た夢を聞いてください。</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 44:14; 創世記 42:6; 創世記 43:26"> わたしたちが畑の中で束を結わえていたとき、わたしの束が起きて立つと、あなたがたの束がまわりにきて、わたしの束を拝みました」。</span>
<span className="v" id="v8" data-v="8" data-xref="サムエル記上 10:27; 使徒行伝 7:35; ヘブル人への手紙 10:29"> すると兄弟たちは彼に向かって、「あなたはほんとうにわたしたちの王になるのか。あなたは実際わたしたちを治めるのか」と言って、彼の夢とその言葉のゆえにますます彼を憎んだ。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行伝 7:9–14; 創世記 37:7; ダニエル書 8:10"> ヨセフはまた一つの夢を見て、それを兄弟たちに語って言った、「わたしはまた夢を見ました。日と月と十一の星とがわたしを拝みました」。</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 27:29; ピリピ人への手紙 2:10–11; イザヤ書 60:14"> 彼はこれを父と兄弟たちに語ったので、父は彼をとがめて言った、「あなたが見たその夢はどういうのか。ほんとうにわたしとあなたの母と、兄弟たちとが行って地に伏し、あなたを拝むのか」。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行伝 7:9; ルカによる福音書 2:19; ルカによる福音書 2:51"> 兄弟たちは彼をねたんだ。しかし父はこの言葉を心にとめた。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="創世記 37:1; 創世記 33:18; 創世記 34:25–31"> さて兄弟たちがシケムに行って、父の羊の群れを飼っていたとき、</span>
<span className="v" id="v13" data-v="13" data-xref="エペソ人への手紙 6:1–3; サムエル記上 3:8; サムエル記上 3:16"> イスラエルはヨセフに言った、「あなたの兄弟たちはシケムで羊を飼っているではないか。さあ、あなたを彼らの所へつかわそう」。ヨセフは父に言った、「はい、行きます」。</span>
<span className="v" id="v14" data-v="14" data-xref="創世記 35:27; ルカによる福音書 19:42; 詩篇 125:5"> 父は彼に言った、「どうか、行って、あなたの兄弟たちは無事であるか、また群れは無事であるか見てきて、わたしに知らせてください」。父が彼をヘブロンの谷からつかわしたので、彼はシケムに行った。</span>
<span className="v" id="v15" data-v="15" data-xref="ヨハネによる福音書 4:27; 士師記 4:22; 創世記 21:14"> ひとりの人が彼に会い、彼が野をさまよっていたので、その人は彼に尋ねて言った、「あなたは何を捜しているのですか」。</span>
<span className="v" id="v16" data-v="16" data-xref="ルカによる福音書 19:10; 雅歌 1:7"> 彼は言った、「兄弟たちを捜しているのです。彼らが、どこで羊を飼っているのか、どうぞわたしに知らせてください」。</span>
<span className="v" id="v17" data-v="17" data-xref="列王紀下 6:13"> その人は言った、「彼らはここを去りました。彼らが『ドタンへ行こう』と言うのをわたしは聞きました」。そこでヨセフは兄弟たちのあとを追って行って、ドタンで彼らに会った。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行伝 23:12; 詩篇 37:12; 詩篇 37:32"> ヨセフが彼らに近づかないうちに、彼らははるかにヨセフを見て、これを殺そうと計り、</span>
<span className="v" id="v19" data-v="19" data-xref="創世記 28:12; 創世記 37:11; 創世記 37:5"> 互に言った、「あの夢見る者がやって来る。</span>
<span className="v" id="v20" data-v="20" data-xref="テトスヘの手紙 3:3; 箴言 27:4; マタイによる福音書 2:2–16"> さあ、彼を殺して穴に投げ入れ、悪い獣が彼を食ったと言おう。そして彼の夢がどうなるか見よう」。</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 42:22; 創世記 35:22; ヨシュア記 10:28"> ルベンはこれを聞いて、ヨセフを彼らの手から救い出そうとして言った、「われわれは彼の命を取ってはならない」。</span>
<span className="v" id="v22" data-v="22" data-xref="創世記 22:12; 申命記 13:9; 創世記 42:22"> ルベンはまた彼らに言った、「血を流してはいけない。彼を荒野のこの穴に投げ入れよう。彼に手をくだしてはならない」。これはヨセフを彼らの手から救いだして父に返すためであった。</span>
<span className="v" id="v23" data-v="23" data-xref="創世記 37:3; マタイによる福音書 27:28; 創世記 42:21"> さて、ヨセフが兄弟たちのもとへ行くと、彼らはヨセフの着物、彼が着ていた長そでの着物をはぎとり、</span>
<span className="v" id="v24" data-v="24" data-xref="エレミヤ書 38:6; 詩篇 130:1–2; ゼカリヤ書 9:11"> 彼を捕えて穴に投げ入れた。その穴はからで、その中に水はなかった。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="創世記 37:28; 創世記 43:11; エレミヤ書 8:22"> こうして彼らはすわってパンを食べた。時に彼らが目をあげて見ると、イシマエルびとの隊商が、らくだに香料と、乳香と、もつやくとを負わせてエジプトへ下り行こうとギレアデからやってきた。</span>
<span className="v" id="v26" data-v="26" data-xref="創世記 37:20; 創世記 4:10; 創世記 25:32"> そこでユダは兄弟たちに言った、「われわれが弟を殺し、その血を隠して何の益があろう。</span>
<span className="v" id="v27" data-v="27" data-xref="マタイによる福音書 16:26; 創世記 42:21; サムエル記上 18:17"> さあ、われわれは彼をイシマエルびとに売ろう。彼はわれわれの兄弟、われわれの肉身だから、彼に手を下してはならない」。兄弟たちはこれを聞き入れた。</span>
<span className="v" id="v28" data-v="28" data-xref="使徒行伝 7:9; 詩篇 105:17; 創世記 45:4–5"> 時にミデアンびとの商人たちが通りかかったので、彼らはヨセフを穴から引き上げ、銀二十シケルでヨセフをイシマエルびとに売った。彼らはヨセフをエジプトへ連れて行った。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="ヨブ記 1:20; 創世記 37:34; 創世記 44:13"> さてルベンは穴に帰って見たが、ヨセフが穴の中にいなかったので、彼は衣服を裂き、</span>
<span className="v" id="v30" data-v="30" data-xref="創世記 42:13; エレミヤ書 31:15; 創世記 42:32"> 兄弟たちのもとに帰って言った、「あの子はいない。ああ、わたしはどこへ行くことができよう」。</span>
<span className="v" id="v31" data-v="31" data-xref="創世記 37:23; 箴言 28:13; 創世記 37:3"> 彼らはヨセフの着物を取り、雄やぎを殺して、着物をその血に浸し、</span>
<span className="v" id="v32" data-v="32" data-xref="ルカによる福音書 15:30; 創世記 37:3; 創世記 44:20–23"> その長そでの着物を父に持ち帰って言った、「わたしたちはこれを見つけましたが、これはあなたの子の着物か、どうか見さだめてください」。</span>
<span className="v" id="v33" data-v="33" data-xref="創世記 37:20; 創世記 44:28; ヨハネによる福音書 13:7"> 父はこれを見さだめて言った、「わが子の着物だ。悪い獣が彼を食ったのだ。確かにヨセフはかみ裂かれたのだ」。</span>
<span className="v" id="v34" data-v="34" data-xref="創世記 37:29; サムエル記下 3:31; 詩篇 69:11"> そこでヤコブは衣服を裂き、荒布を腰にまとって、長い間その子のために嘆いた。</span>
<span className="v" id="v35" data-v="35" data-xref="創世記 42:38; ヨブ記 2:11; サムエル記下 12:17"> 子らと娘らとは皆立って彼を慰めようとしたが、彼は慰められるのを拒んで言った、「いや、わたしは嘆きながら陰府に下って、わが子のもとへ行こう」。こうして父は彼のために泣いた。</span>
<span className="v" id="v36" data-v="36" data-xref="創世記 40:4; 創世記 37:28; 列王紀下 25:8"> さて、かのミデアンびとらはエジプトでパロの役人、侍衛長ポテパルにヨセフを売った。</span>
</div>

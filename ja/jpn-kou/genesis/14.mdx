<span className="v" id="v1" data-v="1" data-xref="創世記 10:10; 創世記 10:22; イザヤ書 37:12"> シナルの王アムラペル、エラサルの王アリオク、エラムの王ケダラオメルおよびゴイムの王テダルの世に、</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 13:10; 申命記 29:23; 創世記 10:19"> これらの王はソドムの王ベラ、ゴモラの王ビルシャ、アデマの王シナブ、ゼボイムの王セメベル、およびベラすなわちゾアルの王と戦った。</span>
<span className="v" id="v3" data-v="3" data-xref="ヨシュア記 3:16; 申命記 3:17; 民数記 34:12"> これら五人の王はみな同盟してシデムの谷、すなわち塩の海に向かって行った。</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 9:25–26; エゼキエル書 17:15"> すなわち彼らは十二年の間ケダラオメルに仕えたが、十三年目にそむいたので、</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 3:11; 創世記 15:20; 申命記 1:4"> 十四年目にケダラオメルは彼と連合した王たちと共にきて、アシタロテ・カルナイムでレパイムびとを、ハムでズジびとを、シャベ・キリアタイムでエミびとを撃ち、</span>
<span className="v" id="v6" data-v="6" data-xref="申命記 2:22; 申命記 2:12; 創世記 21:21"> セイルの山地でホリびとを撃って、荒野のほとりにあるエル・パランに及んだ。</span>
<span className="v" id="v7" data-v="7" data-xref="歴代志下 20:2; 創世記 16:14; 創世記 20:1"> 彼らは引き返してエン・ミシパテすなわちカデシへ行って、アマレクびとの国をことごとく撃ち、またハザゾン・タマルに住むアモリびとをも撃った。</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 19:22; 創世記 13:10; 創世記 19:20"> そこでソドムの王、ゴモラの王、アデマの王、ゼボイムの王およびベラすなわちゾアルの王は出てシデムの谷で彼らに向かい、戦いの陣をしいた。</span>
<span className="v" id="v9" data-v="9"> すなわちエラムの王ケダラオメル、ゴイムの王テダル、シナルの王アムラペル、エラサルの王アリオクの四人の王に対する五人の王であった。</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 19:17; 創世記 19:30; イザヤ書 24:18"> シデムの谷にはアスファルトの穴が多かったので、ソドムの王とゴモラの王は逃げてそこに落ちたが、残りの者は山にのがれた。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 14:21; 創世記 14:16; 申命記 28:31"> そこで彼らはソドムとゴモラの財産と食料とをことごとく奪って去り、</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 12:5; 創世記 11:27; ヨハネの黙示録 3:19"> またソドムに住んでいたアブラムの弟の子ロトとその財産を奪って去った。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="創世記 13:18; 創世記 14:24; 創世記 40:15"> 時に、ひとりの人がのがれてきて、ヘブルびとアブラムに告げた。この時アブラムはエシコルの兄弟、またアネルの兄弟であるアモリびとマムレのテレビンの木のかたわらに住んでいた。彼らはアブラムと同盟していた。</span>
<span className="v" id="v14" data-v="14" data-xref="士師記 18:29; 創世記 15:3; 創世記 17:27"> アブラムは身内の者が捕虜になったのを聞き、訓練した家の子三百十八人を引き連れてダンまで追って行き、</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行伝 9:2; 詩篇 112:5; 列王紀上 15:18"> そのしもべたちを分けて、夜かれらを攻め、これを撃ってダマスコの北、ホバまで彼らを追った。</span>
<span className="v" id="v16" data-v="16" data-xref="サムエル記上 30:18–19; サムエル記上 30:8; 創世記 12:2"> そして彼はすべての財産を取り返し、また身内の者ロトとその財産および女たちと民とを取り返した。</span>
</div>
<div className="bp poetry">
<span className="v" id="v17" data-v="17" data-xref="サムエル記下 18:18; 箴言 19:4; ヘブル人への手紙 7:1"> アブラムがケダラオメルとその連合の王たちを撃ち破って帰った時、ソドムの王はシャベの谷、すなわち王の谷に出て彼を迎えた。</span>
<span className="v" id="v18" data-v="18" data-xref="ヘブル人への手紙 6:20–3; 詩篇 110:4; ヘブル人への手紙 5:6"> その時、サレムの王メルキゼデクはパンとぶどう酒とを持ってきた。彼はいと高き神の祭司である。</span>
<span className="v" id="v19" data-v="19" data-xref="ヘブル人への手紙 7:6–7; 創世記 14:22; 詩篇 24:1"> 彼はアブラムを祝福して言った、<br /><span className="pl pl-1">「願わくは天地の主なるいと高き神が、</span><br /><span className="pl pl-1">アブラムを祝福されるように。</span></span>
<span className="v" id="v20" data-v="20" data-xref="創世記 28:22; ヘブル人への手紙 7:4–9; マラキ書 3:10"> <span className="pl pl-1">願わくはあなたの敵をあなたの手に渡された</span><br /><span className="pl pl-1">いと高き神があがめられるように」。</span><br />アブラムは彼にすべての物の十分の一を贈った。</span>
<span className="v" id="v21" data-v="21"> 時にソドムの王はアブラムに言った、「わたしには人をください。財産はあなたが取りなさい」。</span>
<span className="v" id="v22" data-v="22" data-xref="ダニエル書 12:7; ダニエル書 4:34; 申命記 32:40"> アブラムはソドムの王に言った、「天地の主なるいと高き神、主に手をあげて、わたしは誓います。</span>
<span className="v" id="v23" data-v="23" data-xref="列王紀下 5:16; コリント人への第二の手紙 11:9–12; エステル記 9:15–16"> わたしは糸一本でも、くつひも一本でも、あなたのものは何にも受けません。アブラムを富ませたのはわたしだと、あなたが言わないように。</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 14:13; 箴言 3:27; マタイによる福音書 7:12"> ただし若者たちがすでに食べた物は別です。そしてわたしと共に行った人々アネルとエシコルとマムレとにはその分を取らせなさい」。</span>

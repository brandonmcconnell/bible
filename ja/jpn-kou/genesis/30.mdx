<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨブ記 5:2; 創世記 29:31; 創世記 37:11"> ラケルは自分がヤコブに子を産まないのを知った時、姉をねたんでヤコブに言った、「わたしに子どもをください。さもないと、わたしは死にます」。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 16:2; 詩篇 127:3; 列王紀下 5:7"> ヤコブはラケルに向かい怒って言った、「あなたの胎に子どもをやどらせないのは神です。わたしが神に代ることができようか」。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 50:23; ヨブ記 3:12; ルツ記 4:11"> ラケルは言った、「わたしのつかえめビルハがいます。彼女の所におはいりなさい。彼女が子を産んで、わたしのひざに置きます。そうすれば、わたしもまた彼女によって子を持つでしょう」。</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 35:22; 創世記 21:10; サムエル記下 12:11"> ラケルはつかえめビルハを彼に与えて、妻とさせたので、ヤコブは彼女の所にはいった。</span>
<span className="v" id="v5" data-v="5"> ビルハは、みごもってヤコブに子を産んだ。</span>
<span className="v" id="v6" data-v="6" data-xref="哀歌 3:59; 詩篇 35:24; 詩篇 43:1"> そこでラケルは、「神はわたしの訴えに答え、またわたしの声を聞いて、わたしに子を賜わった」と言って、名をダンと名づけた。</span>
<span className="v" id="v7" data-v="7"> ラケルのつかえめビルハはまた、みごもって第二の子をヤコブに産んだ。</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 32:24–25; 創世記 23:6; 創世記 49:21"> そこでラケルは、「わたしは激しい争いで、姉と争って勝った」と言って、名をナフタリと名づけた。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="創世記 30:4; 創世記 30:17; 創世記 29:35"> さてレアは自分が子を産むことのやんだのを見たとき、つかえめジルパを取り、妻としてヤコブに与えた。</span>
<span className="v" id="v10" data-v="10"> レアのつかえめジルパはヤコブに子を産んだ。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 49:19; イザヤ書 65:11; 創世記 35:26"> そこでレアは、「幸運がきた」と言って、名をガドと名づけた。</span>
<span className="v" id="v12" data-v="12"> レアのつかえめジルパは第二の子をヤコブに産んだ。</span>
<span className="v" id="v13" data-v="13" data-xref="ルカによる福音書 1:48; 箴言 31:28; 雅歌 6:9"> そこでレアは、「わたしは、しあわせです。娘たちはわたしをしあわせな者と言うでしょう」と言って、名をアセルと名づけた。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="雅歌 7:13; 創世記 25:30"> さてルベンは麦刈りの日に野に出て、野で恋なすびを見つけ、それを母レアのもとに持ってきた。ラケルはレアに言った、「あなたの子の恋なすびをどうぞわたしにください」。</span>
<span className="v" id="v15" data-v="15" data-xref="民数記 16:13; コリント人への第一の手紙 4:3; 民数記 16:9–10"> レアはラケルに言った、「あなたがわたしの夫を取ったのは小さな事でしょうか。その上、あなたはまたわたしの子の恋なすびをも取ろうとするのですか」。ラケルは言った、「それではあなたの子の恋なすびに換えて、今夜彼をあなたと共に寝させましょう」。</span>
<span className="v" id="v16" data-v="16"> 夕方になって、ヤコブが野から帰ってきたので、レアは彼を出迎えて言った、「わたしの子の恋なすびをもって、わたしがあなたを雇ったのですから、あなたはわたしの所に、はいらなければなりません」。ヤコブはその夜レアと共に寝た。</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 30:6; 創世記 30:22; 出エジプト記 3:7"> 神はレアの願いを聞かれたので、彼女はみごもって五番目の子をヤコブに産んだ。</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 49:14–15; 申命記 33:18; 創世記 46:13"> そこでレアは、「わたしがつかえめを夫に与えたから、神がわたしにその価を賜わったのです」と言って、名をイッサカルと名づけた。</span>
<span className="v" id="v19" data-v="19"> レアはまた、みごもって六番目の子をヤコブに産んだ。</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 35:23; マタイによる福音書 4:13; 創世記 49:13"> そこでレアは、「神はわたしに良い賜物をたまわった。わたしは六人の子を夫に産んだから、今こそ彼はわたしと一緒に住むでしょう」と言って、その名をゼブルンと名づけた。</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 34:1–3; 創世記 34:26; 創世記 46:15"> その後、彼女はひとりの娘を産んで、名をデナと名づけた。</span>
<span className="v" id="v22" data-v="22" data-xref="創世記 29:31; 詩篇 113:9; 詩篇 127:3"> 次に神はラケルを心にとめられ、彼女の願いを聞き、その胎を開かれたので、</span>
<span className="v" id="v23" data-v="23" data-xref="ルカによる福音書 1:25; 創世記 29:31; ルカによる福音書 1:27"> 彼女は、みごもって男の子を産み、「神はわたしの恥をすすいでくださった」と言って、</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 49:22–26; 創世記 35:24; 創世記 37:2"> 名をヨセフと名づけ、「主がわたしに、なおひとりの子を加えられるように」と言った。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="創世記 24:54; 創世記 24:56; 創世記 28:15"> ラケルがヨセフを産んだ時、ヤコブはラバンに言った、「わたしを去らせて、わたしの故郷、わたしの国へ行かせてください。</span>
<span className="v" id="v26" data-v="26" data-xref="創世記 29:30; ホセア書 12:12; 創世記 31:26"> あなたに仕えて得たわたしの妻子を、わたしに与えて行かせてください。わたしがあなたのために働いた骨折りは、あなたがごぞんじです」。</span>
<span className="v" id="v27" data-v="27" data-xref="ルツ記 2:13; 使徒行伝 7:10; イザヤ書 61:9"> ラバンは彼に言った、「もし、あなたの心にかなうなら、とどまってください。わたしは主があなたのゆえに、わたしを恵まれるしるしを見ました」。</span>
<span className="v" id="v28" data-v="28" data-xref="創世記 29:15; 創世記 29:19"> また言った、「あなたの報酬を申し出てください。わたしはそれを払います」。</span>
<span className="v" id="v29" data-v="29" data-xref="創世記 31:6; 創世記 31:38–40; ペテロの第一の手紙 2:18"> ヤコブは彼に言った、「わたしがどのようにあなたに仕えたか、またどのようにあなたの家畜を飼ったかは、あなたがごぞんじです。</span>
<span className="v" id="v30" data-v="30" data-xref="テモテヘの第一の手紙 5:8; コリント人への第二の手紙 12:14; 申命記 11:10"> わたしが来る前には、あなたの持っておられたものはわずかでしたが、ふえて多くなりました。主はわたしの行く所どこでも、あなたを恵まれました。しかし、いつになったらわたしも自分の家を成すようになるでしょうか」。</span>
<span className="v" id="v31" data-v="31" data-xref="サムエル記下 21:4–6; ヘブル人への手紙 13:5; 詩篇 118:8"> 彼は言った、「何をあなたにあげようか」。ヤコブは言った、「なにもわたしにくださるに及びません。もしあなたが、わたしのためにこの一つの事をしてくださるなら、わたしは今一度あなたの群れを飼い、守りましょう。</span>
<span className="v" id="v32" data-v="32" data-xref="創世記 31:8; 創世記 31:10; 創世記 30:35"> わたしはきょう、あなたの群れをみな回ってみて、その中からすべてぶちとまだらの羊、およびすべて黒い小羊と、やぎの中のまだらのものと、ぶちのものとを移しますが、これをわたしの報酬としましょう。</span>
<span className="v" id="v33" data-v="33" data-xref="出エジプト記 13:14; サムエル記下 22:21; サムエル記上 26:23"> あとで、あなたがきて、あなたの前でわたしの報酬をしらべる時、わたしの正しい事が証明されるでしょう。もしも、やぎの中にぶちのないもの、まだらでないものがあったり、小羊の中に黒くないものがあれば、それはみなわたしが盗んだものとなるでしょう」。</span>
<span className="v" id="v34" data-v="34" data-xref="コリント人への第一の手紙 7:7; 民数記 22:29; コリント人への第一の手紙 14:5"> ラバンは言った、「よろしい。あなたの言われるとおりにしましょう」。</span>
<span className="v" id="v35" data-v="35" data-xref="創世記 31:9"> そこでラバンはその日、雄やぎのしまのあるもの、まだらのもの、すべて雌やぎのぶちのもの、まだらのもの、すべて白みをおびているもの、またすべて小羊の中の黒いものを移して子らの手にわたし、</span>
<span className="v" id="v36" data-v="36"> ヤコブとの間に三日路の隔たりを設けた。ヤコブはラバンの残りの群れを飼った。</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="創世記 31:9–13; エゼキエル書 31:8"> ヤコブは、はこやなぎと、あめんどうと、すずかけの木のなまの枝を取り、皮をはいでそれに白い筋をつくり、枝の白い所を表わし、</span>
<span className="v" id="v38" data-v="38"> 皮をはいだ枝を、群れがきて水を飲む鉢、すなわち水ぶねの中に、群れに向かわせて置いた。群れは水を飲みにきた時に、はらんだ。</span>
<span className="v" id="v39" data-v="39" data-xref="出エジプト記 12:35–36; 創世記 31:9–12; 創世記 31:40"> すなわち群れは枝の前で、はらんで、しまのあるもの、ぶちのもの、まだらのものを産んだ。</span>
<span className="v" id="v40" data-v="40"> ヤコブはその小羊を別においた。彼はまた群れの顔をラバンの群れのしまのあるものと、すべて黒いものとに向かわせた。そして自分の群れを別にまとめておいて、ラバンの群れには、入れなかった。</span>
<span className="v" id="v41" data-v="41"> また群れの強いものが発情した時には、ヤコブは水ぶねの中に、その群れの目の前に、かの枝を置いて、枝の間で、はらませた。</span>
<span className="v" id="v42" data-v="42"> けれども群れの弱いものの時には、それを置かなかった。こうして弱いものはラバンのものとなり、強いものはヤコブのものとなったので、</span>
<span className="v" id="v43" data-v="43" data-xref="創世記 24:35; 創世記 30:30; 創世記 26:13–14"> この人は大いに富み、多くの群れと、男女の奴隷、およびらくだ、ろばを持つようになった。</span>
</div>

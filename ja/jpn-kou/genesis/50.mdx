<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 46:4; 申命記 6:7–8; 使徒行伝 8:2"> ヨセフは父の顔に伏して泣き、口づけした。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 50:26; 歴代志下 16:14; ヨハネによる福音書 19:39–40"> そしてヨセフは彼のしもべである医者たちに、父に薬を塗ることを命じたので、医者たちはイスラエルに薬を塗った。</span>
<span className="v" id="v3" data-v="3" data-xref="民数記 20:29; 申命記 34:8; 創世記 50:10"> このために四十日を費した。薬を塗るにはこれほどの日数を要するのである。エジプトびとは七十日の間、彼のために泣いた。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="創世記 18:3; エステル記 4:2"> 彼のために泣く日が過ぎて、ヨセフはパロの家の者に言った、「今もしわたしがあなたがたの前に恵みを得るなら、どうかパロに伝えてください。</span>
<span className="v" id="v5" data-v="5" data-xref="歴代志下 16:14; イザヤ書 22:16; マタイによる福音書 27:60"> 『わたしの父はわたしに誓わせて言いました「わたしはやがて死にます。カナンの地に、わたしが掘って置いた墓に葬ってください」。それで、どうかわたしを上って行かせ、父を葬らせてください。そうすれば、わたしはまた帰ってきます』」。</span>
<span className="v" id="v6" data-v="6" data-xref="創世記 48:21"> パロは言った、「あなたの父があなたに誓わせたように上って行って彼を葬りなさい」。</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 14:16"> そこでヨセフは父を葬るために上って行った。彼と共に上った者はパロのもろもろの家来たち、パロの家の長老たち、エジプトの国のもろもろの長老たち、</span>
<span className="v" id="v8" data-v="8" data-xref="民数記 32:24–27; 出エジプト記 10:26; 出エジプト記 10:8–9"> ヨセフの全家とその兄弟たち及びその父の家族であった。ただ子供と羊と牛はゴセンの地に残した。</span>
<span className="v" id="v9" data-v="9" data-xref="出エジプト記 14:28; 列王紀下 18:24; 雅歌 1:9"> また戦車と騎兵も彼と共に上ったので、その行列はたいそう盛んであった。</span>
<span className="v" id="v10" data-v="10" data-xref="ヨブ記 2:13; 使徒行伝 8:2; サムエル記下 1:17"> 彼らはヨルダンの向こうのアタデの打ち場に行き着いて、そこで大いに嘆き、非常に悲しんだ。そしてヨセフは七日の間父のために嘆いた。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 10:15–19; 創世記 24:6; 申命記 11:30"> その地の住民、カナンびとがアタデの打ち場の嘆きを見て、「これはエジプトびとの大いなる嘆きだ」と言ったので、その所の名はアベル・ミツライムと呼ばれた。これはヨルダンの向こうにある。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行伝 7:16; 創世記 49:29–32; エペソ人への手紙 6:1"> ヤコブの子らは命じられたようにヤコブにおこなった。</span>
<span className="v" id="v13" data-v="13" data-xref="創世記 49:29–31; 創世記 23:16–18; 使徒行伝 7:16"> すなわちその子らは彼をカナンの地へ運んで行って、マクペラの畑のほら穴に葬った。このほら穴はマムレの東にあって、アブラハムがヘテびとエフロンから畑と共に買って、所有の墓地としたものである。</span>
<span className="v" id="v14" data-v="14"> ヨセフは父を葬った後、その兄弟たち及びすべて父を葬るために一緒に上った者と共にエジプトに帰った。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="箴言 28:1; 創世記 42:21–22; 詩篇 53:5"> ヨセフの兄弟たちは父の死んだのを見て言った、「ヨセフはことによるとわれわれを憎んで、われわれが彼にしたすべての悪に、仕返しするに違いない」。</span>
<span className="v" id="v16" data-v="16" data-xref="箴言 29:25"> そこで彼らはことづけしてヨセフに言った、「あなたの父は死ぬ前に命じて言われました、</span>
<span className="v" id="v17" data-v="17" data-xref="エペソ人への手紙 4:32; マタイによる福音書 6:14–15; 創世記 45:8"> 『おまえたちはヨセフに言いなさい、「あなたの兄弟たちはあなたに悪をおこなったが、どうかそのとがと罪をゆるしてやってください」』。今どうかあなたの父の神に仕えるしもべらのとがをゆるしてください」。ヨセフはこの言葉を聞いて泣いた。</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 37:7–11; 創世記 42:6; 創世記 45:3"> やがて兄弟たちもきて、彼の前に伏して言った、「このとおり、わたしたちはあなたのしもべです」。</span>
<span className="v" id="v19" data-v="19" data-xref="ローマ人への手紙 12:19; 創世記 45:5; 創世記 30:2"> ヨセフは彼らに言った、「恐れることはいりません。わたしが神に代ることができましょうか。</span>
<span className="v" id="v20" data-v="20" data-xref="ローマ人への手紙 8:28; 詩篇 119:71; 創世記 45:5–8"> あなたがたはわたしに対して悪をたくらんだが、神はそれを良きに変らせて、今日のように多くの民の命を救おうと計らわれました。</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 47:12; ペテロの第一の手紙 3:9; 創世記 45:10–11"> それゆえ恐れることはいりません。わたしはあなたがたとあなたがたの子供たちを養いましょう」。彼は彼らを慰めて、親切に語った。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22"> このようにしてヨセフは父の家族と共にエジプトに住んだ。そしてヨセフは百十年生きながらえた。</span>
<span className="v" id="v23" data-v="23" data-xref="民数記 32:39; 創世記 30:3; ヨブ記 42:16"> ヨセフはエフライムの三代の子孫を見た。マナセの子マキルの子らも生れてヨセフのひざの上に置かれた。</span>
<span className="v" id="v24" data-v="24" data-xref="出エジプト記 3:16–17; 創世記 35:12; 創世記 26:3"> ヨセフは兄弟たちに言った、「わたしはやがて死にます。神は必ずあなたがたを顧みて、この国から連れ出し、アブラハム、イサク、ヤコブに誓われた地に導き上られるでしょう」。</span>
<span className="v" id="v25" data-v="25" data-xref="出エジプト記 13:19; ヨシュア記 24:32; 創世記 47:29–31"> さらにヨセフは、「神は必ずあなたがたを顧みられる。その時、あなたがたはわたしの骨をここから携え上りなさい」と言ってイスラエルの子らに誓わせた。</span>
<span className="v" id="v26" data-v="26" data-xref="創世記 50:2–3; 創世記 47:9; ヨシュア記 24:29"> こうしてヨセフは百十歳で死んだ。彼らはこれに薬を塗り、棺に納めて、エジプトに置いた。</span>
</div>

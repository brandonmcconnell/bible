<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 45:10; 創世記 46:31; 創世記 46:28"> ヨセフは行って、パロに言った、「わたしの父と兄弟たち、その羊、牛およびすべての持ち物がカナンの地からきて、今ゴセンの地におります」。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行伝 7:13; コロサイ人への手紙 1:28; ユダの手紙 1:24"> そしてその兄弟のうちの五人を連れて行って、パロに会わせた。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 46:33–34; テサロニケ人への第二の手紙 3:10; 創世記 4:2"> パロはヨセフの兄弟たちに言った、「あなたがたの職業は何か」。彼らはパロに言った、「しもべらは羊を飼う者です。われわれも、われわれの先祖もそうです」。</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 46:34; 創世記 15:13; 申命記 26:5"> 彼らはまたパロに言った、「この国に寄留しようとしてきました。カナンの地はききんが激しく、しもべらの群れのための牧草がないのです。どうかしもべらをゴセンの地に住ませてください」。</span>
<span className="v" id="v5" data-v="5"> パロはヨセフに言った、「あなたの父と兄弟たちとがあなたのところにきた。</span>
<span className="v" id="v6" data-v="6" data-xref="出エジプト記 18:21; 箴言 22:29; 創世記 47:11"> エジプトの地はあなたの前にある。地の最も良い所にあなたの父と兄弟たちとを住ませなさい。ゴセンの地に彼らを住ませなさい。もしあなたが彼らのうちに有能な者があるのを知っているなら、その者にわたしの家畜をつかさどらせなさい」。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="創世記 47:10; サムエル記下 8:10; サムエル記上 2:20"> そこでヨセフは父ヤコブを導いてパロの前に立たせた。ヤコブはパロを祝福した。</span>
<span className="v" id="v8" data-v="8"> パロはヤコブに言った、「あなたの年はいくつか」。</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 39:12; 詩篇 39:5; ヨブ記 14:1"> ヤコブはパロに言った、「わたしの旅路のとしつきは、百三十年です。わたしのよわいの日はわずかで、ふしあわせで、わたしの先祖たちのよわいの日と旅路の日には及びません」。</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 47:7; 詩篇 129:8; ヘブル人への手紙 7:7"> ヤコブはパロを祝福し、パロの前を去った。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 47:6; 出エジプト記 1:11; 出エジプト記 12:37"> ヨセフはパロの命じたように、父と兄弟たちとのすまいを定め、彼らにエジプトの国で最も良い地、ラメセスの地を所有として与えた。</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 45:11; テモテヘの第一の手紙 5:8; 創世記 47:1"> またヨセフは父と兄弟たちと父の全家とに、家族の数にしたがい、食物を与えて養った。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="使徒行伝 7:11; 列王紀上 18:5; 哀歌 4:9"> さて、ききんが非常に激しかったので、全地に食物がなく、エジプトの国もカナンの国も、ききんのために衰えた。</span>
<span className="v" id="v14" data-v="14" data-xref="創世記 41:56; ルカによる福音書 16:10–12; ルカによる福音書 16:1–2"> それでヨセフは人々が買った穀物の代金としてエジプトの国とカナンの国にあった銀をみな集め、その銀をパロの家に納めた。</span>
<span className="v" id="v15" data-v="15" data-xref="士師記 8:8; 詩篇 37:3; マタイによる福音書 6:11"> こうしてエジプトの国とカナンの国に銀が尽きたとき、エジプトびとはみなヨセフのもとにきて言った、「食物をください。銀が尽きたからとて、どうしてあなたの前で死んでよいでしょう」。</span>
<span className="v" id="v16" data-v="16" data-xref="コロサイ人への手紙 4:5; ダニエル書 6:5–7; コリント人への第一の手紙 10:32"> ヨセフは言った、「あなたがたの家畜を出しなさい。銀が尽きたのなら、あなたがたの家畜と引き替えで食物をわたそう」。</span>
<span className="v" id="v17" data-v="17" data-xref="ヨブ記 2:4; 出エジプト記 9:3; イザヤ書 31:1"> 彼らはヨセフの所へ家畜をひいてきたので、ヨセフは馬と羊の群れと牛の群れ及びろばと引き替えで、食物を彼らにわたした。こうして彼はその年、すべての家畜と引き替えた食物で彼らを養った。</span>
<span className="v" id="v18" data-v="18" data-xref="列王紀下 6:26; エレミヤ書 38:9"> やがてその年は暮れ、次の年、人々はまたヨセフの所へきて言った、「わが主には何事も隠しません。われわれの銀は尽き、獣の群れもわが主のものになって、われわれのからだと田地のほかはわが主の前に何も残っていません。</span>
<span className="v" id="v19" data-v="19" data-xref="ネヘミヤ書 5:2–3; ヨブ記 2:4; 哀歌 1:11"> われわれはどうして田地と一緒に、あなたの目の前で滅んでよいでしょう。われわれと田地とを食物と引き替えで買ってください。われわれは田地と一緒にパロの奴隷となりましょう。また種をください。そうすればわれわれは生きながらえ、死を免れて、田地も荒れないでしょう」。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20"> そこでヨセフはエジプトの田地をみなパロのために買い取った。ききんがエジプトびとに、きびしかったので、めいめいその田畑を売ったからである。こうして地はパロのものとなった。</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 41:48"> そしてヨセフはエジプトの国境のこの端からかの端まで民を奴隷とした。</span>
<span className="v" id="v22" data-v="22" data-xref="エズラ記 7:24; ネヘミヤ書 13:10; テサロニケ人への第二の手紙 3:10"> ただ祭司の田地は買い取らなかった。祭司にはパロの給与があって、パロが与える給与で生活していたので、その田地を売らなかったからである。</span>
<span className="v" id="v23" data-v="23" data-xref="詩篇 112:5; 詩篇 41:1; 伝道の書 11:6"> ヨセフは民に言った、「わたしはきょう、あなたがたとその田地とを買い取って、パロのものとした。あなたがたに種をあげるから地にまきなさい。</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 41:34; 詩篇 41:1; 詩篇 112:5"> 収穫の時は、その五分の一をパロに納め、五分の四を自分のものとして田畑の種とし、自分と家族の食糧とし、また子供の食糧としなさい」。</span>
<span className="v" id="v25" data-v="25" data-xref="創世記 33:15; 箴言 11:26–27; 創世記 18:3"> 彼らは言った、「あなたはわれわれの命をお救いくださった。どうかわが主の前に恵みを得させてください。われわれはパロの奴隷になりましょう」。</span>
<span className="v" id="v26" data-v="26" data-xref="創世記 47:22; エゼキエル書 7:24"> ヨセフはエジプトの田地について、収穫の五分の一をパロに納めることをおきてとしたが、それは今日に及んでいる。ただし祭司の田地だけはパロのものとならなかった。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="創世記 46:3; 出エジプト記 1:7; 使徒行伝 7:17"> さてイスラエルはエジプトの国でゴセンの地に住み、そこで財産を得、子を生み、大いにふえた。</span>
<span className="v" id="v28" data-v="28" data-xref="詩篇 90:10; 創世記 47:8–9; 創世記 37:2"> ヤコブはエジプトの国で十七年生きながらえた。ヤコブのよわいの日は百四十七年であった。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="申命記 31:14; 創世記 24:49; 創世記 24:2"> イスラエルは死ぬ時が近づいたので、その子ヨセフを呼んで言った、「もしわたしがあなたの前に恵みを得るなら、どうか手をわたしのももの下に入れて誓い、親切と誠実とをもってわたしを取り扱ってください。どうかわたしをエジプトには葬らないでください。</span>
<span className="v" id="v30" data-v="30" data-xref="創世記 49:29–32; 創世記 23:19; 創世記 25:9"> わたしが先祖たちと共に眠るときには、わたしをエジプトから運び出して先祖たちの墓に葬ってください」。ヨセフは言った、「あなたの言われたようにいたします」。</span>
<span className="v" id="v31" data-v="31" data-xref="列王紀上 1:47; ヘブル人への手紙 11:21; 創世記 24:3"> ヤコブがまた、「わたしに誓ってください」と言ったので、彼は誓った。イスラエルは床のかしらで拝んだ。</span>
</div>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 26:1; 創世記 26:6; 創世記 18:1"> アブラハムはそこからネゲブの地に移って、カデシとシュルの間に住んだ。彼がゲラルにとどまっていた時、</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 12:15; 創世記 26:7; 創世記 12:11–13"> アブラハムは妻サラのことを、「これはわたしの妹です」と言ったので、ゲラルの王アビメレクは、人をつかわしてサラを召し入れた。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 20:7; マタイによる福音書 27:19; 詩篇 105:14"> ところが神は夜の夢にアビメレクに臨んで言われた、「あなたは召し入れたあの女のゆえに死なねばならない。彼女は夫のある身である」。</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 18:23–25; 歴代志上 21:17; サムエル記下 4:11"> アビメレクはまだ彼女に近づいていなかったので言った、「主よ、あなたは正しい民でも殺されるのですか。</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 7:8; 列王紀上 9:4; ダニエル書 6:22"> 彼はわたしに、これはわたしの妹ですと言ったではありませんか。また彼女も自分で、彼はわたしの兄ですと言いました。わたしは心も清く、手もいさぎよく、このことをしました」。</span>
<span className="v" id="v6" data-v="6" data-xref="サムエル記上 25:34; 箴言 21:1; サムエル記上 25:26"> 神はまた夢で彼に言われた、「そうです、あなたが清い心をもってこのことをしたのを知っていたから、わたしもあなたを守って、わたしに対して罪を犯させず、彼女にふれることを許さなかったのです。</span>
<span className="v" id="v7" data-v="7" data-xref="ヨブ記 42:8; サムエル記上 7:5; サムエル記下 24:17"> いま彼の妻を返しなさい。彼は預言者ですから、あなたのために祈って、命を保たせるでしょう。もし返さないなら、あなたも身内の者もみな必ず死ぬと知らなければなりません」。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8"> そこでアビメレクは朝早く起き、しもべたちをことごとく召し集めて、これらの事をみな語り聞かせたので、人々は非常に恐れた。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 12:18; 創世記 26:10; 創世記 39:9"> そしてアビメレクはアブラハムを召して言った、「あなたはわれわれに何をするのですか。あなたに対してわたしがどんな罪を犯したために、あなたはわたしとわたしの国とに、大きな罪を負わせるのですか。あなたはしてはならぬことをわたしにしたのです」。</span>
<span className="v" id="v10" data-v="10"> アビメレクはまたアブラハムに言った、「あなたはなんと思って、この事をしたのですか」。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 26:7; 創世記 12:12; ヨブ記 28:28"> アブラハムは言った、「この所には神を恐れるということが、まったくないので、わたしの妻のゆえに人々がわたしを殺すと思ったからです。</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 11:29; 創世記 12:13; テサロニケ人への第一の手紙 5:22"> また彼女はほんとうにわたしの妹なのです。わたしの父の娘ですが、母の娘ではありません。そして、わたしの妻になったのです。</span>
<span className="v" id="v13" data-v="13" data-xref="創世記 12:1; 創世記 12:9; 使徒行伝 7:3–5"> 神がわたしに父の家を離れて、行き巡らせた時、わたしは彼女に、あなたはわたしたちの行くさきざきでわたしを兄であると言ってください。これはあなたがわたしに施す恵みであると言いました」。</span>
<span className="v" id="v14" data-v="14" data-xref="創世記 12:16; 創世記 20:2; 創世記 20:7"> そこでアビメレクは羊、牛および男女の奴隷を取ってアブラハムに与え、その妻サラを彼に返した。</span>
<span className="v" id="v15" data-v="15" data-xref="創世記 34:10; 創世記 13:9; 創世記 47:6"> そしてアビメレクは言った、「わたしの地はあなたの前にあります。あなたの好きな所に住みなさい」。</span>
<span className="v" id="v16" data-v="16" data-xref="箴言 27:5; 創世記 20:5; 創世記 24:65"> またサラに言った、「わたしはあなたの兄に銀千シケルを与えました。これはあなたの身に起ったすべての事について、あなたに償いをするものです。こうしてすべての人にあなたは正しいと認められます」。</span>
<span className="v" id="v17" data-v="17" data-xref="ヤコブの手紙 5:16; マタイによる福音書 21:22; ヨブ記 42:9–10"> そこでアブラハムは神に祈った。神はアビメレクとその妻および、はしためたちをいやされたので、彼らは子を産むようになった。</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 12:17; 創世記 30:2; 創世記 16:2"> これは主がさきにアブラハムの妻サラのゆえに、アビメレクの家のすべての者の胎を、かたく閉ざされたからである。</span>
</div>

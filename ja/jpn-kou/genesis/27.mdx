<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="サムエル記上 3:2; 創世記 48:10; 創世記 25:23–25"> イサクは年老い、目がかすんで見えなくなった時、長子エサウを呼んで言った、「子よ」。彼は答えて言った、「ここにおります」。</span>
<span className="v" id="v2" data-v="2" data-xref="ヤコブの手紙 4:14; 伝道の書 9:10; 箴言 27:1"> イサクは言った。「わたしは年老いて、いつ死ぬかも知れない。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 25:27–28; 創世記 10:9; コリント人への第一の手紙 6:12"> それであなたの武器、弓矢をもって野に出かけ、わたしのために、しかの肉をとってきて、</span>
<span className="v" id="v4" data-v="4" data-xref="ヘブル人への手紙 11:20; 創世記 48:9; 創世記 49:28"> わたしの好きなおいしい食べ物を作り、持ってきて食べさせよ。わたしは死ぬ前にあなたを祝福しよう」。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5"> イサクがその子エサウに語るのをリベカは聞いていた。やがてエサウが、しかの肉を獲ようと野に出かけたとき、</span>
<span className="v" id="v6" data-v="6" data-xref="創世記 25:28"> リベカはその子ヤコブに言った、「わたしは聞いていましたが、父は兄エサウに、</span>
<span className="v" id="v7" data-v="7" data-xref="ヨシュア記 6:26; サムエル記上 24:19; 申命記 33:1"> 『わたしのために、しかの肉をとってきて、おいしい食べ物を作り、わたしに食べさせよ。わたしは死ぬ前に、主の前であなたを祝福しよう』と言いました。</span>
<span className="v" id="v8" data-v="8" data-xref="エペソ人への手紙 6:1; 創世記 27:13; 使徒行伝 5:29"> それで、子よ、わたしの言葉にしたがい、わたしの言うとおりにしなさい。</span>
<span className="v" id="v9" data-v="9" data-xref="士師記 13:15; サムエル記上 16:20"> 群れの所へ行って、そこからやぎの子の良いのを二頭わたしの所に取ってきなさい。わたしはそれで父のために、父の好きなおいしい食べ物を作りましょう。</span>
<span className="v" id="v10" data-v="10"> あなたはそれを持って行って父に食べさせなさい。父は死ぬ前にあなたを祝福するでしょう」。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 25:25"> ヤコブは母リベカに言った、「兄エサウは毛深い人ですが、わたしはなめらかです。</span>
<span className="v" id="v12" data-v="12" data-xref="申命記 27:18; 創世記 25:27; マラキ書 1:14"> おそらく父はわたしにさわってみるでしょう。そうすればわたしは父を欺く者と思われ、祝福を受けず、かえってのろいを受けるでしょう」。</span>
<span className="v" id="v13" data-v="13" data-xref="マタイによる福音書 27:25; サムエル記上 25:24; サムエル記下 14:9"> 母は彼に言った、「子よ、あなたがうけるのろいはわたしが受けます。ただ、わたしの言葉に従い、行って取ってきなさい」。</span>
<span className="v" id="v14" data-v="14" data-xref="創世記 27:9; 箴言 23:2–3; 創世記 25:28"> そこで彼は行ってやぎの子を取り、母の所に持ってきたので、母は父の好きなおいしい食べ物を作った。</span>
<span className="v" id="v15" data-v="15" data-xref="創世記 27:27; ルカによる福音書 20:46; ルカによる福音書 15:22"> リベカは家にあった長子エサウの晴着を取って、弟ヤコブに着せ、</span>
<span className="v" id="v16" data-v="16"> また子やぎの皮を手と首のなめらかな所とにつけさせ、</span>
<span className="v" id="v17" data-v="17"> 彼女が作ったおいしい食べ物とパンとをその子ヤコブの手にわたした。</span>
</div>
<div className="bp poetry">
<span className="v" id="v18" data-v="18"> そこでヤコブは父の所へ行って言った、「父よ」。すると父は言った、「わたしはここにいる。子よ、あなたはだれか」。</span>
<span className="v" id="v19" data-v="19" data-xref="イザヤ書 28:15; マタイによる福音書 26:70–74; ゼカリヤ書 13:3–4"> ヤコブは父に言った、「長子エサウです。あなたがわたしに言われたとおりにいたしました。どうぞ起きて、すわってわたしのしかの肉を食べ、あなたみずからわたしを祝福してください」。</span>
<span className="v" id="v20" data-v="20" data-xref="出エジプト記 20:7; ヨブ記 13:7; 創世記 24:12"> イサクはその子に言った、「子よ、どうしてあなたはこんなに早く手に入れたのか」。彼は言った、「あなたの神、主がわたしにしあわせを授けられたからです」。</span>
<span className="v" id="v21" data-v="21" data-xref="ヤコブの手紙 4:8; イザヤ書 57:19; 創世記 27:12"> イサクはヤコブに言った、「子よ、近寄りなさい。わたしは、さわってみて、あなたが確かにわが子エサウであるかどうかをみよう」。</span>
<span className="v" id="v22" data-v="22"> ヤコブが、父イサクに近寄ったので、イサクは彼にさわってみて言った、「声はヤコブの声だが、手はエサウの手だ」。</span>
<span className="v" id="v23" data-v="23" data-xref="創世記 27:16; ヘブル人への手紙 11:20; ローマ人への手紙 9:11–12"> ヤコブの手が兄エサウの手のように毛深かったため、イサクはヤコブを見わけることができなかったので、彼を祝福した。</span>
<span className="v" id="v24" data-v="24" data-xref="コロサイ人への手紙 3:9; エペソ人への手紙 4:25; 箴言 12:22"> イサクは言った、「あなたは確かにわが子エサウですか」。彼は言った、「そうです」。</span>
<span className="v" id="v25" data-v="25" data-xref="創世記 27:4"> イサクは言った、「わたしの所へ持ってきなさい。わが子のしかの肉を食べて、わたしみずから、あなたを祝福しよう」。ヤコブがそれを彼の所に持ってきたので、彼は食べた。またぶどう酒を持ってきたので、彼は飲んだ。</span>
<span className="v" id="v26" data-v="26"> そして父イサクは彼に言った、「子よ、さあ、近寄ってわたしに口づけしなさい」。</span>
<span className="v" id="v27" data-v="27" data-xref="ヘブル人への手紙 6:7; 詩篇 65:10; ヘブル人への手紙 11:20"> 彼が近寄って口づけした時、イサクはその着物のかおりをかぎ、彼を祝福して言った、<br /><span className="pl pl-1">「ああ、わが子のかおりは、</span><br /><span className="pl pl-1">主が祝福された野のかおりのようだ。</span></span>
<span className="v" id="v28" data-v="28" data-xref="申命記 33:28; 申命記 33:13; 詩篇 133:3"> <span className="pl pl-1">どうか神が、天の露と、</span><br /><span className="pl pl-1">地の肥えたところと、多くの穀物と、</span><br /><span className="pl pl-1">新しいぶどう酒とをあなたに賜わるように。</span></span>
<span className="v" id="v29" data-v="29" data-xref="創世記 12:3; 民数記 24:9; イザヤ書 49:23"> <span className="pl pl-1">もろもろの民はあなたに仕え、</span><br /><span className="pl pl-1">もろもろの国はあなたに身をかがめる。</span><br /><span className="pl pl-1">あなたは兄弟たちの主となり、</span><br /><span className="pl pl-1">あなたの母の子らは、</span><br /><span className="pl pl-1">あなたに身をかがめるであろう。</span><br /><span className="pl pl-1">あなたをのろう者はのろわれ、</span><br /><span className="pl pl-1">あなたを祝福する者は祝福される」。</span></span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30"> イサクがヤコブを祝福し終って、ヤコブが父イサクの前から出て行くとすぐ、兄エサウが狩から帰ってきた。</span>
<span className="v" id="v31" data-v="31" data-xref="創世記 27:4"> 彼もまたおいしい食べ物を作って、父の所に持ってきて、言った、「父よ、起きてあなたの子のしかの肉を食べ、あなたみずから、わたしを祝福してください」。</span>
<span className="v" id="v32" data-v="32" data-xref="創世記 27:18"> 父イサクは彼に言った、「あなたは、だれか」。彼は言った、「わたしはあなたの子、長子エサウです」。</span>
<span className="v" id="v33" data-v="33" data-xref="創世記 28:3–4; ローマ人への手紙 11:29; エペソ人への手紙 1:3"> イサクは激しくふるえて言った、「それでは、あのしかの肉を取って、わたしに持ってきた者はだれか。わたしはあなたが来る前に、みんな食べて彼を祝福した。ゆえに彼が祝福を得るであろう」。</span>
<span className="v" id="v34" data-v="34" data-xref="ヘブル人への手紙 12:17; 箴言 1:31; サムエル記上 30:4"> エサウは父の言葉を聞いた時、大声をあげ、激しく叫んで、父に言った、「父よ、わたしを、わたしをも祝福してください」。</span>
<span className="v" id="v35" data-v="35" data-xref="テサロニケ人への第一の手紙 4:6; ヨブ記 13:7; マラキ書 2:10"> イサクは言った、「あなたの弟が偽ってやってきて、あなたの祝福を奪ってしまった」。</span>
<span className="v" id="v36" data-v="36" data-xref="創世記 25:26; ヨハネによる福音書 1:47; 創世記 32:28"> エサウは言った、「よくもヤコブと名づけたものだ。彼は二度までもわたしをおしのけた。さきには、わたしの長子の特権を奪い、こんどはわたしの祝福を奪った」。また言った、「あなたはわたしのために祝福を残しておかれませんでしたか」。</span>
<span className="v" id="v37" data-v="37" data-xref="サムエル記下 8:14; 創世記 27:28–29; 創世記 25:23"> イサクは答えてエサウに言った、「わたしは彼をあなたの主人とし、兄弟たちを皆しもべとして彼に与え、また穀物とぶどう酒を彼に授けた。わが子よ、今となっては、あなたのために何ができようか」。</span>
<span className="v" id="v38" data-v="38" data-xref="ヘブル人への手紙 12:17; 創世記 27:34; イザヤ書 65:14"> エサウは父に言った、「父よ、あなたの祝福はただ一つだけですか。父よ、わたしを、わたしをも祝福してください」。エサウは声をあげて泣いた。</span>
</div>
<div className="bp poetry">
<span className="v" id="v39" data-v="39" data-xref="創世記 27:28; ヘブル人への手紙 11:20; ヨシュア記 24:4"> 父イサクは答えて彼に言った、<br /><span className="pl pl-1">「あなたのすみかは地の肥えた所から離れ、</span><br /><span className="pl pl-1">また上なる天の露から離れるであろう。</span></span>
<span className="v" id="v40" data-v="40" data-xref="列王紀下 8:20–22; 創世記 25:23; 歴代志下 25:11–12"> <span className="pl pl-1">あなたはつるぎをもって世を渡り、</span><br /><span className="pl pl-1">あなたの弟に仕えるであろう。</span><br /><span className="pl pl-1">しかし、あなたが勇み立つ時、</span><br /><span className="pl pl-1">首から、そのくびきを振り落すであろう」。</span></span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="ヨハネの第一の手紙 3:12–15; 創世記 37:4; 創世記 50:3–4"> こうしてエサウは父がヤコブに与えた祝福のゆえにヤコブを憎んだ。エサウは心の内で言った、「父の喪の日も遠くはないであろう。その時、弟ヤコブを殺そう」。</span>
<span className="v" id="v42" data-v="42" data-xref="創世記 37:18–20; サムエル記上 30:5; 創世記 42:21–22"> しかしリベカは長子エサウのこの言葉を人づてに聞いたので、人をやり、弟ヤコブを呼んで言った、「兄エサウはあなたを殺そうと考えて、みずから慰めています。</span>
<span className="v" id="v43" data-v="43" data-xref="創世記 27:8; 創世記 11:31; 創世記 27:13"> 子よ、今わたしの言葉に従って、すぐハランにいるわたしの兄ラバンのもとにのがれ、</span>
<span className="v" id="v44" data-v="44" data-xref="創世記 31:38; 創世記 31:41"> あなたの兄の怒りが解けるまで、しばらく彼の所にいなさい。</span>
<span className="v" id="v45" data-v="45" data-xref="箴言 19:21; 創世記 4:8–16; 創世記 9:5–6"> 兄の憤りが解けて、あなたのした事を兄が忘れるようになったならば、わたしは人をやって、あなたをそこから迎えましょう。どうして、わたしは一日のうちにあなたがたふたりを失ってよいでしょうか」。</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="創世記 24:3; 創世記 26:34–35; 創世記 28:8"> リベカはイサクに言った、「わたしはヘテびとの娘どものことで、生きているのがいやになりました。もしヤコブがこの地の、あの娘どものようなヘテびとの娘を妻にめとるなら、わたしは生きていて、何になりましょう」。</span>
</div>

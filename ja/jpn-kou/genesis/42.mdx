<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行伝 7:12; ヨシュア記 7:10; 列王紀下 8:3–4"> ヤコブはエジプトに穀物があると知って、むすこたちに言った、「あなたがたはなぜ顔を見合わせているのですか」。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 43:8; 創世記 45:9; 創世記 43:2"> また言った、「エジプトに穀物があるということだが、あなたがたはそこへ下って行って、そこから、われわれのため穀物を買ってきなさい。そうすれば、われわれは生きながらえて、死を免れるであろう」。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 42:5; 創世記 42:13"> そこでヨセフの十人の兄弟は穀物を買うためにエジプトへ下った。</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 42:38; 創世記 43:29; 創世記 11:4"> しかし、ヤコブはヨセフの弟ベニヤミンを兄弟たちと一緒にやらなかった。彼が災に会うのを恐れたからである。</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 41:57; 使徒行伝 7:11; 創世記 12:10"> こうしてイスラエルの子らは穀物を買おうと人々に交じってやってきた。カナンの地にききんがあったからである。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="ヨハネの黙示録 3:9; 創世記 37:7–10; 創世記 41:40–41"> ときにヨセフは国のつかさであって、国のすべての民に穀物を売ることをしていた。ヨセフの兄弟たちはきて、地にひれ伏し、彼を拝した。</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 42:30; 創世記 42:14–17; マタイによる福音書 15:23–26"> ヨセフは兄弟たちを見て、それと知ったが、彼らに向かっては知らぬ者のようにし、荒々しく語った。すなわち彼らに言った、「あなたがたはどこからきたのか」。彼らは答えた、「食糧を買うためにカナンの地からきました」。</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 37:2; ヨハネによる福音書 20:14; ルカによる福音書 24:16"> ヨセフは、兄弟たちであるのを知っていたが、彼らはヨセフとは知らなかった。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 37:5–9; 出エジプト記 32:35; ヨシュア記 2:1"> ヨセフはかつて彼らについて見た夢を思い出して、彼らに言った、「あなたがたは回し者で、この国のすきをうかがうためにきたのです」。</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 37:8; サムエル記上 26:17; 創世記 27:37"> 彼らはヨセフに答えた、「いいえ、わが主よ、しもべらはただ食糧を買うためにきたのです。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 42:19; コリント人への第二の手紙 6:4; ヨハネによる福音書 7:18"> われわれは皆、ひとりの人の子で、真実な者です。しもべらは回し者ではありません」。</span>
<span className="v" id="v12" data-v="12"> ヨセフは彼らに言った、「いや、あなたがたはこの国のすきをうかがうためにきたのです」。</span>
<span className="v" id="v13" data-v="13" data-xref="創世記 37:30; 創世記 42:32; 創世記 44:20"> 彼らは言った、「しもべらは十二人兄弟で、カナンの地にいるひとりの人の子です。末の弟は今、父と一緒にいますが、他のひとりはいなくなりました」。</span>
<span className="v" id="v14" data-v="14" data-xref="マタイによる福音書 15:21–28; ヨブ記 13:24; 創世記 42:9–11"> ヨセフは彼らに言った、「わたしが言ったとおり、あなたがたは回し者です。</span>
<span className="v" id="v15" data-v="15" data-xref="サムエル記上 17:55; エレミヤ書 5:7; 創世記 42:16"> あなたがたをこうしてためしてみよう。パロのいのちにかけて誓います。末の弟がここにこなければ、あなたがたはここを出ることはできません。</span>
<span className="v" id="v16" data-v="16" data-xref="創世記 42:11"> あなたがたのひとりをやって弟を連れてこさせなさい。それまであなたがたをつないでおいて、あなたがたに誠実があるかどうか、あなたがたの言葉をためしてみよう。パロのいのちにかけて誓います。あなたがたは確かに回し者です」。</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 40:4; ヘブル人への手紙 12:10; 創世記 40:7"> ヨセフは彼らをみな一緒に三日の間、監禁所に入れた。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="レビ記 25:43; ネヘミヤ書 5:15; ルカによる福音書 18:2"> 三日目にヨセフは彼らに言った、「こうすればあなたがたは助かるでしょう。わたしは神を恐れます。</span>
<span className="v" id="v19" data-v="19" data-xref="創世記 45:23; イザヤ書 42:7; 創世記 40:3"> もしあなたがたが真実な者なら、兄弟のひとりをあなたがたのいる監禁所に残し、あなたがたは穀物を携えて行って、家族の飢えを救いなさい。</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 44:23; 創世記 43:5; 創世記 42:34"> そして末の弟をわたしのもとに連れてきなさい。そうすればあなたがたの言葉のほんとうであることがわかって、死を免れるでしょう」。彼らはそのようにした。</span>
<span className="v" id="v21" data-v="21" data-xref="ホセア書 5:15; マルコによる福音書 9:43–45; 創世記 37:23–28"> 彼らは互に言った、「確かにわれわれは弟の事で罪がある。彼がしきりに願った時、その心の苦しみを見ながら、われわれは聞き入れなかった。それでこの苦しみに会うのだ」。</span>
<span className="v" id="v22" data-v="22" data-xref="歴代志下 24:22; 詩篇 9:12; 列王紀上 2:32"> ルベンが彼らに答えて言った、「わたしはあなたがたに、この子供に罪を犯すなと言ったではないか。それにもかかわらず、あなたがたは聞き入れなかった。それで彼の血の報いを受けるのです」。</span>
<span className="v" id="v23" data-v="23" data-xref="コリント人への第二の手紙 5:20; ヨハネによる福音書 16:13–14"> 彼らはヨセフが聞きわけているのを知らなかった。相互の間に通訳者がいたからである。</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 43:30; ユダの手紙 1:22–23; ヘブル人への手紙 4:15"> ヨセフは彼らを離れて行って泣き、また帰ってきて彼らと語り、そのひとりシメオンを捕えて、彼らの目の前で縛った。</span>
<span className="v" id="v25" data-v="25" data-xref="ペテロの第一の手紙 3:9; ローマ人への手紙 12:17–21; 創世記 45:21"> そしてヨセフは人々に命じて、彼らの袋に穀物を満たし、めいめいの銀を袋に返し、道中の食料を与えさせた。ヨセフはこのように彼らにした。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26"> 彼らは穀物をろばに負わせてそこを去った。</span>
<span className="v" id="v27" data-v="27" data-xref="出エジプト記 4:24; ルカによる福音書 2:7; ルカによる福音書 10:34"> そのひとりが宿で、ろばに飼葉をやるため袋をあけて見ると、袋の口に自分の銀があった。</span>
<span className="v" id="v28" data-v="28" data-xref="イザヤ書 45:7; 哀歌 3:37; 創世記 42:36"> 彼は兄弟たちに言った、「わたしの銀は返してある。しかも見よ、それは袋の中にある」。そこで彼らは非常に驚き、互に震えながら言った、「神がわれわれにされたこのことは何事だろう」。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29"> こうして彼らはカナンの地にいる父ヤコブのもとに帰り、その身に起った事をことごとく告げて言った、</span>
<span className="v" id="v30" data-v="30" data-xref="創世記 42:7"> 「あの国の君は、われわれに荒々しく語り、国をうかがう回し者だと言いました。</span>
<span className="v" id="v31" data-v="31" data-xref="創世記 42:11"> われわれは彼に答えました、『われわれは真実な者であって回し者ではない。</span>
<span className="v" id="v32" data-v="32"> われわれは十二人兄弟で、同じ父の子である。ひとりはいなくなり、末の弟は今父と共にカナンの地にいる』。</span>
<span className="v" id="v33" data-v="33" data-xref="創世記 42:19–20; 創世記 42:15"> その国の君であるその人はわれわれに言いました、『わたしはこうしてあなたがたの真実な者であるのを知ろう。あなたがたは兄弟のひとりをわたしのもとに残し、穀物を携えて行って、家族の飢えを救いなさい。</span>
<span className="v" id="v34" data-v="34" data-xref="創世記 34:10; 創世記 34:21; 列王紀上 10:15"> そして末の弟をわたしのもとに連れてきなさい。そうすればあなたがたが回し者ではなく、真実な者であるのを知って、あなたがたの兄弟を返し、この国であなたがたに取引させましょう』」。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="創世記 43:21; 創世記 43:12; 創世記 43:15"> 彼らが袋のものを出して見ると、めいめいの金包みが袋の中にあったので、彼らも父も金包みを見て恐れた。</span>
<span className="v" id="v36" data-v="36" data-xref="創世記 43:14; ローマ人への手紙 8:31; イザヤ書 27:9"> 父ヤコブは彼らに言った、「あなたがたはわたしに子を失わせた。ヨセフはいなくなり、シメオンもいなくなった。今度はベニヤミンをも取り去る。これらはみなわたしの身にふりかかって来るのだ」。</span>
<span className="v" id="v37" data-v="37" data-xref="創世記 46:9; ミカ書 6:7; 創世記 43:9"> ルベンは父に言った、「もしわたしが彼をあなたのもとに連れて帰らなかったら、わたしのふたりの子を殺してください。ただ彼をわたしの手にまかせてください。わたしはきっと、あなたのもとに彼を連れて帰ります」。</span>
<span className="v" id="v38" data-v="38" data-xref="創世記 37:35; 創世記 42:4; 創世記 37:33"> ヤコブは言った、「わたしの子はあなたがたと共に下って行ってはならない。彼の兄は死に、ただひとり彼が残っているのだから。もしあなたがたの行く道で彼が災に会えば、あなたがたは、しらがのわたしを悲しんで陰府に下らせるであろう」。</span>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 28:13; 創世記 26:22–25; 創世記 28:10"> イスラエルはその持ち物をことごとく携えて旅立ち、ベエルシバに行って、父イサクの神に犠牲をささげた。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 15:1; ヨブ記 33:14–15; ヨブ記 4:13"> この時、神は夜の幻のうちにイスラエルに語って言われた、「ヤコブよ、ヤコブよ」。彼は言った、「ここにいます」。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 12:2; 申命記 26:5; イザヤ書 43:1–2"> 神は言われた、「わたしは神、あなたの父の神である。エジプトに下るのを恐れてはならない。わたしはあそこであなたを大いなる国民にする。</span>
<span className="v" id="v4" data-v="4" data-xref="出エジプト記 3:8; 創世記 28:15; 創世記 48:21"> わたしはあなたと一緒にエジプトに下り、また必ずあなたを導き上るであろう。ヨセフが手ずからあなたの目を閉じるであろう」。</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 45:21; 創世記 45:19; 創世記 45:27"> そしてヤコブはベエルシバを立った。イスラエルの子らはヤコブを乗せるためにパロの送った車に、父ヤコブと幼な子たちと妻たちを乗せ、</span>
<span className="v" id="v6" data-v="6" data-xref="ヨシュア記 24:4; イザヤ書 52:4; 使徒行伝 7:15"> またその家畜とカナンの地で得た財産を携え、ヤコブとその子孫は皆ともにエジプトへ行った。</span>
<span className="v" id="v7" data-v="7"> こうしてヤコブはその子と、孫および娘と孫娘などその子孫をみな連れて、エジプトへ行った。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="出エジプト記 1:1–5; 申命記 33:6; 歴代志上 2:1–55"> イスラエルの子らでエジプトへ行った者の名は次のとおりである。すなわちヤコブとその子らであるが、ヤコブの長子はルベン。</span>
<span className="v" id="v9" data-v="9"> ルベンの子らはハノク、パル、ヘヅロン、カルミ。</span>
<span className="v" id="v10" data-v="10" data-xref="出エジプト記 6:15; 創世記 29:33; 創世記 28:1"> シメオンの子らはエムエル、ヤミン、オハデ、ヤキン、ゾハル及びカナンの女の産んだ子シャウル。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 29:34; 歴代志上 6:16; 民数記 8:1–26"> レビの子らはゲルション、コハテ、メラリ。</span>
<span className="v" id="v12" data-v="12" data-xref="歴代志上 4:21; 創世記 38:10; 創世記 29:35"> ユダの子らはエル、オナン、シラ、ペレヅ、ゼラ。エルとオナンはカナンの地で死んだ。ペレヅの子らはヘヅロンとハムル。</span>
<span className="v" id="v13" data-v="13" data-xref="歴代志上 12:32; 創世記 35:23; 創世記 30:14–18"> イッサカルの子らはトラ、プワ、ヨブ、シムロン。</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 33:18–19; 民数記 26:26–27; 民数記 1:30–31"> ゼブルンの子らはセレデ、エロン、ヤリエル。</span>
<span className="v" id="v15" data-v="15" data-xref="創世記 29:32–35; 創世記 30:17–21; 創世記 34:1–31"> これらと娘デナとはレアがパダンアラムでヤコブに産んだ子らである。その子らと娘らは合わせて三十三人。</span>
<span className="v" id="v16" data-v="16" data-xref="民数記 26:15–17; 創世記 30:11; 民数記 1:24–25"> ガドの子らはゼポン、ハギ、シュニ、エヅボン、エリ、アロデ、アレリ。</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 49:20; 創世記 30:13; 民数記 1:13"> アセルの子らはエムナ、イシワ、イスイ、ベリアおよび妹サラ。ベリアの子らはヘベルとマルキエル。</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 29:24; 創世記 35:26; 創世記 30:9–13"> これらはラバンが娘レアに与えたジルパの子らである。彼女はこれらをヤコブに産んだ。合わせて十六人。</span>
<span className="v" id="v19" data-v="19" data-xref="創世記 44:27; 創世記 29:18; 創世記 35:24"> ヤコブの妻ラケルの子らはヨセフとベニヤミンとである。</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 41:50–52; 創世記 41:45; 申命記 33:13–17"> エジプトの国でヨセフにマナセとエフライムとが生れた。これはオンの祭司ポテペラの娘アセナテが彼に産んだ者である。</span>
<span className="v" id="v21" data-v="21" data-xref="歴代志上 7:6–12; 歴代志上 8:1–7; 民数記 26:38–40"> ベニヤミンの子らはベラ、ベケル、アシベル、ゲラ、ナアマン、エヒ、ロシ、ムッピム、ホパム、アルデ。</span>
<span className="v" id="v22" data-v="22"> これらはラケルがヤコブに産んだ子らである。合わせて十四人。</span>
<span className="v" id="v23" data-v="23" data-xref="民数記 1:38–39; 創世記 49:16–17; 民数記 1:12"> ダンの子はホシム。</span>
<span className="v" id="v24" data-v="24" data-xref="歴代志上 7:13; 民数記 1:42–43; 創世記 35:25"> ナフタリの子らはヤジエル、グニ、エゼル、シレム。</span>
<span className="v" id="v25" data-v="25" data-xref="創世記 29:29; 創世記 35:25; 創世記 30:3–8"> これらはラバンが娘ラケルに与えたビルハの子らである。彼女はこれらをヤコブに産んだ。合わせて七人。</span>
<span className="v" id="v26" data-v="26" data-xref="出エジプト記 1:5; 創世記 35:11; 士師記 8:30"> ヤコブと共にエジプトへ行ったすべての者、すなわち彼の身から出た者はヤコブの子らの妻をのぞいて、合わせて六十六人であった。</span>
<span className="v" id="v27" data-v="27" data-xref="申命記 10:22; 使徒行伝 7:14; 出エジプト記 1:5"> エジプトでヨセフに生れた子がふたりあった。エジプトへ行ったヤコブの家の者は合わせて七十人であった。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="創世記 45:10; 創世記 44:16–34; 創世記 49:8"> さてヤコブはユダをさきにヨセフにつかわして、ゴセンで会おうと言わせた。そして彼らはゴセンの地へ行った。</span>
<span className="v" id="v29" data-v="29" data-xref="ルカによる福音書 15:20; 創世記 45:14–15; 創世記 33:4"> ヨセフは車を整えて、父イスラエルを迎えるためにゴセンに上り、父に会い、そのくびを抱き、くびをかかえて久しく泣いた。</span>
<span className="v" id="v30" data-v="30" data-xref="ルカによる福音書 2:29–30; 創世記 45:28"> 時に、イスラエルはヨセフに言った、「あなたがなお生きていて、わたしはあなたの顔を見たので今は死んでもよい」。</span>
<span className="v" id="v31" data-v="31" data-xref="創世記 47:1–3; ヘブル人への手紙 2:11; 使徒行伝 18:3"> ヨセフは兄弟たちと父の家族とに言った、「わたしは上ってパロに言おう、『カナンの地にいたわたしの兄弟たちと父の家族とがわたしの所へきました。</span>
<span className="v" id="v32" data-v="32" data-xref="創世記 47:3; 列王紀上 9:27; 列王紀上 18:5–6"> この者らは羊を飼う者、家畜の牧者で、その羊、牛および持ち物をみな携えてきました』。</span>
<span className="v" id="v33" data-v="33" data-xref="創世記 46:32; 創世記 47:2–4; ヨナ書 1:8"> もしパロがあなたがたを召して、『あなたがたの職業は何か』と言われたら、</span>
<span className="v" id="v34" data-v="34" data-xref="出エジプト記 8:26; 創世記 43:32; 創世記 46:32"> 『しもべらは幼い時から、ずっと家畜の牧者です。われわれも、われわれの先祖もそうです』と言いなさい。そうすればあなたがたはゴセンの地に住むことができましょう。羊飼はすべて、エジプトびとの忌む者だからです」。</span>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨハネの第一の手紙 3:12; 創世記 3:15; 創世記 4:25"> 人はその妻エバを知った。彼女はみごもり、カインを産んで言った、「わたしは主によって、ひとりの人を得た」。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネの第一の手紙 3:15; ヨハネの第一の手紙 3:12; ルカによる福音書 11:51"> 彼女はまた、その弟アベルを産んだ。アベルは羊を飼う者となり、カインは土を耕す者となった。</span>
<span className="v" id="v3" data-v="3" data-xref="民数記 18:12; レビ記 2:1–11; 列王紀上 17:7"> 日がたって、カインは地の産物を持ってきて、主に供え物とした。</span>
<span className="v" id="v4" data-v="4" data-xref="ヘブル人への手紙 11:4; 箴言 3:9; 出エジプト記 13:12"> アベルもまた、その群れのういごと肥えたものとを持ってきた。主はアベルとその供え物とを顧みられた。</span>
<span className="v" id="v5" data-v="5" data-xref="ヘブル人への手紙 11:4; ヨブ記 5:2; ルカによる福音書 15:28–30"> しかしカインとその供え物とは顧みられなかったので、カインは大いに憤って、顔を伏せた。</span>
<span className="v" id="v6" data-v="6" data-xref="イザヤ書 1:18; ヨブ記 5:2; ルカによる福音書 15:31–32"> そこで主はカインに言われた、「なぜあなたは憤るのですか、なぜ顔を伏せるのですか。</span>
<span className="v" id="v7" data-v="7" data-xref="ヤコブの手紙 1:15; ローマ人への手紙 2:6–10; イザヤ書 3:10–11"> 正しい事をしているのでしたら、顔をあげたらよいでしょう。もし正しい事をしていないのでしたら、罪が門口に待ち伏せています。それはあなたを慕い求めますが、あなたはそれを治めなければなりません」。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="マタイによる福音書 23:35; ヨハネの第一の手紙 3:12–15; ユダの手紙 1:11"> カインは弟アベルに言った、「さあ、野原へ行こう」。彼らが野にいたとき、カインは弟アベルに立ちかかって、これを殺した。</span>
<span className="v" id="v9" data-v="9" data-xref="箴言 28:13; ヨハネによる福音書 8:44; 詩篇 9:12"> 主はカインに言われた、「弟アベルは、どこにいますか」。カインは答えた、「知りません。わたしが弟の番人でしょうか」。</span>
<span className="v" id="v10" data-v="10" data-xref="ヘブル人への手紙 12:24; 詩篇 72:14; ヘブル人への手紙 11:4"> 主は言われた、「あなたは何をしたのです。あなたの弟の血の声が土の中からわたしに叫んでいます。</span>
<span className="v" id="v11" data-v="11" data-xref="ガラテヤ人への手紙 3:10; ヨブ記 16:18; 創世記 3:14"> 今あなたはのろわれてこの土地を離れなければなりません。この土地が口をあけて、あなたの手から弟の血を受けたからです。</span>
<span className="v" id="v12" data-v="12" data-xref="ホセア書 9:17; レビ記 26:36; レビ記 26:20"> あなたが土地を耕しても、土地は、もはやあなたのために実を結びません。あなたは地上の放浪者となるでしょう」。</span>
<span className="v" id="v13" data-v="13" data-xref="ヨブ記 15:22; ヨハネの黙示録 16:9; ヨハネの黙示録 16:11"> カインは主に言った、「わたしの罰は重くて負いきれません。</span>
<span className="v" id="v14" data-v="14" data-xref="民数記 35:19; 詩篇 143:7; ヨブ記 15:20–24"> あなたは、きょう、わたしを地のおもてから追放されました。わたしはあなたを離れて、地上の放浪者とならねばなりません。わたしを見付ける人はだれでもわたしを殺すでしょう」。</span>
<span className="v" id="v15" data-v="15" data-xref="エゼキエル書 9:4; 詩篇 79:12; 創世記 4:24"> 主はカインに言われた、「いや、そうではない。だれでもカインを殺す者は七倍の復讐を受けるでしょう」。そして主はカインを見付ける者が、だれも彼を打ち殺すことのないように、彼に一つのしるしをつけられた。</span>
<span className="v" id="v16" data-v="16" data-xref="エレミヤ書 23:39; ヨブ記 2:7; 創世記 4:14"> カインは主の前を去って、エデンの東、ノドの地に住んだ。</span>
</div>
<div className="bp poetry">
<span className="v" id="v17" data-v="17" data-xref="詩篇 49:11; 伝道の書 2:4–11; ダニエル書 4:30"> カインはその妻を知った。彼女はみごもってエノクを産んだ。カインは町を建て、その町の名をその子の名にしたがって、エノクと名づけた。</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 36:2; 創世記 5:21"> エノクにはイラデが生れた。イラデの子はメホヤエル、メホヤエルの子はメトサエル、メトサエルの子はレメクである。</span>
<span className="v" id="v19" data-v="19" data-xref="創世記 2:24; マタイによる福音書 19:8; 創世記 2:18"> レメクはふたりの妻をめとった。ひとりの名はアダといい、ひとりの名はチラといった。</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 4:2; エレミヤ書 35:9–10; ヨハネによる福音書 8:44"> アダはヤバルを産んだ。彼は天幕に住んで、家畜を飼う者の先祖となった。</span>
<span className="v" id="v21" data-v="21" data-xref="ヨブ記 21:12; イザヤ書 5:12; 創世記 31:27"> その弟の名はユバルといった。彼は琴や笛を執るすべての者の先祖となった。</span>
<span className="v" id="v22" data-v="22" data-xref="申命記 33:25; 申命記 8:9; 歴代志下 2:7"> チラもまたトバルカインを産んだ。彼は青銅や鉄のすべての刃物を鍛える者となった。トバルカインの妹をナアマといった。</span>
<span className="v" id="v23" data-v="23" data-xref="民数記 23:18; 出エジプト記 20:13; レビ記 19:18"> <span className="pl pl-1">レメクはその妻たちに言った、</span><br /><span className="pl pl-1">「アダとチラよ、わたしの声を聞け、</span><br /><span className="pl pl-1">レメクの妻たちよ、わたしの言葉に耳を傾けよ。</span><br /><span className="pl pl-1">わたしは受ける傷のために、人を殺し、</span><br /><span className="pl pl-1">受ける打ち傷のために、わたしは若者を殺す。</span></span>
<span className="v" id="v24" data-v="24" data-xref="マタイによる福音書 18:22; 創世記 4:15"> <span className="pl pl-1">カインのための復讐が七倍ならば、</span><br /><span className="pl pl-1">レメクのための復讐は七十七倍」。</span></span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="創世記 4:8; 創世記 4:10–11; 歴代志上 1:1"> アダムはまたその妻を知った。彼女は男の子を産み、その名をセツと名づけて言った、「カインがアベルを殺したので、神はアベルの代りに、ひとりの子をわたしに授けられました」。</span>
<span className="v" id="v26" data-v="26" data-xref="詩篇 116:17; 列王紀上 18:24; ヨエル書 2:32"> セツにもまた男の子が生れた。彼はその名をエノスと名づけた。この時、人々は主の名を呼び始めた。</span>
</div>

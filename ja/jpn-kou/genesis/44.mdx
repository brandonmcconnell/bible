<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 42:25; 創世記 43:16; 創世記 24:2"> さてヨセフは家づかさに命じて言った、「この人々の袋に、運べるだけ多くの食糧を満たし、めいめいの銀を袋の口に入れておきなさい。</span>
<span className="v" id="v2" data-v="2" data-xref="コリント人への第二の手紙 8:8; 創世記 42:20; 申命記 8:16"> またわたしの杯、銀の杯をあの年下の者の袋の口に、穀物の代金と共に入れておきなさい」。家づかさはヨセフの言葉のとおりにした。</span>
<span className="v" id="v3" data-v="3"> 夜が明けると、その人々と、ろばとは送り出されたが、</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネによる福音書 10:32; 詩篇 35:12; 箴言 17:13"> 町を出て、まだ遠くへ行かないうちに、ヨセフは家づかさに言った、「立って、あの人々のあとを追いなさい。追いついて、彼らに言いなさい、『あなたがたはなぜ悪をもって善に報いるのですか。なぜわたしの銀の杯を盗んだのですか。</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 30:27; レビ記 19:26; 列王紀下 21:6"> これはわたしの主人が飲む時に使い、またいつも占いに用いるものではありませんか。あなたがたのした事は悪いことです』」。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6"> 家づかさが彼らに追いついて、これらの言葉を彼らに告げたとき、</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 38:16–18; 創世記 37:18–32; 列王紀下 8:13"> 彼らは言った、「わが主は、どうしてそのようなことを言われるのですか。しもべらは決してそのようなことはいたしません。</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 43:12; 創世記 42:35; ローマ人への手紙 13:9"> 袋の口で見つけた銀でさえ、カナンの地からあなたの所に持ち帰ったほどです。どうして、われわれは御主人の家から銀や金を盗みましょう。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 31:32; 詩篇 7:3–5; ヨブ記 31:38–40"> しもべらのうちのだれの所でそれが見つかっても、その者は死に、またわれわれはわが主の奴隷となりましょう」。</span>
<span className="v" id="v10" data-v="10" data-xref="出エジプト記 22:3; 創世記 44:17; 創世記 44:33"> 家づかさは言った、「それではあなたがたの言葉のようにしよう。杯の見つかった者はわたしの奴隷とならなければならない。ほかの者は無罪です」。</span>
<span className="v" id="v11" data-v="11"> そこで彼らは、めいめい急いで袋を地におろし、ひとりひとりその袋を開いた。</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 44:26–32; 創世記 42:36–38; 創世記 43:14"> 家づかさは年上から捜し始めて年下に終ったが、杯はベニヤミンの袋の中にあった。</span>
<span className="v" id="v13" data-v="13" data-xref="サムエル記下 1:11; 創世記 37:29–34; サムエル記下 1:2"> そこで彼らは衣服を裂き、おのおの、ろばに荷を負わせて町に引き返した。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="創世記 50:18; 創世記 43:25; 創世記 43:16"> ユダと兄弟たちとは、ヨセフの家にはいったが、ヨセフがなおそこにいたので、彼らはその前で地にひれ伏した。</span>
<span className="v" id="v15" data-v="15" data-xref="創世記 4:10; 創世記 21:26; 創世記 3:13"> ヨセフは彼らに言った、「あなたがたのこのしわざは何事ですか。わたしのような人は、必ず占い当てることを知らないのですか」。</span>
<span className="v" id="v16" data-v="16" data-xref="創世記 44:9; ダニエル書 9:7; 民数記 32:23"> ユダは言った、「われわれはわが主に何を言い、何を述べ得ましょう。どうしてわれわれは身の潔白をあらわし得ましょう。神がしもべらの罪をあばかれました。われわれと、杯を持っていた者とは共にわが主の奴隷となりましょう」。</span>
<span className="v" id="v17" data-v="17" data-xref="箴言 17:15; サムエル記下 23:3; 創世記 18:25"> ヨセフは言った、「わたしは決してそのようなことはしない。杯を持っている者だけがわたしの奴隷とならなければならない。ほかの者は安全に父のもとへ上って行きなさい」。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="出エジプト記 32:22; 創世記 41:40; 創世記 18:30"> この時ユダは彼に近づいて言った、「ああ、わが主よ、どうぞわが主の耳にひとこと言わせてください。しもべをおこらないでください。あなたはパロのようなかたです。</span>
<span className="v" id="v19" data-v="19" data-xref="創世記 43:7; 創世記 43:29; 創世記 42:7–10"> わが主はしもべらに尋ねて、『父があるか、また弟があるか』と言われたので、</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 37:3; 創世記 42:38; ルカによる福音書 7:12"> われわれはわが主に言いました、『われわれには老齢の父があり、また年寄り子の弟があります。その兄は死んで、同じ母の子で残っているのは、ただこれだけですから父はこれを愛しています』。</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 42:15; 創世記 42:20; アモス書 9:4"> その時あなたはしもべらに言われました、『その者をわたしの所へ連れてきなさい。わたしはこの目で彼を見よう』。</span>
<span className="v" id="v22" data-v="22" data-xref="創世記 44:30; 創世記 42:38"> われわれはわが主に言いました。『その子供は父を離れることができません。もし父を離れたら父は死ぬでしょう』。</span>
<span className="v" id="v23" data-v="23" data-xref="創世記 43:5; 創世記 43:3; 創世記 42:15–20"> しかし、あなたはしもべらに言われました、『末の弟が一緒に下ってこなければ、おまえたちは再びわたしの顔を見ることはできない』。</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 42:29–34"> それであなたのしもべである父のもとに上って、わが主の言葉を彼に告げました。</span>
<span className="v" id="v25" data-v="25" data-xref="創世記 43:2; 創世記 43:5"> ところで、父が『おまえたちは再び行って、われわれのために少しの食糧を買ってくるように』と言ったので、</span>
<span className="v" id="v26" data-v="26" data-xref="ルカによる福音書 11:7; 創世記 43:4–5"> われわれは言いました、『われわれは下って行けません。もし末の弟が一緒であれば行きましょう。末の弟が一緒でなければ、あの人の顔を見ることができません』。</span>
<span className="v" id="v27" data-v="27" data-xref="創世記 46:19; 創世記 35:16–18; 創世記 30:22–25"> あなたのしもべである父は言いました、『おまえたちの知っているとおり、妻はわたしにふたりの子を産んだ。</span>
<span className="v" id="v28" data-v="28" data-xref="創世記 37:33; 創世記 37:13–14; 創世記 42:36"> ひとりは外へ出たが、きっと裂き殺されたのだと思う。わたしは今になっても彼を見ない。</span>
<span className="v" id="v29" data-v="29" data-xref="創世記 42:38; 創世記 43:14; 申命記 31:17"> もしおまえたちがこの子をもわたしから取って行って、彼が災に会えば、おまえたちは、しらがのわたしを悲しんで陰府に下らせるであろう』。</span>
<span className="v" id="v30" data-v="30" data-xref="サムエル記上 18:1; サムエル記下 18:33; 創世記 44:31"> わたしがあなたのしもべである父のもとに帰って行くとき、もしこの子供が一緒にいなかったら、どうなるでしょう。父の魂は子供の魂に結ばれているのです。</span>
<span className="v" id="v31" data-v="31" data-xref="創世記 44:29; 創世記 37:35; コリント人への第二の手紙 7:10"> この子供がわれわれと一緒にいないのを見たら、父は死ぬでしょう。そうすればしもべらは、あなたのしもべであるしらがの父を悲しんで陰府に下らせることになるでしょう。</span>
<span className="v" id="v32" data-v="32" data-xref="創世記 43:8–9; 創世記 43:16"> しもべは父にこの子供の身を請け合って『もしわたしがこの子をあなたのもとに連れ帰らなかったら、わたしは父に対して永久に罪を負いましょう』と言ったのです。</span>
<span className="v" id="v33" data-v="33" data-xref="ヨハネの第一の手紙 3:16; 出エジプト記 32:32; ヘブル人への手紙 7:22"> どうか、しもべをこの子供の代りに、わが主の奴隷としてとどまらせ、この子供を兄弟たちと一緒に上り行かせてください、</span>
<span className="v" id="v34" data-v="34" data-xref="エステル記 8:6; 詩篇 116:3; 詩篇 119:143"> この子供を連れずに、どうしてわたしは父のもとに上り行くことができましょう。父が災に会うのを見るに忍びません」。</span>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 30:22; 創世記 19:29; 詩篇 136:23"> 神はノアと、箱舟の中にいたすべての生き物と、すべての家畜とを心にとめられた。神が風を地の上に吹かせられたので、水は退いた。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 7:11; マタイによる福音書 8:26–27; 箴言 8:28"> また淵の源と、天の窓とは閉ざされて、天から雨が降らなくなった。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 7:24; 創世記 7:11"> それで水はしだいに地の上から引いて、百五十日の後には水が減り、</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀下 19:37; エレミヤ書 51:27; イザヤ書 37:38"> 箱舟は七月十七日にアララテの山にとどまった。</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 7:11"> 水はしだいに減って、十月になり、十月一日に山々の頂が現れた。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="創世記 6:16; ダニエル書 6:10"> 四十日たって、ノアはその造った箱舟の窓を開いて、</span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 147:9; 列王紀上 17:6; 列王紀上 17:4"> からすを放ったところ、からすは地の上から水がかわききるまで、あちらこちらへ飛びまわった。</span>
<span className="v" id="v8" data-v="8" data-xref="雅歌 2:14; 雅歌 1:15; マタイによる福音書 10:16"> ノアはまた地のおもてから、水がひいたかどうかを見ようと、彼の所から、はとを放ったが、</span>
<span className="v" id="v9" data-v="9" data-xref="マタイによる福音書 11:28; 詩篇 116:7; 申命記 28:65"> はとは足の裏をとどめる所が見つからなかったので、箱舟のノアのもとに帰ってきた。水がまだ全地のおもてにあったからである。彼は手を伸べて、これを捕え、箱舟の中の彼のもとに引き入れた。</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 7:4; 創世記 7:10; 創世記 8:12"> それから七日待って再びはとを箱舟から放った。</span>
<span className="v" id="v11" data-v="11" data-xref="ネヘミヤ書 8:15; ゼカリヤ書 4:12–14; ローマ人への手紙 10:15"> はとは夕方になって彼のもとに帰ってきた。見ると、そのくちばしには、オリブの若葉があった。ノアは地から水がひいたのを知った。</span>
<span className="v" id="v12" data-v="12" data-xref="イザヤ書 25:9; イザヤ書 30:18; 創世記 8:10"> さらに七日待ってまた、はとを放ったところ、もはや彼のもとには帰ってこなかった。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="創世記 7:11"> 六百一歳の一月一日になって、地の上の水はかれた。ノアが箱舟のおおいを取り除いて見ると、土のおもては、かわいていた。</span>
<span className="v" id="v14" data-v="14" data-xref="創世記 7:13–14; 創世記 7:11"> 二月二十七日になって、地は全くかわいた。</span>
<span className="v" id="v15" data-v="15"> この時、神はノアに言われた、</span>
<span className="v" id="v16" data-v="16" data-xref="創世記 7:13; 詩篇 121:8; 詩篇 91:11"> 「あなたは妻と、子らと、子らの妻たちと共に箱舟を出なさい。</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 1:22; 創世記 9:1; エレミヤ書 31:27–28"> あなたは、共にいる肉なるすべての生き物、すなわち鳥と家畜と、地のすべての這うものとを連れて出て、これらのものが地に群がり、地の上にふえ広がるようにしなさい」。</span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 121:8"> ノアは共にいた子らと、妻と、子らの妻たちとを連れて出た。</span>
<span className="v" id="v19" data-v="19"> またすべての獣、すべての這うもの、すべての鳥、すべて地の上に動くものは皆、種類にしたがって箱舟を出た。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="ヘブル人への手紙 13:15–16; ローマ人への手紙 12:1; 創世記 22:9"> ノアは主に祭壇を築いて、すべての清い獣と、すべての清い鳥とのうちから取って、燔祭を祭壇の上にささげた。</span>
<span className="v" id="v21" data-v="21" data-xref="コリント人への第二の手紙 2:15; エペソ人への手紙 5:2; イザヤ書 54:9–10"> 主はその香ばしいかおりをかいで、心に言われた、「わたしはもはや二度と人のゆえに地をのろわない。人が心に思い図ることは、幼い時から悪いからである。わたしは、このたびしたように、もう二度と、すべての生きたものを滅ぼさない。</span>
<span className="v" id="v22" data-v="22" data-xref="ヤコブの手紙 5:7; 詩篇 74:16–17; エレミヤ書 5:24"> 地のある限り、種まきの時も、刈入れの時も、暑さ寒さも、夏冬も、昼も夜もやむことはないであろう」。</span>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="エズラ記 7:7; エズラ記 2:62; 歴代志上 9:1"> アルタシャスタ王の治世に、バビロンからわたしと一緒に上って来た者の氏族の長、およびその系譜は次のとおりである。</span>
<span className="v" id="v2" data-v="2" data-xref="歴代志上 3:22; 歴代志上 3:1; 歴代志上 6:3–15"> ピネハスの子孫のうちではゲルショム。イタマルの子孫のうちではダニエル。ダビデの子孫のうちではシカニヤの子ハットシ。</span>
<span className="v" id="v3" data-v="3" data-xref="エズラ記 2:3; ネヘミヤ書 10:14; ネヘミヤ書 7:8"> パロシの子孫のうちではゼカリヤおよび彼と共に系譜に載せられた男百五十人。</span>
<span className="v" id="v4" data-v="4" data-xref="エズラ記 2:6; ネヘミヤ書 10:14; ネヘミヤ書 7:11"> パハテ・モアブの子孫のうちではゼラヒヤの子エリヨエナイおよび彼と共にある男二百人。</span>
<span className="v" id="v5" data-v="5"> ザッツの子孫のうちではヤハジエルの子シカニヤおよび彼と共にある男三百人。</span>
<span className="v" id="v6" data-v="6" data-xref="エズラ記 2:15; ネヘミヤ書 10:16; ネヘミヤ書 7:20"> アデンの子孫のうちではヨナタンの子エベデおよび彼と共にある男五十人。</span>
<span className="v" id="v7" data-v="7" data-xref="エズラ記 2:31; ネヘミヤ書 7:34; エズラ記 2:7"> エラムの子孫のうちではアタリヤの子エサヤおよび彼と共にある男七十人。</span>
<span className="v" id="v8" data-v="8" data-xref="ネヘミヤ書 11:4; エズラ記 2:4; ネヘミヤ書 7:9"> シパテヤの子孫のうちではミカエルの子ゼバデヤおよび彼と共にある男八十人。</span>
<span className="v" id="v9" data-v="9" data-xref="ネヘミヤ書 7:11; エズラ記 2:6"> ヨアブの子孫のうちではエヒエルの子オバデヤおよび彼と共にある男二百十八人。</span>
<span className="v" id="v10" data-v="10"> バニの子孫のうちではヨシピアの子シロミテおよび彼と共にある男百六十人。</span>
<span className="v" id="v11" data-v="11" data-xref="エズラ記 10:28; ネヘミヤ書 7:16; エズラ記 2:11"> ベバイの子孫のうちではベバイの子ゼカリヤおよび彼と共にある男二十八人。</span>
<span className="v" id="v12" data-v="12" data-xref="エズラ記 2:12; ネヘミヤ書 7:17"> アズガデの子孫のうちではハッカタンの子ヨハナンおよび彼と共にある男百十人。</span>
<span className="v" id="v13" data-v="13" data-xref="エズラ記 2:13; ネヘミヤ書 7:18"> アドニカムの子孫のうちでは後に来た者どもで、その名はエリペレテ、ユエル、シマヤおよび彼らと共にある男六十人。</span>
<span className="v" id="v14" data-v="14" data-xref="ネヘミヤ書 10:12; エズラ記 2:14; ネヘミヤ書 7:19"> ビグワイの子孫のうちではウタイとザックルおよび彼らと共にある男七十人である。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="エズラ記 8:21; エズラ記 8:31; エズラ記 7:7"> わたしは彼らをアハワに流れる川のほとりに集めて、そこに三日のあいだ露営した。わたしは民と祭司とを調べたが、そこにはレビの子孫はひとりもいなかったので、</span>
<span className="v" id="v16" data-v="16" data-xref="箴言 2:6; エズラ記 8:18; エズラ記 10:39"> 人をつかわしてエリエゼル、アリエル、シマヤ、エルナタン、ヤリブ、エルナタン、ナタン、ゼカリヤ、メシュラムという首長たる人々を招き、またヨヤリブ、およびエルナタンのような見識のある人々を招いた。</span>
<span className="v" id="v17" data-v="17" data-xref="エズラ記 2:43; 出エジプト記 4:15; 民数記 8:22–26"> そしてわたしはカシピアという所の首長イドのもとに彼らをつかわし、カシピアという所にいるイドと、その兄弟である宮に仕えるしもべたちに告ぐべき言葉を、彼らに授け、われわれの神の宮のために、仕え人をわれわれに連れて来いと言った。</span>
<span className="v" id="v18" data-v="18" data-xref="エレミヤ書 3:15; エズラ記 7:28; ネヘミヤ書 2:8"> われわれの神がよくわれわれを助けられたので、彼らはイスラエルの子、レビの子、マヘリの子孫のうちの思慮深い人、すなわちセレビヤおよびその子らとその兄弟たち十八人を、われわれに連れて来、</span>
<span className="v" id="v19" data-v="19" data-xref="歴代志上 6:1; 歴代志上 6:16; ネヘミヤ書 10:11"> またハシャビヤおよび彼と共に、メラリの子孫のエサヤとその兄弟およびその子ら二十人、</span>
<span className="v" id="v20" data-v="20" data-xref="エズラ記 2:43; エズラ記 7:7; 歴代志上 9:2"> および宮に仕えるしもべ、すなわちダビデとそのつかさたちが、レビびとに仕えさせるために選んだ宮に仕えるしもべ二百二十人を連れてきた。これらの者は皆その名を言って記録された。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="歴代志下 20:3; ヨエル書 1:14; サムエル記上 7:6"> そこでわたしは、かしこのアハワ川のほとりで断食を布告し、われわれの神の前で身をひくくし、われわれと、われわれの幼き者と、われわれのすべての貨財のために、正しい道を示されるように神に求めた。</span>
<span className="v" id="v22" data-v="22" data-xref="ペテロの第一の手紙 3:12; 詩篇 33:18–19; 歴代志下 16:9"> これは、われわれがさきに王に告げて、「われわれの神の手は、神を求めるすべての者の上にやさしく下り、その威力と怒りとはすべて神を捨てる者の上に下る」と言ったので、わたしは道中の敵に対して、われわれを守るべき歩兵と騎兵とを、王に頼むことを恥じたからである。</span>
<span className="v" id="v23" data-v="23" data-xref="エレミヤ書 29:12–13; マタイによる福音書 7:7–8; エズラ記 8:31"> そこでわれわれは断食して、このことをわれわれの神に求めたところ、神はその願いを聞きいれられた。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="エズラ記 8:18–19"> わたしはおもだった祭司十二人すなわちセレビヤ、ハシャビヤおよびその兄弟十人を選び、</span>
<span className="v" id="v25" data-v="25" data-xref="エズラ記 8:33; エズラ記 7:14–16; エズラ記 1:8"> 金銀および器物、すなわち王と、その議官と、その諸侯およびすべて在留のイスラエルびとが、われわれの神の宮のためにささげた奉納物を量って彼らに渡した。</span>
<span className="v" id="v26" data-v="26" data-xref="エズラ記 1:9–11"> わたしが量って彼らの手に渡したものは、銀六百五十タラント、銀の器百タラント、金百タラントであった。</span>
<span className="v" id="v27" data-v="27" data-xref="哀歌 4:2"> また金の大杯が二十あって、一千ダリクに当る。また光り輝く青銅の器二個あって、その尊いこと金のようである。</span>
<span className="v" id="v28" data-v="28" data-xref="レビ記 22:2–3; レビ記 21:6–8; 歴代志上 23:28"> そしてわたしは彼らに言った、「あなたがたは主に聖別された者である。この器物も聖である。またこの金銀は、あなたがたの先祖の神、主にささげた真心よりの供え物である。</span>
<span className="v" id="v29" data-v="29" data-xref="エズラ記 8:33–34; マルコによる福音書 13:34–35; 歴代志上 26:20–26"> あなたがたはエルサレムで、主の宮のへやの中で、祭司長、レビびとおよびイスラエルの氏族のかしらたちの前で、これを量るまで、見張り、かつ守りなさい」。</span>
<span className="v" id="v30" data-v="30" data-xref="エズラ記 8:22; 歴代志上 29:2–3; イザヤ書 60:13"> そこで祭司およびレビびとたちは、その金銀および器物を、エルサレムにあるわれわれの神の宮に携えて行くため、その重さのものを受け取った。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="エズラ記 8:21–22; エズラ記 7:9; エズラ記 8:15"> われわれは正月の十二日に、アハワ川を出立してエルサレムに向かったが、われわれの神の手は、われわれの上にあって、敵の手および道に待ち伏せする者の手から、われわれを救われた。</span>
<span className="v" id="v32" data-v="32" data-xref="ネヘミヤ書 2:11; エズラ記 7:8–9"> われわれはエルサレムに着いて、三日そこにいたが、</span>
<span className="v" id="v33" data-v="33" data-xref="ネヘミヤ書 3:4; ネヘミヤ書 3:21; エズラ記 8:30"> 四日目にわれわれの神の宮の内で、その金銀および器物を、ウリヤの子祭司メレモテの手に量って渡した。ピネハスの子エレアザルが彼と共にいた。またエシュアの子ヨザバデ、およびビンヌイの子ノアデヤのふたりのレビびとも、彼らと共にいた。</span>
<span className="v" id="v34" data-v="34"> すなわちそのすべての数と重さとを調べ、その重さは皆書きとめられた。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="エズラ記 6:17; 歴代志下 29:31–32; 詩篇 66:10–15"> そのとき捕囚の人々で捕囚から帰って来た者は、イスラエルの神に燔祭をささげた。すなわちイスラエル全体のために雄牛十二頭、雄羊九十六頭、小羊七十七頭をささげ、また罪祭として雄やぎ十二頭をささげた。これらはみな、主にささげた燔祭である。</span>
<span className="v" id="v36" data-v="36" data-xref="エズラ記 7:21–24; エズラ記 4:7–23; エズラ記 6:13"> 彼らはまた王の命令書を、王の総督たち、および川向こうの州の知事たちに渡したので、彼らは民と神の宮とを援助した。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ネヘミヤ書 2:1; 歴代志上 6:4–14; エズラ記 7:21"> これらの事の後ペルシャ王アルタシャスタの治世にエズラという者があった。エズラはセラヤの子、セラヤはアザリヤの子、アザリヤはヒルキヤの子、</span>
<span className="v" id="v2" data-v="2" data-xref="列王紀上 2:35; サムエル記下 8:17"> ヒルキヤはシャルムの子、シャルムはザドクの子、ザドクはアヒトブの子、</span>
<span className="v" id="v3" data-v="3"> アヒトブはアマリヤの子、アマリヤはアザリヤの子、アザリヤはメラヨテの子、</span>
<span className="v" id="v4" data-v="4"> メラヨテはゼラヒヤの子、ゼラヒヤはウジの子、ウジはブッキの子、</span>
<span className="v" id="v5" data-v="5" data-xref="出エジプト記 6:25; 歴代志下 26:20; 歴代志上 6:4"> ブッキはアビシュアの子、アビシュアはピネハスの子、ピネハスはエレアザルの子、エレアザルは祭司長アロンの子である。</span>
<span className="v" id="v6" data-v="6" data-xref="エズラ記 8:22; エズラ記 7:28; エズラ記 8:31"> このエズラはバビロンから上って来た。彼はイスラエルの神、主がお授けになったモーセの律法に精通した学者であった。その神、主の手が彼の上にあったので、その求めることを王はことごとく許した。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="エズラ記 8:1–20; 歴代志上 6:31–48; 歴代志上 9:17–27"> アルタシャスタ王の七年にまたイスラエルの人々および祭司、レビびと、歌うたう者、門衛、宮に仕えるしもべなどエルサレムに上った。</span>
<span className="v" id="v8" data-v="8"> そして王の七年の五月にエズラはエルサレムに来た。</span>
<span className="v" id="v9" data-v="9" data-xref="エズラ記 7:6; ネヘミヤ書 2:8; ネヘミヤ書 2:18"> すなわち正月の一日にバビロンを出立して、五月一日にエルサレムに着いた。その神の恵みの手が彼の上にあったからである。</span>
<span className="v" id="v10" data-v="10" data-xref="マラキ書 2:7; テモテヘの第二の手紙 4:2; マタイによる福音書 7:24"> エズラは心をこめて主の律法を調べ、これを行い、かつイスラエルのうちに定めとおきてとを教えた。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="エズラ記 5:6; エズラ記 7:6; マタイによる福音書 23:2"> 主の戒めの言葉、およびイスラエルに賜わった定めに通じた学者で、祭司であるエズラにアルタシャスタ王の与えた手紙の写しは、次のとおりである。</span>
<span className="v" id="v12" data-v="12" data-xref="ダニエル書 2:37; エゼキエル書 26:7; エズラ記 4:17"> 「諸王の王アルタシャスタ、天の神の律法の学者である祭司エズラに送る。今、</span>
<span className="v" id="v13" data-v="13" data-xref="エズラ記 6:1; 詩篇 148:6; 歴代志下 30:5"> わたしは命を下す。わが国のうちにいるイスラエルの民およびその祭司、レビびとのうち、すべてエルサレムへ行こうと望む者は皆、あなたと共に行くことができる。</span>
<span className="v" id="v14" data-v="14" data-xref="エステル記 1:14; エズラ記 7:25–26; エズラ記 7:28"> あなたは、自分の手にあるあなたの神の律法に照して、ユダとエルサレムの事情を調べるために、王および七人の議官によってつかわされるのである。</span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 135:21; 歴代志下 6:2; エズラ記 6:12"> かつあなたは王およびその議官らが、エルサレムにいますイスラエルの神に真心からささげる銀と金を携え、</span>
<span className="v" id="v16" data-v="16" data-xref="歴代志上 29:6; エズラ記 1:4; 歴代志上 29:9"> またバビロン全州であなたが獲るすべての金銀、および民と祭司とが、エルサレムにあるその神の宮のために、真心からささげた供え物を携えて行く。</span>
<span className="v" id="v17" data-v="17" data-xref="申命記 12:5–11; 民数記 15:4–13; エズラ記 6:9–10"> それであなたはその金をもって雄牛、雄羊、小羊およびその素祭と灌祭の品々を気をつけて買い、エルサレムにあるあなたがたの神の宮の祭壇の上に、これをささげなければならない。</span>
<span className="v" id="v18" data-v="18" data-xref="列王紀下 22:7; エペソ人への手紙 5:17; 列王紀下 12:15"> また、あなたとあなたの兄弟たちが、その余った金銀でしようと思うよい事があるならば、あなたがたの神のみ旨に従ってそれを行え。</span>
<span className="v" id="v19" data-v="19" data-xref="エレミヤ書 3:17; エズラ記 8:33–34; 歴代志下 32:19"> またあなたの神の宮の勤め事のためにあなたが与えられた器は、エルサレムの神の前に納めよ。</span>
<span className="v" id="v20" data-v="20" data-xref="エズラ記 6:4; エズラ記 6:8–18"> そのほかあなたの神の宮のために用うべき必要なものがあれば、それを王の倉から出して用いよ。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="エズラ記 4:16; エズラ記 7:6; エズラ記 7:10–13"> われ、アルタシャスタ王は川向こうの州のすべての倉づかさに命を下して言う、『天の神の律法の学者である祭司エズラがあなたがたに求める事は、すべてこれを心して行え。</span>
<span className="v" id="v22" data-v="22" data-xref="ルカによる福音書 16:6–7; レビ記 2:13; エゼキエル書 45:14"> すなわち銀は百タラントまで、小麦は百コルまで、ぶどう酒は百バテまで、油は百バテまで、塩は制限なく与えよ。</span>
<span className="v" id="v23" data-v="23" data-xref="詩篇 119:4; エズラ記 7:18; エズラ記 6:10–12"> 天の神の宮のために、天の神の命じるところは、すべて正しくこれを行え。そうしないと神の怒りが、王と王の子らの国に臨むであろう』。</span>
<span className="v" id="v24" data-v="24" data-xref="エズラ記 7:7; エズラ記 4:13; エズラ記 2:36–55"> われわれは、またあなたがたに告げる、『祭司、レビびと、歌うたう者、門衛、宮に仕えるしもべ、および神のこの宮の仕えびとたちには、みつぎ、租税、税金を課してはならぬ』。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="エズラ記 7:10; 申命記 16:18; ヤコブの手紙 1:5"> エズラよ、あなたはあなたの手にある神の知恵によって、つかさおよび裁判人を立て、川向こうの州のすべての民、すなわちあなたの神の律法を知っている者たちを、ことごとくさばかせよ。あなたがたはまたこれを知らない者を教えよ。</span>
<span className="v" id="v26" data-v="26" data-xref="エズラ記 6:11; 申命記 13:1–18; レビ記 20:1–27"> あなたの神の律法および王の律法を守らない者を、きびしくその罪に定めて、あるいは死刑に、あるいは追放に、あるいは財産没収に、あるいは投獄に処せよ」。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="エズラ記 6:22; ヨハネの黙示録 17:17; イザヤ書 60:13"> われわれの先祖の神、主はほむべきかな。主はこのように、王の心に、エルサレムにある主の宮を飾る心を起させ、</span>
<span className="v" id="v28" data-v="28" data-xref="テモテヘの第二の手紙 4:17–18; エズラ記 5:5; 創世記 32:28"> また王の前と、その議官の前と王の大臣の前で、わたしに恵みを得させられた。わたしはわが神、主の手がわたしの上にあるので力を得、イスラエルのうちから首領たる人々を集めて、わたしと共に上らせた。</span>
</div>

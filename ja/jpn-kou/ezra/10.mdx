<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ダニエル書 9:20; 詩篇 119:136; ローマ人への手紙 9:2"> エズラが神の宮の前に泣き伏して祈り、かつざんげしていた時、男、女および子供の大いなる群集がイスラエルのうちから彼のもとに集まってきた。民はいたく泣き悲しんだ。</span>
<span className="v" id="v2" data-v="2" data-xref="ネヘミヤ書 13:27; エズラ記 9:2; エレミヤ書 3:12–13"> 時にエラムの子孫のうちのエヒエルの子シカニヤが、エズラに告げて言った、「われわれは神にむかって罪を犯し、この地の民から異邦の女をめとりました。しかし、このことについてはイスラエルに、今なお望みがあります。</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 7:2–3; エズラ記 9:4; ヨシュア記 23:12–13"> それでわれわれはわが主の教と、われわれの神の命令におののく人々の教とに従って、これらの妻ならびにその子供たちを、ことごとく追い出すという契約を、われわれの神に立てましょう。そして律法に従ってこれを行いましょう。</span>
<span className="v" id="v4" data-v="4" data-xref="歴代志上 28:10; 伝道の書 9:10; ヘブル人への手紙 12:12–13"> 立ちあがってください、この事はあなたの仕事です。われわれはあなたを助けます。心を強くしてこれを行いなさい」。</span>
<span className="v" id="v5" data-v="5" data-xref="ネヘミヤ書 13:25; ネヘミヤ書 5:12; 箴言 9:9"> エズラは立って、おもだった祭司、レビびとおよびすべてのイスラエルびとに、この言葉のように行うことを誓わせたので、彼らは誓った。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="申命記 9:18; ネヘミヤ書 3:1; ネヘミヤ書 12:22"> エズラは神の宮の前から出て、エリアシブの子ヨハナンのへやにはいったが、そこへ行っても彼はパンも食べず、水も飲まずに夜を過ごした。これは彼が、捕囚から帰った人々のとがを嘆いたからである。</span>
<span className="v" id="v7" data-v="7" data-xref="エズラ記 1:1; 歴代志下 30:5"> そしてユダおよびエルサレムにあまねく布告を出し、捕囚から帰ったすべての者に告げて、エルサレムに集まるべき事と、</span>
<span className="v" id="v8" data-v="8" data-xref="エズラ記 7:26; ヨハネによる福音書 9:22; 士師記 21:5"> つかさおよび長老たちのさとしに従って、三日のうちにこない者はだれでもその財産はことごとく没収され、その人自身は捕われ人の会から破門されると言った。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="サムエル記上 12:17–18; エレミヤ書 10:13; エズラ記 7:8–9"> そこでユダとベニヤミンの人々は皆三日のうちにエルサレムに集まった。これは九月の二十日であった。すべての民は神の宮の前の広場に座して、このことのため、また大雨のために震えおののいていた。</span>
<span className="v" id="v10" data-v="10" data-xref="エズラ記 9:6; 民数記 32:14; マタイによる福音書 23:32"> 時に祭司エズラは立って彼らに言った、「あなたがたは罪を犯し、異邦の女をめとって、イスラエルのとがを増した。</span>
<span className="v" id="v11" data-v="11" data-xref="ローマ人への手紙 12:2; エズラ記 10:3; イザヤ書 1:16–18"> それで今、あなたがたの先祖の神、主にざんげして、そのみ旨を行いなさい。あなたがたはこの地の民および異邦の女と離れなさい」。</span>
<span className="v" id="v12" data-v="12" data-xref="ネヘミヤ書 13:23; 詩篇 78:57; エズラ記 10:3–4"> すると会衆は皆大声をあげて答えた、「あなたの言われたとおり、われわれは必ず行います。</span>
<span className="v" id="v13" data-v="13" data-xref="エズラ記 10:18–44; マタイによる福音書 7:13–14"> しかし民は多く、また大雨の季節ですから、外に立っていることはできません。またこれは一日やふつかの仕事ではありません。われわれはこの事について大いに罪を犯したからです。</span>
<span className="v" id="v14" data-v="14" data-xref="歴代志下 29:10; 歴代志下 30:8; 民数記 25:4"> それでどうぞ、われわれのつかさたちは全会衆のために立ってください。われわれの町の内に、もし異邦の女をめとった者があるならば、みな定めの時にこさせなさい。またおのおのの町の長老および裁判人も、それと一緒にこさせなさい。そうすればこの事によるわれわれの神の激しい怒りは、ついにわれわれを離れるでしょう」。</span>
<span className="v" id="v15" data-v="15" data-xref="ネヘミヤ書 11:16; ネヘミヤ書 10:20; ネヘミヤ書 12:33"> ところがアサヘルの子ヨナタンおよびテクワの子ヤハジアはこれに反対した。そしてメシュラムおよびレビびとシャベタイは彼らを支持した。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="ヨブ記 29:16; 申命記 13:14; ヨハネによる福音書 7:51"> そこで捕囚から帰って来た人々はこのように行った。すなわち祭司エズラは、氏族の長たちをその氏族にしたがい、おのおのその名をさして選んだ。彼らは十月の一日から座してこの事を調べ、</span>
<span className="v" id="v17" data-v="17"> 正月の一日になって、異邦の女をめとった人々をことごとく調べ終った。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="エズラ記 5:2; エズラ記 3:2; ゼカリヤ書 3:1"> 祭司の子孫のうちで異邦の女をめとった事のあらわれた者は、ヨザダクの子エシュアの子ら、およびその兄弟たちのうちではマアセヤ、エリエゼル、ヤリブ、ゲダリヤであった。</span>
<span className="v" id="v19" data-v="19" data-xref="レビ記 6:6; 列王紀下 10:15; 歴代志下 30:8"> 彼らはその妻を離縁しようという誓いをなし、すでに罪を犯したというので、そのとがのために雄羊一頭をささげた。</span>
<span className="v" id="v20" data-v="20" data-xref="エズラ記 2:37; 歴代志上 24:14; ネヘミヤ書 7:40"> インメルの子らのうちではハナニおよびゼバデヤ。</span>
<span className="v" id="v21" data-v="21" data-xref="歴代志上 24:8; エズラ記 2:39; ネヘミヤ書 7:42"> ハリムの子らのうちではマアセヤ、エリヤ、シマヤ、エヒエル、ウジヤ。</span>
<span className="v" id="v22" data-v="22" data-xref="歴代志上 9:12; ネヘミヤ書 7:41; エズラ記 2:38"> パシュルの子らのうちではエリオエナイ、マアセヤ、イシマエル、ネタンエル、ヨザバデ、エラサ。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="ネヘミヤ書 10:10; ネヘミヤ書 11:16; エズラ記 8:33"> レビびとのうちではヨザバテ、シメイ、ケラヤ（すなわちケリタ）、ペタヒヤ、ユダ、エリエゼル。</span>
<span className="v" id="v24" data-v="24"> 歌うたう者のうちではエリアシブ。門衛のうちではシャルム、テレム、ウリ。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="エズラ記 2:3; ネヘミヤ書 7:8"> イスラエルのうち、パロシの子らのうちではラミヤ、エジア、マルキヤ、ミヤミン、エレアザル、ハシャビヤ、ベナヤ。</span>
<span className="v" id="v26" data-v="26" data-xref="エズラ記 10:2; エズラ記 2:31; ネヘミヤ書 7:12"> エラムの子らのうちではマッタニヤ、ゼカリヤ、エヒエル、アブデ、エレモテ、エリヤ。</span>
<span className="v" id="v27" data-v="27" data-xref="ネヘミヤ書 7:13; エズラ記 2:8"> ザットの子らのうちではエリオエナイ、エリアシブ、マッタニヤ、エレモテ、ザバデ、アジザ。</span>
<span className="v" id="v28" data-v="28" data-xref="エズラ記 8:11; エズラ記 2:11; ネヘミヤ書 7:16"> ベバイの子らのうちではヨハナン、ハナニヤ、ザバイ、アテライ。</span>
<span className="v" id="v29" data-v="29" data-xref="ネヘミヤ書 7:15; ネヘミヤ書 10:4; エズラ記 2:10"> バニの子らのうちではメシュラム、マルク、アダヤ、ヤシュブ、シヤル、エレモテ。</span>
<span className="v" id="v30" data-v="30" data-xref="エズラ記 8:4; ネヘミヤ書 7:11; エズラ記 2:6"> パハテ・モアブの子らのうちではアデナ、ケラル、ベナヤ、マアセヤ、マッタニヤ、ベザレル、ビンヌイ、マナセ。</span>
<span className="v" id="v31" data-v="31" data-xref="ネヘミヤ書 3:11; ネヘミヤ書 7:35; エズラ記 2:32"> ハリムの子らのうちではエリエゼル、イシヤ、マルキヤ、シマヤ、シメオン、</span>
<span className="v" id="v32" data-v="32"> ベニヤミン、マルク、シマリヤ。</span>
<span className="v" id="v33" data-v="33" data-xref="エズラ記 2:19; ネヘミヤ書 7:22"> ハシュムの子らのうちではマッテナイ、マッタタ、ザバデ、エリパレテ、エレマイ、マナセ、シメイ。</span>
<span className="v" id="v34" data-v="34"> バニの子らのうちではマアダイ、アムラム、ウエル、</span>
<span className="v" id="v35" data-v="35"> ベナヤ、ベデヤ、ケルヒ、</span>
<span className="v" id="v36" data-v="36"> ワニア、メレモテ、エリアシブ、</span>
<span className="v" id="v37" data-v="37"> マッタニヤ、マッテナイ、ヤアス。</span>
<span className="v" id="v38" data-v="38"> ビンヌイの子らのうちではシメイ、</span>
<span className="v" id="v39" data-v="39"> シレミヤ、ナタン、アダヤ、</span>
<span className="v" id="v40" data-v="40"> マクナデバイ、シャシャイ、シャライ、</span>
<span className="v" id="v41" data-v="41"> アザリエル、シレミヤ、シマリヤ、</span>
<span className="v" id="v42" data-v="42"> シャルム、アマリヤ、ヨセフ。</span>
<span className="v" id="v43" data-v="43" data-xref="エズラ記 2:29; ネヘミヤ書 7:33"> ネボの子らではエイエル、マッタテヤ、ザバデ、ゼビナ、ヤッダイ、ヨエル、ベナヤ。</span>
<span className="v" id="v44" data-v="44" data-xref="箴言 5:20; エズラ記 10:3; 箴言 2:16"> これらの者は皆異邦の女をめとった者である。彼らはその女たちをその子供と共に離縁した。</span>
</div>
</div>

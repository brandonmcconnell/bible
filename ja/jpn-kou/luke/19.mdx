<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨシュア記 6:1–27; ルカによる福音書 18:35; 列王紀下 2:18–22"> さて、イエスはエリコにはいって、その町をお通りになった。</span>
<span className="v" id="v2" data-v="2" data-xref="ルカによる福音書 18:24–27; 歴代志下 17:5–6"> ところが、そこにザアカイという名の人がいた。この人は取税人のかしらで、金持であった。</span>
<span className="v" id="v3" data-v="3" data-xref="ルカによる福音書 23:8; ルカによる福音書 9:7–9; ヨハネによる福音書 12:21"> 彼は、イエスがどんな人か見たいと思っていたが、背が低かったので、群衆にさえぎられて見ることができなかった。</span>
<span className="v" id="v4" data-v="4" data-xref="イザヤ書 9:10; ルカによる福音書 5:19; 列王紀上 10:27"> それでイエスを見るために、前の方に走って行って、いちじく桑の木に登った。そこを通られるところだったからである。</span>
<span className="v" id="v5" data-v="5" data-xref="ヨハネの黙示録 3:20; ヨハネによる福音書 14:23; ヘブル人への手紙 13:2"> イエスは、その場所にこられたとき、上を見あげて言われた、「ザアカイよ、急いで下りてきなさい。きょう、あなたの家に泊まることにしているから」。</span>
<span className="v" id="v6" data-v="6" data-xref="ルカによる福音書 5:29; 使徒行伝 16:34; 使徒行伝 16:15"> そこでザアカイは急いでおりてきて、よろこんでイエスを迎え入れた。</span>
<span className="v" id="v7" data-v="7" data-xref="ルカによる福音書 15:2; ルカによる福音書 7:39; ルカによる福音書 7:34"> 人々はみな、これを見てつぶやき、「彼は罪人の家にはいって客となった」と言った。</span>
<span className="v" id="v8" data-v="8" data-xref="サムエル記下 12:6; 民数記 5:7; ルカによる福音書 18:22–23"> ザアカイは立って主に言った、「主よ、わたしは誓って自分の財産の半分を貧民に施します。また、もしだれかから不正な取立てをしていましたら、それを四倍にして返します」。</span>
<span className="v" id="v9" data-v="9" data-xref="ガラテヤ人への手紙 3:7; ルカによる福音書 13:16; ローマ人への手紙 4:16"> イエスは彼に言われた、「きょう、救がこの家にきた。この人もアブラハムの子なのだから。</span>
<span className="v" id="v10" data-v="10" data-xref="エゼキエル書 34:16; マタイによる福音書 1:21; テモテヘの第一の手紙 1:13–16"> 人の子がきたのは、失われたものを尋ね出して救うためである」。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="ルカによる福音書 17:20; 使徒行伝 1:6; テサロニケ人への第二の手紙 2:1–3"> 人々がこれらの言葉を聞いているときに、イエスはなお一つの譬をお話しになった。それはエルサレムに近づいてこられたし、また人々が神の国はたちまち現れると思っていたためである。</span>
<span className="v" id="v12" data-v="12" data-xref="マタイによる福音書 25:14–30; ルカによる福音書 19:12–27; ルカによる福音書 20:9"> それで言われた、「ある身分の高い人が、王位を受けて帰ってくるために遠い所へ旅立つことになった。</span>
<span className="v" id="v13" data-v="13" data-xref="マタイによる福音書 25:14–15; ヨハネによる福音書 12:26; コリント人への第一の手紙 12:7–11"> そこで十人の僕を呼び十ミナを渡して言った、『わたしが帰って来るまで、これで商売をしなさい』。</span>
<span className="v" id="v14" data-v="14" data-xref="サムエル記上 8:7; 使徒行伝 7:51–52; 使徒行伝 3:14–15"> ところが、本国の住民は彼を憎んでいたので、あとから使者をおくって、『この人が王になるのをわれわれは望んでいない』と言わせた。</span>
<span className="v" id="v15" data-v="15" data-xref="コリント人への第一の手紙 4:1–5; ローマ人への手紙 14:10–12; 詩篇 2:4–6"> さて、彼が王位を受けて帰ってきたとき、だれがどんなもうけをしたかを知ろうとして、金を渡しておいた僕たちを呼んでこさせた。</span>
<span className="v" id="v16" data-v="16" data-xref="ヤコブの手紙 2:18–26; テモテヘの第二の手紙 4:7–8; コリント人への第一の手紙 15:10"> 最初の者が進み出て言った、『ご主人様、あなたの一ミナで十ミナをもうけました』。</span>
<span className="v" id="v17" data-v="17" data-xref="ルカによる福音書 16:10; マタイによる福音書 25:21; ヨハネの黙示録 2:26–29"> 主人は言った、『よい僕よ、うまくやった。あなたは小さい事に忠実であったから、十の町を支配させる』。</span>
<span className="v" id="v18" data-v="18" data-xref="マルコによる福音書 4:20; マタイによる福音書 13:23; コリント人への第二の手紙 8:12"> 次の者がきて言った、『ご主人様、あなたの一ミナで五ミナをつくりました』。</span>
<span className="v" id="v19" data-v="19" data-xref="コリント人への第一の手紙 15:58; コリント人への第一の手紙 15:41–42; コリント人への第一の手紙 3:8"> そこでこの者にも、『では、あなたは五つの町のかしらになれ』と言った。</span>
<span className="v" id="v20" data-v="20" data-xref="マタイによる福音書 25:24; 箴言 26:13–16; ヤコブの手紙 4:17"> それから、もうひとりの者がきて言った、『ご主人様、さあ、ここにあなたの一ミナがあります。わたしはそれをふくさに包んで、しまっておきました。</span>
<span className="v" id="v21" data-v="21" data-xref="マタイによる福音書 25:24–25; ローマ人への手紙 8:7; ヨハネの第一の手紙 4:18"> あなたはきびしい方で、おあずけにならなかったものを取りたて、おまきにならなかったものを刈る人なので、おそろしかったのです』。</span>
<span className="v" id="v22" data-v="22" data-xref="サムエル記下 1:16; マタイによる福音書 12:37; ヨブ記 15:5–6"> 彼に言った、『悪い僕よ、わたしはあなたの言ったその言葉であなたをさばこう。わたしがきびしくて、あずけなかったものを取りたて、まかなかったものを刈る人間だと、知っているのか。</span>
<span className="v" id="v23" data-v="23" data-xref="出エジプト記 22:25–27; ローマ人への手紙 2:4–5; 申命記 23:19–20"> では、なぜわたしの金を銀行に入れなかったのか。そうすれば、わたしが帰ってきたとき、その金を利子と一緒に引き出したであろうに』。</span>
<span className="v" id="v24" data-v="24" data-xref="ルカによる福音書 16:2; ルカによる福音書 12:20"> そして、そばに立っていた人々に、『その一ミナを彼から取り上げて、十ミナを持っている者に与えなさい』と言った。</span>
<span className="v" id="v25" data-v="25" data-xref="ルカによる福音書 16:2; サムエル記下 7:19; イザヤ書 55:8–9"> 彼らは言った、『ご主人様、あの人は既に十ミナを持っています』。</span>
<span className="v" id="v26" data-v="26" data-xref="ヨハネの第二の手紙 1:8; ルカによる福音書 8:18; マタイによる福音書 21:43"> 『あなたがたに言うが、おおよそ持っている人には、なお与えられ、持っていない人からは、持っているものまでも取り上げられるであろう。</span>
<span className="v" id="v27" data-v="27" data-xref="ルカによる福音書 19:14; 詩篇 21:8–9; マタイによる福音書 22:7"> しかしわたしが王になることを好まなかったあの敵どもを、ここにひっぱってきて、わたしの前で打ち殺せ』」。</span>
</div>
<div className="bp poetry">
<span className="v" id="v28" data-v="28" data-xref="ルカによる福音書 9:51; ヘブル人への手紙 12:2; ペテロの第一の手紙 4:1"> イエスはこれらのことを言ったのち、先頭に立ち、エルサレムへ上って行かれた。</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行伝 1:12; マタイによる福音書 21:17; マタイによる福音書 21:1–11"> そしてオリブという山に沿ったベテパゲとベタニヤに近づかれたとき、ふたりの弟子をつかわして言われた、</span>
<span className="v" id="v30" data-v="30" data-xref="ルカによる福音書 22:8–13; ルカによる福音書 19:32; サムエル記上 10:2–9"> 「向こうの村へ行きなさい。そこにはいったら、まだだれも乗ったことのないろばの子がつないであるのを見るであろう。それを解いて、引いてきなさい。</span>
<span className="v" id="v31" data-v="31" data-xref="詩篇 24:1; 詩篇 50:10–12; マルコによる福音書 11:3–6"> もしだれかが『なぜ解くのか』と問うたら、『主がお入り用なのです』と、そう言いなさい」。</span>
<span className="v" id="v32" data-v="32" data-xref="ルカによる福音書 22:13"> そこで、つかわされた者たちが行って見ると、果して、言われたとおりであった。</span>
<span className="v" id="v33" data-v="33"> 彼らが、そのろばの子を解いていると、その持ち主たちが、「なぜろばの子を解くのか」と言ったので、</span>
<span className="v" id="v34" data-v="34" data-xref="ゼカリヤ書 9:9; ヨハネによる福音書 10:35; コリント人への第二の手紙 8:9"> 「主がお入り用なのです」と答えた。</span>
<span className="v" id="v35" data-v="35" data-xref="マルコによる福音書 11:7–8; マタイによる福音書 21:7; ヨハネによる福音書 12:14"> そしてそれをイエスのところに引いてきて、その子ろばの上に自分たちの上着をかけてイエスをお乗せした。</span>
<span className="v" id="v36" data-v="36" data-xref="列王紀下 9:13; マタイによる福音書 21:8"> そして進んで行かれると、人々は自分たちの上着を道に敷いた。</span>
<span className="v" id="v37" data-v="37" data-xref="ヨハネによる福音書 12:12–13; エズラ記 3:10–13; マタイによる福音書 21:1"> いよいよオリブ山の下り道あたりに近づかれると、大ぜいの弟子たちはみな喜んで、彼らが見たすべての力あるみわざについて、声高らかに神をさんびして言いはじめた、</span>
<span className="v" id="v38" data-v="38" data-xref="ゼカリヤ書 9:9; ルカによる福音書 13:35; 詩篇 118:22–26"> <span className="pl pl-1">「主の御名によってきたる王に、</span><br /><span className="pl pl-1">祝福あれ。</span><br /><span className="pl pl-1">天には平和、</span><br /><span className="pl pl-1">いと高きところには栄光あれ」。</span></span>
<span className="v" id="v39" data-v="39" data-xref="使徒行伝 4:1–2; マタイによる福音書 23:13; 使徒行伝 4:16–18"> <span className="pl pl-1">ところが、群衆の中にいたあるパリサイ人たちがイエスに言った、「先生、あなたの弟子たちをおしかり下さい」。</span></span>
<span className="v" id="v40" data-v="40" data-xref="ハバクク書 2:11; イザヤ書 55:12; マタイによる福音書 3:9"> <span className="pl pl-1">答えて言われた、「あなたがたに言うが、もしこの人たちが黙れば、石が叫ぶであろう」。</span></span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="ルカによる福音書 13:34–35; ヨハネによる福音書 11:35; 詩篇 119:136"> いよいよ都の近くにきて、それが見えたとき、そのために泣いて言われた、</span>
<span className="v" id="v42" data-v="42" data-xref="申命記 32:29; ヘブル人への手紙 10:26–29; イザヤ書 48:18"> 「もしおまえも、この日に、平和をもたらす道を知ってさえいたら……しかし、それは今おまえの目に隠されている。</span>
<span className="v" id="v43" data-v="43" data-xref="ルカによる福音書 21:20–24; イザヤ書 29:1–4; エゼキエル書 4:2"> いつかは、敵が周囲に塁を築き、おまえを取りかこんで、四方から押し迫り、</span>
<span className="v" id="v44" data-v="44" data-xref="ルカによる福音書 21:6; ルカによる福音書 13:34–35; ヨハネによる福音書 3:18–21"> おまえとその内にいる子らとを地に打ち倒し、城内の一つの石も他の石の上に残して置かない日が来るであろう。それは、おまえが神のおとずれの時を知らないでいたからである」。</span>
<span className="v" id="v45" data-v="45" data-xref="マタイによる福音書 21:12–13; マルコによる福音書 11:15–17; ヨハネによる福音書 2:13–17"> それから宮にはいり、商売人たちを追い出しはじめて、</span>
<span className="v" id="v46" data-v="46" data-xref="イザヤ書 56:7; エレミヤ書 7:11; 詩篇 93:5"> 彼らに言われた、「『わが家は祈の家であるべきだ』と書いてあるのに、あなたがたはそれを盗賊の巣にしてしまった」。</span>
</div>
<div className="bp">
<span className="v" id="v47" data-v="47" data-xref="マルコによる福音書 11:18; マタイによる福音書 26:55; マルコによる福音書 11:27–33"> イエスは毎日、宮で教えておられた。祭司長、律法学者また民衆の重立った者たちはイエスを殺そうと思っていたが、</span>
<span className="v" id="v48" data-v="48" data-xref="ネヘミヤ書 8:3; 使徒行伝 16:14; ヨハネによる福音書 7:46–49"> 民衆がみな熱心にイエスに耳を傾けていたので、手のくだしようがなかった。</span>
</div>

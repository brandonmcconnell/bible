<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ルカによる福音書 3:1; マタイによる福音書 24:14; 使徒行伝 25:21"> そのころ、全世界の人口調査をせよとの勅令が、皇帝アウグストから出た。</span>
<span className="v" id="v2" data-v="2" data-xref="ルカによる福音書 3:1; マタイによる福音書 4:24; 使徒行伝 26:30"> これは、クレニオがシリヤの総督であった時に行われた最初の人口調査であった。</span>
<span className="v" id="v3" data-v="3"> 人々はみな登録をするために、それぞれ自分の町へ帰って行った。</span>
<span className="v" id="v4" data-v="4" data-xref="ミカ書 5:2; ヨハネによる福音書 7:42; サムエル記上 16:1"> ヨセフもダビデの家系であり、またその血統であったので、ガリラヤの町ナザレを出て、ユダヤのベツレヘムというダビデの町へ上って行った。</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 22:22–27; マタイによる福音書 1:18–19"> それは、すでに身重になっていたいいなづけの妻マリヤと共に、登録をするためであった。</span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 33:11; ヨハネの黙示録 12:1–5; ミカ書 5:2"> ところが、彼らがベツレヘムに滞在している間に、マリヤは月が満ちて、</span>
<span className="v" id="v7" data-v="7" data-xref="ガラテヤ人への手紙 4:4; コリント人への第二の手紙 8:9; イザヤ書 53:2–3"> 初子を産み、布にくるんで、飼葉おけの中に寝かせた。客間には彼らのいる余地がなかったからである。</span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="創世記 31:39–40; 詩篇 78:70–71; サムエル記上 17:34–35"> さて、この地方で羊飼たちが夜、野宿しながら羊の群れの番をしていた。</span>
<span className="v" id="v9" data-v="9" data-xref="イザヤ書 60:1; コリント人への第二の手紙 3:18; 列王紀上 8:11"> すると主の御使が現れ、主の栄光が彼らをめぐり照したので、彼らは非常に恐れた。</span>
<span className="v" id="v10" data-v="10" data-xref="イザヤ書 40:9; イザヤ書 61:1; イザヤ書 52:7"> 御使は言った、「恐れるな。見よ、すべての民に与えられる大きな喜びを、あなたがたに伝える。</span>
<span className="v" id="v11" data-v="11" data-xref="イザヤ書 9:6; マタイによる福音書 1:21; 使徒行伝 2:36"> きょうダビデの町に、あなたがたのために救主がお生れになった。このかたこそ主なるキリストである。</span>
<span className="v" id="v12" data-v="12" data-xref="イザヤ書 7:14; イザヤ書 53:1–2; イザヤ書 7:11"> あなたがたは、幼な子が布にくるまって飼葉おけの中に寝かしてあるのを見るであろう。それが、あなたがたに与えられるしるしである」。</span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 103:20–21; ヨハネの黙示録 5:11; 詩篇 148:2"> するとたちまち、おびただしい天の軍勢が現れ、御使と一緒になって神をさんびして言った、</span>
<span className="v" id="v14" data-v="14" data-xref="ローマ人への手紙 5:1; ルカによる福音書 19:38; コロサイ人への手紙 1:20"> <span className="pl pl-1">「いと高きところでは、神に栄光があるように、</span><br /><span className="pl pl-1">地の上では、み心にかなう人々に平和があるように」。</span></span>
<span className="v" id="v15" data-v="15" data-xref="ペテロの第一の手紙 3:22; マタイによる福音書 2:1–2; マタイによる福音書 2:9–11"> <span className="pl pl-1">御使たちが彼らを離れて天に帰ったとき、羊飼たちは「さあ、ベツレヘムへ行って、主がお知らせ下さったその出来事を見てこようではないか」と、互に語り合った。</span></span>
<span className="v" id="v16" data-v="16" data-xref="ルカによる福音書 19:32; ルカによる福音書 2:12; ルカによる福音書 2:7"> <span className="pl pl-1">そして急いで行って、マリヤとヨセフ、また飼葉おけに寝かしてある幼な子を捜しあてた。</span></span>
<span className="v" id="v17" data-v="17" data-xref="詩篇 66:16; ルカによる福音書 8:39; 詩篇 71:17–18"> <span className="pl pl-1">彼らに会った上で、この子について自分たちに告げ知らされた事を、人々に伝えた。</span></span>
<span className="v" id="v18" data-v="18" data-xref="ルカによる福音書 2:47; ルカによる福音書 4:36; ルカによる福音書 1:65–66"> <span className="pl pl-1">人々はみな、羊飼たちが話してくれたことを聞いて、不思議に思った。</span></span>
<span className="v" id="v19" data-v="19" data-xref="ルカによる福音書 2:51; ルカによる福音書 1:66; 箴言 4:4"> <span className="pl pl-1">しかし、マリヤはこれらの事をことごとく心に留めて、思いめぐらしていた。</span></span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 106:48; イザヤ書 29:19; 使徒行伝 11:18"> <span className="pl pl-1">羊飼たちは、見聞きしたことが何もかも自分たちに語られたとおりであったので、神をあがめ、またさんびしながら帰って行った。</span></span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="ルカによる福音書 1:31; 創世記 17:12; ガラテヤ人への手紙 4:4–5"> 八日が過ぎ、割礼をほどこす時となったので、受胎のまえに御使が告げたとおり、幼な子をイエスと名づけた。</span>
</div>
<div className="bp poetry">
<span className="v" id="v22" data-v="22" data-xref="レビ記 12:1–8"> それから、モーセの律法による彼らのきよめの期間が過ぎたとき、両親は幼な子を連れてエルサレムへ上った。</span>
<span className="v" id="v23" data-v="23" data-xref="出エジプト記 13:2; 出エジプト記 22:29; 民数記 3:13"> それは主の律法に「母の胎を初めて開く男の子はみな、主に聖別された者と、となえられねばならない」と書いてあるとおり、幼な子を主にささげるためであり、</span>
<span className="v" id="v24" data-v="24" data-xref="レビ記 12:6–8; レビ記 12:2; コリント人への第二の手紙 8:9"> また同じ主の律法に、「山ばと一つがい、または、家ばとのひな二羽」と定めてあるのに従って、犠牲をささげるためであった。</span>
<span className="v" id="v25" data-v="25" data-xref="イザヤ書 25:9; ルカによる福音書 2:38; ルカによる福音書 1:6"> その時、エルサレムにシメオンという名の人がいた。この人は正しい信仰深い人で、イスラエルの慰められるのを待ち望んでいた。また聖霊が彼に宿っていた。</span>
<span className="v" id="v26" data-v="26" data-xref="ヨハネによる福音書 8:51; ヘブル人への手紙 11:5; ルカによる福音書 9:27"> そして主のつかわす救主に会うまでは死ぬことはないと、聖霊の示しを受けていた。</span>
<span className="v" id="v27" data-v="27" data-xref="マタイによる福音書 4:1; ルカによる福音書 2:41; ルカによる福音書 2:51"> この人が御霊に感じて宮にはいった。すると律法に定めてあることを行うため、両親もその子イエスを連れてはいってきたので、</span>
<span className="v" id="v28" data-v="28" data-xref="ルカによる福音書 1:64; ルカによる福音書 2:20; ルカによる福音書 2:13–14"> シメオンは幼な子を腕に抱き、神をほめたたえて言った、</span>
<span className="v" id="v29" data-v="29" data-xref="ヨハネの黙示録 14:13; 創世記 15:15; ピリピ人への手紙 1:23"> <span className="pl pl-1">「主よ、今こそ、あなたはみ言葉のとおりに</span><br /><span className="pl pl-1">この僕を安らかに去らせてくださいます、</span></span>
<span className="v" id="v30" data-v="30" data-xref="イザヤ書 49:6; ルカによる福音書 2:10–11; ルカによる福音書 3:6"> <span className="pl pl-1">わたしの目が今あなたの救を見たのですから。</span></span>
<span className="v" id="v31" data-v="31" data-xref="イザヤ書 62:1–2; イザヤ書 42:1–4; 詩篇 98:2–3"> <span className="pl pl-1">この救はあなたが万民のまえにお備えになったもので、</span></span>
<span className="v" id="v32" data-v="32" data-xref="イザヤ書 60:1–3; イザヤ書 49:6; 使徒行伝 26:23"> <span className="pl pl-1">異邦人を照す啓示の光、</span><br /><span className="pl pl-1">み民イスラエルの栄光であります」。</span></span>
<span className="v" id="v33" data-v="33" data-xref="ルカによる福音書 1:65–66; イザヤ書 8:18; ルカによる福音書 2:48"> <span className="pl pl-1">父と母とは幼な子についてこのように語られたことを、不思議に思った。</span></span>
<span className="v" id="v34" data-v="34" data-xref="コリント人への第一の手紙 1:23; ペテロの第一の手紙 2:7–8; イザヤ書 8:14–15"> <span className="pl pl-1">するとシメオンは彼らを祝し、そして母マリヤに言った、「ごらんなさい、この幼な子は、イスラエルの多くの人を倒れさせたり立ちあがらせたりするために、また反対を受けるしるしとして、定められています。――</span></span>
<span className="v" id="v35" data-v="35" data-xref="申命記 8:2; コリント人への第一の手紙 11:19; マタイによる福音書 12:24–35"> <span className="pl pl-1">そして、あなた自身もつるぎで胸を刺し貫かれるでしょう。――それは多くの人の心にある思いが、現れるようになるためです」。</span></span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="出エジプト記 15:20; 創世記 30:13; 使徒行伝 21:9"> また、アセル族のパヌエルの娘で、アンナという女預言者がいた。彼女は非常に年をとっていた。むすめ時代にとついで、七年間だけ夫と共に住み、</span>
<span className="v" id="v37" data-v="37" data-xref="テモテヘの第一の手紙 5:5; 詩篇 23:6; 使徒行伝 14:23"> その後やもめぐらしをし、八十四歳になっていた。そして宮を離れずに夜も昼も断食と祈とをもって神に仕えていた。</span>
<span className="v" id="v38" data-v="38" data-xref="ルカによる福音書 2:25; コリント人への第二の手紙 9:15; マルコによる福音書 15:43"> この老女も、ちょうどそのとき近寄ってきて、神に感謝をささげ、そしてこの幼な子のことを、エルサレムの救を待ち望んでいるすべての人々に語りきかせた。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="ルカによる福音書 2:4; ガラテヤ人への手紙 4:4–5; 申命記 12:32"> 両親は主の律法どおりすべての事をすませたので、ガリラヤへむかい、自分の町ナザレに帰った。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="ルカによる福音書 2:52; ルカによる福音書 1:80; イザヤ書 11:1–5"> 幼な子は、ますます成長して強くなり、知恵に満ち、そして神の恵みがその上にあった。</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="出エジプト記 12:14; 民数記 28:16; 申命記 12:18"> さて、イエスの両親は、過越の祭には毎年エルサレムへ上っていた。</span>
<span className="v" id="v42" data-v="42"> イエスが十二歳になった時も、慣例に従って祭のために上京した。</span>
<span className="v" id="v43" data-v="43" data-xref="歴代志下 30:21–23; 出エジプト記 12:15; 歴代志下 25:17"> ところが、祭が終って帰るとき、少年イエスはエルサレムに居残っておられたが、両親はそれに気づかなかった。</span>
<span className="v" id="v44" data-v="44" data-xref="詩篇 122:1–4; イザヤ書 2:3; 詩篇 42:4"> そして道連れの中にいることと思いこんで、一日路を行ってしまい、それから、親族や知人の中を捜しはじめたが、</span>
<span className="v" id="v45" data-v="45"> 見つからないので、捜しまわりながらエルサレムへ引返した。</span>
<span className="v" id="v46" data-v="46" data-xref="ルカによる福音書 5:17; イザヤ書 49:1–2; イザヤ書 50:4"> そして三日の後に、イエスが宮の中で教師たちのまん中にすわって、彼らの話を聞いたり質問したりしておられるのを見つけた。</span>
<span className="v" id="v47" data-v="47" data-xref="マタイによる福音書 7:28; ルカによる福音書 4:32; 詩篇 119:99"> 聞く人々はみな、イエスの賢さやその答に驚嘆していた。</span>
<span className="v" id="v48" data-v="48" data-xref="ルカによる福音書 2:49; マタイによる福音書 12:46; ルカによる福音書 3:23"> 両親はこれを見て驚き、そして母が彼に言った、「どうしてこんな事をしてくれたのです。ごらんなさい、おとう様もわたしも心配して、あなたを捜していたのです」。</span>
<span className="v" id="v49" data-v="49" data-xref="ヨハネによる福音書 6:38; ヨハネによる福音書 8:29; マラキ書 3:1"> するとイエスは言われた、「どうしてお捜しになったのですか。わたしが自分の父の家にいるはずのことを、ご存じなかったのですか」。</span>
<span className="v" id="v50" data-v="50" data-xref="ルカによる福音書 18:34; ルカによる福音書 9:45; マルコによる福音書 9:32"> しかし、両親はその語られた言葉を悟ることができなかった。</span>
<span className="v" id="v51" data-v="51" data-xref="ルカによる福音書 2:19; ダニエル書 7:28; 創世記 37:11"> それからイエスは両親と一緒にナザレに下って行き、彼らにお仕えになった。母はこれらの事をみな心に留めていた。</span>
</div>
<div className="bp">
<span className="v" id="v52" data-v="52" data-xref="ルカによる福音書 2:40; 箴言 3:3–4; サムエル記上 2:26"> イエスはますます知恵が加わり、背たけも伸び、そして神と人から愛された。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨハネによる福音書 14:12; ルカによる福音書 10:19; マタイによる福音書 16:19"> それからイエスは十二弟子を呼び集めて、彼らにすべての悪霊を制し、病気をいやす力と権威とをお授けになった。</span>
<span className="v" id="v2" data-v="2" data-xref="マタイによる福音書 10:7–8; ルカによる福音書 10:9; マタイによる福音書 3:2"> また神の国を宣べ伝え、かつ病気をなおすためにつかわして</span>
<span className="v" id="v3" data-v="3" data-xref="ルカによる福音書 22:35; 詩篇 37:3; ルカによる福音書 10:4–12"> 言われた、「旅のために何も携えるな。つえも袋もパンも銭も持たず、また下着も二枚は持つな。</span>
<span className="v" id="v4" data-v="4" data-xref="マタイによる福音書 10:11; マルコによる福音書 6:10; ルカによる福音書 10:5–8"> また、どこかの家にはいったら、そこに留まっておれ。そしてそこから出かけることにしなさい。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行伝 13:51; 使徒行伝 18:6; マルコによる福音書 6:11"> だれもあなたがたを迎えるものがいなかったら、その町を出て行くとき、彼らに対する抗議のしるしに、足からちりを払い落しなさい」。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行伝 4:30; マルコによる福音書 16:20; 使徒行伝 5:15"> 弟子たちは出て行って、村々を巡り歩き、いたる所で福音を宣べ伝え、また病気をいやした。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="マルコによる福音書 6:14–28; マタイによる福音書 14:1–12; ルカによる福音書 3:1"> さて、領主ヘロデはいろいろな出来事を耳にして、あわて惑っていた。それは、ある人たちは、ヨハネが死人の中からよみがえったと言い、</span>
<span className="v" id="v8" data-v="8" data-xref="ヨハネによる福音書 1:21; ルカによる福音書 9:19; マルコによる福音書 6:15"> またある人たちは、エリヤが現れたと言い、またほかの人たちは、昔の預言者のひとりが復活したのだと言っていたからである。</span>
<span className="v" id="v9" data-v="9" data-xref="ルカによる福音書 23:8; ルカによる福音書 13:31–32"> そこでヘロデが言った、「ヨハネはわたしがすでに首を切ったのだが、こうしてうわさされているこの人は、いったい、だれなのだろう」。そしてイエスに会ってみようと思っていた。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="マタイによる福音書 11:21; ヘブル人への手紙 13:17; マタイによる福音書 14:13–21"> 使徒たちは帰ってきて、自分たちのしたことをすべてイエスに話した。それからイエスは彼らを連れて、ベツサイダという町へひそかに退かれた。</span>
<span className="v" id="v11" data-v="11" data-xref="ルカによる福音書 9:2; ルカによる福音書 5:31; ヘブル人への手紙 4:16"> ところが群衆がそれと知って、ついてきたので、これを迎えて神の国のことを語り聞かせ、また治療を要する人たちをいやされた。</span>
<span className="v" id="v12" data-v="12" data-xref="ヨハネによる福音書 6:1; ヨハネによる福音書 6:5–15; ホセア書 13:5"> それから日が傾きかけたので、十二弟子がイエスのもとにきて言った、「群衆を解散して、まわりの村々や部落へ行って宿を取り、食物を手にいれるようにさせてください。わたしたちはこんな寂しい所にきているのですから」。</span>
<span className="v" id="v13" data-v="13" data-xref="箴言 11:24–25; ヨハネによる福音書 6:5–9; 列王紀下 4:42–43"> しかしイエスは言われた、「あなたがたの手で食物をやりなさい」。彼らは言った、「わたしたちにはパン五つと魚二ひきしかありません、この大ぜいの人のために食物を買いに行くかしなければ」。</span>
<span className="v" id="v14" data-v="14" data-xref="マルコによる福音書 8:6; コリント人への第一の手紙 14:40; マルコによる福音書 6:39–40"> というのは、男が五千人ばかりもいたからである。しかしイエスは弟子たちに言われた、「人々をおおよそ五十人ずつの組にして、すわらせなさい」。</span>
<span className="v" id="v15" data-v="15"> 彼らはそのとおりにして、みんなをすわらせた。</span>
<span className="v" id="v16" data-v="16" data-xref="マタイによる福音書 14:19; テモテヘの第一の手紙 4:4–5; マタイによる福音書 15:36"> イエスは五つのパンと二ひきの魚とを手に取り、天を仰いでそれを祝福してさき、弟子たちにわたして群衆に配らせた。</span>
<span className="v" id="v17" data-v="17" data-xref="列王紀下 4:44; マタイによる福音書 15:37–38; ヨハネによる福音書 6:11–13"> みんなの者は食べて満腹した。そして、その余りくずを集めたら、十二かごあった。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="マタイによる福音書 16:13–16; ルカによる福音書 11:1; マタイによる福音書 26:36"> イエスがひとりで祈っておられたとき、弟子たちが近くにいたので、彼らに尋ねて言われた、「群衆はわたしをだれと言っているか」。</span>
<span className="v" id="v19" data-v="19" data-xref="マラキ書 4:5; ルカによる福音書 9:7–8; マタイによる福音書 14:2"> 彼らは答えて言った、「バプテスマのヨハネだと、言っています。しかしほかの人たちは、エリヤだと言い、また昔の預言者のひとりが復活したのだと、言っている者もあります」。</span>
<span className="v" id="v20" data-v="20" data-xref="マタイによる福音書 16:15–17; ヨハネによる福音書 4:29; ヨハネによる福音書 7:41"> 彼らに言われた、「それでは、あなたがたはわたしをだれと言うか」。ペテロが答えて言った、「神のキリストです」。</span>
<span className="v" id="v21" data-v="21" data-xref="マタイによる福音書 16:20; マタイによる福音書 17:9; マルコによる福音書 8:30–31"> イエスは彼らを戒め、この事をだれにも言うなと命じ、そして言われた、</span>
<span className="v" id="v22" data-v="22" data-xref="イザヤ書 53:1–12; ルカによる福音書 24:7; ルカによる福音書 18:31–34"> 「人の子は必ず多くの苦しみを受け、長老、祭司長、律法学者たちに捨てられ、また殺され、そして三日目によみがえる」。</span>
<span className="v" id="v23" data-v="23" data-xref="マタイによる福音書 10:38–39; ルカによる福音書 14:26–27; ローマ人への手紙 8:13"> それから、みんなの者に言われた、「だれでもわたしについてきたいと思うなら、自分を捨て、日々自分の十字架を負うて、わたしに従ってきなさい。</span>
<span className="v" id="v24" data-v="24" data-xref="ルカによる福音書 17:33; ヨハネによる福音書 12:25; 使徒行伝 20:23–24"> 自分の命を救おうと思う者はそれを失い、わたしのために自分の命を失う者は、それを救うであろう。</span>
<span className="v" id="v25" data-v="25" data-xref="マルコによる福音書 8:36; マタイによる福音書 16:26; 詩篇 49:6–8"> 人が全世界をもうけても、自分自身を失いまたは損したら、なんの得になろうか。</span>
<span className="v" id="v26" data-v="26" data-xref="マタイによる福音書 10:32–33; テモテヘの第二の手紙 2:12; ルカによる福音書 12:8–9"> わたしとわたしの言葉とを恥じる者に対しては、人の子もまた、自分の栄光と、父と聖なる御使との栄光のうちに現れて来るとき、その者を恥じるであろう。</span>
<span className="v" id="v27" data-v="27" data-xref="マタイによる福音書 16:28; マルコによる福音書 9:1; ヨハネによる福音書 21:22–23"> よく聞いておくがよい、神の国を見るまでは、死を味わわない者が、ここに立っている者の中にいる」。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="マタイによる福音書 17:1–13; マタイによる福音書 26:37–39; マルコによる福音書 14:33–36"> これらのことを話された後、八日ほどたってから、イエスはペテロ、ヨハネ、ヤコブを連れて、祈るために山に登られた。</span>
<span className="v" id="v29" data-v="29" data-xref="マタイによる福音書 17:2; マルコによる福音書 9:2–3; 出エジプト記 34:29–35"> 祈っておられる間に、み顔の様が変り、み衣がまばゆいほどに白く輝いた。</span>
<span className="v" id="v30" data-v="30" data-xref="ヘブル人への手紙 3:3–6; コリント人への第二の手紙 3:7–11; ルカによる福音書 1:17"> すると見よ、ふたりの人がイエスと語り合っていた。それはモーセとエリヤであったが、</span>
<span className="v" id="v31" data-v="31" data-xref="ピリピ人への手紙 3:21; ペテロの第一の手紙 1:11–12; ペテロの第一の手紙 5:10"> 栄光の中に現れて、イエスがエルサレムで遂げようとする最後のことについて話していたのである。</span>
<span className="v" id="v32" data-v="32" data-xref="ダニエル書 8:18; ヨハネによる福音書 1:14; ダニエル書 10:9"> ペテロとその仲間の者たちとは熟睡していたが、目をさますと、イエスの栄光の姿と、共に立っているふたりの人とを見た。</span>
<span className="v" id="v33" data-v="33" data-xref="マルコによる福音書 9:5–6; マルコによる福音書 10:38; 詩篇 4:6–7"> このふたりがイエスを離れ去ろうとしたとき、ペテロは自分が何を言っているのかわからないで、イエスに言った、「先生、わたしたちがここにいるのは、すばらしいことです。それで、わたしたちは小屋を三つ建てましょう。一つはあなたのために、一つはモーセのために、一つはエリヤのために」。</span>
<span className="v" id="v34" data-v="34" data-xref="出エジプト記 40:34–38; マタイによる福音書 17:5–7; 士師記 13:22"> 彼がこう言っている間に、雲がわき起って彼らをおおいはじめた。そしてその雲に囲まれたとき、彼らは恐れた。</span>
<span className="v" id="v35" data-v="35" data-xref="ルカによる福音書 3:22; 使徒行伝 3:22–23; マタイによる福音書 3:17"> すると雲の中から声があった、「これはわたしの子、わたしの選んだ者である。これに聞け」。</span>
<span className="v" id="v36" data-v="36" data-xref="マタイによる福音書 17:9; マルコによる福音書 9:9–10; マルコによる福音書 9:6"> そして声が止んだとき、イエスがひとりだけになっておられた。弟子たちは沈黙を守って、自分たちが見たことについては、そのころだれにも話さなかった。</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="マタイによる福音書 17:14–20; マルコによる福音書 9:14–29"> 翌日、一同が山を降りて来ると、大ぜいの群衆がイエスを出迎えた。</span>
<span className="v" id="v38" data-v="38" data-xref="ゼカリヤ書 12:10; ヨハネによる福音書 4:47; ルカによる福音書 7:12"> すると突然、ある人が群衆の中から大声をあげて言った、「先生、お願いです。わたしのむすこを見てやってください。この子はわたしのひとりむすこですが、</span>
<span className="v" id="v39" data-v="39" data-xref="マルコによる福音書 9:20; ルカによる福音書 8:29; ルカによる福音書 4:35"> 霊が取りつきますと、彼は急に叫び出すのです。それから、霊は彼をひきつけさせて、あわを吹かせ、彼を弱り果てさせて、なかなか出て行かないのです。</span>
<span className="v" id="v40" data-v="40" data-xref="ルカによる福音書 9:1; 使徒行伝 19:13–16; ルカによる福音書 10:17–19"> それで、お弟子たちに、この霊を追い出してくださるように願いましたが、できませんでした」。</span>
<span className="v" id="v41" data-v="41" data-xref="申命記 32:5; ローマ人への手紙 2:4; ヨハネによる福音書 20:27"> イエスは答えて言われた、「ああ、なんという不信仰な、曲った時代であろう。いつまで、わたしはあなたがたと一緒におられようか、またあなたがたに我慢ができようか。あなたの子をここに連れてきなさい」。</span>
<span className="v" id="v42" data-v="42" data-xref="マルコによる福音書 9:26–27; ルカによる福音書 7:15; ヨハネの黙示録 12:12"> ところが、その子がイエスのところに来る時にも、悪霊が彼を引き倒して、引きつけさせた。イエスはこの汚れた霊をしかりつけ、その子供をいやして、父親にお渡しになった。</span>
<span className="v" id="v43" data-v="43" data-xref="ルカによる福音書 9:43–45; ルカによる福音書 5:26; マタイによる福音書 17:22"> 人々はみな、神の偉大な力に非常に驚いた。<br />みんなの者がイエスのしておられた数々の事を不思議に思っていると、弟子たちに言われた、</span>
<span className="v" id="v44" data-v="44" data-xref="ルカによる福音書 9:22; 使徒行伝 2:23; ルカによる福音書 2:19"> 「あなたがたはこの言葉を耳におさめて置きなさい。人の子は人々の手に渡されようとしている」。</span>
<span className="v" id="v45" data-v="45" data-xref="ルカによる福音書 18:34; ルカによる福音書 2:50; ヨハネによる福音書 12:16"> しかし、彼らはなんのことかわからなかった。それが彼らに隠されていて、悟ることができなかったのである。また彼らはそのことについて尋ねるのを恐れていた。</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="マタイによる福音書 18:1–5; マルコによる福音書 9:33–37; マタイによる福音書 20:20–22"> 弟子たちの間に、彼らのうちでだれがいちばん偉いだろうかということで、議論がはじまった。</span>
<span className="v" id="v47" data-v="47" data-xref="詩篇 139:23; ヨハネによる福音書 16:30; ルカによる福音書 5:22"> イエスは彼らの心の思いを見抜き、ひとりの幼な子を取りあげて自分のそばに立たせ、彼らに言われた、</span>
<span className="v" id="v48" data-v="48" data-xref="ペテロの第一の手紙 5:6; ルカによる福音書 14:11; マルコによる福音書 9:37"> 「だれでもこの幼な子をわたしの名のゆえに受けいれる者は、わたしを受けいれるのである。そしてわたしを受けいれる者は、わたしをおつかわしになったかたを受けいれるのである。あなたがたみんなの中でいちばん小さい者こそ、大きいのである」。</span>
</div>
<div className="bp">
<span className="v" id="v49" data-v="49" data-xref="マルコによる福音書 9:38–40; 民数記 11:27–29; マルコによる福音書 10:13–14"> するとヨハネが答えて言った、「先生、わたしたちはある人があなたの名を使って悪霊を追い出しているのを見ましたが、その人はわたしたちの仲間でないので、やめさせました」。</span>
<span className="v" id="v50" data-v="50" data-xref="マタイによる福音書 12:30; ルカによる福音書 11:23; コリント人への第一の手紙 12:3"> イエスは彼に言われた、「やめさせないがよい。あなたがたに反対しない者は、あなたがたの味方なのである」。</span>
</div>
<div className="bp">
<span className="v" id="v51" data-v="51" data-xref="イザヤ書 50:5–9; マルコによる福音書 16:19; ルカによる福音書 13:22"> さて、イエスが天に上げられる日が近づいたので、エルサレムへ行こうと決意して、その方へ顔をむけられ、</span>
<span className="v" id="v52" data-v="52" data-xref="マタイによる福音書 10:5; ルカによる福音書 17:16; ルカによる福音書 10:1"> 自分に先立って使者たちをおつかわしになった。そして彼らがサマリヤ人の村へはいって行き、イエスのために準備をしようとしたところ、</span>
<span className="v" id="v53" data-v="53" data-xref="ヨハネによる福音書 4:9; ヨハネによる福音書 4:40–42; ルカによる福音書 9:48"> 村人は、エルサレムへむかって進んで行かれるというので、イエスを歓迎しようとはしなかった。</span>
<span className="v" id="v54" data-v="54" data-xref="列王紀下 1:10–14; ヤコブの手紙 3:14–18; ヤコブの手紙 1:19–20"> 弟子のヤコブとヨハネとはそれを見て言った、「主よ、いかがでしょう。彼らを焼き払ってしまうように、天から火をよび求めましょうか」。</span>
<span className="v" id="v55" data-v="55" data-xref="ヨハネの黙示録 3:19; ペテロの第一の手紙 3:9; エレミヤ書 17:9"> イエスは振りかえって、彼らをおしかりになった。</span>
<span className="v" id="v56" data-v="56" data-xref="マタイによる福音書 20:28; ローマ人への手紙 12:21; ヨハネによる福音書 3:17"> そして一同はほかの村へ行った。</span>
</div>
<div className="bp">
<span className="v" id="v57" data-v="57" data-xref="マタイによる福音書 8:19–22; ヨハネによる福音書 13:37; ルカによる福音書 9:57–60"> 道を進んで行くと、ある人がイエスに言った、「あなたがおいでになる所ならどこへでも従ってまいります」。</span>
<span className="v" id="v58" data-v="58" data-xref="マタイによる福音書 8:20; ルカによる福音書 14:26–33; ヤコブの手紙 2:5"> イエスはその人に言われた、「きつねには穴があり、空の鳥には巣がある。しかし、人の子にはまくらする所がない」。</span>
<span className="v" id="v59" data-v="59" data-xref="マタイによる福音書 16:24; マタイによる福音書 6:33; 列王紀上 19:20"> またほかの人に、「わたしに従ってきなさい」と言われた。するとその人が言った、「まず、父を葬りに行かせてください」。</span>

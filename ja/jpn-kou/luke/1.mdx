<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行伝 1:1–3; ペテロの第二の手紙 1:16–19; ヨハネによる福音書 20:31"> わたしたちの間に成就された出来事を、最初から親しく見た人々であって、</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネによる福音書 15:27; 使徒行伝 26:16; ヘブル人への手紙 2:3"> 御言に仕えた人々が伝えたとおり物語に書き連ねようと、多くの人が手を着けましたが、</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行伝 1:1; 使徒行伝 26:25; 使徒行伝 11:4"> テオピロ閣下よ、わたしもすべての事を初めから詳しく調べていますので、ここに、それを順序正しく書きつづって、閣下に献じることにしました。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネによる福音書 20:31; 使徒行伝 18:25; コリント人への第一の手紙 14:19"> すでにお聞きになっている事が確実であることを、これによって十分に知っていただきたいためであります。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="歴代志上 24:10; マタイによる福音書 2:1; ネヘミヤ書 12:4"> ユダヤの王ヘロデの世に、アビヤの組の祭司で名をザカリヤという者がいた。その妻はアロン家の娘のひとりで、名をエリサベツといった。</span>
<span className="v" id="v6" data-v="6" data-xref="創世記 7:1; 創世記 17:1; ピリピ人への手紙 2:15"> ふたりとも神のみまえに正しい人であって、主の戒めと定めとを、みな落度なく行っていた。</span>
<span className="v" id="v7" data-v="7" data-xref="ヘブル人への手紙 11:11; 創世記 18:11; サムエル記上 1:2"> ところが、エリサベツは不妊の女であったため、彼らには子がなく、そしてふたりともすでに年老いていた。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="歴代志下 8:14; 歴代志上 24:19; 歴代志下 31:2"> さてザカリヤは、その組が当番になり神のみまえに祭司の務をしていたとき、</span>
<span className="v" id="v9" data-v="9" data-xref="歴代志下 29:11; 出エジプト記 30:7–8; 歴代志上 23:13"> 祭司職の慣例に従ってくじを引いたところ、主の聖所にはいって香をたくことになった。</span>
<span className="v" id="v10" data-v="10" data-xref="レビ記 16:17; ヨハネの黙示録 8:3; ヘブル人への手紙 4:14"> 香をたいている間、多くの民衆はみな外で祈っていた。</span>
<span className="v" id="v11" data-v="11" data-xref="出エジプト記 40:26–27; 使徒行伝 10:3–4; 士師記 13:3"> すると主の御使が現れて、香壇の右に立った。</span>
<span className="v" id="v12" data-v="12" data-xref="士師記 13:22; 士師記 6:22; ルカによる福音書 2:9–10"> ザカリヤはこれを見て、おじ惑い、恐怖の念に襲われた。</span>
<span className="v" id="v13" data-v="13" data-xref="サムエル記上 2:21; 使徒行伝 10:31; 創世記 25:21"> そこで御使が彼に言った、「恐れるな、ザカリヤよ、あなたの祈が聞きいれられたのだ。あなたの妻エリサベツは男の子を産むであろう。その子をヨハネと名づけなさい。</span>
<span className="v" id="v14" data-v="14" data-xref="ルカによる福音書 1:58; 箴言 23:24; 創世記 21:6"> 彼はあなたに喜びと楽しみとをもたらし、多くの人々もその誕生を喜ぶであろう。</span>
<span className="v" id="v15" data-v="15" data-xref="エレミヤ書 1:5; 民数記 6:2–4; ルカによる福音書 7:33"> 彼は主のみまえに大いなる者となり、ぶどう酒や強い酒をいっさい飲まず、母の胎内にいる時からすでに聖霊に満たされており、</span>
<span className="v" id="v16" data-v="16" data-xref="イザヤ書 40:3–5; マタイによる福音書 21:32; マラキ書 3:1"> そして、イスラエルの多くの子らを、主なる彼らの神に立ち帰らせるであろう。</span>
<span className="v" id="v17" data-v="17" data-xref="マラキ書 4:5–6; マタイによる福音書 11:14; ルカによる福音書 1:76"> 彼はエリヤの霊と力とをもって、みまえに先立って行き、父の心を子に向けさせ、逆らう者に義人の思いを持たせて、整えられた民を主に備えるであろう」。</span>
<span className="v" id="v18" data-v="18" data-xref="イザヤ書 38:22; 創世記 17:17; ルカによる福音書 1:7"> するとザカリヤは御使に言った、「どうしてそんな事が、わたしにわかるでしょうか。わたしは老人ですし、妻も年をとっています」。</span>
<span className="v" id="v19" data-v="19" data-xref="ルカによる福音書 1:26; マタイによる福音書 18:10; ダニエル書 9:21–23"> 御使が答えて言った、「わたしは神のみまえに立つガブリエルであって、この喜ばしい知らせをあなたに語り伝えるために、つかわされたものである。</span>
<span className="v" id="v20" data-v="20" data-xref="エゼキエル書 3:26; エゼキエル書 24:27; ルカによる福音書 1:22"> 時が来れば成就するわたしの言葉を信じなかったから、あなたはおしになり、この事の起る日まで、ものが言えなくなる」。</span>
<span className="v" id="v21" data-v="21" data-xref="民数記 6:23–27"> 民衆はザカリヤを待っていたので、彼が聖所内で暇どっているのを不思議に思っていた。</span>
<span className="v" id="v22" data-v="22" data-xref="ルカによる福音書 1:62; ヨハネによる福音書 13:24; 使徒行伝 21:40"> ついに彼は出てきたが、物が言えなかったので、人々は彼が聖所内でまぼろしを見たのだと悟った。彼は彼らに合図をするだけで、引きつづき、おしのままでいた。</span>
<span className="v" id="v23" data-v="23" data-xref="歴代志上 9:25; 列王紀下 11:5–7"> それから務の期日が終ったので、家に帰った。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24"> そののち、妻エリサベツはみごもり、五か月のあいだ引きこもっていたが、</span>
<span className="v" id="v25" data-v="25" data-xref="創世記 30:22–23; イザヤ書 54:1–4; 創世記 21:1–2"> 「主は、今わたしを心にかけてくださって、人々の間からわたしの恥を取り除くために、こうしてくださいました」と言った。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="マタイによる福音書 2:23; ルカによる福音書 1:19; ヨハネによる福音書 7:41"> 六か月目に、御使ガブリエルが、神からつかわされて、ナザレというガリラヤの町の一処女のもとにきた。</span>
<span className="v" id="v27" data-v="27" data-xref="マタイによる福音書 1:18; イザヤ書 7:14; マタイによる福音書 1:16"> この処女はダビデ家の出であるヨセフという人のいいなづけになっていて、名をマリヤといった。</span>
<span className="v" id="v28" data-v="28" data-xref="士師記 6:12; ダニエル書 10:19; ルカによる福音書 1:30"> 御使がマリヤのところにきて言った、「恵まれた女よ、おめでとう、主があなたと共におられます」。</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行伝 10:17; ルカによる福音書 1:12; 使徒行伝 10:4"> この言葉にマリヤはひどく胸騒ぎがして、このあいさつはなんの事であろうかと、思いめぐらしていた。</span>
<span className="v" id="v30" data-v="30" data-xref="ルカによる福音書 1:13; ローマ人への手紙 8:31; ルカによる福音書 12:32"> すると御使が言った、「恐れるな、マリヤよ、あなたは神から恵みをいただいているのです。</span>
<span className="v" id="v31" data-v="31" data-xref="イザヤ書 7:14; マタイによる福音書 1:21; マタイによる福音書 1:25"> 見よ、あなたはみごもって男の子を産むでしょう。その子をイエスと名づけなさい。</span>
<span className="v" id="v32" data-v="32" data-xref="イザヤ書 9:6–7; イザヤ書 16:5; サムエル記下 7:11–13"> 彼は大いなる者となり、いと高き者の子と、となえられるでしょう。そして、主なる神は彼に父ダビデの王座をお与えになり、</span>
<span className="v" id="v33" data-v="33" data-xref="ダニエル書 2:44; ヘブル人への手紙 1:8; ダニエル書 7:13–14"> 彼はとこしえにヤコブの家を支配し、その支配は限りなく続くでしょう」。</span>
<span className="v" id="v34" data-v="34" data-xref="士師記 13:8–12; 使徒行伝 9:6"> そこでマリヤは御使に言った、「どうして、そんな事があり得ましょうか。わたしにはまだ夫がありませんのに」。</span>
<span className="v" id="v35" data-v="35" data-xref="マタイによる福音書 1:18; ヨハネによる福音書 1:49; マタイによる福音書 1:20"> 御使が答えて言った、「聖霊があなたに臨み、いと高き者の力があなたをおおうでしょう。それゆえに、生れ出る子は聖なるものであり、神の子と、となえられるでしょう。</span>
<span className="v" id="v36" data-v="36"> あなたの親族エリサベツも老年ながら子を宿しています。不妊の女といわれていたのに、はや六か月になっています。</span>
<span className="v" id="v37" data-v="37" data-xref="マタイによる福音書 19:26; エレミヤ書 32:27; マルコによる福音書 10:27"> 神には、なんでもできないことはありません」。</span>
<span className="v" id="v38" data-v="38" data-xref="ローマ人への手紙 4:20–21; 詩篇 119:38; 詩篇 116:16"> そこでマリヤが言った、「わたしは主のはしためです。お言葉どおりこの身に成りますように」。そして御使は彼女から離れて行った。</span>
</div>
<div className="bp poetry">
<span className="v" id="v39" data-v="39" data-xref="ルカによる福音書 1:65; ヨシュア記 15:48–59; ヨシュア記 10:40"> そのころ、マリヤは立って、大急ぎで山里へむかいユダの町に行き、</span>
<span className="v" id="v40" data-v="40"> ザカリヤの家にはいってエリサベツにあいさつした。</span>
<span className="v" id="v41" data-v="41" data-xref="ルカによる福音書 1:67; 使徒行伝 4:8; ルカによる福音書 1:44"> エリサベツがマリヤのあいさつを聞いたとき、その子が胎内でおどった。エリサベツは聖霊に満たされ、</span>
<span className="v" id="v42" data-v="42" data-xref="ルカによる福音書 1:28; 士師記 5:24; 創世記 22:18"> 声高く叫んで言った、「あなたは女の中で祝福されたかた、あなたの胎の実も祝福されています。</span>
<span className="v" id="v43" data-v="43" data-xref="ヨハネによる福音書 20:28; ヨハネによる福音書 13:13; ルカによる福音書 2:11"> 主の母上がわたしのところにきてくださるとは、なんという光栄でしょう。</span>
<span className="v" id="v44" data-v="44"> ごらんなさい。あなたのあいさつの声がわたしの耳にはいったとき、子供が胎内で喜びおどりました。</span>
<span className="v" id="v45" data-v="45" data-xref="ヨハネによる福音書 20:29; ヨハネによる福音書 11:40; ルカによる福音書 11:27–28"> 主のお語りになったことが必ず成就すると信じた女は、なんとさいわいなことでしょう」。</span>
<span className="v" id="v46" data-v="46" data-xref="サムエル記上 2:1–10; 詩篇 34:2–3; 詩篇 35:9"> するとマリヤは言った、<br /><span className="pl pl-1">「わたしの魂は主をあがめ、</span></span>
<span className="v" id="v47" data-v="47" data-xref="詩篇 35:9; テモテヘの第一の手紙 2:3; ハバクク書 3:18"> <span className="pl pl-1">わたしの霊は救主なる神をたたえます。</span></span>
<span className="v" id="v48" data-v="48" data-xref="詩篇 138:6; マラキ書 3:12; コリント人への第一の手紙 1:26–28"> <span className="pl pl-1">この卑しい女をさえ、心にかけてくださいました。</span><br /><span className="pl pl-1">今からのち代々の人々は、わたしをさいわいな女と言うでしょう、</span></span>
<span className="v" id="v49" data-v="49" data-xref="詩篇 126:2–3; 詩篇 111:9; エペソ人への手紙 3:20"> <span className="pl pl-1">力あるかたが、わたしに大きな事をしてくださったからです。</span><br /><span className="pl pl-1">そのみ名はきよく、</span></span>
<span className="v" id="v50" data-v="50" data-xref="詩篇 103:17–18; 出エジプト記 20:6; 創世記 17:7"> <span className="pl pl-1">そのあわれみは、代々限りなく</span><br /><span className="pl pl-1">主をかしこみ恐れる者に及びます。</span></span>
<span className="v" id="v51" data-v="51" data-xref="詩篇 98:1; イザヤ書 52:10; サムエル記上 2:3–4"> <span className="pl pl-1">主はみ腕をもって力をふるい、</span><br /><span className="pl pl-1">心の思いのおごり高ぶる者を追い散らし、</span></span>
<span className="v" id="v52" data-v="52" data-xref="エゼキエル書 17:24; ヤコブの手紙 4:10; 詩篇 107:40–41"> <span className="pl pl-1">権力ある者を王座から引きおろし、</span><br /><span className="pl pl-1">卑しい者を引き上げ、</span></span>
<span className="v" id="v53" data-v="53" data-xref="詩篇 107:8–9; ルカによる福音書 6:21; 詩篇 34:10"> <span className="pl pl-1">飢えている者を良いもので飽かせ、</span><br /><span className="pl pl-1">富んでいる者を空腹のまま帰らせなさいます。</span></span>
<span className="v" id="v54" data-v="54" data-xref="詩篇 98:3; ミカ書 7:20; イザヤ書 44:21"> <span className="pl pl-1">主は、あわれみをお忘れにならず、</span><br /><span className="pl pl-1">その僕イスラエルを助けてくださいました、</span></span>
<span className="v" id="v55" data-v="55" data-xref="詩篇 105:6–10; 創世記 17:19; 詩篇 132:11–17"> <span className="pl pl-1">わたしたちの父祖アブラハムとその子孫とを</span><br /><span className="pl pl-1">とこしえにあわれむと約束なさったとおりに」。</span></span>
<span className="v" id="v56" data-v="56"> <span className="pl pl-1">マリヤは、エリサベツのところに三か月ほど滞在してから、家に帰った。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v57" data-v="57" data-xref="ルカによる福音書 1:13; 創世記 21:2–3; ルカによる福音書 2:6–7"> さてエリサベツは月が満ちて、男の子を産んだ。</span>
<span className="v" id="v58" data-v="58" data-xref="ルカによる福音書 1:25; ルカによる福音書 1:14; ローマ人への手紙 12:15"> 近所の人々や親族は、主が大きなあわれみを彼女におかけになったことを聞いて、共どもに喜んだ。</span>
<span className="v" id="v59" data-v="59" data-xref="創世記 17:12; レビ記 12:3; ピリピ人への手紙 3:5"> 八日目になったので、幼な子に割礼をするために人々がきて、父の名にちなんでザカリヤという名にしようとした。</span>
<span className="v" id="v60" data-v="60" data-xref="ルカによる福音書 1:13; サムエル記下 12:25; ルカによる福音書 1:63"> ところが、母親は、「いいえ、ヨハネという名にしなくてはいけません」と言った。</span>
<span className="v" id="v61" data-v="61"> 人々は、「あなたの親族の中には、そういう名のついた者は、ひとりもいません」と彼女に言った。</span>
<span className="v" id="v62" data-v="62" data-xref="ルカによる福音書 1:22"> そして父親に、どんな名にしたいのですかと、合図で尋ねた。</span>
<span className="v" id="v63" data-v="63" data-xref="ルカによる福音書 1:60; イザヤ書 30:8; ルカによる福音書 1:13"> ザカリヤは書板を持ってこさせて、それに「その名はヨハネ」と書いたので、みんなの者は不思議に思った。</span>
<span className="v" id="v64" data-v="64" data-xref="ルカによる福音書 1:20; 出エジプト記 4:15–16; エゼキエル書 33:22"> すると、立ちどころにザカリヤの口が開けて舌がゆるみ、語り出して神をほめたたえた。</span>
<span className="v" id="v65" data-v="65" data-xref="ルカによる福音書 1:39; 使徒行伝 5:11; ルカによる福音書 7:16"> 近所の人々はみな恐れをいだき、またユダヤの山里の至るところに、これらの事がことごとく語り伝えられたので、</span>
<span className="v" id="v66" data-v="66" data-xref="使徒行伝 11:21; ルカによる福音書 2:19; ルカによる福音書 2:51"> 聞く者たちは皆それを心に留めて、「この子は、いったい、どんな者になるだろう」と語り合った。主のみ手が彼と共にあった。</span>
<span className="v" id="v67" data-v="67" data-xref="ヨエル書 2:28; ルカによる福音書 1:41; ルカによる福音書 1:15"> <span className="pl pl-1">父ザカリヤは聖霊に満たされ、預言して言った、</span></span>
<span className="v" id="v68" data-v="68" data-xref="詩篇 106:48; ルカによる福音書 7:16; 詩篇 41:13"> <span className="pl pl-1">「主なるイスラエルの神は、ほむべきかな。</span><br /><span className="pl pl-1">神はその民を顧みてこれをあがない、</span></span>
<span className="v" id="v69" data-v="69" data-xref="詩篇 18:2; エゼキエル書 29:21; サムエル記下 22:3"> <span className="pl pl-1">わたしたちのために救の角を</span><br /><span className="pl pl-1">僕ダビデの家にお立てになった。</span></span>
<span className="v" id="v70" data-v="70" data-xref="使徒行伝 3:21–24; ローマ人への手紙 1:2; ペテロの第二の手紙 1:21"> <span className="pl pl-1">古くから、聖なる預言者たちの口によってお語りになったように、</span></span>
<span className="v" id="v71" data-v="71" data-xref="詩篇 106:10; エレミヤ書 23:6; ゼパニヤ書 3:15–20"> <span className="pl pl-1">わたしたちを敵から、またすべてわたしたちを憎む者の手から、救い出すためである。</span></span>

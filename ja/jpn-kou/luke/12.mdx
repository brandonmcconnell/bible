<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ペテロの第一の手紙 2:1; コリント人への第一の手紙 5:7–8; ヤコブの手紙 3:17"> その間に、おびただしい群衆が、互に踏み合うほどに群がってきたが、イエスはまず弟子たちに語りはじめられた、「パリサイ人のパン種、すなわち彼らの偽善に気をつけなさい。</span>
<span className="v" id="v2" data-v="2" data-xref="マルコによる福音書 4:22; ルカによる福音書 8:17; コリント人への第二の手紙 5:10"> おおいかぶされたもので、現れてこないものはなく、隠れているもので、知られてこないものはない。</span>
<span className="v" id="v3" data-v="3" data-xref="マタイによる福音書 10:27; マタイによる福音書 12:36; 伝道の書 10:20"> だから、あなたがたが暗やみで言ったことは、なんでもみな明るみで聞かれ、密室で耳にささやいたことは、屋根の上で言いひろめられるであろう。</span>
<span className="v" id="v4" data-v="4" data-xref="マタイによる福音書 10:28; エレミヤ書 1:8; ヨハネの黙示録 2:10"> そこでわたしの友であるあなたがたに言うが、からだを殺しても、そのあとでそれ以上なにもできない者どもを恐れるな。</span>
<span className="v" id="v5" data-v="5" data-xref="ペテロの第二の手紙 2:4; マタイによる福音書 10:28; ヨハネの黙示録 14:7"> 恐るべき者がだれであるか、教えてあげよう。殺したあとで、更に地獄に投げ込む権威のあるかたを恐れなさい。そうだ、あなたがたに言っておくが、そのかたを恐れなさい。</span>
<span className="v" id="v6" data-v="6" data-xref="ルカによる福音書 12:24; 詩篇 145:15–16; 詩篇 147:9"> 五羽のすずめは二アサリオンで売られているではないか。しかも、その一羽も神のみまえで忘れられてはいない。</span>
<span className="v" id="v7" data-v="7" data-xref="マタイによる福音書 10:30–31; マタイによる福音書 6:26; イザヤ書 43:3–4"> その上、あなたがたの頭の毛までも、みな数えられている。恐れることはない。あなたがたは多くのすずめよりも、まさった者である。</span>
<span className="v" id="v8" data-v="8" data-xref="マタイによる福音書 10:32–33; ヨハネの第一の手紙 2:23; ローマ人への手紙 10:9–10"> そこで、あなたがたに言う。だれでも人の前でわたしを受けいれる者を、人の子も神の使たちの前で受けいれるであろう。</span>
<span className="v" id="v9" data-v="9" data-xref="テモテヘの第二の手紙 2:12; ルカによる福音書 9:26; マルコによる福音書 8:38"> しかし、人の前でわたしを拒む者は、神の使たちの前で拒まれるであろう。</span>
<span className="v" id="v10" data-v="10" data-xref="マタイによる福音書 12:31–32; ヨハネの第一の手紙 5:16; テモテヘの第一の手紙 1:13"> また、人の子に言い逆らう者はゆるされるであろうが、聖霊をけがす者は、ゆるされることはない。</span>
<span className="v" id="v11" data-v="11" data-xref="マタイによる福音書 10:17–20; ルカによる福音書 21:12–14; 使徒行伝 4:5–7"> あなたがたが会堂や役人や高官の前へひっぱられて行った場合には、何をどう弁明しようか、何を言おうかと心配しないがよい。</span>
<span className="v" id="v12" data-v="12" data-xref="ルカによる福音書 21:15; マタイによる福音書 10:20; 使徒行伝 4:8"> 言うべきことは、聖霊がその時に教えてくださるからである」。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="ルカによる福音書 6:45; テモテヘの第一の手紙 6:5; エゼキエル書 33:31"> 群衆の中のひとりがイエスに言った、「先生、わたしの兄弟に、遺産を分けてくれるようにおっしゃってください」。</span>
<span className="v" id="v14" data-v="14" data-xref="ローマ人への手紙 2:3; ローマ人への手紙 2:1; ローマ人への手紙 9:20"> 彼に言われた、「人よ、だれがわたしをあなたがたの裁判人または分配人に立てたのか」。</span>
<span className="v" id="v15" data-v="15" data-xref="ヘブル人への手紙 13:5; テモテヘの第一の手紙 6:6–10; 詩篇 119:36–37"> それから人々にむかって言われた、「あらゆる貪欲に対してよくよく警戒しなさい。たといたくさんの物を持っていても、人のいのちは、持ち物にはよらないのである」。</span>
<span className="v" id="v16" data-v="16" data-xref="創世記 26:12–14; ホセア書 2:8; 創世記 41:47–49"> そこで一つの譬を語られた、「ある金持の畑が豊作であった。</span>
<span className="v" id="v17" data-v="17" data-xref="マタイによる福音書 5:42; イザヤ書 58:7; ローマ人への手紙 12:13"> そこで彼は心の中で、『どうしようか、わたしの作物をしまっておく所がないのだが』と思いめぐらして</span>
<span className="v" id="v18" data-v="18" data-xref="ヤコブの手紙 3:15; ヤコブの手紙 4:15; ルカによる福音書 12:21"> 言った、『こうしよう。わたしの倉を取りこわし、もっと大きいのを建てて、そこに穀物や食糧を全部しまい込もう。</span>
<span className="v" id="v19" data-v="19" data-xref="箴言 27:1; ヤコブの手紙 4:13–15; コリント人への第一の手紙 15:32"> そして自分の魂に言おう。たましいよ、おまえには長年分の食糧がたくさんたくわえてある。さあ安心せよ、食え、飲め、楽しめ』。</span>
<span className="v" id="v20" data-v="20" data-xref="ヨブ記 27:8; エレミヤ書 17:11; テモテヘの第一の手紙 6:7"> すると神が彼に言われた、『愚かな者よ、あなたの魂は今夜のうちにも取り去られるであろう。そしたら、あなたが用意した物は、だれのものになるのか』。</span>
<span className="v" id="v21" data-v="21" data-xref="マタイによる福音書 6:19–20; ルカによる福音書 12:33; ヤコブの手紙 2:5"> 自分のために宝を積んで神に対して富まない者は、これと同じである」。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="マタイによる福音書 6:25–34; ピリピ人への手紙 4:6; ヘブル人への手紙 13:5"> それから弟子たちに言われた、「それだから、あなたがたに言っておく。何を食べようかと、命のことで思いわずらい、何を着ようかとからだのことで思いわずらうな。</span>
<span className="v" id="v23" data-v="23" data-xref="ヨブ記 2:6; 箴言 13:8; ヨブ記 2:4"> 命は食物にまさり、からだは着物にまさっている。</span>
<span className="v" id="v24" data-v="24" data-xref="マタイによる福音書 10:31; 詩篇 147:9; ルカによる福音書 12:7"> からすのことを考えて見よ。まくことも、刈ることもせず、また、納屋もなく倉もない。それだのに、神は彼らを養っていて下さる。あなたがたは鳥よりも、はるかにすぐれているではないか。</span>
<span className="v" id="v25" data-v="25" data-xref="マタイによる福音書 6:27; マタイによる福音書 5:36; ルカによる福音書 19:3"> あなたがたのうち、だれが思いわずらったからとて、自分の寿命をわずかでも延ばすことができようか。</span>
<span className="v" id="v26" data-v="26" data-xref="ペテロの第一の手紙 5:7; 詩篇 39:6; 伝道の書 7:13"> そんな小さな事さえできないのに、どうしてほかのことを思いわずらうのか。</span>
<span className="v" id="v27" data-v="27" data-xref="マタイによる福音書 6:28–30; ルカによる福音書 12:24; 列王紀上 10:1–13"> 野の花のことを考えて見るがよい。紡ぎもせず、織りもしない。しかし、あなたがたに言うが、栄華をきわめた時のソロモンでさえ、この花の一つほどにも着飾ってはいなかった。</span>
<span className="v" id="v28" data-v="28" data-xref="マタイによる福音書 14:31; イザヤ書 40:6; マタイによる福音書 6:30"> きょうは野にあって、あすは炉に投げ入れられる草でさえ、神はこのように装って下さるのなら、あなたがたに、それ以上よくしてくださらないはずがあろうか。ああ、信仰の薄い者たちよ。</span>
<span className="v" id="v29" data-v="29" data-xref="マタイによる福音書 6:31; ルカによる福音書 12:22; ルカによる福音書 22:35"> あなたがたも、何を食べ、何を飲もうかと、あくせくするな、また気を使うな。</span>
<span className="v" id="v30" data-v="30" data-xref="マタイによる福音書 6:32; マタイによる福音書 6:8; エペソ人への手紙 4:17"> これらのものは皆、この世の異邦人が切に求めているものである。あなたがたの父は、これらのものがあなたがたに必要であることを、ご存じである。</span>
<span className="v" id="v31" data-v="31" data-xref="マタイによる福音書 6:33; ヘブル人への手紙 13:5; 詩篇 34:9"> ただ、御国を求めなさい。そうすれば、これらのものは添えて与えられるであろう。</span>
<span className="v" id="v32" data-v="32" data-xref="ヘブル人への手紙 12:28; ペテロの第一の手紙 1:3–5; ヨハネの黙示録 1:6"> 恐れるな、小さい群れよ。御国を下さることは、あなたがたの父のみこころなのである。</span>
<span className="v" id="v33" data-v="33" data-xref="マタイによる福音書 19:21; 使徒行伝 4:34–35; 使徒行伝 2:45"> 自分の持ち物を売って、施しなさい。自分のために古びることのない財布をつくり、盗人も近寄らず、虫も食い破らない天に、尽きることのない宝をたくわえなさい。</span>
<span className="v" id="v34" data-v="34" data-xref="コロサイ人への手紙 3:1–3; マタイによる福音書 6:21; ピリピ人への手紙 3:20"> あなたがたの宝のある所には、心もあるからである。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="ペテロの第一の手紙 1:13; エペソ人への手紙 6:14; マタイによる福音書 25:4–10"> 腰に帯をしめ、あかりをともしていなさい。</span>
<span className="v" id="v36" data-v="36" data-xref="ユダの手紙 1:20–21; ヤコブの手紙 5:7–8; ヨハネの黙示録 3:20"> 主人が婚宴から帰ってきて戸をたたくとき、すぐあけてあげようと待っている人のようにしていなさい。</span>
<span className="v" id="v37" data-v="37" data-xref="ペテロの第二の手紙 3:14; マタイによる福音書 24:42; ヨハネによる福音書 13:4–5"> 主人が帰ってきたとき、目を覚しているのを見られる僕たちは、さいわいである。よく言っておく。主人が帯をしめて僕たちを食卓につかせ、進み寄って給仕をしてくれるであろう。</span>
<span className="v" id="v38" data-v="38" data-xref="テサロニケ人への第一の手紙 5:4–5; マタイによる福音書 25:6"> 主人が夜中ごろ、あるいは夜明けごろに帰ってきても、そうしているのを見られるなら、その人たちはさいわいである。</span>
<span className="v" id="v39" data-v="39" data-xref="ペテロの第二の手紙 3:10; ヨハネの黙示録 3:3; ヨハネの黙示録 16:15"> このことを、わきまえているがよい。家の主人は、盗賊がいつごろ来るかわかっているなら、自分の家に押し入らせはしないであろう。</span>
<span className="v" id="v40" data-v="40" data-xref="テサロニケ人への第一の手紙 5:6; マタイによる福音書 25:13; ローマ人への手紙 13:11"> あなたがたも用意していなさい。思いがけない時に人の子が来るからである」。</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="マルコによる福音書 13:37; ペテロの第一の手紙 4:7; ペテロの第一の手紙 5:8"> するとペテロが言った、「主よ、この譬を話しておられるのはわたしたちのためなのですか。それとも、みんなの者のためなのですか」。</span>
<span className="v" id="v42" data-v="42" data-xref="マタイによる福音書 24:45–46; ペテロの第一の手紙 5:1–4; ヘブル人への手紙 13:17"> そこで主が言われた、「主人が、召使たちの上に立てて、時に応じて定めの食事をそなえさせる忠実な思慮深い家令は、いったいだれであろう。</span>
<span className="v" id="v43" data-v="43"> 主人が帰ってきたとき、そのようにつとめているのを見られる僕は、さいわいである。</span>
<span className="v" id="v44" data-v="44" data-xref="ルカによる福音書 22:29–30; マタイによる福音書 24:47; ルカによる福音書 19:17–19"> よく言っておくが、主人はその僕を立てて自分の全財産を管理させるであろう。</span>
<span className="v" id="v45" data-v="45" data-xref="マタイによる福音書 24:48–50; ヨハネの黙示録 18:7–8; ピリピ人への手紙 3:18–19"> しかし、もしその僕が、主人の帰りがおそいと心の中で思い、男女の召使たちを打ちたたき、そして食べたり、飲んだりして酔いはじめるならば、</span>
<span className="v" id="v46" data-v="46" data-xref="ルカによる福音書 12:40; マタイによる福音書 24:51; 詩篇 11:5"> その僕の主人は思いがけない日、気がつかない時に帰って来るであろう。そして、彼を厳罰に処して、不忠実なものたちと同じ目にあわせるであろう。</span>
<span className="v" id="v47" data-v="47" data-xref="ヤコブの手紙 4:17; ヨハネによる福音書 9:41; ヨハネによる福音書 12:48"> 主人のこころを知っていながら、それに従って用意もせず勤めもしなかった僕は、多くむち打たれるであろう。</span>
<span className="v" id="v48" data-v="48" data-xref="ヤコブの手紙 3:1; レビ記 5:17; ルカによる福音書 16:10–12"> しかし、知らずに打たれるようなことをした者は、打たれ方が少ないだろう。多く与えられた者からは多く求められ、多く任せられた者からは更に多く要求されるのである。</span>
</div>
<div className="bp">
<span className="v" id="v49" data-v="49" data-xref="マラキ書 4:1; ルカによる福音書 12:51–52; マタイによる福音書 3:10–12"> わたしは、火を地上に投じるためにきたのだ。火がすでに燃えていたならと、わたしはどんなに願っていることか。</span>
<span className="v" id="v50" data-v="50" data-xref="ヨハネによる福音書 12:27–28; ヨハネによる福音書 19:30; ヨハネによる福音書 7:6–8"> しかし、わたしには受けねばならないバプテスマがある。そして、それを受けてしまうまでは、わたしはどんなにか苦しい思いをすることであろう。</span>
<span className="v" id="v51" data-v="51" data-xref="マタイによる福音書 10:34–36; ルカによる福音書 12:49; マタイによる福音書 24:7–10"> あなたがたは、わたしが平和をこの地上にもたらすためにきたと思っているのか。あなたがたに言っておく。そうではない。むしろ分裂である。</span>
<span className="v" id="v52" data-v="52" data-xref="使徒行伝 14:1–4; ヨハネによる福音書 15:18–21; ミカ書 7:5–6"> というのは、今から後は、一家の内で五人が相分れて、三人はふたりに、ふたりは三人に対立し、</span>
<span className="v" id="v53" data-v="53" data-xref="ミカ書 7:6; マタイによる福音書 10:21–22; マタイによる福音書 24:10"> また父は子に、子は父に、母は娘に、娘は母に、しゅうとめは嫁に、嫁はしゅうとめに、対立するであろう」。</span>
</div>
<div className="bp">
<span className="v" id="v54" data-v="54" data-xref="マタイによる福音書 16:2–4; 列王紀上 18:44–45"> イエスはまた群衆に対しても言われた、「あなたがたは、雲が西に起るのを見るとすぐ、にわか雨がやって来る、と言う。果してそのとおりになる。</span>
<span className="v" id="v55" data-v="55" data-xref="ヨブ記 37:17; マタイによる福音書 20:12"> それから南風が吹くと、暑つくなるだろう、と言う。果してそのとおりになる。</span>
<span className="v" id="v56" data-v="56" data-xref="マタイによる福音書 16:3; マタイによる福音書 24:32–33; マタイによる福音書 11:25"> 偽善者よ、あなたがたは天地の模様を見分けることを知りながら、どうして今の時代を見分けることができないのか。</span>
<span className="v" id="v57" data-v="57" data-xref="申命記 32:29; ヨハネによる福音書 7:24; 使徒行伝 13:26–38"> また、あなたがたは、なぜ正しいことを自分で判断しないのか。</span>
<span className="v" id="v58" data-v="58" data-xref="箴言 25:8–9; マタイによる福音書 5:23–26; ルカによる福音書 13:24–28"> たとえば、あなたを訴える人と一緒に役人のところへ行くときには、途中でその人と和解するように努めるがよい。そうしないと、その人はあなたを裁判官のところへひっぱって行き、裁判官はあなたを獄吏に引き渡し、獄吏はあなたを獄に投げ込むであろう。</span>
<span className="v" id="v59" data-v="59" data-xref="マルコによる福音書 12:42; マタイによる福音書 18:34; マタイによる福音書 25:46"> わたしは言って置く、最後の一レプタまでも支払ってしまうまでは、決してそこから出て来ることはできない」。</span>
</div>

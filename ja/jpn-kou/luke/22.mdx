<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出エジプト記 12:6–23; マタイによる福音書 26:2–5; ヨハネによる福音書 11:55–57"> さて、過越といわれている除酵祭が近づいた。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネによる福音書 11:47–53; マタイによる福音書 12:14; ルカによる福音書 20:19"> 祭司長たちや律法学者たちは、どうかしてイエスを殺そうと計っていた。民衆を恐れていたからである。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="ヨハネによる福音書 13:2; マルコによる福音書 14:10–11; ヨハネによる福音書 13:26–27"> そのとき、十二弟子のひとりで、イスカリオテと呼ばれていたユダに、サタンがはいった。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行伝 4:1; 使徒行伝 5:24; ルカによる福音書 22:52"> すなわち、彼は祭司長たちや宮守がしらたちのところへ行って、どうしてイエスを彼らに渡そうかと、その方法について協議した。</span>
<span className="v" id="v5" data-v="5" data-xref="マタイによる福音書 26:15–16; 使徒行伝 1:18; マタイによる福音書 27:3–5"> 彼らは喜んで、ユダに金を与える取決めをした。</span>
<span className="v" id="v6" data-v="6" data-xref="マルコによる福音書 14:2; マタイによる福音書 26:5"> ユダはそれを承諾した。そして、群衆のいないときにイエスを引き渡そうと、機会をねらっていた。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="出エジプト記 12:18; マルコによる福音書 14:12–16; コリント人への第一の手紙 5:7"> さて、過越の小羊をほふるべき除酵祭の日がきたので、</span>
<span className="v" id="v8" data-v="8" data-xref="マルコによる福音書 14:13–16; 使徒行伝 4:19; 使徒行伝 4:13"> イエスはペテロとヨハネとを使いに出して言われた、「行って、過越の食事ができるように準備をしなさい」。</span>
<span className="v" id="v9" data-v="9"> 彼らは言った、「どこに準備をしたらよいのですか」。</span>
<span className="v" id="v10" data-v="10" data-xref="ヨハネによる福音書 16:4; マタイによる福音書 26:18–19; 使徒行伝 8:26–29"> イエスは言われた、「市内にはいったら、水がめを持っている男に出会うであろう。その人がはいる家までついて行って、</span>
<span className="v" id="v11" data-v="11" data-xref="ヨハネによる福音書 11:28; ヨハネの黙示録 3:20; ルカによる福音書 19:34"> その家の主人に言いなさい、『弟子たちと一緒に過越の食事をする座敷はどこか、と先生が言っておられます』。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行伝 16:14–15; 使徒行伝 1:13; ヨハネによる福音書 2:25"> すると、その主人は席の整えられた二階の広間を見せてくれるから、そこに用意をしなさい」。</span>
<span className="v" id="v13" data-v="13" data-xref="ルカによる福音書 21:33; ルカによる福音書 19:32; ヨハネによる福音書 2:5"> 弟子たちは出て行ってみると、イエスが言われたとおりであったので、過越の食事の用意をした。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="マタイによる福音書 26:20; マルコによる福音書 14:17; 申命記 16:6–7"> 時間になったので、イエスは食卓につかれ、使徒たちも共に席についた。</span>
<span className="v" id="v15" data-v="15" data-xref="ルカによる福音書 12:50; ヨハネによる福音書 4:34; ヨハネによる福音書 17:1"> イエスは彼らに言われた、「わたしは苦しみを受ける前に、あなたがたとこの過越の食事をしようと、切に望んでいた。</span>
<span className="v" id="v16" data-v="16" data-xref="ルカによる福音書 14:15; ヨハネの黙示録 19:9; ルカによる福音書 22:30"> あなたがたに言って置くが、神の国で過越が成就する時までは、わたしは二度と、この過越の食事をすることはない」。</span>
<span className="v" id="v17" data-v="17" data-xref="ルカによる福音書 22:19; 詩篇 116:13; 申命記 8:10"> そして杯を取り、感謝して言われた、「これを取って、互に分けて飲め。</span>
<span className="v" id="v18" data-v="18" data-xref="マタイによる福音書 26:29; ルカによる福音書 22:16; マルコによる福音書 14:25"> あなたがたに言っておくが、今からのち神の国が来るまでは、わたしはぶどうの実から造ったものを、いっさい飲まない」。</span>
<span className="v" id="v19" data-v="19" data-xref="コリント人への第一の手紙 11:23–29; コリント人への第一の手紙 10:16; マルコによる福音書 14:22–24"> またパンを取り、感謝してこれをさき、弟子たちに与えて言われた、「これは、あなたがたのために与えるわたしのからだである。わたしを記念するため、このように行いなさい」。</span>
<span className="v" id="v20" data-v="20" data-xref="マタイによる福音書 26:28; コリント人への第一の手紙 11:25; ゼカリヤ書 9:11"> 食事ののち、杯も同じ様にして言われた、「この杯は、あなたがたのために流すわたしの血で立てられる新しい契約である。</span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 41:9; ヨハネによる福音書 13:26; ヨハネによる福音書 13:21–22"> しかし、そこに、わたしを裏切る者が、わたしと一緒に食卓に手を置いている。</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行伝 2:23; 詩篇 109:6–15; 詩篇 55:12–15"> 人の子は定められたとおりに、去って行く。しかし人の子を裏切るその人は、わざわいである」。</span>
<span className="v" id="v23" data-v="23" data-xref="ヨハネによる福音書 13:22–25; マルコによる福音書 14:19; マタイによる福音書 26:22"> 弟子たちは、自分たちのうちのだれが、そんな事をしようとしているのだろうと、互に論じはじめた。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="ルカによる福音書 9:46; マルコによる福音書 9:34; マルコによる福音書 10:37–41"> それから、自分たちの中でだれがいちばん偉いだろうかと言って、争論が彼らの間に、起った。</span>
<span className="v" id="v25" data-v="25" data-xref="マタイによる福音書 20:25–28; マルコによる福音書 10:41–45"> そこでイエスが言われた、「異邦の王たちはその民の上に君臨し、また、権力をふるっている者たちは恩人と呼ばれる。</span>
<span className="v" id="v26" data-v="26" data-xref="ペテロの第一の手紙 5:5; ルカによる福音書 9:48; マタイによる福音書 18:3–5"> しかし、あなたがたは、そうであってはならない。かえって、あなたがたの中でいちばん偉い人はいちばん若い者のように、指導する人は仕える者のようになるべきである。</span>
<span className="v" id="v27" data-v="27" data-xref="マタイによる福音書 20:28; ルカによる福音書 12:37; ヨハネによる福音書 13:5–16"> 食卓につく人と給仕する者と、どちらが偉いのか。食卓につく人の方ではないか。しかし、わたしはあなたがたの中で、給仕をする者のようにしている。</span>
<span className="v" id="v28" data-v="28" data-xref="ヘブル人への手紙 2:18; ヘブル人への手紙 4:15; 使徒行伝 1:25"> あなたがたは、わたしの試錬のあいだ、わたしと一緒に最後まで忍んでくれた人たちである。</span>
<span className="v" id="v29" data-v="29" data-xref="マタイによる福音書 25:34; テモテヘの第二の手紙 2:12; ヤコブの手紙 2:5"> それで、わたしの父が国の支配をわたしにゆだねてくださったように、わたしもそれをあなたがたにゆだね、</span>
<span className="v" id="v30" data-v="30" data-xref="マタイによる福音書 19:28; マタイによる福音書 8:11; ヨハネの黙示録 2:26–27"> わたしの国で食卓について飲み食いをさせ、また位に座してイスラエルの十二の部族をさばかせるであろう。</span>
<span className="v" id="v31" data-v="31" data-xref="ペテロの第一の手紙 5:8; ゼカリヤ書 3:1; ヨブ記 1:6–12"> シモン、シモン、見よ、サタンはあなたがたを麦のようにふるいにかけることを願って許された。</span>
<span className="v" id="v32" data-v="32" data-xref="ペテロの第一の手紙 5:8–10; ヨハネによる福音書 21:15–17; ヨハネによる福音書 17:9–11"> しかし、わたしはあなたの信仰がなくならないように、あなたのために祈った。それで、あなたが立ち直ったときには、兄弟たちを力づけてやりなさい」。</span>
<span className="v" id="v33" data-v="33" data-xref="マルコによる福音書 14:31; マタイによる福音書 26:33–35; マルコによる福音書 14:29"> シモンが言った、「主よ、わたしは獄にでも、また死に至るまでも、あなたとご一緒に行く覚悟です」。</span>
<span className="v" id="v34" data-v="34" data-xref="ヨハネによる福音書 13:38; マタイによる福音書 26:34; マルコによる福音書 14:30"> するとイエスが言われた、「ペテロよ、あなたに言っておく。きょう、鶏が鳴くまでに、あなたは三度わたしを知らないと言うだろう」。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="マタイによる福音書 10:9–10; ルカによる福音書 10:4; 詩篇 23:1"> そして彼らに言われた、「わたしが財布も袋もくつも持たせずにあなたがたをつかわしたとき、何かこまったことがあったか」。彼らは、「いいえ、何もありませんでした」と答えた。</span>
<span className="v" id="v36" data-v="36" data-xref="マタイによる福音書 10:22–25; テサロニケ人への第一の手紙 3:4; テサロニケ人への第一の手紙 2:14–15"> そこで言われた、「しかし今は、財布のあるものは、それを持って行け。袋も同様に持って行け。また、つるぎのない者は、自分の上着を売って、それを買うがよい。</span>
<span className="v" id="v37" data-v="37" data-xref="イザヤ書 53:12; ルカによる福音書 23:32; コリント人への第二の手紙 5:21"> あなたがたに言うが、『彼は罪人のひとりに数えられた』としるしてあることは、わたしの身に成しとげられねばならない。そうだ、わたしに係わることは成就している」。</span>
<span className="v" id="v38" data-v="38" data-xref="ルカによる福音書 22:49; マタイによる福音書 26:52–54; ヨハネによる福音書 18:36"> 弟子たちが言った、「主よ、ごらんなさい、ここにつるぎが二振りございます」。イエスは言われた、「それでよい」。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="ルカによる福音書 21:37; ヨハネによる福音書 18:1–2; マタイによる福音書 21:1"> イエスは出て、いつものようにオリブ山に行かれると、弟子たちも従って行った。</span>
<span className="v" id="v40" data-v="40" data-xref="マタイによる福音書 6:13; マタイによる福音書 26:36–46; ルカによる福音書 22:46"> いつもの場所に着いてから、彼らに言われた、「誘惑に陥らないように祈りなさい」。</span>
<span className="v" id="v41" data-v="41" data-xref="マタイによる福音書 26:39; マルコによる福音書 14:35; ルカによる福音書 18:11"> そしてご自分は、石を投げてとどくほど離れたところへ退き、ひざまずいて、祈って言われた、</span>
<span className="v" id="v42" data-v="42" data-xref="ヨハネによる福音書 12:27–28; マタイによる福音書 26:39; マタイによる福音書 26:42"> 「父よ、みこころならば、どうぞ、この杯をわたしから取りのけてください。しかし、わたしの思いではなく、みこころが成るようにしてください」。</span>
<span className="v" id="v43" data-v="43" data-xref="マタイによる福音書 4:11; マタイによる福音書 26:53; 詩篇 91:11–12"> そのとき、御使が天からあらわれてイエスを力づけた。</span>
<span className="v" id="v44" data-v="44" data-xref="哀歌 1:12; ヘブル人への手紙 5:7; 詩篇 22:12–21"> イエスは苦しみもだえて、ますます切に祈られた。そして、その汗が血のしたたりのように地に落ちた。</span>
<span className="v" id="v45" data-v="45" data-xref="マルコによる福音書 14:40–41; マタイによる福音書 26:43; マタイによる福音書 26:40"> 祈を終えて立ちあがり、弟子たちのところへ行かれると、彼らが悲しみのはて寝入っているのをごらんになって</span>
<span className="v" id="v46" data-v="46" data-xref="ルカによる福音書 22:40; ヨナ書 1:6; ルカによる福音書 21:34–36"> 言われた、「なぜ眠っているのか。誘惑に陥らないように、起きて祈っていなさい」。</span>
</div>
<div className="bp">
<span className="v" id="v47" data-v="47" data-xref="マルコによる福音書 14:41–50; ヨハネによる福音書 18:2–11; ルカによる福音書 22:3–6"> イエスがまだそう言っておられるうちに、そこに群衆が現れ、十二弟子のひとりでユダという者が先頭に立って、イエスに接吻しようとして近づいてきた。</span>
<span className="v" id="v48" data-v="48" data-xref="マルコによる福音書 14:44–46; サムエル記下 20:9–10; 箴言 27:6"> そこでイエスは言われた、「ユダ、あなたは接吻をもって人の子を裏切るのか」。</span>
<span className="v" id="v49" data-v="49" data-xref="ルカによる福音書 22:38"> イエスのそばにいた人たちは、事のなりゆきを見て、「主よ、つるぎで切りつけてやりましょうか」と言って、</span>
<span className="v" id="v50" data-v="50" data-xref="ヨハネによる福音書 18:10–11; マルコによる福音書 14:47; ローマ人への手紙 12:19"> そのうちのひとりが、祭司長の僕に切りつけ、その右の耳を切り落した。</span>
<span className="v" id="v51" data-v="51" data-xref="ローマ人への手紙 12:21; コリント人への第二の手紙 10:1; ペテロの第一の手紙 2:21–23"> イエスはこれに対して言われた、「それだけでやめなさい」。そして、その僕の耳に手を触て、おいやしになった。</span>
<span className="v" id="v52" data-v="52" data-xref="ルカによる福音書 22:4; マルコによる福音書 14:48–49; ヨハネによる福音書 17:12"> それから、自分にむかって来る祭司長、宮守がしら、長老たちに対して言われた、「あなたがたは、強盗にむかうように剣や棒を持って出てきたのか。</span>
<span className="v" id="v53" data-v="53" data-xref="ヨハネによる福音書 12:27; エペソ人への手紙 6:12; 使徒行伝 26:18"> 毎日あなたがたと一緒に宮にいた時には、わたしに手をかけなかった。だが、今はあなたがたの時、また、やみの支配の時である」。</span>
</div>
<div className="bp">
<span className="v" id="v54" data-v="54" data-xref="マルコによる福音書 14:53–54; マタイによる福音書 26:57–58; ヨハネによる福音書 18:12–17"> それから人々はイエスを捕え、ひっぱって大祭司の邸宅へつれて行った。ペテロは遠くからついて行った。</span>
<span className="v" id="v55" data-v="55" data-xref="詩篇 26:4–5; コリント人への第二の手紙 6:15–17; マルコによる福音書 14:66–72"> 人々は中庭のまん中に火をたいて、一緒にすわっていたので、ペテロもその中にすわった。</span>
<span className="v" id="v56" data-v="56" data-xref="ヨハネによる福音書 18:17; マルコによる福音書 14:6; マルコによる福音書 14:17"> すると、ある女中が、彼が火のそばにすわっているのを見、彼を見つめて、「この人もイエスと一緒にいました」と言った。</span>
<span className="v" id="v57" data-v="57" data-xref="ヨハネの第一の手紙 1:9; ヨハネによる福音書 18:25; マタイによる福音書 26:70"> ペテロはそれを打ち消して、「わたしはその人を知らない」と言った。</span>
<span className="v" id="v58" data-v="58" data-xref="ヨハネによる福音書 18:25; マタイによる福音書 26:71–72; マルコによる福音書 14:69–70"> しばらくして、ほかの人がペテロを見て言った、「あなたもあの仲間のひとりだ」。するとペテロは言った、「いや、それはちがう」。</span>
<span className="v" id="v59" data-v="59" data-xref="ヨハネによる福音書 18:26–27; マルコによる福音書 14:69–70; マタイによる福音書 26:73–74"> 約一時間たってから、またほかの者が言い張った、「たしかにこの人もイエスと一緒だった。この人もガリラヤ人なのだから」。</span>
<span className="v" id="v60" data-v="60" data-xref="マタイによる福音書 26:74–75; ルカによる福音書 22:34; マルコによる福音書 14:71–72"> ペテロは言った、「あなたの言っていることは、わたしにわからない」。すると、彼がまだ言い終らぬうちに、たちまち、鶏が鳴いた。</span>
<span className="v" id="v61" data-v="61" data-xref="ルカによる福音書 22:34; イザヤ書 57:15–18; エレミヤ書 31:18–20"> 主は振りむいてペテロを見つめられた。そのときペテロは、「きょう、鶏が鳴く前に、三度わたしを知らないと言うであろう」と言われた主のお言葉を思い出した。</span>
<span className="v" id="v62" data-v="62" data-xref="マタイによる福音書 26:75; コリント人への第一の手紙 10:12; マルコによる福音書 14:72"> そして外へ出て、激しく泣いた。</span>
</div>
<div className="bp">
<span className="v" id="v63" data-v="63" data-xref="ヨハネによる福音書 18:22; マルコによる福音書 14:55–65; ヨブ記 16:9–10"> イエスを監視していた人たちは、イエスを嘲弄し、打ちたたき、</span>
<span className="v" id="v64" data-v="64" data-xref="士師記 16:25; 士師記 16:21"> 目かくしをして、「言いあててみよ。打ったのは、だれか」ときいたりした。</span>
<span className="v" id="v65" data-v="65" data-xref="ルカによる福音書 12:10; マタイによる福音書 12:31–32; マタイによる福音書 27:39"> そのほか、いろいろな事を言って、イエスを愚弄した。</span>

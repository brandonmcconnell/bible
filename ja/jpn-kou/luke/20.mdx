<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マタイによる福音書 21:23–27; ルカによる福音書 19:47–48; 使徒行伝 6:12"> ある日、イエスが宮で人々に教え、福音を宣べておられると、祭司長や律法学者たちが、長老たちと共に近寄ってきて、</span>
<span className="v" id="v2" data-v="2" data-xref="出エジプト記 2:14; マルコによる福音書 11:28–33; ヨハネによる福音書 2:18"> イエスに言った、「何の権威によってこれらの事をするのですか。そうする権威をあなたに与えたのはだれですか、わたしたちに言ってください」。</span>
<span className="v" id="v3" data-v="3" data-xref="マタイによる福音書 15:2–3; ルカによる福音書 22:68; コロサイ人への手紙 4:6"> そこで、イエスは答えて言われた、「わたしも、ひと言たずねよう。それに答えてほしい。</span>
<span className="v" id="v4" data-v="4" data-xref="ルカによる福音書 15:18; マタイによる福音書 11:7–19; マタイによる福音書 17:11–12"> ヨハネのバプテスマは、天からであったか、人からであったか」。</span>
<span className="v" id="v5" data-v="5" data-xref="ヨハネによる福音書 1:34; ヨハネによる福音書 1:15–18; ヨハネによる福音書 1:30"> 彼らは互に論じて言った、「もし天からだと言えば、では、なぜ彼を信じなかったのか、とイエスは言うだろう。</span>
<span className="v" id="v6" data-v="6" data-xref="マタイによる福音書 21:26; マタイによる福音書 11:9; ヨハネによる福音書 10:41"> しかし、もし人からだと言えば、民衆はみな、ヨハネを預言者だと信じているから、わたしたちを石で打つだろう」。</span>
<span className="v" id="v7" data-v="7" data-xref="イザヤ書 29:14; ペテロの第二の手紙 3:3; イザヤ書 41:28"> それで彼らは「どこからか、知りません」と答えた。</span>
<span className="v" id="v8" data-v="8" data-xref="箴言 26:4–5; マタイによる福音書 21:27; マルコによる福音書 11:33"> イエスはこれに対して言われた、「わたしも何の権威によってこれらの事をするのか、あなたがたに言うまい」。</span>
</div>
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="マタイによる福音書 21:33–46; マルコによる福音書 12:1–12; イザヤ書 5:1–7"> そこでイエスは次の譬を民衆に語り出された、「ある人がぶどう園を造って農夫たちに貸し、長い旅に出た。</span>
<span className="v" id="v10" data-v="10" data-xref="歴代志下 36:15–16; ネヘミヤ書 9:26; マタイによる福音書 21:34–36"> 季節になったので、農夫たちのところへ、ひとりの僕を送って、ぶどう園の収穫の分け前を出させようとした。ところが、農夫たちは、その僕を袋だたきにし、から手で帰らせた。</span>
<span className="v" id="v11" data-v="11" data-xref="ホセア書 10:1; ヘブル人への手紙 11:36–37; テサロニケ人への第一の手紙 2:2"> そこで彼はもうひとりの僕を送った。彼らはその僕も袋だたきにし、侮辱を加えて、から手で帰らせた。</span>
<span className="v" id="v12" data-v="12"> そこで更に三人目の者を送ったが、彼らはこの者も、傷を負わせて追い出した。</span>
<span className="v" id="v13" data-v="13" data-xref="マタイによる福音書 3:17; ヨハネによる福音書 3:16–17; エレミヤ書 36:7"> ぶどう園の主人は言った、『どうしようか。そうだ、わたしの愛子をつかわそう。これなら、たぶん敬ってくれるだろう』。</span>
<span className="v" id="v14" data-v="14" data-xref="ローマ人への手紙 8:17; ヘブル人への手紙 1:2; 使徒行伝 2:23"> ところが、農夫たちは彼を見ると、『あれはあと取りだ。あれを殺してしまおう。そうしたら、その財産はわれわれのものになるのだ』と互に話し合い、</span>
<span className="v" id="v15" data-v="15" data-xref="ヘブル人への手紙 13:12; マルコによる福音書 12:6–9; マタイによる福音書 21:37–40"> 彼をぶどう園の外に追い出して殺した。そのさい、ぶどう園の主人は、彼らをどうするだろうか。</span>
<span className="v" id="v16" data-v="16" data-xref="ルカによる福音書 19:27; 使徒行伝 13:46; マタイによる福音書 21:41"> 彼は出てきて、この農夫たちを殺し、ぶどう園を他の人々に与えるであろう」。人々はこれを聞いて、「そんなことがあってはなりません」と言った。</span>
<span className="v" id="v17" data-v="17" data-xref="詩篇 118:22; イザヤ書 28:16; 使徒行伝 4:11"> そこで、イエスは彼らを見つめて言われた、「それでは、<br /><span className="pl pl-1">『家造りらの捨てた石が</span><br /><span className="pl pl-1">隅のかしら石になった』</span><br />と書いてあるのは、どういうことか。</span>
<span className="v" id="v18" data-v="18" data-xref="イザヤ書 8:14–15; ゼカリヤ書 12:3; ダニエル書 2:44–45"> すべてその石の上に落ちる者は打ち砕かれ、それがだれかの上に落ちかかるなら、その人はこなみじんにされるであろう」。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="ルカによる福音書 19:47–48; ルカによる福音書 20:14; マタイによる福音書 21:45–46"> このとき、律法学者たちや祭司長たちはイエスに手をかけようと思ったが、民衆を恐れた。いまの譬が自分たちに当てて語られたのだと、悟ったからである。</span>
<span className="v" id="v20" data-v="20" data-xref="ルカによる福音書 11:54; マタイによる福音書 22:15–22; マタイによる福音書 27:2"> そこで、彼らは機会をうかがい、義人を装うまわし者どもを送って、イエスを総督の支配と権威とに引き渡すため、その言葉じりを捕えさせようとした。</span>
<span className="v" id="v21" data-v="21" data-xref="テサロニケ人への第一の手紙 2:4–5; マタイによる福音書 26:49–50; マタイによる福音書 22:16"> 彼らは尋ねて言った、「先生、わたしたちは、あなたの語り教えられることが正しく、また、あなたは分け隔てをなさらず、真理に基いて神の道を教えておられることを、承知しています。</span>
<span className="v" id="v22" data-v="22" data-xref="ネヘミヤ書 9:37; マルコによる福音書 12:14–17; 使徒行伝 5:37"> ところで、カイザルに貢を納めてよいでしょうか、いけないでしょうか」。</span>
<span className="v" id="v23" data-v="23" data-xref="マタイによる福音書 22:18; コリント人への第一の手紙 3:19; ルカによる福音書 5:22"> イエスは彼らの悪巧みを見破って言われた、</span>
<span className="v" id="v24" data-v="24" data-xref="マタイによる福音書 18:28; 使徒行伝 11:28; 使徒行伝 26:32"> 「デナリを見せなさい。それにあるのは、だれの肖像、だれの記号なのか」。「カイザルのです」と、彼らが答えた。</span>
<span className="v" id="v25" data-v="25" data-xref="ローマ人への手紙 13:6–7; マルコによる福音書 12:17; ペテロの第一の手紙 2:13–17"> するとイエスは彼らに言われた、「それなら、カイザルのものはカイザルに、神のものは神に返しなさい」。</span>
<span className="v" id="v26" data-v="26" data-xref="ルカによる福音書 20:20; 箴言 26:4–5; テトスヘの手紙 1:10"> そこで彼らは、民衆の前でイエスの言葉じりを捕えることができず、その答に驚嘆して、黙ってしまった。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="使徒行伝 4:1–2; コリント人への第一の手紙 15:12; マルコによる福音書 12:18–27"> 復活ということはないと言い張っていたサドカイ人のある者たちが、イエスに近寄ってきて質問した、</span>
<span className="v" id="v28" data-v="28" data-xref="申命記 25:5–10; 創世記 38:8; 創世記 38:11"> 「先生、モーセは、わたしたちのためにこう書いています、『もしある人の兄が妻をめとり、子がなくて死んだなら、弟はこの女をめとって、兄のために子をもうけねばならない』。</span>
<span className="v" id="v29" data-v="29" data-xref="レビ記 20:20; エレミヤ書 22:30"> ところで、ここに七人の兄弟がいました。長男は妻をめとりましたが、子がなくて死に、</span>
<span className="v" id="v30" data-v="30"> そして次男、三男と、次々に、その女をめとり、</span>
<span className="v" id="v31" data-v="31"> 七人とも同様に、子をもうけずに死にました。</span>
<span className="v" id="v32" data-v="32" data-xref="伝道の書 1:4; 伝道の書 9:5; ヘブル人への手紙 9:27"> のちに、その女も死にました。</span>
<span className="v" id="v33" data-v="33" data-xref="マタイによる福音書 22:24–28; マルコによる福音書 12:19–23"> さて、復活の時には、この女は七人のうち、だれの妻になるのですか。七人とも彼女を妻にしたのですが」。</span>
<span className="v" id="v34" data-v="34" data-xref="ルカによる福音書 16:8; ルカによる福音書 17:27; ヘブル人への手紙 13:4"> イエスは彼らに言われた、「この世の子らは、めとったり、とついだりするが、</span>
<span className="v" id="v35" data-v="35" data-xref="テサロニケ人への第二の手紙 1:5; ヨハネによる福音書 5:29; ダニエル書 12:2–3"> かの世にはいって死人からの復活にあずかるにふさわしい者たちは、めとったり、とついだりすることはない。</span>
<span className="v" id="v36" data-v="36" data-xref="ヨハネの黙示録 21:4; ピリピ人への手紙 3:21; マタイによる福音書 22:30"> 彼らは天使に等しいものであり、また復活にあずかるゆえに、神の子でもあるので、もう死ぬことはあり得ないからである。</span>
<span className="v" id="v37" data-v="37" data-xref="出エジプト記 3:2–6; マルコによる福音書 12:26–27; 使徒行伝 7:30–32"> 死人がよみがえることは、モーセも柴の篇で、主を『アブラハムの神、イサクの神、ヤコブの神』と呼んで、これを示した。</span>
<span className="v" id="v38" data-v="38" data-xref="ヨハネによる福音書 11:25–26; コロサイ人への手紙 3:3–4; ローマ人への手紙 6:10–11"> 神は死んだ者の神ではなく、生きている者の神である。人はみな神に生きるものだからである」。</span>
<span className="v" id="v39" data-v="39" data-xref="使徒行伝 23:9; マルコによる福音書 12:28–34; マタイによる福音書 22:34–40"> 律法学者のうちのある人々が答えて言った、「先生、仰せのとおりです」。</span>
<span className="v" id="v40" data-v="40" data-xref="マタイによる福音書 22:46; マルコによる福音書 12:34; 箴言 26:5"> 彼らはそれ以上何もあえて問いかけようとしなかった。</span>
</div>
<div className="bp poetry">
<span className="v" id="v41" data-v="41" data-xref="マルコによる福音書 12:35–37; マタイによる福音書 1:1; マタイによる福音書 22:41–45"> イエスは彼らに言われた、「どうして人々はキリストをダビデの子だと言うのか。</span>
<span className="v" id="v42" data-v="42" data-xref="詩篇 110:1; 使徒行伝 2:34–35; ヘブル人への手紙 1:13"> ダビデ自身が詩篇の中で言っている、<br /><span className="pl pl-1">『主はわが主に仰せになった、</span></span>
<span className="v" id="v43" data-v="43" data-xref="ルカによる福音書 19:27; 詩篇 110:1; ヨハネの黙示録 19:14–21"> <span className="pl pl-1">あなたの敵をあなたの足台とする時までは、</span><br /><span className="pl pl-1">わたしの右に座していなさい』。</span></span>
<span className="v" id="v44" data-v="44" data-xref="ヨハネの黙示録 22:16; ルカによる福音書 1:31–35; マタイによる福音書 1:23"> <span className="pl pl-1">このように、ダビデはキリストを主と呼んでいる。それなら、どうしてキリストはダビデの子であろうか」。</span></span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="マタイによる福音書 15:10; マルコによる福音書 12:38–39; マルコによる福音書 8:34"> 民衆がみな聞いているとき、イエスは弟子たちに言われた、</span>
<span className="v" id="v46" data-v="46" data-xref="ルカによる福音書 11:43; マルコによる福音書 12:38–39; ルカによる福音書 14:7"> 「律法学者に気をつけなさい。彼らは長い衣を着て歩くのを好み、広場での敬礼や会堂の上席や宴会の上座をよろこび、</span>
<span className="v" id="v47" data-v="47" data-xref="マルコによる福音書 12:40; ヤコブの手紙 3:1; テトスヘの手紙 1:16"> やもめたちの家を食い倒し、見えのために長い祈をする。彼らはもっときびしいさばきを受けるであろう」。</span>

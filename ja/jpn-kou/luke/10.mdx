<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マルコによる福音書 6:7–13; ルカによる福音書 9:52; 民数記 11:24–26"> その後、主は別に七十二人を選び、行こうとしておられたすべての町や村へ、ふたりずつ先におつかわしになった。</span>
<span className="v" id="v2" data-v="2" data-xref="マタイによる福音書 9:36–38; ヨハネによる福音書 4:35–38; コリント人への第一の手紙 3:6–9"> そのとき、彼らに言われた、「収穫は多いが、働き人が少ない。だから、収穫の主に願って、その収穫のために働き人を送り出すようにしてもらいなさい。</span>
<span className="v" id="v3" data-v="3" data-xref="マタイによる福音書 10:16; 使徒行伝 20:29; エゼキエル書 2:3–6"> さあ、行きなさい。わたしがあなたがたをつかわすのは、小羊をおおかみの中に送るようなものである。</span>
<span className="v" id="v4" data-v="4" data-xref="ルカによる福音書 22:35; 列王紀下 4:29; ルカによる福音書 10:4–12"> 財布も袋もくつも持って行くな。だれにも道であいさつするな。</span>
<span className="v" id="v5" data-v="5" data-xref="サムエル記上 25:6; マタイによる福音書 10:12–13; イザヤ書 57:19"> どこかの家にはいったら、まず『平安がこの家にあるように』と言いなさい。</span>
<span className="v" id="v6" data-v="6" data-xref="テサロニケ人への第二の手紙 3:16; コリント人への第二の手紙 2:15–16; エペソ人への手紙 5:6"> もし平安の子がそこにおれば、あなたがたの祈る平安はその人の上にとどまるであろう。もしそうでなかったら、それはあなたがたの上に帰って来るであろう。</span>
<span className="v" id="v7" data-v="7" data-xref="テモテヘの第一の手紙 5:17–18; マタイによる福音書 10:10–11; ガラテヤ人への手紙 6:6"> それで、その同じ家に留まっていて、家の人が出してくれるものを飲み食いしなさい。働き人がその報いを得るのは当然である。家から家へと渡り歩くな。</span>
<span className="v" id="v8" data-v="8" data-xref="コリント人への第一の手紙 10:27; マタイによる福音書 10:40; ルカによる福音書 10:10"> どの町へはいっても、人々があなたがたを迎えてくれるなら、前に出されるものを食べなさい。</span>
<span className="v" id="v9" data-v="9" data-xref="マタイによる福音書 3:2; ヨハネによる福音書 3:5; ルカによる福音書 10:11"> そして、その町にいる病人をいやしてやり、『神の国はあなたがたに近づいた』と言いなさい。</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行伝 18:6; マタイによる福音書 10:14; 使徒行伝 13:51"> しかし、どの町へはいっても、人々があなたがたを迎えない場合には、大通りに出て行って言いなさい、</span>
<span className="v" id="v11" data-v="11" data-xref="ルカによる福音書 10:9; 使徒行伝 13:51; 使徒行伝 13:26"> 『わたしたちの足についているこの町のちりも、ぬぐい捨てて行く。しかし、神の国が近づいたことは、承知しているがよい』。</span>
<span className="v" id="v12" data-v="12" data-xref="マタイによる福音書 10:15; マタイによる福音書 11:24; 哀歌 4:6"> あなたがたに言っておく。その日には、この町よりもソドムの方が耐えやすいであろう。</span>
<span className="v" id="v13" data-v="13" data-xref="イザヤ書 23:1–18; ヨエル書 3:4–8; エゼキエル書 26:1–26"> わざわいだ、コラジンよ。わざわいだ、ベツサイダよ。おまえたちの中でなされた力あるわざが、もしツロとシドンでなされたなら、彼らはとうの昔に、荒布をまとい灰の中にすわって、悔い改めたであろう。</span>
<span className="v" id="v14" data-v="14" data-xref="ヨハネによる福音書 15:22–25; ローマ人への手紙 2:1; ルカによる福音書 12:47–48"> しかし、さばきの日には、ツロとシドンの方がおまえたちよりも、耐えやすいであろう。</span>
<span className="v" id="v15" data-v="15" data-xref="イザヤ書 14:13–15; マタイによる福音書 4:13; ルカによる福音書 13:28"> ああ、カペナウムよ、おまえは天にまで上げられようとでもいうのか。黄泉にまで落されるであろう。</span>
<span className="v" id="v16" data-v="16" data-xref="ヨハネによる福音書 13:20; マタイによる福音書 10:40; テサロニケ人への第一の手紙 4:8"> あなたがたに聞き従う者は、わたしに聞き従うのであり、あなたがたを拒む者は、わたしを拒むのである。そしてわたしを拒む者は、わたしをおつかわしになったかたを拒むのである」。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="ローマ人への手紙 16:20; マルコによる福音書 16:17; ルカによる福音書 9:1"> 七十二人が喜んで帰ってきて言った、「主よ、あなたの名によっていたしますと、悪霊までがわたしたちに服従します」。</span>
<span className="v" id="v18" data-v="18" data-xref="ヨハネの黙示録 12:7–9; イザヤ書 14:12; ヨハネの黙示録 9:1"> 彼らに言われた、「わたしはサタンが電光のように天から落ちるのを見た。</span>
<span className="v" id="v19" data-v="19" data-xref="詩篇 91:13; マルコによる福音書 16:18; ローマ人への手紙 16:20"> わたしはあなたがたに、へびやさそりを踏みつけ、敵のあらゆる力に打ち勝つ権威を授けた。だから、あなたがたに害をおよぼす者はまったく無いであろう。</span>
<span className="v" id="v20" data-v="20" data-xref="ヨハネの黙示録 20:15; ヨハネの黙示録 20:12; ヘブル人への手紙 12:23"> しかし、霊があなたがたに服従することを喜ぶな。むしろ、あなたがたの名が天にしるされていることを喜びなさい」。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="コリント人への第二の手紙 4:3; マタイによる福音書 13:11–16; マタイによる福音書 11:25–27"> そのとき、イエスは聖霊によって喜びあふれて言われた、「天地の主なる父よ。あなたをほめたたえます。これらの事を知恵のある者や賢い者に隠して、幼な子にあらわしてくださいました。父よ、これはまことに、みこころにかなった事でした。</span>
<span className="v" id="v22" data-v="22" data-xref="マタイによる福音書 11:27; ヨハネによる福音書 1:18; ヨハネによる福音書 6:44–46"> すべての事は父からわたしに任せられています。そして、子がだれであるかは、父のほか知っている者はありません。また父がだれであるかは、子と、父をあらわそうとして子が選んだ者とのほか、だれも知っている者はいません」。</span>
<span className="v" id="v23" data-v="23" data-xref="マタイによる福音書 13:16–17"> それから弟子たちの方に振りむいて、ひそかに言われた、「あなたがたが見ていることを見る目は、さいわいである。</span>
<span className="v" id="v24" data-v="24" data-xref="ヨハネによる福音書 8:56; ヘブル人への手紙 11:13; ペテロの第一の手紙 1:10–12"> あなたがたに言っておく。多くの預言者や王たちも、あなたがたの見ていることを見ようとしたが、見ることができず、あなたがたの聞いていることを聞こうとしたが、聞けなかったのである」。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="マタイによる福音書 22:34–39; ルカによる福音書 18:18; マタイによる福音書 19:16–19"> するとそこへ、ある律法学者が現れ、イエスを試みようとして言った、「先生、何をしたら永遠の生命が受けられましょうか」。</span>
<span className="v" id="v26" data-v="26" data-xref="ローマ人への手紙 10:5; イザヤ書 8:20; ガラテヤ人への手紙 3:21–22"> 彼に言われた、「律法にはなんと書いてあるか。あなたはどう読むか」。</span>
<span className="v" id="v27" data-v="27" data-xref="マルコによる福音書 12:30–31; マタイによる福音書 22:37–40; 申命記 6:5"> 彼は答えて言った、「『心をつくし、精神をつくし、力をつくし、思いをつくして、主なるあなたの神を愛せよ』。また、『自分を愛するように、あなたの隣り人を愛せよ』とあります」。</span>
<span className="v" id="v28" data-v="28" data-xref="エゼキエル書 20:11; レビ記 18:5; マタイによる福音書 19:17"> 彼に言われた、「あなたの答は正しい。そのとおり行いなさい。そうすれば、いのちが得られる」。</span>
<span className="v" id="v29" data-v="29" data-xref="ルカによる福音書 16:15; ローマ人への手紙 4:2; レビ記 19:34"> すると彼は自分の立場を弁護しようと思って、イエスに言った、「では、わたしの隣り人とはだれのことですか」。</span>
<span className="v" id="v30" data-v="30" data-xref="詩篇 88:4; ルカによる福音書 18:31; 哀歌 2:12"> イエスが答えて言われた、「ある人がエルサレムからエリコに下って行く途中、強盗どもが彼を襲い、その着物をはぎ取り、傷を負わせ、半殺しにしたまま、逃げ去った。</span>
<span className="v" id="v31" data-v="31" data-xref="ヨハネの第一の手紙 3:16–18; 詩篇 69:20; エレミヤ書 5:31"> するとたまたま、ひとりの祭司がその道を下ってきたが、この人を見ると、向こう側を通って行った。</span>
<span className="v" id="v32" data-v="32" data-xref="箴言 27:10; 使徒行伝 18:17; 詩篇 109:25"> 同様に、レビ人もこの場所にさしかかってきたが、彼を見ると向こう側を通って行った。</span>
<span className="v" id="v33" data-v="33" data-xref="列王紀上 8:50; エレミヤ書 38:7–13; ルカによる福音書 7:13"> ところが、あるサマリヤ人が旅をしてこの人のところを通りかかり、彼を見て気の毒に思い、</span>
<span className="v" id="v34" data-v="34" data-xref="ローマ人への手紙 12:20; 詩篇 147:3; テサロニケ人への第一の手紙 5:15"> 近寄ってきてその傷にオリブ油とぶどう酒とを注いでほうたいをしてやり、自分の家畜に乗せ、宿屋に連れて行って介抱した。</span>
<span className="v" id="v35" data-v="35" data-xref="箴言 19:17; ルカによる福音書 14:13; ローマ人への手紙 16:23"> 翌日、デナリ二つを取り出して宿屋の主人に手渡し、『この人を見てやってください。費用がよけいにかかったら、帰りがけに、わたしが支払います』と言った。</span>
<span className="v" id="v36" data-v="36" data-xref="ルカによる福音書 7:42; マタイによる福音書 21:28–31; マタイによる福音書 17:25"> この三人のうち、だれが強盗に襲われた人の隣り人になったと思うか」。</span>
<span className="v" id="v37" data-v="37" data-xref="ヨハネの第一の手紙 3:16–18; ミカ書 6:8; ペテロの第一の手紙 2:21"> 彼が言った、「その人に慈悲深い行いをした人です」。そこでイエスは言われた、「あなたも行って同じようにしなさい」。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="ヨハネによる福音書 11:19–20; ヨハネによる福音書 11:1–5; ヨハネによる福音書 12:1–3"> 一同が旅を続けているうちに、イエスがある村へはいられた。するとマルタという名の女がイエスを家に迎え入れた。</span>
<span className="v" id="v39" data-v="39" data-xref="箴言 8:34; ルカによる福音書 8:35; ヨハネによる福音書 12:3"> この女にマリヤという妹がいたが、主の足もとにすわって、御言に聞き入っていた。</span>
<span className="v" id="v40" data-v="40" data-xref="ヨハネによる福音書 6:27; ルカによる福音書 12:29; マタイによる福音書 14:15"> ところが、マルタは接待のことで忙がしくて心をとりみだし、イエスのところにきて言った、「主よ、妹がわたしだけに接待をさせているのを、なんともお思いになりませんか。わたしの手伝いをするように妹におっしゃってください」。</span>
<span className="v" id="v41" data-v="41" data-xref="ピリピ人への手紙 4:6; ルカによる福音書 21:34; マタイによる福音書 6:25–34"> 主は答えて言われた、「マルタよ、マルタよ、あなたは多くのことに心を配って思いわずらっている。</span>
<span className="v" id="v42" data-v="42" data-xref="詩篇 27:4; 詩篇 16:5–6; ヨハネによる福音書 10:27–28"> しかし、無くてならぬものは多くはない。いや、一つだけである。マリヤはその良い方を選んだのだ。そしてそれは、彼女から取り去ってはならないものである」。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マルコによる福音書 1:16–20; マタイによる福音書 4:18–22; マルコによる福音書 3:9"> さて、群衆が神の言を聞こうとして押し寄せてきたとき、イエスはゲネサレ湖畔に立っておられたが、</span>
<span className="v" id="v2" data-v="2" data-xref="マルコによる福音書 1:19; マタイによる福音書 4:21"> そこに二そうの小舟が寄せてあるのをごらんになった。漁師たちは、舟からおりて網を洗っていた。</span>
<span className="v" id="v3" data-v="3" data-xref="マタイによる福音書 4:18; マタイによる福音書 13:1–2; ヨハネによる福音書 1:41–42"> その一そうはシモンの舟であったが、イエスはそれに乗り込み、シモンに頼んで岸から少しこぎ出させ、そしてすわって、舟の中から群衆にお教えになった。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネによる福音書 21:6; マタイによる福音書 17:27"> 話がすむと、シモンに「沖へこぎ出し、網をおろして漁をしてみなさい」と言われた。</span>
<span className="v" id="v5" data-v="5" data-xref="ヨハネによる福音書 2:5; ヨハネによる福音書 15:14; ルカによる福音書 6:46–48"> シモンは答えて言った、「先生、わたしたちは夜通し働きましたが、何も取れませんでした。しかし、お言葉ですから、網をおろしてみましょう」。</span>
<span className="v" id="v6" data-v="6" data-xref="コリント人への第一の手紙 15:58; ヨハネによる福音書 21:6–11; 伝道の書 11:6"> そしてそのとおりにしたところ、おびただしい魚の群れがはいって、網が破れそうになった。</span>
<span className="v" id="v7" data-v="7" data-xref="ガラテヤ人への手紙 6:2; ピリピ人への手紙 4:3; 使徒行伝 11:25"> そこで、もう一そうの舟にいた仲間に、加勢に来るよう合図をしたので、彼らがきて魚を両方の舟いっぱいに入れた。そのために、舟が沈みそうになった。</span>
<span className="v" id="v8" data-v="8" data-xref="イザヤ書 6:5; ヨブ記 42:5–6; ヨハネの黙示録 1:17"> これを見てシモン・ペテロは、イエスのひざもとにひれ伏して言った、「主よ、わたしから離れてください。わたしは罪深い者です」。</span>
<span className="v" id="v9" data-v="9" data-xref="ルカによる福音書 4:32; 詩篇 8:8; マルコによる福音書 9:6"> 彼も一緒にいた者たちもみな、取れた魚がおびただしいのに驚いたからである。</span>
<span className="v" id="v10" data-v="10" data-xref="マタイによる福音書 4:19; マタイによる福音書 13:47; エゼキエル書 47:9–10"> シモンの仲間であったゼベダイの子ヤコブとヨハネも、同様であった。すると、イエスがシモンに言われた、「恐れることはない。今からあなたは人間をとる漁師になるのだ」。</span>
<span className="v" id="v11" data-v="11" data-xref="マタイによる福音書 4:20; ルカによる福音書 5:28; マタイによる福音書 19:27"> そこで彼らは舟を陸に引き上げ、いっさいを捨ててイエスに従った。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="詩篇 50:15; ルカによる福音書 17:16; マタイによる福音書 8:2–4"> イエスがある町におられた時、全身らい病になっている人がそこにいた。イエスを見ると、顔を地に伏せて願って言った、「主よ、みこころでしたら、きよめていただけるのですが」。</span>
<span className="v" id="v13" data-v="13" data-xref="マタイによる福音書 9:29–30; ヨハネによる福音書 4:50–53; ホセア書 14:4"> イエスは手を伸ばして彼にさわり、「そうしてあげよう、きよくなれ」と言われた。すると、らい病がただちに去ってしまった。</span>
<span className="v" id="v14" data-v="14" data-xref="レビ記 14:2–32; ルカによる福音書 17:14; マルコによる福音書 1:44"> イエスは、だれにも話さないようにと彼に言い聞かせ、「ただ行って自分のからだを祭司に見せ、それからあなたのきよめのため、モーセが命じたとおりのささげ物をして、人々に証明しなさい」とお命じになった。</span>
<span className="v" id="v15" data-v="15" data-xref="マタイによる福音書 15:30–31; ルカによる福音書 12:1; マルコによる福音書 1:45–2"> しかし、イエスの評判はますますひろまって行き、おびただしい群衆が、教を聞いたり、病気をなおしてもらったりするために、集まってきた。</span>
<span className="v" id="v16" data-v="16" data-xref="ルカによる福音書 6:12; マルコによる福音書 1:35–36; マタイによる福音書 14:23"> しかしイエスは、寂しい所に退いて祈っておられた。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="ルカによる福音書 6:19; ルカによる福音書 8:46; マタイによる福音書 11:5"> ある日のこと、イエスが教えておられると、ガリラヤやユダヤの方々の村から、またエルサレムからきたパリサイ人や律法学者たちが、そこにすわっていた。主の力が働いて、イエスは人々をいやされた。</span>
<span className="v" id="v18" data-v="18" data-xref="マルコによる福音書 2:3–12; マタイによる福音書 9:2–8; ヨハネによる福音書 5:5–6"> その時、ある人々が、ひとりの中風をわずらっている人を床にのせたまま連れてきて、家の中に運び入れ、イエスの前に置こうとした。</span>
<span className="v" id="v19" data-v="19" data-xref="マルコによる福音書 2:4; マタイによる福音書 10:27; マタイによる福音書 24:17"> ところが、群衆のためにどうしても運び入れる方法がなかったので、屋根にのぼり、瓦をはいで、病人を床ごと群衆のまん中につりおろして、イエスの前においた。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行伝 14:9; マタイによる福音書 9:2; マルコによる福音書 2:5"> イエスは彼らの信仰を見て、「人よ、あなたの罪はゆるされた」と言われた。</span>
<span className="v" id="v21" data-v="21" data-xref="イザヤ書 43:25; マルコによる福音書 2:6–7; ルカによる福音書 7:49"> すると律法学者とパリサイ人たちとは、「神を汚すことを言うこの人は、いったい、何者だ。神おひとりのほかに、だれが罪をゆるすことができるか」と言って論じはじめた。</span>
<span className="v" id="v22" data-v="22" data-xref="ルカによる福音書 24:38; イザヤ書 66:18; 詩篇 139:2"> イエスは彼らの論議を見ぬいて、「あなたがたは心の中で何を論じているのか。</span>
<span className="v" id="v23" data-v="23" data-xref="マルコによる福音書 2:9; マタイによる福音書 9:5"> あなたの罪はゆるされたと言うのと、起きて歩けと言うのと、どちらがたやすいか。</span>
<span className="v" id="v24" data-v="24" data-xref="ヨハネの黙示録 1:13; イザヤ書 53:11; ルカによる福音書 8:54"> しかし、人の子は地上で罪をゆるす権威を持っていることが、あなたがたにわかるために」と彼らに対して言い、中風の者にむかって、「あなたに命じる。起きよ、床を取り上げて家に帰れ」と言われた。</span>
<span className="v" id="v25" data-v="25" data-xref="ヨハネによる福音書 9:24; ルカによる福音書 5:13; 詩篇 107:20–22"> すると病人は即座にみんなの前で起きあがり、寝ていた床を取りあげて、神をあがめながら家に帰って行った。</span>
<span className="v" id="v26" data-v="26" data-xref="マタイによる福音書 9:8; マタイによる福音書 12:23; ルカによる福音書 7:16"> みんなの者は驚嘆してしまった。そして神をあがめ、おそれに満たされて、「きょうは驚くべきことを見た」と言った。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="マルコによる福音書 2:13–22; マタイによる福音書 9:9–17; ヨハネによる福音書 1:43"> そののち、イエスが出て行かれると、レビという名の取税人が収税所にすわっているのを見て、「わたしに従ってきなさい」と言われた。</span>
<span className="v" id="v28" data-v="28" data-xref="ルカによる福音書 5:11; マタイによる福音書 19:22–27; 列王紀上 19:19–21"> すると、彼はいっさいを捨てて立ちあがり、イエスに従ってきた。</span>
<span className="v" id="v29" data-v="29" data-xref="マルコによる福音書 2:15; ルカによる福音書 15:1; コリント人への第一の手紙 10:27"> それから、レビは自分の家で、イエスのために盛大な宴会を催したが、取税人やそのほか大ぜいの人々が、共に食卓に着いていた。</span>
<span className="v" id="v30" data-v="30" data-xref="マタイによる福音書 21:28–32; ルカによる福音書 5:17; マルコによる福音書 7:3"> ところが、パリサイ人やその律法学者たちが、イエスの弟子たちに対してつぶやいて言った、「どうしてあなたがたは、取税人や罪人などと飲食を共にするのか」。</span>
<span className="v" id="v31" data-v="31" data-xref="マルコによる福音書 2:17; マタイによる福音書 9:12–13; エレミヤ書 8:22"> イエスは答えて言われた、「健康な人には医者はいらない。いるのは病人である。</span>
<span className="v" id="v32" data-v="32" data-xref="ルカによる福音書 19:10; ルカによる福音書 15:10; テモテヘの第一の手紙 1:15–16"> わたしがきたのは、義人を招くためではなく、罪人を招いて悔い改めさせるためである」。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="マタイによる福音書 9:14–17; マルコによる福音書 2:18–22; ヨハネによる福音書 3:25"> また彼らはイエスに言った、「ヨハネの弟子たちは、しばしば断食をし、また祈をしており、パリサイ人の弟子たちもそうしているのに、あなたの弟子たちは食べたり飲んだりしています」。</span>
<span className="v" id="v34" data-v="34" data-xref="ヨハネによる福音書 3:29; コリント人への第二の手紙 11:2; イザヤ書 54:5"> するとイエスは言われた、「あなたがたは、花婿が一緒にいるのに、婚礼の客に断食をさせることができるであろうか。</span>
<span className="v" id="v35" data-v="35" data-xref="ルカによる福音書 17:22; 使徒行伝 14:23; 使徒行伝 3:21"> しかし、花婿が奪い去られる日が来る。その日には断食をするであろう」。</span>
<span className="v" id="v36" data-v="36" data-xref="マタイによる福音書 9:16–17; マルコによる福音書 2:21–22; コリント人への第二の手紙 6:16"> それからイエスはまた一つの譬を語られた、「だれも、新しい着物から布ぎれを切り取って、古い着物につぎを当てるものはない。もしそんなことをしたら、新しい着物を裂くことになるし、新しいのから取った布ぎれも古いのに合わないであろう。</span>
<span className="v" id="v37" data-v="37" data-xref="ヨシュア記 9:13; 詩篇 119:83; ヨシュア記 9:4"> まただれも、新しいぶどう酒を古い皮袋に入れはしない。もしそんなことをしたら、新しいぶどう酒は皮袋をはり裂き、そしてぶどう酒は流れ出るし、皮袋もむだになるであろう。</span>
<span className="v" id="v38" data-v="38" data-xref="ヘブル人への手紙 8:8–13; コリント人への第二の手紙 5:17; エゼキエル書 36:26"> 新しいぶどう酒は新しい皮袋に入れるべきである。</span>
<span className="v" id="v39" data-v="39" data-xref="ヘブル人への手紙 11:39; マルコによる福音書 7:7–13; エレミヤ書 6:16"> まただれも、古い酒を飲んでから、新しいのをほしがりはしない。『古いのが良い』と考えているからである」。</span>
</div>

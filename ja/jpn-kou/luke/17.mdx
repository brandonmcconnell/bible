<div className="bible-chapter" lang="ja" dir="ltr" data-lang="ja" data-translation="jpn-kou" data-translation-id="jpn_kou" data-translation-label="口語訳" data-book="LUK" data-book-slug="luke" data-book-name="ルカによる福音書" data-chapter="17" data-verses="37">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マタイによる福音書 18:7; ローマ人への手紙 14:13; コリント人への第一の手紙 11:19"> イエスは弟子たちに言われた、「罪の誘惑が来ることは避けられない。しかし、それをきたらせる者は、わざわいである。</span>
<span className="v" id="v2" data-v="2" data-xref="マルコによる福音書 9:42; マタイによる福音書 18:14; マタイによる福音書 18:3–6"> これらの小さい者のひとりを罪に誘惑するよりは、むしろ、ひきうすを首にかけられて海に投げ入れられた方が、ましである。</span>
<span className="v" id="v3" data-v="3" data-xref="レビ記 19:17; マタイによる福音書 18:21; マタイによる福音書 18:15–17"> あなたがたは、自分で注意していなさい。もしあなたの兄弟が罪を犯すなら、彼をいさめなさい。そして悔い改めたら、ゆるしてやりなさい。</span>
<span className="v" id="v4" data-v="4" data-xref="コロサイ人への手紙 3:12–13; マタイによる福音書 18:21–22; ローマ人への手紙 12:20"> もしあなたに対して一日に七度罪を犯し、そして七度『悔い改めます』と言ってあなたのところへ帰ってくれば、ゆるしてやるがよい」。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="マルコによる福音書 9:24; ヘブル人への手紙 12:2; ピリピ人への手紙 4:13"> 使徒たちは主に「わたしたちの信仰を増してください」と言った。</span>
<span className="v" id="v6" data-v="6" data-xref="マタイによる福音書 17:20; マタイによる福音書 21:21; マルコによる福音書 9:23"> そこで主が言われた、「もし、からし種一粒ほどの信仰があるなら、この桑の木に、『抜け出して海に植われ』と言ったとしても、その言葉どおりになるであろう。</span>
<span className="v" id="v7" data-v="7" data-xref="マタイによる福音書 12:11; ルカによる福音書 13:15; ルカによる福音書 14:5"> あなたがたのうちのだれかに、耕作か牧畜かをする僕があるとする。その僕が畑から帰って来たとき、彼に『すぐきて、食卓につきなさい』と言うだろうか。</span>
<span className="v" id="v8" data-v="8" data-xref="ルカによる福音書 12:37; 創世記 43:16; サムエル記下 12:20"> かえって、『夕食の用意をしてくれ。そしてわたしが飲み食いをするあいだ、帯をしめて給仕をしなさい。そのあとで、飲み食いをするがよい』と、言うではないか。</span>
<span className="v" id="v9" data-v="9"> 僕が命じられたことをしたからといって、主人は彼に感謝するだろうか。</span>
<span className="v" id="v10" data-v="10" data-xref="コリント人への第一の手紙 9:16–17; ヨブ記 22:2–3; ペテロの第一の手紙 5:5–6"> 同様にあなたがたも、命じられたことを皆してしまったとき、『わたしたちはふつつかな僕です。すべき事をしたに過ぎません』と言いなさい」。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="ルカによる福音書 9:51–52; ヨハネによる福音書 4:3–4"> イエスはエルサレムへ行かれるとき、サマリヤとガリラヤとの間を通られた。</span>
<span className="v" id="v12" data-v="12" data-xref="レビ記 13:45–46; ルカによる福音書 5:12; 列王紀下 7:3"> そして、ある村にはいられると、十人のらい病人に出会われたが、彼らは遠くの方で立ちとどまり、</span>
<span className="v" id="v13" data-v="13" data-xref="マタイによる福音書 15:22; マタイによる福音書 20:30–31; マタイによる福音書 9:27"> 声を張りあげて、「イエスさま、わたしたちをあわれんでください」と言った。</span>
<span className="v" id="v14" data-v="14" data-xref="ルカによる福音書 5:14; レビ記 13:1–46; 列王紀下 5:14"> イエスは彼らをごらんになって、「祭司たちのところに行って、からだを見せなさい」と言われた。そして、行く途中で彼らはきよめられた。</span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 30:11–12; 詩篇 103:1–4; 詩篇 118:18–19"> そのうちのひとりは、自分がいやされたことを知り、大声で神をほめたたえながら帰ってきて、</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行伝 8:5–25; マタイによる福音書 10:5; ヨハネの黙示録 19:10"> イエスの足もとにひれ伏して感謝した。これはサマリヤ人であった。</span>
<span className="v" id="v17" data-v="17" data-xref="ローマ人への手紙 1:21; 詩篇 106:13; 創世記 3:9"> イエスは彼にむかって言われた、「きよめられたのは、十人ではなかったか。ほかの九人は、どこにいるのか。</span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 50:23; マタイによる福音書 15:24–28; 詩篇 106:13"> 神をほめたたえるために帰ってきたものは、この他国人のほかにはいないのか」。</span>
<span className="v" id="v19" data-v="19" data-xref="ルカによる福音書 7:50; ルカによる福音書 8:48; マルコによる福音書 10:52"> それから、その人に言われた、「立って行きなさい。あなたの信仰があなたを救ったのだ」。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="ヨハネによる福音書 18:36; ルカによる福音書 19:11; ダニエル書 2:44"> 神の国はいつ来るのかと、パリサイ人が尋ねたので、イエスは答えて言われた、「神の国は、見られるかたちで来るものではない。</span>
<span className="v" id="v21" data-v="21" data-xref="マタイによる福音書 12:28; ローマ人への手紙 14:17; マルコによる福音書 13:21"> また『見よ、ここにある』『あそこにある』などとも言えない。神の国は、実にあなたがたのただ中にあるのだ」。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="ルカによる福音書 5:35; マタイによる福音書 9:15; ヨハネによる福音書 8:21–24"> それから弟子たちに言われた、「あなたがたは、人の子の日を一日でも見たいと願っても見ることができない時が来るであろう。</span>
<span className="v" id="v23" data-v="23" data-xref="ルカによる福音書 21:8; マタイによる福音書 24:23–26; ルカによる福音書 17:21"> 人々はあなたがたに、『見よ、あそこに』『見よ、ここに』と言うだろう。しかし、そちらへ行くな、彼らのあとを追うな。</span>
<span className="v" id="v24" data-v="24" data-xref="マタイによる福音書 24:27; マタイによる福音書 24:30; マラキ書 4:1–2"> いなずまが天の端からひかり出て天の端へとひらめき渡るように、人の子もその日には同じようであるだろう。</span>
<span className="v" id="v25" data-v="25" data-xref="マタイによる福音書 16:21; ルカによる福音書 9:22; マルコによる福音書 8:31"> しかし、彼はまず多くの苦しみを受け、またこの時代の人々に捨てられねばならない。</span>
<span className="v" id="v26" data-v="26" data-xref="マタイによる福音書 24:37–39; ルカによる福音書 17:24; 創世記 7:7–23"> そして、ノアの時にあったように、人の子の時にも同様なことが起るであろう。</span>
<span className="v" id="v27" data-v="27" data-xref="ルカによる福音書 12:19–20; テサロニケ人への第一の手紙 5:1–3; ルカによる福音書 16:19–23"> ノアが箱舟にはいる日まで、人々は食い、飲み、めとり、とつぎなどしていたが、そこへ洪水が襲ってきて、彼らをことごとく滅ぼした。</span>
<span className="v" id="v28" data-v="28" data-xref="エゼキエル書 16:49–50; 創世記 18:20–21; ヤコブの手紙 5:1–5"> ロトの時にも同じようなことが起った。人々は食い、飲み、買い、売り、植え、建てなどしていたが、</span>
<span className="v" id="v29" data-v="29" data-xref="ペテロの第二の手紙 2:6; ゼパニヤ書 2:9; ユダの手紙 1:7"> ロトがソドムから出て行った日に、天から火と硫黄とが降ってきて、彼らをことごとく滅ぼした。</span>
<span className="v" id="v30" data-v="30" data-xref="コリント人への第一の手紙 1:7; テサロニケ人への第二の手紙 1:7; ヨハネの黙示録 1:7"> 人の子が現れる日も、ちょうどそれと同様であろう。</span>
<span className="v" id="v31" data-v="31" data-xref="ルカによる福音書 21:21; マルコによる福音書 13:14–16; エレミヤ書 45:5"> その日には、屋上にいる者は、自分の持ち物が家の中にあっても、取りにおりるな。畑にいる者も同じように、あとへもどるな。</span>
<span className="v" id="v32" data-v="32" data-xref="創世記 19:26; ヘブル人への手紙 10:38–39; ペテロの第二の手紙 2:18–22"> ロトの妻のことを思い出しなさい。</span>
<span className="v" id="v33" data-v="33" data-xref="マルコによる福音書 8:35–37; マタイによる福音書 10:39; ヨハネによる福音書 12:25"> 自分の命を救おうとするものは、それを失い、それを失うものは、保つのである。</span>
<span className="v" id="v34" data-v="34" data-xref="マタイによる福音書 24:40–41; ペテロの第二の手紙 2:9; マラキ書 3:16–18"> あなたがたに言っておく。その夜、ふたりの男が一つ寝床にいるならば、ひとりは取り去られ、他のひとりは残されるであろう。</span>
<span className="v" id="v35" data-v="35" data-xref="マタイによる福音書 24:41; 出エジプト記 11:5; 士師記 16:21"> ふたりの女が一緒にうすをひいているならば、ひとりは取り去られ、他のひとりは残されるであろう。〔</span>
<span className="v" id="v36" data-v="36"> ふたりの男が畑におれば、ひとりは取り去られ、他のひとりは残されるであろう〕」。</span>
<span className="v" id="v37" data-v="37" data-xref="マタイによる福音書 24:28; ヨブ記 39:29–30; ヨハネの黙示録 19:17–18"> 弟子たちは「主よ、それはどこであるのですか」と尋ねた。するとイエスは言われた、「死体のある所には、またはげたかが集まるものである」。</span>
</div>

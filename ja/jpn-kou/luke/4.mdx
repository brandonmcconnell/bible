<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マタイによる福音書 4:1–11; 使徒行伝 10:38; マルコによる福音書 1:12–13"> さて、イエスは聖霊に満ちてヨルダン川から帰り、</span>
<span className="v" id="v2" data-v="2" data-xref="出エジプト記 34:28; ヘブル人への手紙 4:15; 申命記 9:9"> 荒野を四十日のあいだ御霊にひきまわされて、悪魔の試みにあわれた。そのあいだ何も食べず、その日数がつきると、空腹になられた。</span>
<span className="v" id="v3" data-v="3" data-xref="マタイによる福音書 4:3; ルカによる福音書 3:22"> そこで悪魔が言った、「もしあなたが神の子であるなら、この石に、パンになれと命じてごらんなさい」。</span>
<span className="v" id="v4" data-v="4" data-xref="申命記 8:3; マタイによる福音書 4:4; マタイによる福音書 6:31"> イエスは答えて言われた、「『人はパンだけで生きるものではない』と書いてある」。</span>
<span className="v" id="v5" data-v="5" data-xref="ヨハネの第一の手紙 2:15–16; コリント人への第一の手紙 15:52; マタイによる福音書 4:8"> それから、悪魔はイエスを高い所へ連れて行き、またたくまに世界のすべての国々を見せて</span>
<span className="v" id="v6" data-v="6" data-xref="ヨハネによる福音書 12:31; ヨハネの第一の手紙 5:19; ヨハネによる福音書 14:30"> 言った、「これらの国々の権威と栄華とをみんな、あなたにあげましょう。それらはわたしに任せられていて、だれでも好きな人にあげてよいのですから。</span>
<span className="v" id="v7" data-v="7" data-xref="ルカによる福音書 8:28; 詩篇 72:11; イザヤ書 45:14"> それで、もしあなたがわたしの前にひざまずくなら、これを全部あなたのものにしてあげましょう」。</span>
<span className="v" id="v8" data-v="8" data-xref="申命記 6:13; 申命記 10:20; マタイによる福音書 4:10"> イエスは答えて言われた、「『主なるあなたの神を拝し、ただ神にのみ仕えよ』と書いてある」。</span>
<span className="v" id="v9" data-v="9" data-xref="マタイによる福音書 4:5–6; ルカによる福音書 4:3; マタイによる福音書 8:29"> それから悪魔はイエスをエルサレムに連れて行き、宮の頂上に立たせて言った、「もしあなたが神の子であるなら、ここから下へ飛びおりてごらんなさい。</span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 91:11–12; ヘブル人への手紙 1:14; コリント人への第二の手紙 11:14"> 『神はあなたのために、御使たちに命じてあなたを守らせるであろう』とあり、</span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 91:12"> また、『あなたの足が石に打ちつけられないように、彼らはあなたを手でささえるであろう』とも書いてあります」。</span>
<span className="v" id="v12" data-v="12" data-xref="申命記 6:16; ヘブル人への手紙 3:8–9; コリント人への第一の手紙 10:9"> イエスは答えて言われた、「『主なるあなたの神を試みてはならない』と言われている」。</span>
<span className="v" id="v13" data-v="13" data-xref="ヘブル人への手紙 4:15; ヤコブの手紙 4:7; マタイによる福音書 4:11"> 悪魔はあらゆる試みをしつくして、一時イエスを離れた。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="マタイによる福音書 4:23–25; 使徒行伝 10:37; マタイによる福音書 4:12"> それからイエスは御霊の力に満ちあふれてガリラヤへ帰られると、そのうわさがその地方全体にひろまった。</span>
<span className="v" id="v15" data-v="15" data-xref="マタイによる福音書 4:23; マタイによる福音書 9:8; マタイによる福音書 9:35"> イエスは諸会堂で教え、みんなの者から尊敬をお受けになった。</span>
</div>
<div className="bp poetry">
<span className="v" id="v16" data-v="16" data-xref="使徒行伝 17:2; 使徒行伝 13:14–16; マタイによる福音書 2:23"> それからお育ちになったナザレに行き、安息日にいつものように会堂にはいり、聖書を朗読しようとして立たれた。</span>
<span className="v" id="v17" data-v="17" data-xref="イザヤ書 61:1–3; 使徒行伝 13:15; 使徒行伝 7:42"> すると預言者イザヤの書が手渡されたので、その書を開いて、こう書いてある所を出された、</span>
<span className="v" id="v18" data-v="18" data-xref="イザヤ書 61:1; マタイによる福音書 11:5; 詩篇 146:7–8"> <span className="pl pl-1">「主の御霊がわたしに宿っている。</span><br /><span className="pl pl-1">貧しい人々に福音を宣べ伝えさせるために、</span><br /><span className="pl pl-1">わたしを聖別してくださったからである。</span><br /><span className="pl pl-1">主はわたしをつかわして、</span><br /><span className="pl pl-1">囚人が解放され、盲人の目が開かれることを告げ知らせ、</span><br /><span className="pl pl-1">打ちひしがれている者に自由を得させ、</span></span>
<span className="v" id="v19" data-v="19" data-xref="イザヤ書 61:2; イザヤ書 63:4; コリント人への第二の手紙 6:1"> <span className="pl pl-1">主のめぐみの年を告げ知らせるのである」。</span></span>
<span className="v" id="v20" data-v="20" data-xref="ルカによる福音書 4:17; ヨハネによる福音書 8:2; ルカによる福音書 19:48"> <span className="pl pl-1">イエスは聖書を巻いて係りの者に返し、席に着かれると、会堂にいるみんなの者の目がイエスに注がれた。</span></span>
<span className="v" id="v21" data-v="21" data-xref="ヨハネによる福音書 4:25–26; 使徒行伝 3:18; 使徒行伝 2:16–18"> <span className="pl pl-1">そこでイエスは、「この聖句は、あなたがたが耳にしたこの日に成就した」と説きはじめられた。</span></span>
<span className="v" id="v22" data-v="22" data-xref="マタイによる福音書 13:54–56; 詩篇 45:2; 使徒行伝 6:10"> <span className="pl pl-1">すると、彼らはみなイエスをほめ、またその口から出て来るめぐみの言葉に感嘆して言った、「この人はヨセフの子ではないか」。</span></span>
<span className="v" id="v23" data-v="23" data-xref="ヨハネによる福音書 4:46–53; マタイによる福音書 11:23–24; マルコによる福音書 2:1–12"> <span className="pl pl-1">そこで彼らに言われた、「あなたがたは、きっと『医者よ、自分自身をいやせ』ということわざを引いて、カペナウムで行われたと聞いていた事を、あなたの郷里のこの地でもしてくれ、と言うであろう」。</span></span>
<span className="v" id="v24" data-v="24" data-xref="マタイによる福音書 13:57; ヨハネによる福音書 4:44; マルコによる福音書 6:4–5"> <span className="pl pl-1">それから言われた、「よく言っておく。預言者は、自分の郷里では歓迎されないものである。</span></span>
<span className="v" id="v25" data-v="25" data-xref="ヤコブの手紙 5:17; 列王紀上 17:1; マタイによる福音書 20:15"> <span className="pl pl-1">よく聞いておきなさい。エリヤの時代に、三年六か月にわたって天が閉じ、イスラエル全土に大ききんがあった際、そこには多くのやもめがいたのに、</span></span>
<span className="v" id="v26" data-v="26" data-xref="列王紀上 17:9–24; マタイによる福音書 11:21; オバデヤ書 1:20"> <span className="pl pl-1">エリヤはそのうちのだれにもつかわされないで、ただシドンのサレプタにいるひとりのやもめにだけつかわされた。</span></span>
<span className="v" id="v27" data-v="27" data-xref="列王紀下 5:1–27; ヨハネによる福音書 17:12; マタイによる福音書 12:4"> <span className="pl pl-1">また預言者エリシャの時代に、イスラエルには多くのらい病人がいたのに、そのうちのひとりもきよめられないで、ただシリヤのナアマンだけがきよめられた」。</span></span>
<span className="v" id="v28" data-v="28" data-xref="使徒行伝 5:33; 歴代志下 24:20–21; エレミヤ書 38:6"> <span className="pl pl-1">会堂にいた者たちはこれを聞いて、みな憤りに満ち、</span></span>
<span className="v" id="v29" data-v="29" data-xref="ヨハネによる福音書 8:59; 使徒行伝 21:28–32; 民数記 15:35"> <span className="pl pl-1">立ち上がってイエスを町の外へ追い出し、その町が建っている丘のがけまでひっぱって行って、突き落そうとした。</span></span>
<span className="v" id="v30" data-v="30" data-xref="ヨハネによる福音書 10:39; ヨハネによる福音書 8:59; ヨハネによる福音書 18:6–7"> <span className="pl pl-1">しかし、イエスは彼らのまん中を通り抜けて、去って行かれた。</span></span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="マルコによる福音書 1:21–28; マタイによる福音書 4:13; 使徒行伝 13:50–2"> それから、イエスはガリラヤの町カペナウムに下って行かれた。そして安息日になると、人々をお教えになったが、</span>
<span className="v" id="v32" data-v="32" data-xref="ルカによる福音書 4:36; マタイによる福音書 7:28–29; ヨハネによる福音書 6:63"> その言葉に権威があったので、彼らはその教に驚いた。</span>
<span className="v" id="v33" data-v="33" data-xref="マルコによる福音書 1:23"> すると、汚れた悪霊につかれた人が会堂にいて、大声で叫び出した、</span>
<span className="v" id="v34" data-v="34" data-xref="マルコによる福音書 1:24; ヤコブの手紙 2:19; マタイによる福音書 8:29"> 「ああ、ナザレのイエスよ、あなたはわたしたちとなんの係わりがあるのです。わたしたちを滅ぼしにこられたのですか。あなたがどなたであるか、わかっています。神の聖者です」。</span>
<span className="v" id="v35" data-v="35" data-xref="ルカによる福音書 4:41; ルカによる福音書 4:39; マタイによる福音書 8:26"> イエスはこれをしかって、「黙れ、この人から出て行け」と言われた。すると悪霊は彼を人なかに投げ倒し、傷は負わせずに、その人から出て行った。</span>
<span className="v" id="v36" data-v="36" data-xref="ルカによる福音書 4:32; ペテロの第一の手紙 3:22; マタイによる福音書 12:22–23"> みんなの者は驚いて、互に語り合って言った、「これは、いったい、なんという言葉だろう。権威と力とをもって汚れた霊に命じられると、彼らは出て行くのだ」。</span>
<span className="v" id="v37" data-v="37" data-xref="マルコによる福音書 1:45; ルカによる福音書 4:14; イザヤ書 52:13"> こうしてイエスの評判が、その地方のいたる所にひろまっていった。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="マタイによる福音書 8:14–15; マルコによる福音書 1:29–31; ヨハネによる福音書 11:22"> イエスは会堂を出てシモンの家におはいりになった。ところがシモンのしゅうとめが高い熱を病んでいたので、人々は彼女のためにイエスにお願いした。</span>
<span className="v" id="v39" data-v="39" data-xref="ルカによる福音書 4:41; ルカによる福音書 4:35; ルカによる福音書 8:24"> そこで、イエスはそのまくらもとに立って、熱が引くように命じられると、熱は引き、女はすぐに起き上がって、彼らをもてなした。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="マルコによる福音書 1:32–34; マタイによる福音書 8:16–17; マルコによる福音書 5:23"> 日が暮れると、いろいろな病気になやむ者をかかえている人々が、皆それをイエスのところに連れてきたので、そのひとりびとりに手を置いて、おいやしになった。</span>
<span className="v" id="v41" data-v="41" data-xref="マルコによる福音書 1:34; ヤコブの手紙 2:19; ルカによる福音書 4:34–35"> 悪霊も「あなたこそ神の子です」と叫びながら多くの人々から出ていった。しかし、イエスは彼らを戒めて、物を言うことをお許しにならなかった。彼らがイエスはキリストだと知っていたからである。</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="ルカによる福音書 6:12; マルコによる福音書 1:35–38; ヨハネによる福音書 4:34"> 夜が明けると、イエスは寂しい所へ出て行かれたが、群衆が捜しまわって、みもとに集まり、自分たちから離れて行かれないようにと、引き止めた。</span>
<span className="v" id="v43" data-v="43" data-xref="マルコによる福音書 1:38–39; テモテヘの第二の手紙 4:2; ヨハネによる福音書 9:4"> しかしイエスは、「わたしは、ほかの町々にも神の国の福音を宣べ伝えねばならない。自分はそのためにつかわされたのである」と言われた。</span>
<span className="v" id="v44" data-v="44" data-xref="マタイによる福音書 4:23; マルコによる福音書 1:39; ルカによる福音書 4:15"> そして、ユダヤの諸会堂で教を説かれた。</span>
</div>

<div className="bible-chapter" lang="ja" dir="ltr" data-lang="ja" data-translation="jpn-kou" data-translation-id="jpn_kou" data-translation-label="口語訳" data-book="LUK" data-book-slug="luke" data-book-name="ルカによる福音書" data-chapter="23" data-verses="56">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マタイによる福音書 27:1–2; マタイによる福音書 27:11–14; ルカによる福音書 22:66"> 群衆はみな立ちあがって、イエスをピラトのところへ連れて行った。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行伝 17:6–7; ヨハネによる福音書 19:12; ルカによる福音書 23:14"> そして訴え出て言った、「わたしたちは、この人が国民を惑わし、貢をカイザルに納めることを禁じ、また自分こそ王なるキリストだと、となえているところを目撃しました」。</span>
<span className="v" id="v3" data-v="3" data-xref="ヨハネによる福音書 1:49; テモテヘの第一の手紙 6:13; ルカによる福音書 22:70"> ピラトはイエスに尋ねた、「あなたがユダヤ人の王であるか」。イエスは「そのとおりである」とお答えになった。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネによる福音書 18:38; ルカによる福音書 23:14–15; ルカによる福音書 23:22"> そこでピラトは祭司長たちと群衆とにむかって言った、「わたしはこの人になんの罪もみとめない」。</span>
<span className="v" id="v5" data-v="5" data-xref="マルコによる福音書 1:14; ヨハネによる福音書 1:43; ヨハネによる福音書 2:11"> ところが彼らは、ますます言いつのってやまなかった、「彼は、ガリラヤからはじめてこの所まで、ユダヤ全国にわたって教え、民衆を煽動しているのです」。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行伝 5:37; ルカによる福音書 13:1"> ピラトはこれを聞いて、この人はガリラヤ人かと尋ね、</span>
<span className="v" id="v7" data-v="7" data-xref="ルカによる福音書 3:1; ルカによる福音書 13:31; マタイによる福音書 14:1"> そしてヘロデの支配下のものであることを確かめたので、ちょうどこのころ、ヘロデがエルサレムにいたのをさいわい、そちらへイエスを送りとどけた。</span>
<span className="v" id="v8" data-v="8" data-xref="ルカによる福音書 9:7–9; マタイによる福音書 14:1; マルコによる福音書 6:14"> ヘロデはイエスを見て非常に喜んだ。それは、かねてイエスのことを聞いていたので、会って見たいと長いあいだ思っていたし、またイエスが何か奇跡を行うのを見たいと望んでいたからである。</span>
<span className="v" id="v9" data-v="9" data-xref="マタイによる福音書 27:14; マタイによる福音書 7:6; ペテロの第一の手紙 2:23"> それで、いろいろと質問を試みたが、イエスは何もお答えにならなかった。</span>
<span className="v" id="v10" data-v="10" data-xref="ルカによる福音書 11:53; ルカによる福音書 23:14–15; ルカによる福音書 23:5"> 祭司長たちと律法学者たちとは立って、激しい語調でイエスを訴えた。</span>
<span className="v" id="v11" data-v="11" data-xref="マルコによる福音書 15:16–20; マタイによる福音書 27:27–30; 詩篇 69:19–20"> またヘロデはその兵卒どもと一緒になって、イエスを侮辱したり嘲弄したりしたあげく、はなやかな着物を着せてピラトへ送りかえした。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行伝 4:27; ヨハネの黙示録 17:13–14; 詩篇 83:4–6"> ヘロデとピラトとは以前は互に敵視していたが、この日に親しい仲になった。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="マルコによる福音書 15:14; マタイによる福音書 27:21–23; ヨハネによる福音書 18:38"> ピラトは、祭司長たちと役人たちと民衆とを、呼び集めて言った、</span>
<span className="v" id="v14" data-v="14" data-xref="ダニエル書 6:4; ヘブル人への手紙 7:26; ルカによる福音書 23:1–2"> 「おまえたちは、この人を民衆を惑わすものとしてわたしのところに連れてきたので、おまえたちの面前でしらべたが、訴え出ているような罪は、この人に少しもみとめられなかった。</span>
<span className="v" id="v15" data-v="15"> ヘロデもまたみとめなかった。現に彼はイエスをわれわれに送りかえしてきた。この人はなんら死に当るようなことはしていないのである。</span>
<span className="v" id="v16" data-v="16" data-xref="マタイによる福音書 27:26; ルカによる福音書 23:22; マルコによる福音書 15:15"> だから、彼をむち打ってから、ゆるしてやることにしよう」。〔</span>
<span className="v" id="v17" data-v="17"> 祭ごとにピラトがひとりの囚人をゆるしてやることになっていた。〕</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行伝 21:36; 使徒行伝 3:14; 使徒行伝 22:22"> ところが、彼らはいっせいに叫んで言った、「その人を殺せ。バラバをゆるしてくれ」。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行伝 3:14; ルカによる福音書 23:5; ルカによる福音書 23:2"> このバラバは、都で起った暴動と殺人とのかどで、獄に投ぜられていた者である。</span>
<span className="v" id="v20" data-v="20" data-xref="マルコによる福音書 15:15; マタイによる福音書 14:8–9; マタイによる福音書 27:19"> ピラトはイエスをゆるしてやりたいと思って、もう一度かれらに呼びかけた。</span>
<span className="v" id="v21" data-v="21" data-xref="マタイによる福音書 27:22–25; マルコによる福音書 15:13; ヨハネによる福音書 19:15"> しかし彼らは、わめきたてて「十字架につけよ、彼を十字架につけよ」と言いつづけた。</span>
<span className="v" id="v22" data-v="22" data-xref="ルカによる福音書 23:14; ルカによる福音書 23:20; ペテロの第一の手紙 3:18"> ピラトは三度目に彼らにむかって言った、「では、この人は、いったい、どんな悪事をしたのか。彼には死に当る罪は全くみとめられなかった。だから、むち打ってから彼をゆるしてやることにしよう」。</span>
<span className="v" id="v23" data-v="23" data-xref="ゼカリヤ書 11:8; 詩篇 57:4; 詩篇 22:12–13"> ところが、彼らは大声をあげて詰め寄り、イエスを十字架につけるように要求した。そして、その声が勝った。</span>
<span className="v" id="v24" data-v="24" data-xref="マタイによる福音書 27:26; 出エジプト記 23:2; 箴言 17:15"> ピラトはついに彼らの願いどおりにすることに決定した。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行伝 3:14; マルコによる福音書 15:6–7; マルコによる福音書 15:15"> そして、暴動と殺人とのかどで獄に投ぜられた者の方を、彼らの要求に応じてゆるしてやり、イエスの方は彼らに引き渡して、その意のままにまかせた。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="マタイによる福音書 27:32–44; マルコによる福音書 15:21–32; 使徒行伝 6:9"> 彼らがイエスをひいてゆく途中、シモンというクレネ人が郊外から出てきたのを捕えて十字架を負わせ、それをになってイエスのあとから行かせた。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="ルカによる福音書 8:52; ルカによる福音書 8:2; マルコによる福音書 15:40"> 大ぜいの民衆と、悲しみ嘆いてやまない女たちの群れとが、イエスに従って行った。</span>
<span className="v" id="v28" data-v="28" data-xref="雅歌 8:4; 雅歌 5:8; 雅歌 1:5"> イエスは女たちの方に振りむいて言われた、「エルサレムの娘たちよ、わたしのために泣くな。むしろ、あなたがた自身のため、また自分の子供たちのために泣くがよい。</span>
<span className="v" id="v29" data-v="29" data-xref="マタイによる福音書 24:19; ルカによる福音書 21:23–24; マルコによる福音書 13:17–19"> 『不妊の女と子を産まなかった胎と、ふくませなかった乳房とは、さいわいだ』と言う日が、いまに来る。</span>
<span className="v" id="v30" data-v="30" data-xref="ヨハネの黙示録 6:16; ホセア書 10:8; イザヤ書 2:19"> そのとき、人々は山にむかって、われわれの上に倒れかかれと言い、また丘にむかって、われわれにおおいかぶされと言い出すであろう。</span>
<span className="v" id="v31" data-v="31" data-xref="ペテロの第一の手紙 4:17–18; ヨハネによる福音書 15:6; 箴言 11:31"> もし、生木でさえもそうされるなら、枯木はどうされることであろう」。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="マルコによる福音書 15:27; イザヤ書 53:12; マタイによる福音書 27:38"> さて、イエスと共に刑を受けるために、ほかにふたりの犯罪人も引かれていった。</span>
<span className="v" id="v33" data-v="33" data-xref="マルコによる福音書 15:22–23; ヨハネによる福音書 19:17–18; ヨハネによる福音書 18:32"> されこうべと呼ばれている所に着くと、人々はそこでイエスを十字架につけ、犯罪人たちも、ひとりは右に、ひとりは左に、十字架につけた。</span>
<span className="v" id="v34" data-v="34" data-xref="マタイによる福音書 5:44; 使徒行伝 7:60; ペテロの第一の手紙 3:9"> そのとき、イエスは言われた、「父よ、彼らをおゆるしください。彼らは何をしているのか、わからずにいるのです」。人々はイエスの着物をくじ引きで分け合った。</span>
<span className="v" id="v35" data-v="35" data-xref="詩篇 22:17; イザヤ書 42:1; ペテロの第一の手紙 2:4"> 民衆は立って見ていた。役人たちもあざ笑って言った、「彼は他人を救った。もし彼が神のキリスト、選ばれた者であるなら、自分自身を救うがよい」。</span>
<span className="v" id="v36" data-v="36" data-xref="詩篇 69:21; マタイによる福音書 27:48; マタイによる福音書 27:34"> 兵卒どももイエスをののしり、近寄ってきて酢いぶどう酒をさし出して言った、</span>
<span className="v" id="v37" data-v="37"> 「あなたがユダヤ人の王なら、自分を救いなさい」。</span>
<span className="v" id="v38" data-v="38" data-xref="マルコによる福音書 15:26; マタイによる福音書 27:37; ヨハネによる福音書 19:19–22"> イエスの上には、「これはユダヤ人の王」と書いた札がかけてあった。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="マタイによる福音書 27:44; マルコによる福音書 15:32; ルカによる福音書 23:35"> 十字架にかけられた犯罪人のひとりが、「あなたはキリストではないか。それなら、自分を救い、またわれわれも救ってみよ」と、イエスに悪口を言いつづけた。</span>
<span className="v" id="v40" data-v="40" data-xref="エペソ人への手紙 5:11; ルカによる福音書 12:5; ヨハネの黙示録 15:4"> もうひとりは、それをたしなめて言った、「おまえは同じ刑を受けていながら、神を恐れないのか。</span>
<span className="v" id="v41" data-v="41" data-xref="レビ記 26:40–41; エズラ記 9:13; ペテロの第一の手紙 1:19"> お互は自分のやった事のむくいを受けているのだから、こうなったのは当然だ。しかし、このかたは何も悪いことをしたのではない」。</span>
<span className="v" id="v42" data-v="42" data-xref="ローマ人への手紙 10:9–14; 使徒行伝 16:31; ヨハネの第一の手紙 5:11–13"> そして言った、「イエスよ、あなたが御国の権威をもっておいでになる時には、わたしを思い出してください」。</span>
<span className="v" id="v43" data-v="43" data-xref="ヨハネの黙示録 2:7; 詩篇 50:15; テモテヘの第一の手紙 1:15–16"> イエスは言われた、「よく言っておくが、あなたはきょう、わたしと一緒にパラダイスにいるであろう」。</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="マタイによる福音書 27:45; マルコによる福音書 15:33–34; アモス書 8:9"> 時はもう昼の十二時ごろであったが、太陽は光を失い、全地は暗くなって、三時に及んだ。</span>
<span className="v" id="v45" data-v="45" data-xref="ヘブル人への手紙 10:19–22; マタイによる福音書 27:51; ヘブル人への手紙 9:3–8"> そして聖所の幕がまん中から裂けた。</span>
<span className="v" id="v46" data-v="46" data-xref="詩篇 31:5; 使徒行伝 7:59; ヨハネによる福音書 19:30"> そのとき、イエスは声高く叫んで言われた、「父よ、わたしの霊をみ手にゆだねます」。こう言ってついに息を引きとられた。</span>
<span className="v" id="v47" data-v="47" data-xref="マタイによる福音書 27:54; マルコによる福音書 15:39; ルカによる福音書 23:41"> 百卒長はこの有様を見て、神をあがめ、「ほんとうに、この人は正しい人であった」と言った。</span>
<span className="v" id="v48" data-v="48" data-xref="ルカによる福音書 18:13; 使徒行伝 2:37; エレミヤ書 31:19"> この光景を見に集まってきた群衆も、これらの出来事を見て、みな胸を打ちながら帰って行った。</span>
<span className="v" id="v49" data-v="49" data-xref="ルカによる福音書 8:2; 詩篇 38:11; ルカによる福音書 23:55"> すべてイエスを知っていた者や、ガリラヤから従ってきた女たちも、遠い所に立って、これらのことを見ていた。</span>
</div>
<div className="bp">
<span className="v" id="v50" data-v="50" data-xref="ヨハネによる福音書 19:38–42; 使徒行伝 11:24; 使徒行伝 10:22"> ここに、ヨセフという議員がいたが、善良で正しい人であった。</span>
<span className="v" id="v51" data-v="51" data-xref="ルカによる福音書 2:25; ルカによる福音書 2:38; イザヤ書 8:12"> この人はユダヤの町アリマタヤの出身で、神の国を待ち望んでいた。彼は議会の議決や行動には賛成していなかった。</span>
<span className="v" id="v52" data-v="52" data-xref="ヨハネによる福音書 19:38–42"> この人がピラトのところへ行って、イエスのからだの引取り方を願い出て、</span>
<span className="v" id="v53" data-v="53" data-xref="マタイによる福音書 27:59–60; イザヤ書 53:9; マルコによる福音書 15:46"> それを取りおろして亜麻布に包み、まだだれも葬ったことのない、岩を掘って造った墓に納めた。</span>
<span className="v" id="v54" data-v="54" data-xref="マタイによる福音書 27:62; ヨハネによる福音書 19:31; マルコによる福音書 15:42"> この日は準備の日であって、安息日が始まりかけていた。</span>
<span className="v" id="v55" data-v="55" data-xref="ルカによる福音書 23:49; マタイによる福音書 27:61; マルコによる福音書 15:47"> イエスと一緒にガリラヤからきた女たちは、あとについてきて、その墓を見、またイエスのからだが納められる様子を見とどけた。</span>
<span className="v" id="v56" data-v="56" data-xref="ルカによる福音書 24:1; マルコによる福音書 16:1; 申命記 5:14"> そして帰って、香料と香油とを用意した。<br />それからおきてに従って安息日を休んだ。</span>
</div>

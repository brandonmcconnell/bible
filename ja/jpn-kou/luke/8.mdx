<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マタイによる福音書 4:23; ローマ人への手紙 10:15; マタイによる福音書 9:35"> そののちイエスは、神の国の福音を説きまた伝えながら、町々村々を巡回し続けられたが、十二弟子もお供をした。</span>
<span className="v" id="v2" data-v="2" data-xref="マルコによる福音書 16:9; マタイによる福音書 27:55–56; マルコによる福音書 15:40–41"> また悪霊を追い出され病気をいやされた数名の婦人たち、すなわち、七つの悪霊を追い出してもらったマグダラと呼ばれるマリヤ、</span>
<span className="v" id="v3" data-v="3" data-xref="ヨハネによる福音書 4:46–53; コリント人への第二の手紙 8:9; 使徒行伝 9:36–39"> ヘロデの家令クーザの妻ヨハンナ、スザンナ、そのほか多くの婦人たちも一緒にいて、自分たちの持ち物をもって一行に奉仕した。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="マルコによる福音書 4:1–9; マタイによる福音書 13:2–9"> さて、大ぜいの群衆が集まり、その上、町々からの人たちがイエスのところに、ぞくぞくと押し寄せてきたので、一つの譬で話をされた、</span>
<span className="v" id="v5" data-v="5" data-xref="ヘブル人への手紙 2:1; ヤコブの手紙 1:23–24; マルコによる福音書 4:15"> 「種まきが種をまきに出て行った。まいているうちに、ある種は道ばたに落ち、踏みつけられ、そして空の鳥に食べられてしまった。</span>
<span className="v" id="v6" data-v="6" data-xref="ヘブル人への手紙 3:7–8; ルカによる福音書 8:13; マルコによる福音書 4:5–6"> ほかの種は岩の上に落ち、はえはしたが水気がないので枯れてしまった。</span>
<span className="v" id="v7" data-v="7" data-xref="エレミヤ書 4:3; ルカによる福音書 8:14; ルカによる福音書 21:34"> ほかの種は、いばらの間に落ちたので、いばらも一緒に茂ってきて、それをふさいでしまった。</span>
<span className="v" id="v8" data-v="8" data-xref="マタイによる福音書 11:15; ヨハネの黙示録 2:11; ヨハネの黙示録 2:7"> ところが、ほかの種は良い地に落ちたので、はえ育って百倍もの実を結んだ」。こう語られたのち、声をあげて「聞く耳のある者は聞くがよい」と言われた。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="マルコによる福音書 4:10; マタイによる福音書 13:10; マタイによる福音書 13:18"> 弟子たちは、この譬はどういう意味でしょうか、とイエスに質問した。</span>
<span className="v" id="v10" data-v="10" data-xref="イザヤ書 6:9; マルコによる福音書 4:11; マタイによる福音書 11:25"> そこで言われた、「あなたがたには、神の国の奥義を知ることが許されているが、ほかの人たちには、見ても見えず、聞いても悟られないために、譬で話すのである。</span>
<span className="v" id="v11" data-v="11" data-xref="マタイによる福音書 13:19; マルコによる福音書 4:14–20; ヤコブの手紙 1:21"> この譬はこういう意味である。種は神の言である。</span>
<span className="v" id="v12" data-v="12" data-xref="テサロニケ人への第二の手紙 2:9–14; ヨハネの黙示録 12:9; ヤコブの手紙 1:23–24"> 道ばたに落ちたのは、聞いたのち、信じることも救われることもないように、悪魔によってその心から御言が奪い取られる人たちのことである。</span>
<span className="v" id="v13" data-v="13" data-xref="ホセア書 6:4; ヨハネによる福音書 5:35; 箴言 12:12"> 岩の上に落ちたのは、御言を聞いた時には喜んで受けいれるが、根が無いので、しばらくは信じていても、試錬の時が来ると、信仰を捨てる人たちのことである。</span>
<span className="v" id="v14" data-v="14" data-xref="ヨハネの第一の手紙 2:15–17; テモテヘの第一の手紙 6:9–10; テモテヘの第一の手紙 6:17"> いばらの中に落ちたのは、聞いてから日を過ごすうちに、生活の心づかいや富や快楽にふさがれて、実の熟するまでにならない人たちのことである。</span>
<span className="v" id="v15" data-v="15" data-xref="ヘブル人への手紙 10:36; ガラテヤ人への手紙 5:22–26; コロサイ人への手紙 1:10"> 良い地に落ちたのは、御言を聞いたのち、これを正しい良い心でしっかりと守り、耐え忍んで実を結ぶに至る人たちのことである。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="ルカによる福音書 11:33; マタイによる福音書 5:15–16; マルコによる福音書 4:21–22"> だれもあかりをともして、それを何かの器でおおいかぶせたり、寝台の下に置いたりはしない。燭台の上に置いて、はいって来る人たちに光が見えるようにするのである。</span>
<span className="v" id="v17" data-v="17" data-xref="ルカによる福音書 12:2–3; マタイによる福音書 10:26; マルコによる福音書 4:22"> 隠されているもので、あらわにならないものはなく、秘密にされているもので、ついには知られ、明るみに出されないものはない。</span>
<span className="v" id="v18" data-v="18" data-xref="マタイによる福音書 13:12; ルカによる福音書 19:26; マルコによる福音書 4:23–25"> だから、どう聞くかに注意するがよい。持っている人は更に与えられ、持っていない人は、持っていると思っているものまでも、取り上げられるであろう」。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="マタイによる福音書 12:46–50; マルコによる福音書 3:31–35; マルコによる福音書 3:21"> さて、イエスの母と兄弟たちとがイエスのところにきたが、群衆のためそば近くに行くことができなかった。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行伝 1:14; マルコによる福音書 6:3; マタイによる福音書 13:55–56"> それで、だれかが「あなたの母上と兄弟がたが、お目にかかろうと思って、外に立っておられます」と取次いだ。</span>
<span className="v" id="v21" data-v="21" data-xref="ルカによる福音書 11:27–28; ヤコブの手紙 1:22; ヨハネによる福音書 13:17"> するとイエスは人々にむかって言われた、「神の御言を聞いて行う者こそ、わたしの母、わたしの兄弟なのである」。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="マタイによる福音書 8:23–27; マルコによる福音書 4:35–41; マルコによる福音書 6:45"> ある日のこと、イエスは弟子たちと舟に乗り込み、「湖の向こう岸へ渡ろう」と言われたので、一同が船出した。</span>
<span className="v" id="v23" data-v="23" data-xref="詩篇 93:3–4; 詩篇 124:2–4; 詩篇 148:8"> 渡って行く間に、イエスは眠ってしまわれた。すると突風が湖に吹きおろしてきたので、彼らは水をかぶって危険になった。</span>
<span className="v" id="v24" data-v="24" data-xref="詩篇 107:25–29; ルカによる福音書 4:39; 詩篇 104:6–9"> そこで、みそばに寄ってきてイエスを起し、「先生、先生、わたしたちは死にそうです」と言った。イエスは起き上がって、風と荒浪とをおしかりになると、止んでなぎになった。</span>
<span className="v" id="v25" data-v="25" data-xref="マタイによる福音書 8:26; 箴言 30:4; マルコによる福音書 4:40–41"> イエスは彼らに言われた、「あなたがたの信仰は、どこにあるのか」。彼らは恐れ驚いて互に言い合った、「いったい、このかたはだれだろう。お命じになると、風も水も従うとは」。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="マルコによる福音書 5:1–20; マタイによる福音書 8:28–34"> それから、彼らはガリラヤの対岸、ゲラサ人の地に渡った。</span>
<span className="v" id="v27" data-v="27" data-xref="マルコによる福音書 5:2–5; サムエル記上 19:24; 民数記 19:16"> 陸にあがられると、その町の人で、悪霊につかれて長いあいだ着物も着ず、家に居つかないで墓場にばかりいた人に、出会われた。</span>
<span className="v" id="v28" data-v="28" data-xref="マタイによる福音書 8:29; ペテロの第二の手紙 2:4; マルコによる福音書 5:6–8"> この人がイエスを見て叫び出し、みまえにひれ伏して大声で言った、「いと高き神の子イエスよ、あなたはわたしとなんの係わりがあるのです。お願いです、わたしを苦しめないでください」。</span>
<span className="v" id="v29" data-v="29" data-xref="マルコによる福音書 5:3–5; ルカによる福音書 9:39; テモテヘの第二の手紙 2:25–26"> それは、イエスが汚れた霊に、その人から出て行け、とお命じになったからである。というのは、悪霊が何度も彼をひき捕えたので、彼は鎖と足かせとでつながれて看視されていたが、それを断ち切っては悪霊によって荒野へ追いやられていたのである。</span>
<span className="v" id="v30" data-v="30" data-xref="マタイによる福音書 26:53; ルカによる福音書 8:2; マタイによる福音書 8:29"> イエスは彼に「なんという名前か」とお尋ねになると、「レギオンと言います」と答えた。彼の中にたくさんの悪霊がはいり込んでいたからである。</span>
<span className="v" id="v31" data-v="31" data-xref="マタイによる福音書 25:41; ピリピ人への手紙 2:10–11; ヨブ記 2:5"> 悪霊どもは、底知れぬ所に落ちて行くことを自分たちにお命じにならぬようにと、イエスに願いつづけた。</span>
<span className="v" id="v32" data-v="32" data-xref="イザヤ書 65:4; イザヤ書 66:3; ヨハネの黙示録 20:7"> ところが、そこの山べにおびただしい豚の群れが飼ってあったので、その豚の中へはいることを許していただきたいと、悪霊どもが願い出た。イエスはそれをお許しになった。</span>
<span className="v" id="v33" data-v="33" data-xref="ペテロの第一の手紙 5:8; ヨハネによる福音書 8:44; ルカによる福音書 8:22–23"> そこで悪霊どもは、その人から出て豚の中へはいり込んだ。するとその群れは、がけから湖へなだれを打って駆け下り、おぼれ死んでしまった。</span>
<span className="v" id="v34" data-v="34" data-xref="マルコによる福音書 5:14; マタイによる福音書 8:33; マタイによる福音書 28:11"> 飼う者たちは、この出来事を見て逃げ出して、町や村里にふれまわった。</span>
<span className="v" id="v35" data-v="35" data-xref="ルカによる福音書 10:39; 使徒行伝 22:3; ヨハネの第一の手紙 3:8"> 人々はこの出来事を見に出てきた。そして、イエスのところにきて、悪霊を追い出してもらった人が着物を着て、正気になってイエスの足もとにすわっているのを見て、恐れた。</span>
<span className="v" id="v36" data-v="36" data-xref="マタイによる福音書 4:24"> それを見た人たちは、この悪霊につかれていた者が救われた次第を、彼らに語り聞かせた。</span>
<span className="v" id="v37" data-v="37" data-xref="使徒行伝 16:39; ルカによる福音書 8:28; ルカによる福音書 10:10–11"> それから、ゲラサの地方の民衆はこぞって、自分たちの所から立ち去ってくださるようにとイエスに頼んだ。彼らが非常な恐怖に襲われていたからである。そこで、イエスは舟に乗って帰りかけられた。</span>
<span className="v" id="v38" data-v="38" data-xref="使徒行伝 9:13–16; マルコによる福音書 5:18–20; 詩篇 145:3–12"> 悪霊を追い出してもらった人は、お供をしたいと、しきりに願ったが、イエスはこう言って彼をお帰しになった。</span>
<span className="v" id="v39" data-v="39" data-xref="ルカによる福音書 17:15–18; テモテヘの第一の手紙 5:8; 申命記 10:21"> 「家へ帰って、神があなたにどんなに大きなことをしてくださったか、語り聞かせなさい」。そこで彼は立ち去って、自分にイエスがして下さったことを、ことごとく町中に言いひろめた。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="マタイによる福音書 9:1; マルコによる福音書 5:21; マルコによる福音書 6:20"> イエスが帰ってこられると、群衆は喜び迎えた。みんながイエスを待ちうけていたのである。</span>
<span className="v" id="v41" data-v="41" data-xref="マルコによる福音書 5:22–43; ルカによる福音書 13:14; 使徒行伝 18:8"> するとそこに、ヤイロという名の人がきた。この人は会堂司であった。イエスの足もとにひれ伏して、自分の家においでくださるようにと、しきりに願った。</span>
<span className="v" id="v42" data-v="42" data-xref="ルカによる福音書 7:12; ルカによる福音書 8:45; ヨブ記 1:18–19"> 彼に十二歳ばかりになるひとり娘があったが、死にかけていた。ところが、イエスが出て行かれる途中、群衆が押し迫ってきた。</span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="マルコによる福音書 5:25–26; マタイによる福音書 9:20–22; レビ記 15:25–33"> ここに、十二年間も長血をわずらっていて、医者のために自分の身代をみな使い果してしまったが、だれにもなおしてもらえなかった女がいた。</span>
<span className="v" id="v44" data-v="44" data-xref="マルコによる福音書 5:27–28; 申命記 22:12; 使徒行伝 19:12"> この女がうしろから近寄ってみ衣のふさにさわったところ、その長血がたちまち止まってしまった。</span>
<span className="v" id="v45" data-v="45" data-xref="マルコによる福音書 5:30–32; ルカによる福音書 9:13; ルカによる福音書 5:5"> イエスは言われた、「わたしにさわったのは、だれか」。人々はみな自分ではないと言ったので、ペテロが「先生、群衆があなたを取り囲んで、ひしめき合っているのです」と答えた。</span>
<span className="v" id="v46" data-v="46" data-xref="ルカによる福音書 6:19; ルカによる福音書 5:17; ペテロの第一の手紙 2:9"> しかしイエスは言われた、「だれかがわたしにさわった。力がわたしから出て行ったのを感じたのだ」。</span>
<span className="v" id="v47" data-v="47" data-xref="マルコによる福音書 5:33; ルカによる福音書 17:15–16; コリント人への第一の手紙 2:3"> 女は隠しきれないのを知って、震えながら進み出て、みまえにひれ伏し、イエスにさわった訳と、さわるとたちまちなおったこととを、みんなの前で話した。</span>
<span className="v" id="v48" data-v="48" data-xref="ルカによる福音書 7:50; マタイによる福音書 9:22; ヘブル人への手紙 4:2"> そこでイエスが女に言われた、「娘よ、あなたの信仰があなたを救ったのです。安心して行きなさい」。</span>
</div>
<div className="bp">
<span className="v" id="v49" data-v="49" data-xref="マルコによる福音書 5:35–43; イザヤ書 7:12; ルカによる福音書 7:6"> イエスがまだ話しておられるうちに、会堂司の家から人がきて、「お嬢さんはなくなられました。この上、先生を煩わすには及びません」と言った。</span>
<span className="v" id="v50" data-v="50" data-xref="ヨハネによる福音書 11:40; ヨハネによる福音書 11:25; マルコによる福音書 5:36"> しかしイエスはこれを聞いて会堂司にむかって言われた、「恐れることはない。ただ信じなさい。娘は助かるのだ」。</span>
<span className="v" id="v51" data-v="51" data-xref="マルコによる福音書 14:33; マタイによる福音書 6:5–6; 列王紀上 17:19–23"> それから家にはいられるとき、ペテロ、ヨハネ、ヤコブおよびその子の父母のほかは、だれも一緒にはいって来ることをお許しにならなかった。</span>
<span className="v" id="v52" data-v="52" data-xref="ルカによる福音書 23:27; ヨハネによる福音書 11:4; ゼカリヤ書 12:10"> 人々はみな、娘のために泣き悲しんでいた。イエスは言われた、「泣くな、娘は死んだのではない。眠っているだけである」。</span>
<span className="v" id="v53" data-v="53" data-xref="ルカによる福音書 16:14; イザヤ書 53:3; ヨハネによる福音書 11:39"> 人々は娘が死んだことを知っていたので、イエスをあざ笑った。</span>
<span className="v" id="v54" data-v="54" data-xref="エレミヤ書 31:32; ヨハネによる福音書 11:43; マルコによる福音書 1:31"> イエスは娘の手を取って、呼びかけて言われた、「娘よ、起きなさい」。</span>
<span className="v" id="v55" data-v="55" data-xref="ヨハネによる福音書 11:44; 列王紀上 17:21–23; マルコによる福音書 5:43"> するとその霊がもどってきて、娘は即座に立ち上がった。イエスは何か食べ物を与えるように、さしずをされた。</span>
<span className="v" id="v56" data-v="56" data-xref="マタイによる福音書 8:4; マタイによる福音書 9:30; ルカによる福音書 5:14"> 両親は驚いてしまった。イエスはこの出来事をだれにも話さないようにと、彼らに命じられた。</span>
</div>

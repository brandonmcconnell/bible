<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命記 23:25; マルコによる福音書 2:23–28; マタイによる福音書 12:1–8"> ある安息日にイエスが麦畑の中をとおって行かれたとき、弟子たちが穂をつみ、手でもみながら食べていた。</span>
<span className="v" id="v2" data-v="2" data-xref="マタイによる福音書 12:2; ヨハネによる福音書 5:16; ヨハネによる福音書 5:9–11"> すると、あるパリサイ人たちが言った、「あなたがたはなぜ、安息日にしてはならぬことをするのか」。</span>
<span className="v" id="v3" data-v="3" data-xref="サムエル記上 21:3–6; マルコによる福音書 2:25–26; マタイによる福音書 12:3–5"> そこでイエスが答えて言われた、「あなたがたは、ダビデとその供の者たちとが飢えていたとき、ダビデのしたことについて、読んだことがないのか。</span>
<span className="v" id="v4" data-v="4" data-xref="レビ記 24:5–9"> すなわち、神の家にはいって、祭司たちのほかだれも食べてはならぬ供えのパンを取って食べ、また供の者たちにも与えたではないか」。</span>
<span className="v" id="v5" data-v="5" data-xref="マルコによる福音書 2:27; ヨハネの黙示録 1:10; マルコによる福音書 9:7"> また彼らに言われた、「人の子は安息日の主である」。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="マルコによる福音書 3:1–6; マタイによる福音書 12:9–14; ルカによる福音書 4:31"> また、ほかの安息日に会堂にはいって教えておられたところ、そこに右手のなえた人がいた。</span>
<span className="v" id="v7" data-v="7" data-xref="ルカによる福音書 20:20; 詩篇 38:12; ルカによる福音書 13:14"> 律法学者やパリサイ人たちは、イエスを訴える口実を見付けようと思って、安息日にいやされるかどうかをうかがっていた。</span>
<span className="v" id="v8" data-v="8" data-xref="イザヤ書 42:4; マタイによる福音書 9:4; ルカによる福音書 5:22"> イエスは彼らの思っていることを知って、その手のなえた人に、「起きて、まん中に立ちなさい」と言われると、起き上がって立った。</span>
<span className="v" id="v9" data-v="9" data-xref="マルコによる福音書 3:4; マタイによる福音書 12:12–13; ルカによる福音書 14:3"> そこでイエスは彼らにむかって言われた、「あなたがたに聞くが、安息日に善を行うのと悪を行うのと、命を救うのと殺すのと、どちらがよいか」。</span>
<span className="v" id="v10" data-v="10" data-xref="出エジプト記 4:6–7; マルコによる福音書 3:5; ヨハネによる福音書 5:8"> そして彼ら一同を見まわして、その人に「手を伸ばしなさい」と言われた。そのとおりにすると、その手は元どおりになった。</span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 2:1–2; 使徒行伝 5:33; 伝道の書 9:3"> そこで彼らは激しく怒って、イエスをどうかしてやろうと、互に話合いをはじめた。</span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="ヘブル人への手紙 5:7; マルコによる福音書 6:46; マルコによる福音書 1:35"> このころ、イエスは祈るために山へ行き、夜を徹して神に祈られた。</span>
<span className="v" id="v13" data-v="13" data-xref="マルコによる福音書 3:13–19; マタイによる福音書 9:36–4; ヨハネの黙示録 21:14"> 夜が明けると、弟子たちを呼び寄せ、その中から十二人を選び出し、これに使徒という名をお与えになった。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行伝 1:13; マタイによる福音書 4:21; マタイによる福音書 4:18"> すなわち、ペテロとも呼ばれたシモンとその兄弟アンデレ、ヤコブとヨハネ、ピリポとバルトロマイ、</span>
<span className="v" id="v15" data-v="15" data-xref="マタイによる福音書 9:9; マルコによる福音書 3:18; 使徒行伝 1:13"> マタイとトマス、アルパヨの子ヤコブと、熱心党と呼ばれたシモン、</span>
<span className="v" id="v16" data-v="16" data-xref="ヨハネによる福音書 14:22; ヨハネによる福音書 6:70–71; マルコによる福音書 3:18"> ヤコブの子ユダ、それからイスカリオテのユダ。このユダが裏切者となったのである。</span>
<span className="v" id="v17" data-v="17" data-xref="マタイによる福音書 11:21; マタイによる福音書 4:23–25; 詩篇 107:17–20"> そして、イエスは彼らと一緒に山を下って平地に立たれたが、大ぜいの弟子たちや、ユダヤ全土、エルサレム、ツロとシドンの海岸地方などからの大群衆が、</span>
<span className="v" id="v18" data-v="18" data-xref="マタイによる福音書 17:15; マタイによる福音書 15:22; 使徒行伝 5:16"> 教を聞こうとし、また病気をなおしてもらおうとして、そこにきていた。そして汚れた霊に悩まされている者たちも、いやされた。</span>
<span className="v" id="v19" data-v="19" data-xref="マタイによる福音書 14:36; マルコによる福音書 3:10; 使徒行伝 5:15–16"> また群衆はイエスにさわろうと努めた。それは力がイエスの内から出て、みんなの者を次々にいやしたからである。</span>
<span className="v" id="v20" data-v="20" data-xref="ヤコブの手紙 2:5; ルカによる福音書 6:20–24; コリント人への第二の手紙 8:9"> そのとき、イエスは目をあげ、弟子たちを見て言われた、<br /><span className="pl pl-1">「あなたがた貧しい人たちは、さいわいだ。</span><br /><span className="pl pl-1">神の国はあなたがたのものである。</span></span>
<span className="v" id="v21" data-v="21" data-xref="ヨハネによる福音書 6:35; マタイによる福音書 5:6; ヤコブの手紙 1:12"> <span className="pl pl-1">あなたがたいま飢えている人たちは、さいわいだ。</span><br /><span className="pl pl-1">飽き足りるようになるからである。</span><br /><span className="pl pl-1">あなたがたいま泣いている人たちは、さいわいだ。</span><br /><span className="pl pl-1">笑うようになるからである。</span></span>
<span className="v" id="v22" data-v="22" data-xref="マタイによる福音書 5:10–12; マタイによる福音書 10:22; ペテロの第一の手紙 4:12–16"> <span className="pl pl-1">人々があなたがたを憎むとき、また人の子のためにあなたがたを排斥し、ののしり、汚名を着せるときは、あなたがたはさいわいだ。</span></span>
<span className="v" id="v23" data-v="23" data-xref="使徒行伝 5:41; ヨハネの黙示録 21:7; ヨハネの黙示録 3:12"> <span className="pl pl-1">その日には喜びおどれ。見よ、天においてあなたがたの受ける報いは大きいのだから。彼らの祖先も、預言者たちに対して同じことをしたのである。</span></span>
<span className="v" id="v24" data-v="24" data-xref="マタイによる福音書 6:2; ヤコブの手紙 5:1–6; 詩篇 49:6–7"> <span className="pl pl-1">しかしあなたがた富んでいる人たちは、わざわいだ。</span><br /><span className="pl pl-1">慰めを受けてしまっているからである。</span></span>
<span className="v" id="v25" data-v="25" data-xref="イザヤ書 65:13; ヤコブの手紙 4:9; 箴言 14:13"> <span className="pl pl-1">あなたがた今満腹している人たちは、わざわいだ。</span><br /><span className="pl pl-1">飢えるようになるからである。</span><br /><span className="pl pl-1">あなたがた今笑っている人たちは、わざわいだ。悲しみ泣くようになるからである。</span></span>
<span className="v" id="v26" data-v="26" data-xref="ヨハネによる福音書 15:19; ヤコブの手紙 4:4; マタイによる福音書 7:15"> <span className="pl pl-1">人が皆あなたがたをほめるときは、あなたがたはわざわいだ。彼らの祖先も、にせ預言者たちに対して同じことをしたのである。</span></span>
<span className="v" id="v27" data-v="27" data-xref="テサロニケ人への第一の手紙 5:15; ルカによる福音書 6:35; ローマ人への手紙 12:17–21"> <span className="pl pl-1">しかし、聞いているあなたがたに言う。敵を愛し、憎む者に親切にせよ。</span></span>
<span className="v" id="v28" data-v="28" data-xref="ペテロの第一の手紙 3:9; コリント人への第一の手紙 4:12; ローマ人への手紙 12:14"> <span className="pl pl-1">のろう者を祝福し、はずかしめる者のために祈れ。</span></span>
<span className="v" id="v29" data-v="29" data-xref="ヘブル人への手紙 10:34; マタイによる福音書 5:39–42; コリント人への第二の手紙 11:20"> <span className="pl pl-1">あなたの頬を打つ者にはほかの頬をも向けてやり、あなたの上着を奪い取る者には下着をも拒むな。</span></span>
<span className="v" id="v30" data-v="30" data-xref="申命記 15:7–10; コリント人への第二の手紙 9:6–14; マタイによる福音書 6:12"> <span className="pl pl-1">あなたに求める者には与えてやり、あなたの持ち物を奪う者からは取りもどそうとするな。</span></span>
<span className="v" id="v31" data-v="31" data-xref="マタイによる福音書 7:12; ガラテヤ人への手紙 5:14; マタイによる福音書 22:39"> <span className="pl pl-1">人々にしてほしいと、あなたがたの望むことを、人々にもそのとおりにせよ。</span></span>
<span className="v" id="v32" data-v="32" data-xref="マタイによる福音書 5:46–47; ペテロの第一の手紙 2:19–20"> <span className="pl pl-1">自分を愛してくれる者を愛したからとて、どれほどの手柄になろうか。罪人でさえ、自分を愛してくれる者を愛している。</span></span>
<span className="v" id="v33" data-v="33"> <span className="pl pl-1">自分によくしてくれる者によくしたとて、どれほどの手柄になろうか。罪人でさえ、それくらいの事はしている。</span></span>
<span className="v" id="v34" data-v="34" data-xref="マタイによる福音書 5:42; ルカによる福音書 14:12–14; ルカによる福音書 6:35"> <span className="pl pl-1">また返してもらうつもりで貸したとて、どれほどの手柄になろうか。罪人でも、同じだけのものを返してもらおうとして、仲間に貸すのである。</span></span>
<span className="v" id="v35" data-v="35" data-xref="マタイによる福音書 5:44–45; ヨハネによる福音書 13:35; 箴言 19:17"> <span className="pl pl-1">しかし、あなたがたは、敵を愛し、人によくしてやり、また何も当てにしないで貸してやれ。そうすれば受ける報いは大きく、あなたがたはいと高き者の子となるであろう。いと高き者は、恩を知らぬ者にも悪人にも、なさけ深いからである。</span></span>
<span className="v" id="v36" data-v="36" data-xref="エペソ人への手紙 5:1–2; マタイによる福音書 5:48; ペテロの第一の手紙 1:15–16"> <span className="pl pl-1">あなたがたの父なる神が慈悲深いように、あなたがたも慈悲深い者となれ。</span></span>
<span className="v" id="v37" data-v="37" data-xref="エペソ人への手紙 4:32; ヤコブの手紙 5:9; マタイによる福音書 7:1–5"> <span className="pl pl-1">人をさばくな。そうすれば、自分もさばかれることがないであろう。また人を罪に定めるな。そうすれば、自分も罪に定められることがないであろう。ゆるしてやれ。そうすれば、自分もゆるされるであろう。</span></span>
<span className="v" id="v38" data-v="38" data-xref="コリント人への第二の手紙 9:6–8; 申命記 15:10; マルコによる福音書 4:24"> <span className="pl pl-1">与えよ。そうすれば、自分にも与えられるであろう。人々はおし入れ、ゆすり入れ、あふれ出るまでに量をよくして、あなたがたのふところに入れてくれるであろう。あなたがたの量るその量りで、自分にも量りかえされるであろうから」。</span></span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="マタイによる福音書 15:14; テモテヘの第二の手紙 3:13; テモテヘの第一の手紙 6:3–5"> イエスはまた一つの譬を語られた、「盲人は盲人の手引ができようか。ふたりとも穴に落ち込まないだろうか。</span>
<span className="v" id="v40" data-v="40" data-xref="ヨハネによる福音書 13:16; マタイによる福音書 10:24–25; ヨハネによる福音書 15:20"> 弟子はその師以上のものではないが、修業をつめば、みなその師のようになろう。</span>
<span className="v" id="v41" data-v="41" data-xref="ヨハネによる福音書 8:7; ヤコブの手紙 1:24; ローマ人への手紙 2:1"> なぜ、兄弟の目にあるちりを見ながら、自分の目にある梁を認めないのか。</span>
<span className="v" id="v42" data-v="42" data-xref="ローマ人への手紙 2:21–29; テサロニケ人への第一の手紙 2:10–12; 詩篇 51:9–13"> 自分の目にある梁は見ないでいて、どうして兄弟にむかって、兄弟よ、あなたの目にあるちりを取らせてください、と言えようか。偽善者よ、まず自分の目から梁を取りのけるがよい、そうすれば、はっきり見えるようになって、兄弟の目にあるちりを取りのけることができるだろう。</span>
<span className="v" id="v43" data-v="43" data-xref="エレミヤ書 2:21; マタイによる福音書 12:33; マタイによる福音書 7:16–20"> 悪い実のなる良い木はないし、また良い実のなる悪い木もない。</span>
<span className="v" id="v44" data-v="44" data-xref="マタイによる福音書 12:33; ヤコブの手紙 3:12; ガラテヤ人への手紙 5:19–23"> 木はそれぞれ、その実でわかる。いばらからいちじくを取ることはないし、野ばらからぶどうを摘むこともない。</span>
<span className="v" id="v45" data-v="45" data-xref="箴言 4:23; マタイによる福音書 12:34–37; エペソ人への手紙 4:29"> 善人は良い心の倉から良い物を取り出し、悪人は悪い倉から悪い物を取り出す。心からあふれ出ることを、口が語るものである。</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="ガラテヤ人への手紙 6:7; マラキ書 1:6; マタイによる福音書 7:21–23"> わたしを主よ、主よ、と呼びながら、なぜわたしの言うことを行わないのか。</span>
<span className="v" id="v47" data-v="47" data-xref="ヤコブの手紙 1:22–25; マタイによる福音書 7:24–27; ルカによる福音書 11:28"> わたしのもとにきて、わたしの言葉を聞いて行う者が、何に似ているか、あなたがたに教えよう。</span>
<span className="v" id="v48" data-v="48" data-xref="コリント人への第一の手紙 3:10–15; 詩篇 62:2; マタイによる福音書 7:25–26"> それは、地を深く掘り、岩の上に土台をすえて家を建てる人に似ている。洪水が出て激流がその家に押し寄せてきても、それを揺り動かすことはできない。よく建ててあるからである。</span>
<span className="v" id="v49" data-v="49" data-xref="エゼキエル書 33:31; ヤコブの手紙 1:22–26; マタイによる福音書 23:3"> しかし聞いても行わない人は、土台なしで、土の上に家を建てた人に似ている。激流がその家に押し寄せてきたら、たちまち倒れてしまい、その被害は大きいのである」。</span>
</div>

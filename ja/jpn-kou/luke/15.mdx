<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="テモテヘの第一の手紙 1:15; マタイによる福音書 9:10–13; ルカによる福音書 5:29–32"> さて、取税人や罪人たちが皆、イエスの話を聞こうとして近寄ってきた。</span>
<span className="v" id="v2" data-v="2" data-xref="マタイによる福音書 9:11; ルカによる福音書 19:7; ルカによる福音書 7:39"> するとパリサイ人や律法学者たちがつぶやいて、「この人は罪人たちを迎えて一緒に食事をしている」と言った。</span>
<span className="v" id="v3" data-v="3"> そこでイエスは彼らに、この譬をお話しになった、</span>
<span className="v" id="v4" data-v="4" data-xref="エゼキエル書 34:16; エゼキエル書 34:11–12; マタイによる福音書 18:12–14"> 「あなたがたのうちに、百匹の羊を持っている者がいたとする。その一匹がいなくなったら、九十九匹を野原に残しておいて、いなくなった一匹を見つけるまでは捜し歩かないであろうか。</span>
<span className="v" id="v5" data-v="5" data-xref="ヘブル人への手紙 12:2; ルカによる福音書 19:9; イザヤ書 46:3–4"> そして見つけたら、喜んでそれを自分の肩に乗せ、</span>
<span className="v" id="v6" data-v="6" data-xref="ルカによる福音書 15:10; ルカによる福音書 15:24; ペテロの第一の手紙 2:25"> 家に帰ってきて友人や隣り人を呼び集め、『わたしと一緒に喜んでください。いなくなった羊を見つけましたから』と言うであろう。</span>
<span className="v" id="v7" data-v="7" data-xref="ルカによる福音書 5:32; ルカによる福音書 15:10; ルカによる福音書 15:32"> よく聞きなさい。それと同じように、罪人がひとりでも悔い改めるなら、悔改めを必要としない九十九人の正しい人のためにもまさる大きいよろこびが、天にあるであろう。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="ルカによる福音書 19:10; エゼキエル書 34:12; ヨハネによる福音書 10:16"> また、ある女が銀貨十枚を持っていて、もしその一枚をなくしたとすれば、彼女はあかりをつけて家中を掃き、それを見つけるまでは注意深く捜さないであろうか。</span>
<span className="v" id="v9" data-v="9" data-xref="ルカによる福音書 15:6–7"> そして、見つけたなら、女友だちや近所の女たちを呼び集めて、『わたしと一緒に喜んでください。なくした銀貨が見つかりましたから』と言うであろう。</span>
<span className="v" id="v10" data-v="10" data-xref="ルカによる福音書 15:7; コリント人への第二の手紙 7:10; エゼキエル書 33:11"> よく聞きなさい。それと同じように、罪人がひとりでも悔い改めるなら、神の御使たちの前でよろこびがあるであろう」。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="マタイによる福音書 21:23–31"> また言われた、「ある人に、ふたりのむすこがあった。</span>
<span className="v" id="v12" data-v="12" data-xref="申命記 21:16–17; マルコによる福音書 12:44; ルカによる福音書 15:30"> ところが、弟が父親に言った、『父よ、あなたの財産のうちでわたしがいただく分をください』。そこで、父はその身代をふたりに分けてやった。</span>
<span className="v" id="v13" data-v="13" data-xref="箴言 29:3; エレミヤ書 2:5; 箴言 21:17"> それから幾日もたたないうちに、弟は自分のものを全部とりまとめて遠い所へ行き、そこで放蕩に身を持ちくずして財産を使い果した。</span>
<span className="v" id="v14" data-v="14" data-xref="歴代志下 33:11; アモス書 8:9–12; ホセア書 2:9–14"> 何もかも浪費してしまったのち、その地方にひどいききんがあったので、彼は食べることにも窮しはじめた。</span>
<span className="v" id="v15" data-v="15" data-xref="テトスヘの手紙 3:3; テモテヘの第二の手紙 2:25–26; イザヤ書 1:5"> そこで、その地方のある住民のところに行って身を寄せたところが、その人は彼を畑にやって豚を飼わせた。</span>
<span className="v" id="v16" data-v="16" data-xref="ローマ人への手紙 6:19–21; 哀歌 4:5; ホセア書 12:1"> 彼は、豚の食べるいなご豆で腹を満たしたいと思うほどであったが、何もくれる人はなかった。</span>
<span className="v" id="v17" data-v="17" data-xref="エゼキエル書 18:28; エペソ人への手紙 2:4–5; ルカによる福音書 15:18–19"> そこで彼は本心に立ちかえって言った、『父のところには食物のあり余っている雇人が大ぜいいるのに、わたしはここで飢えて死のうとしている。</span>
<span className="v" id="v18" data-v="18" data-xref="哀歌 3:40; ヨハネの第一の手紙 1:8–10; ルカによる福音書 15:21"> 立って、父のところへ帰って、こう言おう、父よ、わたしは天に対しても、あなたにむかっても、罪を犯しました。</span>
<span className="v" id="v19" data-v="19" data-xref="ヨブ記 42:6; ルカによる福音書 5:8; 詩篇 84:10"> もう、あなたのむすこと呼ばれる資格はありません。どうぞ、雇人のひとり同様にしてください』。</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 103:10–13; 詩篇 86:5; 詩篇 86:15"> そこで立って、父のところへ出かけた。まだ遠く離れていたのに、父は彼をみとめ、哀れに思って走り寄り、その首をだいて接吻した。</span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 51:4; ルカによる福音書 15:18–19; エレミヤ書 3:13"> むすこは父に言った、『父よ、わたしは天に対しても、あなたにむかっても、罪を犯しました。もうあなたのむすこと呼ばれる資格はありません』。</span>
<span className="v" id="v22" data-v="22" data-xref="創世記 41:42; エステル記 8:2; ヨハネの黙示録 6:11"> しかし父は僕たちに言いつけた、『さあ、早く、最上の着物を出してきてこの子に着せ、指輪を手にはめ、はきものを足にはかせなさい。</span>
<span className="v" id="v23" data-v="23" data-xref="イザヤ書 25:6; マタイによる福音書 22:2–14; 詩篇 63:5"> また、肥えた子牛を引いてきてほふりなさい。食べて楽しもうではないか。</span>
<span className="v" id="v24" data-v="24" data-xref="エペソ人への手紙 2:5; エゼキエル書 34:16; ルカによる福音書 19:10"> このむすこが死んでいたのに生き返り、いなくなっていたのに見つかったのだから』。それから祝宴がはじまった。</span>
<span className="v" id="v25" data-v="25" data-xref="詩篇 150:4; エレミヤ書 31:4; ルカによる福音書 15:11–12"> ところが、兄は畑にいたが、帰ってきて家に近づくと、音楽や踊りの音が聞えたので、</span>
<span className="v" id="v26" data-v="26"> ひとりの僕を呼んで、『いったい、これは何事なのか』と尋ねた。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行伝 9:17; ピレモンヘの手紙 1:16; 使徒行伝 22:13"> 僕は答えた、『あなたのご兄弟がお帰りになりました。無事に迎えたというので、父上が肥えた子牛をほふらせなさったのです』。</span>
<span className="v" id="v28" data-v="28" data-xref="ヨナ書 4:9; サムエル記上 18:8; ヨナ書 4:1–4"> 兄はおこって家にはいろうとしなかったので、父が出てきてなだめると、</span>
<span className="v" id="v29" data-v="29" data-xref="ルカによる福音書 18:11–12; ゼカリヤ書 7:3; イザヤ書 65:5"> 兄は父にむかって言った、『わたしは何か年もあなたに仕えて、一度でもあなたの言いつけにそむいたことはなかったのに、友だちと楽しむために子やぎ一匹も下さったことはありません。</span>
<span className="v" id="v30" data-v="30" data-xref="箴言 29:3; ルカによる福音書 15:12–13; ルカによる福音書 15:32"> それだのに、遊女どもと一緒になって、あなたの身代を食いつぶしたこのあなたの子が帰ってくると、そのために肥えた子牛をほふりなさいました』。</span>
<span className="v" id="v31" data-v="31" data-xref="マルコによる福音書 7:27–28; ローマ人への手紙 9:4; ローマ人への手紙 11:1"> すると父は言った、『子よ、あなたはいつもわたしと一緒にいるし、またわたしのものは全部あなたのものだ。</span>
<span className="v" id="v32" data-v="32" data-xref="エペソ人への手紙 2:1–10; ルカによる福音書 15:24; イザヤ書 35:10"> しかし、このあなたの弟は、死んでいたのに生き返り、いなくなっていたのに見つかったのだから、喜び祝うのはあたりまえである』」。</span>
</div>

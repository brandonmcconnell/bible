<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ペテロの第一の手紙 4:17–18; 哀歌 2:20; エゼキエル書 9:5–7"> ちょうどその時、ある人々がきて、ピラトがガリラヤ人たちの血を流し、それを彼らの犠牲の血に混ぜたことを、イエスに知らせた。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネによる福音書 9:2; 使徒行伝 28:4; ヨブ記 22:5–16"> そこでイエスは答えて言われた、「それらのガリラヤ人が、そのような災難にあったからといって、他のすべてのガリラヤ人以上に罪が深かったと思うのか。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行伝 3:19; マタイによる福音書 3:2; 使徒行伝 2:38–40"> あなたがたに言うが、そうではない。あなたがたも悔い改めなければ、みな同じように滅びるであろう。</span>
<span className="v" id="v4" data-v="4" data-xref="ネヘミヤ書 3:15; ヨブ記 1:19; ヨハネによる福音書 9:11"> また、シロアムの塔が倒れたためにおし殺されたあの十八人は、エルサレムの他の全住民以上に罪の負債があったと思うか。</span>
<span className="v" id="v5" data-v="5" data-xref="エゼキエル書 18:30; ルカによる福音書 13:3; イザヤ書 28:10–13"> あなたがたに言うが、そうではない。あなたがたも悔い改めなければ、みな同じように滅びるであろう」。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="ヨハネによる福音書 15:16; イザヤ書 5:1–4; ガラテヤ人への手紙 5:22"> それから、この譬を語られた、「ある人が自分のぶどう園にいちじくの木を植えて置いたので、実を捜しにきたが見つからなかった。</span>
<span className="v" id="v7" data-v="7" data-xref="マタイによる福音書 7:19; ルカによる福音書 3:9; ヨハネによる福音書 15:6"> そこで園丁に言った、『わたしは三年間も実を求めて、このいちじくの木のところにきたのだが、いまだに見あたらない。その木を切り倒してしまえ。なんのために、土地をむだにふさがせて置くのか』。</span>
<span className="v" id="v8" data-v="8" data-xref="ペテロの第二の手紙 3:9; ヨエル書 2:17; ローマ人への手紙 10:1"> すると園丁は答えて言った、『ご主人様、ことしも、そのままにして置いてください。そのまわりを掘って肥料をやって見ますから。</span>
<span className="v" id="v9" data-v="9" data-xref="ヨハネによる福音書 15:2; テサロニケ人への第一の手紙 2:15; ヘブル人への手紙 6:8"> それで来年実がなりましたら結構です。もしそれでもだめでしたら、切り倒してください』」。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="マタイによる福音書 4:23; ルカによる福音書 4:44; ルカによる福音書 4:15–16"> 安息日に、ある会堂で教えておられると、</span>
<span className="v" id="v11" data-v="11" data-xref="ルカによる福音書 8:2; ルカによる福音書 8:27; ルカによる福音書 13:16"> そこに十八年間も病気の霊につかれ、かがんだままで、からだを伸ばすことの全くできない女がいた。</span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 107:20; マタイによる福音書 8:16; ルカによる福音書 6:8–10"> イエスはこの女を見て、呼びよせ、「女よ、あなたの病気はなおった」と言って、</span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 107:20–22; マルコによる福音書 16:18; マルコによる福音書 5:23"> 手をその上に置かれた。すると立ちどころに、そのからだがまっすぐになり、そして神をたたえはじめた。</span>
<span className="v" id="v14" data-v="14" data-xref="出エジプト記 20:9; マタイによる福音書 12:2; ヨハネによる福音書 9:14–16"> ところが会堂司は、イエスが安息日に病気をいやされたことを憤り、群衆にむかって言った、「働くべき日は六日ある。その間に、なおしてもらいにきなさい。安息日にはいけない」。</span>
<span className="v" id="v15" data-v="15" data-xref="ルカによる福音書 14:5; ヨハネによる福音書 7:21–24; 使徒行伝 13:9–10"> 主はこれに答えて言われた、「偽善者たちよ、あなたがたはだれでも、安息日であっても、自分の牛やろばを家畜小屋から解いて、水を飲ませに引き出してやるではないか。</span>
<span className="v" id="v16" data-v="16" data-xref="マルコによる福音書 2:27; テモテヘの第二の手紙 2:26; ルカによる福音書 19:9"> それなら、十八年間もサタンに縛られていた、アブラハムの娘であるこの女を、安息日であっても、その束縛から解いてやるべきではなかったか」。</span>
<span className="v" id="v17" data-v="17" data-xref="ペテロの第一の手紙 3:16; 詩篇 132:18; イザヤ書 45:24"> こう言われたので、イエスに反対していた人たちはみな恥じ入った。そして群衆はこぞって、イエスがなされたすべてのすばらしいみわざを見て喜んだ。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="マルコによる福音書 4:30–34; ルカによる福音書 17:21; マタイによる福音書 13:31–32"> そこで言われた、「神の国は何に似ているか。またそれを何にたとえようか。</span>
<span className="v" id="v19" data-v="19" data-xref="ダニエル書 4:12; ダニエル書 4:21; ダニエル書 2:44–45"> 一粒のからし種のようなものである。ある人がそれを取って庭にまくと、育って木となり、空の鳥もその枝に宿るようになる」。</span>
<span className="v" id="v20" data-v="20"> また言われた、「神の国を何にたとえようか。</span>
<span className="v" id="v21" data-v="21" data-xref="マタイによる福音書 13:33; コリント人への第一の手紙 5:6; テサロニケ人への第一の手紙 5:23–24"> パン種のようなものである。女がそれを取って三斗の粉の中に混ぜると、全体がふくらんでくる」。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="ルカによる福音書 9:51; マタイによる福音書 9:35; マルコによる福音書 10:32–34"> さてイエスは教えながら町々村々を通り過ぎ、エルサレムへと旅を続けられた。</span>
<span className="v" id="v23" data-v="23" data-xref="マタイによる福音書 7:14; マタイによる福音書 22:14; ヨハネによる福音書 21:21–22"> すると、ある人がイエスに、「主よ、救われる人は少ないのですか」と尋ねた。</span>
<span className="v" id="v24" data-v="24" data-xref="マタイによる福音書 7:13–14; ペテロの第二の手紙 1:10; コリント人への第一の手紙 9:24–27"> そこでイエスは人々にむかって言われた、「狭い戸口からはいるように努めなさい。事実、はいろうとしても、はいれない人が多いのだから。</span>
<span className="v" id="v25" data-v="25" data-xref="マタイによる福音書 25:10–12; ルカによる福音書 13:27; マタイによる福音書 7:21–23"> 家の主人が立って戸を閉じてしまってから、あなたがたが外に立ち戸をたたき始めて、『ご主人様、どうぞあけてください』と言っても、主人はそれに答えて、『あなたがたがどこからきた人なのか、わたしは知らない』と言うであろう。</span>
<span className="v" id="v26" data-v="26" data-xref="イザヤ書 58:2; テトスヘの手紙 1:16; テモテヘの第二の手紙 3:5"> そのとき、『わたしたちはあなたとご一緒に飲み食いしました。また、あなたはわたしたちの大通りで教えてくださいました』と言い出しても、</span>
<span className="v" id="v27" data-v="27" data-xref="詩篇 6:8; マタイによる福音書 25:41; マタイによる福音書 7:22–23"> 彼は、『あなたがたがどこからきた人なのか、わたしは知らない。悪事を働く者どもよ、みんな行ってしまえ』と言うであろう。</span>
<span className="v" id="v28" data-v="28" data-xref="マタイによる福音書 8:11–12; マタイによる福音書 22:13; マタイによる福音書 25:30"> あなたがたは、アブラハム、イサク、ヤコブやすべての預言者たちが、神の国にはいっているのに、自分たちは外に投げ出されることになれば、そこで泣き叫んだり、歯がみをしたりするであろう。</span>
<span className="v" id="v29" data-v="29" data-xref="イザヤ書 43:6; イザヤ書 66:18–20; イザヤ書 49:6"> それから人々が、東から西から、また南から北からきて、神の国で宴会の席につくであろう。</span>
<span className="v" id="v30" data-v="30" data-xref="マタイによる福音書 19:30; マルコによる福音書 10:31; マタイによる福音書 20:16"> こうしてあとのもので先になるものがあり、また、先のものであとになるものもある」。</span>
</div>
<div className="bp poetry">
<span className="v" id="v31" data-v="31" data-xref="ネヘミヤ書 6:9–11; 詩篇 11:1–2; マタイによる福音書 14:1"> ちょうどその時、あるパリサイ人たちが、イエスに近寄ってきて言った、「ここから出て行きなさい。ヘロデがあなたを殺そうとしています」。</span>
<span className="v" id="v32" data-v="32" data-xref="ヘブル人への手紙 2:10; ヘブル人への手紙 5:9; ヨハネによる福音書 17:4–5"> そこで彼らに言われた、「あのきつねのところへ行ってこう言え、『見よ、わたしはきょうもあすも悪霊を追い出し、また、病気をいやし、そして三日目にわざを終えるであろう。</span>
<span className="v" id="v33" data-v="33" data-xref="ルカによる福音書 9:53; マタイによる福音書 21:11; 使徒行伝 13:27"> しかし、きょうもあすも、またその次の日も、わたしは進んで行かねばならない。預言者がエルサレム以外の地で死ぬことは、あり得ないからである』。</span>
<span className="v" id="v34" data-v="34" data-xref="マタイによる福音書 23:37–39; 申命記 32:11–12; 使徒行伝 7:52"> ああ、エルサレム、エルサレム、預言者たちを殺し、おまえにつかわされた人々を石で打ち殺す者よ。ちょうどめんどりが翼の下にひなを集めるように、わたしはおまえの子らを幾たび集めようとしたことであろう。それだのに、おまえたちは応じようとしなかった。</span>
<span className="v" id="v35" data-v="35" data-xref="詩篇 118:26; マルコによる福音書 11:9–10; マタイによる福音書 21:9"> 見よ、おまえたちの家は見捨てられてしまう。わたしは言って置く、<br /><span className="pl pl-1">『主の名によってきたるものに、祝福あれ』</span><br />とおまえたちが言う時の来るまでは、再びわたしに会うことはないであろう」。</span>
</div>

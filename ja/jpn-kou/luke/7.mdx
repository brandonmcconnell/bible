<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マタイによる福音書 8:5–13; ルカによる福音書 7:1–10; マタイによる福音書 7:28–29"> イエスはこれらの言葉をことごとく人々に聞かせてしまったのち、カペナウムに帰ってこられた。</span>
<span className="v" id="v2" data-v="2" data-xref="列王紀下 5:2–3; 創世記 24:27; ヨハネによる福音書 4:46–47"> ところが、ある百卒長の頼みにしていた僕が、病気になって死にかかっていた。</span>
<span className="v" id="v3" data-v="3" data-xref="マタイによる福音書 8:5; ヨハネによる福音書 4:47; ルカによる福音書 9:38"> この百卒長はイエスのことを聞いて、ユダヤ人の長老たちをイエスのところにつかわし、自分の僕を助けにきてくださるようにと、お願いした。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネの黙示録 3:4; マタイによる福音書 10:11; ルカによる福音書 7:6–7"> 彼らはイエスのところにきて、熱心に願って言った、「あの人はそうしていただくねうちがございます。</span>
<span className="v" id="v5" data-v="5" data-xref="歴代志下 2:11–12; 歴代志上 29:3–9; 列王紀上 5:1"> わたしたちの国民を愛し、わたしたちのために会堂を建ててくれたのです」。</span>
<span className="v" id="v6" data-v="6" data-xref="マルコによる福音書 5:24; 創世記 32:10; ヤコブの手紙 4:6"> そこで、イエスは彼らと連れだってお出かけになった。ところが、その家からほど遠くないあたりまでこられたとき、百卒長は友だちを送ってイエスに言わせた、「主よ、どうぞ、ご足労くださいませんように。わたしの屋根の下にあなたをお入れする資格は、わたしにはございません。</span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 107:20; 詩篇 33:9; ルカによる福音書 4:36"> それですから、自分でお迎えにあがるねうちさえないと思っていたのです。ただ、お言葉を下さい。そして、わたしの僕をなおしてください。</span>
<span className="v" id="v8" data-v="8" data-xref="コロサイ人への手紙 3:22; 使徒行伝 23:17; 使徒行伝 22:25–26"> わたしも権威の下に服している者ですが、わたしの下にも兵卒がいまして、ひとりの者に『行け』と言えば行き、ほかの者に『こい』と言えばきますし、また、僕に『これをせよ』と言えば、してくれるのです」。</span>
<span className="v" id="v9" data-v="9" data-xref="マタイによる福音書 15:28; ローマ人への手紙 3:1–3; マタイによる福音書 8:10"> イエスはこれを聞いて非常に感心され、ついてきた群衆の方に振り向いて言われた、「あなたがたに言っておくが、これほどの信仰は、イスラエルの中でも見たことがない」。</span>
<span className="v" id="v10" data-v="10" data-xref="ヨハネによる福音書 4:50–53; マタイによる福音書 8:13; マタイによる福音書 15:28"> 使にきた者たちが家に帰ってみると、僕は元気になっていた。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="使徒行伝 10:38"> そののち、間もなく、ナインという町へおいでになったが、弟子たちや大ぜいの群衆も一緒に行った。</span>
<span className="v" id="v12" data-v="12" data-xref="ルカによる福音書 8:42; ルカによる福音書 8:52; 列王紀上 17:9"> 町の門に近づかれると、ちょうど、あるやもめにとってひとりむすこであった者が死んだので、葬りに出すところであった。大ぜいの町の人たちが、その母につきそっていた。</span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 103:13; イザヤ書 63:9; 詩篇 86:15"> 主はこの婦人を見て深い同情を寄せられ、「泣かないでいなさい」と言われた。</span>
<span className="v" id="v14" data-v="14" data-xref="ヨハネによる福音書 5:25; ヨハネによる福音書 11:43–44; 使徒行伝 9:40–41"> そして近寄って棺に手をかけられると、かついでいる者たちが立ち止まったので、「若者よ、さあ、起きなさい」と言われた。</span>
<span className="v" id="v15" data-v="15" data-xref="列王紀下 13:21; 列王紀下 4:32–37; 列王紀上 17:23–24"> すると、死人が起き上がって物を言い出した。イエスは彼をその母にお渡しになった。</span>
<span className="v" id="v16" data-v="16" data-xref="マタイによる福音書 9:8; ルカによる福音書 7:39; ルカによる福音書 1:68"> 人々はみな恐れをいだき、「大預言者がわたしたちの間に現れた」、また、「神はその民を顧みてくださった」と言って、神をほめたたえた。</span>
<span className="v" id="v17" data-v="17" data-xref="マタイによる福音書 4:24; マルコによる福音書 6:14; マタイによる福音書 9:26"> イエスについてのこの話は、ユダヤ全土およびその附近のいたる所にひろまった。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="ヨハネによる福音書 3:26; マタイによる福音書 11:2–19"> ヨハネの弟子たちは、これらのことを全部彼に報告した。するとヨハネは弟子の中からふたりの者を呼んで、</span>
<span className="v" id="v19" data-v="19" data-xref="イザヤ書 9:6–7; ヨハネによる福音書 4:25; 創世記 22:18"> 主のもとに送り、「『きたるべきかた』はあなたなのですか。それとも、ほかにだれかを待つべきでしょうか」と尋ねさせた。</span>
<span className="v" id="v20" data-v="20" data-xref="ルカによる福音書 7:19"> そこで、この人たちがイエスのもとにきて言った、「わたしたちはバプテスマのヨハネからの使ですが、『きたるべきかた』はあなたなのですか、それとも、ほかにだれかを待つべきでしょうか、とヨハネが尋ねています」。</span>
<span className="v" id="v21" data-v="21" data-xref="マルコによる福音書 3:10; 詩篇 90:7–9; ヘブル人への手紙 12:6"> そのとき、イエスはさまざまの病苦と悪霊とに悩む人々をいやし、また多くの盲人を見えるようにしておられたが、</span>
<span className="v" id="v22" data-v="22" data-xref="イザヤ書 35:5–6; イザヤ書 61:1–3; ルカによる福音書 4:18"> 答えて言われた、「行って、あなたがたが見聞きしたことを、ヨハネに報告しなさい。盲人は見え、足なえは歩き、らい病人はきよまり、耳しいは聞え、死人は生きかえり、貧しい人々は福音を聞かされている。</span>
<span className="v" id="v23" data-v="23" data-xref="マタイによる福音書 11:6; ペテロの第一の手紙 2:7–8; ローマ人への手紙 9:32–33"> わたしにつまずかない者は、さいわいである」。</span>
</div>
<div className="bp poetry">
<span className="v" id="v24" data-v="24" data-xref="エペソ人への手紙 4:14; ヨハネによる福音書 1:23; ルカによる福音書 1:80"> ヨハネの使が行ってしまうと、イエスはヨハネのことを群衆に語りはじめられた、「あなたがたは、何を見に荒野に出てきたのか。風に揺らぐ葦であるか。</span>
<span className="v" id="v25" data-v="25" data-xref="イザヤ書 59:17; エステル記 8:15; エステル記 1:3"> では、何を見に出てきたのか。柔らかい着物をまとった人か。きらびやかに着かざって、ぜいたくに暮している人々なら、宮殿にいる。</span>
<span className="v" id="v26" data-v="26" data-xref="ルカによる福音書 1:76; ヨハネによる福音書 5:35; ルカによる福音書 20:6"> では、何を見に出てきたのか。預言者か。そうだ、あなたがたに言うが、預言者以上の者である。</span>
<span className="v" id="v27" data-v="27" data-xref="マラキ書 3:1; ルカによる福音書 1:76; マルコによる福音書 1:2"> <span className="pl pl-1">『見よ、わたしは使をあなたの先につかわし、</span><br /><span className="pl pl-1">あなたの前に、道を整えさせるであろう』</span><br />と書いてあるのは、この人のことである。</span>
<span className="v" id="v28" data-v="28" data-xref="マタイによる福音書 13:16–17; マタイによる福音書 11:11; コロサイ人への手紙 1:25–27"> あなたがたに言っておく。女の産んだ者の中で、ヨハネより大きい人物はいない。しかし、神の国で最も小さい者も、彼よりは大きい。</span>
<span className="v" id="v29" data-v="29" data-xref="ルカによる福音書 3:12; ルカによる福音書 7:35; 使徒行伝 18:25"> （これを聞いた民衆は皆、また取税人たちも、ヨハネのバプテスマを受けて神の正しいことを認めた。</span>
<span className="v" id="v30" data-v="30" data-xref="ルカによる福音書 13:34; コリント人への第二の手紙 6:1; マタイによる福音書 22:35"> しかし、パリサイ人と律法学者たちとは彼からバプテスマを受けないで、自分たちに対する神のみこころを無にした。）</span>
<span className="v" id="v31" data-v="31" data-xref="マタイによる福音書 11:16–19; 哀歌 2:13; マルコによる福音書 4:30"> だから今の時代の人々を何に比べようか。彼らは何に似ているか。</span>
<span className="v" id="v32" data-v="32" data-xref="マタイによる福音書 11:16–19; エレミヤ書 5:3–5; 箴言 17:16"> それは子供たちが広場にすわって、互に呼びかけ、<br /><span className="pl pl-1">『わたしたちが笛を吹いたのに、</span><br /><span className="pl pl-1">あなたたちは踊ってくれなかった。</span><br /><span className="pl pl-1">弔いの歌を歌ったのに、</span><br /><span className="pl pl-1">泣いてくれなかった』</span><br />と言うのに似ている。</span>
<span className="v" id="v33" data-v="33" data-xref="ルカによる福音書 1:15; マルコによる福音書 1:6; ヨハネによる福音書 8:52"> なぜなら、バプテスマのヨハネがきて、パンを食べることも、ぶどう酒を飲むこともしないと、あなたがたは、あれは悪霊につかれているのだ、と言い、</span>
<span className="v" id="v34" data-v="34" data-xref="ルカによる福音書 15:2; ルカによる福音書 7:36; ヨハネによる福音書 12:2"> また人の子がきて食べたり飲んだりしていると、見よ、あれは食をむさぼる者、大酒を飲む者、また取税人、罪人の仲間だ、と言う。</span>
<span className="v" id="v35" data-v="35" data-xref="箴言 8:32–36; マタイによる福音書 11:19; ホセア書 14:9"> しかし、知恵の正しいことは、そのすべての子が証明する」。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="マルコによる福音書 14:3–9; マタイによる福音書 26:5–6; ルカによる福音書 14:1"> あるパリサイ人がイエスに、食事を共にしたいと申し出たので、そのパリサイ人の家にはいって食卓に着かれた。</span>
<span className="v" id="v37" data-v="37" data-xref="マルコによる福音書 14:3–9; マタイによる福音書 26:6–13; マタイによる福音書 21:31"> するとそのとき、その町で罪の女であったものが、パリサイ人の家で食卓に着いておられることを聞いて、香油が入れてある石膏のつぼを持ってきて、</span>
<span className="v" id="v38" data-v="38" data-xref="詩篇 126:5–6; 詩篇 51:17; 創世記 18:4"> 泣きながら、イエスのうしろでその足もとに寄り、まず涙でイエスの足をぬらし、自分の髪の毛でぬぐい、そして、その足に接吻して、香油を塗った。</span>
<span className="v" id="v39" data-v="39" data-xref="ルカによる福音書 7:16; ルカによる福音書 15:2; マルコによる福音書 7:21"> イエスを招いたパリサイ人がそれを見て、心の中で言った、「もしこの人が預言者であるなら、自分にさわっている女がだれだか、どんな女かわかるはずだ。それは罪の女なのだから」。</span>
<span className="v" id="v40" data-v="40" data-xref="ヨハネによる福音書 16:19; ルカによる福音書 5:31; エゼキエル書 33:31"> そこでイエスは彼にむかって言われた、「シモン、あなたに言うことがある」。彼は「先生、おっしゃってください」と言った。</span>
<span className="v" id="v41" data-v="41" data-xref="ルカによる福音書 7:47; ローマ人への手紙 5:20; マタイによる福音書 18:28"> イエスが言われた、「ある金貸しに金をかりた人がふたりいたが、ひとりは五百デナリ、もうひとりは五十デナリを借りていた。</span>
<span className="v" id="v42" data-v="42" data-xref="ダニエル書 9:18–19; コロサイ人への手紙 3:13; ローマ人への手紙 3:24"> ところが、返すことができなかったので、彼はふたり共ゆるしてやった。このふたりのうちで、どちらが彼を多く愛するだろうか」。</span>
<span className="v" id="v43" data-v="43" data-xref="詩篇 116:16–18; テモテヘの第一の手紙 1:13–16; ルカによる福音書 7:47"> シモンが答えて言った、「多くゆるしてもらったほうだと思います」。イエスが言われた、「あなたの判断は正しい」。</span>
<span className="v" id="v44" data-v="44" data-xref="テモテヘの第一の手紙 5:10; 士師記 19:21; 創世記 18:4"> それから女の方に振り向いて、シモンに言われた、「この女を見ないか。わたしがあなたの家にはいってきた時に、あなたは足を洗う水をくれなかった。ところが、この女は涙でわたしの足をぬらし、髪の毛でふいてくれた。</span>
<span className="v" id="v45" data-v="45" data-xref="サムエル記下 15:5; サムエル記下 19:39; ローマ人への手紙 16:16"> あなたはわたしに接吻をしてくれなかったが、彼女はわたしが家にはいった時から、わたしの足に接吻をしてやまなかった。</span>
<span className="v" id="v46" data-v="46" data-xref="詩篇 23:5; 伝道の書 9:8; マタイによる福音書 6:17"> あなたはわたしの頭に油を塗ってくれなかったが、彼女はわたしの足に香油を塗ってくれた。</span>
<span className="v" id="v47" data-v="47" data-xref="ヨハネの第一の手紙 4:19; ヨハネの第一の手紙 3:18; イザヤ書 1:18"> それであなたに言うが、この女は多く愛したから、その多くの罪はゆるされているのである。少しだけゆるされた者は、少しだけしか愛さない」。</span>
<span className="v" id="v48" data-v="48" data-xref="マタイによる福音書 9:2; マルコによる福音書 2:5; ルカによる福音書 5:20"> そして女に、「あなたの罪はゆるされた」と言われた。</span>
<span className="v" id="v49" data-v="49" data-xref="ルカによる福音書 5:20–21; マタイによる福音書 9:3; マルコによる福音書 2:7"> すると同席の者たちが心の中で言いはじめた、「罪をゆるすことさえするこの人は、いったい、何者だろう」。</span>
<span className="v" id="v50" data-v="50" data-xref="マルコによる福音書 5:34; ルカによる福音書 8:48; ルカによる福音書 18:42"> しかし、イエスは女にむかって言われた、「あなたの信仰があなたを救ったのです。安心して行きなさい」。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="詩篇 19:14; ルカによる福音書 22:39–45; ローマ人への手紙 8:26–27"> また、イエスはある所で祈っておられたが、それが終ったとき、弟子のひとりが言った、「主よ、ヨハネがその弟子たちに教えたように、わたしたちにも祈ることを教えてください」。</span>
<span className="v" id="v2" data-v="2" data-xref="マタイによる福音書 6:6–15; 伝道の書 5:2; 詩篇 72:18–19"> そこで彼らに言われた、「祈るときには、こう言いなさい、『父よ、御名があがめられますように。御国がきますように。</span>
<span className="v" id="v3" data-v="3" data-xref="マタイによる福音書 6:11; マタイによる福音書 6:34; 箴言 30:8"> わたしたちの日ごとの食物を、日々お与えください。</span>
<span className="v" id="v4" data-v="4" data-xref="マタイによる福音書 6:12–15; マタイによる福音書 26:41; イザヤ書 43:25–26"> わたしたちに負債のある者を皆ゆるしますから、わたしたちの罪をもおゆるしください。わたしたちを試みに会わせないでください』」。</span>
<span className="v" id="v5" data-v="5" data-xref="ルカによる福音書 18:1–8"> そして彼らに言われた、「あなたがたのうちのだれかに、友人があるとして、その人のところへ真夜中に行き、『友よ、パンを三つ貸してください。</span>
<span className="v" id="v6" data-v="6"> 友だちが旅先からわたしのところに着いたのですが、何も出すものがありませんから』と言った場合、</span>
<span className="v" id="v7" data-v="7" data-xref="ルカによる福音書 13:25; ガラテヤ人への手紙 6:17; ルカによる福音書 7:6"> 彼は内から、『面倒をかけないでくれ。もう戸は締めてしまったし、子供たちもわたしと一緒に床にはいっているので、いま起きて何もあげるわけにはいかない』と言うであろう。</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 32:26; コロサイ人への手紙 4:12; ローマ人への手紙 15:30"> しかし、よく聞きなさい、友人だからというのでは起きて与えないが、しきりに願うので、起き上がって必要なものを出してくれるであろう。</span>
<span className="v" id="v9" data-v="9" data-xref="マルコによる福音書 11:24; ヨハネによる福音書 16:23–24; マタイによる福音書 21:22"> そこでわたしはあなたがたに言う。求めよ、そうすれば、与えられるであろう。捜せ、そうすれば見いだすであろう。門をたたけ、そうすれば、あけてもらえるであろう。</span>
<span className="v" id="v10" data-v="10" data-xref="ヤコブの手紙 4:3; 哀歌 3:54–58; 詩篇 31:22"> すべて求める者は得、捜す者は見いだし、門をたたく者はあけてもらえるからである。</span>
<span className="v" id="v11" data-v="11" data-xref="マタイによる福音書 7:9; イザヤ書 49:15"> あなたがたのうちで、父であるものは、その子が魚を求めるのに、魚の代りにへびを与えるだろうか。</span>
<span className="v" id="v12" data-v="12" data-xref="ヨハネの黙示録 9:10; ルカによる福音書 10:19; エゼキエル書 2:6"> 卵を求めるのに、さそりを与えるだろうか。</span>
<span className="v" id="v13" data-v="13" data-xref="マタイによる福音書 7:11; イザヤ書 44:3–4; ローマ人への手紙 8:32"> このように、あなたがたは悪い者であっても、自分の子供には、良い贈り物をすることを知っているとすれば、天の父はなおさら、求めて来る者に聖霊を下さらないことがあろうか」。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="マタイによる福音書 12:22–24; マタイによる福音書 9:32–34; マルコによる福音書 7:32–37"> さて、イエスが悪霊を追い出しておられた。それは、おしの霊であった。悪霊が出て行くと、おしが物を言うようになったので、群衆は不思議に思った。</span>
<span className="v" id="v15" data-v="15" data-xref="マタイによる福音書 9:34; マタイによる福音書 12:24–30; ヨハネによる福音書 8:48"> その中のある人々が、「彼は悪霊のかしらベルゼブルによって、悪霊どもを追い出しているのだ」と言い、</span>
<span className="v" id="v16" data-v="16" data-xref="ヨハネによる福音書 6:30; コリント人への第一の手紙 1:22; マルコによる福音書 8:11–12"> またほかの人々は、イエスを試みようとして、天からのしるしを求めた。</span>
<span className="v" id="v17" data-v="17" data-xref="マルコによる福音書 3:23–27; マタイによる福音書 12:25–29; イザヤ書 19:2–3"> しかしイエスは、彼らの思いを見抜いて言われた、「おおよそ国が内部で分裂すれば自滅してしまい、また家が分れ争えば倒れてしまう。</span>
<span className="v" id="v18" data-v="18" data-xref="マタイによる福音書 12:26; マタイによる福音書 12:31–34; ルカによる福音書 11:15"> そこでサタンも内部で分裂すれば、その国はどうして立ち行けよう。あなたがたはわたしがベルゼブルによって悪霊を追い出していると言うが、</span>
<span className="v" id="v19" data-v="19" data-xref="ルカによる福音書 9:49; ヨブ記 15:6; ローマ人への手紙 3:19"> もしわたしがベルゼブルによって悪霊を追い出すとすれば、あなたがたの仲間はだれによって追い出すのであろうか。だから、彼らがあなたがたをさばく者となるであろう。</span>
<span className="v" id="v20" data-v="20" data-xref="出エジプト記 8:19; マタイによる福音書 12:28; ルカによる福音書 10:9"> しかし、わたしが神の指によって悪霊を追い出しているのなら、神の国はすでにあなたがたのところにきたのである。</span>
<span className="v" id="v21" data-v="21" data-xref="マルコによる福音書 3:27; マタイによる福音書 12:29"> 強い人が十分に武装して自分の邸宅を守っている限り、その持ち物は安全である。</span>
<span className="v" id="v22" data-v="22" data-xref="イザヤ書 49:24–25; イザヤ書 53:12; ヨハネの第一の手紙 3:8"> しかし、もっと強い者が襲ってきて彼に打ち勝てば、その頼みにしていた武具を奪って、その分捕品を分けるのである。</span>
<span className="v" id="v23" data-v="23" data-xref="マタイによる福音書 12:30; ルカによる福音書 9:50; マルコによる福音書 9:40"> わたしの味方でない者は、わたしに反対するものであり、わたしと共に集めない者は、散らすものである。</span>
<span className="v" id="v24" data-v="24" data-xref="マタイによる福音書 12:43–45; ペテロの第一の手紙 5:8; ヨブ記 2:2"> 汚れた霊が人から出ると、休み場を求めて水の無い所を歩きまわるが、見つからないので、出てきた元の家に帰ろうと言って、</span>
<span className="v" id="v25" data-v="25" data-xref="テサロニケ人への第二の手紙 2:9–12; ペテロの第二の手紙 2:10–19; ユダの手紙 1:8–13"> 帰って見ると、その家はそうじがしてある上、飾りつけがしてあった。</span>
<span className="v" id="v26" data-v="26" data-xref="ヨハネによる福音書 5:14; マタイによる福音書 12:45; ペテロの第二の手紙 2:20–22"> そこでまた出て行って、自分以上に悪い他の七つの霊を引き連れてきて中にはいり、そこに住み込む。そうすると、その人の後の状態は初めよりももっと悪くなるのである」。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="ルカによる福音書 1:42; ルカによる福音書 1:48; ルカによる福音書 23:29"> イエスがこう話しておられるとき、群衆の中からひとりの女が声を張りあげて言った、「あなたを宿した胎、あなたが吸われた乳房は、なんとめぐまれていることでしょう」。</span>
<span className="v" id="v28" data-v="28" data-xref="ルカによる福音書 6:47–48; ルカによる福音書 8:21; 詩篇 112:1"> しかしイエスは言われた、「いや、めぐまれているのは、むしろ、神の言を聞いてそれを守る人たちである」。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="ルカによる福音書 11:16; マルコによる福音書 8:11–12; コリント人への第一の手紙 1:22"> さて群衆が群がり集まったので、イエスは語り出された、「この時代は邪悪な時代である。それはしるしを求めるが、ヨナのしるしのほかには、なんのしるしも与えられないであろう。</span>
<span className="v" id="v30" data-v="30" data-xref="マタイによる福音書 12:40–42; ヨナ書 1:17; ヨナ書 3:2–10"> というのは、ニネベの人々に対してヨナがしるしとなったように、人の子もこの時代に対してしるしとなるであろう。</span>
<span className="v" id="v31" data-v="31" data-xref="歴代志下 9:1; 列王紀上 10:1–13; ローマ人への手紙 2:27"> 南の女王が、今の時代の人々と共にさばきの場に立って、彼らを罪に定めるであろう。なぜなら、彼女はソロモンの知恵を聞くために、地の果からはるばるきたからである。しかし見よ、ソロモンにまさる者がここにいる。</span>
<span className="v" id="v32" data-v="32" data-xref="ヘブル人への手紙 7:26; ルカによる福音書 11:31; ヨナ書 3:5–4"> ニネベの人々が、今の時代の人々と共にさばきの場に立って、彼らを罪に定めるであろう。なぜなら、ニネベの人々はヨナの宣教によって悔い改めたからである。しかし見よ、ヨナにまさる者がここにいる。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="ルカによる福音書 8:16–17; マルコによる福音書 4:21–22; マタイによる福音書 5:15–16"> だれもあかりをともして、それを穴倉の中や枡の下に置くことはしない。むしろはいって来る人たちに、そのあかりが見えるように、燭台の上におく。</span>
<span className="v" id="v34" data-v="34" data-xref="マタイによる福音書 6:22–23; 使徒行伝 26:18; エレミヤ書 5:21"> あなたの目は、からだのあかりである。あなたの目が澄んでおれば、全身も明るいが、目がわるければ、からだも暗い。</span>
<span className="v" id="v35" data-v="35" data-xref="箴言 16:25; ペテロの第二の手紙 1:9; ヤコブの手紙 3:13–17"> だから、あなたの内なる光が暗くならないように注意しなさい。</span>
<span className="v" id="v36" data-v="36" data-xref="箴言 20:27; 箴言 6:23; 箴言 4:18–19"> もし、あなたのからだ全体が明るくて、暗い部分が少しもなければ、ちょうど、あかりが輝いてあなたを照す時のように、全身が明るくなるであろう」。</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="ルカによる福音書 7:36; コリント人への第一の手紙 9:19–23; ルカによる福音書 14:1"> イエスが語っておられた時、あるパリサイ人が、自分の家で食事をしていただきたいと申し出たので、はいって食卓につかれた。</span>
<span className="v" id="v38" data-v="38" data-xref="マタイによる福音書 15:2–3; マルコによる福音書 7:2–5; ヨハネによる福音書 3:25"> ところが、食前にまず洗うことをなさらなかったのを見て、そのパリサイ人が不思議に思った。</span>
<span className="v" id="v39" data-v="39" data-xref="テトスヘの手紙 1:15; 箴言 30:12; 創世記 6:5"> そこで主は彼に言われた、「いったい、あなたがたパリサイ人は、杯や盆の外側をきよめるが、あなたがたの内側は貪欲と邪悪とで満ちている。</span>
<span className="v" id="v40" data-v="40" data-xref="ルカによる福音書 12:20; コリント人への第一の手紙 15:36; マタイによる福音書 23:26"> 愚かな者たちよ、外側を造ったかたは、また内側も造られたではないか。</span>
<span className="v" id="v41" data-v="41" data-xref="ルカによる福音書 12:33; ヤコブの手紙 1:27; テトスヘの手紙 1:15"> ただ、内側にあるものをきよめなさい。そうすれば、いっさいがあなたがたにとって、清いものとなる。</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="マタイによる福音書 23:23; ルカによる福音書 18:12; 箴言 21:3"> しかし、あなた方パリサイ人は、わざわいである。はっか、うん香、あらゆる野菜などの十分の一を宮に納めておりながら、義と神に対する愛とをなおざりにしている。それもなおざりにはできないが、これは行わねばならない。</span>
<span className="v" id="v43" data-v="43" data-xref="ルカによる福音書 20:46; マルコによる福音書 12:38–39; ルカによる福音書 14:7–11"> あなたがたパリサイ人は、わざわいである。会堂の上席や広場での敬礼を好んでいる。</span>
<span className="v" id="v44" data-v="44" data-xref="マタイによる福音書 23:27–28; 詩篇 5:9; 使徒行伝 23:3"> あなたがたは、わざわいである。人目につかない墓のようなものである。その上を歩いても人々は気づかないでいる」。</span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="ヨハネによる福音書 9:40; マタイによる福音書 22:35; エレミヤ書 6:10"> ひとりの律法学者がイエスに答えて言った、「先生、そんなことを言われるのは、わたしたちまでも侮辱することです」。</span>
<span className="v" id="v46" data-v="46" data-xref="ルカによる福音書 11:52; イザヤ書 10:1; マタイによる福音書 23:2–4"> そこで言われた、「あなたがた律法学者も、わざわいである。負い切れない重荷を人に負わせながら、自分ではその荷に指一本でも触れようとしない。</span>
<span className="v" id="v47" data-v="47" data-xref="テサロニケ人への第一の手紙 2:15; 使徒行伝 7:51; マタイによる福音書 23:29–33"> あなたがたは、わざわいである。預言者たちの碑を建てるが、しかし彼らを殺したのは、あなたがたの先祖であったのだ。</span>
<span className="v" id="v48" data-v="48" data-xref="ヤコブの手紙 5:10; マタイによる福音書 23:31; 歴代志下 36:16"> だから、あなたがたは、自分の先祖のしわざに同意する証人なのだ。先祖が彼らを殺し、あなたがたがその碑を建てるのだから。</span>
<span className="v" id="v49" data-v="49" data-xref="コリント人への第一の手紙 1:30; コロサイ人への手紙 2:3; エペソ人への手紙 4:11"> それゆえに、『神の知恵』も言っている、『わたしは預言者と使徒とを彼らにつかわすが、彼らはそのうちのある者を殺したり、迫害したりするであろう』。</span>
<span className="v" id="v50" data-v="50" data-xref="創世記 9:5–6; ヨハネの黙示録 18:20–24; 列王紀下 24:4"> それで、アベルの血から祭壇と神殿との間で殺されたザカリヤの血に至るまで、世の初めから流されてきたすべての預言者の血について、この時代がその責任を問われる。</span>
<span className="v" id="v51" data-v="51" data-xref="歴代志下 24:20–22; マタイによる福音書 23:35; ヘブル人への手紙 11:4"> そうだ、あなたがたに言っておく、この時代がその責任を問われるであろう。</span>
<span className="v" id="v52" data-v="52" data-xref="マタイによる福音書 23:13; マラキ書 2:7; ルカによる福音書 11:45–46"> あなたがた律法学者は、わざわいである。知識のかぎを取りあげて、自分がはいらないばかりか、はいろうとする人たちを妨げてきた」。</span>
</div>
<div className="bp">
<span className="v" id="v53" data-v="53" data-xref="コリント人への第一の手紙 13:5; エレミヤ書 20:10; ルカによる福音書 20:20"> イエスがそこを出て行かれると、律法学者やパリサイ人は、激しく詰め寄り、いろいろな事を問いかけて、</span>
<span className="v" id="v54" data-v="54" data-xref="マルコによる福音書 12:13; マタイによる福音書 22:15; マタイによる福音書 22:35"> イエスの口から何か言いがかりを得ようと、ねらいはじめた。</span>
</div>

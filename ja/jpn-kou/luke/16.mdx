<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ペテロの第一の手紙 4:10; マタイによる福音書 25:14–30; ヤコブの手紙 4:3"> イエスはまた、弟子たちに言われた、「ある金持のところにひとりの家令がいたが、彼は主人の財産を浪費していると、告げ口をする者があった。</span>
<span className="v" id="v2" data-v="2" data-xref="伝道の書 11:9–10; ペテロの第一の手紙 4:5; ヨハネの黙示録 20:12"> そこで主人は彼を呼んで言った、『あなたについて聞いていることがあるが、あれはどうなのか。あなたの会計報告を出しなさい。もう家令をさせて置くわけにはいかないから』。</span>
<span className="v" id="v3" data-v="3" data-xref="エレミヤ書 5:31; イザヤ書 10:3; 箴言 18:9"> この家令は心の中で思った、『どうしようか。主人がわたしの職を取り上げようとしている。土を掘るには力がないし、物ごいするのは恥ずかしい。</span>
<span className="v" id="v4" data-v="4" data-xref="箴言 30:9; エレミヤ書 4:22; ヤコブの手紙 3:15"> そうだ、わかった。こうしておけば、職をやめさせられる場合、人々がわたしをその家に迎えてくれるだろう』。</span>
<span className="v" id="v5" data-v="5" data-xref="ルカによる福音書 7:41–42; マタイによる福音書 18:24"> それから彼は、主人の負債者をひとりびとり呼び出して、初めの人に、『あなたは、わたしの主人にどれだけ負債がありますか』と尋ねた。</span>
<span className="v" id="v6" data-v="6" data-xref="テトスヘの手紙 2:10; ルカによる福音書 16:12; ルカによる福音書 16:9"> 『油百樽です』と答えた。そこで家令が言った、『ここにあなたの証書がある。すぐそこにすわって、五十樽と書き変えなさい』。</span>
<span className="v" id="v7" data-v="7" data-xref="雅歌 8:11–12; ルカによる福音書 20:9; ルカによる福音書 20:12"> 次に、もうひとりに、『あなたの負債はどれだけですか』と尋ねると、『麦百石です』と答えた。これに対して、『ここに、あなたの証書があるが、八十石と書き変えなさい』と言った。</span>
<span className="v" id="v8" data-v="8" data-xref="テサロニケ人への第一の手紙 5:5; エペソ人への手紙 5:8; 箴言 6:6–8"> ところが主人は、この不正な家令の利口なやり方をほめた。この世の子らはその時代に対しては、光の子らよりも利口である。</span>
<span className="v" id="v9" data-v="9" data-xref="マタイによる福音書 19:21; テモテヘの第一の手紙 6:17–19; ダニエル書 4:27"> またあなたがたに言うが、不正の富を用いてでも、自分のために友だちをつくるがよい。そうすれば、富が無くなった場合、あなたがたを永遠のすまいに迎えてくれるであろう。</span>
<span className="v" id="v10" data-v="10" data-xref="ルカによる福音書 16:11–12; マタイによる福音書 25:21; ルカによる福音書 19:17"> 小事に忠実な人は、大事にも忠実である。そして、小事に不忠実な人は大事にも不忠実である。</span>
<span className="v" id="v11" data-v="11" data-xref="ルカによる福音書 12:33; ヤコブの手紙 2:5; 箴言 8:18–19"> だから、もしあなたがたが不正の富について忠実でなかったら、だれが真の富を任せるだろうか。</span>
<span className="v" id="v12" data-v="12" data-xref="ルカによる福音書 19:13–26; マタイによる福音書 25:14–29; ヨブ記 1:21"> また、もしほかの人のものについて忠実でなかったら、だれがあなたがたのものを与えてくれようか。</span>
<span className="v" id="v13" data-v="13" data-xref="ヨハネの第一の手紙 2:15–16; マタイによる福音書 6:24; ヤコブの手紙 4:4"> どの僕でも、ふたりの主人に兼ね仕えることはできない。一方を憎んで他方を愛し、あるいは、一方に親しんで他方をうとんじるからである。あなたがたは、神と富とに兼ね仕えることはできない」。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="ルカによる福音書 23:35; ルカによる福音書 20:47; エレミヤ書 6:13"> 欲の深いパリサイ人たちが、すべてこれらの言葉を聞いて、イエスをあざ笑った。</span>
<span className="v" id="v15" data-v="15" data-xref="サムエル記上 16:7; 箴言 21:2; コリント人への第一の手紙 4:5"> そこで彼らにむかって言われた、「あなたがたは、人々の前で自分を正しいとする人たちである。しかし、神はあなたがたの心をご存じである。人々の間で尊ばれるものは、神のみまえでは忌みきらわれる。</span>
<span className="v" id="v16" data-v="16" data-xref="マタイによる福音書 11:9–14; マタイによる福音書 21:32; 使徒行伝 3:24–25"> 律法と預言者とはヨハネの時までのものである。それ以来、神の国が宣べ伝えられ、人々は皆これに突入している。</span>
<span className="v" id="v17" data-v="17" data-xref="マタイによる福音書 5:18; ルカによる福音書 21:33; ペテロの第一の手紙 1:25"> しかし、律法の一画が落ちるよりは、天地の滅びる方が、もっとたやすい。</span>
<span className="v" id="v18" data-v="18" data-xref="マタイによる福音書 19:9; マルコによる福音書 10:11–12; マタイによる福音書 5:31–32"> すべて自分の妻を出して他の女をめとる者は、姦淫を行うものであり、また、夫から出された女をめとる者も、姦淫を行うものである。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="エゼキエル書 16:49; アモス書 6:4–6; ルカによる福音書 18:24–25"> ある金持がいた。彼は紫の衣や細布を着て、毎日ぜいたくに遊び暮していた。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行伝 3:2; サムエル記上 2:8; ヤコブの手紙 2:5"> ところが、ラザロという貧乏人が全身でき物でおおわれて、この金持の玄関の前にすわり、</span>
<span className="v" id="v21" data-v="21" data-xref="マタイによる福音書 15:27; マルコによる福音書 7:28; ヨハネによる福音書 6:12"> その食卓から落ちるもので飢えをしのごうと望んでいた。その上、犬がきて彼のでき物をなめていた。</span>
<span className="v" id="v22" data-v="22" data-xref="ペテロの第一の手紙 2:24; 詩篇 49:16–19; ヤコブの手紙 1:11"> この貧乏人がついに死に、御使たちに連れられてアブラハムのふところに送られた。金持も死んで葬られた。</span>
<span className="v" id="v23" data-v="23" data-xref="ペテロの第二の手紙 2:4; ルカによる福音書 16:28; マタイによる福音書 18:9"> そして黄泉にいて苦しみながら、目をあげると、アブラハムとそのふところにいるラザロとが、はるかに見えた。</span>
<span className="v" id="v24" data-v="24" data-xref="ヨハネによる福音書 4:10; ヨハネの黙示録 22:1; ヨハネの黙示録 7:16–17"> そこで声をあげて言った、『父、アブラハムよ、わたしをあわれんでください。ラザロをおつかわしになって、その指先を水でぬらし、わたしの舌を冷やさせてください。わたしはこの火炎の中で苦しみもだえています』。</span>
<span className="v" id="v25" data-v="25" data-xref="ルカによる福音書 6:24; ヨハネの第一の手紙 2:15; 詩篇 17:14"> アブラハムが言った、『子よ、思い出すがよい。あなたは生前よいものを受け、ラザロの方は悪いものを受けた。しかし今ここでは、彼は慰められ、あなたは苦しみもだえている。</span>
<span className="v" id="v26" data-v="26" data-xref="ヨハネによる福音書 3:36; 詩篇 49:14; 詩篇 50:22"> そればかりか、わたしたちとあなたがたとの間には大きな淵がおいてあって、こちらからあなたがたの方へ渡ろうと思ってもできないし、そちらからわたしたちの方へ越えて来ることもできない』。</span>
<span className="v" id="v27" data-v="27"> そこで金持が言った、『父よ、ではお願いします。わたしの父の家へラザロをつかわしてください。</span>
<span className="v" id="v28" data-v="28" data-xref="使徒行伝 2:40; 詩篇 49:12–13; テサロニケ人への第一の手紙 4:6"> わたしに五人の兄弟がいますので、こんな苦しい所へ来ることがないように、彼らに警告していただきたいのです』。</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行伝 15:21; ルカによる福音書 24:27; ルカによる福音書 16:16"> アブラハムは言った、『彼らにはモーセと預言者とがある。それに聞くがよかろう』。</span>
<span className="v" id="v30" data-v="30" data-xref="ヨハネの黙示録 16:9–11; ルカによる福音書 16:24; ルカによる福音書 13:5"> 金持が言った、『いえいえ、父アブラハムよ、もし死人の中からだれかが兄弟たちのところへ行ってくれましたら、彼らは悔い改めるでしょう』。</span>
<span className="v" id="v31" data-v="31" data-xref="コリント人への第二の手紙 4:3; 使徒行伝 19:8; ヨハネによる福音書 11:43–53"> アブラハムは言った、『もし彼らがモーセと預言者とに耳を傾けないなら、死人の中からよみがえってくる者があっても、彼らはその勧めを聞き入れはしないであろう』」。</span>

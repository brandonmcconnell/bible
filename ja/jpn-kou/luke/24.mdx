<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨハネによる福音書 20:1–2; マルコによる福音書 16:1–8; マタイによる福音書 28:1–8"> 週の初めの日、夜明け前に、女たちは用意しておいた香料を携えて、墓に行った。</span>
<span className="v" id="v2" data-v="2" data-xref="マルコによる福音書 16:3–4; マタイによる福音書 27:60–66; マルコによる福音書 15:46–47"> ところが、石が墓からころがしてあるので、</span>
<span className="v" id="v3" data-v="3" data-xref="ルカによる福音書 24:23; ヨハネによる福音書 20:6–7; マタイによる福音書 16:5"> 中にはいってみると、主イエスのからだが見当らなかった。</span>
<span className="v" id="v4" data-v="4" data-xref="マルコによる福音書 16:5; ヨハネによる福音書 20:11–12; 使徒行伝 1:10"> そのため途方にくれていると、見よ、輝いた衣を着たふたりの者が、彼らに現れた。</span>
<span className="v" id="v5" data-v="5" data-xref="マルコによる福音書 16:5–6; マタイによる福音書 28:3–5; ヨハネの黙示録 1:18"> 女たちは驚き恐れて、顔を地に伏せていると、このふたりの者が言った、「あなたがたは、なぜ生きた方を死人の中にたずねているのか。</span>
<span className="v" id="v6" data-v="6" data-xref="マタイによる福音書 17:22–23; ルカによる福音書 9:22; マルコによる福音書 8:31"> そのかたは、ここにはおられない。よみがえられたのだ。まだガリラヤにおられたとき、あなたがたにお話しになったことを思い出しなさい。</span>
<span className="v" id="v7" data-v="7" data-xref="マタイによる福音書 16:21"> すなわち、人の子は必ず罪人らの手に渡され、十字架につけられ、そして三日目によみがえる、と仰せられたではないか」。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨハネによる福音書 12:16; ヨハネによる福音書 14:26; ヨハネによる福音書 2:19–22"> そこで女たちはその言葉を思い出し、</span>
<span className="v" id="v9" data-v="9" data-xref="ルカによる福音書 24:22–24; マルコによる福音書 16:7–8; マタイによる福音書 28:7–8"> 墓から帰って、これらいっさいのことを、十一弟子や、その他みんなの人に報告した。</span>
<span className="v" id="v10" data-v="10" data-xref="マタイによる福音書 27:56; ヨハネによる福音書 20:11–18; ルカによる福音書 8:2–3"> この女たちというのは、マグダラのマリヤ、ヨハンナ、およびヤコブの母マリヤであった。彼女たちと一緒にいたほかの女たちも、このことを使徒たちに話した。</span>
<span className="v" id="v11" data-v="11" data-xref="ヨブ記 9:16; マルコによる福音書 16:11; 創世記 19:14"> ところが、使徒たちには、それが愚かな話のように思われて、それを信じなかった。〔</span>
<span className="v" id="v12" data-v="12" data-xref="ヨハネによる福音書 20:3–10"> ペテロは立って墓へ走って行き、かがんで中を見ると、亜麻布だけがそこにあったので、事の次第を不思議に思いながら帰って行った。〕</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="ルカによる福音書 24:18; マルコによる福音書 16:12–13"> この日、ふたりの弟子が、エルサレムから七マイルばかり離れたエマオという村へ行きながら、</span>
<span className="v" id="v14" data-v="14" data-xref="ルカによる福音書 6:45; 申命記 6:7; マラキ書 3:6"> このいっさいの出来事について互に語り合っていた。</span>
<span className="v" id="v15" data-v="15" data-xref="マタイによる福音書 18:20; ヨハネによる福音書 14:18–19; ルカによる福音書 24:36"> 語り合い論じ合っていると、イエスご自身が近づいてきて、彼らと一緒に歩いて行かれた。</span>
<span className="v" id="v16" data-v="16" data-xref="ヨハネによる福音書 20:14; ヨハネによる福音書 21:4; ルカによる福音書 24:31"> しかし、彼らの目がさえぎられて、イエスを認めることができなかった。</span>
<span className="v" id="v17" data-v="17" data-xref="ヨハネによる福音書 16:20–22; ヨハネによる福音書 16:6; エゼキエル書 9:4–6"> イエスは彼らに言われた、「歩きながら互に語り合っているその話は、なんのことなのか」。彼らは悲しそうな顔をして立ちどまった。</span>
<span className="v" id="v18" data-v="18" data-xref="ヨハネによる福音書 19:25"> そのひとりのクレオパという者が、答えて言った、「あなたはエルサレムに泊まっていながら、あなただけが、この都でこのごろ起ったことをご存じないのですか」。</span>
<span className="v" id="v19" data-v="19" data-xref="マタイによる福音書 21:11; 使徒行伝 7:22; ヨハネによる福音書 4:19"> 「それは、どんなことか」と言われると、彼らは言った、「ナザレのイエスのことです。あのかたは、神とすべての民衆との前で、わざにも言葉にも力ある預言者でしたが、</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行伝 3:13–15; 使徒行伝 4:8–10; ルカによる福音書 23:13"> 祭司長たちや役人たちが、死刑に処するために引き渡し、十字架につけたのです。</span>
<span className="v" id="v21" data-v="21" data-xref="ルカによる福音書 1:68; ペテロの第一の手紙 1:18–19; ルカによる福音書 2:38"> わたしたちは、イスラエルを救うのはこの人であろうと、望みをかけていました。しかもその上に、この事が起ってから、きょうが三日目なのです。</span>
<span className="v" id="v22" data-v="22" data-xref="マルコによる福音書 16:9–10; マタイによる福音書 28:7–8; ヨハネによる福音書 20:1–2"> ところが、わたしたちの仲間である数人の女が、わたしたちを驚かせました。というのは、彼らが朝早く墓に行きますと、</span>
<span className="v" id="v23" data-v="23"> イエスのからだが見当らないので、帰ってきましたが、そのとき御使が現れて、『イエスは生きておられる』と告げたと申すのです。</span>
<span className="v" id="v24" data-v="24" data-xref="ルカによる福音書 24:12; ヨハネによる福音書 20:1–10"> それで、わたしたちの仲間が数人、墓に行って見ますと、果して女たちが言ったとおりで、イエスは見当りませんでした」。</span>
<span className="v" id="v25" data-v="25" data-xref="マルコによる福音書 7:18; マルコによる福音書 9:19; ヘブル人への手紙 5:11–12"> そこでイエスが言われた、「ああ、愚かで心のにぶいため、預言者たちが説いたすべての事を信じられない者たちよ。</span>
<span className="v" id="v26" data-v="26" data-xref="ペテロの第一の手紙 1:11; イザヤ書 53:1–12; ゼカリヤ書 13:7"> キリストは必ず、これらの苦難を受けて、その栄光に入るはずではなかったのか」。</span>
<span className="v" id="v27" data-v="27" data-xref="イザヤ書 7:14; ルカによる福音書 24:44; 申命記 18:15"> こう言って、モーセやすべての預言者からはじめて、聖書全体にわたり、ご自身についてしるしてある事どもを、説きあかされた。</span>
<span className="v" id="v28" data-v="28" data-xref="マルコによる福音書 6:48; 創世記 19:2; 創世記 32:26"> それから、彼らは行こうとしていた村に近づいたが、イエスがなお先へ進み行かれる様子であった。</span>
<span className="v" id="v29" data-v="29" data-xref="列王紀下 4:8; ルカによる福音書 14:23; 創世記 19:3"> そこで、しいて引き止めて言った、「わたしたちと一緒にお泊まり下さい。もう夕暮になっており、日もはや傾いています」。イエスは、彼らと共に泊まるために、家にはいられた。</span>
<span className="v" id="v30" data-v="30" data-xref="マタイによる福音書 14:19; ルカによる福音書 24:35; マタイによる福音書 15:36"> 一緒に食卓につかれたとき、パンを取り、祝福してさき、彼らに渡しておられるうちに、</span>
<span className="v" id="v31" data-v="31" data-xref="ルカによる福音書 24:16; ヨハネによる福音書 8:59; ルカによる福音書 4:30"> 彼らの目が開けて、それがイエスであることがわかった。すると、み姿が見えなくなった。</span>
<span className="v" id="v32" data-v="32" data-xref="ルカによる福音書 24:45; エレミヤ書 23:29; ヘブル人への手紙 4:12"> 彼らは互に言った、「道々お話しになったとき、また聖書を説き明してくださったとき、お互の心が内に燃えたではないか」。</span>
<span className="v" id="v33" data-v="33" data-xref="マルコによる福音書 16:13; ヨハネによる福音書 20:19–26; 使徒行伝 1:14"> そして、すぐに立ってエルサレムに帰って見ると、十一弟子とその仲間が集まっていて、</span>
<span className="v" id="v34" data-v="34" data-xref="コリント人への第一の手紙 15:5; マルコによる福音書 16:7; ルカによる福音書 22:54–62"> 「主は、ほんとうによみがえって、シモンに現れなさった」と言っていた。</span>
<span className="v" id="v35" data-v="35" data-xref="マルコによる福音書 16:12–13; 使徒行伝 2:42; ルカによる福音書 24:30–31"> そこでふたりの者は、途中であったことや、パンをおさきになる様子でイエスだとわかったことなどを話した。</span>
<span className="v" id="v36" data-v="36" data-xref="テサロニケ人への第二の手紙 3:16; イザヤ書 57:18; マルコによる福音書 16:14"> こう話していると、イエスが彼らの中にお立ちになった。〔そして「やすかれ」と言われた。〕</span>
<span className="v" id="v37" data-v="37" data-xref="サムエル記上 28:13; マタイによる福音書 14:26–27; ヨブ記 4:14–16"> 彼らは恐れ驚いて、霊を見ているのだと思った。</span>
<span className="v" id="v38" data-v="38" data-xref="エレミヤ書 4:14; ヘブル人への手紙 4:13; ダニエル書 4:19"> そこでイエスが言われた、「なぜおじ惑っているのか。どうして心に疑いを起すのか。</span>
<span className="v" id="v39" data-v="39" data-xref="ヨハネによる福音書 20:27; ヨハネの第一の手紙 1:1; 伝道の書 12:7"> わたしの手や足を見なさい。まさしくわたしなのだ。さわって見なさい。霊には肉や骨はないが、あなたがたが見るとおり、わたしにはあるのだ」。〔</span>
<span className="v" id="v40" data-v="40"> こう言って、手と足とをお見せになった。〕</span>
<span className="v" id="v41" data-v="41" data-xref="ヨハネによる福音書 21:5; 詩篇 126:1–2; 創世記 45:26–28"> 彼らは喜びのあまり、まだ信じられないで不思議に思っていると、イエスが「ここに何か食物があるか」と言われた。</span>
<span className="v" id="v42" data-v="42"> 彼らが焼いた魚の一きれをさしあげると、</span>
<span className="v" id="v43" data-v="43" data-xref="使徒行伝 10:41"> イエスはそれを取って、みんなの前で食べられた。</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="ゼカリヤ書 12:10; ルカによる福音書 24:26–27; ゼカリヤ書 9:9"> それから彼らに対して言われた、「わたしが以前あなたがたと一緒にいた時分に話して聞かせた言葉は、こうであった。すなわち、モーセの律法と預言書と詩篇とに、わたしについて書いてあることは、必ずことごとく成就する」。</span>
<span className="v" id="v45" data-v="45" data-xref="使徒行伝 16:14; ヨハネの第一の手紙 5:20; 詩篇 119:18"> そこでイエスは、聖書を悟らせるために彼らの心を開いて</span>
<span className="v" id="v46" data-v="46" data-xref="イザヤ書 53:2–12; イザヤ書 50:6; ルカによる福音書 24:44"> 言われた、「こう、しるしてある。キリストは苦しみを受けて、三日目に死人の中からよみがえる。</span>
<span className="v" id="v47" data-v="47" data-xref="使徒行伝 5:31; イザヤ書 49:6; 使徒行伝 2:38"> そして、その名によって罪のゆるしを得させる悔改めが、エルサレムからはじまって、もろもろの国民に宣べ伝えられる。</span>
<span className="v" id="v48" data-v="48" data-xref="使徒行伝 1:8; 使徒行伝 2:32; 使徒行伝 13:31"> あなたがたは、これらの事の証人である。</span>
<span className="v" id="v49" data-v="49" data-xref="使徒行伝 1:8; 使徒行伝 1:4; ヨエル書 2:28–32"> 見よ、わたしの父が約束されたものを、あなたがたに贈る。だから、上から力を授けられるまでは、あなたがたは都にとどまっていなさい」。</span>
</div>
<div className="bp">
<span className="v" id="v50" data-v="50" data-xref="使徒行伝 1:12; マタイによる福音書 21:17; マルコによる福音書 11:1"> それから、イエスは彼らをベタニヤの近くまで連れて行き、手をあげて彼らを祝福された。</span>
<span className="v" id="v51" data-v="51" data-xref="使徒行伝 1:9; マルコによる福音書 16:19; 列王紀下 2:11"> 祝福しておられるうちに、彼らを離れて、〔天にあげられた。〕</span>
<span className="v" id="v52" data-v="52" data-xref="マタイによる福音書 28:9; ヨハネによる福音書 16:22; 詩篇 30:11"> 彼らは〔イエスを拝し、〕非常な喜びをもってエルサレムに帰り、</span>
<span className="v" id="v53" data-v="53" data-xref="マルコによる福音書 16:20; 使徒行伝 2:46–47; 使徒行伝 5:41–42"> 絶えず宮にいて、神をほめたたえていた。</span>
</div>

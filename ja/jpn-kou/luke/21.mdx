<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マルコによる福音書 12:41–44; ヨハネによる福音書 8:20; マタイによる福音書 27:6"> イエスは目をあげて、金持たちがさいせん箱に献金を投げ入れるのを見られ、</span>
<span className="v" id="v2" data-v="2" data-xref="マルコによる福音書 12:42"> また、ある貧しいやもめが、レプタ二つを入れるのを見て</span>
<span className="v" id="v3" data-v="3" data-xref="コリント人への第二の手紙 8:12; 使徒行伝 10:34; コリント人への第二の手紙 8:2–3"> 言われた、「よく聞きなさい。あの貧しいやもめはだれよりもたくさん入れたのだ。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行伝 2:44–45; ルカによる福音書 15:12; 使徒行伝 4:34"> これらの人たちはみな、ありあまる中から献金を投げ入れたが、あの婦人は、その乏しい中から、持っている生活費全部を入れたからである」。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="ヨハネによる福音書 2:20; マタイによる福音書 24:1–51; マルコによる福音書 13:1–37"> ある人々が、見事な石と奉納物とで宮が飾られていることを話していたので、イエスは言われた、</span>
<span className="v" id="v6" data-v="6" data-xref="マタイによる福音書 24:2; マルコによる福音書 13:2; 哀歌 5:18"> 「あなたがたはこれらのものをながめているが、その石一つでもくずされずに、他の石の上に残ることもなくなる日が、来るであろう」。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行伝 1:6–7; マルコによる福音書 13:14; マルコによる福音書 13:3–4"> そこで彼らはたずねた、「先生、では、いつそんなことが起るのでしょうか。またそんなことが起るような場合には、どんな前兆がありますか」。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨハネの第一の手紙 4:1; マルコによる福音書 13:5–6; エペソ人への手紙 5:6"> イエスが言われた、「あなたがたは、惑わされないように気をつけなさい。多くの者がわたしの名を名のって現れ、自分がそれだとか、時が近づいたとか、言うであろう。彼らについて行くな。</span>
<span className="v" id="v9" data-v="9" data-xref="ルカによる福音書 21:28; マタイによる福音書 24:6–8; マルコによる福音書 13:7–8"> 戦争と騒乱とのうわさを聞くときにも、おじ恐れるな。こうしたことはまず起らねばならないが、終りはすぐにはこない」。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="使徒行伝 2:19–20; マルコによる福音書 13:8; 歴代志下 15:5–6"> それから彼らに言われた、「民は民に、国は国に敵対して立ち上がるであろう。</span>
<span className="v" id="v11" data-v="11" data-xref="マタイによる福音書 24:29–30; ルカによる福音書 21:25–27"> また大地震があり、あちこちに疫病やききんが起り、いろいろ恐ろしいことや天からの物すごい前兆があるであろう。</span>
<span className="v" id="v12" data-v="12" data-xref="ペテロの第一の手紙 4:12–14; 使徒行伝 5:40; 使徒行伝 22:30"> しかし、これらのあらゆる出来事のある前に、人々はあなたがたに手をかけて迫害をし、会堂や獄に引き渡し、わたしの名のゆえに王や総督の前にひっぱって行くであろう。</span>
<span className="v" id="v13" data-v="13" data-xref="ピリピ人への手紙 1:12; ピリピ人への手紙 1:28; テサロニケ人への第二の手紙 1:5"> それは、あなたがたがあかしをする機会となるであろう。</span>
<span className="v" id="v14" data-v="14" data-xref="ルカによる福音書 12:11–12; マルコによる福音書 13:11; マタイによる福音書 10:19–20"> だから、どう答弁しようかと、前もって考えておかないことに心を決めなさい。</span>
<span className="v" id="v15" data-v="15" data-xref="エレミヤ書 1:9; エペソ人への手紙 6:19; ルカによる福音書 12:12"> あなたの反対者のだれもが抗弁も否定もできないような言葉と知恵とを、わたしが授けるから。</span>
<span className="v" id="v16" data-v="16" data-xref="ルカによる福音書 12:53; ヨハネの黙示録 6:9; ミカ書 7:5–6"> しかし、あなたがたは両親、兄弟、親族、友人にさえ裏切られるであろう。また、あなたがたの中で殺されるものもあろう。</span>
<span className="v" id="v17" data-v="17" data-xref="ヨハネによる福音書 15:19; ルカによる福音書 6:22; ヨハネによる福音書 15:21"> また、わたしの名のゆえにすべての人に憎まれるであろう。</span>
<span className="v" id="v18" data-v="18" data-xref="マタイによる福音書 10:30; サムエル記上 14:45; ルカによる福音書 12:7"> しかし、あなたがたの髪の毛一すじでも失われることはない。</span>
<span className="v" id="v19" data-v="19" data-xref="ヘブル人への手紙 10:36; マタイによる福音書 10:22; ヤコブの手紙 1:3"> あなたがたは耐え忍ぶことによって、自分の魂をかち取るであろう。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="ルカによる福音書 19:43; ダニエル書 9:27; マルコによる福音書 13:14"> エルサレムが軍隊に包囲されるのを見たならば、そのときは、その滅亡が近づいたとさとりなさい。</span>
<span className="v" id="v21" data-v="21" data-xref="エレミヤ書 6:1; 創世記 19:17; ルカによる福音書 17:31–33"> そのとき、ユダヤにいる人々は山へ逃げよ。市中にいる者は、そこから出て行くがよい。また、いなかにいる者は市内にはいってはいけない。</span>
<span className="v" id="v22" data-v="22" data-xref="ホセア書 9:7; イザヤ書 65:12–16; イザヤ書 63:4"> それは、聖書にしるされたすべての事が実現する刑罰の日であるからだ。</span>
<span className="v" id="v23" data-v="23" data-xref="マルコによる福音書 13:17; マタイによる福音書 24:19; ルカによる福音書 23:29"> その日には、身重の女と乳飲み子をもつ女とは、不幸である。地上には大きな苦難があり、この民にはみ怒りが臨み、</span>
<span className="v" id="v24" data-v="24" data-xref="ローマ人への手紙 11:25; ヨハネの黙示録 11:2; イザヤ書 63:18"> 彼らはつるぎの刃に倒れ、また捕えられて諸国へ引きゆかれるであろう。そしてエルサレムは、異邦人の時期が満ちるまで、彼らに踏みにじられているであろう。</span>
<span className="v" id="v25" data-v="25" data-xref="イザヤ書 13:10; ヨエル書 2:30–31; ヨハネの黙示録 6:12–14"> また日と月と星とに、しるしが現れるであろう。そして、地上では、諸国民が悩み、海と大波とのとどろきにおじ惑い、</span>
<span className="v" id="v26" data-v="26" data-xref="マタイによる福音書 24:29; 申命記 28:65–67; ペテロの第二の手紙 3:10–12"> 人々は世界に起ろうとする事を思い、恐怖と不安で気絶するであろう。もろもろの天体が揺り動かされるからである。</span>
<span className="v" id="v27" data-v="27" data-xref="マタイによる福音書 24:30; ヨハネの黙示録 1:7; マルコによる福音書 13:26"> そのとき、大いなる力と栄光とをもって、人の子が雲に乗って来るのを、人々は見るであろう。</span>
<span className="v" id="v28" data-v="28" data-xref="ローマ人への手紙 8:23; イザヤ書 60:1–2; エペソ人への手紙 4:30"> これらの事が起りはじめたら、身を起し頭をもたげなさい。あなたがたの救が近づいているのだから」。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="マタイによる福音書 24:32–35; マルコによる福音書 13:28–30"> それから一つの譬を話された、「いちじくの木を、またすべての木を見なさい。</span>
<span className="v" id="v30" data-v="30" data-xref="ルカによる福音書 12:57"> はや芽を出せば、あなたがたはそれを見て、夏がすでに近いと、自分で気づくのである。</span>
<span className="v" id="v31" data-v="31" data-xref="ヤコブの手紙 5:9; ヘブル人への手紙 10:37; ペテロの第一の手紙 4:7"> このようにあなたがたも、これらの事が起るのを見たなら、神の国が近いのだとさとりなさい。</span>
<span className="v" id="v32" data-v="32" data-xref="マルコによる福音書 13:30; マタイによる福音書 24:34; マタイによる福音書 23:36"> よく聞いておきなさい。これらの事が、ことごとく起るまでは、この時代は滅びることがない。</span>
<span className="v" id="v33" data-v="33" data-xref="イザヤ書 40:8; マルコによる福音書 13:31; マタイによる福音書 24:35"> 天地は滅びるであろう。しかしわたしの言葉は決して滅びることがない。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="マルコによる福音書 4:19; ルカによる福音書 12:45–46; ルカによる福音書 12:40"> あなたがたが放縦や、泥酔や、世の煩いのために心が鈍っているうちに、思いがけないとき、その日がわなのようにあなたがたを捕えることがないように、よく注意していなさい。</span>
<span className="v" id="v35" data-v="35" data-xref="ヨハネの黙示録 16:15; 詩篇 11:6; エレミヤ書 48:43–44"> その日は地の全面に住むすべての人に臨むのであるから。</span>
<span className="v" id="v36" data-v="36" data-xref="ヨハネの第一の手紙 2:28; マタイによる福音書 25:13; ペテロの第一の手紙 5:8"> これらの起ろうとしているすべての事からのがれて、人の子の前に立つことができるように、絶えず目をさまして祈っていなさい」。</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="ルカによる福音書 22:39; マルコによる福音書 11:19; マタイによる福音書 21:17"> イエスは昼のあいだは宮で教え、夜には出て行ってオリブという山で夜をすごしておられた。</span>
<span className="v" id="v38" data-v="38" data-xref="ヨハネによる福音書 8:1–2"> 民衆はみな、み教を聞こうとして、いつも朝早く宮に行き、イエスのもとに集まった。</span>
</div>

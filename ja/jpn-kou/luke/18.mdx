<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="コロサイ人への手紙 4:2; ローマ人への手紙 12:12; テサロニケ人への第一の手紙 5:17"> また、イエスは失望せずに常に祈るべきことを、人々に譬で教えられた。</span>
<span className="v" id="v2" data-v="2" data-xref="箴言 29:7; 詩篇 8:1–4; ルカによる福音書 18:4"> 「ある町に、神を恐れず、人を人とも思わぬ裁判官がいた。</span>
<span className="v" id="v3" data-v="3" data-xref="イザヤ書 1:17; エレミヤ書 5:28; 申命記 27:19"> ところが、その同じ町にひとりのやもめがいて、彼のもとにたびたびきて、『どうぞ、わたしを訴える者をさばいて、わたしを守ってください』と願いつづけた。</span>
<span className="v" id="v4" data-v="4" data-xref="ヘブル人への手紙 4:12–13; ルカによる福音書 16:3; ルカによる福音書 12:17"> 彼はしばらくの間きき入れないでいたが、そののち、心のうちで考えた、『わたしは神をも恐れず、人を人とも思わないが、</span>
<span className="v" id="v5" data-v="5" data-xref="ルカによる福音書 11:8; ルカによる福音書 18:39; 士師記 16:16"> このやもめがわたしに面倒をかけるから、彼女のためになる裁判をしてやろう。そうしたら、絶えずやってきてわたしを悩ますことがなくなるだろう』」。</span>
<span className="v" id="v6" data-v="6" data-xref="ルカによる福音書 7:13"> そこで主は言われた、「この不義な裁判官の言っていることを聞いたか。</span>
<span className="v" id="v7" data-v="7" data-xref="ヘブル人への手紙 10:35–37; ペテロの第二の手紙 3:9; ルカによる福音書 11:13"> まして神は、日夜叫び求める選民のために、正しいさばきをしてくださらずに長い間そのままにしておかれることがあろうか。</span>
<span className="v" id="v8" data-v="8" data-xref="ヘブル人への手紙 10:23–26; ペテロの第二の手紙 3:8–9; マタイによる福音書 24:9–13"> あなたがたに言っておくが、神はすみやかにさばいてくださるであろう。しかし、人の子が来るとき、地上に信仰が見られるであろうか」。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="ルカによる福音書 16:15; 箴言 30:12; イザヤ書 65:5"> 自分を義人だと自任して他人を見下げている人たちに対して、イエスはまたこの譬をお話しになった。</span>
<span className="v" id="v10" data-v="10" data-xref="マタイによる福音書 21:31–32; 列王紀上 8:30; 列王紀下 20:5"> 「ふたりの人が祈るために宮に上った。そのひとりはパリサイ人であり、もうひとりは取税人であった。</span>
<span className="v" id="v11" data-v="11" data-xref="マタイによる福音書 6:5; イザヤ書 65:5; ヨハネの黙示録 3:17"> パリサイ人は立って、ひとりでこう祈った、『神よ、わたしはほかの人たちのような貪欲な者、不正な者、姦淫をする者ではなく、また、この取税人のような人間でもないことを感謝します。</span>
<span className="v" id="v12" data-v="12" data-xref="ルカによる福音書 11:42; マタイによる福音書 23:23–24; マタイによる福音書 9:14"> わたしは一週に二度断食しており、全収入の十分の一をささげています』。</span>
<span className="v" id="v13" data-v="13" data-xref="エズラ記 9:6; ヨハネの第一の手紙 1:8–10; テモテヘの第一の手紙 1:15"> ところが、取税人は遠く離れて立ち、目を天にむけようともしないで、胸を打ちながら言った、『神様、罪人のわたしをおゆるしください』と。</span>
<span className="v" id="v14" data-v="14" data-xref="ルカによる福音書 14:11; ルカによる福音書 16:15; ヤコブの手紙 4:10"> あなたがたに言っておく。神に義とされて自分の家に帰ったのは、この取税人であって、あのパリサイ人ではなかった。おおよそ、自分を高くする者は低くされ、自分を低くする者は高くされるであろう」。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="マルコによる福音書 10:13–16; マタイによる福音書 19:13–15; サムエル記上 1:24"> イエスにさわっていただくために、人々が幼な子らをみもとに連れてきた。ところが、弟子たちはそれを見て、彼らをたしなめた。</span>
<span className="v" id="v16" data-v="16" data-xref="マタイによる福音書 18:3–4; コリント人への第一の手紙 14:20; コリント人への第一の手紙 7:14"> するとイエスは幼な子らを呼び寄せて言われた、「幼な子らをわたしのところに来るままにしておきなさい、止めてはならない。神の国はこのような者の国である。</span>
<span className="v" id="v17" data-v="17" data-xref="マタイによる福音書 18:3; マルコによる福音書 10:15; 詩篇 131:1–2"> よく聞いておくがよい。だれでも幼な子のように神の国を受けいれる者でなければ、そこにはいることは決してできない」。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="マルコによる福音書 10:17–31; 使徒行伝 16:30; マタイによる福音書 19:16–30"> また、ある役人がイエスに尋ねた、「よき師よ、何をしたら永遠の生命が受けられましょうか」。</span>
<span className="v" id="v19" data-v="19" data-xref="ヨブ記 15:14–16; ヤコブの手紙 1:17; ヘブル人への手紙 7:26"> イエスは言われた、「なぜわたしをよき者と言うのか。神ひとりのほかによい者はいない。</span>
<span className="v" id="v20" data-v="20" data-xref="出エジプト記 20:12–17; 申命記 5:16–21; ローマ人への手紙 13:9"> いましめはあなたの知っているとおりである、『姦淫するな、殺すな、盗むな、偽証を立てるな、父と母とを敬え』」。</span>
<span className="v" id="v21" data-v="21" data-xref="ピリピ人への手紙 3:6; ローマ人への手紙 10:2–3; マルコによる福音書 10:20–21"> すると彼は言った、「それらのことはみな、小さい時から守っております」。</span>
<span className="v" id="v22" data-v="22" data-xref="ルカによる福音書 12:33; テモテヘの第一の手紙 6:18–19; マタイによる福音書 19:21"> イエスはこれを聞いて言われた、「あなたのする事がまだ一つ残っている。持っているものをみな売り払って、貧しい人々に分けてやりなさい。そうすれば、天に宝を持つようになろう。そして、わたしに従ってきなさい」。</span>
<span className="v" id="v23" data-v="23" data-xref="エゼキエル書 33:31; ヨハネの第一の手紙 2:15; ヨブ記 31:24–25"> 彼はこの言葉を聞いて非常に悲しんだ。大金持であったからである。</span>
<span className="v" id="v24" data-v="24" data-xref="箴言 30:9; ヤコブの手紙 2:5–7; マルコによる福音書 10:23–27"> イエスは彼の様子を見て言われた、「財産のある者が神の国にはいるのはなんとむずかしいことであろう。</span>
<span className="v" id="v25" data-v="25" data-xref="マタイによる福音書 23:24"> 富んでいる者が神の国にはいるよりは、らくだが針の穴を通る方が、もっとやさしい」。</span>
<span className="v" id="v26" data-v="26" data-xref="ルカによる福音書 13:23"> これを聞いた人々が、「それでは、だれが救われることができるのですか」と尋ねると、</span>
<span className="v" id="v27" data-v="27" data-xref="エレミヤ書 32:17; マタイによる福音書 19:26; ルカによる福音書 1:37"> イエスは言われた、「人にはできない事も、神にはできる」。</span>
<span className="v" id="v28" data-v="28" data-xref="マルコによる福音書 10:28; ピリピ人への手紙 3:7; マタイによる福音書 19:27"> ペテロが言った、「ごらんなさい、わたしたちは自分のものを捨てて、あなたに従いました」。</span>
<span className="v" id="v29" data-v="29" data-xref="マルコによる福音書 10:29–31; マタイによる福音書 10:37–39; ルカによる福音書 14:26–28"> イエスは言われた、「よく聞いておくがよい。だれでも神の国のために、家、妻、兄弟、両親、子を捨てた者は、</span>
<span className="v" id="v30" data-v="30" data-xref="ヘブル人への手紙 13:5–6; ヨブ記 42:10; ヨハネの黙示録 2:17"> 必ずこの時代ではその幾倍もを受け、また、きたるべき世では永遠の生命を受けるのである」。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="マタイによる福音書 20:17–19; イザヤ書 53:1–12; 詩篇 22:1–31"> イエスは十二弟子を呼び寄せて言われた、「見よ、わたしたちはエルサレムへ上って行くが、人の子について預言者たちがしるしたことは、すべて成就するであろう。</span>
<span className="v" id="v32" data-v="32" data-xref="ルカによる福音書 23:11; イザヤ書 50:6; イザヤ書 53:3"> 人の子は異邦人に引きわたされ、あざけられ、はずかしめを受け、つばきをかけられ、</span>
<span className="v" id="v33" data-v="33" data-xref="コリント人への第一の手紙 15:3–4; ルカによる福音書 24:7; マタイによる福音書 27:63"> また、むち打たれてから、ついに殺され、そして三日目によみがえるであろう」。</span>
<span className="v" id="v34" data-v="34" data-xref="ルカによる福音書 9:45; マルコによる福音書 9:32; ルカによる福音書 24:25"> 弟子たちには、これらのことが何一つわからなかった。この言葉が彼らに隠されていたので、イエスの言われた事が理解できなかった。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="マタイによる福音書 20:29–34; マルコによる福音書 10:46–52; ルカによる福音書 16:20–21"> イエスがエリコに近づかれたとき、ある盲人が道ばたにすわって、物ごいをしていた。</span>
<span className="v" id="v36" data-v="36" data-xref="マタイによる福音書 21:10–11; ルカによる福音書 15:26"> 群衆が通り過ぎる音を耳にして、彼は何事があるのかと尋ねた。</span>
<span className="v" id="v37" data-v="37" data-xref="マタイによる福音書 2:23; ヨハネによる福音書 19:19; ヨハネによる福音書 12:35–36"> ところが、ナザレのイエスがお通りなのだと聞かされたので、</span>
<span className="v" id="v38" data-v="38" data-xref="マタイによる福音書 9:27; ルカによる福音書 18:39; マタイによる福音書 15:22"> 声をあげて、「ダビデの子イエスよ、わたしをあわれんで下さい」と言った。</span>
<span className="v" id="v39" data-v="39" data-xref="創世記 32:26–28; 詩篇 141:1; ルカによる福音書 18:15"> 先頭に立つ人々が彼をしかって黙らせようとしたが、彼はますます激しく叫びつづけた、「ダビデの子よ、わたしをあわれんで下さい」。</span>
<span className="v" id="v40" data-v="40" data-xref="マタイによる福音書 20:31–34; マルコによる福音書 10:48–52"> そこでイエスは立ちどまって、その者を連れて来るように、とお命じになった。彼が近づいたとき、</span>
<span className="v" id="v41" data-v="41" data-xref="列王紀上 3:5–15; マタイによる福音書 20:21–22; ピリピ人への手紙 4:6"> 「わたしに何をしてほしいのか」とおたずねになると、「主よ、見えるようになることです」と答えた。</span>
<span className="v" id="v42" data-v="42" data-xref="マタイによる福音書 8:3; ルカによる福音書 8:48; ルカによる福音書 17:19"> そこでイエスは言われた、「見えるようになれ。あなたの信仰があなたを救った」。</span>
<span className="v" id="v43" data-v="43" data-xref="詩篇 146:8; テサロニケ人への第二の手紙 1:10–12; イザヤ書 43:21"> すると彼は、たちまち見えるようになった。そして神をあがめながらイエスに従って行った。これを見て、人々はみな神をさんびした。</span>
</div>

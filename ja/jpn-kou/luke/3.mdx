<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="ルカによる福音書 23:24; 創世記 49:10; ルカによる福音書 9:7"> 皇帝テベリオ在位の第十五年、ポンテオ・ピラトがユダヤの総督、ヘロデがガリラヤの領主、その兄弟ピリポがイツリヤ・テラコニテ地方の領主、ルサニヤがアビレネの領主、</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行伝 4:6; ヨハネによる福音書 18:24; ルカによる福音書 1:80"> アンナスとカヤパとが大祭司であったとき、神の言が荒野でザカリヤの子ヨハネに臨んだ。</span>
<span className="v" id="v3" data-v="3" data-xref="ルカによる福音書 1:77; マタイによる福音書 3:5–6; 使徒行伝 13:24"> 彼はヨルダンのほとりの全地方に行って、罪のゆるしを得させる悔改めのバプテスマを宣べ伝えた。</span>
<span className="v" id="v4" data-v="4" data-xref="イザヤ書 40:3–5; ヨハネによる福音書 1:23; ルカによる福音書 1:76–79"> それは、預言者イザヤの言葉の書に書いてあるとおりである。すなわち<br /><span className="pl pl-1">「荒野で呼ばわる者の声がする、</span><br /><span className="pl pl-1">『主の道を備えよ、</span><br /><span className="pl pl-1">その道筋をまっすぐにせよ』。</span></span>
<span className="v" id="v5" data-v="5" data-xref="イザヤ書 40:4; イザヤ書 42:16; イザヤ書 45:2"> <span className="pl pl-1">すべての谷は埋められ、</span><br /><span className="pl pl-1">すべての山と丘とは、平らにされ、</span><br /><span className="pl pl-1">曲ったところはまっすぐに、</span><br /><span className="pl pl-1">わるい道はならされ、</span></span>
<span className="v" id="v6" data-v="6" data-xref="イザヤ書 52:10; イザヤ書 40:5; 詩篇 98:2–3"> <span className="pl pl-1">人はみな神の救を見るであろう」。</span></span>
<span className="v" id="v7" data-v="7" data-xref="マタイによる福音書 23:33; マタイによる福音書 12:34; テサロニケ人への第一の手紙 1:10"> <span className="pl pl-1">さて、ヨハネは、彼からバプテスマを受けようとして出てきた群衆にむかって言った、「まむしの子らよ、迫ってきている神の怒りから、のがれられると、おまえたちにだれが教えたのか。</span></span>
<span className="v" id="v8" data-v="8" data-xref="エゼキエル書 18:27–31; 使徒行伝 26:20; イザヤ書 1:16–18"> <span className="pl pl-1">だから、悔改めにふさわしい実を結べ。自分たちの父にはアブラハムがあるなどと、心の中で思ってもみるな。おまえたちに言っておく。神はこれらの石ころからでも、アブラハムの子を起すことができるのだ。</span></span>
<span className="v" id="v9" data-v="9" data-xref="マタイによる福音書 7:19; ヨハネによる福音書 15:6; ルカによる福音書 13:9"> <span className="pl pl-1">斧がすでに木の根もとに置かれている。だから、良い実を結ばない木はことごとく切られて、火の中に投げ込まれるのだ」。</span></span>
<span className="v" id="v10" data-v="10" data-xref="使徒行伝 2:37; ルカによる福音書 3:14; 使徒行伝 16:30"> <span className="pl pl-1">そこで群衆が彼に、「それでは、わたしたちは何をすればよいのですか」と尋ねた。</span></span>
<span className="v" id="v11" data-v="11" data-xref="イザヤ書 58:7–11; ヨハネの第一の手紙 3:17; テモテヘの第一の手紙 6:18"> <span className="pl pl-1">彼は答えて言った、「下着を二枚もっている者は、持たない者に分けてやりなさい。食物を持っている者も同様にしなさい」。</span></span>
<span className="v" id="v12" data-v="12" data-xref="ルカによる福音書 7:29; ルカによる福音書 15:1–2; ルカによる福音書 18:13"> <span className="pl pl-1">取税人もバプテスマを受けにきて、彼に言った、「先生、わたしたちは何をすればよいのですか」。</span></span>
<span className="v" id="v13" data-v="13" data-xref="ルカによる福音書 19:8; エペソ人への手紙 4:28; コリント人への第一の手紙 6:10"> <span className="pl pl-1">彼らに言った、「きまっているもの以上に取り立ててはいけない」。</span></span>
<span className="v" id="v14" data-v="14" data-xref="ヘブル人への手紙 13:5–6; 出エジプト記 20:16; 出エジプト記 23:1"> <span className="pl pl-1">兵卒たちもたずねて言った、「では、わたしたちは何をすればよいのですか」。彼は言った、「人をおどかしたり、だまし取ったりしてはいけない。自分の給与で満足していなさい」。</span></span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="ヨハネによる福音書 10:24; ヨハネによる福音書 3:28–29; ヨハネによる福音書 1:19–28"> 民衆は救主を待ち望んでいたので、みな心の中でヨハネのことを、もしかしたらこの人がそれではなかろうかと考えていた。</span>
<span className="v" id="v16" data-v="16" data-xref="マタイによる福音書 3:11; 使徒行伝 1:5; 使徒行伝 11:15–16"> そこでヨハネはみんなの者にむかって言った、「わたしは水でおまえたちにバプテスマを授けるが、わたしよりも力のあるかたが、おいでになる。わたしには、そのくつのひもを解く値うちもない。このかたは、聖霊と火とによっておまえたちにバプテスマをお授けになるであろう。</span>
<span className="v" id="v17" data-v="17" data-xref="エレミヤ書 15:7; マタイによる福音書 13:30; ミカ書 4:12"> また、箕を手に持って、打ち場の麦をふるい分け、麦は倉に納め、からは消えない火で焼き捨てるであろう」。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="ヨハネによる福音書 3:29–36; ヨハネによる福音書 1:34; ヨハネによる福音書 1:29"> こうしてヨハネはほかにもなお、さまざまの勧めをして、民衆に教を説いた。</span>
<span className="v" id="v19" data-v="19" data-xref="ルカによる福音書 3:1; マタイによる福音書 11:2; マルコによる福音書 6:17–18"> ところが領主ヘロデは、兄弟の妻ヘロデヤのことで、また自分がしたあらゆる悪事について、ヨハネから非難されていたので、</span>
<span className="v" id="v20" data-v="20" data-xref="歴代志下 24:17–22; ヨハネによる福音書 3:24; テサロニケ人への第一の手紙 2:15–16"> 彼を獄に閉じ込めて、いろいろな悪事の上に、もう一つこの悪事を重ねた。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="ヨハネによる福音書 1:32–34; マタイによる福音書 3:13–17; ヨハネによる福音書 12:27–28"> さて、民衆がみなバプテスマを受けたとき、イエスもバプテスマを受けて祈っておられると、天が開けて、</span>
<span className="v" id="v22" data-v="22" data-xref="詩篇 2:7; ペテロの第二の手紙 1:17–18; ヨハネによる福音書 1:32"> 聖霊がはとのような姿をとってイエスの上に下り、そして天から声がした、「あなたはわたしの愛する子、わたしの心にかなう者である」。</span>
</div>

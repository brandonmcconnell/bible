<div className="bp">
<span className="v" id="v1" data-v="1"> 主からエレミヤに臨んだ言葉。</span>
<span className="v" id="v2" data-v="2" data-xref="ヘブル人への手紙 1:1; 使徒行伝 9:6; エレミヤ書 19:1–2"> 「立って、陶器師の家に下って行きなさい。その所でわたしはあなたにわたしの言葉を聞かせよう」。</span>
<span className="v" id="v3" data-v="3" data-xref="ヨハネによる福音書 15:14; ヨナ書 1:3; 使徒行伝 26:19"> わたしは陶器師の家へ下って行った。見ると彼は、ろくろで仕事をしていたが、</span>
<span className="v" id="v4" data-v="4" data-xref="ローマ人への手紙 9:20–23; エレミヤ書 18:6; イザヤ書 45:9"> 粘土で造っていた器が、その人の手の中で仕損じたので、彼は自分の意のままに、それをもってほかの器を造った。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5"> その時、主の言葉がわたしに臨んだ、</span>
<span className="v" id="v6" data-v="6" data-xref="イザヤ書 64:8; ローマ人への手紙 9:20–21; エレミヤ書 18:4"> 「主は仰せられる、イスラエルの家よ、この陶器師がしたように、わたしもあなたがたにできないのだろうか。イスラエルの家よ、陶器師の手に粘土があるように、あなたがたはわたしの手のうちにある。</span>
<span className="v" id="v7" data-v="7" data-xref="エレミヤ書 1:10; エレミヤ書 12:14–17; エレミヤ書 45:4"> ある時には、わたしが民または国を抜く、破る、滅ぼすということがあるが、</span>
<span className="v" id="v8" data-v="8" data-xref="エゼキエル書 18:21; エレミヤ書 26:13; ヨナ書 3:9–10"> もしわたしの言った国がその悪を離れるならば、わたしはこれに災を下そうとしたことを思いかえす。</span>
<span className="v" id="v9" data-v="9" data-xref="エレミヤ書 31:28; アモス書 9:11–15; エレミヤ書 1:10"> またある時には、わたしが民または国を建てる、植えるということがあるが、</span>
<span className="v" id="v10" data-v="10" data-xref="エゼキエル書 33:18; サムエル記上 2:30; エゼキエル書 18:24"> もしその国がわたしの目に悪と見えることを行い、わたしの声に聞き従わないなら、わたしはこれに幸を与えようとしたことを思いかえす。</span>
<span className="v" id="v11" data-v="11" data-xref="列王紀下 17:13; イザヤ書 55:6–7; エレミヤ書 35:15"> それゆえ、ユダの人々とエルサレムに住む者に言いなさい、『主はこう仰せられる、見よ、わたしはあなたがたに災を下そうと工夫し、あなたがたを攻める計りごとを立てている。あなたがたはおのおのその悪しき道を離れ、その道と行いを改めなさい』と。</span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="エレミヤ書 2:25; エレミヤ書 7:24; 申命記 29:19"> しかし彼らは言う、『それはむだです。われわれは自分の図るところに従い、おのおのその悪い強情な心にしたがって行動します』と。</span>
<span className="v" id="v13" data-v="13" data-xref="エレミヤ書 5:30; ホセア書 6:10; エレミヤ書 23:14"> <span className="pl pl-1">それゆえ主はこう言われる、</span><br /><span className="pl pl-1">異邦の民のうちのある者に尋ねてみよ、</span><br /><span className="pl pl-1">このような事を聞いた者があろうか。</span><br /><span className="pl pl-1">おとめイスラエルは恐ろしい事をした。</span></span>
<span className="v" id="v14" data-v="14" data-xref="ヨハネによる福音書 6:68"> <span className="pl pl-1">レバノンの雪が、</span><br /><span className="pl pl-1">どうしてシリオンの岩を離れようか。</span><br /><span className="pl pl-1">山の水、冷たい川の流れが、</span><br /><span className="pl pl-1">どうしてかわいてしまおうか。</span></span>
<span className="v" id="v15" data-v="15" data-xref="エレミヤ書 6:16; エレミヤ書 2:32; ホセア書 11:2"> <span className="pl pl-1">それなのにわが民はわたしを忘れて、</span><br /><span className="pl pl-1">偽りの神々に香をたいている。</span><br /><span className="pl pl-1">彼らはその道、古い道につまずき、</span><br /><span className="pl pl-1">また小道に入り、大路からはなれた。</span></span>
<span className="v" id="v16" data-v="16" data-xref="詩篇 22:7; エレミヤ書 25:9; エレミヤ書 19:8"> <span className="pl pl-1">自分の地を荒れすたれさせて、</span><br /><span className="pl pl-1">いつまでも人に舌打ちされるものとした。</span><br /><span className="pl pl-1">そこを通る人はみな身震いして、首を振る。</span></span>
<span className="v" id="v17" data-v="17" data-xref="エレミヤ書 13:24; エレミヤ書 2:27; ヨブ記 27:21"> <span className="pl pl-1">わたしは東風のように、彼らをその敵の前に散らす。</span><br /><span className="pl pl-1">その滅びの日には、</span><br /><span className="pl pl-1">わたしは彼らに背を向け、顔を向けない」。</span></span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="詩篇 52:2; エレミヤ書 11:19; マラキ書 2:7"> 彼らは言った、「さあ、計略をめぐらして、エレミヤを倒そう。祭司には律法があり、知恵ある者には計りごとがあり、預言者には言葉があって、これらのものが滅びてしまうことはない。さあ、われわれは舌をもって彼を撃とう。彼のすべての言葉に、心を留めないことにしよう」。</span>
</div>
<div className="bp poetry">
<span className="v" id="v19" data-v="19" data-xref="ネヘミヤ書 6:9; エレミヤ書 20:12; 詩篇 55:16–17"> <span className="pl pl-1">主よ、どうぞわたしにみ心を留め、</span><br /><span className="pl pl-1">わたしの訴えをお聞きください。</span></span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 35:7; 詩篇 57:6; 詩篇 106:23"> <span className="pl pl-1">悪をもって善に報いるべきでしょうか。</span><br /><span className="pl pl-1">しかもなお彼らはわたしの命を取ろうとして</span><br /><span className="pl pl-1">穴を掘りました。</span><br /><span className="pl pl-1">わたしがあなたの前に立って、</span><br /><span className="pl pl-1">彼らのことを良く言い、</span><br /><span className="pl pl-1">あなたの憤りを止めようとしたのを</span><br /><span className="pl pl-1">覚えてください。</span></span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 109:9–20; 哀歌 5:3; アモス書 4:10"> <span className="pl pl-1">それゆえ、彼らの子どもたちをききんに渡し、</span><br /><span className="pl pl-1">彼らをつるぎの刃に渡してください。</span><br /><span className="pl pl-1">彼らの妻は子を失い、また寡婦となり、</span><br /><span className="pl pl-1">男は疫病にかかって死に、</span><br /><span className="pl pl-1">若い者は、戦争でつるぎに殺されますように。</span></span>
<span className="v" id="v22" data-v="22" data-xref="エレミヤ書 6:26; 詩篇 140:5; ゼパニヤ書 1:10–11"> <span className="pl pl-1">あなたが敵をにわかに彼らに臨ませられるとき、</span><br /><span className="pl pl-1">彼らの家から叫び声が聞えますように。</span><br /><span className="pl pl-1">彼らは穴を掘って、わたしを捕えようとし、</span><br /><span className="pl pl-1">わなをつくって、わたしの足を</span><br /><span className="pl pl-1">捕えようとしたからです。</span></span>
<span className="v" id="v23" data-v="23" data-xref="詩篇 35:4; 詩篇 69:22–28; ネヘミヤ書 4:4–5"> <span className="pl pl-1">主よ、あなたは彼らがわたしを殺すために</span><br /><span className="pl pl-1">めぐらしている計略を皆ごぞんじです。</span><br /><span className="pl pl-1">その悪をゆるすことなく、</span><br /><span className="pl pl-1">その罪をあなたの前から消し去らないでください。</span><br /><span className="pl pl-1">彼らをあなたの前に倒れさせてください。</span><br /><span className="pl pl-1">あなたのお怒りになる時に彼らを罰してください。</span></span>
</div>

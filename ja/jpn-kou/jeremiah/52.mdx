<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀下 24:18; ヨシュア記 10:29; 歴代志下 36:11"> ゼデキヤは王となったとき二十一歳であったが、エルサレムで十一年世を治めた。母の名はハムタルといい、リブナのエレミヤの娘である。</span>
<span className="v" id="v2" data-v="2" data-xref="列王紀上 14:22; 列王紀下 24:19–20; エゼキエル書 17:16–20"> ゼデキヤはエホヤキムがすべて行ったように、主の目の前に悪事を行った。</span>
<span className="v" id="v3" data-v="3" data-xref="イザヤ書 3:4–5; 歴代志下 36:13; イザヤ書 3:1"> たしかに、主の怒りによって、エルサレムとユダとは、そのみ前から捨て去られるようなことになった。<br />そしてゼデキヤはバビロンの王にそむいた。</span>
<span className="v" id="v4" data-v="4" data-xref="エレミヤ書 39:1; ゼカリヤ書 8:19; エゼキエル書 24:1–2"> そこで彼の治世の九年十月十日に、バビロンの王ネブカデレザルはその軍勢を率い、エルサレムにきて、これを包囲し、周囲に塁を築いてこれを攻めた。</span>
<span className="v" id="v5" data-v="5"> こうしてこの町は攻め囲まれて、ゼデキヤ王の十一年にまで及んだが、</span>
<span className="v" id="v6" data-v="6" data-xref="エレミヤ書 39:2; イザヤ書 3:1; 列王紀下 25:3"> その四月九日になって、町の中の食糧は、はなはだしく欠乏し、その地の民は食物を得ることができなくなった。</span>
<span className="v" id="v7" data-v="7" data-xref="エレミヤ書 39:4–7; エレミヤ書 51:32; 列王紀下 25:4"> そして町の城壁はついに打ち破られたので、兵士たちはみな逃げ、夜のうちに、王の園の近くの、二つの城壁の間の門から町をのがれ出て、カルデヤびとが、町を攻め囲んでいるうちに、アラバの方へ落ちて行った。</span>
<span className="v" id="v8" data-v="8" data-xref="エレミヤ書 34:21; エレミヤ書 32:4; エレミヤ書 38:23"> しかしカルデヤびとの軍勢は王を追って行って、エリコの平地でゼデキヤに追いついたが、彼の軍勢がみな散って彼のそばを離れたので、</span>
<span className="v" id="v9" data-v="9" data-xref="エレミヤ書 39:5; 民数記 13:21; 列王紀下 25:6"> カルデヤびとは王を捕え、ハマテの地のリブラにいるバビロンの王のもとに引いていったので、王は彼の罪を定めた。</span>
<span className="v" id="v10" data-v="10" data-xref="エレミヤ書 22:30; 列王紀下 25:7; 創世記 21:16"> すなわちバビロンの王はゼデキヤの子たちをその目の前で殺させ、ユダのつかさたちをことごとくリブラで殺させ、</span>
<span className="v" id="v11" data-v="11" data-xref="エゼキエル書 12:13; エレミヤ書 34:3–5"> またゼデキヤの目をつぶさせた。そしてバビロンの王は彼を鎖につないでバビロンへ連れて行き、その死ぬ日まで獄屋に入れて置いた。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="列王紀下 25:8; エレミヤ書 39:9; エレミヤ書 52:29"> 五月十日に、――それはバビロンの王ネブカデレザルの世の十九年であった――バビロンの王に仕える侍衛の長ネブザラダンはエルサレムに、はいって、</span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 79:1; ミカ書 3:12; 歴代志下 36:19"> 主の宮と王の宮殿を焼き、エルサレムのすべての家を焼いた。彼は大きな家をみな焼きはらった。</span>
<span className="v" id="v14" data-v="14" data-xref="ネヘミヤ書 1:3; 列王紀下 25:10"> また侍衛の長と共にいたカルデヤびとの軍勢は、エルサレムの周囲の城壁をみな取りこわした。</span>
<span className="v" id="v15" data-v="15" data-xref="エレミヤ書 15:1–2; ゼカリヤ書 14:2"> そして侍衛の長ネブザラダンは民のうちの最も貧しい者若干、そのほか町のうちに残った者、およびバビロンの王にくだった人、その他工匠たちを捕え移した。</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀下 25:12; エレミヤ書 39:9–10; エレミヤ書 40:5–7"> しかし侍衛の長ネブザラダンはその地の最も貧しい者若干を残して、ぶどうを作る者とし、農夫とした。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="エレミヤ書 27:19–22; エレミヤ書 52:21–23; 歴代志下 4:12–15"> カルデヤびとはまた主の宮の青銅の柱と、洗盤の台と、青銅の海を砕いて、その青銅をことごとくバビロンへ運び、</span>
<span className="v" id="v18" data-v="18" data-xref="出エジプト記 27:3; 民数記 4:14; 列王紀上 7:45"> また、つぼと、十能と、心切りばさみと、鉢と、香を盛る皿および宮の勤めに用いる青銅の器をことごとく取って行った。</span>
<span className="v" id="v19" data-v="19" data-xref="列王紀上 7:49–50; 歴代志下 4:6–22; レビ記 26:12"> また彼らは小鉢と、心取り皿と、鉢と、つぼと、燭台と、香を盛る皿と、灌祭の鉢を取った。金で作った物は金として、銀で作った物は銀として、侍衛の長は運び去った。</span>
<span className="v" id="v20" data-v="20" data-xref="列王紀上 7:47; 列王紀下 25:16; 歴代志下 4:18"> ソロモン王が主の宮に造った二本の柱と、一つの海と、海の下の十二の青銅の牛と、台など、このすべての物の青銅の重さは量ることもできなかった。</span>
<span className="v" id="v21" data-v="21" data-xref="列王紀下 25:17; 列王紀上 7:15–21; 歴代志下 3:15–17"> この一本の柱の高さは十八キュビト、周囲は十二キュビトで、指四本の厚さがあり、中は、うつろであった。</span>
<span className="v" id="v22" data-v="22" data-xref="出エジプト記 28:25; 列王紀下 25:17; 歴代志下 3:15"> その上に青銅の柱頭があり、柱頭の高さは五キュビト、柱頭の周囲は網細工と、ざくろとで飾り、これらもみな青銅であった。他の柱もそのざくろも、これと同じであった。</span>
<span className="v" id="v23" data-v="23" data-xref="列王紀上 7:20"> その四方に九十六個のざくろがあり、周囲の網細工の上にあるざくろの数は百個であった。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="列王紀下 25:18; エレミヤ書 29:25; エレミヤ書 35:4"> 侍衛の長は祭司長セラヤと次席の祭司ゼパニヤと三人の門を守る者を捕え、</span>
<span className="v" id="v25" data-v="25" data-xref="列王紀下 25:19; エステル記 1:14; マタイによる福音書 18:10"> また兵士をつかさどるひとりの役人と、町にいた王の側近の者七人と、その地の民を募る軍勢の長の書記官と、町の中にいた六十人の者を町から捕え去った。</span>
<span className="v" id="v26" data-v="26"> 侍衛の長ネブザラダンは、これらの人を捕えて、リブラにいるバビロンの王のもとに連れて行った。</span>
<span className="v" id="v27" data-v="27" data-xref="エゼキエル書 33:28; イザヤ書 32:13–14; イザヤ書 6:11–12"> バビロンの王は、ハマテの地のリブラで彼らを撃ち殺した。こうして、ユダは自分の地から捕え移された。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="列王紀下 24:12–16; 列王紀下 24:2–3; ダニエル書 1:1–3"> ネブカデレザルが捕え移した民の数は次のとおりである。第七年にはユダヤ人三千二十三人。</span>
<span className="v" id="v29" data-v="29" data-xref="エレミヤ書 52:12; 創世記 12:5; 列王紀下 25:11"> またネブカデレザルはその第十八年にエルサレムから八百三十二人を捕え移した。</span>
<span className="v" id="v30" data-v="30" data-xref="エレミヤ書 52:15; エレミヤ書 6:9"> ネブカデレザルの二十三年に侍衛の長ネブザラダンは、ユダヤ人七百四十五人を捕え移した。この総数は四千六百人であった。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="列王紀下 25:27–30; 詩篇 3:3; 創世記 40:13"> ユダの王エホヤキンが捕え移されて後三十七年の十二月二十五日に、バビロンの王エビルメロダクはその即位の年に、ユダの王エホヤキンを獄屋から出し、そのこうべを挙げさせ、</span>
<span className="v" id="v32" data-v="32" data-xref="箴言 12:25; ダニエル書 5:18–19; ダニエル書 2:37"> 親切に彼を慰め、その位を、バビロンで共にいる王たちの位よりも高くした。</span>
<span className="v" id="v33" data-v="33" data-xref="サムエル記下 9:7; 列王紀上 2:7; 創世記 41:14"> こうしてエホヤキンは獄屋の服を脱いだ。そして生きている間は毎日王の食卓で食事し、</span>
<span className="v" id="v34" data-v="34" data-xref="サムエル記下 9:10; ルカによる福音書 11:3; マタイによる福音書 6:11"> 彼の給与としては、その死ぬ日まで一生の間、たえず日々の必要にしたがって、バビロンの王から給与を賜わった。</span>
</div>

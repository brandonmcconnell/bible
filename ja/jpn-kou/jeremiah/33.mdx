<span className="v" id="v1" data-v="1" data-xref="エレミヤ書 38:28; エレミヤ書 37:21; エレミヤ書 32:2–3"> エレミヤがなお監視の庭に閉じ込められている時、主の言葉はふたたび彼に臨んだ、</span>
<span className="v" id="v2" data-v="2" data-xref="出エジプト記 6:3; 出エジプト記 15:3; イザヤ書 37:26"> 「地を造られた主、それを形造って堅く立たせられた主、その名を主と名のっておられる者がこう仰せられる、</span>
<span className="v" id="v3" data-v="3" data-xref="エレミヤ書 29:12; イザヤ書 65:24; エペソ人への手紙 3:20"> わたしに呼び求めよ、そうすれば、わたしはあなたに答える。そしてあなたの知らない大きな隠されている事を、あなたに示す。</span>
<span className="v" id="v4" data-v="4" data-xref="エレミヤ書 32:24; ハバクク書 1:10; エゼキエル書 4:2"> イスラエルの神、主は塁と、つるぎとを防ぐために破壊されたこの町の家と、ユダの王の家についてこう言われる、</span>
<span className="v" id="v5" data-v="5" data-xref="イザヤ書 8:17; エレミヤ書 21:10; エレミヤ書 21:4–7"> カルデヤびとは来て戦い、わたしが怒りと憤りをもって殺す人々の死体を、それに満たす。わたしは人々のもろもろの悪のために、この町にわたしの顔をおおい隠した。</span>
<span className="v" id="v6" data-v="6" data-xref="ヨハネによる福音書 10:10; イザヤ書 30:26; テトスヘの手紙 3:5–6"> 見よ、わたしは健康と、いやしとを、ここにもたらして人々をいやし、豊かな繁栄と安全とを彼らに示す。</span>
<span className="v" id="v7" data-v="7" data-xref="イザヤ書 1:26; エレミヤ書 30:3; アモス書 9:14–15"> わたしはユダとイスラエルを再び栄えさせ、彼らを建てて、もとのようにする。</span>
<span className="v" id="v8" data-v="8" data-xref="ゼカリヤ書 13:1; ミカ書 7:18–19; 詩篇 51:2"> わたしは彼らがわたしに向かって犯した罪のすべてのとがを清め、彼らがわたしに向かって犯した罪と反逆のすべてのとがをゆるす。</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 126:2–3; イザヤ書 60:5; ゼパニヤ書 3:17–20"> この町は地のもろもろの民の前に、わたしのために喜びの名となり、誉となり、栄えとなる。彼らはわたしがわたしの民に施すもろもろの恵みのことを聞く。そして、わたしがこの町に施すもろもろの恵みと、もろもろの繁栄のために恐れて身をふるわす。</span>
</div>
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="エレミヤ書 32:43; エレミヤ書 32:36; エゼキエル書 37:11"> 主はこう言われる、あなたがたが、『それは荒れて、人もおらず獣もいない』というこの所、すなわち、荒れて、人もおらず住む者もなく、獣もいないユダの町とエルサレムのちまたに、</span>
<span className="v" id="v11" data-v="11" data-xref="歴代志上 16:34; 詩篇 106:1; 詩篇 107:22"> 再び喜びの声、楽しみの声、花婿の声、花嫁の声、および<br /><span className="pl pl-1">『万軍の主に感謝せよ、</span><br /><span className="pl pl-1">主は恵みふかく、</span><br /><span className="pl pl-1">そのいつくしみは、いつまでも絶えることがない』</span><br />といって、感謝の供え物を主の宮に携えてくる者の声が聞える。それは、わたしがこの地を再び栄えさせて初めのようにするからであると主は言われる。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="イザヤ書 65:10; エゼキエル書 34:12–15; エレミヤ書 36:29"> 万軍の主はこう言われる、荒れて、人もおらず獣もいないこの所と、そのすべての町々に再びその群れを伏させる牧者のすまいがあるようになる。</span>
<span className="v" id="v13" data-v="13" data-xref="レビ記 27:32; ルカによる福音書 15:4; エレミヤ書 17:26"> 山地の町々と、平地の町々と、ネゲブの町々と、ベニヤミンの地、エルサレムの周囲と、ユダの町々で、群れは再びそれを数える者の手の下を通りすぎると主は言われる。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="ハガイ書 2:6–9; エレミヤ書 23:5; 歴代志上 17:13–14"> 主は言われる、見よ、わたしがイスラエルの家とユダの家に約束したことをなし遂げる日が来る。</span>
<span className="v" id="v15" data-v="15" data-xref="イザヤ書 11:1–5; エレミヤ書 23:5–6; イザヤ書 4:2"> その日、その時になるならば、わたしはダビデのために一つの正しい枝を生じさせよう。彼は公平と正義を地に行う。</span>
<span className="v" id="v16" data-v="16" data-xref="エレミヤ書 23:6; コリント人への第一の手紙 1:30; イザヤ書 45:17"> その日、ユダは救を得、エルサレムは安らかにおる。その名は『主はわれわれの正義』ととなえられる。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="列王紀上 2:4; 詩篇 89:29–37; ルカによる福音書 1:32–33"> 主はこう仰せられる、イスラエルの家の位に座する人がダビデの子孫のうちに欠けることはない。</span>
<span className="v" id="v18" data-v="18" data-xref="イザヤ書 56:7; ヨハネの黙示録 1:6; 申命記 18:1"> またわたしの前に燔祭をささげ、素祭を焼き、つねに犠牲をささげる人が、レビびとである祭司のうちに絶えることはない」。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19"> 主の言葉はエレミヤに臨んだ、</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 8:22; 詩篇 89:37; イザヤ書 54:9–10"> 「主はこう仰せられる、もしあなたがたが、昼と結んだわたしの契約を破り、また夜と結んだわたしの契約を破り、昼と夜が定められた時に来ないようにすることができるならば、</span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 89:34; 歴代志下 7:18; サムエル記下 23:5"> しもべダビデとわたしが結んだ契約もまた破れ、彼はその位に座して王となる子を与えられない。またわたしがわたしに仕えるレビびとである祭司に立てた契約も破れる。</span>
<span className="v" id="v22" data-v="22" data-xref="創世記 15:5; 創世記 22:17; ヘブル人への手紙 11:12"> 天の星は数えることができず、浜の砂は量ることができない。そのようにわたしは、しもべダビデの子孫と、わたしに仕えるレビびとである祭司の数を増そう」。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23"> 主の言葉はエレミヤに臨んだ、</span>
<span className="v" id="v24" data-v="24" data-xref="ネヘミヤ書 4:2–4; 詩篇 83:4; 詩篇 44:13–14"> 「あなたはこの民が、『主は自ら選んだ二つのやからを捨てた』といっているのを聞かないか。彼らはこのようにわたしの民を侮って、これを国とみなさないのである。</span>
<span className="v" id="v25" data-v="25" data-xref="詩篇 74:16–17; エレミヤ書 31:35–36; 詩篇 104:19"> 主はこう言われる、もしわたしが昼と夜とに契約を立てず、また天地のおきてを定めなかったのであれば、</span>
<span className="v" id="v26" data-v="26" data-xref="エレミヤ書 31:37; イザヤ書 14:1; ホセア書 2:23"> わたしは、ヤコブとわたしのしもべダビデとの子孫を捨てて、再び彼の子孫のうちからアブラハム、イサク、ヤコブの子孫を治める者を選ばない。わたしは彼らを再び栄えさせ、彼らにあわれみをたれよう」。</span>
</div>

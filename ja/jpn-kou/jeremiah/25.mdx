<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="エレミヤ書 36:1; 列王紀下 24:1–2; ダニエル書 1:1"> ユダの王ヨシヤの子エホヤキムの四年（バビロンの王ネブカデレザルの元年）にユダのすべての民についての言葉がエレミヤに臨んだ。</span>
<span className="v" id="v2" data-v="2" data-xref="エレミヤ書 18:11; エレミヤ書 19:14–15; マルコによる福音書 7:14–15"> 預言者エレミヤはこの言葉をユダのすべての民とエルサレムに住むすべての人に告げて言った、</span>
<span className="v" id="v3" data-v="3" data-xref="エレミヤ書 11:7; エレミヤ書 26:5; エレミヤ書 1:2"> 「ユダの王アモンの子ヨシヤの十三年から今日にいたるまで二十三年の間、主の言葉がわたしに臨んだ。わたしはたゆまずにそれをあなたがたに語ってきたが、あなたがたは聞かなかった。</span>
<span className="v" id="v4" data-v="4" data-xref="エレミヤ書 25:3; エレミヤ書 26:5; エレミヤ書 13:10–11"> 主はたゆまず、そのしもべである預言者を、あなたがたにつかわされたが、あなたがたは聞かずまた耳を傾けて聞こうともしなかった。</span>
<span className="v" id="v5" data-v="5" data-xref="エレミヤ書 7:7; 創世記 17:8; イザヤ書 55:6–7"> 彼らは言った、『あなたがたはおのおの今その悪の道と悪い行いを捨てなさい。そうすれば主が昔からあなたがたと先祖たちとに与えられた地に永遠に住むことができる。</span>
<span className="v" id="v6" data-v="6" data-xref="申命記 8:19; エレミヤ書 7:6; エレミヤ書 35:15"> あなたがたは、ほかの神に従って、それに仕え、それを拝んではならない。あなたがたの手で作ったものをもって、わたしを怒らせてはならない。このようなことをしないなら、わたしはあなたがたをそこなうことはない』と。</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀下 21:15; 箴言 8:36; 申命記 32:21"> しかしあなたがたはわたしに聞き従わず、あなたがたの手で作った物をもって、わたしを怒らせて自ら害を招いたと、主は言われる。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8"> それゆえ万軍の主はこう仰せられる、あなたがたがわたしの言葉に聞き従わないゆえ、</span>
<span className="v" id="v9" data-v="9" data-xref="イザヤ書 13:3; エレミヤ書 18:16; エレミヤ書 1:15"> 見よ、わたしは北の方のすべての種族と、わたしのしもべであるバビロンの王ネブカデレザルを呼び寄せて、この地とその民と、そのまわりの国々を攻め滅ぼさせ、これを忌みきらわれるものとし、人の笑いものとし、永遠のはずかしめとすると、主は言われる。</span>
<span className="v" id="v10" data-v="10" data-xref="エレミヤ書 7:34; ヨハネの黙示録 18:22–23; エゼキエル書 26:13"> またわたしは喜びの声、楽しみの声、花婿の声、花嫁の声、ひきうすの音、ともしびの光を彼らの中に絶えさせる。</span>
<span className="v" id="v11" data-v="11" data-xref="ダニエル書 9:2; ゼカリヤ書 1:12; 歴代志下 36:21–22"> この地はみな滅ぼされて荒れ地となる。そしてその国々は七十年の間バビロンの王に仕える。</span>
<span className="v" id="v12" data-v="12" data-xref="ダニエル書 9:2; イザヤ書 13:19; エレミヤ書 29:10"> 主は言われる、七十年の終った後に、わたしはバビロンの王と、その民と、カルデヤびとの地を、その罪のために罰し、永遠の荒れ地とする。</span>
<span className="v" id="v13" data-v="13" data-xref="エレミヤ書 1:10; エレミヤ書 1:5; ダニエル書 5:31"> わたしはあの地について、わたしが語ったすべての言葉をその上に臨ませる。これはエレミヤが、万国のことについて預言したものであって、みなこの書にしるされている。</span>
<span className="v" id="v14" data-v="14" data-xref="エレミヤ書 51:6; エレミヤ書 27:7; エレミヤ書 50:9"> 多くの国々と偉大な王たちとは、彼らをさえ奴隷として仕えさせる。わたしは彼らの行いと、その手のわざに従って報いる」。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="詩篇 75:8; イザヤ書 51:17; ヨハネの黙示録 14:10"> イスラエルの神、主はわたしにこう仰せられた、「わたしの手から、この怒りの杯を受けて、わたしがあなたをつかわす国々の民に飲ませなさい。</span>
<span className="v" id="v16" data-v="16" data-xref="ナホム書 3:11; エレミヤ書 51:7; エレミヤ書 51:39"> 彼らは飲んで、よろめき狂う。これはわたしが彼らのうちに、つるぎをつかわそうとしているからである」。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="エレミヤ書 1:10; エレミヤ書 25:28; エゼキエル書 43:3"> こうしてわたしは主の手から杯を受け、主がわたしをつかわされた国々の民に飲ませた。</span>
<span className="v" id="v18" data-v="18" data-xref="エレミヤ書 24:9; 詩篇 60:3; エレミヤ書 44:22"> すなわちエルサレムとユダのすべての町と、その王たちおよびそのつかさたちに飲ませて、それらを滅ぼし、荒れ地とし、人の笑いものとし、のろわれるものとした。今日のとおりである。</span>
<span className="v" id="v19" data-v="19" data-xref="エレミヤ書 46:13–26; ナホム書 3:8–10; エレミヤ書 46:2"> またエジプトの王パロとその家来たち、その君たち、そのすべての民と、</span>
<span className="v" id="v20" data-v="20" data-xref="ヨブ記 1:1; エゼキエル書 30:5; イザヤ書 20:1"> もろもろの寄留の異邦人、およびウズの地のすべての王たち、およびペリシテびとの地のすべての王たち、（アシケロン、ガザ、エクロン、アシドドの残りの者）、</span>
<span className="v" id="v21" data-v="21" data-xref="エレミヤ書 48:1–22; 詩篇 137:7; エレミヤ書 9:26"> エドム、モアブ、アンモンの子孫、</span>
<span className="v" id="v22" data-v="22" data-xref="エレミヤ書 47:4; アモス書 1:9–10; エゼキエル書 28:22–23"> ツロのすべての王たち、シドンのすべての王たち、海のかなたの海沿いの地の王たち、</span>
<span className="v" id="v23" data-v="23" data-xref="エレミヤ書 9:26; エレミヤ書 49:32; エレミヤ書 49:8"> デダン、テマ、ブズおよびすべて髪の毛のすみずみをそる者、</span>
<span className="v" id="v24" data-v="24" data-xref="歴代志下 9:14; エレミヤ書 25:20; エゼキエル書 30:5"> アラビヤのすべての王たち、荒野の雑種の民のすべての王たち、</span>
<span className="v" id="v25" data-v="25" data-xref="イザヤ書 11:11; 創世記 10:22; イザヤ書 13:17"> ジムリのすべての王たち、エラムのすべての王たち、メデアのすべての王たち、</span>
<span className="v" id="v26" data-v="26" data-xref="エレミヤ書 51:41; エレミヤ書 25:9; エレミヤ書 50:1–46"> 北のすべての王たちの遠き者、近き者もつぎつぎに、またすべて地のおもてにある世の国々の王たちもこの杯を飲む。そして彼らの次にバビロンの王もこれを飲む。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="エレミヤ書 25:16; ハバクク書 2:16; エゼキエル書 21:4–5"> 「それであなたは彼らに言いなさい、『万軍の主、イスラエルの神はこう仰せられる、飲め、酔って吐け、倒れて再び立つな、わたしがあなたがたのうちに、つるぎをつかわすからである』」。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="ヨブ記 34:33; エレミヤ書 51:29; イザヤ書 14:24–27"> 「もし彼らがあなたの手から杯を受けて飲むことをしないならば、あなたは彼らに言いなさい、『万軍の主はこう仰せられる、あなたがたは必ず飲まなければならない。</span>
<span className="v" id="v29" data-v="29" data-xref="エゼキエル書 38:21; 箴言 11:31; ペテロの第一の手紙 4:17"> 見よ、わたしの名をもって呼ばれるこの町にさえ災を下すのだ。どうしてあなたがたが罰を免れることができようか。あなたがたは罰を免れることはできない。わたしがつるぎを呼び寄せて、地に住むすべての者を攻めるからであると、万軍の主は仰せられる』。</span>
</div>
<div className="bp poetry">
<span className="v" id="v30" data-v="30" data-xref="アモス書 1:2; ヨエル書 3:16; イザヤ書 42:13"> それゆえ、あなたは彼らにこのすべての言葉を預言して言いなさい、<br /><span className="pl pl-1">『主は高い所から呼ばわり、</span><br /><span className="pl pl-1">その聖なるすまいから声を出し、</span><br /><span className="pl pl-1">自分のすみかに向かって大いに呼ばわり、</span><br /><span className="pl pl-1">地に住むすべての者に向かって</span><br /><span className="pl pl-1">ぶどうを踏む者のように叫ばれる。</span></span>
<span className="v" id="v31" data-v="31" data-xref="ホセア書 4:1; ヨエル書 3:2; イザヤ書 66:16"> <span className="pl pl-1">叫びは地の果にまで響きわたる。</span><br /><span className="pl pl-1">主が国々と争い、</span><br /><span className="pl pl-1">すべての肉なる者をさばき、</span><br /><span className="pl pl-1">悪人をつるぎに渡すからであると、主は言われる』。</span></span>
<span className="v" id="v32" data-v="32" data-xref="エレミヤ書 23:19; イザヤ書 34:2; 歴代志下 15:6"> <span className="pl pl-1">万軍の主はこう仰せられる、</span><br /><span className="pl pl-1">見よ、国から国へ災が出て行く。</span><br /><span className="pl pl-1">大きなあらしが地の果からおこる。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v33" data-v="33" data-xref="イザヤ書 66:16; エレミヤ書 8:2; 詩篇 79:3"> その日、主に殺される人々は、地のこの果から、かの果に及ぶ。彼らは悲しまれず、集められず、また葬られずに、地のおもてに糞土となる。</span>
<span className="v" id="v34" data-v="34" data-xref="エレミヤ書 6:26; エレミヤ書 50:27; 詩篇 2:9"> <span className="pl pl-1">牧者よ、嘆き叫べ、</span><br /><span className="pl pl-1">群れのかしらたちよ、灰の中にまろべ。</span><br /><span className="pl pl-1">あなたがたのほふられる日、</span><br /><span className="pl pl-1">散らされる日が来たからだ。</span><br /><span className="pl pl-1">あなたがたは選び分けられた雄羊のように倒れる。</span></span>
<span className="v" id="v35" data-v="35" data-xref="ヨブ記 11:20; アモス書 2:14; エレミヤ書 52:8–11"> <span className="pl pl-1">牧者には、のがれ場なく、</span><br /><span className="pl pl-1">群れのかしらたちは逃げる所がない。</span></span>
<span className="v" id="v36" data-v="36" data-xref="エレミヤ書 4:8; エレミヤ書 25:34"> <span className="pl pl-1">牧者の叫び声と、</span><br /><span className="pl pl-1">群れのかしらたちの嘆きの声が聞える。</span><br /><span className="pl pl-1">主が彼らの牧場を滅ぼしておられるからだ。</span></span>
<span className="v" id="v37" data-v="37" data-xref="イザヤ書 27:10–11; イザヤ書 32:14"> <span className="pl pl-1">主の激しい怒りによって、</span><br /><span className="pl pl-1">平和な牧場は荒れていく。</span></span>
<span className="v" id="v38" data-v="38" data-xref="エレミヤ書 4:7; エレミヤ書 5:6; ホセア書 13:7–8"> <span className="pl pl-1">ししのように彼はその巣を出た。</span><br /><span className="pl pl-1">主のつるぎと、その激しい怒りによって、</span><br /><span className="pl pl-1">彼らの地は荒れ地となった」。</span></span>
</div>

<div className="bp poetry">
<span className="v" id="v2" data-v="2" data-xref="列王紀下 23:29; エレミヤ書 46:14; エレミヤ書 25:19"> エジプトの事、すなわちユフラテ川のほとりにあるカルケミシの近くにいるエジプトの王パロ・ネコの軍勢の事について。これはユダの王ヨシヤの子エホヤキムの四年に、バビロンの王ネブカデレザルが撃ち破ったものである。その言葉は次のとおりである、</span>
<span className="v" id="v3" data-v="3" data-xref="イザヤ書 21:5; ヨエル書 3:9; ナホム書 2:1"> <span className="pl pl-1">「大盾と小盾とを備え、進んで戦え。</span></span>

<span className="v" id="v5" data-v="5" data-xref="エレミヤ書 49:29; エレミヤ書 6:25; エレミヤ書 46:21"> <span className="pl pl-1">わたしは見たが、何ゆえか彼らは恐れて退き、</span><br /><span className="pl pl-1">その勇士たちは打ち敗られ、あわてて逃げて、</span><br /><span className="pl pl-1">うしろをふり向くこともしない、――</span><br /><span className="pl pl-1">恐れが彼らの周囲にあると主は言われる。</span></span>
<span className="v" id="v6" data-v="6" data-xref="ダニエル書 11:19; エレミヤ書 46:12; 詩篇 27:2"> <span className="pl pl-1">足早き者も逃げることができず、</span><br /><span className="pl pl-1">勇士ものがれることができない。</span><br /><span className="pl pl-1">北の方、ユフラテ川のほとりで</span><br /><span className="pl pl-1">彼らはつまずき倒れた。</span></span>
<span className="v" id="v7" data-v="7" data-xref="エレミヤ書 47:2; イザヤ書 8:7–8; ダニエル書 11:22"> <span className="pl pl-1">あのナイル川のようにわきあがり、</span><br /><span className="pl pl-1">川々のように、その水のさかまく者はだれか。</span></span>

<span className="v" id="v9" data-v="9" data-xref="イザヤ書 66:19; エゼキエル書 27:10; ナホム書 3:9"> <span className="pl pl-1">馬よ、進め、車よ、激しく走れ。</span><br /><span className="pl pl-1">勇士よ、盾を取るエチオピヤびとと、プテびとよ、</span><br /><span className="pl pl-1">弓を巧みに引くルデびとよ、進み出よ。</span></span>

<div className="bp poetry">

<span className="v" id="v14" data-v="14" data-xref="エレミヤ書 46:10; エレミヤ書 44:1; エレミヤ書 46:3–4"> <span className="pl pl-1">「エジプトで宣べ、ミグドルで告げ示し、</span><br /><span className="pl pl-1">またメンピスとタパネスに告げ示して言え、</span><br /><span className="pl pl-1">『堅く立って、備えせよ、</span><br /><span className="pl pl-1">つるぎがあなたの周囲を、滅ぼし尽すからだ』。</span></span>
<span className="v" id="v15" data-v="15" data-xref="イザヤ書 66:15–16; 詩篇 68:2; 詩篇 18:39"> <span className="pl pl-1">なぜ、アピスはのがれたのか。</span><br /><span className="pl pl-1">あなたの雄牛は、なぜ立たなかったのか。</span><br /><span className="pl pl-1">それは主がこれを倒されたからだ。</span></span>

<div className="bp poetry">

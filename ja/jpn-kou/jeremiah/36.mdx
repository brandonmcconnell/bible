<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="エレミヤ書 25:1; 歴代志下 36:5; エレミヤ書 45:1"> ユダの王ヨシヤの子エホヤキムの四年に主からこの言葉がエレミヤに臨んだ、</span>
<span className="v" id="v2" data-v="2" data-xref="エレミヤ書 30:2; エレミヤ書 25:3; エレミヤ書 1:10"> 「あなたは巻物を取り、わたしがあなたに語った日、すなわちヨシヤの日から今日に至るまで、イスラエルとユダと万国とに関してあなたに語ったすべての言葉を、それにしるしなさい。</span>
<span className="v" id="v3" data-v="3" data-xref="エレミヤ書 18:8; 使徒行伝 3:19; エレミヤ書 26:3"> ユダの家がわたしの下そうとしているすべての災を聞いて、おのおのその悪い道を離れて帰ることもあろう。そうすれば、わたしはそのとがとその罪をゆるすかも知れない」。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="エレミヤ書 32:12; エレミヤ書 36:32; エゼキエル書 2:9"> そこでエレミヤはネリヤの子バルクを呼んだ。バルクはエレミヤの口述にしたがって、主が彼にお告げになった言葉をことごとく巻物に書きしるした。</span>
<span className="v" id="v5" data-v="5" data-xref="エレミヤ書 32:2; エレミヤ書 33:1; コリント人への第二の手紙 11:23"> そしてエレミヤはバルクに命じて言った、「わたしは主の宮に行くことを妨げられている。</span>
<span className="v" id="v6" data-v="6" data-xref="エレミヤ書 36:8–9; エレミヤ書 26:2; エレミヤ書 22:2"> それで、あなたが行って、断食の日に主の宮で、すべての民が聞いているところで、あなたがわたしの口述にしたがって、巻物に筆記した主の言葉を読みなさい。またユダの人々がその町々から来て聞いているところで、それを読みなさい。</span>
<span className="v" id="v7" data-v="7" data-xref="エレミヤ書 36:3; エレミヤ書 21:5; 歴代志下 33:12–13"> 彼らは主の前に祈願をささげ、おのおのその悪い道を離れて帰ることもあろう。主がこの民に対して宣告された怒りと憤りは大きいからである」。</span>
<span className="v" id="v8" data-v="8" data-xref="エレミヤ書 1:17; コリント人への第一の手紙 16:10; ルカによる福音書 4:16–30"> こうしてネリヤの子バルクはすべて預言者エレミヤが自分に命じたように、主の宮で、その巻物に書かれた主の言葉を読んだ。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="歴代志下 20:3; ヨナ書 3:5; エステル記 4:16"> ユダの王ヨシヤの子エホヤキムの五年九月、エルサレムのすべての民と、ユダの町々からエルサレムに来たすべての民とは、主の前に断食を行うべきことを告げ示された。</span>
<span className="v" id="v10" data-v="10" data-xref="エレミヤ書 36:11; エレミヤ書 26:10; エレミヤ書 52:25"> バルクは主の宮の上の庭で、主の宮の新しい門の入口のかたわらにある書記シャパンの子であるゲマリヤのへやで、巻物に書かれたエレミヤの言葉をすべての民に読み聞かせた。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="エレミヤ書 36:10; 歴代志下 34:20; 列王紀下 25:22"> シャパンの子であるゲマリヤの子ミカヤはその巻物にある主の言葉をことごとく聞いて、</span>
<span className="v" id="v12" data-v="12" data-xref="エレミヤ書 26:22; 列王紀下 22:12; エレミヤ書 36:25"> 王の家にある書記のへやに下って行くと、もろもろのつかさたち、すなわち書記エリシャマ、シマヤの子デラヤ、アカボルの子エルナタン、シャパンの子ゲマリヤ、ハナニヤの子ゼデキヤおよびすべてのつかさたちがそこに座していた。</span>
<span className="v" id="v13" data-v="13" data-xref="列王紀下 22:10; 歴代志下 34:24; 歴代志下 34:16–18"> ミカヤはバルクが民に巻物を読んで聞かせたとき、自分の聞いたすべての言葉を彼らに告げたので、</span>
<span className="v" id="v14" data-v="14" data-xref="エレミヤ書 36:2; エレミヤ書 41:18; エレミヤ書 41:1–2"> つかさたちはクシの子セレミヤの子であるネタニヤの子エホデをバルクのもとにつかわして言わせた、「あなたが民に読み聞かせたその巻物を手に取って、来てください」。そこでネリヤの子バルクは巻物を手に取って、彼らのもとに来たので、</span>
<span className="v" id="v15" data-v="15"> 彼らはバルクに言った、「座してそれを読んでください」。バルクはそれを彼らに読みきかせた。</span>
<span className="v" id="v16" data-v="16" data-xref="エレミヤ書 13:18; エレミヤ書 36:24; アモス書 7:10–11"> 彼らはそのすべての言葉を聞き、恐れて互に見かわし、バルクに言った、「われわれはこのすべての言葉を、王に報告しなければならない」。</span>
<span className="v" id="v17" data-v="17" data-xref="ヨハネによる福音書 9:15; ヨハネによる福音書 9:10–11; ヨハネによる福音書 9:26–27"> そしてバルクに尋ねて言った、「このすべての言葉を、あなたがどのようにして書いたのか話してください。彼の口述によるのですか」。</span>
<span className="v" id="v18" data-v="18" data-xref="エレミヤ書 36:4; エレミヤ書 36:2; 箴言 26:4–5"> バルクは彼らに答えた、「彼がわたしにこのすべての言葉を口述したので、わたしはそれを墨汁で巻物に書いたのです」。</span>
<span className="v" id="v19" data-v="19" data-xref="列王紀上 17:3; 列王紀上 18:10; エレミヤ書 26:20–24"> つかさたちはバルクに言った、「行って、エレミヤと一緒に身を隠しなさい。人に所在を知られてはなりません」。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="エレミヤ書 36:12; エレミヤ書 36:21"> そこで彼らは巻物を書記エリシャマのへやに置いて庭にはいり、王のもとへ行って、このすべての言葉を王に告げたので、</span>
<span className="v" id="v21" data-v="21" data-xref="列王紀下 22:10; 歴代志下 34:18; エゼキエル書 2:4–5"> 王はその巻物を持ってこさせるためにエホデをつかわした。エホデは書記エリシャマのへやから巻物を取ってきて、それを王と王のかたわらに立っているすべてのつかさたちに読みきかせた。</span>
<span className="v" id="v22" data-v="22" data-xref="アモス書 3:15; エレミヤ書 22:14–16; エレミヤ書 36:9"> 時は九月であって、王は冬の家に座していた。その前に炉があって火が燃えていた。</span>
<span className="v" id="v23" data-v="23" data-xref="列王紀上 22:8; 箴言 21:30; 列王紀上 22:27"> エホデが三段か四段を読むと、王は小刀をもってそれを切り取り、炉の火に投げいれ、ついに巻物全部を炉の火で焼きつくした。</span>
<span className="v" id="v24" data-v="24" data-xref="エレミヤ書 36:16; 詩篇 36:1; ヨナ書 3:6"> 王とその家来たちはこのすべての言葉を聞いても恐れず、またその着物を裂くこともしなかった。</span>
<span className="v" id="v25" data-v="25" data-xref="創世記 37:22; エレミヤ書 36:12; 使徒行伝 5:34–39"> エルナタン、デラヤおよびゲマリヤが王にその巻物を焼かないようにと願ったときにも彼は聞きいれなかった。</span>
<span className="v" id="v26" data-v="26" data-xref="列王紀上 17:3; 列王紀上 19:1–3; 列王紀上 19:14"> そして王は王子エラメルとアヅリエルの子セラヤとアブデルの子セレミヤに、書記バルクと預言者エレミヤを捕えるようにと命じたが、主は彼らを隠された。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="エレミヤ書 36:4"> バルクがエレミヤの口述にしたがって筆記した言葉を載せた巻物を王が焼いた後、主の言葉がエレミヤに臨んだ、</span>
<span className="v" id="v28" data-v="28" data-xref="ゼカリヤ書 1:5–6; ヨブ記 23:13; エレミヤ書 44:28"> 「他の巻物を取り、ユダの王エホヤキムが焼いた、前の巻物のうちにある言葉を皆それに書きしるしなさい。</span>
<span className="v" id="v29" data-v="29" data-xref="イザヤ書 30:10; エレミヤ書 26:9; 申命記 29:19"> またユダの王エホヤキムについて言いなさい、『主はこう仰せられる、あなたはこの巻物を焼いて言った、「どうしてあなたはこの巻物に、バビロンの王が必ず来てこの地を滅ぼし、ここから人と獣とを絶やす、と書いたのか」と。</span>
<span className="v" id="v30" data-v="30" data-xref="エレミヤ書 22:30; 列王紀下 24:12–15; 創世記 31:40"> それゆえ主はユダの王エホヤキムについてこう言われる、彼の子孫にはダビデの位にすわる者がなくなる。また彼の死体は捨てられて昼は暑さにあい、夜は霜にあう。</span>
<span className="v" id="v31" data-v="31" data-xref="箴言 29:1; エレミヤ書 19:15; エレミヤ書 35:17"> わたしはまた彼とその子孫とその家来たちをその罪のために罰する。また彼らとエルサレムの民とユダの人々には災を下す。この災のことについては、すでに語ったけれども、彼らは聞くことをしなかった』」。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="エレミヤ書 36:4; エレミヤ書 36:18; 出エジプト記 4:15–16"> そこでエレミヤは他の巻物を取り、ネリヤの子書記バルクに与えたので、バルクはユダの王エホヤキムが火にくべて焼いた巻物のすべての言葉を、エレミヤの口述にしたがってそれに書きしるし、また同じような言葉を多くそれに加えた。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="エレミヤ書 39:1–2; 列王紀下 25:1–2; エレミヤ書 25:1"> ユダの王ゼデキヤの十年、すなわちネブカデレザルの十八年に、主の言葉がエレミヤに臨んだ。</span>
<span className="v" id="v2" data-v="2" data-xref="エレミヤ書 37:21; ネヘミヤ書 3:25; エレミヤ書 33:1"> その時、バビロンの王の軍勢がエルサレムを攻め囲んでいて、預言者エレミヤはユダの王の宮殿にある監視の庭のうちに監禁されていた。</span>
<span className="v" id="v3" data-v="3" data-xref="エレミヤ書 34:2–3; エレミヤ書 21:4–7; エレミヤ書 26:8–9"> ユダの王ゼデキヤが彼を閉じ込めたのであるが、王は言った、「なぜあなたは預言して言うのか、『主はこう仰せられる、見よ、わたしはこの町をバビロンの王の手に渡し、彼はこれを取る。</span>
<span className="v" id="v4" data-v="4" data-xref="エレミヤ書 39:4–7; 列王紀下 25:4–7; エレミヤ書 37:17"> またユダの王ゼデキヤはカルデヤびとの手をのがれることなく、かならずバビロンの王の手に渡され、顔と顔を合わせて彼と語り、目と目は相まみえる。</span>
<span className="v" id="v5" data-v="5" data-xref="エレミヤ書 39:7; エゼキエル書 17:9–10; エゼキエル書 17:15"> そして彼はゼデキヤをバビロンに引いていき、ゼデキヤは、わたしが彼を顧みる時まで、そこにいると主は言われる。あなたがたは、カルデヤびとと戦っても勝つことはできない』と」。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6"> エレミヤは言った、「主の言葉がわたしに臨んで言われる、</span>
<span className="v" id="v7" data-v="7" data-xref="エレミヤ書 1:1; エレミヤ書 11:21; レビ記 25:25"> 『見よ、あなたのおじシャルムの子ハナメルがあなたの所に来て言う、「アナトテにあるわたしの畑を買いなさい。それは、これを買い取り、あがなう権利があなたにあるから」と』。</span>
<span className="v" id="v8" data-v="8" data-xref="エレミヤ書 32:7; エレミヤ書 32:2; エレミヤ書 33:1"> はたして主の言葉のように、わたしのいとこであるハナメルが監視の庭のうちにいるわたしの所に来て言った、『ベニヤミンの地のアナトテにあるわたしの畑を買ってください。所有するのも、あがなうのも、あなたの権利なのです。買い取ってあなたの物にしてください。これが主の言葉であるのをわたしは知っていました』。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="ゼカリヤ書 11:12–13; エステル記 3:9; 列王紀上 20:39"> そこでわたしは、いとこのハナメルからアナトテにある畑を買い取り、銀十七シケルを量って彼に支払った。</span>
<span className="v" id="v10" data-v="10" data-xref="エレミヤ書 32:44; エレミヤ書 32:12; エレミヤ書 32:25"> すなわち、わたしはその証書をつくって、これに記名し、それを封印し、証人を立て、はかりをもって銀を量って与えた。</span>
<span className="v" id="v11" data-v="11" data-xref="ルカによる福音書 2:27; コリント人への第一の手紙 11:16; 使徒行伝 26:3"> そしてわたしはその約定をしるして封印した買収証書と、封印のない写しとを取り、</span>
<span className="v" id="v12" data-v="12" data-xref="エレミヤ書 32:16; エレミヤ書 51:59; エレミヤ書 36:4–5"> いとこのハナメルと、買収証書に記名した証人たち、および監視の庭にすわっているすべてのユダヤ人の前で、その証書をマアセヤの子であるネリヤの子バルクに与え、</span>
<span className="v" id="v13" data-v="13"> 彼らの前で、わたしはバルクに命じて言った、</span>
<span className="v" id="v14" data-v="14"> 『万軍の主、イスラエルの神はこう仰せられる、これらの証書すなわち、この買収証書の封印したものと、封印のない写しとを取り、これらを土の器に入れて、長く保存せよ。</span>
<span className="v" id="v15" data-v="15" data-xref="ゼカリヤ書 3:10; アモス書 9:14–15; エレミヤ書 30:18"> 万軍の主、イスラエルの神がこう言われるからである、「この地で人々はまた家と畑とぶどう畑を買うようになる」と』。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="エレミヤ書 12:1; 創世記 32:9–12; ピリピ人への手紙 4:6–7"> わたしは買収証書をネリヤの子バルクに渡したあとで主に祈って言った、</span>
<span className="v" id="v17" data-v="17" data-xref="ルカによる福音書 1:37; エレミヤ書 32:27; 創世記 18:14"> 『ああ主なる神よ、あなたは大いなる力と、伸べた腕をもって天と地をお造りになったのです。あなたのできないことは、ひとつもありません。</span>
<span className="v" id="v18" data-v="18" data-xref="エレミヤ書 10:16; 申命記 5:9–10; 出エジプト記 34:7"> あなたはいつくしみを千万人に施し、また父の罪をそののちの子孫に報いられるのです。あなたは大いなる全能の神でいらせられ、その名は万軍の主と申されます。</span>
<span className="v" id="v19" data-v="19" data-xref="エレミヤ書 17:10; マタイによる福音書 16:27; 詩篇 62:12"> あなたの計りごとは大きく、また、事を行うのに力があり、あなたの目は人々の歩むすべての道を見て、おのおのの道にしたがい、その行いの実によってこれに報いられます。</span>
<span className="v" id="v20" data-v="20" data-xref="ネヘミヤ書 9:10; サムエル記下 7:23; 出エジプト記 10:2"> あなたは、しるしと、不思議なわざとをエジプトの地に行い、また今日に至るまでイスラエルと全人類のうちに行い、そして今日のように名をあげられました。</span>
<span className="v" id="v21" data-v="21" data-xref="出エジプト記 6:6; 申命記 26:8; 詩篇 105:43"> あなたは、しるしと、不思議なわざと、強い手と、伸べた腕と、大いなる恐るべき事をもって、あなたの民イスラエルをエジプトの地から導き出し、</span>
<span className="v" id="v22" data-v="22" data-xref="出エジプト記 3:8; 出エジプト記 13:5; エレミヤ書 11:5"> この地を彼らに賜わりました。これはあなたが彼らの先祖たちに与えようと誓われた乳と蜜の流れる地です。</span>
<span className="v" id="v23" data-v="23" data-xref="エズラ記 9:7; 詩篇 78:54–55; ダニエル書 9:10–14"> こうして彼らは、はいってこれを獲たのですが、あなたの声に聞き従わず、あなたの律法を行わず、すべてあなたがせよと命じられたことをしなかったので、あなたはこの災を彼らの上にお下しになりました。</span>
<span className="v" id="v24" data-v="24" data-xref="エレミヤ書 32:36; 申命記 4:26; ヨシュア記 23:15–16"> 見よ、塁が築きあげられたのは、この町を取るためです。つるぎと、ききんと、疫病のために、町はこれを攻めているカルデヤびとの手に渡されます。あなたの言われたようになりましたのは、ごらんのとおりであります。</span>
<span className="v" id="v25" data-v="25" data-xref="エレミヤ書 32:24; 詩篇 97:2; 詩篇 77:19"> 主なる神よ、あなたはわたしに言われました、「銀をもって畑を買い、証人を立てよ」と。そうであるのに、町はカルデヤびとの手に渡されています』」。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26"> 主の言葉がエレミヤに臨んだ、</span>
<span className="v" id="v27" data-v="27" data-xref="マタイによる福音書 19:26; エレミヤ書 32:17; イザヤ書 64:8"> 「見よ、わたしは主である、すべて命ある者の神である。わたしにできない事があろうか。</span>
<span className="v" id="v28" data-v="28" data-xref="エレミヤ書 32:3; エレミヤ書 32:24; エレミヤ書 19:7–12"> それゆえ、主はこう言われる、見よ、わたしはこの町をカルデヤびとと、バビロンの王ネブカデレザルの手に渡す。彼はこれを取る。</span>
<span className="v" id="v29" data-v="29" data-xref="エレミヤ書 21:10; エレミヤ書 19:13; エレミヤ書 52:13"> この町を攻めているカルデヤびとがきて、この町に火をつけて焼き払う。屋根の上で人々が、バアルに香をたき、ほかの神々に酒をそそいで、わたしを怒らせたその家をも彼らは焼く。</span>
<span className="v" id="v30" data-v="30" data-xref="エレミヤ書 7:22–26; 申命記 9:7–12; エレミヤ書 25:7"> それは、イスラエルの人々とユダの人々とは、その若い時から、わたしの前に悪いことのみを行い、またイスラエルの民はその手のわざをもって、わたしを怒らせることばかりをしたからであると主は言われる。</span>
<span className="v" id="v31" data-v="31" data-xref="列王紀下 23:27; エレミヤ書 27:10; 列王紀下 21:4–7"> この町はそれが建った日からきょうまで、わたしの怒りと憤りとをひき起してきたので、わたしの前からこれを除き去るのである。</span>
<span className="v" id="v32" data-v="32" data-xref="ダニエル書 9:8; エレミヤ書 2:26; イザヤ書 1:4–6"> それは、イスラエルの民とユダの民とが、もろもろの悪を行って、わたしを怒らせたことによるのである。――彼らの王たちと、そのつかさたち、祭司たち、預言者たち、またユダの人々とエルサレムの住民たちが皆そうである。</span>
<span className="v" id="v33" data-v="33" data-xref="エレミヤ書 7:13; エレミヤ書 2:27; エゼキエル書 8:16"> 彼らはその背中をわたしに向けて顔をわたしに向けず、わたしがたゆまず教えたにもかかわらず、彼らは教を聞かず、またうけないのである。</span>
<span className="v" id="v34" data-v="34" data-xref="エレミヤ書 7:30; エゼキエル書 8:5–16; 列王紀下 21:4–7"> 彼らは憎むべき物を、わが名をもって呼ばれている家にすえつけて、そこを汚し、</span>
<span className="v" id="v35" data-v="35" data-xref="エレミヤ書 7:31; 歴代志下 33:6; レビ記 18:21"> またベンヒンノムの谷にバアルの高き所を築いて、むすこ娘をモレクにささげた。わたしは彼らにこのようなことを命じたことはなく、また彼らがこの憎むべきことを行って、ユダに罪を犯させようとは考えもしなかった。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="エレミヤ書 32:24; エレミヤ書 32:3; エレミヤ書 32:28"> それゆえ今イスラエルの神、主は、この町、すなわちあなたがたが、『つるぎと、ききんと、疫病のためにバビロンの王の手に渡される』といっている町についてこう仰せられる、</span>
<span className="v" id="v37" data-v="37" data-xref="エレミヤ書 23:3; エレミヤ書 23:6; エゼキエル書 34:12–14"> 見よ、わたしは、わたしの怒りと憤りと大いなる怒りをもって、彼らを追いやったもろもろの国から彼らを集め、この所へ導きかえって、安らかに住まわせる。</span>
<span className="v" id="v38" data-v="38" data-xref="エレミヤ書 24:7; エゼキエル書 11:19–20; ヘブル人への手紙 8:10"> そして彼らはわたしの民となり、わたしは彼らの神となる。</span>
<span className="v" id="v39" data-v="39" data-xref="エゼキエル書 11:19–20; 使徒行伝 4:32; ヨハネによる福音書 17:21"> わたしは彼らに一つの心と一つの道を与えて常にわたしを恐れさせる。これは彼らが彼ら自身とその後の子孫の幸を得るためである。</span>
<span className="v" id="v40" data-v="40" data-xref="エレミヤ書 31:31–33; エゼキエル書 36:26; エレミヤ書 24:7"> わたしは彼らと永遠の契約を立てて、彼らを見捨てずに恵みを施すことを誓い、またわたしを恐れる恐れを彼らの心に置いて、わたしを離れることのないようにしよう。</span>
<span className="v" id="v41" data-v="41" data-xref="エレミヤ書 24:6; ゼパニヤ書 3:17; イザヤ書 62:5"> わたしは彼らに恵みを施すことを喜びとし、心をつくし、精神をつくし、真実をもって彼らをこの地に植える。</span>
<span className="v" id="v42" data-v="42" data-xref="エレミヤ書 31:28; ヨシュア記 23:14–15; エレミヤ書 33:10–11"> 主はこう仰せられる、わたしがこのもろもろの大きな災をこの民に下したように、わたしが彼らに約束するもろもろの幸を彼らの上に下す。</span>
<span className="v" id="v43" data-v="43" data-xref="エゼキエル書 37:11–14; エレミヤ書 32:15; エレミヤ書 32:36"> 人々はこの地に畑を買うようになる。あなたがたが、『それは荒れて人も獣もいなくなり、カルデヤびとの手に渡されてしまう』といっている地である。</span>
<span className="v" id="v44" data-v="44" data-xref="エレミヤ書 17:26; エレミヤ書 33:26; エレミヤ書 33:11"> 人々はベニヤミンの地と、エルサレムの周囲と、ユダの町々と、山地の町々と、平地の町々と、ネゲブの町々で、銀をもって畑を買い、証書をつくって、これに記名し封印し、また証人を立てる。それは、わたしが彼らを再び栄えさせるからであると主は言われる」。</span>
</div>

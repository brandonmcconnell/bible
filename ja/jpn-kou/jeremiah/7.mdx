<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 主からエレミヤに臨んだ言葉はこうである。</span>
<span className="v" id="v2" data-v="2" data-xref="エレミヤ書 26:2; ヨハネの黙示録 3:22; アモス書 7:16"> 「主の家の門に立ち、その所で、この言葉をのべて言え、主を拝むために、この門をはいるユダのすべての人よ、主の言葉を聞け。</span>
<span className="v" id="v3" data-v="3" data-xref="エレミヤ書 18:11; エレミヤ書 26:13; イザヤ書 1:16–19"> 万軍の主、イスラエルの神はこう言われる、あなたがたの道とあなたがたの行いを改めるならば、わたしはあなたがたをこの所に住まわせる。</span>
<span className="v" id="v4" data-v="4" data-xref="ミカ書 3:11; マタイによる福音書 3:9–10; ゼパニヤ書 3:11"> あなたがたは、『これは主の神殿だ、主の神殿だ、主の神殿だ』という偽りの言葉を頼みとしてはならない。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="列王紀上 6:12–13; イザヤ書 1:19; エレミヤ書 7:3"> もしあなたがたが、まことに、その道と行いを改めて、互に公正を行い、</span>
<span className="v" id="v6" data-v="6" data-xref="出エジプト記 22:21–24; ゼカリヤ書 7:9–12; エレミヤ書 13:10"> 寄留の他国人と、みなしごと、やもめをしえたげることなく、罪のない人の血をこの所に流すことなく、また、ほかの神々に従って自ら害をまねくことをしないならば、</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 4:40; エレミヤ書 25:5; エレミヤ書 3:18"> わたしはあなたがたを、わたしが昔あなたがたの先祖に与えたこの地に永遠に住まわせる。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="イザヤ書 28:15; エゼキエル書 13:6–16; エレミヤ書 23:14–16"> 見よ、あなたがたは偽りの言葉を頼みとしているが、それはむだである。</span>
<span className="v" id="v9" data-v="9" data-xref="エレミヤ書 7:6; 出エジプト記 20:3; ヤコブの手紙 4:1–4"> あなたがたは盗み、殺し、姦淫し、偽って誓い、バアルに香をたき、あなたがたが以前には知らなかった他の神々に従いながら、</span>
<span className="v" id="v10" data-v="10" data-xref="エレミヤ書 32:34; エゼキエル書 23:37; エゼキエル書 23:39"> わたしの名をもって、となえられるこの家に来てわたしの前に立ち、『われわれは救われた』と言い、しかもすべてこれら憎むべきことを行うのは、どうしたことか。</span>
<span className="v" id="v11" data-v="11" data-xref="ルカによる福音書 19:45–46; イザヤ書 56:7; マタイによる福音書 21:13"> わたしの名をもって、となえられるこの家が、あなたがたの目には盗賊の巣と見えるのか。わたし自身、そう見たと主は言われる。</span>
<span className="v" id="v12" data-v="12" data-xref="ヨシュア記 18:1; エレミヤ書 26:6; サムエル記上 4:10–11"> わたしが初めにわたしの名を置いた場所シロへ行き、わが民イスラエルの悪のために、わたしがその場所に対して行ったことを見よ。</span>
<span className="v" id="v13" data-v="13" data-xref="イザヤ書 65:12; 歴代志下 36:15–16; エレミヤ書 7:25"> 主は言われる、今あなたがたはこれらのすべてのことを行っている。またわたしはあなたがたに、しきりに語ったけれども、あなたがたは聞かず、あなたがたを呼んだけれども答えなかった。</span>
<span className="v" id="v14" data-v="14" data-xref="詩篇 78:60; 列王紀下 25:9; エレミヤ書 7:4"> それゆえわたしはシロに対して行ったように、わたしの名をもって、となえられるこの家にも行う。すなわちあなたがたが頼みとする所、わたしがあなたがたと、あなたがたの先祖に与えたこの所に行う。</span>
<span className="v" id="v15" data-v="15" data-xref="エレミヤ書 15:1; 列王紀下 17:23; エレミヤ書 52:3"> そしてわたしは、あなたがたのすべての兄弟、すなわちエフライムのすべての子孫を捨てたように、わたしの前からあなたがたをも捨てる。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="エレミヤ書 11:14; エレミヤ書 14:11–12; エレミヤ書 15:1"> あなたはこの民のために祈ってはならない。彼らのために嘆き、祈ってはならない。またわたしに、とりなしをしてはならない。わたしはあなたの求めを聞かない。</span>
<span className="v" id="v17" data-v="17" data-xref="エゼキエル書 8:6–18; エゼキエル書 14:23; エレミヤ書 6:27"> あなたは彼らがユダの町々と、エルサレムのちまたでしていることを見ないのか。</span>
<span className="v" id="v18" data-v="18" data-xref="エレミヤ書 19:13; エレミヤ書 44:17–19; コリント人への第一の手紙 10:22"> 子どもらは、たきぎを集め、父たちは火をたき、女は粉をこね、パンを造ってこれを天后に供える。また彼らは他の神々の前に酒を注いで、わたしを怒らせる。</span>
<span className="v" id="v19" data-v="19" data-xref="エレミヤ書 20:11; エレミヤ書 2:19; ダニエル書 9:7–8"> 主は言われる、彼らが怒らせるのはわたしなのか。自分たち自身ではないのか。そして自らうろたえている。</span>
<span className="v" id="v20" data-v="20" data-xref="エレミヤ書 42:18; 哀歌 2:3–5; イザヤ書 42:25"> それゆえ主なる神はこう言われる、見よ、わたしの怒りと憤りを、この所と、人と獣と、畑の木と、地の産物とに注ぐ。怒りは燃えて消えることがない」。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="ホセア書 8:13; エレミヤ書 6:20; アモス書 5:21–23"> 万軍の主、イスラエルの神はこう言われる、「あなたがたの犠牲に燔祭の物を合わせて肉を食べるがよい。</span>
<span className="v" id="v22" data-v="22" data-xref="ホセア書 6:6; サムエル記上 15:22; 詩篇 51:16–17"> それはあなたがたの先祖をエジプトの地から導き出した日に、わたしは燔祭と犠牲とについて彼らに語ったこともなく、また命じたこともないからである。</span>
<span className="v" id="v23" data-v="23" data-xref="出エジプト記 15:26; 申命記 5:33; 出エジプト記 19:5–6"> ただわたしはこの戒めを彼らに与えて言った、『わたしの声に聞きしたがいなさい。そうすれば、わたしはあなたがたの神となり、あなたがたはわたしの民となる。わたしがあなたがたに命じるすべての道を歩んで幸を得なさい』と。</span>
<span className="v" id="v24" data-v="24" data-xref="詩篇 81:11–12; エレミヤ書 8:5; エレミヤ書 7:26"> しかし彼らは聞き従わず、耳を傾けず、自分の悪い心の計りごとと強情にしたがって歩み、悪くなるばかりで、よくはならなかった。</span>
<span className="v" id="v25" data-v="25" data-xref="歴代志下 36:15; エレミヤ書 25:4; ネヘミヤ書 9:26"> あなたがたの先祖がエジプトの地を出た日から今日まで、わたしはわたしのしもべである預言者たちを日々彼らにつかわした。</span>
<span className="v" id="v26" data-v="26" data-xref="エレミヤ書 16:12; 歴代志下 30:8; エレミヤ書 7:24"> しかし彼らはわたしに聞かず、耳を傾けないで強情になり、先祖たちにもまさって悪を行った。</span>
</div>
<div className="bp poetry">
<span className="v" id="v27" data-v="27" data-xref="エレミヤ書 26:2; エレミヤ書 1:7; イザヤ書 65:12"> たといあなたが彼らにこのすべての言葉を語っても彼らは聞かない。また彼らを呼んでもあなたに答えない。</span>
<span className="v" id="v28" data-v="28" data-xref="イザヤ書 59:14–15; 箴言 1:7; イザヤ書 1:4–5"> それゆえ、あなたはこう彼らに言わなければならない、『これはその神、主の声に聞き従わず、その戒めを受けいれなかった国民である。真実はうせ、彼らの口から絶えた。</span>
<span className="v" id="v29" data-v="29" data-xref="ヨブ記 1:20; ミカ書 1:16; エレミヤ書 6:30"> <span className="pl pl-1">あなたの髪の毛を切って捨てよ、</span><br /><span className="pl pl-1">裸の山の上に嘆きの声をあげよ。</span><br /><span className="pl pl-1">主が、お怒りになっている世の人を</span><br /><span className="pl pl-1">退け捨てられたからだ』。</span></span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="エレミヤ書 32:34; エゼキエル書 7:20; ダニエル書 9:27"> 主は言われる、ユダの民はわたしの前に悪を行い、わたしの名をもってとなえられる家に、憎むべき者を置いてそこを汚した。</span>
<span className="v" id="v31" data-v="31" data-xref="列王紀下 23:10; エレミヤ書 32:35; レビ記 18:21"> またベンヒンノムの谷にあるトペテの高き所を築いて、むすこ娘を火に焼いた。わたしはそれを命じたことはなく、またそのようなことを考えたこともなかった。</span>
<span className="v" id="v32" data-v="32" data-xref="エレミヤ書 19:11; エレミヤ書 19:6; 列王紀下 23:10"> 主は言われる、それゆえに見よ、その所をトペテ、またはベンヒンノムの谷と呼ばないで、ほふりの谷と呼ぶ日が来る。それはほかに場所がないので、トペテに葬るからである。</span>
<span className="v" id="v33" data-v="33" data-xref="エレミヤ書 12:9; 申命記 28:26; ヨハネの黙示録 19:17–18"> この民の死体は空の鳥と地の獣の食物となり、これを追い払う者もない。</span>
<span className="v" id="v34" data-v="34" data-xref="ヨハネの黙示録 18:23; ホセア書 2:11; エゼキエル書 26:13"> そのときわたしはユダの町々とエルサレムのちまたに、喜びの声、楽しみの声、花婿の声、花嫁の声を絶やす。この地は荒れ果てるからである。</span>
</div>

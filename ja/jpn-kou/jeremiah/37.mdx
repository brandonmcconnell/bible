<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="エレミヤ書 22:24; 列王紀下 24:17; 列王紀下 24:12"> ヨシヤの子ゼデキヤはエホヤキムの子コニヤに代って王となった。バビロンの王ネブカデレザルが彼をユダの地の王としたのである。</span>
<span className="v" id="v2" data-v="2" data-xref="列王紀下 24:19–20; 箴言 29:12; 歴代志下 36:12–16"> 彼もその家来たちも、その地の人々も、主が預言者エレミヤによって語られた言葉に聞き従わなかった。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="エレミヤ書 21:1–2; エレミヤ書 29:25; エレミヤ書 42:20"> ゼデキヤ王はセレミヤの子ユカルと、マアセヤの子祭司ゼパニヤを預言者エレミヤにつかわして、「われわれのために、われわれの神、主に祈ってください」と言わせた。</span>
<span className="v" id="v4" data-v="4" data-xref="エレミヤ書 37:15; エレミヤ書 32:2–3"> エレミヤは民の中に出入りしていた。まだ獄屋に入れられなかったからである。</span>
<span className="v" id="v5" data-v="5" data-xref="エゼキエル書 17:15; エレミヤ書 37:11; エレミヤ書 34:21"> パロの軍勢がエジプトから出て来たので、エルサレムを攻め囲んでいたカルデヤびとはその情報を聞いてエルサレムを退いた。</span>
<span className="v" id="v6" data-v="6"> その時、主の言葉は預言者エレミヤに臨んだ、</span>
<span className="v" id="v7" data-v="7" data-xref="哀歌 4:17; 列王紀下 22:18; エゼキエル書 17:17"> 「イスラエルの神、主はこう言われる、あなたがたをつかわしてわたしに求めたユダの王にこう言いなさい、『あなたがたを救うために出てきたパロの軍勢はその国エジプトに帰ろうとしている。</span>
<span className="v" id="v8" data-v="8" data-xref="エレミヤ書 39:2–8; エレミヤ書 38:23; エレミヤ書 34:21–22"> カルデヤびとが再び来てこの町を攻めて戦い、これを取って火で焼き滅ぼす。</span>
<span className="v" id="v9" data-v="9" data-xref="オバデヤ書 1:3; エレミヤ書 29:8; ガラテヤ人への手紙 6:3"> 主はこう言われる、あなたがたは、「カルデヤびとはきっとわれわれを離れ去る」といって自分を欺いてはならない。彼らは去ることはない。</span>
<span className="v" id="v10" data-v="10" data-xref="エレミヤ書 50:45; イザヤ書 30:17; ヨエル書 2:11"> たといあなたがたが自分を攻めて戦うカルデヤびとの全軍を撃ち破って、その天幕のうちに負傷者のみを残しても、彼らは立ち上がって火でこの町を焼き滅ぼす』」。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="エレミヤ書 37:5"> さてカルデヤびとの軍勢がパロの軍勢の来るのを聞いてエルサレムを退いたとき、</span>
<span className="v" id="v12" data-v="12" data-xref="エレミヤ書 1:1; ネヘミヤ書 6:11; 列王紀上 19:3"> エレミヤは、ベニヤミンの地で民のうちに自分の分け前を受け取るため、エルサレムを立ってその地へ行こうと、</span>
<span className="v" id="v13" data-v="13" data-xref="ゼカリヤ書 14:10; エレミヤ書 38:7; ルカによる福音書 23:2"> ベニヤミンの門に着いたとき、そこにハナニヤの子セレミヤの子でイリヤという名の番兵がいて、預言者エレミヤを捕え、「あなたはカルデヤびとの側に脱走しようとしている」と言った。</span>
<span className="v" id="v14" data-v="14" data-xref="詩篇 52:1–2; エレミヤ書 40:4–6; 詩篇 27:12"> エレミヤは言った、「それはまちがいだ。わたしはカルデヤびとの側に脱走しようとしていない」。しかしイリヤは聞かず、エレミヤを捕えて、つかさたちのもとへ引いて行った。</span>
<span className="v" id="v15" data-v="15" data-xref="エレミヤ書 38:26; エレミヤ書 20:1–3; エレミヤ書 26:16"> つかさたちは怒って、エレミヤを打ちたたき、書記ヨナタンの家の獄屋にいれた。この家が獄屋になっていたからである。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="エレミヤ書 38:6; エレミヤ書 38:10–13; 哀歌 3:53"> エレミヤが地下の獄屋にはいって、そこに多くの日を送ってのち、</span>
<span className="v" id="v17" data-v="17" data-xref="エレミヤ書 21:7; エレミヤ書 24:8; 列王紀上 14:1–4"> ゼデキヤ王は人をつかわし、彼を連れてこさせた。王は自分の家でひそかに彼に尋ねて言った、「主から何かお言葉があったか」。エレミヤはあったと答えた。そして言った、「あなたはバビロンの王の手に引き渡されます」。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行伝 25:8; ヨハネによる福音書 10:32; ダニエル書 6:22"> エレミヤはまたゼデキヤ王に言った、「わたしが獄屋にいれられたのは、あなたに、またはあなたの家来に、あるいはこの民に、どのような罪を犯したからなのですか。</span>
<span className="v" id="v19" data-v="19" data-xref="エレミヤ書 2:28; エレミヤ書 28:10–17; エレミヤ書 6:14"> あなたがたに預言して、『バビロンの王はあなたがたをも、この地をも攻めにこない』と言っていたあなたがたの預言者は今どこにいるのですか。</span>
<span className="v" id="v20" data-v="20" data-xref="エレミヤ書 36:7; エレミヤ書 38:6–9; 使徒行伝 28:18–19"> 王なるわが君よ、どうぞ今お聞きください。わたしの願いをお聞きとどけください。わたしを書記ヨナタンの家へ帰らせないでください。そうでないと、わたしはそこで殺されるでしょう」。</span>
<span className="v" id="v21" data-v="21" data-xref="エレミヤ書 38:13; エレミヤ書 38:28; エレミヤ書 38:9"> そこでゼデキヤ王は命を下し、エレミヤを監視の庭に入れさせ、かつ、パンを造る者の町から毎日パン一個を彼に与えさせた。これは町にパンがなくなるまで続いた。こうしてエレミヤは監視の庭にいた。</span>
</div>

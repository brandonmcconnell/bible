<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歴代志下 36:4–5; エレミヤ書 27:1; 列王紀下 23:34–36"> ユダの王ヨシヤの子エホヤキムが世を治めた初めのころ、主からこの言葉があった、</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 4:2; 使徒行伝 20:27; マタイによる福音書 28:20"> 「主はこう仰せられる、主の宮の庭に立ち、わたしがあなたに命じて言わせるすべての言葉を、主の宮で礼拝するために来ているユダの町々の人々に告げなさい。ひと言をも言い残しておいてはならない。</span>
<span className="v" id="v3" data-v="3" data-xref="エレミヤ書 36:3; イザヤ書 1:16–19; エレミヤ書 18:7–10"> 彼らが聞いて、おのおのその悪い道を離れることがあるかも知れない。そのとき、わたしは彼らの行いの悪いために、災を彼らに下そうとしたのを思いなおす。</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀上 9:6; エレミヤ書 44:10; イザヤ書 1:20"> あなたは彼らに言いなさい、『主はこう仰せられる、もしあなたがたがわたしに聞き従わず、わたしがあなたがたの前に定めおいた律法を行わず、</span>
<span className="v" id="v5" data-v="5" data-xref="エレミヤ書 11:7; 列王紀下 9:7; エレミヤ書 7:13"> わたしがあなたがたに、しきりにつかわすわたしのしもべである預言者の言葉に聞き従わないならば、（あなたがたは聞き従わなかったが、）</span>
<span className="v" id="v6" data-v="6" data-xref="エレミヤ書 24:9; 列王紀下 22:19; エレミヤ書 25:18"> わたしはこの宮をシロのようにし、またこの町を地の万国にのろわれるものとする』」。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="エレミヤ書 5:31; ミカ書 3:11; 使徒行伝 5:17"> 祭司と預言者およびすべての民は、エレミヤが主の宮でこれらの言葉を語るのを聞いた。</span>
<span className="v" id="v8" data-v="8" data-xref="哀歌 4:13–14; 使徒行伝 7:52; エレミヤ書 18:18"> エレミヤが主に命じられたすべての言葉を民に告げ終った時、祭司と預言者および民はみな彼を捕えて言った、「あなたは死ななければならない。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行伝 4:17–19; 使徒行伝 19:24–32; ミカ書 2:6"> なぜあなたは主の名によって預言し、この宮はシロのようになり、この町は荒されて住む人もなくなるであろうと言ったのか」と。民はみな主の宮に集まってエレミヤを取り囲んだ。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="エレミヤ書 36:10; エレミヤ書 38:4–6; エレミヤ書 37:14–16"> ユダのつかさたちはこの事を聞いて王の宮殿を出て主の宮に上り、主の宮の「新しい門」の入口に座した。</span>
<span className="v" id="v11" data-v="11" data-xref="エレミヤ書 38:4; マタイによる福音書 26:66; 申命記 18:20"> 祭司と預言者らは、つかさたちとすべての民に訴えて言った、「この人は死刑に処すべき者です。あなたがたが自分の耳で聞かれたように、この町に逆らう預言をしたのです」。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="使徒行伝 5:29; エレミヤ書 26:15; 使徒行伝 4:19"> その時エレミヤは、つかさたちとすべての民に言った、「主はわたしをつかわし、この宮とこの町にむかって、預言をさせられたので、そのすべての言葉をあなたがたは聞いた。</span>
<span className="v" id="v13" data-v="13" data-xref="ヨナ書 3:9; ヨナ書 4:2; イザヤ書 1:19"> それで、あなたがたは今、あなたがたの道と行いを改め、あなたがたの神、主の声に聞き従いなさい。そうするならば主はあなたがたに災を下そうとしたことを思いなおされる。</span>
<span className="v" id="v14" data-v="14" data-xref="ヨシュア記 9:25; サムエル記下 15:26; エレミヤ書 38:5"> 見よ、わたしはあなたがたの手の中にある。あなたがたの目に、良いと見え、正しいと思うことをわたしに行うがよい。</span>
<span className="v" id="v15" data-v="15" data-xref="民数記 35:33; 箴言 6:17; マタイによる福音書 26:25"> ただ明らかにこのことを知っておきなさい。もしあなたがたがわたしを殺すならば、罪なき者の血はあなたがたの身と、この町と、その住民とに帰する。まことに主がわたしをつかわして、このすべての言葉をあなたがたの耳に、告げさせられたからである」。</span>
</div>
<div className="bp poetry">
<span className="v" id="v16" data-v="16" data-xref="使徒行伝 5:34–39; 使徒行伝 23:29; 使徒行伝 25:25"> つかさたちと、すべての民とは、祭司と預言者に言った、「この人は死刑に処すべき者ではない。われわれの神、主の名によってわれわれに語ったのである」。</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行伝 5:34; ミカ書 1:1"> その時この地の長老たち数人が立って、そこに集まっているすべての者に告げて言った、</span>
<span className="v" id="v18" data-v="18" data-xref="ミカ書 1:1; ネヘミヤ書 4:2; ゼカリヤ書 8:3"> 「ユダの王ヒゼキヤの世に、モレシテびとミカはユダのすべての民に預言して言った、『万軍の主はこう仰せられる、<br /><span className="pl pl-1">シオンは畑のように耕され、</span><br /><span className="pl pl-1">エルサレムは石塚となり、</span><br /><span className="pl pl-1">宮の山は木のおい茂る高い所となる』。</span></span>
<span className="v" id="v19" data-v="19" data-xref="出エジプト記 32:14; サムエル記下 24:16; イザヤ書 37:15–20"> <span className="pl pl-1">ユダの王ヒゼキヤと、すべてのユダの人は彼を殺そうとしたことがあろうか。ヒゼキヤは主を恐れ、主の恵みを求めたので、主は彼らに災を下すとお告げになったのを思いなおされたではないか。しかし、われわれは、自分の身に大きな災を招こうとしている」。</span></span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="サムエル記上 7:2; ヨシュア記 9:17; ヨシュア記 15:60"> 主の名によって預言した人がほかにもあった。すなわちキリアテ・ヤリムのシマヤの子ウリヤである。彼はエレミヤとおなじような言葉をもって、この町とこの地にむかって預言した。</span>
<span className="v" id="v21" data-v="21" data-xref="マタイによる福音書 10:23; マタイによる福音書 14:5; エレミヤ書 36:26"> エホヤキム王と、そのすべての勇士と、すべてのつかさたちはその言葉を聞いた。そして王は彼を殺そうと思ったが、ウリヤはこれを聞いて恐れ、エジプトに逃げて行ったので、</span>
<span className="v" id="v22" data-v="22" data-xref="エレミヤ書 36:12; 列王紀下 22:12; 列王紀下 22:14"> エホヤキム王は人をエジプトにつかわした。すなわちアクボルの子エルナタンと他の数名の人を、エジプトにつかわした。</span>
<span className="v" id="v23" data-v="23" data-xref="エレミヤ書 2:30; ヨハネの黙示録 11:7; エゼキエル書 19:6"> 彼らはウリヤをエジプトから引き出し、エホヤキム王のもとに連れてきたので、王はつるぎをもって彼を殺し、その死体を共同墓地に捨てさせた。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="エレミヤ書 40:5–7; エレミヤ書 39:14; エレミヤ書 1:18–19"> しかしシャパンの子アヒカムはエレミヤを助け、民の手に渡されて殺されることのないようにした。</span>
</div>

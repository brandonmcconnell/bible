<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="エステル記 9:20; 使徒行伝 15:23; ヘブル人への手紙 13:22"> これは預言者エレミヤがエルサレムから、かの捕え移された長老たち、およびネブカデネザルによってエルサレムからバビロンに捕え移された祭司と預言者ならびにすべての民に送った手紙に書きしるした言葉である。</span>
<span className="v" id="v2" data-v="2" data-xref="エレミヤ書 22:24–28; エレミヤ書 27:20; 歴代志下 36:9–10"> それはエコニヤ王と太后と宦官およびユダとエルサレムのつかさたち、および工匠と鍛冶とがエルサレムを去ってのちに書かれたものであって、</span>
<span className="v" id="v3" data-v="3" data-xref="エゼキエル書 8:11; 歴代志下 34:20; エレミヤ書 39:14"> エレミヤはその手紙をシャパンの子エラサおよびヒルキヤの子ゲマリヤの手によって送った。この人々はユダの王ゼデキヤがバビロンに行かせ、バビロンの王ネブカデネザルのもとにつかわしたものであった。その手紙には次のように書いてあった。</span>
<span className="v" id="v4" data-v="4" data-xref="エレミヤ書 24:5; イザヤ書 10:5–6; イザヤ書 45:7"> 「万軍の主、イスラエルの神は、すべて捕え移された者、すなわち、わたしがエルサレムから、バビロンに捕え移させた者に、こう言う、</span>
<span className="v" id="v5" data-v="5" data-xref="エレミヤ書 29:28; エレミヤ書 29:10; エゼキエル書 28:26"> あなたがたは家を建てて、それに住み、畑を作ってその産物を食べよ。</span>
<span className="v" id="v6" data-v="6" data-xref="創世記 24:3–4; 創世記 24:51; 創世記 28:1–4"> 妻をめとって、むすこ娘を産み、また、そのむすこに嫁をめとり、娘をとつがせて、むすこ娘を産むようにせよ。その所であなたがたの数を増し、減ってはならない。</span>
<span className="v" id="v7" data-v="7" data-xref="テモテヘの第一の手紙 2:1–2; エズラ記 6:10; ペテロの第一の手紙 2:13–17"> わたしがあなたがたを捕え移させたところの町の平安を求め、そのために主に祈るがよい。その町が平安であれば、あなたがたも平安を得るからである。</span>
<span className="v" id="v8" data-v="8" data-xref="エペソ人への手紙 5:6; エレミヤ書 5:31; テサロニケ人への第二の手紙 2:9–11"> 万軍の主、イスラエルの神はこう言われる、あなたがたのうちにいる預言者と占い師に惑わされてはならない。また彼らの見る夢に聞き従ってはならない。</span>
<span className="v" id="v9" data-v="9" data-xref="エレミヤ書 27:15; エレミヤ書 29:31; エレミヤ書 29:23"> それは、彼らがわたしの名によってあなたがたに偽りを預言しているからである。わたしが彼らをつかわしたのではないと主は言われる。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="ダニエル書 9:2; ゼカリヤ書 7:5; エレミヤ書 24:6–7"> 主はこう言われる、バビロンで七十年が満ちるならば、わたしはあなたがたを顧み、わたしの約束を果し、あなたがたをこの所に導き帰る。</span>
<span className="v" id="v11" data-v="11" data-xref="イザヤ書 55:8–12; 詩篇 33:11; ミカ書 4:12"> 主は言われる、わたしがあなたがたに対していだいている計画はわたしが知っている。それは災を与えようというのではなく、平安を与えようとするものであり、あなたがたに将来を与え、希望を与えようとするものである。</span>
<span className="v" id="v12" data-v="12" data-xref="マタイによる福音書 7:7–8; エレミヤ書 33:3; 詩篇 50:15"> その時、あなたがたはわたしに呼ばわり、来て、わたしに祈る。わたしはあなたがたの祈を聞く。</span>
<span className="v" id="v13" data-v="13" data-xref="申命記 4:29–31; 詩篇 119:2; マタイによる福音書 7:7"> あなたがたはわたしを尋ね求めて、わたしに会う。もしあなたがたが一心にわたしを尋ね求めるならば、</span>
<span className="v" id="v14" data-v="14" data-xref="エゼキエル書 36:1–38; エレミヤ書 30:3; 歴代志上 28:9"> わたしはあなたがたに会うと主は言われる。わたしはあなたがたの繁栄を回復し、あなたがたを万国から、すべてわたしがあなたがたを追いやった所から集め、かつ、わたしがあなたがたを捕われ離れさせたそのもとの所に、あなたがたを導き帰ろうと主は言われる。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="エレミヤ書 29:8–9; エレミヤ書 28:1–17; エゼキエル書 1:3"> あなたがたは、『主はバビロンでわれわれのために預言者たちを起された』と言ったが、――</span>
<span className="v" id="v16" data-v="16" data-xref="エレミヤ書 38:2–3; エレミヤ書 38:17–23; エゼキエル書 17:12–21"> 主はダビデの位に座している王と、この町に住むすべての民で、あなたがたと共に捕え移されなかった兄弟たちについて、こう言われる、</span>
<span className="v" id="v17" data-v="17" data-xref="エレミヤ書 24:8–10; エレミヤ書 29:18; エレミヤ書 24:1–3"> 『万軍の主はこう言われる、見よ、わたしは、つるぎと、ききんと、疫病を彼らに送り、彼らを悪くて食べられない腐ったいちじくのようにしてしまう。</span>
<span className="v" id="v18" data-v="18" data-xref="歴代志下 29:8; エレミヤ書 15:4; エレミヤ書 42:18"> わたしはつるぎと、ききんと、疫病をもって彼らのあとを追い、また彼らを地の万国に忌みきらわれるものとなし、わたしが彼らを追いやる国々で、のろいとなり、恐れとなり、物笑いとなり、はずかしめとならせる。</span>
<span className="v" id="v19" data-v="19" data-xref="エレミヤ書 6:19; エレミヤ書 26:5; エレミヤ書 7:24–26"> それは彼らがわたしの言葉に聞き従わなかったからであると主は言われる。わたしはこの言葉を、わたしのしもべである預言者たちによって、しきりに送ったが、あなたがたは聞こうともしなかったと主は言われる』。――</span>
<span className="v" id="v20" data-v="20" data-xref="エレミヤ書 24:5; ミカ書 4:10; エゼキエル書 3:15"> わたしがエルサレムからバビロンに送ったあなたがたすべての捕われ人よ、主の言葉を聞きなさい、</span>
<span className="v" id="v21" data-v="21" data-xref="エレミヤ書 14:14–15; 哀歌 2:14; エレミヤ書 29:8–9"> 『わたしの名によって、あなたがたに偽りを預言しているコラヤの子アハブと、マアセヤの子ゼデキヤについて万軍の主、イスラエルの神はこう仰せられる、見よ、わたしは彼らをバビロンの王ネブカデレザルの手に渡す。王はあなたがたの目の前で彼らを殺す。</span>
<span className="v" id="v22" data-v="22" data-xref="イザヤ書 65:15; ダニエル書 3:6; ダニエル書 3:21"> バビロンにいるユダの捕われ人は皆、彼らの名を、のろいの言葉に用いて、「主があなたをバビロンの王が火で焼いたゼデキヤとアハブのようにされるように」という。</span>
<span className="v" id="v23" data-v="23" data-xref="エレミヤ書 23:14; ヘブル人への手紙 4:13; マラキ書 3:5"> それは、彼らがイスラエルのうちで愚かな事をし、隣の妻と不義を行い、わたしが命じたのでない偽りの言葉を、わたしの名によって語ったことによるのである。わたしはそれを知っており、またその証人であると主は言われる』」。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="エレミヤ書 29:31–32"> ネヘラムびとシマヤにあなたは言いなさい、</span>
<span className="v" id="v25" data-v="25" data-xref="エレミヤ書 37:3; エレミヤ書 29:29; エレミヤ書 52:24"> 「万軍の主、イスラエルの神はこう仰せられる、あなたは自分の名でエルサレムにいるすべての民と、マアセヤの子祭司ゼパニヤおよびすべての祭司に手紙を送って言う、</span>
<span className="v" id="v26" data-v="26" data-xref="エレミヤ書 20:1–2; 列王紀下 9:11; ヨハネによる福音書 10:20"> 『主は祭司エホヤダに代ってあなたを祭司とし、主の宮をつかさどらせ、すべて狂い、かつ預言する者を足かせと首かせにつながせられる。</span>
<span className="v" id="v27" data-v="27" data-xref="歴代志下 25:16; エレミヤ書 43:2–3; エレミヤ書 29:26"> そうであるのに、どうしてあなたは、あなたがたに預言しているアナトテのエレミヤを戒めないのか。</span>
<span className="v" id="v28" data-v="28" data-xref="エレミヤ書 29:5; エレミヤ書 29:1; エレミヤ書 29:10"> 彼はバビロンにいるわれわれの所に手紙を送って、捕われの時はなお長いゆえ、あなたがたは家を建ててそこに住み、畑を作ってその産物を食べよと言ってきた』」。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="エレミヤ書 29:25"> 祭司ゼパニヤはこの手紙を預言者エレミヤに読み聞かせた。</span>
<span className="v" id="v30" data-v="30"> その時、主の言葉がエレミヤに臨んだ、</span>
<span className="v" id="v31" data-v="31" data-xref="エレミヤ書 29:9; エレミヤ書 29:23–24; エレミヤ書 14:14–15"> 「すべての捕われ人に書き送って言いなさい、ネヘラムびとシマヤの事について主はこう仰せられる、わたしはシマヤをつかわさなかったのに、彼があなたがたに預言して偽りを信じさせたので、</span>
<span className="v" id="v32" data-v="32" data-xref="エレミヤ書 28:16; 列王紀下 7:19–20; エレミヤ書 17:6"> 主はこう仰せられる、見よ、わたしはネヘラムびとシマヤとその子孫を罰する。彼は主に対する反逆を語ったゆえ、彼に属する者で、この民のうちに住み、わたしが自分の民に行おうとしている良い事を見るものはひとりもいない」。</span>
</div>

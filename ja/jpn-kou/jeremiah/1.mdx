<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歴代志上 6:60; エレミヤ書 11:21; 歴代志下 36:21"> ベニヤミンの地アナトテの祭司のひとりである、ヒルキヤの子エレミヤの言葉。</span>
<span className="v" id="v2" data-v="2" data-xref="列王紀上 13:20; ヨナ書 1:1; エレミヤ書 1:11"> アモンの子、ユダの王ヨシヤの時、すなわちその治世の十三年に、主の言葉がエレミヤに臨んだ。</span>
<span className="v" id="v3" data-v="3" data-xref="エレミヤ書 39:2; 歴代志下 36:5–8; 列王紀下 23:34"> その言葉はまたヨシヤの子、ユダの王エホヤキムの時にも臨んで、ヨシヤの子、ユダの王ゼデキヤの十一年の終り、すなわちその年の五月にエルサレムの民が捕え移された時にまで及んだ。</span>
</div>
<div className="bp poetry">
<span className="v" id="v4" data-v="4" data-xref="エゼキエル書 3:16; エゼキエル書 1:3; エレミヤ書 1:2"> 主の言葉がわたしに臨んで言う、</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 139:16; イザヤ書 49:1; ガラテヤ人への手紙 1:15–16"> <span className="pl pl-1">「わたしはあなたをまだ母の胎につくらないさきに、</span><br /><span className="pl pl-1">あなたを知り、</span><br /><span className="pl pl-1">あなたがまだ生れないさきに、</span><br /><span className="pl pl-1">あなたを聖別し、</span><br /><span className="pl pl-1">あなたを立てて万国の預言者とした」。</span></span>
<span className="v" id="v6" data-v="6" data-xref="出エジプト記 6:12; 出エジプト記 4:10–16; 列王紀上 3:7–9"> <span className="pl pl-1">その時わたしは言った、「ああ、主なる神よ、わたしはただ若者にすぎず、どのように語ってよいか知りません」。</span></span>
<span className="v" id="v7" data-v="7" data-xref="マルコによる福音書 16:15–16; エゼキエル書 3:27; 民数記 22:20"> <span className="pl pl-1">しかし主はわたしに言われた、</span><br /><span className="pl pl-1">「あなたはただ若者にすぎないと言ってはならない。</span><br /><span className="pl pl-1">だれにでも、すべてわたしがつかわす人へ行き、</span><br /><span className="pl pl-1">あなたに命じることをみな語らなければならない。</span></span>
<span className="v" id="v8" data-v="8" data-xref="ヨシュア記 1:5; ヨシュア記 1:9; イザヤ書 51:7"> <span className="pl pl-1">彼らを恐れてはならない、</span><br /><span className="pl pl-1">わたしがあなたと共にいて、</span><br /><span className="pl pl-1">あなたを救うからである」と主は仰せられる。</span></span>
<span className="v" id="v9" data-v="9" data-xref="ルカによる福音書 21:15; 出エジプト記 4:11–12; ルカによる福音書 12:12"> <span className="pl pl-1">そして主はみ手を伸べて、わたしの口につけ、主はわたしに言われた、</span><br /><span className="pl pl-1">「見よ、わたしの言葉をあなたの口に入れた。</span></span>
<span className="v" id="v10" data-v="10" data-xref="エレミヤ書 31:28; コリント人への第二の手紙 10:4–5; イザヤ書 44:26–28"> <span className="pl pl-1">見よ、わたしはきょう、</span><br /><span className="pl pl-1">あなたを万民の上と、万国の上に立て、</span><br /><span className="pl pl-1">あなたに、あるいは抜き、あるいはこわし、</span><br /><span className="pl pl-1">あるいは滅ぼし、あるいは倒し、</span><br /><span className="pl pl-1">あるいは建て、あるいは植えさせる」。</span></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="アモス書 7:8; アモス書 8:2; ゼカリヤ書 5:2"> 主の言葉がまたわたしに臨んで言う、「エレミヤよ、あなたは何を見るか」。わたしは答えた、「あめんどうの枝を見ます」。</span>
<span className="v" id="v12" data-v="12" data-xref="エゼキエル書 12:28; エゼキエル書 12:25; エゼキエル書 12:22–23"> 主はわたしに言われた、「あなたの見たとおりだ。わたしは自分の言葉を行おうとして見張っているのだ」。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="エゼキエル書 11:3; エゼキエル書 11:7; ゼカリヤ書 4:2"> 主の言葉がふたたびわたしに臨んで言う、「あなたは何を見るか」。わたしは答えた、「煮え立っているなべを見ます。北からこちらに向かっています」。</span>
<span className="v" id="v14" data-v="14" data-xref="イザヤ書 41:25; エレミヤ書 4:6; エレミヤ書 10:22"> 主はわたしに言われた、「災が北から起って、この地に住むすべての者の上に臨む」。</span>
<span className="v" id="v15" data-v="15" data-xref="エレミヤ書 43:10; エレミヤ書 25:9; エレミヤ書 9:11"> 主は言われる、「見よ、わたしは北の国々のすべての民を呼ぶ。彼らは来て、エルサレムの門の入口と、周囲のすべての城壁、およびユダのすべての町々に向かって、おのおのその座を設ける。</span>
<span className="v" id="v16" data-v="16" data-xref="エレミヤ書 7:9; エレミヤ書 19:4; 使徒行伝 7:41"> わたしは、彼らがわたしを捨てて、すべての悪事を行ったゆえに、わたしのさばきを彼らに告げる。彼らは他の神々に香をたき、自分の手で作った物を拝したのである。</span>
<span className="v" id="v17" data-v="17" data-xref="エレミヤ書 1:7–8; 列王紀上 18:46; ペテロの第一の手紙 1:13"> しかしあなたは腰に帯して立ち、わたしが命じるすべての事を彼らに告げよ。彼らを恐れてはならない。さもないと、わたしは彼らの前であなたをあわてさせる。</span>
<span className="v" id="v18" data-v="18" data-xref="イザヤ書 50:7; エゼキエル書 3:8–9; エレミヤ書 15:20"> 見よ、わたしはきょう、この全国と、ユダの王と、そのつかさと、その祭司と、その地の民の前に、あなたを堅き城、鉄の柱、青銅の城壁とする。</span>
<span className="v" id="v19" data-v="19" data-xref="ヨシュア記 1:9; エレミヤ書 1:8; エレミヤ書 20:11"> 彼らはあなたと戦うが、あなたに勝つことはできない。わたしがあなたと共にいて、あなたを救うからである」と主は言われる。</span>

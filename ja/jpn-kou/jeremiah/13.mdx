<span className="v" id="v1" data-v="1" data-xref="エレミヤ書 13:11; ヘブル人への手紙 1:1; エレミヤ書 27:2"> 主はわたしにこう言われた、「行って、亜麻布の帯を買い、腰に結べ。水につけてはならない」。</span>
<span className="v" id="v2" data-v="2" data-xref="エゼキエル書 2:8; ヨハネによる福音書 15:14; 箴言 3:5"> そこで、わたしは主の言葉に従い、帯を買って腰に結んだ。</span>
<span className="v" id="v3" data-v="3" data-xref="エレミヤ書 13:8"> 主の言葉は、再びわたしに臨んで言った、</span>
<span className="v" id="v4" data-v="4" data-xref="ミカ書 4:10; 詩篇 137:1; エレミヤ書 51:63–64"> 「あなたが買って腰に結んでいる帯を手に取り、立ってユフラテの川へ行き、その所の岩の裂け目にこれを隠せ」。</span>
<span className="v" id="v5" data-v="5" data-xref="出エジプト記 40:16; 出エジプト記 39:42–43; テモテヘの第二の手紙 2:3"> わたしは主が命じられたように、行って、これをユフラテの川のほとりに隠した。</span>
<span className="v" id="v6" data-v="6"> 多くの日を経てのち、主はわたしに言われた、「立って、ユフラテの川へ行き、あなたに命じて、そこに隠させた帯をその所から取ってきなさい」。</span>
<span className="v" id="v7" data-v="7" data-xref="ローマ人への手紙 3:12; イザヤ書 64:6; エレミヤ書 13:10"> そこでわたしはユフラテの川へ行き、地を掘って、隠した所から帯を取り出したが、その帯はそこなわれて、役に立たなくなっていた。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8"> その時、主の言葉がわたしに臨んだ、</span>
<span className="v" id="v9" data-v="9" data-xref="レビ記 26:19; エレミヤ書 13:15–17; ゼパニヤ書 3:11"> 「主はこう仰せられる、これと同じように、わたしはユダの高ぶりとエルサレムの大いなる高ぶりを、破るのである。</span>
<span className="v" id="v10" data-v="10" data-xref="エレミヤ書 16:12; エレミヤ書 9:14; 歴代志下 36:15–16"> この悪しき民はわたしの言葉を聞くことを拒み、自分の心を強情にして歩み、また他の神々に従ってこれに仕え、これを拝んでいる。彼らはこの帯のように、なんの役にも立たなくなる」。</span>
<span className="v" id="v11" data-v="11" data-xref="出エジプト記 19:5–6; エレミヤ書 33:9; 詩篇 81:11"> 主は言われる、「帯が人の腰に着くように、イスラエルのすべての家とユダのすべての家とをわたしに着かせ、これをわたしの民とし、名とし、誉とし、栄えとしようとした。しかし彼らは聞き従おうともしなかった」。</span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="エゼキエル書 24:19"> 「あなたはこの言葉を彼らに語らなければならない、『イスラエルの神はこう言われる、酒つぼには、みな酒が満ちる』と。彼らはあなたに言うであろう、『酒つぼに、みな酒が満ちることをわれわれが知らないことがあろうか』と。</span>
<span className="v" id="v13" data-v="13" data-xref="イザヤ書 63:6; 詩篇 75:8; 詩篇 60:3"> その時、あなたは彼らに言わなければならない、『主はこう言われる、見よ、わたしはこの地に住むすべての者と、ダビデの位に座す王たちと、祭司と預言者およびエルサレムに住むすべての者に酔いを満たし、</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 29:20; 詩篇 2:9; エレミヤ書 19:9–11"> 彼らを互に打ち当てて砕く。父と子をもそのようにすると、主は言われる。わたしは彼らをあわれまず、惜しまず、かわいそうとも思わずに滅ぼす』と」。</span>
<span className="v" id="v15" data-v="15" data-xref="イザヤ書 28:14–22; ヨハネの黙示録 2:29; 使徒行伝 4:19–20"> <span className="pl pl-1">耳を傾けて聞け、高ぶってはならない、</span><br /><span className="pl pl-1">主がお語りになるからである。</span></span>
<span className="v" id="v16" data-v="16" data-xref="イザヤ書 59:9; イザヤ書 8:22; イザヤ書 5:30"> <span className="pl pl-1">主がまだやみを起されないうちに、</span><br /><span className="pl pl-1">またあなたがたの足が</span><br /><span className="pl pl-1">薄暗がりの山につまずかないうちに、</span><br /><span className="pl pl-1">あなたがたの神、主に栄光を帰せよ。</span><br /><span className="pl pl-1">さもないと、あなたがたが光を望んでいる間に、</span><br /><span className="pl pl-1">主はそれを暗黒に変え、</span><br /><span className="pl pl-1">それを暗やみとされるからである。</span></span>
<span className="v" id="v17" data-v="17" data-xref="マラキ書 2:2; エレミヤ書 9:1; エレミヤ書 14:17"> <span className="pl pl-1">もしあなたがたが聞かないならば、</span><br /><span className="pl pl-1">わたしの魂はひそかな所で、</span><br /><span className="pl pl-1">あなたがたの高ぶりのために悲しむ。</span><br /><span className="pl pl-1">また主の群れが、かすめられたために、</span><br /><span className="pl pl-1">わたしの目はいたく泣いて、涙を流すのである。</span></span>
<span className="v" id="v18" data-v="18" data-xref="エレミヤ書 22:26; 列王紀下 24:12; 列王紀下 24:15"> <span className="pl pl-1">王と太后とに告げよ、</span><br /><span className="pl pl-1">「あなたがたは低い座にすわりなさい。</span><br /><span className="pl pl-1">麗しい冠はすでに</span><br /><span className="pl pl-1">あなたがたの頭から落ちてしまったからです」。</span></span>
<span className="v" id="v19" data-v="19" data-xref="エレミヤ書 52:27; エレミヤ書 39:9; 申命記 28:52"> <span className="pl pl-1">ネゲブの町々は閉ざされて、これを開く人がない。</span><br /><span className="pl pl-1">ユダはみな捕え移される、</span><br /><span className="pl pl-1">ことごとく捕え移される。</span></span>
<span className="v" id="v20" data-v="20" data-xref="エレミヤ書 6:22; エレミヤ書 1:14; ハバクク書 1:6"> <span className="pl pl-1">「目をあげて、北の方からくる者を見よ、</span><br /><span className="pl pl-1">あなたに賜わった群れ、</span><br /><span className="pl pl-1">あなたの麗しい群れはどこにいるのか。</span></span>
<span className="v" id="v21" data-v="21" data-xref="イザヤ書 13:8; エレミヤ書 4:31; エレミヤ書 5:31"> <span className="pl pl-1">彼らがあなたの親しみ慣れた人たちを、</span><br /><span className="pl pl-1">あなたの上に立ててかしらとするとき、</span><br /><span className="pl pl-1">あなたは何を言おうとするのか。</span><br /><span className="pl pl-1">あなたの苦しみは、</span><br /><span className="pl pl-1">子を産む女の苦しみのようでないであろうか。</span></span>
<span className="v" id="v22" data-v="22" data-xref="ナホム書 3:5; エレミヤ書 16:10–11; エレミヤ書 5:19"> <span className="pl pl-1">あなたが心のうちに、</span><br /><span className="pl pl-1">『どうしてこのようなことが</span><br /><span className="pl pl-1">わたしに起ったのか』というならば、</span><br /><span className="pl pl-1">あなたの罪が重いゆえに、</span><br /><span className="pl pl-1">あなたの着物のすそはあげられ、</span><br /><span className="pl pl-1">はずかしめを受けるのだ。</span></span>
<span className="v" id="v23" data-v="23" data-xref="エレミヤ書 2:22; エレミヤ書 9:5; マタイによる福音書 19:24–28"> <span className="pl pl-1">エチオピヤびとは</span><br /><span className="pl pl-1">その皮膚を変えることができようか。</span><br /><span className="pl pl-1">ひょうはその斑点を変えることができようか。</span><br /><span className="pl pl-1">もしそれができるならば、悪に慣れたあなたがたも、</span><br /><span className="pl pl-1">善を行うことができる。</span></span>
<span className="v" id="v24" data-v="24" data-xref="詩篇 1:4; レビ記 26:33; エゼキエル書 5:12"> <span className="pl pl-1">わたしはあなたがたを散らし、</span><br /><span className="pl pl-1">野の風に吹き散らされるもみがらのようにする。</span></span>
<span className="v" id="v25" data-v="25" data-xref="ヨブ記 20:29; エレミヤ書 2:32; 詩篇 9:17"> <span className="pl pl-1">主は言われる、これがあなたに授けられた定め、</span><br /><span className="pl pl-1">わたしが量ってあなたに与える分である。</span><br /><span className="pl pl-1">あなたがわたしを忘れて、</span><br /><span className="pl pl-1">偽りを頼みとしたからだ。</span></span>
<span className="v" id="v26" data-v="26" data-xref="哀歌 1:8; ホセア書 2:10; エゼキエル書 23:29"> <span className="pl pl-1">わたしはまたあなたの着物のすそを顔まであげて、</span><br /><span className="pl pl-1">あなたの恥をあらわす。</span></span>
<span className="v" id="v27" data-v="27" data-xref="ホセア書 8:5; エゼキエル書 6:13; エゼキエル書 24:13"> <span className="pl pl-1">わたしはあなたの憎むべき行い、</span><br /><span className="pl pl-1">あなたの姦淫と、いななき、</span><br /><span className="pl pl-1">野の丘の上で行ったあなたのみだらな行いを見た。</span><br /><span className="pl pl-1">エルサレムよ、あなたはわざわいだ、</span><br /><span className="pl pl-1">あなたの清められるのはいつのことであろうか」。</span></span>

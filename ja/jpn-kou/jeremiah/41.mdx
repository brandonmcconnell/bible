<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="エレミヤ書 40:8; エレミヤ書 40:6; 詩篇 41:9"> 七月のころ、王家のもので、エリシャマの子ネタニヤの子であり、また王の高官のひとりであるイシマエルは、王の十人のつかさたちと共にミヅパにいたアヒカムの子ゲダリヤのもとにきて、ミヅパで食を共にしたが、</span>
<span className="v" id="v2" data-v="2" data-xref="列王紀下 25:25; エレミヤ書 40:5; 詩篇 109:5"> ネタニヤの子イシマエルおよび共にいた十人の者は立ち上がって、バビロンの王がこの地の総督としたシャパンの子アヒカムの子であるゲダリヤを刀で殺し、</span>
<span className="v" id="v3" data-v="3" data-xref="列王紀下 25:25; 哀歌 1:2; エレミヤ書 41:11–12"> イシマエルはまたミヅパでゲダリヤと共にいたすべてのユダヤ人と、たまたまそこにいたカルデヤびとの兵士たちを殺した。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="サムエル記上 27:11; 詩篇 52:1–2"> ゲダリヤが殺された次の日、まだだれもその事を知らないうちに、</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀上 16:24; 申命記 14:1; ヨシュア記 18:1"> 八十人の人々がそのひげをそり、衣服をさき、身に傷をつけ、手には素祭のささげ物と香を携え、シケム、シロ、サマリヤからきて、主の宮にささげようとした。</span>
<span className="v" id="v6" data-v="6" data-xref="サムエル記下 3:16; エレミヤ書 50:4; サムエル記下 1:2–16"> ネタニヤの子イシマエルはミヅパから泣きながら出てきて彼らを迎え、彼らに会って、「アヒカムの子ゲダリヤのもとにおいでなさい」と言った。</span>
<span className="v" id="v7" data-v="7" data-xref="イザヤ書 59:7; 詩篇 55:23; エゼキエル書 22:27"> そして彼らが町の中にはいったとき、ネタニヤの子イシマエルは自分と一緒にいた人々と共に彼らを殺して、その死体を穴に投げ入れた。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨブ記 2:4; 箴言 13:8; ピリピ人への手紙 3:7–9"> しかしそのうちの十人はイシマエルに向かい、「わたしたちは畑に小麦、大麦、油、および蜜を隠しています、わたしたちを殺さないでください」と言ったので、彼らをその仲間と共に殺さないでしまった。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="士師記 6:2; 列王紀上 15:17–22; サムエル記上 13:6"> イシマエルが自分の殺した人々の死体を投げ入れた穴は、アサ王がイスラエルの王バアシャを恐れて掘った穴であった。ネタニヤの子イシマエルは殺した人々をこれに満たした。</span>
<span className="v" id="v10" data-v="10" data-xref="エレミヤ書 40:14; エレミヤ書 40:7; ネヘミヤ書 2:10"> 次いでイシマエルはミヅパに残っているすべての民、すなわち王の娘たちと侍衛の長ネブザラダンがアヒカムの子ゲダリヤに託したミヅパに残っているすべての民とを捕虜とした。ネタニヤの子イシマエルは彼らを捕虜とし、アンモンびとのもとに渡り行こうとして立ち去った。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="エレミヤ書 40:13–16; エレミヤ書 40:7–8; エレミヤ書 42:1"> カレヤの子ヨハナンおよび彼と共にいる軍勢の長たちはネタニヤの子イシマエルの行った悪事をみな聞き、</span>
<span className="v" id="v12" data-v="12" data-xref="サムエル記下 2:13; 創世記 14:14–16; サムエル記上 30:1–8"> その兵士たちを率いて、ネタニヤの子イシマエルと戦うために出て行き、ギベオンの大池のほとりで彼に会った。</span>
<span className="v" id="v13" data-v="13"> イシマエルと共にいる人々は、カレヤの子ヨハナンおよび彼と共にいる軍勢の長たちを見て喜んだ。</span>
<span className="v" id="v14" data-v="14"> そしてイシマエルがミヅパから捕虜にしてきた人々は身をめぐらしてカレヤの子ヨハナンのもとへ行った。</span>
<span className="v" id="v15" data-v="15" data-xref="ヨブ記 21:30; 箴言 28:17; 列王紀上 20:20"> ネタニヤの子イシマエルは八人の者と共にヨハナンを避けて逃げ、アンモンびとの所へ行った。</span>
<span className="v" id="v16" data-v="16" data-xref="エレミヤ書 43:4–7; エレミヤ書 42:8; エレミヤ書 41:10"> そこでカレヤの子ヨハナンおよび彼と共にいる軍勢の長たちはネタニヤの子イシマエルがアヒカムの子ゲダリヤを殺して、ミヅパから捕虜として連れてきた、あの残っていた民、すなわち兵士や女、子供、宦官をギベオンから連れ帰ったが、</span>
<span className="v" id="v17" data-v="17" data-xref="サムエル記下 19:37–38; エレミヤ書 42:14; エレミヤ書 43:7"> 彼らはエジプトへ行こうとしてベツレヘムの近くにあるゲルテ・キムハムへ行って、そこにとどまった。</span>
<span className="v" id="v18" data-v="18" data-xref="エレミヤ書 40:5; ルカによる福音書 12:4–5; エレミヤ書 42:16"> これは、ネタニヤの子イシマエルが、バビロンの王によってこの地の総督に任じられたアヒカムの子ゲダリヤを殺したことにより、カルデヤびとを恐れたからである。</span>
</div>

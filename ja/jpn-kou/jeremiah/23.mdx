<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="エレミヤ書 10:21; ゼカリヤ書 11:15–17; エゼキエル書 34:2–10"> 主は言われる、「わが牧場の羊を滅ぼし散らす牧者はわざわいである」。</span>
<span className="v" id="v2" data-v="2" data-xref="出エジプト記 32:34; エレミヤ書 21:12; ミカ書 7:4"> それゆえイスラエルの神、主はわが民を養う牧者についてこう言われる、「あなたがたはわたしの群れを散らし、これを追いやって顧みなかった。見よ、わたしはあなたがたの悪しき行いによってあなたがたに報いると、主は言われる。</span>
<span className="v" id="v3" data-v="3" data-xref="アモス書 9:14–15; エレミヤ書 32:37; イザヤ書 43:5–6"> わたしの群れの残った者を、追いやったすべての地から集め、再びこれをそのおりに帰らせよう。彼らは子を産んでその数が多くなる。</span>
<span className="v" id="v4" data-v="4" data-xref="エレミヤ書 3:14–15; ペテロの第一の手紙 1:5; エゼキエル書 34:23–31"> わたしはこれを養う牧者をその上に立てる、彼らは再び恐れることなく、またおののくことなく、いなくなることもないと、主は言われる。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="ルカによる福音書 1:32–33; イザヤ書 4:2; イザヤ書 9:7"> 主は仰せられる、見よ、わたしがダビデのために一つの正しい枝を起す日がくる。彼は王となって世を治め、栄えて、公平と正義を世に行う。</span>
<span className="v" id="v6" data-v="6" data-xref="コリント人への第一の手紙 1:30; エレミヤ書 33:16; ピリピ人への手紙 3:9"> その日ユダは救を得、イスラエルは安らかにおる。その名は『主はわれわれの正義』ととなえられる。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="エレミヤ書 16:14–15; エレミヤ書 23:3; イザヤ書 43:18–19"> 主は言われる、それゆえ見よ、人々は『イスラエルの民をエジプトの地から導き出された主は生きておられる』とまた言わないで、</span>
<span className="v" id="v8" data-v="8" data-xref="イザヤ書 43:5–6; アモス書 9:14–15; エゼキエル書 34:13"> 『イスラエルの家の子孫を北の地と、そのすべて追いやられた地から導き出された神は生きておられる』という日がくる。その時、彼らは自分の地に住んでいる」。</span>
</div>
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="ハバクク書 3:16; 哀歌 3:15; 詩篇 60:3"> 預言者たちについて。<br /><span className="pl pl-1">わが心はわたしのうちに破れ、</span><br /><span className="pl pl-1">わが骨はみな震う。</span><br /><span className="pl pl-1">主とその聖なる言葉のために、</span><br /><span className="pl pl-1">わたしは酔っている人のよう、</span><br /><span className="pl pl-1">酒に打ち負かされた人のようである。</span></span>
<span className="v" id="v10" data-v="10" data-xref="ホセア書 4:2–3; 詩篇 107:34; エレミヤ書 9:2"> <span className="pl pl-1">この地に姦淫を行うものが満ちているからだ。</span><br /><span className="pl pl-1">のろいによって地は嘆き、荒野の牧場はかわく。</span><br /><span className="pl pl-1">彼らの道は悪く、その力は正しくない。</span></span>
<span className="v" id="v11" data-v="11" data-xref="ゼパニヤ書 3:4; エレミヤ書 6:13; マタイによる福音書 21:12–13"> <span className="pl pl-1">「預言者と祭司とは共に神を汚す者である。</span><br /><span className="pl pl-1">わたしの家においてすら</span><br /><span className="pl pl-1">彼らの悪を見たと、主は言われる。</span></span>
<span className="v" id="v12" data-v="12" data-xref="エレミヤ書 13:16; エレミヤ書 11:23; 詩篇 35:6"> <span className="pl pl-1">それゆえ、彼らの道は、</span><br /><span className="pl pl-1">おのずから暗黒の中にある</span><br /><span className="pl pl-1">なめらかな道のようになり、</span><br /><span className="pl pl-1">彼らは押されてその道に倒れる。</span><br /><span className="pl pl-1">わたしが彼らの罰せられる年に、</span><br /><span className="pl pl-1">災をその上に臨ませるからであると、主は言われる。</span></span>
<span className="v" id="v13" data-v="13" data-xref="エレミヤ書 2:8; イザヤ書 9:16; 列王紀上 18:18–21"> <span className="pl pl-1">わたしはサマリヤの預言者のうちに</span><br /><span className="pl pl-1">不快な事のあるのを見た。</span><br /><span className="pl pl-1">彼らはバアルによって預言し、</span><br /><span className="pl pl-1">わが民イスラエルを惑わした。</span></span>
<span className="v" id="v14" data-v="14" data-xref="イザヤ書 1:9–10; エレミヤ書 29:23; エゼキエル書 22:25"> <span className="pl pl-1">しかしエルサレムの預言者のうちには、</span><br /><span className="pl pl-1">恐ろしい事のあるのを見た。</span><br /><span className="pl pl-1">彼らは姦淫を行い、偽りに歩み、</span><br /><span className="pl pl-1">悪人の手を強くし、</span><br /><span className="pl pl-1">人をその悪から離れさせない。</span><br /><span className="pl pl-1">彼らはみなわたしにはソドムのようであり、</span><br /><span className="pl pl-1">その民はゴモラのようである」。</span></span>
<span className="v" id="v15" data-v="15" data-xref="エレミヤ書 8:14; エレミヤ書 9:15; 哀歌 3:5"> <span className="pl pl-1">それゆえ万軍の主は預言者についてこう言われる、</span><br /><span className="pl pl-1">「見よ、わたしは彼らに、にがよもぎを食べさせ、</span><br /><span className="pl pl-1">毒の水を飲ませる。</span><br /><span className="pl pl-1">神を汚すことがエルサレムの預言者から出て、</span><br /><span className="pl pl-1">全地に及んでいるからである」。</span></span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="エレミヤ書 14:14; エゼキエル書 13:6; ガラテヤ人への手紙 1:8–9"> 万軍の主はこう言われる、「あなたがたに預言する預言者の言葉を聞いてはならない。彼らはあなたがたに、むなしい望みをいだかせ、主の口から出たのでない、自分の心の黙示を語るのである。</span>
<span className="v" id="v17" data-v="17" data-xref="ミカ書 3:11; エレミヤ書 13:10; アモス書 9:10"> 彼らは主の言葉を軽んじる者に向かって絶えず、『あなたがたは平安を得る』と言い、また自分の強情な心にしたがって歩むすべての人に向かって、『あなたがたに災はこない』と言う」。</span>
</div>
<div className="bp poetry">
<span className="v" id="v18" data-v="18" data-xref="エレミヤ書 23:22; イザヤ書 40:13–14; アモス書 3:7"> <span className="pl pl-1">彼らのうちだれか主の議会に立って、</span><br /><span className="pl pl-1">その言葉を見聞きした者があろうか。</span><br /><span className="pl pl-1">だれか耳を傾けてその言葉を聞いた者があろうか。</span></span>
<span className="v" id="v19" data-v="19" data-xref="エレミヤ書 30:23; エレミヤ書 25:32; アモス書 1:14"> <span className="pl pl-1">見よ、主の暴風がくる。</span><br /><span className="pl pl-1">憤りと、つむじ風が出て、悪人のこうべをうつ。</span></span>
<span className="v" id="v20" data-v="20" data-xref="エレミヤ書 30:24; イザヤ書 55:11; ゼカリヤ書 1:6"> <span className="pl pl-1">主の怒りは、み心に思い定められたことを</span><br /><span className="pl pl-1">なし遂げられるまで退くことはない。</span><br /><span className="pl pl-1">末の日にあなたがたはそれを明らかに悟る。</span></span>
<span className="v" id="v21" data-v="21" data-xref="エレミヤ書 14:14; エレミヤ書 27:15; エレミヤ書 23:32"> <span className="pl pl-1">預言者たちはわたしがつかわさなかったのに、</span><br /><span className="pl pl-1">彼らは走った。</span><br /><span className="pl pl-1">わたしが、彼らに告げなかったのに、</span><br /><span className="pl pl-1">彼らは預言した。</span></span>
<span className="v" id="v22" data-v="22" data-xref="エレミヤ書 23:18; ゼカリヤ書 1:4; エレミヤ書 25:5"> <span className="pl pl-1">もし彼らがわたしの議会に立ったのであれば、</span><br /><span className="pl pl-1">わたしの民にわが言葉を告げ示して、</span><br /><span className="pl pl-1">その悪い道と悪い行いから、離れさせたであろうに。</span></span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="詩篇 139:1–10; 列王紀上 20:23; 列王紀上 20:28"> 「主は言われる、わたしはただ近くの神であって、遠くの神ではないのであるか。</span>
<span className="v" id="v24" data-v="24" data-xref="箴言 15:3; 詩篇 139:7; 詩篇 90:8"> 主は言われる、人は、ひそかな所に身を隠して、わたしに見られないようにすることができようか。主は言われる、わたしは天と地とに満ちているではないか。</span>
<span className="v" id="v25" data-v="25" data-xref="エレミヤ書 23:32; エレミヤ書 23:28; エレミヤ書 29:8"> わが名によって偽りを預言する預言者たちが、『わたしは夢を見た、わたしは夢を見た』と言うのを聞いた。</span>
<span className="v" id="v26" data-v="26" data-xref="テモテヘの第一の手紙 4:1–2; エレミヤ書 14:14; テサロニケ人への第二の手紙 2:9–11"> 偽りを預言する預言者たちの心に、いつまで偽りがあるのであるか。彼らはその心の欺きを預言する。</span>
<span className="v" id="v27" data-v="27" data-xref="士師記 8:33–34; 士師記 3:7; 使徒行伝 13:8"> 彼らはその先祖がバアルに従ってわが名を忘れたように、互に夢を語って、わたしの民にわが名を忘れさせようとする。</span>
<span className="v" id="v28" data-v="28" data-xref="コリント人への第二の手紙 2:17; テモテヘの第一の手紙 1:12; コリント人への第一の手紙 3:12–13"> 夢をみた預言者は夢を語るがよい。しかし、わたしの言葉を受けた者は誠実にわたしの言葉を語らなければならない。わらと麦とをくらべることができようかと、主は言われる。</span>
<span className="v" id="v29" data-v="29" data-xref="ヘブル人への手紙 4:12; エレミヤ書 5:14; ルカによる福音書 24:32"> 主は仰せられる、わたしの言葉は火のようではないか。また岩を打ち砕く鎚のようではないか。</span>
<span className="v" id="v30" data-v="30" data-xref="申命記 18:20; エゼキエル書 13:8; エレミヤ書 14:14–15"> それゆえ見よ、わたしはわたしの言葉を互に盗む預言者の敵となると、主は言われる。</span>
<span className="v" id="v31" data-v="31" data-xref="エレミヤ書 23:17; 歴代志下 18:10–12; 歴代志下 18:5"> 見よ、わたしは、『主は言いたもう』と舌をもって語る預言者の敵となると、主は言われる。</span>
<span className="v" id="v32" data-v="32" data-xref="エゼキエル書 13:7–18; ゼパニヤ書 3:4; 哀歌 2:14"> 主は仰せられる、見よ、わたしは偽りの夢を預言する者の敵となる。彼らはそれを語り、またその偽りと大言をもってわたしの民を惑わす。わたしが彼らをつかわしたのではなく、また彼らに命じたのでもない。それで彼らはこの民にすこしも益にならないと、主は言われる。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="マラキ書 1:1; エレミヤ書 12:7; ハバクク書 1:1"> この民のひとり、または預言者、または祭司があなたに、『主の重荷はなんですか』と問うならば、彼らに答えなさい、『あなたがたがその重荷です。そして主は、あなたがたを捨てると言っておられます』と。</span>
<span className="v" id="v34" data-v="34" data-xref="ゼカリヤ書 13:3; 哀歌 2:14"> そして、『主の重荷』と言うその預言者、祭司、または民のひとりを、その家族と共にわたしは罰する。</span>
<span className="v" id="v35" data-v="35" data-xref="エレミヤ書 31:34; エレミヤ書 42:4; エレミヤ書 33:3"> あなたがたは、みな互に、隣り人に、また兄弟に、こう言わなければならない、『主はなんと答えられましたか』、『主はなんと言われましたか』と。</span>
<span className="v" id="v36" data-v="36" data-xref="エレミヤ書 10:10; ペテロの第二の手紙 3:16; イザヤ書 3:8"> しかし重ねて『主の重荷』と言ってはならない。重荷は人おのおのの自分の言葉だからである。あなたがたは生ける神、万軍の主なるわれわれの神の言葉を曲げる者である。</span>
<span className="v" id="v37" data-v="37"> あなたは預言者にこう言わなければならない、『主はあなたになんと答えられましたか』、『主はなんと言われましたか』と。</span>
<span className="v" id="v38" data-v="38" data-xref="歴代志下 11:13–14"> もしあなたがたが『主の重荷』と言うならば、主はこう仰せられる、『わたしが人をあなたがたにつかわして、あなたがたは「主の重荷」と言ってはならないと言わせたのに、あなたがたは「主の重荷」という言葉を言ったので、</span>
<span className="v" id="v39" data-v="39" data-xref="エレミヤ書 23:33; エゼキエル書 8:18; 箴言 13:13"> わたしは必ずあなたがたを捕え移させ、あなたがたとあなたがたの先祖とに与えたこの町と、あなたがたとを、わたしの前から捨て去る。</span>
<span className="v" id="v40" data-v="40" data-xref="エレミヤ書 20:11; エゼキエル書 5:14–15; エレミヤ書 42:18"> そして、忘れられることのない永遠のはずかしめと永遠の恥を、あなたがたにこうむらせる』」。</span>
</div>

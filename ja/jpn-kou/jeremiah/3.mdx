<span className="v" id="v2" data-v="2" data-xref="エレミヤ書 2:7; 創世記 38:14; エゼキエル書 8:4–6"> <span className="pl pl-1">「目をあげてもろもろの裸の山を見よ、</span><br /><span className="pl pl-1">姦淫を行わなかった所がどこにあるか。</span><br /><span className="pl pl-1">荒野にいるアラビヤびとがするように、</span><br /><span className="pl pl-1">あなたは道のかたわらに座して恋人を待った。</span><br /><span className="pl pl-1">あなたは姦淫の悪事をもって、この地を汚した。</span></span>
<span className="v" id="v3" data-v="3" data-xref="レビ記 26:19; エレミヤ書 14:4; 申命記 28:23"> <span className="pl pl-1">それゆえ雨はとどめられ、春の雨は降らなかった。</span><br /><span className="pl pl-1">しかもあなたには遊女の額があり、</span><br /><span className="pl pl-1">少しも恥じようとはしない。</span></span>
<span className="v" id="v4" data-v="4" data-xref="エレミヤ書 2:2; エレミヤ書 3:19; 詩篇 71:17"> <span className="pl pl-1">今あなたは、わたしを呼んで言ったではないか、</span><br /><span className="pl pl-1">『わが父よ、あなたはわたしの若い時の友です。</span></span>
<span className="v" id="v5" data-v="5" data-xref="ミカ書 7:3; イザヤ書 57:16; エゼキエル書 22:6"> <span className="pl pl-1">永久に怒られるのですか、</span><br /><span className="pl pl-1">終りまで憤られるのですか』と。</span><br /><span className="pl pl-1">見よ、あなたはこう言ったけれども、</span><br /><span className="pl pl-1">なしうるかぎりのもろもろの悪を行った」。</span></span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="列王紀下 17:7–17; エゼキエル書 16:31; エレミヤ書 7:24"> ヨシヤ王の時、主はまたわたしに言われた、「あなたは、かの背信のイスラエルがしたことを見たか。彼女はすべての高い丘にのぼり、すべての青木の下に行って、そこで姦淫を行った。</span>
<span className="v" id="v7" data-v="7" data-xref="エゼキエル書 16:46; ホセア書 6:1–4; ホセア書 14:1"> わたしは、彼女がこのすべてを行った後、わたしの所に帰るであろうと思ったが、帰ってこなかった。その不信の姉妹ユダはこれを見た。</span>
<span className="v" id="v8" data-v="8" data-xref="申命記 24:1; ホセア書 4:15–17; イザヤ書 50:1"> わたしが背信のイスラエルを、そのすべての姦淫のゆえに、離縁状を与えて出したのをユダは見た。しかもその不信の姉妹ユダは恐れず、自分も行って姦淫を行った。</span>
<span className="v" id="v9" data-v="9" data-xref="エレミヤ書 2:27; イザヤ書 57:6; エレミヤ書 3:2"> 彼女にとって姦淫は軽いことであったので、石と木とに姦淫を行って、この地を汚した。</span>
<span className="v" id="v10" data-v="10" data-xref="ホセア書 7:14; エレミヤ書 12:2; 歴代志下 34:33–18"> このすべての事があっても、なおその不信の姉妹ユダは真心をもってわたしに帰らない、ただ偽っているだけだ」と主は言われる。</span>
</div>
<div className="bp poetry">
<span className="v" id="v11" data-v="11" data-xref="エゼキエル書 23:11; エゼキエル書 16:51–52; ホセア書 11:7"> 主はまたわたしに言われた、「背信のイスラエルは不信のユダよりも自分の罪の少ないことを示した。</span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 86:15; エゼキエル書 33:11; 申命記 4:29–31"> あなたは行って北にむかい、この言葉をのべて言うがよい、<br /><span className="pl pl-1">『主は言われる、背信のイスラエルよ、帰れ。</span><br /><span className="pl pl-1">わたしは怒りの顔をあなたがたに向けない、</span><br /><span className="pl pl-1">わたしはいつくしみ深い者である。</span><br /><span className="pl pl-1">いつまでも怒ることはしないと、主は言われる。</span></span>
<span className="v" id="v13" data-v="13" data-xref="エレミヤ書 2:25; エレミヤ書 3:6; 申命記 12:2"> <span className="pl pl-1">ただあなたは自分の罪を認め、</span><br /><span className="pl pl-1">あなたの神、主にそむいて</span><br /><span className="pl pl-1">すべての青木の下で異なる神々に</span><br /><span className="pl pl-1">あなたの愛を惜しまず与えたこと、</span><br /><span className="pl pl-1">わたしの声に聞き従わなかったことを</span><br /><span className="pl pl-1">言いあらわせと、主は言われる。</span></span>
<span className="v" id="v14" data-v="14" data-xref="ホセア書 2:19–20; エレミヤ書 2:19; エレミヤ書 31:32"> <span className="pl pl-1">主は言われる、背信の子らよ、帰れ。</span><br /><span className="pl pl-1">わたしはあなたがたの夫だからである。</span><br /><span className="pl pl-1">町からひとり、氏族からふたりを取って、</span><br /><span className="pl pl-1">あなたがたをシオンへ連れて行こう。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="エレミヤ書 23:4; 使徒行伝 20:28; エペソ人への手紙 4:11–12"> わたしは自分の心にかなう牧者たちをあなたがたに与える。彼らは知識と悟りとをもってあなたがたを養う。</span>
<span className="v" id="v16" data-v="16" data-xref="イザヤ書 65:17; アモス書 9:14–15; エゼキエル書 37:26"> 主は言われる、あなたがたが地に増して多くなるとき、その日には、人々はかさねて「主の契約の箱」と言わず、これを思い出さず、これを覚えず、これを尋ねず、これを作らない。</span>
<span className="v" id="v17" data-v="17" data-xref="エゼキエル書 43:7; ミカ書 4:1–5; エレミヤ書 17:12"> そのときエルサレムは主のみ位ととなえられ、万国の民はここに集まる。すなわち主の名のもとにエルサレムに集まり、かさねて、かたくなに自分の悪い心に従うことはしない。</span>
<span className="v" id="v18" data-v="18" data-xref="エレミヤ書 31:8; ホセア書 1:11; アモス書 9:15"> その日には、ユダの家はイスラエルの家と一緒になり、北の地から出て、わたしがあなたがたの先祖たちに嗣業として与えた地に共に来る。</span>
<span className="v" id="v19" data-v="19" data-xref="エレミヤ書 3:4; エレミヤ書 31:9; イザヤ書 63:16"> <span className="pl pl-1">どのようにして、</span><br /><span className="pl pl-1">あなたをわたしの子どもたちのうちに置き、</span><br /><span className="pl pl-1">万国のうちで最も美しい嗣業である良い地を</span><br /><span className="pl pl-1">あなたに与えようかと、わたしは思っていた。</span><br /><span className="pl pl-1">わたしはまた、あなたがわたしを「わが父」と呼び、</span><br /><span className="pl pl-1">わたしに従って離れることはないと思っていた。</span></span>
<span className="v" id="v20" data-v="20" data-xref="イザヤ書 48:8; エレミヤ書 5:11; ホセア書 5:7"> <span className="pl pl-1">イスラエルの家よ、</span><br /><span className="pl pl-1">背信の妻が夫のもとを去るように、</span><br /><span className="pl pl-1">たしかに、あなたがたはわたしにそむいた』と</span><br /><span className="pl pl-1">主は言われる」。</span></span>
<span className="v" id="v21" data-v="21" data-xref="コリント人への第二の手紙 7:10; エレミヤ書 31:9; エレミヤ書 2:32"> <span className="pl pl-1">裸の山の上に声が聞える、</span><br /><span className="pl pl-1">イスラエルの民が悲しみ祈るのである。</span><br /><span className="pl pl-1">彼らが曲った道に歩み、その神、主を忘れたからだ。</span></span>
<span className="v" id="v22" data-v="22" data-xref="ホセア書 14:1; ホセア書 14:4; ゼカリヤ書 13:9"> <span className="pl pl-1">「背信の子どもたちよ、帰れ。</span><br /><span className="pl pl-1">わたしはあなたがたの背信をいやす」。</span><br /><span className="pl pl-1">「見よ、われわれはあなたのもとに帰ります。</span><br /><span className="pl pl-1">あなたはわれわれの神、主であらせられます。</span></span>
<span className="v" id="v23" data-v="23" data-xref="詩篇 121:1–2; 詩篇 3:8; イザヤ書 12:2"> <span className="pl pl-1">まことに、もろもろの丘は迷いであり、</span><br /><span className="pl pl-1">山の上の騒ぎも同じです。</span><br /><span className="pl pl-1">まことに、イスラエルの救は</span><br /><span className="pl pl-1">われわれの神、主にあるのです。</span></span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="ホセア書 9:10; エゼキエル書 16:63; エゼキエル書 16:61"> しかし、われわれの幼少の時から、恥ずべきことが、われわれの先祖のほねおって得たもの、すなわちその羊、その牛、およびそのむすこ、娘たちをことごとくのみ尽しました。</span>
<span className="v" id="v25" data-v="25" data-xref="エレミヤ書 22:21; 箴言 5:13; イザヤ書 50:11"> われわれは恥の中に伏し、はずかしめにおおわれています。それはわれわれと先祖とが、われわれの幼少の時から今日まで、われわれの神、主に罪を犯し、われわれの神、主の声に従わなかったからです」。</span>

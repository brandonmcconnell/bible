<span className="v" id="v1" data-v="1" data-xref="エレミヤ書 17:8"> ひでりの事についてエレミヤに臨んだ主の言葉。</span>
<span className="v" id="v2" data-v="2" data-xref="イザヤ書 3:26; エレミヤ書 8:21; サムエル記上 5:12"> <span className="pl pl-1">「ユダは悲しみ、</span><br /><span className="pl pl-1">その町々の門は傾き、</span><br /><span className="pl pl-1">民は地に座して嘆き、</span><br /><span className="pl pl-1">エルサレムの叫びはあがる。</span></span>
<span className="v" id="v3" data-v="3" data-xref="サムエル記下 15:30; 詩篇 40:14; 列王紀下 18:31"> <span className="pl pl-1">その君たちは、しもべをつかわして水をくませる。</span><br /><span className="pl pl-1">彼らが井戸の所にきても、水は見つからず、</span><br /><span className="pl pl-1">むなしい器をもって帰り、</span><br /><span className="pl pl-1">恥じ、かつ当惑して、その頭をおおう。</span></span>
<span className="v" id="v4" data-v="4" data-xref="ヨエル書 1:19–20; ヨエル書 1:11; エレミヤ書 3:3"> <span className="pl pl-1">地に雨が降らず、土が、かわいて割れたため、</span><br /><span className="pl pl-1">農夫は恥じて、その頭をおおう。</span></span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 29:9; ヨブ記 39:1–4; イザヤ書 15:6"> <span className="pl pl-1">野にいる雌じかでさえも子を産んで、これを捨てる。</span><br /><span className="pl pl-1">草がないからである。</span></span>
<span className="v" id="v6" data-v="6" data-xref="エレミヤ書 2:24; ヨブ記 39:5–6; ヨエル書 1:18"> <span className="pl pl-1">野ろばは、はげ山の上に立って、</span><br /><span className="pl pl-1">山犬のようにあえぎ、</span><br /><span className="pl pl-1">草のないために、その目はくらむ。</span></span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 25:11; ホセア書 5:5; エレミヤ書 14:20–21"> <span className="pl pl-1">主よ、われわれの罪がわれわれを訴えて</span><br /><span className="pl pl-1">不利な証言をしても、</span><br /><span className="pl pl-1">あなたの名のために、事をなしてください。</span><br /><span className="pl pl-1">われわれの背信の数は多く、</span><br /><span className="pl pl-1">あなたに向かって罪を犯しました。</span></span>
<span className="v" id="v8" data-v="8" data-xref="エレミヤ書 17:13; エレミヤ書 50:7; イザヤ書 43:3"> <span className="pl pl-1">イスラエルの望みなる主よ、</span><br /><span className="pl pl-1">悩みの時の救主よ、</span><br /><span className="pl pl-1">なぜ、あなたはこの地に住む異邦の人のようにし、</span><br /><span className="pl pl-1">また一夜の宿りのために立ち寄る旅びとのように</span><br /><span className="pl pl-1">なさらねばならないのですか。</span></span>
<span className="v" id="v9" data-v="9" data-xref="イザヤ書 63:19; イザヤ書 59:1; エレミヤ書 15:16"> <span className="pl pl-1">なぜ、あなたは、うろたえている人のようにし、</span><br /><span className="pl pl-1">また人を救いえない勇士のように</span><br /><span className="pl pl-1">なさらねばならないのですか。</span><br /><span className="pl pl-1">主よ、あなたはわれわれのうちにいらせられます。</span><br /><span className="pl pl-1">われわれは、み名によって呼ばれている者です。</span><br /><span className="pl pl-1">われわれを見捨てないでください」。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="ホセア書 9:9; ホセア書 8:13; 詩篇 119:101"> この民について主はこう言われる、<br /><span className="pl pl-1">「彼らはこのように好んで、さまよい、</span><br /><span className="pl pl-1">その足をとどめることをしなかったので、</span><br /><span className="pl pl-1">主は彼らを喜ばず、</span><br /><span className="pl pl-1">いまそのとがを覚え、その罪を罰するのだ」。</span></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="エレミヤ書 7:16; エレミヤ書 11:14; 出エジプト記 32:32–34"> 主はわたしに言われた、「この民のために恵みを祈ってはならない。</span>
<span className="v" id="v12" data-v="12" data-xref="エレミヤ書 11:11; エゼキエル書 8:18; 箴言 1:28"> 彼らが断食しても、わたしは彼らの呼ぶのを聞かない。燔祭と素祭をささげても、わたしはそれを受けない。かえって、つるぎと、ききん、および疫病をもって、彼らを滅ぼしてしまう」。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="エレミヤ書 6:14; エレミヤ書 4:10; ペテロの第二の手紙 2:1"> わたしは言った、「ああ、主なる神よ、預言者たちはこの民に向かい、『あなたがたは、つるぎを見ることはない。ききんもこない。わたしはこの所に確かな平安をあなたがたに与える』と言っています」。</span>
<span className="v" id="v14" data-v="14" data-xref="エゼキエル書 13:6–7; エゼキエル書 12:24; エレミヤ書 29:8–9"> 主はわたしに言われた、「預言者らはわたしの名によって偽りの預言をしている。わたしは彼らをつかわさなかった。また彼らに命じたこともなく、話したこともない。彼らは偽りの黙示と、役に立たない占い、および自分の心でつくりあげた欺きをあなたがたに預言しているのだ。</span>
<span className="v" id="v15" data-v="15" data-xref="エレミヤ書 5:12–13; エゼキエル書 14:10; エレミヤ書 23:14–15"> それゆえ、わたしがつかわさないのに、わたしの名によって預言して、『つるぎとききんは、この地にこない』と言っているあの預言者について、主はこう仰せられる、この預言者らは、つるぎとききんに滅ぼされる。</span>
<span className="v" id="v16" data-v="16" data-xref="エレミヤ書 7:33; 箴言 1:31; エレミヤ書 15:2–3"> また彼らの預言を聞く民は、ききんとつるぎとによって、エルサレムのちまたに投げ捨てられる。だれもこれを葬る者はない。彼らとその妻、およびそのむすこ娘も同様である。わたしが彼らの悪をその上に注ぐからである。</span>
</div>
<div className="bp poetry">
<span className="v" id="v17" data-v="17" data-xref="エレミヤ書 8:21; エレミヤ書 9:1; エレミヤ書 13:17"> この言葉を彼らに語れ、<br /><span className="pl pl-1">『わたしの目は夜も昼も絶えず涙を流す。</span><br /><span className="pl pl-1">わが民の娘であるおとめが大きな傷と</span><br /><span className="pl pl-1">重い打撃によって滅ぼされるからである。</span></span>
<span className="v" id="v18" data-v="18" data-xref="エゼキエル書 7:15; 哀歌 1:20; エレミヤ書 8:10"> <span className="pl pl-1">わたしが出て畑に行くと、</span><br /><span className="pl pl-1">つるぎで殺された者がある。</span><br /><span className="pl pl-1">町にはいると、ききんで病んでいる者がある。</span><br /><span className="pl pl-1">預言者も祭司も共にその地にさまよって、</span><br /><span className="pl pl-1">知るところがない』」。</span></span>
</div>
<div className="bp poetry">

<span className="v" id="v20" data-v="20" data-xref="エレミヤ書 3:25; 詩篇 32:5; ヨハネの第一の手紙 1:7–9"> <span className="pl pl-1">主よ、われわれは自分の悪と、</span><br /><span className="pl pl-1">先祖のとがとを認めています。</span><br /><span className="pl pl-1">われわれはあなたに罪を犯しました。</span></span>
<span className="v" id="v21" data-v="21" data-xref="エレミヤ書 14:7; 詩篇 106:45; エレミヤ書 3:17"> <span className="pl pl-1">み名のために、われわれを捨てないでください。</span><br /><span className="pl pl-1">あなたの栄えあるみ位を</span><br /><span className="pl pl-1">はずかしめないでください。</span><br /><span className="pl pl-1">あなたがわれわれにお立てになった契約を覚えて、</span><br /><span className="pl pl-1">それを破らないでください。</span></span>
<span className="v" id="v22" data-v="22" data-xref="ヨエル書 2:23; エレミヤ書 5:24; 詩篇 135:7"> <span className="pl pl-1">異邦の偽りの神々のうちに、</span><br /><span className="pl pl-1">雨を降らせうる者があるであろうか。</span><br /><span className="pl pl-1">天が自分で夕立ちを降らすことができようか。</span><br /><span className="pl pl-1">われわれの神、主よ、</span><br /><span className="pl pl-1">あなたこそ、これをなさる方ではありませんか。</span><br /><span className="pl pl-1">われわれの待ち望むのはあなたです。</span><br /><span className="pl pl-1">あなたがこれらすべてのことをなさるからです。</span></span>

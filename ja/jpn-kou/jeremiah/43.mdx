<span className="v" id="v1" data-v="1" data-xref="エレミヤ書 26:8; エレミヤ書 51:63; エレミヤ書 42:22"> エレミヤがすべての民にむかって、彼らの神、主の言葉をことごとく語り、彼らの神、主が自分をつかわして言わせられるその言葉をみな告げ終った時、</span>
<span className="v" id="v2" data-v="2" data-xref="歴代志下 36:13; イザヤ書 7:9; エレミヤ書 40:8"> ホシャヤの子アザリヤと、カレヤの子ヨハナンおよび高慢な人々はみなエレミヤに言った、「あなたは偽りを言っている。われわれの神、主が、『エジプトへ行ってそこに住むな』と言わせるためにあなたをつかわされたのではない。</span>
<span className="v" id="v3" data-v="3" data-xref="エレミヤ書 45:1–3; エレミヤ書 36:4; エレミヤ書 36:26"> ネリヤの子バルクがあなたをそそのかして、われわれに逆らわせ、われわれをカルデヤびとの手に渡して殺すか、あるいはバビロンに捕え移させるのだ」。</span>
<span className="v" id="v4" data-v="4" data-xref="エレミヤ書 42:5–6; 詩篇 37:3; 歴代志下 25:16"> こうしてカレヤの子ヨハナンと軍勢の長たちおよび民らは皆、主の声にしたがわず、ユダの地にとどまろうとしなかった。</span>
<span className="v" id="v5" data-v="5" data-xref="エレミヤ書 40:11–12; エレミヤ書 41:15–16; サムエル記上 26:19"> そしてカレヤの子ヨハナンと軍勢の長たちは、ユダに残っている者すなわち追いやられた国々からユダの地に住むために帰ってきた者、――</span>
<span className="v" id="v6" data-v="6" data-xref="エレミヤ書 39:10; エレミヤ書 40:7; エレミヤ書 41:10"> 男、女、子供、王の娘たち、およびすべて侍衛の長ネブザラダンがシャパンの子であるアヒカムの子ゲダリヤに渡しておいた者、ならびに預言者エレミヤとネリヤの子バルクをつれて、</span>
<span className="v" id="v7" data-v="7" data-xref="エレミヤ書 2:16; エレミヤ書 44:1; イザヤ書 30:4"> エジプトの地へ行った。彼らは主の声にしたがわなかったのである。そして彼らはついにタパネスに行った。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="エレミヤ書 2:16; 詩篇 139:7; テモテヘの第二の手紙 2:9"> 主の言葉はタパネスでエレミヤに臨んだ、</span>
<span className="v" id="v9" data-v="9" data-xref="エレミヤ書 18:2–12; エレミヤ書 19:1–15; エレミヤ書 51:63–64"> 「大きな石を手に取り、ユダの人々の目の前で、これをタパネスにあるパロの宮殿の入口の敷石のしっくいの中に隠して、</span>
<span className="v" id="v10" data-v="10" data-xref="イザヤ書 44:28–1; エレミヤ書 1:15; 詩篇 31:20"> 彼らに言いなさい、『万軍の主、イスラエルの神はこう言われる、見よ、わたしは使者をつかわして、わたしのしもべであるバビロンの王ネブカデレザルを招く。彼はその位をこの隠した石の上にすえ、その上に王の天蓋を張る。</span>
<span className="v" id="v11" data-v="11" data-xref="エレミヤ書 15:2; エレミヤ書 44:13; エゼキエル書 29:19–20"> 彼は来てエジプトの地を撃ち、疫病に定まっている者を疫病に渡し、とりこに定まっている者をとりこにし、つるぎに定まっている者をつるぎにかける。</span>
<span className="v" id="v12" data-v="12" data-xref="エゼキエル書 30:13; 詩篇 109:18–19; イザヤ書 19:1"> 彼はエジプトの神々の宮に火をつけてこれを焼き、彼らをとりこにする。そして羊を飼う者が着物の虫をはらいきよめるように、エジプトの地をきよめる。彼は安らかにそこを去る。</span>
<span className="v" id="v13" data-v="13" data-xref="イザヤ書 19:18"> 彼はエジプトの地にあるヘリオポリスのオベリスクをこわし、エジプトの神々の宮を火で焼く』」。</span>

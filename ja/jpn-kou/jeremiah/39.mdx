<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="エゼキエル書 24:1–2; エレミヤ書 52:4–7; 列王紀下 25:1–12"> ユダの王ゼデキヤの九年十月、バビロンの王ネブカデレザルはその全軍を率い、エルサレムに来てこれを攻め囲んだが、</span>
<span className="v" id="v2" data-v="2" data-xref="エレミヤ書 52:6–7; ミカ書 2:12–13; 列王紀下 25:3–4"> ゼデキヤの十一年四月九日になって町の一角が破れた。</span>
<span className="v" id="v3" data-v="3" data-xref="エレミヤ書 21:4; エレミヤ書 38:17; エレミヤ書 39:13"> エルサレムが取られたので、バビロンの王のつかさたち、すなわちネルガル・シャレゼル、サムガル・ネボ、ラブサリスのサルセキム、ラブマグのネルガル・シャレゼルおよびバビロンの王のその他のつかさたちは皆ともに来て中の門に座した。</span>
<span className="v" id="v4" data-v="4" data-xref="アモス書 2:14; 歴代志下 32:5; 列王紀下 25:4–7"> ユダの王ゼデキヤとすべての兵士たちはこれを見て逃げ、夜のうちに、王の庭園の道を通って、二つの城壁の間の門から町を出て、アラバの方へ行ったが、</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀下 23:33; ヨシュア記 5:10; エレミヤ書 52:26–27"> カルデヤびとの軍勢はこれを追って、エリコの平地でゼデキヤに追いつき、これを捕えて、ハマテの地リブラにいるバビロンの王ネブカデレザルのもとに引いて行ったので、王はそこで彼の罪をさだめた。</span>
<span className="v" id="v6" data-v="6" data-xref="エレミヤ書 52:10; エレミヤ書 34:19–21; エレミヤ書 24:8–10"> バビロンの王はリブラで、ゼデキヤの子たちを彼の目の前で殺した。バビロンの王はまたユダのすべての貴族たちを殺した。</span>
<span className="v" id="v7" data-v="7" data-xref="エゼキエル書 12:13; 列王紀下 25:7; エレミヤ書 52:11"> 王はまたゼデキヤの目をつぶさせ、彼をバビロンに引いて行くために、鎖につないだ。</span>
<span className="v" id="v8" data-v="8" data-xref="ネヘミヤ書 1:3; エレミヤ書 38:18; エレミヤ書 21:10"> またカルデヤびとは王宮と民家を火で焼き、エルサレムの城壁を破壊した。</span>
<span className="v" id="v9" data-v="9" data-xref="エレミヤ書 40:1; 創世記 37:36; エレミヤ書 10:18"> そして侍衛の長ネブザラダンは町のうちに残っている民と、自分に降伏した者、およびその他の残っている民をバビロンに捕え移した。</span>
<span className="v" id="v10" data-v="10" data-xref="列王紀下 25:12; エレミヤ書 40:7; エレミヤ書 52:16"> しかし侍衛の長ネブザラダンは、民の貧しい無産者をユダの地に残し、同時にぶどう畑と田地をこれに与えた。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="使徒行伝 24:23; エレミヤ書 15:21; ヨブ記 5:19"> さてバビロンの王ネブカデレザルはエレミヤの事について侍衛の長ネブザラダンに命じて言った、</span>
<span className="v" id="v12" data-v="12" data-xref="箴言 16:7; エレミヤ書 40:4; 箴言 21:1"> 「彼をとり、よく世話をせよ。害を加えることなく、彼があなたに言うようにしてやりなさい」。</span>
<span className="v" id="v13" data-v="13" data-xref="エレミヤ書 39:3; エレミヤ書 39:9"> そこで侍衛の長ネブザラダン、ラブサリスのネブシャズバン、ラブマグのネルガル・シャレゼル、およびバビロンの王のつかさたちは、</span>
<span className="v" id="v14" data-v="14" data-xref="エレミヤ書 38:28; 列王紀下 22:12; エレミヤ書 26:24"> 人をつかわして、エレミヤを監視の庭から連れてこさせ、シャパンの子アヒカムの子であるゲダリヤに託して、家につれて行かせた。こうして彼は民のうちにいた。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="テモテヘの第二の手紙 2:9; エレミヤ書 32:1–2; エレミヤ書 36:1–5"> エレミヤが監視の庭に閉じこめられていた時、主の言葉が彼に臨んだ、</span>
<span className="v" id="v16" data-v="16" data-xref="ダニエル書 9:12; ゼカリヤ書 1:6; ヨシュア記 23:14–15"> 「行って、エチオピヤびとエベデメレクに告げなさい、『万軍の主、イスラエルの神はこう言われる、わたしの言った災をわたしはこの町に下す、幸をこれに下すのではない。その日、この事があなたの目の前で成就する。</span>
<span className="v" id="v17" data-v="17" data-xref="詩篇 41:1–2; 詩篇 91:14–15; 詩篇 50:15"> 主は言われる、その日わたしはあなたを救う。あなたは自分の恐れている人々の手に渡されることはない。</span>
<span className="v" id="v18" data-v="18" data-xref="エレミヤ書 38:2; 詩篇 34:22; エレミヤ書 21:9"> わたしが必ずあなたを救い、つるぎに倒れることのないようにするからである。あなたの命はあなたのぶんどり物となる。あなたがわたしに寄り頼んだからであると主は言われる』」。</span>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1"> 主からエレミヤに臨んだ言葉は言う、</span>
<span className="v" id="v2" data-v="2" data-xref="エレミヤ書 11:6; 出エジプト記 19:5; 歴代志下 29:10"> 「この契約の言葉を聞き、ユダの人々とエルサレムに住む者に告げよ。</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 27:26; 申命記 28:15–68; 申命記 29:19–20"> 彼らに言え、イスラエルの神、主はこう仰せられる、この契約の言葉に従わない人は、のろわれる。</span>
<span className="v" id="v4" data-v="4" data-xref="レビ記 26:12; エレミヤ書 7:22–23; 申命記 4:20"> この契約は、わたしがあなたがたの先祖をエジプトの地、鉄のかまどの中から導き出した時に、彼らに命じたところのものである。すなわち、その時わたしは彼らに言った、わたしの声を聞き、あなたがたに命じるすべてのことを行うならば、あなたがたはわたしの民となり、わたしはあなたがたの神となる。</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 7:12–13; 詩篇 105:9–11; エレミヤ書 28:6"> そして、わたしがあなたがたの先祖に、乳と蜜との流れる地を与えると誓ったことを、なし遂げると。すなわち今日のとおりである」。その時わたしは、「主よ、仰せのとおりです」と答えた。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="ヤコブの手紙 1:22; ローマ人への手紙 2:13; エレミヤ書 7:2"> 主はわたしに言われた、「このすべての言葉を、ユダの町々と、エルサレムのちまたに告げ示し、この契約の言葉を聞き、これを行え、と言いなさい。</span>
<span className="v" id="v7" data-v="7" data-xref="歴代志下 36:15; エペソ人への手紙 4:17; サムエル記上 8:9"> わたしは、あなたがたの先祖をエジプトの地から導き出した時から今日にいたるまで、おごそかに彼らを戒め、絶えず戒めて、わたしの声に聞き従うようにと言った。</span>
<span className="v" id="v8" data-v="8" data-xref="エレミヤ書 7:24; エレミヤ書 7:26; エレミヤ書 35:15"> しかし彼らは従わず、その耳を傾けず、おのおの自分の悪い強情な心に従って歩んだ。それゆえ、わたしはこの契約の言葉をもって彼らを責めた。これはわたしが彼らに行えと命じたが、行わなかったものである」。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="ホセア書 6:9; マタイによる福音書 26:3–4; ミカ書 3:11"> 主はまたわたしに言われた、「ユダの人々とエルサレムに住む者のうちに反逆の事がある。</span>
<span className="v" id="v10" data-v="10" data-xref="申命記 31:16; エゼキエル書 16:59; 詩篇 78:8–10"> 彼らは、わたしの言葉を聞くことを拒んだその先祖たちの罪に立ち返り、またほかの神々に従ってそれに仕えた。イスラエルの家とユダの家とは、わたしがその先祖たちと結んだ契約を破った。</span>
<span className="v" id="v11" data-v="11" data-xref="エゼキエル書 8:18; 箴言 1:28; イザヤ書 1:15"> それゆえ主はこう言われる、見よ、わたしは災を彼らの上に下す。彼らはそれを免れることはできない。彼らがわたしを呼んでも、わたしは聞かない。</span>
<span className="v" id="v12" data-v="12" data-xref="エレミヤ書 2:28; 申命記 32:37; 歴代志下 28:22"> ユダの町々とエルサレムに住む者は、行って、自分たちがそれに香をたいている神々に呼び求めるが、これらは、彼らの災の時にも決して彼らを救うことはできない。</span>
<span className="v" id="v13" data-v="13" data-xref="エレミヤ書 2:28; 列王紀下 23:13; イザヤ書 2:8"> ユダよ、あなたの神々は、あなたの町の数ほど多くなった。またあなたがたはエルサレムのちまたの数ほどの祭壇を恥ずべき者のために立てた。すなわちバアルに香をたくための祭壇である。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="エレミヤ書 7:16; エレミヤ書 11:11; ヨハネの第一の手紙 5:16"> それゆえ、この民のために祈ってはならない。また彼らのために泣き、あるいは祈り求めてはならない。彼らがその災の時に、わたしに呼ばわっても、わたしは彼らに聞くことをしないからだ。</span>
<span className="v" id="v15" data-v="15" data-xref="箴言 2:14; テトスヘの手紙 1:15; エレミヤ書 3:1–2"> わが愛する者は、わたしの家で何をするのか。すでにこれは悪事を行った。誓願と犠牲の肉とがあなたに災を免れさせることができるであろうか。それであなたは喜ぶことができるであろうか。</span>
<span className="v" id="v16" data-v="16" data-xref="ローマ人への手紙 11:17–24; イザヤ書 27:11; 詩篇 52:8"> 主はあなたを、かつては『良い実のなる美しい青々としたオリブの木』と呼ばれたが、激しい暴風のとどろきと共に、主はそれに火をかけ、その枝を焼き払われるのである。</span>
<span className="v" id="v17" data-v="17" data-xref="イザヤ書 5:2; エレミヤ書 2:21; エレミヤ書 12:2"> あなたを植えた万軍の主は、あなたに向かって災を言い渡された。これはイスラエルの家とユダの家とが悪を行い、バアルに香をたいて、わたしを怒らせたからである」。</span>
</div>
<div className="bp poetry">
<span className="v" id="v18" data-v="18" data-xref="サムエル記上 23:11–12; 列王紀下 6:9–10; エゼキエル書 8:6–18"> <span className="pl pl-1">主が知らせてくださったので、</span><br /><span className="pl pl-1">わたしはそれを知った。</span><br /><span className="pl pl-1">その時、あなたは彼らの悪しきわざを</span><br /><span className="pl pl-1">わたしに示された。</span></span>
<span className="v" id="v19" data-v="19" data-xref="イザヤ書 53:7–8; エレミヤ書 20:10; 詩篇 83:4"> <span className="pl pl-1">しかしわたしは、</span><br /><span className="pl pl-1">ほふられに行く、おとなしい小羊のようで、</span><br /><span className="pl pl-1">彼らがわたしを害しようと、</span><br /><span className="pl pl-1">計りごとをめぐらしているのを知らなかった。</span><br /><span className="pl pl-1">彼らは言う、「さあ、木とその実を共に滅ぼそう。</span><br /><span className="pl pl-1">生ける者の地から彼を絶って、</span><br /><span className="pl pl-1">その名を人に忘れさせよう」。</span></span>
<span className="v" id="v20" data-v="20" data-xref="エレミヤ書 20:12; エレミヤ書 17:10; サムエル記上 16:7"> <span className="pl pl-1">正しいさばきをし、</span><br /><span className="pl pl-1">人の心と思いを探られる万軍の主よ、</span><br /><span className="pl pl-1">わたしは自分の訴えをあなたにお任せしました。</span><br /><span className="pl pl-1">あなたが彼らにあだをかえされるのを見させてください。</span></span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="エレミヤ書 20:10; アモス書 2:12; ルカによる福音書 13:33–34"> それゆえ主はアナトテの人々についてこう言われる、彼らはあなたの命を取ろうと求めて言う、「主の名によって預言してはならない。それをするならば、あなたはわれわれの手にかかって死ぬであろう」。</span>
<span className="v" id="v22" data-v="22" data-xref="エレミヤ書 18:21; 歴代志下 36:17; エレミヤ書 9:21"> それで万軍の主はこう言われる、「見よ、わたしは彼らを罰する。若い人はつるぎで死に、彼らのむすこ娘は、ききんで死に、</span>
<span className="v" id="v23" data-v="23" data-xref="エレミヤ書 23:12; ミカ書 7:4; ホセア書 9:7"> だれも残る者はない。わたしがアナトテの人々に災を下し、彼らを罰する年をこさせるからである」。</span>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀下 23:35; エレミヤ書 1:3; エレミヤ書 25:1"> ユダの王ヨシヤの子エホヤキムの時、主からエレミヤに臨んだ言葉。</span>
<span className="v" id="v2" data-v="2" data-xref="歴代志上 2:55; 歴代志上 9:26; 列王紀上 6:5–6"> 「レカブびとの家に行って、彼らと語り、彼らを主の宮の一室に連れてきて、酒を飲ませなさい」。</span>
<span className="v" id="v3" data-v="3"> そこでわたしはハバジニヤの子エレミヤの子であるヤザニヤと、その兄弟と、そのむすこたち、およびレカブびとの全家を連れ、</span>
<span className="v" id="v4" data-v="4" data-xref="申命記 33:1; 列王紀下 12:9; 歴代志下 8:14"> これを主の宮にあるハナンの子たちの室に連れてきた。ハナンはイグダリヤの子であって神の人であった。その室は、つかさたちの室の次にあって、門を守るシャルムの子マアセヤの室の上にあった。</span>
<span className="v" id="v5" data-v="5" data-xref="伝道の書 9:7; アモス書 2:12; コリント人への第二の手紙 2:9"> わたしはレカブびとの前に酒を満たしたつぼと杯を置き、彼らに、「酒を飲みなさい」と言ったが、</span>
<span className="v" id="v6" data-v="6" data-xref="ルカによる福音書 1:15; 歴代志上 2:55; 列王紀下 10:15"> 彼らは答えた、「われわれは酒を飲みません。それは、レカブの子であるわれわれの先祖ヨナダブがわれわれに命じて、『あなたがたとあなたがたの子孫はいつまでも酒を飲んではならない。</span>
<span className="v" id="v7" data-v="7" data-xref="エレミヤ書 35:10; 創世記 25:27; ネヘミヤ書 8:14–16"> また家を建てず、種をまかず、またぶどう畑を植えてはならない。またこれを所有してはならない。あなたがたは生きながらえる間は幕屋に住んでいなさい。そうするならば、あなたがたはその宿っている地に長く生きることができると言ったからです』。</span>
<span className="v" id="v8" data-v="8" data-xref="コロサイ人への手紙 3:20; 箴言 4:10; 箴言 1:8–9"> こうしてわれわれは、レカブの子であるわれわれの先祖ヨナダブがすべて命じた言葉に従って、われわれも、妻も、むすこ娘も生きながらえる間、酒を飲まず、</span>
<span className="v" id="v9" data-v="9" data-xref="テモテヘの第一の手紙 6:6; エレミヤ書 35:7; 詩篇 37:16"> 住む家を建てず、ぶどう畑も畑も種も持たないで、</span>
<span className="v" id="v10" data-v="10"> 幕屋に住み、すべてわれわれの先祖ヨナダブがわれわれに命じたところに従い、そのように行いました。</span>
<span className="v" id="v11" data-v="11" data-xref="エレミヤ書 8:14; エレミヤ書 4:5–7; ダニエル書 1:1–2"> しかしバビロンの王ネブカデレザルがこの地に上ってきた時、われわれは言いました、『さあ、われわれはエルサレムへ行こう。カルデヤびとの軍勢とスリヤびとの軍勢が恐ろしい』と。こうしてわれわれはエルサレムに住んでいるのです」。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12"> その時、主の言葉がエレミヤに臨んだ、</span>
<span className="v" id="v13" data-v="13" data-xref="エレミヤ書 32:33; エレミヤ書 5:3; エレミヤ書 6:8–10"> 「万軍の主、イスラエルの神はこう言われる、行って、ユダの人々とエルサレムに住む者とに告げよ。主は仰せられる、あなたがたはわたしの言葉を聞いて教を受けないのか。</span>
<span className="v" id="v14" data-v="14" data-xref="エレミヤ書 25:3–4; エレミヤ書 7:24–26; 箴言 1:20–33"> レカブの子ヨナダブがその子孫に酒を飲むなと命じた言葉は守られてきた。彼らは今日に至るまで酒を飲まず、その先祖の命に従ってきた。ところがあなたがたはわたしがしきりに語ったけれども、わたしに聞き従わなかった。</span>
<span className="v" id="v15" data-v="15" data-xref="エレミヤ書 18:11; エゼキエル書 18:30–32; エレミヤ書 25:5–6"> わたしはまた、わたしのしもべである預言者たちを、しきりにあなたがたにつかわして言わせた、『あなたがたは今おのおのその悪い道を離れ、その行いを改めなさい。ほかの神々に従い仕えてはならない。そうすれば、あなたがたはわたしがあなたがたと、あなたがたの先祖に与えたこの地に住むことができる』と。しかしあなたがたは耳を傾けず、わたしに聞かなかった。</span>
<span className="v" id="v16" data-v="16" data-xref="マラキ書 1:6; エレミヤ書 35:14; ルカによる福音書 15:11–13"> レカブの子ヨナダブの子孫は、その先祖が彼らに命じた命令を守っているのである。しかしこの民はわたしに従わなかった。</span>
<span className="v" id="v17" data-v="17" data-xref="イザヤ書 66:4; イザヤ書 65:12; ローマ人への手紙 10:21"> それゆえ万軍の神、主、イスラエルの神はこう仰せられる、見よ、わたしはユダとエルサレムに住む者とに、わたしが彼らの上に宣告した災を下す。わたしが彼らに語っても聞かず、彼らを呼んでも答えなかったからである」。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="申命記 5:16; 出エジプト記 20:12; エペソ人への手紙 6:1–3"> ところでエレミヤはレカブびとの家の人々に言った、「万軍の主、イスラエルの神はこう仰せられる、あなたがたは先祖ヨナダブの命に従い、そのすべての戒めを守り、彼があなたがたに命じた事を行った。</span>
<span className="v" id="v19" data-v="19" data-xref="エレミヤ書 15:19; ルカによる福音書 21:36; エレミヤ書 33:17–18"> それゆえ、万軍の主、イスラエルの神はこう言われる、レカブの子ヨナダブには、わたしの前に立つ人がいつまでも欠けることはない」。</span>
</div>

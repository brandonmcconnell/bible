<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="エレミヤ書 41:11; エレミヤ書 40:13; エレミヤ書 6:13"> そのとき軍勢の長たち、およびカレヤの子ヨハナンと、ホシャヤの子アザリヤ、ならびに民の最も小さい者から最も大いなる者にいたるまで、</span>
<span className="v" id="v2" data-v="2" data-xref="エレミヤ書 36:7; レビ記 26:22; 使徒行伝 8:24"> みな預言者エレミヤの所に来て言った、「どうかあなたの前にわれわれの求めが受けいれられますように。われわれのため、この残っている者すべてのために、あなたの神、主に祈ってください、（今ごらんのとおり、われわれは多くのうち、わずかに残っている者です）</span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 86:11; 箴言 3:6; 詩篇 25:4–5"> そうすれば、あなたの神、主は、われわれの行くべき道と、なすべき事をお示しになるでしょう」。</span>
<span className="v" id="v4" data-v="4" data-xref="サムエル記上 12:23; サムエル記上 3:17–18; 出エジプト記 8:29"> 預言者エレミヤは彼らに言った、「よくわかりました。あなたがたの求めにしたがって、あなたがたの神、主に祈りましょう。主があなたがたに答えられることを、何事も隠さないであなたがたに言いましょう」。</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 31:50; 士師記 11:10; マラキ書 3:5"> 彼らはエレミヤに言った、「もし、あなたの神、主があなたをつかわしてお告げになるすべての言葉を、われわれが行わないときは、どうか主がわれわれに対してまことの真実な証人となられるように。</span>
<span className="v" id="v6" data-v="6" data-xref="エレミヤ書 7:23; 申命記 5:29; ローマ人への手紙 8:7"> われわれは良くても悪くても、われわれがあなたをつかわそうとするわれわれの神、主の声に従います。われわれの神、主の声に従うとき、われわれは幸を得るでしょう」。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="詩篇 27:14; イザヤ書 28:16; ハバクク書 2:3"> 十日の後、主の言葉がエレミヤに臨んだ。</span>
<span className="v" id="v8" data-v="8" data-xref="エレミヤ書 42:1; エレミヤ書 41:11–16; エレミヤ書 43:2–5"> エレミヤはカレヤの子ヨハナンおよび彼と共にいる軍勢の長たち、ならびに民の最も小さい者から最も大いなる者までことごとく招いて、</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀下 19:4; エレミヤ書 42:2; 列王紀下 19:6"> 彼らに言った、「あなたがたがわたしをつかわして、あなたの祈願をその前にのべさせたイスラエルの神、主はこう言われます、</span>
<span className="v" id="v10" data-v="10" data-xref="エレミヤ書 31:28; エゼキエル書 36:36; エレミヤ書 24:6"> もしあなたがたがこの地にとどまるならば、わたしはあなたがたを建てて倒すことなく、あなたがたを植えて抜くことはしない。わたしはあなたがたに災を下したことを悔いているからである。</span>
<span className="v" id="v11" data-v="11" data-xref="ローマ人への手紙 8:31; エレミヤ書 1:19; エレミヤ書 1:8"> 主は言われる、あなたが恐れているバビロンの王を恐れてはならない。彼を恐れてはならない、わたしが共にいて、あなたがたを救い、彼の手から助け出すからである。</span>
<span className="v" id="v12" data-v="12" data-xref="ネヘミヤ書 1:11; 詩篇 106:45–46; 箴言 16:7"> わたしはあなたがたをあわれみ、また彼にあなたがたをあわれませ、あなたがたを自分の地にとどまらせる。</span>
<span className="v" id="v13" data-v="13" data-xref="エレミヤ書 44:16; 出エジプト記 5:2; エレミヤ書 42:10"> しかし、もしあなたがたが、『われわれはこの地にとどまらない』といって、あなたがたの神、主の声にしたがわず、</span>
<span className="v" id="v14" data-v="14" data-xref="エレミヤ書 41:17; エレミヤ書 4:19; イザヤ書 31:1"> また、『いいえ、われわれはあの戦争を見ず、ラッパの声を聞かず、食物も乏しくないエジプトの地へ行って、あそこに住まおう』と言うならば、</span>
<span className="v" id="v15" data-v="15" data-xref="申命記 17:16; エレミヤ書 44:12–14; エレミヤ書 42:17"> あなたがた、ユダの残っている者たちよ、主の言葉を聞きなさい。万軍の主、イスラエルの神はこう言われる、もしあなたがたがむりにエジプトへ行ってそこに住むならば、</span>
<span className="v" id="v16" data-v="16" data-xref="エレミヤ書 44:27; エゼキエル書 11:8; アモス書 9:1–4"> あなたがたの恐れているつるぎはエジプトの地であなたがたに追いつき、あなたがたの恐れているききんは、すぐあとを追ってエジプトまで行き、その所であなたがたは死ぬ。</span>
<span className="v" id="v17" data-v="17" data-xref="エレミヤ書 42:22; エレミヤ書 44:28; エレミヤ書 44:13–14"> すべてむりにエジプトへ行ってそこに住む者は、つるぎと、ききんと、疫病で死ぬ。わたしが彼らに下そうとしている災をのがれて残る者はそのうちにない。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="エレミヤ書 7:20; エレミヤ書 18:16; エレミヤ書 29:18"> 万軍の主、イスラエルの神はこう言われる、わたしの怒りと憤りとをエルサレムの住民の上に注いだように、わたしの憤りは、あなたがたがエジプトへ行くとき、あなたがたの上に注ぐ。あなたがたは、のろいとなり、恐怖となり、ののしりとなり、はずかしめとなる。あなたがたは再びこの所を見ることができない。</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 17:16; イザヤ書 30:1–7; ネヘミヤ書 9:26"> ユダの残っている者たちよ、『エジプトへ行ってはならない』と主はあなたがたに言われた。わたしがきょう警告したことを、あなたがたは確かに知らなければならない。</span>
<span className="v" id="v20" data-v="20" data-xref="エゼキエル書 14:3–4; エゼキエル書 33:31; マタイによる福音書 22:15–18"> あなたがたはみずからそむき去って、命を失った。なぜなら、あなたがたがわたしをあなたがたの神、主につかわし、『われわれの神、主に祈り、われわれの神、主の言われることをことごとく示してください。われわれはそれを行います』と言ったので、</span>
<span className="v" id="v21" data-v="21" data-xref="エゼキエル書 2:7; ゼカリヤ書 7:11–12; 使徒行伝 20:26–27"> わたしはきょうそれを示したが、あなたがたはあなたがたの神、主の声を聞かず、主がわたしをつかわして命じさせられた事には、すこしも従わなかったからである。</span>
<span className="v" id="v22" data-v="22" data-xref="エレミヤ書 42:17; エゼキエル書 6:11; ホセア書 9:6"> それゆえ、あなたがたが行って住まうことを願っているその所で、あなたがたはつるぎと、ききんと、疫病で死ぬことを確かに知らなければならない」。</span>
</div>

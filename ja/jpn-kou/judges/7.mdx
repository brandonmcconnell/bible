<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士師記 6:32; 伝道の書 9:10; 創世記 12:6"> さてエルバアルと呼ばれるギデオンおよび彼と共にいたすべての民は朝早く起き、ハロデの泉のほとりに陣を取った。ミデアンびとの陣は彼らの北の方にあり、モレの丘に沿って谷の中にあった。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="申命記 8:17; コリント人への第一の手紙 1:27–29; コリント人への第二の手紙 4:7"> 主はギデオンに言われた、「あなたと共におる民はあまりに多い。ゆえにわたしは彼らの手にミデアンびとをわたさない。おそらくイスラエルはわたしに向かってみずから誇り、『わたしは自身の手で自分を救ったのだ』と言うであろう。</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 20:8; ヨハネの黙示録 17:14; ヨハネの黙示録 21:8"> それゆえ、民の耳に触れ示して、『だれでも恐れおののく者は帰れ』と言いなさい」。こうしてギデオンは彼らを試みたので、民のうち帰った者は二万二千人あり、残った者は一万人であった。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="詩篇 33:16; サムエル記上 16:7; サムエル記上 14:6"> 主はまたギデオンに言われた、「民はまだ多い。彼らを導いて水ぎわに下りなさい。わたしはそこで、あなたのために彼らを試みよう。わたしがあなたに告げて『この人はあなたと共に行くべきだ』と言う者は、あなたと共に行くべきである。またわたしがあなたに告げて『この人はあなたと共に行ってはならない』と言う者は、だれも行ってはならない」。</span>
<span className="v" id="v5" data-v="5"> そこでギデオンが民を導いて水ぎわに下ると、主は彼に言われた、「すべて犬のなめるように舌をもって水をなめる者はそれを別にしておきなさい。またすべてひざを折り、かがんで水を飲む者もそうしなさい」。</span>
<span className="v" id="v6" data-v="6"> そして手を口にあてて水をなめた者の数は三百人であった。残りの民はみなひざを折り、かがんで水を飲んだ。</span>
<span className="v" id="v7" data-v="7" data-xref="サムエル記上 14:6; イザヤ書 41:14–16; 士師記 7:18–22"> 主はギデオンに言われた、「わたしは水をなめた三百人の者をもって、あなたがたを救い、ミデアンびとをあなたの手にわたそう。残りの民はおのおのその家に帰らせなさい」。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨシュア記 6:20; 民数記 10:9; ヨシュア記 6:4"> そこで彼はかの三百人を留めおき、残りのイスラエルびとの手から、つぼとラッパを取り、民をおのおのその天幕に帰らせた。時にミデアンびとの陣は下の谷の中にあった。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="創世記 46:2–3; 士師記 3:28; 使徒行伝 18:9–10"> その夜、主はギデオンに言われた、「立てよ、下っていって敵陣に攻め入れ。わたしはそれをあなたの手にわたす。</span>
<span className="v" id="v10" data-v="10" data-xref="出エジプト記 4:10–14; 士師記 4:8–9"> もしあなたが下って行くことを恐れるならば、あなたのしもべプラと共に敵陣に下っていって、</span>
<span className="v" id="v11" data-v="11" data-xref="エペソ人への手紙 6:10; 士師記 7:13–15; イザヤ書 35:3–4"> 彼らの言うところを聞け。そうすればあなたの手が強くなって、敵陣に攻め下ることができるであろう」。ギデオンがしもべプラと共に下って、敵陣にある兵隊たちの前哨地点に行ってみると、</span>
<span className="v" id="v12" data-v="12" data-xref="士師記 8:10; 士師記 6:5; ヨシュア記 11:4"> ミデアンびと、アマレクびとおよびすべての東方の民はいなごのように数多く谷に沿って伏していた。そのらくだは海べの砂のように多くて数えきれなかった。</span>
<span className="v" id="v13" data-v="13" data-xref="コリント人への第一の手紙 1:27; イザヤ書 41:14–15; 士師記 4:9"> ギデオンがそこへ行ったとき、ある人がその仲間に夢を語っていた。その人は言った、「わたしは夢を見た。大麦のパン一つがミデアンの陣中にころがってきて、天幕に達し、それを打ち倒し、くつがえしたので、天幕は倒れ伏した」。</span>
<span className="v" id="v14" data-v="14" data-xref="列王紀下 7:6–7; ヨシュア記 2:9; ヨシュア記 2:24"> 仲間は答えて言った、「それはイスラエルの人、ヨアシの子ギデオンのつるぎにちがいない。神はミデアンとすべての軍勢を彼の手にわたされるのだ」。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="コリント人への第二の手紙 10:4–6; 創世記 40:8; 歴代志下 20:18–19"> ギデオンは夢の物語とその解き明かしとを聞いたので、礼拝し、イスラエルの陣営に帰り、そして言った、「立てよ、主はミデアンの軍勢をあなたがたの手にわたされる」。</span>
<span className="v" id="v16" data-v="16" data-xref="コリント人への第二の手紙 4:7"> そして彼は三百人を三組に分け、手に手にラッパと、からつぼとを取らせ、つぼの中にたいまつをともさせ、</span>
<span className="v" id="v17" data-v="17" data-xref="コリント人への第一の手紙 11:1; マタイによる福音書 16:24; ヘブル人への手紙 13:7"> 彼らに言った、「わたしを見て、わたしのするようにしなさい。わたしが敵陣のはずれに達したとき、あなたがたもわたしのするようにしなさい。</span>
<span className="v" id="v18" data-v="18" data-xref="歴代志下 20:15–17; サムエル記上 17:47"> わたしと共におる者がみなラッパを吹くと、あなたがたもまたすべての陣営の四方でラッパを吹き、『主のためだ、ギデオンのためだ』と言いなさい」。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="詩篇 2:9; 出エジプト記 14:24; マタイによる福音書 25:6"> こうしてギデオンと、彼と共にいた百人の者が、中更の初めに敵陣のはずれに行ってみると、ちょうど番兵を交代した時であったので、彼らはラッパを吹き、手に携えていたつぼを打ち砕いた。</span>
<span className="v" id="v20" data-v="20" data-xref="イザヤ書 27:13; コリント人への第二の手紙 4:7; コリント人への第一の手紙 15:52"> すなわち三組の者がラッパを吹き、つぼを打ち砕き、左の手にはたいまつをとり、右の手にはラッパを持ってそれを吹き、「主のためのつるぎ、ギデオンのためのつるぎ」と叫んだ。</span>
<span className="v" id="v21" data-v="21" data-xref="歴代志下 20:17; 箴言 28:1; 列王紀下 7:6–7"> そしておのおのその持ち場に立ち、敵陣を取り囲んだので、敵軍はみな走り、大声をあげて逃げ去った。</span>
<span className="v" id="v22" data-v="22" data-xref="列王紀上 4:12; ヨシュア記 6:20; ヨシュア記 6:4"> 三百人のものがラッパを吹くと、主は敵軍をしてみな互に同志打ちさせられたので、敵軍はゼレラの方、ベテシッタおよびアベルメホラの境、タバテの近くまで逃げ去った。</span>
<span className="v" id="v23" data-v="23" data-xref="士師記 6:35; サムエル記上 14:21–22"> イスラエルの人々はナフタリ、アセルおよび全マナセから集まってきて、ミデアンびとを追撃した。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="士師記 3:27–28; ピリピ人への手紙 1:27; ローマ人への手紙 15:30"> ギデオンは使者をあまねくエフライムの山地につかわし、「下ってきて、ミデアンびとを攻め、ベタバラに至るまでの流れを取り、またヨルダンをも取れ」と言わせた。そこでエフライムの人々はみな集まってきて、ベタバラに至るまでの流れを取り、またヨルダンをも取った。</span>
<span className="v" id="v25" data-v="25" data-xref="イザヤ書 10:26; 士師記 8:3–4; 詩篇 83:11–12"> 彼らはまたミデアンびとのふたりの君オレブとゼエブを捕え、オレブをオレブ岩のほとりで殺し、ゼエブをゼエブの酒ぶねのほとりで殺した。またミデアンびとを追撃し、オレブとゼエブの首を携えてヨルダンの向こうのギデオンのもとへ行った。</span>
</div>
</div>

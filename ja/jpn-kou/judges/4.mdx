<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="エレミヤ書 5:3; 士師記 3:12; 士師記 3:7"> エホデが死んだ後、イスラエルの人々がまた主の前に悪をおこなったので、</span>
<span className="v" id="v2" data-v="2" data-xref="ヨシュア記 11:1; 士師記 4:16; 士師記 4:13"> 主は、ハゾルで世を治めていたカナンの王ヤビンの手に彼らを売りわたされた。ヤビンの軍勢の長はハロセテ・ゴイムに住んでいたシセラであった。</span>
<span className="v" id="v3" data-v="3" data-xref="士師記 1:19; 詩篇 106:42; 士師記 3:9"> 彼は鉄の戦車九百両をもち、二十年の間イスラエルの人々を激しくしえたげたので、イスラエルの人々は主に向かって呼ばわった。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="出エジプト記 15:20; ルカによる福音書 2:36; 列王紀下 22:14"> そのころラピドテの妻、女預言者デボラがイスラエルをさばいていた。</span>
<span className="v" id="v5" data-v="5" data-xref="出エジプト記 18:19; エレミヤ書 31:15; 出エジプト記 18:26"> 彼女はエフライムの山地のラマとベテルの間にあるデボラのしゅろの木の下に座し、イスラエルの人々は彼女のもとに上ってきて、さばきをうけた。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行伝 13:47; 士師記 8:18; ヘブル人への手紙 11:32"> デボラは人をつかわして、ナフタリのケデシからアビノアムの子バラクを招いて言った、「イスラエルの神、主はあなたに、こう命じられるではありませんか、『ナフタリの部族とゼブルンの部族から一万人を率い、行って、タボル山に陣をしけ。</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀上 18:40; エゼキエル書 38:10–16; 詩篇 83:9–10"> わたしはヤビンの軍勢の長シセラとその戦車と軍隊とをキション川に引き寄せて、あなたに出あわせ、彼をあなたの手にわたすであろう』」。</span>
<span className="v" id="v8" data-v="8" data-xref="出エジプト記 4:10–14; マタイによる福音書 14:30–31"> バラクは彼女に言った、「あなたがもし一緒に行ってくだされば、わたしは行きます。しかし、一緒に行ってくださらないならば、行きません」。</span>
<span className="v" id="v9" data-v="9" data-xref="士師記 2:14; サムエル記上 2:30; 士師記 4:17–22"> デボラは言った、「必ずあなたと一緒に行きます。しかしあなたは今行く道では誉を得ないでしょう。主はシセラを女の手にわたされるからです」。デボラは立ってバラクと一緒にケデシに行った。</span>
<span className="v" id="v10" data-v="10" data-xref="士師記 5:18; 士師記 5:15; 士師記 4:14"> バラクはゼブルンとナフタリをケデシに呼び集め、一万人を従えて上った。デボラも彼と共に上った。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="士師記 1:16; ヨシュア記 19:33; 民数記 10:29"> 時にケニびとヘベルはモーセのしゅうとホバブの子孫であるケニびとから分れて、ケデシに近いザアナイムのかしの木までも遠く行って天幕を張っていた。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="詩篇 89:12; エレミヤ書 46:18; ヨシュア記 19:12"> アビノアムの子バラクがタボル山に上ったと、人々がシセラに告げたので、</span>
<span className="v" id="v13" data-v="13" data-xref="士師記 4:2–3; 士師記 4:7"> シセラは自分の戦車の全部すなわち鉄の戦車九百両と、自分と共におるすべての民をハロセテ・ゴイムからキション川に呼び集めた。</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 9:3; サムエル記下 5:24; イザヤ書 52:12"> デボラはバラクに言った、「さあ、立ちあがりなさい。きょうは主がシセラをあなたの手にわたされる日です。主はあなたに先立って出られるではありませんか」。そこでバラクは一万人を従えてタボル山から下った。</span>
<span className="v" id="v15" data-v="15" data-xref="ヨシュア記 10:10; 詩篇 83:9–10; 士師記 5:20–21"> 主はつるぎをもってシセラとすべての戦車および軍勢をことごとくバラクの前に撃ち敗られたので、シセラは戦車から飛びおり、徒歩で逃げ去った。</span>
<span className="v" id="v16" data-v="16" data-xref="ローマ人への手紙 2:12; レビ記 26:7–8; ヤコブの手紙 2:13"> バラクは戦車と軍勢とを追撃してハロセテ・ゴイムまで行った。シセラの軍勢はことごとくつるぎにたおれて、残ったものはひとりもなかった。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="詩篇 69:22; イザヤ書 57:21; アモス書 5:19–20"> しかしシセラは徒歩で逃げ去って、ケニびとヘベルの妻ヤエルの天幕に行った。ハゾルの王ヤビンとケニびとヘベルの家とは互にむつまじかったからである。</span>
<span className="v" id="v18" data-v="18" data-xref="列王紀下 6:19"> ヤエルは出てきてシセラを迎え、彼に言った、「おはいりください。主よ、どうぞうちへおはいりください。恐れるにはおよびません」。シセラが天幕にはいったので、ヤエルは毛布をもって彼をおおった。</span>
<span className="v" id="v19" data-v="19" data-xref="士師記 5:25–26; 創世記 24:43; イザヤ書 41:17"> シセラはヤエルに言った、「どうぞ、わたしに水を少し飲ませてください。のどがかわきましたから」。ヤエルは乳の皮袋を開いて彼に飲ませ、また彼をおおった。</span>
<span className="v" id="v20" data-v="20" data-xref="ヨシュア記 2:3–5; サムエル記下 17:20"> シセラはまたヤエルに言った、「天幕の入口に立っていてください。もし人がきて、あなたに『だれか、ここにおりますか』と問うならば『おりません』と答えてください」。</span>
<span className="v" id="v21" data-v="21" data-xref="士師記 5:26–27; コリント人への第一の手紙 1:27; 士師記 3:21"> しかし彼が疲れて熟睡したとき、ヘベルの妻ヤエルは天幕のくぎを取り、手に槌を携えて彼に忍び寄り、こめかみにくぎを打ち込んで地に刺し通したので、彼は息絶えて死んだ。</span>
<span className="v" id="v22" data-v="22" data-xref="サムエル記下 17:10–15; サムエル記下 17:3"> バラクがシセラを追ってきたとき、ヤエルは彼を出迎えて言った、「おいでなさい。あなたが求めている人をお見せしましょう」。彼がヤエルの天幕にはいって見ると、シセラはこめかみにくぎを打たれて倒れて死んでいた。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="ネヘミヤ書 9:24; 詩篇 18:47; 詩篇 18:39"> こうしてその日、神はカナンの王ヤビンをイスラエルの人々の前に撃ち敗られた。</span>
<span className="v" id="v24" data-v="24" data-xref="サムエル記上 3:12"> そしてイスラエルの人々の手はますますカナンびとの王ヤビンの上に重くなって、ついにカナンの王ヤビンを滅ぼすに至った。</span>
</div>
</div>

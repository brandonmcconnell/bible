<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士師記 20:18; 民数記 27:21; 士師記 20:28"> ヨシュアが死んだ後、イスラエルの人々は主に問うて言った、「わたしたちのうち、だれが先に攻め上って、カナンびとと戦いましょうか」。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネの黙示録 5:5; ヘブル人への手紙 7:14; 民数記 2:3"> 主は言われた、「ユダが上るべきである。わたしはこの国を彼の手にわたした」。</span>
<span className="v" id="v3" data-v="3" data-xref="サムエル記下 10:11; ヨシュア記 19:1; 士師記 1:17"> ユダはその兄弟シメオンに言った、「わたしと一緒に、わたしに割り当てられた領地へ上って行って、カナンびとと戦ってください。そうすればわたしもあなたと一緒に、あなたに割り当てられた領地へ行きましょう」。そこでシメオンは彼と一緒に行った。</span>
<span className="v" id="v4" data-v="4" data-xref="サムエル記上 11:8; 出エジプト記 23:28–29; ヨシュア記 11:6–8"> ユダが上って行くと、主は彼らの手にカナンびととペリジびととをわたされたので、彼らはベゼクで一万人を撃ち破り、</span>
<span className="v" id="v5" data-v="5"> またベゼクでアドニベゼクに会い、彼と戦ってカナンびととペリジびととを撃ち破った。</span>
<span className="v" id="v6" data-v="6"> アドニベゼクは逃げたが、彼らはそのあとを追って彼を捕え、その手足の親指を切り放った。</span>
<span className="v" id="v7" data-v="7" data-xref="サムエル記上 15:33; ヨハネの黙示録 13:10; ルカによる福音書 6:37–38"> アドニベゼクは言った、「かつて七十人の王たちが手足の親指を切られて、わたしの食卓の下で、くずを拾ったことがあったが、神はわたしがしたように、わたしに報いられたのだ」。人々は彼をエルサレムへ連れて行ったが、彼はそこで死んだ。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="ヨシュア記 15:63; 士師記 1:21"> ユダの人々はエルサレムを攻めて、これを取り、つるぎをもってこれを撃ち、町に火を放った。</span>
<span className="v" id="v9" data-v="9" data-xref="ヨシュア記 15:13–20; ヨシュア記 11:21; ヨシュア記 10:36"> その後、ユダの人々は山地とネゲブと平地に住んでいるカナンびとと戦うために下ったが、</span>
<span className="v" id="v10" data-v="10" data-xref="民数記 13:22; ヨシュア記 14:15; エレミヤ書 9:23"> ユダはまずヘブロンに住んでいるカナンびとを攻めて、セシャイとアヒマンとタルマイを撃ち破った。ヘブロンのもとの名はキリアテ・アルバであった。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="ヨシュア記 15:15; ヨシュア記 10:38–39"> またそこから進んでデビルの住民を攻めた。（デビルのもとの名はキリアテ・セペルであった。）</span>
<span className="v" id="v12" data-v="12" data-xref="ヨシュア記 15:16–17; サムエル記上 17:25; サムエル記上 18:23"> 時にカレブは言った、「キリアテ・セペルを撃って、これを取る者には、わたしの娘アクサを妻として与えるであろう」。</span>
<span className="v" id="v13" data-v="13" data-xref="士師記 3:9"> カレブの弟ケナズの子オテニエルがそれを取ったので、カレブは娘アクサを妻として彼に与えた。</span>
<span className="v" id="v14" data-v="14" data-xref="ヨシュア記 15:18–19"> アクサは行くとき彼女の父に畑を求めることを夫にすすめられたので、アクサがろばから降りると、カレブは彼女に言った、「あなたは何を望むのか」。</span>
<span className="v" id="v15" data-v="15" data-xref="サムエル記上 25:18; コリント人への第二の手紙 9:5; ペテロの第一の手紙 3:9"> アクサは彼に言った、「わたしに贈り物をください。あなたはわたしをネゲブの地へやられるのですから、泉をもください」。それでカレブは上の泉と下の泉とを彼女に与えた。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="民数記 10:29–32; 士師記 4:11; サムエル記上 15:6"> モーセのしゅうとであるケニびとの子孫はユダの人々と共に、しゅろの町からアラドに近いネゲブにあるユダの野に上ってきて、アマレクびとと共に住んだ。</span>
<span className="v" id="v17" data-v="17" data-xref="民数記 21:3; 士師記 1:3; ヨシュア記 19:4"> そしてユダはその兄弟シメオンと共に行って、ゼパテに住んでいたカナンびとを撃ち、それをことごとく滅ぼした。これによってその町の名はホルマと呼ばれた。</span>
<span className="v" id="v18" data-v="18" data-xref="ヨシュア記 11:22; 士師記 3:3; ヨシュア記 15:45–47"> ユダはまたガザとその地域、アシケロンとその地域、エクロンとその地域を取った。</span>
<span className="v" id="v19" data-v="19" data-xref="イザヤ書 41:10; 士師記 1:2; 詩篇 60:12"> 主がユダと共におられたので、ユダはついに山地を手に入れたが、平地に住んでいた民は鉄の戦車をもっていたので、これを追い出すことができなかった。</span>
<span className="v" id="v20" data-v="20" data-xref="士師記 1:10; ヨシュア記 15:13–14; 民数記 14:24"> 人々はモーセがかつて言ったように、ヘブロンをカレブに与えたので、カレブはその所からアナクの三人の子を追い出した。</span>
<span className="v" id="v21" data-v="21" data-xref="ヨシュア記 15:63; 士師記 19:10–12; 士師記 1:8"> ベニヤミンの人々はエルサレムに住んでいたエブスびとを追い出さなかったので、エブスびとは今日までベニヤミンの人々と共にエルサレムに住んでいる。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="士師記 1:19; 列王紀下 18:7; 民数記 1:32"> ヨセフの一族はまたベテルに攻め上ったが、主は彼らと共におられた。</span>
<span className="v" id="v23" data-v="23" data-xref="創世記 28:19; 創世記 35:6; 創世記 48:3"> すなわちヨセフの一族は人をやってベテルを探らせた。この町のもとの名はルズであった。</span>
<span className="v" id="v24" data-v="24" data-xref="ヨシュア記 2:12–14; サムエル記上 30:15"> その斥候たちは町から出てきた人を見て、言った、「どうぞこの町にはいる道を教えてください。そうすればわたしたちはあなたに恵みを施しましょう」。</span>
<span className="v" id="v25" data-v="25" data-xref="ヨシュア記 6:22–25"> 彼が町にはいる道を教えたので、彼らはつるぎをもって町を撃った。しかし、かの人とその家族は自由に去らせた。</span>
<span className="v" id="v26" data-v="26" data-xref="列王紀下 7:6; 歴代志下 1:17"> その人はヘテびとの地に行って町を建て、それをルズと名づけた。これは今日までその名である。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="ヨシュア記 17:11–13; エレミヤ書 48:10; 詩篇 106:34–35"> マナセはベテシャンとその村里の住民、タアナクとその村里の住民、ドルとその村里の住民、イブレアムとその村里の住民、メギドとその村里の住民を追い出さなかったので、カナンびとは引き続いてその地に住んでいたが、</span>
<span className="v" id="v28" data-v="28"> イスラエルは強くなったとき、カナンびとを強制労働に服させ、彼らをことごとくは追い出さなかった。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="ヨシュア記 16:10; 列王紀上 9:16"> またエフライムはゲゼルに住んでいたカナンびとを追い出さなかったので、カナンびとはゲゼルにおいて彼らのうちに住んでいた。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="ヨシュア記 19:15"> ゼブルンはキテロンの住民およびナハラルの住民を追い出さなかったので、カナンびとは彼らのうちに住んで強制労働に服した。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="ヨシュア記 19:24–30"> アセルはアッコの住民およびシドン、アヘラブ、アクジブ、ヘルバ、アピク、レホブの住民を追い出さなかったので、</span>
<span className="v" id="v32" data-v="32" data-xref="詩篇 106:34–35"> アセルびとは、その地の住民であるカナンびとのうちに住んでいた。彼らが追い出さなかったからである。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="ヨシュア記 19:32–38; 士師記 1:30; 詩篇 18:24"> ナフタリはベテシメシの住民およびベテアナテの住民を追い出さずに、その地の住民であるカナンびとのうちに住んでいた。しかしベテシメシとベテアナテの住民は、ついに彼らの強制労働に服した。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="ヨシュア記 19:47; 士師記 18:1"> アモリびとはダンの人々を山地に追い込んで平地に下ることを許さなかった。</span>
<span className="v" id="v35" data-v="35" data-xref="ヨシュア記 19:42; 士師記 12:12; ヨシュア記 10:12"> アモリびとは引き続いてハルヘレス、アヤロン、シャラビムに住んでいたが、ヨセフの一族の手が強くなったので、彼らは強制労働に服した。</span>
<span className="v" id="v36" data-v="36" data-xref="民数記 34:4; ヨシュア記 15:2–3"> アモリびとの境はアクラビムの坂からセラを経て上の方に及んだ。</span>
</div>
</div>

</div>

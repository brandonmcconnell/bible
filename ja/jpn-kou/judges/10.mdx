<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士師記 2:16; 士師記 3:9; ヨシュア記 15:48"> アビメレクの後、イッサカルの人で、ドドの子であるプワの子トラが起ってイスラエルを救った。彼はエフライムの山地のシャミルに住み、</span>
<span className="v" id="v2" data-v="2"> 二十三年の間イスラエルをさばいたが、ついに死んでシャミルに葬られた。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="民数記 32:29; 創世記 31:48"> 彼の後にギレアデびとヤイルが起って二十二年の間イスラエルをさばいた。</span>
<span className="v" id="v4" data-v="4" data-xref="民数記 32:41; 士師記 5:10; 申命記 3:14"> 彼に三十人の子があった。彼らは三十頭のろばに乗り、また三十の町をもっていた。ギレアデの地で今日まで、ハボテ・ヤイルと呼ばれているものがそれである。</span>
<span className="v" id="v5" data-v="5"> ヤイルは死んで、カモンに葬られた。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="列王紀上 11:33; 列王紀上 11:7; 列王紀下 23:13"> イスラエルの人々は再び主の前に悪を行い、バアルとアシタロテおよびスリヤの神々、シドンの神々、モアブの神々、アンモンびとの神々、ペリシテびとの神々に仕え、主を捨ててこれに仕えなかった。</span>
<span className="v" id="v7" data-v="7" data-xref="士師記 2:14; 申命記 32:16–22; サムエル記上 12:9–10"> 主はイスラエルに対して怒りを発し、彼らをペリシテびとの手およびアンモンびとの手に売りわたされたので、</span>
<span className="v" id="v8" data-v="8" data-xref="テサロニケ人への第一の手紙 5:3; イザヤ書 30:13; 士師記 10:5"> 彼らはその年イスラエルの人々をしえたげ悩ました。すなわち彼らはヨルダンの向こうのギレアデにあるアモリびとの地にいたすべてのイスラエルびとを十八年のあいだ悩ました。</span>
<span className="v" id="v9" data-v="9" data-xref="歴代志下 20:1–2; 申命記 28:65; 歴代志下 15:5"> またアンモンの人々がユダとベニヤミンとエフライムの氏族を攻めるためにヨルダンを渡ってきたので、イスラエルは非常に悩まされた。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="サムエル記上 12:10; 詩篇 107:28; 詩篇 107:13"> そこでイスラエルの人々は主に呼ばわって言った、「わたしたちはわたしたちの神を捨ててバアルに仕え、あなたに罪を犯しました」。</span>
<span className="v" id="v11" data-v="11" data-xref="士師記 3:31; 民数記 21:21–25; 出エジプト記 14:30"> 主はイスラエルの人々に言われた、「わたしはかつてエジプトびと、アモリびと、アンモンびと、ペリシテびとからあなたがたを救い出したではないか。</span>
<span className="v" id="v12" data-v="12" data-xref="士師記 6:3; 歴代志下 26:6–7; 詩篇 106:42–43"> またシドンびと、アマレクびとおよびマオンびとがあなたがたをしえたげた時、わたしに呼ばわったので、あなたがたを彼らの手から救い出した。</span>
<span className="v" id="v13" data-v="13" data-xref="エレミヤ書 2:13; 歴代志上 28:9; 士師記 2:12"> しかしあなたがたはわたしを捨てて、ほかの神々に仕えた。それゆえ、わたしはかさねてあなたがたを救わないであろう。</span>
<span className="v" id="v14" data-v="14" data-xref="エレミヤ書 2:28; 申命記 32:37–38; 列王紀上 18:27–28"> あなたがたが選んだ神々に行って呼ばわり、あなたがたの悩みの時、彼らにあなたがたを救わせるがよい」。</span>
<span className="v" id="v15" data-v="15" data-xref="サムエル記上 3:18; サムエル記下 15:26; 箴言 28:13"> イスラエルの人々は主に言った、「わたしたちは罪を犯しました。なんでもあなたが良いと思われることをしてください。ただどうぞ、きょう、わたしたちを救ってください」。</span>
<span className="v" id="v16" data-v="16" data-xref="イザヤ書 63:9; 詩篇 106:44–45; エゼキエル書 18:30–32"> そうして彼らは自分たちのうちから異なる神々を取り除いて、主に仕えた。それで主の心はイスラエルの悩みを見るに忍びなくなった。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="士師記 11:29; 創世記 31:49; 士師記 11:11"> 時にアンモンの人々は召集されてギレアデに陣を取ったが、イスラエルの人々は集まってミヅパに陣を取った。</span>
<span className="v" id="v18" data-v="18" data-xref="士師記 11:11; 士師記 12:7; 士師記 1:1"> その時、民とギレアデの君たちとは互に言った、「だれがアンモンの人々に向かって戦いを始めるか。その人はギレアデのすべての民のかしらとなるであろう」。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="サムエル記上 12:9; 士師記 6:1; ローマ人への手紙 2:6"> イスラエルの人々がまた主の前に悪を行ったので、主は彼らを四十年の間ペリシテびとの手にわたされた。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="ヨシュア記 19:41; ルカによる福音書 1:7; ヨシュア記 15:33"> ここにダンびとの氏族の者で、名をマノアというゾラの人があった。その妻はうまずめで、子を産んだことがなかった。</span>
<span className="v" id="v3" data-v="3" data-xref="ルカによる福音書 1:13; ルカによる福音書 1:11; 士師記 6:11–12"> 主の使がその女に現れて言った、「あなたはうまずめで、子を産んだことがありません。しかし、あなたは身ごもって男の子を産むでしょう。</span>
<span className="v" id="v4" data-v="4" data-xref="ルカによる福音書 1:15; 士師記 13:14; 民数記 6:2–3"> それであなたは気をつけて、ぶどう酒または濃い酒を飲んではなりません。またすべて汚れたものを食べてはなりません。</span>
<span className="v" id="v5" data-v="5" data-xref="民数記 6:5; サムエル記上 1:11; 歴代志上 18:1"> あなたは身ごもって男の子を産むでしょう。その頭にかみそりをあててはなりません。その子は生れた時から神にささげられたナジルびとです。彼はペリシテびとの手からイスラエルを救い始めるでしょう」。</span>
<span className="v" id="v6" data-v="6" data-xref="士師記 13:17–18; サムエル記上 9:6; マタイによる福音書 28:3–4"> そこでその女はきて夫に言った、「神の人がわたしのところにきました。その顔かたちは神の使の顔かたちのようで、たいそう恐ろしゅうございました。わたしはその人が、どこからきたのか尋ねませんでしたが、その人もわたしに名を告げませんでした。</span>
<span className="v" id="v7" data-v="7" data-xref="士師記 13:4"> しかしその人はわたしに『あなたは身ごもって男の子を産むでしょう。それであなたはぶどう酒または濃い酒を飲んではなりません。またすべて汚れたものを食べてはなりません。その子は生れた時から死ぬ日まで神にささげられたナジルびとです』と申しました」。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="使徒行伝 9:6; ヨブ記 34:32; 箴言 3:5–6"> そこでマノアは主に願い求めて言った、「ああ、主よ、どうぞ、あなたがさきにつかわされた神の人をもう一度わたしたちに臨ませて、わたしたちがその生れる子になすべきことを教えさせてください」。</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 65:2; マタイによる福音書 7:7–11"> 神がマノアの願いを聞かれたので、神の使は女が畑に座していた時、ふたたび彼女に臨んだ。しかし夫マノアは一緒にいなかった。</span>
<span className="v" id="v10" data-v="10" data-xref="ヨハネによる福音書 4:28–29; ヨハネによる福音書 1:41–42"> 女は急ぎ走って行って夫に言った、「さきごろ、わたしに臨まれた人がまたわたしに現れました」。</span>
<span className="v" id="v11" data-v="11"> マノアは立って妻のあとについて行き、その人のもとに行って言った、「あなたはかつてこの女にお告げになったおかたですか」。その人は言った、「そうです」。</span>
<span className="v" id="v12" data-v="12" data-xref="箴言 22:6; エペソ人への手紙 6:4; 創世記 18:19"> マノアは言った、「あなたの言われたことが事実となったとき、その子の育て方およびこれになすべき事はなんでしょうか」。</span>
<span className="v" id="v13" data-v="13"> 主の使はマノアに言った、「わたしがさきに女に言ったことは皆、守らせなければなりません。</span>
<span className="v" id="v14" data-v="14" data-xref="ヨハネによる福音書 2:5; 士師記 13:4; テサロニケ人への第二の手紙 3:4"> すなわちぶどうの木から産するものはすべて食べてはなりません。またぶどう酒と濃い酒を飲んではなりません。またすべて汚れたものを食べてはなりません。わたしが彼女に命じたことは皆、守らせなければなりません」。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="士師記 6:18–19; 創世記 18:3–5; 士師記 13:3"> マノアは主の使に言った、「どうぞ、わたしたちに、あなたを引き留めさせ、あなたのために子やぎを備えさせてください」。</span>
<span className="v" id="v16" data-v="16" data-xref="士師記 13:23; 士師記 6:20; 士師記 6:26"> 主の使はマノアに言った、「あなたがわたしを引き留めても、わたしはあなたの食物をたべません。しかしあなたが燔祭を備えようとなさるのであれば、主にそれをささげなさい」。マノアは彼が主の使であるのを知らなかったからである。</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 32:29"> マノアは主の使に言った、「あなたの名はなんといいますか。あなたの言われたことが事実となったとき、わたしたちはあなたをあがめましょう」。</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 32:29; イザヤ書 9:6; 士師記 13:6"> 主の使は彼に言った、「わたしの名は不思議です。どうしてあなたはそれをたずねるのですか」。</span>
<span className="v" id="v19" data-v="19" data-xref="士師記 6:19–21; 列王紀上 18:30–38"> そこでマノアは子やぎと素祭とをとり、岩の上でそれを主にささげた。主は不思議なことをされ、マノアとその妻はそれを見た。</span>
<span className="v" id="v20" data-v="20" data-xref="レビ記 9:24; 歴代志上 21:16; 列王紀下 2:11"> すなわち炎が祭壇から天にあがったとき、主の使は祭壇の炎のうちにあってのぼった。マノアとその妻は見て、地にひれ伏した。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="士師記 6:22; ホセア書 12:4–5; 士師記 13:16"> 主の使はふたたびマノアとその妻に現れなかった。その時マノアは彼が主の使であることを知った。</span>
<span className="v" id="v22" data-v="22" data-xref="創世記 32:30; 申命記 5:26; ヨハネによる福音書 1:18"> マノアは妻に向かって言った、「わたしたちは神を見たから、きっと死ぬであろう」。</span>
<span className="v" id="v23" data-v="23" data-xref="詩篇 25:14; コリント人への第一の手紙 12:21; ヨハネによる福音書 15:15"> 妻は彼に言った、「主がもし、わたしたちを殺そうと思われたのならば、わたしたちの手から燔祭と素祭をおうけにならなかったでしょう。またこれらのすべての事をわたしたちにお示しになるはずはなく、また今わたしたちにこのような事をお告げにならなかったでしょう」。</span>
<span className="v" id="v24" data-v="24" data-xref="ルカによる福音書 1:80; サムエル記上 3:19; ヘブル人への手紙 11:32"> やがて女は男の子を産んで、その名をサムソンと呼んだ。その子は成長し、主は彼を恵まれた。</span>
<span className="v" id="v25" data-v="25" data-xref="士師記 3:10; ヨシュア記 15:33; ヨハネによる福音書 3:34"> 主の霊はゾラとエシタオルの間のマハネダンにおいて初めて彼を感動させた。</span>
</div>
</div>

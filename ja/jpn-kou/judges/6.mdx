<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ネヘミヤ書 9:26–29; 士師記 2:19–20; 士師記 2:13–14"> イスラエルの人々はまた主の前に悪をおこなったので、主は彼らを七年の間ミデアンびとの手にわたされた。</span>
<span className="v" id="v2" data-v="2" data-xref="ヘブル人への手紙 11:38; サムエル記上 13:6; 申命記 28:47–48"> ミデアンびとの手はイスラエルに勝った。イスラエルの人々はミデアンびとのゆえに、山にある岩屋と、ほら穴と要害とを自分たちのために造った。</span>
<span className="v" id="v3" data-v="3" data-xref="士師記 6:33; 士師記 3:13; 士師記 7:12"> イスラエルびとが種をまいた時には、いつもミデアンびと、アマレクびとおよび東方の民が上ってきてイスラエルびとを襲い、</span>
<span className="v" id="v4" data-v="4" data-xref="レビ記 26:16; 申命記 28:51; ミカ書 6:15"> イスラエルびとに向かって陣を取り、地の産物を荒してガザの附近にまで及び、イスラエルのうちに命をつなぐべき物を残さず、羊も牛もろばも残さなかった。</span>
<span className="v" id="v5" data-v="5" data-xref="士師記 7:12; 士師記 8:10; エレミヤ書 46:23"> 彼らが家畜と天幕を携えて、いなごのように多く上ってきたからである。すなわち彼らとそのらくだは無数であって、彼らは国を荒すためにはいってきたのであった。</span>
<span className="v" id="v6" data-v="6" data-xref="士師記 3:9; エレミヤ書 5:17; 詩篇 50:15"> こうしてイスラエルはミデアンびとのために非常に衰え、イスラエルの人々は主に呼ばわった。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7"> イスラエルの人々がミデアンびとのゆえに、主に呼ばわったとき、</span>
<span className="v" id="v8" data-v="8" data-xref="エゼキエル書 20:5–32; イザヤ書 63:9–14; 詩篇 136:10–16"> 主はひとりの預言者をイスラエルの人々につかわして彼らに言われた、「イスラエルの神、主はこう言われる、『わたしはかつてあなたがたをエジプトから導き上り、あなたがたを奴隷の家から携え出し、</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 44:2–3"> エジプトびとの手およびすべてあなたがたをしえたげる者の手から救い出し、あなたがたの前から彼らを追い払って、その国をあなたがたに与えた。</span>
<span className="v" id="v10" data-v="10" data-xref="エレミヤ書 10:2; 列王紀下 17:35–39; エレミヤ書 9:13"> そしてあなたがたに言った、「わたしはあなたがたの神、主である。あなたがたが住んでいる国のアモリびとの神々を恐れてはならない」と。しかし、あなたがたはわたしの言葉に従わなかった』」。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="ヨシュア記 17:2; ヘブル人への手紙 11:32; 士師記 13:3"> さて主の使がきて、アビエゼルびとヨアシに属するオフラにあるテレビンの木の下に座した。時にヨアシの子ギデオンはミデアンびとの目を避けるために酒ぶねの中で麦を打っていたが、</span>
<span className="v" id="v12" data-v="12" data-xref="ヨシュア記 1:5; ルカによる福音書 1:28; 士師記 2:18"> 主の使は彼に現れて言った、「大勇士よ、主はあなたと共におられます」。</span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 77:7–9; 歴代志下 15:2; イザヤ書 59:1–2"> ギデオンは言った、「ああ、君よ、主がわたしたちと共におられるならば、どうしてこれらの事がわたしたちに臨んだのでしょう。わたしたちの先祖が『主はわれわれをエジプトから導き上られたではないか』といって、わたしたちに告げたそのすべての不思議なみわざはどこにありますか。今、主はわたしたちを捨てて、ミデアンびとの手にわたされました」。</span>
<span className="v" id="v14" data-v="14" data-xref="ヨシュア記 1:5–9; ヘブル人への手紙 11:34; サムエル記上 12:11"> 主はふり向いて彼に言われた、「あなたはこのあなたの力をもって行って、ミデアンびとの手からイスラエルを救い出しなさい。わたしがあなたをつかわすのではありませんか」。</span>
<span className="v" id="v15" data-v="15" data-xref="サムエル記上 9:21; 出エジプト記 3:11; 出エジプト記 4:10"> ギデオンは主に言った、「ああ主よ、わたしはどうしてイスラエルを救うことができましょうか。わたしの氏族はマナセのうちで最も弱いものです。わたしはまたわたしの父の家族のうちで最も小さいものです」。</span>
<span className="v" id="v16" data-v="16" data-xref="ヨシュア記 1:5; 出エジプト記 3:12; 使徒行伝 11:21"> 主は言われた、「しかし、わたしがあなたと共におるから、ひとりを撃つようにミデアンびとを撃つことができるでしょう」。</span>
<span className="v" id="v17" data-v="17" data-xref="詩篇 86:17; 出エジプト記 33:13; イザヤ書 7:11"> ギデオンはまた主に言った、「わたしがもしあなたの前に恵みを得ていますならば、どうぞ、わたしと語るのがあなたであるというしるしを見せてください。</span>
<span className="v" id="v18" data-v="18" data-xref="士師記 13:15; 創世記 18:3; 創世記 18:5"> どうぞ、わたしが供え物を携えてあなたのもとにもどってきて、あなたの前に供えるまで、ここを去らないでください」。主は言われた、「わたしはあなたがもどって来るまで待ちましょう」。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="創世記 18:6–8; 士師記 13:15–19; レビ記 2:4"> そこでギデオンは自分の家に行って、やぎの子を整え、一エパの粉で種入れぬパンをつくり、肉をかごに入れ、あつものをつぼに盛り、テレビンの木の下におる彼のもとに持ってきて、それを供えた。</span>
<span className="v" id="v20" data-v="20" data-xref="士師記 13:19; 列王紀上 18:33–34"> 神の使は彼に言った、「肉と種入れぬパンをとって、この岩の上に置き、それにあつものを注ぎなさい」。彼はそのようにした。</span>
<span className="v" id="v21" data-v="21" data-xref="レビ記 9:24; 列王紀上 18:38; 歴代志下 7:1"> すると主の使が手にもっていたつえの先を出して、肉と種入れぬパンに触れると、岩から火が燃えあがって、肉と種入れぬパンとを焼きつくした。そして主の使は去って見えなくなった。</span>
<span className="v" id="v22" data-v="22" data-xref="創世記 32:30; 出エジプト記 33:20; 申命記 5:26"> ギデオンはその人が主の使であったことをさとって言った、「ああ主なる神よ、どうなることでしょう。わたしは顔をあわせて主の使を見たのですから」。</span>
<span className="v" id="v23" data-v="23" data-xref="ダニエル書 10:19; ヨハネによる福音書 20:26; 創世記 43:23"> 主は彼に言われた、「安心せよ、恐れるな。あなたは死ぬことはない」。</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 22:14; 出エジプト記 17:15; 士師記 8:32"> そこでギデオンは主のために祭壇をそこに築いて、それを「主は平安」と名づけた。これは今日までアビエゼルびとのオフラにある。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="出エジプト記 34:13; 士師記 3:7; 使徒行伝 5:29"> その夜、主はギデオンに言われた、「あなたの父の雄牛と七歳の第二の雄牛とを取り、あなたの父のもっているバアルの祭壇を打ちこわし、そのかたわらにあるアシラ像を切り倒し、</span>
<span className="v" id="v26" data-v="26" data-xref="コリント人への第一の手紙 14:40; サムエル記下 24:18; コリント人への第一の手紙 14:33"> あなたの神、主のために、このとりでの頂に、石を並べて祭壇を築き、第二の雄牛を取り、あなたが切り倒したアシラの木をもって燔祭をささげなさい」。</span>
<span className="v" id="v27" data-v="27" data-xref="テサロニケ人への第一の手紙 2:4; ヨハネによる福音書 2:5; 申命記 4:1"> ギデオンはしもべ十人を連れて、主が言われたとおりにおこなった。ただし彼は父の家族のもの、および町の人々を恐れたので、昼それを行うことができず、夜それを行った。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28"> 町の人々が朝早く起きて見ると、バアルの祭壇は打ちこわされ、そのかたわらのアシラ像は切り倒され、新たに築いた祭壇の上に、第二の雄牛がささげられてあった。</span>
<span className="v" id="v29" data-v="29"> そこで彼らは互に「これはだれのしわざか」と言って問い尋ねたすえ、「これはヨアシの子ギデオンのしわざだ」と言った。</span>
<span className="v" id="v30" data-v="30" data-xref="使徒行伝 26:9; ピリピ人への手紙 3:6; エレミヤ書 50:38"> 町の人々はヨアシに言った、「あなたのむすこを引き出して殺しなさい。彼はバアルの祭壇を打ちこわしそのかたわらにあったアシラ像を切り倒したのです」。</span>
<span className="v" id="v31" data-v="31" data-xref="エレミヤ書 10:11; コリント人への第一の手紙 8:4; エペソ人への手紙 5:11"> しかしヨアシは自分に向かって立っているすべての者に言った、「あなたがたはバアルのために言い争うのですか。あるいは彼を弁護しようとなさるのですか。バアルのために言い争う者は、あすの朝までに殺されるでしょう。バアルがもし神であるならば、自分の祭壇が打ちこわされたのだから、彼みずから言い争うべきです」。</span>
<span className="v" id="v32" data-v="32" data-xref="サムエル記上 12:11; 士師記 7:1; サムエル記下 11:21"> そこでその日、「自分の祭壇が打ちこわされたのだから、バアルみずからその人と言い争うべきです」と言ったので、ギデオンはエルバアルと呼ばれた。</span>
<span className="v" id="v33" data-v="33" data-xref="ヨシュア記 17:16; 士師記 6:3; ローマ人への手紙 8:35–39"> 時にミデアンびと、アマレクびとおよび東方の民がみな集まってヨルダン川を渡り、エズレルの谷に陣を取ったが、</span>
<span className="v" id="v34" data-v="34" data-xref="士師記 3:27; 歴代志下 24:20; 士師記 3:10"> 主の霊がギデオンに臨み、ギデオンがラッパを吹いたので、アビエゼルびとは集まって彼に従った。</span>
<span className="v" id="v35" data-v="35" data-xref="歴代志下 30:6–12; 士師記 4:6"> 次に彼があまねくマナセに使者をつかわしたので、マナセびともまた集まって彼に従った。彼がまたアセル、ゼブルンおよびナフタリに使者をつかわすと、その人々も上って彼を迎えた。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="士師記 6:14; マタイによる福音書 16:1; 士師記 6:17–20"> ギデオンは神に言った、「あなたがかつて言われたように、わたしの手によってイスラエルを救おうとされるならば、</span>
<span className="v" id="v37" data-v="37" data-xref="ホセア書 14:5; マタイによる福音書 10:5–6; マタイによる福音書 15:24"> わたしは羊の毛一頭分を打ち場に置きますから、露がその羊の毛の上にだけあって、地がすべてかわいているようにしてください。これによってわたしは、あなたがかつて言われたように、わたしの手によってイスラエルをお救いになることを知るでしょう」。</span>
<span className="v" id="v38" data-v="38" data-xref="イザヤ書 35:7"> すなわちそのようになった。彼が翌朝早く起きて、羊の毛をかき寄せ、その毛から露を絞ると、鉢に満ちるほどの水が出た。</span>
<span className="v" id="v39" data-v="39" data-xref="創世記 18:32; イザヤ書 50:2; 詩篇 107:33–35"> ギデオンは神に言った、「わたしをお怒りにならないように願います。わたしにもう一度だけ言わせてください。どうぞ、もう一度だけ羊の毛をもってためさせてください。どうぞ、羊の毛だけをかわかして、地にはことごとく露があるようにしてください」。</span>
<span className="v" id="v40" data-v="40"> 神はその夜、そうされた。すなわち羊の毛だけかわいて、地にはすべて露があった。</span>
</div>
</div>

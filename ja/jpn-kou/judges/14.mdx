<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨシュア記 15:10; ヨシュア記 19:43; ヨハネの第一の手紙 2:16"> サムソンはテムナに下って行き、ペリシテびとの娘で、テムナに住むひとりの女を見た。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 34:4; 創世記 21:21; 創世記 24:2–3"> 彼は帰ってきて父母に言った、「わたしはペリシテびとの娘で、テムナに住むひとりの女を見ました。彼女をめとってわたしの妻にしてください」。</span>
<span className="v" id="v3" data-v="3" data-xref="士師記 15:18; サムエル記上 17:36; サムエル記上 14:6"> 父母は言った、「あなたが行って、割礼をうけないペリシテびとのうちから妻を迎えようとするのは、身内の娘たちのうちに、あるいはわたしたちのすべての民のうちに女がないためなのですか」。しかしサムソンは父に言った、「彼女をわたしにめとってください。彼女はわたしの心にかないますから」。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="ヨシュア記 11:20; 詩篇 115:3; 士師記 13:1"> 父母はこの事が主から出たものであることを知らなかった。サムソンはペリシテびとを攻めようと、おりをうかがっていたからである。そのころペリシテびとはイスラエルを治めていた。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5"> かくてサムソンは父母と共にテムナに下って行った。彼がテムナのぶどう畑に着くと、一頭の若いししがほえたけって彼に向かってきた。</span>
<span className="v" id="v6" data-v="6" data-xref="士師記 3:10; 士師記 13:25; サムエル記上 11:6"> 時に主の霊が激しく彼に臨んだので、彼はあたかも子やぎを裂くようにそのししを裂いたが、手にはなんの武器も持っていなかった。しかしサムソンはそのしたことを父にも母にも告げなかった。</span>
<span className="v" id="v7" data-v="7"> サムソンは下って行って女と話し合ったが、女はサムソンの心にかなった。</span>
<span className="v" id="v8" data-v="8" data-xref="マタイによる福音書 1:20; 創世記 29:21"> 日がたって後、サムソンは彼女をめとろうとして帰ったが、道を転じて、かのししのしかばねを見ると、ししのからだに、はちの群れと、蜜があった。</span>
<span className="v" id="v9" data-v="9" data-xref="サムエル記上 14:25–30; 箴言 25:15"> 彼はそれをかきあつめ、手にとって歩きながら食べ、父母のもとに帰って、彼らに与えたので、彼らもそれを食べた。しかし、ししのからだからその蜜をかきあつめたことは彼らに告げなかった。</span>
</div>
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="創世記 29:22; ヨハネの黙示録 19:9; エステル記 1:7–22"> そこで父が下って、女のもとに行ったので、サムソンはそこにふるまいを設けた。そうすることは花婿のならわしであったからである。</span>
<span className="v" id="v11" data-v="11" data-xref="マタイによる福音書 9:15; サムエル記上 16:6; サムエル記上 10:23"> 人々はサムソンを見ると、三十人の客を連れてきて、同席させた。</span>
<span className="v" id="v12" data-v="12" data-xref="列王紀上 10:1; エゼキエル書 17:2; 創世記 45:22"> サムソンは彼らに言った、「わたしはあなたがたに一つのなぞを出しましょう。あなたがたがもし七日のふるまいのうちにそれを解いて、わたしに告げることができたなら、わたしはあなたがたに亜麻の着物三十と、晴れ着三十をさしあげましょう。</span>
<span className="v" id="v13" data-v="13"> しかしあなたがたが、それをわたしに告げることができなければ、亜麻の着物三十と晴れ着三十をわたしにくれなければなりません」。彼らはサムソンに言った、「なぞを出しなさい。わたしたちはそれを聞きましょう」。</span>
<span className="v" id="v14" data-v="14" data-xref="ヤコブの手紙 1:2–4; 列王紀上 17:6; ローマ人への手紙 8:37"> サムソンは彼らに言った、<br /><span className="pl pl-1">「食らう者から食い物が出、</span><br /><span className="pl pl-1">強い者から甘い物が出た」。</span><br />彼らは三日のあいだなぞを解くことができなかった。</span>
</div>
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="士師記 16:5; 士師記 15:6; 箴言 6:26"> 四日目になって、彼らはサムソンの妻に言った、「あなたの夫を説きすすめて、なぞをわたしたちに明かすようにしてください。そうしなければ、わたしたちは火をつけてあなたとあなたの父の家を焼いてしまいます。あなたはわたしたちの物を取るために、わたしたちを招いたのですか」。</span>
<span className="v" id="v16" data-v="16" data-xref="士師記 16:15; 創世記 2:24"> そこでサムソンの妻はサムソンの前に泣いて言った、「あなたはただわたしを憎むだけで、愛してくれません。あなたはわたしの国の人々になぞを出して、それをわたしに解き明かしませんでした」。サムソンは彼女に言った、「わたしは自分の父にも母にも解き明かさなかった。どうしてあなたに解き明かせよう」。</span>
<span className="v" id="v17" data-v="17" data-xref="士師記 16:16; ヨブ記 2:9; 士師記 16:13"> 彼女は七日のふるまいの間、彼の前に泣いていたが、七日目になって、サムソンはついに彼女に解き明かした。ひどく彼に迫ったからである。そこで彼女はなぞを自分の国の人々にあかした。</span>
<span className="v" id="v18" data-v="18"> 七日目になって、日の没する前に町の人々はサムソンに言った、<br /><span className="pl pl-1">「蜜より甘いものに何があろう。</span><br /><span className="pl pl-1">ししより強いものに何があろう」。</span><br />サムソンは彼らに言った、<br /><span className="pl pl-1">「わたしの若い雌牛で耕さなかったなら、</span><br /><span className="pl pl-1">わたしのなぞは解けなかった」。</span></span>
<span className="v" id="v19" data-v="19" data-xref="サムエル記上 11:6; 士師記 3:10; 士師記 13:25"> <span className="pl pl-1">この時、主の霊が激しくサムソンに臨んだので、サムソンはアシケロンに下って行って、その町の者三十人を殺し、彼らからはぎ取って、かのなぞを解いた人々に、その晴れ着を与え、激しく怒って父の家に帰った。</span></span>
<span className="v" id="v20" data-v="20" data-xref="士師記 15:2; ヨハネによる福音書 3:29; 詩篇 55:12–13"> <span className="pl pl-1">サムソンの妻は花婿付添人であった客の妻となった。</span></span>

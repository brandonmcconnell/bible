<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士師記 8:31; 詩篇 83:2–4; サムエル記下 15:6"> さてエルバアルの子アビメレクはシケムに行き、母の身内の人たちのもとに行って、彼らと母の父の家の一族とに言った、</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 29:14; 士師記 8:30; ヘブル人への手紙 2:14"> 「どうぞ、シケムのすべての人々の耳に告げてください、『エルバアルのすべての子七十人であなたがたを治めるのと、ただひとりであなたがたを治めるのと、どちらがよいか。わたしがあなたがたの骨肉であることを覚えてください』と」。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 29:15; 詩篇 10:3; 箴言 1:11–14"> そこで母の身内の人たちがアビメレクに代ってこれらの言葉をことごとくシケムのすべての人々の耳に告げると、彼らは心をアビメレクに傾け、「彼はわれわれの兄弟だ」と言って、</span>
<span className="v" id="v4" data-v="4" data-xref="士師記 8:33; 使徒行伝 17:5; 歴代志下 13:7"> バアル・ベリテの宮から銀七十シケルを取って彼に与えた。アビメレクはそれをもって、やくざのならず者を雇って自分に従わせ、</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀下 11:1–2; 歴代志下 21:4; 士師記 6:24"> オフラにある父の家に行って、エルバアルの子で、自分の兄弟である七十人を、一つの石の上で殺した。ただしエルバアルの末の子ヨタムは身を隠したので生き残った。</span>
<span className="v" id="v6" data-v="6" data-xref="サムエル記下 5:9; 列王紀上 12:20; 列王紀下 12:20"> そこでシケムのすべての人々とベテミロのすべての人々は集まり、行ってシケムにある石の柱のかたわらのテレビンの木のもとで、アビメレクを立てて王とした。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="申命記 11:29; ヨハネによる福音書 4:20; 申命記 27:12"> このことをヨタムに告げる者があったので、ヨタムは行ってゲリジム山の頂に立ち、大声に叫んで彼らに言った、「シケムの人々よ、わたしに聞きなさい。そうすれば神はあなたがたに聞かれるでしょう。</span>
<span className="v" id="v8" data-v="8" data-xref="士師記 8:22–23; ダニエル書 4:10–18; 列王紀下 14:9"> ある時、もろもろの木が自分たちの上に王を立てようと出て行ってオリブの木に言った、『わたしたちの王になってください』。</span>
<span className="v" id="v9" data-v="9" data-xref="レビ記 2:1; 出エジプト記 29:7; 使徒行伝 4:27"> しかしオリブの木は彼らに言った、『わたしはどうして神と人とをあがめるために用いられるわたしの油を捨てて行って、もろもろの木を治めることができましょう』。</span>
<span className="v" id="v10" data-v="10"> もろもろの木はまたいちじくの木に言った、『きてわたしたちの王になってください』。</span>
<span className="v" id="v11" data-v="11" data-xref="ルカによる福音書 13:6–7"> しかしいちじくの木は彼らに言った、『わたしはどうしてわたしの甘味と、わたしの良い果実とを捨てて行って、もろもろの木を治めることができましょう』。</span>
<span className="v" id="v12" data-v="12"> もろもろの木はまたぶどうの木に言った、『きてわたしたちの王になってください』。</span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 104:15; 伝道の書 10:19; 民数記 15:5"> しかし、ぶどうの木は彼らに言った、『わたしはどうして神と人とを喜ばせるわたしのぶどう酒を捨てて行って、もろもろの木を治めることができましょう』。</span>
<span className="v" id="v14" data-v="14" data-xref="列王紀下 14:9"> そこですべての木はいばらに言った、『きてわたしたちの王になってください』。</span>
<span className="v" id="v15" data-v="15" data-xref="イザヤ書 30:2; 士師記 9:20; ホセア書 14:7"> いばらはもろもろの木に言った、『あなたがたが真実にわたしを立てて王にするならば、きてわたしの陰に難を避けなさい。そうしなければ、いばらから火が出てレバノンの香柏を焼きつくすでしょう』。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="士師記 8:35"> あなたがたがアビメレクを立てて王にしたことは、真実と敬意とをもってしたものですか。あなたがたはエルバアルとその家をよく扱い、彼のおこないに応じてしたのですか。</span>
<span className="v" id="v17" data-v="17" data-xref="ローマ人への手紙 16:4; ローマ人への手紙 5:8; ヨハネの黙示録 12:11"> わたしの父はあなたがたのために戦い、自分の命を投げ出して、あなたがたをミデアンの手から救い出したのに、</span>
<span className="v" id="v18" data-v="18" data-xref="士師記 9:5–6; 士師記 8:30–31; 士師記 9:14"> あなたがたは、きょう、わたしの父の家に反抗して起り、その子七十人を一つの石の上で殺し、その腰元の子アビメレクをあなたがたの身内の者であるゆえに立てて、シケムの人々の王にしました。</span>
<span className="v" id="v19" data-v="19" data-xref="イザヤ書 8:6; ヤコブの手紙 4:16; ピリピ人への手紙 3:3"> あなたがたが、きょう、エルバアルとその家になされたことが真実と敬意をもってしたものであるならば、アビメレクのために喜びなさい。彼もまたあなたがたのために喜ぶでしょう。</span>
<span className="v" id="v20" data-v="20" data-xref="士師記 9:15; 士師記 9:56–57; 歴代志下 20:22–23"> しかし、そうでなければ、アビメレクから火が出て、シケムの人々とベテミロとを焼きつくし、またシケムの人々とベテミロからも火が出てアビメレクを焼きつくすでしょう」。</span>
<span className="v" id="v21" data-v="21" data-xref="民数記 21:16; サムエル記下 20:14; ヨシュア記 19:8"> こうしてヨタムは走って逃げ去り、ベエルに行き、兄弟アビメレクの顔をさけてそこに住んだ。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22"> アビメレクは三年の間イスラエルを治めたが、</span>
<span className="v" id="v23" data-v="23" data-xref="イザヤ書 33:1; イザヤ書 19:14; イザヤ書 19:2"> 神はアビメレクとシケムの人々の間に悪霊をおくられたので、シケムの人々はアビメレクを欺くようになった。</span>
<span className="v" id="v24" data-v="24" data-xref="列王紀上 2:32; 詩篇 7:16; エステル記 9:25"> これはエルバアルの七十人の子が受けた暴虐と彼らの血が、彼らを殺した兄弟アビメレクの上と、彼の手を強めてその兄弟を殺させたシケムの人々の上とに報いとなってきたのである。</span>
<span className="v" id="v25" data-v="25" data-xref="ヨシュア記 8:12–13; 箴言 1:11–12; ヨシュア記 8:4"> シケムの人々は彼に敵して待ち伏せする者を山々の頂におき、すべてその道を通り過ぎる者を略奪させた。このことがアビメレクに告げ知らされた。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="創世記 13:8; 創世記 19:7"> さてエベデの子ガアルはその身内の人々と一緒にシケムに移住したが、シケムの人々は彼を信用した。</span>
<span className="v" id="v27" data-v="27" data-xref="士師記 9:4; 士師記 9:46; 詩篇 109:17"> 人々は畑に出てぶどうを取り入れ、それを踏み絞って祭をし、神の宮に行って飲み食いしてアビメレクをのろった。</span>
<span className="v" id="v28" data-v="28" data-xref="創世記 34:2; 創世記 34:6; サムエル記上 25:10"> そしてエベデの子ガアルは言った、「アビメレクは何ものか。シケムのわれわれは何ものなれば彼に仕えなければならないのか。エルバアルの子とその役人ゼブルはシケムの先祖ハモルの一族に仕えたではないか。われわれはどうして彼に仕えなければならないのか。</span>
<span className="v" id="v29" data-v="29" data-xref="サムエル記下 15:4; サムエル記下 2:14–17; イザヤ書 36:8–9"> ああ、この民がわたしの手の下にあったらよいのだが。そうすればわたしはアビメレクをやめさせ、アビメレクに向かって『おまえの軍勢を増して出てこい』と言うであろう」。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30"> 町のつかさゼブルはエベデの子ガアルの言葉を聞いて怒りを発し、</span>
<span className="v" id="v31" data-v="31"> 使者をアルマにおるアビメレクにつかわして言わせた、「エベデの子ガアルとその身内の人々がシケムにきて、町を騒がせ、あなたにそむかせようとしています。</span>
<span className="v" id="v32" data-v="32" data-xref="ローマ人への手紙 3:15; 詩篇 36:4; 箴言 1:11–16"> それであなたと、あなたと共におる人々が夜のうちに行って、野に身を伏せ、</span>
<span className="v" id="v33" data-v="33" data-xref="サムエル記上 10:7; 伝道の書 9:10; レビ記 25:26"> 朝になって、日ののぼるとき、早く起き出て町を襲うならば、ガアルと、彼と共におる民は出てきて、あなたに抵抗するでしょう。その時あなたは機を得て、彼らを撃つことができるでしょう」。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34"> アビメレクと、彼と共にいたすべての民は夜のうちに起き出て、四組に分れ、身を伏せてシケムをうかがった。</span>
<span className="v" id="v35" data-v="35"> エベデの子ガアルが出て、町の門の入口に立ったとき、アビメレクと、彼と共にいた民が身を伏せていたところから立ちあがったので、</span>
<span className="v" id="v36" data-v="36" data-xref="マルコによる福音書 8:24; エゼキエル書 7:7"> ガアルは民を見てゼブルに言った、「ごらんなさい。民が山々の頂からおりてきます」。ゼブルは彼に言った、「あなたは山々の影を人のように見るのです」。</span>
<span className="v" id="v37" data-v="37" data-xref="申命記 18:14"> ガアルは再び言った、「ごらんなさい。民が国の中央部からおりてきます。一組は占い師のテレビンの木の方からきます」。</span>
<span className="v" id="v38" data-v="38" data-xref="士師記 9:28–29; 列王紀下 14:8–14; サムエル記下 2:26–27"> ゼブルは彼に言った、「あなたがかつて『アビメレクは何ものか。われわれは何ものなれば彼に仕えなければならないのか』と言ったあなたの口は今どこにありますか。これはあなたが侮った民ではありませんか。今、出て彼らと戦いなさい」。</span>
<span className="v" id="v39" data-v="39"> そこでガアルはシケムの人々を率い、出てアビメレクと戦ったが、</span>
<span className="v" id="v40" data-v="40" data-xref="列王紀上 20:18–21; 列王紀上 20:30"> アビメレクは彼を追ったので、ガアルは彼の前から逃げた。そして傷つき倒れる者が多く、門の入口にまで及んだ。</span>
<span className="v" id="v41" data-v="41" data-xref="士師記 9:28; 士師記 9:30"> こうしてアビメレクは引き続いてアルマにいたが、ゼブルはガアルとその身内の人々を追い出してシケムにおらせなかった。</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42"> 翌日、民が畑に出ると、そのことがアビメレクに聞えた。</span>
<span className="v" id="v43" data-v="43"> アビメレクは自分の民を率い、それを三組に分け、野に身を伏せて、うかがっていると、民が町から出てきたので、たちあがってこれを撃った。</span>
<span className="v" id="v44" data-v="44" data-xref="ガラテヤ人への手紙 5:15; 士師記 9:15; 士師記 9:20"> アビメレクと、彼と共にいた組の者は襲って行って、町の門の入口に立ち、他の二組は野にいたすべてのものを襲って、それを殺した。</span>
<span className="v" id="v45" data-v="45" data-xref="列王紀下 3:25; 申命記 29:23; ヤコブの手紙 2:13"> アビメレクはその日、終日、町を攻め、ついに町を取って、そのうちの民を殺し、町を破壊して、塩をまいた。</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="士師記 8:33; 士師記 9:4; 列王紀上 8:26"> シケムのやぐらの人々は皆これを聞いて、エルベリテの宮の塔にはいった。</span>
<span className="v" id="v47" data-v="47"> シケムのやぐらの人々が皆集まったことがアビメレクに聞えたので、</span>
<span className="v" id="v48" data-v="48" data-xref="詩篇 68:14; 箴言 1:11–12; 士師記 7:17–18"> アビメレクは自分と一緒にいた民をことごとく率いてザルモン山にのぼり、アビメレクは手におのを取って、木の枝を切り落し、それを取りあげて自分の肩にのせ、一緒にいた民にむかって言った、「あなたがたはわたしがしたことを見たとおりに急いでしなさい」。</span>
<span className="v" id="v49" data-v="49" data-xref="ガラテヤ人への手紙 5:15; ヤコブの手紙 3:16; 士師記 9:20"> そこで民もまた皆おのおのその枝を切り落し、アビメレクに従って行って、枝を塔によせかけ、塔に火をつけて彼らを攻めた。こうしてシケムのやぐらの人々もまたことごとく死んだ。男女おおよそ一千人であった。</span>
</div>
<div className="bp">
<span className="v" id="v50" data-v="50"> ついでアビメレクはテベツに行き、テベツに向かって陣を張り、これを攻め取ったが、</span>
<span className="v" id="v51" data-v="51"> 町の中に一つの堅固なやぐらがあって、すべての男女すなわち町の人々が皆そこに逃げ込み、あとを閉ざして、やぐらの屋根に上ったので、</span>
<span className="v" id="v52" data-v="52" data-xref="士師記 9:48–49; 列王紀下 14:10; 列王紀下 15:16"> アビメレクはやぐらのもとに押し寄せてこれを攻め、やぐらの入口に近づいて、火をつけて焼こうとしたとき、</span>
<span className="v" id="v53" data-v="53" data-xref="サムエル記下 11:21; ヨブ記 31:3; エレミヤ書 49:20"> ひとりの女がアビメレクの頭に、うすの上石を投げて、その頭骸骨を砕いた。</span>
<span className="v" id="v54" data-v="54" data-xref="サムエル記上 31:4–5"> アビメレクは自分の武器を持つ若者を急ぎ呼んで言った、「つるぎを抜いてわたしを殺せ。さもないと人々はわたしを、女に殺されたのだと言うであろう」。その若者が彼を刺し通したので彼は死んだ。</span>
<span className="v" id="v55" data-v="55" data-xref="サムエル記下 18:16; サムエル記下 20:21–22; 列王紀上 22:35–36"> イスラエルの人々はアビメレクの死んだのを見て、おのおの去って家に帰った。</span>
<span className="v" id="v56" data-v="56" data-xref="詩篇 94:23; 士師記 9:24; 箴言 5:22"> このように神はアビメレクがその兄弟七十人を殺して、自分の父に対して犯した悪に報いられた。</span>
<span className="v" id="v57" data-v="57" data-xref="士師記 9:20; ヨシュア記 6:26; 列王紀上 16:34"> また神はシケムの人々のすべての悪を彼らのこうべに報いられた。こうしてエルバアルの子ヨタムののろいが、彼らに臨んだのである。</span>
</div>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士師記 11:11; サムエル記上 3:20; サムエル記上 10:17"> そこでイスラエルの人々は、ダンからベエルシバまで、またギレアデの地からもみな出てきて、その会衆はひとりのようにミヅパで主のもとに集まった。</span>
<span className="v" id="v2" data-v="2" data-xref="士師記 8:10; 士師記 20:17; 士師記 20:15"> 民の首領たち、すなわちイスラエルのすべての部族の首領たちは、みずから神の民の集合に出た。つるぎを帯びている歩兵が四十万人あった。</span>
<span className="v" id="v3" data-v="3" data-xref="士師記 19:22–27; ルカによる福音書 14:31–32; ルカによる福音書 12:58–59"> ベニヤミンの人々は、イスラエルの人々がミヅパに上ったことを聞いた。イスラエルの人々は言った、「どうして、この悪事が起ったのか、われわれに話してください」。</span>
<span className="v" id="v4" data-v="4" data-xref="士師記 19:15–28"> 殺された女の夫であるレビびとは答えて言った、「わたしは、めかけと一緒にベニヤミンに属するギベアへ行って宿りましたが、</span>
<span className="v" id="v5" data-v="5" data-xref="士師記 19:22; 士師記 19:25–26; 創世記 19:4–8"> ギベアの人々は立ってわたしを攻め、夜の間に、わたしのおる家を取り囲んで、わたしを殺そうと企て、ついにわたしのめかけをはずかしめて、死なせました。</span>
<span className="v" id="v6" data-v="6" data-xref="士師記 19:29; ヨシュア記 7:15; 士師記 19:23"> それでわたしはめかけを捕えて断ち切り、それをイスラエルの嗣業のすべての地方にあまねく送りました。彼らがイスラエルにおいて憎むべきみだらなことを行ったからです。</span>
<span className="v" id="v7" data-v="7" data-xref="士師記 19:30; コリント人への第一の手紙 5:6; コリント人への第一の手紙 5:10–12"> イスラエルの人々よ、あなたがたは皆自分の意見と考えをここに述べてください」。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="伝道の書 9:10; 士師記 20:1; 箴言 21:3"> 民は皆ひとりのように立って言った、「われわれはだれも自分の天幕に行きません。まただれも自分の家に帰りません。</span>
<span className="v" id="v9" data-v="9" data-xref="ヨナ書 1:7; ネヘミヤ書 11:1; ヨシュア記 14:2"> われわれが今ギベアに対してしようとする事はこれです。われわれはくじを引いて、ギベアに攻めのぼりましょう。</span>
<span className="v" id="v10" data-v="10"> すなわちイスラエルのすべての部族から百人について十人、千人について百人、万人について千人を選んで、民の糧食をとらせ、民はベニヤミンのギベアに行って、ベニヤミンびとがイスラエルにおいておこなったすべてのみだらな事に対して、報復しましょう」。</span>
<span className="v" id="v11" data-v="11"> こうしてイスラエルの人々は皆集まり、一致結束して町を攻めようとした。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="申命記 13:14; 申命記 20:10; ローマ人への手紙 12:18"> イスラエルのもろもろの部族は人々をあまねくベニヤミンの部族のうちにつかわして言わせた、「あなたがたのうちに起ったこの事は、なんたる悪事でしょうか。</span>
<span className="v" id="v13" data-v="13" data-xref="申命記 17:12; 申命記 13:13; 士師記 19:22"> それで今ギベアにいるあの悪い人々をわたしなさい。われわれは彼らを殺して、イスラエルから悪を除き去りましょう」。しかしベニヤミンの人々はその兄弟であるイスラエルの人々の言葉を聞きいれなかった。</span>
<span className="v" id="v14" data-v="14" data-xref="民数記 20:20; ヨブ記 15:25–26; 民数記 21:23"> かえってベニヤミンの人々は町々からギベアに集まり、出てイスラエルの人々と戦おうとした。</span>
<span className="v" id="v15" data-v="15" data-xref="民数記 26:41; 士師記 20:25; 民数記 1:37"> その日、町々から集まったベニヤミンの人々はつるぎを帯びている者二万六千人あり、ほかにギベアの住民で集まった精兵が七百人あった。</span>
<span className="v" id="v16" data-v="16" data-xref="士師記 3:15; 歴代志上 12:2; サムエル記上 17:49–50"> このすべての民のうちに左ききの精兵が七百人あって、いずれも一本の毛すじをねらって石を投げても、はずれることがなかった。</span>
<span className="v" id="v17" data-v="17" data-xref="民数記 1:46; 歴代志下 17:14–18; 民数記 26:51"> イスラエルの人々の集まった者はベニヤミンを除いて、つるぎを帯びている者四十万人あり、いずれも軍人であった。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="士師記 20:23; 士師記 20:26–27; 民数記 27:21"> イスラエルの人々は立ちあがってベテルにのぼり、神に尋ねた、「われわれのうち、いずれがさきにのぼって、ベニヤミンの人々と戦いましょうか」。主は言われた、「ユダがさきに」。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="ヨシュア記 7:16; ヨシュア記 3:1; ヨシュア記 6:12"> そこでイスラエルの人々は、朝起きて、ギベアに対し陣を取った。</span>
<span className="v" id="v20" data-v="20"> すなわちイスラエルの人々はベニヤミンと戦うために出て行って、ギベアで彼らに対して戦いの備えをしたが、</span>
<span className="v" id="v21" data-v="21" data-xref="士師記 20:25; 詩篇 73:18–19; 歴代志下 28:10"> ベニヤミンの人々はギベアから出てきて、その日イスラエルの人々のうち二万二千人を地に撃ち倒した。</span>
<span className="v" id="v22" data-v="22" data-xref="詩篇 64:5; 士師記 20:17; サムエル記上 30:6"> しかしイスラエルの民の人々は奮いたって初めの日に備えをした所にふたたび戦いの備えをした。</span>
<span className="v" id="v23" data-v="23" data-xref="士師記 20:26–27; 詩篇 78:34–36; ヨシュア記 7:6"> そしてイスラエルの人々は上って行って主の前に夕暮まで泣き、主に尋ねた、「われわれは再びわれわれの兄弟であるベニヤミンの人々と戦いを交えるべきでしょうか」。主は言われた、「攻めのぼれ」。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24"> そこでイスラエルの人々は、次の日またベニヤミンの人々の所に攻めよせたが、</span>
<span className="v" id="v25" data-v="25" data-xref="士師記 20:21; 創世記 18:25; ローマ人への手紙 2:5"> ベニヤミンは次の日またギベアから出て、これを迎え、ふたたびイスラエルの人々のうち一万八千人を地に撃ち倒した。これらは皆つるぎを帯びている者であった。</span>
<span className="v" id="v26" data-v="26" data-xref="士師記 20:23; ヨエル書 2:12–18; 士師記 20:18"> これがためにイスラエルのすべての人々すなわち全軍はベテルに上って行って泣き、その所で主の前に座して、その日夕暮まで断食し、燔祭と酬恩祭を主の前にささげた。</span>
<span className="v" id="v27" data-v="27" data-xref="ヨシュア記 18:1; 士師記 20:18; サムエル記上 4:3–4"> そしてイスラエルの人々は主に尋ね、――そのころ神の契約の箱はそこにあって、</span>
<span className="v" id="v28" data-v="28" data-xref="士師記 7:9; ヨシュア記 24:33; 申命記 18:5"> アロンの子エレアザルの子であるピネハスが、それに仕えていた――そして言った、「われわれはなおふたたび出て、われわれの兄弟であるベニヤミンの人々と戦うべきでしょうか。あるいはやめるべきでしょうか」。主は言われた、「のぼれ。わたしはあす彼らをあなたがたの手にわたすであろう」。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="ヨシュア記 8:4; サムエル記下 5:23; 士師記 20:34"> そこでイスラエルはギベアの周囲に伏兵を置き、</span>
<span className="v" id="v30" data-v="30"> そしてイスラエルの人々は三日目にまたベニヤミンの人々のところに攻めのぼり、前のようにギベアに対して備えをした。</span>
<span className="v" id="v31" data-v="31" data-xref="士師記 19:13–14; ヨシュア記 7:5; イザヤ書 10:29"> ベニヤミンの人々は出て、民を迎えたが、ついに町からおびき出されたので、彼らは前のように大路で民を撃ちはじめ、また野でイスラエルの人を三十人ばかり殺した。その大路は、一つはベテルに至り、一つはギベアに至るものであった。</span>
<span className="v" id="v32" data-v="32" data-xref="ヨシュア記 8:15–16"> ベニヤミンの人々は言った、「彼らは初めのように、われわれの前に撃ち破られる」。しかしイスラエルの人々は言った、「われわれは逃げて、彼らを町から大路におびき出そう」。</span>
<span className="v" id="v33" data-v="33" data-xref="ヨシュア記 8:18–22"> そしてイスラエルの人々は皆その所から立ってバアル・タマルに備えをした。その間に待ち伏せていたイスラエルの人々がその所から、すなわちゲバの西から現れ出た。</span>
<span className="v" id="v34" data-v="34" data-xref="ヨシュア記 8:14; イザヤ書 47:11; ヨブ記 21:13"> すなわちイスラエルの全軍のうちから精兵一万人がきて、ギベアを襲い、その戦いは激しかった。しかしベニヤミンの人々は災の自分たちに迫っているのを知らなかった。</span>
<span className="v" id="v35" data-v="35" data-xref="ヨブ記 20:5; 士師記 20:15; 士師記 20:44–46"> 主がイスラエルの前にベニヤミンを撃ち敗られたので、イスラエルの人々は、その日ベニヤミンびと二万五千一百人を殺した。これらは皆つるぎを帯びている者であった。</span>
<span className="v" id="v36" data-v="36" data-xref="ヨシュア記 8:15–29"> こうしてベニヤミンの人々は自分たちの撃ち敗られたのを見た。<br />そこでイスラエルの人々はギベアに対して設けた伏兵をたのんで、ベニヤミンびとを避けて退いた。</span>
<span className="v" id="v37" data-v="37" data-xref="ヨシュア記 8:19; ヨシュア記 6:5; 出エジプト記 19:13"> 伏兵は急いでギベアに突き入り、進んでつるぎをもって町をことごとく撃った。</span>
<span className="v" id="v38" data-v="38" data-xref="ヨシュア記 8:20; 創世記 17:21; 列王紀下 4:16"> イスラエルの人々と伏兵の間に定めた合図は、町から大いなるのろしがあがるとき、</span>
<span className="v" id="v39" data-v="39" data-xref="士師記 20:32"> イスラエルの人々が戦いに転じることであった。さてベニヤミンは初めイスラエルの人々を撃って三十人ばかりを殺したので言った、「まことに彼らは最初の戦いのようにわれわれの前に撃ち敗られる」。</span>
<span className="v" id="v40" data-v="40" data-xref="ヨシュア記 8:20; ヨハネの黙示録 19:3; 創世記 19:28"> しかし、のろしが煙の柱となって町からのぼりはじめたので、ベニヤミンの人々がうしろを見ると、町はみな煙となって天にのぼっていた。</span>
<span className="v" id="v41" data-v="41" data-xref="ペテロの第二の手紙 2:12; ルカによる福音書 21:26; ヨハネの黙示録 6:15–17"> その時イスラエルの人々が向きを変えたので、ベニヤミンの人々は災が自分たちに迫ったのを見て、うろたえ、</span>
<span className="v" id="v42" data-v="42" data-xref="ヨシュア記 8:15; ホセア書 9:9; 哀歌 1:3"> イスラエルの人々の前から身をめぐらして荒野の方に向かったが、戦いが彼らに追い迫り、町から出てきた者どもは、彼らを中にはさんで殺した。</span>
<span className="v" id="v43" data-v="43" data-xref="ヨシュア記 8:20–22"> すなわちイスラエルの人々はベニヤミンの人々を切り倒し、追い撃ち、踏みにじって、ノハから東の方ギベアの向かいにまで及んだ。</span>
<span className="v" id="v44" data-v="44"> ベニヤミンの倒れた者は一万八千人で、みな勇士であった。</span>
<span className="v" id="v45" data-v="45" data-xref="ヨシュア記 15:32; 士師記 21:13; ゼカリヤ書 14:10"> 彼らは身をめぐらして荒野の方、リンモンの岩まで逃げたが、イスラエルの人々は大路でそのうち五千人を切り倒し、なおも追撃してギドムに至り、そのうちの二千人を殺した。</span>
<span className="v" id="v46" data-v="46" data-xref="士師記 20:35; 士師記 20:15"> こうしてその日ベニヤミンの倒れた者はつるぎを帯びている者合わせて二万五千人で、みな勇士であった。</span>
<span className="v" id="v47" data-v="47" data-xref="イザヤ書 1:9; 詩篇 103:9–10; ハバクク書 3:2"> しかし六百人の者は身をめぐらして荒野の方、リンモンの岩まで逃げて、四か月の間リンモンの岩に住んだ。</span>
<span className="v" id="v48" data-v="48" data-xref="申命記 13:15–17; 歴代志下 25:13; 歴代志下 28:6–9"> そこでイスラエルの人々はまた身をかえしてベニヤミンの人々を攻め、つるぎをもって人も獣もすべて見つけたものを撃ち殺し、また見つけたすべての町に火をかけた。</span>
</div>

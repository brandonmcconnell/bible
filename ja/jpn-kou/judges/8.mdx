<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="サムエル記下 19:41; 士師記 12:1–6; ヨブ記 5:2"> エフライムの人々はギデオンに向かい「あなたが、ミデアンびとと戦うために行かれたとき、われわれを呼ばれなかったが、どうしてそういうことをされたのですか」と言って激しく彼を責めた。</span>
<span className="v" id="v2" data-v="2" data-xref="コリント人への第一の手紙 13:4–7; ピリピ人への手紙 2:2–3; ヤコブの手紙 3:13–18"> ギデオンは彼らに言った、「今わたしのした事は、あなたがたのした事と比べものになりましょうか。エフライムの拾い集めた取り残りのぶどうはアビエゼルの収穫したぶどうにもまさるではありませんか。</span>
<span className="v" id="v3" data-v="3" data-xref="箴言 15:1; 士師記 7:24–25; ヨハネによる福音書 4:37"> 神はミデアンの君オレブとゼエブをあなたがたの手にわたされました。わたしのなし得た事は、あなたがたのした事と比べものになりましょうか」。ギデオンがこの言葉を述べると、彼らの憤りは解けた。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="ガラテヤ人への手紙 6:9; コリント人への第二の手紙 4:16; サムエル記上 14:28–29"> ギデオンは自分に従っていた三百人と共にヨルダンに行ってこれを渡り、疲れながらもなお追撃したが、</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 33:17; 詩篇 60:6; サムエル記上 25:18"> 彼はスコテの人々に言った、「どうぞわたしに従っている民にパンを与えてください。彼らが疲れているのに、わたしはミデアンの王ゼバとザルムンナを追撃しているのですから」。</span>
<span className="v" id="v6" data-v="6" data-xref="列王紀上 20:11; ピリピ人への手紙 2:21; 箴言 18:23"> スコテのつかさたちは言った、「ゼバとザルムンナは、すでにあなたの手のうちにあるのですか。われわれはどうしてあなたの軍勢にパンを与えねばならないのですか」。</span>
<span className="v" id="v7" data-v="7" data-xref="士師記 7:15"> ギデオンは言った、「それならば主がわたしの手にゼバとザルムンナをわたされるとき、わたしは野のいばらと、おどろをもって、あなたがたの肉を打つであろう」。</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 32:30–31; 列王紀上 12:25"> そしてギデオンはそこからペヌエルに上り、同じことをペヌエルの人々に述べると、彼らもスコテの人々が答えたように答えたので、</span>
<span className="v" id="v9" data-v="9" data-xref="士師記 8:17; 列王紀上 22:27–28"> ペヌエルの人々に言った、「わたしが安らかに帰ってきたとき、このやぐらを打ちこわすであろう」。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="士師記 7:12; 士師記 20:25; 士師記 20:2"> さてゼバとザルムンナは軍勢おおよそ一万五千人を率いて、カルコルにいた。これは皆、東方の民の全軍のうち生き残ったもので、戦死した者は、つるぎを帯びているものが十二万人あった。</span>
<span className="v" id="v11" data-v="11" data-xref="民数記 32:35; 民数記 32:42; 士師記 18:27"> ギデオンはノバとヨグベハの東の隊商の道を上って、敵軍の油断しているところを撃った。</span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 83:11; アモス書 2:14; ヨブ記 12:16–21"> ゼバとザルムンナは逃げたが、ギデオンは追撃して、ミデアンのふたりの王ゼバとザルムンナを捕え、その軍勢をことごとく撃ち敗った。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13"> こうしてヨアシの子ギデオンはヘレスの坂をとおって戦いから帰り、</span>
<span className="v" id="v14" data-v="14" data-xref="士師記 1:24–25; サムエル記上 30:11–15"> スコテの若者ひとりを捕えて、尋ねたところ、彼はスコテのつかさたち及び長老たち七十七人の名をギデオンのために書きしるした。</span>
<span className="v" id="v15" data-v="15" data-xref="士師記 8:6–7"> ギデオンはスコテの人々のところへ行って言った、「あなたがたがかつて『ゼバとザルムンナはすでにあなたの手のうちにあるのか。われわれはどうしてあなたの疲れた人々にパンを与えねばならないのか』と言って、わたしをののしったそのゼバとザルムンナを見なさい」。</span>
<span className="v" id="v16" data-v="16" data-xref="士師記 8:7; エズラ記 2:6; 箴言 10:13"> そして彼は、その町の長老たちを捕え、野のいばらと、おどろとを取り、それをもってスコテの人々を懲らし、</span>
<span className="v" id="v17" data-v="17" data-xref="士師記 8:9; 列王紀上 12:25"> またペヌエルのやぐらを打ちこわして町の人々を殺した。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="士師記 4:6; ユダの手紙 1:16; 詩篇 89:12"> そしてギデオンはゼバとザルムンナに言った、「あなたがたがタボルで殺したのは、どんな人々であったか」。彼らは答えた、「彼らはあなたに似てみな王子のように見えました」。</span>
<span className="v" id="v19" data-v="19"> ギデオンは言った、「彼らはわたしの兄弟、わたしの母の子たちだ。主は生きておられる。もしあなたがたが彼らを生かしておいたならば、わたしはあなたがたを殺さないのだが」。</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 149:9; サムエル記上 15:33; ヨシュア記 10:24"> そして長子エテルに言った、「立って、彼らを殺しなさい」。しかしその若者はなお年が若かったので、恐れてつるぎを抜かなかった。</span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 83:11; 士師記 8:26; イザヤ書 3:18"> そこでゼバとザルムンナは言った、「あなた自身が立って、わたしたちを撃ってください。人によってそれぞれ力も違いますから」。ギデオンは立ちあがってゼバとザルムンナを殺し、彼らのらくだの首に掛けてあった月形の飾りを取った。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="ヨハネによる福音書 6:15; 士師記 9:8–15; サムエル記上 12:12"> イスラエルの人々はギデオンに言った、「あなたはミデアンの手からわれわれを救われたのですから、あなたも、あなたの子も孫もわれわれを治めてください」。</span>
<span className="v" id="v23" data-v="23" data-xref="イザヤ書 33:22; サムエル記上 12:12; サムエル記上 10:19"> ギデオンは彼らに言った、「わたしはあなたがたを治めることはいたしません。またわたしの子もあなたがたを治めてはなりません。主があなたがたを治められます」。</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 25:13; 創世記 37:25; 創世記 37:28"> ギデオンはまた彼らに言った、「わたしはあなたがたに一つの願いがあります。あなたがたのぶんどった耳輪をめいめいわたしにください」。ミデアンびとはイシマエルびとであったゆえに、金の耳輪を持っていたからである。</span>
<span className="v" id="v25" data-v="25"> 彼らは答えた、「わたしどもは喜んでそれをさしあげます」。そして衣をひろげ、めいめいぶんどった耳輪をその中に投げ入れた。</span>
<span className="v" id="v26" data-v="26" data-xref="ヨハネの黙示録 18:16; ヨハネによる福音書 19:2; ヨハネの黙示録 18:12"> こうしてギデオンが求めて得た金の耳輪の重さは一千七百金シケルであった。ほかに月形の飾りと耳飾りと、ミデアンの王たちの着た紫の衣およびらくだの首に掛けた首飾りなどもあった。</span>
<span className="v" id="v27" data-v="27" data-xref="士師記 17:5; 士師記 18:14; 詩篇 106:39"> ギデオンはそれをもって一つのエポデを作り、それを自分の町オフラに置いた。イスラエルは皆それを慕って姦淫をおこなった。それはギデオンとその家にとって、わなとなった。</span>
<span className="v" id="v28" data-v="28" data-xref="士師記 5:31; 士師記 3:11; 士師記 3:30"> このようにしてミデアンはイスラエルの人々に征服されて、再びその頭をあげることができなかった。そして国はギデオンの世にあるうち、四十年のあいだ太平であった。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="士師記 6:32; 士師記 7:1; サムエル記上 12:11"> ヨアシの子エルバアルは行って自分の家に住んだ。</span>
<span className="v" id="v30" data-v="30" data-xref="士師記 9:5; 士師記 9:2; 列王紀上 11:3"> ギデオンは多くの妻をもっていたので、自分の子供だけで七十人あった。</span>
<span className="v" id="v31" data-v="31" data-xref="士師記 9:18; 創世記 22:24; 創世記 16:15"> シケムにいた彼のめかけがまたひとりの子を産んだので、アビメレクと名づけた。</span>
<span className="v" id="v32" data-v="32" data-xref="創世記 25:8; 士師記 6:24; ヨブ記 5:26"> ヨアシの子ギデオンは高齢に達して死に、アビエゼルびとのオフラにある父ヨアシの墓に葬られた。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="士師記 9:46; 士師記 2:19; 士師記 9:4"> ギデオンが死ぬと、イスラエルの人々はまたバアルを慕って、これと姦淫を行い、バアル・ベリテを自分たちの神とした。</span>
<span className="v" id="v34" data-v="34" data-xref="詩篇 78:42; 詩篇 106:21; 詩篇 78:11"> すなわちイスラエルの人々は周囲のもろもろの敵の手から自分たちを救われた彼らの神、主を覚えず、</span>
<span className="v" id="v35" data-v="35" data-xref="伝道の書 9:14–15; 士師記 9:5; 士師記 9:16–19"> またエルバアルすなわちギデオンがイスラエルのためにしたもろもろの善行に応じて彼の家族に親切をつくすこともしなかった。</span>
</div>
</div>

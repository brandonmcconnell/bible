<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士師記 2:21–22; 申命記 7:22; 箴言 17:3"> すべてカナンのもろもろの戦争を知らないイスラエルの人々を試みるために、主が残しておかれた国民は次のとおりである。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 3:5; 創世記 3:7; コリント人への第一の手紙 9:26–27"> これはただイスラエルの代々の子孫、特にまだ戦争を知らないものに、それを教え知らせるためである。</span>
<span className="v" id="v3" data-v="3" data-xref="ヨシュア記 13:3; ヨシュア記 13:5; 士師記 10:7"> すなわちペリシテびとの五人の君たちと、すべてのカナンびとと、シドンびとおよびレバノン山に住んで、バアル・ヘルモン山からハマテの入口までを占めていたヒビびとなどであって、</span>
<span className="v" id="v4" data-v="4" data-xref="士師記 3:1; 士師記 2:22; 出エジプト記 15:25"> これらをもってイスラエルを試み、主がモーセによって先祖たちに命じられた命令に、彼らが従うかどうかを知ろうとされたのである。</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 106:34–38; 創世記 10:15–18; 出エジプト記 3:8"> しかるにイスラエルの人々はカナンびと、ヘテびと、アモリびと、ペリジびと、ヒビびと、エブスびとのうちに住んで、</span>
<span className="v" id="v6" data-v="6" data-xref="申命記 7:3–4; 出エジプト記 34:16; 列王紀上 11:1–5"> 彼らの娘を妻にめとり、また自分たちの娘を彼らのむすこに与えて、彼らの神々に仕えた。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="出エジプト記 34:13; 列王紀下 23:6; 列王紀上 18:19"> こうしてイスラエルの人々は主の前に悪を行い、自分たちの神、主を忘れて、バアルおよびアシラに仕えた。</span>
<span className="v" id="v8" data-v="8" data-xref="士師記 2:14; ハバクク書 3:7; 士師記 4:9"> そこで主はイスラエルに対して激しく怒り、彼らをメソポタミヤの王クシャン・リシャタイムの手に売りわたされたので、イスラエルの人々は八年の間、クシャン・リシャタイムに仕えた。</span>
<span className="v" id="v9" data-v="9" data-xref="士師記 3:15; 士師記 1:13; 詩篇 22:5"> しかし、イスラエルの人々が主に呼ばわったとき、主はイスラエルの人々のために、ひとりの救助者を起して彼らを救われた。すなわちカレブの弟、ケナズの子オテニエルである。</span>
<span className="v" id="v10" data-v="10" data-xref="士師記 13:25; サムエル記上 11:6; 士師記 14:19"> 主の霊がオテニエルに臨んだので、彼はイスラエルをさばいた。彼が戦いに出ると、主はメソポタミヤの王クシャン・リシャタイムをその手にわたされたので、オテニエルの手はクシャン・リシャタイムに勝ち、</span>
<span className="v" id="v11" data-v="11" data-xref="士師記 5:31; 士師記 8:28; ヨシュア記 11:23"> 国は四十年のあいだ太平であった。ケナズの子オテニエルはついに死んだ。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="サムエル記上 12:9; 士師記 2:19; 士師記 2:14"> イスラエルの人々はまた主の前に悪をおこなった。すなわち彼らが主の前に悪をおこなったので、主はモアブの王エグロンを強めて、イスラエルに敵対させられた。</span>
<span className="v" id="v13" data-v="13" data-xref="士師記 1:16; 申命記 34:3; 士師記 5:14"> エグロンはアンモンおよびアマレクの人々を集め、きてイスラエルを撃ち、しゅろの町を占領した。</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 28:47–48; 申命記 28:40; レビ記 26:23–25"> こうしてイスラエルの人々は十八年の間モアブの王エグロンに仕えた。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="士師記 3:9; 詩篇 78:34; イザヤ書 36:16"> しかしイスラエルの人々が主に呼ばわったとき、主は彼らのために、ひとりの救助者を起された。すなわちベニヤミンびと、ゲラの子、左ききのエホデである。イスラエルの人々は彼によってモアブの王エグロンに、みつぎ物を送った。</span>
<span className="v" id="v16" data-v="16" data-xref="雅歌 3:8; ヨハネの黙示録 2:12; 詩篇 149:6"> エホデは長さ一キュビトのもろ刃のつるぎを作らせ、それを衣の下、右のももの上に帯びて、</span>
<span className="v" id="v17" data-v="17" data-xref="エゼキエル書 34:20; ヨブ記 15:27; エレミヤ書 50:11"> モアブの王エグロンにみつぎ物をもってきた。エグロンは非常に肥えた人であった。</span>
<span className="v" id="v18" data-v="18"> エホデがみつぎ物をささげ終ったとき、彼はみつぎ物をになってきた民を帰らせ、</span>
<span className="v" id="v19" data-v="19" data-xref="ヨシュア記 4:20; 士師記 3:20; 使徒行伝 23:18–19"> かれ自身はギルガルに近い石像のある所から引きかえして言った、「王よ、わたしはあなたに申しあげる機密をもっています」。そこで王は「さがっておれ」と言ったので、かたわらに立っている者は皆出て行った。</span>
<span className="v" id="v20" data-v="20" data-xref="エレミヤ書 10:7; アモス書 3:15; 詩篇 29:1"> エホデが王のところにはいって来ると、王はひとりで涼みの高殿に座していたので、エホデが「わたしは神の命によってあなたに申しあげることがあります」と言うと、王は座から立ちあがった。</span>
<span className="v" id="v21" data-v="21" data-xref="ゼカリヤ書 13:3; ヨブ記 20:25; サムエル記上 15:33"> そのときエホデは左の手を伸ばし、右のももからつるぎをとって王の腹を刺した。</span>
<span className="v" id="v22" data-v="22"> つるぎのつかも刃と共にはいったが、つるぎを腹から抜き出さなかったので、脂肪が刃をふさいだ。そして汚物が出た。</span>
<span className="v" id="v23" data-v="23"> エホデは廊下に出て、王のおる高殿の戸を閉じ、錠をおろした。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="サムエル記上 24:3"> 彼が出た後、王のしもべどもがきて、高殿の戸に錠のおろされてあるのを見て、「王はきっと涼み殿のへやで足をおおっておられるのだ」と思った。</span>
<span className="v" id="v25" data-v="25"> しもべどもは長いあいだ待っていたが、王がなお高殿の戸を開かないので、心配してかぎをとって開いて見ると、王は床にたおれて死んでいた。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26"> エホデは彼らのためらうまに、のがれて石像のある所を過ぎ、セイラに逃げていった。</span>
<span className="v" id="v27" data-v="27" data-xref="士師記 6:34; サムエル記上 13:3; 士師記 5:14"> 彼が行ってエフライムの山地にラッパを吹き鳴らしたので、イスラエルの人々は彼と共に山地から下ってエホデに従った。</span>
<span className="v" id="v28" data-v="28" data-xref="士師記 12:5; 士師記 7:9; 士師記 7:15"> エホデは彼らに言った、「わたしについてきなさい。主はあなたがたの敵モアブびとをあなたがたの手にわたされます」。そこで彼らはエホデに従って下り、ヨルダンの渡し場をおさえ、モアブびとをひとりも渡らせなかった。</span>
<span className="v" id="v29" data-v="29" data-xref="申命記 32:15; 士師記 3:17; 詩篇 17:10"> そのとき彼らはモアブびとおおよそ一万人を殺した。これはいずれも肥え太った勇士であって、ひとりも、のがれた者がなかった。</span>
<span className="v" id="v30" data-v="30" data-xref="士師記 3:11; 士師記 5:31"> こうしてモアブはその日イスラエルの手に服し、国は八十年のあいだ太平であった。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="士師記 5:6; コリント人への第一の手紙 1:17; サムエル記上 17:50"> エホデの後、アナテの子シャムガルが起り、牛のむちをもってペリシテびと六百人を殺した。この人もまたイスラエルを救った。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出エジプト記 20:2; 創世記 17:7–8; レビ記 26:42"> 主の使がギルガルからボキムに上って言った、「わたしはあなたがたをエジプトから上らせて、あなたがたの先祖に誓った地に連れてきて、言った、『わたしはあなたと結んだ契約を決して破ることはない。</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 7:2–4; エレミヤ書 2:36; エズラ記 9:1–3"> あなたがたはこの国の住民と契約を結んではならない。彼らの祭壇をこぼたなければならない』と。しかし、あなたがたはわたしの命令に従わなかった。あなたがたは、なんということをしたのか。</span>
<span className="v" id="v3" data-v="3" data-xref="ヨシュア記 23:13; 民数記 33:55; 申命記 7:16"> それでわたしは言う、『わたしはあなたがたの前から彼らを追い払わないであろう。彼らはかえってあなたがたの敵となり、彼らの神々はあなたがたのわなとなるであろう』と」。</span>
<span className="v" id="v4" data-v="4" data-xref="エレミヤ書 31:9; 箴言 17:10; ゼカリヤ書 12:10"> 主の使がこれらの言葉をイスラエルのすべての人々に告げたので、民は声をあげて泣いた。</span>
<span className="v" id="v5" data-v="5" data-xref="サムエル記上 7:9; 創世記 35:8; ヨシュア記 7:26"> それでその所の名をボキムと呼んだ。そして彼らはその所で主に犠牲をささげた。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="ヨシュア記 24:28–31; ヨシュア記 22:6"> ヨシュアが民を去らせたので、イスラエルの人々はおのおのその領地へ行って土地を獲た。</span>
<span className="v" id="v7" data-v="7" data-xref="ピリピ人への手紙 2:12; ヨシュア記 24:31; 歴代志下 24:2"> 民はヨシュアの在世中も、またヨシュアのあとに生き残った長老たち、すなわち主がかつてイスラエルのために行われたすべての大いなるわざを見た人々の在世中も主に仕えた。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨシュア記 24:29–30"> こうして主のしもべヌンの子ヨシュアは百十歳で死んだ。</span>
<span className="v" id="v9" data-v="9" data-xref="ヨシュア記 19:50; ヨシュア記 24:30"> 人々は彼をエフライムの山地のガアシ山の北のテムナテ・ヘレスにある彼の領地内に葬った。</span>
<span className="v" id="v10" data-v="10" data-xref="サムエル記上 2:12; テトスヘの手紙 1:16; 出エジプト記 5:2"> そしてその時代の者もまたことごとくその先祖たちのもとにあつめられた。その後ほかの時代が起ったが、これは主を知らず、また主がイスラエルのために行われたわざをも知らなかった。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="士師記 4:1; 士師記 6:1; 士師記 3:7"> イスラエルの人々は主の前に悪を行い、もろもろのバアルに仕え、</span>
<span className="v" id="v12" data-v="12" data-xref="出エジプト記 20:5; 申命記 13:5; 申命記 6:14–15"> かつてエジプトの地から彼らを導き出された先祖たちの神、主を捨てて、ほかの神々すなわち周囲にある国民の神々に従い、それにひざまずいて、主の怒りをひき起した。</span>
<span className="v" id="v13" data-v="13" data-xref="士師記 10:6; 詩篇 106:36; 士師記 3:7"> すなわち彼らは主を捨てて、バアルとアシタロテに仕えたので、</span>
<span className="v" id="v14" data-v="14" data-xref="列王紀下 17:20; 詩篇 106:40–42; 申命記 32:30"> 主の怒りがイスラエルに対して燃え、かすめ奪う者の手にわたして、かすめ奪わせ、かつ周囲のもろもろの敵の手に売られたので、彼らは再びその敵に立ち向かうことができなかった。</span>
<span className="v" id="v15" data-v="15" data-xref="申命記 28:15–68; ヨシュア記 23:15–16; レビ記 26:14–46"> 彼らがどこへ行っても、主の手は彼らに災をした。これは主がかつて言われ、また主が彼らに誓われたとおりで、彼らはひどく悩んだ。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="使徒行伝 13:20; 詩篇 106:43–45; サムエル記上 12:11"> その時、主はさばきづかさを起して、彼らをかすめ奪う者の手から救い出された。</span>
<span className="v" id="v17" data-v="17" data-xref="ガラテヤ人への手紙 1:6; 申命記 9:12; 士師記 2:7"> しかし彼らはそのさばきづかさにも従わず、かえってほかの神々を慕ってそれと姦淫を行い、それにひざまずき、先祖たちが主の命令に従って歩んだ道を、いちはやく離れ去って、そのようには行わなかった。</span>
<span className="v" id="v18" data-v="18" data-xref="申命記 32:36; ヨシュア記 1:5; 出エジプト記 2:24"> 主が彼らのためにさばきづかさを起されたとき、そのさばきづかさの在世中、主はさばきづかさと共におられて、彼らを敵の手から救い出された。これは彼らが自分をしえたげ悩ました者のゆえに、うめき悲しんだので、主が彼らをあわれまれたからである。</span>
<span className="v" id="v19" data-v="19" data-xref="士師記 8:33; 士師記 4:1; マタイによる福音書 23:32"> しかしさばきづかさが死ぬと、彼らはそむいて、先祖たちにまさって悪を行い、ほかの神々に従ってそれに仕え、それにひざまずいてそのおこないをやめず、かたくなな道を離れなかった。</span>
<span className="v" id="v20" data-v="20" data-xref="士師記 2:14; ヨシュア記 23:16; 出エジプト記 32:10–11"> それで主はイスラエルに対し激しく怒って言われた、「この民はわたしがかつて先祖たちに命じた契約を犯し、わたしの命令に従わないゆえ、</span>
<span className="v" id="v21" data-v="21" data-xref="ヨシュア記 23:13; 士師記 2:3; 士師記 3:3"> わたしもまたヨシュアが死んだときに残しておいた国民を、この後、彼らの前から追い払わないであろう。</span>
<span className="v" id="v22" data-v="22" data-xref="申命記 8:2; 申命記 8:16; 申命記 13:3"> これはイスラエルが、先祖たちの守ったように主の道を守ってそれに歩むかどうかをわたしが試みるためである」。</span>
<span className="v" id="v23" data-v="23"> それゆえ主はこれらの国民を急いで追い払わずに残しておいて、ヨシュアの手にわたされなかったのである。</span>
</div>

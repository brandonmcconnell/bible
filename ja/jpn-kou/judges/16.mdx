<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨシュア記 15:47; エズラ記 9:1–2; 創世記 38:16–18"> サムソンはガザへ行って、そこでひとりの遊女を見、その女のところにはいった。</span>
<span className="v" id="v2" data-v="2" data-xref="詩篇 118:10–12; サムエル記上 23:26; 使徒行伝 9:24"> 「サムソンがここにきた」と、ガザの人々に告げるものがあったので、ガザの人々はその所を取り囲み、夜通し町の門で待ち伏せし、「われわれは朝まで待って彼を殺そう」と言って、夜通し静かにしていた。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行伝 2:24; 詩篇 107:16; イザヤ書 63:1–5"> サムソンは夜中まで寝たが、夜中に起きて、町の門のとびらと二つの門柱に手をかけて、貫の木もろともに引き抜き、肩に載せて、ヘブロンの向かいにある山の頂に運んで行った。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="コリント人への第一の手紙 10:6; 箴言 22:14; ネヘミヤ書 13:26"> この後、サムソンはソレクの谷にいるデリラという女を愛した。</span>
<span className="v" id="v5" data-v="5" data-xref="ヨシュア記 13:3; 士師記 14:15; テモテヘの第一の手紙 6:9–10"> ペリシテびとの君たちはその女のところにきて言った、「あなたはサムソンを説きすすめて、彼の大力はどこにあるのか、またわれわれはどうすれば彼に勝って、彼を縛り苦しめることができるかを見つけなさい。そうすればわれわれはおのおの銀千百枚ずつをあなたにさしあげましょう」。</span>
<span className="v" id="v6" data-v="6" data-xref="箴言 7:21; 箴言 6:26; 箴言 22:14"> そこでデリラはサムソンに言った、「あなたの大力はどこにあるのか、またどうすればあなたを縛って苦しめることができるか、どうぞわたしに聞かせてください」。</span>
<span className="v" id="v7" data-v="7" data-xref="サムエル記上 21:2–3; ローマ人への手紙 3:8; サムエル記上 27:10"> サムソンは女に言った、「人々がもし、かわいたことのない七本の新しい弓弦をもってわたしを縛るなら、わたしは弱くなってほかの人のようになるでしょう」。</span>
<span className="v" id="v8" data-v="8" data-xref="伝道の書 7:26"> そこでペリシテびとの君たちが、かわいたことのない七本の新しい弓弦を女に持ってきたので、女はそれをもってサムソンを縛った。</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 58:9"> 女はかねて奥のへやに人を忍ばせておいて、サムソンに言った、「サムソンよ、ペリシテびとがあなたに迫っています」。しかしサムソンはその弓弦を、あたかも亜麻糸が火にあって断たれるように断ち切った。こうして彼の力の秘密は知れなかった。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="士師記 16:13; ルカによる福音書 22:48; 士師記 16:7"> デリラはサムソンに言った、「あなたはわたしを欺いて、うそを言いました。どうしたらあなたを縛ることができるか、どうぞ今わたしに聞かせてください」。</span>
<span className="v" id="v11" data-v="11" data-xref="箴言 13:5; エペソ人への手紙 4:25; 箴言 13:3"> サムソンは女に言った、「もし人々がまだ用いたことのない新しい綱をもって、わたしを縛るなら、弱くなってほかの人のようになるでしょう」。</span>
<span className="v" id="v12" data-v="12"> そこでデリラは新しい綱をとり、それをもって彼を縛り、そして彼に言った、「サムソンよ、ペリシテびとがあなたに迫っています」。時に人々は奥のへやに忍んでいたが、サムソンはその綱を糸のように腕から断ち落した。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13"> そこでデリラはサムソンに言った、「あなたは今まで、わたしを欺いて、うそを言いましたが、どうしたらあなたを縛ることができるか、わたしに聞かせてください」。彼は女に言った、「あなたがもし、わたしの髪の毛七ふさを機の縦糸と一緒に織って、くぎでそれを留めておくならば、わたしは弱くなってほかの人のようになるでしょう」。そこで彼が眠ったとき、デリラはサムソンの髪の毛、七ふさをとって、それを機の縦糸に織り込み、</span>
<span className="v" id="v14" data-v="14" data-xref="詩篇 106:43; エズラ記 9:13–14"> くぎでそれを留めておいて、彼に言った、「サムソンよ、ペリシテびとがあなたに迫っています」。しかしサムソンは目をさまして、くぎと機と縦糸とを引き抜いた。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="士師記 14:16; ヨハネの第一の手紙 2:15–16; ヨハネによる福音書 14:21–24"> そこで女はサムソンに言った、「あなたの心がわたしを離れているのに、どうして『おまえを愛する』と言うことができますか。あなたはすでに三度もわたしを欺き、あなたの大力がどこにあるかをわたしに告げませんでした」。</span>
<span className="v" id="v16" data-v="16" data-xref="箴言 7:21–23; ルカによる福音書 18:5; マルコによる福音書 14:24"> 女は毎日その言葉をもって彼に迫り促したので、彼の魂は死ぬばかりに苦しんだ。</span>
<span className="v" id="v17" data-v="17" data-xref="ミカ書 7:5; 士師記 13:5; 箴言 12:23"> 彼はついにその心をことごとく打ち明けて女に言った、「わたしの頭にはかみそりを当てたことがありません。わたしは生れた時から神にささげられたナジルびとだからです。もし髪をそり落されたなら、わたしの力は去って弱くなり、ほかの人のようになるでしょう」。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="マタイによる福音書 26:15; 士師記 16:5; テモテヘの第一の手紙 6:10"> デリラはサムソンがその心をことごとく打ち明けたのを見、人をつかわしてペリシテびとの君たちを呼んで言った、「サムソンはその心をことごとくわたしに打ち明けましたから、今度こそ上っておいでなさい」。そこでペリシテびとの君たちは、銀を携えて女のもとに上ってきた。</span>
<span className="v" id="v19" data-v="19" data-xref="箴言 7:26–27; 箴言 7:21–23; 伝道の書 7:26"> 女は自分のひざの上にサムソンを眠らせ、人を呼んで髪の毛、七ふさをそり落させ、彼を苦しめ始めたが、その力は彼を去っていた。</span>
<span className="v" id="v20" data-v="20" data-xref="民数記 14:42–43; サムエル記上 16:14; ヨシュア記 7:12"> そして女が「サムソンよ、ペリシテびとがあなたに迫っています」と言ったので、彼は目をさまして言った、「わたしはいつものように出て行って、からだをゆすろう」。彼は主が自分を去られたことを知らなかった。</span>
<span className="v" id="v21" data-v="21" data-xref="箴言 2:19; 箴言 14:14; イザヤ書 47:2"> そこでペリシテびとは彼を捕えて、両眼をえぐり、ガザに引いて行って、青銅の足かせをかけて彼をつないだ。こうしてサムソンは獄屋の中で、うすをひいていたが、</span>
<span className="v" id="v22" data-v="22" data-xref="詩篇 107:13–14; 詩篇 106:44–45; レビ記 26:44"> その髪の毛はそり落された後、ふたたび伸び始めた。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="サムエル記上 5:2–5; 箴言 24:17; 詩篇 35:15–16"> さてペリシテびとの君たちは、彼らの神ダゴンに大いなる犠牲をささげて祝をしようと、共に集まって言った、「われわれの神は、敵サムソンをわれわれの手にわたされた」。</span>
<span className="v" id="v24" data-v="24" data-xref="ダニエル書 5:4; ダニエル書 5:23; 士師記 15:16"> 民はサムソンを見て、自分たちの神をほめたたえて言った、「われわれの神は、われわれの国を荒し、われわれを多く殺した敵をわれわれの手にわたされた」。</span>
<span className="v" id="v25" data-v="25" data-xref="サムエル記下 13:28; 士師記 19:6; 士師記 9:27"> 彼らはまた心に喜んで言った、「サムソンを呼んで、われわれのために戯れ事をさせよう」。彼らは獄屋からサムソンを呼び出して、彼らの前に戯れ事をさせた。彼らがサムソンを柱のあいだに立たせると、</span>
<span className="v" id="v26" data-v="26"> サムソンは自分の手をひいている若者に言った、「わたしの手を放して、この家をささえている柱をさぐらせ、それに寄りかからせてください」。</span>
<span className="v" id="v27" data-v="27" data-xref="申命記 22:8; サムエル記下 11:2; ヨシュア記 2:8"> その家には男女が満ち、ペリシテびとの君たちも皆そこにいた。また屋根の上には三千人ばかりの男女がいて、サムソンの戯れ事をするのを見ていた。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="エレミヤ書 15:15; 哀歌 3:31–32; 詩篇 143:12"> サムソンは主に呼ばわって言った、「ああ、主なる神よ、どうぞ、わたしを覚えてください。ああ、神よ、どうぞもう一度、わたしを強くして、わたしの二つの目の一つのためにでもペリシテびとにあだを報いさせてください」。</span>
<span className="v" id="v29" data-v="29"> そしてサムソンは、その家をささえている二つの中柱の一つを右の手に、一つを左の手にかかえて、身をそれに寄せ、</span>
<span className="v" id="v30" data-v="30" data-xref="ピリピ人への手紙 2:8; マタイによる福音書 16:25; マタイによる福音書 24:38–39"> 「わたしはペリシテびとと共に死のう」と言って、力をこめて身をかがめると、家はその中にいた君たちと、すべての民の上に倒れた。こうしてサムソンが死ぬときに殺したものは、生きているときに殺したものよりも多かった。</span>
<span className="v" id="v31" data-v="31" data-xref="士師記 15:20; 士師記 13:25; 士師記 13:2"> やがて彼の身内の人たちおよび父の家族の者がみな下ってきて、彼を引き取り、携え上って、ゾラとエシタオルの間にある父マノアの墓に葬った。サムソンがイスラエルをさばいたのは二十年であった。</span>
</div>
</div>

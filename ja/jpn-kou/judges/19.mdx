<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士師記 18:1; 士師記 17:8; マラキ書 2:15"> そのころ、イスラエルに王がなかった時、エフライムの山地の奥にひとりのレビびとが寄留していた。彼はユダのベツレヘムからひとりの女を迎えて、めかけとしていたが、</span>
<span className="v" id="v2" data-v="2" data-xref="エゼキエル書 16:28; 申命記 22:21; レビ記 21:9"> そのめかけは怒って、彼のところを去り、ユダのベツレヘムの父の家に帰って、そこに四か月ばかり過ごした。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 34:3; 創世記 50:21; レビ記 19:17"> そこで夫は彼女をなだめて連れ帰ろうと、しもべと二頭のろばを従え、立って彼女のあとを追って行った。彼が女の父の家に着いた時、娘の父は彼を見て、喜んで迎えた。</span>
<span className="v" id="v4" data-v="4"> 娘の父であるしゅうとが引き留めたので、彼は三日共におり、みな飲み食いしてそこに宿った。</span>
<span className="v" id="v5" data-v="5" data-xref="士師記 19:8; 創世記 18:5; 詩篇 104:15"> 四日目に彼らは朝はやく起き、彼が立ち去ろうとしたので、娘の父は婿に言った、「少し食事をして元気をつけ、それから出かけなさい」。</span>
<span className="v" id="v6" data-v="6" data-xref="士師記 19:9; 士師記 16:25; ルツ記 3:7"> そこでふたりは座して共に飲み食いしたが、娘の父はその人に言った、「どうぞもう一晩泊まって楽しく過ごしなさい」。</span>
<span className="v" id="v7" data-v="7"> その人は立って去ろうとしたが、しゅうとがしいたので、ついにまたそこに宿った。</span>
<span className="v" id="v8" data-v="8"> 五日目になって、朝はやく起きて去ろうとしたが、娘の父は言った、「どうぞ、元気をつけて、日が傾くまでとどまりなさい」。そこで彼らふたりは食事をした。</span>
<span className="v" id="v9" data-v="9" data-xref="箴言 27:1; ルカによる福音書 24:29; ヤコブの手紙 4:13–14"> その人がついにめかけおよびしもべと共に去ろうとして立ちあがったとき、娘の父であるしゅうとは彼に言った、「日も暮れようとしている。どうぞもう一晩泊まりなさい。日は傾いた。ここに宿って楽しく過ごしなさい。そしてあしたの朝はやく起きて出立し、家に帰りなさい」。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="ヨシュア記 15:63; ヨシュア記 15:8; 士師記 1:8"> しかし、その人は泊まることを好まないので、立って去り、エブスすなわちエルサレムの向かいに着いた。くらをおいた二頭のろばと彼のめかけも一緒であった。</span>
<span className="v" id="v11" data-v="11" data-xref="サムエル記下 5:6; 士師記 1:21; 士師記 19:10"> 彼らがエブスに近づいたとき、日はすでに没したので、しもべは主人に言った、「さあ、われわれは道を転じてエブスびとのこの町にはいって、そこに宿りましょう」。</span>
<span className="v" id="v12" data-v="12"> 主人は彼に言った、「われわれは道を転じて、イスラエルの人々の町でない外国人の町に、はいってはならない。ギベアまで行こう」。</span>
<span className="v" id="v13" data-v="13" data-xref="サムエル記上 10:26; ホセア書 5:8; イザヤ書 10:29"> 彼はまたしもべに言った、「さあ、われわれはギベアかラマか、そのうちの一つに着いてそこに宿ろう」。</span>
<span className="v" id="v14" data-v="14"> 彼らは進んで行ったが、ベニヤミンに属するギベアの近くで日が暮れたので、</span>
<span className="v" id="v15" data-v="15" data-xref="士師記 19:18; マタイによる福音書 25:35; マタイによる福音書 25:43"> ギベアへ行って宿ろうと、そこに道を転じ、町にはいって、その広場に座した。だれも彼らを家に迎えて泊めてくれる者がなかったからである。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="士師記 19:1; 詩篇 104:23; 創世記 3:19"> 時にひとりの老人が夕暮に畑の仕事から帰ってきた。この人はエフライムの山地の者で、ギベアに寄留していたのである。ただしこの所の人々はベニヤミンびとであった。</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 32:17; 創世記 16:8"> 彼は目をあげて、町の広場に旅人のおるのを見た。老人は言った、「あなたはどこへ行かれるのですか。どこからおいでになりましたか」。</span>
<span className="v" id="v18" data-v="18" data-xref="士師記 18:31; ヨハネによる福音書 15:6; サムエル記上 1:7"> その人は言った、「われわれはユダのベツレヘムから、エフライムの山地の奥へ行くものです。わたしはあそこの者で、ユダのベツレヘムへ行き、今わたしの家に帰るところですが、だれもわたしを家に泊めてくれる者がありません。</span>
<span className="v" id="v19" data-v="19"> われわれには、ろばのわらも飼葉もあり、またわたしと、はしためと、しもべと共にいる若者との食物も酒もあって、何も欠けているものはありません」。</span>
<span className="v" id="v20" data-v="20" data-xref="士師記 6:23; ヤコブの手紙 2:15–16; ヘブル人への手紙 13:2"> 老人は言った、「安心しなさい。あなたの必要なものはなんでも備えましょう。ただ広場で夜を過ごしてはなりません」。</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 43:24; 創世記 18:4; ルカによる福音書 7:44"> そして彼を家に連れていって、ろばに飼葉を与えた。彼らは足を洗って飲み食いした。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="創世記 19:4–5; コリント人への第一の手紙 6:9; 士師記 20:5"> 彼らが楽しく過ごしていた時、町の人々の悪い者どもがその家を取り囲み、戸を打ちたたいて、家のあるじである老人に言った、「あなたの家にきた人を出しなさい。われわれはその者を知るであろう」。</span>
<span className="v" id="v23" data-v="23" data-xref="創世記 34:7; サムエル記下 13:12; 士師記 20:6"> しかし家のあるじは彼らのところに出ていって言った、「いいえ、兄弟たちよ、どうぞ、そんな悪いことをしないでください。この人はすでにわたしの家にはいったのだから、そんなつまらない事をしないでください。</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 19:8; 申命記 21:14; 創世記 34:2"> ここに処女であるわたしの娘と、この人のめかけがいます。今それを出しますから、それをはずかしめ、あなたがたの好きなようにしなさい。しかしこの人にはそのようなつまらない事をしないでください」。</span>
<span className="v" id="v25" data-v="25" data-xref="ホセア書 10:9; ホセア書 9:9; ホセア書 7:4–7"> しかし人々が聞きいれなかったので、その人は自分のめかけをとって彼らのところに出した。彼らはその女を犯して朝まで終夜はずかしめ、日ののぼるころになって放し帰らせた。</span>
<span className="v" id="v26" data-v="26" data-xref="士師記 19:3; 創世記 18:12; ペテロの第一の手紙 3:6"> 朝になって女は自分の主人を宿してくれた人の家の戸口にきて倒れ伏し、夜のあけるまでに及んだ。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27"> 彼女の主人は朝起きて家の戸を開き、出て旅立とうとすると、そのめかけである女が家の戸口に、手を敷居にかけて倒れていた。</span>
<span className="v" id="v28" data-v="28" data-xref="士師記 20:5; 列王紀上 18:29"> 彼は女に向かって、「起きよ、行こう」と言ったけれども、なんの答もなかった。そこでその人は女をろばに乗せ、立って自分の家におもむいたが、</span>
<span className="v" id="v29" data-v="29" data-xref="士師記 20:6–7; サムエル記上 11:7; ローマ人への手紙 10:2"> その家に着いたとき、刀を執り、めかけを捕えて、そのからだを十二切れに断ち切り、それをイスラエルの全領域にあまねく送った。</span>
<span className="v" id="v30" data-v="30" data-xref="士師記 20:7; 箴言 13:10; ホセア書 9:9"> それを見たものはみな言った、「イスラエルの人々がエジプトの地から上ってきた日から今日まで、このような事は起ったこともなく、また見たこともない。この事をよく考え、協議して言うことを決めよ」。</span>
</div>

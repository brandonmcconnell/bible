<span className="v" id="v1" data-v="1" data-xref="ローマ人への手紙 1:1; テモテヘの第一の手紙 6:3; テモテヘの第二の手紙 2:25"> 神の僕、イエス・キリストの使徒パウロから――わたしが使徒とされたのは、神に選ばれた者たちの信仰を強め、また、信心にかなう真理の知識を彼らに得させるためであり、</span>
<span className="v" id="v2" data-v="2" data-xref="民数記 23:19; ヨハネの第一の手紙 2:25; テモテヘの第二の手紙 1:9"> 偽りのない神が永遠の昔に約束された永遠のいのちの望みに基くのである。</span>
<span className="v" id="v3" data-v="3" data-xref="テモテヘの第一の手紙 1:11; テトスヘの手紙 3:4–6; テモテヘの第一の手紙 1:1"> 神は、定められた時に及んで、御言を宣教によって明らかにされたが、わたしは、わたしたちの救主なる神の任命によって、この宣教をゆだねられたのである――</span>
<span className="v" id="v4" data-v="4" data-xref="テモテヘの第二の手紙 1:2; ユダの手紙 1:3; ペテロの第二の手紙 1:1"> 信仰を同じうするわたしの真実の子テトスへ。<br />父なる神とわたしたちの救主キリスト・イエスから、恵みと平安とが、あなたにあるように。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="使徒行伝 14:23; テモテヘの第一の手紙 1:3; 伝道の書 12:9"> あなたをクレテにおいてきたのは、わたしがあなたに命じておいたように、そこにし残してあることを整理してもらい、また、町々に長老を立ててもらうためにほかならない。</span>
<span className="v" id="v6" data-v="6" data-xref="テモテヘの第一の手紙 3:2–7; テモテヘの第一の手紙 3:12; テトスヘの手紙 1:6–8"> 長老は、責められる点がなく、ひとりの妻の夫であって、その子たちも不品行のうわさをたてられず、親不孝をしない信者でなくてはならない。</span>
<span className="v" id="v7" data-v="7" data-xref="エペソ人への手紙 5:18; ペテロの第二の手紙 2:10; ペテロの第一の手紙 4:10"> 監督たる者は、神に仕える者として、責められる点がなく、わがままでなく、軽々しく怒らず、酒を好まず、乱暴でなく、利をむさぼらず、</span>
<span className="v" id="v8" data-v="8" data-xref="テモテヘの第一の手紙 3:2; テトスヘの手紙 2:7; 列王紀上 5:7"> かえって、旅人をもてなし、善を愛し、慎み深く、正しく、信仰深く、自制する者であり、</span>
<span className="v" id="v9" data-v="9" data-xref="テサロニケ人への第二の手紙 2:15; テモテヘの第二の手紙 1:13; テモテヘの第一の手紙 6:3"> 教にかなった信頼すべき言葉を守る人でなければならない。それは、彼が健全な教によって人をさとし、また、反対者の誤りを指摘することができるためである。</span>
</div>
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="テモテヘの第一の手紙 1:6; ヨハネの第一の手紙 4:1; ガラテヤ人への手紙 2:4"> 実は、法に服さない者、空論に走る者、人の心を惑わす者が多くおり、とくに、割礼のある者の中に多い。</span>
<span className="v" id="v11" data-v="11" data-xref="テモテヘの第二の手紙 3:6; テモテヘの第一の手紙 6:5; ローマ人への手紙 3:19"> 彼らの口を封ずべきである。彼らは恥ずべき利のために、教えてはならないことを教えて、数々の家庭を破壊してしまっている。</span>
<span className="v" id="v12" data-v="12" data-xref="ローマ人への手紙 16:18; テモテヘの第一の手紙 4:2; 使徒行伝 17:28"> クレテ人のうちのある預言者が<br /><span className="pl pl-1">「クレテ人は、いつもうそつき、</span><br /><span className="pl pl-1">たちの悪いけもの、</span><br /><span className="pl pl-1">なまけ者の食いしんぼう」</span><br />と言っているが、</span>
<span className="v" id="v13" data-v="13" data-xref="テトスヘの手紙 2:2; テモテヘの第一の手紙 5:20; テトスヘの手紙 2:15"> この非難はあたっている。だから、彼らをきびしく責めて、その信仰を健全なものにし、</span>
<span className="v" id="v14" data-v="14" data-xref="テモテヘの第二の手紙 4:4; コロサイ人への手紙 2:22; ガラテヤ人への手紙 4:9"> ユダヤ人の作り話や、真理からそれていった人々の定めなどに、気をとられることがないようにさせなさい。</span>
<span className="v" id="v15" data-v="15" data-xref="ローマ人への手紙 14:14; ローマ人への手紙 14:20; コリント人への第一の手紙 10:23"> きよい人には、すべてのものがきよい。しかし、汚れている不信仰な人には、きよいものは一つもなく、その知性も良心も汚れてしまっている。</span>
<span className="v" id="v16" data-v="16" data-xref="ヨハネの第一の手紙 2:4; イザヤ書 29:13; エペソ人への手紙 5:6"> 彼らは神を知っていると、口では言うが、行いではそれを否定している。彼らは忌まわしい者、また不従順な者であって、いっさいの良いわざに関しては、失格者である。</span>
</div>

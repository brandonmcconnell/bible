<span className="v" id="v1" data-v="1" data-xref="テモテヘの第二の手紙 1:13; テモテヘの第一の手紙 6:3; テトスヘの手紙 2:11–14"> しかし、あなたは、健全な教にかなうことを語りなさい。</span>
<span className="v" id="v2" data-v="2" data-xref="ガラテヤ人への手紙 5:23; ペテロの第一の手紙 4:7; テサロニケ人への第一の手紙 5:8"> 老人たちには自らを制し、謹厳で、慎み深くし、また、信仰と愛と忍耐とにおいて健全であるように勧め、</span>
<span className="v" id="v3" data-v="3" data-xref="テトスヘの手紙 2:4; テモテヘの第一の手紙 3:11; ペテロの第一の手紙 3:3–5"> 年老いた女たちにも、同じように、たち居ふるまいをうやうやしくし、人をそしったり大酒の奴隷になったりせず、良いことを教える者となるように、勧めなさい。</span>
<span className="v" id="v4" data-v="4" data-xref="テモテヘの第一の手紙 5:14; テモテヘの第一の手紙 5:2; テモテヘの第一の手紙 5:11"> そうすれば、彼女たちは、若い女たちに、夫を愛し、子供を愛し、</span>
<span className="v" id="v5" data-v="5" data-xref="箴言 31:10–31; コロサイ人への手紙 3:18; テモテヘの第一の手紙 5:10"> 慎み深く、純潔で、家事に努め、善良で、自分の夫に従順であるように教えることになり、したがって、神の言がそしりを受けないようになるであろう。</span>
<span className="v" id="v6" data-v="6" data-xref="伝道の書 12:1; ペテロの第一の手紙 5:5; ヨエル書 2:28"> 若い男にも、同じく、万事につけ慎み深くあるように、勧めなさい。</span>
<span className="v" id="v7" data-v="7" data-xref="ペテロの第一の手紙 5:3; テモテヘの第一の手紙 4:12; コリント人への第二の手紙 4:2"> あなた自身を良いわざの模範として示し、人を教える場合には、清廉と謹厳とをもってし、</span>
<span className="v" id="v8" data-v="8" data-xref="ペテロの第一の手紙 2:12; ペテロの第一の手紙 2:15; ペテロの第一の手紙 3:16"> 非難のない健全な言葉を用いなさい。そうすれば、反対者も、わたしたちについてなんの悪口も言えなくなり、自ら恥じいるであろう。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="ペテロの第一の手紙 2:18–25; テモテヘの第一の手紙 6:1–2; コロサイ人への手紙 3:22–25"> 奴隷には、万事につけその主人に服従して、喜ばれるようになり、反抗をせず、</span>
<span className="v" id="v10" data-v="10" data-xref="マタイによる福音書 5:16; ペテロの第一の手紙 2:12; ヨハネの第二の手紙 1:9"> 盗みをせず、どこまでも心をこめた真実を示すようにと、勧めなさい。そうすれば、彼らは万事につけ、わたしたちの救主なる神の教を飾ることになろう。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="エペソ人への手紙 2:8; テモテヘの第一の手紙 2:4; イザヤ書 45:22"> すべての人を救う神の恵みが現れた。</span>
<span className="v" id="v12" data-v="12" data-xref="エゼキエル書 36:27; マタイによる福音書 16:24; ローマ人への手紙 6:19"> そして、わたしたちを導き、不信心とこの世の情欲とを捨てて、慎み深く、正しく、信心深くこの世で生活し、</span>
<span className="v" id="v13" data-v="13" data-xref="テモテヘの第二の手紙 4:8; コリント人への第一の手紙 1:7; マタイによる福音書 16:27"> 祝福に満ちた望み、すなわち、大いなる神、わたしたちの救主キリスト・イエスの栄光の出現を待ち望むようにと、教えている。</span>
<span className="v" id="v14" data-v="14" data-xref="ヘブル人への手紙 9:14; エペソ人への手紙 2:10; ペテロの第一の手紙 2:9"> このキリストが、わたしたちのためにご自身をささげられたのは、わたしたちをすべての不法からあがない出して、良いわざに熱心な選びの民を、ご自身のものとして聖別するためにほかならない。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="テモテヘの第二の手紙 4:2; テモテヘの第一の手紙 4:12–13; テトスヘの手紙 1:13"> あなたは、権威をもってこれらのことを語り、勧め、また責めなさい。だれにも軽んじられてはならない。</span>

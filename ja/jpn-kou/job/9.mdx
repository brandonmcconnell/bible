<span className="v" id="v1" data-v="1"> ヨブは答えて言った、</span>
<span className="v" id="v2" data-v="2" data-xref="ヨブ記 4:17; ローマ人への手紙 3:20; ヨブ記 25:4"> <span className="pl pl-1">「まことにわたしは、その事の</span><br /><span className="pl pl-1">そのとおりであることを知っている。</span><br /><span className="pl pl-1">しかし人はどうして神の前に正しくありえようか。</span></span>
<span className="v" id="v3" data-v="3" data-xref="ヨブ記 10:2; ヨブ記 40:2; イザヤ書 57:15–16"> <span className="pl pl-1">よし彼と争おうとしても、</span><br /><span className="pl pl-1">千に一つも答えることができない。</span></span>
<span className="v" id="v4" data-v="4" data-xref="ヨブ記 36:5; ローマ人への手紙 11:33; エペソ人への手紙 3:20"> <span className="pl pl-1">彼は心賢く、力強くあられる。</span><br /><span className="pl pl-1">だれが彼にむかい、おのれをかたくなにして、</span><br /><span className="pl pl-1">栄えた者があるか。</span></span>
<span className="v" id="v5" data-v="5" data-xref="マタイによる福音書 27:51; ルカによる福音書 21:11; ハバクク書 3:10"> <span className="pl pl-1">彼は、山を移されるが、山は知らない。</span><br /><span className="pl pl-1">彼は怒りをもって、これらをくつがえされる。</span></span>
<span className="v" id="v6" data-v="6" data-xref="ハガイ書 2:6; ヘブル人への手紙 12:26; 詩篇 75:3"> <span className="pl pl-1">彼が、地を震い動かしてその所を離れさせられると、</span><br /><span className="pl pl-1">その柱はゆらぐ。</span></span>
<span className="v" id="v7" data-v="7" data-xref="イザヤ書 13:10; アモス書 8:9; ルカによる福音書 21:25–26"> <span className="pl pl-1">彼が日に命じられると、日は出ない。</span><br /><span className="pl pl-1">彼はまた星を閉じこめられる。</span></span>
<span className="v" id="v8" data-v="8" data-xref="イザヤ書 44:24; イザヤ書 40:22; 詩篇 104:2–3"> <span className="pl pl-1">彼はただひとり天を張り、</span><br /><span className="pl pl-1">海の波を踏まれた。</span></span>
<span className="v" id="v9" data-v="9" data-xref="アモス書 5:8; 創世記 1:16; ヨブ記 38:31–41"> <span className="pl pl-1">彼は北斗、オリオン、</span><br /><span className="pl pl-1">プレアデスおよび南の密室を造られた。</span></span>
<span className="v" id="v10" data-v="10" data-xref="ヨブ記 5:9; 詩篇 72:18; エペソ人への手紙 3:20"> <span className="pl pl-1">彼が大いなる事をされることは測りがたく、</span><br /><span className="pl pl-1">不思議な事をされることは数知れない。</span></span>
<span className="v" id="v11" data-v="11" data-xref="ヨブ記 23:8–9; ヨブ記 35:14; 詩篇 77:19"> <span className="pl pl-1">見よ、彼がわたしのかたわらを通られても、</span><br /><span className="pl pl-1">わたしは彼を見ない。</span><br /><span className="pl pl-1">彼は進み行かれるが、わたしは彼を認めない。</span></span>
<span className="v" id="v12" data-v="12" data-xref="イザヤ書 45:9; ヨブ記 11:10; ヨブ記 23:13"> <span className="pl pl-1">見よ、彼が奪い去られるのに、</span><br /><span className="pl pl-1">だれが彼をはばむことができるか。</span><br /><span className="pl pl-1">だれが彼にむかって『あなたは何をするのか』と</span><br /><span className="pl pl-1">言うことができるか。</span></span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 89:10; ヨブ記 26:12; イザヤ書 30:7"> <span className="pl pl-1">神はその怒りをやめられない。</span><br /><span className="pl pl-1">ラハブを助ける者どもは彼のもとにかがんだ。</span></span>
<span className="v" id="v14" data-v="14" data-xref="列王紀上 8:27; ヨブ記 9:3; ヨブ記 4:19"> <span className="pl pl-1">どうしてわたしは彼に答え、</span><br /><span className="pl pl-1">言葉を選んで、彼と議論することができよう。</span></span>
<span className="v" id="v15" data-v="15" data-xref="ヨブ記 10:15; ヨブ記 8:5; ヨブ記 10:2"> <span className="pl pl-1">たといわたしは正しくても答えることができない。</span><br /><span className="pl pl-1">わたしを責められる者に</span><br /><span className="pl pl-1">あわれみを請わなければならない。</span></span>
<span className="v" id="v16" data-v="16" data-xref="ヨブ記 29:24; 出エジプト記 6:9; 詩篇 66:18–20"> <span className="pl pl-1">たといわたしが呼ばわり、</span><br /><span className="pl pl-1">彼がわたしに答えられても、</span><br /><span className="pl pl-1">わたしの声に耳を傾けられたとは信じない。</span></span>
<span className="v" id="v17" data-v="17" data-xref="ヨブ記 16:14; ヨブ記 2:3; ヨブ記 34:6"> <span className="pl pl-1">彼は大風をもってわたしを撃ち砕き、</span><br /><span className="pl pl-1">ゆえなく、わたしに多くの傷を負わせ、</span></span>
<span className="v" id="v18" data-v="18" data-xref="ヨブ記 7:19; 哀歌 3:15; 詩篇 88:15–18"> <span className="pl pl-1">わたしに息をつかせず、</span><br /><span className="pl pl-1">苦い物をもってわたしを満たされる。</span></span>
<span className="v" id="v19" data-v="19" data-xref="ヨブ記 9:32–33; ヨブ記 9:4; コリント人への第一の手紙 1:25"> <span className="pl pl-1">力の争いであるならば、彼を見よ、</span><br /><span className="pl pl-1">さばきの事であるならば、</span><br /><span className="pl pl-1">だれが彼を呼び出すことができよう。</span></span>
<span className="v" id="v20" data-v="20" data-xref="ヨブ記 15:5–6; ピリピ人への手紙 3:12–15; 詩篇 143:2"> <span className="pl pl-1">たといわたしは正しくても、</span><br /><span className="pl pl-1">わたしの口はわたしを罪ある者とする。</span><br /><span className="pl pl-1">たといわたしは罪がなくても、</span><br /><span className="pl pl-1">彼はわたしを曲った者とする。</span></span>
<span className="v" id="v21" data-v="21" data-xref="ヨブ記 1:1; 詩篇 139:23–24; 箴言 28:26"> <span className="pl pl-1">わたしは罪がない、しかしわたしは自分を知らない。</span><br /><span className="pl pl-1">わたしは自分の命をいとう。</span></span>
<span className="v" id="v22" data-v="22" data-xref="伝道の書 9:1–3; ルカによる福音書 13:2–4; ヨブ記 10:8"> <span className="pl pl-1">皆同一である。それゆえ、わたしは言う、</span><br /><span className="pl pl-1">『彼は罪のない者と、悪しき者とを</span><br /><span className="pl pl-1">共に滅ぼされるのだ』と。</span></span>
<span className="v" id="v23" data-v="23" data-xref="ヨブ記 24:12; ヨブ記 1:13–19; ヨブ記 4:7"> <span className="pl pl-1">災がにわかに人を殺すような事があると、</span><br /><span className="pl pl-1">彼は罪のない者の苦難をあざ笑われる。</span></span>
<span className="v" id="v24" data-v="24" data-xref="ヨブ記 10:3; エレミヤ書 12:1–2; 詩篇 73:3–7"> <span className="pl pl-1">世は悪人の手に渡されてある。</span><br /><span className="pl pl-1">彼はその裁判人の顔をおおわれる。</span><br /><span className="pl pl-1">もし彼でなければ、これはだれのしわざか。</span></span>
<span className="v" id="v25" data-v="25" data-xref="ヨブ記 7:6–7; ヤコブの手紙 4:14; 詩篇 90:9–10"> <span className="pl pl-1">わたしの日は飛脚よりも速く、</span><br /><span className="pl pl-1">飛び去って幸を見ない。</span></span>
<span className="v" id="v26" data-v="26" data-xref="ハバクク書 1:8; イザヤ書 18:2; ヨブ記 39:27–30"> <span className="pl pl-1">これは走ること葦舟のごとく、</span><br /><span className="pl pl-1">えじきに襲いかかる、わしのようだ。</span></span>
<span className="v" id="v27" data-v="27" data-xref="ヨブ記 7:13; エレミヤ書 8:18; ヨブ記 7:11"> <span className="pl pl-1">たといわたしは『わが嘆きを忘れ、</span><br /><span className="pl pl-1">憂い顔をかえて元気よくなろう』と言っても、</span></span>
<span className="v" id="v28" data-v="28" data-xref="詩篇 119:120; 詩篇 88:15–16; ヨブ記 21:6"> <span className="pl pl-1">わたしはわがもろもろの苦しみを恐れる。</span><br /><span className="pl pl-1">あなたがわたしを罪なき者とされないことを</span><br /><span className="pl pl-1">わたしは知っているからだ。</span></span>
<span className="v" id="v29" data-v="29" data-xref="ヨブ記 10:7; ヨブ記 21:27; ヨブ記 10:14–17"> <span className="pl pl-1">わたしは罪ある者とされている。</span><br /><span className="pl pl-1">どうして、いたずらに労する必要があるか。</span></span>
<span className="v" id="v30" data-v="30" data-xref="エレミヤ書 2:22; 詩篇 26:6; ヨハネの第一の手紙 1:8"> <span className="pl pl-1">たといわたしは雪で身を洗い、</span><br /><span className="pl pl-1">灰汁で手を清めても、</span></span>
<span className="v" id="v31" data-v="31" data-xref="イザヤ書 64:6; イザヤ書 59:6; ヨブ記 15:6"> <span className="pl pl-1">あなたはわたしを、みぞの中に投げ込まれるので、</span><br /><span className="pl pl-1">わたしの着物も、わたしをいとうようになる。</span></span>
<span className="v" id="v32" data-v="32" data-xref="ローマ人への手紙 9:20; 伝道の書 6:10; 詩篇 143:2"> <span className="pl pl-1">神はわたしのように人ではないゆえ、</span><br /><span className="pl pl-1">わたしは彼に答えることができない。</span><br /><span className="pl pl-1">われわれは共にさばきに臨むことができない。</span></span>
<span className="v" id="v33" data-v="33" data-xref="サムエル記上 2:25; ヨハネの第一の手紙 2:1–2; ヨブ記 9:19"> <span className="pl pl-1">われわれの間には、</span><br /><span className="pl pl-1">われわれふたりの上に手を置くべき仲裁者がない。</span></span>
<span className="v" id="v34" data-v="34" data-xref="詩篇 39:10; ヨブ記 13:11; ヨブ記 33:7"> <span className="pl pl-1">どうか彼がそのつえをわたしから取り離し、</span><br /><span className="pl pl-1">その怒りをもって、</span><br /><span className="pl pl-1">わたしを恐れさせられないように。</span></span>
<span className="v" id="v35" data-v="35"> <span className="pl pl-1">そうすれば、わたしは語って、</span><br /><span className="pl pl-1">彼を恐れることはない。</span><br /><span className="pl pl-1">わたしはみずからそのような者ではないからだ。</span></span>

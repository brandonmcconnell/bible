<span className="v" id="v2" data-v="2"> <span className="pl pl-1">彼らの手の力からわたしは何を得るであろうか、</span><br /><span className="pl pl-1">彼らはその気力がすでに衰えた人々だ。</span></span>
<span className="v" id="v3" data-v="3" data-xref="ヨブ記 24:5; ヘブル人への手紙 11:38; ヨブ記 24:13–16"> <span className="pl pl-1">彼らは乏しさと激しい飢えとによって、</span><br /><span className="pl pl-1">かわいた荒れ地をかむ。</span></span>

<span className="v" id="v5" data-v="5" data-xref="ダニエル書 4:25; ダニエル書 4:32–33; 詩篇 109:10"> <span className="pl pl-1">彼らは人々の中から追いだされ、</span><br /><span className="pl pl-1">盗びとを追うように、人々は彼らを追い呼ばわる。</span></span>
<span className="v" id="v6" data-v="6" data-xref="サムエル記上 22:1–2; 士師記 6:2; イザヤ書 2:19"> <span className="pl pl-1">彼らは急流の谷間に住み、</span><br /><span className="pl pl-1">土の穴または岩の穴におり、</span></span>
<span className="v" id="v7" data-v="7" data-xref="ヨブ記 6:5; ヨブ記 11:12; 創世記 16:12"> <span className="pl pl-1">灌木の中にいななき、いらくさの下に押し合う。</span></span>
<span className="v" id="v8" data-v="8" data-xref="箴言 16:22; ヨブ記 40:4; イザヤ書 32:6"> <span className="pl pl-1">彼らは愚かな者の子、また卑しい者の子であって、</span><br /><span className="pl pl-1">国から追いだされた者だ。</span></span>
<span className="v" id="v9" data-v="9" data-xref="哀歌 3:63; ヨブ記 17:6; 哀歌 3:14"> <span className="pl pl-1">それなのに、わたしは今彼らの歌となり、</span><br /><span className="pl pl-1">彼らの笑い草となった。</span></span>
<span className="v" id="v10" data-v="10" data-xref="マタイによる福音書 26:67; イザヤ書 50:6; 民数記 12:14"> <span className="pl pl-1">彼らはわたしをいとい、遠くわたしをはなれ、</span><br /><span className="pl pl-1">わたしの顔につばきすることも、ためらわない。</span></span>
<span className="v" id="v11" data-v="11" data-xref="ヨブ記 12:21; ルツ記 1:21; ヨブ記 12:18"> <span className="pl pl-1">神がわたしの綱を解いて、</span><br /><span className="pl pl-1">わたしを卑しめられたので、</span><br /><span className="pl pl-1">彼らもわたしの前に慎みを捨てた。</span></span>

<span className="v" id="v13" data-v="13" data-xref="イザヤ書 3:12; ゼカリヤ書 1:15; 詩篇 69:26"> <span className="pl pl-1">彼らはわたしの道をこわし、わたしの災を促す。</span><br /><span className="pl pl-1">これをさし止める者はない。</span></span>
<span className="v" id="v14" data-v="14" data-xref="ヨブ記 22:16; 詩篇 18:4; 詩篇 69:14–15"> <span className="pl pl-1">彼らは広い破れ口からはいるように進みきたり、</span><br /><span className="pl pl-1">破壊の中をおし寄せる。</span></span>
<span className="v" id="v15" data-v="15" data-xref="ホセア書 13:3; ヨブ記 6:4; イザヤ書 44:22"> <span className="pl pl-1">恐ろしい事はわたしに臨み、</span><br /><span className="pl pl-1">わたしの誉は風のように吹き払われ、</span><br /><span className="pl pl-1">わたしの繁栄は雲のように消えうせた。</span></span>

<span className="v" id="v18" data-v="18" data-xref="ヨブ記 7:5; ヨブ記 19:20; ヨブ記 2:7"> <span className="pl pl-1">それは暴力をもって、わたしの着物を捕え、</span><br /><span className="pl pl-1">はだ着のえりのように、わたしをしめつける。</span></span>
<span className="v" id="v19" data-v="19" data-xref="ヨブ記 9:31; ヨブ記 42:6; 創世記 18:27"> <span className="pl pl-1">神がわたしを泥の中に投げ入れられたので、</span><br /><span className="pl pl-1">わたしはちり灰のようになった。</span></span>
<span className="v" id="v20" data-v="20" data-xref="ヨブ記 19:7; 詩篇 80:4–5; 詩篇 22:2"> <span className="pl pl-1">わたしがあなたにむかって呼ばわっても、</span><br /><span className="pl pl-1">あなたは答えられない。</span><br /><span className="pl pl-1">わたしが立っていても、あなたは顧みられない。</span></span>

<span className="v" id="v1" data-v="1"> エリフはまた答えて言った、</span>
<span className="v" id="v2" data-v="2" data-xref="箴言 1:5; コリント人への第一の手紙 14:20; コリント人への第一の手紙 10:15"> <span className="pl pl-1">「あなたがた知恵ある人々よ、わたしの言葉を聞け、</span><br /><span className="pl pl-1">あなたがた知識ある人々よ、わたしに耳を傾けよ。</span></span>

<span className="v" id="v4" data-v="4" data-xref="テサロニケ人への第一の手紙 5:21; 士師記 19:30; ローマ人への手紙 12:2"> <span className="pl pl-1">われわれは正しい事を選び、</span><br /><span className="pl pl-1">われわれの間に良い事の</span><br /><span className="pl pl-1">何であるかを明らかにしよう。</span></span>
<span className="v" id="v5" data-v="5" data-xref="ヨブ記 27:2; ヨブ記 33:9; ヨブ記 16:17"> <span className="pl pl-1">ヨブは言った、『わたしは正しい、</span><br /><span className="pl pl-1">神はわたしの公義を奪われた。</span></span>

<span className="v" id="v7" data-v="7" data-xref="ヨブ記 15:16; 申命記 29:19; 箴言 1:22"> <span className="pl pl-1">だれかヨブのような人があろう。</span><br /><span className="pl pl-1">彼はあざけりを水のように飲み、</span></span>

<span className="v" id="v9" data-v="9" data-xref="ヨブ記 21:14–16; ヨブ記 35:3; マラキ書 3:14"> <span className="pl pl-1">彼は言った、『人は神と親しんでも、</span><br /><span className="pl pl-1">なんの益もない』と。</span></span>
<span className="v" id="v10" data-v="10" data-xref="ローマ人への手紙 9:14; 申命記 32:4; ヨブ記 8:3"> <span className="pl pl-1">それであなたがた理解ある人々よ、わたしに聞け、</span><br /><span className="pl pl-1">神は断じて悪を行うことなく、</span><br /><span className="pl pl-1">全能者は断じて不義を行うことはない。</span></span>
<span className="v" id="v11" data-v="11" data-xref="コリント人への第二の手紙 5:10; ローマ人への手紙 2:6; ヨハネの黙示録 22:12"> <span className="pl pl-1">神は人のわざにしたがってその身に報い、</span><br /><span className="pl pl-1">おのおのの道にしたがって、</span><br /><span className="pl pl-1">その身に振りかからせられる。</span></span>
<span className="v" id="v12" data-v="12" data-xref="ヨブ記 8:3; 詩篇 11:7; 詩篇 145:17"> <span className="pl pl-1">まことに神は悪しき事を行われない。</span><br /><span className="pl pl-1">全能者はさばきをまげられない。</span></span>

<span className="v" id="v14" data-v="14" data-xref="詩篇 104:29; ヨブ記 7:17; ヨブ記 9:4"> <span className="pl pl-1">神がもしその霊をご自分に取りもどし、</span><br /><span className="pl pl-1">その息をご自分に取りあつめられるならば、</span></span>
<span className="v" id="v15" data-v="15" data-xref="創世記 3:19; 伝道の書 12:7; イザヤ書 57:16"> <span className="pl pl-1">すべての肉は共に滅び、</span><br /><span className="pl pl-1">人はちりに帰るであろう。</span></span>
<span className="v" id="v16" data-v="16" data-xref="ヨブ記 13:2–6; ヨブ記 12:3"> <span className="pl pl-1">もし、あなたに悟りがあるならば、これを聞け、</span><br /><span className="pl pl-1">わたしの言うところに耳を傾けよ。</span></span>
<span className="v" id="v17" data-v="17" data-xref="ヨブ記 40:8; 創世記 18:25; サムエル記下 23:3"> <span className="pl pl-1">公義を憎む者は世を治めることができようか。</span><br /><span className="pl pl-1">正しく力ある者を、あなたは非難するであろうか。</span></span>
<span className="v" id="v18" data-v="18" data-xref="出エジプト記 22:28; 箴言 17:26; ローマ人への手紙 13:7"> <span className="pl pl-1">王たる者に向かって『よこしまな者』と言い、</span><br /><span className="pl pl-1">つかさたる者に向かって、『悪しき者』と</span><br /><span className="pl pl-1">言うことができるであろうか。</span></span>
<span className="v" id="v19" data-v="19" data-xref="申命記 10:17; 使徒行伝 10:34; ヤコブの手紙 2:5"> <span className="pl pl-1">神は君たる者をもかたより見られることなく、</span><br /><span className="pl pl-1">富める者を貧しき者にまさって</span><br /><span className="pl pl-1">顧みられることはない。</span><br /><span className="pl pl-1">彼らは皆み手のわざだからである。</span></span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 73:19; サムエル記上 25:37–39; サムエル記上 26:10"> <span className="pl pl-1">彼らはまたたく間に死に、</span><br /><span className="pl pl-1">民は夜の間に振われて、消えうせ、</span><br /><span className="pl pl-1">力ある者も人手によらずに除かれる。</span></span>

<span className="v" id="v22" data-v="22" data-xref="ヘブル人への手紙 4:13; アモス書 9:2–3; 箴言 10:29"> <span className="pl pl-1">悪を行う者には身を隠すべき暗やみもなく、</span><br /><span className="pl pl-1">暗黒もない。</span></span>

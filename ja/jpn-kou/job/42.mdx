<span className="v" id="v1" data-v="1"> そこでヨブは主に答えて言った、</span>
<span className="v" id="v2" data-v="2" data-xref="マタイによる福音書 19:26; マルコによる福音書 10:27; 創世記 18:14"> <span className="pl pl-1">「わたしは知ります、</span><br /><span className="pl pl-1">あなたはすべての事をなすことができ、</span><br /><span className="pl pl-1">またいかなるおぼしめしでも、</span><br /><span className="pl pl-1">あなたにできないことはないことを。</span></span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 131:1; 詩篇 139:6; ヨブ記 38:2"> <span className="pl pl-1">『無知をもって神の計りごとをおおう</span><br /><span className="pl pl-1">この者はだれか』。</span><br /><span className="pl pl-1">それゆえ、わたしはみずから悟らない事を言い、</span><br /><span className="pl pl-1">みずから知らない、測り難い事を述べました。</span></span>
<span className="v" id="v4" data-v="4" data-xref="ヨブ記 40:7; ヨブ記 38:3; 創世記 18:30–32"> <span className="pl pl-1">『聞け、わたしは語ろう、</span><br /><span className="pl pl-1">わたしはあなたに尋ねる、わたしに答えよ』。</span></span>
<span className="v" id="v5" data-v="5" data-xref="エペソ人への手紙 1:17–18; ローマ人への手紙 10:17; ヨハネによる福音書 12:45"> <span className="pl pl-1">わたしはあなたの事を耳で聞いていましたが、</span><br /><span className="pl pl-1">今はわたしの目であなたを拝見いたします。</span></span>
<span className="v" id="v6" data-v="6" data-xref="エズラ記 9:6; テモテヘの第一の手紙 1:13–16; ヤコブの手紙 4:7–10"> <span className="pl pl-1">それでわたしはみずから恨み、</span><br /><span className="pl pl-1">ちり灰の中で悔います」。</span></span>
<span className="v" id="v7" data-v="7" data-xref="ヨブ記 11:5–6; ヨブ記 32:2–3; ヨブ記 32:5"> <span className="pl pl-1">主はこれらの言葉をヨブに語られて後、テマンびとエリパズに言われた、</span><br />「わたしの怒りはあなたとあなたのふたりの友に向かって燃える。あなたがたが、わたしのしもべヨブのように正しい事をわたしについて述べなかったからである。</span>
<span className="v" id="v8" data-v="8" data-xref="民数記 23:1; ヤコブの手紙 5:16; 詩篇 103:10"> それで今、あなたがたは雄牛七頭、雄羊七頭を取って、わたしのしもべヨブの所へ行き、あなたがたのために燔祭をささげよ。わたしのしもべヨブはあなたがたのために祈るであろう。わたしは彼の祈を受けいれるによって、あなたがたの愚かを罰することをしない。あなたがたはわたしのしもべヨブのように正しい事をわたしについて述べなかったからである」。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="ヘブル人への手紙 11:8; 使徒行伝 9:6; 使徒行伝 10:33"> そこでテマンびとエリパズ、シュヒびとビルダデ、ナアマびとゾパルは行って、主が彼らに命じられたようにしたので、主はヨブの祈を受けいれられた。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="申命記 30:3; ヨブ記 8:6–7; 箴言 22:4"> ヨブがその友人たちのために祈ったとき、主はヨブの繁栄をもとにかえし、そして主はヨブのすべての財産を二倍に増された。</span>
<span className="v" id="v11" data-v="11" data-xref="ヨブ記 2:11; ヨブ記 19:13–14; 箴言 16:7"> そこで彼のすべての兄弟、すべての姉妹、および彼の旧知の者どもことごとく彼のもとに来て、彼と共にその家で飲み食いし、かつ主が彼にくだされたすべての災について彼をいたわり、慰め、おのおの銀一ケシタと金の輪一つを彼に贈った。</span>
<span className="v" id="v12" data-v="12" data-xref="ヨブ記 8:7; 伝道の書 7:8; 箴言 10:22"> 主はヨブの終りを初めよりも多く恵まれた。彼は羊一万四千頭、らくだ六千頭、牛一千くびき、雌ろば一千頭をもった。</span>
<span className="v" id="v13" data-v="13" data-xref="ヨブ記 1:2; 詩篇 107:41; 詩篇 127:3"> また彼は男の子七人、女の子三人をもった。</span>
<span className="v" id="v14" data-v="14"> 彼はその第一の娘をエミマと名づけ、第二をケジアと名づけ、第三をケレン・ハップクと名づけた。</span>
<span className="v" id="v15" data-v="15" data-xref="民数記 27:7; 詩篇 144:12; 使徒行伝 7:20"> 全国のうちでヨブの娘たちほど美しい女はなかった。父はその兄弟たちと同様に嗣業を彼らにも与えた。</span>
<span className="v" id="v16" data-v="16" data-xref="箴言 17:6; 詩篇 128:6; 創世記 50:23"> この後、ヨブは百四十年生きながらえて、その子とその孫と四代までを見た。</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 25:8; 創世記 15:15; ヨブ記 5:26"> ヨブは年老い、日満ちて死んだ。</span>

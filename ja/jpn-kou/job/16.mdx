<span className="v" id="v3" data-v="3" data-xref="ヨブ記 6:26; ヨブ記 15:2; テトスヘの手紙 2:8"> <span className="pl pl-1">むなしき言葉に、はてしがあろうか。</span><br /><span className="pl pl-1">あなたは何に激して答をするのか。</span></span>

<span className="v" id="v6" data-v="6" data-xref="ヨブ記 10:1; 詩篇 88:15–18; 詩篇 77:1–9"> <span className="pl pl-1">たといわたしは語っても、</span><br /><span className="pl pl-1">わたしの苦しみは和らげられない。</span><br /><span className="pl pl-1">たといわたしは忍んでも、</span><br /><span className="pl pl-1">どれほどそれがわたしを去るであろうか。</span></span>
<span className="v" id="v7" data-v="7" data-xref="ヨブ記 7:3; ヨブ記 1:15–19; 詩篇 6:6–7"> <span className="pl pl-1">まことに神は今わたしを疲れさせた。</span><br /><span className="pl pl-1">彼はわたしのやからをことごとく荒した。</span></span>
<span className="v" id="v8" data-v="8" data-xref="ヨブ記 10:17; ヨブ記 19:20; ルツ記 1:21"> <span className="pl pl-1">彼はわたしを、しわ寄らせた。</span><br /><span className="pl pl-1">これがわたしに対する証拠である。</span><br /><span className="pl pl-1">またわたしのやせ衰えた姿が立って、わたしを攻め、</span><br /><span className="pl pl-1">わたしの顔にむかって証明する。</span></span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 35:16; ヨブ記 13:24; 哀歌 2:16"> <span className="pl pl-1">彼は怒ってわたしをかき裂き、わたしを憎み、</span><br /><span className="pl pl-1">わたしに向かって歯をかみ鳴らした。</span><br /><span className="pl pl-1">わたしの敵は目を鋭くして、わたしを攻める。</span></span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 35:15; 詩篇 22:13; イザヤ書 50:6"> <span className="pl pl-1">人々はわたしに向かって口を張り、</span><br /><span className="pl pl-1">侮ってわたしのほおを打ち、</span><br /><span className="pl pl-1">ともに集まってわたしを攻める。</span></span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 27:12; 詩篇 7:14; 詩篇 31:8"> <span className="pl pl-1">神はわたしをよこしまな者に渡し、</span><br /><span className="pl pl-1">悪人の手に投げいれられる。</span></span>
<span className="v" id="v12" data-v="12" data-xref="ヨブ記 7:20; 哀歌 3:11–12; 哀歌 3:4"> <span className="pl pl-1">わたしは安らかであったのに、</span><br /><span className="pl pl-1">彼はわたしを切り裂き、</span><br /><span className="pl pl-1">首を捕えて、わたしを打ち砕き、</span><br /><span className="pl pl-1">わたしを立てて的とされた。</span></span>
<span className="v" id="v13" data-v="13" data-xref="ヨブ記 20:25; ヨブ記 6:4; 哀歌 2:11"> <span className="pl pl-1">その射手はわたしを囲む。</span><br /><span className="pl pl-1">彼は無慈悲にもわたしの腰を射通し、</span><br /><span className="pl pl-1">わたしの肝を地に流れ出させられる。</span></span>
<span className="v" id="v14" data-v="14" data-xref="士師記 15:8; 哀歌 3:3–5; ヨエル書 2:7"> <span className="pl pl-1">彼はわたしを打ち破って、破れに破れを加え、</span><br /><span className="pl pl-1">勇士のようにわたしに、はせかかられる。</span></span>
<span className="v" id="v15" data-v="15" data-xref="創世記 37:34; 詩篇 7:5; 詩篇 75:5"> <span className="pl pl-1">わたしは荒布を膚に縫いつけ、</span><br /><span className="pl pl-1">わたしの角をちりに伏せた。</span></span>

<span className="v" id="v17" data-v="17" data-xref="箴言 15:8; 詩篇 66:18–19; ヨブ記 27:6–7"> <span className="pl pl-1">しかし、わたしの手には暴虐がなく、</span><br /><span className="pl pl-1">わたしの祈は清い。</span></span>

<span className="v" id="v19" data-v="19" data-xref="ローマ人への手紙 1:9; テサロニケ人への第一の手紙 2:10; コリント人への第二の手紙 11:31"> <span className="pl pl-1">見よ、今でもわたしの証人は天にある。</span><br /><span className="pl pl-1">わたしのために保証してくれる者は高い所にある。</span></span>

<span className="v" id="v22" data-v="22" data-xref="ヨブ記 14:10; ヨブ記 14:14; ヨブ記 14:5"> <span className="pl pl-1">数年過ぎ去れば、</span><br /><span className="pl pl-1">わたしは帰らぬ旅路に行くであろう。</span></span>

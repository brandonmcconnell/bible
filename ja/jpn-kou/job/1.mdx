<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヤコブの手紙 5:11; エゼキエル書 14:14; エゼキエル書 14:20"> ウヅの地にヨブという名の人があった。そのひととなりは全く、かつ正しく、神を恐れ、悪に遠ざかった。</span>
<span className="v" id="v2" data-v="2" data-xref="詩篇 127:3–5; ヨブ記 42:13; 詩篇 128:3"> 彼に男の子七人と女の子三人があり、</span>
<span className="v" id="v3" data-v="3" data-xref="ヨブ記 29:25; ヨブ記 42:12; 士師記 6:3"> その家畜は羊七千頭、らくだ三千頭、牛五百くびき、雌ろば五百頭で、しもべも非常に多く、この人は東の人々のうちで最も大いなる者であった。</span>
<span className="v" id="v4" data-v="4" data-xref="ヘブル人への手紙 13:1; 詩篇 133:1"> そのむすこたちは、めいめい自分の日に、自分の家でふるまいを設け、その三人の姉妹をも招いて一緒に食い飲みするのを常とした。</span>
<span className="v" id="v5" data-v="5" data-xref="ヨブ記 42:8; 創世記 8:20; サムエル記上 16:5"> そのふるまいの日がひとめぐり終るごとに、ヨブは彼らを呼び寄せて聖別し、朝早く起きて、彼らすべての数にしたがって燔祭をささげた。これはヨブが「わたしのむすこたちは、ことによったら罪を犯し、その心に神をのろったかもしれない」と思ったからである。ヨブはいつも、このように行った。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="ヨブ記 2:1; ヨブ記 38:7; ゼカリヤ書 3:1"> ある日、神の子たちが来て、主の前に立った。サタンも来てその中にいた。</span>
<span className="v" id="v7" data-v="7" data-xref="ペテロの第一の手紙 5:8; ヨハネの黙示録 12:12–17; マタイによる福音書 12:43"> 主は言われた、「あなたはどこから来たか」。サタンは主に答えて言った、「地を行きめぐり、あちらこちら歩いてきました」。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨブ記 2:3; ヨブ記 1:1; 民数記 12:7–8"> 主はサタンに言われた、「あなたはわたしのしもべヨブのように全く、かつ正しく、神を恐れ、悪に遠ざかる者の世にないことを気づいたか」。</span>
<span className="v" id="v9" data-v="9" data-xref="マタイによる福音書 16:26; テモテヘの第一の手紙 4:8; ヨブ記 2:10"> サタンは主に答えて言った、「ヨブはいたずらに神を恐れましょうか。</span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 34:7; ゼカリヤ書 2:5; ペテロの第一の手紙 1:5"> あなたは彼とその家およびすべての所有物のまわりにくまなく、まがきを設けられたではありませんか。あなたは彼の勤労を祝福されたので、その家畜は地にふえたのです。</span>
<span className="v" id="v11" data-v="11" data-xref="ヨブ記 2:5; ヨブ記 19:21; ヨハネの黙示録 16:11"> しかし今あなたの手を伸べて、彼のすべての所有物を撃ってごらんなさい。彼は必ずあなたの顔に向かって、あなたをのろうでしょう」。</span>
<span className="v" id="v12" data-v="12" data-xref="ルカによる福音書 22:31–32; ヨハネによる福音書 3:35–36; コリント人への第二の手紙 12:7"> 主はサタンに言われた、「見よ、彼のすべての所有物をあなたの手にまかせる。ただ彼の身に手をつけてはならない」。サタンは主の前から出て行った。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="ルカによる福音書 21:34; 箴言 27:1; ヨブ記 1:4"> ある日ヨブのむすこ、娘たちが第一の兄の家で食事をし、酒を飲んでいたとき、</span>
<span className="v" id="v14" data-v="14" data-xref="サムエル記下 15:13; エレミヤ書 51:31; サムエル記上 4:17"> 使者がヨブのもとに来て言った、「牛が耕し、ろばがそのかたわらで草を食っていると、</span>
<span className="v" id="v15" data-v="15" data-xref="創世記 10:7; ヨブ記 6:19; イザヤ書 45:14"> シバびとが襲ってきて、これを奪い、つるぎをもってしもべたちを打ち殺しました。わたしはただひとりのがれて、あなたに告げるために来ました」。</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀下 1:12; 創世記 19:24; 列王紀上 18:38"> 彼がなお語っているうちに、またひとりが来て言った、「神の火が天から下って、羊およびしもべたちを焼き滅ぼしました。わたしはただひとりのがれて、あなたに告げるために来ました」。</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 11:28; ハバクク書 1:6; 創世記 11:31"> 彼がなお語っているうちに、またひとりが来て言った、「カルデヤびとが三組に分れて来て、らくだを襲ってこれを奪い、つるぎをもってしもべたちを打ち殺しました。わたしはただひとりのがれて、あなたに告げるために来ました」。</span>
<span className="v" id="v18" data-v="18" data-xref="ヨブ記 1:4; ヨブ記 1:13; ヨブ記 27:14"> 彼がなお語っているうちに、またひとりが来て言った、「あなたのむすこ、娘たちが第一の兄の家で食事をし、酒を飲んでいると、</span>
<span className="v" id="v19" data-v="19" data-xref="創世記 42:36; ルカによる福音書 13:1–5; 士師記 16:30"> 荒野の方から大風が吹いてきて、家の四すみを撃ったので、あの若い人たちの上につぶれ落ちて、皆死にました。わたしはただひとりのがれて、あなたに告げるために来ました」。</span>
</div>
<div className="bp poetry">
<span className="v" id="v20" data-v="20" data-xref="ペテロの第一の手紙 5:6; サムエル記下 12:16–20; 創世記 37:34"> このときヨブは起き上がり、上着を裂き、頭をそり、地に伏して拝し、</span>
<span className="v" id="v21" data-v="21" data-xref="伝道の書 5:15; テモテヘの第一の手紙 6:7; テサロニケ人への第一の手紙 5:18"> そして言った、<br /><span className="pl pl-1">「わたしは裸で母の胎を出た。</span><br /><span className="pl pl-1">また裸でかしこに帰ろう。</span><br /><span className="pl pl-1">主が与え、主が取られたのだ。</span><br /><span className="pl pl-1">主のみ名はほむべきかな」。</span></span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="ヤコブの手紙 1:12; ヨブ記 2:10; ペテロの第一の手紙 1:7"> すべてこの事においてヨブは罪を犯さず、また神に向かって愚かなことを言わなかった。</span>
</div>

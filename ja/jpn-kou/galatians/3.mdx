<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ガラテヤ人への手紙 5:7–8; コリント人への第二の手紙 11:3; ガラテヤ人への手紙 1:6"> ああ、物わかりのわるいガラテヤ人よ。十字架につけられたイエス・キリストが、あなたがたの目の前に描き出されたのに、いったい、だれがあなたがたを惑わしたのか。</span>
<span className="v" id="v2" data-v="2" data-xref="ローマ人への手紙 10:16–17; ガラテヤ人への手紙 3:14; 使徒行伝 15:8"> わたしは、ただこの一つの事を、あなたがたに聞いてみたい。あなたがたが御霊を受けたのは、律法を行ったからか、それとも、聞いて信じたからか。</span>
<span className="v" id="v3" data-v="3" data-xref="ガラテヤ人への手紙 5:4–8; ガラテヤ人への手紙 4:7–10; ヘブル人への手紙 7:16–19"> あなたがたは、そんなに物わかりがわるいのか。御霊で始めたのに、今になって肉で仕上げるというのか。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネの第二の手紙 1:8; コリント人への第一の手紙 15:2; ヘブル人への手紙 10:32–39"> あれほどの大きな経験をしたことは、むだであったのか。まさか、むだではあるまい。</span>
<span className="v" id="v5" data-v="5" data-xref="ガラテヤ人への手紙 3:2; 使徒行伝 14:9–10; 使徒行伝 19:11–12"> すると、あなたがたに御霊を賜い、力あるわざをあなたがたの間でなされたのは、律法を行ったからか、それとも、聞いて信じたからか。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="創世記 15:6; ローマ人への手紙 4:21–22; ヤコブの手紙 2:23"> このように、アブラハムは「神を信じた。それによって、彼は義と認められた」のである。</span>
<span className="v" id="v7" data-v="7" data-xref="ローマ人への手紙 9:7–8; ガラテヤ人への手紙 3:9; ガラテヤ人への手紙 3:26–29"> だから、信仰による者こそアブラハムの子であることを、知るべきである。</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 12:3; 創世記 22:18; 創世記 28:14"> 聖書は、神が異邦人を信仰によって義とされることを、あらかじめ知って、アブラハムに、「あなたによって、すべての国民は祝福されるであろう」との良い知らせを、予告したのである。</span>
<span className="v" id="v9" data-v="9" data-xref="ローマ人への手紙 4:16; ガラテヤ人への手紙 3:29; ローマ人への手紙 4:24"> このように、信仰による者は、信仰の人アブラハムと共に、祝福を受けるのである。</span>
<span className="v" id="v10" data-v="10" data-xref="申命記 27:26; ローマ人への手紙 8:7; ローマ人への手紙 3:19–20"> いったい、律法の行いによる者は、皆のろいの下にある。「律法の書に書いてあるいっさいのことを守らず、これを行わない者は、皆のろわれる」と書いてあるからである。</span>
<span className="v" id="v11" data-v="11" data-xref="ハバクク書 2:4; ローマ人への手紙 1:17; ヘブル人への手紙 10:38"> そこで、律法によっては、神のみまえに義とされる者はひとりもないことが、明らかである。なぜなら、「信仰による義人は生きる」からである。</span>
<span className="v" id="v12" data-v="12" data-xref="レビ記 18:5; ローマ人への手紙 10:5–6; ネヘミヤ書 9:29"> 律法は信仰に基いているものではない。かえって、「律法を行う者は律法によって生きる」のである。</span>
<span className="v" id="v13" data-v="13" data-xref="ペテロの第一の手紙 2:24; 申命記 21:23; ヘブル人への手紙 9:12"> キリストは、わたしたちのためにのろいとなって、わたしたちを律法ののろいからあがない出して下さった。聖書に、「木にかけられる者は、すべてのろわれる」と書いてある。</span>
<span className="v" id="v14" data-v="14" data-xref="ガラテヤ人への手紙 3:28–29; コリント人への第一の手紙 12:13; エゼキエル書 36:26–27"> それは、アブラハムの受けた祝福が、イエス・キリストにあって異邦人に及ぶためであり、約束された御霊を、わたしたちが信仰によって受けるためである。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="ヘブル人への手紙 9:17; ローマ人への手紙 6:19; ローマ人への手紙 3:5"> 兄弟たちよ。世のならわしを例にとって言おう。人間の遺言でさえ、いったん作成されたら、これを無効にしたり、これに付け加えたりすることは、だれにもできない。</span>
<span className="v" id="v16" data-v="16" data-xref="創世記 17:7–8; ローマ人への手紙 4:13; ルカによる福音書 1:55"> さて、約束は、アブラハムと彼の子孫とに対してなされたのである。それは、多数をさして「子孫たちとに」と言わずに、ひとりをさして「あなたの子孫とに」と言っている。これは、キリストのことである。</span>
<span className="v" id="v17" data-v="17" data-xref="ヘブル人への手紙 11:39–40; 創世記 15:13; ローマ人への手紙 4:13–14"> わたしの言う意味は、こうである。神によってあらかじめ立てられた契約が、四百三十年の後にできた律法によって破棄されて、その約束がむなしくなるようなことはない。</span>
<span className="v" id="v18" data-v="18" data-xref="ヘブル人への手紙 6:12–15; ガラテヤ人への手紙 2:21; ローマ人への手紙 4:13–16"> もし相続が、律法に基いてなされるとすれば、もはや約束に基いたものではない。ところが事実、神は約束によって、相続の恵みをアブラハムに賜わったのである。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="使徒行伝 7:53; ローマ人への手紙 7:7–13; ヘブル人への手紙 2:2"> それでは、律法はなんであるか。それは違反を促すため、あとから加えられたのであって、約束されていた子孫が来るまで存続するだけのものであり、かつ、天使たちをとおし、仲介者の手によって制定されたものにすぎない。</span>
<span className="v" id="v20" data-v="20" data-xref="テモテヘの第一の手紙 2:5; 申命記 6:4; ヨブ記 9:33"> 仲介者なるものは、一方だけに属する者ではない。しかし、神はひとりである。</span>
<span className="v" id="v21" data-v="21" data-xref="ガラテヤ人への手紙 2:21; ローマ人への手紙 9:31; ローマ人への手紙 3:20–22"> では、律法は神の約束と相いれないものか。断じてそうではない。もし人を生かす力のある律法が与えられていたとすれば、義はたしかに律法によって実現されたであろう。</span>
<span className="v" id="v22" data-v="22" data-xref="ローマ人への手紙 11:32; ヘブル人への手紙 9:15; ガラテヤ人への手紙 3:23"> しかし、約束が、信じる人々にイエス・キリストに対する信仰によって与えられるために、聖書はすべての人を罪の下に閉じ込めたのである。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="ガラテヤ人への手紙 5:18; ガラテヤ人への手紙 3:24–25; ガラテヤ人への手紙 3:19"> しかし、信仰が現れる前には、わたしたちは律法の下で監視されており、やがて啓示される信仰の時まで閉じ込められていた。</span>
<span className="v" id="v24" data-v="24" data-xref="ローマ人への手紙 10:4; 使徒行伝 13:38–39; ローマ人への手紙 7:24–25"> このようにして律法は、信仰によって義とされるために、わたしたちをキリストに連れて行く養育掛となったのである。</span>
<span className="v" id="v25" data-v="25" data-xref="ローマ人への手紙 6:14; ローマ人への手紙 7:4; ヘブル人への手紙 10:15–18"> しかし、いったん信仰が現れた以上、わたしたちは、もはや養育掛のもとにはいない。</span>
<span className="v" id="v26" data-v="26" data-xref="エペソ人への手紙 1:5; コリント人への第二の手紙 6:18; ヨハネによる福音書 1:12–13"> あなたがたはみな、キリスト・イエスにある信仰によって、神の子なのである。</span>
<span className="v" id="v27" data-v="27" data-xref="ローマ人への手紙 13:14; コリント人への第一の手紙 12:13; ローマ人への手紙 6:3–4"> キリストに合うバプテスマを受けたあなたがたは、皆キリストを着たのである。</span>
<span className="v" id="v28" data-v="28" data-xref="コリント人への第一の手紙 12:12–13; コロサイ人への手紙 3:11; ローマ人への手紙 3:29–30"> もはや、ユダヤ人もギリシヤ人もなく、奴隷も自由人もなく、男も女もない。あなたがたは皆、キリスト・イエスにあって一つだからである。</span>
<span className="v" id="v29" data-v="29" data-xref="エペソ人への手紙 3:6; ローマ人への手紙 9:7–8; ガラテヤ人への手紙 3:7"> もしキリストのものであるなら、あなたがたはアブラハムの子孫であり、約束による相続人なのである。</span>
</div>

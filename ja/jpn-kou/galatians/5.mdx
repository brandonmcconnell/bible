<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="コリント人への第二の手紙 3:17; ガラテヤ人への手紙 5:13; ペテロの第一の手紙 2:16"> 自由を得させるために、キリストはわたしたちを解放して下さったのである。だから、堅く立って、二度と奴隷のくびきにつながれてはならない。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="ガラテヤ人への手紙 5:6; 使徒行伝 15:1; ローマ人への手紙 9:31–32"> 見よ、このパウロがあなたがたに言う。もし割礼を受けるなら、キリストはあなたがたに用のないものになろう。</span>
<span className="v" id="v3" data-v="3" data-xref="ガラテヤ人への手紙 3:10; ローマ人への手紙 2:25; ヤコブの手紙 2:10–11"> 割礼を受けようとするすべての人たちに、もう一度言っておく。そういう人たちは、律法の全部を行う義務がある。</span>
<span className="v" id="v4" data-v="4" data-xref="ローマ人への手紙 9:31–32; ペテロの第二の手紙 2:20–22; ローマ人への手紙 11:6"> 律法によって義とされようとするあなたがたは、キリストから離れてしまっている。恵みから落ちている。</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 130:5; テサロニケ人への第一の手紙 1:10; 詩篇 62:5"> わたしたちは、御霊の助けにより、信仰によって義とされる望みを強くいだいている。</span>
<span className="v" id="v6" data-v="6" data-xref="ガラテヤ人への手紙 6:15; コリント人への第一の手紙 7:19; ヤコブの手紙 2:14–26"> キリスト・イエスにあっては、割礼があってもなくても、問題ではない。尊いのは、愛によって働く信仰だけである。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="コリント人への第一の手紙 9:24; ガラテヤ人への手紙 3:1; ヘブル人への手紙 12:1"> あなたがたはよく走り続けてきたのに、だれが邪魔をして、真理にそむかせたのか。</span>
<span className="v" id="v8" data-v="8" data-xref="ガラテヤ人への手紙 1:6; ローマ人への手紙 8:28"> そのような勧誘は、あなたがたを召されたかたから出たものではない。</span>
<span className="v" id="v9" data-v="9" data-xref="コリント人への第一の手紙 15:33; コリント人への第一の手紙 5:6–7; マルコによる福音書 8:15"> 少しのパン種でも、粉のかたまり全体をふくらませる。</span>
<span className="v" id="v10" data-v="10" data-xref="ガラテヤ人への手紙 5:12; コリント人への第二の手紙 2:3; ガラテヤ人への手紙 1:7"> あなたがたはいささかもわたしと違った思いをいだくことはないと、主にあって信頼している。しかし、あなたがたを動揺させている者は、それがだれであろうと、さばきを受けるであろう。</span>
<span className="v" id="v11" data-v="11" data-xref="コリント人への第一の手紙 1:23; ガラテヤ人への手紙 6:12; ガラテヤ人への手紙 4:29"> 兄弟たちよ。わたしがもし今でも割礼を宣べ伝えていたら、どうして、いまなお迫害されるはずがあろうか。そうしていたら、十字架のつまずきは、なくなっているであろう。</span>
<span className="v" id="v12" data-v="12" data-xref="ガラテヤ人への手紙 5:10; コリント人への第一の手紙 5:13; テトスヘの手紙 3:10"> あなたがたの煽動者どもは、自ら不具になるがよかろう。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="ペテロの第一の手紙 2:16; コリント人への第一の手紙 9:19; コリント人への第一の手紙 8:9"> 兄弟たちよ。あなたがたが召されたのは、実に、自由を得るためである。ただ、その自由を、肉の働く機会としないで、愛をもって互に仕えなさい。</span>
<span className="v" id="v14" data-v="14" data-xref="マタイによる福音書 7:12; レビ記 19:18; ガラテヤ人への手紙 6:2"> 律法の全体は、「自分を愛するように、あなたの隣り人を愛せよ」というこの一句に尽きるからである。</span>
<span className="v" id="v15" data-v="15" data-xref="コリント人への第一の手紙 3:3; ヤコブの手紙 3:14–3; ガラテヤ人への手紙 5:26"> 気をつけるがよい。もし互にかみ合い、食い合っているなら、あなたがたは互に滅ぼされてしまうだろう。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="ガラテヤ人への手紙 5:24–25; ローマ人への手紙 8:12–14; ガラテヤ人への手紙 6:8"> わたしは命じる、御霊によって歩きなさい。そうすれば、決して肉の欲を満たすことはない。</span>
<span className="v" id="v17" data-v="17" data-xref="ローマ人への手紙 8:13; ヨハネによる福音書 3:6; ローマ人への手紙 8:5–8"> なぜなら、肉の欲するところは御霊に反し、また御霊の欲するところは肉に反するからである。こうして、二つのものは互に相さからい、その結果、あなたがたは自分でしようと思うことを、することができないようになる。</span>
<span className="v" id="v18" data-v="18" data-xref="ローマ人への手紙 8:14; ローマ人への手紙 6:14–15; ガラテヤ人への手紙 5:25"> もしあなたがたが御霊に導かれるなら、律法の下にはいない。</span>
<span className="v" id="v19" data-v="19" data-xref="コリント人への第一の手紙 6:9–10; コロサイ人への手紙 3:5–8; マタイによる福音書 15:18–19"> 肉の働きは明白である。すなわち、不品行、汚れ、好色、</span>
<span className="v" id="v20" data-v="20" data-xref="テトスヘの手紙 3:10; コリント人への第一の手紙 11:19; ヨハネの黙示録 21:8"> 偶像礼拝、まじない、敵意、争い、そねみ、怒り、党派心、分裂、分派、</span>
<span className="v" id="v21" data-v="21" data-xref="コリント人への第一の手紙 6:9–10; ローマ人への手紙 8:13; ローマ人への手紙 13:13"> ねたみ、泥酔、宴楽、および、そのたぐいである。わたしは以前も言ったように、今も前もって言っておく。このようなことを行う者は、神の国をつぐことがない。</span>
<span className="v" id="v22" data-v="22" data-xref="コロサイ人への手紙 3:12–17; コリント人への第一の手紙 13:4–7; ヨハネによる福音書 15:5"> しかし、御霊の実は、愛、喜び、平和、寛容、慈愛、善意、忠実、</span>
<span className="v" id="v23" data-v="23" data-xref="テモテヘの第一の手紙 1:9; 使徒行伝 24:25; テトスヘの手紙 2:2"> 柔和、自制であって、これらを否定する律法はない。</span>
<span className="v" id="v24" data-v="24" data-xref="ローマ人への手紙 6:6; ローマ人への手紙 13:14; ローマ人への手紙 8:13"> キリスト・イエスに属する者は、自分の肉を、その情と欲と共に十字架につけてしまったのである。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="ガラテヤ人への手紙 5:16; ローマ人への手紙 8:4–5; ローマ人への手紙 8:2"> もしわたしたちが御霊によって生きるのなら、また御霊によって進もうではないか。</span>
<span className="v" id="v26" data-v="26" data-xref="ヤコブの手紙 3:14–16; ピリピ人への手紙 2:1–3; ヤコブの手紙 4:16"> 互にいどみ合い、互にねたみ合って、虚栄に生きてはならない。</span>
</div>

<span className="v" id="v1" data-v="1" data-xref="ローマ人への手紙 15:1; テモテヘの第二の手紙 2:25; テサロニケ人への第二の手紙 3:15"> 兄弟たちよ。もしもある人が罪過に陥っていることがわかったなら、霊の人であるあなたがたは、柔和な心をもって、その人を正しなさい。それと同時に、もしか自分自身も誘惑に陥ることがありはしないかと、反省しなさい。</span>
<span className="v" id="v2" data-v="2" data-xref="ローマ人への手紙 15:1; テサロニケ人への第一の手紙 5:14; ヨハネによる福音書 13:34"> 互に重荷を負い合いなさい。そうすれば、あなたがたはキリストの律法を全うするであろう。</span>
<span className="v" id="v3" data-v="3" data-xref="箴言 26:12; コリント人への第一の手紙 8:2; コリント人への第一の手紙 3:18"> もしある人が、事実そうでないのに、自分が何か偉い者であるように思っているとすれば、その人は自分を欺いているのである。</span>
<span className="v" id="v4" data-v="4" data-xref="コリント人への第二の手紙 13:5; 詩篇 26:2; コリント人への第一の手紙 11:28"> ひとりびとり、自分の行いを検討してみるがよい。そうすれば、自分だけには誇ることができても、ほかの人には誇れなくなるであろう。</span>
<span className="v" id="v5" data-v="5" data-xref="エレミヤ書 32:19; ローマ人への手紙 14:10–12; コリント人への第二の手紙 5:10–11"> 人はそれぞれ、自分自身の重荷を負うべきである。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="テモテヘの第一の手紙 5:17–18; ローマ人への手紙 15:27; 申命記 12:19"> 御言を教えてもらう人は、教える人と、すべて良いものを分け合いなさい。</span>
<span className="v" id="v7" data-v="7" data-xref="コリント人への第二の手紙 9:6; ホセア書 10:12; ヨブ記 4:8"> まちがってはいけない、神は侮られるようなかたではない。人は自分のまいたものを、刈り取ることになる。</span>
<span className="v" id="v8" data-v="8" data-xref="ローマ人への手紙 8:13; ヤコブの手紙 3:18; ペテロの第二の手紙 2:19"> すなわち、自分の肉にまく者は、肉から滅びを刈り取り、霊にまく者は、霊から永遠のいのちを刈り取るであろう。</span>
<span className="v" id="v9" data-v="9" data-xref="コリント人への第一の手紙 15:58; テサロニケ人への第二の手紙 3:13; イザヤ書 40:30–31"> わたしたちは、善を行うことに、うみ疲れてはならない。たゆまないでいると、時が来れば刈り取るようになる。</span>
<span className="v" id="v10" data-v="10" data-xref="ヘブル人への手紙 13:16; 箴言 3:27; テサロニケ人への第一の手紙 5:15"> だから、機会のあるごとに、だれに対しても、とくに信仰の仲間に対して、善を行おうではないか。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="コリント人への第一の手紙 16:21–23; ローマ人への手紙 16:22"> ごらんなさい。わたし自身いま筆をとって、こんなに大きい字で、あなたがたに書いていることを。</span>
<span className="v" id="v12" data-v="12" data-xref="ガラテヤ人への手紙 5:11; コロサイ人への手紙 2:23; 使徒行伝 15:1"> いったい、肉において見えを飾ろうとする者たちは、キリスト・イエスの十字架のゆえに、迫害を受けたくないばかりに、あなたがたにしいて割礼を受けさせようとする。</span>
<span className="v" id="v13" data-v="13" data-xref="ピリピ人への手紙 3:3; コリント人への第一の手紙 5:6; ローマ人への手紙 2:17–25"> 事実、割礼のあるもの自身が律法を守らず、ただ、あなたがたの肉について誇りたいために、割礼を受けさせようとしているのである。</span>
<span className="v" id="v14" data-v="14" data-xref="ローマ人への手紙 6:6; エレミヤ書 9:23–24; ガラテヤ人への手紙 2:20"> しかし、わたし自身には、わたしたちの主イエス・キリストの十字架以外に、誇とするものは、断じてあってはならない。この十字架につけられて、この世はわたしに対して死に、わたしもこの世に対して死んでしまったのである。</span>
<span className="v" id="v15" data-v="15" data-xref="コリント人への第二の手紙 5:17; コロサイ人への手紙 3:10–11; エペソ人への手紙 2:10"> 割礼のあるなしは問題ではなく、ただ、新しく造られることこそ、重要なのである。</span>
<span className="v" id="v16" data-v="16" data-xref="ガラテヤ人への手紙 3:29; ローマ人への手紙 9:6–8; ピリピ人への手紙 3:3"> この法則に従って進む人々の上に、平和とあわれみとがあるように。また、神のイスラエルの上にあるように。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="コリント人への第二の手紙 1:5; コロサイ人への手紙 1:24; コリント人への第二の手紙 11:23–25"> だれも今後は、わたしに煩いをかけないでほしい。わたしは、イエスの焼き印を身に帯びているのだから。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="ローマ人への手紙 16:20; テモテヘの第二の手紙 4:22; ピレモンヘの手紙 1:25"> 兄弟たちよ。わたしたちの主イエス・キリストの恵みが、あなたがたの霊と共にあるように、アァメン。</span>

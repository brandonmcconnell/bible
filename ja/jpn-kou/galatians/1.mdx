<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ガラテヤ人への手紙 1:11–12; コリント人への第一の手紙 1:1; ローマ人への手紙 1:1"> 人々からでもなく、人によってでもなく、イエス・キリストと彼を死人の中からよみがえらせた父なる神とによって立てられた使徒パウロ、</span>
<span className="v" id="v2" data-v="2" data-xref="コリント人への第一の手紙 16:1; ピリピ人への手紙 4:21; 使徒行伝 16:5–6"> ならびにわたしと共にいる兄弟たち一同から、ガラテヤの諸教会へ。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="ヨハネの第二の手紙 1:3; コリント人への第二の手紙 13:14; ローマ人への手紙 1:7–15"> わたしたちの父なる神と主イエス・キリストから、恵みと平安とが、あなたがたにあるように。</span>
<span className="v" id="v4" data-v="4" data-xref="マタイによる福音書 20:28; ローマ人への手紙 4:25; ガラテヤ人への手紙 2:20"> キリストは、わたしたちの父なる神の御旨に従い、わたしたちを今の悪の世から救い出そうとして、ご自身をわたしたちの罪のためにささげられたのである。</span>
<span className="v" id="v5" data-v="5" data-xref="ローマ人への手紙 11:36; ユダの手紙 1:25; 詩篇 72:19"> 栄光が世々限りなく神にあるように、アァメン。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="コリント人への第二の手紙 11:4; ガラテヤ人への手紙 5:7–8; イザヤ書 29:13"> あなたがたがこんなにも早く、あなたがたをキリストの恵みの内へお招きになったかたから離れて、違った福音に落ちていくことが、わたしには不思議でならない。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行伝 15:24; ローマ人への手紙 16:17–18; ガラテヤ人への手紙 5:10"> それは福音というべきものではなく、ただ、ある種の人々があなたがたをかき乱し、キリストの福音を曲げようとしているだけのことである。</span>
<span className="v" id="v8" data-v="8" data-xref="コリント人への第二の手紙 11:13–14; ガラテヤ人への手紙 1:9; ヨハネの黙示録 22:18–19"> しかし、たといわたしたちであろうと、天からの御使であろうと、わたしたちが宣べ伝えた福音に反することをあなたがたに宣べ伝えるなら、その人はのろわるべきである。</span>
<span className="v" id="v9" data-v="9" data-xref="ローマ人への手紙 16:17; 箴言 30:6; 申命記 4:2"> わたしたちが前に言っておいたように、今わたしは重ねて言う。もしある人が、あなたがたの受けいれた福音に反することを宣べ伝えているなら、その人はのろわるべきである。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="テサロニケ人への第一の手紙 2:4; 使徒行伝 5:29; エペソ人への手紙 6:6"> 今わたしは、人に喜ばれようとしているのか、それとも、神に喜ばれようとしているのか。あるいは、人の歓心を買おうと努めているのか。もし、今もなお人の歓心を買おうとしているとすれば、わたしはキリストの僕ではあるまい。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="ガラテヤ人への手紙 1:1; コリント人への第一の手紙 2:9–10; コリント人への第一の手紙 11:23"> 兄弟たちよ。あなたがたに、はっきり言っておく。わたしが宣べ伝えた福音は人間によるものではない。</span>
<span className="v" id="v12" data-v="12" data-xref="ガラテヤ人への手紙 1:16; コリント人への第一の手紙 2:10; ガラテヤ人への手紙 1:1"> わたしは、それを人間から受けたのでも教えられたのでもなく、ただイエス・キリストの啓示によったのである。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行伝 8:3; コリント人への第一の手紙 15:9; 使徒行伝 22:3–5"> ユダヤ教を信じていたころのわたしの行動については、あなたがたはすでによく聞いている。すなわち、わたしは激しく神の教会を迫害し、また荒しまわっていた。</span>
<span className="v" id="v14" data-v="14" data-xref="コロサイ人への手紙 2:8; 使徒行伝 26:5; ピリピ人への手紙 3:4–6"> そして、同国人の中でわたしと同年輩の多くの者にまさってユダヤ教に精進し、先祖たちの言伝えに対して、だれよりもはるかに熱心であった。</span>
<span className="v" id="v15" data-v="15" data-xref="エレミヤ書 1:5; イザヤ書 49:5; イザヤ書 49:1"> ところが、母の胎内にある時からわたしを聖別し、み恵みをもってわたしをお召しになったかたが、</span>
<span className="v" id="v16" data-v="16" data-xref="マタイによる福音書 16:17; エペソ人への手紙 3:5–10; エペソ人への手紙 6:12"> 異邦人の間に宣べ伝えさせるために、御子をわたしの内に啓示して下さった時、わたしは直ちに、血肉に相談もせず、</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行伝 9:20–25; コリント人への第二の手紙 11:32–33; ガラテヤ人への手紙 1:18"> また先輩の使徒たちに会うためにエルサレムにも上らず、アラビヤに出て行った。それから再びダマスコに帰った。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="使徒行伝 9:22–23; 使徒行伝 9:26–29; 使徒行伝 22:17–18"> その後三年たってから、わたしはケパをたずねてエルサレムに上り、彼のもとに十五日間、滞在した。</span>
<span className="v" id="v19" data-v="19" data-xref="マタイによる福音書 13:55; マルコによる福音書 6:3; マタイによる福音書 12:46"> しかし、主の兄弟ヤコブ以外には、ほかのどの使徒にも会わなかった。</span>
<span className="v" id="v20" data-v="20" data-xref="ローマ人への手紙 9:1; コリント人への第二の手紙 11:31; コリント人への第二の手紙 11:10–11"> ここに書いていることは、神のみまえで言うが、決して偽りではない。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行伝 15:41; 使徒行伝 9:30; 使徒行伝 6:9"> その後、わたしはシリヤとキリキヤとの地方に行った。</span>
<span className="v" id="v22" data-v="22" data-xref="テサロニケ人への第一の手紙 2:14; ローマ人への手紙 16:7; テサロニケ人への第二の手紙 1:1"> しかし、キリストにあるユダヤの諸教会には、顔を知られていなかった。</span>
<span className="v" id="v23" data-v="23" data-xref="コリント人への第一の手紙 15:8–10; 使徒行伝 9:13; テモテヘの第一の手紙 1:13–16"> ただ彼らは、「かつて自分たちを迫害した者が、以前には撲滅しようとしていたその信仰を、今は宣べ伝えている」と聞き、</span>
<span className="v" id="v24" data-v="24" data-xref="マタイによる福音書 9:8; 使徒行伝 11:18; ルカによる福音書 15:10"> わたしのことで、神をほめたたえた。</span>
</div>
</div>

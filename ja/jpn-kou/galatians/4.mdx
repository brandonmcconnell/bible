<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ガラテヤ人への手紙 4:23; ガラテヤ人への手紙 4:29; 創世記 24:2–3"> わたしの言う意味は、こうである。相続人が子供である間は、全財産の持ち主でありながら、僕となんの差別もなく、</span>
<span className="v" id="v2" data-v="2"> 父親の定めた時期までは、管理人や後見人の監督の下に置かれているのである。</span>
<span className="v" id="v3" data-v="3" data-xref="コロサイ人への手紙 2:20; コロサイ人への手紙 2:8; ガラテヤ人への手紙 4:9"> それと同じく、わたしたちも子供であった時には、いわゆるこの世のもろもろの霊力の下に、縛られていた者であった。</span>
<span className="v" id="v4" data-v="4" data-xref="イザヤ書 7:14; ヨハネによる福音書 1:14; ローマ人への手紙 1:3"> しかし、時の満ちるに及んで、神は御子を女から生れさせ、律法の下に生れさせて、おつかわしになった。</span>
<span className="v" id="v5" data-v="5" data-xref="ヘブル人への手紙 9:15; エペソ人への手紙 1:5; ペテロの第一の手紙 1:18–20"> それは、律法の下にある者をあがない出すため、わたしたちに子たる身分を授けるためであった。</span>
<span className="v" id="v6" data-v="6" data-xref="ローマ人への手紙 8:15–17; ローマ人への手紙 5:5; ローマ人への手紙 8:9"> このように、あなたがたは子であるのだから、神はわたしたちの心の中に、「アバ、父よ」と呼ぶ御子の霊を送って下さったのである。</span>
<span className="v" id="v7" data-v="7" data-xref="ローマ人への手紙 8:16–17; ガラテヤ人への手紙 3:29–2; ガラテヤ人への手紙 3:26"> したがって、あなたがたはもはや僕ではなく、子である。子である以上、また神による相続人である。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="コリント人への第一の手紙 8:4; エペソ人への手紙 2:11–12; テサロニケ人への第二の手紙 1:8"> 神を知らなかった当時、あなたがたは、本来神ならぬ神々の奴隷になっていた。</span>
<span className="v" id="v9" data-v="9" data-xref="コリント人への第一の手紙 8:3; ガラテヤ人への手紙 3:3; ローマ人への手紙 8:3"> しかし、今では神を知っているのに、否、むしろ神に知られているのに、どうして、あの無力で貧弱な、もろもろの霊力に逆もどりして、またもや、新たにその奴隷になろうとするのか。</span>
<span className="v" id="v10" data-v="10" data-xref="コロサイ人への手紙 2:16–17; ローマ人への手紙 14:5; レビ記 23:1–44"> あなたがたは、日や月や季節や年などを守っている。</span>
<span className="v" id="v11" data-v="11" data-xref="テサロニケ人への第一の手紙 3:5; ピリピ人への手紙 2:16; ガラテヤ人への手紙 2:2"> わたしは、あなたがたのために努力してきたことが、あるいは、むだになったのではないかと、あなたがたのことが心配でならない。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="コリント人への第二の手紙 2:5; 列王紀上 22:4; 創世記 34:15"> 兄弟たちよ。お願いする。どうか、わたしのようになってほしい。わたしも、あなたがたのようになったのだから。あなたがたは、一度もわたしに対して不都合なことをしたことはない。</span>
<span className="v" id="v13" data-v="13" data-xref="コリント人への第一の手紙 2:3; コリント人への第二の手紙 12:7–10; コリント人への第二の手紙 11:30"> あなたがたも知っているとおり、最初わたしがあなたがたに福音を伝えたのは、わたしの肉体が弱っていたためであった。</span>
<span className="v" id="v14" data-v="14" data-xref="マタイによる福音書 10:40; テサロニケ人への第一の手紙 2:13; ヘブル人への手紙 13:2"> そして、わたしの肉体にはあなたがたにとって試錬となるものがあったのに、それを卑しめもせず、またきらいもせず、かえってわたしを、神の使かキリスト・イエスかでもあるように、迎えてくれた。</span>
<span className="v" id="v15" data-v="15" data-xref="ローマ人への手紙 5:2; ヨハネの第一の手紙 3:16–18; コロサイ人への手紙 4:13"> その時のあなたがたの感激は、今どこにあるのか。はっきり言うが、あなたがたは、できることなら、自分の目をえぐり出してでも、わたしにくれたかったのだ。</span>
<span className="v" id="v16" data-v="16" data-xref="アモス書 5:10; 箴言 9:8; ヨハネによる福音書 8:45"> それだのに、真理を語ったために、わたしはあなたがたの敵になったのか。</span>
<span className="v" id="v17" data-v="17" data-xref="ローマ人への手紙 16:18; コリント人への第二の手紙 11:13–15; ペテロの第二の手紙 2:3"> 彼らがあなたがたに対して熱心なのは、善意からではない。むしろ、自分らに熱心にならせるために、あなたがたをわたしから引き離そうとしているのである。</span>
<span className="v" id="v18" data-v="18" data-xref="ピリピ人への手紙 2:12; ヨハネの黙示録 3:19; ピリピ人への手紙 1:27"> わたしがあなたがたの所にいる時だけでなく、いつも、良いことについて熱心に慕われるのは、良いことである。</span>
<span className="v" id="v19" data-v="19" data-xref="エペソ人への手紙 4:13; ローマ人への手紙 8:29; ローマ人への手紙 13:14"> ああ、わたしの幼な子たちよ。あなたがたの内にキリストの形ができるまでは、わたしは、またもや、あなたがたのために産みの苦しみをする。</span>
<span className="v" id="v20" data-v="20" data-xref="テサロニケ人への第一の手紙 2:17–18; コリント人への第一の手紙 4:19–21; テサロニケ人への第一の手紙 3:9"> できることなら、わたしは今あなたがたの所にいて、語調を変えて話してみたい。わたしは、あなたがたのことで、途方にくれている。</span>
</div>
<div className="bp poetry">
<span className="v" id="v21" data-v="21" data-xref="ガラテヤ人への手紙 3:10; ガラテヤ人への手紙 3:23–24; ローマ人への手紙 7:5–6"> 律法の下にとどまっていたいと思う人たちよ。わたしに答えなさい。あなたがたは律法の言うところを聞かないのか。</span>
<span className="v" id="v22" data-v="22" data-xref="創世記 16:15; 創世記 21:10; 創世記 21:1–2"> そのしるすところによると、アブラハムにふたりの子があったが、ひとりは女奴隷から、ひとりは自由の女から生れた。</span>
<span className="v" id="v23" data-v="23" data-xref="ヘブル人への手紙 11:11; ローマ人への手紙 9:7–8; ガラテヤ人への手紙 4:28–29"> 女奴隷の子は肉によって生れたのであり、自由の女の子は約束によって生れたのであった。</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 21:9–13; ヘブル人への手紙 10:15–18; 創世記 16:8"> さて、この物語は比喩としてみられる。すなわち、この女たちは二つの契約をさす。そのひとりはシナイ山から出て、奴隷となる者を産む。ハガルがそれである。</span>
<span className="v" id="v25" data-v="25" data-xref="ルカによる福音書 19:44; 使徒行伝 1:11; ガラテヤ人への手紙 1:17"> ハガルといえば、アラビヤではシナイ山のことで、今のエルサレムに当る。なぜなら、それは子たちと共に、奴隷となっているからである。</span>
<span className="v" id="v26" data-v="26" data-xref="ヘブル人への手紙 12:22; ピリピ人への手紙 3:20; ミカ書 4:1–2"> しかし、上なるエルサレムは、自由の女であって、わたしたちの母をさす。</span>
<span className="v" id="v27" data-v="27" data-xref="イザヤ書 54:1–5; 詩篇 113:9; ルツ記 4:14–16"> すなわち、こう書いてある、<br /><span className="pl pl-1">「喜べ、不妊の女よ。</span><br /><span className="pl pl-1">声をあげて喜べ、産みの苦しみを知らない女よ。</span><br /><span className="pl pl-1">ひとり者となっている女は多くの子を産み、</span><br /><span className="pl pl-1">その数は、夫ある女の子らよりも多い」。</span></span>
<span className="v" id="v28" data-v="28" data-xref="ガラテヤ人への手紙 4:23; ローマ人への手紙 9:8–9; ローマ人への手紙 4:13–18"> <span className="pl pl-1">兄弟たちよ。あなたがたは、イサクのように、約束の子である。</span></span>
<span className="v" id="v29" data-v="29" data-xref="創世記 21:9; ローマ人への手紙 8:13; ガラテヤ人への手紙 5:11"> <span className="pl pl-1">しかし、その当時、肉によって生れた者が、霊によって生れた者を迫害したように、今でも同様である。</span></span>
<span className="v" id="v30" data-v="30" data-xref="創世記 21:10–12; ヨハネによる福音書 8:35; ローマ人への手紙 8:15–17"> <span className="pl pl-1">しかし、聖書はなんと言っているか。「女奴隷とその子とを追い出せ。女奴隷の子は、自由の女の子と共に相続をしてはならない」とある。</span></span>
<span className="v" id="v31" data-v="31" data-xref="ヨハネによる福音書 8:36; ヨハネによる福音書 1:12–13; ガラテヤ人への手紙 5:1"> <span className="pl pl-1">だから、兄弟たちよ。わたしたちは女奴隷の子ではなく、自由の女の子なのである。</span></span>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀上 8:64; エゼキエル書 43:13–17; 列王紀上 9:25"> ソロモンはまた青銅の祭壇を造った。その長さ二十キュビト、幅二十キュビト、高さ十キュビトである。</span>
<span className="v" id="v2" data-v="2" data-xref="テトスヘの手紙 3:5; ゼカリヤ書 13:1; 出エジプト記 30:18–21"> 彼はまた海を鋳て造った。縁から縁まで十キュビトであって、周囲は円形をなし、高さ五キュビトで、その周囲は綱をもって測ると三十キュビトあった。</span>
<span className="v" id="v3" data-v="3" data-xref="エゼキエル書 1:10; エゼキエル書 10:14; コリント人への第一の手紙 9:9–10"> 海の下には三十キュビトの周囲をめぐるひさごの形があって、海の周囲を囲んでいた。そのひさごは二並びで、海を鋳る時に鋳たものである。</span>
<span className="v" id="v4" data-v="4" data-xref="マタイによる福音書 28:19–20; ヨハネの黙示録 21:14; マルコによる福音書 16:15"> その海は十二の牛の上に置かれ、その三つは北に向かい、三つは西に向かい、三つは南に向かい、三つは東に向かっていた。海はその上に置かれ、牛のうしろはみな内に向かっていた。</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀上 7:26"> 海の厚さは手の幅で、その縁は杯の縁のように、ゆりの花に似せて造られた。海には水を三千バテ入れることができた。</span>
<span className="v" id="v6" data-v="6" data-xref="列王紀上 7:38; 出エジプト記 30:18–21; 列王紀上 7:40"> 彼はまた物を洗うために洗盤十個を造って、五個を南側に、五個を北側に置いた。その中で燔祭に用いるものを洗った。しかし海は祭司がその中で身を洗うためであった。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="出エジプト記 25:31–40; 列王紀上 7:49; ヨハネによる福音書 8:12"> 彼はまた金の燭台十個をその定めに従って造り、拝殿の中の南側に五個、北側に五個を置き、</span>
<span className="v" id="v8" data-v="8" data-xref="列王紀上 7:48; マラキ書 1:12; 出エジプト記 25:23–30"> また机十個を造り、神殿の中の南側に五個、北側に五個を置き、また金の鉢百を造った。</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀上 6:36; 列王紀下 21:5; 列王紀上 7:12"> 彼はまた祭司の庭と大庭および庭の戸を造り、その戸を青銅でおおった。</span>
<span className="v" id="v10" data-v="10" data-xref="列王紀上 7:39"> 彼は海を宮の東南のすみにすえた。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="列王紀上 7:40–51; 列王紀上 7:14"> ヒラムはまたつぼと十能と鉢とを造った。こうしてヒラムはソロモン王のため、神の宮の工事を終えた。</span>
<span className="v" id="v12" data-v="12" data-xref="列王紀上 7:41; 歴代志下 3:15–17"> すなわち二本の柱と玉と、柱の頂にある二つの柱頭と、柱の頂にある柱頭の二つの玉をおおう二つの網細工と、</span>
<span className="v" id="v13" data-v="13" data-xref="列王紀上 7:20; 列王紀上 7:42; エレミヤ書 52:23"> その二つの網細工のためのざくろ四百、このざくろはおのおの網細工に二並びにつけて、柱の頂にある柱頭の二つの玉を巻いていた。</span>
<span className="v" id="v14" data-v="14" data-xref="列王紀上 7:27–43"> 彼はまた台と台の上の洗盤と、</span>
<span className="v" id="v15" data-v="15"> 一つの海とその下の十二の牛を造った。</span>
<span className="v" id="v16" data-v="16" data-xref="歴代志下 2:13; 列王紀上 7:13–14; 歴代志下 4:11"> つぼ、十能、肉さしなどすべてこれらの器物を、達人ヒラムはソロモン王のため、主の宮のために、光のある青銅で造った。</span>
<span className="v" id="v17" data-v="17" data-xref="列王紀上 7:46"> 王はヨルダンの低地で、スコテとゼレダの間の粘土の地でこれを鋳た。</span>
<span className="v" id="v18" data-v="18" data-xref="列王紀上 7:47; エレミヤ書 52:20; 歴代志上 22:14"> このようにソロモンはこれらのすべての器物を非常に多く造ったので、その青銅の重量は、量ることができなかった。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="ヨハネの黙示録 9:13; ダニエル書 5:2–3; 出エジプト記 25:23–30"> こうしてソロモンは神の宮のすべての器物を造った。すなわち金の祭壇と、供えのパンを載せる机、</span>
<span className="v" id="v20" data-v="20" data-xref="歴代志下 4:7; 出エジプト記 25:31–37; 列王紀上 6:5"> また定めのように本殿の前で火をともす純金の燭台と、そのともしび皿を造った。</span>
<span className="v" id="v21" data-v="21" data-xref="列王紀上 6:29; 出エジプト記 37:20; 列王紀上 6:35"> その花、ともしび皿、心かきは精金であった。</span>
<span className="v" id="v22" data-v="22" data-xref="列王紀下 12:13; 列王紀下 25:14; エレミヤ書 52:18"> また心切りばさみ、鉢、香の杯、心取り皿は純金であった。また宮の戸、すなわち至聖所の内部の戸および拝殿の戸のひじつぼは金であった。</span>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歴代志上 21:18; 創世記 22:14; 歴代志上 22:1"> ソロモンはエルサレムのモリアの山に主の宮を建てることを始めた。そこは父ダビデに主が現れられた所、すなわちエブスびとオルナンの打ち場にダビデが備えた所である。</span>
<span className="v" id="v2" data-v="2" data-xref="列王紀上 6:1"> ソロモンが宮を建て始めたのは、その治世の四年の二月であった。</span>
<span className="v" id="v3" data-v="3" data-xref="列王紀上 6:2–3; 歴代志上 28:11–19"> ソロモンの建てた神の宮の基の寸法は次のとおりである。すなわち昔の尺度によれば長さ六十キュビト、幅二十キュビト、</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネによる福音書 10:23; 使徒行伝 5:12; 使徒行伝 3:11"> 宮の前の廊は宮の幅に従って長さ二十キュビト高さ百二十キュビトで、その内部は純金でおおった。</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀上 6:15–17; 列王紀上 6:21–22"> またその拝殿はいとすぎの板で張り、精金をもってこれをおおい、その上にしゅろと鎖の形を施した。</span>
<span className="v" id="v6" data-v="6" data-xref="イザヤ書 54:11–12; 歴代志上 29:8; ヨハネの黙示録 21:18–21"> また宝石をはめ込んで宮を飾った。その金はパルワイムの金であった。</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀上 6:20–22; 出エジプト記 26:29; エゼキエル書 7:20"> 彼はまた金をもってその宮、すなわち、梁、敷居、壁および戸をおおい、壁の上にケルビムを彫りつけた。</span>
<span className="v" id="v8" data-v="8" data-xref="出エジプト記 26:33; 列王紀上 6:19–20; 列王紀上 6:16"> 彼はまた至聖所を造った。その長さは宮の長さにしたがって二十キュビト、幅も二十キュビトである。彼は精金六百タラントをもってこれをおおった。</span>
<span className="v" id="v9" data-v="9" data-xref="歴代志上 28:11"> その釘の金の重さは五十シケルであった。彼はまた階上の室も金でおおった。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="列王紀上 6:23–28; 出エジプト記 25:18"> 彼は至聖所に木を刻んだケルビムの像を二つ造り、これを金でおおった。</span>
<span className="v" id="v11" data-v="11"> ケルビムの翼の長さは合わせて二十キュビトあった。すなわち一つのケルブの一つの翼は五キュビトで、宮の壁に届き、ほかの翼も五キュビトで、他のケルブの翼に届き、</span>
<span className="v" id="v12" data-v="12"> 他のケルブの一つの翼も五キュビトで、宮の壁に届き、ほかの翼も五キュビトで、先のケルブの翼に接していた。</span>
<span className="v" id="v13" data-v="13" data-xref="出エジプト記 25:20"> これらのケルビムの翼は広げると二十キュビトあった。かれらは共に足で立ち、その顔は拝殿に向かっていた。</span>
<span className="v" id="v14" data-v="14" data-xref="ヘブル人への手紙 9:3; ヘブル人への手紙 10:20; マタイによる福音書 27:51"> ソロモンはまた青糸、紫糸、緋糸および亜麻糸で垂幕を造り、その上にケルビムの縫い取りを施した。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="列王紀上 7:15–24; エレミヤ書 52:20–23"> 彼は宮の前に柱を二本造った。その高さは三十五キュビト、おのおのの柱の頂に五キュビトの柱頭を造った。</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀上 7:20; 列王紀上 6:21"> 彼は首飾のような鎖を造って、柱の頂につけ、ざくろ百を造ってその鎖の上につけた。</span>
<span className="v" id="v17" data-v="17" data-xref="列王紀上 7:21"> 彼はこの柱を神殿の前に、一本を南の方に、一本を北の方に立て、南の方のをヤキンと名づけ、北の方のをボアズと名づけた。</span>
</div>

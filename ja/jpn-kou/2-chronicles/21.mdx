<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀上 22:50; 列王紀下 8:16–17; 歴代志下 12:16"> ヨシャパテは先祖たちと共に眠り、先祖たちと共にダビデの町に葬られ、その子ヨラムが代って王となった。</span>
<span className="v" id="v2" data-v="2" data-xref="歴代志下 12:6; 歴代志下 23:2; 歴代志下 24:5"> ヨシャパテの子であるその兄弟たちはアザリヤ、エヒエル、ゼカリヤ、アザリヤ、ミカエルおよびシパテヤで、皆ユダの王ヨシャパテの子たちであった。</span>
<span className="v" id="v3" data-v="3" data-xref="歴代志下 11:23; 申命記 21:15–17; 歴代志下 11:5"> その父は彼らに金、銀、宝物の賜物を多く与え、またユダの要害の町々を与えたが、ヨラムは長子なので、国はヨラムに与えた。</span>
<span className="v" id="v4" data-v="4" data-xref="士師記 9:5; 歴代志下 21:17; 創世記 4:8"> ヨラムはその父の位に登って強くなった時、その兄弟たちをことごとくつるぎにかけて殺し、またユダのつかさたち数人を殺した。</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀下 8:17–22"> ヨラムは位についた時三十二歳で、エルサレムで八年の間世を治めた。</span>
<span className="v" id="v6" data-v="6" data-xref="歴代志下 18:1; 列王紀上 12:28–30; 列王紀下 8:18"> 彼はアハブの家がしたようにイスラエルの王たちの道に歩んだ。アハブの娘を妻としたからである。このように彼は主の目の前に悪をおこなったが、</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀上 11:36; 詩篇 132:17–18; サムエル記下 7:12–17"> 主はさきにダビデと結ばれた契約のゆえに、また彼とその子孫とにながく、ともしびを与えると約束されたことによって、ダビデの家を滅ぼすことを好まれなかった。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="歴代志下 21:10; 歴代志下 20:22–23; 創世記 27:40"> ヨラムの世にエドムがそむいて、ユダの支配を脱し、みずから王を立てたので、</span>
<span className="v" id="v9" data-v="9"> ヨラムはその将校たち、およびすべての戦車を従えて渡って行き、夜のうちに立ち上がって、自分を包囲しているエドムびととその戦車の隊長たちを撃った。</span>
<span className="v" id="v10" data-v="10" data-xref="歴代志下 15:2; エレミヤ書 2:13; 歴代志下 13:10"> エドムはこのようにそむいてユダの支配を脱し、今日に至っている。そのころリブナもまたそむいてユダの支配を脱した。ヨラムが先祖たちの神、主を捨てたからである。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="レビ記 20:5; 列王紀上 11:7; レビ記 17:7"> 彼はまたユダの山地に高き所を造って、エルサレムの民に姦淫を行わせ、ユダを惑わした。</span>
<span className="v" id="v12" data-v="12" data-xref="歴代志下 14:2–5; 歴代志下 17:3–4; 列王紀下 2:1"> その時預言者エリヤから次のような一通の手紙がヨラムのもとに来た、「あなたの先祖ダビデの神、主はこう仰せられる、『あなたは父ヨシャパテの道に歩まず、またユダの王アサの道に歩まないで、</span>
<span className="v" id="v13" data-v="13" data-xref="歴代志下 21:4; 歴代志下 21:11; 列王紀上 16:30–33"> イスラエルの王たちの道に歩み、ユダとエルサレムの民に、かのアハブの家がイスラエルに姦淫を行わせたように、姦淫を行わせ、またあなたの父の家の者で、あなたにまさっているあなたの兄弟たちを殺したゆえ、</span>
<span className="v" id="v14" data-v="14" data-xref="レビ記 26:21; 出エジプト記 20:5; ホセア書 5:11"> 主は大いなる災をもってあなたの民と子供と妻たちと、すべての所有を撃たれる。</span>
<span className="v" id="v15" data-v="15" data-xref="歴代志下 21:18–19; 使徒行伝 1:18; 申命記 28:67"> あなたはまた内臓の病気にかかって大病になり、それが日に日に重くなって、ついに内臓が出るようになる』」。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="歴代志下 17:11; 歴代志下 33:11; 列王紀上 11:14"> その時、主はヨラムに対してエチオピヤびとの近くに住んでいるペリシテびととアラビヤびとの霊を振り起されたので、</span>
<span className="v" id="v17" data-v="17" data-xref="歴代志下 22:1; 歴代志下 22:6; 歴代志下 25:23"> 彼らはユダに攻め上って、これを侵し、王の家にある貨財をことごとく奪い去り、またヨラムの子供と妻たちをも奪い去ったので、末の子エホアハズのほかには、ひとりも残った者がなかった。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="歴代志下 21:15; 使徒行伝 12:23; 列王紀下 9:29"> このもろもろの事の後、主は彼を撃って内臓にいえがたい病気を起させられた。</span>
<span className="v" id="v19" data-v="19" data-xref="歴代志下 16:14; エレミヤ書 34:5"> 時がたって、二年の終りになり、その内臓が病気のために出て、重い病苦によって死んだ。民は彼の先祖のために香をたいたように、彼のために香をたかなかった。</span>
<span className="v" id="v20" data-v="20" data-xref="エレミヤ書 22:18; 歴代志下 28:27; エレミヤ書 22:28"> ヨラムはその位についた時三十二歳で、八年の間エルサレムで世を治め、ついに死んだ。ひとりも彼を惜しむ者がなかった。人々は彼をダビデの町に葬ったが、王たちの墓にではなかった。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歴代志下 17:5; 歴代志下 21:6; 歴代志下 19:2"> ヨシャパテは大いなる富と誉とをもち、アハブと縁を結んだ。</span>
<span className="v" id="v2" data-v="2" data-xref="列王紀下 9:1; 歴代志下 19:2; 列王紀上 1:9"> 彼は数年の後、サマリヤに下って、アハブをおとずれた。アハブは彼と彼に従ってきた民のために羊と牛を多くほふり、ラモテ・ギレアデに一緒に攻め上ることを彼にすすめた。</span>
<span className="v" id="v3" data-v="3" data-xref="列王紀上 22:4; 列王紀下 3:7; ヨハネの第二の手紙 1:10–11"> イスラエルの王アハブはユダの王ヨシャパテに言った、「あなたはわたしと一緒にラモテ・ギレアデに攻めて行きますか」。ヨシャパテは答えた、「わたしはあなたと一つです、わたしの民はあなたの民と一つです。わたしはあなたと一緒に戦いに臨みましょう」。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="エレミヤ書 21:2; サムエル記下 5:19; サムエル記下 2:1"> ヨシャパテはまたイスラエルの王に言った、「まず主の言葉を求めなさい」。</span>
<span className="v" id="v5" data-v="5" data-xref="テモテヘの第二の手紙 4:3; ミカ書 3:11; エレミヤ書 28:1–17"> そこでイスラエルの王は預言者四百人を集めて彼らに言った、「われわれはラモテ・ギレアデに、戦いに行くべきか、あるいは控えるべきか」。彼らは言った、「上って行きなさい。神はそれを王の手にわたされるでしょう」。</span>
<span className="v" id="v6" data-v="6" data-xref="列王紀上 22:7–9; 列王紀下 3:11–13"> ヨシャパテは言った、「ほかにわれわれが問うべき主の預言者はここにいませんか」。</span>
<span className="v" id="v7" data-v="7" data-xref="アモス書 5:10; ミカ書 2:7; 列王紀上 21:20"> イスラエルの王はヨシャパテに言った、「ほかになおひとりいます。われわれはこの人によって主に問うことができますが、彼はわたしについて良い事を預言したことがなく、常に悪いことだけを預言するので、わたしは彼を憎みます。その者はイムラの子ミカヤです」。ヨシャパテは言った、「王よ、そうは言わないでください」。</span>
<span className="v" id="v8" data-v="8" data-xref="列王紀上 22:9; イザヤ書 39:7; 歴代志下 18:25–26"> そこでイスラエルの王はひとりの役人を呼んで、「イムラの子ミカヤを急いで連れてきなさい」と言った。</span>
<span className="v" id="v9" data-v="9" data-xref="イザヤ書 14:9; ダニエル書 7:9; マタイによる福音書 19:28"> さてイスラエルの王およびユダの王ヨシャパテは王の衣を着て、サマリヤの門の入口の広場におのおのその玉座に座し、預言者たちは皆その前で預言していた。</span>
<span className="v" id="v10" data-v="10" data-xref="エレミヤ書 23:17; ゼカリヤ書 1:18–21; エレミヤ書 28:2–3"> ケナアナの子ゼデキヤは鉄の角を造って言った、「主はこう仰せられます、『あなたはこれらの角をもってスリヤびとを突いて滅ぼし尽しなさい』」。</span>
<span className="v" id="v11" data-v="11" data-xref="箴言 24:24–25; 歴代志下 18:33–34; ユダの手紙 1:16"> 預言者たちは皆そのように預言して言った、「ラモテ・ギレアデに上っていって勝利を得なさい。主はそれを王の手にわたされるでしょう」。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="ミカ書 2:6; 詩篇 10:11; ミカ書 2:11"> さてミカヤを呼びに行った使者は彼に言った、「預言者たちは一致して王に良い事を言いました。どうぞ、あなたの言葉も、彼らのひとりの言葉のようにし、良い事を言ってください」。</span>
<span className="v" id="v13" data-v="13" data-xref="民数記 22:35; 民数記 24:13; 民数記 22:18–20"> ミカヤは言った、「主は生きておられる。わが神の言われることをわたしは申します」。</span>
<span className="v" id="v14" data-v="14" data-xref="列王紀上 22:15; 哀歌 4:21; アモス書 4:4–5"> 彼が王の所へ行くと、王は彼に言った、「ミカヤよ、われわれはラモテ・ギレアデに戦いに行くべきか、あるいは控えるべきか」。彼は言った、「上って行って勝利を得なさい。彼らはあなたの手にわたされるでしょう」。</span>
<span className="v" id="v15" data-v="15" data-xref="マタイによる福音書 26:63; サムエル記上 14:24; 列王紀上 22:16"> しかし王は彼に言った、「幾たびあなたを誓わせたら、あなたは主の名をもって、ただ真実のみをわたしに告げるだろうか」。</span>
<span className="v" id="v16" data-v="16" data-xref="マタイによる福音書 9:36; エゼキエル書 34:5–6; 民数記 27:17"> 彼は言った、「わたしはイスラエルが皆牧者のない羊のように山に散っているのを見ました。すると主は『これらの者は主人をもっていない。彼らをそれぞれ安らかに、その家に帰らせよ』と言われました」。</span>
<span className="v" id="v17" data-v="17" data-xref="歴代志下 18:7; 列王紀上 22:18; 箴言 29:1"> イスラエルの王はヨシャパテに言った、「わたしはあなたに、彼はわたしについて良い事を預言せず、ただ悪い事だけを預言すると告げたではありませんか」。</span>
<span className="v" id="v18" data-v="18" data-xref="ダニエル書 7:9; イザヤ書 6:1–5; 列王紀上 22:19–23"> ミカヤは言った、「それだから主の言葉を聞きなさい。わたしは主がその玉座に座し、天の万軍がその右左に立っているのを見たが、</span>
<span className="v" id="v19" data-v="19" data-xref="エゼキエル書 14:9; 歴代志下 25:19; 箴言 11:5"> 主は、『だれがイスラエルの王アハブをいざなって、ラモテ・ギレアデに上らせ、彼を倒れさせるであろうか』と言われた。するとひとりは、こうしようと言い、ひとりは、ああしようと言った。</span>
<span className="v" id="v20" data-v="20" data-xref="ヨブ記 1:6; コリント人への第二の手紙 11:13–15; コリント人への第二の手紙 11:3"> その時一つの霊が進み出て、主の前に立ち、『わたしが彼をいざないましょう』と言ったので、主は彼に『何をもってするか』と言われた。</span>
<span className="v" id="v21" data-v="21" data-xref="ヨハネによる福音書 8:44; 列王紀上 22:21–22; ヨハネの第一の手紙 4:6"> 彼は『わたしが出て行って、偽りを言う霊となって、すべての預言者の口に宿りましょう』と言った。そこで主は『おまえは彼をいざなって、それをなし遂げるであろう。出て行って、そうしなさい』と言われた。</span>
<span className="v" id="v22" data-v="22" data-xref="イザヤ書 19:14; エゼキエル書 14:9; ヨブ記 12:16"> それゆえ、主は偽りを言う霊をこの預言者たちの口に入れ、また主はあなたについて災を告げられたのです」。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="マルコによる福音書 14:65; エレミヤ書 20:2; 歴代志下 18:10"> するとケナアナの子ゼデキヤが近寄ってミカヤのほおを打って言った、「主の霊がどの道からわたしを離れて行って、あなたに語りましたか」。</span>
<span className="v" id="v24" data-v="24" data-xref="エレミヤ書 29:21–22; イザヤ書 26:20; エレミヤ書 28:16–17"> ミカヤは言った、「あなたが奥の間にはいって身を隠す日に見るでしょう」。</span>
<span className="v" id="v25" data-v="25" data-xref="歴代志下 18:8; 歴代志下 34:8; エレミヤ書 38:6–7"> イスラエルの王は言った、「ミカヤを捕え、町のつかさアモンと王の子ヨアシの所へ引いて行って、</span>
<span className="v" id="v26" data-v="26" data-xref="歴代志下 16:10; 詩篇 80:5; ルカによる福音書 23:2"> 言いなさい、『王はこう言う、この者を獄屋に入れ、少しばかりのパンと水をもって彼を養い、わたしが勝利を得て帰ってくるのを待て』と」。</span>
<span className="v" id="v27" data-v="27" data-xref="ルカによる福音書 20:45–46; アモス書 9:10; ミカ書 1:2"> ミカヤは言った、「あなたがもし勝利を得て帰るならば、主はわたしによって語られなかったのです」。また彼は言った、「あなたがたすべての民よ、聞きなさい」。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="列王紀上 22:29–33"> こうしてイスラエルの王とユダの王ヨシャパテは、ラモテ・ギレアデに上った。</span>
<span className="v" id="v29" data-v="29" data-xref="サムエル記上 28:8; エレミヤ書 23:24; 箴言 26:25"> イスラエルの王はヨシャパテに言った、「わたしは姿を変えて戦いに行きましょう。しかしあなたは王の衣を着けなさい」。イスラエルの王は姿を変えて戦いに行った。</span>
<span className="v" id="v30" data-v="30" data-xref="創世記 19:11; 申命記 1:17; 列王紀上 20:42"> さて、スリヤの王は、その戦車隊長たちに命じて言った、「あなたがたは小さい者とも、大きい者とも戦ってはならない。ただイスラエルの王とのみ戦いなさい」。</span>
<span className="v" id="v31" data-v="31" data-xref="歴代志下 13:14; 詩篇 118:13; コリント人への第二の手紙 1:9–10"> 戦車隊長らはヨシャパテを見たとき、これはきっとイスラエルの王だと思ったので、身を巡らしてこれと戦おうとした。しかしヨシャパテが呼ばわったので、主はこれを助けられた。すなわち神は敵を彼から離れさせられた。</span>
<span className="v" id="v32" data-v="32" data-xref="列王紀上 22:33"> 戦車隊長らは彼がイスラエルの王でないのを見たので、彼を追うことをやめて引き返した。</span>
<span className="v" id="v33" data-v="33" data-xref="歴代志下 35:23; サムエル記下 15:11; 列王紀上 22:34–35"> しかし、ひとりの人が、なにごころなく弓を引いて、イスラエルの王の胸当と、くさずりの間を射たので、彼はその車の御者に言った、「わたしは傷を受けたから、車をめぐらして、わたしを軍中から運び出せ」。</span>
<span className="v" id="v34" data-v="34" data-xref="箴言 13:21; 歴代志下 18:27; 箴言 28:17"> その日戦いは激しくなった。イスラエルの王は車の中に自分をささえて立ち、夕暮までスリヤびとに向かっていたが、日の入るころになって死んだ。</span>
</div>

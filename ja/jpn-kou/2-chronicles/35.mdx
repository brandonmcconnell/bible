<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出エジプト記 12:6; 民数記 9:3; 列王紀下 23:21–23"> ヨシヤはエルサレムで主に過越の祭を行った。すなわち正月の十四日に過越の小羊をほふらせ、</span>
<span className="v" id="v2" data-v="2" data-xref="歴代志下 31:2; 歴代志上 22:19; 歴代志下 29:5–11"> 祭司にその職務をとり行わせ、彼らを励まして主の宮の務をさせ、</span>
<span className="v" id="v3" data-v="3" data-xref="歴代志上 23:26; マラキ書 2:7; 申命記 33:10"> また主の聖なる者となってすべてのイスラエルびとを教えるレビびとに言った、「あなたがたはイスラエルの王ダビデの子ソロモンの建てた宮に、聖なる箱を置きなさい。再びこれを肩にになうに及ばない。あなたがたの神、主およびその民イスラエルに仕えなさい。</span>
<span className="v" id="v4" data-v="4" data-xref="歴代志下 8:14; 歴代志上 23:1–26; ネヘミヤ書 11:10–20"> あなたがたはイスラエルの王ダビデの書、およびその子ソロモンの書に基いて氏族にしたがい、その班によって、みずから備えをなし、</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 134:1; 詩篇 135:2; エズラ記 6:18"> あなたがたの兄弟である民の人々の氏族の区分にしたがって聖所に立ち、このためにレビびとの氏族の分が欠けることのないようにしなさい。</span>
<span className="v" id="v6" data-v="6" data-xref="歴代志下 29:5; ヘブル人への手紙 9:13–14; 歴代志下 29:15"> あなたがたは過越の小羊をほふり、身を清め、あなたがたの兄弟のために備えをし、モーセが伝えた主の言葉にしたがって行いなさい」。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="列王紀上 8:63; 歴代志下 30:24; イザヤ書 32:8"> ヨシヤは、小羊および子やぎを民の人々に贈った。これは皆その所にいるすべての人のための過越の供え物であって、その数三万、また雄牛三千を贈った。それらは王の所有から出したのである。</span>
<span className="v" id="v8" data-v="8" data-xref="歴代志下 29:31–33; エレミヤ書 29:25–26; 歴代志上 24:4–5"> そのつかさたちも民と祭司とレビびとに真心から贈った。また神の宮のつかさたちヒルキヤ、ゼカリヤ、エヒエルも小羊と子やぎ二千六百頭、牛三百頭を祭司に与えて過越の供え物とした。</span>
<span className="v" id="v9" data-v="9" data-xref="エレミヤ書 7:21–28; エレミヤ書 3:10; イザヤ書 1:10–15"> またレビびとの長である人々すなわちコナニヤおよびその兄弟シマヤ、ネタンエルならびにハシャビヤ、エイエル、ヨザバデなども小羊と子やぎ五千頭、牛五百頭をレビびとに贈って過越の供え物とした。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="歴代志下 30:16; エズラ記 6:18; 歴代志下 35:4–5"> このように勤めのことが備わったので、王の命に従って祭司たちはその持ち場に立ち、レビびとはその班に従って仕え、</span>
<span className="v" id="v11" data-v="11" data-xref="歴代志下 29:34; ヘブル人への手紙 9:21–22; 歴代志下 29:22–24"> やがて過越の小羊がほふられたので、祭司はその血を受け取って注いだ。レビびとはその皮をはいだ。</span>
<span className="v" id="v12" data-v="12" data-xref="レビ記 3:9–11; レビ記 3:3; レビ記 3:5"> それから燔祭の物をとり分け、それを民の人々の氏族の区分に従って渡し、主にささげさせた。これはモーセの書にしるされたとおりである。また牛をもこのようにした。</span>
<span className="v" id="v13" data-v="13" data-xref="出エジプト記 12:8–9; サムエル記上 2:13–15; 申命記 16:7"> そして定めに従って過越の小羊を火であぶり、その他の聖なる供え物を深なべ、かま、浅なべなどに煮て、急いですべての民の人々にくばった。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行伝 6:2–4"> その後、彼らは自分のためと、祭司たちのために備えをした。アロンの子孫である祭司たちは、燔祭と脂肪をささげるのに忙しくて、夜になったからである。それでレビびとは自分たちのためと、アロンの子孫である祭司たちのために備えたのである。</span>
<span className="v" id="v15" data-v="15" data-xref="歴代志上 25:1–7; 歴代志上 26:12–19; 歴代志上 9:17–19"> アサフの子孫である歌うたう者たちは、ダビデ、アサフ、ヘマンおよび王の先見者エドトンの命に従ってその持ち場におり、門衛たちはおのおの門にいて、その職務を離れるに及ばなかった。兄弟であるレビびとが彼らのために備えたからである。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16"> このようにその日、主の勤めの事がことごとく備わったので、ヨシヤ王の命に従って過越の祭を行い、主の祭壇に燔祭をささげた。</span>
<span className="v" id="v17" data-v="17" data-xref="出エジプト記 12:15–20; 歴代志下 30:21–23; 出エジプト記 23:15"> ここに来ていたイスラエルの人々は、そのとき過越の祭を行い、また七日の間、種入れぬパンの祭を行った。</span>
<span className="v" id="v18" data-v="18" data-xref="歴代志下 30:5; 列王紀下 23:21–23; 歴代志下 30:26–27"> 預言者サムエルの日からこのかた、イスラエルでこのような過越の祭を行ったことはなかった。またイスラエルの諸王のうちには、ヨシヤが、祭司、レビびと、ならびにそこに来たユダとイスラエルのすべての人々、およびエルサレムの住民と共に行ったような過越の祭を行った者はひとりもなかった。</span>
<span className="v" id="v19" data-v="19"> この過越の祭はヨシヤの治世の第十八年に行われた。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="イザヤ書 10:9; 列王紀下 23:29–30; エレミヤ書 46:2–12"> このようにヨシヤが宮を整えた後、エジプトの王ネコはユフラテ川のほとりにあるカルケミシで戦うために上ってきたので、ヨシヤはこれを防ごうと出て行った。</span>
<span className="v" id="v21" data-v="21" data-xref="歴代志下 25:19; 列王紀下 18:25; イザヤ書 36:10"> しかしネコは彼に使者をつかわして言った、「ユダの王よ、われわれはお互に何のあずかるところがありますか。わたしはきょう、あなたを攻めようとして来たのではありません。わたしの敵の家を攻めようとして来たのです。神がわたしに命じて急がせています。わたしと共におられる神に逆らうことをやめなさい。そうしないと、神はあなたを滅ぼされるでしょう」。</span>
<span className="v" id="v22" data-v="22" data-xref="士師記 5:19; 歴代志下 18:29; 列王紀上 22:30"> しかしヨシヤは引き返すことを好まず、かえって彼と戦うために、姿を変え、神の口から出たネコの言葉を聞きいれず、行ってメギドの谷で戦ったが、</span>
<span className="v" id="v23" data-v="23" data-xref="列王紀上 22:34; 列王紀下 9:24; 創世記 49:23"> 射手の者どもがヨシヤを射あてたので、王はその家来たちに、「わたしを助け出せ。わたしはひどく傷ついた」と言った。</span>
<span className="v" id="v24" data-v="24" data-xref="ゼカリヤ書 12:11; 列王紀下 23:30; 詩篇 36:6"> そこで家来たちは彼を車から助け出し、王のもっていた第二の車に乗せてエルサレムにつれて行ったが、ついに死んだので、その先祖の墓にこれを葬った。そしてユダとエルサレムは皆ヨシヤのために悲しんだ。</span>
<span className="v" id="v25" data-v="25" data-xref="哀歌 4:20; エレミヤ書 22:10; ヨブ記 3:8"> 時にエレミヤはヨシヤのために哀歌を作った。歌うたう男、歌うたう女は今日に至るまで、その哀歌のうちにヨシヤのことを述べ、イスラエルのうちにこれを例とした。これは哀歌のうちにしるされている。</span>
<span className="v" id="v26" data-v="26" data-xref="歴代志下 31:20; 歴代志下 32:32"> ヨシヤのその他の行為、主の律法にしるされた所に従って行った徳行、</span>
<span className="v" id="v27" data-v="27" data-xref="歴代志下 26:22; 歴代志下 25:26; 列王紀下 10:34"> およびその始終の行いなどは、イスラエルとユダの列王の書にしるされている。</span>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀下 21:1–18; 歴代志上 3:13; イザヤ書 3:12"> マナセは十二歳で王となり、五十五年の間エルサレムで世を治めた。</span>
<span className="v" id="v2" data-v="2" data-xref="歴代志下 28:3; 申命記 18:9; 列王紀下 17:11"> 彼は主がイスラエルの人々の前から追い払われた国々の民の憎むべき行いに見ならって、主の目の前に悪を行った。</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 16:21; 申命記 17:3; 歴代志下 31:1"> すなわち、その父ヒゼキヤがこわした高き所を再び築き、またもろもろのバアルのために祭壇を設け、アシラ像を造り、天の万象を拝んで、これに仕え、</span>
<span className="v" id="v4" data-v="4" data-xref="歴代志下 7:16; 列王紀上 8:29; 申命記 12:11"> また主が「わが名は永遠にエルサレムにある」と言われた主の宮のうちに数個の祭壇を築き、</span>
<span className="v" id="v5" data-v="5" data-xref="歴代志下 4:9; エレミヤ書 32:34–35; エゼキエル書 8:7–18"> 主の宮の二つの庭に天の万象のために祭壇を築いた。</span>
<span className="v" id="v6" data-v="6" data-xref="レビ記 18:21; レビ記 20:6; 歴代志下 28:3"> 彼はまたベンヒンノムの谷でその子供を火に焼いて供え物とし、占いをし、魔法をつかい、まじないを行い、口寄せと、占い師を任用するなど、主の前に多くの悪を行って、その怒りをひき起した。</span>
<span className="v" id="v7" data-v="7" data-xref="歴代志下 33:4; 歴代志下 7:16; 列王紀上 11:13"> 彼はまた刻んだ偶像を造って神の宮に安置した。神はこの宮についてダビデとその子ソロモンに言われたことがある、「わたしはこの宮と、わたしがイスラエルのすべての部族のうちから選んだエルサレムとに、わたしの名を永遠に置く。</span>
<span className="v" id="v8" data-v="8" data-xref="サムエル記下 7:10; 申命記 5:31–1; レビ記 8:36"> 彼らがもし、わたしがすべて命じた事、すなわち、モーセが伝えたすべての律法と定めとおきてとを慎んで行うならば、わたしがあなたがたの先祖のために定めた地から、重ねてイスラエルの足を移すことをしない」と。</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀下 24:3–4; 箴言 29:12; 歴代志下 33:2"> マナセはこのようにユダとエルサレムの住民を迷わせ、主がイスラエルの人々の前に滅ぼされた国々の民にもまさって悪を行わせた。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="歴代志下 36:15–16; エレミヤ書 44:4–5; ゼカリヤ書 1:4"> 主はマナセおよびその民に告げられたが、彼らは心に留めなかった。</span>
<span className="v" id="v11" data-v="11" data-xref="申命記 28:36; 歴代志下 36:6; ネヘミヤ書 9:32"> それゆえ、主はアッスリヤの王の軍勢の諸将をこれに攻めこさせられたので、彼らはマナセをかぎで捕え、青銅のかせにつないで、バビロンに引いて行った。</span>
<span className="v" id="v12" data-v="12" data-xref="出エジプト記 10:3; 詩篇 50:15; 歴代志下 32:26"> 彼は悩みにあうに及んで、その神、主に願い求め、その先祖の神の前に大いに身を低くして、</span>
<span className="v" id="v13" data-v="13" data-xref="歴代志上 5:20; ダニエル書 4:25; マタイによる福音書 7:7–8"> 神に祈ったので、神はその祈を受けいれ、その願いを聞き、彼をエルサレムに連れ帰って、再び国に臨ませられた。これによってマナセは主こそ、まことに神にいますことを知った。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="歴代志下 27:3; 列王紀上 1:33; ネヘミヤ書 3:3"> この後、彼はダビデの町の外の石がきをギホンの西の方の谷のうちに築き、魚の門の入口にまで及ぼし、またオペルに石がきをめぐらして、非常に高くこれを築き上げ、ユダのすべての堅固な町に軍長を置き、</span>
<span className="v" id="v15" data-v="15" data-xref="歴代志下 33:3–7; ホセア書 14:1–3; 列王紀下 21:7"> また主の宮から、異邦の神々および偶像を取り除き、主の宮の山とエルサレムに自分で築いたすべての祭壇を取り除いて、町の外に投げ捨て、</span>
<span className="v" id="v16" data-v="16" data-xref="歴代志下 14:4; 列王紀上 18:30; 歴代志下 33:9"> 主の祭壇を築き直して、酬恩祭および感謝の犠牲を、その上にささげ、ユダに命じてイスラエルの神、主に仕えさせた。</span>
<span className="v" id="v17" data-v="17" data-xref="歴代志下 32:12; 列王紀上 22:43; 列王紀下 15:4"> しかし民は、なお高き所で犠牲をささげた。ただしその神、主にのみささげた。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="歴代志下 33:19; 歴代志下 33:12–13; アモス書 7:12"> マナセのそのほかの行為、その神にささげた祈、およびイスラエルの神、主の名をもって彼に告げた先見者たちの言葉は、イスラエルの列王の記録のうちにしるされている。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行伝 9:11; ヨハネの第一の手紙 1:9; ダニエル書 5:22"> またその祈と、祈の聞かれた事、そのもろもろの罪と、とが、その身を低くする前に高き所を築いて、アシラ像および刻んだ像を立てた場所などは、先見者の記録のうちにしるされている。</span>
<span className="v" id="v20" data-v="20" data-xref="マタイによる福音書 1:10; 歴代志下 32:33; 列王紀下 21:18–25"> マナセはその先祖たちと共に眠ったので、その家に葬られた。その子アモンが彼に代って王となった。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="ヤコブの手紙 4:13–15; ルカによる福音書 12:19–20; 歴代志下 33:1"> アモンは王となった時二十二歳で、二年の間エルサレムで世を治めた。</span>
<span className="v" id="v22" data-v="22" data-xref="列王紀下 21:20; エゼキエル書 20:18; 列王紀下 21:1–11"> 彼はその父マナセのしたように主の前に悪を行った。すなわちアモンはその父マナセが造ったもろもろの刻んだ像に犠牲をささげて、これに仕え、</span>
<span className="v" id="v23" data-v="23" data-xref="歴代志下 33:12; 歴代志下 33:19; エレミヤ書 7:26"> その父マナセが身を低くしたように主の前に身を低くしなかった。かえってこのアモンは、いよいよそのとがを増した。</span>
<span className="v" id="v24" data-v="24" data-xref="ローマ人への手紙 11:22; 歴代志下 25:27–28; 歴代志下 24:25–26"> その家来たちは党を結んで彼にそむき、彼をその家で殺した。</span>
<span className="v" id="v25" data-v="25" data-xref="民数記 35:31; 歴代志下 34:1; 歴代志下 36:1"> しかし国の民は、党を結んでアモン王にそむいた者どもをことごとく撃ち殺した。そして国の民はその子ヨシヤを王となして、そのあとを継がせた。</span>
</div>

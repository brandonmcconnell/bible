<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀上 9:10–28"> ソロモンは二十年を経て、主の家と自分の家とを建て終った。</span>
<span className="v" id="v2" data-v="2" data-xref="列王紀上 9:11–18"> またソロモンはヒラムから送られた町々を建て直して、そこにイスラエルの人々を住ませた。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="民数記 13:21; 歴代志上 18:3; サムエル記下 8:3"> ソロモンはまたハマテ・ゾバを攻めて、これを取った。</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀上 9:17–19"> 彼はまた荒野にタデモルを建て、もろもろの倉の町をハマテに建てた。</span>
<span className="v" id="v5" data-v="5" data-xref="歴代志上 7:24; ヨシュア記 16:5; 歴代志下 14:7"> また城壁、門、貫の木のある堅固な町、上ベテホロンと下ベテホロンを建てた。</span>
<span className="v" id="v6" data-v="6" data-xref="列王紀上 7:2; 歴代志下 8:4; 歴代志下 1:14"> ソロモンはまたバアラテと自分のもっていたすべての倉の町と、すべての戦車の町と、騎兵の町、ならびにエルサレム、レバノンおよび自分の治める全地方に建てようと望んだものを、ことごとく建てた。</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 15:18–21; 申命記 7:1; 列王紀上 9:20–22"> すべてイスラエルの子孫でないヘテびと、アモリびと、ペリジびと、ヒビびと、エブスびとの残った民、</span>
<span className="v" id="v8" data-v="8" data-xref="ヨシュア記 16:10; 列王紀上 9:21; 列王紀上 4:6"> その地にあって彼らのあとに残ったその子孫、すなわちイスラエルの子孫が滅ぼし尽さなかった民に、ソロモンは強制徴募をおこなって今日に及んでいる。</span>
<span className="v" id="v9" data-v="9" data-xref="サムエル記上 8:11–12; 出エジプト記 19:5–6; ガラテヤ人への手紙 4:31"> しかし、イスラエルの人々をソロモンはその工事のためには、ひとりも奴隷としなかった。彼らは兵士となり、将校となり、戦車と、騎兵の長となった。</span>
<span className="v" id="v10" data-v="10" data-xref="列王紀上 9:23; 列王紀上 5:16; 歴代志下 2:18"> これらはソロモン王のおもな官吏で、二百五十人あり、民を治めた。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="列王紀上 3:1; 列王紀上 7:8; 列王紀上 9:24"> ソロモンはパロの娘をダビデの町から連れ上って、彼女のために建てた家に入れて言った、「主の箱を迎えた所は神聖であるから、わたしの妻はイスラエルの王ダビデの家に住んではならない」。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="歴代志下 4:1; 歴代志下 15:8; ヨハネによる福音書 10:23"> ソロモンは廊の前に築いておいた主の祭壇の上で主に燔祭をささげた。</span>
<span className="v" id="v13" data-v="13" data-xref="申命記 16:16; 出エジプト記 29:38–42; エゼキエル書 46:3–15"> すなわちモーセの命令に従って、毎日定めのようにささげ、安息日、新月および年に三度の祭、すなわち種入れぬパンの祭、七週の祭、仮庵の祭にこれをささげた。</span>
<span className="v" id="v14" data-v="14" data-xref="歴代志上 9:17; エズラ記 6:18; ネヘミヤ書 12:36"> ソロモンは、その父ダビデのおきてに従って、祭司の組を定めてその職に任じ、またレビびとをその勤めに任じて、毎日定めのように祭司の前でさんびと奉仕をさせ、また門を守る者に、その組にしたがって、もろもろの門を守らせた。これは神の人ダビデがこのように命じたからである。</span>
<span className="v" id="v15" data-v="15" data-xref="歴代志下 30:12; 歴代志上 9:29; 列王紀上 7:51"> 祭司とレビびとはすべての事につき、また倉の事について、王の命令にそむかなかった。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="列王紀上 5:18; 列王紀上 6:7"> このようにソロモンは、主の宮の基をすえた日からこれをなし終えたときまで、その工事の準備をことごとくなしたので、主の宮は完成した。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="列王紀下 14:22; 申命記 2:8; 民数記 33:35"> それからソロモンはエドムの地の海べにあるエジオン・ゲベルおよびエロテへ行った。</span>
<span className="v" id="v18" data-v="18" data-xref="歴代志下 9:10; 歴代志下 9:13; 伝道の書 2:8"> 時にヒラムはそのしもべどもの手によって船団を彼に送り、また海の事になれたしもべどもをつかわしたので、彼らはソロモンのしもべらと共にオフルへ行き、そこから金四百五十タラントを取って、これをソロモン王のもとに携えてきた。</span>
</div>

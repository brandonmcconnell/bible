<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀下 18:4; 歴代志下 32:12; 創世記 19:15"> この事がすべて終った時、そこにいたイスラエルびとは皆、ユダの町々に出て行って、石柱を砕き、アシラ像を切り倒し、ユダとベニヤミンの全地、およびエフライムとマナセにある高き所と祭壇とを取りこわし、ついにこれをことごとく破壊した。そしてイスラエルの人々はおのおのその町々、その所領に帰った。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="歴代志上 24:1; 歴代志上 16:4–6; 歴代志下 29:24–26"> ヒゼキヤは祭司およびレビびとの班を定め、班ごとにおのおのその勤めに従って、祭司とレビびとに燔祭と酬恩祭をささげさせ、主の営の門で勤めをし、感謝をし、さんびをさせた。</span>
<span className="v" id="v3" data-v="3" data-xref="エゼキエル書 45:17; 歴代志下 35:7; コロサイ人への手紙 2:16–17"> また燔祭のために自分の財産のうちから王の分を出した。すなわち朝夕の燔祭および安息日、新月、定めの祭などの燔祭のために出して、主の律法にしるされているとおりにした。</span>
<span className="v" id="v4" data-v="4" data-xref="マラキ書 2:7; 民数記 18:8–21; ネヘミヤ書 13:10–13"> またエルサレムに住む民に、祭司とレビびとにその分を与えることを命じた。これは彼らをして主の律法に身をゆだねさせるためである。</span>
<span className="v" id="v5" data-v="5" data-xref="ネヘミヤ書 13:12; 歴代志下 24:10–11; ネヘミヤ書 10:35–39"> その命令が伝わるやいなや、イスラエルの人々は穀物、酒、油、蜜ならびに畑のもろもろの産物の初物を多くささげ、またすべての物の十分の一をおびただしく携えて来た。</span>
<span className="v" id="v6" data-v="6" data-xref="レビ記 27:30; 歴代志下 11:16–17; 申命記 14:28"> ユダの町々に住んでいたイスラエルとユダの人々もまた牛、羊の十分の一ならびにその神、主にささげられた奉納物を携えて来て、これを積み重ねた。</span>
<span className="v" id="v7" data-v="7" data-xref="レビ記 23:16–24"> 三月にこれを積み重ねることを始め、七月にこれを終った。</span>
<span className="v" id="v8" data-v="8" data-xref="エペソ人への手紙 1:3; 創世記 14:19–20; ピリピ人への手紙 4:10"> ヒゼキヤおよびつかさたちは来て、その積み重ねた物を見、主とその民イスラエルを祝福した。</span>
<span className="v" id="v9" data-v="9"> そしてヒゼキヤがその積み重ねた物について祭司およびレビびとに問い尋ねた時、</span>
<span className="v" id="v10" data-v="10" data-xref="マラキ書 3:10; 歴代志上 6:8; コリント人への第二の手紙 9:8–11"> ザドクの家から出た祭司の長アザリヤは彼に答えて言った、「民が主の宮に供え物を携えて来ることを始めてからこのかた、われわれは飽きるほど食べたが、たくさん残りました。主がその民を恵まれたからです。それでわれわれは、このように多くの残った物をもっているのです」。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="ネヘミヤ書 10:38–39; ネヘミヤ書 13:5; ネヘミヤ書 13:12–13"> そこでヒゼキヤは主の宮のうちに室を設けることを命じたので、彼らはこれを設け、</span>
<span className="v" id="v12" data-v="12" data-xref="歴代志下 35:9; 列王紀下 12:15; 歴代志上 26:20–26"> その供え物の十分の一および奉納物を忠実に携え入れた。これをつかさどる者のかしらはレビびとコナニヤで、その兄弟シメイは彼に次ぐ者となり、</span>
<span className="v" id="v13" data-v="13" data-xref="歴代志上 24:5; 歴代志下 31:10–11; 歴代志上 9:11"> エヒエル、アザジヤ、ナハテ、アサヘル、エレモテ、ヨザバデ、エリエル、イスマキヤ、マハテ、ベナヤらは、ヒゼキヤ王および神の宮のつかさアザリヤの任命によって、コナニヤおよびその兄弟シメイを助けて、その監督者となった。</span>
<span className="v" id="v14" data-v="14" data-xref="レビ記 23:38; 歴代志上 26:12; レビ記 27:28"> 東の門を守る者レビびとイムナの子コレは、神にささげる自発のささげ物をつかさどり、主の供え物および最も聖なる物を分配した。</span>
<span className="v" id="v15" data-v="15" data-xref="ヨシュア記 21:9–19; 歴代志上 9:22; 歴代志下 29:12"> 彼を助ける者はエデン、ミニヤミン、エシュア、シマヤ、アマリヤおよびシカニヤで、皆祭司の町々でその兄弟たちに、班によって、老若ひとしく忠実に分配した。</span>
<span className="v" id="v16" data-v="16" data-xref="エズラ記 3:4; レビ記 21:22–23; 歴代志上 23:3"> ただしすべて登録された三歳以上の男子で主の宮に入り、その班に従って日々の職分をつくし、その受持の勤めをなす者は除かれた。</span>
<span className="v" id="v17" data-v="17" data-xref="歴代志上 23:24; 歴代志上 23:27; 民数記 3:15"> 祭司の登録はその氏族によってなされ、二十歳以上のレビびとの登録はその班により、その受持にしたがってなされた。</span>
<span className="v" id="v18" data-v="18" data-xref="ローマ人への手紙 15:16; イザヤ書 5:16; 歴代志下 31:15"> また祭司はその幼な子、その妻、そのむすこ、その娘、全会衆と共に登録した。彼らは忠実に身を聖なる事にささげたからである。</span>
<span className="v" id="v19" data-v="19" data-xref="歴代志下 31:12–15; レビ記 25:34; 民数記 35:2–5"> また町々の放牧地におるアロンの子孫である祭司たちのためには、町ごとに人を名ざし選んで、祭司のうちのすべての男およびレビびとのうちの登録されたすべての者に、その分を与えさせた。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="列王紀下 20:3; 列王紀下 22:2; 使徒行伝 24:16"> ヒゼキヤはユダ全国にこのようにし、良い事、正しい事、忠実な事をその神、主の前に行った。</span>
<span className="v" id="v21" data-v="21" data-xref="マタイによる福音書 6:33; エレミヤ書 29:13; ヨシュア記 1:7–8"> 彼がその神を求めるために神の宮の務につき、律法につき、戒めについて始めたわざは、ことごとく心をつくして行い、これをなし遂げた。</span>
</div>

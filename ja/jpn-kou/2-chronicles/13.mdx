<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歴代志下 12:16; 列王紀上 15:1–8"> ヤラベアム王の第十八年にアビヤがユダの王となった。</span>
<span className="v" id="v2" data-v="2" data-xref="歴代志下 11:20; 列王紀上 15:6–7; 士師記 19:16"> 彼は三年の間エルサレムで世を治めた。彼の母はギベアのウリエルの娘で、名をミカヤといった。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="歴代志下 26:12–13; 歴代志上 21:5; サムエル記上 17:1–3"> ここにアビヤとヤラベアムとの間に戦争が起り、アビヤは四十万の精兵から成る勇敢な軍勢をもって戦いにいで、ヤラベアムも大勇士から成る八十万の精兵をもって、これに向かって戦いの備えをした。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨシュア記 18:22; 歴代志下 15:2; 創世記 10:18"> 時にアビヤはエフライムの山地にあるゼマライム山の上に立って言った、「ヤラベアムおよびイスラエルの人々よ皆聞け。</span>
<span className="v" id="v5" data-v="5" data-xref="民数記 18:19; レビ記 2:13; マルコによる福音書 9:49–50"> あなたがたはイスラエルの神、主が塩の契約をもってイスラエルの国をながくダビデとその子孫に賜わったことを知らないのか。</span>
<span className="v" id="v6" data-v="6" data-xref="列王紀上 11:26; 列王紀上 12:20; 歴代志下 10:19"> ところがダビデの子ソロモンの家来であるネバテの子ヤラベアムが起って、その主君にそむき、</span>
<span className="v" id="v7" data-v="7" data-xref="士師記 9:4; 歴代志下 12:13; 使徒行伝 17:5"> また卑しい無頼のともがらが集まって彼にくみし、ソロモンの子レハベアムに敵したが、レハベアムは若く、かつ意志が弱くてこれに当ることができなかった。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="列王紀上 12:28; 歴代志下 11:15; ルカによる福音書 19:14"> 今また、あなたがたは大軍をたのみ、またヤラベアムが造って、あなたがたの神とした金の子牛をたのんで、ダビデの子孫の手にある主の国に敵対しようとしている。</span>
<span className="v" id="v9" data-v="9" data-xref="歴代志下 11:14–15; エレミヤ書 2:11; 出エジプト記 29:35"> またあなたがたはアロンの子孫である主の祭司とレビびととを追いだして、他の国々の民がするように祭司を立てたではないか。すなわちだれでも若い雄牛一頭、雄羊七頭を携えてきて、自分を聖別する者は皆あの神でない者の祭司とすることができた。</span>
<span className="v" id="v10" data-v="10" data-xref="出エジプト記 19:5–6; 歴代志下 11:16–17; ゼカリヤ書 13:9"> しかしわれわれにおいては、主がわれわれの神であって、われわれは彼を捨てない。また主に仕える祭司はアロンの子孫であり、働きをなす者はレビびとである。</span>
<span className="v" id="v11" data-v="11" data-xref="歴代志下 2:4; レビ記 24:2–9; 出エジプト記 29:38"> 彼らは朝ごと夕ごとに主に燔祭と、こうばしい香をささげ、供えのパンを純金の机の上に供え、また金の燭台とそのともしび皿を整えて、夕ごとにともすのである。このようにわれわれはわれわれの神、主の務を守っているが、あなたがたは彼を捨てた。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行伝 5:39; ローマ人への手紙 8:31; 民数記 10:8–9"> 見よ、神はみずからわれわれと共におられて、われわれのかしらとなられ、また、その祭司たちはラッパを吹きならして、あなたがたを攻める。イスラエルの人々よ、あなたがたの先祖の神、主に敵して戦ってはならない。あなたがたは成功しない」。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="ヨシュア記 8:4; ヨシュア記 8:9; 箴言 21:30"> ヤラベアムは伏兵を彼らのうしろに回らせたので、彼の軍隊はユダの前にあり、伏兵は彼らのうしろにあった。</span>
<span className="v" id="v14" data-v="14" data-xref="歴代志下 14:11; 出エジプト記 14:10; ヨシュア記 8:20"> ユダはうしろを見ると、敵が前とうしろとにあったので、主に向かって呼ばわり、祭司たちはラッパを吹いた。</span>
<span className="v" id="v15" data-v="15" data-xref="歴代志下 14:12; ヨシュア記 11:8; 詩篇 118:4–7"> そこでユダの人々はときの声をあげた。ユダの人々がときの声をあげると、神はヤラベアムとイスラエルの人々をアビヤとユダの前に打ち敗られたので、</span>
<span className="v" id="v16" data-v="16" data-xref="歴代志下 16:8; 士師記 11:21; ヨシュア記 10:12"> イスラエルの人々はユダの前から逃げた。神が彼らをユダの手に渡されたので、</span>
<span className="v" id="v17" data-v="17" data-xref="歴代志下 28:6; 歴代志下 13:3; 歴代志下 13:12"> アビヤとその民は、彼らをおびただしく撃ち殺した。イスラエルの殺されて倒れた者は五十万人、皆精兵であった。</span>
<span className="v" id="v18" data-v="18" data-xref="歴代志上 5:20; 歴代志下 14:11; ナホム書 1:7"> このように、この時イスラエルの人々は打ち負かされ、ユダの人々は勝を得た。彼らがその先祖の神、主を頼んだからである。</span>
<span className="v" id="v19" data-v="19" data-xref="歴代志下 15:8; ヨシュア記 15:9; ヨシュア記 10:39"> アビヤはヤラベアムを追撃して数個の町を彼から取った。すなわちベテルとその村里、エシャナとその村里、エフロンとその村里である。</span>
<span className="v" id="v20" data-v="20" data-xref="サムエル記上 25:38; 列王紀上 14:20; 使徒行伝 12:23"> ヤラベアムは、アビヤの世には再び力を得ることができず、主に撃たれて死んだ。</span>
<span className="v" id="v21" data-v="21" data-xref="士師記 9:5; サムエル記下 5:12–13; 士師記 10:4"> しかしアビヤは強くなり、妻十四人をめとり、むすこ二十二人、むすめ十六人をもうけた。</span>
<span className="v" id="v22" data-v="22" data-xref="歴代志下 9:29; 歴代志下 12:15; 歴代志下 24:27"> アビヤのその他の行為すなわちその行動と言葉は、預言者イドの注釈にしるされている。</span>
</div>

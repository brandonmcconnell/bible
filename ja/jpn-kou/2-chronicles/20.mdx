<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="詩篇 83:5–8; イザヤ書 16:6; 歴代志下 32:1"> この後モアブびと、アンモンびとおよびメウニびとらがヨシャパテと戦おうと攻めてきた。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 14:7; サムエル記上 23:29; ヨシュア記 15:62"> その時ある人がきて、ヨシャパテに告げて言った、「海のかなたのエドムから大軍があなたに攻めて来ます。見よ、彼らはハザゾン・タマル（すなわちエンゲデ）にいます」。</span>
<span className="v" id="v3" data-v="3" data-xref="ダニエル書 9:3; 歴代志下 19:3; サムエル記上 7:6"> そこでヨシャパテは恐れ、主に顔を向けて助けを求め、ユダ全国に断食をふれさせた。</span>
<span className="v" id="v4" data-v="4" data-xref="詩篇 50:15; 詩篇 60:10–12; 詩篇 69:35"> それでユダはこぞって集まり、主の助けを求めた。すなわちユダのすべての町から人々が来て主を求めた。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="列王紀下 19:15–19; 歴代志下 6:12–13; 歴代志下 34:31"> そこでヨシャパテは主の宮の新しい庭の前で、ユダとエルサレムの会衆の中に立って、</span>
<span className="v" id="v6" data-v="6" data-xref="申命記 4:39; 歴代志上 29:11–12; ダニエル書 4:17"> 言った、「われわれの先祖の神、主よ、あなたは天にいます神ではありませんか。異邦人のすべての国を治められるではありませんか。あなたの手には力があり、勢いがあって、あなたに逆らいうる者はありません。</span>
<span className="v" id="v7" data-v="7" data-xref="イザヤ書 41:8; ヤコブの手紙 2:23; 詩篇 44:2"> われわれの神よ、あなたはこの国の民をあなたの民イスラエルの前から追い払って、あなたの友アブラハムの子孫に、これを永遠に与えられたではありませんか。</span>
<span className="v" id="v8" data-v="8" data-xref="歴代志下 6:10; 歴代志下 2:4"> 彼らはここに住み、あなたの名のためにここに聖所を建てて言いました、</span>
<span className="v" id="v9" data-v="9" data-xref="歴代志下 6:28–30; 歴代志下 6:20; 列王紀上 8:33"> 『つるぎ、審判、疫病、ききんなどの災がわれわれに臨む時、われわれはこの宮の前に立って、あなたの前におり、その悩みの中であなたに呼ばわります。すると、あなたは聞いて助けられます。あなたの名はこの宮にあるからです』と。</span>
<span className="v" id="v10" data-v="10" data-xref="申命記 2:19; 申命記 2:4–5; 申命記 2:9"> 今アンモン、モアブ、およびセイル山の人々をごらんなさい。昔イスラエルがエジプトの国から出てきた時、あなたはイスラエルに彼らを侵すことをゆるされなかったので、イスラエルは彼らを離れて、滅ぼしませんでした。</span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 83:3–12; 士師記 11:23–24; エレミヤ書 18:20"> 彼らがわれわれに報いるところをごらんください。彼らは来て、あなたがわれわれに賜わったあなたの領地からわれわれを追い払おうとしています。</span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 121:1–2; 詩篇 25:15; 詩篇 141:8"> われわれの神よ、あなたは彼らをさばかれないのですか。われわれはこのように攻めて来る大軍に当る力がなく、またいかになすべきかを知りません。ただ、あなたを仰ぎ望むのみです」。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="エズラ記 10:1; 使徒行伝 21:5; 申命記 29:10"> ユダの人々はその幼な子、その妻、および子供たちと共に皆主の前に立っていた。</span>
<span className="v" id="v14" data-v="14" data-xref="歴代志下 15:1; 歴代志下 24:20; 使徒行伝 10:31"> その時主の霊が会衆の中でアサフの子孫であるレビびとヤハジエルに臨んだ。ヤハジエルはゼカリヤの子、ゼカリヤはベナヤの子、ベナヤはエイエルの子、エイエルはマッタニヤの子である。</span>
<span className="v" id="v15" data-v="15" data-xref="歴代志下 32:7–8; 申命記 31:6; 出エジプト記 14:13–14"> ヤハジエルは言った、「ユダの人々、エルサレムの住民、およびヨシャパテ王よ、聞きなさい。主はあなたがたにこう仰せられる、『この大軍のために恐れてはならない。おののいてはならない。これはあなたがたの戦いではなく、主の戦いだからである。</span>
<span className="v" id="v16" data-v="16"> あす、彼らの所へ攻め下りなさい。見よ、彼らはヂヅの坂から上って来る。あなたがたはエルエルの野の東、谷の端でこれに会うであろう。</span>
<span className="v" id="v17" data-v="17" data-xref="出エジプト記 14:13–14; 歴代志下 15:2; イザヤ書 41:10"> この戦いには、あなたがたは戦うに及ばない。ユダおよびエルサレムよ、あなたがたは進み出て立ち、あなたがたと共におられる主の勝利を見なさい。恐れてはならない。おののいてはならない。あす、彼らの所に攻めて行きなさい。主はあなたがたと共におられるからである』」。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="出エジプト記 4:31; 歴代志下 7:3; 創世記 24:26"> ヨシャパテは地にひれ伏した。ユダの人々およびエルサレムの民も主の前に伏して、主を拝した。</span>
<span className="v" id="v19" data-v="19" data-xref="歴代志上 15:16–22; 歴代志上 16:42; 歴代志上 16:5"> その時コハテびとの子孫、およびコラびとの子孫であるレビびとが立ち上がり、大声をあげてイスラエルの神、主をさんびした。</span>
</div>
<div className="bp poetry">
<span className="v" id="v20" data-v="20" data-xref="ローマ人への手紙 8:31; ヨハネによる福音書 14:1; ヨハネによる福音書 11:40"> 彼らは朝早く起きてテコアの野に出て行った。その出て行くとき、ヨシャパテは立って言った、「ユダの人々およびエルサレムの民よ、わたしに聞きなさい。あなたがたの神、主を信じなさい。そうすればあなたがたは堅く立つことができる。主の預言者を信じなさい。そうすればあなたがたは成功するでしょう」。</span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 107:1; 詩篇 106:1; 歴代志下 5:13"> 彼はまた民と相談して人々を任命し、聖なる飾りを着けて軍勢の前に進ませ、主に向かって歌をうたい、かつさんびさせ、<br /><span className="pl pl-1">「主に感謝せよ、</span><br /><span className="pl pl-1">そのいつくしみはとこしえに絶えることがない」</span><br />と言わせた。</span>
<span className="v" id="v22" data-v="22" data-xref="サムエル記上 14:20; イザヤ書 19:2; エゼキエル書 38:21"> そして彼らが歌をうたい、さんびし始めた時、主は伏兵を設け、かのユダに攻めてきたアンモン、モアブ、セイル山の人々に向かわせられたので、彼らは打ち敗られた。</span>
<span className="v" id="v23" data-v="23" data-xref="士師記 7:22; サムエル記上 14:20; エゼキエル書 35:2–3"> すなわちアンモンとモアブの人々は立ち上がって、セイル山の民に敵し、彼らを殺して全く滅ぼしたが、セイルの民を殺し尽すに及んで、彼らもおのおの互に助けて滅ぼしあった。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="イザヤ書 37:36; 詩篇 110:6; 歴代志上 5:22"> ユダの人々は野の物見やぐらへ行って、かの群衆を見たが、地に倒れた死体だけであって、ひとりものがれた者はなかった。</span>
<span className="v" id="v25" data-v="25" data-xref="サムエル記上 30:19–20; 列王紀下 7:9–16; 民数記 31:15"> それでヨシャパテとその民は彼らの物を奪うために来て見ると、多数の家畜、財宝、衣服および宝石などおびただしくあったので、おのおのそれをはぎ取ったが、運びきれないほどたくさんで、かすめ取るに三日もかかった。それほど物が多かったのである。</span>
<span className="v" id="v26" data-v="26" data-xref="出エジプト記 17:15; 創世記 32:20; 歴代志下 5:9"> 四日目に彼らはベラカの谷に集まり、その所で主を祝福した。それでその所の名を今日までベラカの谷と呼んでいる。</span>
<span className="v" id="v27" data-v="27" data-xref="ネヘミヤ書 12:43; ヘブル人への手紙 6:20; 詩篇 30:1"> そしてユダとエルサレムの人々は皆ヨシャパテを先に立て、喜んでエルサレムに帰ってきた。主が彼らにその敵のことによって喜びを与えられたからである。</span>
<span className="v" id="v28" data-v="28" data-xref="ヨハネの黙示録 14:2–3; 詩篇 57:8; 詩篇 92:3"> すなわち彼らは立琴、琴およびラッパをもってエルサレムの主の宮に来た。</span>
<span className="v" id="v29" data-v="29" data-xref="歴代志下 17:10; 列王紀下 7:6; 出エジプト記 23:27"> そしてもろもろの国の民は主がイスラエルの敵と戦われたことを聞いて神を恐れた。</span>
<span className="v" id="v30" data-v="30" data-xref="歴代志下 15:15; 歴代志下 14:6–7; サムエル記下 7:1"> こうして神が四方に安息を賜わったので、ヨシャパテの国は穏やかであった。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="列王紀上 22:41–44"> このようにヨシャパテはユダを治めた。彼は三十五歳の時、王となり、二十五年の間エルサレムで世を治めた。彼の母の名はアズバといってシルヒの娘である。</span>
<span className="v" id="v32" data-v="32" data-xref="歴代志下 14:2–5; 列王紀上 15:11; 歴代志下 14:11–13"> ヨシャパテは父アサの道を歩んでそれを離れず、主の目に正しいと見られることを行った。</span>
<span className="v" id="v33" data-v="33" data-xref="歴代志下 17:6; 歴代志下 19:3; 歴代志下 12:14"> しかし高き所は除かず、また民はその先祖の神に心を傾けなかった。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="列王紀上 16:1; 歴代志下 19:2; 列王紀上 16:7"> ヨシャパテのその他の始終の行為は、ハナニの子エヒウの書にしるされ、イスラエルの列王の書に載せられてある。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="列王紀上 22:48–49; 列王紀下 1:2–16"> この後ユダの王ヨシャパテはイスラエルの王アハジヤと相結んだ。アハジヤは悪を行った。</span>
<span className="v" id="v36" data-v="36" data-xref="列王紀上 10:22; 歴代志下 9:21; 列王紀上 9:26"> ヨシャパテはタルシシへ行く船を造るためにアハジヤと相結び、エジオン・ゲベルで一緒に船数隻を造った。</span>
<span className="v" id="v37" data-v="37" data-xref="箴言 13:20; 歴代志下 19:2; 歴代志下 9:21"> その時マレシャのドダワの子エリエゼルはヨシャパテに向かって預言し、「あなたはアハジヤと相結んだので、主はあなたの造った物をこわされます」と言ったが、その船は難破して、タルシシへ行くことができなかった。</span>
</div>

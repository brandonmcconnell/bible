<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歴代志上 3:11; 列王紀下 11:21–15"> ヨアシは位についた時七歳で、エルサレムで四十年の間、世を治めた。彼の母はベエルシバから出た者で名をヂビアといった。</span>
<span className="v" id="v2" data-v="2" data-xref="歴代志下 26:4–5; 歴代志下 25:2; 歴代志下 24:17–22"> ヨアシは祭司エホヤダの世にある日の間は常に主の良しと見られることを行った。</span>
<span className="v" id="v3" data-v="3" data-xref="歴代志下 24:15; マタイによる福音書 19:4–8; 創世記 4:19"> エホヤダは彼のためにふたりの妻をめとり、彼に男子と女子が生れた。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4"> この後ヨアシは主の宮を修繕しようと志して、</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀下 12:4–7; 歴代志下 34:8–9; 歴代志下 29:3"> 祭司とレビびとを集めて言った、「ユダの町々へ行って、あなたがたの神の宮を年々修繕する資金をすべてのイスラエルびとから集めなさい。その事を急いでしなさい」。ところがレビびとはこれを急いでしなかった。</span>
<span className="v" id="v6" data-v="6" data-xref="出エジプト記 30:12–16; 民数記 1:50; 民数記 17:7–8"> それで王はかしらであるエホヤダを召して言った、「あなたはなぜレビびとに求めて、主のしもべモーセがあかしの幕屋のためにイスラエルの会衆に課した税金をユダとエルサレムから取り立てさせないのか」。</span>
<span className="v" id="v7" data-v="7" data-xref="歴代志下 21:17; 歴代志下 28:22–24; 列王紀下 12:4"> かの悪い女アタリヤの子らが神の宮に侵入して主の宮のもろもろの奉納物をとり、バアルのために用いたからである。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="マルコによる福音書 12:41; 列王紀下 12:8–9"> そこで王は命じて一個の箱を造らせ、これを主の宮の門の外に置き、</span>
<span className="v" id="v9" data-v="9" data-xref="歴代志下 24:6; マタイによる福音書 17:24–27"> ユダとエルサレムにふれて、神のしもべモーセが荒野でイスラエルに課した税金を主のために持ってこさせた。</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行伝 2:45–47; コリント人への第二の手紙 9:7; 歴代志上 29:9"> すべてのつかさたちおよびすべての民は皆喜んでその税金を持って来て、その箱に投げ入れたので、ついに箱はいっぱいになった。</span>
<span className="v" id="v11" data-v="11" data-xref="列王紀下 12:10–12; コリント人への第一の手紙 16:2"> レビびとはその箱に金が多くあるのを見て、王の役人の所へ持って行くと、王の書記と祭司長の下役とが来て、その箱を傾け、これを取ってもとの所に返した。彼らは日々このようにして金をおびただしく集めた。</span>
<span className="v" id="v12" data-v="12" data-xref="列王紀上 5:15; 歴代志下 34:9–11"> 王とエホヤダはこれを主の宮の工事をなす者に渡し、石工および木工を雇って、主の宮を修繕させ、また鉄工および青銅工を雇って、主の宮を修復させた。</span>
<span className="v" id="v13" data-v="13" data-xref="ネヘミヤ書 4:7; マルコによる福音書 13:1–2; ハガイ書 2:3"> 工人たちは働いたので、修復の工事は彼らの手によってはかどり、神の宮を、もとの状態に復し、これを堅固にした。</span>
<span className="v" id="v14" data-v="14" data-xref="民数記 28:2–29; 箴言 27:22; 列王紀下 12:13–14"> それをなし終ったとき、余った金を王とエホヤダの前に持って来たので、それをもって主の宮のために器物を造った。すなわち勤めの器、燔祭の器、香の皿、および金銀の器を造った。エホヤダの世にある日の間は、絶えず主の宮で燔祭をささげた。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="創世記 47:9; 歴代志上 23:1; 詩篇 90:10"> しかしエホヤダは年老い、日が満ちて死んだ。その死んだ時は百三十歳であった。</span>
<span className="v" id="v16" data-v="16" data-xref="ヘブル人への手紙 6:10; 歴代志下 31:20; ネヘミヤ書 13:14"> 人々は彼をダビデの町で王たちの中に葬った。彼はイスラエルにおいて神とその宮とに良い事を行ったからである。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="申命記 31:27; 箴言 26:28; 使徒行伝 20:29–30"> エホヤダの死んだ後、ユダのつかさたちが来て、うやうやしく王に敬意を表した。王は彼らに聞き従った。</span>
<span className="v" id="v18" data-v="18" data-xref="ヨシュア記 22:20; 歴代志下 19:2; エペソ人への手紙 5:6"> 彼らはその先祖の神、主の宮を捨てて、アシラ像および偶像に仕えたので、そのとがのために、怒りがユダとエルサレムに臨んだ。</span>
<span className="v" id="v19" data-v="19" data-xref="イザヤ書 42:23; ルカによる福音書 20:9–15; マタイによる福音書 13:9"> 主は彼らをご自分に引き返そうとして、預言者たちをつかわし、彼らにむかってあかしをさせられたが、耳を傾けなかった。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="民数記 14:41; エレミヤ書 5:25; 歴代志下 15:1–2"> そこで神の霊が祭司エホヤダの子ゼカリヤに臨んだので、彼は民の前に立ち上がって言った、「神はこう仰せられる、『あなたがたが主の戒めを犯して、災を招くのはどういうわけであるか。あなたがたが主を捨てたために、主もあなたがたを捨てられたのである』」。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行伝 7:58–59; ネヘミヤ書 9:26; エレミヤ書 38:4–6"> しかし人々は彼を害しようと計り、王の命によって、石をもって彼を主の宮の庭で撃ち殺した。</span>
<span className="v" id="v22" data-v="22" data-xref="創世記 9:5; ルカによる福音書 11:51; ヨハネの黙示録 6:9–11"> このようにヨアシ王はゼカリヤの父エホヤダが自分に施した恵みを思わず、その子を殺した。ゼカリヤは死ぬ時、「どうぞ主がこれをみそなわして罰せられるように」と言った。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="列王紀下 12:17–18; 申命記 32:35; 列王紀上 20:22"> 年の終りになって、スリヤの軍勢はヨアシにむかって攻め上り、ユダとエルサレムに来て、民のつかさたちをことごとく民のうちから滅ぼし、そのぶんどり物を皆ダマスコの王に送った。</span>
<span className="v" id="v24" data-v="24" data-xref="歴代志下 22:8; レビ記 26:37; レビ記 26:8"> この時スリヤの軍勢は少数で来たのであるが、主は大軍を彼らの手に渡された。これは彼らがその先祖の神、主を捨てたためである。このように彼らはヨアシを罰した。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="歴代志下 24:21–22; 歴代志下 28:27; 歴代志下 21:18–20"> スリヤ軍はヨアシに大傷を負わせて捨て去ったが、ヨアシの家来たちは祭司エホヤダの子の血のために、党を結んで彼にそむき、彼を床の上に殺して、死なせた。人々は彼をダビデの町に葬ったが、王の墓には葬らなかった。</span>
<span className="v" id="v26" data-v="26" data-xref="列王紀下 12:21"> 党を結んで彼にそむいた者は、アンモンの女シメアテの子ザバデおよびモアブの女シムリテの子ヨザバデであった。</span>
<span className="v" id="v27" data-v="27" data-xref="歴代志下 16:11; 歴代志下 13:22; 歴代志下 24:12"> ヨアシの子らのこと、ヨアシに対する多くの預言および神の宮の修理の事などは、列王の書の注釈にしるされている。ヨアシの子アマジヤが彼に代って王となった。</span>
</div>

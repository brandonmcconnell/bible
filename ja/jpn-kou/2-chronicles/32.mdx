<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀下 18:13–37; 列王紀下 17:6; 歴代志下 20:1–2"> ヒゼキヤがこれらの事を忠実に行った後、アッスリヤの王セナケリブが来てユダに侵入し、堅固な町々に向かって陣を張り、これを攻め取ろうとした。</span>
<span className="v" id="v2" data-v="2" data-xref="ルカによる福音書 9:53; ルカによる福音書 9:51; 列王紀下 12:17"> ヒゼキヤはセナケリブが来て、エルサレムを攻めようとするのを見たので、</span>
<span className="v" id="v3" data-v="3" data-xref="箴言 24:6; 箴言 20:18; 箴言 15:22"> そのつかさたちおよび勇士たちと相談して、町の外にある泉の水を、ふさごうとした。彼らはこれを助けた。</span>
<span className="v" id="v4" data-v="4" data-xref="歴代志下 32:30; 列王紀下 18:9; 列王紀上 19:21"> 多くの民は集まって、すべての泉および国の中を流れる谷川をふさいで言った、「アッスリヤの王たちがきて、多くの水を得られるようなことをしておいていいだろうか」。</span>
<span className="v" id="v5" data-v="5" data-xref="歴代志下 25:23; 列王紀上 9:24; 列王紀下 25:4"> ヒゼキヤはまた勇気を出して、破れた城壁をことごとく築き直して、その上にやぐらを建て、その外にまた城壁を巡らし、ダビデの町のミロを堅固にし、武器および盾を多く造り、</span>
<span className="v" id="v6" data-v="6" data-xref="イザヤ書 40:2; 歴代志下 30:22; ネヘミヤ書 8:16"> 軍長を民の上に置き、町の門の広場に民を集めて、これを励まして言った、</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀下 6:16; ローマ人への手紙 8:31; エペソ人への手紙 6:10"> 「心を強くし、勇みたちなさい。アッスリヤの王をも、彼と共にいるすべての群衆をも恐れてはならない。おののいてはならない。われわれと共におる者は彼らと共におる者よりも大いなる者だからである。</span>
<span className="v" id="v8" data-v="8" data-xref="エレミヤ書 17:5; 歴代志下 20:17; イザヤ書 41:10"> 彼と共におる者は肉の腕である。しかしわれわれと共におる者はわれわれの神、主であって、われわれを助け、われわれに代って戦われる」。民はユダの王ヒゼキヤの言葉に安心した。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="列王紀下 18:17; ヨシュア記 10:31; イザヤ書 36:2"> この後アッスリヤの王セナケリブはその全軍をもってラキシを囲んでいたが、その家来をエルサレムにつかわして、ユダの王ヒゼキヤおよびエルサレムにいるすべてのユダの人に告げさせて言った、</span>
<span className="v" id="v10" data-v="10" data-xref="列王紀下 18:19; イザヤ書 36:4"> 「アッスリヤの王セナケリブはこう言います、『あなたがたは何を頼んでエルサレムにこもっているのか。</span>
<span className="v" id="v11" data-v="11" data-xref="マタイによる福音書 27:43; 詩篇 11:1–3; イザヤ書 36:18"> ヒゼキヤは「われわれの神、主がアッスリヤの王の手から、われわれを救ってくださる」と言って、あなたがたをそそのかし、飢えと、かわきをもって、あなたがたを死なせようとしているのではないか。</span>
<span className="v" id="v12" data-v="12" data-xref="歴代志下 31:1; 申命記 12:13–14; 申命記 12:26–27"> このヒゼキヤは主のもろもろの高き所と祭壇を取り除き、ユダとエルサレムに命じて、「あなたがたはただ一つの祭壇の前で礼拝し、その上に犠牲をささげなければならない」と言った者ではないか。</span>
<span className="v" id="v13" data-v="13" data-xref="列王紀下 18:33–35; イザヤ書 44:8–10; ダニエル書 4:30"> あなたがたは、わたしおよびわたしの先祖たちが、他の国々のすべての民にしたことを知らないのか。それらの国々の民の神々は、少しでもその国を、わたしの手から救い出すことができたか。</span>
<span className="v" id="v14" data-v="14" data-xref="イザヤ書 10:11–12; 出エジプト記 15:9–11; イザヤ書 42:8"> わたしの先祖たちが滅ぼし尽したそれらの国民のもろもろの神のうち、だれか自分の民をわたしの手から救い出すことのできたものがあるか。それで、どうしてあなたがたの神が、あなたがたをわたしの手から救い出すことができよう。</span>
<span className="v" id="v15" data-v="15" data-xref="出エジプト記 5:2; ダニエル書 3:15; イザヤ書 36:18"> それゆえ、あなたがたはヒゼキヤに欺かれてはならない。そそのかされてはならない。また彼を信じてはならない。いずれの民、いずれの国の神もその民をわたしの手、または、わたしの先祖の手から救いだすことができなかったのだから、ましてあなたがたの神が、どうしてわたしの手からあなたがたを救いだすことができようか』」。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="詩篇 73:9; ヨハネによる福音書 15:21; ヨブ記 15:25–26"> セナケリブの家来は、このほかにも多く主なる神、およびそのしもべヒゼキヤをそしった。</span>
<span className="v" id="v17" data-v="17" data-xref="イザヤ書 37:14; 列王紀下 19:12; イザヤ書 37:28–29"> セナケリブはまた手紙を書き送って、イスラエルの神、主をあざけり、かつそしって言った、「諸国の民の神々が、その民をわたしの手から救い出さなかったように、ヒゼキヤの神も、その民をわたしの手から救い出さないであろう」と。</span>
<span className="v" id="v18" data-v="18" data-xref="サムエル記上 17:10; 列王紀下 18:26–28; サムエル記上 17:26"> そして彼らは大声をあげ、ユダヤの言葉をもって、城壁の上にいるエルサレムの民に向かって叫び、これをおどし、かつおびやかした。彼らは町を取るためである。</span>
<span className="v" id="v19" data-v="19" data-xref="列王紀下 19:18; イザヤ書 2:8; エレミヤ書 32:30"> このように彼らがエルサレムの神について語ること、人の手のわざである地上の民の神々について語るようであった。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="詩篇 91:14–15; イザヤ書 37:14–20; 歴代志下 14:11"> そこでヒゼキヤ王およびアモツの子預言者イザヤは共に祈って、天に呼ばわったので、</span>
<span className="v" id="v21" data-v="21" data-xref="イザヤ書 37:36–38; 詩篇 76:5; 詩篇 18:50"> 主はひとりのみ使をつかわして、アッスリヤ王の陣営にいるすべての大勇士と将官、軍長らを滅ぼされた。それで王は赤面して自分の国に帰ったが、その神の家にはいった時、その子のひとりが、つるぎをもって彼をその所で殺した。</span>
<span className="v" id="v22" data-v="22" data-xref="イザヤ書 31:4–5; 詩篇 18:48–50; テサロニケ人への第二の手紙 3:5"> このように主は、ヒゼキヤとエルサレムの住民をアッスリヤの王セナケリブの手およびすべての敵の手から救い出し、いたる所で彼らを守られた。</span>
<span className="v" id="v23" data-v="23" data-xref="歴代志下 17:5; マタイによる福音書 2:11; 歴代志下 1:1"> そこで多くの人々はささげ物をエルサレムに携えてきて主にささげ、また宝物をユダの王ヒゼキヤに贈った。この後ヒゼキヤは万国の民に尊ばれた。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="イザヤ書 38:1–8; 列王紀下 20:1–11; イザヤ書 38:21–22"> そのころ、ヒゼキヤは病んで死ぬばかりであったが、主に祈ったので、主はこれに答えて、しるしを賜わった。</span>
<span className="v" id="v25" data-v="25" data-xref="歴代志下 24:18; 歴代志下 26:16; 歴代志下 32:31"> しかしヒゼキヤはその受けた恵みに報いることをせず、その心が高ぶったので、怒りが彼とユダおよびエルサレムに臨もうとしたが、</span>
<span className="v" id="v26" data-v="26" data-xref="エレミヤ書 26:18–19; 歴代志下 34:27–28; 歴代志下 33:12"> ヒゼキヤはその心の高ぶりを悔いてへりくだり、またエルサレムの住民も同様にしたので、主の怒りは、ヒゼキヤの世には彼らに臨まなかった。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="歴代志上 27:25–31; 歴代志下 1:12; 箴言 10:22"> ヒゼキヤは富と栄誉をきわめ、宝蔵を造って、金、銀、宝石、香料、盾および各種の尊い器物をおさめ、</span>
<span className="v" id="v28" data-v="28" data-xref="サムエル記下 7:8; 歴代志下 26:10; 列王紀上 4:26"> また倉庫を造って穀物、酒、油などの産物をおさめ、小屋を造って種々の家畜を置き、おりを造って羊の群れを置き、</span>
<span className="v" id="v29" data-v="29" data-xref="歴代志上 29:12; 箴言 10:22; サムエル記上 2:7"> また多数の町を設け、かつ羊と牛をおびただしく所有した。神が非常に多くの貨財を彼に賜わったからである。</span>
<span className="v" id="v30" data-v="30" data-xref="列王紀上 1:33; イザヤ書 22:9–11; 詩篇 1:1–3"> このヒゼキヤはまたギホンの水の上の源をふさいで、これをダビデの町の西の方にまっすぐに引き下した。このようにヒゼキヤはそのすべてのわざをなし遂げた。</span>
<span className="v" id="v31" data-v="31" data-xref="申命記 8:2; 箴言 17:3; 創世記 22:1"> しかしバビロンの君たちが使者をつかわして、この国にあった、しるしについて尋ねさせた時には、神は彼を試みて、彼の心にあることを、ことごとく知るために彼を捨て置かれた。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="イザヤ書 36:1–22; 列王紀下 18:1–20; 歴代志下 31:20–21"> ヒゼキヤのその他の行為およびその徳行は、アモツの子預言者イザヤの黙示とユダとイスラエルの列王の書にしるされている。</span>
<span className="v" id="v33" data-v="33" data-xref="箴言 10:7; 列王紀上 1:21; 歴代志下 16:14"> ヒゼキヤはその先祖たちと共に眠ったので、ダビデの子孫の墓のうちの高い所に葬られた。ユダの人々およびエルサレムの住民は皆その死に当って彼に敬意を表した。その子マナセが彼に代って王となった。</span>
</div>

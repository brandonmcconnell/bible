<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀上 12:21–24; 詩篇 33:10; 詩篇 33:16"> レハベアムはエルサレムに来て、ユダとベニヤミンの家の者、すなわち、えり抜きの軍人十八万人を集め、国を取りもどすためにイスラエルと戦おうとしたが、</span>
<span className="v" id="v2" data-v="2" data-xref="歴代志下 12:15; 歴代志下 12:5–7; 歴代志下 8:14"> 主の言葉が神の人シマヤに臨んで言った、</span>
<span className="v" id="v3" data-v="3" data-xref="列王紀下 17:34; 創世記 49:28; ヨハネの黙示録 7:4–8"> 「ソロモンの子、ユダの王レハベアムおよびユダとベニヤミンにいるすべてのイスラエルの人々に言いなさい、</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 50:20; 列王紀上 11:29–38; 歴代志下 10:15–16"> 『主はこう仰せられる、あなたがたは上ってはならない。あなたがたの兄弟と戦ってはならない。おのおの自分の家に帰りなさい。この事はわたしから出たのである』」。それで人々は主の言葉を聞き、ヤラベアムを攻めに行くのをやめて帰った。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="歴代志下 8:2–6; 歴代志下 14:6–7; イザヤ書 22:8–11"> レハベアムはエルサレムに住んで、ユダに防衛の町々を建てた。</span>
<span className="v" id="v6" data-v="6" data-xref="ネヘミヤ書 3:5; アモス書 1:1; 歴代志上 4:32"> すなわちベツレヘム、エタム、テコア、</span>
<span className="v" id="v7" data-v="7" data-xref="ヨシュア記 15:35; サムエル記上 22:1; ヨシュア記 15:58"> ベテズル、ソコ、アドラム、</span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 54:1; ヨシュア記 15:24; サムエル記上 23:19"> ガテ、マレシャ、ジフ、</span>
<span className="v" id="v9" data-v="9" data-xref="ヨシュア記 15:39; ヨシュア記 15:35; ヨシュア記 10:5"> アドライム、ラキシ、アゼカ、</span>
<span className="v" id="v10" data-v="10" data-xref="民数記 13:22; ヨシュア記 15:33; ヨシュア記 14:14"> ゾラ、アヤロン、およびヘブロン。これらはユダとベニヤミンにあって要害の町々である。</span>
<span className="v" id="v11" data-v="11" data-xref="歴代志下 17:19; イザヤ書 22:10–11; 歴代志下 11:23"> 彼はその要害を堅固にし、これに軍長を置き、糧食と油とぶどう酒をたくわえ、</span>
<span className="v" id="v12" data-v="12" data-xref="サムエル記下 13:22; 歴代志下 26:14–15; 歴代志下 32:5"> またそのすべての町に盾とやりを備えて、これを非常に強化し、そしてユダとベニヤミンを確保した。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13"> イスラエルの全地の祭司とレビびとは四方の境から来てレハベアムに身を寄せた。</span>
<span className="v" id="v14" data-v="14" data-xref="歴代志下 13:9; 民数記 35:2–5; 列王紀上 12:28–33"> すなわちレビびとは自分の放牧地と領地を離れてユダとエルサレムに来た。これはヤラベアムとその子らが彼らを排斥して、主の前に祭司の務をさせなかったためである。</span>
<span className="v" id="v15" data-v="15" data-xref="列王紀上 12:28; 列王紀上 12:31; 列王紀上 13:33"> ヤラベアムは高き所と、みだらな神と、自分で造った子牛のために自分の祭司を立てた。</span>
<span className="v" id="v16" data-v="16" data-xref="歴代志下 15:9; 使徒行伝 11:23; 詩篇 84:5–7"> またイスラエルのすべての部族のうちで、すべてその心を傾けて、イスラエルの神、主を求める者は先祖の神、主に犠牲をささげるために、レビびとに従ってエルサレムに来た。</span>
<span className="v" id="v17" data-v="17" data-xref="歴代志下 12:1; 歴代志下 1:1–12; 歴代志下 7:17–19"> このように彼らはユダの国を堅くし、ソロモンの子レハベアムを三年の間強くした。彼らは三年の間ダビデとソロモンの道に歩んだからである。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="サムエル記上 16:6; 歴代志上 27:18; サムエル記上 17:13"> レハベアムはダビデの子エレモテの娘マハラテを妻にめとった。マハラテはエッサイの子エリアブの娘アビハイルが産んだ者である。</span>
<span className="v" id="v19" data-v="19"> 彼女はエウシ、シマリヤおよびザハムの三子を産んだ。</span>
<span className="v" id="v20" data-v="20" data-xref="歴代志下 13:2; 歴代志下 11:21; 歴代志下 12:16"> 彼はまた彼女の後にアブサロムの娘マアカをめとった。マアカはアビヤ、アッタイ、ジザおよびシロミテを産んだ。</span>
<span className="v" id="v21" data-v="21" data-xref="士師記 8:30; 申命記 17:17; 列王紀上 11:3"> レハベアムはアブサロムの娘マアカをすべての妻とそばめにまさって愛した。彼は妻十八人、そばめ六十人をめとって、男の子二十八人と女の子六十人をもうけた。</span>
<span className="v" id="v22" data-v="22" data-xref="申命記 21:15–17; 歴代志上 29:1; 歴代志上 5:1–2"> レハベアムはマアカの子アビヤを立ててかしらとし、その兄弟の長とした。彼はアビヤを王にしようと思ったからである。</span>
<span className="v" id="v23" data-v="23" data-xref="歴代志下 21:3; 創世記 25:6; ルカによる福音書 16:8"> それで王は賢くとり行い、そのむすこたちをことごとく、ユダとベニヤミンの全地方にあるすべての要害の町に散在させ、彼らに糧食を多く与え、また多くの妻を得させた。</span>
</div>

<span className="v" id="v1" data-v="1" data-xref="歴代志下 9:31; 列王紀上 2:10; 列王紀上 14:31"> アビヤはその先祖たちと共に眠って、ダビデの町に葬られ、その子アサが代って王となった。アサの治世に国は十年の間、穏やかであった。</span>
<span className="v" id="v2" data-v="2" data-xref="列王紀上 15:11; 歴代志下 31:20; 列王紀上 15:14"> アサはその神、主の目に良しと見え、また正しと見えることを行った。</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 7:5; 出エジプト記 34:13; 列王紀下 23:14"> 彼は異なる祭壇と、もろもろの高き所を取り除き、石柱をこわし、アシラ像を切り倒し、</span>
<span className="v" id="v4" data-v="4" data-xref="歴代志下 30:19; 詩篇 119:10; 詩篇 101:2–8"> ユダに命じてその先祖たちの神、主を求めさせ、おきてと戒めとを行わせ、</span>
<span className="v" id="v5" data-v="5" data-xref="歴代志下 34:4; 歴代志下 34:7"> ユダのすべての町々から、高き所と香の祭壇とを取り除いた。そして国は彼のもとに穏やかであった。</span>
<span className="v" id="v6" data-v="6" data-xref="歴代志下 15:15; 歴代志上 22:9; ヨブ記 34:29"> 彼は国が穏やかであったので、要害の町数個をユダに建てた。また主が彼に平安を賜わったので、この年ごろ戦争がなかった。</span>
<span className="v" id="v7" data-v="7" data-xref="ペテロの第一の手紙 3:12; 歴代志下 14:6; エレミヤ書 29:12–14"> 彼はユダに言った、「われわれはこれらの町を建て、その周囲に石がきを築き、やぐらを建て、門と貫の木を設けよう。われわれがわれわれの神、主を求めたので、この国はなおわれわれのものであり、われわれが彼を求めたので、四方において、われわれに平安を賜わった」。こうして彼らは滞りなく建て終った。</span>
<span className="v" id="v8" data-v="8" data-xref="歴代志下 13:3; 歴代志下 17:14–19; 歴代志下 11:1"> アサの軍隊はユダから出た者三十万人あって、盾とやりをとり、ベニヤミンから出た者二十八万人あって、小盾をとり、弓を引いた。これはみな大勇士であった。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="歴代志下 16:8; 歴代志下 12:2–3; 歴代志下 11:8"> エチオピヤびとゼラが、百万の軍隊と三百の戦車を率いて、マレシャまで攻めてきた。</span>
<span className="v" id="v10" data-v="10" data-xref="士師記 1:17; ヨシュア記 19:4"> アサは出て、これを迎え、マレシャのゼパタの谷に戦いの備えをした。</span>
<span className="v" id="v11" data-v="11" data-xref="エレミヤ書 1:19; コリント人への第二の手紙 12:9–10; 詩篇 22:5"> 時にアサはその神、主に向かって呼ばわって言った、「主よ、力のある者を助けることも、力のない者を助けることも、あなたにおいては異なることはありません。われわれの神、主よ、われわれをお助けください。われわれはあなたに寄り頼み、あなたの名によってこの大軍に当ります。主よ、あなたはわれわれの神です。どうぞ人をあなたに勝たせないでください」。</span>
<span className="v" id="v12" data-v="12" data-xref="歴代志下 13:15; 詩篇 136:17–18; 申命記 28:7"> そこで主はアサの前とユダの前でエチオピヤびとを撃ち敗られたので、エチオピヤびとは逃げ去った。</span>
<span className="v" id="v13" data-v="13" data-xref="創世記 10:19; 創世記 26:1; 創世記 20:1"> アサと彼に従う民は彼らをゲラルまで追撃したので、エチオピヤびとは倒れて、生き残った者はひとりもなかった。主と主の軍勢の前に撃ち破られたからである。ユダの人々の得たぶんどり物は非常に多かった。</span>
<span className="v" id="v14" data-v="14" data-xref="歴代志下 17:10; 創世記 35:5; 歴代志下 20:29"> 彼らはまた、ゲラルの周囲の町々をことごとく撃ち破った。主の恐れが彼らの上に臨んだからである。そして彼らはそのすべての町をかすめ奪った。その内に多くの物があったからである。</span>
<span className="v" id="v15" data-v="15" data-xref="民数記 31:30–47; 民数記 31:9; サムエル記上 30:20"> また家畜をもっている者の天幕を襲い、多くの羊とらくだを奪い取って、エルサレムに帰った。</span>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歴代志下 22:1; マタイによる福音書 1:8–9; 歴代志下 33:25"> そこでユダの民は皆ウジヤをとって王となし、その父アマジヤに代らせた。時に十六歳であった。</span>
<span className="v" id="v2" data-v="2" data-xref="列王紀下 16:6; 歴代志下 25:28; 歴代志下 25:23"> 彼はエラテを建てて、これをふたたびユダのものにした。これはかの王がその先祖たちと共に眠った後であった。</span>
<span className="v" id="v3" data-v="3" data-xref="列王紀下 15:2–3; アモス書 1:1; ホセア書 1:1"> ウジヤは王となった時十六歳で、エルサレムで五十二年の間世を治めた。その母はエルサレムの者で名をエコリヤといった。</span>
<span className="v" id="v4" data-v="4" data-xref="歴代志下 25:2"> ウジヤは父アマジヤがしたように、すべて主の良しと見られることを行った。</span>
<span className="v" id="v5" data-v="5" data-xref="歴代志下 15:2; 歴代志下 24:2; 歴代志上 22:13"> 彼は神を恐れることを自分に教えたゼカリヤの世にある日の間、神を求めることに努めた。彼が主を求めた間、神は彼を栄えさせられた。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="イザヤ書 14:29; サムエル記上 5:6; サムエル記上 5:1"> 彼は出てペリシテびとと戦い、ガテの城壁、ヤブネの城壁およびアシドドの城壁をくずし、アシドドの地とペリシテびとのなかに町を建てた。</span>
<span className="v" id="v7" data-v="7" data-xref="歴代志下 21:16; 歴代志上 5:20; 歴代志下 14:11"> 神は彼を助けてペリシテびとと、グルバアルに住むアラビヤびとおよびメウニびとを攻め撃たせられた。</span>
<span className="v" id="v8" data-v="8" data-xref="サムエル記下 8:2; 歴代志下 17:11; 創世記 19:38"> アンモンびとはウジヤにみつぎを納めた。ウジヤは非常に強くなったので、その名はエジプトの入口までも広まった。</span>
<span className="v" id="v9" data-v="9" data-xref="ネヘミヤ書 3:13; 歴代志下 25:23; 列王紀下 14:13"> ウジヤはまたエルサレムの隅の門、谷の門および城壁の曲りかどにやぐらを建てて、これを堅固にした。</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 26:18–21; イザヤ書 29:17; 列王紀下 3:4"> 彼はまた荒野にやぐらを建て、また多くの水ためを掘った。彼は平野にも平地にもたくさんの家畜をもっていたからである。彼はまた農事を好んだので、山々および肥えた畑には農夫とぶどうをつくる者をもっていた。</span>
<span className="v" id="v11" data-v="11" data-xref="列王紀下 5:2"> ウジヤはまたよく戦う一軍団を持っていた。彼らは書記エイエルと、つかさマアセヤによって調べた数に従って組々に分れ、皆王の軍長のひとりハナニヤの指揮下にあった。</span>
<span className="v" id="v12" data-v="12"> その氏族の長である大勇士の数は合わせて二千六百人であった。</span>
<span className="v" id="v13" data-v="13" data-xref="歴代志下 25:5; 歴代志下 14:8; 歴代志下 11:1"> その指揮下にある軍勢は三十万七千五百人で、皆大いなる力をもって戦い、王を助けて敵に当った。</span>
<span className="v" id="v14" data-v="14" data-xref="士師記 20:16; サムエル記上 17:49"> ウジヤはその全軍のために盾、やり、かぶと、よろい、弓および石投げの石を備えた。</span>
<span className="v" id="v15" data-v="15" data-xref="出エジプト記 31:4; マタイによる福音書 4:24; 歴代志下 2:7"> 彼はまたエルサレムで技術者の考案した機械を造って、これをやぐらおよび城壁のすみずみにすえ、これをもって矢および大石を射出した。こうして彼の名声は遠くまで広まった。彼が驚くほど神の助けを得て強くなったからである。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="歴代志下 32:25; 歴代志下 25:19; 箴言 16:18"> ところが彼は強くなるに及んで、その心に高ぶり、ついに自分を滅ぼすに至った。すなわち彼はその神、主にむかって罪を犯し、主の宮にはいって香の祭壇の上に香をたこうとした。</span>
<span className="v" id="v17" data-v="17" data-xref="歴代志上 6:10; 歴代志上 26:6; 歴代志上 12:28"> その時、祭司アザリヤは主の祭司である勇士八十人を率いて、彼のあとに従ってはいり、</span>
<span className="v" id="v18" data-v="18" data-xref="出エジプト記 30:7–8; 民数記 18:7; エレミヤ書 13:18"> ウジヤ王を引き止めて言った、「ウジヤよ、主に香をたくことはあなたのなすべきことではなく、ただアロンの子孫で、香をたくために清められた祭司たちのすることです。すぐ聖所から出なさい。あなたは罪を犯しました。あなたは主なる神から栄えを得ることはできません」。</span>
<span className="v" id="v19" data-v="19" data-xref="民数記 12:10; 歴代志下 25:16; 列王紀下 5:25–27"> するとウジヤは怒りを発し、香炉を手にとって香をたこうとしたが、彼が祭司に向かって怒りを発している間に、らい病がその額に起った。時に彼は主の宮で祭司たちの前、香の祭壇のかたわらにいた。</span>
<span className="v" id="v20" data-v="20" data-xref="申命記 28:22; エステル記 6:12; レビ記 14:34"> 祭司の長アザリヤおよびすべての祭司たちが彼を見ると、彼の額にらい病が生じていたので、急いで彼をそこから追い出した。彼自身もまた主に撃たれたことを知って、急いで出て行った。</span>
<span className="v" id="v21" data-v="21" data-xref="レビ記 13:46; 民数記 12:15; 列王紀下 7:3"> ウジヤ王は、死ぬ日までらい病人であった。彼はらい病人であったので、離れ殿に住んだ。主の宮から断たれたからである。その子ヨタムが王の家をつかさどり、国の民を治めた。</span>
<span className="v" id="v22" data-v="22" data-xref="イザヤ書 1:1; イザヤ書 6:1; 歴代志下 9:29"> ウジヤのその他の始終の行為は、アモツの子預言者イザヤがこれを書きしるした。</span>
<span className="v" id="v23" data-v="23" data-xref="歴代志下 28:27; 歴代志下 21:20; 歴代志下 26:18"> ウジヤは先祖たちと共に眠ったので、人々は「彼はらい病人である」と言って、王たちの墓に連なる墓地に、その先祖たちと共に葬った。その子ヨタムが彼に代って王となった。</span>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="エレミヤ書 22:11; 歴代志下 33:25; 歴代志下 26:1"> 国の民はヨシヤの子エホアハズを立て、エルサレムでその父に代って王とならせた。</span>
<span className="v" id="v2" data-v="2"> エホアハズは王となった時二十三歳で、エルサレムで三月の間、世を治めたが、</span>
<span className="v" id="v3" data-v="3" data-xref="列王紀下 23:33"> エジプトの王はエルサレムで彼を廃し、かつ銀百タラント、金一タラントの罰金を国に課した。</span>
<span className="v" id="v4" data-v="4" data-xref="エレミヤ書 22:10–12; 列王紀下 23:34–35; エゼキエル書 19:3–4"> そしてエジプト王は彼の兄弟エリアキムをユダとエルサレムの王とし、その名をエホヤキムと改め、その兄弟エホアハズを捕えてエジプトへ引いて行った。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="列王紀下 23:36–37; エレミヤ書 22:13–19; エレミヤ書 26:1"> エホヤキムは王となった時二十五歳で、十一年の間エルサレムで世を治めた。彼はその神、主の前に悪を行った。</span>
<span className="v" id="v6" data-v="6" data-xref="歴代志下 33:11; 列王紀下 24:5–6; エゼキエル書 19:5–9"> 時に、バビロンの王ネブカデネザルが彼の所に攻め上り、彼をバビロンに引いて行こうとして、かせにつないだ。</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀下 24:13; ダニエル書 5:2–4; エレミヤ書 27:16–18"> ネブカデネザルはまた主の宮の器物をバビロンに運んで行って、バビロンにあるその宮殿にそれをおさめた。</span>
<span className="v" id="v8" data-v="8" data-xref="列王紀下 24:5–6; マタイによる福音書 1:11–12; 歴代志上 3:16–17"> エホヤキムのその他の行為、その行った憎むべき事および彼がひそかに行った事などは、イスラエルとユダの列王の書にしるされている。その子エホヤキンが彼に代って王となった。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="列王紀下 24:8–17"> エホヤキンは王となった時八歳で、エルサレムで三月と十日の間、世を治め、主の前に悪を行った。</span>
<span className="v" id="v10" data-v="10" data-xref="エレミヤ書 37:1; 歴代志下 36:7; 列王紀下 24:10–17"> 年が改まり春になって、ネブカデネザル王は人をつかわして、彼を主の宮の尊い器物と共にバビロンに連れて行かせ、その兄弟ゼデキヤをユダとエルサレムの王とした。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="列王紀下 24:18–20; エレミヤ書 52:1–3; エレミヤ書 27:1"> ゼデキヤは王となった時二十一歳で、十一年の間エルサレムで世を治めた。</span>
<span className="v" id="v12" data-v="12" data-xref="歴代志下 33:23; エレミヤ書 37:2–21; エレミヤ書 38:14–28"> 彼はその神、主の前に悪を行い、主の言葉を伝える預言者エレミヤの前に、身をひくくしなかった。</span>
<span className="v" id="v13" data-v="13" data-xref="エレミヤ書 52:2–3; 歴代志下 30:8; エゼキエル書 17:11–20"> 彼はまた、彼に神をさして誓わせたネブカデネザル王にもそむいた。彼は強情で、その心をかたくなにして、イスラエルの神、主に立ち返らなかった。</span>
<span className="v" id="v14" data-v="14" data-xref="ダニエル書 9:8; エゼキエル書 22:6; ミカ書 3:9–11"> 祭司のかしらたちおよび民らもまた、すべて異邦人のもろもろの憎むべき行為にならって、はなはだしく罪を犯し、主がエルサレムに聖別しておかれた主の宮を汚した。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="エレミヤ書 35:15; エレミヤ書 7:13; エレミヤ書 25:3–4"> その先祖の神、主はその民と、すみかをあわれむがゆえに、しきりに、その使者を彼らにつかわされたが、</span>
<span className="v" id="v16" data-v="16" data-xref="エレミヤ書 5:12–13; 歴代志下 30:10; ルカによる福音書 22:63–64"> 彼らが神の使者たちをあざけり、その言葉を軽んじ、その預言者たちをののしったので、主の怒りがその民に向かって起り、ついに救うことができないようになった。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="詩篇 74:20; エズラ記 9:7; エゼキエル書 9:5–7"> そこで主はカルデヤびとの王を彼らに攻めこさせられたので、彼はその聖所の家でつるぎをもって若者たちを殺し、若者をも、処女をも、老人をも、しらがの者をもあわれまなかった。主は彼らをことごとく彼の手に渡された。</span>
<span className="v" id="v18" data-v="18" data-xref="歴代志下 36:7; 歴代志下 36:10; イザヤ書 39:6"> 彼は神の宮のもろもろの大小の器物、主の宮の貨財、王とそのつかさたちの貨財など、すべてこれをバビロンに携えて行き、</span>
<span className="v" id="v19" data-v="19" data-xref="詩篇 79:1; 列王紀上 9:8; エレミヤ書 52:13–15"> 神の宮を焼き、エルサレムの城壁をくずし、そのうちの宮殿をことごとく火で焼き、そのうちの尊い器物をことごとくこわした。</span>
<span className="v" id="v20" data-v="20" data-xref="エレミヤ書 27:7; エズラ記 1:1–11; 歴代志下 36:22"> 彼はまたつるぎをのがれた者どもを、バビロンに捕えて行って、彼とその子らの家来となし、ペルシャの国の興るまで、そうして置いた。</span>
<span className="v" id="v21" data-v="21" data-xref="エレミヤ書 29:10; レビ記 26:34–35; ゼカリヤ書 1:12"> これはエレミヤの口によって伝えられた主の言葉の成就するためであった。こうして国はついにその安息をうけた。すなわちこれはその荒れている間、安息して、ついに七十年が満ちた。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="エレミヤ書 25:12; エズラ記 1:1–3; エレミヤ書 29:10"> ペルシャ王クロスの元年に当り、主はエレミヤの口によって伝えた主の言葉を成就するため、ペルシャ王クロスの霊を感動されたので、王はあまねく国中にふれ示し、またそれを書き示して言った、</span>
<span className="v" id="v23" data-v="23" data-xref="イザヤ書 44:26–28; エズラ記 7:13; ローマ人への手紙 8:31"> 「ペルシャの王クロスはこう言う、『天の神、主は地上の国々をことごとくわたしに賜わって、主の宮をユダにあるエルサレムに建てることをわたしに命じられた。あなたがたのうち、その民である者は皆、その神、主の助けを得て上って行きなさい』」。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歴代志上 29:25; 列王紀上 2:12; 創世記 39:2"> ダビデの子ソロモンはその国に自分の地位を確立した。その神、主が共にいまして彼を非常に大いなる者にされた。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="歴代志上 28:1; 歴代志上 27:1; 歴代志下 30:2"> ソロモンはすべてのイスラエルびと、すなわち千人の長、百人の長、さばきびとおよびイスラエルの全地のすべてのつかさ、氏族のかしらたちに告げた。</span>
<span className="v" id="v3" data-v="3" data-xref="歴代志上 21:29; 歴代志上 16:39; レビ記 1:1"> そしてソロモンとイスラエルの全会衆はともにギベオンにある高き所へ行った。主のしもべモーセが荒野で造った神の会見の幕屋がそこにあったからである。</span>
<span className="v" id="v4" data-v="4" data-xref="サムエル記下 6:17; 歴代志上 15:25–28; サムエル記下 6:2"> （しかし神の箱はダビデがすでにキリアテ・ヤリムから、これのために備えた所に運び上らせてあった。ダビデはさきに、エルサレムでこれのために天幕を張って置いたからである。）</span>
<span className="v" id="v5" data-v="5" data-xref="出エジプト記 31:2; 出エジプト記 38:1–7; 歴代志上 2:19–20"> またホルの子であるウリの子ベザレルが造った青銅の祭壇がその所の主の幕屋の前にあり、ソロモンおよび会衆は主に求めた。</span>
<span className="v" id="v6" data-v="6" data-xref="列王紀上 3:4; 列王紀上 8:63; 歴代志上 29:21"> ソロモンはそこに上って行って、会見の幕屋のうちにある主の前の青銅の祭壇に燔祭一千をささげた。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="マタイによる福音書 7:7–8; ヨハネの第一の手紙 5:14–15; ヨハネによる福音書 16:23"> その夜、神はソロモンに現れて言われた、「あなたに何を与えようか、求めなさい」。</span>
<span className="v" id="v8" data-v="8" data-xref="歴代志上 28:5; イザヤ書 55:3; サムエル記下 22:51–1"> ソロモンは神に言った、「あなたはわたしの父ダビデに大いなるいつくしみを示し、またわたしを彼に代って王とされました。</span>
<span className="v" id="v9" data-v="9" data-xref="サムエル記下 7:12–16; 創世記 13:16; 詩篇 132:11–12"> 主なる神よ、どうぞわが父ダビデに約束された事を果してください。あなたは地のちりのような多くの民の上にわたしを立てて王とされたからです。</span>
<span className="v" id="v10" data-v="10" data-xref="列王紀上 3:9; 箴言 4:7; 箴言 2:2–6"> この民の前に出入りすることのできるように今わたしに知恵と知識とを与えてください。だれがこのような大いなるあなたの民をさばくことができましょうか」。</span>
<span className="v" id="v11" data-v="11" data-xref="ヤコブの手紙 3:17; 箴言 23:7; サムエル記上 16:7"> 神はソロモンに言われた、「この事があなたの心にあって、富をも、宝をも、誉をも、またあなたを憎む者の命をも求めず、また長命をも求めず、ただわたしがあなたを立てて王としたわたしの民をさばくために知恵と知識とを自分のために求めたので、</span>
<span className="v" id="v12" data-v="12" data-xref="ヤコブの手紙 1:5; 歴代志下 9:22; マタイによる福音書 6:33"> 知恵と知識とはあなたに与えられている。わたしはまたあなたの前の王たちの、まだ得たことのないほどの富と宝と誉とをあなたに与えよう。あなたの後の者も、このようなものを得ないでしょう」。</span>
<span className="v" id="v13" data-v="13" data-xref="歴代志下 1:3; 列王紀上 4:24–25"> それからソロモンはギベオンの高き所を去り、会見の幕屋の前を去って、エルサレムに帰り、イスラエルを治めた。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="列王紀上 4:26; 列王紀上 10:26–29; 歴代志下 9:25"> ソロモンは戦車と騎兵とを集めたが、戦車一千四百両、騎兵一万二千人あった。ソロモンはこれを戦車の町々と、エルサレムの王のもととに置いた。</span>
<span className="v" id="v15" data-v="15" data-xref="歴代志下 9:27; イザヤ書 9:10; 列王紀上 10:27–29"> 王は銀と金を石のようにエルサレムに多くし、香柏を平野のいちじく桑のように多くした。</span>
<span className="v" id="v16" data-v="16" data-xref="歴代志下 9:28; 列王紀上 10:28–29"> ソロモンが馬を輸入したのはエジプトとクエからであった。すなわち王の貿易商人がクエから代価を払って受け取って来た。</span>
<span className="v" id="v17" data-v="17" data-xref="列王紀下 10:29"> 彼らはエジプトから戦車一両を銀六百シケルで輸入し、馬一頭を銀百五十で輸入した。同じようにこれらのものが彼らによってヘテびとのすべての王たち、およびスリヤの王たちにも輸出された。</span>
</div>

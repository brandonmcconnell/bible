<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="詩篇 18:8–11; レビ記 16:2; 出エジプト記 20:21"> そこでソロモンは言った、<br /><span className="pl pl-1">「主はみずから濃き雲の中に住まおうと言われた。</span></span>
<span className="v" id="v2" data-v="2" data-xref="歴代志下 2:4–6; 詩篇 135:21; 歴代志上 28:6"> <span className="pl pl-1">しかしわたしはあなたのために高き家、</span><br /><span className="pl pl-1">とこしえのみすまいを建てた」。</span></span>
<span className="v" id="v3" data-v="3" data-xref="列王紀上 8:14; 歴代志下 29:29; 列王紀上 8:55–61"> <span className="pl pl-1">そして王は顔をふり向けてイスラエルの全会衆を祝福した。その時イスラエルの全会衆は立っていた。</span></span>
<span className="v" id="v4" data-v="4" data-xref="詩篇 72:18–19; マタイによる福音書 24:35; 詩篇 68:32–35"> <span className="pl pl-1">彼は言った、「イスラエルの神、主はほむべきかな。主は口をもってわが父ダビデに約束されたことを、その手をもってなし遂げられた。すなわち主は言われた、</span></span>
<span className="v" id="v5" data-v="5" data-xref="出エジプト記 20:24; 列王紀上 8:16; サムエル記上 13:13–14"> <span className="pl pl-1">『わが民をエジプトの地から導き出した日から、わたしはわが名を置くべき家を建てるために、イスラエルのもろもろの部族のうちから、どの町をも選んだことがなく、また他のだれをもわが民イスラエルの君として選んだことがない。</span></span>
<span className="v" id="v6" data-v="6" data-xref="歴代志上 28:4; 詩篇 132:13; 歴代志下 12:13"> <span className="pl pl-1">わが名を置くために、ただエルサレムだけを選び、またわが民イスラエルを治めさせるために、ただダビデだけを選んだ』。</span></span>
<span className="v" id="v7" data-v="7" data-xref="歴代志上 17:1; 列王紀上 5:3; 歴代志上 22:7"> <span className="pl pl-1">イスラエルの神、主の名のために家を建てることは、父ダビデの心にあった。</span></span>
<span className="v" id="v8" data-v="8" data-xref="コリント人への第二の手紙 8:12; マルコによる福音書 14:8; 列王紀上 8:18–21"> <span className="pl pl-1">しかし主は父ダビデに言われた、『わたしの名のために家を建てることはあなたの心にあった。あなたの心にこの事のあったのは結構である。</span></span>
<span className="v" id="v9" data-v="9" data-xref="サムエル記下 7:12–13; 歴代志上 17:4; 歴代志上 17:11–12"> <span className="pl pl-1">しかしあなたはその家を建ててはならない。あなたの腰から出るあなたの子がわたしの名のために家を建てるであろう』。</span></span>
<span className="v" id="v10" data-v="10" data-xref="伝道の書 1:4; 歴代志上 28:5; 歴代志上 17:11"> <span className="pl pl-1">そして主はそう言われた言葉を行われた。すなわちわたしは父ダビデに代って立ち、主が言われたように、イスラエルの位に座し、イスラエルの神、主の名のために家を建てた。</span></span>
<span className="v" id="v11" data-v="11" data-xref="歴代志下 5:10; 歴代志下 5:7; 列王紀上 8:21"> <span className="pl pl-1">わたしはまた、主がイスラエルの人々と結ばれた主の契約を入れた箱をそこに納めた」。</span></span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="詩篇 63:4; イザヤ書 50:10; ヨブ記 11:13"> ソロモンはイスラエルの全会衆の前、主の祭壇の前に立って、手を伸べた。</span>
<span className="v" id="v13" data-v="13" data-xref="列王紀上 8:54; ネヘミヤ書 8:4; 詩篇 95:6"> ソロモンはさきに長さ五キュビト、幅五キュビト、高さ三キュビトの青銅の台を造って、庭のまん中にすえて置いたので、彼はその上に立ち、イスラエルの全会衆の前でひざをかがめ、その手を天に伸べて、</span>
<span className="v" id="v14" data-v="14" data-xref="出エジプト記 15:11; 申命記 7:9; ネヘミヤ書 1:5"> 言った、「イスラエルの神、主よ、天にも地にも、あなたのような神はありません。あなたは契約を守られ、心をつくしてあなたの前に歩むあなたのしもべらに、いつくしみを施し、</span>
<span className="v" id="v15" data-v="15" data-xref="歴代志上 22:9–10; サムエル記下 7:12; 列王紀上 8:24"> あなたのしもべ、わたしの父ダビデに約束されたことを守られました。あなたが口をもって約束されたことを、手をもってなし遂げられたことは、今日見るとおりであります。</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀上 2:4; ヨハネによる福音書 15:14–15; 歴代志下 7:18"> それゆえ、イスラエルの神、主よ、あなたのしもべ、わたしの父ダビデに、あなたが約束して、『おまえがわたしの前に歩んだように、おまえの子孫がその道を慎んで、わたしのおきてに歩むならば、おまえにはイスラエルの位に座する人がわたしの前に欠けることはない』と言われたことを、ダビデのためにお守りください。</span>
<span className="v" id="v17" data-v="17" data-xref="エレミヤ書 11:5; イザヤ書 41:17; 歴代志下 6:4"> それゆえ、イスラエルの神、主よ、どうぞ、あなたのしもべダビデに言われた言葉を確認してください。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="歴代志下 2:6; イザヤ書 66:1; 詩篇 139:7–10"> しかし神は、はたして人と共に地上に住まわれるでしょうか。見よ、天も、いと高き天もあなたをいれることはできません。わたしの建てたこの家などなおさらです。</span>
<span className="v" id="v19" data-v="19" data-xref="列王紀上 8:28; ルカによる福音書 18:1–7; ヨハネによる福音書 17:20"> しかしわが神、主よ、しもべの祈と願いを顧みて、しもべがあなたの前にささげる叫びと祈をお聞きください。</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 34:15; ダニエル書 6:10; 詩篇 121:5"> どうぞ、あなたの目を昼も夜もこの家に、すなわち、あなたの名をそこに置くと言われた所に向かってお開きください。どうぞ、しもべがこの所に向かってささげる祈をお聞きください。</span>
<span className="v" id="v21" data-v="21" data-xref="ミカ書 7:18; ダニエル書 9:19; イザヤ書 43:25"> どうぞ、しもべと、あなたの民イスラエルがこの所に向かって祈る時に、その願いをお聞きください。あなたのすみかである天から聞き、聞いておゆるしください。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="出エジプト記 22:11; レビ記 5:1; 民数記 5:19–22"> もし人がその隣り人に対して罪を犯し、誓いをすることを求められるとき、来てこの宮で、あなたの祭壇の前に誓うならば、</span>
<span className="v" id="v23" data-v="23" data-xref="イザヤ書 3:10–11; 箴言 17:15; エレミヤ書 51:56"> あなたは天から聞いて、行い、あなたのしもべらをさばき、悪人に報いをなして、その行いの報いをそのこうべに帰し、義人を義として、その義にしたがってその人に報いてください。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="レビ記 26:17; 列王紀下 17:7–18; ヨシュア記 7:8"> もしあなたの民イスラエルが、あなたに対して罪を犯したために、敵の前に敗れた時、あなたに立ち返って、あなたの名をあがめ、この宮であなたの前に祈り願うならば、</span>
<span className="v" id="v25" data-v="25" data-xref="エレミヤ書 33:6–13; エズラ記 1:1–6; 創世記 13:15"> あなたは天から聞き、あなたの民イスラエルの罪をゆるして、あなたが彼らとその先祖に与えられた地に彼らを帰らせてください。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="申命記 28:23; 申命記 11:17; レビ記 26:19"> もし彼らがあなたに罪を犯したために、天が閉ざされて、雨がなく、あなたが彼らを苦しめられるとき、彼らがこの所に向かって祈り、あなたの名をあがめ、その罪を離れるならば、</span>
<span className="v" id="v27" data-v="27" data-xref="列王紀上 8:35–36; エレミヤ書 5:24; ゼカリヤ書 10:1"> あなたは天にあって聞き、あなたのしもべ、あなたの民イスラエルの罪をゆるして、彼らに歩むべき良い道を教え、あなたの民に嗣業として賜わった地に雨を降らせてください。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="ヨハネの黙示録 9:3–11; ヨエル書 2:25; ルツ記 1:1"> もし国にききんがあるか、もしくは疫病、立ち枯れ、腐り穂、いなご、青虫があるか、または敵のために町の門の中に攻め囲まれることがあるか、どんな災害、どんな病気があっても、</span>
<span className="v" id="v29" data-v="29" data-xref="詩篇 50:15; 詩篇 32:2–6; 歴代志下 6:12–13"> もし、ひとりか、あるいはあなたの民イスラエルが皆おのおのその心の悩みを知って、この宮に向かい、手を伸べるならば、どんな祈、どんな願いでも、</span>
<span className="v" id="v30" data-v="30" data-xref="歴代志上 28:9; サムエル記上 16:7; ヨハネの黙示録 2:23"> あなたはそのすみかである天から聞いてゆるし、おのおのの人に、その心を知っておられるゆえ、そのすべての道にしたがって報いてください。ただあなただけがすべての人の心を知っておられるからです。</span>
<span className="v" id="v31" data-v="31" data-xref="使徒行伝 9:31; ヨブ記 28:28; 詩篇 128:1"> あなたがわれわれの先祖たちに賜わった地に、彼らの生きながらえる日の間、常にあなたを恐れさせ、あなたの道に歩ませてください。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="イザヤ書 56:3–7; 列王紀上 8:41–43; マタイによる福音書 8:10–11"> またあなたの民イスラエルの者でなく、他国人で、あなたの大いなる名と、強い手と、伸べた腕のために遠い国から来て、この宮に向かって祈るならば、</span>
<span className="v" id="v33" data-v="33" data-xref="歴代志下 7:14; 列王紀上 8:16; ヨハネの黙示録 11:15"> あなたは、あなたのすみかである天から聞き、すべて他国人があなたに呼び求めるようにしてください。そうすれば地のすべての民はあなたの民イスラエルのように、あなたの名を知り、あなたを恐れ、またわたしが建てたこの宮が、あなたの名によって呼ばれることを知るにいたるでしょう。</span>
</div>
<div className="bp poetry">
<span className="v" id="v34" data-v="34" data-xref="歴代志下 20:6–13; 歴代志下 18:31; 歴代志下 20:4"> あなたの民が敵と戦うために、あなたがつかわされる道によって出るとき、もし彼らがあなたの選ばれたこの町と、わたしがあなたの名のために建てたこの宮に向かってあなたに祈るならば、</span>
<span className="v" id="v35" data-v="35" data-xref="ダニエル書 9:17–19; 詩篇 9:3–4; エレミヤ書 5:28"> あなたは天から彼らの祈と願いとを聞いて彼らをお助けください。</span>
<span className="v" id="v36" data-v="36" data-xref="伝道の書 7:20; ヤコブの手紙 3:2; ヨハネの第一の手紙 1:8–10"> 彼らがあなたに対して罪を犯すことがあって、――罪を犯さない人はないゆえ、――あなたが彼らを怒って、敵にわたし、敵が彼らを捕虜として遠い地あるいは近い地に引いて行くとき、</span>
<span className="v" id="v37" data-v="37" data-xref="エレミヤ書 31:18–20; ダニエル書 9:5–11; イザヤ書 64:6–12"> もし、彼らが捕われて行った地で、みずから省みて悔い、その捕われの地であなたに願い、『われわれは罪を犯し、よこしまな事をし、悪を行いました』と言い、</span>
<span className="v" id="v38" data-v="38" data-xref="歴代志下 33:11–13; ダニエル書 6:10; ダニエル書 9:3–4"> その捕われの地で心をつくし、精神をつくしてあなたに立ち返り、あなたが彼らの先祖に与えられた地、あなたが選ばれた町、わたしがあなたの名のために建てたこの宮に向かって祈るならば、</span>
<span className="v" id="v39" data-v="39" data-xref="ミカ書 7:18–20; 歴代志下 6:35; 詩篇 25:18"> あなたのすみかである天から、彼らの祈と願いとを聞いて彼らを助け、あなたに向かって罪を犯したあなたの民をおゆるしください。</span>
<span className="v" id="v40" data-v="40" data-xref="歴代志下 7:15; 詩篇 116:2; ネヘミヤ書 1:6"> わが神よ、どうぞ、この所でささげる祈にあなたの目を開き、あなたの耳を傾けてください。</span>
<span className="v" id="v41" data-v="41" data-xref="イザヤ書 61:10; 歴代志上 28:2; 詩篇 132:8–10"> <span className="pl pl-1">主なる神よ、今あなたと、あなたの力の箱が</span><br /><span className="pl pl-1">立って、あなたの安息所におはいりください。</span><br /><span className="pl pl-1">主なる神よ、どうぞあなたの祭司たちに</span><br /><span className="pl pl-1">救の衣を着せ、</span><br /><span className="pl pl-1">あなたの聖徒たちに恵みを喜ばせてください。</span></span>
<span className="v" id="v42" data-v="42" data-xref="イザヤ書 55:3; 詩篇 132:1; イザヤ書 61:1"> <span className="pl pl-1">主なる神よ、どうぞあなたの油そそがれた者の顔を</span><br /><span className="pl pl-1">退けないでください。</span><br /><span className="pl pl-1">あなたのしもべダビデに示されたいつくしみを</span><br /><span className="pl pl-1">覚えて下さい」。</span></span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ゼパニヤ書 1:1; エレミヤ書 1:2; 歴代志下 33:25"> ヨシヤは八歳のとき王となり、エルサレムで三十一年の間世を治めた。</span>
<span className="v" id="v2" data-v="2" data-xref="歴代志下 29:2; ヨシュア記 1:7; 列王紀下 22:2"> 彼は主の良しと見られることをなし、その父ダビデの道を歩んで、右にも左にも曲らなかった。</span>
<span className="v" id="v3" data-v="3" data-xref="歴代志下 33:22; 歴代志下 15:2; 箴言 8:17"> 彼はまだ若かったが、その治世の第八年に父ダビデの神を求めることを始め、その十二年には高き所、アシラ像、刻んだ像、鋳た像などを除いて、ユダとエルサレムを清めることを始め、</span>
<span className="v" id="v4" data-v="4" data-xref="出エジプト記 32:20; レビ記 26:30; 列王紀下 23:4–6"> もろもろのバアルの祭壇を、自分の前で打ちこわさせ、その上に立っていた香の祭壇を切り倒し、アシラ像、刻んだ像、鋳た像を打ち砕いて粉々にし、これらの像に犠牲をささげた者どもの墓の上にそれをまき散らし、</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀上 13:2; エレミヤ書 3:10; 民数記 35:33"> 祭司らの骨をそのもろもろの祭壇の上で焼き、こうしてユダとエルサレムを清めた。</span>
<span className="v" id="v6" data-v="6" data-xref="サムエル記上 13:20–21; イザヤ書 7:25; 歴代志下 30:1"> またマナセ、エフライム、シメオンおよびナフタリの荒れた町々にもこのようにし、</span>
<span className="v" id="v7" data-v="7" data-xref="歴代志下 31:1; 申命記 9:21; 歴代志下 34:1"> もろもろの祭壇をこわし、アシラ像およびもろもろの刻んだ像を粉々に打ち砕き、イスラエル全国の香の祭壇をことごとく切り倒して、エルサレムに帰った。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="サムエル記下 8:16; 歴代志上 18:15; エレミヤ書 29:25"> ヨシヤはその治世の十八年に、国と宮とを清めた時、その神、主の宮を繕わせようと、アザリヤの子シャパン、町のつかさマアセヤおよびヨアハズの子史官ヨアをつかわした。</span>
<span className="v" id="v9" data-v="9" data-xref="歴代志下 30:18; 歴代志下 30:10; 歴代志下 35:8"> 彼らは大祭司ヒルキヤのもとへ行って、神の宮にはいった金を渡した。これは門を守るレビびとがマナセ、エフライムおよびその他のすべてのイスラエル、ならびにユダとベニヤミンのすべての人、およびエルサレムの住民の手から集めたものである。</span>
<span className="v" id="v10" data-v="10" data-xref="列王紀下 12:11–12; エズラ記 3:7; 列王紀下 22:5–6"> 彼らはこれを主の宮を監督する職工らの手に渡したので、主の宮で働く職工らは、これを宮を繕い直すために支払った。</span>
<span className="v" id="v11" data-v="11" data-xref="歴代志下 33:4–7; 歴代志下 33:22"> すなわち、大工および建築者にこれを渡して、ユダの王たちが破った建物のために、切り石および骨組の材木を買わせ、梁材を整えさせた。</span>
<span className="v" id="v12" data-v="12" data-xref="列王紀下 12:15; 歴代志上 23:5; 列王紀下 22:7"> その人々は忠実に仕事をした。その監督者はメラリの子孫であるレビびとヤハテとオバデヤ、およびコハテびとの子孫であるゼカリヤとメシュラムであって、工事をつかさどった。また楽器に巧みなレビびとがこれに伴った。</span>
<span className="v" id="v13" data-v="13" data-xref="ネヘミヤ書 4:10; 歴代志下 2:18; エレミヤ書 8:8"> 彼らはまた荷を負う者を監督し、様々の仕事に働くすべての者をつかさどった。また他のレビびとは書記となり、役人となり、また門衛となった。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="レビ記 8:36; 詩篇 1:2; レビ記 10:11"> さて彼らが主の宮にはいった金を取りだした時、祭司ヒルキヤはモーセの伝えた主の律法の書を発見した。</span>
<span className="v" id="v15" data-v="15"> そこでヒルキヤは書記官シャパンに言った、「わたしは主の宮で律法の書を発見しました」と。そしてヒルキヤはその書をシャパンに渡した。</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀下 22:9–10; エレミヤ書 36:20–21"> シャパンはその書を王のもとに持って行き、さらに王に復命して言った、「しもべらはゆだねられた事をことごとくなし、</span>
<span className="v" id="v17" data-v="17"> 主の宮にあった金をあけて、監督者の手および職工の手に渡しました」。</span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 119:46; エレミヤ書 36:20–21; 申命記 17:19"> 書記官シャパンはまた王に告げて、「祭司ヒルキヤはわたしに一つの書物を渡しました」と言い、シャパンはそれを王の前で読んだ。</span>
<span className="v" id="v19" data-v="19" data-xref="ヨシュア記 7:6; 申命記 28:3–68; 列王紀下 22:19"> 王はその律法の言葉を聞いて衣を裂いた。</span>
<span className="v" id="v20" data-v="20" data-xref="列王紀下 22:12; エレミヤ書 26:24; エレミヤ書 40:9"> そして王はヒルキヤおよびシャパンの子アヒカムとミカの子アブドンと書記官シャパンと王の家来アサヤとに命じて言った、</span>
<span className="v" id="v21" data-v="21" data-xref="エレミヤ書 21:2; エゼキエル書 14:1–11; 歴代志下 28:6"> 「あなたがたは行って、この発見された書物の言葉についてわたしのために、またイスラエルとユダの残りの者のために主に問いなさい。われわれの先祖たちが主の言葉を守らず、すべてこの書物にしるされていることを行わなかったので、主はわれわれに大いなる怒りを注がれるからです」。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="ルカによる福音書 2:36; 出エジプト記 15:20; 列王紀下 22:14"> そこでヒルキヤおよび王のつかわした人々は、シャルムの妻である女預言者ホルダのもとへ行った。シャルムはハスラの子であるトクハテの子で、衣装を守る者である。時にホルダは、エルサレムの第二区に住んでいた。彼らはホルダにその趣意を語ったので、</span>
<span className="v" id="v23" data-v="23" data-xref="エレミヤ書 37:7–10; エレミヤ書 21:3–7; 列王紀下 22:15–20"> ホルダは彼らに言った、「イスラエルの神、主はこう仰せられます、『あなたがたをわたしにつかわした人に告げなさい。</span>
<span className="v" id="v24" data-v="24" data-xref="歴代志下 36:14–20; ヨシュア記 23:16; 申命記 28:15–68"> 主はこう仰せられます。見よ、わたしはユダの王の前で読んだ書物にしるされているもろもろののろい、すなわち災をこの所と、ここに住む者に下す。</span>
<span className="v" id="v25" data-v="25" data-xref="エレミヤ書 7:20; マルコによる福音書 9:43–48; ナホム書 1:6"> 彼らはわたしを捨てて、他の神々に香をたき、自分の手で造ったもろもろの物をもって、わたしの怒りを引き起そうとしたからである。それゆえ、わたしの怒りは、この所に注がれて消えない。</span>
<span className="v" id="v26" data-v="26" data-xref="歴代志下 34:23; 歴代志下 34:21"> しかしあなたがたをつかわして、主に問わせるユダの王にはこう言いなさい。イスラエルの神、主はこう仰せられる。あなたが聞いた言葉については、</span>
<span className="v" id="v27" data-v="27" data-xref="歴代志下 32:26; エゼキエル書 9:4; 詩篇 34:18"> この所と、ここに住む者を責める神の言葉を、あなたが聞いた時、心に悔い、神の前に身をひくくし、わたしの前にへりくだり、衣を裂いて、わたしの前に泣いたので、わたしもまた、あなたに聞いた、と主は言われる。</span>
<span className="v" id="v28" data-v="28" data-xref="イザヤ書 39:8; 詩篇 37:37; 列王紀上 21:29"> 見よ、わたしはあなたを先祖たちのもとに集める。あなたは安らかにあなたの墓に集められる。あなたはわたしがこの所と、ここに住む者に下すもろもろの災を目に見ることがない』と」。彼らは王に復命した。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="列王紀下 23:1–3; 歴代志下 30:2; マルコによる福音書 14:8"> そこで王は人をつかわしてユダとエルサレムの長老をことごとく集め、</span>
<span className="v" id="v30" data-v="30" data-xref="出エジプト記 24:7; 列王紀下 23:2; 歴代志下 34:15"> そして王は主の宮に上って行った。ユダのすべての人々、エルサレムの住民、祭司、レビびと、およびすべての民は、老いた者も若い者もことごとく彼に従った。そこで王は主の宮で発見した契約の書の言葉を、ことごとく彼らの耳に読み聞かせ、</span>
<span className="v" id="v31" data-v="31" data-xref="歴代志下 23:16; 列王紀下 23:3; 列王紀下 11:14"> そして王は自分の所に立って、主の前に契約を立て、主に従って歩み、心をつくし、精神をつくして、その戒めと、あかしと定めとをまもり、この書にしるされた契約の言葉を行おうと言い、</span>
<span className="v" id="v32" data-v="32" data-xref="歴代志下 30:12; エレミヤ書 3:10; 歴代志下 14:4"> エルサレムおよびベニヤミンの人々を皆これに加わらせた。エルサレムの住民は先祖の神であるその神の契約にしたがって行った。</span>
<span className="v" id="v33" data-v="33" data-xref="歴代志下 34:3–7; ヨシュア記 24:31; 列王紀下 23:4–20"> ヨシヤはイスラエルの人々に属するすべての地から、憎むべきものをことごとく取り除き、イスラエルにいるすべての人をその神、主に仕えさせた。ヨシヤが世にある日の間は、彼らは先祖の神、主に従って離れなかった。</span>
</div>

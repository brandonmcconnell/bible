<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀下 18:1–3; 歴代志上 3:13; 歴代志下 26:5"> ヒゼキヤは王となった時二十五歳で、二十九年の間エルサレムで世を治めた。その母はアビヤと言って、ゼカリヤの娘である。</span>
<span className="v" id="v2" data-v="2" data-xref="歴代志下 34:2; 歴代志下 28:1"> ヒゼキヤは父ダビデがすべてなしたように主の良しと見られることをした。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="歴代志下 28:24; 歴代志下 29:7; マタイによる福音書 6:33"> 彼はその治世の第一年の一月に主の宮の戸を開き、かつこれを繕った。</span>
<span className="v" id="v4" data-v="4" data-xref="エレミヤ書 19:2; ネヘミヤ書 3:29; 歴代志下 32:6"> 彼は祭司とレビびとを連れていって、東の広場に集め、</span>
<span className="v" id="v5" data-v="5" data-xref="歴代志下 35:6; コリント人への第一の手紙 3:16–17; 歴代志下 34:3–8"> 彼らに言った、「レビびとよ、聞きなさい。あなたがたは今、身を清めて、あなたがたの先祖の神、主の宮を清め、聖所から汚れを除き去りなさい。</span>
<span className="v" id="v6" data-v="6" data-xref="エゼキエル書 8:16; エレミヤ書 2:27; ダニエル書 9:16"> われわれの先祖は罪を犯し、われわれの神、主の悪と見られることを行って、主を捨て、主のすまいに顔をそむけ、うしろを向けた。</span>
<span className="v" id="v7" data-v="7" data-xref="歴代志下 28:24; レビ記 24:2–8; 歴代志下 29:3"> また廊の戸を閉じ、ともしびを消し、聖所でイスラエルの神に香をたかず、燔祭をささげなかった。</span>
<span className="v" id="v8" data-v="8" data-xref="エレミヤ書 25:9; エレミヤ書 25:18; エレミヤ書 29:18"> それゆえ、主の怒りはユダとエルサレムに臨み、あなたがたが目に見るように、主は彼らを恐れと驚きと物笑いにされた。</span>
<span className="v" id="v9" data-v="9" data-xref="歴代志下 28:17; 歴代志下 28:5–8; 哀歌 5:7"> 見よ、われわれの父たちはつるぎにたおれ、われわれのむすこたち、むすめたち、妻たちはこれがために捕虜となった。</span>
<span className="v" id="v10" data-v="10" data-xref="エレミヤ書 50:5; 歴代志下 23:16; エズラ記 10:3"> 今わたしは、イスラエルの神、主と契約を結ぶ志をもっている。そうすればその激しい怒りは、われわれを離れるであろう。</span>
<span className="v" id="v11" data-v="11" data-xref="申命記 10:8; ガラテヤ人への手紙 6:7–8; 民数記 8:6–14"> わが子らよ、今は怠ってはならない。主はあなたがたを選んで、主の前に立って仕えさせ、ご自分に仕える者となし、また香をたく者とされたからである」。</span>
<span className="v" id="v12" data-v="12" data-xref="民数記 3:19–20; 歴代志上 15:5–7; 民数記 4:2–20"> そこでレビびとは立ち上がった。すなわちコハテびとの子孫のうちでは、アマサイの子マハテおよびアザリヤの子ヨエル。メラリの子孫では、アブデの子キシおよびエハレレルの子アザリヤ。ゲルションびとのうちでは、ジンマの子ヨアおよびヨアの子エデン。</span>
<span className="v" id="v13" data-v="13" data-xref="歴代志上 6:39; 歴代志上 15:8; 歴代志上 15:17"> エリザパンの子孫のうちでは、シムリとエイエル。アサフの子孫のうちでは、ゼカリヤとマッタニヤ。</span>
<span className="v" id="v14" data-v="14" data-xref="歴代志上 6:33; 歴代志上 25:1; 歴代志上 25:6"> ヘマンの子孫のうちでは、エヒエルとシメイ。エドトンの子孫のうちでは、シマヤとウジエルである。</span>
<span className="v" id="v15" data-v="15" data-xref="歴代志下 30:12; 歴代志上 23:28; 歴代志下 29:5"> 彼らはその兄弟たちを集めて身を清め、主の言葉による王の命令に従って、主の宮を清めるためにはいって来た。</span>
<span className="v" id="v16" data-v="16" data-xref="歴代志下 15:16; マタイによる福音書 21:12–13; マタイによる福音書 23:27"> 祭司たちが主の宮の奥にはいってこれを清め、主の宮にあった汚れた物をことごとく主の宮の庭に運び出すと、レビびとはそれを受けて外に出し、キデロン川に持って行った。</span>
<span className="v" id="v17" data-v="17" data-xref="出エジプト記 12:2–8; 歴代志下 3:4; 列王紀上 6:3"> 彼らは正月の元日に清めることを始めて、その月の八日に主の宮の廊に達した。それから主の宮を清めるのに八日を費し、正月の十六日にこれを終った。</span>
<span className="v" id="v18" data-v="18" data-xref="歴代志下 4:1; 歴代志下 4:7–8; 歴代志下 13:11"> そこで彼らはヒゼキヤ王の所へ行って言った、「われわれは主の宮をことごとく清め、また燔祭の壇とそのすべての器物、および供えのパンの机とそのすべての器物とを清めました。</span>
<span className="v" id="v19" data-v="19" data-xref="歴代志下 28:24"> またアハズ王がその治世に罪を犯して捨てたすべての器物をも整えて清めました。それらは主の祭壇の前にあります」。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="ヨシュア記 6:12; エレミヤ書 25:4; 出エジプト記 24:4"> そこでヒゼキヤ王は朝早く起きいで、町のつかさたちを集めて、主の宮に上って行き、</span>
<span className="v" id="v21" data-v="21" data-xref="レビ記 4:3–14; ヨブ記 42:8; エゼキエル書 45:23"> 雄牛七頭、雄羊七頭、小羊七頭、雄やぎ七頭を引いてこさせ、国と聖所とユダのためにこれを罪祭とし、アロンの子孫である祭司たちに命じてこれを主の祭壇の上にささげさせた。</span>
<span className="v" id="v22" data-v="22" data-xref="レビ記 4:18; レビ記 8:19; レビ記 8:24"> すなわち、雄牛をほふると、祭司たちはその血を受けて祭壇にふりかけ、また雄羊をほふると、その血を祭壇にふりかけ、また小羊をほふると、その血を祭壇にふりかけた。</span>
<span className="v" id="v23" data-v="23" data-xref="レビ記 4:15; レビ記 4:24; レビ記 1:4"> そして罪祭の雄やぎを王と会衆の前に引いて来たので、彼らはその上に手を置いた。</span>
<span className="v" id="v24" data-v="24" data-xref="レビ記 14:20; エゼキエル書 45:15; コリント人への第二の手紙 5:18–21"> そして祭司たちはこれをほふり、その血を罪祭として祭壇の上にささげてイスラエル全国のためにあがないをした。これは王がイスラエル全国のために燔祭および罪祭をささげることを命じたためである。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="歴代志下 8:14; 歴代志上 23:5; サムエル記下 24:11"> 王はまたレビびとを主の宮に置き、ダビデおよび王の先見者ガドと預言者ナタンの命令に従って、これにシンバル、立琴および琴をとらせた。これは主がその預言者によって命じられたところである。</span>
<span className="v" id="v26" data-v="26" data-xref="歴代志上 23:5; 歴代志上 15:24; アモス書 6:5"> こうしてレビびとはダビデの楽器をとり、祭司はラッパをとって立った。</span>
<span className="v" id="v27" data-v="27" data-xref="歴代志下 23:18; 詩篇 137:3–4; 歴代志下 20:21"> そこでヒゼキヤは燔祭を祭壇の上にささげることを命じた。燔祭をささげ始めた時、主の歌をうたい、ラッパを吹き、イスラエルの王ダビデの楽器をならし始めた。</span>
<span className="v" id="v28" data-v="28" data-xref="ヨハネの黙示録 5:8–14; 詩篇 89:15; 詩篇 68:24–26"> そして会衆は皆礼拝し、歌うたう者は歌をうたい、ラッパ手はラッパを吹き鳴らし、燔祭が終るまですべてこのようであったが、</span>
<span className="v" id="v29" data-v="29" data-xref="歴代志下 20:18; 歴代志上 29:20; ピリピ人への手紙 2:10–11"> ささげる事が終ると、王および彼と共にいた者はみな身をかがめて礼拝した。</span>
<span className="v" id="v30" data-v="30" data-xref="ピリピ人への手紙 4:4; 詩篇 95:1–2; 歴代志上 16:7–36"> またヒゼキヤ王およびつかさたちはレビびとに命じて、ダビデと先見者アサフの言葉をもって主をさんびさせた。彼らは喜んでさんびし、頭をさげて礼拝した。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="歴代志下 13:9; 出エジプト記 35:22; レビ記 7:12"> その時、ヒゼキヤは言った、「あなたがたはすでに主に仕えるために身を清めたのであるから、進みよって、主の宮に犠牲と感謝の供え物を携えて来なさい」と。そこで会衆は犠牲と感謝の供え物を携えて来た。また志ある者は皆燔祭を携えて来た。</span>
<span className="v" id="v32" data-v="32" data-xref="エズラ記 6:17; 列王紀上 3:4; 歴代志上 29:21"> 会衆の携えて来た燔祭の数は雄牛七十頭、雄羊百頭、小羊二百頭、これらは皆主に燔祭としてささげるものであった。</span>
<span className="v" id="v33" data-v="33"> また奉納物は牛六百頭、小羊三千頭であった。</span>
<span className="v" id="v34" data-v="34" data-xref="歴代志下 35:11; 歴代志下 30:3; 詩篇 94:15"> ところが祭司が少なくてその燔祭の物の皮を、はぎつくすことができなかったので、その兄弟であるレビびとがこれを助けて、そのわざをなし終え、その間に他の祭司たちは身を清めた。これはレビびとが祭司たちよりも、身を清めることに、きちょうめんであったからである。</span>
<span className="v" id="v35" data-v="35" data-xref="民数記 15:5–10; 出エジプト記 29:13; 歴代志上 16:37–42"> このほかおびただしい燔祭があり、また、酬恩祭の脂肪および燔祭の灌祭もあった。こうして、主の宮の勤めは回復された。</span>
<span className="v" id="v36" data-v="36" data-xref="使徒行伝 2:41; テサロニケ人への第一の手紙 3:8–9; 歴代志上 29:9"> この事は、にわかになされたけれども、神がこのように民のために備えをされたので、ヒゼキヤおよびすべての民は喜んだ。</span>
</div>

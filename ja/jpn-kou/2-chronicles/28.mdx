<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歴代志上 3:13; イザヤ書 1:1; 列王紀下 16:1–20"> アハズは王となった時二十歳で、十六年の間エルサレムで世を治めたが、その父ダビデとは違って、主の良しと見られることを行わず、</span>
<span className="v" id="v2" data-v="2" data-xref="出エジプト記 34:17; 士師記 2:11; 歴代志下 22:3–4"> イスラエルの王たちの道に歩み、またもろもろのバアルのために鋳た像を造り、</span>
<span className="v" id="v3" data-v="3" data-xref="歴代志下 33:2; 歴代志下 33:6; レビ記 18:21"> ベンヒンノムの谷で香をたき、その子らを火に焼いて供え物とするなど、主がイスラエルの人々の前から追い払われた異邦人の憎むべき行いにならい、</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀下 16:4; 申命記 12:2–3; レビ記 26:30"> また高き所の上、丘の上、すべての青木の下で犠牲をささげ、香をたいた。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="イザヤ書 7:1; 歴代志下 24:24; 列王紀下 16:5–6"> それゆえ、その神、主は彼をスリヤの王の手に渡されたので、スリヤびとは彼を撃ち破り、その民を多く捕虜として、ダマスコに引いて行った。彼はまたイスラエルの王の手にも渡されたので、イスラエルの王も彼を撃ち破って大いに殺した。</span>
<span className="v" id="v6" data-v="6" data-xref="列王紀下 15:27; ヨシュア記 24:20; エレミヤ書 15:6"> すなわちレマリヤの子ペカはユダで一日のうちに十二万人を殺した。皆勇士であった。これは彼らがその先祖の神、主を捨てたためである。</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 43:15; 創世記 41:43; エステル記 10:3"> その時、エフライムの勇士ジクリという者が王の子マアセヤ、宮内大臣アズリカムおよび王に次ぐ人エルカナを殺した。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="歴代志下 11:4; 申命記 28:25; 申命記 28:41"> イスラエルの人々はついにその兄弟のうちから婦人ならびに男子、女子など二十万人を捕虜にし、また多くのぶんどり物をとり、そのぶんどり物をサマリヤに持って行った。</span>
<span className="v" id="v9" data-v="9" data-xref="イザヤ書 47:6; エズラ記 9:6; ヨハネの黙示録 18:5"> その時そこに名をオデデという主の預言者があって、サマリヤに帰って来た軍勢の前に進み出て言った、「見よ、あなたがたの先祖の神、主はユダを怒って、これをあなたがたの手に渡されたが、あなたがたは天に達するほどの怒りをもってこれを殺した。</span>
<span className="v" id="v10" data-v="10" data-xref="レビ記 25:39–46; マタイによる福音書 7:2–4; エレミヤ書 25:29"> そればかりでなく、あなたがたは今、ユダとエルサレムの人々を従わせて、自分の男女の奴隷にしようと思っている。しかしあなたがた自身もまた、あなたがたの神、主に罪を犯しているではないか。</span>
<span className="v" id="v11" data-v="11" data-xref="ヤコブの手紙 2:13; エズラ記 10:14; マタイによる福音書 5:7"> いまわたしに聞き、あなたがたがその兄弟のうちから捕えて来た捕虜を放ち帰らせなさい。主の激しい怒りがあなたがたの上に臨んでいるからです」。</span>
<span className="v" id="v12" data-v="12" data-xref="歴代志上 28:1; エレミヤ書 26:6"> そこでエフライムびとのおもなる人々、すなわちヨハナンの子アザリヤ、メシレモテの子ベレキヤ、シャルムの子ヒゼキヤ、ハデライの子アマサらもまた、戦争から帰った者どもに向かって立ちあがり、</span>
<span className="v" id="v13" data-v="13" data-xref="民数記 32:14; マタイによる福音書 23:32; ヨシュア記 22:17–18"> 彼らに言った、「捕虜をここに引き入れてはならない。あなたがたはわたしどもに主に対するとがを得させて、さらにわれわれの罪とがを増し加えようとしている。われわれのとがは大きく、激しい怒りがイスラエルの上に臨んでいるからです」。</span>
<span className="v" id="v14" data-v="14"> そこで兵卒どもがその捕虜とぶんどり物をつかさたちと全会衆の前に捨てておいたので、</span>
<span className="v" id="v15" data-v="15" data-xref="箴言 25:21–22; 申命記 34:3; 士師記 1:16"> 前に名をあげた人々が立って捕虜を受け取り、ぶんどり物のうちから衣服をとって、裸の者に着せ、また、くつをはかせ、食い飲みさせ、油を注ぎなどし、その弱い者を皆ろばに乗せ、こうして彼らをしゅろの町エリコに連れて行って、その兄弟たちに渡し、そしてサマリヤに帰って来た。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="列王紀下 16:5–7; イザヤ書 7:17; イザヤ書 7:1–9"> その時アハズ王は人をアッスリヤの王につかわして助けを求めさせた。</span>
<span className="v" id="v17" data-v="17" data-xref="オバデヤ書 1:10; オバデヤ書 1:13–14; レビ記 26:18"> エドムびとが再び侵入してユダを撃ち、民を捕え去ったからである。</span>
<span className="v" id="v18" data-v="18" data-xref="エゼキエル書 16:57; エゼキエル書 16:27; サムエル記上 6:9"> ペリシテびともまた平野の町々およびユダのネゲブの町々を侵して、ベテシメシ、アヤロン、ゲデロテおよびソコとその村里、テムナとその村里、ギムゾとその村里を取って、そこに住んだ。</span>
<span className="v" id="v19" data-v="19" data-xref="歴代志下 21:2; ヨブ記 40:12; 申命記 28:43"> これはイスラエルの王アハズのゆえに、主がユダを低くされたのであって、彼がユダのうちにみだらなことを行い、主に向かって大いに罪を犯したからである。</span>
<span className="v" id="v20" data-v="20" data-xref="列王紀下 15:29; 歴代志上 5:26; イザヤ書 30:16"> アッスリヤの王テルガデ・ピルネセルは彼の所に来たが、彼に力を添えないで、かえって彼を悩ました。</span>
<span className="v" id="v21" data-v="21" data-xref="列王紀下 16:8–9; 列王紀下 18:15–16; 歴代志下 12:9"> アハズは主の宮と王の家、およびつかさたちの家の物を取ってアッスリヤの王に与えたが、それはアハズの助けにはならなかった。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="イザヤ書 1:5; エゼキエル書 21:13; エレミヤ書 5:3"> このアハズ王はその悩みの時にあたって、ますます主に罪を犯した。</span>
<span className="v" id="v23" data-v="23" data-xref="歴代志下 25:14; エレミヤ書 44:20–28; ハバクク書 1:11"> すなわち、彼は自分を撃ったダマスコの神々に、犠牲をささげて言った、「スリヤの王たちの神々はその王たちを助けるから、わたしもそれに犠牲をささげよう。そうすれば彼らはわたしを助けるであろう」と。しかし、彼らはかえってアハズとイスラエル全国とを倒す者となった。</span>
<span className="v" id="v24" data-v="24" data-xref="歴代志下 29:7; 列王紀下 16:17–18; 歴代志下 30:14"> アハズは神の宮の器物を集めて、神の宮の器物を切り破り、主の宮の戸を閉じ、エルサレムのすべてのすみずみに祭壇を造り、</span>
<span className="v" id="v25" data-v="25" data-xref="歴代志下 28:3"> ユダのすべての町々に高き所を造って、他の神々に香をたきなどして、先祖の神、主の怒りを引き起した。</span>
<span className="v" id="v26" data-v="26" data-xref="列王紀下 16:19–20; 歴代志下 20:34; 歴代志下 27:7–9"> アハズのその他の始終の行為およびそのすべての行動は、ユダとイスラエルの列王の書にしるされている。</span>
<span className="v" id="v27" data-v="27" data-xref="歴代志下 21:20; 歴代志下 24:25; 箴言 10:7"> アハズはその先祖たちと共に眠ったので、エルサレムの町にこれを葬った。しかし、イスラエルの王たちの墓には持って行かなかった。その子ヒゼキヤが彼に代って王となった。</span>
</div>

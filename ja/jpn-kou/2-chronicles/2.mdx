<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀上 5:5; 歴代志上 22:10; 列王紀上 7:1"> さてソロモンは主の名のために一つの宮を建て、また自分のために一つの王宮を建てようと思った。</span>
<span className="v" id="v2" data-v="2" data-xref="歴代志下 2:18; 列王紀上 5:15–16"> そしてソロモンは荷を負う者七万人、山で石を切り出す者八万人、これらを監督する者三千六百人を数え出した。</span>
<span className="v" id="v3" data-v="3" data-xref="歴代志上 14:1; サムエル記下 5:11; 列王紀上 5:1–11"> ソロモンはまずツロのヒラムに人をつかわして言わせた、「あなたはわたしの父ダビデに、その住むべき家を建てるために香柏を送られました。どうぞ彼にされたように、わたしにもして下さい。</span>
<span className="v" id="v4" data-v="4" data-xref="出エジプト記 30:7; 出エジプト記 25:30; 歴代志下 2:1"> 見よ、わたしはわが神、主の名のために一つの家を建て、これを聖別して彼にささげ、彼の前にこうばしい香をたき、常供のパンを供え、また燔祭を安息日、新月、およびわれらの神、主の定めの祭に朝夕ささげ、これをイスラエルのながく守るべき定めにしようとしています。</span>
<span className="v" id="v5" data-v="5" data-xref="歴代志上 16:25; 出エジプト記 15:11; 詩篇 135:5"> またわたしの建てる家は大きな家です。われらの神はすべての神よりも大いなる神だからです。</span>
<span className="v" id="v6" data-v="6" data-xref="イザヤ書 66:1; 歴代志下 6:18; 列王紀上 8:27"> しかし、天も、諸天の天も彼を入れることができないのに、だれが彼のために家を建てることができましょうか。わたしは何者ですか、彼のために家を建てるというのも、ただ彼の前に香をたく所に、ほかならないのです。</span>
<span className="v" id="v7" data-v="7" data-xref="歴代志下 2:13–14; 歴代志上 22:15–16; 出エジプト記 31:3–5"> それで、どうぞ金、銀、青銅、鉄の細工および紫糸、緋糸、青糸の織物にくわしく、また彫刻の術に巧みな工人ひとりをわたしに送って、父ダビデが備えておいたユダとエルサレムのわたしの工人たちと一緒に働かせてください。</span>
<span className="v" id="v8" data-v="8" data-xref="列王紀上 5:6; 列王紀上 10:11; 歴代志下 9:10–11"> またどうぞレバノンから香柏、いとすぎ、びゃくだんを送ってください。わたしはあなたのしもべたちがレバノンで木を切ることをよくわきまえているのを知っています。わたしのしもべたちも、あなたのしもべたちと一緒に働かせ、</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀上 9:8; 歴代志下 2:5; 歴代志下 7:21"> わたしのためにたくさんの材木を備えさせてください。わたしの建てる家は非常に広大なものですから。</span>
<span className="v" id="v10" data-v="10" data-xref="列王紀上 5:11; エズラ記 7:22; ローマ人への手紙 13:7–8"> わたしは木を切るあなたのしもべたちに砕いた小麦二万コル、大麦二万コル、ぶどう酒二万バテ、油二万バテを与えます」。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="列王紀上 10:9; 歴代志下 9:8; 詩篇 72:17"> そこでツロの王ヒラムは手紙をソロモンに送って答えた、「主はその民を愛するゆえに、あなたを彼らの王とされました」。</span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 33:6; ペテロの第一の手紙 1:3; ヨハネの黙示録 4:11"> ヒラムはまた言った、「天地を造られたイスラエルの神、主はほむべきかな。彼はダビデ王に賢い子を与え、これに分別と知恵を授けて、主のために宮を建て、また自分のために、王宮を建てることをさせられた。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="歴代志下 4:16"> いまわたしは達人ヒラムという知恵のある工人をつかわします。</span>
<span className="v" id="v14" data-v="14" data-xref="歴代志下 2:7; 出エジプト記 31:3–4; 列王紀上 7:13–14"> 彼はダンの子孫である女を母とし、ツロの人を父とし、金銀、青銅、鉄、石、木の細工および紫糸、青糸、亜麻糸、緋糸の織物にくわしく、またよくもろもろの彫刻をし、意匠を凝らしてもろもろの工作をします。彼を用いてあなたの工人およびあなたの父、わが主ダビデの工人と一緒に働かせなさい。</span>
<span className="v" id="v15" data-v="15" data-xref="歴代志下 2:10; 列王紀上 5:11"> それでいまわが主の言われた小麦、大麦、油およびぶどう酒をそのしもべどもに送ってください。</span>
<span className="v" id="v16" data-v="16" data-xref="ヨシュア記 19:46; 列王紀上 5:8–9; エズラ記 3:7"> あなたの求められる材木はレバノンから切りだし、いかだに組んで、海からヨッパに送ります。あなたはそれをエルサレムに運び上げなさい」。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="歴代志上 22:2; 列王紀上 5:13–16; 歴代志下 8:7–8"> そこでソロモンはその父ダビデが数えたようにイスラエルの国にいるすべての他国人を数えたが、合わせて十五万三千六百人あった。</span>
<span className="v" id="v18" data-v="18" data-xref="歴代志下 2:2"> 彼はその七万人を荷を負う者とし、八万人を山で木や石を切る者とし、三千六百人を民を働かせる監督者とした。</span>
</div>

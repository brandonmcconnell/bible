<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="コリント人への第一の手紙 5:7–8; 歴代志下 11:13; ホセア書 5:4"> ヒゼキヤはイスラエルとユダにあまねく人をつかわし、また手紙をエフライムとマナセに書き送り、エルサレムにある主の宮に来て、イスラエルの神、主に過越の祭を行うように勧めた。</span>
<span className="v" id="v2" data-v="2" data-xref="民数記 9:10–11; 歴代志上 13:1–3; 歴代志下 30:13"> 王はすでにつかさたちおよびエルサレムにおる全会衆に計って、二月に過越の祭を行うことを定めた。</span>
<span className="v" id="v3" data-v="3" data-xref="歴代志下 29:34; 出エジプト記 12:6; 出エジプト記 12:18"> ――これは身を清めた祭司の数が足らず、民もまた、エルサレムに集まらなかったので、正月にこれを行うことができなかったからである――</span>
<span className="v" id="v4" data-v="4" data-xref="歴代志上 13:4"> この事が、王にも全会衆にも良かったので、</span>
<span className="v" id="v5" data-v="5" data-xref="士師記 20:1; レビ記 23:2; エステル記 8:8–10"> この事を定めて、ベエルシバからダンまでイスラエルにあまねくふれ示し、エルサレムに来て、イスラエルの神、主に過越の祭を行うことを勧めた。これはしるされているように、これを行う者が多くなかったゆえである。</span>
<span className="v" id="v6" data-v="6" data-xref="エレミヤ書 51:31; エステル記 8:14; 列王紀下 15:19"> そこで飛脚たちは、王とそのつかさたちから受けた手紙をもって、イスラエルとユダをあまねく行き巡り、王の命を伝えて言った、「イスラエルの人々よ、あなたがたはアブラハム、イサク、イスラエルの神、主に立ち返りなさい。そうすれば主は、アッスリヤの王たちの手からのがれた残りのあなたがたに、帰られるでしょう。</span>
<span className="v" id="v7" data-v="7" data-xref="歴代志下 29:8; エゼキエル書 20:13–18; ゼカリヤ書 1:3–4"> あなたがたの父たちおよび兄弟たちのようになってはならない。彼らはその先祖たちの神、主にむかって罪を犯したので、あなたがたの見るように主は彼らを滅びに渡されたのです。</span>
<span className="v" id="v8" data-v="8" data-xref="出エジプト記 32:9; 歴代志下 29:10; 申命記 10:16"> あなたがたの父たちのように強情にならないで、主に帰服し、主がとこしえに聖別された聖所に入り、あなたがたの神、主に仕えなさい。そうすれば、その激しい怒りがあなたがたを離れるでしょう。</span>
<span className="v" id="v9" data-v="9" data-xref="イザヤ書 55:7; ミカ書 7:18; 詩篇 86:5"> もしあなたがたが主に立ち返るならば、あなたがたの兄弟および子供は、これを捕えていった者の前にあわれみを得て、この国に帰ることができるでしょう。あなたがたの神、主は恵みあり、あわれみある方であられるゆえ、あなたがたが彼に立ち返るならば、顔をあなたがたにそむけられることはありません」。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="歴代志下 36:16; 歴代志下 30:6; ネヘミヤ書 2:19"> このように飛脚たちは、エフライムとマナセの国にはいって、町から町に行き巡り、ついに、ゼブルンまで行ったが、人々はこれをあざけり笑った。</span>
<span className="v" id="v11" data-v="11" data-xref="歴代志下 30:18; 歴代志下 30:21; 歴代志下 30:25"> ただしアセル、マナセ、ゼブルンのうちには身を低くして、エルサレムにきた人々もあった。</span>
<span className="v" id="v12" data-v="12" data-xref="エレミヤ書 32:39; エレミヤ書 24:7; ピリピ人への手紙 2:13"> またユダにおいては神の手が人々に一つ心を与えて、王とつかさたちが主の言葉によって命じたことを行わせた。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="歴代志下 30:2; 詩篇 84:7"> こうして二月になって、多くの民は、種入れぬパンの祭を行うためエルサレムに集まったが、非常に大きな会衆であった。</span>
<span className="v" id="v14" data-v="14" data-xref="歴代志下 28:24; サムエル記下 15:23; 歴代志下 15:16"> 彼らは立ってエルサレムにあるもろもろの祭壇を取り除き、またすべての香をたく祭壇を取り除いてキデロン川に投げすて、</span>
<span className="v" id="v15" data-v="15" data-xref="歴代志下 29:34; 歴代志下 5:11; 出エジプト記 19:22"> 二月の十四日に過越の小羊をほふった。そこで祭司たちおよびレビびとはみずから恥じ、身を清めて主の宮に燔祭を携えて来た。</span>
<span className="v" id="v16" data-v="16" data-xref="申命記 33:1; 歴代志下 35:15; 列王紀下 11:14"> 彼らは神の人モーセの律法に従い、いつものようにその所に立ち、祭司たちは、レビびとの手から血を受けて注いだ。</span>
<span className="v" id="v17" data-v="17" data-xref="歴代志下 29:34; 歴代志下 35:3–6; 出エジプト記 12:6"> 時に、会衆のうちにまだ身を清めていない者が多かったので、レビびとはその清くないすべての人々に代って過越の小羊をほふり、主に清めてささげた。</span>
<span className="v" id="v18" data-v="18" data-xref="コリント人への第一の手紙 11:28; ヤコブの手紙 5:15–16; ダニエル書 9:19"> 多くの民すなわちエフライム、マナセ、イッサカル、ゼブルンからきた多くの者はまだ身を清めていないのに、書きしるされたとおりにしないで過越の物を食べた。それでヒゼキヤは、彼らのために祈って言った、「恵みふかき主よ、彼らをゆるしてください。</span>
<span className="v" id="v19" data-v="19" data-xref="歴代志下 19:3; 箴言 23:26; ヨブ記 11:13"> 彼らは聖所の清めの規定どおりにしなかったけれども、その心を傾けて神を求め、その先祖の神、主を求めたのです」。</span>
<span className="v" id="v20" data-v="20" data-xref="出エジプト記 15:26; ヤコブの手紙 5:15–16; 詩篇 103:3"> 主はヒゼキヤに聞いて、民をいやされた。</span>
<span className="v" id="v21" data-v="21" data-xref="出エジプト記 12:15; 出エジプト記 13:6; 申命記 12:12"> そこでエルサレムに来ていたイスラエルの人々は大いなる喜びをいだいて、七日のあいだ種入れぬパンの祭を行った。またレビびとと祭司たちは日々に主をさんびし、力をつくして主をたたえた。</span>
<span className="v" id="v22" data-v="22" data-xref="歴代志下 32:6; ネヘミヤ書 9:3; イザヤ書 40:1–2"> そしてヒゼキヤは主の勤めによく通じているすべてのレビびとを深くねぎらった。こうして人々は酬恩祭の犠牲をささげ、その先祖の神、主に感謝して、七日のあいだ祭の供え物を食べた。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="列王紀上 8:65; 歴代志下 7:9"> なお全会衆は相はかって、さらに七日のあいだ祭を守ることを定め、喜びをもってまた七日のあいだ守った。</span>
<span className="v" id="v24" data-v="24" data-xref="歴代志下 29:34; 歴代志下 35:7–8; エペソ人への手紙 4:8"> 時にユダの王ヒゼキヤは雄牛一千頭、羊七千頭を会衆に贈り、また、つかさたちは雄牛一千頭、羊一万頭を会衆に贈った。祭司もまた多く身を清めた。</span>
<span className="v" id="v25" data-v="25" data-xref="歴代志下 30:11; 歴代志下 30:18; 歴代志上 16:10–11"> ユダの全会衆および祭司、レビびと、ならびにイスラエルからきた全会衆、およびイスラエルの地からきた他国人と、ユダに住む他国人は皆喜んだ。</span>
<span className="v" id="v26" data-v="26" data-xref="歴代志下 7:8–10"> このようにエルサレムに大いなる喜びがあった。イスラエルの王ダビデの子ソロモンの時からこのかた、このような事はエルサレムになかった。</span>
<span className="v" id="v27" data-v="27" data-xref="申命記 26:15; 詩篇 68:5; 民数記 6:23–26"> このとき祭司たちとレビびとは立って、民を祝福したが、その声は聞かれ、その祈は主の聖なるすみかである天に達した。</span>
</div>

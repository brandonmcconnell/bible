<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命記 23:3–5; ネヘミヤ書 9:3; ネヘミヤ書 13:23"> その日モーセの書を読んで民に聞かせたが、その中にアンモンびと、およびモアブびとは、いつまでも神の会に、はいってはならないとしるされているのを見いだした。</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 23:5; ヨシュア記 24:9–10; 民数記 23:8–11"> これは彼らがかつて、パンと水をもってイスラエルの人々を迎えず、かえってこれをのろわせるためにバラムを雇ったからである。しかしわれわれの神はそののろいを変えて祝福とされた。</span>
<span className="v" id="v3" data-v="3" data-xref="ネヘミヤ書 9:2; 出エジプト記 12:38; 民数記 11:4"> 人々はこの律法を聞いた時、混血の民をことごとくイスラエルから分け離した。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="ネヘミヤ書 12:44; ネヘミヤ書 6:17–18; ネヘミヤ書 13:28"> これより先、われわれの神の宮のへやをつかさどっていた祭司エリアシブは、トビヤと縁組したので、</span>
<span className="v" id="v5" data-v="5" data-xref="ネヘミヤ書 12:44; 歴代志下 34:11; 民数記 18:21–24"> トビヤのために大きなへやを備えた。そのへやはもと、素祭の物、乳香、器物および規定によってレビびと、歌うたう者および門を守る者たちに与える穀物、ぶどう酒、油の十分の一、ならびに祭司のためのささげ物を置いた所である。</span>
<span className="v" id="v6" data-v="6" data-xref="ネヘミヤ書 5:14; ネヘミヤ書 2:5–6; マタイによる福音書 13:25"> その当時、わたしはエルサレムにいなかった。わたしはバビロンの王アルタシャスタの三十二年に王の所へ行ったが、しばらくたって王にいとまを請い、</span>
<span className="v" id="v7" data-v="7" data-xref="ネヘミヤ書 13:5; マタイによる福音書 21:12–13; 哀歌 1:10"> エルサレムに来て、エリアシブがトビヤのためにした悪事、すなわち彼のために神の宮の庭に一つのへやを備えたことを発見した。</span>
<span className="v" id="v8" data-v="8" data-xref="マルコによる福音書 11:15–17; エズラ記 10:1; 詩篇 69:9"> わたしは非常に怒り、トビヤの家の器物をことごとくそのへやから投げだし、</span>
<span className="v" id="v9" data-v="9" data-xref="歴代志下 29:5; 歴代志下 29:15–19; ネヘミヤ書 12:45"> 命じて、すべてのへやを清めさせ、そして神の宮の器物および素祭、乳香などを再びそこに携え入れた。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="ネヘミヤ書 10:37; マラキ書 3:8; マラキ書 1:6–14"> わたしはまたレビびとがその受くべき分を与えられていなかったことを知った。これがためにその務をなすレビびとおよび歌うたう者たちは、おのおの自分の畑に逃げ帰った。</span>
<span className="v" id="v11" data-v="11" data-xref="ネヘミヤ書 10:39; ネヘミヤ書 13:17; ネヘミヤ書 13:25"> それでわたしはつかさたちを責めて言った、「なぜ神の宮を捨てさせたのか」。そしてレビびとを招き集めて、その持ち場に復帰させた。</span>
<span className="v" id="v12" data-v="12" data-xref="ネヘミヤ書 10:37–39; マラキ書 3:10; ネヘミヤ書 12:44"> そこでユダの人々は皆、穀物、ぶどう酒、油の十分の一を倉に携えてきた。</span>
<span className="v" id="v13" data-v="13" data-xref="列王紀下 22:7; ネヘミヤ書 7:2; ネヘミヤ書 12:44"> わたしは祭司シレミヤ、学者ザドクおよびレビびとペダヤを倉のつかさとし、またマッタニヤの子ザックルの子ハナンをその助手として倉をつかさどらせた。彼らは忠実な者と思われたからである。彼らの任務は兄弟たちに分配する事であった。</span>
<span className="v" id="v14" data-v="14" data-xref="詩篇 122:6–9; ネヘミヤ書 13:22; ネヘミヤ書 13:31"> わが神よ、この事のためにわたしを覚えてください。わが神の宮とその勤めのためにわたしが行った良きわざをぬぐい去らないでください。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="ネヘミヤ書 10:31; ネヘミヤ書 13:21; 出エジプト記 34:21"> そのころわたしはユダのうちで安息日に酒ぶねを踏む者、麦束を持ってきて、ろばに負わす者、またぶどう酒、ぶどう、いちじくおよびさまざまの荷を安息日にエルサレムに運び入れる者を見たので、わたしは彼らが食物を売っていたその日に彼らを戒めた。</span>
<span className="v" id="v16" data-v="16" data-xref="出エジプト記 23:12; 申命記 5:14"> そこに住んでいたツロの人々もまた魚およびさまざまの品物を持ってきて、安息日にユダの人々に売り、エルサレムで商売した。</span>
<span className="v" id="v17" data-v="17" data-xref="ネヘミヤ書 13:11; ネヘミヤ書 13:25; イザヤ書 1:10"> そこでわたしはユダの尊い人々を責めて言った、「あなたがたはなぜこの悪事を行って、安息日を汚すのか。</span>
<span className="v" id="v18" data-v="18" data-xref="エレミヤ書 17:21–23; エレミヤ書 44:9; 民数記 32:14"> あなたがたの先祖も、このように行ったので、われわれの神はこのすべての災を、われわれとこの町に下されたではないか。ところがあなたがたは安息日を汚して、さらに大いなる怒りをイスラエルの上に招くのである」。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="レビ記 23:32; 出エジプト記 31:14–17; エレミヤ書 17:19–22"> そこで安息日の前に、エルサレムのもろもろの門が暗くなり始めた時、わたしは命じてそのとびらを閉じさせ、安息日が終るまでこれを開いてはならないと命じ、わたしのしもべ数人を門に置いて、安息日に荷を携え入れさせないようにした。</span>
<span className="v" id="v20" data-v="20"> これがために、商人およびさまざまの品物を売る者どもは一、二回エルサレムの外に宿った。</span>
<span className="v" id="v21" data-v="21" data-xref="ローマ人への手紙 13:3–4; ペテロの第一の手紙 2:14; エズラ記 7:26"> わたしは彼らを戒めて言った、「あなたがたはなぜ城壁の前に宿るのか。もしあなたがたが重ねてそのようなことをするならば、わたしはあなたがたを処罰する」と。そのとき以来、彼らは安息日にはこなかった。</span>
<span className="v" id="v22" data-v="22" data-xref="ネヘミヤ書 12:30; ネヘミヤ書 13:14; ネヘミヤ書 13:31"> わたしはまたレビびとに命じて、その身を清めさせ、来て門を守らせて、安息日を聖別した。わが神よ、わたしのためにまた、このことを覚え、あなたの大いなるいつくしみをもって、わたしをあわれんでください。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="エズラ記 9:1–2; エズラ記 10:10; ネヘミヤ書 10:30"> そのころまた、わたしはアシドド、アンモン、モアブの女をめとったユダヤ人を見た。</span>
<span className="v" id="v24" data-v="24" data-xref="ゼパニヤ書 3:9"> 彼らの子供の半分はアシドドの言葉を語って、ユダヤの言葉を語ることができず、おのおのその母親の出た民の言葉を語った。</span>
<span className="v" id="v25" data-v="25" data-xref="申命記 7:3; ネヘミヤ書 13:17; ネヘミヤ書 10:29–30"> わたしは彼らを責め、またののしり、そのうちの数人を撃って、その毛を抜き、神の名をさして誓わせて言った、「あなたがたは彼らのむすこに自分の娘を与えてはならない。またあなたがたのむすこ、またはあなたがた自身のために彼らの娘をめとってはならない。</span>
<span className="v" id="v26" data-v="26" data-xref="列王紀上 11:1–8; 列王紀上 3:13; 伝道の書 7:26"> イスラエルの王ソロモンはこれらのことによって罪を犯したではないか。彼のような王は多くの国民のうちにもなく、神に愛せられた者である。神は彼をイスラエル全国の王とせられた。ところが異邦の女たちは彼に罪を犯させた。</span>
<span className="v" id="v27" data-v="27" data-xref="エズラ記 10:2; サムエル記上 30:24"> それゆえあなたがたが異邦の女をめとり、このすべての大いなる悪を行って、われわれの神に罪を犯すのを、われわれは聞き流しにしておけようか」。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="ネヘミヤ書 2:19; ネヘミヤ書 3:1; ネヘミヤ書 12:22"> 大祭司エリアシブの子ヨイアダのひとりの子はホロニびとサンバラテの婿であったので、わたしは彼をわたしのところから追い出した。</span>
<span className="v" id="v29" data-v="29" data-xref="ネヘミヤ書 6:14; 民数記 25:12–13; マラキ書 2:4–8"> わが神よ、彼らのことを覚えてください。彼らは祭司の職を汚し、また祭司およびレビびとの契約を汚しました。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="ネヘミヤ書 10:30; ネヘミヤ書 12:1–26; 歴代志上 23:1–26"> このように、わたしは彼らを清めて、異邦のものをことごとく捨てさせ、祭司およびレビびとの務を定めて、おのおのそのわざにつかせた。</span>
<span className="v" id="v31" data-v="31" data-xref="ネヘミヤ書 13:14; ネヘミヤ書 13:22; 詩篇 106:4"> また定められた時に、たきぎの供え物をささげさせ、また初物をささげさせた。わが神よ、わたしを覚え、わたしをお恵みください。</span>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ネヘミヤ書 12:39; エレミヤ書 31:38; ヨハネによる福音書 5:2"> かくて大祭司エリアシブは、その兄弟である祭司たちと共に立って羊の門を建て、これを聖別してそのとびらを設け、さらにこれを聖別して、ハンメアの望楼に及ぼし、またハナネルの望楼にまで及ぼした。</span>
<span className="v" id="v2" data-v="2" data-xref="ネヘミヤ書 7:36; エズラ記 2:34; ネヘミヤ書 10:12"> 彼の次にはエリコの人々が建て、その次にはイムリの子ザックルが建てた。</span>
<span className="v" id="v3" data-v="3" data-xref="歴代志下 33:14; ネヘミヤ書 12:39; ゼパニヤ書 1:10"> 魚の門はハッセナアの子らが建て、その梁を置き、そのとびらと横木と貫の木とを設けた。</span>
<span className="v" id="v4" data-v="4" data-xref="エズラ記 8:33; ネヘミヤ書 3:21; ネヘミヤ書 10:7"> その次にハッコヅの子ウリヤの子メレモテが修理し、その次にメシザベルの子ベレキヤの子メシュラムが修理し、その次にバアナの子ザドクが修理した。</span>
<span className="v" id="v5" data-v="5" data-xref="ネヘミヤ書 3:27; サムエル記下 14:2; エレミヤ書 27:2"> その次にテコアびとらが修理したが、その貴人たちはその主の工事に服さなかった。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="ネヘミヤ書 12:39"> 古い門はパセアの子ヨイアダおよびベソデヤの子メシュラムがこれを修理し、その梁を置き、そのとびらと横木と貫の木とを設けた。</span>
<span className="v" id="v7" data-v="7" data-xref="サムエル記下 21:2; ヨシュア記 9:3–27; ネヘミヤ書 3:19"> その次にギベオンびとメラテヤ、メロノテびとヤドン、および川向こうの州の知事の行政下にあるギベオンとミヅパの人々が修理した。</span>
<span className="v" id="v8" data-v="8" data-xref="ネヘミヤ書 12:38; ネヘミヤ書 3:31–32; 創世記 50:2"> その次にハルハヤの子ウジエルなどの金細工人が修理し、その次に製香者のひとりハナニヤが修理した。こうして彼らはエルサレムを城壁の広い所まで復旧した。</span>
<span className="v" id="v9" data-v="9" data-xref="ネヘミヤ書 3:12; ネヘミヤ書 3:17"> その次にエルサレムの半区域の知事ホルの子レパヤが修理し、</span>
<span className="v" id="v10" data-v="10" data-xref="ネヘミヤ書 3:28–30; ネヘミヤ書 10:4; ネヘミヤ書 3:23"> その次にハルマフの子エダヤが自分の家と向かい合っている所を修理し、その次にはハシャブニヤの子ハットシが修理した。</span>
<span className="v" id="v11" data-v="11" data-xref="ネヘミヤ書 12:38; エズラ記 2:6; ネヘミヤ書 10:14"> ハリムの子マルキヤおよびバハテ・モアブの子ハシュブも他の部分および炉の望楼を修理した。</span>
<span className="v" id="v12" data-v="12" data-xref="ネヘミヤ書 3:9; 使徒行伝 21:8–9; 出エジプト記 35:25"> その次にエルサレムの他の半区域の知事ハロヘシの子シャルムがその娘たちと共に修理した。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="ネヘミヤ書 2:13; ヨシュア記 15:34; 歴代志下 26:9"> 谷の門はハヌンがザノアの民と共にこれを修理し、これを建て直して、そのとびらと横木と貫の木とを設け、また糞の門まで城壁一千キュビトを修理した。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="エレミヤ書 6:1; ネヘミヤ書 2:13; ネヘミヤ書 3:12–13"> 糞の門はベテ・ハケレムの区域の知事レカブの子マルキヤがこれを修理し、これを建て直して、そのとびらと横木と貫の木とを設けた。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="ヨハネによる福音書 9:7; イザヤ書 8:6; ネヘミヤ書 12:37"> 泉の門はミヅパの区域の知事コロホゼの子シャルンがこれを修理し、これを建て直して、おおいを施し、そのとびらと横木と貫の木とを設けた。彼はまた王の園のほとりのシラの池に沿った石がきを修理して、ダビデの町から下る階段にまで及んだ。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行伝 2:29; ネヘミヤ書 3:9; 列王紀下 20:20"> その後にベテズルの半区域の知事アズブクの子ネヘミヤが修理して、ダビデの墓と向かい合った所に及び、掘池と勇士の宅にまで及んだ。</span>
<span className="v" id="v17" data-v="17" data-xref="ヨシュア記 15:44; ネヘミヤ書 3:16; サムエル記上 23:1–13"> その後にバニの子レホムなどのレビびとが修理し、その次にケイラの半区域の知事ハシャビヤがその区域のために修理した。</span>
<span className="v" id="v18" data-v="18"> その後にケイラの半区域の知事ヘナダデの子バワイなどその兄弟たちが修理し、</span>
<span className="v" id="v19" data-v="19" data-xref="歴代志下 26:9; ネヘミヤ書 10:9; ネヘミヤ書 12:8"> その次にエシュアの子でミヅパの知事であるエゼルが、城壁の曲りかどにある武器倉に上る所と向かい合った他の部分を修理し、</span>
<span className="v" id="v20" data-v="20" data-xref="ネヘミヤ書 3:1; 伝道の書 9:10; ローマ人への手紙 12:11"> その後にザバイの子バルクが、力をつくして城壁の曲りかどから大祭司エリアシブの家の門までの他の部分を修理し、</span>
<span className="v" id="v21" data-v="21" data-xref="ネヘミヤ書 7:63; エズラ記 2:61"> その後にハッコヅの子ウリヤの子メレモテが、エリアシブの家の門からエリアシブの家の端までの他の部分を修理し、</span>
<span className="v" id="v22" data-v="22" data-xref="ネヘミヤ書 12:28; ネヘミヤ書 6:2"> 彼の後に低地の人々である祭司たちが修理し、</span>
<span className="v" id="v23" data-v="23" data-xref="ネヘミヤ書 10:2; ネヘミヤ書 8:4; ネヘミヤ書 3:29–30"> その後にベニヤミンおよびハシュブが、自分たちの家と向かい合っている所を修理し、その後にアナニヤの子マアセヤの子アザリヤが、自分の家の附近を修理し、</span>
<span className="v" id="v24" data-v="24" data-xref="ネヘミヤ書 3:19; ネヘミヤ書 3:27; ネヘミヤ書 10:9"> その後にヘナダデの子ビンヌイが、アザリヤの家から城壁の曲りかど、およびすみまでの他の部分を修理した。</span>
<span className="v" id="v25" data-v="25" data-xref="エレミヤ書 32:2; エレミヤ書 37:21; ネヘミヤ書 12:39"> ウザイの子パラルは、城壁の曲りかどと向かい合っている所、および監視の庭に近い王の上の家から突き出ている望楼と向かい合っている所を修理した。その後にパロシの子ペダヤ、</span>
<span className="v" id="v26" data-v="26" data-xref="ネヘミヤ書 8:1; ネヘミヤ書 11:21; ネヘミヤ書 12:37"> およびオペルに住んでいる宮に仕えるしもべたちが、東の方の水の門と向かい合っている所、および突き出ている望楼と向かい合っている所まで修理した。</span>
<span className="v" id="v27" data-v="27" data-xref="ネヘミヤ書 3:5"> その後にテコアびとが、突き出ている大望楼と向かい合っている他の部分を修理し、オペルの城壁にまで及んだ。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="歴代志下 23:15; エレミヤ書 31:40; 列王紀下 11:16"> 馬の門から上の方は祭司たちが、おのおの自分の家と向かい合っている所を修理した。</span>
<span className="v" id="v29" data-v="29" data-xref="エレミヤ書 19:2; エズラ記 2:37; ネヘミヤ書 7:40"> その後にインメルの子ザドクが、自分の家と向かい合っている所を修理し、その後にシカニヤの子シマヤという東の門を守る者が修理し、</span>
<span className="v" id="v30" data-v="30"> その後にシレミヤの子ハナニヤおよびザラフの第六の子ハヌンが他の部分を修理し、その後にベレキヤの子メシュラムが、自分のへやと向かい合っている所を修理した。</span>
<span className="v" id="v31" data-v="31" data-xref="ネヘミヤ書 3:8; ネヘミヤ書 3:32"> その後に金細工人のひとりマルキヤという者が、召集の門と向かい合っている所を修理して、すみの二階のへやに至り、宮に仕えるしもべたちおよび商人の家にまで及んだ。</span>
<span className="v" id="v32" data-v="32" data-xref="ネヘミヤ書 3:1; ヨハネによる福音書 5:2; ネヘミヤ書 12:39"> またすみの二階のへやと羊の門の間は金細工人と商人たちがこれを修理した。</span>
</div>

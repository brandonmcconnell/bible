<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ネヘミヤ書 2:10; ヘブル人への手紙 11:36; 詩篇 35:15–16"> サンバラテはわれわれが城壁を築くのを聞いて怒り、大いに憤ってユダヤ人をあざけった。</span>
<span className="v" id="v2" data-v="2" data-xref="エズラ記 4:9–10; コリント人への第一の手紙 1:27; エゼキエル書 37:3–13"> 彼はその兄弟たちおよびサマリヤの兵隊の前で語って言った、「この弱々しいユダヤ人は何をしているのか。自分で再興しようとするのか。犠牲をささげようとするのか。一日で事を終えようとするのか。塵塚の中の石はすでに焼けているのに、これを取りだして生かそうとするのか」。</span>
<span className="v" id="v3" data-v="3" data-xref="ネヘミヤ書 2:19; 列王紀上 20:10; ネヘミヤ書 2:10"> またアンモンびとトビヤは、彼のかたわらにいて言った、「そうだ、彼らの築いている城壁は、きつね一匹が上ってもくずれるであろう」と。</span>
<span className="v" id="v4" data-v="4" data-xref="詩篇 79:12; 詩篇 123:3–4; 箴言 3:34"> 「われわれの神よ、聞いてください。われわれは侮られています。彼らのはずかしめを彼らのこうべに返し、彼らを捕囚の地でぶんどり物にしてください。</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 109:14; エレミヤ書 18:23; 詩篇 69:27–28"> 彼らのとがをおおわず、彼らの罪をみ前から消し去らないでください。彼らは築き建てる者の前であなたを怒らせたからです」。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="ピリピ人への手紙 2:13; ネヘミヤ書 6:15; ヘブル人への手紙 13:21"> こうしてわれわれは城壁を築いたが、石がきはみな相連なって、その高さの半ばにまで達した。民が心をこめて働いたからである。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="ネヘミヤ書 2:10; ネヘミヤ書 4:1; 使徒行伝 5:33"> ところがサンバラテ、トビヤ、アラビヤびと、アンモンびと、アシドドびとらは、エルサレムの城壁の修理が進展し、その破れ目もふさがり始めたと聞いて大いに怒り、</span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 83:3–11; イザヤ書 8:9–10; エレミヤ書 20:10"> 皆共に相はかり、エルサレムを攻めて、その中に混乱を起そうとした。</span>
<span className="v" id="v9" data-v="9" data-xref="ペテロの第一の手紙 5:8; 使徒行伝 4:24–30; 詩篇 50:15"> そこでわれわれは神に祈り、また日夜見張りを置いて彼らに備えた。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="詩篇 11:1–2; ハガイ書 1:2; 歴代志下 2:18"> その時、ユダびとは言った、「荷を負う者の力は衰え、そのうえ、灰土がおびただしいので、われわれは城壁を築くことができない」。</span>
<span className="v" id="v11" data-v="11" data-xref="テサロニケ人への第一の手紙 5:2; 使徒行伝 23:12; 詩篇 56:6"> またわれわれの敵は言った、「彼らの知らないうちに、また見ないうちに、彼らの中にはいりこんで彼らを殺し、その工事をやめさせよう」。</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 31:7; 創世記 31:41; 民数記 14:22"> また彼らの近くに住んでいるユダヤ人たちはきて、十度もわれわれに言った、「彼らはその住んでいるすべての所からわれわれに攻め上るでしょう」と。</span>
<span className="v" id="v13" data-v="13" data-xref="ネヘミヤ書 4:17–18; エペソ人への手紙 6:11–20; 雅歌 3:7–8"> そこでわたしは民につるぎ、やりおよび弓を持たせ、城壁の後の低い所、すなわち空地にその家族にしたがって立たせた。</span>
<span className="v" id="v14" data-v="14" data-xref="サムエル記下 10:12; 民数記 14:9; イザヤ書 41:10–14"> わたしは見めぐり、立って尊い人々、つかさたち、およびその他の民らに言った、「あなたがたは彼らを恐れてはならない。大いなる恐るべき主を覚え、あなたがたの兄弟、むすこ、娘、妻および家のために戦いなさい」。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="サムエル記下 17:14; ローマ人への手紙 12:11; ヨブ記 5:12–13"> われわれの敵は自分たちの事が、われわれに悟られたことを聞き、また神が彼らの計りごとを破られたことを聞いたので、われわれはみな城壁に帰り、おのおのその工事を続けた。</span>
<span className="v" id="v16" data-v="16" data-xref="ネヘミヤ書 4:23; 詩篇 101:6; ネヘミヤ書 5:15–16"> その日から後は、わたしのしもべの半数は工事に働き、半数はやり、盾、弓、よろいをもって武装した。そしてつかさたちは城壁を築いているユダの全家の後に立った。</span>
<span className="v" id="v17" data-v="17" data-xref="コリント人への第二の手紙 6:7; テモテヘの第二の手紙 4:7; テモテヘの第二の手紙 2:3"> 荷を負い運ぶ者はおのおの片手で工事をなし、片手に武器を執った。</span>
<span className="v" id="v18" data-v="18" data-xref="民数記 10:9; 歴代志下 13:12–17"> 築き建てる者はおのおのその腰につるぎを帯びて築き建て、ラッパを吹く者はわたしのかたわらにいた。</span>
<span className="v" id="v19" data-v="19"> わたしは尊い人々、つかさたち、およびその他の民に言った、「工事は大きくかつ広がっているので、われわれは城壁の上で互に遠く離れている。</span>
<span className="v" id="v20" data-v="20" data-xref="出エジプト記 14:14; 申命記 1:30; 申命記 20:4"> どこででもラッパの音を聞いたなら、そこにいるわれわれの所に集まってほしい。われわれの神はわれわれのために戦われます」。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="ガラテヤ人への手紙 6:9; コロサイ人への手紙 1:29; コリント人への第一の手紙 15:58"> このようにして、われわれは工事を進めたが、半数の者は夜明けから星の出る時まで、やりを執っていた。</span>
<span className="v" id="v22" data-v="22" data-xref="ネヘミヤ書 11:1–2"> その時わたしはまた民に告げて、「おのおのそのしもべと共にエルサレムの内に宿り、夜はわれわれの護衛者となり、昼は工事をするように」と言った。</span>
<span className="v" id="v23" data-v="23" data-xref="士師記 9:48; ネヘミヤ書 7:2; コリント人への第一の手紙 15:10"> そして、わたしも、わたしの兄弟たちも、わたしのしもべたちも、わたしを護衛する人々も、われわれのうちひとりも、その衣を脱がず、おのおの手に武器を執っていた。</span>
</div>

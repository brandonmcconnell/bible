<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="イザヤ書 48:2; イザヤ書 52:1; ネヘミヤ書 11:18"> 民のつかさたちはエルサレムに住み、その他の民はくじを引いて、十人のうちからひとりずつを、聖都エルサレムに来て住ませ、九人を他の町々に住ませた。</span>
<span className="v" id="v2" data-v="2" data-xref="士師記 5:9; コリント人への第二の手紙 8:16–17; ヨブ記 29:13"> またすべてみずから進みでてエルサレムに住むことを申し出た人々は、民はこれを祝福した。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="エズラ記 2:1; エズラ記 2:43; 歴代志上 9:1–34"> さてエルサレムに住んだこの州の長たちは次のとおりである。ただしユダの町々ではおのおのその町々にある自分の所有地に住んだ。すなわちイスラエルびと、祭司、レビびと、宮に仕えるしもべ、およびソロモンのしもべであった者たちの子孫である。</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 38:29; マタイによる福音書 1:3; ルカによる福音書 3:33"> そしてエルサレムにはユダの子孫およびベニヤミンの子孫のうちのある者たちが住んだ。すなわちユダの子孫ではウジヤの子アタヤで、ウジヤはゼカリヤの子、ゼカリヤはアマリヤの子、アマリヤはシパテヤの子、シパテヤはマハラレルの子、マハラレルはペレヅの子孫である。</span>
<span className="v" id="v5" data-v="5" data-xref="歴代志上 9:5; ネヘミヤ書 3:15; 民数記 26:20"> またバルクの子マアセヤで、バルクはコロホゼの子、コロホゼはハザヤの子、ハザヤはアダヤの子、アダヤはヨヤリブの子、ヨヤリブはゼカリヤの子、ゼカリヤはシロニびとの子である。</span>
<span className="v" id="v6" data-v="6"> ペレヅの子孫でエルサレムに住んだ者は合わせて四百六十八人で、みな勇敢な人々である。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="歴代志上 9:7–9"> ベニヤミンの子孫では次のとおりである。すなわちメシュラムの子サルで、メシュラムはヨエデの子、ヨエデはペダヤの子、ペダヤはコラヤの子、コラヤはマアセヤの子、マアセヤはイテエルの子、イテエルはエサヤの子である。</span>
<span className="v" id="v8" data-v="8"> その次はガバイおよびサライなどで合わせて九百二十八人。</span>
<span className="v" id="v9" data-v="9" data-xref="歴代志上 9:7"> ジクリの子ヨエルが彼らの監督である。ハッセヌアの子ユダがその副官として町を治めた。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="歴代志上 9:10; ネヘミヤ書 12:6; ネヘミヤ書 12:19"> 祭司ではヨヤリブの子エダヤ、ヤキン、</span>
<span className="v" id="v11" data-v="11" data-xref="歴代志上 9:11; 歴代志上 6:7–14; 民数記 3:32"> および神の宮のつかさセラヤで、セラヤはヒルキヤの子、ヒルキヤはメシュラムの子、メシュラムはザドクの子、ザドクはメラヨテの子、メラヨテはアヒトブの子である。</span>
<span className="v" id="v12" data-v="12" data-xref="歴代志上 9:12–13"> 宮の務をするその兄弟は八百二十二人あり、また、エロハムの子アダヤがある。エロハムはペラリヤの子、ペラリヤはアムジの子、アムジはゼカリヤの子、ゼカリヤはパシホルの子、パシホルはマルキヤの子である。</span>
<span className="v" id="v13" data-v="13"> アダヤの兄弟で、氏族の長たる者は二百四十二人あり、またアザリエルの子アマシサイがある。アザリエルはアハザイの子、アハザイはメシレモテの子、メシレモテはインメルの子である。</span>
<span className="v" id="v14" data-v="14"> その兄弟である勇士は百二十八人あり、その監督はハッゲドリムの子ザブデエルである。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="歴代志上 9:14; 歴代志上 9:19"> レビびとではハシュブの子シマヤで、ハシュブはアズリカムの子、アズリカムはハシャビヤの子、ハシャビヤはブンニの子である。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行伝 6:2–3; ネヘミヤ書 8:7; エズラ記 8:33"> またシャベタイおよびヨザバデがある。これらはレビびとのかしらであって、神の宮の外のわざをつかさどった。</span>
<span className="v" id="v17" data-v="17" data-xref="歴代志上 9:15; 歴代志上 25:1–6; ネヘミヤ書 12:8–9"> またミカの子マッタニヤがある。ミカはザブデの子、ザブデはアサフの子である。マッタニヤは祈の時に感謝の言葉を唱え始める者である。その兄弟のうちのバクブキヤは彼に次ぐ者であった。またシャンマの子アブダがある。シャンマはガラルの子、ガラルはエドトンの子である。</span>
<span className="v" id="v18" data-v="18" data-xref="ネヘミヤ書 11:1; ヨハネの黙示録 21:2; ダニエル書 9:24"> 聖都におるレビびとは合わせて二百八十四人であった。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="ネヘミヤ書 7:45; 歴代志上 9:17–22; 詩篇 84:10"> 門衛では門を守るアックブ、タルモンおよびその兄弟たち合わせて百七十二人である。</span>
<span className="v" id="v20" data-v="20" data-xref="ネヘミヤ書 11:3"> その他のイスラエルびと、祭司、レビびとたちは皆ユダのすべての町々にあって、おのおの自分の嗣業にとどまった。</span>
<span className="v" id="v21" data-v="21" data-xref="ネヘミヤ書 3:26; 歴代志下 27:3; ネヘミヤ書 3:31"> ただし宮に仕えるしもべたちはオペルに住み、ヂハおよびギシパが宮に仕えるしもべたちを監督していた。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="ネヘミヤ書 12:42; 歴代志上 25:1–6; エズラ記 8:19"> エルサレムにおるレビびとの監督はウジである。ウジはバニの子、バニはハシャビヤの子、ハシャビヤはマッタニヤの子、マッタニヤはミカの子である。ミカは歌うたう者なるアサフの子孫である。ウジは神の宮のわざを監督した。</span>
<span className="v" id="v23" data-v="23" data-xref="エズラ記 7:20–24; ネヘミヤ書 12:47; エズラ記 6:8–9"> 彼らについては王からの命令があって、歌うたう者に日々の定まった分を与えさせた。</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 38:30; 歴代志上 18:17; 歴代志上 23:28"> またユダの子ゼラの子孫であるメシザベルの子ペタヒヤは王の手に属して民に関するすべての事を取り扱った。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="ヨシュア記 14:15; ヨシュア記 15:21–22"> また村々とその田畑については、ユダの子孫の者はキリアテ・アルバとその村々、デボンとその村々、エカブジエルとその村々に住み、</span>
<span className="v" id="v26" data-v="26" data-xref="ヨシュア記 15:26–27; ヨシュア記 19:2"> エシュア、モラダおよびベテペレテに住み、</span>
<span className="v" id="v27" data-v="27" data-xref="創世記 26:33; ヨシュア記 15:28; 士師記 20:1"> ハザル・シュアルおよびベエルシバとその村々に住み、</span>
<span className="v" id="v28" data-v="28" data-xref="サムエル記上 27:6; ヨシュア記 15:31"> チクラグおよびメコナとその村々に住み、</span>
<span className="v" id="v29" data-v="29" data-xref="ヨシュア記 19:41; ヨシュア記 15:32–33; ヨシュア記 15:35"> エンリンモン、ザレア、ヤルムテに住み、</span>
<span className="v" id="v30" data-v="30" data-xref="ヨシュア記 10:3; ヨシュア記 15:8; ヨシュア記 18:16"> ザノア、アドラムおよびそれらの村々、ラキシとその田野、アゼカとその村々に住んだ。こうして彼らはベエルシバからヒンノムの谷にまで宿営した。</span>
<span className="v" id="v31" data-v="31" data-xref="創世記 12:8; ヨシュア記 8:9; ヨシュア記 18:13"> ベニヤミンの子孫はまたゲバからミクマシ、アヤおよびベテルとその村々に住み、</span>
<span className="v" id="v32" data-v="32" data-xref="ヨシュア記 21:18; イザヤ書 10:30; サムエル記上 21:1"> アナトテ、ノブ、アナニヤ、</span>
<span className="v" id="v33" data-v="33" data-xref="サムエル記下 4:3; サムエル記上 7:17; ヨシュア記 18:25"> ハゾル、ラマ、ギッタイム、</span>
<span className="v" id="v34" data-v="34" data-xref="サムエル記上 13:18"> ハデデ、ゼボイム、ネバラテ、</span>
<span className="v" id="v35" data-v="35" data-xref="歴代志上 8:12; ネヘミヤ書 7:37; 歴代志上 4:14"> ロド、オノ、工人の谷に住んだ。</span>
<span className="v" id="v36" data-v="36" data-xref="ヨシュア記 21:1–45; 創世記 49:7; 歴代志上 6:54–81"> レビびとの組のユダにあるもののうちベニヤミンに合したものもあった。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行伝 13:2–3; エズラ記 8:23; ネヘミヤ書 8:2"> その月の二十四日にイスラエルの人々は集まって断食し、荒布をまとい、土をかぶった。</span>
<span className="v" id="v2" data-v="2" data-xref="ダニエル書 9:3–10; ネヘミヤ書 13:3; エズラ記 10:11"> そしてイスラエルの子孫は、すべての異邦人を離れ、立って自分の罪と先祖の不義とをざんげした。</span>
<span className="v" id="v3" data-v="3" data-xref="ネヘミヤ書 8:7–8; ネヘミヤ書 8:3–4"> 彼らはその所に立って、その日の四分の一をもってその神、主の律法の書を読み、他の四分の一をもってざんげをなし、その神、主を拝した。</span>
<span className="v" id="v4" data-v="4" data-xref="ネヘミヤ書 8:7; ネヘミヤ書 12:8; ネヘミヤ書 9:5"> その時エシュア、バニ、カデミエル、シバニヤ、ブンニ、セレビヤ、バニ、ケナニらはレビびとの台の上に立ち、大声をあげて、その神、主に呼ばわった。</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 103:1–2; ペテロの第一の手紙 1:3; コリント人への第二の手紙 4:6"> それからまたエシュア、カデミエル、バニ、ハシャブニヤ、セレビヤ、ホデヤ、セバニヤ、ペタヒヤなどのレビびとは言った、「立ちあがって永遠から永遠にいますあなたがたの神、主をほめなさい。あなたの尊いみ名はほむべきかな。これはすべての祝福とさんびを越えるものです」。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="イザヤ書 37:16; 創世記 1:1; ヨハネの黙示録 4:11"> またエズラは言った、「あなたは、ただあなたのみ、主でいらせられます。あなたは天と諸天の天と、その万象、地とその上のすべてのもの、海とその中のすべてのものを造り、これをことごとく保たれます。天の万軍はあなたを拝します。</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 11:31; 創世記 17:5; イザヤ書 51:2"> あなたは主、神でいらせられます。あなたは昔アブラムを選んでカルデヤのウルから導き出し、彼にアブラハムという名を与え、</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 15:6; 創世記 15:18–21; ヘブル人への手紙 6:18"> 彼の心があなたの前に忠信なのを見られて、彼と契約を結び、その子孫にカナンびと、ヘテびと、アモリびと、ペリジびと、エブスびとおよびギルガシびとの地を与えると言われたが、ついにあなたはその約束を成就されました。あなたは正しくいらせられるからです。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="出エジプト記 3:7–9; 使徒行伝 7:34; 出エジプト記 3:16"> あなたはわれわれの先祖がエジプトで苦難を受けるのを顧みられ、また紅海のほとりで呼ばわり叫ぶのを聞きいれられ、</span>
<span className="v" id="v10" data-v="10" data-xref="エレミヤ書 32:20; ダニエル書 9:15; 出エジプト記 18:11"> しるしと不思議とをあらわしてパロと、そのすべての家来と、その国のすべての民を攻められました。彼らがわれわれの先祖に対して、ごうまんにふるまったことを知られたからです。そしてあなたが名をあげられたこと今日のようです。</span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 78:13; 出エジプト記 14:21–22; 出エジプト記 14:27–28"> あなたはまた彼らの前で海を分け、彼らに、かわいた地を踏んで海の中を通らせ、彼らを追う者を、石を大水に投げ入れるように淵に投げ入れ、</span>
<span className="v" id="v12" data-v="12" data-xref="出エジプト記 13:21–22; ネヘミヤ書 9:19; 詩篇 107:7"> 昼は雲の柱をもって彼らを導き、夜は火の柱をもってその行くべき道を照されました。</span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 119:160; 出エジプト記 20:1; 詩篇 119:127–128"> あなたはまたシナイ山の上に下り、天から彼らと語り、正しいおきてと、まことの律法および良きさだめと戒めとを授け、</span>
<span className="v" id="v14" data-v="14" data-xref="出エジプト記 20:8–11; 創世記 2:3; エゼキエル書 20:12"> あなたの聖なる安息日を彼らに示し、あなたのしもべモーセによって戒めと、さだめと、律法とを彼らに命じ、</span>
<span className="v" id="v15" data-v="15" data-xref="コリント人への第一の手紙 10:3–4; 申命記 1:8; 出エジプト記 17:6"> 天から食物を与えてその飢えをとどめ、岩から水を出してそのかわきを潤し、また、彼らに与えると誓われたその国にはいって、これを獲るように彼らに命じられました。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="ネヘミヤ書 9:29; 詩篇 81:11–14; ヘブル人への手紙 3:15"> しかし彼ら、すなわちわれわれの先祖はごうまんにふるまい、かたくなで、あなたの戒めに従わず、</span>
<span className="v" id="v17" data-v="17" data-xref="詩篇 86:5; ヨエル書 2:13; 詩篇 145:8–9"> 従うことを拒み、あなたが彼らの中で行われた奇跡を心にとめず、かえってかたくなになり、みずからひとりのかしらを立てて、エジプトの奴隷の生活に帰ろうとしました。しかしあなたは罪をゆるす神、恵みあり、あわれみあり、怒ることおそく、いつくしみ豊かにましまして、彼らを捨てられませんでした。</span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 106:19–23; 出エジプト記 32:4–8; エゼキエル書 20:7–44"> また彼らがみずから一つの鋳物の子牛を造って、『これはあなたがたをエジプトから導き上ったあなたがたの神である』と言って、大いに汚し事を行った時にも、</span>
<span className="v" id="v19" data-v="19" data-xref="詩篇 106:45; ネヘミヤ書 9:27; マラキ書 3:6"> あなたは大いなるあわれみをもって彼らを荒野に見捨てられず、昼は雲の柱を彼らの上から離さないで道々彼らを導き、夜は火の柱をもって彼らの行くべき道を照されました。</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 143:10; 民数記 11:17; イザヤ書 63:11–14"> またあなたは良きみたまを賜わって彼らを教え、あなたのマナを常に彼らの口に与え、また水を彼らに与えて、かわきをとどめ、</span>
<span className="v" id="v21" data-v="21" data-xref="申命記 2:7; 申命記 8:4; 詩篇 34:10"> 四十年の間彼らを荒野で養われたので、彼らはなんの欠けるところもなく、その衣服も古びず、その足もはれませんでした。</span>
<span className="v" id="v22" data-v="22" data-xref="民数記 21:21–35; 申命記 3:1–17; 申命記 2:26–36"> そしてあなたは彼らに諸国、諸民を与えて、これをすべて分かち取らせられました。彼らはヘシボンの王シホンの領地、およびバシャンの王オグの領地を獲ました。</span>
<span className="v" id="v23" data-v="23" data-xref="創世記 22:17; 創世記 15:5; 歴代志上 27:23"> また彼らの子孫を増して空の星のようにし、彼らの先祖たちに、はいって獲よと言われた地に彼らを導き入れられたので、</span>
<span className="v" id="v24" data-v="24" data-xref="ヨシュア記 21:43; ヨシュア記 11:23; 詩篇 44:2–3"> その子孫は、はいってこの地を獲ました。あなたはまた、この地に住むカナンびとを彼らの前に征服し、その王たちおよびその地の民を彼らの手に渡して、意のままに扱わせられました。</span>
<span className="v" id="v25" data-v="25" data-xref="申命記 32:15; ネヘミヤ書 9:35; 申命記 3:5"> それで彼らは堅固な町々および肥えた地を取り、もろもろの良い物の満ちた家、掘池、ぶどう畑、オリブ畑および多くの果樹を獲、食べて飽き、肥え太り、あなたの大いなる恵みによって楽しみました。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="列王紀上 14:9; 士師記 2:11–12; ネヘミヤ書 9:18"> それにもかかわらず彼らは不従順で、あなたにそむき、あなたの律法を後に投げ捨て、彼らを戒めて、あなたに立ち返らせようとした預言者たちを殺し、大いに汚し事を行いました。</span>
<span className="v" id="v27" data-v="27" data-xref="詩篇 106:41–45; 列王紀下 14:27; 列王紀下 13:5"> そこであなたは彼らを敵の手に渡して苦しめられましたが、彼らがその苦難の時にあなたに呼ばわったので、あなたは天からこれを聞かれ、大いなるあわれみをもって彼らに救う者を与え、敵の手から救わせられました。</span>
<span className="v" id="v28" data-v="28" data-xref="士師記 5:31–1; 士師記 4:1; 列王紀上 8:39"> ところが彼らは安息を得るやいなや、またあなたの前に悪事を行ったので、あなたは彼らを敵の手に捨て置いて、これに治めさせられましたが、彼らがまた立ち返ってあなたに呼ばわったので、あなたは天からこれを聞き、あわれみをもってしばしば彼らを救い出し、</span>
<span className="v" id="v29" data-v="29" data-xref="ネヘミヤ書 9:16; レビ記 18:5; ネヘミヤ書 9:26"> 彼らを戒めて、あなたの律法に引きもどそうとされました。けれども彼らはごうまんにふるまい、あなたの戒めに従わず、人がこれを行うならば、これによって生きるというあなたのおきてを破って罪を犯し、肩をそびやかし、かたくなになって、聞き従おうとはしませんでした。</span>
<span className="v" id="v30" data-v="30" data-xref="ローマ人への手紙 2:4; 歴代志下 36:15–16; イザヤ書 42:24"> それでもあなたは年久しく彼らを忍び、あなたの預言者たちにより、あなたのみたまをもって彼らを戒められましたが、彼らは耳を傾けなかったので、彼らを国々の民の手に渡されました。</span>
<span className="v" id="v31" data-v="31" data-xref="哀歌 3:22; エレミヤ書 4:27; ネヘミヤ書 9:17"> しかしあなたは大いなるあわれみによって彼らを絶やさず、また彼らを捨てられませんでした。あなたは恵みあり、あわれみある神でいらせられるからです。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="申命記 7:9; ネヘミヤ書 1:5; ダニエル書 9:4"> それゆえ、われわれの神、契約を保ち、いつくしみを施される大いにして力強く、恐るべき神よ、アッスリヤの王たちの時から今日まで、われわれとわれわれの王たち、つかさたち、祭司たち、預言者たち、先祖たち、およびあなたのすべての民に臨んだもろもろの苦難を小さい事と見ないでください。</span>
<span className="v" id="v33" data-v="33" data-xref="創世記 18:25; 詩篇 106:6; ヨブ記 34:23"> われわれに臨んだすべての事について、あなたは正しいのです。あなたは誠実をもって行われたのに、われわれは悪を行ったのです。</span>
<span className="v" id="v34" data-v="34" data-xref="エレミヤ書 29:19; 列王紀下 17:13; 申命記 31:21"> われわれの王たち、つかさたち、祭司たち、先祖たちはあなたの律法を行わず、あなたがお与えになった命令と戒めとに聞き従いませんでした。</span>
<span className="v" id="v35" data-v="35" data-xref="申命記 28:47; 申命記 32:12–15; エレミヤ書 5:19"> すなわち彼らはおのれの国におり、あなたが下さった大きな恵みのうちにおり、またあなたがお与えになった広い肥えた地におりながら、あなたに仕えず、また自分の悪いわざをやめることをしませんでした。</span>
<span className="v" id="v36" data-v="36" data-xref="エズラ記 9:9; 申命記 28:48; 歴代志下 12:8"> われわれは今日奴隷です。あなたがわれわれの先祖に与えて、その実とその良き物とを食べさせようとされた地で、われわれは奴隷となっているのです。</span>
<span className="v" id="v37" data-v="37" data-xref="申命記 28:33; 申命記 28:48; エズラ記 7:24"> そしてこの地はわれわれの罪のゆえに、あなたがわれわれの上に立てられた王たちのために多くの産物を出しています。かつ彼らはわれわれの身をも、われわれの家畜をも意のままに左右することができるので、われわれは大いなる苦難のうちにあるのです」。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="ネヘミヤ書 10:1; 歴代志下 34:31; エズラ記 10:3"> このもろもろの事のためにわれわれは堅い契約を結んで、これを記録し、われわれのつかさたち、レビびとたち祭司たちはこれに印を押した。</span>
</div>

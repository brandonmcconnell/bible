<span className="v" id="v1" data-v="1" data-xref="ネヘミヤ書 6:1; ネヘミヤ書 6:15; 歴代志下 31:2"> 城壁が築かれて、とびらを設け、さらに門衛、歌うたう者およびレビびとを任命したので、</span>
<span className="v" id="v2" data-v="2" data-xref="詩篇 101:6; ネヘミヤ書 1:2; マタイによる福音書 25:21"> わたしは、わたしの兄弟ハナニと、城のつかさハナニヤに命じて、エルサレムを治めさせた。彼は多くの者にまさって忠信な、神を恐れる者であったからである。</span>
<span className="v" id="v3" data-v="3" data-xref="ネヘミヤ書 3:28–30; 詩篇 127:1; ネヘミヤ書 3:23"> わたしは彼らに言った、「日の暑くなるまではエルサレムのもろもろの門を開いてはならない。人々が立って守っている間に門を閉じさせ、貫の木を差せ。またエルサレムの住民の中から番兵を立てて、おのおのにその所を守らせ、またおのおのの家と向かい合う所を守らせよ」。</span>
<span className="v" id="v4" data-v="4" data-xref="イザヤ書 58:12; マタイによる福音書 6:33; ハガイ書 1:4–6"> 町は広くて大きかったが、その内の民は少なく、家々はまだ建てられていなかった。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="コリント人への第二の手紙 3:5; コロサイ人への手紙 1:29; エズラ記 7:27"> 時に神はわたしの心に、尊い人々、つかさおよび民を集めて、家系によってその名簿をしらべようとの思いを起された。わたしは最初に上って来た人々の系図を発見し、その中にこのようにしるしてあるのを見いだした。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="エズラ記 5:8; エズラ記 2:1–70; エレミヤ書 52:1–34"> バビロンの王ネブカデネザルが捕え移した捕囚のうち、ゆるされてエルサレムおよびユダに上り、おのおの自分の町に帰ったこの州の人々は次のとおりである。</span>
<span className="v" id="v7" data-v="7" data-xref="エズラ記 2:2; ハガイ書 1:1; ゼカリヤ書 3:1–3"> 彼らはゼルバベル、エシュア、ネヘミヤ、アザリヤ、ラアミヤ、ナハマニ、モルデカイ、ビルシャン、ミスペレテ、ビグワイ、ネホム、バアナと一緒に帰ってきた者たちである。<br />そのイスラエルの民の人数は次のとおりである。</span>
<span className="v" id="v8" data-v="8" data-xref="エズラ記 2:3; エズラ記 8:3; ネヘミヤ書 10:14"> パロシの子孫は二千百七十二人。</span>
<span className="v" id="v9" data-v="9" data-xref="エズラ記 2:4; エズラ記 8:8"> シパテヤの子孫は三百七十二人。</span>

<span className="v" id="v11" data-v="11" data-xref="エズラ記 2:6; ネヘミヤ書 10:14; ネヘミヤ書 8:4"> パハテ・モアブの子孫すなわちエシュアとヨアブの子孫は二千八百十八人。</span>
<span className="v" id="v12" data-v="12" data-xref="エズラ記 10:26; エズラ記 2:7; エズラ記 8:7"> エラムの子孫は一千二百五十四人。</span>
<span className="v" id="v13" data-v="13" data-xref="エズラ記 2:8"> ザットの子孫は八百四十五人。</span>
<span className="v" id="v14" data-v="14" data-xref="エズラ記 2:9"> ザッカイの子孫は七百六十人。</span>
<span className="v" id="v15" data-v="15" data-xref="エズラ記 2:10"> ビンヌイの子孫は六百四十八人。</span>
<span className="v" id="v16" data-v="16" data-xref="エズラ記 2:11"> ベバイの子孫は六百二十八人。</span>
<span className="v" id="v17" data-v="17" data-xref="エズラ記 2:12"> アズガデの子孫は二千三百二十二人。</span>
<span className="v" id="v18" data-v="18" data-xref="エズラ記 2:13"> アドニカムの子孫は六百六十七人。</span>
<span className="v" id="v19" data-v="19" data-xref="エズラ記 2:14"> ビグワイの子孫は二千六十七人。</span>
<span className="v" id="v20" data-v="20" data-xref="エズラ記 2:15"> アデンの子孫は六百五十五人。</span>
<span className="v" id="v21" data-v="21" data-xref="エズラ記 2:16"> ヒゼキヤの家のアテルの子孫は九十八人。</span>

<span className="v" id="v24" data-v="24" data-xref="エズラ記 2:18"> ハリフの子孫は百十二人。</span>
<span className="v" id="v25" data-v="25" data-xref="エズラ記 2:20"> ギベオンの子孫は九十五人。</span>
<span className="v" id="v26" data-v="26" data-xref="エズラ記 2:21–22"> ベツレヘムおよびネトパの人々は百八十八人。</span>
<span className="v" id="v27" data-v="27" data-xref="エレミヤ書 11:21; イザヤ書 10:30; エズラ記 2:23"> アナトテの人々は百二十八人。</span>

<span className="v" id="v29" data-v="29" data-xref="ヨシュア記 18:25; エズラ記 2:25; 士師記 18:12"> キリアテ・ヤリム、ケピラおよびベエロテの人々は七百四十三人。</span>
<span className="v" id="v30" data-v="30" data-xref="ヨシュア記 18:24–25; エズラ記 2:26"> ラマおよびゲバの人々は六百二十一人。</span>
<span className="v" id="v31" data-v="31" data-xref="サムエル記上 13:23; エズラ記 2:27; サムエル記上 13:5"> ミクマシの人々は百二十二人。</span>
<span className="v" id="v32" data-v="32" data-xref="エズラ記 2:28; ヨシュア記 8:9; ヨシュア記 8:17"> ベテルおよびアイの人々は百二十三人。</span>
<span className="v" id="v33" data-v="33" data-xref="エズラ記 2:29"> ほかのネボの人々は五十二人。</span>
<span className="v" id="v34" data-v="34" data-xref="ネヘミヤ書 7:12; エズラ記 2:31"> ほかのエラムの子孫は一千二百五十四人。</span>
<span className="v" id="v35" data-v="35" data-xref="エズラ記 2:32; エズラ記 10:31"> ハリムの子孫は三百二十人。</span>

<span className="v" id="v37" data-v="37" data-xref="歴代志上 8:12; ネヘミヤ書 6:2; ネヘミヤ書 11:34–35"> ロド、ハデデおよびオノの人々は七百二十一人。</span>
<span className="v" id="v38" data-v="38" data-xref="エズラ記 2:35"> セナアの子孫は三千九百三十人。</span>
<span className="v" id="v39" data-v="39" data-xref="歴代志上 24:7–19; エズラ記 2:36"> 祭司では、エシュアの家のエダヤの子孫が九百七十三人。</span>

<span className="v" id="v42" data-v="42" data-xref="歴代志上 24:8; エズラ記 10:31; エズラ記 2:39"> ハリムの子孫が一千十七人。</span>

</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="エズラ記 2:41; 歴代志上 25:2"> 歌うたう者では、アサフの子孫が百四十八人。</span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="歴代志上 26:1–32; エズラ記 2:42"> 門衛では、シャルムの子孫、アテルの子孫、タルモンの子孫、アックブの子孫、ハテタの子孫およびショバイの子孫合わせて百三十八人。</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="エズラ記 2:43; レビ記 27:2–8; ヨシュア記 9:23–27"> 宮に仕えるしもべでは、ジハの子孫、ハスパの子孫、タバオテの子孫、</span>
<span className="v" id="v47" data-v="47" data-xref="エズラ記 2:44"> ケロスの子孫、シアの子孫、パドンの子孫、</span>
<span className="v" id="v48" data-v="48" data-xref="エズラ記 2:45–46"> レバナの子孫、ハガバの子孫、サルマイの子孫、</span>
<span className="v" id="v49" data-v="49"> ハナンの子孫、ギデルの子孫、ガハルの子孫、</span>
<span className="v" id="v50" data-v="50"> レアヤの子孫、レヂンの子孫、ネコダの子孫、</span>
<span className="v" id="v51" data-v="51" data-xref="エズラ記 2:49"> ガザムの子孫、ウザの子孫、パセアの子孫、</span>
<span className="v" id="v52" data-v="52" data-xref="エズラ記 2:50"> ベサイの子孫、メウニムの子孫、ネフセシムの子孫、</span>
<span className="v" id="v53" data-v="53"> バクブクの子孫、ハクパの子孫、ハルホルの子孫、</span>
<span className="v" id="v54" data-v="54" data-xref="エズラ記 2:52"> バヅリテの子孫、メヒダの子孫、ハルシャの子孫、</span>
<span className="v" id="v55" data-v="55" data-xref="エズラ記 2:53"> バルコスの子孫、シセラの子孫、テマの子孫、</span>
<span className="v" id="v56" data-v="56"> ネヂアの子孫およびハテパの子孫。</span>
</div>
<div className="bp">
<span className="v" id="v57" data-v="57" data-xref="エズラ記 2:55; ネヘミヤ書 11:3"> ソロモンのしもべであった者たちの子孫では、ソタイの子孫、ソペレテの子孫、ペリダの子孫、</span>
<span className="v" id="v58" data-v="58" data-xref="エズラ記 2:56"> ヤアラの子孫、ダルコンの子孫、ギデルの子孫、</span>
<span className="v" id="v59" data-v="59" data-xref="エズラ記 2:57"> シパテヤの子孫、ハッテルの子孫、ポケレテ・ハッゼバイムの子孫、アモンの子孫。</span>
</div>
<div className="bp">
<span className="v" id="v60" data-v="60" data-xref="エズラ記 2:58"> 宮に仕えるしもべたちとソロモンのしもべであった者たちの子孫とは合わせて三百九十二人。</span>
</div>
<div className="bp">
<span className="v" id="v61" data-v="61" data-xref="エズラ記 2:59"> テルメラ、テルハレサ、ケルブ、アドンおよびインメルから上って来た者があったが、その氏族と、血統とを示して、イスラエルの者であることを明らかにすることができなかった。その人々は次のとおりである。</span>
<span className="v" id="v62" data-v="62" data-xref="エズラ記 2:60"> すなわちデラヤの子孫、トビヤの子孫、ネコダの子孫であって、合わせて六百四十二人。</span>
<span className="v" id="v63" data-v="63" data-xref="エズラ記 2:61–63; 列王紀上 2:7; サムエル記下 17:27"> また祭司のうちにホバヤの子孫、ハッコヅの子孫、バルジライの子孫がある。バルジライはギレアデびとバルジライの娘たちのうちから妻をめとったので、その名で呼ばれた。</span>
<span className="v" id="v64" data-v="64" data-xref="歴代志上 9:1; ネヘミヤ書 7:5; ネヘミヤ書 13:29"> これらの者はこの系図に載った者のうちに、自分の籍をたずねたが、なかったので、汚れた者として祭司の職から除かれた。</span>
<span className="v" id="v65" data-v="65" data-xref="出エジプト記 28:30; ネヘミヤ書 8:9; ネヘミヤ書 10:1"> 総督は彼らに告げて、ウリムとトンミムを帯びる祭司の起るまでは、いと聖なる物を食べてはならぬと言った。</span>
</div>
<div className="bp">
<span className="v" id="v66" data-v="66" data-xref="エズラ記 2:64"> 会衆は合わせて四万二千三百六十人であった。</span>
<span className="v" id="v67" data-v="67" data-xref="エズラ記 2:65; イザヤ書 45:1–2; エレミヤ書 27:7"> このほかに男女の奴隷が七千三百三十七人、歌うたう者が男女合わせて二百四十五人あった。</span>
<span className="v" id="v68" data-v="68" data-xref="エズラ記 2:66–67"> その馬は七百三十六頭、その騾馬は二百四十五頭、</span>
<span className="v" id="v69" data-v="69"> そのらくだは四百三十五頭、そのろばは六千七百二十頭であった。</span>

</div>

<span className="v" id="v73" data-v="73" data-xref="エズラ記 2:70–1"> こうして祭司、レビびと、門衛、歌うたう者、民のうちのある人々、宮に仕えるしもべたち、およびイスラエルびとは皆その町々に住んだ。<br />イスラエルの人々はその町々に住んで七月になった。</span>

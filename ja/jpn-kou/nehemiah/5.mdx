<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="イザヤ書 5:7; 出エジプト記 22:25–27; コリント人への第一の手紙 6:6–8"> さて、ここに民がその妻と共に、その兄弟であるユダヤ人に向かって大いに叫び訴えることがあった。</span>
<span className="v" id="v2" data-v="2" data-xref="マラキ書 2:2; 詩篇 128:2–4; 詩篇 127:3–5"> すなわち、ある人々は言った、「われわれはむすこ娘と共に大ぜいです。われわれは穀物を得て、食べて生きていかなければなりません」。</span>
<span className="v" id="v3" data-v="3" data-xref="レビ記 25:35–39; マラキ書 3:8–11; 創世記 47:15–25"> またある人々は言った、「われわれは飢えのために、穀物を得ようと田畑も、ぶどう畑も、家も抵当に入れています」。</span>
<span className="v" id="v4" data-v="4" data-xref="エズラ記 4:13; エズラ記 4:20; 申命記 28:47–48"> ある人々は言った、「われわれは王の税金のために、われわれの田畑およびぶどう畑をもって金を借りました。</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀下 4:1; レビ記 25:39–43; イザヤ書 58:7"> 現にわれわれの肉はわれわれの兄弟の肉に等しく、われわれの子供も彼らの子供に等しいのに、見よ、われわれはむすこ娘を人の奴隷とするようにしいられています。われわれの娘のうちには、すでに人の奴隷になった者もありますが、われわれの田畑も、ぶどう畑も他人のものになっているので、われわれにはどうする力もありません」。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="出エジプト記 11:8; ネヘミヤ書 13:25; エペソ人への手紙 4:26"> わたしは彼らの叫びと、これらの言葉を聞いて大いに怒った。</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 23:19–20; レビ記 25:36; 出エジプト記 22:25"> わたしはみずから考えたすえ、尊い人々およびつかさたちを責めて言った、「あなたがたはめいめいその兄弟から利息をとっている」。そしてわたしは彼らの事について大会を開き、</span>
<span className="v" id="v8" data-v="8" data-xref="レビ記 25:47–49; コリント人への第一の手紙 8:11; マタイによる福音書 25:29"> 彼らに言った、「われわれは異邦人に売られたわれわれの兄弟ユダヤ人を、われわれの力にしたがってあがなった。しかるにあなたがたは自分の兄弟を売ろうとするのか。彼らはわれわれに売られるのか」。彼らは黙してひと言もいわなかった。</span>
<span className="v" id="v9" data-v="9" data-xref="レビ記 25:36; サムエル記下 12:14; ローマ人への手紙 2:24"> わたしはまた言った、「あなたがたのする事はよくない。あなたがたは、われわれの敵である異邦人のそしりをやめさせるために、われわれの神を恐れつつ事をなすべきではないか。</span>
<span className="v" id="v10" data-v="10" data-xref="コリント人への第二の手紙 6:1; 出エジプト記 22:25–27; エゼキエル書 18:13"> わたしもわたしの兄弟たちも、わたしのしもべたちも同じく金と穀物とを貸しているが、われわれはこの利息をやめよう。</span>
<span className="v" id="v11" data-v="11" data-xref="イザヤ書 58:6; レビ記 6:4–5; ルカによる福音書 3:8"> どうぞ、あなたがたは、きょうにも彼らの田畑、ぶどう畑、オリブ畑および家屋を彼らに返し、またあなたがたが彼らから取っていた金銭、穀物、ぶどう酒、油などの百分の一を返しなさい」。</span>
<span className="v" id="v12" data-v="12" data-xref="エズラ記 10:5; エレミヤ書 34:8–10; マタイによる福音書 19:21–22"> すると彼らは「われわれはそれを返します。彼らから何をも要求しません。あなたの言うようにします」と言った。そこでわたしは祭司たちを呼び、彼らにこの言葉のとおりに行うという誓いを立てさせた。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行伝 18:6; 歴代志上 16:36; マタイによる福音書 10:14"> わたしはまたわたしのふところを打ち払って言った、「この約束を実行しない者を、どうぞ神がこのように打ち払って、その家およびその仕事を離れさせられるように。その人はこのように打ち払われてむなしくなるように」。会衆はみな「アァメン」と言って、主をさんびした。そして民はこの約束のとおりに行った。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="ネヘミヤ書 13:6; テサロニケ人への第二の手紙 3:8–9; コリント人への第一の手紙 9:4–15"> またわたしは、ユダの地の総督に任ぜられた時から、すなわちアルタシャスタ王の第二十年から第三十二年まで、十二年の間、わたしもわたしの兄弟たちも、総督としての手当てを受けなかった。</span>
<span className="v" id="v15" data-v="15" data-xref="ネヘミヤ書 5:9; イザヤ書 50:10; 箴言 16:6"> わたしより以前の総督らは民に重荷を負わせ、彼らから銀四十シケルのほかにパンとぶどう酒を取り、また彼らのしもべたちも民を圧迫した。しかしわたしは神を恐れるので、そのようなことはしなかった。</span>
<span className="v" id="v16" data-v="16" data-xref="ガラテヤ人への手紙 6:9; テサロニケ人への第一の手紙 2:5–6; コリント人への第一の手紙 15:58"> わたしはかえって、この城壁の工事に身をゆだね、どんな土地をも買ったことはない。わたしのしもべたちは皆そこに集まって工事をした。</span>
<span className="v" id="v17" data-v="17" data-xref="列王紀上 18:19; ペテロの第一の手紙 4:9–10; サムエル記下 9:7"> またわたしの食卓にはユダヤ人と、つかさたち百五十人もあり、そのほかに、われわれの周囲の異邦人のうちからきた人々もあった。</span>
<span className="v" id="v18" data-v="18" data-xref="列王紀上 4:22–23; 詩篇 37:21; 詩篇 37:26"> これがために一日に牛一頭、肥えた羊六頭を備え、また鶏をもわたしのために備え、十日ごとにたくさんのぶどう酒を備えたが、わたしはこの民の労役が重かったので、総督としての手当てを求めなかった。</span>
<span className="v" id="v19" data-v="19" data-xref="ネヘミヤ書 13:31; 詩篇 106:4; ネヘミヤ書 13:14"> わが神よ、わたしがこの民のためにしたすべての事を覚えて、わたしをお恵みください。</span>

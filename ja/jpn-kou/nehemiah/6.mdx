<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ネヘミヤ書 2:19; ネヘミヤ書 2:10; ネヘミヤ書 4:1"> サンバラテ、トビヤ、アラビヤびとガシムおよびその他のわれわれの敵は、わたしが城壁を築き終って、一つの破れも残らないと聞いた。（しかしその時にはまだ門のとびらをつけていなかったのである。）</span>
<span className="v" id="v2" data-v="2" data-xref="詩篇 37:12; 歴代志上 8:12; ネヘミヤ書 11:35"> そこでサンバラテとガシムはわたしに使者をつかわして言った、「さあ、われわれはオノの平野にある一つの村で会見しよう」と。彼らはわたしに危害を加えようと考えていたのである。</span>
<span className="v" id="v3" data-v="3" data-xref="ヨハネによる福音書 9:4; マタイによる福音書 10:16; テモテヘの第一の手紙 4:15–16"> それでわたしは彼らに使者をつかわして言わせた、「わたしは大いなる工事をしているから下って行くことはできない。どうしてこの工事をさしおいて、あなたがたの所へ下って行き、その間、工事をやめることができようか」。</span>
<span className="v" id="v4" data-v="4" data-xref="士師記 16:15–20; ルカによる福音書 18:5; ガラテヤ人への手紙 2:5"> 彼らは四度までこのようにわたしに人をつかわしたが、わたしは同じように彼らに答えた。</span>
<span className="v" id="v5" data-v="5" data-xref="エペソ人への手紙 6:11; コリント人への第二の手紙 2:11; コリント人への第二の手紙 11:13–15"> ところが、サンバラテは五度目にそのしもべを前のようにわたしにつかわした。その手には開封の手紙を携えていた。</span>
<span className="v" id="v6" data-v="6" data-xref="ネヘミヤ書 2:19; エズラ記 4:12; ローマ人への手紙 3:8"> その中に次のようにしるしてあった、「諸国民の間に言い伝えられ、またガシムも言っているが、あなたはユダヤ人と共に反乱を企て、これがために城壁を築いている。またその言うところによれば、あなたは彼らの王になろうとしている。</span>
<span className="v" id="v7" data-v="7" data-xref="箴言 26:24–26; 列王紀上 1:7; 列王紀上 1:18"> またあなたは預言者を立てて、あなたのことをエルサレムにのべ伝えさせ、『ユダに王がある』と言わせているが、そのことはこの言葉のとおり王に聞えるでしょう。それゆえ、今おいでなさい。われわれは共に相談しましょう」。</span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 52:2; ヨブ記 13:4; マタイによる福音書 12:34"> そこでわたしは彼に人をつかわして言わせた、「あなたの言うようなことはしていません。あなたはそれを自分の心から造り出したのです」と。</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 138:3; ペテロの第一の手紙 5:10; エペソ人への手紙 3:16"> 彼らはみな「彼らの手が弱って工事をやめるようになれば、工事は成就しないだろう」と考えて、われわれをおどそうとしたのである。しかし神よ、どうぞいまわたしの手を強めてください。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="エレミヤ書 36:5; マタイによる福音書 7:15; 詩篇 37:12"> さてわたしはメヘタベルの子デラヤの子シマヤの家に行ったところ、彼は閉じこもっていて言った、「われわれは神の宮すなわち神殿の中で会合し、神殿の戸を閉じておきましょう。彼らはあなたを殺そうとして来るからです。きっと夜のうちにあなたを殺そうとして来るでしょう」。</span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 11:1–2; 使徒行伝 21:13; 箴言 28:1"> わたしは言った、「わたしのような者がどうして逃げられよう。わたしのような者でだれが神殿にはいって命を全うすることができよう。わたしははいらない」。</span>
<span className="v" id="v12" data-v="12" data-xref="エゼキエル書 13:22; テモテヘの第一の手紙 3:3; エゼキエル書 13:7"> わたしは悟った。神が彼をつかわされたのではない。彼がわたしにむかってこの預言を伝えたのは、トビヤとサンバラテが彼を買収したためである。</span>
<span className="v" id="v13" data-v="13" data-xref="エレミヤ書 20:10; コリント人への第二の手紙 11:12; テモテヘの第二の手紙 1:7"> 彼が買収されたのはこの事のためである。すなわちわたしを恐れさせ、わたしにこのようにさせて、罪を犯させ、わたしに悪名をきせて侮辱するためであった。</span>
<span className="v" id="v14" data-v="14" data-xref="ネヘミヤ書 13:29; テモテヘの第二の手紙 4:14–15; イザヤ書 9:14–15"> わが神よ、トビヤ、サンバラテおよび女預言者ノアデヤならびにその他の預言者など、すべてわたしを恐れさせようとする者たちをおぼえて、彼らが行ったこれらのわざに報いてください。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="詩篇 1:3; ダニエル書 9:25; ネヘミヤ書 4:1–2"> こうして城壁は五十二日を経て、エルルの月の二十五日に完成した。</span>
<span className="v" id="v16" data-v="16" data-xref="詩篇 126:2; ヨシュア記 5:1; ネヘミヤ書 4:7"> われわれの敵が皆これを聞いた時、われわれの周囲の異邦人はみな恐れ、大いに面目を失った。彼らはこの工事が、われわれの神の助けによって成就したことを悟ったからである。</span>
<span className="v" id="v17" data-v="17" data-xref="ミカ書 7:1–6; マタイによる福音書 24:10–12; ネヘミヤ書 3:5"> またそのころ、ユダの尊い人々は多くの手紙をトビヤに送った。トビヤの手紙もまた彼らにきた。</span>
<span className="v" id="v18" data-v="18" data-xref="エズラ記 2:5; ネヘミヤ書 7:10; ネヘミヤ書 3:4"> トビヤはアラの子シカニヤの婿であったので、ユダのうちの多くの者が彼と誓いを立てていたからである。トビヤの子ヨハナンもベレキヤの子メシュラムの娘を妻にめとった。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行伝 4:18–21; ネヘミヤ書 6:9; ヨハネによる福音書 7:7"> 彼らはまたトビヤの善行をわたしの前に語り、またわたしの言葉を彼に伝えた。トビヤはたびたび手紙を送って、わたしを恐れさせようとした。</span>

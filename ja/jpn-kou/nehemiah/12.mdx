<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ネヘミヤ書 10:2–8; ネヘミヤ書 12:12–21; エズラ記 2:1–2"> シャルテルの子ゼルバベルおよびエシュアと一緒に上ってきた祭司とレビびとは次のとおりである。すなわちセラヤ、エレミヤ、エズラ、</span>
<span className="v" id="v2" data-v="2"> アマリヤ、マルク、ハットシ、</span>
<span className="v" id="v3" data-v="3"> シカニヤ、レホム、メレモテ、</span>
<span className="v" id="v4" data-v="4" data-xref="ルカによる福音書 1:5"> イド、ギンネトイ、アビヤ、</span>
<span className="v" id="v5" data-v="5"> ミヤミン、マアデヤ、ビルガ、</span>
<span className="v" id="v6" data-v="6" data-xref="歴代志上 9:10; ネヘミヤ書 11:10"> シマヤ、ヨヤリブ、エダヤ、</span>
<span className="v" id="v7" data-v="7" data-xref="歴代志上 24:18; ゼカリヤ書 3:1; エズラ記 3:2"> サライ、アモク、ヒルキヤ、エダヤで、これらの者はエシュアの時代に祭司およびその兄弟らのかしらであった。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="ネヘミヤ書 11:17; ネヘミヤ書 12:24; ネヘミヤ書 11:22"> レビびとではエシュア、ビンヌイ、カデミエル、セレビヤ、ユダ、マッタニヤで、マッタニヤはその兄弟らと共に感謝のことをつかさどった。</span>
<span className="v" id="v9" data-v="9" data-xref="ネヘミヤ書 12:24; 詩篇 134:1–3"> また彼らの兄弟であるバグブキヤおよびウンノは彼らの向かいに立って勤めをした。</span>
<span className="v" id="v10" data-v="10" data-xref="歴代志上 6:3–15; ネヘミヤ書 13:28; ネヘミヤ書 13:4"> エシュアの子はヨアキム、ヨアキムの子はエリアシブ、エリアシブの子はヨイアダ、</span>
<span className="v" id="v11" data-v="11"> ヨイアダの子はヨナタン、ヨナタンの子はヤドアである。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="ネヘミヤ書 12:22; 歴代志上 9:33–34; 歴代志上 24:6–31"> ヨアキムの時代に祭司で氏族の長であった者はセラヤの氏族ではメラヤ、エレミヤの氏族ではハナニヤ、</span>
<span className="v" id="v13" data-v="13"> エズラの氏族ではメシュラム、アマリヤの氏族ではヨハナン、</span>
<span className="v" id="v14" data-v="14"> マルキの氏族ではヨナタン、シバニヤの氏族ではヨセフ、</span>
<span className="v" id="v15" data-v="15"> ハリムの氏族ではアデナ、メラヨテの氏族ではヘルカイ、</span>
<span className="v" id="v16" data-v="16"> イドの氏族ではゼカリヤ、ギンネトンの氏族ではメシュラム、</span>
<span className="v" id="v17" data-v="17"> アビヤの氏族ではジクリ、ミニヤミンの氏族、モアデヤの氏族ではピルタイ、</span>
<span className="v" id="v18" data-v="18"> ビルガの氏族ではシャンマ、シマヤの氏族ではヨナタン、</span>
<span className="v" id="v19" data-v="19"> ヨヤリブの氏族ではマッテナイ、エダヤの氏族ではウジ、</span>
<span className="v" id="v20" data-v="20"> サライの氏族ではカライ、アモクの氏族ではエベル、</span>
<span className="v" id="v21" data-v="21"> ヒルキヤの氏族ではハシャビヤ、エダヤの氏族ではネタンエルである。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="ネヘミヤ書 12:10–13"> レビびとについては、エリアシブ、ヨイアダ、ヨハナンおよびヤドアの時代に、その氏族の長たちが登録された。また祭司たちもペルシャ王ダリヨスの治世まで登録された。</span>
<span className="v" id="v23" data-v="23" data-xref="歴代志上 9:14–44"> レビの子孫で氏族の長たる者は、エリアシブの子ヨハナンの世まで歴代志の書にしるされている。</span>
<span className="v" id="v24" data-v="24" data-xref="歴代志上 25:1–26; ネヘミヤ書 11:17; エズラ記 3:10–11"> レビびとのかしらはハシャビヤ、セレビヤおよびカデミエルの子エシュアであって、その兄弟たち相向かい合い、組と組と対応して神の人ダビデの命令に従い、さんびと感謝をささげた。</span>
<span className="v" id="v25" data-v="25" data-xref="歴代志上 26:15; ネヘミヤ書 12:8–9; 歴代志上 26:12"> マツタニヤ、バクブキヤ、オバデヤ、メシュラム、タルモンおよびアックブは門を守る者で門の内の倉を監督した。</span>
<span className="v" id="v26" data-v="26" data-xref="ネヘミヤ書 8:9; エズラ記 7:6; エズラ記 7:11"> これらはヨザダクの子エシュアの子ヨアキムの時代、また総督ネヘミヤおよび学者である祭司エズラの時代にいた人々である。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="歴代志上 15:16; 歴代志上 15:28; 歴代志下 29:30"> さてエルサレムの城壁の落成式に当って、レビびとを、そのすべての所から招いてエルサレムにこさせ、感謝と、歌と、シンバルと、立琴と、琴とをもって喜んで落成式を行おうとした。</span>
<span className="v" id="v28" data-v="28" data-xref="歴代志上 9:16; 歴代志上 2:54; ネヘミヤ書 6:2"> そこで、歌うたう人々はエルサレムの周囲の地方、ネトパびとの村々から集まってきた。</span>
<span className="v" id="v29" data-v="29" data-xref="ヨシュア記 10:43; 歴代志上 6:60; エズラ記 2:24"> またベテギルガルおよびゲバとアズマウテの地方からも集まってきた。この歌うたう者たちはエルサレムの周囲に自分の村々を建てていたからである。</span>
<span className="v" id="v30" data-v="30" data-xref="ヨブ記 1:5; 出エジプト記 19:10; 歴代志下 29:5"> そして祭司とレビびとたちは身を清め、また民およびもろもろの門と城壁とを清めた。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="ネヘミヤ書 2:13; ネヘミヤ書 12:38; 歴代志上 13:1"> そこでわたしはユダのつかさたちを城壁の上にのぼらせ、また感謝する者の二つの大きな組を作って、行進させた。その一つは城壁の上を右に糞の門をさして進んだ。</span>
<span className="v" id="v32" data-v="32"> そのあとに従って進んだ者はホシャヤ、およびユダのつかさたちの半ば、</span>
<span className="v" id="v33" data-v="33" data-xref="ネヘミヤ書 10:2–7"> ならびにアザリヤ、エズラ、メシュラム、</span>
<span className="v" id="v34" data-v="34"> ユダ、ベニヤミン、シマヤ、エレミヤであった。</span>
<span className="v" id="v35" data-v="35" data-xref="ヨシュア記 6:4; 民数記 10:2–10; 歴代志下 5:12"> また数人の祭司がラッパをもって従った。すなわちヨナタンの子ゼカリヤ。ヨナタンはシマヤの子、シマヤはマッタニヤの子、マッタニヤはミカヤの子、ミカヤはザックルの子、ザックルはアサフの子である。</span>
<span className="v" id="v36" data-v="36" data-xref="ネヘミヤ書 12:24; 歴代志下 8:14; 歴代志上 23:5"> またゼカリヤの兄弟たちシマヤ、アザリエル、ミラライ、ギラライ、マアイ、ネタンエル、ユダ、ハナニなどであって、神の人ダビデの楽器を持って従った。そして学者エズラは彼らの先に進んだ。</span>
<span className="v" id="v37" data-v="37" data-xref="ネヘミヤ書 3:26; ネヘミヤ書 2:14; ネヘミヤ書 8:3"> 彼らは泉の門を経て、まっすぐに進み、城壁の上り口で、ダビデの町の階段から上り、ダビデの家の上を過ぎて東の方、水の門に至った。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="ネヘミヤ書 3:8; ネヘミヤ書 3:11; ネヘミヤ書 12:31"> 他の一組の感謝する者は左に進んだ。わたしは民の半ばと共に彼らのあとに従った。そして城壁の上を行き、炉の望楼の上を過ぎて、城壁の広い所に至り、</span>
<span className="v" id="v39" data-v="39" data-xref="ネヘミヤ書 3:1; ネヘミヤ書 3:3; ネヘミヤ書 8:16"> エフライムの門の上を通り、古い門を過ぎ、魚の門およびハナネルの望楼とハンメアの望楼を過ぎて、羊の門に至り、近衛の門に立ち止まった。</span>
<span className="v" id="v40" data-v="40" data-xref="詩篇 42:4; 詩篇 134:1–3; ネヘミヤ書 12:31–32"> こうして二組の感謝する者は神の宮にはいって立った。わたしもそこに立ち、つかさたちの半ばもわたしと共に立った。</span>
<span className="v" id="v41" data-v="41"> また祭司エリアキム、マアセヤ、ミニヤミン、ミカヤ、エリオエナイ、ゼカリヤ、ハナニヤらはラッパを持ち、</span>
<span className="v" id="v42" data-v="42" data-xref="詩篇 81:1; ネヘミヤ書 11:14; 詩篇 100:1–2"> マアセヤ、シマヤ、エレアザル、ウジ、ヨハナン、マルキヤ、エラムおよびエゼルも共にいた。そして歌うたう者たちは声高く歌った。エズラヒヤはその監督であった。</span>
<span className="v" id="v43" data-v="43" data-xref="エズラ記 3:13; 詩篇 92:4; エレミヤ書 31:13"> こうして彼らはその日、大いなる犠牲をささげて喜んだ。神が彼らを大いに喜び楽しませられたからである。女子供までも喜んだ。それでエルサレムの喜びの声は遠くまで聞えた。</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="ネヘミヤ書 13:12–13; ネヘミヤ書 10:37–39; 歴代志下 31:11–13"> その日、倉のもろもろのへやをつかさどる人々を選び、ささげ物、初物、十分の一など律法の定めるところの祭司およびレビびとの分を町々の田畑にしたがって取り集めて、へやに入れることをつかさどらせた。これは祭司およびレビびとの仕えるのを、ユダびとが喜んだからである。</span>
<span className="v" id="v45" data-v="45" data-xref="歴代志上 25:1–26; 歴代志下 23:6; 歴代志上 23:28"> 彼らはダビデおよびその子ソロモンの命令に従って、神の勤めおよび清め事の勤めをした。歌うたう者および門を守る者もそのように行った。</span>
<span className="v" id="v46" data-v="46" data-xref="歴代志下 29:30; 詩篇 73:1; 歴代志上 25:1–31"> 昔ダビデおよびアサフの日には、歌うたう者のかしらがひとりいて、神にさんびと感謝をささげる事があった。</span>
<span className="v" id="v47" data-v="47" data-xref="民数記 18:21–29; ネヘミヤ書 12:26; ネヘミヤ書 13:10–12"> またゼルバベルの日およびネヘミヤの日には、イスラエルびとはみな歌うたう者と門を守る者に日々の分を与え、またレビびとに物を聖別して与え、レビびとはまたこれを聖別してアロンの子孫に与えた。</span>
</div>

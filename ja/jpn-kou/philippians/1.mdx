<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="コリント人への第二の手紙 1:1; 使徒行伝 16:12–15; ローマ人への手紙 1:1"> キリスト・イエスの僕たち、パウロとテモテから、ピリピにいる、キリスト・イエスにあるすべての聖徒たち、ならびに監督たちと執事たちへ。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="ローマ人への手紙 1:7; コリント人への第二の手紙 1:2; ペテロの第一の手紙 1:2"> わたしたちの父なる神と主イエス・キリストから、恵みと平安とが、あなたがたにあるように。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="コリント人への第一の手紙 1:4; テサロニケ人への第一の手紙 1:2–3; ピレモンヘの手紙 1:4–5"> わたしはあなたがたを思うたびごとに、わたしの神に感謝し、</span>
<span className="v" id="v4" data-v="4" data-xref="テサロニケ人への第一の手紙 1:2; ローマ人への手紙 1:9; ヨハネの第二の手紙 1:4"> あなたがた一同のために祈るとき、いつも喜びをもって祈り、</span>
<span className="v" id="v5" data-v="5" data-xref="ピリピ人への手紙 4:14–15; ピリピ人への手紙 1:7; ヘブル人への手紙 3:14"> あなたがたが最初の日から今日に至るまで、福音にあずかっていることを感謝している。</span>
<span className="v" id="v6" data-v="6" data-xref="テサロニケ人への第一の手紙 5:23–24; ピリピ人への手紙 2:13; エペソ人への手紙 4:12"> そして、あなたがたのうちに良いわざを始められたかたが、キリスト・イエスの日までにそれを完成して下さるにちがいないと、確信している。</span>
<span className="v" id="v7" data-v="7" data-xref="コリント人への第二の手紙 7:3; ピリピ人への手紙 1:5; コロサイ人への手紙 4:18"> わたしが、あなたがた一同のために、そう考えるのは当然である。それは、わたしが獄に捕われている時にも、福音を弁明し立証する時にも、あなたがたをみな、共に恵みにあずかる者として、わたしの心に深く留めているからである。</span>
<span className="v" id="v8" data-v="8" data-xref="ピリピ人への手紙 4:1; ローマ人への手紙 1:9; テモテヘの第二の手紙 1:4"> わたしがキリスト・イエスの熱愛をもって、どんなに深くあなたがた一同を思っていることか、それを証明して下さるかたは神である。</span>
<span className="v" id="v9" data-v="9" data-xref="テサロニケ人への第一の手紙 3:12; コロサイ人への手紙 1:9; ペテロの第二の手紙 1:5–6"> わたしはこう祈る。あなたがたの愛が、深い知識において、するどい感覚において、いよいよ増し加わり、</span>
<span className="v" id="v10" data-v="10" data-xref="ローマ人への手紙 12:2; テサロニケ人への第一の手紙 3:13; テサロニケ人への第一の手紙 5:23"> それによって、あなたがたが、何が重要であるかを判別することができ、キリストの日に備えて、純真で責められるところのないものとなり、</span>
<span className="v" id="v11" data-v="11" data-xref="ヘブル人への手紙 12:11; ヨハネによる福音書 15:8; ヨハネによる福音書 15:4–5"> イエス・キリストによる義の実に満たされて、神の栄光とほまれとをあらわすに至るように。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="テモテヘの第二の手紙 2:9; ローマ人への手紙 8:28; 使徒行伝 11:19–21"> さて、兄弟たちよ。わたしの身に起った事が、むしろ福音の前進に役立つようになったことを、あなたがたに知ってもらいたい。</span>
<span className="v" id="v13" data-v="13" data-xref="テモテヘの第二の手紙 2:9; エペソ人への手紙 3:1; ピリピ人への手紙 1:7"> すなわち、わたしが獄に捕われているのはキリストのためであることが、兵営全体にもそのほかのすべての人々にも明らかになり、</span>
<span className="v" id="v14" data-v="14" data-xref="エペソ人への手紙 6:19–20; テサロニケ人への第一の手紙 2:2; ルカによる福音書 1:74"> そして兄弟たちのうち多くの者は、わたしの入獄によって主にある確信を得、恐れることなく、ますます勇敢に、神の言を語るようになった。</span>
<span className="v" id="v15" data-v="15" data-xref="ローマ人への手紙 16:17–18; ピリピ人への手紙 2:3; コリント人への第二の手紙 11:13"> 一方では、ねたみや闘争心からキリストを宣べ伝える者がおり、他方では善意からそうする者がいる。</span>
<span className="v" id="v16" data-v="16" data-xref="コリント人への第二の手紙 2:17; コリント人への第二の手紙 4:1–2; 詩篇 69:26"> 後者は、わたしが福音を弁明するために立てられていることを知り、愛の心でキリストを伝え、</span>
<span className="v" id="v17" data-v="17" data-xref="テモテヘの第二の手紙 1:11–12; ピリピ人への手紙 2:3; ピリピ人への手紙 1:7"> 前者は、わたしの入獄の苦しみに更に患難を加えようと思って、純真な心からではなく、党派心からそうしている。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="ルカによる福音書 9:50; マルコによる福音書 9:38–40; コリント人への第一の手紙 15:11"> すると、どうなのか。見えからであるにしても、真実からであるにしても、要するに、伝えられているのはキリストなのだから、わたしはそれを喜んでいるし、また喜ぶであろう。</span>
<span className="v" id="v19" data-v="19" data-xref="ローマ人への手紙 8:28; 使徒行伝 16:7; コリント人への第二の手紙 1:11"> なぜなら、あなたがたの祈と、イエス・キリストの霊の助けとによって、この事がついには、わたしの救となることを知っているからである。</span>
<span className="v" id="v20" data-v="20" data-xref="ペテロの第一の手紙 4:16; コリント人への第一の手紙 6:20; イザヤ書 54:4"> そこで、わたしが切実な思いで待ち望むことは、わたしが、どんなことがあっても恥じることなく、かえって、いつものように今も、大胆に語ることによって、生きるにも死ぬにも、わたしの身によってキリストがあがめられることである。</span>
<span className="v" id="v21" data-v="21" data-xref="ガラテヤ人への手紙 2:20; コリント人への第二の手紙 5:8; コリント人への第二の手紙 5:1"> わたしにとっては、生きることはキリストであり、死ぬことは益である。</span>
<span className="v" id="v22" data-v="22" data-xref="ペテロの第一の手紙 4:2; ガラテヤ人への手紙 2:20; ピリピ人への手紙 1:24"> しかし、肉体において生きていることが、わたしにとっては実り多い働きになるのだとすれば、どちらを選んだらよいか、わたしにはわからない。</span>
<span className="v" id="v23" data-v="23" data-xref="コリント人への第二の手紙 5:8; 詩篇 17:15; ヨハネの黙示録 14:13"> わたしは、これら二つのものの間に板ばさみになっている。わたしの願いを言えば、この世を去ってキリストと共にいることであり、実は、その方がはるかに望ましい。</span>
<span className="v" id="v24" data-v="24" data-xref="ヨハネによる福音書 16:7; ピリピ人への手紙 1:22; ピリピ人への手紙 1:25–26"> しかし、肉体にとどまっていることは、あなたがたのためには、さらに必要である。</span>
<span className="v" id="v25" data-v="25" data-xref="ピリピ人への手紙 2:24; コリント人への第二の手紙 1:24; エペソ人への手紙 4:11–13"> こう確信しているので、わたしは生きながらえて、あなたがた一同のところにとどまり、あなたがたの信仰を進ませ、その喜びを得させようと思う。</span>
<span className="v" id="v26" data-v="26" data-xref="コリント人への第二の手紙 1:14; コリント人への第二の手紙 5:12; ピリピ人への手紙 3:3"> そうなれば、わたしが再びあなたがたのところに行くので、あなたがたはわたしによってキリスト・イエスにある誇を増すことになろう。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="エペソ人への手紙 4:1; コリント人への第一の手紙 16:13–14; コリント人への第一の手紙 1:10"> ただ、あなたがたはキリストの福音にふさわしく生活しなさい。そして、わたしが行ってあなたがたに会うにしても、離れているにしても、あなたがたが一つの霊によって堅く立ち、一つ心になって福音の信仰のために力を合わせて戦い、</span>
<span className="v" id="v28" data-v="28" data-xref="テモテヘの第二の手紙 1:7–8; テサロニケ人への第二の手紙 1:5–6; マタイによる福音書 10:28"> かつ、何事についても、敵対する者どもにろうばいさせられないでいる様子を、聞かせてほしい。このことは、彼らには滅びのしるし、あなたがたには救のしるしであって、それは神から来るのである。</span>
<span className="v" id="v29" data-v="29" data-xref="ヤコブの手紙 1:2; ペテロの第一の手紙 4:13; 使徒行伝 5:41"> あなたがたはキリストのために、ただ彼を信じることだけではなく、彼のために苦しむことをも賜わっている。</span>
<span className="v" id="v30" data-v="30" data-xref="テサロニケ人への第一の手紙 2:2; 使徒行伝 16:19–40; テモテヘの第二の手紙 4:7"> あなたがたは、さきにわたしについて見、今またわたしについて聞いているのと同じ苦闘を、続けているのである。</span>
</div>

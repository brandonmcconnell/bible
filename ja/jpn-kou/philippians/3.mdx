</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="コリント人への第二の手紙 11:13; テトスヘの手紙 1:16; ヨハネの黙示録 22:15"> あの犬どもを警戒しなさい。悪い働き人たちを警戒しなさい。肉に割礼の傷をつけている人たちを警戒しなさい。</span>
<span className="v" id="v3" data-v="3" data-xref="コロサイ人への手紙 2:11; 申命記 30:6; ローマ人への手紙 7:6"> 神の霊によって礼拝をし、キリスト・イエスを誇とし、肉を頼みとしないわたしたちこそ、割礼の者である。</span>
<span className="v" id="v4" data-v="4" data-xref="コリント人への第二の手紙 11:18–22"> もとより、肉の頼みなら、わたしにも無くはない。もし、だれかほかの人が肉を頼みとしていると言うなら、わたしはそれをもっと頼みとしている。</span>
<span className="v" id="v5" data-v="5" data-xref="コリント人への第二の手紙 11:22; ローマ人への手紙 11:1; 使徒行伝 23:6"> わたしは八日目に割礼を受けた者、イスラエルの民族に属する者、ベニヤミン族の出身、ヘブル人の中のヘブル人、律法の上ではパリサイ人、</span>
<span className="v" id="v6" data-v="6" data-xref="ガラテヤ人への手紙 1:13–14; 使徒行伝 8:3; 使徒行伝 26:9–10"> 熱心の点では教会の迫害者、律法の義については落ち度のない者である。</span>
<span className="v" id="v7" data-v="7" data-xref="ルカによる福音書 14:33; マタイによる福音書 16:26; マタイによる福音書 13:44–46"> しかし、わたしにとって益であったこれらのものを、キリストのゆえに損と思うようになった。</span>
<span className="v" id="v8" data-v="8" data-xref="エレミヤ書 9:23–24; ローマ人への手紙 8:18; ピリピ人への手紙 3:7"> わたしは、更に進んで、わたしの主キリスト・イエスを知る知識の絶大な価値のゆえに、いっさいのものを損と思っている。キリストのゆえに、わたしはすべてを失ったが、それらのものを、ふん土のように思っている。それは、わたしがキリストを得るためであり、</span>
<span className="v" id="v9" data-v="9" data-xref="コリント人への第二の手紙 5:21; コリント人への第一の手紙 1:30; ガラテヤ人への手紙 2:16"> 律法による自分の義ではなく、キリストを信じる信仰による義、すなわち、信仰に基く神からの義を受けて、キリストのうちに自分を見いだすようになるためである。</span>
<span className="v" id="v10" data-v="10" data-xref="ガラテヤ人への手紙 2:20; ローマ人への手紙 8:17; ペテロの第一の手紙 4:1–2"> すなわち、キリストとその復活の力とを知り、その苦難にあずかって、その死のさまとひとしくなり、</span>
<span className="v" id="v11" data-v="11" data-xref="ルカによる福音書 20:35–36; ヨハネの黙示録 20:5; 使徒行伝 23:6"> なんとかして死人のうちからの復活に達したいのである。</span>
<span className="v" id="v12" data-v="12" data-xref="テモテヘの第一の手紙 6:11–12; ペテロの第二の手紙 1:5–8; 詩篇 138:8"> わたしがすでにそれを得たとか、すでに完全な者になっているとか言うのではなく、ただ捕えようとして追い求めているのである。そうするのは、キリスト・イエスによって捕えられているからである。</span>
<span className="v" id="v13" data-v="13" data-xref="ルカによる福音書 9:62; ヘブル人への手紙 12:1–2; ピリピ人への手紙 3:12"> 兄弟たちよ。わたしはすでに捕えたとは思っていない。ただこの一事を努めている。すなわち、後のものを忘れ、前のものに向かってからだを伸ばしつつ、</span>
<span className="v" id="v14" data-v="14" data-xref="コリント人への第一の手紙 9:24; ペテロの第一の手紙 5:10; ヨハネの黙示録 3:21"> 目標を目ざして走り、キリスト・イエスにおいて上に召して下さる神の賞与を得ようと努めているのである。</span>
<span className="v" id="v15" data-v="15" data-xref="ヨハネによる福音書 7:17; ヤコブの手紙 1:4–5; 箴言 2:3–6"> だから、わたしたちの中で全き人たちは、そのように考えるべきである。しかし、あなたがたが違った考えを持っているなら、神はそのことも示して下さるであろう。</span>
<span className="v" id="v16" data-v="16" data-xref="コロサイ人への手紙 2:6; ヨハネの黙示録 3:3; ヨハネの黙示録 2:4–5"> ただ、わたしたちは、達し得たところに従って進むべきである。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="ピリピ人への手紙 4:9; コリント人への第一の手紙 4:16; ペテロの第一の手紙 5:3"> 兄弟たちよ。どうか、わたしにならう者となってほしい。また、あなたがたの模範にされているわたしたちにならって歩く人たちに、目をとめなさい。</span>
<span className="v" id="v18" data-v="18" data-xref="エペソ人への手紙 4:17; イザヤ書 8:11; ガラテヤ人への手紙 6:12"> わたしがそう言うのは、キリストの十字架に敵対して歩いている者が多いからである。わたしは、彼らのことをしばしばあなたがたに話したが、今また涙を流して語る。</span>
<span className="v" id="v19" data-v="19" data-xref="ローマ人への手紙 16:18; ローマ人への手紙 8:5–7; ペテロの第二の手紙 2:3"> 彼らの最後は滅びである。彼らの神はその腹、彼らの栄光はその恥、彼らの思いは地上のことである。</span>
<span className="v" id="v20" data-v="20" data-xref="エペソ人への手紙 2:19; コロサイ人への手紙 3:1–3; コリント人への第二の手紙 4:18–1"> しかし、わたしたちの国籍は天にある。そこから、救主、主イエス・キリストのこられるのを、わたしたちは待ち望んでいる。</span>
<span className="v" id="v21" data-v="21" data-xref="ヨハネの第一の手紙 3:2; コロサイ人への手紙 3:4; コリント人への第一の手紙 15:42–56"> 彼は、万物をご自身に従わせうる力の働きによって、わたしたちの卑しいからだを、ご自身の栄光のからだと同じかたちに変えて下さるであろう。</span>

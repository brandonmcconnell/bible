<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="コロサイ人への手紙 3:12; ヨハネの第一の手紙 4:12; ヨハネの第一の手紙 4:7–8"> そこで、あなたがたに、キリストによる勧め、愛の励まし、御霊の交わり、熱愛とあわれみとが、いくらかでもあるなら、</span>
<span className="v" id="v2" data-v="2" data-xref="ローマ人への手紙 12:16; ペテロの第一の手紙 3:8–9; コリント人への第一の手紙 1:10"> どうか同じ思いとなり、同じ愛の心を持ち、心を合わせ、一つ思いになって、わたしの喜びを満たしてほしい。</span>
<span className="v" id="v3" data-v="3" data-xref="ローマ人への手紙 12:10; ガラテヤ人への手紙 5:26; エペソ人への手紙 5:21"> 何事も党派心や虚栄からするのでなく、へりくだった心をもって互に人を自分よりすぐれた者としなさい。</span>
<span className="v" id="v4" data-v="4" data-xref="コリント人への第一の手紙 10:24; ローマ人への手紙 15:1; ヤコブの手紙 2:8"> おのおの、自分のことばかりでなく、他人のことも考えなさい。</span>
<span className="v" id="v5" data-v="5" data-xref="ヨハネの第一の手紙 2:6; マタイによる福音書 11:29; ペテロの第一の手紙 2:21"> キリスト・イエスにあっていだいているのと同じ思いを、あなたがたの間でも互に生かしなさい。</span>
<span className="v" id="v6" data-v="6" data-xref="ヨハネによる福音書 5:18; コリント人への第二の手紙 4:4; ヘブル人への手紙 1:3"> キリストは、神のかたちであられたが、神と等しくあることを固守すべき事とは思わず、</span>
<span className="v" id="v7" data-v="7" data-xref="コリント人への第二の手紙 8:9; マタイによる福音書 20:28; ヨハネによる福音書 1:14"> かえって、おのれをむなしうして僕のかたちをとり、人間の姿になられた。その有様は人と異ならず、</span>
<span className="v" id="v8" data-v="8" data-xref="ヨハネによる福音書 10:18; ヘブル人への手紙 12:2; ローマ人への手紙 5:19"> おのれを低くして、死に至るまで、しかも十字架の死に至るまで従順であられた。</span>
<span className="v" id="v9" data-v="9" data-xref="ヨハネの黙示録 19:16; マタイによる福音書 28:18; ペテロの第一の手紙 3:22"> それゆえに、神は彼を高く引き上げ、すべての名にまさる名を彼に賜わった。</span>
<span className="v" id="v10" data-v="10" data-xref="イザヤ書 45:23–25; マタイによる福音書 28:18; ヨハネの黙示録 5:13–14"> それは、イエスの御名によって、天上のもの、地上のもの、地下のものなど、あらゆるものがひざをかがめ、</span>
<span className="v" id="v11" data-v="11" data-xref="ヨハネの第一の手紙 4:15; ローマ人への手紙 14:11; ヨハネによる福音書 13:13"> また、あらゆる舌が、「イエス・キリストは主である」と告白して、栄光を父なる神に帰するためである。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="ペテロの第二の手紙 1:5–10; ルカによる福音書 13:23–24; コリント人への第一の手紙 15:58"> わたしの愛する者たちよ。そういうわけだから、あなたがたがいつも従順であったように、わたしが一緒にいる時だけでなく、いない今は、いっそう従順でいて、恐れおののいて自分の救の達成に努めなさい。</span>
<span className="v" id="v13" data-v="13" data-xref="ヘブル人への手紙 13:21; コリント人への第二の手紙 3:5; テモテヘの第二の手紙 1:9"> あなたがたのうちに働きかけて、その願いを起させ、かつ実現に至らせるのは神であって、それは神のよしとされるところだからである。</span>
<span className="v" id="v14" data-v="14" data-xref="ペテロの第一の手紙 4:9; コリント人への第一の手紙 10:10; ピリピ人への手紙 2:3"> すべてのことを、つぶやかず疑わないでしなさい。</span>
<span className="v" id="v15" data-v="15" data-xref="マタイによる福音書 5:14–16; ペテロの第一の手紙 2:12; マタイによる福音書 5:45"> それは、あなたがたが責められるところのない純真な者となり、曲った邪悪な時代のただ中にあって、傷のない神の子となるためである。あなたがたは、いのちの言葉を堅く持って、彼らの間で星のようにこの世に輝いている。</span>
<span className="v" id="v16" data-v="16" data-xref="コリント人への第一の手紙 9:26; ガラテヤ人への手紙 2:2; ヨハネの第一の手紙 1:1"> このようにして、キリストの日に、わたしは自分の走ったことがむだでなく、労したこともむだではなかったと誇ることができる。</span>
<span className="v" id="v17" data-v="17" data-xref="テモテヘの第二の手紙 4:6; ローマ人への手紙 15:16; ヘブル人への手紙 13:15–16"> そして、たとい、あなたがたの信仰の供え物をささげる祭壇に、わたしの血をそそぐことがあっても、わたしは喜ぼう。あなたがた一同と共に喜ぼう。</span>
<span className="v" id="v18" data-v="18" data-xref="ヤコブの手紙 1:2–4; ピリピ人への手紙 4:4; ピリピ人への手紙 3:1"> 同じように、あなたがたも喜びなさい。わたしと共に喜びなさい。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="コリント人への第一の手紙 4:17; テサロニケ人への第一の手紙 3:6–8; テサロニケ人への第一の手紙 3:2"> さて、わたしは、まもなくテモテをあなたがたのところに送りたいと、主イエスにあって願っている。それは、あなたがたの様子を知って、わたしも力づけられたいからである。</span>
<span className="v" id="v20" data-v="20" data-xref="ピリピ人への手紙 2:2; コリント人への第一の手紙 16:10; ピリピ人への手紙 2:22"> テモテのような心で、親身になってあなたがたのことを心配している者は、ほかにひとりもない。</span>
<span className="v" id="v21" data-v="21" data-xref="コリント人への第一の手紙 10:24; マタイによる福音書 16:24; ピリピ人への手紙 2:4"> 人はみな、自分のことを求めるだけで、キリスト・イエスのことは求めていない。</span>
<span className="v" id="v22" data-v="22" data-xref="コリント人への第一の手紙 4:17; コリント人への第二の手紙 2:9; テモテヘの第二の手紙 1:2"> しかし、テモテの錬達ぶりは、あなたがたの知っているとおりである。すなわち、子が父に対するようにして、わたしと一緒に福音に仕えてきたのである。</span>
<span className="v" id="v23" data-v="23" data-xref="サムエル記上 22:3; ピリピ人への手紙 2:19"> そこで、この人を、わたしの成行きがわかりしだい、すぐにでも、そちらへ送りたいと願っている。</span>
<span className="v" id="v24" data-v="24" data-xref="ヨハネの第三の手紙 1:14; ピレモンヘの手紙 1:22; ピリピ人への手紙 1:25–26"> わたし自身もまもなく行けるものと、主にあって確信している。</span>
<span className="v" id="v25" data-v="25" data-xref="ピリピ人への手紙 4:18; ピレモンヘの手紙 1:1–2; ピリピ人への手紙 4:3"> しかし、さしあたり、わたしの同労者で戦友である兄弟、また、あなたがたの使者としてわたしの窮乏を補ってくれたエパフロデトを、あなたがたのもとに送り返すことが必要だと思っている。</span>
<span className="v" id="v26" data-v="26" data-xref="ローマ人への手紙 12:15; 箴言 12:25; エペソ人への手紙 3:13"> 彼は、あなたがた一同にしきりに会いたがっているからである。その上、自分の病気のことがあなたがたに聞えたので、彼は心苦しく思っている。</span>
<span className="v" id="v27" data-v="27" data-xref="詩篇 34:19; ピリピ人への手紙 2:30; 詩篇 103:3–4"> 彼は実に、ひん死の病気にかかったが、神は彼をあわれんで下さった。彼ばかりではなく、わたしをもあわれんで下さったので、わたしは悲しみに悲しみを重ねないですんだのである。</span>
<span className="v" id="v28" data-v="28" data-xref="ヨハネによる福音書 16:22; テモテヘの第二の手紙 1:4; ピリピ人への手紙 2:26–27"> そこで、大急ぎで彼を送り返す。これで、あなたがたは彼と再び会って喜び、わたしもまた、心配を和らげることができよう。</span>
<span className="v" id="v29" data-v="29" data-xref="テサロニケ人への第一の手紙 5:12; コリント人への第一の手紙 16:18; テモテヘの第一の手紙 5:17"> こういうわけだから、大いに喜んで、主にあって彼を迎えてほしい。また、こうした人々は尊重せねばならない。</span>
<span className="v" id="v30" data-v="30" data-xref="コリント人への第一の手紙 16:17; 使徒行伝 20:24; ピリピ人への手紙 4:10"> 彼は、わたしに対してあなたがたが奉仕のできなかった分を補おうとして、キリストのわざのために命をかけ、死ぬばかりになったのである。</span>

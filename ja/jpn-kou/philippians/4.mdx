<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ピリピ人への手紙 1:27; コリント人への第一の手紙 16:13; 詩篇 27:14"> だから、わたしの愛し慕っている兄弟たちよ。わたしの喜びであり冠である愛する者たちよ。このように、主にあって堅く立ちなさい。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="ヘブル人への手紙 12:14; コリント人への第一の手紙 1:10; マルコによる福音書 9:50"> わたしはユウオデヤに勧め、またスントケに勧める。どうか、主にあって一つ思いになってほしい。</span>
<span className="v" id="v3" data-v="3" data-xref="ヨハネの黙示録 3:5; ヨハネの黙示録 13:8; ルカによる福音書 10:20"> ついては、真実な協力者よ。あなたにお願いする。このふたりの女を助けてあげなさい。彼らは、「いのちの書」に名を書きとめられているクレメンスや、その他の同労者たちと協力して、福音のためにわたしと共に戦ってくれた女たちである。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="テサロニケ人への第一の手紙 5:16–18; ローマ人への手紙 12:12; ヤコブの手紙 1:2–4"> あなたがたは、主にあっていつも喜びなさい。繰り返して言うが、喜びなさい。</span>
<span className="v" id="v5" data-v="5" data-xref="ヤコブの手紙 5:8–9; マタイによる福音書 6:25; テトスヘの手紙 3:2"> あなたがたの寛容を、みんなの人に示しなさい。主は近い。</span>
<span className="v" id="v6" data-v="6" data-xref="箴言 3:5–6; ペテロの第一の手紙 5:7; マタイによる福音書 6:25–33"> 何事も思い煩ってはならない。ただ、事ごとに、感謝をもって祈と願いとをささげ、あなたがたの求めるところを神に申し上げるがよい。</span>
<span className="v" id="v7" data-v="7" data-xref="ヨハネによる福音書 14:27; イザヤ書 26:3; テサロニケ人への第二の手紙 3:16"> そうすれば、人知ではとうてい測り知ることのできない神の平安が、あなたがたの心と思いとを、キリスト・イエスにあって守るであろう。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="ヤコブの手紙 3:17; テトスヘの手紙 2:7; ローマ人への手紙 12:9–21"> 最後に、兄弟たちよ。すべて真実なこと、すべて尊ぶべきこと、すべて正しいこと、すべて純真なこと、すべて愛すべきこと、すべてほまれあること、また徳といわれるもの、称賛に値するものがあれば、それらのものを心にとめなさい。</span>
<span className="v" id="v9" data-v="9" data-xref="ヤコブの手紙 1:22; ピリピ人への手紙 3:17; テサロニケ人への第一の手紙 4:1–8"> あなたがたが、わたしから学んだこと、受けたこと、聞いたこと、見たことは、これを実行しなさい。そうすれば、平和の神が、あなたがたと共にいますであろう。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="コリント人への第二の手紙 11:9; ガラテヤ人への手紙 6:6; コリント人への第二の手紙 7:6–7"> さて、わたしが主にあって大いに喜んでいるのは、わたしを思う心が、あなたがたに今またついに芽ばえてきたことである。実は、あなたがたは、わたしのことを心にかけてくれてはいたが、よい機会がなかったのである。</span>
<span className="v" id="v11" data-v="11" data-xref="テモテヘの第一の手紙 6:6–9; ヘブル人への手紙 13:5–6; マタイによる福音書 6:31–34"> わたしは乏しいから、こう言うのではない。わたしは、どんな境遇にあっても、足ることを学んだ。</span>
<span className="v" id="v12" data-v="12" data-xref="マタイによる福音書 11:29; コリント人への第二の手紙 12:7–10; コリント人への第二の手紙 11:27"> わたしは貧に処する道を知っており、富におる道も知っている。わたしは、飽くことにも飢えることにも、富むことにも乏しいことにも、ありとあらゆる境遇に処する秘けつを心得ている。</span>
<span className="v" id="v13" data-v="13" data-xref="イザヤ書 41:10; コリント人への第二の手紙 12:9–10; コロサイ人への手紙 1:11"> わたしを強くして下さるかたによって、何事でもすることができる。</span>
<span className="v" id="v14" data-v="14" data-xref="ヘブル人への手紙 13:16; ピリピ人への手紙 1:7; ヘブル人への手紙 10:34"> しかし、あなたがたは、よくもわたしと患難を共にしてくれた。</span>
<span className="v" id="v15" data-v="15" data-xref="ピリピ人への手紙 1:5; コリント人への第二の手紙 11:8–12; 使徒行伝 16:40–5"> ピリピの人たちよ。あなたがたも知っているとおり、わたしが福音を宣伝し始めたころ、マケドニヤから出かけて行った時、物のやりとりをしてわたしの働きに参加した教会は、あなたがたのほかには全く無かった。</span>
<span className="v" id="v16" data-v="16" data-xref="テサロニケ人への第一の手紙 2:9; 使徒行伝 17:1; テサロニケ人への第一の手紙 2:18"> またテサロニケでも、一再ならず、物を送ってわたしの欠乏を補ってくれた。</span>
<span className="v" id="v17" data-v="17" data-xref="テトスヘの手紙 3:14; ヘブル人への手紙 6:10; コリント人への第二の手紙 9:9–13"> わたしは、贈り物を求めているのではない。わたしの求めているのは、あなたがたの勘定をふやしていく果実なのである。</span>
<span className="v" id="v18" data-v="18" data-xref="ヘブル人への手紙 13:16; ピリピ人への手紙 4:12; コリント人への第二の手紙 9:12"> わたしは、すべての物を受けてあり余るほどである。エパフロデトから、あなたがたの贈り物をいただいて、飽き足りている。それは、かんばしいかおりであり、神の喜んで受けて下さる供え物である。</span>
<span className="v" id="v19" data-v="19" data-xref="コリント人への第二の手紙 9:8–11; 詩篇 84:11; ペテロの第一の手紙 5:10"> わたしの神は、ご自身の栄光の富の中から、あなたがたのいっさいの必要を、キリスト・イエスにあって満たして下さるであろう。</span>
<span className="v" id="v20" data-v="20" data-xref="ローマ人への手紙 11:36; 詩篇 115:1; ヨハネの黙示録 14:7"> わたしたちの父なる神に、栄光が世々限りなくあるように、アァメン。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="ガラテヤ人への手紙 1:2; ピレモンヘの手紙 1:23–24; コロサイ人への手紙 4:10–14"> キリスト・イエスにある聖徒のひとりびとりに、よろしく。わたしと一緒にいる兄弟たちから、あなたがたによろしく。</span>
<span className="v" id="v22" data-v="22" data-xref="ピリピ人への手紙 1:13; コリント人への第二の手紙 13:13; ローマ人への手紙 16:16"> すべての聖徒たちから、特にカイザルの家の者たちから、よろしく。</span>
</div>

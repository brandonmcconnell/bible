<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行伝 7:2; 使徒行伝 28:17; 使徒行伝 13:26"> 「兄弟たち、父たちよ、いま申し上げるわたしの弁明を聞いていただきたい」。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行伝 21:40"> パウロが、ヘブル語でこう語りかけるのを聞いて、人々はますます静粛になった。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行伝 26:5; ピリピ人への手紙 3:5–6; 使徒行伝 9:11"> そこで彼は言葉をついで言った、「わたしはキリキヤのタルソで生れたユダヤ人であるが、この都で育てられ、ガマリエルのひざもとで先祖伝来の律法について、きびしい薫陶を受け、今日の皆さんと同じく神に対して熱心な者であった。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行伝 22:19–20; テモテヘの第一の手紙 1:13–15; 使徒行伝 26:9–11"> そして、この道を迫害し、男であれ女であれ、縛りあげて獄に投じ、彼らを死に至らせた。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行伝 9:1–2; ルカによる福音書 22:66; 使徒行伝 5:21"> このことは、大祭司も長老たち一同も、証明するところである。さらにわたしは、この人たちからダマスコの同志たちへあてた手紙をもらって、その地にいる者たちを縛りあげ、エルサレムにひっぱってきて、処罰するため、出かけて行った。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="使徒行伝 9:3–8; 使徒行伝 26:12–18; ヨハネの黙示録 1:16"> 旅をつづけてダマスコの近くにきた時に、真昼ごろ、突然、つよい光が天からわたしをめぐり照した。</span>
<span className="v" id="v7" data-v="7" data-xref="エレミヤ書 2:9; マタイによる福音書 25:45; 創世記 22:11"> わたしは地に倒れた。そして、『サウロ、サウロ、なぜわたしを迫害するのか』と、呼びかける声を聞いた。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行伝 26:9; サムエル記上 8:7; 出エジプト記 16:7–8"> これに対してわたしは、『主よ、あなたはどなたですか』と言った。すると、その声が、『わたしは、あなたが迫害しているナザレ人イエスである』と答えた。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行伝 9:7; ダニエル書 10:7; 使徒行伝 26:13"> わたしと一緒にいた者たちは、その光は見たが、わたしに語りかけたかたの声は聞かなかった。</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行伝 16:30; 使徒行伝 22:12–16; 使徒行伝 2:37"> わたしが『主よ、わたしは何をしたらよいでしょうか』と尋ねたところ、主は言われた、『起きあがってダマスコに行きなさい。そうすれば、あなたがするように決めてある事が、すべてそこで告げられるであろう』。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行伝 9:8–9; 使徒行伝 13:11; イザヤ書 42:16"> わたしは、光の輝きで目がくらみ、何も見えなくなっていたので、連れの者たちに手を引かれながら、ダマスコに行った。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="使徒行伝 10:22; 使徒行伝 6:3; ヨハネの第三の手紙 1:12"> すると、律法に忠実で、ダマスコ在住のユダヤ人全体に評判のよいアナニヤという人が、</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行伝 9:17–18; ピレモンヘの手紙 1:16"> わたしのところにきて、そばに立ち、『兄弟サウロよ、見えるようになりなさい』と言った。するとその瞬間に、わたしの目が開いて、彼の姿が見えた。</span>
<span className="v" id="v14" data-v="14" data-xref="ガラテヤ人への手紙 1:12; コリント人への第一の手紙 15:8; コリント人への第一の手紙 9:1"> 彼は言った、『わたしたちの先祖の神が、あなたを選んでみ旨を知らせ、かの義人を見させ、その口から声をお聞かせになった。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行伝 23:11; 使徒行伝 4:20; ヨハネによる福音書 15:27"> それはあなたが、その見聞きした事につき、すべての人に対して、彼の証人になるためである。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行伝 2:38; 使徒行伝 2:21; テトスヘの手紙 3:5"> そこで今、なんのためらうことがあろうか。すぐ立って、み名をとなえてバプテスマを受け、あなたの罪を洗い落しなさい』。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="コリント人への第二の手紙 12:1–4; 使徒行伝 10:9–10; 使徒行伝 9:26–28"> それからわたしは、エルサレムに帰って宮で祈っているうちに、夢うつつになり、</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行伝 9:29; ルカによる福音書 21:21; エゼキエル書 3:6–7"> 主にまみえたが、主は言われた、『急いで、すぐにエルサレムを出て行きなさい。わたしについてのあなたのあかしを、人々が受けいれないから』。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行伝 22:4; マタイによる福音書 10:17; 使徒行伝 8:3"> そこで、わたしが言った、『主よ、彼らは、わたしがいたるところの会堂で、あなたを信じる人々を獄に投じたり、むち打ったりしていたことを、知っています。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行伝 7:58; 使徒行伝 8:1; ローマ人への手紙 1:32"> また、あなたの証人ステパノの血が流された時も、わたしは立ち合っていてそれに賛成し、また彼を殺した人たちの上着の番をしていたのです』。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行伝 9:15; テモテヘの第一の手紙 2:7; エペソ人への手紙 3:6–8"> すると、主がわたしに言われた、『行きなさい。わたしが、あなたを遠く異邦の民へつかわすのだ』」。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="使徒行伝 25:24; 使徒行伝 21:36; ヨハネによる福音書 19:15"> 彼の言葉をここまで聞いていた人々は、このとき、声を張りあげて言った、「こんな男は地上から取り除いてしまえ。生かしおくべきではない」。</span>
<span className="v" id="v23" data-v="23" data-xref="サムエル記下 16:13; 使徒行伝 26:11; 伝道の書 10:3"> 人々がこうわめき立てて、空中に上着を投げ、ちりをまき散らす始末であったので、</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行伝 21:31–32; 使徒行伝 21:34; ヨハネによる福音書 19:1"> 千卒長はパウロを兵営に引き入れるように命じ、どういうわけで、彼に対してこんなにわめき立てているのかを確かめるため、彼をむちの拷問にかけて、取り調べるように言いわたした。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行伝 16:37; 使徒行伝 25:16; 使徒行伝 27:43"> 彼らがむちを当てるため、彼を縛りつけていた時、パウロはそばに立っている百卒長に言った、「ローマの市民たる者を、裁判にかけもしないで、むち打ってよいのか」。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行伝 23:27; 使徒行伝 22:29"> 百卒長はこれを聞き、千卒長のところに行って報告し、そして言った、「どうなさいますか。あの人はローマの市民なのです」。</span>
<span className="v" id="v27" data-v="27"> そこで、千卒長がパウロのところにきて言った、「わたしに言ってくれ。あなたはローマの市民なのか」。パウロは「そうです」と言った。</span>
<span className="v" id="v28" data-v="28"> これに対して千卒長が言った、「わたしはこの市民権を、多額の金で買い取ったのだ」。するとパウロは言った、「わたしは生れながらの市民です」。</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行伝 21:33; 使徒行伝 22:24–26; 使徒行伝 16:38–39"> そこで、パウロを取り調べようとしていた人たちは、ただちに彼から身を引いた。千卒長も、パウロがローマの市民であること、また、そういう人を縛っていたことがわかって、恐れた。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="使徒行伝 23:28; 使徒行伝 21:33; 使徒行伝 21:11"> 翌日、彼は、ユダヤ人がなぜパウロを訴え出たのか、その真相を知ろうと思って彼を解いてやり、同時に祭司長たちと全議会とを召集させ、そこに彼を引き出して、彼らの前に立たせた。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行伝 18:23–28; コリント人への第一の手紙 16:12; コリント人への第一の手紙 1:12"> アポロがコリントにいた時、パウロは奥地をとおってエペソにきた。そして、ある弟子たちに出会って、</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネによる福音書 7:39; 使徒行伝 11:15–17; ガラテヤ人への手紙 3:5"> 彼らに「あなたがたは、信仰にはいった時に、聖霊を受けたのか」と尋ねたところ、「いいえ、聖霊なるものがあることさえ、聞いたことがありません」と答えた。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行伝 18:25; コリント人への第一の手紙 12:13; 使徒行伝 8:16"> 「では、だれの名によってバプテスマを受けたのか」と彼がきくと、彼らは「ヨハネの名によるバプテスマを受けました」と答えた。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネによる福音書 1:29–34; 使徒行伝 11:16; 使徒行伝 1:5"> そこで、パウロが言った、「ヨハネは悔改めのバプテスマを授けたが、それによって、自分のあとに来るかた、すなわち、イエスを信じるように、人々に勧めたのである」。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行伝 8:12; 使徒行伝 8:16; ローマ人への手紙 6:3–4"> 人々はこれを聞いて、主イエスの名によるバプテスマを受けた。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行伝 6:6; 使徒行伝 2:4; マルコによる福音書 16:17"> そして、パウロが彼らの上に手をおくと、聖霊が彼らにくだり、それから彼らは異言を語ったり、預言をしたりし出した。</span>
<span className="v" id="v7" data-v="7"> その人たちはみんなで十二人ほどであった。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="使徒行伝 28:23; 使徒行伝 1:3; 使徒行伝 9:20–22"> それから、パウロは会堂にはいって、三か月のあいだ、大胆に神の国について論じ、また勧めをした。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行伝 19:23; 使徒行伝 9:2; 使徒行伝 18:6–8"> ところが、ある人たちは心をかたくなにして、信じようとせず、会衆の前でこの道をあしざまに言ったので、彼は弟子たちを引き連れて、その人たちから離れ、ツラノの講堂で毎日論じた。</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行伝 20:31; テモテヘの第二の手紙 1:15; 使徒行伝 16:6"> それが二年間も続いたので、アジヤに住んでいる者は、ユダヤ人もギリシヤ人も皆、主の言を聞いた。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="マルコによる福音書 16:17–20; 使徒行伝 5:12; ローマ人への手紙 15:18–19"> 神は、パウロの手によって、異常な力あるわざを次々になされた。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行伝 5:15; 列王紀下 13:20–21; マルコによる福音書 16:17"> たとえば、人々が、彼の身につけている手ぬぐいや前掛けを取って病人にあてると、その病気が除かれ、悪霊が出て行くのであった。</span>
<span className="v" id="v13" data-v="13" data-xref="マタイによる福音書 12:27; マルコによる福音書 9:38; ルカによる福音書 11:19"> そこで、ユダヤ人のまじない師で、遍歴している者たちが、悪霊につかれている者にむかって、主イエスの名をとなえ、「パウロの宣べ伝えているイエスによって命じる。出て行け」と、ためしに言ってみた。</span>
<span className="v" id="v14" data-v="14"> ユダヤの祭司長スケワという者の七人のむすこたちも、そんなことをしていた。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行伝 16:17–18; ルカによる福音書 4:33–35; マルコによる福音書 1:34"> すると悪霊がこれに対して言った、「イエスなら自分は知っている。パウロもわかっている。だが、おまえたちは、いったい何者だ」。</span>
<span className="v" id="v16" data-v="16" data-xref="ルカによる福音書 8:29; マルコによる福音書 5:3–4; マルコによる福音書 5:15"> そして、悪霊につかれている人が、彼らに飛びかかり、みんなを押えつけて負かしたので、彼らは傷を負ったまま裸になって、その家を逃げ出した。</span>
<span className="v" id="v17" data-v="17" data-xref="テサロニケ人への第二の手紙 1:12; 使徒行伝 5:5; ピリピ人への手紙 2:9–11"> このことがエペソに住むすべてのユダヤ人やギリシヤ人に知れわたって、みんな恐怖に襲われ、そして、主イエスの名があがめられた。</span>
<span className="v" id="v18" data-v="18" data-xref="ローマ人への手紙 10:10; 詩篇 32:5; マタイによる福音書 3:6"> また信者になった者が大ぜいきて、自分の行為を打ちあけて告白した。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行伝 13:8; 出エジプト記 32:20; 創世記 35:4"> それから、魔術を行っていた多くの者が、魔術の本を持ち出してきては、みんなの前で焼き捨てた。その値段を総計したところ、銀五万にも上ることがわかった。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行伝 12:24; 使徒行伝 6:7; イザヤ書 55:11"> このようにして、主の言はますます盛んにひろまり、また力を増し加えていった。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="使徒行伝 20:22; 使徒行伝 20:16; 使徒行伝 23:11"> これらの事があった後、パウロは御霊に感じて、マケドニヤ、アカヤをとおって、エルサレムへ行く決心をした。そして言った、「わたしは、そこに行ったのち、ぜひローマをも見なければならない」。</span>
<span className="v" id="v22" data-v="22" data-xref="ローマ人への手紙 16:23; テモテヘの第二の手紙 4:20; 使徒行伝 16:3"> そこで、自分に仕えている者の中から、テモテとエラストとのふたりを、まずマケドニヤに送り出し、パウロ自身は、なおしばらくアジヤにとどまった。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="使徒行伝 19:9; 使徒行伝 24:22; コリント人への第二の手紙 1:8–10"> そのころ、この道について容易ならぬ騒動が起った。</span>
<span className="v" id="v24" data-v="24" data-xref="テモテヘの第一の手紙 6:9–10; 使徒行伝 16:16; 使徒行伝 16:19"> そのいきさつは、こうである。デメテリオという銀細工人が、銀でアルテミス神殿の模型を造って、職人たちに少なからぬ利益を得させていた。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行伝 16:19; ホセア書 12:7–8; ヨハネの黙示録 18:11–19"> この男がその職人たちや、同類の仕事をしていた者たちを集めて言った、「諸君、われわれがこの仕事で、金もうけをしていることは、ご承知のとおりだ。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行伝 17:29; コリント人への第一の手紙 8:4; イザヤ書 44:10–20"> しかるに、諸君の見聞きしているように、あのパウロが、手で造られたものは神様ではないなどと言って、エペソばかりか、ほとんどアジヤ全体にわたって、大ぜいの人々を説きつけて誤らせた。</span>
<span className="v" id="v27" data-v="27" data-xref="ゼパニヤ書 2:11; テモテヘの第一の手紙 6:5; マタイによる福音書 23:13"> これでは、お互の仕事に悪評が立つおそれがあるばかりか、大女神アルテミスの宮も軽んじられ、ひいては全アジヤ、いや全世界が拝んでいるこの大女神のご威光さえも、消えてしまいそうである」。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="ヨハネの黙示録 13:4; ヨハネの黙示録 17:13; 使徒行伝 16:19–24"> これを聞くと、人々は怒りに燃え、大声で「大いなるかな、エペソ人のアルテミス」と叫びつづけた。</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行伝 20:4; コロサイ人への手紙 4:10; 使徒行伝 27:2"> そして、町中が大混乱に陥り、人々はパウロの道連れであるマケドニヤ人ガイオとアリスタルコとを捕えて、いっせいに劇場へなだれ込んだ。</span>
<span className="v" id="v30" data-v="30" data-xref="使徒行伝 21:39; サムエル記下 18:2–3; 使徒行伝 17:22–31"> パウロは群衆の中にはいって行こうとしたが、弟子たちがそれをさせなかった。</span>
<span className="v" id="v31" data-v="31" data-xref="使徒行伝 19:10; 使徒行伝 21:12; 使徒行伝 16:6"> アジヤ州の議員で、パウロの友人であった人たちも、彼に使をよこして、劇場にはいって行かないようにと、しきりに頼んだ。</span>
<span className="v" id="v32" data-v="32" data-xref="使徒行伝 21:34; 使徒行伝 19:40; マタイによる福音書 11:7–9"> 中では、集会が混乱に陥ってしまって、ある者はこのことを、ほかの者はあのことを、どなりつづけていたので、大多数の者は、なんのために集まったのかも、わからないでいた。</span>
<span className="v" id="v33" data-v="33" data-xref="使徒行伝 12:17; テモテヘの第二の手紙 4:14; テモテヘの第一の手紙 1:20"> そこで、ユダヤ人たちが、前に押し出したアレキサンデルなる者を、群衆の中のある人たちが促したため、彼は手を振って、人々に弁明を試みようとした。</span>
<span className="v" id="v34" data-v="34" data-xref="使徒行伝 19:28; マタイによる福音書 6:7; ヨハネの黙示録 13:4"> ところが、彼がユダヤ人だとわかると、みんなの者がいっせいに「大いなるかな、エペソ人のアルテミス」と二時間ばかりも叫びつづけた。</span>
<span className="v" id="v35" data-v="35" data-xref="テサロニケ人への第二の手紙 2:10–11; テモテヘの第一の手紙 4:2; エペソ人への手紙 2:12"> ついに、市の書記役が群衆を押し静めて言った、「エペソの諸君、エペソ市が大女神アルテミスと、天くだったご神体との守護役であることを知らない者が、ひとりでもいるだろうか。</span>
<span className="v" id="v36" data-v="36" data-xref="箴言 14:29; 使徒行伝 5:35–39; 箴言 25:8"> これは否定のできない事実であるから、諸君はよろしく静かにしているべきで、乱暴な行動は、いっさいしてはならない。</span>
<span className="v" id="v37" data-v="37" data-xref="コリント人への第二の手紙 6:3; ローマ人への手紙 2:22; 使徒行伝 25:8"> 諸君はこの人たちをここにひっぱってきたが、彼らは宮を荒す者でも、われわれの女神をそしる者でもない。</span>
<span className="v" id="v38" data-v="38" data-xref="使徒行伝 13:7; コリント人への第一の手紙 6:1; 使徒行伝 18:14"> だから、もしデメテリオなりその職人仲間なりが、だれかに対して訴え事があるなら、裁判の日はあるし、総督もいるのだから、それぞれ訴え出るがよい。</span>
<span className="v" id="v39" data-v="39"> しかし、何かもっと要求したい事があれば、それは正式の議会で解決してもらうべきだ。</span>
<span className="v" id="v40" data-v="40" data-xref="使徒行伝 17:5–8; マタイによる福音書 26:5; 使徒行伝 20:1"> きょうの事件については、この騒ぎを弁護できるような理由が全くないのだから、われわれは治安をみだす罪に問われるおそれがある」。</span>
<span className="v" id="v41" data-v="41" data-xref="伝道の書 9:17; 詩篇 65:7; コリント人への第二の手紙 1:8–10"> こう言って、彼はこの集会を解散させた。</span>
</div>

<div className="bible-chapter" lang="ja" dir="ltr" data-lang="ja" data-translation="jpn-kou" data-translation-id="jpn_kou" data-translation-label="口語訳" data-book="ACT" data-book-slug="acts" data-book-name="使徒行伝" data-chapter="23" data-verses="35">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行伝 24:16; テモテヘの第二の手紙 1:3; コリント人への第二の手紙 1:12"> パウロは議会を見つめて言った、「兄弟たちよ、わたしは今日まで、神の前に、ひたすら明らかな良心にしたがって行動してきた」。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネによる福音書 18:22; 使徒行伝 24:1; ミカ書 5:1"> すると、大祭司アナニヤが、パウロのそばに立っている者たちに、彼の口を打てと命じた。</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 25:1–2; ヨハネによる福音書 7:51; マタイによる福音書 23:27–28"> そのとき、パウロはアナニヤにむかって言った、「白く塗られた壁よ、神があなたを打つであろう。あなたは、律法にしたがって、わたしをさばくために座についているのに、律法にそむいて、わたしを打つことを命じるのか」。</span>
<span className="v" id="v4" data-v="4"> すると、そばに立っている者たちが言った、「神の大祭司に対して無礼なことを言うのか」。</span>
<span className="v" id="v5" data-v="5" data-xref="出エジプト記 22:28; 伝道の書 10:20; ユダの手紙 1:8–9"> パウロは言った、「兄弟たちよ、彼が大祭司だとは知らなかった。聖書に『民のかしらを悪く言ってはいけない』と、書いてあるのだった」。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="使徒行伝 24:15; 使徒行伝 24:21; 使徒行伝 26:5–8"> パウロは、議員の一部がサドカイ人であり、一部はパリサイ人であるのを見て、議会の中で声を高めて言った、「兄弟たちよ、わたしはパリサイ人であり、パリサイ人の子である。わたしは、死人の復活の望みをいだいていることで、裁判を受けているのである」。</span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 55:9; ヨハネによる福音書 7:40–43; マタイによる福音書 10:34"> 彼がこう言ったところ、パリサイ人とサドカイ人との間に争論が生じ、会衆が相分れた。</span>
<span className="v" id="v8" data-v="8" data-xref="ルカによる福音書 20:27; マタイによる福音書 22:23; マルコによる福音書 12:18"> 元来、サドカイ人は、復活とか天使とか霊とかは、いっさい存在しないと言い、パリサイ人は、それらは、みな存在すると主張している。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行伝 22:7; 使徒行伝 22:17–18; ヨハネによる福音書 12:29"> そこで、大騒ぎとなった。パリサイ派のある律法学者たちが立って、強く主張して言った、「われわれは、この人には何も悪いことがないと思う。あるいは、霊か天使かが、彼に告げたのかも知れない」。</span>
<span className="v" id="v10" data-v="10" data-xref="ヤコブの手紙 1:19; ヤコブの手紙 3:14–2; 使徒行伝 22:24"> こうして、争論が激しくなったので、千卒長は、パウロが彼らに引き裂かれるのを気づかって、兵卒どもに、降りて行ってパウロを彼らの中から力づくで引き出し、兵営に連れて来るように、命じた。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="使徒行伝 18:9; 使徒行伝 19:21; テモテヘの第二の手紙 4:17"> その夜、主がパウロに臨んで言われた、「しっかりせよ。あなたは、エルサレムでわたしのことをあかししたように、ローマでもあかしをしなくてはならない」。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="使徒行伝 23:30; イザヤ書 8:9–10; 使徒行伝 23:21"> 夜が明けると、ユダヤ人らは申し合わせをして、パウロを殺すまでは飲食をいっさい断つと、誓い合った。</span>
<span className="v" id="v13" data-v="13" data-xref="ヨハネによる福音書 16:2; サムエル記下 15:31; サムエル記下 15:12"> この陰謀に加わった者は、四十人あまりであった。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行伝 23:12; エレミヤ書 8:12; イザヤ書 3:9"> 彼らは、祭司長たちや長老たちのところに行って、こう言った。「われわれは、パウロを殺すまでは何も食べないと、堅く誓い合いました。</span>
<span className="v" id="v15" data-v="15" data-xref="イザヤ書 59:7; 詩篇 37:32–33; 箴言 1:16"> ついては、あなたがたは議会と組んで、彼のことでなお詳しく取調べをするように見せかけ、パウロをあなたがたのところに連れ出すように、千卒長に頼んで下さい。われわれとしては、パウロがそこにこないうちに殺してしまう手はずをしています」。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="使徒行伝 23:10; コリント人への第一の手紙 3:19; 使徒行伝 23:32"> ところが、パウロの姉妹の子が、この待伏せのことを耳にし、兵営にはいって行って、パウロにそれを知らせた。</span>
<span className="v" id="v17" data-v="17" data-xref="箴言 22:3; マタイによる福音書 8:8–9; マタイによる福音書 10:16"> そこでパウロは、百卒長のひとりを呼んで言った、「この若者を千卒長のところに連れて行ってください。何か報告することがあるようですから」。</span>
<span className="v" id="v18" data-v="18" data-xref="エペソ人への手紙 3:1; エペソ人への手紙 4:1; 使徒行伝 28:17"> この百卒長は若者を連れて行き、千卒長に引きあわせて言った、「囚人のパウロが、この若者があなたに話したいことがあるので、あなたのところに連れて行ってくれるようにと、わたしを呼んで頼みました」。</span>
<span className="v" id="v19" data-v="19" data-xref="エレミヤ書 31:32; エステル記 9:12; エステル記 7:2"> そこで千卒長は、若者の手を取り、人のいないところへ連れて行って尋ねた、「わたしに話したいことというのは、何か」。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行伝 23:14–15; 使徒行伝 23:1; 詩篇 12:2"> 若者が言った、「ユダヤ人たちが、パウロのことをもっと詳しく取調べをすると見せかけて、あす議会に彼を連れ出すように、あなたに頼むことに決めています。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行伝 23:12–14; 使徒行伝 14:5–6; コリント人への第二の手紙 11:26"> どうぞ、彼らの頼みを取り上げないで下さい。四十人あまりの者が、パウロを待伏せしているのです。彼らは、パウロを殺すまでは飲食をいっさい断つと、堅く誓い合っています。そして、いま手はずをととのえて、あなたの許可を待っているところなのです」。</span>
<span className="v" id="v22" data-v="22" data-xref="マルコによる福音書 1:44; ヨシュア記 2:14"> そこで千卒長は、「このことをわたしに知らせたことは、だれにも口外するな」と命じて、若者を帰した。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="マタイによる福音書 14:25; 使徒行伝 23:33; ルカによる福音書 12:38"> それから彼は、百卒長ふたりを呼んで言った、「歩兵二百名、騎兵七十名、槍兵二百名を、カイザリヤに向け出発できるように、今夜九時までに用意せよ。</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行伝 25:14; 使徒行伝 23:26; 使徒行伝 24:10"> また、パウロを乗せるために馬を用意して、彼を総督ペリクスのもとへ無事に連れて行け」。</span>
<span className="v" id="v25" data-v="25"> さらに彼は、次のような文面の手紙を書いた。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行伝 15:23; 使徒行伝 26:25; ルカによる福音書 1:3"> 「クラウデオ・ルシヤ、つつしんで総督ペリクス閣下の平安を祈ります。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行伝 22:25–29; 使徒行伝 21:31–33; 使徒行伝 24:6"> 本人のパウロが、ユダヤ人らに捕えられ、まさに殺されようとしていたのを、彼のローマ市民であることを知ったので、わたしは兵卒たちを率いて行って、彼を救い出しました。</span>
<span className="v" id="v28" data-v="28" data-xref="使徒行伝 22:30"> それから、彼が訴えられた理由を知ろうと思い、彼を議会に連れて行きました。</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行伝 26:31; 使徒行伝 25:25; 使徒行伝 18:15"> ところが、彼はユダヤ人の律法の問題で訴えられたものであり、なんら死刑または投獄に当る罪のないことがわかりました。</span>
<span className="v" id="v30" data-v="30" data-xref="使徒行伝 23:35; 使徒行伝 25:16; 使徒行伝 25:5–6"> しかし、この人に対して陰謀がめぐらされているとの報告がありましたので、わたしは取りあえず、彼を閣下のもとにお送りすることにし、訴える者たちには、閣下の前で、彼に対する申立てをするようにと、命じておきました」。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="テモテヘの第二の手紙 2:3–4; ルカによる福音書 7:8; 使徒行伝 23:23–24"> そこで歩兵たちは、命じられたとおりパウロを引き取って、夜の間にアンテパトリスまで連れて行き、</span>
<span className="v" id="v32" data-v="32" data-xref="使徒行伝 23:23; 使徒行伝 23:10"> 翌日は、騎兵たちにパウロを護送させることにして、兵営に帰って行った。</span>
<span className="v" id="v33" data-v="33" data-xref="使徒行伝 23:26; 使徒行伝 23:23–24; 使徒行伝 28:16"> 騎兵たちは、カイザリヤに着くと、手紙を総督に手渡し、さらにパウロを彼に引きあわせた。</span>
<span className="v" id="v34" data-v="34" data-xref="使徒行伝 21:39; 使徒行伝 25:1; ダニエル書 2:49"> 総督は手紙を読んでから、パウロに、どの州の者かと尋ね、キリキヤの出だと知って、</span>
<span className="v" id="v35" data-v="35" data-xref="使徒行伝 23:30; 使徒行伝 25:16; マタイによる福音書 27:27"> 「訴え人たちがきた時に、おまえを調べることにする」と言った。そして、ヘロデの官邸に彼を守っておくように命じた。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ルカによる福音書 22:4; 使徒行伝 6:12; 使徒行伝 23:6–9"> 彼らが人々にこのように語っているあいだに、祭司たち、宮守がしら、サドカイ人たちが近寄ってきて、</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行伝 17:18; テサロニケ人への第一の手紙 4:13–14; 使徒行伝 24:14–15"> 彼らが人々に教を説き、イエス自身に起った死人の復活を宣伝しているのに気をいら立て、</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行伝 5:18; マタイによる福音書 10:16–17; 使徒行伝 16:19–24"> 彼らに手をかけて捕え、はや日が暮れていたので、翌朝まで留置しておいた。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行伝 2:41; コリント人への第二の手紙 2:14–17; テモテヘの第二の手紙 2:9–10"> しかし、彼らの話を聞いた多くの人たちは信じた。そして、その男の数が五千人ほどになった。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="使徒行伝 4:8; マタイによる福音書 27:1–2; ルカによる福音書 20:1"> 明くる日、役人、長老、律法学者たちが、エルサレムに召集された。</span>
<span className="v" id="v6" data-v="6" data-xref="ルカによる福音書 3:2; ヨハネによる福音書 18:24; マタイによる福音書 26:3"> 大祭司アンナスをはじめ、カヤパ、ヨハネ、アレキサンデル、そのほか大祭司の一族もみな集まった。</span>
<span className="v" id="v7" data-v="7" data-xref="マタイによる福音書 21:23; マルコによる福音書 11:28; 使徒行伝 5:40"> そして、そのまん中に使徒たちを立たせて尋問した、「あなたがたは、いったい、なんの権威、また、だれの名によって、このことをしたのか」。</span>
<span className="v" id="v8" data-v="8" data-xref="ルカによる福音書 12:11–12; マタイによる福音書 10:19–20; 使徒行伝 2:4"> その時、ペテロが聖霊に満たされて言った、「民の役人たち、ならびに長老たちよ、</span>
<span className="v" id="v9" data-v="9" data-xref="ペテロの第一の手紙 3:15–17; 使徒行伝 3:7; ヨハネによる福音書 10:32"> わたしたちが、きょう、取調べを受けているのは、病人に対してした良いわざについてであり、この人がどうしていやされたかについてであるなら、</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行伝 5:29–32; 使徒行伝 3:6; 使徒行伝 2:36"> あなたがたご一同も、またイスラエルの人々全体も、知っていてもらいたい。この人が元気になってみんなの前に立っているのは、ひとえに、あなたがたが十字架につけて殺したのを、神が死人の中からよみがえらせたナザレ人イエス・キリストの御名によるのである。</span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 118:22–23; イザヤ書 28:16; マルコによる福音書 12:10–12"> このイエスこそは『あなたがた家造りらに捨てられたが、隅のかしら石となった石』なのである。</span>
<span className="v" id="v12" data-v="12" data-xref="ヨハネによる福音書 14:6; コリント人への第一の手紙 3:11; ヨハネによる福音書 3:36"> この人による以外に救はない。わたしたちを救いうる名は、これを別にしては、天下のだれにも与えられていないからである」。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="コリント人への第一の手紙 1:27; ヨハネによる福音書 7:15; マタイによる福音書 11:25"> 人々はペテロとヨハネとの大胆な話しぶりを見、また同時に、ふたりが無学な、ただの人たちであることを知って、不思議に思った。そして彼らがイエスと共にいた者であることを認め、</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行伝 19:36; 使徒行伝 3:8–12; 使徒行伝 4:21"> かつ、彼らにいやされた者がそのそばに立っているのを見ては、まったく返す言葉がなかった。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行伝 26:30–32; 使徒行伝 5:34–42; マタイによる福音書 5:22"> そこで、ふたりに議会から退場するように命じてから、互に協議をつづけて</span>
<span className="v" id="v16" data-v="16" data-xref="ルカによる福音書 21:15; 使徒行伝 6:10; ヨハネによる福音書 12:18"> 言った、「あの人たちを、どうしたらよかろうか。彼らによって著しいしるしが行われたことは、エルサレムの住民全体に知れわたっているので、否定しようもない。</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行伝 5:28; ローマ人への手紙 15:18–22; 使徒行伝 5:24"> ただ、これ以上このことが民衆の間にひろまらないように、今後はこの名によって、いっさいだれにも語ってはいけないと、おどしてやろうではないか」。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行伝 5:40; ルカによる福音書 24:46–48; 使徒行伝 5:20"> そこで、ふたりを呼び入れて、イエスの名によって語ることも説くことも、いっさい相成らぬと言いわたした。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行伝 5:29; 出エジプト記 1:17; コリント人への第一の手紙 10:15"> ペテロとヨハネとは、これに対して言った、「神に聞き従うよりも、あなたがたに聞き従う方が、神の前に正しいかどうか、判断してもらいたい。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行伝 22:15; エレミヤ書 20:9; コリント人への第一の手紙 9:16–17"> わたしたちとしては、自分の見たこと聞いたことを、語らないわけにはいかない」。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行伝 5:26; マタイによる福音書 21:46; ルカによる福音書 22:2"> そこで、彼らはふたりを更におどしたうえ、ゆるしてやった。みんなの者が、この出来事のために、神をあがめていたので、その人々の手前、ふたりを罰するすべがなかったからである。</span>
<span className="v" id="v22" data-v="22" data-xref="ヨハネによる福音書 5:5; 使徒行伝 9:33; ルカによる福音書 13:11"> そのしるしによっていやされたのは、四十歳あまりの人であった。</span>
</div>
<div className="bp poetry">
<span className="v" id="v23" data-v="23" data-xref="コリント人への第二の手紙 6:14–17; 使徒行伝 12:11–12; 詩篇 119:63"> ふたりはゆるされてから、仲間の者たちのところに帰って、祭司長たちや長老たちが言ったいっさいのことを報告した。</span>
<span className="v" id="v24" data-v="24" data-xref="出エジプト記 20:11; エレミヤ書 32:17; ネヘミヤ書 9:6"> 一同はこれを聞くと、口をそろえて、神にむかい声をあげて言った、「天と地と海と、その中のすべてのものとの造りぬしなる主よ。</span>
<span className="v" id="v25" data-v="25" data-xref="詩篇 2:1–6; 使徒行伝 1:16; 使徒行伝 2:30"> あなたは、わたしたちの先祖、あなたの僕ダビデの口をとおして、聖霊によって、こう仰せになりました、<br /><span className="pl pl-1">『なぜ、異邦人らは、騒ぎ立ち、</span><br /><span className="pl pl-1">もろもろの民は、むなしいことを図り、</span></span>
<span className="v" id="v26" data-v="26" data-xref="詩篇 2:2; ヨハネの黙示録 17:12–14; ダニエル書 9:24"> <span className="pl pl-1">地上の王たちは、立ちかまえ、</span><br /><span className="pl pl-1">支配者たちは、党を組んで、</span><br /><span className="pl pl-1">主とそのキリストとに逆らったのか』。</span></span>
<span className="v" id="v27" data-v="27" data-xref="マタイによる福音書 27:2; 使徒行伝 4:30; ルカによる福音書 9:22"> <span className="pl pl-1">まことに、ヘロデとポンテオ・ピラトとは、異邦人らやイスラエルの民と一緒になって、この都に集まり、あなたから油を注がれた聖なる僕イエスに逆らい、</span></span>
<span className="v" id="v28" data-v="28" data-xref="使徒行伝 2:23; イザヤ書 46:10; 創世記 50:20"> <span className="pl pl-1">み手とみ旨とによって、あらかじめ定められていたことを、なし遂げたのです。</span></span>
<span className="v" id="v29" data-v="29" data-xref="使徒行伝 4:13; 使徒行伝 14:3; ピリピ人への手紙 1:14"> <span className="pl pl-1">主よ、いま、彼らの脅迫に目をとめ、僕たちに、思い切って大胆に御言葉を語らせて下さい。</span></span>
<span className="v" id="v30" data-v="30" data-xref="使徒行伝 4:27; 使徒行伝 3:6; 使徒行伝 5:12"> <span className="pl pl-1">そしてみ手を伸ばしていやしをなし、聖なる僕イエスの名によって、しるしと奇跡とを行わせて下さい」。</span></span>
<span className="v" id="v31" data-v="31" data-xref="マタイによる福音書 21:22; 使徒行伝 2:2; 使徒行伝 2:4"> <span className="pl pl-1">彼らが祈り終えると、その集まっていた場所が揺れ動き、一同は聖霊に満たされて、大胆に神の言を語り出した。</span></span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="コリント人への第一の手紙 1:10; エペソ人への手紙 4:2–6; ペテロの第一の手紙 3:8"> 信じた者の群れは、心を一つにし思いを一つにして、だれひとりその持ち物を自分のものだと主張する者がなく、いっさいの物を共有にしていた。</span>
<span className="v" id="v33" data-v="33" data-xref="ヨハネによる福音書 1:16; 使徒行伝 1:22; 使徒行伝 1:8"> 使徒たちは主イエスの復活について、非常に力強くあかしをした。そして大きなめぐみが、彼ら一同に注がれた。</span>
<span className="v" id="v34" data-v="34" data-xref="使徒行伝 2:45; ルカによる福音書 12:33; ルカによる福音書 16:9"> 彼らの中に乏しい者は、ひとりもいなかった。地所や家屋を持っている人たちは、それを売り、売った物の代金をもってきて、</span>
<span className="v" id="v35" data-v="35" data-xref="使徒行伝 5:2; 使徒行伝 2:45; コリント人への第二の手紙 8:20–21"> 使徒たちの足もとに置いた。そしてそれぞれの必要に応じて、だれにでも分け与えられた。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="ガラテヤ人への手紙 2:9; ガラテヤ人への手紙 2:13; ガラテヤ人への手紙 2:1"> クプロ生れのレビ人で、使徒たちにバルナバ（「慰めの子」との意）と呼ばれていたヨセフは、</span>
<span className="v" id="v37" data-v="37" data-xref="使徒行伝 5:1–2; 使徒行伝 4:34–35; マタイによる福音書 19:29"> 自分の所有する畑を売り、その代金をもってきて、使徒たちの足もとに置いた。</span>
</div>

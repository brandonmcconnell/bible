<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨハネによる福音書 18:19–21; マタイによる福音書 26:61–62; 使徒行伝 6:13–14"> 大祭司は「そのとおりか」と尋ねた。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行伝 22:1; 創世記 11:31; 詩篇 29:3"> そこで、ステパノが言った、<br />「兄弟たち、父たちよ、お聞き下さい。わたしたちの父祖アブラハムが、カランに住む前、まだメソポタミヤにいたとき、栄光の神が彼に現れて</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 12:1; ヘブル人への手紙 11:8; ヨシュア記 24:3"> 仰せになった、『あなたの土地と親族から離れて、あなたにさし示す地に行きなさい』。</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 12:4–5; 創世記 11:31–32; イザヤ書 41:9"> そこで、アブラハムはカルデヤ人の地を出て、カランに住んだ。そして、彼の父が死んだのち、神は彼をそこから、今あなたがたの住んでいるこの地に移住させたが、</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 17:8; 創世記 12:7; 創世記 13:15"> そこでは、遺産となるものは何一つ、一歩の幅の土地すらも、与えられなかった。ただ、その地を所領として授けようとの約束を、彼と、そして彼にはまだ子がなかったのに、その子孫とに与えられたのである。</span>
<span className="v" id="v6" data-v="6" data-xref="創世記 15:13; 出エジプト記 12:40–41; ガラテヤ人への手紙 3:17"> 神はこう仰せになった、『彼の子孫は他国に身を寄せるであろう。そして、そこで四百年のあいだ、奴隷にされて虐待を受けるであろう』。</span>
<span className="v" id="v7" data-v="7" data-xref="出エジプト記 3:12; 詩篇 105:27–36; ネヘミヤ書 9:9–11"> それから、さらに仰せになった、『彼らを奴隷にする国民を、わたしはさばくであろう。その後、彼らはそこからのがれ出て、この場所でわたしを礼拝するであろう』。</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 35:23–26; 創世記 17:9–14; 創世記 21:1–4"> そして、神はアブラハムに、割礼の契約をお与えになった。こうして、彼はイサクの父となり、これに八日目に割礼を施し、それから、イサクはヤコブの父となり、ヤコブは十二人の族長たちの父となった。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="創世記 39:2; 詩篇 105:17; イザヤ書 43:2"> 族長たちは、ヨセフをねたんで、エジプトに売りとばした。しかし、神は彼と共にいまして、</span>
<span className="v" id="v10" data-v="10" data-xref="箴言 3:4; テモテヘの第二の手紙 4:18; 箴言 2:6"> あらゆる苦難から彼を救い出し、エジプト王パロの前で恵みを与え、知恵をあらわさせた。そこで、パロは彼を宰相の任につかせ、エジプトならびに王家全体の支配に当らせた。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 41:54–57; 創世記 45:11; 創世記 42:5"> 時に、エジプトとカナンとの全土にわたって、ききんが起り、大きな苦難が襲ってきて、わたしたちの先祖たちは、食物が得られなくなった。</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 42:1–24; 創世記 43:2"> ヤコブは、エジプトには食糧があると聞いて、初めに先祖たちをつかわしたが、</span>
<span className="v" id="v13" data-v="13" data-xref="創世記 45:1–18; 創世記 46:31–10"> 二回目の時に、ヨセフが兄弟たちに、自分の身の上を打ち明けたので、彼の親族関係がパロに知れてきた。</span>
<span className="v" id="v14" data-v="14" data-xref="創世記 46:26–27; 申命記 10:22; 出エジプト記 1:5"> ヨセフは使をやって、父ヤコブと七十五人にのぼる親族一同とを招いた。</span>
<span className="v" id="v15" data-v="15" data-xref="創世記 49:33; 出エジプト記 1:6; 創世記 46:3–7"> こうして、ヤコブはエジプトに下り、彼自身も先祖たちもそこで死に、</span>
<span className="v" id="v16" data-v="16" data-xref="ヨシュア記 24:32; 創世記 23:16; 出エジプト記 13:19"> それから彼らは、シケムに移されて、かねてアブラハムがいくらかの金を出してこの地のハモルの子らから買っておいた墓に、葬られた。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="出エジプト記 1:7–12; 使徒行伝 7:6; 使徒行伝 13:17"> 神がアブラハムに対して立てられた約束の時期が近づくにつれ、民はふえてエジプト全土にひろがった。</span>
<span className="v" id="v18" data-v="18" data-xref="出エジプト記 1:8"> やがて、ヨセフのことを知らない別な王が、エジプトに起った。</span>
<span className="v" id="v19" data-v="19" data-xref="詩篇 105:25; 出エジプト記 1:9–22; ヨハネの黙示録 12:4–5"> この王は、わたしたちの同族に対し策略をめぐらして、先祖たちを虐待し、その幼な子らを生かしておかないように捨てさせた。</span>
<span className="v" id="v20" data-v="20" data-xref="ヘブル人への手紙 11:23; 出エジプト記 2:2–10; サムエル記上 16:12"> モーセが生れたのは、ちょうどこのころのことである。彼はまれに見る美しい子であった。三か月の間は、父の家で育てられたが、</span>
<span className="v" id="v21" data-v="21" data-xref="ヘブル人への手紙 11:24; 出エジプト記 2:2–10; 申命記 32:26"> そののち捨てられたのを、パロの娘が拾いあげて、自分の子として育てた。</span>
<span className="v" id="v22" data-v="22" data-xref="イザヤ書 19:11; ダニエル書 1:17–20; 歴代志下 9:22"> モーセはエジプト人のあらゆる学問を教え込まれ、言葉にもわざにも、力があった。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="出エジプト記 2:11–12; 箴言 21:1; ヘブル人への手紙 11:24–26"> 四十歳になった時、モーセは自分の兄弟であるイスラエル人たちのために尽すことを、思い立った。</span>
<span className="v" id="v24" data-v="24" data-xref="ヨハネによる福音書 18:10–11; 使徒行伝 7:28; ヨハネによる福音書 18:25–27"> ところが、そのひとりがいじめられているのを見て、これをかばい、虐待されているその人のために、相手のエジプト人を撃って仕返しをした。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行伝 15:7; マルコによる福音書 9:32; 列王紀下 5:1"> 彼は、自分の手によって神が兄弟たちを救って下さることを、みんなが悟るものと思っていたが、実際はそれを悟らなかったのである。</span>
<span className="v" id="v26" data-v="26" data-xref="出エジプト記 2:13–15; 箴言 18:19; ヨハネの第一の手紙 3:11–15"> 翌日モーセは、彼らが争い合っているところに現れ、仲裁しようとして言った、『まて、君たちは兄弟同志ではないか。どうして互に傷つけ合っているのか』。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行伝 7:35; ルカによる福音書 12:14; 使徒行伝 7:54"> すると、仲間をいじめていた者が、モーセを突き飛ばして言った、『だれが、君をわれわれの支配者や裁判人にしたのか。</span>
<span className="v" id="v28" data-v="28"> 君は、きのう、エジプト人を殺したように、わたしも殺そうと思っているのか』。</span>
<span className="v" id="v29" data-v="29" data-xref="出エジプト記 18:2–4; 出エジプト記 2:14–22; 出エジプト記 4:19–20"> モーセは、この言葉を聞いて逃げ、ミデアンの地に身を寄せ、そこで男の子ふたりをもうけた。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="出エジプト記 3:1–2; 使徒行伝 7:35; イザヤ書 43:2"> 四十年たった時、シナイ山の荒野において、御使が柴の燃える炎の中でモーセに現れた。</span>
<span className="v" id="v31" data-v="31" data-xref="出エジプト記 3:3–4"> 彼はこの光景を見て不思議に思い、それを見きわめるために近寄ったところ、主の声が聞えてきた、</span>
<span className="v" id="v32" data-v="32" data-xref="出エジプト記 3:6; マタイによる福音書 22:32; ヨブ記 4:14"> 『わたしは、あなたの先祖たちの神、アブラハム、イサク、ヤコブの神である』。モーセは恐れおののいて、もうそれを見る勇気もなくなった。</span>
<span className="v" id="v33" data-v="33" data-xref="出エジプト記 3:5; ヨシュア記 5:15; 伝道の書 5:1"> すると、主が彼に言われた、『あなたの足から、くつを脱ぎなさい。あなたの立っているこの場所は、聖なる地である。</span>
<span className="v" id="v34" data-v="34" data-xref="出エジプト記 3:7–10; 出エジプト記 4:31; 詩篇 106:44"> わたしは、エジプトにいるわたしの民が虐待されている有様を確かに見とどけ、その苦悩のうめき声を聞いたので、彼らを救い出すために下ってきたのである。さあ、今あなたをエジプトにつかわそう』。</span>
</div>
<div className="bp poetry">
<span className="v" id="v35" data-v="35" data-xref="詩篇 118:22–23; ルカによる福音書 19:14; 詩篇 113:7–8"> こうして、『だれが、君を支配者や裁判人にしたのか』と言って排斥されたこのモーセを、神は、柴の中で彼に現れた御使の手によって、支配者、解放者として、おつかわしになったのである。</span>
<span className="v" id="v36" data-v="36" data-xref="出エジプト記 12:41; 出エジプト記 14:21; 出エジプト記 33:1"> この人が、人々を導き出して、エジプトの地においても、紅海においても、また四十年のあいだ荒野においても、奇跡としるしとを行ったのである。</span>
<span className="v" id="v37" data-v="37" data-xref="申命記 18:15–19; 使徒行伝 3:22–23; ヨハネによる福音書 18:37"> この人が、イスラエル人たちに、『神はわたしをお立てになったように、あなたがたの兄弟たちの中から、ひとりの預言者をお立てになるであろう』と言ったモーセである。</span>
<span className="v" id="v38" data-v="38" data-xref="ローマ人への手紙 3:2; ヘブル人への手紙 5:12; ペテロの第一の手紙 4:11"> この人が、シナイ山で、彼に語りかけた御使や先祖たちと共に、荒野における集会にいて、生ける御言葉を授かり、それをあなたがたに伝えたのである。</span>
<span className="v" id="v39" data-v="39" data-xref="民数記 14:3–4; 民数記 11:5; ネヘミヤ書 9:16–17"> ところが、先祖たちは彼に従おうとはせず、かえって彼を退け、心の中でエジプトにあこがれて、</span>
<span className="v" id="v40" data-v="40" data-xref="出エジプト記 32:1; 出エジプト記 32:23"> 『わたしたちを導いてくれる神々を造って下さい。わたしたちをエジプトの地から導いてきたあのモーセがどうなったのか、わかりませんから』とアロンに言った。</span>
<span className="v" id="v41" data-v="41" data-xref="詩篇 106:19–21; ネヘミヤ書 9:18; ヨハネの黙示録 9:20"> そのころ、彼らは子牛の像を造り、その偶像に供え物をささげ、自分たちの手で造ったものを祭ってうち興じていた。</span>
<span className="v" id="v42" data-v="42" data-xref="アモス書 5:25–26; エゼキエル書 20:39; エレミヤ書 19:13"> そこで、神は顔をそむけ、彼らを天の星を拝むままに任せられた。預言者の書にこう書いてあるとおりである、<br /><span className="pl pl-1">『イスラエルの家よ、</span><br /><span className="pl pl-1">四十年のあいだ荒野にいた時に、</span><br /><span className="pl pl-1">いけにえと供え物とを、わたしにささげたことがあったか。</span></span>
<span className="v" id="v43" data-v="43" data-xref="アモス書 5:26–27; 出エジプト記 20:4–5; 申命記 5:8–9"> <span className="pl pl-1">あなたがたは、モロクの幕屋やロンパの星の神を、かつぎ回った。</span><br /><span className="pl pl-1">それらは、拝むために自分で造った偶像に過ぎぬ。</span><br /><span className="pl pl-1">だからわたしは、あなたがたをバビロンのかなたへ、移してしまうであろう』。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v44" data-v="44" data-xref="出エジプト記 25:40; 出エジプト記 38:21; ヘブル人への手紙 8:5"> わたしたちの先祖には、荒野にあかしの幕屋があった。それは、見たままの型にしたがって造るようにと、モーセに語ったかたのご命令どおりに造ったものである。</span>
<span className="v" id="v45" data-v="45" data-xref="詩篇 44:2; ヨシュア記 18:1; ヨシュア記 23:9"> この幕屋は、わたしたちの先祖が、ヨシュアに率いられ、神によって諸民族を彼らの前から追い払い、その所領をのり取ったときに、そこに持ち込まれ、次々に受け継がれて、ダビデの時代に及んだものである。</span>
<span className="v" id="v46" data-v="46" data-xref="詩篇 132:1–5; 使徒行伝 13:22; サムエル記下 7:1–5"> ダビデは、神の恵みをこうむり、そして、ヤコブの神のために宮を造営したいと願った。</span>
<span className="v" id="v47" data-v="47" data-xref="列王紀上 8:20; 列王紀上 6:37–38; サムエル記下 7:13"> けれども、じっさいにその宮を建てたのは、ソロモンであった。</span>
<span className="v" id="v48" data-v="48" data-xref="使徒行伝 17:24–25; イザヤ書 66:1–2; 列王紀上 8:27"> しかし、いと高き者は、手で造った家の内にはお住みにならない。預言者が言っているとおりである、</span>
<span className="v" id="v49" data-v="49" data-xref="イザヤ書 66:1; 詩篇 11:4; ヨハネによる福音書 4:21"> <span className="pl pl-1">『主が仰せられる、</span><br /><span className="pl pl-1">どんな家をわたしのために建てるのか。</span><br /><span className="pl pl-1">わたしのいこいの場所は、どれか。</span><br /><span className="pl pl-1">天はわたしの王座、</span><br /><span className="pl pl-1">地はわたしの足台である。</span></span>
</div>
<div className="bp">
<span className="v" id="v50" data-v="50" data-xref="エレミヤ書 32:17; 詩篇 33:6–9; 使徒行伝 14:15"> これは皆わたしの手が造ったものではないか』。</span>
<span className="v" id="v51" data-v="51" data-xref="申命記 10:16; エペソ人への手紙 4:30; イザヤ書 63:10"> ああ、強情で、心にも耳にも割礼のない人たちよ。あなたがたは、いつも聖霊に逆らっている。それは、あなたがたの先祖たちと同じである。</span>
<span className="v" id="v52" data-v="52" data-xref="マタイによる福音書 5:12; 歴代志下 36:16; 列王紀上 19:10"> いったい、あなたがたの先祖が迫害しなかった預言者が、ひとりでもいたか。彼らは正しいかたの来ることを予告した人たちを殺し、今やあなたがたは、その正しいかたを裏切る者、また殺す者となった。</span>
<span className="v" id="v53" data-v="53" data-xref="ヘブル人への手紙 2:2; ガラテヤ人への手紙 3:19; 使徒行伝 7:38"> あなたがたは、御使たちによって伝えられた律法を受けたのに、それを守ることをしなかった」。</span>
</div>
<div className="bp">
<span className="v" id="v54" data-v="54" data-xref="使徒行伝 5:33; 詩篇 35:16; マタイによる福音書 25:30"> 人々はこれを聞いて、心の底から激しく怒り、ステパノにむかって、歯ぎしりをした。</span>
<span className="v" id="v55" data-v="55" data-xref="マルコによる福音書 16:19; ヘブル人への手紙 1:3; コリント人への第二の手紙 4:6"> しかし、彼は聖霊に満たされて、天を見つめていると、神の栄光が現れ、イエスが神の右に立っておられるのが見えた。</span>
<span className="v" id="v56" data-v="56" data-xref="マタイによる福音書 26:64–65; 使徒行伝 10:11; ヨハネの黙示録 11:19"> そこで、彼は「ああ、天が開けて、人の子が神の右に立っておいでになるのが見える」と言った。</span>
<span className="v" id="v57" data-v="57" data-xref="ゼカリヤ書 7:11; 詩篇 58:4; 使徒行伝 23:27"> 人々は大声で叫びながら、耳をおおい、ステパノを目がけて、いっせいに殺到し、</span>
<span className="v" id="v58" data-v="58" data-xref="使徒行伝 22:20; 使徒行伝 8:1; 使徒行伝 6:13"> 彼を市外に引き出して、石で打った。これに立ち合った人たちは、自分の上着を脱いで、サウロという若者の足もとに置いた。</span>
<span className="v" id="v59" data-v="59" data-xref="ルカによる福音書 23:46; 詩篇 31:5; 使徒行伝 22:16"> こうして、彼らがステパノに石を投げつけている間、ステパノは祈りつづけて言った、「主イエスよ、わたしの霊をお受け下さい」。</span>
<span className="v" id="v60" data-v="60" data-xref="マタイによる福音書 5:44; ルカによる福音書 23:34; コリント人への第一の手紙 15:20"> そして、ひざまずいて、大声で叫んだ、「主よ、どうぞ、この罪を彼らに負わせないで下さい」。こう言って、彼は眠りについた。</span>
</div>

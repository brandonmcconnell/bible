<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行伝 18:4; 使徒行伝 13:51; 使徒行伝 13:46"> ふたりは、イコニオムでも同じようにユダヤ人の会堂にはいって語った結果、ユダヤ人やギリシヤ人が大ぜい信じた。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行伝 13:50; 使徒行伝 21:27–30; 使徒行伝 14:19"> ところが、信じなかったユダヤ人たちは異邦人たちをそそのかして、兄弟たちに対して悪意をいだかせた。</span>
<span className="v" id="v3" data-v="3" data-xref="ヘブル人への手紙 2:4; エペソ人への手紙 6:18–20; 使徒行伝 20:32"> それにもかかわらず、ふたりは長い期間をそこで過ごして、大胆に主のことを語った。主は、彼らの手によってしるしと奇跡とを行わせ、そのめぐみの言葉をあかしされた。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行伝 28:24; 使徒行伝 14:14; ルカによる福音書 11:21–23"> そこで町の人々が二派に分れ、ある人たちはユダヤ人の側につき、ある人たちは使徒の側についた。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行伝 14:19; テモテヘの第二の手紙 3:11; 使徒行伝 17:5"> その時、異邦人やユダヤ人が役人たちと一緒になって反対運動を起し、使徒たちをはずかしめ、石で打とうとしたので、</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行伝 14:20–21; マタイによる福音書 10:23; テモテヘの第二の手紙 3:11"> ふたりはそれと気づいて、ルカオニヤの町々、ルステラ、デルベおよびその附近の地へのがれ、</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行伝 14:21; 使徒行伝 16:10; テサロニケ人への第一の手紙 2:2"> そこで引きつづき福音を伝えた。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="使徒行伝 3:2; ヨハネによる福音書 9:1–2; ヨハネによる福音書 5:3–5"> ところが、ルステラに足のきかない人が、すわっていた。彼は生れながらの足なえで、歩いた経験が全くなかった。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行伝 3:4; マタイによる福音書 15:28; マタイによる福音書 9:28–29"> この人がパウロの語るのを聞いていたが、パウロは彼をじっと見て、いやされるほどの信仰が彼にあるのを認め、</span>
<span className="v" id="v10" data-v="10" data-xref="イザヤ書 35:6; ヨハネによる福音書 5:8–9; ヨハネによる福音書 14:12"> 大声で「自分の足で、まっすぐに立ちなさい」と言った。すると彼は踊り上がって歩き出した。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行伝 28:6; 使徒行伝 8:10; 使徒行伝 12:22"> 群衆はパウロのしたことを見て、声を張りあげ、ルカオニヤの地方語で、「神々が人間の姿をとって、わたしたちのところにお下りになったのだ」と叫んだ。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行伝 19:35"> 彼らはバルナバをゼウスと呼び、パウロはおもに語る人なので、彼をヘルメスと呼んだ。</span>
<span className="v" id="v13" data-v="13" data-xref="ダニエル書 2:46; 使徒行伝 10:25"> そして、郊外にあるゼウス神殿の祭司が、群衆と共に、ふたりに犠牲をささげようと思って、雄牛数頭と花輪とを門前に持ってきた。</span>
<span className="v" id="v14" data-v="14" data-xref="マタイによる福音書 26:65; コリント人への第一の手紙 9:5–6; 列王紀下 5:7"> ふたりの使徒バルナバとパウロとは、これを聞いて自分の上着を引き裂き、群衆の中に飛び込んで行き、叫んで</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行伝 10:26; コリント人への第一の手紙 8:4; ヤコブの手紙 5:17"> 言った、「皆さん、なぜこんな事をするのか。わたしたちとても、あなたがたと同じような人間である。そして、あなたがたがこのような愚にもつかぬものを捨てて、天と地と海と、その中のすべてのものをお造りになった生ける神に立ち帰るようにと、福音を説いているものである。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行伝 17:30; 詩篇 81:12; ローマ人への手紙 1:28"> 神は過ぎ去った時代には、すべての国々の人が、それぞれの道を行くままにしておかれたが、</span>
<span className="v" id="v17" data-v="17" data-xref="ローマ人への手紙 1:19–20; ヨエル書 2:23; ヨブ記 5:10"> それでも、ご自分のことをあかししないでおられたわけではない。すなわち、あなたがたのために天から雨を降らせ、実りの季節を与え、食物と喜びとで、あなたがたの心を満たすなど、いろいろのめぐみをお与えになっているのである」。</span>
<span className="v" id="v18" data-v="18" data-xref="エレミヤ書 44:16–17; 創世記 19:9; 創世記 11:6"> こう言って、ふたりは、やっとのことで、群衆が自分たちに犠牲をささげるのを、思い止まらせた。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="コリント人への第二の手紙 11:25; テモテヘの第二の手紙 3:11; 使徒行伝 13:50–51"> ところが、あるユダヤ人たちはアンテオケやイコニオムから押しかけてきて、群衆を仲間に引き入れたうえ、パウロを石で打ち、死んでしまったと思って、彼を町の外に引きずり出した。</span>
<span className="v" id="v20" data-v="20" data-xref="コリント人への第二の手紙 1:9–10; コリント人への第二の手紙 6:9; 使徒行伝 14:6"> しかし、弟子たちがパウロを取り囲んでいる間に、彼は起きあがって町にはいって行った。そして翌日には、バルナバと一緒にデルベにむかって出かけた。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行伝 14:19; 使徒行伝 14:1; 使徒行伝 13:51"> その町で福音を伝えて、大ぜいの人を弟子とした後、ルステラ、イコニオム、アンテオケの町々に帰って行き、</span>
<span className="v" id="v22" data-v="22" data-xref="ペテロの第一の手紙 5:10; テモテヘの第二の手紙 3:12; ヨハネによる福音書 16:33"> 弟子たちを力づけ、信仰を持ちつづけるようにと奨励し、「わたしたちが神の国にはいるのには、多くの苦難を経なければならない」と語った。</span>
<span className="v" id="v23" data-v="23" data-xref="テトスヘの手紙 1:5; 使徒行伝 11:30; ヤコブの手紙 5:14"> また教会ごとに彼らのために長老たちを任命し、断食をして祈り、彼らをその信じている主にゆだねた。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="使徒行伝 13:13–14; 使徒行伝 15:38"> それから、ふたりはピシデヤを通過してパンフリヤにきたが、</span>
<span className="v" id="v25" data-v="25"> ペルガで御言を語った後、アタリヤにくだり、</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行伝 15:40; 使徒行伝 11:19; コリント人への第二の手紙 1:12"> そこから舟でアンテオケに帰った。彼らが今なし終った働きのために、神の祝福を受けて送り出されたのは、このアンテオケからであった。</span>
<span className="v" id="v27" data-v="27" data-xref="コリント人への第一の手紙 16:9; 使徒行伝 15:12; コロサイ人への手紙 4:3"> 彼らは到着早々、教会の人々を呼び集めて、神が彼らと共にいてして下さった数々のこと、また信仰の門を異邦人に開いて下さったことなどを、報告した。</span>
<span className="v" id="v28" data-v="28" data-xref="使徒行伝 11:26; 使徒行伝 15:35"> そして、ふたりはしばらくの間、弟子たちと一緒に過ごした。</span>
</div>

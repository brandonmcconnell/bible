<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行伝 27:1; マタイによる福音書 8:5–13; マタイによる福音書 27:27"> さて、カイザリヤにコルネリオという名の人がいた。イタリヤ隊と呼ばれた部隊の百卒長で、</span>
<span className="v" id="v2" data-v="2" data-xref="マタイによる福音書 7:7–8; 使徒行伝 10:4; 使徒行伝 10:22"> 信心深く、家族一同と共に神を敬い、民に数々の施しをなし、絶えず神に祈をしていた。</span>
<span className="v" id="v3" data-v="3" data-xref="ダニエル書 9:20–21; 使徒行伝 3:1; 使徒行伝 5:19"> ある日の午後三時ごろ、神の使が彼のところにきて、「コルネリオよ」と呼ぶのを、幻ではっきり見た。</span>
<span className="v" id="v4" data-v="4" data-xref="ピリピ人への手紙 4:6; ヘブル人への手紙 6:10; 使徒行伝 10:31"> 彼は御使を見つめていたが、恐ろしくなって、「主よ、なんでございますか」と言った。すると御使が言った、「あなたの祈や施しは神のみ前にとどいて、おぼえられている。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行伝 16:9; 使徒行伝 9:38; 使徒行伝 15:7"> ついては今、ヨッパに人をやって、ペテロと呼ばれるシモンという人を招きなさい。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行伝 9:43; 使徒行伝 11:13–14; ローマ人への手紙 10:14–17"> この人は、海べに家をもつ皮なめしシモンという者の客となっている」。</span>
<span className="v" id="v7" data-v="7" data-xref="ピレモンヘの手紙 1:16; サムエル記上 14:6–7; マタイによる福音書 8:9–10"> このお告げをした御使が立ち去ったのち、コルネリオは、僕ふたりと、部下の中で信心深い兵卒ひとりとを呼び、</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行伝 9:36; 詩篇 119:59–60; 使徒行伝 10:33"> いっさいの事を説明して聞かせ、ヨッパへ送り出した。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="ゼパニヤ書 1:5; 詩篇 55:17; サムエル記上 9:25"> 翌日、この三人が旅をつづけて町の近くにきたころ、ペテロは祈をするため屋上にのぼった。時は昼の十二時ごろであった。</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行伝 22:17; ヨハネの黙示録 4:2–3; コリント人への第二の手紙 12:2–4"> 彼は空腹をおぼえて、何か食べたいと思った。そして、人々が食事の用意をしている間に、夢心地になった。</span>
<span className="v" id="v11" data-v="11" data-xref="エペソ人への手紙 3:6; ヨハネによる福音書 1:51; ローマ人への手紙 16:25–26"> すると、天が開け、大きな布のような入れ物が、四すみをつるされて、地上に降りて来るのを見た。</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 7:8–9; ヨハネによる福音書 7:37; コリント人への第一の手紙 6:9–11"> その中には、地上の四つ足や這うもの、また空の鳥など、各種の生きものがはいっていた。</span>
<span className="v" id="v13" data-v="13" data-xref="ヨハネによる福音書 4:31–34; エレミヤ書 35:2–5; 使徒行伝 10:10"> そして声が彼に聞えてきた、「ペテロよ。立って、それらをほふって食べなさい」。</span>
<span className="v" id="v14" data-v="14" data-xref="レビ記 20:25; エゼキエル書 4:14; ダニエル書 1:8"> ペテロは言った、「主よ、それはできません。わたしは今までに、清くないもの、汚れたものは、何一つ食べたことがありません」。</span>
<span className="v" id="v15" data-v="15" data-xref="コリント人への第一の手紙 10:25; マタイによる福音書 15:11; テトスヘの手紙 1:15"> すると、声が二度目にかかってきた、「神がきよめたものを、清くないなどと言ってはならない」。</span>
<span className="v" id="v16" data-v="16" data-xref="創世記 41:32; ヨハネによる福音書 21:17; コリント人への第二の手紙 13:1"> こんなことが三度もあってから、その入れ物はすぐ天に引き上げられた。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="ヨハネによる福音書 13:12; 使徒行伝 10:7–19; 使徒行伝 5:24"> ペテロが、いま見た幻はなんの事だろうかと、ひとり思案にくれていると、ちょうどその時、コルネリオから送られた人たちが、シモンの家を尋ね当てて、その門口に立っていた。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行伝 10:5–6; 使徒行伝 11:11"> そして声をかけて、「ペテロと呼ばれるシモンというかたが、こちらにお泊まりではございませんか」と尋ねた。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行伝 8:29; 使徒行伝 11:12; 使徒行伝 21:4"> ペテロはなおも幻について、思いめぐらしていると、御霊が言った、「ごらんなさい、三人の人たちが、あなたを尋ねてきている。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行伝 15:7–9; ゼカリヤ書 2:9–11; イザヤ書 48:16"> さあ、立って下に降り、ためらわないで、彼らと一緒に出かけるがよい。わたしが彼らをよこしたのである」。</span>
<span className="v" id="v21" data-v="21" data-xref="ヨハネによる福音書 1:38–39; マルコによる福音書 10:51; 使徒行伝 10:29"> そこでペテロは、その人たちのところに降りて行って言った、「わたしがお尋ねのペテロです。どんなご用でおいでになったのですか」。</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行伝 11:14; 使徒行伝 10:2; 使徒行伝 22:12"> 彼らは答えた、「正しい人で、神を敬い、ユダヤの全国民に好感を持たれている百卒長コルネリオが、あなたを家に招いてお話を伺うようにとのお告げを、聖なる御使から受けましたので、参りました」。</span>
<span className="v" id="v23" data-v="23" data-xref="使徒行伝 10:45; 使徒行伝 11:12; ペテロの第一の手紙 4:9"> そこで、ペテロは、彼らを迎えて泊まらせた。<br />翌日、ペテロは立って、彼らと連れだって出発した。ヨッパの兄弟たち数人も一緒に行った。</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行伝 8:40; ゼカリヤ書 8:20–23; ゼカリヤ書 3:10"> その次の日に、一行はカイザリヤに着いた。コルネリオは親族や親しい友人たちを呼び集めて、待っていた。</span>
<span className="v" id="v25" data-v="25" data-xref="ヨハネの黙示録 19:10; ヨハネの黙示録 22:8–9; ダニエル書 2:46"> ペテロがいよいよ到着すると、コルネリオは出迎えて、彼の足もとにひれ伏して拝した。</span>
<span className="v" id="v26" data-v="26" data-xref="ヨハネの黙示録 19:10; ヨハネの黙示録 22:8–9; 使徒行伝 14:14–15"> するとペテロは、彼を引き起して言った、「お立ちなさい。わたしも同じ人間です」。</span>
<span className="v" id="v27" data-v="27" data-xref="コリント人への第二の手紙 2:12; ヨハネによる福音書 4:35; 使徒行伝 10:24"> それから共に話しながら、へやにはいって行くと、そこには、すでに大ぜいの人が集まっていた。</span>
<span className="v" id="v28" data-v="28" data-xref="ヨハネによる福音書 4:9; エペソ人への手紙 3:6–7; ガラテヤ人への手紙 2:12–14"> ペテロは彼らに言った、「あなたがたが知っているとおり、ユダヤ人が他国の人と交際したり、出入りしたりすることは、禁じられています。ところが、神は、どんな人間をも清くないとか、汚れているとか言ってはならないと、わたしにお示しになりました。</span>
<span className="v" id="v29" data-v="29" data-xref="詩篇 119:60; ペテロの第一の手紙 3:15; 使徒行伝 10:19–20"> お招きにあずかった時、少しもためらわずに参ったのは、そのためなのです。そこで伺いますが、どういうわけで、わたしを招いてくださったのですか」。</span>
<span className="v" id="v30" data-v="30" data-xref="使徒行伝 10:3; ダニエル書 9:20–21; ネヘミヤ書 9:1–3"> これに対してコルネリオが答えた、「四日前、ちょうどこの時刻に、わたしが自宅で午後三時の祈をしていますと、突然、輝いた衣を着た人が、前に立って申しました、</span>
<span className="v" id="v31" data-v="31" data-xref="使徒行伝 10:4; ダニエル書 9:23; ルカによる福音書 1:13"> 『コルネリオよ、あなたの祈は聞きいれられ、あなたの施しは神のみ前におぼえられている。</span>
<span className="v" id="v32" data-v="32"> そこでヨッパに人を送ってペテロと呼ばれるシモンを招きなさい。その人は皮なめしシモンの海沿いの家に泊まっている』。</span>
<span className="v" id="v33" data-v="33" data-xref="ヤコブの手紙 1:19; ガラテヤ人への手紙 4:14; 歴代志下 30:12"> それで、早速あなたをお呼びしたのです。ようこそおいで下さいました。今わたしたちは、主があなたにお告げになったことを残らず伺おうとして、みな神のみ前にまかり出ているのです」。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="ローマ人への手紙 2:11; 歴代志下 19:7; 申命記 10:17"> そこでペテロは口を開いて言った、「神は人をかたよりみないかたで、</span>
<span className="v" id="v35" data-v="35" data-xref="ヨハネの第一の手紙 2:29; 使徒行伝 10:2; ローマ人への手紙 10:12–13"> 神を敬い義を行う者はどの国民でも受けいれて下さることが、ほんとうによくわかってきました。</span>
<span className="v" id="v36" data-v="36" data-xref="マタイによる福音書 28:18; 使徒行伝 2:36; ヨハネの黙示録 17:14"> あなたがたは、神がすべての者の主なるイエス・キリストによって平和の福音を宣べ伝えて、イスラエルの子らにお送り下さった御言をご存じでしょう。</span>
<span className="v" id="v37" data-v="37" data-xref="ルカによる福音書 4:14; 使徒行伝 2:22; 使徒行伝 28:22"> それは、ヨハネがバプテスマを説いた後、ガリラヤから始まってユダヤ全土にひろまった福音を述べたものです。</span>
<span className="v" id="v38" data-v="38" data-xref="ルカによる福音書 4:18; 使徒行伝 2:22; イザヤ書 61:1–3"> 神はナザレのイエスに聖霊と力とを注がれました。このイエスは、神が共におられるので、よい働きをしながら、また悪魔に押えつけられている人々をことごとくいやしながら、巡回されました。</span>
<span className="v" id="v39" data-v="39" data-xref="ルカによる福音書 24:48; 使徒行伝 1:8; 使徒行伝 10:41"> わたしたちは、イエスがこうしてユダヤ人の地やエルサレムでなさったすべてのことの証人であります。人々はこのイエスを木にかけて殺したのです。</span>
<span className="v" id="v40" data-v="40" data-xref="ペテロの第一の手紙 1:21; 使徒行伝 13:30–31; コリント人への第一の手紙 15:3–4"> しかし神はイエスを三日目によみがえらせ、</span>
<span className="v" id="v41" data-v="41" data-xref="ヨハネによる福音書 14:22; 使徒行伝 10:39; ヨハネによる福音書 21:13"> 全部の人々にではなかったが、わたしたち証人としてあらかじめ選ばれた者たちに現れるようにして下さいました。わたしたちは、イエスが死人の中から復活された後、共に飲食しました。</span>
<span className="v" id="v42" data-v="42" data-xref="コリント人への第二の手紙 5:10; テモテヘの第二の手紙 4:1; ペテロの第一の手紙 4:5"> それから、イエスご自身が生者と死者との審判者として神に定められたかたであることを、人々に宣べ伝え、またあかしするようにと、神はわたしたちにお命じになったのです。</span>
<span className="v" id="v43" data-v="43" data-xref="ゼカリヤ書 13:1; 使徒行伝 2:38; イザヤ書 53:11"> 預言者たちもみな、イエスを信じる者はことごとく、その名によって罪のゆるしが受けられると、あかしをしています」。</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="使徒行伝 11:15; 使徒行伝 19:6; 使徒行伝 15:8"> ペテロがこれらの言葉をまだ語り終えないうちに、それを聞いていたみんなの人たちに、聖霊がくだった。</span>
<span className="v" id="v45" data-v="45" data-xref="使徒行伝 10:23; 使徒行伝 2:38; ガラテヤ人への手紙 3:13–14"> 割礼を受けている信者で、ペテロについてきた人たちは、異邦人たちにも聖霊の賜物が注がれたのを見て、驚いた。</span>
<span className="v" id="v46" data-v="46" data-xref="使徒行伝 19:6; 使徒行伝 2:4; マルコによる福音書 16:17"> それは、彼らが異言を語って神をさんびしているのを聞いたからである。そこで、ペテロが言い出した、</span>
<span className="v" id="v47" data-v="47" data-xref="使徒行伝 8:36; ローマ人への手紙 10:12; 使徒行伝 11:15–17"> 「この人たちがわたしたちと同じように聖霊を受けたからには、彼らに水でバプテスマを授けるのを、だれがこばみ得ようか」。</span>
<span className="v" id="v48" data-v="48" data-xref="使徒行伝 2:38; 使徒行伝 8:16; ガラテヤ人への手紙 3:27"> こう言って、ペテロはその人々に命じて、イエス・キリストの名によってバプテスマを受けさせた。それから、彼らはペテロに願って、なお数日のあいだ滞在してもらった。</span>
</div>

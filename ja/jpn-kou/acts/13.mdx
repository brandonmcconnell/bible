<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行伝 4:36; 使徒行伝 15:35; 使徒行伝 11:22–27"> さて、アンテオケにある教会には、バルナバ、ニゲルと呼ばれるシメオン、クレネ人ルキオ、領主ヘロデの乳兄弟マナエン、およびサウロなどの預言者や教師がいた。</span>
<span className="v" id="v2" data-v="2" data-xref="ガラテヤ人への手紙 1:15; 使徒行伝 9:15; コリント人への第一の手紙 12:11"> 一同が主に礼拝をささげ、断食をしていると、聖霊が「さあ、バルナバとサウロとを、わたしのために聖別して、彼らに授けておいた仕事に当らせなさい」と告げた。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行伝 6:6; テモテヘの第二の手紙 2:2; 使徒行伝 13:2"> そこで一同は、断食と祈とをして、手をふたりの上においた後、出発させた。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="使徒行伝 4:36; 使徒行伝 13:2; 使徒行伝 11:19"> ふたりは聖霊に送り出されて、セルキヤにくだり、そこから舟でクプロに渡った。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行伝 13:14; 使徒行伝 13:46; 使徒行伝 14:1"> そしてサラミスに着くと、ユダヤ人の諸会堂で神の言を宣べはじめた。彼らはヨハネを助け手として連れていた。</span>
<span className="v" id="v6" data-v="6" data-xref="マタイによる福音書 7:15; ヨハネの第一の手紙 4:1; コリント人への第二の手紙 11:13"> 島全体を巡回して、パポスまで行ったところ、そこでユダヤ人の魔術師、バルイエスというにせ預言者に出会った。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行伝 19:38; 使徒行伝 13:12; 使徒行伝 18:12"> 彼は地方総督セルギオ・パウロのところに出入りをしていた。この総督は賢明な人であって、バルナバとサウロとを招いて、神の言を聞こうとした。</span>
<span className="v" id="v8" data-v="8" data-xref="テモテヘの第二の手紙 3:8; 使徒行伝 13:6–7; テモテヘの第二の手紙 4:14–15"> ところが魔術師エルマ（彼の名は「魔術師」との意）は、総督を信仰からそらそうとして、しきりにふたりの邪魔をした。</span>
<span className="v" id="v9" data-v="9" data-xref="ミカ書 3:8; 使徒行伝 4:8; 使徒行伝 2:4"> サウロ、またの名はパウロ、は聖霊に満たされ、彼をにらみつけて</span>
<span className="v" id="v10" data-v="10" data-xref="ヨハネによる福音書 8:44; コリント人への第二の手紙 11:3; マタイによる福音書 13:38"> 言った、「ああ、あらゆる偽りと邪悪とでかたまっている悪魔の子よ、すべて正しいものの敵よ。主のまっすぐな道を曲げることを止めないのか。</span>
<span className="v" id="v11" data-v="11" data-xref="出エジプト記 9:3; 詩篇 32:4; ヘブル人への手紙 10:31"> 見よ、主のみ手がおまえの上に及んでいる。おまえは盲になって、当分、日の光が見えなくなるのだ」。たちまち、かすみとやみとが彼にかかったため、彼は手さぐりしながら、手を引いてくれる人を捜しまわった。</span>
<span className="v" id="v12" data-v="12" data-xref="コリント人への第二の手紙 10:4–5; 使徒行伝 13:7; ルカによる福音書 4:22"> 総督はこの出来事を見て、主の教にすっかり驚き、そして信じた。</span>
</div>
<div className="bp poetry">
<span className="v" id="v13" data-v="13" data-xref="使徒行伝 15:38; 使徒行伝 2:10; 使徒行伝 14:24–25"> パウロとその一行は、パポスから船出して、パンフリヤのペルガに渡った。ここでヨハネは一行から身を引いて、エルサレムに帰ってしまった。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行伝 16:13; 使徒行伝 14:19; 使徒行伝 13:5"> しかしふたりは、ペルガからさらに進んで、ピシデヤのアンテオケに行き、安息日に会堂にはいって席に着いた。</span>
<span className="v" id="v15" data-v="15" data-xref="ヘブル人への手紙 13:22; 使徒行伝 15:21; マルコによる福音書 5:22"> 律法と預言書の朗読があったのち、会堂司たちが彼らのところに人をつかわして、「兄弟たちよ、もしあなたがたのうち、どなたか、この人々に何か奨励の言葉がありましたら、どうぞお話し下さい」と言わせた。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行伝 12:17; 使徒行伝 13:26; 使徒行伝 10:2"> そこでパウロが立ちあがり、手を振りながら言った。<br />「イスラエルの人たち、ならびに神を敬うかたがたよ、お聞き下さい。</span>
<span className="v" id="v17" data-v="17" data-xref="申命記 7:6–8; イザヤ書 63:9–14; 詩篇 105:23–24"> この民イスラエルの神は、わたしたちの先祖を選び、エジプトの地に滞在中、この民を大いなるものとし、み腕を高くさし上げて、彼らをその地から導き出された。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行伝 7:36; 詩篇 95:8–11; 詩篇 106:13–29"> そして約四十年にわたって、荒野で彼らをはぐくみ、</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 7:1; 詩篇 78:55; 使徒行伝 7:45"> カナンの地では七つの異民族を打ち滅ぼし、その地を彼らに譲り与えられた。</span>
<span className="v" id="v20" data-v="20" data-xref="士師記 2:16; サムエル記上 3:20; 列王紀下 23:22"> それらのことが約四百五十年の年月にわたった。その後、神はさばき人たちをおつかわしになり、預言者サムエルの時に及んだ。</span>
<span className="v" id="v21" data-v="21" data-xref="サムエル記上 10:1; サムエル記上 15:1; サムエル記上 12:12–19"> その時、人々が王を要求したので、神はベニヤミン族の人、キスの子サウロを四十年間、彼らにおつかわしになった。</span>
<span className="v" id="v22" data-v="22" data-xref="サムエル記上 13:13–14; 列王紀上 15:5; 詩篇 78:70–72"> それから神はサウロを退け、ダビデを立てて王とされたが、彼についてあかしをして、『わたしはエッサイの子ダビデを見つけた。彼はわたしの心にかなった人で、わたしの思うところを、ことごとく実行してくれるであろう』と言われた。</span>
<span className="v" id="v23" data-v="23" data-xref="マタイによる福音書 1:1; 詩篇 132:11; ヨハネの黙示録 22:16"> 神は約束にしたがって、このダビデの子孫の中から救主イエスをイスラエルに送られたが、</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行伝 1:22; ヨハネによる福音書 1:6–8; ルカによる福音書 3:2–20"> そのこられる前に、ヨハネがイスラエルのすべての民に悔改めのバプテスマを、あらかじめ宣べ伝えていた。</span>
<span className="v" id="v25" data-v="25" data-xref="マタイによる福音書 3:11; マルコによる福音書 1:7; ヨハネによる福音書 1:26–27"> ヨハネはその一生の行程を終ろうとするに当って言った、『わたしは、あなたがたが考えているような者ではない。しかし、わたしのあとから来るかたがいる。わたしはそのくつを脱がせてあげる値うちもない』。</span>
<span className="v" id="v26" data-v="26" data-xref="ルカによる福音書 1:77; ローマ人への手紙 1:16; ルカによる福音書 1:69"> 兄弟たち、アブラハムの子孫のかたがた、ならびに皆さんの中の神を敬う人たちよ。この救の言葉はわたしたちに送られたのである。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行伝 3:17; ルカによる福音書 24:24–27; ルカによる福音書 24:20"> エルサレムに住む人々やその指導者たちは、イエスを認めずに刑に処し、それによって、安息日ごとに読む預言者の言葉が成就した。</span>
<span className="v" id="v28" data-v="28" data-xref="ルカによる福音書 23:21–25; ルカによる福音書 23:14–16; ヨハネによる福音書 19:4"> また、なんら死に当る理由が見いだせなかったのに、ピラトに強要してイエスを殺してしまった。</span>
<span className="v" id="v29" data-v="29" data-xref="ルカによる福音書 23:53; ヨハネによる福音書 19:28; ヨハネによる福音書 19:30"> そして、イエスについて書いてあることを、皆なし遂げてから、人々はイエスを木から取りおろして墓に葬った。</span>
<span className="v" id="v30" data-v="30" data-xref="使徒行伝 2:24; 使徒行伝 17:31; マタイによる福音書 28:6"> しかし、神はイエスを死人の中から、よみがえらせたのである。</span>
<span className="v" id="v31" data-v="31" data-xref="ルカによる福音書 24:48; 使徒行伝 1:3; 使徒行伝 1:11"> イエスは、ガリラヤからエルサレムへ一緒に上った人たちに、幾日ものあいだ現れ、そして、彼らは今や、人々に対してイエスの証人となっている。</span>
<span className="v" id="v32" data-v="32" data-xref="ローマ人への手紙 4:13; 使徒行伝 26:6; エゼキエル書 34:23"> わたしたちは、神が先祖たちに対してなされた約束を、ここに宣べ伝えているのである。</span>
<span className="v" id="v33" data-v="33" data-xref="詩篇 2:7; ヘブル人への手紙 5:5; ヘブル人への手紙 1:5–6"> 神は、イエスをよみがえらせて、わたしたち子孫にこの約束を、お果しになった。それは詩篇の第二篇にも、『あなたこそは、わたしの子。きょう、わたしはあなたを生んだ』と書いてあるとおりである。</span>
<span className="v" id="v34" data-v="34" data-xref="イザヤ書 55:3; 詩篇 89:2–4; ローマ人への手紙 6:9"> また、神がイエスを死人の中からよみがえらせて、いつまでも朽ち果てることのないものとされたことについては、『わたしは、ダビデに約束した確かな聖なる祝福を、あなたがたに授けよう』と言われた。</span>
<span className="v" id="v35" data-v="35" data-xref="詩篇 16:10; 使徒行伝 2:27–31; 詩篇 49:9"> だから、ほかの箇所でもこう言っておられる、『あなたの聖者が朽ち果てるようなことは、お許しにならないであろう』。</span>
<span className="v" id="v36" data-v="36" data-xref="使徒行伝 2:29; サムエル記下 7:12; 列王紀上 2:10"> 事実、ダビデは、その時代の人々に神のみ旨にしたがって仕えたが、やがて眠りにつき、先祖たちの中に加えられて、ついに朽ち果ててしまった。</span>
<span className="v" id="v37" data-v="37" data-xref="使徒行伝 13:30; 使徒行伝 2:24"> しかし、神がよみがえらせたかたは、朽ち果てることがなかったのである。</span>
<span className="v" id="v38" data-v="38" data-xref="ルカによる福音書 24:47; ヨハネの第一の手紙 2:12; コリント人への第二の手紙 5:18–21"> だから、兄弟たちよ、この事を承知しておくがよい。すなわち、このイエスによる罪のゆるしの福音が、今やあなたがたに宣べ伝えられている。そして、モーセの律法では義とされることができなかったすべての事についても、</span>
<span className="v" id="v39" data-v="39" data-xref="ローマ人への手紙 10:4; ガラテヤ人への手紙 2:16; ローマ人への手紙 8:3"> 信じる者はもれなく、イエスによって義とされるのである。</span>
<span className="v" id="v40" data-v="40" data-xref="マラキ書 4:1; ヘブル人への手紙 3:12; マラキ書 3:2"> だから預言者たちの書にかいてある次のようなことが、あなたがたの身に起らないように気をつけなさい。</span>
<span className="v" id="v41" data-v="41" data-xref="ハバクク書 1:5; ペテロの第一の手紙 4:17; ローマ人への手紙 11:7–14"> <span className="pl pl-1">『見よ、侮る者たちよ。驚け、そして滅び去れ。</span><br /><span className="pl pl-1">わたしは、あなたがたの時代に一つの事をする。</span><br /><span className="pl pl-1">それは、人がどんなに説明して聞かせても、</span><br /><span className="pl pl-1">あなたがたのとうてい信じないような事なのである』」。</span></span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="使徒行伝 28:28; 使徒行伝 10:33; マタイによる福音書 19:30"> ふたりが会堂を出る時、人々は次の安息日にも、これと同じ話をしてくれるようにと、しきりに願った。</span>
<span className="v" id="v43" data-v="43" data-xref="使徒行伝 11:23; 使徒行伝 14:22; エペソ人への手紙 2:8"> そして集会が終ってからも、大ぜいのユダヤ人や信心深い改宗者たちが、パウロとバルナバとについてきたので、ふたりは、彼らが引きつづき神のめぐみにとどまっているようにと、説きすすめた。</span>
</div>
<div className="bp poetry">
<span className="v" id="v44" data-v="44" data-xref="詩篇 110:3; 創世記 49:10; イザヤ書 11:10"> 次の安息日には、ほとんど全市をあげて、神の言を聞きに集まってきた。</span>
<span className="v" id="v45" data-v="45" data-xref="ユダの手紙 1:10; 使徒行伝 18:6; 使徒行伝 5:17"> するとユダヤ人たちは、その群衆を見てねたましく思い、パウロの語ることに口ぎたなく反対した。</span>
<span className="v" id="v46" data-v="46" data-xref="使徒行伝 28:28; マタイによる福音書 21:43; 使徒行伝 18:5–6"> パウロとバルナバとは大胆に語った、「神の言は、まず、あなたがたに語り伝えられなければならなかった。しかし、あなたがたはそれを退け、自分自身を永遠の命にふさわしからぬ者にしてしまったから、さあ、わたしたちはこれから方向をかえて、異邦人たちの方に行くのだ。</span>
<span className="v" id="v47" data-v="47" data-xref="イザヤ書 49:6; イザヤ書 42:6; ルカによる福音書 2:32"> 主はわたしたちに、こう命じておられる、<br /><span className="pl pl-1">『わたしは、あなたを立てて異邦人の光とした。</span><br /><span className="pl pl-1">あなたが地の果までも救をもたらすためである』」。</span></span>
<span className="v" id="v48" data-v="48" data-xref="ローマ人への手紙 8:29–30; エペソ人への手紙 1:4; ローマ人への手紙 11:7"> <span className="pl pl-1">異邦人たちはこれを聞いてよろこび、主の御言をほめたたえてやまなかった。そして、永遠の命にあずかるように定められていた者は、みな信じた。</span></span>
<span className="v" id="v49" data-v="49" data-xref="使徒行伝 12:24; 使徒行伝 19:10; 使徒行伝 19:26"> <span className="pl pl-1">こうして、主の御言はこの地方全体にひろまって行った。</span></span>
<span className="v" id="v50" data-v="50" data-xref="使徒行伝 14:19; 使徒行伝 13:45; 使徒行伝 14:2"> <span className="pl pl-1">ところが、ユダヤ人たちは、信心深い貴婦人たちや町の有力者たちを煽動して、パウロとバルナバを迫害させ、ふたりをその地方から追い出させた。</span></span>
<span className="v" id="v51" data-v="51" data-xref="マタイによる福音書 10:14; 使徒行伝 18:6; ルカによる福音書 9:5"> <span className="pl pl-1">ふたりは、彼らに向けて足のちりを払い落して、イコニオムへ行った。</span></span>
<span className="v" id="v52" data-v="52" data-xref="ローマ人への手紙 15:13; テサロニケ人への第一の手紙 1:6; 使徒行伝 4:31"> <span className="pl pl-1">弟子たちは、ますます喜びと聖霊とに満たされていた。</span></span>
</div>

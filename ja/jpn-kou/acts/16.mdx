<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="テモテヘの第二の手紙 1:5; テモテヘの第二の手紙 1:2; コリント人への第一の手紙 4:17"> それから、彼はデルベに行き、次にルステラに行った。そこにテモテという名の弟子がいた。信者のユダヤ婦人を母とし、ギリシヤ人を父としており、</span>
<span className="v" id="v2" data-v="2" data-xref="テモテヘの第一の手紙 5:10; テモテヘの第二の手紙 3:15; 使徒行伝 14:21"> ルステラとイコニオムの兄弟たちの間で、評判のよい人物であった。</span>
<span className="v" id="v3" data-v="3" data-xref="ガラテヤ人への手紙 2:3; コリント人への第一の手紙 9:20; ガラテヤ人への手紙 5:6"> パウロはこのテモテを連れて行きたかったので、その地方にいるユダヤ人の手前、まず彼に割礼を受けさせた。彼の父がギリシヤ人であることは、みんな知っていたからである。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行伝 15:28–29; 使徒行伝 15:2; 使徒行伝 11:30"> それから彼らは通る町々で、エルサレムの使徒たちや長老たちの取り決めた事項を守るようにと、人々にそれを渡した。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行伝 9:31; 使徒行伝 2:47; 使徒行伝 6:7"> こうして、諸教会はその信仰を強められ、日ごとに数を増していった。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="使徒行伝 18:23; 使徒行伝 16:7; 使徒行伝 13:2–4"> それから彼らは、アジヤで御言を語ることを聖霊に禁じられたので、フルギヤ・ガラテヤ地方をとおって行った。</span>
<span className="v" id="v7" data-v="7" data-xref="ローマ人への手紙 8:9; ピリピ人への手紙 1:19; ガラテヤ人への手紙 4:6"> そして、ムシヤのあたりにきてから、ビテニヤに進んで行こうとしたところ、イエスの御霊がこれを許さなかった。</span>
<span className="v" id="v8" data-v="8" data-xref="コリント人への第二の手紙 2:12; テモテヘの第二の手紙 4:13; 使徒行伝 16:11"> それで、ムシヤを通過して、トロアスに下って行った。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行伝 9:10–12; 使徒行伝 19:21; 使徒行伝 18:5"> ここで夜、パウロは一つの幻を見た。ひとりのマケドニヤ人が立って、「マケドニヤに渡ってきて、わたしたちを助けて下さい」と、彼に懇願するのであった。</span>
<span className="v" id="v10" data-v="10" data-xref="コリント人への第二の手紙 2:12–13; 使徒行伝 14:7; 使徒行伝 16:10–17"> パウロがこの幻を見た時、これは彼らに福音を伝えるために、神がわたしたちをお招きになったのだと確信して、わたしたちは、ただちにマケドニヤに渡って行くことにした。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="使徒行伝 21:1; 使徒行伝 16:8"> そこで、わたしたちはトロアスから船出して、サモトラケに直航し、翌日ネアポリスに着いた。</span>
<span className="v" id="v12" data-v="12" data-xref="テサロニケ人への第一の手紙 2:2; ピリピ人への手紙 1:1; 使徒行伝 20:6"> そこからピリピへ行った。これはマケドニヤのこの地方第一の町で、植民都市であった。わたしたちは、この町に数日間滞在した。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行伝 13:14; コロサイ人への手紙 1:23; 使徒行伝 17:2"> ある安息日に、わたしたちは町の門を出て、祈り場があると思って、川のほとりに行った。そして、そこにすわり、集まってきた婦人たちに話をした。</span>
<span className="v" id="v14" data-v="14" data-xref="エペソ人への手紙 1:17–18; ルカによる福音書 24:45; イザヤ書 50:5"> ところが、テアテラ市の紫布の商人で、神を敬うルデヤという婦人が聞いていた。主は彼女の心を開いて、パウロの語ることに耳を傾けさせた。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行伝 11:14; ヘブル人への手紙 13:2; 使徒行伝 16:33"> そして、この婦人もその家族も、共にバプテスマを受けたが、その時、彼女は「もし、わたしを主を信じる者とお思いでしたら、どうぞ、わたしの家にきて泊まって下さい」と懇望し、しいてわたしたちをつれて行った。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="レビ記 19:31; 申命記 18:9–11; イザヤ書 8:19"> ある時、わたしたちが、祈り場に行く途中、占いの霊につかれた女奴隷に出会った。彼女は占いをして、その主人たちに多くの利益を得させていた者である。</span>
<span className="v" id="v17" data-v="17" data-xref="ヨハネによる福音書 14:6; ペテロの第一の手紙 2:16; マルコによる福音書 5:7"> この女が、パウロやわたしたちのあとを追ってきては、「この人たちは、いと高き神の僕たちで、あなたがたに救の道を伝えるかただ」と、叫び出すのであった。</span>
<span className="v" id="v18" data-v="18" data-xref="マルコによる福音書 16:17; ルカによる福音書 10:17–19; 使徒行伝 3:6"> そして、そんなことを幾日間もつづけていた。パウロは困りはてて、その霊にむかい「イエス・キリストの名によって命じる。その女から出て行け」と言った。すると、その瞬間に霊が女から出て行った。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="使徒行伝 17:6; 使徒行伝 21:30; 使徒行伝 8:3"> 彼女の主人たちは、自分らの利益を得る望みが絶えたのを見て、パウロとシラスとを捕え、役人に引き渡すため広場に引きずって行った。</span>
<span className="v" id="v20" data-v="20" data-xref="ヤコブの手紙 4:4; ヨハネによる福音書 15:18–20; 使徒行伝 28:22"> それから、ふたりを長官たちの前に引き出して訴えた、「この人たちはユダヤ人でありまして、わたしたちの町をかき乱し、</span>
<span className="v" id="v21" data-v="21" data-xref="エステル記 3:8; 使徒行伝 26:3; エレミヤ書 10:3"> わたしたちローマ人が、採用も実行もしてはならない風習を宣伝しているのです」。</span>
<span className="v" id="v22" data-v="22" data-xref="テサロニケ人への第一の手紙 2:2; コリント人への第二の手紙 6:5; コリント人への第二の手紙 11:23–25"> 群衆もいっせいに立って、ふたりを責めたてたので、長官たちはふたりの上着をはぎ取り、むちで打つことを命じた。</span>
<span className="v" id="v23" data-v="23" data-xref="ヨハネの黙示録 2:10; テモテヘの第二の手紙 2:9; サムエル記上 23:22–23"> それで、ふたりに何度もむちを加えさせたのち、獄に入れ、獄吏にしっかり番をするようにと命じた。</span>
<span className="v" id="v24" data-v="24" data-xref="ヨブ記 13:27; ヨブ記 33:11; エレミヤ書 29:26"> 獄吏はこの厳命を受けたので、ふたりを奥の獄屋に入れ、その足に足かせをしっかとかけておいた。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="テサロニケ人への第一の手紙 5:16–18; 詩篇 119:62; ヤコブの手紙 1:2"> 真夜中ごろ、パウロとシラスとは、神に祈り、さんびを歌いつづけたが、囚人たちは耳をすまして聞きいっていた。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行伝 4:31; 使徒行伝 5:19; 使徒行伝 12:10"> ところが突然、大地震が起って、獄の土台が揺れ動き、戸は全部たちまち開いて、みんなの者の鎖が解けてしまった。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行伝 12:19; マタイによる福音書 27:5; 士師記 9:54"> 獄吏は目をさまし、獄の戸が開いてしまっているのを見て、囚人たちが逃げ出したものと思い、つるぎを抜いて自殺しかけた。</span>
<span className="v" id="v28" data-v="28" data-xref="テサロニケ人への第一の手紙 5:15; ルカによる福音書 23:34; ルカによる福音書 6:27–28"> そこでパウロは大声をあげて言った、「自害してはいけない。われわれは皆ひとり残らず、ここにいる」。</span>
<span className="v" id="v29" data-v="29" data-xref="ヨハネの黙示録 3:9; 使徒行伝 24:25; イザヤ書 60:14"> すると、獄吏は、あかりを手に入れた上、獄に駆け込んできて、おののきながらパウロとシラスの前にひれ伏した。</span>
<span className="v" id="v30" data-v="30" data-xref="使徒行伝 2:37; ヨハネによる福音書 6:27–29; イザヤ書 58:9"> それから、ふたりを外に連れ出して言った、「先生がた、わたしは救われるために、何をすべきでしょうか」。</span>
<span className="v" id="v31" data-v="31" data-xref="ヨハネによる福音書 1:12; 使徒行伝 2:38–39; ヨハネによる福音書 3:36"> ふたりが言った、「主イエスを信じなさい。そうしたら、あなたもあなたの家族も救われます」。</span>
<span className="v" id="v32" data-v="32" data-xref="ローマ人への手紙 1:16; コロサイ人への手紙 1:27–28; テモテヘの第一の手紙 1:13–16"> それから、彼とその家族一同とに、神の言を語って聞かせた。</span>
<span className="v" id="v33" data-v="33" data-xref="コリント人への第一の手紙 1:16; 使徒行伝 16:15; 使徒行伝 16:25"> 彼は真夜中にもかかわらず、ふたりを引き取って、その打ち傷を洗ってやった。そして、その場で自分も家族も、ひとり残らずバプテスマを受け、</span>
<span className="v" id="v34" data-v="34" data-xref="ローマ人への手紙 15:13; 使徒行伝 2:46; ローマ人への手紙 5:11"> さらに、ふたりを自分の家に案内して食事のもてなしをし、神を信じる者となったことを、全家族と共に心から喜んだ。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="エレミヤ書 5:22; 詩篇 76:10; 使徒行伝 5:40"> 夜が明けると、長官たちは警吏らをつかわして、「あの人たちを釈放せよ」と言わせた。</span>
<span className="v" id="v36" data-v="36" data-xref="使徒行伝 15:33; ヨハネによる福音書 14:27; サムエル記上 1:17"> そこで、獄吏はこの言葉をパウロに伝えて言った、「長官たちが、あなたがたを釈放させるようにと、使をよこしました。さあ、出てきて、無事にお帰りなさい」。</span>
<span className="v" id="v37" data-v="37" data-xref="使徒行伝 22:25–29; 詩篇 58:1–2; マタイによる福音書 10:16"> ところが、パウロは警吏らに言った、「彼らは、ローマ人であるわれわれを、裁判にかけもせずに、公衆の前でむち打ったあげく、獄に入れてしまった。しかるに今になって、ひそかに、われわれを出そうとするのか。それは、いけない。彼ら自身がここにきて、われわれを連れ出すべきである」。</span>
<span className="v" id="v38" data-v="38" data-xref="使徒行伝 22:29; マタイによる福音書 21:46; マタイによる福音書 14:5"> 警吏らはこの言葉を長官たちに報告した。すると長官たちは、ふたりがローマ人だと聞いて恐れ、</span>
<span className="v" id="v39" data-v="39" data-xref="マタイによる福音書 8:34; マルコによる福音書 5:17; ダニエル書 6:23"> 自分でやってきてわびた上、ふたりを獄から連れ出し、町から立ち去るようにと頼んだ。</span>
<span className="v" id="v40" data-v="40" data-xref="テサロニケ人への第一の手紙 3:2–3; 使徒行伝 16:14; 使徒行伝 14:22"> ふたりは獄を出て、ルデヤの家に行った。そして、兄弟たちに会って勧めをなし、それから出かけた。</span>
</div>

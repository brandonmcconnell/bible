<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="コリント人への第二の手紙 7:5; 使徒行伝 19:21; テモテヘの第一の手紙 1:3"> 騒ぎがやんだ後、パウロは弟子たちを呼び集めて激励を与えた上、別れのあいさつを述べ、マケドニヤへ向かって出発した。</span>
<span className="v" id="v2" data-v="2" data-xref="テサロニケ人への第一の手紙 2:3; テサロニケ人への第一の手紙 4:1; コロサイ人への手紙 1:28"> そして、その地方をとおり、多くの言葉で人々を励ましたのち、ギリシヤにきた。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行伝 20:19; コリント人への第二の手紙 11:26; 使徒行伝 9:23–24"> 彼はそこで三か月を過ごした。それからシリヤへ向かって、船出しようとしていた矢先、彼に対するユダヤ人の陰謀が起ったので、マケドニヤを経由して帰ることに決した。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行伝 19:29; エペソ人への手紙 6:21; テモテヘの第二の手紙 4:20"> プロの子であるエペソ人ソパテロ、テサロニケ人アリスタルコとセクンド、デルベ人ガイオ、それからテモテ、またアジヤ人テキコとトロピモがパウロの同行者であった。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行伝 16:8; 使徒行伝 16:10–11; テモテヘの第二の手紙 4:13"> この人たちは先発して、トロアスでわたしたちを待っていた。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行伝 12:3; 使徒行伝 16:12; 出エジプト記 23:15"> わたしたちは、除酵祭が終ったのちに、ピリピから出帆し、五日かかってトロアスに到着して、彼らと落ち合い、そこに七日間滞在した。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="コリント人への第一の手紙 16:2; 使徒行伝 2:42; ヨハネによる福音書 20:19"> 週の初めの日に、わたしたちがパンをさくために集まった時、パウロは翌日出発することにしていたので、しきりに人々と語り合い、夜中まで語りつづけた。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行伝 1:13; ルカによる福音書 22:12"> わたしたちが集まっていた屋上の間には、あかりがたくさんともしてあった。</span>
<span className="v" id="v9" data-v="9" data-xref="マルコによる福音書 13:36; マタイによる福音書 26:40–41; ヨナ書 1:5–6"> ユテコという若者が窓に腰をかけていたところ、パウロの話がながながと続くので、ひどく眠けがさしてきて、とうとうぐっすり寝入ってしまい、三階から下に落ちた。抱き起してみたら、もう死んでいた。</span>
<span className="v" id="v10" data-v="10" data-xref="マルコによる福音書 5:39; マタイによる福音書 9:23–24; 列王紀上 17:21–22"> そこでパウロは降りてきて、若者の上に身をかがめ、彼を抱きあげて、「騒ぐことはない。まだ命がある」と言った。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行伝 20:7; 使徒行伝 20:9"> そして、また上がって行って、パンをさいて食べてから、明けがたまで長いあいだ人々と語り合って、ついに出発した。</span>
<span className="v" id="v12" data-v="12" data-xref="テサロニケ人への第二の手紙 2:16; テサロニケ人への第一の手紙 5:14; コリント人への第二の手紙 1:4"> 人々は生きかえった若者を連れかえり、ひとかたならず慰められた。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="マルコによる福音書 6:46; マルコによる福音書 1:35; マルコによる福音書 6:31–33"> さて、わたしたちは先に舟に乗り込み、アソスへ向かって出帆した。そこからパウロを舟に乗せて行くことにしていた。彼だけは陸路をとることに決めていたからである。</span>
<span className="v" id="v14" data-v="14"> パウロがアソスで、わたしたちと落ち合った時、わたしたちは彼を舟に乗せてミテレネに行った。</span>
<span className="v" id="v15" data-v="15" data-xref="テモテヘの第二の手紙 4:20; 使徒行伝 20:17"> そこから出帆して、翌日キヨスの沖合にいたり、次の日にサモスに寄り、その翌日ミレトに着いた。</span>
<span className="v" id="v16" data-v="16" data-xref="コリント人への第一の手紙 16:8; 使徒行伝 2:1; 使徒行伝 19:21"> それは、パウロがアジヤで時間をとられないため、エペソには寄らないで続航することに決めていたからである。彼は、できればペンテコステの日には、エルサレムに着いていたかったので、旅を急いだわけである。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="テトスヘの手紙 1:5; 使徒行伝 11:30; テモテヘの第一の手紙 5:17"> そこでパウロは、ミレトからエペソに使をやって、教会の長老たちを呼び寄せた。</span>
<span className="v" id="v18" data-v="18" data-xref="テサロニケ人への第一の手紙 1:5–6; 使徒行伝 18:19; 使徒行伝 19:1"> そして、彼のところに寄り集まってきた時、彼らに言った。<br />「わたしが、アジヤの地に足を踏み入れた最初の日以来、いつもあなたがたとどんなふうに過ごしてきたか、よくご存じである。</span>
<span className="v" id="v19" data-v="19" data-xref="コロサイ人への手紙 3:24; コリント人への第二の手紙 2:4; ローマ人への手紙 12:11"> すなわち、謙遜の限りをつくし、涙を流し、ユダヤ人の陰謀によってわたしの身に及んだ数々の試練の中にあって、主に仕えてきた。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行伝 20:27; テモテヘの第二の手紙 4:2; 使徒行伝 5:42"> また、あなたがたの益になることは、公衆の前でも、また家々でも、すべてあますところなく話して聞かせ、また教え、</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行伝 2:38; 使徒行伝 11:18; ヨハネの第一の手紙 5:11–13"> ユダヤ人にもギリシヤ人にも、神に対する悔改めと、わたしたちの主イエスに対する信仰とを、強く勧めてきたのである。</span>
<span className="v" id="v22" data-v="22" data-xref="ヤコブの手紙 4:14; コリント人への第二の手紙 5:14; ペテロの第二の手紙 1:14"> 今や、わたしは御霊に迫られてエルサレムへ行く。あの都で、どんな事がわたしの身にふりかかって来るか、わたしにはわからない。</span>
<span className="v" id="v23" data-v="23" data-xref="使徒行伝 9:16; テサロニケ人への第一の手紙 3:3; 使徒行伝 21:4"> ただ、聖霊が至るところの町々で、わたしにはっきり告げているのは、投獄と患難とが、わたしを待ちうけているということだ。</span>
<span className="v" id="v24" data-v="24" data-xref="テモテヘの第二の手紙 4:6–8; コリント人への第二の手紙 4:1; コリント人への第二の手紙 12:10"> しかし、わたしは自分の行程を走り終え、主イエスから賜わった、神のめぐみの福音をあかしする任務を果し得さえしたら、このいのちは自分にとって、少しも惜しいとは思わない。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行伝 28:31; 使徒行伝 20:38; マタイによる福音書 4:23"> わたしはいま信じている、あなたがたの間を歩き回って御国を宣べ伝えたこのわたしの顔を、みんなが今後二度と見ることはあるまい。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行伝 18:6; エゼキエル書 3:18–21; エゼキエル書 33:2–9"> だから、きょう、この日にあなたがたに断言しておく。わたしは、すべての人の血について、なんら責任がない。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行伝 20:20; テサロニケ人への第一の手紙 2:4; ガラテヤ人への手紙 1:7–10"> 神のみ旨を皆あますところなく、あなたがたに伝えておいたからである。</span>
<span className="v" id="v28" data-v="28" data-xref="ペテロの第一の手紙 5:2–3; テモテヘの第一の手紙 4:16; イザヤ書 40:11"> どうか、あなたがた自身に気をつけ、また、すべての群れに気をくばっていただきたい。聖霊は、神が御子の血であがない取られた神の教会を牧させるために、あなたがたをその群れの監督者にお立てになったのである。</span>
<span className="v" id="v29" data-v="29" data-xref="マタイによる福音書 7:15; ペテロの第二の手紙 2:1; ヨハネによる福音書 10:12"> わたしが去った後、狂暴なおおかみが、あなたがたの中にはいり込んできて、容赦なく群れを荒すようになることを、わたしは知っている。</span>
<span className="v" id="v30" data-v="30" data-xref="テモテヘの第一の手紙 1:19–20; テモテヘの第二の手紙 4:3–4; 箴言 23:33"> また、あなたがた自身の中からも、いろいろ曲ったことを言って、弟子たちを自分の方に、ひっぱり込もうとする者らが起るであろう。</span>
<span className="v" id="v31" data-v="31" data-xref="使徒行伝 19:8; 使徒行伝 20:19; 使徒行伝 19:10"> だから、目をさましていなさい。そして、わたしが三年の間、夜も昼も涙をもって、あなたがたひとりびとりを絶えずさとしてきたことを、忘れないでほしい。</span>
<span className="v" id="v32" data-v="32" data-xref="コロサイ人への手紙 1:12; エペソ人への手紙 1:14; コロサイ人への手紙 3:24"> 今わたしは、主とその恵みの言とに、あなたがたをゆだねる。御言には、あなたがたの徳をたて、聖別されたすべての人々と共に、御国をつがせる力がある。</span>
<span className="v" id="v33" data-v="33" data-xref="コリント人への第二の手紙 11:9; コリント人への第一の手紙 9:12; コリント人への第一の手紙 9:18"> わたしは、人の金や銀や衣服をほしがったことはない。</span>
<span className="v" id="v34" data-v="34" data-xref="使徒行伝 18:3; コリント人への第一の手紙 4:12; テサロニケ人への第二の手紙 3:8–9"> あなたがた自身が知っているとおり、わたしのこの両手は、自分の生活のためにも、また一緒にいた人たちのためにも、働いてきたのだ。</span>
<span className="v" id="v35" data-v="35" data-xref="ヘブル人への手紙 13:16; 箴言 19:17; コリント人への第二の手紙 9:6–12"> わたしは、あなたがたもこのように働いて、弱い者を助けなければならないこと、また『受けるよりは与える方が、さいわいである』と言われた主イエスの言葉を記憶しているべきことを、万事について教え示したのである」。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="使徒行伝 21:5; ルカによる福音書 22:41; ピリピ人への手紙 4:6"> こう言って、パウロは一同と共にひざまずいて祈った。</span>
<span className="v" id="v37" data-v="37" data-xref="テモテヘの第二の手紙 1:4; コリント人への第一の手紙 16:20; テサロニケ人への第一の手紙 5:26"> みんなの者は、はげしく泣き悲しみ、パウロの首を抱いて、幾度も接吻し、</span>
<span className="v" id="v38" data-v="38" data-xref="使徒行伝 15:3; コリント人への第一の手紙 16:11; 使徒行伝 20:25"> もう二度と自分の顔を見ることはあるまいと彼が言ったので、特に心を痛めた。それから彼を舟まで見送った。</span>
</div>

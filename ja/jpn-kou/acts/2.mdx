<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ローマ人への手紙 15:6; ピリピ人への手紙 2:2; 使徒行伝 1:13–15"> 五旬節の日がきて、みんなの者が一緒に集まっていると、</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行伝 4:31; 列王紀上 19:11; 詩篇 18:10"> 突然、激しい風が吹いてきたような音が天から起ってきて、一同がすわっていた家いっぱいに響きわたった。</span>
<span className="v" id="v3" data-v="3" data-xref="マタイによる福音書 3:11; ヨハネによる福音書 1:32–33; エレミヤ書 23:29"> また、舌のようなものが、炎のように分れて現れ、ひとりびとりの上にとどまった。</span>
<span className="v" id="v4" data-v="4" data-xref="マルコによる福音書 16:17; 使徒行伝 13:52; 使徒行伝 4:31"> すると、一同は聖霊に満たされ、御霊が語らせるままに、いろいろの他国の言葉で語り出した。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="ルカによる福音書 2:25; 使徒行伝 8:2; コロサイ人への手紙 1:23"> さて、エルサレムには、天下のあらゆる国々から、信仰深いユダヤ人たちがきて住んでいたが、</span>
<span className="v" id="v6" data-v="6" data-xref="マタイによる福音書 2:3; コリント人への第一の手紙 16:9; 使徒行伝 2:2"> この物音に大ぜいの人が集まってきて、彼らの生れ故郷の国語で、使徒たちが話しているのを、だれもかれも聞いてあっけに取られた。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行伝 2:12; 使徒行伝 1:11; ヨハネによる福音書 7:52"> そして驚き怪しんで言った、「見よ、いま話しているこの人たちは、皆ガリラヤ人ではないか。</span>
<span className="v" id="v8" data-v="8"> それだのに、わたしたちがそれぞれ、生れ故郷の国語を彼らから聞かされるとは、いったい、どうしたことか。</span>
<span className="v" id="v9" data-v="9" data-xref="ペテロの第一の手紙 1:1; 使徒行伝 18:2; ヨハネの黙示録 1:4"> わたしたちの中には、パルテヤ人、メジヤ人、エラム人もおれば、メソポタミヤ、ユダヤ、カパドキヤ、ポントとアジヤ、</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行伝 16:6; ゼカリヤ書 8:23; ゼカリヤ書 8:20"> フルギヤとパンフリヤ、エジプトとクレネに近いリビヤ地方などに住む者もいるし、またローマ人で旅にきている者、</span>
<span className="v" id="v11" data-v="11" data-xref="コリント人への第一の手紙 12:10; 出エジプト記 15:11; 詩篇 78:4"> ユダヤ人と改宗者、クレテ人とアラビヤ人もいるのだが、あの人々がわたしたちの国語で、神の大きな働きを述べるのを聞くとは、どうしたことか」。</span>
<span className="v" id="v12" data-v="12" data-xref="ルカによる福音書 15:26; 使徒行伝 17:20; ルカによる福音書 18:36"> みんなの者は驚き惑って、互に言い合った、「これは、いったい、どういうわけなのだろう」。</span>
<span className="v" id="v13" data-v="13" data-xref="コリント人への第一の手紙 14:23; 使徒行伝 2:15; サムエル記上 1:14"> しかし、ほかの人たちはあざ笑って、「あの人たちは新しい酒で酔っているのだ」と言った。</span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="イザヤ書 51:7; イザヤ書 51:1; 申命記 27:9"> そこで、ペテロが十一人の者と共に立ちあがり、声をあげて人々に語りかけた。<br />「ユダヤの人たち、ならびにエルサレムに住むすべてのかたがた、どうか、この事を知っていただきたい。わたしの言うことに耳を傾けていただきたい。</span>
<span className="v" id="v15" data-v="15" data-xref="テサロニケ人への第一の手紙 5:5–8; サムエル記上 1:15; マタイによる福音書 20:3"> 今は朝の九時であるから、この人たちは、あなたがたが思っているように、酒に酔っているのではない。</span>
<span className="v" id="v16" data-v="16" data-xref="ヨエル書 2:28–32"> そうではなく、これは預言者ヨエルが預言していたことに外ならないのである。すなわち、</span>
<span className="v" id="v17" data-v="17" data-xref="ヨエル書 2:28–32; イザヤ書 44:3; テトスヘの手紙 3:4–6"> <span className="pl pl-1">『神がこう仰せになる。</span><br /><span className="pl pl-1">終りの時には、</span><br /><span className="pl pl-1">わたしの霊をすべての人に注ごう。</span><br /><span className="pl pl-1">そして、あなたがたのむすこ娘は預言をし、</span><br /><span className="pl pl-1">若者たちは幻を見、</span><br /><span className="pl pl-1">老人たちは夢を見るであろう。</span></span>
<span className="v" id="v18" data-v="18" data-xref="ガラテヤ人への手紙 3:28; コロサイ人への手紙 3:11; コリント人への第一の手紙 7:21–22"> <span className="pl pl-1">その時には、わたしの男女の僕たちにも</span><br /><span className="pl pl-1">わたしの霊を注ごう。</span><br /><span className="pl pl-1">そして彼らも預言をするであろう。</span></span>
<span className="v" id="v19" data-v="19" data-xref="ヨエル書 2:30–31; ゼパニヤ書 1:14–18; マラキ書 4:1–6"> <span className="pl pl-1">また、上では、天に奇跡を見せ、</span><br /><span className="pl pl-1">下では、地にしるしを、</span><br /><span className="pl pl-1">すなわち、血と火と立ちこめる煙とを、</span><br /><span className="pl pl-1">見せるであろう。</span></span>
<span className="v" id="v20" data-v="20" data-xref="ペテロの第二の手紙 3:10; アモス書 8:9; マタイによる福音書 24:29"> <span className="pl pl-1">主の大いなる輝かしい日が来る前に、</span><br /><span className="pl pl-1">日はやみに</span><br /><span className="pl pl-1">月は血に変るであろう。</span></span>
<span className="v" id="v21" data-v="21" data-xref="ローマ人への手紙 10:12–13; ヨエル書 2:32; 詩篇 86:5"> <span className="pl pl-1">そのとき、主の名を呼び求める者は、</span><br /><span className="pl pl-1">みな救われるであろう』。</span></span>
<span className="v" id="v22" data-v="22" data-xref="ヨハネによる福音書 3:2; ヨハネによる福音書 14:10–11; マタイによる福音書 12:28"> <span className="pl pl-1">イスラエルの人たちよ、今わたしの語ることを聞きなさい。あなたがたがよく知っているとおり、ナザレ人イエスは、神が彼をとおして、あなたがたの中で行われた数々の力あるわざと奇跡としるしとにより、神からつかわされた者であることを、あなたがたに示されたかたであった。</span></span>
<span className="v" id="v23" data-v="23" data-xref="ルカによる福音書 22:22; 使徒行伝 4:28; 使徒行伝 3:18"> <span className="pl pl-1">このイエスが渡されたのは神の定めた計画と予知とによるのであるが、あなたがたは彼を不法の人々の手で十字架につけて殺した。</span></span>
<span className="v" id="v24" data-v="24" data-xref="コリント人への第一の手紙 6:14; ペテロの第一の手紙 1:21; 使徒行伝 2:32"> <span className="pl pl-1">神はこのイエスを死の苦しみから解き放って、よみがえらせたのである。イエスが死に支配されているはずはなかったからである。</span></span>
<span className="v" id="v25" data-v="25" data-xref="詩篇 16:8–11; イザヤ書 41:13; 詩篇 62:6"> <span className="pl pl-1">ダビデはイエスについてこう言っている、</span><br /><span className="pl pl-1">『わたしは常に目の前に主を見た。</span><br /><span className="pl pl-1">主は、わたしが動かされないため、</span><br /><span className="pl pl-1">わたしの右にいて下さるからである。</span></span>
<span className="v" id="v26" data-v="26" data-xref="詩篇 16:9; 詩篇 63:5; 詩篇 71:23"> <span className="pl pl-1">それゆえ、わたしの心は楽しみ、</span><br /><span className="pl pl-1">わたしの舌はよろこび歌った。</span><br /><span className="pl pl-1">わたしの肉体もまた、望みに生きるであろう。</span></span>
<span className="v" id="v27" data-v="27" data-xref="詩篇 16:10; 使徒行伝 2:31; ヨハネの黙示録 1:18"> <span className="pl pl-1">あなたは、わたしの魂を黄泉に捨ておくことをせず、</span><br /><span className="pl pl-1">あなたの聖者が朽ち果てるのを、お許しにならないであろう。</span></span>
<span className="v" id="v28" data-v="28" data-xref="詩篇 16:11; 詩篇 25:4; 詩篇 21:6"> <span className="pl pl-1">あなたは、いのちの道をわたしに示し、</span><br /><span className="pl pl-1">み前にあって、わたしを喜びで満たして下さるであろう』。</span></span>
<span className="v" id="v29" data-v="29" data-xref="使徒行伝 13:36; 列王紀上 2:10; 使徒行伝 7:8–9"> <span className="pl pl-1">兄弟たちよ、族長ダビデについては、わたしはあなたがたにむかって大胆に言うことができる。彼は死んで葬られ、現にその墓が今日に至るまで、わたしたちの間に残っている。</span></span>
<span className="v" id="v30" data-v="30" data-xref="詩篇 132:11–18; 詩篇 89:3–4; エレミヤ書 33:14–15"> <span className="pl pl-1">彼は預言者であって、『その子孫のひとりを王位につかせよう』と、神が堅く彼に誓われたことを認めていたので、</span></span>
<span className="v" id="v31" data-v="31" data-xref="使徒行伝 2:27; 詩篇 16:10; 使徒行伝 13:35"> <span className="pl pl-1">キリストの復活をあらかじめ知って、『彼は黄泉に捨ておかれることがなく、またその肉体が朽ち果てることもない』と語ったのである。</span></span>
<span className="v" id="v32" data-v="32" data-xref="使徒行伝 3:15; 使徒行伝 1:8; 使徒行伝 1:22"> <span className="pl pl-1">このイエスを、神はよみがえらせた。そして、わたしたちは皆その証人なのである。</span></span>
<span className="v" id="v33" data-v="33" data-xref="使徒行伝 1:4; 使徒行伝 5:31; 使徒行伝 2:17"> <span className="pl pl-1">それで、イエスは神の右に上げられ、父から約束の聖霊を受けて、それをわたしたちに注がれたのである。このことは、あなたがたが現に見聞きしているとおりである。</span></span>
<span className="v" id="v34" data-v="34" data-xref="詩篇 110:1; マタイによる福音書 22:42–45; ヘブル人への手紙 1:13"> <span className="pl pl-1">ダビデが天に上ったのではない。彼自身こう言っている、</span><br /><span className="pl pl-1">『主はわが主に仰せになった、</span></span>
<span className="v" id="v35" data-v="35" data-xref="ヨハネの黙示録 19:19–3; ローマ人への手紙 16:20; イザヤ書 60:14"> <span className="pl pl-1">あなたの敵をあなたの足台にするまでは、</span><br /><span className="pl pl-1">わたしの右に座していなさい』。</span></span>
<span className="v" id="v36" data-v="36" data-xref="使徒行伝 5:30–31; ローマ人への手紙 14:8–12; コリント人への第二の手紙 5:10"> <span className="pl pl-1">だから、イスラエルの全家は、この事をしかと知っておくがよい。あなたがたが十字架につけたこのイエスを、神は、主またキリストとしてお立てになったのである」。</span></span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="ルカによる福音書 3:10; 使徒行伝 22:10; ヘブル人への手紙 4:12–13"> 人々はこれを聞いて、強く心を刺され、ペテロやほかの使徒たちに、「兄弟たちよ、わたしたちは、どうしたらよいのでしょうか」と言った。</span>
<span className="v" id="v38" data-v="38" data-xref="使徒行伝 22:16; マルコによる福音書 16:16; 使徒行伝 8:12"> すると、ペテロが答えた、「悔い改めなさい。そして、あなたがたひとりびとりが罪のゆるしを得るために、イエス・キリストの名によって、バプテスマを受けなさい。そうすれば、あなたがたは聖霊の賜物を受けるであろう。</span>
<span className="v" id="v39" data-v="39" data-xref="イザヤ書 44:3; 創世記 17:7–8; ローマ人への手紙 8:30"> この約束は、われらの主なる神の召しにあずかるすべての者、すなわちあなたがたと、あなたがたの子らと、遠くの者一同とに、与えられているものである」。</span>
<span className="v" id="v40" data-v="40" data-xref="ピリピ人への手紙 2:15; 申命記 32:5; マタイによる福音書 17:17"> ペテロは、ほかになお多くの言葉であかしをなし、人々に「この曲った時代から救われよ」と言って勧めた。</span>
<span className="v" id="v41" data-v="41" data-xref="使徒行伝 4:4; 使徒行伝 2:47; 使徒行伝 16:31–34"> そこで、彼の勧めの言葉を受けいれた者たちは、バプテスマを受けたが、その日、仲間に加わったものが三千人ほどあった。</span>
<span className="v" id="v42" data-v="42" data-xref="ヘブル人への手紙 10:25; 使徒行伝 1:14; ヨハネの第一の手紙 1:3"> そして一同はひたすら、使徒たちの教を守り、信徒の交わりをなし、共にパンをさき、祈をしていた。</span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="ルカによる福音書 7:16; ヨハネによる福音書 14:12; ルカによる福音書 8:37"> みんなの者におそれの念が生じ、多くの奇跡としるしとが、使徒たちによって、次々に行われた。</span>
<span className="v" id="v44" data-v="44" data-xref="使徒行伝 4:32; ヨハネの第一の手紙 3:16–18; コリント人への第二の手紙 8:14–15"> 信者たちはみな一緒にいて、いっさいの物を共有にし、</span>
<span className="v" id="v45" data-v="45" data-xref="ヨハネの第一の手紙 3:17; テモテヘの第一の手紙 6:18–19; ヤコブの手紙 2:14–16"> 資産や持ち物を売っては、必要に応じてみんなの者に分け与えた。</span>
<span className="v" id="v46" data-v="46" data-xref="使徒行伝 5:42; 使徒行伝 20:7; 使徒行伝 2:42"> そして日々心を一つにして、絶えず宮もうでをなし、家ではパンをさき、よろこびと、まごころとをもって、食事を共にし、</span>
<span className="v" id="v47" data-v="47" data-xref="使徒行伝 16:5; 使徒行伝 5:13–14; 使徒行伝 2:41"> 神をさんびし、すべての人に好意を持たれていた。そして主は、救われる者を日々仲間に加えて下さったのである。</span>
</div>

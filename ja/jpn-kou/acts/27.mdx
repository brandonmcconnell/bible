<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行伝 25:25; 使徒行伝 25:12; 使徒行伝 10:1"> さて、わたしたちが、舟でイタリヤに行くことが決まった時、パウロとそのほか数人の囚人とは、近衛隊の百卒長ユリアスに託された。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行伝 19:29; ピレモンヘの手紙 1:24; コロサイ人への手紙 4:10"> そしてわたしたちは、アジヤ沿岸の各所に寄港することになっているアドラミテオの舟に乗り込んで、出帆した。テサロニケのマケドニヤ人アリスタルコも同行した。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行伝 24:23; 使徒行伝 28:16; 使徒行伝 27:43"> 次の日、シドンに入港したが、ユリアスは、パウロを親切に取り扱い、友人をおとずれてかんたいを受けることを、許した。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行伝 4:36; 使徒行伝 15:39; 使徒行伝 13:4"> それからわたしたちは、ここから船出したが、逆風にあったので、クプロの島かげを航行し、</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行伝 6:9; 使徒行伝 13:13; 使徒行伝 15:41"> キリキヤとパンフリヤの沖を過ぎて、ルキヤのミラに入港した。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行伝 28:11; 使徒行伝 27:1; 使徒行伝 6:9"> そこに、イタリヤ行きのアレキサンドリヤの舟があったので、百卒長は、わたしたちをその舟に乗り込ませた。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行伝 27:21; テトスヘの手紙 1:5; テトスヘの手紙 1:12"> 幾日ものあいだ、舟の進みがおそくて、わたしたちは、かろうじてクニドの沖合にきたが、風がわたしたちの行く手をはばむので、サルモネの沖、クレテの島かげを航行し、</span>
<span className="v" id="v8" data-v="8"> その岸に沿って進み、かろうじて「良き港」と呼ばれる所に着いた。その近くにラサヤの町があった。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="民数記 29:7; レビ記 23:27–29; レビ記 16:29–31"> 長い時が経過し、断食期も過ぎてしまい、すでに航海が危険な季節になったので、パウロは人々に警告して言った、</span>
<span className="v" id="v10" data-v="10" data-xref="ダニエル書 2:30; 使徒行伝 27:20–26; 使徒行伝 27:41–44"> 「皆さん、わたしの見るところでは、この航海では、積荷や船体ばかりでなく、われわれの生命にも、危害と大きな損失が及ぶであろう」。</span>
<span className="v" id="v11" data-v="11" data-xref="エゼキエル書 33:4; ヘブル人への手紙 11:7; エゼキエル書 3:17–18"> しかし百卒長は、パウロの意見よりも、船長や船主の方を信頼した。</span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 107:30; 使徒行伝 27:8"> なお、この港は冬を過ごすのに適しないので、大多数の者は、ここから出て、できればなんとかして、南西と北西とに面しているクレテのピニクス港に行って、そこで冬を過ごしたいと主張した。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="ルカによる福音書 12:55; 雅歌 4:16; ヨブ記 37:17"> 時に、南風が静かに吹いてきたので、彼らは、この時とばかりにいかりを上げて、クレテの岸に沿って航行した。</span>
<span className="v" id="v14" data-v="14" data-xref="マルコによる福音書 4:37; 詩篇 107:25–27; 出エジプト記 14:21–27"> すると間もなく、ユーラクロンと呼ばれる暴風が、島から吹きおろしてきた。</span>
<span className="v" id="v15" data-v="15" data-xref="ヤコブの手紙 3:4; 使徒行伝 27:27"> そのために、舟が流されて風に逆らうことができないので、わたしたちは吹き流されるままに任せた。</span>
<span className="v" id="v16" data-v="16"> それから、クラウダという小島の陰に、はいり込んだので、わたしたちは、やっとのことで小舟を処置することができ、</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行伝 27:29; 使徒行伝 27:26; 使徒行伝 27:41"> それを舟に引き上げてから、綱で船体を巻きつけた。また、スルテスの洲に乗り上げるのを恐れ、帆をおろして流れるままにした。</span>
<span className="v" id="v18" data-v="18" data-xref="ヨナ書 1:5; 使徒行伝 27:38; マタイによる福音書 16:26"> わたしたちは、暴風にひどく悩まされつづけたので、次の日に、人々は積荷を捨てはじめ、</span>
<span className="v" id="v19" data-v="19" data-xref="ヨブ記 2:4; ルカによる福音書 9:24–25; マルコによる福音書 8:35–37"> 三日目には、船具までも、てずから投げすてた。</span>
<span className="v" id="v20" data-v="20" data-xref="マタイによる福音書 24:29; マタイによる福音書 8:24–25; エレミヤ書 2:25"> 幾日ものあいだ、太陽も星も見えず、暴風は激しく吹きすさぶので、わたしたちの助かる最後の望みもなくなった。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="創世記 42:22; 詩篇 107:5–6; 使徒行伝 27:7"> みんなの者は、長いあいだ食事もしないでいたが、その時、パウロが彼らの中に立って言った、「皆さん、あなたがたが、わたしの忠告を聞きいれて、クレテから出なかったら、このような危害や損失を被らなくてすんだはずであった。</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行伝 27:25; 使徒行伝 27:36; コリント人への第二の手紙 4:8–9"> だが、この際、お勧めする。元気を出しなさい。舟が失われるだけで、あなたがたの中で生命を失うものは、ひとりもいないであろう。</span>
<span className="v" id="v23" data-v="23" data-xref="使徒行伝 23:11; ローマ人への手紙 1:9; テモテヘの第二の手紙 4:17"> 昨夜、わたしが仕え、また拝んでいる神からの御使が、わたしのそばに立って言った、</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行伝 23:11; テモテヘの第二の手紙 4:16–17; マタイによる福音書 10:28"> 『パウロよ、恐れるな。あなたは必ずカイザルの前に立たなければならない。たしかに神は、あなたと同船の者を、ことごとくあなたに賜わっている』。</span>
<span className="v" id="v25" data-v="25" data-xref="ローマ人への手紙 4:20–21; ルカによる福音書 1:45; 民数記 23:19"> だから、皆さん、元気を出しなさい。万事はわたしに告げられたとおりに成って行くと、わたしは、神かけて信じている。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行伝 28:1; 使徒行伝 27:17; 使徒行伝 27:29"> われわれは、どこかの島に打ちあげられるに相違ない」。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="ヨナ書 1:6; 使徒行伝 27:30; ヨハネの黙示録 18:17"> わたしたちがアドリヤ海に漂ってから十四日目の夜になった時、真夜中ごろ、水夫らはどこかの陸地に近づいたように感じた。</span>
<span className="v" id="v28" data-v="28"> そこで、水の深さを測ってみたところ、二十ひろであることがわかった。それから少し進んで、もう一度測ってみたら、十五ひろであった。</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行伝 27:17; ヘブル人への手紙 6:19; 申命記 28:67"> わたしたちが、万一暗礁に乗り上げては大変だと、人々は気づかって、ともから四つのいかりを投げおろし、夜の明けるのを待ちわびていた。</span>
<span className="v" id="v30" data-v="30" data-xref="使徒行伝 27:16; 使徒行伝 27:32"> その時、水夫らが舟から逃げ出そうと思って、へさきからいかりを投げおろすと見せかけ、小舟を海におろしていたので、</span>
<span className="v" id="v31" data-v="31" data-xref="テサロニケ人への第二の手紙 2:13–14; 詩篇 91:11–12; エレミヤ書 29:11–13"> パウロは、百卒長や兵卒たちに言った、「あの人たちが、舟に残っていなければ、あなたがたは助からない」。</span>
<span className="v" id="v32" data-v="32" data-xref="ピリピ人への手紙 3:7–9; ルカによる福音書 16:8"> そこで兵卒たちは、小舟の綱を断ち切って、その流れて行くままに任せた。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33"> 夜が明けかけたころ、パウロは一同の者に、食事をするように勧めて言った、「あなたがたが食事もせずに、見張りを続けてから、何も食べないで、きょうが十四日目に当る。</span>
<span className="v" id="v34" data-v="34" data-xref="マタイによる福音書 10:30; 列王紀上 1:52; ルカによる福音書 21:18"> だから、いま食事を取ることをお勧めする。それが、あなたがたを救うことになるのだから。たしかに髪の毛ひとすじでも、あなたがたの頭から失われることはないであろう」。</span>
<span className="v" id="v35" data-v="35" data-xref="マタイによる福音書 15:36; コリント人への第一の手紙 10:30–31; テモテヘの第一の手紙 4:3–4"> 彼はこう言って、パンを取り、みんなの前で神に感謝し、それをさいて食べはじめた。</span>
<span className="v" id="v36" data-v="36" data-xref="コリント人への第二の手紙 1:4–6; 使徒行伝 27:22; 詩篇 27:14"> そこで、みんなの者も元気づいて食事をした。</span>
<span className="v" id="v37" data-v="37" data-xref="使徒行伝 2:41; ローマ人への手紙 13:1; ペテロの第一の手紙 3:20"> 舟にいたわたしたちは、合わせて二百七十六人であった。</span>
<span className="v" id="v38" data-v="38" data-xref="ヨナ書 1:5; マタイによる福音書 6:25; 使徒行伝 27:18–19"> みんなの者は、じゅうぶんに食事をした後、穀物を海に投げすてて舟を軽くした。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="使徒行伝 28:1"> 夜が明けて、どこの土地かよくわからなかったが、砂浜のある入江が見えたので、できれば、それに舟を乗り入れようということになった。</span>
<span className="v" id="v40" data-v="40" data-xref="イザヤ書 33:23; 使徒行伝 27:29–30"> そこで、いかりを切り離して海に捨て、同時にかじの綱をゆるめ、風に前の帆をあげて、砂浜にむかって進んだ。</span>
<span className="v" id="v41" data-v="41" data-xref="コリント人への第二の手紙 11:25–26; エゼキエル書 27:26; 使徒行伝 27:26–29"> ところが、潮流の流れ合う所に突き進んだため、舟を浅瀬に乗りあげてしまって、へさきがめり込んで動かなくなり、ともの方は激浪のためにこわされた。</span>
<span className="v" id="v42" data-v="42" data-xref="マルコによる福音書 15:15–20; 伝道の書 9:3; 詩篇 74:20"> 兵卒たちは、囚人らが泳いで逃げるおそれがあるので、殺してしまおうと図ったが、</span>
<span className="v" id="v43" data-v="43" data-xref="使徒行伝 27:3; 箴言 16:7; 使徒行伝 27:11"> 百卒長は、パウロを救いたいと思うところから、その意図をしりぞけ、泳げる者はまず海に飛び込んで陸に行き、</span>
<span className="v" id="v44" data-v="44" data-xref="使徒行伝 27:22; 詩篇 107:28–30; ヨハネによる福音書 6:39–40"> その他の者は、板や舟の破片に乗って行くように命じた。こうして、全部の者が上陸して救われたのであった。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行伝 8:3; テモテヘの第一の手紙 1:13; ガラテヤ人への手紙 1:13"> さてサウロは、なおも主の弟子たちに対する脅迫、殺害の息をはずませながら、大祭司のところに行って、</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行伝 19:9; 使徒行伝 19:23; 使徒行伝 24:14"> ダマスコの諸会堂あての添書を求めた。それは、この道の者を見つけ次第、男女の別なく縛りあげて、エルサレムにひっぱって来るためであった。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行伝 26:12–13; コリント人への第一の手紙 15:8; 使徒行伝 22:6"> ところが、道を急いでダマスコの近くにきたとき、突然、天から光がさして、彼をめぐり照した。</span>
<span className="v" id="v4" data-v="4" data-xref="ゼカリヤ書 2:8; 創世記 22:11; ローマ人への手紙 11:22"> 彼は地に倒れたが、その時「サウロ、サウロ、なぜわたしを迫害するのか」と呼びかける声を聞いた。</span>
<span className="v" id="v5" data-v="5" data-xref="テモテヘの第一の手紙 1:13; サムエル記上 3:4–10; ヨブ記 9:4"> そこで彼は「主よ、あなたは、どなたですか」と尋ねた。すると答があった、「わたしは、あなたが迫害しているイエスである。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行伝 22:10; 使徒行伝 26:16; テモテヘの第一の手紙 1:14–16"> さあ立って、町にはいって行きなさい。そうすれば、そこであなたのなすべき事が告げられるであろう」。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行伝 22:9; ダニエル書 10:7; 使徒行伝 26:13–14"> サウロの同行者たちは物も言えずに立っていて、声だけは聞えたが、だれも見えなかった。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行伝 22:11; 使徒行伝 9:18; 列王紀下 6:17–20"> サウロは地から起き上がって目を開いてみたが、何も見えなかった。そこで人々は、彼の手を引いてダマスコへ連れて行った。</span>
<span className="v" id="v9" data-v="9" data-xref="ヨナ書 3:6–8; エステル記 4:16; 歴代志下 33:12–13"> 彼は三日間、目が見えず、また食べることも飲むこともしなかった。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="創世記 22:1; 使徒行伝 10:3; 使徒行伝 22:12"> さて、ダマスコにアナニヤというひとりの弟子がいた。この人に主が幻の中に現れて、「アナニヤよ」とお呼びになった。彼は「主よ、わたしでございます」と答えた。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行伝 21:39; 使徒行伝 22:3; 使徒行伝 9:30"> そこで主が彼に言われた、「立って、『真すぐ』という名の路地に行き、ユダの家でサウロというタルソ人を尋ねなさい。彼はいま祈っている。</span>
<span className="v" id="v12" data-v="12" data-xref="マルコによる福音書 5:23; 使徒行伝 9:10; 使徒行伝 9:17–18"> 彼はアナニヤという人がはいってきて、手を自分の上において再び見えるようにしてくれるのを、幻で見たのである」。</span>
<span className="v" id="v13" data-v="13" data-xref="テモテヘの第一の手紙 1:13–15; 使徒行伝 8:3; 使徒行伝 22:19–20"> アナニヤは答えた、「主よ、あの人がエルサレムで、どんなにひどい事をあなたの聖徒たちにしたかについては、多くの人たちから聞いています。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行伝 9:21; 使徒行伝 7:59; テモテヘの第二の手紙 2:22"> そして彼はここでも、御名をとなえる者たちをみな捕縛する権を、祭司長たちから得てきているのです」。</span>
<span className="v" id="v15" data-v="15" data-xref="ガラテヤ人への手紙 1:15–16; エペソ人への手紙 3:7–8; テモテヘの第二の手紙 4:16–17"> しかし、主は仰せになった、「さあ、行きなさい。あの人は、異邦人たち、王たち、またイスラエルの子らにも、わたしの名を伝える器として、わたしが選んだ者である。</span>
<span className="v" id="v16" data-v="16" data-xref="テサロニケ人への第一の手紙 3:3; 使徒行伝 21:11; コリント人への第二の手紙 6:4"> わたしの名のために彼がどんなに苦しまなければならないかを、彼に知らせよう」。</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行伝 8:17; 使徒行伝 6:6; 使徒行伝 2:4"> そこでアナニヤは、出かけて行ってその家にはいり、手をサウロの上において言った、「兄弟サウロよ、あなたが来る途中で現れた主イエスは、あなたが再び見えるようになるため、そして聖霊に満たされるために、わたしをここにおつかわしになったのです」。</span>
<span className="v" id="v18" data-v="18" data-xref="コリント人への第二の手紙 3:14; 使徒行伝 22:16; 使徒行伝 2:38"> するとたちどころに、サウロの目から、うろこのようなものが落ちて、元どおり見えるようになった。そこで彼は立ってバプテスマを受け、</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行伝 26:20; サムエル記上 30:12; ガラテヤ人への手紙 1:17"> また食事をとって元気を取りもどした。<br />サウロは、ダマスコにいる弟子たちと共に数日間を過ごしてから、</span>
<span className="v" id="v20" data-v="20" data-xref="ヨハネによる福音書 20:28; ガラテヤ人への手紙 2:20; ヨハネの第一の手紙 4:14–15"> ただちに諸会堂でイエスのことを宣べ伝え、このイエスこそ神の子であると説きはじめた。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行伝 9:13–14; 使徒行伝 8:3; テサロニケ人への第二の手紙 1:10"> これを聞いた人たちはみな非常に驚いて言った、「あれは、エルサレムでこの名をとなえる者たちを苦しめた男ではないか。その上ここにやってきたのも、彼らを縛りあげて、祭司長たちのところへひっぱって行くためではなかったか」。</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行伝 18:5; イザヤ書 40:29; ルカによる福音書 21:15"> しかし、サウロはますます力が加わり、このイエスがキリストであることを論証して、ダマスコに住むユダヤ人たちを言い伏せた。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="ガラテヤ人への手紙 1:17–18; テサロニケ人への第一の手紙 2:15–16; 使徒行伝 14:19"> 相当の日数がたったころ、ユダヤ人たちはサウロを殺す相談をした。</span>
<span className="v" id="v24" data-v="24" data-xref="コリント人への第二の手紙 11:32; 使徒行伝 25:3; 使徒行伝 20:3"> ところが、その陰謀が彼の知るところとなった。彼らはサウロを殺そうとして、夜昼、町の門を見守っていたのである。</span>
<span className="v" id="v25" data-v="25" data-xref="ヨシュア記 2:15; コリント人への第二の手紙 11:33; サムエル記上 19:11–12"> そこで彼の弟子たちが、夜の間に彼をかごに乗せて、町の城壁づたいにつりおろした。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="使徒行伝 26:20; ガラテヤ人への手紙 1:17–19; 使徒行伝 9:19"> サウロはエルサレムに着いて、弟子たちの仲間に加わろうと努めたが、みんなの者は彼を弟子だとは信じないで、恐れていた。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行伝 4:36; 使徒行伝 4:29; 使徒行伝 4:13"> ところが、バルナバは彼の世話をして使徒たちのところへ連れて行き、途中で主が彼に現れて語りかけたことや、彼がダマスコでイエスの名で大胆に宣べ伝えた次第を、彼らに説明して聞かせた。</span>
<span className="v" id="v28" data-v="28" data-xref="使徒行伝 1:21; 民数記 27:16–17; 詩篇 121:8"> それ以来、彼は使徒たちの仲間に加わり、エルサレムに出入りし、主の名によって大胆に語り、</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行伝 6:1; ユダの手紙 1:9; 使徒行伝 11:20"> ギリシヤ語を使うユダヤ人たちとしばしば語り合い、また論じ合った。しかし、彼らは彼を殺そうとねらっていた。</span>
<span className="v" id="v30" data-v="30" data-xref="使徒行伝 11:25; 使徒行伝 8:40; 使徒行伝 9:11"> 兄弟たちはそれと知って、彼をカイザリヤに連れてくだり、タルソへ送り出した。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="詩篇 111:10; ヨハネによる福音書 14:16–18; イザヤ書 33:6"> こうして教会は、ユダヤ、ガリラヤ、サマリヤ全地方にわたって平安を保ち、基礎がかたまり、主をおそれ聖霊にはげまされて歩み、次第に信徒の数を増して行った。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="使徒行伝 9:13; 使徒行伝 8:25; 箴言 2:8"> ペテロは方々をめぐり歩いたが、ルダに住む聖徒たちのところへも下って行った。</span>
<span className="v" id="v33" data-v="33" data-xref="ルカによる福音書 13:16; ヨハネによる福音書 5:5; マルコによる福音書 2:3–11"> そして、そこで、八年間も床についているアイネヤという人に会った。この人は中風であった。</span>
<span className="v" id="v34" data-v="34" data-xref="マタイによる福音書 9:6; 使徒行伝 3:12; 使徒行伝 3:6"> ペテロが彼に言った、「アイネヤよ、イエス・キリストがあなたをいやして下さるのだ。起きなさい。そして床を取りあげなさい」。すると、彼はただちに起きあがった。</span>
<span className="v" id="v35" data-v="35" data-xref="使徒行伝 11:21; 使徒行伝 9:42; 歴代志上 5:16"> ルダとサロンに住む人たちは、みなそれを見て、主に帰依した。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="テトスヘの手紙 3:8; テトスヘの手紙 2:7; 歴代志下 2:16"> ヨッパにタビタ（これを訳すと、ドルカス、すなわち、かもしか）という女弟子がいた。数々のよい働きや施しをしていた婦人であった。</span>
<span className="v" id="v37" data-v="37" data-xref="使徒行伝 1:13; 使徒行伝 20:8; ヨハネによる福音書 11:36–37"> ところが、そのころ病気になって死んだので、人々はそのからだを洗って、屋上の間に安置した。</span>
<span className="v" id="v38" data-v="38" data-xref="使徒行伝 9:36; 使徒行伝 11:26; 使徒行伝 9:32"> ルダはヨッパに近かったので、弟子たちはペテロがルダにきていると聞き、ふたりの者を彼のもとにやって、「どうぞ、早くこちらにおいで下さい」と頼んだ。</span>
<span className="v" id="v39" data-v="39" data-xref="箴言 10:7; 箴言 31:30–31; テサロニケ人への第一の手紙 1:3"> そこでペテロは立って、ふたりの者に連れられてきた。彼が着くとすぐ、屋上の間に案内された。すると、やもめたちがみんな彼のそばに寄ってきて、ドルカスが生前つくった下着や上着の数々を、泣きながら見せるのであった。</span>
<span className="v" id="v40" data-v="40" data-xref="マタイによる福音書 9:25; マルコによる福音書 5:40–42; ルカによる福音書 8:54"> ペテロはみんなの者を外に出し、ひざまずいて祈った。それから死体の方に向いて、「タビタよ、起きなさい」と言った。すると彼女は目をあけ、ペテロを見て起きなおった。</span>
<span className="v" id="v41" data-v="41" data-xref="マルコによる福音書 1:31; 使徒行伝 6:1; 創世記 45:26"> ペテロは彼女に手をかして立たせた。それから、聖徒たちや、やもめたちを呼び入れて、彼女が生きかえっているのを見せた。</span>
<span className="v" id="v42" data-v="42" data-xref="ヨハネによる福音書 12:44; ヨハネによる福音書 12:11; ヨハネによる福音書 11:45"> このことがヨッパ中に知れわたり、多くの人々が主を信じた。</span>
<span className="v" id="v43" data-v="43" data-xref="使徒行伝 10:6; 使徒行伝 10:32"> ペテロは、皮なめしシモンという人の家に泊まり、しばらくの間ヨッパに滞在した。</span>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ガラテヤ人への手紙 5:6; 使徒行伝 15:5; レビ記 12:3"> さて、ある人たちがユダヤから下ってきて、兄弟たちに「あなたがたも、モーセの慣例にしたがって割礼を受けなければ、救われない」と、説いていた。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行伝 15:22–23; 使徒行伝 15:6–7; ガラテヤ人への手紙 2:1–2"> そこで、パウロやバルナバと彼らとの間に、少なからぬ紛糾と争論とが生じたので、パウロ、バルナバそのほか数人の者がエルサレムに上り、使徒たちや長老たちと、この問題について協議することになった。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行伝 14:27; 使徒行伝 21:5; コリント人への第一の手紙 16:11"> 彼らは教会の人々に見送られ、ピニケ、サマリヤをとおって、道すがら、異邦人たちの改宗の模様をくわしく説明し、すべての兄弟たちを大いに喜ばせた。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行伝 14:27; 使徒行伝 15:12; 使徒行伝 15:3"> エルサレムに着くと、彼らは教会と使徒たち、長老たちに迎えられて、神が彼らと共にいてなされたことを、ことごとく報告した。</span>
<span className="v" id="v5" data-v="5" data-xref="ガラテヤ人への手紙 5:1–3; ピリピ人への手紙 3:5–8; 使徒行伝 15:1"> ところが、パリサイ派から信仰にはいってきた人たちが立って、「異邦人にも割礼を施し、またモーセの律法を守らせるべきである」と主張した。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="箴言 15:22; ヘブル人への手紙 13:7; ヘブル人への手紙 13:17"> そこで、使徒たちや長老たちが、この問題について審議するために集まった。</span>
<span className="v" id="v7" data-v="7" data-xref="ローマ人への手紙 10:17–18; ガラテヤ人への手紙 2:7–9; 歴代志上 28:4–5"> 激しい争論があった後、ペテロが立って言った、「兄弟たちよ、ご承知のとおり、異邦人がわたしの口から福音の言葉を聞いて信じるようにと、神は初めのころに、諸君の中からわたしをお選びになったのである。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行伝 1:24; 使徒行伝 10:47; 使徒行伝 14:3"> そして、人の心をご存じである神は、聖霊をわれわれに賜わったと同様に彼らにも賜わって、彼らに対してあかしをなし、</span>
<span className="v" id="v9" data-v="9" data-xref="エペソ人への手紙 3:6; ガラテヤ人への手紙 5:6; 使徒行伝 10:28"> また、その信仰によって彼らの心をきよめ、われわれと彼らとの間に、なんの分けへだてもなさらなかった。</span>
<span className="v" id="v10" data-v="10" data-xref="ガラテヤ人への手紙 5:1; マタイによる福音書 23:4; ガラテヤ人への手紙 4:9"> しかるに、諸君はなぜ、今われわれの先祖もわれわれ自身も、負いきれなかったくびきをあの弟子たちの首にかけて、神を試みるのか。</span>
<span className="v" id="v11" data-v="11" data-xref="ローマ人への手紙 3:24; テトスヘの手紙 3:4–7; テトスヘの手紙 2:11"> 確かに、主イエスのめぐみによって、われわれは救われるのだと信じるが、彼らとても同様である」。</span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="使徒行伝 14:27; 使徒行伝 15:4; 使徒行伝 21:19"> すると、全会衆は黙ってしまった。それから、バルナバとパウロとが、彼らをとおして異邦人の間に神が行われた数々のしるしと奇跡のことを、説明するのを聞いた。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行伝 12:17; ガラテヤ人への手紙 2:12; ヤコブの手紙 1:1"> ふたりが語り終えた後、ヤコブはそれに応じて述べた、「兄弟たちよ、わたしの意見を聞いていただきたい。</span>
<span className="v" id="v14" data-v="14" data-xref="ペテロの第二の手紙 1:1; 使徒行伝 15:7–9; ルカによる福音書 2:31–32"> 神が初めに異邦人たちを顧みて、その中から御名を負う民を選び出された次第は、シメオンがすでに説明した。</span>
<span className="v" id="v15" data-v="15" data-xref="ローマ人への手紙 15:8–12; 使徒行伝 13:47"> 預言者たちの言葉も、それと一致している。すなわち、こう書いてある、</span>
<span className="v" id="v16" data-v="16" data-xref="アモス書 9:11–12; 詩篇 89:35–49; ルカによる福音書 1:31–33"> <span className="pl pl-1">『その後、わたしは帰ってきて、</span><br /><span className="pl pl-1">倒れたダビデの幕屋を建てかえ、</span><br /><span className="pl pl-1">くずれた箇所を修理し、</span><br /><span className="pl pl-1">それを立て直そう。</span></span>
<span className="v" id="v17" data-v="17" data-xref="ゼカリヤ書 2:11; ゼカリヤ書 8:20–23; イザヤ書 65:1"> <span className="pl pl-1">残っている人々も、</span><br /><span className="pl pl-1">わたしの名を唱えているすべての異邦人も、</span><br /><span className="pl pl-1">主を尋ね求めるようになるためである。</span></span>
<span className="v" id="v18" data-v="18" data-xref="エペソ人への手紙 1:4; エペソ人への手紙 3:9; イザヤ書 46:9–10"> <span className="pl pl-1">世の初めからこれらの事を知らせておられる主が、こう仰せになった』。</span></span>
<span className="v" id="v19" data-v="19" data-xref="使徒行伝 15:28; ガラテヤ人への手紙 1:7–10; 使徒行伝 15:24"> <span className="pl pl-1">そこで、わたしの意見では、異邦人の中から神に帰依している人たちに、わずらいをかけてはいけない。</span></span>
<span className="v" id="v20" data-v="20" data-xref="使徒行伝 15:29; ヨハネの黙示録 2:20; レビ記 3:17"> <span className="pl pl-1">ただ、偶像に供えて汚れた物と、不品行と、絞め殺したものと、血とを、避けるようにと、彼らに書き送ることにしたい。</span></span>
<span className="v" id="v21" data-v="21" data-xref="使徒行伝 13:15; 使徒行伝 13:27; コリント人への第二の手紙 3:14–15"> <span className="pl pl-1">古い時代から、どの町にもモーセの律法を宣べ伝える者がいて、安息日ごとにそれを諸会堂で朗読するならわしであるから」。</span></span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="使徒行伝 15:27; 使徒行伝 15:40; テサロニケ人への第一の手紙 1:1"> そこで、使徒たちや長老たちは、全教会と協議した末、お互の中から人々を選んで、パウロやバルナバと共に、アンテオケに派遣することに決めた。選ばれたのは、バルサバというユダとシラスとであったが、いずれも兄弟たちの間で重んじられていた人たちであった。</span>
<span className="v" id="v23" data-v="23" data-xref="使徒行伝 23:26; ヤコブの手紙 1:1; ガラテヤ人への手紙 1:21"> この人たちに託された書面はこうである。<br />「あなたがたの兄弟である使徒および長老たちから、アンテオケ、シリヤ、キリキヤにいる異邦人の兄弟がたに、あいさつを送る。</span>
<span className="v" id="v24" data-v="24" data-xref="ガラテヤ人への手紙 5:12; ガラテヤ人への手紙 5:10; 使徒行伝 15:1"> こちらから行ったある者たちが、わたしたちからの指示もないのに、いろいろなことを言って、あなたがたを騒がせ、あなたがたの心を乱したと伝え聞いた。</span>
<span className="v" id="v25" data-v="25" data-xref="ペテロの第二の手紙 3:15; 使徒行伝 1:14; 使徒行伝 15:2"> そこで、わたしたちは人々を選んで、愛するバルナバおよびパウロと共に、あなたがたのもとに派遣することに、衆議一決した。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行伝 14:19; 使徒行伝 9:23–25; ピリピ人への手紙 2:29–30"> このふたりは、われらの主イエス・キリストの名のために、その命を投げ出した人々であるが、</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行伝 15:22; 使徒行伝 15:32; ヨハネの第三の手紙 1:13"> 彼らと共に、ユダとシラスとを派遣する次第である。この人たちは、あなたがたに、同じ趣旨のことを、口頭でも伝えるであろう。</span>
<span className="v" id="v28" data-v="28" data-xref="ヨハネによる福音書 16:13; ヨハネの黙示録 2:24; マタイによる福音書 11:30"> すなわち、聖霊とわたしたちとは、次の必要事項のほかは、どんな負担をも、あなたがたに負わせないことに決めた。</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行伝 15:20; 使徒行伝 21:25; ヨハネの黙示録 2:14"> それは、偶像に供えたものと、血と、絞め殺したものと、不品行とを、避けるということである。これらのものから遠ざかっておれば、それでよろしい。以上」。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="使徒行伝 16:4; 使徒行伝 6:2; 使徒行伝 23:33"> さて、一行は人々に見送られて、アンテオケに下って行き、会衆を集めて、その書面を手渡した。</span>
<span className="v" id="v31" data-v="31" data-xref="ガラテヤ人への手紙 2:4–5; ピリピ人への手紙 3:3; ガラテヤ人への手紙 5:1"> 人々はそれを読んで、その勧めの言葉をよろこんだ。</span>
<span className="v" id="v32" data-v="32" data-xref="使徒行伝 11:23; 使徒行伝 14:22; 使徒行伝 13:1"> ユダとシラスとは共に預言者であったので、多くの言葉をもって兄弟たちを励まし、また力づけた。</span>
<span className="v" id="v33" data-v="33" data-xref="コリント人への第一の手紙 16:11; 使徒行伝 16:36; ヘブル人への手紙 11:31"> ふたりは、しばらくの時を、そこで過ごした後、兄弟たちから、旅の平安を祈られて、見送りを受け、自分らを派遣した人々のところに帰って行った。〔</span>
<span className="v" id="v34" data-v="34"> しかし、シラスだけは、引きつづきとどまることにした。〕</span>
<span className="v" id="v35" data-v="35" data-xref="テモテヘの第二の手紙 4:2; コロサイ人への手紙 1:28; 使徒行伝 13:1"> パウロとバルナバとはアンテオケに滞在をつづけて、ほかの多くの人たちと共に、主の言葉を教えかつ宣べ伝えた。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="使徒行伝 14:6; 使徒行伝 13:4; 使徒行伝 13:51"> 幾日かの後、パウロはバルナバに言った、「さあ、前に主の言葉を伝えたすべての町々にいる兄弟たちを、また訪問して、みんながどうしているかを見てこようではないか」。</span>
<span className="v" id="v37" data-v="37" data-xref="使徒行伝 12:12; ピレモンヘの手紙 1:24; 使徒行伝 13:5"> そこで、バルナバはマルコというヨハネも一緒に連れて行くつもりでいた。</span>
<span className="v" id="v38" data-v="38" data-xref="使徒行伝 13:13; 箴言 25:19; ルカによる福音書 14:27–34"> しかし、パウロは、前にパンフリヤで一行から離れて、働きを共にしなかったような者は、連れて行かないがよいと考えた。</span>
<span className="v" id="v39" data-v="39" data-xref="コロサイ人への手紙 4:10; 伝道の書 7:20; 使徒行伝 4:36"> こうして激論が起り、その結果ふたりは互に別れ別れになり、バルナバはマルコを連れてクプロに渡って行き、</span>
<span className="v" id="v40" data-v="40" data-xref="使徒行伝 15:22; 使徒行伝 14:26; 使徒行伝 11:23"> パウロはシラスを選び、兄弟たちから主の恵みにゆだねられて、出発した。</span>
<span className="v" id="v41" data-v="41" data-xref="使徒行伝 15:23; ガラテヤ人への手紙 1:21; 使徒行伝 15:32"> そしてパウロは、シリヤ、キリキヤの地方をとおって、諸教会を力づけた。</span>
</div>

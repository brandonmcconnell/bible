<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行伝 24:11; 使徒行伝 23:2; 使徒行伝 25:2"> 五日の後、大祭司アナニヤは、長老数名と、テルトロという弁護人とを連れて下り、総督にパウロを訴え出た。</span>
<span className="v" id="v2" data-v="2" data-xref="箴言 29:5; 箴言 26:28; 使徒行伝 24:26–27"> パウロが呼び出されたので、テルトロは論告を始めた。<br />「ペリクス閣下、わたしたちが、閣下のお陰でじゅうぶんに平和を楽しみ、またこの国が、ご配慮によって、</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行伝 23:26; 使徒行伝 26:25; ルカによる福音書 1:3"> あらゆる方面に、またいたるところで改善されていることは、わたしたちの感謝してやまないところであります。</span>
<span className="v" id="v4" data-v="4" data-xref="ヘブル人への手紙 11:32"> しかし、ご迷惑をかけないように、くどくどと述べずに、手短かに申し上げますから、どうぞ、忍んでお聞き取りのほど、お願いいたします。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行伝 28:22; 使徒行伝 24:14; 使徒行伝 26:5"> さて、この男は、疫病のような人間で、世界中のすべてのユダヤ人の中に騒ぎを起している者であり、また、ナザレ人らの異端のかしらであります。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行伝 24:12; 使徒行伝 21:27–32; ヨハネによる福音書 18:31"> この者が宮までも汚そうとしていたので、わたしたちは彼を捕縛したのです。〔そして、律法にしたがって、さばこうとしていたところ、</span>
<span className="v" id="v7" data-v="7"> 千卒長ルシヤが干渉して、彼を無理にわたしたちの手から引き離してしまい、</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行伝 23:35; 使徒行伝 25:15–16; 使徒行伝 25:5"> 彼を訴えた人たちには、閣下のところに来るようにと命じました。〕それで、閣下ご自身でお調べになれば、わたしたちが彼を訴え出た理由が、全部おわかりになるでしょう」。</span>
<span className="v" id="v9" data-v="9" data-xref="テサロニケ人への第一の手紙 2:16; ミカ書 7:2–3; 詩篇 4:2"> ユダヤ人たちも、この訴えに同調して、全くそのとおりだと言った。</span>
<span className="v" id="v10" data-v="10" data-xref="ペテロの第一の手紙 3:15; サムエル記上 2:25; ルカによる福音書 18:2"> そこで、総督が合図をして発言を促したので、パウロは答弁して言った。<br />「閣下が、多年にわたり、この国民の裁判をつかさどっておられることを、よく承知していますので、わたしは喜んで、自分のことを弁明いたします。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行伝 24:1; 使徒行伝 21:18; 使徒行伝 23:11"> お調べになればわかるはずですが、わたしが礼拝をしにエルサレムに上ってから、まだ十二日そこそこにしかなりません。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行伝 25:8; 使徒行伝 28:17; 使徒行伝 24:18"> そして、宮の内でも、会堂内でも、あるいは市内でも、わたしがだれかと争論したり、群衆を煽動したりするのを見たものはありませんし、</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行伝 25:7; ペテロの第一の手紙 3:16"> 今わたしを訴え出ていることについて、閣下の前に、その証拠をあげうるものはありません。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行伝 9:2; ローマ人への手紙 3:21; 使徒行伝 3:13"> ただ、わたしはこの事は認めます。わたしは、彼らが異端だとしている道にしたがって、わたしたちの先祖の神に仕え、律法の教えるところ、また預言者の書に書いてあることを、ことごとく信じ、</span>
<span className="v" id="v15" data-v="15" data-xref="ダニエル書 12:2; ヨハネによる福音書 5:28–29; テサロニケ人への第一の手紙 4:14–16"> また、正しい者も正しくない者も、やがてよみがえるとの希望を、神を仰いでいだいているものです。この希望は、彼ら自身も持っているのです。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行伝 23:1; テモテヘの第一の手紙 1:5; コリント人への第二の手紙 4:2"> わたしはまた、神に対しまた人に対して、良心に責められることのないように、常に努めています。</span>
<span className="v" id="v17" data-v="17" data-xref="ガラテヤ人への手紙 2:10; ローマ人への手紙 15:25–28; コリント人への第一の手紙 16:1–4"> さてわたしは、幾年ぶりかに帰ってきて、同胞に施しをし、また、供え物をしていました。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行伝 26:21; 使徒行伝 21:26–30; 使徒行伝 24:12"> そのとき、彼らはわたしが宮できよめを行っているのを見ただけであって、群衆もいず、騒動もなかったのです。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行伝 23:30; 使徒行伝 25:16"> ところが、アジヤからきた数人のユダヤ人が――彼らが、わたしに対して、何かとがめ立てをすることがあったなら、よろしく閣下の前にきて、訴えるべきでした。</span>
<span className="v" id="v20" data-v="20"> あるいは、何かわたしに不正なことがあったなら、わたしが議会の前に立っていた時、彼らみずから、それを指摘すべきでした。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行伝 23:6; 使徒行伝 4:2; 使徒行伝 26:6–8"> ただ、わたしは、彼らの中に立って、『わたしは、死人のよみがえりのことで、きょう、あなたがたの前でさばきを受けているのだ』と叫んだだけのことです」。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="使徒行伝 24:6; 使徒行伝 24:24; 使徒行伝 25:26"> ここでペリクスは、この道のことを相当わきまえていたので、「千卒長ルシヤが下って来るのを待って、おまえたちの事件を判決することにする」と言って、裁判を延期した。</span>
<span className="v" id="v23" data-v="23" data-xref="使徒行伝 28:16; 使徒行伝 27:3; 箴言 16:7"> そして百卒長に、パウロを監禁するように、しかし彼を寛大に取り扱い、友人らが世話をするのを止めないようにと、命じた。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="使徒行伝 20:21; ガラテヤ人への手紙 2:16; マルコによる福音書 6:20"> 数日たってから、ペリクスは、ユダヤ人である妻ドルシラと一緒にきて、パウロを呼び出し、キリスト・イエスに対する信仰のことを、彼から聞いた。</span>
<span className="v" id="v25" data-v="25" data-xref="ヨハネによる福音書 16:8; ペテロの第一の手紙 3:15; 使徒行伝 10:42"> そこで、パウロが、正義、節制、未来の審判などについて論じていると、ペリクスは不安を感じてきて、言った、「きょうはこれで帰るがよい。また、よい機会を得たら、呼び出すことにする」。</span>
<span className="v" id="v26" data-v="26" data-xref="テモテヘの第一の手紙 6:9–10; 箴言 17:23; イザヤ書 56:11"> 彼は、それと同時に、パウロから金をもらいたい下ごころがあったので、たびたびパウロを呼び出しては語り合った。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="使徒行伝 25:9; 使徒行伝 25:14; 使徒行伝 12:3"> さて、二か年たった時、ポルキオ・フェストが、ペリクスと交代して任についた。ペリクスは、ユダヤ人の歓心を買おうと思って、パウロを監禁したままにしておいた。</span>
</div>

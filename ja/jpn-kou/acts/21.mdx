<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="テサロニケ人への第一の手紙 2:17; ルカによる福音書 5:4; サムエル記上 20:41–42"> さて、わたしたちは人々と別れて船出してから、コスに直航し、次の日はロドスに、そこからパタラに着いた。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨナ書 1:3; 使徒行伝 11:19; 使徒行伝 15:3"> ここでピニケ行きの舟を見つけたので、それに乗り込んで出帆した。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行伝 21:16; 使徒行伝 4:36; マタイによる福音書 4:24"> やがてクプロが見えてきたが、それを左手にして通りすぎ、シリヤへ航行をつづけ、ツロに入港した。ここで積荷が陸上げされることになっていたからである。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行伝 20:22–23; 使徒行伝 21:10–12; 使徒行伝 20:6–7"> わたしたちは、弟子たちを捜し出して、そこに七日間泊まった。ところが彼らは、御霊の示しを受けて、エルサレムには上って行かないようにと、しきりにパウロに注意した。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行伝 20:36; 使徒行伝 9:40; 詩篇 95:6"> しかし、滞在期間が終った時、わたしたちはまた旅立つことにしたので、みんなの者は、妻や子供を引き連れて、町はずれまで、わたしたちを見送りにきてくれた。そこで、共に海岸にひざまずいて祈り、</span>
<span className="v" id="v6" data-v="6" data-xref="ヨハネによる福音書 19:27; ヨハネによる福音書 1:11; コリント人への第二の手紙 2:13"> 互に別れを告げた。それから、わたしたちは舟に乗り込み、彼らはそれぞれ自分の家に帰った。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="ヘブル人への手紙 13:24; サムエル記上 10:4; 使徒行伝 28:12"> わたしたちは、ツロからの航行を終ってトレマイに着き、そこの兄弟たちにあいさつをし、彼らのところに一日滞在した。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行伝 6:5; 使徒行伝 8:26–40; エペソ人への手紙 4:11"> 翌日そこをたって、カイザリヤに着き、かの七人のひとりである伝道者ピリポの家に行き、そこに泊まった。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行伝 2:17; ヨハネの黙示録 2:20; ヨエル書 2:28"> この人に四人の娘があったが、いずれも処女であって、預言をしていた。</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行伝 11:28; 使徒行伝 21:4; 使徒行伝 20:16"> 幾日か滞在している間に、アガボという預言者がユダヤから下ってきた。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行伝 21:33; エレミヤ書 13:1–11; サムエル記上 15:27–28"> そして、わたしたちのところにきて、パウロの帯を取り、それで自分の手足を縛って言った、「聖霊がこうお告げになっている、『この帯の持ち主を、ユダヤ人たちがエルサレムでこのように縛って、異邦人の手に渡すであろう』」。</span>
<span className="v" id="v12" data-v="12" data-xref="マタイによる福音書 16:21–23; 使徒行伝 20:22; 使徒行伝 21:4"> わたしたちはこれを聞いて、土地の人たちと一緒になって、エルサレムには上って行かないようにと、パウロに願い続けた。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行伝 20:24; ピリピ人への手紙 2:17; ピリピ人への手紙 1:20–21"> その時パウロは答えた、「あなたがたは、泣いたり、わたしの心をくじいたりして、いったい、どうしようとするのか。わたしは、主イエスの名のためなら、エルサレムで縛られるだけでなく、死ぬことをも覚悟しているのだ」。</span>
<span className="v" id="v14" data-v="14" data-xref="ルカによる福音書 22:42; マタイによる福音書 26:42; マタイによる福音書 26:39"> こうして、パウロが勧告を聞きいれてくれないので、わたしたちは「主のみこころが行われますように」と言っただけで、それ以上、何も言わなかった。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="使徒行伝 25:1; 使徒行伝 25:6; 使徒行伝 25:9"> 数日後、わたしたちは旅装を整えてエルサレムへ上って行った。</span>
<span className="v" id="v16" data-v="16" data-xref="箴言 16:31; 使徒行伝 21:8; 詩篇 92:14"> カイザリヤの弟子たちも数人、わたしたちと同行して、古くからの弟子であるクプロ人マナソンの家に案内してくれた。わたしたちはその家に泊まることになっていたのである。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="使徒行伝 15:4; ローマ人への手紙 15:7; ヘブル人への手紙 13:1–2"> わたしたちがエルサレムに到着すると、兄弟たちは喜んで迎えてくれた。</span>
<span className="v" id="v18" data-v="18" data-xref="ガラテヤ人への手紙 1:19; ガラテヤ人への手紙 2:9; 使徒行伝 15:13"> 翌日パウロはわたしたちを連れて、ヤコブを訪問しに行った。そこに長老たちがみな集まっていた。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行伝 14:27; 使徒行伝 1:17; ローマ人への手紙 15:18–19"> パウロは彼らにあいさつをした後、神が自分の働きをとおして、異邦人の間になさった事どもを一々説明した。</span>
<span className="v" id="v20" data-v="20" data-xref="ローマ人への手紙 10:2; ガラテヤ人への手紙 1:14; 使徒行伝 22:3"> 一同はこれを聞いて神をほめたたえ、そして彼に言った、「兄弟よ、ご承知のように、ユダヤ人の中で信者になった者が、数万にものぼっているが、みんな律法に熱心な人たちである。</span>
<span className="v" id="v21" data-v="21" data-xref="ガラテヤ人への手紙 6:12–15; コリント人への第一の手紙 9:19–21; ガラテヤ人への手紙 5:1–6"> ところが、彼らが伝え聞いているところによれば、あなたは異邦人の中にいるユダヤ人一同に対して、子供に割礼を施すな、またユダヤの慣例にしたがうなと言って、モーセにそむくことを教えている、ということである。</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行伝 15:12; 使徒行伝 15:22; 使徒行伝 19:32"> どうしたらよいか。あなたがここにきていることは、彼らもきっと聞き込むに違いない。</span>
<span className="v" id="v23" data-v="23" data-xref="使徒行伝 18:18; 民数記 6:2–7"> ついては、今わたしたちが言うとおりのことをしなさい。わたしたちの中に、誓願を立てている者が四人いる。</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行伝 21:26; 使徒行伝 24:18; 使徒行伝 18:18"> この人たちを連れて行って、彼らと共にきよめを行い、また彼らの頭をそる費用を引き受けてやりなさい。そうすれば、あなたについて、うわさされていることは、根も葉もないことで、あなたは律法を守って、正しい生活をしていることが、みんなにわかるであろう。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行伝 15:29; 使徒行伝 15:19–20"> 異邦人で信者になった人たちには、すでに手紙で、偶像に供えたものと、血と、絞め殺したものと、不品行とを、慎むようにとの決議が、わたしたちから知らせてある」。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行伝 24:18; 使徒行伝 21:24; 民数記 6:13–20"> そこでパウロは、その次の日に四人の者を連れて、彼らと共にきよめを受けてから宮にはいった。そしてきよめの期間が終って、ひとりびとりのために供え物をささげる時を報告しておいた。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="使徒行伝 26:21; 使徒行伝 24:18; 使徒行伝 13:50"> 七日の期間が終ろうとしていた時、アジヤからきたユダヤ人たちが、宮の内でパウロを見かけて、群衆全体を煽動しはじめ、パウロに手をかけて叫び立てた、</span>
<span className="v" id="v28" data-v="28" data-xref="使徒行伝 24:5–6; 使徒行伝 21:21; 使徒行伝 26:20–21"> 「イスラエルの人々よ、加勢にきてくれ。この人は、いたるところで民と律法とこの場所にそむくことを、みんなに教えている。その上に、ギリシヤ人を宮の内に連れ込んで、この神聖な場所を汚したのだ」。</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行伝 20:4; テモテヘの第二の手紙 4:20; 使徒行伝 18:19"> 彼らは、前にエペソ人トロピモが、パウロと一緒に町を歩いていたのを見かけて、その人をパウロが宮の内に連れ込んだのだと思ったのである。</span>
<span className="v" id="v30" data-v="30" data-xref="使徒行伝 26:21; コリント人への第二の手紙 11:26; 使徒行伝 16:19–22"> そこで、市全体が騒ぎ出し、民衆が駆け集まってきて、パウロを捕え、宮の外に引きずり出した。そして、すぐそのあとに宮の門が閉ざされた。</span>
<span className="v" id="v31" data-v="31" data-xref="コリント人への第二の手紙 11:23–33; 使徒行伝 17:5; 使徒行伝 26:9–10"> 彼らがパウロを殺そうとしていた時に、エルサレム全体が混乱状態に陥っているとの情報が、守備隊の千卒長にとどいた。</span>
<span className="v" id="v32" data-v="32" data-xref="使徒行伝 23:27; イザヤ書 3:15; 使徒行伝 5:40"> そこで、彼はさっそく、兵卒や百卒長たちを率いて、その場に駆けつけた。人々は千卒長や兵卒たちを見て、パウロを打ちたたくのをやめた。</span>
<span className="v" id="v33" data-v="33" data-xref="エペソ人への手紙 6:20; 使徒行伝 21:11; 使徒行伝 20:23"> 千卒長は近寄ってきてパウロを捕え、彼を二重の鎖で縛っておくように命じた上、パウロは何者か、また何をしたのか、と尋ねた。</span>
<span className="v" id="v34" data-v="34" data-xref="使徒行伝 19:32; 使徒行伝 23:10; 使徒行伝 22:24"> しかし、群衆がそれぞれ違ったことを叫びつづけるため、騒がしくて、確かなことがわからないので、彼はパウロを兵営に連れて行くように命じた。</span>
<span className="v" id="v35" data-v="35" data-xref="ハバクク書 1:2–3; 詩篇 55:9; 詩篇 58:2"> パウロが階段にさしかかった時には、群衆の暴行を避けるため、兵卒たちにかつがれて行くという始末であった。</span>
<span className="v" id="v36" data-v="36" data-xref="ヨハネによる福音書 19:15; 使徒行伝 22:22; ルカによる福音書 23:18"> 大ぜいの民衆が「あれをやっつけてしまえ」と叫びながら、ついてきたからである。</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="使徒行伝 21:34; ルカによる福音書 21:15; 使徒行伝 19:30"> パウロが兵営の中に連れて行かれようとした時、千卒長に、「ひと言あなたにお話してもよろしいですか」と尋ねると、千卒長が言った、「おまえはギリシヤ語が話せるのか。</span>
<span className="v" id="v38" data-v="38" data-xref="マタイによる福音書 24:26; 使徒行伝 5:36–37; マタイによる福音書 5:11"> では、もしかおまえは、先ごろ反乱を起した後、四千人の刺客を引き連れて荒野へ逃げて行ったあのエジプト人ではないのか」。</span>
<span className="v" id="v39" data-v="39" data-xref="使徒行伝 22:3; 使徒行伝 9:11; 使徒行伝 23:27"> パウロは答えた、「わたしはタルソ生れのユダヤ人で、キリキヤのれっきとした都市の市民です。お願いですが、民衆に話をさせて下さい」。</span>
<span className="v" id="v40" data-v="40" data-xref="使徒行伝 12:17; 使徒行伝 22:2; ヨハネによる福音書 5:2"> 千卒長が許してくれたので、パウロは階段の上に立ち、民衆にむかって手を振った。すると、一同がすっかり静粛になったので、パウロはヘブル語で話し出した。</span>
</div>

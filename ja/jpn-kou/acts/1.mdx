<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ルカによる福音書 1:3; ルカによる福音書 24:19; マタイによる福音書 4:23–24"> テオピロよ、わたしは先に第一巻を著わして、イエスが行い、また教えはじめてから、</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行伝 1:9; ヨハネによる福音書 20:21; イザヤ書 59:20–21"> お選びになった使徒たちに、聖霊によって命じたのち、天に上げられた日までのことを、ことごとくしるした。</span>
<span className="v" id="v3" data-v="3" data-xref="コリント人への第一の手紙 15:5–7; 使徒行伝 13:31; ヨハネによる福音書 20:26"> イエスは苦難を受けたのち、自分の生きていることを数々の確かな証拠によって示し、四十日にわたってたびたび彼らに現れて、神の国のことを語られた。</span>
<span className="v" id="v4" data-v="4" data-xref="ルカによる福音書 24:49; ヨハネによる福音書 14:16; ヨハネによる福音書 15:26"> そして食事を共にしているとき、彼らにお命じになった、「エルサレムから離れないで、かねてわたしから聞いていた父の約束を待っているがよい。</span>
<span className="v" id="v5" data-v="5" data-xref="マタイによる福音書 3:11; 使徒行伝 11:15–16; ルカによる福音書 3:16"> すなわち、ヨハネは水でバプテスマを授けたが、あなたがたは間もなく聖霊によって、バプテスマを授けられるであろう」。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="ルカによる福音書 19:11; ルカによる福音書 17:20; ダニエル書 7:27"> さて、弟子たちが一緒に集まったとき、イエスに問うて言った、「主よ、イスラエルのために国を復興なさるのは、この時なのですか」。</span>
<span className="v" id="v7" data-v="7" data-xref="マタイによる福音書 24:36; テサロニケ人への第一の手紙 5:1–2; マルコによる福音書 13:32"> 彼らに言われた、「時期や場合は、父がご自分の権威によって定めておられるのであって、あなたがたの知る限りではない。</span>
<span className="v" id="v8" data-v="8" data-xref="マタイによる福音書 28:19; マルコによる福音書 16:15; ローマ人への手紙 15:19"> ただ、聖霊があなたがたにくだる時、あなたがたは力を受けて、エルサレム、ユダヤとサマリヤの全土、さらに地のはてまで、わたしの証人となるであろう」。</span>
<span className="v" id="v9" data-v="9" data-xref="ダニエル書 7:13; ルカによる福音書 24:50–51; マルコによる福音書 16:19"> こう言い終ると、イエスは彼らの見ている前で天に上げられ、雲に迎えられて、その姿が見えなくなった。</span>
<span className="v" id="v10" data-v="10" data-xref="ルカによる福音書 24:4; ヨハネによる福音書 20:12; ヨハネの黙示録 7:14"> イエスの上って行かれるとき、彼らが天を見つめていると、見よ、白い衣を着たふたりの人が、彼らのそばに立っていて</span>
<span className="v" id="v11" data-v="11" data-xref="ヨハネの黙示録 1:7; テサロニケ人への第一の手紙 4:16; マルコによる福音書 13:26"> 言った、「ガリラヤの人たちよ、なぜ天を仰いで立っているのか。あなたがたを離れて天に上げられたこのイエスは、天に上って行かれるのをあなたがたが見たのと同じ有様で、またおいでになるであろう」。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="ルカによる福音書 24:52; マタイによる福音書 21:1; ルカによる福音書 24:50"> それから彼らは、オリブという山を下ってエルサレムに帰った。この山はエルサレムに近く、安息日に許されている距離のところにある。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行伝 20:8; ルカによる福音書 22:12; マルコによる福音書 14:15"> 彼らは、市内に行って、その泊まっていた屋上の間にあがった。その人たちは、ペテロ、ヨハネ、ヤコブ、アンデレ、ピリポとトマス、バルトロマイとマタイ、アルパヨの子ヤコブと熱心党のシモンとヤコブの子ユダとであった。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行伝 6:4; エペソ人への手紙 6:18; コロサイ人への手紙 4:2"> 彼らはみな、婦人たち、特にイエスの母マリヤ、およびイエスの兄弟たちと共に、心を合わせて、ひたすら祈をしていた。</span>
</div>
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="コリント人への第一の手紙 15:6; 使徒行伝 21:20; ヨハネの黙示録 3:4"> そのころ、百二十名ばかりの人々が、一団となって集まっていたが、ペテロはこれらの兄弟たちの中に立って言った、</span>
<span className="v" id="v16" data-v="16" data-xref="詩篇 41:9; ヨハネによる福音書 13:18; 詩篇 55:12–15"> 「兄弟たちよ、イエスを捕えた者たちの手びきになったユダについては、聖霊がダビデの口をとおして預言したその言葉は、成就しなければならなかった。</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行伝 1:25; マルコによる福音書 3:19; ヨハネによる福音書 17:12"> 彼はわたしたちの仲間に加えられ、この務を授かっていた者であった。（</span>
<span className="v" id="v18" data-v="18" data-xref="マタイによる福音書 27:3–10; マタイによる福音書 26:14–15; 詩篇 55:23"> 彼は不義の報酬で、ある地所を手に入れたが、そこへまっさかさまに落ちて、腹がまん中から引き裂け、はらわたがみな流れ出てしまった。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行伝 2:22; マタイによる福音書 28:15; 使徒行伝 21:40"> そして、この事はエルサレムの全住民に知れわたり、そこで、この地所が彼らの国語でアケルダマと呼ばれるようになった。「血の地所」との意である。）</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 69:25; 詩篇 109:8–15; 使徒行伝 1:25"> 詩篇に、<br /><span className="pl pl-1">『その屋敷は荒れ果てよ、</span><br /><span className="pl pl-1">そこにはひとりも住む者がいなくなれ』</span><br />と書いてあり、また<br /><span className="pl pl-1">『その職は、ほかの者に取らせよ』</span><br />とあるとおりである。</span>
<span className="v" id="v21" data-v="21" data-xref="ヨハネによる福音書 15:27; ルカによる福音書 10:1–2; 民数記 27:17"> そういうわけで、主イエスがわたしたちの間にゆききされた期間中、</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行伝 1:2; 使徒行伝 4:33; 使徒行伝 1:8–9"> すなわち、ヨハネのバプテスマの時から始まって、わたしたちを離れて天に上げられた日に至るまで、始終わたしたちと行動を共にした人たちのうち、だれかひとりが、わたしたちに加わって主の復活の証人にならねばならない」。</span>
<span className="v" id="v23" data-v="23" data-xref="使徒行伝 15:22; 使徒行伝 1:26"> そこで一同は、バルサバと呼ばれ、またの名をユストというヨセフと、マッテヤとのふたりを立て、</span>
<span className="v" id="v24" data-v="24" data-xref="サムエル記上 16:7; 使徒行伝 15:8; ヘブル人への手紙 4:13"> 祈って言った、「すべての人の心をご存じである主よ。このふたりのうちのどちらを選んで、</span>
<span className="v" id="v25" data-v="25" data-xref="コリント人への第一の手紙 9:2; ヨハネによる福音書 6:70–71; ヨハネによる福音書 17:12"> ユダがこの使徒の職務から落ちて、自分の行くべきところへ行ったそのあとを継がせなさいますか、お示し下さい」。</span>
<span className="v" id="v26" data-v="26" data-xref="レビ記 16:8; ヨシュア記 18:10; サムエル記上 14:41–42"> それから、ふたりのためにくじを引いたところ、マッテヤに当ったので、この人が十一人の使徒たちに加えられることになった。</span>
</div>

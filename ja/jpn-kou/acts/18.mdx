<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="コリント人への第一の手紙 1:2; テモテヘの第二の手紙 4:20; コリント人への第二の手紙 1:1"> その後、パウロはアテネを去ってコリントへ行った。</span>
<span className="v" id="v2" data-v="2" data-xref="ローマ人への手紙 16:3–4; コリント人への第一の手紙 16:19; テモテヘの第二の手紙 4:19"> そこで、アクラというポント生れのユダヤ人と、その妻プリスキラとに出会った。クラウデオ帝が、すべてのユダヤ人をローマから退去させるようにと、命令したため、彼らは近ごろイタリヤから出てきたのである。</span>
<span className="v" id="v3" data-v="3" data-xref="コリント人への第一の手紙 4:12; テサロニケ人への第一の手紙 2:9; コリント人への第二の手紙 11:9"> パウロは彼らのところに行ったが、互に同業であったので、その家に住み込んで、一緒に仕事をした。天幕造りがその職業であった。</span>
<span className="v" id="v4" data-v="4" data-xref="コリント人への第二の手紙 5:11; 使徒行伝 17:17; 使徒行伝 28:23"> パウロは安息日ごとに会堂で論じては、ユダヤ人やギリシヤ人の説得に努めた。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="コリント人への第二の手紙 5:14; 使徒行伝 18:28; 使徒行伝 20:21"> シラスとテモテが、マケドニヤから下ってきてからは、パウロは御言を伝えることに専念し、イエスがキリストであることを、ユダヤ人たちに力強くあかしした。</span>
<span className="v" id="v6" data-v="6" data-xref="エゼキエル書 33:4; サムエル記下 1:16; エゼキエル書 33:8–9"> しかし、彼らがこれに反抗してののしり続けたので、パウロは自分の上着を振りはらって、彼らに言った、「あなたがたの血は、あなたがた自身にかえれ。わたしには責任がない。今からわたしは異邦人の方に行く」。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行伝 16:14; コロサイ人への手紙 4:11; 使徒行伝 10:2"> こう言って、彼はそこを去り、テテオ・ユストという神を敬う人の家に行った。その家は会堂と隣り合っていた。</span>
<span className="v" id="v8" data-v="8" data-xref="コリント人への第一の手紙 1:13–17; ローマ人への手紙 10:14–17; マルコによる福音書 16:15–16"> 会堂司クリスポは、その家族一同と共に主を信じた。また多くのコリント人も、パウロの話を聞いて信じ、ぞくぞくとバプテスマを受けた。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行伝 23:11; エペソ人への手紙 6:19–20; 使徒行伝 27:23–25"> すると、ある夜、幻のうちに主がパウロに言われた、「恐れるな。語りつづけよ、黙っているな。</span>
<span className="v" id="v10" data-v="10" data-xref="コリント人への第二の手紙 12:9; 出エジプト記 4:12; イザヤ書 41:10"> あなたには、わたしがついている。だれもあなたを襲って、危害を加えるようなことはない。この町には、わたしの民が大ぜいいる」。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行伝 14:3; 使徒行伝 19:10; 使徒行伝 20:31"> パウロは一年六か月の間ここに腰をすえて、神の言を彼らの間に教えつづけた。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="使徒行伝 13:50; 使徒行伝 18:27; 使徒行伝 13:7"> ところが、ガリオがアカヤの総督であった時、ユダヤ人たちは一緒になってパウロを襲い、彼を法廷にひっぱって行って訴えた、</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行伝 25:8; 使徒行伝 24:5–6; 使徒行伝 6:13"> 「この人は、律法にそむいて神を拝むように、人々をそそのかしています」。</span>
<span className="v" id="v14" data-v="14" data-xref="ペテロの第一の手紙 3:14–15; 使徒行伝 25:11; マルコによる福音書 9:19"> パウロが口を開こうとすると、ガリオはユダヤ人たちに言った、「ユダヤ人諸君、何か不法行為とか、悪質の犯罪とかのことなら、わたしは当然、諸君の訴えを取り上げもしようが、</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行伝 23:29; 使徒行伝 25:19; テモテヘの第一の手紙 6:4"> これは諸君の言葉や名称や律法に関する問題なのだから、諸君みずから始末するがよかろう。わたしはそんな事の裁判人にはなりたくない」。</span>
<span className="v" id="v16" data-v="16" data-xref="ヨハネの黙示録 12:16; 詩篇 76:10; ローマ人への手紙 13:3–4"> こう言って、彼らを法廷から追いはらった。</span>
<span className="v" id="v17" data-v="17" data-xref="コリント人への第一の手紙 1:1; アモス書 6:6; 使徒行伝 17:32"> そこで、みんなの者は、会堂司ソステネを引き捕え、法廷の前で打ちたたいた。ガリオはそれに対して、そ知らぬ顔をしていた。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="使徒行伝 21:24; 民数記 6:18; 民数記 6:5–9"> さてパウロは、なお幾日ものあいだ滞在した後、兄弟たちに別れを告げて、シリヤへ向け出帆した。プリスキラとアクラも同行した。パウロは、かねてから、ある誓願を立てていたので、ケンクレヤで頭をそった。</span>
<span className="v" id="v19" data-v="19" data-xref="エペソ人への手紙 1:1; テモテヘの第一の手紙 1:3; テモテヘの第二の手紙 1:18"> 一行がエペソに着くと、パウロはふたりをそこに残しておき、自分だけ会堂にはいって、ユダヤ人たちと論じた。</span>
<span className="v" id="v20" data-v="20" data-xref="マルコによる福音書 1:37–38; コリント人への第一の手紙 16:12; 使徒行伝 20:16"> 人々は、パウロにもっと長いあいだ滞在するように願ったが、彼は聞きいれないで、</span>
<span className="v" id="v21" data-v="21" data-xref="コリント人への第一の手紙 4:19; ヤコブの手紙 4:15; ローマ人への手紙 15:32"> 「神のみこころなら、またあなたがたのところに帰ってこよう」と言って、別れを告げ、エペソから船出した。</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行伝 8:40; 使徒行伝 15:4; 使徒行伝 23:23"> それから、カイザリヤで上陸してエルサレムに上り、教会にあいさつしてから、アンテオケに下って行った。</span>
<span className="v" id="v23" data-v="23" data-xref="使徒行伝 14:22; 使徒行伝 16:6; 使徒行伝 15:41"> そこにしばらくいてから、彼はまた出かけ、ガラテヤおよびフルギヤの地方を歴訪して、すべての弟子たちを力づけた。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="コリント人への第一の手紙 4:6; テトスヘの手紙 3:13; コリント人への第一の手紙 3:5–6"> さて、アレキサンデリヤ生れで、聖書に精通し、しかも、雄弁なアポロというユダヤ人が、エペソにきた。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行伝 19:3; ローマ人への手紙 12:11; ホセア書 14:9"> この人は主の道に通じており、また、霊に燃えてイエスのことを詳しく語ったり教えたりしていたが、ただヨハネのバプテスマしか知っていなかった。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行伝 18:25; 使徒行伝 14:3; コリント人への第一の手紙 12:21"> 彼は会堂で大胆に語り始めた。それをプリスキラとアクラとが聞いて、彼を招きいれ、さらに詳しく神の道を解き聞かせた。</span>
<span className="v" id="v27" data-v="27" data-xref="テサロニケ人への第二の手紙 2:13–14; ヤコブの手紙 1:16–18; ペテロの第一の手紙 1:2–3"> それから、アポロがアカヤに渡りたいと思っていたので、兄弟たちは彼を励まし、先方の弟子たちに、彼をよく迎えるようにと、手紙を書き送った。彼は到着して、すでにめぐみによって信者になっていた人たちに、大いに力になった。</span>
<span className="v" id="v28" data-v="28" data-xref="使徒行伝 18:5; コリント人への第一の手紙 15:3–4; 使徒行伝 9:22"> 彼はイエスがキリストであることを、聖書に基いて示し、公然と、ユダヤ人たちを激しい語調で論破したからである。</span>
</div>

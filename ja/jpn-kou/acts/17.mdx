<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="テサロニケ人への第一の手紙 1:1; ピリピ人への手紙 4:16; 使徒行伝 20:4"> 一行は、アムピポリスとアポロニヤとをとおって、テサロニケに行った。ここにはユダヤ人の会堂があった。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行伝 9:20; 使徒行伝 17:17; 使徒行伝 18:4"> パウロは例によって、その会堂にはいって行って、三つの安息日にわたり、聖書に基いて彼らと論じ、</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行伝 18:28; 使徒行伝 9:22; ルカによる福音書 24:32"> キリストは必ず苦難を受け、そして死人の中からよみがえるべきこと、また「わたしがあなたがたに伝えているこのイエスこそは、キリストである」とのことを、説明もし論証もした。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行伝 17:12; 使徒行伝 13:43; 使徒行伝 14:4"> ある人たちは納得がいって、パウロとシラスにしたがった。その中には、信心深いギリシヤ人が多数あり、貴婦人たちも少なくなかった。</span>
<span className="v" id="v5" data-v="5" data-xref="ガラテヤ人への手紙 5:26; 使徒行伝 17:13; ローマ人への手紙 16:21"> ところが、ユダヤ人たちは、それをねたんで、町をぶらついているならず者らを集めて暴動を起し、町を騒がせた。それからヤソンの家を襲い、ふたりを民衆の前にひっぱり出そうと、しきりに捜した。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行伝 24:5; 使徒行伝 16:19–21; 使徒行伝 28:22"> しかし、ふたりが見つからないので、ヤソンと兄弟たち数人を、市の当局者のところに引きずって行き、叫んで言った、「天下をかき回してきたこの人たちが、ここにもはいり込んでいます。</span>
<span className="v" id="v7" data-v="7" data-xref="ルカによる福音書 23:2; 使徒行伝 16:21; ヨハネによる福音書 19:12"> その人たちをヤソンが自分の家に迎え入れました。この連中は、みなカイザルの詔勅にそむいて行動し、イエスという別の王がいるなどと言っています」。</span>
<span className="v" id="v8" data-v="8" data-xref="マタイによる福音書 2:3; ヨハネによる福音書 11:48"> これを聞いて、群衆と市の当局者は不安に感じた。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行伝 17:5"> そして、ヤソンやほかの者たちから、保証金を取った上、彼らを釈放した。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="使徒行伝 17:2; テサロニケ人への第一の手紙 2:2; 使徒行伝 17:13–14"> そこで、兄弟たちはただちに、パウロとシラスとを、夜の間にベレヤへ送り出した。ふたりはベレヤに到着すると、ユダヤ人の会堂に行った。</span>
<span className="v" id="v11" data-v="11" data-xref="イザヤ書 34:16; 箴言 2:1–5; ヨハネによる福音書 5:39"> ここにいるユダヤ人はテサロニケの者たちよりも素直であって、心から教を受けいれ、果してそのとおりかどうかを知ろうとして、日々聖書を調べていた。</span>
<span className="v" id="v12" data-v="12" data-xref="エペソ人への手紙 5:14; 使徒行伝 14:1; 使徒行伝 13:50"> そういうわけで、彼らのうちの多くの者が信者になった。また、ギリシヤの貴婦人や男子で信じた者も、少なくなかった。</span>
<span className="v" id="v13" data-v="13" data-xref="テサロニケ人への第一の手紙 2:14–16; 箴言 28:25; 使徒行伝 6:12"> テサロニケのユダヤ人たちは、パウロがベレヤでも神の言を伝えていることを知り、そこにも押しかけてきて、群衆を煽動して騒がせた。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行伝 17:10; マタイによる福音書 10:23; 使徒行伝 9:25"> そこで、兄弟たちは、ただちにパウロを送り出して、海べまで行かせ、シラスとテモテとはベレヤに居残った。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行伝 18:5; テサロニケ人への第一の手紙 3:1; 使徒行伝 18:1"> パウロを案内した人たちは、彼をアテネまで連れて行き、テモテとシラスとになるべく早く来るようにとのパウロの伝言を受けて、帰った。</span>
</div>
<div className="bp poetry">
<span className="v" id="v16" data-v="16" data-xref="詩篇 119:158; ペテロの第二の手紙 2:7; 詩篇 119:136"> さて、パウロはアテネで彼らを待っている間に、市内に偶像がおびただしくあるのを見て、心に憤りを感じた。</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行伝 13:16; 使徒行伝 14:1–4; 使徒行伝 17:2–4"> そこで彼は、会堂ではユダヤ人や信心深い人たちと論じ、広場では毎日そこで出会う人々を相手に論じた。</span>
<span className="v" id="v18" data-v="18" data-xref="コリント人への第一の手紙 1:20–21; コロサイ人への手紙 2:8; ルカによる福音書 11:53"> また、エピクロス派やストア派の哲学者数人も、パウロと議論を戦わせていたが、その中のある者たちが言った、「このおしゃべりは、いったい、何を言おうとしているのか」。また、ほかの者たちは、「あれは、異国の神々を伝えようとしているらしい」と言った。パウロが、イエスと復活とを、宣べ伝えていたからであった。</span>
<span className="v" id="v19" data-v="19" data-xref="マルコによる福音書 1:27; 使徒行伝 17:22; 使徒行伝 24:24"> そこで、彼らはパウロをアレオパゴスの評議所に連れて行って、「君の語っている新しい教がどんなものか、知らせてもらえまいか。</span>
<span className="v" id="v20" data-v="20" data-xref="コリント人への第一の手紙 1:23; ホセア書 8:12; コリント人への第一の手紙 2:14"> 君がなんだか珍らしいことをわれわれに聞かせているので、それがなんの事なのか知りたいと思うのだ」と言った。</span>
<span className="v" id="v21" data-v="21" data-xref="テモテヘの第二の手紙 2:16–17; コロサイ人への手紙 4:5; エペソ人への手紙 5:16"> いったい、アテネ人もそこに滞在している外国人もみな、何か耳新しいことを話したり聞いたりすることのみに、時を過ごしていたのである。</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行伝 25:19; 使徒行伝 19:35; 使徒行伝 17:16"> そこでパウロは、アレオパゴスの評議所のまん中に立って言った。<br />「アテネの人たちよ、あなたがたは、あらゆる点において、すこぶる宗教心に富んでおられると、わたしは見ている。</span>
<span className="v" id="v23" data-v="23" data-xref="ヨハネによる福音書 4:22; ガラテヤ人への手紙 4:8–9; ヨハネによる福音書 17:3"> 実は、わたしが道を通りながら、あなたがたの拝むいろいろなものを、よく見ているうちに、『知られない神に』と刻まれた祭壇もあるのに気がついた。そこで、あなたがたが知らずに拝んでいるものを、いま知らせてあげよう。</span>
<span className="v" id="v24" data-v="24" data-xref="列王紀上 8:27; 申命記 10:14; 使徒行伝 7:48"> この世界と、その中にある万物とを造った神は、天地の主であるのだから、手で造った宮などにはお住みにならない。</span>
<span className="v" id="v25" data-v="25" data-xref="詩篇 50:8–13; 創世記 2:7; イザヤ書 42:5"> また、何か不足でもしておるかのように、人の手によって仕えられる必要もない。神は、すべての人々に命と息と万物とを与え、</span>
<span className="v" id="v26" data-v="26" data-xref="申命記 32:7–8; 創世記 3:20; ローマ人への手紙 5:12–19"> また、ひとりの人から、あらゆる民族を造り出して、地の全面に住まわせ、それぞれに時代を区分し、国土の境界を定めて下さったのである。</span>
<span className="v" id="v27" data-v="27" data-xref="エレミヤ書 23:23–24; 申命記 4:7; 使徒行伝 14:17"> こうして、人々が熱心に追い求めて捜しさえすれば、神を見いだせるようにして下さった。事実、神はわれわれひとりびとりから遠く離れておいでになるのではない。</span>
<span className="v" id="v28" data-v="28" data-xref="ヨブ記 12:10; コロサイ人への手紙 1:17; ヘブル人への手紙 1:3"> われわれは神のうちに生き、動き、存在しているからである。あなたがたのある詩人たちも言ったように、<br /><span className="pl pl-1">『われわれも、確かにその子孫である』。</span></span>
<span className="v" id="v29" data-v="29" data-xref="イザヤ書 40:25; 出エジプト記 20:4; 詩篇 115:4–8"> <span className="pl pl-1">このように、われわれは神の子孫なのであるから、神たる者を、人間の技巧や空想で金や銀や石などに彫り付けたものと同じと、見なすべきではない。</span></span>
<span className="v" id="v30" data-v="30" data-xref="使徒行伝 14:16; テトスヘの手紙 2:11–12; ルカによる福音書 24:47"> <span className="pl pl-1">神は、このような無知の時代を、これまでは見過ごしにされていたが、今はどこにおる人でも、みな悔い改めなければならないことを命じておられる。</span></span>
<span className="v" id="v31" data-v="31" data-xref="マタイによる福音書 25:31–46; ペテロの第二の手紙 3:7; ローマ人への手紙 2:16"> <span className="pl pl-1">神は、義をもってこの世界をさばくためその日を定め、お選びになったかたによってそれをなし遂げようとされている。すなわち、このかたを死人の中からよみがえらせ、その確証をすべての人に示されたのである」。</span></span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="使徒行伝 17:18; 使徒行伝 26:8; 使徒行伝 25:19"> 死人のよみがえりのことを聞くと、ある者たちはあざ笑い、またある者たちは、「この事については、いずれまた聞くことにする」と言った。</span>
<span className="v" id="v33" data-v="33"> こうして、パウロは彼らの中から出て行った。</span>
<span className="v" id="v34" data-v="34" data-xref="使徒行伝 17:19; ローマ人への手紙 11:5–6; 使徒行伝 13:48"> しかし、彼にしたがって信じた者も、幾人かあった。その中には、アレオパゴスの裁判人デオヌシオとダマリスという女、また、その他の人々もいた。</span>
</div>

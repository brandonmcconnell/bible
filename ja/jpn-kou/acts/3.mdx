<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="詩篇 55:17; 使徒行伝 10:3; 使徒行伝 4:13"> さて、ペテロとヨハネとが、午後三時の祈のときに宮に上ろうとしていると、</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行伝 14:8; ヨハネによる福音書 9:8; ルカによる福音書 16:20"> 生れながら足のきかない男が、かかえられてきた。この男は、宮もうでに来る人々に施しをこうため、毎日、「美しの門」と呼ばれる宮の門のところに、置かれていた者である。</span>
<span className="v" id="v3" data-v="3"> 彼は、ペテロとヨハネとが、宮にはいって行こうとしているのを見て、施しをこうた。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行伝 14:9–10; ヨハネによる福音書 11:40; ルカによる福音書 4:20"> ペテロとヨハネとは彼をじっと見て、「わたしたちを見なさい」と言った。</span>
<span className="v" id="v5" data-v="5"> 彼は何かもらえるのだろうと期待して、ふたりに注目していると、</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行伝 3:16; 使徒行伝 10:38; 使徒行伝 4:10"> ペテロが言った、「金銀はわたしには無い。しかし、わたしにあるものをあげよう。ナザレ人イエス・キリストの名によって歩きなさい」。</span>
<span className="v" id="v7" data-v="7" data-xref="マルコによる福音書 1:31; マルコによる福音書 9:27; 使徒行伝 9:41"> こう言って彼の右手を取って起してやると、足と、くるぶしとが、立ちどころに強くなって、</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行伝 14:10; イザヤ書 35:6; 詩篇 107:20–22"> 踊りあがって立ち、歩き出した。そして、歩き回ったり踊ったりして神をさんびしながら、彼らと共に宮にはいって行った。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行伝 4:21; 使徒行伝 4:16; ルカによる福音書 13:17"> 民衆はみな、彼が歩き回り、また神をさんびしているのを見、</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行伝 3:2; ヨハネによる福音書 5:20; ヨハネによる福音書 9:3"> これが宮の「美しの門」のそばにすわって、施しをこうていた者であると知り、彼の身に起ったことについて、驚き怪しんだ。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="使徒行伝 5:12; ヨハネによる福音書 10:23; ルカによる福音書 8:38"> 彼がなおもペテロとヨハネとにつきまとっているとき、人々は皆ひどく驚いて、「ソロモンの廊」と呼ばれる柱廊にいた彼らのところに駆け集まってきた。</span>
<span className="v" id="v12" data-v="12" data-xref="コリント人への第二の手紙 3:5; ヨハネによる福音書 3:27–28; ダニエル書 2:28–30"> ペテロはこれを見て、人々にむかって言った、「イスラエルの人たちよ、なぜこの事を不思議に思うのか。また、わたしたちが自分の力や信心で、あの人を歩かせたかのように、なぜわたしたちを見つめているのか。</span>
<span className="v" id="v13" data-v="13" data-xref="マタイによる福音書 22:32; 使徒行伝 7:32; マタイによる福音書 27:17–25"> アブラハム、イサク、ヤコブの神、わたしたちの先祖の神は、その僕イエスに栄光を賜わったのであるが、あなたがたは、このイエスを引き渡し、ピラトがゆるすことに決めていたのに、それを彼の面前で拒んだ。</span>
<span className="v" id="v14" data-v="14" data-xref="マルコによる福音書 1:24; 使徒行伝 7:52; ペテロの第一の手紙 3:18"> あなたがたは、この聖なる正しいかたを拒んで、人殺しの男をゆるすように要求し、</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行伝 2:24; ヨハネの黙示録 21:6; 使徒行伝 2:32"> いのちの君を殺してしまった。しかし、神はこのイエスを死人の中から、よみがえらせた。わたしたちは、その事の証人である。</span>
<span className="v" id="v16" data-v="16" data-xref="マタイによる福音書 21:21–22; 使徒行伝 4:10; 使徒行伝 14:9"> そして、イエスの名が、それを信じる信仰のゆえに、あなたがたのいま見て知っているこの人を、強くしたのであり、イエスによる信仰が、彼をあなたがた一同の前で、このとおり完全にいやしたのである。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="ルカによる福音書 23:34; 使徒行伝 13:27; ヨハネによる福音書 16:3"> さて、兄弟たちよ、あなたがたは知らずにあのような事をしたのであり、あなたがたの指導者たちとても同様であったことは、わたしにわかっている。</span>
<span className="v" id="v18" data-v="18" data-xref="イザヤ書 53:1–12; 使徒行伝 26:22–23; 使徒行伝 2:23"> 神はあらゆる預言者の口をとおして、キリストの受難を予告しておられたが、それをこのように成就なさったのである。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行伝 2:38; イザヤ書 44:22; イザヤ書 43:25"> だから、自分の罪をぬぐい去っていただくために、悔い改めて本心に立ちかえりなさい。</span>
<span className="v" id="v20" data-v="20" data-xref="マタイによる福音書 24:30–36; ヨハネの黙示録 19:11–16; テサロニケ人への第二の手紙 2:2"> それは、主のみ前から慰めの時がきて、あなたがたのためにあらかじめ定めてあったキリストなるイエスを、神がつかわして下さるためである。</span>
<span className="v" id="v21" data-v="21" data-xref="ローマ人への手紙 8:21; イザヤ書 1:26; 使徒行伝 1:11"> このイエスは、神が聖なる預言者たちの口をとおして、昔から預言しておられた万物更新の時まで、天にとどめておかれねばならなかった。</span>
<span className="v" id="v22" data-v="22" data-xref="申命記 18:15–19; 使徒行伝 7:37; ガラテヤ人への手紙 4:4"> モーセは言った、『主なる神は、わたしをお立てになったように、あなたがたの兄弟の中から、ひとりの預言者をお立てになるであろう。その預言者があなたがたに語ることには、ことごとく聞きしたがいなさい。</span>
<span className="v" id="v23" data-v="23" data-xref="申命記 18:19; ヨハネによる福音書 12:48; ヘブル人への手紙 10:28–30"> 彼に聞きしたがわない者は、みな民の中から滅ぼし去られるであろう』。</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行伝 3:21; ルカによる福音書 24:27; サムエル記上 3:20"> サムエルをはじめ、その後つづいて語ったほどの預言者はみな、この時のことを予告した。</span>
<span className="v" id="v25" data-v="25" data-xref="創世記 22:18; ガラテヤ人への手紙 3:8; 使徒行伝 2:39"> あなたがたは預言者の子であり、神があなたがたの先祖たちと結ばれた契約の子である。神はアブラハムに対して、『地上の諸民族は、あなたの子孫によって祝福を受けるであろう』と仰せられた。</span>
<span className="v" id="v26" data-v="26" data-xref="マタイによる福音書 1:21; 使徒行伝 3:22; ユダの手紙 1:24"> 神がまずあなたがたのために、その僕を立てて、おつかわしになったのは、あなたがたひとりびとりを、悪から立ちかえらせて、祝福にあずからせるためなのである」。</span>
</div>

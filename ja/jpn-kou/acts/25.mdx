<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行伝 23:34; 使徒行伝 25:5; 使徒行伝 8:40"> さて、フェストは、任地に着いてから三日の後、カイザリヤからエルサレムに上ったところ、</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行伝 25:15; 箴言 4:16; 使徒行伝 24:1"> 祭司長たちやユダヤ人の重立った者たちが、パウロを訴え出て、</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行伝 9:24; 使徒行伝 23:12–15; サムエル記上 23:19–21"> 彼をエルサレムに呼び出すよう取り計らっていただきたいと、しきりに願った。彼らは途中で待ち伏せして、彼を殺す考えであった。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行伝 24:23"> ところがフェストは、パウロがカイザリヤに監禁してあり、自分もすぐそこへ帰ることになっていると答え、</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行伝 25:25; ヨハネによる福音書 18:29–30; 使徒行伝 25:18–19"> そして言った、「では、もしあの男に何か不都合なことがあるなら、おまえたちのうちの有力者らが、わたしと一緒に下って行って、訴えるがよかろう」。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="使徒行伝 25:17; 使徒行伝 25:10; マタイによる福音書 27:19"> フェストは、彼らのあいだに八日か十日ほど滞在した後、カイザリヤに下って行き、その翌日、裁判の席について、パウロを引き出すように命じた。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行伝 24:13; ルカによる福音書 23:10; 使徒行伝 25:24"> パウロが姿をあらわすと、エルサレムから下ってきたユダヤ人たちが、彼を取りかこみ、彼に対してさまざまの重い罪状を申し立てたが、いずれもその証拠をあげることはできなかった。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行伝 24:12; 使徒行伝 28:17; コリント人への第二の手紙 1:12"> パウロは「わたしは、ユダヤ人の律法に対しても、宮に対しても、またカイザルに対しても、なんら罪を犯したことはない」と弁明した。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行伝 24:27; 使徒行伝 12:3; 使徒行伝 25:20"> ところが、フェストはユダヤ人の歓心を買おうと思って、パウロにむかって言った、「おまえはエルサレムに上り、この事件に関し、わたしからそこで裁判を受けることを承知するか」。</span>
<span className="v" id="v10" data-v="10" data-xref="マタイによる福音書 27:18; コリント人への第二の手紙 4:2; 使徒行伝 28:18"> パウロは言った、「わたしは今、カイザルの法廷に立っています。わたしはこの法廷で裁判されるべきです。よくご承知のとおり、わたしはユダヤ人たちに、何も悪いことをしてはいません。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行伝 28:19; 使徒行伝 26:32; 使徒行伝 25:25"> もしわたしが悪いことをし、死に当るようなことをしているのなら、死を免れようとはしません。しかし、もし彼らの訴えることに、なんの根拠もないとすれば、だれもわたしを彼らに引き渡す権利はありません。わたしはカイザルに上訴します」。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行伝 19:21; ピリピ人への手紙 1:12–14; ピリピ人への手紙 1:20"> そこでフェストは、陪席の者たちと協議したうえ答えた、「おまえはカイザルに上訴を申し出た。カイザルのところに行くがよい」。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="使徒行伝 8:40; 使徒行伝 26:1; 使徒行伝 26:27–28"> 数日たった後、アグリッパ王とベルニケとが、フェストに敬意を表するため、カイザリヤにきた。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行伝 24:27"> ふたりは、そこに何日間も滞在していたので、フェストは、パウロのことを王に話して言った、「ここに、ペリクスが囚人として残して行ったひとりの男がいる。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行伝 25:1–3; エステル記 3:9; ルカによる福音書 18:3–5"> わたしがエルサレムに行った時、この男のことを、祭司長たちやユダヤ人の長老たちが、わたしに報告し、彼を罪に定めるようにと要求した。</span>
<span className="v" id="v16" data-v="16" data-xref="ヨハネによる福音書 7:51; 申命記 19:17–18; 使徒行伝 23:30"> そこでわたしは、彼らに答えた、『訴えられた者が、訴えた者の前に立って、告訴に対し弁明する機会を与えられない前に、その人を見放してしまうのは、ローマ人の慣例にはないことである』。</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行伝 25:6; 使徒行伝 25:10"> それで、彼らがここに集まってきた時、わたしは時をうつさず、次の日に裁判の席について、その男を引き出させた。</span>
<span className="v" id="v18" data-v="18"> 訴えた者たちは立ち上がったが、わたしが推測していたような悪事は、彼について何一つ申し立てはしなかった。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行伝 23:29; 使徒行伝 18:15; コリント人への第一の手紙 15:3–4"> ただ、彼と争い合っているのは、彼ら自身の宗教に関し、また、死んでしまったのに生きているとパウロが主張しているイエスなる者に関する問題に過ぎない。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行伝 25:9"> これらの問題を、どう取り扱ってよいかわからなかったので、わたしは彼に、『エルサレムに行って、これらの問題について、そこでさばいてもらいたくはないか』と尋ねてみた。</span>
<span className="v" id="v21" data-v="21" data-xref="テモテヘの第二の手紙 4:16; ルカによる福音書 2:1; 使徒行伝 25:10–11"> ところがパウロは、皇帝の判決を受ける時まで、このまま自分をとどめておいてほしいと言うので、カイザルに彼を送りとどける時までとどめておくようにと、命じておいた」。</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行伝 9:15; マタイによる福音書 10:18; イザヤ書 52:15"> そこで、アグリッパがフェストに「わたしも、その人の言い分を聞いて見たい」と言ったので、フェストは、「では、あす彼から聞きとるようにしてあげよう」と答えた。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="使徒行伝 26:30; 使徒行伝 25:13; ヨハネの第一の手紙 2:16"> 翌日、アグリッパとベルニケとは、大いに威儀をととのえて、千卒長たちや市の重立った人たちと共に、引見所にはいってきた。すると、フェストの命によって、パウロがそこに引き出された。</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行伝 22:22; 使徒行伝 25:7; 使徒行伝 25:2–3"> そこで、フェストが言った、「アグリッパ王、ならびにご臨席の諸君。ごらんになっているこの人物は、ユダヤ人たちがこぞって、エルサレムにおいても、また、この地においても、これ以上、生かしておくべきでないと叫んで、わたしに訴え出ている者である。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行伝 23:29; 使徒行伝 25:11–12; ルカによる福音書 23:4"> しかし、彼は死に当ることは何もしていないと、わたしは見ているのだが、彼自身が皇帝に上訴すると言い出したので、彼をそちらへ送ることに決めた。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行伝 26:2–3"> ところが、彼について、主君に書きおくる確かなものが何もないので、わたしは、彼を諸君の前に、特に、アグリッパ王よ、あなたの前に引き出して、取調べをしたのち、上書すべき材料を得ようと思う。</span>
<span className="v" id="v27" data-v="27" data-xref="ヨハネによる福音書 7:51; 箴言 18:13"> 囚人を送るのに、その告訴の理由を示さないということは、不合理だと思えるからである」。</span>
</div>

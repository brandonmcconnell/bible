<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行伝 22:20; ダニエル書 3:16–18; 使徒行伝 5:40"> サウロは、ステパノを殺すことに賛成していた。<br />その日、エルサレムの教会に対して大迫害が起り、使徒以外の者はことごとく、ユダヤとサマリヤとの地方に散らされて行った。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 50:10–11; 創世記 23:2; エレミヤ書 22:18"> 信仰深い人たちはステパノを葬り、彼のために胸を打って、非常に悲しんだ。</span>
<span className="v" id="v3" data-v="3" data-xref="テモテヘの第一の手紙 1:13; ガラテヤ人への手紙 1:13; コリント人への第一の手紙 15:9"> ところが、サウロは家々に押し入って、男や女を引きずり出し、次々に獄に渡して、教会を荒し回った。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="マタイによる福音書 10:23; 使徒行伝 11:19; 使徒行伝 8:1"> さて、散らされて行った人たちは、御言を宣べ伝えながら、めぐり歩いた。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行伝 6:5; 使徒行伝 21:8; 使徒行伝 8:35–36"> ピリポはサマリヤの町に下って行き、人々にキリストを宣べはじめた。</span>
<span className="v" id="v6" data-v="6" data-xref="ヨハネによる福音書 4:41–42; 歴代志下 30:12; マタイによる福音書 20:15–16"> 群衆はピリポの話を聞き、その行っていたしるしを見て、こぞって彼の語ることに耳を傾けた。</span>
<span className="v" id="v7" data-v="7" data-xref="マタイによる福音書 10:1; 使徒行伝 14:8–10; マルコによる福音書 16:17–18"> 汚れた霊につかれた多くの人々からは、その霊が大声でわめきながら出て行くし、また、多くの中風をわずらっている者や、足のきかない者がいやされたからである。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行伝 13:52; 使徒行伝 13:48; 使徒行伝 8:39"> それで、この町では人々が、大変なよろこびかたであった。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="使徒行伝 13:6; 使徒行伝 5:36; ヨハネによる福音書 7:18"> さて、この町に以前からシモンという人がいた。彼は魔術を行ってサマリヤの人たちを驚かし、自分をさも偉い者のように言いふらしていた。</span>
<span className="v" id="v10" data-v="10" data-xref="エレミヤ書 31:34; ペテロの第二の手紙 2:2; ヨハネの黙示録 13:3"> それで、小さい者から大きい者にいたるまで皆、彼について行き、「この人こそは『大能』と呼ばれる神の力である」と言っていた。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行伝 8:9; ガラテヤ人への手紙 3:1; イザヤ書 44:25"> 彼らがこの人について行ったのは、ながい間その魔術に驚かされていたためであった。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行伝 2:38; 使徒行伝 1:3; マタイによる福音書 28:19"> ところが、ピリポが神の国とイエス・キリストの名について宣べ伝えるに及んで、男も女も信じて、ぞくぞくとバプテスマを受けた。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行伝 8:6–7; ヨハネによる福音書 5:20; 使徒行伝 19:11"> シモン自身も信じて、バプテスマを受け、それから、引きつづきピリポについて行った。そして、数々のしるしやめざましい奇跡が行われるのを見て、驚いていた。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="テサロニケ人への第一の手紙 2:13; テサロニケ人への第一の手紙 3:2; ガラテヤ人への手紙 2:9"> エルサレムにいる使徒たちは、サマリヤの人々が、神の言を受け入れたと聞いて、ペテロとヨハネとを、そこにつかわした。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行伝 2:38; ヨハネによる福音書 16:23–24; ヨハネによる福音書 14:13–14"> ふたりはサマリヤに下って行って、みんなが聖霊を受けるようにと、彼らのために祈った。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行伝 2:38; 使徒行伝 19:2; マタイによる福音書 28:19"> それは、彼らはただ主イエスの名によってバプテスマを受けていただけで、聖霊はまだだれにも下っていなかったからである。</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行伝 19:6; 使徒行伝 6:6; テモテヘの第二の手紙 1:6"> そこで、ふたりが手を彼らの上においたところ、彼らは聖霊を受けた。</span>
<span className="v" id="v18" data-v="18" data-xref="テモテヘの第一の手紙 6:5; マタイによる福音書 10:8; 列王紀下 8:9"> シモンは、使徒たちが手をおいたために、御霊が人々に授けられたのを見て、金をさし出し、</span>
<span className="v" id="v19" data-v="19" data-xref="ルカによる福音書 14:7–11; ヨハネの第三の手紙 1:9; ヨハネによる福音書 5:44"> 「わたしが手をおけばだれにでも聖霊が授けられるように、その力をわたしにも下さい」と言った。</span>
<span className="v" id="v20" data-v="20" data-xref="ダニエル書 5:17; マタイによる福音書 10:8; 使徒行伝 2:38"> そこで、ペテロが彼に言った、「おまえの金は、おまえもろとも、うせてしまえ。神の賜物が、金で得られるなどと思っているのか。</span>
<span className="v" id="v21" data-v="21" data-xref="ヘブル人への手紙 4:13; 詩篇 36:1; マタイによる福音書 6:22–24"> おまえの心が神の前に正しくないから、おまえは、とうてい、この事にあずかることができない。</span>
<span className="v" id="v22" data-v="22" data-xref="テモテヘの第二の手紙 2:25–26; ダニエル書 4:27; ヘブル人への手紙 4:12"> だから、この悪事を悔いて、主に祈れ。そうすればあるいはそんな思いを心にいだいたことが、ゆるされるかも知れない。</span>
<span className="v" id="v23" data-v="23" data-xref="イザヤ書 58:6; 箴言 5:22; ヨハネによる福音書 8:34"> おまえには、まだ苦い胆汁があり、不義のなわ目がからみついている。それが、わたしにわかっている」。</span>
<span className="v" id="v24" data-v="24" data-xref="出エジプト記 8:8; 民数記 21:7; ヨブ記 42:8"> シモンはこれを聞いて言った、「仰せのような事が、わたしの身に起らないように、どうぞ、わたしのために主に祈って下さい」。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="使徒行伝 20:21; 使徒行伝 26:22–23; 使徒行伝 1:8"> 使徒たちは力強くあかしをなし、また主の言を語った後、サマリヤ人の多くの村々に福音を宣べ伝えて、エルサレムに帰った。</span>
</div>
<div className="bp poetry">
<span className="v" id="v26" data-v="26" data-xref="使徒行伝 5:19; ヘブル人への手紙 1:14; 列王紀下 1:3"> しかし、主の使がピリポにむかって言った、「立って南方に行き、エルサレムからガザへ下る道に出なさい」（このガザは、今は荒れはてている）。</span>
<span className="v" id="v27" data-v="27" data-xref="ゼパニヤ書 3:10; 詩篇 68:31; イザヤ書 56:3–8"> そこで、彼は立って出かけた。すると、ちょうど、エチオピヤ人の女王カンダケの高官で、女王の財宝全部を管理していた宦官であるエチオピヤ人が、礼拝のためエルサレムに上り、</span>
<span className="v" id="v28" data-v="28" data-xref="コロサイ人への手紙 3:16; イザヤ書 1:1; 使徒行伝 28:25"> その帰途についていたところであった。彼は自分の馬車に乗って、預言者イザヤの書を読んでいた。</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行伝 10:19; 使徒行伝 11:12; 使徒行伝 20:22–23"> 御霊がピリポに「進み寄って、あの馬車に並んで行きなさい」と言った。</span>
<span className="v" id="v30" data-v="30" data-xref="ルカによる福音書 24:44–45; ヨハネによる福音書 5:39; エペソ人への手紙 5:17"> そこでピリポが駆けて行くと、預言者イザヤの書を読んでいるその人の声が聞えたので、「あなたは、読んでいることが、おわかりですか」と尋ねた。</span>
<span className="v" id="v31" data-v="31" data-xref="ローマ人への手紙 10:14; 詩篇 73:16–17; イザヤ書 29:18–19"> 彼は「だれかが、手びきをしてくれなければ、どうしてわかりましょう」と答えた。そして、馬車に乗って一緒にすわるようにと、ピリポにすすめた。</span>
<span className="v" id="v32" data-v="32" data-xref="イザヤ書 53:7–8; ペテロの第一の手紙 2:21–24; エレミヤ書 51:40"> 彼が読んでいた聖書の箇所は、これであった、<br /><span className="pl pl-1">「彼は、ほふり場に引かれて行く羊のように、</span><br /><span className="pl pl-1">また、黙々として、</span><br /><span className="pl pl-1">毛を刈る者の前に立つ小羊のように、</span><br /><span className="pl pl-1">口を開かない。</span></span>
<span className="v" id="v33" data-v="33" data-xref="イザヤ書 53:12; イザヤ書 53:8; ゼカリヤ書 13:7"> <span className="pl pl-1">彼は、いやしめられて、</span><br /><span className="pl pl-1">そのさばきも行われなかった。</span><br /><span className="pl pl-1">だれが、彼の子孫のことを語ることができようか、</span><br /><span className="pl pl-1">彼の命が地上から取り去られているからには」。</span></span>
<span className="v" id="v34" data-v="34" data-xref="マタイによる福音書 15:15; マタイによる福音書 13:36; マタイによる福音書 2:2–4"> <span className="pl pl-1">宦官はピリポにむかって言った、「お尋ねしますが、ここで預言者はだれのことを言っているのですか。自分のことですか、それとも、だれかほかの人のことですか」。</span></span>
<span className="v" id="v35" data-v="35" data-xref="ルカによる福音書 24:27; 使徒行伝 18:28; 使徒行伝 28:23"> <span className="pl pl-1">そこでピリポは口を開き、この聖句から説き起して、イエスのことを宣べ伝えた。</span></span>
<span className="v" id="v36" data-v="36" data-xref="使徒行伝 10:47; ヨハネによる福音書 3:5; テトスヘの手紙 3:5–6"> <span className="pl pl-1">道を進んで行くうちに、水のある所にきたので、宦官が言った、「ここに水があります。わたしがバプテスマを受けるのに、なんのさしつかえがありますか」。〔</span></span>
<span className="v" id="v37" data-v="37"> <span className="pl pl-1">これに対して、ピリポは、「あなたがまごころから信じるなら、受けてさしつかえはありません」と言った。すると、彼は「わたしは、イエス・キリストを神の子と信じます」と答えた。〕</span></span>
<span className="v" id="v38" data-v="38" data-xref="ヨハネによる福音書 4:1; ヨハネによる福音書 3:22–23"> <span className="pl pl-1">そこで車をとめさせ、ピリポと宦官と、ふたりとも、水の中に降りて行き、ピリポが宦官にバプテスマを授けた。</span></span>
<span className="v" id="v39" data-v="39" data-xref="列王紀上 18:12; 列王紀下 2:16; エゼキエル書 8:3"> <span className="pl pl-1">ふたりが水から上がると、主の霊がピリポをさらって行ったので、宦官はもう彼を見ることができなかった。宦官はよろこびながら旅をつづけた。</span></span>
<span className="v" id="v40" data-v="40" data-xref="使徒行伝 21:8; 使徒行伝 23:23; 使徒行伝 23:33"> <span className="pl pl-1">その後、ピリポはアゾトに姿をあらわして、町々をめぐり歩き、いたるところで福音を宣べ伝えて、ついにカイザリヤに着いた。</span></span>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="詩篇 22:27; マラキ書 1:11; イザヤ書 32:15"> さて、異邦人たちも神の言を受けいれたということが、使徒たちやユダヤにいる兄弟たちに聞えてきた。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行伝 10:45; 使徒行伝 10:9; 使徒行伝 15:1"> そこでペテロがエルサレムに上ったとき、割礼を重んじる者たちが彼をとがめて言った、</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行伝 10:28; ガラテヤ人への手紙 2:12; ルカによる福音書 15:2"> 「あなたは、割礼のない人たちのところに行って、食事を共にしたということだが」。</span>
<span className="v" id="v4" data-v="4" data-xref="ルカによる福音書 1:3; 使徒行伝 14:27; ヨシュア記 22:21–31"> そこでペテロは口を開いて、順序正しく説明して言った、</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行伝 10:9–32; 使徒行伝 9:10; 使徒行伝 22:17"> 「わたしがヨッパの町で祈っていると、夢心地になって幻を見た。大きな布のような入れ物が、四すみをつるされて、天から降りてきて、わたしのところにとどいた。</span>
<span className="v" id="v6" data-v="6" data-xref="ルカによる福音書 4:20; 使徒行伝 3:4"> 注意して見つめていると、地上の四つ足、野の獣、這うもの、空の鳥などが、はいっていた。</span>
<span className="v" id="v7" data-v="7"> それから声がして、『ペテロよ、立って、それらをほふって食べなさい』と、わたしに言うのが聞えた。</span>
<span className="v" id="v8" data-v="8" data-xref="ローマ人への手紙 14:14; ホセア書 9:3; コリント人への第一の手紙 7:14"> わたしは言った、『主よ、それはできません。わたしは今までに、清くないものや汚れたものを口に入れたことが一度もございません』。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行伝 15:9; ヘブル人への手紙 9:13–14; 使徒行伝 10:34–35"> すると、二度目に天から声がかかってきた、『神がきよめたものを、清くないなどと言ってはならない』。</span>
<span className="v" id="v10" data-v="10" data-xref="ヨハネによる福音書 21:17; 民数記 24:10; コリント人への第二の手紙 12:8"> こんなことが三度もあってから、全部のものがまた天に引き上げられてしまった。</span>
<span className="v" id="v11" data-v="11" data-xref="出エジプト記 4:27; 使徒行伝 9:10–12; 出エジプト記 4:14"> ちょうどその時、カイザリヤからつかわされてきた三人の人が、わたしたちの泊まっていた家に着いた。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行伝 8:29; ローマ人への手紙 3:22; テサロニケ人への第二の手紙 2:2"> 御霊がわたしに、ためらわずに彼らと共に行けと言ったので、ここにいる六人の兄弟たちも、わたしと一緒に出かけて行き、一同がその人の家にはいった。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行伝 10:30–32; 使徒行伝 10:3–6; 使徒行伝 9:43"> すると彼はわたしたちに、御使が彼の家に現れて、『ヨッパに人をやって、ペテロと呼ばれるシモンを招きなさい。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行伝 16:15; 使徒行伝 10:22; 使徒行伝 16:31–34"> この人は、あなたとあなたの全家族とが救われる言葉を語って下さるであろう』と告げた次第を、話してくれた。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行伝 19:6; 使徒行伝 10:34–46; 使徒行伝 2:2–12"> そこでわたしが語り出したところ、聖霊が、ちょうど最初わたしたちの上にくだったと同じように、彼らの上にくだった。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行伝 1:5; マルコによる福音書 1:8; 箴言 1:23"> その時わたしは、主が『ヨハネは水でバプテスマを授けたが、あなたがたは聖霊によってバプテスマを受けるであろう』と仰せになった言葉を思い出した。</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行伝 10:47; ローマ人への手紙 9:20–26; ダニエル書 4:35"> このように、わたしたちが主イエス・キリストを信じた時に下さったのと同じ賜物を、神が彼らにもお与えになったとすれば、わたしのような者が、どうして神を妨げることができようか」。</span>
<span className="v" id="v18" data-v="18" data-xref="ローマ人への手紙 10:12–13; コリント人への第二の手紙 7:10; エゼキエル書 36:26"> 人々はこれを聞いて黙ってしまった。それから神をさんびして、「それでは神は、異邦人にも命にいたる悔改めをお与えになったのだ」と言った。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="使徒行伝 4:36; 使徒行伝 21:2; 使徒行伝 15:3"> さて、ステパノのことで起った迫害のために散らされた人々は、ピニケ、クプロ、アンテオケまでも進んで行ったが、ユダヤ人以外の者には、だれにも御言を語っていなかった。</span>
<span className="v" id="v20" data-v="20" data-xref="マタイによる福音書 27:32; 使徒行伝 13:1; コリント人への第一の手紙 1:23–24"> ところが、その中に数人のクプロ人とクレネ人がいて、アンテオケに行ってからギリシヤ人にも呼びかけ、主イエスを宣べ伝えていた。</span>
<span className="v" id="v21" data-v="21" data-xref="ルカによる福音書 1:66; 使徒行伝 2:47; 使徒行伝 5:14"> そして、主のみ手が彼らと共にあったため、信じて主に帰依するものの数が多かった。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="使徒行伝 9:27; 使徒行伝 8:14; 使徒行伝 13:1–3"> このうわさがエルサレムにある教会に伝わってきたので、教会はバルナバをアンテオケにつかわした。</span>
<span className="v" id="v23" data-v="23" data-xref="コリント人への第一の手紙 15:58; 使徒行伝 14:22; 使徒行伝 13:43"> 彼は、そこに着いて、神のめぐみを見てよろこび、主に対する信仰を揺るがない心で持ちつづけるようにと、みんなの者を励ました。</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行伝 11:21; 使徒行伝 5:14; 使徒行伝 9:31"> 彼は聖霊と信仰とに満ちた立派な人であったからである。こうして主に加わる人々が、大ぜいになった。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行伝 9:11; 使徒行伝 9:27; 使徒行伝 9:30"> そこでバルナバはサウロを捜しにタルソへ出かけて行き、</span>
<span className="v" id="v26" data-v="26" data-xref="ペテロの第一の手紙 4:16; 使徒行伝 26:28; ペテロの第一の手紙 4:14"> 彼を見つけたうえ、アンテオケに連れて帰った。ふたりは、まる一年、ともどもに教会で集まりをし、大ぜいの人々を教えた。このアンテオケで初めて、弟子たちがクリスチャンと呼ばれるようになった。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="使徒行伝 13:1; コリント人への第一の手紙 12:28; エペソ人への手紙 4:11"> そのころ、預言者たちがエルサレムからアンテオケにくだってきた。</span>
<span className="v" id="v28" data-v="28" data-xref="使徒行伝 21:10; 使徒行伝 18:2; ルカによる福音書 3:1"> その中のひとりであるアガボという者が立って、世界中に大ききんが起るだろうと、御霊によって預言したところ、果してそれがクラウデオ帝の時に起った。</span>
<span className="v" id="v29" data-v="29" data-xref="コリント人への第二の手紙 8:12–14; ガラテヤ人への手紙 2:10; コリント人への第二の手紙 8:2–4"> そこで弟子たちは、それぞれの力に応じて、ユダヤに住んでいる兄弟たちに援助を送ることに決めた。</span>
<span className="v" id="v30" data-v="30" data-xref="使徒行伝 14:23; 使徒行伝 12:25; 使徒行伝 15:4"> そして、それをバルナバとサウロとの手に託して、長老たちに送りとどけた。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マタイによる福音書 24:9; ヨハネによる福音書 15:20; マタイによる福音書 10:17–18"> そのころ、ヘロデ王は教会のある者たちに圧迫の手をのばし、</span>
<span className="v" id="v2" data-v="2" data-xref="ヘブル人への手紙 11:37; マタイによる福音書 20:23; マタイによる福音書 4:21–22"> ヨハネの兄弟ヤコブをつるぎで切り殺した。</span>
<span className="v" id="v3" data-v="3" data-xref="出エジプト記 23:15; ヨハネによる福音書 12:43; 使徒行伝 24:27"> そして、それがユダヤ人たちの意にかなったのを見て、さらにペテロをも捕えにかかった。それは除酵祭の時のことであった。</span>
<span className="v" id="v4" data-v="4" data-xref="箴言 19:21; ルカによる福音書 22:33; ルカによる福音書 21:12"> ヘロデはペテロを捕えて獄に投じ、四人一組の兵卒四組に引き渡して、見張りをさせておいた。過越の祭のあとで、彼を民衆の前に引き出すつもりであったのである。</span>
<span className="v" id="v5" data-v="5" data-xref="コリント人への第一の手紙 12:26; テサロニケ人への第一の手紙 5:17; ヤコブの手紙 5:16"> こうして、ペテロは獄に入れられていた。教会では、彼のために熱心な祈が神にささげられた。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="使徒行伝 21:33; ヘブル人への手紙 13:6; ピリピ人への手紙 4:6–7"> ヘロデが彼を引き出そうとしていたその夜、ペテロは二重の鎖につながれ、ふたりの兵卒の間に置かれて眠っていた。番兵たちは戸口で獄を見張っていた。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行伝 5:19; 使徒行伝 16:26; 詩篇 146:7"> すると、突然、主の使がそばに立ち、光が獄内を照した。そして御使はペテロのわき腹をつついて起し、「早く起きあがりなさい」と言った。すると鎖が彼の両手から、はずれ落ちた。</span>
<span className="v" id="v8" data-v="8"> 御使が「帯をしめ、くつをはきなさい」と言ったので、彼はそのとおりにした。それから「上着を着て、ついてきなさい」と言われたので、</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 126:1; ヘブル人への手紙 11:8; 創世記 45:26"> ペテロはついて出て行った。彼には御使のしわざが現実のこととは考えられず、ただ幻を見ているように思われた。</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行伝 5:19; 使徒行伝 16:26; イザヤ書 45:1–2"> 彼らは第一、第二の衛所を通りすぎて、町に抜ける鉄門のところに来ると、それがひとりでに開いたので、そこを出て一つの通路に進んだとたんに、御使は彼を離れ去った。</span>
<span className="v" id="v11" data-v="11" data-xref="ダニエル書 6:22; ダニエル書 3:28; ペテロの第二の手紙 2:9"> その時ペテロはわれにかえって言った、「今はじめて、ほんとうのことがわかった。主が御使をつかわして、ヘロデの手から、またユダヤ人たちの待ちもうけていたあらゆる災から、わたしを救い出して下さったのだ」。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="ヨハネの第一の手紙 5:14–15; 使徒行伝 12:5; マタイによる福音書 18:19–20"> ペテロはこうとわかってから、マルコと呼ばれているヨハネの母マリヤの家に行った。その家には大ぜいの人が集まって祈っていた。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行伝 12:16; ルカによる福音書 13:25; ヨハネによる福音書 18:16–17"> 彼が門の戸をたたいたところ、ロダという女中が取次ぎに出てきたが、</span>
<span className="v" id="v14" data-v="14" data-xref="ルカによる福音書 24:41; マタイによる福音書 28:8"> ペテロの声だとわかると、喜びのあまり、門をあけもしないで家に駆け込み、ペテロが門口に立っていると報告した。</span>
<span className="v" id="v15" data-v="15" data-xref="マタイによる福音書 18:10; ルカによる福音書 24:11; マルコによる福音書 16:14"> 人々は「あなたは気が狂っている」と言ったが、彼女は自分の言うことに間違いはないと、言い張った。そこで彼らは「それでは、ペテロの御使だろう」と言った。</span>
<span className="v" id="v16" data-v="16"> しかし、ペテロが門をたたきつづけるので、彼らがあけると、そこにペテロがいたのを見て驚いた。</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行伝 21:40; 使徒行伝 13:16; 使徒行伝 19:33"> ペテロは手を振って彼らを静め、主が獄から彼を連れ出して下さった次第を説明し、「このことを、ヤコブやほかの兄弟たちに伝えて下さい」と言い残して、どこかほかの所へ出て行った。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="使徒行伝 5:22–25; 使徒行伝 16:27; 使徒行伝 19:23"> 夜が明けると、兵卒たちの間に、ペテロはいったいどうなったのだろうと、大へんな騒ぎが起った。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行伝 16:27; 詩篇 37:32–33; ヨハネによる福音書 12:10–11"> ヘロデはペテロを捜しても見つからないので、番兵たちを取り調べたうえ、彼らを死刑に処するように命じ、そして、ユダヤからカイザリヤにくだって行って、そこに滞在した。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="エズラ記 3:7; マタイによる福音書 11:21–22; エゼキエル書 27:17"> さて、ツロとシドンとの人々は、ヘロデの怒りに触ていたので、一同うちそろって王をおとずれ、王の侍従官ブラストに取りいって、和解かたを依頼した。彼らの地方が、王の国から食糧を得ていたからである。</span>
<span className="v" id="v21" data-v="21"> 定められた日に、ヘロデは王服をまとって王座にすわり、彼らにむかって演説をした。</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行伝 14:10–13; ヨハネの黙示録 13:4; ユダの手紙 1:16"> 集まった人々は、「これは神の声だ、人間の声ではない」と叫びつづけた。</span>
<span className="v" id="v23" data-v="23" data-xref="詩篇 115:1; 使徒行伝 10:25–26; テサロニケ人への第二の手紙 2:4"> するとたちまち、主の使が彼を打った。神に栄光を帰することをしなかったからである。彼は虫にかまれて息が絶えてしまった。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="使徒行伝 6:7; 使徒行伝 19:20; テサロニケ人への第二の手紙 3:1"> こうして、主の言はますます盛んにひろまって行った。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="使徒行伝 12:12; ペテロの第一の手紙 5:13; 使徒行伝 15:37"> バルナバとサウロとは、その任務を果したのち、マルコと呼ばれていたヨハネを連れて、エルサレムから帰ってきた。</span>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行伝 27:26; 使徒行伝 27:44; 使徒行伝 27:39"> わたしたちが、こうして救われてからわかったが、これはマルタと呼ばれる島であった。</span>
<span className="v" id="v2" data-v="2" data-xref="ローマ人への手紙 1:14; ヘブル人への手紙 13:2; コロサイ人への手紙 3:11"> 土地の人々は、わたしたちに並々ならぬ親切をあらわしてくれた。すなわち、降りしきる雨や寒さをしのぐために、火をたいてわたしたち一同をねぎらってくれたのである。</span>
<span className="v" id="v3" data-v="3" data-xref="マタイによる福音書 23:33; マタイによる福音書 12:34; 使徒行伝 28:4"> そのとき、パウロはひとかかえの柴をたばねて火にくべたところ、熱気のためにまむしが出てきて、彼の手にかみついた。</span>
<span className="v" id="v4" data-v="4" data-xref="ルカによる福音書 13:2; ルカによる福音書 13:4; ヨハネによる福音書 7:24"> 土地の人々は、この生きものがパウロの手からぶら下がっているのを見て、互に言った、「この人は、きっと人殺しに違いない。海からはのがれたが、ディケーの神様が彼を生かしてはおかないのだ」。</span>
<span className="v" id="v5" data-v="5" data-xref="ルカによる福音書 10:19; マルコによる福音書 16:18; 詩篇 91:13"> ところがパウロは、まむしを火の中に振り落して、なんの害も被らなかった。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行伝 12:22; 使徒行伝 14:11–13; マタイによる福音書 21:9"> 彼らは、彼が間もなくはれ上がるか、あるいは、たちまち倒れて死ぬだろうと、様子をうかがっていた。しかし、長い間うかがっていても、彼の身になんの変ったことも起らないのを見て、彼らは考えを変えて、「この人は神様だ」と言い出した。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="マタイによる福音書 10:40–41; ルカによる福音書 19:6–9; 使徒行伝 28:2"> さて、その場所の近くに、島の首長、ポプリオという人の所有地があった。彼は、そこにわたしたちを招待して、三日のあいだ親切にもてなしてくれた。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行伝 9:40; マルコによる福音書 6:5; ヤコブの手紙 5:14–16"> たまたま、ポプリオの父が赤痢をわずらい、高熱で床についていた。そこでパウロは、その人のところにはいって行って祈り、手を彼の上においていやしてやった。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行伝 5:12; マルコによる福音書 6:54–56; 使徒行伝 5:15"> このことがあってから、ほかに病気をしている島の人たちが、ぞくぞくとやってきて、みないやされた。</span>
<span className="v" id="v10" data-v="10" data-xref="テサロニケ人への第一の手紙 2:6; ピリピ人への手紙 4:11–12; マタイによる福音書 6:31–34"> 彼らはわたしたちを非常に尊敬し、出帆の時には、必要な品々を持ってきてくれた。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="使徒行伝 27:6; コリント人への第一の手紙 8:4; イザヤ書 45:20"> 三か月たった後、わたしたちは、この島に冬ごもりをしていたデオスクリの船飾りのあるアレキサンドリヤの舟で、出帆した。</span>
<span className="v" id="v12" data-v="12"> そして、シラクサに寄港して三日のあいだ停泊し、</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行伝 27:13"> そこから進んでレギオンに行った。それから一日おいて、南風が吹いてきたのに乗じ、ふつか目にポテオリに着いた。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行伝 21:4; 使徒行伝 20:6; 使徒行伝 19:1"> そこで兄弟たちに会い、勧められるまま、彼らのところに七日間も滞在した。それからわたしたちは、ついにローマに到着した。</span>
<span className="v" id="v15" data-v="15" data-xref="ヘブル人への手紙 13:3; ローマ人への手紙 15:24; 出エジプト記 4:14"> ところが、兄弟たちは、わたしたちのことを聞いて、アピオ・ポロおよびトレス・タベルネまで出迎えてくれた。パウロは彼らに会って、神に感謝し勇み立った。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="使徒行伝 27:3; 使徒行伝 24:23; 使徒行伝 28:30–31"> わたしたちがローマに着いた後、パウロは、ひとりの番兵をつけられ、ひとりで住むことを許された。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="使徒行伝 25:8; 使徒行伝 6:14; 使徒行伝 25:10"> 三日たってから、パウロは、重立ったユダヤ人たちを招いた。みんなの者が集まったとき、彼らに言った、「兄弟たちよ、わたしは、わが国民に対しても、あるいは先祖伝来の慣例に対しても、何一つそむく行為がなかったのに、エルサレムで囚人としてローマ人たちの手に引き渡された。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行伝 26:31–32; 使徒行伝 23:29; 使徒行伝 22:24–25"> 彼らはわたしを取り調べた結果、なんら死に当る罪状もないので、わたしを釈放しようと思ったのであるが、</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行伝 26:32; 使徒行伝 25:21; 使徒行伝 25:10–12"> ユダヤ人たちがこれに反対したため、わたしはやむを得ず、カイザルに上訴するに至ったのである。しかしわたしは、わが同胞を訴えようなどとしているのではない。</span>
<span className="v" id="v20" data-v="20" data-xref="エペソ人への手紙 6:20; テモテヘの第二の手紙 2:9; 使徒行伝 26:6–7"> こういうわけで、あなたがたに会って語り合いたいと願っていた。事実、わたしは、イスラエルのいだいている希望のゆえに、この鎖につながれているのである」。</span>
<span className="v" id="v21" data-v="21" data-xref="イザヤ書 54:17; イザヤ書 41:11; イザヤ書 50:8"> そこで彼らは、パウロに言った、「わたしたちは、ユダヤ人たちから、あなたについて、なんの文書も受け取っていないし、また、兄弟たちの中からここにきて、あなたについて不利な報告をしたり、悪口を言ったりした者もなかった。</span>
<span className="v" id="v22" data-v="22" data-xref="ペテロの第一の手紙 2:12; 使徒行伝 24:14; ペテロの第一の手紙 3:16"> わたしたちは、あなたの考えていることを、直接あなたから聞くのが、正しいことだと思っている。実は、この宗派については、いたるところで反対のあることが、わたしたちの耳にもはいっている」。</span>
</div>
<div className="bp poetry">
<span className="v" id="v23" data-v="23" data-xref="使徒行伝 17:2–3; 使徒行伝 19:8; 使徒行伝 18:28"> そこで、日を定めて、大ぜいの人が、パウロの宿につめかけてきたので、朝から晩まで、パウロは語り続け、神の国のことをあかしし、またモーセの律法や預言者の書を引いて、イエスについて彼らの説得につとめた。</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行伝 14:4; 使徒行伝 17:4–5; 使徒行伝 19:8–9"> ある者はパウロの言うことを受けいれ、ある者は信じようともしなかった。</span>
<span className="v" id="v25" data-v="25" data-xref="マタイによる福音書 15:7; ペテロの第二の手紙 1:21; マルコによる福音書 7:6"> 互に意見が合わなくて、みんなの者が帰ろうとしていた時、パウロはひとこと述べて言った、「聖霊はよくも預言者イザヤによって、あなたがたの先祖に語ったものである。</span>
<span className="v" id="v26" data-v="26" data-xref="イザヤ書 6:9–10; エゼキエル書 12:2; イザヤ書 42:19–20"> <span className="pl pl-1">『この民に行って言え、</span><br /><span className="pl pl-1">あなたがたは聞くには聞くが、決して悟らない。</span><br /><span className="pl pl-1">見るには見るが、決して認めない。</span></span>
<span className="v" id="v27" data-v="27" data-xref="イザヤ書 6:10"> <span className="pl pl-1">この民の心は鈍くなり、</span><br /><span className="pl pl-1">その耳は聞えにくく、</span><br /><span className="pl pl-1">その目は閉じている。</span><br /><span className="pl pl-1">それは、彼らが目で見ず、</span><br /><span className="pl pl-1">耳で聞かず、</span><br /><span className="pl pl-1">心で悟らず、悔い改めて</span><br /><span className="pl pl-1">いやされることがないためである』。</span></span>
<span className="v" id="v28" data-v="28" data-xref="ルカによる福音書 2:30–32; 使徒行伝 26:17–18; ローマ人への手紙 3:29–30"> <span className="pl pl-1">そこで、あなたがたは知っておくがよい。神のこの救の言葉は、異邦人に送られたのだ。彼らは、これに聞きしたがうであろう」。〔</span></span>
<span className="v" id="v29" data-v="29"> <span className="pl pl-1">パウロがこれらのことを述べ終ると、ユダヤ人らは、互に論じ合いながら帰って行った。〕</span></span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30"> パウロは、自分の借りた家に満二年のあいだ住んで、たずねて来る人々をみな迎え入れ、</span>
<span className="v" id="v31" data-v="31" data-xref="使徒行伝 4:29; エペソ人への手紙 6:19–20; マタイによる福音書 4:23"> はばからず、また妨げられることもなく、神の国を宣べ伝え、主イエス・キリストのことを教えつづけた。</span>
</div>

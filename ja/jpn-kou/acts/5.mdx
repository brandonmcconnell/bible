<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="レビ記 10:1–3; テモテヘの第二の手紙 2:20; マタイによる福音書 13:47–48"> ところが、アナニヤという人とその妻サッピラとは共に資産を売ったが、</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行伝 4:37; ペテロの第二の手紙 2:14–15; マタイによる福音書 23:5"> 共謀して、その代金をごまかし、一部だけを持ってきて、使徒たちの足もとに置いた。</span>
<span className="v" id="v3" data-v="3" data-xref="エレミヤ書 23:24; イザヤ書 29:15; ヨハネによる福音書 13:2"> そこで、ペテロが言った、「アナニヤよ、どうしてあなたは、自分の心をサタンに奪われて、聖霊を欺き、地所の代金をごまかしたのか。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行伝 5:3; ヨシュア記 7:25–26; 列王紀下 5:25–27"> 売らずに残しておけば、あなたのものであり、売ってしまっても、あなたの自由になったはずではないか。どうして、こんなことをする気になったのか。あなたは人を欺いたのではなくて、神を欺いたのだ」。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行伝 5:10–11; 使徒行伝 2:43; 使徒行伝 5:13"> アナニヤはこの言葉を聞いているうちに、倒れて息が絶えた。このことを伝え聞いた人々は、みな非常なおそれを感じた。</span>
<span className="v" id="v6" data-v="6" data-xref="ヨハネによる福音書 19:40; サムエル記下 18:17; 申命記 21:23"> それから、若者たちが立って、その死体を包み、運び出して葬った。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7"> 三時間ばかりたってから、たまたま彼の妻が、この出来事を知らずに、はいってきた。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行伝 5:2"> そこで、ペテロが彼女にむかって言った、「あの地所は、これこれの値段で売ったのか。そのとおりか」。彼女は「そうです、その値段です」と答えた。</span>
<span className="v" id="v9" data-v="9" data-xref="コリント人への第一の手紙 10:9; 使徒行伝 5:3–4; 詩篇 95:8–11"> ペテロは言った、「あなたがたふたりが、心を合わせて主の御霊を試みるとは、何事であるか。見よ、あなたの夫を葬った人たちの足が、そこの門口にきている。あなたも運び出されるであろう」。</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行伝 5:5"> すると女は、たちまち彼の足もとに倒れて、息が絶えた。そこに若者たちがはいってきて、女が死んでしまっているのを見、それを運び出してその夫のそばに葬った。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行伝 5:5; コリント人への第一の手紙 10:11–12; 使徒行伝 19:17"> 教会全体ならびにこれを伝え聞いた人たちは、みな非常なおそれを感じた。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="使徒行伝 19:11; コリント人への第二の手紙 12:12; ヘブル人への手紙 2:4"> そのころ、多くのしるしと奇跡とが、次々に使徒たちの手により人々の中で行われた。そして、一同は心を一つにして、ソロモンの廊に集まっていた。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行伝 2:47; 使徒行伝 4:21; ヨハネによる福音書 12:42"> ほかの者たちは、だれひとり、その交わりに入ろうとはしなかったが、民衆は彼らを尊敬していた。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行伝 2:47; 使徒行伝 4:4; イザヤ書 55:11–13"> しかし、主を信じて仲間に加わる者が、男女とも、ますます多くなってきた。</span>
<span className="v" id="v15" data-v="15" data-xref="マタイによる福音書 14:36; 使徒行伝 19:11–12; ヨハネによる福音書 14:12"> ついには、病人を大通りに運び出し、寝台や寝床の上に置いて、ペテロが通るとき、彼の影なりと、そのうちのだれかにかかるようにしたほどであった。</span>
<span className="v" id="v16" data-v="16" data-xref="マルコによる福音書 16:17–18; マルコによる福音書 2:3–4; マタイによる福音書 15:30–31"> またエルサレム附近の町々からも、大ぜいの人が、病人や汚れた霊に苦しめられている人たちを引き連れて、集まってきたが、その全部の者が、ひとり残らずいやされた。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="使徒行伝 13:45; 使徒行伝 7:9; 使徒行伝 17:5"> そこで、大祭司とその仲間の者、すなわち、サドカイ派の人たちが、みな嫉妬の念に満たされて立ちあがり、</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行伝 4:3; ルカによる福音書 21:12; コリント人への第二の手紙 11:23"> 使徒たちに手をかけて捕え、公共の留置場に入れた。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行伝 16:26; 詩篇 34:7; 使徒行伝 12:7–11"> ところが夜、主の使が獄の戸を開き、彼らを連れ出して言った、</span>
<span className="v" id="v20" data-v="20" data-xref="ヨハネによる福音書 6:63; ヨハネによる福音書 6:68; ヨハネの第一の手紙 5:11–12"> 「さあ行きなさい。そして、宮の庭に立ち、この命の言葉を漏れなく、人々に語りなさい」。</span>
<span className="v" id="v21" data-v="21" data-xref="ヨハネによる福音書 8:2; 使徒行伝 22:15; 使徒行伝 12:18–19"> 彼らはこれを聞き、夜明けごろ宮にはいって教えはじめた。<br />一方では、大祭司とその仲間の者とが、集まってきて、議会とイスラエル人の長老一同とを召集し、使徒たちを引き出してこさせるために、人を獄につかわした。</span>
<span className="v" id="v22" data-v="22"> そこで、下役どもが行って見ると、使徒たちが獄にいないので、引き返して報告した、</span>
<span className="v" id="v23" data-v="23" data-xref="詩篇 2:4; 詩篇 33:10; ダニエル書 6:22–24"> 「獄には、しっかりと錠がかけてあり、戸口には、番人が立っていました。ところが、あけて見たら、中にはだれもいませんでした」。</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行伝 4:1; 使徒行伝 5:26; ヨハネによる福音書 12:19"> 宮守がしらと祭司長たちとは、この報告を聞いて、これは、いったい、どんな事になるのだろうと、あわて惑っていた。</span>
<span className="v" id="v25" data-v="25"> そこへ、ある人がきて知らせた、「行ってごらんなさい。あなたがたが獄に入れたあの人たちが、宮の庭に立って、民衆を教えています」。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行伝 5:13; 使徒行伝 4:21; マタイによる福音書 26:5"> そこで宮守がしらが、下役どもと一緒に出かけて行って、使徒たちを連れてきた。しかし、人々に石で打ち殺されるのを恐れて、手荒なことはせず、</span>
<span className="v" id="v27" data-v="27" data-xref="マタイによる福音書 5:22; 使徒行伝 4:7; ルカによる福音書 22:66"> 彼らを連れてきて、議会の中に立たせた。すると、大祭司が問うて</span>
<span className="v" id="v28" data-v="28" data-xref="マタイによる福音書 27:25; 使徒行伝 7:52; 使徒行伝 4:10–11"> 言った、「あの名を使って教えてはならないと、きびしく命じておいたではないか。それだのに、なんという事だ。エルサレム中にあなたがたの教を、はんらんさせている。あなたがたは確かに、あの人の血の責任をわたしたちに負わせようと、たくらんでいるのだ」。</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行伝 4:19; サムエル記上 15:24; マルコによる福音書 7:7–9"> これに対して、ペテロをはじめ使徒たちは言った、「人間に従うよりは、神に従うべきである。</span>
<span className="v" id="v30" data-v="30" data-xref="ガラテヤ人への手紙 3:13; ペテロの第一の手紙 2:24; 使徒行伝 10:39"> わたしたちの先祖の神は、あなたがたが木にかけて殺したイエスをよみがえらせ、</span>
<span className="v" id="v31" data-v="31" data-xref="ルカによる福音書 24:47; 使徒行伝 2:33; ヘブル人への手紙 2:10"> そして、イスラエルを悔い改めさせてこれに罪のゆるしを与えるために、このイエスを導き手とし救主として、ご自身の右に上げられたのである。</span>
<span className="v" id="v32" data-v="32" data-xref="ヨハネによる福音書 15:26–27; ヘブル人への手紙 2:3–4; 使徒行伝 1:8"> わたしたちはこれらの事の証人である。神がご自身に従う者に賜わった聖霊もまた、その証人である」。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="使徒行伝 7:54; 使徒行伝 2:37; ルカによる福音書 4:28–29"> これを聞いた者たちは、激しい怒りのあまり、使徒たちを殺そうと思った。</span>
<span className="v" id="v34" data-v="34" data-xref="使徒行伝 22:3; ルカによる福音書 2:46; ルカによる福音書 5:17"> ところが、国民全体に尊敬されていた律法学者ガマリエルというパリサイ人が、議会で立って、使徒たちをしばらくのあいだ外に出すように要求してから、</span>
<span className="v" id="v35" data-v="35" data-xref="使徒行伝 22:26; エレミヤ書 26:19; マタイによる福音書 27:19"> 一同にむかって言った、「イスラエルの諸君、あの人たちをどう扱うか、よく気をつけるがよい。</span>
<span className="v" id="v36" data-v="36" data-xref="使徒行伝 8:9; ペテロの第二の手紙 2:2; ガラテヤ人への手紙 6:3"> 先ごろ、チゥダが起って、自分を何か偉い者のように言いふらしたため、彼に従った男の数が、四百人ほどもあったが、結局、彼は殺されてしまい、従った者もみな四散して、全く跡方もなくなっている。</span>
<span className="v" id="v37" data-v="37" data-xref="ルカによる福音書 2:1–2; 詩篇 7:14–15; マタイによる福音書 26:52"> そののち、人口調査の時に、ガリラヤ人ユダが民衆を率いて反乱を起したが、この人も滅び、従った者もみな散らされてしまった。</span>
<span className="v" id="v38" data-v="38" data-xref="マタイによる福音書 15:13; 哀歌 3:37; イザヤ書 8:9–10"> そこで、この際、諸君に申し上げる。あの人たちから手を引いて、そのなすままにしておきなさい。その企てや、しわざが、人間から出たものなら、自滅するだろう。</span>
<span className="v" id="v39" data-v="39" data-xref="箴言 21:30; イザヤ書 46:10; マタイによる福音書 16:18"> しかし、もし神から出たものなら、あの人たちを滅ぼすことはできまい。まかり違えば、諸君は神を敵にまわすことになるかも知れない」。そこで彼らはその勧告にしたがい、</span>
<span className="v" id="v40" data-v="40" data-xref="マタイによる福音書 10:17; 使徒行伝 5:28; 使徒行伝 4:17–21"> 使徒たちを呼び入れて、むち打ったのち、今後イエスの名によって語ることは相成らぬと言いわたして、ゆるしてやった。</span>
<span className="v" id="v41" data-v="41" data-xref="ヤコブの手紙 1:2; ペテロの第一の手紙 4:13–16; ルカによる福音書 6:22"> 使徒たちは、御名のために恥を加えられるに足る者とされたことを喜びながら、議会から出てきた。</span>
<span className="v" id="v42" data-v="42" data-xref="使徒行伝 2:46; 使徒行伝 20:20; ルカによる福音書 21:37"> そして、毎日、宮や家で、イエスがキリストであることを、引きつづき教えたり宣べ伝えたりした。</span>
</div>

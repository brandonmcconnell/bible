<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="テサロニケ人への第二の手紙 3:1; コリント人への第一の手紙 15:2; コリント人への第一の手紙 15:58"> 兄弟たちよ。あなたがた自身が知っているとおり、わたしたちがあなたがたの所にはいって行ったことは、むだではなかった。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行伝 16:22–24; 使徒行伝 4:13; 使徒行伝 17:2–9"> それどころか、あなたがたが知っているように、わたしたちは、先にピリピで苦しめられ、はずかしめられたにもかかわらず、わたしたちの神に勇気を与えられて、激しい苦闘のうちに神の福音をあなたがたに語ったのである。</span>
<span className="v" id="v3" data-v="3" data-xref="コリント人への第二の手紙 2:17; コリント人への第二の手紙 4:2; テサロニケ人への第一の手紙 4:7"> いったい、わたしたちの宣教は、迷いや汚れた心から出たものでもなく、だましごとでもない。</span>
<span className="v" id="v4" data-v="4" data-xref="ガラテヤ人への手紙 1:10; ローマ人への手紙 8:27; ガラテヤ人への手紙 2:7"> かえって、わたしたちは神の信任を受けて福音を託されたので、人間に喜ばれるためではなく、わたしたちの心を見分ける神に喜ばれるように、福音を語るのである。</span>
<span className="v" id="v5" data-v="5" data-xref="ローマ人への手紙 1:9; コリント人への第二の手紙 12:17; 使徒行伝 20:33"> わたしたちは、あなたがたが知っているように、決してへつらいの言葉を用いたこともなく、口実を設けて、むさぼったこともない。それは、神があかしして下さる。</span>
<span className="v" id="v6" data-v="6" data-xref="ガラテヤ人への手紙 1:10; テサロニケ人への第一の手紙 2:9; ヨハネによる福音書 5:41"> また、わたしたちは、キリストの使徒として重んじられることができたのであるが、あなたがたからにもせよ、ほかの人々からにもせよ、人間からの栄誉を求めることはしなかった。</span>
<span className="v" id="v7" data-v="7" data-xref="イザヤ書 66:13; テサロニケ人への第一の手紙 2:11; テモテヘの第二の手紙 2:24–25"> むしろ、あなたがたの間で、ちょうど母がその子供を育てるように、やさしくふるまった。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨハネの第一の手紙 3:16; コリント人への第二の手紙 12:15; ピリピ人への手紙 2:17"> このように、あなたがたを慕わしく思っていたので、ただ神の福音ばかりではなく、自分のいのちまでもあなたがたに与えたいと願ったほどに、あなたがたを愛したのである。</span>
<span className="v" id="v9" data-v="9" data-xref="テサロニケ人への第二の手紙 3:7–9; コリント人への第二の手紙 11:9; 使徒行伝 18:3"> 兄弟たちよ。あなたがたはわたしたちの労苦と努力とを記憶していることであろう。すなわち、あなたがたのだれにも負担をかけまいと思って、日夜はたらきながら、あなたがたに神の福音を宣べ伝えた。</span>
<span className="v" id="v10" data-v="10" data-xref="ペテロの第一の手紙 5:3; テサロニケ人への第一の手紙 1:5; コリント人への第二の手紙 1:12"> あなたがたもあかしし、神もあかしして下さるように、わたしたちはあなたがた信者の前で、信心深く、正しく、責められるところがないように、生活をしたのである。</span>
<span className="v" id="v11" data-v="11" data-xref="コリント人への第一の手紙 4:14–15; ヘブル人への手紙 13:22; テモテヘの第一の手紙 5:21"> そして、あなたがたも知っているとおり、父がその子に対してするように、あなたがたのひとりびとりに対して、</span>
<span className="v" id="v12" data-v="12" data-xref="エペソ人への手紙 4:1; ヨハネの第一の手紙 2:6; ヨハネの第一の手紙 1:6–7"> 御国とその栄光とに召して下さった神のみこころにかなって歩くようにと、勧め、励まし、また、さとしたのである。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="ヘブル人への手紙 4:12; ローマ人への手紙 10:17; ペテロの第一の手紙 1:23"> これらのことを考えて、わたしたちがまた絶えず神に感謝しているのは、あなたがたがわたしたちの説いた神の言を聞いた時に、それを人間の言葉としてではなく、神の言として――事実そのとおりであるが――受けいれてくれたことである。そして、この神の言は、信じるあなたがたのうちに働いているのである。</span>
<span className="v" id="v14" data-v="14" data-xref="テサロニケ人への第一の手紙 3:4; ヘブル人への手紙 10:33–34; ヘブル人への手紙 5:7–8"> 兄弟たちよ。あなたがたは、ユダヤの、キリスト・イエスにある神の諸教会にならう者となった。すなわち、彼らがユダヤ人たちから苦しめられたと同じように、あなたがたもまた同国人から苦しめられた。</span>
<span className="v" id="v15" data-v="15" data-xref="マタイによる福音書 5:12; ルカによる福音書 11:48–53; 使徒行伝 7:52"> ユダヤ人たちは主イエスと預言者たちとを殺し、わたしたちを迫害し、神を喜ばせず、すべての人に逆らい、</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行伝 17:13; 使徒行伝 14:19; マルコによる福音書 16:16"> わたしたちが異邦人に救の言を語るのを妨げて、絶えず自分の罪を満たしている。そこで、神の怒りは最も激しく彼らに臨むに至ったのである。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="コロサイ人への手紙 2:5; コリント人への第一の手紙 5:3; テサロニケ人への第一の手紙 3:6"> 兄弟たちよ。わたしたちは、しばらくの間、あなたがたから引き離されていたので――心においてではなく、からだだけではあるが――なおさら、あなたがたの顔を見たいと切にこいねがった。</span>
<span className="v" id="v18" data-v="18" data-xref="ローマ人への手紙 15:22; ローマ人への手紙 1:13; ヨハネの黙示録 2:10"> だから、わたしたちは、あなたがたの所に行こうとした。ことに、このパウロは、一再ならず行こうとしたのである。それだのに、わたしたちはサタンに妨げられた。</span>
<span className="v" id="v19" data-v="19" data-xref="ピリピ人への手紙 4:1; テサロニケ人への第一の手紙 3:13; ピリピ人への手紙 2:16"> 実際、わたしたちの主イエスの来臨にあたって、わたしたちの望みと喜びと誇の冠となるべき者は、あなたがたを外にして、だれがあるだろうか。</span>
<span className="v" id="v20" data-v="20" data-xref="コリント人への第二の手紙 1:14; コリント人への第一の手紙 11:7; 箴言 17:6"> あなたがたこそ、実にわたしたちのほまれであり、喜びである。</span>
</div>

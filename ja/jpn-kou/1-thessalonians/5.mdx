<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行伝 1:7; テサロニケ人への第一の手紙 4:9; マタイによる福音書 24:36"> 兄弟たちよ。その時期と場合とについては、書きおくる必要はない。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネの黙示録 16:15; ペテロの第二の手紙 3:10; マタイによる福音書 24:42–44"> あなたがた自身がよく知っているとおり、主の日は盗人が夜くるように来る。</span>
<span className="v" id="v3" data-v="3" data-xref="ルカによる福音書 21:34–35; マタイによる福音書 24:37–39; ルカによる福音書 17:26–30"> 人々が平和だ無事だと言っているその矢先に、ちょうど妊婦に産みの苦しみが臨むように、突如として滅びが彼らをおそって来る。そして、それからのがれることは決してできない。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネの第一の手紙 2:8; ペテロの第二の手紙 3:10; 申命記 19:6"> しかし兄弟たちよ。あなたがたは暗やみの中にいないのだから、その日が、盗人のようにあなたがたを不意に襲うことはないであろう。</span>
<span className="v" id="v5" data-v="5" data-xref="エペソ人への手紙 5:8; 使徒行伝 26:18; ヨハネによる福音書 12:36"> あなたがたはみな光の子であり、昼の子なのである。わたしたちは、夜の者でもやみの者でもない。</span>
<span className="v" id="v6" data-v="6" data-xref="ペテロの第一の手紙 1:13; マタイによる福音書 24:42; ルカによる福音書 22:46"> だから、ほかの人々のように眠っていないで、目をさまして慎んでいよう。</span>
<span className="v" id="v7" data-v="7" data-xref="ローマ人への手紙 13:13; コリント人への第一の手紙 15:34; ペテロの第二の手紙 2:13"> 眠る者は夜眠り、酔う者は夜酔うのである。</span>
<span className="v" id="v8" data-v="8" data-xref="ローマ人への手紙 13:12–13; エペソ人への手紙 6:11; ペテロの第一の手紙 1:13"> しかし、わたしたちは昼の者なのだから、信仰と愛との胸当を身につけ、救の望みのかぶとをかぶって、慎んでいよう。</span>
<span className="v" id="v9" data-v="9" data-xref="テサロニケ人への第一の手紙 1:10; ペテロの第一の手紙 2:10; テモテヘの第二の手紙 2:10"> 神は、わたしたちを怒りにあわせるように定められたのではなく、わたしたちの主イエス・キリストによって救を得るように定められたのである。</span>
<span className="v" id="v10" data-v="10" data-xref="ローマ人への手紙 14:8–9; ペテロの第一の手紙 3:18; ローマ人への手紙 8:34"> キリストがわたしたちのために死なれたのは、さめていても眠っていても、わたしたちが主と共に生きるためである。</span>
<span className="v" id="v11" data-v="11" data-xref="エペソ人への手紙 4:29; ヘブル人への手紙 10:25; ローマ人への手紙 15:2"> だから、あなたがたは、今しているように、互に慰め合い、相互の徳を高めなさい。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="ヘブル人への手紙 13:17; ヘブル人への手紙 13:7; テモテヘの第一の手紙 5:17–18"> 兄弟たちよ。わたしたちはお願いする。どうか、あなたがたの間で労し、主にあってあなたがたを指導し、かつ訓戒している人々を重んじ、</span>
<span className="v" id="v13" data-v="13" data-xref="マルコによる福音書 9:50; ヘブル人への手紙 12:14; ガラテヤ人への手紙 6:6"> 彼らの働きを思って、特に愛し敬いなさい。互に平和に過ごしなさい。</span>
<span className="v" id="v14" data-v="14" data-xref="テモテヘの第二の手紙 4:2; ローマ人への手紙 14:1; 使徒行伝 20:35"> 兄弟たちよ。あなたがたにお勧めする。怠惰な者を戒め、小心な者を励まし、弱い者を助け、すべての人に対して寛容でありなさい。</span>
<span className="v" id="v15" data-v="15" data-xref="ペテロの第一の手紙 3:9; ガラテヤ人への手紙 6:10; レビ記 19:18"> だれも悪をもって悪に報いないように心がけ、お互に、またみんなに対して、いつも善を追い求めなさい。</span>
<span className="v" id="v16" data-v="16" data-xref="ローマ人への手紙 12:12; ピリピ人への手紙 4:4; マタイによる福音書 5:12"> いつも喜んでいなさい。</span>
<span className="v" id="v17" data-v="17" data-xref="ローマ人への手紙 12:12; コロサイ人への手紙 4:2; エペソ人への手紙 6:18"> 絶えず祈りなさい。</span>
<span className="v" id="v18" data-v="18" data-xref="エペソ人への手紙 5:20; ピリピ人への手紙 4:6; コロサイ人への手紙 3:17"> すべての事について、感謝しなさい。これが、キリスト・イエスにあって、神があなたがたに求めておられることである。</span>
<span className="v" id="v19" data-v="19" data-xref="エペソ人への手紙 4:30; 使徒行伝 7:51; テモテヘの第二の手紙 1:6"> 御霊を消してはいけない。</span>
<span className="v" id="v20" data-v="20" data-xref="コリント人への第一の手紙 14:3–6; コリント人への第一の手紙 14:1; 民数記 11:25–29"> 預言を軽んじてはならない。</span>
<span className="v" id="v21" data-v="21" data-xref="ヨハネの第一の手紙 4:1; ローマ人への手紙 12:2; エペソ人への手紙 5:10"> すべてのものを識別して、良いものを守り、</span>
<span className="v" id="v22" data-v="22" data-xref="コリント人への第二の手紙 6:3; ピリピ人への手紙 4:8; コリント人への第一の手紙 10:31–33"> あらゆる種類の悪から遠ざかりなさい。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="ユダの手紙 1:24; ヘブル人への手紙 4:12; コリント人への第一の手紙 1:8–9"> どうか、平和の神ご自身が、あなたがたを全くきよめて下さるように。また、あなたがたの霊と心とからだとを完全に守って、わたしたちの主イエス・キリストの来臨のときに、責められるところのない者にして下さるように。</span>
<span className="v" id="v24" data-v="24" data-xref="テサロニケ人への第二の手紙 3:3; 民数記 23:19; コリント人への第一の手紙 1:9"> あなたがたを召されたかたは真実であられるから、このことをして下さるであろう。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="ヘブル人への手紙 13:18–19; ピリピ人への手紙 1:19; ピレモンヘの手紙 1:22"> 兄弟たちよ。わたしたちのためにも、祈ってほしい。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="ローマ人への手紙 16:16; コリント人への第一の手紙 16:20"> すべての兄弟たちに、きよい接吻をもって、よろしく伝えてほしい。</span>
<span className="v" id="v27" data-v="27" data-xref="コロサイ人への手紙 4:16; 使徒行伝 19:13; テモテヘの第一の手紙 1:3"> わたしは主によって命じる。この手紙を、みんなの兄弟に読み聞かせなさい。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="ローマ人への手紙 16:20; テサロニケ人への第二の手紙 3:18; ローマ人への手紙 16:23"> わたしたちの主イエス・キリストの恵みが、あなたがたと共にあるように。</span>
</div>

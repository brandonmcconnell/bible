<span className="v" id="v1" data-v="1" data-xref="使徒行伝 17:15; テサロニケ人への第一の手紙 3:5; テサロニケ人への第一の手紙 2:17"> そこで、わたしたちはこれ以上耐えられなくなって、わたしたちだけがアテネに留まることに定め、</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行伝 14:22–23; エペソ人への手紙 6:21–22; ピリピ人への手紙 2:19–25"> わたしたちの兄弟で、キリストの福音における神の同労者テモテをつかわした。それは、あなたがたの信仰を強め、</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行伝 14:22; ローマ人への手紙 5:3; 使徒行伝 9:16"> このような患難の中にあって、動揺する者がひとりもないように励ますためであった。あなたがたの知っているとおり、わたしたちは患難に会うように定められているのである。</span>
<span className="v" id="v4" data-v="4" data-xref="テサロニケ人への第一の手紙 2:14; コリント人への第二の手紙 8:1–2; テサロニケ人への第一の手紙 2:2"> そして、あなたがたの所にいたとき、わたしたちがやがて患難に会うことをあらかじめ言っておいたが、あなたがたの知っているように、今そのとおりになったのである。</span>
<span className="v" id="v5" data-v="5" data-xref="ヤコブの手紙 1:13–14; マタイによる福音書 4:3; コリント人への第二の手紙 2:11"> そこで、わたしはこれ以上耐えられなくなって、もしや「試みる者」があなたがたを試み、そのためにわたしたちの労苦がむだになりはしないかと気づかって、あなたがたの信仰を知るために、彼をつかわしたのである。</span>
<span className="v" id="v6" data-v="6" data-xref="コリント人への第一の手紙 11:2; イザヤ書 52:7; 箴言 25:25"> ところが今テモテが、あなたがたの所からわたしたちのもとに帰ってきて、あなたがたの信仰と愛とについて知らせ、また、あなたがたがいつもわたしたちのことを覚え、わたしたちがあなたがたに会いたく思っていると同じように、わたしたちにしきりに会いたがっているという吉報をもたらした。</span>
<span className="v" id="v7" data-v="7" data-xref="コリント人への第二の手紙 1:4; ヨハネの第二の手紙 1:4; テサロニケ人への第一の手紙 3:8–9"> 兄弟たちよ。それによって、わたしたちはあらゆる苦難と患難との中にありながら、あなたがたの信仰によって慰められた。</span>
<span className="v" id="v8" data-v="8" data-xref="コロサイ人への手紙 1:23; コリント人への第一の手紙 16:13; ヨハネの黙示録 3:11"> なぜなら、あなたがたが主にあって堅く立ってくれるなら、わたしたちはいま生きることになるからである。</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 71:14–15; 詩篇 96:12–13; コリント人への第二の手紙 9:15"> ほんとうに、わたしたちの神のみまえで、あなたがたのことで喜ぶ大きな喜びのために、どんな感謝を神にささげたらよいだろうか。</span>
<span className="v" id="v10" data-v="10" data-xref="コリント人への第二の手紙 13:9; テサロニケ人への第一の手紙 3:11; ピリピ人への手紙 1:25"> わたしたちは、あなたがたの顔を見、あなたがたの信仰の足りないところを補いたいと、日夜しきりに願っているのである。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="箴言 3:5–6; マタイによる福音書 6:32; テサロニケ人への第二の手紙 2:16"> どうか、わたしたちの父なる神ご自身と、わたしたちの主イエスとが、あなたがたのところへ行く道を、わたしたちに開いて下さるように。</span>
<span className="v" id="v12" data-v="12" data-xref="ピリピ人への手紙 1:9; ヨハネの第一の手紙 4:7–16; マタイによる福音書 22:39"> どうか、主が、あなたがた相互の愛とすべての人に対する愛とを、わたしたちがあなたがたを愛する愛と同じように、増し加えて豊かにして下さるように。</span>
<span className="v" id="v13" data-v="13" data-xref="コロサイ人への手紙 1:22; テサロニケ人への第一の手紙 5:23; エペソ人への手紙 5:27"> そして、どうか、わたしたちの主イエスが、そのすべての聖なる者と共にこられる時、神のみまえに、あなたがたの心を強め、清く、責められるところのない者にして下さるように。</span>

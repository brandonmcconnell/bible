<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歴代志上 6:34; 歴代志上 6:25–27; サムエル記上 1:19"> エフライムの山地のラマタイム・ゾピムに、エルカナという名の人があった。エフライムびとで、エロハムの子であった。エロハムはエリウの子、エリウはトフの子、トフはツフの子である。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 16:1–2; 士師記 13:2; 創世記 29:23–29"> エルカナには、ふたりの妻があって、ひとりの名はハンナといい、ひとりの名はペニンナといった。ペニンナには子どもがあったが、ハンナには子どもがなかった。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="ルカによる福音書 2:41; ヨシュア記 18:1; 申命記 12:5–7"> この人は年ごとに、その町からシロに上っていって、万軍の主を拝し、主に犠牲をささげるのを常とした。シロには、エリのふたりの子、ホフニとピネハスとがいて、主に仕える祭司であった。</span>
<span className="v" id="v4" data-v="4" data-xref="申命記 12:17–18; 申命記 16:11; 申命記 12:5–7"> エルカナは、犠牲をささげる日、妻ペニンナとそのむすこ娘にはみな、その分け前を与えた。</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 30:2; 創世記 29:30–31; 創世記 45:22"> エルカナはハンナを愛していたが、彼女には、ただ一つの分け前を与えるだけであった。主がその胎を閉ざされたからである。</span>
<span className="v" id="v6" data-v="6" data-xref="ヨブ記 6:14; ヨブ記 24:21; レビ記 18:18"> また彼女を憎んでいる他の妻は、ひどく彼女を悩まして、主がその胎を閉ざされたことを恨ませようとした。</span>
<span className="v" id="v7" data-v="7" data-xref="サムエル記上 2:19"> こうして年は暮れ、年は明けたが、ハンナが主の宮に上るごとに、ペニンナは彼女を悩ましたので、ハンナは泣いて食べることもしなかった。</span>
<span className="v" id="v8" data-v="8" data-xref="ルツ記 4:15; ヨブ記 6:14; イザヤ書 54:6"> 夫エルカナは彼女に言った、「ハンナよ、なぜ泣くのか。なぜ食べないのか。どうして心に悲しむのか。わたしはあなたにとって十人の子どもよりもまさっているではないか」。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="サムエル記上 3:3; 詩篇 27:4; 詩篇 5:7"> シロで彼らが飲み食いしたのち、ハンナは立ちあがった。その時、祭司エリは主の神殿の柱のかたわらの座にすわっていた。</span>
<span className="v" id="v10" data-v="10" data-xref="ヨブ記 7:11; ルカによる福音書 22:44; ヨブ記 10:1"> ハンナは心に深く悲しみ、主に祈って、はげしく泣いた。</span>
<span className="v" id="v11" data-v="11" data-xref="士師記 13:5; 民数記 6:5; 創世記 29:32"> そして誓いを立てて言った、「万軍の主よ、まことに、はしための悩みをかえりみ、わたしを覚え、はしためを忘れずに、はしために男の子を賜わりますなら、わたしはその子を一生のあいだ主にささげ、かみそりをその頭にあてません」。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="テサロニケ人への第一の手紙 5:17; ヤコブの手紙 5:16; ルカによる福音書 18:1"> 彼女が主の前で長く祈っていたので、エリは彼女の口に目をとめた。</span>
<span className="v" id="v13" data-v="13" data-xref="ローマ人への手紙 8:26; 使徒行伝 2:13; 創世記 24:42–45"> ハンナは心のうちで物を言っていたので、くちびるが動くだけで、声は聞えなかった。それゆえエリは、酔っているのだと思って、</span>
<span className="v" id="v14" data-v="14" data-xref="エペソ人への手紙 4:25; ヨブ記 8:2; 箴言 6:9"> 彼女に言った、「いつまで酔っているのか。酔いをさましなさい」。</span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 62:8; 哀歌 2:19; 詩篇 42:4"> しかしハンナは答えた、「いいえ、わが主よ。わたしは不幸な女です。ぶどう酒も濃い酒も飲んだのではありません。ただ主の前に心を注ぎ出していたのです。</span>
<span className="v" id="v16" data-v="16" data-xref="サムエル記上 2:12; ヨブ記 6:2–3; マタイによる福音書 12:34–35"> はしためを、悪い女と思わないでください。積る憂いと悩みのゆえに、わたしは今まで物を言っていたのです」。</span>
<span className="v" id="v17" data-v="17" data-xref="マルコによる福音書 5:34; 士師記 18:6; 詩篇 20:3–5"> そこでエリは答えた、「安心して行きなさい。どうかイスラエルの神があなたの求める願いを聞きとどけられるように」。</span>
<span className="v" id="v18" data-v="18" data-xref="ルツ記 2:13; ローマ人への手紙 15:13; 伝道の書 9:7"> 彼女は言った、「どうぞ、はしためにも、あなたの前に恵みを得させてください」。こうして、その女は去って食事し、その顔は、もはや悲しげではなくなった。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="創世記 21:1; 創世記 30:22; サムエル記上 1:11"> 彼らは朝早く起きて、主の前に礼拝し、そして、ラマにある家に帰って行った。エルカナは妻ハンナを知り、主が彼女を顧みられたので、</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 41:51–52; マタイによる福音書 1:21; 出エジプト記 2:10"> 彼女はみごもり、その時が巡ってきて、男の子を産み、「わたしがこの子を主に求めたからだ」といって、その名をサムエルと名づけた。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="サムエル記上 1:3; 申命記 12:11; ヨシュア記 24:15"> エルカナその人とその家族とはみな上っていって、年ごとの犠牲と、誓いの供え物とをささげた。</span>
<span className="v" id="v22" data-v="22" data-xref="サムエル記上 1:28; サムエル記上 1:11; ルカによる福音書 2:22"> しかしハンナは上って行かず、夫に言った、「わたしはこの子が乳離れしてから、主の前に連れていって、いつまでも、そこにおらせましょう」。</span>
<span className="v" id="v23" data-v="23" data-xref="サムエル記下 7:25; ルカによる福音書 11:27; 創世記 21:7–8"> 夫エルカナは彼女に言った、「あなたが良いと思うようにして、この子の乳離れするまで待ちなさい。ただどうか主がその言われたことを実現してくださるように」。こうしてその女はとどまって、その子に乳をのませ、乳離れするのを待っていたが、</span>
<span className="v" id="v24" data-v="24" data-xref="民数記 15:9–10; ヨシュア記 18:1; サムエル記上 4:3–4"> 乳離れした時、三歳の雄牛一頭、麦粉一エパ、ぶどう酒のはいった皮袋一つを取り、その子を連れて、シロにある主の宮に行った。その子はなお幼かった。</span>
<span className="v" id="v25" data-v="25" data-xref="ルカによる福音書 18:15–16; ルカによる福音書 2:22"> そして彼らはその牛を殺し、子供をエリのもとへ連れて行った。</span>
<span className="v" id="v26" data-v="26" data-xref="列王紀下 4:30; 列王紀下 2:4; 列王紀下 2:6"> ハンナは言った、「わが君よ、あなたは生きておられます。わたしは、かつてここに立って、あなたの前で、主に祈った女です。</span>
<span className="v" id="v27" data-v="27" data-xref="ヨハネの第一の手紙 5:15; 詩篇 118:5; マタイによる福音書 7:7"> この子を与えてくださいと、わたしは祈りましたが、主はわたしの求めた願いを聞きとどけられました。</span>
<span className="v" id="v28" data-v="28" data-xref="創世記 24:26; 創世記 24:52; テモテヘの第二の手紙 3:15"> それゆえ、わたしもこの子を主にささげます。この子は一生のあいだ主にささげたものです」。<br />そして彼らはそこで主を礼拝した。</span>
</div>

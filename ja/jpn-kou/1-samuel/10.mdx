<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="サムエル記上 16:13; 詩篇 78:71; サムエル記上 9:16"> その時サムエルは油のびんを取って、サウルの頭に注ぎ、彼に口づけして言った、「主はあなたに油を注いで、その民イスラエルの君とされたではありませんか。あなたは主の民を治め、周囲の敵の手から彼らを救わなければならない。主があなたに油を注いで、その嗣業の君とされたことの、しるしは次のとおりです。</span>
<span className="v" id="v2" data-v="2" data-xref="サムエル記上 9:3–5; 創世記 35:19–20; ヨシュア記 18:28"> あなたがきょう、わたしを離れて、去って行くとき、ベニヤミンの領地のゼルザにあるラケルの墓のかたわらで、ふたりの人に会うでしょう。そして彼らはあなたに言います、『あなたが捜しに行かれたろばは見つかりました。いま父上は、ろばよりもあなたがたの事を心配して、「わが子のことは、どうしよう」と言っておられます』。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 35:3; 創世記 35:1; 創世記 28:22"> あなたが、そこからなお進んで、タボルのかしの木の所へ行くと、そこでベテルに上って神を拝もうとする三人の者に会うでしょう。ひとりは三頭の子やぎを連れ、ひとりは三つのパンを携え、ひとりは、ぶどう酒のはいった皮袋一つを携えている。</span>
<span className="v" id="v4" data-v="4" data-xref="士師記 18:15"> 彼らはあなたにあいさつし、二つのパンをくれるでしょう。あなたはそれを、その手から受けなければならない。</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀下 3:15; サムエル記上 13:3; サムエル記上 19:20"> その後、あなたは神のギベアへ行く。そこはペリシテびとの守備兵のいる所である。あなたはその所へ行って、町にはいる時、立琴、手鼓、笛、琴を執る人々を先に行かせて、預言しながら高き所から降りてくる一群の預言者に会うでしょう。</span>
<span className="v" id="v6" data-v="6" data-xref="サムエル記上 10:10; サムエル記上 19:23–24; 民数記 11:25"> その時、主の霊があなたの上にもはげしく下って、あなたは彼らと一緒に預言し、変って新しい人となるでしょう。</span>
<span className="v" id="v7" data-v="7" data-xref="士師記 6:12; ヨシュア記 1:5; イザヤ書 7:14"> これらのしるしが、あなたの身に起ったならば、あなたは手当たりしだいになんでもしなさい。神があなたと一緒におられるからです。</span>
<span className="v" id="v8" data-v="8" data-xref="サムエル記上 11:14–15; サムエル記上 13:4; サムエル記上 13:8–15"> あなたはわたしに先立ってギルガルに下らなければならない。わたしはあなたのもとに下っていって、燔祭を供え、酬恩祭をささげるでしょう。わたしがあなたのもとに行って、あなたのしなければならない事をあなたに示すまで、七日のあいだ待たなければならない」。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="イザヤ書 38:7–8; サムエル記上 10:2–6; 士師記 7:11"> サウルが背をかえしてサムエルを離れたとき、神は彼に新しい心を与えられた。これらのしるしは皆その日に起った。</span>
<span className="v" id="v10" data-v="10" data-xref="サムエル記上 10:5–6; サムエル記上 19:20–24"> 彼らはギベアにきた時、預言者の一群に出会った。そして神の霊が、はげしくサウルの上に下り、彼は彼らのうちにいて預言した。</span>
<span className="v" id="v11" data-v="11" data-xref="サムエル記上 19:24; ヨハネによる福音書 7:15; マタイによる福音書 13:54–55"> もとからサウルを知っていた人々はみな、サウルが預言者たちと共に預言するのを見て互に言った、「キシの子に何事が起ったのか。サウルもまた預言者たちのうちにいるのか」。</span>
<span className="v" id="v12" data-v="12" data-xref="イザヤ書 54:13; ヨハネによる福音書 6:45; ヤコブの手紙 1:17"> その所のひとりの者が答えた、「彼らの父はだれなのか」。それで「サウルもまた預言者たちのうちにいるのか」というのが、ことわざとなった。</span>
<span className="v" id="v13" data-v="13"> サウルは預言することを終えて、高き所へ行った。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="サムエル記上 14:50; 列王紀下 5:25; サムエル記上 9:3–10"> サウルのおじが、サウルとそのしもべとに言った、「あなたがたは、どこへ行ったのか」。サウルは言った、「ろばを捜しにいったのですが、どこにもいないので、サムエルのもとに行きました」。</span>
<span className="v" id="v15" data-v="15"> サウルのおじは言った、「サムエルが、どんなことを言ったか、どうぞ話してください」。</span>
<span className="v" id="v16" data-v="16" data-xref="箴言 29:11; 士師記 14:6; サムエル記上 9:20"> サウルはおじに言った、「ろばが見つかったと、はっきり、わたしたちに言いました」。しかしサムエルが言った王国のことについて、おじには何も告げなかった。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="士師記 20:1; サムエル記上 7:5–6"> さて、サムエルは民をミヅパで主の前に集め、</span>
<span className="v" id="v18" data-v="18" data-xref="士師記 6:8–9; ネヘミヤ書 9:27–28; 士師記 2:1"> イスラエルの人々に言った、「イスラエルの神、主はこう仰せられる、『わたしはイスラエルをエジプトから導き出し、あなたがたをエジプトびとの手、およびすべてあなたがたをしえたげる王国の手から救い出した』。</span>
<span className="v" id="v19" data-v="19" data-xref="サムエル記上 12:12; サムエル記上 8:19; ヨシュア記 24:1"> しかしあなたがたは、きょう、あなたがたをその悩みと苦しみの中から救われるあなたがたの神を捨て、その上、『いいえ、われわれの上に王を立てよ』と言う。それゆえ今、あなたがたは、部族にしたがい、また氏族にしたがって、主の前に出なさい」。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="ヨシュア記 7:16–18; 使徒行伝 1:24–26; サムエル記上 14:41"> こうしてサムエルがイスラエルのすべての部族を呼び寄せた時、ベニヤミンの部族が、くじに当った。</span>
<span className="v" id="v21" data-v="21"> またベニヤミンの部族をその氏族にしたがって呼び寄せた時、マテリの氏族が、くじに当り、マテリの氏族を人ごとに呼び寄せた時、キシの子サウルが、くじに当った。しかし人々が彼を捜した時、見つからなかった。</span>
<span className="v" id="v22" data-v="22" data-xref="民数記 27:21; 士師記 20:18; サムエル記上 23:2–4"> そこでまた主に「その人はここにきているのですか」と問うと、主は言われた、「彼は荷物の間に隠れている」。</span>
<span className="v" id="v23" data-v="23" data-xref="サムエル記上 9:2; サムエル記上 16:7; サムエル記上 17:4"> 人々は走って行って、彼をそこから連れてきた。彼は民の中に立ったが、肩から上は、民のどの人よりも高かった。</span>
<span className="v" id="v24" data-v="24" data-xref="列王紀上 1:25; 列王紀上 1:39; サムエル記下 21:6"> サムエルはすべての民に言った、「主が選ばれた人をごらんなさい。民のうちに彼のような人はないではありませんか」。民はみな「王万歳」と叫んだ。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="サムエル記上 8:11–18; 申命記 17:14–20; ローマ人への手紙 13:1–7"> その時サムエルは王国のならわしを民に語り、それを書にしるして、主の前におさめた。こうしてサムエルはすべての民をそれぞれ家に帰らせた。</span>
<span className="v" id="v26" data-v="26" data-xref="サムエル記上 11:4; ヨシュア記 18:28; サムエル記上 15:34"> サウルもまたギベアにある彼の家に帰った。そして神にその心を動かされた勇士たちも彼と共に行った。</span>
<span className="v" id="v27" data-v="27" data-xref="申命記 13:13; 歴代志下 17:5; 列王紀上 10:25"> しかし、よこしまな人々は「この男がどうしてわれわれを救うことができよう」と言って、彼を軽んじ、贈り物をしなかった。しかしサウルは黙っていた。</span>
</div>

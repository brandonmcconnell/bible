<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="サムエル記上 9:16; サムエル記上 12:14; 詩篇 2:10–11"> さて、サムエルはサウルに言った、「主は、わたしをつかわし、あなたに油をそそいで、その民イスラエルの王とされました。それゆえ、今、主の言葉を聞きなさい。</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 25:17–19; 出エジプト記 17:8–16; 民数記 24:20"> 万軍の主は、こう仰せられる、『わたしは、アマレクがイスラエルにした事、すなわちイスラエルがエジプトから上ってきた時、その途中で敵対したことについて彼らを罰するであろう。</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 20:16–18; 民数記 24:20; 民数記 31:17"> 今、行ってアマレクを撃ち、そのすべての持ち物を滅ぼしつくせ。彼らをゆるすな。男も女も、幼な子も乳飲み子も、牛も羊も、らくだも、ろばも皆、殺せ』」。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="ヨシュア記 15:24; サムエル記上 11:8; サムエル記上 13:15"> サウルは民を呼び集め、テライムで人数を調べたところ、歩兵は二十万、ユダの人は一万であった。</span>
<span className="v" id="v5" data-v="5"> そしてサウルはアマレクの町へ行って、谷に兵を伏せた。</span>
<span className="v" id="v6" data-v="6" data-xref="士師記 1:16; 民数記 10:29–32; 出エジプト記 18:19"> サウルはケニびとに言った、「さあ、あなたがたはアマレクびとを離れて、下っていってください。彼らと一緒にあなたがたを滅ぼすようなことがあってはならない。あなたがたは、イスラエルの人々がエジプトから上ってきた時、親切にしてくれたのですから」。そこでケニびとはアマレクびとを離れて行った。</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 16:7; 創世記 25:18; サムエル記上 14:48"> サウルはアマレクびとを撃って、ハビラからエジプトの東にあるシュルにまで及んだ。</span>
<span className="v" id="v8" data-v="8" data-xref="サムエル記上 30:1; エステル記 3:1; 民数記 24:7"> そしてアマレクびとの王アガグをいけどり、つるぎをもってその民をことごとく滅ぼした。</span>
<span className="v" id="v9" data-v="9" data-xref="サムエル記上 15:15; サムエル記上 15:19; サムエル記上 15:3"> しかしサウルと民はアガグをゆるし、また羊と牛の最も良いもの、肥えたものならびに小羊と、すべての良いものを残し、それらを滅ぼし尽すことを好まず、ただ値うちのない、つまらない物を滅ぼし尽した。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10"> その時、主の言葉がサムエルに臨んだ、</span>
<span className="v" id="v11" data-v="11" data-xref="サムエル記上 13:13; 創世記 6:6; サムエル記下 24:16"> 「わたしはサウルを王としたことを悔いる。彼がそむいて、わたしに従わず、わたしの言葉を行わなかったからである」。サムエルは怒って、夜通し、主に呼ばわった。</span>
<span className="v" id="v12" data-v="12" data-xref="ヨシュア記 15:55; サムエル記下 18:18; サムエル記上 25:2"> そして朝サウルに会うため、早く起きたが、サムエルに告げる人があった、「サウルはカルメルにきて、自分のために戦勝記念碑を建て、身をかえして進み、ギルガルへ下って行きました」。</span>
<span className="v" id="v13" data-v="13" data-xref="士師記 17:2; ルツ記 3:10; 箴言 31:31"> サムエルがサウルのもとへ来ると、サウルは彼に言った、「どうぞ、主があなたを祝福されますように。わたしは主の言葉を実行しました」。</span>
<span className="v" id="v14" data-v="14" data-xref="マラキ書 3:13–15; エレミヤ書 2:18–19; エレミヤ書 2:34–37"> サムエルは言った、「それならば、わたしの耳にはいる、この羊の声と、わたしの聞く牛の声は、いったい、なんですか」。</span>
<span className="v" id="v15" data-v="15" data-xref="サムエル記上 15:21; サムエル記上 15:9; 出エジプト記 32:22–23"> サウルは言った、「人々がアマレクびとの所から引いてきたのです。民は、あなたの神、主にささげるために、羊と牛の最も良いものを残したのです。そのほかは、われわれが滅ぼし尽しました」。</span>
<span className="v" id="v16" data-v="16" data-xref="サムエル記上 9:27; 列王紀上 22:16; サムエル記上 12:7"> サムエルはサウルに言った、「おやめなさい。昨夜、主がわたしに言われたことを、あなたに告げましょう」。サウルは彼に言った、「言ってください」。</span>
</div>
<div className="bp poetry">
<span className="v" id="v17" data-v="17" data-xref="サムエル記上 10:22; サムエル記上 9:21; サムエル記上 15:1–3"> サムエルは言った、「たとい、自分では小さいと思っても、あなたはイスラエルの諸部族の長ではありませんか。主はあなたに油を注いでイスラエルの王とされた。</span>
<span className="v" id="v18" data-v="18" data-xref="箴言 10:29; 創世記 13:13; 創世記 15:16"> そして主はあなたに使命を授け、つかわして言われた、『行って、罪びとなるアマレクびとを滅ぼし尽せ。彼らを皆殺しにするまで戦え』。</span>
<span className="v" id="v19" data-v="19" data-xref="サムエル記上 14:32; 歴代志下 33:6; 歴代志下 36:12"> それであるのに、どうしてあなたは主の声に聞き従わないで、ぶんどり物にとびかかり、主の目の前に悪をおこなったのですか」。</span>
<span className="v" id="v20" data-v="20" data-xref="サムエル記上 15:13; マタイによる福音書 19:20; ローマ人への手紙 10:3"> サウルはサムエルに言った、「わたしは主の声に聞き従い、主がつかわされた使命を帯びて行き、アマレクの王アガグを連れてきて、アマレクびとを滅ぼし尽しました。</span>
<span className="v" id="v21" data-v="21" data-xref="サムエル記上 15:15; 出エジプト記 32:22–23; 創世記 3:13"> しかし民は滅ぼし尽すべきもののうち最も良いものを、ギルガルで、あなたの神、主にささげるため、ぶんどり物のうちから羊と牛を取りました」。</span>
<span className="v" id="v22" data-v="22" data-xref="ホセア書 6:6; 詩篇 51:16–17; 箴言 21:3"> サムエルは言った、<br /><span className="pl pl-1">「主はそのみ言葉に聞き従う事を喜ばれるように、</span><br /><span className="pl pl-1">燔祭や犠牲を喜ばれるであろうか。</span><br /><span className="pl pl-1">見よ、従うことは犠牲にまさり、</span><br /><span className="pl pl-1">聞くことは雄羊の脂肪にまさる。</span></span>
<span className="v" id="v23" data-v="23" data-xref="エレミヤ書 28:16; サムエル記上 13:14; レビ記 20:6"> <span className="pl pl-1">そむくことは占いの罪に等しく、</span><br /><span className="pl pl-1">強情は偶像礼拝の罪に等しいからである。</span><br /><span className="pl pl-1">あなたが主のことばを捨てたので、</span><br /><span className="pl pl-1">主もまたあなたを捨てて、王の位から退けられた」。</span></span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="サムエル記下 12:13; イザヤ書 51:12–13; 民数記 22:34"> サウルはサムエルに言った、「わたしは主の命令とあなたの言葉にそむいて罪を犯しました。民を恐れて、その声に聞き従ったからです。</span>
<span className="v" id="v25" data-v="25" data-xref="出エジプト記 10:17"> どうぞ、今わたしの罪をゆるし、わたしと一緒に帰って、主を拝ませてください」。</span>
<span className="v" id="v26" data-v="26" data-xref="ホセア書 4:6; サムエル記上 13:14; サムエル記上 16:1"> サムエルはサウルに言った、「あなたと一緒に帰りません。あなたが主の言葉を捨てたので、主もあなたを捨てて、イスラエルの王位から退けられたからです」。</span>
<span className="v" id="v27" data-v="27" data-xref="列王紀上 11:30–31"> こうしてサムエルが去ろうとして身をかえした時、サウルがサムエルの上着のすそを捕えたので、それは裂けた。</span>
<span className="v" id="v28" data-v="28" data-xref="サムエル記上 28:17–18; 使徒行伝 13:22; ダニエル書 4:32"> サムエルは彼に言った、「主はきょう、あなたからイスラエルの王国を裂き、もっと良いあなたの隣人に与えられた。</span>
<span className="v" id="v29" data-v="29" data-xref="エゼキエル書 24:14; 民数記 23:19; テトスヘの手紙 1:2"> またイスラエルの栄光は偽ることもなく、悔いることもない。彼は人ではないから悔いることはない」。</span>
<span className="v" id="v30" data-v="30" data-xref="ヨハネによる福音書 5:44; ヨハネによる福音書 12:43; イザヤ書 29:13"> サウルは言った、「わたしは罪を犯しましたが、どうぞ、民の長老たち、およびイスラエルの前で、わたしを尊び、わたしと一緒に帰って、あなたの神、主を拝ませてください」。</span>
<span className="v" id="v31" data-v="31"> そこでサムエルはサウルのあとについて帰った。そしてサウルは主を拝んだ。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="ヨハネの黙示録 18:7; テサロニケ人への第一の手紙 5:3; エレミヤ書 48:44"> 時にサムエルは言った、「わたしの所にアマレクびとの王アガグを引いてきなさい」。アガグはうれしそうにサムエルの所にきた。アガグは「死の苦しみはきっと過ぎ去ったのだ」と思った。</span>
<span className="v" id="v33" data-v="33" data-xref="士師記 1:7; 創世記 9:6; マタイによる福音書 7:2"> サムエルは言った、「あなたのつるぎは多くの女に子供を失わせた。そのようにあなたの母も女のうちで最も無惨に子供を失う者となるであろう」。サムエルはギルガルで主の前に、アガグを寸断した。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="サムエル記上 11:4; サムエル記上 7:17"> そしてサムエルはラマに行き、サウルは故郷のギベアに上って、その家に帰った。</span>
<span className="v" id="v35" data-v="35" data-xref="サムエル記上 15:11; サムエル記上 19:24; サムエル記上 16:1"> サムエルは死ぬ日まで、二度とサウルを見なかった。しかしサムエルはサウルのために悲しんだ。また主はサウルをイスラエルの王としたことを悔いられた。</span>
</div>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="アモス書 8:11–12; 詩篇 74:9; サムエル記上 3:21"> わらべサムエルは、エリの前で、主に仕えていた。そのころ、主の言葉はまれで、黙示も常ではなかった。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="サムエル記上 4:15; 詩篇 90:10; 創世記 27:1"> さてエリは、しだいに目がかすんで、見ることができなくなり、そのとき自分のへやで寝ていた。</span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 27:4; レビ記 24:2–4; 出エジプト記 27:20–21"> 神のともしびはまだ消えず、サムエルが神の箱のある主の神殿に寝ていた時、</span>
<span className="v" id="v4" data-v="4" data-xref="イザヤ書 6:8; コリント人への第一の手紙 12:6–11; 出エジプト記 3:4"> 主は「サムエルよ、サムエルよ」と呼ばれた。彼は「はい、ここにおります」と言って、</span>
<span className="v" id="v5" data-v="5"> エリの所へ走っていって言った、「あなたがお呼びになりました。わたしは、ここにおります」。しかしエリは言った、「わたしは呼ばない。帰って寝なさい」。彼は行って寝た。</span>
<span className="v" id="v6" data-v="6" data-xref="マタイによる福音書 9:2; サムエル記上 4:16; サムエル記下 18:22"> 主はまたかさねて「サムエルよ、サムエルよ」と呼ばれた。サムエルは起きてエリのもとへ行って言った、「あなたがお呼びになりました。わたしは、ここにおります」。エリは言った、「子よ、わたしは呼ばない。もう一度寝なさい」。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行伝 19:2; エレミヤ書 9:24"> サムエルはまだ主を知らず、主の言葉がまだ彼に現されなかった。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨブ記 33:14–15; コリント人への第一の手紙 13:11–12"> 主はまた三度目にサムエルを呼ばれたので、サムエルは起きてエリのもとへ行って言った、「あなたがお呼びになりました。わたしは、ここにおります」。その時、エリは主がわらべを呼ばれたのであることを悟った。</span>
<span className="v" id="v9" data-v="9" data-xref="出エジプト記 20:19; イザヤ書 6:8; 詩篇 85:8"> そしてエリはサムエルに言った、「行って寝なさい。もしあなたを呼ばれたら、『しもべは聞きます。主よ、お話しください』と言いなさい」。サムエルは行って自分の所で寝た。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="サムエル記上 3:8; サムエル記上 3:4–6"> 主はきて立ち、前のように、「サムエルよ、サムエルよ」と呼ばれたので、サムエルは言った、「しもべは聞きます。お話しください」。</span>
<span className="v" id="v11" data-v="11" data-xref="ハバクク書 1:5; エレミヤ書 19:3; 列王紀下 21:12"> その時、主はサムエルに言われた、「見よ、わたしはイスラエルのうちに一つの事をする。それを聞く者はみな、耳が二つとも鳴るであろう。</span>
<span className="v" id="v12" data-v="12" data-xref="サムエル記上 2:27–36; ゼカリヤ書 1:6; ヨシュア記 23:15"> その日には、わたしが、かつてエリの家について話したことを、はじめから終りまでことごとく、エリに行うであろう。</span>
<span className="v" id="v13" data-v="13" data-xref="箴言 19:18; マタイによる福音書 10:37; サムエル記上 2:12"> わたしはエリに、彼が知っている悪事のゆえに、その家を永久に罰することを告げる。その子らが神をけがしているのに、彼がそれをとめなかったからである。</span>
<span className="v" id="v14" data-v="14" data-xref="イザヤ書 22:14; サムエル記上 2:25; エレミヤ書 15:1"> それゆえ、わたしはエリの家に誓う。エリの家の悪は、犠牲や供え物をもってしても、永久にあがなわれないであろう」。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="エレミヤ書 1:6–8; マラキ書 1:10; サムエル記上 1:9"> サムエルは朝まで寝て、主の宮の戸をあけたが、サムエルはその幻のことをエリに語るのを恐れた。</span>
<span className="v" id="v16" data-v="16"> しかしエリはサムエルを呼んで言った、「わが子サムエルよ」。サムエルは言った、「はい、ここにおります」。</span>
<span className="v" id="v17" data-v="17" data-xref="サムエル記下 3:35; ルツ記 1:17; 詩篇 141:5"> エリは言った、「何事をお告げになったのか。隠さず話してください。もしお告げになったことを一つでも隠して、わたしに言わないならば、どうぞ神があなたを罰し、さらに重く罰せられるように」。</span>
<span className="v" id="v18" data-v="18" data-xref="ヨブ記 2:10; イザヤ書 39:8; 士師記 10:15"> そこでサムエルは、その事をことごとく話して、何も彼に隠さなかった。エリは言った、「それは主である。どうぞ主が、良いと思うことを行われるように」。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="創世記 39:2; サムエル記上 9:6; 列王紀上 8:56"> サムエルは育っていった。主が彼と共におられて、その言葉を一つも地に落ちないようにされたので、</span>
<span className="v" id="v20" data-v="20" data-xref="士師記 20:1; サムエル記下 3:10; テモテヘの第一の手紙 1:12"> ダンからベエルシバまで、イスラエルのすべての人は、サムエルが主の預言者と定められたことを知った。</span>
<span className="v" id="v21" data-v="21" data-xref="サムエル記上 3:1; 創世記 12:7; サムエル記上 3:4"> 主はふたたびシロで現れられた。すなわち主はシロで、主の言葉によって、サムエルに自らを現された。こうしてサムエルの言葉は、あまねくイスラエルの人々に及んだ。</span>
</div>

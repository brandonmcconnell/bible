<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命記 16:18–19; テモテヘの第一の手紙 5:21; ネヘミヤ書 7:2"> サムエルは年老いて、その子らをイスラエルのさばきづかさとした。</span>
<span className="v" id="v2" data-v="2" data-xref="歴代志上 6:38; 創世記 22:19; 歴代志上 6:28"> 長子の名はヨエルといい、次の子の名はアビヤと言った。彼らはベエルシバでさばきづかさであった。</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 16:19; 詩篇 15:5; テモテヘの第一の手紙 6:10"> しかしその子らは父の道を歩まないで、利にむかい、まいないを取って、さばきを曲げた。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="サムエル記上 7:17; サムエル記下 5:3; 出エジプト記 3:16"> この時、イスラエルの長老たちはみな集まってラマにおるサムエルのもとにきて、</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 17:14–15; ホセア書 13:10–11; サムエル記上 8:6–8"> 言った、「あなたは年老い、あなたの子たちはあなたの道を歩まない。今ほかの国々のように、われわれをさばく王を、われわれのために立ててください」。</span>
<span className="v" id="v6" data-v="6" data-xref="サムエル記上 15:11; ヤコブの手紙 1:5; サムエル記上 12:17"> しかし彼らが、「われわれをさばく王を、われわれに与えよ」と言うのを聞いて、サムエルは喜ばなかった。そしてサムエルが主に祈ると、</span>
<span className="v" id="v7" data-v="7" data-xref="ルカによる福音書 10:16; サムエル記上 10:19; 出エジプト記 16:8"> 主はサムエルに言われた、「民が、すべてあなたに言う所の声に聞き従いなさい。彼らが捨てるのはあなたではなく、わたしを捨てて、彼らの上にわたしが王であることを認めないのである。</span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 106:34–40; 出エジプト記 32:1; 士師記 13:1"> 彼らは、わたしがエジプトから連れ上った日から、きょうまで、わたしを捨ててほかの神々に仕え、さまざまの事をわたしにしたように、あなたにもしているのである。</span>
<span className="v" id="v9" data-v="9" data-xref="サムエル記上 10:25; サムエル記上 8:11–18; エゼキエル書 46:18"> 今その声に聞き従いなさい。ただし、深く彼らを戒めて、彼らを治める王のならわしを彼らに示さなければならない」。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10"> サムエルは王を立てることを求める民に主の言葉をことごとく告げて、</span>
<span className="v" id="v11" data-v="11" data-xref="サムエル記上 14:52; 申命記 17:14–20; サムエル記上 10:25"> 言った、「あなたがたを治める王のならわしは次のとおりである。彼はあなたがたのむすこを取って、戦車隊に入れ、騎兵とし、自分の戦車の前に走らせるであろう。</span>
<span className="v" id="v12" data-v="12" data-xref="サムエル記上 22:7; 列王紀上 4:7; 歴代志上 27:1–22"> 彼はまたそれを千人の長、五十人の長に任じ、またその地を耕させ、その作物を刈らせ、またその武器と戦車の装備を造らせるであろう。</span>
<span className="v" id="v13" data-v="13"> また、あなたがたの娘を取って、香をつくる者とし、料理をする者とし、パンを焼く者とするであろう。</span>
<span className="v" id="v14" data-v="14" data-xref="エゼキエル書 46:18; 列王紀上 21:7; 列王紀上 21:19"> また、あなたがたの畑とぶどう畑とオリブ畑の最も良い物を取って、その家来に与え、</span>
<span className="v" id="v15" data-v="15" data-xref="ダニエル書 1:3; イザヤ書 39:7; 創世記 37:36"> あなたがたの穀物と、ぶどう畑の、十分の一を取って、その役人と家来に与え、</span>
<span className="v" id="v16" data-v="16"> また、あなたがたの男女の奴隷および、あなたがたの最も良い牛とろばを取って、自分のために働かせ、</span>
<span className="v" id="v17" data-v="17"> また、あなたがたの羊の十分の一を取り、あなたがたは、その奴隷となるであろう。</span>
<span className="v" id="v18" data-v="18" data-xref="ミカ書 3:4; イザヤ書 1:15; 箴言 1:25–28"> そしてその日あなたがたは自分のために選んだ王のゆえに呼ばわるであろう。しかし主はその日にあなたがたに答えられないであろう」。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="エレミヤ書 44:16; エレミヤ書 7:13; イザヤ書 66:4"> ところが民はサムエルの声に聞き従うことを拒んで言った、「いいえ、われわれを治める王がなければならない。</span>
<span className="v" id="v20" data-v="20" data-xref="サムエル記上 8:5; 詩篇 106:35; 申命記 7:6"> われわれも他の国々のようになり、王がわれわれをさばき、われわれを率いて、われわれの戦いにたたかうのである」。</span>
<span className="v" id="v21" data-v="21" data-xref="士師記 11:11"> サムエルは民の言葉をことごとく聞いて、それを主の耳に告げた。</span>
<span className="v" id="v22" data-v="22" data-xref="サムエル記上 8:7; ホセア書 13:11"> 主はサムエルに言われた、「彼らの声に聞き従い、彼らのために王を立てよ」。サムエルはイスラエルの人々に言った、「あなたがたは、めいめいその町に帰りなさい」。</span>
</div>

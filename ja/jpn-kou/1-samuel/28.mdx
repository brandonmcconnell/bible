<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="サムエル記上 17:1; サムエル記上 29:1–3; サムエル記上 7:7"> そのころ、ペリシテびとがイスラエルと戦おうとして、いくさのために軍勢を集めたので、アキシはダビデに言った、「あなたは、しかと承知してください。あなたとあなたの従者たちとは、わたしと共に出て、軍勢に加わらなければなりません」。</span>
<span className="v" id="v2" data-v="2" data-xref="ローマ人への手紙 12:9; サムエル記下 16:16–19; サムエル記上 27:10"> ダビデはアキシに言った、「よろしい、あなたはしもべが何をするかを知られるでしょう」。アキシはダビデに言った、「よろしい、あなたを終身わたしの護衛の長としよう」。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="レビ記 19:31; サムエル記上 25:1; レビ記 20:27"> さてサムエルはすでに死んで、イスラエルのすべての人は彼のために悲しみ、その町ラマに葬った。また先にサウルは口寄せや占い師をその地から追放した。</span>
<span className="v" id="v4" data-v="4" data-xref="サムエル記上 31:1; ヨシュア記 19:18; 列王紀下 4:8"> ペリシテびとが集まってきてシュネムに陣を取ったので、サウルはイスラエルのすべての人を集めて、ギルボアに陣を取った。</span>
<span className="v" id="v5" data-v="5" data-xref="イザヤ書 57:20–21; ダニエル書 5:6; イザヤ書 21:3–4"> サウルはペリシテびとの軍勢を見て恐れ、その心はいたくおののいた。</span>
<span className="v" id="v6" data-v="6" data-xref="民数記 12:6; サムエル記上 14:37; 哀歌 2:9"> そこでサウルは主に伺いをたてたが、主は夢によっても、ウリムによっても、預言者によっても彼に答えられなかった。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行伝 16:16; ヨシュア記 17:11; 歴代志上 10:13"> サウルはしもべたちに言った、「わたしのために、口寄せの女を捜し出しなさい。わたしは行ってその女に尋ねよう」。しもべたちは彼に言った、「見よ、エンドルにひとりの口寄せがいます」。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="イザヤ書 8:19; 歴代志上 10:13; 列王紀上 22:30"> サウルは姿を変えてほかの着物をまとい、ふたりの従者を伴って行き、夜の間に、その女の所にきた。そしてサウルは言った、「わたしのために口寄せの術を行って、わたしがあなたに告げる人を呼び起してください」。</span>
<span className="v" id="v9" data-v="9" data-xref="サムエル記上 28:3; 列王紀下 5:7; サムエル記下 18:13"> 女は彼に言った、「あなたはサウルがしたことをごぞんじでしょう。彼は口寄せや占い師をその国から断ち滅ぼしました。どうしてあなたは、わたしの命にわなをかけて、わたしを死なせようとするのですか」。</span>
<span className="v" id="v10" data-v="10" data-xref="サムエル記下 14:11; サムエル記上 19:6; 申命記 18:10–12"> サウルは主をさして彼女に誓って言った、「主は生きておられる。この事のためにあなたが罰を受けることはないでしょう」。</span>
<span className="v" id="v11" data-v="11"> 女は言った、「あなたのためにだれを呼び起しましょうか」。サウルは言った、「サムエルを呼び起してください」。</span>
<span className="v" id="v12" data-v="12" data-xref="サムエル記上 28:3; 列王紀上 14:5"> 女はサムエルを見た時、大声で叫んだ。そしてその女はサウルに言った、「どうしてあなたはわたしを欺かれたのですか。あなたはサウルです」。</span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 82:6–7; ヨハネによる福音書 10:34–35; 出エジプト記 22:28"> 王は彼女に言った、「恐れることはない。あなたには何が見えるのですか」。女はサウルに言った、「神のようなかたが地からのぼられるのが見えます」。</span>
<span className="v" id="v14" data-v="14" data-xref="サムエル記上 15:27; 列王紀下 2:8; サムエル記上 24:8"> サウルは彼女に言った、「その人はどんな様子をしていますか」。彼女は言った、「ひとりの老人がのぼってこられます。その人は上着をまとっておられます」。サウルはその人がサムエルであるのを知り、地にひれ伏して拝した。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="ルカによる福音書 16:23–26; サムエル記上 28:6; サムエル記上 18:12"> サムエルはサウルに言った、「なぜ、わたしを呼び起して、わたしを煩わすのか」。サウルは言った、「わたしは、ひじょうに悩んでいます。ペリシテびとがわたしに向かっていくさを起し、神はわたしを離れて、預言者によっても、夢によっても、もはやわたしに答えられないのです。それで、わたしのすべきことを知るために、あなたを呼びました」。</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀下 6:27; 哀歌 2:5; 詩篇 68:1–3"> サムエルは言った、「主があなたを離れて、あなたの敵となられたのに、どうしてあなたはわたしに問うのですか。</span>
<span className="v" id="v17" data-v="17" data-xref="サムエル記上 15:27–29; サムエル記上 16:13; サムエル記上 13:13–14"> 主は、わたしによって語られたとおりにあなたに行われた。主は王国を、あなたの手から裂きはなして、あなたの隣人であるダビデに与えられた。</span>
<span className="v" id="v18" data-v="18" data-xref="サムエル記上 15:9; 列王紀上 20:42; 詩篇 50:21–22"> あなたは主の声に聞き従わず、主の激しい怒りに従って、アマレクびとを撃ち滅ぼさなかったゆえに、主はこの事を、この日、あなたに行われたのである。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行伝 5:5; エレミヤ書 28:16–17; 列王紀上 22:20"> 主はまたイスラエルをも、あなたと共に、ペリシテびとの手に渡されるであろう。あすは、あなたもあなたの子らもわたしと一緒になるであろう。また主はイスラエルの軍勢をもペリシテびとの手に渡される」。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="サムエル記上 28:5; ヨブ記 26:2; ヨブ記 15:20–24"> そのときサウルは、ただちに、地に伸び、倒れ、サムエルの言葉のために、ひじょうに恐れ、またその力はうせてしまった。その一日一夜、食物をとっていなかったからである。</span>
<span className="v" id="v21" data-v="21" data-xref="士師記 12:3; ヨブ記 13:14; サムエル記上 19:5"> 女はサウルのもとにきて、彼のおののいているのを見て言った、「あなたのつかえめは、あなたの声に聞き従い、わたしの命をかけて、あなたの言われた言葉に従いました。</span>
<span className="v" id="v22" data-v="22"> それゆえ今あなたも、つかえめの声に聞き従い、一口のパンをあなたの前にそなえさせてください。あなたはそれをめしあがって力をつけ、道を行ってください」。</span>
<span className="v" id="v23" data-v="23" data-xref="列王紀上 21:4; ルカによる福音書 24:29; ルカによる福音書 14:23"> ところがサウルは断って言った、「わたしは食べません」。しかし彼のしもべたちも、その女もしいてすすめたので、サウルはその言葉を聞きいれ、地から起きあがり、床の上にすわった。</span>
<span className="v" id="v24" data-v="24" data-xref="ルカによる福音書 15:23; 創世記 18:7–8"> その女は家に肥えた子牛があったので、急いでそれをほふり、また麦粉をとり、こねて、種入れぬパンを焼き、</span>
<span className="v" id="v25" data-v="25"> サウルとそのしもべたちの前に持ってきたので、彼らは食べた。そして彼らは立ち上がって、その夜のうちに去った。</span>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨシュア記 15:44; ミカ書 6:15; ネヘミヤ書 3:17–18"> さて人々はダビデに告げて言った、「ペリシテびとがケイラを攻めて、打ち場の穀物をかすめています」。</span>
<span className="v" id="v2" data-v="2" data-xref="サムエル記上 23:4; サムエル記下 5:19; サムエル記下 5:23"> そこでダビデは主に問うて言った、「わたしが行って、このペリシテびとを撃ちましょうか」。主はダビデに言われた、「行ってペリシテびとを撃ち、ケイラを救いなさい」。</span>
<span className="v" id="v3" data-v="3" data-xref="エレミヤ書 12:5; 詩篇 11:1; サムエル記上 23:15"> しかしダビデの従者たちは彼に言った、「われわれは、ユダのここにおってさえ、恐れているのに、ましてケイラへ行って、ペリシテびとの軍に当ることができましょうか」。</span>
<span className="v" id="v4" data-v="4" data-xref="士師記 7:7; ヨシュア記 8:7; 列王紀下 3:18"> ダビデが重ねて主に問うたところ、主は彼に答えて言われた、「立って、ケイラへ下りなさい。わたしはペリシテびとをあなたの手に渡します」。</span>
<span className="v" id="v5" data-v="5"> ダビデとその従者たちはケイラへ行って、ペリシテびとと戦い、彼らの家畜を奪いとり、彼らを多く撃ち殺した。こうしてダビデはケイラの住民を救った。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="サムエル記上 22:20; サムエル記上 14:3; サムエル記上 14:18"> アヒメレクの子アビヤタルは、ケイラにいるダビデのもとにのがれてきた時、手にエポデをもって下ってきた。</span>
<span className="v" id="v7" data-v="7" data-xref="サムエル記上 24:4–6; ヨブ記 20:5; サムエル記上 26:8–9"> さてダビデのケイラにきたことがサウルに聞えたので、サウルは言った、「神はわたしの手に彼をわたされた。彼は門と貫の木のある町にはいって、自分で身を閉じこめたからである」。</span>
<span className="v" id="v8" data-v="8"> そこでサウルはすべての民を戦いに呼び集めて、ケイラに下り、ダビデとその従者を攻め囲もうとした。</span>
<span className="v" id="v9" data-v="9" data-xref="サムエル記上 30:7; サムエル記上 23:6; 民数記 27:21"> ダビデはサウルが自分に害を加えようとしているのを知って、祭司アビヤタルに言った、「エポデを持ってきてください」。</span>
<span className="v" id="v10" data-v="10" data-xref="ローマ人への手紙 3:15–16; サムエル記上 23:8; 創世記 18:24"> そしてダビデは言った、「イスラエルの神、主よ、しもべはサウルがケイラにきて、わたしのために、この町を滅ぼそうとしていることを確かに聞きました。</span>
<span className="v" id="v11" data-v="11" data-xref="エレミヤ書 33:3; 詩篇 50:15; マタイによる福音書 7:7–8"> ケイラの人々はわたしを彼の手に渡すでしょうか。しもべの聞いたように、サウルは下ってくるでしょうか。イスラエルの神、主よ、どうぞ、しもべに告げてください」。主は言われた、「彼は下って来る」。</span>
<span className="v" id="v12" data-v="12" data-xref="サムエル記上 23:20; 詩篇 31:8; 詩篇 62:1"> ダビデは言った、「ケイラの人々はわたしと従者たちをサウルの手にわたすでしょうか」。主は言われた、「彼らはあなたがたを渡すであろう」。</span>
<span className="v" id="v13" data-v="13" data-xref="サムエル記上 22:2; サムエル記上 25:13; サムエル記上 30:9–10"> そこでダビデとその六百人ほどの従者たちは立って、ケイラを去り、いずこともなくさまよった。ダビデのケイラから逃げ去ったことがサウルに聞えたので、サウルは戦いに出ることをやめた。</span>
<span className="v" id="v14" data-v="14" data-xref="詩篇 54:3–4; 詩篇 32:7; ヨシュア記 15:24"> ダビデは荒野にある要害におり、またジフの荒野の山地におった。サウルは日々に彼を尋ね求めたが、神は彼をその手に渡されなかった。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15"> さてダビデはサウルが自分の命を求めて出てきたので恐れた。その時ダビデはジフの荒野のホレシにいたが、</span>
<span className="v" id="v16" data-v="16" data-xref="イザヤ書 35:3–4; ヘブル人への手紙 12:12–13; ヨブ記 4:3–4"> サウルの子ヨナタンは立って、ホレシにいるダビデのもとに行き、神によって彼を力づけた。</span>
<span className="v" id="v17" data-v="17" data-xref="サムエル記上 20:31; サムエル記上 24:20; 使徒行伝 28:16"> そしてヨナタンは彼に言った、「恐れるにはおよびません。父サウルの手はあなたに届かないでしょう。あなたはイスラエルの王となり、わたしはあなたの次となるでしょう。このことは父サウルも知っています」。</span>
<span className="v" id="v18" data-v="18" data-xref="サムエル記下 21:7; サムエル記上 20:42; サムエル記上 18:3"> こうして彼らふたりは主の前で契約を結び、ダビデはホレシにとどまり、ヨナタンは家に帰った。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="サムエル記上 26:1; サムエル記上 26:3; 詩篇 54:1–7"> その時ジフびとはギベアにいるサウルのもとに上って行き、そして言った、「ダビデは、荒野の南にあるハキラの丘の上のホレシの要害に隠れて、われわれと共にいるではありませんか。</span>
<span className="v" id="v20" data-v="20" data-xref="サムエル記上 23:12; 箴言 29:26; 箴言 11:23"> それゆえ王よ、あなたが下って行こうという望みのとおり、いま下ってきてください。われわれは彼を王の手に渡します」。</span>
<span className="v" id="v21" data-v="21" data-xref="サムエル記上 22:8; イザヤ書 66:5; ミカ書 3:11"> サウルは言った、「あなたがたはわたしに同情を寄せてくれたのです。どうぞ主があなたがたを祝福されるように。</span>
<span className="v" id="v22" data-v="22" data-xref="ヨブ記 5:13"> あなたがたは行って、なお確かめてください。彼のよく行く所とだれがそこで彼を見たかを見きわめてください。人の語るところによると、彼はひじょうに悪賢いそうだ。</span>
<span className="v" id="v23" data-v="23" data-xref="ローマ人への手紙 3:15–16; マルコによる福音書 14:1; 民数記 10:36"> それで、あなたがたは彼が隠れる隠れ場所をみな見きわめ、確かな知らせをもってわたしの所に帰ってきなさい。その時わたしはあなたがたと共に行きます。もし彼がこの地にいるならば、わたしはユダの氏族をあまねく尋ねて彼を捜しだします」。</span>
<span className="v" id="v24" data-v="24" data-xref="サムエル記上 25:2; ヨシュア記 15:55"> 彼らは立って、サウルに先立ってジフへ行った。<br />さてダビデとその従者たちは荒野の南のアラバにあるマオンの荒野にいた。</span>
<span className="v" id="v25" data-v="25" data-xref="士師記 15:8; サムエル記上 23:28"> そしてサウルとその従者たちはきて彼を捜した。人々がこれをダビデに告げたので、ダビデはマオンの荒野にある岩の所へ下って行った。サウルはこれを聞いて、マオンの荒野にきてダビデを追った。</span>
<span className="v" id="v26" data-v="26" data-xref="詩篇 17:9; コリント人への第二の手紙 1:8; 詩篇 140:1–9"> サウルは山のこちら側を行き、ダビデとその従者たちとは山のむこう側を行った。そしてダビデは急いでサウルからのがれようとした。サウルとその従者たちが、ダビデとその従者たちを囲んで捕えようとしたからである。</span>
<span className="v" id="v27" data-v="27" data-xref="列王紀下 19:9; 詩篇 116:3; 申命記 32:36"> その時、サウルの所に、ひとりの使者がきて言った、「ペリシテびとが国を侵しています。急いできてください」。</span>
<span className="v" id="v28" data-v="28"> そこでサウルはダビデを追うことをやめて帰り、行ってペリシテびとに当った。それで人々は、その所を「のがれの岩」と名づけた。</span>
<span className="v" id="v29" data-v="29" data-xref="歴代志下 20:2; ヨシュア記 15:62; エゼキエル書 47:10"> ダビデはそこから上ってエンゲデの要害にいた。</span>
</div>
</div>

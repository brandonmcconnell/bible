<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="ルカによる福音書 1:46–56; 詩篇 13:5; イザヤ書 12:2–3"> ハンナは祈って言った、<br /><span className="pl pl-1">「わたしの心は主によって喜び、</span><br /><span className="pl pl-1">わたしの力は主によって強められた、</span><br /><span className="pl pl-1">わたしの口は敵をあざ笑う、</span><br /><span className="pl pl-1">あなたの救によってわたしは楽しむからである。</span></span>
<span className="v" id="v2" data-v="2" data-xref="サムエル記下 22:32; イザヤ書 44:6; 詩篇 86:8"> <span className="pl pl-1">主のように聖なるものはない、</span><br /><span className="pl pl-1">あなたのほかには、だれもない、</span><br /><span className="pl pl-1">われわれの神のような岩はない。</span></span>
<span className="v" id="v3" data-v="3" data-xref="箴言 8:13; 列王紀上 8:39; 箴言 24:12"> <span className="pl pl-1">あなたがたは重ねて高慢に語ってはならない、</span><br /><span className="pl pl-1">たかぶりの言葉を口にすることをやめよ。</span><br /><span className="pl pl-1">主はすべてを知る神であって、</span><br /><span className="pl pl-1">もろもろのおこないは主によって量られる。</span></span>
<span className="v" id="v4" data-v="4" data-xref="詩篇 76:3; 詩篇 37:15; 詩篇 46:9"> <span className="pl pl-1">勇士の弓は折れ、</span><br /><span className="pl pl-1">弱き者は力を帯びる。</span></span>
<span className="v" id="v5" data-v="5" data-xref="エレミヤ書 15:9; ルカによる福音書 1:53; 詩篇 113:9"> <span className="pl pl-1">飽き足りた者は食のために雇われ、</span><br /><span className="pl pl-1">飢えたものは、もはや飢えることがない。</span><br /><span className="pl pl-1">うまずめは七人の子を産み、</span><br /><span className="pl pl-1">多くの子をもつ女は孤独となる。</span></span>
<span className="v" id="v6" data-v="6" data-xref="申命記 32:39; イザヤ書 26:19; ヨハネの黙示録 1:18"> <span className="pl pl-1">主は殺し、また生かし、</span><br /><span className="pl pl-1">陰府にくだし、また上げられる。</span></span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 75:7; ヨブ記 5:11; 申命記 8:17–18"> <span className="pl pl-1">主は貧しくし、また富ませ、</span><br /><span className="pl pl-1">低くし、また高くされる。</span></span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 113:7–8; ダニエル書 2:48; ヤコブの手紙 2:5"> <span className="pl pl-1">貧しい者を、ちりのなかから立ちあがらせ、</span><br /><span className="pl pl-1">乏しい者を、あくたのなかから引き上げて、</span><br /><span className="pl pl-1">王侯と共にすわらせ、</span><br /><span className="pl pl-1">栄誉の位を継がせられる。</span><br /><span className="pl pl-1">地の柱は主のものであって、</span><br /><span className="pl pl-1">その柱の上に、世界をすえられたからである。</span></span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 121:3; 詩篇 91:11–12; 詩篇 33:16–17"> <span className="pl pl-1">主はその聖徒たちの足を守られる、</span><br /><span className="pl pl-1">しかし悪いものどもは暗黒のうちに滅びる。</span><br /><span className="pl pl-1">人は力をもって勝つことができないからである。</span></span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 2:9; 詩篇 89:24; 詩篇 18:13–14"> <span className="pl pl-1">主と争うものは粉々に砕かれるであろう、</span><br /><span className="pl pl-1">主は彼らにむかって天から雷をとどろかし、</span><br /><span className="pl pl-1">地のはてまでもさばき、王に力を与え、</span><br /><span className="pl pl-1">油そそがれた者の力を強くされるであろう」。</span></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="サムエル記上 3:1; サムエル記上 2:18; サムエル記上 1:28"> エルカナはラマにある家に帰ったが、幼な子は祭司エリの前にいて主に仕えた。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="ローマ人への手紙 1:28–30; エレミヤ書 2:8; 士師記 2:10"> さて、エリの子らは、よこしまな人々で、主を恐れなかった。</span>
<span className="v" id="v13" data-v="13" data-xref="レビ記 7:29–34"> 民のささげ物についての祭司のならわしはこうである。人が犠牲をささげる時、その肉を煮る間に、祭司のしもべは、みつまたの肉刺しを手に持ってきて、</span>
<span className="v" id="v14" data-v="14" data-xref="出エジプト記 29:27–28; イザヤ書 56:11; サムエル記上 2:29"> それをかま、またはなべ、またはおおがま、または鉢に突きいれ、肉刺しの引き上げるものは祭司がみな自分のものとした。彼らはシロで、そこに来るすべてのイスラエルの人に、このようにした。</span>
<span className="v" id="v15" data-v="15" data-xref="レビ記 3:16; レビ記 3:3–5; ローマ人への手紙 16:18"> 人々が脂肪を焼く前にもまた、祭司のしもべがきて、犠牲をささげる人に言うのであった、「祭司のために焼く肉を与えよ。祭司はあなたから煮た肉を受けない。生の肉がよい」。</span>
<span className="v" id="v16" data-v="16" data-xref="レビ記 7:23–25; レビ記 3:16; ペテロの第一の手紙 5:2–3"> その人が、「まず脂肪を焼かせましょう。その後ほしいだけ取ってください」と言うと、しもべは、「いや、今もらいたい。くれないなら、わたしは力づくで、それを取ろう」と言う。</span>
<span className="v" id="v17" data-v="17" data-xref="マラキ書 2:7–9; 創世記 13:13; マラキ書 2:13"> このように、その若者たちの罪は、主の前に非常に大きかった。この人々が主の供え物を軽んじたからである。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="サムエル記上 3:1; 出エジプト記 28:4; サムエル記上 2:11"> サムエルはまだ幼く、身に亜麻布のエポデを着けて、主の前に仕えていた。</span>
<span className="v" id="v19" data-v="19" data-xref="サムエル記上 1:3; サムエル記上 1:21; 出エジプト記 23:14"> 母は彼のために小さい上着を作り、年ごとに、夫と共にその年の犠牲をささげるために上る時、それを持ってきた。</span>
<span className="v" id="v20" data-v="20" data-xref="サムエル記上 1:27–28; ルカによる福音書 2:34; ルツ記 4:11"> エリはいつもエルカナとその妻を祝福して言った、「この女が主にささげた者のかわりに、主がこの女によってあなたに子を与えられるように」。そして彼らはその家に帰るのを常とした。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="ルカによる福音書 2:40; サムエル記上 3:19; 創世記 21:1"> こうして主がハンナを顧みられたので、ハンナはみごもって、三人の男の子とふたりの女の子を産んだ。わらべサムエルは主の前で育った。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="出エジプト記 38:8; サムエル記上 2:13–17; エレミヤ書 7:9–10"> エリはひじょうに年をとった。そしてその子らがイスラエルの人々にしたいろいろのことを聞き、また会見の幕屋の入口で勤めていた女たちと寝たことを聞いて、</span>
<span className="v" id="v23" data-v="23" data-xref="エレミヤ書 8:12; ピリピ人への手紙 3:19; 使徒行伝 9:4"> 彼らに言った、「なにゆえ、そのようなことをするのか。わたしはこのすべての民から、あなたがたの悪いおこないのことを聞く。</span>
<span className="v" id="v24" data-v="24" data-xref="マラキ書 2:8; テモテヘの第一の手紙 3:7; 使徒行伝 6:3"> わが子らよ、それはいけない。わたしの聞く、主の民の言いふらしている風説は良くない。</span>
<span className="v" id="v25" data-v="25" data-xref="サムエル記上 3:14; ヨシュア記 11:20; ヘブル人への手紙 10:26"> もし人が人に対して罪を犯すならば、神が仲裁されるであろう。しかし人が主に対して罪を犯すならば、だれが、そのとりなしをすることができようか」。しかし彼らは父の言うことに耳を傾けようともしなかった。主が彼らを殺そうとされたからである。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="ルカによる福音書 2:52; ルカによる福音書 2:40; 使徒行伝 2:47"> わらべサムエルは育っていき、主にも、人々にも、ますます愛せられた。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="申命記 33:1; 出エジプト記 4:27; 出エジプト記 4:14–16"> このとき、ひとりの神の人が、エリのもとにきて言った、「主はかく仰せられる、『あなたの先祖の家がエジプトでパロの家の奴隷であったとき、わたしはその先祖の家に自らを現した。</span>
<span className="v" id="v28" data-v="28" data-xref="出エジプト記 28:1; レビ記 8:7–8; 民数記 18:19"> そしてイスラエルのすべての部族のうちからそれを選び出して、わたしの祭司とし、わたしの祭壇に上って、香をたかせ、わたしの前でエポデを着けさせ、また、イスラエルの人々の火祭をことごとくあなたの先祖の家に与えた。</span>
<span className="v" id="v29" data-v="29" data-xref="マタイによる福音書 10:37; 申命記 32:15; サムエル記上 2:13–17"> それにどうしてあなたがたは、わたしが命じた犠牲と供え物をむさぼりの目をもって見るのか。またなにゆえ、わたしよりも自分の子らを尊び、わたしの民イスラエルのささげるもろもろの供え物の、最も良き部分をもって自分を肥やすのか』。</span>
<span className="v" id="v30" data-v="30" data-xref="ヨハネによる福音書 12:26; エレミヤ書 18:9–10; 箴言 3:9–10"> それゆえイスラエルの神、主は仰せられる、『わたしはかつて、「あなたの家とあなたの父の家とは、永久にわたしの前に歩むであろう」と言った』。しかし今、主は仰せられる、『決してそうはしない。わたしを尊ぶ者を、わたしは尊び、わたしを卑しめる者は、軽んぜられるであろう。</span>
<span className="v" id="v31" data-v="31" data-xref="サムエル記上 22:17–20; 列王紀上 2:26–27; 詩篇 37:17"> 見よ、日が来るであろう。その日、わたしはあなたの力と、あなたの父の家の力を断ち、あなたの家に年老いた者をなくするであろう。</span>
<span className="v" id="v32" data-v="32" data-xref="ゼカリヤ書 8:4; サムエル記上 4:11; 詩篇 78:59–64"> そのとき、あなたは災のうちにあって、イスラエルに与えられるもろもろの繁栄を、ねたみ見るであろう。あなたの家には永久に年老いた者がいなくなるであろう。</span>
<span className="v" id="v33" data-v="33" data-xref="列王紀上 2:26–27; 列王紀上 1:7; サムエル記上 22:21–23"> しかしあなたの一族のひとりを、わたしの祭壇から断たないであろう。彼は残されてその目を泣きはらし、心を痛めるであろう。またあなたの家に生れ出るものは、みなつるぎに死ぬであろう。</span>
<span className="v" id="v34" data-v="34" data-xref="サムエル記上 4:11; 列王紀上 13:3; サムエル記上 4:17"> あなたのふたりの子ホフニとピネハスの身に起ることが、あなたのためにそのしるしとなるであろう。すなわちそのふたりは共に同じ日に死ぬであろう。</span>
<span className="v" id="v35" data-v="35" data-xref="サムエル記下 7:27; サムエル記下 7:11; 列王紀上 11:38"> わたしは自分のために、ひとりの忠実な祭司を起す。その人はわたしの心と思いとに従って行うであろう。わたしはその家を確立しよう。その人はわたしが油そそいだ者の前につねに歩むであろう。</span>
<span className="v" id="v36" data-v="36" data-xref="列王紀上 2:27; マラキ書 1:13; エゼキエル書 44:10–12"> そしてあなたの家で生き残っている人々はみなきて、彼に一枚の銀と一個のパンを請い求め、「どうぞ、わたしを祭司の職の一つに任じ、一口のパンでも食べることができるようにしてください」と言うであろう』」。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出エジプト記 12:5; ミカ書 6:6"> サウルは三十歳で王の位につき、二年イスラエルを治めた。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="サムエル記上 10:26; サムエル記上 13:5; サムエル記上 14:31"> さてサウルはイスラエルびと三千を選んだ。二千はサウルと共にミクマシ、およびベテルの山地におり、一千はヨナタンと共にベニヤミンのギベアにいた。サウルはその他の民を、おのおの、その天幕に帰らせた。</span>
<span className="v" id="v3" data-v="3" data-xref="サムエル記上 10:5; 士師記 3:27; 士師記 6:34"> ヨナタンは、ゲバにあるペリシテびとの守備兵を敗った。ペリシテびとはそのことを聞いた。そこで、サウルは国中に、あまねく角笛を吹きならして言わせた、「ヘブルびとよ、聞け」。</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 34:30; 出エジプト記 5:21; ゼカリヤ書 11:8"> イスラエルの人は皆、サウルがペリシテびとの守備兵を敗ったこと、そしてイスラエルがペリシテびとに憎まれるようになったことを聞いた。こうして民は召されて、ギルガルのサウルのもとに集まった。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="サムエル記上 14:23; ヨシュア記 11:4; ヨシュア記 18:12"> ペリシテびとはイスラエルと戦うために集まった。戦車三千、騎兵六千、民は浜べの砂のように多かった。彼らは上ってきて、ベテアベンの東のミクマシに陣を張った。</span>
<span className="v" id="v6" data-v="6" data-xref="士師記 6:2; ヘブル人への手紙 11:38; 士師記 10:9"> イスラエルびとは、ひどく圧迫され、味方が危くなったのを見て、ほら穴に、縦穴に、岩に、墓に、ため池に身を隠した。</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 20:8; レビ記 26:17; 民数記 32:1–5"> また、あるヘブルびとはヨルダンを渡って、ガドとギレアデの地へ行った。しかしサウルはなおギルガルにいて、民はみな、ふるえながら彼に従った。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="サムエル記上 10:8"> サウルは、サムエルが定めたように、七日のあいだ待ったが、サムエルがギルガルにこなかったので、民は彼を離れて散って行った。</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀上 3:4; 箴言 21:27; 箴言 15:8"> そこでサウルは言った、「燔祭と酬恩祭をわたしの所に持ってきなさい」。こうして彼は燔祭をささげた。</span>
<span className="v" id="v10" data-v="10" data-xref="サムエル記上 15:13; ルツ記 2:4; 詩篇 129:8"> その燔祭をささげ終ると、サムエルがきた。サウルはあいさつをしようと、彼を迎えに出た。</span>
<span className="v" id="v11" data-v="11" data-xref="サムエル記上 13:23; サムエル記上 13:5; サムエル記上 13:16"> その時サムエルは言った、「あなたは何をしたのですか」。サウルは言った、「民はわたしを離れて散って行き、あなたは定まった日のうちにこられないのに、ペリシテびとがミクマシに集まったのを見たので、</span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 66:3; アモス書 8:5; コリント人への第二の手紙 9:7"> わたしは、ペリシテびとが今にも、ギルガルに下ってきて、わたしを襲うかも知れないのに、わたしはまだ主の恵みを求めることをしていないと思い、やむを得ず燔祭をささげました」。</span>
<span className="v" id="v13" data-v="13" data-xref="サムエル記上 15:22; 歴代志下 16:9; サムエル記上 15:28"> サムエルはサウルに言った、「あなたは愚かなことをした。あなたは、あなたの神、主の命じられた命令を守らなかった。もし守ったならば、主は今あなたの王国を長くイスラエルの上に確保されたであろう。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行伝 13:22; サムエル記上 15:28; 詩篇 89:19–37"> しかし今は、あなたの王国は続かないであろう。主は自分の心にかなう人を求めて、その人に民の君となることを命じられた。あなたが主の命じられた事を守らなかったからである」。</span>
<span className="v" id="v15" data-v="15" data-xref="サムエル記上 14:2; サムエル記上 13:2; サムエル記上 13:6–7"> こうしてサムエルは立って、ギルガルからベニヤミンのギベアに上っていった。<br />サウルは共にいる民を数えてみたが、おおよそ六百人あった。</span>
<span className="v" id="v16" data-v="16" data-xref="サムエル記上 13:3"> サウルとその子ヨナタン、ならびに、共にいる民は、ベニヤミンのゲバにおり、ペリシテびとはミクマシに陣を張っていた。</span>
<span className="v" id="v17" data-v="17" data-xref="ヨシュア記 18:23; サムエル記上 14:15; ヨシュア記 19:3"> そしてペリシテびとの陣から三つの部隊にわかれた略奪隊が出てきて、一部隊はオフラの方に向かって、シュアルの地に行き、</span>
<span className="v" id="v18" data-v="18" data-xref="ネヘミヤ書 11:34; ヨシュア記 18:13–14; ヨシュア記 16:3"> 一部隊はベテホロンの方に向かい、一部隊は荒野の方のゼボイムの谷を見おろす境の方に向かった。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="列王紀下 24:14; 士師記 5:8; エレミヤ書 24:1"> そのころ、イスラエルの地にはどこにも鉄工がいなかった。ペリシテびとが「ヘブルびとはつるぎも、やりも造ってはならない」と言ったからである。</span>
<span className="v" id="v20" data-v="20"> ただしイスラエルの人は皆、そのすきざき、くわ、おの、かまに刃をつけるときは、ペリシテびとの所へ下って行った。</span>
<span className="v" id="v21" data-v="21"> すきざきと、くわのための料金は一ピムであり、おのに刃をつけるのと、とげのあるむちを直すのは三分の一シケルであった。</span>
<span className="v" id="v22" data-v="22" data-xref="士師記 5:8; ゼカリヤ書 4:6; サムエル記上 17:50"> それでこの戦いの日には、サウルおよびヨナタンと共にいた民の手には、つるぎもやりもなく、ただサウルとその子ヨナタンとがそれを持っていた。</span>
<span className="v" id="v23" data-v="23" data-xref="イザヤ書 10:28; サムエル記上 14:1; サムエル記上 14:4–5"> ペリシテびとの先陣はミクマシの渡りに進み出た。</span>
</div>

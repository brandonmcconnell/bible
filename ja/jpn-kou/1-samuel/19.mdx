<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="サムエル記上 18:1; サムエル記上 18:9"> サウルはその子ヨナタンおよびすべての家来たちにダビデを殺すようにと言った。しかしサウルの子ヨナタンは深くダビデを愛していた。</span>
<span className="v" id="v2" data-v="2" data-xref="箴言 17:17; 使徒行伝 9:24; サムエル記上 18:1–3"> ヨナタンはダビデに言った、「父サウルはあなたを殺そうとしています。それゆえあすの朝、気をつけて、わからない場所に身を隠していてください。</span>
<span className="v" id="v3" data-v="3" data-xref="サムエル記上 20:9; サムエル記上 20:13"> わたしは出て行って、あなたがいる野原で父のかたわらに立ち、父にあなたのことを話しましょう。そして、何かわたしにわかれば、あなたに告げましょう」。</span>
<span className="v" id="v4" data-v="4" data-xref="エレミヤ書 18:20; 箴言 31:8–9; 創世記 42:22"> ヨナタンは父サウルにダビデのことをほめて言った、「王よ、どうか家来ダビデに対して罪を犯さないでください。彼は、あなたに罪を犯さず、また彼のしたことは、あなたのためになることでした。</span>
<span className="v" id="v5" data-v="5" data-xref="サムエル記上 11:13; 歴代志上 11:14; 士師記 9:17"> 彼は命をかけて、あのペリシテびとを殺し、主はイスラエルの人々に大いなる勝利を与えられたのです。あなたはそれを見て喜ばれました。それであるのに、どうしてゆえなくダビデを殺し、罪なき者の血を流して罪を犯そうとされるのですか」。</span>
<span className="v" id="v6" data-v="6" data-xref="箴言 26:24–25; エレミヤ書 5:2; 詩篇 15:4"> サウルはヨナタンの言葉を聞きいれた。そしてサウルは誓った、「主は生きておられる。わたしは決して彼を殺さない」。</span>
<span className="v" id="v7" data-v="7" data-xref="サムエル記上 18:2; サムエル記上 16:21; サムエル記上 18:13"> ヨナタンはダビデを呼んでこれらのことをみなダビデに告げた。そしてヨナタンがダビデをサウルのもとに連れてきたので、ダビデは、もとのようにサウルの前にいた。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="詩篇 27:3; 詩篇 18:32–50"> ところがまた戦争がおこって、ダビデは出てペリシテびとと戦い、大いに彼らを殺したので、彼らはその前から逃げ去った。</span>
<span className="v" id="v9" data-v="9" data-xref="サムエル記上 16:14; サムエル記上 18:10–11; サムエル記上 16:16"> さてサウルが家にいて手にやりを持ってすわっていた時、主から来る悪霊がサウルに臨んだので、ダビデは琴をひいていたが、</span>
<span className="v" id="v10" data-v="10" data-xref="サムエル記上 20:33; サムエル記上 18:11; 箴言 21:30"> サウルはそのやりをもってダビデを壁に刺し通そうとした。しかし彼はサウルの前に身をかわしたので、やりは壁につきささった。そしてダビデは逃げ去った。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="詩篇 59:1–17; 士師記 16:2"> その夜、サウルはダビデの家に使者たちをつかわして見張りをさせ、朝になって彼を殺させようとした。しかしダビデの妻ミカルはダビデに言った、「もし今夜のうちに、あなたが自分の命を救わないならば、あすは殺されるでしょう」。</span>
<span className="v" id="v12" data-v="12" data-xref="ヨシュア記 2:15; 使徒行伝 9:24–25; 詩篇 34:19"> そしてミカルがダビデを窓からつりおろしたので、彼は逃げ去った。</span>
<span className="v" id="v13" data-v="13" data-xref="創世記 31:19; 士師記 18:17; 士師記 18:14"> ミカルは一つの像をとって、寝床の上に横たえ、その頭にやぎの毛の網をかけ、着物をもってそれをおおった。</span>
<span className="v" id="v14" data-v="14" data-xref="ヨシュア記 2:5; サムエル記下 16:17–19; サムエル記下 17:20"> サウルはダビデを捕えるため使者たちをつかわしたが、彼女は言った、「あの人は病気です」。</span>
<span className="v" id="v15" data-v="15" data-xref="箴言 27:3–4; 詩篇 37:12; ヨブ記 31:31"> そこでサウルは、ダビデを見させようと使者たちをつかわして言った、「彼を寝床のまま、わたしの所に連れてきなさい。わたしが彼を殺そう」。</span>
<span className="v" id="v16" data-v="16"> 使者たちがはいって見ると、寝床には像が横たえてあって、その頭には、やぎの毛の網がかけてあった。</span>
<span className="v" id="v17" data-v="17" data-xref="サムエル記下 2:22; サムエル記上 22:17; 出エジプト記 1:17–19"> サウルはミカルに言った、「あなたはどうして、このようにわたしを欺いて、わたしの敵を逃がしたのか」。ミカルはサウルに答えた、「あの人はわたしに『逃がしてくれ。さもないと、おまえを殺す』と言いました」。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="サムエル記上 7:17; 詩篇 116:11; サムエル記上 15:34"> ダビデは逃げ去り、ラマにいるサムエルのもとへ行って、サウルが自分にしたすべてのことを彼に告げた。そしてダビデとサムエルは行ってナヨテに住んだ。</span>
<span className="v" id="v19" data-v="19" data-xref="サムエル記上 23:19; サムエル記上 22:9–10; サムエル記上 26:1"> ある人がサウルに「ダビデはラマのナヨテにいます」と告げたので、</span>
<span className="v" id="v20" data-v="20" data-xref="ヨエル書 2:28; ヨハネによる福音書 7:32; サムエル記上 10:5–6"> サウルは、ダビデを捕えるために、使者たちをつかわした。彼らは預言者の一群が預言していて、サムエルが、そのうちの、かしらとなって立っているのを見たが、その時、神の霊はサウルの使者たちにも臨んで、彼らもまた預言した。</span>
<span className="v" id="v21" data-v="21" data-xref="箴言 27:22; エレミヤ書 13:23; ヨエル書 2:28"> サウルは、このことを聞いて、他の使者たちをつかわしたが、彼らもまた預言した。サウルは三たび使者たちをつかわしたが、彼らもまた預言した。</span>
<span className="v" id="v22" data-v="22"> そこでサウルはみずからラマに行き、セクの大井戸に着いた時、問うて言った、「サムエルとダビデは、どこにおるか」。ひとりの人が答えた、「彼らはラマのナヨテにいます」。</span>
<span className="v" id="v23" data-v="23" data-xref="箴言 16:9; サムエル記上 10:10; サムエル記上 19:20"> そこでサウルはそこからラマのナヨテに行ったが、神の霊はまた彼にも臨んで、彼はラマのナヨテに着くまで歩きながら預言した。</span>
<span className="v" id="v24" data-v="24" data-xref="サムエル記下 6:20; イザヤ書 20:2; ミカ書 1:8"> そして彼もまた着物を脱いで、同じようにサムエルの前で預言し、一日一夜、裸で倒れ伏していた。人々が「サウルもまた預言者たちのうちにいるのか」というのはこのためである。</span>
</div>

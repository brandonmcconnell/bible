<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀下 9:1; サムエル記上 15:23; 詩篇 78:68–71"> さて主はサムエルに言われた、「わたしがすでにサウルを捨てて、イスラエルの王位から退けたのに、あなたはいつまで彼のために悲しむのか。角に油を満たし、それをもって行きなさい。あなたをベツレヘムびとエッサイのもとにつかわします。わたしはその子たちのうちにひとりの王を捜し得たからである」。</span>
<span className="v" id="v2" data-v="2" data-xref="サムエル記上 9:12; サムエル記上 20:29; マタイによる福音書 10:16"> サムエルは言った、「どうしてわたしは行くことができましょう。サウルがそれを聞けば、わたしを殺すでしょう」。主は言われた、「一頭の子牛を引いていって、『主に犠牲をささげるためにきました』と言いなさい。</span>
<span className="v" id="v3" data-v="3" data-xref="サムエル記上 9:16; サムエル記上 16:12–13; サムエル記下 15:11"> そしてエッサイを犠牲の場所に呼びなさい。その時わたしはあなたのすることを示します。わたしがあなたに告げる人に油を注がなければならない」。</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀上 2:13; 歴代志上 12:17–18; サムエル記上 21:1"> サムエルは主が命じられたようにして、ベツレヘムへ行った。町の長老たちは、恐れながら出て、彼を迎え、「穏やかな事のためにこられたのですか」と言った。</span>
<span className="v" id="v5" data-v="5" data-xref="ヨシュア記 3:5; レビ記 20:7–8; 出エジプト記 19:10"> サムエルは言った、「穏やかな事のためです。わたしは主に犠牲をささげるためにきました。身をきよめて、犠牲の場所にわたしと共にきてください」。そしてサムエルはエッサイとその子たちをきよめて犠牲の場に招いた。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="サムエル記上 17:13; 歴代志上 2:13; サムエル記上 17:22"> 彼らがきた時、サムエルはエリアブを見て、「自分の前にいるこの人こそ、主が油をそそがれる人だ」と思った。</span>
<span className="v" id="v7" data-v="7" data-xref="ヨハネによる福音書 7:24; エレミヤ書 17:10; ルカによる福音書 16:15"> しかし主はサムエルに言われた、「顔かたちや身のたけを見てはならない。わたしはすでにその人を捨てた。わたしが見るところは人とは異なる。人は外の顔かたちを見、主は心を見る」。</span>
<span className="v" id="v8" data-v="8" data-xref="サムエル記上 17:13; 歴代志上 2:13"> そこでエッサイはアビナダブを呼んでサムエルの前を通らせた。サムエルは言った、「主が選ばれたのはこの人でもない」。</span>
<span className="v" id="v9" data-v="9" data-xref="サムエル記上 17:13; 歴代志上 2:13; サムエル記下 13:3"> エッサイはシャンマを通らせたが、サムエルは言った、「主が選ばれたのはこの人でもない」。</span>
<span className="v" id="v10" data-v="10" data-xref="歴代志上 2:13–15"> エッサイは七人の子にサムエルの前を通らせたが、サムエルはエッサイに言った、「主が選ばれたのはこの人たちではない」。</span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 78:70–71; サムエル記下 7:8; サムエル記下 13:3"> サムエルはエッサイに言った、「あなたのむすこたちは皆ここにいますか」。彼は言った、「まだ末の子が残っていますが羊を飼っています」。サムエルはエッサイに言った、「人をやって彼を連れてきなさい。彼がここに来るまで、われわれは食卓につきません」。</span>
<span className="v" id="v12" data-v="12" data-xref="哀歌 4:7; 詩篇 89:19–20; 雅歌 5:10"> そこで人をやって彼をつれてきた。彼は血色のよい、目のきれいな、姿の美しい人であった。主は言われた、「立ってこれに油をそそげ。これがその人である」。</span>
<span className="v" id="v13" data-v="13" data-xref="サムエル記上 10:6; ヘブル人への手紙 1:9; ヨハネによる福音書 3:34"> サムエルは油の角をとって、その兄弟たちの中で、彼に油をそそいだ。この日からのち、主の霊は、はげしくダビデの上に臨んだ。そしてサムエルは立ってラマへ行った。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="詩篇 51:11; サムエル記上 18:12; 士師記 9:23"> さて主の霊はサウルを離れ、主から来る悪霊が彼を悩ました。</span>
<span className="v" id="v15" data-v="15"> サウルの家来たちは彼に言った、「ごらんなさい。神から来る悪霊があなたを悩ましているのです。</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀下 3:15; 列王紀上 10:8; サムエル記上 19:9"> どうぞ、われわれの主君が、あなたの前に仕えている家来たちに命じて、じょうずに琴をひく者ひとりを捜させてください。神から来る悪霊があなたに臨む時、彼が手で琴をひくならば、あなたは良くなられるでしょう」。</span>
<span className="v" id="v17" data-v="17"> そこでサウルは家来たちに言った、「じょうずに琴をひく者を捜して、わたしのもとに連れてきなさい」。</span>
<span className="v" id="v18" data-v="18" data-xref="サムエル記上 3:19; 創世記 39:23; 創世記 39:2"> その時、ひとりの若者がこたえた、「わたしはベツレヘムびとエッサイの子を見ましたが、琴がじょうずで、勇気もあり、いくさびとで、弁舌にひいで、姿の美しい人です。また主が彼と共におられます」。</span>
<span className="v" id="v19" data-v="19" data-xref="サムエル記上 16:11; サムエル記上 17:15; 詩篇 78:70–72"> そこでサウルはエッサイのもとに使者をつかわして言った、「羊を飼っているあなたの子ダビデをわたしのもとによこしなさい」。</span>
<span className="v" id="v20" data-v="20" data-xref="サムエル記上 10:27; 箴言 18:16; サムエル記上 17:18"> エッサイは、ろばにパンを負わせ、皮袋にいれたぶどう酒一袋と、やぎの子とを取って、その子ダビデの手によってサウルに送った。</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 41:46; 箴言 22:29; 詩篇 146:3"> ダビデはサウルのもとにきて、彼に仕えた。サウルはひじょうにこれを愛して、その武器を執る者とした。</span>
<span className="v" id="v22" data-v="22"> またサウルは人をつかわしてエッサイに言った、「ダビデをわたしに仕えさせてください。彼はわたしの心にかないました」。</span>
<span className="v" id="v23" data-v="23" data-xref="サムエル記上 16:14–16; サムエル記上 18:10–11; ルカによる福音書 11:24–26"> 神から出る悪霊がサウルに臨む時、ダビデは琴をとり、手でそれをひくと、サウルは気が静まり、良くなって、悪霊は彼を離れた。</span>

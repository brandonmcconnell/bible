<div className="bible-chapter" lang="ja" dir="ltr" data-lang="ja" data-translation="jpn-kou" data-translation-id="jpn_kou" data-translation-label="口語訳" data-book="1SA" data-book-slug="1-samuel" data-book-name="サムエル記上" data-chapter="20" data-verses="42">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ペテロの第二の手紙 2:9; コリント人への第二の手紙 1:12; ヨハネの第一の手紙 3:21"> ダビデはラマのナヨテから逃げてきて、ヨナタンに言った、「わたしが何をし、どのような悪いことがあり、あなたの父の前にどんな罪を犯したので、わたしを殺そうとされるのでしょうか」。</span>
<span className="v" id="v2" data-v="2" data-xref="サムエル記上 9:15; ヨハネによる福音書 17:8; ヨハネによる福音書 15:15"> ヨナタンは彼に言った、「決して殺されることはありません。父は事の大小を問わず、わたしに告げないですることはありません。どうして父がわたしにその事を隠しましょう。そのようなことはありません」。</span>
<span className="v" id="v3" data-v="3" data-xref="サムエル記上 25:26; 申命記 6:13; 列王紀下 2:6"> しかしダビデは答えた、「あなたの父は、わたしがあなたの好意をえていることをよく知っておられます。それで『ヨナタンが悲しむことのないように、これを知らせないでおこう』と思っておられるのです。しかし、主は生きておられ、あなたの魂は生きています。わたしと死との間は、ただ一歩です」。</span>
<span className="v" id="v4" data-v="4"> ヨナタンはダビデに言った、「あなたが言われることはなんでもします」。</span>
<span className="v" id="v5" data-v="5" data-xref="民数記 10:10; サムエル記上 19:2; 民数記 28:11"> ダビデはヨナタンに言った、「あすは、ついたちですから、わたしは王と一緒に食事をしなければなりません。しかしわたしを行かせて三日目の夕方まで、野原に隠れることを許してください。</span>
<span className="v" id="v6" data-v="6" data-xref="サムエル記上 17:58; サムエル記上 9:12; 申命記 12:5"> もしあなたの父がわたしのことを尋ねられるならば、その時、言ってください、『ダビデはふるさとの町ベツレヘムへ急いで行くことを許してくださいと、しきりにわたしに求めました。そこで全家の年祭があるからです』。</span>
<span className="v" id="v7" data-v="7" data-xref="サムエル記上 25:17; エステル記 7:7; 申命記 1:23"> もし彼が「良し」と言われるなら、しもべは安全ですが、怒られるなら、わたしに害を加える決心でおられるのを知ってください。</span>
<span className="v" id="v8" data-v="8" data-xref="サムエル記下 14:32; サムエル記上 18:3; サムエル記上 23:18"> あなたは、主の前で、しもべと契約を結んでくださいました。それでどうぞしもべにいつくしみを施してください。しかし、もしわたしに悪いことがあるならば、あなた自らわたしを殺してください。どうしてあなたの父のもとへわたしを引いていかなければならないでしょう」。</span>
<span className="v" id="v9" data-v="9" data-xref="サムエル記上 20:42; サムエル記上 19:2; サムエル記上 20:38"> ヨナタンは言った、「そのようなことは決してありません。父があなたに害を加える決心をしていることがわたしにわかっているならば、わたしはそれをあなたに告げないでおきましょうか」。</span>
<span className="v" id="v10" data-v="10" data-xref="サムエル記上 25:14; サムエル記上 25:17; 創世記 42:30"> ダビデはヨナタンに言った、「あなたの父が荒々しくあなたに答えられる時、だれがわたしに告げるでしょうか」。</span>
<span className="v" id="v11" data-v="11"> ヨナタンはダビデに言った、「さあ、野原へ出ていこう」。こうしてふたりは野原へ出て行った。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="ヨシュア記 22:22; ヨブ記 31:4; 箴言 25:2–3"> そしてヨナタンはダビデに言った、「イスラエルの神、主が、証人です。明日か明後日の今ごろ、わたしが父の心を探って、父がダビデに対して良いのを見ながら、人をつかわしてあなたに知らせないようなことをするでしょうか。</span>
<span className="v" id="v13" data-v="13" data-xref="ルツ記 1:17; 歴代志上 22:11; ヨシュア記 1:5"> しかし、もし父があなたに害を加えようと思っているのに、それをあなたに知らせず、あなたを逃がして、安全に去らせないならば、主よ、どうぞ幾重にも、このヨナタンを罰してください。どうぞ主が父と共におられたように、あなたと共におられますように。</span>
<span className="v" id="v14" data-v="14" data-xref="サムエル記下 9:3; エペソ人への手紙 5:1–2"> もしわたしがなお生きながらえているならば、主のいつくしみをわたしに施し、死を免れさせてください。</span>
<span className="v" id="v15" data-v="15" data-xref="サムエル記下 21:7; サムエル記上 24:21; サムエル記下 9:1–7"> またわたしの家をも、長くあなたのいつくしみにあずからせてください。主がダビデの敵をことごとく地のおもてから断ち滅ぼされる時、</span>
<span className="v" id="v16" data-v="16" data-xref="サムエル記上 25:22; サムエル記上 18:3; サムエル記下 21:8"> ヨナタンの名をダビデの家から絶やさないでください。どうぞ主がダビデの敵に、あだを返されるように」。</span>
<span className="v" id="v17" data-v="17" data-xref="箴言 18:24; サムエル記上 18:1; サムエル記上 18:3"> そしてヨナタンは重ねてダビデに誓わせた。彼を愛したからである。ヨナタンは自分の命のように彼を愛していた。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="サムエル記上 20:25; サムエル記上 20:5"> ヨナタンはダビデに言った、「あすはついたちです。あなたの席があいているので、どうしたのかと尋ねられるでしょう。</span>
<span className="v" id="v19" data-v="19" data-xref="サムエル記上 19:2; サムエル記上 20:5"> 三日目には、きびしく尋ねられるでしょうから、先にあなたが隠れた場所へ行って、向こうの石塚のかたわらにいてください。</span>
<span className="v" id="v20" data-v="20"> わたしは的を射るようにして、矢を三本、そのそばに放ちます。</span>
<span className="v" id="v21" data-v="21" data-xref="エレミヤ書 5:2; アモス書 8:14; エレミヤ書 12:16"> そして、『行って矢を捜してきなさい』と言って子供をつかわしましょう。わたしが子供に、『矢は手前にある。それを取ってきなさい』と言うならば、その時あなたはきてください。主が生きておられるように、あなたは安全で、何も危険がないからです。</span>
<span className="v" id="v22" data-v="22" data-xref="サムエル記上 20:37"> しかしわたしがその子供に、『矢は向こうにある』と言うならば、その時、あなたは去って行きなさい。主があなたを去らせられるのです。</span>
<span className="v" id="v23" data-v="23" data-xref="サムエル記上 20:14–15; サムエル記上 20:42; 創世記 31:50"> あなたとわたしとで話しあった事については、主が常にあなたとわたしとの間におられます」。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="箴言 4:17; イザヤ書 1:11–15; 箴言 21:3"> そこでダビデは野原に身を隠した。さて、ついたちになったので、王は食事をするため席に着いた。</span>
<span className="v" id="v25" data-v="25" data-xref="サムエル記上 20:18; 士師記 16:20"> 王はいつものように壁寄りに席に着き、ヨナタンはその向かい側の席に着き、アブネルはサウルの横の席に着いたが、ダビデの場所にはだれもいなかった。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="レビ記 15:5; レビ記 11:24; レビ記 11:27"> ところがその日サウルは何も言わなかった、「彼に何か起って汚れたのだろう。きっと汚れたのにちがいない」と思ったからである。</span>
<span className="v" id="v27" data-v="27" data-xref="ペテロの第一の手紙 2:4; サムエル記上 19:15; サムエル記上 18:11"> しかし、ふつか目すなわち、ついたちの明くる日も、ダビデの場所はあいていたので、サウルは、その子ヨナタンに言った、「どうしてエッサイの子は、きのうもきょうも食事にこないのか」。</span>
<span className="v" id="v28" data-v="28" data-xref="サムエル記上 20:6"> ヨナタンはサウルに答えた、「ダビデは、ベツレヘムへ行くことを許してくださいと、しきりにわたしに求めました。</span>
<span className="v" id="v29" data-v="29" data-xref="サムエル記上 17:28"> 彼は言いました、『わたしに行かせてください。われわれの一族が町で祭をするので、兄がわたしに来るようにと命じました。それでもし、あなたの前に恵みを得ますならば、どうぞ、わたしに行くことを許し、兄弟たちに会わせてください』。それで彼は王の食卓にこなかったのです」。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="箴言 21:24; ヤコブの手紙 1:19–20; 箴言 25:28"> その時サウルはヨナタンにむかって怒りを発し、彼に言った、「あなたは心の曲った、そむく女の産んだ子だ。あなたがエッサイの子を選んで、自分の身をはずかしめ、また母の身をはずかしめていることをわたしが知らないと思うのか。</span>
<span className="v" id="v31" data-v="31" data-xref="サムエル記上 19:6; サムエル記上 20:8; サムエル記上 19:11–15"> エッサイの子がこの世に生きながらえている間は、あなたも、あなたの王国も堅く立っていくことはできない。それゆえ今、人をつかわして、彼をわたしのもとに連れてこさせなさい。彼は必ず死ななければならない」。</span>
<span className="v" id="v32" data-v="32" data-xref="マタイによる福音書 27:23; サムエル記上 19:5; ルカによる福音書 23:22"> ヨナタンは父サウルに答えた、「どうして彼は殺されなければならないのですか。彼は何をしたのですか」。</span>
<span className="v" id="v33" data-v="33" data-xref="サムエル記上 20:7; サムエル記上 18:11; サムエル記上 19:10"> ところがサウルはヨナタンを撃とうとして、やりを彼に向かって振り上げたので、ヨナタンは父がダビデを殺そうと、心に決めているのを知った。</span>
<span className="v" id="v34" data-v="34" data-xref="エペソ人への手紙 4:26; マルコによる福音書 3:5; 伝道の書 7:20"> ヨナタンは激しく怒って席を立ち、その月のふつかには食事をしなかった。父がダビデをはずかしめたので、ダビデのために憂えたからである。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="サムエル記下 20:5; サムエル記上 20:19"> あくる朝、ヨナタンは、ひとりの小さい子供を連れて、ダビデと打ち合わせたように野原に出て行った。</span>
<span className="v" id="v36" data-v="36" data-xref="サムエル記上 20:20–22"> そしてその子供に言った、「走って行って、わたしの射る矢を捜しなさい」。子供が走って行く間に、ヨナタンは矢を彼の前の方に放った。</span>
<span className="v" id="v37" data-v="37" data-xref="サムエル記上 20:22"> そして子供が、ヨナタンの放った矢のところへ行った時、ヨナタンは子供のうしろから呼ばわって、「矢は向こうにあるではないか」と言った。</span>
<span className="v" id="v38" data-v="38" data-xref="詩篇 55:6–9; 箴言 6:4–5; マルコによる福音書 13:14–16"> ヨナタンはまた、その子供のうしろから呼ばわって言った、「早くせよ、急げ。とどまるな」。その子供は矢を拾い集めて主人ヨナタンのもとにきた。</span>
<span className="v" id="v39" data-v="39"> しかし子供は何も知らず、ヨナタンとダビデだけがそのことを知っていた。</span>
<span className="v" id="v40" data-v="40"> ヨナタンは自分の武器をその子供に渡して言った、「あなたはこれを町へ運んで行きなさい」。</span>
<span className="v" id="v41" data-v="41" data-xref="創世記 29:11; サムエル記上 18:3; サムエル記下 9:6"> 子供が行ってしまうとダビデは石塚のかたわらをはなれて立ちいで、地にひれ伏して三度敬礼した。そして、ふたりは互に口づけし、互に泣いた。やがてダビデは心が落ち着いた。</span>
<span className="v" id="v42" data-v="42" data-xref="サムエル記上 1:17; サムエル記上 23:18; サムエル記上 20:22–23"> その時ヨナタンはダビデに言った、「無事に行きなさい。われわれふたりは、『主が常にわたしとあなたの間におられ、また、わたしの子孫とあなたの子孫の間におられる』と言って、主の名をさして誓ったのです」。こうしてダビデは立ち去り、ヨナタンは町にはいった。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 12:10; 創世記 26:1; エゼキエル書 14:13"> さばきづかさが世を治めているころ、国に飢きんがあったので、ひとりの人がその妻とふたりの男の子を連れてユダのベツレヘムを去り、モアブの地へ行ってそこに滞在した。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 35:19; ミカ書 5:2; サムエル記上 17:21"> その人の名はエリメレク、妻の名はナオミ、ふたりの男の子の名はマロンとキリオンといい、ユダのベツレヘムのエフラタびとであった。彼らはモアブの地へ行って、そこにおったが、</span>
<span className="v" id="v3" data-v="3" data-xref="ヘブル人への手紙 12:10–11; 詩篇 34:19; ヘブル人への手紙 12:6"> ナオミの夫エリメレクは死んで、ナオミとふたりの男の子が残された。</span>
<span className="v" id="v4" data-v="4" data-xref="マタイによる福音書 1:5; 列王紀上 11:1–2; 申命記 23:3"> ふたりの男の子はそれぞれモアブの女を妻に迎えた。そのひとりの名はオルパといい、ひとりの名はルツといった。彼らはそこに十年ほど住んでいたが、</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 32:39; 詩篇 89:30–32; イザヤ書 49:21"> マロンとキリオンのふたりもまた死んだ。こうしてナオミはふたりの子と夫とに先だたれた。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="詩篇 132:15; 出エジプト記 3:16; 詩篇 111:5"> その時、ナオミはモアブの地で、主がその民を顧みて、すでに食物をお与えになっていることを聞いたので、その嫁と共に立って、モアブの地からふるさとへ帰ろうとした。</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀下 8:3; ルツ記 1:14; 出エジプト記 18:27"> そこで彼女は今いる所を出立し、ユダの地へ帰ろうと、ふたりの嫁を連れて道に進んだ。</span>
<span className="v" id="v8" data-v="8" data-xref="ルツ記 2:20; ルツ記 1:5; コロサイ人への手紙 3:18"> しかしナオミはふたりの嫁に言った、「あなたがたは、それぞれ自分の母の家に帰って行きなさい。あなたがたが、死んだふたりの子とわたしに親切をつくしたように、どうぞ、主があなたがたに、いつくしみを賜わりますよう。</span>
<span className="v" id="v9" data-v="9" data-xref="ルツ記 3:1; 使徒行伝 20:37; 創世記 29:11"> どうぞ、主があなたがたに夫を与え、夫の家で、それぞれ身の落ち着き所を得させられるように」。こう言って、ふたりの嫁に口づけしたので、彼らは声をあげて泣き、</span>
<span className="v" id="v10" data-v="10" data-xref="ゼカリヤ書 8:23; 詩篇 16:3; 詩篇 119:63"> ナオミに言った、「いいえ、わたしたちは一緒にあなたの民のところへ帰ります」。</span>
<span className="v" id="v11" data-v="11" data-xref="申命記 25:5; 創世記 38:11"> しかしナオミは言った、「娘たちよ、帰って行きなさい。どうして、わたしと一緒に行こうというのですか。あなたがたの夫となる子がまだわたしの胎内にいると思うのですか。</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 17:17; テモテヘの第一の手紙 5:9"> 娘たちよ、帰って行きなさい。わたしは年をとっているので、夫をもつことはできません。たとい、わたしが今夜、夫をもち、また子を産む望みがあるとしても、</span>
<span className="v" id="v13" data-v="13" data-xref="ヨブ記 19:21; 士師記 2:15; 詩篇 32:4"> そのためにあなたがたは、子どもの成長するまで待っているつもりなのですか。あなたがたは、そのために夫をもたずにいるつもりなのですか。娘たちよ、それはいけません。主の手がわたしに臨み、わたしを責められたことで、あなたがたのために、わたしは非常に心を痛めているのです」。</span>
<span className="v" id="v14" data-v="14" data-xref="箴言 18:24; マタイによる福音書 16:24; マタイによる福音書 10:37"> 彼らはまた声をあげて泣いた。そしてオルパはそのしゅうとめに口づけしたが、ルツはしゅうとめを離れなかった。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="士師記 11:24; ヨシュア記 24:15; ゼパニヤ書 1:6"> そこでナオミは言った、「ごらんなさい。あなたの相嫁は自分の民と自分の神々のもとへ帰って行きました。あなたも相嫁のあとについて帰りなさい」。</span>
<span className="v" id="v16" data-v="16" data-xref="サムエル記下 15:21; ルツ記 2:11–12; 列王紀下 2:2–6"> しかしルツは言った、「あなたを捨て、あなたを離れて帰ることをわたしに勧めないでください。わたしはあなたの行かれる所へ行き、またあなたの宿られる所に宿ります。あなたの民はわたしの民、あなたの神はわたしの神です。</span>
<span className="v" id="v17" data-v="17" data-xref="サムエル記上 3:17; 列王紀上 2:23; 列王紀下 6:31"> あなたの死なれる所でわたしも死んで、そのかたわらに葬られます。もし死に別れでなく、わたしがあなたと別れるならば、主よ、どうぞわたしをいくえにも罰してください」。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行伝 21:14; エペソ人への手紙 6:10; 使徒行伝 2:42"> ナオミはルツが自分と一緒に行こうと、固く決心しているのを見たので、そのうえ言うことをやめた。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="マタイによる福音書 21:10; イザヤ書 23:7; 哀歌 2:15"> そしてふたりは旅をつづけて、ついにベツレヘムに着いた。彼らがベツレヘムに着いたとき、町はこぞって彼らのために騒ぎたち、女たちは言った、「これはナオミですか」。</span>
<span className="v" id="v20" data-v="20" data-xref="ヨブ記 6:4; ヘブル人への手紙 12:11; 詩篇 73:14"> ナオミは彼らに言った、「わたしをナオミ（楽しみ）と呼ばずに、マラ（苦しみ）と呼んでください。なぜなら全能者がわたしをひどく苦しめられたからです。</span>
<span className="v" id="v21" data-v="21" data-xref="サムエル記上 2:7–8; ヨブ記 1:21; ヨブ記 16:8"> わたしは出て行くときは豊かでありましたが、主はわたしをから手で帰されました。主がわたしを悩まし、全能者がわたしに災をくだされたのに、どうしてわたしをナオミと呼ぶのですか」。</span>
<span className="v" id="v22" data-v="22" data-xref="ルツ記 2:23; サムエル記下 21:9; 出エジプト記 9:31–32"> こうしてナオミは、モアブの地から帰った嫁、モアブの女ルツと一緒に帰ってきて、大麦刈の初めにベツレヘムに着いた。</span>
</div>

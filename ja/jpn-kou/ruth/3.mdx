<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ルツ記 1:9; テモテヘの第一の手紙 5:8; テモテヘの第一の手紙 5:14"> 時にしゅうとめナオミは彼女に言った、「娘よ、わたしはあなたの落ち着き所を求めて、あなたをしあわせにすべきではないでしょうか。</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 25:5–10; ルツ記 2:20–23; ルツ記 2:8"> あなたが一緒に働いた女たちの主人ボアズはわたしたちの親戚ではありませんか。彼は今夜、打ち場で大麦をあおぎ分けます。</span>
<span className="v" id="v3" data-v="3" data-xref="サムエル記下 14:2; テモテヘの第一の手紙 2:9–10; エステル記 5:1"> それであなたは身を洗って油をぬり、晴れ着をまとって打ち場に下って行きなさい。ただ、あなたはその人が飲み食いを終るまで、その人に知られてはなりません。</span>
<span className="v" id="v4" data-v="4" data-xref="テサロニケ人への第一の手紙 5:22"> そしてその人が寝る時、その寝る場所を見定め、はいって行って、その足の所をまくって、そこに寝なさい。彼はあなたのすべきことを知らせるでしょう」。</span>
<span className="v" id="v5" data-v="5" data-xref="コロサイ人への手紙 3:20; エペソ人への手紙 6:1"> ルツはしゅうとめに言った、「あなたのおっしゃることを皆いたしましょう」。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="箴言 1:8; ヨハネによる福音書 2:5; 出エジプト記 20:12"> こうして彼女は打ち場に下り、すべてしゅうとめが命じたとおりにした。</span>
<span className="v" id="v7" data-v="7" data-xref="士師記 19:6; エステル記 1:10; サムエル記下 13:28"> ボアズは飲み食いして、心をたのしませたあとで、麦を積んである場所のかたわらへ行って寝た。そこで彼女はひそかに行き、ボアズの足の所をまくって、そこに寝た。</span>
<span className="v" id="v8" data-v="8"> 夜中になって、その人は驚き、起きかえって見ると、ひとりの女が足のところに寝ていたので、</span>
<span className="v" id="v9" data-v="9" data-xref="エゼキエル書 16:8; ルツ記 2:20; ルツ記 3:12"> 「あなたはだれですか」と言うと、彼女は答えた、「わたしはあなたのはしためルツです。あなたのすそで、はしためをおおってください。あなたは最も近い親戚です」。</span>
<span className="v" id="v10" data-v="10" data-xref="ルツ記 2:20; コリント人への第一の手紙 13:4–5; ルツ記 1:8"> ボアズは言った、「娘よ、どうぞ、主があなたを祝福されるように。あなたは貧富にかかわらず若い人に従い行くことはせず、あなたが最後に示したこの親切は、さきに示した親切にまさっています。</span>
<span className="v" id="v11" data-v="11" data-xref="箴言 31:29–31; 箴言 31:10; 箴言 12:4"> それで、娘よ、あなたは恐れるにおよびません。あなたが求めることは皆、あなたのためにいたしましょう。わたしの町の人々は皆、あなたがりっぱな女であることを知っているからです。</span>
<span className="v" id="v12" data-v="12" data-xref="ルツ記 4:1; テサロニケ人への第一の手紙 4:6; マタイによる福音書 7:12"> たしかにわたしは近い親戚ではありますが、わたしよりも、もっと近い親戚があります。</span>
<span className="v" id="v13" data-v="13" data-xref="ルツ記 4:5; エレミヤ書 4:2; ルツ記 2:20"> 今夜はここにとどまりなさい。朝になって、もしその人が、あなたのために親戚の義務をつくすならば、よろしい、その人にさせなさい。しかし主は生きておられます。その人が、あなたのために親戚の義務をつくすことを好まないならば、わたしはあなたのために親戚の義務をつくしましょう。朝までここにおやすみなさい」。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="コリント人への第二の手紙 8:21; ローマ人への手紙 14:16; コリント人への第一の手紙 10:32"> ルツは朝まで彼の足のところに寝たが、だれかれの見分け難いころに起きあがった。それはボアズが「この女の打ち場にきたことが人に知られてはならない」と言ったからである。</span>
<span className="v" id="v15" data-v="15" data-xref="イザヤ書 32:8; ガラテヤ人への手紙 6:10"> そしてボアズは言った、「あなたの着る外套を持ってきて、それを広げなさい」。彼女がそれを広げると、ボアズは大麦六オメルをはかって彼女に負わせた。彼女は町に帰り、</span>
<span className="v" id="v16" data-v="16"> しゅうとめのところへ行くと、しゅうとめは言った、「娘よ、どうでしたか」。そこでルツはその人が彼女にしたことをことごとく告げて、</span>
<span className="v" id="v17" data-v="17"> 言った、「あのかたはわたしに向かって、から手で、しゅうとめのところへ帰ってはならないと言って、この大麦六オメルをわたしにくださいました」。</span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 37:3–5; イザヤ書 28:16; イザヤ書 30:7"> しゅうとめは言った、「娘よ、この事がどうなるかわかるまでお待ちなさい。あの人は、きょう、その事を決定しなければ落ち着かないでしょう」。</span>
</div>

<span className="v" id="v3" data-v="3" data-xref="エゼキエル書 16:22; イザヤ書 32:13–14; エゼキエル書 19:13"> <span className="pl pl-1">そうでなければ、</span><br /><span className="pl pl-1">わたしは彼女の着物をはいで裸にし、</span><br /><span className="pl pl-1">その生れ出た日のようにし、</span><br /><span className="pl pl-1">また荒野のようにし、</span><br /><span className="pl pl-1">かわききった地のようにし、</span><br /><span className="pl pl-1">かわきによって彼女を殺す。</span></span>

<span className="v" id="v6" data-v="6" data-xref="ヨブ記 19:8; ヨブ記 3:23; 哀歌 3:7–9"> <span className="pl pl-1">それゆえ、わたしはいばらで彼女の道をふさぎ、</span><br /><span className="pl pl-1">かきをたてて、彼女には</span><br /><span className="pl pl-1">その道がわからないようにする。</span></span>
<span className="v" id="v7" data-v="7" data-xref="エレミヤ書 2:2; ホセア書 5:13; エゼキエル書 23:4"> <span className="pl pl-1">彼女はその恋人たちのあとを慕って行く、</span><br /><span className="pl pl-1">しかし彼らに追いつくことはない。</span><br /><span className="pl pl-1">彼らを尋ねる、しかし見いだすことはない。</span><br /><span className="pl pl-1">そこで彼女は言う、</span><br /><span className="pl pl-1">『わたしは行って、さきの夫に帰ろう。</span><br /><span className="pl pl-1">あの時は今よりもわたしによかったから』と。</span></span>
<span className="v" id="v8" data-v="8" data-xref="イザヤ書 1:3; ホセア書 4:11; ホセア書 13:2"> <span className="pl pl-1">彼女に穀物と酒と油とを与えた者、</span><br /><span className="pl pl-1">またバアルのために用いた銀と金とを</span><br /><span className="pl pl-1">多く彼女に与えた者は、</span><br /><span className="pl pl-1">わたしであったことを彼女は知らなかった。</span></span>
<span className="v" id="v9" data-v="9" data-xref="ホセア書 2:3; ハガイ書 1:6–11; マラキ書 1:4"> <span className="pl pl-1">それゆえ、わたしは穀物をその時になって奪い、</span><br /><span className="pl pl-1">ぶどう酒をその季節になって奪い、</span><br /><span className="pl pl-1">また彼女の裸をおおうために用いる</span><br /><span className="pl pl-1">羊の毛と麻とを奪い取る。</span></span>
<span className="v" id="v10" data-v="10" data-xref="エゼキエル書 23:29; エレミヤ書 13:26; ホセア書 13:7–8"> <span className="pl pl-1">わたしは今、彼女のみだらなことを</span><br /><span className="pl pl-1">その恋人たちの目の前にあらわす。</span><br /><span className="pl pl-1">だれも彼女をわたしの手から救う者はない。</span></span>

<span className="v" id="v14" data-v="14" data-xref="イザヤ書 40:1–2; ヨハネの黙示録 12:6; エゼキエル書 20:35–36"> <span className="pl pl-1">それゆえ、見よ、わたしは彼女をいざなって、</span><br /><span className="pl pl-1">荒野に導いて行き、ねんごろに彼女に語ろう。</span></span>

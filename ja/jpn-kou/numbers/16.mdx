<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ユダの手紙 1:11; 申命記 11:6; 出エジプト記 6:21"> ここに、レビの子コハテの子なるイヅハルの子コラと、ルベンの子なるエリアブの子ダタンおよびアビラムと、ルベンの子なるペレテの子オンとが相結び、</span>
<span className="v" id="v2" data-v="2" data-xref="民数記 26:9; エゼキエル書 23:10; 創世記 6:4"> イスラエルの人々のうち、会衆のうちから選ばれて、つかさとなった名のある人々二百五十人と共に立って、モーセに逆らった。</span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 106:16; 民数記 14:14; 出エジプト記 19:6"> 彼らは集まって、モーセとアロンとに逆らって言った、「あなたがたは、分を越えています。全会衆は、ことごとく聖なるものであって、主がそのうちにおられるのに、どうしてあなたがたは、主の会衆の上に立つのですか」。</span>
<span className="v" id="v4" data-v="4" data-xref="民数記 14:5; 民数記 20:6; ヨシュア記 7:6"> モーセはこれを聞いてひれ伏した。</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 65:4; 民数記 17:5; テモテヘの第二の手紙 2:19"> やがて彼はコラと、そのすべての仲間とに言った、「あす、主は、主につくものはだれ、聖なる者はだれであるかを示して、その人をみもとに近づけられるであろう。すなわち、その選んだ人を、みもとに近づけられるであろう。</span>
<span className="v" id="v6" data-v="6" data-xref="レビ記 10:1; 民数記 16:46–48; 列王紀上 18:21–23"> それで、次のようにしなさい。コラとそのすべての仲間とは、火ざらを取り、</span>
<span className="v" id="v7" data-v="7" data-xref="民数記 16:3; エペソ人への手紙 1:4; 列王紀上 18:17–18"> その中に火を入れ、それに薫香を盛って、あす、主の前に出なさい。その時、主が選ばれる人は聖なる者である。レビの子たちよ、あなたがたこそ、分を越えている」。</span>
<span className="v" id="v8" data-v="8"> モーセはまたコラに言った、「レビの子たちよ、聞きなさい。</span>
<span className="v" id="v9" data-v="9" data-xref="イザヤ書 7:13; 申命記 10:8; エゼキエル書 44:10–11"> イスラエルの神はあなたがたをイスラエルの会衆のうちから分かち、主に近づかせて、主の幕屋の務をさせ、かつ会衆の前に立って仕えさせられる。これはあなたがたにとって、小さいことであろうか。</span>
<span className="v" id="v10" data-v="10" data-xref="箴言 13:10; ヨハネの第三の手紙 1:9; 民数記 18:7"> 神はあなたとあなたの兄弟なるレビの子たちをみな近づけられた。あなたがたはなお、その上に祭司となることを求めるのか。</span>
<span className="v" id="v11" data-v="11" data-xref="出エジプト記 16:7–8; 出エジプト記 17:2; 民数記 16:3"> あなたとあなたの仲間は、みなそのために集まって主に敵している。あなたがたはアロンをなんと思って、彼に対してつぶやくのか」。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="ペテロの第一の手紙 2:13–14; ユダの手紙 1:8; 箴言 29:9"> モーセは人をやって、エリアブの子ダタンとアビラムとを呼ばせたが、彼らは言った、「わたしたちは参りません。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行伝 7:35; 出エジプト記 2:14; 民数記 11:5"> あなたは乳と蜜の流れる地から、わたしたちを導き出して、荒野でわたしたちを殺そうとしている。これは小さいことでしょうか。その上、あなたはわたしたちに君臨しようとしている。</span>
<span className="v" id="v14" data-v="14" data-xref="レビ記 20:24; 民数記 36:8–10; 民数記 20:5"> かつまた、あなたはわたしたちを、乳と蜜の流れる地に導いて行かず、畑と、ぶどう畑とを嗣業として与えもしない。これらの人々の目をくらまそうとするのですか。わたしたちは参りません」。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="創世記 4:4–5; コリント人への第二の手紙 7:2; テサロニケ人への第一の手紙 2:10"> モーセは大いに怒って、主に言った、「彼らの供え物を顧みないでください。わたしは彼らから、ろば一頭をも取ったことなく、また彼らのひとりをも害したことはありません」。</span>
<span className="v" id="v16" data-v="16" data-xref="サムエル記上 12:3; サムエル記上 12:7; テモテヘの第二の手紙 2:14"> そしてモーセはコラに言った、「あなたとあなたの仲間はみなアロンと一緒に、あす、主の前に出なさい。</span>
<span className="v" id="v17" data-v="17" data-xref="サムエル記上 12:7"> あなたがたは、おのおの火ざらを取って、それに薫香を盛り、おのおのその火ざらを主の前に携えて行きなさい。その火ざらは会わせて二百五十。あなたとアロンも、おのおの火ざらを携えて行きなさい」。</span>
<span className="v" id="v18" data-v="18"> 彼らは、おのおの火ざらを取り、火をその中に入れ、それに薫香を盛り、モーセとアロンも共に、会見の幕屋の入口に立った。</span>
<span className="v" id="v19" data-v="19" data-xref="民数記 14:10; 民数記 16:42; 出エジプト記 16:7"> そのとき、コラは会衆を、ことごとく会見の幕屋の入口に集めて、彼らふたりに逆らわせようとしたが、主の栄光は全会衆に現れた。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20"> 主はモーセとアロンに言われた、</span>
<span className="v" id="v21" data-v="21" data-xref="民数記 16:45; 出エジプト記 32:10; 詩篇 73:19"> 「あなたがたはこの会衆を離れなさい。わたしはただちに彼らを滅ぼすであろう」。</span>
<span className="v" id="v22" data-v="22" data-xref="民数記 27:16; ゼカリヤ書 12:1; ヨブ記 12:10"> 彼らふたりは、ひれ伏して言った、「神よ、すべての肉なる者の命の神よ、このひとりの人が、罪を犯したからといって、あなたは全会衆に対して怒られるのですか」。</span>
<span className="v" id="v23" data-v="23"> 主はモーセに言われた、</span>
<span className="v" id="v24" data-v="24" data-xref="民数記 16:21"> 「あなたは会衆に告げて、コラとダタンとアビラムのすまいの周囲を去れと言いなさい」。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="民数記 11:16–17; 民数記 11:25; 民数記 11:30"> モーセは立ってダタンとアビラムのもとに行ったが、イスラエルの長老たちも、彼に従って行った。</span>
<span className="v" id="v26" data-v="26" data-xref="イザヤ書 52:11; コリント人への第二の手紙 6:17; ヨハネの黙示録 18:4"> モーセは会衆に言った、「どうぞ、あなたがたはこれらの悪い人々の天幕を離れてください。彼らのものには何にも触れてはならない。彼らのもろもろの罪によって、あなたがたも滅ぼされてはいけないから」。</span>
<span className="v" id="v27" data-v="27" data-xref="ヨブ記 9:4; イザヤ書 28:14; ヨブ記 40:10–11"> そこで人々はコラとダタンとアビラムのすまいの周囲を離れ去った。そして、ダタンとアビラムとは、妻、子、および幼児と一緒に出て、天幕の入口に立った。</span>
<span className="v" id="v28" data-v="28" data-xref="ヨハネによる福音書 6:38; 出エジプト記 3:12; ヨハネによる福音書 14:11"> モーセは言った、「あなたがたは主がこれらのすべての事をさせるために、わたしをつかわされたこと、またわたしが、これを自分の心にしたがって行うものでないことを、次のことによって知るであろう。</span>
<span className="v" id="v29" data-v="29" data-xref="哀歌 4:22; 列王紀上 22:28; 出エジプト記 32:34"> すなわち、もしこれらの人々が、普通の死に方で死に、普通の運命に会うのであれば、主がわたしをつかわされたのではない。</span>
<span className="v" id="v30" data-v="30" data-xref="詩篇 55:15; 民数記 16:33; ヨブ記 31:3"> しかし、主が新しい事をされ、地が口を開いて、これらの人々と、それに属する者とを、ことごとくのみつくして、生きながら陰府に下らせられるならば、あなたがたはこれらの人々が、主を侮ったのであることを知らなければならない」。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="詩篇 106:17–18; 民数記 27:3; 申命記 11:6"> モーセが、これらのすべての言葉を述べ終ったとき、彼らの下の土地が裂け、</span>
<span className="v" id="v32" data-v="32" data-xref="詩篇 106:17; 民数記 26:11; ヨハネの黙示録 12:16"> 地は口を開いて、彼らとその家族、ならびにコラに属するすべての人々と、すべての所有物をのみつくした。</span>
<span className="v" id="v33" data-v="33" data-xref="エゼキエル書 32:18; イザヤ書 14:9; 詩篇 9:15"> すなわち、彼らと、彼らに属するものは、皆生きながら陰府に下り、地はその上を閉じふさいで、彼らは会衆のうちから、断ち滅ぼされた。</span>
<span className="v" id="v34" data-v="34" data-xref="ゼカリヤ書 14:5; イザヤ書 33:3; ヨハネの黙示録 6:15–17"> この時、その周囲にいたイスラエルの人々は、みな彼らの叫びを聞いて逃げ去り、「恐らく地はわたしたちをも、のみつくすであろう」と言った。</span>
<span className="v" id="v35" data-v="35" data-xref="民数記 26:10; レビ記 10:2; 詩篇 106:18"> また主のもとから火が出て、薫香を供える二百五十人をも焼きつくした。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36"> 主はモーセに言われた、</span>
<span className="v" id="v37" data-v="37" data-xref="レビ記 27:28; 民数記 16:18; 民数記 16:7"> 「あなたは祭司アロンの子エレアザルに告げて、その燃える火の中から、かの火ざらを取り出させ、その中の火を遠く広くまき散らさせなさい。それらの火ざらは聖となったから、</span>
<span className="v" id="v38" data-v="38" data-xref="民数記 26:10; エゼキエル書 14:8; ペテロの第二の手紙 2:6"> 罪を犯して命を失った人々の、これらの火ざらを、広い延べ板として、祭壇のおおいとしなさい。これは主の前にささげられて、聖となったからである。こうして、これはイスラエルの人々に、しるしとなるであろう」。</span>
<span className="v" id="v39" data-v="39"> そこで祭司エレアザルは、かの焼き殺された人々が供えた青銅の火ざらを取り、これを広く打ち延ばして、祭壇のおおいとし、</span>
<span className="v" id="v40" data-v="40" data-xref="民数記 3:10; 民数記 18:4–7; 歴代志下 26:16–21"> これをイスラエルの人々の記念の物とした。これはアロンの子孫でないほかの人が、主の前に近づいて、薫香をたくことのないようにするため、またその人がコラ、およびその仲間のようにならないためである。すなわち、主がモーセによってエレアザルに言われたとおりである。</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="民数記 16:1–7; 詩篇 106:23; 民数記 14:2"> その翌日、イスラエルの人々の会衆は、みなモーセとアロンとにつぶやいて言った、「あなたがたは主の民を殺しました」。</span>
<span className="v" id="v42" data-v="42" data-xref="民数記 16:19; レビ記 9:23; 民数記 20:6"> 会衆が集まって、モーセとアロンとに逆らったとき、会見の幕屋を望み見ると、雲がこれをおおい、主の栄光が現れていた。</span>
<span className="v" id="v43" data-v="43"> モーセとアロンとが、会見の幕屋の前に行くと、</span>
<span className="v" id="v44" data-v="44"> 主はモーセに言われた、</span>
<span className="v" id="v45" data-v="45" data-xref="民数記 16:21–22; 民数記 16:24; 民数記 20:6"> 「あなたがたはこの会衆を離れなさい。わたしはただちに彼らを滅ぼそう」。そこで彼らふたりは、ひれ伏した。</span>
<span className="v" id="v46" data-v="46" data-xref="民数記 8:19; 歴代志上 27:24; レビ記 10:6"> モーセはアロンに言った、「あなたは火ざらを取って、それに祭壇から取った火を入れ、その上に薫香を盛り、急いでそれを会衆のもとに持って行って、彼らのために罪のあがないをしなさい。主が怒りを発せられ、疫病がすでに始まったからです」。</span>
<span className="v" id="v47" data-v="47" data-xref="マタイによる福音書 5:44; 申命記 33:10–11; 詩篇 106:29"> そこで、アロンはモーセの言ったように、それを取って会衆の中に走って行ったが、疫病はすでに民のうちに始まっていたので、薫香をたいて、民のために罪のあがないをし、</span>
<span className="v" id="v48" data-v="48" data-xref="サムエル記下 24:25; ヘブル人への手紙 7:24–25; 民数記 16:18"> すでに死んだ者と、なお生きている者との間に立つと、疫病はやんだ。</span>
<span className="v" id="v49" data-v="49" data-xref="民数記 25:9; 民数記 16:32–35; ヘブル人への手紙 2:1–3"> コラの事によって死んだ者のほかに、この疫病によって死んだ者は一万四千七百人であった。</span>
<span className="v" id="v50" data-v="50" data-xref="歴代志上 21:26–30; 民数記 16:43"> アロンは会見の幕屋の入口にいるモーセのもとに帰った。こうして疫病はやんだ。</span>
</div>
</div>

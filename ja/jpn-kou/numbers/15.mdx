<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 主はモーセに言われた、</span>
<span className="v" id="v2" data-v="2" data-xref="レビ記 23:10; 民数記 15:18; レビ記 25:2"> 「イスラエルの人々に言いなさい、『あなたがたが、わたしの与えて住ませる地に行って、</span>
<span className="v" id="v3" data-v="3" data-xref="出エジプト記 29:18; 創世記 8:21; ピリピ人への手紙 4:18"> 主に火祭をささげる時、すなわち特別の誓願の供え物、あるいは自発の供え物、あるいは祝のときの供え物として、牛または羊を燔祭または犠牲としてささげ、主に香ばしいかおりとするとき、</span>
<span className="v" id="v4" data-v="4" data-xref="出エジプト記 29:40; レビ記 23:13; レビ記 6:14"> その供え物を主にささげる者は、燔祭または犠牲と共に、小羊一頭ごとに、麦粉一エパの十分の一に、油一ヒンの四分の一を混ぜたものを、素祭としてささげ、ぶどう酒一ヒンの四分の一を、灌祭としてささげなければならない。</span>
<span className="v" id="v6" data-v="6" data-xref="民数記 28:12–14; 民数記 15:4"> もし、また雄羊を用いるときは、麦粉一エパの十分の二に、油一ヒンの三分の一を混ぜたものを、素祭としてささげ、</span>
<span className="v" id="v7" data-v="7"> また、ぶどう酒一ヒンの三分の一を、灌祭としてささげて、主に香ばしいかおりとしなければならない。</span>
<span className="v" id="v8" data-v="8" data-xref="レビ記 3:1; レビ記 7:11–18; レビ記 1:3"> またあなたが特別の誓願の供え物、あるいは酬恩祭を、主にささげる時、若い雄牛を、燔祭または犠牲とするならば、</span>
<span className="v" id="v9" data-v="9" data-xref="民数記 28:14; 民数記 28:12; レビ記 6:14"> 麦粉一エパの十分の三に、油一ヒンの二分の一を混ぜたものを、素祭として、若い雄牛と共にささげ、</span>
<span className="v" id="v10" data-v="10" data-xref="民数記 15:5; 民数記 6:15"> また、ぶどう酒一ヒンの二分の一を、灌祭としてささげなければならない。これは火祭であって、主に香ばしいかおりとするものである。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11"> 雄牛、あるいは雄羊、あるいは小羊、あるいは子やぎは、一頭ごとに、このようにしなければならない。</span>
<span className="v" id="v12" data-v="12"> すなわち、あなたがたのささげる数にてらし、その数にしたがって、一頭ごとに、このようにしなければならない。</span>
<span className="v" id="v13" data-v="13"> すべて国に生れた者が、火祭をささげて、主に香ばしいかおりとするときは、このように、これらのことを行わなければならない。</span>
<span className="v" id="v14" data-v="14"> またあなたがたのうちに寄留している他国人、またはあなたがたのうちに、代々ながく住む者が、火祭をささげて、主に香ばしいかおりとしようとする時は、あなたがたがするように、その人もしなければならない。</span>
<span className="v" id="v15" data-v="15" data-xref="民数記 9:14; 民数記 15:29; 出エジプト記 12:49"> 会衆たる者は、あなたがたも、あなたがたのうちに寄留している他国人も、同一の定めに従わなければならない。これは、あなたがたが代々ながく守るべき定めである。他国の人も、主の前には、あなたがたと等しくなければならない。</span>
<span className="v" id="v16" data-v="16"> すなわち、あなたがたも、あなたがたのうちに寄留している他国人も、同一の律法、同一のおきてに従わなければならない』」。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17"> 主はまたモーセに言われた、</span>
<span className="v" id="v18" data-v="18" data-xref="民数記 15:2; 申命記 26:1–15"> 「イスラエルの人々に言いなさい、『わたしが導いて行く地に、あなたがたがはいって、</span>
<span className="v" id="v19" data-v="19" data-xref="ヨシュア記 5:11–12"> その地の食物を食べるとき、あなたがたは、ささげ物を主にささげなければならない。</span>
<span className="v" id="v20" data-v="20" data-xref="レビ記 2:14; 出エジプト記 34:26; 申命記 26:2–10"> すなわち、麦粉の初物で作った菓子を、ささげ物としなければならない。これを、打ち場からのささげ物のように、ささげなければならない。</span>
<span className="v" id="v21" data-v="21" data-xref="出エジプト記 29:28; 民数記 18:26"> あなたがたは代々その麦粉の初物で、主にささげ物をしなければならない。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="レビ記 4:2; レビ記 4:27; レビ記 5:15–17"> あなたがたが、もしあやまって、主がモーセに告げられたこのすべての戒めを行わず、</span>
<span className="v" id="v23" data-v="23"> 主がモーセによって戒めを与えられた日からこのかた、代々にわたり、あなたがたに命じられたすべての事を行わないとき、</span>
<span className="v" id="v24" data-v="24" data-xref="レビ記 4:23; レビ記 4:13–21; レビ記 5:15"> すなわち、会衆が知らずに、あやまって犯した時は、全会衆は若い雄牛一頭を、燔祭としてささげ、主に香ばしいかおりとし、これに素祭と灌祭とを定めのように加え、また雄やぎ一頭を、罪祭としてささげなければならない。</span>
<span className="v" id="v25" data-v="25" data-xref="レビ記 4:20; ローマ人への手紙 3:25; ヘブル人への手紙 2:17"> そして祭司は、イスラエルの人々の全会衆のために、罪のあがないをしなければならない。そうすれば、彼らはゆるされるであろう。それは過失だからである。彼らはその過失のために、その供え物として、火祭を主にささげ、また罪祭を主の前にささげなければならない。</span>
<span className="v" id="v26" data-v="26" data-xref="民数記 15:24"> そうすれば、イスラエルの人々の全会衆はゆるされ、また彼らのうちに寄留している他国人も、ゆるされるであろう。民はみな過失を犯したからである。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="レビ記 4:27–28; 使徒行伝 17:30; 使徒行伝 3:17"> もし人があやまって罪を犯す時は、一歳の雌やぎ一頭を罪祭としてささげなければならない。</span>
<span className="v" id="v28" data-v="28" data-xref="レビ記 4:35"> そして祭司は、人があやまって罪を犯した時、そのあやまって罪を犯した人のために、主の前に罪のあがないをして、その罪をあがなわなければならない。そうすれば、彼はゆるされるであろう。</span>
<span className="v" id="v29" data-v="29" data-xref="民数記 15:15; レビ記 16:29; レビ記 17:15"> イスラエルの人々のうちの、国に生れた者でも、そのうちに寄留している他国人でも、あやまって罪を犯す者には、あなたがたは同一の律法を用いなければならない。</span>
<span className="v" id="v30" data-v="30" data-xref="ヘブル人への手紙 10:26; 詩篇 19:13; 申命記 1:43"> しかし、国に生れた者でも、他国の人でも、故意に罪を犯す者は主を汚すもので、その人は民のうちから断たれなければならない。</span>
<span className="v" id="v31" data-v="31" data-xref="サムエル記下 12:9; 箴言 13:13; エゼキエル書 18:20"> 彼は主の言葉を侮り、その戒めを破ったのであるから、必ず断たれ、その罪を負わなければならない』」。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="出エジプト記 35:2–3; 出エジプト記 31:14–15; 出エジプト記 20:8–10"> イスラエルの人々が荒野におるとき、安息日にひとりの人が、たきぎを集めるのを見た。</span>
<span className="v" id="v33" data-v="33" data-xref="ヨハネによる福音書 8:3–20"> そのたきぎを集めるのを見た人々は、その人をモーセとアロン、および全会衆のもとに連れてきたが、</span>
<span className="v" id="v34" data-v="34" data-xref="レビ記 24:12; 民数記 9:8"> どう取り扱うべきか、まだ示しを受けていなかったので、彼を閉じ込めておいた。</span>
<span className="v" id="v35" data-v="35" data-xref="使徒行伝 7:58; 出エジプト記 31:14–15; 列王紀上 21:13"> そのとき、主はモーセに言われた、「その人は必ず殺されなければならない。全会衆は宿営の外で、彼を石で撃ち殺さなければならない」。</span>
<span className="v" id="v36" data-v="36" data-xref="ヨシュア記 7:25"> そこで、全会衆は彼を宿営の外に連れ出し、彼を石で撃ち殺し、主がモーセに命じられたようにした。</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37"> 主はまたモーセに言われた、</span>
<span className="v" id="v38" data-v="38" data-xref="マタイによる福音書 23:5; 申命記 22:12; マタイによる福音書 9:20"> 「イスラエルの人々に命じて、代々その衣服のすその四すみにふさをつけ、そのふさを青ひもで、すその四すみにつけさせなさい。</span>
<span className="v" id="v39" data-v="39" data-xref="詩篇 106:39; 箴言 28:26; 詩篇 73:27"> あなたがたが、そのふさを見て、主のもろもろの戒めを思い起して、それを行い、あなたがたが自分の心と、目の欲に従って、みだらな行いをしないためである。</span>
<span className="v" id="v40" data-v="40" data-xref="ローマ人への手紙 12:1; テサロニケ人への第一の手紙 4:7; レビ記 11:44–45"> こうして、あなたがたは、わたしのもろもろの戒めを思い起して、それを行い、あなたがたの神に聖なる者とならなければならない。</span>
<span className="v" id="v41" data-v="41" data-xref="ペテロの第一の手紙 2:9–10; エゼキエル書 36:25–27; ヘブル人への手紙 11:16"> わたしはあなたがたの神、主であって、あなたがたの神となるために、あなたがたをエジプトの国から導き出した者である。わたしはあなたがたの神、主である」。</span>
</div>

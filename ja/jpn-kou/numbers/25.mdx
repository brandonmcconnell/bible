<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="コリント人への第一の手紙 10:8; 民数記 33:49; ヨシュア記 2:1"> イスラエルはシッテムにとどまっていたが、民はモアブの娘たちと、みだらな事をし始めた。</span>
<span className="v" id="v2" data-v="2" data-xref="コリント人への第一の手紙 10:20; 出エジプト記 20:5; 出エジプト記 34:15–16"> その娘たちが神々に犠牲をささげる時に民を招くと、民は一緒にそれを食べ、娘たちの神々を拝んだ。</span>
<span className="v" id="v3" data-v="3" data-xref="ヨシュア記 22:17; 詩篇 106:28–29; ホセア書 9:10"> イスラエルはこうしてペオルのバアルにつきしたがったので、主はイスラエルにむかって怒りを発せられた。</span>
<span className="v" id="v4" data-v="4" data-xref="申命記 13:17; 申命記 4:3; 申命記 21:23"> そして主はモーセに言われた、「民の首領をことごとく捕え、日のあるうちにその人々を主の前で処刑しなさい。そうすれば主の怒りはイスラエルを離れるであろう」。</span>
<span className="v" id="v5" data-v="5" data-xref="出エジプト記 18:21; 列王紀上 18:40; 申命記 13:9"> モーセはイスラエルのさばきびとたちにむかって言った、「あなたがたはおのおの、配下の者どもでペオルのバアルにつきしたがったものを殺しなさい」。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="ヨエル書 2:17; 民数記 22:4; エレミヤ書 36:23"> モーセとイスラエルの人々の全会衆とが会見の幕屋の入口で泣いていた時、彼らの目の前で、ひとりのイスラエルびとが、その兄弟たちの中に、ひとりのミデアンの女を連れてきた。</span>
<span className="v" id="v7" data-v="7" data-xref="出エジプト記 6:25; 詩篇 106:30; ヨシュア記 22:30–31"> 祭司アロンの子なるエレアザルの子ピネハスはこれを見て、会衆のうちから立ち上がり、やりを手に執り、</span>
<span className="v" id="v8" data-v="8" data-xref="民数記 16:46–48; 詩篇 106:29–31; 歴代志上 21:22"> そのイスラエルの人の後を追って、奥の間に入り、そのイスラエルの人を突き、またその女の腹を突き通して、ふたりを殺した。こうして疫病がイスラエルの人々に及ぶのがやんだ。</span>
<span className="v" id="v9" data-v="9" data-xref="コリント人への第一の手紙 10:8; 申命記 4:3–4; 民数記 25:4–5"> しかし、その疫病で死んだ者は二万四千人であった。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10"> 主はモーセに言われた、</span>
<span className="v" id="v11" data-v="11" data-xref="申命記 32:21; 詩篇 78:58; 申命記 32:16"> 「祭司アロンの子なるエレアザルの子ピネハスは自分のことのように、わたしの憤激をイスラエルの人々のうちに表わし、わたしの怒りをそのうちから取り去ったので、わたしは憤激して、イスラエルの人々を滅ぼすことをしなかった。</span>
<span className="v" id="v12" data-v="12" data-xref="マラキ書 2:4–5; マラキ書 3:1; イザヤ書 54:10"> このゆえにあなたは言いなさい、『わたしは平和の契約を彼に授ける。</span>
<span className="v" id="v13" data-v="13" data-xref="ヘブル人への手紙 2:17; ローマ人への手紙 10:2–4; エレミヤ書 33:22"> これは彼とその後の子孫に永遠の祭司職の契約となるであろう。彼はその神のために熱心であって、イスラエルの人々のために罪のあがないをしたからである』と」。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="民数記 1:23; 民数記 26:14; 歴代志下 19:7"> ミデアンの女と共に殺されたイスラエルの人の名はジムリといい、サルの子で、シメオンびとのうちの一族のつかさであった。</span>
<span className="v" id="v15" data-v="15" data-xref="民数記 31:8; ヨシュア記 13:21; 民数記 25:18"> またその殺されたミデアンの女の名はコズビといい、ツルの娘であった。ツルはミデアンの民の一族のかしらであった。</span>
<span className="v" id="v16" data-v="16"> 主はまたモーセに言われた、</span>
<span className="v" id="v17" data-v="17" data-xref="民数記 31:1–3; ヨハネの黙示録 18:6"> 「ミデアンびとを打ち悩ましなさい。</span>
<span className="v" id="v18" data-v="18" data-xref="ヨハネの黙示録 2:14; 出エジプト記 32:35; コリント人への第二の手紙 11:3"> 彼らはたくらみをもって、あなたがたを悩まし、ペオルの事と、彼らの姉妹、ミデアンのつかさの娘コズビ、すなわちペオルの事により、疫病の起った日に殺された女の事とによって、あなたがたを惑わしたからである」。</span>
</div>

<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="民数記 23:29; ユダの手紙 1:11; 出エジプト記 27:1–8"> バラムはバラクに言った、「わたしのために、ここに七つの祭壇を築き、七頭の雄牛と七頭の雄羊とを整えなさい」。</span>
<span className="v" id="v2" data-v="2" data-xref="民数記 23:14; 民数記 23:30"> バラクはバラムの言ったとおりにした。そしてバラクとバラムとは、その祭壇ごとに雄牛一頭と雄羊一頭とをささげた。</span>
<span className="v" id="v3" data-v="3" data-xref="民数記 23:15; 創世記 8:20; 創世記 22:2"> バラムはバラクに言った、「あなたは燔祭のかたわらに立っていてください。その間にわたしは行ってきます。主はたぶんわたしに会ってくださるでしょう。そして、主がわたしに示される事はなんでもあなたに告げましょう」。こうして彼は一つのはげ山に登った。</span>
<span className="v" id="v4" data-v="4" data-xref="民数記 23:16; エペソ人への手紙 2:9; ルカによる福音書 18:12"> 神がバラムに会われたので、バラムは神に言った、「わたしは七つの祭壇を設け、祭壇ごとに雄牛一頭と雄羊一頭とをささげました」。</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 18:18; エレミヤ書 1:9; イザヤ書 59:21"> 主はバラムの口に言葉を授けて言われた、「バラクのもとに帰ってこう言いなさい」。</span>
<span className="v" id="v6" data-v="6"> 彼がバラクのもとに帰ってみると、バラクはモアブのすべてのつかさたちと共に燔祭のかたわらに立っていた。</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 23:4; 民数記 24:3; 民数記 22:5–6"> バラムはこの託宣を述べた。<br /><span className="pl pl-1">「バラクはわたしをアラムから招き寄せ、</span><br /><span className="pl pl-1">モアブの王はわたしを東の山から招き寄せて言う、</span><br /><span className="pl pl-1">『きてわたしのためにヤコブをのろえ、</span><br /><span className="pl pl-1">きてイスラエルをのろえ』と。</span></span>
<span className="v" id="v8" data-v="8" data-xref="民数記 23:23; イザヤ書 44:25; 民数記 23:20"> <span className="pl pl-1">神ののろわない者を、わたしがどうしてのろえよう。</span><br /><span className="pl pl-1">主ののろわない者を、わたしがどうしてのろえよう。</span></span>
<span className="v" id="v9" data-v="9" data-xref="申命記 33:28; 申命記 32:8; 出エジプト記 33:16"> <span className="pl pl-1">岩の頂からながめ、</span><br /><span className="pl pl-1">丘の上から見たが、</span><br /><span className="pl pl-1">これはひとり離れて住む民、</span><br /><span className="pl pl-1">もろもろの国民のうちに並ぶものはない。</span></span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 37:37; 創世記 13:16; 詩篇 116:15"> <span className="pl pl-1">だれがヤコブの群衆を数え、</span><br /><span className="pl pl-1">イスラエルの無数の民を数え得よう。</span><br /><span className="pl pl-1">わたしは義人のように死に、</span><br /><span className="pl pl-1">わたしの終りは彼らの終りのようでありたい」。</span></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="ネヘミヤ書 13:2; 民数記 24:10; 民数記 22:17"> そこでバラクはバラムに言った、「あなたはわたしに何をするのですか。わたしは敵をのろうために、あなたを招いたのに、あなたはかえって敵を祝福するばかりです」。</span>
<span className="v" id="v12" data-v="12" data-xref="民数記 22:38; 民数記 23:20; 民数記 23:26"> バラムは答えた、「わたしは、主がわたしの口に授けられる事だけを語るように注意すべきではないでしょうか」。</span>
</div>
<div className="bp poetry">
<span className="v" id="v13" data-v="13" data-xref="詩篇 109:17; ヤコブの手紙 3:9–10; 民数記 22:41"> バラクは彼に言った、「わたしと一緒にほかのところへ行って、そこから彼らをごらんください。あなたはただ彼らの一端を見るだけで、全体を見ることはできないでしょうが、そこからわたしのために彼らをのろってください」。</span>
<span className="v" id="v14" data-v="14" data-xref="イザヤ書 46:6; 民数記 23:29; イザヤ書 1:10–11"> そして彼はバラムを連れてゾピムの野に行き、ピスガの頂に登って、そこに七つの祭壇を築き、祭壇ごとに雄牛一頭と雄羊一頭とをささげた。</span>
<span className="v" id="v15" data-v="15" data-xref="民数記 23:3; 民数記 22:8"> ときにはバラムはバラクに言った、「あなたはここで、燔祭のかたわらに立っていてください。わたしは向こうへ行って、主に伺いますから」。</span>
<span className="v" id="v16" data-v="16" data-xref="民数記 23:5; 民数記 24:1; 民数記 22:35"> 主はバラムに臨み、言葉を口に授けて言われた、「バラクのもとに帰ってこう言いなさい」。</span>
<span className="v" id="v17" data-v="17" data-xref="民数記 23:26; サムエル記上 3:17; エレミヤ書 37:17"> 彼がバラクのところへ行って見ると、バラクは燔祭のかたわらに立ち、モアブのつかさたちも共にいた。バラクはバラムに言った、「主はなんと言われましたか」。</span>
<span className="v" id="v18" data-v="18" data-xref="士師記 3:20"> そこでバラムはまたこの託宣を述べた。<br /><span className="pl pl-1">「バラクよ、立って聞け、</span><br /><span className="pl pl-1">チッポルの子よ、わたしに耳を傾けよ。</span></span>
<span className="v" id="v19" data-v="19" data-xref="サムエル記上 15:29; ヤコブの手紙 1:17; マラキ書 3:6"> <span className="pl pl-1">神は人のように偽ることはなく、</span><br /><span className="pl pl-1">また人の子のように悔いることもない。</span><br /><span className="pl pl-1">言ったことで、行わないことがあろうか、</span><br /><span className="pl pl-1">語ったことで、しとげないことがあろうか。</span></span>
<span className="v" id="v20" data-v="20" data-xref="ヨハネによる福音書 10:27–29; 民数記 22:12; 創世記 12:2"> <span className="pl pl-1">祝福せよとの命をわたしはうけた、</span><br /><span className="pl pl-1">すでに神が祝福されたものを、</span><br /><span className="pl pl-1">わたしは変えることができない。</span></span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 23:4; マタイによる福音書 1:23; エレミヤ書 50:20"> <span className="pl pl-1">だれもヤコブのうちに災のあるのを見ない、</span><br /><span className="pl pl-1">またイスラエルのうちに悩みのあるのを見ない。</span><br /><span className="pl pl-1">彼らの神、主が共にいまし、</span><br /><span className="pl pl-1">王をたたえる声がその中に聞える。</span></span>
<span className="v" id="v22" data-v="22" data-xref="民数記 24:8; 申命記 33:17; ヨブ記 39:9–11"> <span className="pl pl-1">神は彼らをエジプトから導き出された、</span><br /><span className="pl pl-1">彼らは野牛の角のようだ。</span></span>
<span className="v" id="v23" data-v="23" data-xref="ルカによる福音書 10:18–19; ヨシュア記 13:22; ガラテヤ人への手紙 1:23–24"> <span className="pl pl-1">ヤコブには魔術がなく、</span><br /><span className="pl pl-1">イスラエルには占いがない。</span><br /><span className="pl pl-1">神がそのなすところを時に応じてヤコブに告げ、</span><br /><span className="pl pl-1">イスラエルに示されるからだ。</span></span>
<span className="v" id="v24" data-v="24" data-xref="創世記 49:27; 創世記 49:9; 民数記 24:17"> <span className="pl pl-1">見よ、この民は雌じしのように立ち上がり、</span><br /><span className="pl pl-1">雄じしのように身を起す。</span><br /><span className="pl pl-1">これはその獲物を食らい、</span><br /><span className="pl pl-1">その殺した者の血を飲むまでは身を横たえない」。</span></span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="詩篇 2:1–3"> バラクはバラムに言った、「あなたは彼らをのろうことも祝福することも、やめてください」。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行伝 5:29; 民数記 22:18; 使徒行伝 4:19–20"> バラムは答えてバラクに言った、「主の言われることは、なんでもしなければならないと、わたしはあなたに告げませんでしたか」。</span>
<span className="v" id="v27" data-v="27" data-xref="ローマ人への手紙 11:29; 箴言 21:30; 民数記 23:19–20"> バラクはバラムに言った、「どうぞ、おいでください。わたしはあなたをほかの所へお連れしましょう。神はあなたがそこからわたしのために彼らをのろうことを許されるかもしれません」。</span>
<span className="v" id="v28" data-v="28" data-xref="民数記 21:20; 詩篇 106:28"> そしてバラクはバラムを連れて、荒野を見おろすペオルの頂に行った。</span>
<span className="v" id="v29" data-v="29" data-xref="民数記 23:1–2"> バラムはバラクに言った、「わたしのためにここに七つの祭壇を築き、雄牛七頭と、雄羊七頭とを整えなさい」。</span>
<span className="v" id="v30" data-v="30"> バラクはバラムの言ったとおりにし、その祭壇ごとに雄牛一頭と雄羊一頭とをささげた。</span>
</div>

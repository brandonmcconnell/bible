<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数記 27:1; 歴代志上 7:14–16; ヨシュア記 17:2–3"> ヨセフの子孫の氏族のうち、マナセの子マキルの子であるギレアデの子らの氏族のかしらたちがきて、モーセとイスラエルの人々のかしらであるつかさたちとの前で語って、</span>
<span className="v" id="v2" data-v="2" data-xref="ヨシュア記 17:3–6; 民数記 27:1–7; 民数記 33:54"> 言った、「イスラエルの人々に、その嗣業の地をくじによって与えることを主はあなたに命じられ、あなたもまた、われわれの兄弟ゼロペハデの嗣業を、その娘たちに与えるよう、主によって命じられました。</span>
<span className="v" id="v3" data-v="3"> その娘たちがもし、イスラエルの人々のうちの他の部族のむすこたちにとつぐならば、彼女たちの嗣業は、われわれの父祖の嗣業のうちから取り除かれて、そのとつぐ部族の嗣業に加えられるでしょう。こうしてそれはわれわれの嗣業の分から取り除かれるでしょう。</span>
<span className="v" id="v4" data-v="4" data-xref="レビ記 25:10–18; イザヤ書 61:2; レビ記 25:23"> そしてイスラエルの人々のヨベルの年がきた時、彼女たちの嗣業は、そのとついだ部族の嗣業に加えられるでしょう。こうして彼女たちの嗣業は、われわれの父祖の部族の嗣業のうちから取り除かれるでしょう」。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="民数記 27:7; 申命記 5:28"> モーセは主の言葉にしたがって、イスラエルの人々に命じて言った、「ヨセフの子孫の部族の言うところは正しい。</span>
<span className="v" id="v6" data-v="6" data-xref="民数記 36:12; コリント人への第二の手紙 6:14; 創世記 24:3"> ゼロペハデの娘たちについて、主が命じられたことはこうである。すなわち『彼女たちはその心にかなう者にとついでもよいが、ただその父祖の部族の一族にのみ、とつがなければならない。</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀上 21:3; 民数記 36:9"> そうすればイスラエルの人々の嗣業は、部族から部族に移るようなことはないであろう。イスラエルの人々は、おのおのその父祖の部族の嗣業をかたく保つべきだからである。</span>
<span className="v" id="v8" data-v="8" data-xref="歴代志上 23:22"> イスラエルの人々の部族のうち、嗣業をもっている娘はみな、その父の部族に属する一族にとつがなければならない。そうすればイスラエルの人々は、おのおのその父祖の嗣業を保つことができる。</span>
<span className="v" id="v9" data-v="9"> こうして嗣業は一つの部族から他の部族に移ることはなかろう。イスラエルの人々の部族はおのおのその嗣業をかたく保つべきだからである』」。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="歴代志下 30:12; マタイによる福音書 28:20; 出エジプト記 39:42–43"> そこでゼロペハデの娘たちは、主がモーセに命じられたようにした。</span>
<span className="v" id="v11" data-v="11" data-xref="民数記 27:1; 民数記 26:33"> すなわちゼロペハデの娘たち、マアラ、テルザ、ホグラ、ミルカおよびノアは、その父の兄弟のむすこたちにとついだ。</span>
<span className="v" id="v12" data-v="12"> 彼女たちはヨセフの子マナセのむすこたちの一族にとついだので、その嗣業はその父の一族の属する部族にとどまった。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="レビ記 27:34; レビ記 26:46; 民数記 22:1"> これらはエリコに近いヨルダンのほとりのモアブの平野で、主がモーセによってイスラエルの人々に命じられた命令とおきてである。</span>
</div>

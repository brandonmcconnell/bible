<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> さて主はモーセに言われた、</span>
<span className="v" id="v2" data-v="2" data-xref="民数記 27:13; 民数記 25:14–18; ヨハネの黙示録 6:10"> 「ミデアンびとにイスラエルの人々のあだを報いなさい。その後、あなたはあなたの民に加えられるであろう」。</span>
<span className="v" id="v3" data-v="3" data-xref="レビ記 26:25; 民数記 25:11; 列王紀下 10:30"> モーセは民に言った、「あなたがたのうちから人を選んで戦いのために武装させ、ミデアンびとを攻めて、主のためミデアンびとに復讐しなさい。</span>
<span className="v" id="v4" data-v="4" data-xref="レビ記 26:8; サムエル記上 14:6; 士師記 7:2"> すなわちイスラエルのすべての部族から、部族ごとに千人ずつを戦いに送り出さなければならない」。</span>
<span className="v" id="v5" data-v="5"> そこでイスラエルの部族のうちから部族ごとに千人ずつを選び、一万二千人を得て、戦いのために武装させた。</span>
<span className="v" id="v6" data-v="6" data-xref="民数記 14:44; 民数記 10:8–9; 歴代志下 13:12–15"> モーセは各部族から千人ずつを戦いにつかわし、また祭司エレアザルの子ピネハスに、聖なる器と吹き鳴らすラッパとを執らせて、共に戦いにつかわした。</span>
<span className="v" id="v7" data-v="7" data-xref="士師記 21:11; 列王紀上 11:15–16; サムエル記上 27:9"> 彼らは主がモーセに命じられたようにミデアンびとと戦って、その男子をみな殺した。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨシュア記 13:21–22; 民数記 25:15; ヨハネの黙示録 2:14"> その殺した者のほかにまたミデアンの王五人を殺した。その名はエビ、レケム、ツル、フル、レバである。またベオルの子バラムをも、つるぎにかけて殺した。</span>
<span className="v" id="v9" data-v="9" data-xref="申命記 20:14; 歴代志下 28:8–10; 歴代志下 28:5"> またイスラエルの人々はミデアンの女たちとその子供たちを捕虜にし、その家畜と、羊の群れと、貨財とをことごとく奪い取り、</span>
<span className="v" id="v10" data-v="10" data-xref="イザヤ書 1:7; サムエル記上 30:1; ヨシュア記 6:24"> そのすまいのある町々と、その部落とを、ことごとく火で焼いた。</span>
<span className="v" id="v11" data-v="11" data-xref="申命記 20:14; ヨシュア記 8:2"> こうして彼らはすべて奪ったものと、かすめたものとは人をも家畜をも取り、</span>
<span className="v" id="v12" data-v="12" data-xref="民数記 22:1"> その生けどった者と、かすめたものと、奪ったものとを携えて、エリコに近いヨルダンのほとりのモアブの平野の宿営におるモーセと祭司エレアザルとイスラエルの人々の会衆のもとへもどってきた。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="民数記 5:2; サムエル記上 30:21; 民数記 31:12"> ときにモーセと祭司エレアザルと会衆のつかさたちはみな宿営の外に出て迎えたが、</span>
<span className="v" id="v14" data-v="14" data-xref="列王紀下 13:19; サムエル記上 15:13–14; 民数記 31:48"> モーセは軍勢の将たち、すなわち戦場から帰ってきた千人の長たちと、百人の長たちに対して怒った。</span>
<span className="v" id="v15" data-v="15" data-xref="サムエル記上 15:3; エレミヤ書 48:10; 申命記 2:34"> モーセは彼らに言った、「あなたがたは女たちをみな生かしておいたのか。</span>
<span className="v" id="v16" data-v="16" data-xref="民数記 25:1–9; ペテロの第二の手紙 2:15; ヨハネの黙示録 2:14"> 彼らはバラムのはかりごとによって、イスラエルの人々に、ペオルのことで主に罪を犯させ、ついに主の会衆のうちに疫病を起すに至った。</span>
<span className="v" id="v17" data-v="17" data-xref="士師記 21:11–12; 申命記 20:16–18; 申命記 7:2"> それで今、この子供たちのうちの男の子をみな殺し、また男と寝て、男を知った女をみな殺しなさい。</span>
<span className="v" id="v18" data-v="18" data-xref="申命記 21:10–14; 歴代志下 28:8–10; 申命記 20:14"> ただし、まだ男と寝ず、男を知らない娘はすべてあなたがたのために生かしておきなさい。</span>
<span className="v" id="v19" data-v="19" data-xref="民数記 19:11–22; 民数記 5:2; 歴代志上 22:8"> そしてあなたがたは七日のあいだ宿営の外にとどまりなさい。あなたがたのうちすべて人を殺した者、およびすべて殺された者に触れた者は、あなたがた自身も、あなたがたの捕虜も共に、三日目と七日目とに身を清めなければならない。</span>
<span className="v" id="v20" data-v="20" data-xref="民数記 19:22; 創世記 35:2; 出エジプト記 19:10"> またすべての衣服と、すべての皮の器と、すべてやぎの毛で作ったものと、すべての木の器とを清めなければならない」。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="民数記 30:16"> 祭司エレアザルは戦いに出たいくさびとたちに言った、「これは主がモーセに命じられた律法の定めである。</span>
<span className="v" id="v22" data-v="22"> 金、銀、青銅、鉄、すず、鉛など、</span>
<span className="v" id="v23" data-v="23" data-xref="民数記 19:9; 民数記 19:17; コリント人への第一の手紙 3:13"> すべて火に耐える物は火の中を通さなければならない。そうすれば清くなるであろう。なおその上、汚れを清める水で、清めなければならない。しかし、すべて火に耐えないものは水の中を通さなければならない。</span>
<span className="v" id="v24" data-v="24" data-xref="レビ記 11:25; レビ記 15:13; レビ記 14:9"> あなたがたは七日目に衣服を洗わなければならない。そして清くなり、その後宿営にはいることができる」。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25"> 主はモーセに言われた、</span>
<span className="v" id="v26" data-v="26"> 「あなたと祭司エレアザルおよび会衆の氏族のかしらたちは、その生けどった人と家畜の獲物の総数を調べ、</span>
<span className="v" id="v27" data-v="27" data-xref="ヨシュア記 22:8; 詩篇 68:12; サムエル記上 30:24–25"> その獲物を戦いに出た勇士と、全会衆とに折半しなさい。</span>
<span className="v" id="v28" data-v="28" data-xref="民数記 18:26; 民数記 31:30; 民数記 31:47"> そして戦いに出たいくさびとに、人または牛、またはろば、または羊を、おのおの五百ごとに一つを取り、みつぎとして主にささげさせなさい。</span>
<span className="v" id="v29" data-v="29" data-xref="出エジプト記 29:27; 申命記 12:19; 申命記 12:12"> すなわち彼らが受ける半分のなかから、それを取り、主にささげる物として祭司エレアザルに渡しなさい。</span>
<span className="v" id="v30" data-v="30" data-xref="民数記 3:31; 民数記 3:7–8; 民数記 3:25"> またイスラエルの人々が受ける半分のなかから、その獲た人または牛、またはろば、または羊などの家畜を、おのおの五十ごとに一つを取り、主の幕屋の務をするレビびとに与えなさい」。</span>
<span className="v" id="v31" data-v="31"> モーセと祭司エレアザルとは主がモーセに命じられたとおりに行った。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32"> そこでその獲物、すなわち、いくさびとたちが奪い取ったものの残りは羊六十七万五千、</span>
<span className="v" id="v33" data-v="33"> 牛七万二千、</span>
<span className="v" id="v34" data-v="34"> ろば六万一千、</span>
<span className="v" id="v35" data-v="35"> 人三万二千、これはみな男と寝ず、男を知らない女であった。</span>
<span className="v" id="v36" data-v="36"> そしてその半分、すなわち戦いに出た者の分は羊三十三万七千五百、</span>
<span className="v" id="v37" data-v="37"> 主にみつぎとした羊は六百七十五。</span>
<span className="v" id="v38" data-v="38"> 牛は三万六千、そのうちから主にみつぎとしたものは七十二。</span>
<span className="v" id="v39" data-v="39"> ろばは三万五百、そのうちから主にみつぎとしたものは六十一。</span>
<span className="v" id="v40" data-v="40"> 人は一万六千、そのうちから主にみつぎとしたものは三十二人であった。</span>
<span className="v" id="v41" data-v="41" data-xref="民数記 18:8; 民数記 18:19; ヘブル人への手紙 7:9–12"> モーセはそのみつぎを主にささげる物として祭司エレアザルに渡した。主がモーセに命じられたとおりである。</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42"> モーセが戦いに出た人々とは別にイスラエルの人々に与えた半分、</span>
<span className="v" id="v43" data-v="43"> すなわち会衆の受けた半分は羊三十三万七千五百、</span>
<span className="v" id="v44" data-v="44"> 牛三万六千、</span>
<span className="v" id="v45" data-v="45"> ろば三万五百、</span>
<span className="v" id="v46" data-v="46"> 人一万六千であって、</span>
<span className="v" id="v47" data-v="47" data-xref="民数記 31:30; ルカによる福音書 10:1–8; イザヤ書 56:10–11"> モーセはイスラエルの人々の受けた半分のなかから、人および獣をおのおの五十ごとに一つを取って、主の幕屋の務をするレビびとに与えた。主がモーセに命じられたとおりである。</span>
</div>
<div className="bp">
<span className="v" id="v48" data-v="48"> 時に軍勢の将であったものども、すなわち千人の長たちと百人の長たちとがモーセのところにきて、</span>
<span className="v" id="v49" data-v="49" data-xref="ヨハネによる福音書 18:9; サムエル記上 30:18–19; 詩篇 72:14"> モーセに言った、「しもべらは、指揮下のいくさびとを数えましたが、われわれのうち、ひとりも欠けた者はありませんでした。</span>
<span className="v" id="v50" data-v="50" data-xref="出エジプト記 30:12; 出エジプト記 30:15–16; 詩篇 116:12"> それで、われわれは、おのおの手に入れた金の飾り物、すなわち腕飾り、腕輪、指輪、耳輪、首飾りなどを主に携えてきて供え物とし、主の前にわれわれの命のあがないをしようと思います」。</span>
<span className="v" id="v51" data-v="51" data-xref="民数記 7:2–6"> モーセと祭司エレアザルとは、彼らから細工を施した金の飾り物を受け取った。</span>
<span className="v" id="v52" data-v="52"> 千人の長たちと百人の長たちとが、主にささげものとした金は合わせて一万六千七百五十シケル。</span>
<span className="v" id="v53" data-v="53" data-xref="申命記 20:14; 民数記 31:32"> いくさびとは、おのおの自分のぶんどり物を獲た。</span>
<span className="v" id="v54" data-v="54" data-xref="出エジプト記 30:16; ゼカリヤ書 6:14; 使徒行伝 10:4"> モーセと祭司エレアザルとは、千人の長たちと百人の長たちとから、その金を受け取り、それを携えて会見の幕屋に入り、主の前に置いてイスラエルの人々のために記念とした。</span>
</div>
</div>

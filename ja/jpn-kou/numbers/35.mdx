<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数記 22:1; 民数記 31:12; 民数記 33:50"> エリコに近いヨルダンのほとりのモアブの平野で、主はモーセに言われた、</span>
<span className="v" id="v2" data-v="2" data-xref="ヨシュア記 14:3–4; エゼキエル書 48:8; ヨシュア記 21:2–42"> 「イスラエルの人々に命じて、その獲た嗣業のうちから、レビびとに住むべき町々を与えさせなさい。また、あなたがたは、その町々の周囲の放牧地をレビびとに与えなければならない。</span>
<span className="v" id="v3" data-v="3" data-xref="歴代志下 11:14; ヨシュア記 21:11; エゼキエル書 45:2"> その町々は彼らの住む所、その放牧地は彼らの家畜と群れ、およびすべての獣のためである。</span>
<span className="v" id="v4" data-v="4"> あなたがたがレビびとに与える町々の放牧地は、町の石がきから一千キュビトの周囲としなければならない。</span>
<span className="v" id="v5" data-v="5"> あなたがたは町の外で東側に二千キュビト、南側に二千キュビト、西側に二千キュビト、北側に二千キュビトを計り、町はその中央にしなければならない。彼らの町の放牧地はこのようにしなければならない。</span>
<span className="v" id="v6" data-v="6" data-xref="ヨシュア記 21:13; ヨシュア記 21:3; 詩篇 9:9"> あなたがたがレビびとに与える町々は六つで、のがれの町とし、人を殺した者がのがれる所としなければならない。なおこのほかに四十二の町を与えなければならない。</span>
<span className="v" id="v7" data-v="7" data-xref="ヨシュア記 21:3–42; 歴代志上 6:54–81"> すなわちあなたがたがレビびとに与える町は合わせて四十八で、これをその放牧地と共に与えなければならない。</span>
<span className="v" id="v8" data-v="8" data-xref="民数記 26:54; 民数記 33:54; ヨシュア記 21:1–42"> あなたがたがイスラエルの人々の所有のうちからレビびとに町々を与えるには、大きい部族からは多く取り、小さい部族からは少なく取り、おのおの受ける嗣業にしたがって、その町々をレビびとに与えなければならない」。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9"> 主はモーセに言われた、</span>
<span className="v" id="v10" data-v="10" data-xref="申命記 12:9; 申命記 19:1–2; レビ記 14:34"> 「イスラエルの人々に言いなさい。あなたがたがヨルダンを渡ってカナンの地にはいるときは、</span>
<span className="v" id="v11" data-v="11" data-xref="出エジプト記 21:13; ヨシュア記 20:2; 民数記 35:6"> あなたがたのために町を選んで、のがれの町とし、あやまって人を殺した者を、そこにのがれさせなければならない。</span>
<span className="v" id="v12" data-v="12" data-xref="ヨシュア記 20:3–6; 申命記 19:6; ヨシュア記 20:9"> これはあなたがたが復讐する者を避けてのがれる町であって、人を殺した者が会衆の前に立って、さばきを受けないうちに、殺されることのないためである。</span>
<span className="v" id="v13" data-v="13"> あなたがたが与える町々のうち、六つをのがれの町としなければならない。</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 19:8–10; 申命記 4:41–43; ヨシュア記 20:7–9"> すなわちヨルダンのかなたで三つの町を与え、カナンの地で三つの町を与えて、のがれの町としなければならない。</span>
<span className="v" id="v15" data-v="15" data-xref="民数記 15:16; ガラテヤ人への手紙 3:28; ローマ人への手紙 3:29"> これらの六つの町は、イスラエルの人々と、他国の人および寄留者のために、のがれの場所としなければならない。すべてあやまって人を殺した者が、そこにのがれるためである。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="レビ記 24:17; 創世記 9:5–6; 申命記 19:11–13"> もし人が鉄の器で、人を打って死なせたならば、その人は故殺人である。故殺人は必ず殺されなければならない。</span>
<span className="v" id="v17" data-v="17" data-xref="出エジプト記 21:18"> またもし人を殺せるほどの石を取って、人を打って死なせたならば、その人は故殺人である。故殺人は必ず殺されなければならない。</span>
<span className="v" id="v18" data-v="18"> あるいは人を殺せるほどの木の器を取って、人を打って死なせたならば、その人は故殺人である。故殺人は必ず殺されなければならない。</span>
<span className="v" id="v19" data-v="19" data-xref="ヨシュア記 20:3; 申命記 19:6; 申命記 19:12"> 血の復讐をする者は、自分でその故殺人を殺すことができる。すなわち彼に出会うとき、彼を殺すことができる。</span>
<span className="v" id="v20" data-v="20" data-xref="出エジプト記 21:14; 申命記 19:11; サムエル記下 3:27"> またもし恨みのために人を突き、あるいは故意に人に物を投げつけて死なせ、</span>
<span className="v" id="v21" data-v="21"> あるいは恨みによって手で人を打って死なせたならば、その打った者は必ず殺されなければならない。彼は故殺人だからである。血の復讐をする者は、その故殺人に出会うとき殺すことができる。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="民数記 35:11; 出エジプト記 21:13; ヨシュア記 20:3"> しかし、もし恨みもないのに思わず人を突き、または、なにごころなく人に物を投げつけ、</span>
<span className="v" id="v23" data-v="23"> あるいは人のいるのも見ずに、人を殺せるほどの石を投げつけて死なせた場合、その人がその敵でもなく、また害を加えようとしたのでもない時は、</span>
<span className="v" id="v24" data-v="24" data-xref="ヨシュア記 20:6; 民数記 35:12"> 会衆はこれらのおきてによって、その人を殺した者と、血の復讐をする者との間をさばかなければならない。</span>
<span className="v" id="v25" data-v="25" data-xref="出エジプト記 29:7; レビ記 4:3; ローマ人への手紙 3:24–26"> すなわち会衆はその人を殺した者を血の復讐をする者の手から救い出して、逃げて行ったのがれの町に返さなければならない。その者は聖なる油を注がれた大祭司の死ぬまで、そこにいなければならない。</span>
<span className="v" id="v26" data-v="26"> しかし、もし人を殺した者が、その逃げて行ったのがれの町の境を出た場合、</span>
<span className="v" id="v27" data-v="27" data-xref="出エジプト記 22:2; 申命記 19:10; 申命記 19:6"> 血の復讐をする者は、のがれの町の境の外で、これに出会い、血の復讐をする者が、その人を殺した者を殺しても、彼には血を流した罪はない。</span>
<span className="v" id="v28" data-v="28" data-xref="ヘブル人への手紙 3:14; ヘブル人への手紙 10:26–30; ヘブル人への手紙 6:4–8"> 彼は大祭司の死ぬまで、そののがれの町におるべきものだからである。大祭司の死んだ後は、人を殺した者は自分の所有の地にかえることができる。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="民数記 27:11; 民数記 27:1"> これらのことはすべてあなたがたの住む所で、代々あなたがたのためのおきての定めとしなければならない。</span>
<span className="v" id="v30" data-v="30" data-xref="ヘブル人への手紙 10:28; 申命記 19:15; マタイによる福音書 18:16"> 人を殺した者、すなわち故殺人はすべて証人の証言にしたがって殺されなければならない。しかし、だれもただひとりの証言によって殺されることはない。</span>
<span className="v" id="v31" data-v="31" data-xref="申命記 19:11–13; 創世記 9:5–6; 詩篇 51:14"> あなたがたは死に当る罪を犯した故殺人の命のあがないしろを取ってはならない。彼は必ず殺されなければならない。</span>
<span className="v" id="v32" data-v="32" data-xref="使徒行伝 4:12; ガラテヤ人への手紙 3:10–13; ガラテヤ人への手紙 2:21"> また、のがれの町にのがれた者のために、あがないしろを取って大祭司の死ぬ前に彼を自分の地に帰り住まわせてはならない。</span>
<span className="v" id="v33" data-v="33" data-xref="ルカによる福音書 11:50–51; 詩篇 106:38; ホセア書 4:2–3"> あなたがたはそのおる所の地を汚してはならない。流血は地を汚すからである。地の上に流された血は、それを流した者の血によらなければあがなうことができない。</span>
<span className="v" id="v34" data-v="34" data-xref="民数記 5:3; 詩篇 135:21; ヨハネの黙示録 21:27"> あなたがたは、その住む所の地、すなわちわたしのおる地を汚してはならない。主なるわたしがイスラエルの人々のうちに住んでいるからである」。</span>
</div>

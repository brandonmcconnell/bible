<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 主はまたモーセとアロンに言われた、</span>
<span className="v" id="v2" data-v="2" data-xref="民数記 3:27; 民数記 3:19"> 「レビの子たちのうちから、コハテの子たちの総数を、その氏族により、その父祖の家にしたがって調べ、</span>
<span className="v" id="v3" data-v="3" data-xref="民数記 4:23; 歴代志上 23:3–5; 列王紀下 11:4–12"> 三十歳以上五十歳以下で、務につき、会見の幕屋で働くことのできる者を、ことごとく数えなさい。</span>
<span className="v" id="v4" data-v="4" data-xref="民数記 4:19; マルコによる福音書 13:34; 民数記 4:30"> コハテの子たちの、会見の幕屋の務は、いと聖なる物にかかわるものであって、次のとおりである。</span>
<span className="v" id="v5" data-v="5" data-xref="マタイによる福音書 27:51; ヘブル人への手紙 9:3; 出エジプト記 40:3"> すなわち、宿営の進む時に、アロンとその子たちとは、まず、はいって、隔ての垂幕を取りおろし、それをもって、あかしの箱をおおい、</span>
<span className="v" id="v6" data-v="6" data-xref="出エジプト記 25:13–15; 出エジプト記 35:19; 民数記 4:7–8"> その上に、じゅごんの皮のおおいを施し、またその上に総青色の布をうちかけ、環にさおをさし入れる。</span>
<span className="v" id="v7" data-v="7" data-xref="レビ記 24:5–8; 出エジプト記 37:10–16; 出エジプト記 25:23–30"> また供えのパンの机の上には、青色の布をうちかけ、その上に、さら、乳香を盛る杯、鉢、および灌祭の瓶を並べ、また絶やさず供えるパンを置き、</span>
<span className="v" id="v8" data-v="8" data-xref="民数記 4:6–7; 民数記 4:11–13; 民数記 4:9"> 緋色の布をその上にうちかけ、じゅごんの皮のおおいをもって、これをおおい、さおをさし入れる。</span>
<span className="v" id="v9" data-v="9" data-xref="出エジプト記 25:31–39; 出エジプト記 37:17–24; ヨハネの黙示録 1:20–1"> また青色の布を取って、燭台とそのともし火ざら、芯切りばさみ、芯取りざら、およびそれに用いるもろもろの油の器をおおい、</span>
<span className="v" id="v10" data-v="10" data-xref="民数記 4:12; 民数記 4:6"> じゅごんの皮のおおいのうちに、燭台とそのもろもろの器をいれて、担架に載せる。</span>
<span className="v" id="v11" data-v="11" data-xref="出エジプト記 40:5; 出エジプト記 30:1–19; 出エジプト記 40:26–27"> また、金の祭壇の上に青色の布をうちかけ、じゅごんの皮のおおいで、これをおおい、そのさおをさし入れる。</span>
<span className="v" id="v12" data-v="12" data-xref="歴代志上 9:29; 出エジプト記 25:9; 歴代志下 4:22"> また聖所の務に用いる務の器をみな取り、青色の布に包み、じゅごんの皮のおおいで、これをおおって、担架に載せる。</span>
<span className="v" id="v13" data-v="13" data-xref="レビ記 6:12–13; 出エジプト記 39:1; 出エジプト記 39:41"> また祭壇の灰を取り去って、紫の布をその祭壇の上にうちかけ、</span>
<span className="v" id="v14" data-v="14" data-xref="歴代志下 4:19; 出エジプト記 38:1–7"> その上に、務をするのに用いるもろもろの器、すなわち、火ざら、肉さし、十能、鉢、および祭壇のすべての器を載せ、またその上に、じゅごんの皮のおおいをうちかけ、そしてさおをさし入れる。</span>
<span className="v" id="v15" data-v="15" data-xref="サムエル記下 6:6–7; 民数記 7:9; 申命記 31:9"> 宿営の進むとき、アロンとその子たちとが、聖所と聖所のすべての器をおおうことを終ったならば、その後コハテの子たちは、それを運ぶために、はいってこなければならない。しかし、彼らは聖なる物に触れてはならない。触れると死ぬであろう。会見の幕屋のうちの、これらの物は、コハテの子たちが運ぶものである。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="出エジプト記 25:6; レビ記 24:2; 出エジプト記 30:23–38"> 祭司アロンの子エレアザルは、ともし油、香ばしい薫香、絶やさず供える素祭および注ぎ油をつかさどり、また幕屋の全体と、そのうちにあるすべての聖なる物、およびその所のもろもろの器をつかさどらなければならない」。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17"> 主はまた、モーセとアロンに言われた、</span>
<span className="v" id="v18" data-v="18" data-xref="サムエル記下 6:6–7; 民数記 17:10; 民数記 18:5"> 「あなたがたはコハテびとの一族を、レビびとのうちから絶えさせてはならない。</span>
<span className="v" id="v19" data-v="19" data-xref="民数記 4:15"> 彼らがいと聖なる物に近づく時、死なないで、命を保つために、このようにしなさい、すなわち、アロンとその子たちが、まず、はいり、彼らをおのおのその働きにつかせ、そのになうべきものを取らせなさい。</span>
<span className="v" id="v20" data-v="20" data-xref="サムエル記上 6:19; 出エジプト記 19:21; 民数記 4:15"> しかし、彼らは、はいって、ひと目でも聖なる物を見てはならない。見るならば死ぬであろう」。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21"> 主はまたモーセに言われた、</span>
<span className="v" id="v22" data-v="22" data-xref="民数記 3:18; 民数記 3:21; 民数記 3:24"> 「あなたはまたゲルションの子たちの総数を、その父祖の家により、その氏族にしたがって調べ、</span>
<span className="v" id="v23" data-v="23" data-xref="民数記 4:3; テモテヘの第一の手紙 1:18; コリント人への第一の手紙 9:7"> 三十歳以上五十歳以下で、務につき、会見の幕屋で働くことのできる者を、ことごとく数えなさい。</span>
<span className="v" id="v24" data-v="24" data-xref="民数記 4:19; 民数記 4:31–32; 民数記 4:47"> ゲルションびとの氏族の務として働くことと、運ぶ物とは次のとおりである。</span>
<span className="v" id="v25" data-v="25" data-xref="民数記 3:25–26; 出エジプト記 26:14; 民数記 7:5–7"> すなわち、彼らは幕屋の幕、会見の幕屋およびそのおおいと、その上のじゅごんの皮のおおい、ならびに会見の幕屋の入口のとばりを運び、</span>
<span className="v" id="v26" data-v="26" data-xref="出エジプト記 35:18; 出エジプト記 27:9"> また庭のあげばり、および幕屋と祭壇のまわりの庭の門の入口のとばりと、そのひも、ならびにそれに用いるすべての器を運ばなければならない。そして彼らはすべてこれらのものについての働きをしなければならない。</span>
<span className="v" id="v27" data-v="27" data-xref="ルカによる福音書 1:70; コリント人への第一の手紙 11:2"> ゲルションびとの子たちのすべての務、すなわち、その運ぶことと、働くこととは、すべてアロンとその子たちの命に従わなければならない。あなたがたは彼らにすべてその運ぶべき物を定めて、これを守らせなければならない。</span>
<span className="v" id="v28" data-v="28" data-xref="民数記 4:33; コリント人への第一の手紙 12:5–6"> これはすなわちゲルションびとの子たちの氏族が、会見の幕屋でする働きであって、彼らの務は祭司アロンの子イタマルの指揮のもとにおかなければならない。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="民数記 3:33–35"> メラリの子たちをもまたあなたはその氏族により、その祖父の家にしたがって調べ、</span>
<span className="v" id="v30" data-v="30" data-xref="民数記 4:3; 民数記 4:23; テモテヘの第二の手紙 2:4"> 三十歳以上五十歳以下で、務につき、会見の幕屋の働きをすることのできる者を、ことごとく数えなさい。</span>
<span className="v" id="v31" data-v="31" data-xref="民数記 3:36–37; 出エジプト記 26:15; 民数記 7:8–9"> 彼らが会見の幕屋でするすべての務にしたがって、その運ぶ責任のある物は次のとおりである。すなわち、幕屋の枠、その横木、その柱、その座、</span>
<span className="v" id="v32" data-v="32" data-xref="出エジプト記 38:21; 歴代志上 9:29; 民数記 3:8"> 庭のまわりの柱、その座、その釘、そのひも、またそのすべての器、およびそれに用いるすべてのものである。あなたがたは彼らが運ぶ責任のある器を、その名によって割り当てなければならない。</span>
<span className="v" id="v33" data-v="33" data-xref="民数記 4:28; ヨシュア記 3:6; イザヤ書 3:6"> これはすなわちメラリの子たちの氏族の働きであって、彼らは祭司アロンの子イタマルの指揮のもとに、会見の幕屋で、このすべての働きをしなければならない」。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34"> そこでモーセとアロン、および会衆のつかさたちは、コハテの子たちをその氏族により、その父祖の家にしたがって調べ、</span>
<span className="v" id="v35" data-v="35" data-xref="歴代志上 23:24; 民数記 4:23; 歴代志上 23:3"> 三十歳以上五十歳以下で、務につき、会見の幕屋で働くことのできる者を、ことごとく数えたが、</span>
<span className="v" id="v36" data-v="36"> その氏族にしたがって数えられた者は二千七百五十人であった。</span>
<span className="v" id="v37" data-v="37"> これはすなわち、コハテびとの氏族の数えられた者で、すべて会見の幕屋で働くことのできる者であった。モーセとアロンが、主のモーセによって命じられたところにしたがって数えたのである。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38"> またゲルションの子たちを、その氏族により、その父祖の家にしたがって調べ、</span>
<span className="v" id="v39" data-v="39"> 三十歳以上五十歳以下で、務につき、会見の幕屋で働くことのできる者を、ことごとく数えたが、</span>
<span className="v" id="v40" data-v="40" data-xref="民数記 3:32"> その氏族により、その父祖の家にしたがって数えられた者は二千六百三十人であった。</span>
<span className="v" id="v41" data-v="41"> これはすなわち、ゲルションの子たちの氏族の数えられた者で、すべて会見の幕屋で働くことのできる者であった。モーセとアロンが、主の命にしたがって数えたのである。</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42"> またメラリの子たちの氏族を、その氏族により、その父祖の家にしたがって調べ、</span>
<span className="v" id="v43" data-v="43"> 三十歳以上五十歳以下で、務につき、会見の幕屋で働くことのできる者を、ことごとく数えたが、</span>
<span className="v" id="v44" data-v="44" data-xref="コリント人への第一の手紙 10:13; コリント人への第二の手紙 12:9–10; コリント人への第一の手紙 12:8–12"> その氏族にしたがって数えられた者は三千二百人であった。</span>
<span className="v" id="v45" data-v="45" data-xref="民数記 4:29"> これはすなわち、メラリの子たちの氏族の数えられた者で、モーセとアロンが、主のモーセによって命じられたところにしたがって数えたのである。</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46"> モーセとアロン、およびイスラエルのつかさたちは、レビびとを、その氏族により、その父祖の家にしたがって調べ、</span>
<span className="v" id="v47" data-v="47" data-xref="コリント人への第一の手紙 12:4–31; ローマ人への手紙 12:6–8; 民数記 4:3"> 三十歳以上五十歳以下で、会見の幕屋にはいって務の働きをし、また、運ぶ働きをする者を、ことごとく数えたが、</span>
<span className="v" id="v48" data-v="48" data-xref="民数記 3:39; マタイによる福音書 20:16; マタイによる福音書 22:15"> その数えられた者は八千五百八十人であった。</span>
<span className="v" id="v49" data-v="49" data-xref="民数記 1:54; 民数記 4:31; 民数記 4:15"> 彼らは主の命により、モーセによって任じられ、おのおのその働きにつき、かつその運ぶところを受け持った。こうして彼らは主のモーセに命じられたように数えられたのである。</span>
</div>
</div>

<span className="v" id="v1" data-v="1" data-xref="レビ記 23:24–25; 歴代志上 15:28; イザヤ書 27:13"> 七月には、その月の第一日に聖会を開かなければならない。なんの労役をもしてはならない。これはあなたがたがラッパを吹く日である。</span>
<span className="v" id="v2" data-v="2" data-xref="民数記 28:27; 民数記 28:19; 民数記 29:36"> あなたがたは燔祭をささげて、主に香ばしいかおりとしなければならない。すなわち若い雄牛一頭、雄羊一頭、一歳の雄の全き小羊七頭をささげなければならない。</span>
<span className="v" id="v3" data-v="3"> その素祭には油を混ぜた麦粉をささげなければならない。すなわち雄牛一頭について一エパの十分の三、雄羊一頭について十分の二をささげ、</span>
<span className="v" id="v4" data-v="4"> また七頭の小羊には一頭ごとに十分の一をささげなければならない。</span>
<span className="v" id="v5" data-v="5" data-xref="民数記 28:30; 民数記 28:15; 民数記 28:22"> また雄やぎ一頭を罪祭としてささげ、あなたがたのために罪のあがないをしなければならない。</span>
<span className="v" id="v6" data-v="6" data-xref="民数記 28:3–8; 民数記 28:11–15; 民数記 29:18"> これは新月の燔祭とその素祭、常燔祭とその素祭、および灌祭のほかのものであって、これらのものの定めにしたがい、香ばしいかおりとして、主に火祭としなければならない。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="マタイによる福音書 5:4; レビ記 16:29–31; ゼカリヤ書 12:10"> またその七月の十日に聖会を開き、かつあなたがたの身を悩まさなければならない。なんの仕事もしてはならない。</span>
<span className="v" id="v8" data-v="8" data-xref="民数記 28:19; 民数記 29:13; 民数記 29:2"> あなたがたは主に燔祭をささげて、香ばしいかおりとしなければならない。すなわち若い雄牛一頭、雄羊一頭、一歳の雄の小羊七頭をささげなければならない。これらはみな全きものでなければならない。</span>
<span className="v" id="v9" data-v="9" data-xref="民数記 15:3–12"> その素祭には油を混ぜた麦粉をささげなければならない。すなわち雄牛一頭につき一エパの十分の三、雄羊一頭につき十分の二をささげ、</span>
<span className="v" id="v10" data-v="10"> また七頭の小羊には一頭ごとに十分の一をささげなければならない。</span>
<span className="v" id="v11" data-v="11" data-xref="レビ記 16:3; レビ記 16:5; 民数記 28:3–8"> また雄やぎ一頭を罪祭としてささげなければならない。これらは贖罪の罪祭と常燔祭とその素祭、および灌祭のほかのものである。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="申命記 16:13–14; ゼカリヤ書 14:16–19; 出エジプト記 34:22"> 七月の十五日に聖会を開かなければならない。なんの労役もしてはならない。七日のあいだ主のために祭をしなければならない。</span>
<span className="v" id="v13" data-v="13" data-xref="民数記 28:11; エズラ記 3:4; 民数記 29:2"> あなたがたは燔祭をささげて、主に香ばしいかおりの火祭としなければならない。すなわち若い雄牛十三頭、雄羊二頭、一歳の雄の小羊十四頭をささげなければならない。これらはみな全きものでなければならない。</span>
<span className="v" id="v14" data-v="14"> その素祭には油を混ぜた麦粉をささげなければならない。すなわち十三頭の雄牛には一頭ごとに十分の三、その二頭の雄羊には一頭ごとに十分の二をささげ、</span>
<span className="v" id="v15" data-v="15"> その十四頭の小羊には一頭ごとに十分の一をささげなければならない。</span>
<span className="v" id="v16" data-v="16"> また雄やぎ一頭を罪祭としてささげなければならない。これらは常燔祭とその素祭および灌祭のほかのものである。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="ヘブル人への手紙 8:13; 詩篇 50:8–9; 詩篇 69:31"> 第二日には若い雄牛十二頭、雄羊二頭、一歳の雄の全き小羊十四頭をささげなければならない。</span>
<span className="v" id="v18" data-v="18" data-xref="民数記 28:7; 民数記 15:4–12; 民数記 28:14"> その雄牛と雄羊と小羊とのための素祭と灌祭とはその数にしたがって、定めのようにささげなければならない。</span>
<span className="v" id="v19" data-v="19" data-xref="民数記 29:11; 民数記 29:25; 民数記 29:22"> また雄やぎ一頭を罪祭としてささげなければならない。これらは常燔祭とその素祭および灌祭のほかのものである。</span>
<span className="v" id="v20" data-v="20"> 第三日には雄牛十一頭、雄羊二頭、一歳の雄の全き小羊十四頭をささげなければならない。</span>
<span className="v" id="v21" data-v="21"> その雄牛と雄羊と小羊とのための素祭と灌祭とは、その数にしたがって定めのようにささげなければならない。</span>
<span className="v" id="v22" data-v="22" data-xref="ヨエル書 1:13; 詩篇 16:4; ヨエル書 2:14"> また雄やぎ一頭を罪祭としてささげなければならない。これらは常燔祭とその素祭および灌祭のほかのものである。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23"> 第四日には雄牛十頭、雄羊二頭、一歳の雄の全き小羊十四頭をささげなければならない。</span>
<span className="v" id="v24" data-v="24"> その雄牛と雄羊と小羊とのための素祭と灌祭とは、その数にしたがって定めのようにささげなければならない。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行伝 13:43; ガラテヤ人への手紙 2:5; ガラテヤ人への手紙 6:9"> また雄やぎ一頭を罪祭としてささげなければならない。これらは常燔祭とその素祭および灌祭のほかのものである。</span>

<div className="bp">
<span className="v" id="v26" data-v="26"> 第五日には雄牛九頭、雄羊二頭、一歳の雄の全き小羊十四頭をささげなければならない。</span>

<span className="v" id="v29" data-v="29"> 第六日には雄牛八頭、雄羊二頭、一歳の雄の全き小羊十四頭をささげなければならない。</span>

<span className="v" id="v33" data-v="33"> その雄牛と雄羊と小羊とのための素祭と灌祭とは、その数にしたがって定めのようにささげなければならない。</span>

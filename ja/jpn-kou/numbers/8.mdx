<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 主はモーセに言われた、</span>
<span className="v" id="v2" data-v="2" data-xref="出エジプト記 25:37; 出エジプト記 40:25; レビ記 24:1–2"> 「アロンに言いなさい、『あなたがともし火をともす時は、七つのともし火で燭台の前方を照すようにしなさい』」。</span>
<span className="v" id="v3" data-v="3"> アロンはそのようにした。すなわち、主がモーセに命じられたように、燭台の前方を照すように、ともし火をともした。</span>
<span className="v" id="v4" data-v="4" data-xref="出エジプト記 25:31–40; 出エジプト記 25:9; 出エジプト記 25:18"> 燭台の造りは次のとおりである。それは金の打ち物で、その台もその花も共に打物造りであった。モーセは主に示された型にしたがって、そのようにその燭台を造った。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5"> 主はまたモーセに言われた、</span>
<span className="v" id="v6" data-v="6" data-xref="コリント人への第二の手紙 7:1; ヤコブの手紙 4:8; 出エジプト記 19:15"> 「レビびとをイスラエルの人々のうちから取って、彼らを清めなさい。</span>
<span className="v" id="v7" data-v="7" data-xref="民数記 19:13; 民数記 19:7–10; レビ記 8:6"> あなたはこのようにして彼らを清めなければならない。すなわち、罪を清める水を彼らに注ぎかけ、彼らに全身をそらせ、衣服を洗わせて、身を清めさせ、</span>
<span className="v" id="v8" data-v="8" data-xref="レビ記 2:1; 出エジプト記 29:1; レビ記 16:3"> そして彼らに若い雄牛一頭と、油を混ぜた麦粉の素祭とを取らせなさい。あなたはまた、ほかに若い雄牛を罪祭のために取らなければならない。</span>
<span className="v" id="v9" data-v="9" data-xref="出エジプト記 40:12; レビ記 8:3; 出エジプト記 29:4–37"> そして、あなたはレビびとを会見の幕屋の前に連れてきて、イスラエルの人々の全会衆を集め、</span>
<span className="v" id="v10" data-v="10" data-xref="レビ記 1:4; 使徒行伝 6:6; テモテヘの第一の手紙 4:14"> レビびとを主の前に進ませ、イスラエルの人々をして、手をレビびとの上に置かせなければならない。</span>
<span className="v" id="v11" data-v="11" data-xref="レビ記 7:30; レビ記 8:29; 民数記 1:49–53"> そしてアロンは、レビびとをイスラエルの人々のささげる揺祭として、主の前にささげなければならない。これは彼らに主の務をさせるためである。</span>
<span className="v" id="v12" data-v="12" data-xref="ヘブル人への手紙 10:4–10; 出エジプト記 29:10; レビ記 1:4"> それからあなたはレビびとをして、手をかの雄牛の頭の上に置かせ、その一つを罪祭とし、一つを燔祭として主にささげ、レビびとのために罪のあがないをしなければならない。</span>
<span className="v" id="v13" data-v="13" data-xref="民数記 8:21; 民数記 8:11; ローマ人への手紙 15:16"> あなたはレビびとを、アロンとその子たちの前に立たせ、これを揺祭として主にささげなければならない。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="民数記 3:45; マラキ書 3:17; 民数記 18:6"> こうして、あなたはレビびとをイスラエルの人々のうちから分かち、レビびとをわたしのものとしなければならない。</span>
<span className="v" id="v15" data-v="15" data-xref="民数記 8:11; 民数記 8:13; 民数記 3:23–37"> こうして後レビびとは会見の幕屋にはいって務につくことができる。あなたは彼らを清め、彼らをささげて揺祭としなければならない。</span>
<span className="v" id="v16" data-v="16" data-xref="民数記 3:12; 民数記 3:45; 民数記 3:9"> 彼らはイスラエルの人々のうちから、全くわたしにささげられたものだからである。イスラエルの人々のうちの初めに生れた者、すなわち、すべてのういごの代りに、わたしは彼らを取ってわたしのものとした。</span>
<span className="v" id="v17" data-v="17" data-xref="出エジプト記 13:2; ルカによる福音書 2:23; 出エジプト記 13:12–15"> イスラエルの人々のうちのういごは、人も獣も、みなわたしのものだからである。わたしはエジプトの地で、すべてのういごを撃ち殺した日に、彼らを聖別してわたしのものとした。</span>
<span className="v" id="v18" data-v="18"> それでわたしはイスラエルの人々のうちの、すべてのういごの代りにレビびとを取った。</span>
<span className="v" id="v19" data-v="19" data-xref="民数記 1:53; 民数記 16:46; 歴代志下 26:16–20"> わたしはイスラエルの人々のうちからレビびとを取って、アロンとその子たちに与え、彼らに会見の幕屋で、イスラエルの人々に代って務をさせ、またイスラエルの人々のために罪のあがないをさせるであろう。これはイスラエルの人々が、聖所に近づいて、イスラエルの人々のうちに災の起ることのないようにするためである」。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20"> モーセとアロン、およびイスラエルの人々の全会衆は、すべて主がレビびとの事につき、モーセに命じられた所にしたがって、レビびとに行った、すなわち、イスラエルの人々は、そのように彼らに行った。</span>
<span className="v" id="v21" data-v="21" data-xref="民数記 8:7; 民数記 19:19; 民数記 8:15"> そこでレビびとは身を清め、その衣服を洗った。アロンは彼らを主の前にささげて揺祭とした。アロンはまた彼らのために、罪のあがないをして彼らを清めた。</span>
<span className="v" id="v22" data-v="22" data-xref="歴代志下 31:2; 歴代志下 35:8–15; 民数記 8:15"> こうして後、レビびとは会見の幕屋にはいって、アロンとその子たちに仕えて務をした。すなわち、彼らはレビびとの事について、主がモーセに命じられた所にしたがって、そのように彼らに行った。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23"> 主はまたモーセに言われた、</span>
<span className="v" id="v24" data-v="24" data-xref="民数記 4:3; 歴代志上 23:3; 民数記 4:23"> 「レビびとは次のようにしなければならない。すなわち、二十五歳以上の者は務につき、会見の幕屋の働きをしなければならない。</span>
<span className="v" id="v25" data-v="25" data-xref="民数記 4:23; テモテヘの第二の手紙 4:7"> しかし、五十歳からは務の働きを退き、重ねて務をしてはならない。</span>
<span className="v" id="v26" data-v="26" data-xref="民数記 1:53; 民数記 3:32; テモテヘの第一の手紙 4:15"> ただ、会見の幕屋でその兄弟たちの務の助けをすることができる。しかし、務をしてはならない。あなたがレビびとにその務をさせるには、このようにしなければならない」。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出エジプト記 6:20; 創世記 10:1; 出エジプト記 6:16"> 主がシナイ山で、モーセと語られた時の、アロンとモーセの一族は、次のとおりであった。</span>
<span className="v" id="v2" data-v="2" data-xref="出エジプト記 6:23; 民数記 26:60; 出エジプト記 28:1"> アロンの子たちの名は、次のとおりである。長子はナダブ、次はアビウ、エレアザル、イタマル。</span>
<span className="v" id="v3" data-v="3" data-xref="出エジプト記 28:41; レビ記 8:30; レビ記 8:12"> これがアロンの子たちの名であって、彼らはみな油を注がれ、祭司の職に任じられて祭司となった。</span>
<span className="v" id="v4" data-v="4" data-xref="レビ記 10:1–2; 民数記 26:61"> ナダブとアビウとは、シナイの荒野において、異火を主の前にささげたので、主の前で死んだ。彼らには子供がなかった。そしてエレアザルとイタマルとが、父アロンの前で祭司の務をした。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5"> 主はまたモーセに言われた、</span>
<span className="v" id="v6" data-v="6" data-xref="申命記 10:8; 民数記 2:33; 民数記 1:49–53"> 「レビの部族を召し寄せ、祭司アロンの前に立って仕えさせなさい。</span>
<span className="v" id="v7" data-v="7" data-xref="民数記 1:50; 民数記 8:15; 民数記 8:11"> 彼らは会見の幕屋の前にあって、アロンと全会衆のために、その務をし、幕屋の働きをしなければならない。</span>
<span className="v" id="v8" data-v="8" data-xref="民数記 4:33; 民数記 10:17; イザヤ書 52:11"> すなわち、彼らは会見の幕屋の、すべての器をまもり、イスラエルの人々のために務をし、幕屋の働きをしなければならない。</span>
<span className="v" id="v9" data-v="9" data-xref="民数記 8:19; 民数記 18:6–7; エペソ人への手紙 4:8"> あなたはレビびとを、アロンとその子たちとに、与えなければならない。彼らはイスラエルの人々のうちから、全くアロンに与えられたものである。</span>
<span className="v" id="v10" data-v="10" data-xref="民数記 1:51; 民数記 3:38; ローマ人への手紙 12:7"> あなたはアロンとその子たちとを立てて、祭司の職を守らせなければならない。ほかの人で近づくものは殺されるであろう」。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11"> 主はまたモーセに言われた、</span>
<span className="v" id="v12" data-v="12" data-xref="民数記 3:41; 民数記 8:16; 民数記 18:6"> 「わたしは、イスラエルの人々のうちの初めに生れたすべてのういごの代りに、レビびとをイスラエルの人々のうちから取るであろう。レビびとは、わたしのものとなるであろう。</span>
<span className="v" id="v13" data-v="13" data-xref="ルカによる福音書 2:23; 出エジプト記 13:12; 出エジプト記 13:2"> ういごはすべてわたしのものだからである。わたしは、エジプトの国において、すべてのういごを撃ち殺した日に、イスラエルのういごを、人も獣も、ことごとく聖別して、わたしに帰せしめた。彼らはわたしのものとなるであろう。わたしは主である」。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14"> 主はまたシナイの荒野でモーセに言われた、</span>
<span className="v" id="v15" data-v="15" data-xref="民数記 26:62; マルコによる福音書 10:14; テモテヘの第二の手紙 3:15"> 「あなたはレビの子たちを、その父祖の家により、その氏族によって数えなさい。すなわち、一か月以上の男子を数えなければならない」。</span>
<span className="v" id="v16" data-v="16" data-xref="民数記 3:39; 民数記 4:37; 民数記 4:49"> それでモーセは主の言葉にしたがって、命じられたとおりに、それを数えた。</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 46:11; 出エジプト記 6:16–19; 民数記 15:5–23"> レビの子たちの名は次のとおりである。すなわち、ゲルション、コハテ、メラリ。</span>
<span className="v" id="v18" data-v="18" data-xref="歴代志上 6:17; 歴代志上 26:1–32; 出エジプト記 6:17–19"> ゲルションの子たちの名は、その氏族によれば次のとおりである。すなわち、リブニ、シメイ。</span>
<span className="v" id="v19" data-v="19" data-xref="出エジプト記 6:18; 歴代志上 6:18; 歴代志上 15:17–21"> コハテの子たちは、その氏族によれば、アムラム、イヅハル、ヘブロン、ウジエル。</span>
<span className="v" id="v20" data-v="20" data-xref="出エジプト記 6:19; 歴代志上 6:19; 民数記 3:33"> メラリの子たちは、その氏族によれば、マヘリ、ムシ。これらはその父祖の家によるレビの氏族である。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21"> ゲルションからリブニびとの氏族と、シメイびとの氏族とが出た。これらはゲルションびとの氏族である。</span>
<span className="v" id="v22" data-v="22" data-xref="民数記 4:38–40"> その数えられた者、すなわち、一か月以上の男子の数は合わせて七千五百人であった。</span>
<span className="v" id="v23" data-v="23" data-xref="民数記 1:53; 民数記 2:17"> ゲルションびとの氏族は幕屋の後方、すなわち、西の方に宿営し、</span>
<span className="v" id="v24" data-v="24"> ラエルの子エリアサフが、ゲルションびとの父祖の家のつかさとなるであろう。</span>
<span className="v" id="v25" data-v="25" data-xref="出エジプト記 25:9; 歴代志上 23:32; 歴代志上 9:14–33"> 会見の幕屋の、ゲルションの子たちの務は、幕屋、天幕とそのおおい、会見の幕屋の入口のとばり、</span>
<span className="v" id="v26" data-v="26" data-xref="出エジプト記 35:18; 出エジプト記 38:9–16; 出エジプト記 27:9–16"> 庭のあげばり、幕屋と祭壇のまわりの庭の入口のとばり、そのひも、およびすべてそれに用いる物を守ることである。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="歴代志上 26:23; 民数記 3:19; 歴代志上 23:12"> また、コハテからアムラムびとの氏族、イヅハルびとの氏族、ヘブロンびとの氏族、ウジエルびとの氏族が出た。これらはコハテびとの氏族である。</span>
<span className="v" id="v28" data-v="28" data-xref="民数記 3:31; 民数記 4:35–36; 民数記 3:7"> 一か月以上の男子の数は、合わせて八千六百人であって、聖所の務を守る者たちである。</span>
<span className="v" id="v29" data-v="29" data-xref="民数記 1:53; 民数記 3:23; 民数記 2:10"> コハテの子たちの氏族は、幕屋の南の方に宿営し、</span>
<span className="v" id="v30" data-v="30"> ウジエルの子エリザパンが、コハテびとの氏族の父祖の家のつかさとなるであろう。</span>
<span className="v" id="v31" data-v="31" data-xref="出エジプト記 36:35–36; 出エジプト記 27:1–8; 出エジプト記 26:31–33"> 彼らの務は、契約の箱、机、燭台、二つの祭壇、聖所の務に用いる器、とばり、およびすべてそれに用いる物を守ることである。</span>
<span className="v" id="v32" data-v="32" data-xref="民数記 4:27; 民数記 4:16; 民数記 20:25–28"> 祭司アロンの子エレアザルが、レビびとのつかさたちの長となり、聖所の務を守るものたちを監督するであろう。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="民数記 3:20; 歴代志上 6:19; 歴代志上 23:21"> メラリからマヘリびとの氏族と、ムシびとの氏族とが出た。これらはメラリの氏族である。</span>
<span className="v" id="v34" data-v="34" data-xref="民数記 2:9; 民数記 2:11; 民数記 1:21"> その数えられた者、すなわち、一か月以上の男子の数は、合わせて六千二百人であった。</span>
<span className="v" id="v35" data-v="35" data-xref="民数記 1:53; 民数記 2:25; 民数記 3:28–29"> アビハイルの子ツリエルが、メラリの氏族の父祖の家のつかさとなるであろう。彼らは幕屋の北の方に宿営しなければならない。</span>
<span className="v" id="v36" data-v="36" data-xref="出エジプト記 26:32; 出エジプト記 26:37; 出エジプト記 26:15–29"> メラリの子たちが、その務として管理すべきものは、幕屋の枠、その横木、その柱、その座、そのすべての器、およびそれに用いるすべての物、</span>
<span className="v" id="v37" data-v="37"> ならびに庭のまわりの柱とその座、その釘、およびそのひもである。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="民数記 3:10; 民数記 1:53; 民数記 2:3"> また幕屋の前、その東の方、すなわち、会見の幕屋の東の方に宿営する者は、モーセとアロン、およびアロンの子たちであって、イスラエルの人々の務に代って、聖所の務を守るものである。ほかの人で近づく者は殺されるであろう。</span>
<span className="v" id="v39" data-v="39" data-xref="民数記 26:62; マタイによる福音書 7:14; 民数記 4:47–48"> モーセとアロンとが、主の言葉にしたがって数えたレビびとで、その氏族によって数えられた者、一か月以上の男子は、合わせて二万二千人であった。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="民数記 3:15; ルカによる福音書 10:20; 詩篇 87:6"> 主はまたモーセに言われた、「あなたは、イスラエルの人々のうち、すべてういごである男子の一か月以上のものを数えて、その名の数を調べなさい。</span>
<span className="v" id="v41" data-v="41" data-xref="民数記 3:12; 民数記 3:45; 民数記 8:16"> また主なるわたしのために、イスラエルの人々のうちの、すべてのういごの代りにレビびとを取り、またイスラエルの人々の家畜のうちの、すべてのういごの代りに、レビびとの家畜を取りなさい」。</span>
<span className="v" id="v42" data-v="42"> そこでモーセは主の命じられたように、イスラエルの人々のうちの、すべてのういごを数えた。</span>
<span className="v" id="v43" data-v="43" data-xref="民数記 3:39"> その数えられたういごの男子、すべて一か月以上の者は、その名の数によると二万二千二百七十三人であった。</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44"> 主はモーセに言われた、</span>
<span className="v" id="v45" data-v="45" data-xref="民数記 3:12; 民数記 3:40–41"> 「あなたはイスラエルの人々のうちの、すべてのういごの代りに、レビびとを取り、また彼らの家畜の代りに、レビびとの家畜を取りなさい。レビびとはわたしのものとなる。わたしは主である。</span>
<span className="v" id="v46" data-v="46" data-xref="出エジプト記 13:13; 民数記 18:15–16"> またイスラエルの人々のういごは、レビびとの数を二百七十三人超過しているから、そのあがないのために、</span>
<span className="v" id="v47" data-v="47" data-xref="出エジプト記 30:13; レビ記 27:6; 民数記 18:16"> そのあたまかずによって、ひとりごとに銀五シケルを取らなければならない。すなわち、聖所のシケルにしたがって、それを取らなければならない。一シケルは二十ゲラである。</span>
<span className="v" id="v48" data-v="48"> あなたは、その超過した者をあがなう金を、アロンと、その子たちに渡さなければならない」。</span>
<span className="v" id="v49" data-v="49"> そこでモーセは、レビびとによってあがなわれた者を超過した人々から、あがないの金を取った。</span>
<span className="v" id="v50" data-v="50" data-xref="民数記 3:46–47; ペテロの第一の手紙 3:18; マタイによる福音書 20:28"> すなわち、モーセは、イスラエルの人々のういごから、聖所のシケルにしたがって千三百六十五シケルの銀を取り、</span>
<span className="v" id="v51" data-v="51" data-xref="民数記 3:48; 民数記 16:15; サムエル記上 12:3–4"> そのあがないの金を、主の言葉にしたがって、アロンとその子たちに渡した。主がモーセに命じられたとおりである。</span>
</div>
</div>

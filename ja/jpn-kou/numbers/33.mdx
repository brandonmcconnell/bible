<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="詩篇 77:20; ミカ書 6:4; 出エジプト記 12:51"> イスラエルの人々が、モーセとアロンとに導かれ、その部隊に従って、エジプトの国を出てから経た旅路は次のとおりである。</span>
<span className="v" id="v2" data-v="2" data-xref="民数記 9:17–23; 申命記 10:11; 民数記 10:6"> モーセは主の命により、その旅路にしたがって宿駅を書きとめた。その宿駅にしたがえば旅路は次のとおりである。</span>
<span className="v" id="v3" data-v="3" data-xref="出エジプト記 14:8; 出エジプト記 12:37; 出エジプト記 13:4"> 彼らは正月の十五日にラメセスを出立した。すなわち過越の翌日イスラエルの人々は、すべてのエジプトびとの目の前を意気揚々と出立した。</span>
<span className="v" id="v4" data-v="4" data-xref="出エジプト記 12:12; イザヤ書 19:1; 出エジプト記 18:11"> その時エジプトびとは、主に撃ち殺されたすべてのういごを葬っていた。主はまた彼らの神々にも罰を加えられた。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="出エジプト記 12:37"> こうしてイスラエルの人々はラメセスを出立してスコテに宿営し、</span>
<span className="v" id="v6" data-v="6" data-xref="出エジプト記 13:20"> スコテを出立して荒野の端にあるエタムに宿営し、</span>
<span className="v" id="v7" data-v="7" data-xref="出エジプト記 14:2; 出エジプト記 14:9; 民数記 33:8"> エタムを出立してバアル・ゼポンの前にあるピハヒロテに引き返してミグドルの前に宿営し、</span>
<span className="v" id="v8" data-v="8" data-xref="出エジプト記 15:22–26; 出エジプト記 14:21–31"> ピハヒロテを出立して、海のなかをとおって荒野に入り、エタムの荒野を三日路ほど行って、メラに宿営し、</span>
<span className="v" id="v9" data-v="9" data-xref="出エジプト記 15:27"> メラを出立し、エリムに行って宿営した。エリムには水の泉十二と、なつめやし七十本とがあった。</span>
<span className="v" id="v10" data-v="10" data-xref="出エジプト記 16:1; 出エジプト記 17:1"> エリムを出立して紅海のほとりに宿営し、</span>
<span className="v" id="v11" data-v="11" data-xref="出エジプト記 16:1"> 紅海を出立してシンの荒野に宿営し、</span>
<span className="v" id="v12" data-v="12"> シンの荒野を出立してドフカに宿営し、</span>
<span className="v" id="v13" data-v="13"> ドフカを出立してアルシに宿営し、</span>
<span className="v" id="v14" data-v="14" data-xref="出エジプト記 17:1–8; 出エジプト記 19:2"> アルシを出立してレピデムに宿営した。そこには民の飲む水がなかった。</span>
<span className="v" id="v15" data-v="15" data-xref="出エジプト記 19:1–2; 出エジプト記 16:1"> レピデムを出立してシナイの荒野に宿営し、</span>
<span className="v" id="v16" data-v="16" data-xref="民数記 11:34; 民数記 10:11–13; 民数記 10:33"> シナイの荒野を出立してキブロテ・ハッタワに宿営し、</span>
<span className="v" id="v17" data-v="17" data-xref="民数記 11:35"> キブロテ・ハッタワを出立してハゼロテに宿営し、</span>
<span className="v" id="v18" data-v="18" data-xref="民数記 12:16"> ハゼロテを出立してリテマに宿営し、</span>
<span className="v" id="v19" data-v="19"> リテマを出立してリンモン・パレツに宿営し、</span>
<span className="v" id="v20" data-v="20"> リンモン・パレツを出立してリブナに宿営し、</span>
<span className="v" id="v21" data-v="21" data-xref="申命記 1:1"> リブナを出立してリッサに宿営し、</span>
<span className="v" id="v22" data-v="22"> リッサを出立してケヘラタに宿営し、</span>
<span className="v" id="v23" data-v="23"> ケヘラタを出立してシャペル山に宿営し、</span>
<span className="v" id="v24" data-v="24"> シャペル山を出立してハラダに宿営し、</span>
<span className="v" id="v25" data-v="25"> ハラダを出立してマケロテに宿営し、</span>
<span className="v" id="v26" data-v="26"> マケロテを出立してタハテに宿営し、</span>
<span className="v" id="v27" data-v="27"> タハテを出立してテラに宿営し、</span>
<span className="v" id="v28" data-v="28"> テラを出立してミテカに宿営し、</span>
<span className="v" id="v29" data-v="29"> ミテカを出立してハシモナに宿営し、</span>
<span className="v" id="v30" data-v="30" data-xref="申命記 10:5–6"> ハシモナを出立してモセラに宿営し、</span>
<span className="v" id="v31" data-v="31" data-xref="申命記 10:6; 創世記 36:27; 歴代志上 1:43"> モセラを出立してベネヤカンに宿営し、</span>
<span className="v" id="v32" data-v="32" data-xref="申命記 10:7"> ベネヤカンを出立してホル・ハギデガデに宿営し、</span>
<span className="v" id="v33" data-v="33" data-xref="申命記 10:7"> ホル・ハギデガデを出立してヨテバタに宿営し、</span>
<span className="v" id="v34" data-v="34"> ヨテバタを出立してアブロナに宿営し、</span>
<span className="v" id="v35" data-v="35" data-xref="申命記 2:8; 列王紀上 9:26; 列王紀上 22:48"> アブロナを出立してエジオン・ゲベルに宿営し、</span>
<span className="v" id="v36" data-v="36" data-xref="民数記 20:1; 民数記 27:14; 申命記 32:51"> エジオン・ゲベルを出立してチンの荒野すなわちカデシに宿営し、</span>
<span className="v" id="v37" data-v="37" data-xref="民数記 21:4; 民数記 20:22–23; 民数記 20:16"> カデシを出立してエドムの国の端にあるホル山に宿営した。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="申命記 10:6; 申命記 32:50; 民数記 20:24–28"> イスラエルの人々がエジプトの国を出て四十年目の五月一日に、祭司アロンは主の命によりホル山に登って、その所で死んだ。</span>
<span className="v" id="v39" data-v="39"> アロンはホル山で死んだとき百二十三歳であった。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="民数記 21:1–9"> カナンの地のネゲブに住んでいたカナンびとアラデの王は、イスラエルの人々の来るのを聞いた。</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="民数記 21:4"> ついで、ホル山を出立してザルモナに宿営し、</span>
<span className="v" id="v42" data-v="42"> ザルモナを出立してプノンに宿営し、</span>
<span className="v" id="v43" data-v="43" data-xref="民数記 21:10"> プノンを出立してオボテに宿営し、</span>
<span className="v" id="v44" data-v="44" data-xref="民数記 21:11"> オボテを出立してモアブの境にあるイエ・アバリムに宿営し、</span>
<span className="v" id="v45" data-v="45"> イエ・アバリムを出立してデボン・ガドに宿営し、</span>
<span className="v" id="v46" data-v="46" data-xref="エレミヤ書 48:18; エゼキエル書 6:14; イザヤ書 15:2"> デボン・ガドを出立してアルモン・デブラタイムに宿営し、</span>
<span className="v" id="v47" data-v="47" data-xref="申命記 32:49; 申命記 34:1; 民数記 27:12"> アルモン・デブラタイムを出立してネボの前にあるアバリムの山に宿営し、</span>
<span className="v" id="v48" data-v="48" data-xref="民数記 22:1"> アバリムの山を出立してエリコに近いヨルダンのほとりのモアブの平野に宿営した。</span>
<span className="v" id="v49" data-v="49" data-xref="ヨシュア記 2:1; ヨシュア記 13:20; 民数記 25:1–9"> すなわちヨルダンのほとりのモアブの平野で、ベテエシモテとアベル・シッテムとの間に宿営した。</span>
</div>
<div className="bp">
<span className="v" id="v50" data-v="50" data-xref="民数記 33:48–49"> エリコに近いヨルダンのほとりのモアブの平野で、主はモーセに言われた、</span>
<span className="v" id="v51" data-v="51" data-xref="ヨシュア記 3:17; 申命記 9:1; 申命記 7:1"> 「イスラエルの人々に言いなさい。あなたがたがヨルダンを渡ってカナンの地にはいるときは、</span>
<span className="v" id="v52" data-v="52" data-xref="出エジプト記 23:24; レビ記 26:1; 申命記 20:16–18"> その地の住民をことごとくあなたがたの前から追い払い、すべての石像をこぼち、すべての鋳像をこぼち、すべての高き所を破壊しなければならない。</span>
<span className="v" id="v53" data-v="53" data-xref="申命記 11:31; 詩篇 115:16; 申命記 32:8"> またあなたがたはその地の民を追い払って、そこに住まなければならない。わたしがその地をあなたがたの所有として与えたからである。</span>
<span className="v" id="v54" data-v="54" data-xref="民数記 26:53–56; ヨシュア記 18:11–48; ヨシュア記 15:1–12"> あなたがたは、おのおの氏族ごとにくじを引き、その地を分けて嗣業としなければならない。大きい部族には多くの嗣業を与え、小さい部族には少しの嗣業を与えなければならない。そのくじの当った所がその所有となるであろう。あなたがたは父祖の部族にしたがって、それを継がなければならない。</span>
<span className="v" id="v55" data-v="55" data-xref="士師記 2:3; 詩篇 106:34–36; 申命記 7:16"> しかし、その地の住民をあなたがたの前から追い払わないならば、その残して置いた者はあなたがたの目にとげとなり、あなたがたの脇にいばらとなり、あなたがたの住む国において、あなたがたを悩ますであろう。</span>
<span className="v" id="v56" data-v="56" data-xref="ルカによる福音書 21:23–24; 申命記 28:63; レビ記 20:23"> また、わたしは彼らにしようと思ったとおりに、あなたがたにするであろう」。</span>
</div>
</div>

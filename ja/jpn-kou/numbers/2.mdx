<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 主はモーセとアロンに言われた、</span>
<span className="v" id="v2" data-v="2" data-xref="コリント人への第一の手紙 14:40; 民数記 10:22; 民数記 1:50"> 「イスラエルの人々は、おのおのその部隊の旗のもとに、その父祖の家の旗印にしたがって宿営しなければならない。また会見の幕屋のまわりに、それに向かって宿営しなければならない。</span>
<span className="v" id="v3" data-v="3" data-xref="歴代志上 2:10; ルツ記 4:20; ルカによる福音書 3:32–33"> すなわち、日の出る方、東に宿営するものは、ユダの宿営の旗につく者であって、その部隊にしたがって宿営し、アミナダブの子ナションが、ユダの子たちのつかさとなるであろう。</span>
<span className="v" id="v4" data-v="4" data-xref="民数記 26:22; 民数記 1:27"> その部隊、すなわち、数えられた者は七万四千六百人である。</span>
<span className="v" id="v5" data-v="5" data-xref="民数記 1:8; 民数記 7:18; 民数記 7:23"> そのかたわらに宿営する者はイッサカルの部族で、ツアルの子ネタニエルが、イッサカルの子たちのつかさとなるであろう。</span>
<span className="v" id="v6" data-v="6" data-xref="民数記 26:25; 民数記 1:29"> その部隊、すなわち、数えられた者は五万四千四百人である。</span>
<span className="v" id="v7" data-v="7" data-xref="民数記 1:9; 民数記 7:24; 民数記 10:16"> 次はゼブルンの部族で、ヘロンの子エリアブが、ゼブルンの子たちのつかさとなるであろう。</span>
<span className="v" id="v8" data-v="8" data-xref="民数記 26:26–27; 民数記 1:31"> その部隊、すなわち、数えられた者は五万七千四百人である。</span>
<span className="v" id="v9" data-v="9" data-xref="民数記 10:14"> ユダの宿営の、その部隊にしたがって数えられた者は、合わせて十八万六千四百人である。これらの者は、まっ先に進まなければならない。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="民数記 1:5; 創世記 49:3–4; 民数記 7:35"> 南の方では、ルベンの宿営の旗につく者が、その部隊にしたがっており、シデウルの子エリヅルが、ルベンの子たちのつかさとなるであろう。</span>
<span className="v" id="v11" data-v="11" data-xref="民数記 26:7; 民数記 1:21"> その部隊、すなわち、数えられた者は四万六千五百人である。</span>
<span className="v" id="v12" data-v="12" data-xref="民数記 1:6; 民数記 10:19; 民数記 7:41"> そのかたわらに宿営する者はシメオンの部族で、ツリシャダイの子シルミエルが、シメオンの子たちのつかさとなるであろう。</span>
<span className="v" id="v13" data-v="13" data-xref="民数記 26:14; 民数記 1:23"> その部隊、すなわち、数えられた者は五万九千三百人である。</span>
<span className="v" id="v14" data-v="14" data-xref="民数記 1:14; 民数記 7:42; 民数記 7:47"> 次はガドの部族で、デウエルの子エリアサフが、ガドの子たちのつかさとなるであろう。</span>
<span className="v" id="v15" data-v="15" data-xref="民数記 26:18; 民数記 1:25"> その部隊、すなわち、数えられた者は四万五千六百五十人である。</span>
<span className="v" id="v16" data-v="16" data-xref="民数記 10:18; 民数記 2:9; 民数記 2:24"> ルベンの宿営の、その部隊にしたがって数えられた者は、合わせて十五万一千四百五十人である。これらの者は二番目に進まなければならない。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="民数記 10:21; 民数記 10:17; 民数記 3:38"> その次に会見の幕屋を、レビびとの宿営とともに、もろもろの宿営の中央にして進まなければならない。彼らは宿営するのと同じように、おのおのその位置で、その旗にしたがって進まなければならない。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="民数記 1:10; 民数記 10:22; 創世記 48:14–20"> 西の方では、エフライムの宿営の旗につく者が、その部隊にしたがっており、アミホデの子エリシャマが、エフライムの子たちのつかさとなるであろう。</span>
<span className="v" id="v19" data-v="19" data-xref="民数記 1:33; 民数記 26:37"> その部隊、すなわち、数えられた者は四万五百人である。</span>
<span className="v" id="v20" data-v="20" data-xref="民数記 1:10; 民数記 7:54; 民数記 10:23"> そのかたわらにマナセの部族がおって、パダヅルの子ガマリエルが、マナセの子たちのつかさとなるであろう。</span>
<span className="v" id="v21" data-v="21" data-xref="民数記 26:34; 民数記 1:35"> その部隊、すなわち、数えられた者は三万二千二百人である。</span>
<span className="v" id="v22" data-v="22" data-xref="民数記 1:11; 民数記 7:60; 民数記 10:24"> 次にベニヤミンの部族がおって、ギデオニの子アビダンが、ベニヤミンの子たちのつかさとなるであろう。</span>
<span className="v" id="v23" data-v="23" data-xref="民数記 1:37; 民数記 26:41"> その部隊、すなわち、数えられた者は三万五千四百人である。</span>
<span className="v" id="v24" data-v="24" data-xref="民数記 10:22; 民数記 2:31; 詩篇 80:2"> エフライムの宿営の、その部隊にしたがって数えられた者は、合わせて十万八千百人である。これらの者は三番目に進まなければならない。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="民数記 1:12; 民数記 7:66; 民数記 10:25"> 北の方では、ダンの宿営の旗につく者が、その部隊にしたがっており、アミシャダイの子アヒエゼルが、ダンの子たちのつかさとなるであろう。</span>
<span className="v" id="v26" data-v="26" data-xref="民数記 26:43; 民数記 1:39"> その部隊、すなわち、数えられた者は六万二千七百人である。</span>
<span className="v" id="v27" data-v="27" data-xref="民数記 1:13; 民数記 7:77; 民数記 7:72"> そのかたわらに宿営する者は、アセルの部族であって、オクランの子パギエルが、アセルの子たちのつかさとなるであろう。</span>
<span className="v" id="v28" data-v="28" data-xref="民数記 1:41; 民数記 26:47"> その部隊、すなわち、数えられた者は四万一千五百人である。</span>
<span className="v" id="v29" data-v="29" data-xref="民数記 1:15; 民数記 10:27; 民数記 26:48–50"> 次にナフタリの部族がおって、エナンの子アヒラが、ナフタリの子たちのつかさとなるであろう。</span>
<span className="v" id="v30" data-v="30" data-xref="民数記 1:42–43; 民数記 26:50"> その部隊、すなわち、数えられた者は五万三千四百人である。</span>
<span className="v" id="v31" data-v="31" data-xref="民数記 10:25; 民数記 2:16; 民数記 2:9"> ダンの宿営の、数えられた者は合わせて十五万七千六百人である。これらの者はその旗にしたがって、最後に進まなければならない」。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="民数記 1:46; 出エジプト記 38:26; 民数記 2:9"> これがイスラエルの人々の、その父祖の家にしたがって数えられた人々である。もろもろの宿営の、その部隊にしたがって数えられた者は合わせて六十万三千五百五十人であった。</span>
<span className="v" id="v33" data-v="33" data-xref="民数記 26:57–62; 民数記 1:47–49"> しかし、レビびとはイスラエルの人々のうちに数えられなかった。主がモーセに命じられたとおりである。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="詩篇 119:6; 民数記 24:2; 民数記 24:5–6"> イスラエルの人々は、すべて主がモーセに命じられたとおりに行い、その旗にしたがって宿営し、おのおのその氏族に従い、その父祖の家に従って進んだ。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数記 25:9"> 疫病の後、主はモーセと祭司アロンの子エレアザルとに言われた、</span>
<span className="v" id="v2" data-v="2" data-xref="出エジプト記 38:25–26; 民数記 1:2–3; 出エジプト記 30:11–16"> 「イスラエルの人々の全会衆の総数をその父祖の家にしたがって調べ、イスラエルにおいて、すべて戦争に出ることのできる二十歳以上の者を数えなさい」。</span>
<span className="v" id="v3" data-v="3" data-xref="民数記 22:1; 民数記 33:48; 民数記 35:1"> そこでモーセと祭司エレアザルとは、エリコに近いヨルダンのほとりにあるモアブの平野で彼らに言った、</span>
<span className="v" id="v4" data-v="4" data-xref="民数記 1:1; 歴代志上 21:1"> 「主がモーセに命じられたように、あなたがたのうちの二十歳以上の者を数えなさい」。エジプトの地から出てきたイスラエルの人々は次のとおりである。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="歴代志上 5:3; 創世記 46:8–9; 出エジプト記 6:14"> ルベンはイスラエルの長子である。ルベンの子孫は、ヘノクからヘノクびとの氏族が出、パルからパルびとの氏族が出、</span>
<span className="v" id="v6" data-v="6"> ヘヅロンからヘヅロンびとの氏族が出、カルミからカルミびとの氏族が出た。</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 46:9; 民数記 26:21; 民数記 2:11"> これらはルベンびとの氏族であって、数えられた者は四万三千七百三十人であった。</span>
<span className="v" id="v8" data-v="8"> またパルの子はエリアブ。</span>
<span className="v" id="v9" data-v="9" data-xref="民数記 1:16; 民数記 16:1–35; 詩篇 106:17"> エリアブの子はネムエル、ダタン、アビラムである。このダタンとアビラムとは会衆のうちから選び出された者で、コラのともがらと共にモーセとアロンとに逆らって主と争った時、</span>
<span className="v" id="v10" data-v="10" data-xref="民数記 16:38; ペテロの第二の手紙 2:6; 民数記 16:31–35"> 地は口を開いて彼らとコラとをのみ、その仲間は死んだ。その時二百五十人が火に焼き滅ぼされて、戒めの鏡となった。</span>
<span className="v" id="v11" data-v="11" data-xref="出エジプト記 6:24; 詩篇 42:1; 民数記 16:33"> ただし、コラの子たちは死ななかった。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="歴代志上 4:24; 創世記 46:10; 出エジプト記 6:15"> シメオンの子孫は、その氏族によれば、ネムエルからネムエルびとの氏族が出、ヤミンからヤミンびとの氏族が出、ヤキンからヤキンびとの氏族が出、</span>
<span className="v" id="v13" data-v="13" data-xref="創世記 46:10"> ゼラからゼラびとの氏族が出、シャウルからシャウルびとの氏族が出た。</span>
<span className="v" id="v14" data-v="14" data-xref="民数記 1:22–23; 民数記 2:12–13"> これらはシメオンびとの氏族であって、数えられた者は二万二千二百人であった。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="創世記 46:16; 民数記 2:14"> ガドの子孫は、その氏族によれば、ゼポンからゼポンびとの氏族が出、ハギからハギびとの氏族が出、シュニからシュニびとの氏族が出、</span>
<span className="v" id="v16" data-v="16" data-xref="創世記 46:16"> オズニからオズニびとの氏族が出、エリからエリびとの氏族が出、</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 46:16"> アロドからアロドびとの氏族が出、アレリからアレリびとの氏族が出た。</span>
<span className="v" id="v18" data-v="18" data-xref="民数記 1:24–25; 民数記 2:14–15"> これらはガドの子孫の氏族であって、数えられた者は四万五百人であった。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="創世記 46:12; 創世記 38:1–10; 歴代志上 2:3–8"> ユダの子らはエルとオナンとであって、エルとオナンとはカナンの地で死んだ。</span>
<span className="v" id="v20" data-v="20" data-xref="ネヘミヤ書 11:24; 創世記 46:12; ルカによる福音書 3:33"> ユダの子孫は、その氏族によれば、シラからシラびとの氏族が出、ペレヅからペレヅびとの氏族が出、ゼラからゼラびとの氏族が出た。</span>
<span className="v" id="v21" data-v="21"> ペレヅの子孫は、ヘヅロンからヘヅロンびとの氏族が出、ハムルからハムルびとの氏族が出た。</span>
<span className="v" id="v22" data-v="22" data-xref="民数記 1:26–27; 民数記 2:3–4; 創世記 49:8"> これらはユダの氏族であって、数えられた者は七万六千五百人であった。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="創世記 46:13; 歴代志上 7:1; 創世記 30:17–18"> イッサカルの子孫は、その氏族によれば、トラからトラびとの氏族が出、プワからプワびとの氏族が出、</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 46:13"> ヤシュブからヤシュブびとの氏族が出、シムロンからシムロンびとの氏族が出た。</span>
<span className="v" id="v25" data-v="25" data-xref="民数記 2:5–6; 民数記 1:28–29"> これらはイッサカルの氏族であって、数えられた者は六万四千三百人であった。</span>
<span className="v" id="v26" data-v="26" data-xref="創世記 46:14; 創世記 30:19–20"> ゼブルンの子孫は、その氏族によれば、セレデからセレデびとの氏族が出、エロンからエロンびとの氏族が出、ヤリエルからヤリエルびとの氏族が出た。</span>
<span className="v" id="v27" data-v="27" data-xref="民数記 1:30–31; 民数記 2:7–8"> これらはゼブルンびとの氏族であって、数えられた者は六万五百人であった。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="創世記 46:20; 創世記 48:5; 創世記 41:51–52"> ヨセフの子らは、その氏族によれば、マナセとエフライムとであって、</span>
<span className="v" id="v29" data-v="29" data-xref="ヨシュア記 17:1; 民数記 36:1; 歴代志上 7:14–19"> マナセの子孫は、マキルからマキルびとの氏族が出た。マキルからギレアデが生れ、ギレアデからギレアデびとの氏族が出た。</span>
<span className="v" id="v30" data-v="30" data-xref="士師記 6:11; 士師記 6:34; 士師記 6:24"> ギレアデの子孫は次のとおりである。イエゼルからイエゼルびとの氏族が出、ヘレクからヘレクびとの氏族が出、</span>
<span className="v" id="v31" data-v="31"> アスリエルからアスリエルびとの氏族が出、シケムからシケムびとの氏族が出、</span>
<span className="v" id="v32" data-v="32"> セミダからセミダびとの氏族が出、ヘペルからヘペルびとの氏族が出た。</span>
<span className="v" id="v33" data-v="33" data-xref="民数記 27:1; 民数記 36:10–12"> ヘペルの子ゼロペハデには男の子がなく、ただ女の子のみで、ゼロペハデの女の子の名はマアラ、ノア、ホグラ、ミルカ、テルザといった。</span>
<span className="v" id="v34" data-v="34" data-xref="民数記 1:34–35; 民数記 2:20–21"> これらはマナセの氏族であって、数えられた者は五万二千七百人であった。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="歴代志上 7:20–21"> エフライムの子孫は、その氏族によれば、次のとおりである。シュテラからはシュテラびとの氏族が出、ベケルからベケルびとの氏族が出、タハンからタハンびとの氏族が出た。</span>
<span className="v" id="v36" data-v="36"> またシュテラの子孫は次のとおりである。すなわちエランからエランびとの氏族が出た。</span>
<span className="v" id="v37" data-v="37" data-xref="民数記 1:32–33; 民数記 2:18–19"> これらはエフライムの子孫の氏族であって、数えられた者は三万二千五百人であった。以上はヨセフの子孫で、その氏族によるものである。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="歴代志上 8:1; 歴代志上 7:6–12; 創世記 46:2"> ベニヤミンの子孫は、その氏族によれば、ベラからベラびとの氏族が出、アシベルからアシベルびとの氏族が出、アヒラムからアヒラムびとの氏族が出、</span>
<span className="v" id="v39" data-v="39" data-xref="創世記 46:21"> シュパムからシュパムびとの氏族が出、ホパムからホパムびとの氏族が出た。</span>
<span className="v" id="v40" data-v="40" data-xref="歴代志上 8:3"> ベラの子はアルデとナアマンとであって、アルデからアルデびとの氏族が出、ナアマンからナアマンびとの氏族が出た。</span>
<span className="v" id="v41" data-v="41" data-xref="民数記 2:22–23; 創世記 46:21; 民数記 1:36–37"> これらはベニヤミンの子孫であって、その氏族によれば数えられた者は四万五千六百人であった。</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="創世記 46:23"> ダンの子孫は、その氏族によれば、次のとおりである。シュハムからシュハムびとの氏族が出た。これらはダンの氏族であって、その氏族によるものである。</span>
<span className="v" id="v43" data-v="43" data-xref="民数記 1:38–39; 民数記 2:25–26"> シュハムびとのすべての氏族のうち、数えられた者は六万四千四百人であった。</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="創世記 46:17; 歴代志上 7:30"> アセルの子孫は、その氏族によれば、エムナからエムナびとの氏族が出、エスイからエスイびとの氏族が出、ベリアからベリアびとの氏族が出た。</span>
<span className="v" id="v45" data-v="45"> ベリアの子孫のうちヘベルからヘベルびとの氏族が出、マルキエルからマルキエルびとの氏族が出た。</span>
<span className="v" id="v46" data-v="46" data-xref="創世記 46:17"> アセルの娘の名はサラといった。</span>
<span className="v" id="v47" data-v="47" data-xref="民数記 2:27–28; 民数記 1:40–41"> これらはアセルの子孫の氏族であって、数えられた者は五万三千四百人であった。</span>
</div>
<div className="bp">
<span className="v" id="v48" data-v="48" data-xref="創世記 46:24; 歴代志上 7:13"> ナフタリの子孫は、その氏族によれば、ヤジエルからヤジエルびとの氏族が出、グニからグニびとの氏族が出、</span>
<span className="v" id="v49" data-v="49" data-xref="歴代志上 7:13"> エゼルからエゼルびとの氏族が出、シレムからシレムびとの氏族が出た。</span>
<span className="v" id="v50" data-v="50" data-xref="民数記 1:42–43; 民数記 2:29–30"> これらはナフタリの氏族であって、その氏族により、数えられた者は四万五千四百人であった。</span>
</div>
<div className="bp">
<span className="v" id="v51" data-v="51" data-xref="民数記 1:46; 民数記 2:32; 出エジプト記 12:37"> これらはイスラエルの子孫の数えられた者であって、六十万一千百三十人であった。</span>
</div>
<div className="bp">
<span className="v" id="v52" data-v="52"> 主はモーセに言われた、</span>
<span className="v" id="v53" data-v="53" data-xref="ヨシュア記 11:23; ヨシュア記 14:1; 詩篇 105:44"> 「これらの人々に、その名の数にしたがって地を分け与え、嗣業とさせなさい。</span>
<span className="v" id="v54" data-v="54" data-xref="民数記 33:54; 民数記 32:3; 民数記 32:5"> 大きい部族には多くの嗣業を与え、小さい部族には少しの嗣業を与えなさい。すなわち数えられた数にしたがって、おのおのの部族にその嗣業を与えなければならない。</span>
<span className="v" id="v55" data-v="55" data-xref="民数記 34:13; 民数記 33:54; ヨシュア記 14:2"> ただし地は、くじをもって分け、その父祖の部族の名にしたがって、それを継がなければならない。</span>
<span className="v" id="v56" data-v="56" data-xref="コリント人への第一の手紙 12:4; ローマ人への手紙 11:7"> すなわち、くじをもってその嗣業を大きいものと、小さいものとに分けなければならない」。</span>
</div>
<div className="bp">
<span className="v" id="v57" data-v="57" data-xref="創世記 46:11; 歴代志上 6:1; 出エジプト記 6:16–19"> レビびとのその氏族にしたがって数えられた者は次のとおりである。ゲルションからゲルションびとの氏族が出、コハテからコハテびとの氏族が出、メラリからメラリびとの氏族が出た。</span>
<span className="v" id="v58" data-v="58" data-xref="民数記 16:1; 民数記 3:17–21; 出エジプト記 6:20"> レビの氏族は次のとおりである。すなわちリブニびとの氏族、ヘブロンびとの氏族、マヘリびとの氏族、ムシびとの氏族、コラびとの氏族であって、コハテからアムラムが生れた。</span>
<span className="v" id="v59" data-v="59" data-xref="出エジプト記 6:20; 出エジプト記 2:1–2; レビ記 18:12"> アムラムの妻の名はヨケベデといって、レビの娘である。彼女はエジプトでレビに生れた者であるが、アムラムにとついで、アロンとモーセおよびその姉妹ミリアムを産んだ。</span>
<span className="v" id="v60" data-v="60" data-xref="民数記 3:2; 民数記 3:8"> アロンにはナダブ、アビウ、エレアザルおよびイタマルが生れた。</span>
<span className="v" id="v61" data-v="61" data-xref="民数記 3:4; レビ記 10:1–2; 歴代志上 24:1–2"> ナダブとアビウは異火を主の前にささげた時に死んだ。</span>
<span className="v" id="v62" data-v="62" data-xref="申命記 10:9; 民数記 35:2–8; 民数記 3:39"> その数えられた一か月以上のすべての男子は二万三千人であった。彼らはイスラエルの人々のうちに嗣業を与えられなかったため、イスラエルの人々のうちに数えられなかった者である。</span>
</div>
<div className="bp">
<span className="v" id="v63" data-v="63" data-xref="民数記 26:3"> これらはモーセと祭司エレアザルが、エリコに近いヨルダンのほとりにあるモアブの平野で数えたイスラエルの人々の数である。</span>
<span className="v" id="v64" data-v="64" data-xref="申命記 2:14–15; 申命記 4:3–4; コリント人への第一の手紙 10:5"> ただしそのうちには、モーセと祭司アロンがシナイの荒野でイスラエルの人々を数えた時に数えられた者はひとりもなかった。</span>
<span className="v" id="v65" data-v="65" data-xref="コリント人への第一の手紙 10:5–6; 民数記 14:38; ローマ人への手紙 11:22"> それは主がかつて彼らについて「彼らは必ず荒野で死ぬであろう」と言われたからである。それで彼らのうちエフンネの子カレブとヌンの子ヨシュアのほか、ひとりも残った者はなかった。</span>
</div>
</div>

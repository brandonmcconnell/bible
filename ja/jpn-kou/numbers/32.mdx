<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数記 21:32; 民数記 32:3; 創世記 13:10–11"> ルベンの子孫とガドの子孫とは非常に多くの家畜の群れを持っていた。彼らがヤゼルの地と、ギレアデの地とを見ると、そこは家畜を飼うのに適していたので、</span>
<span className="v" id="v2" data-v="2"> ガドの子孫とルベンの子孫とがきて、モーセと、祭司エレアザルと、会衆のつかさたちとに言った、</span>
<span className="v" id="v3" data-v="3" data-xref="エレミヤ書 48:34; イザヤ書 16:8–9; 民数記 32:34–38"> 「アタロテ、デボン、ヤゼル、ニムラ、ヘシボン、エレアレ、シバム、ネボ、ベオン、</span>
<span className="v" id="v4" data-v="4" data-xref="民数記 21:34; 申命記 2:24–35; 民数記 21:24"> すなわち主がイスラエルの会衆の前に撃ち滅ぼされた国は、家畜を飼うのに適した地ですが、しもべらは家畜を持っています」。</span>
<span className="v" id="v5" data-v="5" data-xref="ルツ記 2:10; ヨシュア記 7:7; エレミヤ書 31:2"> 彼らはまた言った、「それでもし、あなたの恵みを得られますなら、どうぞこの地をしもべらの領地にして、われわれにヨルダンを渡らせないでください」。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="コリント人への第一の手紙 13:5; サムエル記下 11:11; ピリピ人への手紙 2:4"> モーセはガドの子孫とルベンの子孫とに言った、「あなたがたは兄弟が戦いに行くのに、ここにすわっていようというのか。</span>
<span className="v" id="v7" data-v="7" data-xref="民数記 13:27–4; 民数記 32:9; 申命記 1:28"> どうしてあなたがたはイスラエルの人々の心をくじいて、主が彼らに与えられる地に渡ることができないようにするのか。</span>
<span className="v" id="v8" data-v="8" data-xref="申命記 1:19–25; 民数記 14:2; 民数記 13:2–26"> あなたがたの先祖も、わたしがカデシ・バルネアから、その地を見るためにつかわした時に、同じようなことをした。</span>
<span className="v" id="v9" data-v="9" data-xref="民数記 13:23–10; 申命記 1:24–28"> すなわち彼らはエシコルの谷に行って、その地を見たとき、イスラエルの人々の心をくじいて、主が与えられる地に行くことができないようにした。</span>
<span className="v" id="v10" data-v="10" data-xref="民数記 14:11; 詩篇 95:11; エゼキエル書 20:15"> そこでその時、主は怒りを発し、誓って言われた、</span>
<span className="v" id="v11" data-v="11" data-xref="民数記 14:28–30; 民数記 14:24; 民数記 26:2"> 『エジプトから出てきた人々で二十歳以上の者はひとりもわたしがアブラハム、イサク、ヤコブに誓った地を見ることはできない。彼らはわたしに従わなかったからである。</span>
<span className="v" id="v12" data-v="12" data-xref="申命記 1:36; 民数記 14:30; 民数記 14:24"> ただケニズびとエフンネの子カレブとヌンの子ヨシュアとはそうではない。このふたりは全く主に従ったからである』。</span>
<span className="v" id="v13" data-v="13" data-xref="コリント人への第一の手紙 10:5; 民数記 14:33–35; ヘブル人への手紙 3:16–19"> 主はこのようにイスラエルにむかって怒りを発し、彼らを四十年のあいだ荒野にさまよわされたので、主の前に悪を行ったその世代の人々は、ついにみな滅びた。</span>
<span className="v" id="v14" data-v="14" data-xref="ルカによる福音書 11:48; 詩篇 78:57; マタイによる福音書 23:31–33"> あなたがたはその父に代って立った罪びとのやからであって、主のイスラエルに対する激しい怒りをさらに増そうとしている。</span>
<span className="v" id="v15" data-v="15" data-xref="コリント人への第一の手紙 8:11–12; 歴代志下 15:2; 歴代志下 7:19–22"> あなたがたがもしそむいて主に従わないならば、主はまたこの民を荒野にすておかれるであろう。そうすればあなたがたはこの民をことごとく滅ぼすに至るであろう」。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="創世記 33:17; 民数記 34:22"> 彼らはモーセのところへ進み寄って言った、「われわれはこの所に、群れのために羊のおりを建て、また子供たちのために町々を建てようと思います。</span>
<span className="v" id="v17" data-v="17" data-xref="ヨシュア記 4:12–13; 民数記 32:29–32; 申命記 3:18–20"> しかし、われわれは武装してイスラエルの人々の前に進み、彼らをその所へ導いて行きましょう。ただわれわれの子供たちは、この地の住民の害をのがれるため、堅固な町々に住ませておかなければなりません。</span>
<span className="v" id="v18" data-v="18" data-xref="ヨシュア記 22:1–5"> われわれはイスラエルの人々が、おのおのその嗣業を受けるまでは、家に帰りません。</span>
<span className="v" id="v19" data-v="19" data-xref="ヨシュア記 13:8; ヨシュア記 12:1–6; 民数記 34:15"> またわれわれはヨルダンのかなたで彼らとともには嗣業を受けません。われわれはヨルダンのこなた、すなわち東の方で嗣業を受けるからです」。</span>
<span className="v" id="v20" data-v="20" data-xref="ヨシュア記 4:12–13; 申命記 3:18–20; ヨシュア記 1:13–15"> モーセは彼らに言った、「もし、あなたがたがそのようにし、みな武装して主の前に行って戦い、</span>
<span className="v" id="v21" data-v="21"> みな武装して主の前に行ってヨルダン川を渡り、主がその敵を自分の前から追い払われて、</span>
<span className="v" id="v22" data-v="22" data-xref="ヨシュア記 22:9; ヨシュア記 22:4; 申命記 3:20"> この国が主の前に征服されて後、帰ってくるならば、あなたがたは主の前にも、イスラエルの前にも、とがめはないであろう。そしてこの地は主の前にあなたがたの所有となるであろう。</span>
<span className="v" id="v23" data-v="23" data-xref="イザヤ書 59:12; 箴言 13:21; 創世記 44:16"> しかし、そうしないならば、あなたがたは主にむかって罪を犯した者となり、その罪は必ず身に及ぶことを知らなければならない。</span>
<span className="v" id="v24" data-v="24" data-xref="民数記 32:16; 民数記 30:2; 民数記 32:34–42"> あなたがたは子供たちのために町々を建て、羊のために、おりを建てなさい。しかし、あなたがたは約束したことは行わなければならない」。</span>
<span className="v" id="v25" data-v="25" data-xref="ヨシュア記 1:13–14"> ガドの子孫とルベンの子孫とは、モーセに言った、「しもべらはあなたの命じられたとおりにいたします。</span>
<span className="v" id="v26" data-v="26" data-xref="ヨシュア記 1:14"> われわれの子供たちと妻と羊と、すべての家畜とは、このギレアデの町々に残します。</span>
<span className="v" id="v27" data-v="27" data-xref="ヨシュア記 4:12; 民数記 32:17; 民数記 12:11"> しかし、しもべらはみな武装して、あなたの言われるとおり、主の前に渡って行って戦います」。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="ヨシュア記 1:13"> モーセは彼らのことについて、祭司エレアザルと、ヌンの子ヨシュアと、イスラエルの人々の部族のうちの氏族のかしらたちとに命じた。</span>
<span className="v" id="v29" data-v="29"> そしてモーセは彼らに言った、「ガドの子孫と、ルベンの子孫とが、おのおの武装してあなたがたと一緒にヨルダンを渡り、主の前に戦って、その地をあなたがたが征服するならば、あなたがたは彼らにギレアデの地を領地として与えなければならない。</span>
<span className="v" id="v30" data-v="30" data-xref="ヨシュア記 22:19"> しかし、もし彼らが武装してあなたがたと一緒に渡って行かないならば、彼らはカナンの地であなたがたのうちに領地を獲なければならない」。</span>
<span className="v" id="v31" data-v="31"> ガドの子孫と、ルベンの子孫とは答えて言った、「しもべらは主が言われたとおりにいたします。</span>
<span className="v" id="v32" data-v="32"> われわれは武装して、主の前にカナンの地へ渡って行きますが、ヨルダンのこなたで、われわれの嗣業をもつことにします」。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="ヨシュア記 12:6; 申命記 29:8; 申命記 3:12–17"> そこでモーセはガドの子孫と、ルベンの子孫と、ヨセフの子マナセの部族の半ばとに、アモリびとの王シホンの国と、バシャンの王オグの国とを与えた。すなわち、その国およびその領内の町々とその町々の周囲の地とを与えた。</span>
<span className="v" id="v34" data-v="34" data-xref="申命記 2:36; 民数記 32:3; イザヤ書 17:2"> こうしてガドの子孫は、デボン、アタロテ、アロエル、</span>
<span className="v" id="v35" data-v="35" data-xref="民数記 32:1; 民数記 32:3"> アテロテ・ショパン、ヤゼル、ヨグベハ、</span>
<span className="v" id="v36" data-v="36" data-xref="民数記 32:3"> ベテニムラ、ベテハランなどの堅固な町々を建て、羊のおりを建てた。</span>
<span className="v" id="v37" data-v="37" data-xref="民数記 21:27; 民数記 32:3; イザヤ書 15:4"> またルベンの子孫は、ヘシボン、エレアレ、キリヤタイム、</span>
<span className="v" id="v38" data-v="38" data-xref="イザヤ書 46:1; 民数記 32:3; ヨシュア記 23:7"> および後に名を改めたネボと、バアル・メオンの町を建て、またシブマの町を建てた。彼らは建てた町々に新しい名を与えた。</span>
<span className="v" id="v39" data-v="39" data-xref="創世記 50:23; ヨシュア記 17:1; 民数記 26:29"> またマナセの子マキルの子孫はギレアデに行って、そこを取り、その住民アモリびとを追い払ったので、</span>
<span className="v" id="v40" data-v="40" data-xref="ヨシュア記 17:1; ヨシュア記 13:29–31; 申命記 3:13–15"> モーセはギレアデをマナセの子マキルに与えてそこに住まわせた。</span>
<span className="v" id="v41" data-v="41" data-xref="申命記 3:14; 士師記 10:4; ヨシュア記 13:30"> またマナセの子ヤイルは行って村々を取り、それをハオテヤイルと名づけた。</span>
<span className="v" id="v42" data-v="42" data-xref="詩篇 49:11; サムエル記下 18:18"> またノバは行ってケナテとその村々を取り、自分の名にしたがって、それをノバと名づけた。</span>
</div>

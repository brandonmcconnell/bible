<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数記 13:21; 出エジプト記 15:20; 民数記 33:36"> イスラエルの人々の全会衆は正月になってチンの荒野にはいった。そして民はカデシにとどまったが、ミリアムがそこで死んだので、彼女をそこに葬った。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="民数記 16:19; 民数記 16:42; 出エジプト記 15:23–24"> そのころ会衆は水が得られなかったため、相集まってモーセとアロンに迫った。</span>
<span className="v" id="v3" data-v="3" data-xref="出エジプト記 17:2; 民数記 14:1–2; 民数記 16:31–35"> すなわち民はモーセと争って言った、「さきにわれわれの兄弟たちが主の前に死んだ時、われわれも死んでいたらよかったものを。</span>
<span className="v" id="v4" data-v="4" data-xref="出エジプト記 17:3; 詩篇 106:21; 民数記 16:13–14"> なぜ、あなたがたは主の会衆をこの荒野に導いて、われわれと、われわれの家畜とを、ここで死なせようとするのですか。</span>
<span className="v" id="v5" data-v="5" data-xref="民数記 16:14; エレミヤ書 2:2; エレミヤ書 2:6"> どうしてあなたがたはわれわれをエジプトから上らせて、この悪い所に導き入れたのですか。ここには種をまく所もなく、いちじくもなく、ぶどうもなく、ざくろもなく、また飲む水もありません」。</span>
<span className="v" id="v6" data-v="6" data-xref="民数記 14:5; 民数記 16:4; 民数記 16:19"> そこでモーセとアロンは会衆の前を去り、会見の幕屋の入口へ行ってひれ伏した。すると主の栄光が彼らに現れ、</span>
<span className="v" id="v7" data-v="7"> 主はモーセに言われた、</span>
<span className="v" id="v8" data-v="8" data-xref="出エジプト記 4:17; 使徒行伝 2:1–4; ヨハネの黙示録 22:17"> 「あなたは、つえをとり、あなたの兄弟アロンと共に会衆を集め、その目の前で岩に命じて水を出させなさい。こうしてあなたは彼らのために岩から水を出して、会衆とその家畜に飲ませなさい」。</span>
<span className="v" id="v9" data-v="9" data-xref="民数記 17:10"> モーセは命じられたように主の前にあるつえを取った。</span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 106:32–33; 使徒行伝 14:9–15; ルカによる福音書 9:54–55"> モーセはアロンと共に会衆を岩の前に集めて彼らに言った、「そむく人たちよ、聞きなさい。われわれがあなたがたのためにこの岩から水を出さなければならないのであろうか」。</span>
<span className="v" id="v11" data-v="11" data-xref="コリント人への第一の手紙 10:4; 出エジプト記 17:6; 申命記 8:15"> モーセは手をあげ、つえで岩を二度打つと、水がたくさんわき出たので、会衆とその家畜はともに飲んだ。</span>
<span className="v" id="v12" data-v="12" data-xref="申命記 1:37; 民数記 27:14; エゼキエル書 36:23"> そのとき主はモーセとアロンに言われた、「あなたがたはわたしを信じないで、イスラエルの人々の前にわたしの聖なることを現さなかったから、この会衆をわたしが彼らに与えた地に導き入れることができないであろう」。</span>
<span className="v" id="v13" data-v="13" data-xref="出エジプト記 17:7; 詩篇 95:8; 申命記 33:8"> これがメリバの水であって、イスラエルの人々はここで主と争ったが、主は自分の聖なることを彼らのうちに現された。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="士師記 11:16–17; 申命記 23:7; オバデヤ書 1:10–12"> さて、モーセはカデシからエドムの王に使者をつかわして言った、「あなたの兄弟、イスラエルはこう申します、『あなたはわたしたちが遭遇したすべての患難をご存じです。</span>
<span className="v" id="v15" data-v="15" data-xref="出エジプト記 12:40; 申命記 26:6; 創世記 46:6"> わたしたちの先祖はエジプトに下って行って、わたしたちは年久しくエジプトに住んでいましたが、エジプトびとがわたしたちと、わたしたちの先祖を悩ましたので、</span>
<span className="v" id="v16" data-v="16" data-xref="出エジプト記 14:19; 出エジプト記 23:20; 出エジプト記 33:2"> わたしたちが主に呼ばわったとき、主はわたしたちの声を聞き、ひとりの天の使をつかわして、わたしたちをエジプトから導き出されました。わたしたちは今あなたの領地の端にあるカデシの町におります。</span>
<span className="v" id="v17" data-v="17" data-xref="申命記 2:27; 申命記 2:29; 民数記 21:22–24"> どうぞ、わたしたちにあなたの国を通らせてください。わたしたちは畑もぶどう畑も通りません。また井戸の水も飲みません。ただ王の大路を通り、あなたの領地を過ぎるまでは右にも左にも曲りません』」。</span>
<span className="v" id="v18" data-v="18"> しかし、エドムはモーセに言った、「あなたはわたしの領地をとおってはなりません。さもないと、わたしはつるぎをもって出て、あなたに立ちむかうでしょう」。</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 2:28; 申命記 2:6; 出エジプト記 12:38"> イスラエルの人々はエドムに言った、「わたしたちは大路を通ります。もしわたしたちとわたしたちの家畜とが、あなたの水を飲むことがあれば、その価を払います。わたしは徒歩で通るだけですから何事もないでしょう」。</span>
<span className="v" id="v20" data-v="20" data-xref="士師記 11:17; アモス書 1:11; 創世記 32:6"> しかし、エドムは「あなたは通ることはなりません」と言って、多くの民と強い軍勢とを率い、出て、これに立ちむかってきた。</span>
<span className="v" id="v21" data-v="21" data-xref="士師記 11:18; 申命記 2:29; 申命記 2:4–8"> このようにエドムはイスラエルに、その領地を通ることを拒んだので、イスラエルはエドムからほかに向かった。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="民数記 20:1; 民数記 20:14; 民数記 21:4"> こうしてイスラエルの人々の全会衆はカデシから進んでホル山に着いた。</span>
<span className="v" id="v23" data-v="23" data-xref="民数記 33:37"> 主はエドムの国境に近いホル山で、モーセとアロンに言われた、</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 25:8; 申命記 32:50; 民数記 31:2"> 「アロンはその民に連ならなければならない。彼はわたしがイスラエルの人々に与えた地に、はいることができない。これはメリバの水で、あなたがたがわたしの言葉にそむいたからである。</span>
<span className="v" id="v25" data-v="25" data-xref="民数記 33:38–39"> あなたはアロンとその子エレアザルを連れてホル山に登り、</span>
<span className="v" id="v26" data-v="26" data-xref="民数記 20:24; イザヤ書 22:21–22; ヘブル人への手紙 7:11"> アロンに衣服を脱がせて、それをその子エレアザルに着せなさい。アロンはそのところで死んで、その民に連なるであろう」。</span>
<span className="v" id="v27" data-v="27"> モーセは主が命じられたとおりにし、連れだって全会衆の目の前でホル山に登った。</span>
<span className="v" id="v28" data-v="28" data-xref="申命記 10:6; 出エジプト記 29:29–30; 申命記 34:9"> そしてモーセはアロンに衣服を脱がせ、それをその子エレアザルに着せた。アロンはその山の頂で死んだ。そしてモーセとエレアザルは山から下ったが、</span>
<span className="v" id="v29" data-v="29" data-xref="申命記 34:8; 歴代志下 35:24–25; 創世記 1:10"> 全会衆がアロンの死んだのを見たとき、イスラエルの全家は三十日の間アロンのために泣いた。</span>
</div>

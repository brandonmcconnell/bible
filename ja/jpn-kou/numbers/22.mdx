<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命記 34:1; 申命記 3:8; 民数記 21:20"> さて、イスラエルの人々はまた道を進んで、エリコに近いヨルダンのかなたのモアブの平野に宿営した。</span>
<span className="v" id="v2" data-v="2" data-xref="士師記 11:25; 民数記 21:20–35; 民数記 21:3"> チッポルの子バラクはイスラエルがアモリびとにしたすべての事を見たので、</span>
<span className="v" id="v3" data-v="3" data-xref="出エジプト記 15:15; イザヤ書 23:5; ヨシュア記 9:24"> モアブは大いにイスラエルの民を恐れた。その数が多かったためである。モアブはイスラエルの人々をひじょうに恐れたので、</span>
<span className="v" id="v4" data-v="4" data-xref="民数記 25:15–18; 民数記 31:8; 民数記 24:17"> ミデアンの長老たちに言った、「この群衆は牛が野の草をなめつくすように、われわれの周囲の物をみな、なめつくそうとしている」。チッポルの子バラクはこの時モアブの王であった。</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 23:4; ヨシュア記 24:9; ミカ書 6:5"> 彼はアンモンびとの国のユフラテ川のほとりにあるペトルに使者をつかわし、ベオルの子バラムを招こうとして言わせた、「エジプトから出てきた民があり、地のおもてをおおってわたしの前にいます。</span>
<span className="v" id="v6" data-v="6" data-xref="民数記 24:9; 民数記 23:7–8; 使徒行伝 16:16"> どうぞ今きてわたしのためにこの民をのろってください。彼らはわたしよりも強いのです。そうしてくだされば、われわれは彼らを撃って、この国から追い払うことができるかもしれません。あなたが祝福する者は祝福され、あなたがのろう者はのろわれることをわたしは知っています」。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="サムエル記上 9:7–8; ミカ書 3:11; ローマ人への手紙 16:18"> モアブの長老たちとミデアンの長老たちは占いの礼物を手にして出発し、バラムのもとへ行って、バラクの言葉を告げた。</span>
<span className="v" id="v8" data-v="8" data-xref="民数記 23:12; 民数記 22:19–20; エレミヤ書 12:2"> バラムは彼らに言った、「今夜ここに泊まりなさい。主がわたしに告げられるとおりに、あなたがたに返答しましょう」。それでモアブのつかさたちはバラムのもとにとどまった。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 20:3; 民数記 22:20; 創世記 16:8"> ときに神はバラムに臨んで言われた、「あなたのところにいるこの人々はだれですか」。</span>
<span className="v" id="v10" data-v="10"> バラムは神に言った、「モアブの王チッポルの子バラクが、わたしに人をよこして言いました。</span>
<span className="v" id="v11" data-v="11"> 『エジプトから出てきた民があり、地のおもてをおおっています。どうぞ今きてわたしのために彼らをのろってください。そうすればわたしは戦って、彼らを追い払うことができるかもしれません』」。</span>
<span className="v" id="v12" data-v="12" data-xref="申命記 23:5; エペソ人への手紙 1:3; 創世記 12:2"> 神はバラムに言われた、「あなたは彼らと一緒に行ってはならない。またその民をのろってはならない。彼らは祝福された者だからである」。</span>
<span className="v" id="v13" data-v="13" data-xref="申命記 23:5; 民数記 22:14"> 明くる朝起きて、バラムはバラクのつかさたちに言った、「あなたがたは国にお帰りなさい。主はわたしがあなたがたと一緒に行くことを、お許しになりません」。</span>
<span className="v" id="v14" data-v="14" data-xref="民数記 22:37; 民数記 22:13"> モアブのつかさたちは立ってバラクのもとに行って言った、「バラムはわたしたちと一緒に来ることを承知しません」。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="使徒行伝 10:7–8; 民数記 22:7–8"> バラクはまた前の者よりも身分の高いつかさたちを前よりも多くつかわした。</span>
<span className="v" id="v16" data-v="16"> 彼らはバラムのところへ行って言った、「チッポルの子バラクはこう申します、『どんな妨げをも顧みず、どうぞわたしのところへおいでください。</span>
<span className="v" id="v17" data-v="17" data-xref="民数記 24:11; エステル記 5:11; マタイによる福音書 4:8–9"> わたしはあなたを大いに優遇します。そしてあなたがわたしに言われる事はなんでもいたします。どうぞきてわたしのためにこの民をのろってください』」。</span>
<span className="v" id="v18" data-v="18" data-xref="民数記 24:13; 列王紀上 22:14; 歴代志下 18:13"> しかし、バラムはバラクの家来たちに答えた、「たといバラクがその家に満ちるほどの金銀をわたしに与えようとも、事の大小を問わず、わたしの神、主の言葉を越えては何もすることができません。</span>
<span className="v" id="v19" data-v="19" data-xref="ユダの手紙 1:11; ペテロの第二の手紙 2:3; テモテヘの第一の手紙 6:9–10"> それで、どうぞ、あなたがたも今夜ここにとどまって、主がこの上、わたしになんと仰せられるかを確かめさせてください」。</span>
<span className="v" id="v20" data-v="20" data-xref="民数記 23:12; 民数記 24:13; 民数記 23:26"> 夜になり、神はバラムに臨んで言われた、「この人々はあなたを招きにきたのだから、立ってこの人々と一緒に行きなさい。ただしわたしが告げることだけを行わなければならない」。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="箴言 1:15–16"> 明くる朝起きてバラムは、ろばにくらをおき、モアブのつかさたちと一緒に行った。</span>
<span className="v" id="v22" data-v="22" data-xref="出エジプト記 4:24; 哀歌 2:4; 民数記 22:32"> しかるに神は彼が行ったために怒りを発せられ、主の使は彼を妨げようとして、道に立ちふさがっていた。バラムは、ろばに乗り、そのしもべふたりも彼と共にいたが、</span>
<span className="v" id="v23" data-v="23" data-xref="ユダの手紙 1:11; ペテロの第二の手紙 2:16; コリント人への第一の手紙 1:27–29"> ろばは主の使が、手に抜き身のつるぎをもって、道に立ちふさがっているのを見、道をそれて畑にはいったので、バラムは、ろばを打って道に返そうとした。</span>
<span className="v" id="v24" data-v="24"> しかるに主の使はまたぶどう畑の間の狭い道に立ちふさがっていた。道の両側には石がきがあった。</span>
<span className="v" id="v25" data-v="25" data-xref="イザヤ書 47:12; ヨブ記 5:13–15"> ろばは主の使を見て、石がきにすり寄り、バラムの足を石がきに押しつけたので、バラムは、また、ろばを打った。</span>
<span className="v" id="v26" data-v="26" data-xref="ホセア書 2:6; イザヤ書 26:11"> 主の使はまた先に進んで、狭い所に立ちふさがっていた。そこは右にも左にも、曲る道がなかったので、</span>
<span className="v" id="v27" data-v="27" data-xref="箴言 14:16; ヤコブの手紙 1:19; 箴言 27:3–4"> ろばは主の使を見てバラムの下に伏した。そこでバラムは怒りを発し、つえでろばを打った。</span>
<span className="v" id="v28" data-v="28" data-xref="ペテロの第二の手紙 2:16; ルカによる福音書 1:37; 出エジプト記 4:11"> すると、主が、ろばの口を開かれたので、ろばはバラムにむかって言った、「わたしがあなたに何をしたというのですか。あなたは三度もわたしを打ったのです」。</span>
<span className="v" id="v29" data-v="29" data-xref="箴言 12:10; マタイによる福音書 15:19; 箴言 12:16"> バラムは、ろばに言った、「お前がわたしを侮ったからだ。わたしの手につるぎがあれば、いま、お前を殺してしまうのだが」。</span>
<span className="v" id="v30" data-v="30" data-xref="ペテロの第二の手紙 2:16; コリント人への第一の手紙 1:27–28"> ろばはまたバラムに言った、「わたしはあなたが、きょうまで長いあいだ乗られたろばではありませんか。わたしはいつでも、あなたにこのようにしたでしょうか」。バラムは言った、「いや、しなかった」。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="創世記 21:19; ルカによる福音書 24:31; 使徒行伝 26:18"> このとき主がバラムの目を開かれたので、彼は主の使が手に抜き身のつるぎをもって、道に立ちふさがっているのを見て、頭を垂れてひれ伏した。</span>
<span className="v" id="v32" data-v="32" data-xref="箴言 28:18; 使徒行伝 13:10; 民数記 22:22"> 主の使は彼に言った、「なぜあなたは三度もろばを打ったのか。あなたが誤って道を行くので、わたしはあなたを妨げようとして出てきたのだ。</span>
<span className="v" id="v33" data-v="33" data-xref="民数記 16:33–35; 民数記 14:37; 列王紀上 13:24–28"> ろばはわたしを見て三度も身を巡らしてわたしを避けた。もし、ろばが身を巡らしてわたしを避けなかったなら、わたしはきっと今あなたを殺して、ろばを生かしておいたであろう」。</span>
<span className="v" id="v34" data-v="34" data-xref="ヨブ記 34:31–32; サムエル記下 12:13; サムエル記上 15:24"> バラムは主の使に言った、「わたしは罪を犯しました。あなたがわたしをとどめようとして、道に立ちふさがっておられるのを、わたしは知りませんでした。それで今、もし、お気に召さないのであれば、わたしは帰りましょう」。</span>
<span className="v" id="v35" data-v="35" data-xref="テサロニケ人への第二の手紙 2:9–12; イザヤ書 37:26–29; 民数記 22:20–21"> 主の使はバラムに言った、「この人々と一緒に行きなさい。ただし、わたしが告げることのみを述べなければならない」。こうしてバラムはバラクのつかさたちと一緒に行った。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="イザヤ書 16:2; 使徒行伝 28:15; エレミヤ書 48:20"> さて、バラクはバラムがきたと聞いて、国境のアルノン川のほとり、国境の一端にあるモアブの町まで出て行って迎えた。</span>
<span className="v" id="v37" data-v="37" data-xref="民数記 24:11; ヨハネによる福音書 5:44; マタイによる福音書 4:8–9"> そしてバラクはバラムに言った、「わたしは人をつかわしてあなたを招いたではありませんか。あなたはなぜわたしのところへきませんでしたか。わたしは実際あなたを優遇することができないでしょうか」。</span>
<span className="v" id="v38" data-v="38" data-xref="民数記 22:18; 箴言 19:21; 民数記 23:16"> バラムはバラクに言った、「ごらんなさい。わたしはあなたのところにきています。しかし、今、何事かをみずから言うことができましょうか。わたしはただ神がわたしの口に授けられることを述べなければなりません」。</span>
<span className="v" id="v39" data-v="39"> こうしてバラムはバラクと一緒に行き、キリアテ・ホゾテにきたとき、</span>
<span className="v" id="v40" data-v="40" data-xref="民数記 23:14; 箴言 1:16; 民数記 23:2"> バラクは牛と羊とをほふって、バラムおよび彼と共にいたバラムを連れてきたつかさたちに贈った。</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="民数記 23:13; 民数記 25:2–3; 歴代志下 11:15"> 明くる朝バラクはバラムを伴ってバモテバアルにのぼり、そこからイスラエルの民の宿営の一端をながめさせた。</span>
</div>
</div>

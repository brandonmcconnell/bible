<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出エジプト記 25:22; 出エジプト記 19:1; 民数記 10:11–12"> エジプトの国を出た次の年の二月一日に、主はシナイの荒野において、会見の幕屋で、モーセに言われた、</span>
<span className="v" id="v2" data-v="2" data-xref="出エジプト記 38:26; 出エジプト記 30:12; 民数記 1:18"> 「あなたがたは、イスラエルの人々の全会衆を、その氏族により、その父祖の家によって調査し、そのすべての男子の名の数を、ひとりびとり数えて、その総数を得なさい。</span>
<span className="v" id="v3" data-v="3" data-xref="出エジプト記 30:14; 民数記 14:29; 民数記 33:1"> イスラエルのうちで、すべて戦争に出ることのできる二十歳以上の者を、あなたとアロンとは、その部隊にしたがって数えなければならない。</span>
<span className="v" id="v4" data-v="4" data-xref="民数記 1:16; 出エジプト記 18:25; 民数記 13:2–15"> また、すべての部族は、おのおの父祖の家の長たるものを、ひとりずつ出して、あなたがたと協力させなければならない。</span>
<span className="v" id="v5" data-v="5" data-xref="民数記 7:30; 創世記 30:5–20; 創世記 49:1–33"> すなわち、あなたがたに協力すべき人々の名は、次のとおりである。ルベンからはシデウルの子エリヅル。</span>
<span className="v" id="v6" data-v="6" data-xref="民数記 7:36; 民数記 2:12"> シメオンからはツリシャダイの子シルミエル。</span>
<span className="v" id="v7" data-v="7" data-xref="ルカによる福音書 3:32; 民数記 10:14; マタイによる福音書 1:2–5"> ユダからはアミナダブの子ナション。</span>
<span className="v" id="v8" data-v="8" data-xref="民数記 7:18; 民数記 10:15; 民数記 2:5"> イッサカルからはツアルの子ネタニエル。</span>
<span className="v" id="v9" data-v="9" data-xref="民数記 7:24; 民数記 10:16; 民数記 2:7"> ゼブルンからはヘロンの子エリアブ。</span>
<span className="v" id="v10" data-v="10" data-xref="民数記 7:54; 民数記 7:48; 歴代志上 7:26–27"> ヨセフの子たちのうち、エフライムからはアミホデの子エリシャマ、マナセからはパダヅルの子ガマリエル。</span>
<span className="v" id="v11" data-v="11" data-xref="民数記 7:60; 民数記 10:24; 民数記 2:22"> ベニヤミンからはギデオニの子アビダン。</span>
<span className="v" id="v12" data-v="12" data-xref="民数記 7:66; 民数記 2:25; 民数記 10:25"> ダンからはアミシャダイの子アヒエゼル。</span>
<span className="v" id="v13" data-v="13" data-xref="民数記 7:72; 民数記 10:26; 民数記 2:27"> アセルからはオクランの子パギエル。</span>
<span className="v" id="v14" data-v="14" data-xref="民数記 2:14; 民数記 7:42; 民数記 10:20"> ガドからはデウエルの子エリアサフ。</span>
<span className="v" id="v15" data-v="15" data-xref="民数記 7:78; 民数記 10:27; 民数記 2:29"> ナフタリからはエナンの子アヒラ」。</span>
<span className="v" id="v16" data-v="16" data-xref="民数記 7:2; 出エジプト記 18:21; 出エジプト記 18:25"> これらは会衆のうちから選び出された人々で、その父祖の部族のつかさたち、またイスラエルの氏族のかしらたちである。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="ヨハネによる福音書 10:3; ヨハネの黙示録 7:4–17; 民数記 1:5–15"> こうして、モーセとアロンが、ここに名を掲げた人々を引き連れて、</span>
<span className="v" id="v18" data-v="18" data-xref="エズラ記 2:59; ネヘミヤ書 7:61; ヘブル人への手紙 7:3"> 二月一日に会衆をことごとく集めたので、彼らはその氏族により、その父祖の家により、その名の数にしたがって二十歳以上のものが、ひとりびとり登録した。</span>
<span className="v" id="v19" data-v="19" data-xref="民数記 1:2; 民数記 26:1–2; サムエル記下 24:1–10"> 主が命じられたように、モーセはシナイの荒野で彼らを数えた。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="民数記 26:5–7; 民数記 2:10–11; 創世記 46:9"> すなわち、イスラエルの長子ルベンの子たちから生れたものを、その氏族により、その父祖の家によって調べ、すべて戦争に出ることのできる二十歳以上の男子の名の数を、ひとりびとり得たが、</span>
<span className="v" id="v21" data-v="21" data-xref="民数記 26:7; 民数記 2:10–11"> ルベンの部族のうちで、数えられたものは四万六千五百人であった。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="民数記 26:12–14; 創世記 34:25–30; 民数記 2:12–13"> またシメオンの子たちから生れたものを、その氏族により、その父祖の家によって調べ、すべて戦争に出ることのできる二十歳以上の男子の名の数を、ひとりびとり得たが、</span>
<span className="v" id="v23" data-v="23" data-xref="民数記 26:14; 民数記 2:13; 民数記 25:8–9"> シメオンの部族のうちで、数えられたものは五万九千三百人であった。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="民数記 26:15–18; 創世記 46:16; 民数記 2:14–15"> またガドの子たちから生れたものを、その氏族により、その父祖の家によって調べ、すべて戦争に出ることのできる二十歳以上の者の名の数を得たが、</span>
<span className="v" id="v25" data-v="25" data-xref="民数記 26:18; 民数記 2:15"> ガドの部族のうちで、数えられたものは四万五千六百五十人であった。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="創世記 29:35; 民数記 26:19–22; サムエル記下 24:9"> ユダの子たちから生れたものを、その氏族により、その父祖の家によって調べ、すべて戦争に出ることのできる二十歳以上の者の名の数を得たが、</span>
<span className="v" id="v27" data-v="27" data-xref="サムエル記下 24:9; 民数記 26:22; 歴代志下 17:14–16"> ユダの部族のうちで、数えられたものは七万四千六百人であった。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="創世記 46:13; 創世記 49:14–15; 創世記 30:18"> イッサカルの子たちから生れたものを、その氏族により、その父祖の家によって調べ、すべて戦争に出ることのできる二十歳以上の者の名の数を得たが、</span>
<span className="v" id="v29" data-v="29" data-xref="民数記 26:25; 民数記 2:6"> イッサカルの部族のうちで、数えられたものは五万四千四百人であった。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="民数記 26:26–27; 創世記 49:13; 創世記 30:20"> ゼブルンの子たちから生れたものを、その氏族により、その父祖の家によって調べ、すべて戦争に出ることのできる二十歳以上の者の名の数を得たが、</span>
<span className="v" id="v31" data-v="31" data-xref="民数記 26:27; 民数記 2:8"> ゼブルンの部族のうちで、数えられたものは五万七千四百人であった。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="民数記 26:35–37; 申命記 33:17; 創世記 46:20"> ヨセフの子たちのうち、エフライムの子たちから生れたものを、その氏族により、その父祖の家によって調べ、すべて戦争に出ることのできる二十歳以上の者の名の数を得たが、</span>
<span className="v" id="v33" data-v="33" data-xref="民数記 26:37; 申命記 33:17; 民数記 2:19"> エフライムの部族のうちで、数えられたものは四万五百人であった。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="民数記 26:28–34"> マナセの子たちから生れたものを、その氏族により、その父祖の家によって調べ、すべて戦争に出ることのできる二十歳以上の者の名の数を得たが、</span>
<span className="v" id="v35" data-v="35" data-xref="民数記 26:34; 創世記 48:19–20; 民数記 2:21"> マナセの部族のうちで、数えられたものは三万二千二百人であった。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="創世記 49:27; 創世記 44:20; ヨハネの黙示録 7:8"> ベニヤミンの子たちから生れたものを、その氏族により、その父祖の家によって調べ、すべて戦争に出ることのできる二十歳以上の者の名の数を得たが、</span>
<span className="v" id="v37" data-v="37" data-xref="民数記 26:41; 士師記 20:44–46; 歴代志下 17:17"> ベニヤミンの部族のうちで、数えられたものは三万五千四百人であった。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="創世記 46:23; 創世記 30:5–6; 創世記 49:16–17"> ダンの子たちから生れたものを、その氏族により、その父祖の家によって調べ、すべて戦争に出ることのできる二十歳以上の者の名の数を得たが、</span>
<span className="v" id="v39" data-v="39" data-xref="民数記 26:43; 民数記 2:26"> ダンの部族のうちで、数えられたものは六万二千七百人であった。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="創世記 30:12–13; 創世記 46:27; 創世記 49:20"> アセルの子たちから生れたものを、その氏族により、その父祖の家によって調べ、すべて戦争に出ることのできる二十歳以上の者の名の数を得たが、</span>
<span className="v" id="v41" data-v="41" data-xref="民数記 26:47; 民数記 2:28"> アセルの部族のうちで、数えられたものは四万一千五百人であった。</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="創世記 49:21; 民数記 26:48–50; 創世記 46:24"> ナフタリの子たちから生れたものを、その氏族により、その父祖の家によって調べ、すべて戦争に出ることのできる二十歳以上の者の名の数を得たが、</span>
<span className="v" id="v43" data-v="43" data-xref="民数記 26:50; 民数記 2:30"> ナフタリの部族のうちで、数えられたものは、五万三千四百人であった。</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="民数記 26:64; 民数記 1:2–16"> これらが数えられた人々であって、モーセとアロンとイスラエルのつかさたちとが数えた人々である。そのつかさたちは十二人であって、おのおのその父祖の家のために出たものである。</span>
<span className="v" id="v45" data-v="45"> そしてイスラエルの人々のうち、その父祖の家にしたがって数えられた者は、すべてイスラエルのうち、戦争に出ることのできる二十歳以上の者であって、</span>
<span className="v" id="v46" data-v="46" data-xref="出エジプト記 12:37; 民数記 26:51; 出エジプト記 38:26"> その数えられた者は合わせて六十万三千五百五十人であった。</span>
</div>
<div className="bp">
<span className="v" id="v47" data-v="47" data-xref="民数記 2:33; 民数記 3:1–49; 民数記 26:57–62"> しかし、レビびとは、その父祖の部族にしたがって、そのうちに数えられなかった。</span>
<span className="v" id="v48" data-v="48"> すなわち、主はモーセに言われた、</span>
<span className="v" id="v49" data-v="49" data-xref="民数記 26:62; 民数記 2:33"> 「あなたはレビの部族だけは数えてはならない。またその総数をイスラエルの人々のうちに数えあげてはならない。</span>
<span className="v" id="v50" data-v="50" data-xref="出エジプト記 38:21; 出エジプト記 31:18; 民数記 4:15"> あなたはレビびとに、あかしの幕屋と、そのもろもろの器と、それに附属するもろもろの物を管理させなさい。彼らは幕屋と、そのもろもろの器とを持ち運び、またそこで務をし、幕屋のまわりに宿営しなければならない。</span>
<span className="v" id="v51" data-v="51" data-xref="民数記 3:38; 民数記 3:10; サムエル記上 6:19"> 幕屋が進む時は、レビびとがこれを取りくずし、幕屋を張る時は、レビびとがこれを組み立てなければならない。ほかの人がこれに近づく時は殺されるであろう。</span>
<span className="v" id="v52" data-v="52" data-xref="民数記 2:2; 民数記 2:34; 民数記 10:1–36"> イスラエルの人々はその部隊にしたがって、おのおのその宿営に、おのおのその旗のもとにその天幕を張らなければならない。</span>
<span className="v" id="v53" data-v="53" data-xref="民数記 16:46; 歴代志上 23:32; レビ記 10:6"> しかし、レビびとは、あかしの幕屋のまわりに宿営しなければならない。そうすれば、主の怒りはイスラエルの人々の会衆の上に臨むことがないであろう。レビびとは、あかしの幕屋の務を守らなければならない」。</span>
<span className="v" id="v54" data-v="54" data-xref="申命記 12:32; 出エジプト記 40:16; 出エジプト記 39:32"> イスラエルの人々はこのようにして、すべて主がモーセに命じられたように行った。</span>
</div>
</div>

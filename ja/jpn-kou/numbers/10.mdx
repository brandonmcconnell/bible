<div className="bp">
<span className="v" id="v1" data-v="1"> 主はモーセに言われた、</span>
<span className="v" id="v2" data-v="2" data-xref="イザヤ書 1:13; ヨエル書 1:14; 詩篇 81:3"> 「銀のラッパを二本つくりなさい。すなわち、打物造りとし、それで会衆を呼び集め、また宿営を進ませなさい。</span>
<span className="v" id="v3" data-v="3" data-xref="エレミヤ書 4:5; ヨエル書 2:15–16"> この二つを吹くときは、全会衆が会見の幕屋の入口に、あなたの所に集まってこなければならない。</span>
<span className="v" id="v4" data-v="4" data-xref="民数記 7:2; 出エジプト記 18:21; 民数記 1:4–16"> もしその一つだけを吹くときは、イスラエルの氏族の長であるつかさたちが、あなたの所に集まってこなければならない。</span>
<span className="v" id="v5" data-v="5" data-xref="民数記 2:3–9; 民数記 10:14; イザヤ書 58:1"> またあなたがたが警報を吹き鳴らす時は、東の方の宿営が、道に進まなければならない。</span>
<span className="v" id="v6" data-v="6" data-xref="民数記 10:18; 民数記 2:10–16"> 二度目の警報を吹き鳴らす時は、南の方の宿営が、道に進まなければならない。すべて道に進む時は、警報を吹き鳴らさなければならない。</span>
<span className="v" id="v7" data-v="7" data-xref="ヨエル書 2:1; 民数記 10:3–4"> また会衆を集める時にも、ラッパを吹き鳴らすが、警報は吹き鳴らしてはならない。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨシュア記 6:4–16; 民数記 31:6; 歴代志上 15:24"> アロンの子である祭司たちが、ラッパを吹かなければならない。これはあなたがたが、代々ながく守るべき定めとしなければならない。</span>
<span className="v" id="v9" data-v="9" data-xref="サムエル記上 10:18; 士師記 2:18; 創世記 8:1"> また、あなたがたの国で、あなたがたをしえたげるあだとの戦いに出る時は、ラッパをもって、警報を吹き鳴らさなければならない。そうするならば、あなたがたは、あなたがたの神、主に覚えられて、あなたがたの敵から救われるであろう。</span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 81:3; テサロニケ人への第一の手紙 4:16; コリント人への第一の手紙 11:24–26"> また、あなたがたの喜びの日、あなたがたの祝いの時、および月々の第一日には、あなたがたの燔祭と酬恩祭の犠牲をささげるに当って、ラッパを吹き鳴らさなければならない。そうするならば、あなたがたの神は、それによって、あなたがたを覚えられるであろう。わたしはあなたがたの神、主である」。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="出エジプト記 40:17; 民数記 1:1; 民数記 9:11"> 第二年の二月二十日に、雲があかしの幕屋を離れてのぼったので、</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 21:21; 民数記 12:16; 民数記 9:5"> イスラエルの人々は、シナイの荒野を出て、その旅路に進んだが、パランの荒野に至って、雲はとどまった。</span>
<span className="v" id="v13" data-v="13" data-xref="申命記 1:6; 民数記 9:23"> こうして彼らは、主がモーセによって、命じられたところにしたがって、道に進むことを始めた。</span>
<span className="v" id="v14" data-v="14" data-xref="民数記 2:3–9; 民数記 1:7; 民数記 7:12"> 先頭には、ユダの子たちの宿営の旗が、その部隊を従えて進んだ。ユダの部隊の長はアミナダブの子ナション、</span>
<span className="v" id="v15" data-v="15" data-xref="民数記 7:18; 民数記 1:8"> イッサカルの子たちの部族の部隊の長はツアルの子ネタニエル、</span>
<span className="v" id="v16" data-v="16" data-xref="民数記 7:24; 民数記 1:9"> ゼブルンの子たちの部族の部隊の長はヘロンの子エリアブであった。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="民数記 7:6–8; 民数記 1:51; ヘブル人への手紙 12:28"> そして幕屋は取りくずされ、ゲルションの子たち、およびメラリの子たちは幕屋を運び進んだ。</span>
<span className="v" id="v18" data-v="18" data-xref="民数記 2:10–16; 民数記 1:5; 民数記 26:5–18"> 次にルベンの宿営の旗が、その部隊を従えて進んだ。ルベンの部隊の長はシデウルの子エリヅル、</span>
<span className="v" id="v19" data-v="19" data-xref="民数記 1:6; 民数記 7:36"> シメオンの子たちの部族の部隊の長はツリシャダイの子シルミエル、</span>
<span className="v" id="v20" data-v="20" data-xref="民数記 1:14; 民数記 2:14; 民数記 7:42"> ガドの子たちの部族の部隊の長はデウエルの子エリアサフであった。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="民数記 10:17; 民数記 7:9; 民数記 4:4–16"> そしてコハテびとは聖なる物を運び進んだ。これが着くまでに、人々は幕屋を建て終るのである。</span>
<span className="v" id="v22" data-v="22" data-xref="民数記 2:18–24; 民数記 1:10; 民数記 26:23–41"> 次にエフライムの子たちの宿営の旗が、その部隊を従えて進んだ。エフライムの部隊の長はアミホデの子エリシャマ、</span>
<span className="v" id="v23" data-v="23" data-xref="民数記 1:10; 民数記 7:54"> マナセの子たちの部族の部隊の長はパダヅルの子ガマリエル、</span>
<span className="v" id="v24" data-v="24" data-xref="民数記 1:11; 民数記 7:60"> ベニヤミンの子たちの部族の部隊の長はギデオニの子アビダンであった。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="ヨシュア記 6:9; 民数記 1:12; 創世記 49:16–17"> 次にダンの子たちの宿営の旗が、その部隊を従えて進んだ。この部隊はすべての宿営のしんがりであった。ダンの部隊の長はアミシャダイの子アヒエゼル、</span>
<span className="v" id="v26" data-v="26" data-xref="民数記 1:13; 民数記 7:72"> アセルの子たちの部族の部隊の長はオクランの子パギエル、</span>
<span className="v" id="v27" data-v="27" data-xref="民数記 1:15; 民数記 7:78"> ナフタリの子たちの部族の部隊の長はエナンの子アヒラであった。</span>
<span className="v" id="v28" data-v="28" data-xref="民数記 2:34; 民数記 24:4–5; コリント人への第一の手紙 14:33"> イスラエルの人々が、その道に進む時は、このように、その部隊に従って進んだ。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="創世記 12:7; 士師記 4:11; 出エジプト記 3:1"> さて、モーセは、妻の父、ミデヤンびとリウエルの子ホバブに言った、「わたしたちは、かつて主がおまえたちに与えると約束された所に向かって進んでいます。あなたも一緒においでください。あなたが幸福になられるようにいたしましょう。主がイスラエルに幸福を約束されたのですから」。</span>
<span className="v" id="v30" data-v="30" data-xref="ルツ記 1:15–17; 詩篇 45:10; マタイによる福音書 21:29"> 彼はモーセに言った、「わたしは行きません。わたしは国に帰って、親族のもとに行きます」。</span>
<span className="v" id="v31" data-v="31" data-xref="ヨブ記 29:15; ガラテヤ人への手紙 6:2; コリント人への第一の手紙 12:14–21"> モーセはまた言った、「どうかわたしたちを見捨てないでください。あなたは、わたしたちが荒野のどこに宿営すべきかを御存じですから、わたしたちの目となってください。</span>
<span className="v" id="v32" data-v="32" data-xref="士師記 1:16; 申命記 10:18; ヨハネの第一の手紙 1:3"> もしあなたが一緒においでくださるなら、主がわたしたちに賜わる幸福をあなたにも及ぼしましょう」。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="申命記 1:33; 出エジプト記 3:1; 詩篇 95:11"> こうして彼らは主の山を去って、三日の行程を進んだ。主の契約の箱は、その三日の行程の間、彼らに先立って行き、彼らのために休む所を尋ねもとめた。</span>
<span className="v" id="v34" data-v="34" data-xref="ネヘミヤ書 9:12; ネヘミヤ書 9:19; 詩篇 105:39"> 彼らが宿営を出て、道に進むとき、昼は主の雲が彼らの上にあった。</span>
</div>
<div className="bp poetry">
<span className="v" id="v35" data-v="35" data-xref="詩篇 68:1–2; イザヤ書 17:12–14; 詩篇 132:8"> 契約の箱の進むときモーセは言った、<br /><span className="pl pl-1">「主よ、立ちあがってください。</span><br /><span className="pl pl-1">あなたの敵は打ち散らされ、</span><br /><span className="pl pl-1">あなたを憎む者どもは、</span><br /><span className="pl pl-1">あなたの前から逃げ去りますように」。</span></span>
<span className="v" id="v36" data-v="36" data-xref="申命記 1:10; 詩篇 90:13–17; イザヤ書 63:17"> <span className="pl pl-1">またそのとどまるとき、彼は言った、</span><br /><span className="pl pl-1">「主よ、帰ってきてください、</span><br /><span className="pl pl-1">イスラエルのちよろずの人に」。</span></span>
</div>

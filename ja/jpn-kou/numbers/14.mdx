<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命記 1:45; 民数記 11:1–4"> そこで、会衆はみな声をあげて叫び、民はその夜、泣き明かした。</span>
<span className="v" id="v2" data-v="2" data-xref="出エジプト記 15:24; 出エジプト記 17:3; 民数記 16:41"> またイスラエルの人々はみなモーセとアロンにむかってつぶやき、全会衆は彼らに言った、「ああ、わたしたちはエジプトの国で死んでいたらよかったのに。この荒野で死んでいたらよかったのに。</span>
<span className="v" id="v3" data-v="3" data-xref="民数記 14:31–32; エレミヤ書 9:3; 詩篇 78:40"> なにゆえ、主はわたしたちをこの地に連れてきて、つるぎに倒れさせ、またわたしたちの妻子をえじきとされるのであろうか。エジプトに帰る方が、むしろ良いではないか」。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="使徒行伝 7:39; ネヘミヤ書 9:16–17; 申命記 17:16"> 彼らは互に言った、「わたしたちはひとりのかしらを立てて、エジプトに帰ろう」。</span>
<span className="v" id="v5" data-v="5" data-xref="民数記 16:4; 民数記 16:22; 民数記 16:45"> そこで、モーセとアロンはイスラエルの人々の全会衆の前でひれふした。</span>
<span className="v" id="v6" data-v="6" data-xref="民数記 14:30; 民数記 13:30; 民数記 14:38"> このとき、その地を探った者のうちのヌンの子ヨシュアとエフンネの子カレブは、その衣服を裂き、</span>
<span className="v" id="v7" data-v="7" data-xref="民数記 13:27; 申命記 1:25; 申命記 8:7–9"> イスラエルの人々の全会衆に言った、「わたしたちが行き巡って探った地は非常に良い地です。</span>
<span className="v" id="v8" data-v="8" data-xref="サムエル記下 22:20; イザヤ書 62:4; 民数記 13:27"> もし、主が良しとされるならば、わたしたちをその地に導いて行って、それをわたしたちにくださるでしょう。それは乳と蜜の流れている地です。</span>
<span className="v" id="v9" data-v="9" data-xref="申命記 7:18; ローマ人への手紙 8:31; 申命記 31:6"> ただ、主にそむいてはなりません。またその地の民を恐れてはなりません。彼らはわたしたちの食い物にすぎません。彼らを守る者は取り除かれます。主がわたしたちと共におられますから、彼らを恐れてはなりません」。</span>
<span className="v" id="v10" data-v="10" data-xref="出エジプト記 17:4; サムエル記上 30:6; レビ記 9:23"> ところが会衆はみな石で彼らを撃ち殺そうとした。<br />そのとき、主の栄光が、会見の幕屋からイスラエルのすべての人に現れた。</span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 78:32; 詩篇 106:24; 詩篇 78:22"> 主はモーセに言われた、「この民はいつまでわたしを侮るのか。わたしがもろもろのしるしを彼らのうちに行ったのに、彼らはいつまでわたしを信じないのか。</span>
<span className="v" id="v12" data-v="12" data-xref="出エジプト記 32:10; 民数記 25:9; サムエル記下 24:12–15"> わたしは疫病をもって彼らを撃ち滅ぼし、あなたを彼らよりも大いなる強い国民としよう」。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="詩篇 106:23; エゼキエル書 20:9; 申命記 32:27"> モーセは主に言った、「エジプトびとは、あなたが力をもって、この民を彼らのうちから導き出されたことを聞いて、</span>
<span className="v" id="v14" data-v="14" data-xref="出エジプト記 15:14; 出エジプト記 33:11; 申命記 5:4"> この地の住民に告げるでしょう。彼らは、主なるあなたが、この民のうちにおられ、主なるあなたが、まのあたり現れ、あなたの雲が、彼らの上にとどまり、昼は雲の柱のうちに、夜は火の柱のうちにあって、彼らの前に行かれるのを聞いたのです。</span>
<span className="v" id="v15" data-v="15" data-xref="士師記 6:16"> いま、もし、あなたがこの民をひとり残らず殺されるならば、あなたのことを聞いた国民は語って、</span>
<span className="v" id="v16" data-v="16" data-xref="申命記 9:28; ヨシュア記 7:9; ヨシュア記 7:7"> 『主は与えると誓った地に、この民を導き入れることができなかったため、彼らを荒野で殺したのだ』と言うでしょう。</span>
<span className="v" id="v17" data-v="17" data-xref="マタイによる福音書 9:6; マタイによる福音書 9:8; ミカ書 3:8"> どうぞ、あなたが約束されたように、いま主の大いなる力を現してください。</span>
<span className="v" id="v18" data-v="18" data-xref="出エジプト記 34:6–7; 詩篇 145:8; 出エジプト記 20:5"> あなたはかつて、『主は怒ることおそく、いつくしみに富み、罪ととがをゆるす者、しかし、罰すべき者は、決してゆるさず、父の罪を子に報いて、三、四代に及ぼす者である』と言われました。</span>
<span className="v" id="v19" data-v="19" data-xref="出エジプト記 34:9; 詩篇 78:38; 詩篇 106:45"> どうぞ、あなたの大いなるいつくしみによって、エジプトからこのかた、今にいたるまで、この民をゆるされたように、この民の罪をおゆるしください」。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="ミカ書 7:18–20; ヤコブの手紙 5:16; 詩篇 106:23"> 主は言われた、「わたしはあなたの言葉のとおりにゆるそう。</span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 72:19; ハバクク書 2:14; イザヤ書 6:3"> しかし、わたしは生きている。また主の栄光が、全世界に満ちている。</span>
<span className="v" id="v22" data-v="22" data-xref="ヨブ記 19:3; 創世記 31:7; 出エジプト記 32:1"> わたしの栄光と、わたしがエジプトと荒野で行ったしるしを見ながら、このように十度もわたしを試みて、わたしの声に聞きしたがわなかった人々はひとりも、</span>
<span className="v" id="v23" data-v="23" data-xref="民数記 32:11; 民数記 26:64; エゼキエル書 20:15"> わたしがかつて彼らの先祖たちに与えると誓った地を見ないであろう。またわたしを侮った人々も、それを見ないであろう。</span>
<span className="v" id="v24" data-v="24" data-xref="民数記 14:6–9; ヨシュア記 14:6–14; エペソ人への手紙 6:6"> ただし、わたしのしもべカレブは違った心をもっていて、わたしに完全に従ったので、わたしは彼が行ってきた地に彼を導き入れるであろう。彼の子孫はそれを所有するにいたるであろう。</span>
<span className="v" id="v25" data-v="25" data-xref="申命記 1:40; 民数記 13:29; 詩篇 81:11–13"> 谷にはアマレクびととカナンびとが住んでいるから、あなたがたは、あす、身をめぐらして紅海の道を荒野へ進みなさい」。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26"> 主はモーセとアロンに言われた、</span>
<span className="v" id="v27" data-v="27" data-xref="出エジプト記 16:12; コリント人への第一の手紙 10:10; 出エジプト記 16:28"> 「わたしにむかってつぶやくこの悪い会衆をいつまで忍ぶことができようか。わたしはイスラエルの人々が、わたしにむかってつぶやくのを聞いた。</span>
<span className="v" id="v28" data-v="28" data-xref="民数記 14:21; ヘブル人への手紙 3:17; 民数記 14:2"> あなたは彼らに言いなさい、『主は言われる、「わたしは生きている。あなたがたが、わたしの耳に語ったように、わたしはあなたがたにするであろう。</span>
<span className="v" id="v29" data-v="29" data-xref="民数記 1:45; コリント人への第一の手紙 10:5; ヘブル人への手紙 3:17"> あなたがたは死体となって、この荒野に倒れるであろう。あなたがたのうち、わたしにむかってつぶやいた者、すなわち、すべて数えられた二十歳以上の者はみな倒れるであろう。</span>
<span className="v" id="v30" data-v="30" data-xref="民数記 26:65; 民数記 14:38; 申命記 1:36–38"> エフンネの子カレブと、ヌンの子ヨシュアのほかは、わたしがかつて、あなたがたを住まわせようと、手をあげて誓った地に、はいることができないであろう。</span>
<span className="v" id="v31" data-v="31" data-xref="申命記 1:39; 詩篇 106:24; 民数記 26:64"> しかし、あなたがたが、えじきになるであろうと言ったあなたがたの子供は、わたしが導いて、はいるであろう。彼らはあなたがたが、いやしめた地を知るようになるであろう。</span>
<span className="v" id="v32" data-v="32" data-xref="コリント人への第一の手紙 10:5; 民数記 14:29; ヘブル人への手紙 3:17"> しかしあなたがたは死体となってこの荒野に倒れるであろう。</span>
<span className="v" id="v33" data-v="33" data-xref="エゼキエル書 23:35; 民数記 32:13; 申命記 2:14"> あなたがたの子たちは、あなたがたの死体が荒野に朽ち果てるまで四十年のあいだ、荒野で羊飼となり、あなたがたの不信の罪を負うであろう。</span>
<span className="v" id="v34" data-v="34" data-xref="エゼキエル書 4:6; 民数記 13:25; エレミヤ書 18:9–10"> あなたがたは、かの地を探った四十日の日数にしたがい、その一日を一年として、四十年のあいだ、自分の罪を負い、わたしがあなたがたを遠ざかったことを知るであろう」。</span>
<span className="v" id="v35" data-v="35" data-xref="民数記 23:19; コリント人への第一の手紙 10:5; ヘブル人への手紙 3:19"> 主なるわたしがこれを言う。わたしは必ずわたしに逆らって集まったこの悪い会衆に、これをことごとく行うであろう。彼らはこの荒野に朽ち、ここで死ぬであろう』」。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="民数記 13:31–33; 民数記 13:4–16"> こうして、モーセにつかわされ、かの地を探りに行き、帰ってきて、その地を悪く言い、全会衆を、モーセにむかって、つぶやかせた人々、</span>
<span className="v" id="v37" data-v="37" data-xref="コリント人への第一の手紙 10:10; 民数記 16:49; ヘブル人への手紙 3:17"> すなわち、その地を悪く言いふらした人々は、疫病にかかって主の前に死んだが、</span>
<span className="v" id="v38" data-v="38" data-xref="ヨシュア記 14:6–10; 民数記 26:65"> その地を探りに行った人々のうち、ヌンの子ヨシュアと、エフンネの子カレブとは生き残った。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="出エジプト記 33:4; マタイによる福音書 8:12; ヘブル人への手紙 12:17"> モーセが、これらのことを、イスラエルのすべての人々に告げたとき、民は非常に悲しみ、</span>
<span className="v" id="v40" data-v="40" data-xref="申命記 1:41; マタイによる福音書 7:21–23; ルカによる福音書 13:25"> 朝早く起きて山の頂きに登って言った、「わたしたちはここにいる。さあ、主が約束された所へ上って行こう。わたしたちは罪を犯したのだから」。</span>
<span className="v" id="v41" data-v="41" data-xref="歴代志下 24:20; ヨブ記 4:9; エレミヤ書 2:37"> モーセは言った、「あなたがたは、それをなし遂げることもできないのに、どうして、そのように主の命にそむくのか。</span>
<span className="v" id="v42" data-v="42" data-xref="申命記 1:42; ヨシュア記 7:8; ヨシュア記 7:12"> あなたがたは上って行ってはならない。主があなたがたのうちにおられないから、あなたがたは敵の前に、撃ち破られるであろう。</span>
<span className="v" id="v43" data-v="43" data-xref="民数記 13:29; 民数記 14:25; 歴代志下 15:2"> そこには、アマレクびとと、カナンびとがあなたがたの前にいるから、あなたがたは、つるぎに倒れるであろう。あなたがたがそむいて、主に従わなかったゆえ、主はあなたがたと共におられないからである」。</span>
<span className="v" id="v44" data-v="44" data-xref="申命記 1:43; サムエル記上 4:3–11; 民数記 31:6"> しかし、彼らは、ほしいままに山の頂に登った。ただし、主の契約の箱と、モーセとは、宿営の中から出なかった。</span>
<span className="v" id="v45" data-v="45" data-xref="民数記 21:3; 士師記 1:17; 申命記 1:44"> そこで、その山に住んでいたアマレクびとと、カナンびとが下ってきて、彼らを撃ち破り、ホルマまで追ってきた。</span>
</div>
</div>

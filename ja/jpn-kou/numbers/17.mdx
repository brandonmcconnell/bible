<div className="bp">
<span className="v" id="v1" data-v="1"> 主はモーセに言われた、</span>
<span className="v" id="v2" data-v="2" data-xref="出エジプト記 4:17; エゼキエル書 19:14; 創世記 49:10"> 「イスラエルの人々に告げて、彼らのうちから、おのおのの父祖の家にしたがって、つえ一本ずつを取りなさい。すなわち、そのすべてのつかさたちから、父祖の家にしたがって、つえ十二本を取り、その人々の名を、おのおのそのつえに書きしるし、</span>
<span className="v" id="v3" data-v="3" data-xref="出エジプト記 6:20; 民数記 18:1; 民数記 3:2–3"> レビのつえにはアロンの名を書きしるしなさい。父祖の家のかしらは、おのおののつえ一本を出すのだからである。</span>
<span className="v" id="v4" data-v="4" data-xref="出エジプト記 30:36; 出エジプト記 29:42–43; 出エジプト記 25:16–22"> そして、これらのつえを、わたしがあなたがたに会う会見の幕屋の中の、あかしの箱の前に置きなさい。</span>
<span className="v" id="v5" data-v="5" data-xref="民数記 16:5; 民数記 17:8; 民数記 16:11"> わたしの選んだ人のつえには、芽が出るであろう。こうして、わたしはイスラエルの人々が、あなたがたにむかって、つぶやくのをやめさせるであろう」。</span>
<span className="v" id="v6" data-v="6"> モーセが、このようにイスラエルの人々に語ったので、つかさたちはみな、その父祖の家にしたがって、おのおの、つえ一本ずつを彼に渡した。そのつえは合わせて十二本。アロンのつえも、そのつえのうちにあった。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行伝 7:44; 出エジプト記 38:21; 民数記 18:2"> モーセは、それらのつえを、あかしの幕屋の中の、主の前に置いた。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="エゼキエル書 17:24; ヨハネによる福音書 15:1–6; 詩篇 132:17–18"> その翌日、モーセが、あかしの幕屋にはいって見ると、レビの家のために出したアロンのつえは芽をふき、つぼみを出し、花が咲いて、あめんどうの実を結んでいた。</span>
<span className="v" id="v9" data-v="9"> モーセがそれらのつえを、ことごとく主の前から、イスラエルのすべての人の所に持ち出したので、彼らは見て、おのおの自分のつえを取った。</span>
<span className="v" id="v10" data-v="10" data-xref="ヘブル人への手紙 9:4; エペソ人への手紙 5:6; イザヤ書 1:2"> 主はモーセに言われた、「アロンのつえを、あかしの箱の前に持ち帰り、そこに保存して、そむく者どものために、しるしとしなさい。こうして、彼らのわたしに対するつぶやきをやめさせ、彼らの死ぬのをまぬかれさせなければならない」。</span>
<span className="v" id="v11" data-v="11"> モーセはそのようにして、主が彼に命じられたとおりに行った。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="民数記 26:11; イザヤ書 57:16; イザヤ書 6:5"> イスラエルの人々は、モーセに言った、「ああ、わたしたちは死ぬ。破滅です、全滅です。</span>
<span className="v" id="v13" data-v="13" data-xref="ヘブル人への手紙 10:19–22; サムエル記下 6:6–12; 創世記 3:3"> 主の幕屋に近づく者が、みな死ぬのであれば、わたしたちは死に絶えるではありませんか」。</span>
</div>

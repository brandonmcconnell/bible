<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 主はまたモーセに言われた、</span>
<span className="v" id="v2" data-v="2" data-xref="レビ記 21:1; レビ記 13:46; 民数記 12:14"> 「イスラエルの人々に命じて、らい病人、流出のある者、死体にふれて汚れた者を、ことごとく宿営の外に出させなさい。</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 23:14; レビ記 26:11–12; 詩篇 68:18"> 男でも女でも、あなたがたは彼らを宿営の外に出してそこにおらせ、彼らに宿営を汚させてはならない。わたしがその中に住んでいるからである」。</span>
<span className="v" id="v4" data-v="4"> イスラエルの人々はそのようにして、彼らを宿営の外に出した。すなわち、主がモーセに言われたようにイスラエルの人々は行った。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5"> 主はまたモーセに言われた、</span>
<span className="v" id="v6" data-v="6" data-xref="レビ記 5:1–4; レビ記 5:14–7"> 「イスラエルの人々に告げなさい、『男または女が、もし人の犯す罪をおかして、主に罪を得、その人がとがある者となる時は、</span>
<span className="v" id="v7" data-v="7" data-xref="レビ記 5:5; レビ記 26:40; ヨシュア記 7:19"> その犯した罪を告白し、その物の価にその五分の一を加えて、彼がとがを犯した相手方に渡し、そのとがをことごとく償わなければならない。</span>
<span className="v" id="v8" data-v="8" data-xref="レビ記 6:6–7; レビ記 7:7; レビ記 25:25–26"> しかし、もし、そのとがの償いを受け取るべき親族も、その人にない時は、主にそのとがの償いをして、これを祭司に帰せしめなければならない。なお、このほか、そのあがないをするために用いた贖罪の雄羊も、祭司に帰せしめなければならない。</span>
<span className="v" id="v9" data-v="9" data-xref="申命記 18:3–4; レビ記 7:6–14; レビ記 6:17–18"> イスラエルの人々が、祭司のもとに携えて来るすべての聖なるささげ物は、みな祭司に帰せしめなければならない。</span>
<span className="v" id="v10" data-v="10" data-xref="レビ記 10:13"> すべて人の聖なるささげ物は祭司に帰し、すべて人が祭司に与える物は祭司に帰するであろう』」。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11"> 主はまたモーセに言われた、</span>
<span className="v" id="v12" data-v="12" data-xref="民数記 5:19–20; 箴言 2:16–17"> 「イスラエルの人々に告げなさい、『もし人の妻たる者が、道ならぬ事をして、その夫に罪を犯し、</span>
<span className="v" id="v13" data-v="13" data-xref="レビ記 18:20; レビ記 20:10; 箴言 7:18–19"> 人が彼女と寝たのに、その事が夫の目に隠れて現れず、彼女はその身を汚したけれども、それに対する証人もなく、彼女もまたその時に捕えられなかった場合、</span>
<span className="v" id="v14" data-v="14" data-xref="雅歌 8:6; 箴言 6:34; ゼパニヤ書 3:8"> すなわち、妻が身を汚したために、夫が疑いの心を起して妻を疑うことがあり、または妻が身を汚した事がないのに、夫が疑いの心を起して妻を疑うことがあれば、</span>
<span className="v" id="v15" data-v="15" data-xref="エゼキエル書 29:16; 列王紀上 17:18; レビ記 5:11"> 夫は妻を祭司のもとに伴い、彼女のために大麦の粉一エパの十分の一を供え物として携えてこなければならない。ただし、その上に油を注いではならない。また乳香を加えてはならない。これは疑いの供え物、覚えの供え物であって罪を覚えさせるものだからである。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="ヨハネの黙示録 2:22–23; エレミヤ書 17:10; ヘブル人への手紙 13:4"> 祭司はその女を近く進ませ、主の前に立たせなければならない。</span>
<span className="v" id="v17" data-v="17" data-xref="出エジプト記 30:18; ヨハネによる福音書 8:6; 民数記 19:2–9"> 祭司はまた土の器に聖なる水を入れ、幕屋のゆかのちりを取ってその水に入れ、</span>
<span className="v" id="v18" data-v="18" data-xref="箴言 5:4; 民数記 5:22; ヨハネの黙示録 10:9–10"> その女を主の前に立たせ、女にその髪の毛をほどかせ、覚えの供え物すなわち、疑いの供え物を、その手に持たせなければならない。そして祭司は、のろいの苦い水を手に取り、</span>
<span className="v" id="v19" data-v="19" data-xref="ローマ人への手紙 7:2; 民数記 5:12; マタイによる福音書 26:63"> 女に誓わせて、これに言わなければならない、「もし人があなたと寝たことがなく、またあなたが、夫のもとにあって、道ならぬ事をして汚れたことがなければ、のろいの苦い水も、あなたに害を与えないであろう。</span>
<span className="v" id="v20" data-v="20" data-xref="民数記 5:12"> しかし、あなたが、もし夫のもとにあって、道ならぬことをして身を汚し、あなたの夫でない人が、あなたと寝たことがあるならば、――</span>
<span className="v" id="v21" data-v="21" data-xref="ヨシュア記 6:26; ネヘミヤ書 10:29; サムエル記上 14:24"> 祭司はその女に、のろいの誓いをもって誓わせ、その女に言わなければならない。――主はあなたのももをやせさせ、あなたの腹をふくれさせて、あなたを民のうちの、のろいとし、また、ののしりとされるように。</span>
<span className="v" id="v22" data-v="22" data-xref="詩篇 109:18; 詩篇 89:52; ヨブ記 31:39–40"> また、のろいの水が、あなたの腹にはいってあなたの腹をふくれさせ、あなたのももをやせさせるように」。その時、女は「アァメン、アァメン」と言わなければならない。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="使徒行伝 3:19; 詩篇 51:1; 詩篇 51:9"> 祭司は、こののろいを書き物に書きしるし、それを苦い水に洗い落し、</span>
<span className="v" id="v24" data-v="24" data-xref="ゼカリヤ書 5:3–4; マラキ書 3:5"> 女にそののろいの水を飲ませなければならない。そののろいの水は彼女のうちにはいって苦くなるであろう。</span>
<span className="v" id="v25" data-v="25" data-xref="レビ記 8:27; 民数記 5:18; 民数記 5:15"> そして祭司はその女の手から疑いの供え物を取り、その供え物を主の前に揺り動かして、それを祭壇に持ってこなければならない。</span>
<span className="v" id="v26" data-v="26" data-xref="レビ記 2:2; レビ記 2:9; レビ記 5:12"> 祭司はその供え物のうちから、覚えの分、一握りを取って、それを祭壇で焼き、その後、女にその水を飲ませなければならない。</span>
<span className="v" id="v27" data-v="27" data-xref="エレミヤ書 42:18; ゼカリヤ書 8:13; エレミヤ書 29:18"> その水を女に飲ませる時、もしその女が身を汚し、夫に罪を犯した事があれば、そののろいの水は女のうちにはいって苦くなり、その腹はふくれ、ももはやせて、その女は民のうちののろいとなるであろう。</span>
<span className="v" id="v28" data-v="28" data-xref="ミカ書 7:7–10; コリント人への第二の手紙 4:17; 詩篇 113:9"> しかし、もし女が身を汚した事がなく、清いならば、害を受けないで、子を産むことができるであろう。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="民数記 5:19; 民数記 5:12; 民数記 5:15"> これは疑いのある時のおきてである。妻たる者が夫のもとにあって、道ならぬ事をして身を汚した時、</span>
<span className="v" id="v30" data-v="30"> または夫たる者が疑いの心を起して、妻を疑う時、彼はその女を主の前に立たせ、祭司はこのおきてを、ことごとく彼女に行わなければならない。</span>
<span className="v" id="v31" data-v="31" data-xref="レビ記 20:10; ローマ人への手紙 2:8–9; エゼキエル書 18:4"> こうするならば、夫は罪がなく、妻は罪を負うであろう』」。</span>
</div>
</div>

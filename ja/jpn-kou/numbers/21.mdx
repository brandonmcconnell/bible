<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士師記 1:16; 民数記 33:40; ヨシュア記 12:14"> 時にネゲブに住んでいたカナンびとアラデの王は、イスラエルがアタリムの道をとおって来ると聞いて、イスラエルを攻撃し、そのうちの数人を捕虜にした。</span>
<span className="v" id="v2" data-v="2" data-xref="士師記 11:30; 創世記 28:20; サムエル記上 1:11"> そこでイスラエルは主に誓いを立てて言った、「もし、あなたがこの民をわたしの手にわたしてくださるならば、わたしはその町々をことごとく滅ぼしましょう」。</span>
<span className="v" id="v3" data-v="3" data-xref="民数記 14:45; 申命記 1:44; 詩篇 10:17"> 主はイスラエルの言葉を聞きいれ、カナンびとをわたされたので、イスラエルはそのカナンびとと、その町々とをことごとく滅ぼした。それでその所の名はホルマと呼ばれた。</span>
</div>
<div className="bp poetry">
<span className="v" id="v4" data-v="4" data-xref="出エジプト記 6:9; 士師記 11:18; 民数記 32:7"> 民はホル山から進み、紅海の道をとおって、エドムの地を回ろうとしたが、民はその道に堪えがたくなった。</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 78:19; 民数記 16:13–14; 出エジプト記 17:2–3"> 民は神とモーセとにむかい、つぶやいて言った、「あなたがたはなぜわたしたちをエジプトから導き上って、荒野で死なせようとするのですか。ここには食物もなく、水もありません。わたしたちはこの粗悪な食物はいやになりました」。</span>
<span className="v" id="v6" data-v="6" data-xref="コリント人への第一の手紙 10:9; エレミヤ書 8:17; 申命記 8:15"> そこで主は、火のへびを民のうちに送られた。へびは民をかんだので、イスラエルの民のうち、多くのものが死んだ。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行伝 8:24; 民数記 11:2; 詩篇 78:34"> 民はモーセのもとに行って言った、「わたしたちは主にむかい、またあなたにむかい、つぶやいて罪を犯しました。どうぞへびをわたしたちから取り去られるように主に祈ってください」。モーセは民のために祈った。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨハネによる福音書 3:14; 詩篇 106:43–45; 詩篇 145:8"> そこで主はモーセに言われた、「火のへびを造って、それをさおの上に掛けなさい。すべてのかまれた者が仰いで、それを見るならば生きるであろう」。</span>
<span className="v" id="v9" data-v="9" data-xref="ヨハネによる福音書 3:14–15; ヘブル人への手紙 12:2; ヨハネによる福音書 6:40"> モーセは青銅で一つのへびを造り、それをさおの上に掛けて置いた。すべてへびにかまれた者はその青銅のへびを仰いで見て生きた。</span>
<span className="v" id="v10" data-v="10" data-xref="民数記 33:43–45"> イスラエルの人々は道を進んでオボテに宿営した。</span>
<span className="v" id="v11" data-v="11"> またオボテから進んで東の方、モアブの前にある荒野において、イエアバリムに宿営した。</span>
<span className="v" id="v12" data-v="12" data-xref="申命記 2:13–14"> またそこから進んでゼレデの谷に宿営し、</span>
<span className="v" id="v13" data-v="13" data-xref="士師記 11:18; 民数記 22:36; イザヤ書 16:2"> さらにそこから進んでアルノン川のかなたに宿営した。アルノン川はアモリびとの境から延び広がる荒野を流れるもので、モアブとアモリびととの間にあって、モアブの境をなしていた。</span>
<span className="v" id="v14" data-v="14" data-xref="ヨシュア記 10:13; サムエル記下 1:18"> それゆえに、「主の戦いの書」にこう言われている。<br /><span className="pl pl-1">「スパのワヘブ、</span><br /><span className="pl pl-1">アルノンの谷々、</span></span>
<span className="v" id="v15" data-v="15" data-xref="民数記 21:28; 申命記 2:18; 申命記 2:9"> <span className="pl pl-1">谷々の斜面、</span><br /><span className="pl pl-1">アルの町まで傾き、</span><br /><span className="pl pl-1">モアブの境に寄りかかる」。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v16" data-v="16" data-xref="民数記 20:8; イザヤ書 12:3; イザヤ書 41:17–18"> 彼らはそこからベエルへ進んで行った。これは主がモーセにむかって、「民を集めよ。わたしはかれらに水を与えるであろう」と言われた井戸である。</span>
<span className="v" id="v17" data-v="17" data-xref="ヤコブの手紙 5:13; 出エジプト記 15:1–2; 詩篇 106:12"> その時イスラエルはこの歌をうたった。<br /><span className="pl pl-1">「井戸の水よ、わきあがれ、</span><br /><span className="pl pl-1">人々よ、この井戸のために歌え、</span></span>
<span className="v" id="v18" data-v="18" data-xref="イザヤ書 33:22; テモテヘの第一の手紙 6:17–18; ヤコブの手紙 4:12"> <span className="pl pl-1">笏とつえとをもって</span><br /><span className="pl pl-1">つかさたちがこの井戸を掘り、</span><br /><span className="pl pl-1">民のおさたちがこれを掘った」。</span><br />そして彼らは荒野からマッタナに進み、</span>
<span className="v" id="v19" data-v="19"> マッタナからナハリエルに、ナハリエルからバモテに、</span>
<span className="v" id="v20" data-v="20" data-xref="民数記 23:28; 民数記 23:14; 申命記 1:5"> バモテからモアブの野にある谷に行き、荒野を見おろすピスガの頂に着いた。</span>
</div>
<div className="bp poetry">
<span className="v" id="v21" data-v="21" data-xref="申命記 2:26–28; 民数記 20:14–19; 士師記 11:19–21"> ここでイスラエルはアモリびとの王シホンに使者をつかわして言わせた、</span>
<span className="v" id="v22" data-v="22" data-xref="民数記 20:17"> 「わたしにあなたの国を通らせてください。わたしたちは畑にもぶどう畑にも、はいりません。また井戸の水も飲みません。わたしたちはあなたの領地を通り過ぎるまで、ただ王の大路を通ります」。</span>
<span className="v" id="v23" data-v="23" data-xref="士師記 11:20; 申命記 29:7–8; イザヤ書 15:4"> しかし、シホンはイスラエルに自分の領地を通ることを許さなかった。そしてシホンは民をことごとく集め、荒野に出て、イスラエルを攻めようとし、ヤハズにきてイスラエルと戦った。</span>
<span className="v" id="v24" data-v="24" data-xref="アモス書 2:9; ヨシュア記 24:8; 創世記 32:22"> イスラエルは、やいばで彼を撃ちやぶり、アルノンからヤボクまで彼の地を占領し、アンモンびとの境に及んだ。ヤゼルはアンモンびとの境だからである。</span>
<span className="v" id="v25" data-v="25" data-xref="民数記 32:33–42; イザヤ書 16:8–9; エレミヤ書 48:2"> こうしてイスラエルはこれらの町々をことごとく取った。そしてイスラエルはアモリびとのすべての町々に住み、ヘシボンとそれに附属するすべての村々にいた。</span>
<span className="v" id="v26" data-v="26"> ヘシボンはアモリびとの王シホンの都であって、シホンはモアブの以前の王と戦って、彼の地をアルノンまで、ことごとくその手から奪い取ったのである。</span>
<span className="v" id="v27" data-v="27" data-xref="イザヤ書 14:4; 民数記 21:14; ハバクク書 2:6"> それゆえに歌にうたわれている。<br /><span className="pl pl-1">「人々よ、ヘシボンにきたれ、</span><br /><span className="pl pl-1">シホンの町を築き建てよ。</span></span>
<span className="v" id="v28" data-v="28" data-xref="民数記 21:15; エレミヤ書 48:45–46; イザヤ書 15:1–2"> <span className="pl pl-1">ヘシボンから火が燃え出し、</span><br /><span className="pl pl-1">シホンの都から炎が出て、</span><br /><span className="pl pl-1">モアブのアルを焼き尽し、</span><br /><span className="pl pl-1">アルノンの高地の君たちを滅ぼしたからだ。</span></span>
<span className="v" id="v29" data-v="29" data-xref="士師記 11:24; 列王紀下 23:13; エレミヤ書 48:46"> <span className="pl pl-1">モアブよ、お前はわざわいなるかな、</span><br /><span className="pl pl-1">ケモシの民よ、お前は滅ぼされるであろう。</span><br /><span className="pl pl-1">彼は、むすこらを逃げ去らせ、</span><br /><span className="pl pl-1">娘らをアモリびとの王シホンの捕虜とならせた。</span></span>
<span className="v" id="v30" data-v="30" data-xref="エレミヤ書 48:18; イザヤ書 15:2; エレミヤ書 48:22"> <span className="pl pl-1">彼らの子らは滅び去った、</span><br /><span className="pl pl-1">ヘシボンからデボンまで。</span><br /><span className="pl pl-1">われわれは荒した、火はついてメデバに及んだ」。</span></span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="ヨシュア記 13:8–12; 民数記 32:33–42; 申命記 3:16–17"> こうしてイスラエルはアモリびとの地に住んだが、</span>
<span className="v" id="v32" data-v="32" data-xref="エレミヤ書 48:32; 民数記 32:1; 民数記 32:35"> モーセはまた人をつかわしてヤゼルを探らせ、ついにその村々を取って、そこにいたアモリびとを追い出し、</span>
<span className="v" id="v33" data-v="33" data-xref="ヨシュア記 13:12; 申命記 1:4; 申命記 29:7"> 転じてバシャンの道に上って行ったが、バシャンの王オグは、その民をことごとく率い、エデレイで戦おうとして出迎えた。</span>
<span className="v" id="v34" data-v="34" data-xref="詩篇 135:10–11; ヨシュア記 8:7; 申命記 3:2–3"> 主はモーセに言われた、「彼を恐れてはならない。わたしは彼とその民とその地とを、ことごとくあなたの手にわたす。あなたはヘシボンに住んでいたアモリびとの王シホンにしたように彼にもするであろう」。</span>
<span className="v" id="v35" data-v="35" data-xref="申命記 29:7–8; ヨシュア記 13:12; 申命記 3:3–17"> そこで彼とその子とすべての民とを、ひとり残らず撃ち殺して、その地を占領した。</span>
</div>

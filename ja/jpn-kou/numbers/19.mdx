<div className="bp">
<span className="v" id="v1" data-v="1"> 主はモーセとアロンに言われた、</span>
<span className="v" id="v2" data-v="2" data-xref="レビ記 22:20–25; 申命記 21:3; サムエル記上 6:7"> 「主の命じられた律法の定めは次のとおりである。すなわち『イスラエルの人々に告げて、完全で、傷がなく、まだくびきを負ったことのない赤い雌牛を、あなたのもとに引いてこさせ、</span>
<span className="v" id="v3" data-v="3" data-xref="レビ記 4:12; レビ記 4:21; レビ記 16:27"> これを祭司エレアザルにわたして、宿営の外にひき出させ、彼の前でこれをほふらせなければならない。</span>
<span className="v" id="v4" data-v="4" data-xref="レビ記 4:17; レビ記 4:6; レビ記 16:14"> そして祭司エレアザルは、指をもってその血を取り、会見の幕屋の表に向かって、その血を七たびふりかけなければならない。</span>
<span className="v" id="v5" data-v="5" data-xref="出エジプト記 29:14; レビ記 4:11–12; 詩篇 22:14"> ついでその雌牛を自分の目の前で焼かせ、その皮と肉と血とは、その汚物と共に焼かなければならない。</span>
<span className="v" id="v6" data-v="6" data-xref="レビ記 14:4; レビ記 14:49; 詩篇 51:7"> そして祭司は香柏の木と、ヒソプと、緋の糸とを取って雌牛の燃えているなかに投げ入れなければならない。</span>
<span className="v" id="v7" data-v="7" data-xref="レビ記 11:25; レビ記 11:40; 民数記 19:8"> そして祭司は衣服を洗い、水に身をすすいで後、宿営に、はいることができる。ただし祭司は夕まで汚れる。</span>
<span className="v" id="v8" data-v="8"> またその雌牛を焼いた者も水で衣服を洗い、水に身をすすがなければならない。彼も夕まで汚れる。</span>
<span className="v" id="v9" data-v="9" data-xref="ヘブル人への手紙 9:13; 民数記 19:13; 民数記 19:20–21"> それから身の清い者がひとり、その雌牛の灰を集め、宿営の外の清い所にたくわえておかなければならない。これはイスラエルの人々の会衆のため、汚れを清める水をつくるために備えるものであって、罪を清めるものである。</span>
<span className="v" id="v10" data-v="10" data-xref="出エジプト記 12:49; 民数記 19:7–8; コロサイ人への手紙 3:11"> その雌牛の灰を集めた者は衣服を洗わなければならない。その人は夕まで汚れる。これはイスラエルの人々と、そのうちに宿っている他国人との、永久に守るべき定めとしなければならない。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="民数記 5:2; 民数記 31:19; レビ記 21:1"> すべて人の死体に触れる者は、七日のあいだ汚れる。</span>
<span className="v" id="v12" data-v="12" data-xref="民数記 31:19; ヨハネの黙示録 7:14; レビ記 7:17"> その人は三日目と七日目とに、この灰の水をもって身を清めなければならない。そうすれば清くなるであろう。しかし、もし三日目と七日目とに、身を清めないならば、清くならないであろう。</span>
<span className="v" id="v13" data-v="13" data-xref="レビ記 15:31; レビ記 22:3; レビ記 7:20"> すべて死人の死体に触れて、身を清めない者は主の幕屋を汚す者で、その人はイスラエルから断たれなければならない。汚れを清める水がその身に注ぎかけられないゆえ、その人は清くならず、その汚れは、なお、その身にあるからである。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14"> 人が天幕の中で死んだ時に用いる律法は次のとおりである。すなわち、すべてその天幕にはいった者、およびすべてその天幕にいた者は七日のあいだ汚れる。</span>
<span className="v" id="v15" data-v="15" data-xref="レビ記 14:36; レビ記 11:32; 民数記 31:20"> ふたで上をおおわない器はみな汚れる。</span>
<span className="v" id="v16" data-v="16" data-xref="民数記 31:19; マタイによる福音書 23:27; ルカによる福音書 11:44"> つるぎで殺された者、または死んだ者、または人の骨、または墓などに、野外で触れる者は皆、七日のあいだ汚れる。</span>
<span className="v" id="v17" data-v="17" data-xref="ヨハネによる福音書 7:38; 創世記 26:19; ヨハネの黙示録 7:17"> 汚れた者があった時には、罪を清める焼いた雌牛の灰を取って器に入れ、流れの水をこれに加え、</span>
<span className="v" id="v18" data-v="18" data-xref="エゼキエル書 36:25–27; ヘブル人への手紙 9:14; 民数記 19:9"> 身の清い者がひとりヒソプを取って、その水に浸し、これをその天幕と、すべての器と、そこにいた人々と、骨、あるいは殺された者、あるいは死んだ者、あるいは墓などに触れた者とにふりかけなければならない。</span>
<span className="v" id="v19" data-v="19" data-xref="ヨハネの第一の手紙 1:7; ヘブル人への手紙 10:22; エゼキエル書 36:25"> すなわちその身の清い人は三日目と七日目とにその汚れたものに、それをふりかけなければならない。そして七日目にその人は身を清め、衣服を洗い、水に身をすすがなければならない。そうすれば夕になって清くなるであろう。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="マルコによる福音書 16:16; 創世記 17:14; 民数記 19:13"> しかし、汚れて身を清めない人は主の聖所を汚す者で、その人は会衆のうちから断たれなければならない。汚れを清める水がその身に注ぎかけられないゆえ、その人は汚れているからである。</span>
<span className="v" id="v21" data-v="21" data-xref="ヘブル人への手紙 9:13–14; ヘブル人への手紙 10:4; ヘブル人への手紙 9:10"> これは彼らの永久に守るべき定めとしなければならない。すなわち汚れを清める水をふりかけた者は衣服を洗わなければならない。また汚れを清める水に触れた者も夕まで汚れるであろう。</span>
<span className="v" id="v22" data-v="22" data-xref="ハガイ書 2:13; レビ記 7:19; マタイによる福音書 15:19–20"> すべて汚れた人の触れる物は汚れる。またそれに触れる人も夕まで汚れるであろう』」。</span>
</div>

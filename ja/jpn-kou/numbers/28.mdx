<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 主はモーセに言われた、</span>
<span className="v" id="v2" data-v="2" data-xref="レビ記 3:11; 創世記 8:21; 民数記 9:2–3"> 「イスラエルの人々に命じて言いなさい、『あなたがたは香ばしいかおりとしてわたしにささげる火祭、すなわち、わたしの供え物、わたしの食物を定めの時にわたしにささげることを怠ってはならない』。</span>
<span className="v" id="v3" data-v="3" data-xref="レビ記 6:9; ダニエル書 11:31; ヨハネによる福音書 1:29"> また彼らに言いなさい、『あなたがたが主にささぐべき火祭はこれである。すなわち一歳の雄の全き小羊二頭を毎日ささげて常燔祭としなければならない。</span>
<span className="v" id="v4" data-v="4" data-xref="ダニエル書 9:21; 列王紀上 18:36; 出エジプト記 12:6"> すなわち一頭の小羊を朝にささげ、一頭の小羊を夕にささげなければならない。</span>
<span className="v" id="v5" data-v="5" data-xref="レビ記 2:1; 出エジプト記 16:36; 出エジプト記 29:38–42"> また麦粉一エパの十分の一に、砕いて取った油一ヒンの四分の一を混ぜて素祭としなければならない。</span>
<span className="v" id="v6" data-v="6" data-xref="アモス書 5:25; レビ記 6:9; 詩篇 50:8"> これはシナイ山で定められた常燔祭であって、主に香ばしいかおりとしてささげる火祭である。</span>
<span className="v" id="v7" data-v="7" data-xref="出エジプト記 29:42; 民数記 28:14; イザヤ書 57:6"> またその灌祭は小羊一頭について一ヒンの四分の一をささげなければならない。すなわち聖所において主のために濃い酒をそそいで灌祭としなければならない。</span>
<span className="v" id="v8" data-v="8"> 夕には他の一頭の小羊をささげなければならない。その素祭と灌祭とは朝のものと同じようにし、その小羊を火祭としてささげ、主に香ばしいかおりとしなければならない。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="イザヤ書 58:13; 詩篇 92:1–4; ヨハネの黙示録 1:10"> また安息日には一歳の雄の全き小羊二頭と、麦粉一エパの十分の二に油を混ぜた素祭と、その灌祭とをささげなければならない。</span>
<span className="v" id="v10" data-v="10" data-xref="エゼキエル書 46:4–5; 民数記 29:22; 民数記 29:31"> これは安息日ごとの燔祭であって、常燔祭とその灌祭とに加えらるべきものである。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="民数記 10:10; エゼキエル書 46:6; エズラ記 3:5"> またあなたがたは月々の第一日に燔祭を主にささげなければならない。すなわち若い雄牛二頭、雄羊一頭、一歳の雄の全き小羊七頭をささげ、</span>
<span className="v" id="v12" data-v="12" data-xref="民数記 15:4–12; エゼキエル書 46:5–7; 民数記 29:10"> 雄牛一頭には麦粉一エパの十分の三に油を混ぜたものを素祭とし、雄羊一頭には麦粉一エパの十分の二に油を混ぜたものを素祭とし、</span>
<span className="v" id="v13" data-v="13"> 小羊一頭には麦粉十分の一に油を混ぜたものを素祭とし、これを香ばしいかおりの燔祭として主のために火祭としなければならない。</span>
<span className="v" id="v14" data-v="14"> またその灌祭は雄牛一頭についてぶどう酒一ヒンの二分の一、雄羊一頭について一ヒンの三分の一、小羊一頭について一ヒンの四分の一をささげなければならない。これは年の月々を通じて、新月ごとにささぐべき燔祭である。</span>
<span className="v" id="v15" data-v="15" data-xref="民数記 28:3; 民数記 28:22; 民数記 15:24"> また常燔祭とその灌祭とのほかに、雄やぎ一頭を罪祭として主にささげなければならない。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="申命記 16:1–8; 出エジプト記 12:18; レビ記 23:5–8"> 正月の十四日は主の過越の祭である。</span>
<span className="v" id="v17" data-v="17" data-xref="レビ記 23:6; 出エジプト記 23:15; 出エジプト記 13:6"> またその月の十五日は祭日としなければならない。七日のあいだ種入れぬパンを食べなければならない。</span>
<span className="v" id="v18" data-v="18" data-xref="出エジプト記 12:16; レビ記 23:7–8"> その初めの日には聖会を開かなければならない。なんの労役をもしてはならない。</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 15:21; エゼキエル書 45:21–25; 民数記 29:8"> あなたがたは火祭として主に燔祭をささげなければならない。すなわち若い雄牛二頭、雄羊一頭、一歳の雄の小羊七頭をささげなければならない。これらはみな全きものでなければならない。</span>
<span className="v" id="v20" data-v="20"> その素祭には油を混ぜた麦粉をささげなければならない。すなわち雄牛一頭につき麦粉一エパの十分の三、雄羊一頭につき十分の二をささげ、</span>
<span className="v" id="v21" data-v="21"> また七頭の小羊にはその一頭ごとに十分の一をささげなければならない。</span>
<span className="v" id="v22" data-v="22" data-xref="ローマ人への手紙 8:3"> また雄やぎ一頭を罪祭としてささげ、あなたがたのために罪のあがないをしなければならない。</span>
<span className="v" id="v23" data-v="23" data-xref="民数記 28:3; 民数記 28:10"> あなたがたは朝にささげる常燔祭の燔祭のほかに、これらをささげなければならない。</span>
<span className="v" id="v24" data-v="24"> このようにあなたがたは七日のあいだ毎日、火祭の食物をささげて、主に香ばしいかおりとしなければならない。これは常燔祭とその灌祭とのほかにささぐべきものである。</span>
<span className="v" id="v25" data-v="25" data-xref="レビ記 23:8; 民数記 28:18; 出エジプト記 13:6"> そして第七日に、あなたがたは聖会を開かなければならない。なんの労役をもしてはならない。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="出エジプト記 23:16; 出エジプト記 34:22; レビ記 23:10"> あなたがたは七週の祭、すなわち新しい素祭を主にささげる初穂の日にも聖会を開かなければならない。なんの労役をもしてはならない。</span>
<span className="v" id="v27" data-v="27" data-xref="レビ記 23:18–19; 民数記 28:11; 民数記 28:19"> あなたがたは燔祭をささげて、主に香ばしいかおりとしなければならない。すなわち若い雄牛二頭、雄羊一頭、一歳の雄の小羊七頭をささげなければならない。</span>
<span className="v" id="v28" data-v="28"> その素祭には油を混ぜた麦粉をささげなければならない。すなわち雄牛一頭につき一エパの十分の三、雄羊一頭につき十分の二をささげ、</span>
<span className="v" id="v29" data-v="29"> また七頭の小羊には一頭ごとに十分の一をささげなければならない。</span>
<span className="v" id="v30" data-v="30" data-xref="民数記 28:15; 民数記 28:22; ペテロの第一の手紙 2:24"> また雄やぎ一頭をささげてあなたがたのために罪のあがないをしなければならない。</span>
<span className="v" id="v31" data-v="31" data-xref="民数記 28:19; 民数記 28:3; マラキ書 1:13–14"> あなたがたは常燔祭とその素祭とその灌祭とのほかに、これらをささげなければならない。これらはみな、全きものでなければならない。</span>
</div>

<span className="v" id="v1" data-v="1" data-xref="民数記 23:3; 民数記 23:23; 民数記 23:28"> バラムはイスラエルを祝福することが主の心にかなうのを見たので、今度はいつものように行って魔術を求めることをせず、顔を荒野にむけ、</span>
<span className="v" id="v2" data-v="2" data-xref="サムエル記上 19:20; 歴代志下 15:1; サムエル記上 19:23"> 目を上げて、イスラエルがそれぞれ部族にしたがって宿営しているのを見た。その時、神の霊が臨んだので、</span>
<span className="v" id="v3" data-v="3" data-xref="民数記 22:31; 民数記 24:16; 民数記 23:7"> 彼はこの託宣を述べた。<br /><span className="pl pl-1">「ベオルの子バラムの言葉、</span><br /><span className="pl pl-1">目を閉じた人の言葉、</span></span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネの黙示録 1:17; ヨハネの黙示録 1:10; 民数記 12:6"> <span className="pl pl-1">神の言葉を聞く者、</span><br /><span className="pl pl-1">全能者の幻を見る者、</span><br /><span className="pl pl-1">倒れ伏して、目の開かれた者の言葉。</span></span>

<span className="v" id="v7" data-v="7" data-xref="サムエル記下 5:12; 歴代志上 14:2; ヨハネの黙示録 17:1"> <span className="pl pl-1">水は彼らのかめからあふれ、</span><br /><span className="pl pl-1">彼らの種は水の潤いに育つであろう。</span><br /><span className="pl pl-1">彼らの王はアガグよりも高くなり、</span><br /><span className="pl pl-1">彼らの国はあがめられるであろう。</span></span>

<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="民数記 23:11; エゼキエル書 21:14; エゼキエル書 21:17"> そこでバラクはバラムにむかって怒りを発し、手を打ち鳴らした。そしてバラクはバラムに言った、「敵をのろうために招いたのに、あなたはかえって三度までも彼らを祝福した。</span>
<span className="v" id="v11" data-v="11" data-xref="民数記 22:17; 民数記 22:37; ヘブル人への手紙 11:24–26"> それで今あなたは急いで自分のところへ帰ってください。わたしはあなたを大いに優遇しようと思った。しかし、主はその優遇をあなたに得させないようにされました」。</span>
<span className="v" id="v12" data-v="12" data-xref="民数記 22:18; 民数記 22:38"> バラムはバラクに言った、「わたしはあなたがつかわされた使者たちに言ったではありませんか、</span>
<span className="v" id="v13" data-v="13" data-xref="民数記 16:28; 民数記 22:18; 民数記 22:20"> 『たといバラクがその家に満ちるほどの金銀をわたしに与えようとも、主の言葉を越えて心のままに善も悪も行うことはできません。わたしは主の言われることを述べるだけです』。</span>
<span className="v" id="v14" data-v="14" data-xref="ミカ書 6:5; ヨハネの黙示録 2:14; 創世記 49:1"> わたしは今わたしの民のところへ帰って行きます。それでわたしはこの民が後の日にあなたの民にどんなことをするかをお知らせしましょう」。</span>
<span className="v" id="v15" data-v="15" data-xref="民数記 24:3–4; 民数記 23:7; マタイによる福音書 13:35"> そしてこの託宣を述べた。<br /><span className="pl pl-1">「ベオルの子バラムの言葉、</span><br /><span className="pl pl-1">目を閉じた人の言葉。</span></span>
<span className="v" id="v16" data-v="16" data-xref="民数記 24:4; コリント人への第一の手紙 8:1; サムエル記下 23:1–2"> <span className="pl pl-1">神の言葉を聞く者、</span><br /><span className="pl pl-1">いと高き者の知識をもつ者、</span><br /><span className="pl pl-1">全能者の幻を見、</span><br /><span className="pl pl-1">倒れ伏して、目の開かれた者の言葉。</span></span>
<span className="v" id="v17" data-v="17" data-xref="ヨハネの黙示録 22:16; ルカによる福音書 1:32–33; 創世記 49:10"> <span className="pl pl-1">わたしは彼を見る、しかし今ではない。</span><br /><span className="pl pl-1">わたしは彼を望み見る、しかし近くではない。</span><br /><span className="pl pl-1">ヤコブから一つの星が出、</span><br /><span className="pl pl-1">イスラエルから一本のつえが起り、</span><br /><span className="pl pl-1">モアブのこめかみと、</span><br /><span className="pl pl-1">セツのすべての子らの脳天を撃つであろう。</span></span>
<span className="v" id="v18" data-v="18" data-xref="アモス書 9:12; 創世記 27:29; サムエル記下 8:14"> <span className="pl pl-1">敵のエドムは領地となり、</span><br /><span className="pl pl-1">セイルもまた領地となるであろう。</span><br /><span className="pl pl-1">そしてイスラエルは勝利を得るであろう。</span></span>
<span className="v" id="v19" data-v="19" data-xref="創世記 49:10; ミカ書 5:2; 詩篇 2:1–12"> <span className="pl pl-1">権を執る者がヤコブから出、</span><br /><span className="pl pl-1">生き残った者を町から断ち滅ぼすであろう」。</span></span>
<span className="v" id="v20" data-v="20" data-xref="出エジプト記 17:14; 士師記 6:3; 歴代志上 4:43"> <span className="pl pl-1">バラムはまたアマレクを望み見て、この託宣を述べた。</span><br /><span className="pl pl-1">「アマレクは諸国民のうちの最初のもの、</span><br /><span className="pl pl-1">しかし、ついに滅び去るであろう」。</span></span>
<span className="v" id="v21" data-v="21" data-xref="創世記 15:19; 士師記 1:16; ヨブ記 29:18"> <span className="pl pl-1">またケニびとを望み見てこの託宣を述べた。</span><br /><span className="pl pl-1">「お前のすみかは堅固だ、</span><br /><span className="pl pl-1">岩に、お前は巣をつくっている。</span></span>
<span className="v" id="v22" data-v="22" data-xref="詩篇 83:8; 創世記 10:22; エズラ記 4:2"> <span className="pl pl-1">しかし、カインは滅ぼされるであろう。</span><br /><span className="pl pl-1">アシュルはいつまでお前を捕虜とするであろうか」。</span></span>

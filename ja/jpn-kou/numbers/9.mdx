<span className="v" id="v1" data-v="1" data-xref="民数記 1:1; 出エジプト記 40:2"> エジプトの国を出た次の年の正月、主はシナイの荒野でモーセに言われた、</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 16:1–2; コリント人への第一の手紙 5:7–8; 歴代志下 35:1"> 「イスラエルの人々に、過越の祭を定めの時に行わせなさい。</span>
<span className="v" id="v3" data-v="3" data-xref="出エジプト記 12:6–11; レビ記 23:5; 歴代志下 30:2"> この月の十四日の夕暮、定めの時に、それを行わなければならない。あなたがたは、そのすべての定めと、そのすべてのおきてにしたがって、それを行わなければならない」。</span>
<span className="v" id="v4" data-v="4"> そこでモーセがイスラエルの人々に、過越の祭を行わなければならないと言ったので、</span>
<span className="v" id="v5" data-v="5" data-xref="ヨシュア記 5:10; マタイによる福音書 28:20; 出エジプト記 12:1–13"> 彼らは正月の十四日の夕暮、シナイの荒野で過越の祭を行った。すなわち、イスラエルの人々は、すべて主がモーセに命じられたようにおこなった。</span>
<span className="v" id="v6" data-v="6" data-xref="民数記 27:2; 出エジプト記 18:15; 民数記 5:2"> ところが人の死体に触れて身を汚したために、その日に過越の祭を行うことのできない人々があって、その日モーセとアロンの前にきて、</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 16:2; コリント人への第一の手紙 5:7–8; 出エジプト記 12:27"> その人々は彼に言った、「わたしたちは人の死体に触れて身を汚しましたが、なぜその定めの時に、イスラエルの人々と共に、主に供え物をささげることができないのですか」。</span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 85:8; 民数記 27:5; コリント人への第一の手紙 4:4"> モーセは彼らに言った、「しばらく待て。主があなたがたについて、どう仰せになるかを聞こう」。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9"> 主はモーセに言われた、</span>
<span className="v" id="v10" data-v="10" data-xref="エペソ人への手紙 2:1–2; エペソ人への手紙 2:12–13; コリント人への第一の手紙 11:28"> 「イスラエルの人々に言いなさい、『あなたがたのうち、また、あなたがたの子孫のうち、死体に触れて身を汚した人も、遠い旅路にある人も、なお、過越の祭を主に対して行うことができるであろう。</span>
<span className="v" id="v11" data-v="11" data-xref="歴代志下 30:2–15; 出エジプト記 12:43–49; ヨハネによる福音書 19:36"> すなわち、二月の十四日の夕暮、それを行い、種入れぬパンと苦菜を添えて、それを食べなければならない。</span>
<span className="v" id="v12" data-v="12" data-xref="ヨハネによる福音書 19:36; 出エジプト記 12:46; 出エジプト記 12:10"> これを少しでも朝まで残しておいてはならない。またその骨は一本でも折ってはならない。過越の祭のすべての定めにしたがってこれを行わなければならない。</span>
<span className="v" id="v13" data-v="13" data-xref="創世記 17:14; 出エジプト記 12:15; 民数記 9:7"> しかし、その身は清く、旅に出てもいないのに、過越の祭を行わないときは、その人は民のうちから断たれるであろう。このような人は、定めの時に主の供え物をささげないゆえ、その罪を負わなければならない。</span>
<span className="v" id="v14" data-v="14" data-xref="出エジプト記 12:48–49; レビ記 24:22; イザヤ書 56:3–7"> もし他国の人が、あなたがたのうちに寄留していて、主に対して過越の祭を行おうとするならば、過越の祭の定めにより、そのおきてにしたがって、これを行わなければならない。あなたがたは他国の人にも、自国の人にも、同一の定めを用いなければならない』」。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="出エジプト記 13:21; 出エジプト記 40:34; ネヘミヤ書 9:19"> 幕屋を建てた日に、雲は幕屋をおおった。すれはすなわち、あかしの幕屋であって、夕には、幕屋の上に、雲は火のように見えて、朝にまで及んだ。</span>
<span className="v" id="v16" data-v="16" data-xref="ネヘミヤ書 9:12; 出エジプト記 40:38; コリント人への第一の手紙 10:1"> 常にそうであって、昼は雲がそれをおおい、夜は火のように見えた。</span>
<span className="v" id="v17" data-v="17" data-xref="出エジプト記 40:36–38; 詩篇 32:8; ヨハネによる福音書 10:9"> 雲が幕屋を離れてのぼる時は、イスラエルの人々は、ただちに道に進んだ。また雲がとどまる所に、イスラエルの人々は宿営した。</span>
<span className="v" id="v18" data-v="18" data-xref="コリント人への第一の手紙 10:1; ヨハネの第二の手紙 1:6; 出エジプト記 17:1"> すなわち、イスラエルの人々は、主の命によって道に進み、主の命によって宿営し、幕屋の上に雲がとどまっている間は、宿営していた。</span>
<span className="v" id="v19" data-v="19" data-xref="ゼカリヤ書 3:7; 民数記 1:52–53; 民数記 3:8"> 幕屋の上に、日久しく雲のとどまる時は、イスラエルの人々は主の言いつけを守って、道に進まなかった。</span>
<span className="v" id="v20" data-v="20"> また幕屋の上に、雲のとどまる日の少ない時もあったが、彼らは、ただ主の命にしたがって宿営し、主の命にしたがって、道に進んだ。</span>
<span className="v" id="v21" data-v="21" data-xref="ネヘミヤ書 9:19; ネヘミヤ書 9:12"> また雲は夕から朝まで、とどまることもあったが、朝になって、雲がのぼる時は、彼らは道に進んだ。また昼でも夜でも、雲がのぼる時は、彼らは道に進んだ。</span>
<span className="v" id="v22" data-v="22" data-xref="詩篇 32:8; 出エジプト記 40:36–37; 出エジプト記 40:16"> ふつかでも、一か月でも、あるいはそれ以上でも、幕屋の上に、雲がとどまっている間は、イスラエルの人々は宿営していて、道に進まなかったが、それがのぼると道に進んだ。</span>
<span className="v" id="v23" data-v="23" data-xref="ヨシュア記 22:3; 民数記 9:19; 創世記 26:5"> すなわち、彼らは主の命にしたがって宿営し、主の命にしたがって道に進み、モーセによって、主が命じられたとおりに、主の言いつけを守った。</span>

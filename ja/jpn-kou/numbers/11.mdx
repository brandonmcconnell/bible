<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数記 21:5; 民数記 16:35; 列王紀下 1:12"> さて、民は災難に会っている人のように、主の耳につぶやいた。主はこれを聞いて怒りを発せられ、主の火が彼らのうちに燃えあがって、宿営の端を焼いた。</span>
<span className="v" id="v2" data-v="2" data-xref="民数記 21:7; ヤコブの手紙 5:16; 民数記 16:45–48"> そこで民はモーセにむかって叫んだ。モーセが主に祈ったので、その火はしずまった。</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 9:22"> 主の火が彼らのうちに燃えあがったことによって、その所の名はタベラと呼ばれた。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="コリント人への第一の手紙 10:6; 出エジプト記 12:38; 詩篇 106:14"> また彼らのうちにいた多くの寄り集まりびとは欲心を起し、イスラエルの人々もまた再び泣いて言った、「ああ、肉が食べたい。</span>
<span className="v" id="v5" data-v="5" data-xref="出エジプト記 16:3; 詩篇 17:14; ピリピ人への手紙 3:19"> われわれは思い起すが、エジプトでは、ただで、魚を食べた。きゅうりも、すいかも、にらも、たまねぎも、そして、にんにくも。</span>
<span className="v" id="v6" data-v="6" data-xref="民数記 21:5; サムエル記下 13:4"> しかし、いま、われわれの精根は尽きた。われわれの目の前には、このマナのほか何もない」。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="出エジプト記 16:31; 創世記 2:12; 出エジプト記 16:14–15"> マナは、こえんどろの実のようで、色はブドラクの色のようであった。</span>
<span className="v" id="v8" data-v="8" data-xref="出エジプト記 16:31; 出エジプト記 16:16–18; 出エジプト記 16:23"> 民は歩きまわって、これを集め、ひきうすでひき、または、うすでつき、かまで煮て、これをもちとした。その味は油菓子の味のようであった。</span>
<span className="v" id="v9" data-v="9" data-xref="出エジプト記 16:13–14; 詩篇 78:23–25; 申命記 32:2"> 夜、宿営の露がおりるとき、マナはそれと共に降った。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="詩篇 78:21; 民数記 16:27; 民数記 14:1–2"> モーセは、民が家ごとに、おのおのその天幕の入口で泣くのを聞いた。そこで主は激しく怒られ、またモーセは不快に思った。</span>
<span className="v" id="v11" data-v="11" data-xref="申命記 1:12; 出エジプト記 5:22; エレミヤ書 15:10"> そして、モーセは主に言った、「あなたはなぜ、しもべに悪い仕打ちをされるのですか。どうしてわたしはあなたの前に恵みを得ないで、このすべての民の重荷を負わされるのですか。</span>
<span className="v" id="v12" data-v="12" data-xref="イザヤ書 49:23; イザヤ書 40:11; テサロニケ人への第一の手紙 2:7"> わたしがこのすべての民を、はらんだのですか。わたしがこれを生んだのですか。そうではないのに、あなたはなぜわたしに『養い親が乳児を抱くように、彼らをふところに抱いて、あなたが彼らの先祖たちに誓われた地に行け』と言われるのですか。</span>
<span className="v" id="v13" data-v="13" data-xref="マタイによる福音書 15:33; マルコによる福音書 8:4; ヨハネによる福音書 6:5–9"> わたしはどこから肉を獲て、このすべての民に与えることができましょうか。彼らは泣いて、『肉を食べさせよ』とわたしに言っているのです。</span>
<span className="v" id="v14" data-v="14" data-xref="出エジプト記 18:18; 申命記 1:9–12; コリント人への第二の手紙 2:16"> わたしひとりでは、このすべての民を負うことができません。それはわたしには重過ぎます。</span>
<span className="v" id="v15" data-v="15" data-xref="ピリピ人への手紙 1:20–24; 列王紀上 19:4; ヨナ書 4:3"> もしわたしがあなたの前に恵みを得ますならば、わたしにこのような仕打ちをされるよりは、むしろ、ひと思いに殺し、このうえ苦しみに会わせないでください」。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="出エジプト記 24:1; 出エジプト記 24:9; 申命記 16:18"> 主はモーセに言われた、「イスラエルの長老たちのうち、民の長老となり、つかさとなるべきことを、あなたが知っている者七十人をわたしのもとに集め、会見の幕屋に連れてきて、そこにあなたと共に立たせなさい。</span>
<span className="v" id="v17" data-v="17" data-xref="民数記 11:25; サムエル記上 10:6; コリント人への第一の手紙 12:4–11"> わたしは下って、その所で、あなたと語り、またわたしはあなたの上にある霊を、彼らにも分け与えるであろう。彼らはあなたと共に、民の重荷を負い、あなたが、ただひとりで、それを負うことのないようにするであろう。</span>
<span className="v" id="v18" data-v="18" data-xref="出エジプト記 19:10; 使徒行伝 7:39; 出エジプト記 16:3–7"> あなたはまた民に言いなさい、『あなたがたは身を清めて、あすを待ちなさい。あなたがたは肉を食べることができるであろう。あなたがたが泣いて主の耳に、わたしたちは肉が食べたい。エジプトにいた時は良かったと言ったからである。それゆえ、主はあなたがたに肉を与えて食べさせられるであろう。</span>
<span className="v" id="v19" data-v="19"> あなたがたがそれを食べるのは、一日や二日や五日や十日や二十日ではなく、</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 106:15; 民数記 21:5; 詩篇 78:27–30"> 一か月に及び、ついにあなたがたの鼻から出るようになり、あなたがたは、それに飽き果てるであろう。それはあなたがたのうちにおられる主を軽んじて、その前に泣き、なぜ、わたしたちはエジプトから出てきたのだろうと言ったからである』」。</span>
<span className="v" id="v21" data-v="21" data-xref="出エジプト記 12:37; 民数記 1:46; 創世記 12:2"> モーセは言った、「わたしと共におる民は徒歩の男子だけでも六十万です。ところがあなたは、『わたしは彼らに肉を与えて一か月のあいだ食べさせよう』と言われます。</span>
<span className="v" id="v22" data-v="22" data-xref="マタイによる福音書 15:33; 列王紀下 7:2; ヨハネによる福音書 6:9"> 羊と牛の群れを彼らのためにほふって、彼らを飽きさせるというのですか。海のすべての魚を彼らのために集めて、彼らを飽きさせるというのですか」。</span>
<span className="v" id="v23" data-v="23" data-xref="イザヤ書 59:1; イザヤ書 50:2; 創世記 18:14"> 主はモーセに言われた、「主の手は短かろうか。あなたは、いま、わたしの言葉の成るかどうかを見るであろう」。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="民数記 11:16; 民数記 11:26"> この時モーセは出て、主の言葉を民に告げ、民の長老たち七十人を集めて、幕屋の周囲に立たせた。</span>
<span className="v" id="v25" data-v="25" data-xref="民数記 11:17; ヨエル書 2:28–29; サムエル記上 10:10"> 主は雲のうちにあって下り、モーセと語られ、モーセの上にある霊を、その七十人の長老たちにも分け与えられた。その霊が彼らの上にとどまった時、彼らは預言した。ただし、その後は重ねて預言しなかった。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="エレミヤ書 36:5; サムエル記上 20:26; サムエル記上 10:22"> その時ふたりの者が、宿営にとどまっていたが、ひとりの名はエルダデと言い、ひとりの名はメダデといった。彼らの上にも霊がとどまった。彼らは名をしるされた者であったが、幕屋に行かなかったので、宿営のうちで預言した。</span>
<span className="v" id="v27" data-v="27"> 時にひとりの若者が走ってきて、モーセに告げて言った、「エルダデとメダデとが宿営のうちで預言しています」。</span>
<span className="v" id="v28" data-v="28" data-xref="マルコによる福音書 9:38–40; ルカによる福音書 9:49–50; ヨハネによる福音書 3:26"> 若い時からモーセの従者であったヌンの子ヨシュアは答えて言った、「わが主、モーセよ、彼らをさし止めてください」。</span>
<span className="v" id="v29" data-v="29" data-xref="コリント人への第一の手紙 14:5; マタイによる福音書 9:37–38; ルカによる福音書 10:2"> モーセは彼に言った、「あなたは、わたしのためを思って、ねたみを起しているのか。主の民がみな預言者となり、主がその霊を彼らに与えられることは、願わしいことだ」。</span>
<span className="v" id="v30" data-v="30"> こうしてモーセはイスラエルの長老たちと共に、宿営に引きあげた。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="出エジプト記 16:13; 詩篇 105:40; 詩篇 78:26–29"> さて、主のもとから風が起り、海の向こうから、うずらを運んできて、これを宿営の近くに落した。その落ちた範囲は、宿営の周囲で、こちら側も、おおよそ一日の行程、あちら側も、おおよそ一日の行程、地面から高さおおよそ二キュビトであった。</span>
<span className="v" id="v32" data-v="32" data-xref="エゼキエル書 45:11; 出エジプト記 16:36"> そこで民は立ち上がってその日は終日、その夜は終夜、またその次の日も終日、うずらを集めたが、集める事の最も少ない者も、十ホメルほど集めた。彼らはみな、それを宿営の周囲に広げておいた。</span>
<span className="v" id="v33" data-v="33" data-xref="詩篇 78:30–31; 詩篇 106:14–15; 民数記 25:9"> その肉がなお、彼らの歯の間にあって食べつくさないうちに、主は民にむかって怒りを発し、主は非常に激しい疫病をもって民を撃たれた。</span>
<span className="v" id="v34" data-v="34" data-xref="申命記 9:22; コリント人への第一の手紙 10:6; 民数記 33:16"> これによって、その所の名はキブロテ・ハッタワと呼ばれた。欲心を起した民を、そこに埋めたからである。</span>
<span className="v" id="v35" data-v="35" data-xref="民数記 33:17; 民数記 12:16; 申命記 1:1"> キブロテ・ハッタワから、民はハゼロテに進み、ハゼロテにとどまった。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 主はモーセに言われた、</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 1:22–25; 民数記 32:8; 民数記 34:18"> 「人をつかわして、わたしがイスラエルの人々に与えるカナンの地を探らせなさい。すなわち、その父祖の部族ごとに、すべて彼らのうちのつかさたる者ひとりずつをつかわしなさい」。</span>
<span className="v" id="v3" data-v="3" data-xref="民数記 12:16; 民数記 32:8; 申命記 1:19"> モーセは主の命にしたがって、パランの荒野から彼らをつかわした。その人々はみなイスラエルの人々のかしらたちであった。</span>
<span className="v" id="v4" data-v="4"> 彼らの名は次のとおりである。ルベンの部族ではザックルの子シャンマ、</span>
<span className="v" id="v5" data-v="5"> シメオンの部族ではホリの子シャパテ、</span>
<span className="v" id="v6" data-v="6" data-xref="民数記 34:19; 民数記 14:6; 民数記 13:30"> ユダの部族ではエフンネの子カレブ、</span>
<span className="v" id="v7" data-v="7"> イッサカルの部族ではヨセフの子イガル、</span>
<span className="v" id="v8" data-v="8" data-xref="出エジプト記 24:13; 民数記 11:28; 民数記 13:16"> エフライムの部族ではヌンの子ホセア、</span>
<span className="v" id="v9" data-v="9"> ベニヤミンの部族ではラフの子パルテ、</span>
<span className="v" id="v10" data-v="10"> ゼブルンの部族ではソデの子ガデエル、</span>
<span className="v" id="v11" data-v="11"> ヨセフの部族すなわち、マナセの部族ではスシの子ガデ、</span>
<span className="v" id="v12" data-v="12"> ダンの部族ではゲマリの子アンミエル、</span>
<span className="v" id="v13" data-v="13"> アセルの部族ではミカエルの子セトル、</span>
<span className="v" id="v14" data-v="14"> ナフタリの部族ではワフシの子ナヘビ、</span>
<span className="v" id="v15" data-v="15"> ガドの部族ではマキの子ギウエル。</span>
<span className="v" id="v16" data-v="16" data-xref="民数記 13:8; 出エジプト記 17:9; 民数記 14:6"> 以上はモーセがその地を探らせるためにつかわした人々の名である。そしてモーセはヌンの子ホセアをヨシュアと名づけた。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="士師記 1:9; 創世記 12:9; 士師記 1:19"> モーセは彼らをつかわし、カナンの地を探らせようとして、これに言った、「あなたがたはネゲブに行って、山に登り、</span>
<span className="v" id="v18" data-v="18" data-xref="エゼキエル書 34:14; 出エジプト記 3:8"> その地の様子を見、そこに住む民は、強いか弱いか、少ないか多いか、</span>
<span className="v" id="v19" data-v="19"> また彼らの住んでいる地は、良いか悪いか。人々の住んでいる町々は、天幕か、城壁のある町か、</span>
<span className="v" id="v20" data-v="20" data-xref="申命記 31:23; 申命記 31:6–8; エゼキエル書 34:14"> その地は、肥えているか、やせているか、そこには、木があるかないかを見なさい。あなたがたは、勇んで行って、その地のくだものを取ってきなさい」。時は、ぶどうの熟し始める季節であった。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="民数記 20:1; 民数記 33:36; 民数記 27:14"> そこで、彼らはのぼっていって、その地をチンの荒野からハマテの入口に近いレホブまで探った。</span>
<span className="v" id="v22" data-v="22" data-xref="詩篇 78:12; 詩篇 78:43; イザヤ書 19:11"> 彼らはネゲブにのぼって、ヘブロンまで行った。そこにはアナクの子孫であるアヒマン、セシャイ、およびタルマイがいた。ヘブロンはエジプトのゾアンよりも七年前に建てられたものである。</span>
<span className="v" id="v23" data-v="23" data-xref="民数記 13:24; 民数記 32:9; 申命記 1:24–25"> ついに彼らはエシコルの谷に行って、そこで一ふさのぶどうの枝を切り取り、これを棒をもって、ふたりでかつぎ、また、ざくろといちじくをも取った。</span>
<span className="v" id="v24" data-v="24"> イスラエルの人々が、そこで切り取ったぶどうの一ふさにちなんで、その所はエシコルの谷と呼ばれた。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="出エジプト記 34:28; 出エジプト記 24:18; 民数記 14:33–34"> 四十日の後、彼らはその地を探り終って帰ってきた。</span>
<span className="v" id="v26" data-v="26" data-xref="民数記 32:8; 民数記 20:1; 申命記 1:19"> そして、パランの荒野にあるカデシにいたモーセとアロン、およびイスラエルの人々の全会衆のもとに行って、彼らと全会衆とに復命し、その地のくだものを彼らに見せた。</span>
<span className="v" id="v27" data-v="27" data-xref="出エジプト記 3:8; 出エジプト記 3:17; 出エジプト記 13:5"> 彼らはモーセに言った、「わたしたちはあなたが、つかわした地へ行きました。そこはまことに乳と蜜の流れている地です。これはそのくだものです。</span>
<span className="v" id="v28" data-v="28" data-xref="申命記 9:1–2; 申命記 1:28; 民数記 13:33"> しかし、その地に住む民は強く、その町々は堅固で非常に大きく、わたしたちはそこにアナクの子孫がいるのを見ました。</span>
<span className="v" id="v29" data-v="29" data-xref="民数記 14:43; 士師記 6:3; 創世記 15:19–21"> またネゲブの地には、アマレクびとが住み、山地にはヘテびと、エブスびと、アモリびとが住み、海べとヨルダンの岸べには、カナンびとが住んでいます」。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="民数記 14:24; ローマ人への手紙 8:31; ピリピ人への手紙 4:13"> そのとき、カレブはモーセの前で、民をしずめて言った、「わたしたちはすぐにのぼって、攻め取りましょう。わたしたちは必ず勝つことができます」。</span>
<span className="v" id="v31" data-v="31" data-xref="申命記 1:28; ヨシュア記 14:8; ヘブル人への手紙 3:19"> しかし、彼とともにのぼって行った人々は言った、「わたしたちはその民のところへ攻めのぼることはできません。彼らはわたしたちよりも強いからです」。</span>
<span className="v" id="v32" data-v="32" data-xref="アモス書 2:9; 民数記 14:36–37; エゼキエル書 36:13–14"> そして彼らはその探った地のことを、イスラエルの人々に悪く言いふらして言った、「わたしたちが行き巡って探った地は、そこに住む者を滅ぼす地です。またその所でわたしたちが見た民はみな背の高い人々です。</span>
<span className="v" id="v33" data-v="33" data-xref="申命記 1:28; イザヤ書 40:22; 創世記 6:4"> わたしたちはまたそこで、ネピリムから出たアナクの子孫ネピリムを見ました。わたしたちには自分が、いなごのように思われ、また彼らにも、そう見えたに違いありません」。</span>
</div>

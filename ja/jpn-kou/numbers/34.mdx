<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 主はモーセに言われた、</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 17:8; 詩篇 105:11; 申命記 1:7–8"> 「イスラエルの人々に命じて言いなさい。あなたがたがカナンの地にはいるとき、あなたがたの嗣業となるべき地はカナンの地で、その全域は次のとおりである。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 14:3; エゼキエル書 47:13; ヨシュア記 3:16"> 南の方はエドムに接するチンの荒野に始まり、南の境は、東は塩の海の端に始まる。</span>
<span className="v" id="v4" data-v="4" data-xref="民数記 32:8; ヨシュア記 15:3–4; 民数記 13:26"> その境はアクラビムの坂の南を巡ってチンに向かい、カデシ・バルネアの南に至り、ハザル・アダルに進み、アズモンに及ぶ。</span>
<span className="v" id="v5" data-v="5" data-xref="ヨシュア記 15:4; 創世記 15:18; 列王紀上 8:65"> その境はまたアズモンから転じてエジプトの川に至り、海に及んで尽きる。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="ヨシュア記 1:4; エゼキエル書 47:20; エゼキエル書 47:15"> 西の境はおおうみとその沿岸で、これがあなたがたの西の境である。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="民数記 33:37; 民数記 34:6; 民数記 34:3"> あなたがたの北の境は次のとおりである。すなわちおおうみからホル山まで線を引き、</span>
<span className="v" id="v8" data-v="8" data-xref="民数記 13:21; 列王紀下 14:25; ヨシュア記 13:5–6"> ホル山からハマテの入口まで線を引き、その境をゼダデに至らせ、</span>
<span className="v" id="v9" data-v="9" data-xref="エゼキエル書 47:17"> またその境はジフロンに進み、ハザル・エノンに至って尽きる。これがあなたがたの北の境である。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10"> あなたがたの東の境は、ハザル・エノンからシパムまで線を引き、</span>
<span className="v" id="v11" data-v="11" data-xref="列王紀下 23:33; 申命記 3:17; ヨシュア記 11:2"> またその境はアインの東の方で、シパムからリブラに下り、またその境は下ってキンネレテの海の東の斜面に至り、</span>
<span className="v" id="v12" data-v="12" data-xref="民数記 34:3; 創世記 13:10; 創世記 19:24–26"> またその境はヨルダンに下り、塩の海に至って尽きる。あなたがたの国の周囲の境は以上のとおりである」。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="民数記 34:1; ヨシュア記 14:1–5"> モーセはイスラエルの人々に命じて言った、「これはあなたがたが、くじによって継ぐべき地である。主はこれを九つの部族と半部族とに与えよと命じられた。</span>
<span className="v" id="v14" data-v="14" data-xref="民数記 32:33; 民数記 32:23; ヨシュア記 14:2–3"> それはルベンの子孫の部族とガドの子孫の部族とが共に父祖の家にしたがって、すでにその嗣業を受け、またマナセの半部族もその嗣業を受けていたからである。</span>
<span className="v" id="v15" data-v="15" data-xref="民数記 32:32"> この二つの部族と半部族とはエリコに近いヨルダンのかなた、すなわち東の方、日の出る方で、その嗣業を受けた」。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16"> 主はまたモーセに言われた、</span>
<span className="v" id="v17" data-v="17" data-xref="ヨシュア記 14:1; ヨシュア記 19:51; 民数記 13:8"> 「あなたがたに、嗣業として地を分け与える人々の名は次のとおりである。すなわち祭司エレアザルと、ヌンの子ヨシュアとである。</span>
<span className="v" id="v18" data-v="18" data-xref="民数記 1:4–16"> あなたがたはまた、おのおの部族から、つかさひとりずつを選んで、地を分け与えさせなければならない。</span>
<span className="v" id="v19" data-v="19" data-xref="民数記 26:65; 民数記 13:30; 民数記 14:24"> その人々の名は次のとおりである。すなわちユダの部族ではエフンネの子カレブ、</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 49:5"> シメオンの子孫の部族ではアミホデの子サムエル、</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 49:27; 詩篇 68:27"> ベニヤミンの部族ではキスロンの子エリダデ、</span>
<span className="v" id="v22" data-v="22"> ダンの子孫の部族ではヨグリの子つかさブッキ、</span>
<span className="v" id="v23" data-v="23"> ヨセフの子孫、すなわちマナセの部族ではエポデの子つかさハニエル、</span>
<span className="v" id="v24" data-v="24"> エフライムの子孫の部族ではシフタンの子つかさケムエル、</span>
<span className="v" id="v25" data-v="25"> ゼブルンの子孫の部族ではパルナクの子つかさエリザパン、</span>
<span className="v" id="v26" data-v="26"> イッサカルの子孫の部族ではアザンの子つかさパルテエル、</span>
<span className="v" id="v27" data-v="27"> アセルの子孫の部族ではシロミの子つかさアヒウデ、</span>
<span className="v" id="v28" data-v="28"> ナフタリの子孫の部族では、アミホデの子つかさパダヘル。</span>
<span className="v" id="v29" data-v="29" data-xref="ヨシュア記 19:51; 民数記 34:18"> カナンの地でイスラエルの人々に嗣業を分け与えることを主が命じられた人々は以上のとおりである」。</span>
</div>

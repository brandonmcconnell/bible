<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数記 26:33; ガラテヤ人への手紙 3:28; 歴代志上 7:15"> さて、ヨセフの子マナセの氏族のうちのヘペルの子、ゼロペハデの娘たちが訴えてきた。ヘペルはギレアデの子、ギレアデはマキルの子、マキルはマナセの子である。その娘たちは名をマアラ、ノア、ホグラ、ミルカ、テルザといったが、</span>
<span className="v" id="v2" data-v="2" data-xref="民数記 15:33–34; 申命記 17:8–10; 出エジプト記 18:19–26"> 彼らは会見の幕屋の入口でモーセと、祭司エレアザルと、つかさたちと全会衆との前に立って言った、</span>
<span className="v" id="v3" data-v="3" data-xref="民数記 26:64–65; エゼキエル書 18:4; 民数記 14:35"> 「わたしたちの父は荒野で死にました。彼は、コラの仲間となって主に逆らった者どもの仲間のうちには加わりませんでした。彼は自分の罪によって死んだのですが、男の子がありませんでした。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨシュア記 17:4; 詩篇 109:13; 出エジプト記 32:11"> 男の子がないからといって、どうしてわたしたちの父の名がその氏族のうちから削られなければならないのでしょうか。わたしたちの父の兄弟と同じように、わたしたちにも所有地を与えてください」。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="レビ記 24:12–13; ヨブ記 23:4; 箴言 3:5–6"> モーセがその事を主の前に述べると、</span>
<span className="v" id="v6" data-v="6" data-xref="ガラテヤ人への手紙 3:28; 詩篇 68:5–6"> 主はモーセに言われた、</span>
<span className="v" id="v7" data-v="7" data-xref="ガラテヤ人への手紙 3:28; エレミヤ書 49:11; ヨシュア記 17:4"> 「ゼロペハデの娘たちの言うことは正しい。あなたは必ず彼らの父の兄弟たちと同じように、彼らにも嗣業の所有地を与えなければならない。すなわち、その父の嗣業を彼らに渡さなければならない。</span>
<span className="v" id="v8" data-v="8"> あなたはイスラエルの人々に言いなさい、『もし人が死んで、男の子がない時は、その嗣業を娘に渡さなければならない。</span>
<span className="v" id="v9" data-v="9"> もしまた娘もない時は、その嗣業を兄弟に与えなければならない。</span>
<span className="v" id="v10" data-v="10"> もし兄弟もない時は、その嗣業を父の兄弟に与えなければならない。</span>
<span className="v" id="v11" data-v="11" data-xref="民数記 35:29; ルツ記 4:3–6; エレミヤ書 32:8"> もしまた父に兄弟がない時は、その氏族のうちで彼に最も近い親族にその嗣業を与えて所有させなければならない』。主がモーセに命じられたようにイスラエルの人々は、これをおきての定めとしなければならない」。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="民数記 33:47–48; 申命記 34:1–4; 申命記 3:23–27"> 主はモーセに言われた、「このアバリムの山に登って、わたしがイスラエルの人々に与える地を見なさい。</span>
<span className="v" id="v13" data-v="13" data-xref="申命記 10:6; 民数記 31:2; 民数記 20:24–28"> あなたはそれを見てから、兄弟アロンのようにその民に加えられるであろう。</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 1:37; 民数記 20:8–13; 出エジプト記 17:7"> これは会衆がチンの荒野で逆らい争った時、あなたがたはわたしの命にそむき、あの水のかたわらで彼らの目の前にわたしの聖なることを現さなかったからである」。これはチンの荒野にあるカデシのメリバの水である。</span>
<span className="v" id="v15" data-v="15"> モーセは主に言った、</span>
<span className="v" id="v16" data-v="16" data-xref="民数記 16:22; エレミヤ書 3:15; ヘブル人への手紙 12:9"> 「すべての肉なるものの命の神、主よ、どうぞ、この会衆の上にひとりの人を立て、</span>
<span className="v" id="v17" data-v="17" data-xref="エゼキエル書 34:5; マルコによる福音書 6:34; 列王紀上 22:17"> 彼らの前に出入りし、彼らを導き出し、彼らを導き入れる者とし、主の会衆を牧者のない羊のようにしないでください」。</span>
<span className="v" id="v18" data-v="18" data-xref="申命記 34:9; 民数記 27:23; 創世記 41:38"> 主はモーセに言われた、「神の霊のやどっているヌンの子ヨシュアを選び、あなたの手をその上におき、</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 3:28; 申命記 31:7–8; 申命記 31:23"> 彼を祭司エレアザルと全会衆の前に立たせて、彼らの前で職に任じなさい。</span>
<span className="v" id="v20" data-v="20" data-xref="ヨシュア記 1:16–18; サムエル記上 10:9; 列王紀下 2:9–10"> そして彼にあなたの権威を分け与え、イスラエルの人々の全会衆を彼に従わせなさい。</span>
<span className="v" id="v21" data-v="21" data-xref="ヨシュア記 9:14; サムエル記上 28:6; 出エジプト記 28:30"> 彼は祭司エレアザルの前に立ち、エレアザルは彼のためにウリムをもって、主の前に判断を求めなければならない。ヨシュアとイスラエルの人々の全会衆とはエレアザルの言葉に従っていで、エレアザルの言葉に従ってはいらなければならない」。</span>
<span className="v" id="v22" data-v="22"> そこでモーセは主が命じられたようにし、ヨシュアを選んで、祭司エレアザルと全会衆の前に立たせ、</span>
<span className="v" id="v23" data-v="23" data-xref="申命記 3:28; 民数記 27:19; 申命記 31:7–8"> 彼の上に手をおき、主がモーセによって語られたとおりに彼を任命した。</span>
</div>

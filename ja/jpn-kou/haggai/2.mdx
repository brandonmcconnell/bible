<span className="v" id="v1" data-v="1" data-xref="ハガイ書 1:1; ハガイ書 2:20; ハガイ書 2:10"> ダリヨス王の二年の七月二十一日に、主の言葉が預言者ハガイに臨んだ、</span>
<span className="v" id="v2" data-v="2" data-xref="ハガイ書 1:1; ネヘミヤ書 8:9; エズラ記 2:63"> 「シャルテルの子、ユダの総督ゼルバベルと、ヨザダクの子、大祭司ヨシュア、および残りのすべての民に告げて言え、</span>
<span className="v" id="v3" data-v="3" data-xref="エズラ記 3:12; ハガイ書 2:9; エゼキエル書 7:20"> 『あなたがた残りの者のうち、以前の栄光に輝く主の家を見た者はだれか。あなたがたは今、この状態をどう思うか。これはあなたがたの目には、無にひとしいではないか。</span>
<span className="v" id="v4" data-v="4" data-xref="歴代志上 28:20; ヨシュア記 1:9; ゼカリヤ書 8:9"> 主は言われる、ゼルバベルよ、勇気を出せ。ヨザダクの子、大祭司ヨシュアよ、勇気を出せ。主は言われる。この地のすべての民よ、勇気を出せ。働け。わたしはあなたがたと共にいると、万軍の主は言われる。</span>
<span className="v" id="v5" data-v="5" data-xref="出エジプト記 34:10; 出エジプト記 29:45–46; イザヤ書 41:13"> これはあなたがたがエジプトから出た時、わたしがあなたがたに、約束した言葉である。わたしの霊が、あなたがたのうちに宿っている。恐れるな。</span>
<span className="v" id="v6" data-v="6" data-xref="ヘブル人への手紙 12:26–28; イザヤ書 10:25; マルコによる福音書 13:24–26"> 万軍の主はこう言われる、しばらくして、いま一度、わたしは天と、地と、海と、かわいた地とを震う。</span>
<span className="v" id="v7" data-v="7" data-xref="マラキ書 3:1; 列王紀上 8:11; ヨハネによる福音書 7:37–39"> わたしはまた万国民を震う。万国民の財宝は、はいって来て、わたしは栄光をこの家に満たすと、万軍の主は言われる。</span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 50:10–12; 詩篇 24:1; イザヤ書 60:17"> 銀はわたしのもの、金もわたしのものであると、万軍の主は言われる。</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 85:8–9; コリント人への第二の手紙 3:9–10; コロサイ人への手紙 1:19–21"> 主の家の後の栄光は、前の栄光よりも大きいと、万軍の主は言われる。わたしはこの所に繁栄を与えると、万軍の主は言われる』」。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="ハガイ書 2:20; ハガイ書 1:1; ハガイ書 1:15–1"> ダリヨスの二年の九月二十四日に、主の言葉が預言者ハガイに臨んだ、</span>
<span className="v" id="v11" data-v="11" data-xref="レビ記 10:10–11; マラキ書 2:7; 申命記 33:10"> 「万軍の主はこう言われる、律法について祭司たちに尋ねて言え、</span>
<span className="v" id="v12" data-v="12" data-xref="レビ記 6:27; マタイによる福音書 23:19; レビ記 7:6"> 『人がその衣服のすそで聖なる肉を運んで行き、そのすそがもし、パンまたはあつもの、または酒、または油、またはどんな食物にでもさわったなら、それらは聖なるものとなるか』と」。祭司たちは「ならない」と答えた。</span>
<span className="v" id="v13" data-v="13" data-xref="民数記 5:2–3; 民数記 19:11–22; レビ記 22:4–6"> ハガイはまた言った、「もし、死体によって汚れた人が、これらの一つにさわったなら、それは汚れるか」。祭司たちは「汚れる」と答えた。</span>
<span className="v" id="v14" data-v="14" data-xref="箴言 28:9; テトスヘの手紙 1:15; イザヤ書 1:11–15"> そこで、ハガイは言った、「主は言われる、この民も、この国も、わたしの前では、そのようである。またその手のわざもそのようである。その所で彼らのささげるものは、汚れたものである。</span>
<span className="v" id="v15" data-v="15" data-xref="ハガイ書 1:5; エズラ記 3:10; エズラ記 4:24"> 今、あなたがたはこの日から、後の事を思うがよい。主の宮で石の上に石が積まれなかった前、あなたがたは、どんなであったか。</span>
<span className="v" id="v16" data-v="16" data-xref="ハガイ書 1:6; マラキ書 2:2; 箴言 3:9–10"> あの時には、二十枡の麦の積まれる所に行ったが、わずかに十枡を得、また五十桶をくもうとして、酒ぶねに行ったが、二十桶を得たのみであった。</span>
<span className="v" id="v17" data-v="17" data-xref="申命記 28:22; ハガイ書 1:11; ハガイ書 1:9"> わたしは立ち枯れと、腐り穂と、ひょうをもってあなたがたと、あなたがたのすべての手のわざを撃った。しかし、あなたがたは、わたしに帰らなかったと主は言われる。</span>
<span className="v" id="v18" data-v="18" data-xref="ゼカリヤ書 8:9; ハガイ書 2:15; エズラ記 5:1–2"> あなたがたはこの日より後、すなわち、九月二十四日よりの事を思うがよい。また主の宮の基をすえた日から後の事を心にとめるがよい。</span>
<span className="v" id="v19" data-v="19" data-xref="マラキ書 3:10; ハバクク書 3:17–18; 箴言 3:9–10"> 種はなお、納屋にあるか。ぶどうの木、いちじくの木、ざくろの木、オリブの木もまだ実を結ばない。しかし、わたしはこの日から、あなたがたに恵みを与える」。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20"> この月の二十四日に、主の言葉がふたたびハガイに臨んだ、</span>
<span className="v" id="v21" data-v="21" data-xref="ゼカリヤ書 4:6–10; ハガイ書 2:6–7; ハガイ書 1:1"> 「ユダの総督ゼルバベルに告げて言え、わたしは天と地を震う。</span>
<span className="v" id="v22" data-v="22" data-xref="ミカ書 5:10; 士師記 7:22; ゼパニヤ書 3:8"> わたしは国々の王位を倒し、異邦の国々の力を滅ぼし、また戦車、およびこれに乗る者を倒す。馬およびこれに乗る者は、たがいにその仲間のつるぎによって倒れる。</span>
<span className="v" id="v23" data-v="23" data-xref="イザヤ書 43:10; イザヤ書 42:1; 雅歌 8:6"> 万軍の主は言われる、シャルテルの子、わがしもべゼルバベルよ、主は言われる、その日、わたしはあなたを立て、あなたを印章のようにする。わたしはあなたを選んだからであると、万軍の主は言われる」。</span>
</div>

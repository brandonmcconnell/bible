<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="ローマ人への手紙 15:1; コリント人への第一の手紙 8:7–13; コリント人への第一の手紙 9:22"> 信仰の弱い者を受けいれなさい。ただ、意見を批評するためであってはならない。</span>
<span className="v" id="v2" data-v="2" data-xref="テモテヘの第一の手紙 4:4; ローマ人への手紙 14:22–23; ローマ人への手紙 14:14"> ある人は、何を食べてもさしつかえないと信じているが、弱い人は野菜だけを食べる。</span>
<span className="v" id="v3" data-v="3" data-xref="ローマ人への手紙 14:10; コロサイ人への手紙 2:16–17; ルカによる福音書 18:9"> 食べる者は食べない者を軽んじてはならず、食べない者も食べる者をさばいてはならない。神は彼を受けいれて下さったのであるから。</span>
<span className="v" id="v4" data-v="4" data-xref="ヤコブの手紙 4:11–12; ローマ人への手紙 9:20; ローマ人への手紙 8:31–39"> 他人の僕をさばくあなたは、いったい、何者であるか。彼が立つのも倒れるのも、その主人によるのである。しかし、彼は立つようになる。主は彼を立たせることができるからである。</span>
<span className="v" id="v5" data-v="5" data-xref="コロサイ人への手紙 2:16–17; ローマ人への手紙 14:23; ガラテヤ人への手紙 4:9–10"> また、ある人は、この日がかの日よりも大事であると考え、ほかの人はどの日も同じだと考える。各自はそれぞれ心の中で、確信を持っておるべきである。</span>
<span className="v" id="v6" data-v="6" data-xref="コリント人への第一の手紙 10:30–31; テモテヘの第一の手紙 4:3–5; マタイによる福音書 14:19"> 日を重んじる者は、主のために重んじる。また食べる者も主のために食べる。神に感謝して食べるからである。食べない者も主のために食べない。そして、神に感謝する。</span>
<span className="v" id="v7" data-v="7" data-xref="ペテロの第一の手紙 4:2; コリント人への第二の手紙 5:15; コリント人への第一の手紙 6:19–20"> すなわち、わたしたちのうち、だれひとり自分のために生きる者はなく、だれひとり自分のために死ぬ者はない。</span>
<span className="v" id="v8" data-v="8" data-xref="ピリピ人への手紙 1:20; テサロニケ人への第一の手紙 5:10; コリント人への第一の手紙 15:23"> わたしたちは、生きるのも主のために生き、死ぬのも主のために死ぬ。だから、生きるにしても死ぬにしても、わたしたちは主のものなのである。</span>
<span className="v" id="v9" data-v="9" data-xref="ヨハネの黙示録 1:18; ルカによる福音書 24:26; ヘブル人への手紙 12:2"> なぜなら、キリストは、死者と生者との主となるために、死んで生き返られたからである。</span>
<span className="v" id="v10" data-v="10" data-xref="コリント人への第二の手紙 5:10; コリント人への第一の手紙 4:5; 伝道の書 12:14"> それだのに、あなたは、なぜ兄弟をさばくのか。あなたは、なぜ兄弟を軽んじるのか。わたしたちはみな、神のさばきの座の前に立つのである。</span>
<span className="v" id="v11" data-v="11" data-xref="イザヤ書 45:22–25; ピリピ人への手紙 2:10–11; 詩篇 72:11"> すなわち、<br /><span className="pl pl-1">「主が言われる。わたしは生きている。</span><br /><span className="pl pl-1">すべてのひざは、わたしに対してかがみ、</span><br /><span className="pl pl-1">すべての舌は、神にさんびをささげるであろう」</span><br />と書いてある。</span>
<span className="v" id="v12" data-v="12" data-xref="ペテロの第一の手紙 4:5; マタイによる福音書 12:36; マタイによる福音書 16:27"> だから、わたしたちひとりびとりは、神に対して自分の言いひらきをすべきである。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="コリント人への第二の手紙 6:3; ヤコブの手紙 4:11; コリント人への第一の手紙 8:9–13"> それゆえ、今後わたしたちは、互にさばき合うことをやめよう。むしろ、あなたがたは、妨げとなる物や、つまずきとなる物を兄弟の前に置かないことに、決めるがよい。</span>
<span className="v" id="v14" data-v="14" data-xref="テトスヘの手紙 1:15; ローマ人への手紙 14:2; テモテヘの第一の手紙 4:4"> わたしは、主イエスにあって知りかつ確信している。それ自体、汚れているものは一つもない。ただ、それが汚れていると考える人にだけ、汚れているのである。</span>
<span className="v" id="v15" data-v="15" data-xref="コリント人への第一の手紙 8:11–12; ピリピ人への手紙 2:2–4; ガラテヤ人への手紙 5:13"> もし食物のゆえに兄弟を苦しめるなら、あなたは、もはや愛によって歩いているのではない。あなたの食物によって、兄弟を滅ぼしてはならない。キリストは彼のためにも、死なれたのである。</span>
<span className="v" id="v16" data-v="16" data-xref="ローマ人への手紙 12:17; テサロニケ人への第一の手紙 5:22; コリント人への第一の手紙 10:29–30"> それだから、あなたがたにとって良い事が、そしりの種にならぬようにしなさい。</span>
<span className="v" id="v17" data-v="17" data-xref="マタイによる福音書 6:33; ローマ人への手紙 15:13; コリント人への第一の手紙 4:20"> 神の国は飲食ではなく、義と、平和と、聖霊における喜びとである。</span>
<span className="v" id="v18" data-v="18" data-xref="コリント人への第二の手紙 8:21; コリント人への第二の手紙 5:11; ペテロの第一の手紙 2:20"> こうしてキリストに仕える者は、神に喜ばれ、かつ、人にも受けいれられるのである。</span>
<span className="v" id="v19" data-v="19" data-xref="エペソ人への手紙 4:29; ローマ人への手紙 12:18; 詩篇 34:14"> こういうわけで、平和に役立つことや、互の徳を高めることを、追い求めようではないか。</span>
<span className="v" id="v20" data-v="20" data-xref="ローマ人への手紙 14:14–15; マタイによる福音書 18:6; テトスヘの手紙 1:15"> 食物のことで、神のみわざを破壊してはならない。すべての物はきよい。ただ、それを食べて人をつまずかせる者には、悪となる。</span>
<span className="v" id="v21" data-v="21" data-xref="コリント人への第一の手紙 8:13; ローマ人への手紙 14:13; ローマ人への手紙 15:1–2"> 肉を食わず、酒を飲まず、そのほか兄弟をつまずかせないのは、良いことである。</span>
<span className="v" id="v22" data-v="22" data-xref="ヨハネの第一の手紙 3:21; ローマ人への手紙 14:5; ヤコブの手紙 3:13"> あなたの持っている信仰を、神のみまえに、自分自身に持っていなさい。自ら良いと定めたことについて、やましいと思わない人は、さいわいである。</span>
<span className="v" id="v23" data-v="23" data-xref="ヘブル人への手紙 11:6; テトスヘの手紙 1:15; コリント人への第一の手紙 11:29–31"> しかし、疑いながら食べる者は、信仰によらないから、罪に定められる。すべて信仰によらないことは、罪である。</span>

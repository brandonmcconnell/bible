<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ペテロの第一の手紙 2:5; ローマ人への手紙 6:13; ヘブル人への手紙 13:15–16"> 兄弟たちよ。そういうわけで、神のあわれみによってあなたがたに勧める。あなたがたのからだを、神に喜ばれる、生きた、聖なる供え物としてささげなさい。それが、あなたがたのなすべき霊的な礼拝である。</span>
<span className="v" id="v2" data-v="2" data-xref="ペテロの第一の手紙 1:14; エペソ人への手紙 4:22–24; コリント人への第二の手紙 5:17"> あなたがたは、この世と妥協してはならない。むしろ、心を新たにすることによって、造りかえられ、何が神の御旨であるか、何が善であって、神に喜ばれ、かつ全きことであるかを、わきまえ知るべきである。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="ガラテヤ人への手紙 6:3; ピリピ人への手紙 2:3–8; 箴言 26:12"> わたしは、自分に与えられた恵みによって、あなたがたひとりびとりに言う。思うべき限度を越えて思いあがることなく、むしろ、神が各自に分け与えられた信仰の量りにしたがって、慎み深く思うべきである。</span>
<span className="v" id="v4" data-v="4" data-xref="コリント人への第一の手紙 12:27; コリント人への第一の手紙 12:12–14; エペソ人への手紙 4:15–16"> なぜなら、一つのからだにたくさんの肢体があるが、それらの肢体がみな同じ働きをしてはいないように、</span>
<span className="v" id="v5" data-v="5" data-xref="コリント人への第一の手紙 12:20; コリント人への第一の手紙 10:17; コリント人への第一の手紙 12:27–28"> わたしたちも数は多いが、キリストにあって一つのからだであり、また各自は互に肢体だからである。</span>
<span className="v" id="v6" data-v="6" data-xref="ペテロの第一の手紙 4:10–11; コリント人への第一の手紙 7:7; コリント人への第一の手紙 12:28–31"> このように、わたしたちは与えられた恵みによって、それぞれ異なった賜物を持っているので、もし、それが預言であれば、信仰の程度に応じて預言をし、</span>
<span className="v" id="v7" data-v="7" data-xref="エペソ人への手紙 4:11; テモテヘの第二の手紙 4:2; 使徒行伝 13:1"> 奉仕であれば奉仕をし、また教える者であれば教え、</span>
<span className="v" id="v8" data-v="8" data-xref="コリント人への第二の手紙 9:7; テモテヘの第一の手紙 5:17; コリント人への第一の手紙 12:28"> 勧めをする者であれば勧め、寄附する者は惜しみなく寄附し、指導する者は熱心に指導し、慈善をする者は快く慈善をすべきである。</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 34:14; ペテロの第一の手紙 4:8; テモテヘの第一の手紙 1:5"> 愛には偽りがあってはならない。悪は憎み退け、善には親しみ結び、</span>
<span className="v" id="v10" data-v="10" data-xref="ピリピ人への手紙 2:3; ヨハネによる福音書 13:34–35; ヘブル人への手紙 13:1"> 兄弟の愛をもって互にいつくしみ、進んで互に尊敬し合いなさい。</span>
<span className="v" id="v11" data-v="11" data-xref="ヘブル人への手紙 6:10–11; 使徒行伝 18:25; ヨハネの黙示録 3:15–16"> 熱心で、うむことなく、霊に燃え、主に仕え、</span>
<span className="v" id="v12" data-v="12" data-xref="ローマ人への手紙 15:13; ヘブル人への手紙 10:36; 詩篇 62:8"> 望みをいだいて喜び、患難に耐え、常に祈りなさい。</span>
<span className="v" id="v13" data-v="13" data-xref="ヘブル人への手紙 13:16; コリント人への第二の手紙 9:12; ヨハネの第一の手紙 3:17"> 貧しい聖徒を助け、努めて旅人をもてなしなさい。</span>
<span className="v" id="v14" data-v="14" data-xref="ペテロの第一の手紙 3:9; マタイによる福音書 5:44; テサロニケ人への第一の手紙 5:15"> あなたがたを迫害する者を祝福しなさい。祝福して、のろってはならない。</span>
<span className="v" id="v15" data-v="15" data-xref="コリント人への第一の手紙 12:26; ヘブル人への手紙 13:3; 詩篇 35:13–14"> 喜ぶ者と共に喜び、泣く者と共に泣きなさい。</span>
<span className="v" id="v16" data-v="16" data-xref="ペテロの第一の手紙 3:8; 箴言 3:7; ヤコブの手紙 3:13–17"> 互に思うことをひとつにし、高ぶった思いをいだかず、かえって低い者たちと交わるがよい。自分が知者だと思いあがってはならない。</span>
<span className="v" id="v17" data-v="17" data-xref="箴言 20:22; テサロニケ人への第一の手紙 5:15; マタイによる福音書 5:39"> だれに対しても悪をもって悪に報いず、すべての人に対して善を図りなさい。</span>
<span className="v" id="v18" data-v="18" data-xref="ヘブル人への手紙 12:14; マタイによる福音書 5:9; ローマ人への手紙 14:19"> あなたがたは、できる限りすべての人と平和に過ごしなさい。</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 32:35; ヘブル人への手紙 10:30; 箴言 24:29"> 愛する者たちよ。自分で復讐をしないで、むしろ、神の怒りに任せなさい。なぜなら、「主が言われる。復讐はわたしのすることである。わたし自身が報復する」と書いてあるからである。</span>
<span className="v" id="v20" data-v="20" data-xref="箴言 25:21–22; マタイによる福音書 5:44; ルカによる福音書 6:27"> むしろ、「もしあなたの敵が飢えるなら、彼に食わせ、かわくなら、彼に飲ませなさい。そうすることによって、あなたは彼の頭に燃えさかる炭火を積むことになるのである」。</span>
<span className="v" id="v21" data-v="21" data-xref="ペテロの第一の手紙 3:9; ルカによる福音書 6:27–30; 箴言 16:32"> 悪に負けてはいけない。かえって、善をもって悪に勝ちなさい。</span>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行伝 18:18; ペテロの第一の手紙 1:22–23; テモテヘの第一の手紙 5:9–10"> ケンクレヤにある教会の執事、わたしたちの姉妹フィベを、あなたがたに紹介する。</span>
<span className="v" id="v2" data-v="2" data-xref="ピリピ人への手紙 2:29; ピリピ人への手紙 1:27; マタイによる福音書 10:40–42"> どうか、聖徒たるにふさわしく、主にあって彼女を迎え、そして、彼女があなたがたにしてもらいたいことがあれば、何事でも、助けてあげてほしい。彼女は多くの人の援助者であり、またわたし自身の援助者でもあった。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="コリント人への第一の手紙 16:19; テモテヘの第二の手紙 4:19; 使徒行伝 18:26"> キリスト・イエスにあるわたしの同労者プリスカとアクラとに、よろしく言ってほしい。</span>
<span className="v" id="v4" data-v="4" data-xref="ピリピ人への手紙 2:30; ヨハネの第一の手紙 3:16; コリント人への第一の手紙 16:1"> 彼らは、わたしのいのちを救うために、自分の首をさえ差し出してくれたのである。彼らに対しては、わたしだけではなく、異邦人のすべての教会も、感謝している。</span>
<span className="v" id="v5" data-v="5" data-xref="コロサイ人への手紙 4:15; ピレモンヘの手紙 1:2; コリント人への第一の手紙 16:19"> また、彼らの家の教会にも、よろしく。わたしの愛するエパネトに、よろしく言ってほしい。彼は、キリストにささげられたアジヤの初穂である。</span>
<span className="v" id="v6" data-v="6" data-xref="ローマ人への手紙 16:12; マタイによる福音書 27:55; テモテヘの第一の手紙 5:10"> あなたがたのために一方ならず労苦したマリヤに、よろしく言ってほしい。</span>
<span className="v" id="v7" data-v="7" data-xref="ローマ人への手紙 16:11; ローマ人への手紙 16:21; ピレモンヘの手紙 1:23"> わたしの同族であって、わたしと一緒に投獄されたことのあるアンデロニコとユニアスとに、よろしく。彼らは使徒たちの間で評判がよく、かつ、わたしよりも先にキリストを信じた人々である。</span>
<span className="v" id="v8" data-v="8" data-xref="ピリピ人への手紙 4:1; ヨハネの第一の手紙 3:14; ローマ人への手紙 16:5"> 主にあって愛するアムプリアトに、よろしく。</span>
<span className="v" id="v9" data-v="9" data-xref="ローマ人への手紙 16:2–3; ローマ人への手紙 16:21"> キリストにあるわたしたちの同労者ウルバノと、愛するスタキスとに、よろしく。</span>
<span className="v" id="v10" data-v="10" data-xref="ローマ人への手紙 14:18; ペテロの第一の手紙 1:7; 申命記 8:2"> キリストにあって錬達なアペレに、よろしく。アリストブロの家の人たちに、よろしく。</span>
<span className="v" id="v11" data-v="11" data-xref="ローマ人への手紙 16:21; ローマ人への手紙 16:7"> 同族のヘロデオンに、よろしく。ナルキソの家の、主にある人たちに、よろしく。</span>
<span className="v" id="v12" data-v="12" data-xref="テサロニケ人への第一の手紙 5:12–13; ヘブル人への手紙 6:10–11; コリント人への第一の手紙 15:58"> 主にあって労苦しているツルパナとツルポサとに、よろしく。主にあって一方ならず労苦した愛するペルシスに、よろしく。</span>
<span className="v" id="v13" data-v="13" data-xref="マルコによる福音書 15:21; テモテヘの第一の手紙 5:2; ヨハネの第二の手紙 1:1"> 主にあって選ばれたルポスと、彼の母とに、よろしく。彼の母は、わたしの母でもある。</span>
<span className="v" id="v14" data-v="14" data-xref="コロサイ人への手紙 1:2; ローマ人への手紙 8:29; ヘブル人への手紙 3:1"> アスンクリト、フレゴン、ヘルメス、パトロバ、ヘルマスおよび彼らと一緒にいる兄弟たちに、よろしく。</span>
<span className="v" id="v15" data-v="15" data-xref="ローマ人への手紙 16:2; ローマ人への手紙 1:7; ローマ人への手紙 16:14"> ピロロゴとユリヤとに、またネレオとその姉妹とに、オルンパに、また彼らと一緒にいるすべての聖徒たちに、よろしく言ってほしい。</span>
<span className="v" id="v16" data-v="16" data-xref="テサロニケ人への第一の手紙 5:26; コリント人への第一の手紙 16:20; コリント人への第二の手紙 13:12"> きよい接吻をもって、互にあいさつをかわしなさい。キリストのすべての教会から、あなたがたによろしく。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="ユダの手紙 1:19; テサロニケ人への第二の手紙 3:6; テモテヘの第一の手紙 6:3–5"> さて兄弟たちよ。あなたがたに勧告する。あなたがたが学んだ教にそむいて分裂を引き起し、つまずきを与える人々を警戒し、かつ彼らから遠ざかるがよい。</span>
<span className="v" id="v18" data-v="18" data-xref="コロサイ人への手紙 2:4; マタイによる福音書 7:15; テモテヘの第一の手紙 6:5"> なぜなら、こうした人々は、わたしたちの主キリストに仕えないで、自分の腹に仕え、そして甘言と美辞とをもって、純朴な人々の心を欺く者どもだからである。</span>
<span className="v" id="v19" data-v="19" data-xref="マタイによる福音書 10:16; コリント人への第一の手紙 14:20; ピリピ人への手紙 2:15"> あなたがたの従順は、すべての人々の耳に達しており、それをあなたがたのために喜んでいる。しかし、わたしの願うところは、あなたがたが善にさとく、悪には、うとくあってほしいことである。</span>
<span className="v" id="v20" data-v="20" data-xref="ルカによる福音書 10:19; ヨハネの第一の手紙 3:8; 創世記 3:15"> 平和の神は、サタンをすみやかにあなたがたの足の下に踏み砕くであろう。<br />どうか、わたしたちの主イエスの恵みが、あなたがたと共にあるように。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="使徒行伝 20:4; 使徒行伝 17:5; 使徒行伝 13:1"> わたしの同労者テモテおよび同族のルキオ、ヤソン、ソシパテロから、あなたがたによろしく。</span>
<span className="v" id="v22" data-v="22" data-xref="ガラテヤ人への手紙 6:11; コリント人への第一の手紙 16:21; ローマ人への手紙 16:8"> （この手紙を筆記したわたしテルテオも、主にあってあなたがたにあいさつの言葉をおくる。）</span>
<span className="v" id="v23" data-v="23" data-xref="コリント人への第一の手紙 1:14; 使徒行伝 19:22; テモテヘの第二の手紙 4:20"> わたしと全教会との家主ガイオから、あなたがたによろしく。市の会計係エラストと兄弟クワルトから、あなたがたによろしく。<br />〔</span>
<span className="v" id="v24" data-v="24"> わたしたちの主イエス・キリストの恵みが、あなたがた一同と共にあるように、アァメン。〕</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="コリント人への第一の手紙 2:7; ローマ人への手紙 2:16; コロサイ人への手紙 1:26–27"> 願わくは、わたしの福音とイエス・キリストの宣教とにより、かつ、長き世々にわたって、隠されていたが、今やあらわされ、預言の書をとおして、永遠の神の命令に従い、信仰の従順に至らせるために、もろもろの国人に告げ知らされた奥義の啓示によって、あなたがたを力づけることのできるかた、</span>
<span className="v" id="v27" data-v="27" data-xref="テモテヘの第一の手紙 1:17; ローマ人への手紙 11:36; ヨハネの黙示録 7:10–12"> すなわち、唯一の知恵深き神に、イエス・キリストにより、栄光が永遠より永遠にあるように、アァメン。</span>
</div>

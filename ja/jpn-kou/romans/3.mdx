<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="ローマ人への手紙 2:25–29; 創世記 25:32; 伝道の書 6:11"> では、ユダヤ人のすぐれている点は何か。また割礼の益は何か。</span>
<span className="v" id="v2" data-v="2" data-xref="ローマ人への手紙 9:4; 使徒行伝 7:38; コリント人への第一の手紙 9:17"> それは、いろいろの点で数多くある。まず第一に、神の言が彼らにゆだねられたことである。</span>
<span className="v" id="v3" data-v="3" data-xref="テモテヘの第二の手紙 2:13; ヘブル人への手紙 4:2; ローマ人への手紙 9:6"> すると、どうなるのか。もし、彼らのうちに不真実の者があったとしたら、その不真実によって、神の真実は無になるであろうか。</span>
<span className="v" id="v4" data-v="4" data-xref="詩篇 51:4; 詩篇 116:11; ガラテヤ人への手紙 2:17"> 断じてそうではない。あらゆる人を偽り者としても、神を真実なものとすべきである。それは、<br /><span className="pl pl-1">「あなたが言葉を述べるときは、義とせられ、</span><br /><span className="pl pl-1">あなたがさばきを受けるとき、勝利を得るため」</span><br />と書いてあるとおりである。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="ローマ人への手紙 6:19; ガラテヤ人への手紙 3:15; ローマ人への手紙 9:18–20"> しかし、もしわたしたちの不義が、神の義を明らかにするとしたら、なんと言うべきか。怒りを下す神は、不義であると言うのか（これは人間的な言い方ではある）。</span>
<span className="v" id="v6" data-v="6" data-xref="創世記 18:25; 使徒行伝 17:31; ヨブ記 8:3"> 断じてそうではない。もしそうであったら、神はこの世を、どうさばかれるだろうか。</span>
<span className="v" id="v7" data-v="7" data-xref="ローマ人への手紙 3:4; ローマ人への手紙 9:19–20; 使徒行伝 13:27–29"> しかし、もし神の真実が、わたしの偽りによりいっそう明らかにされて、神の栄光となるなら、どうして、わたしはなおも罪人としてさばかれるのだろうか。</span>
<span className="v" id="v8" data-v="8" data-xref="ローマ人への手紙 6:1; ローマ人への手紙 6:15; ローマ人への手紙 5:20"> むしろ、「善をきたらせるために、わたしたちは悪をしようではないか」（わたしたちがそう言っていると、ある人々はそしっている）。彼らが罰せられるのは当然である。</span>
</div>
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="ガラテヤ人への手紙 3:22; ローマ人への手紙 6:15; イザヤ書 65:5"> すると、どうなるのか。わたしたちには何かまさったところがあるのか。絶対にない。ユダヤ人もギリシヤ人も、ことごとく罪の下にあることを、わたしたちはすでに指摘した。</span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 53:1–3; 詩篇 14:1–3; ローマ人への手紙 3:23"> 次のように書いてある、<br /><span className="pl pl-1">「義人はいない、ひとりもいない。</span></span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 14:2–4; 詩篇 53:2; テトスヘの手紙 3:3"> <span className="pl pl-1">悟りのある人はいない、</span><br /><span className="pl pl-1">神を求める人はいない。</span></span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 14:3; 伝道の書 7:20; イザヤ書 64:6"> <span className="pl pl-1">すべての人は迷い出て、</span><br /><span className="pl pl-1">ことごとく無益なものになっている。</span><br /><span className="pl pl-1">善を行う者はいない、</span><br /><span className="pl pl-1">ひとりもいない。</span></span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 5:9; 詩篇 140:3; マタイによる福音書 23:27–28"> <span className="pl pl-1">彼らののどは、開いた墓であり、</span><br /><span className="pl pl-1">彼らは、その舌で人を欺き、</span><br /><span className="pl pl-1">彼らのくちびるには、まむしの毒があり、</span></span>
<span className="v" id="v14" data-v="14" data-xref="詩篇 10:7; 詩篇 109:17–18; 詩篇 59:12"> <span className="pl pl-1">彼らの口は、のろいと苦い言葉とで満ちている。</span></span>
<span className="v" id="v15" data-v="15" data-xref="イザヤ書 59:7–8; 箴言 1:16; 箴言 6:18"> <span className="pl pl-1">彼らの足は、血を流すのに速く、</span></span>
<span className="v" id="v16" data-v="16"> <span className="pl pl-1">彼らの道には、破壊と悲惨とがある。</span></span>
<span className="v" id="v17" data-v="17" data-xref="イザヤ書 59:8; ローマ人への手紙 5:1; ルカによる福音書 1:79"> <span className="pl pl-1">そして、彼らは平和の道を知らない。</span></span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="詩篇 36:1; 箴言 23:17; 箴言 16:6"> 彼らの目の前には、神に対する恐れがない」。</span>
<span className="v" id="v19" data-v="19" data-xref="ガラテヤ人への手紙 3:10; ガラテヤ人への手紙 3:22–23; ローマ人への手紙 2:12–18"> さて、わたしたちが知っているように、すべて律法の言うところは、律法のもとにある者たちに対して語られている。それは、すべての口がふさがれ、全世界が神のさばきに服するためである。</span>
<span className="v" id="v20" data-v="20" data-xref="ガラテヤ人への手紙 2:16; 使徒行伝 13:39; ローマ人への手紙 3:28"> なぜなら、律法を行うことによっては、すべての人間は神の前に義とせられないからである。律法によっては、罪の自覚が生じるのみである。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="使徒行伝 10:43; エレミヤ書 33:16; ピリピ人への手紙 3:9"> しかし今や、神の義が、律法とは別に、しかも律法と預言者とによってあかしされて、現された。</span>
<span className="v" id="v22" data-v="22" data-xref="ローマ人への手紙 10:12; ガラテヤ人への手紙 3:28; ローマ人への手紙 8:1"> それは、イエス・キリストを信じる信仰による神の義であって、すべて信じる人に与えられるものである。そこにはなんらの差別もない。</span>
<span className="v" id="v23" data-v="23" data-xref="伝道の書 7:20; ヨハネの第一の手紙 1:8–10; ローマ人への手紙 3:9"> すなわち、すべての人は罪を犯したため、神の栄光を受けられなくなっており、</span>
<span className="v" id="v24" data-v="24" data-xref="ペテロの第一の手紙 1:18–19; テトスヘの手紙 3:5–7; コロサイ人への手紙 1:14"> 彼らは、価なしに、神の恵みにより、キリスト・イエスによるあがないによって義とされるのである。</span>
<span className="v" id="v25" data-v="25" data-xref="ローマ人への手紙 3:23–24; ペテロの第一の手紙 1:18–20; ヨハネの第一の手紙 4:10"> 神はこのキリストを立てて、その血による、信仰をもって受くべきあがないの供え物とされた。それは神の義を示すためであった。すなわち、今までに犯された罪を、神は忍耐をもって見のがしておられたが、</span>
<span className="v" id="v26" data-v="26" data-xref="申命記 32:4; ローマ人への手紙 4:5; ローマ人への手紙 3:30"> それは、今の時に、神の義を示すためであった。こうして、神みずからが義となり、さらに、イエスを信じる者を義とされるのである。</span>
<span className="v" id="v27" data-v="27" data-xref="ローマ人への手紙 4:2; ローマ人への手紙 2:23; コリント人への第一の手紙 1:29–31"> すると、どこにわたしたちの誇があるのか。全くない。なんの法則によってか。行いの法則によってか。そうではなく、信仰の法則によってである。</span>
<span className="v" id="v28" data-v="28" data-xref="ガラテヤ人への手紙 2:16; ガラテヤ人への手紙 3:8; テトスヘの手紙 3:7"> わたしたちは、こう思う。人が義とされるのは、律法の行いによるのではなく、信仰によるのである。</span>
<span className="v" id="v29" data-v="29" data-xref="コロサイ人への手紙 3:11; エペソ人への手紙 3:6; ゼカリヤ書 2:11"> それとも、神はユダヤ人だけの神であろうか。また、異邦人の神であるのではないか。確かに、異邦人の神でもある。</span>
<span className="v" id="v30" data-v="30" data-xref="ガラテヤ人への手紙 3:8; ガラテヤ人への手紙 3:20; ピリピ人への手紙 3:3"> まことに、神は唯一であって、割礼のある者を信仰によって義とし、また、無割礼の者をも信仰のゆえに義とされるのである。</span>
<span className="v" id="v31" data-v="31" data-xref="ガラテヤ人への手紙 2:21; マタイによる福音書 5:17; ローマ人への手紙 13:8–10"> すると、信仰のゆえに、わたしたちは律法を無効にするのであるか。断じてそうではない。かえって、それによって律法を確立するのである。</span>
</div>

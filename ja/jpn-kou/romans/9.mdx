<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="テモテヘの第一の手紙 2:7; ローマ人への手紙 1:9; ガラテヤ人への手紙 1:20"> わたしはキリストにあって真実を語る。偽りは言わない。わたしの良心も聖霊によって、わたしにこうあかしをしている。</span>
<span className="v" id="v2" data-v="2" data-xref="ピリピ人への手紙 3:18; 詩篇 119:136; エレミヤ書 13:17"> すなわち、わたしに大きな悲しみがあり、わたしの心に絶えざる痛みがある。</span>
<span className="v" id="v3" data-v="3" data-xref="出エジプト記 32:32; エステル記 8:6; ローマ人への手紙 11:14"> 実際、わたしの兄弟、肉による同族のためなら、わたしのこの身がのろわれて、キリストから離されてもいとわない。</span>
<span className="v" id="v4" data-v="4" data-xref="エペソ人への手紙 2:12; 詩篇 147:19; ローマ人への手紙 9:6"> 彼らはイスラエル人であって、子たる身分を授けられることも、栄光も、もろもろの契約も、律法を授けられることも、礼拝も、数々の約束も彼らのもの、</span>
<span className="v" id="v5" data-v="5" data-xref="ヨハネによる福音書 10:30; ヨハネによる福音書 1:1–3; コロサイ人への手紙 1:16–19"> また父祖たちも彼らのものであり、肉によればキリストもまた彼らから出られたのである。万物の上にいます神は、永遠にほむべきかな、アァメン。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="ローマ人への手紙 2:28–29; ガラテヤ人への手紙 6:16; ローマ人への手紙 11:1–2"> しかし、神の言が無効になったというわけではない。なぜなら、イスラエルから出た者が全部イスラエルなのではなく、</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 21:12; ヘブル人への手紙 11:18; ヨハネによる福音書 8:37–39"> また、アブラハムの子孫だからといって、その全部が子であるのではないからである。かえって「イサクから出る者が、あなたの子孫と呼ばれるであろう」。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨハネによる福音書 1:13; ローマ人への手紙 4:11–16; ガラテヤ人への手紙 3:26–29"> すなわち、肉の子がそのまま神の子なのではなく、むしろ約束の子が子孫として認められるのである。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 18:10; 創世記 18:14; 創世記 17:21"> 約束の言葉はこうである。「来年の今ごろ、わたしはまた来る。そして、サラに男子が与えられるであろう」。</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 25:21–23; ルカによる福音書 16:26; ローマ人への手紙 5:11"> そればかりではなく、ひとりの人、すなわち、わたしたちの父祖イサクによって受胎したリベカの場合も、また同様である。</span>
<span className="v" id="v11" data-v="11" data-xref="テモテヘの第二の手紙 1:9; エペソ人への手紙 1:4–5; ペテロの第二の手紙 1:10"> まだ子供らが生れもせず、善も悪もしない先に、神の選びの計画が、</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 25:22–23; サムエル記下 8:14; 列王紀上 22:47"> わざによらず、召したかたによって行われるために、「兄は弟に仕えるであろう」と、彼女に仰せられたのである。</span>
<span className="v" id="v13" data-v="13" data-xref="マラキ書 1:2–3; 申命記 21:15; 創世記 29:33"> 「わたしはヤコブを愛しエサウを憎んだ」と書いてあるとおりである。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="歴代志下 19:7; 詩篇 145:17; 申命記 32:4"> では、わたしたちはなんと言おうか。神の側に不正があるのか。断じてそうではない。</span>
<span className="v" id="v15" data-v="15" data-xref="出エジプト記 33:19; ローマ人への手紙 9:16; ミカ書 7:18"> 神はモーセに言われた、「わたしは自分のあわれもうとする者をあわれみ、いつくしもうとする者を、いつくしむ」。</span>
<span className="v" id="v16" data-v="16" data-xref="エペソ人への手紙 2:8; マタイによる福音書 11:25–26; ペテロの第一の手紙 2:9–10"> ゆえに、それは人間の意志や努力によるのではなく、ただ神のあわれみによるのである。</span>
<span className="v" id="v17" data-v="17" data-xref="出エジプト記 9:16; 箴言 16:4; 出エジプト記 14:17–18"> 聖書はパロにこう言っている、「わたしがあなたを立てたのは、この事のためである。すなわち、あなたによってわたしの力をあらわし、また、わたしの名が全世界に言いひろめられるためである」。</span>
<span className="v" id="v18" data-v="18" data-xref="ヨシュア記 11:20; 出エジプト記 4:21; ローマ人への手紙 9:15–16"> だから、神はそのあわれもうと思う者をあわれみ、かたくなにしようと思う者を、かたくなになさるのである。</span>
</div>
<div className="bp poetry">
<span className="v" id="v19" data-v="19" data-xref="ダニエル書 4:35; 歴代志下 20:6; コリント人への第一の手紙 15:12"> そこで、あなたは言うであろう、「なぜ神は、なおも人を責められるのか。だれが、神の意図に逆らい得ようか」。</span>
<span className="v" id="v20" data-v="20" data-xref="イザヤ書 29:16; イザヤ書 45:9–11; イザヤ書 64:8"> ああ人よ。あなたは、神に言い逆らうとは、いったい、何者なのか。造られたものが造った者に向かって、「なぜ、わたしをこのように造ったのか」と言うことがあろうか。</span>
<span className="v" id="v21" data-v="21" data-xref="イザヤ書 64:8; 箴言 16:4; テモテヘの第二の手紙 2:20–21"> 陶器を造る者は、同じ土くれから、一つを尊い器に、他を卑しい器に造りあげる権能がないのであろうか。</span>
<span className="v" id="v22" data-v="22" data-xref="箴言 16:4; ユダの手紙 1:4; ローマ人への手紙 9:21"> もし、神が怒りをあらわし、かつ、ご自身の力を知らせようと思われつつも、滅びることになっている怒りの器を、大いなる寛容をもって忍ばれたとすれば、</span>
<span className="v" id="v23" data-v="23" data-xref="ローマ人への手紙 2:4; ペテロの第一の手紙 1:2–5; コロサイ人への手紙 1:27"> かつ、栄光にあずからせるために、あらかじめ用意されたあわれみの器にご自身の栄光の富を知らせようとされたとすれば、どうであろうか。</span>
<span className="v" id="v24" data-v="24" data-xref="コロサイ人への手紙 3:11; 使徒行伝 13:47–48; エペソ人への手紙 3:6–8"> 神は、このあわれみの器として、またわたしたちをも、ユダヤ人の中からだけではなく、異邦人の中からも召されたのである。</span>
<span className="v" id="v25" data-v="25" data-xref="ホセア書 2:23; ペテロの第一の手紙 2:10; ヨハネによる福音書 16:27"> それは、ホセアの書でも言われているとおりである、<br /><span className="pl pl-1">「わたしは、わたしの民でない者を、</span><br /><span className="pl pl-1">わたしの民と呼び、</span><br /><span className="pl pl-1">愛されなかった者を、愛される者と呼ぶであろう。</span></span>
<span className="v" id="v26" data-v="26" data-xref="ホセア書 1:9–10; ヨハネの第一の手紙 3:1–3; ガラテヤ人への手紙 3:26"> <span className="pl pl-1">あなたがたはわたしの民ではないと、</span><br /><span className="pl pl-1">彼らに言ったその場所で、</span><br /><span className="pl pl-1">彼らは生ける神の子らであると、</span><br /><span className="pl pl-1">呼ばれるであろう」。</span></span>
<span className="v" id="v27" data-v="27" data-xref="イザヤ書 10:20–23; ローマ人への手紙 11:4–6; イザヤ書 1:9"> <span className="pl pl-1">また、イザヤはイスラエルについて叫んでいる、</span><br /><span className="pl pl-1">「たとい、イスラエルの子らの数は、</span><br /><span className="pl pl-1">浜の砂のようであっても、</span><br /><span className="pl pl-1">救われるのは、残された者だけであろう。</span></span>
<span className="v" id="v28" data-v="28" data-xref="イザヤ書 10:23; ヨハネの黙示録 19:11; 使徒行伝 17:31"> <span className="pl pl-1">主は、御言をきびしくまたすみやかに、</span><br /><span className="pl pl-1">地上になしとげられるであろう」。</span></span>
<span className="v" id="v29" data-v="29" data-xref="イザヤ書 1:9; イザヤ書 13:19; アモス書 4:11"> <span className="pl pl-1">さらに、イザヤは預言した、</span><br /><span className="pl pl-1">「もし、万軍の主がわたしたちに</span><br /><span className="pl pl-1">子孫を残されなかったなら、</span><br /><span className="pl pl-1">わたしたちはソドムのようになり、</span><br /><span className="pl pl-1">ゴモラと同じようになったであろう」。</span></span>
<span className="v" id="v30" data-v="30" data-xref="ピリピ人への手紙 3:9; ヘブル人への手紙 11:7; ガラテヤ人への手紙 2:16"> <span className="pl pl-1">では、わたしたちはなんと言おうか。義を追い求めなかった異邦人は、義、すなわち、信仰による義を得た。</span></span>
<span className="v" id="v31" data-v="31" data-xref="ローマ人への手紙 11:7; ローマ人への手紙 3:20; ヤコブの手紙 2:10–11"> <span className="pl pl-1">しかし、義の律法を追い求めていたイスラエルは、その律法に達しなかった。</span></span>
<span className="v" id="v32" data-v="32" data-xref="コリント人への第一の手紙 1:23; ペテロの第一の手紙 2:8; ルカによる福音書 7:23"> <span className="pl pl-1">なぜであるか。信仰によらないで、行いによって得られるかのように、追い求めたからである。彼らは、つまずきの石につまずいたのである。</span></span>
<span className="v" id="v33" data-v="33" data-xref="イザヤ書 28:16; イザヤ書 8:14–15; ローマ人への手紙 10:11"> <span className="pl pl-1">「見よ、わたしはシオンに、</span><br /><span className="pl pl-1">つまずきの石、さまたげの岩を置く。</span><br /><span className="pl pl-1">それにより頼む者は、失望に終ることがない」</span><br />と書いてあるとおりである。</span>
</div>

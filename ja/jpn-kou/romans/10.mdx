<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="コリント人への第一の手紙 9:20–22; ローマ人への手紙 9:1–3; ヨハネによる福音書 5:34"> 兄弟たちよ。わたしの心の願い、彼らのために神にささげる祈は、彼らが救われることである。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行伝 21:20; ローマ人への手紙 9:31–32; 箴言 19:2"> わたしは、彼らが神に対して熱心であることはあかしするが、その熱心は深い知識によるものではない。</span>
<span className="v" id="v3" data-v="3" data-xref="ピリピ人への手紙 3:9; ルカによる福音書 16:15; コリント人への第二の手紙 5:21"> なぜなら、彼らは神の義を知らないで、自分の義を立てようと努め、神の義に従わなかったからである。</span>
<span className="v" id="v4" data-v="4" data-xref="ガラテヤ人への手紙 3:24; ローマ人への手紙 8:3–4; マタイによる福音書 5:17–18"> キリストは、すべて信じる者に義を得させるために、律法の終りとなられたのである。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="レビ記 18:5; エゼキエル書 20:11; ネヘミヤ書 9:29"> モーセは、律法による義を行う人は、その義によって生きる、と書いている。</span>
<span className="v" id="v6" data-v="6" data-xref="申命記 30:11–14; 箴言 30:4; エペソ人への手紙 4:8–10"> しかし、信仰による義は、こう言っている、「あなたは心のうちで、だれが天に上るであろうかと言うな」。それは、キリストを引き降ろすことである。</span>
<span className="v" id="v7" data-v="7" data-xref="ヘブル人への手紙 13:20; ヨハネの黙示録 1:18; ローマ人への手紙 4:25"> また、「だれが底知れぬ所に下るであろうかと言うな」。それは、キリストを死人の中から引き上げることである。</span>
<span className="v" id="v8" data-v="8" data-xref="申命記 30:14; ローマ人への手紙 1:16–17; テモテヘの第一の手紙 4:6"> では、なんと言っているか。「言葉はあなたの近くにある。あなたの口にあり、心にある」。この言葉とは、わたしたちが宣べ伝えている信仰の言葉である。</span>
<span className="v" id="v9" data-v="9" data-xref="ルカによる福音書 12:8; 使徒行伝 16:31; ピリピ人への手紙 2:11"> すなわち、自分の口で、イエスは主であると告白し、自分の心で、神が死人の中からイエスをよみがえらせたと信じるなら、あなたは救われる。</span>
<span className="v" id="v10" data-v="10" data-xref="ヨハネの第一の手紙 4:15; ローマ人への手紙 10:9; ガラテヤ人への手紙 2:16"> なぜなら、人は心に信じて義とされ、口で告白して救われるからである。</span>
<span className="v" id="v11" data-v="11" data-xref="イザヤ書 28:16; ローマ人への手紙 9:33; ペテロの第一の手紙 2:6"> 聖書は、「すべて彼を信じる者は、失望に終ることがない」と言っている。</span>
<span className="v" id="v12" data-v="12" data-xref="ピリピ人への手紙 4:19; ヨハネの黙示録 17:14; ガラテヤ人への手紙 3:28"> ユダヤ人とギリシヤ人との差別はない。同一の主が万民の主であって、彼を呼び求めるすべての人を豊かに恵んで下さるからである。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行伝 2:21; ヨエル書 2:32"> なぜなら、「主の御名を呼び求める者は、すべて救われる」とあるからである。</span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="マルコによる福音書 16:15–16; 使徒行伝 26:17–18; テトスヘの手紙 1:3"> しかし、信じたことのない者を、どうして呼び求めることがあろうか。聞いたことのない者を、どうして信じることがあろうか。宣べ伝える者がいなくては、どうして聞くことがあろうか。</span>
<span className="v" id="v15" data-v="15" data-xref="イザヤ書 52:7; ナホム書 1:15; エペソ人への手紙 2:17"> つかわされなくては、どうして宣べ伝えることがあろうか。「ああ、麗しいかな、良きおとずれを告げる者の足は」と書いてあるとおりである。</span>
<span className="v" id="v16" data-v="16" data-xref="イザヤ書 53:1; ローマ人への手紙 3:3; ヨハネによる福音書 12:38–40"> しかし、すべての人が福音に聞き従ったのではない。イザヤは、「主よ、だれがわたしたちから聞いたことを信じましたか」と言っている。</span>
<span className="v" id="v17" data-v="17" data-xref="ガラテヤ人への手紙 3:2; ガラテヤ人への手紙 3:5; テサロニケ人への第一の手紙 2:13"> したがって、信仰は聞くことによるのであり、聞くことはキリストの言葉から来るのである。</span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 19:4; ローマ人への手紙 1:8; マタイによる福音書 24:14"> しかしわたしは言う、彼らには聞えなかったのであろうか。否、むしろ<br /><span className="pl pl-1">「その声は全地にひびきわたり、</span><br /><span className="pl pl-1">その言葉は世界のはてにまで及んだ」。</span></span>
<span className="v" id="v19" data-v="19" data-xref="申命記 32:21; ローマ人への手紙 11:11; ローマ人への手紙 11:14"> <span className="pl pl-1">なお、わたしは言う、イスラエルは知らなかったのであろうか。まずモーセは言っている、</span><br /><span className="pl pl-1">「わたしはあなたがたに、</span><br /><span className="pl pl-1">国民でない者に対してねたみを起させ、</span><br /><span className="pl pl-1">無知な国民に対して、</span><br /><span className="pl pl-1">怒りをいだかせるであろう」。</span></span>
<span className="v" id="v20" data-v="20" data-xref="イザヤ書 65:1–2; ローマ人への手紙 9:30; イザヤ書 55:4–5"> <span className="pl pl-1">イザヤも大胆に言っている、</span><br /><span className="pl pl-1">「わたしは、わたしを求めない者たちに見いだされ、</span><br /><span className="pl pl-1">わたしを尋ねない者に、自分を現した」。</span></span>
<span className="v" id="v21" data-v="21" data-xref="イザヤ書 65:2–5; ペテロの第一の手紙 2:8; エレミヤ書 35:15"> <span className="pl pl-1">そして、イスラエルについては、</span><br /><span className="pl pl-1">「わたしは服従せずに反抗する民に、</span><br /><span className="pl pl-1">終日わたしの手をさし伸べていた」</span><br />と言っている。</span>

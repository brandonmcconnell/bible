<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="イザヤ書 51:2; ローマ人への手紙 4:16; コリント人への第二の手紙 11:22"> それでは、肉によるわたしたちの先祖アブラハムの場合については、なんと言ったらよいか。</span>
<span className="v" id="v2" data-v="2" data-xref="コリント人への第一の手紙 1:31; コリント人への第二の手紙 11:30; ピリピ人への手紙 3:9"> もしアブラハムが、その行いによって義とされたのであれば、彼は誇ることができよう。しかし、神のみまえでは、できない。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 15:6; ヤコブの手紙 2:23; ガラテヤ人への手紙 3:6–8"> なぜなら、聖書はなんと言っているか、「アブラハムは神を信じた。それによって、彼は義と認められた」とある。</span>
<span className="v" id="v4" data-v="4" data-xref="ローマ人への手紙 11:6; ローマ人への手紙 9:32; ローマ人への手紙 11:35"> いったい、働く人に対する報酬は、恩恵としてではなく、当然の支払いとして認められる。</span>
<span className="v" id="v5" data-v="5" data-xref="ピリピ人への手紙 3:9; ローマ人への手紙 3:22; テトスヘの手紙 3:3–7"> しかし、働きはなくても、不信心な者を義とするかたを信じる人は、その信仰が義と認められるのである。</span>
<span className="v" id="v6" data-v="6" data-xref="テモテヘの第二の手紙 1:9; ピリピ人への手紙 3:9; コリント人への第一の手紙 1:30"> ダビデもまた、行いがなくても神に義と認められた人の幸福について、次のように言っている、</span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 32:1–2; 詩篇 130:3–4; ルカによる福音書 7:47–50"> <span className="pl pl-1">「不法をゆるされ、罪をおおわれた人たちは、</span><br /><span className="pl pl-1">さいわいである。</span></span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 32:2; ペテロの第一の手紙 2:24; コリント人への第二の手紙 5:19–20"> <span className="pl pl-1">罪を主に認められない人は、さいわいである」。</span></span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="ガラテヤ人への手紙 3:14; コロサイ人への手紙 3:11; ガラテヤ人への手紙 3:26–28"> さて、この幸福は、割礼の者だけが受けるのか。それとも、無割礼の者にも及ぶのか。わたしたちは言う、「アブラハムには、その信仰が義と認められた」のである。</span>
<span className="v" id="v10" data-v="10" data-xref="ガラテヤ人への手紙 6:15; ガラテヤ人への手紙 5:6; 創世記 17:10"> それでは、どういう場合にそう認められたのか。割礼を受けてからか、それとも受ける前か。割礼を受けてからではなく、無割礼の時であった。</span>
<span className="v" id="v11" data-v="11" data-xref="ローマ人への手紙 3:22; ルカによる福音書 19:9; コリント人への第二の手紙 1:22"> そして、アブラハムは割礼というしるしを受けたが、それは、無割礼のままで信仰によって受けた義の証印であって、彼が、無割礼のままで信じて義とされるに至るすべての人の父となり、</span>
<span className="v" id="v12" data-v="12" data-xref="雅歌 1:8; ヨハネによる福音書 8:39–40; 箴言 2:20"> かつ、割礼の者の父となるためなのである。割礼の者というのは、割礼を受けた者ばかりではなく、われらの父アブラハムが無割礼の時に持っていた信仰の足跡を踏む人々をもさすのである。</span>
<span className="v" id="v13" data-v="13" data-xref="ガラテヤ人への手紙 3:29; 創世記 22:17–18; 創世記 28:14"> なぜなら、世界を相続させるとの約束が、アブラハムとその子孫とに対してなされたのは、律法によるのではなく、信仰の義によるからである。</span>
<span className="v" id="v14" data-v="14" data-xref="ガラテヤ人への手紙 3:18–24; ピリピ人への手紙 3:9; ローマ人への手紙 4:16"> もし、律法に立つ人々が相続人であるとすれば、信仰はむなしくなり、約束もまた無効になってしまう。</span>
<span className="v" id="v15" data-v="15" data-xref="ローマ人への手紙 5:13; ガラテヤ人への手紙 3:10; ローマ人への手紙 3:19–20"> いったい、律法は怒りを招くものであって、律法のないところには違反なるものはない。</span>
<span className="v" id="v16" data-v="16" data-xref="ローマ人への手紙 3:24–26; エペソ人への手紙 2:8; ガラテヤ人への手紙 3:22"> このようなわけで、すべては信仰によるのである。それは恵みによるのであって、すべての子孫に、すなわち、律法に立つ者だけにではなく、アブラハムの信仰に従う者にも、この約束が保証されるのである。アブラハムは、神の前で、わたしたちすべての者の父であって、</span>
<span className="v" id="v17" data-v="17" data-xref="コリント人への第一の手紙 1:28; 創世記 17:4–5; ヨハネによる福音書 5:21"> 「わたしは、あなたを立てて多くの国民の父とした」と書いてあるとおりである。彼はこの神、すなわち、死人を生かし、無から有を呼び出される神を信じたのである。</span>
<span className="v" id="v18" data-v="18" data-xref="ローマ人への手紙 8:24; 創世記 15:5–6; 使徒行伝 27:25"> 彼は望み得ないのに、なおも望みつつ信じた。そのために、「あなたの子孫はこうなるであろう」と言われているとおり、多くの国民の父となったのである。</span>
<span className="v" id="v19" data-v="19" data-xref="ヘブル人への手紙 11:11–19; ローマ人への手紙 4:20–21; 創世記 17:17"> すなわち、およそ百歳となって、彼自身のからだが死んだ状態であり、また、サラの胎が不妊であるのを認めながらも、なお彼の信仰は弱らなかった。</span>
<span className="v" id="v20" data-v="20" data-xref="ルカによる福音書 1:45; コリント人への第一の手紙 16:13; ダニエル書 10:19"> 彼は、神の約束を不信仰のゆえに疑うようなことはせず、かえって信仰によって強められ、栄光を神に帰し、</span>
<span className="v" id="v21" data-v="21" data-xref="ルカによる福音書 1:37; エレミヤ書 32:27; 創世記 18:14"> 神はその約束されたことを、また成就することができると確信した。</span>
<span className="v" id="v22" data-v="22" data-xref="ローマ人への手紙 4:6; ローマ人への手紙 4:3"> だから、彼は義と認められたのである。</span>
<span className="v" id="v23" data-v="23" data-xref="コリント人への第一の手紙 10:11; ローマ人への手紙 15:4; コリント人への第一の手紙 10:6"> しかし「義と認められた」と書いてあるのは、アブラハムのためだけではなく、</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行伝 2:24; ペテロの第一の手紙 1:21; 使徒行伝 13:30"> わたしたちのためでもあって、わたしたちの主イエスを死人の中からよみがえらせたかたを信じるわたしたちも、義と認められるのである。</span>
<span className="v" id="v25" data-v="25" data-xref="ヨハネの第一の手紙 4:9–10; イザヤ書 53:5–6; コリント人への第二の手紙 5:21"> 主は、わたしたちの罪過のために死に渡され、わたしたちが義とされるために、よみがえらされたのである。</span>

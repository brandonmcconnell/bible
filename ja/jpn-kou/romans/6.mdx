<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ペテロの第一の手紙 2:16; ガラテヤ人への手紙 5:13; ローマ人への手紙 6:15"> では、わたしたちは、なんと言おうか。恵みが増し加わるために、罪にとどまるべきであろうか。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネの第一の手紙 3:9; コロサイ人への手紙 3:3; ローマ人への手紙 7:4"> 断じてそうではない。罪に対して死んだわたしたちが、どうして、なお、その中に生きておれるだろうか。</span>
<span className="v" id="v3" data-v="3" data-xref="ガラテヤ人への手紙 3:27; ガラテヤ人への手紙 2:20–21; ローマ人への手紙 6:8"> それとも、あなたがたは知らないのか。キリスト・イエスにあずかるバプテスマを受けたわたしたちは、彼の死にあずかるバプテスマを受けたのである。</span>
<span className="v" id="v4" data-v="4" data-xref="コリント人への第二の手紙 5:17; コロサイ人への手紙 3:10; エペソ人への手紙 4:22–24"> すなわち、わたしたちは、その死にあずかるバプテスマによって、彼と共に葬られたのである。それは、キリストが父の栄光によって、死人の中からよみがえらされたように、わたしたちもまた、新しいいのちに生きるためである。</span>
<span className="v" id="v5" data-v="5" data-xref="ピリピ人への手紙 3:10–11; コリント人への第二の手紙 4:10; コロサイ人への手紙 2:12"> もしわたしたちが、彼に結びついてその死の様にひとしくなるなら、さらに、彼の復活の様にもひとしくなるであろう。</span>
<span className="v" id="v6" data-v="6" data-xref="ガラテヤ人への手紙 2:20; エペソ人への手紙 4:22; ガラテヤ人への手紙 5:24"> わたしたちは、この事を知っている。わたしたちの内の古き人はキリストと共に十字架につけられた。それは、この罪のからだが滅び、わたしたちがもはや、罪の奴隷となることがないためである。</span>
<span className="v" id="v7" data-v="7" data-xref="ペテロの第一の手紙 4:1; コロサイ人への手紙 3:1–3; ローマ人への手紙 7:4"> それは、すでに死んだ者は、罪から解放されているからである。</span>
<span className="v" id="v8" data-v="8" data-xref="テモテヘの第二の手紙 2:11–12; コロサイ人への手紙 3:3–4; コリント人への第二の手紙 4:10–14"> もしわたしたちが、キリストと共に死んだなら、また彼と共に生きることを信じる。</span>
<span className="v" id="v9" data-v="9" data-xref="ローマ人への手紙 6:14; ヨハネの黙示録 1:18; 使徒行伝 2:24–28"> キリストは死人の中からよみがえらされて、もはや死ぬことがなく、死はもはや彼を支配しないことを、知っているからである。</span>
<span className="v" id="v10" data-v="10" data-xref="コリント人への第二の手紙 5:21; ペテロの第一の手紙 4:6; ペテロの第一の手紙 3:18"> なぜなら、キリストが死んだのは、ただ一度罪に対して死んだのであり、キリストが生きるのは、神に生きるのだからである。</span>
<span className="v" id="v11" data-v="11" data-xref="コロサイ人への手紙 3:3–5; コリント人への第一の手紙 6:20; ローマ人への手紙 6:2"> このように、あなたがた自身も、罪に対して死んだ者であり、キリスト・イエスにあって神に生きている者であることを、認むべきである。</span>
<span className="v" id="v12" data-v="12" data-xref="ガラテヤ人への手紙 5:16; ローマ人への手紙 6:16; ローマ人への手紙 8:13"> だから、あなたがたの死ぬべきからだを罪の支配にゆだねて、その情欲に従わせることをせず、</span>
<span className="v" id="v13" data-v="13" data-xref="ローマ人への手紙 12:1; ローマ人への手紙 6:16; コロサイ人への手紙 3:5"> また、あなたがたの肢体を不義の武器として罪にささげてはならない。むしろ、死人の中から生かされた者として、自分自身を神にささげ、自分の肢体を義の武器として神にささげるがよい。</span>
<span className="v" id="v14" data-v="14" data-xref="ガラテヤ人への手紙 5:18; ローマ人への手紙 8:2; ローマ人への手紙 7:4–11"> なぜなら、あなたがたは律法の下にあるのではなく、恵みの下にあるので、罪に支配されることはないからである。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="テトスヘの手紙 2:11–14; エペソ人への手紙 2:8–10; ローマ人への手紙 6:1–2"> それでは、どうなのか。律法の下にではなく、恵みの下にあるからといって、わたしたちは罪を犯すべきであろうか。断じてそうではない。</span>
<span className="v" id="v16" data-v="16" data-xref="ヨハネによる福音書 8:34; マタイによる福音書 6:24; ヨシュア記 24:15"> あなたがたは知らないのか。あなたがた自身が、だれかの僕になって服従するなら、あなたがたは自分の服従するその者の僕であって、死に至る罪の僕ともなり、あるいは、義にいたる従順の僕ともなるのである。</span>
<span className="v" id="v17" data-v="17" data-xref="ペテロの第一の手紙 2:9; テモテヘの第二の手紙 1:13; ローマ人への手紙 1:8"> しかし、神は感謝すべきかな。あなたがたは罪の僕であったが、伝えられた教の基準に心から服従して、</span>
<span className="v" id="v18" data-v="18" data-xref="ローマ人への手紙 6:22; ローマ人への手紙 8:2; ガラテヤ人への手紙 5:1"> 罪から解放され、義の僕となった。</span>
<span className="v" id="v19" data-v="19" data-xref="ローマ人への手紙 6:13; ペテロの第一の手紙 4:2–4; コロサイ人への手紙 3:5–7"> わたしは人間的な言い方をするが、それは、あなたがたの肉の弱さのゆえである。あなたがたは、かつて自分の肢体を汚れと不法との僕としてささげて不法に陥ったように、今や自分の肢体を義の僕としてささげて、きよくならねばならない。</span>
<span className="v" id="v20" data-v="20" data-xref="ローマ人への手紙 6:16–17; ヨハネによる福音書 8:34"> あなたがたが罪の僕であった時は、義とは縁のない者であった。</span>
<span className="v" id="v21" data-v="21" data-xref="ローマ人への手紙 1:32; ローマ人への手紙 7:5; ローマ人への手紙 6:23"> その時あなたがたは、どんな実を結んだのか。それは、今では恥とするようなものであった。それらのものの終極は、死である。</span>
<span className="v" id="v22" data-v="22" data-xref="ペテロの第一の手紙 2:16; ローマ人への手紙 6:18; ローマ人への手紙 8:2"> しかし今や、あなたがたは罪から解放されて神に仕え、きよきに至る実を結んでいる。その終極は永遠のいのちである。</span>
<span className="v" id="v23" data-v="23" data-xref="ヨハネによる福音書 3:36; ローマ人への手紙 5:12; ヤコブの手紙 1:15"> 罪の支払う報酬は死である。しかし神の賜物は、わたしたちの主キリスト・イエスにおける永遠のいのちである。</span>

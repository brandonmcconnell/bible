<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="コリント人への第二の手紙 11:22; サムエル記上 12:22; ピリピ人への手紙 3:5"> そこで、わたしは問う、「神はその民を捨てたのであろうか」。断じてそうではない。わたしもイスラエル人であり、アブラハムの子孫、ベニヤミン族の者である。</span>
<span className="v" id="v2" data-v="2" data-xref="詩篇 94:14; ローマ人への手紙 8:29–30; 出エジプト記 32:1"> 神は、あらかじめ知っておられたその民を、捨てることはされなかった。聖書がエリヤについてなんと言っているか、あなたがたは知らないのか。すなわち、彼はイスラエルを神に訴えてこう言った。</span>
<span className="v" id="v3" data-v="3" data-xref="列王紀上 19:10–18; 列王紀上 18:13; ネヘミヤ書 9:26"> 「主よ、彼らはあなたの預言者たちを殺し、あなたの祭壇をこぼち、そして、わたしひとりが取り残されたのに、彼らはわたしのいのちをも求めています」。</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀上 19:18; 民数記 25:3; ゼパニヤ書 1:4"> しかし、彼に対する御告げはなんであったか、「バアルにひざをかがめなかった七千人を、わたしのために残しておいた」。</span>
<span className="v" id="v5" data-v="5" data-xref="ローマ人への手紙 9:27; エペソ人への手紙 1:5–6; ローマ人への手紙 9:11"> それと同じように、今の時にも、恵みの選びによって残された者がいる。</span>
<span className="v" id="v6" data-v="6" data-xref="ガラテヤ人への手紙 2:21; ローマ人への手紙 4:4–5; テモテヘの第二の手紙 1:9"> しかし、恵みによるのであれば、もはや行いによるのではない。そうでないと、恵みはもはや恵みでなくなるからである。</span>
<span className="v" id="v7" data-v="7" data-xref="ローマ人への手紙 9:18; ローマ人への手紙 11:5; コリント人への第二の手紙 4:4"> では、どうなるのか。イスラエルはその追い求めているものを得ないで、ただ選ばれた者が、それを得た。そして、他の者たちはかたくなになった。</span>
<span className="v" id="v8" data-v="8" data-xref="申命記 29:4; イザヤ書 29:10; エゼキエル書 12:2"> <span className="pl pl-1">「神は、彼らに鈍い心と、</span><br /><span className="pl pl-1">見えない目と、聞えない耳とを与えて、</span><br /><span className="pl pl-1">きょう、この日に及んでいる」</span><br />と書いてあるとおりである。</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 69:22–23; ルカによる福音書 12:20; 詩篇 28:4"> ダビデもまた言っている、<br /><span className="pl pl-1">「彼らの食卓は、彼らのわなとなれ、網となれ、</span><br /><span className="pl pl-1">つまずきとなれ、報復となれ。</span></span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 69:23; 申命記 28:64–68; ペテロの第二の手紙 2:4"> <span className="pl pl-1">彼らの目は、くらんで見えなくなれ、</span><br /><span className="pl pl-1">彼らの背は、いつまでも曲っておれ」。</span></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="使徒行伝 13:46–48; ローマ人への手紙 11:31; ローマ人への手紙 10:19"> そこで、わたしは問う、「彼らがつまずいたのは、倒れるためであったのか」。断じてそうではない。かえって、彼らの罪過によって、救が異邦人に及び、それによってイスラエルを奮起させるためである。</span>
<span className="v" id="v12" data-v="12" data-xref="ローマ人への手紙 11:25; コロサイ人への手紙 1:27; ローマ人への手紙 11:15"> しかし、もし、彼らの罪過が世の富となり、彼らの失敗が異邦人の富となったとすれば、まして彼らが全部救われたなら、どんなにかすばらしいことであろう。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="使徒行伝 9:15; テモテヘの第二の手紙 1:11–12; エペソ人への手紙 3:8"> そこでわたしは、あなたがた異邦人に言う。わたし自身は異邦人の使徒なのであるから、わたしの務を光栄とし、</span>
<span className="v" id="v14" data-v="14" data-xref="コリント人への第一の手紙 7:16; テモテヘの第一の手紙 4:16; ローマ人への手紙 9:3"> どうにかしてわたしの骨肉を奮起させ、彼らの幾人かを救おうと願っている。</span>
<span className="v" id="v15" data-v="15" data-xref="エペソ人への手紙 1:10; ローマ人への手紙 5:10–11; コロサイ人への手紙 1:20–21"> もし彼らの捨てられたことが世の和解となったとすれば、彼らの受けいれられることは、死人の中から生き返ることではないか。</span>
<span className="v" id="v16" data-v="16" data-xref="エゼキエル書 44:30; ヤコブの手紙 1:18; 箴言 3:9"> もし、麦粉の初穂がきよければ、そのかたまりもきよい。もし根がきよければ、その枝もきよい。</span>
<span className="v" id="v17" data-v="17" data-xref="エペソ人への手紙 2:11–13; エペソ人への手紙 3:6; マタイによる福音書 21:43"> しかし、もしある枝が切り去られて、野生のオリブであるあなたがそれにつがれ、オリブの根の豊かな養分にあずかっているとすれば、</span>
<span className="v" id="v18" data-v="18" data-xref="コリント人への第一の手紙 10:12; ローマ人への手紙 11:20; エペソ人への手紙 2:19–20"> あなたはその枝に対して誇ってはならない。たとえ誇るとしても、あなたが根をささえているのではなく、根があなたをささえているのである。</span>
<span className="v" id="v19" data-v="19" data-xref="ローマ人への手紙 11:17; ローマ人への手紙 11:11–12; ローマ人への手紙 11:23–24"> すると、あなたは、「枝が切り去られたのは、わたしがつがれるためであった」と言うであろう。</span>
<span className="v" id="v20" data-v="20" data-xref="ローマ人への手紙 12:16; コリント人への第二の手紙 1:24; コリント人への第一の手紙 10:12"> まさに、そのとおりである。彼らは不信仰のゆえに切り去られ、あなたは信仰のゆえに立っているのである。高ぶった思いをいだかないで、むしろ恐れなさい。</span>
<span className="v" id="v21" data-v="21" data-xref="ペテロの第二の手紙 2:4–9; エレミヤ書 25:29; エレミヤ書 49:12"> もし神が元木の枝を惜しまなかったとすれば、あなたを惜しむようなことはないであろう。</span>
<span className="v" id="v22" data-v="22" data-xref="ヘブル人への手紙 3:14; ヘブル人への手紙 3:6; コリント人への第一の手紙 15:2"> 神の慈愛と峻厳とを見よ。神の峻厳は倒れた者たちに向けられ、神の慈愛は、もしあなたがその慈愛にとどまっているなら、あなたに向けられる。そうでないと、あなたも切り取られるであろう。</span>
<span className="v" id="v23" data-v="23" data-xref="コリント人への第二の手紙 3:16; ゼカリヤ書 12:10; マタイによる福音書 23:39"> しかし彼らも、不信仰を続けなければ、つがれるであろう。神には彼らを再びつぐ力がある。</span>
<span className="v" id="v24" data-v="24" data-xref="ローマ人への手紙 11:17–18; ローマ人への手紙 11:30"> なぜなら、もしあなたが自然のままの野生のオリブから切り取られ、自然の性質に反して良いオリブにつがれたとすれば、まして、これら自然のままの良い枝は、もっとたやすく、元のオリブにつがれないであろうか。</span>
</div>
<div className="bp poetry">
<span className="v" id="v25" data-v="25" data-xref="ルカによる福音書 21:24; コリント人への第二の手紙 3:14–16; ローマ人への手紙 16:25"> 兄弟たちよ。あなたがたが知者だと自負することのないために、この奥義を知らないでいてもらいたくない。一部のイスラエル人がかたくなになったのは、異邦人が全部救われるに至る時までのことであって、</span>
<span className="v" id="v26" data-v="26" data-xref="イザヤ書 59:20; エレミヤ書 31:31–37; 詩篇 14:7"> こうして、イスラエル人は、すべて救われるであろう。すなわち、次のように書いてある、<br /><span className="pl pl-1">「救う者がシオンからきて、</span><br /><span className="pl pl-1">ヤコブから不信心を追い払うであろう。</span></span>
<span className="v" id="v27" data-v="27" data-xref="エレミヤ書 31:31–34; イザヤ書 59:21; エゼキエル書 36:25–29"> <span className="pl pl-1">そして、これが、彼らの罪を除き去る時に、</span><br /><span className="pl pl-1">彼らに対して立てるわたしの契約である」。</span></span>
<span className="v" id="v28" data-v="28" data-xref="申命記 10:15; 申命記 7:7–8; マタイによる福音書 21:43"> <span className="pl pl-1">福音について言えば、彼らは、あなたがたのゆえに、神の敵とされているが、選びについて言えば、父祖たちのゆえに、神に愛せられる者である。</span></span>
<span className="v" id="v29" data-v="29" data-xref="ヘブル人への手紙 7:21; 民数記 23:19; マラキ書 3:6"> <span className="pl pl-1">神の賜物と召しとは、変えられることがない。</span></span>
<span className="v" id="v30" data-v="30" data-xref="コロサイ人への手紙 3:7; エペソ人への手紙 2:1–2; コリント人への第一の手紙 7:25"> <span className="pl pl-1">あなたがたが、かつては神に不従順であったが、今は彼らの不従順によってあわれみを受けたように、</span></span>
<span className="v" id="v31" data-v="31" data-xref="ローマ人への手紙 11:15; ローマ人への手紙 10:16; ローマ人への手紙 11:25"> <span className="pl pl-1">彼らも今は不従順になっているが、それは、あなたがたの受けたあわれみによって、彼ら自身も今あわれみを受けるためなのである。</span></span>
<span className="v" id="v32" data-v="32" data-xref="ガラテヤ人への手紙 3:22; ローマ人への手紙 3:9; テモテヘの第一の手紙 2:4–6"> <span className="pl pl-1">すなわち、神はすべての人をあわれむために、すべての人を不従順のなかに閉じ込めたのである。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v33" data-v="33" data-xref="ヨブ記 5:9; ヨブ記 11:7–9; 詩篇 92:5"> ああ深いかな、神の知恵と知識との富は。そのさばきは窮めがたく、その道は測りがたい。</span>
<span className="v" id="v34" data-v="34" data-xref="イザヤ書 40:13; コリント人への第一の手紙 2:16; ヨブ記 15:8"> <span className="pl pl-1">「だれが、主の心を知っていたか。</span><br /><span className="pl pl-1">だれが、主の計画にあずかったか。</span></span>
<span className="v" id="v35" data-v="35" data-xref="ヨブ記 41:11; ヨブ記 35:7; コリント人への第一の手紙 4:7"> <span className="pl pl-1">また、だれが、まず主に与えて、</span><br /><span className="pl pl-1">その報いを受けるであろうか」。</span></span>
<span className="v" id="v36" data-v="36" data-xref="コロサイ人への手紙 1:15–17; コリント人への第一の手紙 8:6; ヘブル人への手紙 2:10"> <span className="pl pl-1">万物は、神からいで、神によって成り、神に帰するのである。栄光がとこしえに神にあるように、アァメン。</span></span>
</div>

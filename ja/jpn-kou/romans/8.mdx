<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨハネによる福音書 3:18–19; コリント人への第二の手紙 5:17; ガラテヤ人への手紙 3:13"> こういうわけで、今やキリスト・イエスにある者は罪に定められることがない。</span>
<span className="v" id="v2" data-v="2" data-xref="ローマ人への手紙 6:14; コリント人への第二の手紙 3:17; ローマ人への手紙 6:18"> なぜなら、キリスト・イエスにあるいのちの御霊の法則は、罪と死との法則からあなたを解放したからである。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行伝 13:39; ガラテヤ人への手紙 4:4–5; ヘブル人への手紙 7:18–19"> 律法が肉により無力になっているためになし得なかった事を、神はなし遂げて下さった。すなわち、御子を、罪の肉の様で罪のためにつかわし、肉において罪を罰せられたのである。</span>
<span className="v" id="v4" data-v="4" data-xref="ガラテヤ人への手紙 5:16; ガラテヤ人への手紙 5:22–25; コロサイ人への手紙 1:22"> これは律法の要求が、肉によらず霊によって歩くわたしたちにおいて、満たされるためである。</span>
<span className="v" id="v5" data-v="5" data-xref="コリント人への第一の手紙 2:14; ガラテヤ人への手紙 5:19–25; ヨハネによる福音書 3:6"> なぜなら、肉に従う者は肉のことを思い、霊に従う者は霊のことを思うからである。</span>
<span className="v" id="v6" data-v="6" data-xref="ガラテヤ人への手紙 6:8; ローマ人への手紙 8:7; ローマ人への手紙 8:13"> 肉の思いは死であるが、霊の思いは、いのちと平安とである。</span>
<span className="v" id="v7" data-v="7" data-xref="コリント人への第一の手紙 2:14; ヨハネの第一の手紙 2:15–16; ヤコブの手紙 4:4"> なぜなら、肉の思いは神に敵するからである。すなわち、それは神の律法に従わず、否、従い得ないのである。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨハネによる福音書 3:5–6; ヘブル人への手紙 11:5–6; ローマ人への手紙 8:9"> また、肉にある者は、神を喜ばせることができない。</span>
<span className="v" id="v9" data-v="9" data-xref="ガラテヤ人への手紙 4:6; コリント人への第一の手紙 3:16; テモテヘの第二の手紙 1:14"> しかし、神の御霊があなたがたの内に宿っているなら、あなたがたは肉におるのではなく、霊におるのである。もし、キリストの霊を持たない人がいるなら、その人はキリストのものではない。</span>
<span className="v" id="v10" data-v="10" data-xref="エペソ人への手紙 3:17; ガラテヤ人への手紙 2:20; コリント人への第二の手紙 5:21"> もし、キリストがあなたがたの内におられるなら、からだは罪のゆえに死んでいても、霊は義のゆえに生きているのである。</span>
<span className="v" id="v11" data-v="11" data-xref="コリント人への第二の手紙 4:14; ローマ人への手紙 6:4–5; コリント人への第二の手紙 4:11"> もし、イエスを死人の中からよみがえらせたかたの御霊が、あなたがたの内に宿っているなら、キリスト・イエスを死人の中からよみがえらせたかたは、あなたがたの内に宿っている御霊によって、あなたがたの死ぬべきからだをも、生かしてくださるであろう。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="ローマ人への手紙 6:2–15; コリント人への第一の手紙 6:19–20; ペテロの第一の手紙 4:2–3"> それゆえに、兄弟たちよ。わたしたちは、果すべき責任を負っている者であるが、肉に従って生きる責任を肉に対して負っているのではない。</span>
<span className="v" id="v13" data-v="13" data-xref="ガラテヤ人への手紙 6:8; ペテロの第一の手紙 2:11; コリント人への第一の手紙 9:27"> なぜなら、もし、肉に従って生きるなら、あなたがたは死ぬ外はないからである。しかし、霊によってからだの働きを殺すなら、あなたがたは生きるであろう。</span>
<span className="v" id="v14" data-v="14" data-xref="ガラテヤ人への手紙 5:18; ヨハネによる福音書 1:12; ガラテヤ人への手紙 3:26"> すべて神の御霊に導かれている者は、すなわち、神の子である。</span>
<span className="v" id="v15" data-v="15" data-xref="ガラテヤ人への手紙 4:5–7; テモテヘの第二の手紙 1:7; コリント人への第一の手紙 2:12"> あなたがたは再び恐れをいだかせる奴隷の霊を受けたのではなく、子たる身分を授ける霊を受けたのである。その霊によって、わたしたちは「アバ、父よ」と呼ぶのである。</span>
<span className="v" id="v16" data-v="16" data-xref="ヨハネの第一の手紙 4:13; コリント人への第二の手紙 1:22; コリント人への第二の手紙 5:5"> 御霊みずから、わたしたちの霊と共に、わたしたちが神の子であることをあかしして下さる。</span>
<span className="v" id="v17" data-v="17" data-xref="ガラテヤ人への手紙 4:7; ガラテヤ人への手紙 3:29; エペソ人への手紙 3:6"> もし子であれば、相続人でもある。神の相続人であって、キリストと栄光を共にするために苦難をも共にしている以上、キリストと共同の相続人なのである。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="コリント人への第二の手紙 4:17–18; ペテロの第一の手紙 4:13; ペテロの第一の手紙 1:5–7"> わたしは思う。今のこの時の苦しみは、やがてわたしたちに現されようとする栄光に比べると、言うに足りない。</span>
<span className="v" id="v19" data-v="19" data-xref="マラキ書 3:17–18; ローマ人への手紙 8:23; ヨハネの第一の手紙 3:2"> 被造物は、実に、切なる思いで神の子たちの出現を待ち望んでいる。</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 3:17–19; 創世記 5:29; ローマ人への手紙 8:22"> なぜなら、被造物が虚無に服したのは、自分の意志によるのではなく、服従させたかたによるのであり、</span>
<span className="v" id="v21" data-v="21" data-xref="ヨハネの黙示録 22:3–5; 使徒行伝 3:21; ペテロの第二の手紙 3:13"> かつ、被造物自身にも、滅びのなわめから解放されて、神の子たちの栄光の自由に入る望みが残されているからである。</span>
<span className="v" id="v22" data-v="22" data-xref="エレミヤ書 12:4; エレミヤ書 12:11; ヨハネによる福音書 16:21"> 実に、被造物全体が、今に至るまで、共にうめき共に産みの苦しみを続けていることを、わたしたちは知っている。</span>
<span className="v" id="v23" data-v="23" data-xref="ピリピ人への手紙 3:20–21; コリント人への第二の手紙 5:2–5; ヘブル人への手紙 9:28"> それだけではなく、御霊の最初の実を持っているわたしたち自身も、心の内でうめきながら、子たる身分を授けられること、すなわち、からだのあがなわれることを待ち望んでいる。</span>
<span className="v" id="v24" data-v="24" data-xref="コリント人への第二の手紙 5:7; ヘブル人への手紙 11:1; コリント人への第二の手紙 4:18"> わたしたちは、この望みによって救われているのである。しかし、目に見える望みは望みではない。なぜなら、現に見ている事を、どうして、なお望む人があろうか。</span>
<span className="v" id="v25" data-v="25" data-xref="ローマ人への手紙 12:12; ヘブル人への手紙 10:36; 詩篇 27:14"> もし、わたしたちが見ないことを望むなら、わたしたちは忍耐して、それを待ち望むのである。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="マタイによる福音書 10:20; エペソ人への手紙 6:18; ガラテヤ人への手紙 4:6"> 御霊もまた同じように、弱いわたしたちを助けて下さる。なぜなら、わたしたちはどう祈ったらよいかわからないが、御霊みずから、言葉にあらわせない切なるうめきをもって、わたしたちのためにとりなして下さるからである。</span>
<span className="v" id="v27" data-v="27" data-xref="エレミヤ書 17:10; ヨハネの第一の手紙 5:14–15; エペソ人への手紙 2:18"> そして、人の心を探り知るかたは、御霊の思うところがなんであるかを知っておられる。なぜなら、御霊は、聖徒のために、神の御旨にかなうとりなしをして下さるからである。</span>
<span className="v" id="v28" data-v="28" data-xref="ペテロの第一の手紙 5:10; ヤコブの手紙 1:12; 創世記 50:20"> 神は、神を愛する者たち、すなわち、ご計画に従って召された者たちと共に働いて、万事を益となるようにして下さることを、わたしたちは知っている。</span>
<span className="v" id="v29" data-v="29" data-xref="エペソ人への手紙 1:4–5; エレミヤ書 1:5; エペソ人への手紙 1:11"> 神はあらかじめ知っておられる者たちを、更に御子のかたちに似たものとしようとして、あらかじめ定めて下さった。それは、御子を多くの兄弟の中で長子とならせるためであった。</span>
<span className="v" id="v30" data-v="30" data-xref="ヨハネの黙示録 17:14; ローマ人への手紙 8:28; エペソ人への手紙 1:11"> そして、あらかじめ定めた者たちを更に召し、召した者たちを更に義とし、義とした者たちには、更に栄光を与えて下さったのである。</span>
</div>
<div className="bp poetry">
<span className="v" id="v31" data-v="31" data-xref="詩篇 118:6; エレミヤ書 1:19; 詩篇 56:11"> それでは、これらの事について、なんと言おうか。もし、神がわたしたちの味方であるなら、だれがわたしたちに敵し得ようか。</span>
<span className="v" id="v32" data-v="32" data-xref="ヨハネによる福音書 3:16; ローマ人への手紙 8:28; 詩篇 84:11"> ご自身の御子をさえ惜しまないで、わたしたちすべての者のために死に渡されたかたが、どうして、御子のみならず万物をも賜わらないことがあろうか。</span>
<span className="v" id="v33" data-v="33" data-xref="ヨハネの黙示録 12:10–11; イザヤ書 50:8–9; イザヤ書 54:17"> だれが、神の選ばれた者たちを訴えるのか。神は彼らを義とされるのである。</span>
<span className="v" id="v34" data-v="34" data-xref="ヘブル人への手紙 7:25; ローマ人への手紙 8:27; ヘブル人への手紙 9:24"> だれが、わたしたちを罪に定めるのか。キリスト・イエスは、死んで、否、よみがえって、神の右に座し、また、わたしたちのためにとりなして下さるのである。</span>
<span className="v" id="v35" data-v="35" data-xref="ヨハネによる福音書 10:28; 詩篇 103:17; ヨハネによる福音書 16:33"> だれが、キリストの愛からわたしたちを離れさせるのか。患難か、苦悩か、迫害か、飢えか、裸か、危難か、剣か。</span>
<span className="v" id="v36" data-v="36" data-xref="詩篇 44:22; イザヤ書 53:7; コリント人への第一の手紙 15:30"> <span className="pl pl-1">「わたしたちはあなたのために終日、</span><br /><span className="pl pl-1">死に定められており、</span><br /><span className="pl pl-1">ほふられる羊のように見られている」</span><br />と書いてあるとおりである。</span>
<span className="v" id="v37" data-v="37" data-xref="コリント人への第一の手紙 15:57; ヨハネの第一の手紙 4:4; コリント人への第二の手紙 2:14"> しかし、わたしたちを愛して下さったかたによって、わたしたちは、これらすべての事において勝ち得て余りがある。</span>
<span className="v" id="v38" data-v="38" data-xref="ヨハネによる福音書 10:28; ローマ人への手紙 14:8; テモテヘの第二の手紙 1:12"> わたしは確信する。死も生も、天使も支配者も、現在のものも将来のものも、力あるものも、</span>
<span className="v" id="v39" data-v="39" data-xref="ヨハネによる福音書 10:28–30; ローマ人への手紙 8:35; ローマ人への手紙 5:8"> 高いものも深いものも、その他どんな被造物も、わたしたちの主キリスト・イエスにおける神の愛から、わたしたちを引き離すことはできないのである。</span>
</div>

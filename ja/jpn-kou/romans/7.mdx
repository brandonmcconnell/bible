<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ローマ人への手紙 6:14; ローマ人への手紙 7:6; ローマ人への手紙 6:3"> それとも、兄弟たちよ。あなたがたは知らないのか。わたしは律法を知っている人々に語るのであるが、律法は人をその生きている期間だけ支配するものである。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 2:23–24; コリント人への第一の手紙 7:39; コリント人への第一の手紙 7:4"> すなわち、夫のある女は、夫が生きている間は、律法によって彼につながれている。しかし、夫が死ねば、夫の律法から解放される。</span>
<span className="v" id="v3" data-v="3" data-xref="出エジプト記 20:14; マタイによる福音書 5:32; マルコによる福音書 10:6–12"> であるから、夫の生存中に他の男に行けば、その女は淫婦と呼ばれるが、もし夫が死ねば、その律法から解かれるので、他の男に行っても、淫婦とはならない。</span>
<span className="v" id="v4" data-v="4" data-xref="ペテロの第一の手紙 2:24; ガラテヤ人への手紙 5:22–23; イザヤ書 54:5"> わたしの兄弟たちよ。このように、あなたがたも、キリストのからだをとおして、律法に対して死んだのである。それは、あなたがたが他の人、すなわち、死人の中からよみがえられたかたのものとなり、こうして、わたしたちが神のために実を結ぶに至るためなのである。</span>
<span className="v" id="v5" data-v="5" data-xref="エペソ人への手紙 2:3; ガラテヤ人への手紙 5:16–17; ガラテヤ人への手紙 5:24"> というのは、わたしたちが肉にあった時には、律法による罪の欲情が、死のために実を結ばせようとして、わたしたちの肢体のうちに働いていた。</span>
<span className="v" id="v6" data-v="6" data-xref="ガラテヤ人への手紙 3:23–25; コリント人への第二の手紙 3:6; ローマ人への手紙 7:4"> しかし今は、わたしたちをつないでいたものに対して死んだので、わたしたちは律法から解放され、その結果、古い文字によってではなく、新しい霊によって仕えているのである。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="ローマ人への手紙 3:20; ローマ人への手紙 4:15; コリント人への第一の手紙 15:56"> それでは、わたしたちは、なんと言おうか。律法は罪なのか。断じてそうではない。しかし、律法によらなければ、わたしは罪を知らなかったであろう。すなわち、もし律法が「むさぼるな」と言わなかったら、わたしはむさぼりなるものを知らなかったであろう。</span>
<span className="v" id="v8" data-v="8" data-xref="ローマ人への手紙 7:11; コリント人への第一の手紙 15:56; ローマ人への手紙 4:15"> しかるに、罪は戒めによって機会を捕え、わたしの内に働いて、あらゆるむさぼりを起させた。すなわち、律法がなかったら、罪は死んでいるのである。</span>
<span className="v" id="v9" data-v="9" data-xref="ガラテヤ人への手紙 3:10; ローマ人への手紙 8:7; ヤコブの手紙 2:10–11"> わたしはかつては、律法なしに生きていたが、戒めが来るに及んで、罪は生き返り、</span>
<span className="v" id="v10" data-v="10" data-xref="コリント人への第二の手紙 3:7; ローマ人への手紙 10:5; レビ記 18:5"> わたしは死んだ。そして、いのちに導くべき戒めそのものが、かえってわたしを死に導いて行くことがわかった。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 3:13; ローマ人への手紙 7:8; ヘブル人への手紙 3:13"> なぜなら、罪は戒めによって機会を捕え、わたしを欺き、戒めによってわたしを殺したからである。</span>
<span className="v" id="v12" data-v="12" data-xref="テモテヘの第一の手紙 1:8; 詩篇 119:137; 詩篇 19:7–12"> このようなわけで、律法そのものは聖なるものであり、戒めも聖であって、正しく、かつ善なるものである。</span>
<span className="v" id="v13" data-v="13" data-xref="ヤコブの手紙 1:13–15; ガラテヤ人への手紙 3:21; ローマ人への手紙 8:3"> では、善なるものが、わたしにとって死となったのか。断じてそうではない。それはむしろ、罪の罪たることが現れるための、罪のしわざである。すなわち、罪は、戒めによって、はなはだしく悪性なものとなるために、善なるものによってわたしを死に至らせたのである。</span>
<span className="v" id="v14" data-v="14" data-xref="列王紀上 21:25; 列王紀下 17:17; ローマ人への手紙 7:18"> わたしたちは、律法は霊的なものであると知っている。しかし、わたしは肉につける者であって、罪の下に売られているのである。</span>
<span className="v" id="v15" data-v="15" data-xref="ガラテヤ人への手紙 5:17; ローマ人への手紙 7:19–20; 伝道の書 7:20"> わたしは自分のしていることが、わからない。なぜなら、わたしは自分の欲する事は行わず、かえって自分の憎む事をしているからである。</span>
<span className="v" id="v16" data-v="16" data-xref="ローマ人への手紙 7:12; ローマ人への手紙 7:14; テモテヘの第一の手紙 1:8"> もし、自分の欲しない事をしているとすれば、わたしは律法が良いものであることを承認していることになる。</span>
<span className="v" id="v17" data-v="17" data-xref="ローマ人への手紙 7:20; ピリピ人への手紙 3:8–9; ローマ人への手紙 7:18"> そこで、この事をしているのは、もはやわたしではなく、わたしの内に宿っている罪である。</span>
<span className="v" id="v18" data-v="18" data-xref="ヨハネによる福音書 3:6; 詩篇 51:5; ガラテヤ人への手紙 5:17"> わたしの内に、すなわち、わたしの肉の内には、善なるものが宿っていないことを、わたしは知っている。なぜなら、善をしようとする意志は、自分にあるが、それをする力がないからである。</span>
<span className="v" id="v19" data-v="19" data-xref="ローマ人への手紙 7:15"> すなわち、わたしの欲している善はしないで、欲していない悪は、これを行っている。</span>
<span className="v" id="v20" data-v="20" data-xref="ローマ人への手紙 7:17"> もし、欲しないことをしているとすれば、それをしているのは、もはやわたしではなく、わたしの内に宿っている罪である。</span>
<span className="v" id="v21" data-v="21" data-xref="ローマ人への手紙 6:14; ローマ人への手紙 7:23; 詩篇 119:133"> そこで、善をしようと欲しているわたしに、悪がはいり込んでいるという法則があるのを見る。</span>
<span className="v" id="v22" data-v="22" data-xref="詩篇 1:2; 詩篇 40:8; 詩篇 119:35"> すなわち、わたしは、内なる人としては神の律法を喜んでいるが、</span>
<span className="v" id="v23" data-v="23" data-xref="ガラテヤ人への手紙 5:17; ヤコブの手紙 4:1; ローマ人への手紙 8:2"> わたしの肢体には別の律法があって、わたしの心の法則に対して戦いをいどみ、そして、肢体に存在する罪の法則の中に、わたしをとりこにしているのを見る。</span>
<span className="v" id="v24" data-v="24" data-xref="ローマ人への手紙 6:6; テモテヘの第二の手紙 4:18; テトスヘの手紙 2:14"> わたしは、なんというみじめな人間なのだろう。だれが、この死のからだから、わたしを救ってくれるだろうか。</span>
<span className="v" id="v25" data-v="25" data-xref="ガラテヤ人への手紙 5:17–24; コロサイ人への手紙 3:17; コリント人への第二の手紙 12:9–10"> わたしたちの主イエス・キリストによって、神は感謝すべきかな。このようにして、わたし自身は、心では神の律法に仕えているが、肉では罪の律法に仕えているのである。</span>
</div>

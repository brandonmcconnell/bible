<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="テサロニケ人への第一の手紙 5:14; ローマ人への手紙 14:1; ガラテヤ人への手紙 6:1–2"> わたしたち強い者は、強くない者たちの弱さをになうべきであって、自分だけを喜ばせることをしてはならない。</span>
<span className="v" id="v2" data-v="2" data-xref="ローマ人への手紙 14:19; コリント人への第一の手紙 10:24; ピリピ人への手紙 2:4–5"> わたしたちひとりびとりは、隣り人の徳を高めるために、その益を図って彼らを喜ばすべきである。</span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 69:9; ピリピ人への手紙 2:8; ヨハネによる福音書 4:34"> キリストさえ、ご自身を喜ばせることはなさらなかった。むしろ「あなたをそしる者のそしりが、わたしに降りかかった」と書いてあるとおりであった。</span>
<span className="v" id="v4" data-v="4" data-xref="コリント人への第一の手紙 10:11; テモテヘの第二の手紙 3:16–17; ローマ人への手紙 4:23–24"> これまでに書かれた事がらは、すべてわたしたちの教のために書かれたのであって、それは聖書の与える忍耐と慰めとによって、望みをいだかせるためである。</span>
<span className="v" id="v5" data-v="5" data-xref="ピリピ人への手紙 2:4–5; ペテロの第一の手紙 3:8; ローマ人への手紙 12:16"> どうか、忍耐と慰めとの神が、あなたがたに、キリスト・イエスにならって互に同じ思いをいだかせ、</span>
<span className="v" id="v6" data-v="6" data-xref="ヨハネによる福音書 10:29–30; ヨハネの黙示録 1:6; エペソ人への手紙 1:3"> こうして、心を一つにし、声を合わせて、わたしたちの主イエス・キリストの父なる神をあがめさせて下さるように。</span>
</div>
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="マタイによる福音書 10:40; ヨハネによる福音書 13:34; ローマ人への手紙 5:2"> こういうわけで、キリストもわたしたちを受けいれて下さったように、あなたがたも互に受けいれて、神の栄光をあらわすべきである。</span>
<span className="v" id="v8" data-v="8" data-xref="ガラテヤ人への手紙 4:4–5; マタイによる福音書 15:24; ヨハネによる福音書 1:11"> わたしは言う、キリストは神の真実を明らかにするために、割礼のある者の僕となられた。それは父祖たちの受けた約束を保証すると共に、</span>
<span className="v" id="v9" data-v="9" data-xref="サムエル記下 22:50; 詩篇 18:49; ローマ人への手紙 3:29"> 異邦人もあわれみを受けて神をあがめるようになるためである、<br /><span className="pl pl-1">「それゆえ、わたしは、異邦人の中で</span><br /><span className="pl pl-1">あなたにさんびをささげ、</span><br /><span className="pl pl-1">また、御名をほめ歌う」</span><br />と書いてあるとおりである。</span>
</div>
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="詩篇 67:3–4; 申命記 32:43; イザヤ書 42:10–12"> また、こう言っている、<br /><span className="pl pl-1">「異邦人よ、主の民と共に喜べ」。</span></span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 117:1"> <span className="pl pl-1">また、</span><br /><span className="pl pl-1">「すべての異邦人よ、主をほめまつれ。</span><br /><span className="pl pl-1">もろもろの民よ、主をほめたたえよ」。</span></span>
<span className="v" id="v12" data-v="12" data-xref="イザヤ書 11:10; イザヤ書 11:1; マタイによる福音書 12:21"> <span className="pl pl-1">またイザヤは言っている、</span><br /><span className="pl pl-1">「エッサイの根から芽が出て、</span><br /><span className="pl pl-1">異邦人を治めるために立ち上がる者が来る。</span><br /><span className="pl pl-1">異邦人は彼に望みをおくであろう」。</span></span>
<span className="v" id="v13" data-v="13" data-xref="テサロニケ人への第二の手紙 2:16–17; ローマ人への手紙 12:12; コリント人への第二の手紙 9:8"> <span className="pl pl-1">どうか、望みの神が、信仰から来るあらゆる喜びと平安とを、あなたがたに満たし、聖霊の力によって、あなたがたを、望みにあふれさせて下さるように。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="コロサイ人への手紙 3:16; ペテロの第二の手紙 1:12; ヨハネの第一の手紙 2:21"> さて、わたしの兄弟たちよ。あなたがた自身が、善意にあふれ、あらゆる知恵に満たされ、そして互に訓戒し合う力のあることを、わたしは堅く信じている。</span>
<span className="v" id="v15" data-v="15" data-xref="ローマ人への手紙 12:3; コリント人への第一の手紙 15:10; ローマ人への手紙 1:5"> しかし、わたしはあなたがたの記憶を新たにするために、ところどころ、かなり思いきって書いた。それは、神からわたしに賜わった恵みによって、書いたのである。</span>
<span className="v" id="v16" data-v="16" data-xref="ローマ人への手紙 11:13; ローマ人への手紙 1:1; 使徒行伝 9:15"> このように恵みを受けたのは、わたしが異邦人のためにキリスト・イエスに仕える者となり、神の福音のために祭司の役を勤め、こうして異邦人を、聖霊によってきよめられた、御旨にかなうささげ物とするためである。</span>
<span className="v" id="v17" data-v="17" data-xref="コリント人への第二の手紙 2:14–16; コリント人への第二の手紙 12:11–21; ヘブル人への手紙 5:1"> だから、わたしは神への奉仕については、キリスト・イエスにあって誇りうるのである。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行伝 15:12; ローマ人への手紙 1:5; 使徒行伝 21:19"> わたしは、異邦人を従順にするために、キリストがわたしを用いて、言葉とわざ、</span>
<span className="v" id="v19" data-v="19" data-xref="コリント人への第二の手紙 12:12; ヘブル人への手紙 2:4; 使徒行伝 19:11–12"> しるしと不思議との力、聖霊の力によって、働かせて下さったことの外には、あえて何も語ろうとは思わない。こうして、わたしはエルサレムから始まり、巡りめぐってイルリコに至るまで、キリストの福音を満たしてきた。</span>
<span className="v" id="v20" data-v="20" data-xref="コリント人への第二の手紙 10:13–16; コリント人への第一の手紙 3:9–15; エペソ人への手紙 2:20–22"> その際、わたしの切に望んだところは、他人の土台の上に建てることをしないで、キリストの御名がまだ唱えられていない所に福音を宣べ伝えることであった。</span>
<span className="v" id="v21" data-v="21" data-xref="イザヤ書 52:15; イザヤ書 65:1"> すなわち、<br /><span className="pl pl-1">「彼のことを宣べ伝えられていなかった人々が見、</span><br /><span className="pl pl-1">聞いていなかった人々が悟るであろう」</span><br />と書いてあるとおりである。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="ローマ人への手紙 1:13; テサロニケ人への第一の手紙 2:17–18"> こういうわけで、わたしはあなたがたの所に行くことを、たびたび妨げられてきた。</span>
<span className="v" id="v23" data-v="23" data-xref="ローマ人への手紙 15:32; ローマ人への手紙 1:10–12; ローマ人への手紙 15:29"> しかし今では、この地方にはもはや働く余地がなく、かつイスパニヤに赴く場合、あなたがたの所に行くことを、多年、熱望していたので、――</span>
<span className="v" id="v24" data-v="24" data-xref="ローマ人への手紙 15:28; ローマ人への手紙 1:12; 使徒行伝 15:3"> その途中あなたがたに会い、まず幾分でもわたしの願いがあなたがたによって満たされたら、あなたがたに送られてそこへ行くことを、望んでいるのである。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行伝 24:17; 使徒行伝 19:21; 使徒行伝 20:22"> しかし今の場合、聖徒たちに仕えるために、わたしはエルサレムに行こうとしている。</span>
<span className="v" id="v26" data-v="26" data-xref="コリント人への第二の手紙 8:1–9; 使徒行伝 11:27–30; コリント人への第二の手紙 9:2"> なぜなら、マケドニヤとアカヤとの人々は、エルサレムにおる聖徒の中の貧しい人々を援助することに賛成したからである。</span>
<span className="v" id="v27" data-v="27" data-xref="コリント人への第一の手紙 9:11; ガラテヤ人への手紙 6:6; ピレモンヘの手紙 1:19"> たしかに、彼らは賛成した。しかし同時に、彼らはかの人々に負債がある。というのは、もし異邦人が彼らの霊の物にあずかったとすれば、肉の物をもって彼らに仕えるのは、当然だからである。</span>
<span className="v" id="v28" data-v="28" data-xref="ローマ人への手紙 15:24; ピリピ人への手紙 4:17; コロサイ人への手紙 1:6"> そこでわたしは、この仕事を済ませて彼らにこの実を手渡した後、あなたがたの所をとおって、イスパニヤに行こうと思う。</span>
<span className="v" id="v29" data-v="29" data-xref="エペソ人への手紙 4:13; ローマ人への手紙 1:10–12; 詩篇 16:11"> そしてあなたがたの所に行く時には、キリストの満ちあふれる祝福をもって行くことと、信じている。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="コロサイ人への手紙 4:12; コリント人への第二の手紙 1:11; コリント人への第二の手紙 4:11"> 兄弟たちよ。わたしたちの主イエス・キリストにより、かつ御霊の愛によって、あなたがたにお願いする。どうか、共に力をつくして、わたしのために神に祈ってほしい。</span>
<span className="v" id="v31" data-v="31" data-xref="テサロニケ人への第二の手紙 3:2; コリント人への第二の手紙 8:4; コリント人への第二の手紙 9:1"> すなわち、わたしがユダヤにおる不信の徒から救われ、そしてエルサレムに対するわたしの奉仕が聖徒たちに受けいれられるものとなるように、</span>
<span className="v" id="v32" data-v="32" data-xref="コリント人への第一の手紙 16:18; ピレモンヘの手紙 1:20; ピレモンヘの手紙 1:7"> また、神の御旨により、喜びをもってあなたがたの所に行き、共になぐさめ合うことができるように祈ってもらいたい。</span>
<span className="v" id="v33" data-v="33" data-xref="コリント人への第二の手紙 13:11; ピリピ人への手紙 4:9; テサロニケ人への第一の手紙 5:23"> どうか、平和の神があなたがた一同と共にいますように、アァメン。</span>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="イザヤ書 32:17; ローマ人への手紙 15:13; ヨハネによる福音書 16:33"> このように、わたしたちは、信仰によって義とされたのだから、わたしたちの主イエス・キリストにより、神に対して平和を得ている。</span>
<span className="v" id="v2" data-v="2" data-xref="エペソ人への手紙 2:18; エペソ人への手紙 3:12; ローマ人への手紙 12:12"> わたしたちは、さらに彼により、いま立っているこの恵みに信仰によって導き入れられ、そして、神の栄光にあずかる希望をもって喜んでいる。</span>
<span className="v" id="v3" data-v="3" data-xref="ヤコブの手紙 1:2–3; ヤコブの手紙 1:12; ペテロの第一の手紙 3:14"> それだけではなく、患難をも喜んでいる。なぜなら、患難は忍耐を生み出し、</span>
<span className="v" id="v4" data-v="4" data-xref="ペテロの第一の手紙 5:10; ヤコブの手紙 1:12; コリント人への第二の手紙 4:8–12"> 忍耐は錬達を生み出し、錬達は希望を生み出すことを、知っているからである。</span>
<span className="v" id="v5" data-v="5" data-xref="ガラテヤ人への手紙 4:6; エペソ人への手紙 3:16–19; ピリピ人への手紙 1:20"> そして、希望は失望に終ることはない。なぜなら、わたしたちに賜わっている聖霊によって、神の愛がわたしたちの心に注がれているからである。</span>
<span className="v" id="v6" data-v="6" data-xref="エペソ人への手紙 2:1–5; ローマ人への手紙 5:8; コロサイ人への手紙 2:13"> わたしたちがまだ弱かったころ、キリストは、時いたって、不信心な者たちのために死んで下さったのである。</span>
<span className="v" id="v7" data-v="7" data-xref="ヨハネによる福音書 15:13; ヨハネの第一の手紙 3:16; ローマ人への手紙 16:4"> 正しい人のために死ぬ者は、ほとんどいないであろう。善人のためには、進んで死ぬ者もあるいはいるであろう。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨハネによる福音書 15:13; ヨハネによる福音書 3:16; ローマ人への手紙 5:6"> しかし、まだ罪人であった時、わたしたちのためにキリストが死んで下さったことによって、神はわたしたちに対する愛を示されたのである。</span>
<span className="v" id="v9" data-v="9" data-xref="テサロニケ人への第一の手紙 1:10; ローマ人への手紙 8:1; エペソ人への手紙 2:13"> わたしたちは、キリストの血によって今は義とされているのだから、なおさら、彼によって神の怒りから救われるであろう。</span>
<span className="v" id="v10" data-v="10" data-xref="コリント人への第二の手紙 5:18–19; コリント人への第二の手紙 4:10–11; ローマ人への手紙 8:32"> もし、わたしたちが敵であった時でさえ、御子の死によって神との和解を受けたとすれば、和解を受けている今は、なおさら、彼のいのちによって救われるであろう。</span>
<span className="v" id="v11" data-v="11" data-xref="コリント人への第二の手紙 5:18–19; ローマ人への手紙 5:10; イザヤ書 61:10"> そればかりではなく、わたしたちは、今や和解を得させて下さったわたしたちの主イエス・キリストによって、神を喜ぶのである。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="コリント人への第一の手紙 15:21–22; ローマ人への手紙 5:19; ローマ人への手紙 6:23"> このようなわけで、ひとりの人によって、罪がこの世にはいり、また罪によって死がはいってきたように、こうして、すべての人が罪を犯したので、死が全人類にはいり込んだのである。</span>
<span className="v" id="v13" data-v="13" data-xref="ローマ人への手紙 4:15; コリント人への第一の手紙 15:56; ヨハネの第一の手紙 3:4"> というのは、律法以前にも罪は世にあったが、律法がなければ、罪は罪として認められないのである。</span>
<span className="v" id="v14" data-v="14" data-xref="コリント人への第一の手紙 15:45; ローマ人への手紙 5:17; ヘブル人への手紙 9:27"> しかし、アダムからモーセまでの間においても、アダムの違反と同じような罪を犯さなかった者も、死の支配を免れなかった。このアダムは、きたるべき者の型である。</span>
<span className="v" id="v15" data-v="15" data-xref="ローマ人への手紙 6:23; エペソ人への手紙 2:8; ローマ人への手紙 5:12"> しかし、恵みの賜物は罪過の場合とは異なっている。すなわち、もしひとりの罪過のために多くの人が死んだとすれば、まして、神の恵みと、ひとりの人イエス・キリストの恵みによる賜物とは、さらに豊かに多くの人々に満ちあふれたはずではないか。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行伝 13:38–39; イザヤ書 1:18; イザヤ書 44:22"> かつ、この賜物は、ひとりの犯した罪の結果とは異なっている。なぜなら、さばきの場合は、ひとりの罪過から、罪に定めることになったが、恵みの場合には、多くの人の罪過から、義とする結果になるからである。</span>
<span className="v" id="v17" data-v="17" data-xref="コリント人への第一の手紙 15:21–22; コリント人への第一の手紙 15:49; ローマ人への手紙 5:12"> もし、ひとりの罪過によって、そのひとりをとおして死が支配するに至ったとすれば、まして、あふれるばかりの恵みと義の賜物とを受けている者たちは、ひとりのイエス・キリストをとおし、いのちにあって、さらに力強く支配するはずではないか。</span>
<span className="v" id="v18" data-v="18" data-xref="コリント人への第一の手紙 15:22; ローマ人への手紙 5:12; ローマ人への手紙 5:15"> このようなわけで、ひとりの罪過によってすべての人が罪に定められたように、ひとりの義なる行為によって、いのちを得させる義がすべての人に及ぶのである。</span>
<span className="v" id="v19" data-v="19" data-xref="ローマ人への手紙 5:18; コリント人への第二の手紙 5:21; ピリピ人への手紙 2:8"> すなわち、ひとりの人の不従順によって、多くの人が罪人とされたと同じように、ひとりの従順によって、多くの人が義人とされるのである。</span>
<span className="v" id="v20" data-v="20" data-xref="ローマ人への手紙 6:1; テトスヘの手紙 3:3–7; ローマ人への手紙 6:14"> 律法がはいり込んできたのは、罪過の増し加わるためである。しかし、罪の増し加わったところには、恵みもますます満ちあふれた。</span>
<span className="v" id="v21" data-v="21" data-xref="テトスヘの手紙 2:11; ローマ人への手紙 5:14; ローマ人への手紙 8:10"> それは、罪が死によって支配するに至ったように、恵みもまた義によって支配し、わたしたちの主イエス・キリストにより、永遠のいのちを得させるためである。</span>

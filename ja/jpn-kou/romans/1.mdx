<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行伝 9:15; ローマ人への手紙 15:16; コリント人への第一の手紙 1:1"> キリスト・イエスの僕、神の福音のために選び別たれ、召されて使徒となったパウロから――</span>
<span className="v" id="v2" data-v="2" data-xref="テトスヘの手紙 1:2; ルカによる福音書 1:70; ローマ人への手紙 3:21"> この福音は、神が、預言者たちにより、聖書の中で、あらかじめ約束されたものであって、</span>
<span className="v" id="v3" data-v="3" data-xref="マタイによる福音書 1:1; ガラテヤ人への手紙 4:4; エレミヤ書 23:5–6"> 御子に関するものである。御子は、肉によればダビデの子孫から生れ、</span>
<span className="v" id="v4" data-v="4" data-xref="ヘブル人への手紙 9:14; ヘブル人への手紙 5:5–6; エペソ人への手紙 1:19–23"> 聖なる霊によれば、死人からの復活により、御力をもって神の御子と定められた。これがわたしたちの主イエス・キリストである。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行伝 9:15; ローマ人への手紙 16:26; 使徒行伝 6:7"> わたしたちは、その御名のために、すべての異邦人を信仰の従順に至らせるようにと、彼によって恵みと使徒の務とを受けたのであり、</span>
<span className="v" id="v6" data-v="6" data-xref="ペテロの第一の手紙 2:9; ヨハネの黙示録 17:14; ペテロの第二の手紙 1:10"> あなたがたもまた、彼らの中にあって、召されてイエス・キリストに属する者となったのである――</span>
<span className="v" id="v7" data-v="7" data-xref="コロサイ人への手紙 1:2; ユダの手紙 1:1–2; エペソ人への手紙 1:2"> ローマにいる、神に愛され、召された聖徒一同へ。<br />わたしたちの父なる神および主イエス・キリストから、恵みと平安とが、あなたがたにあるように。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="ローマ人への手紙 16:19; コリント人への第一の手紙 1:4; テサロニケ人への第一の手紙 1:8–9"> まず第一に、わたしは、あなたがたの信仰が全世界に言い伝えられていることを、イエス・キリストによって、あなたがた一同のために、わたしの神に感謝する。</span>
<span className="v" id="v9" data-v="9" data-xref="エペソ人への手紙 6:18; テモテヘの第二の手紙 1:3; エペソ人への手紙 1:16–19"> わたしは、祈のたびごとに、絶えずあなたがたを覚え、いつかは御旨にかなって道が開かれ、どうにかして、あなたがたの所に行けるようにと願っている。このことについて、わたしのためにあかしをして下さるのは、わたしが霊により、御子の福音を宣べ伝えて仕えている神である。</span>
<span className="v" id="v11" data-v="11" data-xref="ペテロの第二の手紙 1:12; ローマ人への手紙 16:25; ローマ人への手紙 15:29"> わたしは、あなたがたに会うことを熱望している。あなたがたに霊の賜物を幾分でも分け与えて、力づけたいからである。</span>
<span className="v" id="v12" data-v="12" data-xref="テサロニケ人への第一の手紙 3:7–10; ヨハネの第三の手紙 1:3–4; コリント人への第二の手紙 7:13"> それは、あなたがたの中にいて、あなたがたとわたしとのお互の信仰によって、共に励まし合うためにほかならない。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行伝 19:21; ピリピ人への手紙 4:17; テモテヘの第二の手紙 4:17"> 兄弟たちよ。このことを知らずにいてもらいたくない。わたしはほかの異邦人の間で得たように、あなたがたの間でも幾分かの実を得るために、あなたがたの所に行こうとしばしば企てたが、今まで妨げられてきた。</span>
<span className="v" id="v14" data-v="14" data-xref="コリント人への第一の手紙 9:16–23; 使徒行伝 9:15; コロサイ人への手紙 3:11"> わたしには、ギリシヤ人にも未開の人にも、賢い者にも無知な者にも、果すべき責任がある。</span>
<span className="v" id="v15" data-v="15" data-xref="ローマ人への手紙 15:20; イザヤ書 6:8; コリント人への第一の手紙 9:17"> そこで、わたしとしての切なる願いは、ローマにいるあなたがたにも、福音を宣べ伝えることなのである。</span>
<span className="v" id="v16" data-v="16" data-xref="マルコによる福音書 8:38; テモテヘの第二の手紙 1:8; ペテロの第一の手紙 4:16"> わたしは福音を恥としない。それは、ユダヤ人をはじめ、ギリシヤ人にも、すべて信じる者に、救を得させる神の力である。</span>
<span className="v" id="v17" data-v="17" data-xref="ハバクク書 2:4; ガラテヤ人への手紙 3:11; ヘブル人への手紙 10:38"> 神の義は、その福音の中に啓示され、信仰に始まり信仰に至らせる。これは、「信仰による義人は生きる」と書いてあるとおりである。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="エペソ人への手紙 5:6; テモテヘの第一の手紙 4:1–2; ローマ人への手紙 1:32"> 神の怒りは、不義をもって真理をはばもうとする人間のあらゆる不信心と不義とに対して、天から啓示される。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行伝 14:16–17; 詩篇 19:1–6; ローマ人への手紙 1:20"> なぜなら、神について知りうる事がらは、彼らには明らかであり、神がそれを彼らに明らかにされたのである。</span>
<span className="v" id="v20" data-v="20" data-xref="ローマ人への手紙 1:19; イザヤ書 40:26; 詩篇 19:1–6"> 神の見えない性質、すなわち、神の永遠の力と神性とは、天地創造このかた、被造物において知られていて、明らかに認められるからである。したがって、彼らには弁解の余地がない。</span>
<span className="v" id="v21" data-v="21" data-xref="エペソ人への手紙 4:17–18; 列王紀下 17:15; エレミヤ書 2:5"> なぜなら、彼らは神を知っていながら、神としてあがめず、感謝もせず、かえってその思いはむなしくなり、その無知な心は暗くなったからである。</span>
<span className="v" id="v22" data-v="22" data-xref="コリント人への第一の手紙 1:19–21; ローマ人への手紙 11:25; 箴言 26:12"> 彼らは自ら知者と称しながら、愚かになり、</span>
<span className="v" id="v23" data-v="23" data-xref="詩篇 106:20; エレミヤ書 2:11; 使徒行伝 17:29"> 不朽の神の栄光を変えて、朽ちる人間や鳥や獣や這うものの像に似せたのである。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="詩篇 81:11–12; 使徒行伝 7:42; 使徒行伝 14:16"> ゆえに、神は、彼らが心の欲情にかられ、自分のからだを互にはずかしめて、汚すままに任せられた。</span>
<span className="v" id="v25" data-v="25" data-xref="ハバクク書 2:18; エレミヤ書 13:25; ヨハネの第一の手紙 2:15–16"> 彼らは神の真理を変えて虚偽とし、創造者の代りに被造物を拝み、これに仕えたのである。創造者こそ永遠にほむべきものである、アァメン。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="ユダの手紙 1:7; テモテヘの第一の手紙 1:10; ローマ人への手紙 1:24"> それゆえ、神は彼らを恥ずべき情欲に任せられた。すなわち、彼らの中の女は、その自然の関係を不自然なものに代え、</span>
<span className="v" id="v27" data-v="27" data-xref="レビ記 20:13; レビ記 18:22; ローマ人への手紙 1:23–24"> 男もまた同じように女との自然の関係を捨てて、互にその情欲の炎を燃やし、男は男に対して恥ずべきことをなし、そしてその乱行の当然の報いを、身に受けたのである。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="テサロニケ人への第二の手紙 2:10–12; ローマ人への手紙 1:21; テトスヘの手紙 1:16"> そして、彼らは神を認めることを正しいとしなかったので、神は彼らを正しからぬ思いにわたし、なすべからざる事をなすに任せられた。</span>
<span className="v" id="v29" data-v="29" data-xref="コリント人への第二の手紙 12:20; 箴言 16:28; 詩篇 41:7"> すなわち、彼らは、あらゆる不義と悪と貪欲と悪意とにあふれ、ねたみと殺意と争いと詐欺と悪念とに満ち、また、ざん言する者、</span>
<span className="v" id="v30" data-v="30" data-xref="テモテヘの第二の手紙 3:2; ユダの手紙 1:16; ペテロの第二の手紙 2:18"> そしる者、神を憎む者、不遜な者、高慢な者、大言壮語する者、悪事をたくらむ者、親に逆らう者となり、</span>
<span className="v" id="v31" data-v="31" data-xref="テモテヘの第二の手紙 3:3; 箴言 18:2; ローマ人への手紙 3:11"> 無知、不誠実、無情、無慈悲な者となっている。</span>
<span className="v" id="v32" data-v="32" data-xref="ローマ人への手紙 2:1–5; ローマ人への手紙 1:21; ローマ人への手紙 6:21"> 彼らは、こうした事を行う者どもが死に価するという神の定めをよく知りながら、自らそれを行うばかりではなく、それを行う者どもを是認さえしている。</span>
</div>

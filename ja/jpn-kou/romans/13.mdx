<span className="v" id="v1" data-v="1" data-xref="テトスヘの手紙 3:1; ペテロの第一の手紙 2:13–17; ダニエル書 2:21"> すべての人は、上に立つ権威に従うべきである。なぜなら、神によらない権威はなく、おおよそ存在している権威は、すべて神によって立てられたものだからである。</span>
<span className="v" id="v2" data-v="2" data-xref="ペテロの第一の手紙 2:13; テトスヘの手紙 3:1; ローマ人への手紙 13:5"> したがって、権威に逆らう者は、神の定めにそむく者である。そむく者は、自分の身にさばきを招くことになる。</span>
<span className="v" id="v3" data-v="3" data-xref="伝道の書 10:4–6; ペテロの第一の手紙 2:13–14; 箴言 20:2"> いったい、支配者たちは、善事をする者には恐怖でなく、悪事をする者にこそ恐怖である。あなたは権威を恐れないことを願うのか。それでは、善事をするがよい。そうすれば、彼からほめられるであろう。</span>
<span className="v" id="v4" data-v="4" data-xref="ローマ人への手紙 12:19; 歴代志下 19:6; 箴言 16:14"> 彼は、あなたに益を与えるための神の僕なのである。しかし、もしあなたが悪事をすれば、恐れなければならない。彼はいたずらに剣を帯びているのではない。彼は神の僕であって、悪事を行う者に対しては、怒りをもって報いるからである。</span>
<span className="v" id="v5" data-v="5" data-xref="伝道の書 8:2; 使徒行伝 24:16; ペテロの第一の手紙 2:19"> だから、ただ怒りをのがれるためだけではなく、良心のためにも従うべきである。</span>
<span className="v" id="v6" data-v="6" data-xref="マタイによる福音書 22:17–21; マルコによる福音書 12:14–17; マタイによる福音書 17:24–27"> あなたがたが貢を納めるのも、また同じ理由からである。彼らは神に仕える者として、もっぱらこの務に携わっているのである。</span>
<span className="v" id="v7" data-v="7" data-xref="箴言 24:21; ペテロの第一の手紙 2:17–18; ルカによる福音書 20:25"> あなたがたは、彼らすべてに対して、義務を果しなさい。すなわち、貢を納むべき者には貢を納め、税を納むべき者には税を納め、恐るべき者は恐れ、敬うべき者は敬いなさい。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="ローマ人への手紙 13:10; マタイによる福音書 22:39–40; ガラテヤ人への手紙 5:14"> 互に愛し合うことの外は、何人にも借りがあってはならない。人を愛する者は、律法を全うするのである。</span>
<span className="v" id="v9" data-v="9" data-xref="出エジプト記 20:12–17; マタイによる福音書 22:39; ルカによる福音書 10:27"> 「姦淫するな、殺すな、盗むな、むさぼるな」など、そのほかに、どんな戒めがあっても、結局「自分を愛するようにあなたの隣り人を愛せよ」というこの言葉に帰する。</span>
<span className="v" id="v10" data-v="10" data-xref="マタイによる福音書 22:39–40; ローマ人への手紙 13:8; コリント人への第一の手紙 13:4–7"> 愛は隣り人に害を加えることはない。だから、愛は律法を完成するものである。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="テサロニケ人への第一の手紙 5:5–8; ペテロの第一の手紙 4:7; エペソ人への手紙 5:14"> なお、あなたがたは時を知っているのだから、特に、この事を励まねばならない。すなわち、あなたがたの眠りからさめるべき時が、すでにきている。なぜなら今は、わたしたちの救が、初め信じた時よりも、もっと近づいているからである。</span>
<span className="v" id="v12" data-v="12" data-xref="エゼキエル書 18:31–32; エペソ人への手紙 5:11; コリント人への第二の手紙 6:7"> 夜はふけ、日が近づいている。それだから、わたしたちは、やみのわざを捨てて、光の武具を着けようではないか。</span>
<span className="v" id="v13" data-v="13" data-xref="ガラテヤ人への手紙 5:21; エペソ人への手紙 5:18; テサロニケ人への第一の手紙 4:3–5"> そして、宴楽と泥酔、淫乱と好色、争いとねたみを捨てて、昼歩くように、つつましく歩こうではないか。</span>
<span className="v" id="v14" data-v="14" data-xref="エペソ人への手紙 4:24; ガラテヤ人への手紙 5:16–17; ガラテヤ人への手紙 3:27"> あなたがたは、主イエス・キリストを着なさい。肉の欲を満たすことに心を向けてはならない。</span>
</div>

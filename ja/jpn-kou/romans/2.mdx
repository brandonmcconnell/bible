<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ルカによる福音書 6:37; ローマ人への手紙 2:3; ヨハネによる福音書 8:7–9"> だから、ああ、すべて人をさばく者よ。あなたには弁解の余地がない。あなたは、他人をさばくことによって、自分自身を罪に定めている。さばくあなたも、同じことを行っているからである。</span>
<span className="v" id="v2" data-v="2" data-xref="詩篇 9:7–8; ゼパニヤ書 3:5; 詩篇 145:17"> わたしたちは、神のさばきが、このような事を行う者どもの上に正しく下ることを、知っている。</span>
<span className="v" id="v3" data-v="3" data-xref="箴言 16:5; ルカによる福音書 12:14; ローマ人への手紙 1:32–1"> ああ、このような事を行う者どもをさばきながら、しかも自ら同じことを行う人よ。あなたは、神のさばきをのがれうると思うのか。</span>
<span className="v" id="v4" data-v="4" data-xref="ペテロの第二の手紙 3:9; イザヤ書 30:18; 出エジプト記 34:6"> それとも、神の慈愛があなたを悔改めに導くことも知らないで、その慈愛と忍耐と寛容との富を軽んじるのか。</span>
<span className="v" id="v5" data-v="5" data-xref="伝道の書 12:14; ローマ人への手紙 1:18; ローマ人への手紙 2:2–3"> あなたのかたくなな、悔改めのない心のゆえに、あなたは、神の正しいさばきの現れる怒りの日のために神の怒りを、自分の身に積んでいるのである。</span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 62:12; エレミヤ書 32:19; マタイによる福音書 16:27"> 神は、おのおのに、そのわざにしたがって報いられる。</span>
<span className="v" id="v7" data-v="7" data-xref="テモテヘの第二の手紙 4:7–8; ルカによる福音書 8:15; テモテヘの第二の手紙 1:10"> すなわち、一方では、耐え忍んで善を行って、光栄とほまれと朽ちぬものとを求める人に、永遠のいのちが与えられ、</span>
<span className="v" id="v8" data-v="8" data-xref="ヨハネによる福音書 3:18–21; テサロニケ人への第二の手紙 1:8; テモテヘの第一の手紙 6:3–4"> 他方では、党派心をいだき、真理に従わないで不義に従う人に、怒りと激しい憤りとが加えられる。</span>
<span className="v" id="v9" data-v="9" data-xref="ペテロの第一の手紙 4:17; エゼキエル書 18:4; ローマ人への手紙 1:16"> 悪を行うすべての人には、ユダヤ人をはじめギリシヤ人にも、患難と苦悩とが与えられ、</span>
<span className="v" id="v10" data-v="10" data-xref="イザヤ書 32:17; イザヤ書 26:12; 民数記 6:26"> 善を行うすべての人には、ユダヤ人をはじめギリシヤ人にも、光栄とほまれと平安とが与えられる。</span>
<span className="v" id="v11" data-v="11" data-xref="申命記 10:17; 使徒行伝 10:34; 歴代志下 19:7"> なぜなら、神には、かたより見ることがないからである。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="コリント人への第一の手紙 9:21; ガラテヤ人への手紙 3:10; ガラテヤ人への手紙 2:16–19"> そのわけは、律法なしに罪を犯した者は、また律法なしに滅び、律法のもとで罪を犯した者は、律法によってさばかれる。</span>
<span className="v" id="v13" data-v="13" data-xref="ヤコブの手紙 1:22–25; ヨハネの第一の手紙 3:7; ヤコブの手紙 2:21–25"> なぜなら、律法を聞く者が、神の前に義なるものではなく、律法を行う者が、義とされるからである。</span>
<span className="v" id="v14" data-v="14" data-xref="ローマ人への手紙 2:12; ローマ人への手紙 1:19–20; ローマ人への手紙 2:27"> すなわち、律法を持たない異邦人が、自然のままで、律法の命じる事を行うなら、たとい律法を持たなくても、彼らにとっては自分自身が律法なのである。</span>
<span className="v" id="v15" data-v="15" data-xref="コリント人への第二の手紙 5:11; コリント人への第二の手紙 1:12; ローマ人への手紙 1:18–19"> 彼らは律法の要求がその心にしるされていることを現し、そのことを彼らの良心も共にあかしをして、その判断が互にあるいは訴え、あるいは弁明し合うのである。</span>
<span className="v" id="v16" data-v="16" data-xref="伝道の書 12:14; コリント人への第一の手紙 4:5; 使徒行伝 17:31"> そして、これらのことは、わたしの福音によれば、神がキリスト・イエスによって人々の隠れた事がらをさばかれるその日に、明らかにされるであろう。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="ローマ人への手紙 2:23; ミカ書 3:11; イザヤ書 48:1–2"> もしあなたが、自らユダヤ人と称し、律法に安んじ、神を誇とし、</span>
<span className="v" id="v18" data-v="18" data-xref="テサロニケ人への第一の手紙 5:21; 申命記 4:8; ヤコブの手紙 4:17"> 御旨を知り、律法に教えられて、なすべきことをわきまえており、</span>
<span className="v" id="v19" data-v="19" data-xref="ヨハネの黙示録 3:17–18; マタイによる福音書 15:14; イザヤ書 49:6"> さらに、知識と真理とが律法の中に形をとっているとして、自ら盲人の手引き、やみにおる者の光、愚かな者の導き手、幼な子の教師をもって任じているのなら、</span>
<span className="v" id="v21" data-v="21" data-xref="コリント人への第一の手紙 9:27; マタイによる福音書 23:3–28; ルカによる福音書 12:47"> なぜ、人を教えて自分を教えないのか。盗むなと人に説いて、自らは盗むのか。</span>
<span className="v" id="v22" data-v="22" data-xref="マラキ書 3:8; マタイによる福音書 12:39; マルコによる福音書 11:17"> 姦淫するなと言って、自らは姦淫するのか。偶像を忌みきらいながら、自らは宮の物をかすめるのか。</span>
<span className="v" id="v23" data-v="23" data-xref="ヤコブの手紙 4:16–17; ローマ人への手紙 2:17; ローマ人への手紙 3:2"> 律法を誇としながら、自らは律法に違反して、神を侮っているのか。</span>
<span className="v" id="v24" data-v="24" data-xref="エゼキエル書 36:20–23; イザヤ書 52:5; ペテロの第二の手紙 2:2"> 聖書に書いてあるとおり、「神の御名は、あなたがたのゆえに、異邦人の間で汚されている」。</span>
<span className="v" id="v25" data-v="25" data-xref="エレミヤ書 4:4; ガラテヤ人への手紙 5:3–6; 使徒行伝 7:51"> もし、あなたが律法を行うなら、なるほど、割礼は役に立とう。しかし、もし律法を犯すなら、あなたの割礼は無割礼となってしまう。</span>
<span className="v" id="v26" data-v="26" data-xref="コロサイ人への手紙 2:11; コリント人への第一の手紙 7:18–19; ローマ人への手紙 8:4"> だから、もし無割礼の者が律法の規定を守るなら、その無割礼は割礼と見なされるではないか。</span>
<span className="v" id="v27" data-v="27" data-xref="マタイによる福音書 12:41–42; ローマ人への手紙 2:29; コリント人への第二の手紙 3:6"> かつ、生れながら無割礼の者であって律法を全うする者は、律法の文字と割礼とを持ちながら律法を犯しているあなたを、さばくのである。</span>
<span className="v" id="v28" data-v="28" data-xref="ガラテヤ人への手紙 6:15; マタイによる福音書 3:9; ローマ人への手紙 9:6–8"> というのは、外見上のユダヤ人がユダヤ人ではなく、また、外見上の肉における割礼が割礼でもない。</span>
<span className="v" id="v29" data-v="29" data-xref="申命記 30:6; ピリピ人への手紙 3:3; 申命記 10:16"> かえって、隠れたユダヤ人がユダヤ人であり、また、文字によらず霊による心の割礼こそ割礼であって、そのほまれは人からではなく、神から来るのである。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="コロサイ人への手紙 1:2; コリント人への第二の手紙 1:1; コリント人への第一の手紙 1:1–2"> 神の御旨によるキリスト・イエスの使徒パウロから、エペソにいる、キリスト・イエスにあって忠実な聖徒たちへ。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="ローマ人への手紙 1:7; ガラテヤ人への手紙 1:3; テトスヘの手紙 1:4"> わたしたちの父なる神と主イエス・キリストから、恵みと平安とが、あなたがたにあるように。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="ペテロの第一の手紙 1:3; コリント人への第二の手紙 1:3; エペソ人への手紙 2:6"> ほむべきかな、わたしたちの主イエス・キリストの父なる神。神はキリストにあって、天上で霊のもろもろの祝福をもって、わたしたちを祝福し、</span>
<span className="v" id="v4" data-v="4" data-xref="テモテヘの第二の手紙 1:9; ローマ人への手紙 8:28–30; エペソ人への手紙 2:10"> みまえにきよく傷のない者となるようにと、天地の造られる前から、キリストにあってわたしたちを選び、</span>
<span className="v" id="v5" data-v="5" data-xref="ローマ人への手紙 8:29–30; エペソ人への手紙 1:11; ガラテヤ人への手紙 4:5–6"> わたしたちに、イエス・キリストによって神の子たる身分を授けるようにと、御旨のよしとするところに従い、愛のうちにあらかじめ定めて下さったのである。</span>
<span className="v" id="v6" data-v="6" data-xref="ローマ人への手紙 3:22–26; エペソ人への手紙 1:12; コロサイ人への手紙 1:13"> これは、その愛する御子によって賜わった栄光ある恵みを、わたしたちがほめたたえるためである。</span>
<span className="v" id="v7" data-v="7" data-xref="ペテロの第一の手紙 2:24; ローマ人への手紙 3:24; ヨハネの第一の手紙 1:7–9"> わたしたちは、御子にあって、神の豊かな恵みのゆえに、その血によるあがない、すなわち、罪過のゆるしを受けたのである。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨハネの黙示録 5:12; エペソ人への手紙 3:10; ローマ人への手紙 5:15"> 神はその恵みをさらに増し加えて、あらゆる知恵と悟りとをわたしたちに賜わり、</span>
<span className="v" id="v9" data-v="9" data-xref="コロサイ人への手紙 1:26–28; ローマ人への手紙 16:25–27; エペソ人への手紙 3:3–9"> 御旨の奥義を、自らあらかじめ定められた計画に従って、わたしたちに示して下さったのである。</span>
<span className="v" id="v10" data-v="10" data-xref="コロサイ人への手紙 1:20; ピリピ人への手紙 2:9–10; ガラテヤ人への手紙 4:4"> それは、時の満ちるに及んで実現されるご計画にほかならない。それによって、神は天にあるもの地にあるものを、ことごとく、キリストにあって一つに帰せしめようとされたのである。</span>
<span className="v" id="v11" data-v="11" data-xref="ローマ人への手紙 8:28; ペテロの第一の手紙 1:4; イザヤ書 46:10–11"> わたしたちは、御旨の欲するままにすべての事をなさるかたの目的の下に、キリストにあってあらかじめ定められ、神の民として選ばれたのである。</span>
<span className="v" id="v12" data-v="12" data-xref="エペソ人への手紙 1:6; エレミヤ書 17:5–7; エペソ人への手紙 1:13–14"> それは、早くからキリストに望みをおいているわたしたちが、神の栄光をほめたたえる者となるためである。</span>
<span className="v" id="v13" data-v="13" data-xref="コリント人への第二の手紙 1:22; エペソ人への手紙 4:30; テモテヘの第二の手紙 2:19"> あなたがたもまた、キリストにあって、真理の言葉、すなわち、あなたがたの救の福音を聞き、また、彼を信じた結果、約束された聖霊の証印をおされたのである。</span>
<span className="v" id="v14" data-v="14" data-xref="コリント人への第二の手紙 1:22; コリント人への第二の手紙 5:5; エペソ人への手紙 4:30"> この聖霊は、わたしたちが神の国をつぐことの保証であって、やがて神につける者が全くあがなわれ、神の栄光をほめたたえるに至るためである。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="ピレモンヘの手紙 1:5; コロサイ人への手紙 1:3–4; テサロニケ人への第二の手紙 1:3"> こういうわけで、わたしも、主イエスに対するあなたがたの信仰と、すべての聖徒に対する愛とを耳にし、</span>
<span className="v" id="v16" data-v="16" data-xref="ローマ人への手紙 1:8–9; コロサイ人への手紙 1:9; コロサイ人への手紙 1:3"> わたしの祈のたびごとにあなたがたを覚えて、絶えずあなたがたのために感謝している。</span>
<span className="v" id="v17" data-v="17" data-xref="イザヤ書 11:2; ヤコブの手紙 3:17–18; コロサイ人への手紙 1:9–10"> どうか、わたしたちの主イエス・キリストの神、栄光の父が、知恵と啓示との霊をあなたがたに賜わって神を認めさせ、</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行伝 26:18; コリント人への第二の手紙 4:6; ルカによる福音書 24:45"> あなたがたの心の目を明らかにして下さるように、そして、あなたがたが神に召されていだいている望みがどんなものであるか、聖徒たちがつぐべき神の国がいかに栄光に富んだものであるか、</span>
<span className="v" id="v19" data-v="19" data-xref="ピリピ人への手紙 2:13; エペソ人への手紙 3:20; コロサイ人への手紙 2:12"> また、神の力強い活動によって働く力が、わたしたち信じる者にとっていかに絶大なものであるかを、あなたがたが知るに至るように、と祈っている。</span>
<span className="v" id="v20" data-v="20" data-xref="ヘブル人への手紙 10:12; マルコによる福音書 16:19; 詩篇 110:1"> 神はその力をキリストのうちに働かせて、彼を死人の中からよみがえらせ、天上においてご自分の右に座せしめ、</span>
<span className="v" id="v21" data-v="21" data-xref="ピリピ人への手紙 2:9–11; コロサイ人への手紙 2:10; コロサイ人への手紙 1:15–16"> 彼を、すべての支配、権威、権力、権勢の上におき、また、この世ばかりでなくきたるべき世においても唱えられる、あらゆる名の上におかれたのである。</span>
<span className="v" id="v22" data-v="22" data-xref="コロサイ人への手紙 1:18; コロサイ人への手紙 2:10; コリント人への第一の手紙 15:25–27"> そして、万物をキリストの足の下に従わせ、彼を万物の上にかしらとして教会に与えられた。</span>
<span className="v" id="v23" data-v="23" data-xref="コロサイ人への手紙 1:18–19; ヨハネによる福音書 1:16; コロサイ人への手紙 2:9–10"> この教会はキリストのからだであって、すべてのものを、すべてのもののうちに満たしているかたが、満ちみちているものに、ほかならない。</span>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="コロサイ人への手紙 1:24; テモテヘの第二の手紙 1:8; ピリピ人への手紙 1:13–16"> こういうわけで、あなたがた異邦人のためにキリスト・イエスの囚人となっているこのパウロ――</span>
<span className="v" id="v2" data-v="2" data-xref="コロサイ人への手紙 1:25–27; テモテヘの第一の手紙 1:11; テモテヘの第二の手紙 1:11"> わたしがあなたがたのために神から賜わった恵みの務について、あなたがたはたしかに聞いたであろう。</span>
<span className="v" id="v3" data-v="3" data-xref="ガラテヤ人への手紙 1:12; ローマ人への手紙 16:25; エペソ人への手紙 1:9–11"> すなわち、すでに簡単に書きおくったように、わたしは啓示によって奥義を知らされたのである。</span>
<span className="v" id="v4" data-v="4" data-xref="コロサイ人への手紙 4:3; コリント人への第一の手紙 4:1; コリント人への第二の手紙 11:6"> あなたがたはそれを読めば、キリストの奥義をわたしがどう理解しているかがわかる。</span>
<span className="v" id="v5" data-v="5" data-xref="ペテロの第一の手紙 1:10–12; ペテロの第二の手紙 3:2; テトスヘの手紙 1:1–3"> この奥義は、いまは、御霊によって彼の聖なる使徒たちと預言者たちとに啓示されているが、前の時代には、人の子らに対して、そのように知らされてはいなかったのである。</span>
<span className="v" id="v6" data-v="6" data-xref="ガラテヤ人への手紙 3:26–29; ヨハネの第一の手紙 1:3; ヨハネの第一の手紙 2:25"> それは、異邦人が、福音によりキリスト・イエスにあって、わたしたちと共に神の国をつぐ者となり、共に一つのからだとなり、共に約束にあずかる者となることである。</span>
<span className="v" id="v7" data-v="7" data-xref="エペソ人への手紙 1:19; エペソ人への手紙 3:20; エペソ人への手紙 3:2"> わたしは、神の力がわたしに働いて、自分に与えられた神の恵みの賜物により、福音の僕とされたのである。</span>
<span className="v" id="v8" data-v="8" data-xref="コロサイ人への手紙 1:27; コリント人への第一の手紙 15:9; エペソ人への手紙 2:7"> すなわち、聖徒たちのうちで最も小さい者であるわたしにこの恵みが与えられたが、それは、キリストの無尽蔵の富を異邦人に宣べ伝え、</span>
<span className="v" id="v9" data-v="9" data-xref="コロサイ人への手紙 1:26; マタイによる福音書 13:35; テモテヘの第二の手紙 1:9"> 更にまた、万物の造り主である神の中に世々隠されていた奥義にあずかる務がどんなものであるかを、明らかに示すためである。</span>
<span className="v" id="v10" data-v="10" data-xref="ペテロの第一の手紙 1:12; エペソ人への手紙 6:12; コリント人への第一の手紙 2:7"> それは今、天上にあるもろもろの支配や権威が、教会をとおして、神の多種多様な知恵を知るに至るためであって、</span>
<span className="v" id="v11" data-v="11" data-xref="テモテヘの第二の手紙 1:9; エペソ人への手紙 1:11; エペソ人への手紙 1:4"> わたしたちの主キリスト・イエスにあって実現された神の永遠の目的にそうものである。</span>
<span className="v" id="v12" data-v="12" data-xref="エペソ人への手紙 2:18; ローマ人への手紙 5:2; ヘブル人への手紙 4:14–16"> この主キリストにあって、わたしたちは、彼に対する信仰によって、確信をもって大胆に神に近づくことができるのである。</span>
<span className="v" id="v13" data-v="13" data-xref="コロサイ人への手紙 1:24; テサロニケ人への第二の手紙 3:13; コリント人への第二の手紙 1:6"> だから、あなたがたのためにわたしが受けている患難を見て、落胆しないでいてもらいたい。わたしの患難は、あなたがたの光栄なのである。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="詩篇 95:6; エペソ人への手紙 1:16–19; ピリピ人への手紙 2:10"> こういうわけで、わたしはひざをかがめて、</span>
<span className="v" id="v15" data-v="15" data-xref="エペソ人への手紙 1:10; ヨハネの黙示録 5:8–14; エペソ人への手紙 1:21"> 天上にあり地上にあって「父」と呼ばれているあらゆるものの源なる父に祈る。</span>
<span className="v" id="v16" data-v="16" data-xref="コロサイ人への手紙 1:11; ピリピ人への手紙 4:13; イザヤ書 40:29–31"> どうか父が、その栄光の富にしたがい、御霊により、力をもってあなたがたの内なる人を強くして下さるように、</span>
<span className="v" id="v17" data-v="17" data-xref="コロサイ人への手紙 2:7; ヨハネの第一の手紙 4:16; ヨハネによる福音書 14:23"> また、信仰によって、キリストがあなたがたの心のうちに住み、あなたがたが愛に根ざし愛を基として生活することにより、</span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 103:11–12; ヨブ記 11:7–9; エペソ人への手紙 1:18–23"> すべての聖徒と共に、その広さ、長さ、高さ、深さを理解することができ、</span>
<span className="v" id="v19" data-v="19" data-xref="エペソ人への手紙 1:23; コロサイ人への手紙 2:9–10; コロサイ人への手紙 1:10"> また人知をはるかに越えたキリストの愛を知って、神に満ちているもののすべてをもって、あなたがたが満たされるように、と祈る。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="コリント人への第二の手紙 9:8; ローマ人への手紙 4:21; エレミヤ書 32:27"> どうか、わたしたちのうちに働く力によって、わたしたちが求めまた思うところのいっさいを、はるかに越えてかなえて下さることができるかたに、</span>
<span className="v" id="v21" data-v="21" data-xref="ユダの手紙 1:25; ローマ人への手紙 11:36; ペテロの第二の手紙 3:18"> 教会により、また、キリスト・イエスによって、栄光が世々限りなくあるように、アァメン。</span>

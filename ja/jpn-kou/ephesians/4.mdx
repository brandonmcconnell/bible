<span className="v" id="v1" data-v="1" data-xref="コロサイ人への手紙 1:10; ピリピ人への手紙 1:27; テサロニケ人への第一の手紙 2:12"> さて、主にある囚人であるわたしは、あなたがたに勧める。あなたがたが召されたその召しにふさわしく歩き、</span>
<span className="v" id="v2" data-v="2" data-xref="コロサイ人への手紙 3:12–13; コリント人への第一の手紙 13:7; コリント人への第一の手紙 13:4–5"> できる限り謙虚で、かつ柔和であり、寛容を示し、愛をもって互に忍びあい、</span>
<span className="v" id="v3" data-v="3" data-xref="コリント人への第一の手紙 1:10; コロサイ人への手紙 3:13–15; コリント人への第一の手紙 12:12–13"> 平和のきずなで結ばれて、聖霊による一致を守り続けるように努めなさい。</span>
<span className="v" id="v4" data-v="4" data-xref="エペソ人への手紙 2:18; ローマ人への手紙 12:4–5; コリント人への第一の手紙 12:4–13"> からだは一つ、御霊も一つである。あなたがたが召されたのは、一つの望みを目ざして召されたのと同様である。</span>
<span className="v" id="v5" data-v="5" data-xref="コリント人への第一の手紙 8:6; コリント人への第一の手紙 12:13; ペテロの第一の手紙 3:21"> 主は一つ、信仰は一つ、バプテスマは一つ。</span>
<span className="v" id="v6" data-v="6" data-xref="ローマ人への手紙 11:36; マラキ書 2:10; コリント人への第一の手紙 8:6"> すべてのものの上にあり、すべてのものを貫き、すべてのものの内にいます、すべてのものの父なる神は一つである。</span>
<span className="v" id="v7" data-v="7" data-xref="ペテロの第一の手紙 4:10; ローマ人への手紙 12:3; コリント人への第一の手紙 12:7–11"> しかし、キリストから賜わる賜物のはかりに従って、わたしたちひとりびとりに、恵みが与えられている。</span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 68:18; コロサイ人への手紙 2:15; サムエル記上 30:26"> そこで、こう言われている、<br /><span className="pl pl-1">「彼は高いところに上った時、</span><br /><span className="pl pl-1">とりこを捕えて引き行き、</span><br /><span className="pl pl-1">人々に賜物を分け与えた」。</span></span>
<span className="v" id="v9" data-v="9" data-xref="ヨハネによる福音書 3:13; マタイによる福音書 12:40; 箴言 30:4"> <span className="pl pl-1">さて「上った」と言う以上、また地下の低い底にも降りてこられたわけではないか。</span></span>
<span className="v" id="v10" data-v="10" data-xref="ヘブル人への手紙 7:26; ヘブル人への手紙 4:14; エペソ人への手紙 1:20–23"> <span className="pl pl-1">降りてこられた者自身は、同時に、あらゆるものに満ちるために、もろもろの天の上にまで上られたかたなのである。</span></span>
<span className="v" id="v11" data-v="11" data-xref="エレミヤ書 3:15; コリント人への第一の手紙 12:28–29; エペソ人への手紙 2:20"> <span className="pl pl-1">そして彼は、ある人を使徒とし、ある人を預言者とし、ある人を伝道者とし、ある人を牧師、教師として、お立てになった。</span></span>
<span className="v" id="v12" data-v="12" data-xref="テサロニケ人への第一の手紙 5:11–14; エペソ人への手紙 4:16; コリント人への第一の手紙 12:27"> <span className="pl pl-1">それは、聖徒たちをととのえて奉仕のわざをさせ、キリストのからだを建てさせ、</span></span>
<span className="v" id="v13" data-v="13" data-xref="コロサイ人への手紙 1:28; ヨハネによる福音書 17:21; エペソ人への手紙 4:5"> <span className="pl pl-1">わたしたちすべての者が、神の子を信じる信仰の一致と彼を知る知識の一致とに到達し、全き人となり、ついに、キリストの満ちみちた徳の高さにまで至るためである。</span></span>
<span className="v" id="v14" data-v="14" data-xref="ヘブル人への手紙 13:9; ローマ人への手紙 16:17–18; コリント人への第一の手紙 14:20"> <span className="pl pl-1">こうして、わたしたちはもはや子供ではないので、だまし惑わす策略により、人々の悪巧みによって起る様々な教の風に吹きまわされたり、もてあそばれたりすることがなく、</span></span>
<span className="v" id="v15" data-v="15" data-xref="ヨハネの第一の手紙 3:18; エペソ人への手紙 4:25; ゼカリヤ書 8:16"> <span className="pl pl-1">愛にあって真理を語り、あらゆる点において成長し、かしらなるキリストに達するのである。</span></span>
<span className="v" id="v16" data-v="16" data-xref="コロサイ人への手紙 2:19; ヨハネによる福音書 15:5; コロサイ人への手紙 2:2"> <span className="pl pl-1">また、キリストを基として、全身はすべての節々の助けにより、しっかりと組み合わされ結び合わされ、それぞれの部分は分に応じて働き、からだを成長させ、愛のうちに育てられていくのである。</span></span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="ローマ人への手紙 1:21; ペテロの第一の手紙 4:3–4; テサロニケ人への第一の手紙 4:1–2"> そこで、わたしは主にあっておごそかに勧める。あなたがたは今後、異邦人がむなしい心で歩いているように歩いてはならない。</span>
<span className="v" id="v18" data-v="18" data-xref="マタイによる福音書 13:15; エペソ人への手紙 2:12; ローマ人への手紙 1:21–23"> 彼らの知力は暗くなり、その内なる無知と心の硬化とにより、神のいのちから遠く離れ、</span>
<span className="v" id="v19" data-v="19" data-xref="コロサイ人への手紙 3:5; ローマ人への手紙 1:24–26; テモテヘの第一の手紙 4:2"> 自ら無感覚になって、ほしいままにあらゆる不潔な行いをして、放縦に身をゆだねている。</span>
<span className="v" id="v20" data-v="20" data-xref="テトスヘの手紙 2:11–14; ヨハネによる福音書 6:45; マタイによる福音書 11:29"> しかしあなたがたは、そのようにキリストに学んだのではなかった。</span>
<span className="v" id="v21" data-v="21" data-xref="ヨハネの第一の手紙 5:20; エペソ人への手紙 1:13; ヘブル人への手紙 3:7–8"> あなたがたはたしかに彼に聞き、彼にあって教えられて、イエスにある真理をそのまま学んだはずである。</span>
<span className="v" id="v22" data-v="22" data-xref="ローマ人への手紙 6:6; ヘブル人への手紙 12:1; ヤコブの手紙 1:21"> すなわち、あなたがたは、以前の生活に属する、情欲に迷って滅び行く古き人を脱ぎ捨て、</span>
<span className="v" id="v23" data-v="23" data-xref="ローマ人への手紙 12:2; ローマ人への手紙 8:6; 詩篇 51:10"> 心の深みまで新たにされて、</span>
<span className="v" id="v24" data-v="24" data-xref="コロサイ人への手紙 3:10–14; コリント人への第二の手紙 5:17; エペソ人への手紙 2:10"> 真の義と聖とをそなえた神にかたどって造られた新しき人を着るべきである。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="コロサイ人への手紙 3:9; ゼカリヤ書 8:16; 箴言 12:22"> こういうわけだから、あなたがたは偽りを捨てて、おのおの隣り人に対して、真実を語りなさい。わたしたちは、お互に肢体なのであるから。</span>
<span className="v" id="v26" data-v="26" data-xref="ヤコブの手紙 1:19; 詩篇 4:4; 詩篇 37:8"> 怒ることがあっても、罪を犯してはならない。憤ったままで、日が暮れるようであってはならない。</span>
<span className="v" id="v27" data-v="27" data-xref="ヤコブの手紙 4:7; ペテロの第一の手紙 5:8; エペソ人への手紙 6:16"> また、悪魔に機会を与えてはいけない。</span>
<span className="v" id="v28" data-v="28" data-xref="テモテヘの第一の手紙 6:18; テサロニケ人への第一の手紙 4:11–12; ガラテヤ人への手紙 6:10"> 盗んだ者は、今後、盗んではならない。むしろ、貧しい人々に分け与えるようになるために、自分の手で正当な働きをしなさい。</span>
<span className="v" id="v29" data-v="29" data-xref="コロサイ人への手紙 4:6; テサロニケ人への第一の手紙 5:11; 伝道の書 10:12"> 悪い言葉をいっさい、あなたがたの口から出してはいけない。必要があれば、人の徳を高めるのに役立つような言葉を語って、聞いている者の益になるようにしなさい。</span>
<span className="v" id="v30" data-v="30" data-xref="テサロニケ人への第一の手紙 5:19; イザヤ書 63:10; エペソ人への手紙 1:13–14"> 神の聖霊を悲しませてはいけない。あなたがたは、あがないの日のために、聖霊の証印を受けたのである。</span>
<span className="v" id="v31" data-v="31" data-xref="コロサイ人への手紙 3:8; 伝道の書 7:9; テトスヘの手紙 3:2–3"> すべての無慈悲、憤り、怒り、騒ぎ、そしり、また、いっさいの悪意を捨て去りなさい。</span>
<span className="v" id="v32" data-v="32" data-xref="コロサイ人への手紙 3:12–13; マタイによる福音書 6:14–15; マルコによる福音書 11:25"> 互に情深く、あわれみ深い者となり、神がキリストにあってあなたがたをゆるして下さったように、あなたがたも互にゆるし合いなさい。</span>

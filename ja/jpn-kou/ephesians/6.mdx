<span className="v" id="v1" data-v="1" data-xref="コロサイ人への手紙 3:20–25; 箴言 23:22; 箴言 6:20"> 子たる者よ。主にあって両親に従いなさい。これは正しいことである。</span>
<span className="v" id="v2" data-v="2" data-xref="出エジプト記 20:12; 申命記 27:16; マタイによる福音書 15:4–6"> 「あなたの父と母とを敬え」。これが第一の戒めであって、次の約束がそれについている、</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 5:16; 申命記 4:40; 申命記 12:28"> 「そうすれば、あなたは幸福になり、地上でながく生きながらえるであろう」。</span>
<span className="v" id="v4" data-v="4" data-xref="コロサイ人への手紙 3:21; 箴言 22:6; 箴言 29:15"> 父たる者よ。子供をおこらせないで、主の薫陶と訓戒とによって、彼らを育てなさい。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="ペテロの第一の手紙 2:18–21; テトスヘの手紙 2:9–10; コロサイ人への手紙 3:17–24"> 僕たる者よ。キリストに従うように、恐れおののきつつ、真心をこめて、肉による主人に従いなさい。</span>
<span className="v" id="v6" data-v="6" data-xref="コロサイ人への手紙 3:22–23; テサロニケ人への第一の手紙 2:4; ガラテヤ人への手紙 1:10"> 人にへつらおうとして目先だけの勤めをするのでなく、キリストの僕として心から神の御旨を行い、</span>
<span className="v" id="v7" data-v="7" data-xref="コロサイ人への手紙 3:23; エペソ人への手紙 6:5–6; コリント人への第一の手紙 10:31"> 人にではなく主に仕えるように、快く仕えなさい。</span>
<span className="v" id="v8" data-v="8" data-xref="コロサイ人への手紙 3:24; ルカによる福音書 14:14; 箴言 11:18"> あなたがたが知っているとおり、だれでも良いことを行えば、僕であれ、自由人であれ、それに相当する報いを、それぞれ主から受けるであろう。</span>
<span className="v" id="v9" data-v="9" data-xref="コロサイ人への手紙 3:25–1; 使徒行伝 10:34; ローマ人への手紙 2:11"> 主人たる者よ。僕たちに対して、同様にしなさい。おどすことを、してはならない。あなたがたが知っているとおり、彼らとあなたがたとの主は天にいますのであり、かつ人をかたより見ることをなさらないのである。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="ピリピ人への手紙 4:13; イザヤ書 40:31; ヨシュア記 1:9"> 最後に言う。主にあって、その偉大な力によって、強くなりなさい。</span>
<span className="v" id="v11" data-v="11" data-xref="コリント人への第二の手紙 10:4; ローマ人への手紙 13:12; エペソ人への手紙 6:13"> 悪魔の策略に対抗して立ちうるために、神の武具で身を固めなさい。</span>
<span className="v" id="v12" data-v="12" data-xref="コロサイ人への手紙 1:13; コリント人への第二の手紙 4:4; エペソ人への手紙 2:2"> わたしたちの戦いは、血肉に対するものではなく、もろもろの支配と、権威と、やみの世の主権者、また天上にいる悪の霊に対する戦いである。</span>
<span className="v" id="v13" data-v="13" data-xref="コリント人への第二の手紙 10:4; ルカによる福音書 21:36; エペソ人への手紙 6:11–17"> それだから、悪しき日にあたって、よく抵抗し、完全に勝ち抜いて、堅く立ちうるために、神の武具を身につけなさい。</span>
<span className="v" id="v14" data-v="14" data-xref="イザヤ書 59:17; テサロニケ人への第一の手紙 5:8; イザヤ書 11:5"> すなわち、立って真理の帯を腰にしめ、正義の胸当を胸につけ、</span>
<span className="v" id="v15" data-v="15" data-xref="イザヤ書 52:7; ローマ人への手紙 10:15; コリント人への第二の手紙 5:18–21"> 平和の福音の備えを足にはき、</span>
<span className="v" id="v16" data-v="16" data-xref="ペテロの第一の手紙 5:8–9; ヨハネの第一の手紙 5:4–5; 箴言 18:10"> その上に、信仰のたてを手に取りなさい。それをもって、悪しき者の放つ火の矢を消すことができるであろう。</span>
<span className="v" id="v17" data-v="17" data-xref="ヘブル人への手紙 4:12; イザヤ書 59:17; ヨハネの黙示録 19:15"> また、救のかぶとをかぶり、御霊の剣、すなわち、神の言を取りなさい。</span>
<span className="v" id="v18" data-v="18" data-xref="テサロニケ人への第一の手紙 5:17; コロサイ人への手紙 4:2; ピリピ人への手紙 4:6"> 絶えず祈と願いをし、どんな時でも御霊によって祈り、そのために目をさましてうむことがなく、すべての聖徒のために祈りつづけなさい。</span>
<span className="v" id="v19" data-v="19" data-xref="コロサイ人への手紙 4:3; 使徒行伝 4:29; テサロニケ人への第二の手紙 3:1"> また、わたしが口を開くときに語るべき言葉を賜わり、大胆に福音の奥義を明らかに示しうるように、わたしのためにも祈ってほしい。</span>
<span className="v" id="v20" data-v="20" data-xref="コリント人への第二の手紙 5:20; コロサイ人への手紙 4:4; テモテヘの第二の手紙 2:9"> わたしはこの福音のための使節であり、そして鎖につながれているのであるが、つながれていても、語るべき時には大胆に語れるように祈ってほしい。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="使徒行伝 20:4; テモテヘの第二の手紙 4:12; テトスヘの手紙 3:12"> わたしがどういう様子か、何をしているかを、あなたがたに知ってもらうために、主にあって忠実に仕えている愛する兄弟テキコが、いっさいの事を報告するであろう。</span>
<span className="v" id="v22" data-v="22" data-xref="ピリピ人への手紙 2:25; コロサイ人への手紙 4:7–8; テサロニケ人への第二の手紙 2:17"> 彼をあなたがたのもとに送るのは、あなたがたがわたしたちの様子を知り、また彼によって心に励ましを受けるようになるためなのである。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="ガラテヤ人への手紙 6:16; ガラテヤ人への手紙 5:6; ペテロの第一の手紙 5:14"> 父なる神とわたしたちの主イエス・キリストから平安ならびに信仰に伴う愛が、兄弟たちにあるように。</span>
<span className="v" id="v24" data-v="24" data-xref="マタイによる福音書 22:37; コリント人への第二の手紙 8:12; マタイによる福音書 6:13"> 変らない真実をもって、わたしたちの主イエス・キリストを愛するすべての人々に、恵みがあるように。</span>

<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="ヨハネの第一の手紙 4:11; ペテロの第一の手紙 1:15–16; エペソ人への手紙 4:32"> こうして、あなたがたは、神に愛されている子供として、神にならう者になりなさい。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネによる福音書 13:34; ガラテヤ人への手紙 2:20; コロサイ人への手紙 3:14"> また愛のうちを歩きなさい。キリストもあなたがたを愛して下さって、わたしたちのために、ご自身を、神へのかんばしいかおりのささげ物、また、いけにえとしてささげられたのである。</span>
<span className="v" id="v3" data-v="3" data-xref="コロサイ人への手紙 3:5; エペソ人への手紙 5:5; ガラテヤ人への手紙 5:19–21"> また、不品行といろいろな汚れや貪欲などを、聖徒にふさわしく、あなたがたの間では、口にすることさえしてはならない。</span>
<span className="v" id="v4" data-v="4" data-xref="コロサイ人への手紙 3:8; エペソ人への手紙 4:29; テサロニケ人への第一の手紙 5:18"> また、卑しい言葉と愚かな話やみだらな冗談を避けなさい。これらは、よろしくない事である。それよりは、むしろ感謝をささげなさい。</span>
<span className="v" id="v5" data-v="5" data-xref="ガラテヤ人への手紙 5:21; コリント人への第一の手紙 6:9–10; エペソ人への手紙 5:3"> あなたがたは、よく知っておかねばならない。すべて不品行な者、汚れたことをする者、貪欲な者、すなわち、偶像を礼拝する者は、キリストと神との国をつぐことができない。</span>
<span className="v" id="v6" data-v="6" data-xref="ローマ人への手紙 1:18; コロサイ人への手紙 2:8; マタイによる福音書 24:4"> あなたがたは、だれにも不誠実な言葉でだまされてはいけない。これらのことから、神の怒りは不従順の子らに下るのである。</span>
<span className="v" id="v7" data-v="7" data-xref="ヨハネの黙示録 18:4; エペソ人への手紙 5:11; テモテヘの第一の手紙 5:22"> だから、彼らの仲間になってはいけない。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨハネによる福音書 8:12; ヨハネの第一の手紙 1:7; 使徒行伝 26:18"> あなたがたは、以前はやみであったが、今は主にあって光となっている。光の子らしく歩きなさい――</span>
<span className="v" id="v9" data-v="9" data-xref="ヨハネの第一の手紙 3:9–10; ガラテヤ人への手紙 5:22–23; ヨハネの第三の手紙 1:11"> 光はあらゆる善意と正義と真実との実を結ばせるものである――</span>
<span className="v" id="v10" data-v="10" data-xref="ローマ人への手紙 12:1–2; ヘブル人への手紙 12:28; 詩篇 19:14"> 主に喜ばれるものがなんであるかを、わきまえ知りなさい。</span>
<span className="v" id="v11" data-v="11" data-xref="ローマ人への手紙 13:12; テモテヘの第一の手紙 5:20; テサロニケ人への第二の手紙 3:6"> 実を結ばないやみのわざに加わらないで、むしろ、それを指摘してやりなさい。</span>
<span className="v" id="v12" data-v="12" data-xref="エペソ人への手紙 5:3; エレミヤ書 23:24; 伝道の書 12:14"> 彼らが隠れて行っていることは、口にするだけでも恥ずかしい事である。</span>
<span className="v" id="v13" data-v="13" data-xref="ヨハネによる福音書 3:20–21; コリント人への第一の手紙 4:5; ホセア書 2:10"> しかし、光にさらされる時、すべてのものは、明らかになる。</span>
<span className="v" id="v14" data-v="14" data-xref="イザヤ書 60:1; ローマ人への手紙 13:11–12; イザヤ書 26:19"> 明らかにされたものは皆、光となるのである。だから、こう書いてある、<br /><span className="pl pl-1">「眠っている者よ、起きなさい。</span><br /><span className="pl pl-1">死人のなかから、立ち上がりなさい。</span><br /><span className="pl pl-1">そうすれば、キリストがあなたを照すであろう」。</span></span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="コロサイ人への手紙 4:5; ヤコブの手紙 3:13; ピリピ人への手紙 1:27"> そこで、あなたがたの歩きかたによく注意して、賢くない者のようにではなく、賢い者のように歩き、</span>
<span className="v" id="v16" data-v="16" data-xref="コロサイ人への手紙 4:5; アモス書 5:13; ヨハネによる福音書 12:35"> 今の時を生かして用いなさい。今は悪い時代なのである。</span>
<span className="v" id="v17" data-v="17" data-xref="ローマ人への手紙 12:2; テサロニケ人への第一の手紙 5:18; コロサイ人への手紙 1:9"> だから、愚かな者にならないで、主の御旨がなんであるかを悟りなさい。</span>
<span className="v" id="v18" data-v="18" data-xref="箴言 20:1; ルカによる福音書 1:15; ローマ人への手紙 13:13"> 酒に酔ってはいけない。それは乱行のもとである。むしろ御霊に満たされて、</span>
<span className="v" id="v19" data-v="19" data-xref="コロサイ人への手紙 3:16; コリント人への第一の手紙 14:26; 詩篇 95:2"> 詩とさんびと霊の歌とをもって語り合い、主にむかって心からさんびの歌をうたいなさい。</span>
<span className="v" id="v20" data-v="20" data-xref="コロサイ人への手紙 3:17; テサロニケ人への第一の手紙 5:18; ヘブル人への手紙 13:15"> そしてすべてのことにつき、いつも、わたしたちの主イエス・キリストの御名によって、父なる神に感謝し、</span>
<span className="v" id="v21" data-v="21" data-xref="ピリピ人への手紙 2:3; エペソ人への手紙 5:24; エペソ人への手紙 5:22"> キリストに対する恐れの心をもって、互に仕え合うべきである。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="コロサイ人への手紙 3:18–1; ペテロの第一の手紙 3:1–6; テトスヘの手紙 2:5"> 妻たる者よ。主に仕えるように自分の夫に仕えなさい。</span>
<span className="v" id="v23" data-v="23" data-xref="コリント人への第一の手紙 11:3–10; コロサイ人への手紙 1:18; エペソ人への手紙 1:22–23"> キリストが教会のかしらであって、自らは、からだなる教会の救主であられるように、夫は妻のかしらである。</span>
<span className="v" id="v24" data-v="24" data-xref="エペソ人への手紙 5:33; コロサイ人への手紙 3:20; テトスヘの手紙 2:7"> そして教会がキリストに仕えるように、妻もすべてのことにおいて、夫に仕えるべきである。</span>
<span className="v" id="v25" data-v="25" data-xref="ペテロの第一の手紙 3:7; コロサイ人への手紙 3:19; エペソ人への手紙 5:28"> 夫たる者よ。キリストが教会を愛してそのためにご自身をささげられたように、妻を愛しなさい。</span>
<span className="v" id="v26" data-v="26" data-xref="ヘブル人への手紙 10:22; ヨハネによる福音書 15:3; エゼキエル書 36:25"> キリストがそうなさったのは、水で洗うことにより、言葉によって、教会をきよめて聖なるものとするためであり、</span>
<span className="v" id="v27" data-v="27" data-xref="コロサイ人への手紙 1:22; ヘブル人への手紙 9:14; ペテロの第一の手紙 1:19"> また、しみも、しわも、そのたぐいのものがいっさいなく、清くて傷のない栄光の姿の教会を、ご自分に迎えるためである。</span>
<span className="v" id="v28" data-v="28" data-xref="エペソ人への手紙 5:25; マタイによる福音書 19:5; 創世記 2:21–24"> それと同じく、夫も自分の妻を、自分のからだのように愛さねばならない。自分の妻を愛する者は、自分自身を愛するのである。</span>
<span className="v" id="v29" data-v="29" data-xref="エゼキエル書 34:14–15; エペソ人への手紙 5:31; 伝道の書 4:5"> 自分自身を憎んだ者は、いまだかつて、ひとりもいない。かえって、キリストが教会になさったようにして、おのれを育て養うのが常である。</span>
<span className="v" id="v30" data-v="30" data-xref="コリント人への第一の手紙 6:15; コリント人への第一の手紙 12:12–27; ローマ人への手紙 12:5"> わたしたちは、キリストのからだの肢体なのである。</span>
<span className="v" id="v31" data-v="31" data-xref="創世記 2:24; マタイによる福音書 19:5; マルコによる福音書 10:7–8"> 「それゆえに、人は父母を離れてその妻と結ばれ、ふたりの者は一体となるべきである」。</span>
<span className="v" id="v32" data-v="32" data-xref="ヨハネの黙示録 21:2; コリント人への第二の手紙 11:2; イザヤ書 54:5"> この奥義は大きい。それは、キリストと教会とをさしている。</span>
<span className="v" id="v33" data-v="33" data-xref="ペテロの第一の手紙 3:2–7; エステル記 1:20; エペソ人への手紙 5:25"> いずれにしても、あなたがたは、それぞれ、自分の妻を自分自身のように愛しなさい。妻もまた夫を敬いなさい。</span>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨシュア記 14:1; ヨシュア記 19:51; ヨシュア記 17:4"> 時にレビの族長たちは、祭司エレアザル、ヌンの子ヨシュアおよびイスラエルの部族の族長たちのもとにきて、</span>
<span className="v" id="v2" data-v="2" data-xref="ヨシュア記 18:1; 民数記 35:2–8; マタイによる福音書 10:10"> カナンの地のシロで彼らに言った、「主はかつて、われわれに住むべき町々を与えることと、それに属する放牧地を、家畜のために与えることを、モーセによって命じられました」。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 49:7; 申命記 33:8–10; 歴代志上 6:54–81"> それでイスラエルの人々は、主の命にしたがって、自分たちの嗣業のうちから、次の町々と、その放牧地とを、レビびとに与えた。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="歴代志上 6:54–60; ヨシュア記 24:33; ヨシュア記 21:8–19"> まずコハテびとの氏族のために、くじを引いた。祭司アロンの子孫であるこれらのレビびとは、くじによって、ユダの部族、シメオンの部族、およびベニヤミンの部族のうちから、十三の町を獲た。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="ヨシュア記 21:20–26; 出エジプト記 6:16–25; 歴代志上 6:66–70"> その他のコハテびとは、くじによって、エフライムの部族の氏族、ダンの部族、およびマナセの半部族のうちから、十の町を獲た。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="ヨシュア記 21:27–33; 歴代志上 6:71–76; 出エジプト記 6:16–17"> またゲルションびとは、くじによって、イッサカルの部族の氏族、アセルの部族、ナフタリの部族、およびバシャンにあるマナセの半部族のうちから、十三の町を獲た。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="ヨシュア記 21:34–40; 歴代志上 6:77–81; 出エジプト記 6:19"> またメラリびとは、その氏族にしたがって、ルベンの部族、ガドの部族、およびゼブルンの部族のうちから、十二の町を獲た。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="ヨシュア記 21:3; ヨシュア記 18:6; 民数記 33:54"> イスラエルの人々は、主がモーセによって命じられたとおりに、これらの町と、その放牧地とを、くじによって、レビびとに与えた。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="歴代志上 6:65; ヨシュア記 21:13–18"> まずユダの部族と、シメオンの部族のうちから、次に名をあげる町々を与えた。</span>
<span className="v" id="v10" data-v="10" data-xref="ヨシュア記 21:4; 民数記 3:27; 出エジプト記 6:20–26"> これらはレビびとに属するコハテびとの氏族の一つである、アロンの子孫に与えられた。最初のくじが彼らに当ったからである。</span>
<span className="v" id="v11" data-v="11" data-xref="歴代志上 6:55; ルカによる福音書 1:39; サムエル記下 5:1–5"> すなわちユダの山地にあるキリアテ・アルバすなわちヘブロンおよびその周囲の放牧地を彼らに与えた。このアルバはアナクの父であった。</span>
<span className="v" id="v12" data-v="12" data-xref="ヨシュア記 14:13–15; 歴代志上 6:55–57"> ただし、この町の畑と、それに属する村々とは、すでにエフンネの子カレブが、それを受けて所有していた。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="ヨシュア記 15:42; ヨシュア記 10:29; ヨシュア記 15:54"> 祭司アロンの子孫に与えたのは、人を殺した者の、のがれる町であるヘブロンとその放牧地、リブナとその放牧地、</span>
<span className="v" id="v14" data-v="14" data-xref="ヨシュア記 15:48; ヨシュア記 15:50; サムエル記上 30:27–28"> ヤッテルとその放牧地、エシテモアとその放牧地、</span>
<span className="v" id="v15" data-v="15" data-xref="ヨシュア記 15:49; ヨシュア記 15:51; ヨシュア記 12:13"> ホロンとその放牧地、デビルとその放牧地、</span>
<span className="v" id="v16" data-v="16" data-xref="ヨシュア記 15:10; 歴代志上 6:59; ヨシュア記 15:55"> アインとその放牧地、ユッタとその放牧地、ベテシメシとその放牧地など、九つの町であって、この二つの部族のうちから分け与えたものである。</span>
<span className="v" id="v17" data-v="17" data-xref="ヨシュア記 18:24–25; ヨシュア記 9:3; 歴代志上 6:60"> またベニヤミンの部族のうちから、ギベオンとその放牧地、ゲバとその放牧地、</span>
<span className="v" id="v18" data-v="18" data-xref="イザヤ書 10:30; 歴代志上 6:60; エレミヤ書 1:1"> アナトテとその放牧地、アルモンとその放牧地など、四つの町を与えた。</span>
<span className="v" id="v19" data-v="19"> アロンの子孫である祭司たちの町は、合わせて十三であって、それに属する放牧地があった。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="歴代志上 6:66; ヨシュア記 21:5"> その他のコハテびとであるレビびとの氏族は、くじによって、エフライムの部族のうちから町を獲た。</span>
<span className="v" id="v21" data-v="21" data-xref="ヨシュア記 20:7; 士師記 9:1; 列王紀上 12:1"> すなわち、その町は、人を殺したものの、のがれる町であるエフライムの山地のシケムとその放牧地、ゲゼルとその放牧地、</span>
<span className="v" id="v22" data-v="22" data-xref="歴代志上 6:68; ヨシュア記 16:3; ヨシュア記 18:13–14"> キブザイムとその放牧地、ベテホロンとその放牧地など、四つの町である。</span>
<span className="v" id="v23" data-v="23" data-xref="ヨシュア記 19:44–45"> またダンの部族のうちから分け与えた町は、エルテケとその放牧地、ギベトンとその放牧地、</span>
<span className="v" id="v24" data-v="24" data-xref="ヨシュア記 19:42; ヨシュア記 10:12; 歴代志上 6:69"> アヤロンとその放牧地、ガテリンモンとその放牧地など、四つの町である。</span>
<span className="v" id="v25" data-v="25" data-xref="ヨシュア記 17:11; 士師記 5:19"> またマナセの半部族のうちから分け与えた町は、タアナクとその放牧地、およびガテリンモンとその放牧地など、二つの町である。</span>
<span className="v" id="v26" data-v="26"> その他のコハテびとの氏族の町は、合わせて十であって、それに属する放牧地があった。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="歴代志上 6:71; 申命記 1:4; ヨシュア記 20:8"> ゲルションびとであるレビびとの氏族の一つに与えられた町は、マナセの半部族のうちからは、人を殺した者の、のがれる町であるバシャンのゴランとその放牧地、およびベエシテラとその放牧地など、二つの町である。</span>
<span className="v" id="v28" data-v="28" data-xref="ヨシュア記 19:12; 歴代志上 6:72–73"> イッサカルの部族のうちからは、キションとその放牧地、ダベラテとその放牧地、</span>
<span className="v" id="v29" data-v="29" data-xref="ヨシュア記 10:23; ヨシュア記 12:11; ヨシュア記 10:3"> ヤルムテとその放牧地、エンガンニムとその放牧地など、四つの町である。</span>
<span className="v" id="v30" data-v="30" data-xref="歴代志上 6:74–75; ヨシュア記 19:25–28"> アセルの部族のうちからは、ミシャルとその放牧地、アブドンとその放牧地、</span>
<span className="v" id="v31" data-v="31" data-xref="士師記 18:21; 歴代志上 6:75; 士師記 1:31"> ヘルカテとその放牧地、レホブとその放牧地など、四つの町である。</span>
<span className="v" id="v32" data-v="32" data-xref="歴代志上 6:76; ヨシュア記 20:7; ヨシュア記 19:37"> ナフタリの部族のうちからは、人を殺した者の、のがれる町であるガリラヤのケデシとその放牧地、ハンモテ・ドルとその放牧地、カルタンとその放牧地など、三つの町である。</span>
<span className="v" id="v33" data-v="33"> ゲルションびとが、その氏族にしたがって獲た町は、合わせて十三の町であって、それに属する放牧地があった。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="歴代志上 6:77; ヨシュア記 19:11; ヨシュア記 21:7"> その他のレビびとである、メラリびとの氏族に与えられた町は、ゼブルンの部族のうちからは、ヨクネアムとその放牧地、カルタとその放牧地、</span>
<span className="v" id="v35" data-v="35"> デムナとその放牧地、ナハラルとその放牧地など、四つの町である。</span>
<span className="v" id="v36" data-v="36" data-xref="ヨシュア記 20:8; 申命記 4:43; 民数記 21:23"> ルベンの部族のうちからは、ベゼルとその放牧地、ヤハヅとその放牧地、</span>
<span className="v" id="v37" data-v="37"> ケデモテとその放牧地、メパアテとその放牧地など、四つの町である。</span>
<span className="v" id="v38" data-v="38" data-xref="創世記 32:2; 列王紀上 22:3; 歴代志上 6:80"> ガドの部族のうちからは、人を殺した者の、のがれる町であるギレアデのラモテとその放牧地、マハナイムとその放牧地、</span>
<span className="v" id="v39" data-v="39" data-xref="イザヤ書 16:8–9; 民数記 32:35; 民数記 32:1"> ヘシボンとその放牧地、ヤゼルとその放牧地など、合わせて四つの町である。</span>
<span className="v" id="v40" data-v="40"> これらはみな、ほかのレビびとであるメラリびとが、その氏族にしたがって、くじをもって獲た町であって、合わせて十二であった。</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="民数記 35:1–8; 申命記 33:10; 創世記 49:7"> イスラエルの人々の所有のうちに、レビびとが持った町々は、合わせて四十八であって、それに属する放牧地があった。</span>
<span className="v" id="v42" data-v="42"> これらの町々は、それぞれその周囲に放牧地があった。これらの町々はみなそうであった。</span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="創世記 13:15; 詩篇 106:42–45; 出エジプト記 23:27–31"> このように、主が、イスラエルに与えると、その先祖たちに誓われた地を、ことごとく与えられたので、彼らはそれを獲て、そこに住んだ。</span>
<span className="v" id="v44" data-v="44" data-xref="ヨシュア記 11:23; ヘブル人への手紙 4:9; 申命記 31:3–5"> 主は彼らの先祖たちに誓われたように、四方に安息を賜わったので、すべての敵のうち、ひとりも彼らに手向かう者はなかった。主が敵をことごとく彼らの手に渡されたからである。</span>
<span className="v" id="v45" data-v="45" data-xref="列王紀上 8:56; ヨシュア記 23:14–15; 民数記 23:19"> 主がイスラエルの家に約束されたすべての良いことは、一つとしてたがわず、みな実現した。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨシュア記 1:9; 申命記 7:18; 申命記 1:21"> 主はヨシュアに言われた、「恐れてはならない、おののいてはならない。いくさびとを皆、率い、立って、アイに攻め上りなさい。わたしはアイの王とその民、その町、その地をあなたの手に授ける。</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 20:14; ヨシュア記 6:21; 歴代志下 20:22"> あなたは、さきにエリコとその王にしたとおり、アイとその王とにしなければならない。ただし、ぶんどり物と家畜とは戦利品としてあなたがたのものとすることができるであろう。あなたはまず、町のうしろに伏兵を置きなさい」。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="マタイによる福音書 24:39; マタイによる福音書 25:6; テサロニケ人への第一の手紙 5:2"> ヨシュアは立って、すべてのいくさびとと共に、アイに攻め上ろうとして、まず大勇士三万人を選び、それを夜のうちにつかわした。</span>
<span className="v" id="v4" data-v="4" data-xref="士師記 20:29; ヨシュア記 8:16; 士師記 20:36"> ヨシュアは彼らに命じて言った、「あなたがたは町に向かって、町のうしろに伏せていなければならない。町を遠く離れないで、みな備えをしていなければならない。</span>
<span className="v" id="v5" data-v="5" data-xref="ヨシュア記 7:5; マタイによる福音書 10:16; 士師記 20:31–33"> わたしとわたしに従う民とは皆共に、町に攻め寄せよう。そして彼らが前のようにわれわれにむかって出てくるとき、われわれは彼らの前から逃げるであろう。</span>
<span className="v" id="v6" data-v="6" data-xref="士師記 20:32; 出エジプト記 15:9; 伝道の書 8:11"> そうすれば彼らはわれわれを追って出てくるであろうから、われわれはついに彼らを町からおびき出すことができる。彼らは言うであろう、『この人々はまた前のように、われわれの前から逃げていく』。こうしてわれわれは彼らの前から逃げるであろう。</span>
<span className="v" id="v7" data-v="7" data-xref="箴言 21:30–31; 列王紀下 5:1; ヨシュア記 8:1"> その時、あなたがたは伏せている所から立ち上がって、町を取らなければならない。あなたがたの神、主がそれをあなたがたの手に与えられるからである。</span>
<span className="v" id="v8" data-v="8" data-xref="サムエル記下 13:28; ヨシュア記 1:16; ヨシュア記 1:9"> あなたがたが、町を取ったならば、町に火を放ち、主が命じられたようにしなければならない。わたしはこう、あなたがたに命じるのである」。</span>
<span className="v" id="v9" data-v="9" data-xref="ヨシュア記 7:2; 創世記 12:8; エズラ記 2:28"> そうしてヨシュアが彼らをつかわしたので、彼らはアイの西方、ベテルとアイの間の待ち伏せする場所に行って身を伏せた。ヨシュアはその夜、民の中に宿った。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="ヨシュア記 6:12; 詩篇 119:60; 創世記 22:3"> ヨシュアは明くる朝、早く起きて、民を集め、イスラエルの長老たちと共に、民に先立って、アイに上っていった。</span>
<span className="v" id="v11" data-v="11"> 彼と共にいたいくさびとたちもみな上っていって、町の前に近づき、アイの北に陣を取った。彼らとアイの間には、一つの谷があった。</span>
<span className="v" id="v12" data-v="12" data-xref="ヨシュア記 8:2–3"> ヨシュアはおおよそ五千人をとって、町の西方、ベテルとアイの間に、伏せておいた。</span>
<span className="v" id="v13" data-v="13" data-xref="ヨシュア記 8:12; ヨシュア記 8:8"> こうして民の主力を町の北におき、しんがりを町の西においた。ヨシュアはその夜、谷の中で宿った。</span>
<span className="v" id="v14" data-v="14" data-xref="マタイによる福音書 24:39; 士師記 20:34–36; 申命記 1:1"> アイの王はこれを見て、すべての民と共に、急いで、早く起き、アラバに行く下り坂に進み出て、イスラエルと戦った。しかし、王は町のうしろに、すきをうかがう伏兵のおることを知らなかった。</span>
<span className="v" id="v15" data-v="15" data-xref="ヨシュア記 18:12; ヨシュア記 16:1; 士師記 20:36"> ヨシュアはイスラエルのすべての人々と共に、彼らに打ち破られたふりをして、荒野の方向へ逃げだしたので、</span>
<span className="v" id="v16" data-v="16" data-xref="士師記 20:31; 士師記 20:36–39; ヨシュア記 8:5–6"> その町の民はみな呼ばわり集まって彼らのあとを追い、ヨシュアのあとを追って町からおびき出され、</span>
<span className="v" id="v17" data-v="17" data-xref="ヨブ記 5:13; ヨシュア記 8:3; イザヤ書 19:11–13"> アイにもベテルにも残っているものはひとりもなく、みな出てイスラエルのあとを追い、町を開け放して、イスラエルのあとを追った。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="ヨシュア記 8:26; ヨブ記 15:25; サムエル記上 17:41"> その時、主はヨシュアに言われた、「あなたの手にあるなげやりを、アイの方にさし伸べなさい。わたしはその町をあなたの手に与えるであろう」。そこでヨシュアが手にしていたなげやりを、アイの方にさし伸べると、</span>
<span className="v" id="v19" data-v="19"> 伏兵はたちまちその場所から立ち上がり、ヨシュアが手をのべると同時に、走って町に入り、それを取って、ただちに町に火をかけた。</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 76:5; ヨブ記 11:20; 創世記 19:28"> それでアイの人々が、うしろをふり返って見ると、町の焼ける煙が天に立ちのぼっていたので、こちらへもあちらへも逃げるすべがなかった。荒野へ逃げていった民も身をかえして、追ってきた者に迫った。</span>
<span className="v" id="v21" data-v="21"> ヨシュアとすべてのイスラエルびとは、伏兵が町を取り、町の焼ける煙が立ち上るのを見て、身をかえしてアイの人々を撃った。</span>
<span className="v" id="v22" data-v="22" data-xref="申命記 7:2; ヨシュア記 10:28; ヨシュア記 6:21"> また町を取ったものは町を出て彼らに向かったので、彼らは、こちらとあちらとからイスラエルの中にはさまれた。こうしてイスラエルびとが彼らを撃ったので、生き残ったもの、逃げおおせたものは、ひとりもなかった。</span>
<span className="v" id="v23" data-v="23" data-xref="サムエル記上 15:8; ヨシュア記 10:17; ヨハネの黙示録 19:20"> そしてアイの王を生けどりにして、ヨシュアのもとへ連れてきた。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="ヨシュア記 11:10–14; ヨシュア記 10:30–41; 民数記 21:24"> イスラエルびとは、荒野に追撃してきたアイの住民をことごとく野で殺し、つるぎをもってひとりも残さず撃ち倒してのち、皆アイに帰り、つるぎをもってその町を撃ち滅ぼした。</span>
<span className="v" id="v25" data-v="25" data-xref="申命記 20:16–18"> その日アイの人々はことごとく倒れた。その数は男女あわせて一万二千人であった。</span>
<span className="v" id="v26" data-v="26" data-xref="出エジプト記 17:11–12; ヨシュア記 8:18"> ヨシュアはアイの住民をことごとく滅ぼしつくすまでは、なげやりをさし伸べた手を引っこめなかった。</span>
<span className="v" id="v27" data-v="27" data-xref="ヨシュア記 8:2; 民数記 31:26; 詩篇 50:10"> ただし、その町の家畜および、ぶんどり品はイスラエルびとが自分たちの戦利品として取った。主がヨシュアに命じられた言葉にしたがったのである。</span>
<span className="v" id="v28" data-v="28" data-xref="申命記 13:16; エレミヤ書 49:2; 列王紀下 19:25"> こうしてヨシュアはアイを焼いて、永久に荒塚としたが、それは今日まで荒れ地となっている。</span>
<span className="v" id="v29" data-v="29" data-xref="ヨシュア記 7:26; サムエル記下 18:17; 申命記 21:22–23"> ヨシュアはまた、アイの王を夕方まで木に掛けてさらし、日の入るころ、命じて、その死体を木から取りおろし、町の門の入口に投げすて、その上に石の大塚を積み上げさせたが、それは今日まで残っている。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="申命記 27:4–6; 出エジプト記 20:24; 創世記 12:7–8"> そしてヨシュアはエバル山にイスラエルの神、主のために一つの祭壇を築いた。</span>
<span className="v" id="v31" data-v="31" data-xref="申命記 27:5–7; 出エジプト記 20:24–25; ヨシュア記 8:34–35"> これは主のしもべモーセがイスラエルの人々に命じたことにもとづき、モーセの律法の書にしるされているように、鉄の道具を当てない自然のままの石の祭壇であって、人々はその上で、主に燔祭をささげ、酬恩祭を供えた。</span>
<span className="v" id="v32" data-v="32" data-xref="申命記 27:2–3; 申命記 27:8"> その所で、ヨシュアはまたモーセの書きしるした律法を、イスラエルの人々の前で、石に書き写した。</span>
<span className="v" id="v33" data-v="33" data-xref="申命記 11:29; 申命記 31:12; 申命記 31:9"> こうしてすべてのイスラエルびとは、本国人も、寄留の他国人も、長老、つかさびと、さばきびとと共に、主の契約の箱をかくレビびとである祭司たちの前で、箱のこなたとかなたに分れて、半ばはゲリジム山の前に、半ばはエバル山の前に立った。これは主のしもべモーセがさきに命じたように、イスラエルの民を祝福するためであった。</span>
<span className="v" id="v34" data-v="34" data-xref="ネヘミヤ書 8:2–3; ネヘミヤ書 13:1; 申命記 31:10–12"> そして後、ヨシュアはすべての律法の書にしるされている所にしたがって、祝福と、のろいとに関する律法の言葉をことごとく読んだ。</span>
<span className="v" id="v35" data-v="35" data-xref="申命記 31:12; ネヘミヤ書 8:2; エレミヤ書 26:2"> モーセが命じたすべての言葉のうち、ヨシュアがイスラエルの全会衆および女と子どもたち、ならびにイスラエルのうちに住む寄留の他国人の前で、読まなかったものは一つもなかった。</span>
</div>

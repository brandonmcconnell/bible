<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数記 34:17–29"> イスラエルの人々が、カナンの地で受けた嗣業の地は、次のとおりである。すなわち、祭司エレアザル、ヌンの子ヨシュア、およびイスラエルの人々の部族の首長たちが、これを彼らに分かち、</span>
<span className="v" id="v2" data-v="2" data-xref="民数記 33:54; 民数記 34:13; 民数記 26:55–56"> 主がモーセによって命じられたように、くじによって、これを九つの部族と、半ばの部族とに、嗣業として与えた。</span>
<span className="v" id="v3" data-v="3" data-xref="ヨシュア記 13:14; ヨシュア記 13:8; ヨシュア記 13:32–33"> これはヨルダンの向こう側で、モーセがすでに他の二つの部族と、半ばの部族とに、嗣業を与えていたからである。ただしレビびとには、彼らの中で嗣業を与えず、</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 48:5; 歴代志上 5:1–2; 民数記 35:2–8"> ヨセフの子孫が、マナセと、エフライムの二つの部族となったからである。レビびとには土地の分け前を与えず、ただ、その住むべき町々および、家畜と持ち物とを置くための放牧地を与えたばかりであった。</span>
<span className="v" id="v5" data-v="5" data-xref="ヨシュア記 21:2; 民数記 35:1–2"> イスラエルの人々は、主がモーセに命じられたようにおこなって、その地を分けた。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="民数記 14:30; 民数記 13:6; 民数記 14:24"> 時に、ユダの人々がギルガルのヨシュアの所にきて、ケニズびとエフンネの子カレブが、ヨシュアに言った、「主がカデシ・バルネアで、あなたとわたしとについて、神の人モーセに言われたことを、あなたはごぞんじです。</span>
<span className="v" id="v7" data-v="7" data-xref="民数記 13:6; 民数記 13:26–33; 民数記 14:6–10"> 主のしもべモーセが、この地を探るために、わたしをカデシ・バルネアからつかわした時、わたしは四十歳でした。そしてわたしは、自分の信ずるところを復命しました。</span>
<span className="v" id="v8" data-v="8" data-xref="民数記 14:24; 申命記 1:36; 民数記 13:31"> しかし、共に上って行った兄弟たちは、民の心をくじいてしまいましたが、わたしは全くわが神、主に従いました。</span>
<span className="v" id="v9" data-v="9" data-xref="ヨシュア記 1:3; 申命記 1:36; 民数記 14:22–24"> その日モーセは誓って、言いました、『おまえの足で踏んだ地は、かならず長くおまえと子孫との嗣業となるであろう。おまえが全くわが神、主に従ったからである』。</span>
<span className="v" id="v10" data-v="10" data-xref="民数記 14:33–34; 民数記 14:30; ヨシュア記 11:18"> 主がこの言葉をモーセに語られた時からこのかた、イスラエルが荒野に歩んだ四十五年の間、主は言われたように、わたしを生きながらえさせてくださいました。わたしは今日すでに八十五歳ですが、</span>
<span className="v" id="v11" data-v="11" data-xref="申命記 34:7; 詩篇 103:5; 申命記 31:2"> 今もなお、モーセがわたしをつかわした日のように、健やかです。わたしの今の力は、あの時の力に劣らず、どんな働きにも、戦いにも堪えることができます。</span>
<span className="v" id="v12" data-v="12" data-xref="ヘブル人への手紙 11:33; ピリピ人への手紙 4:13; 民数記 13:33"> それで主があの日語られたこの山地を、どうか今、わたしにください。あの日あなたも聞いたように、そこにはアナキびとがいて、その町々は大きく堅固です。しかし、主がわたしと共におられて、わたしはついには、主が言われたように、彼らを追い払うことができるでしょう」。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="士師記 1:20; ヨシュア記 22:6; 歴代志上 6:55–56"> そこでヨシュアはエフンネの子カレブを祝福し、ヘブロンを彼に与えて嗣業とさせた。</span>
<span className="v" id="v14" data-v="14" data-xref="ヨシュア記 14:8–9; コリント人への第一の手紙 15:58"> こうしてヘブロンは、ケニズびとエフンネの子カレブの嗣業となって、今日に至っている。彼が全くイスラエルの神、主に従ったからである。</span>
<span className="v" id="v15" data-v="15" data-xref="ヨシュア記 11:23; 創世記 23:2; ヨシュア記 15:13"> ヘブロンの名は、もとはキリアテ・アルバといった。アルバは、アナキびとのうちの、最も大いなる人であった。こうしてこの地に戦争はやんだ。</span>
</div>

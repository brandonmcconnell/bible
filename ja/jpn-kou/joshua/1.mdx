<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命記 34:9; 申命記 1:38; 申命記 31:23"> 主のしもべモーセが死んだ後、主はモーセの従者、ヌンの子ヨシュアに言われた、</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 3:28; 申命記 31:7; 民数記 27:16–21"> 「わたしのしもべモーセは死んだ。それゆえ、今あなたと、このすべての民とは、共に立って、このヨルダンを渡り、わたしがイスラエルの人々に与える地に行きなさい。</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 11:24; ヨシュア記 14:9; テトスヘの手紙 1:2"> あなたがたが、足の裏で踏む所はみな、わたしがモーセに約束したように、あなたがたに与えるであろう。</span>
<span className="v" id="v4" data-v="4" data-xref="出エジプト記 23:31; 創世記 15:18–21; 申命記 3:25"> あなたがたの領域は、荒野からレバノンに及び、また大川ユフラテからヘテびとの全地にわたり、日の入る方の大海に達するであろう。</span>
<span className="v" id="v5" data-v="5" data-xref="ローマ人への手紙 8:31; 申命記 31:6–8; マタイによる福音書 28:20"> あなたが生きながらえる日の間、あなたに当ることのできる者は、ひとりもないであろう。わたしは、モーセと共にいたように、あなたと共におるであろう。わたしはあなたを見放すことも、見捨ることもしない。</span>
<span className="v" id="v6" data-v="6" data-xref="ダニエル書 10:19; エペソ人への手紙 6:10; ヨシュア記 1:9"> 強く、また雄々しくあれ。あなたはこの民に、わたしが彼らに与えると、その先祖たちに誓った地を獲させなければならない。</span>
<span className="v" id="v7" data-v="7" data-xref="歴代志上 22:13; 申命記 5:32; ヨシュア記 1:8"> ただ強く、また雄々しくあって、わたしのしもべモーセがあなたに命じた律法をことごとく守って行い、これを離れて右にも左にも曲ってはならない。それはすべてあなたが行くところで、勝利を得るためである。</span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 119:15; 詩篇 19:14; コロサイ人への手紙 3:16"> この律法の書をあなたの口から離すことなく、昼も夜もそれを思い、そのうちにしるされていることを、ことごとく守って行わなければならない。そうするならば、あなたの道は栄え、あなたは勝利を得るであろう。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 28:15; エレミヤ書 1:7–8; ヨシュア記 1:6–7"> わたしはあなたに命じたではないか。強く、また雄々しくあれ。あなたがどこへ行くにも、あなたの神、主が共におられるゆえ、恐れてはならない、おののいてはならない」。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10"> そこでヨシュアは民のつかさたちに命じて言った、</span>
<span className="v" id="v11" data-v="11" data-xref="申命記 9:1; ホセア書 6:2; 列王紀下 20:5"> 「宿営のなかを巡って民に命じて言いなさい、『糧食の備えをしなさい。三日のうちに、あなたがたはこのヨルダンを渡って、あなたがたの神、主があなたがたに与えて獲させようとされる地を獲るために、進み行かなければならないからである』」。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="民数記 32:20–22"> ヨシュアはまたルベンびと、ガドびと、およびマナセの半部族に言った、</span>
<span className="v" id="v13" data-v="13" data-xref="民数記 32:20–28; 申命記 3:18–20; ヨシュア記 22:1–4"> 「主のしもべモーセがあなたがたに命じて、『あなたがたの神、主はあなたがたのために安息の場所を備え、この地をあなたがたに賜わるであろう』と言った言葉を記憶しなさい。</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 20:8; 出エジプト記 13:18; ヨハネの黙示録 17:4"> あなたがたの妻子と家畜とは、モーセがあなたがたに与えたヨルダンのこちら側の地にとどまらなければならない。しかし、あなたがたのうちの勇士はみな武装して、兄弟たちの先に立って渡り、これを助けなければならない。</span>
<span className="v" id="v15" data-v="15" data-xref="ピリピ人への手紙 2:4; 民数記 32:17–22; コリント人への第一の手紙 12:26"> そして主があなたがたに賜わったように、あなたがたの兄弟たちにも安息を賜わり、彼らもあなたがたの神、主が賜わる地を獲るようになるならば、あなたがたは、主のしもべモーセから与えられた、ヨルダンのこちら側、日の出の方にある、あなたがたの所有の地に帰って、それを保つことができるであろう」。</span>
<span className="v" id="v16" data-v="16" data-xref="テトスヘの手紙 3:1; 申命記 5:27; ペテロの第一の手紙 2:13–15"> 彼らはヨシュアに答えた、「あなたがわれわれに命じられたことをみな行います。あなたがつかわされる所へは、どこへでも行きます。</span>
<span className="v" id="v17" data-v="17" data-xref="ヨシュア記 1:5; 列王紀上 1:37; ヨシュア記 1:9"> われわれはすべてのことをモーセに聞き従ったように、あなたに聞き従います。ただ、どうぞ、あなたの神、主がモーセと共におられたように、あなたと共におられますように。</span>
<span className="v" id="v18" data-v="18" data-xref="エペソ人への手紙 6:10; ヨシュア記 1:9; エズラ記 10:4"> だれであっても、あなたの命令にそむき、あなたの命じられる言葉に聞き従わないものがあれば、生かしてはおきません。ただ、強く、また雄々しくあってください」。</span>
</div>

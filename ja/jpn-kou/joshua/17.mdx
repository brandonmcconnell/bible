<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数記 26:29; 創世記 41:51; 創世記 50:23"> マナセの部族が、くじによって獲た地は、次のとおりである。マナセはヨセフの長子であった。マナセの長子で、ギレアデの父であるマキルは、軍人であったので、ギレアデとバシャンを獲た。</span>
<span className="v" id="v2" data-v="2" data-xref="歴代志上 7:18; 民数記 26:29–32; 士師記 6:11"> マナセの部族の他のものにも、その家族にしたがって、地を与えたが、それは、アビエゼル、ヘレク、アスリエル、シケム、ヘペル、セミダで、これらはヨセフの子マナセの男の子孫であって、その家族にしたがって、あげたものである。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="民数記 27:1; 民数記 26:33; 民数記 36:2–11"> しかし、マナセの子マキル、その子ギレアデ、その子ヘペル、その子であったゼロペハデには、女の子だけで、男の子がなかった。女の子たちの名は、マヘラ、ノア、ホグラ、ミルカ、テルザといった。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨシュア記 14:1; 民数記 27:5–7; ガラテヤ人への手紙 3:28"> 彼女たちは、祭司エレアザル、ヌンの子ヨシュアおよび、つかさたちの前に進み出て、「わたしたちの兄弟と同じように、わたしたちにも、嗣業を与えよと、主はモーセに命じおきになりました」と言ったので、ヨシュアは主の命にしたがって、彼らの父の兄弟たちと同じように、彼女たちにも嗣業を与えた。</span>
<span className="v" id="v5" data-v="5" data-xref="ヨシュア記 17:2–3; 民数記 32:30–42; ヨシュア記 13:29–31"> こうしてマナセはヨルダンの向こう側で、ギレアデとバシャンの地のほかに、なお十の部分を獲た。</span>
<span className="v" id="v6" data-v="6"> マナセの娘たちが、男の子らと共に、嗣業を獲たからである。ギレアデの地は、そのほかのマナセの子孫に分け与えられた。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="ヨシュア記 21:21; ヨシュア記 20:7; ヨシュア記 24:32"> マナセの獲た地の境は、アセルからシケムの東のミクメタテに及び、その境は南に延びて、エンタップアの住民に達する。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨシュア記 16:8; ヨシュア記 15:34; ヨシュア記 12:17"> タップアの地はマナセに属していたが、マナセの境にあるタップアの町は、エフライムの子孫に属していた。</span>
<span className="v" id="v9" data-v="9" data-xref="ヨシュア記 16:3; ヨシュア記 19:29; ヨシュア記 16:8–9"> またその境はカナの川に下って、川の南に至る。そこの町々はマナセの町々の中にあって、エフライムに属した。マナセの境は、川の北に沿って進み、海に達して尽きる。</span>
<span className="v" id="v10" data-v="10"> その川の南の地は、エフライムに属し、北はマナセに属する。海がその境となる。マナセは北はアセルに接し、東はイッサカルに接する。</span>
<span className="v" id="v11" data-v="11" data-xref="歴代志上 7:29; 列王紀下 9:27; 士師記 5:19"> マナセはまたイッサカルとアセルの中に、ベテシャンとその村々、イブレアムとその村々、ドルの住民とその村々、エンドルの住民とその村々、タアナクの住民とその村々、メギドの住民とその村々を獲た。このうち第三のものは高地である。</span>
<span className="v" id="v12" data-v="12" data-xref="士師記 1:27–28; 出エジプト記 23:29–33; ローマ人への手紙 6:12–14"> しかし、マナセの子孫は、これらの町々を取ることができなかったので、カナンびとは長くこの地に住み続けようとした。</span>
<span className="v" id="v13" data-v="13" data-xref="ヨシュア記 16:10; ピリピ人への手紙 4:13; 士師記 1:35"> しかし、イスラエルの人々が強くなるにしたがって、カナンびとを使役するようになり、ことごとく追い払うことはしなかった。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="民数記 26:34–37; 創世記 48:19; 創世記 48:22"> ヨセフの子孫はヨシュアに言った、「主が今まで、わたしを祝福されたので、わたしは数の多い民となったのに、あなたはなぜ、わたしの嗣業として、ただ一つのくじ、一つの分だけを、くださったのですか」。</span>
<span className="v" id="v15" data-v="15" data-xref="創世記 13:7; 創世記 14:5; ルカによる福音書 12:48"> ヨシュアは彼らに言った、「もしあなたが数の多い民ならば、林に上っていって、そこで、ペリジびとやレパイムびとの地を自分で切り開くがよい。エフライムの山地が、あなたがたには狭いのだから」。</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀上 4:12; 士師記 4:3; 士師記 1:19"> ヨセフの子孫は答えた、「山地はわたしどもに十分ではありません。かつまた平地におるカナンびとは、ベテシャンとその村々におるものも、エズレルの谷におるものも、みな鉄の戦車を持っています」。</span>
<span className="v" id="v17" data-v="17"> ヨシュアはまたヨセフの家、すなわちエフライムとマナセに言った、「あなたは数の多い民で、大きな力をもっています。それでただ一つのくじでは足りません。</span>
<span className="v" id="v18" data-v="18" data-xref="ヘブル人への手紙 13:6; ローマ人への手紙 8:31; 民数記 14:6–9"> 山地をもあなたのものとしなければなりません。それは林ではあるが、切り開いて、向こうの端まで、自分のものとしなければなりません。カナンびとは鉄の戦車があって、強くはあるが、あなたはそれを追い払うことができます」。</span>

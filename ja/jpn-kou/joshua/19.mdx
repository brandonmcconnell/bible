<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨシュア記 19:9; 創世記 49:5–7; ヨシュア記 18:6–11"> 次にシメオンのため、すなわちシメオンの子孫の部族のために、その家族にしたがって、くじを引いた。その嗣業はユダの子孫の嗣業のうちにあった。</span>
<span className="v" id="v2" data-v="2" data-xref="歴代志上 4:28–30; ネヘミヤ書 11:26–30; 創世記 21:31"> その嗣業として獲たものは、ベエルシバ、すなわちシバ、モラダ、</span>
<span className="v" id="v3" data-v="3" data-xref="ヨシュア記 15:28–29"> ハザル・シュアル、バラ、エゼム、</span>
<span className="v" id="v4" data-v="4" data-xref="ヨシュア記 15:30; 士師記 1:17"> エルトラデ、ベトル、ホルマ、</span>
<span className="v" id="v5" data-v="5" data-xref="サムエル記上 30:1; 歴代志上 4:31; ヨシュア記 15:31"> チクラグ、ベテ・マルカボテ、ハザルスサ、</span>
<span className="v" id="v6" data-v="6" data-xref="ヨシュア記 15:32"> ベテレバオテ、シャルヘン。すなわち十三の町々と、それに属する村々。</span>
<span className="v" id="v7" data-v="7" data-xref="ヨシュア記 15:42; ヨシュア記 15:32; 民数記 33:19–20"> またアイン、リンモン、エテル、アシャン。すなわち四つの町々と、それに属する村々。</span>
<span className="v" id="v8" data-v="8" data-xref="歴代志上 4:33; サムエル記上 30:27"> およびこれらの町の周囲にあって、バアラテ・ベエル、すなわちネゲブのラマに至るまでのすべての村々。これがシメオンの子孫の部族の、その家族にしたがって獲た嗣業である。</span>
<span className="v" id="v9" data-v="9" data-xref="コリント人への第二の手紙 8:14–15; 出エジプト記 16:18"> シメオンの子孫の嗣業は、ユダの子孫の領域のうちにあった。これはユダの子孫の分が大きかったので、シメオンの子孫が、その嗣業を彼らの嗣業の中に獲たからである。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="ヨシュア記 18:11; ヨシュア記 18:6; 創世記 49:13"> 第三にゼブルンの子孫のために、その家族にしたがって、くじを引いた。その嗣業の領域はサリデに及び、</span>
<span className="v" id="v11" data-v="11" data-xref="ヨシュア記 12:22; 歴代志上 6:68; 列王紀上 4:12"> その境は西に上って、マララに至り、ダバセテに達し、ヨクネアムの東にある川に達し、</span>
<span className="v" id="v12" data-v="12" data-xref="士師記 4:6; 歴代志上 6:72; ヨシュア記 19:22"> サリデから、東の方、日の出の方に曲り、キスロテ・タボルの境に至り、ダベラテに出て、ヤピアに上り、</span>
<span className="v" id="v13" data-v="13" data-xref="列王紀下 14:25"> そこから東の方、日の出の方に進んで、ガテヘペルとイッタ・カジンに至り、リンモンに進んで、ネアの方に曲る。</span>
<span className="v" id="v14" data-v="14"> 北ではその境はハンナトンに回り、イフタエルの谷に至って尽きる。</span>
<span className="v" id="v15" data-v="15" data-xref="ヨシュア記 11:1; ルツ記 1:19; サムエル記下 23:15"> そしてカッタテ、ナハラル、シムロン、イダラ、ベツレヘムなど十二の町々と、それに属する村々があった。</span>
<span className="v" id="v16" data-v="16"> これがゼブルンの子孫の、その家族にしたがって獲た嗣業であって、その町々と、それに属する村々とである。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17"> 第四にイッサカル、すなわちイッサカルの子孫のために、その家族にしたがって、くじを引いた。</span>
<span className="v" id="v18" data-v="18" data-xref="サムエル記上 28:4; 列王紀下 4:8; ホセア書 1:4–5"> その領域には、エズレル、ケスロテ、シュネム、</span>
<span className="v" id="v19" data-v="19"> ハパライム、シオン、アナハラテ、</span>
<span className="v" id="v20" data-v="20"> ラビテ、キション、エベツ、</span>
<span className="v" id="v21" data-v="21" data-xref="ヨシュア記 21:29"> レメテ、エンガンニム、エンハダ、ベテパッゼズがあり、</span>
<span className="v" id="v22" data-v="22" data-xref="士師記 4:6; 歴代志上 6:77; ヨシュア記 19:38"> その境はタボル、シャハヂマ、ベテシメシに達し、その境はヨルダンに至って尽きる。十六の町々と、それに属する村々があった。</span>
<span className="v" id="v23" data-v="23"> これがイッサカルの子孫の部族の、その家族にしたがって獲た嗣業であって、その町々と、それに属する村々とである。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="ルカによる福音書 2:26–38"> 第五に、アセルの子孫の部族のために、その家族にしたがって、くじを引いた。</span>
<span className="v" id="v25" data-v="25" data-xref="ヨシュア記 12:20; ヨシュア記 11:1; サムエル記下 2:16"> その領域には、ヘルカテ、ハリ、ベテン、アクサフ、</span>
<span className="v" id="v26" data-v="26" data-xref="雅歌 7:5; 列王紀上 18:42; イザヤ書 33:9"> アランメレク、アマデ、ミシャルがあり、その境は西では、カルメルとシホル・リブナテに達し、</span>
<span className="v" id="v27" data-v="27" data-xref="列王紀上 9:13; サムエル記上 5:2"> それから東に折れて、ベテダゴンに至り、北の方ゼブルンと、イプタエルの谷に達し、ベテエメクおよびネイエルに至り、北はカブルにいで、</span>
<span className="v" id="v28" data-v="28" data-xref="士師記 1:31; ヨシュア記 11:8; イザヤ書 23:12"> 更にエブロン、レホブ、ハンモン、カナを経て、大シドンに及び、</span>
<span className="v" id="v29" data-v="29" data-xref="士師記 1:31; サムエル記下 5:11; ミカ書 1:14"> それから、その境はラマに曲り、堅固な町ツロに至る。またその境はホサに曲り、海に至って尽きる。そして、マハラブ、アクジブ、</span>
<span className="v" id="v30" data-v="30" data-xref="ヨシュア記 21:31; 列王紀上 20:30; サムエル記上 4:1"> ウンマ、アペク、レホブなど、二十二の町々と、それに属する村々があった。</span>
<span className="v" id="v31" data-v="31" data-xref="申命記 33:24–25; 創世記 49:20"> これがアセルの子孫の部族の、その家族にしたがって獲た嗣業であって、その町々と、それに属する村々とである。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32"> 第六に、ナフタリの子孫のために、その家族にしたがって、くじを引いた。</span>
<span className="v" id="v33" data-v="33" data-xref="士師記 4:11"> その境はヘレフから、すなわちザアナニイムのかしの木から起り、アダミ・ネケブおよび、ヤブネルを経て、ラクムに至り、ヨルダンに至って尽きる。</span>
<span className="v" id="v34" data-v="34" data-xref="申命記 33:23; ヨシュア記 19:12; ヨシュア記 19:22"> そしてその境は西に向かって、アズノテ・タボルに至り、そこからホッコクに出る。南はゼブルンに接し、西はアセルに接し、東はヨルダンのユダに達する。</span>
<span className="v" id="v35" data-v="35" data-xref="ヨシュア記 11:2; 列王紀上 8:65; 創世記 10:18"> その堅固な町々は、ヂデム、ゼル、ハンマテ、ラッカテ、キンネレテ、</span>
<span className="v" id="v36" data-v="36" data-xref="ヨシュア記 11:1; ヨシュア記 11:20; ヨシュア記 12:19"> アダマ、ラマ、ハゾル、</span>
<span className="v" id="v37" data-v="37" data-xref="ヨシュア記 20:7; ヨシュア記 12:22"> ケデシ、エデレイ、エンハゾル、</span>
<span className="v" id="v38" data-v="38"> イロン、ミグダルエル、ホレム、ベテアナテ、ベテシメシなどで、十九の町々と、それに属する村々があった。</span>
<span className="v" id="v39" data-v="39"> これがナフタリの子孫の部族が、その家族にしたがって獲た嗣業であって、その町々と、それに属する村々とである。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40"> 第七に、ダンの子孫の部族のために、その家族にしたがって、くじを引いた。</span>
<span className="v" id="v41" data-v="41" data-xref="歴代志上 2:53; ヨシュア記 15:33; 士師記 13:25"> その嗣業の領域には、ゾラ、エシタオル、イルシメシ、</span>
<span className="v" id="v42" data-v="42" data-xref="士師記 1:35; ヨシュア記 10:12; ヨシュア記 21:24"> シャラビム、アヤロン、イテラ、</span>
<span className="v" id="v43" data-v="43" data-xref="創世記 38:12; サムエル記上 5:10; 士師記 14:1–2"> エロン、テムナ、エクロン、</span>
<span className="v" id="v44" data-v="44" data-xref="列王紀上 15:27; 列王紀上 16:15; 列王紀上 9:18"> エルテケ、ギベトン、バアラテ、</span>
<span className="v" id="v45" data-v="45" data-xref="ヨシュア記 21:24"> エホデ、ベネベラク、ガテリンモン、</span>
<span className="v" id="v46" data-v="46" data-xref="ヨナ書 1:3; 使徒行伝 9:36; 歴代志下 2:16"> メヤルコン、ラッコン、およびヨッパと相対する地域があった。</span>
<span className="v" id="v47" data-v="47" data-xref="士師記 1:34–35; 士師記 18:1–29"> ただし、ダンの子孫の領域は、彼らのために小さかったので、ダンの子孫は、上って行き、レセムを攻めてそれを取り、つるぎにかけて撃ち滅ぼし、それを獲てそこに住み、先祖ダンの名にしたがって、レセムをダンと名づけた。</span>
<span className="v" id="v48" data-v="48"> これがダンの子孫の部族の、その家族にしたがって獲た嗣業であって、その町々と、それに属する村々とである。</span>
</div>
<div className="bp">
<span className="v" id="v49" data-v="49" data-xref="エゼキエル書 45:7–8"> こうして国の各地域を嗣業として分け与えることを終ったとき、イスラエルの人々は、自分たちのうちに、一つの嗣業を、ヌンの子ヨシュアに与えた。</span>
<span className="v" id="v50" data-v="50" data-xref="ヨシュア記 24:30; 士師記 2:9; 歴代志上 7:24"> すなわち、主の命に従って、彼が求めた町を与えたが、それはエフライムの山地にあるテムナテ・セラであって、彼はその町を建てなおして、そこに住んだ。</span>
</div>
<div className="bp">
<span className="v" id="v51" data-v="51" data-xref="ヨシュア記 18:10; ヨシュア記 14:1; ヨシュア記 18:1"> これらは、祭司エレアザル、ヌンの子ヨシュア、およびイスラエルの子孫の部族の族長たちが、シロにおいて会見の幕屋の入口で、主の前に、くじを引いて分け与えた嗣業である。こうして地を分けることを終った。</span>
</div>

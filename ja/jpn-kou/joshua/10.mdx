<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨシュア記 6:21; ヘブル人への手紙 7:1; ヨシュア記 8:2"> エルサレムの王アドニゼデクは、ヨシュアがアイを攻め取って、それを全く滅ぼし、さきにエリコとその王とにしたように、アイとその王にもしたこと、またギベオンの住民が、イスラエルと和を講じて、そのうちにおることを聞き、</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 11:25; ヨシュア記 2:24; 出エジプト記 15:14–16"> 大いに恐れた。それは、ギベオンが大きな町であって、王の都にもひとしいものであり、またアイより大きくて、そのうちの人々が、すべて強かったからである。</span>
<span className="v" id="v3" data-v="3" data-xref="歴代志下 11:9; ミカ書 1:13; ヨシュア記 10:1"> それでエルサレムの王アドニゼデクは、ヘブロンの王ホハム、ヤルムテの王ピラム、ラキシの王ヤピア、およびエグロンの王デビルに人をつかわして言った、</span>
<span className="v" id="v4" data-v="4" data-xref="ヨシュア記 9:15; ヨシュア記 10:1; イザヤ書 8:9–10"> 「わたしの所に上ってきて、わたしを助けてください。われわれはギベオンを撃ちましょう。ギベオンはヨシュアおよびイスラエルの人々と和を講じたからです」。</span>
<span className="v" id="v5" data-v="5" data-xref="イザヤ書 8:9–10; 創世記 15:16; ヨシュア記 10:6"> アモリびとの五人の王、すなわちエルサレムの王、ヘブロンの王、ヤルムテの王、ラキシの王、およびエグロンの王は兵を集め、そのすべての軍勢を率いて上ってきて、ギベオンに向かって陣を取り、それを攻めて戦った。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="ヨシュア記 9:6; ヨシュア記 5:10; 申命記 1:15"> ギベオンの人々は、ギルガルの陣営に人をつかわし、ヨシュアに言った、「あなたの手を引かないで、しもべどもを助けてください。早く、われわれの所に上ってきて、われわれを救い、助けてください。山地に住むアモリびとの王たちがみな集まって、われわれを攻めるからです」。</span>
<span className="v" id="v7" data-v="7" data-xref="ヨシュア記 8:1; イザヤ書 8:12; イザヤ書 8:14"> そこでヨシュアはすべてのいくさびとと、すべての大勇士を率いて、ギルガルから上って行った。</span>
<span className="v" id="v8" data-v="8" data-xref="ローマ人への手紙 8:31; 申命記 3:2; 詩篇 27:1–2"> その時、主はヨシュアに言われた、「彼らを恐れてはならない。わたしが彼らをあなたの手にわたしたからである。彼らのうちには、あなたに当ることのできるものは、ひとりもないであろう」。</span>
<span className="v" id="v9" data-v="9" data-xref="伝道の書 9:10; テモテヘの第二の手紙 2:3; 箴言 24:11–12"> ヨシュアは、ギルガルから、よもすがら進みのぼって、にわかに彼らに攻めよせたところ、</span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 18:14; ヨシュア記 16:3; ヨシュア記 16:5"> 主は彼らを、イスラエルの前に、恐れあわてさせられたので、イスラエルはギベオンで彼らをおびただしく撃ち殺し、ベテホロンの上り坂をとおって逃げる彼らを、アゼカとマッケダまで追撃した。</span>
<span className="v" id="v11" data-v="11" data-xref="イザヤ書 28:2; 士師記 5:20; 詩篇 18:12–14"> 彼らがイスラエルの前から逃げ走って、ベテホロンの下り坂をおりていた時、主は天から彼らの上に大石を降らし、アゼカにいたるまでもそうされたので、多くの人々が死んだ。イスラエルの人々がつるぎをもって殺したものよりも、雹に打たれて死んだもののほうが多かった。</span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="ハバクク書 3:11; イザヤ書 38:8; イザヤ書 60:20"> 主がアモリびとをイスラエルの人々にわたされた日に、ヨシュアはイスラエルの人々の前で主にむかって言った、<br /><span className="pl pl-1">「日よ、ギベオンの上にとどまれ、</span><br /><span className="pl pl-1">月よ、アヤロンの谷にやすらえ」。</span></span>
<span className="v" id="v13" data-v="13" data-xref="ハバクク書 3:11; イザヤ書 38:8; ヨシュア記 10:14"> <span className="pl pl-1">民がその敵を撃ち破るまで、</span><br /><span className="pl pl-1">日はとどまり、</span><br /><span className="pl pl-1">月は動かなかった。</span><br />これはヤシャルの書にしるされているではないか。日が天の中空にとどまって、急いで没しなかったこと、おおよそ一日であった。</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 1:30; 出エジプト記 14:14; ヨシュア記 10:42"> これより先にも、あとにも、主がこのように人の言葉を聞きいれられた日は一日もなかった。主がイスラエルのために戦われたからである。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="ヨシュア記 10:43; ヨシュア記 10:6"> こうしてヨシュアはイスラエルのすべての人と共にギルガルの陣営に帰った。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="サムエル記上 24:8; アモス書 9:2; 詩篇 139:7–10"> かの五人の王たちは逃げて行って、マッケダのほら穴に隠れたが、</span>
<span className="v" id="v17" data-v="17"> 五人の王たちがマッケダのほら穴にかくれているのが見つかったと、ヨシュアに告げる者があったので、</span>
<span className="v" id="v18" data-v="18" data-xref="マタイによる福音書 27:66; ヨブ記 21:30; アモス書 9:1"> ヨシュアは言った、「ほら穴の口に大石をころがし、そのそばに人を置いて、守らせなさい。</span>
<span className="v" id="v19" data-v="19" data-xref="詩篇 18:37–41; エレミヤ書 8:14; イザヤ書 9:14–15"> ただし、あなたがたは、そこにとどまらないで、敵のあとを追い、そのしんがりを撃ち、彼らをその町にはいらせてはならない。あなたがたの神、主が彼らをあなたがたの手に渡されたからである」。</span>
<span className="v" id="v20" data-v="20" data-xref="ヨシュア記 8:24; サムエル記下 20:6; ヨシュア記 10:10"> ヨシュアとイスラエルの人々は、大いに彼らを撃ち殺し、ついに彼らを滅ぼしつくしたが、彼らのうちのがれて生き残った者どもは、堅固な町々に逃げこんだので、</span>
<span className="v" id="v21" data-v="21" data-xref="出エジプト記 11:7; イザヤ書 54:17; イザヤ書 57:4"> 民はみな安らかにマッケダの陣営のヨシュアのもとに帰ってきたが、イスラエルの人々にむかって舌を鳴らす者はひとりもなかった。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="サムエル記上 15:32"> その時ヨシュアは言った、「ほら穴の口を開いて、ほら穴から、かの五人の王たちを、わたしのもとにひき出しなさい」。</span>
<span className="v" id="v23" data-v="23" data-xref="ヨシュア記 10:1; ヨシュア記 10:5; ヨシュア記 10:3"> やがて、そのようにして、かの五人の王たち、すなわち、エルサレムの王、ヘブロンの王、ヤルムテの王、ラキシの王、およびエグロンの王を、ほら穴から彼のもとにひき出した。</span>
<span className="v" id="v24" data-v="24" data-xref="マラキ書 4:3; ローマ人への手紙 16:20; ヨハネの黙示録 2:26–27"> この王たちをヨシュアのもとにひき出した時、ヨシュアはイスラエルのすべての人々を呼び寄せ、自分と共に行ったいくさびとの長たちに言った、「近寄って、この王たちのくびに足をかけなさい」。そこで近寄って、その王たちのくびに足をかけたので、</span>
<span className="v" id="v25" data-v="25" data-xref="コリント人への第二の手紙 1:10; ヨシュア記 1:9; エペソ人への手紙 6:10"> ヨシュアは彼らに言った、「恐れおののいてはならない。強くまた雄々しくあれ。あなたがたが攻めて戦うすべての敵には、主がこのようにされるのである」。</span>
<span className="v" id="v26" data-v="26" data-xref="ヨシュア記 8:29; サムエル記下 21:9; マタイによる福音書 27:25"> そして後ヨシュアは彼らを撃って死なせ、五本の木にかけて、夕暮れまで木の上にさらして置いたが、</span>
<span className="v" id="v27" data-v="27" data-xref="ヨシュア記 8:29; 申命記 21:22–23; ヨシュア記 7:26"> 日の入るころになって、ヨシュアが命じたので、これを木からおろし、彼らが隠れていたほら穴に投げ入れ、ほら穴の口に大石を置いた。これは今日まで残っている。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="ヨシュア記 6:21; 申命記 7:16; 申命記 20:16–17"> その日ヨシュアはマッケダを取り、つるぎをもって、それと、その王とを撃ち、その中のすべての人を、ことごとく滅ぼして、ひとりも残さず、エリコの王にしたように、マッケダの王にもした。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="ヨシュア記 21:13; ヨシュア記 15:42; エレミヤ書 52:1"> こうしてヨシュアはイスラエルのすべての人を率いて、マッケダからリブナに進み、リブナを攻めて戦った。</span>
<span className="v" id="v30" data-v="30"> 主が、それと、その王をも、イスラエルの手に渡されたので、つるぎをもって、それと、その中のすべての人を撃ち滅ぼして、ひとりもその中に残さず、エリコの王にしたように、その王にもした。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="ヨシュア記 10:3; ヨシュア記 12:11; ヨシュア記 10:5"> ヨシュアはまたイスラエルのすべての人を率いて、リブナからラキシに進み、これに向かって陣をしき、攻め戦った。</span>
<span className="v" id="v32" data-v="32"> 主がラキシをイスラエルの手に渡されたので、ふつか目にこれを取り、つるぎをもって、それと、その中のすべての人を撃ち滅ぼした。すべてリブナにしたとおりであった。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="ヨシュア記 16:10; 士師記 1:29; ヨシュア記 16:3"> その時、ゲゼルの王ホラムが、ラキシを助けるために上ってきたので、ヨシュアは彼と、その民とを撃ち滅ぼして、ついにひとりも残さなかった。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="ヨシュア記 10:3; ヨシュア記 12:12; ヨシュア記 15:39"> ヨシュアはまたイスラエルのすべての人を率いて、ラキシからエグロンに進み、これに向かって陣をしき、攻め戦った。</span>
<span className="v" id="v35" data-v="35" data-xref="レビ記 26:44; ヨシュア記 10:37; ヨブ記 19:10"> その日これを取り、つるぎをもって、これを撃ち、その中のすべての人を、ことごとくその日に滅ぼした。すべてラキシにしたとおりであった。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="士師記 1:10; ヨシュア記 15:13; ヨシュア記 14:13–14"> ヨシュアはまたイスラエルのすべての人を率いて、エグロンからヘブロンに進み上り、これを攻めて戦い、</span>
<span className="v" id="v37" data-v="37"> それを取って、それと、その王、およびそのすべての町々と、その中のすべての人を、つるぎをもって撃ち滅ぼし、ひとりも残さなかった。すべてエグロンにしたとおりであった。すなわち、それとその中のすべての人を、ことごとく滅ぼした。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="ヨシュア記 15:15; ヨシュア記 12:13; ヨシュア記 15:49"> またヨシュアはイスラエルのすべての人を率いて、デビルへひきかえし、これを攻めて戦い、</span>
<span className="v" id="v39" data-v="39" data-xref="オバデヤ書 1:18; ヨシュア記 11:8; 申命記 3:3"> それと、その王、およびそのすべての町々を取り、つるぎをもってそれを撃ち、その中のすべての人を、ことごとく滅ぼし、ひとりも残さなかった。彼がデビルと、その王にしたことは、ヘブロンにしたとおりであり、またリブナと、その王にしたとおりであった。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="申命記 7:2–16; 出エジプト記 23:31–33; ヨシュア記 8:27"> こうしてヨシュアはその地の全部、すなわち、山地、ネゲブ、平地、および山腹の地と、そのすべての王たちを撃ち滅ぼして、ひとりも残さず、すべて息のあるものは、ことごとく滅ぼした。イスラエルの神、主が命じられたとおりであった。</span>
<span className="v" id="v41" data-v="41" data-xref="ヨシュア記 11:16; ヨシュア記 15:51; 申命記 9:23"> ヨシュアはカデシ・バルネアからガザまでの国々、およびゴセンの全地を撃ち滅ぼして、ギベオンにまで及んだ。</span>
<span className="v" id="v42" data-v="42" data-xref="ヨシュア記 10:14; 詩篇 46:7; 詩篇 80:3"> イスラエルの神、主がイスラエルのために戦われたので、ヨシュアはこれらすべての王たちと、その地をいちどきに取った。</span>
<span className="v" id="v43" data-v="43" data-xref="ヨシュア記 10:15; ヨシュア記 4:19; サムエル記上 11:14"> そしてヨシュアはイスラエルのすべての人を率いて、ギルガルの陣営に帰った。</span>
</div>

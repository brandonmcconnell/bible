<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨシュア記 19:51; サムエル記上 1:3; ヨシュア記 21:2"> そこでイスラエルの人々の全会衆は、その地を征服したので、シロに集まり、そこに会見の幕屋を立てた。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2"> その時、イスラエルの人々のうちに、まだ嗣業を分かち取らない部族が、七つ残っていたので、</span>
<span className="v" id="v3" data-v="3" data-xref="士師記 18:9; 箴言 13:4; 箴言 10:4"> ヨシュアはイスラエルの人々に言った、「あなたがたは、先祖の神、主が、あなたがたに与えられた地を取りに行くのを、いつまで怠っているのですか。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨシュア記 18:6; ヨシュア記 4:2; ヨシュア記 18:3"> 部族ごとに三人ずつを出しなさい。わたしはその人々をつかわしましょう。彼らは立っていって、その地を行き巡り、おのおのの嗣業のために、それを図面にして、わたしのところへ持ってこなければならない。</span>
<span className="v" id="v5" data-v="5" data-xref="ヨシュア記 16:1–10; ヨシュア記 19:1–9; ヨシュア記 15:1–12"> 彼らはその地を七つの部分に分けなければならない。ユダは南のその領地にとどまり、ヨセフの家は北のその領地にとどまらなければならない。</span>
<span className="v" id="v6" data-v="6" data-xref="ヨシュア記 14:2; ヨシュア記 18:10; 使徒行伝 13:19"> あなたがたは、その地を七つに分けて、図面にし、それをここに、わたしのところへ持ってこなければならない。わたしはここで、われわれの神、主の前に、あなたがたのために、くじを引くであろう。</span>
<span className="v" id="v7" data-v="7" data-xref="ヨシュア記 13:33; ヨシュア記 13:8–31; 民数記 18:20"> レビびとは、あなたがたのうちに何の分をも持たない。主の祭司たることが、彼らの嗣業だからである。またガドとルベンとマナセの半部族とは、ヨルダンの向こう側、東の方で、すでにその嗣業を受けた。それは主のしもべモーセが、彼らに与えたものである」。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="ヨシュア記 18:10; ローマ人への手紙 14:19; サムエル記上 14:41"> そこでその人々は立って行った。その地の図面を作るために出て行く人々に、ヨシュアは命じて言った、「あなたがたは行って、その地を行き巡り、それを図面にして、わたしのところに持って帰りなさい。わたしはシロで、主の前に、あなたがたのために、ここでくじを引きましょう」。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行伝 13:19"> こうしてその人々は行って、その地を経めぐり、町々にしたがって、それを七つの部分とし、図面にして、書物に書きしるし、シロの宿営におるヨシュアのもとへ持ってきた。</span>
<span className="v" id="v10" data-v="10" data-xref="コロサイ人への手紙 1:12; 使徒行伝 13:19; ヨシュア記 18:6"> ヨシュアはシロで、彼らのために主の前に、くじを引いた。そしてヨシュアはその所で、イスラエルの人々に、それぞれの分として、地を分け与えた。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="ヨシュア記 16:1–10; ヨシュア記 15:1–8; 申命記 10:1–22"> まずベニヤミンの子孫の部族のために、その家族にしたがって、くじを引いた。そしてそのくじによって獲た領地は、ユダの子孫と、ヨセフの子孫との間にあった。</span>
<span className="v" id="v12" data-v="12" data-xref="ヨシュア記 16:1; ヨシュア記 7:2; ヨシュア記 2:1"> すなわち、その北の方の境は、ヨルダンに始まり、エリコの北のわきに上り、また西の方の山地をとおって上り、ベテアベンの荒野に達して尽きる。</span>
<span className="v" id="v13" data-v="13" data-xref="創世記 28:19; ヨシュア記 16:2–3; ヨシュア記 10:11"> そこから、その境はルズに進み、ルズの南のわきに至る。ルズはベテルである。ついでその境は下ベテホロンの南の山にあるアタロテ・アダルに下り、</span>
<span className="v" id="v14" data-v="14" data-xref="ヨシュア記 15:9; 歴代志上 13:5–6; サムエル記上 7:1–2"> 西の方では、ベテホロンの南にある山から南に曲り、ユダの子孫の町キリアテ・バアルに至って尽きる。キリアテ・バアルはキリアテ・ヤリムである。これが西の方の境であった。</span>
<span className="v" id="v15" data-v="15" data-xref="ヨシュア記 15:9"> また南の方は、キリアテ・ヤリムの端に始まり、その境はそこからエフロンにおもむき、ネフトアの水の源に至り、</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀下 23:10; ヨシュア記 15:7–8; イザヤ書 30:33"> ついでその境は、レパイムの谷の北の端にあるベンヒンノムの谷を見おろす山の端に下り、進んでエブスびとのわきの南、ヒンノムの谷に下り、また下ってエンロゲルに至り、</span>
<span className="v" id="v17" data-v="17" data-xref="ヨシュア記 15:6"> 北に曲ってエンシメシにおもむき、アドミムの坂に対するゲリロテにおもむき、ルベンびとボハンの石に下り、</span>
<span className="v" id="v18" data-v="18" data-xref="ヨシュア記 15:6; ヨシュア記 15:61"> ベテアラバのわきを北に進んで、アラバに下り、</span>
<span className="v" id="v19" data-v="19" data-xref="創世記 14:3; ヨシュア記 15:2; 民数記 34:3"> その境は、ベテホグラの北のわきに進み、ヨルダンの南端で、塩の海の北の入海に至って尽きる。これが南の境である。</span>
<span className="v" id="v20" data-v="20"> ヨルダンは東の方の境となっていた。これがベニヤミンの子孫の、その家族にしたがって獲た嗣業の四方の境である。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="ヨシュア記 18:12; ヨシュア記 6:1; ヨシュア記 18:19"> ベニヤミンの子孫の部族が、その家族にしたがって獲た町々は、エリコ、ベテホグラ、エメクケジツ、</span>
<span className="v" id="v22" data-v="22" data-xref="ヨシュア記 15:6; 列王紀上 12:29–32; ヨシュア記 18:18"> ベテアラバ、ゼマライム、ベテル、</span>
<span className="v" id="v23" data-v="23" data-xref="サムエル記上 13:17"> アビム、パラ、オフラ、</span>
<span className="v" id="v24" data-v="24" data-xref="エズラ記 2:26; ヨシュア記 21:17; イザヤ書 10:29"> ケパル・アンモニ、オフニ、ゲバ。すなわち十二の町々と、それに属する村々。</span>
<span className="v" id="v25" data-v="25" data-xref="ヨシュア記 9:17; 列王紀上 3:4–5; ヨシュア記 10:2"> またギベオン、ラマ、ベエロテ、</span>
<span className="v" id="v26" data-v="26" data-xref="士師記 10:17; エズラ記 2:25; ヨシュア記 9:17"> ミヅパ、ケピラ、モザ、</span>
<span className="v" id="v27" data-v="27"> レケム、イルピエル、タララ、</span>
<span className="v" id="v28" data-v="28" data-xref="サムエル記下 21:14; ヨシュア記 15:8; 士師記 20:4–5"> ゼラ、エレフ、エブスすなわちエルサレム、ギベア、キリアテ・ヤリム。すなわち十四の町々と、それに属する村々。これがベニヤミンの子孫の、その家族にしたがって獲た嗣業である。</span>
</div>

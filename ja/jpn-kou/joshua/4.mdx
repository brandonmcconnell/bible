<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命記 27:2; ヨシュア記 3:17"> 民が皆、ヨルダンを渡り終った時、主はヨシュアに言われた、</span>
<span className="v" id="v2" data-v="2" data-xref="ヨシュア記 3:12; 民数記 1:4–15; 列王紀上 18:31"> 「民のうちから、部族ごとにひとりずつ、合わせて十二人を選び、</span>
<span className="v" id="v3" data-v="3" data-xref="ヨシュア記 4:19–20; ヨシュア記 3:13; ヨシュア記 4:8"> 彼らに命じて言いなさい、『ヨルダンの中で祭司たちが足を踏みとどめたその所から、石十二を取り、それを携えて渡り、今夜あなたがたが宿る場所にすえなさい』」。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨシュア記 4:2; マルコによる福音書 3:14–19"> そこでヨシュアはイスラエルの人々のうちから、部族ごとに、ひとりずつ、かねて定めておいた十二人の者を召し寄せ、</span>
<span className="v" id="v5" data-v="5"> ヨシュアは彼らに言った、「あなたがたの神、主の契約の箱の前に立って行き、ヨルダンの中に進み入り、イスラエルの人々の部族の数にしたがって、おのおの石一つを取り上げ、肩にのせて運びなさい。</span>
<span className="v" id="v6" data-v="6" data-xref="出エジプト記 13:14; ヨシュア記 4:21; 詩篇 44:1"> これはあなたがたのうちに、しるしとなるであろう。後の日になって、あなたがたの子どもたちが、『これらの石は、どうしたわけですか』と問うならば、</span>
<span className="v" id="v7" data-v="7" data-xref="出エジプト記 12:14; 民数記 16:40; 出エジプト記 28:12"> その時あなたがたは彼らに、むかしヨルダンの水が、主の契約の箱の前で、せきとめられたこと、すなわちその箱がヨルダンを渡った時、ヨルダンの水が、せきとめられたことを告げなければならない。こうして、それらの石は永久にイスラエルの人々の記念となるであろう」。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="ヨシュア記 4:2–5; ヨシュア記 1:16–18; ヨシュア記 4:20"> イスラエルの人々はヨシュアが命じたようにし、主がヨシュアに言われたように、イスラエルの人々の部族の数にしたがって、ヨルダンの中から十二の石を取り、それを携えて渡り、彼らの宿る場所へ行って、そこにすえた。</span>
<span className="v" id="v9" data-v="9" data-xref="サムエル記上 7:12; 士師記 1:26; 歴代志下 5:9"> ヨシュアはまたヨルダンの中で、契約の箱をかく祭司たちが、足を踏みとどめた所に、十二の石を立てたが、今日まで、そこに残っている。</span>
<span className="v" id="v10" data-v="10" data-xref="ヨシュア記 3:13; 詩篇 119:60; 箴言 27:1"> 箱をかく祭司たちは、主がヨシュアに命じて、民に告げさせられた事が、すべて行われてしまうまで、ヨルダンの中に立っていた。すべてモーセがヨシュアに命じたとおりである。民は急いで渡った。</span>
<span className="v" id="v11" data-v="11" data-xref="ヨシュア記 3:8; ヨシュア記 4:18; ヨシュア記 3:17"> 民がみな渡り終った時、主の箱と祭司たちとは、民の見る前で渡った。</span>
<span className="v" id="v12" data-v="12" data-xref="民数記 32:20–32; ヨシュア記 1:14"> ルベンの子孫とガドの子孫、およびマナセの部族の半ばは、モーセが彼らに命じていたように武装して、イスラエルの人々に先立って渡り、</span>
<span className="v" id="v13" data-v="13" data-xref="エペソ人への手紙 6:11; エレミヤ書 39:5; エレミヤ書 52:8"> 戦いのために武装したおおよそ四万の者が戦うため、主の前に渡って、エリコの平野に着いた。</span>
<span className="v" id="v14" data-v="14" data-xref="ヨシュア記 3:7; 歴代志下 30:12; 列王紀上 3:28"> この日、主はイスラエルのすべての人の前にヨシュアを尊い者とされたので、彼らはみなモーセを敬ったように、ヨシュアを一生のあいだ敬った。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15"> 主はヨシュアに言われた、</span>
<span className="v" id="v16" data-v="16" data-xref="ヨハネの黙示録 11:19; 出エジプト記 25:16–22; ヨシュア記 3:3–6"> 「あかしの箱をかく祭司たちに命じて、ヨルダンから上がってこさせなさい」。</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 8:16–18; 使徒行伝 16:35–39; 使徒行伝 16:23"> ヨシュアは祭司たちに命じて言った、「ヨルダンから上がってきなさい」。</span>
<span className="v" id="v18" data-v="18" data-xref="ヨシュア記 3:15; 歴代志上 12:15; ヨシュア記 3:13"> 主の契約の箱をかく祭司たちはヨルダンの中から上がってきたが、祭司たちの足の裏がかわいた地にあがると同時に、ヨルダンの水はもとの所に流れかえって、以前のように、その岸にことごとくあふれた。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="ヨシュア記 5:9; ミカ書 6:5; 出エジプト記 12:2–3"> 民は正月の十日に、ヨルダンから上がってきて、エリコの東の境にあるギルガルに宿営した。</span>
<span className="v" id="v20" data-v="20" data-xref="ヨシュア記 4:3; ヨシュア記 4:8"> そしてヨシュアは、人々がヨルダンから取ってきた十二の石をギルガルに立て、</span>
<span className="v" id="v21" data-v="21" data-xref="ヨシュア記 4:6; 詩篇 145:4–7; 詩篇 105:2–5"> イスラエルの人々に言った、「後の日にあなたがたの子どもたちが、その父に『これらの石は、どうしたわけですか』とたずねたならば、</span>
<span className="v" id="v22" data-v="22" data-xref="ヨシュア記 3:17; イザヤ書 51:10; イザヤ書 44:27"> 『むかしイスラエルがこのヨルダンを、かわいた地にされて渡ったのだ』と言って、その子どもたちに知らせなければならない。</span>
<span className="v" id="v23" data-v="23" data-xref="出エジプト記 14:21; イザヤ書 43:16; イザヤ書 63:12–14"> すなわちあなたがたの神、主はヨルダンの水を、あなたがたのために干しからして、あなたがたを渡らせてくださった。それはあたかも、あなたがたの神、主が、われわれのために紅海を干しからして、われわれを渡らせてくださったのと同じである。</span>
<span className="v" id="v24" data-v="24" data-xref="詩篇 106:8; 詩篇 89:13; 列王紀上 8:42–43"> このようにされたのは、地のすべての民に、主の手に力のあることを知らせ、あなたがたの神、主をつねに恐れさせるためである」。</span>
</div>

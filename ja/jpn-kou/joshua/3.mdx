<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨシュア記 2:1; マルコによる福音書 1:35; 民数記 25:1"> ヨシュアは朝早く起き、イスラエルの人々すべてとともにシッテムを出立して、ヨルダンに行き、それを渡らずに、そこに宿った。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨシュア記 1:10–11"> 三日の後、つかさたちは宿営の中を行き巡り、</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 31:9; サムエル記下 6:13; 申命記 31:25"> 民に命じて言った、「レビびとである祭司たちが、あなたがたの神、主の契約の箱をかきあげるのを見るならば、あなたがたはその所を出立して、そのあとに従わなければならない。</span>
<span className="v" id="v4" data-v="4" data-xref="詩篇 89:7; ヘブル人への手紙 12:28–29; 出エジプト記 3:5"> そうすれば、あなたがたは行くべき道を知ることができるであろう。あなたがたは前にこの道をとおったことがないからである。しかし、あなたがたと箱との間には、おおよそ二千キュビトの距離をおかなければならない。それに近づいてはならない」。</span>
<span className="v" id="v5" data-v="5" data-xref="ヨシュア記 7:13; レビ記 20:7; ヨエル書 2:16"> ヨシュアはまた民に言った、「あなたがたは身を清めなさい。あす、主があなたがたのうちに不思議を行われるからである」。</span>
<span className="v" id="v6" data-v="6" data-xref="ヨハネによる福音書 14:2–3; 民数記 14:15; ミカ書 2:13"> ヨシュアは祭司たちに言った、「契約の箱をかき、民に先立って渡りなさい」。そこで彼らは契約の箱をかき、民に先立って進んだ。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="ヨシュア記 4:14; ヨシュア記 1:5; 歴代志上 29:25"> 主はヨシュアに言われた、「きょうからわたしはすべてのイスラエルの前にあなたを尊い者とするであろう。こうしてわたしがモーセと共にいたように、あなたとともにおることを彼らに知らせるであろう。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨシュア記 3:3; ヨシュア記 3:17; 歴代志下 29:15"> あなたは契約の箱をかく祭司たちに命じて言わなければならない、『あなたがたは、ヨルダンの水ぎわへ行くと、すぐ、ヨルダンの中に立ちとどまらなければならない』」。</span>
<span className="v" id="v9" data-v="9" data-xref="申命記 4:1; 申命記 12:8"> ヨシュアはイスラエルの人々に言った、「あなたがたはここに近づいて、あなたがたの神、主の言葉を聞きなさい」。</span>
<span className="v" id="v10" data-v="10" data-xref="申命記 7:1; 出エジプト記 33:2; 詩篇 44:2–3"> そしてヨシュアは言った、「生ける神があなたがたのうちにおいでになり、あなたがたの前から、カナンびと、ヘテびと、ヒビびと、ペリジびと、ギルガシびと、アモリびと、エブスびとを、必ず追い払われることを、次のことによって、あなたがたは知るであろう。</span>
<span className="v" id="v11" data-v="11" data-xref="ゼカリヤ書 6:5; ゼカリヤ書 4:14; 詩篇 24:1"> ごらんなさい。全地の主の契約の箱は、あなたがたに先立ってヨルダンを渡ろうとしている。</span>
<span className="v" id="v12" data-v="12" data-xref="ヨシュア記 4:2; ヨシュア記 4:9; ヨシュア記 4:4"> それゆえ、今、イスラエルの部族のうちから、部族ごとにひとりずつ、合わせて十二人を選びなさい。</span>
<span className="v" id="v13" data-v="13" data-xref="出エジプト記 15:8; 詩篇 78:13; ヨシュア記 3:15–16"> 全地の主なる神の箱をかく祭司たちの足の裏が、ヨルダンの水の中に踏みとどまる時、ヨルダンの水は流れをせきとめられ、上から流れくだる水はとどまって、うず高くなるであろう」。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="使徒行伝 7:44–45; ヨシュア記 6:6; コリント人への第一の手紙 1:24–25"> こうして民はヨルダンを渡ろうとして天幕をいで立ち、祭司たちは契約の箱をかき、民に先立って行ったが、</span>
<span className="v" id="v15" data-v="15" data-xref="歴代志上 12:15; ヨシュア記 4:18; ヨシュア記 3:13"> 箱をかく者がヨルダンにきて、箱をかく祭司たちの足が水ぎわにひたると同時に、――ヨルダンは刈入れの間中、岸一面にあふれるのであるが、――</span>
<span className="v" id="v16" data-v="16" data-xref="ヨシュア記 3:13; 列王紀上 4:12; 列王紀上 7:46"> 上から流れくだる水はとどまって、はるか遠くのザレタンのかたわらにある町アダムのあたりで、うず高く立ち、アラバの海すなわち塩の海の方に流れくだる水は全くせきとめられたので、民はエリコに向かって渡った。</span>
<span className="v" id="v17" data-v="17" data-xref="出エジプト記 14:22; 出エジプト記 14:29; 詩篇 66:6"> すべてのイスラエルが、かわいた地を渡って行く間、主の契約の箱をかく祭司たちは、ヨルダンの中のかわいた地に立っていた。そしてついに民はみなヨルダンを渡り終った。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨシュア記 2:24; ヨシュア記 2:9–14; 詩篇 127:1"> さてエリコは、イスラエルの人々のゆえに、かたく閉ざして、出入りするものがなかった。</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 7:24; ヨシュア記 8:1; ヨシュア記 2:24"> 主はヨシュアに言われた、「見よ、わたしはエリコと、その王および大勇士を、あなたの手にわたしている。</span>
<span className="v" id="v3" data-v="3" data-xref="コリント人への第二の手紙 4:7; 民数記 14:9; ヨシュア記 6:7"> あなたがた、いくさびとはみな、町を巡って、町の周囲を一度回らなければならない。六日の間そのようにしなければならない。</span>
<span className="v" id="v4" data-v="4" data-xref="歴代志下 20:17; ヨハネの黙示録 16:1; 列王紀上 18:43"> 七人の祭司たちは、おのおの雄羊の角のラッパを携えて、箱に先立たなければならない。そして七日目には七度町を巡り、祭司たちはラッパを吹き鳴らさなければならない。</span>
<span className="v" id="v5" data-v="5" data-xref="コリント人への第二の手紙 10:4–5; ヘブル人への手紙 11:30; 出エジプト記 19:19"> そして祭司たちが雄羊の角を長く吹き鳴らし、そのラッパの音が、あなたがたに聞える時、民はみな大声に呼ばわり、叫ばなければならない。そうすれば、町の周囲の石がきは、くずれ落ち、民はみなただちに進んで、攻め上ることができる」。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行伝 9:1; 申命記 20:2–4; ヨシュア記 3:3"> ヌンの子ヨシュアは祭司たちを召して言った、「あなたがたは契約の箱をかき、七人の祭司たちは雄羊の角のラッパ七本を携えて、主の箱に先立たなければならない」。</span>
<span className="v" id="v7" data-v="7" data-xref="ヨシュア記 4:13; ヨシュア記 6:3; ヨシュア記 1:14"> そして民に言った、「あなたがたは進んで行って町を巡りなさい。武装した者は主の箱に先立って進まなければならない」。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="民数記 32:20; ヨシュア記 6:3–4"> ヨシュアが民に命じたように、七人の祭司たちは、雄羊の角のラッパ七本を携えて、主に先立って進み、ラッパを吹き鳴らした。主の契約の箱はそのあとに従った。</span>
<span className="v" id="v9" data-v="9" data-xref="ヨシュア記 6:13; 民数記 10:25; イザヤ書 58:8"> 武装した者はラッパを吹き鳴らす祭司たちに先立って行き、しんがりは箱に従った。ラッパは絶え間なく鳴り響いた。</span>
<span className="v" id="v10" data-v="10" data-xref="ルカによる福音書 24:49; マタイによる福音書 12:19; イザヤ書 42:2"> しかし、ヨシュアは民に命じて言った、「あなたがたは呼ばわってはならない。あなたがたの声を聞えさせてはならない。また口から言葉を出してはならない。ただ、わたしが呼ばわれと命じる日に、あなたがたは呼ばわらなければならない」。</span>
<span className="v" id="v11" data-v="11"> こうして主の箱を持って、町を巡らせ、その周囲を一度回らせた。人々は宿営に帰り、夜を宿営で過ごした。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="ヨシュア記 3:1; ヘブル人への手紙 11:7–8; 創世記 22:3"> 翌朝ヨシュアは早く起き、祭司たちは主の箱をかき、</span>
<span className="v" id="v13" data-v="13" data-xref="ガラテヤ人への手紙 6:9; マタイによる福音書 24:13; 歴代志上 15:26"> 七人の祭司たちは、雄羊の角のラッパ七本を携えて、主の箱に先立ち、絶えず、ラッパを吹き鳴らして進み、武装した者はこれに先立って行き、しんがりは主の箱に従った。ラッパは絶え間なく鳴り響いた。</span>
<span className="v" id="v14" data-v="14" data-xref="ヨシュア記 6:15; ヨシュア記 6:11; ヨシュア記 6:3"> その次の日にも、町の周囲を一度巡って宿営に帰った。六日の間そのようにした。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="詩篇 119:147; ペテロの第二の手紙 1:19; マタイによる福音書 28:1"> 七日目には、夜明けに、早く起き、同じようにして、町を七度めぐった。町を七度めぐったのはこの日だけであった。</span>
<span className="v" id="v16" data-v="16" data-xref="歴代志下 13:15; ヨシュア記 6:5; 歴代志下 20:22–23"> 七度目に、祭司たちがラッパを吹いた時、ヨシュアは民に言った、「呼ばわりなさい。主はこの町をあなたがたに賜わった。</span>
<span className="v" id="v17" data-v="17" data-xref="申命記 20:17; ヤコブの手紙 2:25; ミカ書 4:13"> この町と、その中のすべてのものは、主への奉納物として滅ぼされなければならない。ただし遊女ラハブと、その家に共におる者はみな生かしておかなければならない。われわれが送った使者たちをかくまったからである。</span>
<span className="v" id="v18" data-v="18" data-xref="ヨハネの第一の手紙 5:21; エペソ人への手紙 5:11; ヨシュア記 7:1"> また、あなたがたは、奉納物に手を触れてはならない。奉納に当り、その奉納物をみずから取って、イスラエルの宿営を、滅ぼさるべきものとし、それを悩ますことのないためである。</span>
<span className="v" id="v19" data-v="19" data-xref="歴代志上 26:20; マタイによる福音書 27:6; マルコによる福音書 12:41"> ただし、銀と金、青銅と鉄の器は、みな主に聖なる物であるから、主の倉に携え入れなければならない」。</span>
<span className="v" id="v20" data-v="20" data-xref="ヘブル人への手紙 11:30; コリント人への第二の手紙 10:4–5; ヨシュア記 6:5"> そこで民は呼ばわり、祭司たちはラッパを吹き鳴らした。民はラッパの音を聞くと同時に、みな大声をあげて呼ばわったので、石がきはくずれ落ちた。そこで民はみな、すぐに上って町にはいり、町を攻め取った。</span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 137:8–9; エレミヤ書 48:18; ヨシュア記 11:14"> そして町にあるものは、男も、女も、若い者も、老いた者も、また牛、羊、ろばをも、ことごとくつるぎにかけて滅ぼした。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="ヘブル人への手紙 11:31; ヨシュア記 6:17; エゼキエル書 17:18–19"> その時ヨシュアは、この地を探ったふたりの人に言った、「あの遊女の家にはいって、その女と彼女に属するすべてのものを連れ出し、彼女に誓ったようにしなさい」。</span>
<span className="v" id="v23" data-v="23" data-xref="ヘブル人への手紙 11:7; 創世記 18:24; 使徒行伝 27:24"> 斥候となったその若い人たちははいって、ラハブとその父母、兄弟、そのほか彼女に属するすべてのものを連れ出し、その親族をみな連れ出して、イスラエルの宿営の外に置いた。</span>
<span className="v" id="v24" data-v="24" data-xref="ヨシュア記 8:28; ヨハネの黙示録 17:16; 列王紀下 25:9"> そして火で町とその中のすべてのものを焼いた。ただ、銀と金、青銅と鉄の器は、主の家の倉に納めた。</span>
<span className="v" id="v25" data-v="25" data-xref="ヘブル人への手紙 11:31; マタイによる福音書 1:5; 士師記 1:24–25"> しかし、遊女ラハブとその父の家の一族と彼女に属するすべてのものとは、ヨシュアが生かしておいたので、ラハブは今日までイスラエルのうちに住んでいる。これはヨシュアがエリコを探らせるためにつかわした使者たちをかくまったためである。</span>
</div>
<div className="bp poetry">
<span className="v" id="v26" data-v="26" data-xref="列王紀上 16:34; 使徒行伝 19:13; 民数記 5:19–21"> ヨシュアは、その時、人々に誓いを立てて言った、「おおよそ立って、このエリコの町を再建する人は、主の前にのろわれるであろう。<br /><span className="pl pl-1">その礎をすえる人は長子を失い、</span><br /><span className="pl pl-1">その門を建てる人は末の子を失うであろう」。</span></span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="ヨシュア記 9:3; ヨシュア記 1:5; マタイによる福音書 28:20"> 主はヨシュアと共におられ、ヨシュアの名声は、あまねくその地に広がった。</span>
</div>

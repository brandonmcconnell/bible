<span className="v" id="v1" data-v="1" data-xref="申命記 3:8–9; 士師記 11:18; ヨシュア記 1:15"> さてヨルダンの向こう側、日の出の方で、アルノンの谷からヘルモン山まで、および東アラバの全土のうちで、イスラエルの人々が撃ち滅ぼして地を取った国の王たちは、次のとおりである。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 32:22; 士師記 11:22; 詩篇 136:19–20"> まず、アモリびとの王シホン。彼はヘシボンに住み、その領地は、アルノンの谷のほとりにあるアロエル、および谷の中の町から、ギレアデの半ばを占めて、アンモンびととの境であるヤボク川に達し、</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 3:17; ヨシュア記 13:20; ヨシュア記 11:2"> 東の方ではアラバをキンネレテの湖まで占め、またアラバの海すなわち塩の海の東におよび、ベテエシモテの道を経て、南はピスガの山のふもとに達した。</span>
<span className="v" id="v4" data-v="4" data-xref="申命記 1:4; 申命記 3:10–11; ヨシュア記 13:12"> 次にレパイムの生き残りのひとりであったバシャンの王オグ。彼はアシタロテとエデレイとに住み、</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 3:14; サムエル記上 27:8; ヨシュア記 13:11"> ヘルモン山、サレカ、およびバシャンの全土を領したので、ゲシュルびと、およびマアカびとと境を接し、またギレアデの半ばを領したので、ヘシボンの王シホンと境を接していた。</span>
<span className="v" id="v6" data-v="6" data-xref="民数記 32:33; 民数記 32:29; ルカによる福音書 22:29–42"> 主のしもべモーセと、イスラエルの人々とが、彼らを撃ち滅ぼし、そして主のしもべモーセは、これらの地を、ルベンびと、ガドびと、およびマナセの半部族に与えて所有とさせた。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="ヨシュア記 11:17; ヨシュア記 11:23–1; ヨシュア記 1:3–4"> ヨルダンのこちら側、西の方にあって、レバノンの谷にあるバアルガデから、セイルへ上って行く道のハラク山までの間で、ヨシュアと、イスラエルの人々とが、撃ち滅ぼした国の王たちは、次のとおりである。ヨシュアは彼らの地をイスラエルの部族に、それぞれの分を与えて嗣業とさせた。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨシュア記 11:16; ヨシュア記 10:40; ヨシュア記 9:1"> これは、山地、平地、アラバ、山腹、荒野、およびネゲブであって、ヘテびと、アモリびと、カナンびと、ペリジびと、ヒビびと、エブスびとの所領であった。</span>
<span className="v" id="v9" data-v="9" data-xref="ヨシュア記 8:29–35; ヨシュア記 6:2–21; ヨシュア記 8:1"> エリコの王ひとり。ベテルのほとりのアイの王ひとり。</span>
<span className="v" id="v10" data-v="10" data-xref="ヨシュア記 10:23; ヨシュア記 10:36–37; ヨシュア記 10:3"> エルサレムの王ひとり。ヘブロンの王ひとり。</span>
<span className="v" id="v11" data-v="11" data-xref="ヨシュア記 10:31–32; ヨシュア記 10:3–23"> ヤルムテの王ひとり。ラキシの王ひとり。</span>
<span className="v" id="v12" data-v="12" data-xref="ヨシュア記 10:33; ヨシュア記 15:39; ヨシュア記 10:3"> エグロンの王ひとり。ゲゼルの王ひとり。</span>
<span className="v" id="v13" data-v="13" data-xref="ヨシュア記 10:38; ヨシュア記 10:3; ヨシュア記 15:36"> デビルの王ひとり。ゲデルの王ひとり。</span>
<span className="v" id="v14" data-v="14" data-xref="民数記 21:1; 民数記 14:45; 民数記 21:3"> ホルマの王ひとり。アラデの王ひとり。</span>
<span className="v" id="v15" data-v="15" data-xref="ヨシュア記 10:29–30; サムエル記上 22:1"> リブナの王ひとり。アドラムの王ひとり。</span>
<span className="v" id="v16" data-v="16" data-xref="ヨシュア記 10:28; 士師記 1:22; ヨシュア記 8:17"> マッケダの王ひとり。ベテルの王ひとり。</span>
<span className="v" id="v17" data-v="17" data-xref="列王紀上 4:10; ヨシュア記 15:34; ヨシュア記 19:13"> タップアの王ひとり。ヘペルの王ひとり。</span>
<span className="v" id="v18" data-v="18" data-xref="ヨシュア記 19:30; イザヤ書 33:9; ヨシュア記 13:4"> アペクの王ひとり。シャロンの王ひとり。</span>
<span className="v" id="v19" data-v="19" data-xref="ヨシュア記 11:1; 士師記 4:2; ヨシュア記 11:10–11"> マドンの王ひとり。ハゾルの王ひとり。</span>
<span className="v" id="v20" data-v="20" data-xref="ヨシュア記 11:1; ヨシュア記 19:15; ヨシュア記 19:25"> シムロン・メロンの王ひとり。アクサフの王ひとり。</span>
<span className="v" id="v21" data-v="21" data-xref="ヨシュア記 17:11; 列王紀下 23:29–30; 士師記 5:19"> タアナクの王ひとり。メギドの王ひとり。</span>
<span className="v" id="v22" data-v="22" data-xref="ヨシュア記 19:37; ヨシュア記 21:32; ヨシュア記 15:23"> ケデシの王ひとり。カルメルのヨクネアムの王ひとり。</span>
<span className="v" id="v23" data-v="23" data-xref="ヨシュア記 11:2; 創世記 14:1–2; ヨシュア記 4:19"> ドルの高地におるドルの王ひとり。ガリラヤのゴイイムの王ひとり。</span>
<span className="v" id="v24" data-v="24" data-xref="列王紀下 15:14; 列王紀上 16:23; 申命記 7:24"> テルザの王ひとり。合わせて三十一王である。</span>

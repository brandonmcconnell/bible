<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数記 26:55–56; ヨシュア記 14:2; 民数記 33:36–37"> ユダの人々の部族が、その家族にしたがって、くじで獲た地は、南の方では、エドムの境に達し、南のはてにあるチンの荒野に及んでいた。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 14:3; エゼキエル書 47:8; イザヤ書 11:15"> その南の境は、塩の海の南の端の、入海から起り、</span>
<span className="v" id="v3" data-v="3" data-xref="民数記 34:4; 士師記 1:36; 民数記 20:1"> アクラビムの坂の南に出てチンに進み、カデシ・バルネアの南から上って、ヘヅロンに進み、アダルに上っていって、カルカに回り、</span>
<span className="v" id="v4" data-v="4" data-xref="民数記 34:5; ヨシュア記 13:3; 出エジプト記 23:31"> アヅモンに進んで、エジプトの川に達し、その境は海に至って尽きる。これが彼らの南の境である。</span>
<span className="v" id="v5" data-v="5" data-xref="民数記 34:12; ヨシュア記 18:15–19; 民数記 34:10"> 東の境は塩の海であって、ヨルダンの川口に達する。北の方の境は、ヨルダンの川口の、入海から起り、</span>
<span className="v" id="v6" data-v="6" data-xref="ヨシュア記 18:17; ヨシュア記 18:19–21"> 上ってベテホグラに行き、ベテアラバの北を過ぎ、上ってルベンびとボハンの石に達し、</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀上 1:9; サムエル記下 17:17; ヨシュア記 7:26"> またアコルの谷からデビルに上って、北におもむき、川の南にあるアドミムの坂に対するギルガルに向かって進み、エンシメシの水に達し、エンロゲルに至って尽きる。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨシュア記 18:16; ヨシュア記 15:63; ヨシュア記 18:28"> またその境はベンヒンノムの谷に沿って、エブスびとの地、すなわちエルサレムの南のわきに上り、ヒンノムの谷の西にある山の頂に上る。これはレパイムの谷の北の果にあるものである。</span>
<span className="v" id="v9" data-v="9" data-xref="歴代志上 13:6; ヨシュア記 18:15; 士師記 18:12"> その境は、この山の頂からネフトアの水の源に至り、その所からエフロン山の町々に及び、その境は曲ってバアラに達する。これは、すなわちキリアテ・ヤリムである。</span>
<span className="v" id="v10" data-v="10" data-xref="士師記 14:1; 士師記 14:5; 創世記 38:12–13"> その境は、バアラから西に回って、セイル山に及び、ヤリム山、すなわちケサロンの北のわきを経て、ベテシメシに下り、テムナに進み、</span>
<span className="v" id="v11" data-v="11" data-xref="ヨシュア記 15:45; 列王紀下 1:2–3; サムエル記上 5:10"> エクロンの北の丘のわきに出て、シッケロンに曲り、バアラ山に進み、ヤブネルに達し、海に至って尽きる。</span>
<span className="v" id="v12" data-v="12" data-xref="民数記 34:6–7; ヨシュア記 15:47; エゼキエル書 47:20"> また西の境は大海であって、海岸を境とした。これがユダの人々の、その家族にしたがって獲た地の四方の境である。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="民数記 13:30; 申命記 1:34–36; 民数記 14:23–24"> ヨシュアは、主に命じられたように、エフンネの子カレブに、ユダの人々のうちで、キリアテ・アルバ、すなわちヘブロンを与えて、その分とさせた。アルバはアナクの父であった。</span>
<span className="v" id="v14" data-v="14" data-xref="士師記 1:20; 士師記 1:10; 民数記 13:22–23"> カレブはその所から、アナクの子三人を追い払った。すなわち、セシャイ、アヒマン、およびタルマイであって、アナクから出たものである。</span>
<span className="v" id="v15" data-v="15" data-xref="ヨシュア記 10:38; ヨシュア記 10:3; 士師記 1:11–13"> そして彼はこの所からデビルに住む民の所に攻め上った。デビルの名は、もとはキリアテ・セペルといった。</span>
<span className="v" id="v16" data-v="16" data-xref="士師記 1:12–13; 士師記 1:6"> カレブは言った、「キリアテ・セペルを撃って、これを取る者には、わたしの娘アクサを妻として与えるであろう」。</span>
<span className="v" id="v17" data-v="17" data-xref="士師記 3:9; 士師記 1:13; ヨシュア記 14:6"> ケナズの子で、カレブの弟オテニエルがそれを取ったので、カレブは娘アクサを、妻として彼に与えた。</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 24:64; サムエル記上 25:23"> 彼女がとつぐ時、畑を父に求めるようにと、オテニエルに勧められた。そして彼女が、ろばから降りたので、カレブは彼女に、何を望むのかとたずねた。</span>
<span className="v" id="v19" data-v="19" data-xref="士師記 1:14–15; サムエル記上 25:27; 申命記 33:7"> 彼女は答えて言った、「わたしに贈り物をください。あなたはネゲブの地に、わたしをやられるのですから、泉をもください」。カレブは彼女に上の泉と下の泉とを与えた。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="創世記 49:8–12; 申命記 33:7"> ユダの人々の部族が、その家族にしたがって獲た嗣業は、次のとおりである。</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 35:21; ネヘミヤ書 11:25"> ユダの人々の部族が、南でエドムの境の方にもっていた遠くの町々は、カブジエル、エデル、ヤグル、</span>
<span className="v" id="v22" data-v="22"> キナ、デモナ、アダダ、</span>
<span className="v" id="v23" data-v="23" data-xref="ヨシュア記 12:22; 民数記 33:37; 申命記 1:19"> ケデシ、ハゾル、イテナン、</span>
<span className="v" id="v24" data-v="24" data-xref="サムエル記上 23:14; サムエル記上 23:24; サムエル記上 23:19"> ジフ、テレム、ベアロテ、</span>
<span className="v" id="v25" data-v="25"> ハゾル・ハダッタ、ケリオテ・ヘヅロンすなわちハゾル、</span>
<span className="v" id="v26" data-v="26" data-xref="歴代志上 4:28"> アマム、シマ、モラダ、</span>
<span className="v" id="v27" data-v="27" data-xref="ネヘミヤ書 11:26"> ハザルガダ、ヘシモン、ベテペレテ、</span>
<span className="v" id="v28" data-v="28" data-xref="創世記 26:33; 歴代志上 4:28; 創世記 21:31–33"> ハザル・シュアル、ベエルシバ、ビジョテヤ、</span>
<span className="v" id="v29" data-v="29" data-xref="ヨシュア記 15:9–11; ヨシュア記 19:3; 歴代志上 4:29"> バアラ、イイム、エゼム、</span>
<span className="v" id="v30" data-v="30" data-xref="ヨシュア記 19:4; 民数記 14:45; 申命記 1:44"> エルトラデ、ケシル、ホルマ、</span>
<span className="v" id="v31" data-v="31" data-xref="サムエル記上 27:6; サムエル記上 30:1; 歴代志上 12:1"> チクラグ、マデマンナ、サンサンナ、</span>
<span className="v" id="v32" data-v="32" data-xref="民数記 34:11; ネヘミヤ書 11:29"> レバオテ、シルヒム、アイン、リンモン。これらの町は合わせて二十九、ならびにそれに属する村々。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="士師記 13:25; 士師記 16:31; 民数記 13:23"> 平地では、エシタオル、ゾラ、アシナ、</span>
<span className="v" id="v34" data-v="34" data-xref="ヨシュア記 12:17; ヨシュア記 15:53"> ザノア、エンガンニム、タップア、エナム、</span>
<span className="v" id="v35" data-v="35" data-xref="サムエル記上 17:1; サムエル記上 22:1; ヨシュア記 10:3"> ヤルムテ、アドラム、ソコ、アゼカ、</span>
<span className="v" id="v36" data-v="36" data-xref="サムエル記上 17:52"> シャアライム、アデタイム、ゲデラ、ゲデロタイム。すなわち十四の町々と、それに属する村々。</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37"> ゼナン、ハダシャ、ミグダルガデ、</span>
<span className="v" id="v38" data-v="38" data-xref="列王紀下 14:7; 士師記 20:1; サムエル記上 10:17"> デラン、ミヅパ、ヨクテル、</span>

<span className="v" id="v41" data-v="41" data-xref="ヨシュア記 10:21; ヨシュア記 12:16; ヨシュア記 10:10"> ゲデロテ、ベテダゴン、ナアマ、マッケダ。すなわち十六の町々と、それに属する村々。</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="ヨシュア記 10:29; 列王紀下 8:22; ヨシュア記 19:7"> またリブナ、エテル、アシャン、</span>
<span className="v" id="v43" data-v="43"> イフタ、アシナ、ネジブ、</span>
<span className="v" id="v44" data-v="44" data-xref="創世記 38:5; ミカ書 1:14–15; サムエル記上 23:1–14"> ケイラ、アクジブ、マレシャ。すなわち九つの町々と、それに属する村々。</span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="ヨシュア記 13:3; アモス書 1:8; サムエル記上 6:17"> エクロンと、その町々、および村々。</span>
<span className="v" id="v46" data-v="46" data-xref="歴代志下 26:6; アモス書 1:8; サムエル記上 5:1"> エクロンから海まで、すべてアシドドのほとりにある町々、およびそれに属する村々。</span>
</div>
<div className="bp">
<span className="v" id="v47" data-v="47" data-xref="ヨシュア記 15:4; 出エジプト記 23:31; アモス書 1:6–7"> アシドドとその町々および村々。ガザとその町々および村々。エジプトの川と大海の海岸までが、その境であった。</span>
</div>
<div className="bp">
<span className="v" id="v48" data-v="48" data-xref="ヨシュア記 21:14"> 山地では、シャミル、ヤッテル、ソコ、</span>
<span className="v" id="v49" data-v="49" data-xref="ヨシュア記 15:15; 士師記 1:11"> ダンナ、キリアテ・サンナすなわちデビル、</span>
<span className="v" id="v50" data-v="50"> アナブ、エシテモ、アニム、</span>
<span className="v" id="v51" data-v="51" data-xref="ヨシュア記 11:16; ヨシュア記 10:41; サムエル記下 15:12"> ゴセン、ホロン、ギロ。すなわち十一の町々と、それに属する村々。</span>
</div>
<div className="bp">
<span className="v" id="v52" data-v="52" data-xref="イザヤ書 21:11"> アラブ、ドマ、エシャン、</span>
<span className="v" id="v53" data-v="53"> ヤニム、ベテタップア、アペカ、</span>
<span className="v" id="v54" data-v="54" data-xref="ヨシュア記 15:13; 創世記 23:2; ヨシュア記 14:15"> ホムタ、キリアテ・アルバすなわちヘブロン、ヂオル。すなわち九つの町々と、それに属する村々。</span>
</div>
<div className="bp">
<span className="v" id="v55" data-v="55" data-xref="サムエル記上 25:2; ヨシュア記 15:24; サムエル記上 23:25"> マオン、カルメル、ジフ、ユッタ、</span>
<span className="v" id="v56" data-v="56"> エズレル、ヨクデアム、ザノア、</span>
<span className="v" id="v57" data-v="57" data-xref="ヨシュア記 15:10; 創世記 38:12; エレミヤ書 14:1"> カイン、ギベア、テムナ。すなわち十の町々と、それに属する村々。</span>
</div>
<div className="bp">
<span className="v" id="v58" data-v="58" data-xref="歴代志上 4:39"> ハルホル、ベテズル、ゲドル、</span>
<span className="v" id="v59" data-v="59"> マアラテ、ベテアノテ、エルテコン。すなわち六つの町々と、それに属する村々。</span>
</div>
<div className="bp">
<span className="v" id="v60" data-v="60" data-xref="ヨシュア記 18:14; サムエル記上 7:1"> キリアテ・バアルすなわちキリアテ・ヤリム、ラバ。これらの二つの町とそれに属する村々。</span>
</div>
<div className="bp">
<span className="v" id="v61" data-v="61" data-xref="ヨシュア記 15:6; ヨシュア記 18:18"> 荒野では、ベテアラバ、ミデン、セカカ、</span>

</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨシュア記 23:2; サムエル記上 10:19; 創世記 33:18–19"> ヨシュアは、イスラエルのすべての部族をシケムに集め、イスラエルの長老、かしら、さばきびと、つかさたちを召し寄せて、共に神の前に進み出た。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨシュア記 24:15; エゼキエル書 16:3; 創世記 31:30"> そしてヨシュアはすべての民に言った、「イスラエルの神、主は、こう仰せられる、『あなたがたの先祖たち、すなわちアブラハムの父、ナホルの父テラは、昔、ユフラテ川の向こうに住み、みな、ほかの神々に仕えていたが、</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 12:1–4; 創世記 21:2–3; 使徒行伝 7:2–3"> わたしは、あなたがたの先祖アブラハムを、川の向こうから連れ出して、カナンの全地を導き通り、その子孫を増した。わたしは彼にイサクを与え、</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 36:8; 申命記 2:5; 創世記 25:24–26"> イサクにヤコブとエサウを与え、エサウにはセイルの山地を与えて、所有とさせたが、ヤコブとその子供たちはエジプトに下った。</span>
<span className="v" id="v5" data-v="5" data-xref="出エジプト記 3:10; 出エジプト記 7:1–12; 詩篇 105:26–36"> わたしはモーセとアロンをつかわし、またエジプトのうちに不思議をおこなって、これに災を下し、その後あなたがたを導き出した。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行伝 7:36; ヘブル人への手紙 11:29; イザヤ書 63:12–13"> わたしはあなたがたの父たちを、エジプトから導き出し、あなたがたが海にきたとき、エジプトびとは、戦車と騎兵とをもって、あなたがたの父たちを紅海に追ってきた。</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 4:34; 出エジプト記 14:10; 出エジプト記 14:20"> そのとき、あなたがたの父たちが主に呼ばわったので、主は暗やみをあなたがたとエジプトびととの間に置き、海を彼らの上に傾けて彼らをおおわれた。あなたがたは、わたしがエジプトでしたことを目で見た。そして長い間、荒野に住んでいた。</span>
<span className="v" id="v8" data-v="8" data-xref="民数記 21:21–35; 詩篇 135:10–11; ネヘミヤ書 9:22"> わたしはまたヨルダンの向こう側に住んでいたアモリびとの地に、あなたがたを導き入れた。彼らはあなたがたと戦ったので、わたしは彼らをあなたがたの手に渡して、彼らの地を獲させ、彼らをあなたがたの前から滅ぼし去った。</span>
<span className="v" id="v9" data-v="9" data-xref="士師記 11:25; ミカ書 6:5; 民数記 22:2"> ついで、モアブの王チッポルの子バラクが立って、イスラエルに敵し、人をつかわし、ベオルの子バラムを招き、あなたがたをのろわせようとしたが、</span>
<span className="v" id="v10" data-v="10" data-xref="申命記 23:5; 民数記 24:5–10; イザヤ書 54:17"> わたしがバラムに聞こうとしなかったので、彼は、かえって、あなたがたを祝福した。こうしてわたしは彼の手からあなたがたを救い出した。</span>
<span className="v" id="v11" data-v="11" data-xref="ヨシュア記 4:10–12; ヨシュア記 3:14–17; 詩篇 114:5"> そしてあなたがたは、ヨルダンを渡って、エリコにきたが、エリコの人々はあなたがたと戦い、アモリびと、ペリジびと、カナンびと、ヘテびと、ギルガシびと、ヒビびと、およびエブスびとも、あなたがたと戦ったが、わたしは彼らをあなたがたの手に渡した。</span>
<span className="v" id="v12" data-v="12" data-xref="申命記 7:20; 出エジプト記 23:28; 詩篇 44:3–6"> わたしは、あなたがたの前に、くまばちを送って、あのアモリびとのふたりの王を、あなたがたの前から追い払った。これはあなたがたのつるぎ、または、あなたがたの弓によってではなかった。</span>
<span className="v" id="v13" data-v="13" data-xref="申命記 6:10–12; 申命記 8:7; ヨシュア記 21:45"> そしてわたしは、あなたがたが自分で労しなかった地を、あなたがたに与え、あなたがたが建てなかった町を、あなたがたに与えた。そしてあなたがたはいまその所に住んでいる。あなたがたはまた自分で作らなかったぶどう畑と、オリブ畑の実を食べている』。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="サムエル記上 12:24; 申命記 10:12; 創世記 35:2"> それゆえ、いま、あなたがたは主を恐れ、まことと、まごころと、真実とをもって、主に仕え、あなたがたの先祖が、川の向こう、およびエジプトで仕えた他の神々を除き去って、主に仕えなさい。</span>
<span className="v" id="v15" data-v="15" data-xref="列王紀上 18:21; ヨハネによる福音書 6:67–68; ルツ記 1:15–16"> もしあなたがたが主に仕えることを、こころよしとしないのならば、あなたがたの先祖が、川の向こうで仕えた神々でも、または、いまあなたがたの住む地のアモリびとの神々でも、あなたがたの仕える者を、きょう、選びなさい。ただし、わたしとわたしの家とは共に主に仕えます」。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="ヘブル人への手紙 10:38–39; サムエル記上 12:23; ローマ人への手紙 6:2"> その時、民は答えて言った、「主を捨てて、他の神々に仕えるなど、われわれは決していたしません。</span>
<span className="v" id="v17" data-v="17" data-xref="出エジプト記 19:4; イザヤ書 63:7–14; イザヤ書 46:4"> われわれの神、主がみずからわれわれと、われわれの先祖とを、エジプトの地、奴隷の家から導き上り、またわれわれの目の前で、あの大いなるしるしを行い、われわれの行くすべての道で守り、われわれが通ったすべての国民の中でわれわれを守られたからです。</span>
<span className="v" id="v18" data-v="18" data-xref="ミカ書 4:2; 出エジプト記 10:2; 詩篇 116:16"> 主はまた、この地に住んでいたアモリびとなど、すべての民を、われわれの前から追い払われました。それゆえ、われわれも主に仕えます。主はわれわれの神だからです」。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="イザヤ書 5:16; 出エジプト記 23:21; 詩篇 99:9"> しかし、ヨシュアは民に言った、「あなたがたは主に仕えることはできないであろう。主は聖なる神であり、ねたむ神であって、あなたがたの罪、あなたがたのとがを、ゆるされないからである。</span>
<span className="v" id="v20" data-v="20" data-xref="ヘブル人への手紙 10:26–27; エゼキエル書 18:24; 歴代志上 28:9"> もしあなたがたが主を捨てて、異なる神々に仕えるならば、あなたがたにさいわいを下されたのちにも、ひるがえってあなたがたに災をくだし、あなたがたを滅ぼしつくされるであろう」。</span>
<span className="v" id="v21" data-v="21" data-xref="出エジプト記 20:19; イザヤ書 44:5; 申命記 5:27–28"> 民はヨシュアに言った、「いいえ、われわれは主に仕えます」。</span>
<span className="v" id="v22" data-v="22" data-xref="詩篇 119:173; 詩篇 119:11; ヨブ記 15:6"> そこでヨシュアは民に言った、「あなたがたは主を選んで、主に仕えると言った。あなたがたみずからその証人である」。彼らは言った、「われわれは証人です」。</span>
<span className="v" id="v23" data-v="23" data-xref="コリント人への第二の手紙 6:16–18; ヨシュア記 24:14; ヘブル人への手紙 12:28–29"> ヨシュアはまた言った、「それならば、あなたがたのうちにある、異なる神々を除き去り、イスラエルの神、主に、心を傾けなさい」。</span>
<span className="v" id="v24" data-v="24" data-xref="出エジプト記 24:7; 出エジプト記 24:3; 申命記 5:27–29"> 民はヨシュアに言った、「われわれの神、主に、われわれは仕え、その声に聞きしたがいます」。</span>
<span className="v" id="v25" data-v="25" data-xref="ネヘミヤ書 9:38; 歴代志下 23:16; 出エジプト記 15:25"> こうしてヨシュアは、その日、民と契約をむすび、シケムにおいて、定めと、おきてを、彼らのために設けた。</span>
<span className="v" id="v26" data-v="26" data-xref="士師記 9:6; 創世記 35:4; ヨシュア記 4:20–24"> ヨシュアはこれらの言葉を神の律法の書にしるし、大きな石を取って、その所で、主の聖所にあるかしの木の下にそれを立て、</span>
<span className="v" id="v27" data-v="27" data-xref="ルカによる福音書 19:40; ヨシュア記 22:34; ヨシュア記 22:27–28"> ヨシュアは、すべての民に言った、「見よ、この石はわれわれのあかしとなるであろう。主がわれわれに語られたすべての言葉を、聞いたからである。それゆえ、あなたがたが自分の神を捨てることのないために、この石が、あなたがたのあかしとなるであろう」。</span>
<span className="v" id="v28" data-v="28" data-xref="士師記 2:6"> こうしてヨシュアは民を、おのおのその嗣業の地に帰し去らせた。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="士師記 2:8; テモテヘの第二の手紙 4:7–8; 申命記 34:5"> これらの事の後、主のしもべ、ヌンの子ヨシュアは百十歳で死んだ、</span>
<span className="v" id="v30" data-v="30" data-xref="ヨシュア記 19:50; 士師記 2:9; サムエル記下 23:30"> 人々は彼をその嗣業の地のうちのテムナテ・セラに葬った。テムナテ・セラは、エフライムの山地で、ガアシ山の北にある。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="士師記 2:7; 申命記 31:13; 申命記 11:2"> イスラエルはヨシュアの世にある日の間、また主がイスラエルのために行われたもろもろのことを知っていて、ヨシュアのあとに生き残った長老たちが世にある日の間、つねに主に仕えた。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="創世記 50:25; 創世記 33:19; 出エジプト記 13:19"> イスラエルの人々が、エジプトから携え上ったヨセフの骨は、むかしヤコブが銀百枚で、シケムの父ハモルの子らから買い取ったシケムのうちの地所の一部に葬られた。これはヨセフの子孫の嗣業となった。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="ヨシュア記 22:13; 出エジプト記 6:25; イザヤ書 57:1–2"> アロンの子エレアザルも死んだ。人々は彼を、その子ピネハスに与えられた町で、エフライムの山地にあるギベアに葬った。</span>
</div>
</div>

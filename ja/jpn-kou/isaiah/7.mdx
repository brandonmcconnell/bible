<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀下 15:37; 列王紀下 16:1; イザヤ書 1:1"> ユダの王、ウジヤの子ヨタム、その子アハズの時、スリヤの王レヂンとレマリヤの子であるイスラエルの王ペカとが上ってきて、エルサレムを攻めたが勝つことができなかった。</span>
<span className="v" id="v2" data-v="2" data-xref="イザヤ書 8:12; イザヤ書 7:13; イザヤ書 9:9"> 時に「スリヤがエフライムと同盟している」とダビデの家に告げる者があったので、王の心と民の心とは風に動かされる林の木のように動揺した。</span>
</div>
<div className="bp poetry">
<span className="v" id="v3" data-v="3" data-xref="列王紀下 18:17; イザヤ書 36:2; ローマ人への手紙 9:27"> その時、主はイザヤに言われた、「今、あなたとあなたの子シャル・ヤシュブと共に出て行って、布さらしの野へ行く大路に沿う上の池の水道の端でアハズに会い、</span>
<span className="v" id="v4" data-v="4" data-xref="イザヤ書 35:4; 哀歌 3:26; 申命記 20:3"> 彼に言いなさい、『気をつけて、静かにし、恐れてはならない。レヂンとスリヤおよびレマリヤの子が激しく怒っても、これら二つの燃え残りのくすぶっている切り株のゆえに心を弱くしてはならない。</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 83:3–4; ゼカリヤ書 1:15; 詩篇 2:2"> スリヤはエフライムおよびレマリヤの子と共にあなたにむかって悪い事を企てて言う、</span>
<span className="v" id="v6" data-v="6"> 「われわれはユダに攻め上って、これを脅し、われわれのためにこれを破り取り、タビエルの子をそこの王にしよう」と。</span>
<span className="v" id="v7" data-v="7" data-xref="イザヤ書 8:10; 哀歌 3:37; イザヤ書 46:10–11"> <span className="pl pl-1">主なる神はこう言われる、</span><br /><span className="pl pl-1">この事は決して行われない、また起ることはない。</span></span>
<span className="v" id="v8" data-v="8" data-xref="イザヤ書 17:1–3; 創世記 14:15; サムエル記下 8:6"> <span className="pl pl-1">スリヤのかしらはダマスコ、</span><br /><span className="pl pl-1">ダマスコのかしらはレヂンである。</span><br /><span className="pl pl-1">（六十五年のうちにエフライムは敗れて、国をなさないようになる。）</span></span>
<span className="v" id="v9" data-v="9" data-xref="ヘブル人への手紙 11:6; ローマ人への手紙 11:20; 歴代志下 20:20"> <span className="pl pl-1">エフライムのかしらはサマリヤ、</span><br /><span className="pl pl-1">サマリヤのかしらはレマリヤの子である。</span><br /><span className="pl pl-1">もしあなたがたが信じないならば、立つことはできない』」。</span></span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="イザヤ書 8:5; イザヤ書 1:5; イザヤ書 10:20"> 主は再びアハズに告げて言われた、</span>
<span className="v" id="v11" data-v="11" data-xref="イザヤ書 37:30; イザヤ書 38:7–8; イザヤ書 38:22"> 「あなたの神、主に一つのしるしを求めよ、陰府のように深い所に、あるいは天のように高い所に求めよ」。</span>
<span className="v" id="v12" data-v="12" data-xref="エゼキエル書 33:31; 歴代志下 28:22; マラキ書 3:15"> しかしアハズは言った、「わたしはそれを求めて、主を試みることをいたしません」。</span>
<span className="v" id="v13" data-v="13" data-xref="イザヤ書 43:24; イザヤ書 63:10; エゼキエル書 34:18"> そこでイザヤは言った、「ダビデの家よ、聞け。あなたがたは人を煩わすことを小さい事とし、またわが神をも煩わそうとするのか。</span>
<span className="v" id="v14" data-v="14" data-xref="マタイによる福音書 1:23; イザヤ書 9:6; ルカによる福音書 1:31"> それゆえ、主はみずから一つのしるしをあなたがたに与えられる。見よ、おとめがみごもって男の子を産む。その名はインマヌエルととなえられる。</span>
<span className="v" id="v15" data-v="15" data-xref="イザヤ書 7:22; アモス書 5:15; マタイによる福音書 3:4"> その子が悪を捨て、善を選ぶことを知るころになって、凝乳と、蜂蜜とを食べる。</span>
<span className="v" id="v16" data-v="16" data-xref="イザヤ書 8:4; 申命記 1:39; イザヤ書 9:11"> それはこの子が悪を捨て、善を選ぶことを知る前に、あなたが恐れているふたりの王の地は捨てられるからである。</span>
<span className="v" id="v17" data-v="17" data-xref="イザヤ書 8:7–8; イザヤ書 10:5–6; 歴代志下 28:19–21"> 主はエフライムがユダから分れた時からこのかた、臨んだことのないような日をあなたと、あなたの民と、あなたの父の家とに臨ませられる。それはアッスリヤの王である」。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="イザヤ書 5:26; ヨシュア記 24:12; 申命記 1:44"> その日、主はエジプトの川々の源にいる、はえを招き、アッスリヤの地にいる蜂を呼ばれる。</span>
<span className="v" id="v19" data-v="19" data-xref="イザヤ書 2:19; エレミヤ書 16:16; イザヤ書 2:21"> 彼らはみな来て、険しい谷、岩の裂け目、すべてのいばら、すべての牧場の上にとどまる。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="イザヤ書 8:7; エゼキエル書 29:18; イザヤ書 10:15"> その日、主は大川の向こうから雇ったかみそり、すなわちアッスリヤの王をもって、頭と足の毛とをそり、また、ひげをも除き去られる。</span>
<span className="v" id="v21" data-v="21" data-xref="イザヤ書 5:17; エレミヤ書 39:10; イザヤ書 37:30"> その日、人は若い雌牛一頭と羊二頭を飼い、</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="イザヤ書 7:15; マタイによる福音書 3:4; サムエル記下 17:29"> それから出る乳が多いので、凝乳を食べることができ、すべて国のうちに残された者は凝乳と、蜂蜜とを食べることができる。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="イザヤ書 5:6; 雅歌 8:11–12; マタイによる福音書 21:33"> その日、銀一千シケルの価ある千株のぶどうの木のあった所も、ことごとくいばらと、おどろの生える所となり、</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 27:3"> いばらと、おどろとが地にはびこるために、人々は弓と矢をもってそこへ行く。</span>
<span className="v" id="v25" data-v="25" data-xref="イザヤ書 7:21–22; イザヤ書 13:20–22; イザヤ書 5:17"> くわをもって掘り耕したすべての山々にも、あなたは、いばらと、おどろとを恐れて、そこへ行くことができない。その地はただ牛を放ち、羊の踏むところとなる。</span>
</div>

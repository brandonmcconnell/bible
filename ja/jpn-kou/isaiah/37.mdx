<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀下 19:1–37; エズラ記 9:5; イザヤ書 36:22–38"> ヒゼキヤ王はこれを聞いて、衣を裂き、荒布を身にまとって主の宮に入り、</span>
<span className="v" id="v2" data-v="2" data-xref="イザヤ書 1:1; 列王紀下 18:18; イザヤ書 36:3"> 宮内卿エリアキムと書記官セブナおよび祭司のうちの年長者たちに荒布をまとわせて、アモツの子預言者イザヤのもとへつかわした。</span>
<span className="v" id="v3" data-v="3" data-xref="イザヤ書 66:9; ホセア書 13:13; イザヤ書 26:17–18"> 彼らはイザヤに言った、「ヒゼキヤはこう言います、『きょうは悩みと責めと、はずかしめの日です。胎児がまさに生れようとして、これを産み出す力がないのです。</span>
<span className="v" id="v4" data-v="4" data-xref="イザヤ書 1:9; イザヤ書 36:20; イザヤ書 10:22"> あなたの神、主は、あるいはラブシャケのもろもろの言葉を聞かれたかもしれません。彼はその主君アッスリヤの王につかわされて、生ける神をそしりました。あなたの神、主はその言葉を聞いて、あるいは責められるかもしれません。それゆえ、この残っている者のために祈をささげてください』」。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5"> ヒゼキヤ王の家来たちがイザヤのもとに来たとき、</span>
<span className="v" id="v6" data-v="6" data-xref="イザヤ書 7:4; イザヤ書 35:4; マルコによる福音書 5:36"> イザヤは彼らに言った、「あなたがたの主君にこう言いなさい、『主はこう仰せられる、アッスリヤの王のしもべらが、わたしをそしった言葉を聞いて恐れるには及ばない。</span>
<span className="v" id="v7" data-v="7" data-xref="イザヤ書 31:8–9; 歴代志下 32:21; イザヤ書 33:10–12"> 見よ、わたしは一つの霊を彼のうちに送って、一つのうわさを聞かせ、彼を自分の国へ帰らせて、その国でつるぎに倒れさせる』」。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="ヨシュア記 10:29; 民数記 33:20–21; 列王紀下 19:8–9"> ラブシャケは引き返して、アッスリヤの王がリブナを攻めているところへ行った。彼は王がラキシを去ったことを聞いたからである。</span>
<span className="v" id="v9" data-v="9" data-xref="イザヤ書 18:1; イザヤ書 20:5; イザヤ書 37:7"> この時、アッスリヤの王はエチオピヤの王テルハカについて、「彼はあなたと戦うために出てきた」と人々が言うのを聞いた。彼はこのことを聞いて、使者をヒゼキヤにつかわそうとして言った、</span>
<span className="v" id="v10" data-v="10" data-xref="イザヤ書 36:15; 列王紀下 18:5; マタイによる福音書 27:43"> 「ユダの王ヒゼキヤにこう言いなさい、『あなたは、エルサレムはアッスリヤの王の手に陥ることはない、と言うあなたの信頼する神に欺かれてはならない。</span>
<span className="v" id="v11" data-v="11" data-xref="イザヤ書 36:18–20; 列王紀下 18:33–35; イザヤ書 14:17"> あなたはアッスリヤの王たちが、国々にしたこと、彼らを全く滅ぼしたことを聞いている。どうしてあなたは救われることができようか。</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 11:31; 列王紀下 17:6; 列王紀下 18:11"> わたしの先祖たちはゴザン、ハラン、レゼフおよびテラサルにいたエデンの人々を滅ぼしたが、その国々の神々は彼らを救ったか。</span>
<span className="v" id="v13" data-v="13" data-xref="列王紀下 19:13; 列王紀下 17:24; イザヤ書 36:19"> ハマテの王、アルパデの王、セパルワイムの町の王、ヘナの王およびイワの王はどこにいるか』」。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="列王紀下 19:14; 詩篇 123:1–4; ヨエル書 2:17–20"> ヒゼキヤは使者の手から手紙を受け取ってそれを読み、主の宮にのぼっていって、主の前にそれをひろげ、</span>
<span className="v" id="v15" data-v="15" data-xref="サムエル記上 7:8–9; ダニエル書 9:3–4; ヤコブの手紙 5:13"> 主に祈って言った、</span>
<span className="v" id="v16" data-v="16" data-xref="出エジプト記 25:22; 詩篇 99:1; 詩篇 86:10"> 「ケルビムの上に座しておられるイスラエルの神、万軍の主よ、地のすべての国のうちで、ただあなただけが神でいらせられます。あなたは天と地を造られました。</span>
<span className="v" id="v17" data-v="17" data-xref="歴代志下 6:40; 詩篇 17:6; イザヤ書 37:4"> 主よ、耳を傾けて聞いてください。主よ、目を開いて見てください。セナケリブが生ける神をそしるために書き送った言葉を聞いてください。</span>
<span className="v" id="v18" data-v="18" data-xref="ナホム書 2:11–12; 列王紀下 15:29; 列王紀下 17:6"> 主よ、まことにアッスリヤの王たちは、もろもろの民とその国々を滅ぼし、</span>
<span className="v" id="v19" data-v="19" data-xref="イザヤ書 44:9–10; エレミヤ書 10:11; ホセア書 8:6"> またその神々を火に投げ入れました。それらは神ではなく、人の手の造ったもので、木や石だから滅ぼされたのです。</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 46:10; 列王紀上 18:36–37; 詩篇 83:17–18"> 今われわれの神、主よ、どうぞ、われわれを彼の手から救い出してください。そうすれば地の国々は皆あなただけが主でいらせられることを知るようになるでしょう」。</span>
</div>
<div className="bp poetry">
<span className="v" id="v21" data-v="21" data-xref="イザヤ書 58:9; イザヤ書 38:3–6; 使徒行伝 4:31"> その時アモツの子イザヤは人をつかわしてヒゼキヤに言った、「イスラエルの神、主はこう言われる、あなたはアッスリヤの王セナケリブについてわたしに祈ったゆえ、</span>
<span className="v" id="v22" data-v="22" data-xref="ヨブ記 16:4; 哀歌 2:13; イザヤ書 1:8"> 主が彼について語られた言葉はこうである、<br /><span className="pl pl-1">『処女であるシオンの娘は</span><br /><span className="pl pl-1">あなたを侮り、あなたをあざける。</span><br /><span className="pl pl-1">エルサレムの娘は、あなたのうしろで頭を振る。</span></span>
<span className="v" id="v23" data-v="23" data-xref="エゼキエル書 39:7; ダニエル書 5:20–23; イザヤ書 17:7"> <span className="pl pl-1">あなたはだれをそしり、だれをののしったのか。</span><br /><span className="pl pl-1">あなたはだれにむかって声をあげ、</span><br /><span className="pl pl-1">目を高くあげたのか。</span><br /><span className="pl pl-1">イスラエルの聖者にむかってだ。</span></span>
<span className="v" id="v24" data-v="24" data-xref="イザヤ書 14:8; イザヤ書 10:18; 出エジプト記 15:9"> <span className="pl pl-1">あなたは、そのしもべらによって</span><br /><span className="pl pl-1">主をそしって言った、</span><br /><span className="pl pl-1">「わたしは多くの戦車を率いて山々の頂にのぼり、</span><br /><span className="pl pl-1">レバノンの奥へ行き、</span><br /><span className="pl pl-1">たけの高い香柏と、最も良いいとすぎを切り倒し、</span><br /><span className="pl pl-1">またその果の高地へ行き、その密林にはいった。</span></span>
<span className="v" id="v25" data-v="25" data-xref="列王紀上 20:10; イザヤ書 36:12; 列王紀下 19:23–24"> <span className="pl pl-1">わたしは井戸を掘って水を飲んだ。</span><br /><span className="pl pl-1">わたしは足の裏で</span><br /><span className="pl pl-1">エジプトのすべての川を踏みからした」。</span></span>
<span className="v" id="v26" data-v="26" data-xref="使徒行伝 4:27–28; 使徒行伝 2:23; ペテロの第一の手紙 2:8"> <span className="pl pl-1">あなたは聞かなかったか、</span><br /><span className="pl pl-1">昔わたしがそれを定めたことを。</span><br /><span className="pl pl-1">堅固な町々を、</span><br /><span className="pl pl-1">あなたがこわして荒塚とすることも、</span><br /><span className="pl pl-1">いにしえの日から、わたしが計画して</span><br /><span className="pl pl-1">今それをきたらせたのだ。</span></span>
<span className="v" id="v27" data-v="27" data-xref="詩篇 129:6; 詩篇 37:2; ペテロの第一の手紙 1:24"> <span className="pl pl-1">そのうちに住む民は力弱く、</span><br /><span className="pl pl-1">おののき恥をいだいて、</span><br /><span className="pl pl-1">野の草のように、青菜のようになり、</span><br /><span className="pl pl-1">育たずに枯れる屋根の草のようになった。</span></span>
<span className="v" id="v28" data-v="28" data-xref="ヨハネの黙示録 2:13; 詩篇 139:1–11; エレミヤ書 23:23–24"> <span className="pl pl-1">わたしは、あなたの座すること、出入りすること、</span><br /><span className="pl pl-1">また、わたしにむかって</span><br /><span className="pl pl-1">怒り叫んだことをも知っている。</span></span>
<span className="v" id="v29" data-v="29" data-xref="エゼキエル書 38:4; イザヤ書 30:28; イザヤ書 37:34"> <span className="pl pl-1">あなたが、わたしにむかって怒り叫んだことと、</span><br /><span className="pl pl-1">あなたの高慢な言葉とがわたしの耳にはいったゆえ、</span><br /><span className="pl pl-1">わたしは、あなたの鼻に輪をつけ、</span><br /><span className="pl pl-1">あなたの口にくつわをはめて、</span><br /><span className="pl pl-1">あなたを、もと来た道へ引きもどす』。</span></span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="列王紀下 19:29; レビ記 25:4–5; 列王紀上 13:3–5"> あなたに与えるしるしはこれである。すなわち、ことしは落ち穂から生えた物を食べ、二年目には、またその落ち穂から生えた物を食べ、三年目には種をまき、刈り入れ、ぶどう畑を作ってその実を食べる。</span>
<span className="v" id="v31" data-v="31" data-xref="イザヤ書 27:6; 列王紀下 19:30–31; 詩篇 80:9"> ユダの家の、のがれて残る者は再び下に根を張り、上に実を結ぶ。</span>
<span className="v" id="v32" data-v="32" data-xref="イザヤ書 9:7; 列王紀下 19:31; イザヤ書 59:17"> すなわち残る者はエルサレムから出、のがれる物はシオンの山から出る。万軍の主の熱心がこれをなし遂げられる。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="イザヤ書 17:12; イザヤ書 10:32–34; イザヤ書 17:14"> それゆえ、主はアッスリヤの王について、こう仰せられる、『彼はこの町にこない。またここに矢を放たない。また盾をもって、その前にこない。また塁を築いて、これを攻めることはない。</span>
<span className="v" id="v34" data-v="34" data-xref="イザヤ書 37:29; 箴言 21:30"> 彼は来た道から帰って、この町に、はいることはない、と主は言う。</span>
<span className="v" id="v35" data-v="35" data-xref="列王紀下 20:6; イザヤ書 38:6; イザヤ書 31:5"> わたしは自分のため、また、わたしのしもべダビデのために町を守って、これを救おう』」。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="イザヤ書 10:12; 列王紀下 19:35; イザヤ書 10:33–34"> 主の使が出て、アッスリヤびとの陣営で十八万五千人を撃ち殺した。人々が朝早く起きて見ると、彼らは皆死体となっていた。</span>
<span className="v" id="v37" data-v="37" data-xref="ヨナ書 1:2; ヨナ書 3:3; 創世記 10:11–12"> アッスリヤの王セナケリブは立ち去り、帰っていってニネベにいたが、</span>
<span className="v" id="v38" data-v="38" data-xref="創世記 8:4; エレミヤ書 51:27; エズラ記 4:2"> その神ニスロクの神殿で礼拝していた時、その子らのアデラン・メレクとシャレゼルがつるぎをもって彼を殺し、ともにアララテの地へ逃げていった。それで、その子エサルハドンが代って王となった。</span>
</div>

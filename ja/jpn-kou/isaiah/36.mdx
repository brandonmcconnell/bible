<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歴代志下 32:1; 列王紀下 18:13; 列王紀下 18:17"> ヒゼキヤ王の第十四年に、アッスリヤの王セナケリブが上ってきて、ユダのすべての堅固な町々を攻め取った。</span>
<span className="v" id="v2" data-v="2" data-xref="歴代志下 32:9–23; イザヤ書 7:3; 列王紀下 18:17–37"> アッスリヤの王はラキシからラブシャケをエルサレムにつかわし、大軍を率いてヒゼキヤ王のもとへ行かせた。ラブシャケは布さらしの野へ行く大路に沿う、上の池の水道のかたわらに立った。</span>
<span className="v" id="v3" data-v="3" data-xref="サムエル記下 8:16–17; イザヤ書 22:15–21; サムエル記下 20:24–25"> この時ヒルキヤの子である宮内卿エリアキム、書記官セブナおよびアサフの子である史官ヨアが彼の所に出てきた。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="列王紀下 18:19–37; ユダの手紙 1:16; 箴言 16:18"> ラブシャケは彼らに言った、「ヒゼキヤに言いなさい、『大王アッスリヤの王はこう仰せられる、あなたが頼みとする者は何か。</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀下 18:7; エレミヤ書 52:3; 箴言 21:30–31"> 口先だけの言葉が戦争をする計略と力だと考えるのか。あなたは今だれを頼んで、わたしにそむいたのか。</span>
<span className="v" id="v6" data-v="6" data-xref="エゼキエル書 29:6–7; エレミヤ書 37:5–8; 列王紀下 18:21"> 見よ、あなたはかの折れかけている葦のつえエジプトを頼みとしているが、それは人が寄りかかるとき、その人の手を刺し通す。エジプトの王パロはすべて寄り頼む者にそのようにするのだ。</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀下 18:4–5; 詩篇 42:10–11; 詩篇 42:5"> しかし、あなたがもし「われわれはわれわれの神、主を頼む」とわたしに言うならば、ヒゼキヤがユダとエルサレムに告げて、「あなたがたはこの祭壇の前で礼拝しなければならない」と言って除いたのは、その神の高き所と祭壇ではなかったのか。</span>
<span className="v" id="v8" data-v="8" data-xref="サムエル記上 17:40–43; 列王紀上 20:10; ネヘミヤ書 4:2–5"> さあ、今わたしの主君アッスリヤの王とかけをせよ。もしあなたの方に乗る人があるならば、わたしは馬二千頭を与えよう。</span>
<span className="v" id="v9" data-v="9" data-xref="イザヤ書 10:8; イザヤ書 30:16–17; イザヤ書 36:6"> あなたはエジプトを頼み、戦車と騎兵を請い求めているが、わたしの主君の家来のうちの最も小さい一隊長でさえ、どうして撃退することができようか。</span>
<span className="v" id="v10" data-v="10" data-xref="列王紀下 18:25; イザヤ書 10:5–7; 列王紀上 13:18"> わたしがこの国を滅ぼすために上ってきたのは、主の許しなしでしたことであろうか。主はわたしに、この国へ攻め上って、これを滅ぼせと言われたのだ』」。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="エズラ記 4:7; ダニエル書 2:4; 列王紀下 18:26–27"> その時、エリアキム、セブナおよびヨアはラブシャケに言った、「どうぞ、アラム語でしもべたちに話してください。わたしたちはそれがわかるからです。城壁の上にいる民の聞いているところで、わたしたちにユダヤの言葉で話さないでください」。</span>
<span className="v" id="v12" data-v="12" data-xref="列王紀下 18:27; レビ記 26:29; 哀歌 4:9–10"> しかしラブシャケは言った、「わたしの主君は、あなたの主君とあなたにだけでなく、城壁の上に座している人々にも、この言葉を告げるために、わたしをつかわされたのではないか。彼らをも、あなたがたと共に自分の糞尿を食い飲みするに至らせるためではないか」。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="歴代志下 32:18; 詩篇 73:8–9; 列王紀下 18:28–32"> そしてラブシャケは立ちあがり、ユダヤの言葉で大声に呼ばわって言った、「大王、アッスリヤの王の言葉を聞け。</span>
<span className="v" id="v14" data-v="14" data-xref="テサロニケ人への第二の手紙 2:4; ヨハネの黙示録 13:5–6; ダニエル書 6:20"> 王はこう仰せられる、『あなたがたはヒゼキヤに欺かれてはならない。彼はあなたがたを救い出すことはできない。</span>
<span className="v" id="v15" data-v="15" data-xref="イザヤ書 37:23–24; マタイによる福音書 27:43; 詩篇 71:9–11"> ヒゼキヤが、主は必ずわれわれを救い出される。この町はアッスリヤの王の手に陥ることはない、と言っても、あなたがたは主を頼みとしてはならない』。</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀上 4:25; ゼカリヤ書 3:10; ミカ書 4:4"> あなたがたはヒゼキヤの言葉を聞いてはならない。アッスリヤの王はこう仰せられる、『あなたがたは、わたしと和ぼくして、わたしに降服せよ。そうすれば、あなたがたはめいめい自分のぶどうの実を食べ、めいめい自分のいちじくの実を食べ、めいめい自分の井戸の水を飲むことができる。</span>
<span className="v" id="v17" data-v="17" data-xref="列王紀下 18:32; 申命記 8:7–9; ヨブ記 20:17"> やがて、わたしが来て、あなたがたを一つの国へ連れて行く。それは、あなたがたの国のように穀物とぶどう酒の多い地、パンとぶどう畑の多い地だ。</span>
<span className="v" id="v18" data-v="18" data-xref="イザヤ書 37:17–18; イザヤ書 36:15; イザヤ書 37:10"> ヒゼキヤが、主はわれわれを救われる、と言って、あなたがたを惑わすことのないように気をつけよ。もろもろの国の神々のうち、どの神がその国をアッスリヤの王の手から救ったか。</span>
<span className="v" id="v19" data-v="19" data-xref="イザヤ書 10:9–11; エレミヤ書 49:23; サムエル記下 8:9"> ハマテやアルパデの神々はどこにいるか。セパルワイムの神々はどこにいるか。彼らはサマリヤをわたしの手から救い出したか。</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 50:21; 歴代志下 32:19; イザヤ書 37:23–29"> これらの国々のすべての神々のうちに、だれかその国をわたしの手から救い出した者があるか。主がどうしてエルサレムをわたしの手から救い出すことができよう』」。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="箴言 26:4; 詩篇 38:13–15; マタイによる福音書 7:6"> しかし民は黙ってひと言も答えなかった。王が命じて、「彼に答えてはならない」と言っておいたからである。</span>
<span className="v" id="v22" data-v="22" data-xref="イザヤ書 36:3; イザヤ書 33:7; マタイによる福音書 26:65"> その時ヒルキヤの子である宮内卿エリアキム、書記官セブナおよびアサフの子である史官ヨアは衣を裂き、ヒゼキヤのもとに来て、ラブシャケの言葉を彼に告げた。</span>
</div>

<span className="v" id="v1" data-v="1" data-xref="イザヤ書 38:1–8; 歴代志下 32:24; 列王紀下 20:1–11"> そのころヒゼキヤは病気になって死にかかっていた。アモツの子預言者イザヤは彼のところに来て言った、「主はこう仰せられます、あなたの家を整えておきなさい。あなたは死にます、生きながらえることはできません」。</span>
<span className="v" id="v2" data-v="2" data-xref="マタイによる福音書 6:6; 詩篇 91:15; 列王紀上 8:30"> そこでヒゼキヤは顔を壁に向けて主に祈って言った、</span>
<span className="v" id="v3" data-v="3" data-xref="ヘブル人への手紙 5:7; 詩篇 18:20–27; ヘブル人への手紙 6:10"> 「ああ主よ、願わくは、わたしが真実と真心とをもって、み前に歩み、あなたの目にかなう事を行ったのを覚えてください」。そしてヒゼキヤはひどく泣いた。</span>
<span className="v" id="v4" data-v="4"> その時主の言葉がイザヤに臨んで言った、</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 34:5–6; ヨハネの第一の手紙 5:14–15; ヨハネの黙示録 7:17"> 「行って、ヒゼキヤに言いなさい、『あなたの父ダビデの神、主はこう仰せられます、「わたしはあなたの祈を聞いた。あなたの涙を見た。見よ、わたしはあなたのよわいを十五年増そう。</span>
<span className="v" id="v6" data-v="6" data-xref="イザヤ書 37:35; イザヤ書 31:4–5; イザヤ書 12:6"> わたしはあなたと、この町とをアッスリヤの王の手から救い、この町を守ろう」。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="士師記 6:37–39; イザヤ書 37:30; イザヤ書 7:11–14"> 主が約束されたことを行われることについては、あなたは主からこのしるしを得る。</span>
<span className="v" id="v8" data-v="8" data-xref="列王紀下 20:9–11; ヨシュア記 10:12–14; マタイによる福音書 16:1"> 見よ、わたしはアハズの日時計の上に進んだ日影を十度退かせよう』」。すると日時計の上に進んだ日影が十度退いた。</span>
</div>
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="詩篇 18:1; 出エジプト記 15:1–21; ヨブ記 5:18"> 次の言葉はユダの王ヒゼキヤが病気になって、その病気が直った後、書きしるしたものである。</span>

<span className="v" id="v11" data-v="11" data-xref="詩篇 27:13; 詩篇 116:8–9; 詩篇 31:22"> <span className="pl pl-1">わたしは言った、わたしは生ける者の地で、</span><br /><span className="pl pl-1">主を見ることなく、</span><br /><span className="pl pl-1">世におる人々のうちに、再び人を見ることがない。</span></span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 73:14; コリント人への第二の手紙 5:1; ヘブル人への手紙 1:12"> <span className="pl pl-1">わがすまいは抜き去られて</span><br /><span className="pl pl-1">羊飼の天幕のようにわたしを離れる。</span><br /><span className="pl pl-1">わたしは、わが命を機織りのように巻いた。</span><br /><span className="pl pl-1">彼はわたしを機から切り離す。</span><br /><span className="pl pl-1">あなたは朝から夕までの間に、わたしを滅ぼされる。</span></span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 51:8; ダニエル書 6:24; 詩篇 50:22"> <span className="pl pl-1">わたしは朝まで叫んだ。</span><br /><span className="pl pl-1">主はししのようにわが骨をことごとく砕かれる。</span><br /><span className="pl pl-1">あなたは朝から夕までの間に、わたしを滅ぼされる。</span></span>
<span className="v" id="v14" data-v="14" data-xref="イザヤ書 59:11; 詩篇 69:3; 詩篇 123:1–4"> <span className="pl pl-1">わたしは、つばめのように、つるのように鳴き、</span><br /><span className="pl pl-1">はとのようにうめき、</span><br /><span className="pl pl-1">わが目は上を見て衰える。</span><br /><span className="pl pl-1">主よ、わたしは、しえたげられています。</span><br /><span className="pl pl-1">どうか、わたしの保証人となってください。</span></span>
<span className="v" id="v15" data-v="15" data-xref="列王紀上 21:27; ヨブ記 7:11; ヨブ記 10:1"> <span className="pl pl-1">しかし、わたしは何を言うことができましょう。</span><br /><span className="pl pl-1">主はわたしに言われ、</span><br /><span className="pl pl-1">かつ、自らそれをなされたからである。</span><br /><span className="pl pl-1">わが魂の苦しみによって、</span><br /><span className="pl pl-1">わが眠りはことごとく逃げ去った。</span></span>
<span className="v" id="v16" data-v="16" data-xref="ヘブル人への手紙 12:10–11; コリント人への第一の手紙 11:32; 詩篇 119:25"> <span className="pl pl-1">主よ、これらの事によって人は生きる。</span><br /><span className="pl pl-1">わが霊の命もすべてこれらの事による。</span><br /><span className="pl pl-1">どうか、わたしをいやし、</span><br /><span className="pl pl-1">わたしを生かしてください。</span></span>

<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="列王紀下 20:7–8; マルコによる福音書 7:33; ヨハネによる福音書 9:6"> イザヤは言った、「干いちじくのひとかたまりを持ってこさせ、それを腫物につけなさい。そうすれば直るでしょう」。</span>

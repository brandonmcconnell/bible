<span className="v" id="v2" data-v="2" data-xref="ヨハネの黙示録 4:8; エゼキエル書 1:11; 詩篇 104:4"> その上にセラピムが立ち、おのおの六つの翼をもっていた。その二つをもって顔をおおい、二つをもって足をおおい、二つをもって飛びかけり、</span>
<span className="v" id="v3" data-v="3" data-xref="ヨハネの黙示録 4:8–9; 詩篇 72:19; 民数記 14:21"> 互に呼びかわして言った。<br /><span className="pl pl-1">「聖なるかな、聖なるかな、聖なるかな、万軍の主、その栄光は全地に満つ」。</span></span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネの黙示録 15:8; 出エジプト記 40:34; 歴代志下 5:13–1"> <span className="pl pl-1">その呼ばわっている者の声によって敷居の基が震い動き、神殿の中に煙が満ちた。</span></span>
<span className="v" id="v5" data-v="5" data-xref="ルカによる福音書 5:8–9; ヤコブの手紙 3:6–10; エレミヤ書 9:3–8"> <span className="pl pl-1">その時わたしは言った、「わざわいなるかな、わたしは滅びるばかりだ。わたしは汚れたくちびるの者で、汚れたくちびるの民の中に住む者であるのに、わたしの目が万軍の主なる王を見たのだから」。</span></span>

<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="ヨハネの黙示録 8:3–5; ヘブル人への手紙 9:22–26; エゼキエル書 10:2"> この時セラピムのひとりが火ばしをもって、祭壇の上から取った燃えている炭を手に携え、わたしのところに飛んできて、</span>
<span className="v" id="v7" data-v="7" data-xref="エレミヤ書 1:9; ヨハネの第一の手紙 1:7; イザヤ書 43:25"> わたしの口に触れて言った、「見よ、これがあなたのくちびるに触れたので、あなたの悪は除かれ、あなたの罪はゆるされた」。</span>
<span className="v" id="v8" data-v="8" data-xref="出エジプト記 4:10–13; 使徒行伝 26:16–17; エペソ人への手紙 3:8"> わたしはまた主の言われる声を聞いた、「わたしはだれをつかわそうか。だれがわれわれのために行くだろうか」。その時わたしは言った、「ここにわたしがおります。わたしをおつかわしください」。</span>
<span className="v" id="v9" data-v="9" data-xref="マタイによる福音書 13:14–15; ルカによる福音書 8:10; マルコによる福音書 4:12"> 主は言われた、「あなたは行って、この民にこう言いなさい、<br /><span className="pl pl-1">『あなたがたはくりかえし聞くがよい、</span><br /><span className="pl pl-1">しかし悟ってはならない。</span><br /><span className="pl pl-1">あなたがたはくりかえし見るがよい、</span><br /><span className="pl pl-1">しかしわかってはならない』と。</span></span>
<span className="v" id="v10" data-v="10" data-xref="マタイによる福音書 13:15; 使徒行伝 28:27; エレミヤ書 5:21"> <span className="pl pl-1">あなたはこの民の心を鈍くし、</span><br /><span className="pl pl-1">その耳を聞えにくくし、その目を閉ざしなさい。</span><br /><span className="pl pl-1">これは彼らがその目で見、その耳で聞き、</span><br /><span className="pl pl-1">その心で悟り、</span><br /><span className="pl pl-1">悔い改めていやされることのないためである」。</span></span>
<span className="v" id="v11" data-v="11" data-xref="イザヤ書 24:1–12; 詩篇 94:3; レビ記 26:31"> <span className="pl pl-1">そこで、わたしは言った、「主よ、いつまでですか」。</span><br /><span className="pl pl-1">主は言われた、</span><br /><span className="pl pl-1">「町々は荒れすたれて、住む者もなく、</span><br /><span className="pl pl-1">家には人かげもなく、国は全く荒れ地となり、</span></span>
<span className="v" id="v12" data-v="12" data-xref="エレミヤ書 4:29; 申命記 28:64; 列王紀下 25:11"> <span className="pl pl-1">人々は主によって遠くへ移され、</span><br /><span className="pl pl-1">荒れはてた所が国の中に多くなる時まで、</span><br /><span className="pl pl-1">こうなっている。</span></span>
<span className="v" id="v13" data-v="13" data-xref="ヨブ記 14:7–9; ローマ人への手紙 11:5–6; 創世記 22:18"> <span className="pl pl-1">その中に十分の一の残る者があっても、</span><br /><span className="pl pl-1">これもまた焼き滅ぼされる。</span><br /><span className="pl pl-1">テレビンの木またはかしの木が切り倒されるとき、</span><br /><span className="pl pl-1">その切り株が残るように」。</span><br /><span className="pl pl-1">聖なる種族はその切り株である。</span></span>

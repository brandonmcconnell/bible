<span className="v" id="v1" data-v="1" data-xref="イザヤ書 30:8; ヨブ記 19:23–24; ハバクク書 2:2–3"> 主はわたしに言われた、「一枚の大きな札を取って、その上に普通の文字で、『マヘル・シャラル・ハシ・バズ』と書きなさい」。</span>
<span className="v" id="v2" data-v="2" data-xref="列王紀下 16:10–11; 列王紀下 18:2; コリント人への第二の手紙 13:1"> そこで、わたしは確かな証人として、祭司ウリヤおよびエベレキヤの子ゼカリヤを立てた。</span>
<span className="v" id="v3" data-v="3" data-xref="ホセア書 1:3–9; 士師記 4:4; イザヤ書 7:13–14"> わたしが預言者の妻に近づくと、彼女はみごもって男の子を産んだ。その時、主はわたしに言われた、「その名をマヘル・シャラル・ハシ・バズと呼びなさい。</span>
<span className="v" id="v4" data-v="4" data-xref="ローマ人への手紙 9:11; 列王紀下 16:9; 申命記 1:39"> それはこの子がまだ『おとうさん、おかあさん』と呼ぶことを知らないうちに、ダマスコの富と、サマリヤのぶんどり品とが、アッスリヤ王の前に奪い去られるからである」。</span>
</div>
<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="イザヤ書 7:10"> 主はまた重ねてわたしに言われた、</span>
<span className="v" id="v6" data-v="6" data-xref="ヨハネによる福音書 9:7; ネヘミヤ書 3:15; イザヤ書 7:6"> 「この民はゆるやかに流れるシロアの水を捨てて、レヂンとレマリヤの子の前に恐れくじける。</span>
<span className="v" id="v7" data-v="7" data-xref="イザヤ書 17:12–13; 創世記 6:17; イザヤ書 7:17"> それゆえ見よ、主は勢いたけく、みなぎりわたる大川の水を彼らにむかってせき入れられる。これはアッスリヤの王と、そのもろもろの威勢とであって、そのすべての支流にはびこり、すべての岸を越え、</span>
<span className="v" id="v8" data-v="8" data-xref="イザヤ書 7:14; イザヤ書 30:28; マタイによる福音書 1:23"> ユダに流れ入り、あふれみなぎって、首にまで及ぶ。インマヌエルよ、その広げた翼はあまねく、あなたの国に満ちわたる」。</span>
<span className="v" id="v9" data-v="9" data-xref="イザヤ書 14:5–6; 箴言 11:21; 詩篇 37:14–15"> <span className="pl pl-1">もろもろの民よ、打ち破られて、驚きあわてよ。</span><br /><span className="pl pl-1">遠き国々のものよ、耳を傾けよ。</span><br /><span className="pl pl-1">腰に帯して、驚きあわてよ。</span><br /><span className="pl pl-1">腰に帯して、驚きあわてよ。</span></span>
<span className="v" id="v10" data-v="10" data-xref="哀歌 3:37; ローマ人への手紙 8:31; ヨブ記 5:12"> <span className="pl pl-1">ともに計れ、しかし、成らない。</span><br /><span className="pl pl-1">言葉を出せ、しかし、行われない。</span><br /><span className="pl pl-1">神がわれわれと共におられるからである。</span></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="エゼキエル書 3:14; 箴言 1:15; エレミヤ書 15:19"> 主は強いみ手をもって、わたしを捕え、わたしに語り、この民の道に歩まないように、さとして言われた、</span>
<span className="v" id="v12" data-v="12" data-xref="ペテロの第一の手紙 3:14–15; ルカによる福音書 21:9; 詩篇 53:5"> 「この民がすべて陰謀ととなえるものを陰謀ととなえてはならない。彼らの恐れるものを恐れてはならない。またおののいてはならない。</span>
<span className="v" id="v13" data-v="13" data-xref="ルカによる福音書 12:5; イザヤ書 26:3–4; ヨハネの黙示録 15:4"> あなたがたは、ただ万軍の主を聖として、彼をかしこみ、彼を恐れなければならない。</span>
<span className="v" id="v14" data-v="14" data-xref="ペテロの第一の手紙 2:8; ローマ人への手紙 9:32–33; イザヤ書 28:16"> 主はイスラエルの二つの家には聖所となり、またさまたげの石、つまずきの岩となり、エルサレムの住民には網となり、わなとなる。</span>
<span className="v" id="v15" data-v="15" data-xref="マタイによる福音書 21:44; ルカによる福音書 20:17–18; イザヤ書 28:13"> 多くの者はこれにつまずき、かつ倒れ、破られ、わなにかけられ、捕えられる」。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="ダニエル書 12:4; ヘブル人への手紙 3:5; マルコによる福音書 4:10–11"> わたしは、あかしを一つにまとめ、教をわが弟子たちのうちに封じておこう。</span>
<span className="v" id="v17" data-v="17" data-xref="ヘブル人への手紙 10:36–39; ハバクク書 2:3; 哀歌 3:25–26"> 主はいま、ヤコブの家に、み顔をかくしておられるとはいえ、わたしはその主を待ち、主を望みまつる。</span>
<span className="v" id="v18" data-v="18" data-xref="ヘブル人への手紙 2:13–14; ルカによる福音書 2:34; ゼカリヤ書 8:3"> 見よ、わたしと、主のわたしに賜わった子たちとは、シオンの山にいます万軍の主から与えられたイスラエルのしるしであり、前ぶれである。</span>
<span className="v" id="v19" data-v="19" data-xref="歴代志上 10:13; レビ記 20:6; 歴代志下 33:6"> 人々があなたがたにむかって「さえずるように、ささやくように語る巫子および魔術者に求めよ」という時、民は自分たちの神に求むべきではないか。生ける者のために死んだ者に求めるであろうか。</span>
<span className="v" id="v20" data-v="20" data-xref="ペテロの第二の手紙 1:19; テモテヘの第二の手紙 3:15–17; イザヤ書 30:8–11"> ただ教とあかしとに求めよ。まことに彼らはこの言葉によって語るが、そこには夜明けがない。</span>
<span className="v" id="v21" data-v="21" data-xref="イザヤ書 9:20; 箴言 19:3; 哀歌 4:4–5"> 彼らはしえたげられ、飢えて国の中を経あるく。その飢えるとき怒りを放ち、自分たちの王、自分たちの神をのろい、かつその顔を天に向ける。</span>
<span className="v" id="v22" data-v="22" data-xref="イザヤ書 5:30; マタイによる福音書 22:13; エレミヤ書 13:16"> また地を見ると、見よ、悩みと暗きと、苦しみのやみとがあり、彼らは暗黒に追いやられる。</span>

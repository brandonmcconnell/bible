<span className="v" id="v2" data-v="2" data-xref="ピリピ人への手紙 2:21; ローマ人への手紙 1:29–31; ユダの手紙 1:16"> その時、人々は自分を愛する者、金を愛する者、大言壮語する者、高慢な者、神をそしる者、親に逆らう者、恩を知らぬ者、神聖を汚す者、</span>
<span className="v" id="v3" data-v="3" data-xref="ユダの手紙 1:18; ローマ人への手紙 1:31; マタイによる福音書 10:21"> 無情な者、融和しない者、そしる者、無節制な者、粗暴な者、善を好まない者、</span>
<span className="v" id="v4" data-v="4" data-xref="ピリピ人への手紙 3:18–19; テモテヘの第一の手紙 3:6; ユダの手紙 1:4"> 裏切り者、乱暴者、高言をする者、神よりも快楽を愛する者、</span>
<span className="v" id="v5" data-v="5" data-xref="イザヤ書 29:13; テトスヘの手紙 1:16; マタイによる福音書 23:27–28"> 信心深い様子をしながらその実を捨てる者となるであろう。こうした人々を避けなさい。</span>
<span className="v" id="v6" data-v="6" data-xref="ユダの手紙 1:4; ペテロの第二の手紙 3:17; テトスヘの手紙 3:3"> 彼らの中には、人の家にもぐり込み、そして、さまざまの欲に心を奪われて、多くの罪を積み重ねている愚かな女どもを、とりこにしている者がある。</span>
<span className="v" id="v7" data-v="7" data-xref="テモテヘの第二の手紙 4:3–4; エペソ人への手紙 4:14; テモテヘの第一の手紙 2:4"> 彼女たちは、常に学んではいるが、いつになっても真理の知識に達することができない。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行伝 13:8–11; ヨハネの黙示録 2:20; テモテヘの第一の手紙 6:5"> ちょうど、ヤンネとヤンブレとがモーセに逆らったように、こうした人々も真理に逆らうのである。彼らは知性の腐った、信仰の失格者である。</span>
<span className="v" id="v9" data-v="9" data-xref="テモテヘの第二の手紙 3:8; 出エジプト記 7:12; エレミヤ書 28:15–17"> しかし、彼らはそのまま進んでいけるはずがない。彼らの愚かさは、あのふたりの場合と同じように、多くの人に知れて来るであろう。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="テモテヘの第一の手紙 6:11; テトスヘの手紙 2:7; ペテロの第二の手紙 1:5–7"> しかしあなたは、わたしの教、歩み、こころざし、信仰、寛容、愛、忍耐、</span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 34:19; 使徒行伝 14:5–6; コリント人への第二の手紙 11:23–28"> それから、わたしがアンテオケ、イコニオム、ルステラで受けた数々の迫害、苦難に、よくも続いてきてくれた。そのひどい迫害にわたしは耐えてきたが、主はそれらいっさいのことから、救い出して下さったのである。</span>
<span className="v" id="v12" data-v="12" data-xref="ペテロの第一の手紙 3:14; ペテロの第一の手紙 4:12–16; ペテロの第一の手紙 2:20–21"> いったい、キリスト・イエスにあって信心深く生きようとする者は、みな、迫害を受ける。</span>
<span className="v" id="v13" data-v="13" data-xref="テモテヘの第一の手紙 4:1; ペテロの第二の手紙 2:20; テトスヘの手紙 3:3"> 悪人と詐欺師とは人を惑わし人に惑わされて、悪から悪へと落ちていく。</span>
<span className="v" id="v14" data-v="14" data-xref="テサロニケ人への第一の手紙 2:13; テモテヘの第二の手紙 2:2; テモテヘの第二の手紙 1:13"> しかし、あなたは、自分が学んで確信しているところに、いつもとどまっていなさい。あなたは、それをだれから学んだか知っており、</span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 119:98–99; ルカによる福音書 24:45; 箴言 22:6"> また幼い時から、聖書に親しみ、それが、キリスト・イエスに対する信仰によって救に至る知恵を、あなたに与えうる書物であることを知っている。</span>
<span className="v" id="v16" data-v="16" data-xref="ローマ人への手紙 15:4; ヘブル人への手紙 4:12; ペテロの第二の手紙 1:19–21"> 聖書は、すべて神の霊感を受けて書かれたものであって、人を教え、戒め、正しくし、義に導くのに有益である。</span>
<span className="v" id="v17" data-v="17" data-xref="テモテヘの第二の手紙 2:21; エペソ人への手紙 2:10; コリント人への第二の手紙 9:8"> それによって、神の人が、あらゆる良いわざに対して十分な準備ができて、完全にととのえられた者になるのである。</span>

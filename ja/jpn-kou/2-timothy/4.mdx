<span className="v" id="v1" data-v="1" data-xref="使徒行伝 10:42; テモテヘの第二の手紙 4:8; テモテヘの第一の手紙 5:21"> 神のみまえと、生きている者と死んだ者とをさばくべきキリスト・イエスのみまえで、キリストの出現とその御国とを思い、おごそかに命じる。</span>
<span className="v" id="v2" data-v="2" data-xref="テサロニケ人への第一の手紙 5:14; テモテヘの第一の手紙 4:15–16; テトスヘの手紙 2:15"> 御言を宣べ伝えなさい。時が良くても悪くても、それを励み、あくまでも寛容な心でよく教えて、責め、戒め、勧めなさい。</span>
<span className="v" id="v3" data-v="3" data-xref="ペテロの第二の手紙 2:1–3; テモテヘの第二の手紙 3:1–6; テモテヘの第一の手紙 4:1–3"> 人々が健全な教に耐えられなくなり、耳ざわりのよい話をしてもらおうとして、自分勝手な好みにまかせて教師たちを寄せ集め、</span>
<span className="v" id="v4" data-v="4" data-xref="ゼカリヤ書 7:11; テモテヘの第一の手紙 1:4; 使徒行伝 7:57"> そして、真理からは耳をそむけて、作り話の方にそれていく時が来るであろう。</span>
<span className="v" id="v5" data-v="5" data-xref="テモテヘの第二の手紙 1:8; ペテロの第一の手紙 1:13; テモテヘの第二の手紙 2:3"> しかし、あなたは、何事にも慎み、苦難を忍び、伝道者のわざをなし、自分の務を全うしなさい。</span>
<span className="v" id="v6" data-v="6" data-xref="ピリピ人への手紙 1:23; ピリピ人への手紙 2:17; ペテロの第二の手紙 1:14–15"> わたしは、すでに自身を犠牲としてささげている。わたしが世を去るべき時はきた。</span>
<span className="v" id="v7" data-v="7" data-xref="テモテヘの第一の手紙 6:12; コリント人への第一の手紙 9:24–27; ヘブル人への手紙 12:1–2"> わたしは戦いをりっぱに戦いぬき、走るべき行程を走りつくし、信仰を守りとおした。</span>
<span className="v" id="v8" data-v="8" data-xref="ヤコブの手紙 1:12; ヨハネの黙示録 2:10; ペテロの第一の手紙 5:4"> 今や、義の冠がわたしを待っているばかりである。かの日には、公平な審判者である主が、それを授けて下さるであろう。わたしばかりではなく、主の出現を心から待ち望んでいたすべての人にも授けて下さるであろう。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="テモテヘの第二の手紙 1:4; テモテヘの第二の手紙 4:21"> わたしの所に、急いで早くきてほしい。</span>
<span className="v" id="v10" data-v="10" data-xref="ヨハネの第一の手紙 2:15–16; テモテヘの第二の手紙 1:15; コロサイ人への手紙 4:14–15"> デマスはこの世を愛し、わたしを捨ててテサロニケに行ってしまい、クレスケンスはガラテヤに、テトスはダルマテヤに行った。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行伝 12:12; ピレモンヘの手紙 1:24; 使徒行伝 12:25"> ただルカだけが、わたしのもとにいる。マルコを連れて、一緒にきなさい。彼はわたしの務のために役に立つから。</span>
<span className="v" id="v12" data-v="12" data-xref="エペソ人への手紙 6:21; 使徒行伝 20:4; テトスヘの手紙 3:12"> わたしはテキコをエペソにつかわした。</span>
<span className="v" id="v13" data-v="13" data-xref="コリント人への第一の手紙 4:11; コリント人への第二の手紙 11:27; 使徒行伝 16:11"> あなたが来るときに、トロアスのカルポの所に残しておいた上着を持ってきてほしい。また書物も、特に、羊皮紙のを持ってきてもらいたい。</span>
<span className="v" id="v14" data-v="14" data-xref="テモテヘの第一の手紙 1:20; テサロニケ人への第二の手紙 1:6; 詩篇 28:4"> 銅細工人のアレキサンデルが、わたしを大いに苦しめた。主はそのしわざに対して、彼に報いなさるだろう。</span>
<span className="v" id="v15" data-v="15" data-xref="テモテヘの第二の手紙 3:8; ピリピ人への手紙 3:2; マタイによる福音書 10:16–17"> あなたも、彼を警戒しなさい。彼は、わたしたちの言うことに強く反対したのだから。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行伝 7:60; ヨハネによる福音書 16:32; マルコによる福音書 14:50"> わたしの第一回の弁明の際には、わたしに味方をする者はひとりもなく、みなわたしを捨てて行った。どうか、彼らが、そのために責められることがないように。</span>
<span className="v" id="v17" data-v="17" data-xref="ペテロの第一の手紙 5:8; ピリピ人への手紙 1:12–14; サムエル記上 17:37"> しかし、わたしが御言を余すところなく宣べ伝えて、すべての異邦人に聞かせるように、主はわたしを助け、力づけて下さった。そして、わたしは、ししの口から救い出されたのである。</span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 121:7; テサロニケ人への第二の手紙 3:3; ユダの手紙 1:24–25"> 主はわたしを、すべての悪のわざから助け出し、天にある御国に救い入れて下さるであろう。栄光が永遠から永遠にわたって主にあるように、アァメン。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="使徒行伝 18:2; コリント人への第一の手紙 16:19; ローマ人への手紙 16:3–4"> プリスカとアクラとに、またオネシポロの家に、よろしく伝えてほしい。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行伝 20:4; 使徒行伝 19:22; ピリピ人への手紙 2:26–27"> エラストはコリントにとどまっており、トロピモは病気なので、ミレトに残してきた。</span>
<span className="v" id="v21" data-v="21" data-xref="テモテヘの第二の手紙 4:9; ピリピ人への手紙 4:22; ヨハネの第三の手紙 1:14"> 冬になる前に、急いできてほしい。ユブロ、プデス、リノス、クラウデヤならびにすべての兄弟たちから、あなたによろしく。</span>
</div>

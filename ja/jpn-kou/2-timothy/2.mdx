<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="コリント人への第二の手紙 12:9–10; エペソ人への手紙 6:10; テモテヘの第二の手紙 1:7"> そこで、わたしの子よ。あなたはキリスト・イエスにある恵みによって、強くなりなさい。</span>
<span className="v" id="v2" data-v="2" data-xref="テモテヘの第二の手紙 1:13–14; テモテヘの第一の手紙 4:6; テモテヘの第一の手紙 6:12"> そして、あなたが多くの証人の前でわたしから聞いたことを、さらにほかの者たちにも教えることのできるような忠実な人々に、ゆだねなさい。</span>
<span className="v" id="v3" data-v="3" data-xref="ヘブル人への手紙 12:2–3; ヤコブの手紙 1:12; テモテヘの第二の手紙 4:5"> キリスト・イエスの良い兵卒として、わたしと苦しみを共にしてほしい。</span>
<span className="v" id="v4" data-v="4" data-xref="テサロニケ人への第一の手紙 2:4; ルカによる福音書 8:14; ペテロの第二の手紙 2:20"> 兵役に服している者は、日常生活の事に煩わされてはいない。ただ、兵を募った司令官を喜ばせようと努める。</span>
<span className="v" id="v5" data-v="5" data-xref="コリント人への第一の手紙 9:24–27; ヨハネの黙示録 3:11; テモテヘの第二の手紙 4:7–8"> また、競技をするにしても、規定に従って競技をしなければ、栄冠は得られない。</span>
<span className="v" id="v6" data-v="6" data-xref="ヘブル人への手紙 10:36; コリント人への第一の手紙 9:7–11; コリント人への第一の手紙 3:6–9"> 労苦をする農夫が、だれよりも先に、生産物の分配にあずかるべきである。</span>
<span className="v" id="v7" data-v="7" data-xref="ヤコブの手紙 1:5; ヨハネの第一の手紙 5:20; ルカによる福音書 24:45"> わたしの言うことを、よく考えてみなさい。主は、それを十分に理解する力をあなたに賜わるであろう。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="使徒行伝 2:24; ローマ人への手紙 2:16; コリント人への第一の手紙 15:11–20"> ダビデの子孫として生れ、死人のうちからよみがえったイエス・キリストを、いつも思っていなさい。これがわたしの福音である。</span>
<span className="v" id="v9" data-v="9" data-xref="ピリピ人への手紙 1:7; 使徒行伝 28:31; テモテヘの第二の手紙 1:8"> この福音のために、わたしは悪者のように苦しめられ、ついに鎖につながれるに至った。しかし、神の言はつながれてはいない。</span>
<span className="v" id="v10" data-v="10" data-xref="ペテロの第一の手紙 5:10; コロサイ人への手紙 1:24; テモテヘの第二の手紙 2:3"> それだから、わたしは選ばれた人たちのために、いっさいのことを耐え忍ぶのである。それは、彼らもキリスト・イエスによる救を受け、また、それと共に永遠の栄光を受けるためである。</span>
<span className="v" id="v11" data-v="11" data-xref="ローマ人への手紙 6:8; コロサイ人への手紙 3:3–4; ローマ人への手紙 6:5"> 次の言葉は確実である。「もしわたしたちが、彼と共に死んだなら、また彼と共に生きるであろう。</span>
<span className="v" id="v12" data-v="12" data-xref="ローマ人への手紙 8:17; マタイによる福音書 10:33; ヨハネの黙示録 20:4"> もし耐え忍ぶなら、彼と共に支配者となるであろう。もし彼を否むなら、彼もわたしたちを否むであろう。</span>
<span className="v" id="v13" data-v="13" data-xref="民数記 23:19; ローマ人への手紙 3:3; テサロニケ人への第二の手紙 3:3"> たとい、わたしたちは不真実であっても、彼は常に真実である。彼は自分を偽ることが、できないのである」。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="テトスヘの手紙 3:9–11; テモテヘの第二の手紙 2:23; テモテヘの第二の手紙 4:1"> あなたは、これらのことを彼らに思い出させて、なんの益もなく、聞いている人々を破滅におとしいれるだけである言葉の争いをしないように、神のみまえでおごそかに命じなさい。</span>
<span className="v" id="v15" data-v="15" data-xref="テサロニケ人への第一の手紙 2:4; ペテロの第二の手紙 1:10; テモテヘの第一の手紙 4:6"> あなたは真理の言葉を正しく教え、恥じるところのない錬達した働き人になって、神に自分をささげるように努めはげみなさい。</span>
<span className="v" id="v16" data-v="16" data-xref="テトスヘの手紙 3:9; テモテヘの第一の手紙 6:20; テモテヘの第二の手紙 2:14"> 俗悪なむだ話を避けなさい。それによって人々は、ますます不信心に落ちていき、</span>
<span className="v" id="v17" data-v="17" data-xref="テモテヘの第一の手紙 1:20; ナホム書 3:15; ヤコブの手紙 5:3"> 彼らの言葉は、がんのように腐れひろがるであろう。その中にはヒメナオとピレトとがいる。</span>
<span className="v" id="v18" data-v="18" data-xref="コリント人への第一の手紙 15:12; テモテヘの第一の手紙 1:19; ヘブル人への手紙 3:10"> 彼らは真理からはずれ、復活はすでに済んでしまったと言い、そして、ある人々の信仰をくつがえしている。</span>
<span className="v" id="v19" data-v="19" data-xref="ヨハネによる福音書 10:14; コリント人への第一の手紙 8:3; ナホム書 1:7"> しかし、神のゆるがない土台はすえられていて、それに次の句が証印として、しるされている。「主は自分の者たちを知る」。また「主の名を呼ぶ者は、すべて不義から離れよ」。</span>
<span className="v" id="v20" data-v="20" data-xref="ローマ人への手紙 9:21–23; ペテロの第一の手紙 2:5; テモテヘの第一の手紙 3:15"> 大きな家には、金や銀の器ばかりではなく、木や土の器もあり、そして、あるものは尊いことに用いられ、あるものは卑しいことに用いられる。</span>
<span className="v" id="v21" data-v="21" data-xref="テモテヘの第二の手紙 3:17; エペソ人への手紙 2:10; コリント人への第二の手紙 7:1"> もし人が卑しいものを取り去って自分をきよめるなら、彼は尊いきよめられた器となって、主人に役立つものとなり、すべての良いわざに間に合うようになる。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="ペテロの第一の手紙 2:11; ペテロの第一の手紙 3:11; コリント人への第一の手紙 6:18"> そこで、あなたは若い時の情欲を避けなさい。そして、きよい心をもって主を呼び求める人々と共に、義と信仰と愛と平和とを追い求めなさい。</span>
<span className="v" id="v23" data-v="23" data-xref="テモテヘの第二の手紙 2:14; テトスヘの手紙 3:9; テモテヘの第一の手紙 4:7"> 愚かで無知な論議をやめなさい。それは、あなたが知っているとおり、ただ争いに終るだけである。</span>
<span className="v" id="v24" data-v="24" data-xref="テトスヘの手紙 3:2; ヤコブの手紙 1:19–20; テモテヘの第一の手紙 3:2–3"> 主の僕たる者は争ってはならない。だれに対しても親切であって、よく教え、よく忍び、</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行伝 11:18; ガラテヤ人への手紙 6:1; テモテヘの第一の手紙 2:4"> 反対する者を柔和な心で教え導くべきである。おそらく神は、彼らに悔改めの心を与えて、真理を知らせ、</span>
<span className="v" id="v26" data-v="26" data-xref="テモテヘの第一の手紙 3:7; イザヤ書 49:25–26; 詩篇 124:7"> 一度は悪魔に捕えられてその欲するままになっていても、目ざめて彼のわなからのがれさせて下さるであろう。</span>
</div>

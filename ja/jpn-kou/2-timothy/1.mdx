<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヘブル人への手紙 9:15; ヨハネによる福音書 17:3; ヨハネによる福音書 10:28"> 神の御旨により、キリスト・イエスにあるいのちの約束によって立てられたキリスト・イエスの使徒パウロから、</span>
<span className="v" id="v2" data-v="2" data-xref="テモテヘの第二の手紙 2:1; テモテヘの第一の手紙 1:2; 使徒行伝 16:1"> 愛する子テモテへ。<br />父なる神とわたしたちの主キリスト・イエスから、恵みとあわれみと平安とが、あなたにあるように。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="ローマ人への手紙 1:8–9; ヘブル人への手紙 13:8; 使徒行伝 23:1"> わたしは、日夜、祈の中で、絶えずあなたのことを思い出しては、きよい良心をもって先祖以来つかえている神に感謝している。</span>
<span className="v" id="v4" data-v="4" data-xref="テモテヘの第二の手紙 4:9; ピリピ人への手紙 1:8; テサロニケ人への第一の手紙 2:17–1"> わたしは、あなたの涙をおぼえており、あなたに会って喜びで満たされたいと、切に願っている。</span>
<span className="v" id="v5" data-v="5" data-xref="テモテヘの第一の手紙 1:5; 使徒行伝 16:1; テモテヘの第二の手紙 3:15"> また、あなたがいだいている偽りのない信仰を思い起している。この信仰は、まずあなたの祖母ロイスとあなたの母ユニケとに宿ったものであったが、今あなたにも宿っていると、わたしは確信している。</span>
<span className="v" id="v6" data-v="6" data-xref="テモテヘの第一の手紙 4:14; ペテロの第一の手紙 4:10–11; ローマ人への手紙 12:6–8"> こういうわけで、あなたに注意したい。わたしの按手によって内にいただいた神の賜物を、再び燃えたたせなさい。</span>
<span className="v" id="v7" data-v="7" data-xref="ローマ人への手紙 8:15; ヨハネの第一の手紙 4:18; ガラテヤ人への手紙 5:22"> というのは、神がわたしたちに下さったのは、臆する霊ではなく、力と愛と慎みとの霊なのである。</span>
<span className="v" id="v8" data-v="8" data-xref="ローマ人への手紙 1:16; マルコによる福音書 8:38; ペテロの第一の手紙 4:13–15"> だから、あなたは、わたしたちの主のあかしをすることや、わたしが主の囚人であることを、決して恥ずかしく思ってはならない。むしろ、神の力にささえられて、福音のために、わたしと苦しみを共にしてほしい。</span>
<span className="v" id="v9" data-v="9" data-xref="エペソ人への手紙 2:8–9; テトスヘの手紙 3:4–5; エペソ人への手紙 1:3–4"> 神はわたしたちを救い、聖なる招きをもって召して下さったのであるが、それは、わたしたちのわざによるのではなく、神ご自身の計画に基き、また、永遠の昔にキリスト・イエスにあってわたしたちに賜わっていた恵み、</span>
<span className="v" id="v10" data-v="10" data-xref="ヨハネの第一の手紙 1:2; ローマ人への手紙 16:26; ペテロの第二の手紙 3:18"> そして今や、わたしたちの救主キリスト・イエスの出現によって明らかにされた恵みによるのである。キリストは死を滅ぼし、福音によっていのちと不死とを明らかに示されたのである。</span>
<span className="v" id="v11" data-v="11" data-xref="テモテヘの第一の手紙 2:7; エペソ人への手紙 3:7–8; 使徒行伝 9:15"> わたしは、この福音のために立てられて、その宣教者、使徒、教師になった。</span>
<span className="v" id="v12" data-v="12" data-xref="テモテヘの第二の手紙 1:8; ユダの手紙 1:24; ペテロの第一の手紙 4:19"> そのためにまた、わたしはこのような苦しみを受けているが、それを恥としない。なぜなら、わたしは自分の信じてきたかたを知っており、またそのかたは、わたしにゆだねられているものを、かの日に至るまで守って下さることができると、確信しているからである。</span>
<span className="v" id="v13" data-v="13" data-xref="テトスヘの手紙 1:9; テモテヘの第二の手紙 3:14; ピリピ人への手紙 4:9"> あなたは、キリスト・イエスに対する信仰と愛とをもって、わたしから聞いた健全な言葉を模範にしなさい。</span>
<span className="v" id="v14" data-v="14" data-xref="ヨハネによる福音書 14:17; ローマ人への手紙 8:13; テモテヘの第一の手紙 6:20"> そして、あなたにゆだねられている尊いものを、わたしたちの内に宿っている聖霊によって守りなさい。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="テモテヘの第二の手紙 4:16; ピリピ人への手紙 2:21; 使徒行伝 19:10"> あなたの知っているように、アジヤにいる者たちは、皆わたしから離れて行った。その中には、フゲロとヘルモゲネもいる。</span>
<span className="v" id="v16" data-v="16" data-xref="テモテヘの第二の手紙 4:19; ピレモンヘの手紙 1:20; ピレモンヘの手紙 1:7"> どうか、主が、オネシポロの家にあわれみをたれて下さるように。彼はたびたび、わたしを慰めてくれ、またわたしの鎖を恥とも思わないで、</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行伝 28:30–31"> ローマに着いた時には、熱心にわたしを捜しまわった末、尋ね出してくれたのである。</span>
<span className="v" id="v18" data-v="18" data-xref="ヘブル人への手紙 6:10; テモテヘの第二の手紙 1:12; テモテヘの第一の手紙 1:3"> どうか、主がかの日に、あわれみを彼に賜わるように。――彼がエペソで、どれほどわたしに仕えてくれたかは、だれよりもあなたがよく知っている。</span>

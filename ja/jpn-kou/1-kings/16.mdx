<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歴代志下 20:34; 歴代志下 19:2; 列王紀上 16:7"> そこで主の言葉がハナニの子エヒウに臨み、バアシャを責めて言った、</span>
<span className="v" id="v2" data-v="2" data-xref="列王紀上 15:34; 列王紀上 14:7; サムエル記上 2:8"> 「わたしはあなたをちりの中からあげて、わたしの民イスラエルの上に君としたが、あなたはヤラベアムの道に歩み、わたしの民イスラエルに罪を犯させ、その罪をもってわたしを怒らせた。</span>
<span className="v" id="v3" data-v="3" data-xref="列王紀上 14:10; 列王紀上 15:29–30; イザヤ書 66:24"> それでわたしは、バアシャとその家を全く滅ぼし去り、あなたの家をネバテの子ヤラベアムの家のようにする。</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀上 14:11; 列王紀上 21:24"> バアシャに属する者で、町で死ぬ者は犬が食べ、彼に属する者で、野で死ぬ者は空の鳥が食べるであろう」。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="列王紀上 14:19; 列王紀上 15:31; 歴代志下 16:1–6"> バアシャのその他の事績と、彼がした事と、その勲功とは、イスラエルの王の歴代志の書にしるされているではないか。</span>
<span className="v" id="v6" data-v="6" data-xref="列王紀上 14:17; 列王紀上 15:21; 列王紀上 16:13–14"> バアシャはその先祖と共に眠って、テルザに葬られ、その子エラが代って王となった。</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀上 14:14; ホセア書 1:4; 詩篇 115:4"> 主の言葉はまたハナニの子預言者エヒウによって臨み、バアシャとその家を責めた。これは彼が主の目の前に、もろもろの悪を行い、その手のわざをもって主を怒らせ、ヤラベアムの家にならったためであり、また彼がヤラベアムの家を滅ぼしたためであった。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8"> ユダの王アサの第二十六年にバアシャの子エラはテルザでイスラエルの王となり、二年世を治めた。</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀上 18:3; 創世記 39:4; ダニエル書 5:1–4"> 彼がテルザにいて、テルザの宮殿のつかさアルザの家で酒を飲んで酔った時、その家来で戦車隊の半ばを指揮していたジムリが、彼にそむいた。</span>
<span className="v" id="v10" data-v="10" data-xref="列王紀下 9:31"> そしてユダの王アサの第二十七年にジムリは、はいってきて彼を撃ち殺し、彼に代って王となった。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="サムエル記上 25:22; 列王紀上 16:3; 列王紀上 15:29"> ジムリは王となって、位についた時、バアシャの全家を殺し、その親族または友だちの男子は、ひとりも残さなかった。</span>
<span className="v" id="v12" data-v="12" data-xref="列王紀上 16:1; 列王紀上 16:7; 歴代志下 10:15"> こうしてジムリはバアシャの全家を滅ぼした。主が預言者エヒウによってバアシャを責めて言われた言葉のとおりである。</span>
<span className="v" id="v13" data-v="13" data-xref="申命記 32:21; 列王紀上 15:30; イザヤ書 41:29"> これはバアシャのもろもろの罪と、その子エラの罪のためであって、彼らが罪を犯し、またイスラエルに罪を犯させ、彼らの偶像をもってイスラエルの神、主を怒らせたからである。</span>
<span className="v" id="v14" data-v="14"> エラのその他の事績と、彼がしたすべての事は、イスラエルの王の歴代志の書にしるされているではないか。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="列王紀上 15:27; ヨシュア記 19:44; ヨブ記 20:5"> ユダの王アサの第二十七年にジムリはテルザで七日の間、世を治めた。民はペリシテびとに属するギベトンにむかって陣取っていたが、</span>
<span className="v" id="v16" data-v="16" data-xref="歴代志下 22:2; 列王紀下 8:26; ミカ書 6:16"> その陣取っていた民が「ジムリはむほんを起して王を殺した」と人のいうのを聞いたので、イスラエルは皆その日陣営で、軍の長オムリをイスラエルの王とした。</span>
<span className="v" id="v17" data-v="17" data-xref="士師記 9:50; ルカによる福音書 19:43–44; 列王紀下 18:9–12"> そこでオムリはイスラエルの人々と共にギベトンから上ってテルザを囲んだ。</span>
<span className="v" id="v18" data-v="18" data-xref="サムエル記下 17:23; サムエル記上 31:4–5; ヨブ記 2:9–10"> ジムリはその町の陥るのを見て、王の宮殿の天守にはいり、王の宮殿に火をかけてその中で死んだ。</span>
<span className="v" id="v19" data-v="19" data-xref="列王紀上 15:26; 列王紀上 14:16; 列王紀上 12:28"> これは彼が犯した罪のためであって、彼が主の目の前に悪を行い、ヤラベアムの道に歩み、ヤラベアムがイスラエルに犯させたその罪を行ったからである。</span>
<span className="v" id="v20" data-v="20" data-xref="列王紀上 16:14; 列王紀上 16:5; 列王紀上 16:27"> ジムリのその他の事績と、彼が企てた陰謀は、イスラエルの王の歴代志の書にしるされているではないか。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="マタイによる福音書 12:25; エペソ人への手紙 4:3–5; 箴言 28:2"> その時イスラエルの民は二つに分れ、民の半ばはギナテの子テブニに従って、これを王としようとし、半ばはオムリに従った。</span>
<span className="v" id="v22" data-v="22"> しかしオムリに従った民はギナテの子テブニに従った民に勝って、テブニは死に、オムリが王となった。</span>
<span className="v" id="v23" data-v="23" data-xref="列王紀上 16:8; 列王紀上 16:29; 歴代志下 22:2"> ユダの王アサの第三十一年にオムリはイスラエルの王となって十二年世を治めた。彼はテルザで六年王であった。</span>
<span className="v" id="v24" data-v="24" data-xref="列王紀上 13:32; 列王紀上 16:32; 使徒行伝 8:5–8"> 彼は銀二タラントでセメルからサマリヤの山を買い、その上に町を建て、その建てた町の名をその山の持ち主であったセメルの名に従ってサマリヤと呼んだ。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="ミカ書 6:16; 列王紀上 16:30–31; 列王紀上 14:9"> オムリは主の目の前に悪を行い、彼よりも先にいたすべての者にまさって悪い事をした。</span>
<span className="v" id="v26" data-v="26" data-xref="列王紀上 16:19; 列王紀上 16:13; 列王紀上 12:26–33"> 彼はネバテの子ヤラベアムのすべての道に歩み、ヤラベアムがイスラエルに罪を犯させ、彼らの偶像をもってイスラエルの神、主を怒らせたその罪を行った。</span>
<span className="v" id="v27" data-v="27" data-xref="列王紀上 16:20; 列王紀上 16:14; 列王紀上 16:5"> オムリが行ったその他の事績と、彼があらわした勲功とは、イスラエルの王の歴代志の書にしるされているではないか。</span>
<span className="v" id="v28" data-v="28"> オムリはその先祖と共に眠って、サマリヤに葬られ、その子アハブが代って王となった。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29"> ユダの王アサの第三十八年にオムリの子アハブがイスラエルの王となった。オムリの子アハブはサマリヤで二十二年イスラエルを治めた。</span>
<span className="v" id="v30" data-v="30" data-xref="列王紀上 16:25; 列王紀上 21:25; 列王紀上 14:9"> オムリの子アハブは彼よりも先にいたすべての者にまさって、主の目の前に悪を行った。</span>
<span className="v" id="v31" data-v="31" data-xref="列王紀下 17:16; 列王紀下 10:18; 士師記 18:7"> 彼はネバテの子ヤラベアムの罪を行うことを、軽い事とし、シドンびとの王エテバアルの娘イゼベルを妻にめとり、行ってバアルに仕え、これを拝んだ。</span>
<span className="v" id="v32" data-v="32" data-xref="列王紀下 10:21; 列王紀下 10:26–27"> 彼はサマリヤに建てたバアルの宮に、バアルのために祭壇を築いた。</span>
<span className="v" id="v33" data-v="33" data-xref="列王紀下 13:6; 列王紀上 21:25; 列王紀下 21:3"> アハブはまたアシラ像を造った。アハブは彼よりも先にいたイスラエルのすべての王にまさってイスラエルの神、主を怒らせることを行った。</span>
<span className="v" id="v34" data-v="34" data-xref="ヨシュア記 6:26; ヨシュア記 23:14–15; マタイによる福音書 24:35"> 彼の代にベテルびとヒエルはエリコを建てた。彼はその基をすえる時に長子アビラムを失い、その門を立てる時に末の子セグブを失った。主がヌンの子ヨシュアによって言われた言葉のとおりである。</span>
</div>

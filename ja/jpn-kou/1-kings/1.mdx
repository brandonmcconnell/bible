<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨシュア記 23:1–2; 歴代志上 29:27–28; 歴代志上 23:1"> ダビデ王は年がすすんで老い、夜着を着せても暖まらなかったので、</span>
<span className="v" id="v2" data-v="2" data-xref="伝道の書 4:11; 創世記 16:5; ミカ書 7:5"> その家来たちは彼に言った、「王わが主のために、ひとりの若いおとめを捜し求めて王にはべらせ、王の付添いとし、あなたのふところに寝て、王わが主を暖めさせましょう」。</span>
<span className="v" id="v3" data-v="3" data-xref="ヨシュア記 19:18; エステル記 2:4; エステル記 2:2"> そして彼らはあまねくイスラエルの領土に美しいおとめを捜し求めて、シュナミびとアビシャグを得、王のもとに連れてきた。</span>
<span className="v" id="v4" data-v="4" data-xref="マタイによる福音書 1:25"> おとめは非常に美しく、王の付添いとなって王に仕えたが、王は彼女を知ることがなかった。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="サムエル記下 15:1; サムエル記下 3:4; 申命記 17:15–16"> さてハギテの子アドニヤは高ぶって、「わたしは王となろう」と言い、自分のために戦車と騎兵および自分の前に駆ける者五十人を備えた。</span>
<span className="v" id="v6" data-v="6" data-xref="サムエル記下 3:3–4; サムエル記上 3:13; ヘブル人への手紙 12:5–6"> 彼の父は彼が生れてこのかた一度も「なぜ、そのような事をするのか」と言って彼をたしなめたことがなかった。アドニヤもまた非常に姿の良い人であって、アブサロムの次に生れた者である。</span>
<span className="v" id="v7" data-v="7" data-xref="サムエル記下 20:25; 列王紀上 2:22; サムエル記上 22:20–23"> 彼がゼルヤの子ヨアブと祭司アビヤタルとに相談したので、彼らはアドニヤに従って彼を助けた。</span>
<span className="v" id="v8" data-v="8" data-xref="列王紀上 4:18; サムエル記下 23:8–39; サムエル記下 20:25"> しかし祭司ザドクと、エホヤダの子ベナヤと、預言者ナタンおよびシメイとレイ、ならびにダビデの勇士たちはアドニヤに従わなかった。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="サムエル記下 17:17; サムエル記下 13:23–27; サムエル記下 15:11–12"> アドニヤはエンロゲルのほとりにある「へびの石」のかたわらで、羊と牛と肥えた家畜をほふって、王の子である自分の兄弟たち、および王の家来であるユダの人々をことごとく招いた。</span>
<span className="v" id="v10" data-v="10" data-xref="サムエル記下 12:24; 列王紀上 1:19; サムエル記下 12:1–15"> しかし預言者ナタンと、ベナヤと、勇士たちと、自分の兄弟ソロモンとは招かなかった。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="サムエル記下 3:4; サムエル記下 7:12–17; サムエル記下 12:24–25"> 時にナタンはソロモンの母バテシバに言った、「ハギテの子アドニヤが王となったのをお聞きになりませんでしたか。われわれの主ダビデはそれをごぞんじないのです。</span>
<span className="v" id="v12" data-v="12" data-xref="箴言 11:14; 使徒行伝 27:31; 創世記 19:17"> それでいま、あなたに計りごとを授けて、あなたの命と、あなたの子ソロモンの命を救うようにいたしましょう。</span>
<span className="v" id="v13" data-v="13" data-xref="列王紀上 1:30; 列王紀上 1:17; 詩篇 132:11–12"> あなたはすぐダビデ王のところへ行って、『王わが主よ、あなたは、はしために誓って、おまえの子ソロモンが、わたしに次いで王となり、わたしの位に座するであろうと言われたではありませんか。そうであるのに、どうしてアドニヤが王となったのですか』と言いなさい。</span>
<span className="v" id="v14" data-v="14" data-xref="コリント人への第二の手紙 13:1; 列王紀上 1:17–27"> あなたがなお王と話しておられる間に、わたしもまた、あなたのあとから、はいって行って、あなたの言葉を確認しましょう」。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="列王紀上 1:1"> そこでバテシバは寝室にはいって王の所へ行った。（王は非常に老いて、シュナミびとアビシャグが王に仕えていた）。</span>
<span className="v" id="v16" data-v="16" data-xref="サムエル記上 25:23; サムエル記上 24:8; サムエル記上 20:41"> バテシバは身をかがめて王を拝した。王は言った、「何の用か」。</span>
<span className="v" id="v17" data-v="17" data-xref="列王紀上 1:13; 列王紀上 1:30; ペテロの第一の手紙 3:6"> 彼女は王に言った、「わが主よ、あなたは、あなたの神、主をさして、はしために誓い、『おまえの子ソロモンがわたしに次いで王となり、わたしの位に座するであろう』と言われました。</span>
<span className="v" id="v18" data-v="18" data-xref="列王紀上 1:24; 列王紀上 1:11; 使徒行伝 3:17"> そうであるのに、ごらんなさい、今アドニヤが王となりました。王わが主よ、あなたはそれをごぞんじないのです。</span>
<span className="v" id="v19" data-v="19" data-xref="列王紀上 1:25; 列王紀上 1:7–10"> 彼は牛と肥えた家畜と羊をたくさんほふって、王の子たち、および祭司アビヤタルと、軍の長ヨアブを招きましたが、あなたのしもべソロモンは招きませんでした。</span>
<span className="v" id="v20" data-v="20" data-xref="歴代志上 29:1; 詩篇 123:2; 歴代志上 22:8–10"> 王わが主よ、イスラエルのすべての目はあなたに注がれ、だれがあなたに次いで、王わが主の位に座すべきかを告げられるのを望んでいます。</span>
<span className="v" id="v21" data-v="21" data-xref="列王紀上 2:10; 申命記 31:16; 創世記 15:15"> 王わが主が先祖と共に眠られるとき、わたしと、わたしの子ソロモンは謀叛人とみなされるでしょう」。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="ヨブ記 1:16–18; 創世記 24:15; ダニエル書 9:20"> バテシバがなお王と話しているうちに、預言者ナタンがはいってきた。</span>
<span className="v" id="v23" data-v="23" data-xref="列王紀上 1:16; ペテロの第一の手紙 2:17; ローマ人への手紙 13:7"> 人々は王に告げて、「預言者ナタンがここにおります」と言った。彼は王の前にはいり、地に伏して王を拝した。</span>
<span className="v" id="v24" data-v="24" data-xref="列王紀上 1:17–18; 列王紀上 1:5; 列王紀上 1:13–14"> そしてナタンは言った、「王わが主よ、あなたは、『アドニヤがわたしに次いで王となり、わたしの位に座するであろう』と仰せられましたか。</span>
<span className="v" id="v25" data-v="25" data-xref="サムエル記上 10:24; 列王紀上 1:19; 列王紀上 1:9"> 彼はきょう下っていって、牛と、肥えた家畜と羊をたくさんほふって、王の子たちと、軍の長ヨアブと、祭司アビヤタルを招きました。彼らはアドニヤの前で食い飲みして、『アドニヤ万歳』と言いました。</span>
<span className="v" id="v26" data-v="26" data-xref="列王紀上 1:8; 列王紀上 1:10; サムエル記下 7:2"> しかし、あなたのしもべであるわたしと、祭司ザドクと、エホヤダの子ベナヤと、あなたのしもべソロモンを招きませんでした。</span>
<span className="v" id="v27" data-v="27" data-xref="ヨハネによる福音書 15:15; 列王紀上 1:24; 列王紀下 4:27"> この事は王わが主がさせられた事ですか。あなたはしもべたちに、だれがあなたに次いで王わが主の位に座すべきかを告げられませんでした」。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28"> ダビデ王は答えて言った、「バテシバをわたしのところに呼びなさい」。彼女は王の前にはいってきて、王の前に立った。</span>
<span className="v" id="v29" data-v="29" data-xref="サムエル記下 4:9; 詩篇 136:24; サムエル記上 14:45"> すると王は誓って言った、「わたしの命をすべての苦難から救われた主は生きておられる。</span>
<span className="v" id="v30" data-v="30" data-xref="列王紀上 1:13; 列王紀上 1:17"> わたしがイスラエルの神、主をさしてあなたに誓い、『あなたの子ソロモンがわたしに次いで王となり、わたしに代って、わたしの位に座するであろう』と言ったように、わたしはきょう、そのようにしよう」。</span>
<span className="v" id="v31" data-v="31" data-xref="ダニエル書 2:4; ダニエル書 5:10; ダニエル書 3:9"> そこでバテシバは身をかがめ、地に伏して王を拝し、「わが主ダビデ王が、とこしえに生きながらえられますように」と言った。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="列王紀上 1:8; 列王紀上 1:38; 列王紀上 1:26"> ダビデは言った、「祭司ザドクと、預言者ナタンおよびエホヤダの子ベナヤをわたしの所に呼びなさい」。やがて彼らは王の前にきた。</span>
<span className="v" id="v33" data-v="33" data-xref="歴代志下 32:30; 列王紀上 1:38; 歴代志下 33:14"> 王は彼らに言った、「あなたがたの主君の家来たちを連れ、わが子ソロモンをわたしの騾馬に乗せ、彼を導いてギホンに下り、</span>
<span className="v" id="v34" data-v="34" data-xref="列王紀上 1:25; サムエル記下 15:10; サムエル記上 10:1"> その所で祭司ザドクと預言者ナタンは彼に油を注いでイスラエルの王としなさい。そしてラッパを吹いて、『ソロモン王万歳』と言いなさい。</span>
<span className="v" id="v35" data-v="35" data-xref="列王紀上 1:17; 詩篇 72:1–2; 列王紀上 1:13"> それから、あなたがたは彼に従って上ってきなさい。彼はきて、わたしの位に座し、わたしに代って王となるであろう。わたしは彼を立ててイスラエルとユダの上に主君とする」。</span>
<span className="v" id="v36" data-v="36" data-xref="エレミヤ書 28:6; コリント人への第一の手紙 14:16; 詩篇 72:19"> エホヤダの子ベナヤは王に答えて言った、「アァメン、願わくは、王わが主君の神、主もまたそう仰せられますように。</span>
<span className="v" id="v37" data-v="37" data-xref="サムエル記上 20:13; 列王紀上 1:47; ヨシュア記 1:17"> 願わくは、主が王わが主君と共におられたように、ソロモンと共におられて、その位をわが主君ダビデ王の位よりも大きくせられますように」。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="サムエル記下 8:18; 列王紀上 1:8; 列王紀上 1:33"> そこで祭司ザドクと預言者ナタンおよびエホヤダの子ベナヤ、ならびにケレテびとと、ペレテびとは下って行って、ソロモンをダビデ王の騾馬に乗せ、彼をギホンに導いて行った。</span>
<span className="v" id="v39" data-v="39" data-xref="詩篇 89:20; 列王紀上 1:34; 歴代志上 29:22"> 祭司ザドクは幕屋から油の角を取ってきて、ソロモンに油を注いだ。そしてラッパを吹き鳴らし、民は皆「ソロモン王万歳」と言った。</span>
<span className="v" id="v40" data-v="40" data-xref="列王紀下 11:14; ゼカリヤ書 9:9; 列王紀下 11:20"> 民はみな彼に従って上り、笛を吹いて大いに喜び祝った。地は彼らの声で裂けるばかりであった。</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="ヨブ記 15:21–22; ルカによる福音書 17:26–29; 使徒行伝 21:31"> アドニヤおよび彼と共にいた客たちは皆食事を終ったとき、これを聞いた。ヨアブはラッパの音を聞いて言った、「町の中のあの騒ぎは何か」。</span>
<span className="v" id="v42" data-v="42" data-xref="サムエル記下 15:36; サムエル記下 17:17; サムエル記下 18:27"> 彼の言葉のなお終らないうちに、そこへ祭司アビヤタルの子ヨナタンがきたので、アドニヤは彼に言った、「はいりなさい。あなたは勇敢な人で、よい知らせを持ってきたのでしょう」。</span>
<span className="v" id="v43" data-v="43"> ヨナタンは答えてアドニヤに言った、「いいえ、主君ダビデ王はソロモンを王とせられました。</span>
<span className="v" id="v44" data-v="44"> 王は祭司ザドクと預言者ナタンおよびエホヤダの子ベナヤ、ならびにケレテびとと、ペレテびとをソロモンと共につかわされたので、彼らはソロモンを王の騾馬に乗せて行き、</span>
<span className="v" id="v45" data-v="45" data-xref="列王紀上 1:40; ダニエル書 5:26–28; サムエル記上 4:5"> 祭司ザドクと預言者ナタンはギホンで彼に油を注いで王としました。そして彼らがそこから喜んで上って来るので、町が騒がしいのです。あなたが聞いた声はそれなのです。</span>
<span className="v" id="v46" data-v="46" data-xref="歴代志上 29:23; 詩篇 132:11; 列王紀上 1:13"> こうしてソロモンは王の位に座し、</span>
<span className="v" id="v47" data-v="47" data-xref="創世記 47:31; 列王紀上 1:37; エズラ記 6:10"> かつ王の家来たちがきて、主君ダビデ王に祝いを述べて、『願わくは、あなたの神がソロモンの名をあなたの名よりも高くし、彼の位をあなたの位よりも大きくされますように』と言いました。そして王は床の上で拝されました。</span>
<span className="v" id="v48" data-v="48" data-xref="列王紀上 3:6; 詩篇 132:11–12; 詩篇 145:2"> 王はまたこう言われました、『イスラエルの神、主はほむべきかな。主はきょう、わたしの位に座するひとりの子を与えて、これをわたしに見せてくださった』と」。</span>
</div>
<div className="bp">
<span className="v" id="v49" data-v="49" data-xref="イザヤ書 21:4–5; 箴言 28:1; ダニエル書 5:4–6"> その時アドニヤと共にいた客はみな驚き、立っておのおの自分の道に去って行った。</span>
<span className="v" id="v50" data-v="50" data-xref="列王紀上 2:28; 出エジプト記 21:14; 出エジプト記 27:2"> そしてアドニヤはソロモンを恐れ、立って行って祭壇の角をつかんだ。</span>
<span className="v" id="v51" data-v="51"> ある人がこれをソロモンに告げて言った、「アドニヤはソロモンを恐れ、今彼は祭壇の角をつかんで、『どうぞ、ソロモン王がきょう、つるぎをもってしもべを殺さないとわたしに誓ってくださるように』と言っています」。</span>
<span className="v" id="v52" data-v="52" data-xref="サムエル記上 14:45; サムエル記下 14:11; 箴言 13:6"> ソロモンは言った、「もし彼がよい人となるならば、その髪の毛ひとすじも地に落ちることはなかろう。しかし彼のうちに悪のあることがわかるならば、彼は死ななければならない」。</span>
<span className="v" id="v53" data-v="53" data-xref="列王紀上 1:16; サムエル記下 14:24; サムエル記下 1:2"> ソロモンは人をつかわして彼を祭壇からつれて下らせた。彼がきてソロモンを拝したので、ソロモンは彼に「家に帰りなさい」と言った。</span>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歴代志上 14:1; 歴代志下 2:3; 列王紀上 5:10"> さてツロの王ヒラムは、ソロモンが油を注がれ、その父に代って、王となったのを聞いて、家来をソロモンにつかわした。ヒラムは常にダビデを愛したからである。</span>
<span className="v" id="v2" data-v="2" data-xref="歴代志下 2:3"> そこでソロモンはヒラムに人をつかわして言った、</span>
<span className="v" id="v3" data-v="3" data-xref="歴代志上 28:3; 歴代志上 22:8; 詩篇 110:1"> 「あなたの知られるとおり、父ダビデはその周囲にあった敵との戦いのゆえに、彼の神、主の名のために宮を建てることができず、主が彼らをその足の裏の下に置かれるのを待ちました。</span>
<span className="v" id="v4" data-v="4" data-xref="歴代志上 22:9; 列王紀上 4:24; 使徒行伝 9:31"> ところが今わが神、主はわたしに四方の太平を賜わって、敵もなく、災もなくなったので、</span>
<span className="v" id="v5" data-v="5" data-xref="歴代志上 17:12; 歴代志上 22:10; サムエル記下 7:12–13"> 主が父ダビデに『おまえに代って、おまえの位に、わたしがつかせるおまえの子、その人がわが名のために宮を建てるであろう』と言われたように、わが神、主の名のために宮を建てようと思います。</span>
<span className="v" id="v6" data-v="6" data-xref="歴代志下 2:8; 列王紀上 6:9–10; ローマ人への手紙 12:17"> それゆえ、あなたは命令を下して、レバノンの香柏をわたしのために切り出させてください。わたしのしもべたちをあなたのしもべたちと一緒に働かせます。またわたしはすべてあなたのおっしゃるとおり、あなたのしもべたちの賃銀をあなたに払います。あなたの知られるとおり、わたしたちのうちにはシドンびとのように木を切るに巧みな人がないからです」。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="箴言 23:24; イザヤ書 9:6; 歴代志下 2:11–12"> ヒラムはソロモンの言葉を聞いて大いに喜び、「きょう、主はあがむべきかな。主はこのおびただしい民を治める賢い子をダビデに賜わった」と言った。</span>
<span className="v" id="v8" data-v="8" data-xref="列王紀上 6:34; 歴代志下 3:5; サムエル記下 6:5"> そしてヒラムはソロモンに人をつかわして言った、「わたしはあなたが申しおくられたことを聞きました。香柏の材木と、いとすぎの材木については、すべてお望みのようにいたします。</span>
<span className="v" id="v9" data-v="9" data-xref="エズラ記 3:7; エゼキエル書 27:17; 使徒行伝 12:20"> わたしのしもべどもにそれをレバノンから海に運びおろさせましょう。わたしはそれをいかだに組んで、海路、あなたの指示される場所まで送り、そこでそれをくずしましょう。あなたはそれを受け取ってください。また、あなたはわたしの家のために食物を供給して、わたしの望みをかなえてください」。</span>
<span className="v" id="v10" data-v="10"> こうしてヒラムはソロモンにすべて望みのように香柏の材木と、いとすぎの材木を与えた。</span>
<span className="v" id="v11" data-v="11" data-xref="歴代志下 2:10; 列王紀上 4:22"> またソロモンはヒラムにその家の食物として小麦二万コルを与え、またオリブをつぶして取った油二万コルを与えた。このようにソロモンは年々ヒラムに与えた。</span>
<span className="v" id="v12" data-v="12" data-xref="列王紀上 3:12; アモス書 1:9; ヤコブの手紙 1:5"> 主は約束されたようにソロモンに知恵を賜わった。またヒラムとソロモンの間は平和であって、彼らふたりは条約を結んだ。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="列王紀上 9:15; 列王紀上 4:6"> ソロモン王はイスラエルの全地から強制的に労働者を徴募した。その徴募人員は三万人であった。</span>
<span className="v" id="v14" data-v="14" data-xref="列王紀上 4:6–19; 歴代志上 27:1–15"> ソロモンは彼らを一か月交代に一万人ずつレバノンにつかわした。すなわち一か月レバノンに、二か月家にあり、アドニラムは徴募の監督であった。</span>
<span className="v" id="v15" data-v="15" data-xref="列王紀上 9:20–22; 歴代志下 2:17–18; 歴代志下 8:7–9"> ソロモンにはまた荷を負う者が七万人、山で石を切る者が八万人あった。</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀上 9:23; 歴代志下 2:2"> ほかにソロモンには工事を監督する上役の官吏が三千三百人あって、工事に働く民を監督した。</span>
<span className="v" id="v17" data-v="17" data-xref="列王紀上 6:7; 歴代志上 22:2; イザヤ書 28:16"> 王は命じて大きい高価な石を切り出させ、切り石をもって宮の基をすえさせた。</span>
<span className="v" id="v18" data-v="18" data-xref="ヨシュア記 13:5; エゼキエル書 27:9; 詩篇 83:7"> こうしてソロモンの建築者と、ヒラムの建築者およびゲバルびとは石を切り、材木と石とを宮を建てるために備えた。</span>
</div>

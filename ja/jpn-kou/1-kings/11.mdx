<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命記 17:17; 箴言 6:24; ネヘミヤ書 13:23–27"> ソロモン王は多くの外国の女を愛した。すなわちパロの娘、モアブびと、アンモンびと、エドムびと、シドンびと、ヘテびとの女を愛した。</span>
<span className="v" id="v2" data-v="2" data-xref="出エジプト記 34:16; 申命記 7:3–4; ヨシュア記 23:12–13"> 主はかつてこれらの国民について、イスラエルの人々に言われた、「あなたがたは彼らと交わってはならない。彼らもまたあなたがたと交わってはならない。彼らは必ずあなたがたの心を転じて彼らの神々に従わせるからである」。しかしソロモンは彼らを愛して離れなかった。</span>
<span className="v" id="v3" data-v="3" data-xref="伝道の書 7:28; サムエル記下 5:13–16; 歴代志下 11:21"> 彼には王妃としての妻七百人、そばめ三百人があった。その妻たちが彼の心を転じたのである。</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀上 9:4; 列王紀上 8:61; 列王紀上 11:6"> ソロモンが年老いた時、その妻たちが彼の心を転じて他の神々に従わせたので、彼の心は父ダビデの心のようには、その神、主に真実でなかった。</span>
<span className="v" id="v5" data-v="5" data-xref="士師記 2:13; 列王紀上 11:7; 列王紀下 23:13"> これはソロモンがシドンびとの女神アシタロテに従い、アンモンびとの神である憎むべき者ミルコムに従ったからである。</span>
<span className="v" id="v6" data-v="6" data-xref="民数記 14:24; ヨシュア記 14:8; ヨシュア記 14:14"> このようにソロモンは主の目の前に悪を行い、父ダビデのように全くは主に従わなかった。</span>
<span className="v" id="v7" data-v="7" data-xref="民数記 21:29; 士師記 11:24; 使徒行伝 7:43"> そしてソロモンはモアブの神である憎むべき者ケモシのために、またアンモンの人々の神である憎むべき者モレクのためにエルサレムの東の山に高き所を築いた。</span>
<span className="v" id="v8" data-v="8" data-xref="コリント人への第一の手紙 10:11–12; 列王紀上 11:1; エゼキエル書 16:22–29"> 彼はまた外国のすべての妻たちのためにもそうしたので、彼女たちはその神々に香をたき、犠牲をささげた。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="列王紀上 9:2; 列王紀上 3:5; 申命記 7:4"> このようにソロモンの心が転じて、イスラエルの神、主を離れたため、主は彼を怒られた。すなわち主がかつて二度彼に現れ、</span>
<span className="v" id="v10" data-v="10" data-xref="列王紀上 6:12–13; 歴代志下 7:17–22; 列王紀上 9:4–7"> この事について彼に、他の神々に従ってはならないと命じられたのに、彼は主の命じられたことを守らなかったからである。</span>
<span className="v" id="v11" data-v="11" data-xref="列王紀上 12:15–16; 列王紀上 11:31; 列王紀下 17:21"> それゆえ、主はソロモンに言われた、「これがあなたの本心であり、わたしが命じた契約と定めとを守らなかったので、わたしは必ずあなたから国を裂き離して、それをあなたの家来に与える。</span>
<span className="v" id="v12" data-v="12" data-xref="列王紀下 20:19; サムエル記上 9:4–5; 列王紀下 22:19–20"> しかしあなたの父ダビデのために、あなたの世にはそれをしないが、あなたの子の手からそれを裂き離す。</span>
<span className="v" id="v13" data-v="13" data-xref="列王紀上 12:20; 申命記 12:11; 列王紀上 11:32"> ただし、わたしは国をことごとくは裂き離さず、わたしのしもべダビデのために、またわたしが選んだエルサレムのために一つの部族をあなたの子に与えるであろう」。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="歴代志上 5:26; 詩篇 89:30–34; イザヤ書 13:17"> こうして主はエドムびとハダデを起して、ソロモンの敵とされた。彼はエドムの王家の者であった。</span>
<span className="v" id="v15" data-v="15" data-xref="サムエル記下 8:14; 歴代志上 18:12–13; 申命記 20:13"> さきにダビデはエドムにいたが、軍の長ヨアブが上っていって、戦死した者を葬り、エドムの男子をことごとく打ち殺した時、</span>
<span className="v" id="v16" data-v="16"> （ヨアブはイスラエルの人々と共に六か月そこにとどまって、エドムの男子をことごとく断った）。</span>
<span className="v" id="v17" data-v="17" data-xref="マタイによる福音書 2:13–14; 出エジプト記 2:1–10; 列王紀下 11:2"> ハダデはその父のしもべである数人のエドムびとと共に逃げてエジプトへ行こうとした。その時ハダデはまだ少年であった。</span>
<span className="v" id="v18" data-v="18" data-xref="民数記 10:12; 申命記 33:2; 申命記 1:1"> 彼らがミデアンを立ってパランへ行き、パランから人々を伴ってエジプトへ行き、エジプトの王パロのところへ行くと、パロは彼に家を与え、食糧を定め、かつ土地を与えた。</span>
<span className="v" id="v19" data-v="19" data-xref="創世記 39:4; エレミヤ書 43:7–9; 創世記 39:21"> ハダデは大いにパロの心にかなったので、パロは自分の妻の妹すなわち王妃タペネスの妹を妻として彼に与えた。</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 21:7; サムエル記上 1:24"> タペネスの妹は彼に男の子ゲヌバテを産んだので、タペネスはその子をパロの家のうちで乳離れさせた。ゲヌバテはパロの家で、パロの子どもたちと一緒にいた。</span>
<span className="v" id="v21" data-v="21" data-xref="列王紀上 2:10; 出エジプト記 4:19; マタイによる福音書 2:20"> さてハダデはエジプトで、ダビデがその先祖と共に眠ったことと、軍の長ヨアブが死んだことを聞いたので、ハダデはパロに言った、「わたしを去らせて、国へ帰らせてください」。</span>
<span className="v" id="v22" data-v="22" data-xref="サムエル記下 18:22–23; ルカによる福音書 22:35; マルコによる福音書 14:31"> パロは彼に言った、「わたしと共にいて、なんの不足があって国へ帰ることを求めるのですか」。彼は言った、「ただ、わたしを帰らせてください」。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="列王紀上 11:14; サムエル記下 8:3; サムエル記下 10:15–18"> 神はまたエリアダの子レゾンを起してソロモンの敵とされた。彼はその主人ゾバの王ハダデゼルのもとを逃げ去った者であった。</span>
<span className="v" id="v24" data-v="24" data-xref="サムエル記下 10:8; サムエル記下 10:18; 列王紀上 20:34"> ダビデがゾバの人々を殺した後、彼は人々を自分のまわりに集めて略奪隊の首領となった。彼らはダマスコへ行って、そこに住み、ダマスコで彼を王とした。</span>
<span className="v" id="v25" data-v="25" data-xref="歴代志下 15:2; 詩篇 106:40; 列王紀上 5:4"> 彼はソロモンの一生の間、イスラエルの敵となって、ハダデがしたように害をなし、イスラエルを憎んでスリヤを治めた。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="歴代志下 13:6; 列王紀上 12:2; 列王紀上 11:28"> ゼレダのエフライムびとネバテの子ヤラベアムはソロモンの家来であったが、その母の名はゼルヤといって寡婦であった。彼もまたその手をあげて王に敵した。</span>
<span className="v" id="v27" data-v="27" data-xref="列王紀上 9:24; 列王紀上 9:15; 箴言 30:32"> 彼が手をあげて、王に敵した事情はこうである。ソロモンはミロを築き、父ダビデの町の破れ口をふさいでいた。</span>
<span className="v" id="v28" data-v="28" data-xref="箴言 22:29; サムエル記下 19:20; 士師記 1:22–23"> ヤラベアムは非常に手腕のある人であったが、ソロモンはこの若者がよく働くのを見て、彼にヨセフの家のすべての強制労働の監督をさせた。</span>
<span className="v" id="v29" data-v="29" data-xref="列王紀上 12:15; 列王紀上 14:2; 歴代志下 9:29"> そのころ、ヤラベアムがエルサレムを出たとき、シロびとである預言者アヒヤが道で彼に会った。アヒヤは新しい着物を着ていた。そして彼らふたりだけが野にいた。</span>
<span className="v" id="v30" data-v="30" data-xref="サムエル記上 15:27–28; サムエル記上 24:4–5"> アヒヤは着ている着物をつかんで、それを十二切れに裂き、</span>
<span className="v" id="v31" data-v="31" data-xref="列王紀上 11:11–12"> ヤラベアムに言った、「あなたは十切れを取りなさい。イスラエルの神、主はこう言われる、『見よ、わたしは国をソロモンの手から裂き離して、あなたに十部族を与えよう。</span>
<span className="v" id="v32" data-v="32" data-xref="列王紀上 11:13; 列王紀上 12:20–21; 列王紀上 14:21"> （ただし彼はわたしのしもべダビデのために、またわたしがイスラエルのすべての部族のうちから選んだ町エルサレムのために、一つの部族をもつであろう）。</span>
<span className="v" id="v33" data-v="33" data-xref="列王紀上 11:9; 列王紀上 11:5–7; 列王紀上 9:5–7"> それは彼がわたしを捨てて、シドンびとの女神アシタロテと、モアブの神ケモシと、アンモンの人々の神ミルコムを拝み、父ダビデのように、わたしの道に歩んで、わたしの目にかなう事を行い、わたしの定めと、おきてを守ることをしなかったからである。</span>
<span className="v" id="v34" data-v="34" data-xref="列王紀上 11:12–13; 列王紀上 11:31; ヨブ記 11:6"> しかし、わたしは国をことごとくは彼の手から取らない。わたしが選んだ、わたしのしもべダビデが、わたしの命令と定めとを守ったので、わたしは彼のためにソロモンを一生の間、君としよう。</span>
<span className="v" id="v35" data-v="35" data-xref="列王紀上 12:20; 列王紀上 11:12; 出エジプト記 20:5–6"> そして、わたしはその子の手から国を取って、その十部族をあなたに与える。</span>
<span className="v" id="v36" data-v="36" data-xref="列王紀下 8:19; 列王紀上 11:13; 列王紀上 15:4"> その子には一つの部族を与えて、わたしの名を置くために選んだ町エルサレムで、わたしのしもべダビデに、わたしの前に常に一つのともしびを保たせるであろう。</span>
<span className="v" id="v37" data-v="37" data-xref="申命記 14:26; 列王紀上 11:26; サムエル記下 3:21"> わたしがあなたを選び、あなたはすべて心の望むところを治めて、イスラエルの上に王となるであろう。</span>
<span className="v" id="v38" data-v="38" data-xref="サムエル記下 7:11; ヨシュア記 1:5; 申命記 31:8"> もし、あなたが、わたしの命じるすべての事を聞いて、わたしの道に歩み、わたしの目にかなう事を行い、わたしのしもべダビデがしたように、わたしの定めと戒めとを守るならば、わたしはあなたと共にいて、わたしがダビデのために建てたように、あなたのために堅固な家を建てて、イスラエルをあなたに与えよう。</span>
<span className="v" id="v39" data-v="39" data-xref="ルカによる福音書 1:32–33; ルカによる福音書 2:11; イザヤ書 11:1–10"> わたしはこのためにダビデの子孫を苦しめる。しかし永久にではない』」。</span>
<span className="v" id="v40" data-v="40" data-xref="歴代志下 12:2–9; イザヤ書 14:24–27; 哀歌 3:37"> ソロモンはヤラベアムを殺そうとしたが、ヤラベアムは立ってエジプトにのがれ、エジプト王シシャクのところへ行って、ソロモンの死ぬまでエジプトにいた。</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="歴代志下 9:29–31"> ソロモンのそのほかの事績と、彼がしたすべての事およびその知恵は、ソロモンの事績の書にしるされているではないか。</span>
<span className="v" id="v42" data-v="42" data-xref="列王紀上 2:11"> ソロモンがエルサレムでイスラエルの全地を治めた日は四十年であった。</span>
<span className="v" id="v43" data-v="43" data-xref="列王紀下 21:18; 列王紀上 2:10; マタイによる福音書 1:7"> ソロモンはその先祖と共に眠って、父ダビデの町に葬られ、その子レハベアムが代って王となった。</span>
</div>

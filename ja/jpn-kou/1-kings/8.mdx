<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歴代志下 5:2–10; 歴代志上 15:25; サムエル記下 6:12–17"> ソロモンは主の契約の箱をダビデの町、すなわちシオンからかつぎ上ろうとして、イスラエルの長老たちと、すべての部族のかしらたちと、イスラエルの人々の氏族の長たちをエルサレムでソロモン王のもとに召し集めた。</span>
<span className="v" id="v2" data-v="2" data-xref="レビ記 23:34; 歴代志下 7:8–10; ゼカリヤ書 14:16–19"> イスラエルの人は皆エタニムの月すなわち七月の祭にソロモン王のもとに集まった。</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 31:9; ヨシュア記 3:6; 民数記 4:15"> イスラエルの長老たちが皆来たので、祭司たちは箱を取りあげた。</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀上 3:4; 歴代志下 1:3; 出エジプト記 40:2–33"> そして彼らは主の箱と、会見の幕屋と、幕屋にあるすべての聖なる器をかつぎ上った。すなわち祭司とレビびとがこれらの物をかつぎ上った。</span>
<span className="v" id="v5" data-v="5" data-xref="サムエル記下 6:13; 歴代志上 16:1; 列王紀上 8:62–63"> ソロモン王および彼のもとに集まったイスラエルの会衆は皆彼と共に箱の前で、羊と牛をささげたが、その数が多くて調べることも数えることもできなかった。</span>
<span className="v" id="v6" data-v="6" data-xref="列王紀上 6:19; サムエル記下 6:17; 列王紀上 6:27"> 祭司たちは主の契約の箱をその場所にかつぎ入れた。すなわち宮の本殿である至聖所のうちのケルビムの翼の下に置いた。</span>
<span className="v" id="v7" data-v="7"> ケルビムは翼を箱の所に伸べていたので、ケルビムは上から箱とそのさおをおおった。</span>
<span className="v" id="v8" data-v="8" data-xref="出エジプト記 25:13–15; 出エジプト記 37:4–5; ヨシュア記 4:9"> さおは長かったので、さおの端が本殿の前の聖所から見えた。しかし外には見えなかった。そのさおは今日までそこにある。</span>
<span className="v" id="v9" data-v="9" data-xref="出エジプト記 25:21; ヘブル人への手紙 9:4; 出エジプト記 40:20"> 箱の内には二つの石の板のほか何もなかった。これはイスラエルの人々がエジプトの地から出たとき、主が彼らと契約を結ばれたときに、モーセがホレブで、それに納めたものである。</span>
<span className="v" id="v10" data-v="10" data-xref="出エジプト記 40:34–35; 歴代志下 7:1–2"> そして祭司たちが聖所から出たとき、雲が主の宮に満ちたので、</span>
<span className="v" id="v11" data-v="11" data-xref="エゼキエル書 43:4–5; エゼキエル書 44:4; コリント人への第二の手紙 3:18"> 祭司たちは雲のために立って仕えることができなかった。主の栄光が主の宮に満ちたからである。</span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="詩篇 97:2; 歴代志下 6:1–11; レビ記 16:2"> そこでソロモンは言った、<br /><span className="pl pl-1">「主は日を天に置かれた。</span><br /><span className="pl pl-1">しかも主は自ら濃き雲の中に住まおうと言われた。</span></span>
<span className="v" id="v13" data-v="13" data-xref="サムエル記下 7:13; 詩篇 132:13–14; ヘブル人への手紙 9:24"> <span className="pl pl-1">わたしはあなたのために高き家、</span><br /><span className="pl pl-1">とこしえのみすまいを建てた」。</span></span>
<span className="v" id="v14" data-v="14" data-xref="サムエル記下 6:18; 列王紀上 8:55–56; 歴代志下 30:18–20"> <span className="pl pl-1">王は身をめぐらして、イスラエルのすべての会衆を祝福した。その時イスラエルのすべての会衆は立っていた。</span></span>
<span className="v" id="v15" data-v="15" data-xref="ルカによる福音書 1:68; 歴代志上 29:20; 歴代志上 29:10"> <span className="pl pl-1">彼は言った、「イスラエルの神、主はほむべきかな。主はその口をもってわたしの父ダビデに約束されたことを、その手をもってなし遂げられた。主は言われた、</span></span>
<span className="v" id="v16" data-v="16" data-xref="サムエル記上 16:1; 列王紀上 8:29; サムエル記下 7:4–8"> <span className="pl pl-1">『わが民イスラエルをエジプトから導き出した日から、わたしはわたしの名を置くべき宮を建てるために、イスラエルのもろもろの部族のうちから、どの町をも選んだことがなかった。ただダビデを選んで、わが民イスラエルの上に立たせた』と。</span></span>
<span className="v" id="v17" data-v="17" data-xref="サムエル記下 7:2–3; 歴代志上 22:7; 歴代志上 28:2"> <span className="pl pl-1">イスラエルの神、主の名のために宮を建てることは、わたしの父ダビデの心にあった。</span></span>
<span className="v" id="v18" data-v="18" data-xref="歴代志下 6:7–9; コリント人への第二の手紙 8:12"> <span className="pl pl-1">しかし主はわたしの父ダビデに言われた、『わたしの名のために宮を建てることはあなたの心にあった。あなたの心にこの事のあったのは結構である。</span></span>
<span className="v" id="v19" data-v="19" data-xref="サムエル記下 7:5; 歴代志上 22:8–10; 歴代志上 28:6"> <span className="pl pl-1">けれどもあなたはその宮を建ててはならない。あなたの身から出るあなたの子がわたしの名のために宮を建てるであろう』と。</span></span>
<span className="v" id="v20" data-v="20" data-xref="歴代志上 28:5–6; ピリピ人への手紙 1:6; 列王紀上 8:15"> <span className="pl pl-1">そして主はその言われた言葉を行われた。すなわちわたしは父ダビデに代って立ち、主が言われたように、イスラエルの位に座し、イスラエルの神、主の名のために宮を建てた。</span></span>
<span className="v" id="v21" data-v="21" data-xref="列王紀上 8:9; 申命記 31:26; 列王紀上 8:5–6"> <span className="pl pl-1">わたしはまたそこに主の契約を納めた箱のために一つの場所を設けた。その契約は主がわれわれの先祖をエジプトの地から導き出された時に、彼らと結ばれたものである」。</span></span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="エズラ記 9:5; 列王紀上 8:54; 出エジプト記 9:33"> ソロモンはイスラエルの全会衆の前で、主の祭壇の前に立ち、手を天に伸べて、</span>
<span className="v" id="v23" data-v="23" data-xref="サムエル記下 7:22; 申命記 7:9; ダニエル書 9:4"> 言った、「イスラエルの神、主よ、上の天にも、下の地にも、あなたのような神はありません。あなたは契約を守られ、心をつくしてあなたの前に歩むあなたのしもべらに、いつくしみを施し、</span>
<span className="v" id="v24" data-v="24" data-xref="サムエル記下 7:16; 列王紀上 8:15; サムエル記下 7:12"> あなたのしもべであるわたしの父ダビデに約束されたことを守られました。あなたが口をもって約束されたことを、手をもってなし遂げられたことは、今日見るとおりであります。</span>
<span className="v" id="v25" data-v="25" data-xref="列王紀上 2:4; 列王紀上 9:4–6; エレミヤ書 33:17–26"> それゆえ、イスラエルの神、主よ、あなたのしもべであるわたしの父ダビデに、あなたが約束して『おまえがわたしの前に歩んだように、おまえの子孫が、その道を慎んで、わたしの前に歩むならば、おまえにはイスラエルの位に座する人が、わたしの前に欠けることはないであろう』と言われたことを、ダビデのために守ってください。</span>
<span className="v" id="v26" data-v="26" data-xref="サムエル記下 7:25–29; イザヤ書 41:17; サムエル記上 1:17"> イスラエルの神よ、どうぞ、あなたのしもべであるわたしの父ダビデに言われた言葉を確認してください。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="歴代志下 2:6; イザヤ書 66:1; エレミヤ書 23:24"> しかし神は、はたして地上に住まわれるでしょうか。見よ、天も、いと高き天もあなたをいれることはできません。ましてわたしの建てたこの宮はなおさらです。</span>
<span className="v" id="v28" data-v="28" data-xref="詩篇 88:1–2; 詩篇 5:1; ルカによる福音書 18:1"> しかしわが神、主よ、しもべの祈と願いを顧みて、しもべがきょう、あなたの前にささげる叫びと祈をお聞きください。</span>
<span className="v" id="v29" data-v="29" data-xref="歴代志下 6:20; 列王紀上 8:16; 歴代志下 7:15–16"> あなたが『わたしの名をそこに置く』と言われた所、すなわち、この宮に向かって夜昼あなたの目をお開きください。しもべがこの所に向かって祈る祈をお聞きください。</span>
<span className="v" id="v30" data-v="30" data-xref="列王紀上 8:39; 列王紀上 8:34; 列王紀上 8:36"> しもべと、あなたの民イスラエルがこの所に向かって祈る時に、その願いをお聞きください。あなたのすみかである天で聞き、聞いておゆるしください。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="出エジプト記 22:8–11; 歴代志下 6:22–23; レビ記 5:1"> もし人がその隣り人に対して罪を犯し、誓いをすることを求められる時、来てこの宮であなたの祭壇の前に誓うならば、</span>
<span className="v" id="v32" data-v="32" data-xref="申命記 25:1; イザヤ書 3:10–11; ローマ人への手紙 2:6–10"> あなたは天で聞いて行い、あなたのしもべらをさばき、悪人を罰して、そのおこないの報いをそのこうべに帰し、義人を義として、その義にしたがって、その人に報いてください。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="レビ記 26:17; 申命記 28:25; ヨナ書 3:10"> もしあなたの民イスラエルが、あなたに対して罪を犯したために敵の前に敗れた時、あなたに立ち返って、あなたの名をあがめ、この宮であなたに祈り願うならば、</span>
<span className="v" id="v34" data-v="34" data-xref="エレミヤ書 31:4–9; ダニエル書 9:12; 創世記 13:15"> あなたは天にあって聞き、あなたの民イスラエルの罪をゆるして、あなたが彼らの先祖に賜わった地に彼らを帰らせてください。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="レビ記 26:19; 申命記 11:17; 列王紀上 8:33"> もし彼らがあなたに罪を犯したために、天が閉ざされて雨がなく、あなたが彼らを苦しめられる時、彼らがこの所に向かって祈り、あなたの名をあがめ、その罪を離れるならば、</span>
<span className="v" id="v36" data-v="36" data-xref="詩篇 27:11; サムエル記上 12:23; エレミヤ書 6:16"> あなたは天で聞き、あなたのしもべ、あなたの民イスラエルの罪をゆるし、彼らに歩むべき良い道を教えて、あなたが、あなたの民に嗣業として与えられた地に雨を降らせてください。</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="申命記 28:21–22; レビ記 26:16; 歴代志下 20:9"> もし国にききんがあるか、もしくは疫病、立ち枯れ、腐り穂、いなご、青虫があるか、もしくは敵のために町の中に攻め囲まれることがあるか、どんな災害、どんな病気があっても、</span>
<span className="v" id="v38" data-v="38" data-xref="詩篇 73:21–22; 列王紀上 8:22; ピリピ人への手紙 4:6"> もし、だれでも、あなたの民イスラエルがみな、おのおのその心の悩みを知って、この宮に向かい、手を伸べるならば、どんな祈、どんな願いでも、</span>
<span className="v" id="v39" data-v="39" data-xref="歴代志上 28:9; エレミヤ書 17:10; 使徒行伝 1:24"> あなたは、あなたのすみかである天で聞いてゆるし、かつ行い、おのおのの人に、その心を知っておられるゆえ、そのすべての道にしたがって報いてください。ただ、あなただけ、すべての人の心を知っておられるからです。</span>
<span className="v" id="v40" data-v="40" data-xref="詩篇 130:4; ヨハネの黙示録 19:5; 申命記 6:2"> あなたが、われわれの先祖に賜わった地に、彼らの生きながらえる日の間、常にあなたを恐れさせてください。</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="列王紀上 10:1–2; 使徒行伝 8:27–40; 出エジプト記 18:8–12"> またあなたの民イスラエルの者でなく、あなたの名のために遠い国から来る異邦人が、</span>
<span className="v" id="v42" data-v="42" data-xref="申命記 3:24; 列王紀下 17:36; 出エジプト記 3:13–16"> ――それは彼らがあなたの大いなる名と、強い手と、伸べた腕とについて聞き及ぶからです、――もしきて、この宮に向かって祈るならば、</span>
<span className="v" id="v43" data-v="43" data-xref="詩篇 102:15; サムエル記上 17:46; 詩篇 22:27"> あなたは、あなたのすみかである天で聞き、すべて異邦人があなたに呼び求めることをかなえさせてください。そうすれば、地のすべての民は、あなたの民イスラエルのように、あなたの名を知り、あなたを恐れ、またわたしが建てたこの宮があなたの名によって呼ばれることを知るにいたるでしょう。</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="歴代志下 6:34; 詩篇 78:67–69; 列王紀上 8:16"> あなたの民が敵と戦うために、あなたがつかわされる道を通って出て行くとき、もし彼らがあなたの選ばれた町、わたしがあなたの名のために建てた宮の方に向かって、主に祈るならば、</span>
<span className="v" id="v45" data-v="45" data-xref="創世記 18:25; 詩篇 9:4; エレミヤ書 5:28"> あなたは天で、彼らの祈と願いを聞いて彼らをお助けください。</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="伝道の書 7:20; 箴言 20:9; ヨハネの第一の手紙 1:8–10"> 彼らがあなたに対して罪を犯すことがあって、――人は罪を犯さない者はないのです、――あなたが彼らを怒り、彼らを敵にわたし、敵が彼らを捕虜として遠近にかかわらず、敵の地に引いて行く時、</span>
<span className="v" id="v47" data-v="47" data-xref="詩篇 106:6; ネヘミヤ書 1:6–11; ネヘミヤ書 9:26–30"> もし彼らが捕われていった地で、みずから省みて悔い、自分を捕えていった者の地で、あなたに願い、『われわれは罪を犯しました、そむいて悪を行いました』と言い、</span>
<span className="v" id="v48" data-v="48" data-xref="ダニエル書 6:10; エレミヤ書 29:12–14; 申命記 4:29"> 自分を捕えていった敵の地で、心をつくし、精神をつくしてあなたに立ち返り、あなたが彼らの先祖に与えられた地、あなたが選ばれた町、わたしがあなたの名のために建てた宮の方に向かって、あなたに祈るならば、</span>
<span className="v" id="v49" data-v="49" data-xref="列王紀下 19:19; 列王紀上 8:45; ゼカリヤ書 1:15–16"> あなたのすみかである天で、彼らの祈と願いを聞いて、彼らを助け、</span>
<span className="v" id="v50" data-v="50" data-xref="詩篇 106:46; 歴代志下 30:9; 使徒行伝 7:10"> あなたの民が、あなたに対して犯した罪と、あなたに対して行ったすべてのあやまちをゆるし、彼らを捕えていった者の前で、彼らにあわれみを得させ、その人々が彼らをあわれむようにしてください。</span>
<span className="v" id="v51" data-v="51" data-xref="ネヘミヤ書 1:10; エレミヤ書 11:4; 申命記 4:20"> （彼らはあなたがエジプトから、鉄のかまどの中から導き出されたあなたの民、あなたの嗣業であるからです）。</span>
<span className="v" id="v52" data-v="52" data-xref="詩篇 145:18; 列王紀上 8:29; 詩篇 86:5"> どうぞ、しもべの願いと、あなたの民イスラエルの願いに、あなたの目を開き、すべてあなたに呼び求める時、彼らの願いをお聞きください。</span>
<span className="v" id="v53" data-v="53" data-xref="出エジプト記 19:5–6; 申命記 14:2; 申命記 32:9"> あなたは彼らを地のすべての民のうちから区別して、あなたの嗣業とされたからです。主なる神よ、あなたがわれわれの先祖をエジプトから導き出された時、モーセによって言われたとおりです」。</span>
</div>
<div className="bp">
<span className="v" id="v54" data-v="54" data-xref="歴代志下 7:1; 歴代志下 6:12–13; ルカによる福音書 22:45"> ソロモンはこの祈と願いをことごとく主にささげ終ると、それまで天に向かって手を伸べ、ひざまずいていた主の祭壇の前から立ちあがり、</span>
<span className="v" id="v55" data-v="55" data-xref="列王紀上 8:14; サムエル記下 6:18; 民数記 6:23–26"> 立って大声でイスラエルの全会衆を祝福して言った、</span>
<span className="v" id="v56" data-v="56" data-xref="ヨシュア記 23:14–15; ヨシュア記 21:44–45; ルカによる福音書 21:33"> 「主はほむべきかな。主はすべて約束されたように、その民イスラエルに太平を賜わった。そのしもべモーセによって仰せられたその良き約束は皆一つもたがわなかった。</span>
<span className="v" id="v57" data-v="57" data-xref="ヨシュア記 1:5; 申命記 31:6; 申命記 31:8"> われわれの神がわれわれの先祖と共におられたように、われわれと共におられるように。われわれを離れず、またわれわれを見捨てられないように。</span>
<span className="v" id="v58" data-v="58" data-xref="詩篇 119:36; エゼキエル書 36:26–27; エレミヤ書 31:33"> われわれの心を主に傾けて、主のすべての道に歩ませ、われわれの先祖に命じられた戒めと定めと、おきてとを守らせられるように。</span>
<span className="v" id="v59" data-v="59" data-xref="詩篇 141:2; ヨハネによる福音書 17:9; ヨハネによる福音書 17:20–24"> 主の前にわたしが述べたこれらの願いの言葉が、日夜われわれの神、主に覚えられるように。そして主は日々の事に、しもべを助け、主の民イスラエルを助けられるように。</span>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀上 12:32–33; 列王紀下 23:17; テサロニケ人への第一の手紙 4:15"> 見よ、神の人が主の命によってユダからベテルにきた。その時ヤラベアムは祭壇の上に立って香をたいていた。</span>
<span className="v" id="v2" data-v="2" data-xref="エゼキエル書 36:1; 列王紀下 23:15–18; 列王紀下 22:1–2"> 神の人は祭壇にむかい主の命によって呼ばわって言った、「祭壇よ、祭壇よ、主はこう仰せられる、『見よ、ダビデの家にひとりの子が生れる。その名をヨシヤという。彼はおまえの上で香をたく高き所の祭司らを、おまえの上にささげる。また人の骨がおまえの上で焼かれる』」。</span>
<span className="v" id="v3" data-v="3" data-xref="コリント人への第一の手紙 1:22; 出エジプト記 4:3–5; 士師記 6:17"> その日、彼はまた一つのしるしを示して言った、「主の言われたしるしはこれである、『見よ、祭壇は裂け、その上にある灰はこぼれ出るであろう』」。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネの黙示録 11:5; 歴代志下 18:25–27; ルカによる福音書 6:10"> ヤラベアム王は、神の人がベテルにある祭壇にむかって呼ばわる言葉を聞いた時、祭壇から手を伸ばして、「彼を捕えよ」と言ったが、彼にむかって伸ばした手が枯れて、ひっ込めることができなかった。</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀上 13:3; エレミヤ書 28:16–17; 申命記 18:22"> そして神の人が主の言葉をもって示したしるしのように祭壇は裂け、灰は祭壇からこぼれ出た。</span>
<span className="v" id="v6" data-v="6" data-xref="出エジプト記 9:28; 使徒行伝 8:24; 出エジプト記 10:17"> 王は神の人に言った、「あなたの神、主に願い、わたしのために祈って、わたしの手をもとに返らせてください」。神の人が主に願ったので、王の手はもとに返って、前のようになった。</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀下 5:15; サムエル記上 9:7–8; 士師記 13:15"> そこで王は神の人に言った、「わたしと一緒に家にきて、身を休めなさい。あなたに謝礼をさしあげましょう」。</span>
<span className="v" id="v8" data-v="8" data-xref="民数記 24:13; 民数記 22:18; マルコによる福音書 6:23"> 神の人は王に言った、「たとい、あなたの家の半ばをくださっても、わたしはあなたと一緒にまいりません。またこの所では、パンも食べず水も飲みません。</span>
<span className="v" id="v9" data-v="9" data-xref="ヨハネによる福音書 13:17; 申命記 13:13–18; ローマ人への手紙 16:17"> 主の言葉によってわたしは、『パンを食べてはならない、水を飲んではならない。また来た道から帰ってはならない』と命じられているからです」。</span>
<span className="v" id="v10" data-v="10"> こうして彼はほかの道を行き、ベテルに来た道からは帰らなかった。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="列王紀下 23:18; 列王紀上 13:20–21; 民数記 24:2"> さてベテルにひとりの年老いた預言者が住んでいたが、そのむすこたちがきて、その日神の人がベテルでした事どもを彼に話した。また神の人が王に言った言葉をもその父に話した。</span>
<span className="v" id="v12" data-v="12"> 父が彼らに「その人はどの道を行ったか」と聞いたので、むすこたちはユダからきた神の人の行った道を父に示した。</span>
<span className="v" id="v13" data-v="13" data-xref="士師記 10:4; サムエル記下 19:26; 士師記 5:10"> 父はむすこたちに言った、「わたしのためにろばにくらを置きなさい」。彼らがろばにくらを置いたので、彼はそれに乗り、</span>
<span className="v" id="v14" data-v="14" data-xref="ピリピ人への手紙 4:12–13; コリント人への第二の手紙 11:27; コリント人への第一の手紙 4:11–12"> 神の人のあとを追って行き、かしの木の下にすわっているのを見て、その人に言った、「あなたはユダからこられた神の人ですか」。その人は言った、「そうです」。</span>
<span className="v" id="v15" data-v="15"> そこで彼はその人に言った、「わたしと一緒に家にきてパンを食べてください」。</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀上 13:8–9; マタイによる福音書 16:23; 民数記 22:19"> その人は言った、「わたしはあなたと一緒に引き返すことはできません。あなたと一緒に行くことはできません。またわたしはこの所であなたと一緒にパンも食べず水も飲みません。</span>
<span className="v" id="v17" data-v="17" data-xref="列王紀上 20:35; テサロニケ人への第一の手紙 4:15; 列王紀上 13:1"> 主の言葉によってわたしは、『その所でパンを食べてはならない、水を飲んではならない。また来た道から帰ってはならない』と言われているからです」。</span>
<span className="v" id="v18" data-v="18" data-xref="ヨハネの第一の手紙 4:1; マタイによる福音書 7:15; 民数記 22:35"> 彼はその人に言った、「わたしもあなたと同じ預言者ですが、天の使が主の命によってわたしに告げて、『その人を一緒に家につれ帰り、パンを食べさせ、水を飲ませよ』と言いました」。これは彼がその人を欺いたのである。</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 13:1; 創世記 3:6; 使徒行伝 4:19"> そこでその人は彼と一緒に引き返し、その家でパンを食べ、水を飲んだ。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="マタイによる福音書 7:22; 民数記 24:4; 民数記 24:16–24"> 彼らが食卓についていたとき、主の言葉が、その人をつれて帰った預言者に臨んだので、</span>
<span className="v" id="v21" data-v="21" data-xref="列王紀上 13:17; サムエル記上 13:13–14; サムエル記上 4:18"> 彼はユダからきた神の人にむかい呼ばわって言った、「主はこう仰せられます、『あなたが主の言葉にそむき、あなたの神、主がお命じになった命令を守らず、</span>
<span className="v" id="v22" data-v="22" data-xref="イザヤ書 14:18–20; 列王紀上 14:13; エレミヤ書 22:18–19"> 引き返して、主があなたに、パンを食べてはならない、水を飲んではならない、と言われた場所でパンを食べ、水を飲んだゆえ、あなたの死体はあなたの先祖の墓に行かないであろう』」。</span>
<span className="v" id="v23" data-v="23"> そしてその人がパンを食べ、水を飲んだ後、彼はその人のため、すなわちつれ帰った預言者のためにろばにくらを置いた。</span>
<span className="v" id="v24" data-v="24" data-xref="列王紀上 20:36; 列王紀下 2:24; 箴言 26:13"> こうしてその人は立ち去ったが、道でししが彼に会って彼を殺した。そしてその死体は道に捨てられ、ろばはそのかたわらに立ち、ししもまた死体のかたわらに立っていた。</span>
<span className="v" id="v25" data-v="25" data-xref="列王紀上 13:11"> 人々はそこをとおって、道に捨てられている死体と、死体のかたわらに立っているししを見て、かの老預言者の住んでいる町にきてそれを話した。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="エゼキエル書 9:6; 箴言 11:31; 詩篇 119:120"> その人を道からつれて帰った預言者はそれを聞いて言った、「それは主の言葉にそむいた神の人だ。主が彼に言われた言葉のように、主は彼をししにわたされ、ししが彼を裂き殺したのだ」。</span>
<span className="v" id="v27" data-v="27"> そしてむすこたちに言った、「わたしのためにろばにくらを置きなさい」。彼らがくらを置いたので、</span>
<span className="v" id="v28" data-v="28" data-xref="列王紀上 17:6; 詩篇 148:7–8; ダニエル書 6:22–24"> 彼は行って、死体が道に捨てられ、ろばとししが死体のかたわらに立っているのを見た。ししはその死体を食べず、ろばも裂いていなかった。</span>
<span className="v" id="v29" data-v="29"> そこで預言者は神の人の死体を取りあげ、それをろばに載せて町に持ち帰り、悲しんでそれを葬った。</span>
<span className="v" id="v30" data-v="30" data-xref="エレミヤ書 22:18; 使徒行伝 8:2; 列王紀上 14:13"> すなわちその死体を自分の墓に納め、皆これがために「ああ、わが兄弟よ」と言って悲しんだ。</span>
<span className="v" id="v31" data-v="31" data-xref="列王紀下 23:17–18; 民数記 23:10; ルカによる福音書 16:22–23"> 彼はそれを葬って後、むすこたちに言った、「わたしが死んだ時は、神の人を葬った墓に葬り、わたしの骨を彼の骨のかたわらに納めなさい。</span>
<span className="v" id="v32" data-v="32" data-xref="列王紀上 16:24; 列王紀上 13:2; 列王紀上 12:31"> 彼が主の命によって、ベテルにある祭壇にむかい、またサマリヤの町々にある高き所のすべての家にむかって呼ばわった言葉は必ず成就するのです」。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="歴代志下 11:15; 歴代志下 13:9; 民数記 17:12–13"> この事の後も、ヤラベアムはその悪い道を離れて立ち返ることをせず、また一般の民を、高き所の祭司に任命した。すなわち、だれでも好む者は、それを立てて高き所の祭司とした。</span>
<span className="v" id="v34" data-v="34" data-xref="列王紀上 14:10; 列王紀上 15:29–30; 列王紀上 12:30"> この事はヤラベアムの家の罪となって、ついにこれを地のおもてから断ち滅ぼすようになった。</span>
</div>

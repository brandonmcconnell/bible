<span className="v" id="v1" data-v="1" data-xref="歴代志下 7:11–6; 列王紀上 9:19; 列王紀上 7:51"> ソロモンが主の宮と王の宮殿およびソロモンが建てようと望んだすべてのものを建て終った時、</span>
<span className="v" id="v2" data-v="2" data-xref="列王紀上 3:5; 歴代志下 7:12; 列王紀上 11:9"> 主はかつてギベオンでソロモンに現れられたように再び現れて、</span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 10:17; ヨハネの第一の手紙 5:14; 列王紀下 20:5"> 彼に言われた、「あなたが、わたしの前に願った祈と願いとを聞いた。わたしはあなたが建てたこの宮を聖別して、わたしの名を永久にそこに置く。わたしの目と、わたしの心は常にそこにあるであろう。</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀上 15:5; 列王紀上 3:14; 列王紀上 11:6"> あなたがもし、あなたの父ダビデが歩んだように全き心をもって正しくわたしの前に歩み、すべてわたしが命じたようにおこなって、わたしの定めと、おきてとを守るならば、</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀上 2:4; 列王紀上 6:12; サムエル記下 7:16"> わたしは、あなたの父ダビデに約束して『イスラエルの王位にのぼる人があなたに欠けることはないであろう』と言ったように、あなたのイスラエルに王たる位をながく確保するであろう。</span>
<span className="v" id="v6" data-v="6" data-xref="サムエル記下 7:14–16; 歴代志上 28:9; 歴代志下 15:2"> しかし、あなたがた、またはあなたがたの子孫がそむいてわたしに従わず、わたしがあなたがたの前に置いた戒めと定めとを守らず、他の神々に行って、それに仕え、それを拝むならば、</span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 44:14; エレミヤ書 24:9; 申命記 4:26"> わたしはイスラエルを、わたしが与えた地のおもてから断つであろう。またわたしの名のために聖別した宮をわたしの前から投げすてるであろう。そしてイスラエルはもろもろの民のうちにことわざとなり、笑い草となるであろう。</span>
<span className="v" id="v8" data-v="8" data-xref="申命記 29:24–26; エレミヤ書 22:8–9; 歴代志下 7:21"> かつ、この宮は荒塚となり、そのかたわらを過ぎる者は皆驚き、うそぶいて『なにゆえ、主はこの地と、この宮とにこのようにされたのか』と言うであろう。</span>
<span className="v" id="v9" data-v="9" data-xref="エレミヤ書 2:19; エレミヤ書 5:19; 申命記 29:25–28"> その時人々は答えて『彼らは自分の先祖をエジプトの地から導き出した彼らの神、主を捨てて、他の神々につき従い、それを拝み、それに仕えたために、主はこのすべての災を彼らの上に下したのである』と言うであろう」。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="列王紀上 6:37–1; 歴代志下 8:1–18; 列王紀上 9:1"> ソロモンは二十年を経て二つの家すなわち主の宮と王の宮殿とを建て終った時、</span>
<span className="v" id="v11" data-v="11" data-xref="歴代志下 8:2; 歴代志下 2:16; 歴代志下 2:8–10"> ツロの王ヒラムがソロモンの望みに任せて香柏と、いとすぎと、金とを供給したので、ソロモン王はガリラヤの地の町二十をヒラムに与えた。</span>
<span className="v" id="v12" data-v="12" data-xref="民数記 22:34; 士師記 14:3"> しかしヒラムがツロから来て、ソロモンが彼に与えた町々を見たとき、それらは彼の気にいらなかったので、</span>
<span className="v" id="v13" data-v="13" data-xref="ヨシュア記 19:27; アモス書 1:9; 列王紀上 5:1–2"> 彼は、「兄弟よ、あなたがくださったこれらの町々は、いったいなんですか」と言った。それで、そこは今日までカブルの地と呼ばれている。</span>
<span className="v" id="v14" data-v="14" data-xref="列王紀上 9:11; 列王紀上 10:10; 列王紀上 9:28"> ヒラムはかつて金百二十タラントを王に贈った。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="ヨシュア記 17:11; 列王紀上 9:24; サムエル記下 5:9"> ソロモン王が強制的に労働者を徴募したのはこうである。すなわち主の宮と自分の宮殿と、ミロとエルサレムの城壁と、ハゾルとメギドとゲゼルを建てるためであった。</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀上 3:1; 列王紀上 9:24; 列王紀上 7:8"> （エジプトの王パロはかつて上ってきて、ゲゼルを取り、火でこれを焼き、その町に住んでいたカナンびとを殺し、これをソロモンの妻である自分の娘に与えて婚姻の贈り物としたので、</span>
<span className="v" id="v17" data-v="17" data-xref="ヨシュア記 16:3; ヨシュア記 21:22; 歴代志下 8:4–18"> ソロモンはそのゲゼルを建て直した）。また下ベテホロンと、</span>
<span className="v" id="v18" data-v="18" data-xref="ヨシュア記 19:44; 歴代志下 8:4"> バアラテとユダの国の荒野にあるタマル、</span>
<span className="v" id="v19" data-v="19" data-xref="列王紀上 9:1; 伝道の書 6:9; 出エジプト記 1:11"> およびソロモンが持っていた倉庫の町々、戦車の町々、騎兵の町々ならびにソロモンがエルサレム、レバノンおよびそのすべての領地において建てようと望んだものをことごとく建てるためであった。</span>
<span className="v" id="v20" data-v="20" data-xref="出エジプト記 23:23; 創世記 15:19–21; 申命記 7:1–3"> すべてイスラエルの子孫でないアモリびと、ヘテびと、ペリジびと、ヒビびと、エブスびとの残った者、</span>
<span className="v" id="v21" data-v="21" data-xref="ヨシュア記 17:12; 士師記 1:21; ヨシュア記 15:63"> その地にあって彼らのあとに残った子孫すなわちイスラエルの人々の滅ぼしつくすことのできなかった者を、ソロモンは強制的に奴隷として徴募をおこない、今日に至っている。</span>
<span className="v" id="v22" data-v="22" data-xref="レビ記 25:39; 列王紀上 4:1–27; サムエル記上 8:11–12"> しかしイスラエルの人々をソロモンはひとりも奴隷としなかった。彼らは軍人、また彼の役人、司令官、指揮官、戦車隊長、騎兵隊長であったからである。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="列王紀上 5:16; 歴代志下 8:10; 歴代志下 2:18"> ソロモンの工事を監督する上役の官吏は五百五十人であって、工事に働く民を治めた。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="列王紀上 7:8; サムエル記下 5:9; 歴代志下 32:5"> パロの娘はダビデの町から上って、ソロモンが彼女のために建てた家に住んだ。その時ソロモンはミロを建てた。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="歴代志下 8:12–13; 歴代志下 8:16; 出エジプト記 23:14–17"> ソロモンは主のために築いた祭壇の上に年に三度燔祭と酬恩祭をささげ、また主の前に香をたいた。こうしてソロモンは宮を完成した。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="列王紀上 22:48; 民数記 33:35; 申命記 2:8"> ソロモン王はエドムの地、紅海の岸のエラテに近いエジオン・ゲベルで数隻の船を造った。</span>
<span className="v" id="v27" data-v="27" data-xref="列王紀上 10:11; 列王紀上 5:6; 列王紀上 5:9"> ヒラムは海の事を知っている船員であるそのしもべをソロモンのしもべと共にその船でつかわした。</span>
<span className="v" id="v28" data-v="28" data-xref="歴代志下 8:18; 歴代志上 29:4; 列王紀上 10:11"> 彼らはオフルへ行って、そこから金四百二十タラントを取って、ソロモン王の所にもってきた。</span>

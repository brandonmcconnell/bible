<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歴代志下 3:1–2; 使徒行伝 7:47; 歴代志上 29:19"> イスラエルの人々がエジプトの地を出て後四百八十年、ソロモンがイスラエルの王となって第四年のジフの月すなわち二月に、ソロモンは主のために宮を建てることを始めた。</span>
<span className="v" id="v2" data-v="2" data-xref="エゼキエル書 40:1–41; エゼキエル書 41:1–15; ヨハネの黙示録 21:16–17"> ソロモン王が主のために建てた宮は長さ六十キュビト、幅二十キュビト、高さ三十キュビトであった。</span>
<span className="v" id="v3" data-v="3" data-xref="歴代志上 28:11; 歴代志下 3:3–4; エゼキエル書 41:15"> 宮の拝殿の前の廊は宮の幅にしたがって長さ二十キュビト、その幅は宮の前で十キュビトであった。</span>
<span className="v" id="v4" data-v="4" data-xref="エゼキエル書 40:16; エゼキエル書 41:26; エゼキエル書 41:16"> 彼は宮に、内側の広い枠の窓を造った。</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀上 6:16; 列王紀上 6:19–21; 列王紀上 6:31"> また宮の壁につけて周囲に脇屋を設け、宮の壁すなわち拝殿と本殿の壁の周囲に建てめぐらし、宮の周囲に脇間があるようにした。</span>
<span className="v" id="v6" data-v="6"> 下の脇間は広さ五キュビト、中の広さ六キュビト、第三のは広さ七キュビトであった。宮の外側には壁に段を造って、梁を宮の壁の中に差し込まないようにした。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="申命記 27:5–6; ペテロの第一の手紙 2:5; 出エジプト記 20:25"> 宮は建てる時に、石切り場で切り整えた石をもって造ったので、建てている間は宮のうちには、つちも、おのも、その他の鉄器もその音が聞えなかった。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="エゼキエル書 41:6–7"> 下の脇間の入口は宮の右側にあり、回り階段によって中の脇間に、中の脇間から第三の脇間にのぼった。</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀上 6:14; 列王紀上 6:38"> こうして彼は宮を建て終り、香柏のたるきと板をもって宮の天井を造った。</span>
<span className="v" id="v10" data-v="10"> また宮につけて、おのおの高さ五キュビトの脇間のある脇屋を建てめぐらし、香柏の材木をもって宮に接続させた。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11"> そこで主の言葉がソロモンに臨んだ、</span>
<span className="v" id="v12" data-v="12" data-xref="歴代志上 22:10; コロサイ人への手紙 1:23; 列王紀上 3:14"> 「あなたが建てるこの宮については、もしあなたがわたしの定めに歩み、おきてを行い、すべての戒めを守り、それに従って歩むならば、わたしはあなたの父ダビデに約束したことを成就する。</span>
<span className="v" id="v13" data-v="13" data-xref="申命記 31:6; 出エジプト記 25:8; レビ記 26:11"> そしてわたしはイスラエルの人々のうちに住み、わたしの民イスラエルを捨てることはない」。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="列王紀上 6:9; 列王紀上 6:38; 使徒行伝 7:47–48"> こうしてソロモンは宮を建て終った。</span>
<span className="v" id="v15" data-v="15" data-xref="列王紀上 7:7"> 彼は香柏の板をもって宮の壁の内側を張った。すなわち宮の床から天井のたるきまで香柏の板で張った。また、いとすぎの板をもって宮の床を張った。</span>
<span className="v" id="v16" data-v="16" data-xref="歴代志下 3:8; 列王紀上 8:6; ヘブル人への手紙 9:3"> また宮の奥に二十キュビトの室を床から天井のたるきまで香柏の板をもって造った。すなわち宮の内に至聖所としての本堂を造った。</span>
<span className="v" id="v17" data-v="17"> 宮すなわち本殿の前にある拝殿は長さ四十キュビトであった。</span>
<span className="v" id="v18" data-v="18" data-xref="列王紀上 7:24"> 宮の内側の香柏の板は、ひさごの形と、咲いた花を浮彫りにしたもので、みな香柏の板で、石は見えなかった。</span>
<span className="v" id="v19" data-v="19" data-xref="列王紀上 8:6–10; 詩篇 28:2; 列王紀上 6:5"> そして主の契約の箱を置くために、宮の内の奥に本殿を設けた。</span>
<span className="v" id="v20" data-v="20" data-xref="列王紀上 6:2–3; 列王紀上 6:22; 列王紀上 7:48"> 本殿は長さ二十キュビト、幅二十キュビト、高さ二十キュビトであって、純金でこれをおおった。また香柏の祭壇を造った。</span>
<span className="v" id="v21" data-v="21" data-xref="歴代志下 3:7–9; 歴代志下 3:14–16; 列王紀上 6:5"> ソロモンは純金をもって宮の内側をおおい、本殿の前に金の鎖をもって隔てを造り、金をもってこれをおおった。</span>
<span className="v" id="v22" data-v="22" data-xref="出エジプト記 30:1; 出エジプト記 30:3; 歴代志下 3:7–14"> また金をもって残らず宮をおおい、ついに宮を飾ることをことごとく終えた。また本殿に属する祭壇をことごとく金でおおった。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="出エジプト記 37:7–9; 創世記 3:24; ペテロの第一の手紙 1:12"> 本殿のうちにオリブの木をもって二つのケルビムを造った。その高さはおのおの十キュビト。</span>
<span className="v" id="v24" data-v="24"> そのケルブの一つの翼の長さは五キュビト、またそのケルブの他の翼の長さも五キュビトであった。一つの翼の端から他の翼の端までは十キュビトあった。</span>
<span className="v" id="v25" data-v="25"> 他のケルブも十キュビトであって、二つのケルビムは同じ寸法、同じ形であった。</span>
<span className="v" id="v26" data-v="26"> このケルブの高さは十キュビト、かのケルブの高さも同じであった。</span>
<span className="v" id="v27" data-v="27" data-xref="出エジプト記 37:9; 出エジプト記 25:20; 歴代志下 5:8"> ソロモンは宮のうちの奥にケルビムをすえた。ケルビムの翼を伸ばしたところ、このケルブの翼はこの壁に達し、かのケルブの翼はかの壁に達し、他の二つの翼は宮の中で互に触れ合った。</span>
<span className="v" id="v28" data-v="28"> 彼は金をもってそのケルビムをおおった。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="列王紀上 6:32; 詩篇 92:12–15; 歴代志下 4:2–5"> 彼は宮の周囲の壁に、内外の室とも皆ケルビムと、しゅろの木と、咲いた花の形の彫り物を刻み、</span>
<span className="v" id="v30" data-v="30" data-xref="ヨハネの黙示録 21:18–21; イザヤ書 60:17; イザヤ書 54:11–12"> 宮の床は、内外の室とも金でおおった。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="ヘブル人への手紙 10:19–20; エペソ人への手紙 3:18; ヨハネによる福音書 14:6"> 本殿の入口にはオリブの木のとびらを造った。そのとびらの上のかまちと脇柱とで五辺形をなしていた。</span>
<span className="v" id="v32" data-v="32" data-xref="列王紀上 6:18; 列王紀上 6:29"> その二つのとびらもオリブの木であって、ソロモンはその上にケルビムと、しゅろの木と、咲いた花の形を刻み、金をもっておおった。すなわちケルビムと、しゅろの木の上に金を着せた。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33"> こうしてソロモンはまた拝殿の入口のためにオリブの木で四角の形に脇柱を造った。</span>
<span className="v" id="v34" data-v="34" data-xref="エゼキエル書 41:23–25; 列王紀上 5:8"> その二つのとびらはいとすぎであって、一つのとびらは二つにたたむ折り戸であり、他のとびらも二つにたたむ折り戸であった。</span>
<span className="v" id="v35" data-v="35"> ソロモンはその上にケルビムと、しゅろの木と、咲いた花を刻み、金をもって彫り物の上を形どおりにおおった。</span>
<span className="v" id="v36" data-v="36" data-xref="列王紀上 7:12; 歴代志下 7:7; 出エジプト記 27:9–19"> また切り石三かさねと、香柏の角材ひとかさねとをもって内庭を造った。</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="列王紀上 6:1; 歴代志下 3:2"> 第四年のジフの月に主の宮の基をすえ、</span>
<span className="v" id="v38" data-v="38" data-xref="エズラ記 6:14–15; 列王紀上 7:1; ゼカリヤ書 4:9"> 第十一年のブルの月すなわち八月に、宮のすべての部分が設計どおりに完成した。ソロモンはこれを建てるのに七年を要した。</span>
</div>
</div>

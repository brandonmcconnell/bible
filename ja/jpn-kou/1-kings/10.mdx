<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マタイによる福音書 12:42; ルカによる福音書 11:31; 歴代志下 9:1–12"> シバの女王は主の名にかかわるソロモンの名声を聞いたので、難問をもってソロモンを試みようとたずねてきた。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行伝 25:23; 詩篇 4:4; ヨブ記 4:2"> 彼女は多くの従者を連れ、香料と、たくさんの金と宝石とをらくだに負わせてエルサレムにきた。彼女はソロモンのもとにきて、その心にあることをことごとく彼に告げたが、</span>
<span className="v" id="v3" data-v="3" data-xref="箴言 1:5–6; マタイによる福音書 13:11; 列王紀上 10:1"> ソロモンはそのすべての問に答えた。王が知らないで彼女に説明のできないことは一つもなかった。</span>
<span className="v" id="v4" data-v="4" data-xref="マタイによる福音書 12:42; 列王紀上 3:28; 歴代志下 9:3–4"> シバの女王はソロモンのもろもろの知恵と、ソロモンが建てた宮殿、</span>
<span className="v" id="v5" data-v="5" data-xref="歴代志上 26:16; 列王紀上 4:22–23; 列王紀下 16:18"> その食卓の食物と、列座の家来たちと、その侍臣たちの伺候ぶり、彼らの服装と、彼の給仕たち、および彼が主の宮でささげる燔祭を見て、全く気を奪われてしまった。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="歴代志下 9:5–6"> 彼女は王に言った、「わたしが国であなたの事と、あなたの知恵について聞いたことは真実でありました。</span>
<span className="v" id="v7" data-v="7" data-xref="コリント人への第一の手紙 2:9; ヨハネによる福音書 20:25–29; ヨハネの第一の手紙 3:2"> しかしわたしがきて、目に見るまでは、その言葉を信じませんでしたが、今見るとその半分もわたしは知らされていなかったのです。あなたの知恵と繁栄はわたしが聞いたうわさにまさっています。</span>
<span className="v" id="v8" data-v="8" data-xref="箴言 8:34; 箴言 10:21; ルカによる福音書 11:31"> あなたの奥方たちはさいわいです。常にあなたの前に立って、あなたの知恵を聞く家来たちはさいわいです。</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 72:2; 列王紀上 5:7; サムエル記下 8:15"> あなたの神、主はほむべきかな。主はあなたを喜び、あなたをイスラエルの位にのぼらせられました。主は永久にイスラエルを愛せられるゆえ、あなたを王として公道と正義とを行わせられるのです」。</span>
<span className="v" id="v10" data-v="10" data-xref="列王紀上 10:2; マタイによる福音書 2:11; 列王紀上 9:14"> そして彼女は金百二十タラントおよび多くの香料と宝石とを王に贈った。シバの女王がソロモン王に贈ったような多くの香料は再びこなかった。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="列王紀上 9:27–28; 歴代志下 8:18; 詩篇 45:9"> オフルから金を載せてきたヒラムの船は、またオフルからたくさんのびゃくだんの木と宝石とを運んできたので、</span>
<span className="v" id="v12" data-v="12" data-xref="歴代志上 25:1–31; 詩篇 150:3–5; ヨハネの黙示録 14:2–3"> 王はびゃくだんの木をもって主の宮と王の宮殿のために壁柱を造り、また歌う人々のために琴と立琴とを造った。このようなびゃくだんの木は、かつてきたこともなく、また今日まで見たこともなかった。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="詩篇 37:4; マタイによる福音書 15:28; 詩篇 20:4"> ソロモン王はその豊かなのにしたがってシバの女王に贈り物をしたほかに、彼女の望みにまかせて、すべてその求める物を贈った。そして彼女はその家来たちと共に自分の国へ帰っていった。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="歴代志下 9:13–28; 列王紀上 9:28"> さて一年の間にソロモンのところに、はいってきた金の目方は六百六十六タラントであった。</span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 72:10; 歴代志上 9:24; イザヤ書 21:13"> そのほかに貿易商および商人の取引、ならびにアラビヤの諸王と国の代官たちからも、はいってきた。</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀上 14:26–28; 歴代志下 12:9–10; 歴代志下 9:15–16"> ソロモン王は延金の大盾二百を造った。その大盾にはおのおの六百シケルの金を用いた。</span>
<span className="v" id="v17" data-v="17" data-xref="列王紀上 7:2; 列王紀上 14:26"> また延金の小盾三百を造った。その小盾にはおのおの三ミナの金を用いた。王はこれらをレバノンの森の家に置いた。</span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 45:8; 列王紀上 10:22; ヨハネの黙示録 20:11"> 王はまた大きな象牙の玉座を造り、純金をもってこれをおおった。</span>
<span className="v" id="v19" data-v="19"> その玉座に六つの段があり、玉座の後に子牛の頭があり、座席の両側にひじ掛けがあって、ひじ掛けのわきに二つのししが立っていた。</span>
<span className="v" id="v20" data-v="20" data-xref="民数記 24:9; 創世記 49:9; 民数記 23:24"> また六つの段のおのおのの両側に十二のししが立っていた。このような物はどこの国でも造られたことがなかった。</span>
<span className="v" id="v21" data-v="21" data-xref="列王紀上 10:17; 列王紀上 7:2; 歴代志下 9:20–22"> ソロモン王が飲むときに用いた器は皆金であった。またレバノンの森の家の器も皆純金であって、銀のものはなかった。銀はソロモンの世には顧みられなかった。</span>
<span className="v" id="v22" data-v="22" data-xref="列王紀上 22:48; 創世記 10:4; 歴代志下 20:36–37"> これは王が海にタルシシの船隊を所有して、ヒラムの船隊と一緒に航海させ、タルシシの船隊に三年に一度、金、銀、象牙、さる、くじゃくを載せてこさせたからである。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="列王紀上 3:12–13; コロサイ人への手紙 2:2–3; 列王紀上 4:29–34"> このようにソロモン王は富も知恵も、地のすべての王にまさっていたので、</span>
<span className="v" id="v24" data-v="24" data-xref="列王紀上 3:12; ヤコブの手紙 1:5; 列王紀上 3:28"> 全地の人々は神がソロモンの心に授けられた知恵を聞こうとしてソロモンに謁見を求めた。</span>
<span className="v" id="v25" data-v="25" data-xref="ヨブ記 42:11; 詩篇 72:10; 詩篇 72:15"> 人々はおのおの贈り物を携えてきた。すなわち銀の器、金の器、衣服、没薬、香料、馬、騾馬など年々定まっていた。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="歴代志下 9:25; 列王紀上 4:26; 申命記 17:16"> ソロモンは戦車と騎兵とを集めたが、戦車一千四百両、騎兵一万二千あった。ソロモンはこれを戦車の町とエルサレムの王のもとに置いた。</span>
<span className="v" id="v27" data-v="27" data-xref="歴代志下 1:15–17; 申命記 17:17; 歴代志下 9:27"> 王はエルサレムで、銀を石のように用い、香柏を平地にあるいちじく桑のように多く用いた。</span>
<span className="v" id="v28" data-v="28" data-xref="申命記 17:16; 歴代志下 9:28; イザヤ書 31:1–3"> ソロモンが馬を輸入したのはエジプトとクエからであった。すなわち王の貿易商はクエから代価を払って受け取ってきた。</span>
<span className="v" id="v29" data-v="29" data-xref="ヨシュア記 1:4; 列王紀下 7:6–7; マラキ書 1:1"> エジプトから輸入される戦車一両は銀六百シケル、馬は百五十シケルであった。このようにして、これらのものが王の貿易商によって、ヘテびとのすべての王たちおよびスリヤの王たちに輸出された。</span>
</div>

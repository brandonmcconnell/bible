<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出エジプト記 20:5; 列王紀上 13:33–34; サムエル記上 31:2"> そのころヤラベアムの子アビヤが病気になったので、</span>
<span className="v" id="v2" data-v="2" data-xref="サムエル記上 28:8; 列王紀上 11:29–38; サムエル記下 14:2"> ヤラベアムは妻に言った、「立って姿を変え、ヤラベアムの妻であることの知られないようにしてシロへ行きなさい。わたしがこの民の王となることを、わたしに告げた預言者アヒヤがそこにいます。</span>
<span className="v" id="v3" data-v="3" data-xref="サムエル記上 9:7–8; 列王紀上 13:7; 列王紀下 4:42"> パン十個と菓子数個および、みつ一びんを携えて彼のところへ行きなさい。彼はこの子がどうなるかをあなたに告げるでしょう」。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="列王紀上 11:29; サムエル記上 3:2; サムエル記上 4:15"> ヤラベアムの妻はそのようにして、立ってシロへ行き、アヒヤの家に着いたが、アヒヤは年老いたため、目がかすんで見ることができなかった。</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀下 6:8–12; 箴言 21:30; 列王紀下 4:27"> しかし主はアヒヤに言われた、「ヤラベアムの妻が子供の事をあなたに尋ねるために来る。子供は病気だ。あなたは彼女にこうこう言わなければならない」。<br />彼女は来るとき、他人を装っていた。</span>
<span className="v" id="v6" data-v="6" data-xref="ダニエル書 5:17–28; 使徒行伝 5:9–10; ルカによる福音書 20:20–23"> しかし彼女が戸口にはいってきたとき、アヒヤはその足音を聞いて言った、「ヤラベアムの妻よ、はいりなさい。なぜ、他人を装うのですか。わたしはあなたにきびしい事を告げるよう、命じられています。</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀上 16:2; サムエル記下 12:7–8; サムエル記上 15:16"> 行ってヤラベアムに言いなさい、『イスラエルの神、主はこう仰せられる、「わたしはあなたを民のうちからあげ、わたしの民イスラエルの上に立てて君とし、</span>
<span className="v" id="v8" data-v="8" data-xref="列王紀上 15:5; 列王紀上 11:33–38; 歴代志下 28:1"> 国をダビデの家から裂き離して、それをあなたに与えたのに、あなたはわたしのしもべダビデが、わたしの命令を守って一心にわたしに従い、ただわたしの目にかなった事のみを行ったようにではなく、</span>
<span className="v" id="v9" data-v="9" data-xref="エゼキエル書 23:35; ネヘミヤ書 9:26; 詩篇 50:17"> あなたよりも先にいたすべての者にまさって悪をなし、行って自分のために他の神々と鋳た像を造り、わたしを怒らせ、わたしをうしろに捨て去った。</span>
<span className="v" id="v10" data-v="10" data-xref="申命記 32:36; 列王紀上 21:21; 列王紀下 14:26"> それゆえ、見よ、わたしはヤラベアムの家に災を下し、ヤラベアムに属する男は、イスラエルについて、つながれた者も、自由な者もことごとく断ち、人があくたを残りなく焼きつくすように、ヤラベアムの家を全く断ち滅ぼすであろう。</span>
<span className="v" id="v11" data-v="11" data-xref="列王紀上 16:4; エレミヤ書 15:3; 列王紀上 21:23–24"> ヤラベアムに属する者は、町で死ぬ者を犬が食べ、野で死ぬ者を空の鳥が食べるであろう。主がこれを言われるのである」』。</span>
<span className="v" id="v12" data-v="12" data-xref="列王紀上 14:3; 列王紀上 14:16–17; 列王紀下 1:6"> あなたは立って、家へ帰りなさい。あなたの足が町にはいる時に、子どもは死にます。</span>
<span className="v" id="v13" data-v="13" data-xref="歴代志下 19:3; 歴代志下 12:12; ヨブ記 19:28"> そしてイスラエルは皆、彼のために悲しんで彼を葬るでしょう。ヤラベアムに属する者は、ただ彼だけ墓に葬られるでしょう。ヤラベアムの家のうちで、彼はイスラエルの神、主にむかって良い思いをいだいていたからです。</span>
<span className="v" id="v14" data-v="14" data-xref="列王紀上 15:27–29; エゼキエル書 7:2–7; エゼキエル書 12:22–28"> 主はイスラエルの上にひとりの王を起されます。彼はその日ヤラベアムの家を断つでしょう。</span>
<span className="v" id="v15" data-v="15" data-xref="ヨシュア記 23:15–16; 詩篇 52:5; 列王紀下 15:29"> その後主はイスラエルを撃って、水に揺らぐ葦のようにし、イスラエルを、その先祖に賜わったこの良い地から抜き去って、ユフラテ川の向こうに散らされるでしょう。彼らがアシラ像を造って主を怒らせたからです。</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀上 15:34; 列王紀上 16:2; 列王紀上 13:34"> 主はヤラベアムの罪のゆえに、すなわち彼がみずから犯し、またイスラエルに犯させたその罪のゆえにイスラエルを捨てられるでしょう」。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="列王紀上 15:33; 列王紀上 16:15; 列王紀上 16:23"> ヤラベアムの妻は立って去り、テルザへ行って、家の敷居をまたいだ時、子どもは死んだ。</span>
<span className="v" id="v18" data-v="18" data-xref="列王紀上 14:13"> イスラエルは皆彼を葬り、彼のために悲しんだ。主がそのしもべ預言者アヒヤによって言われた言葉のとおりである。</span>
<span className="v" id="v19" data-v="19" data-xref="歴代志下 13:2–20; 歴代志上 27:24; 列王紀上 16:20"> ヤラベアムのその他の事績、彼がどのように戦い、どのように世を治めたかは、イスラエルの王の歴代志の書にしるされている。</span>
<span className="v" id="v20" data-v="20" data-xref="ヨブ記 14:12; 詩篇 3:5; 列王紀上 11:43"> ヤラベアムが世を治めた日は二十二年であった。彼はその先祖と共に眠って、その子ナダブが代って王となった。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="歴代志下 12:13; 列王紀上 11:36; 列王紀上 14:31"> ソロモンの子レハベアムはユダで世を治めた。レハベアムは王となったとき四十一歳であったが、主がその名を置くために、イスラエルのすべての部族のうちから選ばれた町エルサレムで、十七年世を治めた。その母の名はナアマといってアンモンびとであった。</span>
<span className="v" id="v22" data-v="22" data-xref="歴代志下 12:1; コリント人への第一の手紙 10:22; 詩篇 78:58"> ユダの人々はその先祖の行ったすべての事にまさって、主の目の前に悪を行い、その犯した罪によって主の怒りを引き起した。</span>
<span className="v" id="v23" data-v="23" data-xref="申命記 12:2; イザヤ書 57:5; 列王紀下 17:9–10"> 彼らもすべての高い丘の上と、すべての青木の下に、高き所と石の柱とアシラ像とを建てたからである。</span>
<span className="v" id="v24" data-v="24" data-xref="申命記 23:17; コリント人への第一の手紙 6:9; 列王紀上 15:12"> その国にはまた神殿男娼たちがいた。彼らは主がイスラエルの人々の前から追い払われた国民のすべての憎むべき事をならい行った。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="列王紀上 11:40; 歴代志下 12:2–4; 歴代志下 12:9"> レハベアムの王の第五年にエジプトの王シシャクがエルサレムに攻め上ってきて、</span>
<span className="v" id="v26" data-v="26" data-xref="列王紀上 15:18; 歴代志下 9:15–16; 列王紀上 7:51"> 主の宮の宝物と、王の宮殿の宝物を奪い去った。彼はそれをことごとく奪い去り、またソロモンの造った金の盾をみな奪い去った。</span>
<span className="v" id="v27" data-v="27" data-xref="サムエル記上 8:11; サムエル記上 22:17; 列王紀上 18:46"> レハベアムはその代りに青銅の盾を造って、王の宮殿の門を守る侍衛長の手にわたした。</span>
<span className="v" id="v28" data-v="28" data-xref="歴代志下 12:11"> 王が主の宮にはいるごとに、侍衛はそれを携え、また、それを侍衛のへやへ持ち帰った。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="列王紀上 22:45; 列王紀上 15:23; 列王紀上 14:19"> レハベアムのその他の事績と、彼がしたすべての事は、ユダの王の歴代志の書にしるされているではないか。</span>
<span className="v" id="v30" data-v="30" data-xref="列王紀上 12:24; 列王紀上 12:21; 列王紀上 15:6–7"> レハベアムとヤラベアムの間には絶えず戦争があった。</span>
<span className="v" id="v31" data-v="31" data-xref="歴代志下 12:16; マタイによる福音書 1:7; 列王紀上 15:3"> レハベアムはその先祖と共に眠って先祖と共にダビデの町に葬られた。その母の名はナアマといってアンモンびとであった。その子アビヤムが代って王となった。</span>
</div>

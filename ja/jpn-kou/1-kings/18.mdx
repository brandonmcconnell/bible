<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ルカによる福音書 4:25; ヤコブの手紙 5:17; 申命記 28:12"> 多くの日を経て、三年目に主の言葉がエリヤに臨んだ、「行って、あなたの身をアハブに示しなさい。わたしは雨を地に降らせる」。</span>
<span className="v" id="v2" data-v="2" data-xref="列王紀下 6:25; 箴言 28:1; レビ記 26:26"> エリヤはその身をアハブに示そうとして行った。その時、サマリヤにききんが激しかった。</span>
<span className="v" id="v3" data-v="3" data-xref="ネヘミヤ書 7:2; 列王紀上 16:9; マタイによる福音書 10:28"> アハブは家づかさオバデヤを召した。（オバデヤは深く主を恐れる人で、</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀上 18:13; マタイによる福音書 10:40–42; ヨハネの黙示録 17:4–6"> イゼベルが主の預言者を断ち滅ぼした時、オバデヤは百人の預言者を救い出して五十人ずつほら穴に隠し、パンと水をもって彼らを養った）。</span>
<span className="v" id="v5" data-v="5" data-xref="エレミヤ書 14:5–6; ヨエル書 1:18; ヨエル書 2:22"> アハブはオバデヤに言った、「国中のすべての水の源と、すべての川に行ってみるがよい。馬と騾馬を生かしておくための草があるかもしれない。そうすれば、われわれは家畜をいくぶんでも失わずにすむであろう」。</span>
<span className="v" id="v6" data-v="6" data-xref="エレミヤ書 14:3"> 彼らは行き巡る地をふたりで分け、アハブはひとりでこの道を行き、オバデヤはひとりで他の道を行った。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="列王紀下 1:6–8; 創世記 44:20; イザヤ書 60:14"> オバデヤが道を進んでいた時、エリヤが彼に会った。彼はエリヤを認めて伏して言った、「わが主エリヤよ、あなたはここにおられるのですか」。</span>
<span className="v" id="v8" data-v="8" data-xref="ローマ人への手紙 13:7; 列王紀上 18:3; ペテロの第一の手紙 2:17–18"> エリヤは彼に言った、「そうです。行って、あなたの主人に、エリヤはここにいると告げなさい」。</span>
<span className="v" id="v9" data-v="9" data-xref="出エジプト記 5:21; 列王紀上 18:12; 列王紀上 17:18"> 彼は言った、「わたしにどんな罪があって、あなたはしもべをアハブの手にわたして殺そうとされるのですか。</span>
<span className="v" id="v10" data-v="10" data-xref="列王紀上 17:1; 列王紀上 1:29; 列王紀上 18:15"> あなたの神、主は生きておられます。わたしの主人があなたを尋ねるために、人をつかわさない民はなく、国もありません。そしてエリヤはいないと言う時は、その国、その民に、あなたが見つからないという誓いをさせるのです。</span>
<span className="v" id="v11" data-v="11" data-xref="列王紀上 18:8; 列王紀上 18:14"> あなたは今『行って、エリヤはここにいると主人に告げよ』と言われます。</span>
<span className="v" id="v12" data-v="12" data-xref="列王紀下 2:16; 使徒行伝 8:39; エゼキエル書 8:3"> しかしわたしがあなたを離れて行くと、主の霊はあなたを、わたしの知らない所へ連れて行くでしょう。わたしが行ってアハブに告げ、彼があなたを見つけることができなければ、彼はわたしを殺すでしょう。しかし、しもべは幼い時から主を恐れている者です。</span>
<span className="v" id="v13" data-v="13" data-xref="列王紀上 18:4; マタイによる福音書 25:35; 詩篇 18:21–24"> イゼベルが主の預言者を殺した時に、わたしがした事、すなわち、わたしが主の預言者のうち百人を五十人ずつほら穴に隠して、パンと水をもって養った事を、わが主は聞かれませんでしたか。</span>
<span className="v" id="v14" data-v="14" data-xref="マタイによる福音書 10:28"> ところが今あなたは『行って、エリヤはここにいると主人に告げよ』と言われます。そのようなことをすれば彼はわたしを殺すでしょう」。</span>
<span className="v" id="v15" data-v="15" data-xref="列王紀上 17:1; 列王紀上 18:10; ルカによる福音書 2:13–14"> エリヤは言った、「わたしの仕える万軍の主は生きておられる。わたしは必ず、きょう、わたしの身を彼に示すであろう」。</span>
<span className="v" id="v16" data-v="16"> オバデヤは行ってアハブに会い、彼に告げたので、アハブはエリヤに会おうとして行った。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="ヨシュア記 7:25; 列王紀上 21:20; 使徒行伝 16:20"> アハブはエリヤを見たとき、彼に言った、「イスラエルを悩ます者よ、あなたはここにいるのですか」。</span>
<span className="v" id="v18" data-v="18" data-xref="歴代志下 15:2; 列王紀上 9:9; エレミヤ書 2:19"> 彼は答えた、「わたしがイスラエルを悩ますのではありません。あなたと、あなたの父の家が悩ましたのです。あなたがたが主の命令を捨て、バアルに従ったためです。</span>
<span className="v" id="v19" data-v="19" data-xref="ヨシュア記 19:26; 列王紀上 16:33; ペテロの第二の手紙 2:1"> それで今、人をつかわしてイスラエルのすべての人およびバアルの預言者四百五十人、ならびにアシラの預言者四百人、イゼベルの食卓で食事する者たちをカルメル山に集めて、わたしの所にこさせなさい」。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="列王紀上 22:9"> そこでアハブはイスラエルのすべての人に人をつかわして、預言者たちをカルメル山に集めた。</span>
<span className="v" id="v21" data-v="21" data-xref="マタイによる福音書 6:24; ヨシュア記 24:15; コリント人への第一の手紙 10:21–22"> そのときエリヤはすべての民に近づいて言った、「あなたがたはいつまで二つのものの間に迷っているのですか。主が神ならばそれに従いなさい。しかしバアルが神ならば、それに従いなさい」。民はひと言も彼に答えなかった。</span>
<span className="v" id="v22" data-v="22" data-xref="列王紀上 19:10; 列王紀上 19:14; テモテヘの第二の手紙 4:3–4"> エリヤは民に言った、「わたしはただひとり残った主の預言者です。しかしバアルの預言者は四百五十人あります。</span>
<span className="v" id="v23" data-v="23"> われわれに二頭の牛をください。そして一頭の牛を彼らに選ばせ、それを切り裂いて、たきぎの上に載せ、それに火をつけずにおかせなさい。わたしも一頭の牛を整え、それをたきぎの上に載せて火をつけずにおきましょう。</span>
<span className="v" id="v24" data-v="24" data-xref="列王紀上 18:38; 歴代志上 21:26; 歴代志下 7:1"> こうしてあなたがたはあなたがたの神の名を呼びなさい。わたしは主の名を呼びましょう。そして火をもって答える神を神としましょう」。民は皆答えて「それがよかろう」と言った。</span>
<span className="v" id="v25" data-v="25"> そこでエリヤはバアルの預言者たちに言った、「あなたがたは大ぜいだから初めに一頭の牛を選んで、それを整え、あなたがたの神の名を呼びなさい。ただし火をつけてはなりません」。</span>
<span className="v" id="v26" data-v="26" data-xref="エレミヤ書 10:5; コリント人への第一の手紙 8:4; マタイによる福音書 6:7"> 彼らは与えられた牛を取って整え、朝から昼までバアルの名を呼んで「バアルよ、答えてください」と言った。しかしなんの声もなく、また答える者もなかったので、彼らは自分たちの造った祭壇のまわりに踊った。</span>
<span className="v" id="v27" data-v="27" data-xref="詩篇 78:65–66; イザヤ書 41:23; 伝道の書 11:9"> 昼になってエリヤは彼らをあざけって言った、「彼は神だから、大声をあげて呼びなさい。彼は考えにふけっているのか、よそへ行ったのか、旅に出たのか、または眠っていて起されなければならないのか」。</span>
<span className="v" id="v28" data-v="28" data-xref="レビ記 19:28; 申命記 14:1; マルコによる福音書 5:5"> そこで彼らは大声に呼ばわり、彼らのならわしに従って、刀とやりで身を傷つけ、血をその身に流すに至った。</span>
<span className="v" id="v29" data-v="29" data-xref="列王紀上 18:26; サムエル記上 18:10; 出エジプト記 29:39"> こうして昼が過ぎても彼らはなお叫び続けて、夕の供え物をささげる時にまで及んだ。しかしなんの声もなく、答える者もなく、また顧みる者もなかった。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="歴代志下 33:16; 列王紀上 19:14; 列王紀上 19:10"> その時エリヤはすべての民にむかって「わたしに近寄りなさい」と言ったので、民は皆彼に近寄った。彼はこわれている主の祭壇を繕った。</span>
<span className="v" id="v31" data-v="31" data-xref="列王紀下 17:34; 創世記 35:10; 創世記 32:28"> そしてエリヤは昔、主の言葉がヤコブに臨んで、「イスラエルをあなたの名とせよ」と言われたヤコブの子らの部族の数にしたがって十二の石を取り、</span>
<span className="v" id="v32" data-v="32" data-xref="コロサイ人への手紙 3:17; 出エジプト記 20:24–25; 士師記 21:4"> その石で主の名によって祭壇を築き、祭壇の周囲に種二セヤをいれるほどの大きさの、みぞを作った。</span>
<span className="v" id="v33" data-v="33" data-xref="創世記 22:9; 士師記 6:20; レビ記 1:6–8"> また、たきぎを並べ、牛を切り裂いてたきぎの上に載せて言った、「四つのかめに水を満たし、それを燔祭とたきぎの上に注げ」。</span>
<span className="v" id="v34" data-v="34" data-xref="コリント人への第二の手紙 8:21; コリント人への第二の手紙 4:2"> また言った、「それを二度せよ」。二度それをすると、また言った、「三度それをせよ」。三度それをした。</span>
<span className="v" id="v35" data-v="35" data-xref="列王紀上 18:32; 列王紀上 18:38"> 水は祭壇の周囲に流れた。またみぞにも水を満たした。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="列王紀上 18:29; 列王紀下 19:19; 出エジプト記 3:6"> 夕の供え物をささげる時になって、預言者エリヤは近寄って言った、「アブラハム、イサク、ヤコブの神、主よ、イスラエルでは、あなたが神であること、わたしがあなたのしもべであって、あなたの言葉に従ってこのすべての事を行ったことを、今日知らせてください。</span>
<span className="v" id="v37" data-v="37" data-xref="ダニエル書 9:17–19; ルカによる福音書 1:16–17; エゼキエル書 36:25–27"> 主よ、わたしに答えてください、わたしに答えてください。主よ、この民にあなたが神であること、またあなたが彼らの心を翻されたのであることを知らせてください」。</span>
<span className="v" id="v38" data-v="38" data-xref="歴代志上 21:26; レビ記 9:24; 歴代志下 7:1"> そのとき主の火が下って燔祭と、たきぎと、石と、ちりとを焼きつくし、またみぞの水をなめつくした。</span>
<span className="v" id="v39" data-v="39" data-xref="列王紀上 18:24; 歴代志下 7:3; 列王紀上 18:21"> 民は皆見て、ひれ伏して言った、「主が神である。主が神である」。</span>
<span className="v" id="v40" data-v="40" data-xref="申命記 18:20; 士師記 4:7; 申命記 13:5"> エリヤは彼らに言った、「バアルの預言者を捕えよ。そのひとりも逃がしてはならない」。そこで彼らを捕えたので、エリヤは彼らをキション川に連れくだって、そこで彼らを殺した。</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="列王紀上 18:1; 伝道の書 9:7; 列王紀上 17:1"> エリヤはアハブに言った、「大雨の音がするから、上って行って、食い飲みしなさい」。</span>
<span className="v" id="v42" data-v="42" data-xref="ルカによる福音書 6:12; ダニエル書 9:7; ヨシュア記 7:6"> アハブは食い飲みするために上っていった。しかしエリヤはカルメルの頂に登り、地に伏して顔をひざの間に入れていたが、</span>
<span className="v" id="v43" data-v="43" data-xref="ハバクク書 2:3; ルカによる福音書 18:7; ルカによる福音書 18:1"> 彼はしもべに言った、「上っていって海の方を見なさい」。彼は上っていって、見て、「何もありません」と言ったので、エリヤは「もう一度行きなさい」と言って七度に及んだ。</span>
<span className="v" id="v44" data-v="44" data-xref="ルカによる福音書 12:54; ヨブ記 8:7; ゼカリヤ書 4:10"> 七度目にしもべは言った、「海から人の手ほどの小さな雲が起っています」。エリヤは言った、「上っていって、『雨にとどめられないように車を整えて下れ』とアハブに言いなさい」。</span>
<span className="v" id="v45" data-v="45" data-xref="列王紀上 18:39–40; ヨシュア記 17:16; 列王紀上 21:1"> すると間もなく、雲と風が起り、空が黒くなって大雨が降ってきた。アハブは車に乗ってエズレルへ行った。</span>
<span className="v" id="v46" data-v="46" data-xref="エゼキエル書 3:14; エゼキエル書 1:3; 列王紀下 9:1"> また主の手がエリヤに臨んだので、彼は腰をからげ、エズレルの入口までアハブの前に走っていった。</span>
</div>

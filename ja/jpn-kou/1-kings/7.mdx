<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀上 9:10; 歴代志下 8:1; 伝道の書 2:4–5"> またソロモンは自分の家を建てたが、十三年かかってその家を全部建て終った。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="列王紀上 10:17; 歴代志下 9:16; 列王紀上 10:21"> 彼はレバノンの森の家を建てた。長さ百キュビト、幅五十キュビト、高さ三十キュビトで、三列の香柏の柱があり、その柱の上に香柏の梁があった。</span>
<span className="v" id="v3" data-v="3" data-xref="列王紀上 6:5"> 四十五本の柱の上にある室は香柏の板でおおった。柱は各列十五本あった。</span>
<span className="v" id="v4" data-v="4" data-xref="エゼキエル書 40:22; エゼキエル書 40:16; 列王紀上 6:4"> また窓わくが三列あって、窓と窓と三段に向かい合っていた。</span>
<span className="v" id="v5" data-v="5"> 戸口と窓はみな四角の枠をもち、窓と窓と三段に向かい合った。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="列王紀上 7:12; エゼキエル書 41:25–26"> また柱の広間を造った。長さ五十キュビト、幅三十キュビトであった。柱の前に一つの広間があり、その玄関に柱とひさしがあった。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="箴言 20:8; 詩篇 122:5; イザヤ書 9:7"> またソロモンはみずから審判をするために玉座の広間、すなわち審判の広間を造った。床からたるきまで香柏をもっておおった。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="歴代志下 8:11; 列王紀上 3:1; 列王紀上 9:24"> ソロモンが住んだ宮殿はその広間のうしろの他の庭にあって、その造作は同じであった。ソロモンはまた彼がめとったパロの娘のために家を建てたが、その広間と同じであった。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="列王紀上 7:10–11; 列王紀上 5:17"> これらはみな内外とも、土台から軒まで、また主の宮の庭から大庭まで、寸法に合わせて切った石、すなわち、のこぎりでひいた高価な石で造られた。</span>
<span className="v" id="v10" data-v="10" data-xref="ヨハネの黙示録 21:19–20; コリント人への第一の手紙 3:10–11; イザヤ書 54:11"> また土台は高価な石、大きな石、すなわち八キュビトの石、十キュビトの石であった。</span>
<span className="v" id="v11" data-v="11" data-xref="エペソ人への手紙 2:20–22; ペテロの第一の手紙 2:5"> その上には寸法に合わせて切った高価な石と香柏とがあった。</span>
<span className="v" id="v12" data-v="12" data-xref="列王紀上 6:36; 列王紀上 7:6; ヨハネによる福音書 10:23"> また大庭の周囲には三かさねの切り石と、一かさねの香柏の角材があった。主の宮の内庭と宮殿の広間の庭の場合と同じである。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="歴代志下 4:11; 歴代志下 2:13–14; 列王紀上 7:40"> ソロモン王は人をつかわしてツロからヒラムを呼んできた。</span>
<span className="v" id="v14" data-v="14" data-xref="歴代志下 2:14; 歴代志下 4:16; 出エジプト記 31:2–6"> 彼はナフタリの部族の寡婦の子であって、その父はツロの人で、青銅の細工人であった。ヒラムは青銅のいろいろな細工をする知恵と悟りと知識に満ちた者であったが、ソロモン王のところにきて、そのすべての細工をした。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="エレミヤ書 52:21; 歴代志下 3:15–17; 列王紀上 7:21"> 彼は青銅の柱二本を鋳た。一本の柱の高さは十八キュビト、そのまわりは綱をもって測ると十二キュビトあり、指四本の厚さで空洞であった。他の柱も同じである。</span>
<span className="v" id="v16" data-v="16" data-xref="出エジプト記 38:19; 歴代志下 4:12–13; 出エジプト記 38:17"> また青銅を溶かして柱頭二つを造り、柱の頂にすえた。その一つの柱頭の高さは五キュビト、他の柱頭の高さも五キュビトであった。</span>
<span className="v" id="v17" data-v="17" data-xref="出エジプト記 28:14; 出エジプト記 28:24–25; 出エジプト記 28:22"> 柱の頂にある柱頭のために鎖に編んだ飾りひもで市松模様の網細工二つを造った。すなわちこの柱頭のために一つ、かの柱頭のために一つを造った。</span>
<span className="v" id="v18" data-v="18" data-xref="出エジプト記 28:14; 出エジプト記 39:15–18; 出エジプト記 28:22"> またざくろを造った。すなわち二並びのざくろを一つの網細工の上のまわりに造って、柱の頂にある柱頭を巻いた。他の柱頭にも同じようにした。</span>
<span className="v" id="v19" data-v="19" data-xref="列王紀上 7:22; 列王紀上 6:32–35; 列王紀上 6:18"> この廊の柱の頂にある柱頭の上に四キュビトのゆりの花の細工があった。</span>
<span className="v" id="v20" data-v="20" data-xref="歴代志下 3:16; 歴代志下 4:13; エレミヤ書 52:22–23"> 二つの柱の上端の丸い突出部の上にある網細工の柱頭の周囲には、おのおの二百のざくろが二並びになっていた。</span>
<span className="v" id="v21" data-v="21" data-xref="歴代志下 3:17; 列王紀上 6:3; 列王紀上 7:12"> この柱を神殿の廊に立てた。すなわち南に柱を立てて、その名をヤキンと名づけ、北に柱を立てて、その名をボアズと名づけた。</span>
<span className="v" id="v22" data-v="22"> その柱の頂にはゆりの花の細工があった。こうしてその柱の造作ができあがった。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="歴代志下 4:2; 列王紀下 25:13; エレミヤ書 52:17"> また海を鋳て造った。縁から縁まで十キュビトであって、周囲は円形をなし、高さ五キュビトで、その周囲は綱をもって測ると三十キュビトであった。</span>
<span className="v" id="v24" data-v="24" data-xref="列王紀上 6:18; 歴代志下 4:3; 出エジプト記 37:17–22"> その縁の下には三十キュビトの周囲をめぐるひさごがあって、海の周囲を囲んでいた。そのひさごは二並びで、海を鋳る時に鋳たものである。</span>
<span className="v" id="v25" data-v="25" data-xref="エレミヤ書 52:20; 歴代志下 4:4–5; マタイによる福音書 28:19"> その海は十二の牛の上に置かれ、その三つは北に向かい、三つは西に向かい、三つは南に向かい、三つは東に向かっていた。海はその上に置かれ、牛のうしろは皆内に向かっていた。</span>
<span className="v" id="v26" data-v="26" data-xref="歴代志下 4:5; 列王紀上 7:38; 列王紀上 6:18"> 海の厚さは手の幅で、その縁は杯の縁のように、ゆりの花に似せて造られた。海には水が二千バテはいった。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="歴代志下 4:14; 列王紀下 25:13; エレミヤ書 52:17"> また青銅の台を十個造った。台は長さ四キュビト、幅四キュビト、高さ三キュビトであった。</span>
<span className="v" id="v28" data-v="28"> その台の構造は次のとおりである。台には鏡板があり、鏡板は枠の中にあった。</span>
<span className="v" id="v29" data-v="29" data-xref="ホセア書 5:14; エゼキエル書 10:14; 出エジプト記 37:7"> 枠の中にある鏡板には、ししと牛とケルビムとがあり、また、ししと牛の上と下にある枠の斜面には花飾りが細工してあった。</span>
<span className="v" id="v30" data-v="30" data-xref="エゼキエル書 10:10–13; エゼキエル書 3:13; エゼキエル書 1:15–21"> また台にはおのおの四つの青銅の車輪と、青銅の車軸があり、その四すみには洗盤のささえがあった。そのささえは、おのおの花飾りのかたわらに鋳て造りつけてあった。</span>
<span className="v" id="v31" data-v="31"> その口は一キュビト上に突き出て、台の頂の内にあり、その口は丸く、台座のように造られ、深さ一キュビト半であった。またその口には彫り物があった。その鏡板は四角で、丸くなかった。</span>
<span className="v" id="v32" data-v="32"> 四つの車輪は鏡板の下にあり、車軸は台に取り付けてあり、車輪の高さはおのおの一キュビト半であった。</span>
<span className="v" id="v33" data-v="33" data-xref="エゼキエル書 1:18; エゼキエル書 1:16"> 車輪の構造は戦車の車輪の構造と同じで、その車軸と縁と輻と轂とはみな鋳物であった。</span>
<span className="v" id="v34" data-v="34"> おのおのの台の四すみに四つのささえがあり、そのささえは台の一部をなしていた。</span>
<span className="v" id="v35" data-v="35"> 台の上には高さ半キュビトの丸い帯輪があった。そして台の上にあるその支柱と鏡板とはその一部をなしていた。</span>
<span className="v" id="v36" data-v="36" data-xref="列王紀上 7:29; 列王紀上 6:29; エゼキエル書 41:18–20"> その支柱の表面と鏡板にはそれぞれの場所に、ケルビムと、ししと、しゅろを刻み、またその周囲に花飾りを施した。</span>
<span className="v" id="v37" data-v="37"> このようにして十個の台を造った。それはみな同じ鋳方、同じ寸法、同じ形であった。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="出エジプト記 40:11–12; ゼカリヤ書 13:1; ヨハネの第一の手紙 1:7"> また青銅の洗盤を十個造った。洗盤はおのおの四十バテの水がはいり、洗盤はおのおの四キュビトであった。十個の台の上にはおのおの一つずつの洗盤があった。</span>
<span className="v" id="v39" data-v="39" data-xref="歴代志下 4:10; 歴代志下 4:6"> その台の五個を宮の南の方に、五個を宮の北の方に置き、宮の東南の方に海をすえた。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="歴代志下 4:11–16; 出エジプト記 24:6; 出エジプト記 39:32–43"> ヒラムはまたつぼと十能と鉢を造った。こうしてヒラムはソロモン王のために主の宮のすべての細工をなし終えた。</span>
<span className="v" id="v41" data-v="41" data-xref="列王紀上 7:15–22; 歴代志下 4:12"> すなわち二本の柱と、その柱の頂にある柱頭の二つの玉と、柱の頂にある柱頭の二つの玉をおおう二つの網細工と、</span>
<span className="v" id="v42" data-v="42" data-xref="列王紀上 7:20"> その二つの網細工のためのざくろ四百。このざくろは一つの網細工に、二並びにつけて、柱の頂にある柱頭の二つの玉を巻いた。</span>
<span className="v" id="v43" data-v="43"> また十個の台と、その台の上の十個の洗盤と、</span>
<span className="v" id="v44" data-v="44" data-xref="列王紀上 7:23; 列王紀上 7:25"> 一つの海と、その海の下の十二の牛とであった。</span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="出エジプト記 27:3; 出エジプト記 38:3; 歴代志下 4:16"> さてつぼと十能と鉢、すなわちヒラムがソロモン王のために造った主の宮のこれらの器はみな光のある青銅であった。</span>
<span className="v" id="v46" data-v="46" data-xref="ヨシュア記 3:16; 歴代志下 4:17; 創世記 33:17"> 王はヨルダンの低地で、スコテとザレタンの間の粘土の地でこれらを鋳た。</span>
<span className="v" id="v47" data-v="47" data-xref="歴代志上 22:14; 歴代志上 22:3; 歴代志下 4:18"> ソロモンはその器が非常に多かったので、皆それをはからずにおいた。その青銅の重さは、はかり得なかった。</span>
</div>
<div className="bp">
<span className="v" id="v48" data-v="48" data-xref="出エジプト記 37:10–16; 歴代志下 4:8; 出エジプト記 39:36"> またソロモンは主の宮にあるもろもろの器を造った。すなわち金の祭壇と、供えのパンを載せる金の机、</span>
<span className="v" id="v49" data-v="49" data-xref="歴代志下 4:7; 歴代志下 4:20; ゼカリヤ書 4:11–14"> および純金の燭台。この燭台は本殿の前に、五つは南に、五つは北にあった。また金の花と、ともしび皿と、心かきと、</span>
<span className="v" id="v50" data-v="50" data-xref="出エジプト記 25:29; 歴代志下 4:21–22; 出エジプト記 27:3"> 純金の皿と、心切りばさみと、鉢と、香の杯と、心取り皿と、至聖所である宮の奥のとびらのためおよび、宮の拝殿のとびらのために、金のひじつぼを造った。</span>
</div>
<div className="bp">
<span className="v" id="v51" data-v="51" data-xref="歴代志下 5:1; サムエル記下 8:7–11; 歴代志上 28:11–18"> こうしてソロモン王が主の宮のために造るすべての細工は終った。そしてソロモンは父ダビデがささげた物、すなわち金銀および器物を携え入り、主の宮の宝蔵の中にたくわえた。</span>
</div>
</div>

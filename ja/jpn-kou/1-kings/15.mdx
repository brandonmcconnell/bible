<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀上 14:31; 歴代志下 13:1–22"> ネバテの子ヤラベアム王の第十八年にアビヤムがユダの王となり、</span>
<span className="v" id="v2" data-v="2" data-xref="歴代志下 13:2; 歴代志下 11:20–22; 列王紀上 15:13"> エルサレムで三年世を治めた。その母の名はマアカといって、アブサロムの娘であった。</span>
<span className="v" id="v3" data-v="3" data-xref="列王紀上 11:4; 詩篇 119:80; 列王紀上 3:14"> 彼はその父が先に行ったもろもろの罪をおこない、その心は父ダビデの心のようにその神、主に対して全く真実ではなかった。</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀上 11:36; 歴代志下 21:7; イザヤ書 37:35"> それにもかかわらず、その神、主はダビデのために、エルサレムにおいて彼に一つのともしびを与え、その子を彼のあとに立てて、エルサレムを固められた。</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀上 14:8; サムエル記下 11:15–17; 列王紀上 15:3"> それはダビデがヘテびとウリヤの事のほか、一生の間、主の目にかなう事を行い、主が命じられたすべての事に、そむかなかったからである。</span>
<span className="v" id="v6" data-v="6" data-xref="列王紀上 14:30"> レハベアムとヤラベアムの間には一生の間、戦争があった。</span>
<span className="v" id="v7" data-v="7" data-xref="歴代志下 13:2–22; 列王紀上 14:29"> アビヤムのその他の行為と、彼がしたすべての事は、ユダの王の歴代志の書にしるされているではないか。アビヤムとヤラベアムの間にも戦争があった。</span>
<span className="v" id="v8" data-v="8" data-xref="歴代志下 14:1; 列王紀上 14:31; マタイによる福音書 1:7–8"> アビヤムはその先祖と共に眠って、ダビデの町に葬られ、その子アサが代って王となった。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9"> イスラエルの王ヤラベアムの第二十年にアサはユダの王となり、</span>
<span className="v" id="v10" data-v="10" data-xref="列王紀上 15:2; 列王紀上 15:13; 歴代志下 13:2"> エルサレムで四十一年世を治めた。その母の名はマアカといってアブサロムの娘であった。</span>
<span className="v" id="v11" data-v="11" data-xref="歴代志下 14:2; 歴代志下 15:17; 列王紀上 15:3"> アサはその父ダビデがしたように主の目にかなう事をし、</span>
<span className="v" id="v12" data-v="12" data-xref="列王紀上 22:46; 列王紀上 14:23–24; 歴代志下 14:2–5"> 神殿男娼を国から追い出し、先祖たちの造ったもろもろの偶像を除いた。</span>
<span className="v" id="v13" data-v="13" data-xref="出エジプト記 32:20; 申命記 7:5; ゼカリヤ書 13:3"> 彼はまたその母マアカが、アシラのために憎むべき像を造らせたので、彼女を太后の位から退けた。そしてアサはその憎むべき像を切り倒してキデロンの谷で焼き捨てた。</span>
<span className="v" id="v14" data-v="14" data-xref="列王紀上 22:43; 列王紀上 8:61; 列王紀上 15:3"> ただし高き所は除かなかった。けれどもアサの心は一生の間、主に対して全く真実であった。</span>
<span className="v" id="v15" data-v="15" data-xref="列王紀上 7:51; 歴代志下 14:13; 歴代志下 15:18"> 彼は父の献納した物と自分の献納した物、金銀および器物を主の宮に携え入れた。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="列王紀上 15:32; 列王紀上 14:30; 歴代志下 16:1–6"> アサとイスラエルの王バアシャの間には一生の間、戦争があった。</span>
<span className="v" id="v17" data-v="17" data-xref="列王紀上 12:27; 歴代志下 16:1–6; ヨシュア記 18:25"> イスラエルの王バアシャはユダに攻め上り、ユダの王アサの所に、だれをも出入りさせないためにラマを築いた。</span>
<span className="v" id="v18" data-v="18" data-xref="列王紀上 14:26; 列王紀下 12:18; 列王紀上 11:23–24"> そこでアサは主の宮の宝蔵と、王の宮殿の宝蔵に残っている金銀をことごとく取って、これを家来たちの手にわたし、そしてアサ王は彼らをダマスコに住んでいるスリヤの王、ヘジョンの子タブリモンの子であるベネハダデにつかわして言わせた、</span>
<span className="v" id="v19" data-v="19" data-xref="ローマ人への手紙 1:31; 歴代志下 16:7; ローマ人への手紙 3:8"> 「わたしの父とあなたの父との間に結ばれていたように、わたしとあなたの間に同盟を結びましょう。わたしはあなたに金銀の贈り物をさしあげます。行って、あなたとイスラエルの王バアシャとの同盟を破棄し、彼をわたしの所から撤退させてください」。</span>
<span className="v" id="v20" data-v="20" data-xref="列王紀下 15:29; 士師記 18:29; ヨシュア記 11:2"> ベネハダデはアサ王の言うことを聞き、自分の軍勢の長たちをつかわしてイスラエルの町々を攻め、イヨンとダンとアベル・ベテ・マアカおよびキンネレテの全地と、ナフタリの全地を撃った。</span>
<span className="v" id="v21" data-v="21" data-xref="列王紀上 14:17; 列王紀上 16:15–18; 歴代志下 16:5"> バアシャはこれを聞き、ラマを築くことをやめて、テルザにとどまった。</span>
<span className="v" id="v22" data-v="22" data-xref="ヨシュア記 21:17; ヨシュア記 18:24; ヨシュア記 18:26"> そこでアサ王はユダ全国に布告を発した。ひとりも免れる者はなかった。すなわちバアシャがラマを築くために用いた石と材木を運びこさせ、アサ王はそれを用いて、ベニヤミンのゲバとミヅパを築いた。</span>
<span className="v" id="v23" data-v="23" data-xref="歴代志下 16:11–14; 列王紀上 14:29–31; 列王紀上 15:7–8"> アサのその他の事績とそのすべての勲功と、彼がしたすべての事および彼が建てた町々は、ユダの王の歴代志の書にしるされているではないか。彼は老年になって足を病んだ。</span>
<span className="v" id="v24" data-v="24" data-xref="マタイによる福音書 1:8; 列王紀上 22:41–43; 歴代志下 17:1–9"> アサはその先祖と共に眠って、父ダビデの町に先祖と共に葬られ、その子ヨシャパテが代って王となった。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="列王紀上 14:20; 列王紀上 14:12"> ユダの王アサの第二年にヤラベアムの子ナダブがイスラエルの王となって、二年イスラエルを治めた。</span>
<span className="v" id="v26" data-v="26" data-xref="列王紀上 14:16; 列王紀上 15:34; 列王紀上 15:30"> 彼は主の目の前に悪を行い、その父の道に歩み、父がイスラエルに犯させた罪をおこなった。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="ヨシュア記 19:44; ヨシュア記 21:23; 列王紀上 14:14"> イッサカルの家のアヒヤの子バアシャは彼に対してむほんを企て、ペリシテびとに属するギベトンで彼を撃った。これはナダブとイスラエルが皆ギベトンを囲んでいたからである。</span>
<span className="v" id="v28" data-v="28" data-xref="申命記 32:35"> こうしてユダの王アサの第三年にバアシャは彼を殺し、彼に代って王となった。</span>
<span className="v" id="v29" data-v="29" data-xref="列王紀上 14:9–16; 列王紀下 19:25; 列王紀下 10:10–11"> 彼は王となるとすぐヤラベアムの全家を撃ち、息のある者をひとりもヤラベアムの家に残さず、ことごとく滅ぼした。主がそのしもべシロびとアヒヤによって言われた言葉のとおりであって、</span>
<span className="v" id="v30" data-v="30" data-xref="列王紀上 15:26; 列王紀上 14:22; 列王紀上 14:9–16"> これはヤラベアムがみずから犯し、またイスラエルに犯させた罪のため、また彼がイスラエルの神、主を怒らせたその怒りによるのであった。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="列王紀上 14:19; 列王紀上 16:20; 列王紀上 16:14"> ナダブのその他の事績と、彼がしたすべての事は、イスラエルの王の歴代志の書にしるされているではないか。</span>
<span className="v" id="v32" data-v="32" data-xref="列王紀上 15:16"> アサとイスラエルの王バアシャの間には一生の間戦争があった。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="列王紀上 16:8"> ユダの王アサの第三年にアヒヤの子バアシャはテルザでイスラエルの全地の王となって、二十四年世を治めた。</span>
<span className="v" id="v34" data-v="34" data-xref="列王紀上 15:26; 列王紀上 14:16; 列王紀上 12:28–29"> 彼は主の目の前に悪を行い、ヤラベアムの道に歩み、ヤラベアムがイスラエルに犯させた罪をおこなった。</span>
</div>

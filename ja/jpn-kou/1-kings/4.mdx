<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="伝道の書 1:12; 歴代志下 9:30; 列王紀上 12:19–20"> ソロモン王はイスラエルの全地の王であった。</span>
<span className="v" id="v2" data-v="2" data-xref="出エジプト記 18:21; コリント人への第一の手紙 12:28; サムエル記下 8:15–18"> 彼の高官たちは次のとおりである。ザドクの子アザリヤは祭司。</span>
<span className="v" id="v3" data-v="3" data-xref="サムエル記下 8:16; イザヤ書 62:6; 歴代志上 18:15"> シシャの子エリホレフとアヒヤは書記官。アヒルデの子ヨシャバテは史官。</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀上 2:35; 列王紀上 2:26–27"> エホヤダの子ベナヤは軍の長。ザドクとアビヤタルは祭司。</span>
<span className="v" id="v5" data-v="5" data-xref="歴代志上 27:33; サムエル記下 15:37; サムエル記下 16:16"> ナタンの子アザリヤは代官の長。ナタンの子ザブデは祭司で、王の友であった。</span>
<span className="v" id="v6" data-v="6" data-xref="列王紀上 9:15; サムエル記下 20:24; 列王紀上 12:18"> アヒシャルは宮内卿。アブダの子アドニラムは徴募の長であった。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="歴代志上 27:1–15"> ソロモンはまたイスラエルの全地に十二人の代官を置いた。その人々は王とその家のために食物を備えた。すなわちおのおの一年に一月ずつ食物を備えるのであった。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨシュア記 24:33; 士師記 19:1; 士師記 17:1"> その名は次のとおりである。エフライムの山地にはベンホル。</span>
<span className="v" id="v9" data-v="9" data-xref="ヨシュア記 21:16; サムエル記上 6:20; サムエル記上 6:12"> マカヅと、シャラビムと、ベテシメシと、エロン・ベテハナンにはベンデケル。</span>
<span className="v" id="v10" data-v="10" data-xref="ヨシュア記 15:35; ヨシュア記 12:17; ヨシュア記 17:2"> アルボテにはベンヘセデ、（彼はソコとヘペルの全地を担当した）。</span>
<span className="v" id="v11" data-v="11" data-xref="ヨシュア記 11:2; ヨシュア記 12:23; ヨシュア記 17:11"> ドルの高地の全部にはベン・アビナダブ、（彼はソロモンの娘タパテを妻とした）。</span>
<span className="v" id="v12" data-v="12" data-xref="ヨシュア記 17:11; 士師記 5:19; ヨシュア記 3:16"> アヒルデの子バアナはタアナクとメギドと、エズレルの下、ザレタンのかたわらにあるベテシャンの全地を担当して、ベテシャンからアベル・メホラに至り、ヨクメアムの向こうにまで及んだ。</span>
<span className="v" id="v13" data-v="13" data-xref="申命記 3:4; 民数記 32:41; 列王紀上 22:3"> ラモテ・ギレアデにはベンゲベル、（彼はギレアデにあるマナセの子ヤイルの村々を担当し、またバシャンにあるアルゴブの地方の城壁と青銅の貫の木のある大きな町六十を担当した）。</span>
<span className="v" id="v14" data-v="14" data-xref="ヨシュア記 13:26; サムエル記下 17:24; サムエル記下 2:8"> マハナイムにはイドの子アヒナダブ。</span>
<span className="v" id="v15" data-v="15" data-xref="ヨシュア記 19:32–39; サムエル記下 15:27; サムエル記上 18:18"> ナフタリにはアヒマアズ、（彼もソロモンの娘バスマテを妻にめとった）。</span>
<span className="v" id="v16" data-v="16" data-xref="ヨシュア記 19:24–31; サムエル記下 15:32"> アセルとベアロテにはホシャイの子バアナ。</span>
<span className="v" id="v17" data-v="17" data-xref="ヨシュア記 19:17–23"> イッサカルにはパルアの子ヨシャパテ。</span>
<span className="v" id="v18" data-v="18" data-xref="列王紀上 1:8; ヨシュア記 18:20–28; ゼカリヤ書 12:13"> ベニヤミンにはエラの子シメイ。</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 2:26–17; ヨシュア記 13:9–12; 民数記 21:21–35"> アモリびとの王シホンの地およびバシャンの王オグの地なるギレアデの地にはウリの子ゲベル。彼はその地のただひとりの代官であった。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="創世記 22:17; 列王紀上 3:8; 創世記 32:12"> ユダとイスラエルの人々は多くて、海べの砂のようであったが、彼らは飲み食いして楽しんだ。</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 15:18; ヨシュア記 1:4; 詩篇 68:29"> ソロモンはユフラテ川からペリシテびとの地と、エジプトの境に至るまでの諸国を治めたので、皆みつぎ物を携えてきて、ソロモンの一生のあいだ仕えた。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22"> さてソロモンの一日の食物は細かい麦粉三十コル、荒い麦粉六十コル、</span>
<span className="v" id="v23" data-v="23" data-xref="ネヘミヤ書 5:17–18"> 肥えた牛十頭、牧場の牛二十頭、羊百頭で、そのほかに雄じか、かもしか、こじか、および肥えた鳥があった。</span>
<span className="v" id="v24" data-v="24" data-xref="歴代志上 22:9; 詩篇 72:11; 詩篇 72:3"> これはソロモンがユフラテ川の西の地方をテフサからガザまで、ことごとく治めたからである。すなわち彼はユフラテ川の西の諸王をことごとく治め、周囲至る所に平安を得た。</span>
<span className="v" id="v25" data-v="25" data-xref="ミカ書 4:4; ゼカリヤ書 3:10; 士師記 20:1"> ソロモンの一生の間、ユダとイスラエルはダンからベエルシバに至るまで、安らかにおのおの自分たちのぶどうの木の下と、いちじくの木の下に住んだ。</span>
<span className="v" id="v26" data-v="26" data-xref="歴代志下 1:14; 歴代志下 9:25; サムエル記下 8:4"> ソロモンはまた戦車の馬の、うまや四千と、騎兵一万二千を持っていた。</span>
<span className="v" id="v27" data-v="27"> そしてそれらの代官たちはおのおの当番の月にソロモン王のため、およびすべてソロモン王の食卓に連なる者のために、食物を備えて欠けることのないようにした。</span>
<span className="v" id="v28" data-v="28" data-xref="エステル記 8:10; エステル記 8:14; ミカ書 1:13"> また彼らはおのおのその割当にしたがって馬および早馬に食わせる大麦とわらを、その馬のいる所に持ってきた。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="列王紀上 3:12; ヤコブの手紙 3:17; 列王紀上 4:20"> 神はソロモンに非常に多くの知恵と悟りを授け、また海べの砂原のように広い心を授けられた。</span>
<span className="v" id="v30" data-v="30" data-xref="ダニエル書 5:11–12; 創世記 25:6; ダニエル書 1:20"> ソロモンの知恵は東の人々の知恵とエジプトのすべての知恵にまさった。</span>
<span className="v" id="v31" data-v="31" data-xref="歴代志上 2:6; 歴代志上 15:19; 列王紀上 3:12"> 彼はすべての人よりも賢く、エズラびとエタンよりも、またマホルの子ヘマン、カルコル、ダルダよりも賢く、その名声は周囲のすべての国々に聞えた。</span>
<span className="v" id="v32" data-v="32" data-xref="雅歌 1:1–17; マタイによる福音書 13:35; 箴言 1:1–31"> 彼はまた箴言三千を説いた。またその歌は一千五首あった。</span>
<span className="v" id="v33" data-v="33" data-xref="列王紀下 19:23; 詩篇 51:7; 詩篇 92:12"> 彼はまた草木のことを論じてレバノンの香柏から石がきにはえるヒソプにまで及んだ。彼はまた獣と鳥と這うものと魚のことを論じた。</span>
<span className="v" id="v34" data-v="34" data-xref="歴代志下 9:23; 列王紀上 10:1; 歴代志下 9:1"> 諸国の人々はソロモンの知恵を聞くためにきた。地の諸王はソロモンの知恵を聞いて人をつかわした。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ルカによる福音書 4:25–26; ヤコブの手紙 5:17; ルカによる福音書 1:17"> ギレアデのテシベに住むテシベびとエリヤはアハブに言った、「わたしの仕えているイスラエルの神、主は生きておられます。わたしの言葉のないうちは、数年雨も露もないでしょう」。</span>
<span className="v" id="v2" data-v="2" data-xref="エレミヤ書 18:1; エレミヤ書 7:1; ホセア書 1:1–2"> 主の言葉がエリヤに臨んだ、</span>
<span className="v" id="v3" data-v="3" data-xref="ヨハネの黙示録 12:6; エレミヤ書 36:26; 詩篇 83:3"> 「ここを去って東におもむき、ヨルダンの東にあるケリテ川のほとりに身を隠しなさい。</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀上 17:9; 詩篇 147:9; ヨブ記 38:41"> そしてその川の水を飲みなさい。わたしはからすに命じて、そこであなたを養わせよう」。</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀上 19:9; マタイによる福音書 16:24; ヨハネによる福音書 15:14"> エリヤは行って、主の言葉のとおりにした。すなわち行って、ヨルダンの東にあるケリテ川のほとりに住んだ。</span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 78:23–24; マタイによる福音書 6:31–33; エレミヤ書 37:21"> すると、からすが朝ごとに彼の所にパンと肉を運び、また夕ごとにパンと肉を運んできた。そして彼はその川の水を飲んだ。</span>
<span className="v" id="v7" data-v="7" data-xref="イザヤ書 54:10; イザヤ書 40:30–31"> しかし国に雨がなかったので、しばらくしてその川はかれた。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="創世記 22:14; 列王紀上 17:2; ヘブル人への手紙 13:6"> その時、主の言葉が彼に臨んで言った、</span>
<span className="v" id="v9" data-v="9" data-xref="ルカによる福音書 4:26; オバデヤ書 1:20; コリント人への第二の手紙 4:7"> 「立ってシドンに属するザレパテへ行って、そこに住みなさい。わたしはそのところのやもめ女に命じてあなたを養わせよう」。</span>
<span className="v" id="v10" data-v="10" data-xref="ヨハネによる福音書 4:7; 創世記 24:17; 創世記 21:15"> そこで彼は立ってザレパテへ行ったが、町の門に着いたとき、ひとりのやもめ女が、その所でたきぎを拾っていた。彼はその女に声をかけて言った、「器に水を少し持ってきて、わたしに飲ませてください」。</span>
<span className="v" id="v11" data-v="11" data-xref="マタイによる福音書 25:35–40; 列王紀上 18:4; ヘブル人への手紙 13:2"> 彼女が行って、それを持ってこようとした時、彼は彼女を呼んで言った、「手に一口のパンを持ってきてください」。</span>
<span className="v" id="v12" data-v="12" data-xref="マタイによる福音書 15:33–34; 列王紀上 17:1; 創世記 21:16"> 彼女は言った、「あなたの神、主は生きておられます。わたしにはパンはありません。ただ、かめに一握りの粉と、びんに少しの油があるだけです。今わたしはたきぎ二、三本を拾い、うちへ帰って、わたしと子供のためにそれを調理し、それを食べて死のうとしているのです」。</span>
<span className="v" id="v13" data-v="13" data-xref="マタイによる福音書 6:33; マラキ書 3:10; 創世記 22:1–2"> エリヤは彼女に言った、「恐れるにはおよばない。行って、あなたが言ったとおりにしなさい。しかしまず、それでわたしのために小さいパンを、一つ作って持ってきなさい。その後、あなたと、あなたの子供のために作りなさい。</span>
<span className="v" id="v14" data-v="14" data-xref="マタイによる福音書 15:36–38; マタイによる福音書 14:17–20; 列王紀下 4:42–44"> 『主が雨を地のおもてに降らす日まで、かめの粉は尽きず、びんの油は絶えない』とイスラエルの神、主が言われるからです」。</span>
<span className="v" id="v15" data-v="15" data-xref="ヘブル人への手紙 11:17; マルコによる福音書 12:43; マタイによる福音書 15:28"> 彼女は行って、エリヤが言ったとおりにした。彼女と彼および彼女の家族は久しく食べた。</span>
<span className="v" id="v16" data-v="16" data-xref="マタイによる福音書 9:28–30; ヨハネによる福音書 4:50–51; ルカによる福音書 1:37"> 主がエリヤによって言われた言葉のように、かめの粉は尽きず、びんの油は絶えなかった。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="ペテロの第一の手紙 1:7; ダニエル書 5:23; ヨハネによる福音書 11:14"> これらの事の後、その家の主婦であるこの女の男の子が病気になった。その病気はたいそう重く、息が絶えたので、</span>
<span className="v" id="v18" data-v="18" data-xref="ルカによる福音書 5:8; ヨハネによる福音書 2:4; 列王紀下 3:13"> 彼女はエリヤに言った、「神の人よ、あなたはわたしに、何の恨みがあるのですか。あなたはわたしの罪を思い出させるため、またわたしの子を死なせるためにおいでになったのですか」。</span>
<span className="v" id="v19" data-v="19" data-xref="列王紀下 4:32; 列王紀下 4:10; 使徒行伝 9:37"> エリヤは彼女に言った、「子をわたしによこしなさい」。そして彼女のふところから子供を取り、自分のいる屋上のへやへかかえて上り、自分の寝台に寝かせ、</span>
<span className="v" id="v20" data-v="20" data-xref="ヤコブの手紙 5:15–18; マタイによる福音書 21:22; ヨシュア記 7:8–9"> 主に呼ばわって言った、「わが神、主よ、あなたはわたしが宿っている家のやもめにさえ災をくだして、子供を殺されるのですか」。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行伝 20:10; 使徒行伝 9:40; 列王紀下 4:33–35"> そして三度その子供の上に身を伸ばし、主に呼ばわって言った、「わが神、主よ、この子供の魂をもとに帰らせてください」。</span>
<span className="v" id="v22" data-v="22" data-xref="申命記 32:39; ヨハネの黙示録 11:11; ヘブル人への手紙 11:35"> 主はエリヤの声を聞きいれられたので、その子供の魂はもとに帰って、彼は生きかえった。</span>
<span className="v" id="v23" data-v="23" data-xref="列王紀下 4:36–37; 使徒行伝 9:41; ルカによる福音書 7:15"> エリヤはその子供を取って屋上のへやから家の中につれて降り、その母にわたして言った、「ごらんなさい。あなたの子は生きかえりました」。</span>
<span className="v" id="v24" data-v="24" data-xref="ヨハネによる福音書 16:30; ヨハネによる福音書 2:11; ヨハネによる福音書 3:2"> 女はエリヤに言った、「今わたしはあなたが神の人であることと、あなたの口にある主の言葉が真実であることを知りました」。</span>

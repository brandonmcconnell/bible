<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀上 20:34"> スリヤとイスラエルの間に戦争がなくて三年を経た。</span>
<span className="v" id="v2" data-v="2" data-xref="列王紀上 15:24; 列王紀上 22:1; 列王紀上 22:41"> しかし三年目にユダの王ヨシャパテがイスラエルの王の所へ下っていったので、</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 4:43; 列王紀上 4:13; ヨシュア記 21:38"> イスラエルの王はその家来たちに言った、「あなたがたは、ラモテ・ギレアデがわれわれの所有であることを知っていますか。しかもなおわれわれはスリヤの王の手からそれを取らずに黙っているのです」。</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀下 3:7; エペソ人への手紙 5:11; ヨハネの第二の手紙 1:11"> 彼はヨシャパテに言った、「ラモテ・ギレアデで戦うためにわたしと一緒に行かれませんか」。ヨシャパテはイスラエルの王に言った、「わたしはあなたと一つです。わたしの民はあなたの民と一つです。わたしの馬はあなたの馬と一つです」。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="箴言 3:5–6; 歴代志下 18:4–5; エレミヤ書 42:2–6"> ヨシャパテはまたイスラエルの王に言った、「まず、主の言葉を伺いなさい」。</span>
<span className="v" id="v6" data-v="6" data-xref="列王紀上 18:19; エレミヤ書 23:14–17; エゼキエル書 13:7–16"> そこでイスラエルの王は預言者四百人ばかりを集めて、彼らに言った、「わたしはラモテ・ギレアデに戦いに行くべきでしょうか、あるいは控えるべきでしょうか」。彼らは言った、「上っていきなさい。主はそれを王の手にわたされるでしょう」。</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀下 3:11–13; 歴代志下 18:6–7"> ヨシャパテは言った、「ここには、われわれの問うべき主の預言者がほかにいませんか」。</span>
<span className="v" id="v8" data-v="8" data-xref="アモス書 5:10; ヨハネによる福音書 3:19–21; ヨハネによる福音書 7:7"> イスラエルの王はヨシャパテに言った、「われわれが主に問うことのできる人が、まだひとりいます。イムラの子ミカヤです。彼はわたしについて良い事を預言せず、ただ悪い事だけを預言するので、わたしは彼を憎んでいます」。ヨシャパテは言った、「王よ、そう言わないでください」。</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀下 9:32; イザヤ書 39:7; 列王紀上 22:26–27"> そこでイスラエルの王は役人を呼んで、「急いでイムラの子ミカヤを連れてきなさい」と言った。</span>
<span className="v" id="v10" data-v="10" data-xref="エステル記 5:1; エステル記 6:8–9; 列王紀上 18:29"> さてイスラエルの王およびユダの王ヨシャパテは王の服を着て、サマリヤの門の入口の広場に、おのおのその王座にすわり、預言者たちは皆その前で預言していた。</span>
<span className="v" id="v11" data-v="11" data-xref="ゼカリヤ書 1:18–21; 申命記 33:17; エゼキエル書 22:27–28"> ケナアナの子ゼデキヤは鉄の角を造って言った、「主はこう仰せられます、『あなたはこれらの角をもってスリヤびとを突いて彼らを滅ぼしなさい』」。</span>
<span className="v" id="v12" data-v="12" data-xref="歴代志下 35:22; 列王紀上 22:6–15; 列王紀上 22:32–36"> 預言者たちは皆そのように預言して言った、「ラモテ・ギレアデに上っていって勝利を得なさい。主はそれを王の手にわたされるでしょう」。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="ミカ書 2:6–7; 詩篇 11:1; イザヤ書 30:10–11"> さてミカヤを呼びにいった使者は彼に言った、「預言者たちは一致して王に良い事を言いました。どうぞ、あなたも、彼らのひとりの言葉のようにして、良い事を言ってください」。</span>
<span className="v" id="v14" data-v="14" data-xref="民数記 24:13; 民数記 22:18; 歴代志下 18:12–13"> ミカヤは言った、「主は生きておられます。主がわたしに言われる事を申しましょう」。</span>
<span className="v" id="v15" data-v="15" data-xref="列王紀上 18:27; 士師記 10:14; マタイによる福音書 26:45"> 彼が王の所へ行くと、王は彼に言った、「ミカヤよ、われわれはラモテ・ギレアデに戦いに行くべきでしょうか、あるいは控えるべきでしょうか」。彼は王に言った、「上っていって勝利を得なさい。主はそれを王の手にわたされるでしょう」。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行伝 19:13; マタイによる福音書 26:63; ヨシュア記 6:26"> しかし王は彼に言った、「幾たびあなたを誓わせたら、あなたは主の名をもって、ただ真実のみをわたしに告げるでしょうか」。</span>
<span className="v" id="v17" data-v="17" data-xref="民数記 27:17; マタイによる福音書 9:36; 列王紀上 22:34–36"> 彼は言った、「わたしはイスラエルが皆、牧者のない羊のように、山に散っているのを見ました。すると主は『これらの者は飼主がいない。彼らをそれぞれ安らかに、その家に帰らせよ』と言われました」。</span>
<span className="v" id="v18" data-v="18" data-xref="列王紀上 22:8; 箴言 10:24; ルカによる福音書 11:45"> イスラエルの王はヨシャパテに言った、「彼がわたしについて良い事を預言せず、ただ悪い事だけを預言すると、あなたに告げたではありませんか」。</span>
<span className="v" id="v19" data-v="19" data-xref="ヨブ記 2:1; ヨブ記 1:6; ダニエル書 7:9–10"> ミカヤは言った、「それゆえ主の言葉を聞きなさい。わたしは主がその玉座にすわり、天の万軍がそのかたわらに、右左に立っているのを見たが、</span>
<span className="v" id="v20" data-v="20" data-xref="エゼキエル書 14:9; ヨブ記 12:16; エレミヤ書 4:10"> 主は『だれがアハブをいざなってラモテ・ギレアデに上らせ、彼を倒れさせるであろうか』と言われました。するとひとりはこの事を言い、ひとりはほかの事を言いました。</span>
<span className="v" id="v21" data-v="21" data-xref="ヨブ記 2:1; 列王紀上 22:23; ヨブ記 1:6–7"> その時一つの霊が進み出て、主の前に立ち、『わたしが彼をいざないましょう』と言いました。</span>
<span className="v" id="v22" data-v="22" data-xref="士師記 9:23; サムエル記上 19:9; サムエル記上 16:14"> 主は『どのような方法でするのか』と言われたので、彼は『わたしが出て行って、偽りを言う霊となって、すべての預言者の口に宿りましょう』と言いました。そこで主は『おまえは彼をいざなって、それを成し遂げるであろう。出て行って、そうしなさい』と言われました。</span>
<span className="v" id="v23" data-v="23" data-xref="エゼキエル書 14:9; マタイによる福音書 24:24–25; イザヤ書 44:20"> それで主は偽りを言う霊をあなたのすべての預言者の口に入れ、また主はあなたの身に起る災を告げられたのです」。</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行伝 23:2; 哀歌 3:30; ミカ書 5:1"> するとケナアナの子ゼデキヤは近寄って、ミカヤのほおを打って言った、「どのようにして主の霊がわたしを離れて、あなたに語りましたか」。</span>
<span className="v" id="v25" data-v="25" data-xref="列王紀上 20:30; ペテロの第二の手紙 2:1; ヨハネの黙示録 19:20"> ミカヤは言った、「あなたが奥の間にはいって身を隠すその日に、わかるでしょう」。</span>
<span className="v" id="v26" data-v="26"> イスラエルの王は言った、「ミカヤを捕え、町のつかさアモンと、王の子ヨアシの所へ引いて帰って、</span>
<span className="v" id="v27" data-v="27" data-xref="歴代志下 16:10; 歴代志下 18:25–27; ヨハネの黙示録 2:10"> 言いなさい、『王がこう言います、この者を獄屋に入れ、わずかのパンと水をもって彼を養い、わたしが勝利を得て帰ってくるのを待て』」。</span>
<span className="v" id="v28" data-v="28" data-xref="民数記 16:29; ミカ書 1:2; 使徒行伝 13:10–11"> ミカヤは言った、「もしあなたが勝利を得て帰ってこられるならば、主がわたしによって語られなかったのです」。また彼は言った、「あなたがた、すべての民よ、聞きなさい」。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="歴代志下 18:28; 列王紀上 22:2–9"> こうしてイスラエルの王とユダの王ヨシャパテはラモテ・ギレアデに上っていった。</span>
<span className="v" id="v30" data-v="30" data-xref="歴代志下 35:22; エレミヤ書 23:24; サムエル記上 28:8"> イスラエルの王はヨシャパテに言った、「わたしは姿を変えて、戦いに行きます。あなたは王の服を着けなさい」。イスラエルの王は姿を変えて戦いに行った。</span>
<span className="v" id="v31" data-v="31" data-xref="列王紀上 20:24; 歴代志下 18:30; エレミヤ書 16:6"> さて、スリヤの王は、その戦車長三十二人に命じて言った、「あなたがたは、小さい者とも大きい者とも戦わないで、ただイスラエルの王とだけ戦いなさい」。</span>
<span className="v" id="v32" data-v="32" data-xref="箴言 13:20; ヨナ書 2:1–2; 詩篇 130:1–4"> 戦車長らはヨシャパテを見たとき、これはきっとイスラエルの王だと思ったので、身をめぐらして、これと戦おうとすると、ヨシャパテは呼ばわった。</span>
<span className="v" id="v33" data-v="33" data-xref="詩篇 76:10; 列王紀上 22:31"> 戦車長らは彼がイスラエルの王でないのを見たので、彼を追うことをやめて引き返した。</span>
<span className="v" id="v34" data-v="34" data-xref="歴代志下 35:23; ミカ書 6:13; サムエル記上 17:49"> しかし、ひとりの人が何心なく弓をひいて、イスラエルの王の胸当と草摺の間を射たので、彼はその戦車の御者に言った、「わたしは傷を受けた。戦車をめぐらして、わたしを戦場から運び出せ」。</span>
<span className="v" id="v35" data-v="35" data-xref="列王紀上 22:28; 列王紀上 20:42"> その日戦いは激しくなった。王は戦車の中にささえられて立ち、スリヤびとにむかっていたが、ついに、夕暮になって死んだ。傷の血は戦車の底に流れた。</span>
<span className="v" id="v36" data-v="36" data-xref="列王紀下 14:12; 列王紀上 22:31; 士師記 21:24"> 日の没するころ、軍勢の中に呼ばわる声がした、「めいめいその町へ、めいめいその国へ帰れ」。</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37"> 王は死んで、サマリヤへ携え行かれた。人々は王をサマリヤに葬った。</span>
<span className="v" id="v38" data-v="38" data-xref="列王紀上 21:19; マタイによる福音書 24:35; エレミヤ書 44:21–23"> またその戦車をサマリヤの池で洗ったが、犬がその血をなめた。また遊女がそこで身を洗った。主が言われた言葉のとおりである。</span>
<span className="v" id="v39" data-v="39" data-xref="アモス書 3:15; エゼキエル書 27:6; 詩篇 45:8"> アハブのそのほかの事績と、彼がしたすべての事と、その建てた象牙の家と、その建てたすべての町は、イスラエルの王の歴代志の書にしるされているではないか。</span>
<span className="v" id="v40" data-v="40" data-xref="サムエル記下 7:12; 列王紀下 1:17; 列王紀下 1:2"> こうしてアハブはその先祖と共に眠って、その子アハジヤが代って王となった。</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="歴代志下 20:31; 列王紀上 22:2; 歴代志下 17:1"> アサの子ヨシャパテはイスラエルの王アハブの第四年にユダの王となった。</span>
<span className="v" id="v42" data-v="42" data-xref="列王紀下 1:17; 列王紀上 15:2; 列王紀上 15:10"> ヨシャパテは王となった時、三十五歳であったが、エルサレムで二十五年世を治めた。その母の名はアズバといい、シルヒの娘であった。</span>
<span className="v" id="v43" data-v="43" data-xref="列王紀上 15:14; 列王紀下 12:3; 箴言 4:27"> ヨシャパテは父アサのすべての道に歩み、それを離れることなく、主の目にかなう事をした。ただし高き所は除かなかったので、民はなお高き所で犠牲をささげ、香をたいた。</span>
<span className="v" id="v44" data-v="44" data-xref="列王紀上 22:2; 歴代志下 19:2; 列王紀下 8:18"> ヨシャパテはまたイスラエルの王と、よしみを結んだ。</span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="列王紀上 14:29; 列王紀上 11:41; 歴代志下 20:34"> ヨシャパテのその他の事績と、彼があらわした勲功およびその戦争については、ユダの王の歴代志の書にしるされているではないか。</span>
<span className="v" id="v46" data-v="46" data-xref="列王紀上 15:12; 列王紀上 14:24; 申命記 23:17"> 彼は父アサの世になお残っていた神殿男娼たちを国のうちから追い払った。</span>
</div>
<div className="bp">
<span className="v" id="v47" data-v="47" data-xref="サムエル記下 8:14; 列王紀下 3:9; 列王紀下 8:20"> そのころエドムには王がなく、代官が王であった。</span>
<span className="v" id="v48" data-v="48" data-xref="列王紀上 9:26; 列王紀上 10:22; 列王紀上 9:28"> ヨシャパテはタルシシの船を造って、金を獲るためにオフルに行かせようとしたが、その船はエジオン・ゲベルで難破したため、ついに行かなかった。</span>
<span className="v" id="v49" data-v="49"> そこでアハブの子アハジヤはヨシャパテに「わたしの家来をあなたの家来と一緒に船で行かせなさい」と言ったが、ヨシャパテは承知しなかった。</span>
<span className="v" id="v50" data-v="50" data-xref="歴代志下 21:1; 列王紀上 22:40; 列王紀上 15:24"> ヨシャパテはその先祖と共に眠って、父ダビデの町に先祖と共に葬られ、その子ヨラムが代って王となった。</span>
</div>
<div className="bp">
<span className="v" id="v51" data-v="51" data-xref="列王紀下 1:17; 列王紀上 22:40; 列王紀上 15:25"> アハブの子アハジヤはユダの王ヨシャパテの第十七年にサマリヤでイスラエルの王となり、二年イスラエルを治めた。</span>
<span className="v" id="v52" data-v="52" data-xref="列王紀上 15:26; 列王紀上 21:25; ヨハネの黙示録 3:20"> 彼は主の目の前に悪を行い、その父の道と、その母の道、およびかのイスラエルに罪を犯させたネバテの子ヤラベアムの道に歩み、</span>
<span className="v" id="v53" data-v="53" data-xref="列王紀上 16:30–32; イザヤ書 65:3; 列王紀下 3:2"> バアルに仕えて、それを拝み、イスラエルの神、主を怒らせた。すべて彼の父がしたとおりであった。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士師記 6:33; 歴代志下 28:22; ヨシュア記 19:18"> さてエズレルびとナボテはエズレルにぶどう畑をもっていたが、サマリヤの王アハブの宮殿のかたわらにあったので、</span>
<span className="v" id="v2" data-v="2" data-xref="サムエル記上 8:14; ヤコブの手紙 1:14–15; テモテヘの第一の手紙 6:9"> アハブはナボテに言った、「あなたのぶどう畑はわたしの家の近くにあるので、わたしに譲って青物畑にさせてください。その代り、わたしはそれよりも良いぶどう畑をあなたにあげましょう。もしお望みならば、その価を金でさしあげましょう」。</span>
<span className="v" id="v3" data-v="3" data-xref="民数記 36:7; レビ記 25:23; エゼキエル書 46:18"> ナボテはアハブに言った、「わたしは先祖の嗣業をあなたに譲ることを断じていたしません」。</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀上 20:43; ヤコブの手紙 1:14; ヨナ書 4:9"> アハブはエズレルびとナボテが言った言葉を聞いて、悲しみ、かつ怒って家にはいった。ナボテが「わたしは先祖の嗣業をあなたに譲りません」と言ったからである。アハブは床に伏し、顔をそむけて食事をしなかった。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="列王紀上 16:31; 創世記 3:6; 列王紀上 19:2"> 妻イゼベルは彼の所にきて、言った、「あなたは何をそんなに悲しんで、食事をなさらないのですか」。</span>
<span className="v" id="v6" data-v="6" data-xref="エステル記 5:9–14; ヤコブの手紙 4:2–7; テモテヘの第一の手紙 6:9–10"> 彼は彼女に言った、「わたしはエズレルびとナボテに『あなたのぶどう畑を金で譲ってください。もし望むならば、その代りに、ほかのぶどう畑をあげよう』と言ったが、彼は答えて『わたしはぶどう畑を譲りません』と言ったからだ」。</span>
<span className="v" id="v7" data-v="7" data-xref="サムエル記上 8:14; ミカ書 7:3; サムエル記下 13:4"> 妻イゼベルは彼に言った、「あなたが今イスラエルを治めているのですか。起きて食事をし、元気を出してください。わたしがエズレルびとナボテのぶどう畑をあなたにあげます」。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="ネヘミヤ書 6:5; 列王紀下 10:11; エズラ記 4:7–8"> 彼女はアハブの名で手紙を書き、彼の印をおして、ナボテと同じように、その町に住んでいる長老たちと身分の尊い人々に、その手紙を送った。</span>
<span className="v" id="v9" data-v="9" data-xref="イザヤ書 58:4; マタイによる福音書 23:13; ルカによる福音書 20:47"> 彼女はその手紙に書きしるした、「断食を布告して、ナボテを民のうちの高い所にすわらせ、</span>
<span className="v" id="v10" data-v="10" data-xref="出エジプト記 22:28; 使徒行伝 6:11; レビ記 24:15–16"> またふたりのよこしまな者を彼の前にすわらせ、そして彼を訴えて、『あなたは神と王とをのろった』と言わせなさい。こうして彼を引き出し、石で撃ち殺しなさい」。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行伝 4:19; レビ記 19:15; 列王紀下 10:6–7"> その町の人々、すなわち、その町に住んでいる長老たちおよび身分の尊い人々は、イゼベルが言いつかわしたようにした。彼女が彼らに送った手紙に書きしるされていたように、</span>
<span className="v" id="v12" data-v="12" data-xref="イザヤ書 58:4; 列王紀上 21:8–10"> 彼らは断食を布告して、ナボテを民のうちの高い所にすわらせた。</span>
<span className="v" id="v13" data-v="13" data-xref="列王紀下 9:26; 申命記 22:24; 伝道の書 10:20"> そしてふたりのよこしまな者がはいってきて、その前にすわり、そのよこしまな者たちが民の前でナボテを訴えて、「ナボテは神と王とをのろった」と言った。そこで人々は彼を町の外に引き出し、石で撃ち殺した。</span>
<span className="v" id="v14" data-v="14" data-xref="伝道の書 8:14; サムエル記下 11:14–24; 伝道の書 5:8"> そして人々はイゼベルに「ナボテは石で撃ち殺された」と言い送った。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="箴言 1:10–16; 箴言 4:17; 列王紀上 21:7"> イゼベルはナボテが石で撃ち殺されたのを聞くとすぐ、アハブに言った、「立って、あのエズレルびとナボテが、あなたに金で譲ることを拒んだぶどう畑を取りなさい。ナボテは生きていません。死んだのです」。</span>
<span className="v" id="v16" data-v="16" data-xref="オバデヤ書 1:12–14; ローマ人への手紙 1:32; サムエル記下 11:25–27"> アハブはナボテの死んだのを聞くとすぐ、立って、エズレルびとナボテのぶどう畑を取るために、そこへ下っていった。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="詩篇 9:12; イザヤ書 26:21; 列王紀下 5:26"> そのとき、主の言葉がテシベびとエリヤに臨んだ、</span>
<span className="v" id="v18" data-v="18" data-xref="列王紀上 13:32; 歴代志下 22:9"> 「立って、下って行き、サマリヤにいるイスラエルの王アハブに会いなさい。彼はナボテのぶどう畑を取ろうとしてそこへ下っている。</span>
<span className="v" id="v19" data-v="19" data-xref="列王紀上 22:38; サムエル記下 12:9; ハバクク書 2:9"> あなたは彼に言わなければならない、『主はこう仰せられる、あなたは殺したのか、また取ったのか』と。また彼に言いなさい、『主はこう仰せられる、犬がナボテの血をなめた場所で、犬があなたの血をなめるであろう』」。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="列王紀下 17:17; ローマ人への手紙 7:14; 列王紀上 21:25"> アハブはエリヤに言った、「わが敵よ、ついに、わたしを見つけたのか」。彼は言った、「見つけました。あなたが主の目の前に悪を行うことに身をゆだねたゆえ、</span>
<span className="v" id="v21" data-v="21" data-xref="列王紀上 14:10; サムエル記上 25:34; 列王紀下 10:1–7"> わたしはあなたに災を下し、あなたを全く滅ぼし、アハブに属する男は、イスラエルにいてつながれた者も、自由な者もことごとく断ち、</span>
<span className="v" id="v22" data-v="22" data-xref="列王紀上 16:3; 列王紀上 14:16; 列王紀上 16:11"> またあなたの家をネバテの子ヤラベアムの家のようにし、アヒヤの子バアシャの家のようにするでしょう。これはあなたがわたしを怒らせた怒りのゆえ、またイスラエルに罪を犯させたゆえです。</span>
<span className="v" id="v23" data-v="23" data-xref="列王紀下 9:10; 列王紀下 9:30–37; 列王紀上 21:25"> イゼベルについて、主はまた言われました、『犬がエズレルの地域でイゼベルを食うであろう』と。</span>
<span className="v" id="v24" data-v="24" data-xref="列王紀上 16:4; 列王紀上 14:11; エレミヤ書 15:3"> アハブに属する者は、町で死ぬ者を犬が食い、野で死ぬ者を空の鳥が食うでしょう」。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="箴言 22:14; 列王紀上 21:20; 列王紀上 16:30–33"> アハブのように主の目の前に悪を行うことに身をゆだねた者はなかった。その妻イゼベルが彼をそそのかしたのである。</span>
<span className="v" id="v26" data-v="26" data-xref="列王紀下 21:11; 創世記 15:16; レビ記 18:25–30"> 彼は主がイスラエルの人々の前から追い払われたアモリびとがしたように偶像に従って、はなはだ憎むべき事を行った。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="列王紀下 6:30; 創世記 37:34; サムエル記下 3:31"> アハブはこれらの言葉を聞いた時、衣を裂き、荒布を身にまとい、食を断ち、荒布に伏し、打ちしおれて歩いた。</span>
<span className="v" id="v28" data-v="28"> この時、主の言葉がテシベびとエリヤに臨んだ、</span>
<span className="v" id="v29" data-v="29" data-xref="ペテロの第二の手紙 3:9; ミカ書 7:18; 詩篇 86:15"> 「アハブがわたしの前にへりくだっているのを見たか。彼がわたしの前にへりくだっているゆえ、わたしは彼の世には災を下さない。その子の世に災をその家に下すであろう」。</span>
</div>

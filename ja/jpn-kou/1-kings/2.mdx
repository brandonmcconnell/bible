<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 47:29; 申命記 31:14; テモテヘの第一の手紙 1:18"> ダビデの死ぬ日が近づいたので、彼はその子ソロモンに命じて言った、</span>
<span className="v" id="v2" data-v="2" data-xref="ヨシュア記 1:6–7; ヨシュア記 23:14; エペソ人への手紙 6:10"> 「わたしは世のすべての人の行く道を行こうとしている。あなたは強く、男らしくなければならない。</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 29:9; 申命記 17:18–20; 箴言 3:1–4"> あなたの神、主のさとしを守り、その道に歩み、その定めと戒めと、おきてとあかしとを、モーセの律法にしるされているとおりに守らなければならない。そうすれば、あなたがするすべての事と、あなたの向かうすべての所で、あなたは栄えるであろう。</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀下 20:3; サムエル記下 7:25; 列王紀上 8:25"> また主がさきにわたしについて語って『もしおまえの子たちが、その道を慎み、心をつくし、精神をつくして真実をもって、わたしの前に歩むならば、おまえに次いでイスラエルの位にのぼる人が、欠けることはなかろう』と言われた言葉を確実にされるであろう。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="サムエル記下 3:27; サムエル記下 20:10; サムエル記下 18:5"> またあなたはゼルヤの子ヨアブがわたしにした事、すなわち彼がイスラエルのふたりの軍の長ネルの子アブネルと、エテルの子アマサにした事を知っている。彼はこのふたりを殺して、戦争で流した地を太平の時に報い、罪のない者の血をわたしの腰のまわりの帯と、わたしの足のくつにつけた。</span>
<span className="v" id="v6" data-v="6" data-xref="列王紀上 2:9; イザヤ書 57:21; 詩篇 37:37"> それゆえ、あなたの知恵にしたがって事を行い、彼のしらがを安らかに陰府に下らせてはならない。</span>
<span className="v" id="v7" data-v="7" data-xref="サムエル記下 17:27–29; サムエル記下 9:7; サムエル記下 19:31–40"> ただしギレアデびとバルジライの子らには恵みを施し、彼らをあなたの食卓で食事する人々のうちに加えなさい。彼らはわたしがあなたの兄弟アブサロムを避けて逃げた時、わたしを迎えてくれたからである。</span>
<span className="v" id="v8" data-v="8" data-xref="サムエル記下 16:5–8; 列王紀上 2:36–46; サムエル記下 19:16–23"> またバホリムのベニヤミンびとゲラの子シメイがあなたと共にいる。彼はわたしがマハナイムへ行った時、激しいのろいの言葉をもってわたしをのろった。しかし彼がヨルダンへ下ってきて、わたしを迎えたので、わたしは主をさして彼に誓い、『わたしはつるぎをもってあなたを殺さない』と言った。</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀上 2:6; 創世記 42:38; 創世記 44:31"> しかし彼を罪のない者としてはならない。あなたは知恵のある人であるから、彼になすべき事を知っている。あなたは彼のしらがを血に染めて陰府に下らせなければならない」。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="使徒行伝 2:29; 使徒行伝 13:36; 列王紀上 1:21"> ダビデはその先祖と共に眠って、ダビデの町に葬られた。</span>
<span className="v" id="v11" data-v="11" data-xref="サムエル記下 5:4–5; 歴代志上 29:26–27"> ダビデがイスラエルを治めた日数は四十年であった。すなわちヘブロンで七年、エルサレムで三十三年、王であった。</span>
<span className="v" id="v12" data-v="12" data-xref="歴代志下 1:1; 歴代志上 29:23–25; 詩篇 132:12"> このようにしてソロモンは父ダビデの位に座し、国は堅く定まった。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="サムエル記上 16:4–5; 列王紀上 1:5–10; ルカによる福音書 10:5–6"> さて、ハギテの子アドニヤがソロモンの母バテシバのところへきたので、バテシバは言った、「あなたは穏やかな事のためにきたのですか」。彼は言った、「穏やかな事のためです」。</span>
<span className="v" id="v14" data-v="14" data-xref="サムエル記下 14:12; ルカによる福音書 7:40"> 彼はまた言った、「あなたに申しあげる事があります」。バテシバは言った、「言いなさい」。</span>
<span className="v" id="v15" data-v="15" data-xref="歴代志上 22:9–10; 歴代志上 28:5–7; 列王紀上 1:25"> 彼は言った、「ごぞんじのように、国はわたしのもので、イスラエルの人は皆わたしが王になるものと期待していました。しかし国は転じて、わたしの兄弟のものとなりました。彼のものとなったのは、主から出たことです。</span>
<span className="v" id="v16" data-v="16" data-xref="箴言 30:7; 詩篇 132:10"> 今わたしはあなたに一つのお願いがあります。断らないでください」。バテシバは彼に言った、「言いなさい」。</span>
<span className="v" id="v17" data-v="17" data-xref="サムエル記下 12:8; 列王紀上 1:2–4; サムエル記下 3:7"> 彼は言った、「どうかソロモン王に請うて、――王はあなたに断るようなことはないでしょうから――シュナミびとアビシャグをわたしに与えて妻にさせてください」。</span>
<span className="v" id="v18" data-v="18" data-xref="箴言 14:15"> バテシバは言った、「よろしい。わたしはあなたのために王に話しましょう」。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="詩篇 45:9; 列王紀上 15:13; レビ記 19:32"> バテシバはアドニヤのためにソロモン王に話すため、王のもとへ行った。王は立って迎え、彼女を拝して王座に着き、王母のために座を設けさせたので、彼女は王の右に座した。</span>
<span className="v" id="v20" data-v="20" data-xref="マタイによる福音書 7:7–11; マタイによる福音書 11:24; ヨハネによる福音書 2:3–4"> そこでバテシバは言った、「あなたに一つの小さいお願いがあります。お断りにならないでください」。王は彼女に言った、「母上よ、あなたの願いを言ってください。わたしは断らないでしょう」。</span>
<span className="v" id="v21" data-v="21" data-xref="列王紀上 1:3; サムエル記下 16:21–22"> 彼女は言った、「どうぞ、シュナミびとアビシャグをあなたの兄弟アドニヤに与えて、妻にさせてください」。</span>
<span className="v" id="v22" data-v="22" data-xref="歴代志上 3:2; 歴代志上 3:5; マタイによる福音書 20:22"> ソロモン王は答えて母に言った、「どうしてアドニヤのためにシュナミびとアビシャグを求められるのですか。彼のためには国をも求めなさい。彼はわたしの兄で、彼の味方には祭司アビヤタルとゼルヤの子ヨアブがいるのですから」。</span>
<span className="v" id="v23" data-v="23" data-xref="ルツ記 1:17; 詩篇 140:9; 詩篇 64:8"> そしてソロモン王は主をさして誓って言った、「もしアドニヤがこの言葉によって自分の命を失うのでなければ、どんなにでもわたしを罰してください。</span>
<span className="v" id="v24" data-v="24" data-xref="歴代志上 22:10; 歴代志上 17:10; 歴代志上 17:17"> わたしを立てて、父ダビデの位にのぼらせ、主が約束されたように、わたしに一家を与えてくださった主は生きておられる。アドニヤはきょう殺されなければならない」。</span>
<span className="v" id="v25" data-v="25" data-xref="サムエル記下 8:18; 列王紀上 2:46; 士師記 8:20–21"> ソロモン王はエホヤダの子ベナヤをつかわしたので、彼はアドニヤを撃って殺した。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="ヨシュア記 21:18; サムエル記上 22:20–23; エレミヤ書 1:1"> 王はまた祭司アビヤタルに言った、「あなたの領地アナトテへ行きなさい。あなたは死に当る者ですが、さきにわたしの父ダビデの前に神、主の箱をかつぎ、またすべてわたしの父が受けた苦しみを、あなたも共に苦しんだので、わたしは、きょうは、あなたを殺しません」。</span>
<span className="v" id="v27" data-v="27" data-xref="サムエル記上 2:27–36; サムエル記上 3:12–14; エレミヤ書 7:12–14"> そしてソロモンはアビヤタルを主の祭司職から追放した。こうして主がシロでエリの家について言われた主の言葉が成就した。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="列王紀上 1:50; 列王紀上 1:7; サムエル記下 18:2"> さてこの知らせがヨアブに達したので、ヨアブは主の幕屋にのがれて、祭壇の角をつかんだ。ヨアブはアブサロムを支持しなかったけれども、アドニヤを支持したからである。</span>
<span className="v" id="v29" data-v="29" data-xref="列王紀上 2:25; 出エジプト記 21:14; 列王紀上 2:46"> ヨアブが主の幕屋にのがれて、祭壇のかたわらにいることを、ソロモン王に告げる者があったので、ソロモン王はエホヤダの子ベナヤをつかわし、「行って彼を撃て」と言った。</span>
<span className="v" id="v30" data-v="30"> ベナヤは主の幕屋へ行って彼に言った、「王はあなたに、出て来るようにと申されます」。しかし彼は言った、「いや、わたしはここで死にます」。ベナヤは王に復命して言った、「ヨアブはこう申しました。またわたしにこう答えました」。</span>
<span className="v" id="v31" data-v="31" data-xref="申命記 21:8–9; 民数記 35:33; 出エジプト記 21:14"> そこで王はベナヤに言った、「彼が言うようにし、彼を撃ち殺して葬り、ヨアブがゆえなく流した血のとがをわたしと、わたしの父の家から除き去りなさい。</span>
<span className="v" id="v32" data-v="32" data-xref="士師記 9:24; 士師記 9:57; 詩篇 7:16"> 主はまたヨアブが血を流した行為を、彼自身のこうべに報いられるであろう。これは彼が自分よりも正しいすぐれたふたりの人、すなわちイスラエルの軍の長ネルの子アブネルと、ユダの軍の長エテルの子アマサを、つるぎをもって撃ち殺し、わたしの父ダビデのあずかり知らない事をしたからである。</span>
<span className="v" id="v33" data-v="33" data-xref="マタイによる福音書 27:25; 列王紀上 2:32; ルカによる福音書 2:14"> それゆえ、彼らの血は永遠にヨアブのこうべと、その子孫のこうべに帰すであろう。しかしダビデと、その子孫と、その家と、その位とには、主から賜わる平安が永久にあるであろう」。</span>
<span className="v" id="v34" data-v="34" data-xref="マタイによる福音書 3:1; ヨシュア記 15:61; 列王紀上 2:25"> そこでエホヤダの子ベナヤは上っていって、彼を撃ち殺した。彼は荒野にある自分の家に葬られた。</span>
<span className="v" id="v35" data-v="35" data-xref="列王紀上 2:27; 歴代志上 24:3; 歴代志上 29:22"> 王はエホヤダの子ベナヤを、ヨアブに代って軍の長とした。王はまた祭司ザドクをアビヤタルに代らせた。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="サムエル記下 16:5–9; 列王紀上 2:8–9; 箴言 20:26"> また王は人をつかわし、シメイを召して言った、「あなたはエルサレムのうちに、自分のために家を建てて、そこに住み、そこからどこへも出てはならない。</span>
<span className="v" id="v37" data-v="37" data-xref="サムエル記下 1:16; サムエル記下 15:23; ヨシュア記 2:19"> あなたが出て、キデロン川を渡る日には必ず殺されることを、しかと知らなければならない。あなたの血はあなたのこうべに帰すであろう」。</span>
<span className="v" id="v38" data-v="38" data-xref="列王紀上 20:4; 列王紀下 20:19"> シメイは王に言った、「お言葉は結構です。王、わが主の仰せられるとおりに、しもべはいたしましょう」。こうしてシメイは久しくエルサレムに住んだ。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="サムエル記上 21:10; サムエル記上 27:2–3"> ところが三年の後、シメイのふたりの奴隷が、ガテの王マアカの子アキシのところへ逃げ去った。人々がシメイに告げて、「ごらんなさい、あなたの奴隷はガテにいます」と言ったので、</span>
<span className="v" id="v40" data-v="40" data-xref="ルカによる福音書 12:15; 箴言 15:27; テモテヘの第一の手紙 6:10"> シメイは立って、ろばにくらを置き、ガテのアキシのところへ行って、その奴隷を尋ねた。すなわちシメイは行ってその奴隷をガテから連れてきたが、</span>
<span className="v" id="v41" data-v="41"> シメイがエルサレムからガテへ行って帰ったことがソロモン王に聞えたので、</span>
<span className="v" id="v42" data-v="42" data-xref="詩篇 15:4; 列王紀上 2:36–38; ルカによる福音書 15:22"> 王は人をつかわし、シメイを召して言った、「わたしはあなたに主をさして誓わせ、かつおごそかにあなたを戒めて、『あなたが出て、どこかへ行く日には、必ず殺されることを、しかと知らなければならない』と言ったではないか。そしてあなたは、わたしに『お言葉は結構です。従います』と言った。</span>
<span className="v" id="v43" data-v="43" data-xref="ローマ人への手紙 13:5; 歴代志下 30:12; 伝道の書 8:2"> ところで、あなたはなぜ主に対する誓いと、わたしが命じた命令を守らなかったのか」。</span>
<span className="v" id="v44" data-v="44" data-xref="サムエル記下 16:5–13; 詩篇 7:16; エゼキエル書 17:19"> 王はまたシメイに言った、「あなたは自分の心に、あなたがわたしの父ダビデにしたもろもろの悪を知っている。主はあなたの悪をあなたのこうべに報いられるであろう。</span>
<span className="v" id="v45" data-v="45" data-xref="箴言 25:5; 列王紀上 2:24; イザヤ書 9:6–7"> しかしソロモン王は祝福をうけ、ダビデの位は永久に主の前に堅く立つであろう」。</span>
<span className="v" id="v46" data-v="46" data-xref="歴代志下 1:1; 列王紀上 2:12; 列王紀上 2:45"> 王がエホヤダの子ベナヤに命じたので、彼は出ていってシメイを撃ち殺した。こうして国はソロモンの手に堅く立った。</span>
</div>

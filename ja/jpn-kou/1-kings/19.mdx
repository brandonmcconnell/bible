<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀上 18:40; 列王紀上 21:25; 列王紀上 21:5–7"> アハブはエリヤのしたすべての事、また彼がすべての預言者を刀で殺したことをイゼベルに告げたので、</span>
<span className="v" id="v2" data-v="2" data-xref="ルツ記 1:17; 列王紀下 6:31; 列王紀上 20:10"> イゼベルは使者をエリヤにつかわして言った、「もしわたしが、あすの今ごろ、あなたの命をあの人々のひとりの命のようにしていないならば、神々がどんなにでも、わたしを罰してくださるように」。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 21:31; マタイによる福音書 26:70–74; マタイによる福音書 26:56"> そこでエリヤは恐れて、自分の命を救うために立って逃げ、ユダに属するベエルシバへ行って、しもべをそこに残し、</span>
<span className="v" id="v4" data-v="4" data-xref="ヨナ書 4:3; 民数記 11:15; ヨナ書 4:8"> 自分は一日の道のりほど荒野にはいって行って、れだまの木の下に座し、自分の死を求めて言った、「主よ、もはや、じゅうぶんです。今わたしの命を取ってください。わたしは先祖にまさる者ではありません」。</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 34:7; 使徒行伝 12:7; ヘブル人への手紙 13:5"> 彼はれだまの木の下に伏して眠ったが、天の使が彼にさわり、「起きて食べなさい」と言ったので、</span>
<span className="v" id="v6" data-v="6" data-xref="列王紀上 17:6; マタイによる福音書 4:11; マタイによる福音書 6:32"> 起きて見ると、頭のそばに、焼け石の上で焼いたパン一個と、一びんの水があった。彼は食べ、かつ飲んでまた寝た。</span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 103:13–14; 申命記 33:25"> 主の使は再びきて、彼にさわって言った、「起きて食べなさい。道が遠くて耐えられないでしょうから」。</span>
<span className="v" id="v8" data-v="8" data-xref="出エジプト記 34:28; 出エジプト記 24:18; 出エジプト記 3:1"> 彼は起きて食べ、かつ飲み、その食物で力づいて四十日四十夜行って、神の山ホレブに着いた。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="列王紀上 19:13; 出エジプト記 33:21–22; エレミヤ書 2:18"> その所で彼はほら穴にはいって、そこに宿ったが、主の言葉が彼に臨んで、彼に言われた、「エリヤよ、あなたはここで何をしているのか」。</span>
<span className="v" id="v10" data-v="10" data-xref="列王紀上 18:4; 列王紀上 18:22; 出エジプト記 34:14"> 彼は言った、「わたしは万軍の神、主のために非常に熱心でありました。イスラエルの人々はあなたの契約を捨て、あなたの祭壇をこわし、刀をもってあなたの預言者たちを殺したのです。ただわたしだけ残りましたが、彼らはわたしの命を取ろうとしています」。</span>
<span className="v" id="v11" data-v="11" data-xref="エゼキエル書 1:4; 詩篇 50:3; ヨブ記 38:1"> 主は言われた、「出て、山の上で主の前に、立ちなさい」。その時主は通り過ぎられ、主の前に大きな強い風が吹き、山を裂き、岩を砕いた。しかし主は風の中におられなかった。風の後に地震があったが、地震の中にも主はおられなかった。</span>
<span className="v" id="v12" data-v="12" data-xref="ヨブ記 4:16; ゼカリヤ書 4:6; 申命記 4:33"> 地震の後に火があったが、火の中にも主はおられなかった。火の後に静かな細い声が聞えた。</span>
<span className="v" id="v13" data-v="13" data-xref="列王紀上 19:9; イザヤ書 6:2; 創世記 16:8"> エリヤはそれを聞いて顔を外套に包み、出てほら穴の口に立つと、彼に語る声が聞えた、「エリヤよ、あなたはここで何をしているのか」。</span>
<span className="v" id="v14" data-v="14" data-xref="列王紀上 19:9–10; エレミヤ書 22:9; イザヤ書 62:1"> 彼は言った、「わたしは万軍の神、主のために非常に熱心でありました。イスラエルの人々はあなたの契約を捨て、あなたの祭壇をこわし、刀であなたの預言者たちを殺したからです。ただわたしだけ残りましたが、彼らはわたしの命を取ろうとしています」。</span>
<span className="v" id="v15" data-v="15" data-xref="イザヤ書 45:1; エレミヤ書 1:10; 列王紀下 8:7–15"> 主は彼に言われた、「あなたの道を帰って行って、ダマスコの荒野におもむき、ダマスコに着いて、ハザエルに油を注ぎ、スリヤの王としなさい。</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀下 9:1–14; 列王紀上 19:19–21; 列王紀下 2:9"> またニムシの子エヒウに油を注いでイスラエルの王としなさい。またアベルメホラのシャパテの子エリシャに油を注いで、あなたに代って預言者としなさい。</span>
<span className="v" id="v17" data-v="17" data-xref="列王紀下 13:22; 列王紀下 8:12; 列王紀下 13:3"> ハザエルのつるぎをのがれる者をエヒウが殺し、エヒウのつるぎをのがれる者をエリシャが殺すであろう。</span>
<span className="v" id="v18" data-v="18" data-xref="ローマ人への手紙 11:4–5; イザヤ書 1:9; イザヤ書 10:20–22"> また、わたしはイスラエルのうちに七千人を残すであろう。皆バアルにひざをかがめず、それに口づけしない者である」。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="列王紀下 2:8; 列王紀下 2:13–14; サムエル記上 28:14"> さてエリヤはそこを去って行って、シャパテの子エリシャに会った。彼は十二くびきの牛を前に行かせ、自分は十二番目のくびきと共にいて耕していた。エリヤは彼のかたわらを通り過ぎて外套を彼の上にかけた。</span>
<span className="v" id="v20" data-v="20" data-xref="マタイによる福音書 8:21–22; ルカによる福音書 9:61–62; 使徒行伝 20:37"> エリシャは牛を捨て、エリヤのあとに走ってきて言った、「わたしの父母に口づけさせてください。そして後あなたに従いましょう」。エリヤは彼に言った、「行ってきなさい。わたしはあなたに何をしましたか」。</span>
<span className="v" id="v21" data-v="21" data-xref="サムエル記下 24:22; テモテヘの第二の手紙 4:11; ピレモンヘの手紙 1:13"> エリシャは彼を離れて帰り、ひとくびきの牛を取って殺し、牛のくびきを燃やしてその肉を煮、それを民に与えて食べさせ、立って行ってエリヤに従い、彼に仕えた。</span>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ペテロの第一の手紙 1:5; テサロニケ人への第一の手紙 5:23; ペテロの第一の手紙 2:9"> イエス・キリストの僕またヤコブの兄弟であるユダから、父なる神に愛され、イエス・キリストに守られている召された人々へ。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="ペテロの第二の手紙 1:2; ペテロの第一の手紙 1:2; ヨハネの黙示録 1:4–6"> あわれみと平安と愛とが、あなたがたに豊かに加わるように。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="テモテヘの第一の手紙 6:12; ピリピ人への手紙 1:27; ユダの手紙 1:20"> 愛する者たちよ。わたしたちが共にあずかっている救について、あなたがたに書きおくりたいと心から願っていたので、聖徒たちによって、ひとたび伝えられた信仰のために戦うことを勧めるように、手紙をおくる必要を感じるに至った。</span>
<span className="v" id="v4" data-v="4" data-xref="ペテロの第二の手紙 2:1–3; ガラテヤ人への手紙 2:4; ペテロの第二の手紙 2:10"> そのわけは、不信仰な人々がしのび込んできて、わたしたちの神の恵みを放縦な生活に変え、唯一の君であり、わたしたちの主であるイエス・キリストを否定しているからである。彼らは、このようなさばきを受けることに、昔から予告されているのである。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="民数記 26:64–65; ヘブル人への手紙 3:16–2; コリント人への第一の手紙 10:1–12"> あなたがたはみな、じゅうぶんに知っていることではあるが、主が民をエジプトの地から救い出して後、不信仰な者を滅ぼされたことを、思い起してもらいたい。</span>
<span className="v" id="v6" data-v="6" data-xref="ペテロの第二の手紙 2:4; マタイによる福音書 25:41; エペソ人への手紙 6:12"> 主は、自分たちの地位を守ろうとはせず、そのおるべき所を捨て去った御使たちを、大いなる日のさばきのために、永久にしばりつけたまま、暗やみの中に閉じ込めておかれた。</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 29:23; ペテロの第二の手紙 2:6; ローマ人への手紙 1:26–27"> ソドム、ゴモラも、まわりの町々も、同様であって、同じように淫行にふけり、不自然な肉欲に走ったので、永遠の火の刑罰を受け、人々の見せしめにされている。</span>
<span className="v" id="v8" data-v="8" data-xref="ヘブル人への手紙 13:17; ペテロの第一の手紙 2:17; ペテロの第二の手紙 2:10–12"> しかし、これと同じように、これらの人々は、夢に迷わされて肉を汚し、権威ある者たちを軽んじ、栄光ある者たちをそしっている。</span>
<span className="v" id="v9" data-v="9" data-xref="ゼカリヤ書 3:2; ペテロの第二の手紙 2:11; 申命記 34:6"> 御使のかしらミカエルは、モーセの死体について悪魔と論じ争った時、相手をののしりさばくことはあえてせず、ただ、「主がおまえを戒めて下さるように」と言っただけであった。</span>
<span className="v" id="v10" data-v="10" data-xref="ペテロの第二の手紙 2:12; ローマ人への手紙 1:21–22"> しかし、この人々は自分が知りもしないことをそしり、また、分別のない動物のように、ただ本能的な知識にあやまられて、自らの滅亡を招いている。</span>
<span className="v" id="v11" data-v="11" data-xref="ペテロの第二の手紙 2:15; ヨハネの第一の手紙 3:12; ヨハネの黙示録 2:14"> 彼らはわざわいである。彼らはカインの道を行き、利のためにバラムの惑わしに迷い入り、コラのような反逆をして滅んでしまうのである。</span>
<span className="v" id="v12" data-v="12" data-xref="ペテロの第二の手紙 2:17–20; マタイによる福音書 15:13; エゼキエル書 34:8"> 彼らは、あなたがたの愛餐に加わるが、それを汚し、無遠慮に宴会に同席して、自分の腹を肥やしている。彼らは、いわば、風に吹きまわされる水なき雲、実らない枯れ果てて、抜き捨てられた秋の木、</span>
<span className="v" id="v13" data-v="13" data-xref="ペテロの第二の手紙 2:17; ピリピ人への手紙 3:19; イザヤ書 57:20"> 自分の恥をあわにして出す海の荒波、さまよう星である。彼らには、まっくらなやみが永久に用意されている。</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 33:2; 詩篇 50:3–5; ヘブル人への手紙 11:5–6"> アダムから七代目にあたるエノクも彼らについて預言して言った、「見よ、主は無数の聖徒たちを率いてこられた。</span>
<span className="v" id="v15" data-v="15" data-xref="ローマ人への手紙 2:16; 伝道の書 11:9; コリント人への第一の手紙 4:5"> それは、すべての者にさばきを行うためであり、また、不信心な者が、信仰を無視して犯したすべての不信心なしわざと、さらに、不信心な罪人が主にそむいて語ったすべての暴言とを責めるためである」。</span>
<span className="v" id="v16" data-v="16" data-xref="ペテロの第二の手紙 2:18; ペテロの第二の手紙 2:10; ピリピ人への手紙 2:14"> 彼らは不平をならべ、不満を鳴らす者であり、自分の欲のままに生活し、その口は大言を吐き、利のために人にへつらう者である。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="ペテロの第二の手紙 3:2; ヨハネの第一の手紙 4:6; エペソ人への手紙 4:11"> 愛する者たちよ。わたしたちの主イエス・キリストの使徒たちが予告した言葉を思い出しなさい。</span>
<span className="v" id="v18" data-v="18" data-xref="ペテロの第二の手紙 3:3; テモテヘの第二の手紙 4:3; テモテヘの第二の手紙 3:1–5"> 彼らはあなたがたにこう言った、「終りの時に、あざける者たちがあらわれて、自分の不信心な欲のままに生活するであろう」。</span>
<span className="v" id="v19" data-v="19" data-xref="コリント人への第一の手紙 2:14; 箴言 18:1; ローマ人への手紙 8:9"> 彼らは分派をつくる者、肉に属する者、御霊を持たない者たちである。</span>
<span className="v" id="v20" data-v="20" data-xref="エペソ人への手紙 6:18; ローマ人への手紙 8:26–27; コリント人への第一の手紙 14:15"> しかし、愛する者たちよ。あなたがたは、最も神聖な信仰の上に自らを築き上げ、聖霊によって祈り、</span>
<span className="v" id="v21" data-v="21" data-xref="ヨハネの第一の手紙 4:16; 哀歌 3:25–26; ヘブル人への手紙 9:28"> 神の愛の中に自らを保ち、永遠のいのちを目あてとして、わたしたちの主イエス・キリストのあわれみを待ち望みなさい。</span>
<span className="v" id="v22" data-v="22" data-xref="ヤコブの手紙 5:19–20; ガラテヤ人への手紙 6:1; ヨハネの第一の手紙 5:16–18"> 疑いをいだく人々があれば、彼らをあわれみ、</span>
<span className="v" id="v23" data-v="23" data-xref="テモテヘの第一の手紙 4:16; コリント人への第一の手紙 15:33; ヨハネの黙示録 3:4"> 火の中から引き出して救ってやりなさい。また、そのほかの人たちを、おそれの心をもってあわれみなさい。しかし、肉に汚れた者に対しては、その下着さえも忌みきらいなさい。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="テモテヘの第二の手紙 4:18; エペソ人への手紙 3:20; コロサイ人への手紙 1:22"> あなたがたを守ってつまずかない者とし、また、その栄光のまえに傷なき者として、喜びのうちに立たせて下さるかた、</span>
<span className="v" id="v25" data-v="25" data-xref="テモテヘの第一の手紙 1:17; ヨハネの黙示録 5:13–14; ペテロの第一の手紙 5:10–11"> すなわち、わたしたちの救主なる唯一の神に、栄光、大能、力、権威が、わたしたちの主イエス・キリストによって、世々の初めにも、今も、また、世々限りなく、あるように、アァメン。</span>
</div>

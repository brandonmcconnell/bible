<div className="bible-chapter" lang="ja" dir="ltr" data-lang="ja" data-translation="jpn-kou" data-translation-id="jpn_kou" data-translation-label="口語訳" data-book="JHN" data-book-slug="john" data-book-name="ヨハネによる福音書" data-chapter="9" data-verses="41">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> イエスが道をとおっておられるとき、生れつきの盲人を見られた。</span>
<span className="v" id="v2" data-v="2" data-xref="ルカによる福音書 13:2; ヨハネによる福音書 9:34; 使徒行伝 28:4"> 弟子たちはイエスに尋ねて言った、「先生、この人が生れつき盲人なのは、だれが罪を犯したためですか。本人ですか、それともその両親ですか」。</span>
<span className="v" id="v3" data-v="3" data-xref="ヨハネによる福音書 11:4; ヨハネによる福音書 11:40; 伝道の書 9:1–2"> イエスは答えられた、「本人が罪を犯したのでもなく、また、その両親が犯したのでもない。ただ神のみわざが、彼の上に現れるためである。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネによる福音書 12:35; エペソ人への手紙 5:16; ヨハネによる福音書 4:34"> わたしたちは、わたしをつかわされたかたのわざを、昼の間にしなければならない。夜が来る。すると、だれも働けなくなる。</span>
<span className="v" id="v5" data-v="5" data-xref="ヨハネによる福音書 8:12; ヨハネによる福音書 12:46; 使徒行伝 13:47"> わたしは、この世にいる間は、世の光である」。</span>
<span className="v" id="v6" data-v="6" data-xref="マルコによる福音書 8:23; マルコによる福音書 7:33; ヨハネの黙示録 3:18"> イエスはそう言って、地につばきをし、そのつばきで、どろをつくり、そのどろを盲人の目に塗って言われた、</span>
<span className="v" id="v7" data-v="7" data-xref="イザヤ書 35:5; ヨハネによる福音書 9:11; ヨハネによる福音書 11:37"> 「シロアム（つかわされた者、の意）の池に行って洗いなさい」。そこで彼は行って洗った。そして見えるようになって、帰って行った。</span>
<span className="v" id="v8" data-v="8" data-xref="サムエル記上 2:8; サムエル記上 21:11; ルカによる福音書 18:35"> 近所の人々や、彼がもと、こじきであったのを見知っていた人々が言った、「この人は、すわってこじきをしていた者ではないか」。</span>
<span className="v" id="v9" data-v="9"> ある人々は「その人だ」と言い、他の人々は「いや、ただあの人に似ているだけだ」と言った。しかし、本人は「わたしがそれだ」と言った。</span>
<span className="v" id="v10" data-v="10" data-xref="ヨハネによる福音書 9:26; ヨハネによる福音書 9:21; 伝道の書 11:5"> そこで人々は彼に言った、「では、おまえの目はどうしてあいたのか」。</span>
<span className="v" id="v11" data-v="11" data-xref="ヨハネによる福音書 9:6–7; ヨハネによる福音書 9:27; エレミヤ書 36:17"> 彼は答えた、「イエスというかたが、どろをつくって、わたしの目に塗り、『シロアムに行って洗え』と言われました。それで、行って洗うと、見えるようになりました」。</span>
<span className="v" id="v12" data-v="12" data-xref="ヨハネによる福音書 5:11–13; 出エジプト記 2:18–20; ヨハネによる福音書 7:11"> 人々は彼に言った、「その人はどこにいるのか」。彼は「知りません」と答えた。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="ヨハネによる福音書 11:57; ヨハネによる福音書 11:46–47; ヨハネによる福音書 12:42"> 人々は、もと盲人であったこの人を、パリサイ人たちのところにつれて行った。</span>
<span className="v" id="v14" data-v="14" data-xref="ヨハネによる福音書 5:9; ルカによる福音書 13:10–17; マタイによる福音書 12:1–14"> イエスがどろをつくって彼の目をあけたのは、安息日であった。</span>
<span className="v" id="v15" data-v="15" data-xref="ヨハネによる福音書 9:26–27; ヨハネによる福音書 9:10–11"> パリサイ人たちもまた、「どうして見えるようになったのか」、と彼に尋ねた。彼は答えた、「あのかたがわたしの目にどろを塗り、わたしがそれを洗い、そして見えるようになりました」。</span>
<span className="v" id="v16" data-v="16" data-xref="ヨハネによる福音書 7:43; ヨハネによる福音書 10:19; マタイによる福音書 12:2"> そこで、あるパリサイ人たちが言った、「その人は神からきた人ではない。安息日を守っていないのだから」。しかし、ほかの人々は言った、「罪のある人が、どうしてそのようなしるしを行うことができようか」。そして彼らの間に分争が生じた。</span>
<span className="v" id="v17" data-v="17" data-xref="ヨハネによる福音書 4:19; ヨハネによる福音書 6:14; 使徒行伝 3:22–26"> そこで彼らは、もう一度この盲人に聞いた、「おまえの目をあけてくれたその人を、どう思うか」。「預言者だと思います」と彼は言った。</span>
<span className="v" id="v18" data-v="18" data-xref="ヘブル人への手紙 3:15–19; ヨハネによる福音書 5:44; イザヤ書 26:11"> ユダヤ人たちは、彼がもと盲人であったが見えるようになったことを、まだ信じなかった。ついに彼らは、目が見えるようになったこの人の両親を呼んで、</span>
<span className="v" id="v19" data-v="19" data-xref="ヨハネによる福音書 9:8–9; 使徒行伝 4:14; 使徒行伝 3:10"> 尋ねて言った、「これが、生れつき盲人であったと、おまえたちの言っているむすこか。それではどうして、いま目が見えるのか」。</span>
<span className="v" id="v20" data-v="20"> 両親は答えて言った、「これがわたしどものむすこであること、また生れつき盲人であったことは存じています。</span>
<span className="v" id="v21" data-v="21"> しかし、どうしていま見えるようになったのか、それは知りません。また、だれがその目をあけて下さったのかも知りません。あれに聞いて下さい。あれはもうおとなですから、自分のことは自分で話せるでしょう」。</span>
<span className="v" id="v22" data-v="22" data-xref="ヨハネによる福音書 7:13; ヨハネによる福音書 16:2; ルカによる福音書 6:22"> 両親はユダヤ人たちを恐れていたので、こう答えたのである。それは、もしイエスをキリストと告白する者があれば、会堂から追い出すことに、ユダヤ人たちが既に決めていたからである。</span>
<span className="v" id="v23" data-v="23" data-xref="ヨハネによる福音書 9:21"> 彼の両親が「おとなですから、あれに聞いて下さい」と言ったのは、そのためであった。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="ヨシュア記 7:19; ヨハネによる福音書 9:16; ヨハネによる福音書 8:49"> そこで彼らは、盲人であった人をもう一度呼んで言った、「神に栄光を帰するがよい。あの人が罪人であることは、わたしたちにはわかっている」。</span>
<span className="v" id="v25" data-v="25" data-xref="ヨハネの第一の手紙 5:10; ヨハネによる福音書 9:30; ヨハネによる福音書 5:11"> すると彼は言った、「あのかたが罪人であるかどうか、わたしは知りません。ただ一つのことだけ知っています。わたしは盲であったが、今は見えるということです」。</span>
<span className="v" id="v26" data-v="26"> そこで彼らは言った、「その人はおまえに何をしたのか。どんなにしておまえの目をあけたのか」。</span>
<span className="v" id="v27" data-v="27" data-xref="ルカによる福音書 22:67; ヨハネによる福音書 9:10–15"> 彼は答えた、「そのことはもう話してあげたのに、聞いてくれませんでした。なぜまた聞こうとするのですか。あなたがたも、あの人の弟子になりたいのですか」。</span>
<span className="v" id="v28" data-v="28" data-xref="ローマ人への手紙 2:17; ヨハネによる福音書 7:19; マタイによる福音書 27:39"> そこで彼らは彼をののしって言った、「おまえはあれの弟子だが、わたしたちはモーセの弟子だ。</span>
<span className="v" id="v29" data-v="29" data-xref="ヨハネによる福音書 8:14; 民数記 12:2–7; 使徒行伝 7:35"> モーセに神が語られたということは知っている。だが、あの人がどこからきた者か、わたしたちは知らぬ」。</span>
<span className="v" id="v30" data-v="30" data-xref="ヨハネによる福音書 12:37; 詩篇 119:18; イザヤ書 29:18"> そこで彼が答えて言った、「わたしの目をあけて下さったのに、そのかたがどこからきたか、ご存じないとは、不思議千万です。</span>
<span className="v" id="v31" data-v="31" data-xref="箴言 15:29; イザヤ書 1:15; 箴言 28:9"> わたしたちはこのことを知っています。神は罪人の言うことはお聞きいれになりませんが、神を敬い、そのみこころを行う人の言うことは、聞きいれて下さいます。</span>
<span className="v" id="v32" data-v="32" data-xref="イザヤ書 64:4; ヨハネの黙示録 16:18; ヨブ記 20:4"> 生れつき盲であった者の目をあけた人があるということは、世界が始まって以来、聞いたことがありません。</span>
<span className="v" id="v33" data-v="33" data-xref="ヨハネによる福音書 9:16; ヨハネによる福音書 3:2; 使徒行伝 5:38–39"> もしあのかたが神からきた人でなかったら、何一つできなかったはずです」。</span>
<span className="v" id="v34" data-v="34" data-xref="ヨハネによる福音書 9:22; ヨハネによる福音書 9:2; イザヤ書 66:5"> これを聞いて彼らは言った、「おまえは全く罪の中に生れていながら、わたしたちを教えようとするのか」。そして彼を外へ追い出した。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="ヨハネによる福音書 20:31; ヨハネの第一の手紙 5:13; ヨハネによる福音書 10:36"> イエスは、その人が外へ追い出されたことを聞かれた。そして彼に会って言われた、「あなたは人の子を信じるか」。</span>
<span className="v" id="v36" data-v="36" data-xref="ローマ人への手紙 10:14; 雅歌 5:9; ヨハネによる福音書 1:38"> 彼は答えて言った、「主よ、それはどなたですか。そのかたを信じたいのですが」。</span>
<span className="v" id="v37" data-v="37" data-xref="ヨハネによる福音書 4:26; 詩篇 25:8–9; ヨハネによる福音書 14:21–23"> イエスは彼に言われた、「あなたは、もうその人に会っている。今あなたと話しているのが、その人である」。</span>
<span className="v" id="v38" data-v="38" data-xref="マタイによる福音書 14:33; マタイによる福音書 28:9; ルカによる福音書 24:52"> すると彼は、「主よ、信じます」と言って、イエスを拝した。</span>
<span className="v" id="v39" data-v="39" data-xref="ヨハネによる福音書 3:19; ヨハネによる福音書 12:46; 使徒行伝 26:18"> そこでイエスは言われた、「わたしがこの世にきたのは、さばくためである。すなわち、見えない人たちが見えるようになり、見える人たちが見えないようになるためである」。</span>
<span className="v" id="v40" data-v="40" data-xref="ヨハネの黙示録 3:17; マタイによる福音書 15:12–14; ヨハネによる福音書 7:47–52"> そこにイエスと一緒にいたあるパリサイ人たちが、それを聞いてイエスに言った、「それでは、わたしたちも盲なのでしょうか」。</span>
<span className="v" id="v41" data-v="41" data-xref="イザヤ書 5:21; ヨハネによる福音書 15:22–24; ヨハネの第一の手紙 1:8–10"> イエスは彼らに言われた、「もしあなたがたが盲人であったなら、罪はなかったであろう。しかし、今あなたがたが『見える』と言い張るところに、あなたがたの罪がある。</span>
</div>

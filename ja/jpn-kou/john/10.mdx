<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マタイによる福音書 7:15; ヨハネによる福音書 10:8–10; ローマ人への手紙 16:18"> よくよくあなたがたに言っておく。羊の囲いにはいるのに、門からでなく、ほかの所からのりこえて来る者は、盗人であり、強盗である。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネによる福音書 10:14; 使徒行伝 20:28; ペテロの第一の手紙 5:4"> 門からはいる者は、羊の羊飼である。</span>
<span className="v" id="v3" data-v="3" data-xref="エゼキエル書 34:11–16; テモテヘの第二の手紙 2:19; ヨハネによる福音書 10:4"> 門番は彼のために門を開き、羊は彼の声を聞く。そして彼は自分の羊の名をよんで連れ出す。</span>
<span className="v" id="v4" data-v="4" data-xref="申命記 1:30; ヨハネによる福音書 10:16; ヨハネによる福音書 12:26"> 自分の羊をみな出してしまうと、彼は羊の先頭に立って行く。羊はその声を知っているので、彼について行くのである。</span>
<span className="v" id="v5" data-v="5" data-xref="ヨハネの第一の手紙 4:5–6; コロサイ人への手紙 2:6–10; マルコによる福音書 4:24"> ほかの人には、ついて行かないで逃げ去る。その人の声を知らないからである」。</span>
<span className="v" id="v6" data-v="6" data-xref="イザヤ書 56:11; 詩篇 82:5; 箴言 28:5"> イエスは彼らにこの比喩を話されたが、彼らは自分たちにお話しになっているのが何のことだか、わからなかった。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="ヨハネによる福音書 14:6; エペソ人への手紙 2:18; ヨハネによる福音書 10:1"> そこで、イエスはまた言われた、「よくよくあなたがたに言っておく。わたしは羊の門である。</span>
<span className="v" id="v8" data-v="8" data-xref="エゼキエル書 34:2; エレミヤ書 23:1; ヨハネによる福音書 10:1"> わたしよりも前にきた人は、みな盗人であり、強盗である。羊は彼らに聞き従わなかった。</span>
<span className="v" id="v9" data-v="9" data-xref="ヨハネによる福音書 14:6; エペソ人への手紙 2:18; ヨハネによる福音書 10:7"> わたしは門である。わたしをとおってはいる者は救われ、また出入りし、牧草にありつくであろう。</span>
<span className="v" id="v10" data-v="10" data-xref="ルカによる福音書 19:10; ヨハネによる福音書 6:51; ヨハネによる福音書 12:47"> 盗人が来るのは、盗んだり、殺したり、滅ぼしたりするためにほかならない。わたしがきたのは、羊に命を得させ、豊かに得させるためである。</span>
<span className="v" id="v11" data-v="11" data-xref="ヨハネによる福音書 10:14–15; 詩篇 23:1; ヨハネによる福音書 15:13"> わたしはよい羊飼である。よい羊飼は、羊のために命を捨てる。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行伝 20:29; ゼカリヤ書 11:16–17; エゼキエル書 34:2–6"> 羊飼ではなく、羊が自分のものでもない雇人は、おおかみが来るのを見ると、羊をすてて逃げ去る。そして、おおかみは羊を奪い、また追い散らす。</span>
<span className="v" id="v13" data-v="13" data-xref="ピリピ人への手紙 2:20; ヨハネによる福音書 12:6; 使徒行伝 18:17"> 彼は雇人であって、羊のことを心にかけていないからである。</span>
<span className="v" id="v14" data-v="14" data-xref="ヨハネによる福音書 10:27; ヨハネによる福音書 10:11; テモテヘの第二の手紙 2:19"> わたしはよい羊飼であって、わたしの羊を知り、わたしの羊はまた、わたしを知っている。</span>
<span className="v" id="v15" data-v="15" data-xref="ガラテヤ人への手紙 1:4; ヨハネによる福音書 10:11; イザヤ書 53:10"> それはちょうど、父がわたしを知っておられ、わたしが父を知っているのと同じである。そして、わたしは羊のために命を捨てるのである。</span>
<span className="v" id="v16" data-v="16" data-xref="イザヤ書 56:8; ヨハネによる福音書 11:52; ペテロの第一の手紙 2:25"> わたしにはまた、この囲いにいない他の羊がある。わたしは彼らをも導かねばならない。彼らも、わたしの声に聞き従うであろう。そして、ついに一つの群れ、ひとりの羊飼となるであろう。</span>
<span className="v" id="v17" data-v="17" data-xref="ヨハネによる福音書 10:18; ヨハネによる福音書 10:11; ヘブル人への手紙 2:9"> 父は、わたしが自分の命を捨てるから、わたしを愛して下さるのである。命を捨てるのは、それを再び得るためである。</span>
<span className="v" id="v18" data-v="18" data-xref="ヘブル人への手紙 2:9; テトスヘの手紙 2:14; ヨハネによる福音書 2:19–21"> だれかが、わたしからそれを取り去るのではない。わたしが、自分からそれを捨てるのである。わたしには、それを捨てる力があり、またそれを受ける力もある。これはわたしの父から授かった定めである」。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="ヨハネによる福音書 9:16; コリント人への第一の手紙 3:3; ヨハネによる福音書 7:40–43"> これらの言葉を語られたため、ユダヤ人の間にまたも分争が生じた。</span>
<span className="v" id="v20" data-v="20" data-xref="ヨハネによる福音書 7:20; マルコによる福音書 3:21; ヨハネによる福音書 8:47–48"> そのうちの多くの者が言った、「彼は悪霊に取りつかれて、気が狂っている。どうして、あなたがたはその言うことを聞くのか」。</span>
<span className="v" id="v21" data-v="21" data-xref="出エジプト記 4:11; イザヤ書 35:5–6; 詩篇 94:9"> 他の人々は言った、「それは悪霊に取りつかれた者の言葉ではない。悪霊は盲人の目をあけることができようか」。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22"> そのころ、エルサレムで宮きよめの祭が行われた。時は冬であった。</span>
<span className="v" id="v23" data-v="23" data-xref="使徒行伝 5:12; 使徒行伝 3:11"> イエスは、宮の中にあるソロモンの廊を歩いておられた。</span>
<span className="v" id="v24" data-v="24" data-xref="ルカによる福音書 22:67–70; ヨハネによる福音書 1:19; ヨハネによる福音書 8:25"> するとユダヤ人たちが、イエスを取り囲んで言った、「いつまでわたしたちを不安のままにしておくのか。あなたがキリストであるなら、そうとはっきり言っていただきたい」。</span>
<span className="v" id="v25" data-v="25" data-xref="ヨハネによる福音書 10:38; ヨハネによる福音書 8:58; ヨハネによる福音書 14:11"> イエスは彼らに答えられた、「わたしは話したのだが、あなたがたは信じようとしない。わたしの父の名によってしているすべてのわざが、わたしのことをあかししている。</span>
<span className="v" id="v26" data-v="26" data-xref="ヨハネによる福音書 8:47; コリント人への第二の手紙 4:3–4; ヨハネによる福音書 12:37–40"> あなたがたが信じないのは、わたしの羊でないからである。</span>
<span className="v" id="v27" data-v="27" data-xref="ヨハネによる福音書 10:16; ヨハネによる福音書 10:14; ヨハネの黙示録 3:20"> わたしの羊はわたしの声に聞き従う。わたしは彼らを知っており、彼らはわたしについて来る。</span>
<span className="v" id="v28" data-v="28" data-xref="ヨハネによる福音書 6:39–40; ヨハネによる福音書 6:37; ヨハネによる福音書 3:15–16"> わたしは、彼らに永遠の命を与える。だから、彼らはいつまでも滅びることがなく、また、彼らをわたしの手から奪い去る者はない。</span>
<span className="v" id="v29" data-v="29" data-xref="ヨハネによる福音書 6:37; ヨハネによる福音書 17:2; ヨハネによる福音書 17:9"> わたしの父がわたしに下さったものは、すべてにまさるものである。そしてだれも父のみ手から、それを奪い取ることはできない。</span>
<span className="v" id="v30" data-v="30" data-xref="ヨハネによる福音書 1:1–2; ヨハネによる福音書 14:9; ヨハネによる福音書 17:21–23"> わたしと父とは一つである」。</span>
<span className="v" id="v31" data-v="31" data-xref="ヨハネによる福音書 5:18; ヨハネによる福音書 8:59; サムエル記上 30:6"> そこでユダヤ人たちは、イエスを打ち殺そうとして、また石を取りあげた。</span>
<span className="v" id="v32" data-v="32" data-xref="ヨハネの第一の手紙 3:12; ヨハネによる福音書 5:36; 詩篇 35:12"> するとイエスは彼らに答えられた、「わたしは、父による多くのよいわざを、あなたがたに示した。その中のどのわざのために、わたしを石で打ち殺そうとするのか」。</span>
<span className="v" id="v33" data-v="33" data-xref="ヨハネによる福音書 5:18; レビ記 24:16; ヨハネによる福音書 10:30"> ユダヤ人たちは答えた、「あなたを石で殺そうとするのは、よいわざをしたからではなく、神を汚したからである。また、あなたは人間であるのに、自分を神としているからである」。</span>
<span className="v" id="v34" data-v="34" data-xref="詩篇 82:6–7; 出エジプト記 7:1; 詩篇 82:1"> イエスは彼らに答えられた、「あなたがたの律法に、『わたしは言う、あなたがたは神々である』と書いてあるではないか。</span>
<span className="v" id="v35" data-v="35" data-xref="マタイによる福音書 24:35; ローマ人への手紙 13:1; ルカによる福音書 16:17"> 神の言を託された人々が、神々といわれておるとすれば、（そして聖書の言は、すたることがあり得ない）</span>
<span className="v" id="v36" data-v="36" data-xref="ヨハネによる福音書 5:17–18; ヨハネによる福音書 3:17; エレミヤ書 1:5"> 父が聖別して、世につかわされた者が、『わたしは神の子である』と言ったからとて、どうして『あなたは神を汚す者だ』と言うのか。</span>
<span className="v" id="v37" data-v="37" data-xref="ヨハネによる福音書 15:24; ヨハネによる福音書 10:25; ヨハネによる福音書 12:37–40"> もしわたしが父のわざを行わないとすれば、わたしを信じなくてもよい。</span>
<span className="v" id="v38" data-v="38" data-xref="ヨハネによる福音書 14:20; ヨハネによる福音書 10:25; ヨハネによる福音書 10:30"> しかし、もし行っているなら、たといわたしを信じなくても、わたしのわざを信じるがよい。そうすれば、父がわたしにおり、また、わたしが父におることを知って悟るであろう」。</span>
<span className="v" id="v39" data-v="39" data-xref="ヨハネによる福音書 7:30; ヨハネによる福音書 8:59; ヨハネによる福音書 7:44"> そこで、彼らはまたイエスを捕えようとしたが、イエスは彼らの手をのがれて、去って行かれた。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="ヨハネによる福音書 1:28; ヨハネによる福音書 11:54; ヨハネによる福音書 7:1"> さて、イエスはまたヨルダンの向こう岸、すなわち、ヨハネが初めにバプテスマを授けていた所に行き、そこに滞在しておられた。</span>
<span className="v" id="v41" data-v="41" data-xref="ヨハネによる福音書 1:33–34; ヨハネによる福音書 1:29–30; マルコによる福音書 1:37"> 多くの人々がイエスのところにきて、互に言った、「ヨハネはなんのしるしも行わなかったが、ヨハネがこのかたについて言ったことは、皆ほんとうであった」。</span>
<span className="v" id="v42" data-v="42" data-xref="ヨハネによる福音書 4:41; ヨハネによる福音書 2:23; ヨハネによる福音書 7:31"> そして、そこで多くの者がイエスを信じた。</span>
</div>

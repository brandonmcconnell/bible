<div className="bible-chapter" lang="ja" dir="ltr" data-lang="ja" data-translation="jpn-kou" data-translation-id="jpn_kou" data-translation-label="口語訳" data-book="JHN" data-book-slug="john" data-book-name="ヨハネによる福音書" data-chapter="16" data-verses="33">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ペテロの第一の手紙 2:8; マタイによる福音書 13:21; マタイによる福音書 26:31–33"> わたしがこれらのことを語ったのは、あなたがたがつまずくことのないためである。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネによる福音書 9:22; 使徒行伝 26:9–11; ローマ人への手紙 10:2–3"> 人々はあなたがたを会堂から追い出すであろう。更にあなたがたを殺す者がみな、それによって自分たちは神に仕えているのだと思う時が来るであろう。</span>
<span className="v" id="v3" data-v="3" data-xref="ヨハネによる福音書 15:21; ヨハネによる福音書 17:25; ヨハネによる福音書 8:55"> 彼らがそのようなことをするのは、父をもわたしをも知らないからである。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネによる福音書 14:29; マルコによる福音書 13:23; ヨハネによる福音書 17:12–13"> わたしがあなたがたにこれらのことを言ったのは、彼らの時がきた場合、わたしが彼らについて言ったことを、思い起させるためである。これらのことを初めから言わなかったのは、わたしがあなたがたと一緒にいたからである。</span>
<span className="v" id="v5" data-v="5" data-xref="ヨハネによる福音書 13:36; ヨハネによる福音書 7:33; ヨハネによる福音書 16:28"> けれども今わたしは、わたしをつかわされたかたのところに行こうとしている。しかし、あなたがたのうち、だれも『どこへ行くのか』と尋ねる者はない。</span>
<span className="v" id="v6" data-v="6" data-xref="ヨハネによる福音書 14:1; ヨハネによる福音書 16:20–22; ルカによる福音書 24:17"> かえって、わたしがこれらのことを言ったために、あなたがたの心は憂いで満たされている。</span>
<span className="v" id="v7" data-v="7" data-xref="ヨハネによる福音書 14:26; ヨハネによる福音書 14:16–17; ヨハネによる福音書 15:26"> しかし、わたしはほんとうのことをあなたがたに言うが、わたしが去って行くことは、あなたがたの益になるのだ。わたしが去って行かなければ、あなたがたのところに助け主はこないであろう。もし行けば、それをあなたがたにつかわそう。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行伝 2:37; ユダの手紙 1:15; ゼカリヤ書 12:10"> それがきたら、罪と義とさばきとについて、世の人の目を開くであろう。</span>
<span className="v" id="v9" data-v="9" data-xref="ヨハネによる福音書 15:22–25; ヨハネによる福音書 8:23–24; ヨハネによる福音書 12:47–48"> 罪についてと言ったのは、彼らがわたしを信じないからである。</span>
<span className="v" id="v10" data-v="10" data-xref="コリント人への第二の手紙 5:21; ペテロの第一の手紙 3:18; ローマ人への手紙 10:3–4"> 義についてと言ったのは、わたしが父のみもとに行き、あなたがたは、もはやわたしを見なくなるからである。</span>
<span className="v" id="v11" data-v="11" data-xref="ヨハネによる福音書 12:31; ヨハネの第一の手紙 3:8; ヘブル人への手紙 2:14"> さばきについてと言ったのは、この世の君がさばかれるからである。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="マルコによる福音書 4:33; ヨハネによる福音書 15:15; コリント人への第一の手紙 3:1–2"> わたしには、あなたがたに言うべきことがまだ多くあるが、あなたがたは今はそれに堪えられない。</span>
<span className="v" id="v13" data-v="13" data-xref="ヨハネによる福音書 14:26; コリント人への第一の手紙 2:10–13; ヨハネによる福音書 14:17"> けれども真理の御霊が来る時には、あなたがたをあらゆる真理に導いてくれるであろう。それは自分から語るのではなく、その聞くところを語り、きたるべき事をあなたがたに知らせるであろう。</span>
<span className="v" id="v14" data-v="14" data-xref="ヨハネの第一の手紙 4:13–14; コリント人への第二の手紙 3:14–18; ヨハネによる福音書 15:26"> 御霊はわたしに栄光を得させるであろう。わたしのものを受けて、それをあなたがたに知らせるからである。</span>
<span className="v" id="v15" data-v="15" data-xref="ヨハネによる福音書 17:10; マタイによる福音書 11:27; ヨハネによる福音書 3:35"> 父がお持ちになっているものはみな、わたしのものである。御霊はわたしのものを受けて、それをあなたがたに知らせるのだと、わたしが言ったのは、そのためである。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="ヨハネによる福音書 7:33; 使徒行伝 1:3; ヨハネによる福音書 14:18–24"> しばらくすれば、あなたがたはもうわたしを見なくなる。しかし、またしばらくすれば、わたしに会えるであろう」。</span>
<span className="v" id="v17" data-v="17" data-xref="ヨハネによる福音書 16:16; マルコによる福音書 9:32; ヨハネによる福音書 16:5"> そこで、弟子たちのうちのある者は互に言い合った、「『しばらくすれば、わたしを見なくなる。またしばらくすれば、わたしに会えるであろう』と言われ、『わたしの父のところに行く』と言われたのは、いったい、どういうことなのであろう」。</span>
<span className="v" id="v18" data-v="18" data-xref="ルカによる福音書 24:25; マタイによる福音書 16:9–11; ヘブル人への手紙 5:12"> 彼らはまた言った、「『しばらくすれば』と言われるのは、どういうことか。わたしたちには、その言葉の意味がわからない」。</span>
<span className="v" id="v19" data-v="19" data-xref="ヨハネによる福音書 16:30; ヨハネによる福音書 16:16; ヨハネによる福音書 14:19"> イエスは、彼らが尋ねたがっていることに気がついて、彼らに言われた、「しばらくすればわたしを見なくなる、またしばらくすればわたしに会えるであろうと、わたしが言ったことで、互に論じ合っているのか。</span>
<span className="v" id="v20" data-v="20" data-xref="ヤコブの手紙 1:2; マタイによる福音書 5:4; 詩篇 126:5–6"> よくよくあなたがたに言っておく。あなたがたは泣き悲しむが、この世は喜ぶであろう。あなたがたは憂えているが、その憂いは喜びに変るであろう。</span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 113:9; イザヤ書 13:8; テサロニケ人への第一の手紙 5:3"> 女が子を産む場合には、その時がきたというので、不安を感じる。しかし、子を産んでしまえば、もはやその苦しみをおぼえてはいない。ひとりの人がこの世に生れた、という喜びがあるためである。</span>
<span className="v" id="v22" data-v="22" data-xref="ペテロの第一の手紙 1:8; 使徒行伝 13:52; ヨハネによる福音書 16:6"> このように、あなたがたにも今は不安がある。しかし、わたしは再びあなたがたと会うであろう。そして、あなたがたの心は喜びに満たされるであろう。その喜びをあなたがたから取り去る者はいない。</span>
<span className="v" id="v23" data-v="23" data-xref="ヨハネによる福音書 15:7; ヨハネによる福音書 14:13–14; マタイによる福音書 21:22"> その日には、あなたがたがわたしに問うことは、何もないであろう。よくよくあなたがたに言っておく。あなたがたが父に求めるものはなんでも、わたしの名によって下さるであろう。</span>
<span className="v" id="v24" data-v="24" data-xref="マタイによる福音書 7:7–8; ヤコブの手紙 4:2–3; ヨハネによる福音書 15:11"> 今までは、あなたがたはわたしの名によって求めたことはなかった。求めなさい、そうすれば、与えられるであろう。そして、あなたがたの喜びが満ちあふれるであろう。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="ヨハネによる福音書 16:12; マルコによる福音書 4:13; マタイによる福音書 13:34–35"> わたしはこれらのことを比喩で話したが、もはや比喩では話さないで、あからさまに、父のことをあなたがたに話してきかせる時が来るであろう。</span>
<span className="v" id="v26" data-v="26" data-xref="ローマ人への手紙 8:34; ヨハネによる福音書 17:24; ヨハネによる福音書 17:19"> その日には、あなたがたは、わたしの名によって求めるであろう。わたしは、あなたがたのために父に願ってあげようとは言うまい。</span>
<span className="v" id="v27" data-v="27" data-xref="ヨハネによる福音書 14:21; ヨハネによる福音書 14:23; ヨハネによる福音書 17:23"> 父ご自身があなたがたを愛しておいでになるからである。それは、あなたがたがわたしを愛したため、また、わたしが神のみもとからきたことを信じたためである。</span>
<span className="v" id="v28" data-v="28" data-xref="ヨハネによる福音書 13:1; ヨハネによる福音書 13:3; ヨハネによる福音書 8:14"> わたしは父から出てこの世にきたが、またこの世を去って、父のみもとに行くのである」。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="ヨハネによる福音書 16:25"> 弟子たちは言った、「今はあからさまにお話しになって、少しも比喩ではお話しになりません。</span>
<span className="v" id="v30" data-v="30" data-xref="ヨハネによる福音書 21:17; ヨハネによる福音書 17:8; ヨハネによる福音書 16:17"> あなたはすべてのことをご存じであり、だれもあなたにお尋ねする必要のないことが、今わかりました。このことによって、わたしたちはあなたが神からこられたかたであると信じます」。</span>
<span className="v" id="v31" data-v="31" data-xref="ルカによる福音書 9:44–45; ヨハネによる福音書 13:38"> イエスは答えられた、「あなたがたは今信じているのか。</span>
<span className="v" id="v32" data-v="32" data-xref="ゼカリヤ書 13:7; マタイによる福音書 26:31; ヨハネによる福音書 8:29"> 見よ、あなたがたは散らされて、それぞれ自分の家に帰り、わたしをひとりだけ残す時が来るであろう。いや、すでにきている。しかし、わたしはひとりでいるのではない。父がわたしと一緒におられるのである。</span>
<span className="v" id="v33" data-v="33" data-xref="ヨハネによる福音書 14:27; ヨハネの第一の手紙 5:4; テサロニケ人への第二の手紙 3:16"> これらのことをあなたがたに話したのは、わたしにあって平安を得るためである。あなたがたは、この世ではなやみがある。しかし、勇気を出しなさい。わたしはすでに世に勝っている」。</span>
</div>

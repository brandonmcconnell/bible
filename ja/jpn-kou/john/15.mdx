<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="エレミヤ書 2:21; イザヤ書 27:2–3; コリント人への第一の手紙 3:9"> わたしはまことのぶどうの木、わたしの父は農夫である。</span>
<span className="v" id="v2" data-v="2" data-xref="マタイによる福音書 3:10; ヘブル人への手紙 12:10–11; マタイによる福音書 15:13"> わたしにつながっている枝で実を結ばないものは、父がすべてこれをとりのぞき、実を結ぶものは、もっと豊かに実らせるために、手入れしてこれをきれいになさるのである。</span>
<span className="v" id="v3" data-v="3" data-xref="ヨハネによる福音書 17:17; エペソ人への手紙 5:26; ペテロの第一の手紙 1:22"> あなたがたは、わたしが語った言葉によって既にきよくされている。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネの第一の手紙 2:6; ガラテヤ人への手紙 2:20; ヨハネによる福音書 8:31"> わたしにつながっていなさい。そうすれば、わたしはあなたがたとつながっていよう。枝がぶどうの木につながっていなければ、自分だけでは実を結ぶことができないように、あなたがたもわたしにつながっていなければ実を結ぶことができない。</span>
<span className="v" id="v5" data-v="5" data-xref="ピリピ人への手紙 4:13; コロサイ人への手紙 1:10; ヨハネによる福音書 15:16"> わたしはぶどうの木、あなたがたはその枝である。もし人がわたしにつながっており、またわたしがその人とつながっておれば、その人は実を豊かに結ぶようになる。わたしから離れては、あなたがたは何一つできないからである。</span>
<span className="v" id="v6" data-v="6" data-xref="マタイによる福音書 7:19; ヘブル人への手紙 6:7–8; マタイによる福音書 13:41"> 人がわたしにつながっていないならば、枝のように外に投げすてられて枯れる。人々はそれをかき集め、火に投げ入れて、焼いてしまうのである。</span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 37:4; ヨハネの第一の手紙 5:14; ヨハネによる福音書 14:13"> あなたがたがわたしにつながっており、わたしの言葉があなたがたにとどまっているならば、なんでも望むものを求めるがよい。そうすれば、与えられるであろう。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨハネによる福音書 8:31; マタイによる福音書 5:16; ピリピ人への手紙 1:11"> あなたがたが実を豊かに結び、そしてわたしの弟子となるならば、それによって、わたしの父は栄光をお受けになるであろう。</span>
<span className="v" id="v9" data-v="9" data-xref="ヨハネによる福音書 17:23–24; ヨハネによる福音書 17:26; ヨハネの第一の手紙 2:28"> 父がわたしを愛されたように、わたしもあなたがたを愛したのである。わたしの愛のうちにいなさい。</span>
<span className="v" id="v10" data-v="10" data-xref="ヨハネによる福音書 14:15; ヨハネの第一の手紙 5:3; ヨハネの第一の手紙 3:21–24"> もしわたしのいましめを守るならば、あなたがたはわたしの愛のうちにおるのである。それはわたしがわたしの父のいましめを守ったので、その愛のうちにおるのと同じである。</span>
<span className="v" id="v11" data-v="11" data-xref="ヨハネによる福音書 17:13; ローマ人への手紙 15:13; ヨハネによる福音書 16:24"> わたしがこれらのことを話したのは、わたしの喜びがあなたがたのうちにも宿るため、また、あなたがたの喜びが満ちあふれるためである。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="ヨハネの第一の手紙 4:21; ペテロの第一の手紙 4:8; ヨハネによる福音書 13:34"> わたしのいましめは、これである。わたしがあなたがたを愛したように、あなたがたも互に愛し合いなさい。</span>
<span className="v" id="v13" data-v="13" data-xref="ヨハネによる福音書 10:11; エペソ人への手紙 5:2; ローマ人への手紙 5:6–8"> 人がその友のために自分の命を捨てること、これよりも大きな愛はない。</span>
<span className="v" id="v14" data-v="14" data-xref="マタイによる福音書 12:50; ヨハネの第一の手紙 5:3; ヤコブの手紙 2:23"> あなたがたにわたしが命じることを行うならば、あなたがたはわたしの友である。</span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 25:14; コリント人への第一の手紙 2:9–12; マタイによる福音書 13:11"> わたしはもう、あなたがたを僕とは呼ばない。僕は主人のしていることを知らないからである。わたしはあなたがたを友と呼んだ。わたしの父から聞いたことを皆、あなたがたに知らせたからである。</span>
<span className="v" id="v16" data-v="16" data-xref="ヨハネによる福音書 15:19; エレミヤ書 1:5–7; エペソ人への手紙 2:10"> あなたがたがわたしを選んだのではない。わたしがあなたがたを選んだのである。そして、あなたがたを立てた。それは、あなたがたが行って実をむすび、その実がいつまでも残るためであり、また、あなたがたがわたしの名によって父に求めるものはなんでも、父が与えて下さるためである。</span>
<span className="v" id="v17" data-v="17" data-xref="ヨハネによる福音書 15:12; ヨハネの第一の手紙 3:14–17; ペテロの第一の手紙 2:17"> これらのことを命じるのは、あなたがたが互に愛し合うためである。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="ヨハネの第一の手紙 3:13; ヨハネによる福音書 7:7; マルコによる福音書 13:13"> もしこの世があなたがたを憎むならば、あなたがたよりも先にわたしを憎んだことを、知っておくがよい。</span>
<span className="v" id="v19" data-v="19" data-xref="ヨハネの第一の手紙 4:4–5; ヨハネによる福音書 17:14–16; エペソ人への手紙 1:4–11"> もしあなたがたがこの世から出たものであったなら、この世は、あなたがたを自分のものとして愛したであろう。しかし、あなたがたはこの世のものではない。かえって、わたしがあなたがたをこの世から選び出したのである。だから、この世はあなたがたを憎むのである。</span>
<span className="v" id="v20" data-v="20" data-xref="テモテヘの第二の手紙 3:12; ヨハネによる福音書 13:16; マタイによる福音書 10:24"> わたしがあなたがたに『僕はその主人にまさるものではない』と言ったことを、おぼえていなさい。もし人々がわたしを迫害したなら、あなたがたをも迫害するであろう。また、もし彼らがわたしの言葉を守っていたなら、あなたがたの言葉をも守るであろう。</span>
<span className="v" id="v21" data-v="21" data-xref="マタイによる福音書 10:22; ヨハネによる福音書 16:3; マタイによる福音書 10:18"> 彼らはわたしの名のゆえに、あなたがたに対してすべてそれらのことをするであろう。それは、わたしをつかわされたかたを彼らが知らないからである。</span>
<span className="v" id="v22" data-v="22" data-xref="ヨハネによる福音書 9:41; ヤコブの手紙 4:17; 使徒行伝 17:30"> もしわたしがきて彼らに語らなかったならば、彼らは罪を犯さないですんだであろう。しかし今となっては、彼らには、その罪について言いのがれる道がない。</span>
<span className="v" id="v23" data-v="23" data-xref="ヨハネによる福音書 8:40–42; ヨハネの第二の手紙 1:9; ヨハネの第一の手紙 2:23"> わたしを憎む者は、わたしの父をも憎む。</span>
<span className="v" id="v24" data-v="24" data-xref="ヨハネによる福音書 5:36; ヨハネによる福音書 14:9; ヨハネによる福音書 7:31"> もし、ほかのだれもがしなかったようなわざを、わたしが彼らの間でしなかったならば、彼らは罪を犯さないですんだであろう。しかし事実、彼らはわたしとわたしの父とを見て、憎んだのである。</span>
<span className="v" id="v25" data-v="25" data-xref="詩篇 109:3; 詩篇 69:4; 詩篇 35:19"> それは、『彼らは理由なしにわたしを憎んだ』と書いてある彼らの律法の言葉が成就するためである。</span>
<span className="v" id="v26" data-v="26" data-xref="ヨハネによる福音書 14:26; ヨハネによる福音書 14:16–17; ヨハネによる福音書 16:13–15"> わたしが父のみもとからあなたがたにつかわそうとしている助け主、すなわち、父のみもとから来る真理の御霊が下る時、それはわたしについてあかしをするであろう。</span>
<span className="v" id="v27" data-v="27" data-xref="ヨハネの第一の手紙 4:14; ヨハネによる福音書 21:24; 使徒行伝 10:39–42"> あなたがたも、初めからわたしと一緒にいたのであるから、あかしをするのである。</span>
</div>

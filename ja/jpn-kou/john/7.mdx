<div className="bible-chapter" lang="ja" dir="ltr" data-lang="ja" data-translation="jpn-kou" data-translation-id="jpn_kou" data-translation-label="口語訳" data-book="JHN" data-book-slug="john" data-book-name="ヨハネによる福音書" data-chapter="7" data-verses="53">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨハネによる福音書 5:16–18; ヨハネによる福音書 4:3; マタイによる福音書 21:38"> そののち、イエスはガリラヤを巡回しておられた。ユダヤ人たちが自分を殺そうとしていたので、ユダヤを巡回しようとはされなかった。</span>
<span className="v" id="v2" data-v="2" data-xref="ゼカリヤ書 14:16–19; 申命記 16:13–16; 出エジプト記 23:16–17"> 時に、ユダヤ人の仮庵の祭が近づいていた。</span>
<span className="v" id="v3" data-v="3" data-xref="マタイによる福音書 12:46; ヨハネによる福音書 7:5; ルカによる福音書 8:19"> そこで、イエスの兄弟たちがイエスに言った、「あなたがしておられるわざを弟子たちにも見せるために、ここを去りユダヤに行ってはいかがです。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネによる福音書 18:20; 箴言 18:1–2; マタイによる福音書 23:5"> 自分を公けにあらわそうと思っている人で、隠れて仕事をするものはありません。あなたがこれらのことをするからには、自分をはっきりと世にあらわしなさい」。</span>
<span className="v" id="v5" data-v="5" data-xref="マルコによる福音書 3:21; ヨハネによる福音書 1:11–13; ミカ書 7:5–6"> こう言ったのは、兄弟たちもイエスを信じていなかったからである。</span>
<span className="v" id="v6" data-v="6" data-xref="ヨハネによる福音書 7:8; ヨハネによる福音書 2:4; ヨハネによる福音書 7:30"> そこでイエスは彼らに言われた、「わたしの時はまだきていない。しかし、あなたがたの時はいつも備わっている。</span>
<span className="v" id="v7" data-v="7" data-xref="ヨハネによる福音書 15:18–19; ヨハネによる福音書 3:19; ガラテヤ人への手紙 4:16"> 世はあなたがたを憎み得ないが、わたしを憎んでいる。わたしが世のおこないの悪いことを、あかししているからである。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨハネによる福音書 7:6; ヨハネによる福音書 8:20; ヨハネによる福音書 7:30"> あなたがたこそ祭に行きなさい。わたしはこの祭には行かない。わたしの時はまだ満ちていないから」。</span>
<span className="v" id="v9" data-v="9"> 彼らにこう言って、イエスはガリラヤにとどまっておられた。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="アモス書 5:13; マタイによる福音書 10:16; イザヤ書 42:2–3"> しかし、兄弟たちが祭に行ったあとで、イエスも人目にたたぬように、ひそかに行かれた。</span>
<span className="v" id="v11" data-v="11" data-xref="ヨハネによる福音書 11:56"> ユダヤ人らは祭の時に、「あの人はどこにいるのか」と言って、イエスを捜していた。</span>
<span className="v" id="v12" data-v="12" data-xref="ヨハネによる福音書 7:40–43; ヨハネによる福音書 9:16; ヨハネによる福音書 7:32"> 群衆の中に、イエスについていろいろとうわさが立った。ある人々は、「あれはよい人だ」と言い、他の人々は、「いや、あれは群衆を惑わしている」と言った。</span>
<span className="v" id="v13" data-v="13" data-xref="ヨハネによる福音書 9:22; ヨハネによる福音書 19:38; ヨハネによる福音書 20:19"> しかし、ユダヤ人らを恐れて、イエスのことを公然と口にする者はいなかった。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="ヨハネによる福音書 7:28; ルカによる福音書 19:47; ヨハネによる福音書 7:37"> 祭も半ばになってから、イエスは宮に上って教え始められた。</span>
<span className="v" id="v15" data-v="15" data-xref="ルカによる福音書 4:22; マタイによる福音書 7:28–29; マタイによる福音書 13:54"> すると、ユダヤ人たちは驚いて言った、「この人は学問をしたこともないのに、どうして律法の知識をもっているのだろう」。</span>
<span className="v" id="v16" data-v="16" data-xref="ヨハネによる福音書 14:10; ヨハネによる福音書 14:24; ヨハネによる福音書 17:8"> そこでイエスは彼らに答えて言われた、「わたしの教はわたし自身の教ではなく、わたしをつかわされたかたの教である。</span>
<span className="v" id="v17" data-v="17" data-xref="ヨハネによる福音書 8:31–32; ヨハネによる福音書 8:43; エレミヤ書 31:33–34"> 神のみこころを行おうと思う者であれば、だれでも、わたしの語っているこの教が神からのものか、それとも、わたし自身から出たものか、わかるであろう。</span>
<span className="v" id="v18" data-v="18" data-xref="ヨハネによる福音書 5:41; コリント人への第一の手紙 10:31–33; ヨハネによる福音書 13:31–32"> 自分から出たことを語る者は、自分の栄光を求めるが、自分をつかわされたかたの栄光を求める者は真実であって、その人の内には偽りがない。</span>
<span className="v" id="v19" data-v="19" data-xref="ヨハネによる福音書 1:17; ヨハネによる福音書 11:53; マタイによる福音書 12:14"> モーセはあなたがたに律法を与えたではないか。それだのに、あなたがたのうちには、その律法を行う者がひとりもない。あなたがたは、なぜわたしを殺そうと思っているのか」。</span>
<span className="v" id="v20" data-v="20" data-xref="ヨハネによる福音書 10:20; ヨハネによる福音書 8:48; ヨハネによる福音書 8:52"> 群衆は答えた、「あなたは悪霊に取りつかれている。だれがあなたを殺そうと思っているものか」。</span>
<span className="v" id="v21" data-v="21" data-xref="ヨハネによる福音書 7:23; ヨハネによる福音書 5:2–11"> イエスは彼らに答えて言われた、「わたしが一つのわざをしたところ、あなたがたは皆それを見て驚いている。</span>
<span className="v" id="v22" data-v="22" data-xref="レビ記 12:3; 創世記 17:10–14; ローマ人への手紙 4:9–11"> モーセはあなたがたに割礼を命じたので、（これは、実は、モーセから始まったのではなく、先祖たちから始まったものである）あなたがたは安息日にも人に割礼を施している。</span>
<span className="v" id="v23" data-v="23" data-xref="マタイによる福音書 12:5; ヨハネによる福音書 5:14–16; マタイによる福音書 12:2"> もし、モーセの律法が破られないように、安息日であっても割礼を受けるのなら、安息日に人の全身を丈夫にしてやったからといって、どうして、そんなにおこるのか。</span>
<span className="v" id="v24" data-v="24" data-xref="イザヤ書 11:3–4; ヤコブの手紙 2:9; ヨハネによる福音書 8:15"> うわべで人をさばかないで、正しいさばきをするがよい」。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="ヨハネによる福音書 7:10–11"> さて、エルサレムのある人たちが言った、「この人は人々が殺そうと思っている者ではないか。</span>
<span className="v" id="v26" data-v="26" data-xref="テモテヘの第二の手紙 1:7–8; ヨハネによる福音書 7:48; ヨハネによる福音書 12:42"> 見よ、彼は公然と語っているのに、人々はこれに対して何も言わない。役人たちは、この人がキリストであることを、ほんとうに知っているのではなかろうか。</span>
<span className="v" id="v27" data-v="27" data-xref="ミカ書 5:2; ヨハネによる福音書 7:41–42; ヨハネによる福音書 6:42"> わたしたちはこの人がどこからきたのか知っている。しかし、キリストが現れる時には、どこから来るのか知っている者は、ひとりもいない」。</span>
<span className="v" id="v28" data-v="28" data-xref="ヨハネによる福音書 8:42; ヨハネによる福音書 8:19; ヨハネによる福音書 8:26"> イエスは宮の内で教えながら、叫んで言われた、「あなたがたは、わたしを知っており、また、わたしがどこからきたかも知っている。しかし、わたしは自分からきたのではない。わたしをつかわされたかたは真実であるが、あなたがたは、そのかたを知らない。</span>
<span className="v" id="v29" data-v="29" data-xref="ヨハネによる福音書 8:55; マタイによる福音書 11:27; ヨハネによる福音書 17:18"> わたしは、そのかたを知っている。わたしはそのかたのもとからきた者で、そのかたがわたしをつかわされたのである」。</span>
<span className="v" id="v30" data-v="30" data-xref="ヨハネによる福音書 8:20; ヨハネによる福音書 10:39; ヨハネによる福音書 7:6"> そこで人々はイエスを捕えようと計ったが、だれひとり手をかける者はなかった。イエスの時が、まだきていなかったからである。</span>
<span className="v" id="v31" data-v="31" data-xref="ヨハネによる福音書 12:42; マタイによる福音書 12:23; ヨハネによる福音書 10:41–42"> しかし、群衆の中の多くの者が、イエスを信じて言った、「キリストがきても、この人が行ったよりも多くのしるしを行うだろうか」。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="ヨハネによる福音書 18:3; ルカによる福音書 22:52–53; ヨハネによる福音書 11:47–48"> 群衆がイエスについてこのようなうわさをしているのを、パリサイ人たちは耳にした。そこで、祭司長たちやパリサイ人たちは、イエスを捕えようとして、下役どもをつかわした。</span>
<span className="v" id="v33" data-v="33" data-xref="ヨハネによる福音書 16:5; ヨハネによる福音書 13:33; マルコによる福音書 16:19"> イエスは言われた、「今しばらくの間、わたしはあなたがたと一緒にいて、それから、わたしをおつかわしになったかたのみもとに行く。</span>
<span className="v" id="v34" data-v="34" data-xref="箴言 1:24–31; ヨハネによる福音書 13:33–36; ヨハネによる福音書 14:6"> あなたがたはわたしを捜すであろうが、見つけることはできない。そしてわたしのいる所に、あなたがたは来ることができない」。</span>
<span className="v" id="v35" data-v="35" data-xref="ヤコブの手紙 1:1; イザヤ書 11:12; ゼパニヤ書 3:10"> そこでユダヤ人たちは互に言った、「わたしたちが見つけることができないというのは、どこへ行こうとしているのだろう。ギリシヤ人の中に離散している人たちのところにでも行って、ギリシヤ人を教えようというのだろうか。</span>
<span className="v" id="v36" data-v="36" data-xref="ヨハネによる福音書 3:9; ヨハネによる福音書 7:34; ヨハネによる福音書 12:34"> また、『わたしを捜すが、見つけることはできない。そしてわたしのいる所には来ることができないだろう』と言ったその言葉は、どういう意味だろう」。</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="イザヤ書 55:1; ヨハネによる福音書 4:14; ヨハネによる福音書 6:35"> 祭の終りの大事な日に、イエスは立って、叫んで言われた、「だれでもかわく者は、わたしのところにきて飲むがよい。</span>
<span className="v" id="v38" data-v="38" data-xref="ヨハネによる福音書 4:14; イザヤ書 44:3; イザヤ書 58:11"> わたしを信じる者は、聖書に書いてあるとおり、その腹から生ける水が川となって流れ出るであろう」。</span>
<span className="v" id="v39" data-v="39" data-xref="使徒行伝 2:17; ヨエル書 2:28; ヨハネによる福音書 14:16–17"> これは、イエスを信じる人々が受けようとしている御霊をさして言われたのである。すなわち、イエスはまだ栄光を受けておられなかったので、御霊がまだ下っていなかったのである。</span>
<span className="v" id="v40" data-v="40" data-xref="マタイによる福音書 21:11; ヨハネによる福音書 1:21; ヨハネによる福音書 6:14"> 群衆のある者がこれらの言葉を聞いて、「このかたは、ほんとうに、あの預言者である」と言い、</span>
<span className="v" id="v41" data-v="41" data-xref="ヨハネによる福音書 7:52; ヨハネによる福音書 1:46; ヨハネによる福音書 1:49"> ほかの人たちは「このかたはキリストである」と言い、また、ある人々は、「キリストはまさか、ガリラヤからは出てこないだろう。</span>
<span className="v" id="v42" data-v="42" data-xref="ミカ書 5:2; マタイによる福音書 2:5; ルカによる福音書 2:4"> キリストは、ダビデの子孫から、またダビデのいたベツレヘムの村から出ると、聖書に書いてあるではないか」と言った。</span>
<span className="v" id="v43" data-v="43" data-xref="ヨハネによる福音書 9:16; ヨハネによる福音書 10:19; ヨハネによる福音書 7:12"> こうして、群衆の間にイエスのことで分争が生じた。</span>
<span className="v" id="v44" data-v="44" data-xref="ヨハネによる福音書 7:30; 使徒行伝 23:11; ヨハネによる福音書 8:20"> 彼らのうちのある人々は、イエスを捕えようと思ったが、だれひとり手をかける者はなかった。</span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="ヨハネによる福音書 7:32; 使徒行伝 5:21–27"> さて、下役どもが祭司長たちやパリサイ人たちのところに帰ってきたので、彼らはその下役どもに言った、「なぜ、あの人を連れてこなかったのか」。</span>
<span className="v" id="v46" data-v="46" data-xref="マタイによる福音書 7:28–29; ルカによる福音書 4:22; ヨハネによる福音書 7:26"> 下役どもは答えた、「この人の語るように語った者は、これまでにありませんでした」。</span>
<span className="v" id="v47" data-v="47" data-xref="ヨハネによる福音書 7:12; コリント人への第二の手紙 6:8; 列王紀下 18:32"> パリサイ人たちが彼らに答えた、「あなたがたまでが、だまされているのではないか。</span>
<span className="v" id="v48" data-v="48" data-xref="ヨハネによる福音書 12:42; コリント人への第一の手紙 1:20; コリント人への第一の手紙 2:8"> 役人たちやパリサイ人たちの中で、ひとりでも彼を信じた者があっただろうか。</span>
<span className="v" id="v49" data-v="49" data-xref="コリント人への第一の手紙 1:20–21; ヨハネによる福音書 9:40; ヨハネによる福音書 9:34"> 律法をわきまえないこの群衆は、のろわれている」。</span>
<span className="v" id="v50" data-v="50" data-xref="ヨハネによる福音書 19:39; ヨハネによる福音書 3:1–2"> 彼らの中のひとりで、以前にイエスに会いにきたことのあるニコデモが、彼らに言った、</span>
<span className="v" id="v51" data-v="51" data-xref="箴言 18:13; 申命記 1:17; 申命記 19:15–19"> 「わたしたちの律法によれば、まずその人の言い分を聞き、その人のしたことを知った上でなければ、さばくことをしないのではないか」。</span>
<span className="v" id="v52" data-v="52" data-xref="ヨハネによる福音書 7:41; ヨハネによる福音書 1:46; イザヤ書 9:1–2"> 彼らは答えて言った、「あなたもガリラヤ出なのか。よく調べてみなさい、ガリラヤからは預言者が出るものではないことが、わかるだろう」。<br />〔</span>
<span className="v" id="v53" data-v="53" data-xref="詩篇 33:10; ヨブ記 5:12–13; 詩篇 76:10"> そして、人々はおのおの家に帰って行った。</span>
</div>

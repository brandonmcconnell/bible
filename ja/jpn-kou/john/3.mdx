<div className="bible-chapter" lang="ja" dir="ltr" data-lang="ja" data-translation="jpn-kou" data-translation-id="jpn_kou" data-translation-label="口語訳" data-book="JHN" data-book-slug="john" data-book-name="ヨハネによる福音書" data-chapter="3" data-verses="36">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨハネによる福音書 19:39; ヨハネによる福音書 7:47–50; ヨハネによる福音書 3:10"> パリサイ人のひとりで、その名をニコデモというユダヤ人の指導者があった。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネによる福音書 5:36; 使徒行伝 10:38; 使徒行伝 2:22"> この人が夜イエスのもとにきて言った、「先生、わたしたちはあなたが神からこられた教師であることを知っています。神がご一緒でないなら、あなたがなさっておられるようなしるしは、だれにもできはしません」。</span>
<span className="v" id="v3" data-v="3" data-xref="コリント人への第二の手紙 5:17; ヨハネによる福音書 3:5–6; ペテロの第一の手紙 1:23–25"> イエスは答えて言われた、「よくよくあなたに言っておく。だれでも新しく生れなければ、神の国を見ることはできない」。</span>
<span className="v" id="v4" data-v="4" data-xref="コリント人への第一の手紙 2:14; コリント人への第一の手紙 1:18; ヨハネによる福音書 3:3"> ニコデモは言った、「人は年をとってから生れることが、どうしてできますか。もう一度、母の胎にはいって生れることができましょうか」。</span>
<span className="v" id="v5" data-v="5" data-xref="エゼキエル書 36:25–27; エペソ人への手紙 5:26; 使徒行伝 2:38"> イエスは答えられた、「よくよくあなたに言っておく。だれでも、水と霊とから生れなければ、神の国にはいることはできない。</span>
<span className="v" id="v6" data-v="6" data-xref="ガラテヤ人への手紙 5:16–21; エゼキエル書 36:26–27; ローマ人への手紙 8:4–9"> 肉から生れる者は肉であり、霊から生れる者は霊である。</span>
<span className="v" id="v7" data-v="7" data-xref="ヨハネによる福音書 3:3; エペソ人への手紙 4:22–24; ローマ人への手紙 12:1–2"> あなたがたは新しく生れなければならないと、わたしが言ったからとて、不思議に思うには及ばない。</span>
<span className="v" id="v8" data-v="8" data-xref="伝道の書 11:4–5; コリント人への第一の手紙 2:11; 使徒行伝 2:2"> 風は思いのままに吹く。あなたはその音を聞くが、それがどこからきて、どこへ行くかは知らない。霊から生れる者もみな、それと同じである」。</span>
<span className="v" id="v9" data-v="9" data-xref="ヨハネによる福音書 6:60; ルカによる福音書 1:34; イザヤ書 42:16"> ニコデモはイエスに答えて言った、「どうして、そんなことがあり得ましょうか」。</span>
<span className="v" id="v10" data-v="10" data-xref="マタイによる福音書 22:29; エレミヤ書 8:8–9; エゼキエル書 11:19"> イエスは彼に答えて言われた、「あなたはイスラエルの教師でありながら、これぐらいのことがわからないのか。</span>
<span className="v" id="v11" data-v="11" data-xref="ヨハネによる福音書 8:38; ヨハネの第一の手紙 5:6–12; ヨハネによる福音書 12:49"> よくよく言っておく。わたしたちは自分の知っていることを語り、また自分の見たことをあかししているのに、あなたがたはわたしたちのあかしを受けいれない。</span>
<span className="v" id="v12" data-v="12" data-xref="コリント人への第一の手紙 3:1–2; コリント人への第一の手紙 2:7–9; ヘブル人への手紙 5:11"> わたしが地上のことを語っているのに、あなたがたが信じないならば、天上のことを語った場合、どうしてそれを信じるだろうか。</span>
<span className="v" id="v13" data-v="13" data-xref="箴言 30:4; ヨハネによる福音書 6:38; 使徒行伝 2:34"> 天から下ってきた者、すなわち人の子のほかには、だれも天に上った者はない。</span>
<span className="v" id="v14" data-v="14" data-xref="民数記 21:7–9; ヨハネによる福音書 8:28; ヨハネによる福音書 12:32–34"> そして、ちょうどモーセが荒野でへびを上げたように、人の子もまた上げられなければならない。</span>
<span className="v" id="v15" data-v="15" data-xref="ヨハネによる福音書 3:16; ヨハネによる福音書 6:40; ヨハネによる福音書 12:44–46"> それは彼を信じる者が、すべて永遠の命を得るためである」。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="ローマ人への手紙 5:8; ヨハネの第一の手紙 4:9–10; ヨハネによる福音書 3:15"> 神はそのひとり子を賜わったほどに、この世を愛して下さった。それは御子を信じる者がひとりも滅びないで、永遠の命を得るためである。</span>
<span className="v" id="v17" data-v="17" data-xref="ヨハネの第一の手紙 4:14; ルカによる福音書 19:10; ヨハネによる福音書 12:47–48"> 神が御子を世につかわされたのは、世をさばくためではなく、御子によって、この世が救われるためである。</span>
<span className="v" id="v18" data-v="18" data-xref="マルコによる福音書 16:16; ヨハネの第一の手紙 5:10; ローマ人への手紙 8:1"> 彼を信じる者は、さばかれない。信じない者は、すでにさばかれている。神のひとり子の名を信じることをしないからである。</span>
<span className="v" id="v19" data-v="19" data-xref="ヨハネによる福音書 8:12; テサロニケ人への第二の手紙 2:12; ヨハネによる福音書 9:39–41"> そのさばきというのは、光がこの世にきたのに、人々はそのおこないが悪いために、光よりもやみの方を愛したことである。</span>
<span className="v" id="v20" data-v="20" data-xref="エペソ人への手紙 5:11–13; ヨハネによる福音書 7:7; ヨブ記 24:13–17"> 悪を行っている者はみな光を憎む。そして、そのおこないが明るみに出されるのを恐れて、光にこようとはしない。</span>
<span className="v" id="v21" data-v="21" data-xref="ヨハネの第一の手紙 1:6; 詩篇 139:23–24; ヨハネの第三の手紙 1:11"> しかし、真理を行っている者は光に来る。その人のおこないの、神にあってなされたということが、明らかにされるためである。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="ヨハネによる福音書 4:1–3; ヨハネによる福音書 3:26; ヨハネによる福音書 2:13"> こののち、イエスは弟子たちとユダヤの地に行き、彼らと一緒にそこに滞在して、バプテスマを授けておられた。</span>
<span className="v" id="v23" data-v="23" data-xref="マルコによる福音書 1:4–5; エゼキエル書 43:2; マタイによる福音書 3:5–6"> ヨハネもサリムに近いアイノンで、バプテスマを授けていた。そこには水がたくさんあったからである。人々がぞくぞくとやってきてバプテスマを受けていた。</span>
<span className="v" id="v24" data-v="24" data-xref="マタイによる福音書 4:12; マタイによる福音書 14:3; マルコによる福音書 6:17"> そのとき、ヨハネはまだ獄に入れられてはいなかった。</span>
<span className="v" id="v25" data-v="25" data-xref="ヨハネによる福音書 2:6; マタイによる福音書 3:11; ヘブル人への手紙 6:2"> ところが、ヨハネの弟子たちとひとりのユダヤ人との間に、きよめのことで争論が起った。</span>
<span className="v" id="v26" data-v="26" data-xref="ヨハネによる福音書 1:7; ヨハネによる福音書 1:15; ヨハネによる福音書 12:19"> そこで彼らはヨハネのところにきて言った、「先生、ごらん下さい。ヨルダンの向こうであなたと一緒にいたことがあり、そして、あなたがあかしをしておられたあのかたが、バプテスマを授けており、皆の者が、そのかたのところへ出かけています」。</span>
<span className="v" id="v27" data-v="27" data-xref="ヤコブの手紙 1:17; コリント人への第一の手紙 4:7; コリント人への第一の手紙 15:10"> ヨハネは答えて言った、「人は天から与えられなければ、何ものも受けることはできない。</span>
<span className="v" id="v28" data-v="28" data-xref="ヨハネによる福音書 1:20; ヨハネによる福音書 1:23; マタイによる福音書 3:11–12"> 『わたしはキリストではなく、そのかたよりも先につかわされた者である』と言ったことをあかししてくれるのは、あなたがた自身である。</span>
<span className="v" id="v29" data-v="29" data-xref="マタイによる福音書 9:15; ホセア書 2:19; イザヤ書 54:5"> 花嫁をもつ者は花婿である。花婿の友人は立って彼の声を聞き、その声を聞いて大いに喜ぶ。こうして、この喜びはわたしに満ち足りている。</span>
<span className="v" id="v30" data-v="30" data-xref="コロサイ人への手紙 1:18; 詩篇 72:17–19; ヘブル人への手紙 3:2–6"> 彼は必ず栄え、わたしは衰える。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="ヨハネによる福音書 8:23; マタイによる福音書 28:18; ローマ人への手紙 9:5"> 上から来る者は、すべてのものの上にある。地から出る者は、地に属する者であって、地のことを語る。天から来る者は、すべてのものの上にある。</span>
<span className="v" id="v32" data-v="32" data-xref="ヨハネによる福音書 3:11; ヨハネによる福音書 15:15; ヨハネによる福音書 1:11"> 彼はその見たところ、聞いたところをあかししているが、だれもそのあかしを受けいれない。</span>
<span className="v" id="v33" data-v="33" data-xref="ヘブル人への手紙 6:17; エペソ人への手紙 1:13; テトスヘの手紙 1:1–2"> しかし、そのあかしを受けいれる者は、神がまことであることを、たしかに認めたのである。</span>
<span className="v" id="v34" data-v="34" data-xref="使徒行伝 10:38; マタイによる福音書 12:18; ヨハネによる福音書 15:26"> 神がおつかわしになったかたは、神の言葉を語る。神は聖霊を限りなく賜うからである。</span>
<span className="v" id="v35" data-v="35" data-xref="マタイによる福音書 28:18; ヨハネによる福音書 5:22; ヨハネによる福音書 5:20"> 父は御子を愛して、万物をその手にお与えになった。</span>
<span className="v" id="v36" data-v="36" data-xref="ヨハネによる福音書 5:24; ヨハネによる福音書 1:12; テサロニケ人への第一の手紙 5:9"> 御子を信じる者は永遠の命をもつ。御子に従わない者は、命にあずかることがないばかりか、神の怒りがその上にとどまるのである」。</span>
</div>

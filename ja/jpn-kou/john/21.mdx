<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨハネによる福音書 6:1; ヨハネによる福音書 6:23; マタイによる福音書 28:16"> そののち、イエスはテベリヤの海べで、ご自身をまた弟子たちにあらわされた。そのあらわされた次第は、こうである。</span>
<span className="v" id="v2" data-v="2" data-xref="マタイによる福音書 4:21–22; ヨハネによる福音書 1:45–1; ヨハネによる福音書 4:46"> シモン・ペテロが、デドモと呼ばれているトマス、ガリラヤのカナのナタナエル、ゼベダイの子らや、ほかのふたりの弟子たちと一緒にいた時のことである。</span>
<span className="v" id="v3" data-v="3" data-xref="ルカによる福音書 5:5; マタイによる福音書 4:18–20; テサロニケ人への第二の手紙 3:7–9"> シモン・ペテロは彼らに「わたしは漁に行くのだ」と言うと、彼らは「わたしたちも一緒に行こう」と言った。彼らは出て行って舟に乗った。しかし、その夜はなんの獲物もなかった。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネによる福音書 20:14; ルカによる福音書 24:15–16; ルカによる福音書 24:31"> 夜が明けたころ、イエスが岸に立っておられた。しかし弟子たちはそれがイエスだとは知らなかった。</span>
<span className="v" id="v5" data-v="5" data-xref="ピリピ人への手紙 4:19; ピリピ人への手紙 4:11–13; ヨハネの第一の手紙 2:13"> イエスは彼らに言われた、「子たちよ、何か食べるものがあるか」。彼らは「ありません」と答えた。</span>
<span className="v" id="v6" data-v="6" data-xref="ルカによる福音書 5:4–7; 使徒行伝 2:41; ヨハネによる福音書 2:5"> すると、イエスは彼らに言われた、「舟の右の方に網をおろして見なさい。そうすれば、何かとれるだろう」。彼らは網をおろすと、魚が多くとれたので、それを引き上げることができなかった。</span>
<span className="v" id="v7" data-v="7" data-xref="ヨハネによる福音書 13:23; ヨハネによる福音書 20:2; マタイによる福音書 14:28–29"> イエスの愛しておられた弟子が、ペテロに「あれは主だ」と言った。シモン・ペテロは主であると聞いて、裸になっていたため、上着をまとって海にとびこんだ。</span>
<span className="v" id="v8" data-v="8" data-xref="申命記 3:11"> しかし、ほかの弟子たちは舟に乗ったまま、魚のはいっている網を引きながら帰って行った。陸からはあまり遠くない五十間ほどの所にいたからである。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="ヨハネによる福音書 21:13; 列王紀上 19:5–6; ヨハネによる福音書 21:10"> 彼らが陸に上って見ると、炭火がおこしてあって、その上に魚がのせてあり、またそこにパンがあった。</span>
<span className="v" id="v10" data-v="10"> イエスは彼らに言われた、「今とった魚を少し持ってきなさい」。</span>
<span className="v" id="v11" data-v="11" data-xref="ルカによる福音書 5:6–8; 使徒行伝 2:41"> シモン・ペテロが行って、網を陸へ引き上げると、百五十三びきの大きな魚でいっぱいになっていた。そんなに多かったが、網はさけないでいた。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行伝 10:41; ルカによる福音書 9:45; ヨハネによる福音書 16:19"> イエスは彼らに言われた、「さあ、朝の食事をしなさい」。弟子たちは、主であることがわかっていたので、だれも「あなたはどなたですか」と進んで尋ねる者がなかった。</span>
<span className="v" id="v13" data-v="13" data-xref="ヨハネによる福音書 21:9; 使徒行伝 10:41; ルカによる福音書 24:42–43"> イエスはそこにきて、パンをとり彼らに与え、また魚も同じようにされた。</span>
<span className="v" id="v14" data-v="14" data-xref="ヨハネによる福音書 20:26; ヨハネによる福音書 20:19"> イエスが死人の中からよみがえったのち、弟子たちにあらわれたのは、これで既に三度目である。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="イザヤ書 40:11; ヨハネの第一の手紙 4:19; ローマ人への手紙 15:1"> 彼らが食事をすませると、イエスはシモン・ペテロに言われた、「ヨハネの子シモンよ、あなたはこの人たちが愛する以上に、わたしを愛するか」。ペテロは言った、「主よ、そうです。わたしがあなたを愛することは、あなたがご存じです」。イエスは彼に「わたしの小羊を養いなさい」と言われた。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行伝 20:28; ペテロの第一の手紙 5:2; ペテロの第一の手紙 2:25"> またもう一度彼に言われた、「ヨハネの子シモンよ、わたしを愛するか」。彼はイエスに言った、「主よ、そうです。わたしがあなたを愛することは、あなたがご存じです」。イエスは彼に言われた、「わたしの羊を飼いなさい」。</span>
<span className="v" id="v17" data-v="17" data-xref="ヨハネによる福音書 13:38; ヨハネによる福音書 16:30; マルコによる福音書 14:72"> イエスは三度目に言われた、「ヨハネの子シモンよ、わたしを愛するか」。ペテロは「わたしを愛するか」とイエスが三度も言われたので、心をいためてイエスに言った、「主よ、あなたはすべてをご存じです。わたしがあなたを愛していることは、おわかりになっています」。イエスは彼に言われた、「わたしの羊を養いなさい。</span>
<span className="v" id="v18" data-v="18" data-xref="ヨハネによる福音書 13:36; 使徒行伝 12:3–4; 使徒行伝 21:11"> よくよくあなたに言っておく。あなたが若かった時には、自分で帯をしめて、思いのままに歩きまわっていた。しかし年をとってからは、自分の手をのばすことになろう。そして、ほかの人があなたに帯を結びつけ、行きたくない所へ連れて行くであろう」。</span>
<span className="v" id="v19" data-v="19" data-xref="ペテロの第二の手紙 1:14; ヨハネによる福音書 21:22; マタイによる福音書 10:38"> これは、ペテロがどんな死に方で、神の栄光をあらわすかを示すために、お話しになったのである。こう話してから、「わたしに従ってきなさい」と言われた。</span>
<span className="v" id="v20" data-v="20" data-xref="ヨハネによる福音書 21:7; ヨハネによる福音書 20:2; ヨハネによる福音書 21:24"> ペテロはふり返ると、イエスの愛しておられた弟子がついて来るのを見た。この弟子は、あの夕食のときイエスの胸近くに寄りかかって、「主よ、あなたを裏切る者は、だれなのですか」と尋ねた人である。</span>
<span className="v" id="v21" data-v="21" data-xref="ルカによる福音書 13:23–24; 使徒行伝 1:6–7; マタイによる福音書 24:3–4"> ペテロはこの弟子を見て、イエスに言った、「主よ、この人はどうなのですか」。</span>
<span className="v" id="v22" data-v="22" data-xref="ヨハネの黙示録 2:25; ヨハネの黙示録 3:11; マルコによる福音書 9:1"> イエスは彼に言われた、「たとい、わたしの来る時まで彼が生き残っていることを、わたしが望んだとしても、あなたにはなんの係わりがあるか。あなたは、わたしに従ってきなさい」。</span>
<span className="v" id="v23" data-v="23" data-xref="申命記 29:29; ヨブ記 33:13; ダニエル書 4:35"> こういうわけで、この弟子は死ぬことがないといううわさが、兄弟たちの間にひろまった。しかし、イエスは彼が死ぬことはないと言われたのではなく、ただ「たとい、わたしの来る時まで彼が生き残っていることを、わたしが望んだとしても、あなたにはなんの係わりがあるか」と言われただけである。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="ヨハネによる福音書 19:35; ヨハネによる福音書 15:27; ヨハネの第一の手紙 5:6"> これらの事についてあかしをし、またこれらの事を書いたのは、この弟子である。そして彼のあかしが真実であることを、わたしたちは知っている。</span>
<span className="v" id="v25" data-v="25" data-xref="詩篇 40:5; ヨハネによる福音書 20:30–31; 詩篇 71:15"> イエスのなさったことは、このほかにまだ数多くある。もしいちいち書きつけるならば、世界もその書かれた文書を収めきれないであろうと思う。</span>
</div>

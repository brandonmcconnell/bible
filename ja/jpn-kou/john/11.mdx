<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ルカによる福音書 10:38–42; ヨハネによる福音書 12:17; 列王紀下 20:1–12"> さて、ひとりの病人がいた。ラザロといい、マリヤとその姉妹マルタの村ベタニヤの人であった。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネによる福音書 12:3; マルコによる福音書 14:3; マタイによる福音書 26:6–7"> このマリヤは主に香油をぬり、自分の髪の毛で、主の足をふいた女であって、病気であったのは、彼女の兄弟ラザロであった。</span>
<span className="v" id="v3" data-v="3" data-xref="ヨハネによる福音書 11:5; ヨハネの黙示録 3:19; テモテヘの第二の手紙 4:20"> 姉妹たちは人をイエスのもとにつかわして、「主よ、ただ今、あなたが愛しておられる者が病気をしています」と言わせた。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネによる福音書 11:40; ヨハネによる福音書 9:3; ペテロの第一の手紙 4:14"> イエスはそれを聞いて言われた、「この病気は死ぬほどのものではない。それは神の栄光のため、また、神の子がそれによって栄光を受けるためのものである」。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="ヨハネによる福音書 15:9–13; ヨハネによる福音書 16:27; ヨハネによる福音書 17:26"> イエスは、マルタとその姉妹とラザロとを愛しておられた。</span>
<span className="v" id="v6" data-v="6" data-xref="イザヤ書 30:18; イザヤ書 55:8–9; 創世記 45:1–5"> ラザロが病気であることを聞いてから、なおふつか、そのおられた所に滞在された。</span>
<span className="v" id="v7" data-v="7" data-xref="ヨハネによる福音書 10:40–42; ルカによる福音書 9:51; 使徒行伝 20:22–24"> それから弟子たちに、「もう一度ユダヤに行こう」と言われた。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨハネによる福音書 10:31; ヨハネによる福音書 8:59; 使徒行伝 21:12–13"> 弟子たちは言った、「先生、ユダヤ人らが、さきほどもあなたを石で殺そうとしていましたのに、またそこに行かれるのですか」。</span>
<span className="v" id="v9" data-v="9" data-xref="ヨハネによる福音書 9:4; ヨハネによる福音書 12:35; エレミヤ書 31:9"> イエスは答えられた、「一日には十二時間あるではないか。昼間あるけば、人はつまずくことはない。この世の光を見ているからである。</span>
<span className="v" id="v10" data-v="10" data-xref="ヨハネの第一の手紙 2:10–11; 箴言 4:18–19; エレミヤ書 13:16"> しかし、夜あるけば、つまずく。その人のうちに、光がないからである」。</span>
<span className="v" id="v11" data-v="11" data-xref="ダニエル書 12:2; ヨハネによる福音書 11:13; ヨハネによる福音書 11:43–44"> そう言われたが、それからまた、彼らに言われた、「わたしたちの友ラザロが眠っている。わたしは彼を起しに行く」。</span>
<span className="v" id="v12" data-v="12"> すると弟子たちは言った、「主よ、眠っているのでしたら、助かるでしょう」。</span>
<span className="v" id="v13" data-v="13" data-xref="マタイによる福音書 9:24"> イエスはラザロが死んだことを言われたのであるが、弟子たちは、眠って休んでいることをさして言われたのだと思った。</span>
<span className="v" id="v14" data-v="14" data-xref="ヨハネによる福音書 16:25; ヨハネによる福音書 16:29; ヨハネによる福音書 10:24"> するとイエスは、あからさまに彼らに言われた、「ラザロは死んだのだ。</span>
<span className="v" id="v15" data-v="15" data-xref="テモテヘの第二の手紙 2:10; ヨハネによる福音書 14:10–11; イザヤ書 54:15"> そして、わたしがそこにいあわせなかったことを、あなたがたのために喜ぶ。それは、あなたがたが信じるようになるためである。では、彼のところに行こう」。</span>
<span className="v" id="v16" data-v="16" data-xref="ヨハネによる福音書 13:37; マタイによる福音書 10:3; ヨハネによる福音書 21:2"> するとデドモと呼ばれているトマスが、仲間の弟子たちに言った、「わたしたちも行って、先生と一緒に死のうではないか」。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="ヨハネによる福音書 11:39; ホセア書 6:2; 使徒行伝 2:27–31"> さて、イエスが行ってごらんになると、ラザロはすでに四日間も墓の中に置かれていた。</span>
<span className="v" id="v18" data-v="18" data-xref="ヨハネの黙示録 14:20; ヨハネの黙示録 21:16; ヨハネによる福音書 6:19"> ベタニヤはエルサレムに近く、二十五丁ばかり離れたところにあった。</span>
<span className="v" id="v19" data-v="19" data-xref="ヨブ記 2:11; ヨハネによる福音書 11:31; テサロニケ人への第一の手紙 5:11"> 大ぜいのユダヤ人が、その兄弟のことで、マルタとマリヤとを慰めようとしてきていた。</span>
<span className="v" id="v20" data-v="20" data-xref="ルカによる福音書 10:38–42; テサロニケ人への第一の手紙 4:17; マタイによる福音書 25:1"> マルタはイエスがこられたと聞いて、出迎えに行ったが、マリヤは家ですわっていた。</span>
<span className="v" id="v21" data-v="21" data-xref="ヨハネによる福音書 11:32; 列王紀上 17:18; マタイによる福音書 9:18"> マルタはイエスに言った、「主よ、もしあなたがここにいて下さったなら、わたしの兄弟は死ななかったでしょう。</span>
<span className="v" id="v22" data-v="22" data-xref="ヨハネによる福音書 9:31; ヨハネによる福音書 11:41–42; マタイによる福音書 28:18"> しかし、あなたがどんなことをお願いになっても、神はかなえて下さることを、わたしは今でも存じています」。</span>
<span className="v" id="v23" data-v="23" data-xref="ヨハネによる福音書 11:43–44"> イエスはマルタに言われた、「あなたの兄弟はよみがえるであろう」。</span>
<span className="v" id="v24" data-v="24" data-xref="ダニエル書 12:2–3; 使徒行伝 24:15; ヨハネによる福音書 5:28–29"> マルタは言った、「終りの日のよみがえりの時よみがえることは、存じています」。</span>
<span className="v" id="v25" data-v="25" data-xref="テサロニケ人への第一の手紙 4:14; ヨハネによる福音書 3:36; ヨハネの第一の手紙 5:11–12"> イエスは彼女に言われた、「わたしはよみがえりであり、命である。わたしを信じる者は、たとい死んでも生きる。</span>
<span className="v" id="v26" data-v="26" data-xref="ヨハネによる福音書 10:28; ヨハネによる福音書 5:24; ローマ人への手紙 8:13"> また、生きていて、わたしを信じる者は、いつまでも死なない。あなたはこれを信じるか」。</span>
<span className="v" id="v27" data-v="27" data-xref="マタイによる福音書 16:16; ヨハネによる福音書 6:69; ヨハネによる福音書 6:14"> マルタはイエスに言った、「主よ、信じます。あなたがこの世にきたるべきキリスト、神の御子であると信じております」。</span>
<span className="v" id="v28" data-v="28" data-xref="ヨハネによる福音書 11:20; ヨハネによる福音書 13:13; マルコによる福音書 10:49"> マルタはこう言ってから、帰って姉妹のマリヤを呼び、「先生がおいでになって、あなたを呼んでおられます」と小声で言った。</span>
<span className="v" id="v29" data-v="29" data-xref="箴言 15:23; 詩篇 27:8; 雅歌 3:1–4"> これを聞いたマリヤはすぐ立ち上がって、イエスのもとに行った。</span>
<span className="v" id="v30" data-v="30" data-xref="ヨハネによる福音書 11:20"> イエスはまだ村に、はいってこられず、マルタがお迎えしたその場所におられた。</span>
<span className="v" id="v31" data-v="31" data-xref="ヨハネによる福音書 11:19; 創世記 37:35; サムエル記下 12:16–18"> マリヤと一緒に家にいて彼女を慰めていたユダヤ人たちは、マリヤが急いで立ち上がって出て行くのを見て、彼女は墓に泣きに行くのであろうと思い、そのあとからついて行った。</span>
<span className="v" id="v32" data-v="32" data-xref="ヨハネによる福音書 11:21; ルカによる福音書 17:16; ルカによる福音書 5:8"> マリヤは、イエスのおられる所に行ってお目にかかり、その足もとにひれ伏して言った、「主よ、もしあなたがここにいて下さったなら、わたしの兄弟は死ななかったでしょう」。</span>
<span className="v" id="v33" data-v="33" data-xref="ヨハネによる福音書 11:38; ヨハネによる福音書 12:27; マルコによる福音書 3:5"> イエスは、彼女が泣き、また、彼女と一緒にきたユダヤ人たちも泣いているのをごらんになり、激しく感動し、また心を騒がせ、そして言われた、</span>
<span className="v" id="v34" data-v="34" data-xref="マルコによる福音書 15:47; マタイによる福音書 28:6; ヨハネによる福音書 1:39"> 「彼をどこに置いたのか」。彼らはイエスに言った、「主よ、きて、ごらん下さい」。</span>
<span className="v" id="v35" data-v="35" data-xref="ルカによる福音書 19:41; ヘブル人への手紙 4:15; ヨハネによる福音書 11:33"> イエスは涙を流された。</span>
<span className="v" id="v36" data-v="36" data-xref="ヨハネによる福音書 11:3; ヨハネの第一の手紙 3:1; ヨハネの第一の手紙 4:9–10"> するとユダヤ人たちは言った、「ああ、なんと彼を愛しておられたことか」。</span>
<span className="v" id="v37" data-v="37" data-xref="ヨハネによる福音書 9:6–7; ヨハネによる福音書 11:32; ルカによる福音書 23:39"> しかし、彼らのある人たちは言った、「あの盲人の目をあけたこの人でも、ラザロを死なせないようには、できなかったのか」。</span>
<span className="v" id="v38" data-v="38" data-xref="ヨハネによる福音書 11:33; ルカによる福音書 24:2; マタイによる福音書 27:60"> イエスはまた激しく感動して、墓にはいられた。それは洞穴であって、そこに石がはめてあった。</span>
<span className="v" id="v39" data-v="39" data-xref="ヨハネによる福音書 11:17; マルコによる福音書 16:3; 詩篇 49:7"> イエスは言われた、「石を取りのけなさい」。死んだラザロの姉妹マルタが言った、「主よ、もう臭くなっております。四日もたっていますから」。</span>
<span className="v" id="v40" data-v="40" data-xref="ヨハネによる福音書 11:4; ヨハネによる福音書 11:23–26; ローマ人への手紙 4:17–25"> イエスは彼女に言われた、「もし信じるなら神の栄光を見るであろうと、あなたに言ったではないか」。</span>
<span className="v" id="v41" data-v="41" data-xref="マタイによる福音書 11:25; ヨハネによる福音書 17:1; 詩篇 123:1"> 人々は石を取りのけた。すると、イエスは目を天にむけて言われた、「父よ、わたしの願いをお聞き下さったことを感謝します。</span>
<span className="v" id="v42" data-v="42" data-xref="ヨハネによる福音書 3:17; ヨハネによる福音書 17:21; ヨハネの第一の手紙 4:14"> あなたがいつでもわたしの願いを聞きいれて下さることを、よく知っています。しかし、こう申しますのは、そばに立っている人々に、あなたがわたしをつかわされたことを、信じさせるためであります」。</span>
<span className="v" id="v43" data-v="43" data-xref="列王紀下 4:33–36; 使徒行伝 9:40; 使徒行伝 9:34"> こう言いながら、大声で「ラザロよ、出てきなさい」と呼ばわれた。</span>
<span className="v" id="v44" data-v="44" data-xref="ヨハネによる福音書 5:25; ヨハネによる福音書 20:7; ヨハネによる福音書 11:25–26"> すると、死人は手足を布でまかれ、顔も顔おおいで包まれたまま、出てきた。イエスは人々に言われた、「彼をほどいてやって、帰らせなさい」。</span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="ヨハネによる福音書 2:23; ヨハネによる福音書 11:19; ヨハネによる福音書 10:41"> マリヤのところにきて、イエスのなさったことを見た多くのユダヤ人たちは、イエスを信じた。</span>
<span className="v" id="v46" data-v="46" data-xref="ヨハネによる福音書 9:13; 使徒行伝 5:25; ヨハネによる福音書 12:37"> しかし、そのうちの数人がパリサイ人たちのところに行って、イエスのされたことを告げた。</span>
<span className="v" id="v47" data-v="47" data-xref="マタイによる福音書 26:3; ヨハネによる福音書 12:19; 使徒行伝 4:5–6"> そこで、祭司長たちとパリサイ人たちとは、議会を召集して言った、「この人が多くのしるしを行っているのに、お互は何をしているのだ。</span>
<span className="v" id="v48" data-v="48" data-xref="テサロニケ人への第一の手紙 2:15–16; マタイによる福音書 23:35–38; マタイによる福音書 27:25"> もしこのままにしておけば、みんなが彼を信じるようになるだろう。そのうえ、ローマ人がやってきて、わたしたちの土地も人民も奪ってしまうであろう」。</span>
<span className="v" id="v49" data-v="49" data-xref="マタイによる福音書 26:3; ヨハネによる福音書 11:51; ヨハネによる福音書 18:13–14"> 彼らのうちのひとりで、その年の大祭司であったカヤパが、彼らに言った、「あなたがたは、何もわかっていないし、</span>
<span className="v" id="v50" data-v="50" data-xref="ヨハネによる福音書 18:14; ルカによる福音書 24:46; ローマ人への手紙 3:8"> ひとりの人が人民に代って死んで、全国民が滅びないようになるのがわたしたちにとって得だということを、考えてもいない」。</span>
<span className="v" id="v51" data-v="51" data-xref="ダニエル書 9:26; コリント人への第二の手紙 5:21; 出エジプト記 28:30"> このことは彼が自分から言ったのではない。彼はこの年の大祭司であったので、預言をして、イエスが国民のために、</span>
<span className="v" id="v52" data-v="52" data-xref="ヨハネによる福音書 10:16; イザヤ書 49:6; ヨハネの第一の手紙 2:2"> ただ国民のためだけではなく、また散在している神の子らを一つに集めるために、死ぬことになっていると、言ったのである。</span>
<span className="v" id="v53" data-v="53" data-xref="使徒行伝 5:33; 使徒行伝 9:23; マルコによる福音書 14:1"> 彼らはこの日からイエスを殺そうと相談した。</span>
<span className="v" id="v54" data-v="54" data-xref="ヨハネによる福音書 7:1; ヨハネによる福音書 7:4; 歴代志下 13:19"> そのためイエスは、もはや公然とユダヤ人の間を歩かないで、そこを出て、荒野に近い地方のエフライムという町に行かれ、そこに弟子たちと一緒に滞在しておられた。</span>
</div>
<div className="bp">
<span className="v" id="v55" data-v="55" data-xref="歴代志下 30:17–20; ヘブル人への手紙 9:13–14; ヨハネによる福音書 6:4"> さて、ユダヤ人の過越の祭が近づいたので、多くの人々は身をきよめるために、祭の前に、地方からエルサレムへ上った。</span>
<span className="v" id="v56" data-v="56" data-xref="ヨハネによる福音書 7:11; ヨハネによる福音書 11:7–8"> 人々はイエスを捜し求め、宮の庭に立って互に言った、「あなたがたはどう思うか。イエスはこの祭にこないのだろうか」。</span>
<span className="v" id="v57" data-v="57" data-xref="ヨハネによる福音書 9:22; ヨハネによる福音書 8:59; ヨハネによる福音書 5:16–18"> 祭司長たちとパリサイ人たちとは、イエスを捕えようとして、そのいどころを知っている者があれば申し出よ、という指令を出していた。</span>
</div>

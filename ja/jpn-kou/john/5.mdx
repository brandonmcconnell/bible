<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命記 16:16; 出エジプト記 23:14–17; 出エジプト記 34:23"> こののち、ユダヤ人の祭があったので、イエスはエルサレムに上られた。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="ネヘミヤ書 12:39; ネヘミヤ書 3:1; ネヘミヤ書 3:32"> エルサレムにある羊の門のそばに、ヘブル語でベテスダと呼ばれる池があった。そこには五つの廊があった。</span>
<span className="v" id="v3" data-v="3" data-xref="マルコによる福音書 3:1–4; ルカによる福音書 7:22; マタイによる福音書 15:30"> その廊の中には、病人、盲人、足なえ、やせ衰えた者などが、大ぜいからだを横たえていた。〔彼らは水の動くのを待っていたのである。</span>
<span className="v" id="v4" data-v="4"> それは、時々、主の御使がこの池に降りてきて水を動かすことがあるが、水が動いた時まっ先にはいる者は、どんな病気にかかっていても、いやされたからである。〕</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行伝 3:2; ルカによる福音書 8:43; マルコによる福音書 9:21"> さて、そこに三十八年のあいだ、病気に悩んでいる人があった。</span>
<span className="v" id="v6" data-v="6" data-xref="ルカによる福音書 18:41; ヘブル人への手紙 4:15; ヘブル人への手紙 4:13"> イエスはその人が横になっているのを見、また長い間わずらっていたのを知って、その人に「なおりたいのか」と言われた。</span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 72:12; 申命記 32:36; コリント人への第一の手紙 9:24"> この病人はイエスに答えた、「主よ、水が動く時に、わたしを池の中に入れてくれる人がいません。わたしがはいりかけると、ほかの人が先に降りて行くのです」。</span>
<span className="v" id="v8" data-v="8" data-xref="ルカによる福音書 5:24; マタイによる福音書 9:6; マルコによる福音書 2:11"> イエスは彼に言われた、「起きて、あなたの床を取りあげ、そして歩きなさい」。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行伝 3:7–8; ヨハネによる福音書 9:14; マルコによる福音書 3:2–4"> すると、この人はすぐにいやされ、床をとりあげて歩いて行った。<br />その日は安息日であった。</span>
<span className="v" id="v10" data-v="10" data-xref="エレミヤ書 17:21; ルカによる福音書 6:2; ヨハネによる福音書 9:16"> そこでユダヤ人たちは、そのいやされた人に言った、「きょうは安息日だ。床を取りあげるのは、よろしくない」。</span>
<span className="v" id="v11" data-v="11" data-xref="マルコによる福音書 2:9–11; ヨハネによる福音書 9:16"> 彼は答えた、「わたしをなおして下さったかたが、床を取りあげて歩けと、わたしに言われました」。</span>
<span className="v" id="v12" data-v="12" data-xref="マタイによる福音書 21:23; 士師記 6:29; ローマ人への手紙 10:2"> 彼らは尋ねた、「取りあげて歩けと言った人は、だれか」。</span>
<span className="v" id="v13" data-v="13" data-xref="ルカによる福音書 4:30; ルカによる福音書 24:31; ヨハネによる福音書 8:59"> しかし、このいやされた人は、それがだれであるか知らなかった。群衆がその場にいたので、イエスはそっと出て行かれたからである。</span>
<span className="v" id="v14" data-v="14" data-xref="ヨハネによる福音書 8:11; レビ記 26:23–24; 詩篇 118:18"> そののち、イエスは宮でその人に出会ったので、彼に言われた、「ごらん、あなたはよくなった。もう罪を犯してはいけない。何かもっと悪いことが、あなたの身に起るかも知れないから」。</span>
<span className="v" id="v15" data-v="15" data-xref="ヨハネによる福音書 9:11–12; ヨハネによる福音書 4:29; ヨハネによる福音書 9:25"> 彼は出て行って、自分をいやしたのはイエスであったと、ユダヤ人たちに告げた。</span>
<span className="v" id="v16" data-v="16" data-xref="ヨハネによる福音書 10:39; ヨハネによる福音書 7:19–20; マルコによる福音書 3:6"> そのためユダヤ人たちは、安息日にこのようなことをしたと言って、イエスを責めた。</span>
<span className="v" id="v17" data-v="17" data-xref="ヨハネによる福音書 9:4; ヨハネによる福音書 14:10; コロサイ人への手紙 1:16"> そこで、イエスは彼らに答えられた、「わたしの父は今に至るまで働いておられる。わたしも働くのである」。</span>
<span className="v" id="v18" data-v="18" data-xref="ヨハネによる福音書 10:30; ヨハネによる福音書 10:33; ヨハネによる福音書 19:7"> このためにユダヤ人たちは、ますますイエスを殺そうと計るようになった。それは、イエスが安息日を破られたばかりではなく、神を自分の父と呼んで、自分を神と等しいものとされたからである。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="ヨハネによる福音書 12:49; ヨハネによる福音書 8:28; ヨハネによる福音書 14:10"> さて、イエスは彼らに答えて言われた、「よくよくあなたがたに言っておく。子は父のなさることを見てする以外に、自分からは何事もすることができない。父のなさることであればすべて、子もそのとおりにするのである。</span>
<span className="v" id="v20" data-v="20" data-xref="ヨハネによる福音書 3:35; マタイによる福音書 3:17; ヨハネによる福音書 17:26"> なぜなら、父は子を愛して、みずからなさることは、すべて子にお示しになるからである。そして、それよりもなお大きなわざを、お示しになるであろう。あなたがたが、それによって不思議に思うためである。</span>
<span className="v" id="v21" data-v="21" data-xref="ローマ人への手紙 8:11; 申命記 32:39; ヨハネによる福音書 11:25"> すなわち、父が死人を起して命をお与えになるように、子もまた、そのこころにかなう人々に命を与えるであろう。</span>
<span className="v" id="v22" data-v="22" data-xref="ヨハネによる福音書 5:27; 使徒行伝 17:31; コリント人への第二の手紙 5:10"> 父はだれをもさばかない。さばきのことはすべて、子にゆだねられたからである。</span>
<span className="v" id="v23" data-v="23" data-xref="ヨハネの第一の手紙 2:23; ルカによる福音書 10:16; マタイによる福音書 11:27"> それは、すべての人が父を敬うと同様に、子を敬うためである。子を敬わない者は、子をつかわされた父をも敬わない。</span>
<span className="v" id="v24" data-v="24" data-xref="ヨハネによる福音書 3:36; ヨハネによる福音書 6:40; ヨハネの第一の手紙 5:11–13"> よくよくあなたがたに言っておく。わたしの言葉を聞いて、わたしをつかわされたかたを信じる者は、永遠の命を受け、またさばかれることがなく、死から命に移っているのである。</span>
<span className="v" id="v25" data-v="25" data-xref="ヨハネによる福音書 5:28; エペソ人への手紙 5:14; エペソ人への手紙 2:5"> よくよくあなたがたに言っておく。死んだ人たちが、神の子の声を聞く時が来る。今すでにきている。そして聞く人は生きるであろう。</span>
<span className="v" id="v26" data-v="26" data-xref="ヨハネによる福音書 11:26; ヨハネによる福音書 1:4; 出エジプト記 3:14"> それは、父がご自分のうちに生命をお持ちになっていると同様に、子にもまた、自分のうちに生命を持つことをお許しになったからである。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行伝 10:42; ヨハネによる福音書 5:22; 使徒行伝 17:31"> そして子は人の子であるから、子にさばきを行う権威をお与えになった。</span>
<span className="v" id="v28" data-v="28" data-xref="ヨハネの黙示録 20:12; テサロニケ人への第一の手紙 4:14–17; イザヤ書 26:19"> このことを驚くには及ばない。墓の中にいる者たちがみな神の子の声を聞き、</span>
<span className="v" id="v29" data-v="29" data-xref="ダニエル書 12:2–3; ローマ人への手紙 2:6–10; 使徒行伝 24:15"> 善をおこなった人々は、生命を受けるためによみがえり、悪をおこなった人々は、さばきを受けるためによみがえって、それぞれ出てくる時が来るであろう。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="ヨハネによる福音書 6:38; ヨハネによる福音書 5:19; ヨハネによる福音書 4:34"> わたしは、自分からは何事もすることができない。ただ聞くままにさばくのである。そして、わたしのこのさばきは正しい。それは、わたし自身の考えでするのではなく、わたしをつかわされたかたの、み旨を求めているからである。</span>
<span className="v" id="v31" data-v="31" data-xref="箴言 27:2; ヨハネによる福音書 8:54; ヨハネの黙示録 3:14"> もし、わたしが自分自身についてあかしをするならば、わたしのあかしはほんとうではない。</span>
<span className="v" id="v32" data-v="32" data-xref="ヨハネによる福音書 1:33; ヨハネによる福音書 12:28–30; ヨハネによる福音書 5:36–37"> わたしについてあかしをするかたはほかにあり、そして、その人がするあかしがほんとうであることを、わたしは知っている。</span>
<span className="v" id="v33" data-v="33" data-xref="ヨハネによる福音書 1:29–34; ヨハネによる福音書 3:26–36; ヨハネによる福音書 1:15–27"> あなたがたはヨハネのもとへ人をつかわしたが、そのとき彼は真理についてあかしをした。</span>
<span className="v" id="v34" data-v="34" data-xref="ルカによる福音書 19:41–42; ヨハネによる福音書 20:31; ヨハネの第一の手紙 5:9"> わたしは人からあかしを受けないが、このことを言うのは、あなたがたが救われるためである。</span>
<span className="v" id="v35" data-v="35" data-xref="ペテロの第二の手紙 1:19; ヨハネによる福音書 1:7–8; マタイによる福音書 11:11"> ヨハネは燃えて輝くあかりであった。あなたがたは、しばらくの間その光を喜び楽しもうとした。</span>
<span className="v" id="v36" data-v="36" data-xref="ヨハネによる福音書 10:25; ヨハネによる福音書 10:37–38; ヨハネによる福音書 15:24"> しかし、わたしには、ヨハネのあかしよりも、もっと力あるあかしがある。父がわたしに成就させようとしてお与えになったわざ、すなわち、今わたしがしているこのわざが、父のわたしをつかわされたことをあかししている。</span>
<span className="v" id="v37" data-v="37" data-xref="ヨハネによる福音書 8:18; ヨハネによる福音書 1:18; マタイによる福音書 3:17"> また、わたしをつかわされた父も、ご自分でわたしについてあかしをされた。あなたがたは、まだそのみ声を聞いたこともなく、そのみ姿を見たこともない。</span>
<span className="v" id="v38" data-v="38" data-xref="ヨハネの第一の手紙 2:14; 申命記 6:6–9; ヨハネによる福音書 12:44–48"> また、神がつかわされた者を信じないから、神の御言はあなたがたのうちにとどまっていない。</span>
<span className="v" id="v39" data-v="39" data-xref="ルカによる福音書 24:27; ルカによる福音書 24:44; ペテロの第二の手紙 1:19–21"> あなたがたは、聖書の中に永遠の命があると思って調べているが、この聖書は、わたしについてあかしをするものである。</span>
<span className="v" id="v40" data-v="40" data-xref="ヨハネによる福音書 3:19; ヨハネによる福音書 1:11; 詩篇 81:11"> しかも、あなたがたは、命を得るためにわたしのもとにこようともしない。</span>
<span className="v" id="v41" data-v="41" data-xref="ヨハネによる福音書 7:18; ヨハネによる福音書 5:34; テサロニケ人への第一の手紙 2:6"> わたしは人からの誉を受けることはしない。</span>
<span className="v" id="v42" data-v="42" data-xref="ヨハネの第一の手紙 4:20; ヨハネの第一の手紙 3:17; ヨハネによる福音書 2:25"> しかし、あなたがたのうちには神を愛する愛がないことを知っている。</span>
<span className="v" id="v43" data-v="43" data-xref="ヨハネによる福音書 10:25; マタイによる福音書 24:5; ヨハネによる福音書 17:4–6"> わたしは父の名によってきたのに、あなたがたはわたしを受けいれない。もし、ほかの人が彼自身の名によって来るならば、その人を受けいれるのであろう。</span>
<span className="v" id="v44" data-v="44" data-xref="ヨハネによる福音書 12:43; ローマ人への手紙 2:29; ピリピ人への手紙 2:3"> 互に誉を受けながら、ただひとりの神からの誉を求めようとしないあなたがたは、どうして信じることができようか。</span>
<span className="v" id="v45" data-v="45" data-xref="ローマ人への手紙 3:19–20; ガラテヤ人への手紙 3:10; コリント人への第二の手紙 3:7–11"> わたしがあなたがたのことを父に訴えると、考えてはいけない。あなたがたを訴える者は、あなたがたが頼みとしているモーセその人である。</span>
<span className="v" id="v46" data-v="46" data-xref="申命記 18:15; 申命記 18:18–19; ヨハネによる福音書 1:45"> もし、あなたがたがモーセを信じたならば、わたしをも信じたであろう。モーセは、わたしについて書いたのである。</span>
<span className="v" id="v47" data-v="47" data-xref="ルカによる福音書 16:31; ルカによる福音書 16:29"> しかし、モーセの書いたものを信じないならば、どうしてわたしの言葉を信じるだろうか」。</span>
</div>

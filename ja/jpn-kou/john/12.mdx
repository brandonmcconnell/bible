<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マルコによる福音書 14:3–8; ヨハネによる福音書 11:1; ルカによる福音書 24:50"> 過越の祭の六日まえに、イエスはベタニヤに行かれた。そこは、イエスが死人の中からよみがえらせたラザロのいた所である。</span>
<span className="v" id="v2" data-v="2" data-xref="ルカによる福音書 22:27; ルカによる福音書 10:38–42; ヨハネの黙示録 3:20"> イエスのためにそこで夕食の用意がされ、マルタは給仕をしていた。イエスと一緒に食卓についていた者のうちに、ラザロも加わっていた。</span>
<span className="v" id="v3" data-v="3" data-xref="マルコによる福音書 14:3–9; ヨハネによる福音書 11:2; ルカによる福音書 10:38–39"> その時、マリヤは高価で純粋なナルドの香油一斤を持ってきて、イエスの足にぬり、自分の髪の毛でそれをふいた。すると、香油のかおりが家にいっぱいになった。</span>
<span className="v" id="v4" data-v="4" data-xref="マタイによる福音書 10:4; サムエル記上 17:28–29; ヨハネによる福音書 13:2"> 弟子のひとりで、イエスを裏切ろうとしていたイスカリオテのユダが言った、</span>
<span className="v" id="v5" data-v="5" data-xref="ルカによる福音書 18:22; ルカによる福音書 12:33; マルコによる福音書 14:4–5"> 「なぜこの香油を三百デナリに売って、貧しい人たちに、施さなかったのか」。</span>
<span className="v" id="v6" data-v="6" data-xref="ヨハネによる福音書 13:29; 詩篇 50:16–20; ヤコブの手紙 2:6"> 彼がこう言ったのは、貧しい人たちに対する思いやりがあったからではなく、自分が盗人であり、財布を預かっていて、その中身をごまかしていたからであった。</span>
<span className="v" id="v7" data-v="7" data-xref="マタイによる福音書 26:12; マルコによる福音書 14:6; マタイによる福音書 27:57–60"> イエスは言われた、「この女のするままにさせておきなさい。わたしの葬りの日のために、それをとっておいたのだから。</span>
<span className="v" id="v8" data-v="8" data-xref="申命記 15:11; マルコによる福音書 14:7; マタイによる福音書 26:11"> 貧しい人たちはいつもあなたがたと共にいるが、わたしはいつも共にいるわけではない」。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行伝 4:14; ヨハネによる福音書 11:43–45; 使徒行伝 3:10–11"> 大ぜいのユダヤ人たちが、そこにイエスのおられるのを知って、押しよせてきた。それはイエスに会うためだけではなく、イエスが死人のなかから、よみがえらせたラザロを見るためでもあった。</span>
<span className="v" id="v10" data-v="10" data-xref="ルカによる福音書 16:31; マタイによる福音書 2:16; ヨハネによる福音書 11:47–53"> そこで祭司長たちは、ラザロも殺そうと相談した。</span>
<span className="v" id="v11" data-v="11" data-xref="ヨハネによる福音書 11:45; ヨハネによる福音書 12:18; 使徒行伝 13:45"> それは、ラザロのことで、多くのユダヤ人が彼らを離れ去って、イエスを信じるに至ったからである。</span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="マルコによる福音書 11:7–10; マタイによる福音書 21:4–9; ルカによる福音書 19:35–38"> その翌日、祭にきていた大ぜいの群衆は、イエスがエルサレムにこられると聞いて、</span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 118:25–26; ヨハネの黙示録 15:3; マタイによる福音書 21:9–11"> しゅろの枝を手にとり、迎えに出て行った。そして叫んだ、<br /><span className="pl pl-1">「ホサナ、</span><br /><span className="pl pl-1">主の御名によってきたる者に祝福あれ、</span><br /><span className="pl pl-1">イスラエルの王に」。</span></span>
<span className="v" id="v14" data-v="14" data-xref="ゼカリヤ書 9:9; マルコによる福音書 11:1–7; マタイによる福音書 21:1–7"> <span className="pl pl-1">イエスは、ろばの子を見つけて、その上に乗られた。それは</span></span>
<span className="v" id="v15" data-v="15" data-xref="ゼカリヤ書 9:9; イザヤ書 62:11; ゼパニヤ書 3:16–17"> <span className="pl pl-1">「シオンの娘よ、恐れるな。</span><br /><span className="pl pl-1">見よ、あなたの王が</span><br /><span className="pl pl-1">ろばの子に乗っておいでになる」</span><br />と書いてあるとおりであった。</span>
<span className="v" id="v16" data-v="16" data-xref="ヨハネによる福音書 2:22; ヨハネによる福音書 14:26; ヨハネによる福音書 7:39"> 弟子たちは初めにはこのことを悟らなかったが、イエスが栄光を受けられた時に、このことがイエスについて書かれてあり、またそのとおりに、人々がイエスに対してしたのだということを、思い起した。</span>
<span className="v" id="v17" data-v="17" data-xref="ヨハネの黙示録 1:2; ヨハネの第一の手紙 5:9–12; ヨハネによる福音書 19:35"> また、イエスがラザロを墓から呼び出して、死人の中からよみがえらせたとき、イエスと一緒にいた群衆が、そのあかしをした。</span>
<span className="v" id="v18" data-v="18" data-xref="ヨハネによる福音書 12:11"> 群衆がイエスを迎えに出たのは、イエスがこのようなしるしを行われたことを、聞いていたからである。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行伝 17:6; 詩篇 22:27; ヨハネの第一の手紙 2:2"> そこで、パリサイ人たちは互に言った、「何をしてもむだだった。世をあげて彼のあとを追って行ったではないか」。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="ヨハネによる福音書 7:35; イザヤ書 11:10; 使徒行伝 17:4"> 祭で礼拝するために上ってきた人々のうちに、数人のギリシヤ人がいた。</span>
<span className="v" id="v21" data-v="21" data-xref="マタイによる福音書 2:2; ルカによる福音書 19:2–4; ヨハネによる福音書 6:40"> 彼らはガリラヤのベツサイダ出であるピリポのところにきて、「君よ、イエスにお目にかかりたいのですが」と言って頼んだ。</span>
<span className="v" id="v22" data-v="22" data-xref="マルコによる福音書 10:13–14; ルカによる福音書 9:49–50; ヨハネによる福音書 1:40–41"> ピリポはアンデレのところに行ってそのことを話し、アンデレとピリポは、イエスのもとに行って伝えた。</span>
<span className="v" id="v23" data-v="23" data-xref="ヨハネによる福音書 13:31–32; ヨハネによる福音書 17:1–5; イザヤ書 60:9"> すると、イエスは答えて言われた、「人の子が栄光を受ける時がきた。</span>
<span className="v" id="v24" data-v="24" data-xref="コリント人への第一の手紙 15:36–38; イザヤ書 53:10–12; ヘブル人への手紙 2:9–10"> よくよくあなたがたに言っておく。一粒の麦が地に落ちて死ななければ、それはただ一粒のままである。しかし、もし死んだなら、豊かに実を結ぶようになる。</span>
<span className="v" id="v25" data-v="25" data-xref="マタイによる福音書 10:39; ルカによる福音書 9:23–24; マルコによる福音書 8:35"> 自分の命を愛する者はそれを失い、この世で自分の命を憎む者は、それを保って永遠の命に至るであろう。</span>
<span className="v" id="v26" data-v="26" data-xref="コロサイ人への手紙 3:24; ガラテヤ人への手紙 1:10; サムエル記上 2:30"> もしわたしに仕えようとする人があれば、その人はわたしに従って来るがよい。そうすれば、わたしのおる所に、わたしに仕える者もまた、おるであろう。もしわたしに仕えようとする人があれば、その人を父は重んじて下さるであろう。</span>
<span className="v" id="v27" data-v="27" data-xref="ヨハネによる福音書 12:23; ヘブル人への手紙 5:7; マタイによる福音書 26:42"> 今わたしは心が騒いでいる。わたしはなんと言おうか。父よ、この時からわたしをお救い下さい。しかし、わたしはこのために、この時に至ったのです。</span>
<span className="v" id="v28" data-v="28" data-xref="ヨハネによる福音書 13:31–32; マタイによる福音書 26:42; ヨハネの黙示録 5:9–14"> 父よ、み名があがめられますように」。すると天から声があった、「わたしはすでに栄光をあらわした。そして、更にそれをあらわすであろう」。</span>
<span className="v" id="v29" data-v="29" data-xref="ヨブ記 37:2–5; ヨハネの黙示録 6:1; ヨハネの黙示録 14:2"> すると、そこに立っていた群衆がこれを聞いて、「雷がなったのだ」と言い、ほかの人たちは、「御使が彼に話しかけたのだ」と言った。</span>
<span className="v" id="v30" data-v="30" data-xref="ヨハネによる福音書 11:42; ヨハネによる福音書 11:15; ヨハネによる福音書 5:34"> イエスは答えて言われた、「この声があったのは、わたしのためではなく、あなたがたのためである。</span>
<span className="v" id="v31" data-v="31" data-xref="コリント人への第二の手紙 4:4; ヨハネの第一の手紙 5:19; ヨハネの第一の手紙 3:8"> 今はこの世がさばかれる時である。今こそこの世の君は追い出されるであろう。</span>
<span className="v" id="v32" data-v="32" data-xref="ヨハネによる福音書 3:14; ヨハネによる福音書 8:28; ペテロの第一の手紙 2:24"> そして、わたしがこの地から上げられる時には、すべての人をわたしのところに引きよせるであろう」。</span>
<span className="v" id="v33" data-v="33" data-xref="ヨハネによる福音書 18:32; ヨハネによる福音書 21:19"> イエスはこう言って、自分がどんな死に方で死のうとしていたかを、お示しになったのである。</span>
<span className="v" id="v34" data-v="34" data-xref="エゼキエル書 37:24–25; イザヤ書 9:7; ダニエル書 7:14"> すると群衆はイエスにむかって言った、「わたしたちは律法によって、キリストはいつまでも生きておいでになるのだ、と聞いていました。それだのに、どうして人の子は上げられねばならないと、言われるのですか。その人の子とは、だれのことですか」。</span>
<span className="v" id="v35" data-v="35" data-xref="ヨハネによる福音書 12:46; ヨハネによる福音書 16:16; エペソ人への手紙 5:8"> そこでイエスは彼らに言われた、「もうしばらくの間、光はあなたがたと一緒にここにある。光がある間に歩いて、やみに追いつかれないようにしなさい。やみの中を歩く者は、自分がどこへ行くのかわかっていない。</span>
<span className="v" id="v36" data-v="36" data-xref="エペソ人への手紙 5:8; ヨハネによる福音書 8:59; 使徒行伝 13:47–48"> 光のある間に、光の子となるために、光を信じなさい」。<br />イエスはこれらのことを話してから、そこを立ち去って、彼らから身をお隠しになった。</span>
<span className="v" id="v37" data-v="37" data-xref="ルカによる福音書 16:31; ヨハネによる福音書 1:11; ヨハネによる福音書 15:24"> このように多くのしるしを彼らの前でなさったが、彼らはイエスを信じなかった。</span>
<span className="v" id="v38" data-v="38" data-xref="イザヤ書 53:1; ローマ人への手紙 10:16; ローマ人への手紙 10:20"> それは、預言者イザヤの次の言葉が成就するためである、「主よ、わたしたちの説くところを、だれが信じたでしょうか。また、主のみ腕はだれに示されたでしょうか」。</span>
<span className="v" id="v39" data-v="39" data-xref="ヨハネによる福音書 10:38; ヨハネによる福音書 5:44; ペテロの第二の手紙 2:14"> こういうわけで、彼らは信じることができなかった。イザヤはまた、こうも言った、</span>
<span className="v" id="v40" data-v="40" data-xref="イザヤ書 6:10; マタイによる福音書 13:13–15; ルカによる福音書 8:10"> 「神は彼らの目をくらまし、心をかたくなになさった。それは、彼らが目で見ず、心で悟らず、悔い改めていやされることがないためである」。</span>
<span className="v" id="v41" data-v="41" data-xref="イザヤ書 6:1–5; イザヤ書 6:9–10; ヨハネによる福音書 1:14"> イザヤがこう言ったのは、イエスの栄光を見たからであって、イエスのことを語ったのである。</span>
<span className="v" id="v42" data-v="42" data-xref="ヨハネによる福音書 9:22; ヨハネによる福音書 7:13; イザヤ書 51:7"> しかし、役人たちの中にも、イエスを信じた者が多かったが、パリサイ人をはばかって、告白はしなかった。会堂から追い出されるのを恐れていたのである。</span>
<span className="v" id="v43" data-v="43" data-xref="ヨハネによる福音書 5:44; マタイによる福音書 23:5–7; ヨハネによる福音書 5:41"> 彼らは神のほまれよりも、人のほまれを好んだからである。</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="マタイによる福音書 10:40; ヨハネによる福音書 13:20; ヨハネによる福音書 5:24"> イエスは大声で言われた、「わたしを信じる者は、わたしを信じるのではなく、わたしをつかわされたかたを信じるのであり、</span>
<span className="v" id="v45" data-v="45" data-xref="ヨハネによる福音書 14:9–10; コリント人への第二の手紙 4:6; コロサイ人への手紙 1:15"> また、わたしを見る者は、わたしをつかわされたかたを見るのである。</span>
<span className="v" id="v46" data-v="46" data-xref="ヨハネによる福音書 8:12; 詩篇 36:9; ヨハネによる福音書 9:5"> わたしは光としてこの世にきた。それは、わたしを信じる者が、やみのうちにとどまらないようになるためである。</span>
<span className="v" id="v47" data-v="47" data-xref="ヨハネによる福音書 3:17; ヨハネによる福音書 8:15–16; ヨハネによる福音書 12:48"> たとい、わたしの言うことを聞いてそれを守らない人があっても、わたしはその人をさばかない。わたしがきたのは、この世をさばくためではなく、この世を救うためである。</span>
<span className="v" id="v48" data-v="48" data-xref="ルカによる福音書 10:16; ヘブル人への手紙 9:27–28; ローマ人への手紙 2:16"> わたしを捨てて、わたしの言葉を受けいれない人には、その人をさばくものがある。わたしの語ったその言葉が、終りの日にその人をさばくであろう。</span>
<span className="v" id="v49" data-v="49" data-xref="ヨハネによる福音書 14:10; ヨハネによる福音書 8:26; ヨハネによる福音書 5:30"> わたしは自分から語ったのではなく、わたしをつかわされた父ご自身が、わたしの言うべきこと、語るべきことをお命じになったのである。</span>
<span className="v" id="v50" data-v="50" data-xref="ヨハネによる福音書 17:3; ヨハネによる福音書 6:68; ヨハネの第一の手紙 5:20"> わたしは、この命令が永遠の命であることを知っている。それゆえに、わたしが語っていることは、わたしの父がわたしに仰せになったことを、そのまま語っているのである」。</span>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨハネによる福音書 3:26; ヨハネによる福音書 3:22; コリント人への第二の手紙 4:5"> イエスが、ヨハネよりも多く弟子をつくり、またバプテスマを授けておられるということを、パリサイ人たちが聞き、それを主が知られたとき、</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行伝 10:48; コリント人への第一の手紙 1:13–17"> （しかし、イエスみずからが、バプテスマをお授けになったのではなく、その弟子たちであった）</span>
<span className="v" id="v3" data-v="3" data-xref="マタイによる福音書 10:23; ヨハネによる福音書 10:40; ヨハネによる福音書 2:11"> ユダヤを去って、またガリラヤへ行かれた。</span>
<span className="v" id="v4" data-v="4" data-xref="ルカによる福音書 17:11; ルカによる福音書 2:49; ルカによる福音書 9:51–52"> しかし、イエスはサマリヤを通過しなければならなかった。</span>
<span className="v" id="v5" data-v="5" data-xref="ヨシュア記 24:32; 創世記 33:19; 創世記 48:22"> そこで、イエスはサマリヤのスカルという町においでになった。この町は、ヤコブがその子ヨセフに与えた土地の近くにあったが、</span>
<span className="v" id="v6" data-v="6" data-xref="ヘブル人への手紙 4:15; ヘブル人への手紙 2:17; マタイによる福音書 8:24"> そこにヤコブの井戸があった。イエスは旅の疲れを覚えて、そのまま、この井戸のそばにすわっておられた。時は昼の十二時ごろであった。</span>
<span className="v" id="v7" data-v="7" data-xref="マタイによる福音書 10:42; 列王紀上 17:10; 創世記 24:43"> ひとりのサマリヤの女が水をくみにきたので、イエスはこの女に、「水を飲ませて下さい」と言われた。</span>
<span className="v" id="v8" data-v="8" data-xref="ルカによる福音書 9:13; ヨハネによる福音書 4:39; ヨハネによる福音書 4:5"> 弟子たちは食物を買いに町に行っていたのである。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行伝 10:28; マタイによる福音書 10:5; 列王紀下 17:24–41"> すると、サマリヤの女はイエスに言った、「あなたはユダヤ人でありながら、どうしてサマリヤの女のわたしに、飲ませてくれとおっしゃるのですか」。これは、ユダヤ人はサマリヤ人と交際していなかったからである。</span>
<span className="v" id="v10" data-v="10" data-xref="ヨハネによる福音書 4:14; ヨハネの黙示録 7:17; ヨハネによる福音書 7:37–39"> イエスは答えて言われた、「もしあなたが神の賜物のことを知り、また、『水を飲ませてくれ』と言った者が、だれであるか知っていたならば、あなたの方から願い出て、その人から生ける水をもらったことであろう」。</span>
<span className="v" id="v11" data-v="11" data-xref="コリント人への第一の手紙 2:14; ヨハネによる福音書 3:4"> 女はイエスに言った、「主よ、あなたは、くむ物をお持ちにならず、その上、井戸は深いのです。その生ける水を、どこから手に入れるのですか。</span>
<span className="v" id="v12" data-v="12" data-xref="ヨハネによる福音書 4:6; ヨハネによる福音書 8:53; マタイによる福音書 12:42"> あなたは、この井戸を下さったわたしたちの父ヤコブよりも、偉いかたなのですか。ヤコブ自身も飲み、その子らも、その家畜も、この井戸から飲んだのですが」。</span>
<span className="v" id="v13" data-v="13" data-xref="ヨハネによる福音書 6:27; イザヤ書 65:13–14; ルカによる福音書 16:24"> イエスは女に答えて言われた、「この水を飲む者はだれでも、またかわくであろう。</span>
<span className="v" id="v14" data-v="14" data-xref="ヨハネによる福音書 7:38–39; ヨハネによる福音書 6:35; イザヤ書 49:10"> しかし、わたしが与える水を飲む者は、いつまでも、かわくことがないばかりか、わたしが与える水は、その人のうちで泉となり、永遠の命に至る水が、わきあがるであろう」。</span>
<span className="v" id="v15" data-v="15" data-xref="ヨハネによる福音書 6:34; ローマ人への手紙 8:5; 詩篇 4:6"> 女はイエスに言った、「主よ、わたしがかわくことがなく、また、ここにくみにこなくてもよいように、その水をわたしに下さい」。</span>
<span className="v" id="v16" data-v="16" data-xref="ヘブル人への手紙 4:13; ヨハネの黙示録 2:23; ヨハネによる福音書 4:18"> イエスは女に言われた、「あなたの夫を呼びに行って、ここに連れてきなさい」。</span>
<span className="v" id="v17" data-v="17"> 女は答えて言った、「わたしには夫はありません」。イエスは女に言われた、「夫がないと言ったのは、もっともだ。</span>
<span className="v" id="v18" data-v="18" data-xref="エレミヤ書 3:20; コリント人への第一の手紙 7:10–11; ローマ人への手紙 7:3"> あなたには五人の夫があったが、今のはあなたの夫ではない。あなたの言葉のとおりである」。</span>
<span className="v" id="v19" data-v="19" data-xref="ルカによる福音書 7:39; ヨハネによる福音書 6:14; ヨハネによる福音書 9:17"> 女はイエスに言った、「主よ、わたしはあなたを預言者と見ます。</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 12:6–7; 申命記 27:12; 申命記 11:29"> わたしたちの先祖は、この山で礼拝をしたのですが、あなたがたは礼拝すべき場所は、エルサレムにあると言っています」。</span>
<span className="v" id="v21" data-v="21" data-xref="テモテヘの第一の手紙 2:8; マラキ書 1:11; ヨハネによる福音書 4:23"> イエスは女に言われた、「女よ、わたしの言うことを信じなさい。あなたがたが、この山でも、またエルサレムでもない所で、父を礼拝する時が来る。</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行伝 17:23; イザヤ書 2:3; ローマ人への手紙 9:4–5"> あなたがたは自分の知らないものを拝んでいるが、わたしたちは知っているかたを礼拝している。救はユダヤ人から来るからである。</span>
<span className="v" id="v23" data-v="23" data-xref="ピリピ人への手紙 3:3; ヨハネによる福音書 5:25; マタイによる福音書 15:7–9"> しかし、まことの礼拝をする者たちが、霊とまこととをもって父を礼拝する時が来る。そうだ、今きている。父は、このような礼拝をする者たちを求めておられるからである。</span>
<span className="v" id="v24" data-v="24" data-xref="コリント人への第二の手紙 3:17; マタイによる福音書 15:8–9; ピリピ人への手紙 3:3"> 神は霊であるから、礼拝をする者も、霊とまこととをもって礼拝すべきである」。</span>
<span className="v" id="v25" data-v="25" data-xref="ヨハネによる福音書 1:49; ダニエル書 9:24–26; ヨハネによる福音書 1:41–42"> 女はイエスに言った、「わたしは、キリストと呼ばれるメシヤがこられることを知っています。そのかたがこられたならば、わたしたちに、いっさいのことを知らせて下さるでしょう」。</span>
<span className="v" id="v26" data-v="26" data-xref="ヨハネによる福音書 8:24; マルコによる福音書 14:61–62; ローマ人への手紙 10:20–21"> イエスは女に言われた、「あなたと話をしているこのわたしが、それである」。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="ルカによる福音書 7:39; ヨハネによる福音書 4:8–9"> そのとき、弟子たちが帰って来て、イエスがひとりの女と話しておられるのを見て不思議に思ったが、しかし、「何を求めておられますか」とも、「何を彼女と話しておられるのですか」とも、尋ねる者はひとりもなかった。</span>
<span className="v" id="v28" data-v="28" data-xref="ヨハネによる福音書 4:7; ルカによる福音書 24:33; マルコによる福音書 16:8–10"> この女は水がめをそのままそこに置いて町に行き、人々に言った、</span>
<span className="v" id="v29" data-v="29" data-xref="ヨハネの黙示録 22:17; コリント人への第一の手紙 14:24–25; ヨハネによる福音書 4:25"> 「わたしのしたことを何もかも、言いあてた人がいます。さあ、見にきてごらんなさい。もしかしたら、この人がキリストかも知れません」。</span>
<span className="v" id="v30" data-v="30" data-xref="ローマ人への手紙 5:20; 使徒行伝 8:5–8; ルカによる福音書 17:16–18"> 人々は町を出て、ぞくぞくとイエスのところへ行った。</span>
<span className="v" id="v31" data-v="31" data-xref="ヨハネによる福音書 1:38; 創世記 24:33; 使徒行伝 16:30–34"> その間に弟子たちはイエスに、「先生、召しあがってください」とすすめた。</span>
<span className="v" id="v32" data-v="32" data-xref="ヨブ記 23:12; 詩篇 119:103; ヨハネによる福音書 4:34"> ところが、イエスは言われた、「わたしには、あなたがたの知らない食物がある」。</span>
<span className="v" id="v33" data-v="33" data-xref="マタイによる福音書 16:6–11; ルカによる福音書 9:45"> そこで、弟子たちが互に言った、「だれかが、何か食べるものを持ってきてさしあげたのであろうか」。</span>
<span className="v" id="v34" data-v="34" data-xref="ヨハネによる福音書 6:38; ヨハネによる福音書 5:30; ヨブ記 23:12"> イエスは彼らに言われた、「わたしの食物というのは、わたしをつかわされたかたのみこころを行い、そのみわざをなし遂げることである。</span>
<span className="v" id="v35" data-v="35" data-xref="ルカによる福音書 10:2–3; マタイによる福音書 9:37–38; ヨハネによる福音書 4:30"> あなたがたは、刈入れ時が来るまでには、まだ四か月あると、言っているではないか。しかし、わたしはあなたがたに言う。目をあげて畑を見なさい。はや色づいて刈入れを待っている。</span>
<span className="v" id="v36" data-v="36" data-xref="ヤコブの手紙 5:19–20; ローマ人への手紙 1:13; コリント人への第一の手紙 3:5–9"> 刈る者は報酬を受けて、永遠の命に至る実を集めている。まく者も刈る者も、共々に喜ぶためである。</span>
<span className="v" id="v37" data-v="37" data-xref="ミカ書 6:15; ヨブ記 31:8; ルカによる福音書 19:21"> そこで、『ひとりがまき、ひとりが刈る』ということわざが、ほんとうのこととなる。</span>
<span className="v" id="v38" data-v="38" data-xref="ヨハネによる福音書 1:7; 歴代志下 36:15; 使徒行伝 10:42–43"> わたしは、あなたがたをつかわして、あなたがたがそのために労苦しなかったものを刈りとらせた。ほかの人々が労苦し、あなたがたは、彼らの労苦の実にあずかっているのである」。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="ヨハネによる福音書 4:29; ヨハネによる福音書 4:5; ヨハネによる福音書 10:41–42"> さて、この町からきた多くのサマリヤ人は、「この人は、わたしのしたことを何もかも言いあてた」とあかしした女の言葉によって、イエスを信じた。</span>
<span className="v" id="v40" data-v="40" data-xref="ヨハネの黙示録 3:20; 使徒行伝 16:15; ルカによる福音書 24:29"> そこで、サマリヤ人たちはイエスのもとにきて、自分たちのところに滞在していただきたいと願ったので、イエスはそこにふつか滞在された。</span>
<span className="v" id="v41" data-v="41" data-xref="コリント人への第一の手紙 2:4–5; 使徒行伝 1:8; 使徒行伝 8:12"> そしてなお多くの人々が、イエスの言葉を聞いて信じた。</span>
<span className="v" id="v42" data-v="42" data-xref="ヨハネの第一の手紙 4:14; ヨハネによる福音書 1:29; ヨハネの第一の手紙 5:20"> 彼らは女に言った、「わたしたちが信じるのは、もうあなたが話してくれたからではない。自分自身で親しく聞いて、この人こそまことに世の救主であることが、わかったからである」。</span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="マタイによる福音書 4:13; ローマ人への手紙 15:8; マルコによる福音書 7:27–28"> ふつかの後に、イエスはここを去ってガリラヤへ行かれた。</span>
<span className="v" id="v44" data-v="44" data-xref="マタイによる福音書 13:57; ルカによる福音書 4:24; マルコによる福音書 6:4"> イエスはみずからはっきり、「預言者は自分の故郷では敬われないものだ」と言われたのである。</span>
<span className="v" id="v45" data-v="45" data-xref="ヨハネによる福音書 2:23; ヨハネによる福音書 2:13–16; 申命記 16:16"> ガリラヤに着かれると、ガリラヤの人たちはイエスを歓迎した。それは、彼らも祭に行っていたので、その祭の時、イエスがエルサレムでなされたことをことごとく見ていたからである。</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="ヨハネによる福音書 2:1–11; ルカによる福音書 7:2; ホセア書 5:15"> イエスは、またガリラヤのカナに行かれた。そこは、かつて水をぶどう酒にかえられた所である。ところが、病気をしているむすこを持つある役人がカペナウムにいた。</span>
<span className="v" id="v47" data-v="47" data-xref="ヨハネによる福音書 4:3; ヨハネによる福音書 11:21; ヨハネによる福音書 11:32"> この人が、ユダヤからガリラヤにイエスのきておられることを聞き、みもとにきて、カペナウムに下って、彼の子をなおしていただきたいと、願った。その子が死にかかっていたからである。</span>
<span className="v" id="v48" data-v="48" data-xref="ヨハネによる福音書 20:29; ヘブル人への手紙 2:4; コリント人への第一の手紙 1:22"> そこで、イエスは彼に言われた、「あなたがたは、しるしと奇跡とを見ない限り、決して信じないだろう」。</span>
<span className="v" id="v49" data-v="49" data-xref="マルコによる福音書 5:23; 詩篇 88:10–12; 詩篇 40:17"> この役人はイエスに言った、「主よ、どうぞ、子供が死なないうちにきて下さい」。</span>
<span className="v" id="v50" data-v="50" data-xref="マタイによる福音書 8:13; マルコによる福音書 7:29–30; ローマ人への手紙 4:20–21"> イエスは彼に言われた、「お帰りなさい。あなたのむすこは助かるのだ」。彼は自分に言われたイエスの言葉を信じて帰って行った。</span>
<span className="v" id="v51" data-v="51" data-xref="列王紀上 17:23; ヨハネによる福音書 4:50; ヨハネによる福音書 4:53"> その下って行く途中、僕たちが彼に出会い、その子が助かったことを告げた。</span>
<span className="v" id="v52" data-v="52"> そこで、彼は僕たちに、そのなおりはじめた時刻を尋ねてみたら、「きのうの午後一時に熱が引きました」と答えた。</span>
<span className="v" id="v53" data-v="53" data-xref="詩篇 107:20; ルカによる福音書 19:9; 使徒行伝 16:34"> それは、イエスが「あなたのむすこは助かるのだ」と言われたのと同じ時刻であったことを、この父は知って、彼自身もその家族一同も信じた。</span>
<span className="v" id="v54" data-v="54" data-xref="ヨハネによる福音書 4:45; ヨハネによる福音書 2:1–11"> これは、イエスがユダヤからガリラヤにきてなされた第二のしるしである。</span>
</div>

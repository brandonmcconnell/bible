<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マルコによる福音書 14:32; マタイによる福音書 26:36; サムエル記下 15:23"> イエスはこれらのことを語り終えて、弟子たちと一緒にケデロンの谷の向こうへ行かれた。そこには園があって、イエスは弟子たちと一緒にその中にはいられた。</span>
<span className="v" id="v2" data-v="2" data-xref="ルカによる福音書 21:37; ルカによる福音書 22:39; マルコによる福音書 11:11–12"> イエスを裏切ったユダは、その所をよく知っていた。イエスと弟子たちとがたびたびそこで集まったことがあるからである。</span>
<span className="v" id="v3" data-v="3" data-xref="ヨハネによる福音書 18:12; ルカによる福音書 22:47–53; 詩篇 22:12"> さてユダは、一隊の兵卒と祭司長やパリサイ人たちの送った下役どもを引き連れ、たいまつやあかりや武器を持って、そこへやってきた。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネによる福音書 13:1; ヨハネによる福音書 18:7; 詩篇 27:3"> しかしイエスは、自分の身に起ろうとすることをことごとく承知しておられ、進み出て彼らに言われた、「だれを捜しているのか」。</span>
<span className="v" id="v5" data-v="5" data-xref="マタイによる福音書 21:11; ヨハネによる福音書 19:19; マタイによる福音書 2:23"> 彼らは「ナザレのイエスを」と答えた。イエスは彼らに言われた、「わたしが、それである」。イエスを裏切ったユダも、彼らと一緒に立っていた。</span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 27:2; 詩篇 70:2–3; 列王紀下 1:9–15"> イエスが彼らに「わたしが、それである」と言われたとき、彼らはうしろに引きさがって地に倒れた。</span>
<span className="v" id="v7" data-v="7" data-xref="ヨハネによる福音書 18:4"> そこでまた彼らに、「だれを捜しているのか」とお尋ねになると、彼らは「ナザレのイエスを」と言った。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨハネによる福音書 10:28; マタイによる福音書 26:56; コリント人への第二の手紙 12:9"> イエスは答えられた、「わたしがそれであると、言ったではないか。わたしを捜しているのなら、この人たちを去らせてもらいたい」。</span>
<span className="v" id="v9" data-v="9" data-xref="ヨハネによる福音書 17:12"> それは、「あなたが与えて下さった人たちの中のひとりも、わたしは失わなかった」とイエスの言われた言葉が、成就するためである。</span>
<span className="v" id="v10" data-v="10" data-xref="マルコによる福音書 14:47; マタイによる福音書 26:51–54; ルカによる福音書 22:49–51"> シモン・ペテロは剣を持っていたが、それを抜いて、大祭司の僕に切りかかり、その右の耳を切り落した。その僕の名はマルコスであった。</span>
<span className="v" id="v11" data-v="11" data-xref="マタイによる福音書 20:22; マタイによる福音書 26:39; ヨハネによる福音書 20:17"> すると、イエスはペテロに言われた、「剣をさやに納めなさい。父がわたしに下さった杯は、飲むべきではないか」。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="マタイによる福音書 26:57; ヨハネによる福音書 18:3; 使徒行伝 21:37"> それから一隊の兵卒やその千卒長やユダヤ人の下役どもが、イエスを捕え、縛りあげて、</span>
<span className="v" id="v13" data-v="13" data-xref="ヨハネによる福音書 18:24; ヨハネによる福音書 11:51; マタイによる福音書 26:3"> まずアンナスのところに引き連れて行った。彼はその年の大祭司カヤパのしゅうとであった。</span>
<span className="v" id="v14" data-v="14" data-xref="ヨハネによる福音書 11:49–52"> カヤパは前に、ひとりの人が民のために死ぬのはよいことだと、ユダヤ人に助言した者であった。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="ルカによる福音書 22:54; マルコによる福音書 14:54; マタイによる福音書 26:58–68"> シモン・ペテロともうひとりの弟子とが、イエスについて行った。この弟子は大祭司の知り合いであったので、イエスと一緒に大祭司の中庭にはいった。</span>
<span className="v" id="v16" data-v="16" data-xref="マタイによる福音書 26:69; マルコによる福音書 14:66–68; ルカによる福音書 22:55–57"> しかし、ペテロは外で戸口に立っていた。すると大祭司の知り合いであるその弟子が、外に出て行って門番の女に話し、ペテロを内に入れてやった。</span>
<span className="v" id="v17" data-v="17" data-xref="マタイによる福音書 26:69–70; ヨハネによる福音書 21:15; ルカによる福音書 22:56–57"> すると、この門番の女がペテロに言った、「あなたも、あの人の弟子のひとりではありませんか」。ペテロは「いや、そうではない」と答えた。</span>
<span className="v" id="v18" data-v="18" data-xref="マルコによる福音書 14:54; ヨハネによる福音書 18:25; マルコによる福音書 14:67"> 僕や下役どもは、寒い時であったので、炭火をおこし、そこに立ってあたっていた。ペテロもまた彼らに交じり、立ってあたっていた。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="マルコによる福音書 14:55–65; ルカによる福音書 20:20; ルカによる福音書 22:63–71"> 大祭司はイエスに、弟子たちのことやイエスの教のことを尋ねた。</span>
<span className="v" id="v20" data-v="20" data-xref="ヨハネによる福音書 7:26; イザヤ書 48:16; マタイによる福音書 4:23"> イエスは答えられた、「わたしはこの世に対して公然と語ってきた。すべてのユダヤ人が集まる会堂や宮で、いつも教えていた。何事も隠れて語ったことはない。</span>
<span className="v" id="v21" data-v="21" data-xref="マタイによる福音書 26:59–60; 使徒行伝 24:12–13; ルカによる福音書 22:67"> なぜ、わたしに尋ねるのか。わたしが彼らに語ったことは、それを聞いた人々に尋ねるがよい。わたしの言ったことは、彼らが知っているのだから」。</span>
<span className="v" id="v22" data-v="22" data-xref="ヨハネによる福音書 19:3; マルコによる福音書 14:65; ルカによる福音書 22:63–64"> イエスがこう言われると、そこに立っていた下役のひとりが、「大祭司にむかって、そのような答をするのか」と言って、平手でイエスを打った。</span>
<span className="v" id="v23" data-v="23" data-xref="ペテロの第一の手紙 2:20–23; コリント人への第二の手紙 10:1; マタイによる福音書 5:39"> イエスは答えられた、「もしわたしが何か悪いことを言ったのなら、その悪い理由を言いなさい。しかし、正しいことを言ったのなら、なぜわたしを打つのか」。</span>
<span className="v" id="v24" data-v="24" data-xref="ヨハネによる福音書 18:13; マタイによる福音書 26:57"> それからアンナスは、イエスを縛ったまま大祭司カヤパのところへ送った。</span>
<span className="v" id="v25" data-v="25" data-xref="マルコによる福音書 14:67–72; ヨハネによる福音書 18:17–18; 創世記 18:15"> シモン・ペテロは、立って火にあたっていた。すると人々が彼に言った、「あなたも、あの人の弟子のひとりではないか」。彼はそれをうち消して、「いや、そうではない」と言った。</span>
<span className="v" id="v26" data-v="26" data-xref="ヨハネによる福音書 18:1; ヨハネによる福音書 18:10; マタイによる福音書 26:73"> 大祭司の僕のひとりで、ペテロに耳を切りおとされた人の親族の者が言った、「あなたが園であの人と一緒にいるのを、わたしは見たではないか」。</span>
<span className="v" id="v27" data-v="27" data-xref="ヨハネによる福音書 13:38; マルコによる福音書 14:71–72; ルカによる福音書 22:60–62"> ペテロはまたそれを打ち消した。するとすぐに、鶏が鳴いた。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="ヨハネによる福音書 18:33; ヨハネによる福音書 19:9; マタイによる福音書 27:27"> それから人々は、イエスをカヤパのところから官邸につれて行った。時は夜明けであった。彼らは、けがれを受けないで過越の食事ができるように、官邸にはいらなかった。</span>
<span className="v" id="v29" data-v="29" data-xref="マタイによる福音書 27:23; マルコによる福音書 15:2–5; マタイによる福音書 27:11–14"> そこで、ピラトは彼らのところに出てきて言った、「あなたがたは、この人に対してどんな訴えを起すのか」。</span>
<span className="v" id="v30" data-v="30" data-xref="使徒行伝 3:13; ルカによる福音書 20:19–26; マルコによる福音書 10:33"> 彼らはピラトに答えて言った、「もしこの人が悪事をはたらかなかったなら、あなたに引き渡すようなことはしなかったでしょう」。</span>
<span className="v" id="v31" data-v="31" data-xref="ヨハネによる福音書 19:6–7; ヨハネによる福音書 19:15; 使徒行伝 25:18–20"> そこでピラトは彼らに言った、「あなたがたは彼を引き取って、自分たちの律法でさばくがよい」。ユダヤ人らは彼に言った、「わたしたちには、人を死刑にする権限がありません」。</span>
<span className="v" id="v32" data-v="32" data-xref="ヨハネによる福音書 3:14; マタイによる福音書 20:19; マタイによる福音書 26:2"> これは、ご自身がどんな死にかたをしようとしているかを示すために言われたイエスの言葉が、成就するためである。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="ルカによる福音書 23:3–4; ヨハネによる福音書 18:37; ヨハネによる福音書 19:3"> さて、ピラトはまた官邸にはいり、イエスを呼び出して言った、「あなたは、ユダヤ人の王であるか」。</span>
<span className="v" id="v34" data-v="34"> イエスは答えられた、「あなたがそう言うのは、自分の考えからか。それともほかの人々が、わたしのことをあなたにそう言ったのか」。</span>
<span className="v" id="v35" data-v="35" data-xref="使徒行伝 18:14–16; ネヘミヤ書 4:2; ローマ人への手紙 3:1–2"> ピラトは答えた、「わたしはユダヤ人なのか。あなたの同族や祭司長たちが、あなたをわたしに引き渡したのだ。あなたは、いったい、何をしたのか」。</span>
<span className="v" id="v36" data-v="36" data-xref="ルカによる福音書 17:20–21; コロサイ人への手紙 1:12–14; ローマ人への手紙 14:17"> イエスは答えられた、「わたしの国はこの世のものではない。もしわたしの国がこの世のものであれば、わたしに従っている者たちは、わたしをユダヤ人に渡さないように戦ったであろう。しかし事実、わたしの国はこの世のものではない」。</span>
<span className="v" id="v37" data-v="37" data-xref="ヨハネの第一の手紙 4:6; ヨハネによる福音書 8:47; ヨハネによる福音書 8:14"> そこでピラトはイエスに言った、「それでは、あなたは王なのだな」。イエスは答えられた、「あなたの言うとおり、わたしは王である。わたしは真理についてあかしをするために生れ、また、そのためにこの世にきたのである。だれでも真理につく者は、わたしの声に耳を傾ける」。</span>
<span className="v" id="v38" data-v="38" data-xref="ヨハネによる福音書 19:4; ルカによる福音書 23:4; ヨハネによる福音書 19:6"> ピラトはイエスに言った、「真理とは何か」。こう言って、彼はまたユダヤ人の所に出て行き、彼らに言った、「わたしには、この人になんの罪も見いだせない。</span>
<span className="v" id="v39" data-v="39" data-xref="マタイによる福音書 27:15–18; ルカによる福音書 23:16–23; マルコによる福音書 15:6–14"> 過越の時には、わたしがあなたがたのために、ひとりの人を許してやるのが、あなたがたのしきたりになっている。ついては、あなたがたは、このユダヤ人の王を許してもらいたいのか」。</span>
<span className="v" id="v40" data-v="40" data-xref="ルカによる福音書 23:25; マルコによる福音書 15:15; マタイによる福音書 27:16"> すると彼らは、また叫んで「その人ではなく、バラバを」と言った。このバラバは強盗であった。</span>
</div>
</div>

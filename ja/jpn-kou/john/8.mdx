<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マタイによる福音書 21:1; マルコによる福音書 11:1; ルカによる福音書 19:37"> イエスはオリブ山に行かれた。</span>
<span className="v" id="v2" data-v="2" data-xref="マタイによる福音書 26:55; ルカによる福音書 4:20; ルカによる福音書 21:37"> 朝早くまた宮にはいられると、人々が皆みもとに集まってきたので、イエスはすわって彼らを教えておられた。</span>
<span className="v" id="v3" data-v="3"> すると、律法学者たちやパリサイ人たちが、姦淫をしている時につかまえられた女をひっぱってきて、中に立たせた上、イエスに言った、</span>
<span className="v" id="v4" data-v="4"> 「先生、この女は姦淫の場でつかまえられました。</span>
<span className="v" id="v5" data-v="5" data-xref="レビ記 20:10; 申命記 22:21–24; エゼキエル書 16:38–40"> モーセは律法の中で、こういう女を石で打ち殺せと命じましたが、あなたはどう思いますか」。</span>
<span className="v" id="v6" data-v="6" data-xref="エレミヤ書 17:13; ルカによる福音書 10:25; 伝道の書 3:7"> 彼らがそう言ったのは、イエスをためして、訴える口実を得るためであった。しかし、イエスは身をかがめて、指で地面に何か書いておられた。</span>
<span className="v" id="v7" data-v="7" data-xref="マタイによる福音書 7:1–5; ローマ人への手紙 2:21–25; ローマ人への手紙 2:1–3"> 彼らが問い続けるので、イエスは身を起して彼らに言われた、「あなたがたの中で罪のない者が、まずこの女に石を投げつけるがよい」。</span>
<span className="v" id="v8" data-v="8"> そしてまた身をかがめて、地面に物を書きつづけられた。</span>
<span className="v" id="v9" data-v="9" data-xref="伝道の書 7:22; ローマ人への手紙 2:15; ヨハネの第一の手紙 3:20"> これを聞くと、彼らは年寄から始めて、ひとりびとり出て行き、ついに、イエスだけになり、女は中にいたまま残された。</span>
<span className="v" id="v10" data-v="10" data-xref="イザヤ書 41:11–12"> そこでイエスは身を起して女に言われた、「女よ、みんなはどこにいるか。あなたを罰する者はなかったのか」。</span>
<span className="v" id="v11" data-v="11" data-xref="ヨハネによる福音書 3:17; ヨハネによる福音書 5:14; イザヤ書 1:16–18"> 女は言った、「主よ、だれもございません」。イエスは言われた、「わたしもあなたを罰しない。お帰りなさい。今後はもう罪を犯さないように」。〕</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="ヨハネによる福音書 12:46; ヨハネによる福音書 9:5; ヨハネによる福音書 12:35"> イエスは、また人々に語ってこう言われた、「わたしは世の光である。わたしに従って来る者は、やみのうちを歩くことがなく、命の光をもつであろう」。</span>
<span className="v" id="v13" data-v="13" data-xref="ヨハネによる福音書 5:31–47"> するとパリサイ人たちがイエスに言った、「あなたは、自分のことをあかししている。あなたのあかしは真実ではない」。</span>
<span className="v" id="v14" data-v="14" data-xref="ヨハネによる福音書 16:28; ヨハネによる福音書 13:3; ヨハネによる福音書 8:42"> イエスは彼らに答えて言われた、「たとい、わたしが自分のことをあかししても、わたしのあかしは真実である。それは、わたしがどこからきたのか、また、どこへ行くのかを知っているからである。しかし、あなたがたは、わたしがどこからきて、どこへ行くのかを知らない。</span>
<span className="v" id="v15" data-v="15" data-xref="サムエル記上 16:7; ヨハネによる福音書 7:24; ヨハネによる福音書 12:47"> あなたがたは肉によって人をさばくが、わたしはだれもさばかない。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行伝 17:31; ヨハネによる福音書 8:29; ヨハネによる福音書 16:32"> しかし、もしわたしがさばくとすれば、わたしのさばきは正しい。なぜなら、わたしはひとりではなく、わたしをつかわされたかたが、わたしと一緒だからである。</span>
<span className="v" id="v17" data-v="17" data-xref="申命記 19:15; 申命記 17:6; ヘブル人への手紙 10:28"> あなたがたの律法には、ふたりによる証言は真実だと、書いてある。</span>
<span className="v" id="v18" data-v="18" data-xref="ヨハネによる福音書 8:38; ヨハネによる福音書 8:58; ヨハネによる福音書 8:25"> わたし自身のことをあかしするのは、わたしであるし、わたしをつかわされた父も、わたしのことをあかしして下さるのである」。</span>
<span className="v" id="v19" data-v="19" data-xref="ヨハネによる福音書 16:3; ヨハネによる福音書 8:54–55; ヨハネによる福音書 14:6–9"> すると、彼らはイエスに言った、「あなたの父はどこにいるのか」。イエスは答えられた、「あなたがたは、わたしをもわたしの父をも知っていない。もし、あなたがたがわたしを知っていたなら、わたしの父をも知っていたであろう」。</span>
<span className="v" id="v20" data-v="20" data-xref="ヨハネによる福音書 7:30; ヨハネによる福音書 7:8; マルコによる福音書 12:41"> イエスが宮の内で教えていた時、これらの言葉をさいせん箱のそばで語られたのであるが、イエスの時がまだきていなかったので、だれも捕える者がなかった。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="ヨハネによる福音書 7:34; ヨハネによる福音書 8:24; コリント人への第一の手紙 15:17–18"> さて、また彼らに言われた、「わたしは去って行く。あなたがたはわたしを捜し求めるであろう。そして自分の罪のうちに死ぬであろう。わたしの行く所には、あなたがたは来ることができない」。</span>
<span className="v" id="v22" data-v="22" data-xref="ヨハネによる福音書 8:52; 詩篇 22:6; ヨハネによる福音書 8:48"> そこでユダヤ人たちは言った、「わたしの行く所に、あなたがたは来ることができないと、言ったのは、あるいは自殺でもしようとするつもりか」。</span>
<span className="v" id="v23" data-v="23" data-xref="ヨハネによる福音書 3:31; ヨハネによる福音書 17:14; ヨハネによる福音書 17:16"> イエスは彼らに言われた、「あなたがたは下から出た者だが、わたしは上からきた者である。あなたがたはこの世の者であるが、わたしはこの世の者ではない。</span>
<span className="v" id="v24" data-v="24" data-xref="ヨハネによる福音書 3:36; マルコによる福音書 16:16; ヨハネによる福音書 3:18"> だからわたしは、あなたがたは自分の罪のうちに死ぬであろうと、言ったのである。もしわたしがそういう者であることをあなたがたが信じなければ、罪のうちに死ぬことになるからである」。</span>
<span className="v" id="v25" data-v="25" data-xref="ヨハネによる福音書 5:17–29; ルカによる福音書 22:67; ヨハネによる福音書 1:22"> そこで彼らはイエスに言った、「あなたは、いったい、どういうかたですか」。イエスは彼らに言われた、「わたしがどういう者であるかは、初めからあなたがたに言っているではないか。</span>
<span className="v" id="v26" data-v="26" data-xref="ヨハネによる福音書 15:15; ヨハネによる福音書 12:47–50; ヨハネによる福音書 8:40"> あなたがたについて、わたしの言うべきこと、さばくべきことが、たくさんある。しかし、わたしをつかわされたかたは真実なかたである。わたしは、そのかたから聞いたままを世にむかって語るのである」。</span>
<span className="v" id="v27" data-v="27" data-xref="イザヤ書 6:9; ヨハネによる福音書 8:43; コリント人への第二の手紙 4:3–4"> 彼らは、イエスが父について話しておられたことを悟らなかった。</span>
<span className="v" id="v28" data-v="28" data-xref="ヨハネによる福音書 5:19; ヨハネによる福音書 5:30; ヨハネによる福音書 6:38"> そこでイエスは言われた、「あなたがたが人の子を上げてしまった後はじめて、わたしがそういう者であること、また、わたしは自分からは何もせず、ただ父が教えて下さったままを話していたことが、わかってくるであろう。</span>
<span className="v" id="v29" data-v="29" data-xref="ヨハネによる福音書 6:38; ヨハネによる福音書 16:32; ヨハネによる福音書 4:34"> わたしをつかわされたかたは、わたしと一緒におられる。わたしは、いつも神のみこころにかなうことをしているから、わたしをひとり置きざりになさることはない」。</span>
<span className="v" id="v30" data-v="30" data-xref="ヨハネによる福音書 7:31; ヨハネによる福音書 2:23; ヨハネによる福音書 11:45"> これらのことを語られたところ、多くの人々がイエスを信じた。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="ヨハネの第二の手紙 1:9; ヨハネによる福音書 15:4–9; テモテヘの第二の手紙 3:14"> イエスは自分を信じたユダヤ人たちに言われた、「もしわたしの言葉のうちにとどまっておるなら、あなたがたは、ほんとうにわたしの弟子なのである。</span>
<span className="v" id="v32" data-v="32" data-xref="ローマ人への手紙 8:2; ヨハネによる福音書 8:36; ヨハネによる福音書 17:17"> また真理を知るであろう。そして真理は、あなたがたに自由を得させるであろう」。</span>
<span className="v" id="v33" data-v="33" data-xref="マタイによる福音書 3:9; ヨハネによる福音書 8:39; 創世記 15:13"> そこで、彼らはイエスに言った、「わたしたちはアブラハムの子孫であって、人の奴隷になったことなどは、一度もない。どうして、あなたがたに自由を得させるであろうと、言われるのか」。</span>
<span className="v" id="v34" data-v="34" data-xref="ローマ人への手紙 6:16; ペテロの第二の手紙 2:19; 箴言 5:22"> イエスは彼らに答えられた、「よくよくあなたがたに言っておく。すべて罪を犯す者は罪の奴隷である。</span>
<span className="v" id="v35" data-v="35" data-xref="ガラテヤ人への手紙 4:4–7; ルカによる福音書 15:31; ローマ人への手紙 8:15–17"> そして、奴隷はいつまでも家にいる者ではない。しかし、子はいつまでもいる。</span>
<span className="v" id="v36" data-v="36" data-xref="コリント人への第二の手紙 3:17; ガラテヤ人への手紙 5:1; ローマ人への手紙 8:2"> だから、もし子があなたがたに自由を得させるならば、あなたがたは、ほんとうに自由な者となるのである。</span>
<span className="v" id="v37" data-v="37" data-xref="コリント人への第一の手紙 2:14; ヨハネによる福音書 8:45–47; ヨハネによる福音書 7:1"> わたしは、あなたがたがアブラハムの子孫であることを知っている。それだのに、あなたがたはわたしを殺そうとしている。わたしの言葉が、あなたがたのうちに根をおろしていないからである。</span>
<span className="v" id="v38" data-v="38" data-xref="ヨハネによる福音書 5:19; ヨハネによる福音書 8:44; ヨハネによる福音書 8:41"> わたしはわたしの父のもとで見たことを語っているが、あなたがたは自分の父から聞いたことを行っている」。</span>
<span className="v" id="v39" data-v="39" data-xref="ガラテヤ人への手紙 3:7; ヨハネによる福音書 8:37; ローマ人への手紙 9:7"> 彼らはイエスに答えて言った、「わたしたちの父はアブラハムである」。イエスは彼らに言われた、「もしアブラハムの子であるなら、アブラハムのわざをするがよい。</span>
<span className="v" id="v40" data-v="40" data-xref="ヨハネによる福音書 8:26; ガラテヤ人への手紙 4:29; ガラテヤ人への手紙 4:16"> ところが今、神から聞いた真理をあなたがたに語ってきたこのわたしを、殺そうとしている。そんなことをアブラハムはしなかった。</span>
<span className="v" id="v41" data-v="41" data-xref="イザヤ書 64:8; ヨハネによる福音書 8:38; イザヤ書 63:16"> あなたがたは、あなたがたの父のわざを行っているのである」。彼らは言った、「わたしたちは、不品行の結果うまれた者ではない。わたしたちにはひとりの父がある。それは神である」。</span>
<span className="v" id="v42" data-v="42" data-xref="ヨハネによる福音書 12:49; ヨハネによる福音書 14:10; ヨハネによる福音書 17:8"> イエスは彼らに言われた、「神があなたがたの父であるならば、あなたがたはわたしを愛するはずである。わたしは神から出た者、また神からきている者であるからだ。わたしは自分からきたのではなく、神からつかわされたのである。</span>
<span className="v" id="v43" data-v="43" data-xref="ヨハネによる福音書 12:39–40; ローマ人への手紙 8:7–8; ヨハネによる福音書 7:17"> どうしてあなたがたは、わたしの話すことがわからないのか。あなたがたが、わたしの言葉を悟ることができないからである。</span>
<span className="v" id="v44" data-v="44" data-xref="使徒行伝 13:10; ヨハネの第一の手紙 3:12; ヨハネの第一の手紙 3:8–10"> あなたがたは自分の父、すなわち、悪魔から出てきた者であって、その父の欲望どおりを行おうと思っている。彼は初めから、人殺しであって、真理に立つ者ではない。彼のうちには真理がないからである。彼が偽りを言うとき、いつも自分の本音をはいているのである。彼は偽り者であり、偽りの父であるからだ。</span>
<span className="v" id="v45" data-v="45" data-xref="テモテヘの第二の手紙 4:3–4; ガラテヤ人への手紙 4:16; ヨハネによる福音書 18:37"> しかし、わたしが真理を語っているので、あなたがたはわたしを信じようとしない。</span>
<span className="v" id="v46" data-v="46" data-xref="ヘブル人への手紙 4:15; ヨハネによる福音書 16:8; ペテロの第一の手紙 2:22"> あなたがたのうち、だれがわたしに罪があると責めうるのか。わたしは真理を語っているのに、なぜあなたがたは、わたしを信じないのか。</span>
<span className="v" id="v47" data-v="47" data-xref="ヨハネによる福音書 10:26–27; ヨハネの第二の手紙 1:9; ヨハネによる福音書 18:37"> 神からきた者は神の言葉に聞き従うが、あなたがたが聞き従わないのは、神からきた者でないからである」。</span>
</div>
<div className="bp">
<span className="v" id="v48" data-v="48" data-xref="ヨハネによる福音書 7:20; ヨハネによる福音書 8:52; マタイによる福音書 10:5"> ユダヤ人たちはイエスに答えて言った、「あなたはサマリヤ人で、悪霊に取りつかれていると、わたしたちが言うのは、当然ではないか」。</span>
<span className="v" id="v49" data-v="49" data-xref="ペテロの第一の手紙 2:23; イザヤ書 49:3; ヨハネによる福音書 13:31–32"> イエスは答えられた、「わたしは、悪霊に取りつかれているのではなくて、わたしの父を重んじているのだが、あなたがたはわたしを軽んじている。</span>
<span className="v" id="v50" data-v="50" data-xref="ヨハネによる福音書 5:41; ヨハネによる福音書 8:54; ヨハネによる福音書 7:18"> わたしは自分の栄光を求めてはいない。それを求めるかたが別にある。そのかたは、またさばくかたである。</span>
<span className="v" id="v51" data-v="51" data-xref="ヨハネによる福音書 11:25–26; ヨハネによる福音書 5:24; ヨハネによる福音書 3:15–16"> よくよく言っておく。もし人がわたしの言葉を守るならば、その人はいつまでも死を見ることがないであろう」。</span>
<span className="v" id="v52" data-v="52" data-xref="ヨハネによる福音書 9:24; ヨハネによる福音書 8:48; ヘブル人への手紙 2:9"> ユダヤ人たちが言った、「あなたが悪霊に取りつかれていることが、今わかった。アブラハムは死に、預言者たちも死んでいる。それだのに、あなたは、わたしの言葉を守る者はいつまでも死を味わうことがないであろうと、言われる。</span>
<span className="v" id="v53" data-v="53" data-xref="ヨハネによる福音書 4:12; ローマ人への手紙 9:5; ヘブル人への手紙 7:1–7"> あなたは、わたしたちの父アブラハムより偉いのだろうか。彼も死に、預言者たちも死んだではないか。あなたは、いったい、自分をだれと思っているのか」。</span>
<span className="v" id="v54" data-v="54" data-xref="ヨハネによる福音書 8:50; 箴言 25:27; ペテロの第二の手紙 1:17"> イエスは答えられた、「わたしがもし自分に栄光を帰するなら、わたしの栄光は、むなしいものである。わたしに栄光を与えるかたは、わたしの父であって、あなたがたが自分の神だと言っているのは、そのかたのことである。</span>
<span className="v" id="v55" data-v="55" data-xref="ヨハネによる福音書 8:19; ヨハネによる福音書 8:44; ヨハネによる福音書 7:28–29"> あなたがたはその神を知っていないが、わたしは知っている。もしわたしが神を知らないと言うならば、あなたがたと同じような偽り者であろう。しかし、わたしはそのかたを知り、その御言を守っている。</span>
<span className="v" id="v56" data-v="56" data-xref="ヘブル人への手紙 11:13; 創世記 22:18; ガラテヤ人への手紙 3:7–9"> あなたがたの父アブラハムは、わたしのこの日を見ようとして楽しんでいた。そしてそれを見て喜んだ」。</span>
<span className="v" id="v57" data-v="57"> そこでユダヤ人たちはイエスに言った、「あなたはまだ五十にもならないのに、アブラハムを見たのか」。</span>
<span className="v" id="v58" data-v="58" data-xref="出エジプト記 3:14; コロサイ人への手紙 1:17; ヨハネによる福音書 17:5"> イエスは彼らに言われた、「よくよくあなたがたに言っておく。アブラハムの生れる前からわたしは、いるのである」。</span>
<span className="v" id="v59" data-v="59" data-xref="ヨハネによる福音書 11:8; ヨハネによる福音書 10:30–33; ヨハネによる福音書 10:39–40"> そこで彼らは石をとって、イエスに投げつけようとした。しかし、イエスは身を隠して、宮から出て行かれた。</span>

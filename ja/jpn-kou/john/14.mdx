<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="イザヤ書 26:3; ヨハネによる福音書 16:22–23; イザヤ書 12:2–3"> 「あなたがたは、心を騒がせないがよい。神を信じ、またわたしを信じなさい。</span>
<span className="v" id="v2" data-v="2" data-xref="コリント人への第二の手紙 5:1; ヨハネによる福音書 13:36; ヘブル人への手紙 13:14"> わたしの父の家には、すまいがたくさんある。もしなかったならば、わたしはそう言っておいたであろう。あなたがたのために、場所を用意しに行くのだから。</span>
<span className="v" id="v3" data-v="3" data-xref="テサロニケ人への第一の手紙 4:16–17; ヨハネによる福音書 12:26; テモテヘの第二の手紙 2:12"> そして、行って、場所の用意ができたならば、またきて、あなたがたをわたしのところに迎えよう。わたしのおる所にあなたがたもおらせるためである。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネによる福音書 10:9; ヨハネによる福音書 16:28; ヨハネによる福音書 13:3"> わたしがどこへ行くのか、その道はあなたがたにわかっている」。</span>
<span className="v" id="v5" data-v="5" data-xref="ヨハネによる福音書 11:16; マルコによる福音書 9:19; ヨハネによる福音書 20:25–28"> トマスはイエスに言った、「主よ、どこへおいでになるのか、わたしたちにはわかりません。どうしてその道がわかるでしょう」。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行伝 4:12; ヨハネによる福音書 10:9; エペソ人への手紙 2:18"> イエスは彼に言われた、「わたしは道であり、真理であり、命である。だれでもわたしによらないでは、父のみもとに行くことはできない。</span>
<span className="v" id="v7" data-v="7" data-xref="コロサイ人への手紙 1:15–17; ヨハネによる福音書 8:19; ルカによる福音書 10:22"> もしあなたがたがわたしを知っていたならば、わたしの父をも知ったであろう。しかし、今は父を知っており、またすでに父を見たのである」。</span>
<span className="v" id="v8" data-v="8" data-xref="出エジプト記 33:18–23; ヨハネの黙示録 22:3–5; ヨハネによる福音書 1:43–46"> ピリポはイエスに言った、「主よ、わたしたちに父を示して下さい。そうして下されば、わたしたちは満足します」。</span>
<span className="v" id="v9" data-v="9" data-xref="コロサイ人への手紙 1:15; ヨハネによる福音書 12:45; ヨハネによる福音書 14:7"> イエスは彼に言われた、「ピリポよ、こんなに長くあなたがたと一緒にいるのに、わたしがわかっていないのか。わたしを見た者は、父を見たのである。どうして、わたしたちに父を示してほしいと、言うのか。</span>
<span className="v" id="v10" data-v="10" data-xref="ヨハネによる福音書 5:19; ヨハネによる福音書 10:38; ヨハネによる福音書 10:30"> わたしが父におり、父がわたしにおられることをあなたは信じないのか。わたしがあなたがたに話している言葉は、自分から話しているのではない。父がわたしのうちにおられて、みわざをなさっているのである。</span>
<span className="v" id="v11" data-v="11" data-xref="ヨハネによる福音書 10:38; ヨハネによる福音書 10:25; ヨハネによる福音書 5:36"> わたしが父におり、父がわたしにおられることを信じなさい。もしそれが信じられないならば、わざそのものによって信じなさい。</span>
<span className="v" id="v12" data-v="12" data-xref="マタイによる福音書 21:21; マルコによる福音書 16:17; ルカによる福音書 10:17–19"> よくよくあなたがたに言っておく。わたしを信じる者は、またわたしのしているわざをするであろう。そればかりか、もっと大きいわざをするであろう。わたしが父のみもとに行くからである。</span>
<span className="v" id="v13" data-v="13" data-xref="ヨハネによる福音書 15:7; マルコによる福音書 11:24; マタイによる福音書 7:7"> わたしの名によって願うことは、なんでもかなえてあげよう。父が子によって栄光をお受けになるためである。</span>
<span className="v" id="v14" data-v="14"> 何事でもわたしの名によって願うならば、わたしはそれをかなえてあげよう。</span>
<span className="v" id="v15" data-v="15" data-xref="ヨハネの第一の手紙 2:3–5; ヨハネの第一の手紙 5:2–3; ヨハネによる福音書 14:21–24"> もしあなたがたがわたしを愛するならば、わたしのいましめを守るべきである。</span>
<span className="v" id="v16" data-v="16" data-xref="ヨハネによる福音書 14:26; ヨハネによる福音書 15:26; ヨハネによる福音書 16:7–15"> わたしは父にお願いしよう。そうすれば、父は別に助け主を送って、いつまでもあなたがたと共におらせて下さるであろう。</span>
<span className="v" id="v17" data-v="17" data-xref="エゼキエル書 36:27; ヨハネによる福音書 16:13; ヨハネの第一の手紙 2:27"> それは真理の御霊である。この世はそれを見ようともせず、知ろうともしないので、それを受けることができない。あなたがたはそれを知っている。なぜなら、それはあなたがたと共におり、またあなたがたのうちにいるからである。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="ヨハネによる福音書 14:3; 詩篇 23:4; マタイによる福音書 18:20"> わたしはあなたがたを捨てて孤児とはしない。あなたがたのところに帰って来る。</span>
<span className="v" id="v19" data-v="19" data-xref="ヨハネによる福音書 16:16; ヨハネによる福音書 7:33; ヘブル人への手紙 7:25"> もうしばらくしたら、世はもはやわたしを見なくなるだろう。しかし、あなたがたはわたしを見る。わたしが生きるので、あなたがたも生きるからである。</span>
<span className="v" id="v20" data-v="20" data-xref="ヨハネによる福音書 15:5–7; ガラテヤ人への手紙 2:20; ヨハネによる福音書 17:21–23"> その日には、わたしはわたしの父におり、あなたがたはわたしにおり、また、わたしがあなたがたにおることが、わかるであろう。</span>
<span className="v" id="v21" data-v="21" data-xref="ヨハネによる福音書 14:15; ヨハネの第一の手紙 5:3; ヨハネの第一の手紙 2:5"> わたしのいましめを心にいだいてこれを守る者は、わたしを愛する者である。わたしを愛する者は、わたしの父に愛されるであろう。わたしもその人を愛し、その人にわたし自身をあらわすであろう」。</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行伝 1:13; ルカによる福音書 6:16; マタイによる福音書 10:3"> イスカリオテでない方のユダがイエスに言った、「主よ、あなたご自身をわたしたちにあらわそうとして、世にはあらわそうとされないのはなぜですか」。</span>
<span className="v" id="v23" data-v="23" data-xref="ヨハネによる福音書 14:21; ヨハネによる福音書 14:15; ヨハネの黙示録 3:20–21"> イエスは彼に答えて言われた、「もしだれでもわたしを愛するならば、わたしの言葉を守るであろう。そして、わたしの父はその人を愛し、また、わたしたちはその人のところに行って、その人と一緒に住むであろう。</span>
<span className="v" id="v24" data-v="24" data-xref="ヨハネによる福音書 7:16; ヨハネによる福音書 14:10; ヨハネによる福音書 8:42"> わたしを愛さない者はわたしの言葉を守らない。あなたがたが聞いている言葉は、わたしの言葉ではなく、わたしをつかわされた父の言葉である。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="ヨハネによる福音書 17:6–8; ヨハネによる福音書 13:19; ヨハネによる福音書 16:12"> これらのことは、あなたがたと一緒にいた時、すでに語ったことである。</span>
<span className="v" id="v26" data-v="26" data-xref="ヨハネによる福音書 15:26; ヨハネによる福音書 14:16; ヨハネの第一の手紙 2:27"> しかし、助け主、すなわち、父がわたしの名によってつかわされる聖霊は、あなたがたにすべてのことを教え、またわたしが話しておいたことを、ことごとく思い起させるであろう。</span>
<span className="v" id="v27" data-v="27" data-xref="ピリピ人への手紙 4:7; ヨハネによる福音書 16:33; イザヤ書 41:10"> わたしは平安をあなたがたに残して行く。わたしの平安をあなたがたに与える。わたしが与えるのは、世が与えるようなものとは異なる。あなたがたは心を騒がせるな、またおじけるな。</span>
<span className="v" id="v28" data-v="28" data-xref="ヨハネによる福音書 10:29–30; コリント人への第一の手紙 15:24–28; コリント人への第一の手紙 11:3"> 『わたしは去って行くが、またあなたがたのところに帰って来る』と、わたしが言ったのを、あなたがたは聞いている。もしわたしを愛しているなら、わたしが父のもとに行くのを喜んでくれるであろう。父がわたしより大きいかたであるからである。</span>
<span className="v" id="v29" data-v="29" data-xref="ヨハネによる福音書 13:19; ヨハネによる福音書 16:4–31; マタイによる福音書 24:24–25"> 今わたしは、そのことが起らない先にあなたがたに語った。それは、事が起った時にあなたがたが信じるためである。</span>
<span className="v" id="v30" data-v="30" data-xref="ヨハネの第一の手紙 5:19; ヨハネの第一の手紙 4:4; ヨハネの黙示録 12:9"> わたしはもはや、あなたがたに、多くを語るまい。この世の君が来るからである。だが、彼はわたしに対して、なんの力もない。</span>
<span className="v" id="v31" data-v="31" data-xref="ヨハネによる福音書 10:18; ピリピ人への手紙 2:8; ヨハネによる福音書 12:49"> しかし、わたしが父を愛していることを世が知るように、わたしは父がお命じになったとおりのことを行うのである。立て。さあ、ここから出かけて行こう。</span>
</div>

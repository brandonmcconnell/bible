<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨハネによる福音書 4:46; 箴言 31:10–12; ヨハネによる福音書 21:2"> 三日目にガリラヤのカナに婚礼があって、イエスの母がそこにいた。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネによる福音書 1:40–49; マタイによる福音書 10:40–42; コリント人への第一の手紙 7:39"> イエスも弟子たちも、その婚礼に招かれた。</span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 104:15; ピリピ人への手紙 4:6; イザヤ書 24:11"> ぶどう酒がなくなったので、母はイエスに言った、「ぶどう酒がなくなってしまいました」。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネによる福音書 7:6; ヨハネによる福音書 13:1; ヨハネによる福音書 7:30"> イエスは母に言われた、「婦人よ、あなたは、わたしと、なんの係わりがありますか。わたしの時は、まだきていません」。</span>
<span className="v" id="v5" data-v="5" data-xref="ヨハネによる福音書 15:14; 創世記 6:22; ヘブル人への手紙 11:8"> 母は僕たちに言った、「このかたが、あなたがたに言いつけることは、なんでもして下さい」。</span>
<span className="v" id="v6" data-v="6" data-xref="ヨハネによる福音書 3:25; ヘブル人への手紙 9:10; エペソ人への手紙 5:26"> そこには、ユダヤ人のきよめのならわしに従って、それぞれ四、五斗もはいる石の水がめが、六つ置いてあった。</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀下 4:2–6; ヨハネによる福音書 2:5; ヨハネによる福音書 2:3"> イエスは彼らに「かめに水をいっぱい入れなさい」と言われたので、彼らは口のところまでいっぱいに入れた。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨハネによる福音書 2:9; 箴言 3:5–6; ローマ人への手紙 13:7"> そこで彼らに言われた、「さあ、くんで、料理がしらのところに持って行きなさい」。すると、彼らは持って行った。</span>
<span className="v" id="v9" data-v="9" data-xref="ヨハネによる福音書 4:46; ヨハネによる福音書 7:17; 詩篇 119:100"> 料理がしらは、ぶどう酒になった水をなめてみたが、それがどこからきたのか知らなかったので、（水をくんだ僕たちは知っていた）花婿を呼んで</span>
<span className="v" id="v10" data-v="10" data-xref="ヨハネの黙示録 7:16–17; 箴言 9:1–6; ルカによる福音書 16:25"> 言った、「どんな人でも、初めによいぶどう酒を出して、酔いがまわったころにわるいのを出すものだ。それだのに、あなたはよいぶどう酒を今までとっておかれました」。</span>
<span className="v" id="v11" data-v="11" data-xref="ヨハネによる福音書 20:30–31; ヨハネによる福音書 1:14; ヨハネによる福音書 3:2"> イエスは、この最初のしるしをガリラヤのカナで行い、その栄光を現された。そして弟子たちはイエスを信じた。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="マタイによる福音書 12:46; マタイによる福音書 13:55–56; マルコによる福音書 6:3"> そののち、イエスは、その母、兄弟たち、弟子たちと一緒に、カペナウムに下って、幾日かそこにとどまられた。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="ルカによる福音書 2:41; ヨハネによる福音書 11:55; ヨハネによる福音書 2:23"> さて、ユダヤ人の過越の祭が近づいたので、イエスはエルサレムに上られた。</span>
<span className="v" id="v14" data-v="14" data-xref="ルカによる福音書 19:45–46; マルコによる福音書 11:15; マルコによる福音書 11:17"> そして牛、羊、はとを売る者や両替する者などが宮の庭にすわり込んでいるのをごらんになって、</span>
<span className="v" id="v15" data-v="15" data-xref="ヨハネによる福音書 18:6; ゼカリヤ書 4:6; コリント人への第二の手紙 10:4"> なわでむちを造り、羊も牛もみな宮から追いだし、両替人の金を散らし、その台をひっくりかえし、</span>
<span className="v" id="v16" data-v="16" data-xref="マタイによる福音書 21:13; エレミヤ書 7:11; マルコによる福音書 11:17"> はとを売る人々には「これらのものを持って、ここから出て行け。わたしの父の家を商売の家とするな」と言われた。</span>
<span className="v" id="v17" data-v="17" data-xref="詩篇 69:9; 詩篇 119:139"> 弟子たちは、「あなたの家を思う熱心が、わたしを食いつくすであろう」と書いてあることを思い出した。</span>
<span className="v" id="v18" data-v="18" data-xref="マタイによる福音書 21:23; マルコによる福音書 8:11; マルコによる福音書 11:27–28"> そこで、ユダヤ人はイエスに言った、「こんなことをするからには、どんなしるしをわたしたちに見せてくれますか」。</span>
<span className="v" id="v19" data-v="19" data-xref="マルコによる福音書 14:58; マルコによる福音書 15:29; マタイによる福音書 27:40"> イエスは彼らに答えて言われた、「この神殿をこわしたら、わたしは三日のうちに、それを起すであろう」。</span>
<span className="v" id="v20" data-v="20"> そこで、ユダヤ人たちは言った、「この神殿を建てるのには、四十六年もかかっています。それだのに、あなたは三日のうちに、それを建てるのですか」。</span>
<span className="v" id="v21" data-v="21" data-xref="コリント人への第一の手紙 6:19; コリント人への第一の手紙 3:16; エペソ人への手紙 2:20–22"> イエスは自分のからだである神殿のことを言われたのである。</span>
<span className="v" id="v22" data-v="22" data-xref="ヨハネによる福音書 12:16; ヨハネによる福音書 16:4; ルカによる福音書 24:7–8"> それで、イエスが死人の中からよみがえったとき、弟子たちはイエスがこう言われたことを思い出して、聖書とイエスのこの言葉とを信じた。</span>
<span className="v" id="v23" data-v="23" data-xref="ヨハネによる福音書 7:31; ルカによる福音書 8:13; ヨハネによる福音書 6:14"> 過越の祭の間、イエスがエルサレムに滞在しておられたとき、多くの人々は、その行われたしるしを見て、イエスの名を信じた。</span>
<span className="v" id="v24" data-v="24" data-xref="ヨハネによる福音書 6:64; ヘブル人への手紙 4:13; 使徒行伝 1:24"> しかしイエスご自身は、彼らに自分をお任せにならなかった。それは、すべての人を知っておられ、</span>
<span className="v" id="v25" data-v="25" data-xref="ヨハネによる福音書 13:11; マタイによる福音書 9:4; ヨハネによる福音書 6:64"> また人についてあかしする者を、必要とされなかったからである。それは、ご自身人の心の中にあることを知っておられたからである。</span>
</div>

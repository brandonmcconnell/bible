<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マルコによる福音書 16:9; マタイによる福音書 27:60; ヨハネによる福音書 19:25"> さて、一週の初めの日に、朝早くまだ暗いうちに、マグダラのマリヤが墓に行くと、墓から石がとりのけてあるのを見た。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネによる福音書 13:23; ヨハネによる福音書 20:13; ヨハネによる福音書 21:24"> そこで走って、シモン・ペテロとイエスが愛しておられた、もうひとりの弟子のところへ行って、彼らに言った、「だれかが、主を墓から取り去りました。どこへ置いたのか、わかりません」。</span>
<span className="v" id="v3" data-v="3" data-xref="ルカによる福音書 24:12"> そこでペテロともうひとりの弟子は出かけて、墓へむかって行った。</span>
<span className="v" id="v4" data-v="4" data-xref="サムエル記下 18:23; コリント人への第二の手紙 8:12; コリント人への第一の手紙 9:24"> ふたりは一緒に走り出したが、そのもうひとりの弟子の方が、ペテロよりも早く走って先に墓に着き、</span>
<span className="v" id="v5" data-v="5" data-xref="ヨハネによる福音書 19:40; ヨハネによる福音書 20:11; ヨハネによる福音書 11:44"> そして身をかがめてみると、亜麻布がそこに置いてあるのを見たが、中へははいらなかった。</span>
<span className="v" id="v6" data-v="6" data-xref="ヨハネによる福音書 18:17; ヨハネによる福音書 21:7; マタイによる福音書 16:15–16"> シモン・ペテロも続いてきて、墓の中にはいった。彼は亜麻布がそこに置いてあるのを見たが、</span>
<span className="v" id="v7" data-v="7" data-xref="ヨハネによる福音書 11:44"> イエスの頭に巻いてあった布は亜麻布のそばにはなくて、はなれた別の場所にくるめてあった。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨハネによる福音書 20:25; ヨハネによる福音書 20:4; ヨハネによる福音書 1:50"> すると、先に墓に着いたもうひとりの弟子もはいってきて、これを見て信じた。</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 16:10; イザヤ書 25:8; イザヤ書 53:10–12"> しかし、彼らは死人のうちからイエスがよみがえるべきことをしるした聖句を、まだ悟っていなかった。</span>
<span className="v" id="v10" data-v="10" data-xref="ヨハネによる福音書 7:53; ヨハネによる福音書 16:32"> それから、ふたりの弟子たちは自分の家に帰って行った。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="ヨハネによる福音書 20:5"> しかし、マリヤは墓の外に立って泣いていた。そして泣きながら、身をかがめて墓の中をのぞくと、</span>
<span className="v" id="v12" data-v="12" data-xref="ルカによる福音書 24:3–7; ヨハネの黙示録 3:4; マルコによる福音書 16:5–6"> 白い衣を着たふたりの御使が、イエスの死体のおかれていた場所に、ひとりは頭の方に、ひとりは足の方に、すわっているのを見た。</span>
<span className="v" id="v13" data-v="13" data-xref="ヨハネによる福音書 20:15; ヨハネによる福音書 2:4; サムエル記上 1:8"> すると、彼らはマリヤに、「女よ、なぜ泣いているのか」と言った。マリヤは彼らに言った、「だれかが、わたしの主を取り去りました。そして、どこに置いたのか、わからないのです」。</span>
<span className="v" id="v14" data-v="14" data-xref="ルカによる福音書 24:16; ヨハネによる福音書 21:4; マタイによる福音書 28:9"> そう言って、うしろをふり向くと、そこにイエスが立っておられるのを見た。しかし、それがイエスであることに気がつかなかった。</span>
<span className="v" id="v15" data-v="15" data-xref="ヨハネによる福音書 20:13; ヨハネによる福音書 18:7; ヨハネによる福音書 1:38"> イエスは女に言われた、「女よ、なぜ泣いているのか。だれを捜しているのか」。マリヤは、その人が園の番人だと思って言った、「もしあなたが、あのかたを移したのでしたら、どこへ置いたのか、どうぞ、おっしゃって下さい。わたしがそのかたを引き取ります」。</span>
<span className="v" id="v16" data-v="16" data-xref="ヨハネによる福音書 10:3; ヨハネによる福音書 1:38; 使徒行伝 10:3"> イエスは彼女に「マリヤよ」と言われた。マリヤはふり返って、イエスにむかってヘブル語で「ラボニ」と言った。それは、先生という意味である。</span>
<span className="v" id="v17" data-v="17" data-xref="ヨハネによる福音書 16:28; エペソ人への手紙 4:8–10; ガラテヤ人への手紙 4:6–7"> イエスは彼女に言われた、「わたしにさわってはいけない。わたしは、まだ父のみもとに上っていないのだから。ただ、わたしの兄弟たちの所に行って、『わたしは、わたしの父またあなたがたの父であって、わたしの神またあなたがたの神であられるかたのみもとへ上って行く』と、彼らに伝えなさい」。</span>
<span className="v" id="v18" data-v="18" data-xref="ルカによる福音書 24:10; マタイによる福音書 28:10; ヨハネによる福音書 20:1"> マグダラのマリヤは弟子たちのところに行って、自分が主に会ったこと、またイエスがこれこれのことを自分に仰せになったことを、報告した。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="ヨハネによる福音書 20:26; ヨハネによる福音書 14:27; ヨハネによる福音書 20:21"> その日、すなわち、一週の初めの日の夕方、弟子たちはユダヤ人をおそれて、自分たちのおる所の戸をみなしめていると、イエスがはいってきて、彼らの中に立ち、「安かれ」と言われた。</span>
<span className="v" id="v20" data-v="20" data-xref="ヨハネによる福音書 16:22; ヨハネによる福音書 16:20; ヨハネによる福音書 20:27"> そう言って、手とわきとを、彼らにお見せになった。弟子たちは主を見て喜んだ。</span>
<span className="v" id="v21" data-v="21" data-xref="ヨハネによる福音書 17:18–19; ヨハネによる福音書 13:20; ヨハネによる福音書 3:17"> イエスはまた彼らに言われた、「安かれ。父がわたしをおつかわしになったように、わたしもまたあなたがたをつかわす」。</span>
<span className="v" id="v22" data-v="22" data-xref="ヨブ記 33:4; 創世記 2:7; 使徒行伝 8:15"> そう言って、彼らに息を吹きかけて仰せになった、「聖霊を受けよ。</span>
<span className="v" id="v23" data-v="23" data-xref="マタイによる福音書 18:18; マタイによる福音書 16:19; マルコによる福音書 2:5–10"> あなたがたがゆるす罪は、だれの罪でもゆるされ、あなたがたがゆるさずにおく罪は、そのまま残るであろう」。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="ヨハネによる福音書 11:16; ヨハネによる福音書 6:66–67; ヘブル人への手紙 10:25"> 十二弟子のひとりで、デドモと呼ばれているトマスは、イエスがこられたとき、彼らと一緒にいなかった。</span>
<span className="v" id="v25" data-v="25" data-xref="ヨハネによる福音書 6:30; マルコによる福音書 16:11; ヘブル人への手紙 3:12"> ほかの弟子たちが、彼に「わたしたちは主にお目にかかった」と言うと、トマスは彼らに言った、「わたしは、その手に釘あとを見、わたしの指をその釘あとにさし入れ、また、わたしの手をそのわきにさし入れてみなければ、決して信じない」。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="ヨハネによる福音書 20:19; イザヤ書 54:10; ヨハネによる福音書 20:21"> 八日ののち、イエスの弟子たちはまた家の内におり、トマスも一緒にいた。戸はみな閉ざされていたが、イエスがはいってこられ、中に立って「安かれ」と言われた。</span>
<span className="v" id="v27" data-v="27" data-xref="ヨハネによる福音書 20:25; ヨハネの第一の手紙 1:1–2; ヨハネによる福音書 20:20"> それからトマスに言われた、「あなたの指をここにつけて、わたしの手を見なさい。手をのばしてわたしのわきにさし入れてみなさい。信じない者にならないで、信じる者になりなさい」。</span>
<span className="v" id="v28" data-v="28" data-xref="ヨハネによる福音書 1:1; イザヤ書 9:6; イザヤ書 7:14"> トマスはイエスに答えて言った、「わが主よ、わが神よ」。</span>
<span className="v" id="v29" data-v="29" data-xref="ペテロの第一の手紙 1:8; コリント人への第二の手紙 5:7; ヘブル人への手紙 11:1"> イエスは彼に言われた、「あなたはわたしを見たので信じたのか。見ないで信ずる者は、さいわいである」。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="ヨハネによる福音書 21:25; テモテヘの第二の手紙 3:15–17; ローマ人への手紙 15:4"> イエスは、この書に書かれていないしるしを、ほかにも多く、弟子たちの前で行われた。</span>
<span className="v" id="v31" data-v="31" data-xref="使徒行伝 10:43; ヨハネによる福音書 3:15–16; ヨハネの第一の手紙 5:1"> しかし、これらのことを書いたのは、あなたがたがイエスは神の子キリストであると信じるためであり、また、そう信じて、イエスの名によって命を得るためである。</span>
</div>

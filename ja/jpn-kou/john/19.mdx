<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="イザヤ書 53:5; イザヤ書 50:6; マタイによる福音書 20:19"> そこでピラトは、イエスを捕え、むちで打たせた。</span>
<span className="v" id="v2" data-v="2" data-xref="マルコによる福音書 15:16–20; ルカによる福音書 23:11; マタイによる福音書 27:27–31"> 兵卒たちは、いばらで冠をあんで、イエスの頭にかぶらせ、紫の上着を着せ、</span>
<span className="v" id="v3" data-v="3" data-xref="マタイによる福音書 27:29; マタイによる福音書 26:49; ルカによる福音書 1:28"> それから、その前に進み出て、「ユダヤ人の王、ばんざい」と言った。そして平手でイエスを打ちつづけた。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネによる福音書 18:38; ヨハネによる福音書 19:6; ルカによる福音書 23:4"> するとピラトは、また出て行ってユダヤ人たちに言った、「見よ、わたしはこの人をあなたがたの前に引き出すが、それはこの人になんの罪も見いだせないことを、あなたがたに知ってもらうためである」。</span>
<span className="v" id="v5" data-v="5" data-xref="ヨハネによる福音書 19:2; ヘブル人への手紙 12:2; イザヤ書 7:14"> イエスはいばらの冠をかぶり、紫の上着を着たままで外へ出られると、ピラトは彼らに言った、「見よ、この人だ」。</span>
<span className="v" id="v6" data-v="6" data-xref="ヨハネによる福音書 18:31; ヨハネによる福音書 19:4; 使徒行伝 2:23"> 祭司長たちや下役どもはイエスを見ると、叫んで「十字架につけよ、十字架につけよ」と言った。ピラトは彼らに言った、「あなたがたが、この人を引き取って十字架につけるがよい。わたしは、彼にはなんの罪も見いだせない」。</span>
<span className="v" id="v7" data-v="7" data-xref="レビ記 24:16; ヨハネによる福音書 5:18; マタイによる福音書 26:63–66"> ユダヤ人たちは彼に答えた、「わたしたちには律法があります。その律法によれば、彼は自分を神の子としたのだから、死罪に当る者です」。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨハネによる福音書 19:13; 使徒行伝 14:11–19"> ピラトがこの言葉を聞いたとき、ますますおそれ、</span>
<span className="v" id="v9" data-v="9" data-xref="ヨハネによる福音書 18:33; 詩篇 38:13–15; ピリピ人への手紙 1:28"> もう一度官邸にはいってイエスに言った、「あなたは、もともと、どこからきたのか」。しかし、イエスはなんの答もなさらなかった。</span>
<span className="v" id="v10" data-v="10" data-xref="ダニエル書 5:19; ヨハネによる福音書 18:39; ダニエル書 3:14–15"> そこでピラトは言った、「何も答えないのか。わたしには、あなたを許す権威があり、また十字架につける権威があることを、知らないのか」。</span>
<span className="v" id="v11" data-v="11" data-xref="ローマ人への手紙 13:1; ヨハネによる福音書 3:27; 使徒行伝 2:23"> イエスは答えられた、「あなたは、上から賜わるのでなければ、わたしに対してなんの権威もない。だから、わたしをあなたに引き渡した者の罪は、もっと大きい」。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行伝 17:6–7; ヨハネによる福音書 18:33–36; マルコによる福音書 6:16–26"> これを聞いて、ピラトはイエスを許そうと努めた。しかしユダヤ人たちが叫んで言った、「もしこの人を許したなら、あなたはカイザルの味方ではありません。自分を王とするものはすべて、カイザルにそむく者です」。</span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 82:5–7; マタイによる福音書 27:19; アモス書 4:7"> ピラトはこれらの言葉を聞いて、イエスを外へ引き出して行き、敷石（ヘブル語ではガバタ）という場所で裁判の席についた。</span>
<span className="v" id="v14" data-v="14" data-xref="マタイによる福音書 27:62; ヨハネによる福音書 19:5; マルコによる福音書 15:25"> その日は過越の準備の日であって、時は昼の十二時ころであった。ピラトはユダヤ人らに言った、「見よ、これがあなたがたの王だ」。</span>
<span className="v" id="v15" data-v="15" data-xref="ルカによる福音書 23:18; 使徒行伝 21:36; ヨハネによる福音書 19:6"> すると彼らは叫んだ、「殺せ、殺せ、彼を十字架につけよ」。ピラトは彼らに言った、「あなたがたの王を、わたしが十字架につけるのか」。祭司長たちは答えた、「わたしたちには、カイザル以外に王はありません」。</span>
<span className="v" id="v16" data-v="16" data-xref="ルカによる福音書 23:24–25; マタイによる福音書 27:26–31; マルコによる福音書 15:15–20"> そこでピラトは、十字架につけさせるために、イエスを彼らに引き渡した。<br />彼らはイエスを引き取った。</span>
<span className="v" id="v17" data-v="17" data-xref="ルカによる福音書 23:33; ルカによる福音書 14:27; ルカによる福音書 23:26"> イエスはみずから十字架を背負って、されこうべ（ヘブル語ではゴルゴダ）という場所に出て行かれた。</span>
<span className="v" id="v18" data-v="18" data-xref="イザヤ書 53:12; マルコによる福音書 15:24–27; ガラテヤ人への手紙 3:13"> 彼らはそこで、イエスを十字架につけた。イエスをまん中にして、ほかのふたりの者を両側に、イエスと一緒に十字架につけた。</span>
<span className="v" id="v19" data-v="19" data-xref="マタイによる福音書 27:37; ルカによる福音書 23:38; マルコによる福音書 15:26"> ピラトは罪状書きを書いて、十字架の上にかけさせた。それには「ユダヤ人の王、ナザレのイエス」と書いてあった。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行伝 26:14; ヨハネの黙示録 16:16; 使徒行伝 22:2"> イエスが十字架につけられた場所は都に近かったので、多くのユダヤ人がこの罪状書きを読んだ。それはヘブル、ローマ、ギリシヤの国語で書いてあった。</span>
<span className="v" id="v21" data-v="21" data-xref="ヨハネによる福音書 19:14; ヨハネによる福音書 19:19"> ユダヤ人の祭司長たちがピラトに言った、「『ユダヤ人の王』と書かずに、『この人はユダヤ人の王と自称していた』と書いてほしい」。</span>
<span className="v" id="v22" data-v="22" data-xref="詩篇 76:10; 詩篇 65:7; 箴言 8:29"> ピラトは答えた、「わたしが書いたことは、書いたままにしておけ」。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="ルカによる福音書 23:34; マルコによる福音書 15:24; マタイによる福音書 27:35"> さて、兵卒たちはイエスを十字架につけてから、その上着をとって四つに分け、おのおの、その一つを取った。また下着を手に取ってみたが、それには縫い目がなく、上の方から全部一つに織ったものであった。</span>
<span className="v" id="v24" data-v="24" data-xref="詩篇 22:18; ヨハネによる福音書 19:28; ヨハネによる福音書 19:36–37"> そこで彼らは互に言った、「それを裂かないで、だれのものになるか、くじを引こう」。これは、「彼らは互にわたしの上着を分け合い、わたしの衣をくじ引にした」という聖書が成就するためで、兵卒たちはそのようにしたのである。</span>
<span className="v" id="v25" data-v="25" data-xref="ルカによる福音書 23:49; マタイによる福音書 27:55–56; ヨハネによる福音書 20:1"> さて、イエスの十字架のそばには、イエスの母と、母の姉妹と、クロパの妻マリヤと、マグダラのマリヤとが、たたずんでいた。</span>
<span className="v" id="v26" data-v="26" data-xref="ヨハネによる福音書 21:24; ヨハネによる福音書 20:2; ヨハネによる福音書 2:4"> イエスは、その母と愛弟子とがそばに立っているのをごらんになって、母にいわれた、「婦人よ、ごらんなさい。これはあなたの子です」。</span>
<span className="v" id="v27" data-v="27" data-xref="マタイによる福音書 12:48–50; ヨハネによる福音書 16:32; テモテヘの第一の手紙 5:2–4"> それからこの弟子に言われた、「ごらんなさい。これはあなたの母です」。そのとき以来、この弟子はイエスの母を自分の家に引きとった。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="詩篇 69:21; 詩篇 22:15; ヨハネによる福音書 19:30"> そののち、イエスは今や万事が終ったことを知って、「わたしは、かわく」と言われた。それは、聖書が全うされるためであった。</span>
<span className="v" id="v29" data-v="29" data-xref="民数記 19:18; ルカによる福音書 23:36; マルコによる福音書 15:36"> そこに、酢いぶどう酒がいっぱい入れてある器がおいてあったので、人々は、このぶどう酒を含ませた海綿をヒソプの茎に結びつけて、イエスの口もとにさし出した。</span>
<span className="v" id="v30" data-v="30" data-xref="ヨハネによる福音書 17:4; ピリピ人への手紙 2:8; コロサイ人への手紙 2:14–17"> すると、イエスはそのぶどう酒を受けて、「すべてが終った」と言われ、首をたれて息をひきとられた。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="ヨハネによる福音書 19:14; ヨハネによる福音書 19:42; マルコによる福音書 15:42"> さてユダヤ人たちは、その日が準備の日であったので、安息日に死体を十字架の上に残しておくまいと、（特にその安息日は大事な日であったから）、ピラトに願って、足を折った上で、死体を取りおろすことにした。</span>
<span className="v" id="v32" data-v="32" data-xref="ヨハネによる福音書 19:18; ルカによる福音書 23:39–43"> そこで兵卒らがきて、イエスと一緒に十字架につけられた初めの者と、もうひとりの者との足を折った。</span>
<span className="v" id="v33" data-v="33"> しかし、彼らがイエスのところにきた時、イエスはもう死んでおられたのを見て、その足を折ることはしなかった。</span>
<span className="v" id="v34" data-v="34" data-xref="ヨハネの第一の手紙 5:6; ゼカリヤ書 12:10; ゼカリヤ書 13:1"> しかし、ひとりの兵卒がやりでそのわきを突きさすと、すぐ血と水とが流れ出た。</span>
<span className="v" id="v35" data-v="35" data-xref="ヨハネによる福音書 21:24; ヘブル人への手紙 2:3–4; ヨハネの第一の手紙 1:1–3"> それを見た者があかしをした。そして、そのあかしは真実である。その人は、自分が真実を語っていることを知っている。それは、あなたがたも信ずるようになるためである。</span>
<span className="v" id="v36" data-v="36" data-xref="詩篇 34:20; 民数記 9:12; 出エジプト記 12:46"> これらのことが起ったのは、「その骨はくだかれないであろう」との聖書の言葉が、成就するためである。</span>
<span className="v" id="v37" data-v="37" data-xref="ゼカリヤ書 12:10; ヨハネの黙示録 1:7; 詩篇 22:16–17"> また聖書のほかのところに、「彼らは自分が刺し通した者を見るであろう」とある。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="マルコによる福音書 15:42–47; マタイによる福音書 27:57–61; 箴言 29:25"> そののち、ユダヤ人をはばかって、ひそかにイエスの弟子となったアリマタヤのヨセフという人が、イエスの死体を取りおろしたいと、ピラトに願い出た。ピラトはそれを許したので、彼はイエスの死体を取りおろしに行った。</span>
<span className="v" id="v39" data-v="39" data-xref="ヨハネによる福音書 7:50–52; 雅歌 4:14; ヨハネによる福音書 3:1–21"> また、前に、夜、イエスのみもとに行ったニコデモも、没薬と沈香とをまぜたものを百斤ほど持ってきた。</span>
<span className="v" id="v40" data-v="40" data-xref="ヨハネによる福音書 11:44; ヨハネによる福音書 20:5–7; 使徒行伝 5:6"> 彼らは、イエスの死体を取りおろし、ユダヤ人の埋葬の習慣にしたがって、香料を入れて亜麻布で巻いた。</span>
<span className="v" id="v41" data-v="41" data-xref="ルカによる福音書 23:53; マタイによる福音書 27:60; ヨハネによる福音書 20:15"> イエスが十字架にかけられた所には、一つの園があり、そこにはまだだれも葬られたことのない新しい墓があった。</span>
<span className="v" id="v42" data-v="42" data-xref="ヨハネによる福音書 19:31; ヨハネによる福音書 19:14; イザヤ書 53:9"> その日はユダヤ人の準備の日であったので、その墓が近くにあったため、イエスをそこに納めた。</span>
</div>

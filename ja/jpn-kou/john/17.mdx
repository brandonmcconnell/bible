<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨハネによる福音書 13:31–32; ヨハネによる福音書 17:4–5; ピリピ人への手紙 2:9–11"> これらのことを語り終えると、イエスは天を見あげて言われた、「父よ、時がきました。あなたの子があなたの栄光をあらわすように、子の栄光をあらわして下さい。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネによる福音書 10:28–29; ヨハネによる福音書 6:39; ダニエル書 7:14"> あなたは、子に賜わったすべての者に、永遠の命を授けさせるため、万民を支配する権威を子にお与えになったのですから。</span>
<span className="v" id="v3" data-v="3" data-xref="ヨハネの第一の手紙 5:20; ヨハネの第一の手紙 5:11–12; エレミヤ書 9:23–24"> 永遠の命とは、唯一の、まことの神でいますあなたと、また、あなたがつかわされたイエス・キリストとを知ることであります。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネによる福音書 4:34; 使徒行伝 20:24; テモテヘの第二の手紙 4:7"> わたしは、わたしにさせるためにお授けになったわざをなし遂げて、地上であなたの栄光をあらわしました。</span>
<span className="v" id="v5" data-v="5" data-xref="ヨハネによる福音書 1:1–3; コロサイ人への手紙 1:15–17; ヨハネによる福音書 10:30"> 父よ、世が造られる前に、わたしがみそばで持っていた栄光で、今み前にわたしを輝かせて下さい。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="ヨハネによる福音書 17:26; ヨハネによる福音書 14:21–24; ヨハネの第一の手紙 5:20"> わたしは、あなたが世から選んでわたしに賜わった人々に、み名をあらわしました。彼らはあなたのものでありましたが、わたしに下さいました。そして、彼らはあなたの言葉を守りました。</span>
<span className="v" id="v7" data-v="7" data-xref="ヨハネによる福音書 7:16–17; ヨハネによる福音書 16:15; ヨハネによる福音書 14:7–10"> いま彼らは、わたしに賜わったものはすべて、あなたから出たものであることを知りました。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨハネによる福音書 17:14; ヨハネによる福音書 15:15; ヨハネによる福音書 16:30"> なぜなら、わたしはあなたからいただいた言葉を彼らに与え、そして彼らはそれを受け、わたしがあなたから出たものであることをほんとうに知り、また、あなたがわたしをつかわされたことを信じるに至ったからです。</span>
<span className="v" id="v9" data-v="9" data-xref="ヘブル人への手紙 9:24; ヨハネによる福音書 17:2; ヨハネによる福音書 17:6"> わたしは彼らのためにお願いします。わたしがお願いするのは、この世のためにではなく、あなたがわたしに賜わった者たちのためです。彼らはあなたのものなのです。</span>
<span className="v" id="v10" data-v="10" data-xref="ヨハネによる福音書 10:30; ペテロの第一の手紙 2:9; ヨハネの黙示録 5:8–14"> わたしのものは皆あなたのもの、あなたのものはわたしのものです。そして、わたしは彼らによって栄光を受けました。</span>
<span className="v" id="v11" data-v="11" data-xref="マタイによる福音書 6:9; 箴言 18:10; ヨハネによる福音書 17:12–18"> わたしはもうこの世にはいなくなりますが、彼らはこの世に残っており、わたしはみもとに参ります。聖なる父よ、わたしに賜わった御名によって彼らを守って下さい。それはわたしたちが一つであるように、彼らも一つになるためであります。</span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 109:6–19; ヨハネによる福音書 10:27–28; ヨハネによる福音書 18:9"> わたしが彼らと一緒にいた間は、あなたからいただいた御名によって彼らを守り、また保護してまいりました。彼らのうち、だれも滅びず、ただ滅びの子だけが滅びました。それは聖書が成就するためでした。</span>
<span className="v" id="v13" data-v="13" data-xref="ヘブル人への手紙 12:2; ガラテヤ人への手紙 5:22; ヨハネによる福音書 15:11"> 今わたしはみもとに参ります。そして世にいる間にこれらのことを語るのは、わたしの喜びが彼らのうちに満ちあふれるためであります。</span>
<span className="v" id="v14" data-v="14" data-xref="ヨハネによる福音書 17:16; ヨハネによる福音書 15:18–21; ヨハネの第一の手紙 5:19–20"> わたしは彼らに御言を与えましたが、世は彼らを憎みました。わたしが世のものでないように、彼らも世のものではないからです。</span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 121:7; ヨハネの第一の手紙 5:18; マタイによる福音書 6:13"> わたしがお願いするのは、彼らを世から取り去ることではなく、彼らを悪しき者から守って下さることであります。</span>
<span className="v" id="v16" data-v="16" data-xref="ヨハネによる福音書 17:14"> わたしが世のものでないように、彼らも世のものではありません。</span>
<span className="v" id="v17" data-v="17" data-xref="ヨハネによる福音書 15:3; 詩篇 119:160; エペソ人への手紙 5:26"> 真理によって彼らを聖別して下さい。あなたの御言は真理であります。</span>
<span className="v" id="v18" data-v="18" data-xref="コリント人への第二の手紙 5:20; ヨハネによる福音書 20:21; ヨハネによる福音書 17:3"> あなたがわたしを世につかわされたように、わたしも彼らを世につかわしました。</span>
<span className="v" id="v19" data-v="19" data-xref="テトスヘの手紙 2:14; ヘブル人への手紙 2:11; ヨハネによる福音書 17:17"> また彼らが真理によって聖別されるように、彼らのためわたし自身を聖別いたします。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="ヨハネによる福音書 17:6–11; 使徒行伝 2:41; 使徒行伝 4:4"> わたしは彼らのためばかりではなく、彼らの言葉を聞いてわたしを信じている人々のためにも、お願いいたします。</span>
<span className="v" id="v21" data-v="21" data-xref="コリント人への第一の手紙 12:12; コロサイ人への手紙 3:11–14; ヨハネによる福音書 17:11"> 父よ、それは、あなたがわたしのうちにおられ、わたしがあなたのうちにいるように、みんなの者が一つとなるためであります。すなわち、彼らをもわたしたちのうちにおらせるためであり、それによって、あなたがわたしをおつかわしになったことを、世が信じるようになるためであります。</span>
<span className="v" id="v22" data-v="22" data-xref="コリント人への第二の手紙 3:18; ヨハネによる福音書 14:20; マルコによる福音書 16:17–20"> わたしは、あなたからいただいた栄光を彼らにも与えました。それは、わたしたちが一つであるように、彼らも一つになるためであります。</span>
<span className="v" id="v23" data-v="23" data-xref="ヨハネによる福音書 17:21; ヨハネによる福音書 16:27; ヨハネの第一の手紙 3:1"> わたしが彼らにおり、あなたがわたしにいますのは、彼らが完全に一つとなるためであり、また、あなたがわたしをつかわし、わたしを愛されたように、彼らをお愛しになったことを、世が知るためであります。</span>
<span className="v" id="v24" data-v="24" data-xref="ヨハネによる福音書 17:5; ヨハネによる福音書 12:26; ヨハネによる福音書 14:3"> 父よ、あなたがわたしに賜わった人々が、わたしのいる所に一緒にいるようにして下さい。天地が造られる前からわたしを愛して下さって、わたしに賜わった栄光を、彼らに見させて下さい。</span>
<span className="v" id="v25" data-v="25" data-xref="ヨハネによる福音書 17:11; ヨハネによる福音書 7:29; ヨハネによる福音書 17:8"> 正しい父よ、この世はあなたを知っていません。しかし、わたしはあなたを知り、また彼らも、あなたがわたしをおつかわしになったことを知っています。</span>
<span className="v" id="v26" data-v="26" data-xref="ヨハネによる福音書 17:23; ヨハネによる福音書 17:6; ヨハネによる福音書 15:9"> そしてわたしは彼らに御名を知らせました。またこれからも知らせましょう。それは、あなたがわたしを愛して下さったその愛が彼らのうちにあり、またわたしも彼らのうちにおるためであります」。</span>
</div>

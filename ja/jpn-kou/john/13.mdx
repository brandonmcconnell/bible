<div className="bible-chapter" lang="ja" dir="ltr" data-lang="ja" data-translation="jpn-kou" data-translation-id="jpn_kou" data-translation-label="口語訳" data-book="JHN" data-book-slug="john" data-book-name="ヨハネによる福音書" data-chapter="13" data-verses="38">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨハネによる福音書 12:23; ヨハネの第一の手紙 4:19; ヨハネによる福音書 13:34"> 過越の祭の前に、イエスは、この世を去って父のみもとに行くべき自分の時がきたことを知り、世にいる自分の者たちを愛して、彼らを最後まで愛し通された。</span>
<span className="v" id="v2" data-v="2" data-xref="ヤコブの手紙 1:13–17; 使徒行伝 5:3; ヨハネによる福音書 13:26–27"> 夕食のとき、悪魔はすでにシモンの子イスカリオテのユダの心に、イエスを裏切ろうとする思いを入れていたが、</span>
<span className="v" id="v3" data-v="3" data-xref="ヨハネによる福音書 3:35; マタイによる福音書 11:27; ヘブル人への手紙 1:2"> イエスは、父がすべてのものを自分の手にお与えになったこと、また、自分は神から出てきて、神にかえろうとしていることを思い、</span>
<span className="v" id="v4" data-v="4" data-xref="ルカによる福音書 22:27; コリント人への第二の手紙 8:9; ルカによる福音書 12:37"> 夕食の席から立ち上がって、上着を脱ぎ、手ぬぐいをとって腰に巻き、</span>
<span className="v" id="v5" data-v="5" data-xref="ルカによる福音書 7:44; 詩篇 51:2; 創世記 18:4"> それから水をたらいに入れて、弟子たちの足を洗い、腰に巻いた手ぬぐいでふき始められた。</span>
<span className="v" id="v6" data-v="6" data-xref="マタイによる福音書 3:11–14; ヨハネによる福音書 1:27; ルカによる福音書 5:8"> こうして、シモン・ペテロの番になった。すると彼はイエスに、「主よ、あなたがわたしの足をお洗いになるのですか」と言った。</span>
<span className="v" id="v7" data-v="7" data-xref="ダニエル書 12:8; ヨハネによる福音書 12:16; ヨハネによる福音書 14:26"> イエスは彼に答えて言われた、「わたしのしていることは今あなたにはわからないが、あとでわかるようになるだろう」。</span>
<span className="v" id="v8" data-v="8" data-xref="エゼキエル書 36:25; 使徒行伝 22:16; テトスヘの手紙 3:5"> ペテロはイエスに言った、「わたしの足を決して洗わないで下さい」。イエスは彼に答えられた、「もしわたしがあなたの足を洗わないなら、あなたはわたしとなんの係わりもなくなる」。</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 51:7; 詩篇 51:2; ペテロの第一の手紙 3:21"> シモン・ペテロはイエスに言った、「主よ、では、足だけではなく、どうぞ、手も頭も」。</span>
<span className="v" id="v10" data-v="10" data-xref="ヨハネによる福音書 15:3; コリント人への第二の手紙 7:1; コリント人への第二の手紙 5:17"> イエスは彼に言われた、「すでにからだを洗った者は、足のほかは洗う必要がない。全身がきれいなのだから。あなたがたはきれいなのだ。しかし、みんながそうなのではない」。</span>
<span className="v" id="v11" data-v="11" data-xref="ヨハネによる福音書 13:26; ヨハネによる福音書 13:2; ヨハネによる福音書 13:21"> イエスは自分を裏切る者を知っておられた。それで、「みんながきれいなのではない」と言われたのである。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="ヨハネによる福音書 13:7; ヨハネによる福音書 13:4; エゼキエル書 24:24"> こうして彼らの足を洗ってから、上着をつけ、ふたたび席にもどって、彼らに言われた、「わたしがあなたがたにしたことがわかるか。</span>
<span className="v" id="v13" data-v="13" data-xref="ルカによる福音書 6:46; コリント人への第一の手紙 12:3; ヨハネによる福音書 11:28"> あなたがたはわたしを教師、また主と呼んでいる。そう言うのは正しい。わたしはそのとおりである。</span>
<span className="v" id="v14" data-v="14" data-xref="ペテロの第一の手紙 5:5; 使徒行伝 20:35; ローマ人への手紙 12:16"> しかし、主であり、また教師であるわたしが、あなたがたの足を洗ったからには、あなたがたもまた、互に足を洗い合うべきである。</span>
<span className="v" id="v15" data-v="15" data-xref="ヨハネの第一の手紙 2:6; マタイによる福音書 11:29; ペテロの第一の手紙 3:17–18"> わたしがあなたがたにしたとおりに、あなたがたもするように、わたしは手本を示したのだ。</span>
<span className="v" id="v16" data-v="16" data-xref="ルカによる福音書 6:40; ヨハネによる福音書 15:20; マタイによる福音書 10:24–25"> よくよくあなたがたに言っておく。僕はその主人にまさるものではなく、つかわされた者はつかわした者にまさるものではない。</span>
<span className="v" id="v17" data-v="17" data-xref="ルカによる福音書 11:28; ヤコブの手紙 4:17; ヤコブの手紙 1:25"> もしこれらのことがわかっていて、それを行うなら、あなたがたはさいわいである。</span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 41:9; マタイによる福音書 26:23; ヨハネによる福音書 17:12"> あなたがた全部の者について、こう言っているのではない。わたしは自分が選んだ人たちを知っている。しかし、『わたしのパンを食べている者が、わたしにむかってそのかかとをあげた』とある聖書は成就されなければならない。</span>
<span className="v" id="v19" data-v="19" data-xref="イザヤ書 43:10; ヨハネによる福音書 14:29; ヨハネによる福音書 16:4"> そのことがまだ起らない今のうちに、あなたがたに言っておく。いよいよ事が起ったとき、わたしがそれであることを、あなたがたが信じるためである。</span>
<span className="v" id="v20" data-v="20" data-xref="ルカによる福音書 10:16; ルカによる福音書 9:48; マタイによる福音書 25:40"> よくよくあなたがたに言っておく。わたしがつかわす者を受けいれる者は、わたしを受けいれるのである。わたしを受けいれる者は、わたしをつかわされたかたを、受けいれるのである」。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="ヨハネによる福音書 13:18; マタイによる福音書 26:21; マルコによる福音書 14:18"> イエスがこれらのことを言われた後、その心が騒ぎ、おごそかに言われた、「よくよくあなたがたに言っておく。あなたがたのうちのひとりが、わたしを裏切ろうとしている」。</span>
<span className="v" id="v22" data-v="22" data-xref="ルカによる福音書 22:23; マタイによる福音書 26:22; マルコによる福音書 14:19"> 弟子たちはだれのことを言われたのか察しかねて、互に顔を見合わせた。</span>
<span className="v" id="v23" data-v="23" data-xref="ヨハネによる福音書 19:26; ヨハネによる福音書 21:7; ヨハネによる福音書 21:20"> 弟子たちのひとりで、イエスの愛しておられた者が、み胸に近く席についていた。</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行伝 12:17; ルカによる福音書 1:22; 使徒行伝 13:16"> そこで、シモン・ペテロは彼に合図をして言った、「だれのことをおっしゃったのか、知らせてくれ」。</span>
<span className="v" id="v25" data-v="25" data-xref="ヨハネによる福音書 21:20; 創世記 44:4–12; エステル記 7:5"> その弟子はそのままイエスの胸によりかかって、「主よ、だれのことですか」と尋ねると、</span>
<span className="v" id="v26" data-v="26" data-xref="マタイによる福音書 26:23; ヨハネによる福音書 13:30; マルコによる福音書 14:19–20"> イエスは答えられた、「わたしが一きれの食物をひたして与える者が、それである」。そして、一きれの食物をひたしてとり上げ、シモンの子イスカリオテのユダにお与えになった。</span>
<span className="v" id="v27" data-v="27" data-xref="ルカによる福音書 22:3; ヨハネによる福音書 13:2; 伝道の書 9:3"> この一きれの食物を受けるやいなや、サタンがユダにはいった。そこでイエスは彼に言われた、「しようとしていることを、今すぐするがよい」。</span>
<span className="v" id="v28" data-v="28"> 席を共にしていた者のうち、なぜユダにこう言われたのか、わかっていた者はひとりもなかった。</span>
<span className="v" id="v29" data-v="29" data-xref="ヨハネによる福音書 12:5–6; ヨハネによる福音書 13:1; エペソ人への手紙 4:28"> ある人々は、ユダが金入れをあずかっていたので、イエスが彼に、「祭のために必要なものを買え」と言われたか、あるいは、貧しい者に何か施させようとされたのだと思っていた。</span>
<span className="v" id="v30" data-v="30" data-xref="イザヤ書 59:7; ヨブ記 24:13–15; 箴言 4:16"> ユダは一きれの食物を受けると、すぐに出て行った。時は夜であった。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="ヨハネによる福音書 14:13; ペテロの第一の手紙 4:11; ヨハネによる福音書 7:39"> さて、彼が出て行くと、イエスは言われた、「今や人の子は栄光を受けた。神もまた彼によって栄光をお受けになった。</span>
<span className="v" id="v32" data-v="32" data-xref="ヨハネの黙示録 22:1; イザヤ書 53:10–12; ヨハネによる福音書 17:4–6"> 彼によって栄光をお受けになったのなら、神ご自身も彼に栄光をお授けになるであろう。すぐにもお授けになるであろう。</span>
<span className="v" id="v33" data-v="33" data-xref="ヨハネによる福音書 7:33–34; ヨハネによる福音書 8:21–24; ヨハネによる福音書 16:16–22"> 子たちよ、わたしはまだしばらく、あなたがたと一緒にいる。あなたがたはわたしを捜すだろうが、すでにユダヤ人たちに言ったとおり、今あなたがたにも言う、『あなたがたはわたしの行く所に来ることはできない』。</span>
<span className="v" id="v34" data-v="34" data-xref="エペソ人への手紙 5:2; レビ記 19:18; ヨハネによる福音書 15:17"> わたしは、新しいいましめをあなたがたに与える、互に愛し合いなさい。わたしがあなたがたを愛したように、あなたがたも互に愛し合いなさい。</span>
<span className="v" id="v35" data-v="35" data-xref="ヨハネの第一の手紙 4:20–21; ヨハネの第一の手紙 3:10–14; ヨハネの第一の手紙 2:10"> 互に愛し合うならば、それによって、あなたがたがわたしの弟子であることを、すべての者が認めるであろう」。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="ペテロの第二の手紙 1:14; ヨハネによる福音書 13:33; ヨハネによる福音書 21:21–22"> シモン・ペテロがイエスに言った、「主よ、どこへおいでになるのですか」。イエスは答えられた、「あなたはわたしの行くところに、今はついて来ることはできない。しかし、あとになってから、ついて来ることになろう」。</span>
<span className="v" id="v37" data-v="37" data-xref="使徒行伝 21:13; 使徒行伝 20:24; マルコによる福音書 14:27–31"> ペテロはイエスに言った、「主よ、なぜ、今あなたについて行くことができないのですか。あなたのためには、命も捨てます」。</span>
<span className="v" id="v38" data-v="38" data-xref="ルカによる福音書 22:34; マタイによる福音書 26:34; マルコによる福音書 14:30"> イエスは答えられた、「わたしのために命を捨てると言うのか。よくよくあなたに言っておく。鶏が鳴く前に、あなたはわたしを三度知らないと言うであろう」。</span>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歴代志下 36:5–7; 列王紀下 24:1–2; 列王紀下 24:13"> ユダの王エホヤキムの治世の第三年にバビロンの王ネブカデネザルはエルサレムにきて、これを攻め囲んだ。</span>
<span className="v" id="v2" data-v="2" data-xref="歴代志下 36:7; ゼカリヤ書 5:11; エレミヤ書 27:19–20"> 主はユダの王エホヤキムと、神の宮の器具の一部とを、彼の手にわたされたので、彼はこれをシナルの地の自分の神の宮に携えゆき、その器具を自分の神の蔵に納めた。</span>
<span className="v" id="v3" data-v="3" data-xref="イザヤ書 39:7; 列王紀下 20:17–18; 列王紀下 24:15"> 時に王は宦官の長アシペナズに、イスラエルの人々の中から、王の血統の者と、貴族たる者数人とを、連れて来るように命じた。</span>
<span className="v" id="v4" data-v="4" data-xref="ダニエル書 5:11; 使徒行伝 7:22; 箴言 22:29"> すなわち身に傷がなく、容姿が美しく、すべての知恵にさとく、知識があって、思慮深く、王の宮に仕えるに足る若者を連れてこさせ、これにカルデヤびとの文学と言語とを学ばせようとした。</span>
<span className="v" id="v5" data-v="5" data-xref="ダニエル書 1:19; 列王紀上 10:8; ダニエル書 1:8"> そして王は王の食べる食物と、王の飲む酒の中から、日々の分を彼らに与えて、三年のあいだ彼らを養い育て、その後、彼らをして王の前に、はべらせようとした。</span>
<span className="v" id="v6" data-v="6" data-xref="エゼキエル書 14:14; マタイによる福音書 24:15; ダニエル書 2:17"> 彼らのうちに、ユダの部族のダニエル、ハナニヤ、ミシャエル、アザリヤがあった。</span>
<span className="v" id="v7" data-v="7" data-xref="ダニエル書 5:12; ダニエル書 4:8; ダニエル書 2:49"> 宦官の長は彼らに名を与えて、ダニエルをベルテシャザルと名づけ、ハナニヤをシャデラクと名づけ、ミシャエルをメシャクと名づけ、アザリヤをアベデネゴと名づけた。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="詩篇 141:4; エゼキエル書 4:13–14; レビ記 11:45–47"> ダニエルは王の食物と、王の飲む酒とをもって、自分を汚すまいと、心に思い定めたので、自分を汚させることのないように、宦官の長に求めた。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 39:21; 箴言 16:7; 詩篇 106:46"> 神はダニエルをして、宦官の長の前に、恵みとあわれみとを得させられたので、</span>
<span className="v" id="v10" data-v="10" data-xref="マタイによる福音書 6:16–18; ヨハネによる福音書 12:42–43; 箴言 29:25"> 宦官の長はダニエルに言った、「わが主なる王は、あなたがたの食べ物と、飲み物とを定められたので、わたしはあなたがたの健康の状態が、同年輩の若者たちよりも悪いと、王が見られることを恐れるのです。そうすればあなたがたのために、わたしのこうべが、王の前に危くなるでしょう」。</span>
<span className="v" id="v11" data-v="11"> そこでダニエルは宦官の長がダニエル、ハナニヤ、ミシャエルおよびアザリヤの上に立てた家令に言った、</span>
<span className="v" id="v12" data-v="12" data-xref="ローマ人への手紙 14:2; ダニエル書 1:16; 創世記 1:29–30"> 「どうぞ、しもべらを十日の間ためしてください。わたしたちにただ野菜を与えて食べさせ、水を飲ませ、</span>
<span className="v" id="v13" data-v="13"> そしてわたしたちの顔色と、王の食物を食べる若者の顔色とをくらべて見て、あなたの見るところにしたがって、しもべらを扱ってください」。</span>
<span className="v" id="v14" data-v="14"> 家令はこの事について彼らの言うところを聞きいれ、十日の間、彼らをためした。</span>
<span className="v" id="v15" data-v="15" data-xref="出エジプト記 23:25; 箴言 10:22; 列王紀下 4:42–44"> 十日の終りになってみると、彼らの顔色は王の食物を食べたすべての若者よりも美しく、また肉も肥え太っていた。</span>
<span className="v" id="v16" data-v="16" data-xref="ダニエル書 1:12"> それで家令は彼らの食物と、彼らの飲むべき酒とを除いて、彼らに野菜を与えた。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="列王紀上 3:12; ヤコブの手紙 1:5; ダニエル書 2:21"> この四人の者には、神は知識を与え、すべての文学と知恵にさとい者とされた。ダニエルはまたすべての幻と夢とを理解した。</span>
<span className="v" id="v18" data-v="18" data-xref="ダニエル書 1:5"> さて、王が命じたところの若者を召し入れるまでの日数が過ぎたので、宦官の町は彼らをネブカデネザルの前に連れていった。</span>
<span className="v" id="v19" data-v="19" data-xref="箴言 22:29; 創世記 41:46; ダニエル書 1:5"> 王が彼らと語ってみると、彼らすべての中にはダニエル、ハナニヤ、ミシャエル、アザリヤにならぶ者がなかったので、彼らは王の前にはべることとなった。</span>
<span className="v" id="v20" data-v="20" data-xref="出エジプト記 8:19; イザヤ書 47:12–14; 列王紀上 4:29–34"> 王が彼らにさまざまの事を尋ねてみると、彼らは知恵と理解において、全国の博士、法術士にまさること十倍であった。</span>
<span className="v" id="v21" data-v="21" data-xref="ダニエル書 6:28; ダニエル書 10:1"> ダニエルはクロス王の元年まで仕えていた。</span>
</div>

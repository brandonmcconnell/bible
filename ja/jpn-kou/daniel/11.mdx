<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ダニエル書 9:1; ダニエル書 5:31; ダニエル書 10:18"> わたしはまたメデアびとダリヨスの元年に立って彼を強め、彼を力づけたことがあります。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="エズラ記 4:5–6; ダニエル書 8:26; ヨハネの黙示録 21:5"> わたしは今あなたに真理を示そう。見よ、ペルシャになお三人の王が起るでしょう。その第四の者は、他のすべての者にまさって富み、その富によって強くなったとき、彼はすべてのものを動員して、ギリシヤの国を攻めます。</span>
<span className="v" id="v3" data-v="3" data-xref="ダニエル書 11:16; ダニエル書 11:36; ダニエル書 8:21"> またひとりの勇ましい王が起り、大いなる権力をもって世を治め、その意のままに事をなすでしょう。</span>
<span className="v" id="v4" data-v="4" data-xref="ダニエル書 8:22; ダニエル書 8:8; エレミヤ書 12:17"> 彼が強くなった時、その国は破られ、天の四方に分かたれます。それは彼の子孫に帰せず、また彼が治めたほどの権力もなく、彼の国は抜き取られて、これら以外の者どもに帰するでしょう。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="ダニエル書 11:14; ダニエル書 11:11; ダニエル書 11:25"> 南の王は強くなります。しかしその将軍のひとりが、彼にまさって強くなり、権力をふるいます。その権力は、大いなる権力です。</span>
<span className="v" id="v6" data-v="6" data-xref="ダニエル書 11:13; ダニエル書 11:40; ダニエル書 11:7"> 年を経て後、彼らは縁組をなし、南の王の娘が、北の王にきて、和親をはかります。しかしその女は、その腕の力を保つことができず、またその王も、その子も立つことができません。その女と、その従者と、その子およびその女を獲た者とは、わたされるでしょう。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="ダニエル書 11:38–39; ダニエル書 11:19–20; イザヤ書 9:14"> そのころ、この女の根から、一つの芽が起って彼に代り、北の王の軍勢にむかってきて、その城に討ち入り、これを攻めて勝つでしょう。</span>
<span className="v" id="v8" data-v="8" data-xref="イザヤ書 37:19; イザヤ書 46:1–2; エレミヤ書 43:12–13"> 彼はまた彼らの神々、鋳像および金銀の貴重な器物を、エジプトに携え去り、そして数年の間、北の王を討つことを控えます。</span>
<span className="v" id="v9" data-v="9"> その後、北の王は、南の王の国に討ち入るが、自分の国に帰るでしょう。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="エレミヤ書 51:42; ダニエル書 11:7; ダニエル書 11:26"> その子らはまた憤激して、あまたの大軍を集め、進んで行って、みなぎりあふれ、通り過ぎるが、また行って、その城にまで攻め寄せるでしょう。</span>
<span className="v" id="v11" data-v="11" data-xref="ダニエル書 8:7; ダニエル書 11:5; 詩篇 33:16–17"> そこで南の王は、大いに怒り、出てきて北の王と戦います。彼は大軍を起すけれども、その軍は相手の手にわたされるでしょう。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行伝 12:22–23; 列王紀下 14:10; イザヤ書 10:7–12"> 彼がその軍を打ち破ったとき、その心は高ぶり、数万人を倒します。しかし、勝つことはありません。</span>
<span className="v" id="v13" data-v="13" data-xref="ダニエル書 4:16; ダニエル書 12:7; ダニエル書 11:6–7"> それは北の王がまた初めよりも大いなる軍を起し、数年の後、大いなる軍勢と多くの軍需品とをもって、攻めて来るからです。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="ヨハネの黙示録 17:17; 使徒行伝 4:25–28"> そのころ多くの者が起って、南の王に敵します。またあなたの民のうちのあらくれ者が、みずから高ぶって事をなし、幻を成就しようとするが失敗するでしょう。</span>
<span className="v" id="v15" data-v="15" data-xref="エレミヤ書 6:6; エゼキエル書 17:17; エゼキエル書 4:2"> こうして北の王がきて、塁を築き、堅固な町を取るが、南の王の力は、これに立ち向かうことができず、またそのえり抜きの民も、これに立ち向かう力がありません。</span>
<span className="v" id="v16" data-v="16" data-xref="ダニエル書 8:9; ダニエル書 11:36; ダニエル書 11:3"> これに攻めて来る者は、その心のままに事をなし、その前に立ち向かうことのできる者はなく、彼は麗しい地に立ち、その地は全く彼のために荒されます。</span>
<span className="v" id="v17" data-v="17" data-xref="列王紀下 12:17; エゼキエル書 4:3; エゼキエル書 4:7"> 彼は全国の力をもって討ち入ろうと、その顔を向けるが、相手と仲直りをし、その娘を与えて、その国を取ろうとします。しかし、その事は成らず、また彼の利益にはならないでしょう。</span>
<span className="v" id="v18" data-v="18" data-xref="ホセア書 12:14; エレミヤ書 31:10; ゼパニヤ書 2:11"> その後、彼は顔を海沿いの国々に向けて、その多くのものを取ります。しかし、ひとりの大将があって、彼が与えた恥辱をそそぎ、その恥辱を彼の上に返します。</span>
<span className="v" id="v19" data-v="19" data-xref="エゼキエル書 26:21; 詩篇 37:36; ヨブ記 20:8"> こうして彼は、その顔を自分の国の要害に向けるが、彼はつまずき倒れて消えうせるでしょう。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="イザヤ書 60:17; ダニエル書 11:7; 申命記 15:2–3"> 彼に代って起る者は、栄光の国に人をつかわして、租税を取り立てさせるでしょう。しかし彼は、怒りにも戦いにもよらず、数日のうちに滅ぼされます。</span>
<span className="v" id="v21" data-v="21" data-xref="ダニエル書 11:34; ダニエル書 8:25; 士師記 9:1–20"> 彼に代って起る者は、卑しむべき者であって、彼には、王の尊厳が与えられず、彼は不意にきて、巧言をもって国を獲るでしょう。</span>
<span className="v" id="v22" data-v="22" data-xref="ダニエル書 8:10–11; ダニエル書 11:10; ダニエル書 9:26"> 洪水のような軍勢は、彼の前に押し流されて敗られ、契約の君たる者もまた敗られるでしょう。</span>
<span className="v" id="v23" data-v="23" data-xref="ダニエル書 8:25; テサロニケ人への第二の手紙 2:9; 詩篇 52:2"> 彼は、これと同盟を結んで後、偽りのおこないをなし、わずかな民をもって強くなり、</span>
<span className="v" id="v24" data-v="24" data-xref="ダニエル書 7:25; 箴言 23:7; マタイによる福音書 9:4"> 不意にその州の最も肥えた所に攻め入り、その父も、その父の父もしなかった事をおこない、その奪った物、かすめた物および財宝を、人々の中に散らすでしょう。彼はまた計略をめぐらして、堅固な城を攻めるが、ただし、それは時の至るまでです。</span>
<span className="v" id="v25" data-v="25" data-xref="箴言 15:18; ダニエル書 11:2; 箴言 28:25"> 彼はその勢力と勇気とを奮い起し、大軍を率いて南の王を攻めます。南の王もまたみずから奮い、はなはだ大いなる強力な軍勢をもって戦います。しかし、彼に対して、陰謀をめぐらす者があるので、これに立ち向かうことができません。</span>
<span className="v" id="v26" data-v="26" data-xref="ダニエル書 11:10; ダニエル書 11:40; サムエル記下 4:2–12"> すなわち彼の食物を食べる者たちが、彼を滅ぼします。そして、その軍勢は押し流されて、多くの者が倒れ死ぬでしょう。</span>
<span className="v" id="v27" data-v="27" data-xref="詩篇 12:2; エレミヤ書 9:3–5; ハバクク書 2:3"> このふたりの王は、害を与えようと心にはかり、ひとつ食卓に共に食して、偽りを語るが、それは成功しません。終りはなお定まった時の来るまでこないからです。</span>
<span className="v" id="v28" data-v="28" data-xref="ダニエル書 11:30–32; ダニエル書 8:24; 使徒行伝 3:25"> 彼は大いなる財宝をもって、自分の国に帰るでしょう。しかし、彼の心は聖なる契約にそむき、ほしいままに事をなして、自分の国に帰ります。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="使徒行伝 17:26; イザヤ書 14:31; ダニエル書 11:25"> 定まった時になって、彼はまた南に討ち入ります。しかし、この時は前の時のようではありません。</span>
<span className="v" id="v30" data-v="30" data-xref="創世記 10:4; 民数記 24:24; エレミヤ書 2:10"> それはキッテムの船が、彼に立ち向かって来るので、彼は脅かされて帰り、聖なる契約に対して憤り、事を行うでしょう。彼は帰っていって、聖なる契約を捨てる者を顧み用いるでしょう。</span>
<span className="v" id="v31" data-v="31" data-xref="ダニエル書 12:11; ダニエル書 9:27; マタイによる福音書 24:15"> 彼から軍勢が起って、神殿と城郭を汚し、常供の燔祭を取り除き、荒す憎むべきものを立てるでしょう。</span>
<span className="v" id="v32" data-v="32" data-xref="歴代志上 28:9; 詩篇 9:10; ヨハネによる福音書 17:3"> 彼は契約を破る者どもを、巧言をもってそそのかし、そむかせるが、自分の神を知る民は、堅く立って事を行います。</span>
<span className="v" id="v33" data-v="33" data-xref="マタイによる福音書 24:9; ヨハネによる福音書 16:2; マラキ書 2:7"> 民のうちの賢い人々は、多くの人を悟りに至らせます。それでも、彼らはしばらくの間、やいばにかかり、火に焼かれ、捕われ、かすめられなどして倒れます。</span>
<span className="v" id="v34" data-v="34" data-xref="マタイによる福音書 7:15; ローマ人への手紙 16:18; 使徒行伝 20:29–30"> その倒れるとき、彼らは少しの助けを獲ます。また多くの人が、巧言をもって彼らにくみするでしょう。</span>
<span className="v" id="v35" data-v="35" data-xref="ゼカリヤ書 13:9; マラキ書 3:2–4; ヨハネの黙示録 2:10"> また賢い者のうちのある者は、終りの時まで、自分を練り、清め、白くするために倒れるでしょう。終りはなお定まった時の来るまでこないからです。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="ヨハネの黙示録 13:5–6; テサロニケ人への第二の手紙 2:4; 申命記 10:17"> この王は、その心のままに事をおこない、すべての神を越えて、自分を高くし、自分を大いにし、神々の神たる者にむかって、驚くべき事を語り、憤りのやむ時まで栄えるでしょう。これは定められた事が成就するからです。</span>
<span className="v" id="v37" data-v="37" data-xref="テサロニケ人への第二の手紙 2:4; イザヤ書 14:13; テモテヘの第一の手紙 4:3"> 彼はその先祖の神々を顧みず、また婦人の好む者も、いかなる神をも顧みないでしょう。彼はすべてにまさって、自分を大いなる者とするからです。</span>
<span className="v" id="v38" data-v="38" data-xref="ヨハネの黙示録 17:1–5; イザヤ書 44:9; ヨハネの黙示録 13:12–17"> 彼はこれらの者の代りに、要害の神をあがめ、金、銀、宝石、および宝物をもって、その先祖たちの知らなかった神をあがめ、</span>
<span className="v" id="v39" data-v="39" data-xref="ヨハネの黙示録 18:9–13"> 異邦の神の助けによって、最も強固な城にむかって、事をなすでしょう。そして彼を認める者には、栄誉を増し与え、これに多くの人を治めさせ、賞与として土地を分け与えるでしょう。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="ダニエル書 11:35; ダニエル書 11:10; イザヤ書 5:28"> 終りの時になって、南の王は彼と戦います。北の王は、戦車と騎兵と、多くの船をもって、つむじ風のように彼を攻め、国々にはいっていって、みなぎりあふれ、通り過ぎるでしょう。</span>
<span className="v" id="v41" data-v="41" data-xref="エレミヤ書 48:47; エレミヤ書 49:6; イザヤ書 11:13–15"> 彼はまた麗しい国にはいります。また彼によって、多くの者が滅ぼされます。しかし、エドム、モアブ、アンモンびとらのうちのおもな者は、彼の手から救われましょう。</span>
<span className="v" id="v42" data-v="42" data-xref="ゼカリヤ書 10:10–11; エゼキエル書 29:14; ヨハネの黙示録 11:8"> 彼は国々にその手を伸ばし、エジプトの地も免れません。</span>
<span className="v" id="v43" data-v="43" data-xref="歴代志下 12:3; ナホム書 3:9; エゼキエル書 30:4–5"> 彼は金銀の財宝と、エジプトのすべての宝物を支配し、リビヤびと、エチオピヤびとは、彼のあとに従います。</span>
<span className="v" id="v44" data-v="44" data-xref="ヨハネの黙示録 19:19–21; ヨハネの黙示録 16:12; ヨハネの黙示録 17:13"> しかし東と北からの知らせが彼を驚かし、彼は多くの人を滅ぼし絶やそうと、大いなる怒りをもって出て行きます。</span>
<span className="v" id="v45" data-v="45" data-xref="テサロニケ人への第二の手紙 2:4; ダニエル書 8:25; ヨハネの黙示録 19:19–21"> 彼は海と麗しい聖山との間に、天幕の宮殿を設けるでしょう。しかし、彼はついにその終りにいたり、彼を助ける者はないでしょう。</span>
</div>

<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="ダニエル書 1:17; アモス書 3:7; ダニエル書 5:1"> バビロンの王ベルシャザルの元年に、ダニエルは床にあって夢を見、また脳中に幻を得たので、彼はその夢をしるして、その事の大意を述べた。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネの黙示録 7:1; ヨハネの黙示録 17:15"> ダニエルは述べて言った、「わたしは夜の幻のうちに見た。見よ、天の四方からの風が大海をかきたてると、</span>
<span className="v" id="v3" data-v="3" data-xref="ヨハネの黙示録 13:1; ダニエル書 7:17; ダニエル書 2:32–33"> 四つの大きな獣が海からあがってきた。その形は、おのおの異なり、</span>
<span className="v" id="v4" data-v="4" data-xref="エレミヤ書 4:7; イザヤ書 14:13–17; エゼキエル書 17:3"> 第一のものは、ししのようで、わしの翼をもっていたが、わたしが見ていると、その翼は抜きとられ、また地から起されて、人のように二本の足で立たせられ、かつ人の心が与えられた。</span>
<span className="v" id="v5" data-v="5" data-xref="ダニエル書 2:39; イザヤ書 13:17–18; 箴言 17:12"> 見よ、第二の獣は熊のようであった。これはそのからだの一方をあげ、その口の歯の間に、三本の肋骨をくわえていたが、これに向かって『起きあがって、多くの肉を食らえ』と言う声があった。</span>
<span className="v" id="v6" data-v="6" data-xref="ヨハネの黙示録 13:2; ダニエル書 8:20–22; ダニエル書 8:5–8"> その後わたしが見たのは、ひょうのような獣で、その背には鳥の翼が四つあった。またこの獣には四つの頭があり、主権が与えられた。</span>
<span className="v" id="v7" data-v="7" data-xref="ヨハネの黙示録 13:1; ヨハネの黙示録 12:3; ヨハネの黙示録 17:12"> その後わたしが夜の幻のうちに見た第四の獣は、恐ろしい、ものすごい、非常に強いもので、大きな鉄の歯があり、食らい、かつ、かみ砕いて、その残りを足で踏みつけた。これは、その前に出たすべての獣と違って、十の角を持っていた。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨハネの黙示録 13:5–6; ヨハネの黙示録 13:1; 詩篇 12:3"> わたしが、その角を注意して見ていると、その中に、また一つの小さい角が出てきたが、この小さい角のために、さきの角のうち三つがその根から抜け落ちた。見よ、この小さい角には、人の目のような目があり、また大きな事を語る口があった。</span>
<span className="v" id="v9" data-v="9" data-xref="ヨハネの黙示録 1:14; マルコによる福音書 9:3; ダニエル書 7:13"> わたしが見ていると、<br /><span className="pl pl-1">もろもろのみ座が設けられて、</span><br /><span className="pl pl-1">日の老いたる者が座しておられた。</span><br /><span className="pl pl-1">その衣は雪のように白く、</span><br /><span className="pl pl-1">頭の毛は混じりもののない羊の毛のようであった。</span><br /><span className="pl pl-1">そのみ座は火の炎であり、</span><br /><span className="pl pl-1">その車輪は燃える火であった。</span></span>
<span className="v" id="v10" data-v="10" data-xref="イザヤ書 30:27; 申命記 33:2; ヨハネの黙示録 20:11–15"> <span className="pl pl-1">彼の前から、ひと筋の火の流れが出てきた。</span><br /><span className="pl pl-1">彼に仕える者は千々、</span><br /><span className="pl pl-1">彼の前にはべる者は万々、</span><br /><span className="pl pl-1">審判を行う者はその席に着き、</span><br /><span className="pl pl-1">かずかずの書き物が開かれた。</span></span>
<span className="v" id="v11" data-v="11" data-xref="ヨハネの黙示録 19:20; ヨハネの黙示録 20:10; テサロニケ人への第二の手紙 2:8"> <span className="pl pl-1">わたしは、その角の語る大いなる言葉の声がするので見ていたが、わたしが見ている間にその獣は殺され、そのからだはそこなわれて、燃える火に投げ入れられた。</span></span>
<span className="v" id="v12" data-v="12" data-xref="ダニエル書 8:7; ダニエル書 7:4–6"> <span className="pl pl-1">その他の獣はその主権を奪われたが、その命は、時と季節の来るまで延ばされた。</span></span>
<span className="v" id="v13" data-v="13" data-xref="マタイによる福音書 26:64; ヨハネの黙示録 1:7; ルカによる福音書 21:27"> <span className="pl pl-1">わたしはまた夜の幻のうちに見ていると、</span><br /><span className="pl pl-1">見よ、人の子のような者が、</span><br /><span className="pl pl-1">天の雲に乗ってきて、</span><br /><span className="pl pl-1">日の老いたる者のもとに来ると、</span><br /><span className="pl pl-1">その前に導かれた。</span></span>
<span className="v" id="v14" data-v="14" data-xref="ヨハネの黙示録 11:15; ダニエル書 7:27; ヨハネによる福音書 3:35"> <span className="pl pl-1">彼に主権と光栄と国とを賜い、</span><br /><span className="pl pl-1">諸民、諸族、諸国語の者を彼に仕えさせた。</span><br /><span className="pl pl-1">その主権は永遠の主権であって、</span><br /><span className="pl pl-1">なくなることがなく、</span><br /><span className="pl pl-1">その国は滅びることがない。</span></span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="ダニエル書 7:28; エレミヤ書 17:16; 創世記 40:7–8"> そこで、われダニエル、わがうちなる霊は憂え、わが脳中の幻は、わたしを悩ましたので、</span>
<span className="v" id="v16" data-v="16" data-xref="ヨハネの黙示録 7:13–14; ゼカリヤ書 2:3; ヨハネの黙示録 5:5"> わたしは、そこに立っている者のひとりに近寄って、このすべての事の真意を尋ねた。するとその者は、わたしにこの事の解き明かしを告げ知らせた。</span>
<span className="v" id="v17" data-v="17" data-xref="ダニエル書 8:19–22; ダニエル書 2:37–40; ヨハネによる福音書 18:36"> 『この四つの大きな獣は、地に起らんとする四人の王である。</span>
<span className="v" id="v18" data-v="18" data-xref="ダニエル書 7:27; イザヤ書 60:12–14; ヨハネの黙示録 5:10"> しかしついには、いと高き者の聖徒が国を受け、永遠にその国を保って、世々かぎりなく続く』。</span>
</div>
<div className="bp poetry">
<span className="v" id="v19" data-v="19" data-xref="ダニエル書 7:7; ダニエル書 2:40–43"> そこでわたしは、さらに第四の獣の真意を知ろうとした。その獣は他の獣と異なって、はなはだ恐ろしく、その歯は鉄、そのつめは青銅であって、食らい、かつ、かみ砕いて、その残りを足で踏みつけた。</span>
<span className="v" id="v20" data-v="20" data-xref="ダニエル書 7:23; ダニエル書 7:8; ダニエル書 7:11"> この獣の頭には、十の角があったが、そのほかに一つの角が出てきたので、この角のために、三つの角が抜け落ちた。この角には目があり、また大きな事を語る口があって、その形は、その同類のものよりも大きく見えた。</span>
<span className="v" id="v21" data-v="21" data-xref="ダニエル書 12:7; ヨハネの黙示録 17:14; ダニエル書 8:24"> わたしが見ていると、この角は聖徒と戦って、彼らに勝ったが、</span>
<span className="v" id="v22" data-v="22" data-xref="ダニエル書 7:18; ヨハネの黙示録 20:4; ヨハネの黙示録 5:10"> ついに日の老いたる者がきて、いと高き者の聖徒のために審判をおこなった。そしてその時がきて、この聖徒たちは国を受けた。</span>
<span className="v" id="v23" data-v="23" data-xref="ダニエル書 2:40; ダニエル書 7:7; ルカによる福音書 2:1"> <span className="pl pl-1">彼はこう言った、</span><br /><span className="pl pl-1">『第四の獣は地上の第四の国である。</span><br /><span className="pl pl-1">これはすべての国と異なって、</span><br /><span className="pl pl-1">全世界を併合し、</span><br /><span className="pl pl-1">これを踏みつけ、かつ打ち砕く。</span></span>
<span className="v" id="v24" data-v="24" data-xref="ダニエル書 7:20; ダニエル書 11:36; ヨハネの黙示録 13:1"> <span className="pl pl-1">十の角はこの国から起る十人の王である。</span><br /><span className="pl pl-1">その後にまたひとりの王が起る。</span><br /><span className="pl pl-1">彼は先の者と異なり、</span><br /><span className="pl pl-1">かつ、その三人の王を倒す。</span></span>
<span className="v" id="v25" data-v="25" data-xref="ダニエル書 12:7; ヨハネの黙示録 12:14; テサロニケ人への第二の手紙 2:4"> <span className="pl pl-1">彼は、いと高き者に敵して言葉を出し、</span><br /><span className="pl pl-1">かつ、いと高き者の聖徒を悩ます。</span><br /><span className="pl pl-1">彼はまた時と律法とを変えようと望む。</span><br /><span className="pl pl-1">聖徒はひと時と、ふた時と、半時の間、</span><br /><span className="pl pl-1">彼の手にわたされる。</span></span>
<span className="v" id="v26" data-v="26" data-xref="ヨハネの黙示録 20:10–11; テサロニケ人への第二の手紙 2:8; ヨハネの黙示録 11:13"> <span className="pl pl-1">しかし審判が行われ、</span><br /><span className="pl pl-1">彼の主権は奪われて、</span><br /><span className="pl pl-1">永遠に滅び絶やされ、</span></span>
<span className="v" id="v27" data-v="27" data-xref="詩篇 72:11; ルカによる福音書 1:33; ヨハネの黙示録 11:15"> <span className="pl pl-1">国と主権と全天下の国々の権威とは、</span><br /><span className="pl pl-1">いと高き者の聖徒たる民に与えられる。</span><br /><span className="pl pl-1">彼らの国は永遠の国であって、</span><br /><span className="pl pl-1">諸国の者はみな彼らに仕え、かつ従う』。</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="ルカによる福音書 2:19; ルカによる福音書 2:51; ダニエル書 10:8"> その事はここで終った。われダニエルは、これを思いまわして、非常に悩み、顔色も変った。しかし、わたしはこの事を心に留めた」。</span>

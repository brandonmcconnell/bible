<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ダニエル書 11:1; ダニエル書 1:21; ダニエル書 5:31–1"> メデアびとアハシュエロスの子ダリヨスが、カルデヤびとの王となったその元年、</span>
<span className="v" id="v2" data-v="2" data-xref="エレミヤ書 29:10; エレミヤ書 25:11–12; 歴代志下 36:21"> すなわちその治世の第一年に、われダニエルは主が預言者エレミヤに臨んで告げられたその言葉により、エルサレムの荒廃の終るまでに経ねばならぬ年の数は七十年であることを、文書によって悟った。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="エレミヤ書 33:3; エレミヤ書 29:10–13; ヤコブの手紙 5:16–18"> それでわたしは、わが顔を主なる神に向け、断食をなし、荒布を着、灰をかぶって祈り、かつ願い求めた。</span>
<span className="v" id="v4" data-v="4" data-xref="ローマ人への手紙 8:28; 出エジプト記 20:6; 申命記 5:10"> すなわちわたしは、わが神、主に祈り、ざんげして言った、「ああ、大いなる恐るべき神、主、おのれを愛し、おのれの戒めを守る者のために契約を保ち、いつくしみを施される者よ、</span>
<span className="v" id="v5" data-v="5" data-xref="マラキ書 3:7; ダニエル書 9:11; ダニエル書 9:15"> われわれは罪を犯し、悪をおこない、よこしまなふるまいをなし、そむいて、あなたの戒めと、おきてを離れました。</span>
<span className="v" id="v6" data-v="6" data-xref="ダニエル書 9:10; 歴代志下 36:15–16; ルカによる福音書 20:10–12"> われわれはまた、あなたのしもべなる預言者たちが、あなたの名をもって、われわれの王たち、君たち、先祖たち、および国のすべての民に告げた言葉に聞き従いませんでした。</span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 44:15; エレミヤ書 3:25; エレミヤ書 2:26–27"> 主よ、正義はあなたのものですが、恥はわれわれに加えられて、今日のような有様です。すなわちユダの人々、エルサレムの住民および全イスラエルの者は、近き者も、遠き者もみな、あなたが追いやられたすべての国々で恥をこうむりました。これは彼らがあなたにそむいて犯した罪によるのです。</span>
<span className="v" id="v8" data-v="8" data-xref="ダニエル書 9:6–7; 哀歌 1:7–8; 哀歌 1:18"> 主よ、恥はわれわれのもの、われわれの王たち、君たちおよび先祖たちのものです。これはわれわれがあなたにむかって罪を犯したからです。</span>
<span className="v" id="v9" data-v="9" data-xref="エペソ人への手紙 1:6–8; ダニエル書 9:7; ダニエル書 9:5"> あわれみと、ゆるしはわれわれの神、主のものです。これはわれわれが彼にそむいたからです。</span>
<span className="v" id="v10" data-v="10" data-xref="ダニエル書 9:6; 列王紀下 18:12; ネヘミヤ書 9:13–17"> またわれわれの神、主のみ声に聞き従わず、主がそのしもべ預言者たちによって、われわれの前に賜わった律法を行わなかったからです。</span>
<span className="v" id="v11" data-v="11" data-xref="エレミヤ書 8:5–10; イザヤ書 1:4–6; 申命記 28:15–68"> まことにイスラエルの人々は皆あなたの律法を犯し、離れ去って、あなたのみ声に聞き従わなかったので、神のしもべモーセの律法にしるされたのろいと誓いが、われわれの上に注ぎかかりました。これはわれわれが神にむかって罪を犯したからです。</span>
<span className="v" id="v12" data-v="12" data-xref="エゼキエル書 5:9; 哀歌 1:12; ヨブ記 12:17"> すなわち神は大いなる災をわれわれの上にくだして、さきにわれわれと、われわれを治めたつかさたちにむかって告げられた言葉を実行されたのです。あのエルサレムに臨んだような事は、全天下にいまだかつてなかった事です。</span>
<span className="v" id="v13" data-v="13" data-xref="申命記 28:15–68; イザヤ書 9:13; ダニエル書 9:11"> モーセの律法にしるされたように、この災はすべてわれわれに臨みましたが、なおわれわれの神、主の恵みを請い求めることをせず、その不義を離れて、あなたの真理を悟ることをもしませんでした。</span>
<span className="v" id="v14" data-v="14" data-xref="ダニエル書 9:7; ネヘミヤ書 9:33; 詩篇 51:14"> それゆえ、主はこれを心に留めて、災をわれわれに下されたのです。われわれの神、主は、何事をされるにも、正しくあらせられます。ところが、われわれはそのみ声に聞き従わなかったのです。</span>
<span className="v" id="v15" data-v="15" data-xref="ネヘミヤ書 9:10; 出エジプト記 32:11; ネヘミヤ書 1:10"> われわれの神、主よ、あなたは強きみ手をもって、あなたの民をエジプトの地から導き出して、今日のように、み名をあげられました。われわれは罪を犯し、よこしまなふるまいをしました。</span>
<span className="v" id="v16" data-v="16" data-xref="ゼカリヤ書 8:3; ヨエル書 3:17; 詩篇 87:1–3"> 主よ、どうぞあなたが、これまで正しいみわざをなされたように、あなたの町エルサレム、あなたの聖なる山から、あなたの怒りと憤りとを取り去ってください。これはわれわれの罪と、われわれの先祖の不義のために、エルサレムと、あなたの民が、われわれの周囲の者の物笑いとなったからです。</span>
<span className="v" id="v17" data-v="17" data-xref="詩篇 80:19; 哀歌 5:18; コリント人への第二の手紙 1:20"> それゆえ、われわれの神よ、しもべの祈と願いを聞いてください。主よ、あなたご自身のために、あの荒れたあなたの聖所に、あなたのみ顔を輝かせてください。</span>
<span className="v" id="v18" data-v="18" data-xref="イザヤ書 37:17; エレミヤ書 36:7; 列王紀下 19:16"> わが神よ、耳を傾けて聞いてください。目を開いて、われわれの荒れたさまを見、み名をもってとなえられる町をごらんください。われわれがあなたの前に祈をささげるのは、われわれの義によるのではなく、ただあなたの大いなるあわれみによるのです。</span>
<span className="v" id="v19" data-v="19" data-xref="ダニエル書 9:18; エペソ人への手紙 1:12; アモス書 7:2"> 主よ、聞いてください。主よ、ゆるしてください。主よ、み心に留めて、おこなってください。わが神よ、あなたご自身のために、これを延ばさないでください。あなたの町と、あなたの民は、み名をもってとなえられているからです」。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="詩篇 145:18; ダニエル書 9:3–4; ローマ人への手紙 3:23"> わたしがこう言って祈り、かつわが罪とわが民イスラエルの罪をざんげし、わが神の聖なる山のために、わが神、主の前に願いをしていたとき、</span>
<span className="v" id="v21" data-v="21" data-xref="ルカによる福音書 1:19; ダニエル書 8:16; 列王紀上 18:36"> すなわちわたしが祈の言葉を述べていたとき、わたしが初めに幻のうちに見た、かの人ガブリエルは、すみやかに飛んできて、夕の供え物をささげるころ、わたしに近づき、</span>
<span className="v" id="v22" data-v="22" data-xref="ダニエル書 9:24–27; ダニエル書 10:21; ダニエル書 8:16"> わたしに告げて言った、「ダニエルよ、わたしは今あなたに、知恵と悟りを与えるためにきました。</span>
<span className="v" id="v23" data-v="23" data-xref="ダニエル書 10:19; マタイによる福音書 24:15; ダニエル書 10:11–12"> あなたが祈を始めたとき、み言葉が出たので、それをあなたに告げるためにきたのです。あなたは大いに愛せられている者です。ゆえに、このみ言葉を考えて、この幻を悟りなさい。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="ヘブル人への手紙 9:11–14; ローマ人への手紙 5:10; エレミヤ書 23:5–6"> あなたの民と、あなたの聖なる町については、七十週が定められています。これはとがを終らせ、罪に終りを告げ、不義をあがない、永遠の義をもたらし、幻と預言者を封じ、いと聖なる者に油を注ぐためです。</span>
<span className="v" id="v25" data-v="25" data-xref="エズラ記 4:24; イザヤ書 9:6; イザヤ書 55:4"> それゆえ、エルサレムを建て直せという命令が出てから、メシヤなるひとりの君が来るまで、七週と六十二週あることを知り、かつ悟りなさい。その間に、しかも不安な時代に、エルサレムは広場と街路とをもって、建て直されるでしょう。</span>
<span className="v" id="v26" data-v="26" data-xref="イザヤ書 53:8; ナホム書 1:8; マルコによる福音書 13:2"> その六十二週の後にメシヤは断たれるでしょう。ただし自分のためにではありません。またきたるべき君の民は、町と聖所とを滅ぼすでしょう。その終りは洪水のように臨むでしょう。そしてその終りまで戦争が続き、荒廃は定められています。</span>
<span className="v" id="v27" data-v="27" data-xref="マタイによる福音書 24:15; ルカによる福音書 21:20; ダニエル書 12:11"> 彼は一週の間多くの者と、堅く契約を結ぶでしょう。そして彼はその週の半ばに、犠牲と供え物とを廃するでしょう。また荒す者が憎むべき者の翼に乗って来るでしょう。こうしてついにその定まった終りが、その荒す者の上に注がれるのです」。</span>
</div>

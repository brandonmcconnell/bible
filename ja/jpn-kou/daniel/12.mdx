<span className="v" id="v1" data-v="1" data-xref="エレミヤ書 30:7; マタイによる福音書 24:21; マルコによる福音書 13:19"> その時あなたの民を守っている大いなる君ミカエルが立ちあがります。また国が始まってから、その時にいたるまで、かつてなかったほどの悩みの時があるでしょう。しかし、その時あなたの民は救われます。すなわちあの書に名をしるされた者は皆救われます。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネによる福音書 5:28–29; イザヤ書 26:19; マタイによる福音書 25:46"> また地のちりの中に眠っている者のうち、多くの者は目をさますでしょう。そのうち永遠の生命にいたる者もあり、また恥と、限りなき恥辱をうける者もあるでしょう。</span>
<span className="v" id="v3" data-v="3" data-xref="マタイによる福音書 13:43; 箴言 4:18; ヤコブの手紙 5:19–20"> 賢い者は、大空の輝きのように輝き、また多くの人を義に導く者は、星のようになって永遠にいたるでしょう。</span>
<span className="v" id="v4" data-v="4" data-xref="ダニエル書 12:9; ヨハネの黙示録 22:10; ダニエル書 8:26"> ダニエルよ、あなたは終りの時までこの言葉を秘し、この書を封じておきなさい。多くの者は、あちこちと探り調べ、そして知識が増すでしょう」。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="ダニエル書 10:4–6; ダニエル書 10:16; ダニエル書 10:10"> そこで、われダニエルが見ていると、ほかにまたふたりの者があって、ひとりは川のこなたの岸に、ひとりは川のかなたの岸に立っていた。</span>
<span className="v" id="v6" data-v="6" data-xref="ダニエル書 8:13; エゼキエル書 9:2; ゼカリヤ書 1:12–13"> わたしは、かの亜麻布を着て川の水の上にいる人にむかって言った、「この異常なできごとは、いつになって終るでしょうか」と。</span>
<span className="v" id="v7" data-v="7" data-xref="ダニエル書 7:25; ヨハネの黙示録 12:14; ダニエル書 8:24"> かの亜麻布を着て、川の水の上にいた人が、天に向かって、その右の手と左の手をあげ、永遠に生ける者をさして誓い、それは、ひと時とふた時と半時である。聖なる民を打ち砕く力が消え去る時に、これらの事はみな成就するだろうと言うのを、わたしは聞いた。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行伝 1:7; ペテロの第一の手紙 1:11; ダニエル書 10:14"> わたしはこれを聞いたけれども悟れなかった。わたしは言った、「わが主よ、これらの事の結末はどんなでしょうか」。</span>
<span className="v" id="v9" data-v="9" data-xref="ダニエル書 12:4; ダニエル書 8:26; ヨハネの黙示録 10:4"> 彼は言った、「ダニエルよ、あなたの道を行きなさい。この言葉は終りの時まで秘し、かつ封じておかれます。</span>
<span className="v" id="v10" data-v="10" data-xref="ヨハネの黙示録 22:11; ダニエル書 11:35; ホセア書 14:9"> 多くの者は、自分を清め、自分を白くし、かつ練られるでしょう。しかし、悪い者は悪い事をおこない、ひとりも悟ることはないが、賢い者は悟るでしょう。</span>
<span className="v" id="v11" data-v="11" data-xref="ダニエル書 11:31; マタイによる福音書 24:15; マルコによる福音書 13:14"> 常供の燔祭が取り除かれ、荒す憎むべきものが立てられる時から、千二百九十日が定められている。</span>
<span className="v" id="v12" data-v="12" data-xref="イザヤ書 30:18; ダニエル書 8:14; ローマ人への手紙 11:15"> 待っていて千三百三十五日に至る者はさいわいです。</span>
<span className="v" id="v13" data-v="13" data-xref="ヨハネの黙示録 14:13; テモテヘの第二の手紙 4:7–8; ゼカリヤ書 3:7"> しかし、終りまであなたの道を行きなさい。あなたは休みに入り、定められた日の終りに立って、あなたの分を受けるでしょう」。</span>

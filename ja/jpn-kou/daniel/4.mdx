<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="ダニエル書 6:25; ペテロの第一の手紙 1:2; ダニエル書 3:4"> ネブカデネザル王は全世界に住む諸民、諸族、諸国語の者に告げる。どうか、あなたがたに平安が増すように。</span>
<span className="v" id="v2" data-v="2" data-xref="ダニエル書 3:26; 詩篇 66:16; 詩篇 71:18"> いと高き神はわたしにしるしと奇跡とを行われた。わたしはこれを知らせたいと思う。</span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 145:13; イザヤ書 25:1; ダニエル書 2:44"> <span className="pl pl-1">ああ、そのしるしの大いなること、</span><br /><span className="pl pl-1">ああ、その奇跡のすばらしいこと、</span><br /><span className="pl pl-1">その国は永遠の国、</span><br /><span className="pl pl-1">その主権は世々に及ぶ。</span></span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="イザヤ書 47:7–8; テサロニケ人への第一の手紙 5:2–3; 詩篇 30:6–7"> われネブカデネザルはわが家に安らかにおり、わが宮にあって栄えていたが、</span>
<span className="v" id="v5" data-v="5" data-xref="ダニエル書 2:1; ヨブ記 7:13–14; ダニエル書 2:28–29"> わたしは一つの夢を見て、そのために恐れた。すなわち床にあって、その事を思いめぐらし、わが脳中の幻のために心を悩ました。</span>
<span className="v" id="v6" data-v="6" data-xref="ダニエル書 2:2; 創世記 41:7–8; イザヤ書 8:19"> そこでわたしは命令を下し、バビロンの知者をことごとくわが前に召し寄せて、その夢の解き明かしを示させようとした。</span>
<span className="v" id="v7" data-v="7" data-xref="イザヤ書 44:25; ダニエル書 2:7; 創世記 41:8"> すると、博士、法術士、カルデヤびと、占い師たちがきたので、わたしはその夢を彼らに語ったが、彼らはその解き明かしを示すことができなかった。</span>
<span className="v" id="v8" data-v="8" data-xref="ダニエル書 1:7; ダニエル書 5:14; ダニエル書 4:18"> 最後にダニエルがわたしの前にきた、――彼の名はわが神の名にちなんで、ベルテシャザルととなえられ、彼のうちには聖なる神の霊がやどっていた――わたしは彼にその夢を語って言った、</span>
<span className="v" id="v9" data-v="9" data-xref="ダニエル書 2:48; ダニエル書 5:11; ダニエル書 4:8"> 「博士の長ベルテシャザルよ、わたしは知っている。聖なる神の霊があなたのうちにやどっているから、どんな秘密もあなたにはむずかしいことはない。ここにわたしが見た夢がある。その解き明かしをわたしに告げなさい。</span>
<span className="v" id="v10" data-v="10" data-xref="エレミヤ書 12:2; ダニエル書 4:5; 詩篇 37:35–36"> わたしが床にあって見た脳中の幻はこれである。わたしが見たのに、地の中央に一本の木があって、そのたけが高かったが、</span>
<span className="v" id="v11" data-v="11" data-xref="ダニエル書 4:21–22; 申命記 9:1; マタイによる福音書 11:23"> その木は成長して強くなり、天に達するほどの高さになって、地の果までも見えわたり、</span>
<span className="v" id="v12" data-v="12" data-xref="ルカによる福音書 13:19; 哀歌 4:20; エゼキエル書 31:6–7"> その葉は美しく、その実は豊かで、すべての者がその中から食物を獲、また野の獣はその陰にやどり、空の鳥はその枝にすみ、すべての肉なる者はこれによって養われた。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="申命記 33:2; ダニエル書 8:13; ダニエル書 7:1"> わたしが床にあって見た脳中の幻の中に、ひとりの警護者、ひとりの聖者の天から下るのを見たが、</span>
<span className="v" id="v14" data-v="14" data-xref="マタイによる福音書 3:10; ダニエル書 4:23; エゼキエル書 31:12–13"> 彼は声高く呼ばわって、こう言った、『この木を切り倒し、その枝を切りはらい、その葉をゆり落し、その実を打ち散らし、獣をその下から逃げ去らせ、鳥をその枝から飛び去らせよ。</span>
<span className="v" id="v15" data-v="15" data-xref="ヨブ記 14:7–9; ダニエル書 4:25–27; エゼキエル書 29:14–15"> ただしその根の切り株を地に残し、それに鉄と青銅のなわをかけて、野の若草の中におき、天からくだる露にぬれさせ、また地の草の中で、獣と共にその分にあずからせよ。</span>
<span className="v" id="v16" data-v="16" data-xref="ダニエル書 4:23; ヨハネの黙示録 12:14; ダニエル書 4:25"> またその心は変って人間の心のようでなく、獣の心が与えられて、七つの時を過ごさせよ。</span>
<span className="v" id="v17" data-v="17" data-xref="ダニエル書 4:25; ダニエル書 2:21; 詩篇 75:6–7"> この宣言は警護者たちの命令によるもの、この決定は聖者たちの言葉によるもので、いと高き者が、人間の国を治めて、自分の意のままにこれを人に与え、また人のうちの最も卑しい者を、その上に立てられるという事を、すべての者に知らせるためである』と。</span>
<span className="v" id="v18" data-v="18" data-xref="ダニエル書 5:15; 創世記 41:8; ダニエル書 5:8"> われネブカデネザル王はこの夢を見た。ベルテシャザルよ、あなたはその解き明かしをわたしに告げなさい。わが国の知者たちは、いずれもその解き明かしを、わたしに示すことができなかったけれども、あなたにはそれができる。あなたのうちには、聖なる神の霊がやどっているからだ」。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="ダニエル書 8:27; ダニエル書 7:28; ダニエル書 4:24"> その時、その名をベルテシャザルととなえるダニエルは、しばらくのあいだ驚き、思い悩んだので、王は彼に告げて言った、「ベルテシャザルよ、あなたはこの夢と、その解き明かしのために、悩むには及ばない」。ベルテシャザルは答えて言った、「わが主よ、どうか、この夢は、あなたを憎む者にかかわるように。この解き明かしは、あなたの敵に臨むように。</span>
<span className="v" id="v20" data-v="20" data-xref="ダニエル書 4:10–12; エゼキエル書 31:3; エゼキエル書 31:16"> あなたが見られた木、すなわちその成長して強くなり、天に達するほどの高さになって、地の果までも見えわたり、</span>
<span className="v" id="v21" data-v="21"> その葉は美しく、その実は豊かで、すべての者がその中から食物を獲、また野の獣がその陰にやどり、空の鳥がその枝に住んだ木、</span>
<span className="v" id="v22" data-v="22" data-xref="ダニエル書 2:37–38; サムエル記下 12:7; エレミヤ書 27:6–8"> 王よ、それはすなわちあなたです。あなたは成長して強くなり、天に達するほどに大きくなり、あなたの主権は地の果にまで及びました。</span>
<span className="v" id="v23" data-v="23" data-xref="ダニエル書 5:21; ダニエル書 4:13–16"> ところが、王はひとりの警護者、ひとりの聖者が、天から下って、こう言うのを見られました、『この木を切り倒して、これを滅ぼせ。ただしその根の切り株を地に残し、それに鉄と青銅のなわをかけて、野の若草の中におき、天からくだる露にぬれさせ、また野の獣と共にその分にあずからせて、七つの時を過ごさせよ』と。</span>
<span className="v" id="v24" data-v="24" data-xref="詩篇 107:40; ヨブ記 40:11–12; イザヤ書 46:10–11"> 王よ、その解き明かしはこうです。すなわちこれはいと高き者の命令であって、わが主なる王に臨まんとするものです。</span>
<span className="v" id="v25" data-v="25" data-xref="ダニエル書 4:17; エレミヤ書 27:5; 詩篇 83:18"> すなわちあなたは追われて世の人を離れ、野の獣と共におり、牛のように草を食い、天からくだる露にぬれるでしょう。こうして七つの時が過ぎて、ついにあなたは、いと高き者が人間の国を治めて、自分の意のままに、これを人に与えられることを知るに至るでしょう。</span>
<span className="v" id="v26" data-v="26" data-xref="ダニエル書 4:15; マタイによる福音書 5:34; マタイによる福音書 21:20"> また彼らはその木の根の切り株を残しおけと命じたので、あなたが、天はまことの支配者であるということを知った後、あなたの国はあなたに確保されるでしょう。</span>
<span className="v" id="v27" data-v="27" data-xref="イザヤ書 55:6–7; ヨナ書 3:9; 使徒行伝 8:22"> それゆえ王よ、あなたはわたしの勧告をいれ、義を行って罪を離れ、しえたげられる者をあわれんで、不義を離れなさい。そうすれば、あるいはあなたの繁栄が、長く続くかもしれません」。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="民数記 23:19; ゼカリヤ書 1:6; 箴言 10:24"> この事は皆ネブカデネザル王に臨んだ。</span>
<span className="v" id="v29" data-v="29" data-xref="ヨハネの黙示録 2:21; 伝道の書 8:11; ペテロの第一の手紙 3:20"> 十二か月を経て後、王がバビロンの王宮の屋上を歩いていたとき、</span>
<span className="v" id="v30" data-v="30" data-xref="箴言 16:18; ヨハネの黙示録 18:10; ルカによる福音書 14:11"> 王は自ら言った、「この大いなるバビロンは、わたしの大いなる力をもって建てた王城であって、わが威光を輝かすものではないか」。</span>
<span className="v" id="v31" data-v="31" data-xref="使徒行伝 9:3–5; ヨハネの黙示録 16:7; ルカによる福音書 12:20"> その言葉がなお王の口にあるうちに、天から声がくだって言った、「ネブカデネザル王よ、あなたに告げる。国はあなたを離れ去った。</span>
<span className="v" id="v32" data-v="32" data-xref="エレミヤ書 27:5; ダニエル書 5:21; 箴言 8:15–16"> あなたは、追われて世の人を離れ、野の獣と共におり、牛のように草を食い、こうして七つの時を経て、ついにあなたは、いと高き者が人間の国を治めて、自分の意のままに、これを人に与えられることを知るに至るだろう」。</span>
<span className="v" id="v33" data-v="33" data-xref="ダニエル書 4:32; ダニエル書 4:25; ダニエル書 5:5"> この言葉は、ただちにネブカデネザルに成就した。彼は追われて世の人を離れ、牛のように草を食い、その身は天からくだる露にぬれ、ついにその毛は、わしの羽のようになり、そのつめは鳥のつめのようになった。</span>
</div>
<div className="bp poetry">
<span className="v" id="v34" data-v="34" data-xref="ヨハネの黙示録 4:10; エレミヤ書 10:10; ダニエル書 12:7"> こうしてその期間が満ちた後、われネブカデネザルは、目をあげて天を仰ぎ見ると、わたしの理性が自分に帰ったので、わたしはいと高き者をほめ、その永遠に生ける者をさんびし、かつあがめた。<br /><span className="pl pl-1">その主権は永遠の主権、</span><br /><span className="pl pl-1">その国は世々かぎりなく、</span></span>
<span className="v" id="v35" data-v="35" data-xref="ヨブ記 42:2; 詩篇 135:6; 詩篇 115:3"> <span className="pl pl-1">地に住む民はすべて無き者のように思われ、</span><br /><span className="pl pl-1">天の衆群にも、</span><br /><span className="pl pl-1">地に住む民にも、</span><br /><span className="pl pl-1">彼はその意のままに事を行われる。</span><br /><span className="pl pl-1">だれも彼の手をおさえて</span><br /><span className="pl pl-1">「あなたは何をするのか」と言いうる者はない。</span></span>
<span className="v" id="v36" data-v="36" data-xref="ダニエル書 4:34; 箴言 22:4; ダニエル書 4:15–16"> <span className="pl pl-1">この時わたしの理性は自分に帰り、またわが国の光栄のために、わが尊厳と光輝とが、わたしに帰った。わが大臣、わが貴族らもきて、わたしに求め、わたしは国の上に堅く立って、前にもまさって大いなる者となった。</span></span>
<span className="v" id="v37" data-v="37" data-xref="ヤコブの手紙 4:6–7; 詩篇 33:4–5; ペテロの第一の手紙 5:5–6"> <span className="pl pl-1">そこでわれネブカデネザルは今、天の王をほめたたえ、かつあがめたてまつる。そのみわざはことごとく真実で、その道は正しく、高ぶり歩む者を低くされる。</span></span>
</div>

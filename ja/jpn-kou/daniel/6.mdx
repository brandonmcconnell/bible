<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出エジプト記 18:21–22; ダニエル書 5:31; エステル記 1:1"> ダリヨスは全国を治めるために、その国に百二十人の総督を立てることをよしとし、</span>
<span className="v" id="v2" data-v="2" data-xref="ダニエル書 2:48–49; ダニエル書 5:29; エステル記 7:4"> また彼らの上に三人の総監を立てた。ダニエルはそのひとりであった。これは総督たちをして、この三人の前に、その職務に関する報告をさせて、王に損失の及ぶことのないようにするためであった。</span>
<span className="v" id="v3" data-v="3" data-xref="ダニエル書 5:14; 箴言 22:29; 創世記 41:38–41"> ダニエルは彼のうちにあるすぐれた霊のゆえに、他のすべての総監および総督たちにまさっていたので、王は彼を立てて全国を治めさせようとした。</span>
<span className="v" id="v4" data-v="4" data-xref="ペテロの第一の手紙 3:16; ピリピ人への手紙 2:15; ペテロの第一の手紙 2:12"> そこで総監および総督らは、国事についてダニエルを訴えるべき口実を得ようとしたが、訴えるべきなんの口実も、なんのとがをも見いだすことができなかった。それは彼が忠信な人であって、その身になんのあやまちも、とがも見いだされなかったからである。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行伝 24:13–16; エステル記 3:8; 使徒行伝 24:20–21"> そこでその人々は言った、「われわれはダニエルの神の律法に関して、彼を訴える口実を得るのでなければ、ついに彼を訴えることはできまい」と。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="ダニエル書 2:4; ネヘミヤ書 2:3; ダニエル書 6:21"> こうして総監と総督らは、王のもとに集まってきて、王に言った、「ダリヨス王よ、どうかとこしえに生きながらえられますように。</span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 59:3; 詩篇 62:4; ダニエル書 3:27"> 国の総監、長官および総督、参議および知事らは、相はかって、王が一つのおきてを立て、一つの禁令を定められるよう求めることになりました。王よ、それはこうです。すなわち今から三十日の間は、ただあなたにのみ願い事をさせ、もしあなたをおいて、神または人にこれをなす者があれば、すべてその者を、ししの穴に投げ入れるというのです。</span>
<span className="v" id="v8" data-v="8" data-xref="ダニエル書 6:15; エステル記 1:19; ダニエル書 6:12"> それで王よ、その禁令を定め、その文書に署名して、メデアとペルシャの変ることのない法律のごとく、これを変えることのできないようにしてください」。</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 146:3; 詩篇 118:9; 詩篇 62:9–10"> そこでダリヨス王は、その禁令の文書に署名した。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="使徒行伝 5:29; 詩篇 55:17; テサロニケ人への第一の手紙 5:17–18"> ダニエルは、その文書の署名されたことを知って家に帰り、二階のへやの、エルサレムに向かって窓の開かれた所で、以前からおこなっていたように、一日に三度ずつ、ひざをかがめて神の前に祈り、かつ感謝した。</span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 37:32–33; 詩篇 10:9; ダニエル書 6:6"> そこでその人々は集まってきて、ダニエルがその神の前に祈り、かつ求めていることを見たので、</span>
<span className="v" id="v12" data-v="12" data-xref="ダニエル書 6:8; ダニエル書 3:8–12; エステル記 1:19"> 彼らは王の前にきて、王の禁令について奏上して言った、「王よ、あなたは禁令に署名して、今から三十日の間は、ただあなたにのみ願い事をさせ、もしあなたをおいて、神または人に、これをなす者があれば、すべてその者を、ししの穴に投げ入れると、定められたではありませんか」。王は答えて言った、「その事は確かであって、メデアとペルシャの法律のごとく、変えることのできないものだ」。</span>
<span className="v" id="v13" data-v="13" data-xref="ダニエル書 3:12; 使徒行伝 5:29; ダニエル書 2:25"> 彼らは王の前に答えて言った、「王よ、ユダから引いてきた捕囚のひとりである、かのダニエルは、あなたをも、あなたの署名された禁令をも顧みず、一日に三度ずつ、祈をささげています」。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="マルコによる福音書 6:26; マタイによる福音書 27:17–24; サムエル記下 3:28–29"> 王はこの言葉を聞いて大いに憂え、ダニエルを救おうと心を用い、日の入るまで、彼を救い出すことに努めた。</span>
<span className="v" id="v15" data-v="15" data-xref="ダニエル書 6:12; 詩篇 94:20–21; ダニエル書 6:8"> 時にその人々は、また王のもとに集まってきて、王に言った、「王よ、メデアとペルシャの法律によれば、王の立てた禁令、または、おきては変えることのできないものであることを、ご承知ください」。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="詩篇 37:39–40; ヨブ記 5:19; 詩篇 91:14–16"> そこで王は命令を下したので、ダニエルは引き出されて、ししの穴に投げ入れられた。王はダニエルに言った、「どうか、あなたの常に仕える神が、あなたを救われるように」。</span>
<span className="v" id="v17" data-v="17" data-xref="哀歌 3:53; 使徒行伝 12:4; マタイによる福音書 27:60–66"> そして一つの石を持ってきて、穴の口をふさいだので、王は自分の印と、大臣らの印をもって、これに封印した。これはダニエルの処置を変えることのないようにするためであった。</span>
<span className="v" id="v18" data-v="18" data-xref="エステル記 6:1; ダニエル書 2:1; サムエル記下 12:16–17"> こうして王はその宮殿に帰ったが、その夜は食をとらず、また、そばめたちを召し寄せず、全く眠ることもしなかった。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="テサロニケ人への第一の手紙 3:5; マルコによる福音書 16:2; マタイによる福音書 28:1"> こうして王は朝まだき起きて、ししの穴へ急いで行ったが、</span>
<span className="v" id="v20" data-v="20" data-xref="歴代志上 16:11; ヘブル人への手紙 7:25; ダニエル書 6:27"> ダニエルのいる穴に近づいたとき、悲しげな声をあげて呼ばわり、ダニエルに言った、「生ける神のしもべダニエルよ、あなたが常に仕えている神はあなたを救って、ししの害を免れさせることができたか」。</span>
<span className="v" id="v21" data-v="21" data-xref="ダニエル書 2:4; ダニエル書 6:6; ネヘミヤ書 2:3"> ダニエルは王に言った、「王よ、どうか、とこしえに生きながらえられますように。</span>
<span className="v" id="v22" data-v="22" data-xref="テモテヘの第二の手紙 4:17; ヘブル人への手紙 11:33; 使徒行伝 12:11"> わたしの神はその使をおくって、ししの口を閉ざされたので、ししはわたしを害しませんでした。これはわたしに罪のないことが、神の前に認められたからです。王よ、わたしはあなたの前にも、何も悪い事をしなかったのです」。</span>
<span className="v" id="v23" data-v="23" data-xref="歴代志上 5:20; マルコによる福音書 9:23; ダニエル書 3:27–28"> そこで王は大いに喜び、ダニエルを穴の中から出せと命じたので、ダニエルは穴の中から出されたが、その身になんの害をも受けていなかった。これは彼が自分の神を頼みとしていたからである。</span>
<span className="v" id="v24" data-v="24" data-xref="イザヤ書 38:13; エステル記 7:10; 申命記 24:16"> 王はまた命令を下して、ダニエルをあしざまに訴えた人々を引いてこさせ、彼らをその妻子と共に、ししの穴に投げ入れさせた。彼らが穴の底に達しないうちに、ししは彼らにとびかかって、その骨までもかみ砕いた。</span>
</div>
<div className="bp poetry">
<span className="v" id="v25" data-v="25" data-xref="ダニエル書 4:1; エズラ記 1:1–2; エステル記 3:12"> そこでダリヨス王は全世界に住む諸民、諸族、諸国語の者に詔を書きおくって言った、「どうか、あなたがたに平安が増すように。</span>
<span className="v" id="v26" data-v="26" data-xref="ダニエル書 4:34; ルカによる福音書 1:33; ダニエル書 3:29"> わたしは命令を出す。わが国のすべての州の人は、皆ダニエルの神を、おののき恐れなければならない。<br /><span className="pl pl-1">彼は生ける神であって、</span><br /><span className="pl pl-1">とこしえに変ることなく、</span><br /><span className="pl pl-1">その国は滅びず、その主権は終りまで続く。</span></span>
<span className="v" id="v27" data-v="27" data-xref="ダニエル書 4:2–3; 詩篇 18:50; 使徒行伝 4:30"> <span className="pl pl-1">彼は救を施し、助けをなし、</span><br /><span className="pl pl-1">天においても、地においても、</span><br /><span className="pl pl-1">しるしと奇跡とをおこない、</span><br /><span className="pl pl-1">ダニエルを救って、</span><br /><span className="pl pl-1">ししの力をのがれさせたかたである」。</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="ダニエル書 1:21; 歴代志下 36:22–2; イザヤ書 44:28–1"> こうして、このダニエルはダリヨスの世と、ペルシャ人クロスの世において栄えた。</span>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ハバクク書 2:19; エレミヤ書 16:20; イザヤ書 46:6"> ネブカデネザル王は一つの金の像を造った。その高さは六十キュビト、その幅は六キュビトで、彼はこれをバビロン州のドラの平野に立てた。</span>
<span className="v" id="v2" data-v="2" data-xref="ダニエル書 3:27; 箴言 29:12; 列王紀上 12:32"> そしてネブカデネザル王は、総督、長官、知事、参議、庫官、法官、高僧および諸州の官吏たちを召し集め、ネブカデネザル王の立てたこの像の落成式に臨ませようとした。</span>
<span className="v" id="v3" data-v="3" data-xref="ヨハネの黙示録 17:17; ヨハネの黙示録 17:13; ヨハネの黙示録 13:13–16"> そこで、総督、長官、知事、参議、庫官、法官、高僧および諸州の官吏たちは、ネブカデネザル王の立てた像の落成式に臨み、そのネブカデネザルの立てた像の前に立った。</span>
<span className="v" id="v4" data-v="4" data-xref="ダニエル書 4:1; ダニエル書 6:25; ミカ書 6:16"> 時に伝令者は大声に呼ばわって言った、「諸民、諸族、諸国語の者よ、あなたがたにこう命じられる。</span>
<span className="v" id="v5" data-v="5" data-xref="ダニエル書 3:15; ダニエル書 3:10; ダニエル書 3:7"> 角笛、横笛、琴、三角琴、立琴、風笛などの、もろもろの楽器の音を聞く時は、ひれ伏してネブカデネザル王の立てた金の像を拝まなければならない。</span>
<span className="v" id="v6" data-v="6" data-xref="マタイによる福音書 13:50; マタイによる福音書 13:42; エレミヤ書 29:22"> だれでもひれ伏して拝まない者は、ただちに火の燃える炉の中に投げ込まれる」と。</span>
<span className="v" id="v7" data-v="7" data-xref="ヨハネの黙示録 17:8; ヨハネの黙示録 13:3; ヨハネの黙示録 13:8"> そこで民らはみな、角笛、横笛、琴、三角琴、立琴、風笛などの、もろもろの楽器の音を聞くや、諸民、諸族、諸国語の者たちはみな、ひれ伏して、ネブカデネザル王の立てた金の像を拝んだ。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="エズラ記 4:12–16; ダニエル書 6:12–13; エステル記 3:8–9"> その時、あるカルデヤびとらが進みきて、ユダヤ人をあしざまに訴えた。</span>
<span className="v" id="v9" data-v="9" data-xref="ダニエル書 5:10; ダニエル書 6:6; ダニエル書 6:21"> すなわち彼らはネブカデネザル王に言った、「王よ、とこしえに生きながらえられますように。</span>
<span className="v" id="v10" data-v="10" data-xref="ダニエル書 3:4–7; ダニエル書 6:12; エステル記 3:12–14"> 王よ、あなたは命令を出して仰せられました。すべて、角笛、横笛、琴、三角琴、立琴、風笛などの、もろもろの楽器の音を聞く者は皆、ひれ伏して金の像を拝まなければならない。</span>
<span className="v" id="v11" data-v="11"> また、だれでもひれ伏して拝まない者はみな、火の燃える炉の中に投げ込まれると。</span>
<span className="v" id="v12" data-v="12" data-xref="ダニエル書 6:13; ダニエル書 2:49; 使徒行伝 17:7"> ここにあなたが任命して、バビロン州の事務をつかさどらせられているユダヤ人シャデラク、メシャクおよびアベデネゴがおります。王よ、この人々はあなたを尊ばず、あなたの神々にも仕えず、あなたの立てられた金の像をも拝もうとしません」。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="ダニエル書 3:19; ダニエル書 2:12; エステル記 3:5–6"> そこでネブカデネザルは怒りかつ憤って、シャデラク、メシャクおよびアベデネゴを連れてこいと命じたので、この人々を王の前に連れてきた。</span>
<span className="v" id="v14" data-v="14" data-xref="エレミヤ書 50:2; ダニエル書 3:1; イザヤ書 46:1"> ネブカデネザルは彼らに言った、「シャデラク、メシャク、アベデネゴよ、あなたがたがわが神々に仕えず、またわたしの立てた金の像を拝まないとは、ほんとうなのか。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行伝 5:29; 歴代志下 32:15–17; 出エジプト記 5:2"> あなたがたがもし、角笛、横笛、琴、三角琴、立琴、風笛などの、もろもろの楽器の音を聞くときにひれ伏して、わたしが立てた像を、ただちに拝むならば、それでよろしい。しかし、拝むことをしないならば、ただちに火の燃える炉の中に投げ込まれる。いったい、どの神が、わたしの手からあなたがたを救うことができようか」。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="ダニエル書 1:7; ダニエル書 3:12"> シャデラク、メシャクおよびアベデネゴは王に答えて言った、「ネブカデネザルよ、この事について、お答えする必要はありません。</span>
<span className="v" id="v17" data-v="17" data-xref="ローマ人への手紙 8:31; ルカによる福音書 1:37; ヘブル人への手紙 7:25"> もしそんなことになれば、わたしたちの仕えている神は、その火の燃える炉から、わたしたちを救い出すことができます。また王よ、あなたの手から、わたしたちを救い出されます。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行伝 5:29–32; マタイによる福音書 10:39; ヨハネの黙示録 2:10–11"> たといそうでなくても、王よ、ご承知ください。わたしたちはあなたの神々に仕えず、またあなたの立てた金の像を拝みません」。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="ダニエル書 3:13; レビ記 26:24; 箴言 21:24"> そこでネブカデネザルは怒りに満ち、シャデラク、メシャクおよびアベデネゴにむかって、顔色を変え、炉を平常よりも七倍熱くせよと命じた。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行伝 16:23; 使徒行伝 16:25; ダニエル書 3:15"> またその軍勢の中の力の強い人々を呼んで、シャデラク、メシャクおよびアベデネゴを縛って、彼らを火の燃える炉の中に投げ込めと命じた。</span>
<span className="v" id="v21" data-v="21"> そこでこの人々は、外套、下着、帽子、その他の衣服のまま縛られて、火の燃える炉の中に投げ込まれた。</span>
<span className="v" id="v22" data-v="22" data-xref="出エジプト記 12:33; 箴言 21:18; 箴言 11:8"> 王の命令はきびしく、かつ炉は、はなはだしく熱していたので、シャデラク、メシャクおよびアベデネゴを引きつれていった人々は、その火炎に焼き殺された。</span>
<span className="v" id="v23" data-v="23" data-xref="ダニエル書 6:16–17; エレミヤ書 38:6; 詩篇 34:19"> シャデラク、メシャク、アベデネゴの三人は縛られたままで、火の燃える炉の中に落ち込んだ。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="ダニエル書 6:7; ダニエル書 6:22; ダニエル書 3:9–10"> その時、ネブカデネザル王は驚いて急ぎ立ちあがり、大臣たちに言った、「われわれはあの三人を縛って、火の中に投げ入れたではないか」。彼らは王に答えて言った、「王よ、そのとおりです」。</span>
<span className="v" id="v25" data-v="25" data-xref="イザヤ書 43:2; 使徒行伝 28:5; マルコによる福音書 16:18"> 王は答えて言った、「しかし、わたしの見るのに四人の者がなわめなしに、火の中を歩いているが、なんの害をも受けていない。その第四の者の様子は神の子のようだ」。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="ダニエル書 3:17; イザヤ書 52:12; ヨハネの黙示録 19:5"> そこでネブカデネザルは、その火の燃える炉の入口に近寄って、「いと高き神のしもべシャデラク、メシャク、アベデネゴよ、出てきなさい」と言ったので、シャデラク、メシャク、アベデネゴはその火の中から出てきた。</span>
<span className="v" id="v27" data-v="27" data-xref="イザヤ書 43:2; ヘブル人への手紙 11:34; イザヤ書 26:11"> 総督、長官、知事および王の大臣たちも集まってきて、この人々を見たが、火は彼らの身にはなんの力もなく、その頭の毛は焼けず、その外套はそこなわれず、火のにおいもこれに付かなかった。</span>
<span className="v" id="v28" data-v="28" data-xref="ローマ人への手紙 14:7–8; 詩篇 34:7–8; 詩篇 84:11–12"> ネブカデネザルは言った、「シャデラク、メシャク、アベデネゴの神はほむべきかな。神はその使者をつかわして、自分に寄り頼むしもべらを救った。また彼らは自分の神以外の神に仕え、拝むよりも、むしろ王の命令を無視し、自分の身をも捨てようとしたのだ。</span>
<span className="v" id="v29" data-v="29" data-xref="ダニエル書 2:5; 詩篇 76:10; 申命記 32:31"> それでわたしはいま命令を下す。諸民、諸族、諸国語の者のうちだれでも、シャデラク、メシャク、アベデネゴの神をののしる者があるならば、その身は切り裂かれ、その家は滅ぼされなければならない。このように救を施すことのできる神は、ほかにないからだ」。</span>
<span className="v" id="v30" data-v="30" data-xref="ダニエル書 2:49; サムエル記上 2:30; ダニエル書 3:12"> こうして、王はシャデラク、メシャクおよびアベデネゴの位を進めて、バビロン州におらせた。</span>
</div>

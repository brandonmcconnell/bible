<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ルカによる福音書 8:4–10; マタイによる福音書 13:1–15; マルコによる福音書 4:1–12"> その日、イエスは家を出て、海べにすわっておられた。</span>
<span className="v" id="v2" data-v="2" data-xref="ルカによる福音書 5:3; マタイによる福音書 4:25; マルコによる福音書 4:1"> ところが、大ぜいの群衆がみもとに集まったので、イエスは舟に乗ってすわられ、群衆はみな岸に立っていた。</span>
<span className="v" id="v3" data-v="3" data-xref="マルコによる福音書 4:2–9; マルコによる福音書 4:13; 詩篇 78:2"> イエスは譬で多くの事を語り、こう言われた、「見よ、種まきが種をまきに出て行った。</span>
<span className="v" id="v4" data-v="4" data-xref="マタイによる福音書 13:18–19"> まいているうちに、道ばたに落ちた種があった。すると、鳥がきて食べてしまった。</span>
<span className="v" id="v5" data-v="5" data-xref="エゼキエル書 11:19; エゼキエル書 36:26; ゼカリヤ書 7:12"> ほかの種は土の薄い石地に落ちた。そこは土が深くないので、すぐ芽を出したが、</span>
<span className="v" id="v6" data-v="6" data-xref="マタイによる福音書 13:21; ヤコブの手紙 1:11–12; コロサイ人への手紙 1:23"> 日が上ると焼けて、根がないために枯れてしまった。</span>
<span className="v" id="v7" data-v="7" data-xref="マルコによる福音書 4:18–19; エレミヤ書 4:3–4; 創世記 3:18"> ほかの種はいばらの地に落ちた。すると、いばらが伸びて、ふさいでしまった。</span>
<span className="v" id="v8" data-v="8" data-xref="マタイによる福音書 13:23; ルカによる福音書 8:15; 創世記 26:12"> ほかの種は良い地に落ちて実を結び、あるものは百倍、あるものは六十倍、あるものは三十倍にもなった。</span>
<span className="v" id="v9" data-v="9" data-xref="ヨハネの黙示録 2:11; マタイによる福音書 11:15; ヨハネの黙示録 2:7"> 耳のある者は聞くがよい」。</span>
</div>
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="マルコによる福音書 4:33–34; マルコによる福音書 4:10"> それから、弟子たちがイエスに近寄ってきて言った、「なぜ、彼らに譬でお話しになるのですか」。</span>
<span className="v" id="v11" data-v="11" data-xref="コリント人への第一の手紙 2:9–10; コリント人への第一の手紙 2:14; マタイによる福音書 19:11"> そこでイエスは答えて言われた、「あなたがたには、天国の奥義を知ることが許されているが、彼らには許されていない。</span>
<span className="v" id="v12" data-v="12" data-xref="マタイによる福音書 25:29; マルコによる福音書 4:24–25; ルカによる福音書 8:18"> おおよそ、持っている人は与えられて、いよいよ豊かになるが、持っていない人は、持っているものまでも取り上げられるであろう。</span>
<span className="v" id="v13" data-v="13" data-xref="エゼキエル書 12:2; エレミヤ書 5:21; イザヤ書 42:18–20"> だから、彼らには譬で語るのである。それは彼らが、見ても見ず、聞いても聞かず、また悟らないからである。</span>
<span className="v" id="v14" data-v="14" data-xref="イザヤ書 6:9–10; エゼキエル書 12:2; コリント人への第二の手紙 3:14"> こうしてイザヤの言った預言が、彼らの上に成就したのである。<br /><span className="pl pl-1">『あなたがたは聞くには聞くが、決して悟らない。</span><br /><span className="pl pl-1">見るには見るが、決して認めない。</span></span>
<span className="v" id="v15" data-v="15" data-xref="イザヤ書 6:10; マルコによる福音書 4:12; ゼカリヤ書 7:11"> <span className="pl pl-1">この民の心は鈍くなり、</span><br /><span className="pl pl-1">その耳は聞えにくく、</span><br /><span className="pl pl-1">その目は閉じている。</span><br /><span className="pl pl-1">それは、彼らが目で見ず、耳で聞かず、心で悟らず、</span><br /><span className="pl pl-1">悔い改めていやされることがないためである』。</span></span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="ルカによる福音書 10:23–24; エペソ人への手紙 1:17–18; マタイによる福音書 16:17"> しかし、あなたがたの目は見ており、耳は聞いているから、さいわいである。</span>
<span className="v" id="v17" data-v="17" data-xref="ヨハネによる福音書 8:56; ヘブル人への手紙 11:13; ペテロの第一の手紙 1:10–12"> あなたがたによく言っておく。多くの預言者や義人は、あなたがたの見ていることを見ようと熱心に願ったが、見ることができず、またあなたがたの聞いていることを聞こうとしたが、聞けなかったのである。</span>
<span className="v" id="v18" data-v="18" data-xref="マタイによる福音書 13:11–12; ルカによる福音書 8:11–15; マルコによる福音書 4:13–20"> そこで、種まきの譬を聞きなさい。</span>
<span className="v" id="v19" data-v="19" data-xref="ルカによる福音書 8:11–15; マタイによる福音書 13:38; ヘブル人への手紙 2:1"> だれでも御国の言を聞いて悟らないならば、悪い者がきて、その人の心にまかれたものを奪いとって行く。道ばたにまかれたものというのは、そういう人のことである。</span>
<span className="v" id="v20" data-v="20" data-xref="エゼキエル書 33:31–32; 詩篇 106:12–13; ヨハネによる福音書 5:35"> 石地にまかれたものというのは、御言を聞くと、すぐに喜んで受ける人のことである。</span>
<span className="v" id="v21" data-v="21" data-xref="マタイによる福音書 11:6; ペテロの第二の手紙 1:8–9; エペソ人への手紙 3:17"> その中に根がないので、しばらく続くだけであって、御言のために困難や迫害が起ってくると、すぐつまずいてしまう。</span>
<span className="v" id="v22" data-v="22" data-xref="テモテヘの第一の手紙 6:17; ルカによる福音書 8:14; テモテヘの第一の手紙 6:9–10"> また、いばらの中にまかれたものとは、御言を聞くが、世の心づかいと富の惑わしとが御言をふさぐので、実を結ばなくなる人のことである。</span>
<span className="v" id="v23" data-v="23" data-xref="ピリピ人への手紙 1:11; マタイによる福音書 12:33; ヨハネによる福音書 15:16"> また、良い地にまかれたものとは、御言を聞いて悟る人のことであって、そういう人が実を結び、百倍、あるいは六十倍、あるいは三十倍にもなるのである」。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="マタイによる福音書 25:1; マタイによる福音書 13:47; マタイによる福音書 20:1"> また、ほかの譬を彼らに示して言われた、「天国は、良い種を自分の畑にまいておいた人のようなものである。</span>
<span className="v" id="v25" data-v="25" data-xref="ペテロの第一の手紙 5:8; ペテロの第二の手紙 2:1; 使徒行伝 20:30–31"> 人々が眠っている間に敵がきて、麦の中に毒麦をまいて立ち去った。</span>
<span className="v" id="v26" data-v="26" data-xref="マルコによる福音書 4:26–29"> 芽がはえ出て実を結ぶと、同時に毒麦もあらわれてきた。</span>
<span className="v" id="v27" data-v="27" data-xref="ローマ人への手紙 16:17; コリント人への第二の手紙 6:1; コリント人への第二の手紙 5:18–20"> 僕たちがきて、家の主人に言った、『ご主人様、畑におまきになったのは、良い種ではありませんでしたか。どうして毒麦がはえてきたのですか』。</span>
<span className="v" id="v28" data-v="28" data-xref="コリント人への第一の手紙 5:3–7; テサロニケ人への第一の手紙 5:14; ルカによる福音書 9:49–54"> 主人は言った、『それは敵のしわざだ』。すると僕たちが言った『では行って、それを抜き集めましょうか』。</span>
<span className="v" id="v29" data-v="29"> 彼は言った、『いや、毒麦を集めようとして、麦も一緒に抜くかも知れない。</span>
<span className="v" id="v30" data-v="30" data-xref="マタイによる福音書 3:12; テモテヘの第一の手紙 5:24; コリント人への第一の手紙 4:5"> 収穫まで、両方とも育つままにしておけ。収穫の時になったら、刈る者に、まず毒麦を集めて束にして焼き、麦の方は集めて倉に入れてくれ、と言いつけよう』」。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="ルカによる福音書 13:18–19; マタイによる福音書 17:20; マルコによる福音書 4:30–32"> また、ほかの譬を彼らに示して言われた、「天国は、一粒のからし種のようなものである。ある人がそれをとって畑にまくと、</span>
<span className="v" id="v32" data-v="32" data-xref="エゼキエル書 31:6; ダニエル書 4:12; エゼキエル書 17:23–24"> それはどんな種よりも小さいが、成長すると、野菜の中でいちばん大きくなり、空の鳥がきて、その枝に宿るほどの木になる」。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="ガラテヤ人への手紙 5:9; コリント人への第一の手紙 5:6–7; ルカによる福音書 13:21"> またほかの譬を彼らに語られた、「天国は、パン種のようなものである。女がそれを取って三斗の粉の中に混ぜると、全体がふくらんでくる」。</span>
</div>
<div className="bp poetry">
<span className="v" id="v34" data-v="34" data-xref="マルコによる福音書 4:33–34; ヨハネによる福音書 16:25; マタイによる福音書 13:13"> イエスはこれらのことをすべて、譬で群衆に語られた。譬によらないでは何事も彼らに語られなかった。</span>
<span className="v" id="v35" data-v="35" data-xref="詩篇 78:2; エペソ人への手紙 3:9; ペテロの第一の手紙 1:20–21"> これは預言者によって言われたことが、成就するためである、<br /><span className="pl pl-1">「わたしは口を開いて譬を語り、</span><br /><span className="pl pl-1">世の初めから隠されていることを語り出そう」。</span></span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="ヨハネによる福音書 16:17–20; マタイによる福音書 13:11; マタイによる福音書 9:28"> それからイエスは、群衆をあとに残して家にはいられた。すると弟子たちは、みもとにきて言った、「畑の毒麦の譬を説明してください」。</span>
<span className="v" id="v37" data-v="37" data-xref="コリント人への第一の手紙 3:5–7; マタイによる福音書 13:41; ルカによる福音書 10:16"> イエスは答えて言われた、「良い種をまく者は、人の子である。</span>
<span className="v" id="v38" data-v="38" data-xref="ヨハネによる福音書 8:44; ピリピ人への手紙 3:18–19; 使徒行伝 13:10"> 畑は世界である。良い種と言うのは御国の子たちで、毒麦は悪い者の子たちである。</span>
<span className="v" id="v39" data-v="39" data-xref="マタイによる福音書 13:49; ヨハネの黙示録 14:15–19; マタイによる福音書 25:31"> それをまいた敵は悪魔である。収穫とは世の終りのことで、刈る者は御使たちである。</span>
<span className="v" id="v40" data-v="40" data-xref="マタイによる福音書 13:39"> だから、毒麦が集められて火で焼かれるように、世の終りにもそのとおりになるであろう。</span>
<span className="v" id="v41" data-v="41" data-xref="マタイによる福音書 24:31; マタイによる福音書 18:7; ペテロの第二の手紙 2:1–2"> 人の子はその使たちをつかわし、つまずきとなるものと不法を行う者とを、ことごとく御国からとり集めて、</span>
<span className="v" id="v42" data-v="42" data-xref="マタイによる福音書 13:50; ルカによる福音書 16:23–24; マタイによる福音書 8:12"> 炉の火に投げ入れさせるであろう。そこでは泣き叫んだり、歯がみをしたりするであろう。</span>
<span className="v" id="v43" data-v="43" data-xref="ダニエル書 12:3; マタイによる福音書 11:15; ルカによる福音書 12:32"> そのとき、義人たちは彼らの父の御国で、太陽のように輝きわたるであろう。耳のある者は聞くがよい。</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="箴言 2:2–5; コロサイ人への手紙 2:3; ピリピ人への手紙 3:7–9"> 天国は、畑に隠してある宝のようなものである。人がそれを見つけると隠しておき、喜びのあまり、行って持ち物をみな売りはらい、そしてその畑を買うのである。</span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="箴言 3:13–18; マタイによる福音書 16:26; マタイによる福音書 13:24"> また天国は、良い真珠を捜している商人のようなものである。</span>
<span className="v" id="v46" data-v="46" data-xref="エペソ人への手紙 3:8; ルカによる福音書 18:28–30; 箴言 2:4"> 高価な真珠一個を見いだすと、行って持ち物をみな売りはらい、そしてこれを買うのである。</span>
</div>
<div className="bp">
<span className="v" id="v47" data-v="47" data-xref="ヨハネによる福音書 15:6; テモテヘの第二の手紙 3:2–5; マタイによる福音書 22:9–10"> また天国は、海におろして、あらゆる種類の魚を囲みいれる網のようなものである。</span>
<span className="v" id="v48" data-v="48" data-xref="マタイによる福音書 13:30; マタイによる福音書 13:40–43; マタイによる福音書 3:12"> それがいっぱいになると岸に引き上げ、そしてすわって、良いのを器に入れ、悪いのを外へ捨てるのである。</span>
<span className="v" id="v49" data-v="49" data-xref="ヨハネの黙示録 20:12–15; マタイによる福音書 24:31; マタイによる福音書 13:39"> 世の終りにも、そのとおりになるであろう。すなわち、御使たちがきて、義人のうちから悪人をえり分け、</span>
<span className="v" id="v50" data-v="50" data-xref="マタイによる福音書 13:42; マタイによる福音書 8:12; ヨハネの黙示録 14:10–11"> そして炉の火に投げこむであろう。そこでは泣き叫んだり、歯がみをしたりするであろう。</span>
</div>
<div className="bp">
<span className="v" id="v51" data-v="51" data-xref="マタイによる福音書 13:19; マタイによる福音書 13:11; マルコによる福音書 4:34"> あなたがたは、これらのことが皆わかったか」。彼らは「わかりました」と答えた。</span>
<span className="v" id="v52" data-v="52" data-xref="ヨハネの第一の手紙 2:7–8; テモテヘの第二の手紙 3:16–17; テトスヘの手紙 1:9"> そこで、イエスは彼らに言われた、「それだから、天国のことを学んだ学者は、新しいものと古いものとを、その倉から取り出す一家の主人のようなものである」。</span>
</div>
<div className="bp">
<span className="v" id="v53" data-v="53" data-xref="マタイによる福音書 7:28; マルコによる福音書 4:33–35"> イエスはこれらの譬を語り終えてから、そこを立ち去られた。</span>
<span className="v" id="v54" data-v="54" data-xref="マタイによる福音書 7:28; ヨハネによる福音書 7:15–16; マルコによる福音書 6:1–6"> そして郷里に行き、会堂で人々を教えられたところ、彼らは驚いて言った、「この人は、この知恵とこれらの力あるわざとを、どこで習ってきたのか。</span>
<span className="v" id="v55" data-v="55" data-xref="ヨハネによる福音書 6:42; マルコによる福音書 6:3; ルカによる福音書 3:23"> この人は大工の子ではないか。母はマリヤといい、兄弟たちは、ヤコブ、ヨセフ、シモン、ユダではないか。</span>
<span className="v" id="v56" data-v="56"> またその姉妹たちもみな、わたしたちと一緒にいるではないか。こんな数々のことを、いったい、どこで習ってきたのか」。</span>
<span className="v" id="v57" data-v="57" data-xref="ヨハネによる福音書 4:44; マタイによる福音書 11:6; ルカによる福音書 4:24"> こうして人々はイエスにつまずいた。しかし、イエスは言われた、「預言者は、自分の郷里や自分の家以外では、どこででも敬われないことはない」。</span>
<span className="v" id="v58" data-v="58" data-xref="マルコによる福音書 6:5–6; ローマ人への手紙 11:20; ヘブル人への手紙 3:12–19"> そして彼らの不信仰のゆえに、そこでは力あるわざを、あまりなさらなかった。</span>
</div>

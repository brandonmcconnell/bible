<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨハネによる福音書 10:40; マタイによる福音書 19:1–9; マタイによる福音書 7:28"> イエスはこれらのことを語り終えられてから、ガリラヤを去ってヨルダンの向こうのユダヤの地方へ行かれた。</span>
<span className="v" id="v2" data-v="2" data-xref="マタイによる福音書 12:15; マルコによる福音書 6:55–56; マタイによる福音書 15:30–31"> すると大ぜいの群衆がついてきたので、彼らをそこでおいやしになった。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="マルコによる福音書 10:2; ヘブル人への手紙 3:9; マタイによる福音書 16:1"> さてパリサイ人たちが近づいてきて、イエスを試みようとして言った、「何かの理由で、夫がその妻を出すのは、さしつかえないでしょうか」。</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 2:23; 創世記 1:27; 創世記 5:2"> イエスは答えて言われた、「あなたがたはまだ読んだことがないのか。『創造者は初めから人を男と女とに造られ、</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 2:21–24; コリント人への第一の手紙 7:4; コリント人への第一の手紙 7:2"> そして言われた、それゆえに、人は父母を離れ、その妻と結ばれ、ふたりの者は一体となるべきである』。</span>
<span className="v" id="v6" data-v="6" data-xref="ヘブル人への手紙 13:4; マルコによる福音書 10:9; コリント人への第一の手紙 7:10–14"> 彼らはもはや、ふたりではなく一体である。だから、神が合わせられたものを、人は離してはならない」。</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 24:1–4; マタイによる福音書 5:31; マルコによる福音書 10:4"> 彼らはイエスに言った、「それでは、なぜモーセは、妻を出す場合には離縁状を渡せ、と定めたのですか」。</span>
<span className="v" id="v8" data-v="8" data-xref="マラキ書 2:13–14; 創世記 2:24; マルコによる福音書 10:5"> イエスが言われた、「モーセはあなたがたの心が、かたくななので、妻を出すことを許したのだが、初めからそうではなかった。</span>
<span className="v" id="v9" data-v="9" data-xref="マタイによる福音書 5:32; ルカによる福音書 16:18; コリント人への第一の手紙 7:39"> そこでわたしはあなたがたに言う。不品行のゆえでなくて、自分の妻を出して他の女をめとる者は、姦淫を行うのである」。</span>
<span className="v" id="v10" data-v="10" data-xref="コリント人への第一の手紙 7:32–35; 箴言 19:13–14; 箴言 21:19"> 弟子たちは言った、「もし妻に対する夫の立場がそうだとすれば、結婚しない方がましです」。</span>
<span className="v" id="v11" data-v="11" data-xref="コリント人への第一の手紙 7:17; コリント人への第一の手紙 7:35; コリント人への第一の手紙 7:7–9"> するとイエスは彼らに言われた、「その言葉を受けいれることができるのはすべての人ではなく、ただそれを授けられている人々だけである。</span>
<span className="v" id="v12" data-v="12" data-xref="コリント人への第一の手紙 7:32–38; コリント人への第一の手紙 9:5; イザヤ書 56:3–4"> というのは、母の胎内から独身者に生れついているものがあり、また他から独身者にされたものもあり、また天国のために、みずから進んで独身者となったものもある。この言葉を受けられる者は、受けいれるがよい」。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="マルコによる福音書 10:13–16; ルカによる福音書 18:15–17; マタイによる福音書 18:2–5"> そのとき、イエスに手をおいて祈っていただくために、人々が幼な子らをみもとに連れてきた。ところが、弟子たちは彼らをたしなめた。</span>
<span className="v" id="v14" data-v="14" data-xref="マタイによる福音書 18:3; ルカによる福音書 18:16–17; コリント人への第一の手紙 14:20"> するとイエスは言われた、「幼な子らをそのままにしておきなさい。わたしのところに来るのをとめてはならない。天国はこのような者の国である」。</span>
<span className="v" id="v15" data-v="15" data-xref="マルコによる福音書 10:16; テモテヘの第二の手紙 3:15; コリント人への第一の手紙 7:14"> そして手を彼らの上においてから、そこを去って行かれた。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="マルコによる福音書 10:17–30; ヨハネによる福音書 3:15; ユダの手紙 1:21"> すると、ひとりの人がイエスに近寄ってきて言った、「先生、永遠の生命を得るためには、どんなよいことをしたらいいでしょうか」。</span>
<span className="v" id="v17" data-v="17" data-xref="レビ記 18:5; ルカによる福音書 10:26–28; ガラテヤ人への手紙 3:11–13"> イエスは言われた、「なぜよい事についてわたしに尋ねるのか。よいかたはただひとりだけである。もし命に入りたいと思うなら、いましめを守りなさい」。</span>
<span className="v" id="v18" data-v="18" data-xref="申命記 5:16–21; 出エジプト記 20:12–17; マルコによる福音書 10:19"> 彼は言った、「どのいましめですか」。イエスは言われた、「『殺すな、姦淫するな、盗むな、偽証を立てるな。</span>
<span className="v" id="v19" data-v="19" data-xref="レビ記 19:18; 出エジプト記 20:12; マタイによる福音書 22:39"> 父と母とを敬え』。また『自分を愛するように、あなたの隣り人を愛せよ』」。</span>
<span className="v" id="v20" data-v="20" data-xref="ガラテヤ人への手紙 3:24; マルコによる福音書 10:20–21; ピリピ人への手紙 3:6"> この青年はイエスに言った、「それはみな守ってきました。ほかに何が足りないのでしょう」。</span>
<span className="v" id="v21" data-v="21" data-xref="マルコによる福音書 10:21; ルカによる福音書 18:22; ルカによる福音書 12:33"> イエスは彼に言われた、「もしあなたが完全になりたいと思うなら、帰ってあなたの持ち物を売り払い、貧しい人々に施しなさい。そうすれば、天に宝を持つようになろう。そして、わたしに従ってきなさい」。</span>
<span className="v" id="v22" data-v="22" data-xref="マタイによる福音書 6:24; エゼキエル書 33:31; マタイによる福音書 13:22"> この言葉を聞いて、青年は悲しみながら立ち去った。たくさんの資産を持っていたからである。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="テモテヘの第一の手紙 6:9–10; マタイによる福音書 13:22; マルコによる福音書 10:23"> それからイエスは弟子たちに言われた、「よく聞きなさい。富んでいる者が天国にはいるのは、むずかしいものである。</span>
<span className="v" id="v24" data-v="24" data-xref="ヨハネによる福音書 5:44; ルカによる福音書 18:25; マルコによる福音書 10:24–25"> また、あなたがたに言うが、富んでいる者が神の国にはいるよりは、らくだが針の穴を通る方が、もっとやさしい」。</span>
<span className="v" id="v25" data-v="25" data-xref="ローマ人への手紙 10:13; マタイによる福音書 24:22; ローマ人への手紙 11:5–7"> 弟子たちはこれを聞いて非常に驚いて言った、「では、だれが救われることができるのだろう」。</span>
<span className="v" id="v26" data-v="26" data-xref="エレミヤ書 32:27; ルカによる福音書 1:37; ヨブ記 42:2"> イエスは彼らを見つめて言われた、「人にはそれはできないが、神にはなんでもできない事はない」。</span>
<span className="v" id="v27" data-v="27" data-xref="ピリピ人への手紙 3:8; ルカによる福音書 18:28; ルカによる福音書 5:11"> そのとき、ペテロがイエスに答えて言った、「ごらんなさい、わたしたちはいっさいを捨てて、あなたに従いました。ついては、何がいただけるでしょうか」。</span>
<span className="v" id="v28" data-v="28" data-xref="ルカによる福音書 22:28–30; コリント人への第一の手紙 6:2–3; マタイによる福音書 25:31"> イエスは彼らに言われた、「よく聞いておくがよい。世が改まって、人の子がその栄光の座につく時には、わたしに従ってきたあなたがたもまた、十二の位に座してイスラエルの十二の部族をさばくであろう。</span>
<span className="v" id="v29" data-v="29" data-xref="ルカによる福音書 18:29–30; マルコによる福音書 10:29–30; ピリピ人への手紙 3:8"> おおよそ、わたしの名のために、家、兄弟、姉妹、父、母、子、もしくは畑を捨てた者は、その幾倍もを受け、また永遠の生命を受けつぐであろう。</span>
<span className="v" id="v30" data-v="30" data-xref="マタイによる福音書 20:16; ルカによる福音書 13:30; マルコによる福音書 10:31"> しかし、多くの先の者はあとになり、あとの者は先になるであろう。</span>
</div>
</div>

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="マルコによる福音書 3:22; マタイによる福音書 23:2; ルカによる福音書 5:21"> ときに、パリサイ人と律法学者たちとが、エルサレムからイエスのもとにきて言った、</span>
<span className="v" id="v2" data-v="2" data-xref="ルカによる福音書 11:38; マルコによる福音書 7:2; コロサイ人への手紙 2:20–23"> 「あなたの弟子たちは、なぜ昔の人々の言伝えを破るのですか。彼らは食事の時に手を洗っていません」。</span>
<span className="v" id="v3" data-v="3" data-xref="コロサイ人への手紙 2:23; テトスヘの手紙 1:14; コロサイ人への手紙 2:8"> イエスは答えて言われた、「なぜ、あなたがたも自分たちの言伝えによって、神のいましめを破っているのか。</span>
<span className="v" id="v4" data-v="4" data-xref="出エジプト記 20:12; レビ記 20:9; 出エジプト記 21:17"> 神は言われた、『父と母とを敬え』、また『父または母をののしる者は、必ず死に定められる』と。</span>
<span className="v" id="v5" data-v="5" data-xref="マルコによる福音書 7:10–13; 使徒行伝 5:29; マタイによる福音書 23:16–18"> それだのに、あなたがたは『だれでも父または母にむかって、あなたにさしあげるはずのこのものは供え物です、と言えば、</span>
<span className="v" id="v6" data-v="6" data-xref="テモテヘの第一の手紙 5:8; エレミヤ書 8:8; マルコによる福音書 7:13"> 父または母を敬わなくてもよろしい』と言っている。こうしてあなたがたは自分たちの言伝えによって、神の言を無にしている。</span>
<span className="v" id="v7" data-v="7" data-xref="マルコによる福音書 7:6; マタイによる福音書 23:23–29; 使徒行伝 28:25–27"> 偽善者たちよ、イザヤがあなたがたについて、こういう適切な預言をしている、</span>
<span className="v" id="v8" data-v="8" data-xref="イザヤ書 29:13; エゼキエル書 33:31; 使徒行伝 8:21"> <span className="pl pl-1">『この民は、口さきではわたしを敬うが、</span><br /><span className="pl pl-1">その心はわたしから遠く離れている。</span></span>
<span className="v" id="v9" data-v="9" data-xref="イザヤ書 29:13; マルコによる福音書 7:7; テモテヘの第一の手紙 1:4"> <span className="pl pl-1">人間のいましめを教として教え、</span><br /><span className="pl pl-1">無意味にわたしを拝んでいる』」。</span></span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="マルコによる福音書 7:14–15; ルカによる福音書 20:45–47; ルカによる福音書 24:45"> それからイエスは群衆を呼び寄せて言われた、「聞いて悟るがよい。</span>
<span className="v" id="v11" data-v="11" data-xref="マルコによる福音書 7:15; マタイによる福音書 15:18–20; ヤコブの手紙 3:5–8"> 口にはいるものは人を汚すことはない。かえって、口から出るものが人を汚すのである」。</span>
<span className="v" id="v12" data-v="12" data-xref="列王紀上 22:13–14; コリント人への第一の手紙 10:32–33; ガラテヤ人への手紙 2:5"> そのとき、弟子たちが近寄ってきてイエスに言った、「パリサイ人たちが御言を聞いてつまずいたことを、ご存じですか」。</span>
<span className="v" id="v13" data-v="13" data-xref="ヨハネによる福音書 15:2; イザヤ書 60:21; ヨハネによる福音書 15:6"> イエスは答えて言われた、「わたしの天の父がお植えにならなかったものは、みな抜き取られるであろう。</span>
<span className="v" id="v14" data-v="14" data-xref="ルカによる福音書 6:39; イザヤ書 56:10; マタイによる福音書 23:16–24"> 彼らをそのままにしておけ。彼らは盲人を手引きする盲人である。もし盲人が盲人を手引きするなら、ふたりとも穴に落ち込むであろう」。</span>
<span className="v" id="v15" data-v="15" data-xref="マタイによる福音書 13:36; マルコによる福音書 4:34; ヨハネによる福音書 16:29"> ペテロが答えて言った、「その譬を説明してください」。</span>
<span className="v" id="v16" data-v="16" data-xref="マタイによる福音書 16:9; マルコによる福音書 7:18; マルコによる福音書 9:32"> イエスは言われた、「あなたがたも、まだわからないのか。</span>
<span className="v" id="v17" data-v="17" data-xref="ルカによる福音書 6:45; コリント人への第一の手紙 6:13; マタイによる福音書 7:19–20"> 口にはいってくるものは、みな腹の中にはいり、そして、外に出て行くことを知らないのか。</span>
<span className="v" id="v18" data-v="18" data-xref="箴言 15:28; マタイによる福音書 12:34; ヤコブの手紙 3:6–10"> しかし、口から出て行くものは、心の中から出てくるのであって、それが人を汚すのである。</span>
<span className="v" id="v19" data-v="19" data-xref="マルコによる福音書 7:21–23; ガラテヤ人への手紙 5:19–21; エレミヤ書 17:9"> というのは、悪い思い、すなわち、殺人、姦淫、不品行、盗み、偽証、誹りは、心の中から出てくるのであって、</span>
<span className="v" id="v20" data-v="20" data-xref="マルコによる福音書 7:3–4; エペソ人への手紙 5:3–6; コリント人への第一の手紙 6:18–20"> これらのものが人を汚すのである。しかし、洗わない手で食事することは、人を汚すのではない」。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="マルコによる福音書 7:24–30; マタイによる福音書 11:21–23; 士師記 1:31"> さて、イエスはそこを出て、ツロとシドンとの地方へ行かれた。</span>
<span className="v" id="v22" data-v="22" data-xref="マタイによる福音書 9:27; マルコによる福音書 7:25–26; マタイによる福音書 17:15"> すると、そこへ、その地方出のカナンの女が出てきて、「主よ、ダビデの子よ、わたしをあわれんでください。娘が悪霊にとりつかれて苦しんでいます」と言って叫びつづけた。</span>
<span className="v" id="v23" data-v="23" data-xref="マタイによる福音書 14:15; マルコによる福音書 10:47–48; 哀歌 3:8"> しかし、イエスはひと言もお答えにならなかった。そこで弟子たちがみもとにきて願って言った、「この女を追い払ってください。叫びながらついてきていますから」。</span>
<span className="v" id="v24" data-v="24" data-xref="マタイによる福音書 10:5–6; ローマ人への手紙 15:8; エレミヤ書 50:6–7"> するとイエスは答えて言われた、「わたしは、イスラエルの家の失われた羊以外の者には、つかわされていない」。</span>
<span className="v" id="v25" data-v="25" data-xref="創世記 32:26; マタイによる福音書 20:31; マタイによる福音書 14:33"> しかし、女は近寄りイエスを拝して言った、「主よ、わたしをお助けください」。</span>
<span className="v" id="v26" data-v="26" data-xref="マルコによる福音書 7:27–28; マタイによる福音書 7:6; ピリピ人への手紙 3:2"> イエスは答えて言われた、「子供たちのパンを取って小犬に投げてやるのは、よろしくない」。</span>
<span className="v" id="v27" data-v="27" data-xref="エペソ人への手紙 3:8; ルカによる福音書 16:21; ヨブ記 40:4–5"> すると女は言った、「主よ、お言葉どおりです。でも、小犬もその主人の食卓から落ちるパンくずは、いただきます」。</span>
<span className="v" id="v28" data-v="28" data-xref="マルコによる福音書 9:23–24; マタイによる福音書 8:13; 詩篇 145:19"> そこでイエスは答えて言われた、「女よ、あなたの信仰は見あげたものである。あなたの願いどおりになるように」。その時に、娘はいやされた。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="マタイによる福音書 4:18; ヨハネによる福音書 6:1; マタイによる福音書 5:1"> イエスはそこを去って、ガリラヤの海べに行き、それから山に登ってそこにすわられた。</span>
<span className="v" id="v30" data-v="30" data-xref="ルカによる福音書 6:17–19; 使徒行伝 5:15–16; マタイによる福音書 14:35–36"> すると大ぜいの群衆が、足なえ、不具者、盲人、おし、そのほか多くの人々を連れてきて、イエスの足もとに置いたので、彼らをおいやしになった。</span>
<span className="v" id="v31" data-v="31" data-xref="マタイによる福音書 9:8; ルカによる福音書 18:43; ルカによる福音書 17:15–18"> 群衆は、おしが物を言い、不具者が直り、足なえが歩き、盲人が見えるようになったのを見て驚き、そしてイスラエルの神をほめたたえた。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="使徒行伝 27:33; ルカによる福音書 12:29–30; マタイによる福音書 9:36"> イエスは弟子たちを呼び寄せて言われた、「この群衆がかわいそうである。もう三日間もわたしと一緒にいるのに、何も食べるものがない。しかし、彼らを空腹のままで帰らせたくはない。恐らく途中で弱り切ってしまうであろう」。</span>
<span className="v" id="v33" data-v="33" data-xref="マルコによる福音書 6:37; マタイによる福音書 14:15; マルコによる福音書 8:4–5"> 弟子たちは言った、「荒野の中で、こんなに大ぜいの群衆にじゅうぶん食べさせるほどたくさんのパンを、どこで手に入れましょうか」。</span>
<span className="v" id="v34" data-v="34" data-xref="マタイによる福音書 16:9–10; ルカによる福音書 24:41–42; ヨハネによる福音書 21:9–10"> イエスは弟子たちに「パンはいくつあるか」と尋ねられると、「七つあります。また小さい魚が少しあります」と答えた。</span>
<span className="v" id="v35" data-v="35" data-xref="ルカによる福音書 9:14–16; マルコによる福音書 6:39–40; ヨハネによる福音書 6:10"> そこでイエスは群衆に、地にすわるようにと命じ、</span>
<span className="v" id="v36" data-v="36" data-xref="ルカによる福音書 22:19; ローマ人への手紙 14:6; ヨハネによる福音書 6:11"> 七つのパンと魚とを取り、感謝してこれをさき、弟子たちにわたされ、弟子たちはこれを群衆にわけた。</span>
<span className="v" id="v37" data-v="37" data-xref="マルコによる福音書 8:19–21; マタイによる福音書 16:9–10; マタイによる福音書 15:33"> 一同の者は食べて満腹した。そして残ったパンくずを集めると、七つのかごにいっぱいになった。</span>
<span className="v" id="v38" data-v="38"> 食べた者は、女と子供とを除いて四千人であった。</span>
<span className="v" id="v39" data-v="39" data-xref="マルコによる福音書 8:10; マタイによる福音書 14:22"> そこでイエスは群衆を解散させ、舟に乗ってマガダンの地方へ行かれた。</span>
</div>

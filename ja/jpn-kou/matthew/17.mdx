<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ルカによる福音書 9:28–36; マタイによる福音書 26:37; マルコによる福音書 5:37"> 六日ののち、イエスはペテロ、ヤコブ、ヤコブの兄弟ヨハネだけを連れて、高い山に登られた。</span>
<span className="v" id="v2" data-v="2" data-xref="詩篇 104:2; マタイによる福音書 28:3; ルカによる福音書 9:29"> ところが、彼らの目の前でイエスの姿が変り、その顔は日のように輝き、その衣は光のように白くなった。</span>
<span className="v" id="v3" data-v="3" data-xref="ルカによる福音書 24:44; マルコによる福音書 9:4; マラキ書 4:5"> すると、見よ、モーセとエリヤが彼らに現れて、イエスと語り合っていた。</span>
<span className="v" id="v4" data-v="4" data-xref="マルコによる福音書 9:5–6; ルカによる福音書 9:33; ヨハネによる福音書 14:8–9"> ペテロはイエスにむかって言った、「主よ、わたしたちがここにいるのは、すばらしいことです。もし、おさしつかえなければ、わたしはここに小屋を三つ建てましょう。一つはあなたのために、一つはモーセのために、一つはエリヤのために」。</span>
<span className="v" id="v5" data-v="5" data-xref="マタイによる福音書 3:17; マタイによる福音書 12:18; 申命記 18:15"> 彼がまだ話し終えないうちに、たちまち、輝く雲が彼らをおおい、そして雲の中から声がした、「これはわたしの愛する子、わたしの心にかなう者である。これに聞け」。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行伝 26:14; ペテロの第二の手紙 1:18; ダニエル書 8:17"> 弟子たちはこれを聞いて非常に恐れ、顔を地に伏せた。</span>
<span className="v" id="v7" data-v="7" data-xref="ダニエル書 10:18; マタイによる福音書 14:27; ダニエル書 8:18"> イエスは近づいてきて、手を彼らにおいて言われた、「起きなさい、恐れることはない」。</span>
<span className="v" id="v8" data-v="8" data-xref="ルカによる福音書 9:36; マルコによる福音書 9:8; 使徒行伝 12:10–11"> 彼らが目をあげると、イエスのほかには、だれも見えなかった。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="マルコによる福音書 8:30; マルコによる福音書 9:9–13; マタイによる福音書 17:23"> 一同が山を下って来るとき、イエスは「人の子が死人の中からよみがえるまでは、いま見たことをだれにも話してはならない」と、彼らに命じられた。</span>
<span className="v" id="v10" data-v="10" data-xref="マラキ書 4:5–6; マタイによる福音書 11:14; ヨハネによる福音書 1:21"> 弟子たちはイエスにお尋ねして言った、「いったい、律法学者たちは、なぜ、エリヤが先に来るはずだと言っているのですか」。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行伝 3:21; ルカによる福音書 1:16–17; マラキ書 4:6"> 答えて言われた、「確かに、エリヤがきて、万事を元どおりに改めるであろう。</span>
<span className="v" id="v12" data-v="12" data-xref="イザヤ書 53:3–12; マタイによる福音書 16:21; 使徒行伝 13:24–28"> しかし、あなたがたに言っておく。エリヤはすでにきたのだ。しかし人々は彼を認めず、自分かってに彼をあしらった。人の子もまた、そのように彼らから苦しみを受けることになろう」。</span>
<span className="v" id="v13" data-v="13" data-xref="マタイによる福音書 11:14"> そのとき、弟子たちは、イエスがバプテスマのヨハネのことを言われたのだと悟った。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="マルコによる福音書 9:14–29; マルコによる福音書 1:40; 使徒行伝 10:25–26"> さて彼らが群衆のところに帰ると、ひとりの人がイエスに近寄ってきて、ひざまずいて、言った、</span>
<span className="v" id="v15" data-v="15" data-xref="マタイによる福音書 4:24; ヨブ記 1:10–19; マルコによる福音書 9:20–22"> 「主よ、わたしの子をあわれんでください。てんかんで苦しんでおります。何度も何度も火の中や水の中に倒れるのです。</span>
<span className="v" id="v16" data-v="16" data-xref="マタイによる福音書 17:19–20; ルカによる福音書 9:40; 使徒行伝 19:15–16"> それで、その子をお弟子たちのところに連れてきましたが、なおしていただけませんでした」。</span>
<span className="v" id="v17" data-v="17" data-xref="民数記 14:11; マタイによる福音書 6:30; マルコによる福音書 16:14"> イエスは答えて言われた、「ああ、なんという不信仰な、曲った時代であろう。いつまで、わたしはあなたがたと一緒におられようか。いつまであなたがたに我慢ができようか。その子をここに、わたしのところに連れてきなさい」。</span>
<span className="v" id="v18" data-v="18" data-xref="マタイによる福音書 9:22; マルコによる福音書 1:34; マルコによる福音書 5:8"> イエスがおしかりになると、悪霊はその子から出て行った。そして子はその時いやされた。</span>
<span className="v" id="v19" data-v="19" data-xref="マルコによる福音書 9:28; マルコによる福音書 4:10"> それから、弟子たちがひそかにイエスのもとにきて言った、「わたしたちは、どうして霊を追い出せなかったのですか」。</span>
<span className="v" id="v20" data-v="20" data-xref="ルカによる福音書 17:6; マルコによる福音書 11:23; ルカによる福音書 1:37"> するとイエスは言われた、「あなたがたの信仰が足りないからである。よく言い聞かせておくが、もし、からし種一粒ほどの信仰があるなら、この山にむかって『ここからあそこに移れ』と言えば、移るであろう。このように、あなたがたにできない事は、何もないであろう。〔</span>
<span className="v" id="v21" data-v="21"> しかし、このたぐいは、祈と断食とによらなければ、追い出すことはできない〕」。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="マタイによる福音書 16:21; ルカによる福音書 18:31–34; マタイによる福音書 17:23"> 彼らがガリラヤで集まっていた時、イエスは言われた、「人の子は人々の手にわたされ、</span>
<span className="v" id="v23" data-v="23" data-xref="マタイによる福音書 16:21; イザヤ書 53:10–12; マルコによる福音書 8:31"> 彼らに殺され、そして三日目によみがえるであろう」。弟子たちは非常に心をいためた。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="出エジプト記 38:26; 出エジプト記 30:13; マルコによる福音書 9:33"> 彼らがカペナウムにきたとき、宮の納入金を集める人たちがペテロのところにきて言った、「あなたがたの先生は宮の納入金を納めないのか」。</span>
<span className="v" id="v25" data-v="25" data-xref="マタイによる福音書 22:21; ローマ人への手紙 13:6–7; マタイによる福音書 22:17"> ペテロは「納めておられます」と言った。そして彼が家にはいると、イエスから先に話しかけて言われた、「シモン、あなたはどう思うか。この世の王たちは税や貢をだれから取るのか。自分の子からか、それとも、ほかの人たちからか」。</span>
<span className="v" id="v26" data-v="26"> ペテロが「ほかの人たちからです」と答えると、イエスは言われた、「それでは、子は納めなくてもよいわけである。</span>
<span className="v" id="v27" data-v="27" data-xref="コリント人への第二の手紙 6:3; コリント人への第一の手紙 8:9; コリント人への第一の手紙 9:19–22"> しかし、彼らをつまずかせないために、海に行って、つり針をたれなさい。そして最初につれた魚をとって、その口をあけると、銀貨一枚が見つかるであろう。それをとり出して、わたしとあなたのために納めなさい」。</span>
</div>

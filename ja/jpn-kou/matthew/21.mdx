<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="ゼカリヤ書 14:4; マルコによる福音書 11:1–10; ルカによる福音書 21:37"> さて、彼らがエルサレムに近づき、オリブ山沿いのベテパゲに着いたとき、イエスはふたりの弟子をつかわして言われた、</span>
<span className="v" id="v2" data-v="2" data-xref="ルカによる福音書 19:30–32; マルコによる福音書 11:2–3; ヨハネによる福音書 2:5–8"> 「向こうの村へ行きなさい。するとすぐ、ろばがつながれていて、子ろばがそばにいるのを見るであろう。それを解いてわたしのところに引いてきなさい。</span>
<span className="v" id="v3" data-v="3" data-xref="コリント人への第二の手紙 8:1–2; 使徒行伝 17:25; コリント人への第二の手紙 8:9"> もしだれかが、あなたがたに何か言ったなら、主がお入り用なのです、と言いなさい。そう言えば、すぐ渡してくれるであろう」。</span>
<span className="v" id="v4" data-v="4" data-xref="ゼカリヤ書 9:9; ヨハネによる福音書 12:15; マタイによる福音書 1:22"> こうしたのは、預言者によって言われたことが、成就するためである。</span>
<span className="v" id="v5" data-v="5" data-xref="ゼカリヤ書 9:9–10; イザヤ書 62:11; イザヤ書 12:6"> すなわち、<br /><span className="pl pl-1">「シオンの娘に告げよ、</span><br /><span className="pl pl-1">見よ、あなたの王がおいでになる、</span><br /><span className="pl pl-1">柔和なおかたで、ろばに乗って、</span><br /><span className="pl pl-1">くびきを負うろばの子に乗って」。</span></span>
<span className="v" id="v6" data-v="6" data-xref="出エジプト記 39:43; ヨハネによる福音書 15:14; 出エジプト記 40:16"> <span className="pl pl-1">弟子たちは出て行って、イエスがお命じになったとおりにし、</span></span>
<span className="v" id="v7" data-v="7" data-xref="列王紀下 9:13; マルコによる福音書 11:4–8; ルカによる福音書 19:32–35"> <span className="pl pl-1">ろばと子ろばとを引いてきた。そしてその上に自分たちの上着をかけると、イエスはそれにお乗りになった。</span></span>
<span className="v" id="v8" data-v="8" data-xref="列王紀下 9:13; ヨハネによる福音書 12:13; レビ記 23:40"> <span className="pl pl-1">群衆のうち多くの者は自分たちの上着を道に敷き、また、ほかの者たちは木の枝を切ってきて道に敷いた。</span></span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 118:24–26; ルカによる福音書 2:14; ヨハネによる福音書 12:13–15"> <span className="pl pl-1">そして群衆は、前に行く者も、あとに従う者も、共に叫びつづけた、</span><br /><span className="pl pl-1">「ダビデの子に、ホサナ。</span><br /><span className="pl pl-1">主の御名によってきたる者に、祝福あれ。</span><br /><span className="pl pl-1">いと高き所に、ホサナ」。</span></span>
<span className="v" id="v10" data-v="10" data-xref="使徒行伝 9:5; ルツ記 1:19; ヨハネによる福音書 12:16–19"> <span className="pl pl-1">イエスがエルサレムにはいって行かれたとき、町中がこぞって騒ぎ立ち、「これは、いったい、どなただろう」と言った。</span></span>
<span className="v" id="v11" data-v="11" data-xref="ヨハネによる福音書 6:14; ルカによる福音書 7:16; ヨハネによる福音書 7:40"> <span className="pl pl-1">そこで群衆は、「この人はガリラヤのナザレから出た預言者イエスである」と言った。</span></span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="ヨハネによる福音書 2:14–17; ルカによる福音書 19:45–47; マルコによる福音書 11:15–18"> それから、イエスは宮にはいられた。そして、宮の庭で売り買いしていた人々をみな追い出し、また両替人の台や、はとを売る者の腰掛をくつがえされた。</span>
<span className="v" id="v13" data-v="13" data-xref="エレミヤ書 7:11; イザヤ書 56:7; ルカによる福音書 19:46"> そして彼らに言われた、「『わたしの家は、祈の家ととなえらるべきである』と書いてある。それだのに、あなたがたはそれを強盗の巣にしている」。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行伝 3:1–9; 使徒行伝 10:38; マタイによる福音書 11:4–5"> そのとき宮の庭で、盲人や足なえがみもとにきたので、彼らをおいやしになった。</span>
<span className="v" id="v15" data-v="15" data-xref="マタイによる福音書 21:9; ルカによる福音書 19:39–40; イザヤ書 26:11"> しかし、祭司長、律法学者たちは、イエスがなされた不思議なわざを見、また宮の庭で「ダビデの子に、ホサナ」と叫んでいる子供たちを見て立腹し、</span>
<span className="v" id="v16" data-v="16" data-xref="詩篇 8:2; マタイによる福音書 11:25; ルカによる福音書 19:39–40"> イエスに言った、「あの子たちが何を言っているのか、お聞きですか」。イエスは彼らに言われた、「そうだ、聞いている。あなたがたは『幼な子、乳のみ子たちの口にさんびを備えられた』とあるのを読んだことがないのか」。</span>
<span className="v" id="v17" data-v="17" data-xref="ヨハネによる福音書 11:18; マルコによる福音書 11:11; ルカによる福音書 24:50"> それから、イエスは彼らをあとに残し、都を出てベタニヤに行き、そこで夜を過ごされた。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="マタイによる福音書 4:2; ヘブル人への手紙 4:15; マタイによる福音書 12:1"> 朝はやく都に帰るとき、イエスは空腹をおぼえられた。</span>
<span className="v" id="v19" data-v="19" data-xref="ヨハネによる福音書 15:6; マルコによる福音書 11:14; テトスヘの手紙 1:16"> そして、道のかたわらに一本のいちじくの木があるのを見て、そこに行かれたが、ただ葉のほかは何も見当らなかった。そこでその木にむかって、「今から後いつまでも、おまえには実がならないように」と言われた。すると、いちじくの木はたちまち枯れた。</span>
<span className="v" id="v20" data-v="20" data-xref="イザヤ書 40:6–8; マルコによる福音書 11:20–21; ヤコブの手紙 1:10–11"> 弟子たちはこれを見て、驚いて言った、「いちじくがどうして、こうすぐに枯れたのでしょう」。</span>
<span className="v" id="v21" data-v="21" data-xref="ヤコブの手紙 1:6; マタイによる福音書 17:20; マルコによる福音書 11:22–23"> イエスは答えて言われた、「よく聞いておくがよい。もしあなたがたが信じて疑わないならば、このいちじくにあったようなことが、できるばかりでなく、この山にむかって、動き出して海の中にはいれと言っても、そのとおりになるであろう。</span>
<span className="v" id="v22" data-v="22" data-xref="マタイによる福音書 7:7; ヨハネの第一の手紙 5:14–15; マルコによる福音書 11:24"> また、祈のとき、信じて求めるものは、みな与えられるであろう」。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="使徒行伝 4:7; マルコによる福音書 11:27–33; 歴代志上 24:1–19"> イエスが宮にはいられたとき、祭司長たちや民の長老たちが、その教えておられる所にきて言った、「何の権威によって、これらの事をするのですか。だれが、そうする権威を授けたのですか」。</span>
<span className="v" id="v24" data-v="24" data-xref="ルカによる福音書 6:9; コロサイ人への手紙 4:6; マタイによる福音書 10:16"> そこでイエスは彼らに言われた、「わたしも一つだけ尋ねよう。あなたがたがそれに答えてくれたなら、わたしも、何の権威によってこれらの事をするのか、あなたがたに言おう。</span>
<span className="v" id="v25" data-v="25" data-xref="ヨハネの第一の手紙 3:20; マルコによる福音書 1:1–11; ヨハネによる福音書 3:18"> ヨハネのバプテスマはどこからきたのであったか。天からであったか、人からであったか」。すると、彼らは互に論じて言った、「もし天からだと言えば、では、なぜ彼を信じなかったのか、とイエスは言うだろう。</span>
<span className="v" id="v26" data-v="26" data-xref="マルコによる福音書 6:20; マタイによる福音書 14:5; ヨハネによる福音書 5:35"> しかし、もし人からだと言えば、群衆が恐ろしい。人々がみなヨハネを預言者と思っているのだから」。</span>
<span className="v" id="v27" data-v="27" data-xref="ローマ人への手紙 1:18–22; テサロニケ人への第二の手紙 2:9–10; ルカによる福音書 20:7–8"> そこで彼らは、「わたしたちにはわかりません」と答えた。すると、イエスが言われた、「わたしも何の権威によってこれらの事をするのか、あなたがたに言うまい。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="コリント人への第一の手紙 15:58; マタイによる福音書 20:1; コリント人への第一の手紙 10:15"> あなたがたはどう思うか。ある人にふたりの子があったが、兄のところに行って言った、『子よ、きょう、ぶどう園へ行って働いてくれ』。</span>
<span className="v" id="v29" data-v="29" data-xref="エゼキエル書 18:28–32; マタイによる福音書 3:2–8; イザヤ書 55:6–7"> すると彼は『おとうさん、参ります』と答えたが、行かなかった。</span>
<span className="v" id="v30" data-v="30" data-xref="テトスヘの手紙 1:16; エゼキエル書 33:31; マタイによる福音書 23:3"> また弟のところにきて同じように言った。彼は『いやです』と答えたが、あとから心を変えて、出かけた。</span>
<span className="v" id="v31" data-v="31" data-xref="ルカによる福音書 7:29; ルカによる福音書 7:37–50; マタイによる福音書 7:21"> このふたりのうち、どちらが父の望みどおりにしたのか」。彼らは言った、「あとの者です」。イエスは言われた、「よく聞きなさい。取税人や遊女は、あなたがたより先に神の国にはいる。</span>
<span className="v" id="v32" data-v="32" data-xref="ルカによる福音書 7:37–50; ゼカリヤ書 7:11–12; ルカによる福音書 7:29–30"> というのは、ヨハネがあなたがたのところにきて、義の道を説いたのに、あなたがたは彼を信じなかった。ところが、取税人や遊女は彼を信じた。あなたがたはそれを見たのに、あとになっても、心をいれ変えて彼を信じようとしなかった。</span>
</div>
<div className="bp poetry">
<span className="v" id="v33" data-v="33" data-xref="イザヤ書 5:1–4; マルコによる福音書 12:1–12; ルカによる福音書 20:9–19"> もう一つの譬を聞きなさい。ある所に、ひとりの家の主人がいたが、ぶどう園を造り、かきをめぐらし、その中に酒ぶねの穴を掘り、やぐらを立て、それを農夫たちに貸して、旅に出かけた。</span>
<span className="v" id="v34" data-v="34" data-xref="ルカによる福音書 20:10–19; イザヤ書 5:4; ゼカリヤ書 1:3–6"> 収穫の季節がきたので、その分け前を受け取ろうとして、僕たちを農夫のところへ送った。</span>
<span className="v" id="v35" data-v="35" data-xref="歴代志下 36:15–16; マタイによる福音書 5:12; ヘブル人への手紙 11:36–37"> すると、農夫たちは、その僕たちをつかまえて、ひとりを袋だたきにし、ひとりを殺し、もうひとりを石で打ち殺した。</span>
<span className="v" id="v36" data-v="36" data-xref="マタイによる福音書 22:4"> また別に、前よりも多くの僕たちを送ったが、彼らをも同じようにあしらった。</span>
<span className="v" id="v37" data-v="37" data-xref="ヨハネによる福音書 3:16; ヨハネによる福音書 3:35–36; ゼパニヤ書 3:7"> しかし、最後に、わたしの子は敬ってくれるだろうと思って、主人はその子を彼らの所につかわした。</span>
<span className="v" id="v38" data-v="38" data-xref="ルカによる福音書 20:14; 創世記 37:18–20; マルコによる福音書 12:7–8"> すると農夫たちは、その子を見て互に言った、『あれはあと取りだ。さあ、これを殺して、その財産を手に入れよう』。</span>
<span className="v" id="v39" data-v="39" data-xref="使徒行伝 2:23; ヤコブの手紙 5:6; ルカによる福音書 22:52–54"> そして彼をつかまえて、ぶどう園の外に引き出して殺した。</span>
<span className="v" id="v40" data-v="40" data-xref="ヘブル人への手紙 10:29; マルコによる福音書 12:9; ルカによる福音書 20:15–16"> このぶどう園の主人が帰ってきたら、この農夫たちをどうするだろうか」。</span>
<span className="v" id="v41" data-v="41" data-xref="使徒行伝 18:6; マタイによる福音書 21:43; 使徒行伝 28:28"> 彼らはイエスに言った、「悪人どもを、皆殺しにして、季節ごとに収穫を納めるほかの農夫たちに、そのぶどう園を貸し与えるでしょう」。</span>
<span className="v" id="v42" data-v="42" data-xref="詩篇 118:22–23; イザヤ書 28:16; 使徒行伝 4:11"> イエスは彼らに言われた、「あなたがたは、聖書でまだ読んだことがないのか、<br /><span className="pl pl-1">『家造りらの捨てた石が</span><br /><span className="pl pl-1">隅のかしら石になった。</span><br /><span className="pl pl-1">これは主がなされたことで、</span><br /><span className="pl pl-1">わたしたちの目には不思議に見える』。</span></span>
<span className="v" id="v43" data-v="43" data-xref="マタイによる福音書 21:41; マタイによる福音書 8:11–12; ペテロの第一の手紙 2:9"> <span className="pl pl-1">それだから、あなたがたに言うが、神の国はあなたがたから取り上げられて、御国にふさわしい実を結ぶような異邦人に与えられるであろう。</span></span>
<span className="v" id="v44" data-v="44" data-xref="イザヤ書 8:14–15; ペテロの第一の手紙 2:8; ダニエル書 2:34–35"> <span className="pl pl-1">またその石の上に落ちる者は打ち砕かれ、それがだれかの上に落ちかかるなら、その人はこなみじんにされるであろう」。</span></span>
<span className="v" id="v45" data-v="45" data-xref="ルカによる福音書 20:19; ルカによる福音書 11:45; マタイによる福音書 12:12"> <span className="pl pl-1">祭司長たちやパリサイ人たちがこの譬を聞いたとき、自分たちのことをさして言っておられることを悟ったので、</span></span>
<span className="v" id="v46" data-v="46" data-xref="マタイによる福音書 21:11; マタイによる福音書 21:26; ルカによる福音書 7:16"> <span className="pl pl-1">イエスを捕えようとしたが、群衆を恐れた。群衆はイエスを預言者だと思っていたからである。</span></span>
</div>

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="ミカ書 5:2; ヨハネによる福音書 7:42; ルカによる福音書 2:4–7"> イエスがヘロデ王の代に、ユダヤのベツレヘムでお生れになったとき、見よ、東からきた博士たちがエルサレムに着いて言った、</span>
<span className="v" id="v2" data-v="2" data-xref="民数記 24:17; エレミヤ書 23:5; ヨハネの黙示録 22:16"> 「ユダヤ人の王としてお生れになったかたは、どこにおられますか。わたしたちは東の方でその星を見たので、そのかたを拝みにきました」。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行伝 17:6–7; ヨハネによる福音書 11:47–48; マタイによる福音書 23:37"> ヘロデ王はこのことを聞いて不安を感じた。エルサレムの人々もみな、同様であった。</span>
<span className="v" id="v4" data-v="4" data-xref="マタイによる福音書 21:23; マタイによる福音書 7:29; 使徒行伝 6:12"> そこで王は祭司長たちと民の律法学者たちとを全部集めて、キリストはどこに生れるのかと、彼らに問いただした。</span>
<span className="v" id="v5" data-v="5" data-xref="ヨハネによる福音書 7:42; ルツ記 1:1; サムエル記上 16:1"> 彼らは王に言った、「それはユダヤのベツレヘムです。預言者がこうしるしています、</span>
<span className="v" id="v6" data-v="6" data-xref="エゼキエル書 34:23–25; ミカ書 5:2; イザヤ書 9:6–7"> <span className="pl pl-1">『ユダの地、ベツレヘムよ、</span><br /><span className="pl pl-1">おまえはユダの君たちの中で、</span><br /><span className="pl pl-1">決して最も小さいものではない。</span><br /><span className="pl pl-1">おまえの中からひとりの君が出て、</span><br /><span className="pl pl-1">わが民イスラエルの牧者となるであろう』」。</span></span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="出エジプト記 1:10; サムエル記上 18:21; 詩篇 55:21"> そこで、ヘロデはひそかに博士たちを呼んで、星の現れた時について詳しく聞き、</span>
<span className="v" id="v8" data-v="8" data-xref="コリント人への第一の手紙 3:19–20; エレミヤ書 41:5–7; ルカによる福音書 20:20–21"> 彼らをベツレヘムにつかわして言った、「行って、その幼な子のことを詳しく調べ、見つかったらわたしに知らせてくれ。わたしも拝みに行くから」。</span>
<span className="v" id="v9" data-v="9" data-xref="マタイによる福音書 2:2; 箴言 8:17; 詩篇 25:12"> 彼らは王の言うことを聞いて出かけると、見よ、彼らが東方で見た星が、彼らより先に進んで、幼な子のいる所まで行き、その上にとどまった。</span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 105:3; ルカによる福音書 2:20; ルカによる福音書 2:10"> 彼らはその星を見て、非常な喜びにあふれた。</span>
<span className="v" id="v11" data-v="11" data-xref="イザヤ書 60:6; 詩篇 72:10; ルカによる福音書 2:16"> そして、家にはいって、母マリヤのそばにいる幼な子に会い、ひれ伏して拝み、また、宝の箱をあけて、黄金・乳香・没薬などの贈り物をささげた。</span>
<span className="v" id="v12" data-v="12" data-xref="マタイによる福音書 2:22; マタイによる福音書 2:19; マタイによる福音書 2:13"> そして、夢でヘロデのところに帰るなとのみ告げを受けたので、他の道をとおって自分の国へ帰って行った。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="使徒行伝 10:7; 使徒行伝 5:19; マタイによる福音書 1:20"> 彼らが帰って行ったのち、見よ、主の使が夢でヨセフに現れて言った、「立って、幼な子とその母を連れて、エジプトに逃げなさい。そして、あなたに知らせるまで、そこにとどまっていなさい。ヘロデが幼な子を捜し出して、殺そうとしている」。</span>
<span className="v" id="v14" data-v="14" data-xref="マタイによる福音書 2:20–21; 使徒行伝 26:21; マタイによる福音書 1:24"> そこで、ヨセフは立って、夜の間に幼な子とその母とを連れてエジプトへ行き、</span>
<span className="v" id="v15" data-v="15" data-xref="ホセア書 11:1; 出エジプト記 4:22; 民数記 24:8"> ヘロデが死ぬまでそこにとどまっていた。それは、主が預言者によって「エジプトからわが子を呼び出した」と言われたことが、成就するためである。</span>
</div>
<div className="bp poetry">
<span className="v" id="v16" data-v="16" data-xref="イザヤ書 59:7; 箴言 28:15; 士師記 16:10"> さて、ヘロデは博士たちにだまされたと知って、非常に立腹した。そして人々をつかわし、博士たちから確かめた時に基いて、ベツレヘムとその附近の地方とにいる二歳以下の男の子を、ことごとく殺した。</span>
<span className="v" id="v17" data-v="17"> こうして、預言者エレミヤによって言われたことが、成就したのである。</span>
<span className="v" id="v18" data-v="18" data-xref="エレミヤ書 31:15; エレミヤ書 9:17–21; エレミヤ書 4:31"> <span className="pl pl-1">「叫び泣く大いなる悲しみの声が</span><br /><span className="pl pl-1">ラマで聞えた。</span><br /><span className="pl pl-1">ラケルはその子らのためになげいた。</span><br /><span className="pl pl-1">子らがもはやいないので、</span><br /><span className="pl pl-1">慰められることさえ願わなかった」。</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="マタイによる福音書 1:20; ダニエル書 8:25; マタイによる福音書 2:12–13"> さて、ヘロデが死んだのち、見よ、主の使がエジプトにいるヨセフに夢で現れて言った、</span>
<span className="v" id="v20" data-v="20" data-xref="出エジプト記 4:19; 列王紀上 12:1–3; マタイによる福音書 2:13"> 「立って、幼な子とその母を連れて、イスラエルの地に行け。幼な子の命をねらっていた人々は、死んでしまった」。</span>
<span className="v" id="v21" data-v="21" data-xref="ヘブル人への手紙 11:8; 創世記 6:22"> そこでヨセフは立って、幼な子とその母とを連れて、イスラエルの地に帰った。</span>
<span className="v" id="v22" data-v="22" data-xref="イザヤ書 48:17–18; ルカによる福音書 2:39; ヨハネによる福音書 7:52"> しかし、アケラオがその父ヘロデに代ってユダヤを治めていると聞いたので、そこへ行くことを恐れた。そして夢でみ告げを受けたので、ガリラヤの地方に退き、</span>
<span className="v" id="v23" data-v="23" data-xref="士師記 13:5; ヨハネによる福音書 1:45–46; マルコによる福音書 1:24"> ナザレという町に行って住んだ。これは預言者たちによって、「彼はナザレ人と呼ばれるであろう」と言われたことが、成就するためである。</span>
</div>

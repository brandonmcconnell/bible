<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ルカによる福音書 9:1–6; マルコによる福音書 3:13–15; マルコによる福音書 6:7–13"> そこで、イエスは十二弟子を呼び寄せて、汚れた霊を追い出し、あらゆる病気、あらゆるわずらいをいやす権威をお授けになった。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="マタイによる福音書 4:21; 使徒行伝 1:13; ルカによる福音書 5:10"> 十二使徒の名は、次のとおりである。まずペテロと呼ばれたシモンとその兄弟アンデレ、それからゼベダイの子ヤコブとその兄弟ヨハネ、</span>
<span className="v" id="v3" data-v="3" data-xref="マルコによる福音書 3:18; 使徒行伝 1:13; マルコによる福音書 2:14"> ピリポとバルトロマイ、トマスと取税人マタイ、アルパヨの子ヤコブとタダイ、</span>
<span className="v" id="v4" data-v="4" data-xref="マタイによる福音書 26:14; マタイによる福音書 26:47; ヨハネによる福音書 13:2"> 熱心党のシモンとイスカリオテのユダ。このユダはイエスを裏切った者である。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="ヨハネによる福音書 4:9; 使徒行伝 22:21–23; 列王紀下 17:24–41"> イエスはこの十二人をつかわすに当り、彼らに命じて言われた、「異邦人の道に行くな。またサマリヤ人の町にはいるな。</span>
<span className="v" id="v6" data-v="6" data-xref="エレミヤ書 50:6; エゼキエル書 34:6; イザヤ書 53:6"> むしろ、イスラエルの家の失われた羊のところに行け。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行伝 28:31; マタイによる福音書 3:2; ルカによる福音書 9:60"> 行って、『天国が近づいた』と宣べ伝えよ。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行伝 3:6; ルカによる福音書 10:9; 使徒行伝 4:30"> 病人をいやし、死人をよみがえらせ、らい病人をきよめ、悪霊を追い出せ。ただで受けたのだから、ただで与えるがよい。</span>
<span className="v" id="v9" data-v="9" data-xref="ルカによる福音書 22:35; ルカによる福音書 9:3–5; ルカによる福音書 10:4–12"> 財布の中に金、銀または銭を入れて行くな。</span>
<span className="v" id="v10" data-v="10" data-xref="ルカによる福音書 10:7–12; テモテヘの第一の手紙 5:17–18; コリント人への第一の手紙 9:4–14"> 旅行のための袋も、二枚の下着も、くつも、つえも持って行くな。働き人がその食物を得るのは当然である。</span>
<span className="v" id="v11" data-v="11" data-xref="ルカによる福音書 10:7–8; ヨブ記 31:32; 士師記 19:16–21"> どの町、どの村にはいっても、その中でだれがふさわしい人か、たずね出して、立ち去るまではその人のところにとどまっておれ。</span>
<span className="v" id="v12" data-v="12" data-xref="サムエル記上 25:6; ルカによる福音書 10:5–6; 使徒行伝 10:36"> その家にはいったなら、平安を祈ってあげなさい。</span>
<span className="v" id="v13" data-v="13" data-xref="ルカによる福音書 10:6; 詩篇 35:13; コリント人への第二の手紙 2:16"> もし平安を受けるにふさわしい家であれば、あなたがたの祈る平安はその家に来るであろう。もしふさわしくなければ、その平安はあなたがたに帰って来るであろう。</span>
<span className="v" id="v14" data-v="14" data-xref="ルカによる福音書 10:10–11; 使徒行伝 18:6; ネヘミヤ書 5:13"> もしあなたがたを迎えもせず、またあなたがたの言葉を聞きもしない人があれば、その家や町を立ち去る時に、足のちりを払い落しなさい。</span>
<span className="v" id="v15" data-v="15" data-xref="ペテロの第二の手紙 2:6; ヨハネの第一の手紙 4:17; ヨハネによる福音書 15:22–24"> あなたがたによく言っておく。さばきの日には、ソドム、ゴモラの地の方が、その町よりは耐えやすいであろう。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="ルカによる福音書 10:3; ピリピ人への手紙 2:15; コリント人への第一の手紙 14:20"> わたしがあなたがたをつかわすのは、羊をおおかみの中に送るようなものである。だから、へびのように賢く、はとのように素直であれ。</span>
<span className="v" id="v17" data-v="17" data-xref="マルコによる福音書 13:9; マタイによる福音書 23:34; 使徒行伝 26:11"> 人々に注意しなさい。彼らはあなたがたを衆議所に引き渡し、会堂でむち打つであろう。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行伝 5:25–27; マタイによる福音書 8:4; 詩篇 2:1–6"> またあなたがたは、わたしのために長官たちや王たちの前に引き出されるであろう。それは、彼らと異邦人とに対してあかしをするためである。</span>
<span className="v" id="v19" data-v="19" data-xref="出エジプト記 4:12; マルコによる福音書 13:11–13; テモテヘの第二の手紙 4:17"> 彼らがあなたがたを引き渡したとき、何をどう言おうかと心配しないがよい。言うべきことは、その時に授けられるからである。</span>
<span className="v" id="v20" data-v="20" data-xref="ルカによる福音書 21:15; 使徒行伝 6:10; ルカによる福音書 12:12"> 語る者は、あなたがたではなく、あなたがたの中にあって語る父の霊である。</span>
<span className="v" id="v21" data-v="21" data-xref="ルカによる福音書 21:16–17; ミカ書 7:5–6; マルコによる福音書 13:12–13"> 兄弟は兄弟を、父は子を殺すために渡し、また子は親に逆らって立ち、彼らを殺させるであろう。</span>
<span className="v" id="v22" data-v="22" data-xref="マタイによる福音書 24:13; ヤコブの手紙 1:12; ヨハネの黙示録 2:10"> またあなたがたは、わたしの名のゆえにすべての人に憎まれるであろう。しかし、最後まで耐え忍ぶ者は救われる。</span>
<span className="v" id="v23" data-v="23" data-xref="マタイによる福音書 16:28; 使徒行伝 8:1; マルコによる福音書 13:26"> 一つの町で迫害されたなら、他の町へ逃げなさい。よく言っておく。あなたがたがイスラエルの町々を回り終らないうちに、人の子は来るであろう。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="ヨハネによる福音書 15:20; ルカによる福音書 6:40; ヨハネによる福音書 13:16"> 弟子はその師以上のものではなく、僕はその主人以上の者ではない。</span>
<span className="v" id="v25" data-v="25" data-xref="ルカによる福音書 11:15; マタイによる福音書 12:24; マタイによる福音書 9:34"> 弟子がその師のようであり、僕がその主人のようであれば、それで十分である。もし家の主人がベルゼブルと言われるならば、その家の者どもはなおさら、どんなにか悪く言われることであろう。</span>
<span className="v" id="v26" data-v="26" data-xref="ルカによる福音書 8:17; マルコによる福音書 4:22; エレミヤ書 1:8"> だから彼らを恐れるな。おおわれたもので、現れてこないものはなく、隠れているもので、知られてこないものはない。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行伝 5:20; ヨハネによる福音書 16:13; ヨハネによる福音書 16:1"> わたしが暗やみであなたがたに話すことを、明るみで言え。耳にささやかれたことを、屋根の上で言いひろめよ。</span>
<span className="v" id="v28" data-v="28" data-xref="ルカによる福音書 12:4–5; イザヤ書 8:12–13; ヨハネの黙示録 2:10"> また、からだを殺しても、魂を殺すことのできない者どもを恐れるな。むしろ、からだも魂も地獄で滅ぼす力のあるかたを恐れなさい。</span>
<span className="v" id="v29" data-v="29" data-xref="ルカによる福音書 12:6–7; 詩篇 104:27–30"> 二羽のすずめは一アサリオンで売られているではないか。しかもあなたがたの父の許しがなければ、その一羽も地に落ちることはない。</span>
<span className="v" id="v30" data-v="30" data-xref="ルカによる福音書 12:7; サムエル記上 14:45; 使徒行伝 27:34"> またあなたがたの頭の毛までも、みな数えられている。</span>
<span className="v" id="v31" data-v="31" data-xref="ルカによる福音書 12:24; 詩篇 8:5; マタイによる福音書 6:26"> それだから、恐れることはない。あなたがたは多くのすずめよりも、まさった者である。</span>
<span className="v" id="v32" data-v="32" data-xref="ヨハネの黙示録 3:5; ローマ人への手紙 10:9–10; ルカによる福音書 12:8–9"> だから人の前でわたしを受けいれる者を、わたしもまた、天にいますわたしの父の前で受けいれるであろう。</span>
<span className="v" id="v33" data-v="33" data-xref="テモテヘの第二の手紙 2:12; ルカによる福音書 9:26; ルカによる福音書 12:9"> しかし、人の前でわたしを拒む者を、わたしも天にいますわたしの父の前で拒むであろう。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="ルカによる福音書 12:49–53; 使徒行伝 14:4; 使徒行伝 13:45–50"> 地上に平和をもたらすために、わたしがきたと思うな。平和ではなく、つるぎを投げ込むためにきたのである。</span>
<span className="v" id="v35" data-v="35" data-xref="ミカ書 7:5–6; マタイによる福音書 10:21; ルカによる福音書 21:16"> わたしがきたのは、人をその父と、娘をその母と、嫁をそのしゅうとめと仲たがいさせるためである。</span>
<span className="v" id="v36" data-v="36" data-xref="ミカ書 7:6; エレミヤ書 12:6; 詩篇 41:9"> そして家の者が、その人の敵となるであろう。</span>
<span className="v" id="v37" data-v="37" data-xref="ルカによる福音書 14:26; マタイによる福音書 22:37; ピリピ人への手紙 3:7–9"> わたしよりも父または母を愛する者は、わたしにふさわしくない。わたしよりもむすこや娘を愛する者は、わたしにふさわしくない。</span>
<span className="v" id="v38" data-v="38" data-xref="ルカによる福音書 14:27; マルコによる福音書 8:34; マタイによる福音書 16:24"> また自分の十字架をとってわたしに従ってこない者はわたしにふさわしくない。</span>
<span className="v" id="v39" data-v="39" data-xref="ヨハネによる福音書 12:25; マルコによる福音書 8:35–36; ルカによる福音書 17:33"> 自分の命を得ている者はそれを失い、わたしのために自分の命を失っている者は、それを得るであろう。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="ヨハネによる福音書 13:20; ルカによる福音書 9:48; ルカによる福音書 10:16"> あなたがたを受けいれる者は、わたしを受けいれるのである。わたしを受けいれる者は、わたしをおつかわしになったかたを受けいれるのである。</span>
<span className="v" id="v41" data-v="41" data-xref="ヨハネの第三の手紙 1:5–8; ヘブル人への手紙 6:10; 列王紀下 4:16–17"> 預言者の名のゆえに預言者を受けいれる者は、預言者の報いを受け、義人の名のゆえに義人を受けいれる者は、義人の報いを受けるであろう。</span>
<span className="v" id="v42" data-v="42" data-xref="ヘブル人への手紙 6:10; マタイによる福音書 25:40; マルコによる福音書 9:41–42"> わたしの弟子であるという名のゆえに、この小さい者のひとりに冷たい水一杯でも飲ませてくれる者は、よく言っておくが、決してその報いからもれることはない」。</span>
</div>

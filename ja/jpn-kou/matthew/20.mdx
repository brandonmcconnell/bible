<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マタイによる福音書 13:47; マタイによる福音書 13:24; 雅歌 8:11–12"> 天国は、ある家の主人が、自分のぶどう園に労働者を雇うために、夜が明けると同時に、出かけて行くようなものである。</span>
<span className="v" id="v2" data-v="2" data-xref="サムエル記上 2:26; 伝道の書 12:1; マタイによる福音書 22:19"> 彼は労働者たちと、一日一デナリの約束をして、彼らをぶどう園に送った。</span>
<span className="v" id="v3" data-v="3" data-xref="テモテヘの第一の手紙 5:13; 使徒行伝 2:15; マタイによる福音書 20:6–7"> それから九時ごろに出て行って、他の人々が市場で何もせずに立っているのを見た。</span>
<span className="v" id="v4" data-v="4" data-xref="コリント人への第一の手紙 6:11; ペテロの第一の手紙 4:2–3; ルカによる福音書 19:7–10"> そして、その人たちに言った、『あなたがたも、ぶどう園に行きなさい。相当な賃銀を払うから』。</span>
<span className="v" id="v5" data-v="5" data-xref="ヘブル人への手紙 11:24–26; 使徒行伝 10:3; マルコによる福音書 15:33–34"> そこで、彼らは出かけて行った。主人はまた、十二時ごろと三時ごろとに出て行って、同じようにした。</span>
<span className="v" id="v6" data-v="6" data-xref="ヘブル人への手紙 6:12; ヨハネによる福音書 9:4; 使徒行伝 17:21"> 五時ごろまた出て行くと、まだ立っている人々を見たので、彼らに言った、『なぜ、何もしないで、一日中ここに立っていたのか』。</span>
<span className="v" id="v7" data-v="7" data-xref="エペソ人への手紙 2:11–12; ヘブル人への手紙 6:10; ヨハネによる福音書 9:4"> 彼らが『だれもわたしたちを雇ってくれませんから』と答えたので、その人々に言った、『あなたがたも、ぶどう園に行きなさい』。</span>
<span className="v" id="v8" data-v="8" data-xref="申命記 24:15; ペテロの第一の手紙 4:10; ローマ人への手紙 2:6–10"> さて、夕方になって、ぶどう園の主人は管理人に言った、『労働者たちを呼びなさい。そして、最後にきた人々からはじめて順々に最初にきた人々にわたるように、賃銀を払ってやりなさい』。</span>
<span className="v" id="v9" data-v="9" data-xref="マタイによる福音書 20:6–7; ルカによる福音書 23:40–43; マタイによる福音書 20:2"> そこで、五時ごろに雇われた人々がきて、それぞれ一デナリずつもらった。</span>
<span className="v" id="v10" data-v="10"> ところが、最初の人々がきて、もっと多くもらえるだろうと思っていたのに、彼らも一デナリずつもらっただけであった。</span>
<span className="v" id="v11" data-v="11" data-xref="テサロニケ人への第一の手紙 2:16; ルカによる福音書 19:7; 使徒行伝 22:21–22"> もらったとき、家の主人にむかって不平をもらして</span>
<span className="v" id="v12" data-v="12" data-xref="ローマ人への手紙 11:5–6; コリント人への第二の手紙 11:23–28; ルカによる福音書 12:55"> 言った、『この最後の者たちは一時間しか働かなかったのに、あなたは一日じゅう、労苦と暑さを辛抱したわたしたちと同じ扱いをなさいました』。</span>
<span className="v" id="v13" data-v="13" data-xref="マタイによる福音書 26:50; マタイによる福音書 22:12; ローマ人への手紙 9:14–15"> そこで彼はそのひとりに答えて言った、『友よ、わたしはあなたに対して不正をしてはいない。あなたはわたしと一デナリの約束をしたではないか。</span>
<span className="v" id="v14" data-v="14" data-xref="ヨハネによる福音書 17:2; ルカによる福音書 15:31; マタイによる福音書 6:6"> 自分の賃銀をもらって行きなさい。わたしは、この最後の者にもあなたと同様に払ってやりたいのだ。</span>
<span className="v" id="v15" data-v="15" data-xref="ローマ人への手紙 9:15–24; 申命記 15:9; ヨナ書 4:1–4"> 自分の物を自分がしたいようにするのは、当りまえではないか。それともわたしが気前よくしているので、ねたましく思うのか』。</span>
<span className="v" id="v16" data-v="16" data-xref="マタイによる福音書 19:30; マルコによる福音書 10:31; マタイによる福音書 22:14"> このように、あとの者は先になり、先の者はあとになるであろう」。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="マルコによる福音書 10:32–34; ルカによる福音書 18:31–34; マタイによる福音書 16:13"> さて、イエスはエルサレムへ上るとき、十二弟子をひそかに呼びよせ、その途中で彼らに言われた、</span>
<span className="v" id="v18" data-v="18" data-xref="マタイによる福音書 16:21; 使徒行伝 2:23; マタイによる福音書 27:1"> 「見よ、わたしたちはエルサレムへ上って行くが、人の子は祭司長、律法学者たちの手に渡されるであろう。彼らは彼に死刑を宣告し、</span>
<span className="v" id="v19" data-v="19" data-xref="マタイによる福音書 16:21; マルコによる福音書 15:16–20; マタイによる福音書 27:27–31"> そして彼をあざけり、むち打ち、十字架につけさせるために、異邦人に引きわたすであろう。そして彼は三日目によみがえるであろう」。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="マタイによる福音書 4:21; マルコによる福音書 10:35–45; マタイによる福音書 8:2"> そのとき、ゼベダイの子らの母が、その子らと一緒にイエスのもとにきてひざまずき、何事かをお願いした。</span>
<span className="v" id="v21" data-v="21" data-xref="マタイによる福音書 19:28; マルコによる福音書 10:36–37; エステル記 5:3"> そこでイエスは彼女に言われた、「何をしてほしいのか」。彼女は言った、「わたしのこのふたりのむすこが、あなたの御国で、ひとりはあなたの右に、ひとりは左にすわれるように、お言葉をください」。</span>
<span className="v" id="v22" data-v="22" data-xref="マタイによる福音書 26:42; ルカによる福音書 22:42; マタイによる福音書 26:39"> イエスは答えて言われた、「あなたがたは、自分が何を求めているのか、わかっていない。わたしの飲もうとしている杯を飲むことができるか」。彼らは「できます」と答えた。</span>
<span className="v" id="v23" data-v="23" data-xref="ヨハネの黙示録 1:9; マタイによる福音書 25:34; 使徒行伝 12:2"> イエスは彼らに言われた、「確かに、あなたがたはわたしの杯を飲むことになろう。しかし、わたしの右、左にすわらせることは、わたしのすることではなく、わたしの父によって備えられている人々だけに許されることである」。</span>
<span className="v" id="v24" data-v="24" data-xref="ペテロの第一の手紙 5:5; ピリピ人への手紙 2:3; マルコによる福音書 10:41"> 十人の者はこれを聞いて、このふたりの兄弟たちのことで憤慨した。</span>
<span className="v" id="v25" data-v="25" data-xref="ルカによる福音書 22:25–27; マタイによる福音書 20:25–28; ヨハネによる福音書 13:12–17"> そこで、イエスは彼らを呼び寄せて言われた、「あなたがたの知っているとおり、異邦人の支配者たちはその民を治め、また偉い人たちは、その民の上に権力をふるっている。</span>
<span className="v" id="v26" data-v="26" data-xref="マルコによる福音書 10:43; マルコによる福音書 9:35; マルコによる福音書 10:45"> あなたがたの間ではそうであってはならない。かえって、あなたがたの間で偉くなりたいと思う者は、仕える人となり、</span>
<span className="v" id="v27" data-v="27" data-xref="ルカによる福音書 22:26; マルコによる福音書 9:33–35; マタイによる福音書 18:4"> あなたがたの間でかしらになりたいと思う者は、僕とならねばならない。</span>
<span className="v" id="v28" data-v="28" data-xref="ルカによる福音書 22:27; ヘブル人への手紙 9:28; テトスヘの手紙 2:14"> それは、人の子がきたのも、仕えられるためではなく、仕えるためであり、また多くの人のあがないとして、自分の命を与えるためであるのと、ちょうど同じである」。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="マルコによる福音書 10:46–52; ルカによる福音書 18:35–43; マタイによる福音書 9:27–31"> それから、彼らがエリコを出て行ったとき、大ぜいの群衆がイエスに従ってきた。</span>
<span className="v" id="v30" data-v="30" data-xref="マルコによる福音書 10:46; イザヤ書 42:16; マタイによる福音書 21:9"> すると、ふたりの盲人が道ばたにすわっていたが、イエスがとおって行かれると聞いて、叫んで言った、「主よ、ダビデの子よ、わたしたちをあわれんで下さい」。</span>
<span className="v" id="v31" data-v="31" data-xref="マタイによる福音書 19:13; コロサイ人への手紙 4:2; マタイによる福音書 7:7–8"> 群衆は彼らをしかって黙らせようとしたが、彼らはますます叫びつづけて言った、「主よ、ダビデの子よ、わたしたちをあわれんで下さい」。</span>
<span className="v" id="v32" data-v="32" data-xref="エゼキエル書 36:37; ピリピ人への手紙 4:6; マタイによる福音書 20:21"> イエスは立ちどまり、彼らを呼んで言われた、「わたしに何をしてほしいのか」。</span>
<span className="v" id="v33" data-v="33" data-xref="詩篇 119:18; エペソ人への手紙 1:17–19"> 彼らは言った、「主よ、目をあけていただくことです」。</span>
<span className="v" id="v34" data-v="34" data-xref="ヘブル人への手紙 4:15–16; マタイによる福音書 9:29; 使徒行伝 26:18"> イエスは深くあわれんで、彼らの目にさわられた。すると彼らは、たちまち見えるようになり、イエスに従って行った。</span>
</div>

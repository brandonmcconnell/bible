<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マタイによる福音書 23:5; ヨハネによる福音書 12:43; ヘブル人への手紙 6:10"> 自分の義を、見られるために人の前で行わないように、注意しなさい。もし、そうしないと、天にいますあなたがたの父から報いを受けることがないであろう。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="マタイによる福音書 6:5; マタイによる福音書 6:16; コリント人への第二の手紙 9:6–15"> だから、施しをする時には、偽善者たちが人にほめられるため会堂や町の中でするように、自分の前でラッパを吹きならすな。よく言っておくが、彼らはその報いを受けてしまっている。</span>
<span className="v" id="v3" data-v="3" data-xref="ヨハネによる福音書 7:4; マタイによる福音書 9:30; マルコによる福音書 1:44"> あなたは施しをする場合、右の手のしていることを左の手に知らせるな。</span>
<span className="v" id="v4" data-v="4" data-xref="マタイによる福音書 6:18; マタイによる福音書 6:6; エレミヤ書 17:10"> それは、あなたのする施しが隠れているためである。すると、隠れた事を見ておられるあなたの父は、報いてくださるであろう。</span>
</div>
<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="ルカによる福音書 18:10–11; マタイによる福音書 6:2; ルカによる福音書 18:13"> また祈る時には、偽善者たちのようにするな。彼らは人に見せようとして、会堂や大通りのつじに立って祈ることを好む。よく言っておくが、彼らはその報いを受けてしまっている。</span>
<span className="v" id="v6" data-v="6" data-xref="列王紀下 4:33; マタイによる福音書 14:23; イザヤ書 65:24"> あなたは祈る時、自分のへやにはいり、戸を閉じて、隠れた所においでになるあなたの父に祈りなさい。すると、隠れた事を見ておられるあなたの父は、報いてくださるであろう。</span>
<span className="v" id="v7" data-v="7" data-xref="伝道の書 5:2–3; 伝道の書 5:7; 列王紀上 18:26–29"> また、祈る場合、異邦人のように、くどくどと祈るな。彼らは言葉かずが多ければ、聞きいれられるものと思っている。</span>
<span className="v" id="v8" data-v="8" data-xref="マタイによる福音書 6:32; ルカによる福音書 12:30; ピリピ人への手紙 4:6"> だから、彼らのまねをするな。あなたがたの父なる神は、求めない先から、あなたがたに必要なものはご存じなのである。</span>
<span className="v" id="v9" data-v="9" data-xref="ルカによる福音書 11:1–4; ヨハネの黙示録 4:11; ローマ人への手紙 8:15"> だから、あなたがたはこう祈りなさい、<br /><span className="pl pl-1">天にいますわれらの父よ、</span><br /><span className="pl pl-1">御名があがめられますように。</span></span>
<span className="v" id="v10" data-v="10" data-xref="ヘブル人への手紙 10:36; マタイによる福音書 26:42; マタイによる福音書 12:50"> <span className="pl pl-1">御国がきますように。</span><br /><span className="pl pl-1">みこころが天に行われるとおり、</span><br /><span className="pl pl-1">地にも行われますように。</span></span>
<span className="v" id="v11" data-v="11" data-xref="箴言 30:8; ルカによる福音書 11:3; マタイによる福音書 4:4"> <span className="pl pl-1">わたしたちの日ごとの食物を、</span><br /><span className="pl pl-1">きょうもお与えください。</span></span>
<span className="v" id="v12" data-v="12" data-xref="エペソ人への手紙 4:32; マルコによる福音書 11:25; エペソ人への手紙 1:7"> <span className="pl pl-1">わたしたちに負債のある者をゆるしましたように、</span><br /><span className="pl pl-1">わたしたちの負債をもおゆるしください。</span></span>
<span className="v" id="v13" data-v="13" data-xref="コリント人への第一の手紙 10:13; ヨハネの黙示録 7:14–17; マタイによる福音書 26:41"> <span className="pl pl-1">わたしたちを試みに会わせないで、</span><br /><span className="pl pl-1">悪しき者からお救いください。</span></span>
<span className="v" id="v14" data-v="14" data-xref="エペソ人への手紙 4:32; マルコによる福音書 11:25; コロサイ人への手紙 3:13"> <span className="pl pl-1">もしも、あなたがたが、人々のあやまちをゆるすならば、あなたがたの天の父も、あなたがたをゆるして下さるであろう。</span></span>
<span className="v" id="v15" data-v="15" data-xref="マタイによる福音書 18:35"> <span className="pl pl-1">もし人をゆるさないならば、あなたがたの父も、あなたがたのあやまちをゆるして下さらないであろう。</span></span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="イザヤ書 58:3–5; マタイによる福音書 9:14–15; ダニエル書 9:3"> また断食をする時には、偽善者がするように、陰気な顔つきをするな。彼らは断食をしていることを人に見せようとして、自分の顔を見苦しくするのである。よく言っておくが、彼らはその報いを受けてしまっている。</span>
<span className="v" id="v17" data-v="17" data-xref="ルツ記 3:3; 伝道の書 9:8; サムエル記下 12:20"> あなたがたは断食をする時には、自分の頭に油を塗り、顔を洗いなさい。</span>
<span className="v" id="v18" data-v="18" data-xref="マタイによる福音書 6:6; マタイによる福音書 6:4; コリント人への第二の手紙 10:18"> それは断食をしていることが人に知れないで、隠れた所においでになるあなたの父に知られるためである。すると、隠れた事を見ておられるあなたの父は、報いて下さるであろう。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="ヘブル人への手紙 13:5; ヨハネの第一の手紙 2:15–16; ルカによる福音書 12:21"> あなたがたは自分のために、虫が食い、さびがつき、また、盗人らが押し入って盗み出すような地上に、宝をたくわえてはならない。</span>
<span className="v" id="v20" data-v="20" data-xref="ルカによる福音書 12:33; マタイによる福音書 19:21; ヤコブの手紙 2:5"> むしろ自分のため、虫も食わず、さびもつかず、また、盗人らが押し入って盗み出すこともない天に、宝をたくわえなさい。</span>
<span className="v" id="v21" data-v="21" data-xref="コロサイ人への手紙 3:1–3; ルカによる福音書 12:34; コリント人への第二の手紙 4:18"> あなたの宝のある所には、心もあるからである。</span>
<span className="v" id="v22" data-v="22" data-xref="ルカによる福音書 11:34–36; コリント人への第二の手紙 11:3; コロサイ人への手紙 3:22"> 目はからだのあかりである。だから、あなたの目が澄んでおれば、全身も明るいだろう。</span>
<span className="v" id="v23" data-v="23" data-xref="ヨハネの第一の手紙 2:11; マタイによる福音書 6:22; イザヤ書 5:20–21"> しかし、あなたの目が悪ければ、全身も暗いだろう。だから、もしあなたの内なる光が暗ければ、その暗さは、どんなであろう。</span>
<span className="v" id="v24" data-v="24" data-xref="ヨハネの第一の手紙 2:15–16; ルカによる福音書 16:13; ヤコブの手紙 4:4"> だれも、ふたりの主人に兼ね仕えることはできない。一方を憎んで他方を愛し、あるいは、一方に親しんで他方をうとんじるからである。あなたがたは、神と富とに兼ね仕えることはできない。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="ピリピ人への手紙 4:6; ペテロの第一の手紙 5:7; ローマ人への手紙 8:32"> それだから、あなたがたに言っておく。何を食べようか、何を飲もうかと、自分の命のことで思いわずらい、何を着ようかと自分のからだのことで思いわずらうな。命は食物にまさり、からだは着物にまさるではないか。</span>
<span className="v" id="v26" data-v="26" data-xref="マタイによる福音書 10:29–31; 詩篇 147:9; ルカによる福音書 12:24–32"> 空の鳥を見るがよい。まくことも、刈ることもせず、倉に取りいれることもしない。それだのに、あなたがたの天の父は彼らを養っていて下さる。あなたがたは彼らよりも、はるかにすぐれた者ではないか。</span>
<span className="v" id="v27" data-v="27" data-xref="ルカによる福音書 12:25–26; 伝道の書 3:14; 詩篇 39:5–6"> あなたがたのうち、だれが思いわずらったからとて、自分の寿命をわずかでも延ばすことができようか。</span>
<span className="v" id="v28" data-v="28" data-xref="マタイによる福音書 6:25; ピリピ人への手紙 4:6; ルカによる福音書 12:27"> また、なぜ、着物のことで思いわずらうのか。野の花がどうして育っているか、考えて見るがよい。働きもせず、紡ぎもしない。</span>
<span className="v" id="v29" data-v="29" data-xref="歴代志下 9:20–22; 歴代志下 9:4–6; ペテロの第一の手紙 3:2–5"> しかし、あなたがたに言うが、栄華をきわめた時のソロモンでさえ、この花の一つほどにも着飾ってはいなかった。</span>
<span className="v" id="v30" data-v="30" data-xref="マタイによる福音書 14:31; ルカによる福音書 12:28; ペテロの第一の手紙 1:24"> きょうは生えていて、あすは炉に投げ入れられる野の草でさえ、神はこのように装って下さるのなら、あなたがたに、それ以上よくしてくださらないはずがあろうか。ああ、信仰の薄い者たちよ。</span>
<span className="v" id="v31" data-v="31" data-xref="ペテロの第一の手紙 5:7; ルカによる福音書 12:29; マタイによる福音書 4:4"> だから、何を食べようか、何を飲もうか、あるいは何を着ようかと言って思いわずらうな。</span>
<span className="v" id="v32" data-v="32" data-xref="マタイによる福音書 6:8; ルカによる福音書 12:30; エペソ人への手紙 4:17"> これらのものはみな、異邦人が切に求めているものである。あなたがたの天の父は、これらのものが、ことごとくあなたがたに必要であることをご存じである。</span>
<span className="v" id="v33" data-v="33" data-xref="ルカによる福音書 12:31; マタイによる福音書 5:6; ヨハネによる福音書 6:27"> まず神の国と神の義とを求めなさい。そうすれば、これらのものは、すべて添えて与えられるであろう。</span>
<span className="v" id="v34" data-v="34" data-xref="マタイによる福音書 6:25; ヨハネによる福音書 14:27; ヘブル人への手紙 13:5–6"> だから、あすのことを思いわずらうな。あすのことは、あす自身が思いわずらうであろう。一日の苦労は、その日一日だけで十分である。</span>
</div>

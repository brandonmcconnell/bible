<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="ヘブル人への手紙 2:18; ルカによる福音書 4:1–13; マルコによる福音書 1:12–15"> さて、イエスは御霊によって荒野に導かれた。悪魔に試みられるためである。</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 9:18; 出エジプト記 34:28; 列王紀上 19:8"> そして、四十日四十夜、断食をし、そののち空腹になられた。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 3:1–5; テサロニケ人への第一の手紙 3:5; 民数記 11:4–6"> すると試みる者がきて言った、「もしあなたが神の子であるなら、これらの石がパンになるように命じてごらんなさい」。</span>
<span className="v" id="v4" data-v="4" data-xref="申命記 8:3; ルカによる福音書 4:4; ヨハネによる福音書 6:63"> イエスは答えて言われた、「『人はパンだけで生きるものではなく、神の口から出る一つ一つの言で生きるものである』と書いてある」。</span>
<span className="v" id="v5" data-v="5" data-xref="ルカによる福音書 4:9; マタイによる福音書 27:53; ヨハネの黙示録 11:2"> それから悪魔は、イエスを聖なる都に連れて行き、宮の頂上に立たせて</span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 91:11–12; ヘブル人への手紙 1:14; 詩篇 34:7"> 言った、「もしあなたが神の子であるなら、下へ飛びおりてごらんなさい。<br /><span className="pl pl-1">『神はあなたのために御使たちにお命じになると、</span><br /><span className="pl pl-1">あなたの足が石に打ちつけられないように、</span><br /><span className="pl pl-1">彼らはあなたを手でささえるであろう』</span><br />と書いてありますから」。</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 6:16; コリント人への第一の手紙 10:9; 詩篇 78:18"> イエスは彼に言われた、「『主なるあなたの神を試みてはならない』とまた書いてある」。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨハネの第一の手紙 2:15–16; ヨハネの黙示録 11:15; 詩篇 49:16–17"> 次に悪魔は、イエスを非常に高い山に連れて行き、この世のすべての国々とその栄華とを見せて</span>
<span className="v" id="v9" data-v="9" data-xref="コリント人への第二の手紙 4:4; ダニエル書 5:18–19; ヨハネによる福音書 16:11"> 言った、「もしあなたが、ひれ伏してわたしを拝むなら、これらのものを皆あなたにあげましょう」。</span>
<span className="v" id="v10" data-v="10" data-xref="申命記 6:13–14; 申命記 10:20; ヨシュア記 24:14"> するとイエスは彼に言われた、「サタンよ、退け。『主なるあなたの神を拝し、ただ神にのみ仕えよ』と書いてある」。</span>
<span className="v" id="v11" data-v="11" data-xref="マタイによる福音書 26:53; ヘブル人への手紙 1:14; ルカによる福音書 22:43"> そこで、悪魔はイエスを離れ去り、そして、御使たちがみもとにきて仕えた。</span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="マルコによる福音書 1:14; ルカによる福音書 3:20; マタイによる福音書 14:3"> さて、イエスはヨハネが捕えられたと聞いて、ガリラヤへ退かれた。</span>
<span className="v" id="v13" data-v="13" data-xref="ヨハネによる福音書 4:46; マルコによる福音書 1:21; マタイによる福音書 11:23"> そしてナザレを去り、ゼブルンとナフタリとの地方にある海べの町カペナウムに行って住まわれた。</span>
<span className="v" id="v14" data-v="14" data-xref="イザヤ書 9:1–2; マタイによる福音書 2:23; ルカによる福音書 24:44"> これは預言者イザヤによって言われた言が、成就するためである。</span>
<span className="v" id="v15" data-v="15" data-xref="イザヤ書 9:1; 列王紀下 15:29; ヨシュア記 21:32"> <span className="pl pl-1">「ゼブルンの地、ナフタリの地、</span><br /><span className="pl pl-1">海に沿う地方、ヨルダンの向こうの地、</span><br /><span className="pl pl-1">異邦人のガリラヤ、</span></span>
<span className="v" id="v16" data-v="16" data-xref="イザヤ書 9:2; イザヤ書 42:6–7; イザヤ書 60:1–3"> <span className="pl pl-1">暗黒の中に住んでいる民は大いなる光を見、</span><br /><span className="pl pl-1">死の地、死の陰に住んでいる人々に、光がのぼった」。</span></span>
<span className="v" id="v17" data-v="17" data-xref="マタイによる福音書 3:2; 使徒行伝 2:38; マルコによる福音書 1:14–15"> <span className="pl pl-1">この時からイエスは教を宣べはじめて言われた、「悔い改めよ、天国は近づいた」。</span></span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="ヨハネによる福音書 1:40–42; マタイによる福音書 10:2; ルカによる福音書 6:14"> さて、イエスがガリラヤの海べを歩いておられると、ふたりの兄弟、すなわち、ペテロと呼ばれたシモンとその兄弟アンデレとが、海に網を打っているのをごらんになった。彼らは漁師であった。</span>
<span className="v" id="v19" data-v="19" data-xref="マルコによる福音書 1:17–18; ヨハネによる福音書 12:26; マタイによる福音書 16:24"> イエスは彼らに言われた、「わたしについてきなさい。あなたがたを、人間をとる漁師にしてあげよう」。</span>
<span className="v" id="v20" data-v="20" data-xref="マルコによる福音書 10:28–31; マタイによる福音書 19:27; ルカによる福音書 18:28–30"> すると、彼らはすぐに網を捨てて、イエスに従った。</span>
<span className="v" id="v21" data-v="21" data-xref="マルコによる福音書 1:19–20; マタイによる福音書 10:2; マルコによる福音書 3:17"> そこから進んで行かれると、ほかのふたりの兄弟、すなわち、ゼベダイの子ヤコブとその兄弟ヨハネとが、父ゼベダイと一緒に、舟の中で網を繕っているのをごらんになった。そこで彼らをお招きになると、</span>
<span className="v" id="v22" data-v="22" data-xref="マタイによる福音書 10:37; ルカによる福音書 9:59–60; 申命記 33:9–10"> すぐ舟と父とをおいて、イエスに従って行った。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="マタイによる福音書 9:35; マルコによる福音書 1:39; 使徒行伝 10:38"> イエスはガリラヤの全地を巡り歩いて、諸会堂で教え、御国の福音を宣べ伝え、民の中のあらゆる病気、あらゆるわずらいをおいやしになった。</span>
<span className="v" id="v24" data-v="24" data-xref="マタイによる福音書 8:6; マタイによる福音書 17:15; ルカによる福音書 5:15"> そこで、その評判はシリヤ全地にひろまり、人々があらゆる病にかかっている者、すなわち、いろいろの病気と苦しみとに悩んでいる者、悪霊につかれている者、てんかん、中風の者などをイエスのところに連れてきたので、これらの人々をおいやしになった。</span>
<span className="v" id="v25" data-v="25" data-xref="ルカによる福音書 6:17; マルコによる福音書 5:20; マルコによる福音書 3:7–8"> こうして、ガリラヤ、デカポリス、エルサレム、ユダヤ及びヨルダンの向こうから、おびただしい群衆がきてイエスに従った。</span>
</div>

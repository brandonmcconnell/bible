<div className="bible-chapter" lang="ja" dir="ltr" data-lang="ja" data-translation="jpn-kou" data-translation-id="jpn_kou" data-translation-label="口語訳" data-book="MAT" data-book-slug="matthew" data-book-name="マタイによる福音書" data-chapter="9" data-verses="38">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マタイによる福音書 4:13; ルカによる福音書 8:37; マタイによる福音書 8:18"> さて、イエスは舟に乗って海を渡り、自分の町に帰られた。</span>
<span className="v" id="v2" data-v="2" data-xref="マルコによる福音書 2:1–12; ルカによる福音書 5:18–26; エレミヤ書 31:33–34"> すると、人々が中風の者を床の上に寝かせたままでみもとに運んできた。イエスは彼らの信仰を見て、中風の者に、「子よ、しっかりしなさい。あなたの罪はゆるされたのだ」と言われた。</span>
<span className="v" id="v3" data-v="3" data-xref="マタイによる福音書 26:65; ルカによる福音書 5:21; レビ記 24:16"> すると、ある律法学者たちが心の中で言った、「この人は神を汚している」。</span>
<span className="v" id="v4" data-v="4" data-xref="ルカによる福音書 6:8; マタイによる福音書 12:25; ヨハネの黙示録 2:23"> イエスは彼らの考えを見抜いて、「なぜ、あなたがたは心の中で悪いことを考えているのか。</span>
<span className="v" id="v5" data-v="5" data-xref="ヨハネによる福音書 5:8–14; マルコによる福音書 2:9–12; 使徒行伝 3:16"> あなたの罪はゆるされた、と言うのと、起きて歩け、と言うのと、どちらがたやすいか。</span>
<span className="v" id="v6" data-v="6" data-xref="イザヤ書 43:25; マタイによる福音書 9:5; ヨハネによる福音書 20:21–23"> しかし、人の子は地上で罪をゆるす権威をもっていることが、あなたがたにわかるために」と言い、中風の者にむかって、「起きよ、床を取りあげて家に帰れ」と言われた。</span>
<span className="v" id="v7" data-v="7"> すると彼は起きあがり、家に帰って行った。</span>
<span className="v" id="v8" data-v="8" data-xref="ルカによる福音書 7:16; マタイによる福音書 15:31; 使徒行伝 4:21"> 群衆はそれを見て恐れ、こんな大きな権威を人にお与えになった神をあがめた。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="ルカによる福音書 5:27–38; マルコによる福音書 2:14–22; ルカによる福音書 19:2–10"> さてイエスはそこから進んで行かれ、マタイという人が収税所にすわっているのを見て、「わたしに従ってきなさい」と言われた。すると彼は立ちあがって、イエスに従った。</span>
<span className="v" id="v10" data-v="10" data-xref="テモテヘの第一の手紙 1:13–16; ルカによる福音書 5:29–32; マルコによる福音書 2:15–17"> それから、イエスが家で食事の席についておられた時のことである。多くの取税人や罪人たちがきて、イエスや弟子たちと共にその席に着いていた。</span>
<span className="v" id="v11" data-v="11" data-xref="マタイによる福音書 11:19; ルカによる福音書 5:30; マルコによる福音書 2:16"> パリサイ人たちはこれを見て、弟子たちに言った、「なぜ、あなたがたの先生は、取税人や罪人などと食事を共にするのか」。</span>
<span className="v" id="v12" data-v="12" data-xref="ルカによる福音書 5:31; ヨハネの黙示録 3:17–18; マルコによる福音書 2:17"> イエスはこれを聞いて言われた、「丈夫な人には医者はいらない。いるのは病人である。</span>
<span className="v" id="v13" data-v="13" data-xref="マルコによる福音書 2:17; ルカによる福音書 19:10; ホセア書 6:6"> 『わたしが好むのは、あわれみであって、いけにえではない』とはどういう意味か、学んできなさい。わたしがきたのは、義人を招くためではなく、罪人を招くためである」。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="ルカによる福音書 5:33–39; マルコによる福音書 2:18–22; マタイによる福音書 6:16"> そのとき、ヨハネの弟子たちがイエスのところにきて言った、「わたしたちとパリサイ人たちとが断食をしているのに、あなたの弟子たちは、なぜ断食をしないのですか」。</span>
<span className="v" id="v15" data-v="15" data-xref="ヨハネの黙示録 19:9; ヨハネによる福音書 3:29; ヨハネの黙示録 21:2"> するとイエスは言われた、「婚礼の客は、花婿が一緒にいる間は、悲しんでおられようか。しかし、花婿が奪い去られる日が来る。その時には断食をするであろう。</span>
<span className="v" id="v16" data-v="16" data-xref="コリント人への第一の手紙 3:1–2; ヨハネによる福音書 16:12; 詩篇 125:3"> だれも、真新しい布ぎれで、古い着物につぎを当てはしない。そのつぎきれは着物を引き破り、そして、破れがもっとひどくなるから。</span>
<span className="v" id="v17" data-v="17" data-xref="ヨシュア記 9:4; ヨブ記 32:19; 詩篇 119:83"> だれも、新しいぶどう酒を古い皮袋に入れはしない。もしそんなことをしたら、その皮袋は張り裂け、酒は流れ出るし、皮袋もむだになる。だから、新しいぶどう酒は新しい皮袋に入れるべきである。そうすれば両方とも長もちがするであろう」。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="ルカによる福音書 8:41–56; マルコによる福音書 5:22–43; マタイによる福音書 8:2"> これらのことを彼らに話しておられると、そこにひとりの会堂司がきて、イエスを拝して言った、「わたしの娘がただ今死にました。しかしおいでになって手をその上においてやって下さい。そうしたら、娘は生き返るでしょう」。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行伝 10:38; ガラテヤ人への手紙 6:9–10; マタイによる福音書 8:7"> そこで、イエスが立って彼について行かれると、弟子たちも一緒に行った。</span>
<span className="v" id="v20" data-v="20" data-xref="ルカによる福音書 8:43–56; マタイによる福音書 14:36; マルコによる福音書 6:56"> するとそのとき、十二年間も長血をわずらっている女が近寄ってきて、イエスのうしろからみ衣のふさにさわった。</span>
<span className="v" id="v21" data-v="21" data-xref="マルコによる福音書 5:26–33; ルカによる福音書 8:45–47; 使徒行伝 19:12"> み衣にさわりさえすれば、なおしていただけるだろう、と心の中で思っていたからである。</span>
<span className="v" id="v22" data-v="22" data-xref="ルカによる福音書 7:50; マタイによる福音書 15:28; マタイによる福音書 9:2"> イエスは振り向いて、この女を見て言われた、「娘よ、しっかりしなさい。あなたの信仰があなたを救ったのです」。するとこの女はその時に、いやされた。</span>
<span className="v" id="v23" data-v="23" data-xref="歴代志下 35:25; マルコによる福音書 5:35–40; ルカによる福音書 8:49–51"> それからイエスは司の家に着き、笛吹きどもや騒いでいる群衆を見て言われた。</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行伝 20:10; ヨハネによる福音書 11:11–13; マタイによる福音書 27:39–43"> 「あちらへ行っていなさい。少女は死んだのではない。眠っているだけである」。すると人々はイエスをあざ笑った。</span>
<span className="v" id="v25" data-v="25" data-xref="マルコによる福音書 9:27; マルコによる福音書 5:41; ルカによる福音書 8:54"> しかし、群衆を外へ出したのち、イエスは内へはいって、少女の手をお取りになると、少女は起きあがった。</span>
<span className="v" id="v26" data-v="26" data-xref="マタイによる福音書 4:24; マタイによる福音書 14:1–2; マルコによる福音書 1:45"> そして、そのうわさがこの地方全体にひろまった。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="マタイによる福音書 15:22; マタイによる福音書 20:30–31; マルコによる福音書 10:46–48"> そこから進んで行かれると、ふたりの盲人が、「ダビデの子よ、わたしたちをあわれんで下さい」と叫びながら、イエスについてきた。</span>
<span className="v" id="v28" data-v="28" data-xref="マルコによる福音書 9:23–24; マタイによる福音書 13:58; マタイによる福音書 8:2"> そしてイエスが家にはいられると、盲人たちがみもとにきたので、彼らに「わたしにそれができると信じるか」と言われた。彼らは言った、「主よ、信じます」。</span>
<span className="v" id="v29" data-v="29" data-xref="マタイによる福音書 15:28; マルコによる福音書 10:52; マタイによる福音書 8:13"> そこで、イエスは彼らの目にさわって言われた、「あなたがたの信仰どおり、あなたがたの身になるように」。</span>
<span className="v" id="v30" data-v="30" data-xref="マタイによる福音書 8:4; ルカによる福音書 5:14; マタイによる福音書 17:9"> すると彼らの目が開かれた。イエスは彼らをきびしく戒めて言われた、「だれにも知れないように気をつけなさい」。</span>
<span className="v" id="v31" data-v="31" data-xref="マルコによる福音書 7:36; マタイによる福音書 9:26; マルコによる福音書 1:44–45"> しかし、彼らは出て行って、その地方全体にイエスのことを言いひろめた。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="マタイによる福音書 4:24; マタイによる福音書 12:22–24; ルカによる福音書 11:14"> 彼らが出て行くと、人々は悪霊につかれたおしをイエスのところに連れてきた。</span>
<span className="v" id="v33" data-v="33" data-xref="イザヤ書 35:6; マルコによる福音書 7:32–37; 出エジプト記 4:11–12"> すると、悪霊は追い出されて、おしが物を言うようになった。群衆は驚いて、「このようなことがイスラエルの中で見られたことは、これまで一度もなかった」と言った。</span>
<span className="v" id="v34" data-v="34" data-xref="ルカによる福音書 11:15; マルコによる福音書 3:22; マタイによる福音書 12:23–24"> しかし、パリサイ人たちは言った、「彼は、悪霊どものかしらによって悪霊どもを追い出しているのだ」。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="マタイによる福音書 4:23–24; 使徒行伝 10:38; マルコによる福音書 6:56"> イエスは、すべての町々村々を巡り歩いて、諸会堂で教え、御国の福音を宣べ伝え、あらゆる病気、あらゆるわずらいをおいやしになった。</span>
<span className="v" id="v36" data-v="36" data-xref="マルコによる福音書 6:34; 民数記 27:17; エレミヤ書 50:6"> また群衆が飼う者のない羊のように弱り果てて、倒れているのをごらんになって、彼らを深くあわれまれた。</span>
<span className="v" id="v37" data-v="37" data-xref="ルカによる福音書 10:2; マルコによる福音書 16:15; コリント人への第一の手紙 3:9"> そして弟子たちに言われた、「収穫は多いが、働き人が少ない。</span>
<span className="v" id="v38" data-v="38" data-xref="ルカによる福音書 10:1–2; エレミヤ書 3:15; テサロニケ人への第二の手紙 3:1"> だから、収穫の主に願って、その収穫のために働き人を送り出すようにしてもらいなさい」。</span>
</div>

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="マルコによる福音書 3:13; マタイによる福音書 15:29; マルコによる福音書 4:1"> イエスはこの群衆を見て、山に登り、座につかれると、弟子たちがみもとに近寄ってきた。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行伝 8:35; ルカによる福音書 6:20–26; 使徒行伝 10:34"> そこで、イエスは口を開き、彼らに教えて言われた。</span>
<span className="v" id="v3" data-v="3" data-xref="イザヤ書 66:2; 箴言 29:23; 詩篇 34:18"> <span className="pl pl-1">「こころの貧しい人たちは、さいわいである、</span><br /><span className="pl pl-1">天国は彼らのものである。</span></span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネの黙示録 21:4; コリント人への第二の手紙 7:9–10; ヨハネによる福音書 16:20–22"> <span className="pl pl-1">悲しんでいる人たちは、さいわいである、</span><br /><span className="pl pl-1">彼らは慰められるであろう。</span></span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 37:11; イザヤ書 29:19; ヤコブの手紙 3:13"> <span className="pl pl-1">柔和な人たちは、さいわいである、</span><br /><span className="pl pl-1">彼らは地を受けつぐであろう。</span></span>
<span className="v" id="v6" data-v="6" data-xref="ヨハネによる福音書 4:14; 詩篇 107:9; ヨハネによる福音書 6:27"> <span className="pl pl-1">義に飢えかわいている人たちは、さいわいである、</span><br /><span className="pl pl-1">彼らは飽き足りるようになるであろう。</span></span>
<span className="v" id="v7" data-v="7" data-xref="エペソ人への手紙 4:32–1; マタイによる福音書 6:14–15; サムエル記下 22:26"> <span className="pl pl-1">あわれみ深い人たちは、さいわいである、</span><br /><span className="pl pl-1">彼らはあわれみを受けるであろう。</span></span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 24:4; 詩篇 51:10; ヘブル人への手紙 10:22"> <span className="pl pl-1">心の清い人たちは、さいわいである、</span><br /><span className="pl pl-1">彼らは神を見るであろう。</span></span>
<span className="v" id="v9" data-v="9" data-xref="ヘブル人への手紙 12:14; ヤコブの手紙 3:16–18; ローマ人への手紙 12:18"> <span className="pl pl-1">平和をつくり出す人たちは、さいわいである、</span><br /><span className="pl pl-1">彼らは神の子と呼ばれるであろう。</span></span>
<span className="v" id="v10" data-v="10" data-xref="ヤコブの手紙 1:12; ペテロの第一の手紙 3:13–14; コリント人への第二の手紙 4:17"> <span className="pl pl-1">義のために迫害されてきた人たちは、</span><br /><span className="pl pl-1">さいわいである、</span><br /><span className="pl pl-1">天国は彼らのものである。</span></span>
<span className="v" id="v11" data-v="11" data-xref="ペテロの第一の手紙 4:14; ルカによる福音書 21:17; マルコによる福音書 13:13"> <span className="pl pl-1">わたしのために人々があなたがたをののしり、また迫害し、あなたがたに対し偽って様々の悪口を言う時には、あなたがたは、さいわいである。</span></span>
<span className="v" id="v12" data-v="12" data-xref="ルカによる福音書 6:23; ヤコブの手紙 1:2; コロサイ人への手紙 3:24"> <span className="pl pl-1">喜び、よろこべ、天においてあなたがたの受ける報いは大きい。あなたがたより前の預言者たちも、同じように迫害されたのである。</span></span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="コロサイ人への手紙 4:6; ルカによる福音書 14:34–35; マルコによる福音書 9:49–50"> あなたがたは、地の塩である。もし塩のききめがなくなったら、何によってその味が取りもどされようか。もはや、なんの役にも立たず、ただ外に捨てられて、人々にふみつけられるだけである。</span>
<span className="v" id="v14" data-v="14" data-xref="ピリピ人への手紙 2:15; ヨハネによる福音書 8:12; エペソ人への手紙 5:8–14"> あなたがたは、世の光である。山の上にある町は隠れることができない。</span>
<span className="v" id="v15" data-v="15" data-xref="ルカによる福音書 11:33; マルコによる福音書 4:21; ルカによる福音書 8:16"> また、あかりをつけて、それを枡の下におく者はいない。むしろ燭台の上において、家の中のすべてのものを照させるのである。</span>
<span className="v" id="v16" data-v="16" data-xref="ペテロの第一の手紙 2:12; テトスヘの手紙 2:7; ヨハネによる福音書 15:8"> そのように、あなたがたの光を人々の前に輝かし、そして、人々があなたがたのよいおこないを見て、天にいますあなたがたの父をあがめるようにしなさい。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="ローマ人への手紙 10:4; ルカによる福音書 16:17; ガラテヤ人への手紙 4:4–5"> わたしが律法や預言者を廃するためにきた、と思ってはならない。廃するためではなく、成就するためにきたのである。</span>
<span className="v" id="v18" data-v="18" data-xref="ルカによる福音書 16:17; イザヤ書 40:8; ペテロの第一の手紙 1:25"> よく言っておく。天地が滅び行くまでは、律法の一点、一画もすたることはなく、ことごとく全うされるのである。</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 12:32; ヤコブの手紙 2:10–11; マタイによる福音書 28:20"> それだから、これらの最も小さいいましめの一つでも破り、またそうするように人に教えたりする者は、天国で最も小さい者と呼ばれるであろう。しかし、これをおこないまたそう教える者は、天国で大いなる者と呼ばれるであろう。</span>
<span className="v" id="v20" data-v="20" data-xref="ローマ人への手紙 10:2–3; ピリピ人への手紙 3:9; ローマ人への手紙 9:30–32"> わたしは言っておく。あなたがたの義が律法学者やパリサイ人の義にまさっていなければ、決して天国に、はいることはできない。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="申命記 5:17; 出エジプト記 20:13; 民数記 35:30–34"> 昔の人々に『殺すな。殺す者は裁判を受けねばならない』と言われていたことは、あなたがたの聞いているところである。</span>
<span className="v" id="v22" data-v="22" data-xref="ヨハネの第一の手紙 3:14–15; ヨハネの第一の手紙 4:20–21; ヨハネの第一の手紙 2:9"> しかし、わたしはあなたがたに言う。兄弟に対して怒る者は、だれでも裁判を受けねばならない。兄弟にむかって愚か者と言う者は、議会に引きわたされるであろう。また、ばか者と言う者は、地獄の火に投げ込まれるであろう。</span>
<span className="v" id="v23" data-v="23" data-xref="マルコによる福音書 11:25; レビ記 6:2–6; マタイによる福音書 5:24"> だから、祭壇に供え物をささげようとする場合、兄弟が自分に対して何かうらみをいだいていることを、そこで思い出したなら、</span>
<span className="v" id="v24" data-v="24" data-xref="ヤコブの手紙 5:16; ローマ人への手紙 12:17–18; マタイによる福音書 18:15–17"> その供え物を祭壇の前に残しておき、まず行ってその兄弟と和解し、それから帰ってきて、供え物をささげることにしなさい。</span>
<span className="v" id="v25" data-v="25" data-xref="ルカによる福音書 12:58–59; 箴言 25:8; ヘブル人への手紙 3:13"> あなたを訴える者と一緒に道を行く時には、その途中で早く仲直りをしなさい。そうしないと、その訴える者はあなたを裁判官にわたし、裁判官は下役にわたし、そして、あなたは獄に入れられるであろう。</span>
<span className="v" id="v26" data-v="26" data-xref="マタイによる福音書 18:34; ルカによる福音書 12:59; テサロニケ人への第二の手紙 1:9"> よくあなたに言っておく。最後の一コドラントを支払ってしまうまでは、決してそこから出てくることはできない。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="申命記 5:18; 箴言 6:32; 出エジプト記 20:14"> 『姦淫するな』と言われていたことは、あなたがたの聞いているところである。</span>
<span className="v" id="v28" data-v="28" data-xref="ヨハネの第一の手紙 2:16; ヤコブの手紙 1:14–15; 箴言 6:25"> しかし、わたしはあなたがたに言う。だれでも、情欲をいだいて女を見る者は、心の中ですでに姦淫をしたのである。</span>
<span className="v" id="v29" data-v="29" data-xref="ローマ人への手紙 8:13; マルコによる福音書 9:43–48; コロサイ人への手紙 3:5"> もしあなたの右の目が罪を犯させるなら、それを抜き出して捨てなさい。五体の一部を失っても、全身が地獄に投げ入れられない方が、あなたにとって益である。</span>
<span className="v" id="v30" data-v="30" data-xref="マルコによる福音書 9:43; マタイによる福音書 5:29; ペテロの第一の手紙 2:8"> もしあなたの右の手が罪を犯させるなら、それを切って捨てなさい。五体の一部を失っても、全身が地獄に落ち込まない方が、あなたにとって益である。</span>
<span className="v" id="v31" data-v="31" data-xref="エレミヤ書 3:1; 申命記 24:1–4; マタイによる福音書 19:7"> また『妻を出す者は離縁状を渡せ』と言われている。</span>
<span className="v" id="v32" data-v="32" data-xref="ローマ人への手紙 7:3; コリント人への第一の手紙 7:10–11; ルカによる福音書 16:18"> しかし、わたしはあなたがたに言う。だれでも、不品行以外の理由で自分の妻を出す者は、姦淫を行わせるのである。また出された女をめとる者も、姦淫を行うのである。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="申命記 23:21; レビ記 19:12; 伝道の書 5:4–6"> また昔の人々に『いつわり誓うな、誓ったことは、すべて主に対して果せ』と言われていたことは、あなたがたの聞いているところである。</span>
<span className="v" id="v34" data-v="34" data-xref="ヤコブの手紙 5:12; イザヤ書 66:1; 申命記 23:21–23"> しかし、わたしはあなたがたに言う。いっさい誓ってはならない。天をさして誓うな。そこは神の御座であるから。</span>
<span className="v" id="v35" data-v="35" data-xref="詩篇 48:2; マラキ書 1:14; 歴代志下 6:6"> また地をさして誓うな。そこは神の足台であるから。またエルサレムをさして誓うな。それは『大王の都』であるから。</span>
<span className="v" id="v36" data-v="36" data-xref="ルカによる福音書 12:25; マタイによる福音書 6:27; マタイによる福音書 23:16–21"> また、自分の頭をさして誓うな。あなたは髪の毛一すじさえ、白くも黒くもすることができない。</span>
<span className="v" id="v37" data-v="37" data-xref="ヤコブの手紙 5:12; コロサイ人への手紙 4:6; コロサイ人への手紙 3:9"> あなたがたの言葉は、ただ、しかり、しかり、否、否、であるべきだ。それ以上に出ることは、悪から来るのである。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="レビ記 24:19–20; 申命記 19:21; 出エジプト記 21:22–27"> 『目には目を、歯には歯を』と言われていたことは、あなたがたの聞いているところである。</span>
<span className="v" id="v39" data-v="39" data-xref="テサロニケ人への第一の手紙 5:15; ペテロの第一の手紙 3:9; ローマ人への手紙 12:17–19"> しかし、わたしはあなたがたに言う。悪人に手向かうな。もし、だれかがあなたの右の頬を打つなら、ほかの頬をも向けてやりなさい。</span>
<span className="v" id="v40" data-v="40" data-xref="ルカによる福音書 6:29; コリント人への第一の手紙 6:7"> あなたを訴えて、下着を取ろうとする者には、上着をも与えなさい。</span>
<span className="v" id="v41" data-v="41" data-xref="ルカによる福音書 23:26; マタイによる福音書 27:32; マルコによる福音書 15:21"> もし、だれかが、あなたをしいて一マイル行かせようとするなら、その人と共に二マイル行きなさい。</span>
<span className="v" id="v42" data-v="42" data-xref="箴言 19:17; ヘブル人への手紙 13:16; ルカによる福音書 6:30–36"> 求める者には与え、借りようとする者を断るな。</span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="レビ記 19:18; 詩篇 139:21–22; ガラテヤ人への手紙 5:13–14"> 『隣り人を愛し、敵を憎め』と言われていたことは、あなたがたの聞いているところである。</span>
<span className="v" id="v44" data-v="44" data-xref="ローマ人への手紙 12:14; ペテロの第一の手紙 3:9; ルカによる福音書 6:27–28"> しかし、わたしはあなたがたに言う。敵を愛し、迫害する者のために祈れ。</span>
<span className="v" id="v45" data-v="45" data-xref="詩篇 145:9; ルカによる福音書 6:35; 使徒行伝 14:17"> こうして、天にいますあなたがたの父の子となるためである。天の父は、悪い者の上にも良い者の上にも、太陽をのぼらせ、正しい者にも正しくない者にも、雨を降らして下さるからである。</span>
<span className="v" id="v46" data-v="46" data-xref="ルカによる福音書 6:32–35; ペテロの第一の手紙 2:20–23; マタイによる福音書 9:10–11"> あなたがたが自分を愛する者を愛したからとて、なんの報いがあろうか。そのようなことは取税人でもするではないか。</span>
<span className="v" id="v47" data-v="47" data-xref="マタイによる福音書 5:20; ルカによる福音書 6:32; ペテロの第一の手紙 2:20"> 兄弟だけにあいさつをしたからとて、なんのすぐれた事をしているだろうか。そのようなことは異邦人でもしているではないか。</span>
<span className="v" id="v48" data-v="48" data-xref="ペテロの第一の手紙 1:15–16; ヤコブの手紙 1:4; レビ記 19:2"> それだから、あなたがたの天の父が完全であられるように、あなたがたも完全な者となりなさい。</span>
</div>

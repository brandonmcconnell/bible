<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マタイによる福音書 7:28; マタイによる福音書 19:1"> イエスはこれらの言葉をすべて語り終えてから、弟子たちに言われた。</span>
<span className="v" id="v2" data-v="2" data-xref="ルカによる福音書 22:1–2; マルコによる福音書 14:1–2; ヨハネによる福音書 13:1–2"> 「あなたがたが知っているとおり、ふつかの後には過越の祭になるが、人の子は十字架につけられるために引き渡される」。</span>
<span className="v" id="v3" data-v="3" data-xref="ヨハネによる福音書 11:47–53; ヨハネによる福音書 18:24; マルコによる福音書 14:54"> そのとき、祭司長たちや民の長老たちが、カヤパという大祭司の中庭に集まり、</span>
<span className="v" id="v4" data-v="4" data-xref="マタイによる福音書 12:14; 詩篇 2:2; 使徒行伝 13:10"> 策略をもってイエスを捕えて殺そうと相談した。</span>
<span className="v" id="v5" data-v="5" data-xref="マタイによる福音書 27:24; マタイによる福音書 21:26; マタイによる福音書 14:5"> しかし彼らは言った、「祭の間はいけない。民衆の中に騒ぎが起るかも知れない」。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="マルコによる福音書 14:3–9; ルカによる福音書 7:37–39; ヨハネによる福音書 12:1–8"> さて、イエスがベタニヤで、らい病人シモンの家におられたとき、</span>
<span className="v" id="v7" data-v="7" data-xref="ヨハネによる福音書 12:2–3; ルカによる福音書 7:46; ルカによる福音書 7:37–38"> ひとりの女が、高価な香油が入れてある石膏のつぼを持ってきて、イエスに近寄り、食事の席についておられたイエスの頭に香油を注ぎかけた。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨハネによる福音書 12:4–6; マルコによる福音書 14:4; 出エジプト記 5:17"> すると、弟子たちはこれを見て憤って言った、「なんのためにこんなむだ使をするのか。</span>
<span className="v" id="v9" data-v="9" data-xref="ヨハネによる福音書 12:5–6; マルコによる福音書 14:5; ヨシュア記 7:20–21"> それを高く売って、貧しい人たちに施すことができたのに」。</span>
<span className="v" id="v10" data-v="10" data-xref="テトスヘの手紙 3:8; ヘブル人への手紙 13:21; テモテヘの第一の手紙 5:10"> イエスはそれを聞いて彼らに言われた、「なぜ、女を困らせるのか。わたしによい事をしてくれたのだ。</span>
<span className="v" id="v11" data-v="11" data-xref="申命記 15:11; マルコによる福音書 14:7; ヨハネによる福音書 12:8"> 貧しい人たちはいつもあなたがたと一緒にいるが、わたしはいつも一緒にいるわけではない。</span>
<span className="v" id="v12" data-v="12" data-xref="マルコによる福音書 14:8; ヨハネによる福音書 12:7; マルコによる福音書 16:1"> この女がわたしのからだにこの香油を注いだのは、わたしの葬りの用意をするためである。</span>
<span className="v" id="v13" data-v="13" data-xref="マルコによる福音書 14:9; マタイによる福音書 24:14; 詩篇 112:6"> よく聞きなさい。全世界のどこででも、この福音が宣べ伝えられる所では、この女のした事も記念として語られるであろう」。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="ルカによる福音書 22:3–6; マタイによる福音書 10:4; マルコによる福音書 14:10–11"> 時に、十二弟子のひとりイスカリオテのユダという者が、祭司長たちのところに行って</span>
<span className="v" id="v15" data-v="15" data-xref="ゼカリヤ書 11:12–13; 創世記 37:26–28; 出エジプト記 21:32"> 言った、「彼をあなたがたに引き渡せば、いくらくださいますか」。すると、彼らは銀貨三十枚を彼に支払った。</span>
<span className="v" id="v16" data-v="16" data-xref="マルコによる福音書 14:11; ルカによる福音書 22:6"> その時から、ユダはイエスを引きわたそうと、機会をねらっていた。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="ルカによる福音書 22:7–13; マルコによる福音書 14:12–16; 出エジプト記 12:18–20"> さて、除酵祭の第一日に、弟子たちはイエスのもとにきて言った、「過越の食事をなさるために、わたしたちはどこに用意をしたらよいでしょうか」。</span>
<span className="v" id="v18" data-v="18" data-xref="マルコによる福音書 14:13–16; ヨハネによる福音書 7:6; ヨハネによる福音書 17:1"> イエスは言われた、「市内にはいり、かねて話してある人の所に行って言いなさい、『先生が、わたしの時が近づいた、あなたの家で弟子たちと一緒に過越を守ろうと、言っておられます』」。</span>
<span className="v" id="v19" data-v="19" data-xref="ヨハネによる福音書 2:5; ヨハネによる福音書 15:14; マタイによる福音書 21:6"> 弟子たちはイエスが命じられたとおりにして、過越の用意をした。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="マルコによる福音書 14:17–21; ヨハネによる福音書 13:21; ルカによる福音書 22:14–16"> 夕方になって、イエスは十二弟子と一緒に食事の席につかれた。</span>
<span className="v" id="v21" data-v="21" data-xref="ヨハネによる福音書 13:21; ヘブル人への手紙 4:13; ヨハネによる福音書 6:70–71"> そして、一同が食事をしているとき言われた、「特にあなたがたに言っておくが、あなたがたのうちのひとりが、わたしを裏切ろうとしている」。</span>
<span className="v" id="v22" data-v="22" data-xref="ヨハネによる福音書 13:22–25; ルカによる福音書 22:23; マルコによる福音書 14:19–20"> 弟子たちは非常に心配して、つぎつぎに「主よ、まさか、わたしではないでしょう」と言い出した。</span>
<span className="v" id="v23" data-v="23" data-xref="ヨハネによる福音書 13:18; 詩篇 41:9; ヨハネによる福音書 13:26–28"> イエスは答えて言われた、「わたしと一緒に同じ鉢に手を入れている者が、わたしを裏切ろうとしている。</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行伝 26:22–23; ルカによる福音書 24:46; マタイによる福音書 18:7"> たしかに人の子は、自分について書いてあるとおりに去って行く。しかし、人の子を裏切るその人は、わざわいである。その人は生れなかった方が、彼のためによかったであろう」。</span>
<span className="v" id="v25" data-v="25" data-xref="マタイによる福音書 26:64; マタイによる福音書 27:11; ルカによる福音書 22:70"> イエスを裏切ったユダが答えて言った、「先生、まさか、わたしではないでしょう」。イエスは言われた、「いや、あなただ」。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="コリント人への第一の手紙 11:23–29; ルカによる福音書 22:18–20; コリント人への第一の手紙 10:16–17"> 一同が食事をしているとき、イエスはパンを取り、祝福してこれをさき、弟子たちに与えて言われた、「取って食べよ、これはわたしのからだである」。</span>
<span className="v" id="v27" data-v="27" data-xref="イザヤ書 25:6; コリント人への第一の手紙 10:16; 詩篇 116:13"> また杯を取り、感謝して彼らに与えて言われた、「みな、この杯から飲め。</span>
<span className="v" id="v28" data-v="28" data-xref="ヘブル人への手紙 10:4–14; ヘブル人への手紙 9:14–22; レビ記 17:11"> これは、罪のゆるしを得させるようにと、多くの人のために流すわたしの契約の血である。</span>
<span className="v" id="v29" data-v="29" data-xref="ヘブル人への手紙 12:2; ヨハネの黙示録 7:17; マルコによる福音書 14:25"> あなたがたに言っておく。わたしの父の国であなたがたと共に、新しく飲むその日までは、わたしは今後決して、ぶどうの実から造ったものを飲むことをしない」。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="マタイによる福音書 21:1; エペソ人への手紙 5:19–20; ルカによる福音書 22:39"> 彼らは、さんびを歌った後、オリブ山へ出かけて行った。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="ゼカリヤ書 13:7; マルコによる福音書 14:27–28; ヨハネによる福音書 16:32"> そのとき、イエスは弟子たちに言われた、「今夜、あなたがたは皆わたしにつまずくであろう。『わたしは羊飼を打つ。そして、羊の群れは散らされるであろう』と、書いてあるからである。</span>
<span className="v" id="v32" data-v="32" data-xref="マタイによる福音書 28:10; ルカによる福音書 18:33–34; マタイによる福音書 28:16"> しかしわたしは、よみがえってから、あなたがたより先にガリラヤへ行くであろう」。</span>
<span className="v" id="v33" data-v="33" data-xref="ルカによる福音書 22:33; ヨハネによる福音書 13:36–38; 箴言 28:25–26"> するとペテロはイエスに答えて言った、「たとい、みんなの者があなたにつまずいても、わたしは決してつまずきません」。</span>
<span className="v" id="v34" data-v="34" data-xref="ヨハネによる福音書 13:38; ルカによる福音書 22:34; マタイによる福音書 26:75"> イエスは言われた、「よくあなたに言っておく。今夜、鶏が鳴く前に、あなたは三度わたしを知らないと言うだろう」。</span>
<span className="v" id="v35" data-v="35" data-xref="ローマ人への手紙 11:20; ヨハネによる福音書 13:37; 箴言 29:23"> ペテロは言った、「たといあなたと一緒に死なねばならなくなっても、あなたを知らないなどとは、決して申しません」。弟子たちもみな同じように言った。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="マルコによる福音書 14:32–42; マタイによる福音書 26:42; ルカによる福音書 22:39–46"> それから、イエスは彼らと一緒に、ゲツセマネという所へ行かれた。そして弟子たちに言われた、「わたしが向こうへ行って祈っている間、ここにすわっていなさい」。</span>
<span className="v" id="v37" data-v="37" data-xref="マタイによる福音書 4:21; マタイによる福音書 17:1; マルコによる福音書 5:37"> そしてペテロとゼベダイの子ふたりとを連れて行かれたが、悲しみを催しまた悩みはじめられた。</span>
<span className="v" id="v38" data-v="38" data-xref="ヨハネによる福音書 12:27; ペテロの第一の手紙 3:18; ペテロの第一の手紙 2:24"> そのとき、彼らに言われた、「わたしは悲しみのあまり死ぬほどである。ここに待っていて、わたしと一緒に目をさましていなさい」。</span>
<span className="v" id="v39" data-v="39" data-xref="ヨハネによる福音書 6:38; ピリピ人への手紙 2:8; ルカによる福音書 22:41–42"> そして少し進んで行き、うつぶしになり、祈って言われた、「わが父よ、もしできることでしたらどうか、この杯をわたしから過ぎ去らせてください。しかし、わたしの思いのままにではなく、みこころのままになさって下さい」。</span>
<span className="v" id="v40" data-v="40" data-xref="マルコによる福音書 14:37; ルカによる福音書 22:45; マタイによる福音書 26:43"> それから、弟子たちの所にきてごらんになると、彼らが眠っていたので、ペテロに言われた、「あなたがたはそんなに、ひと時もわたしと一緒に目をさましていることが、できなかったのか。</span>
<span className="v" id="v41" data-v="41" data-xref="マルコによる福音書 14:38; ルカによる福音書 22:46; エペソ人への手紙 6:18"> 誘惑に陥らないように、目をさまして祈っていなさい。心は熱しているが、肉体が弱いのである」。</span>
<span className="v" id="v42" data-v="42" data-xref="マタイによる福音書 26:39; マルコによる福音書 14:39–40; ヘブル人への手紙 4:15"> また二度目に行って、祈って言われた、「わが父よ、この杯を飲むほかに道がないのでしたら、どうか、みこころが行われますように」。</span>
<span className="v" id="v43" data-v="43" data-xref="ルカによる福音書 9:32; ローマ人への手紙 13:1; 箴言 23:34"> またきてごらんになると、彼らはまた眠っていた。その目が重くなっていたのである。</span>
<span className="v" id="v44" data-v="44" data-xref="コリント人への第二の手紙 12:8; ルカによる福音書 18:1; マタイによる福音書 6:7"> それで彼らをそのままにして、また行って、三度目に同じ言葉で祈られた。</span>
<span className="v" id="v45" data-v="45" data-xref="ヨハネによる福音書 13:1; ヨハネによる福音書 12:27; マルコによる福音書 14:41–42"> それから弟子たちの所に帰ってきて、言われた、「まだ眠っているのか、休んでいるのか。見よ、時が迫った。人の子は罪人らの手に渡されるのだ。</span>
<span className="v" id="v46" data-v="46" data-xref="ルカによる福音書 9:51; ヨハネによる福音書 14:31; サムエル記上 17:48"> 立て、さあ行こう。見よ、わたしを裏切る者が近づいてきた」。</span>
</div>
<div className="bp">
<span className="v" id="v47" data-v="47" data-xref="使徒行伝 1:16; マタイによる福音書 26:55; マルコによる福音書 14:43–50"> そして、イエスがまだ話しておられるうちに、そこに、十二弟子のひとりのユダがきた。また祭司長、民の長老たちから送られた大ぜいの群衆も、剣と棒とを持って彼についてきた。</span>
<span className="v" id="v48" data-v="48" data-xref="詩篇 55:20–21; 詩篇 28:3; サムエル記下 3:27"> イエスを裏切った者が、あらかじめ彼らに、「わたしの接吻する者が、その人だ。その人をつかまえろ」と合図をしておいた。</span>
<span className="v" id="v49" data-v="49" data-xref="マタイによる福音書 26:25; テサロニケ人への第一の手紙 5:26; 箴言 27:6"> 彼はすぐイエスに近寄り、「先生、いかがですか」と言って、イエスに接吻した。</span>
<span className="v" id="v50" data-v="50" data-xref="マタイによる福音書 20:13; マタイによる福音書 22:12; 詩篇 41:9"> しかし、イエスは彼に言われた、「友よ、なんのためにきたのか」。このとき、人々が進み寄って、イエスに手をかけてつかまえた。</span>
<span className="v" id="v51" data-v="51" data-xref="ヨハネによる福音書 18:36; マルコによる福音書 14:47; コリント人への第二の手紙 10:4"> すると、イエスと一緒にいた者のひとりが、手を伸ばして剣を抜き、そして大祭司の僕に切りかかって、その片耳を切り落した。</span>
<span className="v" id="v52" data-v="52" data-xref="ヨハネの黙示録 13:10; 創世記 9:6; ローマ人への手紙 12:19"> そこで、イエスは彼に言われた、「あなたの剣をもとの所におさめなさい。剣をとる者はみな、剣で滅びる。</span>
<span className="v" id="v53" data-v="53" data-xref="列王紀下 6:17; マタイによる福音書 4:11; ダニエル書 7:10"> それとも、わたしが父に願って、天の使たちを十二軍団以上も、今つかわしていただくことができないと、あなたは思うのか。</span>
<span className="v" id="v54" data-v="54" data-xref="ゼカリヤ書 13:7; マタイによる福音書 26:24; 使徒行伝 1:16"> しかし、それでは、こうならねばならないと書いてある聖書の言葉は、どうして成就されようか」。</span>
<span className="v" id="v55" data-v="55" data-xref="マルコによる福音書 12:35; ヨハネによる福音書 8:2; ルカによる福音書 22:52–53"> そのとき、イエスは群衆に言われた、「あなたがたは強盗にむかうように、剣や棒を持ってわたしを捕えにきたのか。わたしは毎日、宮ですわって教えていたのに、わたしをつかまえはしなかった。</span>
<span className="v" id="v56" data-v="56" data-xref="ゼカリヤ書 13:7; ヨハネによる福音書 16:32; マルコによる福音書 14:50–52"> しかし、すべてこうなったのは、預言者たちの書いたことが、成就するためである」。そのとき、弟子たちは皆イエスを見捨てて逃げ去った。</span>
</div>
<div className="bp">
<span className="v" id="v57" data-v="57" data-xref="マタイによる福音書 26:3; マルコによる福音書 14:53–65; 詩篇 56:5–6"> さて、イエスをつかまえた人たちは、大祭司カヤパのところにイエスを連れて行った。そこには律法学者、長老たちが集まっていた。</span>
<span className="v" id="v58" data-v="58" data-xref="ヨハネによる福音書 7:32; ヨハネによる福音書 18:15–16; ヨハネによる福音書 18:25"> ペテロは遠くからイエスについて、大祭司の中庭まで行き、そのなりゆきを見とどけるために、中にはいって下役どもと一緒にすわっていた。</span>
<span className="v" id="v59" data-v="59" data-xref="使徒行伝 6:11–13; 申命記 19:16–21; マルコによる福音書 14:55–56"> さて、祭司長たちと全議会とは、イエスを死刑にするため、イエスに不利な偽証を求めようとしていた。</span>
<span className="v" id="v60" data-v="60" data-xref="申命記 19:15; 詩篇 35:11; 詩篇 27:12"> そこで多くの偽証者が出てきたが、証拠があがらなかった。しかし、最後にふたりの者が出てきて</span>
<span className="v" id="v61" data-v="61" data-xref="ヨハネによる福音書 2:19–21; マタイによる福音書 27:40; マルコによる福音書 15:29"> 言った、「この人は、わたしは神の宮を打ちこわし、三日の後に建てることができる、と言いました」。</span>
<span className="v" id="v62" data-v="62" data-xref="ヨハネによる福音書 19:9–11; ヨハネによる福音書 18:19–24; マルコによる福音書 14:60"> すると、大祭司が立ち上がってイエスに言った、「何も答えないのか。これらの人々があなたに対して不利な証言を申し立てているが、どうなのか」。</span>
<span className="v" id="v63" data-v="63" data-xref="レビ記 5:1; マタイによる福音書 16:16; イザヤ書 53:7"> しかし、イエスは黙っておられた。そこで大祭司は言った、「あなたは神の子キリストなのかどうか、生ける神に誓ってわれわれに答えよ」。</span>
<span className="v" id="v64" data-v="64" data-xref="ダニエル書 7:13; マルコによる福音書 14:62; 詩篇 110:1"> イエスは彼に言われた、「あなたの言うとおりである。しかし、わたしは言っておく。あなたがたは、間もなく、人の子が力ある者の右に座し、天の雲に乗って来るのを見るであろう」。</span>
<span className="v" id="v65" data-v="65" data-xref="エレミヤ書 36:24; ヨハネによる福音書 10:33; マタイによる福音書 9:3"> すると、大祭司はその衣を引き裂いて言った、「彼は神を汚した。どうしてこれ以上、証人の必要があろう。あなたがたは今このけがし言を聞いた。</span>
<span className="v" id="v66" data-v="66" data-xref="ヨハネによる福音書 19:7; 使徒行伝 7:52; レビ記 24:11–16"> あなたがたの意見はどうか」。すると、彼らは答えて言った、「彼は死に当るものだ」。</span>
<span className="v" id="v67" data-v="67" data-xref="イザヤ書 50:6; イザヤ書 53:3; マタイによる福音書 27:30"> それから、彼らはイエスの顔につばきをかけて、こぶしで打ち、またある人は手のひらでたたいて言った、</span>
<span className="v" id="v68" data-v="68" data-xref="ルカによる福音書 22:63–65; マルコによる福音書 14:65; ペテロの第一の手紙 2:4–8"> 「キリストよ、言いあててみよ、打ったのはだれか」。</span>

<span className="v" id="v69" data-v="69" data-xref="列王紀上 19:13; マタイによる福音書 26:71; 使徒行伝 5:37"> ペテロは外で中庭にすわっていた。するとひとりの女中が彼のところにきて、「あなたもあのガリラヤ人イエスと一緒だった」と言った。</span>
<span className="v" id="v70" data-v="70" data-xref="コリント人への第一の手紙 10:12; ヨハネの黙示録 21:8; マタイによる福音書 26:40–43"> するとペテロは、みんなの前でそれを打ち消して言った、「あなたが何を言っているのか、わからない」。</span>
<span className="v" id="v71" data-v="71" data-xref="マルコによる福音書 14:68–69; ヨハネによる福音書 18:25–27; ルカによる福音書 22:58"> そう言って入口の方に出て行くと、ほかの女中が彼を見て、そこにいる人々にむかって、「この人はナザレ人イエスと一緒だった」と言った。</span>
<span className="v" id="v72" data-v="72" data-xref="マタイによる福音書 26:74; イザヤ書 48:1; ゼカリヤ書 8:17"> そこで彼は再びそれを打ち消して、「そんな人は知らない」と誓って言った。</span>
<span className="v" id="v73" data-v="73" data-xref="士師記 12:6; ヨハネによる福音書 18:26–27; ネヘミヤ書 13:24"> しばらくして、そこに立っていた人々が近寄ってきて、ペテロに言った、「確かにあなたも彼らの仲間だ。言葉づかいであなたのことがわかる」。</span>
<span className="v" id="v74" data-v="74" data-xref="ヨハネの黙示録 3:19; コリント人への第一の手紙 16:22; マルコによる福音書 14:71–72"> 彼は「その人のことは何も知らない」と言って、激しく誓いはじめた。するとすぐ鶏が鳴いた。</span>
<span className="v" id="v75" data-v="75" data-xref="マタイによる福音書 26:34; ローマ人への手紙 7:18–20; ルカによる福音書 22:31–34"> ペテロは「鶏が鳴く前に、三度わたしを知らないと言うであろう」と言われたイエスの言葉を思い出し、外に出て激しく泣いた。</span>

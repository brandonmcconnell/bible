<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マルコによる福音書 16:1–8; ヨハネによる福音書 20:1–10; マタイによる福音書 27:56"> さて、安息日が終って、週の初めの日の明け方に、マグダラのマリヤとほかのマリヤとが、墓を見にきた。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行伝 16:26; ヨハネによる福音書 20:12–13; マルコによる福音書 16:3–5"> すると、大きな地震が起った。それは主の使が天から下って、そこにきて石をわきへころがし、その上にすわったからである。</span>
<span className="v" id="v3" data-v="3" data-xref="マルコによる福音書 9:3; 使徒行伝 1:10; マルコによる福音書 16:5"> その姿はいなずまのように輝き、その衣は雪のように真白であった。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネの黙示録 1:17; ダニエル書 10:7; マタイによる福音書 27:65–66"> 見張りをしていた人たちは、恐ろしさの余り震えあがって、死人のようになった。</span>
<span className="v" id="v5" data-v="5" data-xref="ヨハネの黙示録 1:17–18; ヘブル人への手紙 1:14; イザヤ書 41:10"> この御使は女たちにむかって言った、「恐れることはない。あなたがたが十字架におかかりになったイエスを捜していることは、わたしにわかっているが、</span>
<span className="v" id="v6" data-v="6" data-xref="マルコによる福音書 16:6; マタイによる福音書 12:40; ルカによる福音書 24:6–8"> もうここにはおられない。かねて言われたとおりに、よみがえられたのである。さあ、イエスが納められていた場所をごらんなさい。</span>
<span className="v" id="v7" data-v="7" data-xref="マタイによる福音書 26:32; ルカによる福音書 24:22–24; マタイによる福音書 28:10"> そして、急いで行って、弟子たちにこう伝えなさい、『イエスは死人の中からよみがえられた。見よ、あなたがたより先にガリラヤへ行かれる。そこでお会いできるであろう』。あなたがたに、これだけ言っておく」。</span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 2:11; マルコによる福音書 16:8; ルカによる福音書 24:36–41"> そこで女たちは恐れながらも大喜びで、急いで墓を立ち去り、弟子たちに知らせるために走って行った。</span>
<span className="v" id="v9" data-v="9" data-xref="マタイによる福音書 28:17; ヨハネによる福音書 20:14–17; マタイによる福音書 14:33"> すると、イエスは彼らに出会って、「平安あれ」と言われたので、彼らは近寄りイエスのみ足をいだいて拝した。</span>
<span className="v" id="v10" data-v="10" data-xref="ローマ人への手紙 8:29; ヨハネによる福音書 20:17; マタイによる福音書 28:7"> そのとき、イエスは彼らに言われた、「恐れることはない。行って兄弟たちに、ガリラヤに行け、そこでわたしに会えるであろう、と告げなさい」。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="マタイによる福音書 27:65–66; マタイによる福音書 28:4"> 女たちが行っている間に、番人のうちのある人々が都に帰って、いっさいの出来事を祭司長たちに話した。</span>
<span className="v" id="v12" data-v="12" data-xref="マタイによる福音書 26:3–4; 使徒行伝 4:5–22; マタイによる福音書 27:1–2"> 祭司長たちは長老たちと集まって協議をこらし、兵卒たちにたくさんの金を与えて言った、</span>
<span className="v" id="v13" data-v="13" data-xref="マタイによる福音書 26:64"> 「『弟子たちが夜中にきて、われわれの寝ている間に彼を盗んだ』と言え。</span>
<span className="v" id="v14" data-v="14" data-xref="マタイによる福音書 27:2; 使徒行伝 12:19"> 万一このことが総督の耳にはいっても、われわれが総督に説いて、あなたがたに迷惑が掛からないようにしよう」。</span>
<span className="v" id="v15" data-v="15" data-xref="テモテヘの第一の手紙 6:10; マタイによる福音書 27:8; マタイによる福音書 26:15"> そこで、彼らは金を受け取って、教えられたとおりにした。そしてこの話は、今日に至るまでユダヤ人の間にひろまっている。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="マタイによる福音書 26:32; マタイによる福音書 28:10; マタイによる福音書 28:7"> さて、十一人の弟子たちはガリラヤに行って、イエスが彼らに行くように命じられた山に登った。</span>
<span className="v" id="v17" data-v="17" data-xref="詩篇 45:11; 詩篇 2:12; ヨハネによる福音書 5:23"> そして、イエスに会って拝した。しかし、疑う者もいた。</span>
<span className="v" id="v18" data-v="18" data-xref="ヨハネによる福音書 3:35; ペテロの第一の手紙 3:22; マタイによる福音書 11:27"> イエスは彼らに近づいてきて言われた、「わたしは、天においても地においても、いっさいの権威を授けられた。</span>
<span className="v" id="v19" data-v="19" data-xref="マルコによる福音書 16:15–16; 使徒行伝 2:38–39; 使徒行伝 1:8"> それゆえに、あなたがたは行って、すべての国民を弟子として、父と子と聖霊との名によって、彼らにバプテスマを施し、</span>
<span className="v" id="v20" data-v="20" data-xref="イザヤ書 41:10; ヨシュア記 1:5; 使徒行伝 18:9–10"> あなたがたに命じておいたいっさいのことを守るように教えよ。見よ、わたしは世の終りまで、いつもあなたがたと共にいるのである」。</span>
</div>

<div className="bible-chapter" lang="ja" dir="ltr" data-lang="ja" data-translation="jpn-kou" data-translation-id="jpn_kou" data-translation-label="口語訳" data-book="MAT" data-book-slug="matthew" data-book-name="マタイによる福音書" data-chapter="8" data-verses="34">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マタイによる福音書 8:18; マタイによる福音書 4:25–1; ルカによる福音書 5:15"> イエスが山をお降りになると、おびただしい群衆がついてきた。</span>
<span className="v" id="v2" data-v="2" data-xref="マタイによる福音書 15:25; ルカによる福音書 17:12–19; マタイによる福音書 18:26"> すると、そのとき、ひとりのらい病人がイエスのところにきて、ひれ伏して言った、「主よ、みこころでしたら、きよめていただけるのですが」。</span>
<span className="v" id="v3" data-v="3" data-xref="ルカによる福音書 5:13; 詩篇 33:9; 列王紀下 5:14"> イエスは手を伸ばして、彼にさわり、「そうしてあげよう、きよくなれ」と言われた。すると、らい病は直ちにきよめられた。</span>
<span className="v" id="v4" data-v="4" data-xref="レビ記 14:2–32; ルカによる福音書 5:14; ルカによる福音書 17:14"> イエスは彼に言われた、「だれにも話さないように、注意しなさい。ただ行って、自分のからだを祭司に見せ、それから、モーセが命じた供え物をささげて、人々に証明しなさい」。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="ルカによる福音書 7:1–10; 使徒行伝 27:43; 使徒行伝 10:1–33"> さて、イエスがカペナウムに帰ってこられたとき、ある百卒長がみもとにきて訴えて言った、</span>
<span className="v" id="v6" data-v="6" data-xref="コロサイ人への手紙 4:1; マタイによる福音書 4:24; 使徒行伝 9:33"> 「主よ、わたしの僕が中風でひどく苦しんで、家に寝ています」。</span>
<span className="v" id="v7" data-v="7" data-xref="マタイによる福音書 9:18–19; ルカによる福音書 7:6; マルコによる福音書 5:23–24"> イエスは彼に、「わたしが行ってなおしてあげよう」と言われた。</span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 107:20; ルカによる福音書 7:6–7; 詩篇 33:9"> そこで百卒長は答えて言った、「主よ、わたしの屋根の下にあなたをお入れする資格は、わたしにはございません。ただ、お言葉を下さい。そうすれば僕はなおります。</span>
<span className="v" id="v9" data-v="9" data-xref="ルカによる福音書 4:35–36; テトスヘの手紙 2:9; コロサイ人への手紙 3:22"> わたしも権威の下にある者ですが、わたしの下にも兵卒がいまして、ひとりの者に『行け』と言えば行き、ほかの者に『こい』と言えばきますし、また、僕に『これをせよ』と言えば、してくれるのです」。</span>
<span className="v" id="v10" data-v="10" data-xref="マタイによる福音書 15:28; ルカによる福音書 7:9; マルコによる福音書 6:6"> イエスはこれを聞いて非常に感心され、ついてきた人々に言われた、「よく聞きなさい。イスラエル人の中にも、これほどの信仰を見たことがない。</span>
<span className="v" id="v11" data-v="11" data-xref="ルカによる福音書 13:28–29; エペソ人への手紙 3:6; ガラテヤ人への手紙 3:28–29"> なお、あなたがたに言うが、多くの人が東から西からきて、天国で、アブラハム、イサク、ヤコブと共に宴会の席につくが、</span>
<span className="v" id="v12" data-v="12" data-xref="マタイによる福音書 25:30; ルカによる福音書 13:28; マタイによる福音書 21:43"> この国の子らは外のやみに追い出され、そこで泣き叫んだり、歯がみをしたりするであろう」。</span>
<span className="v" id="v13" data-v="13" data-xref="マタイによる福音書 9:29–30; マルコによる福音書 9:23; ヨハネによる福音書 4:50"> それからイエスは百卒長に「行け、あなたの信じたとおりになるように」と言われた。すると、ちょうどその時に、僕はいやされた。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="ルカによる福音書 4:38–41; マルコによる福音書 1:29–34; コリント人への第一の手紙 9:5"> それから、イエスはペテロの家にはいって行かれ、そのしゅうとめが熱病で、床についているのをごらんになった。</span>
<span className="v" id="v15" data-v="15" data-xref="列王紀下 13:21; ルカによる福音書 4:38–39; ルカによる福音書 8:54"> そこで、その手にさわられると、熱が引いた。そして女は起きあがってイエスをもてなした。</span>
<span className="v" id="v16" data-v="16" data-xref="出エジプト記 15:26; マタイによる福音書 14:14; マルコによる福音書 1:32–34"> 夕暮になると、人々は悪霊につかれた者を大ぜい、みもとに連れてきたので、イエスはみ言葉をもって霊どもを追い出し、病人をことごとくおいやしになった。</span>
<span className="v" id="v17" data-v="17" data-xref="イザヤ書 53:4; ペテロの第一の手紙 2:24; マタイによる福音書 1:22"> これは、預言者イザヤによって「彼は、わたしたちのわずらいを身に受け、わたしたちの病を負うた」と言われた言葉が成就するためである。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="ルカによる福音書 4:42–43; ルカによる福音書 8:22; マルコによる福音書 4:35"> イエスは、群衆が自分のまわりに群がっているのを見て、向こう岸に行くようにと弟子たちにお命じになった。</span>
<span className="v" id="v19" data-v="19" data-xref="ルカによる福音書 22:33–34; ヨハネによる福音書 13:36–38; ルカによる福音書 14:25–27"> するとひとりの律法学者が近づいてきて言った、「先生、あなたがおいでになる所なら、どこへでも従ってまいります」。</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 84:3; ルカによる福音書 2:7; イザヤ書 53:2–3"> イエスはその人に言われた、「きつねには穴があり、空の鳥には巣がある。しかし、人の子にはまくらする所がない」。</span>
<span className="v" id="v21" data-v="21" data-xref="ルカによる福音書 9:59–62; レビ記 21:11–12; 民数記 6:6–7"> また弟子のひとりが言った、「主よ、まず、父を葬りに行かせて下さい」。</span>
<span className="v" id="v22" data-v="22" data-xref="コロサイ人への手紙 2:13; ルカによる福音書 15:32; エペソ人への手紙 5:14"> イエスは彼に言われた、「わたしに従ってきなさい。そして、その死人を葬ることは、死人に任せておくがよい」。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="ルカによる福音書 8:22–25; マルコによる福音書 4:36–41; マタイによる福音書 9:1"> それから、イエスが舟に乗り込まれると、弟子たちも従った。</span>
<span className="v" id="v24" data-v="24" data-xref="ルカによる福音書 8:23; 詩篇 107:23–27; マルコによる福音書 4:37–38"> すると突然、海上に激しい暴風が起って、舟は波にのまれそうになった。ところが、イエスは眠っておられた。</span>
<span className="v" id="v25" data-v="25" data-xref="ヨナ書 1:6; 歴代志下 14:11; マルコによる福音書 4:38–39"> そこで弟子たちはみそばに寄ってきてイエスを起し、「主よ、お助けください、わたしたちは死にそうです」と言った。</span>
<span className="v" id="v26" data-v="26" data-xref="イザヤ書 41:10–14; 詩篇 65:7; 詩篇 107:28–30"> するとイエスは彼らに言われた、「なぜこわがるのか、信仰の薄い者たちよ」。それから起きあがって、風と海とをおしかりになると、大なぎになった。</span>
<span className="v" id="v27" data-v="27" data-xref="マルコによる福音書 7:37; マルコによる福音書 6:51; マタイによる福音書 14:33"> 彼らは驚いて言った、「このかたはどういう人なのだろう。風も海も従わせるとは」。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="ルカによる福音書 8:26–39; マルコによる福音書 5:1–20; 使徒行伝 10:38"> それから、向こう岸、ガダラ人の地に着かれると、悪霊につかれたふたりの者が、墓場から出てきてイエスに出会った。彼らは手に負えない乱暴者で、だれもその辺の道を通ることができないほどであった。</span>
<span className="v" id="v29" data-v="29" data-xref="マルコによる福音書 1:24; ルカによる福音書 4:34; ヤコブの手紙 2:19"> すると突然、彼らは叫んで言った、「神の子よ、あなたはわたしどもとなんの係わりがあるのです。まだその時ではないのに、ここにきて、わたしどもを苦しめるのですか」。</span>
<span className="v" id="v30" data-v="30" data-xref="申命記 14:8; レビ記 11:7; マルコによる福音書 5:11"> さて、そこからはるか離れた所に、おびただしい豚の群れが飼ってあった。</span>
<span className="v" id="v31" data-v="31" data-xref="ヨハネの黙示録 20:1–2; ルカによる福音書 8:30–33; マルコによる福音書 5:12"> 悪霊どもはイエスに願って言った、「もしわたしどもを追い出されるのなら、あの豚の群れの中につかわして下さい」。</span>
<span className="v" id="v32" data-v="32" data-xref="マルコによる福音書 5:13; 使徒行伝 2:23; ヨハネの黙示録 20:7"> そこで、イエスが「行け」と言われると、彼らは出て行って、豚の中へはいり込んだ。すると、その群れ全体が、がけから海へなだれを打って駆け下り、水の中で死んでしまった。</span>
<span className="v" id="v33" data-v="33" data-xref="ルカによる福音書 8:34–36; マルコによる福音書 5:14–16; 使徒行伝 19:15–17"> 飼う者たちは逃げて町に行き、悪霊につかれた者たちのことなど、いっさいを知らせた。</span>
<span className="v" id="v34" data-v="34" data-xref="使徒行伝 16:39; ルカによる福音書 8:37–39; ルカによる福音書 5:8"> すると、町中の者がイエスに会いに出てきた。そして、イエスに会うと、この地方から去ってくださるようにと頼んだ。</span>
</div>

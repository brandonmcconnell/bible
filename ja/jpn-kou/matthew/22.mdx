<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マタイによる福音書 20:1–16; マタイによる福音書 12:43–45; ルカによる福音書 14:16"> イエスはまた、譬で彼らに語って言われた、</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネの黙示録 19:7–9; マタイによる福音書 13:24; エペソ人への手紙 5:24–32"> 「天国は、ひとりの王がその王子のために、婚宴を催すようなものである。</span>
<span className="v" id="v3" data-v="3" data-xref="ヨハネの黙示録 22:17; ヨハネによる福音書 5:40; ルカによる福音書 14:15–17"> 王はその僕たちをつかわして、この婚宴に招かれていた人たちを呼ばせたが、その人たちはこようとはしなかった。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行伝 13:46; マタイによる福音書 21:36; ヨハネによる福音書 6:50–57"> そこでまた、ほかの僕たちをつかわして言った、『招かれた人たちに言いなさい。食事の用意ができました。牛も肥えた獣もほふられて、すべての用意ができました。さあ、婚宴においでください』。</span>
<span className="v" id="v5" data-v="5" data-xref="ヘブル人への手紙 2:3; ルカによる福音書 14:18–20; ヨハネの第一の手紙 2:15–16"> しかし、彼らは知らぬ顔をして、ひとりは自分の畑に、ひとりは自分の商売に出て行き、</span>
<span className="v" id="v6" data-v="6" data-xref="ヨハネによる福音書 15:19–20; ヨハネによる福音書 16:2–3; 使徒行伝 7:51–57"> またほかの人々は、この僕たちをつかまえて侮辱を加えた上、殺してしまった。</span>
<span className="v" id="v7" data-v="7" data-xref="ルカによる福音書 19:27; ペテロの第一の手紙 4:17–18; ルカによる福音書 21:24"> そこで王は立腹し、軍隊を送ってそれらの人殺しどもを滅ぼし、その町を焼き払った。</span>
<span className="v" id="v8" data-v="8" data-xref="テサロニケ人への第二の手紙 1:5; 使徒行伝 13:46; ヨハネの黙示録 3:4"> それから僕たちに言った、『婚宴の用意はできているが、招かれていたのは、ふさわしくない人々であった。</span>
<span className="v" id="v9" data-v="9" data-xref="ルカによる福音書 14:21–24; 箴言 1:20–23; マルコによる福音書 16:15–16"> だから、町の大通りに出て行って、出会った人はだれでも婚宴に連れてきなさい』。</span>
<span className="v" id="v10" data-v="10" data-xref="コリント人への第一の手紙 6:9–11; ヨハネの黙示録 19:6–9; コリント人への第二の手紙 12:21"> そこで、僕たちは道に出て行って、出会う人は、悪人でも善人でもみな集めてきたので、婚宴の席は客でいっぱいになった。</span>
<span className="v" id="v11" data-v="11" data-xref="ヨハネの黙示録 3:4–5; ヨハネの黙示録 19:8; ヘブル人への手紙 4:12–13"> 王は客を迎えようとしてはいってきたが、そこに礼服をつけていないひとりの人を見て、</span>
<span className="v" id="v12" data-v="12" data-xref="サムエル記上 2:9; ヨブ記 5:16; マタイによる福音書 20:13"> 彼に言った、『友よ、どうしてあなたは礼服をつけないで、ここにはいってきたのですか』。しかし、彼は黙っていた。</span>
<span className="v" id="v13" data-v="13" data-xref="マタイによる福音書 8:12; マタイによる福音書 25:30; マタイによる福音書 24:51"> そこで、王はそばの者たちに言った、『この者の手足をしばって、外の暗やみにほうり出せ。そこで泣き叫んだり、歯がみをしたりするであろう』。</span>
<span className="v" id="v14" data-v="14" data-xref="ペテロの第二の手紙 1:10; ルカによる福音書 13:23–24; マタイによる福音書 7:13–14"> 招かれる者は多いが、選ばれる者は少ない」。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="ルカによる福音書 20:20–26; マルコによる福音書 12:13–17; 詩篇 2:2"> そのときパリサイ人たちがきて、どうかしてイエスを言葉のわなにかけようと、相談をした。</span>
<span className="v" id="v16" data-v="16" data-xref="マルコによる福音書 3:6; マルコによる福音書 8:15; マルコによる福音書 12:14"> そして、彼らの弟子を、ヘロデ党の者たちと共に、イエスのもとにつかわして言わせた、「先生、わたしたちはあなたが真実なかたであって、真理に基いて神の道を教え、また、人に分け隔てをしないで、だれをもはばかられないことを知っています。</span>
<span className="v" id="v17" data-v="17" data-xref="ルカによる福音書 2:1; ローマ人への手紙 13:6–7; マタイによる福音書 17:25"> それで、あなたはどう思われますか、答えてください。カイザルに税金を納めてよいでしょうか、いけないでしょうか」。</span>
<span className="v" id="v18" data-v="18" data-xref="ヨハネによる福音書 8:6; ルカによる福音書 5:22; ヨハネによる福音書 2:25"> イエスは彼らの悪意を知って言われた、「偽善者たちよ、なぜわたしをためそうとするのか。</span>
<span className="v" id="v19" data-v="19" data-xref="マタイによる福音書 20:2; ヨハネの黙示録 6:6; マタイによる福音書 18:28"> 税に納める貨幣を見せなさい」。彼らはデナリ一つを持ってきた。</span>
<span className="v" id="v20" data-v="20" data-xref="ルカによる福音書 20:24"> そこでイエスは言われた、「これは、だれの肖像、だれの記号か」。</span>
<span className="v" id="v21" data-v="21" data-xref="ローマ人への手紙 13:7; 箴言 24:21; 使徒行伝 4:19"> 彼らは「カイザルのです」と答えた。するとイエスは言われた、「それでは、カイザルのものはカイザルに、神のものは神に返しなさい」。</span>
<span className="v" id="v22" data-v="22" data-xref="マルコによる福音書 12:12; マタイによる福音書 22:46; ルカによる福音書 20:25–26"> 彼らはこれを聞いて驚嘆し、イエスを残して立ち去った。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="使徒行伝 4:1; マルコによる福音書 12:18–27; 使徒行伝 23:6–8"> 復活ということはないと主張していたサドカイ人たちが、その日、イエスのもとにきて質問した、</span>
<span className="v" id="v24" data-v="24" data-xref="申命記 25:5–10; ルカによる福音書 20:28; ルツ記 1:11"> 「先生、モーセはこう言っています、『もし、ある人が子がなくて死んだなら、その弟は兄の妻をめとって、兄のために子をもうけねばならない』。</span>
<span className="v" id="v25" data-v="25" data-xref="ルカによる福音書 20:29–33; マルコによる福音書 12:19–23; ヘブル人への手紙 9:27"> さて、わたしたちのところに七人の兄弟がありました。長男は妻をめとったが死んでしまい、そして子がなかったので、その妻を弟に残しました。</span>
<span className="v" id="v26" data-v="26"> 次男も三男も、ついに七人とも同じことになりました。</span>
<span className="v" id="v27" data-v="27"> 最後に、その女も死にました。</span>
<span className="v" id="v28" data-v="28"> すると復活の時には、この女は、七人のうちだれの妻なのでしょうか。みんながこの女を妻にしたのですが」。</span>
<span className="v" id="v29" data-v="29" data-xref="ヨハネによる福音書 20:9; ローマ人への手紙 15:4; ルカによる福音書 1:37"> イエスは答えて言われた、「あなたがたは聖書も神の力も知らないから、思い違いをしている。</span>
<span className="v" id="v30" data-v="30" data-xref="ルカによる福音書 20:34–36; マルコによる福音書 12:24–25; マタイによる福音書 24:38"> 復活の時には、彼らはめとったり、とついだりすることはない。彼らは天にいる御使のようなものである。</span>
<span className="v" id="v31" data-v="31" data-xref="マタイによる福音書 12:3; マタイによる福音書 21:16; マタイによる福音書 21:42"> また、死人の復活については、神があなたがたに言われた言葉を読んだことがないのか。</span>
<span className="v" id="v32" data-v="32" data-xref="出エジプト記 3:6; マルコによる福音書 12:26–27; ルカによる福音書 20:37–38"> 『わたしはアブラハムの神、イサクの神、ヤコブの神である』と書いてある。神は死んだ者の神ではなく、生きている者の神である」。</span>
<span className="v" id="v33" data-v="33" data-xref="マルコによる福音書 12:17; マルコによる福音書 6:2; ヨハネによる福音書 7:46"> 群衆はこれを聞いて、イエスの教に驚いた。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="マルコによる福音書 12:28–31; マタイによる福音書 25:3–5; マタイによる福音書 12:14"> さて、パリサイ人たちは、イエスがサドカイ人たちを言いこめられたと聞いて、一緒に集まった。</span>
<span className="v" id="v35" data-v="35" data-xref="ルカによる福音書 7:30; ルカによる福音書 10:25–37; ルカによる福音書 11:52"> そして彼らの中のひとりの律法学者が、イエスをためそうとして質問した、</span>
<span className="v" id="v36" data-v="36" data-xref="マルコによる福音書 12:28–33; マタイによる福音書 5:19–20; ルカによる福音書 11:42"> 「先生、律法の中で、どのいましめがいちばん大切なのですか」。</span>
<span className="v" id="v37" data-v="37" data-xref="マルコによる福音書 12:29–30; ルカによる福音書 10:27; 申命記 6:5"> イエスは言われた、「『心をつくし、精神をつくし、思いをつくして、主なるあなたの神を愛せよ』。</span>
<span className="v" id="v38" data-v="38"> これがいちばん大切な、第一のいましめである。</span>
<span className="v" id="v39" data-v="39" data-xref="マルコによる福音書 12:31; ルカによる福音書 10:27–37; レビ記 19:18"> 第二もこれと同様である、『自分を愛するようにあなたの隣り人を愛せよ』。</span>
<span className="v" id="v40" data-v="40" data-xref="ローマ人への手紙 13:9; マタイによる福音書 7:12; ヨハネの第一の手紙 4:19–21"> これらの二つのいましめに、律法全体と預言者とが、かかっている」。</span>
</div>
<div className="bp poetry">
<span className="v" id="v41" data-v="41" data-xref="ルカによる福音書 20:41–44; マルコによる福音書 12:35–37; マタイによる福音書 22:34"> パリサイ人たちが集まっていたとき、イエスは彼らにお尋ねになった、</span>
<span className="v" id="v42" data-v="42" data-xref="エレミヤ書 23:5–6; ヨハネによる福音書 6:68–69; マタイによる福音書 16:13–17"> 「あなたがたはキリストをどう思うか。だれの子なのか」。彼らは「ダビデの子です」と答えた。</span>
<span className="v" id="v43" data-v="43" data-xref="サムエル記下 23:2; ヨハネの黙示録 4:2; マルコによる福音書 12:36"> イエスは言われた、「それではどうして、ダビデが御霊に感じてキリストを主と呼んでいるのか。</span>
<span className="v" id="v44" data-v="44" data-xref="詩篇 110:1; ヘブル人への手紙 1:13; 使徒行伝 2:34–35"> すなわち<br /><span className="pl pl-1">『主はわが主に仰せになった、</span><br /><span className="pl pl-1">あなたの敵をあなたの足もとに置くときまでは、</span><br /><span className="pl pl-1">わたしの右に座していなさい』。</span></span>
<span className="v" id="v45" data-v="45" data-xref="ローマ人への手紙 1:3–4; ヨハネの黙示録 22:16; ヨハネによる福音書 8:58"> <span className="pl pl-1">このように、ダビデ自身がキリストを主と呼んでいるなら、キリストはどうしてダビデの子であろうか」。</span></span>
<span className="v" id="v46" data-v="46" data-xref="マルコによる福音書 12:34; ルカによる福音書 20:40; ルカによる福音書 14:6"> <span className="pl pl-1">イエスにひと言でも答えうる者は、なかったし、その日からもはや、進んでイエスに質問する者も、いなくなった。</span></span>
</div>

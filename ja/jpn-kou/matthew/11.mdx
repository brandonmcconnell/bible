<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="イザヤ書 61:1–3; 使徒行伝 10:38; ルカによる福音書 8:1"> イエスは十二弟子にこのように命じ終えてから、町々で教えまた宣べ伝えるために、そこを立ち去られた。</span>
</div>
<div className="bp poetry">
<span className="v" id="v2" data-v="2" data-xref="マルコによる福音書 6:17; マタイによる福音書 14:3; マタイによる福音書 9:14"> さて、ヨハネは獄中でキリストのみわざについて伝え聞き、自分の弟子たちをつかわして、</span>
<span className="v" id="v3" data-v="3" data-xref="ヨハネによる福音書 11:27; マラキ書 3:1; 申命記 18:15–18"> イエスに言わせた、「『きたるべきかた』はあなたなのですか。それとも、ほかにだれかを待つべきでしょうか」。</span>
<span className="v" id="v4" data-v="4"> イエスは答えて言われた、「行って、あなたがたが見聞きしていることをヨハネに報告しなさい。</span>
<span className="v" id="v5" data-v="5" data-xref="イザヤ書 35:4–6; イザヤ書 61:1–3; ルカによる福音書 4:18"> 盲人は見え、足なえは歩き、らい病人はきよまり、耳しいは聞え、死人は生きかえり、貧しい人々は福音を聞かされている。</span>
<span className="v" id="v6" data-v="6" data-xref="イザヤ書 8:14–15; コリント人への第一の手紙 2:14; マタイによる福音書 26:31"> わたしにつまずかない者は、さいわいである」。</span>
<span className="v" id="v7" data-v="7" data-xref="ヤコブの手紙 1:6; ヨハネによる福音書 5:35; マルコによる福音書 1:3–5"> 彼らが帰ってしまうと、イエスはヨハネのことを群衆に語りはじめられた、「あなたがたは、何を見に荒野に出てきたのか。風に揺らぐ葦であるか。</span>
<span className="v" id="v8" data-v="8" data-xref="マタイによる福音書 3:4; 列王紀下 1:8; ゼカリヤ書 13:4"> では、何を見に出てきたのか。柔らかい着物をまとった人か。柔らかい着物をまとった人々なら、王の家にいる。</span>
<span className="v" id="v9" data-v="9" data-xref="ルカによる福音書 1:76; マタイによる福音書 14:5; マタイによる福音書 21:24–26"> では、なんのために出てきたのか。預言者を見るためか。そうだ、あなたがたに言うが、預言者以上の者である。</span>
<span className="v" id="v10" data-v="10" data-xref="マラキ書 3:1; イザヤ書 40:3; マラキ書 4:5"> <span className="pl pl-1">『見よ、わたしは使をあなたの先につかわし、</span><br /><span className="pl pl-1">あなたの前に、道を整えさせるであろう』</span><br />と書いてあるのは、この人のことである。</span>
<span className="v" id="v11" data-v="11" data-xref="ルカによる福音書 7:28; エペソ人への手紙 3:8; マタイによる福音書 3:11"> あなたがたによく言っておく。女の産んだ者の中で、バプテスマのヨハネより大きい人物は起らなかった。しかし、天国で最も小さい者も、彼よりは大きい。</span>
<span className="v" id="v12" data-v="12" data-xref="ルカによる福音書 16:16; ルカによる福音書 13:24; エペソ人への手紙 6:11–13"> バプテスマのヨハネの時から今に至るまで、天国は激しく襲われている。そして激しく襲う者たちがそれを奪い取っている。</span>
<span className="v" id="v13" data-v="13" data-xref="マタイによる福音書 5:17–18; ローマ人への手紙 3:21; 使徒行伝 13:27"> すべての預言者と律法とが預言したのは、ヨハネの時までである。</span>
<span className="v" id="v14" data-v="14" data-xref="マラキ書 4:5; マタイによる福音書 17:10–13; マルコによる福音書 9:11–13"> そして、もしあなたがたが受けいれることを望めば、この人こそは、きたるべきエリヤなのである。</span>
<span className="v" id="v15" data-v="15" data-xref="ルカによる福音書 8:8; マタイによる福音書 13:9; マルコによる福音書 4:23"> 耳のある者は聞くがよい。</span>
</div>
<div className="bp poetry">
<span className="v" id="v16" data-v="16" data-xref="ルカによる福音書 7:31–35; マタイによる福音書 12:34; マタイによる福音書 23:36"> 今の時代を何に比べようか。それは子供たちが広場にすわって、ほかの子供たちに呼びかけ、</span>
<span className="v" id="v17" data-v="17" data-xref="イザヤ書 28:9–13; イザヤ書 30:29; エレミヤ書 9:17–20"> <span className="pl pl-1">『わたしたちが笛を吹いたのに、</span><br /><span className="pl pl-1">あなたたちは踊ってくれなかった。</span><br /><span className="pl pl-1">弔いの歌を歌ったのに、</span><br /><span className="pl pl-1">胸を打ってくれなかった』</span><br />と言うのに似ている。</span>
<span className="v" id="v18" data-v="18" data-xref="ルカによる福音書 1:15; マタイによる福音書 3:4; ヨハネによる福音書 10:20"> なぜなら、ヨハネがきて、食べることも、飲むこともしないと、あれは悪霊につかれているのだ、と言い、</span>
<span className="v" id="v19" data-v="19" data-xref="マタイによる福音書 9:10–11; ルカによる福音書 15:1–2; ルカによる福音書 19:7"> また人の子がきて、食べたり飲んだりしていると、見よ、あれは食をむさぼる者、大酒を飲む者、また取税人、罪人の仲間だ、と言う。しかし、知恵の正しいことは、その働きが証明する」。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="ルカによる福音書 10:13–15; エレミヤ書 8:6; テモテヘの第二の手紙 2:25–26"> それからイエスは、数々の力あるわざがなされたのに、悔い改めることをしなかった町々を、責めはじめられた。</span>
<span className="v" id="v21" data-v="21" data-xref="エゼキエル書 3:6–7; 使徒行伝 12:20; ルカによる福音書 9:10"> 「わざわいだ、コラジンよ。わざわいだ、ベツサイダよ。おまえたちのうちでなされた力あるわざが、もしツロとシドンでなされたなら、彼らはとうの昔に、荒布をまとい灰をかぶって、悔い改めたであろう。</span>
<span className="v" id="v22" data-v="22" data-xref="マタイによる福音書 11:24; マタイによる福音書 10:15; ヘブル人への手紙 10:26–31"> しかし、おまえたちに言っておく。さばきの日には、ツロとシドンの方がおまえたちよりも、耐えやすいであろう。</span>
<span className="v" id="v23" data-v="23" data-xref="イザヤ書 14:13–15; ヨハネによる福音書 4:46–54; 創世記 13:13"> ああ、カペナウムよ、おまえは天にまで上げられようとでもいうのか。黄泉にまで落されるであろう。おまえの中でなされた力あるわざが、もしソドムでなされたなら、その町は今日までも残っていたであろう。</span>
<span className="v" id="v24" data-v="24" data-xref="マタイによる福音書 10:15; マタイによる福音書 11:22; マルコによる福音書 6:11"> しかし、あなたがたに言う。さばきの日には、ソドムの地の方がおまえよりは耐えやすいであろう」。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="マタイによる福音書 21:16; 詩篇 8:2; マタイによる福音書 16:17"> そのときイエスは声をあげて言われた、「天地の主なる父よ。あなたをほめたたえます。これらの事を知恵のある者や賢い者に隠して、幼な子にあらわしてくださいました。</span>
<span className="v" id="v26" data-v="26" data-xref="テモテヘの第二の手紙 1:9; エペソ人への手紙 1:11; ヨブ記 33:13"> 父よ、これはまことにみこころにかなった事でした。</span>
<span className="v" id="v27" data-v="27" data-xref="ヨハネによる福音書 14:6–9; マタイによる福音書 28:18; ルカによる福音書 10:22"> すべての事は父からわたしに任せられています。そして、子を知る者は父のほかにはなく、父を知る者は、子と、父をあらわそうとして子が選んだ者とのほかに、だれもありません。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="マタイによる福音書 11:29; ヨハネによる福音書 7:37; ヨハネによる福音書 6:37"> すべて重荷を負うて苦労している者は、わたしのもとにきなさい。あなたがたを休ませてあげよう。</span>
<span className="v" id="v29" data-v="29" data-xref="エレミヤ書 6:16; ヨハネの第一の手紙 2:6; ピリピ人への手紙 2:7–8"> わたしは柔和で心のへりくだった者であるから、わたしのくびきを負うて、わたしに学びなさい。そうすれば、あなたがたの魂に休みが与えられるであろう。</span>
<span className="v" id="v30" data-v="30" data-xref="ヨハネの第一の手紙 5:3; ヨハネによる福音書 16:33; ピリピ人への手紙 4:13"> わたしのくびきは負いやすく、わたしの荷は軽いからである」。</span>
</div>

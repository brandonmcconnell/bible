<div className="bible-chapter" lang="ja" dir="ltr" data-lang="ja" data-translation="jpn-kou" data-translation-id="jpn_kou" data-translation-label="口語訳" data-book="MAT" data-book-slug="matthew" data-book-name="マタイによる福音書" data-chapter="14" data-verses="36">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ルカによる福音書 3:1; マルコによる福音書 8:15; ルカによる福音書 9:7–9"> そのころ、領主ヘロデはイエスのうわさを聞いて、</span>
<span className="v" id="v2" data-v="2" data-xref="マタイによる福音書 16:14; ヨハネによる福音書 10:41; マルコによる福音書 8:28"> 家来に言った、「あれはバプテスマのヨハネだ。死人の中からよみがえったのだ。それで、あのような力が彼のうちに働いているのだ」。</span>
<span className="v" id="v3" data-v="3" data-xref="マルコによる福音書 6:17; ルカによる福音書 3:19–20; マタイによる福音書 4:12"> というのは、ヘロデは先に、自分の兄弟ピリポの妻ヘロデヤのことで、ヨハネを捕えて縛り、獄に入れていた。</span>
<span className="v" id="v4" data-v="4" data-xref="レビ記 20:21; レビ記 18:16; マルコによる福音書 6:18"> すなわち、ヨハネはヘロデに、「その女をめとるのは、よろしくない」と言ったからである。</span>
<span className="v" id="v5" data-v="5" data-xref="マタイによる福音書 21:26; マタイによる福音書 11:9; マルコによる福音書 6:19–20"> そこでヘロデはヨハネを殺そうと思ったが、群衆を恐れた。彼らがヨハネを預言者と認めていたからである。</span>
<span className="v" id="v6" data-v="6" data-xref="マルコによる福音書 6:21–23; 創世記 40:20; ホセア書 1:5–6"> さてヘロデの誕生日の祝に、ヘロデヤの娘がその席上で舞をまい、ヘロデを喜ばせたので、</span>
<span className="v" id="v7" data-v="7" data-xref="エステル記 5:3; エステル記 5:6; エステル記 7:2"> 彼女の願うものは、なんでも与えようと、彼は誓って約束までした。</span>
<span className="v" id="v8" data-v="8" data-xref="マルコによる福音書 6:24; 箴言 29:10; 箴言 1:16"> すると彼女は母にそそのかされて、「バプテスマのヨハネの首を盆に載せて、ここに持ってきていただきとうございます」と言った。</span>
<span className="v" id="v9" data-v="9" data-xref="ヨハネによる福音書 19:12–16; サムエル記上 14:28; マルコによる福音書 6:26"> 王は困ったが、いったん誓ったのと、また列座の人たちの手前、それを与えるように命じ、</span>
<span className="v" id="v10" data-v="10" data-xref="マタイによる福音書 17:12; マタイによる福音書 21:35–36; ルカによる福音書 9:9"> 人をつかわして、獄中でヨハネの首を切らせた。</span>
<span className="v" id="v11" data-v="11" data-xref="ヨハネの黙示録 16:6; 創世記 49:7; エゼキエル書 16:3–4"> その首は盆に載せて運ばれ、少女にわたされ、少女はそれを母のところに持って行った。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行伝 8:2; マタイによる福音書 27:58–61"> それから、ヨハネの弟子たちがきて、死体を引き取って葬った。そして、イエスのところに行って報告した。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="ルカによる福音書 9:10–17; マタイによる福音書 14:1–2; マルコによる福音書 6:30–44"> イエスはこのことを聞くと、舟に乗ってそこを去り、自分ひとりで寂しい所へ行かれた。しかし、群衆はそれと聞いて、町々から徒歩であとを追ってきた。</span>
<span className="v" id="v14" data-v="14" data-xref="ヘブル人への手紙 4:15; マタイによる福音書 9:36; ヘブル人への手紙 2:17"> イエスは舟から上がって、大ぜいの群衆をごらんになり、彼らを深くあわれんで、そのうちの病人たちをおいやしになった。</span>
<span className="v" id="v15" data-v="15" data-xref="マタイによる福音書 15:23; マルコによる福音書 8:3; マルコによる福音書 6:35–36"> 夕方になったので、弟子たちがイエスのもとにきて言った、「ここは寂しい所でもあり、もう時もおそくなりました。群衆を解散させ、めいめいで食物を買いに、村々へ行かせてください」。</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀下 4:42–44; コリント人への第二の手紙 8:2–3; 伝道の書 11:2"> するとイエスは言われた、「彼らが出かけて行くには及ばない。あなたがたの手で食物をやりなさい」。</span>
<span className="v" id="v17" data-v="17" data-xref="マタイによる福音書 15:33–34; マルコによる福音書 6:37–38; ルカによる福音書 9:13"> 弟子たちは言った、「わたしたちはここに、パン五つと魚二ひきしか持っていません」。</span>
<span className="v" id="v18" data-v="18"> イエスは言われた、「それをここに持ってきなさい」。</span>
<span className="v" id="v19" data-v="19" data-xref="マルコによる福音書 8:6–7; ルカによる福音書 24:30; サムエル記上 9:13"> そして群衆に命じて、草の上にすわらせ、五つのパンと二ひきの魚とを手に取り、天を仰いでそれを祝福し、パンをさいて弟子たちに渡された。弟子たちはそれを群衆に与えた。</span>
<span className="v" id="v20" data-v="20" data-xref="出エジプト記 16:12; マルコによる福音書 6:42–44; マタイによる福音書 16:8–10"> みんなの者は食べて満腹した。パンくずの残りを集めると、十二のかごにいっぱいになった。</span>
<span className="v" id="v21" data-v="21" data-xref="ピリピ人への手紙 4:19; コリント人への第二の手紙 9:8–11; 使徒行伝 4:4"> 食べた者は、女と子供とを除いて、おおよそ五千人であった。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="マルコによる福音書 6:45–51; ヨハネによる福音書 6:15–21; マタイによる福音書 15:39"> それからすぐ、イエスは群衆を解散させておられる間に、しいて弟子たちを舟に乗り込ませ、向こう岸へ先におやりになった。</span>
<span className="v" id="v23" data-v="23" data-xref="ルカによる福音書 6:12; マルコによる福音書 6:46; マタイによる福音書 26:36"> そして群衆を解散させてから、祈るためひそかに山へ登られた。夕方になっても、ただひとりそこにおられた。</span>
<span className="v" id="v24" data-v="24" data-xref="ヨハネによる福音書 6:18; マルコによる福音書 6:48; マタイによる福音書 8:24"> ところが舟は、もうすでに陸から数丁も離れており、逆風が吹いていたために、波に悩まされていた。</span>
<span className="v" id="v25" data-v="25" data-xref="ヨブ記 9:8; ヨハネによる福音書 6:19; マルコによる福音書 6:48"> イエスは夜明けの四時ごろ、海の上を歩いて彼らの方へ行かれた。</span>
<span className="v" id="v26" data-v="26" data-xref="マルコによる福音書 6:49–50; ヨハネの黙示録 1:17; ルカによる福音書 1:11–12"> 弟子たちは、イエスが海の上を歩いておられるのを見て、幽霊だと言っておじ惑い、恐怖のあまり叫び声をあげた。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行伝 23:11; ヨハネの黙示録 1:17–18; ヨハネによる福音書 16:33"> しかし、イエスはすぐに彼らに声をかけて、「しっかりするのだ、わたしである。恐れることはない」と言われた。</span>
<span className="v" id="v28" data-v="28" data-xref="ヨハネによる福音書 6:68; ローマ人への手紙 12:3; マタイによる福音書 26:33–35"> するとペテロが答えて言った、「主よ、あなたでしたか。では、わたしに命じて、水の上を渡ってみもとに行かせてください」。</span>
<span className="v" id="v29" data-v="29" data-xref="ピリピ人への手紙 4:13; マルコによる福音書 9:23; 使徒行伝 3:16"> イエスは、「おいでなさい」と言われたので、ペテロは舟からおり、水の上を歩いてイエスのところへ行った。</span>
<span className="v" id="v30" data-v="30" data-xref="哀歌 3:54–57; テモテヘの第二の手紙 4:16–17; マルコによる福音書 14:38"> しかし、風を見て恐ろしくなり、そしておぼれかけたので、彼は叫んで、「主よ、お助けください」と言った。</span>
<span className="v" id="v31" data-v="31" data-xref="ヤコブの手紙 1:6–8; 詩篇 138:7; 創世記 22:14"> イエスはすぐに手を伸ばし、彼をつかまえて言われた、「信仰の薄い者よ、なぜ疑ったのか」。</span>
<span className="v" id="v32" data-v="32" data-xref="詩篇 107:29–30; マルコによる福音書 4:41; ヨハネによる福音書 6:21"> ふたりが舟に乗り込むと、風はやんでしまった。</span>
<span className="v" id="v33" data-v="33" data-xref="ヨハネによる福音書 11:27; 詩篇 2:7; ローマ人への手紙 1:4"> 舟の中にいた者たちはイエスを拝して、「ほんとうに、あなたは神の子です」と言った。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="マルコによる福音書 6:53–56; ルカによる福音書 5:1; ヨハネによる福音書 6:24–25"> それから、彼らは海を渡ってゲネサレの地に着いた。</span>
<span className="v" id="v35" data-v="35" data-xref="マタイによる福音書 4:24–25; マルコによる福音書 6:55; マルコによる福音書 1:28–34"> するとその土地の人々はイエスと知って、その附近全体に人をつかわし、イエスのところに病人をみな連れてこさせた。</span>
<span className="v" id="v36" data-v="36" data-xref="ルカによる福音書 6:19; マルコによる福音書 3:10; 出エジプト記 28:33–43"> そして彼らにイエスの上着のふさにでも、さわらせてやっていただきたいとお願いした。そしてさわった者は皆いやされた。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ルカによる福音書 12:35–36; ピリピ人への手紙 2:15–16; マタイによる福音書 24:42–51"> そこで天国は、十人のおとめがそれぞれあかりを手にして、花婿を迎えに出て行くのに似ている。</span>
<span className="v" id="v2" data-v="2" data-xref="エレミヤ書 24:2; コリント人への第一の手紙 10:1–5; マタイによる福音書 13:19–23"> その中の五人は思慮が浅く、五人は思慮深い者であった。</span>
<span className="v" id="v3" data-v="3" data-xref="ヨハネの黙示録 3:15–16; テモテヘの第二の手紙 3:5; イザヤ書 48:1–2"> 思慮の浅い者たちは、あかりは持っていたが、油を用意していなかった。</span>
<span className="v" id="v4" data-v="4" data-xref="ローマ人への手紙 8:9; ヨハネの第一の手紙 2:27; ヨハネの第一の手紙 2:20"> しかし、思慮深い者たちは、自分たちのあかりと一緒に、入れものの中に油を用意していた。</span>
<span className="v" id="v5" data-v="5" data-xref="ハバクク書 2:3; テサロニケ人への第一の手紙 5:6–8; ペテロの第二の手紙 3:4–9"> 花婿の来るのがおくれたので、彼らはみな居眠りをして、寝てしまった。</span>
<span className="v" id="v6" data-v="6" data-xref="ペテロの第二の手紙 3:10; マタイによる福音書 24:31; マタイによる福音書 24:44"> 夜中に、『さあ、花婿だ、迎えに出なさい』と呼ぶ声がした。</span>
<span className="v" id="v7" data-v="7" data-xref="ルカによる福音書 12:35; ヨハネの黙示録 3:19–20; ペテロの第二の手紙 3:14"> そのとき、おとめたちはみな起きて、それぞれあかりを整えた。</span>
<span className="v" id="v8" data-v="8" data-xref="箴言 13:9; ルカによる福音書 12:35; ヘブル人への手紙 4:1"> ところが、思慮の浅い女たちが、思慮深い女たちに言った、『あなたがたの油をわたしたちにわけてください。わたしたちのあかりが消えかかっていますから』。</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 49:7–9; ヨハネの黙示録 3:17–18; イザヤ書 55:6–7"> すると、思慮深い女たちは答えて言った、『わたしたちとあなたがたとに足りるだけは、多分ないでしょう。店に行って、あなたがたの分をお買いになる方がよいでしょう』。</span>
<span className="v" id="v10" data-v="10" data-xref="ルカによる福音書 13:25; マタイによる福音書 24:44; ルカによる福音書 12:36–37"> 彼らが買いに出ているうちに、花婿が着いた。そこで、用意のできていた女たちは、花婿と一緒に婚宴のへやにはいり、そして戸がしめられた。</span>
<span className="v" id="v11" data-v="11" data-xref="マタイによる福音書 7:21–23; ヘブル人への手紙 12:16–17"> そのあとで、ほかのおとめたちもきて、『ご主人様、ご主人様、どうぞ、あけてください』と言った。</span>
<span className="v" id="v12" data-v="12" data-xref="コリント人への第一の手紙 8:3; テモテヘの第二の手紙 2:19; ヨハネによる福音書 10:27"> しかし彼は答えて、『はっきり言うが、わたしはあなたがたを知らない』と言った。</span>
<span className="v" id="v13" data-v="13" data-xref="マタイによる福音書 24:42–44; ヨハネの黙示録 16:15; テサロニケ人への第一の手紙 5:6"> だから、目をさましていなさい。その日その時が、あなたがたにはわからないからである。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="マルコによる福音書 13:34; ルカによる福音書 19:12–27; ペテロの第一の手紙 4:9–11"> また天国は、ある人が旅に出るとき、その僕どもを呼んで、自分の財産を預けるようなものである。</span>
<span className="v" id="v15" data-v="15" data-xref="マタイによる福音書 18:24; ルカによる福音書 19:13–14; ルカによる福音書 12:48"> すなわち、それぞれの能力に応じて、ある者には五タラント、ある者には二タラント、ある者には一タラントを与えて、旅に出た。</span>
<span className="v" id="v16" data-v="16" data-xref="ヨハネの第三の手紙 1:5–8; テモテヘの第一の手紙 6:17–18; テモテヘの第二の手紙 2:6"> 五タラントを渡された者は、すぐに行って、それで商売をして、ほかに五タラントをもうけた。</span>
<span className="v" id="v17" data-v="17" data-xref="箴言 3:9–10; エペソ人への手紙 5:16; ペテロの第一の手紙 4:10"> 二タラントの者も同様にして、ほかに二タラントをもうけた。</span>
<span className="v" id="v18" data-v="18" data-xref="ペテロの第二の手紙 1:8; ハガイ書 1:2–4; マラキ書 1:10"> しかし、一タラントを渡された者は、行って地を掘り、主人の金を隠しておいた。</span>
<span className="v" id="v19" data-v="19" data-xref="コリント人への第一の手紙 3:12–15; コリント人への第二の手紙 5:10; ローマ人への手紙 14:7–12"> だいぶ時がたってから、これらの僕の主人が帰ってきて、彼らと計算をしはじめた。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行伝 20:24; ルカによる福音書 19:16–17; コロサイ人への手紙 1:29"> すると五タラントを渡された者が進み出て、ほかの五タラントをさし出して言った、『ご主人様、あなたはわたしに五タラントをお預けになりましたが、ごらんのとおり、ほかに五タラントをもうけました』。</span>
<span className="v" id="v21" data-v="21" data-xref="マタイによる福音書 25:23; ルカによる福音書 16:10; ヨハネによる福音書 12:26"> 主人は彼に言った、『良い忠実な僕よ、よくやった。あなたはわずかなものに忠実であったから、多くのものを管理させよう。主人と一緒に喜んでくれ』。</span>
<span className="v" id="v22" data-v="22" data-xref="コリント人への第二の手紙 8:12; コリント人への第二の手紙 8:7–8; コリント人への第二の手紙 8:1–3"> 二タラントの者も進み出て言った、『ご主人様、あなたはわたしに二タラントをお預けになりましたが、ごらんのとおり、ほかに二タラントをもうけました』。</span>
<span className="v" id="v23" data-v="23" data-xref="マタイによる福音書 25:21; マルコによる福音書 14:8–9; マルコによる福音書 12:41–44"> 主人は彼に言った、『良い忠実な僕よ、よくやった。あなたはわずかなものに忠実であったから、多くのものを管理させよう。主人と一緒に喜んでくれ』。</span>
<span className="v" id="v24" data-v="24" data-xref="ルカによる福音書 19:20–22; ルカによる福音書 15:29; マラキ書 3:14–15"> 一タラントを渡された者も進み出て言った、『ご主人様、わたしはあなたが、まかない所から刈り、散らさない所から集める酷な人であることを承知していました。</span>
<span className="v" id="v25" data-v="25" data-xref="テモテヘの第二の手紙 1:6–7; ローマ人への手紙 8:15; ヨハネの黙示録 21:8"> そこで恐ろしさのあまり、行って、あなたのタラントを地の中に隠しておきました。ごらんください。ここにあなたのお金がございます』。</span>
<span className="v" id="v26" data-v="26" data-xref="マタイによる福音書 18:32; ヨブ記 15:5–6"> すると、主人は彼に答えて言った、『悪い怠惰な僕よ、あなたはわたしが、まかない所から刈り、散らさない所から集めることを知っているのか。</span>
<span className="v" id="v27" data-v="27" data-xref="申命記 23:19–20; ローマ人への手紙 3:19; ユダの手紙 1:15"> それなら、わたしの金を銀行に預けておくべきであった。そうしたら、わたしは帰ってきて、利子と一緒にわたしの金を返してもらえたであろうに。</span>
<span className="v" id="v28" data-v="28" data-xref="ルカによる福音書 19:24; ルカによる福音書 10:42"> さあ、そのタラントをこの者から取りあげて、十タラントを持っている者にやりなさい。</span>
<span className="v" id="v29" data-v="29" data-xref="ルカによる福音書 8:18; マルコによる福音書 4:25; マタイによる福音書 13:12"> おおよそ、持っている人は与えられて、いよいよ豊かになるが、持っていない人は、持っているものまでも取り上げられるであろう。</span>
<span className="v" id="v30" data-v="30" data-xref="マタイによる福音書 8:12; ヨハネの黙示録 3:15–16; マタイによる福音書 13:50"> この役に立たない僕を外の暗い所に追い出すがよい。彼は、そこで泣き叫んだり、歯がみをしたりするであろう』。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="ヨハネの黙示録 1:7; テサロニケ人への第二の手紙 1:7–8; マタイによる福音書 19:28"> 人の子が栄光の中にすべての御使たちを従えて来るとき、彼はその栄光の座につくであろう。</span>
<span className="v" id="v32" data-v="32" data-xref="マラキ書 3:18; マタイによる福音書 13:49; コリント人への第二の手紙 5:10"> そして、すべての国民をその前に集めて、羊飼が羊とやぎとを分けるように、彼らをより分け、</span>
<span className="v" id="v33" data-v="33" data-xref="詩篇 100:3; ヨハネによる福音書 10:26–28; ヨハネによる福音書 21:15–17"> 羊を右に、やぎを左におくであろう。</span>
<span className="v" id="v34" data-v="34" data-xref="ペテロの第一の手紙 1:19–20; ヤコブの手紙 2:5; ヨハネの黙示録 21:7"> そのとき、王は右にいる人々に言うであろう、『わたしの父に祝福された人たちよ、さあ、世の初めからあなたがたのために用意されている御国を受けつぎなさい。</span>
<span className="v" id="v35" data-v="35" data-xref="ヨハネの第一の手紙 3:16–19; ヤコブの手紙 2:15–16; 申命記 15:7–11"> あなたがたは、わたしが空腹のときに食べさせ、かわいていたときに飲ませ、旅人であったときに宿を貸し、</span>
<span className="v" id="v36" data-v="36" data-xref="ヤコブの手紙 1:27; テモテヘの第二の手紙 1:16–18; ヤコブの手紙 5:14–15"> 裸であったときに着せ、病気のときに見舞い、獄にいたときに尋ねてくれたからである』。</span>
<span className="v" id="v37" data-v="37" data-xref="マタイによる福音書 6:3; 歴代志上 29:14; ペテロの第一の手紙 5:5–6"> そのとき、正しい者たちは答えて言うであろう、『主よ、いつ、わたしたちは、あなたが空腹であるのを見て食物をめぐみ、かわいているのを見て飲ませましたか。</span>
<span className="v" id="v38" data-v="38"> いつあなたが旅人であるのを見て宿を貸し、裸なのを見て着せましたか。</span>
<span className="v" id="v39" data-v="39"> また、いつあなたが病気をし、獄にいるのを見て、あなたの所に参りましたか』。</span>
<span className="v" id="v40" data-v="40" data-xref="箴言 19:17; 箴言 14:31; マタイによる福音書 10:42"> すると、王は答えて言うであろう、『あなたがたによく言っておく。わたしの兄弟であるこれらの最も小さい者のひとりにしたのは、すなわち、わたしにしたのである』。</span>
<span className="v" id="v41" data-v="41" data-xref="ペテロの第二の手紙 2:4; ユダの手紙 1:6–7; テサロニケ人への第二の手紙 1:9"> それから、左にいる人々にも言うであろう、『のろわれた者どもよ、わたしを離れて、悪魔とその使たちとのために用意されている永遠の火にはいってしまえ。</span>
<span className="v" id="v42" data-v="42" data-xref="ヤコブの手紙 2:15–24; ヨハネによる福音書 5:23; マタイによる福音書 12:30"> あなたがたは、わたしが空腹のときに食べさせず、かわいていたときに飲ませず、</span>
<span className="v" id="v43" data-v="43"> 旅人であったときに宿を貸さず、裸であったときに着せず、また病気のときや、獄にいたときに、わたしを尋ねてくれなかったからである』。</span>
<span className="v" id="v44" data-v="44" data-xref="マタイによる福音書 7:22; ルカによる福音書 10:29; マタイによる福音書 25:24–27"> そのとき、彼らもまた答えて言うであろう、『主よ、いつ、あなたが空腹であり、かわいておられ、旅人であり、裸であり、病気であり、獄におられたのを見て、わたしたちはお世話をしませんでしたか』。</span>
<span className="v" id="v45" data-v="45" data-xref="箴言 21:13; 箴言 17:5; 箴言 14:31"> そのとき、彼は答えて言うであろう、『あなたがたによく言っておく。これらの最も小さい者のひとりにしなかったのは、すなわち、わたしにしなかったのである』。</span>
<span className="v" id="v46" data-v="46" data-xref="ダニエル書 12:2; ヨハネによる福音書 3:36; ヨハネによる福音書 5:29"> そして彼らは永遠の刑罰を受け、正しい者は永遠の生命に入るであろう」。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マルコによる福音書 9:33–37; ルカによる福音書 9:46–48; マタイによる福音書 20:20–28"> そのとき、弟子たちがイエスのもとにきて言った、「いったい、天国ではだれがいちばん偉いのですか」。</span>
<span className="v" id="v2" data-v="2" data-xref="マタイによる福音書 19:13–14; マルコによる福音書 9:36–37; 列王紀上 3:7"> すると、イエスは幼な子を呼び寄せ、彼らのまん中に立たせて言われた、</span>
<span className="v" id="v3" data-v="3" data-xref="マルコによる福音書 10:14–15; ペテロの第一の手紙 2:2; マタイによる福音書 19:14"> 「よく聞きなさい。心をいれかえて幼な子のようにならなければ、天国にはいることはできないであろう。</span>
<span className="v" id="v4" data-v="4" data-xref="ヤコブの手紙 4:10; ルカによる福音書 14:11; マルコによる福音書 10:43"> この幼な子のように自分を低くする者が、天国でいちばん偉いのである。</span>
<span className="v" id="v5" data-v="5" data-xref="マタイによる福音書 25:40; マルコによる福音書 9:37; ヨハネによる福音書 13:20"> また、だれでも、このようなひとりの幼な子を、わたしの名のゆえに受けいれる者は、わたしを受けいれるのである。</span>
<span className="v" id="v6" data-v="6" data-xref="マルコによる福音書 9:42; ルカによる福音書 17:1–2; マタイによる福音書 18:10"> しかし、わたしを信ずるこれらの小さい者のひとりをつまずかせる者は、大きなひきうすを首にかけられて海の深みに沈められる方が、その人の益になる。</span>
<span className="v" id="v7" data-v="7" data-xref="ルカによる福音書 17:1; コリント人への第一の手紙 11:19; マタイによる福音書 26:24"> この世は、罪の誘惑があるから、わざわいである。罪の誘惑は必ず来る。しかし、それをきたらせる人は、わざわいである。</span>
<span className="v" id="v8" data-v="8" data-xref="マタイによる福音書 5:29–30; ピリピ人への手紙 3:8–9; ローマ人への手紙 13:12"> もしあなたの片手または片足が、罪を犯させるなら、それを切って捨てなさい。両手、両足がそろったままで、永遠の火に投げ込まれるよりは、片手、片足になって命に入る方がよい。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行伝 14:22; マタイによる福音書 18:8; マタイによる福音書 5:29"> もしあなたの片目が罪を犯させるなら、それを抜き出して捨てなさい。両眼がそろったままで地獄の火に投げ入れられるよりは、片目になって命に入る方がよい。</span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 91:11; 詩篇 34:7; ヘブル人への手紙 1:14"> あなたがたは、これらの小さい者のひとりをも軽んじないように、気をつけなさい。あなたがたに言うが、彼らの御使たちは天にあって、天にいますわたしの父のみ顔をいつも仰いでいるのである。〔</span>
<span className="v" id="v11" data-v="11"> 人の子は、滅びる者を救うためにきたのである。〕</span>
<span className="v" id="v12" data-v="12" data-xref="エゼキエル書 34:12; ルカによる福音書 15:4–7; エゼキエル書 34:16"> あなたがたはどう思うか。ある人に百匹の羊があり、その中の一匹が迷い出たとすれば、九十九匹を山に残しておいて、その迷い出ている羊を捜しに出かけないであろうか。</span>
<span className="v" id="v13" data-v="13" data-xref="ゼパニヤ書 3:17; ルカによる福音書 15:5–10; ヤコブの手紙 2:13"> もしそれを見つけたなら、よく聞きなさい、迷わないでいる九十九匹のためよりも、むしろその一匹のために喜ぶであろう。</span>
<span className="v" id="v14" data-v="14" data-xref="ヨハネによる福音書 17:12; ヨハネによる福音書 6:39–40; ペテロの第二の手紙 3:9"> そのように、これらの小さい者のひとりが滅びることは、天にいますあなたがたの父のみこころではない。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="レビ記 19:17; ルカによる福音書 17:3–4; ガラテヤ人への手紙 6:1"> もしあなたの兄弟が罪を犯すなら、行って、彼とふたりだけの所で忠告しなさい。もし聞いてくれたら、あなたの兄弟を得たことになる。</span>
<span className="v" id="v16" data-v="16" data-xref="申命記 19:15; コリント人への第二の手紙 13:1; ヨハネによる福音書 8:17"> もし聞いてくれないなら、ほかにひとりふたりを、一緒に連れて行きなさい。それは、ふたりまたは三人の証人の口によって、すべてのことがらが確かめられるためである。</span>
<span className="v" id="v17" data-v="17" data-xref="テサロニケ人への第二の手紙 3:6; コリント人への第一の手紙 5:9–7; テサロニケ人への第二の手紙 3:14–15"> もし彼らの言うことを聞かないなら、教会に申し出なさい。もし教会の言うことも聞かないなら、その人を異邦人または取税人同様に扱いなさい。</span>
<span className="v" id="v18" data-v="18" data-xref="マタイによる福音書 16:19; コリント人への第二の手紙 2:10; ヨハネによる福音書 20:23"> よく言っておく。あなたがたが地上でつなぐことは、天でも皆つながれ、あなたがたが地上で解くことは、天でもみな解かれるであろう。</span>
<span className="v" id="v19" data-v="19" data-xref="マタイによる福音書 7:7; ヨハネの第一の手紙 5:14–16; マルコによる福音書 11:24"> また、よく言っておく。もしあなたがたのうちのふたりが、どんな願い事についても地上で心を合わせるなら、天にいますわたしの父はそれをかなえて下さるであろう。</span>
<span className="v" id="v20" data-v="20" data-xref="コリント人への第一の手紙 5:4; ヨハネの黙示録 21:3; マタイによる福音書 28:20"> ふたりまたは三人が、わたしの名によって集まっている所には、わたしもその中にいるのである」。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="ルカによる福音書 17:3–4; マタイによる福音書 18:15"> そのとき、ペテロがイエスのもとにきて言った、「主よ、兄弟がわたしに対して罪を犯した場合、幾たびゆるさねばなりませんか。七たびまでですか」。</span>
<span className="v" id="v22" data-v="22" data-xref="コロサイ人への手紙 3:13; マルコによる福音書 11:25; マタイによる福音書 6:14–15"> イエスは彼に言われた、「わたしは七たびまでとは言わない。七たびを七十倍するまでにしなさい。</span>
<span className="v" id="v23" data-v="23" data-xref="マタイによる福音書 13:24; ローマ人への手紙 14:12; マタイによる福音書 3:2"> それだから、天国は王が僕たちと決算をするようなものだ。</span>
<span className="v" id="v24" data-v="24" data-xref="詩篇 38:4; 詩篇 130:3–4; ルカによる福音書 16:5"> 決算が始まると、一万タラントの負債のある者が、王のところに連れられてきた。</span>
<span className="v" id="v25" data-v="25" data-xref="列王紀下 4:1; ネヘミヤ書 5:5; ルカによる福音書 7:42"> しかし、返せなかったので、主人は、その人自身とその妻子と持ち物全部とを売って返すように命じた。</span>
<span className="v" id="v26" data-v="26" data-xref="マタイによる福音書 18:29; ルカによる福音書 7:43; マタイによる福音書 8:2"> そこで、この僕はひれ伏して哀願した、『どうぞお待ちください。全部お返しいたしますから』。</span>
<span className="v" id="v27" data-v="27" data-xref="詩篇 145:8; ネヘミヤ書 9:17; 詩篇 86:15"> 僕の主人はあわれに思って、彼をゆるし、その負債を免じてやった。</span>
<span className="v" id="v28" data-v="28" data-xref="マタイによる福音書 20:2; エゼキエル書 45:9; 申命記 15:2"> その僕が出て行くと、百デナリを貸しているひとりの仲間に出会い、彼をつかまえ、首をしめて『借金を返せ』と言った。</span>
<span className="v" id="v29" data-v="29" data-xref="マタイによる福音書 18:26; マタイによる福音書 6:12; ピレモンヘの手紙 1:18–19"> そこでこの仲間はひれ伏し、『どうか待ってくれ。返すから』と言って頼んだ。</span>
<span className="v" id="v30" data-v="30" data-xref="列王紀上 22:27; 列王紀上 21:27–29"> しかし承知せずに、その人をひっぱって行って、借金を返すまで獄に入れた。</span>
<span className="v" id="v31" data-v="31" data-xref="ローマ人への手紙 12:15; ヘブル人への手紙 13:3; マルコによる福音書 3:5"> その人の仲間たちは、この様子を見て、非常に心をいため、行ってそのことをのこらず主人に話した。</span>
<span className="v" id="v32" data-v="32" data-xref="ルカによる福音書 19:22; マタイによる福音書 25:26; ローマ人への手紙 3:19"> そこでこの主人は彼を呼びつけて言った、『悪い僕、わたしに願ったからこそ、あの負債を全部ゆるしてやったのだ。</span>
<span className="v" id="v33" data-v="33" data-xref="コロサイ人への手紙 3:13; マタイによる福音書 6:12; エペソ人への手紙 4:32–2"> わたしがあわれんでやったように、あの仲間をあわれんでやるべきではなかったか』。</span>
<span className="v" id="v34" data-v="34" data-xref="マタイによる福音書 5:25–26; ヤコブの手紙 2:13; ルカによる福音書 12:58–59"> そして主人は立腹して、負債全部を返してしまうまで、彼を獄吏に引きわたした。</span>
<span className="v" id="v35" data-v="35" data-xref="マタイによる福音書 6:14–15; ヤコブの手紙 2:13; ルカによる福音書 6:37–38"> あなたがためいめいも、もし心から兄弟をゆるさないならば、わたしの天の父もまたあなたがたに対して、そのようになさるであろう」。</span>
</div>

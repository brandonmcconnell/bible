<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命記 23:25; マルコによる福音書 2:23–28; ルカによる福音書 6:1–5"> そのころ、ある安息日に、イエスは麦畑の中を通られた。すると弟子たちは、空腹であったので、穂を摘んで食べはじめた。</span>
<span className="v" id="v2" data-v="2" data-xref="マタイによる福音書 12:10; ヨハネによる福音書 7:21–24; ルカによる福音書 14:3"> パリサイ人たちがこれを見て、イエスに言った、「ごらんなさい、あなたの弟子たちが、安息日にしてはならないことをしています」。</span>
<span className="v" id="v3" data-v="3" data-xref="サムエル記上 21:3–6; ルカによる福音書 6:3; マルコによる福音書 2:25–26"> そこでイエスは彼らに言われた、「あなたがたは、ダビデとその供の者たちとが飢えたとき、ダビデが何をしたか読んだことがないのか。</span>
<span className="v" id="v4" data-v="4" data-xref="レビ記 24:5–9; 出エジプト記 25:30; レビ記 8:31"> すなわち、神の家にはいって、祭司たちのほか、自分も供の者たちも食べてはならぬ供えのパンを食べたのである。</span>
<span className="v" id="v5" data-v="5" data-xref="民数記 28:9–10; ヨハネによる福音書 7:22–23; ネヘミヤ書 13:17"> また、安息日に宮仕えをしている祭司たちは安息日を破っても罪にはならないことを、律法で読んだことがないのか。</span>
<span className="v" id="v6" data-v="6" data-xref="マタイによる福音書 12:41–42; 歴代志下 6:18; ペテロの第一の手紙 2:4–5"> あなたがたに言っておく。宮よりも大いなる者がここにいる。</span>
<span className="v" id="v7" data-v="7" data-xref="ホセア書 6:6; マタイによる福音書 9:13; ミカ書 6:6–8"> 『わたしが好むのは、あわれみであって、いけにえではない』とはどういう意味か知っていたなら、あなたがたは罪のない者をとがめなかったであろう。</span>
<span className="v" id="v8" data-v="8" data-xref="マルコによる福音書 2:28; ルカによる福音書 6:5; ヨハネによる福音書 5:17–23"> 人の子は安息日の主である」。</span>
</div>
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="マルコによる福音書 3:1–6; ルカによる福音書 6:6–11"> イエスはそこを去って、彼らの会堂にはいられた。</span>
<span className="v" id="v10" data-v="10" data-xref="ルカによる福音書 13:14; ヨハネによる福音書 9:16; ヨハネによる福音書 8:6"> すると、そのとき、片手のなえた人がいた。人々はイエスを訴えようと思って、「安息日に人をいやしても、さしつかえないか」と尋ねた。</span>
<span className="v" id="v11" data-v="11" data-xref="申命記 22:4; ルカによる福音書 14:5; ルカによる福音書 13:15–17"> イエスは彼らに言われた、「あなたがたのうちに、一匹の羊を持っている人があるとして、もしそれが安息日に穴に落ちこんだなら、手をかけて引き上げてやらないだろうか。</span>
<span className="v" id="v12" data-v="12" data-xref="マタイによる福音書 6:26; ルカによる福音書 6:9; マルコによる福音書 3:4"> 人は羊よりも、はるかにすぐれているではないか。だから、安息日に良いことをするのは、正しいことである」。</span>
<span className="v" id="v13" data-v="13" data-xref="ルカによる福音書 13:13; 使徒行伝 3:7–8"> そしてイエスはその人に、「手を伸ばしなさい」と言われた。そこで手を伸ばすと、ほかの手のように良くなった。</span>
<span className="v" id="v14" data-v="14" data-xref="ヨハネによる福音書 11:53; ヨハネによる福音書 10:39; マルコによる福音書 3:6"> パリサイ人たちは出て行って、なんとかしてイエスを殺そうと相談した。</span>
<span className="v" id="v15" data-v="15" data-xref="マルコによる福音書 3:7–12; マタイによる福音書 10:23; マタイによる福音書 19:2"> イエスはこれを知って、そこを去って行かれた。ところが多くの人々がついてきたので、彼らを皆いやし、</span>
<span className="v" id="v16" data-v="16" data-xref="マタイによる福音書 8:4; マタイによる福音書 9:30; マタイによる福音書 17:9"> そして自分のことを人々にあらわさないようにと、彼らを戒められた。</span>
<span className="v" id="v17" data-v="17" data-xref="イザヤ書 42:1–4; イザヤ書 42:9; マタイによる福音書 13:35"> これは預言者イザヤの言った言葉が、成就するためである、</span>
<span className="v" id="v18" data-v="18" data-xref="イザヤ書 42:1; ルカによる福音書 4:18; 使徒行伝 10:38"> <span className="pl pl-1">「見よ、わたしが選んだ僕、</span><br /><span className="pl pl-1">わたしの心にかなう、愛する者。</span><br /><span className="pl pl-1">わたしは彼にわたしの霊を授け、</span><br /><span className="pl pl-1">そして彼は正義を異邦人に宣べ伝えるであろう。</span></span>
<span className="v" id="v19" data-v="19" data-xref="マタイによる福音書 11:29; ヨハネによる福音書 18:36–38; テモテヘの第二の手紙 2:24–25"> <span className="pl pl-1">彼は争わず、叫ばず、</span><br /><span className="pl pl-1">またその声を大路で聞く者はない。</span></span>
<span className="v" id="v20" data-v="20" data-xref="イザヤ書 42:3–4; エゼキエル書 34:16; イザヤ書 61:1–3"> <span className="pl pl-1">彼が正義に勝ちを得させる時まで、</span><br /><span className="pl pl-1">いためられた葦を折ることがなく、</span><br /><span className="pl pl-1">煙っている燈心を消すこともない。</span></span>
<span className="v" id="v21" data-v="21" data-xref="イザヤ書 11:10; ローマ人への手紙 15:12–13; イザヤ書 42:4"> <span className="pl pl-1">異邦人は彼の名に望みを置くであろう」。</span></span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="ルカによる福音書 11:14–15; マルコによる福音書 7:35–37; イザヤ書 29:18"> そのとき、人々が悪霊につかれた盲人のおしを連れてきたので、イエスは彼をいやして、物を言い、また目が見えるようにされた。</span>
<span className="v" id="v23" data-v="23" data-xref="マタイによる福音書 9:27; ヨハネによる福音書 4:29; マタイによる福音書 22:42–43"> すると群衆はみな驚いて言った、「この人が、あるいはダビデの子ではあるまいか」。</span>
<span className="v" id="v24" data-v="24" data-xref="マルコによる福音書 3:22; マタイによる福音書 9:34; ルカによる福音書 11:15"> しかし、パリサイ人たちは、これを聞いて言った、「この人が悪霊を追い出しているのは、まったく悪霊のかしらベルゼブルによるのだ」。</span>
<span className="v" id="v25" data-v="25" data-xref="ガラテヤ人への手紙 5:15; エレミヤ書 17:10; マタイによる福音書 9:4"> イエスは彼らの思いを見抜いて言われた、「おおよそ、内部で分れ争う国は自滅し、内わで分れ争う町や家は立ち行かない。</span>
<span className="v" id="v26" data-v="26" data-xref="コロサイ人への手紙 1:13; ヨハネの黙示録 20:2–3; ヨハネの第一の手紙 5:19"> もしサタンがサタンを追い出すならば、それは内わで分れ争うことになる。それでは、その国はどうして立ち行けよう。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行伝 19:13–16; マルコによる福音書 9:38–39; ルカによる福音書 9:49–50"> もしわたしがベルゼブルによって悪霊を追い出すとすれば、あなたがたの仲間はだれによって追い出すのであろうか。だから、彼らがあなたがたをさばく者となるであろう。</span>
<span className="v" id="v28" data-v="28" data-xref="ルカによる福音書 11:20; ダニエル書 7:14; マタイによる福音書 6:33"> しかし、わたしが神の霊によって悪霊を追い出しているのなら、神の国はすでにあなたがたのところにきたのである。</span>
<span className="v" id="v29" data-v="29" data-xref="イザヤ書 49:24; マルコによる福音書 3:27; ルカによる福音書 11:21–22"> まただれでも、まず強い人を縛りあげなければ、どうして、その人の家に押し入って家財を奪い取ることができようか。縛ってから、はじめてその家を掠奪することができる。</span>
<span className="v" id="v30" data-v="30" data-xref="マルコによる福音書 9:40; ルカによる福音書 11:23; ヨシュア記 24:15"> わたしの味方でない者は、わたしに反対するものであり、わたしと共に集めない者は、散らすものである。</span>
<span className="v" id="v31" data-v="31" data-xref="ルカによる福音書 12:10; マルコによる福音書 3:28–30; ヘブル人への手紙 10:29"> だから、あなたがたに言っておく。人には、その犯すすべての罪も神を汚す言葉も、ゆるされる。しかし、聖霊を汚す言葉は、ゆるされることはない。</span>
<span className="v" id="v32" data-v="32" data-xref="マルコによる福音書 3:29; ヘブル人への手紙 10:26–29; ヘブル人への手紙 6:4–6"> また人の子に対して言い逆らう者は、ゆるされるであろう。しかし、聖霊に対して言い逆らう者は、この世でも、きたるべき世でも、ゆるされることはない。</span>
<span className="v" id="v33" data-v="33" data-xref="ルカによる福音書 6:43–44; マタイによる福音書 7:16–20; ヤコブの手紙 4:8"> 木が良ければ、その実も良いとし、木が悪ければ、その実も悪いとせよ。木はその実でわかるからである。</span>
<span className="v" id="v34" data-v="34" data-xref="ルカによる福音書 6:45; マタイによる福音書 15:18; エペソ人への手紙 4:29"> まむしの子らよ。あなたがたは悪い者であるのに、どうして良いことを語ることができようか。おおよそ、心からあふれることを、口が語るものである。</span>
<span className="v" id="v35" data-v="35" data-xref="箴言 15:4; コロサイ人への手紙 4:6; 箴言 15:28"> 善人はよい倉から良い物を取り出し、悪人は悪い倉から悪い物を取り出す。</span>
<span className="v" id="v36" data-v="36" data-xref="伝道の書 12:14; ローマ人への手紙 2:16; ヨハネの黙示録 20:12"> あなたがたに言うが、審判の日には、人はその語る無益な言葉に対して、言い開きをしなければならないであろう。</span>
<span className="v" id="v37" data-v="37" data-xref="箴言 13:3; ヤコブの手紙 2:21–25"> あなたは、自分の言葉によって正しいとされ、また自分の言葉によって罪ありとされるからである」。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="コリント人への第一の手紙 1:22; マルコによる福音書 8:11–12; ルカによる福音書 11:16"> そのとき、律法学者、パリサイ人のうちのある人々がイエスにむかって言った、「先生、わたしたちはあなたから、しるしを見せていただきとうございます」。</span>
<span className="v" id="v39" data-v="39" data-xref="マタイによる福音書 16:4; ルカによる福音書 11:29–32; マルコによる福音書 8:38"> すると、彼らに答えて言われた、「邪悪で不義な時代は、しるしを求める。しかし、預言者ヨナのしるしのほかには、なんのしるしも与えられないであろう。</span>
<span className="v" id="v40" data-v="40" data-xref="ヨナ書 1:17; マタイによる福音書 27:63–64; マタイによる福音書 16:21"> すなわち、ヨナが三日三晩、大魚の腹の中にいたように、人の子も三日三晩、地の中にいるであろう。</span>
<span className="v" id="v41" data-v="41" data-xref="マタイによる福音書 12:42; ヘブル人への手紙 11:7; マタイによる福音書 12:6"> ニネベの人々が、今の時代の人々と共にさばきの場に立って、彼らを罪に定めるであろう。なぜなら、ニネベの人々はヨナの宣教によって悔い改めたからである。しかし見よ、ヨナにまさる者がここにいる。</span>
<span className="v" id="v42" data-v="42" data-xref="列王紀上 10:1–13; 歴代志下 9:1–12; ヘブル人への手紙 1:2–4"> 南の女王が、今の時代の人々と共にさばきの場に立って、彼らを罪に定めるであろう。なぜなら、彼女はソロモンの知恵を聞くために地の果から、はるばるきたからである。しかし見よ、ソロモンにまさる者がここにいる。</span>
<span className="v" id="v43" data-v="43" data-xref="ルカによる福音書 11:24–26; ルカによる福音書 8:28–32; マタイによる福音書 8:29"> 汚れた霊が人から出ると、休み場を求めて水の無い所を歩きまわるが、見つからない。</span>
<span className="v" id="v44" data-v="44" data-xref="ヨハネの第一の手紙 4:4; ヨハネの黙示録 13:8–9; ユダの手紙 1:4–5"> そこで、出てきた元の家に帰ろうと言って帰って見ると、その家はあいていて、そうじがしてある上、飾りつけがしてあった。</span>
<span className="v" id="v45" data-v="45" data-xref="ルカによる福音書 11:26; マルコによる福音書 5:9; ヘブル人への手紙 6:4–8"> そこでまた出て行って、自分以上に悪い他の七つの霊を一緒に引き連れてきて中にはいり、そこに住み込む。そうすると、その人ののちの状態は初めよりももっと悪くなるのである。よこしまな今の時代も、このようになるであろう」。</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="マタイによる福音書 13:55; ヨハネによる福音書 2:12; ヨハネによる福音書 7:3"> イエスがまだ群衆に話しておられるとき、その母と兄弟たちとが、イエスに話そうと思って外に立っていた。</span>
<span className="v" id="v47" data-v="47"> それで、ある人がイエスに言った、「ごらんなさい。あなたの母上と兄弟がたが、あなたに話そうと思って、外に立っておられます」。</span>
<span className="v" id="v48" data-v="48" data-xref="マルコによる福音書 3:32–33; マタイによる福音書 10:37; ルカによる福音書 2:52"> イエスは知らせてくれた者に答えて言われた、「わたしの母とは、だれのことか。わたしの兄弟とは、だれのことか」。</span>
<span className="v" id="v49" data-v="49" data-xref="マルコによる福音書 3:34; ヨハネによる福音書 17:8–9; ヨハネによる福音書 20:17–20"> そして、弟子たちの方に手をさし伸べて言われた、「ごらんなさい。ここにわたしの母、わたしの兄弟がいる。</span>
<span className="v" id="v50" data-v="50" data-xref="ルカによる福音書 8:21; マルコによる福音書 3:35; ヨハネによる福音書 15:14"> 天にいますわたしの父のみこころを行う者はだれでも、わたしの兄弟、また姉妹、また母なのである」。</span>

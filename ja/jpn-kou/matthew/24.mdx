<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マルコによる福音書 13:1–37; ルカによる福音書 21:5–36; エゼキエル書 8:6"> イエスが宮から出て行こうとしておられると、弟子たちは近寄ってきて、宮の建物にイエスの注意を促した。</span>
<span className="v" id="v2" data-v="2" data-xref="ルカによる福音書 19:44; エレミヤ書 26:18; ミカ書 3:12"> そこでイエスは彼らにむかって言われた、「あなたがたは、これらすべてのものを見ないか。よく言っておく。その石一つでもくずされずに、そこに他の石の上に残ることもなくなるであろう」。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="マルコによる福音書 13:3–4; 使徒行伝 1:7; テサロニケ人への第一の手紙 5:1–11"> またオリブ山ですわっておられると、弟子たちが、ひそかにみもとにきて言った、「どうぞお話しください。いつ、そんなことが起るのでしょうか。あなたがまたおいでになる時や、世の終りには、どんな前兆がありますか」。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネの第一の手紙 4:1; エレミヤ書 29:8; テサロニケ人への第二の手紙 2:3"> そこでイエスは答えて言われた、「人に惑わされないように気をつけなさい。</span>
<span className="v" id="v5" data-v="5" data-xref="マタイによる福音書 24:11; マタイによる福音書 24:24; エレミヤ書 14:14"> 多くの者がわたしの名を名のって現れ、自分がキリストだと言って、多くの人を惑わすであろう。</span>
<span className="v" id="v6" data-v="6" data-xref="マルコによる福音書 13:7–8; ルカによる福音書 21:9; ペテロの第一の手紙 3:14–15"> また、戦争と戦争のうわさとを聞くであろう。注意していなさい、あわててはいけない。それは起らねばならないが、まだ終りではない。</span>
<span className="v" id="v7" data-v="7" data-xref="ルカによる福音書 21:11; ヨハネの黙示録 6:8; イザヤ書 19:2"> 民は民に、国は国に敵対して立ち上がるであろう。またあちこちに、ききんが起り、また地震があるであろう。</span>
<span className="v" id="v8" data-v="8" data-xref="テサロニケ人への第一の手紙 5:3; ペテロの第一の手紙 4:17–18; 申命記 28:59"> しかし、すべてこれらは産みの苦しみの初めである。</span>
<span className="v" id="v9" data-v="9" data-xref="ヨハネによる福音書 16:2; ヨハネによる福音書 15:19–20; ルカによる福音書 21:16–17"> そのとき人々は、あなたがたを苦しみにあわせ、また殺すであろう。またあなたがたは、わたしの名のゆえにすべての民に憎まれるであろう。</span>
<span className="v" id="v10" data-v="10" data-xref="ミカ書 7:5–6; ルカによる福音書 21:16; マタイによる福音書 11:6"> そのとき、多くの人がつまずき、また互に裏切り、憎み合うであろう。</span>
<span className="v" id="v11" data-v="11" data-xref="マタイによる福音書 24:24; マタイによる福音書 7:15; マタイによる福音書 24:5"> また多くのにせ預言者が起って、多くの人を惑わすであろう。</span>
<span className="v" id="v12" data-v="12" data-xref="ヨハネの黙示録 2:4–5; ヤコブの手紙 4:1–4; ヨハネの黙示録 3:15"> また不法がはびこるので、多くの人の愛が冷えるであろう。</span>
<span className="v" id="v13" data-v="13" data-xref="マタイによる福音書 10:22; マルコによる福音書 13:13; ヨハネの黙示録 2:10"> しかし、最後まで耐え忍ぶ者は救われる。</span>
<span className="v" id="v14" data-v="14" data-xref="ヨハネの黙示録 14:6; ローマ人への手紙 10:18; ローマ人への手紙 16:25–26"> そしてこの御国の福音は、すべての民に対してあかしをするために、全世界に宣べ伝えられるであろう。そしてそれから最後が来るのである。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="ダニエル書 9:27; ダニエル書 12:11; マルコによる福音書 13:14"> 預言者ダニエルによって言われた荒らす憎むべき者が、聖なる場所に立つのを見たならば（読者よ、悟れ）、</span>
<span className="v" id="v16" data-v="16" data-xref="創世記 19:15–17; ルカによる福音書 21:21–22; ヘブル人への手紙 11:7"> そのとき、ユダヤにいる人々は山へ逃げよ。</span>
<span className="v" id="v17" data-v="17" data-xref="ルカによる福音書 17:31–33; マルコによる福音書 13:15–16; マタイによる福音書 10:27"> 屋上にいる者は、家からものを取り出そうとして下におりるな。</span>
<span className="v" id="v18" data-v="18"> 畑にいる者は、上着を取りにあとへもどるな。</span>
<span className="v" id="v19" data-v="19" data-xref="ルカによる福音書 23:29–30; 申命記 28:53–56; ルカによる福音書 21:23"> その日には、身重の女と乳飲み子をもつ女とは、不幸である。</span>
<span className="v" id="v20" data-v="20" data-xref="出エジプト記 16:29; 使徒行伝 1:12"> あなたがたの逃げるのが、冬または安息日にならないように祈れ。</span>
<span className="v" id="v21" data-v="21" data-xref="ダニエル書 12:1; ヨエル書 2:2; マラキ書 4:1"> その時には、世の初めから現在に至るまで、かつてなく今後もないような大きな患難が起るからである。</span>
<span className="v" id="v22" data-v="22" data-xref="マルコによる福音書 13:20; テモテヘの第二の手紙 2:10; マタイによる福音書 24:31"> もしその期間が縮められないなら、救われる者はひとりもないであろう。しかし、選民のためには、その期間が縮められるであろう。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="ルカによる福音書 21:8; ルカによる福音書 17:23–24; 申命記 13:1–3"> そのとき、だれかがあなたがたに『見よ、ここにキリストがいる』、また、『あそこにいる』と言っても、それを信じるな。</span>
<span className="v" id="v24" data-v="24" data-xref="テサロニケ人への第二の手紙 2:9–11; マルコによる福音書 13:22; ヨハネの黙示録 13:13–14"> にせキリストたちや、にせ預言者たちが起って、大いなるしるしと奇跡とを行い、できれば、選民をも惑わそうとするであろう。</span>
<span className="v" id="v25" data-v="25" data-xref="ヨハネによる福音書 16:1; ルカによる福音書 21:13; イザヤ書 48:5–6"> 見よ、あなたがたに前もって言っておく。</span>
<span className="v" id="v26" data-v="26" data-xref="ルカによる福音書 3:2–3; イザヤ書 40:3; マタイによる福音書 3:1"> だから、人々が『見よ、彼は荒野にいる』と言っても、出て行くな。また『見よ、へやの中にいる』と言っても、信じるな。</span>
<span className="v" id="v27" data-v="27" data-xref="ルカによる福音書 17:24–37; ゼカリヤ書 9:14; ヨブ記 37:3"> ちょうど、いなずまが東から西にひらめき渡るように、人の子も現れるであろう。</span>
<span className="v" id="v28" data-v="28" data-xref="ルカによる福音書 17:37; ヨブ記 39:27–30; 申命記 28:49"> 死体のあるところには、はげたかが集まるものである。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="アモス書 8:9; ヨエル書 3:15; イザヤ書 13:10"> しかし、その時に起る患難の後、たちまち日は暗くなり、月はその光を放つことをやめ、星は空から落ち、天体は揺り動かされるであろう。</span>
<span className="v" id="v30" data-v="30" data-xref="ヨハネの黙示録 1:7; ダニエル書 7:13; ルカによる福音書 21:27"> そのとき、人の子のしるしが天に現れるであろう。またそのとき、地のすべての民族は嘆き、そして力と大いなる栄光とをもって、人の子が天の雲に乗って来るのを、人々は見るであろう。</span>
<span className="v" id="v31" data-v="31" data-xref="テサロニケ人への第一の手紙 4:16; マルコによる福音書 13:27; イザヤ書 27:13"> また、彼は大いなるラッパの音と共に御使たちをつかわして、天のはてからはてに至るまで、四方からその選民を呼び集めるであろう。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="マルコによる福音書 13:28–29; ルカによる福音書 21:29–30"> いちじくの木からこの譬を学びなさい。その枝が柔らかになり、葉が出るようになると、夏の近いことがわかる。</span>
<span className="v" id="v33" data-v="33" data-xref="ヤコブの手紙 5:9; ヘブル人への手紙 10:37; エゼキエル書 7:2–14"> そのように、すべてこれらのことを見たならば、人の子が戸口まで近づいていると知りなさい。</span>
<span className="v" id="v34" data-v="34" data-xref="マルコによる福音書 13:30–31; ルカによる福音書 21:32–33; マタイによる福音書 16:28"> よく聞いておきなさい。これらの事が、ことごとく起るまでは、この時代は滅びることがない。</span>
<span className="v" id="v35" data-v="35" data-xref="イザヤ書 40:8; ペテロの第一の手紙 1:25; 民数記 23:19"> 天地は滅びるであろう。しかしわたしの言葉は滅びることがない。</span>
<span className="v" id="v36" data-v="36" data-xref="マルコによる福音書 13:32; 使徒行伝 1:7; マタイによる福音書 24:44"> その日、その時は、だれも知らない。天の御使たちも、また子も知らない、ただ父だけが知っておられる。</span>
<span className="v" id="v37" data-v="37" data-xref="ルカによる福音書 17:26–27; 創世記 6:1–7; ペテロの第二の手紙 2:5"> 人の子の現れるのも、ちょうどノアの時のようであろう。</span>
<span className="v" id="v38" data-v="38" data-xref="ルカによる福音書 17:26–28; ローマ人への手紙 13:13–14; ルカによる福音書 14:18–20"> すなわち、洪水の出る前、ノアが箱舟にはいる日まで、人々は食い、飲み、めとり、とつぎなどしていた。</span>
<span className="v" id="v39" data-v="39" data-xref="ヨハネによる福音書 3:20; マタイによる福音書 24:37; 使徒行伝 13:41"> そして洪水が襲ってきて、いっさいのものをさらって行くまで、彼らは気がつかなかった。人の子の現れるのも、そのようであろう。</span>
<span className="v" id="v40" data-v="40" data-xref="ルカによる福音書 17:34–37; ペテロの第二の手紙 2:7–9; ペテロの第二の手紙 2:5"> そのとき、ふたりの者が畑にいると、ひとりは取り去られ、ひとりは取り残されるであろう。</span>
<span className="v" id="v41" data-v="41" data-xref="出エジプト記 11:5; イザヤ書 47:2; ルカによる福音書 17:35"> ふたりの女がうすをひいていると、ひとりは取り去られ、ひとりは残されるであろう。</span>
<span className="v" id="v42" data-v="42" data-xref="ルカによる福音書 21:36; テサロニケ人への第一の手紙 5:6; マタイによる福音書 25:13"> だから、目をさましていなさい。いつの日にあなたがたの主がこられるのか、あなたがたには、わからないからである。</span>
<span className="v" id="v43" data-v="43" data-xref="ルカによる福音書 12:39; マタイによる福音書 24:44; テサロニケ人への第一の手紙 5:2–6"> このことをわきまえているがよい。家の主人は、盗賊がいつごろ来るかわかっているなら、目をさましていて、自分の家に押し入ることを許さないであろう。</span>
<span className="v" id="v44" data-v="44" data-xref="マタイによる福音書 25:10; マタイによる福音書 24:42; マタイによる福音書 25:13"> だから、あなたがたも用意をしていなさい。思いがけない時に人の子が来るからである。</span>
<span className="v" id="v45" data-v="45" data-xref="マタイによる福音書 25:21; マタイによる福音書 25:23; コリント人への第一の手紙 4:1–2"> 主人がその家の僕たちの上に立てて、時に応じて食物をそなえさせる忠実な思慮深い僕は、いったい、だれであろう。</span>
<span className="v" id="v46" data-v="46" data-xref="ヨハネの黙示録 16:15; ルカによる福音書 12:43; ルカによる福音書 12:37"> 主人が帰ってきたとき、そのようにつとめているのを見られる僕は、さいわいである。</span>
<span className="v" id="v47" data-v="47" data-xref="マタイによる福音書 25:23; マタイによる福音書 25:21; ルカによる福音書 12:37"> よく言っておくが、主人は彼を立てて自分の全財産を管理させるであろう。</span>
<span className="v" id="v48" data-v="48" data-xref="マタイによる福音書 18:32; イザヤ書 32:6; ルカによる福音書 12:45"> もしそれが悪い僕であって、自分の主人は帰りがおそいと心の中で思い、</span>
<span className="v" id="v49" data-v="49" data-xref="ヨハネの黙示録 17:6; ヨハネの黙示録 16:6; ミカ書 3:5"> その僕仲間をたたきはじめ、また酒飲み仲間と一緒に食べたり飲んだりしているなら、</span>
<span className="v" id="v50" data-v="50" data-xref="テサロニケ人への第一の手紙 5:2–3; ヨハネの黙示録 3:3; マタイによる福音書 24:42–44"> その僕の主人は思いがけない日、気がつかない時に帰ってきて、</span>
<span className="v" id="v51" data-v="51" data-xref="マタイによる福音書 8:12; マタイによる福音書 22:13; ルカによる福音書 12:46"> 彼を厳罰に処し、偽善者たちと同じ目にあわせるであろう。彼はそこで泣き叫んだり、歯がみをしたりするであろう。</span>
</div>

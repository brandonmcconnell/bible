<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ルカによる福音書 11:16; マタイによる福音書 16:6; 使徒行伝 4:1"> パリサイ人とサドカイ人とが近寄ってきて、イエスを試み、天からのしるしを見せてもらいたいと言った。</span>
<span className="v" id="v2" data-v="2" data-xref="ルカによる福音書 12:54–56"> イエスは彼らに言われた、「あなたがたは夕方になると、『空がまっかだから、晴だ』と言い、</span>
<span className="v" id="v3" data-v="3" data-xref="ルカによる福音書 12:56; 歴代志上 12:32; マタイによる福音書 11:5"> また明け方には『空が曇ってまっかだから、きょうは荒れだ』と言う。あなたがたは空の模様を見分けることを知りながら、時のしるしを見分けることができないのか。</span>
<span className="v" id="v4" data-v="4" data-xref="ルカによる福音書 11:29–30; マタイによる福音書 12:39–40; ヨナ書 1:17"> 邪悪で不義な時代は、しるしを求める。しかし、ヨナのしるしのほかには、なんのしるしも与えられないであろう」。そして、イエスは彼らをあとに残して立ち去られた。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="マルコによる福音書 8:13–14; マタイによる福音書 15:39"> 弟子たちは向こう岸に行ったが、パンを持って来るのを忘れていた。</span>
<span className="v" id="v6" data-v="6" data-xref="ルカによる福音書 12:1; ガラテヤ人への手紙 5:9; マタイによる福音書 16:12"> そこでイエスは言われた、「パリサイ人とサドカイ人とのパン種を、よくよく警戒せよ」。</span>
<span className="v" id="v7" data-v="7" data-xref="マルコによる福音書 8:16–18; マタイによる福音書 15:16–18; 使徒行伝 10:14"> 弟子たちは、これは自分たちがパンを持ってこなかったためであろうと言って、互に論じ合った。</span>
<span className="v" id="v8" data-v="8" data-xref="マタイによる福音書 6:30; マタイによる福音書 14:31; マタイによる福音書 8:26"> イエスはそれと知って言われた、「信仰の薄い者たちよ、なぜパンがないからだと互に論じ合っているのか。</span>
<span className="v" id="v9" data-v="9" data-xref="マタイによる福音書 14:17–21; ヨハネによる福音書 6:9–13; ルカによる福音書 9:13–17"> まだわからないのか。覚えていないのか。五つのパンを五千人に分けたとき、幾かご拾ったか。</span>
<span className="v" id="v10" data-v="10" data-xref="マタイによる福音書 15:34–38; マルコによる福音書 8:17–21; マルコによる福音書 8:5–9"> また、七つのパンを四千人に分けたとき、幾かご拾ったか。</span>
<span className="v" id="v11" data-v="11" data-xref="マタイによる福音書 16:6; ルカによる福音書 12:56; マルコによる福音書 8:21"> わたしが言ったのは、パンについてではないことを、どうして悟らないのか。ただ、パリサイ人とサドカイ人とのパン種を警戒しなさい」。</span>
<span className="v" id="v12" data-v="12" data-xref="マタイによる福音書 5:20; 使徒行伝 23:8; マタイによる福音書 15:4–9"> そのとき彼らは、イエスが警戒せよと言われたのは、パン種のことではなく、パリサイ人とサドカイ人との教のことであると悟った。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="ルカによる福音書 9:18–20; マルコによる福音書 8:27–29; ダニエル書 7:13"> イエスがピリポ・カイザリヤの地方に行かれたとき、弟子たちに尋ねて言われた、「人々は人の子をだれと言っているか」。</span>
<span className="v" id="v14" data-v="14" data-xref="マルコによる福音書 6:15; マタイによる福音書 14:2; マラキ書 4:5"> 彼らは言った、「ある人々はバプテスマのヨハネだと言っています。しかし、ほかの人たちは、エリヤだと言い、また、エレミヤあるいは預言者のひとりだ、と言っている者もあります」。</span>
<span className="v" id="v15" data-v="15" data-xref="ルカによる福音書 9:20; マタイによる福音書 13:11; マルコによる福音書 8:29"> そこでイエスは彼らに言われた、「それでは、あなたがたはわたしをだれと言うか」。</span>
<span className="v" id="v16" data-v="16" data-xref="マタイによる福音書 14:33; ヨハネによる福音書 11:27; ヨハネの第一の手紙 4:15"> シモン・ペテロが答えて言った、「あなたこそ、生ける神の子キリストです」。</span>
<span className="v" id="v17" data-v="17" data-xref="ヨハネによる福音書 6:45; エペソ人への手紙 1:17–18; マタイによる福音書 11:25–27"> すると、イエスは彼にむかって言われた、「バルヨナ・シモン、あなたはさいわいである。あなたにこの事をあらわしたのは、血肉ではなく、天にいますわたしの父である。</span>
<span className="v" id="v18" data-v="18" data-xref="エペソ人への手紙 2:19–22; コリント人への第一の手紙 3:9–11; イザヤ書 28:16"> そこで、わたしもあなたに言う。あなたはペテロである。そして、わたしはこの岩の上にわたしの教会を建てよう。黄泉の力もそれに打ち勝つことはない。</span>
<span className="v" id="v19" data-v="19" data-xref="マタイによる福音書 18:18; イザヤ書 22:22; ヨハネの黙示録 1:18"> わたしは、あなたに天国のかぎを授けよう。そして、あなたが地上でつなぐことは、天でもつながれ、あなたが地上で解くことは天でも解かれるであろう」。</span>
<span className="v" id="v20" data-v="20" data-xref="マルコによる福音書 8:30; ルカによる福音書 9:21; ヨハネによる福音書 1:41"> そのとき、イエスは、自分がキリストであることをだれにも言ってはいけないと、弟子たちを戒められた。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="ルカによる福音書 24:6–7; マタイによる福音書 20:17–19; マタイによる福音書 17:22–23"> この時から、イエス・キリストは、自分が必ずエルサレムに行き、長老、祭司長、律法学者たちから多くの苦しみを受け、殺され、そして三日目によみがえるべきことを、弟子たちに示しはじめられた。</span>
<span className="v" id="v22" data-v="22" data-xref="マルコによる福音書 8:32; ヨハネによる福音書 13:6–8; マタイによる福音書 16:16–17"> すると、ペテロはイエスをわきへ引き寄せて、いさめはじめ、「主よ、とんでもないことです。そんなことがあるはずはございません」と言った。</span>
<span className="v" id="v23" data-v="23" data-xref="ローマ人への手紙 8:5–8; コロサイ人への手紙 3:2; ピリピ人への手紙 3:19"> イエスは振り向いて、ペテロに言われた、「サタンよ、引きさがれ。わたしの邪魔をする者だ。あなたは神のことを思わないで、人のことを思っている」。</span>
<span className="v" id="v24" data-v="24" data-xref="マタイによる福音書 10:38; ルカによる福音書 14:27; ペテロの第一の手紙 4:1–2"> それからイエスは弟子たちに言われた、「だれでもわたしについてきたいと思うなら、自分を捨て、自分の十字架を負うて、わたしに従ってきなさい。</span>
<span className="v" id="v25" data-v="25" data-xref="マタイによる福音書 10:39; マルコによる福音書 8:35; ヨハネの黙示録 12:11"> 自分の命を救おうと思う者はそれを失い、わたしのために自分の命を失う者は、それを見いだすであろう。</span>
<span className="v" id="v26" data-v="26" data-xref="マルコによる福音書 8:36–37; ヨブ記 27:8; ルカによる福音書 9:25"> たとい人が全世界をもうけても、自分の命を損したら、なんの得になろうか。また、人はどんな代価を払って、その命を買いもどすことができようか。</span>
<span className="v" id="v27" data-v="27" data-xref="コリント人への第二の手紙 5:10; 詩篇 62:12; ローマ人への手紙 2:6"> 人の子は父の栄光のうちに、御使たちを従えて来るが、その時には、実際のおこないに応じて、それぞれに報いるであろう。</span>
<span className="v" id="v28" data-v="28" data-xref="ルカによる福音書 9:27; マルコによる福音書 9:1; ヨハネによる福音書 8:52"> よく聞いておくがよい、人の子が御国の力をもって来るのを見るまでは、死を味わわない者が、ここに立っている者の中にいる」。</span>
</div>

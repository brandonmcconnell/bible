<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="使徒行伝 7:8; ヘブル人への手紙 11:17–18; 創世記 46:8–27"> アブラハムはイサクの父であり、イサクはヤコブの父、ヤコブはユダとその兄弟たちとの父、</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 46:12; 創世記 38:29–30; 歴代志上 4:1"> ユダはタマルによるパレスとザラとの父、パレスはエスロンの父、エスロンはアラムの父、</span>
<span className="v" id="v4" data-v="4" data-xref="歴代志上 2:10–12; 民数記 7:12; 民数記 2:3"> アラムはアミナダブの父、アミナダブはナアソンの父、ナアソンはサルモンの父、</span>
<span className="v" id="v5" data-v="5" data-xref="ヘブル人への手紙 11:31; ルツ記 1:16–17; ヤコブの手紙 2:25"> サルモンはラハブによるボアズの父、ボアズはルツによるオベデの父、オベデはエッサイの父、</span>
<span className="v" id="v6" data-v="6" data-xref="列王紀上 15:5; サムエル記上 17:12; サムエル記下 12:24–25"> エッサイはダビデ王の父であった。<br />ダビデはウリヤの妻によるソロモンの父であり、</span>
<span className="v" id="v7" data-v="7" data-xref="歴代志下 14:1–15; 列王紀上 14:31; 列王紀上 11:43–24"> ソロモンはレハベアムの父、レハベアムはアビヤの父、アビヤはアサの父、</span>
<span className="v" id="v8" data-v="8" data-xref="歴代志上 3:11; 歴代志下 26:1–23; 列王紀下 8:16"> アサはヨサパテの父、ヨサパテはヨラムの父、ヨラムはウジヤの父、</span>
<span className="v" id="v9" data-v="9" data-xref="イザヤ書 7:1–13; 歴代志下 26:21; 歴代志下 27:1–32"> ウジヤはヨタムの父、ヨタムはアハズの父、アハズはヒゼキヤの父、</span>
<span className="v" id="v10" data-v="10" data-xref="歴代志下 32:33–27; 列王紀上 13:2; 歴代志上 3:13–15"> ヒゼキヤはマナセの父、マナセはアモンの父、アモンはヨシヤの父、</span>
<span className="v" id="v11" data-v="11" data-xref="エレミヤ書 27:20; エレミヤ書 52:28–30; ダニエル書 1:2"> ヨシヤはバビロンへ移されたころ、エコニヤとその兄弟たちとの父となった。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="歴代志上 3:17; エズラ記 3:2; ルカによる福音書 3:27"> バビロンへ移されたのち、エコニヤはサラテルの父となった。サラテルはゾロバベルの父、</span>
<span className="v" id="v13" data-v="13"> ゾロバベルはアビウデの父、アビウデはエリヤキムの父、エリヤキムはアゾルの父、</span>
<span className="v" id="v14" data-v="14"> アゾルはサドクの父、サドクはアキムの父、アキムはエリウデの父、</span>
<span className="v" id="v15" data-v="15"> エリウデはエレアザルの父、エレアザルはマタンの父、マタンはヤコブの父、</span>
<span className="v" id="v16" data-v="16" data-xref="マタイによる福音書 27:17; ヨハネによる福音書 4:25; ルカによる福音書 3:23"> ヤコブはマリヤの夫ヨセフの父であった。このマリヤからキリストといわれるイエスがお生れになった。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="マタイによる福音書 1:11–12; 列王紀下 24:14; マタイによる福音書 11:2"> だから、アブラハムからダビデまでの代は合わせて十四代、ダビデからバビロンへ移されるまでは十四代、そして、バビロンへ移されてからキリストまでは十四代である。</span>
</div>
<div className="bp poetry">
<span className="v" id="v18" data-v="18" data-xref="ガラテヤ人への手紙 4:4–5; ルカによる福音書 1:27–38; ヨブ記 14:4"> イエス・キリストの誕生の次第はこうであった。母マリヤはヨセフと婚約していたが、まだ一緒にならない前に、聖霊によって身重になった。</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 22:21–24; 申命記 24:1–4; ヨハネによる福音書 8:4–5"> 夫ヨセフは正しい人であったので、彼女のことが公けになることを好まず、ひそかに離縁しようと決心した。</span>
<span className="v" id="v20" data-v="20" data-xref="箴言 3:5–6; ルカによる福音書 1:19; マタイによる福音書 1:18"> 彼がこのことを思いめぐらしていたとき、主の使が夢に現れて言った、「ダビデの子ヨセフよ、心配しないでマリヤを妻として迎えるがよい。その胎内に宿っているものは聖霊によるのである。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行伝 13:23; 使徒行伝 4:12; ヨハネによる福音書 1:29"> 彼女は男の子を産むであろう。その名をイエスと名づけなさい。彼は、おのれの民をそのもろもろの罪から救う者となるからである」。</span>
<span className="v" id="v22" data-v="22" data-xref="ルカによる福音書 24:44; マタイによる福音書 2:23; 列王紀上 8:15"> すべてこれらのことが起ったのは、主が預言者によって言われたことの成就するためである。すなわち、</span>
<span className="v" id="v23" data-v="23" data-xref="イザヤ書 7:14; イザヤ書 9:6–7; 詩篇 46:11"> <span className="pl pl-1">「見よ、おとめがみごもって男の子を産むであろう。</span><br /><span className="pl pl-1">その名はインマヌエルと呼ばれるであろう」。</span><br />これは、「神われらと共にいます」という意味である。</span>
<span className="v" id="v24" data-v="24" data-xref="ヨハネによる福音書 15:14; ヤコブの手紙 2:21–26; ヨハネによる福音書 2:5–8"> ヨセフは眠りからさめた後に、主の使が命じたとおりに、マリヤを妻に迎えた。</span>
<span className="v" id="v25" data-v="25" data-xref="ルカによる福音書 2:21; 出エジプト記 13:2; マタイによる福音書 1:21"> しかし、子が生れるまでは、彼女を知ることはなかった。そして、その子をイエスと名づけた。</span>

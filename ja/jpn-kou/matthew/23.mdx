<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ルカによる福音書 12:1; ルカによる福音書 20:45–46; マタイによる福音書 15:10–20"> そのときイエスは、群衆と弟子たちとに語って言われた、</span>
<span className="v" id="v2" data-v="2" data-xref="ルカによる福音書 20:46; マルコによる福音書 12:38; マラキ書 2:7"> 「律法学者とパリサイ人とは、モーセの座にすわっている。</span>
<span className="v" id="v3" data-v="3" data-xref="テモテヘの第二の手紙 3:5; テトスヘの手紙 1:16; ローマ人への手紙 2:19–24"> だから、彼らがあなたがたに言うことは、みな守って実行しなさい。しかし、彼らのすることには、ならうな。彼らは言うだけで、実行しないから。</span>
<span className="v" id="v4" data-v="4" data-xref="ルカによる福音書 11:46; 使徒行伝 15:10; ガラテヤ人への手紙 6:13"> また、重い荷物をくくって人々の肩にのせるが、それを動かすために、自分では指一本も貸そうとはしない。</span>
<span className="v" id="v5" data-v="5" data-xref="マタイによる福音書 6:1–16; ヨハネによる福音書 12:43; ピリピ人への手紙 2:3"> そのすることは、すべて人に見せるためである。すなわち、彼らは経札を幅広くつくり、その衣のふさを大きくし、</span>
<span className="v" id="v6" data-v="6" data-xref="ヨハネの第三の手紙 1:9; ルカによる福音書 11:43–54; マルコによる福音書 12:38–39"> また、宴会の上座、会堂の上席を好み、</span>
<span className="v" id="v7" data-v="7" data-xref="ヨハネによる福音書 1:38; ヨハネによる福音書 1:49; ヨハネによる福音書 3:26"> 広場であいさつされることや、人々から先生と呼ばれることを好んでいる。</span>
<span className="v" id="v8" data-v="8" data-xref="ヤコブの手紙 3:1; コリント人への第一の手紙 1:12–13; ペテロの第一の手紙 5:3"> しかし、あなたがたは先生と呼ばれてはならない。あなたがたの先生は、ただひとりであって、あなたがたはみな兄弟なのだから。</span>
<span className="v" id="v9" data-v="9" data-xref="ヨハネの第一の手紙 3:1; ヘブル人への手紙 12:9; マラキ書 1:6"> また、地上のだれをも、父と呼んではならない。あなたがたの父はただひとり、すなわち、天にいます父である。</span>
<span className="v" id="v10" data-v="10"> また、あなたがたは教師と呼ばれてはならない。あなたがたの教師はただひとり、すなわち、キリストである。</span>
<span className="v" id="v11" data-v="11" data-xref="コリント人への第一の手紙 9:19; ガラテヤ人への手紙 5:13; ヨハネによる福音書 13:14–15"> そこで、あなたがたのうちでいちばん偉い者は、仕える人でなければならない。</span>
<span className="v" id="v12" data-v="12" data-xref="ペテロの第一の手紙 5:5; ヤコブの手紙 4:6; 箴言 29:23"> だれでも自分を高くする者は低くされ、自分を低くする者は高くされるであろう。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="ルカによる福音書 11:52; マタイによる福音書 23:29; マタイによる福音書 23:23"> 偽善な律法学者、パリサイ人たちよ。あなたがたは、わざわいである。あなたがたは、天国を閉ざして人々をはいらせない。自分もはいらないし、はいろうとする人をはいらせもしない。〔</span>
<span className="v" id="v14" data-v="14"> 偽善な律法学者、パリサイ人たちよ。あなたがたは、わざわいである。あなたがたは、やもめたちの家を食い倒し、見えのために長い祈をする。だから、もっときびしいさばきを受けるに違いない。〕</span>
<span className="v" id="v15" data-v="15" data-xref="エペソ人への手紙 2:3; 使徒行伝 13:10; 使徒行伝 13:43"> 偽善な律法学者、パリサイ人たちよ。あなたがたは、わざわいである。あなたがたはひとりの改宗者をつくるために、海と陸とを巡り歩く。そして、つくったなら、彼を自分より倍もひどい地獄の子にする。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="マタイによる福音書 15:14; マタイによる福音書 5:33–35; ヤコブの手紙 5:12"> 盲目な案内者たちよ。あなたがたは、わざわいである。あなたがたは言う、『神殿をさして誓うなら、そのままでよいが、神殿の黄金をさして誓うなら、果す責任がある』と。</span>
<span className="v" id="v17" data-v="17" data-xref="マタイによる福音書 23:19; 民数記 16:38–39; 詩篇 94:8"> 愚かな盲目な人たちよ。黄金と、黄金を神聖にする神殿と、どちらが大事なのか。</span>
<span className="v" id="v18" data-v="18"> また、あなたがたは言う、『祭壇をさして誓うなら、そのままでよいが、その上の供え物をさして誓うなら、果す責任がある』と。</span>
<span className="v" id="v19" data-v="19" data-xref="出エジプト記 29:37; 出エジプト記 30:29"> 盲目な人たちよ。供え物と供え物を神聖にする祭壇とどちらが大事なのか。</span>
<span className="v" id="v20" data-v="20"> 祭壇をさして誓う者は、祭壇と、その上にあるすべての物とをさして誓うのである。</span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 26:8; 列王紀上 8:13; 歴代志下 6:2"> 神殿をさして誓う者は、神殿とその中に住んでおられるかたとをさして誓うのである。</span>
<span className="v" id="v22" data-v="22" data-xref="マタイによる福音書 5:34; 詩篇 11:4; イザヤ書 66:1"> また、天をさして誓う者は、神の御座とその上にすわっておられるかたとをさして誓うのである。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="ルカによる福音書 11:42; ミカ書 6:8; ホセア書 6:6"> 偽善な律法学者、パリサイ人たちよ。あなたがたは、わざわいである。はっか、いのんど、クミンなどの薬味の十分の一を宮に納めておりながら、律法の中でもっと重要な、公平とあわれみと忠実とを見のがしている。それもしなければならないが、これも見のがしてはならない。</span>
<span className="v" id="v24" data-v="24" data-xref="マタイによる福音書 19:24; マタイによる福音書 27:6–8; マタイによる福音書 15:2–6"> 盲目な案内者たちよ。あなたがたは、ぶよはこしているが、らくだはのみこんでいる。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="ルカによる福音書 11:39–40; マタイによる福音書 15:19–20; マルコによる福音書 7:4–13"> 偽善な律法学者、パリサイ人たちよ。あなたがたは、わざわいである。杯と皿との外側はきよめるが、内側は貪欲と放縦とで満ちている。</span>
<span className="v" id="v26" data-v="26" data-xref="コリント人への第二の手紙 7:1; ヤコブの手紙 4:8; ヘブル人への手紙 10:22"> 盲目なパリサイ人よ。まず、杯の内側をきよめるがよい。そうすれば、外側も清くなるであろう。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="ルカによる福音書 11:44; 使徒行伝 23:3; 民数記 19:16"> 偽善な律法学者、パリサイ人たちよ。あなたがたは、わざわいである。あなたがたは白く塗った墓に似ている。外側は美しく見えるが、内側は死人の骨や、あらゆる不潔なものでいっぱいである。</span>
<span className="v" id="v28" data-v="28" data-xref="ルカによる福音書 16:15; 詩篇 51:6; マタイによる福音書 23:5"> このようにあなたがたも、外側は人に正しく見えるが、内側は偽善と不法とでいっぱいである。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="ルカによる福音書 11:47–48; 使徒行伝 2:29"> 偽善な律法学者、パリサイ人たちよ。あなたがたは、わざわいである。あなたがたは預言者の墓を建て、義人の碑を飾り立てて、こう言っている、</span>
<span className="v" id="v30" data-v="30" data-xref="エレミヤ書 2:30; マタイによる福音書 23:34–35; マタイによる福音書 21:35–36"> 『もしわたしたちが先祖の時代に生きていたなら、預言者の血を流すことに加わってはいなかっただろう』と。</span>
<span className="v" id="v31" data-v="31" data-xref="使徒行伝 7:51–52; テサロニケ人への第一の手紙 2:15–16; ヨシュア記 24:22"> このようにして、あなたがたは預言者を殺した者の子孫であることを、自分で証明している。</span>
<span className="v" id="v32" data-v="32" data-xref="創世記 15:16; 民数記 32:14; テサロニケ人への第一の手紙 2:16"> あなたがたもまた先祖たちがした悪の枡目を満たすがよい。</span>
<span className="v" id="v33" data-v="33" data-xref="マタイによる福音書 3:7; マタイによる福音書 12:34; マタイによる福音書 5:22"> へびよ、まむしの子らよ、どうして地獄の刑罰をのがれることができようか。</span>
<span className="v" id="v34" data-v="34" data-xref="マタイによる福音書 10:16–17; マタイによる福音書 13:52; コロサイ人への手紙 1:28"> それだから、わたしは、預言者、知者、律法学者たちをあなたがたにつかわすが、そのうちのある者を殺し、また十字架につけ、そのある者を会堂でむち打ち、また町から町へと迫害して行くであろう。</span>
<span className="v" id="v35" data-v="35" data-xref="歴代志下 24:20–22; ゼカリヤ書 1:1; ヘブル人への手紙 11:4"> こうして義人アベルの血から、聖所と祭壇との間であなたがたが殺したバラキヤの子ザカリヤの血に至るまで、地上に流された義人の血の報いが、ことごとくあなたがたに及ぶであろう。</span>
<span className="v" id="v36" data-v="36" data-xref="マタイによる福音書 10:23; マタイによる福音書 24:34; マルコによる福音書 13:30–31"> よく言っておく。これらのことの報いは、みな今の時代に及ぶであろう。</span>
</div>
<div className="bp poetry">
<span className="v" id="v37" data-v="37" data-xref="ルカによる福音書 13:34–35; ルツ記 2:12; 詩篇 91:4"> ああ、エルサレム、エルサレム、預言者たちを殺し、おまえにつかわされた人たちを石で打ち殺す者よ。ちょうど、めんどりが翼の下にそのひなを集めるように、わたしはおまえの子らを幾たび集めようとしたことであろう。それだのに、おまえたちは応じようとしなかった。</span>
<span className="v" id="v38" data-v="38" data-xref="エレミヤ書 22:5; ルカによる福音書 13:35; ルカによる福音書 21:24"> 見よ、おまえたちの家は見捨てられてしまう。</span>
<span className="v" id="v39" data-v="39" data-xref="詩篇 118:26; マタイによる福音書 21:9; ローマ人への手紙 11:25"> わたしは言っておく、<br /><span className="pl pl-1">『主の御名によってきたる者に、祝福あれ』</span><br />とおまえたちが言う時までは、今後ふたたび、わたしに会うことはないであろう」。</span>
</div>

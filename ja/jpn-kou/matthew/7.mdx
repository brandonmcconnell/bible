<div className="bible-chapter" lang="ja" dir="ltr" data-lang="ja" data-translation="jpn-kou" data-translation-id="jpn_kou" data-translation-label="口語訳" data-book="MAT" data-book-slug="matthew" data-book-name="マタイによる福音書" data-chapter="7" data-verses="29">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ルカによる福音書 6:37; ローマ人への手紙 2:1–2; ヤコブの手紙 4:11–12"> 人をさばくな。自分がさばかれないためである。</span>
<span className="v" id="v2" data-v="2" data-xref="ヤコブの手紙 2:13; マルコによる福音書 4:24; ルカによる福音書 6:38"> あなたがたがさばくそのさばきで、自分もさばかれ、あなたがたの量るそのはかりで、自分にも量り与えられるであろう。</span>
<span className="v" id="v3" data-v="3" data-xref="ヨハネによる福音書 8:7–9; ガラテヤ人への手紙 6:1; ルカによる福音書 6:41–42"> なぜ、兄弟の目にあるちりを見ながら、自分の目にある梁を認めないのか。</span>
<span className="v" id="v4" data-v="4"> 自分の目には梁があるのに、どうして兄弟にむかって、あなたの目からちりを取らせてください、と言えようか。</span>
<span className="v" id="v5" data-v="5" data-xref="ルカによる福音書 6:42; 詩篇 51:9–13; マタイによる福音書 23:13–28"> 偽善者よ、まず自分の目から梁を取りのけるがよい。そうすれば、はっきり見えるようになって、兄弟の目からちりを取りのけることができるだろう。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="箴言 9:7–8; 箴言 23:9; マタイによる福音書 10:14–15"> 聖なるものを犬にやるな。また真珠を豚に投げてやるな。恐らく彼らはそれらを足で踏みつけ、向きなおってあなたがたにかみついてくるであろう。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="マタイによる福音書 21:22; ヨハネの第一の手紙 3:22; ヨハネによる福音書 15:7"> 求めよ、そうすれば、与えられるであろう。捜せ、そうすれば、見いだすであろう。門をたたけ、そうすれば、あけてもらえるであろう。</span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 81:10; 詩篇 81:16; ルカによる福音書 23:42–43"> すべて求める者は得、捜す者は見いだし、門をたたく者はあけてもらえるからである。</span>
<span className="v" id="v9" data-v="9" data-xref="ルカによる福音書 11:11–13"> あなたがたのうちで、自分の子がパンを求めるのに、石を与える者があろうか。</span>
<span className="v" id="v10" data-v="10"> 魚を求めるのに、へびを与える者があろうか。</span>
<span className="v" id="v11" data-v="11" data-xref="ルカによる福音書 11:11–13; ヤコブの手紙 1:17; ローマ人への手紙 8:32"> このように、あなたがたは悪い者であっても、自分の子供には、良い贈り物をすることを知っているとすれば、天にいますあなたがたの父はなおさら、求めてくる者に良いものを下さらないことがあろうか。</span>
<span className="v" id="v12" data-v="12" data-xref="ルカによる福音書 6:31; ローマ人への手紙 13:8–10; ガラテヤ人への手紙 5:13–14"> だから、何事でも人々からしてほしいと望むことは、人々にもそのとおりにせよ。これが律法であり預言者である。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="ルカによる福音書 13:24–25; 箴言 16:25; ヨハネによる福音書 14:6"> 狭い門からはいれ。滅びにいたる門は大きく、その道は広い。そして、そこからはいって行く者が多い。</span>
<span className="v" id="v14" data-v="14" data-xref="ルカによる福音書 13:23–30; マタイによる福音書 22:14; マタイによる福音書 16:24–25"> 命にいたる門は狭く、その道は細い。そして、それを見いだす者が少ない。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="ヨハネの第一の手紙 4:1; ペテロの第二の手紙 2:1–3; マタイによる福音書 24:11"> にせ預言者を警戒せよ。彼らは、羊の衣を着てあなたがたのところに来るが、その内側は強欲なおおかみである。</span>
<span className="v" id="v16" data-v="16" data-xref="ルカによる福音書 6:43–45; マタイによる福音書 12:33; ヤコブの手紙 3:12"> あなたがたは、その実によって彼らを見わけるであろう。茨からぶどうを、あざみからいちじくを集める者があろうか。</span>
<span className="v" id="v17" data-v="17" data-xref="マタイによる福音書 12:33–35; ガラテヤ人への手紙 5:22–24; エペソ人への手紙 5:9"> そのように、すべて良い木は良い実を結び、悪い木は悪い実を結ぶ。</span>
<span className="v" id="v18" data-v="18" data-xref="ガラテヤ人への手紙 5:17; ヨハネの第一の手紙 3:9–10"> 良い木が悪い実をならせることはないし、悪い木が良い実をならせることはできない。</span>
<span className="v" id="v19" data-v="19" data-xref="マタイによる福音書 3:10; ヘブル人への手紙 6:8; ヨハネによる福音書 15:2–6"> 良い実を結ばない木はことごとく切られて、火の中に投げ込まれる。</span>
<span className="v" id="v20" data-v="20" data-xref="マタイによる福音書 7:16; 使徒行伝 5:38"> このように、あなたがたはその実によって彼らを見わけるのである。</span>
<span className="v" id="v21" data-v="21" data-xref="ローマ人への手紙 2:13; ルカによる福音書 6:46; ヤコブの手紙 1:22"> わたしにむかって『主よ、主よ』と言う者が、みな天国にはいるのではなく、ただ、天にいますわが父の御旨を行う者だけが、はいるのである。</span>
<span className="v" id="v22" data-v="22" data-xref="ルカによる福音書 13:25–27; コリント人への第一の手紙 13:1–2; マラキ書 3:17–18"> その日には、多くの者が、わたしにむかって『主よ、主よ、わたしたちはあなたの名によって預言したではありませんか。また、あなたの名によって悪霊を追い出し、あなたの名によって多くの力あるわざを行ったではありませんか』と言うであろう。</span>
<span className="v" id="v23" data-v="23" data-xref="マタイによる福音書 25:41; 詩篇 6:8; ルカによる福音書 13:25"> そのとき、わたしは彼らにはっきり、こう言おう、『あなたがたを全く知らない。不法を働く者どもよ、行ってしまえ』。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="ルカによる福音書 6:47–49; ヨハネによる福音書 13:17; コリント人への第一の手紙 3:10–11"> それで、わたしのこれらの言葉を聞いて行うものを、岩の上に自分の家を建てた賢い人に比べることができよう。</span>
<span className="v" id="v25" data-v="25" data-xref="ヤコブの手紙 1:12; 詩篇 125:1–2; ペテロの第一の手紙 1:7"> 雨が降り、洪水が押し寄せ、風が吹いてその家に打ちつけても、倒れることはない。岩を土台としているからである。</span>
<span className="v" id="v26" data-v="26" data-xref="エレミヤ書 8:9; ルカによる福音書 6:49; ヤコブの手紙 2:20"> また、わたしのこれらの言葉を聞いても行わない者を、砂の上に自分の家を建てた愚かな人に比べることができよう。</span>
<span className="v" id="v27" data-v="27" data-xref="マタイによる福音書 13:19–22; ペテロの第二の手紙 2:20–22; コリント人への第一の手紙 3:13"> 雨が降り、洪水が押し寄せ、風が吹いてその家に打ちつけると、倒れてしまう。そしてその倒れ方はひどいのである」。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="ルカによる福音書 4:32; マルコによる福音書 1:22; ヨハネによる福音書 7:46"> イエスがこれらの言を語り終えられると、群衆はその教にひどく驚いた。</span>
<span className="v" id="v29" data-v="29" data-xref="ヘブル人への手紙 4:12–13; ルカによる福音書 20:8; 申命記 18:18–19"> それは律法学者たちのようにではなく、権威ある者のように、教えられたからである。</span>
</div>

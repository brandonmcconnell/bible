<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マルコによる福音書 15:1; ヨハネによる福音書 18:28; ミカ書 2:1"> 夜が明けると、祭司長たち、民の長老たち一同は、イエスを殺そうとして協議をこらした上、</span>
<span className="v" id="v2" data-v="2" data-xref="マタイによる福音書 20:19; 使徒行伝 3:13; テモテヘの第一の手紙 6:13"> イエスを縛って引き出し、総督ピラトに渡した。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="コリント人への第二の手紙 7:10; ルカによる福音書 22:47–48; ヨブ記 20:15–29"> そのとき、イエスを裏切ったユダは、イエスが罪に定められたのを見て後悔し、銀貨三十枚を祭司長、長老たちに返して</span>
<span className="v" id="v4" data-v="4" data-xref="サムエル記上 15:30; テトスヘの手紙 1:16; 使徒行伝 18:15–17"> 言った、「わたしは罪のない人の血を売るようなことをして、罪を犯しました」。しかし彼らは言った、「それは、われわれの知ったことか。自分で始末するがよい」。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行伝 1:18–19; サムエル記下 17:23; 列王紀上 16:18"> そこで、彼は銀貨を聖所に投げ込んで出て行き、首をつって死んだ。</span>
<span className="v" id="v6" data-v="6" data-xref="ルカによる福音書 6:7–9; 申命記 23:18; イザヤ書 61:8"> 祭司長たちは、その銀貨を拾いあげて言った、「これは血の代価だから、宮の金庫に入れるのはよくない」。</span>
<span className="v" id="v7" data-v="7"> そこで彼らは協議の上、外国人の墓地にするために、その金で陶器師の畑を買った。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行伝 1:19; マタイによる福音書 28:15; ヨシュア記 4:9"> そのために、この畑は今日まで血の畑と呼ばれている。</span>
<span className="v" id="v9" data-v="9" data-xref="ゼカリヤ書 11:12–13; マタイによる福音書 1:22; レビ記 27:2–7"> こうして預言者エレミヤによって言われた言葉が、成就したのである。すなわち、「彼らは、値をつけられたもの、すなわち、イスラエルの子らが値をつけたものの代価、銀貨三十を取って、</span>
<span className="v" id="v10" data-v="10" data-xref="ゼカリヤ書 11:13"> 主がお命じになったように、陶器師の畑の代価として、その金を与えた」。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="ルカによる福音書 23:2–3; マルコによる福音書 15:2–5; マタイによる福音書 26:25"> さて、イエスは総督の前に立たれた。すると総督はイエスに尋ねて言った、「あなたがユダヤ人の王であるか」。イエスは「そのとおりである」と言われた。</span>
<span className="v" id="v12" data-v="12" data-xref="マタイによる福音書 26:63; イザヤ書 53:7; マタイによる福音書 27:14"> しかし、祭司長、長老たちが訴えている間、イエスはひと言もお答えにならなかった。</span>
<span className="v" id="v13" data-v="13" data-xref="マタイによる福音書 26:62; ヨハネによる福音書 18:35; 使徒行伝 22:24"> するとピラトは言った、「あんなにまで次々に、あなたに不利な証言を立てているのが、あなたには聞えないのか」。</span>
<span className="v" id="v14" data-v="14" data-xref="イザヤ書 8:18; 詩篇 71:7; コリント人への第一の手紙 4:9"> しかし、総督が非常に不思議に思ったほどに、イエスは何を言われても、ひと言もお答えにならなかった。</span>
<span className="v" id="v15" data-v="15" data-xref="ヨハネによる福音書 18:38–40; ルカによる福音書 23:16; ヨハネによる福音書 19:16"> さて、祭のたびごとに、総督は群衆が願い出る囚人ひとりを、ゆるしてやる慣例になっていた。</span>
<span className="v" id="v16" data-v="16" data-xref="マルコによる福音書 15:7; 使徒行伝 3:14; ルカによる福音書 23:25"> ときに、バラバという評判の囚人がいた。</span>
<span className="v" id="v17" data-v="17" data-xref="ヨハネによる福音書 19:15; 列王紀上 18:21; マルコによる福音書 15:9–12"> それで、彼らが集まったとき、ピラトは言った、「おまえたちは、だれをゆるしてほしいのか。バラバか、それとも、キリストといわれるイエスか」。</span>
<span className="v" id="v18" data-v="18" data-xref="箴言 27:4; 使徒行伝 5:17; マルコによる福音書 15:10"> 彼らがイエスを引きわたしたのは、ねたみのためであることが、ピラトにはよくわかっていたからである。</span>
<span className="v" id="v19" data-v="19" data-xref="ゼカリヤ書 9:9; 箴言 29:1; マタイによる福音書 27:24"> また、ピラトが裁判の席についていたとき、その妻が人を彼のもとにつかわして、「あの義人には関係しないでください。わたしはきょう夢で、あの人のためにさんざん苦しみましたから」と言わせた。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行伝 3:14–15; ヨハネによる福音書 19:15–16; ヨハネによる福音書 18:40"> しかし、祭司長、長老たちは、バラバをゆるして、イエスを殺してもらうようにと、群衆を説き伏せた。</span>
<span className="v" id="v21" data-v="21"> 総督は彼らにむかって言った、「ふたりのうち、どちらをゆるしてほしいのか」。彼らは「バラバの方を」と言った。</span>
<span className="v" id="v22" data-v="22" data-xref="イザヤ書 53:2–3; イザヤ書 49:7; 使徒行伝 13:38"> ピラトは言った、「それではキリストといわれるイエスは、どうしたらよいか」。彼らはいっせいに「十字架につけよ」と言った。</span>
<span className="v" id="v23" data-v="23" data-xref="創世記 37:18–19; 使徒行伝 7:57; 使徒行伝 23:12–15"> しかし、ピラトは言った、「あの人は、いったい、どんな悪事をしたのか」。すると彼らはいっそう激しく叫んで、「十字架につけよ」と言った。</span>
<span className="v" id="v24" data-v="24" data-xref="マタイによる福音書 27:4; 詩篇 26:6; コリント人への第二の手紙 5:21"> ピラトは手のつけようがなく、かえって暴動になりそうなのを見て、水を取り、群衆の前で手を洗って言った、「この人の血について、わたしには責任がない。おまえたちが自分で始末をするがよい」。</span>
<span className="v" id="v25" data-v="25" data-xref="ヨシュア記 2:19; 使徒行伝 5:28; 使徒行伝 7:52"> すると、民衆全体が答えて言った、「その血の責任は、われわれとわれわれの子孫の上にかかってもよい」。</span>
<span className="v" id="v26" data-v="26" data-xref="イザヤ書 53:5; ヨハネによる福音書 19:1; マルコによる福音書 15:15"> そこで、ピラトはバラバをゆるしてやり、イエスをむち打ったのち、十字架につけるために引きわたした。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="ヨハネによる福音書 18:28; ヨハネによる福音書 18:33; 使徒行伝 10:1"> それから総督の兵士たちは、イエスを官邸に連れて行って、全部隊をイエスのまわりに集めた。</span>
<span className="v" id="v28" data-v="28" data-xref="マルコによる福音書 15:17; ヨハネによる福音書 19:2–5; ルカによる福音書 23:11"> そしてその上着をぬがせて、赤い外套を着せ、</span>
<span className="v" id="v29" data-v="29" data-xref="イザヤ書 53:3; マタイによる福音書 20:19; 詩篇 69:19–20"> また、いばらで冠を編んでその頭にかぶらせ、右の手には葦の棒を持たせ、それからその前にひざまずき、嘲弄して、「ユダヤ人の王、ばんざい」と言った。</span>
<span className="v" id="v30" data-v="30" data-xref="イザヤ書 50:6; マタイによる福音書 26:67; イザヤ書 53:7"> また、イエスにつばきをかけ、葦の棒を取りあげてその頭をたたいた。</span>
<span className="v" id="v31" data-v="31" data-xref="イザヤ書 53:7; 列王紀上 21:13; 列王紀上 21:10"> こうしてイエスを嘲弄したあげく、外套をはぎ取って元の上着を着せ、それから十字架につけるために引き出した。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="マルコによる福音書 15:21; マタイによる福音書 16:24; ルカによる福音書 23:26"> 彼らが出て行くと、シモンという名のクレネ人に出会ったので、イエスの十字架を無理に負わせた。</span>
<span className="v" id="v33" data-v="33" data-xref="ヨハネによる福音書 19:17–19; マルコによる福音書 15:22–32; マルコによる福音書 15:34"> そして、ゴルゴタ、すなわち、されこうべの場、という所にきたとき、</span>
<span className="v" id="v34" data-v="34" data-xref="詩篇 69:21; マルコによる福音書 15:23; マタイによる福音書 27:48"> 彼らはにがみをまぜたぶどう酒を飲ませようとしたが、イエスはそれをなめただけで、飲もうとされなかった。</span>
<span className="v" id="v35" data-v="35" data-xref="詩篇 22:18; マルコによる福音書 15:24–32; ルカによる福音書 23:34"> 彼らはイエスを十字架につけてから、くじを引いて、その着物を分け、</span>
<span className="v" id="v36" data-v="36" data-xref="マタイによる福音書 27:54; マルコによる福音書 15:44; マルコによる福音書 15:39"> そこにすわってイエスの番をしていた。</span>
<span className="v" id="v37" data-v="37" data-xref="ルカによる福音書 23:38; ヨハネによる福音書 19:19–22; マルコによる福音書 15:26"> そしてその頭の上の方に、「これはユダヤ人の王イエス」と書いた罪状書きをかかげた。</span>
<span className="v" id="v38" data-v="38" data-xref="ヨハネによる福音書 19:18; ルカによる福音書 23:39–43; イザヤ書 53:12"> 同時に、ふたりの強盗がイエスと一緒に、ひとりは右に、ひとりは左に、十字架につけられた。</span>
<span className="v" id="v39" data-v="39" data-xref="詩篇 109:25; 哀歌 1:12; 詩篇 69:7–12"> そこを通りかかった者たちは、頭を振りながら、イエスをののしって</span>
<span className="v" id="v40" data-v="40" data-xref="マタイによる福音書 26:61; マタイによる福音書 4:6; マタイによる福音書 4:3"> 言った、「神殿を打ちこわして三日のうちに建てる者よ。もし神の子なら、自分を救え。そして十字架からおりてこい」。</span>
<span className="v" id="v41" data-v="41" data-xref="詩篇 35:26; イザヤ書 28:22; 詩篇 22:12–13"> 祭司長たちも同じように、律法学者、長老たちと一緒になって、嘲弄して言った、</span>
<span className="v" id="v42" data-v="42" data-xref="ヨハネによる福音書 1:49; マタイによる福音書 27:37; 使徒行伝 4:14"> 「他人を救ったが、自分自身を救うことができない。あれがイスラエルの王なのだ。いま十字架からおりてみよ。そうしたら信じよう。</span>
<span className="v" id="v43" data-v="43" data-xref="詩篇 22:8; ヨハネによる福音書 10:36; イザヤ書 37:10"> 彼は神にたよっているが、神のおぼしめしがあれば、今、救ってもらうがよい。自分は神の子だと言っていたのだから」。</span>
<span className="v" id="v44" data-v="44" data-xref="マタイによる福音書 27:38; マルコによる福音書 15:32; ルカによる福音書 23:39–43"> 一緒に十字架につけられた強盗どもまでも、同じようにイエスをののしった。</span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="アモス書 8:9; マルコによる福音書 15:33–34; ルカによる福音書 23:44–45"> さて、昼の十二時から地上の全面が暗くなって、三時に及んだ。</span>
<span className="v" id="v46" data-v="46" data-xref="詩篇 22:1; ヘブル人への手紙 5:7; イザヤ書 53:10"> そして三時ごろに、イエスは大声で叫んで、「エリ、エリ、レマ、サバクタニ」と言われた。それは「わが神、わが神、どうしてわたしをお見捨てになったのですか」という意味である。</span>
<span className="v" id="v47" data-v="47" data-xref="マラキ書 4:5; マルコによる福音書 15:35–36; マタイによる福音書 11:14"> すると、そこに立っていたある人々が、これを聞いて言った、「あれはエリヤを呼んでいるのだ」。</span>
<span className="v" id="v48" data-v="48" data-xref="詩篇 69:21; マタイによる福音書 27:34; ルカによる福音書 23:36"> するとすぐ、彼らのうちのひとりが走り寄って、海綿を取り、それに酢いぶどう酒を含ませて葦の棒につけ、イエスに飲ませようとした。</span>
<span className="v" id="v49" data-v="49"> ほかの人々は言った、「待て、エリヤが彼を救いに来るかどうか、見ていよう」。</span>
<span className="v" id="v50" data-v="50" data-xref="ヨハネによる福音書 19:30; イザヤ書 53:9–12; 詩篇 22:14–15"> イエスはもう一度大声で叫んで、ついに息をひきとられた。</span>
<span className="v" id="v51" data-v="51" data-xref="ヘブル人への手紙 10:19–22; マルコによる福音書 15:38; ヘブル人への手紙 6:19"> すると見よ、神殿の幕が上から下まで真二つに裂けた。また地震があり、岩が裂け、</span>
<span className="v" id="v52" data-v="52" data-xref="イザヤ書 26:19; テサロニケ人への第一の手紙 4:14; コリント人への第一の手紙 15:20"> また墓が開け、眠っている多くの聖徒たちの死体が生き返った。</span>
<span className="v" id="v53" data-v="53" data-xref="ヨハネの黙示録 11:2; イザヤ書 48:2; ヨハネの黙示録 21:2"> そしてイエスの復活ののち、墓から出てきて、聖なる都にはいり、多くの人に現れた。</span>
<span className="v" id="v54" data-v="54" data-xref="マタイによる福音書 27:36; マルコによる福音書 15:39; マタイによる福音書 27:43"> 百卒長、および彼と一緒にイエスの番をしていた人々は、地震や、いろいろのできごとを見て非常に恐れ、「まことに、この人は神の子であった」と言った。</span>
<span className="v" id="v55" data-v="55" data-xref="ルカによる福音書 8:2–3; ルカによる福音書 23:48–49; ヨハネによる福音書 19:25–27"> また、そこには遠くの方から見ている女たちも多くいた。彼らはイエスに仕えて、ガリラヤから従ってきた人たちであった。</span>
<span className="v" id="v56" data-v="56" data-xref="ヨハネによる福音書 19:25; マルコによる福音書 15:47–1; マタイによる福音書 28:1"> その中には、マグダラのマリヤ、ヤコブとヨセフとの母マリヤ、またゼベダイの子たちの母がいた。</span>
</div>
<div className="bp">
<span className="v" id="v57" data-v="57" data-xref="ヨハネによる福音書 19:38–42; マルコによる福音書 15:42–47; ルカによる福音書 23:50–56"> 夕方になってから、アリマタヤの金持で、ヨセフという名の人がきた。彼もまたイエスの弟子であった。</span>
<span className="v" id="v58" data-v="58" data-xref="ルカによる福音書 23:52–53; マルコによる福音書 15:44–46"> この人がピラトの所へ行って、イエスのからだの引取りかたを願った。そこで、ピラトはそれを渡すように命じた。</span>
<span className="v" id="v59" data-v="59"> ヨセフは死体を受け取って、きれいな亜麻布に包み、</span>
<span className="v" id="v60" data-v="60" data-xref="イザヤ書 53:9; マタイによる福音書 28:2; マタイによる福音書 27:66"> 岩を掘って造った彼の新しい墓に納め、そして墓の入口に大きい石をころがしておいて、帰った。</span>
<span className="v" id="v61" data-v="61" data-xref="マタイによる福音書 28:1; マタイによる福音書 27:56"> マグダラのマリヤとほかのマリヤとが、墓にむかってそこにすわっていた。</span>
</div>
<div className="bp">
<span className="v" id="v62" data-v="62" data-xref="マルコによる福音書 15:42; ヨハネによる福音書 19:14; ヨハネによる福音書 19:42"> あくる日は準備の日の翌日であったが、その日に、祭司長、パリサイ人たちは、ピラトのもとに集まって言った、</span>
<span className="v" id="v63" data-v="63" data-xref="ルカによる福音書 9:22; マタイによる福音書 16:21; ヨハネによる福音書 2:19"> 「長官、あの偽り者がまだ生きていたとき、『三日の後に自分はよみがえる』と言ったのを、思い出しました。</span>
<span className="v" id="v64" data-v="64" data-xref="マタイによる福音書 28:13; マタイによる福音書 12:45"> ですから、三日目まで墓の番をするように、さしずをして下さい。そうしないと、弟子たちがきて彼を盗み出し、『イエスは死人の中から、よみがえった』と、民衆に言いふらすかも知れません。そうなると、みんなが前よりも、もっとひどくだまされることになりましょう」。</span>
<span className="v" id="v65" data-v="65" data-xref="マタイによる福音書 27:66; マタイによる福音書 28:11–15; 箴言 21:30"> ピラトは彼らに言った、「番人がいるから、行ってできる限り、番をさせるがよい」。</span>
<span className="v" id="v66" data-v="66" data-xref="ダニエル書 6:17; マタイによる福音書 27:60; テモテヘの第二の手紙 2:19"> そこで、彼らは行って石に封印をし、番人を置いて墓の番をさせた。</span>
</div>

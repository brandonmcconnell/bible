<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="イザヤ書 40:3–6; ヨハネによる福音書 1:6–8; ルカによる福音書 1:76"> そのころ、バプテスマのヨハネが現れ、ユダヤの荒野で教を宣べて言った、</span>
<span className="v" id="v2" data-v="2" data-xref="マタイによる福音書 4:17; マルコによる福音書 1:15; ダニエル書 2:44"> 「悔い改めよ、天国は近づいた」。</span>
<span className="v" id="v3" data-v="3" data-xref="イザヤ書 40:3; マラキ書 3:1; ヨハネによる福音書 1:23"> 預言者イザヤによって、<br /><span className="pl pl-1">「荒野で呼ばわる者の声がする、</span><br /><span className="pl pl-1">『主の道を備えよ、</span><br /><span className="pl pl-1">その道筋をまっすぐにせよ』」</span><br />と言われたのは、この人のことである。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="列王紀下 1:8; ゼカリヤ書 13:4; マルコによる福音書 1:6"> このヨハネは、らくだの毛ごろもを着物にし、腰に皮の帯をしめ、いなごと野蜜とを食物としていた。</span>
<span className="v" id="v5" data-v="5" data-xref="マルコによる福音書 1:5; ルカによる福音書 3:7; ヨハネによる福音書 3:23"> すると、エルサレムとユダヤ全土とヨルダン附近一帯の人々が、ぞくぞくとヨハネのところに出てきて、</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行伝 19:18; マタイによる福音書 3:13–16; 使徒行伝 2:38–41"> 自分の罪を告白し、ヨルダン川でヨハネからバプテスマを受けた。</span>
<span className="v" id="v7" data-v="7" data-xref="マタイによる福音書 12:34; テサロニケ人への第一の手紙 1:10; ローマ人への手紙 5:9"> ヨハネは、パリサイ人やサドカイ人が大ぜいバプテスマを受けようとしてきたのを見て、彼らに言った、「まむしの子らよ、迫ってきている神の怒りから、おまえたちはのがれられると、だれが教えたのか。</span>
<span className="v" id="v8" data-v="8" data-xref="ルカによる福音書 3:8; 使徒行伝 26:20; ペテロの第二の手紙 1:4–8"> だから、悔改めにふさわしい実を結べ。</span>
<span className="v" id="v9" data-v="9" data-xref="ルカによる福音書 3:8; ローマ人への手紙 9:7–8; ガラテヤ人への手紙 3:27–29"> 自分たちの父にはアブラハムがあるなどと、心の中で思ってもみるな。おまえたちに言っておく、神はこれらの石ころからでも、アブラハムの子を起すことができるのだ。</span>
<span className="v" id="v10" data-v="10" data-xref="ヨハネによる福音書 15:6; ルカによる福音書 3:9; マタイによる福音書 7:19"> 斧がすでに木の根もとに置かれている。だから、良い実を結ばない木はことごとく切られて、火の中に投げ込まれるのだ。</span>
<span className="v" id="v11" data-v="11" data-xref="イザヤ書 4:4; ルカによる福音書 3:16; 使徒行伝 1:5"> わたしは悔改めのために、水でおまえたちにバプテスマを授けている。しかし、わたしのあとから来る人はわたしよりも力のあるかたで、わたしはそのくつをぬがせてあげる値うちもない。このかたは、聖霊と火とによっておまえたちにバプテスマをお授けになるであろう。</span>
<span className="v" id="v12" data-v="12" data-xref="マラキ書 4:1; マタイによる福音書 13:30; ルカによる福音書 3:17"> また、箕を手に持って、打ち場の麦をふるい分け、麦は倉に納め、からは消えない火で焼き捨てるであろう」。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="ヨハネによる福音書 1:32–34; マタイによる福音書 2:22; マルコによる福音書 1:9–11"> そのときイエスは、ガリラヤを出てヨルダン川に現れ、ヨハネのところにきて、バプテスマを受けようとされた。</span>
<span className="v" id="v14" data-v="14" data-xref="ヨハネによる福音書 3:3–7; 使徒行伝 1:5–8; ヨハネによる福音書 13:6–8"> ところがヨハネは、それを思いとどまらせようとして言った、「わたしこそあなたからバプテスマを受けるはずですのに、あなたがわたしのところにおいでになるのですか」。</span>
<span className="v" id="v15" data-v="15" data-xref="ヨハネによる福音書 4:34; ヨハネによる福音書 15:10; 詩篇 40:7–8"> しかし、イエスは答えて言われた、「今は受けさせてもらいたい。このように、すべての正しいことを成就するのは、われわれにふさわしいことである」。そこでヨハネはイエスの言われるとおりにした。</span>
<span className="v" id="v16" data-v="16" data-xref="イザヤ書 11:2; マルコによる福音書 1:10; ルカによる福音書 3:21–22"> イエスはバプテスマを受けるとすぐ、水から上がられた。すると、見よ、天が開け、神の御霊がはとのように自分の上に下ってくるのを、ごらんになった。</span>
<span className="v" id="v17" data-v="17" data-xref="イザヤ書 42:1; 詩篇 2:7; マタイによる福音書 17:5"> また天から声があって言った、「これはわたしの愛する子、わたしの心にかなう者である」。</span>
</div>

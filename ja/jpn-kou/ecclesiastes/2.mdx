<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ルカによる福音書 12:19; 伝道の書 8:15; ヤコブの手紙 5:5"> わたしは自分の心に言った、「さあ、快楽をもって、おまえを試みよう。おまえは愉快に過ごすがよい」と。しかし、これもまた空であった。</span>
<span className="v" id="v2" data-v="2" data-xref="箴言 14:13; 伝道の書 7:2–6; ペテロの第一の手紙 4:2–4"> わたしは笑いについて言った、「これは狂気である」と。また快楽について言った、「これは何をするのか」と。</span>
<span className="v" id="v3" data-v="3" data-xref="箴言 20:1; 伝道の書 1:17; 箴言 31:4–5"> わたしの心は知恵をもってわたしを導いているが、わたしは酒をもって自分の肉体を元気づけようと試みた。また、人の子は天が下でその短い一生の間、どんな事をしたら良いかを、見きわめるまでは、愚かな事をしようと試みた。</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀上 7:1–12; 歴代志下 8:11; 歴代志下 26:10"> わたしは大きな事業をした。わたしは自分のために家を建て、ぶどう畑を設け、</span>
<span className="v" id="v5" data-v="5" data-xref="ルカによる福音書 17:27–29; 雅歌 4:12–1; エレミヤ書 39:4"> 園と庭をつくり、またすべて実のなる木をそこに植え、</span>
<span className="v" id="v6" data-v="6" data-xref="ネヘミヤ書 2:14; 詩篇 1:3; エレミヤ書 17:8"> 池をつくって、木のおい茂る林に、そこから水を注がせた。</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀下 3:4; 創世記 15:3; 列王紀上 4:23"> わたしは男女の奴隷を買った。またわたしの家で生れた奴隷を持っていた。わたしはまた、わたしより先にエルサレムにいただれよりも多くの牛や羊の財産を持っていた。</span>
<span className="v" id="v8" data-v="8" data-xref="列王紀上 10:10; 列王紀上 9:28; サムエル記下 19:35"> わたしはまた銀と金を集め、王たちと国々の財宝を集めた。またわたしは歌うたう男、歌うたう女を得た。また人の子の楽しみとするそばめを多く得た。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="歴代志上 29:25; 伝道の書 1:16; 列王紀上 10:23"> こうして、わたしは大いなる者となり、わたしより先にエルサレムにいたすべての者よりも、大いなる者となった。わたしの知恵もまた、わたしを離れなかった。</span>
<span className="v" id="v10" data-v="10" data-xref="伝道の書 9:9; 伝道の書 5:18; 伝道の書 3:22"> なんでもわたしの目の好むものは遠慮せず、わたしの心の喜ぶものは拒まなかった。わたしの心がわたしのすべての労苦によって、快楽を得たからである。そしてこれはわたしのすべての労苦によって得た報いであった。</span>
<span className="v" id="v11" data-v="11" data-xref="伝道の書 1:14; ヨハネの第一の手紙 2:16–17; 伝道の書 1:3"> そこで、わたしはわが手のなしたすべての事、およびそれをなすに要した労苦を顧みたとき、見よ、皆、空であって、風を捕えるようなものであった。日の下には益となるものはないのである。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="伝道の書 1:17; 伝道の書 7:25; 伝道の書 1:9–10"> わたしはまた、身をめぐらして、知恵と、狂気と、愚痴とを見た。そもそも、王の後に来る人は何をなし得ようか。すでに彼がなした事にすぎないのだ。</span>
<span className="v" id="v13" data-v="13" data-xref="エペソ人への手紙 5:8; 伝道の書 7:11–12; マタイによる福音書 6:23"> 光が暗きにまさるように、知恵が愚痴にまさるのを、わたしは見た。</span>
<span className="v" id="v14" data-v="14" data-xref="詩篇 49:10; 箴言 17:24; 伝道の書 9:11"> 知者の目は、その頭にある。しかし愚者は暗やみを歩む。けれどもわたしはなお同一の運命が彼らのすべてに臨むことを知っている。</span>
<span className="v" id="v15" data-v="15" data-xref="伝道の書 6:8; 伝道の書 1:14; 伝道の書 1:2"> わたしは心に言った、「愚者に臨む事はわたしにも臨むのだ。それでどうしてわたしは賢いことがあろう」。わたしはまた心に言った、「これもまた空である」と。</span>
<span className="v" id="v16" data-v="16" data-xref="伝道の書 1:11; 伝道の書 9:5; 詩篇 88:12"> そもそも、知者も愚者も同様に長く覚えられるものではない。きたるべき日には皆忘れられてしまうのである。知者が愚者と同じように死ぬのは、どうしたことであろう。</span>
<span className="v" id="v17" data-v="17" data-xref="伝道の書 2:11; ヨナ書 4:8; 伝道の書 4:2"> そこで、わたしは生きることをいとった。日の下に行われるわざは、わたしに悪しく見えたからである。皆空であって、風を捕えるようである。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="詩篇 39:6; 詩篇 49:10; ルカによる福音書 16:27–28"> わたしは日の下で労したすべての労苦を憎んだ。わたしの後に来る人にこれを残さなければならないからである。</span>
<span className="v" id="v19" data-v="19" data-xref="ヤコブの手紙 3:17; 伝道の書 3:22; 伝道の書 9:13"> そして、その人が知者であるか、または愚者であるかは、だれが知り得よう。そうであるのに、その人が、日の下でわたしが労し、かつ知恵を働かしてなしたすべての労苦をつかさどることになるのだ。これもまた空である。</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 43:14; ヨブ記 17:11–15; コリント人への第二の手紙 1:8–10"> それでわたしはふり返ってみて、日の下でわたしが労したすべての労苦について、望みを失った。</span>
<span className="v" id="v21" data-v="21" data-xref="伝道の書 2:17–18; 歴代志下 31:20–21; 歴代志下 34:2"> 今ここに人があって、知恵と知識と才能をもって労しても、これがために労しない人に、すべてを残して、その所有とさせなければならないのだ。これもまた空であって、大いに悪い。</span>
<span className="v" id="v22" data-v="22" data-xref="詩篇 127:2; 伝道の書 1:3; ピリピ人への手紙 4:6"> そもそも、人は日の下で労するすべての労苦と、その心づかいによってなんの得るところがあるか。</span>
<span className="v" id="v23" data-v="23" data-xref="ヨブ記 14:1; ヨブ記 5:7; 詩篇 6:6–7"> そのすべての日はただ憂いのみであって、そのわざは苦しく、その心は夜の間も休まることがない。これもまた空である。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="伝道の書 3:22; 伝道の書 8:15; テモテヘの第一の手紙 6:17"> 人は食い飲みし、その労苦によって得たもので心を楽しませるより良い事はない。これもまた神の手から出ることを、わたしは見た。</span>
<span className="v" id="v25" data-v="25" data-xref="伝道の書 2:1–12; 列王紀上 4:21–24"> だれが神を離れて、食い、かつ楽しむことのできる者があろう。</span>
<span className="v" id="v26" data-v="26" data-xref="箴言 13:22; ヨブ記 27:16–17; 箴言 28:8"> 神は、その心にかなう人に、知恵と知識と喜びとをくださる。しかし罪びとには仕事を与えて集めることと、積むことをさせられる。これは神の心にかなう者にそれを賜わるためである。これもまた空であって、風を捕えるようである。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="テトスヘの手紙 2:13; ローマ人への手紙 3:21–26; テトスヘの手紙 1:4"> イエス・キリストの僕また使徒であるシメオン・ペテロから、わたしたちの神と救主イエス・キリストとの義によって、わたしたちと同じ尊い信仰を授かった人々へ。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="ペテロの第二の手紙 3:18; ヨハネによる福音書 17:3; ピリピ人への手紙 3:8"> 神とわたしたちの主イエスとを知ることによって、恵みと平安とが、あなたがたに豊かに加わるように。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="ペテロの第一の手紙 5:10; テモテヘの第二の手紙 1:9; ローマ人への手紙 8:28–30"> いのちと信心とにかかわるすべてのことは、主イエスの神聖な力によって、わたしたちに与えられている。それは、ご自身の栄光と徳とによって、わたしたちを召されたかたを知る知識によるのである。</span>
<span className="v" id="v4" data-v="4" data-xref="エペソ人への手紙 4:23–24; エゼキエル書 36:25–27; コリント人への第二の手紙 3:18"> また、それらのものによって、尊く、大いなる約束が、わたしたちに与えられている。それは、あなたがたが、世にある欲のために滅びることを免れ、神の性質にあずかる者となるためである。</span>
<span className="v" id="v5" data-v="5" data-xref="ピリピ人への手紙 4:8; 箴言 4:23; ペテロの第二の手紙 3:18"> それだから、あなたがたは、力の限りをつくして、あなたがたの信仰に徳を加え、徳に知識を、</span>
<span className="v" id="v6" data-v="6" data-xref="ヘブル人への手紙 10:36; ローマ人への手紙 5:3–4; ルカによる福音書 21:19"> 知識に節制を、節制に忍耐を、忍耐に信心を、</span>
<span className="v" id="v7" data-v="7" data-xref="ヘブル人への手紙 13:1; ローマ人への手紙 12:10; テサロニケ人への第一の手紙 3:12"> 信心に兄弟愛を、兄弟愛に愛を加えなさい。</span>
<span className="v" id="v8" data-v="8" data-xref="テトスヘの手紙 3:14; ヨハネによる福音書 15:2; ヘブル人への手紙 6:12"> これらのものがあなたがたに備わって、いよいよ豊かになるならば、わたしたちの主イエス・キリストを知る知識について、あなたがたは、怠る者、実を結ばない者となることはないであろう。</span>
<span className="v" id="v9" data-v="9" data-xref="ペテロの第二の手紙 2:18–20; エペソ人への手紙 5:26; テトスヘの手紙 2:14"> これらのものを備えていない者は、盲人であり、近視の者であり、自分の以前の罪がきよめられたことを忘れている者である。</span>
<span className="v" id="v10" data-v="10" data-xref="ペテロの第二の手紙 3:17; ルカによる福音書 6:47–49; ヘブル人への手紙 6:11"> 兄弟たちよ。それだから、ますます励んで、あなたがたの受けた召しと選びとを、確かなものにしなさい。そうすれば、決してあやまちに陥ることはない。</span>
<span className="v" id="v11" data-v="11" data-xref="ヨハネの黙示録 5:10; マタイによる福音書 25:34; ヨハネの黙示録 3:21"> こうして、わたしたちの主また救主イエス・キリストの永遠の国に入る恵みが、あなたがたに豊かに与えられるからである。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="ヨハネの第一の手紙 2:21; ローマ人への手紙 15:14–15; ピリピ人への手紙 3:1"> それだから、あなたがたは既にこれらのことを知っており、また、いま持っている真理に堅く立ってはいるが、わたしは、これらのことをいつも、あなたがたに思い起させたいのである。</span>
<span className="v" id="v13" data-v="13" data-xref="ペテロの第二の手紙 3:1; ペテロの第二の手紙 1:14; ヘブル人への手紙 13:3"> わたしがこの幕屋にいる間、あなたがたに思い起させて、奮い立たせることが適当と思う。</span>
<span className="v" id="v14" data-v="14" data-xref="テモテヘの第二の手紙 4:6; ヨハネによる福音書 21:18–19; 申命記 31:14"> それは、わたしたちの主イエス・キリストもわたしに示して下さったように、わたしのこの幕屋を脱ぎ去る時が間近であることを知っているからである。</span>
<span className="v" id="v15" data-v="15" data-xref="申命記 31:19–29; 詩篇 71:18; ヨシュア記 24:24–29"> わたしが世を去った後にも、これらのことを、あなたがたにいつも思い出させるように努めよう。</span>
<span className="v" id="v16" data-v="16" data-xref="ヨハネの第一の手紙 4:14; ヨハネによる福音書 1:14; テモテヘの第一の手紙 1:4"> わたしたちの主イエス・キリストの力と来臨とを、あなたがたに知らせた時、わたしたちは、巧みな作り話を用いることはしなかった。わたしたちが、そのご威光の目撃者なのだからである。</span>
<span className="v" id="v17" data-v="17" data-xref="マルコによる福音書 9:7; マタイによる福音書 17:5; マタイによる福音書 3:17"> イエスは父なる神からほまれと栄光とをお受けになったが、その時、おごそかな栄光の中から次のようなみ声がかかったのである、「これはわたしの愛する子、わたしの心にかなう者である」。</span>
<span className="v" id="v18" data-v="18" data-xref="マタイによる福音書 17:6; ヨシュア記 5:15; 出エジプト記 3:5"> わたしたちもイエスと共に聖なる山にいて、天から出たこの声を聞いたのである。</span>
<span className="v" id="v19" data-v="19" data-xref="ヨハネの黙示録 22:16; イザヤ書 9:2; 詩篇 119:105"> こうして、預言の言葉は、わたしたちにいっそう確実なものになった。あなたがたも、夜が明け、明星がのぼって、あなたがたの心の中を照すまで、この預言の言葉を暗やみに輝くともしびとして、それに目をとめているがよい。</span>
<span className="v" id="v20" data-v="20" data-xref="ペテロの第二の手紙 3:3; ローマ人への手紙 12:6; ローマ人への手紙 6:6"> 聖書の預言はすべて、自分勝手に解釈すべきでないことを、まず第一に知るべきである。</span>
<span className="v" id="v21" data-v="21" data-xref="テモテヘの第二の手紙 3:15–17; ペテロの第一の手紙 1:11; サムエル記下 23:2"> なぜなら、預言は決して人間の意志から出たものではなく、人々が聖霊に感じ、神によって語ったものだからである。</span>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="テモテヘの第二の手紙 1:6; ペテロの第二の手紙 1:12–15; ペテロの第一の手紙 1:22"> 愛する者たちよ。わたしは今この第二の手紙をあなたがたに書きおくり、これらの手紙によって記憶を呼び起し、あなたがたの純真な心を奮い立たせようとした。</span>
<span className="v" id="v2" data-v="2" data-xref="ユダの手紙 1:17; ペテロの第二の手紙 2:21; ルカによる福音書 1:70"> それは、聖なる預言者たちがあらかじめ語った言葉と、あなたがたの使徒たちが伝えた主なる救主の戒めとを、思い出させるためである。</span>
<span className="v" id="v3" data-v="3" data-xref="ユダの手紙 1:18; テモテヘの第一の手紙 4:1–2; ペテロの第二の手紙 2:10"> まず次のことを知るべきである。終りの時にあざける者たちが、あざけりながら出てきて、自分の欲情のままに生活し、</span>
<span className="v" id="v4" data-v="4" data-xref="エレミヤ書 17:15; マラキ書 2:17; エレミヤ書 5:12–13"> 「主の来臨の約束はどうなったのか。先祖たちが眠りについてから、すべてのものは天地創造の初めからそのままであって、変ってはいない」と言うであろう。</span>
<span className="v" id="v5" data-v="5" data-xref="ヘブル人への手紙 11:3; 創世記 1:9; 詩篇 24:2"> すなわち、彼らはこのことを認めようとはしない。古い昔に天が存在し、地は神の言によって、水がもとになり、また、水によって成ったのであるが、</span>
<span className="v" id="v6" data-v="6" data-xref="マタイによる福音書 24:38–39; ペテロの第二の手紙 2:5; ルカによる福音書 17:27"> その時の世界は、御言により水でおおわれて滅んでしまった。</span>
<span className="v" id="v7" data-v="7" data-xref="ペテロの第二の手紙 3:10; イザヤ書 51:6; ペテロの第二の手紙 3:12"> しかし、今の天と地とは、同じ御言によって保存され、不信仰な人々がさばかれ、滅ぼさるべき日に火で焼かれる時まで、そのまま保たれているのである。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="詩篇 90:4; ローマ人への手紙 11:25; コリント人への第一の手紙 12:1"> 愛する者たちよ。この一事を忘れてはならない。主にあっては、一日は千年のようであり、千年は一日のようである。</span>
<span className="v" id="v9" data-v="9" data-xref="テモテヘの第一の手紙 2:4; ローマ人への手紙 2:4; ハバクク書 2:3"> ある人々がおそいと思っているように、主は約束の実行をおそくしておられるのではない。ただ、ひとりも滅びることがなく、すべての者が悔改めに至ることを望み、あなたがたに対してながく忍耐しておられるのである。</span>
<span className="v" id="v10" data-v="10" data-xref="ヨハネの黙示録 21:1; マタイによる福音書 24:35; ペテロの第二の手紙 3:7"> しかし、主の日は盗人のように襲って来る。その日には、天は大音響をたてて消え去り、天体は焼けてくずれ、地とその上に造り出されたものも、みな焼きつくされるであろう。</span>
<span className="v" id="v11" data-v="11" data-xref="ペテロの第一の手紙 1:15; ピリピ人への手紙 1:27; ペテロの第一の手紙 2:12"> このように、これらはみなくずれ落ちていくものであるから、神の日の到来を熱心に待ち望んでいるあなたがたは、</span>
<span className="v" id="v12" data-v="12" data-xref="ペテロの第二の手紙 3:10; イザヤ書 34:4; ミカ書 1:4"> 極力、きよく信心深い行いをしていなければならない。その日には、天は燃えくずれ、天体は焼けうせてしまう。</span>
<span className="v" id="v13" data-v="13" data-xref="イザヤ書 65:17; ヨハネの黙示録 21:1; イザヤ書 66:22"> しかし、わたしたちは、神の約束に従って、義の住む新しい天と新しい地とを待ち望んでいる。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="テサロニケ人への第一の手紙 5:23; テサロニケ人への第一の手紙 3:13; ピリピ人への手紙 1:10"> 愛する者たちよ。それだから、この日を待っているあなたがたは、しみもなくきずもなく、安らかな心で、神のみまえに出られるように励みなさい。</span>
<span className="v" id="v15" data-v="15" data-xref="ローマ人への手紙 2:4; ペテロの第二の手紙 3:9; テモテヘの第一の手紙 1:16"> また、わたしたちの主の寛容は救のためであると思いなさい。このことは、わたしたちの愛する兄弟パウロが、彼に与えられた知恵によって、あなたがたに書きおくったとおりである。</span>
<span className="v" id="v16" data-v="16" data-xref="マタイによる福音書 15:6; ヘブル人への手紙 5:11; ヤコブの手紙 1:8"> 彼は、どの手紙にもこれらのことを述べている。その手紙の中には、ところどころ、わかりにくい箇所もあって、無学で心の定まらない者たちは、ほかの聖書についてもしているように、無理な解釈をほどこして、自分の滅亡を招いている。</span>
<span className="v" id="v17" data-v="17" data-xref="ヘブル人への手紙 3:14; コロサイ人への手紙 2:8; コリント人への第二の手紙 11:13–15"> 愛する者たちよ。それだから、あなたがたはかねてから心がけているように、非道の者の惑わしに誘い込まれて、あなたがた自身の確信を失うことのないように心がけなさい。</span>
<span className="v" id="v18" data-v="18" data-xref="コロサイ人への手紙 1:10; エペソ人への手紙 4:15; ペテロの第一の手紙 2:2"> そして、わたしたちの主また救主イエス・キリストの恵みと知識とにおいて、ますます豊かになりなさい。栄光が、今も、また永遠の日に至るまでも、主にあるように、アァメン。</span>

<span className="v" id="v1" data-v="1" data-xref="マタイによる福音書 7:15; ユダの手紙 1:4; 申命記 13:1–3"> しかし、民の間に、にせ預言者が起ったことがあるが、それと同じく、あなたがたの間にも、にせ教師が現れるであろう。彼らは、滅びに至らせる異端をひそかに持ち込み、自分たちをあがなって下さった主を否定して、すみやかな滅亡を自分の身に招いている。</span>
<span className="v" id="v2" data-v="2" data-xref="ローマ人への手紙 2:24; ユダの手紙 1:10; ペテロの第一の手紙 2:12"> また、大ぜいの人が彼らの放縦を見習い、そのために、真理の道がそしりを受けるに至るのである。</span>
<span className="v" id="v3" data-v="3" data-xref="コリント人への第二の手紙 2:17; 申命記 32:35; ローマ人への手紙 16:18"> 彼らは、貪欲のために、甘言をもってあなたがたをあざむき、利をむさぼるであろう。彼らに対するさばきは昔から猶予なく行われ、彼らの滅亡も滞ることはない。</span>
<span className="v" id="v4" data-v="4" data-xref="ユダの手紙 1:6; マタイによる福音書 25:41; ローマ人への手紙 8:32"> 神は、罪を犯した御使たちを許しておかないで、彼らを下界におとしいれ、さばきの時まで暗やみの穴に閉じ込めておかれた。</span>
<span className="v" id="v5" data-v="5" data-xref="ヘブル人への手紙 11:7; ペテロの第二の手紙 3:6; ユダの手紙 1:14–15"> また、古い世界をそのままにしておかないで、その不信仰な世界に洪水をきたらせ、ただ、義の宣伝者ノアたち八人の者だけを保護された。</span>
<span className="v" id="v6" data-v="6" data-xref="ユダの手紙 1:7; ルカによる福音書 17:28–30; 申命記 29:23"> また、ソドムとゴモラの町々を灰に帰せしめて破滅に処し、不信仰に走ろうとする人々の見せしめとし、</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 19:16; 創世記 19:29; 創世記 19:7–8"> ただ、非道の者どもの放縦な行いによってなやまされていた義人ロトだけを救い出された。</span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 119:158; エゼキエル書 9:4; 詩篇 119:136"> （この義人は、彼らの間に住み、彼らの不法の行いを日々見聞きして、その正しい心を痛めていたのである。）</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 34:15–19; コリント人への第一の手紙 10:13; ヨハネの黙示録 3:10"> こういうわけで、主は、信心深い者を試錬の中から救い出し、また、不義な者ども、</span>
<span className="v" id="v10" data-v="10" data-xref="ユダの手紙 1:16; ユダの手紙 1:10; ユダの手紙 1:18"> 特に、汚れた情欲におぼれ肉にしたがって歩み、また、権威ある者を軽んじる人々を罰して、さばきの日まで閉じ込めておくべきことを、よくご存じなのである。こういう人々は、大胆不敵なわがまま者であって、栄光ある者たちをそしってはばかるところがない。</span>
<span className="v" id="v11" data-v="11" data-xref="ユダの手紙 1:9; テサロニケ人への第二の手紙 1:7; 詩篇 104:4"> しかし、御使たちは、勢いにおいても力においても、彼らにまさっているにかかわらず、彼らを主のみまえに訴えそしることはしない。</span>
<span className="v" id="v12" data-v="12" data-xref="ユダの手紙 1:10; エレミヤ書 12:3; ガラテヤ人への手紙 6:8"> これらの者は、捕えられ、ほふられるために生れてきた、分別のない動物のようなもので、自分が知りもしないことをそしり、その不義の報いとして罰を受け、必ず滅ぼされてしまうのである。</span>
<span className="v" id="v13" data-v="13" data-xref="ローマ人への手紙 13:13; ローマ人への手紙 2:8–9; ヘブル人への手紙 2:2–3"> 彼らは、真昼でさえ酒食を楽しみ、あなたがたと宴会に同席して、だましごとにふけっている。彼らは、しみであり、きずである。</span>
<span className="v" id="v14" data-v="14" data-xref="ペテロの第二の手紙 2:3; ペテロの第二の手紙 2:18; エペソ人への手紙 2:3"> その目は淫行を追い、罪を犯して飽くことを知らない。彼らは心の定まらない者を誘惑し、その心は貪欲に慣れ、のろいの子となっている。</span>
<span className="v" id="v15" data-v="15" data-xref="ヨハネの黙示録 2:14; ユダの手紙 1:11; 申命記 23:4–5"> 彼らは正しい道からはずれて迷いに陥り、ベオルの子バラムの道に従った。バラムは不義の実を愛し、</span>
<span className="v" id="v16" data-v="16" data-xref="民数記 22:21–33; 伝道の書 7:25; ルカによる福音書 16:11"> そのために、自分のあやまちに対するとがめを受けた。ものを言わないろばが、人間の声でものを言い、この預言者の狂気じみたふるまいをはばんだのである。</span>
<span className="v" id="v17" data-v="17" data-xref="ユダの手紙 1:12–13; エペソ人への手紙 4:14; エレミヤ書 14:3"> この人々は、いわば、水のない井戸、突風に吹きはらわれる霧であって、彼らには暗やみが用意されている。</span>
<span className="v" id="v18" data-v="18" data-xref="ペテロの第二の手紙 2:20; ユダの手紙 1:15–16; ローマ人への手紙 13:13"> 彼らはむなしい誇を語り、迷いの中に生きている人々の間から、かろうじてのがれてきた者たちを、肉欲と色情とによって誘惑し、</span>
<span className="v" id="v19" data-v="19" data-xref="ヨハネによる福音書 8:34; ローマ人への手紙 6:16–22; ガラテヤ人への手紙 5:13"> この人々に自由を与えると約束しながら、彼ら自身は滅亡の奴隷になっている。おおよそ、人は征服者の奴隷となるものである。</span>
<span className="v" id="v20" data-v="20" data-xref="ヘブル人への手紙 10:26–27; ヘブル人への手紙 6:4–8; ピリピ人への手紙 3:19"> 彼らが、主また救主なるイエス・キリストを知ることにより、この世の汚れからのがれた後、またそれに巻き込まれて征服されるならば、彼らの後の状態は初めよりも、もっと悪くなる。</span>
<span className="v" id="v21" data-v="21" data-xref="エゼキエル書 18:24; ヘブル人への手紙 6:4–6; ヤコブの手紙 4:17"> 義の道を心得ていながら、自分に授けられた聖なる戒めにそむくよりは、むしろ義の道を知らなかった方がよい。</span>
<span className="v" id="v22" data-v="22" data-xref="箴言 26:11"> ことわざに、「犬は自分の吐いた物に帰り、豚は洗われても、また、どろの中にころがって行く」とあるが、彼らの身に起ったことは、そのとおりである。</span>

<div className="bp">
<span className="v" id="v1" data-v="1"> 主の言葉がまたわたしに臨んだ、</span>
<span className="v" id="v2" data-v="2" data-xref="アモス書 8:2; ペテロの第一の手紙 4:7; エゼキエル書 7:3"> 「人の子よ、イスラエルの地の終りについて主はこう言われる、この国の四方の境に終りが来た。</span>
<span className="v" id="v3" data-v="3" data-xref="エゼキエル書 18:30; エゼキエル書 5:13; エゼキエル書 33:20"> いま、あなたの終りが来た。わたしはわが怒りをあなたに漏らし、あなたの行いに従って、あなたをさばき、あなたのもろもろの憎むべき物のためにあなたを罰する。</span>
<span className="v" id="v4" data-v="4" data-xref="エゼキエル書 6:7; エゼキエル書 11:21; エゼキエル書 5:11"> わたしの目はあなたを惜しみ見ず、またあなたをあわれまない。わたしはあなたの行いのためにあなたを罰する。あなたの憎むべき事があなたのうちにある。これによって、あなたがたはわたしが主であることを知るようになる。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="ナホム書 1:9; 列王紀下 21:12–13; エゼキエル書 5:9"> 主なる神はこう言われる、災が引き続いて起る。見よ、災が来る。</span>
<span className="v" id="v6" data-v="6" data-xref="ゼカリヤ書 13:7; エゼキエル書 7:3; ペテロの第二の手紙 2:5"> 終りが来る。その終りが来る。それが起って、あなたに臨む。見よ、それが来る。</span>
<span className="v" id="v7" data-v="7" data-xref="エゼキエル書 12:28; エゼキエル書 7:12; イザヤ書 22:5"> この地に住む者よ、あなたの最後の運命があなたに来た。時は来た。日が近づいた。混乱の日で、山々に聞える喜びの日ではない。</span>
<span className="v" id="v8" data-v="8" data-xref="エゼキエル書 9:8; エゼキエル書 14:19; エゼキエル書 20:8"> 今わたしは、すみやかにわたしの憤りをあなたの上に注ぎ、わたしの怒りをあなたに漏らし尽し、あなたの行いに従ってあなたをさばき、あなたのもろもろの憎むべき事のためにあなたを罰する。</span>
<span className="v" id="v9" data-v="9" data-xref="ヨハネの黙示録 20:13; ミカ書 6:9; イザヤ書 9:13"> わたしの目はあなたを惜しみ見ず、またあなたをあわれまない。わたしはあなたの行いのためにあなたを罰する。あなたの憎むべき事があなたのうちにある。これによって、あなたがたは、主であるわたしがあなたを撃つことを知るようになる。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="イザヤ書 10:5; ヤコブの手紙 4:6; テサロニケ人への第一の手紙 5:3"> 見よ、その日を。また見よ、かの日が来た。あなたの最後の運命が来た。不義は花咲き、高ぶりは芽を出した。</span>
<span className="v" id="v11" data-v="11" data-xref="ゼパニヤ書 1:18; エゼキエル書 7:23; イザヤ書 59:6–8"> 暴虐はつのって悪のつえとなった。彼らもその群衆も、その富も消え、また彼らの名声も消えて何も残らなくなる。</span>
<span className="v" id="v12" data-v="12" data-xref="イザヤ書 5:13–14; コリント人への第一の手紙 7:29–31; エゼキエル書 7:5–7"> 時は来た。日は近づいた。買う者は喜ぶな。売る者は悲しむな。怒りがすべての群衆の上に臨むからだ。</span>
<span className="v" id="v13" data-v="13" data-xref="レビ記 25:24–28; レビ記 25:31; ヨブ記 15:25"> 売る者はたとい生きていても、その売ったものに帰ることはない。怒りがそのすべての民衆の上にあるからだ。それはもとに帰らない。その不義のために、だれも命を全うすることはできない。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="エレミヤ書 4:5; エレミヤ書 7:20; エレミヤ書 51:27"> 人々がラッパを吹いて備えをしても戦いに出る者はない。それはわたしの怒りがそのすべての群衆の上にあるからだ。</span>
<span className="v" id="v15" data-v="15" data-xref="エレミヤ書 14:18; エゼキエル書 5:12; 哀歌 1:20"> 外にはつるぎがあり、内には疫病とききんがある。畑にいる者はつるぎに死に、町にいる者はききんと疫病に滅ぼされる。</span>
<span className="v" id="v16" data-v="16" data-xref="イザヤ書 59:11; イザヤ書 38:14; エズラ記 9:15"> そのうちの、のがれる者は谷間のはとのように山々に行って、おのおの皆その罪のために悲しむ。</span>
<span className="v" id="v17" data-v="17" data-xref="エゼキエル書 21:7; ヘブル人への手紙 12:12; エレミヤ書 6:24"> 両手とも弱くなり、両ひざとも水のように弱くなる。</span>
<span className="v" id="v18" data-v="18" data-xref="アモス書 8:10; イザヤ書 15:2–3; イザヤ書 3:24"> 彼らは荒布を身にまとい、恐れが彼らをおおい、すべての顔には恥があらわれ、すべての頭は髪をそり落す。</span>
<span className="v" id="v19" data-v="19" data-xref="箴言 11:4; ゼパニヤ書 1:18; ルカによる福音書 12:19–20"> 彼らはその銀をちまたに捨て、その金はあくたのようになる。主の怒りの日には金銀も彼らを救うことはできない。それらは彼らの飢えを満足させることができない、またその腹を満たすことができない。それは彼らの不義のつまずきであったからだ。</span>
<span className="v" id="v20" data-v="20" data-xref="エゼキエル書 24:21; エレミヤ書 7:30; エゼキエル書 8:15–16"> 彼らはその美しい飾り物を高ぶりのために用い、またこれをもってその憎むべき偶像と忌むべき物を造った。それゆえわたしはこれを彼らに対して汚れたものとする。</span>
<span className="v" id="v21" data-v="21" data-xref="列王紀下 24:13; 詩篇 74:2–8; 歴代志下 36:18–19"> わたしはこれを外国人の手に渡して奪わせ、地の悪人に渡してかすめさせる。彼らはこれを汚す。</span>
<span className="v" id="v22" data-v="22" data-xref="エレミヤ書 18:17; 詩篇 74:18–23; 詩篇 74:10–11"> わたしは彼らから顔をそむけて、彼らにわたしの聖所を汚させる。強盗がこれにはいって汚し、</span>
<span className="v" id="v23" data-v="23" data-xref="エゼキエル書 9:9; エレミヤ書 27:2; エゼキエル書 11:6"> また荒れ地とする。<br />この地は流血のとがに満ち、この町は暴虐に満ちているゆえ、</span>
<span className="v" id="v24" data-v="24" data-xref="エゼキエル書 28:7; 詩篇 106:41; エゼキエル書 21:31"> わたしは国々のうちの悪い者どもを招いて、彼らの家をかすめさせる。わたしは強い者の高ぶりをやめさせる。また彼らの聖所は汚される。</span>
<span className="v" id="v25" data-v="25" data-xref="エレミヤ書 8:15–16; イザヤ書 57:21; 哀歌 4:17–18"> 滅びが来るとき、彼らは平安を求めても得られない。</span>
<span className="v" id="v26" data-v="26" data-xref="エレミヤ書 4:20; エゼキエル書 14:1; ミカ書 3:6"> 災に災が重なりきたり、知らせに知らせが相つぐ。その時、彼らは預言者に幻を求める。しかし律法は祭司のうちに絶え、計りごとは長老のうちに絶える。</span>
<span className="v" id="v27" data-v="27" data-xref="エゼキエル書 18:30; エゼキエル書 7:4–8; エゼキエル書 26:16"> 王は悲しみ、つかさは望みを失い、その地の民の手はおののきによってこわばる。わたしは彼らの行いに従って彼らをあつかい、そのさばきに従って彼らをさばく。そして彼らはわたしが主であることを知るようになる」。</span>
</div>

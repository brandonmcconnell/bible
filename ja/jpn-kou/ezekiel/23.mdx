<div className="bp">
<span className="v" id="v1" data-v="1"> 主の言葉がわたしに臨んだ、</span>
<span className="v" id="v2" data-v="2" data-xref="エゼキエル書 16:44–46; エレミヤ書 3:7–10"> 「人の子よ、ここにふたりの女があった。ひとりの母の娘である。</span>
<span className="v" id="v3" data-v="3" data-xref="レビ記 17:7; エゼキエル書 16:22; ヨシュア記 24:14"> 彼らはエジプトで淫行をした。彼らは若い時に淫行をした。すなわちその所で彼らの胸は押され、その処女の乳ぶさはいじられた。</span>
<span className="v" id="v4" data-v="4" data-xref="エゼキエル書 16:8; 詩篇 76:2; エレミヤ書 2:2–3"> 彼らの名は姉はアホラ、妹はアホリバである。彼らはわたしのものとなって、むすこ娘たちを産んだ。その本名はアホラはサマリヤ、アホリバはエルサレムである。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="ホセア書 5:13; 列王紀下 17:3; 列王紀下 16:7"> アホラはわたしのものである間に淫行をなし、その恋人なるアッスリヤびとにこがれた。</span>
<span className="v" id="v6" data-v="6" data-xref="エゼキエル書 23:23"> すなわち紫の衣をきた軍人、長官、司令官、すべて好ましい若者、馬に乗る者たちである。</span>
<span className="v" id="v7" data-v="7" data-xref="ホセア書 5:3; ホセア書 6:10; エゼキエル書 22:3–4"> 彼女は彼らに淫行を供えた。彼らはすべてアッスリヤのえり抜きの人々である。彼女はまた、そのこがれたすべての者のもろもろの偶像をもって、おのれを汚した。</span>
<span className="v" id="v8" data-v="8" data-xref="エゼキエル書 23:19; エゼキエル書 23:3; 出エジプト記 32:4"> 彼女はエジプトの日からおこなっていた、その淫行を捨てなかった。それは彼女の若い時に、彼らが彼女と寝、その処女の乳ぶさをいじり、その情欲を彼女の上に注いだからである。</span>
<span className="v" id="v9" data-v="9" data-xref="ホセア書 11:5; 列王紀下 15:29; 列王紀下 17:23"> それゆえ、わたしは彼女をその恋人の手に渡し、そのこがれたアッスリヤの人々の手に渡した。</span>
<span className="v" id="v10" data-v="10" data-xref="エゼキエル書 23:29; ホセア書 2:10; エレミヤ書 22:8–9"> 彼らは彼女の裸を現し、そのむすこ娘たちを奪い、つるぎをもって彼女を殺した。こうして彼女に対するさばきが行われたとき、彼女は女たちの間の語り草となった。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="エレミヤ書 3:8–11; エゼキエル書 16:47–51; エゼキエル書 23:4"> その妹アホリバはこれを見て、姉よりも情欲をほしいままにし、姉の淫行よりも多く淫行をなし、</span>
<span className="v" id="v12" data-v="12" data-xref="列王紀下 16:7–15; エゼキエル書 23:23; 歴代志下 28:16–23"> アッスリヤの人々に恋こがれた。長官、司令官、盛装した軍人、馬に乗る者たちで、すべて好ましい若者たちである。</span>
<span className="v" id="v13" data-v="13" data-xref="ホセア書 12:1–2; 列王紀下 17:18–19; エゼキエル書 23:31"> わたしは彼女が身を汚したのを見た。彼らは共に一つの道をたどったが、</span>
<span className="v" id="v14" data-v="14" data-xref="エゼキエル書 8:10; エレミヤ書 22:14; エレミヤ書 50:2"> 彼女はさらにその淫行を続け、壁に描いた人々を見た。すなわち朱で描いたカルデヤびとの像で、</span>
<span className="v" id="v15" data-v="15" data-xref="士師記 8:18; サムエル記上 18:4; イザヤ書 22:21"> 腰には帯を結び、頭にはたれさがったずきんをいただいていた。これらはみな官吏のような姿で、その生れた国カルデヤのバビロン人に似ていた。</span>
<span className="v" id="v16" data-v="16" data-xref="エゼキエル書 16:29; マタイによる福音書 5:28; ヨブ記 31:1"> 彼女はこれらを見て、これに恋こがれ、使者をカルデヤの彼らのもとに送った。</span>
<span className="v" id="v17" data-v="17" data-xref="エゼキエル書 23:28; エゼキエル書 23:22; 創世記 10:10"> そこでバビロンの人々は彼女のもとに来て、恋の床につき、情欲をもって彼女を汚したが、彼女は彼らに汚されるにおよんで、その心は彼らから離れた。</span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 78:59; 詩篇 106:40; エレミヤ書 12:8"> 彼女がその淫行を公然と続け、その裸をさらしたので、わたしの心は彼女から離れた。これはあたかもわたしの心が、彼女の姉から離れたと同様である。</span>
<span className="v" id="v19" data-v="19" data-xref="エゼキエル書 23:3; エゼキエル書 20:7; エゼキエル書 16:51"> しかし彼女はなおエジプトの地で姦淫をしたその若き日を覚えて、その淫行を続け、</span>
<span className="v" id="v20" data-v="20" data-xref="エゼキエル書 17:15; エゼキエル書 16:26; エレミヤ書 5:8"> その情夫たちに恋こがれた。その人の肉は、ろばの肉のごとく、その精は馬の精のようであった。</span>
<span className="v" id="v21" data-v="21"> このようにあなたは、かのエジプトびとが、あなたの胸に手をつけ、あなたの若い乳ぶさをおさえた時の、若い時の淫行を慕っている」。</span>
</div>
<div className="bp poetry">
<span className="v" id="v22" data-v="22" data-xref="エゼキエル書 16:37; ヨハネの黙示録 17:16; エレミヤ書 6:22–23"> それゆえ、アホリバよ、主なる神はこう言われる、「見よ、わたしは、あなたの心がすでに離れたあなたの恋人らを起して、あなたを攻めさせ、彼らに四方から来てあなたを攻めさせる。</span>
<span className="v" id="v23" data-v="23" data-xref="エレミヤ書 50:21; 列王紀下 24:2; 列王紀下 20:14–17"> すなわちバビロンの人々およびカルデヤのすべての人々、ペコデ、ショア、コア、アッスリヤのすべての人々、好ましい若者、長官、司令官、官吏、軍人など、すべて馬に乗る者たちである。</span>
<span className="v" id="v24" data-v="24" data-xref="サムエル記下 24:14; エゼキエル書 26:10; エゼキエル書 23:45"> 彼らは戦車、貨車、および多くの民を率いて、北からあなたに攻めて来る。大盾、小盾、かぶとを備えて、四方からあなたに攻めかかる。わたしが彼らにさばきをゆだねるゆえ、彼らは、そのおきてに従って、あなたをさばく。</span>
<span className="v" id="v25" data-v="25" data-xref="エゼキエル書 23:47; エゼキエル書 8:1–18; エゼキエル書 15:6–7"> わたしはあなたに向かってわたしの憤りを起すゆえ、彼らは怒りをもってあなたを扱い、あなたの鼻と耳とを切り落し、そして残りの者はつるぎに倒れる。彼らはあなたのむすこ娘たちを奪い、生き残った者を火で焼く。</span>
<span className="v" id="v26" data-v="26" data-xref="エゼキエル書 16:39; エレミヤ書 13:22; エゼキエル書 23:29"> 彼らはまたあなたの衣服をはぎ取り、あなたの美しい飾りを取り去る。</span>
<span className="v" id="v27" data-v="27" data-xref="エゼキエル書 16:41; エゼキエル書 23:3; エゼキエル書 23:19"> こうしてわたしはあなたの淫乱と、エジプトの地から持って来た淫行とを取り除き、重ねてあなたの目を、エジプトびとに向けて上げさせず、彼らの事を思わないようにする。</span>
<span className="v" id="v28" data-v="28" data-xref="エゼキエル書 23:22; エゼキエル書 23:17; エレミヤ書 34:20"> 主なる神はこう言われる、見よ、わたしはあなたの憎む者の手、あなたの心の離れた者の手にあなたを渡す。</span>
<span className="v" id="v29" data-v="29" data-xref="エゼキエル書 16:39; エゼキエル書 23:25–26; エゼキエル書 23:45–47"> 彼らは憎しみをもってあなたを扱い、あなたの所得をことごとく取り去り、あなたを赤はだかにし、あなたの淫行の裸を現す。あなたの淫乱と淫行とのゆえに、</span>
<span className="v" id="v30" data-v="30" data-xref="エゼキエル書 6:9; 詩篇 106:35–38; エレミヤ書 2:18–20"> すなわち、あなたが異邦人を慕って姦淫を行い、彼らの偶像をもって身を汚したゆえに、これらのことがあなたに臨むのだ。</span>
<span className="v" id="v31" data-v="31" data-xref="列王紀下 21:13; エレミヤ書 7:14–15; エゼキエル書 16:47–51"> あなたはその姉の道を歩んだので、わたしも彼女の杯をあなたにわたす。</span>
<span className="v" id="v32" data-v="32" data-xref="イザヤ書 51:17; 詩篇 60:3; エゼキエル書 22:4–5"> 主なる神はこう言われる、<br /><span className="pl pl-1">あなたは姉の深い、大きな杯を飲み、</span><br /><span className="pl pl-1">笑い物となり、あざけりとなる、</span><br /><span className="pl pl-1">この杯にはそれらが多くこもっている。</span></span>
<span className="v" id="v33" data-v="33" data-xref="イザヤ書 51:17; エレミヤ書 25:27; エレミヤ書 25:15–16"> <span className="pl pl-1">あなたは酔いと憂いとに満たされる。</span><br /><span className="pl pl-1">驚きと滅びの杯、</span><br /><span className="pl pl-1">これがあなたの姉サマリヤの杯である。</span></span>
<span className="v" id="v34" data-v="34" data-xref="詩篇 75:8; イザヤ書 51:17; ヨハネの黙示録 18:7"> <span className="pl pl-1">あなたはこれを飲みこれをかたむけ、</span><br /><span className="pl pl-1">あなたの髪の毛をひきむしり、</span><br /><span className="pl pl-1">あなたの乳ぶさをかきさく。</span><br />わたしがこれを言うと、主なる神は言われる。</span>
<span className="v" id="v35" data-v="35" data-xref="列王紀上 14:9; イザヤ書 17:10; エレミヤ書 32:33"> それゆえ、主なる神はこう言われる、あなたはわたしを忘れ、わたしをあなたのうしろに捨て去ったゆえ、あなたは自分の淫乱と淫行との罪を負わねばならぬ」。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="エゼキエル書 22:2; イザヤ書 58:1; エゼキエル書 16:2"> 主はわたしに言われた、「人の子よ、あなたはアホラとアホリバをさばくのか。それならば彼らにその憎むべき事を告げよ。</span>
<span className="v" id="v37" data-v="37" data-xref="エゼキエル書 16:36; エレミヤ書 32:35; エレミヤ書 7:31"> 彼らは姦淫を行い、血が彼らの手の上にある。彼らはその偶像と姦淫を行い、またわたしに産んだ子らを、食物のために彼らにささげた。</span>
<span className="v" id="v38" data-v="38" data-xref="エゼキエル書 20:13; 列王紀下 21:7; エゼキエル書 7:20"> さらに彼らは、わたしに対してこのようにした。すなわち、彼らは同じ日にわたしの聖所を汚し、わたしの安息日を犯した。</span>
<span className="v" id="v39" data-v="39" data-xref="列王紀下 21:4; エゼキエル書 44:7; エレミヤ書 23:11"> 彼らはその子らを、偶像にささげるためにほふった同じ日に、わたしの聖所にきて、これを汚した。見よ、彼らがわたしの家の中でしたことはこれである。</span>
<span className="v" id="v40" data-v="40" data-xref="列王紀下 9:30; エレミヤ書 4:30; エゼキエル書 16:13–16"> さらに彼らは使者をやって、遠くから来るように人々を招いた。見よ、彼らはきた。あなたは、この人々のために身を洗い、目を描き、飾り物を身につけ、</span>
<span className="v" id="v41" data-v="41" data-xref="エステル記 1:6; エレミヤ書 44:17; イザヤ書 65:11"> 尊い床に座し、食卓をその前に設け、わたしの香と、わたしの油とを、その上に供えた。</span>
<span className="v" id="v42" data-v="42" data-xref="エゼキエル書 16:11–12; ヨハネの黙示録 12:3; 出エジプト記 32:18–19"> こうして、のんきな群衆の声は彼女と共にあり、また、荒野から連れて来た通りがかりの酔いどれも、彼らと共にいた。彼らは女たちの手に腕輪をはめさせ、頭に美しい冠をいただかせた。</span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="エゼキエル書 23:3; エレミヤ書 13:23; エズラ記 9:7"> そこでわたしは言った、彼女と姦淫を行う時、人々は姦淫を犯さないであろうか。</span>
<span className="v" id="v44" data-v="44" data-xref="エゼキエル書 23:9–13; エゼキエル書 23:3"> 人が遊女の所にはいるように、彼らは彼女の所にはいった。こうして彼らは姦淫を行うために、アホラおよびアホリバの所にはいった。</span>
<span className="v" id="v45" data-v="45" data-xref="ホセア書 6:5; レビ記 20:10; エゼキエル書 23:36–39"> しかし正しい人々は淫婦のさばきと、血を流した女のさばきとをもって、彼らをさばく。それは彼らが淫婦であって、その手に血があるからである」。</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="エゼキエル書 16:40; エレミヤ書 15:4; エレミヤ書 24:9"> 主なる神はこう言われる、「わたしは軍隊を彼らに向かって攻め上らせ、彼らを恐れと略奪とに渡す。</span>
<span className="v" id="v47" data-v="47" data-xref="エゼキエル書 16:40–41; エレミヤ書 39:8; エゼキエル書 24:21"> 軍隊は彼らを石で打ち、つるぎで切り、そのむすこ娘たちを殺し、火でその家を焼く。</span>
<span className="v" id="v48" data-v="48" data-xref="エゼキエル書 6:6; エゼキエル書 23:27; エゼキエル書 16:41"> こうしてわたしはこの地に淫乱を絶やす。すべての女はみずからいましめて、あなたがたがしたような淫乱を行わない。</span>
<span className="v" id="v49" data-v="49" data-xref="エゼキエル書 9:10; エゼキエル書 7:4; エゼキエル書 6:7"> あなたがたの淫乱の報いは、あなたがたの上にくだり、あなたがたはその偶像礼拝の罪を負い、そしてわたしが主なる神であることを知るようになる」。</span>
</div>

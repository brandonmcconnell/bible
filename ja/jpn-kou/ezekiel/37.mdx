<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="エゼキエル書 3:22; エゼキエル書 1:3; 使徒行伝 8:39"> 主の手がわたしに臨み、主はわたしを主の霊に満たして出て行かせ、谷の中にわたしを置かれた。そこには骨が満ちていた。</span>
<span className="v" id="v2" data-v="2" data-xref="詩篇 141:7; エゼキエル書 37:11; 申命記 11:30"> 彼はわたしに谷の周囲を行きめぐらせた。見よ、谷の面には、はなはだ多くの骨があり、皆いたく枯れていた。</span>
<span className="v" id="v3" data-v="3" data-xref="ヨハネによる福音書 11:25–26; ヨハネによる福音書 5:21; 申命記 32:39"> 彼はわたしに言われた、「人の子よ、これらの骨は、生き返ることができるのか」。わたしは答えた、「主なる神よ、あなたはご存じです」。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネによる福音書 5:25; ヨハネによる福音書 5:28–29; マタイによる福音書 21:21"> 彼はまたわたしに言われた、「これらの骨に預言して、言え。枯れた骨よ、主の言葉を聞け。</span>
<span className="v" id="v5" data-v="5" data-xref="エゼキエル書 37:14; 詩篇 104:29–30; 創世記 2:7"> 主なる神はこれらの骨にこう言われる、見よ、わたしはあなたがたのうちに息を入れて、あなたがたを生かす。</span>
<span className="v" id="v6" data-v="6" data-xref="ヨエル書 2:27; イザヤ書 49:23; ヨエル書 3:17"> わたしはあなたがたの上に筋を与え、肉を生じさせ、皮でおおい、あなたがたのうちに息を与えて生かす。そこであなたがたはわたしが主であることを悟る」。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="使徒行伝 2:2; 列王紀上 19:11–13; エレミヤ書 13:5–7"> わたしは命じられたように預言したが、わたしが預言した時、声があった。見よ、動く音があり、骨と骨が集まって相つらなった。</span>
<span className="v" id="v8" data-v="8"> わたしが見ていると、その上に筋ができ、肉が生じ、皮がこれをおおったが、息はその中になかった。</span>
<span className="v" id="v9" data-v="9" data-xref="ヨハネによる福音書 3:8; 雅歌 4:16; 詩篇 104:30"> 時に彼はわたしに言われた、「人の子よ、息に預言せよ、息に預言して言え。主なる神はこう言われる、息よ、四方から吹いて来て、この殺された者たちの上に吹き、彼らを生かせ」。</span>
<span className="v" id="v10" data-v="10" data-xref="ヨハネの黙示録 11:11; 詩篇 104:30; ヨハネの黙示録 20:4–5"> そこでわたしが命じられたように預言すると、息はこれにはいった。すると彼らは生き、その足で立ち、はなはだ大いなる群衆となった。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="エペソ人への手紙 2:1; 詩篇 77:7–9; エゼキエル書 39:25"> そこで彼はわたしに言われた、「人の子よ、これらの骨はイスラエルの全家である。見よ、彼らは言う、『われわれの骨は枯れ、われわれの望みは尽き、われわれは絶え果てる』と。</span>
<span className="v" id="v12" data-v="12" data-xref="イザヤ書 26:19; ホセア書 13:14; テサロニケ人への第一の手紙 4:16"> それゆえ彼らに預言して言え。主なる神はこう言われる、わが民よ、見よ、わたしはあなたがたの墓を開き、あなたがたを墓からとりあげて、イスラエルの地にはいらせる。</span>
<span className="v" id="v13" data-v="13" data-xref="エゼキエル書 37:6; エゼキエル書 16:62; 詩篇 126:2–3"> わが民よ、わたしがあなたがたの墓を開き、あなたがたをその墓からとりあげる時、あなたがたは、わたしが主であることを悟る。</span>
<span className="v" id="v14" data-v="14" data-xref="エゼキエル書 36:27; ヨエル書 2:28–29; エゼキエル書 36:36"> わたしがわが霊を、あなたがたのうちに置いて、あなたがたを生かし、あなたがたをその地に安住させる時、あなたがたは、主なるわたしがこれを言い、これをおこなったことを悟ると、主は言われる」。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15"> 主の言葉がわたしに臨んだ、</span>
<span className="v" id="v16" data-v="16" data-xref="歴代志下 15:9; 歴代志下 10:19; 歴代志下 10:17"> 「人の子よ、あなたは一本の木を取り、その上に『ユダおよびその友であるイスラエルの子孫のために』と書き、また一本の木を取って、その上に『ヨセフおよびその友であるイスラエルの全家のために』と書け。これはエフライムの木である。</span>
<span className="v" id="v17" data-v="17" data-xref="ホセア書 1:11; エレミヤ書 50:4; イザヤ書 11:13"> あなたはこれらを合わせて、一つの木となせ。これらはあなたの手で一つになる。</span>
<span className="v" id="v18" data-v="18" data-xref="エゼキエル書 24:19; エゼキエル書 12:9; エゼキエル書 17:12"> あなたの民の人々があなたに向かって、『これはなんのことであるか、われわれに示してくれないか』と言う時は、</span>
<span className="v" id="v19" data-v="19" data-xref="ゼカリヤ書 10:6; エゼキエル書 37:16–17; エペソ人への手紙 2:13–14"> これに言え、主なる神はこう言われる、見よ、わたしはエフライムの手にあるヨセフと、その友であるイスラエルの部族の木を取り、これをユダの木に合わせて、一つの木となす。これらはわたしの手で一つとなる。</span>
<span className="v" id="v20" data-v="20" data-xref="エゼキエル書 12:3; 民数記 17:6–9; ホセア書 12:10"> あなたが文字を書いた木が、彼らの目の前で、あなたの手にあるとき、</span>
<span className="v" id="v21" data-v="21" data-xref="エゼキエル書 36:24; エレミヤ書 29:14; エレミヤ書 23:8"> あなたは彼らに言え。主なる神は、こう言われる、見よ、わたしはイスラエルの人々を、その行った国々から取り出し、四方から彼らを集めて、その地にみちびき、</span>
<span className="v" id="v22" data-v="22" data-xref="エゼキエル書 37:24; エゼキエル書 34:23–24; エレミヤ書 3:18"> その地で彼らを一つの民となしてイスラエルの山々におらせ、ひとりの王が彼ら全体の王となり、彼らは重ねて二つの国民とならず、再び二つの国に分れない。</span>
<span className="v" id="v23" data-v="23" data-xref="ヨハネの黙示録 21:3–4; エゼキエル書 36:28–29; ヨハネの第一の手紙 1:9"> 彼らはまた、その偶像と、その憎むべきことどもと、もろもろのとがとをもって、身を汚すことはない。わたしは彼らを、その犯したすべての背信から救い出して、これを清める。そして彼らはわが民となり、わたしは彼らの神となる。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="エゼキエル書 34:23–24; ホセア書 3:5; エゼキエル書 37:25"> わがしもべダビデは彼らの王となる。彼らすべての者のために、ひとりの牧者が立つ。彼らはわがおきてに歩み、わが定めを守って行う。</span>
<span className="v" id="v25" data-v="25" data-xref="アモス書 9:15; エゼキエル書 37:24; エゼキエル書 28:25"> 彼らはわがしもべヤコブに、わたしが与えた地に住む。これはあなたがたの先祖の住んだ所である。そこに彼らと、その子らと、その子孫とが永遠に住み、わがしもべダビデが、永遠に彼らの君となる。</span>
<span className="v" id="v26" data-v="26" data-xref="イザヤ書 55:3; エレミヤ書 30:19; エゼキエル書 34:25"> わたしは彼らと平和の契約を結ぶ。これは彼らの永遠の契約となる。わたしは彼らを祝福し、彼らをふやし、わが聖所を永遠に彼らの中に置く。</span>
<span className="v" id="v27" data-v="27" data-xref="ヨハネの黙示録 21:3; ヨハネによる福音書 1:14; エゼキエル書 37:23"> わがすみかは彼らと共にあり、わたしは彼らの神となり、彼らはわが民となる。</span>
<span className="v" id="v28" data-v="28" data-xref="ヨハネによる福音書 17:17–19; エゼキエル書 20:12; 出エジプト記 31:13"> そしてわが聖所が永遠に、彼らのうちにあるようになるとき、諸国民は主なるわたしが、イスラエルを聖別する者であることを悟る」。</span>
</div>

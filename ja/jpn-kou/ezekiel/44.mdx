<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="エゼキエル書 43:1; エゼキエル書 40:17; エゼキエル書 42:14"> こうして、彼はわたしを連れて、聖所の東に向いている外の門に帰ると、門は閉じてあった。</span>
<span className="v" id="v2" data-v="2" data-xref="エゼキエル書 43:2–4; 出エジプト記 24:10; イザヤ書 6:1–5"> 彼はわたしに言った、「この門は閉じたままにしておけ、開いてはならない。ここからだれもはいってはならない。イスラエルの神、主が、ここからはいったのだから、これは閉じたままにしておけ。</span>
<span className="v" id="v3" data-v="3" data-xref="エゼキエル書 46:2; エゼキエル書 34:24; エゼキエル書 37:25"> ただ君たる者だけが、この内に座し、主の前でパンを食し、門の廊を通ってはいり、またそこから外に出よ」。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="エゼキエル書 1:28; ヨハネの黙示録 1:17; エゼキエル書 3:23"> 彼はまたわたしを連れて、北の門の道から宮の前に行った。わたしが見ていると、見よ、主の栄光が主の宮に満ちた。わたしがひれ伏すと、</span>
<span className="v" id="v5" data-v="5" data-xref="エゼキエル書 40:4; エゼキエル書 43:10–11; 申命記 12:32"> 主はわたしに言われた、「人の子よ、主の宮のすべてのおきてと、そのすべての規定とについて、わたしがあなたに告げるすべての事に心をとめ、目を注ぎ、耳を傾けよ。また宮にはいることを許されている者と、聖所にはいることのできない者とに心せよ。</span>
<span className="v" id="v6" data-v="6" data-xref="エゼキエル書 3:9; エゼキエル書 45:9; ペテロの第一の手紙 4:3"> また反逆の家であるイスラエルの家に言え。主なる神は、こう言われる、イスラエルの家よ、その憎むべきことをやめよ。</span>
<span className="v" id="v7" data-v="7" data-xref="レビ記 22:25; エレミヤ書 9:26; エゼキエル書 44:9"> すなわちあなたがたは、わたしの食物である脂肪と血とがささげられる時、心にも肉にも、割礼を受けない異邦人を入れて、わが聖所におらせ、これを汚した。また、もろもろの憎むべきものをもって、わが契約を破った。</span>
<span className="v" id="v8" data-v="8" data-xref="エゼキエル書 44:14; 民数記 18:3–5; エゼキエル書 40:45–46"> あなたがたは、わが聖なる物を守る務を怠り、かえって異邦人を立てて、わが聖所の務を守らせた。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="ヨエル書 3:17; エゼキエル書 44:7; ゼカリヤ書 14:21"> それゆえ、主なる神は、こう言われる、イスラエルの人々のうちにいるすべての異邦人のうち、心と肉とに割礼を受けないすべての者は、わが聖所にはいってはならない。</span>
<span className="v" id="v10" data-v="10" data-xref="エゼキエル書 22:26; エゼキエル書 48:11; 列王紀下 23:8–9"> またレビ人であって、イスラエルが迷った時、偶像を慕い、わたしから迷い出て、遠く離れた者は、その罪を負わなければならない。</span>
<span className="v" id="v11" data-v="11" data-xref="民数記 16:9; 歴代志下 29:34; 歴代志下 30:17"> すなわち彼らはわが聖所で、仕え人となり、宮の門を守る者となり、宮に仕えるしもべとなり、民のために、燔祭および犠牲のものを殺し、彼らの前に立って仕えなければならない。</span>
<span className="v" id="v12" data-v="12" data-xref="列王紀下 16:10–16; 詩篇 106:26; エゼキエル書 14:3–4"> 彼らはその偶像の前で民に仕え、イスラエルの家にとって、罪のつまずきとなったゆえ、主なる神は言われる、わたしは彼らについて誓った。彼らはその罪を負わなければならない。</span>
<span className="v" id="v13" data-v="13" data-xref="民数記 18:3; 列王紀下 23:9; エゼキエル書 16:61"> 彼らはわたしに近づき、祭司として、わたしに仕えることはできない。またわたしの聖なる物、および最も聖なる物に、近づいてはならない。彼らはそのおこなった憎むべきことのため、恥を負わなければならない。</span>
<span className="v" id="v14" data-v="14" data-xref="歴代志上 23:28–32; 民数記 18:4"> しかし彼らには、宮を守る務をさせ、そのもろもろの務と、宮でなすべきすべての事とに当らせる。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="申命記 10:8; エゼキエル書 48:11; エゼキエル書 44:7"> しかしザドクの子孫であるレビの祭司たち、すなわちイスラエルの人々が、わたしを捨てて迷った時に、わが聖所の務を守った者どもは、わたしに仕えるために近づき、脂肪と血とをわたしにささげるために、わたしの前に立てと、主なる神は言われる。</span>
<span className="v" id="v16" data-v="16" data-xref="エゼキエル書 41:22; マラキ書 1:12; 民数記 18:7–8"> すなわち彼らはわが聖所に入り、わが台に近づいてわたしに仕え、わたしの務を守る。</span>
<span className="v" id="v17" data-v="17" data-xref="ヨハネの黙示録 19:8; 出エジプト記 28:43; 出エジプト記 39:27–29"> 彼らが内庭の門にはいる時は、麻の衣服を着なければならない。内庭の門および宮の内で、務をなす時は、毛織物を身につけてはならない。</span>
<span className="v" id="v18" data-v="18" data-xref="出エジプト記 39:28; コリント人への第一の手紙 11:4–10; イザヤ書 3:20"> また頭には亜麻布の冠をつけ、腰には亜麻布の袴をつけなければならない。ただし汗の出るような衣を身につけてはならない。</span>
<span className="v" id="v19" data-v="19" data-xref="エゼキエル書 46:20; レビ記 6:27; レビ記 6:10–11"> 彼らは外庭に出る時、すなわち外庭に出て民に接する時は、務をなす時の衣服は脱いで聖なる室に置き、ほかの衣服を着なければならない。これはその衣服をもって、その聖なることを民にうつさないためである。</span>
<span className="v" id="v20" data-v="20" data-xref="コリント人への第一の手紙 11:14; 民数記 6:5; レビ記 21:5–24"> 彼らはまた頭をそってはならない。また髪を長くのばしてはならない。その頭の髪は切らなければならない。</span>
<span className="v" id="v21" data-v="21" data-xref="レビ記 10:9; テトスヘの手紙 1:7–8; テモテヘの第一の手紙 5:23"> 祭司はすべて内庭にはいる時は、酒を飲んではならない。</span>
<span className="v" id="v22" data-v="22" data-xref="レビ記 21:7; レビ記 21:13–14; テモテヘの第一の手紙 3:2"> また寡婦、および出された女をめとってはならない。ただイスラエルの家の血統の処女、あるいは祭司の妻で、やもめになったものをめとらなければならない。</span>
<span className="v" id="v23" data-v="23" data-xref="エゼキエル書 22:26; レビ記 10:10–11; テモテヘの第二の手紙 2:24–25"> 彼らはわが民に、聖と俗との区別を教え、汚れたものと、清いものとの区別を示さなければならない。</span>
<span className="v" id="v24" data-v="24" data-xref="歴代志上 23:4; エゼキエル書 22:26; 歴代志下 19:8–10"> 争いのある時は、さばきのために立ち、わがおきてにしたがってさばき、また、わたしのもろもろの祭の時は、彼らはわが律法と定めを守り、わが安息日を、聖別しなければならない。</span>
<span className="v" id="v25" data-v="25" data-xref="コリント人への第二の手紙 5:16; レビ記 22:4; マタイによる福音書 8:21–22"> 死人に近づいて、身を汚してはならない。ただ父のため、母のため、むすこのため、娘のため、兄弟のため、夫をもたない姉妹のためには、近よって身を汚すことも許される。</span>
<span className="v" id="v26" data-v="26" data-xref="ヘブル人への手紙 9:13–14; 民数記 19:11–14; 民数記 6:10–21"> このような人は、汚れた後、自身のために、七日の期間を数えよ。そうすれば清まる。</span>
<span className="v" id="v27" data-v="27" data-xref="民数記 6:9–11; エゼキエル書 44:17; レビ記 4:3–35"> 彼は聖所に入り、内庭に行き、聖所で務に当る日には、罪祭をささげなければならないと、主なる神は言われる。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="ヨシュア記 13:33; 民数記 18:20; 申命記 18:1–2"> 彼らには嗣業はない。わたしがその嗣業である。あなたがたはイスラエルの中で、彼らに所有を与えてはならない。わたしが彼らの所有である。</span>
<span className="v" id="v29" data-v="29" data-xref="民数記 18:14; レビ記 27:21; レビ記 27:28"> 彼らは素祭、罪祭、愆祭の物を食べる。すべてイスラエルのうちのささげられた物は彼らの物となる。</span>
<span className="v" id="v30" data-v="30" data-xref="ネヘミヤ書 10:35–37; 歴代志下 31:10; 申命記 18:4"> すべての物の初なりの初物、およびすべてあなたがたのささげるもろもろのささげ物は、みな祭司のものとなる。またあなたがたの麦粉の初物は祭司に与えよ。これはあなたがたの家が、祝福されるためである。</span>
<span className="v" id="v31" data-v="31" data-xref="レビ記 22:8; 出エジプト記 22:31; 申命記 14:21"> 祭司は、鳥でも獣でも、すべて自然に死んだもの、または裂き殺されたものを食べてはならない。</span>
</div>

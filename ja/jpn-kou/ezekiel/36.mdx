<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="エゼキエル書 37:4; エゼキエル書 34:14; エゼキエル書 37:22"> 人の子よ、イスラエルの山々に預言して言え。イスラエルの山々よ、主の言葉を聞け。</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 32:13; エゼキエル書 25:3; エゼキエル書 35:10"> 主なる神はこう言われる、敵はあなたがたについて言う、『ああ、昔の高き所が、われわれのものとなった』と。</span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 44:13–14; 哀歌 2:15–16; エレミヤ書 18:16"> それゆえ、あなたは預言して言え。主なる神はこう言われる、彼らはあなたがたを荒し、四方からあなたがたを打ち滅ぼしたので、あなたがたは他の国民の所有となり、また民の悪いうわさとなった。</span>
<span className="v" id="v4" data-v="4" data-xref="エゼキエル書 34:28; 申命記 11:11; エゼキエル書 36:6"> それゆえ、イスラエルの山々よ、主なる神の言葉を聞け。主なる神は、山と、丘と、くぼ地と、谷と、滅びた荒れ跡と、人の捨てた町々、すなわちその周囲にある諸国民の残った者にかすめられ、あざけられるようになったものに、こう言われる。</span>
<span className="v" id="v5" data-v="5" data-xref="ミカ書 7:8; エゼキエル書 36:3; 詩篇 137:7"> 主なる神はこう言われる、わたしはねたみの炎をもって、他の国民とエドム全国とに対して言う、彼らは心ゆくまで喜び、心に誇ってわが地を自分の所有とし、これを奪い、かすめた者である。</span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 123:3–4; エゼキエル書 34:29; 詩篇 74:23"> それゆえ、あなたはイスラエルの地の事を預言し、山と、丘と、くぼ地と、谷とに言え。主なる神はこう言われる、見よ、あなたがたは諸国民のはずかしめを受けたので、わたしはねたみと怒りとをもって語る。</span>
<span className="v" id="v7" data-v="7" data-xref="エゼキエル書 20:5; アモス書 1:1–15; エゼキエル書 20:15"> それゆえ、主なる神はこう言われる、わたしは誓って言う、あなたがたの周囲の諸国民は必ずはずかしめを受ける。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="イザヤ書 27:6; ヘブル人への手紙 10:37; エゼキエル書 34:26–29"> しかしイスラエルの山々よ、あなたがたは枝を出し、わが民イスラエルのために実を結ぶ。この事の成るのは近い。</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 46:11; ホセア書 2:21–23; エゼキエル書 36:34"> 見よ、わたしはあなたがたに臨み、あなたがたを顧みる。あなたがたは耕され、種をまかれる。</span>
<span className="v" id="v10" data-v="10" data-xref="エゼキエル書 36:33; エレミヤ書 33:12; エゼキエル書 36:37"> わたしはあなたがたの上に人をふやす。これはことごとくイスラエルの家の者となり、町々には人が住み、荒れ跡は建て直される。</span>
<span className="v" id="v11" data-v="11" data-xref="エレミヤ書 33:12; エレミヤ書 23:5–8; エレミヤ書 31:27"> わたしはあなたがたの上に人と獣とをふやす。彼らはふえて、子を生む。わたしはあなたがたの上に、昔のように人を住ませ、初めの時よりも、まさる恵みをあなたがたに施す。その時あなたがたは、わたしが主であることを悟る。</span>
<span className="v" id="v12" data-v="12" data-xref="エレミヤ書 15:7; エゼキエル書 36:13; エレミヤ書 32:44"> わたしはわが民イスラエルの人々をあなたがたの上に歩ませる。彼らはあなたがたを所有し、あなたがたはその嗣業となり、あなたがたは重ねて彼らに子のない嘆きをさせない。</span>
<span className="v" id="v13" data-v="13" data-xref="民数記 13:32"> 主なる神はこう言われる、彼らはあなたがたに向かって、『あなたは人を食い、あなたの民に子のない嘆きをさせる』と言う。</span>
<span className="v" id="v14" data-v="14" data-xref="エゼキエル書 37:25–28; アモス書 9:15; イザヤ書 60:21"> あなたはもはや人を食わない。あなたの民に重ねて子のない嘆きをさせることはないと、主なる神は言われる。</span>
<span className="v" id="v15" data-v="15" data-xref="エゼキエル書 34:29; 詩篇 89:50; エゼキエル書 36:6"> わたしは重ねて諸国民のはずかしめをあなたに聞かせない。あなたは重ねて、もろもろの民のはずかしめを受けることはなく、あなたの民を重ねてつまずかせることはないと、主なる神は言われる」。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16"> 主の言葉がわたしに臨んだ、</span>
<span className="v" id="v17" data-v="17" data-xref="エレミヤ書 2:7; 民数記 35:33–34; ミカ書 2:10"> 「人の子よ、昔、イスラエルの家が、自分の国に住んだとき、彼らはおのれのおこないとわざとをもって、これを汚した。そのおこないは、わたしの前には、汚れにある女の汚れのようであった。</span>
<span className="v" id="v18" data-v="18" data-xref="歴代志下 34:21; エゼキエル書 7:8; 哀歌 2:4"> 彼らが国に血を流し、またその偶像をもって、国を汚したため、わたしはわが怒りを彼らの上に注ぎ、</span>
<span className="v" id="v19" data-v="19" data-xref="エゼキエル書 39:24; 申命記 28:64; エゼキエル書 5:12"> 彼らを諸国民の中に散らしたので、彼らは国々の中に散った。わたしは彼らのおこないと、わざとにしたがって、彼らをさばいた。</span>
<span className="v" id="v20" data-v="20" data-xref="ローマ人への手紙 2:24; イザヤ書 52:5; エレミヤ書 33:24"> 彼らがその行くところの国々へ行ったとき、わが聖なる名を汚した。これは人々が彼らについて『これは主の民であるが、その国から出た者である』と言ったからである。</span>
<span className="v" id="v21" data-v="21" data-xref="イザヤ書 48:9; 詩篇 74:18; エゼキエル書 20:9"> しかしわたしはイスラエルの家が、その行くところの諸国民の中で汚したわが聖なる名を惜しんだ。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="詩篇 106:8; エゼキエル書 36:32; 詩篇 115:1–2"> それゆえ、あなたはイスラエルの家に言え。主なる神はこう言われる、イスラエルの家よ、わたしがすることはあなたがたのためではない。それはあなたがたが行った諸国民の中で汚した、わが聖なる名のためである。</span>
<span className="v" id="v23" data-v="23" data-xref="エゼキエル書 20:41; イザヤ書 5:16; エゼキエル書 39:7"> わたしは諸国民の中で汚されたもの、すなわち、あなたがたが彼らの中で汚した、わが大いなる名の聖なることを示す。わたしがあなたがたによって、彼らの目の前に、わたしの聖なることを示す時、諸国民はわたしが主であることを悟ると、主なる神は言われる。</span>
<span className="v" id="v24" data-v="24" data-xref="エゼキエル書 37:21; エゼキエル書 34:13; アモス書 9:14–15"> わたしはあなたがたを諸国民の中から導き出し、万国から集めて、あなたがたの国に行かせる。</span>
<span className="v" id="v25" data-v="25" data-xref="ヘブル人への手紙 10:22; ヨハネによる福音書 3:5; エレミヤ書 33:8"> わたしは清い水をあなたがたに注いで、すべての汚れから清め、またあなたがたを、すべての偶像から清める。</span>
<span className="v" id="v26" data-v="26" data-xref="エゼキエル書 11:19–20; 詩篇 51:10; コリント人への第二の手紙 5:17"> わたしは新しい心をあなたがたに与え、新しい霊をあなたがたの内に授け、あなたがたの肉から、石の心を除いて、肉の心を与える。</span>
<span className="v" id="v27" data-v="27" data-xref="テトスヘの手紙 3:3–6; ヘブル人への手紙 13:21; コリント人への第一の手紙 3:16"> わたしはまたわが霊をあなたがたのうちに置いて、わが定めに歩ませ、わがおきてを守ってこれを行わせる。</span>
<span className="v" id="v28" data-v="28" data-xref="エレミヤ書 31:33; エレミヤ書 32:38; エゼキエル書 37:27"> あなたがたは、わたしがあなたがたの先祖に与えた地に住んで、わが民となり、わたしはあなたがたの神となる。</span>
<span className="v" id="v29" data-v="29" data-xref="ヨハネによる福音書 1:7–9; マタイによる福音書 1:21; ホセア書 2:21–23"> わたしはあなたがたをそのすべての汚れから救い、穀物を呼びよせてこれを増し、ききんをあなたがたに臨ませない。</span>
<span className="v" id="v30" data-v="30" data-xref="エゼキエル書 34:27; ヨエル書 2:26; 申命記 29:23–28"> またわたしは木の実と、田畑の作物とを多くする。あなたがたは重ねて諸国民の間に、ききんのはずかしめを受けることがない。</span>
<span className="v" id="v31" data-v="31" data-xref="エゼキエル書 6:9; エゼキエル書 20:43; ネヘミヤ書 9:26–35"> その時あなたがたは自身の悪しきおこないと、良からぬわざとを覚えて、その罪と、その憎むべきこととのために、みずから恨む。</span>
<span className="v" id="v32" data-v="32" data-xref="申命記 9:5; エゼキエル書 36:22; テモテヘの第二の手紙 1:9"> わたしがなすことはあなたがたのためではないと、主なる神は言われる。あなたがたはこれを知れ。イスラエルの家よ、あなたがたは自分のおこないを恥じて悔やむべきである。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="イザヤ書 58:12; エゼキエル書 36:10; エレミヤ書 33:10"> 主なる神はこう言われる、わたしは、あなたがたのすべての罪を清める日に、町々に人を住ませ、その荒れ跡を建て直す。</span>
<span className="v" id="v34" data-v="34" data-xref="エゼキエル書 6:14; エレミヤ書 25:9–11; 歴代志下 36:21"> 荒れた地は、行き来の人々の目に荒れ地と見えたのに引きかえて耕される。</span>
<span className="v" id="v35" data-v="35" data-xref="イザヤ書 51:3; ヨエル書 2:3; エレミヤ書 33:9"> そこで人々は言う、『この荒れた地は、エデンの園のようになった。荒れ、滅び、くずれた町々は、堅固になり、人の住む所となった』と。</span>
<span className="v" id="v36" data-v="36" data-xref="マタイによる福音書 24:35; 民数記 23:19; エゼキエル書 17:24"> あなたがたの周囲に残った諸国民は主なるわたしがくずれた所を建て直し、荒れた所にものを植えたということを悟るようになる。主なるわたしがこれを言い、これをなすのである。</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="ヨハネの第一の手紙 5:14; ヘブル人への手紙 10:21–22; エゼキエル書 14:3"> 主なる神はこう言われる、イスラエルの家は、わたしが次のことを彼らのためにするように、わたしに求めるべきである。すなわち人を群れのようにふやすこと、</span>
<span className="v" id="v38" data-v="38" data-xref="列王紀上 8:63; 使徒行伝 2:5–11; ヨハネによる福音書 10:16"> すなわち犠牲のための群れのように、エルサレムの祝い日の群れのようにすることである。こうして荒れた町々は人の群れで満ちる。その時人々は、わたしが主であることを悟るようになる」。</span>
</div>

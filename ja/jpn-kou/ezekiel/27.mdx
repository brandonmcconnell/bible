<div className="bp poetry">
<span className="v" id="v1" data-v="1"> 主の言葉がわたしに臨んだ、</span>
<span className="v" id="v2" data-v="2" data-xref="エゼキエル書 19:1; エレミヤ書 9:10; エゼキエル書 28:12"> 「人の子よ、ツロのために悲しみの歌をのべ、</span>
<span className="v" id="v3" data-v="3" data-xref="エゼキエル書 27:4; イザヤ書 23:11; イザヤ書 23:2–3"> 海の入口に住んで、多くの海沿いの国々の民の商人であるツロに対して言え、主なる神はこう言われる、<br /><span className="pl pl-1">ツロよ、あなたは言った、</span><br /><span className="pl pl-1">『わたしの美は完全である』と。</span></span>
<span className="v" id="v4" data-v="4" data-xref="エゼキエル書 26:5"> <span className="pl pl-1">あなたの境は海の中にあり、</span><br /><span className="pl pl-1">あなたの建設者はあなたの美を完全にした。</span></span>
<span className="v" id="v5" data-v="5" data-xref="申命記 3:9; イザヤ書 14:8; 雅歌 4:8"> <span className="pl pl-1">人々はセニルのもみの木で</span><br /><span className="pl pl-1">あなたのために船板を造り、</span><br /><span className="pl pl-1">レバノンから香柏をとって、</span><br /><span className="pl pl-1">あなたのために帆柱を造り、</span></span>
<span className="v" id="v6" data-v="6" data-xref="創世記 10:4; イザヤ書 2:13; ゼカリヤ書 11:2"> <span className="pl pl-1">バシャンのかしの木で、</span><br /><span className="pl pl-1">あなたのためにかいを造り、</span><br /><span className="pl pl-1">クプロの島から来る松の木に象牙をはめて、</span><br /><span className="pl pl-1">あなたのために甲板を造った。</span></span>
<span className="v" id="v7" data-v="7" data-xref="エレミヤ書 10:9; 出エジプト記 25:4; 創世記 10:4"> <span className="pl pl-1">あなたの帆はエジプトから来るあや布であって、</span><br /><span className="pl pl-1">あなたの旗に用いられ、</span><br /><span className="pl pl-1">あなたのおおいはエリシャの海岸から来る</span><br /><span className="pl pl-1">青と紫の布である。</span></span>
<span className="v" id="v8" data-v="8" data-xref="創世記 10:18; 列王紀上 9:27; エゼキエル書 27:11"> <span className="pl pl-1">あなたのこぎ手は、</span><br /><span className="pl pl-1">シドンとアルワデの住民、</span><br /><span className="pl pl-1">あなたのかじとりは、</span><br /><span className="pl pl-1">あなたのうちにいる熟練なゼメルの人々である。</span></span>
<span className="v" id="v9" data-v="9" data-xref="列王紀上 5:18; ヨシュア記 13:5; 詩篇 83:7"> <span className="pl pl-1">ゲバルの老人たち、およびその熟練な人々は、</span><br /><span className="pl pl-1">あなたのうちにいて漏りを繕い、</span><br /><span className="pl pl-1">海のすべての船およびその船員らは</span><br /><span className="pl pl-1">あなたのうちにいて、あなたの商品を交易する。</span></span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="エゼキエル書 38:5; エゼキエル書 30:5; イザヤ書 66:19"> ペルシャ人、ルデびと、プテびとはあなたの軍に加わって、あなたの戦士となる。彼らはあなたのうちに、盾とかぶとを掛け、あなたに輝きをそえた。</span>
<span className="v" id="v11" data-v="11" data-xref="エゼキエル書 27:3–4"> アルワデとヘレクの人々は、あなたの周囲の城壁の上にあり、ガマデの人々は、あなたのやぐらの中にあり、彼らは、あなたの周囲の城壁にその盾を掛けて、あなたの美観を全うした。</span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="創世記 10:4; イザヤ書 23:10; エゼキエル書 38:13"> あなたはそのすべての貨物に富むゆえに、タルシシはあなたと交易をなし、銀、鉄、すず、鉛をあなたの商品と交換した。</span>
<span className="v" id="v13" data-v="13" data-xref="創世記 10:2; イザヤ書 66:19; エゼキエル書 39:1"> ヤワン、トバル、およびメセクはあなたと取引し、彼らは人身と青銅の器とを、あなたの商品と交換した。</span>
<span className="v" id="v14" data-v="14" data-xref="創世記 10:3; エゼキエル書 38:6; 歴代志上 1:6"> ベテ・トガルマは馬、軍馬、および騾馬をあなたの商品と交換した。</span>
<span className="v" id="v15" data-v="15" data-xref="創世記 10:7; ヨハネの黙示録 18:12; 列王紀上 10:22"> ローヅ島の人々はあなたと取引し、多くの海沿いの国々は、あなたの市場となり、象牙と黒たんとを、みつぎとしてあなたに持ってきた。</span>
<span className="v" id="v16" data-v="16" data-xref="士師記 10:6; エゼキエル書 28:13; サムエル記下 10:6"> あなたの製品が多いので、エドムはあなたと商売し、彼らは赤玉、紫、縫い取りの布、細布、さんご、めのうをもって、あなたの商品と交換した。</span>
<span className="v" id="v17" data-v="17" data-xref="士師記 11:33; 列王紀上 5:9; エレミヤ書 8:22"> ユダとイスラエルの地は、あなたと取引し、麦、オリブ、いちじく、蜜、油、および乳香をもって、あなたの商品と交換した。</span>
<span className="v" id="v18" data-v="18" data-xref="イザヤ書 7:8; 創世記 15:2; エゼキエル書 47:16–18"> あなたの製品が多く、あなたの富が多いので、ダマスコはあなたと取引し、ヘルボンの酒と、さらした羊毛と、</span>
<span className="v" id="v19" data-v="19" data-xref="出エジプト記 30:23–24; 詩篇 45:8; 雅歌 4:13–14"> ウザルの酒をもって、あなたの商品と交換し、銑鉄、肉桂、菖蒲をもって、あなたの商品と交易した。</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 25:3; エゼキエル書 27:15"> デダンは乗物の鞍敷をもって、あなたと取引した。</span>
<span className="v" id="v21" data-v="21" data-xref="イザヤ書 60:7; 創世記 25:13; 列王紀上 10:15"> アラビヤびと、およびケダルのすべての君たちは小羊、雄羊、やぎをもって、あなたと取引し、これらの物をあなたと交易した。</span>
<span className="v" id="v22" data-v="22" data-xref="創世記 10:7; イザヤ書 60:6; 詩篇 72:10"> シバとラアマの商人は、あなたと取引し、もろもろの尊い香料と、もろもろの宝石と金とをもって、あなたの商品と交換した。</span>
<span className="v" id="v23" data-v="23" data-xref="列王紀下 19:12; イザヤ書 37:12; アモス書 1:5"> ハラン、カンネ、エデン、アッスリヤ、キルマデはあなたと取引した。</span>
<span className="v" id="v24" data-v="24" data-xref="列王紀下 2:8"> 彼らは、はなやかな衣服と、青く縫い取りした布と、ひもで結んで、じょうぶにした敷物などをもって、あなたと取引した。</span>
<span className="v" id="v25" data-v="25" data-xref="イザヤ書 2:16; 詩篇 48:7; イザヤ書 23:14"> タルシシの船はあなたの商品を運んでまわった。<br /><span className="pl pl-1">あなたは海の中にいて満ち足り、いたく栄えた。</span></span>
<span className="v" id="v26" data-v="26" data-xref="詩篇 48:7; エゼキエル書 26:19; 使徒行伝 27:14"> <span className="pl pl-1">あなたのこぎ手らはあなたを大海の中に進め、</span><br /><span className="pl pl-1">海の中で東風があなたの船を破った。</span></span>
<span className="v" id="v27" data-v="27" data-xref="箴言 11:4; エゼキエル書 27:24; エゼキエル書 27:12"> <span className="pl pl-1">あなたの財宝、あなたの貨物、あなたの商品、</span><br /><span className="pl pl-1">あなたの船員、あなたのかじ取り、</span><br /><span className="pl pl-1">あなたの漏りを繕う者、あなたの商品を商う者、</span><br /><span className="pl pl-1">あなたの中にいるすべての軍人、</span><br /><span className="pl pl-1">あなたの中にいるすべての仲間は皆、</span><br /><span className="pl pl-1">あなたの破滅の日に海の中に沈む。</span></span>
<span className="v" id="v28" data-v="28" data-xref="エゼキエル書 26:10; 出エジプト記 15:14; エゼキエル書 31:16"> <span className="pl pl-1">あなたのかじ取りの叫び声に、近郷は震い、</span></span>
<span className="v" id="v29" data-v="29" data-xref="エゼキエル書 26:16; エゼキエル書 32:10; ヨハネの黙示録 18:17–24"> <span className="pl pl-1">すべてかいをとる者は船からくだる。</span><br /><span className="pl pl-1">船員および海のすべてのかじ取りは海べに立ち、</span></span>
<span className="v" id="v30" data-v="30" data-xref="エレミヤ書 6:26; サムエル記下 1:2; 哀歌 2:10"> <span className="pl pl-1">あなたのために声をあげて泣き、はげしく叫び、</span><br /><span className="pl pl-1">ちりをこうべにかぶり、灰の中にまろび、</span></span>
<span className="v" id="v31" data-v="31" data-xref="エゼキエル書 7:18; イザヤ書 22:12; イザヤ書 15:2"> <span className="pl pl-1">あなたのために髪をそり、荒布をまとい、</span><br /><span className="pl pl-1">あなたのために心を痛めて泣き、はげしく嘆く。</span></span>
<span className="v" id="v32" data-v="32" data-xref="エゼキエル書 26:17; ヨハネの黙示録 18:18; エゼキエル書 27:2"> <span className="pl pl-1">彼らは悲しんで、あなたのために悲しみの歌をのべ、</span><br /><span className="pl pl-1">あなたを弔って言う、</span><br /><span className="pl pl-1">『だれかツロのように海の中で滅びたものがあるか。</span></span>
<span className="v" id="v33" data-v="33" data-xref="ヨハネの黙示録 18:19; エゼキエル書 27:3; エゼキエル書 28:16"> <span className="pl pl-1">あなたの商品が海を越えてきた時、</span><br /><span className="pl pl-1">あなたは多くの民を飽かせ、</span><br /><span className="pl pl-1">あなたの多くの財宝と商品とをもって、</span><br /><span className="pl pl-1">地の王たちを富ませた。</span></span>
<span className="v" id="v34" data-v="34" data-xref="エゼキエル書 27:26–27; ゼカリヤ書 9:3–4; エゼキエル書 26:19–21"> <span className="pl pl-1">今あなたは海で破船し、深い水に沈み、</span><br /><span className="pl pl-1">あなたの商品と、あなたのすべての船員とは、</span><br /><span className="pl pl-1">あなたと共に沈んだ。</span></span>
<span className="v" id="v35" data-v="35" data-xref="エゼキエル書 32:10; イザヤ書 23:6; エゼキエル書 26:15–18"> <span className="pl pl-1">海沿いの国々に住む者は皆あなたについて驚き、</span><br /><span className="pl pl-1">その王たちは大いに恐れてその顔を震わす。</span></span>
<span className="v" id="v36" data-v="36" data-xref="エレミヤ書 18:16; 詩篇 37:10; ゼパニヤ書 2:15"> <span className="pl pl-1">もろもろの民の中の商人らはあなたをあざける。</span><br /><span className="pl pl-1">あなたは恐るべき終りを遂げ、</span><br /><span className="pl pl-1">永遠にうせはてる』」。</span></span>
</div>

<span className="v" id="v1" data-v="1" data-xref="エゼキエル書 30:20; エレミヤ書 52:5–6; エゼキエル書 1:2"> 第十一年の三月一日に主の言葉がわたしに臨んだ、</span>
<span className="v" id="v2" data-v="2" data-xref="エゼキエル書 29:19; エゼキエル書 30:10; エゼキエル書 31:18"> 「人の子よ、エジプトの王パロと、その民衆とに言え、<br /><span className="pl pl-1">あなたはその大いなること、だれに似ているか。</span></span>
<span className="v" id="v3" data-v="3" data-xref="イザヤ書 10:33–34; ダニエル書 4:10; ダニエル書 4:20–23"> <span className="pl pl-1">見よ、わたしはあなたを</span><br /><span className="pl pl-1">レバノンの香柏のようにする。</span><br /><span className="pl pl-1">麗しき枝と森の陰があり、たけが高く、</span><br /><span className="pl pl-1">その頂は雲の中にある。</span></span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネの黙示録 17:15; 箴言 14:28; エゼキエル書 17:5"> <span className="pl pl-1">水はこれを育て、</span><br /><span className="pl pl-1">大水がこれを高くする。</span><br /><span className="pl pl-1">その川々はその植えた所をめぐって流れ、</span><br /><span className="pl pl-1">その流れを野のすべての木に送る。</span></span>
<span className="v" id="v5" data-v="5" data-xref="ダニエル書 4:11; エゼキエル書 17:5; 詩篇 1:3"> <span className="pl pl-1">これによってそのたけは、</span><br /><span className="pl pl-1">野のすべての木よりも高くなり、</span><br /><span className="pl pl-1">その育つとき多くの水のために</span><br /><span className="pl pl-1">枝葉は茂り、枝は伸び、</span></span>
<span className="v" id="v6" data-v="6" data-xref="エゼキエル書 17:23; マタイによる福音書 13:32; ダニエル書 4:12"> <span className="pl pl-1">その枝葉に空のすべての鳥が、巣をつくり、</span><br /><span className="pl pl-1">その枝の下に野のすべての獣は子を生み、</span><br /><span className="pl pl-1">その陰にもろもろの国民は住む。</span></span>
<span className="v" id="v7" data-v="7"> <span className="pl pl-1">これはその大きなことと、</span><br /><span className="pl pl-1">その枝の長いことによって美しかった。</span><br /><span className="pl pl-1">その根を多くの水に、おろしていたからである。</span></span>
<span className="v" id="v8" data-v="8" data-xref="エゼキエル書 28:13; 創世記 13:10; イザヤ書 51:3"> <span className="pl pl-1">神の園の香柏も、これと競うことはできない。</span><br /><span className="pl pl-1">もみの木もその枝葉に及ばない。</span><br /><span className="pl pl-1">けやきもその枝と比べられない。</span><br /><span className="pl pl-1">神の園のすべての木も、その麗しきこと、</span><br /><span className="pl pl-1">これに比すべきものはない。</span></span>
<span className="v" id="v9" data-v="9" data-xref="エゼキエル書 28:13; ダニエル書 2:37–38; 創世記 13:10"> <span className="pl pl-1">わたしはその枝を多くして、これを美しくした。</span><br /><span className="pl pl-1">神の園にあるエデンの木は皆</span><br /><span className="pl pl-1">これをうらやんだ。</span></span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="エゼキエル書 28:17; ダニエル書 5:20; 歴代志下 32:25"> それゆえ、主なる神はこう言われる、これは、たけが高くなり、その頂を雲の中におき、その心が高ぶりおごるゆえ、</span>
<span className="v" id="v11" data-v="11" data-xref="エゼキエル書 32:11–12; ナホム書 3:18; ダニエル書 5:18–19"> わたしはこれを、もろもろの国民の力ある者の手に渡す。彼はこれに対してその悪のために正しい処置をとる。わたしはこれを追い出した。</span>
<span className="v" id="v12" data-v="12" data-xref="エゼキエル書 28:7; エゼキエル書 35:8; エゼキエル書 30:11"> もろもろの国民の最も恐れている異邦人はこれを切り倒して捨てる。その枝はもろもろの山と、すべての谷とに落ち、その枝葉は砕けて、地のすべての流れにあり、地のすべての民は、その陰を離れて、これを捨てる。</span>
<span className="v" id="v13" data-v="13" data-xref="エゼキエル書 32:4; エゼキエル書 29:5; イザヤ書 18:6"> その倒れた所に、空のもろもろの鳥は住み、その枝の上に、野のもろもろの獣はいる。</span>
<span className="v" id="v14" data-v="14" data-xref="詩篇 63:9–10; ネヘミヤ書 13:18; ペテロの第二の手紙 2:6"> これは水のほとりのすべての木が、その高さのために誇ることなく、その頂を雲の中におくことなく、水に潤う木が、みずから高ぶり立つことのないためである。これらは皆、死に渡され、下の国に入り、穴に下る者と共に他の人々のうちにいる。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="マラキ書 3:4; ナホム書 2:8–10; ヨハネの黙示録 18:9–11"> 主なる神はこう言われる、これが陰府に下る日にわたしが淵をこれがために悲しませ、その川々をせきとめるので、大水はとどまる。わたしはレバノンを、これがために嘆かせ、野のすべての木を、これがために衰えさせる。</span>
<span className="v" id="v16" data-v="16" data-xref="イザヤ書 14:15; イザヤ書 14:8; エゼキエル書 26:15"> わたしがこれを穴に下る者と共に陰府に落す時、もろもろの国民をその落ちる響きのために、打ち震えさせる。そしてエデンのすべての木、レバノンのすぐれて美しいもの、すべて水に潤うものは、下の国で慰められる。</span>
<span className="v" id="v17" data-v="17" data-xref="詩篇 9:17; エゼキエル書 31:6; エゼキエル書 31:3"> 彼らもこれと共に陰府に下り、つるぎで殺された者のところに至る。まことにもろもろの国民のうちで、その陰に住んだ者も滅びる。</span>
<span className="v" id="v18" data-v="18" data-xref="エゼキエル書 32:19; エゼキエル書 32:21; エゼキエル書 28:10"> エデンの木のうちで、その栄えと大いなることで、あなたはどれに似ているのか。あなたはこのように、エデンの木と共に、下の国に落され、つるぎで殺された者と共に、割礼を受けない者のうちに住む。<br />これがパロとその民衆であると、主なる神は言われる」。</span>

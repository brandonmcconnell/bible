<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 時に主の言葉がわたしに臨んだ、</span>
<span className="v" id="v2" data-v="2" data-xref="エゼキエル書 20:49; マタイによる福音書 13:35; コリント人への第一の手紙 13:12"> 「人の子よ、イスラエルの家になぞをかけ、たとえを語って、</span>
<span className="v" id="v3" data-v="3" data-xref="ホセア書 8:1; エレミヤ書 48:40; エゼキエル書 17:7"> 言え。主なる神がこう言われる、さまざまの色の羽毛を多く持ち、大きな翼と、長い羽根とを持つ大わしがレバノンに来て、香柏のこずえにとまり、</span>
<span className="v" id="v4" data-v="4" data-xref="イザヤ書 43:14; イザヤ書 47:15; ヨハネの黙示録 18:11–19"> その若枝の頂を摘み切り、これを商業の地に運び、商人の町に置いた。</span>
<span className="v" id="v5" data-v="5" data-xref="イザヤ書 44:4; 申命記 8:7–9; エレミヤ書 37:1"> またその地の種をとって、これを肥えた土に植えた。すなわち水の多い所にもって行って、柳を植えるようにこれを植えた。</span>
<span className="v" id="v6" data-v="6" data-xref="エゼキエル書 17:14; 箴言 16:18–19"> これが成長して、たけ低く、はびこるぶどうの木となり、枝はわしに向かい、根はわしの下にあり、こうしてついにぶどうの木となり、枝を伸ばし、葉を出した。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="エゼキエル書 31:4; エゼキエル書 17:15; 列王紀下 24:20"> ここにまた大きな翼と、羽毛の多いほかの一羽の大わしがあった。見よ、このぶどうの木は、潤いを得るために、その根をわしに向かってまげ、その枝をわしに向かって伸ばした。</span>
<span className="v" id="v8" data-v="8" data-xref="エゼキエル書 17:5–6"> これが枝を出し、実を結び、みごとなぶどうの木となるために、わしはこれを植えた苗床から水の多い良い地に移し植えた。</span>
<span className="v" id="v9" data-v="9" data-xref="エゼキエル書 17:10; エレミヤ書 32:5; イザヤ書 30:1–7"> あなたは、主なる神がこう言われると言え、これは栄えるであろうか。わしはその根を抜き、その枝を切り、その若葉を皆枯らさないであろうか。これをその根からあげるには、強い腕や多くの民を必要としない。</span>
<span className="v" id="v10" data-v="10" data-xref="ホセア書 13:15; ヨハネによる福音書 15:6; マタイによる福音書 21:19"> 見よ、それが移し植えられたら、また栄えるであろうか。東風がこれを打つ時、それは枯れてしまわないであろうか。その育った苗床で枯れないであろうか」。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11"> 主の言葉がまたわたしに臨んだ、</span>
<span className="v" id="v12" data-v="12" data-xref="エゼキエル書 24:19; エゼキエル書 17:3; エゼキエル書 1:2"> 「反逆の家に言え。これらがなんであるかをあなたがたは知らないのか。彼らに言え、見よ、バビロンの王がエルサレムにきて、その王とつかさとを捕え、これをバビロンに引いて行った。</span>
<span className="v" id="v13" data-v="13" data-xref="歴代志下 36:13; 列王紀下 24:15–17; エゼキエル書 17:5"> また王の子孫のひとりを捕えて、これと契約を結び、誓いを立てさせ、また国のおもだった人々を捕えて行った。</span>
<span className="v" id="v14" data-v="14" data-xref="エゼキエル書 29:14; 申命記 28:43; サムエル記上 2:30"> これはこの国を卑しくして、みずから立つことができないようにし、その契約を守ることによって立たせるためである。</span>
<span className="v" id="v15" data-v="15" data-xref="エレミヤ書 52:3; エレミヤ書 38:18; エゼキエル書 17:7"> しかし彼はバビロンの王にそむき、使者をエジプトに送って、馬と多くの兵とをそこから獲ようとした。彼は成功するだろうか。このようなことをなす者は、のがれることができようか。</span>
<span className="v" id="v16" data-v="16" data-xref="エゼキエル書 12:13; エレミヤ書 52:11; エゼキエル書 17:18–19"> 契約を破ってなおのがれることができようか。主なる神は言われる、わたしは生きている、必ず彼は自分を王となした王の住む所、彼が立てた誓いを軽んじ、その契約を破った相手の王のいるバビロンで彼は死ぬ。</span>
<span className="v" id="v17" data-v="17" data-xref="エレミヤ書 37:7; エゼキエル書 4:2; エゼキエル書 29:6–7"> 多くの命を断つために塁を築き、雲梯を建てるとき、パロは決して大いなる軍勢と、多くの人とをもって、彼を助けて戦いをしない。</span>
<span className="v" id="v18" data-v="18" data-xref="歴代志上 29:24; 歴代志下 30:8; 哀歌 5:6"> 彼は誓いを軽んじ、契約を破り、その手を与えて誓いながら、なおこれらの事をしたゆえ、のがれることはできない。</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 5:11; エレミヤ書 5:9; エレミヤ書 5:2"> それゆえ、主なる神はこう言われる、わたしは生きている、彼がわたしの誓いを軽んじ、わたしの契約を破ったことを、必ず彼のこうべに報いる。</span>
<span className="v" id="v20" data-v="20" data-xref="エゼキエル書 12:13; エゼキエル書 32:3; エレミヤ書 2:35"> わたしはわが網を彼の上に打ちかけ、彼をわがわなに捕えて、バビロンに引いて行き、彼がわたしにむかって犯した反逆のために、その所で彼をさばく。</span>
<span className="v" id="v21" data-v="21" data-xref="列王紀下 25:5; 列王紀下 25:11; エゼキエル書 12:14"> 彼のすべての軍隊のえり抜きの兵士は皆つるぎに倒れ、生き残った者は八方に散らされる。そしてあなたがたは主なるわたしが、これを語ったことを知るようになる」。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="イザヤ書 53:2; ゼカリヤ書 6:12–13; イザヤ書 11:1–5"> 主なる神はこう言われる、「わたしはまた香柏の高いこずえから小枝をとって、これを植え、その若芽の頂から柔かい芽を摘みとり、これを高いすぐれた山に植える。</span>
<span className="v" id="v23" data-v="23" data-xref="マタイによる福音書 13:32; エゼキエル書 31:6; イザヤ書 2:2"> わたしはイスラエルの高い山にこれを植える。これは枝を出し、実を結び、みごとな香柏となり、その下にもろもろの種類の獣が住み、その枝の陰に各種の鳥が巣をつくる。</span>
<span className="v" id="v24" data-v="24" data-xref="アモス書 9:11; コリント人への第一の手紙 1:27–28; エゼキエル書 24:14"> そして野のすべての木は、主なるわたしが高い木を低くし、低い木を高くし、緑の木を枯らし、枯れ木を緑にすることを知るようになる。主であるわたしはこれを語り、これをするのである」。</span>
</div>

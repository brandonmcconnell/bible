<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マタイによる福音書 3:16; エゼキエル書 11:24; 使徒行伝 7:56"> 第三十年四月五日に、わたしがケバル川のほとりで、捕囚の人々のうちにいた時、天が開けて、神の幻を見た。</span>
<span className="v" id="v2" data-v="2" data-xref="列王紀下 24:12–15; エゼキエル書 8:1; エゼキエル書 20:1"> これはエホヤキン王の捕え移された第五年であって、その月の五日に、</span>
<span className="v" id="v3" data-v="3" data-xref="エゼキエル書 3:14; エゼキエル書 3:22; 列王紀下 3:15"> 主の言葉がケバル川のほとり、カルデヤびとの地でブジの子祭司エゼキエルに臨み、主の手がその所で彼の上にあった。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="エゼキエル書 1:27; エゼキエル書 8:2; エレミヤ書 23:19"> わたしが見ていると、見よ、激しい風と大いなる雲が北から来て、その周囲に輝きがあり、たえず火を吹き出していた。その火の中に青銅のように輝くものがあった。</span>
<span className="v" id="v5" data-v="5" data-xref="ヨハネの黙示録 4:6–8; エゼキエル書 1:26; ヨハネの黙示録 6:6"> またその中から四つの生きものの形が出てきた。その様子はこうである。彼らは人の姿をもっていた。</span>
<span className="v" id="v6" data-v="6" data-xref="エゼキエル書 10:14; ヨハネの黙示録 4:7–8; エゼキエル書 1:15"> おのおの四つの顔をもち、またそのおのおのに四つの翼があった。</span>
<span className="v" id="v7" data-v="7" data-xref="ヨハネの黙示録 1:15; ダニエル書 10:6; 詩篇 104:4"> その足はまっすぐで、足のうらは子牛の足のうらのようであり、みがいた青銅のように光っていた。</span>
<span className="v" id="v8" data-v="8" data-xref="エゼキエル書 10:21; エゼキエル書 10:11; イザヤ書 6:6"> その四方に、そのおのおのの翼の下に人の手があった。この四つの者はみな顔と翼をもち、</span>
<span className="v" id="v9" data-v="9" data-xref="エゼキエル書 10:22; エゼキエル書 10:11; エゼキエル書 1:11–12"> 翼は互に連なり、行く時は回らずに、おのおの顔の向かうところにまっすぐに進んだ。</span>
<span className="v" id="v10" data-v="10" data-xref="エゼキエル書 10:14; ヨハネの黙示録 4:7; コリント人への第一の手紙 9:9–10"> 顔の形は、おのおのその前方に人の顔をもっていた。四つの者は右の方に、ししの顔をもち、四つの者は左の方に牛の顔をもち、また四つの者は後ろの方に、わしの顔をもっていた。</span>
<span className="v" id="v11" data-v="11" data-xref="イザヤ書 6:2; エゼキエル書 1:23; エゼキエル書 10:19"> 彼らの顔はこのようであった。その翼は高く伸ばされ、その二つは互に連なり、他の二つをもってからだをおおっていた。</span>
<span className="v" id="v12" data-v="12" data-xref="エゼキエル書 1:9; エゼキエル書 10:22; ヘブル人への手紙 1:14"> 彼らはおのおのその顔の向かうところへまっすぐに行き、霊の行くところへ彼らも行き、その行く時は回らない。</span>
<span className="v" id="v13" data-v="13" data-xref="ヨハネの黙示録 4:5; 詩篇 104:4; マタイによる福音書 28:3"> この生きもののうちには燃える炭の火のようなものがあり、たいまつのように、生きものの中を行き来している。火は輝いて、その火から、いなずまが出ていた。</span>
<span className="v" id="v14" data-v="14" data-xref="マタイによる福音書 24:27; ゼカリヤ書 4:10; マルコによる福音書 13:27"> 生きものは、いなずまのひらめきのように速く行き来していた。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="ダニエル書 7:9; エゼキエル書 10:9; エゼキエル書 1:19–21"> わたしが生きものを見ていると、生きもののかたわら、地の上に輪があった。四つの生きものおのおのに、一つずつの輪である。</span>
<span className="v" id="v16" data-v="16" data-xref="ダニエル書 10:6; エゼキエル書 10:9–11; 出エジプト記 39:13"> もろもろの輪の形と作りは、光る貴かんらん石のようである。四つのものは同じ形で、その作りは、あたかも、輪の中に輪があるようである。</span>
<span className="v" id="v17" data-v="17" data-xref="エゼキエル書 1:9; エゼキエル書 1:12; イザヤ書 55:11"> その行く時、彼らは四方のいずれかに行き、行く時は回らない。</span>
<span className="v" id="v18" data-v="18" data-xref="エゼキエル書 10:12; ヨハネの黙示録 4:6; ヨハネの黙示録 4:8"> 四つの輪には輪縁と輻とがあり、その輪縁の周囲は目をもって満たされていた。</span>
<span className="v" id="v19" data-v="19" data-xref="エゼキエル書 10:16; エゼキエル書 10:19; 詩篇 103:20"> 生きものが行く時には、輪もそのかたわらに行き、生きものが地からあがる時は、輪もあがる。</span>
<span className="v" id="v20" data-v="20" data-xref="エゼキエル書 1:12; エゼキエル書 10:17; コリント人への第一の手紙 14:32"> 霊の行く所には彼らも行き、輪は彼らに伴ってあがる。生きものの霊が輪の中にあるからである。</span>
<span className="v" id="v21" data-v="21" data-xref="エゼキエル書 10:17; エゼキエル書 1:19–20; ローマ人への手紙 8:2"> 彼らが行く時は、これらも行き、彼らがとどまる時は、これらもとどまり、彼らが地からあがる時は、輪もまたこれらと共にあがる。生きものの霊が輪の中にあるからである。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="エゼキエル書 10:1; エゼキエル書 1:26; ヨハネの黙示録 4:6"> 生きものの頭の上に水晶のように輝く大空の形があって、彼らの頭の上に広がっている。、</span>
<span className="v" id="v23" data-v="23" data-xref="ヨブ記 4:18; エゼキエル書 1:11–12; 詩篇 89:7"> 大空の下にはまっすぐに伸ばした翼があり、たがいに相連なり、生きものはおのおの二つの翼をもって、からだをおおっている。</span>
<span className="v" id="v24" data-v="24" data-xref="エゼキエル書 43:2; ダニエル書 10:6; ヨハネの黙示録 1:15"> その行く時、わたしは大水の声、全能者の声のような翼の声を聞いた。その声の響きは大軍の声のようで、そのとどまる時は翼をたれる。</span>
<span className="v" id="v25" data-v="25" data-xref="エゼキエル書 1:22"> また彼らの頭の上の大空から声があった。彼らが立ちとどまる時は翼をおろした。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="エゼキエル書 10:1; 出エジプト記 24:10; ヨハネの黙示録 1:13"> 彼らの頭の上の大空の上に、サファイヤのような位の形があった。またその位の形の上に、人の姿のような形があった。</span>
<span className="v" id="v27" data-v="27" data-xref="エゼキエル書 1:4; エゼキエル書 8:2; ヘブル人への手紙 12:29"> そしてその腰とみえる所の上の方に、火の形のような光る青銅の色のものが、これを囲んでいるのを見た。わたしはその腰とみえる所の下の方に、火のようなものを見た。そして彼のまわりに輝きがあった。</span>
<span className="v" id="v28" data-v="28" data-xref="ヨハネの黙示録 10:1; ヨハネの黙示録 4:3; 創世記 17:3"> そのまわりにある輝きのさまは、雨の日に雲に起るにじのようであった。<br />主の栄光の形のさまは、このようであった。わたしはこれを見て、わたしの顔をふせたとき、語る者の声を聞いた。</span>
</div>

<span className="v" id="v1" data-v="1" data-xref="エゼキエル書 22:1; エゼキエル書 21:1; エゼキエル書 34:1"> 主の言葉がわたしに臨んだ、</span>
<span className="v" id="v2" data-v="2" data-xref="エゼキエル書 6:2; 創世記 32:3; エゼキエル書 25:8"> 「人の子よ、あなたの顔をセイル山に向け、これに対して預言し、</span>
<span className="v" id="v3" data-v="3" data-xref="エレミヤ書 6:12; エゼキエル書 35:7; エゼキエル書 6:14"> これに言え。主なる神はこう言われる、セイル山よ、見よ、わたしはあなたを敵とし、わたしの手をあなたに向かって伸べ、あなたを全く荒し、</span>
<span className="v" id="v4" data-v="4" data-xref="エゼキエル書 35:9; マラキ書 1:3–4; ヨエル書 3:19"> あなたの町々を滅ぼす。あなたは荒れはてる。そしてわたしが主であることを悟る。</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 137:7; オバデヤ書 1:10–16; アモス書 1:11"> あなたは限りない敵意をいだいて、イスラエルの人々をその災の時、終りの刑罰の時に、つるぎの手に渡した。</span>
<span className="v" id="v6" data-v="6" data-xref="イザヤ書 63:2–6; ヨハネの黙示録 18:24; オバデヤ書 1:15"> それゆえ、主なる神は言われる、わたしは生きている。わたしはあなたを血にわたす。血はあなたを追いかける。あなたには血のとががあるゆえ、血はあなたを追いかける</span>
<span className="v" id="v7" data-v="7" data-xref="エゼキエル書 29:11; エゼキエル書 35:3; 士師記 5:6–7"> わたしはセイル山を全く荒し、そこに行き来する者を断ち、</span>
<span className="v" id="v8" data-v="8" data-xref="エゼキエル書 31:12; エゼキエル書 32:4–5; エゼキエル書 39:4–5"> その山々を殺された者で満たす。つるぎで殺された者が、あなたのもろもろの丘、もろもろの谷、もろもろのくぼ地に倒れる。</span>
<span className="v" id="v9" data-v="9" data-xref="エゼキエル書 25:13; マラキ書 1:3–4; エゼキエル書 6:7"> わたしはあなたを、永遠の荒れ地とし、あなたの町々には住む者がなくなる。そしてあなたがたは、わたしが主であることを悟る。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="エゼキエル書 36:5; 詩篇 83:4–12; エゼキエル書 48:35"> あなたは言う、『これら二つの国民、二つの国はわたしのもの、われわれはこれを獲よう』と。しかし主はそこにおられる。</span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 9:16; マタイによる福音書 7:2; 詩篇 73:17–18"> それゆえ、主なる神は言われる、わたしは生きている。あなたが彼らを憎んで、彼らに示した怒りと、ねたみにしたがって、わたしはあなたを扱う。わたしがあなたをさばく時、わたし自身をあなたに示す。</span>
<span className="v" id="v12" data-v="12" data-xref="エゼキエル書 36:2; 詩篇 83:12; エゼキエル書 6:7"> あなたがイスラエルの山々に向かって、『これは荒れはてて、われわれの食となる』と言ったもろもろのそしりを、主なるわたしが聞いたことをあなたは悟る。</span>
<span className="v" id="v13" data-v="13" data-xref="ダニエル書 11:36; イザヤ書 36:20; エレミヤ書 29:23"> あなたがたは、わたしに対して口をもって誇り、またわたしに対して、あなたがたの言葉を多くした。わたしはそれを聞いた。</span>
<span className="v" id="v14" data-v="14" data-xref="エレミヤ書 51:48; イザヤ書 14:7–8; イザヤ書 65:13–15"> 主なる神はこう言われる、全地の喜びのために、わたしはあなたを荒れ地とする。</span>
<span className="v" id="v15" data-v="15" data-xref="エゼキエル書 35:3–4; 哀歌 4:21; イザヤ書 34:5–6"> あなたが、イスラエルの家の嗣業の荒れるのを喜んだように、わたしはあなたに、そのようにする。セイル山よ、あなたは荒れ地となる。エドムもすべてそのようになる。そのとき彼らは、わたしが主であることを悟るようになる。</span>

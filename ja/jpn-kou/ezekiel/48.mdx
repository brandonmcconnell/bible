<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="エゼキエル書 47:15–17; ヨシュア記 19:40–47; ヨハネの黙示録 7:4–8"> イスラエルの部族の名は次のとおりである。北の果からヘテロンの道を経て、ハマテの入口に至り、ハマテに相対するダマスコの北の境にあるハザル・エノンに及び、東の方から西の方へのびる地方、これがダンの分である。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨシュア記 19:24–31; 創世記 30:12–13"> ダンの領地に沿って、東の方から西の方へのびる地方、これがアセルの分である。</span>
<span className="v" id="v3" data-v="3" data-xref="ヨシュア記 19:32–39; 創世記 30:7–8"> アセルの領地に沿って、東の方から西の方へのびる地方、これがナフタリの分である。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨシュア記 17:1–11; ヨシュア記 13:29–31; 創世記 48:14–20"> ナフタリの領地に沿って、東の方から西の方へのびる地方、これがマナセの分である。</span>
<span className="v" id="v5" data-v="5" data-xref="ヨシュア記 17:8–10; ヨシュア記 17:14–18; ヨシュア記 16:1–10"> マナセの領地に沿って、東の方から西の方へのびる地方、これがエフライムの分である。</span>
<span className="v" id="v6" data-v="6" data-xref="ヨシュア記 13:15–21; 創世記 29:32; 創世記 49:3–4"> エフライムの領地に沿って、東の方から西の方へのびる地方、これがルベンの分である。</span>
<span className="v" id="v7" data-v="7" data-xref="ヨシュア記 15:1–63; ヨシュア記 19:9; 創世記 29:35"> ルベンの領地に沿って、東の方から西の方へのびる地方、これがユダの分である。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="エゼキエル書 45:1–6; イザヤ書 12:6; イザヤ書 33:20–22"> ユダの領地に沿って、東の方から西の方へのびる地方は、あなたがたのささげる献納地とせよ。その幅は二万五千キュビト、その東の方から西の方へのびる長さは、部族の一つの分に同じで、聖所はその中にある。</span>
<span className="v" id="v9" data-v="9"> すなわちあなたがたの主にささげる献納地は長さ二万五千キュビト、幅二万キュビトとである。</span>
<span className="v" id="v10" data-v="10" data-xref="エゼキエル書 45:4; エゼキエル書 44:28; マタイによる福音書 10:10"> これが祭司への聖なる献納地である。すなわち祭司の分は、北は二万五千キュビト、西は幅一万キュビト、東は幅一万キュビト、南は長さ二万五千キュビトである。主の聖所はその中にある。</span>
<span className="v" id="v11" data-v="11" data-xref="エゼキエル書 40:46; エゼキエル書 44:10; マタイによる福音書 24:45–46"> これはイスラエルの人々が迷い出た時、レビびとが迷ったように迷ったことはなく、わが務を守り通したザドクの子孫のうちから、聖別された祭司に属する。</span>
<span className="v" id="v12" data-v="12" data-xref="レビ記 27:21; エゼキエル書 45:4"> このようにレビびとの境に沿って、いと聖なる地、すなわち聖なる献納地が、特別な分として彼らに帰属する。</span>
<span className="v" id="v13" data-v="13" data-xref="エゼキエル書 45:3; 申命記 12:19; エゼキエル書 45:5"> レビびとの分は祭司の所有地の境に沿って、長さ二万五千キュビト、幅一万キュビト、すなわち、そのすべての長さ二万五千キュビト、幅二万キュビトである。</span>
<span className="v" id="v14" data-v="14" data-xref="レビ記 27:28; レビ記 27:9–10; 出エジプト記 22:29"> 彼らはこれを売ってはならない、また交換してはならない、またその大事な分を手ばなしてはならない。これは主に属する聖なる物だからである。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="エゼキエル書 42:20; エゼキエル書 45:6; エゼキエル書 44:23"> その残りの地すなわち幅五千キュビト、長さ二万五千キュビトは町のため、すみかのため、また郊外のための一般人の地所とせよ。町はその中に置け。</span>
<span className="v" id="v16" data-v="16" data-xref="ヨハネの黙示録 21:16"> 一般人の地所の広さは次のとおりである。すなわち北の方四千五百キュビト、南の方四千五百キュビト、東の方四千五百キュビト、西の方四千五百キュビトである。</span>
<span className="v" id="v17" data-v="17"> 町は郊外を含む。郊外は北二百五十キュビト、南二百五十キュビト、東二百五十キュビト、西二百五十キュビトである。</span>
<span className="v" id="v18" data-v="18" data-xref="ヨシュア記 9:27; エズラ記 2:43–58; エゼキエル書 45:6"> 聖なる献納地に沿っている残りの地の長さは東へ一万キュビト、西へ一万キュビトである。これは聖なる献納地に沿っており、その産物は町の働き人の食物となる。</span>
<span className="v" id="v19" data-v="19" data-xref="エゼキエル書 45:6; 列王紀上 4:7–23; ネヘミヤ書 11:1–36"> 町の働き人は、イスラエルのすべての部族から出て、これを耕作するのである。</span>
<span className="v" id="v20" data-v="20" data-xref="ヨハネの黙示録 21:16; ヘブル人への手紙 12:17"> あなたがたがささげる献納地の全体は二万五千キュビト四方である。これは町の所有地と共に聖なる献納地である。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="エゼキエル書 48:22; エゼキエル書 37:24; エゼキエル書 48:8"> 聖なる献納地と町の所有地との、こなたかなたの残りの地は、君たる者に属する。これは聖なる献納地の二万五千キュビトに面して東の境に至り、西はその二万五千キュビトに面して西の境に至り、部族の分に沿うもので、君たる者に属する。聖なる献納地と、宮の聖所とは、その中にある。</span>
<span className="v" id="v22" data-v="22"> 町の所有地は、君たる者に属する部分の中にあり、そして君たる者の分は、ユダの領地と、ベニヤミンの領地との間にある。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="ヨシュア記 18:21–28; エゼキエル書 48:1–7; 創世記 35:16–19"> なお残りの部族では東の方から西の方に至る地方、これがベニヤミンの分である。</span>
<span className="v" id="v24" data-v="24" data-xref="ヨシュア記 19:1–9; 創世記 29:33; 創世記 49:5–7"> ベニヤミンの領地に沿って、東の方から西の方に至る地方、これがシメオンの分である。</span>
<span className="v" id="v25" data-v="25" data-xref="ヨシュア記 19:17–23; 創世記 30:14–18"> シメオンの領地に沿って、東の方から西の方に至る地方、これがイッサカルの分である。</span>
<span className="v" id="v26" data-v="26" data-xref="ヨシュア記 19:10–16; 創世記 30:19–20"> イッサカルの領地に沿って、東の方から西の方に至る地方、これがゼブルンの分である。</span>
<span className="v" id="v27" data-v="27" data-xref="ヨシュア記 13:24–28; 創世記 30:10–11"> ゼブルンの領地に沿って、東の方から西の方に至る地方、これがガドの分である。</span>
<span className="v" id="v28" data-v="28" data-xref="エゼキエル書 47:15; 歴代志下 20:2; エゼキエル書 47:19–20"> 南の方はガドの領地に沿って、タマルからメリボテ・カデシの水に至り、そこからエジプトの川に沿って大海に至る。</span>
<span className="v" id="v29" data-v="29" data-xref="ヨシュア記 13:1–21; 民数記 34:2; 民数記 34:13"> これはあなたがたが、くじをもってイスラエルの部族のうちに分けて、嗣業とすべき地である。これが彼らの分であると、主なる神は言われる。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="エゼキエル書 48:16; ヨハネの黙示録 21:16; エゼキエル書 48:32–35"> 町の出口は次のとおりである。北の方の長さは四千五百キュビトである。</span>
<span className="v" id="v31" data-v="31" data-xref="ヨハネの黙示録 21:12–13; イザヤ書 26:1–2; ヨハネの黙示録 21:21"> 町の門はイスラエルの部族の名にしたがい、三つの門になっている。すなわちルベンの門、ユダの門、レビの門である。</span>
<span className="v" id="v32" data-v="32"> 東の方は四千五百キュビトであって、三つの門がある。すなわちヨセフの門、ベニヤミンの門、ダンの門である。</span>
<span className="v" id="v33" data-v="33"> 南の方は四千五百キュビトであって、三つの門がある。すなわちシメオンの門、イッサカルの門、ゼブルンの門である。</span>
<span className="v" id="v34" data-v="34"> 西の方は四千五百キュビトであって、三つの門がある。すなわちガドの門、アセルの門、ナフタリの門である。</span>
<span className="v" id="v35" data-v="35" data-xref="ヨハネの黙示録 21:3; ゼカリヤ書 2:10; ヨハネの黙示録 22:3"> 町の周囲は一万八千キュビトあり、この日から後、この町の名は『主そこにいます』と呼ばれる」。</span>
</div>

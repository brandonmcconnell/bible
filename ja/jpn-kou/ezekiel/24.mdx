<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="エゼキエル書 8:1; エゼキエル書 20:1; エゼキエル書 29:17"> 第九年の十月十日に、主の言葉がわたしに臨んだ、</span>
<span className="v" id="v2" data-v="2" data-xref="エレミヤ書 39:1; エレミヤ書 52:4; 列王紀下 25:1"> 「人の子よ、あなたはこの日すなわち今日の名を書きしるせ。バビロンの王は、この日エルサレムを包囲した。</span>
<span className="v" id="v3" data-v="3" data-xref="エゼキエル書 11:3; エゼキエル書 17:2; エゼキエル書 20:49"> あなたはこの反逆の家にたとえを語って言え。主なる神はこう言われる、<br /><span className="pl pl-1">かますをすえ、これをすえて、水をくみ入れよ。</span></span>
<span className="v" id="v4" data-v="4" data-xref="ミカ書 3:2–3; エゼキエル書 22:18–22; マタイによる福音書 7:2"> <span className="pl pl-1">その中に肉の切れを入れよ、</span><br /><span className="pl pl-1">すべて良い肉の切れ、</span><br /><span className="pl pl-1">すなわち、ももと肩の肉をこれに入れよ。</span><br /><span className="pl pl-1">良い骨をこれに満たせ。</span></span>
<span className="v" id="v5" data-v="5" data-xref="エレミヤ書 52:24–27; エレミヤ書 52:10; エレミヤ書 39:6"> <span className="pl pl-1">羊の最も良いものを取れ。</span><br /><span className="pl pl-1">かまの下にまきを積み、</span><br /><span className="pl pl-1">その肉を煮たぎらせ、またその中の骨を煮よ。</span></span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="エゼキエル書 22:2; ナホム書 3:1; オバデヤ書 1:11"> それゆえ、主なる神はこう言われる、わざわいなるかな、流血の町、さびているかま。そのさびはこれを離れない。肉をひとつびとつ無差別に取り出せ。</span>
<span className="v" id="v7" data-v="7" data-xref="レビ記 17:13; 申命記 12:16; ヨブ記 16:18"> その流した血はまだその中にある。彼女はこれを裸岩の上に流し、土でこれをおおうために、地面には注がなかった。</span>
<span className="v" id="v8" data-v="8" data-xref="申命記 32:21–22; ヨハネの黙示録 18:5–10; エゼキエル書 22:30–31"> これは、わたしの怒りをつのらせ、あだを返すために、その流した血がおおわれないように、裸岩の上に流したのである。</span>
<span className="v" id="v9" data-v="9" data-xref="エゼキエル書 24:6; ハバクク書 2:12; イザヤ書 31:9"> それゆえ、主なる神はこう言われる、わざわいなるかな、流血の町。わたしもまた、まきをさらに積み重ねる。</span>
<span className="v" id="v10" data-v="10" data-xref="哀歌 2:16; エレミヤ書 17:3; 哀歌 1:10"> まきを積み重ね、火を燃やし、肉をよく煮て、煮つくし、骨を焼け。</span>
<span className="v" id="v11" data-v="11" data-xref="エレミヤ書 21:10; マラキ書 4:1; イザヤ書 1:25"> そしてかまを熱くするため、それをからにして炭火の上に置き、その銅を焼いて、汚れをその中に溶かし、そのさびを去れ。</span>
<span className="v" id="v12" data-v="12" data-xref="エレミヤ書 9:5; エレミヤ書 2:13; エレミヤ書 5:3"> しかしわたしのほねおりは、むだであった。その多くのさびは火によって消えない。</span>
<span className="v" id="v13" data-v="13" data-xref="エゼキエル書 22:24; エゼキエル書 5:13; ゼパニヤ書 3:2"> そのさびとは、あなたの不潔な淫行である。わたしはあなたを清めようとしたが、あなたはあなたの不潔から清められようとしないから、わたしの怒りをあなたに漏らし尽すまでは、あなたは汚れから清まることはない。</span>
<span className="v" id="v14" data-v="14" data-xref="マタイによる福音書 16:27; エゼキエル書 18:30; イザヤ書 3:11"> 主なるわたしはこれを言った。そしてこれは必ず成る。わたしはこれをなす。わたしはやめない、惜しまない、悔いない。あなたのおこないにより、あなたのわざによって、あなたをさばくと、主なる神は言われる」。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15"> また主の言葉がわたしに臨んだ、</span>
<span className="v" id="v16" data-v="16" data-xref="エレミヤ書 22:10; エレミヤ書 13:17; 雅歌 7:10"> 「人の子よ、見よ、わたしは、にわかにあなたの目の喜ぶ者を取り去る。嘆いてはならない。泣いてはならない。涙を流してはならない。</span>
<span className="v" id="v17" data-v="17" data-xref="ホセア書 9:4; サムエル記下 15:30; レビ記 10:6"> 声をたてずに嘆け。死人のために嘆き悲しむな。ずきんをかぶり、足にくつをはけ。口をおおうな。嘆きのパンを食べるな」。</span>
<span className="v" id="v18" data-v="18" data-xref="コリント人への第一の手紙 7:29–30"> 朝のうちに、わたしは人々に語ったが、夕べには、わたしの妻は死んだ。翌朝わたしは命じられたようにした。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="エゼキエル書 12:9; エゼキエル書 37:18; マラキ書 3:7–8"> 人々はわたしに言った、「あなたがするこの事は、われわれになんの関係があるのか、それをわれわれに告げてはくれまいか」。</span>
<span className="v" id="v20" data-v="20"> わたしは彼らに言った、「主の言葉がわたしに臨んだ、</span>
<span className="v" id="v21" data-v="21" data-xref="エゼキエル書 23:47; エゼキエル書 23:25; 詩篇 27:4"> 『イスラエルの家に言え、主なる神はこう言われる、見よ、わたしはあなたがたの力の誇、目の喜び、心の望みであるわが聖所を汚す。あなたがたが残すむすこ娘たちは、つるぎに倒れる。</span>
<span className="v" id="v22" data-v="22" data-xref="詩篇 78:64; エレミヤ書 16:4–7; エゼキエル書 24:16–17"> あなたがたもわたしがしたようにし、口をおおわず、嘆きのパンを食べず、</span>
<span className="v" id="v23" data-v="23" data-xref="エゼキエル書 33:10; エゼキエル書 4:17; レビ記 26:39"> 頭にずきんをかぶり、足にくつをはき、嘆かず、泣かず、その罪の中にやせ衰えて、互にうめくようになる。</span>
<span className="v" id="v24" data-v="24" data-xref="エゼキエル書 4:3; イザヤ書 20:3; ルカによる福音書 11:29–30"> このようにエゼキエルはあなたがたのためにしるしとなる。彼がしたようにあなたがたもせよ。この事が成る時、あなたがたはわたしが主なる神であることを知るようになる』。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="エゼキエル書 24:21; 詩篇 48:2; エレミヤ書 11:22"> 人の子よ、わたしが、彼らのとりで、彼らの喜びと栄え、彼らの目の喜びであり、その心の望みであるもの、また彼らのむすこ娘たちを取り去る日、</span>
<span className="v" id="v26" data-v="26" data-xref="ヨブ記 1:15–19; エゼキエル書 33:21–22; サムエル記上 4:12–18"> その日に難をのがれて来る者が、あなたのもとにきて、あなたに事を告げる。</span>
<span className="v" id="v27" data-v="27" data-xref="エゼキエル書 33:22; エゼキエル書 29:21; ルカによる福音書 21:15"> その日あなたは、そののがれてきた者に向かって口を開き、語り、もはや沈黙しない。こうしてあなたは彼らのためにしるしとなり、彼らはわたしが主であることを知る」。</span>
</div>

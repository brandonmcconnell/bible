<div className="bp">
<span className="v" id="v1" data-v="1"> 主の言葉がわたしに臨んだ、</span>
<span className="v" id="v2" data-v="2" data-xref="エレミヤ書 49:1–6; アモス書 1:13–15; エゼキエル書 6:2"> 「人の子よ、あなたの顔をアンモンの人々に向け、これに向かって預言し、</span>
<span className="v" id="v3" data-v="3" data-xref="エゼキエル書 36:2; 詩篇 70:2–3; 箴言 17:5"> アンモンの人々に言え。主なる神の言葉を聞け。主なる神はこう言われる、あなたはわが聖所の汚された時、またイスラエルの地の荒された時、またユダの家が捕え移された時、ああ、それはよい気味であると言った。</span>
<span className="v" id="v4" data-v="4" data-xref="申命記 28:33; 士師記 6:33; 列王紀上 4:30"> それゆえ、わたしはあなたを、東の人々に渡して彼らの所有とする。彼らはあなたのうちに陣営を設け、あなたのうちに住居を造り、あなたのくだものを食べ、あなたの乳を飲む。</span>
<span className="v" id="v5" data-v="5" data-xref="エゼキエル書 21:20; サムエル記下 12:26; イザヤ書 17:2"> わたしはラバを、らくだを飼う所とし、アンモンびとの町々を、羊の伏す所とする。そしてあなたがたは、わたしが主であることを知るようになる。</span>
<span className="v" id="v6" data-v="6" data-xref="ゼパニヤ書 2:8; オバデヤ書 1:12; ゼパニヤ書 2:10"> 主なる神はこう言われる、あなたはイスラエルの地に向かって手をうち、足を踏み、心に悪意を満たして喜んだ。</span>
<span className="v" id="v7" data-v="7" data-xref="ゼパニヤ書 1:4; エゼキエル書 25:16; エゼキエル書 6:14"> それゆえ、見よ、わたしはわが手をあなたに向けて伸べ、あなたを、もろもろの国民に渡して略奪にあわせ、あなたを、もろもろの民の中から断ち、諸国の中から滅ぼし絶やす。そしてあなたは、わたしが主であることを知るようになる。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="イザヤ書 15:1–9; エレミヤ書 25:21; エレミヤ書 48:1–47"> 主なる神はわたしにこう言われる、モアブは言った、見よ、ユダの家は、他のすべての国民と同様であると。</span>
<span className="v" id="v9" data-v="9" data-xref="エレミヤ書 48:23; ヨシュア記 13:17; ヨシュア記 13:19–20"> それゆえ、わたしはモアブの境界の町々、すなわち国の栄えであるベテエシモテ、バアルメオン、キリアタイムの横腹を開き、</span>
<span className="v" id="v10" data-v="10" data-xref="エゼキエル書 21:32; 詩篇 83:3–6; エゼキエル書 25:4"> これをアンモンの人々と共に、東方の人々に与えて、その所有とし、モアブの人々をもろもろの国民の中に記憶させない。</span>
<span className="v" id="v11" data-v="11" data-xref="エゼキエル書 35:15; エゼキエル書 30:19; 詩篇 149:7"> わたしはモアブの上にさばきを行う。そのとき、彼らはわたしが主であることを知る。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="エレミヤ書 49:7–22; エゼキエル書 25:8; 詩篇 137:7"> 主なる神はこう言われる、エドムは恨みをふくんでユダの家に敵対し、これに恨みを返して、はなはだしく罪を犯した。</span>
<span className="v" id="v13" data-v="13" data-xref="エゼキエル書 29:8; マラキ書 1:3–4; エレミヤ書 25:23"> それゆえ、主なる神はこう言われる、わたしはエドムの上に手を伸べて、その中から人と獣とを断ち、これを荒れ地とする。テマンからデダンまで人々はつるぎに倒れる。</span>
<span className="v" id="v14" data-v="14" data-xref="イザヤ書 11:14; 創世記 27:29; ヘブル人への手紙 10:30–31"> わたしはわが民イスラエルの手をもって、エドムにわがあだを報いる。彼らがわが怒り、わが憤りに従ってエドムに行う時、エドムの人々は、わたしがあだを返すことを知るようになると、主なる神は言われる。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="エゼキエル書 25:6; イザヤ書 14:29–31; エゼキエル書 25:12"> 主なる神はこう言われる、ペリシテびとは恨みをふくんで行動し、心に悪意をもってあだを返し、深い敵意をもって、滅ぼすことをした。</span>
<span className="v" id="v16" data-v="16" data-xref="サムエル記上 30:14; ゼパニヤ書 2:4–15; エゼキエル書 25:13"> それゆえ、主なる神はこう言われる、見よ、わたしは手をペリシテびとの上に伸べ、ケレテびとを断ち、海べの残りの者を滅ぼす。</span>
<span className="v" id="v17" data-v="17" data-xref="エゼキエル書 25:11; エゼキエル書 25:14; エゼキエル書 5:15"> わたしは怒りに満ちた懲罰をもって、大いなる復讐を彼らになす。わたしが彼らにあだを返す時、彼らはわたしが主であることを知るようになる」。</span>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="エゼキエル書 38:2–3; エゼキエル書 35:3; ナホム書 3:5"> 人の子よ、ゴグに向かって預言して言え。主なる神はこう言われる、メセクとトバルの大君であるゴグよ、見よ、わたしはあなたの敵となる。</span>
<span className="v" id="v2" data-v="2" data-xref="詩篇 40:14; エゼキエル書 38:15; イザヤ書 37:29"> わたしはあなたを引きもどし、あなたを押しやり、北の果から上らせ、イスラエルの山々に導き、</span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 76:3; ホセア書 1:5; エレミヤ書 21:4–5"> あなたの左の手から弓を打ち落し、右の手から矢を落させる。</span>
<span className="v" id="v4" data-v="4" data-xref="エゼキエル書 39:17–20; エゼキエル書 33:27; エゼキエル書 38:21"> あなたとあなたのすべての軍隊およびあなたと共にいる民たちは、イスラエルの山々に倒れる。わたしはあなたを、諸種の猛禽と野獣とに与えて食わせる。</span>
<span className="v" id="v5" data-v="5" data-xref="エレミヤ書 22:19; エゼキエル書 32:4; エレミヤ書 8:2"> あなたは野の面に倒れる。わたしがこれを言ったからであると、主なる神は言われる。</span>
<span className="v" id="v6" data-v="6" data-xref="エゼキエル書 30:16; アモス書 1:4; エゼキエル書 30:8"> わたしはゴグと、海沿いの国々に安らかに住む者に対して火を送り、彼らにわたしが主であることを悟らせる。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="エゼキエル書 38:16; エゼキエル書 38:23; 出エジプト記 20:7"> わたしはわが聖なる名を、わが民イスラエルのうちに知らせ、重ねてわが聖なる名を汚させない。諸国民はわたしが主、イスラエルの聖者であることを悟る。</span>
<span className="v" id="v8" data-v="8" data-xref="エゼキエル書 38:17; ヨハネの黙示録 16:17; エゼキエル書 7:2–10"> 主なる神は言われる、見よ、これは来る、必ず成就する。これはわたしが言った日である。</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 46:9; イザヤ書 66:24; マラキ書 1:5"> イスラエルの町々に住む者は出て来て、武器すなわち大盾、小盾、弓、矢、手やり、およびやりなどを燃やし、焼き、七年の間これを火に燃やす。</span>
<span className="v" id="v10" data-v="10" data-xref="イザヤ書 33:1; イザヤ書 14:2; ミカ書 5:8"> 彼らは野から木を取らず、森から木を切らず、武器で火を燃やし、自分をかすめた者をかすめ、自分の物を奪った者を奪うと、主なる神は言われる。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="エゼキエル書 47:18; 民数記 34:11; エゼキエル書 38:2"> その日、わたしはイスラエルのうちに、墓地をゴグに与える。これは旅びとの谷にあって海の東にある。これは旅びとを妨げる。そこにゴグとその民衆を埋めるからである。これをハモン・ゴグの谷と名づける。</span>
<span className="v" id="v12" data-v="12" data-xref="申命記 21:23; エゼキエル書 39:14; エゼキエル書 39:16"> イスラエルの家はこれを埋めて、地を清めるために七か月を費す。</span>
<span className="v" id="v13" data-v="13" data-xref="エゼキエル書 28:22; ゼパニヤ書 3:19–20; エレミヤ書 33:9"> 国のすべての民はこれを埋め、これによって名を高める。これはわが栄えを現す日であると、主なる神は言われる。</span>
<span className="v" id="v14" data-v="14" data-xref="エゼキエル書 39:12; 民数記 19:11–19"> 彼らは人々を選んで、絶えず国の中を行きめぐらせ、地のおもてに残っている者を埋めて、これを清めさせる。七か月の終りに彼らは尋ねる。</span>
<span className="v" id="v15" data-v="15" data-xref="ルカによる福音書 11:44"> 国を行きめぐる者が行きめぐって、人の骨を見る時、死人を埋める者が、これをハモン・ゴグの谷に埋めるまで、そのかたわらに、標を建てて置く。</span>
<span className="v" id="v16" data-v="16"> （ハモナの町もそこにある。）こうして彼らはその国を清める。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="ゼパニヤ書 1:7; ヨハネの黙示録 19:17–18; イザヤ書 34:6"> 主なる神はこう言われる、人の子よ、諸種の鳥と野の獣とに言え、みな集まってこい。わたしがおまえたちのために供えた犠牲、すなわちイスラエルの山々の上にある、大いなる犠牲に、四方から集まり、その肉を食い、その血を飲め。</span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 22:12; エレミヤ書 51:40; ヨハネの黙示録 19:17–18"> おまえたちは勇士の肉を食い、地の君たちの血を飲め。雄羊、小羊、雄やぎ、雄牛などすべてバシャンの肥えた獣を食え。</span>
<span className="v" id="v19" data-v="19"> わたしがおまえたちのために供えた犠牲は、飽きるまでその脂肪を食べ、酔うまで血を飲め。</span>
<span className="v" id="v20" data-v="20" data-xref="ヨハネの黙示録 19:18; ハガイ書 2:22; 詩篇 76:5–6"> おまえたちはわが食卓について馬と、騎手と、勇士と、もろもろの戦士とを飽きるほど食べると、主なる神は言われる。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="エゼキエル書 38:16; エゼキエル書 38:23; イザヤ書 37:20"> わたしはわが栄光を諸国民に示す。すべての国民はわたしが行ったさばきと、わたしが彼らの上に加えた手とを見る。</span>
<span className="v" id="v22" data-v="22" data-xref="エレミヤ書 24:7; エゼキエル書 28:26; エゼキエル書 39:28"> この日から後、イスラエルの家はわたしが彼らの神、主であることを悟るようになる。</span>
<span className="v" id="v23" data-v="23" data-xref="エレミヤ書 22:8–9; イザヤ書 1:15; イザヤ書 59:2"> また諸国民はイスラエルの家が、その悪によって捕え移されたことを悟る。彼らがわたしにそむいたので、わたしはわが顔を彼らに隠し、彼らをその敵の手に渡した。それで彼らは皆つるぎに倒れた。</span>
<span className="v" id="v24" data-v="24" data-xref="エゼキエル書 36:19; エレミヤ書 2:17; エレミヤ書 4:18"> わたしは彼らの汚れと、とがとに従って、彼らを扱い、わたしの顔を彼らに隠した。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="エゼキエル書 34:13; イザヤ書 27:12–13; ホセア書 1:11"> それゆえ、主なる神はこう言われる、いまわたしはヤコブの幸福をもとに返し、イスラエルの全家をあわれみ、わが聖なる名のために、ねたみを起す。</span>
<span className="v" id="v26" data-v="26" data-xref="ミカ書 4:4; 列王紀上 4:25; エゼキエル書 16:63"> 彼らは、その国に安らかに住み、だれもこれを恐れさせる者がないようになった時、自分の恥と、わたしに向かってなした反逆とを忘れる。</span>
<span className="v" id="v27" data-v="27" data-xref="エゼキエル書 38:16; エゼキエル書 38:23; エゼキエル書 36:23–24"> わたしが彼らを諸国民の中から帰らせ、その敵の国から呼び集め、彼らによって、わたしの聖なることを、多くの国民の前に示す時、</span>
<span className="v" id="v28" data-v="28" data-xref="エゼキエル書 39:22; アモス書 9:9; イザヤ書 27:12"> 彼らは、わたしが彼らの神、主であることを悟る。これはわたしが彼らを諸国民のうちに移し、またこれをその国に呼び集めたからである。わたしはそのひとりをも、国々のうちに残すことをしない。</span>
<span className="v" id="v29" data-v="29" data-xref="ヨエル書 2:28; ヨハネの第一の手紙 3:24; イザヤ書 32:15"> わたしは、わが霊をイスラエルの家に注ぐ時、重ねてわが顔を彼らに隠さないと、主なる神は言われる」。</span>
</div>

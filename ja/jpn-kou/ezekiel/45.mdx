<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="エゼキエル書 48:29; ゼカリヤ書 14:20–21; 民数記 34:13"> あなたがたは、くじを引き、地を分けて、それを所有するときには、地の一部を聖なる地所として主にささげよ。その長さは二万五千キュビト、幅は二万キュビトで、その区域はすべて聖なる地である。</span>
<span className="v" id="v2" data-v="2" data-xref="エゼキエル書 42:16–20; エゼキエル書 27:28"> そのうち聖所に属するものは縦横五百キュビトずつであって、それは四角である。また五十キュビトの空地をその周囲につくれ。</span>
<span className="v" id="v3" data-v="3" data-xref="エゼキエル書 48:10"> あなたはこの聖なる地所から長さ二万五千キュビト、幅一万キュビトを測り取り、その中に聖所と至聖所とを設けよ。</span>
<span className="v" id="v4" data-v="4" data-xref="エゼキエル書 43:19; 民数記 16:5; エゼキエル書 40:45"> これは国の中で聖なる所であって、主に近く仕える聖所の仕え人である祭司に帰属する。これは彼らのためには家を建てる所、聖所のためには聖地となる。</span>
<span className="v" id="v5" data-v="5" data-xref="エゼキエル書 48:13; ネヘミヤ書 10:38–39; エゼキエル書 48:20"> また長さ二万五千キュビト、幅一万キュビトの別の地所は、宮に仕えるレビびとに帰属し、彼らの住む町のための所有とする。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="エゼキエル書 48:15–18; エゼキエル書 48:30–35"> 聖地として区別した部分に沿い、幅五千キュビト、長さ二万五千キュビトは、町の所有とせよ。これはイスラエル全家のものとなる。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="エゼキエル書 48:21; エゼキエル書 34:24; エゼキエル書 46:16–18"> また君たる者の分は、かの聖地と町の所有地との、こなたかなたにある。すなわち聖地と町の所有地に沿い、西と東に向かい、部族の分の一つに応じて、地所の西から東の境に至り、</span>
<span className="v" id="v8" data-v="8" data-xref="イザヤ書 11:3–5; エゼキエル書 46:18; エゼキエル書 22:27"> その所有の地所はイスラエルの中にある。わたしの君たちは、重ねてわたしの民をしえたげず、部族にしたがってイスラエルの家に土地を与える。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="ゼカリヤ書 8:16; エレミヤ書 22:3; エゼキエル書 44:6"> 主なる神は、こう言われる、イスラエルの君たちよ、暴虐と略奪とをやめ、公道と正義を行え。わが民を追いたてることをやめよと、主なる神は言われる。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="ミカ書 6:10–11; アモス書 8:4–6; 箴言 16:11"> あなたがたは正しいはかり、正しいエパ、正しいバテを用いよ。</span>
<span className="v" id="v11" data-v="11" data-xref="イザヤ書 5:10"> エパとバテとは同量にせよ。すなわちバテをホメルの十分の一とし、エパもホメルの十分の一とし、すべてホメルによって量を定めよ。</span>
<span className="v" id="v12" data-v="12" data-xref="出エジプト記 30:13; 民数記 3:47; レビ記 27:25"> 一シケルは二十ゲラである。五シケルは五シケル、十シケルは十シケルとせよ。一ミナは五十シケルとせよ。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13"> あなたがたがささげるささげ物はこれである。すなわち、一ホメルの小麦のうちから六分の一エパをささげ、大麦一ホメルのうちから六分の一エパをささげよ。</span>
<span className="v" id="v14" data-v="14"> 油は一コルのうちから十分の一バテをささげよ。コルはホメルと同じく十バテに当る。</span>
<span className="v" id="v15" data-v="15" data-xref="レビ記 1:4; レビ記 6:30; コロサイ人への手紙 1:21"> またイスラエルの氏族から、家畜の群れ二百につき一頭の羊を出して、素祭、燔祭、酬恩祭とし、彼らのために、あがないをなせと主なる神は言われる。</span>
<span className="v" id="v16" data-v="16" data-xref="出エジプト記 30:14–15; イザヤ書 16:1"> 国の民は皆これをイスラエルの君にささげ物とせよ。</span>
<span className="v" id="v17" data-v="17" data-xref="エゼキエル書 46:4–12; 歴代志下 31:3; イザヤ書 66:23"> また祭日、ついたち、安息日、すなわちイスラエルの家のすべての祝い日に、燔祭、素祭、灌祭を供えるのは、君たる者の務である。すなわち彼はイスラエルの家のあがないのために、罪祭、素祭、燔祭、酬恩祭をささげなければならない。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="レビ記 16:16; 出エジプト記 12:2; エゼキエル書 43:22"> 主なる神は、こう言われる、正月の元日に、あなたは無傷の雄牛の子を取って聖所を清めよ。</span>
<span className="v" id="v19" data-v="19" data-xref="エゼキエル書 43:20; エゼキエル書 43:14; レビ記 16:18–20"> 祭司は罪祭の獣の血を取って、宮の柱と祭壇のかさねの四すみ、および内庭の門の柱に塗れ。</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 19:12; レビ記 4:27–35; エゼキエル書 45:15"> 月の七日に、あなたがたは、過失や無知のために罪を犯した者のために、このように行って宮のためにあがないをなせ。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="レビ記 23:5–8; コリント人への第一の手紙 5:7–8; 民数記 9:2–14"> 正月の十四日に、あなたがたは過越の祭を祝え。七日の間、種を入れぬパンを食べよ。</span>
<span className="v" id="v22" data-v="22" data-xref="レビ記 4:14; コリント人への第二の手紙 5:21; マタイによる福音書 20:28"> その日に君たる者は、自身のため、また国のすべての民のため、雄牛をささげて罪祭とし、</span>
<span className="v" id="v23" data-v="23" data-xref="ヨブ記 42:8; レビ記 23:8; 民数記 23:1–2"> 祝い日である七日の間は、七頭の雄牛と、七頭の雄羊の無傷のものを、七日の間毎日、燔祭として主に供えよ。また、雄やぎを罪祭として日々ささげよ。</span>
<span className="v" id="v24" data-v="24" data-xref="エゼキエル書 46:5–7; 民数記 28:12–15"> また素祭として麦粉一エパを各雄牛のため、一エパを各雄羊のためにととのえ、油一ヒンを各エパに加えよ。</span>
<span className="v" id="v25" data-v="25" data-xref="レビ記 23:33–43; 民数記 29:12–38; 歴代志下 5:3"> 七月十五日の祝い日に、彼は七日の間、罪祭、燔祭、素祭および油を、このように供えなければならない。</span>
</div>

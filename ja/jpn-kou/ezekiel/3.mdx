<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨハネの黙示録 10:9–10; エゼキエル書 3:17–21; エゼキエル書 2:8–9"> 彼はわたしに言われた。「人の子よ、あなたに与えられたものを食べなさい。この巻物を食べ、行ってイスラエルの家に語りなさい」。</span>
<span className="v" id="v2" data-v="2" data-xref="エレミヤ書 25:17; 使徒行伝 26:19"> そこでわたしが口を開くと、彼はわたしにその巻物を食べさせた。</span>
<span className="v" id="v3" data-v="3" data-xref="エレミヤ書 15:16; ヨハネの黙示録 10:9–10; 詩篇 119:103"> そして彼はわたしに言われた、「人の子よ、わたしがあなたに与えるこの巻物を食べ、これであなたの腹を満たしなさい」。わたしがそれを食べると、それはわたしの口に甘いこと蜜のようであった。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="マタイによる福音書 10:5–6; 使徒行伝 1:8; エゼキエル書 2:3"> 彼はまたわたしに言われた、「人の子よ、イスラエルの家に行って、わたしの言葉を語りなさい。</span>
<span className="v" id="v5" data-v="5" data-xref="ヨナ書 1:2; イザヤ書 33:19; ヨナ書 3:2–4"> わたしはあなたを、異国語を用い、舌の重い民につかわすのでなく、イスラエルの家につかわすのである。</span>
<span className="v" id="v6" data-v="6" data-xref="マタイによる福音書 11:20–24; ローマ人への手紙 9:30–33; ヨナ書 3:5–10"> すなわちあなたがその言葉を知らない、異国語の舌の重い多くの民につかわすのではない。もしわたしがあなたをそのような民につかわしたら、彼らはあなたに聞いたであろう。</span>
<span className="v" id="v7" data-v="7" data-xref="ルカによる福音書 10:16; エゼキエル書 2:4; サムエル記上 8:7"> しかしイスラエルの家はあなたに聞くのを好まない。彼らはわたしに聞くのを好まないからである。イスラエルの家はすべて厚顔でまた強情である。</span>
<span className="v" id="v8" data-v="8" data-xref="エレミヤ書 1:18; 使徒行伝 7:51–56; ミカ書 3:8"> 見よ、わたしはあなたの顔を彼らの顔に向かって堅くし、あなたの額を彼らの額に向かって堅くした。</span>
<span className="v" id="v9" data-v="9" data-xref="エゼキエル書 2:6; エレミヤ書 1:8; イザヤ書 50:7"> わたしはあなたの額を岩よりも堅いダイヤモンドのようにした。ゆえに彼らを恐れてはならない。彼らの顔をはばかってはならない。彼らは反逆の家である」。</span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 119:11; ヨブ記 22:22; エゼキエル書 3:1–3"> また彼はわたしに言われた、「人の子よ、わたしがあなたに語るすべての言葉をあなたの心におさめ、あなたの耳に聞きなさい。</span>
<span className="v" id="v11" data-v="11" data-xref="エゼキエル書 2:7; エゼキエル書 3:27; エゼキエル書 33:30"> そして捕囚の人々、あなたの民の人々の所へ行って、彼らが聞いても、彼らが拒んでも、『主なる神はこう言われる』と彼らに言いなさい」。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="エゼキエル書 8:3; 使徒行伝 8:39; エゼキエル書 11:1"> 時に霊がわたしをもたげた。そして主の栄光がその所からのぼった時、わたしの後に大いなる地震の響きを聞いた。</span>
<span className="v" id="v13" data-v="13" data-xref="エゼキエル書 1:24; エゼキエル書 10:16–17; エゼキエル書 10:5"> それは互に相触れる生きものの翼の音と、そのかたわらの輪の音で、大いなる地震のように響いた。</span>
<span className="v" id="v14" data-v="14" data-xref="エゼキエル書 37:1; エレミヤ書 20:7–9; 列王紀下 3:15"> 霊はわたしをもたげ、わたしを取り去ったので、わたしは心を熱くし、苦々しい思いで出て行った。主の手が強くわたしの上にあった。</span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 137:1; ヨブ記 2:13; 創世記 50:10"> そしてわたしはケバル川のほとりのテルアビブにいる捕囚の人々のもとへ行き、七日の間、驚きあきれて彼らの中に座した。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="エレミヤ書 42:7"> 七日過ぎて後、主の言葉がわたしに臨んだ、</span>
<span className="v" id="v17" data-v="17" data-xref="イザヤ書 52:8; ヘブル人への手紙 13:17; 歴代志下 19:10"> 「人の子よ、わたしはあなたをイスラエルの家のために見守る者とした。あなたはわたしの口から言葉を聞くたびに、わたしに代って彼らを戒めなさい。</span>
<span className="v" id="v18" data-v="18" data-xref="エゼキエル書 33:6; ヤコブの手紙 5:19–20; エゼキエル書 3:20"> わたしが悪人に『あなたは必ず死ぬ』と言うとき、あなたは彼の命を救うために彼を戒めず、また悪人を戒めて、その悪い道から離れるように語らないなら、その悪人は自分の悪のために死ぬ。しかしその血をわたしはあなたの手から求める。</span>
<span className="v" id="v19" data-v="19" data-xref="エゼキエル書 33:9; エゼキエル書 14:20; テモテヘの第一の手紙 4:16"> しかし、もしあなたが悪人を戒めても、彼がその悪をも、またその悪い道をも離れないなら、彼はその悪のために死ぬ。しかしあなたは自分の命を救う。</span>
<span className="v" id="v20" data-v="20" data-xref="エゼキエル書 18:24; エゼキエル書 18:26; エゼキエル書 33:12–13"> また義人がその義にそむき、不義を行うなら、わたしは彼の前に、つまずきを置き、彼は死ぬ。あなたが彼を戒めなかったゆえ、彼はその罪のために死に、その行った義は覚えられない。しかしその血をわたしはあなたの手から求める。</span>
<span className="v" id="v21" data-v="21" data-xref="テモテヘの第一の手紙 4:16; 箴言 9:9; テトスヘの手紙 2:15"> けれども、もしあなたが義人を戒めて、罪を犯さないように語り、そして彼が罪を犯さないなら、彼は戒めを受けいれたゆえに、その命を保ち、あなたは自分の命を救う」。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="使徒行伝 9:6; エゼキエル書 37:1; エゼキエル書 8:4"> その所で主の手がわたしの上に臨み、彼はわたしに言われた、「立って、平野に出て行きなさい。その所でわたしはあなたに語ろう」。</span>
<span className="v" id="v23" data-v="23" data-xref="エゼキエル書 1:28; 使徒行伝 7:55; ヨハネの黙示録 1:17"> そこで、わたしは立って平野に出て行った。見よ、主の栄光が、かつてわたしがケバル川のほとりで見た栄光のように、その所に立ち現れたので、わたしはひれ伏した。</span>
<span className="v" id="v24" data-v="24" data-xref="エゼキエル書 2:2; ダニエル書 10:19; ダニエル書 10:8–10"> しかし霊がわたしのうちにはいって、わたしを立ちあがらせ、わたしに語って言った、「行って、あなたの家にこもっていなさい。</span>
<span className="v" id="v25" data-v="25" data-xref="エゼキエル書 4:8; 使徒行伝 9:16; マルコによる福音書 3:21"> 人の子よ、見よ、彼らはあなたの上になわをかけ、それであなたを縛り、あなたを民の中に行かせないようにする。</span>
<span className="v" id="v26" data-v="26" data-xref="エゼキエル書 24:27; ミカ書 3:6–7; アモス書 8:11–12"> わたしはあなたの舌を上あごにつかせ、あなたをおしにして、彼らを戒めることができないようにする。彼らは反逆の家だからである。</span>
<span className="v" id="v27" data-v="27" data-xref="エゼキエル書 12:2–3; エゼキエル書 24:27; エゼキエル書 3:11"> しかし、わたしがあなたと語るときは、あなたの口を開く。あなたは彼らに『主なる神はこう言われる』と言わなければならない。聞く者は聞くがよい、拒む者は拒むがよい。彼らは反逆の家だからである。</span>
</div>

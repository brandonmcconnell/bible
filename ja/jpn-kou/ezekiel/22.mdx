<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> また主の言葉がわたしに臨んで言った、</span>
<span className="v" id="v2" data-v="2" data-xref="イザヤ書 58:1; エゼキエル書 24:6; エゼキエル書 24:9"> 「人の子よ、あなたはさばくのか。血を流すこの町をさばくのか。それならこの町にそのもろもろの憎むべき事を示して、</span>
<span className="v" id="v3" data-v="3" data-xref="エゼキエル書 22:27; ローマ人への手紙 2:5; ペテロの第二の手紙 2:3"> 言え。主なる神はこう言われる、自分のうちに血を流して、その刑罰の時をまねき、偶像を造ってその身を汚す町よ、</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀下 21:16; 詩篇 44:13–14; エゼキエル書 22:2"> あなたはその流した血によって罪を得、その造った偶像によって汚れ、あなたの日を近づかせ、あなたの年の定めの時はきた。それゆえわたしはあなたをもろもろの国民のあざけりとなし、万国の物笑いとする。</span>
<span className="v" id="v5" data-v="5" data-xref="イザヤ書 22:2; エレミヤ書 15:2–3"> あなたに近い者も、遠い者も、汚れと、混乱に満ちているあなたをあざける。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="エゼキエル書 22:27; イザヤ書 1:23; ゼカリヤ書 3:3"> 見よ、あなたのうちのイスラエルの君たちは、おのおのその力にしたがって、血を流そうとしている。</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 27:16; 出エジプト記 22:21–22; レビ記 20:9"> 父母はあなたのうちで卑しめられ、寄留者はあなたのうちで虐待をうけ、みなしごと、やもめとはあなたのうちで悩まされている。</span>
<span className="v" id="v8" data-v="8" data-xref="エゼキエル書 23:38–39; エゼキエル書 22:26; エゼキエル書 20:13"> あなたはわたしの聖なるものを卑しめ、わたしの安息日を汚した。</span>
<span className="v" id="v9" data-v="9" data-xref="ホセア書 4:14; レビ記 19:16; ホセア書 4:10"> 人をののしって血を流そうとする者は、あなたのうちにおり、人々はあなたのうちで、山の上で食事をし、あなたのうちで、みだらなおこないをし、</span>
<span className="v" id="v10" data-v="10" data-xref="レビ記 18:19; レビ記 18:7–8; エゼキエル書 18:6"> あなたのうちで、父の裸を現し、あなたのうちで、汚れのうちにある女を犯す。</span>
<span className="v" id="v11" data-v="11" data-xref="レビ記 18:15; サムエル記下 13:14; レビ記 20:17"> またあなたのうちに、その隣の妻と憎むべき事を行う者があり、淫行をもって、その嫁を汚す者があり、自分の父の娘である自分の姉妹を犯す者があり、</span>
<span className="v" id="v12" data-v="12" data-xref="申命記 27:25; エゼキエル書 23:35; 詩篇 106:21"> また血を流そうとして、あなたのうちで、まいないを取る者がある。あなたは利息と高利とを取り、しえたげによって、あなたの隣り人のものをかすめ、そしてわたしを忘れてしまったと、主なる神は言われる。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="エゼキエル書 21:17; イザヤ書 33:15; アモス書 2:6–8"> それゆえ見よ、あなたが得た不正の利の事、およびあなたのうちにある流血の事に対して、わたしは手を打ちならす。</span>
<span className="v" id="v14" data-v="14" data-xref="エゼキエル書 21:7; エゼキエル書 17:24; エゼキエル書 24:14"> わたしがあなたを攻める日には、あなたの勇気は、これに耐え得ようか。またあなたの手は強くあり得ようか。主なるわたしはこれを宣言し、これをなす。</span>
<span className="v" id="v15" data-v="15" data-xref="ネヘミヤ書 1:8; エゼキエル書 22:22; 申命記 4:27"> わたしはあなたを、もろもろの国民のうちに散らし、国々の間にまき、そしてあなたから汚れを除く。</span>
<span className="v" id="v16" data-v="16" data-xref="エゼキエル書 6:7; 詩篇 83:18; エゼキエル書 7:24"> わたしはあなたによって、もろもろの国民の前に汚される。そしてあなたはわたしが主であることを知る」。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17"> 主の言葉がまたわたしに臨んだ、</span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 119:119; イザヤ書 1:22; エレミヤ書 6:28–30"> 「人の子よ、イスラエルの家はわたしに対して、かなかすとなった。彼らはすべて炉の中の銀、青銅、すず、鉄、鉛のかなかすとなった。</span>
<span className="v" id="v19" data-v="19" data-xref="マタイによる福音書 13:30; エゼキエル書 24:3–6; ミカ書 4:12"> それゆえ、主なる神はこう言われる、あなたがたは皆かなかすとなったゆえ、見よ、わたしはあなたがたをエルサレムの中に集める。</span>
<span className="v" id="v20" data-v="20" data-xref="エレミヤ書 4:11–12; イザヤ書 54:16; エゼキエル書 24:13"> 人が銀、青銅、鉄、鉛、すずなどを炉の中に集め、これに火を吹きかけて溶かすように、わたしは怒りと憤りとをもって、あなたがたを集め入れて溶かす。</span>
<span className="v" id="v21" data-v="21" data-xref="イザヤ書 64:7; ナホム書 1:6; 詩篇 50:3"> すなわち、わたしはあなたがたを集め、わたしの怒りの火を、あなたがたに吹きかける。あなたがたはその中で溶ける。</span>
<span className="v" id="v22" data-v="22" data-xref="エゼキエル書 20:8; エゼキエル書 20:33; ホセア書 5:10"> 銀が炉の中で溶けるように、あなたがたもその中で溶ける。そしてあなたがたは主なるわたしが、あなたがたの上に、わたしの怒りを注いだことを知るようになる」。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23"> 主の言葉がまたわたしに臨んだ、</span>
<span className="v" id="v24" data-v="24" data-xref="歴代志下 36:14–16; エレミヤ書 2:30; 歴代志下 28:22"> 「人の子よ、これに言え、あなたは怒りの日に清められず、また雨の降らない地である。</span>
<span className="v" id="v25" data-v="25" data-xref="ホセア書 6:9; エレミヤ書 2:34; エゼキエル書 13:19"> その中の君たちは、獲物を裂くほえるししのような者で、彼らは人々を滅ぼし、宝と尊い物とを取り、そのうちに、やもめの数をふやす。</span>
<span className="v" id="v26" data-v="26" data-xref="レビ記 10:10; エゼキエル書 44:23; エゼキエル書 22:8"> その祭司たちはわが律法を犯し、聖なる物を汚した。彼らは聖なる物と汚れた物とを区別せず、清くない物と清い物との違いを教えず、わが安息日を無視し、こうしてわたしは彼らの間に汚されている。</span>
<span className="v" id="v27" data-v="27" data-xref="エゼキエル書 22:13; イザヤ書 1:23; エゼキエル書 22:6"> その中にいる君たちは、獲物を裂くおおかみのようで、血を流し、不正の利を得るために人々を滅ぼす。</span>
<span className="v" id="v28" data-v="28" data-xref="エゼキエル書 13:6–7; エゼキエル書 13:10–16; エレミヤ書 23:25–32"> その預言者たちは、水しっくいでこれを塗り、偽りの幻を見、彼らに偽りを占い、主が語らないのに『主なる神はこう言われる』と言う。</span>
<span className="v" id="v29" data-v="29" data-xref="エゼキエル書 22:7; 出エジプト記 23:9; 出エジプト記 22:21"> 国の民はしえたげを行い、奪うことをなし、乏しい者と貧しい者とをかすめ、不法に他国人をしえたぐ。</span>
<span className="v" id="v30" data-v="30" data-xref="イザヤ書 59:16; エレミヤ書 5:1; 詩篇 106:23"> わたしは、国のために石がきを築き、わたしの前にあって、破れ口に立ち、わたしにこれを滅ぼさせないようにする者を、彼らのうちに尋ねたが得られなかった。</span>
<span className="v" id="v31" data-v="31" data-xref="エゼキエル書 16:43; エゼキエル書 7:8–9; エゼキエル書 9:10"> それゆえ、わたしはわが怒りを彼らの上に注ぎ、わが憤りの火をもって彼らを滅ぼし、彼らのおこないを、そのこうべに報いたと、主なる神は言われる」。</span>
</div>

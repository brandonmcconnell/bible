<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="エゼキエル書 40:20; エゼキエル書 40:17; エゼキエル書 42:13"> 彼はわたしを北の方の内庭に連れ出し、庭に向かった北の方の建物に対する室に導いた。</span>
<span className="v" id="v2" data-v="2" data-xref="エゼキエル書 41:13"> 北側にある建物の長さは百キュビト、幅は五十キュビトである。</span>
<span className="v" id="v3" data-v="3" data-xref="エゼキエル書 41:15–16; エゼキエル書 41:10; 雅歌 7:5"> 二十キュビトの内庭に続いて、外庭の敷石に面し、三階になった廊下があった。</span>
<span className="v" id="v4" data-v="4" data-xref="エゼキエル書 46:19; ルカによる福音書 13:24; マタイによる福音書 7:14"> また室の前に幅十キュビト、長さ百キュビトの通路があった。その戸は北に向かっていた。</span>
<span className="v" id="v5" data-v="5" data-xref="エゼキエル書 41:7"> その建物の上の室は、下の室と中の室よりも狭かった。それは廊下のために、場所を取ったためである。</span>
<span className="v" id="v6" data-v="6" data-xref="エゼキエル書 41:6; 列王紀上 6:8"> これらは三階であって、外庭の柱のような柱は持たなかった。それで上の室は、下および中の室よりも狭いのである。</span>
<span className="v" id="v7" data-v="7" data-xref="エゼキエル書 42:12; エゼキエル書 42:10"> 室の外に沿ってかきがあり、それは他の室に向かって外庭に至る。その長さは五十キュビト、</span>
<span className="v" id="v8" data-v="8" data-xref="エゼキエル書 41:13–14"> 外庭の室の長さも五十キュビトあった。宮に面する所は百キュビトであった。</span>
<span className="v" id="v9" data-v="9" data-xref="エゼキエル書 46:19; エゼキエル書 44:5"> これらの室の下に外庭からこれにはいるように、東側に入口があった。</span>
<span className="v" id="v10" data-v="10" data-xref="エゼキエル書 42:1; エゼキエル書 42:13; エゼキエル書 41:12–15"> 外側のかきは、外庭に始まっている。<br />南の方で、庭と建物との前に、室があった。</span>
<span className="v" id="v11" data-v="11" data-xref="エゼキエル書 42:4"> 北向きの室と同様に、その前に通路があり、その長さも幅も同様で、その出口もその配置もその戸も同様である。</span>
<span className="v" id="v12" data-v="12"> 南の室の下に、人々が通路にはいる東の入口があり、これに対して隔てのかきがあった。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="レビ記 10:17; レビ記 7:6; エゼキエル書 40:46"> 時に彼はわたしに言った、「庭に面した北の室と、南の室とは、聖なる室であって、主に近く仕える祭司たちが、最も聖なるものを食べる場所である。その場所に彼らは、最も聖なるもの、すなわち素祭、罪祭、愆祭のものを置かなければならない。その場所は聖だからである。</span>
<span className="v" id="v14" data-v="14" data-xref="エゼキエル書 44:19; レビ記 8:7; 出エジプト記 29:4–9"> 祭司たちが、聖所にはいった時は、そこから外庭に出てはならない。彼らは勤めを行う衣服を、その所に置かなければならない。これは聖だからである。彼らは民衆に属する場所に近づく前に、他の衣服を着けなければならない」。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="エゼキエル書 43:1; エゼキエル書 41:15; エゼキエル書 40:6–16"> 彼らは宮の庭の内部を測り終えると、東向きの門の道から、わたしを連れ出して、宮の周囲を測った。</span>
<span className="v" id="v16" data-v="16" data-xref="エゼキエル書 40:3; ヨハネの黙示録 11:1–2; ゼカリヤ書 2:1"> 彼が測りざおで、東側を測ると、測りざおで五百キュビトあり、</span>
<span className="v" id="v17" data-v="17"> また転じて、北側を測ると、測りざおで五百キュビトあり、</span>
<span className="v" id="v18" data-v="18"> また転じて、南側を測ると、測りざおで五百キュビトあり、</span>
<span className="v" id="v19" data-v="19"> また転じて、西側を測ると、測りざおで五百キュビトあった。</span>
<span className="v" id="v20" data-v="20" data-xref="エゼキエル書 45:2; エゼキエル書 22:26; エゼキエル書 40:5"> このように、四方を測ったが、その周囲に、長さ五百キュビト、幅五百キュビトのかきがあって、聖所と、俗の所との隔てをなしていた。</span>
</div>

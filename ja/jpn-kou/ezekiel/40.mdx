<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="エゼキエル書 33:21; エゼキエル書 1:2–3; エゼキエル書 3:14"> われわれが捕え移されてから二十五年、都が打ち破られて後十四年、その年の初めの月の十日、その日に主の手がわたしに臨み、わたしをかの所に携えて行った。</span>
<span className="v" id="v2" data-v="2" data-xref="エゼキエル書 1:1; ダニエル書 7:1; ダニエル書 7:7"> すなわち神は幻のうちに、わたしをイスラエルの地に携えて行って、非常に高い山の上におろされた。その山の上に、わたしと相対して、一つの町のような建物があった。</span>
<span className="v" id="v3" data-v="3" data-xref="エゼキエル書 47:3; ヨハネの黙示録 11:1; ダニエル書 10:5–6"> 神がわたしをそこに携えて行かれると、見よ、ひとりの人がいた。その姿は青銅の形のようで、手に麻のなわと、測りざおとを持って門に立っていた。</span>
<span className="v" id="v4" data-v="4" data-xref="エゼキエル書 44:5; マタイによる福音書 10:27; エゼキエル書 2:7–8"> その人はわたしに言った、「人の子よ、目で見、耳で聞き、わたしがあなたに示す、すべての事を心にとめよ。あなたをここに携えて来たのは、これをあなたに示すためである。あなたの見ることを、ことごとくイスラエルの家に告げよ」。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="エゼキエル書 42:20; イザヤ書 26:1; ヨハネの黙示録 21:12"> 見よ、宮の外の周囲に、かきがあり、その人の手に六キュビトの測りざおがあった。そのキュビトは、おのおの一キュビトと一手幅とである。彼が、そのかきの厚さを測ると、一さおあり、高さも一さおあった。</span>
<span className="v" id="v6" data-v="6" data-xref="エゼキエル書 43:1; エゼキエル書 8:16; エゼキエル書 11:1"> 彼が東向きの門に行き、その階段を上って、門の敷居を測ると、その厚さは一さおあり、</span>
<span className="v" id="v7" data-v="7" data-xref="エゼキエル書 40:36; エゼキエル書 40:33; 歴代志上 23:28"> その詰め所は長さ一さお、幅一さお、詰め所と、詰め所との間は五キュビトあり、内の門の廊のかたわらの門の敷居は一さおあった。</span>
<span className="v" id="v8" data-v="8"> 門の廊を測ると八キュビトあり、</span>
<span className="v" id="v9" data-v="9" data-xref="エゼキエル書 45:19"> その脇柱は二キュビト、門の廊は内側にあった。</span>
<span className="v" id="v10" data-v="10"> 東向きの門の詰め所は、こなたに三つ、かなたに三つあり、三つとも同じ寸法である。脇柱もまた、こなたかなたともに同じ寸法である。</span>
<span className="v" id="v11" data-v="11"> 門の入口の広さを測ると十キュビトあり、門の長さは十三キュビトあった。</span>
<span className="v" id="v12" data-v="12"> 詰め所の前の境は一キュビト、かなたの境も一キュビトで、詰め所は、こなたかなたともに六キュビトあった。</span>
<span className="v" id="v13" data-v="13"> 彼がまたこの詰め所の裏から、かの詰め所の裏まで、門を測ると、入口から入口まで二十五キュビトあった。</span>
<span className="v" id="v14" data-v="14" data-xref="出エジプト記 27:9; イザヤ書 62:9; エゼキエル書 42:1"> 彼がまた廊を測ると二十キュビトあり、門の廊の周囲は、すべて庭である。</span>
<span className="v" id="v15" data-v="15"> 入口の門の前から内の門の廊の前まで五十キュビトあり、</span>
<span className="v" id="v16" data-v="16" data-xref="歴代志下 3:5; 列王紀上 6:4; エゼキエル書 41:26"> 詰め所と、門の内側の周囲の脇柱とに窓があり、廊の内側の周囲にも、同様に窓があり、脇柱には、しゅろがあった。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="ヨハネの黙示録 11:2; エゼキエル書 42:1; 歴代志上 23:28"> 彼がまたわたしを外庭に携え入れると、見よ、庭の周囲に設けた室と、敷石とがあり、敷石の上に三十の室があった。</span>
<span className="v" id="v18" data-v="18"> 敷石は門のわきにあり、門と同じ長さで、これは下の敷石である。</span>
<span className="v" id="v19" data-v="19" data-xref="エゼキエル書 40:23; エゼキエル書 40:27; エゼキエル書 46:1–2"> 彼が下の門の内の前から、内庭の外の前までの距離を測ると、百キュビトあった。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="エゼキエル書 40:6"> また彼はわたしに先だって北へ行った。見よ、そこに外庭に属する北向きの門があった。彼はその長さと幅とを測った。</span>
<span className="v" id="v21" data-v="21" data-xref="エゼキエル書 40:29–30; エゼキエル書 40:25–26; エゼキエル書 40:10–16"> その詰め所が、こなたに三つ、かなたに三つあり、また脇柱と廊とがあった。これらは初めの門と同じ寸法で、長さは五十キュビト、幅は二十五キュビトである。</span>
<span className="v" id="v22" data-v="22" data-xref="エゼキエル書 40:31; エゼキエル書 40:37; エゼキエル書 40:6"> その窓と、廊と、しゅろとは、東向きの門にあるものと同じ寸法である。そして七段の階段を経て、それに上ると、廊は内側にあった。</span>
<span className="v" id="v23" data-v="23" data-xref="エゼキエル書 40:19; エゼキエル書 40:27–28; 出エジプト記 38:9–12"> 内庭の門は北と東の門に向かっていた。彼が門から門までを測ると、百キュビトあった。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="エゼキエル書 46:9; エゼキエル書 40:6; エゼキエル書 40:20–21"> 彼がまたわたしを南へ行かせると、見よ、南向きの門があった。その脇柱と廊を測ると、他と同じ寸法であった。</span>
<span className="v" id="v25" data-v="25" data-xref="エゼキエル書 40:33; エゼキエル書 40:16; エゼキエル書 40:21–22"> これと、その廊の周囲とに、他の窓のような窓があって、その長さは五十キュビト、幅は二十五キュビトあった。</span>
<span className="v" id="v26" data-v="26" data-xref="エゼキエル書 40:22; エゼキエル書 40:16; エゼキエル書 40:6"> これを上るのに七段の階段があり、その廊は内側にあった。その脇柱の上には、こなたに一つ、かなたに一つのしゅろがあった。</span>
<span className="v" id="v27" data-v="27" data-xref="エゼキエル書 40:23; エゼキエル書 40:32; エゼキエル書 40:19"> 内庭には南向きの門があり、門から門まで南の方へ測ると、百キュビトあった。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="エゼキエル書 40:35; エゼキエル書 40:32"> 彼がわたしを南の門から内庭にはいらせ、南の門を測ると、さきのものと、同じ寸法であった。</span>
<span className="v" id="v29" data-v="29" data-xref="エゼキエル書 40:25; エゼキエル書 40:16; エゼキエル書 40:7"> その詰め所と、脇柱と、廊とは、他のものと同じ寸法で、その門と、廊の周囲とには窓があり、門の長さは五十キュビト、幅は二十五キュビトであった。</span>
<span className="v" id="v30" data-v="30" data-xref="エゼキエル書 40:21; エゼキエル書 40:36; エゼキエル書 40:25"> 周囲に廊があって、その長さは二十五キュビト、幅は五キュビトである。</span>
<span className="v" id="v31" data-v="31" data-xref="エゼキエル書 40:26; エゼキエル書 40:34; エゼキエル書 40:22"> その廊は外庭に面して、脇柱の上にしゅろがあり、その階段は八段であった。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="エゼキエル書 40:35; エゼキエル書 40:28–31"> 彼はまたわたしを内庭の東の方に携えて行って、門を測った。それは他と同じ寸法であった。</span>
<span className="v" id="v33" data-v="33" data-xref="エゼキエル書 40:21; エゼキエル書 40:36; エゼキエル書 40:25"> その詰め所と、脇柱と、廊とは、他と同じ寸法で、その門と、その廊の周囲とに窓があり、門の長さは五十キュビト、幅は二十五キュビトである。</span>
<span className="v" id="v34" data-v="34" data-xref="エゼキエル書 40:22; エゼキエル書 40:31; エゼキエル書 40:37"> その廊は外庭に面し、その脇柱の上には、こなたかなたに、しゅろがあり、その階段は八段であった。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="エゼキエル書 47:2; エゼキエル書 40:32; エゼキエル書 44:4"> 彼がまたわたしを北の門に携えて行って、これを測ると、それは他と同じ寸法であった。</span>
<span className="v" id="v36" data-v="36" data-xref="エゼキエル書 40:29; エゼキエル書 40:21; エゼキエル書 40:16"> その詰め所と、脇柱と、廊とは、他と同じ寸法で、その周囲に窓があり、門の長さは五十キュビト、幅は二十五キュビトである。</span>
<span className="v" id="v37" data-v="37" data-xref="エゼキエル書 40:34; エゼキエル書 40:31"> その廊は外庭に面し、その脇柱の上には、こなたかなたに、しゅろがあり、その階段は八段であった。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="歴代志下 4:6; エゼキエル書 40:17; レビ記 8:21"> 門の廊に戸のある室があって、そこは燔祭の物を洗う所である。</span>
<span className="v" id="v39" data-v="39" data-xref="エゼキエル書 46:2; レビ記 1:3–17; レビ記 4:2–3"> 門の廊に、こなたに二つの台、かなたに二つの台があり、その上で、燔祭、罪祭、愆祭の物をほふるのであった。</span>
<span className="v" id="v40" data-v="40"> 北の門の入口にある廊の外の片側に、二つの台があり、門の廊の他の側にも、二つの台があり、</span>
<span className="v" id="v41" data-v="41" data-xref="エゼキエル書 40:39–40"> 門のかたわら、内側に四つの台、外側に四つの台があって、合わせて八つの台である。その上で、犠牲の物をほふるのである。</span>
<span className="v" id="v42" data-v="42" data-xref="エゼキエル書 40:39; 出エジプト記 20:25"> そこにまた燔祭のために四つの切り石の台があり、その長さは一キュビト半、幅は一キュビト半、高さは一キュビト、その上に燔祭および犠牲をほふる器を置くのである。</span>
<span className="v" id="v43" data-v="43" data-xref="レビ記 1:8; レビ記 1:6; レビ記 8:20"> 内の周囲に、一手幅の折り釘が打ちつけてあって、供え物の肉は、台の上に置かれるのである。</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="歴代志上 6:31–32; 歴代志上 16:41–43; エゼキエル書 40:27"> 彼はまたわたしを、外から内庭に連れてはいった。見よ、内庭に二つの室があり、一つは北の門のかたわらにあって南に向かい、一つは南の門のかたわらにあって、北に向かっていた。</span>
<span className="v" id="v45" data-v="45" data-xref="歴代志上 9:23; 詩篇 134:1; レビ記 8:35"> 彼はわたしに言った、この南向きの室は、宮を守る祭司のためのもの、</span>
<span className="v" id="v46" data-v="46" data-xref="エゼキエル書 44:15; エゼキエル書 43:19; 列王紀上 2:35"> また北向きの室は、祭壇を守る祭司のためのものである。その人たちは、レビの子孫のうちのザドクの子孫であって、主に近く仕える者たちである。</span>
<span className="v" id="v47" data-v="47" data-xref="エゼキエル書 40:19; エゼキエル書 40:23; エゼキエル書 40:27"> そして彼が庭を測ると、その長さは百キュビト、幅も百キュビトで四角である。宮の前には祭壇があった。</span>
</div>
<div className="bp">
<span className="v" id="v48" data-v="48" data-xref="歴代志下 3:4; 列王紀上 6:3"> 彼がわたしを宮の廊に連れて行って、廊の脇柱を測ると、こなたも五キュビト、かなたも五キュビトであり、門の幅は十四キュビトである。門の壁は、こなたも三キュビト、かなたも三キュビトである。</span>
<span className="v" id="v49" data-v="49" data-xref="列王紀上 7:15–21; エゼキエル書 40:34; 歴代志下 3:17"> 廊の長さは二十キュビト、幅は十二キュビトであり、十の階段によって上るのである。脇柱に沿って、こなたに一つ、かなたに一つの柱があった。</span>
</div>

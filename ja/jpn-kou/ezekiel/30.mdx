<span className="v" id="v1" data-v="1"> 主の言葉がわたしに臨んだ、</span>
<span className="v" id="v2" data-v="2" data-xref="イザヤ書 13:6; エゼキエル書 21:12; ヨエル書 1:11"> 「人の子よ、預言して言え、主なる神はこう言われる、<br /><span className="pl pl-1">嘆け、その日はわざわいだ。</span></span>
<span className="v" id="v3" data-v="3" data-xref="オバデヤ書 1:15; ヨエル書 2:1–2; ヨエル書 1:15"> <span className="pl pl-1">その日は近い、主の日は近い。</span><br /><span className="pl pl-1">これは雲の日、異邦人の滅びの時である。</span></span>
<span className="v" id="v4" data-v="4" data-xref="エゼキエル書 29:19; エゼキエル書 29:8; イザヤ書 16:7"> <span className="pl pl-1">つるぎがエジプトに臨む。</span><br /><span className="pl pl-1">エジプトで殺される者の倒れる時、</span><br /><span className="pl pl-1">エチオピヤには苦しみがあり、</span><br /><span className="pl pl-1">その財宝は奪い去られ、その基は破られる。</span></span>
<span className="v" id="v5" data-v="5" data-xref="エレミヤ書 25:20; エゼキエル書 27:10; エレミヤ書 25:24"> <span className="pl pl-1">エチオピヤ、プテ、ルデ、アラビヤ、リビヤおよび同盟国の人々は、彼らと共につるぎに倒れる。</span></span>
<span className="v" id="v6" data-v="6" data-xref="エゼキエル書 29:10; イザヤ書 20:3–6; イザヤ書 31:3"> <span className="pl pl-1">主はこう言われる、</span><br /><span className="pl pl-1">エジプトを助ける者は倒れ、</span><br /><span className="pl pl-1">その誇る力はうせる。</span><br /><span className="pl pl-1">ミグドルからスエネまで、</span><br /><span className="pl pl-1">人々はつるぎによってそのうちに倒れると</span><br /><span className="pl pl-1">主なる神が言われる。</span></span>
<span className="v" id="v7" data-v="7" data-xref="エゼキエル書 29:12; エレミヤ書 25:18–26; エゼキエル書 32:18–32"> <span className="pl pl-1">それは荒れて、荒れはてた国々のうちにあり、</span><br /><span className="pl pl-1">その町々は荒れた町々のうちにある。</span></span>
<span className="v" id="v8" data-v="8" data-xref="エゼキエル書 29:6; エゼキエル書 29:16; アモス書 1:7"> <span className="pl pl-1">わたしがエジプトに火を送り、</span><br /><span className="pl pl-1">これを助ける者が皆滅びる時、</span><br /><span className="pl pl-1">彼らはわたしが主であることを知る。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="イザヤ書 18:1–2; イザヤ書 23:5; エゼキエル書 32:9–10"> その日、早足の使者がわたしから出て、何事も知らぬエチオピヤびとを恐れさせる。そしてかのエジプトの滅びの日に、彼らに苦しみが来る。見よ、これはかならず来る。</span>
<span className="v" id="v10" data-v="10" data-xref="エゼキエル書 29:19; エゼキエル書 32:11–16; エゼキエル書 29:4–5"> <span className="pl pl-1">主なる神はこう言われる、</span><br /><span className="pl pl-1">わたしはバビロンの王ネブカデレザルの手によって</span><br /><span className="pl pl-1">エジプトの富を滅ぼす。</span></span>
<span className="v" id="v11" data-v="11" data-xref="エゼキエル書 28:7; エゼキエル書 32:12; エゼキエル書 39:11–20"> <span className="pl pl-1">彼と彼に従うその民、すなわち国民のうちの</span><br /><span className="pl pl-1">最も恐るべき者がきて、その地を滅ぼす。</span><br /><span className="pl pl-1">彼らはつるぎを抜いて、エジプトを攻め、</span><br /><span className="pl pl-1">殺した者を国に満たす。</span></span>
<span className="v" id="v12" data-v="12" data-xref="エゼキエル書 29:3; ナホム書 1:4; ヨハネの黙示録 16:12"> <span className="pl pl-1">わたしはナイル川をからし、</span><br /><span className="pl pl-1">その国を悪しき者の手に売り、</span><br /><span className="pl pl-1">異邦人の手によって国とその中のものとを荒す。</span><br /><span className="pl pl-1">主なるわたしはこれを言った。</span></span>
<span className="v" id="v13" data-v="13" data-xref="ゼカリヤ書 10:11; エレミヤ書 46:14; エレミヤ書 2:16"> <span className="pl pl-1">主なる神はこう言われる、</span><br /><span className="pl pl-1">わたしは偶像をこわし、メンピスで偶像を滅ぼす。</span><br /><span className="pl pl-1">エジプトの国には、もはや君たる者がなくなる。</span><br /><span className="pl pl-1">わたしはエジプトの国に恐れを与える。</span></span>
<span className="v" id="v14" data-v="14" data-xref="エゼキエル書 29:14; エレミヤ書 46:25; 詩篇 78:43"> <span className="pl pl-1">わたしはパテロスを荒し、</span><br /><span className="pl pl-1">ゾアンに火を放ち、</span><br /><span className="pl pl-1">テーベにさばきをおこない、</span></span>
<span className="v" id="v15" data-v="15" data-xref="ヨハネの黙示録 16:1; ナホム書 1:6; 詩篇 11:6"> <span className="pl pl-1">わたしの怒りを、</span><br /><span className="pl pl-1">エジプトの要害であるペルシゥムに注ぎ、</span><br /><span className="pl pl-1">テーベの群衆を断ち、</span></span>
<span className="v" id="v16" data-v="16" data-xref="エゼキエル書 30:8–9; エゼキエル書 28:18"> <span className="pl pl-1">エジプトに火を下す。</span><br /><span className="pl pl-1">ペルシゥムはいたく苦しみ、</span><br /><span className="pl pl-1">テーベは打ち破られ、</span><br /><span className="pl pl-1">その城壁は破壊され、</span></span>
<span className="v" id="v17" data-v="17" data-xref="創世記 41:45"> <span className="pl pl-1">オンとピベセテの若者はつるぎに倒れ、</span><br /><span className="pl pl-1">女たちは捕え移される。</span></span>
<span className="v" id="v18" data-v="18" data-xref="エゼキエル書 30:3; エゼキエル書 29:15; イザヤ書 10:27"> <span className="pl pl-1">わたしがエジプトの支配を砕く時、</span><br /><span className="pl pl-1">テパネスでは日は暗くなり、</span><br /><span className="pl pl-1">その誇る力は絶え、</span><br /><span className="pl pl-1">雲はこれをおおい、</span><br /><span className="pl pl-1">その娘たちは捕え移される。</span></span>
<span className="v" id="v19" data-v="19" data-xref="エゼキエル書 30:14; ヨハネの黙示録 17:1; エゼキエル書 5:8"> <span className="pl pl-1">このようにわたしはエジプトにさばきを行う。</span><br /><span className="pl pl-1">そのとき彼らはわたしが主であることを知る」。</span></span>

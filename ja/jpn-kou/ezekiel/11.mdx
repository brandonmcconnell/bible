<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="エゼキエル書 3:14; エゼキエル書 11:24; エゼキエル書 11:13"> 時に霊はわたしをあげて、東に向かう主の宮の東の門に連れて行った。見よ、その門の入口に二十五人の者がいた。わたしはその中にアズルの子ヤザニヤと、ベナヤの子ペラテヤを見た。共に民のつかさであった。</span>
<span className="v" id="v2" data-v="2" data-xref="イザヤ書 30:1; エレミヤ書 5:5; 詩篇 2:1–2"> すると彼はわたしに言われた、「人の子よ、これらの者はこの町の中で悪い事を考え、悪い計りごとをめぐらす人々である。</span>
<span className="v" id="v3" data-v="3" data-xref="エゼキエル書 12:27; エゼキエル書 12:22; エゼキエル書 11:7–11"> 彼らは言う、『家を建てる時は近くはない。この町はなべであり、われわれは肉である』と。</span>
<span className="v" id="v4" data-v="4" data-xref="エゼキエル書 20:46–47; エゼキエル書 21:2; エゼキエル書 3:2–15"> それゆえ、彼らに向かって預言せよ。人の子よ、預言せよ」。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="エレミヤ書 17:10; エレミヤ書 16:17; ヨハネの黙示録 2:23"> 時に、主の霊がわたしに下って、わたしに言われた、「主はこう言われると言え、イスラエルの家よ、考えてみよ。わたしはあなたがたの心にある事どもを知っている。</span>
<span className="v" id="v6" data-v="6" data-xref="エゼキエル書 7:23; エゼキエル書 22:27; エゼキエル書 22:12"> あなたがたはこの町に殺される者を増し、殺された者をもってちまたを満たした。</span>
<span className="v" id="v7" data-v="7" data-xref="エゼキエル書 24:3–13; ミカ書 3:2–3; 列王紀下 25:18–22"> それゆえ、主なる神はこう言われる、町の中にあなたがたが置く殺された者は肉である。この町はなべである。しかし、あなたがたはその中から取り出される。</span>
<span className="v" id="v8" data-v="8" data-xref="箴言 10:24; イザヤ書 24:17–18; ヨブ記 3:25"> あなたがたはつるぎを恐れた。わたしはあなたがたにつるぎを臨ませると、主は言われる。</span>
<span className="v" id="v9" data-v="9" data-xref="エゼキエル書 5:8; 詩篇 106:41; 申命記 28:36"> またわたしはあなたがたをその中から引き出して、他国人の手に渡し、あなたがたをさばく。</span>
<span className="v" id="v10" data-v="10" data-xref="列王紀下 14:25; エレミヤ書 52:9–10; 列王紀下 25:19–21"> あなたがたはつるぎに倒れる。わたしはあなたがたをイスラエルの境でさばく。これによってあなたがたはわたしが主であることを知るようになる。</span>
<span className="v" id="v11" data-v="11" data-xref="エゼキエル書 11:3; エゼキエル書 11:7–10"> この町はあなたがたに対してなべとはならず、あなたがたはその肉とはならない。わたしはイスラエルの境であなたがたをさばく。</span>
<span className="v" id="v12" data-v="12" data-xref="エゼキエル書 8:10; エゼキエル書 8:16; エゼキエル書 8:14"> これによって、あなたがたはわたしが主であることを知るようになる。あなたがたはわたしの定めに歩まず、またわたしのおきてを行わず、かえってその周囲の他国人のおきてに従って行っているからである」。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="エゼキエル書 11:1; エゼキエル書 9:8; 使徒行伝 5:5"> このようにわたしが預言していた時、ベナヤの子ペラテヤが死んだので、わたしは打ち伏して、大声で叫んで言った、「ああ主なる神よ、あなたはイスラエルの残りの者をことごとく滅ぼそうとされるのですか」。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14"> 時に主の言葉がわたしに臨んで言った、</span>
<span className="v" id="v15" data-v="15" data-xref="エゼキエル書 33:24; イザヤ書 65:5; ヨハネによる福音書 16:2"> 「人の子よ、あなたの兄弟、あなたの友、あなたの兄弟である捕われ人、イスラエルの全家、エルサレムの住民は言った、『彼らが主から遠く離れた。この地はわれわれの所有として与えられているのだ』と。</span>
<span className="v" id="v16" data-v="16" data-xref="イザヤ書 8:14; 申命記 30:3–4; 詩篇 90:1"> それゆえ、言え、『主なる神はこう言われる、たといわたしは彼らを遠く他国人の中に移し、国々の中に散らしても、彼らの行った国々で、わたしはしばらく彼らのために聖所となる』と。</span>
<span className="v" id="v17" data-v="17" data-xref="エゼキエル書 28:25; エレミヤ書 3:18; エゼキエル書 34:13"> それゆえ、言え、『主はこう言われる、わたしはあなたがたをもろもろの民の中から集め、その散らされた国々から集めて、イスラエルの地をあなたがたに与える』と。</span>
<span className="v" id="v18" data-v="18" data-xref="エゼキエル書 37:23; エゼキエル書 5:11; エゼキエル書 42:7–8"> 彼らはその所に来る時、そのもろもろのいとうべきものと、もろもろの憎むべきものとをその所から取り除く。</span>
<span className="v" id="v19" data-v="19" data-xref="エゼキエル書 36:26–27; エレミヤ書 31:33; 詩篇 51:10"> そしてわたしは彼らに一つの心を与え、彼らのうちに新しい霊を授け、彼らの肉から石の心を取り去って、肉の心を与える。</span>
<span className="v" id="v20" data-v="20" data-xref="エゼキエル書 14:11; 詩篇 105:45; エレミヤ書 30:22"> これは彼らがわたしの定めに歩み、わたしのおきてを守って行い、そして彼らがわたしの民となり、わたしが彼らの神となるためである。</span>
<span className="v" id="v21" data-v="21" data-xref="エゼキエル書 9:10; 伝道の書 11:9; エレミヤ書 1:16"> しかしいとうべきもの、憎むべきものをその心に慕って歩む者には、彼らの行いに従ってそのこうべに報いると、主なる神は言われる」。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="エゼキエル書 10:19; エゼキエル書 1:19–20"> 時にケルビムはその翼をあげた。輪がそのかたわらにあり、イスラエルの神の栄光がその上にあった。</span>
<span className="v" id="v23" data-v="23" data-xref="ゼカリヤ書 14:4; エゼキエル書 8:4; エゼキエル書 10:4"> 主の栄光が町の中からのぼって、町の東にある山の上に立ちどまった。</span>
<span className="v" id="v24" data-v="24" data-xref="エゼキエル書 3:12; エゼキエル書 8:3; エゼキエル書 11:1"> その時、霊はわたしをあげ、神の霊によって、幻のうちにわたしをカルデヤの捕われ人の所へ携えて行った。そしてわたしが見た幻はわたしを離れてのぼった。</span>
<span className="v" id="v25" data-v="25" data-xref="エゼキエル書 3:4; エゼキエル書 3:27; エゼキエル書 3:17"> そこでわたしは主がわたしに示された事をことごとくかの捕われ人に告げた。</span>
</div>

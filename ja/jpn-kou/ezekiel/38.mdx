<div className="bp">
<span className="v" id="v1" data-v="1"> 主の言葉がわたしに臨んだ、</span>
<span className="v" id="v2" data-v="2" data-xref="エゼキエル書 39:1; エゼキエル書 27:13; エゼキエル書 38:3"> 「人の子よ、メセクとトバルの大君であるマゴグの地のゴグに、あなたの顔を向け、これに対して預言して、</span>
<span className="v" id="v3" data-v="3" data-xref="エゼキエル書 13:8; エゼキエル書 39:1–10; エゼキエル書 29:3"> 言え。主なる神はこう言われる、メセクとトバルの大君であるゴグよ、見よ、わたしはあなたの敵となる。</span>
<span className="v" id="v4" data-v="4" data-xref="エゼキエル書 29:4; ダニエル書 11:40; エゼキエル書 38:15"> わたしはあなたを引きもどし、あなたのあごにかぎをかけて、あなたと、あなたのすべての軍勢と、馬と、騎兵とを引き出す。彼らはみな武具をつけ、大盾、小盾を持ち、すべてつるぎをとる者で大軍である。</span>
<span className="v" id="v5" data-v="5" data-xref="エゼキエル書 27:10; 創世記 10:6; エゼキエル書 30:5"> ペルシャ、エチオピヤ、プテは彼らと共におり、みな盾とかぶとを持つ。</span>
<span className="v" id="v6" data-v="6" data-xref="エゼキエル書 27:14; 創世記 10:2–3; 歴代志上 1:5–6"> ゴメルとそのすべての軍隊、北の果のベテ・トガルマと、そのすべての軍隊など、多くの民もあなたと共におる。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="歴代志下 25:8; ヨエル書 3:9–12; イザヤ書 37:22"> あなたは備えをなせ。あなたとあなたの所に集まった軍隊は、みな備えをなせ。そしてあなたは彼らの保護者となれ。</span>
<span className="v" id="v8" data-v="8" data-xref="エゼキエル書 38:16; イザヤ書 24:22; エゼキエル書 38:11–12"> 多くの日の後、あなたは集められ、終りの年にあなたは戦いから回復された地、すなわち多くの民の中から、人々が集められた地に向かい、久しく荒れすたれたイスラエルの山々に向かって進む。その人々は国々から導き出されて、みな安らかに住んでいる。</span>
<span className="v" id="v9" data-v="9" data-xref="イザヤ書 28:2; エレミヤ書 4:13; ヨエル書 2:2"> あなたはそのすべての軍隊および多くの民を率いて上り、暴風のように進み、雲のように地をおおう。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="詩篇 36:4; ミカ書 2:1; 詩篇 83:3–4"> 主なる神はこう言われる、その日に、あなたの心に思いが起り、悪い計りごとを企てて、</span>
<span className="v" id="v11" data-v="11" data-xref="ゼカリヤ書 2:4–5; 箴言 3:29–30; エレミヤ書 49:31–32"> 言う、『わたしは無防備の村々の地に上り、穏やかにして安らかに住む民、すべて石がきもなく、貫の木も門もない地に住む者どもを攻めよう』と。</span>
<span className="v" id="v12" data-v="12" data-xref="イザヤ書 10:6; エゼキエル書 38:8; エゼキエル書 29:19"> そしてあなたは物を奪い、物をかすめ、いま人の住むようになっている荒れ跡を攻め、また国々から集まってきて、地の中央に住み、家畜と貨財とを持つ民を攻めようとする。</span>
<span className="v" id="v13" data-v="13" data-xref="エゼキエル書 27:15; エゼキエル書 27:22–23; エゼキエル書 32:2"> シバ、デダン、タルシシの商人、およびそのもろもろの村々はあなたに言う、『あなたは物を奪うために来たのか。物をかすめるために軍隊を集めたのか。あなたは金銀を持ち去り、家畜と貨財とを取りあげ、大いに物を奪おうとするのか』と。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="エゼキエル書 38:8; ゼカリヤ書 2:5; エレミヤ書 23:6"> それゆえ、人の子よ、ゴグに預言して言え。主なる神はこう言われる、わが民イスラエルの安らかに住むその日に、あなたは立ちあがり、</span>
<span className="v" id="v15" data-v="15" data-xref="エゼキエル書 39:2; エゼキエル書 38:6; ヨハネの黙示録 20:8"> 北の果のあなたの所から来る。多くの民はあなたと共におり、みな馬に乗り、その軍隊は大きく、その兵士は強い。</span>
<span className="v" id="v16" data-v="16" data-xref="エゼキエル書 39:21; エゼキエル書 38:23; ホセア書 3:5"> あなたはわが民イスラエルに攻めのぼり、雲のように地をおおう。ゴグよ、終りの日にわたしはあなたを、わが国に攻めきたらせ、あなたをとおして、わたしの聖なることを諸国民の目の前にあらわして、彼らにわたしを知らせる。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="ダニエル書 11:40–45; イザヤ書 63:1–6; ヨエル書 3:9–14"> 主なる神はこう言われる、わたしが昔、わがしもべイスラエルの預言者たちによって語ったのは、あなたのことではないか。すなわち彼らは、そのころ年久しく預言して、わたしはあなたを送って、彼らを攻めさせると言ったではないか。</span>
<span className="v" id="v18" data-v="18" data-xref="エゼキエル書 36:5–6; ヘブル人への手紙 12:29; 詩篇 89:46"> しかし主なる神は言われる、その日、すなわちゴグがイスラエルの地に攻め入る日に、わが怒りは現れる。</span>
<span className="v" id="v19" data-v="19" data-xref="ハガイ書 2:6–7; ヨハネの黙示録 11:13; ヨハネの黙示録 16:20"> わたしは、わがねたみと、燃えたつ怒りとをもって言う。その日には必ずイスラエルの地に、大いなる震動があり、</span>
<span className="v" id="v20" data-v="20" data-xref="ホセア書 4:3; ナホム書 1:4–6; ヨハネの黙示録 6:12–13"> 海の魚、空の鳥、野の獣、すべての地に這うもの、地のおもてにあるすべての人は、わが前に打ち震える。また山々はくずれ、がけは落ち、すべての石がきは地に倒れる。</span>
<span className="v" id="v21" data-v="21" data-xref="ハガイ書 2:22; 士師記 7:22; エゼキエル書 14:17"> 主なる神は言われる、わたしはゴグに対し、すべての恐れを呼びよせる。すべての人のつるぎは、その兄弟に向けられる。</span>
<span className="v" id="v22" data-v="22" data-xref="イザヤ書 66:16; 詩篇 11:6; ヨハネの黙示録 16:21"> わたしは疫病と流血とをもって彼をさばく。わたしはみなぎる雨と、ひょうと、火と、硫黄とを、彼とその軍隊および彼と共におる多くの民の上に降らせる。</span>
<span className="v" id="v23" data-v="23" data-xref="詩篇 9:16; ヨハネの黙示録 19:1–6; エゼキエル書 38:16"> そしてわたしはわたしの大いなることと、わたしの聖なることとを、多くの国民の目に示す。そして彼らはわたしが主であることを悟る。</span>
</div>

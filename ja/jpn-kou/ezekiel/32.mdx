<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="エゼキエル書 30:20; エゼキエル書 32:17; エゼキエル書 31:1"> 第十二年の十二月一日に、主の言葉がわたしに臨んだ、</span>
<span className="v" id="v2" data-v="2" data-xref="エゼキエル書 29:3; ナホム書 2:11–13; エゼキエル書 27:2"> 「人の子よ、エジプトの王パロのために、悲しみの歌をのべて、これに言え、<br /><span className="pl pl-1">あなたは自分をもろもろの国民のうちの</span><br /><span className="pl pl-1">ししであると考えているが、</span><br /><span className="pl pl-1">あなたは海の中の龍のような者である。</span><br /><span className="pl pl-1">あなたは川の中に、はね起き、</span><br /><span className="pl pl-1">足で水をかきまぜ、川を濁す。</span></span>
<span className="v" id="v3" data-v="3" data-xref="エゼキエル書 12:13; エレミヤ書 16:16; 伝道の書 9:12"> <span className="pl pl-1">主なる神はこう言われる、</span><br /><span className="pl pl-1">わたしは多くの民の集団をもって、</span><br /><span className="pl pl-1">わたしの網をあなたに投げかけ、</span><br /><span className="pl pl-1">あなたを網で引きあげる。</span></span>
<span className="v" id="v4" data-v="4" data-xref="イザヤ書 18:6; エゼキエル書 29:5; エゼキエル書 31:12–13"> <span className="pl pl-1">わたしはあなたを地に投げ捨て、</span><br /><span className="pl pl-1">野の面に投げうち、</span><br /><span className="pl pl-1">空のすべての鳥をあなたの上にとまらせ、</span><br /><span className="pl pl-1">全地の獣にあなたを与えて飽かせる。</span></span>
<span className="v" id="v5" data-v="5" data-xref="エゼキエル書 31:12"> <span className="pl pl-1">わたしはあなたの肉を山々に捨て、</span><br /><span className="pl pl-1">あなたの死体で谷を満たす。</span></span>
<span className="v" id="v6" data-v="6" data-xref="イザヤ書 34:3; イザヤ書 34:7; ヨハネの黙示録 14:20"> <span className="pl pl-1">わたしはあなたの流れる血で、</span><br /><span className="pl pl-1">地を潤し、山々にまで及ぼす。</span><br /><span className="pl pl-1">谷川はあなたの死体で満ちる。</span></span>
<span className="v" id="v7" data-v="7" data-xref="マタイによる福音書 24:29; ヨエル書 2:31; イザヤ書 13:10"> <span className="pl pl-1">わたしはあなたを滅ぼす時、</span><br /><span className="pl pl-1">空をおおい、星を暗くし、</span><br /><span className="pl pl-1">雲で日をおおい、月に光を放たせない。</span></span>
<span className="v" id="v8" data-v="8" data-xref="創世記 1:14; 箴言 20:20"> <span className="pl pl-1">わたしは空の輝く光を、</span><br /><span className="pl pl-1">ことごとくあなたの上に暗くし、</span><br /><span className="pl pl-1">あなたの国をやみとすると</span><br /><span className="pl pl-1">主なる神は言う。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="ヨハネの黙示録 18:10–15; エゼキエル書 30:26; エレミヤ書 25:15–25"> わたしはもろもろの国民、あなたの知らない国々の中に、あなたを捕え移す時、多くの民の心を痛ませる。</span>
<span className="v" id="v10" data-v="10" data-xref="エゼキエル書 26:16; エゼキエル書 27:35; 列王紀上 9:8"> わたしはあなたについて、多くの民を驚かせる。その王たちは、わたしがわたしのつるぎを、彼らの前に振るう時、あなたの事でおののく。あなたの倒れる日には、彼らはおのおの自分の命を思って、絶えず打ち震える。</span>
<span className="v" id="v11" data-v="11" data-xref="エレミヤ書 43:10; エゼキエル書 26:7; エゼキエル書 30:22–25"> 主なる神はこう言われる、バビロンの王のつるぎはあなたに臨む。</span>
<span className="v" id="v12" data-v="12" data-xref="エゼキエル書 28:7; エゼキエル書 29:19; エゼキエル書 31:11"> わたしはあなたの民衆を勇士のつるぎに倒れさせる。彼らは皆、もろもろの国民の中で、最も恐れられている者たちである。<br /><span className="pl pl-1">彼らはエジプトの誇を断つ、</span><br /><span className="pl pl-1">エジプトの民衆は皆滅ぼされる。</span></span>
<span className="v" id="v13" data-v="13" data-xref="エゼキエル書 29:11; エゼキエル書 29:8; エゼキエル書 30:12"> <span className="pl pl-1">わたしはその家畜をことごとく、</span><br /><span className="pl pl-1">多くの水のかたわらから滅ぼす。</span><br /><span className="pl pl-1">人の足は再びこれを濁さず、</span><br /><span className="pl pl-1">家畜のひずめもこれを乱さない。</span></span>
<span className="v" id="v14" data-v="14"> <span className="pl pl-1">その時わたしはその水を清くし、</span><br /><span className="pl pl-1">その川々を油のように流れさせると、</span><br /><span className="pl pl-1">主なる神は言う。</span></span>
<span className="v" id="v15" data-v="15" data-xref="エゼキエル書 6:7; 出エジプト記 7:5; 出エジプト記 14:4"> <span className="pl pl-1">わたしはエジプトの国を荒し、</span><br /><span className="pl pl-1">その国に満ちるものが、ことごとく取り去られる時、</span><br /><span className="pl pl-1">わたしがその中に住む者をことごとく撃つ時、</span><br /><span className="pl pl-1">彼らはわたしが主であることを知る。</span></span>
<span className="v" id="v16" data-v="16" data-xref="サムエル記下 1:17; 歴代志下 35:25; エゼキエル書 26:17"> <span className="pl pl-1">これは悲しみの歌である。人々はこれを歌い、もろもろの国の娘たちはこれを歌う。すなわちエジプトと、そのすべての民衆とのために、これを歌うのであると、主なる神は言われる」。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v17" data-v="17" data-xref="エゼキエル書 32:1; エゼキエル書 33:21; エゼキエル書 1:2"> 第十二年の一月十五日に、主の言葉がわたしに臨んだ、</span>
<span className="v" id="v18" data-v="18" data-xref="エゼキエル書 31:14; エゼキエル書 32:2; エレミヤ書 1:10"> 「人の子よ、エジプトの民衆のために嘆き、これと大いなる国々の娘らとを、下の国に投げ下し、穴に下った者のところに至らせよ。</span>
<span className="v" id="v19" data-v="19" data-xref="エゼキエル書 31:18; エゼキエル書 32:29–30; エレミヤ書 9:25–26"> <span className="pl pl-1">『あなたの美はだれにまさっているか。</span><br /><span className="pl pl-1">下って、割礼を受けない者と共に伏せよ』。</span></span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 28:3; エゼキエル書 32:23–26; エゼキエル書 32:29–30"> <span className="pl pl-1">彼らはつるぎに殺される者のうちに倒れる。その民衆はこれと共に伏せる。</span></span>
<span className="v" id="v21" data-v="21" data-xref="イザヤ書 14:9–10; エゼキエル書 32:27; エゼキエル書 32:19"> <span className="pl pl-1">勇士の首領はその助け手と共に、陰府の中から彼らに言う、『割礼を受けない者、つるぎに殺された者は下って伏している』と。</span></span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="エゼキエル書 32:26; エゼキエル書 32:29–30; エゼキエル書 32:24"> アッスリヤとその仲間とはその所におり、その墓はこれを囲む。彼らはみな殺された者、またつるぎに倒れた者である。</span>
<span className="v" id="v23" data-v="23" data-xref="エゼキエル書 26:20; エゼキエル書 32:24–27; 詩篇 27:13"> 彼らの墓は穴の奥に設けられ、その仲間はその墓の周囲にあり、これはみな殺された者、つるぎに倒れた者、生ける者の地に恐れを起した者である。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="エゼキエル書 32:18; エゼキエル書 26:20; エレミヤ書 49:34–39"> その所にエラムがおり、その民衆は皆、その墓の周囲におる。彼らはみな殺された者、つるぎに倒れた者、割礼を受けないで、下の国に下った者、生ける者の地に、恐れを起した者で、穴に下る者と共に、恥を負うのである。</span>
<span className="v" id="v25" data-v="25" data-xref="詩篇 139:8; 歴代志上 10:4; サムエル記下 1:20"> 彼らはそのすべての民衆と共に、殺された者の中に床を置き、その墓はこれを囲む。これは皆、割礼を受けない者、つるぎに殺された者、生ける者の地に恐れを起した者で、穴に下る者と共に恥を負う。彼らは殺された者の中に置かれている。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="エゼキエル書 27:13; 創世記 10:2; エゼキエル書 38:2–3"> その所にメセクとトバル、およびすべての民衆がおる。その墓はこれを囲む。彼らは皆、割礼を受けない者で、つるぎで殺された者である。生ける者の地に恐れを起したからである。</span>
<span className="v" id="v27" data-v="27" data-xref="イザヤ書 14:18–19; ヨブ記 3:13–15; エゼキエル書 32:21"> 彼らは昔の倒れた勇士と共に伏さない。これらの勇士は、武具を持って陰府に下り、つるぎをまくらとし、その盾は骨の上にある。これは勇士の恐れが、生ける者の地にあったからである。</span>
<span className="v" id="v28" data-v="28" data-xref="ダニエル書 2:34–35"> あなたは割礼を受けない者のうちに、つるぎで殺された者と共に横たわる。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="エレミヤ書 49:7–22; マラキ書 1:3–4; オバデヤ書 1:1–9"> その所にエドムとその王たちと、そのすべての君たちがおる。彼らはその力を持つにもかかわらず、かのつるぎで殺された者と共に横たえられ、割礼を受けない者および穴に下る者と共に伏している。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="エゼキエル書 38:6; エゼキエル書 39:2; エゼキエル書 28:21"> その所に北の君たち、およびシドンびとが皆おる。彼らは自分の力によって恐れを起したので、殺された者と共に恥を受けて、下って行った者である。彼らはつるぎで殺された者と共に、割礼を受けずに伏し、穴に下る者と共に恥を負う。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="エゼキエル書 31:16; エゼキエル書 14:22; 哀歌 2:13"> パロは彼らを見る時、そのすべての民衆について慰められる。パロとそのすべての軍勢とは、つるぎで殺されると、主なる神は言われる。</span>
<span className="v" id="v32" data-v="32" data-xref="エゼキエル書 32:27; 創世記 35:5; コリント人への第二の手紙 5:11"> 彼は生ける者の国に恐れを広げた。それゆえ、パロとすべての民衆とは、割礼を受けない者のうちにあって、つるぎで殺された者と共に伏すと、主なる神は言われる」。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 主の言葉がわたしに臨んだ、</span>
<span className="v" id="v2" data-v="2" data-xref="エレミヤ書 31:29–30; 哀歌 5:7; エゼキエル書 37:11"> 「あなたがたがイスラエルの地について、このことわざを用い、『父たちが、酢いぶどうを食べたので子供たちの歯がうく』というのはどんなわけか。</span>
<span className="v" id="v3" data-v="3" data-xref="エゼキエル書 18:19–20; エゼキエル書 33:11–20; エゼキエル書 18:30"> 主なる神は言われる、わたしは生きている、あなたがたは再びイスラエルでこのことわざを用いることはない。</span>
<span className="v" id="v4" data-v="4" data-xref="エゼキエル書 18:20; ローマ人への手紙 6:23; 民数記 16:22"> 見よ、すべての魂はわたしのものである。父の魂も子の魂もわたしのものである。罪を犯した魂は必ず死ぬ。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="エゼキエル書 33:14; ヨハネの第一の手紙 3:7; 箴言 21:3"> 人がもし正しくあって、公道と正義とを行い、</span>
<span className="v" id="v6" data-v="6" data-xref="エゼキエル書 18:15; 申命記 4:19; エゼキエル書 6:13"> 山の上で食事をせず、また目をあげてイスラエルの家の偶像を仰がず、隣り人の妻を犯さず、汚れの時にある女に近づかず、</span>
<span className="v" id="v7" data-v="7" data-xref="エゼキエル書 18:16; 出エジプト記 22:26; エゼキエル書 18:12"> だれをもしえたげず、質物を返し、決して奪わず、食物を飢えた者に与え、裸の者に衣服を着せ、</span>
<span className="v" id="v8" data-v="8" data-xref="出エジプト記 22:25; ゼカリヤ書 8:16; 申命記 23:19–20"> 利息や高利をとって貸さず、手をひいて悪を行わず、人と人との間に真実のさばきを行い、</span>
<span className="v" id="v9" data-v="9" data-xref="エゼキエル書 20:11; ハバクク書 2:4; アモス書 5:4"> わたしの定めに歩み、わたしのおきてを忠実に守るならば、彼は正しい人である。彼は必ず生きることができると、主なる神は言われる。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="出エジプト記 21:12; ヨハネの第一の手紙 3:12; ヨハネによる福音書 18:40"> しかし彼が子を生み、その子が荒い者で、人の血を流し、これらの義務の一つをも行わず、</span>
<span className="v" id="v11" data-v="11" data-xref="ヨハネの黙示録 22:14; マタイによる福音書 7:21–27; 列王紀上 13:8"> かえって山の上で食事をし、隣り人の妻を犯し、</span>
<span className="v" id="v12" data-v="12" data-xref="エゼキエル書 8:17; エゼキエル書 8:6; 列王紀下 21:11"> 乏しい者や貧しい者をしえたげ、物を奪い、質物を返さず、目をあげて偶像を仰ぎ、憎むべき事をおこない、</span>
<span className="v" id="v13" data-v="13" data-xref="出エジプト記 22:25; レビ記 20:9; エゼキエル書 3:18"> 利息や高利をとって貸すならば、その子は生きるであろうか。彼は生きることはできない。彼はこれらの憎むべき事をしたので、必ず死に、その血は彼自身に帰する。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="歴代志下 34:21; 箴言 23:24; エレミヤ書 8:6"> しかし彼が子を生み、その子が父の行ったすべての罪を見て、恐れ、そのようなことを行わず、</span>
<span className="v" id="v15" data-v="15" data-xref="エゼキエル書 18:6–7; エゼキエル書 18:11–13"> 山の上で食事せず、目をあげてイスラエルの家の偶像を仰がず、隣り人の妻を犯さず、</span>
<span className="v" id="v16" data-v="16" data-xref="エゼキエル書 18:7; イザヤ書 58:7–10; ヨブ記 22:7"> だれをもしえたげず、質物をひき留めず、物を奪わず、かえって自分の食物を飢えた者に与え、裸の者に衣服を着せ、</span>
<span className="v" id="v17" data-v="17" data-xref="エゼキエル書 18:8–9; マタイによる福音書 18:27–35; エゼキエル書 18:13"> その手をひいて悪を行わず、利息や高利をとらず、わたしのおきてを行い、わたしの定めに歩むならば、彼はその父の悪のために死なず、必ず生きる。</span>
<span className="v" id="v18" data-v="18" data-xref="エゼキエル書 3:18; エゼキエル書 18:26; エゼキエル書 18:24"> しかしその父は人をかすめ、その兄弟の物を奪い、その民の中で良くない事を行ったゆえ、見よ、彼はその悪のために死ぬ。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="出エジプト記 20:5; ゼカリヤ書 1:3–6; 申命記 5:9"> しかしあなたがたは、『なぜ、子は父の悪を負わないのか』と言う。子は公道と正義とを行い、わたしのすべての定めを守っておこなったので、必ず生きるのである。</span>
<span className="v" id="v20" data-v="20" data-xref="申命記 24:16; 列王紀下 14:6; エゼキエル書 18:4"> 罪を犯す魂は死ぬ。子は父の悪を負わない。父は子の悪を負わない。義人の義はその人に帰し、悪人の悪はその人に帰する。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="エゼキエル書 18:27–28; テトスヘの手紙 2:11–14; エゼキエル書 33:19"> しかし、悪人がもしその行ったもろもろの罪を離れ、わたしのすべての定めを守り、公道と正義とを行うならば、彼は必ず生きる。死ぬことはない。</span>
<span className="v" id="v22" data-v="22" data-xref="ミカ書 7:19; エゼキエル書 33:16; イザヤ書 43:25"> その犯したもろもろのとがは、彼に対して覚えられない。彼はそのなした正しい事のために生きる。</span>
<span className="v" id="v23" data-v="23" data-xref="エゼキエル書 33:11; テモテヘの第一の手紙 2:4; ペテロの第二の手紙 3:9"> 主なる神は言われる、わたしは悪人の死を好むであろうか。むしろ彼がそのおこないを離れて生きることを好んでいるではないか。</span>
<span className="v" id="v24" data-v="24" data-xref="エゼキエル書 33:18; 箴言 21:16; ヨハネの第二の手紙 1:8"> しかし義人がもしその義を離れて悪を行い、悪人のなすもろもろの憎むべき事を行うならば、生きるであろうか。彼が行ったもろもろの正しい事は覚えられない。彼はその犯したとがと、その犯した罪とのために死ぬ。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="エゼキエル書 33:17; マラキ書 3:13–15; マラキ書 2:17"> しかしあなたがたは、『主のおこないは正しくない』と言う。イスラエルの家よ、聞け。わたしのおこないは正しくないのか。正しくないのは、あなたがたのおこないではないか。</span>
<span className="v" id="v26" data-v="26"> 義人がその義を離れて悪を行い、そのために死ぬならば、彼は自分の行った悪のために死ぬのである。</span>
<span className="v" id="v27" data-v="27" data-xref="エゼキエル書 18:21; イザヤ書 1:18; イザヤ書 55:7"> しかし悪人がその行った悪を離れて、公道と正義とを行うならば、彼は自分の命を救うことができる。</span>
<span className="v" id="v28" data-v="28" data-xref="申命記 32:29; ルカによる福音書 15:17–18; ヤコブの手紙 2:10–12"> 彼は省みて、その犯したすべてのとがを離れたのだから必ず生きる。死ぬことはない。</span>
<span className="v" id="v29" data-v="29" data-xref="エゼキエル書 18:25; 箴言 19:3; エゼキエル書 18:2"> しかしイスラエルの家は『主のおこないは正しくない』と言う。イスラエルの家よ、わたしのおこないは、はたして正しくないのか。正しくないのは、あなたがたのおこないではないか。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="エゼキエル書 18:21; マタイによる福音書 16:27; マタイによる福音書 3:2"> それゆえ、イスラエルの家よ、わたしはあなたがたを、おのおのそのおこないに従ってさばくと、主なる神は言われる。悔い改めて、あなたがたのすべてのとがを離れよ。さもないと悪はあなたがたを滅ぼす。</span>
<span className="v" id="v31" data-v="31" data-xref="詩篇 51:10; エゼキエル書 36:26; エゼキエル書 11:19"> あなたがたがわたしに対しておこなったすべてのとがを捨て去り、新しい心と、新しい霊とを得よ。イスラエルの家よ、あなたがたはどうして死んでよかろうか。</span>
<span className="v" id="v32" data-v="32" data-xref="ペテロの第二の手紙 3:9; エゼキエル書 18:23; エゼキエル書 33:11"> わたしは何人との死をも喜ばないのであると、主なる神は言われる。それゆえ、あなたがたは翻って生きよ」。</span>
</div>

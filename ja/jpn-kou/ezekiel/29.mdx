<span className="v" id="v1" data-v="1" data-xref="エゼキエル書 29:17; エゼキエル書 26:1; エゼキエル書 20:1"> 第十年の十月十二日に、主の言葉がわたしに臨んだ、</span>
<span className="v" id="v2" data-v="2" data-xref="エゼキエル書 6:2; エレミヤ書 44:30; エレミヤ書 46:2–16"> 「人の子よ、あなたの顔をエジプトの王パロに向け、彼とエジプト全国に対して預言し、</span>
<span className="v" id="v3" data-v="3" data-xref="エゼキエル書 32:2; イザヤ書 27:1; エレミヤ書 44:30"> 語って言え。主なる神はこう言われる、<br /><span className="pl pl-1">エジプトの王パロよ、</span><br /><span className="pl pl-1">見よ、わたしはあなたの敵となる。</span><br /><span className="pl pl-1">あなたはその川の中に伏す大いなる龍で、</span><br /><span className="pl pl-1">『ナイル川はわたしのもの、</span><br /><span className="pl pl-1">わたしがこれを造った』と言う。</span></span>
<span className="v" id="v4" data-v="4" data-xref="列王紀下 19:28; エゼキエル書 38:4; アモス書 4:2"> <span className="pl pl-1">わたしは、かぎをあなたのあごにかけ、</span><br /><span className="pl pl-1">あなたの川の魚を、あなたのうろこにつかせ、</span><br /><span className="pl pl-1">あなたと、あなたのうろこについている</span><br /><span className="pl pl-1">もろもろの魚を、あなたの川から引きあげ、</span></span>
<span className="v" id="v5" data-v="5" data-xref="エレミヤ書 34:20; エゼキエル書 32:4–6; エレミヤ書 8:2"> <span className="pl pl-1">あなたとあなたの川のもろもろの魚を、</span><br /><span className="pl pl-1">荒野に投げ捨てる。</span><br /><span className="pl pl-1">あなたは野の面に倒れ、</span><br /><span className="pl pl-1">あなたを取り集める者も、葬る者もない。</span><br /><span className="pl pl-1">わたしはあなたを</span><br /><span className="pl pl-1">地の獣と空の鳥のえじきとして与える。</span></span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="列王紀下 18:21; イザヤ書 36:6; 出エジプト記 9:14"> そしてエジプトのすべての住民はわたしが主であることを知る。あなたはイスラエルの家に対して葦のつえであった。</span>
<span className="v" id="v7" data-v="7" data-xref="イザヤ書 36:6; エゼキエル書 17:15–17; エレミヤ書 17:5–6"> 彼らがあなたを手にとる時、あなたは折れ、彼らの肩はことごとく裂ける。彼らがまたあなたに寄りかかる時、あなたは破れ、彼らの腰をことごとく震えさせる。</span>
<span className="v" id="v8" data-v="8" data-xref="エゼキエル書 14:17; エゼキエル書 30:10; エゼキエル書 29:19–20"> それゆえ、主なる神はこう言われる、見よ、わたしはつるぎをあなたに持ってきて、人と獣とをあなたのうちから断つ。</span>
<span className="v" id="v9" data-v="9" data-xref="エゼキエル書 29:3; 箴言 16:18; エゼキエル書 29:10–12"> エジプトの地は荒れて、むなしくなる。そして彼はわたしが主であることを知る。<br />あなたは『ナイル川はわたしのもの、わたしがこれを造った』と言っているゆえに、</span>
<span className="v" id="v10" data-v="10" data-xref="エゼキエル書 30:12; エゼキエル書 30:6–9; 出エジプト記 14:2"> 見よ、わたしはあなたとあなたの川々の敵となって、エジプトの地をミグドルからスエネまで、エチオピヤの境に至るまで、ことごとく荒し、むなしくする。</span>
<span className="v" id="v11" data-v="11" data-xref="エゼキエル書 32:13; エレミヤ書 43:11–12; エゼキエル書 30:10–13"> 人の足はこれを渡らず、獣の足もこれを渡らない。四十年の間、ここに住む者はない。</span>
<span className="v" id="v12" data-v="12" data-xref="エレミヤ書 46:19; エゼキエル書 30:7; エゼキエル書 30:23"> わたしはエジプトの地を荒して、荒れた国々の中に置き、その町々は荒れて、四十年のあいだ荒れた町々の中にある。わたしはエジプトびとを、もろもろの国民の中に散らし、もろもろの国の中に散らす。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="エレミヤ書 46:26; イザヤ書 19:22"> 主なる神はこう言われる、四十年の後、わたしはエジプトびとを、その散らされたもろもろの民の中から集める。</span>
<span className="v" id="v14" data-v="14" data-xref="エゼキエル書 30:14; イザヤ書 11:11; エレミヤ書 44:1"> すなわちエジプトの運命をもとに返し、彼らをその生れた地であるパテロスの地に帰らせる。その所で彼らは卑しい国となる。</span>
<span className="v" id="v15" data-v="15" data-xref="ゼカリヤ書 10:11; エゼキエル書 30:13; エゼキエル書 17:14"> これはもろもろの国よりも卑しくなり、再びもろもろの国民の上に出ることができない。わたしは彼らを小さくするゆえ、再びもろもろの国民を治めることはない。</span>
<span className="v" id="v16" data-v="16" data-xref="ホセア書 8:13; イザヤ書 20:5; エゼキエル書 29:6–7"> これはイスラエルが助けを求める時、その罪を思い出して、再びイスラエルの家の頼みとはならない。こうして彼らは、わたしが主なる神であることを知る」。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="エゼキエル書 29:1; エゼキエル書 1:2; エゼキエル書 24:1"> 第二十七年の一月一日に、主の言葉がわたしに臨んだ、</span>
<span className="v" id="v18" data-v="18" data-xref="エレミヤ書 27:6; エレミヤ書 25:9; エゼキエル書 26:7–12"> 「人の子よ、バビロンの王ネブカデレザルは、その軍勢をツロに対して大いに働かせた。頭は皆はげ、肩はみな破れた。しかし彼もその軍勢も、ツロに対してなしたその働きのために、なんの報いをも得なかった。</span>
<span className="v" id="v19" data-v="19" data-xref="エゼキエル書 30:24–25; エレミヤ書 43:10–13; エゼキエル書 32:11"> それゆえ、主なる神はこう言われる、見よ、わたしはバビロンの王ネブカデレザルに、エジプトの地を与える。彼はその財宝を取り、物をかすめ、物を奪い、それをその軍勢に与えて報いとする。</span>
<span className="v" id="v20" data-v="20" data-xref="エレミヤ書 25:9; イザヤ書 10:6–7; イザヤ書 45:1–3"> 彼の働いた報酬として、わたしはエジプトの地を彼に与える。彼らはわたしのために、これをしたからであると、主なる神は言われる。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="サムエル記上 2:10; ルカによる福音書 21:15; 詩篇 132:17"> その日、わたしはイスラエルの家に、一つの角を生じさせ、あなたの口を彼らのうちに開かせる。そして彼らはわたしが主であることを知る」。</span>

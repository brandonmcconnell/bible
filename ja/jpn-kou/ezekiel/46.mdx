<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="イザヤ書 66:23; エゼキエル書 44:1–2; 出エジプト記 20:9"> 主なる神は、こう言われる、内庭にある東向きの門は、働きをする六日の間は閉じ、安息日にはこれを開き、またついたちにはこれを開け。</span>
<span className="v" id="v2" data-v="2" data-xref="エゼキエル書 44:3; エゼキエル書 46:8; 歴代志上 29:10–12"> 君たる者は、外から門の廊をとおってはいり、門の柱のかたわらに立て。そのとき祭司たちは、燔祭と酬恩祭とをささげ、彼は門の敷居で、礼拝して出て行くのである。しかし門は夕暮まで閉じてはならない。</span>
<span className="v" id="v3" data-v="3" data-xref="ルカによる福音書 1:10; ヨハネによる福音書 10:9; ヘブル人への手紙 10:19–22"> 国の民は安息日と、ついたちとに、その門の入口で主の前に礼拝をせよ。</span>
<span className="v" id="v4" data-v="4" data-xref="エゼキエル書 45:17; 民数記 28:9–10"> 君たる者が、安息日に主にささげる燔祭は、六頭の無傷の小羊と、一頭の無傷の雄羊とである。</span>
<span className="v" id="v5" data-v="5" data-xref="エゼキエル書 45:24; エゼキエル書 46:7; 申命記 16:17"> また素祭は雄羊のために麦粉一エパ、小羊のための素祭は、その人のささげうる程度とし、麦粉一エパに油一ヒンを加えよ。</span>
<span className="v" id="v6" data-v="6" data-xref="エゼキエル書 46:1"> ついたちには無傷の雄牛の子一頭、六頭の小羊および一頭の雄羊をささげよ。これらはすべて無傷のものでなければならない。</span>
<span className="v" id="v7" data-v="7" data-xref="エゼキエル書 46:5"> 素祭は雄牛のために麦粉一エパ、雄羊のために麦粉一エパ、小羊のためには、その人のささげうる程度のものを供えよ。また麦粉一エパに油一ヒンを加えよ。</span>
<span className="v" id="v8" data-v="8" data-xref="エゼキエル書 46:2; エゼキエル書 44:1–3; コロサイ人への手紙 1:18"> 君たる者がはいる時は門の廊の道からはいり、またその道から出よ。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="申命記 16:16; 出エジプト記 23:14–17; ペテロの第二の手紙 2:20–21"> 国の民が、祝い日に主の前に出る時、礼拝のため、北の門の道からはいる者は、南の門の道から出て行き、南の門の道からはいる者は、北の門の道から出て行け。そのはいった門の道からは、帰ってはならない。まっすぐに進んで、出て行かなければならない。</span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 42:4; 歴代志上 29:20; 歴代志上 29:22"> 彼らがはいる時、君たる者は、彼らと共にはいり、彼らが出る時、彼も出なければならない。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="エゼキエル書 46:5; エゼキエル書 46:7; 民数記 15:1–41"> 祭日と祝い日には、素祭として、若い雄牛のために麦粉一エパ、雄羊のために麦粉一エパ、小羊のためには、その人のささげうる程度のものを供え、麦粉一エパには油一ヒンを加えよ。</span>
<span className="v" id="v12" data-v="12" data-xref="エゼキエル書 46:1–2; エゼキエル書 45:17; エゼキエル書 44:3"> また君たる者が、心からの供え物として、燔祭または酬恩祭を主にささげる時は、彼のために東に面した門を開け。彼は安息日に行うように、その燔祭と酬恩祭を供え、そして退出する。その退出の後、門は閉ざされる。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="イザヤ書 50:4; ヨハネによる福音書 1:29; 出エジプト記 12:5"> 彼は日ごとに一歳の無傷の小羊を燔祭として、主にささげなければならない。すなわち朝ごとに、これをささげなければならない。</span>
<span className="v" id="v14" data-v="14" data-xref="民数記 28:5"> 彼は朝ごとに、素祭をこれに添えてささげなければならない。すなわち麦粉一エパの六分の一に、これを潤す油一ヒンの三分の一を、素祭として主にささげなければならない。これは常燔祭のおきてである。</span>
<span className="v" id="v15" data-v="15" data-xref="ヘブル人への手紙 10:1–10; 民数記 28:6; 出エジプト記 29:42"> すなわち朝ごとに常燔祭として、小羊と素祭と油とをささげなければならない。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="歴代志下 21:3; ガラテヤ人への手紙 4:7; 創世記 25:5–6"> 主なる神は、こう言われる、君たる者が、もしその嗣業から、その子のひとりに財産を与える時は、それはその子らの嗣業の所有となる。</span>
<span className="v" id="v17" data-v="17" data-xref="レビ記 25:10; ルカによる福音書 19:25–26; ガラテヤ人への手紙 4:30–31"> しかし彼がその奴隷のひとりに、嗣業の一部分を与える時は、それは彼の解放の年まで、その人に属していて、その後は君たる人に帰る。彼の嗣業は、ただその子らにだけ伝わるべきである。</span>
<span className="v" id="v18" data-v="18" data-xref="エゼキエル書 45:8; 列王紀上 21:19; エゼキエル書 22:27"> 君たる者はその民の嗣業を取って、その財産を継がせないようにしてはならない。彼はただ、自分の財産のうちから、その子らにその嗣業を、与えなければならない。これはわが民のひとりでも、その財産を失わないためである」。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="エゼキエル書 42:9; エゼキエル書 44:4–5; エゼキエル書 40:44–46"> こうして彼はわたしを連れて、門のかたわらの入口から、北向きの祭司の聖なる室に、はいらせた。見ると、西の奥の方に一つの場所があった。</span>
<span className="v" id="v20" data-v="20" data-xref="歴代志下 35:13; エゼキエル書 44:29; エゼキエル書 44:19"> 彼はわたしに言った、「これは祭司たちが愆祭および罪祭のものを煮、素祭のものを焼く所である。これは外庭にそれらを携え出て、聖なるべきことを、民にうつさないためである」。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21"> 彼はまたわたしを外庭に連れ出し、庭の四すみを通らせた。見よ、庭のこのすみにも庭があり、また庭のかのすみにも庭があった。</span>
<span className="v" id="v22" data-v="22"> すなわち庭の四すみに小さい庭があり、長さ四十キュビト、幅三十キュビトで、四つとも同じ大きさである。</span>
<span className="v" id="v23" data-v="23"> その四つの小さい庭の内部の四方には、石の壁があり、周囲の壁の下に、物を煮る所が設けてあった。</span>
<span className="v" id="v24" data-v="24" data-xref="エゼキエル書 46:20; ヨハネによる福音書 21:15–17; ペテロの第一の手紙 5:2"> 彼はわたしに言った、「これらは宮の仕え人たちが、民のささげる犠牲のものを煮る台所である」。</span>
</div>

<span className="v" id="v1" data-v="1"> 主の言葉がわたしに臨んだ、</span>
<span className="v" id="v2" data-v="2" data-xref="エゼキエル書 20:46; エゼキエル書 4:7; エゼキエル書 25:2"> 「人の子よ、あなたの顔をエルサレムに向け、あなたの言葉を聖所に向けてのべ、イスラエルの地に向かって預言し、</span>
<span className="v" id="v3" data-v="3" data-xref="ヨブ記 9:22; エレミヤ書 21:13; エゼキエル書 5:8"> イスラエルの地に言え。主はこう言われる、見よ、わたしはあなたを攻め、わたしのつるぎをさやから抜き、あなたのうちから、正しい者も悪しき者をも断ってしまう。</span>
<span className="v" id="v4" data-v="4" data-xref="エゼキエル書 20:47; エゼキエル書 7:2; エゼキエル書 6:11–14"> わたしがあなたのうちから、正しい者も悪しき者をも断つゆえに、わたしのつるぎはさやから抜け出て、南から北までのすべての肉なる者を攻める。</span>
<span className="v" id="v5" data-v="5" data-xref="エゼキエル書 21:30; ナホム書 1:9; サムエル記上 3:12"> すべて肉なる者は、主なるわたしが、そのつるぎをさやから抜き放ったことを知る。このつるぎは再びさやに納められない。</span>
<span className="v" id="v6" data-v="6" data-xref="イザヤ書 22:4; エゼキエル書 6:11; エレミヤ書 19:10"> それゆえ、人の子よ、嘆け、心砕けるまでに嘆き、彼らの目の前でいたく嘆け。</span>
<span className="v" id="v7" data-v="7" data-xref="エゼキエル書 7:17; エゼキエル書 7:26; イザヤ書 13:7"> 人があなたに向かって、『なぜ嘆くのか』と言うなら、『この知らせのためである。それが来れば人の心はみな溶け、手はみななえ、霊はみな弱り、ひざはみな水のようになる。見よ、それは来る、必ず成就する』と言え」と主なる神は言われる。</span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8"> 主の言葉がわたしに臨んだ、</span>
<span className="v" id="v9" data-v="9" data-xref="イザヤ書 34:5–6; エゼキエル書 21:28; エゼキエル書 21:3"> 「人の子よ、預言して言え、主はこう言われる、<br /><span className="pl pl-1">つるぎがある、</span><br /><span className="pl pl-1">とぎ、かつ、みがいたつるぎがある。</span></span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 110:5–6; エゼキエル書 20:47; エゼキエル書 21:25–27"> <span className="pl pl-1">殺すためにといであり、</span><br /><span className="pl pl-1">いなずまのようにきらめくためにみがいてある。</span><br />わたしたちは喜ぶことができるか。わが子よ、あなたはつえと、すべて木で作ったものとを軽んじた。</span>
<span className="v" id="v11" data-v="11" data-xref="エゼキエル書 21:19; エレミヤ書 25:33; エレミヤ書 51:20–23"> このつるぎは手にとるために、とがれ、殺す者の手に渡すために、とがれみがかれるのである。</span>
<span className="v" id="v12" data-v="12" data-xref="エゼキエル書 21:6; ヨエル書 1:13; エゼキエル書 21:14"> 人の子よ、叫び嘆け、このことはわが民に臨み、イスラエルのすべての君たちに臨むからである。彼らはわが民と共につるぎにわたされる。それゆえ、あなたのももを打て。</span>
<span className="v" id="v13" data-v="13" data-xref="エゼキエル書 21:10; コリント人への第二の手紙 8:2; エゼキエル書 21:25"> これはためしにすることではない。もしあなたが、つえをあざけったら、どういうことになろうか」と主なる神は言われる。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="列王紀下 24:1; 民数記 24:10; レビ記 26:24"> 「それゆえ、人の子よ、あなたは預言し、手を打ちならせ。つるぎを二度も三度も臨ませよ。これは人を殺すつるぎ、大いに殺すつるぎであって、彼らを囲むものである。</span>
<span className="v" id="v15" data-v="15" data-xref="エゼキエル書 21:10; エレミヤ書 17:27; エゼキエル書 21:22"> これがために彼らの心は溶け、多くの者がすべての門に倒れる。わたしはひらめくつるぎを彼らに送る。ああ、これはいなずまのようになり、人を殺すためにみがかれている。</span>
<span className="v" id="v16" data-v="16" data-xref="エゼキエル書 21:20; エゼキエル書 21:4; エゼキエル書 14:17"> あなたの刃の向かうところで、右に左になぎ倒せ。</span>
<span className="v" id="v17" data-v="17" data-xref="エゼキエル書 5:13; エゼキエル書 21:14; ゼカリヤ書 6:8"> わたしもまた、わたしの手を打ちならし、わたしの怒りをしずめると、主なるわたしは言った」。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18"> 主の言葉がまたわたしに臨んだ、</span>
<span className="v" id="v19" data-v="19" data-xref="エゼキエル書 4:1–3; エレミヤ書 1:10; エゼキエル書 5:1–17"> 「人の子よ、バビロンの王のつるぎが来るために、二つの道を備えよ。この二つの道は一つの国から出ている。あなたは道しるべを作り、これを町に向かう道のはじめに置け。</span>
<span className="v" id="v20" data-v="20" data-xref="アモス書 1:14; エレミヤ書 49:2; エゼキエル書 25:5"> あなたはまたアンモンの人々のラバと、ユダと、堅固な城の町エルサレムとにつるぎの来る道を設けよ。</span>
<span className="v" id="v21" data-v="21" data-xref="士師記 18:20; 箴言 16:33; 士師記 17:5"> バビロンの王は道の分れ目、二つの道のはじめに立って占いをし、矢をふり、テラピムに問い、肝を見る。</span>
<span className="v" id="v22" data-v="22" data-xref="エゼキエル書 4:2; エゼキエル書 26:9; エレミヤ書 51:14"> 彼の右にエルサレムのために占いが出る。すなわち口を開いて叫び、声をあげ、ときを作り、門に向かって城くずしを設け、塁を築き、雲悌を建てよと言う。</span>
<span className="v" id="v23" data-v="23" data-xref="民数記 5:15; エゼキエル書 21:24; エゼキエル書 29:16"> しかしこれは彼らの目には偽りの占いと思われ、彼らは堅き誓いをなした。しかし彼は、彼らを捕えることによって、罪を思い出させる。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="ホセア書 4:2; ミカ書 3:10–12; エレミヤ書 3:2"> それゆえ、主なる神はこう言われる、あなたがたの罪は覚えられ、その反逆は現れ、その罪はすべてのわざに現れる。このようにあなたがたは、すでに覚えられているから、彼らの手に捕えられる。</span>
<span className="v" id="v25" data-v="25" data-xref="エゼキエル書 35:5; エゼキエル書 21:29; エゼキエル書 17:19"> 汚れた悪人であるイスラエルの君よ、あなたの終りの刑罰の時であるその日が来る。</span>
<span className="v" id="v26" data-v="26" data-xref="エゼキエル書 17:24; 詩篇 75:7; エレミヤ書 13:18"> 主なる神はこう言われる、かぶり物を脱ぎ、冠を取り離せ。すべてのものは、そのままには残らない。卑しい者は高くされ、高い者は卑しくされる。</span>
<span className="v" id="v27" data-v="27" data-xref="ミカ書 5:2; エレミヤ書 23:5–6; ゼカリヤ書 9:9"> ああ破滅、破滅、破滅、わたしはこれをこさせる。わたしが与える権威をもつ者が来る時まで、その跡形さえも残らない。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="エゼキエル書 21:20; エゼキエル書 21:9–10; ゼパニヤ書 2:8–10"> 人の子よ、預言して言え。主なる神はアンモンの人々と、そのあざけりについて、こう言われる、つるぎがある。このつるぎは殺すために抜かれ、いなずまのようにひかりきらめくようにとがれている。</span>
<span className="v" id="v29" data-v="29" data-xref="エゼキエル書 21:25; エゼキエル書 22:28; 詩篇 37:13"> 彼らがあなたに偽りの幻を示し、偽りを占ったゆえ、これは殺さるべき悪しき者の首の上に置かれる。彼らの終りの刑罰の時であるその日がきている。</span>
<span className="v" id="v30" data-v="30" data-xref="エゼキエル書 16:38; 創世記 15:14; エレミヤ書 47:6–7"> これをさやに納めよ、わたしはあなたの造られた所、あなたの生れた地であなたをさばく。</span>
<span className="v" id="v31" data-v="31" data-xref="ナホム書 1:6; エレミヤ書 6:22–23; エゼキエル書 14:19"> わたしの怒りをあなたに注ぎ、わたしの憤りの火をあなたに向けて燃やし、滅ぼすことに巧みな残忍な人の手にあなたを渡す。</span>
<span className="v" id="v32" data-v="32" data-xref="エゼキエル書 25:10; マラキ書 4:1; エゼキエル書 20:47–48"> あなたは火のための、たきぎとなり、あなたの血は国の中に流され、覚えられることはない、主なるわたしが言う」。</span>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1"> 主の言葉がわたしに臨んだ、</span>
<span className="v" id="v2" data-v="2" data-xref="マルコによる福音書 4:12; エレミヤ書 5:21; 詩篇 78:40"> 「人の子よ、あなたは反逆の家の中にいる。彼らは見る目があるが見ず、聞く耳があるが聞かず、彼らは反逆の家である。</span>
<span className="v" id="v3" data-v="3" data-xref="エレミヤ書 36:3; テモテヘの第二の手紙 2:25; エレミヤ書 26:3"> それゆえ、人の子よ、捕囚の荷物を整え、彼らの目の前で昼のうちに移れ、彼らの目の前であなたの所から他の所に移れ。彼らは反逆の家であるが、あるいは彼らは顧みるところがあろう。</span>
<span className="v" id="v4" data-v="4" data-xref="エレミヤ書 39:4; エゼキエル書 12:12; 列王紀下 25:4"> あなたは、捕囚の荷物のようなあなたの荷物を、彼らの目の前で昼のうちに持ち出せ。そして捕囚に行くべき人々のように、彼らの目の前で夕べのうちに出て行け。</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀下 25:4; エレミヤ書 39:2–4"> すなわち彼らの目の前で壁に穴をあけ、そこから出て行け。</span>
<span className="v" id="v6" data-v="6" data-xref="エゼキエル書 4:3; イザヤ書 8:18; エゼキエル書 24:24"> あなたは彼らの目の前でその荷物を肩に負い、やみのうちにそれを運び出せ。あなたの顔をおおって地を見るな。わたしはあなたをしるしとなして、イスラエルの家に示すのだ」。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="エゼキエル書 24:18; エゼキエル書 37:10; エゼキエル書 37:7"> そこでわたしは命じられたようにし、捕囚の荷物のような荷物を昼のうちに持ち出し、夕べにはわたしの手で壁に穴をあけ、やみのうちに彼らの目の前で、これを肩に負って運び出した。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8"> 次の朝、主の言葉がわたしに臨んだ、</span>
<span className="v" id="v9" data-v="9" data-xref="エゼキエル書 24:19; エゼキエル書 17:12; エゼキエル書 20:49"> 「人の子よ、反逆の家であるイスラエルの家は、あなたに向かって、『何をしているのか』と言わなかったか。</span>
<span className="v" id="v10" data-v="10" data-xref="列王紀下 9:25; イザヤ書 13:1; エレミヤ書 24:8"> あなたは彼らに言いなさい、『主なる神はこう言われる、この託宣はエルサレムの君、およびその中にあるイスラエルの全家にかかわるものである』と。</span>
<span className="v" id="v11" data-v="11" data-xref="エレミヤ書 52:15; エレミヤ書 15:2; エレミヤ書 52:28–30"> また言いなさい、『わたしはあなたがたのしるしである。わたしがしたとおりに彼らもされる。彼らはとりこにされて移される』と。</span>
<span className="v" id="v12" data-v="12" data-xref="列王紀下 25:4; エレミヤ書 39:4; エゼキエル書 12:6"> 彼らのうちの君は、やみのうちにその荷物を肩に載せて出て行く。彼は壁に穴をあけて、そこから出て行く。彼は顔をおおって、自分の目でこの地を見ない。</span>
<span className="v" id="v13" data-v="13" data-xref="エレミヤ書 39:7; ホセア書 7:12; エゼキエル書 17:20"> わたしはわたしの網を彼の上に打ちかける。彼はわたしのわなにかかる。わたしは彼をカルデヤびとの地のバビロンに引いて行く。しかし彼はそれを見ないで、そこで死ぬであろう。</span>
<span className="v" id="v14" data-v="14" data-xref="エゼキエル書 5:2; 列王紀下 25:4–5; エゼキエル書 17:21"> またすべて彼の周囲にいて彼を助ける者および彼の軍隊を、わたしは四方に散らし、つるぎを抜いてそのあとを追う。</span>
<span className="v" id="v15" data-v="15" data-xref="エゼキエル書 6:7; エゼキエル書 12:16; エゼキエル書 12:20"> わたしが彼らを諸国民の中に散らし、国々にまき散らすとき、彼らはわたしが主であることを知る。</span>
<span className="v" id="v16" data-v="16" data-xref="エレミヤ書 22:8–9; エゼキエル書 14:22–23; エゼキエル書 6:8–10"> ただし、わたしは彼らのうちに、わずかの者を残して、つるぎと、ききんと、疫病を免れさせ、彼らがおこなったもろもろの憎むべきことを、彼らが行く国びとの中に告白させよう。そして彼らはわたしが主であることを知るようになる」。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17"> 主の言葉がまたわたしに臨んだ、</span>
<span className="v" id="v18" data-v="18" data-xref="哀歌 5:9; 詩篇 80:5; ヨブ記 3:24"> 「人の子よ、震えてあなたのパンを食べ、おののきと恐れとをもって水を飲め。</span>
<span className="v" id="v19" data-v="19" data-xref="ゼカリヤ書 7:14; エゼキエル書 6:6–7; エゼキエル書 6:14"> そしてこの地の民について言え、主なる神はイスラエルの地のエルサレムの民についてこう言われる、彼らは恐れをもってそのパンを食べ、驚きをもってその水を飲むようになる。これはその地が、すべてその中に住む者の暴虐のために衰え、荒れ地となるからである。</span>
<span className="v" id="v20" data-v="20" data-xref="エレミヤ書 4:7; イザヤ書 7:23–24; エレミヤ書 25:9"> 人の住んでいた町々は荒れはて、地は荒塚となる。そしてあなたがたは、わたしが主であることを知るようになる」。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21"> 主の言葉がわたしに臨んだ、</span>
<span className="v" id="v22" data-v="22" data-xref="エゼキエル書 18:2–3; エゼキエル書 11:3; エゼキエル書 12:27"> 「人の子よ、イスラエルの地について、あなたがたが『日は延び、すべての幻はむなしくなった』という、このことわざはなんであるか。</span>
<span className="v" id="v23" data-v="23" data-xref="ヨエル書 2:1; エゼキエル書 7:5–7; ゼパニヤ書 1:14"> それゆえ、彼らに言え、『主なる神はこう言われる、わたしはこのことわざをやめさせ、彼らが再びイスラエルで、これをことわざとしないようにする』と。しかし、あなたは彼らに言え、『日とすべての幻の実現とは近づいた』と。</span>
<span className="v" id="v24" data-v="24" data-xref="エレミヤ書 14:13–16; エゼキエル書 13:23; ゼカリヤ書 13:2–4"> イスラエルの家のうちには、もはやむなしい幻も、偽りの占いもなくなる。</span>
<span className="v" id="v25" data-v="25" data-xref="ハバクク書 1:5; エゼキエル書 12:28; イザヤ書 55:11"> しかし主なるわたしは、わが語るべきことを語り、それは必ず成就する。決して延びることはない。ああ、反逆の家よ、あなたの日にわたしはこれを語り、これを成就すると、主なる神は言われる」。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26"> 主の言葉がまたわたしに臨んだ、</span>
<span className="v" id="v27" data-v="27" data-xref="ダニエル書 10:14; エゼキエル書 12:22; ペテロの第二の手紙 3:4"> 「人の子よ、見よ、イスラエルの家は言う、『彼の見る幻は、なお多くの日の後の事である。彼が預言することは遠い後の時のことである』と。</span>
<span className="v" id="v28" data-v="28" data-xref="エゼキエル書 12:23–25; マルコによる福音書 13:32–37; テサロニケ人への第一の手紙 5:2–3"> それゆえ、彼らに言え、主なる神はこう言われる、わたしの言葉はもはや延びない。わたしの語る言葉は成就すると、主なる神は言われる」。</span>
</div>

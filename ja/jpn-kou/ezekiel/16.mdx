<div className="bp">
<span className="v" id="v1" data-v="1"> 主の言葉が再びわたしに臨んだ、</span>
<span className="v" id="v2" data-v="2" data-xref="エゼキエル書 22:2; エゼキエル書 20:4; イザヤ書 58:1"> 「人の子よ、エルサレムにその憎むべき事どもを示して、</span>
<span className="v" id="v3" data-v="3" data-xref="エゼキエル書 16:45; イザヤ書 51:1–2; 申命記 20:17"> 言え。主なる神はエルサレムにこう言われる、あなたの起り、あなたの生れはカナンびとの地である。あなたの父はアモリびと、あなたの母はヘテびとである。</span>
<span className="v" id="v4" data-v="4" data-xref="ホセア書 2:3; 創世記 15:13; 出エジプト記 5:16–21"> あなたの生れについていえば、その生れた日に、へその緒は切られず、水で洗い清められず、塩でこすられず、また布で包まれなかった。</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 32:10; 創世記 21:10; 出エジプト記 1:22"> ひとりもあなたをあわれみ見る者なく、情をもってこれらのことの一つをも、あなたにしてやる者もなく、あなたの生れた日に、あなたはきらわれて、野原に捨てられた。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="エペソ人への手紙 2:4–5; ヨハネによる福音書 5:25; テトスヘの手紙 3:3–7"> わたしはあなたのかたわらを通り、あなたが血の中にころがりまわっているのを見た時、わたしは血の中にいるあなたに言った、『生きよ、</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 1:10; 出エジプト記 1:7; イザヤ書 62:3"> 野の木のように育て』と。すなわちあなたは成長して大きくなり、一人前の女になり、その乳ぶさは形が整い、髪は長くなったが、着物がなく、裸であった。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="ルツ記 3:9; エレミヤ書 2:2–3; ローマ人への手紙 5:8"> わたしは再びあなたのかたわらをとおって、あなたを見たが、見よ、あなたは愛せられる年齢に達していたので、わたしは着物のすそであなたをおおい、あなたの裸をかくし、そしてあなたに誓い、あなたと契約を結んだ。そしてあなたはわたしのものとなったと、主なる神は言われる。</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 23:5; ルツ記 3:3; ヨハネの第一の手紙 2:27"> そこでわたしは水であなたを洗い、あなたの血を洗い落して油を塗り、</span>
<span className="v" id="v10" data-v="10" data-xref="エゼキエル書 16:18; エゼキエル書 16:13; イザヤ書 61:10"> 縫い取りした着物を着せ、皮のくつをはかせ、細布をかぶらせ、絹のきれであなたをおおった。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 24:22; イザヤ書 3:19; 創世記 41:42"> また飾り物であなたを飾り、腕輪をあなたの手にはめ、鎖をあなたの首にかけ、</span>
<span className="v" id="v12" data-v="12" data-xref="イザヤ書 3:21; イザヤ書 28:5; エレミヤ書 13:18"> 鼻には鼻輪、耳には耳輪、頭には美しい冠を与えた。</span>
<span className="v" id="v13" data-v="13" data-xref="申命記 32:13–14; 詩篇 50:2; 列王紀上 4:21"> このようにあなたは金銀で飾られ、細布、絹、縫い取りの服をあなたの衣とし、麦粉と、蜜と、油とを食べた。あなたは非常に美しくなって王の地位に進み、</span>
<span className="v" id="v14" data-v="14" data-xref="列王紀上 10:24; 哀歌 2:15; コリント人への第一の手紙 4:7"> あなたの美しさのために、あなたの名声は国々に広まった。これはわたしが、あなたに施した飾りによって全うされたからであると、主なる神は言われる。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="イザヤ書 57:8; エレミヤ書 2:20; エゼキエル書 16:25"> ところが、あなたは自分の美しさをたのみ、自分の名声によって姦淫を行い、すべてかたわらを通る者と、ほしいままに姦淫を行った。</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀下 23:7; エゼキエル書 7:20; 歴代志下 28:24"> あなたは自分の衣をとって、自分のために、はなやかに色どった聖所を造り、その上で姦淫を行っている。こんなことはかつてなかったこと、またあってはならないことである。</span>
<span className="v" id="v17" data-v="17" data-xref="エゼキエル書 23:14–21; エレミヤ書 3:9; エゼキエル書 16:11"> あなたはわたしが与えた金銀の美しい飾りの品をとり、自分のために男の像を造って、これと姦淫を行った。</span>
<span className="v" id="v18" data-v="18"> また縫い取りのある自分の衣をとって彼らに着せ、わたしの油と香とをその前に供え、</span>
<span className="v" id="v19" data-v="19" data-xref="エゼキエル書 16:13; ホセア書 2:8–13; 創世記 8:21"> またわたしがあなたに与えたパン、わたしがあなたを養うための麦粉、油および蜜を、こうばしきかおりとして彼らの前に供えたと、主なる神は言われる。</span>
<span className="v" id="v20" data-v="20" data-xref="エゼキエル書 23:37; エゼキエル書 20:31; エレミヤ書 7:31"> あなたはまた、あなたがわたしに産んだむすこ、娘たちをとって、その像に供え、彼らに食わせた。このようなあなたの姦淫は小さい事であろうか。</span>
<span className="v" id="v21" data-v="21" data-xref="列王紀下 17:17; レビ記 18:21; 申命記 18:10"> あなたはわたしの子どもを殺し、火の中を通らせて彼らにささげた。</span>
<span className="v" id="v22" data-v="22" data-xref="エレミヤ書 2:2; ホセア書 11:1; エゼキエル書 16:43"> あなたがそのすべての憎むべきことや姦淫を行うに当って、あなたが衣もなく、裸で、血の中にころがりまわっていた自分の若き日のことを思わなかった。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="ヨハネの黙示録 12:12; エゼキエル書 2:10; エゼキエル書 24:6"> あなたがもろもろの悪を行った後、（あなたはわざわいだ、わざわいだと、主なる神は言われる）</span>
<span className="v" id="v24" data-v="24" data-xref="詩篇 78:58; エゼキエル書 16:39; エゼキエル書 16:31"> あなたは自分のために高楼を建て、広場、広場に台を造り、</span>
<span className="v" id="v25" data-v="25" data-xref="エゼキエル書 16:31; エレミヤ書 3:2; 創世記 38:21"> ちまた、ちまたのつじに台を造って、あなたの美しさを汚し、すべてかたわらを通る者に身をまかせて、大いに姦淫を行っている。</span>
<span className="v" id="v26" data-v="26" data-xref="エゼキエル書 23:19–21; エゼキエル書 20:7–8; エゼキエル書 8:10"> あなたはまた、かの肉欲的な隣りエジプトの人々と姦淫を行い、大いに姦淫を行って、わたしを怒らせた。</span>
<span className="v" id="v27" data-v="27" data-xref="イザヤ書 9:12; エゼキエル書 16:57; エゼキエル書 16:37"> それゆえ、わたしはわたしの手をあなたの上に伸べて、あなたの賜わる分を減らし、あなたの敵、すなわち、あなたのみだらな行為を恥じるペリシテびとの娘らの欲のままに、あなたを渡した。</span>
<span className="v" id="v28" data-v="28" data-xref="列王紀下 16:7; ホセア書 10:6; 列王紀下 16:10–18"> あなたは飽くことがないので、またアッスリヤの人々と姦淫を行ったが、彼らと姦淫を行っても、なお飽くことがなかった。</span>
<span className="v" id="v29" data-v="29" data-xref="列王紀下 21:9; 士師記 2:12–19; エゼキエル書 13:14–23"> あなたはまたカルデヤの商業地と大いに姦淫を行ったが、これと姦淫を行っても、なお飽くことがなかった。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="エレミヤ書 3:3; イザヤ書 1:3; イザヤ書 3:9"> 主なる神は言われる、あなたの心はどんなに恋いわずらうのか。あなたは、これらすべての事を行った。これはあつかましい姦淫のわざである。</span>
<span className="v" id="v31" data-v="31" data-xref="エゼキエル書 16:33–34; イザヤ書 52:3; エゼキエル書 16:39"> あなたは、ちまた、ちまたのつじに高楼を建て、広場、広場に台を設けたが、価をもらうことをあざけったので、遊女のようではなかった。</span>
<span className="v" id="v32" data-v="32" data-xref="エレミヤ書 2:28; エゼキエル書 23:37; エレミヤ書 2:25"> 自分の夫に替えて他人と通じる姦婦よ。</span>
<span className="v" id="v33" data-v="33" data-xref="イザヤ書 57:9; ホセア書 8:9–10; エゼキエル書 16:41"> 人はすべての遊女に物を与える。しかしあなたはすべての恋人に物を与え、彼らにまいないして、あなたと姦淫するために、四方からあなたの所にこさせる。</span>
<span className="v" id="v34" data-v="34"> このようにあなたは姦淫を行うに当って、他の女と違っている。すなわち、だれもあなたに姦淫をさせたのではない。あなたはかえって価を払い、相手はあなたに払わない。これがあなたの違うところである。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="ヨハネによる福音書 4:18; 列王紀上 22:19; ヨハネによる福音書 4:10"> それで遊女よ、主の言葉を聞け。</span>
<span className="v" id="v36" data-v="36" data-xref="エゼキエル書 23:10; エゼキエル書 24:13; ゼパニヤ書 3:1"> 主なる神はこう言われる、あなたがその恋人と姦淫して、あなたの恥じる所をあらわし、あなたの裸をあらわし、またすべての偶像と、あなたが彼らにささげたあなたの子どもらの血のゆえに、</span>
<span className="v" id="v37" data-v="37" data-xref="ホセア書 2:10; エレミヤ書 13:22; ホセア書 2:3"> 見よ、わたしはあなたと遊んだあなたのすべての恋人、およびすべてあなたが恋した者と、すべてあなたが憎んだ者とを集め、四方から彼らをあなたの所に集めて、あなたの裸を彼らにあらわす。彼らはあなたの裸を、ことごとく見る。</span>
<span className="v" id="v38" data-v="38" data-xref="レビ記 20:10; 創世記 9:6; ゼパニヤ書 1:17"> わたしは姦淫を行った女と、血を流した女がさばかれるように、あなたをさばき、憤りと、ねたみの血とを、あなたに注ぐ。</span>
<span className="v" id="v39" data-v="39" data-xref="エゼキエル書 23:26; ホセア書 2:3; エゼキエル書 16:24–25"> わたしはあなたを恋人の手に渡す。彼らはあなたの高楼を倒し、台をこわし、あなたの衣をはぎ取り、あなたの美しい飾りの品を奪い、あなたを衣服のない裸者にする。</span>
<span className="v" id="v40" data-v="40" data-xref="エゼキエル書 23:47; ハバクク書 1:6–10; ヨハネによる福音書 8:5–7"> 彼らは民衆をかり立ててあなたを攻め、石であなたを撃ち、つるぎであなたを切り、</span>
<span className="v" id="v41" data-v="41" data-xref="エゼキエル書 23:48; エレミヤ書 52:13; エレミヤ書 39:8"> 火であなたの家を焼き、多くの女たちの前で、あなたにさばきを行う。こうしてわたしはあなたに淫行をやめさせ、重ねて価を払わせないようにする。</span>
<span className="v" id="v42" data-v="42" data-xref="エゼキエル書 5:13; エゼキエル書 21:17; イザヤ書 40:1–2"> そしてあなたに対するわが憤りをしずめ、わがねたみをあなたから離し、わたしは心を安んじて、再び怒ることをしない。</span>
<span className="v" id="v43" data-v="43" data-xref="エゼキエル書 16:22; エゼキエル書 11:21; 詩篇 78:42"> またあなたはその若き日の事を覚えず、すべてこれらの事をもって、わたしを怒らせたから、見よ、わたしもあなたの行うところをあなたのこうべに報いると、主なる神は言われる。<br />あなたはもろもろの憎むべき事に加えて、このみだらな事をおこなったではないか。</span>
<span className="v" id="v44" data-v="44" data-xref="エゼキエル書 18:2–3; 詩篇 106:35–38; サムエル記上 24:13"> 見よ、すべてことわざを用いる者は、あなたについて、『この母にしてこの娘あり』という、ことわざを用いる。</span>
<span className="v" id="v45" data-v="45" data-xref="ゼカリヤ書 11:8; イザヤ書 1:4; エゼキエル書 23:37–39"> あなたは、その夫と子どもとを捨てたあなたの母の娘、またその夫と子どもとを捨てた姉妹を持っている。あなたの母はヘテびと、あなたの父はアモリびと、</span>
<span className="v" id="v46" data-v="46" data-xref="エゼキエル書 23:4; エゼキエル書 16:48–49; エゼキエル書 16:53–56"> あなたの姉はサマリヤ、サマリヤはその娘たちと共に、あなたの北に住み、あなたの妹はソドムで、その娘たちと共に、あなたの南に住んでいる。</span>
<span className="v" id="v47" data-v="47" data-xref="列王紀下 21:9; エゼキエル書 16:51; エゼキエル書 5:6–7"> あなたは彼らの道を歩まず、彼らの憎むべき事に従っていないが、しばらくすると、あなたのおこないは、彼らよりもさらに悪くなる。</span>
<span className="v" id="v48" data-v="48" data-xref="マタイによる福音書 10:15; ルカによる福音書 10:12; 使徒行伝 7:52"> 主なる神は言われる、わたしは生きている。あなたの妹ソドムとその娘たちは、あなたとあなたの娘たちがしたほどのことはしなかった。</span>
<span className="v" id="v49" data-v="49" data-xref="詩篇 138:6; エゼキエル書 28:2; 創世記 13:10"> 見よ、あなたの妹ソドムの罪はこれである。すなわち彼女と、その娘たちは高ぶり、食物に飽き、安泰に暮していたが、彼らは、乏しい者と貧しい者を助けなかった。</span>
<span className="v" id="v50" data-v="50" data-xref="創世記 19:24; 創世記 18:20; 創世記 19:5"> 彼らは高ぶり、わたしの前に憎むべき事をおこなったので、わたしはそれを見た時、彼らを除いた。</span>
<span className="v" id="v51" data-v="51" data-xref="エレミヤ書 3:8–11; ルカによる福音書 12:47–48; ローマ人への手紙 3:9–20"> サマリヤはあなたの半分も罪を犯さなかった。あなたは彼らよりも多く憎むべき事をおこない、あなたのおこなったもろもろの憎むべき事によって、あなたの姉妹を義と見せかけた。</span>
<span className="v" id="v52" data-v="52" data-xref="マタイによる福音書 7:1–5; エゼキエル書 36:15; エゼキエル書 16:56"> あなたはその姉妹を有利にさばいたことによって、あなたもまた自分のはずかしめを負わなければならない。それはあなたが彼らよりも、さらに憎むべきことをした罪によって、彼らはあなたよりも義とされるからである。それであなたも恥を受け、はずかしめを負わなければならない。それはあなたがその姉妹を義と見せかけたからである。</span>
</div>
<div className="bp">
<span className="v" id="v53" data-v="53" data-xref="エゼキエル書 29:14; エレミヤ書 12:16; エゼキエル書 39:25"> わたしは彼らの幸福をもとに返す。すなわちソドムとその娘たちの幸福、サマリヤとその娘たちの幸福、また彼らの中にいるあなたの幸福をもとに返す。</span>
<span className="v" id="v54" data-v="54" data-xref="エゼキエル書 14:22–23; エレミヤ書 2:26; エゼキエル書 36:31–32"> これはあなたに自分のはずかしめを負わせるため、またすべてあなたのなした事を恥じさせるためである。こうしてあなたは彼らの慰めとなる。</span>
<span className="v" id="v55" data-v="55" data-xref="エゼキエル書 36:11; マラキ書 3:4; エゼキエル書 16:53"> あなたの姉妹ソドムと、その娘たちとは、そのもとの所に帰り、サマリヤと、その娘たちとは、そのもとの所に帰り、あなたと、あなたの娘たちとは、そのもとの所に帰る。</span>
<span className="v" id="v56" data-v="56" data-xref="イザヤ書 65:5; ルカによる福音書 15:28–30; ゼパニヤ書 3:11"> あなたの高ぶりの日に、あなたの姉妹ソドムは、あなたの口に、ことわざとなったではなかったか。</span>
<span className="v" id="v57" data-v="57" data-xref="列王紀下 16:5–7; エゼキエル書 16:36–37; 歴代志下 28:5–6"> すなわちあなたの悪があらわされた時まで、そうではなかったか。しかし今はあなたも彼女と同様に、エドムの娘たちと、すべてその周囲の者、および四方からあなたをあざけるペリシテの娘たちのそしりとなった。</span>
<span className="v" id="v58" data-v="58" data-xref="エゼキエル書 23:49; 哀歌 5:7; 創世記 4:13"> あなたはあなたのみだらな行為と、あなたの憎むべき事のとがとを、身に負っていると主は言われる。</span>
</div>
<div className="bp">
<span className="v" id="v59" data-v="59" data-xref="イザヤ書 24:5; エゼキエル書 17:19; 申命記 29:25"> 主なる神はこう言われる、誓いを軽んじ、契約を破ったあなたには、あなたがしたように、わたしもあなたにする。</span>
<span className="v" id="v60" data-v="60" data-xref="ホセア書 2:19–20; ヘブル人への手紙 12:24; エゼキエル書 16:8"> しかしわたしはあなたの若き日に、あなたと結んだ契約を覚え、永遠の契約をあなたと立てる。</span>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出エジプト記 24:10; ヨハネの黙示録 4:2–3; ヨハネの黙示録 1:13"> 時にわたしは見ていたが、見よ、ケルビムの頭の上の大空に、サファイヤのようなものが王座の形をして、その上に現れた。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネの黙示録 8:5; エゼキエル書 10:16; エゼキエル書 1:13"> 彼は亜麻布を着たその人に言われた、「ケルビムの下の回る車の間にはいり、ケルビムの間から炭火をとってあなたの手に満たし、これを町中にまき散らせ」。<br />そして彼はわたしの目の前ではいった。</span>
<span className="v" id="v3" data-v="3" data-xref="エゼキエル書 43:4; エゼキエル書 9:3; エゼキエル書 8:16"> この人がはいった時、ケルビムは宮の南側に立っていた。また雲はその内庭を満たしていた。</span>
<span className="v" id="v4" data-v="4" data-xref="エゼキエル書 1:28; エゼキエル書 9:3; 出エジプト記 40:35"> 主の栄光はケルビムの上から宮の敷居の上にあがり、宮は雲で満ち、庭は主の栄光の輝きで満たされた。</span>
<span className="v" id="v5" data-v="5" data-xref="エゼキエル書 1:24; ヨブ記 40:9; 出エジプト記 19:16"> 時にケルビムの翼の音が大能の神が語られる声のように外庭にまで聞えた。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="エゼキエル書 10:2; 詩篇 99:1; 詩篇 80:1"> 彼が亜麻布を着ている人に、「回る車の間、ケルビムの間から火を取れ」。と命じた時、その人ははいって、輪のかたわらに立った。</span>
<span className="v" id="v7" data-v="7" data-xref="マタイによる福音書 13:41–42; エゼキエル書 1:13; エゼキエル書 41:23–26"> ひとりのケルブはその手をケルビムの間から伸べて、ケルビムの間にある火を取り、亜麻布を着た人の手に置いた。すると彼はこれを取って出て行った。</span>
<span className="v" id="v8" data-v="8" data-xref="エゼキエル書 1:8; エゼキエル書 10:21; イザヤ書 6:6"> ケルビムはその翼の下に人の手のような形のものを持っているように見えた。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="エゼキエル書 1:15–17; ダニエル書 10:6; ヨハネの黙示録 21:20"> わたしが見ていると、見よ、ケルビムのかたわらに四つの輪があり、一つの輪はひとりのケルブのかたわらに、他の輪は他のケルブのかたわらにあった。輪のさまは、光る貴かんらん石のようであった。</span>
<span className="v" id="v10" data-v="10" data-xref="エゼキエル書 1:16; 詩篇 36:6; 詩篇 104:24"> そのさまは四つとも同じ形で、あたかも輪の中に輪があるようであった。</span>
<span className="v" id="v11" data-v="11" data-xref="エゼキエル書 1:17; エゼキエル書 10:22; エゼキエル書 1:20"> その行く時は四方のどこへでも行く。その行く時は回らない。ただ先頭の輪の向くところに従い、その行く時は回ることをしない。</span>
<span className="v" id="v12" data-v="12" data-xref="エゼキエル書 1:18; ヨハネの黙示録 4:8; ヨハネの黙示録 4:6"> その輪縁、その輻、および輪には、まわりに目が満ちていた。―その輪は四つともこれを持っていた。</span>
<span className="v" id="v13" data-v="13"> その輪はわたしの聞いている所で、「回る輪」と呼ばれた。</span>
<span className="v" id="v14" data-v="14" data-xref="ヨハネの黙示録 4:7; エゼキエル書 10:21; 列王紀上 7:36"> そのおのおのには四つの顔があった。第一の顔はケルブの顔、第二の顔は人の顔、第三はししの顔、第四はわしの顔であった。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="エゼキエル書 1:5; ホセア書 9:12; エゼキエル書 11:22"> その時ケルビムはのぼった。これがケバル川でわたしが見た生きものである。</span>
<span className="v" id="v16" data-v="16" data-xref="エゼキエル書 1:19–21"> ケルビムの行く時、輪もそのかたわらに行き、ケルビムが翼をあげて地から飛びあがる時は、輪もそのかたわらを離れない。</span>
<span className="v" id="v17" data-v="17" data-xref="エゼキエル書 1:20–21; ローマ人への手紙 8:2; エゼキエル書 1:12"> その立ちどまる時は、輪も立ちどまり、そののぼる時は、輪も共にのぼる。生きものの霊がその中にあるからである。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="詩篇 18:10; マタイによる福音書 23:37–39; 詩篇 78:60–61"> 時に主の栄光が宮の敷居から出て行って、ケルビムの上に立った。</span>
<span className="v" id="v19" data-v="19" data-xref="エゼキエル書 8:16; エゼキエル書 1:17–21; エゼキエル書 1:26–28"> するとケルビムは翼をあげて、わたしの目の前で、地からのぼった。その出て行く時、輪もまたこれと共にあり、主の宮の東の門の入口の所へ行って止まった。イスラエルの神の栄光がその上にあった。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="エゼキエル書 1:1; エゼキエル書 10:15; 列王紀上 7:36"> これがすなわちわたしがケバル川のほとりで、イスラエルの神の下に見たかの生きものである。わたしはそれがケルビムであることを知っていた。</span>
<span className="v" id="v21" data-v="21" data-xref="エゼキエル書 1:6; エゼキエル書 41:18–19; エゼキエル書 10:14"> これにはおのおの四つの顔があり、おのおの四つの翼があり、また人の手のようなものがその翼の下にあった。</span>
<span className="v" id="v22" data-v="22" data-xref="エゼキエル書 10:11; エゼキエル書 1:10; エゼキエル書 1:12"> その顔の形は、ケバル川のほとりでわたしが見たそのままの顔である。おのおのその前の方にまっすぐに行った。</span>
</div>

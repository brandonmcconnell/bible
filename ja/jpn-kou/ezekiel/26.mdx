<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="エゼキエル書 20:1; エゼキエル書 1:2; エレミヤ書 39:2"> 第十一年の第一日に主の言葉がわたしに臨んだ、</span>
<span className="v" id="v2" data-v="2" data-xref="イザヤ書 23:1–18; エゼキエル書 36:2; ヨエル書 3:4"> 「人の子よ、ツロはエルサレムについて言った、『ああ、それはよい気味である。もろもろの民の門は破れて、わたしに開かれた。わたしは豊かになり、彼は破れはてた』と。</span>
<span className="v" id="v3" data-v="3" data-xref="エレミヤ書 51:42; イザヤ書 5:30; ミカ書 4:11"> それゆえ、主なる神はこう言われる、ツロよ、わたしはあなたを攻め、海がその波を起すように、わたしは多くの国民を、あなたに攻めこさせる。</span>
<span className="v" id="v4" data-v="4" data-xref="イザヤ書 23:11; アモス書 1:10; エゼキエル書 26:9"> 彼らはツロの城壁をこわし、そのやぐらを倒す。わたしはその土を払い去って、裸の岩にする。</span>
<span className="v" id="v5" data-v="5" data-xref="エゼキエル書 29:19; エゼキエル書 27:32; エゼキエル書 25:7"> ツロは海の中にあって、網をはる場所になる。これはわたしが言ったのであると、主なる神は言われる。ツロは、もろもろの民にかすめられ、</span>
<span className="v" id="v6" data-v="6" data-xref="エゼキエル書 16:46; エゼキエル書 26:8; エレミヤ書 49:2"> その本土におる娘たちは、つるぎで殺される。そして彼らは、わたしが主であることを知るようになる。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="エズラ記 7:12; ダニエル書 2:37; エゼキエル書 23:24"> 主なる神はこう言われる、見よ、わたしは王の王なるバビロンの王ネブカデレザルに、馬、戦車、騎兵、および多くの軍勢をひきいて、北からツロに攻めこさせる。</span>
<span className="v" id="v8" data-v="8" data-xref="エゼキエル書 21:22; エレミヤ書 52:4; エレミヤ書 32:24"> 彼は本土におるあなたの娘たちを、つるぎで殺し、あなたに向かって雲悌を建て、塁を築き、盾を備え、</span>
<span className="v" id="v9" data-v="9" data-xref="歴代志下 26:15"> 城くずしをあなたの城壁に向け、おのであなたのやぐらを打ち砕く。</span>
<span className="v" id="v10" data-v="10" data-xref="エゼキエル書 26:15; エゼキエル書 27:28; エレミヤ書 47:3"> その多くの馬の土煙は、あなたをおおう。人が破れた町にはいるように、彼があなたの門にはいる時、騎兵と貨車と戦車の響きによって、あなたの石がきはゆるぐ。</span>
<span className="v" id="v11" data-v="11" data-xref="イザヤ書 5:28; イザヤ書 26:5; ハバクク書 1:8"> 彼はその馬のひずめで、あなたのすべてのちまたを踏みあらし、つるぎであなたの民を殺す。あなたの力強い柱は地に倒れる。</span>
<span className="v" id="v12" data-v="12" data-xref="イザヤ書 23:8; 歴代志下 32:27; ゼカリヤ書 9:3–4"> 彼らはあなたの財宝を奪い、商品をかすめ、城壁をくずし、楽しい家をこわし、石と木と土とを水の中に投げ込む。</span>
<span className="v" id="v13" data-v="13" data-xref="エレミヤ書 7:34; イザヤ書 23:16; イザヤ書 14:11"> わたしはあなたの歌の声をとどめる。琴の音はもはや聞えなくなる。</span>
<span className="v" id="v14" data-v="14" data-xref="マラキ書 1:4; ヨブ記 12:14; 民数記 23:19"> わたしはあなたを裸の岩にする。あなたは網を張る場所となり、再び建てられることはない。主なるわたしがこれを言ったと、主なる神は言われる。</span>
</div>
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="エゼキエル書 27:35; エレミヤ書 49:21; エゼキエル書 26:18"> 主なる神はツロにこう言われる、海沿いの国々はあなたの倒れる響き、手負いのうめき、あなたのうちの殺人のゆえに、身震いしないであろうか。</span>
<span className="v" id="v16" data-v="16" data-xref="エゼキエル書 32:10; ヨナ書 3:6; ヨブ記 8:22"> その時、海の君たちは皆その位からおり、朝服を脱ぎ、縫い取りの衣服を取り去り、恐れを身にまとい、地に座して、いたく恐れ、あなたの事を驚き、</span>
<span className="v" id="v17" data-v="17" data-xref="イザヤ書 14:12; エゼキエル書 19:1; サムエル記下 1:25–27"> あなたのために悲しみの歌をのべて言う、<br /><span className="pl pl-1">『あなたは海にあって、強い誉ある町、</span><br /><span className="pl pl-1">本土に恐れを与えていたあなたも、その住民も、</span><br /><span className="pl pl-1">海から消え去った。</span></span>
<span className="v" id="v18" data-v="18" data-xref="エゼキエル書 26:15; イザヤ書 23:5–7; エゼキエル書 27:35"> <span className="pl pl-1">島々はあなたの倒れる日に身震いする。</span><br /><span className="pl pl-1">海の島々はあなたの去り行くことを見て驚く』。</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="イザヤ書 8:7–8; エゼキエル書 26:3; ダニエル書 11:40"> 主なる神はこう言われる、わたしはあなたを、荒れた町となし、住む者のない町のようにし、淵をあなたに向かってわきあがらせ、大水にあなたをおおわせる時、</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 27:13; ルカによる福音書 10:15; ゼカリヤ書 2:8"> あなたを穴に下る者どもと共に、昔の民の所に下し、穴に下る者と共に下の国に、昔のままの荒れ跡の中に、あなたを住ませる。それゆえ、あなたは人の住む所とならず、また生ある者の地に所を得ない。</span>
<span className="v" id="v21" data-v="21" data-xref="エゼキエル書 27:36; エゼキエル書 28:19; ヨハネの黙示録 18:21"> わたしはあなたの終りを、恐るべきものとする。あなたは無に帰する。あなたを尋ねる人があっても、永久に見いださないと、主なる神は言われる」。</span>
</div>

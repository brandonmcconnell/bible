<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="エゼキエル書 44:1; エゼキエル書 42:15; エゼキエル書 46:1"> その後、彼はわたしを門に導いた。門は東に面していた。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネの黙示録 18:1; エゼキエル書 11:23; イザヤ書 6:3"> その時、見よ、イスラエルの神の栄光が、東の方から来たが、その来る響きは、大水の響きのようで、地はその栄光で輝いた。</span>
<span className="v" id="v3" data-v="3" data-xref="エゼキエル書 9:5; エゼキエル書 9:1; エレミヤ書 1:10"> わたしが見た幻の様は、彼がこの町を滅ぼしに来た時に、わたしが見た幻と同様で、これはまたわたしがケバル川のほとりで見た幻のようであった。それでわたしは顔を伏せた。</span>
<span className="v" id="v4" data-v="4" data-xref="エゼキエル書 10:18–19; エゼキエル書 44:2; エゼキエル書 43:2"> 主の栄光が、東の方に面した門の道から宮にはいった時、</span>
<span className="v" id="v5" data-v="5" data-xref="コリント人への第二の手紙 12:2–4; 列王紀上 8:10–11; エゼキエル書 8:3"> 霊がわたしを引き上げて、内庭に導き入れると、見よ、主の栄光が宮に満ちた。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="エゼキエル書 40:3; イザヤ書 66:6; ヨハネの黙示録 16:1"> その人がわたしのかたわらに立った時、わたしはひとりの人が、宮の中からわたしに語るのを聞いた。</span>
<span className="v" id="v7" data-v="7" data-xref="エゼキエル書 43:9; 詩篇 47:8; レビ記 26:30"> 彼はわたしに言った、「人の子よ、これはわたしの位のある所、わたしの足の裏の踏む所、わたしが永久にイスラエルの人々の中に住む所である。またイスラエルの家は、民もその王たちも、再び姦淫と、王たちの死体とをもって、わが聖なる名を汚さない。</span>
<span className="v" id="v8" data-v="8" data-xref="エゼキエル書 5:11; エゼキエル書 8:3–16; 歴代志下 33:7"> 彼らはその敷居を、わが敷居のかたわらに設け、その門柱を、わが門柱のかたわらに設けたので、わたしと彼らとの間には、わずかに壁があるのみである。そして彼らは、その犯した憎むべき事をもって、わが聖なる名を汚したので、わたしは怒りをもって、これを滅ぼした。</span>
<span className="v" id="v9" data-v="9" data-xref="エゼキエル書 43:7; エゼキエル書 37:26–28; エゼキエル書 18:30–31"> 今彼らに命じて姦淫と、その王たちの死体を、わたしから遠く取り除かせよ。そうしたら、わたしは永久に彼らの中に住む。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="エゼキエル書 40:4; エゼキエル書 16:61; エゼキエル書 16:63"> 人の子よ、宮と、その外形と、設計とをイスラエルの家に示せ。彼らはその悪を恥じるであろう。</span>
<span className="v" id="v11" data-v="11" data-xref="エゼキエル書 36:27; エゼキエル書 11:20; マタイによる福音書 28:20"> 彼らがその犯したすべての事を恥じたら、彼らに、この宮の建て方、設備、出口、入口、すべての形式、すべてのおきて、すべての規定を示せ。これを彼らの目の前に書き、彼らにそのすべての規定と、おきてとを守り行わせよ。</span>
<span className="v" id="v12" data-v="12" data-xref="エゼキエル書 40:2; ヨハネの黙示録 21:27; 詩篇 93:5"> 宮の規定はこれである。山の頂の四方の地域はみな最も聖である。見よ、これは宮の規定である。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="エゼキエル書 40:5; 出エジプト記 27:1–8; エゼキエル書 41:8"> 祭壇の寸法はキュビトですれば、次のようである。（そのキュビトは一キュビトと一手幅である。）土台は高さ一キュビト、幅一キュビト、その周囲の縁は半キュビトである。</span>
<span className="v" id="v14" data-v="14"> 祭壇の高さは、次のとおりである。地面の土台から下のかさねまで二キュビト、幅は一キュビト、また小さいかさねから大きいかさねまで四キュビト、その幅は一キュビトである。</span>
<span className="v" id="v15" data-v="15" data-xref="出エジプト記 27:2; 詩篇 118:27; レビ記 9:9"> 祭壇の炉は四キュビトで、祭壇の炉から高さ一キュビトの角が四本出ていた。</span>
<span className="v" id="v16" data-v="16" data-xref="出エジプト記 27:1; 歴代志下 4:1; 出エジプト記 38:1–2"> 炉は長さ十二キュビト、幅十二キュビトの四角形である。</span>
<span className="v" id="v17" data-v="17" data-xref="出エジプト記 20:26; エゼキエル書 40:6; 出エジプト記 25:25"> そのかさねは四方とも長さ十四キュビト、幅十四キュビトの四角形、その周囲の縁は幅半キュビト、その台は四方一キュビト、その階段は東に面する」。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="出エジプト記 40:29; ヘブル人への手紙 10:4–12; エゼキエル書 2:1"> 彼はわたしに言った、「人の子よ、主なる神はこう言われる、祭壇を建て、その上に燔祭をささげ、これに血を注ぐ日には、次のことを祭壇の定めとせよ。</span>
<span className="v" id="v19" data-v="19" data-xref="エゼキエル書 40:46; エゼキエル書 44:15; 民数記 16:40"> すなわち主なる神は言われる、ザドクの子孫で、わたしに近く仕えるレビびとである祭司には、罪祭のために雄牛の子を与えよ。</span>
<span className="v" id="v20" data-v="20" data-xref="レビ記 16:19; レビ記 8:15; 出エジプト記 29:12"> またその血をとって、これを祭壇の四つの角と、かさねの四すみと、周囲の縁に塗って、祭壇を清め、これをあがなえ。</span>
<span className="v" id="v21" data-v="21" data-xref="出エジプト記 29:14; レビ記 4:12; レビ記 8:17"> あなたはまた罪祭の牛をとって、これを聖所の外、宮のうちの定められた所で焼け。</span>
<span className="v" id="v22" data-v="22" data-xref="エゼキエル書 43:25–26; エゼキエル書 43:20; ペテロの第一の手紙 1:19"> 第二日に、あなたは無傷の雄やぎを、罪祭としてささげよ。すなわち雄牛で清めたように、これで祭壇を清めよ。</span>
<span className="v" id="v23" data-v="23" data-xref="出エジプト記 29:1"> 清めごとを終えたなら、無傷の雄牛の子と、群れの中の無傷の雄羊とをささげよ。</span>
<span className="v" id="v24" data-v="24" data-xref="レビ記 2:13; マルコによる福音書 9:49–50; 民数記 18:19"> これを主の前に持ってきて、祭司らはその上に塩をまき、これらを燔祭として主にささげよ。</span>
<span className="v" id="v25" data-v="25" data-xref="レビ記 8:33; 出エジプト記 29:35–37; レビ記 8:35"> 七日の間、あなたは日々雄やぎを罪祭とせよ。また雄牛の子と、群れの中の雄羊との無傷のものをととのえ、</span>
<span className="v" id="v26" data-v="26" data-xref="出エジプト記 29:24; レビ記 8:34; 出エジプト記 32:29"> 七日の間、彼らは祭壇をあがない、これを清め、これを聖別しなければならない。</span>
<span className="v" id="v27" data-v="27" data-xref="レビ記 9:1; エゼキエル書 20:40–41; ペテロの第一の手紙 2:5"> 彼らがこれらの日を満たしたとき、八日目から後は、祭司たちは、あなたがたの燔祭と、酬恩祭とを祭壇の上に供える。そうすれば、わたしは、あなたがたを受けいれると、主なる神は言われる」。</span>
</div>

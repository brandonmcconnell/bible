<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 主はまたモーセに言われた、</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 21:21; レビ記 18:21; レビ記 20:27"> 「イスラエルの人々に言いなさい、『イスラエルの人々のうち、またイスラエルのうちに寄留する他国人のうち、だれでもその子供をモレクにささげる者は、必ず殺されなければならない。すなわち、国の民は彼を石で撃たなければならない。</span>
<span className="v" id="v3" data-v="3" data-xref="レビ記 18:21; エゼキエル書 5:11; エゼキエル書 23:38–39"> わたしは顔をその人に向け、彼を民のうちから断つであろう。彼がその子供をモレクにささげてわたしの聖所を汚し、またわたしの聖なる名を汚したからである。</span>
<span className="v" id="v4" data-v="4" data-xref="申命記 17:2–5; 使徒行伝 17:30; 列王紀上 20:42"> その人が子供をモレクにささげるとき、国の民がもしことさらに、この事に目をおおい、これを殺さないならば、</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 106:39; ホセア書 2:13; ホセア書 2:5"> わたし自身、顔をその人とその家族とに向け、彼および彼に見ならってモレクを慕い、これと姦淫する者を、すべて民のうちから断つであろう。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="レビ記 19:31; イザヤ書 8:19; レビ記 20:27"> もし口寄せ、または占い師のもとにおもむき、彼らを慕って姦淫する者があれば、わたしは顔をその人に向け、これを民のうちから断つであろう。</span>
<span className="v" id="v7" data-v="7" data-xref="レビ記 11:44; レビ記 19:2; ペテロの第一の手紙 1:15–16"> ゆえにあなたがたは、みずからを聖別し、聖なる者とならなければならない。わたしはあなたがたの神、主である。</span>
<span className="v" id="v8" data-v="8" data-xref="出エジプト記 31:13; ヤコブの手紙 1:22; テサロニケ人への第一の手紙 5:23"> あなたがたはわたしの定めを守って、これを行わなければならない。わたしはあなたがたを聖別する主である。</span>
<span className="v" id="v9" data-v="9" data-xref="出エジプト記 21:17; マルコによる福音書 7:10; 申命記 27:16"> だれでも父または母をのろう者は、必ず殺されなければならない。彼が父または母をのろったので、その血は彼に帰するであろう。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="ヨハネによる福音書 8:4–5; 申命記 22:22–24; 申命記 5:18"> 人の妻と姦淫する者、すなわち隣人の妻と姦淫する者があれば、その姦夫、姦婦は共に必ず殺されなければならない。</span>
<span className="v" id="v11" data-v="11" data-xref="申命記 27:20; 申命記 27:23; アモス書 2:7"> その父の妻と寝る者は、その父をはずかしめる者である。彼らはふたりとも必ず殺されなければならない。その血は彼らに帰するであろう。</span>
<span className="v" id="v12" data-v="12" data-xref="レビ記 18:15; レビ記 18:23; 創世記 38:18"> 子の妻と寝る者は、ふたり共に必ず殺されなければならない。彼らは道ならぬことをしたので、その血は彼らに帰するであろう。</span>
<span className="v" id="v13" data-v="13" data-xref="コリント人への第一の手紙 6:9; レビ記 18:22; ユダの手紙 1:7"> 女と寝るように男と寝る者は、ふたりとも憎むべき事をしたので、必ず殺されなければならない。その血は彼らに帰するであろう。</span>
<span className="v" id="v14" data-v="14" data-xref="レビ記 18:17; 申命記 27:23; ヨシュア記 7:15"> 女をその母と一緒にめとるならば、これは悪事であって、彼も、女たちも火に焼かれなければならない。このような悪事をあなたがたのうちになくするためである。</span>
<span className="v" id="v15" data-v="15" data-xref="レビ記 18:23; 申命記 27:21; 出エジプト記 22:19"> 男がもし、獣と寝るならば彼は必ず殺されなければならない。あなたがたはまた、その獣を殺さなければならない。</span>
<span className="v" id="v16" data-v="16" data-xref="出エジプト記 21:32; 出エジプト記 19:13; ヘブル人への手紙 12:20"> 女がもし、獣に近づいて、これと寝るならば、あなたは、その女と獣とを殺さなければならない。彼らは必ず殺さるべきである。その血は彼らに帰するであろう。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="レビ記 18:9; 申命記 27:22; エゼキエル書 22:11"> 人がもし、その姉妹、すなわち父の娘、あるいは母の娘に近づいて、その姉妹のはだを見、女はその兄弟のはだを見るならば、これは恥ずべき事である。彼らは、その民の人々の目の前で、断たれなければならない。彼は、その姉妹を犯したのであるから、その罪を負わなければならない。</span>
<span className="v" id="v18" data-v="18" data-xref="レビ記 15:24; レビ記 18:19; エゼキエル書 18:6"> 人がもし、月のさわりのある女と寝て、そのはだを現すならば、男は女の源を現し、女は自分の血の源を現したのであるから、ふたり共にその民のうちから断たれなければならない。</span>
<span className="v" id="v19" data-v="19" data-xref="レビ記 18:6; レビ記 18:12–30; 出エジプト記 6:20"> あなたの母の姉妹、またはあなたの父の姉妹を犯してはならない。これは、自分の肉親の者を犯すことであるから、彼らはその罪を負わなければならない。</span>
<span className="v" id="v20" data-v="20" data-xref="レビ記 18:14; ヨブ記 18:19; ルカによる福音書 23:29"> 人がもし、そのおばと寝るならば、これはおじをはずかしめることであるから、彼らはその罪を負い、子なくして死ぬであろう。</span>
<span className="v" id="v21" data-v="21" data-xref="レビ記 18:16; マタイによる福音書 14:3–4"> 人がもし、その兄弟の妻を取るならば、これは汚らわしいことである。彼はその兄弟をはずかしめたのであるから、彼らは子なき者となるであろう。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="レビ記 18:25–28; エゼキエル書 36:27; レビ記 18:4–5"> あなたがたはわたしの定めとおきてとをことごとく守って、これを行わなければならない。そうすれば、わたしがあなたがたを住まわせようと導いて行く地は、あなたがたを吐き出さぬであろう。</span>
<span className="v" id="v23" data-v="23" data-xref="申命記 9:5; レビ記 18:24; レビ記 18:30"> あなたがたの前からわたしが追い払う国びとの風習に、あなたがたは歩んではならない。彼らは、このもろもろのことをしたから、わたしは彼らを憎むのである。</span>
<span className="v" id="v24" data-v="24" data-xref="申命記 14:2; 出エジプト記 6:8; 申命記 7:6"> わたしはあなたがたに言った、「あなたがたは、彼らの地を獲るであろう。わたしはこれをあなたがたに与えて、これを獲させるであろう。これは乳と蜜との流れる地である」。わたしはあなたがたを他の民から区別したあなたがたの神、主である。</span>
<span className="v" id="v25" data-v="25" data-xref="申命記 14:3–21; レビ記 11:1–47; 使徒行伝 10:11–15"> あなたがたは清い獣と汚れた獣、汚れた鳥と清い鳥を区別しなければならない。わたしがあなたがたのために汚れたものとして区別した獣、または鳥またはすべて地を這うものによって、あなたがたの身を忌むべきものとしてはならない。</span>
<span className="v" id="v26" data-v="26" data-xref="ペテロの第一の手紙 1:15–16; レビ記 20:7; レビ記 20:24"> あなたがたはわたしに対して聖なる者でなければならない。主なるわたしは聖なる者で、あなたがたをわたしのものにしようと、他の民から区別したからである。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="レビ記 19:31; レビ記 20:6; サムエル記上 28:7–9"> 男または女で、口寄せ、または占いをする者は、必ず殺されなければならない。すなわち、石で撃ち殺さなければならない。その血は彼らに帰するであろう』」。</span>
</div>

<div className="bible-chapter" lang="ja" dir="ltr" data-lang="ja" data-translation="jpn-kou" data-translation-id="jpn_kou" data-translation-label="口語訳" data-book="LEV" data-book-slug="leviticus" data-book-name="レビ記" data-chapter="8" data-verses="36">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 主はまたモーセに言われた、</span>
<span className="v" id="v2" data-v="2" data-xref="出エジプト記 28:2–4; 出エジプト記 39:41; ヘブル人への手紙 7:27"> 「あなたはアロンとその子たち、およびその衣服、注ぎ油、罪祭の雄牛、雄羊二頭、種入れぬパン一かごを取り、</span>
<span className="v" id="v3" data-v="3" data-xref="歴代志下 30:13; 使徒行伝 2:1; ネヘミヤ書 8:1"> また全会衆を会見の幕屋の入口に集めなさい」。</span>
<span className="v" id="v4" data-v="4" data-xref="出エジプト記 39:26; 出エジプト記 39:7; 出エジプト記 39:5"> モーセは主が命じられたようにした。そして会衆は会見の幕屋の入口に集まった。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="出エジプト記 29:4–37"> そこでモーセは会衆にむかって言った、「これは主があなたがたにせよと命じられたことである」。</span>
<span className="v" id="v6" data-v="6" data-xref="コリント人への第一の手紙 6:11; エペソ人への手紙 5:26; 出エジプト記 29:4"> そしてモーセはアロンとその子たちを連れてきて、水で彼らを洗い清め、</span>
<span className="v" id="v7" data-v="7" data-xref="出エジプト記 28:4; イザヤ書 61:10; ガラテヤ人への手紙 3:27"> アロンに服を着させ、帯をしめさせ、衣をまとわせ、エポデを着けさせ、エポデの帯をしめさせ、それをもってエポデを身に結いつけ、</span>
<span className="v" id="v8" data-v="8" data-xref="エズラ記 2:63; テサロニケ人への第一の手紙 5:8; イザヤ書 59:17"> また胸当を着けさせ、その胸当にウリムとトンミムを入れ、</span>
<span className="v" id="v9" data-v="9" data-xref="ピリピ人への手紙 2:9–11; ゼカリヤ書 6:11–14; 出エジプト記 28:36–38"> その頭に帽子をかぶらせ、その帽子の前に金の板、すなわち聖なる冠をつけさせた。主がモーセに命じられたとおりである。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="出エジプト記 40:9–11; レビ記 8:2; 出エジプト記 30:23–29"> モーセはまた注ぎ油を取り、幕屋とそのうちのすべての物に油を注いでこれを聖別し、</span>
<span className="v" id="v11" data-v="11" data-xref="テトスヘの手紙 3:6; 出エジプト記 30:29; 出エジプト記 16:19"> かつ、それを七たび祭壇に注ぎ、祭壇とそのもろもろの器、洗盤とその台に油を注いでこれを聖別し、</span>
<span className="v" id="v12" data-v="12" data-xref="出エジプト記 30:30; 詩篇 133:2; 出エジプト記 29:7"> また注ぎ油をアロンの頭に注ぎ、彼に油を注いでこれを聖別した。</span>
<span className="v" id="v13" data-v="13" data-xref="出エジプト記 29:8–9; ヨハネの黙示録 5:10; ヨハネの黙示録 1:6"> モーセはまたアロンの子たちを連れてきて、服を彼らに着させ、帯を彼らにしめさせ、頭巾を頭に巻かせた。主がモーセに命じられたとおりである。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="エゼキエル書 43:19; 詩篇 66:15; ペテロの第一の手紙 3:18"> 彼はまた罪祭の雄牛を連れてこさせ、アロンとその子たちは、その罪祭の雄牛の頭に手を置いた。</span>
<span className="v" id="v15" data-v="15" data-xref="レビ記 4:7; ヘブル人への手紙 9:18–23; エゼキエル書 43:19–27"> モーセはこれをほふり、その血を取り、指をもってその血を祭壇の四すみの角につけて祭壇を清め、また残りの血を祭壇のもとに注いで、これを聖別し、これがためにあがないをした。</span>
<span className="v" id="v16" data-v="16" data-xref="出エジプト記 29:13; レビ記 3:3–5; レビ記 4:8–9"> モーセはまたその内臓の上のすべての脂肪、肝臓の小葉、二つの腎臓とその脂肪とを取り、これを祭壇の上で焼いた。</span>
<span className="v" id="v17" data-v="17" data-xref="レビ記 4:11–12; 出エジプト記 29:14; レビ記 6:30"> ただし、その雄牛の皮と肉と汚物は宿営の外で、火をもって焼き捨てた。主がモーセに命じられたとおりである。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="レビ記 8:2; レビ記 1:4–13; 出エジプト記 29:15–18"> 彼はまた燔祭の雄羊を連れてこさせ、アロンとその子たちは、その雄羊の頭に手を置いた。</span>
<span className="v" id="v19" data-v="19"> モーセはこれをほふって、その血を祭壇の周囲に注ぎかけた。</span>
<span className="v" id="v20" data-v="20" data-xref="レビ記 1:8"> そして、モーセはその雄羊を節々に切り分かち、その頭と切り分けたものと脂肪とを焼いた。</span>
<span className="v" id="v21" data-v="21" data-xref="エペソ人への手紙 5:2; 出エジプト記 29:18; レビ記 1:17"> またモーセは水でその内臓と足とを洗い、その雄羊をことごとく祭壇の上で焼いた。これは香ばしいかおりのための燔祭であって、主にささげる火祭である。主がモーセに命じられたとおりである。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="レビ記 8:2; レビ記 8:29; 出エジプト記 29:19–31"> 彼はまたほかの雄羊、すなわち任職の雄羊を連れてこさせ、アロンとその子たちは、その雄羊の頭に手を置いた。</span>
<span className="v" id="v23" data-v="23" data-xref="出エジプト記 29:20; レビ記 14:14; ローマ人への手紙 12:1"> モーセはこれをほふり、その血を取って、アロンの右の耳たぶと、右手の親指と、右足の親指とにつけた。</span>
<span className="v" id="v24" data-v="24" data-xref="ヘブル人への手紙 9:18–22"> またモーセはアロンの子たちを連れてきて、その血を彼らの右の耳たぶと、右手の親指と、右足の親指とにつけた。そしてモーセはその残りの血を、祭壇の周囲に注ぎかけた。</span>
<span className="v" id="v25" data-v="25" data-xref="レビ記 3:9; レビ記 3:3–5; イザヤ書 53:10"> 彼はまたその脂肪、すなわち脂尾、内臓の上のすべての脂肪、肝臓の小葉、二つの腎臓とその脂肪、ならびにその右のももを取り、</span>
<span className="v" id="v26" data-v="26" data-xref="出エジプト記 29:23; テモテヘの第一の手紙 2:5; 使徒行伝 5:12"> また主の前にある種入れぬパンのかごから種入れぬ菓子一つと、油を入れたパンの菓子一つと、煎餅一つとを取って、かの脂肪と右のももとの上に載せ、</span>
<span className="v" id="v27" data-v="27" data-xref="エレミヤ書 30:21; ヘブル人への手紙 9:14; 出エジプト記 29:24–37"> これをすべてアロンの手と、その子たちの手に渡し、主の前に揺り動かさせて揺祭とした。</span>
<span className="v" id="v28" data-v="28" data-xref="出エジプト記 29:25; 詩篇 22:13–14; ヘブル人への手紙 10:14–22"> そしてモーセはこれを彼らの手から取り、祭壇の上で燔祭と共に焼いた。これは香ばしいかおりとする任職の供え物であって、主にささげる火祭である。</span>
<span className="v" id="v29" data-v="29" data-xref="コリント人への第一の手紙 10:31; ペテロの第一の手紙 4:11; レビ記 7:30–34"> そしてモーセはその胸を取り、主の前にこれを揺り動かして揺祭とした。これは任職の雄羊のうちモーセに帰すべき分であった。主がモーセに命じられたとおりである。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="出エジプト記 29:21; 民数記 3:3; 出エジプト記 30:30"> モーセはまた注ぎ油と祭壇の上の血とを取り、これをアロンとその服、またその子たちとその服とに注いで、アロンとその服、およびその子たちと、その服とを聖別した。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="出エジプト記 29:31–32; ガラテヤ人への手紙 2:20; サムエル記上 2:13–17"> モーセはまたアロンとその子たちに言った、「会見の幕屋の入口でその肉を煮なさい。そして任職祭のかごの中のパンと共に、それをその所で食べなさい。これは『アロンとその子たちが食べなければならない、と言え』とわたしが命じられたとおりである。</span>
<span className="v" id="v32" data-v="32" data-xref="出エジプト記 29:34; 出エジプト記 12:10; ヘブル人への手紙 3:13–14"> あなたがたはその肉とパンとの残ったものを火で焼き捨てなければならない。</span>
<span className="v" id="v33" data-v="33" data-xref="出エジプト記 29:35; 民数記 19:12; エゼキエル書 43:25–27"> あなたがたはその任職祭の終る日まで七日の間、会見の幕屋の入口から出てはならない。あなたがたの任職は七日を要するからである。</span>
<span className="v" id="v34" data-v="34" data-xref="ヘブル人への手紙 7:27; ヘブル人への手紙 7:16; ヘブル人への手紙 10:11–12"> きょう行ったように、あなたがたのために、あがないをせよ、と主はお命じになった。</span>
<span className="v" id="v35" data-v="35" data-xref="民数記 3:7; 申命記 11:1; 列王紀上 2:3"> あなたがたは会見の幕屋の入口に七日の間、日夜とどまり、主の仰せを守って、死ぬことのないようにしなければならない。わたしはそのように命じられたからである」。</span>
<span className="v" id="v36" data-v="36" data-xref="申命記 12:32; 申命記 4:2; 出エジプト記 40:16"> アロンとその子たちは主がモーセによってお命じになったことを、ことごとく行った。</span>
</div>
</div>

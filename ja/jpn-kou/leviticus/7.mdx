<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="レビ記 6:17; レビ記 5:14–7; レビ記 6:25"> 愆祭のおきては次のとおりである。それはいと聖なる物である。</span>
<span className="v" id="v2" data-v="2" data-xref="レビ記 1:5; レビ記 6:25; レビ記 1:11"> 愆祭は燔祭をほふる場所でほふらなければならない。そして祭司はその血を祭壇の周囲に注ぎかけ、</span>
<span className="v" id="v3" data-v="3" data-xref="出エジプト記 29:13; レビ記 3:15–16; 詩篇 51:6"> そのすべての脂肪をささげなければならない。すなわち脂尾、内臓をおおう脂肪、</span>
<span className="v" id="v4" data-v="4" data-xref="レビ記 3:4"> 二つの腎臓とその上の腰のあたりにある脂肪、腎臓と共に取られる肝臓の上の小葉である。</span>
<span className="v" id="v5" data-v="5" data-xref="レビ記 1:13; ガラテヤ人への手紙 5:24; ペテロの第一の手紙 4:1–2"> 祭司はこれを祭壇の上で焼いて、主に火祭としなければならない。これは愆祭である。</span>
<span className="v" id="v6" data-v="6" data-xref="レビ記 6:29; 民数記 18:9–10; レビ記 2:3"> 祭司たちのうちのすべての男子は、これを食べることができる。これは聖なる所で食べなければならない。これはいと聖なる物である。</span>
<span className="v" id="v7" data-v="7" data-xref="レビ記 6:25–26; レビ記 14:13; コリント人への第一の手紙 9:13"> 罪祭も愆祭も、そのおきては一つであって、異なるところはない。これは、あがないをなす祭司に帰する。</span>
<span className="v" id="v8" data-v="8" data-xref="レビ記 4:11; 出エジプト記 29:14; ローマ人への手紙 13:14"> 人が携えてくる燔祭をささげる祭司、その祭司に、そのささげる燔祭のものの皮は帰する。</span>
<span className="v" id="v9" data-v="9" data-xref="民数記 18:9; エゼキエル書 44:29; レビ記 2:10"> すべて天火で焼いた素祭、またすべて深鍋または平鍋で作ったものは、これをささげる祭司に帰する。</span>
<span className="v" id="v10" data-v="10" data-xref="コリント人への第二の手紙 8:14; 出エジプト記 16:18"> すべて素祭は、油を混ぜたものも、かわいたものも、アロンのすべての子たちにひとしく帰する。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="レビ記 22:18–21; エゼキエル書 45:15; レビ記 3:1–17"> 主にささぐべき酬恩祭の犠牲のおきては次のとおりである。</span>
<span className="v" id="v12" data-v="12" data-xref="レビ記 2:4; 民数記 6:15; ペテロの第一の手紙 2:5"> もしこれを感謝のためにささげるのであれば、油を混ぜた種入れぬ菓子と、油を塗った種入れぬ煎餅と、よく混ぜた麦粉に油を混ぜて作った菓子とを、感謝の犠牲に合わせてささげなければならない。</span>
<span className="v" id="v13" data-v="13" data-xref="アモス書 4:5; レビ記 23:17; マタイによる福音書 13:33"> また種を入れたパンの菓子をその感謝のための酬恩祭の犠牲に合わせ、供え物としてささげなければならない。</span>
<span className="v" id="v14" data-v="14" data-xref="民数記 18:19; 出エジプト記 29:27–28; 民数記 18:24–32"> すなわちこのすべての供え物のうちから、菓子一つずつを取って主にささげなければならない。これは酬恩祭の血を注ぎかける祭司に帰する。</span>
<span className="v" id="v15" data-v="15" data-xref="レビ記 22:29–30"> その感謝のための酬恩祭の犠牲の肉は、その供え物をささげた日のうちに食べなければならない。少しでも明くる朝まで残して置いてはならない。</span>
<span className="v" id="v16" data-v="16" data-xref="レビ記 19:5–8; 申命記 12:6; 詩篇 116:14"> しかし、その供え物の犠牲がもし誓願の供え物、または自発の供え物であるならば、その犠牲をささげた日のうちにそれを食べ、その残りはまた明くる日に食べることができる。</span>
<span className="v" id="v17" data-v="17" data-xref="出エジプト記 12:10; ホセア書 6:2; コリント人への第一の手紙 15:4"> ただし、その犠牲の肉の残りは三日目には火で焼き捨てなければならない。</span>
<span className="v" id="v18" data-v="18" data-xref="レビ記 19:7–8; レビ記 11:41; 民数記 18:27"> もしその酬恩祭の犠牲の肉を三日目に少しでも食べるならば、それは受け入れられず、また供え物と見なされず、かえって忌むべき物となるであろう。そしてそれを食べる者はとがを負わなければならない。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="ルカによる福音書 11:41; テトスヘの手紙 1:15; 使徒行伝 10:15–16"> その肉がもし汚れた物に触れるならば、それを食べることなく、火で焼き捨てなければならない。犠牲の肉はすべて清い者がこれを食べることができる。</span>
<span className="v" id="v20" data-v="20" data-xref="レビ記 15:2–33; 創世記 17:14; レビ記 22:3–7"> もし人がその身に汚れがあるのに、主にささげた酬恩祭の犠牲の肉を食べるならば、その人は民のうちから断たれるであろう。</span>
<span className="v" id="v21" data-v="21" data-xref="レビ記 12:1–59; レビ記 11:20; エゼキエル書 4:14"> また人がもしすべて汚れたもの、すなわち人の汚れ、あるいは汚れた獣、あるいは汚れた這うものに触れながら、主にささげた酬恩祭の犠牲の肉を食べるならば、その人は民のうちから断たれるであろう』」。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22"> 主はまたモーセに言われた、</span>
<span className="v" id="v23" data-v="23" data-xref="レビ記 3:16–17; レビ記 17:6; サムエル記上 2:15–17"> 「イスラエルの人々に言いなさい、『あなたがたは、すべて牛、羊、やぎの脂肪を食べてはならない。</span>
<span className="v" id="v24" data-v="24" data-xref="出エジプト記 22:31; レビ記 17:15; レビ記 22:8"> 自然に死んだ獣の脂肪および裂き殺された獣の脂肪は、さまざまのことに使ってもよい。しかし、それは決して食べてはならない。</span>
<span className="v" id="v25" data-v="25"> だれでも火祭として主にささげる獣の脂肪を食べるならば、これを食べる人は民のうちから断たれるであろう。</span>
<span className="v" id="v26" data-v="26" data-xref="創世記 9:4; レビ記 3:17; 使徒行伝 15:20"> またあなたがたはすべてその住む所で、鳥にせよ、獣にせよ、すべてその血を食べてはならない。</span>
<span className="v" id="v27" data-v="27" data-xref="ヘブル人への手紙 10:29; レビ記 7:20–21; レビ記 7:25"> だれでもすべて血を食べるならば、その人は民のうちから断たれるであろう』」。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28"> 主はまたモーセに言われた、</span>
<span className="v" id="v29" data-v="29" data-xref="コロサイ人への手紙 1:20; ヨハネの第一の手紙 1:7; レビ記 3:1–17"> 「イスラエルの人々に言いなさい、『酬恩祭の犠牲を主にささげる者は、その酬恩祭の犠牲のうちから、その供え物を主に携えてこなければならない。</span>
<span className="v" id="v30" data-v="30" data-xref="民数記 6:20; レビ記 3:9; レビ記 3:14"> 主の火祭は手ずからこれを携えてこなければならない。すなわちその脂肪と胸とを携えてきて、その胸を主の前に揺り動かして、揺祭としなければならない。</span>
<span className="v" id="v31" data-v="31" data-xref="レビ記 3:5; レビ記 3:11; レビ記 3:16"> そして祭司はその脂肪を祭壇の上で焼かなければならない。その胸はアロンとその子たちに帰する。</span>
<span className="v" id="v32" data-v="32" data-xref="民数記 6:20; レビ記 7:34; レビ記 9:21"> あなたがたの酬恩祭の犠牲のうちから、その右のももを挙祭として、祭司に与えなければならない。</span>
<span className="v" id="v33" data-v="33" data-xref="レビ記 26:1–46; レビ記 6:1–30; レビ記 7:3"> アロンの子たちのうち、酬恩祭の血と脂肪とをささげる者は、その右のももを自分の分として、獲るであろう。</span>
<span className="v" id="v34" data-v="34" data-xref="民数記 18:18–19; レビ記 10:14–15; 出エジプト記 29:9"> わたしはイスラエルの人々の酬恩祭の犠牲のうちから、その揺祭の胸と挙祭のももを取って、祭司アロンとその子たちに与え、これをイスラエルの人々から永久に彼らの受くべき分とする。</span>
<span className="v" id="v35" data-v="35" data-xref="ヨハネの第一の手紙 2:20; ヨハネの第一の手紙 2:27; 民数記 18:7–19"> これは主の火祭のうちから、アロンの受ける分と、その子たちの受ける分とであって、祭司の職をなすため、彼らが主にささげられた日に定められたのである。</span>
<span className="v" id="v36" data-v="36" data-xref="レビ記 8:12; レビ記 8:30; 出エジプト記 40:13–15"> すなわち、これは彼らに油を注ぐ日に、イスラエルの人々が彼らに与えるように、主が命じられたものであって、代々永久に受くべき分である』」。</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="出エジプト記 29:1; レビ記 1:1–6; レビ記 6:9–18"> これは燔祭、素祭、罪祭、愆祭、任職祭、酬恩祭の犠牲のおきてである。</span>
<span className="v" id="v38" data-v="38" data-xref="レビ記 1:1–2"> すなわち、主がシナイの荒野においてイスラエルの人々にその供え物を主にささげることを命じられた日に、シナイ山でモーセに命じられたものである。</span>
</div>

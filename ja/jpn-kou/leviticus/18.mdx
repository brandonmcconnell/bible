<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 主はまたモーセに言われた、</span>
<span className="v" id="v2" data-v="2" data-xref="出エジプト記 6:7; レビ記 11:44; エゼキエル書 20:5"> 「イスラエルの人々に言いなさい、『わたしはあなたがたの神、主である。</span>
<span className="v" id="v3" data-v="3" data-xref="レビ記 20:23; 出エジプト記 23:24; ペテロの第一の手紙 4:2–4"> あなたがたの住んでいたエジプトの国の習慣を見習ってはならない。またわたしがあなたがたを導き入れるカナンの国の習慣を見習ってはならない。また彼らの定めに歩んではならない。</span>
<span className="v" id="v4" data-v="4" data-xref="レビ記 18:2; レビ記 18:26; エゼキエル書 20:19"> わたしのおきてを行い、わたしの定めを守り、それに歩まなければならない。わたしはあなたがたの神、主である。</span>
<span className="v" id="v5" data-v="5" data-xref="ローマ人への手紙 10:5; エゼキエル書 20:11; ガラテヤ人への手紙 3:12"> あなたがたはわたしの定めとわたしのおきてを守らなければならない。もし人が、これを行うならば、これによって生きるであろう。わたしは主である。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="レビ記 20:17–21; レビ記 18:7–19; レビ記 20:11–12"> あなたがたは、だれも、その肉親の者に近づいて、これを犯してはならない。わたしは主である。</span>
<span className="v" id="v7" data-v="7" data-xref="レビ記 20:11; エゼキエル書 22:10; レビ記 18:8–16"> あなたの母を犯してはならない。それはあなたの父をはずかしめることだからである。彼女はあなたの母であるから、これを犯してはならない。</span>
<span className="v" id="v8" data-v="8" data-xref="レビ記 20:11; コリント人への第一の手紙 5:1; 申命記 27:20"> あなたの父の妻を犯してはならない。それはあなたの父をはずかしめることだからである。</span>
<span className="v" id="v9" data-v="9" data-xref="レビ記 20:17; 申命記 27:22; エゼキエル書 22:11"> あなたの姉妹、すなわちあなたの父の娘にせよ、母の娘にせよ、家に生れたのと、よそに生れたのとを問わず、これを犯してはならない。</span>
<span className="v" id="v10" data-v="10"> あなたのむすこの娘、あるいは、あなたの娘の娘を犯してはならない。それはあなた自身をはずかしめることだからである。</span>
<span className="v" id="v11" data-v="11"> あなたの父の妻があなたの父によって産んだ娘は、あなたの姉妹であるから、これを犯してはならない。</span>
<span className="v" id="v12" data-v="12" data-xref="レビ記 20:19; 出エジプト記 6:20"> あなたの父の姉妹を犯してはならない。彼女はあなたの父の肉親だからである。</span>
<span className="v" id="v13" data-v="13"> またあなたの母の姉妹を犯してはならない。彼女はあなたの母の肉親だからである。</span>
<span className="v" id="v14" data-v="14" data-xref="レビ記 20:20"> あなたの父の兄弟の妻を犯し、父の兄弟をはずかしめてはならない。彼女はあなたのおばだからである。</span>
<span className="v" id="v15" data-v="15" data-xref="レビ記 20:12; 創世記 38:26; エゼキエル書 22:11"> あなたの嫁を犯してはならない。彼女はあなたのむすこの妻であるから、これを犯してはならない。</span>
<span className="v" id="v16" data-v="16" data-xref="申命記 25:5; レビ記 20:21; マタイによる福音書 22:24"> あなたの兄弟の妻を犯してはならない。それはあなたの兄弟をはずかしめることだからである。</span>
<span className="v" id="v17" data-v="17" data-xref="レビ記 20:14; アモス書 2:7; 申命記 27:23"> あなたは女とその娘とを一緒に犯してはならない。またその女のむすこの娘、またはその娘の娘を取って、これを犯してはならない。彼らはあなたの肉親であるから、これは悪事である。</span>
<span className="v" id="v18" data-v="18" data-xref="マラキ書 2:15; 創世記 30:15; 創世記 29:28"> あなたは妻のなお生きているうちにその姉妹を取って、同じく妻となし、これを犯してはならない。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="レビ記 20:18; レビ記 15:24; エゼキエル書 22:10"> あなたは月のさわりの不浄にある女に近づいて、これを犯してはならない。</span>
<span className="v" id="v20" data-v="20" data-xref="出エジプト記 20:14; コリント人への第一の手紙 6:9; ヘブル人への手紙 13:4"> 隣の妻と交わり、彼女によって身を汚してはならない。</span>
<span className="v" id="v21" data-v="21" data-xref="申命記 12:31; レビ記 20:2–5; 申命記 18:10"> あなたの子どもをモレクにささげてはならない。またあなたの神の名を汚してはならない。わたしは主である。</span>
<span className="v" id="v22" data-v="22" data-xref="レビ記 20:13; ローマ人への手紙 1:26–27; コリント人への第一の手紙 6:9"> あなたは女と寝るように男と寝てはならない。これは憎むべきことである。</span>
<span className="v" id="v23" data-v="23" data-xref="出エジプト記 22:19; レビ記 20:15–16; レビ記 20:12"> あなたは獣と交わり、これによって身を汚してはならない。また女も獣の前に立って、これと交わってはならない。これは道にはずれたことである。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="申命記 18:12; レビ記 18:30; レビ記 20:22–23"> あなたがたはこれらのもろもろの事によって身を汚してはならない。わたしがあなたがたの前から追い払う国々の人は、これらのもろもろの事によって汚れ、</span>
<span className="v" id="v25" data-v="25" data-xref="レビ記 18:28; レビ記 20:22–23; エレミヤ書 2:7"> その地もまた汚れている。ゆえに、わたしはその悪のためにこれを罰し、その地もまたその住民を吐き出すのである。</span>
<span className="v" id="v26" data-v="26" data-xref="レビ記 18:5; レビ記 17:10; レビ記 18:30"> ゆえに、あなたがたはわたしの定めとわたしのおきてを守り、これらのもろもろの憎むべき事の一つでも行ってはならない。国に生れた者も、あなたがたのうちに宿っている寄留者もそうである。</span>
<span className="v" id="v27" data-v="27" data-xref="歴代志下 36:14; レビ記 18:24; 申命記 23:18"> あなたがたの先にいたこの地の人々は、これらのもろもろの憎むべき事を行ったので、その地も汚れたからである。</span>
<span className="v" id="v28" data-v="28" data-xref="ヨハネの黙示録 3:16; レビ記 20:22; レビ記 18:25"> これは、あなたがたがこの地を汚して、この地があなたがたの先にいた民を吐き出したように、あなたがたをも吐き出すことのないためである。</span>
<span className="v" id="v29" data-v="29" data-xref="レビ記 20:6; 出エジプト記 12:15; レビ記 17:10"> これらのもろもろの憎むべき事の一つでも行う者があれば、これを行う人は、だれでもその民のうちから断たれるであろう。</span>
<span className="v" id="v30" data-v="30" data-xref="レビ記 20:23; 申命記 18:9–12; レビ記 22:9"> それゆえに、あなたがたはわたしの言いつけを守り、先に行われたこれらの憎むべき風習の一つをも行ってはならない。またこれによって身を汚してはならない。わたしはあなたがたの神、主である』」。</span>
</div>

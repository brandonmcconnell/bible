<div className="bp">
<span className="v" id="v1" data-v="1"> 主はまたモーセに言われた、</span>
<span className="v" id="v2" data-v="2" data-xref="ルカによる福音書 17:14; ルカによる福音書 5:12–14; マルコによる福音書 1:40–44"> 「らい病人が清い者とされる時のおきては次のとおりである。すなわち、その人を祭司のもとに連れて行き、</span>
<span className="v" id="v3" data-v="3" data-xref="レビ記 13:46; ルカによる福音書 7:22; ルカによる福音書 17:15–19"> 祭司は宿営の外に出て行って、その人を見、もしらい病の患部がいえているならば、</span>
<span className="v" id="v4" data-v="4" data-xref="民数記 19:6; レビ記 14:6; ヘブル人への手紙 9:19"> 祭司は命じてその清められる者のために、生きている清い小鳥二羽と、香柏の木と、緋の糸と、ヒソプとを取ってこさせ、</span>
<span className="v" id="v5" data-v="5" data-xref="レビ記 14:50; ヘブル人への手紙 2:14; コリント人への第二の手紙 5:1"> 祭司はまた命じて、その小鳥の一羽を、流れ水を盛った土の器の上で殺させ、</span>
<span className="v" id="v6" data-v="6" data-xref="ヨハネの黙示録 1:5; ゼカリヤ書 13:1; ピリピ人への手紙 2:9–11"> そして生きている小鳥を、香柏の木と、緋の糸と、ヒソプと共に取って、これをかの流れ水を盛った土の器の上で殺した小鳥の血に、その生きている小鳥と共に浸し、</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀下 5:14; エゼキエル書 36:25; イザヤ書 52:15"> これをらい病から清められる者に七たび注いで、その人を清い者とし、その生きている小鳥は野に放たなければならない。</span>
<span className="v" id="v8" data-v="8" data-xref="レビ記 11:25; 民数記 8:7; ペテロの第一の手紙 3:21"> 清められる者はその衣服を洗い、毛をことごとくそり落し、水に身をすすいで清くなり、その後、宿営にはいることができる。ただし七日の間はその天幕の外にいなければならない。</span>
<span className="v" id="v9" data-v="9" data-xref="民数記 6:9; レビ記 14:8; 民数記 8:7"> そして七日目に毛をことごとくそらなければならい。頭の毛も、ひげも、まゆも、ことごとくそらなければならない。彼はその衣服を洗い、水に身をすすいで清くなるであろう。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="レビ記 2:1; マタイによる福音書 8:4; ルカによる福音書 5:14"> 八日目にその人は雄の小羊の全きもの二頭と、一歳の雌の小羊の全きもの一頭とを取り、また麦粉十分の三エパに油を混ぜた素祭と、油一ログとを取らなければならない。</span>
<span className="v" id="v11" data-v="11" data-xref="エペソ人への手紙 5:26–27; 出エジプト記 29:1–4; 民数記 8:21"> 清めをなす祭司は、清められる人とこれらの物とを、会見の幕屋の入口で主の前に置き、</span>
<span className="v" id="v12" data-v="12" data-xref="出エジプト記 29:24; レビ記 6:6–7; レビ記 8:27–29"> 祭司は、かの雄の小羊一頭を取って、これを一ログの油と共に愆祭としてささげ、またこれを主の前に揺り動かして揺祭としなければならない。</span>
<span className="v" id="v13" data-v="13" data-xref="出エジプト記 29:11; レビ記 1:11; レビ記 4:24"> この雄の小羊は罪祭および燔祭をほふる場所、すなわち聖なる所で、これをほふらなければならない。愆祭は罪祭と同じく、祭司に帰するものであって、いと聖なる物である。</span>
<span className="v" id="v14" data-v="14" data-xref="出エジプト記 29:20; レビ記 8:23–24; コリント人への第二の手紙 7:1"> そして祭司はその愆祭の血を取り、これを清められる者の右の耳たぶと、右の手の親指と、右の足の親指とにつけなければならない。</span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 45:7; ヨハネによる福音書 3:34; ヨハネの第一の手紙 2:20"> 祭司はまた一ログの油を取って、これを自分の左の手のひらに注ぎ、</span>
<span className="v" id="v16" data-v="16" data-xref="レビ記 4:17; コリント人への第一の手紙 10:31; レビ記 4:6"> そして祭司は右の指を左の手のひらにある油に浸し、その指をもって、その油を七たび主の前に注がなければならない。</span>
<span className="v" id="v17" data-v="17" data-xref="ペテロの第一の手紙 1:2; エゼキエル書 36:27; レビ記 14:14"> 祭司は手のひらにある油の残りを、清められる者の右の耳たぶと、右の手の親指と、右の足の親指とに、さきにつけた愆祭の血の上につけなければならない。</span>
<span className="v" id="v18" data-v="18" data-xref="レビ記 4:26; コリント人への第二の手紙 1:21–22; エペソ人への手紙 1:17–18"> そして祭司は手のひらになお残っている油を、清められる者の頭につけ、主の前で、その人のためにあがないをしなければならない。</span>
<span className="v" id="v19" data-v="19" data-xref="レビ記 14:12; レビ記 5:1; レビ記 12:6–8"> また祭司は罪祭をささげて、汚れのゆえに、清められねばならぬ者のためにあがないをし、その後、燔祭のものをほふらなければならない。</span>
<span className="v" id="v20" data-v="20" data-xref="レビ記 14:10; エペソ人への手紙 5:2; レビ記 14:8"> そして祭司は燔祭と素祭とを祭壇の上にささげ、その人のために、あがないをしなければならない。こうしてその人は清くなるであろう。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="レビ記 5:7; レビ記 12:8; 箴言 17:5"> その人がもし貧しくて、それに手の届かない時は、自分のあがないのために揺り動かす愆祭として、雄の小羊一頭を取り、また素祭として油を混ぜた麦粉十分の一エパと、油一ログとを取り、</span>
<span className="v" id="v22" data-v="22" data-xref="エゼキエル書 7:16; イザヤ書 59:11; エレミヤ書 48:28"> さらにその手の届く山ばと二羽、または家ばとのひな二羽を取らなければならない。その一つは罪祭のため、他の一つは燔祭のためである。</span>
<span className="v" id="v23" data-v="23" data-xref="レビ記 14:10–11"> そして八日目に、その清めのために会見の幕屋の入口におる祭司のもと、主の前にこれを携えて行かなければならない。</span>
<span className="v" id="v24" data-v="24" data-xref="レビ記 14:12; レビ記 14:10"> 祭司はその愆祭の雄の小羊と、一ログの油とを取り、これを主の前に揺り動かして揺祭としなければならない。</span>
<span className="v" id="v25" data-v="25" data-xref="伝道の書 5:1; 詩篇 40:6; レビ記 14:14–20"> そして祭司は愆祭の雄の小羊をほふり、その愆祭の血を取って、これを清められる者の右の耳たぶと、右の手の親指と、右の足の親指とにつけなければならない。</span>
<span className="v" id="v26" data-v="26"> また祭司はその油を自分の左の手のひらに注ぎ、</span>
<span className="v" id="v27" data-v="27"> 祭司はその右の指をもって、左の手のひらにある油を、七たび主の前に注がなければならない。</span>
<span className="v" id="v28" data-v="28"> また祭司はその手のひらにある油を、清められる者の右の耳たぶと、右の手の親指と、右の足の親指とに、すなわち、愆祭の血をつけたところにつけなければならない。</span>
<span className="v" id="v29" data-v="29" data-xref="レビ記 14:18; ヨハネの第一の手紙 2:1–2; 出エジプト記 30:15–16"> また祭司は手のひらに残っている油を、清められる者の頭につけ、主の前で、その人のために、あがないをしなければならない。</span>
<span className="v" id="v30" data-v="30" data-xref="レビ記 14:22; ローマ人への手紙 8:3; レビ記 12:8"> その人はその手の届く山ばと一羽、または家ばとのひな一羽をささげなければならない。</span>
<span className="v" id="v31" data-v="31" data-xref="レビ記 14:18; レビ記 5:7"> すなわち、その手の届くものの一つを罪祭とし、他の一つを燔祭として素祭と共にささげなければならない。こうして祭司は清められる者のために、主の前にあがないをするであろう。</span>
<span className="v" id="v32" data-v="32" data-xref="レビ記 14:10; レビ記 14:21; マタイによる福音書 11:5"> これはらい病の患者で、その清めに必要なものに、手の届かない者のためのおきてである」。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33"> 主はまたモーセとアロンに言われた、</span>
<span className="v" id="v34" data-v="34" data-xref="申命記 32:49; 創世記 17:8; 民数記 32:22"> 「あなたがたに所有として与えるカナンの地に、あなたがたがはいる時、その所有の地において、家にわたしがらい病の患部を生じさせることがあれば、</span>
<span className="v" id="v35" data-v="35" data-xref="詩篇 91:10; 申命記 7:26; ゼカリヤ書 5:4"> その家の持ち主はきて、祭司に告げ、『患部のようなものが、わたしの家にあります』と言わなければならない。</span>
<span className="v" id="v36" data-v="36" data-xref="ヨハネの黙示録 18:4; ヘブル人への手紙 12:15; テモテヘの第二の手紙 2:17–18"> 祭司は命じて、祭司がその患部を見に行く前に、その家をあけさせ、その家にあるすべての物が汚されないようにし、その後、祭司は、はいってその家を見なければならない。</span>
<span className="v" id="v37" data-v="37" data-xref="レビ記 13:42; レビ記 13:3; レビ記 13:19–20"> その患部を見て、もしその患部が家の壁にあって、青または赤のくぼみをもち、それが壁よりも低く見えるならば、</span>
<span className="v" id="v38" data-v="38" data-xref="レビ記 13:50"> 祭司はその家を出て、家の入口にいたり、七日の間その家を閉鎖しなければならない。</span>
<span className="v" id="v39" data-v="39" data-xref="レビ記 13:36; レビ記 13:27; レビ記 13:22"> 祭司は七日目に、またきてそれを見、その患部がもし家の壁に広がっているならば、</span>
<span className="v" id="v40" data-v="40" data-xref="ヨハネの黙示録 2:20; テトスヘの手紙 3:10; コリント人への第一の手紙 5:5–6"> 祭司は命じて、その患部のある石を取り出し、町の外の汚れた物を捨てる場所に捨てさせ、</span>
<span className="v" id="v41" data-v="41" data-xref="イザヤ書 65:4; ヨハネの黙示録 22:15; マタイによる福音書 24:51"> またその家の内側のまわりを削らせ、その削ったしっくいを町の外の汚れた物を捨てる場所に捨てさせ、</span>
<span className="v" id="v42" data-v="42" data-xref="テモテヘの第二の手紙 2:2; テモテヘの第一の手紙 5:21–22; 歴代志下 17:7–9"> ほかの石を取って、元の石のところに入れさせ、またほかのしっくいを取って、家を塗らせなければならない。</span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="エレミヤ書 6:28–30; ユダの手紙 1:12; ペテロの第二の手紙 2:20"> このように石を取り出し、家を削り、塗りかえた後に、その患部がもし再び家に出るならば、</span>
<span className="v" id="v44" data-v="44" data-xref="レビ記 13:51–52; ゼカリヤ書 5:4"> 祭司はまたきて見なければならない。患部がもし家に広がっているならば、これは家にある悪性のらい病であって、これは汚れた物である。</span>
<span className="v" id="v45" data-v="45" data-xref="列王紀下 10:27; マタイによる福音書 24:2; 列王紀上 9:6–9"> その家は、こぼち、その石、その木、その家のしっくいは、ことごとく町の外の汚れた物を捨てる場所に運び出さなければならない。</span>
<span className="v" id="v46" data-v="46" data-xref="民数記 19:21–22; レビ記 22:6; レビ記 11:28"> その家が閉鎖されている日の間に、これにはいる者は夕まで汚れるであろう。</span>
<span className="v" id="v47" data-v="47" data-xref="レビ記 14:8–9; レビ記 11:25"> その家に寝る者はその衣服を洗わなければならない。その家で食する者も、その衣服を洗わなければならない。</span>
</div>
<div className="bp">
<span className="v" id="v48" data-v="48" data-xref="コリント人への第一の手紙 6:11; ヨブ記 5:18; マルコによる福音書 5:29"> しかし、祭司がはいって見て、もし家を塗りかえた後に、その患部が家に広がっていなければ、これはその患部がいえたのであるから、祭司はその家を清いものとしなければならない。</span>
<span className="v" id="v49" data-v="49" data-xref="レビ記 14:4"> また彼はその家を清めるために、小鳥二羽と、香柏の木と、緋の糸と、ヒソプとを取り、</span>
<span className="v" id="v50" data-v="50"> その小鳥の一羽を流れ水を盛った土の器の上で殺し、</span>
<span className="v" id="v51" data-v="51" data-xref="詩篇 51:7"> 香柏の木と、ヒソプと、緋の糸と、生きている小鳥とを取って、その殺した小鳥の血と流れ水に浸し、これを七たび家に注がなければならない。</span>
<span className="v" id="v52" data-v="52"> こうして祭司は小鳥の血と流れ水と、生きている小鳥と、香柏の木と、ヒソプと、緋の糸とをもって家を清め、</span>
<span className="v" id="v53" data-v="53" data-xref="レビ記 14:20; レビ記 14:7"> その生きている小鳥は町の外の野に放して、その家のために、あがないをしなければならない。こうして、それは清くなるであろう」。</span>
</div>
<div className="bp">
<span className="v" id="v54" data-v="54" data-xref="レビ記 15:32; レビ記 14:32; レビ記 6:9"> これはらい病のすべての患部、かいせん、</span>
<span className="v" id="v55" data-v="55" data-xref="レビ記 13:47–59"> および衣服と家のらい病、</span>
<span className="v" id="v56" data-v="56" data-xref="レビ記 13:2"> ならびに腫と、吹出物と、光る所とに関するおきてであって、</span>
<span className="v" id="v57" data-v="57" data-xref="レビ記 10:10; エゼキエル書 44:23; エレミヤ書 15:19"> いつそれが汚れているか、いつそれが清いかを教えるものである。これがらい病に関するおきてである。</span>
</div>

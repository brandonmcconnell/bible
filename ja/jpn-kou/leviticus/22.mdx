<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 主はまたモーセに言われた、</span>
<span className="v" id="v2" data-v="2" data-xref="レビ記 18:21; 申命記 15:19; レビ記 22:32"> 「アロンとその子たちに告げて、イスラエルの人々の聖なる物、すなわち、彼らがわたしにささげる物をみだりに用いて、わたしの聖なる名を汚さないようにさせなさい。わたしは主である。</span>
<span className="v" id="v3" data-v="3" data-xref="レビ記 7:20–21; 民数記 19:13; 詩篇 16:11"> 彼らに言いなさい、『あなたがたの代々の子孫のうち、だれでも、イスラエルの人々が主にささげる聖なる物に、汚れた身をもって近づく者があれば、その人はわたしの前から断たれるであろう。わたしは主である。</span>
<span className="v" id="v4" data-v="4" data-xref="レビ記 11:39; レビ記 15:2–3; レビ記 15:13–16"> アロンの子孫のうち、だれでも、らい病の者、また流出ある者は清くなるまで、聖なる物を食べてはならない。また、すべて死体によって汚れた物に触れた者、精を漏らした者、</span>
<span className="v" id="v5" data-v="5" data-xref="レビ記 11:43–44; レビ記 15:7; レビ記 15:19"> または、すべて人を汚す這うものに触れた者、または、どのような汚れにせよ、人を汚れさせる人に触れた者、</span>
<span className="v" id="v6" data-v="6" data-xref="レビ記 15:5; ヘブル人への手紙 10:22; ハガイ書 2:13"> このようなものに触れた人は夕まで汚れるであろう。彼はその身を水にすすがないならば、聖なる物を食べてはならない。</span>
<span className="v" id="v7" data-v="7" data-xref="レビ記 21:22; 申命記 18:3–4; コリント人への第一の手紙 9:13–14"> 日が入れば、彼は清くなるであろう。そののち、聖なる物を食べることができる。それは彼の食物だからである。</span>
<span className="v" id="v8" data-v="8" data-xref="レビ記 17:15; 出エジプト記 22:31; エゼキエル書 44:31"> 自然に死んだもの、または裂き殺されたものを食べ、それによって身を汚してはならない。わたしは主である。</span>
<span className="v" id="v9" data-v="9" data-xref="出エジプト記 28:43; 民数記 18:22; 民数記 18:32"> それゆえに、彼らはわたしの言いつけを守らなければならない。彼らがこれを汚し、これがために、罪を獲て死ぬことのないためである。わたしは彼らを聖別する主である。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="マタイによる福音書 12:4; サムエル記上 21:6; 出エジプト記 29:33"> すべて一般の人は聖なる物を食べてはならない。祭司の同居人や雇人も聖なる物を食べてはならない。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 17:13; 出エジプト記 12:44; 民数記 18:11–13"> しかし、祭司が金をもって人を買った時は、その者はこれを食べることができる。またその家に生れた者も祭司の食物を食べることができる。</span>
<span className="v" id="v12" data-v="12" data-xref="イザヤ書 40:13; レビ記 21:3"> もし祭司の娘が一般の人にとついだならば、彼女は聖なる供え物を食べてはならない。</span>
<span className="v" id="v13" data-v="13" data-xref="レビ記 10:14; 創世記 38:11; 民数記 18:11–19"> もし祭司の娘が、寡婦となり、または出されて、子供もなく、その父の家に帰り、娘の時のようであれば、その父の食物を食べることができる。ただし、一般の人は、すべてこれを食べてはならない。</span>
<span className="v" id="v14" data-v="14" data-xref="レビ記 27:15; レビ記 27:13; レビ記 5:15–19"> もし人があやまって聖なる物を食べるならば、それにその五分の一を加え、聖なる物としてこれを祭司に渡さなければならない。</span>
<span className="v" id="v15" data-v="15" data-xref="民数記 18:32; レビ記 19:8; エゼキエル書 22:26"> 祭司はイスラエルの人々が、主にささげる聖なる物を汚してはならない。</span>
<span className="v" id="v16" data-v="16" data-xref="レビ記 22:9; ペテロの第一の手紙 2:24; イザヤ書 53:11–12"> 人々が聖なる物を食べて、その罪のとがを負わないようにさせなければならない。わたしは彼らを聖別する主である』」。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17"> 主はまたモーセに言われた、</span>
<span className="v" id="v18" data-v="18" data-xref="レビ記 1:2; 申命記 12:6; 民数記 15:3"> 「アロンとその子たち、およびイスラエルのすべての人々に言いなさい、『イスラエルの家の者、またはイスラエルにおる他国人のうちのだれでも、誓願の供え物、または自発の供え物を燔祭として主にささげようとするならば、</span>
<span className="v" id="v19" data-v="19" data-xref="レビ記 1:10; レビ記 1:3; エペソ人への手紙 5:27"> あなたがたの受け入れられるように牛、羊、あるいはやぎの雄の全きものをささげなければならない。</span>
<span className="v" id="v20" data-v="20" data-xref="申命記 17:1; マラキ書 1:8; 申命記 15:21"> すべてきずのあるものはささげてはならない。それはあなたがたのために、受け入れられないからである。</span>
<span className="v" id="v21" data-v="21" data-xref="民数記 15:8; 民数記 15:3; レビ記 3:6"> もし人が特別の誓願をなすため、または自発の供え物のために、牛または羊を酬恩祭の犠牲として、主にささげようとするならば、その受け入れられるために、それは全きものでなければならない。それには、どんなきずもあってはならない。</span>
<span className="v" id="v22" data-v="22" data-xref="レビ記 22:20; マラキ書 1:8; レビ記 1:9"> すなわち獣のうちで、めくらのもの、折れた所のあるもの、切り取った所のあるもの、うみの出る者、かいせんの者、かさぶたのある者など、あなたがたは、このようなものを主にささげてはならない。また祭壇の上に、これらを火祭として、主にささげてはならない。</span>
<span className="v" id="v23" data-v="23" data-xref="レビ記 21:18"> 牛あるいは羊で、足の長すぎる者、または短すぎる者は、あなたがたが自発の供え物とすることはできるが、誓願の供え物としては受け入れられないであろう。</span>
<span className="v" id="v24" data-v="24" data-xref="レビ記 22:20; 申命記 23:1; レビ記 21:20"> あなたがたは、こうがんの破れたもの、つぶれたもの、裂けたもの、または切り取られたものを、主にささげてはならない。またあなたがたの国のうちで、このようなことを、行ってはならない。</span>
<span className="v" id="v25" data-v="25" data-xref="レビ記 21:8; エズラ記 6:8–10; 民数記 15:14–16"> また、あなたがたは異邦人の手からこれらのものを受けて、あなたがたの神の食物としてささげてはならない。これらのものには欠点があり、きずがあって、あなたがたのために受け入れられないからである』」。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26"> 主はまたモーセに言われた、</span>
<span className="v" id="v27" data-v="27" data-xref="出エジプト記 22:30; レビ記 19:23–24; レビ記 22:25"> 「牛、または羊、またはやぎが生れたならば、これを七日の間その母親のもとに置かなければならない。八日目からは主にささげる火祭として受け入れられるであろう。</span>
<span className="v" id="v28" data-v="28" data-xref="申命記 22:6–7; 申命記 14:21; 出エジプト記 34:26"> あなたがたは雌牛または雌羊をその子と同じ日にほふってはならない。</span>
<span className="v" id="v29" data-v="29" data-xref="詩篇 116:17; 詩篇 107:22; アモス書 4:5"> あなたがたが感謝の犠牲を主にささげるときは、あなたがたの受け入れられるようにささげなければならない。</span>
<span className="v" id="v30" data-v="30" data-xref="レビ記 7:15–18; 出エジプト記 16:19–20; レビ記 19:7"> これはその日のうちに食べなければならない。明くる日まで残しておいてはならない。わたしは主である。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="申命記 4:40; レビ記 19:37; 民数記 15:40"> あなたがたはわたしの戒めを守り、これを行わなければならない。わたしは主である。</span>
<span className="v" id="v32" data-v="32" data-xref="レビ記 18:21; ルカによる福音書 11:2; マタイによる福音書 6:9"> あなたがたはわたしの聖なる名を汚してはならない。かえって、わたしはイスラエルの人々のうちに聖とされなければならない。わたしはあなたがたを聖別する主である。</span>
<span className="v" id="v33" data-v="33" data-xref="レビ記 11:45; 出エジプト記 6:7; レビ記 25:38"> あなたがたの神となるために、あなたがたをエジプトの国から導き出した者である。わたしは主である」。</span>
</div>

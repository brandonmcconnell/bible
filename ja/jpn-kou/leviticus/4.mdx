<div className="bp">
<span className="v" id="v1" data-v="1"> 主はまたモーセに言われた、</span>
<span className="v" id="v2" data-v="2" data-xref="詩篇 19:12; ヘブル人への手紙 9:7; レビ記 4:27"> 「イスラエルの人々に言いなさい、『もし人があやまって罪を犯し、主のいましめにそむいて、してはならないことの一つをした時は次のようにしなければならない。</span>
<span className="v" id="v3" data-v="3" data-xref="ヘブル人への手紙 7:27–28; レビ記 4:14; レビ記 9:2"> すなわち、油注がれた祭司が罪を犯して、とがを民に及ぼすならば、彼はその犯した罪のために雄の全き子牛を罪祭として主にささげなければならない。</span>
<span className="v" id="v4" data-v="4" data-xref="レビ記 1:3–4; ダニエル書 9:26; イザヤ書 53:6"> その子牛を会見の幕屋の入口に連れてきて主の前に至り、その子牛の頭に手を置き、その子牛を主の前で、ほふらなければならない。</span>
<span className="v" id="v5" data-v="5" data-xref="レビ記 16:14; 民数記 19:4; レビ記 4:16–17"> 油注がれた祭司は、その子牛の血を取って、それを会見の幕屋に携え入り、</span>
<span className="v" id="v6" data-v="6" data-xref="レビ記 16:14; レビ記 14:18; レビ記 26:28"> そして祭司は指をその血に浸して、聖所の垂幕の前で主の前にその血を七たび注がなければならない。</span>
<span className="v" id="v7" data-v="7" data-xref="レビ記 8:15; レビ記 9:9; レビ記 16:18"> 祭司はまたその血を取り、主の前で会見の幕屋の中にある香ばしい薫香の祭壇の角に、それを塗らなければならない。その子牛の血の残りはことごとく会見の幕屋の入口にある燔祭の祭壇のもとに注がなければならない。</span>
<span className="v" id="v8" data-v="8" data-xref="レビ記 3:3–5; レビ記 4:26; レビ記 4:31"> またその罪祭の子牛から、すべての脂肪を取らなければならない。すなわち内臓をおおう脂肪と内臓の上のすべての脂肪、</span>
<span className="v" id="v9" data-v="9" data-xref="レビ記 3:4"> 二つの腎臓とその上の腰のあたりにある脂肪、ならびに腎臓と共に取られる肝臓の上の小葉である。</span>
<span className="v" id="v10" data-v="10"> これを取るには酬恩祭の犠牲の雄牛から取るのと同じようにしなければならない。そして祭司はそれを燔祭の祭壇の上で焼かなければならない。</span>
<span className="v" id="v11" data-v="11" data-xref="民数記 19:5; 出エジプト記 29:14; レビ記 9:8–11"> その子牛の皮とそのすべての肉、およびその頭と足と内臓と汚物など、</span>
<span className="v" id="v12" data-v="12" data-xref="ヘブル人への手紙 13:11; 出エジプト記 29:14; レビ記 16:27"> すべてその子牛の残りは、これを宿営の外の、清い場所なる灰捨場に携え出し、火をもってこれをたきぎの上で焼き捨てなければならない。すなわちこれは灰捨場で焼き捨てらるべきである。</span>
<span className="v" id="v13" data-v="13" data-xref="レビ記 5:17; レビ記 5:2–5; ホセア書 5:15"> もしイスラエルの全会衆があやまちを犯し、そのことが会衆の目に隠れていても、主のいましめにそむいて、してはならないことの一つをなして、とがを得たならば、</span>
<span className="v" id="v14" data-v="14" data-xref="レビ記 4:23; レビ記 4:3; レビ記 4:28"> その犯した罪が現れた時、会衆は雄の子牛を罪祭としてささげなければならない。すなわちそれを会見の幕屋の前に連れてきて、</span>
<span className="v" id="v15" data-v="15" data-xref="レビ記 1:4; レビ記 16:21; レビ記 8:14"> 会衆の長老たちは、主の前でその子牛の頭に手を置き、その子牛を主の前で、ほふらなければならない。</span>
<span className="v" id="v16" data-v="16" data-xref="レビ記 4:5–12; ヘブル人への手紙 9:12–14"> そして、油注がれた祭司は、その子牛の血を会見の幕屋に携え入り、</span>
<span className="v" id="v17" data-v="17" data-xref="レビ記 4:6–7"> 祭司は指をその血に浸し、垂幕の前で主の前に七たび注がなければならない。</span>
<span className="v" id="v18" data-v="18" data-xref="レビ記 4:7"> またその血を取って、会見の幕屋の中の主の前にある祭壇の角に、それを塗らなければならない。その血の残りはことごとく会見の幕屋の入口にある燔祭の祭壇のもとに注がなければならない。</span>
<span className="v" id="v19" data-v="19" data-xref="レビ記 5:6; レビ記 4:26; 民数記 15:25"> またそのすべての脂肪を取って祭壇の上で焼かなければならない。</span>
<span className="v" id="v20" data-v="20" data-xref="民数記 15:25; ヘブル人への手紙 10:10–12; レビ記 12:8"> すなわち祭司は罪祭の雄牛にしたように、この雄牛にも、しなければならない。こうして、祭司が彼らのためにあがないをするならば、彼らはゆるされるであろう。</span>
<span className="v" id="v21" data-v="21" data-xref="レビ記 16:15; マタイによる福音書 20:28; コリント人への第二の手紙 5:21"> そして、彼はその雄牛を宿営の外に携え出し、はじめの雄牛を焼き捨てたように、これを焼き捨てなければならない。これは会衆の罪祭である。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="レビ記 4:2; レビ記 4:13; 民数記 31:13"> またつかさたる者が罪を犯し、あやまって、その神、主のいましめにそむき、してはならないことの一つをして、とがを得、</span>
<span className="v" id="v23" data-v="23" data-xref="レビ記 4:14; ローマ人への手紙 8:3; 民数記 7:22"> もしその犯した罪を知るようになったときは、供え物として雄やぎの全きものを連れてきて、</span>
<span className="v" id="v24" data-v="24" data-xref="レビ記 3:13; レビ記 7:2; レビ記 4:3–35"> そのやぎの頭に手を置き、燔祭をほふる場所で、主の前にこれをほふらなければならない。これは罪祭である。</span>
<span className="v" id="v25" data-v="25" data-xref="レビ記 4:7; レビ記 4:18; レビ記 4:30"> 祭司は指でその罪祭の血を取り、燔祭の祭壇の角にそれを塗り、残りの血は燔祭の祭壇のもとに注がなければならない。</span>
<span className="v" id="v26" data-v="26" data-xref="レビ記 4:20; レビ記 4:31; レビ記 4:35"> また、そのすべての脂肪は、酬恩祭の犠牲の脂肪と同じように、祭壇の上で焼かなければならない。こうして、祭司が彼のためにその罪のあがないをするならば、彼はゆるされるであろう。</span>
<span className="v" id="v27" data-v="27" data-xref="レビ記 4:2; 民数記 15:27; レビ記 4:13"> また一般の人がもしあやまって罪を犯し、主のいましめにそむいて、してはならないことの一つをして、とがを得、</span>
<span className="v" id="v28" data-v="28" data-xref="レビ記 4:23; レビ記 4:3; レビ記 4:32"> その犯した罪を知るようになったときは、その犯した罪のために供え物として雌やぎの全きものを連れてきて、</span>
<span className="v" id="v29" data-v="29" data-xref="レビ記 4:4; レビ記 4:24; レビ記 1:4"> その罪祭の頭に手を置き、燔祭をほふる場所で、その罪祭をほふらなければならない。</span>
<span className="v" id="v30" data-v="30" data-xref="レビ記 4:7; レビ記 4:25; レビ記 4:34"> そして祭司は指でその血を取り、燔祭の祭壇の角にこれを塗り、残りの血をことごとく祭壇のもとに注がなければならない。</span>
<span className="v" id="v31" data-v="31" data-xref="レビ記 4:26; レビ記 4:35; レビ記 1:9"> またそのすべての脂肪は酬恩祭の犠牲から脂肪を取るのと同じように取り、これを祭壇の上で焼いて主にささげる香ばしいかおりとしなければならない。こうして祭司が彼のためにあがないをするならば、彼はゆるされるであろう。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="レビ記 4:28; ペテロの第一の手紙 3:18; ペテロの第一の手紙 2:22"> もし小羊を罪祭のために供え物として連れてくるならば、雌の全きものを連れてこなければならない。</span>
<span className="v" id="v33" data-v="33" data-xref="レビ記 4:29–31; レビ記 4:4"> その罪祭の頭に手を置き、燔祭をほふる場所で、これをほふり、罪祭としなければならない。</span>
<span className="v" id="v34" data-v="34" data-xref="レビ記 4:30; レビ記 4:25; レビ記 4:7"> そして祭司は指でその罪祭の血を取り、燔祭の祭壇の角にそれを塗り、残りの血はことごとく祭壇のもとに注がなければならない。</span>
<span className="v" id="v35" data-v="35" data-xref="レビ記 4:26; レビ記 4:20; レビ記 14:18"> またそのすべての脂肪は酬恩祭の犠牲から小羊の脂肪を取るのと同じように取り、祭司はこれを主にささげる火祭のように祭壇の上で焼かなければならない。こうして祭司が彼の犯した罪のためにあがないをするならば、彼はゆるされるであろう。</span>

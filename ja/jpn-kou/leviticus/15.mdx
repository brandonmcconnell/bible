<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="アモス書 3:7; レビ記 13:1; レビ記 11:1"> 主はまた、モーセとアロンに言われた、</span>
<span className="v" id="v2" data-v="2" data-xref="民数記 5:2; サムエル記下 3:29; レビ記 22:4"> 「イスラエルの人々に言いなさい、『だれでもその肉に流出があれば、その流出は汚れである。</span>
<span className="v" id="v3" data-v="3" data-xref="エゼキエル書 23:20; エゼキエル書 16:26; レビ記 12:3"> その流出による汚れは次のとおりである。すなわち、その肉の流出が続いていても、あるいは、その肉の流出が止まっていても、共に汚れである。</span>
<span className="v" id="v4" data-v="4" data-xref="テトスヘの手紙 1:15; エペソ人への手紙 5:11; コリント人への第一の手紙 15:33"> 流出ある者の寝た床はすべて汚れる。またその人のすわった物はすべて汚れるであろう。</span>
<span className="v" id="v5" data-v="5" data-xref="レビ記 11:25; レビ記 16:26; レビ記 17:15"> その床に触れる者は、その衣服を洗い、水に身をすすがなければならない。彼は夕まで汚れるであろう。</span>
<span className="v" id="v6" data-v="6" data-xref="ヤコブの手紙 4:8; イザヤ書 1:16"> 流出ある者のすわった物の上にすわる者は、その衣服を洗い、水に身をすすがなければならない。彼は夕まで汚れるであろう。</span>
<span className="v" id="v7" data-v="7"> 流出ある者の肉に触れる者は衣服を洗い、水に身をすすがなければならない。彼は夕まで汚れるであろう。</span>
<span className="v" id="v8" data-v="8" data-xref="ユダの手紙 1:4; ペテロの第二の手紙 2:1–3; イザヤ書 1:16"> 流出ある者のつばきが、清い者にかかったならば、その人は衣服を洗い、水に身をすすがなければならない。彼は夕まで汚れるであろう。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 31:34"> 流出ある者の乗った鞍はすべて汚れる。</span>
<span className="v" id="v10" data-v="10" data-xref="ヤコブの手紙 4:8; 詩篇 26:6; レビ記 15:8"> また彼の下になった物に触れる者は、すべて夕まで汚れるであろう。またそれらの物を運ぶ者は、その衣服を洗い、水に身をすすがなければならない。彼は夕まで汚れるであろう。</span>
<span className="v" id="v11" data-v="11"> 流出ある者が、水で手を洗わずに人に触れるならば、その人は衣服を洗い、水に身をすすがなければならない。彼は夕まで汚れるであろう。</span>
<span className="v" id="v12" data-v="12" data-xref="レビ記 6:28; レビ記 11:32–33; コリント人への第二の手紙 5:1"> 流出ある者が触れた土の器は砕かなければならない。木の器はすべて水で洗わなければならない。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="レビ記 14:8; レビ記 8:33; レビ記 15:28"> 流出ある者の流出がやんで清くなるならば、清めのために七日を数え、その衣服を洗い、流れ水に身をすすがなければならない。そうして清くなるであろう。</span>
<span className="v" id="v14" data-v="14" data-xref="レビ記 12:8; レビ記 12:6; ヘブル人への手紙 10:10"> 八日目に、山ばと二羽、または家ばとのひな二羽を取って、会見の幕屋の入口に行き、主の前に出て、それを祭司に渡さなければならない。</span>
<span className="v" id="v15" data-v="15" data-xref="レビ記 14:30–31; レビ記 4:26; マタイによる福音書 3:17"> 祭司はその一つを罪祭とし、他の一つを燔祭としてささげなければならない。こうして祭司はその人のため、その流出のために主の前に、あがないをするであろう。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="申命記 23:10–11; レビ記 22:4; レビ記 15:5"> 人がもし精を漏らすことがあれば、その全身を水にすすがなければならない。彼は夕まで汚れるであろう。</span>
<span className="v" id="v17" data-v="17"> すべて精のついた衣服および皮で作った物は水で洗わなければならない。これは夕まで汚れるであろう。</span>
<span className="v" id="v18" data-v="18" data-xref="レビ記 15:5; テサロニケ人への第一の手紙 4:3–5; コリント人への第一の手紙 6:12"> 男がもし女と寝て精を漏らすことがあれば、彼らは共に水に身をすすがなければならない。彼らは夕まで汚れるであろう。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="レビ記 12:2; マタイによる福音書 15:19; マルコによる福音書 5:25"> また女に流出があって、その身の流出がもし血であるならば、その女は七日のあいだ不浄である。すべてその女に触れる者は夕まで汚れるであろう。</span>
<span className="v" id="v20" data-v="20" data-xref="レビ記 15:4–9; 箴言 2:16–19; 箴言 6:35"> その不浄の間に、その女の寝た物はすべて汚れる。またその女のすわった物も、すべて汚れるであろう。</span>
<span className="v" id="v21" data-v="21" data-xref="ヨハネの黙示録 7:14; コリント人への第二の手紙 7:1; イザヤ書 22:14"> すべてその女の床に触れる者は、その衣服を洗い、水に身をすすがなければならない。彼は夕まで汚れるであろう。</span>
<span className="v" id="v22" data-v="22"> すべてその女のすわった物に触れる者は皆その衣服を洗い、水に身をすすがなければならない。彼は夕まで汚れるであろう。</span>
<span className="v" id="v23" data-v="23"> またその女が床の上、またはすわる物の上におる時、それに触れるならば、その人は夕まで汚れるであろう。</span>
<span className="v" id="v24" data-v="24" data-xref="レビ記 20:18; ペテロの第一の手紙 2:11; レビ記 18:19"> 男がもし、その女と寝て、その不浄を身にうけるならば、彼は七日のあいだ汚れるであろう。また彼の寝た床はすべて汚れるであろう。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="マルコによる福音書 5:25; マタイによる福音書 9:20; ルカによる福音書 8:43"> 女にもし、その不浄の時のほかに、多くの日にわたって血の流出があるか、あるいはその不浄の時を越して流出があれば、その汚れの流出の日の間は、すべてその不浄の時と同じように、その女は汚れた者である。</span>
<span className="v" id="v26" data-v="26"> その流出の日の間に、その女の寝た床は、すべてその女の不浄の時の床と同じようになる。すべてその女のすわった物は、不浄の汚れのように汚れるであろう。</span>
<span className="v" id="v27" data-v="27" data-xref="レビ記 15:21; ヘブル人への手紙 10:22; レビ記 17:15–16"> すべてこれらの物に触れる人は汚れる。その衣服を洗い、水に身をすすがなければならない。彼は夕まで汚れるであろう。</span>
<span className="v" id="v28" data-v="28" data-xref="レビ記 15:13–15; ガラテヤ人への手紙 3:13; エペソ人への手紙 1:6–7"> しかし、その女の流出がやんで、清くなるならば、自分のために、なお七日を数えなければならない。そして後、清くなるであろう。</span>
<span className="v" id="v29" data-v="29"> その女は八日目に山ばと二羽、または家ばとのひな二羽を自分のために取り、それを会見の幕屋の入口におる祭司のもとに携えて行かなければならない。</span>
<span className="v" id="v30" data-v="30"> 祭司はその一つを罪祭とし、他の一つを燔祭としてささげなければならない。こうして祭司はその女のため、その汚れの流出のために主の前に、あがないをするであろう。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="民数記 19:20; 民数記 19:13; エゼキエル書 5:11"> このようにしてあなたがたは、イスラエルの人々を汚れから離さなければならない。これは彼らのうちにあるわたしの幕屋を彼らが汚し、その汚れのために死ぬことのないためである』」。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="レビ記 11:46; レビ記 13:59; 民数記 6:13"> これは流出ある者、精を漏らして汚れる者、</span>
<span className="v" id="v33" data-v="33" data-xref="レビ記 15:19; レビ記 20:18; レビ記 15:24–25"> 不浄をわずらう女、ならびに男あるいは女の流出ある者、および不浄の女と寝る者に関するおきてである。</span>
</div>

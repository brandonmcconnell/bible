<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="エゼキエル書 44:25; レビ記 21:11; レビ記 10:6–7"> 主はまたモーセに言われた、「アロンの子なる祭司たちに告げて言いなさい、『民のうちの死人のために、身を汚す者があってはならない。</span>
<span className="v" id="v2" data-v="2" data-xref="テサロニケ人への第一の手紙 4:13; レビ記 18:6"> ただし、近親の者、すなわち、父、母、むすこ、娘、兄弟のため、</span>
<span className="v" id="v3" data-v="3"> また彼の近親で、まだ夫のない処女なる姉妹のためには、その身を汚してもよい。</span>
<span className="v" id="v4" data-v="4" data-xref="エゼキエル書 24:16–17"> しかし、夫にとついだ姉妹のためには、身を汚してはならない。</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 14:1; エゼキエル書 44:20; レビ記 19:27–28"> 彼らは頭の頂をそってはならない。ひげの両端をそり落してはならない。また身に傷をつけてはならない。</span>
<span className="v" id="v6" data-v="6" data-xref="レビ記 3:11; レビ記 18:21; ペテロの第一の手紙 2:9"> 彼らは神に対して聖でなければならない。また神の名を汚してはならない。彼らは主の火祭、すなわち、神の食物をささげる者であるから、聖でなければならない。</span>
<span className="v" id="v7" data-v="7" data-xref="レビ記 21:13–14; エゼキエル書 44:22; レビ記 21:8"> 彼らは遊女や汚れた女をめとってはならない。また夫に出された女をめとってはならない。祭司は神に対して聖なる者だからである。</span>
<span className="v" id="v8" data-v="8" data-xref="レビ記 20:7–8; レビ記 19:2; レビ記 11:44–45"> あなたは彼を聖としなければならない。彼はあなたの神の食物をささげる者だからである。彼はあなたにとって聖なる者でなければならない。あなたがたを聖とする主、すなわち、わたしは聖なる者だからである。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 38:24; レビ記 19:29; エゼキエル書 9:6"> 祭司の娘である者が、淫行をなして、その身を汚すならば、その父を汚すのであるから、彼女を火で焼かなければならない。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="レビ記 10:6–7; レビ記 16:32; マタイによる福音書 26:65"> その兄弟のうち、頭に注ぎ油を注がれ、職に任ぜられて、その衣服をつけ、大祭司となった者は、その髪の毛を乱してはならない。またその衣服を裂いてはならない。</span>
<span className="v" id="v11" data-v="11" data-xref="民数記 19:14; レビ記 21:1–2; 民数記 6:7"> 死人のところに、はいってはならない。また父のためにも母のためにも身を汚してはならない。</span>
<span className="v" id="v12" data-v="12" data-xref="レビ記 10:7; 出エジプト記 29:6–7; レビ記 8:9–12"> また聖所から出てはならない。神の聖所を汚してはならない。その神の注ぎ油による聖別が、彼の上にあるからである。わたしは主である。</span>
<span className="v" id="v13" data-v="13" data-xref="レビ記 21:7; コリント人への第二の手紙 11:2; ヨハネの黙示録 14:4"> 彼は処女を妻にめとらなければならない。</span>
<span className="v" id="v14" data-v="14" data-xref="レビ記 21:7; エゼキエル書 44:22"> 寡婦、出された女、汚れた女、遊女などをめとってはならない。ただ、自分の民のうちの処女を、妻にめとらなければならない。</span>
<span className="v" id="v15" data-v="15" data-xref="ローマ人への手紙 11:16; コリント人への第一の手紙 7:14; ネヘミヤ書 13:23–29"> そうすれば、彼は民のうちに、自分の子孫を汚すことはない。わたしは彼を聖別する主だからである』」。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16"> 主はまたモーセに言われた、</span>
<span className="v" id="v17" data-v="17" data-xref="詩篇 65:4; 民数記 16:5; レビ記 10:3"> 「アロンに告げて言いなさい、『あなたの代々の子孫で、だれでも身にきずのある者は近寄って、神の食物をささげてはならない。</span>
<span className="v" id="v18" data-v="18" data-xref="テモテヘの第一の手紙 3:2–3; レビ記 22:19–25; テトスヘの手紙 1:7"> すべて、その身にきずのある者は近寄ってはならない。すなわち、目しい、足なえ、鼻のかけた者、手足の不つりあいの者、</span>
<span className="v" id="v19" data-v="19"> 足の折れた者、手の折れた者、</span>
<span className="v" id="v20" data-v="20" data-xref="申命記 23:1; イザヤ書 56:3"> せむし、こびと、目にきずのある者、かいせんの者、かさぶたのある者、こうがんのつぶれた者などである。</span>
<span className="v" id="v21" data-v="21" data-xref="レビ記 21:6; レビ記 21:8; レビ記 21:17"> すべて祭司アロンの子孫のうち、身にきずのある者は近寄って、主の火祭をささげてはならない。彼は身にきずがあるから、神の食物をささげるために、近寄ってはならない。</span>
<span className="v" id="v22" data-v="22" data-xref="レビ記 2:3; 民数記 18:19; レビ記 24:8–9"> 彼は神の食物の聖なる物も、最も聖なる物も食べることができる。</span>
<span className="v" id="v23" data-v="23" data-xref="レビ記 21:12; エゼキエル書 44:9–14; 出エジプト記 30:6–8"> ただし、垂幕に近づいてはならない。また祭壇に近寄ってはならない。身にきずがあるからである。彼はわたしの聖所を汚してはならない。わたしはそれを聖別する主である』」。</span>
<span className="v" id="v24" data-v="24" data-xref="テモテヘの第一の手紙 1:18; マラキ書 2:1–7; テモテヘの第二の手紙 2:2"> モーセはこれをアロンとその子ら及びイスラエルのすべての人々に告げた。</span>

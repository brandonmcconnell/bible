<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 主はまたモーセとアロンに言われた、</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 24:8; レビ記 14:56; レビ記 14:3"> 「人がその身の皮に腫、あるいは吹出物、あるいは光る所ができ、これがその身の皮にらい病の患部のようになるならば、その人を祭司アロンまたは、祭司なるアロンの子たちのひとりのもとに、連れて行かなければならない。</span>
<span className="v" id="v3" data-v="3" data-xref="ローマ人への手紙 3:19–20; 使徒行伝 20:28; マラキ書 2:7"> 祭司はその身の皮の患部を見、その患部の毛がもし白く変り、かつ患部が、その身の皮よりも深く見えるならば、それはらい病の患部である。祭司は彼を見て、これを汚れた者としなければならない。</span>
<span className="v" id="v4" data-v="4" data-xref="民数記 12:15; コリント人への第一の手紙 4:5; テモテヘの第一の手紙 5:24"> もしまたその身の皮の光る所が白くて、皮よりも深く見えず、また毛も白く変っていないならば、祭司はその患者を七日のあいだ留め置かなければならない。</span>
<span className="v" id="v5" data-v="5"> 七日目に祭司はこれを見て、もし患部の様子に変りがなく、また患部が皮に広がっていないならば、祭司はその人をさらに七日のあいだ留め置かなければならない。</span>
<span className="v" id="v6" data-v="6" data-xref="レビ記 11:25; レビ記 14:8; 申命記 32:5"> 七日目に祭司は再びその人を見て、患部がもし薄らぎ、また患部が皮に広がっていないならば、祭司はこれを清い者としなければならない。これは吹出物である。その人は衣服を洗わなければならない。そして清くなるであろう。</span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 38:3; レビ記 13:35–36; テモテヘの第二の手紙 2:16–17"> しかし、その人が祭司に見せて清い者とされた後に、その吹出物が皮に広くひろがるならば、再び祭司にその身を見せなければならない。</span>
<span className="v" id="v8" data-v="8" data-xref="マタイによる福音書 15:7–8; ピリピ人への手紙 3:18–19; 使徒行伝 8:21"> 祭司はこれを見て、その吹出物が皮に広がっているならば、祭司はその人を汚れた者としなければならない。これはらい病である。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9"> もし人にらい病の患部があるならば、その人を祭司のもとに連れて行かなければならない。</span>
<span className="v" id="v10" data-v="10" data-xref="列王紀下 5:27; 歴代志下 26:19–20; レビ記 13:14–15"> 祭司がこれを見て、その皮に白い腫があり、その毛も白く変り、かつその腫に生きた生肉が見えるならば、</span>
<span className="v" id="v11" data-v="11"> これは古いらい病がその身の皮にあるのであるから、祭司はその人を汚れた者としなければならない。その人は汚れた者であるから、これを留め置くに及ばない。</span>
<span className="v" id="v12" data-v="12" data-xref="ヨハネの第一の手紙 1:8–10; ヨブ記 42:6; ローマ人への手紙 7:14"> もしらい病が広く皮に出て、そのらい病が、その患者の皮を頭から足まで、ことごとくおおい、祭司の見るところすべてに及んでおれば、</span>
<span className="v" id="v13" data-v="13" data-xref="ヨハネによる福音書 9:41; イザヤ書 64:6"> 祭司はこれを見、もしらい病がその身をことごとくおおっておれば、その患者を清い者としなければならない。それはことごとく白く変ったから、彼は清い者である。</span>
<span className="v" id="v14" data-v="14"> しかし、もし生肉がその人に現れておれば、汚れた者である。</span>
<span className="v" id="v15" data-v="15"> 祭司はその生肉を見て、その人を汚れた者としなければならない。生肉は汚れたものであって、それはらい病である。</span>
<span className="v" id="v16" data-v="16" data-xref="ガラテヤ人への手紙 1:14–16; ローマ人への手紙 7:14–24; ピリピ人への手紙 3:6–8"> もしまたその生肉が再び白く変るならば、その人は祭司のもとに行かなければならない。</span>
<span className="v" id="v17" data-v="17"> 祭司はその人を見て、もしその患部が白く変っておれば、祭司はその患者を清い者としなければならない。その人は清い者である。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="出エジプト記 9:9; イザヤ書 38:21; 詩篇 38:3–7"> また身の皮に腫物があったが、直って、</span>
<span className="v" id="v19" data-v="19" data-xref="レビ記 13:24"> その腫物の場所に白い腫、または赤みをおびた白い光る所があれば、これを祭司に見せなければならない。</span>
<span className="v" id="v20" data-v="20" data-xref="ヨハネによる福音書 5:14; レビ記 13:3; ペテロの第二の手紙 2:20"> 祭司はこれを見て、もし皮よりも低く見え、その毛が白く変っていれば、祭司はその人を汚れた者としなければならない。それは腫物に起ったらい病の患部だからである。</span>
<span className="v" id="v21" data-v="21" data-xref="コリント人への第一の手紙 5:5"> しかし、祭司がこれを見て、もしその所に白い毛がなく、また皮よりも低い所がなく、かえって薄らいでいるならば、祭司はその人を七日のあいだ留め置かなければならない。</span>
<span className="v" id="v22" data-v="22"> そしてもし皮に広くひろがっているならば、祭司はその人を汚れた者としなければならない。それは患部だからである。</span>
<span className="v" id="v23" data-v="23" data-xref="ガラテヤ人への手紙 6:1; ヨブ記 34:31–32; マタイによる福音書 26:75"> しかし、その光る所がもしその所にとどまって広がらなければ、それは腫物の跡である。祭司はその人を清い者としなければならない。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="イザヤ書 3:24"> また身の皮にやけどがあって、そのやけどの生きた肉がもし赤みをおびた白、または、ただ白くて光る所となるならば、</span>
<span className="v" id="v25" data-v="25" data-xref="レビ記 13:18–20; レビ記 13:4"> 祭司はこれを見なければならない。そしてもし、その光る所にある毛が白く変って、そこが皮よりも深く見えるならば、これはやけどに生じたらい病である。祭司はその人を汚れた者としなければならない。これはらい病の患部だからである。</span>
<span className="v" id="v26" data-v="26" data-xref="レビ記 13:23; レビ記 13:4–5"> けれども祭司がこれを見て、その光る所に白い毛がなく、また皮よりも低い所がなく、かえって薄らいでいるならば、祭司はその人を七日のあいだ留め置き、</span>
<span className="v" id="v27" data-v="27"> 七日目に祭司は彼を見なければならない。もし皮に広くひろがっているならば、祭司はその人を汚れた者としなければならない。これはらい病の患部だからである。</span>
<span className="v" id="v28" data-v="28"> もしその光る所が、その所にとどまって、皮に広がらずに、かえって薄らいでいるならば、これはやけどの腫である。祭司はその人を清い者としなければならない。これはやけどの跡だからである。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="イザヤ書 9:15; マタイによる福音書 13:14–15; コリント人への第二の手紙 4:3–4"> 男あるいは女がもし、頭またはあごに患部が生じたならば、</span>
<span className="v" id="v30" data-v="30" data-xref="レビ記 13:34–37; レビ記 14:54"> 祭司はその患部を見なければならない。もしそれが皮よりも深く見え、またそこに黄色の細い毛があるならば、祭司はその人を汚れた者としなければならない。それはかいせんであって、頭またはあごのらい病だからである。</span>
<span className="v" id="v31" data-v="31"> また祭司がそのかいせんの患部を見て、もしそれが皮よりも深く見えず、またそこに黒い毛がないならば、祭司はそのかいせんの患者を七日のあいだ留め置き、</span>
<span className="v" id="v32" data-v="32" data-xref="レビ記 13:30; マタイによる福音書 23:5; ルカによる福音書 18:9–12"> 七日目に祭司はその患部を見なければならない。そのかいせんがもし広がらず、またそこに黄色の毛がなく、そのかいせんが皮よりも深く見えないならば、</span>
<span className="v" id="v33" data-v="33"> その人は身をそらなければならない。ただし、そのかいせんをそってはならない。祭司はそのかいせんのある者をさらに七日のあいだ留め置き、</span>
<span className="v" id="v34" data-v="34" data-xref="ユダの手紙 1:22; ヨハネの第一の手紙 4:1; ヨハネの黙示録 2:2"> 七日目に祭司はそのかいせんを見なければならない。もしそのかいせんが皮に広がらず、またそれが皮よりも深く見えないならば、祭司はその人を清い者としなければならない。その人はまたその衣服を洗わなければならない。そして清くなるであろう。</span>
<span className="v" id="v35" data-v="35" data-xref="レビ記 13:27; テモテヘの第二の手紙 2:16–17; レビ記 13:7"> しかし、もし彼が清い者とされた後に、そのかいせんが、皮に広くひろがるならば、</span>
<span className="v" id="v36" data-v="36"> 祭司はその人を見なければならない。もしそのかいせんが皮に広がっているならば、祭司は黄色の毛を捜すまでもなく、その人は汚れた者である。</span>
<span className="v" id="v37" data-v="37"> しかし、もしそのかいせんの様子に変りなく、そこに黒い毛が生じているならば、そのかいせんは直ったので、その人は清い。祭司はその人を清い者としなければならない。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38"> また男あるいは女がもし、その身の皮に光る所、すなわち白い光る所があるならば、</span>
<span className="v" id="v39" data-v="39" data-xref="ローマ人への手紙 7:22–25; ヤコブの手紙 3:2; 伝道の書 7:20"> 祭司はこれを見なければならない。もしその身の皮の光る所が、鈍い白であるならば、これはただ白せんがその皮に生じたのであって、その人は清い。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="ガラテヤ人への手紙 4:13; ローマ人への手紙 8:10; 雅歌 5:11"> 人がもしその頭から毛が抜け落ちても、それがはげならば清い。</span>
<span className="v" id="v41" data-v="41"> もしその額の毛が抜け落ちても、それが額のはげならば清い。</span>
<span className="v" id="v42" data-v="42"> けれども、もしそのはげ頭または、はげ額に赤みをおびた白い患部があるならば、それはそのはげ頭または、はげ額にらい病が発したのである。</span>
<span className="v" id="v43" data-v="43"> 祭司はこれを見なければならない。もしそのはげ頭または、はげ額の患部の腫が白く赤みをおびて、身の皮にらい病があらわれているならば、</span>
<span className="v" id="v44" data-v="44" data-xref="ペテロの第二の手紙 2:1–2; マタイによる福音書 6:23; イザヤ書 1:5"> その人はらい病に冒された者であって、汚れた者である。祭司はその人を確かに汚れた者としなければならない。患部が頭にあるからである。</span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="ミカ書 3:7; レビ記 10:6; エゼキエル書 24:17"> 患部のあるらい病人は、その衣服を裂き、その頭を現し、その口ひげをおおって『汚れた者、汚れた者』と呼ばわらなければならない。</span>
<span className="v" id="v46" data-v="46" data-xref="列王紀下 7:3; 列王紀下 15:5; 歴代志下 26:21"> その患部が身にある日の間は汚れた者としなければならない。その人は汚れた者であるから、離れて住まなければならない。すなわち、そのすまいは宿営の外でなければならない。</span>
</div>
<div className="bp">
<span className="v" id="v47" data-v="47" data-xref="ユダの手紙 1:23; ローマ人への手紙 13:12; エゼキエル書 16:16"> また衣服にらい病の患部が生じた時は、それが羊毛の衣服であれ、亜麻の衣服であれ、</span>
<span className="v" id="v48" data-v="48" data-xref="レビ記 13:51; ヨハネの黙示録 3:4; 申命記 8:11"> あるいは亜麻または羊毛の縦糸であれ、横糸であれ、あるいは皮であれ、皮で作ったどのような物であれ、</span>
<span className="v" id="v49" data-v="49"> もしその衣服あるいは皮、あるいは縦糸、あるいは横糸、あるいは皮で作ったどのような物であれ、その患部が青みをおびているか、あるいは赤みをおびているならば、これはらい病の患部である。これを祭司に見せなければならない。</span>
<span className="v" id="v50" data-v="50" data-xref="エゼキエル書 44:23"> 祭司はその患部を見て、その患部のある物を七日のあいだ留め置き、</span>
<span className="v" id="v51" data-v="51" data-xref="レビ記 14:44"> 七日目に患部を見て、もしその衣服、あるいは縦糸、あるいは横糸、あるいは皮、またどのように用いられている皮であれ、患部が広がっているならば、その患部は悪性のらい病であって、それは汚れた物である。</span>
<span className="v" id="v52" data-v="52" data-xref="レビ記 11:35; レビ記 11:33; レビ記 14:44–45"> 彼はその患部のある衣服、あるいは羊毛、または亜麻の縦糸、または横糸、あるいはすべて皮で作った物を焼かなければならない。これは悪性のらい病であるから、その物を火で焼かなければならない。</span>
</div>
<div className="bp">
<span className="v" id="v53" data-v="53"> しかし、祭司がこれを見て、もし患部がその衣服、あるいは縦糸、あるいは横糸、あるいはすべて皮で作った物に広がっていないならば、</span>
<span className="v" id="v54" data-v="54"> 祭司は命じて、その患部のある物を洗わせ、さらに七日の間これを留め置かなければならない。</span>
<span className="v" id="v55" data-v="55" data-xref="エゼキエル書 24:13; ヘブル人への手紙 6:4–8; ペテロの第二の手紙 2:20–22"> そしてその患部を洗った後、祭司はそれを見て、もし患部の色が変らなければ、患部が広がらなくても、それは汚れた物である。それが表にあっても裏にあっても腐れであるから、それを火で焼かなければならない。</span>
</div>
<div className="bp">
<span className="v" id="v56" data-v="56"> しかし、祭司がこれを見て、それを洗った後に、その患部が薄らいだならば、その衣服、あるいは皮、あるいは縦糸、あるいは横糸から、それを切り取らなければならない。</span>
<span className="v" id="v57" data-v="57" data-xref="マタイによる福音書 22:7; ヨハネの黙示録 21:8; マタイによる福音書 3:12"> しかし、なおその衣服、あるいは縦糸、あるいは横糸、あるいはすべて皮で作った物にそれが現れれば、それは再発したのである。その患部のある物を火で焼かなければならない。</span>
<span className="v" id="v58" data-v="58" data-xref="列王紀下 5:14; ヨハネの黙示録 1:5; 詩篇 51:2"> また洗った衣服、あるいは縦糸、あるいは横糸、あるいはすべて皮で作った物から、患部が消え去るならば、再びそれを洗わなければならない。そうすれば清くなるであろう」。</span>
</div>
<div className="bp">
<span className="v" id="v59" data-v="59"> これは羊毛または亜麻の衣服、あるいは縦糸、あるいは横糸、あるいはすべて皮で作った物に生じるらい病の患部について、それを清い物とし、または汚れた物とするためのおきてである。</span>
</div>
</div>

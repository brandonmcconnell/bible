<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 主はまたモーセに言われた、</span>
<span className="v" id="v2" data-v="2" data-xref="レビ記 23:4; レビ記 23:37; 民数記 29:39"> 「イスラエルの人々に言いなさい、『あなたがたが、ふれ示して聖会とすべき主の定めの祭は次のとおりである。これらはわたしの定めの祭である。</span>
<span className="v" id="v3" data-v="3" data-xref="レビ記 19:3; 出エジプト記 23:12; 出エジプト記 35:2–3"> 六日の間は仕事をしなければならない。第七日は全き休みの安息日であり、聖会である。どのような仕事もしてはならない。これはあなたがたのすべてのすまいにおいて守るべき主の安息日である。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="レビ記 23:2; 出エジプト記 23:14; レビ記 23:37"> その時々に、あなたがたが、ふれ示すべき主の定めの祭なる聖会は次のとおりである。</span>
<span className="v" id="v5" data-v="5" data-xref="ヨシュア記 5:10; 申命記 16:1–8; 民数記 28:16–17"> 正月の十四日の夕は主の過越の祭である。</span>
<span className="v" id="v6" data-v="6" data-xref="出エジプト記 34:18; 申命記 16:8; 出エジプト記 12:15–16"> またその月の十五日は主の種入れぬパンの祭である。あなたがたは七日の間は種入れぬパンを食べなければならない。</span>
<span className="v" id="v7" data-v="7" data-xref="民数記 28:18–25; レビ記 23:8; レビ記 23:21"> その初めの日に聖会を開かなければならない。どんな労働もしてはならない。</span>
<span className="v" id="v8" data-v="8"> あなたがたは七日の間、主に火祭をささげなければならない。第七日には、また聖会を開き、どのような労働もしてはならない』」。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9"> 主はまたモーセに言われた、</span>
<span className="v" id="v10" data-v="10" data-xref="出エジプト記 34:26; 出エジプト記 23:19; 申命記 16:9"> 「イスラエルの人々に言いなさい、『わたしが与える地にはいって穀物を刈り入れるとき、あなたがたは穀物の初穂の束を、祭司のところへ携えてこなければならない。</span>
<span className="v" id="v11" data-v="11" data-xref="出エジプト記 29:24; レビ記 10:14; レビ記 9:21"> 彼はあなたがたの受け入れられるように、その束を主の前に揺り動かすであろう。すなわち、祭司は安息日の翌日に、これを揺り動かすであろう。</span>
<span className="v" id="v12" data-v="12" data-xref="ヘブル人への手紙 10:10–12; ペテロの第一の手紙 1:19; レビ記 1:10"> またその束を揺り動かす日に、一歳の雄の小羊の全きものを燔祭として主にささげなければならない。</span>
<span className="v" id="v13" data-v="13" data-xref="レビ記 2:14–16; ヨエル書 1:9; 民数記 28:10"> その素祭には油を混ぜた麦粉十分の二エパを用い、これを主にささげて火祭とし、香ばしいかおりとしなければならない。またその灌祭には、ぶどう酒一ヒンの四分の一を用いなければならない。</span>
<span className="v" id="v14" data-v="14" data-xref="出エジプト記 34:26; 創世記 4:4–5; レビ記 3:17"> あなたがたの神にこの供え物をささげるその日まで、あなたがたはパンも、焼麦も、新穀も食べてはならない。これはあなたがたのすべてのすまいにおいて、代々ながく守るべき定めである。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="レビ記 23:10–11; レビ記 25:8; 申命記 16:9–10"> また安息日の翌日、すなわち、揺祭の束をささげた日から満七週を数えなければならない。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行伝 2:1; 民数記 28:26"> すなわち、第七の安息日の翌日までに、五十日を数えて、新穀の素祭を主にささげなければならない。</span>
<span className="v" id="v17" data-v="17" data-xref="レビ記 23:10; 出エジプト記 34:26; 出エジプト記 34:22"> またあなたがたのすまいから、十分の二エパの麦粉に種を入れて焼いたパン二個を携えてきて揺祭としなければならない。これは初穂として主にささげるものである。</span>
<span className="v" id="v18" data-v="18" data-xref="民数記 28:27–31; レビ記 23:12–13; マラキ書 1:13–14"> あなたがたはまたパンのほかに、一歳の全き小羊七頭と、若き雄牛一頭と、雄羊二頭をささげなければならない。すなわち、これらをその素祭および灌祭とともに主にささげて燔祭としなければならない。これは火祭であって、主に香ばしいかおりとなるであろう。</span>
<span className="v" id="v19" data-v="19" data-xref="民数記 28:30; レビ記 4:23–28; レビ記 7:11–18"> また雄やぎ一頭を罪祭としてささげ、一歳の小羊二頭を酬恩祭の犠牲としてささげなければならない。</span>
<span className="v" id="v20" data-v="20" data-xref="申命記 18:4; エペソ人への手紙 2:14; 民数記 18:8–12"> そして祭司はその初穂のパンと共に、この二頭の小羊を主の前に揺祭として揺り動かさなければならない。これらは主にささげる聖なる物であって、祭司に帰するであろう。</span>
<span className="v" id="v21" data-v="21" data-xref="レビ記 23:2; レビ記 23:4; 民数記 18:23"> あなたがたは、その日にふれ示して、聖会を開かなければならない。どのような労働もしてはならない。これはあなたがたのすべてのすまいにおいて、代々ながく守るべき定めである。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="申命記 24:19–21; レビ記 19:9–10; イザヤ書 58:10"> あなたがたの地の穀物を刈り入れるときは、その刈入れにあたって、畑のすみずみまで刈りつくしてはならない。またあなたの穀物の落ち穂を拾ってはならない。貧しい者と寄留者のために、それを残しておかなければならない。わたしはあなたがたの神、主である』」。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23"> 主はまたモーセに言われた、</span>
<span className="v" id="v24" data-v="24" data-xref="コリント人への第一の手紙 15:52; テサロニケ人への第一の手紙 4:16; レビ記 25:9"> 「イスラエルの人々に言いなさい、『七月一日をあなたがたの安息の日とし、ラッパを吹き鳴らして記念する聖会としなければならない。</span>
<span className="v" id="v25" data-v="25" data-xref="レビ記 23:21"> どのような労働もしてはならない。しかし、主に火祭をささげなければならない』」。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26"> 主はまたモーセに言われた、</span>
<span className="v" id="v27" data-v="27" data-xref="レビ記 16:29–31; 出エジプト記 30:10; レビ記 16:24"> 「特にその七月の十日は贖罪の日である。あなたがたは聖会を開き、身を悩まし、主に火祭をささげなければならない。</span>
<span className="v" id="v28" data-v="28" data-xref="ゼカリヤ書 3:9; レビ記 16:34; ヘブル人への手紙 10:10"> その日には、どのような仕事もしてはならない。これはあなたがたのために、あなたがたの神、主の前にあがないをなすべき贖罪の日だからである。</span>
<span className="v" id="v29" data-v="29" data-xref="創世記 17:14; 民数記 5:2; レビ記 23:27"> すべてその日に身を悩まさない者は、民のうちから断たれるであろう。</span>
<span className="v" id="v30" data-v="30" data-xref="レビ記 20:3; ゼパニヤ書 2:5; エレミヤ書 15:7"> またすべてその日にどのような仕事をしても、その人をわたしは民のうちから滅ぼし去るであろう。</span>
<span className="v" id="v31" data-v="31"> あなたがたはどのような仕事もしてはならない。これはあなたがたのすべてのすまいにおいて、代々ながく守るべき定めである。</span>
<span className="v" id="v32" data-v="32" data-xref="レビ記 16:31; マタイによる福音書 11:28–30; 詩篇 69:10–11"> これはあなたがたの全き休みの安息日である。あなたがたは身を悩まさなければならない。またその月の九日の夕には、その夕から次の夕まで安息を守らなければならない」。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33"> 主はまたモーセに言われた、</span>
<span className="v" id="v34" data-v="34" data-xref="ヨハネによる福音書 7:2; ネヘミヤ書 8:14; エズラ記 3:4"> 「イスラエルの人々に言いなさい、『その七月の十五日は仮庵の祭である。七日の間、主の前にそれを守らなければならない。</span>
<span className="v" id="v35" data-v="35" data-xref="レビ記 23:24–25; レビ記 23:7–8"> 初めの日に聖会を開かなければならない。どのような労働もしてはならない。</span>
<span className="v" id="v36" data-v="36" data-xref="ネヘミヤ書 8:18; ヨハネによる福音書 7:37; 歴代志下 7:8–11"> また七日の間、主に火祭をささげなければならない。八日目には聖会を開き、主に火祭をささげなければならない。これは聖会の日であるから、どのような労働もしてはならない。</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="レビ記 23:2; レビ記 23:4; 伝道の書 3:1"> これらは主の定めの祭であって、あなたがたがふれ示して聖会とし、主に火祭すなわち、燔祭、素祭、犠牲および灌祭を、そのささぐべき日にささげなければならない。</span>
<span className="v" id="v38" data-v="38" data-xref="民数記 29:39; レビ記 19:3; エズラ記 2:68–69"> このほかに主の安息日があり、またほかに、あなたがたのささげ物があり、またほかに、あなたがたのもろもろの誓願の供え物があり、またそのほかに、あなたがたのもろもろの自発の供え物がある。これらは皆あなたがたが主にささげるものである。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="出エジプト記 23:16; 申命記 16:13; レビ記 23:34"> あなたがたが、地の産物を集め終ったときは、七月の十五日から七日のあいだ、主の祭を守らなければならない。すなわち、初めの日にも安息をし、八日目にも安息をしなければならない。</span>
<span className="v" id="v40" data-v="40" data-xref="ピリピ人への手紙 4:4; ヨハネの黙示録 7:9; 申命記 16:14–15"> 初めの日に、美しい木の実と、なつめやしの枝と、茂った木の枝と、谷のはこやなぎの枝を取って、七日の間あなたがたの神、主の前に楽しまなければならない。</span>
<span className="v" id="v41" data-v="41" data-xref="民数記 29:12; ネヘミヤ書 8:18"> あなたがたは年に七日の間、主にこの祭を守らなければならない。これはあなたがたの代々ながく守るべき定めであって、七月にこれを守らなければならない。</span>
<span className="v" id="v42" data-v="42" data-xref="ネヘミヤ書 8:14–17; 創世記 33:17; 民数記 24:5"> あなたがたは七日の間、仮庵に住み、イスラエルで生れた者はみな仮庵に住まなければならない。</span>
<span className="v" id="v43" data-v="43" data-xref="申命記 31:10–13; 詩篇 78:5–6; 出エジプト記 13:14"> これはわたしがイスラエルの人々をエジプトの国から導き出したとき、彼らを仮庵に住まわせた事を、あなたがたの代々の子孫に知らせるためである。わたしはあなたがたの神、主である』」。</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="レビ記 23:1–2; マタイによる福音書 18:20; レビ記 21:24"> モーセは主の定めの祭をイスラエルの人々に告げた。</span>
</div>

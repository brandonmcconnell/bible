<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数記 26:61; 申命記 12:32; レビ記 16:12"> さてアロンの子ナダブとアビフとは、おのおのその香炉を取って火をこれに入れ、薫香をその上に盛って、異火を主の前にささげた。これは主の命令に反することであったので、</span>
<span className="v" id="v2" data-v="2" data-xref="民数記 26:61; 民数記 16:35; レビ記 9:24"> 主の前から火が出て彼らを焼き滅ぼし、彼らは主の前に死んだ。</span>
<span className="v" id="v3" data-v="3" data-xref="出エジプト記 19:22; レビ記 21:6; イザヤ書 49:3"> その時モーセはアロンに言った、「主は、こう仰せられた。すなわち『わたしは、わたしに近づく者のうちに、わたしの聖なることを示し、すべての民の前に栄光を現すであろう』」。アロンは黙していた。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="出エジプト記 6:22; 出エジプト記 6:18; 使徒行伝 5:6"> モーセはアロンの叔父ウジエルの子ミシヤエルとエルザパンとを呼び寄せて彼らに言った、「近寄って、あなたがたの兄弟たちを聖所の前から、宿営の外に運び出しなさい」。</span>
<span className="v" id="v5" data-v="5" data-xref="レビ記 8:13"> 彼らは近寄って、彼らをその服のまま宿営の外に運び出し、モーセの言ったようにした。</span>
<span className="v" id="v6" data-v="6" data-xref="ヨシュア記 22:18; ヨシュア記 7:1; 民数記 16:22"> モーセはまたアロンおよびその子エレアザルとイタマルとに言った、「あなたがたは髪の毛を乱し、また衣服を裂いてはならない。あなたがたが死ぬことのないため、また主の怒りが、すべての会衆に及ぶことのないためである。ただし、あなたがたの兄弟イスラエルの全家は、主が火をもって焼き滅ぼしたもうたことを嘆いてもよい。</span>
<span className="v" id="v7" data-v="7" data-xref="レビ記 21:12; レビ記 8:30; 使徒行伝 10:38"> また、あなたがたは死ぬことのないように、会見の幕屋の入口から外へ出てはならない。あなたがたの上に主の注ぎ油があるからである」。彼らはモーセの言葉のとおりにした。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8"> 主はアロンに言われた、</span>
<span className="v" id="v9" data-v="9" data-xref="ルカによる福音書 1:15; テモテヘの第一の手紙 3:3; エペソ人への手紙 5:18"> 「あなたも、あなたの子たちも会見の幕屋にはいる時には、死ぬことのないように、ぶどう酒と濃い酒を飲んではならない。これはあなたがたが代々永く守るべき定めとしなければならない。</span>
<span className="v" id="v10" data-v="10" data-xref="エゼキエル書 22:26; ペテロの第一の手紙 1:14–16; レビ記 11:47"> これはあなたがたが聖なるものと俗なるもの、汚れたものと清いものとの区別をすることができるため、</span>
<span className="v" id="v11" data-v="11" data-xref="マタイによる福音書 28:20; マラキ書 2:7; ネヘミヤ書 8:8"> また主がモーセによって語られたすべての定めを、イスラエルの人々に教えることができるためである」。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="レビ記 21:22; 民数記 18:9–10; レビ記 7:9"> モーセはまたアロンおよびその残っている子エレアザルとイタマルとに言った、「あなたがたは主の火祭のうちから素祭の残りを取り、パン種を入れずに、これを祭壇のかたわらで食べなさい。これはいと聖なる物である。</span>
<span className="v" id="v13" data-v="13" data-xref="レビ記 2:3; レビ記 6:16; 民数記 18:10"> これは主の火祭のうちからあなたの受ける分、またあなたの子たちの受ける分であるから、あなたがたはこれを聖なる所で食べなければならない。わたしはこのように命じられたのである。</span>
<span className="v" id="v14" data-v="14" data-xref="民数記 18:11; レビ記 7:29–34; 出エジプト記 29:24–28"> また揺り動かした胸とささげたももとは、あなたとあなたのむすこ、娘たちがこれを清い所で食べなければならない。これはイスラエルの人々の酬恩祭の犠牲の中からあなたの分、あなたの子たちの分として与えられるものだからである。</span>
<span className="v" id="v15" data-v="15" data-xref="レビ記 7:34; 創世記 17:13; レビ記 7:29–30"> 彼らはそのささげたももと揺り動かした胸とを、火祭の脂肪と共に携えてきて、これを主の前に揺り動かして揺祭としなければならない。これは主がお命じになったように、長く受くべき分としてあなたと、あなたの子たちとに帰するであろう」。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="レビ記 9:3; レビ記 9:15; レビ記 6:26"> さてモーセは罪祭のやぎを、ていねいに捜したが、見よ、それがすでに焼かれていたので、彼は残っているアロンの子エレアザルとイタマルとにむかい、怒って言った、</span>
<span className="v" id="v17" data-v="17" data-xref="レビ記 7:6–7; 民数記 18:1; レビ記 6:24–30"> 「あなたがたは、なぜ罪祭のものを聖なる所で食べなかったのか。これはいと聖なる物であって、あなたがたが会衆の罪を負って、彼らのために主の前にあがないをするため、あなたがたに賜わった物である。</span>
<span className="v" id="v18" data-v="18" data-xref="レビ記 6:30; レビ記 6:26"> 見よ、その血は聖所の中に携え入れなかった。その肉はわたしが命じたように、あなたがたは必ずそれを聖なる所で食べるべきであった」。</span>
<span className="v" id="v19" data-v="19" data-xref="レビ記 9:12; レビ記 9:8; エレミヤ書 14:12"> アロンはモーセに言った、「見よ、きょう、彼らはその罪祭と燔祭とを主の前にささげたが、このような事がわたしに臨んだ。もしわたしが、きょう罪祭のものを食べたとしたら、主はこれを良しとせられたであろうか」。</span>
<span className="v" id="v20" data-v="20" data-xref="ゼカリヤ書 7:8–9; マタイによる福音書 12:20; 歴代志下 30:18–20"> モーセはこれを聞いて良しとした。</span>
</div>

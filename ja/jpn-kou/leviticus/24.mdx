<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 主はまたモーセに言われた、</span>
<span className="v" id="v2" data-v="2" data-xref="コリント人への第二の手紙 4:6; エペソ人への手紙 5:8–14; 出エジプト記 27:20–21"> 「イスラエルの人々に命じて、オリブを砕いて採った純粋の油を、ともしびのためにあなたの所へ持ってこさせ、絶えずともしびをともさせなさい。</span>
<span className="v" id="v3" data-v="3"> すなわち、アロンは会見の幕屋のうちのあかしの垂幕の外で、夕から朝まで絶えず、そのともしびを主の前に整えなければならない。これはあなたがたが代々ながく守るべき定めである。</span>
<span className="v" id="v4" data-v="4" data-xref="出エジプト記 31:8; 出エジプト記 37:17–24; 出エジプト記 39:37"> 彼は純金の燭台の上に、そのともしびを絶えず主の前に整えなければならない。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="出エジプト記 25:30; 列王紀上 18:31; 出エジプト記 40:23"> あなたは麦粉を取り、それで十二個の菓子を焼かなければならない。菓子一個に麦粉十分の二エパを用いなければならない。</span>
<span className="v" id="v6" data-v="6" data-xref="列王紀上 7:48; 出エジプト記 25:23–24; 歴代志下 4:19"> そしてそれを主の前の純金の机の上に、ひと重ね六個ずつ、ふた重ねにして置かなければならない。</span>
<span className="v" id="v7" data-v="7" data-xref="レビ記 2:2; ヨハネの黙示録 8:3–4; 創世記 9:16"> あなたはまた、おのおのの重ねの上に、純粋の乳香を置いて、そのパンの記念の分とし、主にささげて火祭としなければならない。</span>
<span className="v" id="v8" data-v="8" data-xref="歴代志下 2:4; 民数記 4:7; 歴代志上 9:32"> 安息日ごとに絶えず、これを主の前に整えなければならない。これはイスラエルの人々のささぐべきものであって、永遠の契約である。</span>
<span className="v" id="v9" data-v="9" data-xref="レビ記 8:31; ルカによる福音書 6:4; マルコによる福音書 2:26"> これはアロンとその子たちに帰する。彼らはこれを聖なる所で食べなければならない。これはいと聖なる物であって、主の火祭のうち彼に帰すべき永久の分である」。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="民数記 11:4; 出エジプト記 12:38"> イスラエルの女を母とし、エジプトびとを父とするひとりの者が、イスラエルの人々のうちに出てきて、そのイスラエルの女の産んだ子と、ひとりのイスラエルびとが宿営の中で争いをし、</span>
<span className="v" id="v11" data-v="11" data-xref="出エジプト記 20:7; レビ記 24:15–16; 出エジプト記 3:15"> そのイスラエルの女の産んだ子が主の名を汚して、のろったので、人々は彼をモーセのもとに連れてきた。その母はダンの部族のデブリの娘で、名をシロミテといった。</span>
<span className="v" id="v12" data-v="12" data-xref="出エジプト記 18:15–16; 民数記 15:34; 民数記 27:5"> 人々は彼を閉じ込めて置いて、主の示しを受けるのを待っていた。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13"> 時に主はモーセに言われた、</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 17:7; レビ記 20:27; 申命記 21:21"> 「あの、のろいごとを言った者を宿営の外に引き出し、それを聞いた者に、みな手を彼の頭に置かせ、全会衆に彼を石で撃たせなさい。</span>
<span className="v" id="v15" data-v="15" data-xref="民数記 9:13; 出エジプト記 22:28; レビ記 5:1"> あなたはまたイスラエルの人々に言いなさい、『だれでも、その神をのろう者は、その罪を負わなければならない。</span>
<span className="v" id="v16" data-v="16" data-xref="マタイによる福音書 12:31; ヤコブの手紙 2:7; ヨハネによる福音書 10:33–36"> 主の名を汚す者は必ず殺されるであろう。全会衆は必ず彼を石で撃たなければならない。他国の者でも、この国に生れた者でも、主の名を汚すときは殺されなければならない。</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 9:5–6; 申命記 19:11–12; 申命記 27:24"> だれでも、人を撃ち殺した者は、必ず殺されなければならない。</span>
<span className="v" id="v18" data-v="18" data-xref="レビ記 24:21; 出エジプト記 21:34–36"> 獣を撃ち殺した者は、獣をもってその獣を償わなければならない。</span>
<span className="v" id="v19" data-v="19" data-xref="マタイによる福音書 5:38; マタイによる福音書 7:2; 申命記 19:21"> もし人が隣人に傷を負わせるなら、その人は自分がしたように自分にされなければならない。</span>
<span className="v" id="v20" data-v="20" data-xref="申命記 19:21; マタイによる福音書 5:38; 出エジプト記 21:23–25"> すなわち、骨折には骨折、目には目、歯には歯をもって、人に傷を負わせたように、自分にもされなければならない。</span>
<span className="v" id="v21" data-v="21" data-xref="レビ記 24:17–18; 出エジプト記 21:33"> 獣を撃ち殺した者はそれを償い、人を撃ち殺した者は殺されなければならない。</span>
<span className="v" id="v22" data-v="22" data-xref="出エジプト記 12:49; 民数記 15:15–16; 民数記 9:14"> 他国の者にも、この国に生れた者にも、あなたがたは同一のおきてを用いなければならない。わたしはあなたがたの神、主だからである』」。</span>
<span className="v" id="v23" data-v="23" data-xref="ヘブル人への手紙 10:28–29; ヘブル人への手紙 2:2–3; 民数記 15:35–36"> モーセがイスラエルの人々に向かい、「あの、のろいごとを言った者を宿営の外に引き出し、石で撃て」と命じたので、イスラエルの人々は、主がモーセに命じられたようにした。</span>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 主はまたモーセとアロンに言われた、</span>
<span className="v" id="v2" data-v="2" data-xref="マタイによる福音書 15:11; レビ記 11:11; ヘブル人への手紙 9:10"> 「イスラエルの人々に言いなさい、『地にあるすべての獣のうち、あなたがたの食べることができる動物は次のとおりである。</span>
<span className="v" id="v3" data-v="3" data-xref="箴言 2:10; コリント人への第二の手紙 6:17; 申命記 6:6–7"> 獣のうち、すべてひずめの分かれたもの、すなわち、ひずめの全く切れたもの、反芻するものは、これを食べることができる。</span>
<span className="v" id="v4" data-v="4"> ただし、反芻するもの、またはひずめの分かれたもののうち、次のものは食べてはならない。すなわち、らくだ、これは、反芻するけれども、ひずめが分かれていないから、あなたがたには汚れたものである。</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 104:18; 箴言 30:26; マタイによる福音書 7:26"> 岩たぬき、これは、反芻するけれども、ひずめが分かれていないから、あなたがたには汚れたものである。</span>
<span className="v" id="v6" data-v="6" data-xref="申命記 14:7"> 野うさぎ、これは、反芻するけれども、ひずめが分かれていないから、あなたがたには汚れたものである。</span>
<span className="v" id="v7" data-v="7" data-xref="イザヤ書 66:17; イザヤ書 65:4; イザヤ書 66:3"> 豚、これは、ひずめが分かれており、ひずめが全く切れているけれども、反芻することをしないから、あなたがたには汚れたものである。</span>
<span className="v" id="v8" data-v="8" data-xref="イザヤ書 52:11; コロサイ人への手紙 2:16; ヘブル人への手紙 9:10"> あなたがたは、これらのものの肉を食べてはならない。またその死体に触れてはならない。これらは、あなたがたには汚れたものである。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="ガラテヤ人への手紙 5:6; ヤコブの手紙 2:18; 使徒行伝 20:21"> 水の中にいるすべてのもののうち、あなたがたの食べることができるものは次のとおりである。すなわち、海でも、川でも、すべて水の中にいるもので、ひれと、うろこのあるものは、これを食べることができる。</span>
<span className="v" id="v10" data-v="10" data-xref="箴言 29:27; レビ記 7:18; 詩篇 139:21–22"> すべて水に群がるもの、またすべての水の中にいる生き物のうち、すなわち、すべて海、また川にいて、ひれとうろこのないものは、あなたがたに忌むべきものである。</span>
<span className="v" id="v11" data-v="11"> これらはあなたがたに忌むべきものであるから、あなたがたはその肉を食べてはならない。またその死体は忌むべきものとしなければならない。</span>
<span className="v" id="v12" data-v="12"> すべて水の中にいて、ひれも、うろこもないものは、あなたがたに忌むべきものである。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="ヨブ記 39:27–30; エレミヤ書 4:22; テトスヘの手紙 3:3"> 鳥のうち、次のものは、あなたがたに忌むべきものとして、食べてはならない。それらは忌むべきものである。すなわち、はげわし、ひげはげわし、みさご、</span>
<span className="v" id="v14" data-v="14"> とび、はやぶさの類、</span>
<span className="v" id="v15" data-v="15" data-xref="ルカによる福音書 12:24; 列王紀上 17:6; 箴言 30:17"> もろもろのからすの類、</span>
<span className="v" id="v16" data-v="16" data-xref="イザヤ書 34:11–15; エペソ人への手紙 5:7–11; エペソ人への手紙 2:2–3"> だちょう、よたか、かもめ、たかの類、</span>
<span className="v" id="v17" data-v="17"> ふくろう、う、みみずく、</span>
<span className="v" id="v18" data-v="18"> むらさきばん、ペリカン、はげたか、</span>
<span className="v" id="v19" data-v="19"> こうのとり、さぎの類、やつがしら、こうもり。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="テモテヘの第二の手紙 4:10; ピリピ人への手紙 3:18–19; レビ記 11:23"> また羽があって四つの足で歩くすべての這うものは、あなたがたに忌むべきものである。</span>
<span className="v" id="v21" data-v="21"> ただし、羽があって四つの足で歩くすべての這うもののうち、その足のうえに、跳ね足があり、それで地の上をはねるものは食べることができる。</span>
<span className="v" id="v22" data-v="22" data-xref="マタイによる福音書 3:4; マルコによる福音書 1:6; 出エジプト記 10:4–5"> すなわち、そのうち次のものは食べることができる。移住いなごの類、遍歴いなごの類、大いなごの類、小いなごの類である。</span>
<span className="v" id="v23" data-v="23"> しかし、羽があって四つの足で歩く、そのほかのすべての這うものは、あなたがたに忌むべきものである。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="コリント人への第一の手紙 15:33; エペソ人への手紙 2:1–3; コリント人への第二の手紙 6:17"> あなたがたは次の場合に汚れたものとなる。すなわち、すべてこれらのものの死体に触れる者は夕まで汚れる。</span>
<span className="v" id="v25" data-v="25" data-xref="レビ記 15:5; レビ記 14:8; 民数記 31:24"> すべてこれらのものの死体を運ぶ者は、その衣服を洗わなければならない。彼は夕まで汚れる。</span>
<span className="v" id="v26" data-v="26"> すべて、ひずめの分かれた獣で、その切れ目の切れていないもの、また、反芻することをしないものは、あなたがたに汚れたものである。すべて、これに触れる者は汚れる。</span>
<span className="v" id="v27" data-v="27" data-xref="レビ記 11:23; レビ記 11:20"> すべて四つの足で歩く獣のうち、その足の裏のふくらみで歩くものは皆あなたがたに汚れたものである。すべてその死体に触れる者は夕まで汚れる。</span>
<span className="v" id="v28" data-v="28" data-xref="レビ記 11:24–25"> その死体を運ぶ者は、その衣服を洗わなければならない。彼は夕まで汚れる。これは、あなたがたに汚れたものである。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="レビ記 11:41–42; テモテヘの第二の手紙 3:2–5; 詩篇 10:3"> 地にはう這うもののうち、次のものはあなたがたに汚れたものである。すなわち、もぐらねずみ、とびねずみ、とげ尾とかげの類、</span>
<span className="v" id="v30" data-v="30"> やもり、大とかげ、とかげ、すなとかげ、カメレオン。</span>
<span className="v" id="v31" data-v="31" data-xref="レビ記 11:24–25; レビ記 11:8"> もろもろの這うもののうち、これらはあなたがたに汚れたものである。すべてそれらのものが死んで、それに触れる者は夕まで汚れる。</span>
<span className="v" id="v32" data-v="32" data-xref="レビ記 15:12; テトスヘの手紙 3:5; テトスヘの手紙 2:14"> またそれらのものが死んで、それが落ちかかった物はすべて汚れる。木の器であれ、衣服であれ、皮であれ、袋であれ、およそ仕事に使う器はそれを水に入れなければならない。それは夕まで汚れているが、そののち清くなる。</span>
<span className="v" id="v33" data-v="33" data-xref="レビ記 6:28; レビ記 15:12; レビ記 14:45"> またそれらのものが、土の器の中に落ちたならば、その中にあるものは皆汚れる。あなたがたはその器をこわさなければならない。</span>
<span className="v" id="v34" data-v="34" data-xref="テトスヘの手紙 1:15; 箴言 21:4; 箴言 21:27"> またすべてその中にある食物で、水分のあるものは汚れる。またすべてそのような器の中にある飲み物も皆汚れる。</span>
<span className="v" id="v35" data-v="35" data-xref="レビ記 15:12; レビ記 6:28; レビ記 11:33"> またそれらのものの死体が落ちかかったならば、その物はすべて汚れる。天火であれ、かまどであれ、それをこわさなければならない。これらは汚れたもので、あなたがたに汚れたものとなる。</span>
<span className="v" id="v36" data-v="36" data-xref="ゼカリヤ書 13:1; ヨハネによる福音書 4:14"> ただし、泉、あるいは水の集まった水たまりは汚れない。しかし、その死体に触れる者は汚れる。</span>
<span className="v" id="v37" data-v="37" data-xref="コリント人への第一の手紙 15:37; ペテロの第一の手紙 1:23; ヨハネの第一の手紙 5:18"> それらのものの死体が、まく種の上に落ちても、それは汚れない。</span>
<span className="v" id="v38" data-v="38"> ただし、種の上に水がかかっていて、その上にそれらのものの死体が、落ちるならば、それはあなたがたに汚れたものとなる。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="レビ記 11:40; レビ記 11:24; レビ記 15:7"> あなたがたの食べる獣が死んだ時、その死体に触れる者は夕まで汚れる。</span>
<span className="v" id="v40" data-v="40" data-xref="レビ記 22:8; エゼキエル書 44:31; 申命記 14:21"> その死体を食べる者は、その衣服を洗わなければならない。夕まで汚れる。その死体を運ぶ者も、その衣服を洗わなければならない。夕まで汚れる。</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="レビ記 11:29; レビ記 11:20; レビ記 11:23"> すべて地にはう這うものは忌むべきものである。これを食べてはならない。</span>
<span className="v" id="v42" data-v="42" data-xref="テトスヘの手紙 1:12; イザヤ書 65:25; コリント人への第二の手紙 11:3"> すべて腹ばい行くもの、四つ足で歩くもの、あるいは多くの足をもつもの、すなわち、すべて地にはう這うものは、あなたがたはこれを食べてはならない。それらは忌むべきものだからである。</span>
<span className="v" id="v43" data-v="43" data-xref="レビ記 20:25; レビ記 11:41–42"> あなたがたはすべて這うものによって、あなたがたの身を忌むべきものとしてはならない。また、これをもって身を汚し、あるいはこれによって汚されてはならない。</span>
<span className="v" id="v44" data-v="44" data-xref="出エジプト記 20:2; ペテロの第一の手紙 1:15–16; レビ記 19:2"> わたしはあなたがたの神、主であるから、あなたがたはおのれを聖別し、聖なる者とならなければならない。わたしは聖なる者である。地にはう這うものによって、あなたがたの身を汚してはならない。</span>
<span className="v" id="v45" data-v="45" data-xref="レビ記 11:44; 出エジプト記 20:2; 出エジプト記 6:7"> わたしはあなたがたの神となるため、あなたがたをエジプトの国から導き上った主である。わたしは聖なる者であるから、あなたがたは聖なる者とならなければならない』」。</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="レビ記 14:54; レビ記 15:32; エゼキエル書 43:12"> これは獣と鳥と、水の中に動くすべての生き物と、地に這うすべてのものに関するおきてであって、</span>
<span className="v" id="v47" data-v="47" data-xref="レビ記 10:10; エゼキエル書 44:23; ローマ人への手紙 14:13–23"> 汚れたものと清いもの、食べられる生き物と、食べられない生き物とを区別するものである。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数記 1:1; ガラテヤ人への手紙 4:24–25; 出エジプト記 19:1"> 主はシナイ山で、モーセに言われた、</span>
<span className="v" id="v2" data-v="2" data-xref="歴代志下 36:21; レビ記 26:34–35; 出エジプト記 23:10"> 「イスラエルの人々に言いなさい、『わたしが与える地に、あなたがたがはいったときは、その地にも、主に向かって安息を守らせなければならない。</span>
<span className="v" id="v3" data-v="3" data-xref="出エジプト記 23:10"> 六年の間あなたは畑に種をまき、また六年の間ぶどう畑の枝を刈り込み、その実を集めることができる。</span>
<span className="v" id="v4" data-v="4" data-xref="歴代志下 36:21; レビ記 25:20–23; 出エジプト記 23:10–11"> しかし、七年目には、地に全き休みの安息を与えなければならない。これは、主に向かって守る安息である。あなたは畑に種をまいてはならない。また、ぶどう畑の枝を刈り込んではならない。</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀下 19:29; イザヤ書 37:30"> あなたの穀物の自然に生えたものは刈り取ってはならない。また、あなたのぶどうの枝の手入れをしないで結んだ実は摘んではならない。これは地のために全き休みの年だからである。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行伝 2:44; 出エジプト記 23:11; 使徒行伝 4:34–35"> 安息の年の地の産物は、あなたがたの食物となるであろう。すなわち、あなたと、男女の奴隷と、雇人と、あなたの所に宿っている他国人と、</span>
<span className="v" id="v7" data-v="7"> あなたの家畜と、あなたの国のうちの獣とのために、その産物はみな、食物となるであろう。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="レビ記 23:15; 創世記 2:2"> あなたは安息の年を七たび、すなわち、七年を七回数えなければならない。安息の年七たびの年数は四十九年である。</span>
<span className="v" id="v9" data-v="9" data-xref="レビ記 23:24; レビ記 23:27; テサロニケ人への第一の手紙 1:8"> 七月の十日にあなたはラッパの音を響き渡らせなければならない。すなわち、贖罪の日にあなたがたは全国にラッパを響き渡らせなければならない。</span>
<span className="v" id="v10" data-v="10" data-xref="エレミヤ書 34:8; イザヤ書 63:4; ペテロの第一の手紙 2:16"> その五十年目を聖別して、国中のすべての住民に自由をふれ示さなければならない。この年はあなたがたにはヨベルの年であって、あなたがたは、おのおのその所有の地に帰り、おのおのその家族に帰らなければならない。</span>
<span className="v" id="v11" data-v="11" data-xref="レビ記 27:17; レビ記 25:4–5"> その五十年目はあなたがたにはヨベルの年である。種をまいてはならない。また自然に生えたものは刈り取ってはならない。手入れをしないで結んだぶどうの実は摘んではならない。</span>
<span className="v" id="v12" data-v="12" data-xref="レビ記 25:6–7"> この年はヨベルの年であって、あなたがたに聖であるからである。あなたがたは畑に自然にできた物を食べなければならない。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="レビ記 25:10; レビ記 27:17–24; 民数記 36:4"> このヨベルの年には、おのおのその所有の地に帰らなければならない。</span>
<span className="v" id="v14" data-v="14" data-xref="レビ記 19:13; レビ記 25:17; サムエル記上 12:3–4"> あなたの隣人に物を売り、また隣人から物を買うときは、互に欺いてはならない。</span>
<span className="v" id="v15" data-v="15" data-xref="レビ記 27:18–23; ピリピ人への手紙 4:5"> ヨベルの後の年の数にしたがって、あなたは隣人から買い、彼もまた畑の産物の年数にしたがって、あなたに売らなければならない。</span>
<span className="v" id="v16" data-v="16" data-xref="レビ記 25:27; レビ記 25:51"> 年の数の多い時は、その値を増し、年の数の少ない時は、値を減らさなければならない。彼があなたに売るのは産物の数だからである。</span>
<span className="v" id="v17" data-v="17" data-xref="レビ記 19:14; レビ記 19:32; レビ記 25:43"> あなたがたは互に欺いてはならない。あなたの神を恐れなければならない。わたしはあなたがたの神、主である。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="エレミヤ書 23:6; 申命記 12:10; 箴言 1:33"> あなたがたはわたしの定めを行い、またわたしのおきてを守って、これを行わなければならない。そうすれば、あなたがたは安らかにその地に住むことができるであろう。</span>
<span className="v" id="v19" data-v="19" data-xref="ヨエル書 2:26; 詩篇 85:12; レビ記 26:5"> 地はその実を結び、あなたがたは飽きるまでそれを食べ、安らかにそこに住むことができるであろう。</span>
<span className="v" id="v20" data-v="20" data-xref="レビ記 25:4; ルカによる福音書 12:29; 民数記 11:4"> 「七年目に種をまくことができず、また産物を集めることができないならば、わたしたちは何を食べようか」とあなたがたは言うのか。</span>
<span className="v" id="v21" data-v="21" data-xref="申命記 28:8; 箴言 10:22; コリント人への第二の手紙 9:10"> わたしは命じて六年目に、あなたがたに祝福をくだし、三か年分の産物を実らせるであろう。</span>
<span className="v" id="v22" data-v="22" data-xref="列王紀下 19:29; レビ記 26:10; イザヤ書 37:30"> あなたがたは八年目に種をまく時には、なお古い産物を食べているであろう。九年目にその産物のできるまで、あなたがたは古いものを食べることができるであろう。</span>
<span className="v" id="v23" data-v="23" data-xref="ペテロの第一の手紙 2:11; 詩篇 39:12; エゼキエル書 48:14"> 地は永代には売ってはならない。地はわたしのものだからである。あなたがたはわたしと共にいる寄留者、また旅びとである。</span>
<span className="v" id="v24" data-v="24" data-xref="エペソ人への手紙 1:7; レビ記 25:51–53; レビ記 25:27"> あなたがたの所有としたどのような土地でも、その土地の買いもどしに応じなければならない。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="ルツ記 2:20; エレミヤ書 32:7–8; ルツ記 3:12"> あなたの兄弟が落ちぶれてその所有の地を売った時は、彼の近親者がきて、兄弟の売ったものを買いもどさなければならない。</span>
<span className="v" id="v26" data-v="26" data-xref="レビ記 5:7"> たといその人に、それを買いもどしてくれる人がいなくても、その人が富み、自分でそれを買いもどすことができるようになったならば、</span>
<span className="v" id="v27" data-v="27"> それを売ってからの年を数えて残りの分を買い手に返さなければならない。そうすればその人はその所有の地に帰ることができる。</span>
<span className="v" id="v28" data-v="28" data-xref="イザヤ書 35:9–10; レビ記 25:10; ペテロの第一の手紙 1:4–5"> しかし、もしそれを買いもどすことができないならば、その売った物はヨベルの年まで買い主の手にあり、ヨベルにはもどされて、その人はその所有の地に帰ることができるであろう。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29"> 人が城壁のある町の住宅を売った時は、売ってから満一年の間は、それを買いもどすことができる。その間は彼に買いもどすことを許さなければならない。</span>
<span className="v" id="v30" data-v="30"> 満一年のうちに、それを買いもどさない時は、城壁のある町の内のその家は永代にそれを買った人のものと定まって、代々の所有となり、ヨベルの年にももどされないであろう。</span>
<span className="v" id="v31" data-v="31" data-xref="詩篇 49:7–8"> しかし、周囲に城壁のない村々の家は、その地方の畑に附属するものとみなされ、買いもどすことができ、またヨベルの年には、もどされるであろう。</span>
<span className="v" id="v32" data-v="32" data-xref="ヨシュア記 21:1–45; 民数記 35:1–8"> レビびとの町々、すなわち、彼らの所有の町々の家は、レビびとはいつでも買いもどすことができる。</span>
<span className="v" id="v33" data-v="33" data-xref="民数記 18:20–24; 申命記 18:1–2"> レビびとのひとりが、それを買いもどさない時は、その所有の町にある売った家はヨベルの年にはもどされるであろう。レビびとの町々の家はイスラエルの人々のうちに彼らがもっている所有だからである。</span>
<span className="v" id="v34" data-v="34" data-xref="レビ記 25:23; 使徒行伝 4:36–37; 民数記 35:2–5"> ただし、彼らの町々の周囲の放牧地は売ってはならない。それは彼らの永久の所有だからである。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="申命記 15:7–8; 使徒行伝 11:29; レビ記 25:25"> あなたの兄弟が落ちぶれ、暮して行けない時は、彼を助け、寄留者または旅びとのようにして、あなたと共に生きながらえさせなければならない。</span>
<span className="v" id="v36" data-v="36" data-xref="出エジプト記 22:25; 申命記 23:19–20; エゼキエル書 18:8"> 彼から利子も利息も取ってはならない。あなたの神を恐れ、あなたの兄弟をあなたと共に生きながらえさせなければならない。</span>
<span className="v" id="v37" data-v="37"> あなたは利子を取って彼に金を貸してはならない。また利益をえるために食物を貸してはならない。</span>
<span className="v" id="v38" data-v="38" data-xref="レビ記 11:45; 民数記 15:41; 出エジプト記 20:2"> わたしはあなたがたの神、主であって、カナンの地をあなたがたに与え、かつあなたがたの神となるためにあなたがたをエジプトの国から導き出した者である。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="出エジプト記 21:2; 列王紀上 9:22; 列王紀下 4:1"> あなたの兄弟が落ちぶれて、あなたに身を売るときは、奴隷のように働かせてはならない。</span>
<span className="v" id="v40" data-v="40" data-xref="出エジプト記 21:2–3"> 彼を雇人のように、また旅びとのようにしてあなたの所におらせ、ヨベルの年まであなたの所で勤めさせなさい。</span>
<span className="v" id="v41" data-v="41" data-xref="レビ記 25:28; 出エジプト記 21:3; ヨハネによる福音書 8:32"> その時には、彼は子供たちと共にあなたの所から出て、その一族のもとに帰り、先祖の所有の地にもどるであろう。</span>
<span className="v" id="v42" data-v="42" data-xref="レビ記 25:55; ローマ人への手紙 6:22; コリント人への第一の手紙 7:21–23"> 彼らはエジプトの国からわたしが導き出したわたしのしもべであるから、身を売って奴隷となってはならない。</span>
<span className="v" id="v43" data-v="43" data-xref="コロサイ人への手紙 4:1; レビ記 25:46; 出エジプト記 1:13–14"> あなたは彼をきびしく使ってはならない。あなたの神を恐れなければならない。</span>
<span className="v" id="v44" data-v="44" data-xref="出エジプト記 12:44; 詩篇 2:8–9; イザヤ書 14:1–2"> あなたがもつ奴隷は男女ともにあなたの周囲の異邦人のうちから買わなければならない。すなわち、彼らのうちから男女の奴隷を買うべきである。</span>
<span className="v" id="v45" data-v="45" data-xref="イザヤ書 56:3–6"> また、あなたがたのうちに宿っている旅びとの子供のうちからも買うことができる。また彼らのうちあなたがたの国で生れて、あなたがたと共におる人々の家族からも買うことができる。そして彼らはあなたがたの所有となるであろう。</span>
<span className="v" id="v46" data-v="46" data-xref="イザヤ書 14:2; レビ記 25:43"> あなたがたは彼らを獲て、あなたがたの後の子孫に所有として継がせることができる。すなわち、彼らは長くあなたがたの奴隷となるであろう。しかし、あなたがたの兄弟であるイスラエルの人々をあなたがたは互にきびしく使ってはならない。</span>
</div>
<div className="bp">
<span className="v" id="v47" data-v="47" data-xref="ヤコブの手紙 2:5; レビ記 25:26; サムエル記上 2:7–8"> あなたと共にいる寄留者または旅びとが富み、そのかたわらにいるあなたの兄弟が落ちぶれて、あなたと共にいるその寄留者、旅びと、または寄留者の一族のひとりに身を売った場合、</span>
<span className="v" id="v48" data-v="48" data-xref="ネヘミヤ書 5:5; ヘブル人への手紙 2:11–13; レビ記 25:35"> 身を売った後でも彼を買いもどすことができる。その兄弟のひとりが彼を買いもどさなければならない。</span>
<span className="v" id="v49" data-v="49" data-xref="レビ記 25:26"> あるいは、おじ、または、おじの子が彼を買いもどさなければならない。あるいは一族の近親の者が、彼を買いもどさなければならない。あるいは自分に富ができたならば、自分で買いもどさなければならない。</span>
<span className="v" id="v50" data-v="50" data-xref="イザヤ書 16:14; イザヤ書 21:16; レビ記 25:53"> その時、彼は自分の身を売った年からヨベルの年までを、その買い主と共に数え、その年数によって、身の代金を決めなければならない。その年数は雇われた年数として数えなければならない。</span>
<span className="v" id="v51" data-v="51"> なお残りの年が多い時は、その年数にしたがい、買われた金額に照して、あがないの金を払わなければならない。</span>
<span className="v" id="v52" data-v="52"> またヨベルの年までに残りの年が少なければ、その人と共に計算し、その年数にしたがって、あがないの金を払わなければならない。</span>
<span className="v" id="v53" data-v="53" data-xref="レビ記 25:46; レビ記 25:43"> 彼は年々雇われる人のように扱われなければならない。あなたの目の前で彼をきびしく使わせてはならない。</span>
<span className="v" id="v54" data-v="54" data-xref="出エジプト記 21:2–3; レビ記 25:40–41; イザヤ書 49:9"> もし彼がこのようにしてあがなわれないならば、ヨベルの年に彼は子供と共に出て行くことができる。</span>
<span className="v" id="v55" data-v="55" data-xref="レビ記 25:42; イザヤ書 43:3; 出エジプト記 13:3"> イスラエルの人々は、わたしのしもべだからである。彼らはわたしがエジプトの国から導き出したわたしのしもべである。わたしはあなたがたの神、主である。</span>
</div>

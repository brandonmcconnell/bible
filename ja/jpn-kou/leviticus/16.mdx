<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="レビ記 10:1–2"> アロンのふたりの子が、主の前に近づいて死んだ後、</span>
<span className="v" id="v2" data-v="2" data-xref="出エジプト記 30:10; 列王紀上 8:10–12; ヘブル人への手紙 10:19–20"> 主はモーセに言われた、「あなたの兄弟アロンに告げて、彼が時をわかたず、垂幕の内なる聖所に入り、箱の上なる贖罪所の前に行かぬようにさせなさい。彼が死を免れるためである。なぜなら、わたしは雲の中にあって贖罪所の上に現れるからである。</span>
<span className="v" id="v3" data-v="3" data-xref="レビ記 4:3; ヘブル人への手紙 9:24–25; ヘブル人への手紙 9:7"> アロンが聖所に、はいるには、次のようにしなければならない。すなわち雄の子牛を罪祭のために取り、雄羊を燔祭のために取り、</span>
<span className="v" id="v4" data-v="4" data-xref="出エジプト記 28:39–43; エゼキエル書 44:17–18; 出エジプト記 30:20"> 聖なる亜麻布の服を着、亜麻布のももひきをその身にまとい、亜麻布の帯をしめ、亜麻布の帽子をかぶらなければならない。これらは聖なる衣服である。彼は水に身をすすいで、これを着なければならない。</span>
<span className="v" id="v5" data-v="5" data-xref="歴代志下 29:21; レビ記 8:2; エズラ記 6:17"> またイスラエルの人々の会衆から雄やぎ二頭を罪祭のために取り、雄羊一頭を燔祭のために取らなければならない。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="レビ記 9:7; ヘブル人への手紙 9:7; ヘブル人への手紙 7:27"> そしてアロンは自分のための罪祭の雄牛をささげて、自分と自分の家族のために、あがないをしなければならない。</span>
<span className="v" id="v7" data-v="7" data-xref="ローマ人への手紙 12:1; レビ記 4:4; マタイによる福音書 16:21"> アロンはまた二頭のやぎを取り、それを会見の幕屋の入口で主の前に立たせ、</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行伝 1:23–26; ヨナ書 1:7; 箴言 16:33"> その二頭のやぎのために、くじを引かなければならない。すなわち一つのくじは主のため、一つのくじはアザゼルのためである。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行伝 4:27–28; 使徒行伝 2:23"> そしてアロンは主のためのくじに当ったやぎをささげて、これを罪祭としなければならない。</span>
<span className="v" id="v10" data-v="10" data-xref="ヨハネの第一の手紙 2:2; レビ記 16:21–22; ヘブル人への手紙 9:23–24"> しかし、アザゼルのためのくじに当ったやぎは、主の前に生かしておき、これをもって、あがないをなし、これをアザゼルのために、荒野に送らなければならない。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="レビ記 16:6; ヘブル人への手紙 7:27; ヘブル人への手紙 9:7"> すなわち、アロンは自分のための罪祭の雄牛をささげて、自分と自分の家族のために、あがないをしなければならない。彼は自分のための罪祭の雄牛をほふり、</span>
<span className="v" id="v12" data-v="12" data-xref="レビ記 10:1; 出エジプト記 30:34–38; ヨハネの黙示録 8:3–4"> 主の前の祭壇から炭火を満たした香炉と、細かくひいた香ばしい薫香を両手いっぱい取って、これを垂幕の内に携え入り、</span>
<span className="v" id="v13" data-v="13" data-xref="出エジプト記 25:21; 出エジプト記 30:1; 出エジプト記 30:7–8"> 主の前で薫香をその火にくべ、薫香の雲に、あかしの箱の上なる贖罪所をおおわせなければならない。こうして、彼は死を免れるであろう。</span>
<span className="v" id="v14" data-v="14" data-xref="ヘブル人への手紙 9:25; レビ記 4:5–6; ヘブル人への手紙 9:13"> 彼はまたその雄牛の血を取り、指をもってこれを贖罪所の東の面に注ぎ、また指をもってその血を贖罪所の前に、七たび注がなければならない。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="ヘブル人への手紙 9:7; ヘブル人への手紙 2:17; ヘブル人への手紙 9:3"> また民のための罪祭のやぎをほふり、その血を垂幕の内に携え入り、その血をかの雄牛の血のように、贖罪所の上と、贖罪所の前に注ぎ、</span>
<span className="v" id="v16" data-v="16" data-xref="ヘブル人への手紙 9:22–23; レビ記 16:18; エゼキエル書 45:18–19"> イスラエルの人々の汚れと、そのとが、すなわち、彼らのもろもろの罪のゆえに、聖所のためにあがないをしなければならない。また彼らの汚れのうちに、彼らと共にある会見の幕屋のためにも、そのようにしなければならない。</span>
<span className="v" id="v17" data-v="17" data-xref="イザヤ書 53:6; ルカによる福音書 1:10; 出エジプト記 34:3"> 彼が聖所であがないをするために、はいった時は、自分と自分の家族と、イスラエルの全会衆とのために、あがないをなし終えて出るまで、だれも会見の幕屋の内にいてはならない。</span>
<span className="v" id="v18" data-v="18" data-xref="レビ記 4:7; ヘブル人への手紙 5:7–8; レビ記 16:16"> そして彼は主の前の祭壇のもとに出てきて、これがために、あがないをしなければならない、すなわち、かの雄牛の血と、やぎの血とを取って祭壇の四すみの角につけ、</span>
<span className="v" id="v19" data-v="19" data-xref="ゼカリヤ書 13:1; エゼキエル書 43:18–22"> また指をもって七たびその血をその上に注ぎ、イスラエルの人々の汚れを除いてこれを清くし、聖別しなければならない。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="レビ記 16:16; エゼキエル書 45:20; コロサイ人への手紙 1:20"> こうして聖所と会見の幕屋と祭壇とのために、あがないをなし終えたとき、かの生きているやぎを引いてこなければならない。</span>
<span className="v" id="v21" data-v="21" data-xref="イザヤ書 53:6; コリント人への第二の手紙 5:21; エズラ記 10:1"> そしてアロンは、その生きているやぎの頭に両手をおき、イスラエルの人々のもろもろの悪と、もろもろのとが、すなわち、彼らのもろもろの罪をその上に告白して、これをやぎの頭にのせ、定めておいた人の手によって、これを荒野に送らなければならない。</span>
<span className="v" id="v22" data-v="22" data-xref="ヘブル人への手紙 9:28; イザヤ書 53:11–12; ヨハネによる福音書 1:29"> こうしてやぎは彼らのもろもろの悪をになって、人里離れた地に行くであろう。すなわち、そのやぎを荒野に送らなければならない。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="エゼキエル書 44:19; エゼキエル書 42:14; レビ記 16:4"> そして、アロンは会見の幕屋に入り、聖所に入る時に着た亜麻布の衣服を脱いで、そこに置き、</span>
<span className="v" id="v24" data-v="24" data-xref="レビ記 16:3–5; ヘブル人への手紙 10:19–22; 出エジプト記 28:4–14"> 聖なる所で水に身をすすぎ、他の衣服を着、出てきて、自分の燔祭と民の燔祭とをささげて、自分のため、また民のために、あがないをしなければならない。</span>
<span className="v" id="v25" data-v="25" data-xref="出エジプト記 29:13; レビ記 4:8–10; レビ記 16:6"> また罪祭の脂肪を祭壇の上で焼かなければならない。</span>
<span className="v" id="v26" data-v="26" data-xref="レビ記 16:10; ヘブル人への手紙 7:19; 民数記 19:21"> かのやぎをアザゼルに送った者は衣服を洗い、水に身をすすがなければならない。その後、宿営に入ることができる。</span>
<span className="v" id="v27" data-v="27" data-xref="レビ記 4:21; レビ記 6:30; レビ記 4:11–12"> 聖所で、あがないをするために、その血を携え入れられた罪祭の雄牛と、罪祭のやぎとは、宿営の外に携え出し、その皮と肉と汚物とは、火で焼き捨てなければならない。</span>
<span className="v" id="v28" data-v="28"> これを焼く者は衣服を洗い、水に身をすすがなければならない。その後、宿営に入ることができる。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="イザヤ書 58:3; 民数記 29:7; 出エジプト記 20:10"> これはあなたがたが永久に守るべき定めである。すなわち、七月になって、その月の十日に、あなたがたは身を悩まし、何の仕事もしてはならない。この国に生れた者も、あなたがたのうちに宿っている寄留者も、そうしなければならない。</span>
<span className="v" id="v30" data-v="30" data-xref="エレミヤ書 33:8; 詩篇 51:2; エペソ人への手紙 5:26"> この日にあなたがたのため、あなたがたを清めるために、あがないがなされ、あなたがたは主の前に、もろもろの罪が清められるからである。</span>
<span className="v" id="v31" data-v="31" data-xref="レビ記 23:32; イザヤ書 58:5; レビ記 25:4"> これはあなたがたの全き休みの安息日であって、あなたがたは身を悩まさなければならない。これは永久に守るべき定めである。</span>
<span className="v" id="v32" data-v="32" data-xref="レビ記 16:4; 出エジプト記 29:29–30; レビ記 4:5"> 油を注がれ、父に代って祭司の職に任じられる祭司は、亜麻布の衣服、すなわち、聖なる衣服を着て、あがないをしなければならない。</span>
<span className="v" id="v33" data-v="33" data-xref="レビ記 16:16; レビ記 16:24; レビ記 16:6"> 彼は至聖所のために、あがないをなし、また会見の幕屋のためと、祭壇のために、あがないをなし、また祭司たちのためと、民の全会衆のために、あがないをしなければならない。</span>
<span className="v" id="v34" data-v="34" data-xref="ヘブル人への手紙 9:7; ヘブル人への手紙 9:25; 出エジプト記 30:10"> これはあなたがたの永久に守るべき定めであって、イスラエルの人々のもろもろの罪のために、年に一度あがないをするものである」。<br />彼は主がモーセに命じられたとおりにおこなった。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="レビ記 6:14–18; レビ記 9:17; イザヤ書 66:20"> 人が素祭の供え物を主にささげるときは、その供え物は麦粉でなければならない。その上に油を注ぎ、またその上に乳香を添え、</span>
<span className="v" id="v2" data-v="2" data-xref="レビ記 5:12; レビ記 6:15; 使徒行伝 10:4"> これをアロンの子なる祭司たちのもとに携えて行かなければならない。祭司はその麦粉とその油の一握りを乳香の全部と共に取り、これを記念の分として、祭壇の上で焼かなければならない。これは火祭であって、主にささげる香ばしいかおりである。</span>
<span className="v" id="v3" data-v="3" data-xref="レビ記 10:12–13; 民数記 18:9; レビ記 21:22"> 素祭の残りはアロンとその子らのものになる。これは主の火祭のいと聖なる物である。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="出エジプト記 29:2; コリント人への第一の手紙 5:7–8; 詩篇 22:14"> あなたが、もし天火で焼いたものを素祭としてささげるならば、それは麦粉に油を混ぜて作った種入れぬ菓子、または油を塗った種入れぬ煎餅でなければならない。</span>
<span className="v" id="v5" data-v="5" data-xref="レビ記 6:21; レビ記 7:9"> あなたの供え物が、もし、平鍋で焼いた素祭であるならば、それは麦粉に油を混ぜて作った種入れぬものでなければならない。</span>
<span className="v" id="v6" data-v="6" data-xref="ヨハネによる福音書 18:1–19; 詩篇 22:1–21; マルコによる福音書 14:1–15"> あなたはそれを細かく砕き、その上に油を注がなければならない。これは素祭である。</span>
<span className="v" id="v7" data-v="7" data-xref="レビ記 2:1–2; レビ記 7:9"> あなたの供え物が、もし深鍋で煮た素祭であるならば、麦粉に油を混ぜて作らなければならない。</span>
<span className="v" id="v8" data-v="8"> あなたはこれらの物で作った素祭を、主に携えて行かなければならない。それを祭司に渡すならば、祭司はそれを祭壇に携えて行き、</span>
<span className="v" id="v9" data-v="9" data-xref="レビ記 2:2; ピリピ人への手紙 4:18; レビ記 6:15"> その素祭のうちから記念の分を取って、祭壇の上で焼かなければならない。これは火祭であって、主にささげる香ばしいかおりである。</span>
<span className="v" id="v10" data-v="10" data-xref="レビ記 2:3"> 素祭の残りはアロンとその子らのものになる。これは、主の火祭のいと聖なる物である。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="ガラテヤ人への手紙 5:9; ルカによる福音書 12:1; 出エジプト記 23:18"> あなたがたが主にささげる素祭は、すべて種を入れて作ってはならない。パン種も蜜も、すべて主にささげる火祭として焼いてはならないからである。</span>
<span className="v" id="v12" data-v="12" data-xref="出エジプト記 23:19; 創世記 23:10–11; 出エジプト記 22:29"> ただし、初穂の供え物としては、これらを主にささげることができる。しかし香ばしいかおりとして祭壇にささげてはならない。</span>
<span className="v" id="v13" data-v="13" data-xref="エゼキエル書 43:24; マタイによる福音書 5:13; コロサイ人への手紙 4:6"> あなたの素祭の供え物は、すべて塩をもって味をつけなければならない。あなたの素祭に、あなたの神の契約の塩を欠いてはならない。すべて、あなたの供え物は、塩を添えてささげなければならない。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="レビ記 23:10; マラキ書 1:11; 民数記 28:2"> もしあなたが初穂の素祭を主にささげるならば、火で穂を焼いたもの、新穀の砕いたものを、あなたの初穂の素祭としてささげなければならない。</span>
<span className="v" id="v15" data-v="15"> あなたはそれに油を加え、その上に乳香を置かなければならない。これは素祭である。</span>
<span className="v" id="v16" data-v="16" data-xref="ヘブル人への手紙 5:7; ローマ人への手紙 8:26–27; イザヤ書 61:1"> 祭司は、その砕いた物およびその油のうちから記念の分を取って、乳香の全部と共に焼かなければならない。これは主にささげる火祭である。</span>
</div>

<div className="bible-chapter" lang="ja" dir="ltr" data-lang="ja" data-translation="jpn-kou" data-translation-id="jpn_kou" data-translation-label="口語訳" data-book="LEV" data-book-slug="leviticus" data-book-name="レビ記" data-chapter="19" data-verses="37">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 主はモーセに言われた、</span>
<span className="v" id="v2" data-v="2" data-xref="レビ記 11:44–45; レビ記 20:7; ペテロの第一の手紙 1:15–16"> 「イスラエルの人々の全会衆に言いなさい、『あなたがたの神、主なるわたしは、聖であるから、あなたがたも聖でなければならない。</span>
<span className="v" id="v3" data-v="3" data-xref="出エジプト記 20:12; 出エジプト記 20:8; ヘブル人への手紙 12:9"> あなたがたは、おのおのその母とその父とをおそれなければならない。またわたしの安息日を守らなければならない。わたしはあなたがたの神、主である。</span>
<span className="v" id="v4" data-v="4" data-xref="レビ記 26:1; 出エジプト記 20:23; 詩篇 115:4–7"> むなしい神々に心を寄せてはならない。また自分のために神々を鋳て造ってはならない。わたしはあなたがたの神、主である。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="レビ記 22:19; レビ記 22:29; レビ記 7:16"> 酬恩祭の犠牲を主にささげるときは、あなたがたが受け入れられるように、それをささげなければならない。</span>
<span className="v" id="v6" data-v="6" data-xref="レビ記 7:11–17"> それは、ささげた日と、その翌日とに食べ、三日目まで残ったものは、それを火で焼かなければならない。</span>
<span className="v" id="v7" data-v="7" data-xref="レビ記 7:18–21; レビ記 22:25; エレミヤ書 16:18"> もし三日目に、少しでも食べるならば、それは忌むべきものとなって、あなたは受け入れられないであろう。</span>
<span className="v" id="v8" data-v="8" data-xref="レビ記 22:15; レビ記 5:1"> それを食べる者は、主の聖なる物を汚すので、そのとがを負わなければならない。その人は民のうちから断たれるであろう。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="レビ記 23:22; 申命記 24:19–22; ルツ記 2:2"> あなたがたの地の実のりを刈り入れるときは、畑のすみずみまで刈りつくしてはならない。またあなたの刈入れの落ち穂を拾ってはならない。</span>
<span className="v" id="v10" data-v="10" data-xref="イザヤ書 17:6; レビ記 25:6; イザヤ書 24:13"> あなたのぶどう畑の実を取りつくしてはならない。またあなたのぶどう畑に落ちた実を拾ってはならない。貧しい者と寄留者とのために、これを残しておかなければならない。わたしはあなたがたの神、主である。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="詩篇 101:7; エペソ人への手紙 4:25; コロサイ人への手紙 3:9"> あなたがたは盗んではならない。欺いてはならない。互に偽ってはならない。</span>
<span className="v" id="v12" data-v="12" data-xref="出エジプト記 20:7; 申命記 5:11; レビ記 18:21"> わたしの名により偽り誓って、あなたがたの神の名を汚してはならない。わたしは主である。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="ヤコブの手紙 5:4; マラキ書 3:5; 申命記 24:14–15"> あなたの隣人をしえたげてはならない。また、かすめてはならない。日雇人の賃銀を明くる朝まで、あなたのもとにとどめておいてはならない。</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 27:18; レビ記 19:32; レビ記 25:17"> 耳しいを、のろってはならない。目しいの前につまずく物を置いてはならない。あなたの神を恐れなければならない。わたしは主である。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="申命記 1:17; 箴言 24:23; 申命記 27:19"> さばきをするとき、不正を行ってはならない。貧しい者を片よってかばい、力ある者を曲げて助けてはならない。ただ正義をもって隣人をさばかなければならない。</span>
<span className="v" id="v16" data-v="16" data-xref="出エジプト記 23:1; 出エジプト記 23:7; 箴言 20:19"> 民のうちを行き巡って、人の悪口を言いふらしてはならない。あなたの隣人の血にかかわる偽証をしてはならない。わたしは主である。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="ヨハネの第一の手紙 2:9; ヨハネの第一の手紙 2:11; ルカによる福音書 17:3"> あなたは心に兄弟を憎んではならない。あなたの隣人をねんごろにいさめて、彼のゆえに罪を身に負ってはならない。</span>
<span className="v" id="v18" data-v="18" data-xref="ローマ人への手紙 13:9; マタイによる福音書 22:39–40; マルコによる福音書 12:31–34"> あなたはあだを返してはならない。あなたの民の人々に恨みをいだいてはならない。あなた自身のようにあなたの隣人を愛さなければならない。わたしは主である。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="コリント人への第二の手紙 6:14–17; 申命記 22:9–11; マタイによる福音書 9:16–17"> あなたがたはわたしの定めを守らなければならない。あなたの家畜に異なった種をかけてはならない。あなたの畑に二種の種をまいてはならない。二種の糸の混ぜ織りの衣服を身につけてはならない。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="申命記 22:23–24; 出エジプト記 21:20–21"> だれでも、人と婚約のある女奴隷で、まだあがなわれず、自由を与えられていない者と寝て交わったならば、彼らふたりは罰を受ける。しかし、殺されることはない。彼女は自由の女ではないからである。</span>
<span className="v" id="v21" data-v="21" data-xref="レビ記 6:6–7; レビ記 5:1–6; レビ記 5:15"> しかし、その男は愆祭を主に携えてこなければならない。すなわち、愆祭の雄羊を、会見の幕屋の入口に連れてこなければならない。</span>
<span className="v" id="v22" data-v="22" data-xref="レビ記 4:26; レビ記 4:20"> そして、祭司は彼の犯した罪のためにその愆祭の雄羊をもって、主の前に彼のために、あがないをするであろう。こうして彼の犯した罪はゆるされるであろう。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="レビ記 22:27; 使徒行伝 7:51; エレミヤ書 9:25–26"> あなたがたが、かの地にはいって、もろもろのくだものの木を植えるときは、その実はまだ割礼をうけないものと、見なさなければならない。すなわち、それは三年の間あなたがたには、割礼のないものであって、食べてはならない。</span>
<span className="v" id="v24" data-v="24" data-xref="箴言 3:9; 申命記 18:4; 民数記 18:12–13"> 四年目には、そのすべての実を聖なる物とし、それをさんびの供え物として主にささげなければならない。</span>
<span className="v" id="v25" data-v="25" data-xref="ハガイ書 1:9–11; マラキ書 3:8–10; レビ記 26:3–4"> しかし五年目には、あなたがたはその実を食べることができるであろう。こうするならば、それはあなたがたのために、多くの実を結ぶであろう。わたしはあなたがたの神、主である。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="申命記 18:10–14; 列王紀下 17:17; 歴代志下 33:6"> あなたがたは何をも血のままで食べてはならない。また占いをしてはならない。魔法を行ってはならない。</span>
<span className="v" id="v27" data-v="27" data-xref="レビ記 21:5; 申命記 14:1; エゼキエル書 44:20"> あなたがたのびんの毛を切ってはならない。ひげの両端をそこなってはならない。</span>
<span className="v" id="v28" data-v="28" data-xref="申命記 14:1; レビ記 21:5; 列王紀上 18:28"> 死人のために身を傷つけてはならない。また身に入墨をしてはならない。わたしは主である。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="申命記 23:17–18; レビ記 21:7; ホセア書 4:12–14"> あなたの娘に遊女のわざをさせて、これを汚してはならない。これはみだらな事が国に行われ、悪事が地に満ちないためである。</span>
<span className="v" id="v30" data-v="30" data-xref="レビ記 26:2; レビ記 19:3; 伝道の書 5:1"> あなたがたはわたしの安息日を守り、わたしの聖所を敬わなければならない。わたしは主である。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="イザヤ書 8:19; レビ記 20:27; レビ記 20:6–7"> あなたがたは口寄せ、または占い師のもとにおもむいてはならない。彼らに問うて汚されてはならない。わたしはあなたがたの神、主である。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="テモテヘの第一の手紙 5:1; 哀歌 5:12; 箴言 16:31"> あなたは白髪の人の前では、起立しなければならない。また老人を敬い、あなたの神を恐れなければならない。わたしは主である。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="出エジプト記 23:9; 出エジプト記 22:21; マラキ書 3:5"> もし他国人があなたがたの国に寄留して共にいるならば、これをしえたげてはならない。</span>
<span className="v" id="v34" data-v="34" data-xref="申命記 10:19; レビ記 19:18; 出エジプト記 12:48–49"> あなたがたと共にいる寄留の他国人を、あなたがたと同じ国に生れた者のようにし、あなた自身のようにこれを愛さなければならない。あなたがたもかつてエジプトの国で他国人であったからである。わたしはあなたがたの神、主である。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="申命記 25:15; 申命記 25:13; 箴言 16:11"> あなたがたは、さばきにおいても、物差しにおいても、はかりにおいても、ますにおいても、不正を行ってはならない。</span>
<span className="v" id="v36" data-v="36" data-xref="箴言 11:1; 出エジプト記 20:2; 申命記 25:13–15"> あなたがたは正しいてんびん、正しいおもり石、正しいエパ、正しいヒンを使わなければならない。わたしは、あなたがたをエジプトの国から導き出したあなたがたの神、主である。</span>
<span className="v" id="v37" data-v="37" data-xref="申命記 8:1; レビ記 18:4–5; 申命記 5:1"> あなたがたはわたしのすべての定めと、わたしのすべてのおきてを守って、これを行わなければならない。わたしは主である』」。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="テトスヘの手紙 2:5; ペテロの第一の手紙 2:17–20; テトスヘの手紙 2:8–10"> くびきの下にある奴隷はすべて、自分の主人を、真に尊敬すべき者として仰ぐべきである。それは、神の御名と教とが、そしりを受けないためである。</span>
<span className="v" id="v2" data-v="2" data-xref="コロサイ人への手紙 4:1; テモテヘの第一の手紙 4:11; 創世記 16:4–5"> 信者である主人を持っている者たちは、その主人が兄弟であるというので軽視してはならない。むしろ、ますます励んで仕えるべきである。その益を受ける主人は、信者であり愛されている人だからである。<br />あなたは、これらの事を教えかつ勧めなさい。</span>
<span className="v" id="v3" data-v="3" data-xref="テモテヘの第一の手紙 1:3; ローマ人への手紙 16:17; テモテヘの第一の手紙 1:10"> もし違ったことを教えて、わたしたちの主イエス・キリストの健全な言葉、ならびに信心にかなう教に同意しないような者があれば、</span>
<span className="v" id="v4" data-v="4" data-xref="テモテヘの第二の手紙 2:23; テモテヘの第二の手紙 3:4; テモテヘの第一の手紙 3:6"> 彼は高慢であって、何も知らず、ただ論議と言葉の争いとに病みついている者である。そこから、ねたみ、争い、そしり、さいぎの心が生じ、</span>
<span className="v" id="v5" data-v="5" data-xref="テモテヘの第二の手紙 3:5; テトスヘの手紙 1:11; ペテロの第二の手紙 2:3"> また知性が腐って、真理にそむき、信心を利得と心得る者どもの間に、はてしのないいがみ合いが起るのである。</span>
<span className="v" id="v6" data-v="6" data-xref="ヘブル人への手紙 13:5; テモテヘの第一の手紙 6:8; 箴言 16:8"> しかし、信心があって足ることを知るのは、大きな利得である。</span>
<span className="v" id="v7" data-v="7" data-xref="ヨブ記 1:21; 詩篇 49:17; ルカによる福音書 12:20–21"> わたしたちは、何ひとつ持たないでこの世にきた。また、何ひとつ持たないでこの世を去って行く。</span>
<span className="v" id="v8" data-v="8" data-xref="ヘブル人への手紙 13:5–6; マタイによる福音書 6:11; マタイによる福音書 6:25–33"> ただ衣食があれば、それで足れりとすべきである。</span>
<span className="v" id="v9" data-v="9" data-xref="ヨハネの第一の手紙 2:15–17; 箴言 15:27; テモテヘの第一の手紙 3:7"> 富むことを願い求める者は、誘惑と、わなとに陥り、また、人を滅びと破壊とに沈ませる、無分別な恐ろしいさまざまの情欲に陥るのである。</span>
<span className="v" id="v10" data-v="10" data-xref="箴言 1:19; テモテヘの第一の手紙 6:9; 詩篇 32:10"> 金銭を愛することは、すべての悪の根である。ある人々は欲ばって金銭を求めたため、信仰から迷い出て、多くの苦痛をもって自分自身を刺しとおした。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="テモテヘの第二の手紙 2:22; テモテヘの第二の手紙 3:17; テモテヘの第一の手紙 4:12"> しかし、神の人よ。あなたはこれらの事を避けなさい。そして、義と信心と信仰と愛と忍耐と柔和とを追い求めなさい。</span>
<span className="v" id="v12" data-v="12" data-xref="ペテロの第一の手紙 5:10; テモテヘの第一の手紙 1:18; コリント人への第一の手紙 9:25–26"> 信仰の戦いをりっぱに戦いぬいて、永遠のいのちを獲得しなさい。あなたは、そのために召され、多くの証人の前で、りっぱなあかしをしたのである。</span>
<span className="v" id="v13" data-v="13" data-xref="ヨハネによる福音書 18:36–37; マタイによる福音書 27:11; テモテヘの第一の手紙 5:21"> わたしはすべてのものを生かして下さる神のみまえと、またポンテオ・ピラトの面前でりっぱなあかしをなさったキリスト・イエスのみまえで、あなたに命じる。</span>
<span className="v" id="v14" data-v="14" data-xref="ペテロの第二の手紙 3:14; ペテロの第一の手紙 1:7; テサロニケ人への第一の手紙 5:23"> わたしたちの主イエス・キリストの出現まで、その戒めを汚すことがなく、また、それを非難のないように守りなさい。</span>
<span className="v" id="v15" data-v="15" data-xref="ヨハネの黙示録 19:16; ヨハネの黙示録 17:14; テモテヘの第一の手紙 1:17"> 時がくれば、祝福に満ちた、ただひとりの力あるかた、もろもろの王の王、もろもろの主の主が、キリストを出現させて下さるであろう。</span>
<span className="v" id="v16" data-v="16" data-xref="テモテヘの第一の手紙 1:17; ヨハネによる福音書 1:18; ヨハネの第一の手紙 1:5"> 神はただひとり不死を保ち、近づきがたい光の中に住み、人間の中でだれも見た者がなく、見ることもできないかたである。ほまれと永遠の支配とが、神にあるように、アァメン。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="箴言 11:28; 使徒行伝 14:17; 箴言 27:24"> この世で富んでいる者たちに、命じなさい。高慢にならず、たよりにならない富に望みをおかず、むしろ、わたしたちにすべての物を豊かに備えて楽しませて下さる神に、のぞみをおくように、</span>
<span className="v" id="v18" data-v="18" data-xref="ヘブル人への手紙 13:16; ヨハネの第一の手紙 3:17; 詩篇 37:3"> また、良い行いをし、良いわざに富み、惜しみなく施し、人に分け与えることを喜び、</span>
<span className="v" id="v19" data-v="19" data-xref="マタイによる福音書 6:19–21; テモテヘの第一の手紙 6:12; テモテヘの第二の手紙 2:19"> こうして、真のいのちを得るために、未来に備えてよい土台を自分のために築き上げるように、命じなさい。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="コロサイ人への手紙 2:8; テモテヘの第二の手紙 2:16; テモテヘの第二の手紙 1:12–14"> テモテよ。あなたにゆだねられていることを守りなさい。そして、俗悪なむだ話と、偽りの「知識」による反対論とを避けなさい。</span>
<span className="v" id="v21" data-v="21" data-xref="テモテヘの第二の手紙 2:18; テモテヘの第一の手紙 1:6; テモテヘの第二の手紙 4:22"> ある人々はそれに熱中して、信仰からそれてしまったのである。<br />恵みが、あなたがたと共にあるように。</span>
</div>

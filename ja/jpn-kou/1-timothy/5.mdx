<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="レビ記 19:32; ペテロの第一の手紙 5:5–6; テトスヘの手紙 2:2"> 老人をとがめてはいけない。むしろ父親に対するように、話してあげなさい。若い男には兄弟に対するように、</span>
<span className="v" id="v2" data-v="2" data-xref="テモテヘの第一の手紙 4:12; マタイによる福音書 12:50; ピリピ人への手紙 4:8"> 年とった女には母親に対するように、若い女には、真に純潔な思いをもって、姉妹に対するように、勧告しなさい。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="申命記 27:19; 使徒行伝 6:1; 申命記 10:18"> やもめについては、真にたよりのないやもめたちを、よくしてあげなさい。</span>
<span className="v" id="v4" data-v="4" data-xref="エペソ人への手紙 6:1–3; ヨハネによる福音書 19:26–27; マタイによる福音書 15:4–6"> やもめに子か孫かがある場合には、これらの者に、まず自分の家で孝養をつくし、親の恩に報いることを学ばせるべきである。それが、神のみこころにかなうことなのである。</span>
<span className="v" id="v5" data-v="5" data-xref="テモテヘの第一の手紙 5:3; ルカによる福音書 2:37; コリント人への第一の手紙 7:32"> 真にたよりのない、ひとり暮しのやもめは、望みを神において、日夜、たえず願いと祈とに専心するが、</span>
<span className="v" id="v6" data-v="6" data-xref="ヤコブの手紙 5:5; ヨハネの黙示録 18:7; ルカによる福音書 15:24"> これに反して、みだらな生活をしているやもめは、生けるしかばねにすぎない。</span>
<span className="v" id="v7" data-v="7" data-xref="テモテヘの第一の手紙 4:11; テトスヘの手紙 2:15; テモテヘの第二の手紙 4:1"> これらのことを命じて、彼女たちを非難のない者としなさい。</span>
<span className="v" id="v8" data-v="8" data-xref="ガラテヤ人への手紙 6:10; コリント人への第二の手紙 12:14; ルカによる福音書 11:11–13"> もしある人が、その親族を、ことに自分の家族をかえりみない場合には、その信仰を捨てたことになるのであって、不信者以上にわるい。</span>
<span className="v" id="v9" data-v="9" data-xref="テモテヘの第一の手紙 3:2; テモテヘの第一の手紙 5:11; ルカによる福音書 2:36–37"> やもめとして登録さるべき者は、六十歳以下のものではなくて、ひとりの夫の妻であった者、</span>
<span className="v" id="v10" data-v="10" data-xref="テモテヘの第一の手紙 6:18; テトスヘの手紙 3:8; 使徒行伝 9:36"> また子女をよく養育し、旅人をもてなし、聖徒の足を洗い、困っている人を助け、種々の善行に努めるなど、そのよいわざでひろく認められている者でなければならない。</span>
<span className="v" id="v11" data-v="11" data-xref="テモテヘの第一の手紙 5:14; ホセア書 13:6; ヤコブの手紙 5:5"> 若いやもめは除外すべきである。彼女たちがキリストにそむいて気ままになると、結婚をしたがるようになり、</span>
<span className="v" id="v12" data-v="12" data-xref="ガラテヤ人への手紙 1:6; ヤコブの手紙 3:1; コリント人への第一の手紙 11:34"> 初めの誓いを無視したという非難を受けねばならないからである。</span>
<span className="v" id="v13" data-v="13" data-xref="箴言 20:19; テサロニケ人への第二の手紙 3:6–11; 使徒行伝 20:30"> その上、彼女たちはなまけていて、家々を遊び歩くことをおぼえ、なまけるばかりか、むだごとをしゃべって、いたずらに動きまわり、口にしてはならないことを言う。</span>
<span className="v" id="v14" data-v="14" data-xref="テトスヘの手紙 2:5; テモテヘの第一の手紙 6:1; テトスヘの手紙 2:8"> そういうわけだから、若いやもめは結婚して子を産み、家をおさめ、そして、反対者にそしられるすきを作らないようにしてほしい。</span>
<span className="v" id="v15" data-v="15" data-xref="ペテロの第二の手紙 2:2; ユダの手紙 1:4–5; ペテロの第二の手紙 2:20–22"> 彼女たちのうちには、サタンのあとを追って道を踏みはずした者もある。</span>
<span className="v" id="v16" data-v="16" data-xref="テモテヘの第一の手紙 5:3–5; テモテヘの第一の手紙 5:8"> 女の信者が家にやもめを持っている場合には、自分でそのやもめの世話をしてあげなさい。教会のやっかいになってはいけない。教会は、真にたよりのないやもめの世話をしなければならない。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="ヘブル人への手紙 13:17; テサロニケ人への第一の手紙 5:12–13; ガラテヤ人への手紙 6:6"> よい指導をしている長老、特に宣教と教とのために労している長老は、二倍の尊敬を受けるにふさわしい者である。</span>
<span className="v" id="v18" data-v="18" data-xref="申命記 25:4; コリント人への第一の手紙 9:14; コリント人への第一の手紙 9:7–10"> 聖書は、「穀物をこなしている牛に、くつこをかけてはならない」また「働き人がその報酬を受けるのは当然である」と言っている。</span>
<span className="v" id="v19" data-v="19" data-xref="マタイによる福音書 18:16; 申命記 19:15; コリント人への第二の手紙 13:1"> 長老に対する訴訟は、ふたりか三人の証人がない場合には、受理してはならない。</span>
<span className="v" id="v20" data-v="20" data-xref="テモテヘの第二の手紙 4:2; テトスヘの手紙 1:13; テモテヘの第一の手紙 1:20"> 罪を犯した者に対しては、ほかの人々も恐れをいだくに至るために、すべての人の前でその罪をとがむべきである。</span>
<span className="v" id="v21" data-v="21" data-xref="ペテロの第二の手紙 2:4; テモテヘの第二の手紙 4:1; テモテヘの第一の手紙 6:13"> わたしは、神とキリスト・イエスと選ばれた御使たちとの前で、おごそかにあなたに命じる。これらのことを偏見なしに守り、何事についても、不公平な仕方をしてはならない。</span>
<span className="v" id="v22" data-v="22" data-xref="エペソ人への手紙 5:11; テモテヘの第一の手紙 3:10; テモテヘの第一の手紙 3:6"> 軽々しく人に手をおいてはならない。また、ほかの人の罪に加わってはいけない。自分をきよく守りなさい。</span>
<span className="v" id="v23" data-v="23" data-xref="詩篇 104:15; 箴言 31:4–7; テモテヘの第一の手紙 4:4"> （これからは、水ばかりを飲まないで、胃のため、また、たびたびのいたみを和らげるために、少量のぶどう酒を用いなさい。）</span>
<span className="v" id="v24" data-v="24" data-xref="テモテヘの第二の手紙 4:10; 使徒行伝 8:18; ガラテヤ人への手紙 5:19–21"> ある人の罪は明白であって、すぐ裁判にかけられるが、ほかの人の罪は、あとになってわかって来る。</span>
<span className="v" id="v25" data-v="25" data-xref="箴言 10:9; ルカによる福音書 11:33; 詩篇 37:5–6"> それと同じく、良いわざもすぐ明らかになり、そうならない場合でも、隠れていることはあり得ない。</span>

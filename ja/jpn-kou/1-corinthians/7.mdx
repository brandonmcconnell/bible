<div className="bible-chapter" lang="ja" dir="ltr" data-lang="ja" data-translation="jpn-kou" data-translation-id="jpn_kou" data-translation-label="口語訳" data-book="1CO" data-book-slug="1-corinthians" data-book-name="コリント人への第一の手紙" data-chapter="7" data-verses="40">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="コリント人への第一の手紙 7:8; コリント人への第一の手紙 7:26–27; コリント人への第一の手紙 7:37–38"> さて、あなたがたが書いてよこした事について答えると、男子は婦人にふれないがよい。</span>
<span className="v" id="v2" data-v="2" data-xref="エペソ人への手紙 5:28; エペソ人への手紙 5:33; コリント人への第一の手紙 7:9"> しかし、不品行に陥ることのないために、男子はそれぞれ自分の妻を持ち、婦人もそれぞれ自分の夫を持つがよい。</span>
<span className="v" id="v3" data-v="3" data-xref="ペテロの第一の手紙 3:7; 出エジプト記 21:10"> 夫は妻にその分を果し、妻も同様に夫にその分を果すべきである。</span>
<span className="v" id="v4" data-v="4" data-xref="ホセア書 3:3; マタイによる福音書 19:9; マルコによる福音書 10:11–12"> 妻は自分のからだを自由にすることはできない。それができるのは夫である。夫も同様に自分のからだを自由にすることはできない。それができるのは妻である。</span>
<span className="v" id="v5" data-v="5" data-xref="出エジプト記 19:15; ヨエル書 2:16; ゼカリヤ書 12:12–14"> 互に拒んではいけない。ただし、合意の上で祈に専心するために、しばらく相別れ、それからまた一緒になることは、さしつかえない。そうでないと、自制力のないのに乗じて、サタンがあなたがたを誘惑するかも知れない。</span>
<span className="v" id="v6" data-v="6" data-xref="コリント人への第二の手紙 8:8; コリント人への第一の手紙 7:25; コリント人への第一の手紙 7:12"> 以上のことは、譲歩のつもりで言うのであって、命令するのではない。</span>
<span className="v" id="v7" data-v="7" data-xref="マタイによる福音書 19:11–12; ローマ人への手紙 12:6; コリント人への第一の手紙 9:5"> わたしとしては、みんなの者がわたし自身のようになってほしい。しかし、ひとりびとり神からそれぞれの賜物をいただいていて、ある人はこうしており、他の人はそうしている。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="コリント人への第一の手紙 7:32; コリント人への第一の手紙 7:34–35; コリント人への第一の手紙 7:26–27"> 次に、未婚者たちとやもめたちとに言うが、わたしのように、ひとりでおれば、それがいちばんよい。</span>
<span className="v" id="v9" data-v="9" data-xref="コリント人への第一の手紙 7:2; テモテヘの第一の手紙 5:14; テモテヘの第一の手紙 5:11"> しかし、もし自制することができないなら、結婚するがよい。情の燃えるよりは、結婚する方が、よいからである。</span>
<span className="v" id="v10" data-v="10" data-xref="マタイによる福音書 5:32; ルカによる福音書 16:18; マタイによる福音書 19:3–9"> 更に、結婚している者たちに命じる。命じるのは、わたしではなく主であるが、妻は夫から別れてはいけない。</span>
<span className="v" id="v11" data-v="11" data-xref="エレミヤ書 3:1; コリント人への第一の手紙 7:10; イザヤ書 50:1"> （しかし、万一別れているなら、結婚しないでいるか、それとも夫と和解するかしなさい）。また夫も妻と離婚してはならない。</span>
<span className="v" id="v12" data-v="12" data-xref="コリント人への第二の手紙 11:17; コリント人への第一の手紙 7:6; コリント人への第一の手紙 7:25"> そのほかの人々に言う。これを言うのは、主ではなく、わたしである。ある兄弟に不信者の妻があり、そして共にいることを喜んでいる場合には、離婚してはいけない。</span>
<span className="v" id="v13" data-v="13"> また、ある婦人の夫が不信者であり、そして共にいることを喜んでいる場合には、離婚してはいけない。</span>
<span className="v" id="v14" data-v="14" data-xref="マラキ書 2:15–16; テモテヘの第一の手紙 4:5; テトスヘの手紙 1:15"> なぜなら、不信者の夫は妻によってきよめられており、また、不信者の妻も夫によってきよめられているからである。もしそうでなければ、あなたがたの子は汚れていることになるが、実際はきよいではないか。</span>
<span className="v" id="v15" data-v="15" data-xref="ローマ人への手紙 14:19; コリント人への第二の手紙 13:11; ヤコブの手紙 3:17–18"> しかし、もし不信者の方が離れて行くのなら、離れるままにしておくがよい。兄弟も姉妹も、こうした場合には、束縛されてはいない。神は、あなたがたを平和に暮させるために、召されたのである。</span>
<span className="v" id="v16" data-v="16" data-xref="ペテロの第一の手紙 3:1–2; コリント人への第一の手紙 9:22; ローマ人への手紙 11:14"> なぜなら、妻よ、あなたが夫を救いうるかどうか、どうしてわかるか。また、夫よ、あなたも妻を救いうるかどうか、どうしてわかるか。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="コリント人への第一の手紙 4:17; ローマ人への手紙 12:3–8; コリント人への第一の手紙 7:24"> ただ、各自は、主から賜わった分に応じ、また神に召されたままの状態にしたがって、歩むべきである。これが、すべての教会に対してわたしの命じるところである。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行伝 15:5; 使徒行伝 15:28; 使徒行伝 15:24"> 召されたとき割礼を受けていたら、その跡をなくそうとしないがよい。また、召されたとき割礼を受けていなかったら、割礼を受けようとしないがよい。</span>
<span className="v" id="v19" data-v="19" data-xref="ガラテヤ人への手紙 6:15; ガラテヤ人への手紙 5:6; ヨハネの第一の手紙 2:3–4"> 割礼があってもなくても、それは問題ではない。大事なのは、ただ神の戒めを守ることである。</span>
<span className="v" id="v20" data-v="20" data-xref="コリント人への第一の手紙 7:17; テサロニケ人への第一の手紙 4:11; テサロニケ人への第二の手紙 3:12"> 各自は、召されたままの状態にとどまっているべきである。</span>
<span className="v" id="v21" data-v="21" data-xref="ペテロの第一の手紙 2:18–24; コロサイ人への手紙 3:11; ルカによる福音書 10:40–41"> 召されたとき奴隷であっても、それを気にしないがよい。しかし、もし自由の身になりうるなら、むしろ自由になりなさい。</span>
<span className="v" id="v22" data-v="22" data-xref="ペテロの第一の手紙 2:16; ピレモンヘの手紙 1:16; コロサイ人への手紙 3:22–24"> 主にあって召された奴隷は、主によって自由人とされた者であり、また、召された自由人はキリストの奴隷なのである。</span>
<span className="v" id="v23" data-v="23" data-xref="コリント人への第一の手紙 6:20; ペテロの第一の手紙 1:18–19; テトスヘの手紙 2:14"> あなたがたは、代価を払って買いとられたのだ。人の奴隷となってはいけない。</span>
<span className="v" id="v24" data-v="24" data-xref="コリント人への第一の手紙 7:20; コロサイ人への手紙 3:23–24; コリント人への第一の手紙 7:17"> 兄弟たちよ。各自は、その召されたままの状態で、神のみまえにいるべきである。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="コリント人への第一の手紙 7:6; コリント人への第一の手紙 4:2; コリント人への第一の手紙 7:40"> おとめのことについては、わたしは主の命令を受けてはいないが、主のあわれみにより信任を受けている者として、意見を述べよう。</span>
<span className="v" id="v26" data-v="26" data-xref="コリント人への第一の手紙 7:1; コリント人への第一の手紙 7:8; ペテロの第一の手紙 4:17"> わたしはこう考える。現在迫っている危機のゆえに、人は現状にとどまっているがよい。</span>
<span className="v" id="v27" data-v="27" data-xref="コリント人への第一の手紙 7:20; コリント人への第一の手紙 7:12–14"> もし妻に結ばれているなら、解こうとするな。妻に結ばれていないなら、妻を迎えようとするな。</span>
<span className="v" id="v28" data-v="28" data-xref="ヘブル人への手紙 13:4; コリント人への第一の手紙 7:32–36; コリント人への第一の手紙 7:26"> しかし、たとい結婚しても、罪を犯すのではない。また、おとめが結婚しても、罪を犯すのではない。ただ、それらの人々はその身に苦難を受けるであろう。わたしは、あなたがたを、それからのがれさせたいのだ。</span>
<span className="v" id="v29" data-v="29" data-xref="ヨハネの第一の手紙 2:17; コリント人への第一の手紙 7:31; ローマ人への手紙 13:11–12"> 兄弟たちよ。わたしの言うことを聞いてほしい。時は縮まっている。今からは妻のある者はないもののように、</span>
<span className="v" id="v30" data-v="30" data-xref="詩篇 30:5; ルカによる福音書 6:25; ルカによる福音書 6:21"> 泣く者は泣かないもののように、喜ぶ者は喜ばないもののように、買う者は持たないもののように、</span>
<span className="v" id="v31" data-v="31" data-xref="ヨハネの第一の手紙 2:17; ペテロの第一の手紙 4:7; ヤコブの手紙 4:14"> 世と交渉のある者は、それに深入りしないようにすべきである。なぜなら、この世の有様は過ぎ去るからである。</span>
<span className="v" id="v32" data-v="32" data-xref="マタイによる福音書 6:25–34; テモテヘの第一の手紙 5:5; ピリピ人への手紙 4:6"> わたしはあなたがたが、思い煩わないようにしていてほしい。未婚の男子は主のことに心をくばって、どうかして主を喜ばせようとするが、</span>
<span className="v" id="v33" data-v="33" data-xref="ペテロの第一の手紙 3:7; コロサイ人への手紙 3:19; エペソ人への手紙 5:25–33"> 結婚している男子はこの世のことに心をくばって、どうかして妻を喜ばせようとして、その心が分れるのである。</span>
<span className="v" id="v34" data-v="34" data-xref="ルカによる福音書 10:40–42; コリント人への第一の手紙 6:20; ルカによる福音書 2:36–37"> 未婚の婦人とおとめとは、主のことに心をくばって、身も魂もきよくなろうとするが、結婚した婦人はこの世のことに心をくばって、どうかして夫を喜ばせようとする。</span>
<span className="v" id="v35" data-v="35" data-xref="コリント人への第一の手紙 7:33–34; コリント人への第一の手紙 7:36; ルカによる福音書 8:14"> わたしがこう言うのは、あなたがたの利益になると思うからであって、あなたがたを束縛するためではない。そうではなく、正しい生活を送って、余念なく主に奉仕させたいからである。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="コリント人への第一の手紙 7:37; コリント人への第一の手紙 7:9; サムエル記上 2:33"> もしある人が、相手のおとめに対して、情熱をいだくようになった場合、それは適当でないと思いつつも、やむを得なければ、望みどおりにしてもよい。それは罪を犯すことではない。ふたりは結婚するがよい。</span>
<span className="v" id="v37" data-v="37"> しかし、彼が心の内で堅く決心していて、無理をしないで自分の思いを制することができ、その上で、相手のおとめをそのままにしておこうと、心の中で決めたなら、そうしてもよい。</span>
<span className="v" id="v38" data-v="38" data-xref="ヘブル人への手紙 13:4; コリント人への第一の手紙 7:1–2; コリント人への第一の手紙 7:8"> だから、相手のおとめと結婚することはさしつかえないが、結婚しない方がもっとよい。</span>
<span className="v" id="v39" data-v="39" data-xref="ローマ人への手紙 7:2–3; コリント人への第二の手紙 6:14–16; コリント人への第一の手紙 7:10"> 妻は夫が生きている間は、その夫につながれている。夫が死ねば、望む人と結婚してもさしつかえないが、それは主にある者とに限る。</span>
<span className="v" id="v40" data-v="40" data-xref="コリント人への第一の手紙 7:35; ペテロの第二の手紙 3:15–16; コリント人への第一の手紙 7:8"> しかし、わたしの意見では、そのままでいたなら、もっと幸福である。わたしも神の霊を受けていると思う。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="コリント人への第一の手紙 12:4–11; コリント人への第一の手紙 14:37; コリント人への第一の手紙 14:1–18"> 兄弟たちよ。霊の賜物については、次のことを知らずにいてもらいたくない。</span>
<span className="v" id="v2" data-v="2" data-xref="ペテロの第一の手紙 4:3; テサロニケ人への第一の手紙 1:9; 詩篇 115:5"> あなたがたがまだ異邦人であった時、誘われるまま、物の言えない偶像のところに引かれて行ったことは、あなたがたの承知しているとおりである。</span>
<span className="v" id="v3" data-v="3" data-xref="ヨハネの第一の手紙 4:2–3; マタイによる福音書 16:16–17; ローマ人への手紙 10:9"> そこで、あなたがたに言っておくが、神の霊によって語る者はだれも「イエスはのろわれよ」とは言わないし、また、聖霊によらなければ、だれも「イエスは主である」と言うことができない。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="ペテロの第一の手紙 4:10; コリント人への第一の手紙 12:28; ローマ人への手紙 12:4–6"> 霊の賜物は種々あるが、御霊は同じである。</span>
<span className="v" id="v5" data-v="5" data-xref="エペソ人への手紙 4:11–12; ローマ人への手紙 12:6–8; ローマ人への手紙 14:8–9"> 務は種々あるが、主は同じである。</span>
<span className="v" id="v6" data-v="6" data-xref="コリント人への第一の手紙 3:7; コリント人への第一の手紙 12:11; ヨハネによる福音書 5:17"> 働きは種々あるが、すべてのものの中に働いてすべてのことをなさる神は、同じである。</span>
<span className="v" id="v7" data-v="7" data-xref="ペテロの第一の手紙 4:10–11; ローマ人への手紙 12:6–8; コリント人への第一の手紙 14:19"> 各自が御霊の現れを賜わっているのは、全体の益になるためである。</span>
<span className="v" id="v8" data-v="8" data-xref="箴言 2:6; コリント人への第一の手紙 2:6–10; 詩篇 143:10"> すなわち、ある人には御霊によって知恵の言葉が与えられ、ほかの人には、同じ御霊によって知識の言、</span>
<span className="v" id="v9" data-v="9" data-xref="ヤコブの手紙 5:14–15; コリント人への第二の手紙 4:13; エペソ人への手紙 2:8"> またほかの人には、同じ御霊によって信仰、またほかの人には、一つの御霊によっていやしの賜物、</span>
<span className="v" id="v10" data-v="10" data-xref="コリント人への第一の手紙 14:39; ヨハネの第一の手紙 4:1; マルコによる福音書 16:17"> またほかの人には力あるわざ、またほかの人には預言、またほかの人には霊を見わける力、またほかの人には種々の異言、またほかの人には異言を解く力が、与えられている。</span>
<span className="v" id="v11" data-v="11" data-xref="コリント人への第一の手紙 12:4; ヘブル人への手紙 2:4; コリント人への第二の手紙 10:13"> すべてこれらのものは、一つの同じ御霊の働きであって、御霊は思いのままに、それらを各自に分け与えられるのである。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="ローマ人への手紙 12:4–5; コロサイ人への手紙 3:15; コリント人への第一の手紙 12:27"> からだが一つであっても肢体は多くあり、また、からだのすべての肢体が多くあっても、からだは一つであるように、キリストの場合も同様である。</span>
<span className="v" id="v13" data-v="13" data-xref="エペソ人への手紙 4:5; コロサイ人への手紙 3:11; ガラテヤ人への手紙 3:28"> なぜなら、わたしたちは皆、ユダヤ人もギリシヤ人も、奴隷も自由人も、一つの御霊によって、一つのからだとなるようにバプテスマを受け、そして皆一つの御霊を飲んだからである。</span>
<span className="v" id="v14" data-v="14" data-xref="コリント人への第一の手紙 12:27–28; コリント人への第一の手紙 12:12; エペソ人への手紙 4:25"> 実際、からだは一つの肢体だけではなく、多くのものからできている。</span>
<span className="v" id="v15" data-v="15" data-xref="士師記 9:8–15; 列王紀下 14:9"> もし足が、わたしは手ではないから、からだに属していないと言っても、それで、からだに属さないわけではない。</span>
<span className="v" id="v16" data-v="16" data-xref="ローマ人への手紙 12:3; コリント人への第一の手紙 12:22; ピリピ人への手紙 2:3"> また、もし耳が、わたしは目ではないから、からだに属していないと言っても、それで、からだに属さないわけではない。</span>
<span className="v" id="v17" data-v="17" data-xref="コリント人への第一の手紙 12:21; 詩篇 139:13–16; 箴言 20:12"> もしからだ全体が目だとすれば、どこで聞くのか。もし、からだ全体が耳だとすれば、どこでかぐのか。</span>
<span className="v" id="v18" data-v="18" data-xref="コリント人への第一の手紙 12:28; ローマ人への手紙 12:3; コリント人への第一の手紙 12:11"> そこで神は御旨のままに、肢体をそれぞれ、からだに備えられたのである。</span>
<span className="v" id="v19" data-v="19"> もし、すべてのものが一つの肢体なら、どこにからだがあるのか。</span>
<span className="v" id="v20" data-v="20" data-xref="コリント人への第一の手紙 12:14; コリント人への第一の手紙 12:12"> ところが実際、肢体は多くあるが、からだは一つなのである。</span>
<span className="v" id="v21" data-v="21" data-xref="エズラ記 10:1–5; ネヘミヤ書 4:16–21; ヨブ記 29:11"> 目は手にむかって、「おまえはいらない」とは言えず、また頭は足にむかって、「おまえはいらない」とも言えない。</span>
<span className="v" id="v22" data-v="22" data-xref="箴言 14:28; 伝道の書 9:14–15; 伝道の書 4:9–12"> そうではなく、むしろ、からだのうちで他よりも弱く見える肢体が、かえって必要なのであり、</span>
<span className="v" id="v23" data-v="23" data-xref="創世記 3:21; 創世記 3:7"> からだのうちで、他よりも見劣りがすると思えるところに、ものを着せていっそう見よくする。麗しくない部分はいっそう麗しくするが、</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 3:11; 創世記 2:25"> 麗しい部分はそうする必要がない。神は劣っている部分をいっそう見よくして、からだに調和をお与えになったのである。</span>
<span className="v" id="v25" data-v="25" data-xref="コリント人への第二の手紙 13:11; コリント人への第一の手紙 1:10–12; ヨハネによる福音書 17:21–26"> それは、からだの中に分裂がなく、それぞれの肢体が互にいたわり合うためなのである。</span>
<span className="v" id="v26" data-v="26" data-xref="ローマ人への手紙 12:15; ガラテヤ人への手紙 6:2; ヘブル人への手紙 13:3"> もし一つの肢体が悩めば、ほかの肢体もみな共に悩み、一つの肢体が尊ばれると、ほかの肢体もみな共に喜ぶ。</span>
<span className="v" id="v27" data-v="27" data-xref="エペソ人への手紙 4:12; コロサイ人への手紙 1:24; エペソ人への手紙 5:30"> あなたがたはキリストのからだであり、ひとりびとりはその肢体である。</span>
<span className="v" id="v28" data-v="28" data-xref="エペソ人への手紙 4:11–13; ローマ人への手紙 12:6–8; コリント人への第一の手紙 12:18"> そして、神は教会の中で、人々を立てて、第一に使徒、第二に預言者、第三に教師とし、次に力あるわざを行う者、次にいやしの賜物を持つ者、また補助者、管理者、種々の異言を語る者をおかれた。</span>
<span className="v" id="v29" data-v="29" data-xref="コリント人への第一の手紙 12:4–11; コリント人への第一の手紙 12:14–20"> みんなが使徒だろうか。みんなが預言者だろうか。みんなが教師だろうか。みんなが力あるわざを行う者だろうか。</span>
<span className="v" id="v30" data-v="30" data-xref="コリント人への第一の手紙 12:10"> みんながいやしの賜物を持っているのだろうか。みんなが異言を語るのだろうか。みんなが異言を解くのだろうか。</span>
<span className="v" id="v31" data-v="31" data-xref="コリント人への第一の手紙 13:1; コリント人への第一の手紙 14:39; マタイによる福音書 5:6"> だが、あなたがたは、更に大いなる賜物を得ようと熱心に努めなさい。そこで、わたしは最もすぐれた道をあなたがたに示そう。</span>

<div className="bible-chapter" lang="ja" dir="ltr" data-lang="ja" data-translation="jpn-kou" data-translation-id="jpn_kou" data-translation-label="口語訳" data-book="1CO" data-book-slug="1-corinthians" data-book-name="コリント人への第一の手紙" data-chapter="14" data-verses="40">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="コリント人への第一の手紙 14:39; テモテヘの第一の手紙 4:14; コリント人への第一の手紙 12:1"> 愛を追い求めなさい。また、霊の賜物を、ことに預言することを、熱心に求めなさい。</span>
<span className="v" id="v2" data-v="2" data-xref="マルコによる福音書 16:17; 使徒行伝 19:6; 使徒行伝 10:46"> 異言を語る者は、人にむかって語るのではなく、神にむかって語るのである。それはだれにもわからない。彼はただ、霊によって奥義を語っているだけである。</span>
<span className="v" id="v3" data-v="3" data-xref="コリント人への第一の手紙 14:12; テモテヘの第一の手紙 4:13; ユダの手紙 1:20"> しかし預言をする者は、人に語ってその徳を高め、彼を励まし、慰めるのである。</span>
<span className="v" id="v4" data-v="4" data-xref="コリント人への第一の手紙 14:22; コリント人への第一の手紙 14:26; マルコによる福音書 16:17"> 異言を語る者は自分だけの徳を高めるが、預言をする者は教会の徳を高める。</span>
<span className="v" id="v5" data-v="5" data-xref="コリント人への第一の手紙 12:28–30; コリント人への第一の手紙 12:10; マルコによる福音書 16:17"> わたしは実際、あなたがたがひとり残らず異言を語ることを望むが、特に預言をしてもらいたい。教会の徳を高めるように異言を解かない限り、異言を語る者よりも、預言をする者の方がまさっている。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="エペソ人への手紙 1:17; ローマ人への手紙 6:17; テモテヘの第二の手紙 3:16"> だから、兄弟たちよ。たといわたしがあなたがたの所に行って異言を語るとしても、啓示か知識か預言か教かを語らなければ、あなたがたに、なんの役に立つだろうか。</span>
<span className="v" id="v7" data-v="7" data-xref="コリント人への第一の手紙 14:8; ルカによる福音書 7:32; コリント人への第一の手紙 13:1"> また、笛や立琴のような楽器でも、もしその音に変化がなければ、何を吹いているのか、弾いているのか、どうして知ることができようか。</span>
<span className="v" id="v8" data-v="8" data-xref="民数記 10:9; エゼキエル書 33:3–6; エレミヤ書 4:19"> また、もしラッパがはっきりした音を出さないなら、だれが戦闘の準備をするだろうか。</span>
<span className="v" id="v9" data-v="9" data-xref="コリント人への第一の手紙 9:26"> それと同様に、もしあなたがたが異言ではっきりしない言葉を語れば、どうしてその語ることがわかるだろうか。それでは、空にむかって語っていることになる。</span>
<span className="v" id="v10" data-v="10"> 世には多種多様の言葉があるだろうが、意味のないものは一つもない。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行伝 28:2; ローマ人への手紙 1:14; コロサイ人への手紙 3:11"> もしその言葉の意味がわからないなら、語っている人にとっては、わたしは異国人であり、語っている人も、わたしにとっては異国人である。</span>
<span className="v" id="v12" data-v="12" data-xref="コリント人への第一の手紙 14:26; コリント人への第一の手紙 14:3–4; コリント人への第一の手紙 14:1"> だから、あなたがたも、霊の賜物を熱心に求めている以上は、教会の徳を高めるために、それを豊かにいただくように励むがよい。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="マルコによる福音書 11:24; コリント人への第一の手紙 12:30; ヨハネによる福音書 14:13–14"> このようなわけであるから、異言を語る者は、自分でそれを解くことができるように祈りなさい。</span>
<span className="v" id="v14" data-v="14" data-xref="コリント人への第一の手紙 14:2; コリント人への第一の手紙 14:15–16; コリント人への第一の手紙 14:19"> もしわたしが異言をもって祈るなら、わたしの霊は祈るが、知性は実を結ばないからである。</span>
<span className="v" id="v15" data-v="15" data-xref="コロサイ人への手紙 3:16; ヨハネによる福音書 4:23–24; エペソ人への手紙 6:18"> すると、どうしたらよいのか。わたしは霊で祈ると共に、知性でも祈ろう。霊でさんびを歌うと共に、知性でも歌おう。</span>
<span className="v" id="v16" data-v="16" data-xref="歴代志上 16:36; 詩篇 106:48; ヨハネの黙示録 5:14"> そうでないと、もしあなたが霊で祝福の言葉を唱えても、初心者の席にいる者は、あなたの感謝に対して、どうしてアァメンと言えようか。あなたが何を言っているのか、彼には通じない。</span>
<span className="v" id="v17" data-v="17" data-xref="コリント人への第一の手紙 14:4; コリント人への第一の手紙 14:6"> 感謝するのは結構だが、それで、ほかの人の徳を高めることにはならない。</span>
<span className="v" id="v18" data-v="18" data-xref="コリント人への第一の手紙 1:4–6; コリント人への第一の手紙 4:7"> わたしは、あなたがたのうちのだれよりも多く異言が語れることを、神に感謝する。</span>
<span className="v" id="v19" data-v="19" data-xref="コリント人への第一の手紙 14:21–22; コリント人への第一の手紙 14:4"> しかし教会では、一万の言葉を異言で語るよりも、ほかの人たちをも教えるために、むしろ五つの言葉を知性によって語る方が願わしい。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="ペテロの第一の手紙 2:2; コリント人への第一の手紙 13:11; ローマ人への手紙 16:19"> 兄弟たちよ。物の考えかたでは、子供となってはいけない。悪事については幼な子となるのはよいが、考えかたでは、おとなとなりなさい。</span>
<span className="v" id="v21" data-v="21" data-xref="イザヤ書 28:11–12; エレミヤ書 5:15; 申命記 28:49"> 律法にこう書いてある、「わたしは、異国の舌と異国のくちびるとで、この民に語るが、それでも、彼らはわたしに耳を傾けない、と主が仰せになる」。</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行伝 2:6–12; マルコによる福音書 16:17; コリント人への第一の手紙 14:1"> このように、異言は信者のためではなく未信者のためのしるしであるが、預言は未信者のためではなく信者のためのしるしである。</span>
<span className="v" id="v23" data-v="23" data-xref="使徒行伝 2:13; 使徒行伝 26:24; コリント人への第一の手紙 11:18"> もし全教会が一緒に集まって、全員が異言を語っているところに、初心者か不信者かがはいってきたら、彼らはあなたがたを気違いだと言うだろう。</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行伝 2:37; コリント人への第一の手紙 2:15; ヘブル人への手紙 4:12–13"> しかし、全員が預言をしているところに、不信者か初心者がはいってきたら、彼の良心はみんなの者に責められ、みんなの者にさばかれ、</span>
<span className="v" id="v25" data-v="25" data-xref="イザヤ書 45:14; ゼカリヤ書 8:23; 詩篇 72:11"> その心の秘密があばかれ、その結果、ひれ伏して神を拝み、「まことに、神があなたがたのうちにいます」と告白するに至るであろう。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="エペソ人への手紙 5:19; ローマ人への手紙 14:19; コリント人への第一の手紙 12:7–10"> すると、兄弟たちよ。どうしたらよいのか。あなたがたが一緒に集まる時、各自はさんびを歌い、教をなし、啓示を告げ、異言を語り、それを解くのであるが、すべては徳を高めるためにすべきである。</span>
<span className="v" id="v27" data-v="27" data-xref="コリント人への第一の手紙 14:26"> もし異言を語る者があれば、ふたりか、多くて三人の者が、順々に語り、そして、ひとりがそれを解くべきである。</span>
<span className="v" id="v28" data-v="28"> もし解く者がいない時には、教会では黙っていて、自分に対しまた神に対して語っているべきである。</span>
<span className="v" id="v29" data-v="29" data-xref="コリント人への第一の手紙 12:10; テサロニケ人への第一の手紙 5:19–21; ヨハネの第一の手紙 4:1–3"> 預言をする者の場合にも、ふたりか三人かが語り、ほかの者はそれを吟味すべきである。</span>
<span className="v" id="v30" data-v="30" data-xref="テサロニケ人への第一の手紙 5:19–20; ヨブ記 33:31–33; ヨブ記 32:11"> しかし、席にいる他の者が啓示を受けた場合には、初めの者は黙るがよい。</span>
<span className="v" id="v31" data-v="31" data-xref="テサロニケ人への第一の手紙 5:14; コリント人への第一の手紙 14:3; テサロニケ人への第一の手紙 5:11"> あなたがたは、みんなが学びみんなが勧めを受けるために、ひとりずつ残らず預言をすることができるのだから。</span>
<span className="v" id="v32" data-v="32" data-xref="使徒行伝 4:19–20; ヨハネの第一の手紙 4:1; サムエル記上 10:10–13"> かつ、預言者の霊は預言者に服従するものである。</span>
<span className="v" id="v33" data-v="33" data-xref="ヤコブの手紙 3:17–18; コリント人への第一の手紙 14:40; テサロニケ人への第二の手紙 3:16"> 神は無秩序の神ではなく、平和の神である。<br />聖徒たちのすべての教会で行われているように、</span>
<span className="v" id="v34" data-v="34" data-xref="テモテヘの第一の手紙 2:11–12; 創世記 3:16; 民数記 30:3–13"> 婦人たちは教会では黙っていなければならない。彼らは語ることが許されていない。だから、律法も命じているように、服従すべきである。</span>
<span className="v" id="v35" data-v="35" data-xref="エペソ人への手紙 5:12; ペテロの第一の手紙 3:7; エペソ人への手紙 5:25–27"> もし何か学びたいことがあれば、家で自分の夫に尋ねるがよい。教会で語るのは、婦人にとっては恥ずべきことである。</span>
<span className="v" id="v36" data-v="36" data-xref="使徒行伝 18:1–17; ゼカリヤ書 14:8; 使徒行伝 17:15"> それとも、神の言はあなたがたのところから出たのか。あるいは、あなたがただけにきたのか。</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="ヨハネの第一の手紙 4:6; コリント人への第二の手紙 10:7; ペテロの第二の手紙 3:2"> もしある人が、自分は預言者か霊の人であると思っているなら、わたしがあなたがたに書いていることは、主の命令だと認めるべきである。</span>
<span className="v" id="v38" data-v="38" data-xref="テモテヘの第二の手紙 4:3–4; ホセア書 4:17; ヨハネの黙示録 22:11–12"> もしそれを無視する者があれば、その人もまた無視される。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="コリント人への第一の手紙 12:31; コリント人への第一の手紙 14:1; テサロニケ人への第一の手紙 5:20"> わたしの兄弟たちよ。このようなわけだから、預言することを熱心に求めなさい。また、異言を語ることを妨げてはならない。</span>
<span className="v" id="v40" data-v="40" data-xref="コロサイ人への手紙 2:5; テトスヘの手紙 1:5; コリント人への第一の手紙 14:26–33"> しかし、すべてのことを適宜に、かつ秩序を正して行うがよい。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ピリピ人への手紙 3:17; テサロニケ人への第一の手紙 1:6; コリント人への第一の手紙 4:16"> わたしがキリストにならう者であるように、あなたがたもわたしにならう者になりなさい。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="テサロニケ人への第二の手紙 2:15; コリント人への第一の手紙 4:17; 箴言 31:28–31"> あなたがたが、何かにつけわたしを覚えていて、あなたがたに伝えたとおりに言伝えを守っているので、わたしは満足に思う。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 3:16; コロサイ人への手紙 1:18; コロサイ人への手紙 3:18"> しかし、あなたがたに知っていてもらいたい。すべての男のかしらはキリストであり、女のかしらは男であり、キリストのかしらは神である。</span>
<span className="v" id="v4" data-v="4" data-xref="サムエル記下 15:30; コリント人への第一の手紙 12:28; コリント人への第一の手紙 12:10"> 祈をしたり預言をしたりする時、かしらに物をかぶる男は、そのかしらをはずかしめる者である。</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 21:12; ルカによる福音書 2:36; 使徒行伝 2:17"> 祈をしたり預言をしたりする時、かしらにおおいをかけない女は、そのかしらをはずかしめる者である。それは、髪をそったのとまったく同じだからである。</span>
<span className="v" id="v6" data-v="6" data-xref="申命記 22:5; 民数記 5:18"> もし女がおおいをかけないなら、髪を切ってしまうがよい。髪を切ったりそったりするのが、女にとって恥ずべきことであるなら、おおいをかけるべきである。</span>
<span className="v" id="v7" data-v="7" data-xref="コリント人への第一の手紙 11:3; 創世記 5:1; 詩篇 8:6"> 男は、神のかたちであり栄光であるから、かしらに物をかぶるべきではない。女は、また男の光栄である。</span>
<span className="v" id="v8" data-v="8" data-xref="テモテヘの第一の手紙 2:13; 創世記 2:21–23"> なぜなら、男が女から出たのではなく、女が男から出たのだからである。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 2:18; 創世記 2:23–24; 創世記 2:20"> また、男は女のために造られたのではなく、女が男のために造られたのである。</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 24:64–65; ヘブル人への手紙 1:14; マタイによる福音書 18:10"> それだから、女は、かしらに権威のしるしをかぶるべきである。それは天使たちのためでもある。</span>
<span className="v" id="v11" data-v="11" data-xref="ガラテヤ人への手紙 3:28; コリント人への第一の手紙 7:10–14; コリント人への第一の手紙 12:12–22"> ただ、主にあっては、男なしには女はないし、女なしには男はない。</span>
<span className="v" id="v12" data-v="12" data-xref="ローマ人への手紙 11:36; コリント人への第一の手紙 8:6; ヘブル人への手紙 1:2–3"> それは、女が男から出たように、男もまた女から生れたからである。そして、すべてのものは神から出たのである。</span>
<span className="v" id="v13" data-v="13" data-xref="ルカによる福音書 12:57; ヨハネによる福音書 7:24; コリント人への第一の手紙 10:15"> あなたがた自身で判断してみるがよい。女がおおいをかけずに神に祈るのは、ふさわしいことだろうか。</span>
<span className="v" id="v14" data-v="14" data-xref="サムエル記下 14:26; コリント人への第一の手紙 14:35"> 自然そのものが教えているではないか。男に長い髪があれば彼の恥になり、</span>
<span className="v" id="v15" data-v="15"> 女に長い髪があれば彼女の光栄になるのである。長い髪はおおいの代りに女に与えられているものだからである。</span>
<span className="v" id="v16" data-v="16" data-xref="コリント人への第一の手紙 7:17; テモテヘの第一の手紙 6:3–4; テサロニケ人への第一の手紙 2:14"> しかし、だれかがそれに反対の意見を持っていても、そんな風習はわたしたちにはなく、神の諸教会にもない。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="ヘブル人への手紙 10:25; コリント人への第一の手紙 14:23; コリント人への第一の手紙 11:22"> ところで、次のことを命じるについては、あなたがたをほめるわけにはいかない。というのは、あなたがたの集まりが利益にならないで、かえって損失になっているからである。</span>
<span className="v" id="v18" data-v="18" data-xref="コリント人への第一の手紙 3:3; コリント人への第一の手紙 1:10–12; コリント人への第一の手紙 5:1"> まず、あなたがたが教会に集まる時、お互の間に分争があることを、わたしは耳にしており、そしていくぶんか、それを信じている。</span>
<span className="v" id="v19" data-v="19" data-xref="ヨハネの第一の手紙 2:19; テトスヘの手紙 3:10; 使徒行伝 20:30"> たしかに、あなたがたの中でほんとうの者が明らかにされるためには、分派もなければなるまい。</span>
<span className="v" id="v20" data-v="20"> そこで、あなたがたが一緒に集まるとき、主の晩餐を守ることができないでいる。</span>
<span className="v" id="v21" data-v="21" data-xref="ペテロの第二の手紙 2:13; ユダの手紙 1:12; コリント人への第一の手紙 11:23–25"> というのは、食事の際、各自が自分の晩餐をかってに先に食べるので、飢えている人があるかと思えば、酔っている人がある始末である。</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行伝 20:28; 箴言 17:5; ヤコブの手紙 2:5–6"> あなたがたには、飲み食いをする家がないのか。それとも、神の教会を軽んじ、貧しい人々をはずかしめるのか。わたしはあなたがたに対して、なんと言おうか。あなたがたを、ほめようか。この事では、ほめるわけにはいかない。</span>
<span className="v" id="v23" data-v="23" data-xref="ルカによる福音書 22:19–20; マタイによる福音書 26:26–28; コリント人への第一の手紙 11:23–25"> わたしは、主から受けたことを、また、あなたがたに伝えたのである。すなわち、主イエスは、渡される夜、パンをとり、</span>
<span className="v" id="v24" data-v="24" data-xref="ヨハネによる福音書 6:53–58; コリント人への第一の手紙 11:27–28; コリント人への第一の手紙 10:3–4"> 感謝してこれをさき、そして言われた、「これはあなたがたのための、わたしのからだである。わたしを記念するため、このように行いなさい」。</span>
<span className="v" id="v25" data-v="25" data-xref="ルカによる福音書 22:20; ヘブル人への手紙 9:15–20; ヘブル人への手紙 13:20"> 食事ののち、杯をも同じようにして言われた、「この杯は、わたしの血による新しい契約である。飲むたびに、わたしの記念として、このように行いなさい」。</span>
<span className="v" id="v26" data-v="26" data-xref="ヘブル人への手紙 9:28; ヨハネの黙示録 1:7; ヨハネによる福音書 14:3"> だから、あなたがたは、このパンを食し、この杯を飲むごとに、それによって、主がこられる時に至るまで、主の死を告げ知らせるのである。</span>
<span className="v" id="v27" data-v="27" data-xref="ヨハネによる福音書 6:51; コリント人への第一の手紙 10:21; ヘブル人への手紙 10:29"> だから、ふさわしくないままでパンを食し主の杯を飲む者は、主のからだと血とを犯すのである。</span>
<span className="v" id="v28" data-v="28" data-xref="ガラテヤ人への手紙 6:4; コリント人への第二の手紙 13:5; 哀歌 3:40"> だれでもまず自分を吟味し、それからパンを食べ杯を飲むべきである。</span>
<span className="v" id="v29" data-v="29" data-xref="コリント人への第一の手紙 11:27; コリント人への第一の手紙 11:30; コリント人への第一の手紙 11:32–34"> 主のからだをわきまえないで飲み食いする者は、その飲み食いによって自分にさばきを招くからである。</span>
<span className="v" id="v30" data-v="30" data-xref="ヨハネの黙示録 3:19; 民数記 20:12; アモス書 3:2"> あなたがたの中に、弱い者や病人が大ぜいおり、また眠った者も少なくないのは、そのためである。</span>
<span className="v" id="v31" data-v="31" data-xref="ヨハネの第一の手紙 1:9; 詩篇 32:3–5; ヨハネの黙示録 2:5"> しかし、自分をよくわきまえておくならば、わたしたちはさばかれることはないであろう。</span>
<span className="v" id="v32" data-v="32" data-xref="ヘブル人への手紙 12:5–11; 詩篇 118:18; 箴言 3:11–12"> しかし、さばかれるとすれば、それは、この世と共に罪に定められないために、主の懲らしめを受けることなのである。</span>
<span className="v" id="v33" data-v="33"> それだから、兄弟たちよ。食事のために集まる時には、互に待ち合わせなさい。</span>
<span className="v" id="v34" data-v="34" data-xref="コリント人への第一の手紙 11:21–22; コリント人への第一の手紙 7:17; コリント人への第一の手紙 4:19"> もし空腹であったら、さばきを受けに集まることにならないため、家で食べるがよい。そのほかの事は、わたしが行った時に、定めることにしよう。</span>
</div>

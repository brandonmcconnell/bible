<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行伝 9:17; テモテヘの第一の手紙 2:7; コリント人への第一の手紙 9:19"> わたしは自由な者ではないか。使徒ではないか。わたしたちの主イエスを見たではないか。あなたがたは、主にあるわたしの働きの実ではないか。</span>
<span className="v" id="v2" data-v="2" data-xref="コリント人への第二の手紙 12:12; ヨハネによる福音書 6:27; コリント人への第二の手紙 3:1–3"> わたしは、ほかの人に対しては使徒でないとしても、あなたがたには使徒である。あなたがたが主にあることは、わたしの使徒職の印なのである。</span>
<span className="v" id="v3" data-v="3" data-xref="コリント人への第二の手紙 12:16–19; コリント人への第二の手紙 13:3; コリント人への第二の手紙 13:10"> わたしの批判者たちに対する弁明は、これである。</span>
<span className="v" id="v4" data-v="4" data-xref="テサロニケ人への第一の手紙 2:6; テサロニケ人への第二の手紙 3:8–9; ルカによる福音書 10:7"> わたしたちには、飲み食いをする権利がないのか。</span>
<span className="v" id="v5" data-v="5" data-xref="ヨハネによる福音書 1:42; ヘブル人への手紙 13:4; マタイによる福音書 8:14"> わたしたちには、ほかの使徒たちや主の兄弟たちやケパのように、信者である妻を連れて歩く権利がないのか。</span>
<span className="v" id="v6" data-v="6" data-xref="テサロニケ人への第二の手紙 3:7–9; 使徒行伝 13:1–2; 使徒行伝 4:36"> それとも、わたしとバルナバとだけには、労働をせずにいる権利がないのか。</span>
<span className="v" id="v7" data-v="7" data-xref="箴言 27:18; 申命記 20:6; テモテヘの第二の手紙 2:3–4"> いったい、自分で費用を出して軍隊に加わる者があろうか。ぶどう畑を作っていて、その実を食べない者があろうか。また、羊を飼っていて、その乳を飲まない者があろうか。</span>
<span className="v" id="v8" data-v="8" data-xref="イザヤ書 8:20; テサロニケ人への第一の手紙 4:8; ローマ人への手紙 3:31"> わたしは、人間の考えでこう言うのではない。律法もまた、そのように言っているではないか。</span>
<span className="v" id="v9" data-v="9" data-xref="申命記 25:4; テモテヘの第一の手紙 5:18; 詩篇 104:27"> すなわち、モーセの律法に、「穀物をこなしている牛に、くつこをかけてはならない」と書いてある。神は、牛のことを心にかけておられるのだろうか。</span>
<span className="v" id="v10" data-v="10" data-xref="テモテヘの第二の手紙 2:6; ローマ人への手紙 15:4; ローマ人への手紙 4:23–24"> それとも、もっぱら、わたしたちのために言っておられるのか。もちろん、それはわたしたちのためにしるされたのである。すなわち、耕す者は望みをもって耕し、穀物をこなす者は、その分け前をもらう望みをもってこなすのである。</span>
<span className="v" id="v11" data-v="11" data-xref="ローマ人への手紙 15:27; ガラテヤ人への手紙 6:6; コリント人への第二の手紙 11:15"> もしわたしたちが、あなたがたのために霊のものをまいたのなら、肉のものをあなたがたから刈りとるのは、行き過ぎだろうか。</span>
<span className="v" id="v12" data-v="12" data-xref="コリント人への第一の手紙 9:15; コリント人への第一の手紙 9:18; コリント人への第二の手紙 11:12"> もしほかの人々が、あなたがたに対するこの権利にあずかっているとすれば、わたしたちはなおさらのことではないか。しかしわたしたちは、この権利を利用せず、かえってキリストの福音の妨げにならないようにと、すべてのことを忍んでいる。</span>
<span className="v" id="v13" data-v="13" data-xref="民数記 18:8–20; 民数記 5:9–10; レビ記 6:26"> あなたがたは、宮仕えをしている人たちは宮から下がる物を食べ、祭壇に奉仕している人たちは祭壇の供え物の分け前にあずかることを、知らないのか。</span>
<span className="v" id="v14" data-v="14" data-xref="マタイによる福音書 10:10; テモテヘの第一の手紙 5:17–18; コリント人への第一の手紙 9:4"> それと同様に、主は、福音を宣べ伝えている者たちが福音によって生活すべきことを、定められたのである。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="テサロニケ人への第一の手紙 2:9; テサロニケ人への第二の手紙 3:8; コリント人への第一の手紙 9:12"> しかしわたしは、これらの権利を一つも利用しなかった。また、自分がそうしてもらいたいから、このように書くのではない。そうされるよりは、死ぬ方がましである。わたしのこの誇は、何者にも奪い去られてはならないのだ。</span>
<span className="v" id="v16" data-v="16" data-xref="ローマ人への手紙 1:14; エレミヤ書 20:9; コロサイ人への手紙 4:17"> わたしが福音を宣べ伝えても、それは誇にはならない。なぜなら、わたしは、そうせずにはおれないからである。もし福音を宣べ伝えないなら、わたしはわざわいである。</span>
<span className="v" id="v17" data-v="17" data-xref="ガラテヤ人への手紙 2:7; コリント人への第一の手紙 3:8; 歴代志上 28:9"> 進んでそれをすれば、報酬を受けるであろう。しかし、進んでしないとしても、それは、わたしにゆだねられた務なのである。</span>
<span className="v" id="v18" data-v="18" data-xref="コリント人への第二の手紙 11:7–9; コリント人への第一の手紙 8:9; テサロニケ人への第一の手紙 2:6"> それでは、その報酬はなんであるか。福音を宣べ伝えるのにそれを無代価で提供し、わたしが宣教者として持つ権利を利用しないことである。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="ガラテヤ人への手紙 5:13; マタイによる福音書 18:15; ヤコブの手紙 5:19–20"> わたしは、すべての人に対して自由であるが、できるだけ多くの人を得るために、自ら進んですべての人の奴隷になった。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行伝 16:3; ガラテヤ人への手紙 5:18; 使徒行伝 21:20–26"> ユダヤ人には、ユダヤ人のようになった。ユダヤ人を得るためである。律法の下にある人には、わたし自身は律法の下にはないが、律法の下にある者のようになった。律法の下にある人を得るためである。</span>
<span className="v" id="v21" data-v="21" data-xref="ローマ人への手紙 2:12; ローマ人への手紙 2:14; ガラテヤ人への手紙 3:2"> 律法のない人には――わたしは神の律法の外にあるのではなく、キリストの律法の中にあるのだが――律法のない人のようになった。律法のない人を得るためである。</span>
<span className="v" id="v22" data-v="22" data-xref="コリント人への第一の手紙 10:33; ローマ人への手紙 15:1; コリント人への第一の手紙 9:19"> 弱い人には弱い者になった。弱い人を得るためである。すべての人に対しては、すべての人のようになった。なんとかして幾人かを救うためである。</span>
<span className="v" id="v23" data-v="23" data-xref="テモテヘの第二の手紙 2:10; マルコによる福音書 8:35; コリント人への第一の手紙 9:25–27"> 福音のために、わたしはどんな事でもする。わたしも共に福音にあずかるためである。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="ピリピ人への手紙 3:14; ヘブル人への手紙 12:1; テモテヘの第二の手紙 4:7–8"> あなたがたは知らないのか。競技場で走る者は、みな走りはするが、賞を得る者はひとりだけである。あなたがたも、賞を得るように走りなさい。</span>
<span className="v" id="v25" data-v="25" data-xref="テモテヘの第二の手紙 2:5; ヨハネの黙示録 2:10; テモテヘの第二の手紙 4:7–8"> しかし、すべて競技をする者は、何ごとにも節制をする。彼らは朽ちる冠を得るためにそうするが、わたしたちは朽ちない冠を得るためにそうするのである。</span>
<span className="v" id="v26" data-v="26" data-xref="ペテロの第二の手紙 1:10; ピリピ人への手紙 1:21; テモテヘの第二の手紙 2:5"> そこで、わたしは目標のはっきりしないような走り方をせず、空を打つような拳闘はしない。</span>
<span className="v" id="v27" data-v="27" data-xref="ローマ人への手紙 8:13; コリント人への第一の手紙 9:25; コロサイ人への手紙 3:5"> すなわち、自分のからだを打ちたたいて服従させるのである。そうしないと、ほかの人に宣べ伝えておきながら、自分は失格者になるかも知れない。</span>
</div>

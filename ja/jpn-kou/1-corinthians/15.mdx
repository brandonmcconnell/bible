<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ガラテヤ人への手紙 1:6–12; ペテロの第一の手紙 5:12; コリント人への第一の手紙 15:3–11"> 兄弟たちよ。わたしが以前あなたがたに伝えた福音、あなたがたが受けいれ、それによって立ってきたあの福音を、思い起してもらいたい。</span>
<span className="v" id="v2" data-v="2" data-xref="ヘブル人への手紙 3:6; ヘブル人への手紙 2:1; ヘブル人への手紙 3:14"> もしあなたがたが、いたずらに信じないで、わたしの宣べ伝えたとおりの言葉を固く守っておれば、この福音によって救われるのである。</span>
<span className="v" id="v3" data-v="3" data-xref="ペテロの第一の手紙 2:24; ガラテヤ人への手紙 1:4; イザヤ書 53:1–12"> わたしが最も大事なこととしてあなたがたに伝えたのは、わたし自身も受けたことであった。すなわちキリストが、聖書に書いてあるとおり、わたしたちの罪のために死んだこと、</span>
<span className="v" id="v4" data-v="4" data-xref="ホセア書 6:2; マタイによる福音書 12:40; 詩篇 16:10–11"> そして葬られたこと、聖書に書いてあるとおり、三日目によみがえったこと、</span>
<span className="v" id="v5" data-v="5" data-xref="マルコによる福音書 16:14; コリント人への第一の手紙 1:12; ヨハネによる福音書 1:42"> ケパに現れ、次に、十二人に現れたことである。</span>
<span className="v" id="v6" data-v="6" data-xref="マタイによる福音書 28:10; マルコによる福音書 16:7; 使徒行伝 13:36"> そののち、五百人以上の兄弟たちに、同時に現れた。その中にはすでに眠った者たちもいるが、大多数はいまなお生存している。</span>
<span className="v" id="v7" data-v="7" data-xref="ルカによる福音書 24:50; 使徒行伝 1:2–12; ルカによる福音書 24:33"> そののち、ヤコブに現れ、次に、すべての使徒たちに現れ、</span>
<span className="v" id="v8" data-v="8" data-xref="コリント人への第一の手紙 9:1; 使徒行伝 26:16; 使徒行伝 22:18"> そして最後に、いわば、月足らずに生れたようなわたしにも、現れたのである。</span>
<span className="v" id="v9" data-v="9" data-xref="エペソ人への手紙 3:7–8; テモテヘの第一の手紙 1:13–15; 使徒行伝 8:3"> 実際わたしは、神の教会を迫害したのであるから、使徒たちの中でいちばん小さい者であって、使徒と呼ばれる値うちのない者である。</span>
<span className="v" id="v10" data-v="10" data-xref="ピリピ人への手紙 4:13; コリント人への第二の手紙 3:5; ピリピ人への手紙 2:13"> しかし、神の恵みによって、わたしは今日あるを得ているのである。そして、わたしに賜わった神の恵みはむだにならず、むしろ、わたしは彼らの中のだれよりも多く働いてきた。しかしそれは、わたし自身ではなく、わたしと共にあった神の恵みである。</span>
<span className="v" id="v11" data-v="11" data-xref="コリント人への第一の手紙 15:3–4; コリント人への第一の手紙 2:2"> とにかく、わたしにせよ彼らにせよ、そのように、わたしたちは宣べ伝えており、そのように、あなたがたは信じたのである。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="使徒行伝 26:8; 使徒行伝 17:32; テモテヘの第二の手紙 2:18"> さて、キリストは死人の中からよみがえったのだと宣べ伝えられているのに、あなたがたの中のある者が、死人の復活などはないと言っているのは、どうしたことか。</span>
<span className="v" id="v13" data-v="13" data-xref="ヨハネによる福音書 11:25–26; ローマ人への手紙 8:11; テサロニケ人への第一の手紙 4:14"> もし死人の復活がないならば、キリストもよみがえらなかったであろう。</span>
<span className="v" id="v14" data-v="14" data-xref="コリント人への第一の手紙 15:17; テサロニケ人への第一の手紙 4:14; ガラテヤ人への手紙 2:2"> もしキリストがよみがえらなかったとしたら、わたしたちの宣教はむなしく、あなたがたの信仰もまたむなしい。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行伝 2:24; ヨブ記 13:7–10; 使徒行伝 2:32"> すると、わたしたちは神にそむく偽証人にさえなるわけだ。なぜなら、万一死人がよみがえらないとしたら、わたしたちは神が実際よみがえらせなかったはずのキリストを、よみがえらせたと言って、神に反するあかしを立てたことになるからである。</span>
<span className="v" id="v16" data-v="16"> もし死人がよみがえらないなら、キリストもよみがえらなかったであろう。</span>
<span className="v" id="v17" data-v="17" data-xref="ローマ人への手紙 4:25; ペテロの第一の手紙 1:3; コリント人への第一の手紙 15:14"> もしキリストがよみがえらなかったとすれば、あなたがたの信仰は空虚なものとなり、あなたがたは、いまなお罪の中にいることになろう。</span>
<span className="v" id="v18" data-v="18" data-xref="テサロニケ人への第一の手紙 4:13–14; ヨハネの黙示録 14:13; テサロニケ人への第一の手紙 4:16"> そうだとすると、キリストにあって眠った者たちは、滅んでしまったのである。</span>
<span className="v" id="v19" data-v="19" data-xref="ペテロの第一の手紙 1:21; ヨハネの黙示録 14:13; テモテヘの第二の手紙 1:12"> もしわたしたちが、この世の生活でキリストにあって単なる望みをいだいているだけだとすれば、わたしたちは、すべての人の中で最もあわれむべき存在となる。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="コリント人への第一の手紙 15:23; 使徒行伝 26:23; ヨハネの黙示録 1:5"> しかし事実、キリストは眠っている者の初穂として、死人の中からよみがえったのである。</span>
<span className="v" id="v21" data-v="21" data-xref="ヨハネによる福音書 11:25; ローマ人への手紙 5:12–17; コリント人への第一の手紙 15:22"> それは、死がひとりの人によってきたのだから、死人の復活もまた、ひとりの人によってこなければならない。</span>
<span className="v" id="v22" data-v="22" data-xref="ローマ人への手紙 5:12–21; コリント人への第一の手紙 15:45–49; ヨハネによる福音書 5:21–29"> アダムにあってすべての人が死んでいるのと同じように、キリストにあってすべての人が生かされるのである。</span>
<span className="v" id="v23" data-v="23" data-xref="イザヤ書 26:19; ガラテヤ人への手紙 3:29; コリント人への第一の手紙 15:52"> ただ、各自はそれぞれの順序に従わねばならない。最初はキリスト、次に、主の来臨に際してキリストに属する者たち、</span>
<span className="v" id="v24" data-v="24" data-xref="ダニエル書 7:27; ダニエル書 7:14; マタイによる福音書 28:18"> それから終末となって、その時に、キリストはすべての君たち、すべての権威と権力とを打ち滅ぼして、国を父なる神に渡されるのである。</span>
<span className="v" id="v25" data-v="25" data-xref="ヘブル人への手紙 10:12–13; 詩篇 110:1; マタイによる福音書 22:44"> なぜなら、キリストはあらゆる敵をその足もとに置く時までは、支配を続けることになっているからである。</span>
<span className="v" id="v26" data-v="26" data-xref="テモテヘの第二の手紙 1:10; コリント人への第一の手紙 15:55; ヨハネの黙示録 21:4"> 最後の敵として滅ぼされるのが、死である。</span>
<span className="v" id="v27" data-v="27" data-xref="詩篇 8:6; ヘブル人への手紙 2:8; マタイによる福音書 28:18"> 「神は万物を彼の足もとに従わせた」からである。ところが、万物を従わせたと言われる時、万物を従わせたかたがそれに含まれていないことは、明らかである。</span>
<span className="v" id="v28" data-v="28" data-xref="コロサイ人への手紙 3:11; コリント人への第一の手紙 3:23; エペソ人への手紙 1:23"> そして、万物が神に従う時には、御子自身もまた、万物を従わせたそのかたに従うであろう。それは、神がすべての者にあって、すべてとなられるためである。</span>
</div>
<div className="bp poetry">
<span className="v" id="v29" data-v="29" data-xref="ローマ人への手紙 6:3–4; コリント人への第一の手紙 15:16; マタイによる福音書 20:22"> そうでないとすれば、死者のためにバプテスマを受ける人々は、なぜそれをするのだろうか。もし死者が全くよみがえらないとすれば、なぜ人々が死者のためにバプテスマを受けるのか。</span>
<span className="v" id="v30" data-v="30" data-xref="コリント人への第二の手紙 6:9; ガラテヤ人への手紙 5:11; コリント人への第二の手紙 4:7–12"> また、なんのために、わたしたちはいつも危険を冒しているのか。</span>
<span className="v" id="v31" data-v="31" data-xref="コリント人への第二の手紙 4:10–11; ローマ人への手紙 8:36; コリント人への第一の手紙 4:9–13"> 兄弟たちよ。わたしたちの主キリスト・イエスにあって、わたしがあなたがたにつき持っている誇にかけて言うが、わたしは日々死んでいるのである。</span>
<span className="v" id="v32" data-v="32" data-xref="イザヤ書 22:13; イザヤ書 56:12; ルカによる福音書 12:19"> もし、わたしが人間の考えによってエペソで獣と戦ったとすれば、それはなんの役に立つのか。もし死人がよみがえらないのなら、「わたしたちは飲み食いしようではないか。あすもわからぬいのちなのだ」。</span>
<span className="v" id="v33" data-v="33" data-xref="箴言 13:20; マタイによる福音書 24:4; コリント人への第一の手紙 5:6"> まちがってはいけない。<br /><span className="pl pl-1">「悪い交わりは、良いならわしをそこなう」。</span></span>
<span className="v" id="v34" data-v="34" data-xref="コリント人への第一の手紙 6:5; ローマ人への手紙 13:11; ヘブル人への手紙 5:11–12"> <span className="pl pl-1">目ざめて身を正し、罪を犯さないようにしなさい。あなたがたのうちには、神について無知な人々がいる。あなたがたをはずかしめるために、わたしはこう言うのだ。</span></span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="エゼキエル書 37:3; コリント人への第一の手紙 15:38–53; ローマ人への手紙 9:19"> しかし、ある人は言うだろう。「どんなふうにして、死人がよみがえるのか。どんなからだをして来るのか」。</span>
<span className="v" id="v36" data-v="36" data-xref="ヨハネによる福音書 12:24; ルカによる福音書 11:40; エペソ人への手紙 5:15"> おろかな人である。あなたのまくものは、死ななければ、生かされないではないか。</span>
<span className="v" id="v37" data-v="37"> また、あなたのまくのは、やがて成るべきからだをまくのではない。麦であっても、ほかの種であっても、ただの種粒にすぎない。</span>
<span className="v" id="v38" data-v="38" data-xref="コリント人への第一の手紙 3:7; イザヤ書 61:11; マルコによる福音書 4:26–29"> ところが、神はみこころのままに、これにからだを与え、その一つ一つの種にそれぞれのからだをお与えになる。</span>
<span className="v" id="v39" data-v="39" data-xref="創世記 1:20–26"> すべての肉が、同じ肉なのではない。人の肉があり、獣の肉があり、鳥の肉があり、魚の肉がある。</span>
<span className="v" id="v40" data-v="40"> 天に属するからだもあれば、地に属するからだもある。天に属するものの栄光は、地に属するものの栄光と違っている。</span>
<span className="v" id="v41" data-v="41" data-xref="イザヤ書 24:23; 詩篇 148:3–5; 申命記 4:19"> 日の栄光があり、月の栄光があり、星の栄光がある。また、この星とあの星との間に、栄光の差がある。</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="マタイによる福音書 13:43; ダニエル書 12:3; ローマ人への手紙 8:21"> 死人の復活も、また同様である。朽ちるものでまかれ、朽ちないものによみがえり、</span>
<span className="v" id="v43" data-v="43" data-xref="コリント人への第一の手紙 6:14; コロサイ人への手紙 3:4; ピリピ人への手紙 3:20–21"> 卑しいものでまかれ、栄光あるものによみがえり、弱いものでまかれ、強いものによみがえり、</span>
<span className="v" id="v44" data-v="44" data-xref="コリント人への第一の手紙 15:50; ルカによる福音書 24:31; ヨハネによる福音書 20:19"> 肉のからだでまかれ、霊のからだによみがえるのである。肉のからだがあるのだから、霊のからだもあるわけである。</span>
<span className="v" id="v45" data-v="45" data-xref="ヨハネによる福音書 5:21; 創世記 2:7; ローマ人への手紙 8:2"> 聖書に「最初の人アダムは生きたものとなった」と書いてあるとおりである。しかし最後のアダムは命を与える霊となった。</span>
<span className="v" id="v46" data-v="46" data-xref="コロサイ人への手紙 3:9–10; ローマ人への手紙 6:6; エペソ人への手紙 4:22–24"> 最初にあったのは、霊のものではなく肉のものであって、その後に霊のものが来るのである。</span>
<span className="v" id="v47" data-v="47" data-xref="ヨハネによる福音書 3:31; 創世記 2:7; 創世記 3:19"> 第一の人は地から出て土に属し、第二の人は天から来る。</span>
<span className="v" id="v48" data-v="48" data-xref="創世記 5:3; ローマ人への手紙 5:12–21; ヨハネによる福音書 3:6"> この土に属する人に、土に属している人々は等しく、この天に属する人に、天に属している人々は等しいのである。</span>
<span className="v" id="v49" data-v="49" data-xref="ローマ人への手紙 8:29; コリント人への第二の手紙 3:18; 創世記 5:3"> すなわち、わたしたちは、土に属している形をとっているのと同様に、また天に属している形をとるであろう。</span>
</div>
<div className="bp poetry">
<span className="v" id="v50" data-v="50" data-xref="ヨハネによる福音書 3:3–6; マタイによる福音書 16:17; エペソ人への手紙 4:17"> 兄弟たちよ。わたしはこの事を言っておく。肉と血とは神の国を継ぐことができないし、朽ちるものは朽ちないものを継ぐことがない。</span>
<span className="v" id="v51" data-v="51" data-xref="テサロニケ人への第一の手紙 4:14–17; ピリピ人への手紙 3:21; コリント人への第一の手紙 15:20"> ここで、あなたがたに奥義を告げよう。わたしたちすべては、眠り続けるのではない。終りのラッパの響きと共に、またたく間に、一瞬にして変えられる。</span>
<span className="v" id="v52" data-v="52" data-xref="テサロニケ人への第一の手紙 4:16–17; マタイによる福音書 24:31; ヨハネによる福音書 5:28"> というのは、ラッパが響いて、死人は朽ちない者によみがえらされ、わたしたちは変えられるのである。</span>
<span className="v" id="v53" data-v="53" data-xref="コリント人への第二の手紙 5:2–4; ヨハネの第一の手紙 3:2; ローマ人への手紙 2:7"> なぜなら、この朽ちるものは必ず朽ちないものを着、この死ぬものは必ず死なないものを着ることになるからである。</span>
<span className="v" id="v54" data-v="54" data-xref="イザヤ書 25:8; ヨハネの黙示録 20:14; ヘブル人への手紙 2:14–15"> この朽ちるものが朽ちないものを着、この死ぬものが死なないものを着るとき、聖書に書いてある言葉が成就するのである。</span>
<span className="v" id="v55" data-v="55" data-xref="ホセア書 13:14; 詩篇 89:48; 使徒行伝 2:27"> <span className="pl pl-1">「死は勝利にのまれてしまった。</span><br /><span className="pl pl-1">死よ、おまえの勝利は、どこにあるのか。</span><br /><span className="pl pl-1">死よ、おまえのとげは、どこにあるのか」。</span></span>
<span className="v" id="v56" data-v="56" data-xref="ローマ人への手紙 4:15; ガラテヤ人への手紙 3:10–13; ローマ人への手紙 7:5–13"> <span className="pl pl-1">死のとげは罪である。罪の力は律法である。</span></span>
<span className="v" id="v57" data-v="57" data-xref="コリント人への第二の手紙 2:14; ローマ人への手紙 8:37; ヨハネの第一の手紙 5:4–5"> <span className="pl pl-1">しかし感謝すべきことには、神はわたしたちの主イエス・キリストによって、わたしたちに勝利を賜わったのである。</span></span>
<span className="v" id="v58" data-v="58" data-xref="ガラテヤ人への手紙 6:9; 歴代志下 15:7; ヘブル人への手紙 6:10"> <span className="pl pl-1">だから、愛する兄弟たちよ。堅く立って動かされず、いつも全力を注いで主のわざに励みなさい。主にあっては、あなたがたの労苦がむだになることはないと、あなたがたは知っているからである。</span></span>
</div>

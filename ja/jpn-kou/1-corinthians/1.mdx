<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ローマ人への手紙 1:1; エペソ人への手紙 1:1; コリント人への第二の手紙 1:1"> 神の御旨により召されてキリスト・イエスの使徒となったパウロと、兄弟ソステネから、</span>
<span className="v" id="v2" data-v="2" data-xref="ローマ人への手紙 1:7; コリント人への第一の手紙 6:9–11; コリント人への第一の手紙 1:30"> コリントにある神の教会、すなわち、わたしたちの主イエス・キリストの御名を至る所で呼び求めているすべての人々と共に、キリスト・イエスにあってきよめられ、聖徒として召されたかたがたへ。このキリストは、わたしたちの主であり、また彼らの主であられる。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="ローマ人への手紙 1:7; コリント人への第二の手紙 1:2; ペテロの第一の手紙 1:2"> わたしたちの父なる神と主イエス・キリストから、恵みと平安とが、あなたがたにあるように。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="ローマ人への手紙 1:8; ヨハネによる福音書 14:26; テモテヘの第一の手紙 1:14"> わたしは、あなたがたがキリスト・イエスにあって与えられた神の恵みを思って、いつも神に感謝している。</span>
<span className="v" id="v5" data-v="5" data-xref="コリント人への第二の手紙 9:11; コリント人への第二の手紙 8:7; コロサイ人への手紙 2:3"> あなたがたはキリストにあって、すべてのことに、すなわち、すべての言葉にもすべての知識にも恵まれ、</span>
<span className="v" id="v6" data-v="6" data-xref="ヨハネの黙示録 1:2; テモテヘの第二の手紙 1:8; テモテヘの第一の手紙 2:6"> キリストのためのあかしが、あなたがたのうちに確かなものとされ、</span>
<span className="v" id="v7" data-v="7" data-xref="ピリピ人への手紙 3:20; ペテロの第二の手紙 3:12; ヘブル人への手紙 9:28"> こうして、あなたがたは恵みの賜物にいささかも欠けることがなく、わたしたちの主イエス・キリストの現れるのを待ち望んでいる。</span>
<span className="v" id="v8" data-v="8" data-xref="テサロニケ人への第一の手紙 5:23–24; テサロニケ人への第一の手紙 3:13; コロサイ人への手紙 1:22"> 主もまた、あなたがたを最後まで堅くささえて、わたしたちの主イエス・キリストの日に、責められるところのない者にして下さるであろう。</span>
<span className="v" id="v9" data-v="9" data-xref="テサロニケ人への第二の手紙 3:3; ヘブル人への手紙 10:23; 申命記 7:9"> 神は真実なかたである。あなたがたは神によって召され、御子、わたしたちの主イエス・キリストとの交わりに、はいらせていただいたのである。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="ピリピ人への手紙 2:1–4; エペソ人への手紙 4:1–7; コリント人への第一の手紙 12:25"> さて兄弟たちよ。わたしたちの主イエス・キリストの名によって、あなたがたに勧める。みな語ることを一つにし、お互の間に分争がないようにし、同じ心、同じ思いになって、堅く結び合っていてほしい。</span>
<span className="v" id="v11" data-v="11" data-xref="箴言 18:6; テモテヘの第一の手紙 6:4; テモテヘの第二の手紙 2:23–25"> わたしの兄弟たちよ。実は、クロエの家の者たちから、あなたがたの間に争いがあると聞かされている。</span>
<span className="v" id="v12" data-v="12" data-xref="コリント人への第一の手紙 3:21–23; ヨハネによる福音書 1:42; マタイによる福音書 23:9–10"> はっきり言うと、あなたがたがそれぞれ、「わたしはパウロにつく」「わたしはアポロに」「わたしはケパに」「わたしはキリストに」と言い合っていることである。</span>
<span className="v" id="v13" data-v="13" data-xref="エペソ人への手紙 4:5; コリント人への第二の手紙 11:4; 使徒行伝 2:38"> キリストは、いくつにも分けられたのか。パウロは、あなたがたのために十字架につけられたことがあるのか。それとも、あなたがたは、パウロの名によってバプテスマを受けたのか。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行伝 18:8; ローマ人への手紙 16:23; コリント人への第一の手紙 1:4"> わたしは感謝しているが、クリスポとガイオ以外には、あなたがたのうちのだれにも、バプテスマを授けたことがない。</span>
<span className="v" id="v15" data-v="15" data-xref="コリント人への第二の手紙 11:2; ヨハネによる福音書 3:28–29; ヨハネによる福音書 7:18"> それはあなたがたがわたしの名によってバプテスマを受けたのだと、だれにも言われることのないためである。</span>
<span className="v" id="v16" data-v="16" data-xref="コリント人への第一の手紙 16:15; コリント人への第一の手紙 16:17; 使徒行伝 16:33"> もっとも、ステパナの家の者たちには、バプテスマを授けたことがある。しかし、そのほかには、だれにも授けた覚えがない。</span>
<span className="v" id="v17" data-v="17" data-xref="コリント人への第一の手紙 2:1; コリント人への第一の手紙 2:13; ペテロの第二の手紙 1:16"> いったい、キリストがわたしをつかわされたのは、バプテスマを授けるためではなく、福音を宣べ伝えるためであり、しかも知恵の言葉を用いずに宣べ伝えるためであった。それは、キリストの十字架が無力なものになってしまわないためなのである。</span>
</div>
<div className="bp poetry">
<span className="v" id="v18" data-v="18" data-xref="コリント人への第一の手紙 2:14; ローマ人への手紙 1:16; テサロニケ人への第二の手紙 2:10"> 十字架の言は、滅び行く者には愚かであるが、救にあずかるわたしたちには、神の力である。</span>
<span className="v" id="v19" data-v="19" data-xref="イザヤ書 29:14; エレミヤ書 8:9; コリント人への第一の手紙 3:19"> すなわち、聖書に、<br /><span className="pl pl-1">「わたしは知者の知恵を滅ぼし、</span><br /><span className="pl pl-1">賢い者の賢さをむなしいものにする」</span><br />と書いてある。</span>
<span className="v" id="v20" data-v="20" data-xref="ローマ人への手紙 1:22; ヨブ記 12:17; コリント人への第一の手紙 3:19"> 知者はどこにいるか。学者はどこにいるか。この世の論者はどこにいるか。神はこの世の知恵を、愚かにされたではないか。</span>
<span className="v" id="v21" data-v="21" data-xref="ルカによる福音書 10:21; ローマ人への手紙 1:20–22; マタイによる福音書 11:25"> この世は、自分の知恵によって神を認めるに至らなかった。それは、神の知恵にかなっている。そこで神は、宣教の愚かさによって、信じる者を救うこととされたのである。</span>
<span className="v" id="v22" data-v="22" data-xref="マタイによる福音書 16:1–4; マタイによる福音書 12:38–39; マルコによる福音書 8:11"> ユダヤ人はしるしを請い、ギリシヤ人は知恵を求める。</span>
<span className="v" id="v23" data-v="23" data-xref="コリント人への第一の手紙 2:14; コリント人への第一の手紙 2:2; ペテロの第一の手紙 2:8"> しかしわたしたちは、十字架につけられたキリストを宣べ伝える。このキリストは、ユダヤ人にはつまずかせるもの、異邦人には愚かなものであるが、</span>
<span className="v" id="v24" data-v="24" data-xref="コリント人への第一の手紙 1:30; コロサイ人への手紙 2:3; コリント人への第一の手紙 1:18"> 召された者自身にとっては、ユダヤ人にもギリシヤ人にも、神の力、神の知恵たるキリストなのである。</span>
<span className="v" id="v25" data-v="25" data-xref="ローマ人への手紙 11:33–36; コリント人への第一の手紙 1:18; ゼカリヤ書 4:6–7"> 神の愚かさは人よりも賢く、神の弱さは人よりも強いからである。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="ヤコブの手紙 2:5; コリント人への第一の手紙 3:18–20; ヤコブの手紙 1:9–11"> 兄弟たちよ。あなたがたが召された時のことを考えてみるがよい。人間的には、知恵のある者が多くはなく、権力のある者も多くはなく、身分の高い者も多くはいない。</span>
<span className="v" id="v27" data-v="27" data-xref="ヤコブの手紙 2:5; マタイによる福音書 11:25; コリント人への第一の手紙 1:20"> それだのに神は、知者をはずかしめるために、この世の愚かな者を選び、強い者をはずかしめるために、この世の弱い者を選び、</span>
<span className="v" id="v28" data-v="28" data-xref="ヨブ記 34:24; ローマ人への手紙 4:17; イザヤ書 2:11"> 有力な者を無力な者にするために、この世で身分の低い者や軽んじられている者、すなわち、無きに等しい者を、あえて選ばれたのである。</span>
<span className="v" id="v29" data-v="29" data-xref="ローマ人への手紙 3:27; エレミヤ書 9:23; エペソ人への手紙 2:9"> それは、どんな人間でも、神のみまえに誇ることがないためである。</span>
<span className="v" id="v30" data-v="30" data-xref="エペソ人への手紙 1:7; ピリピ人への手紙 3:9; ローマ人への手紙 8:1"> あなたがたがキリスト・イエスにあるのは、神によるのである。キリストは神に立てられて、わたしたちの知恵となり、義と聖とあがないとになられたのである。</span>
<span className="v" id="v31" data-v="31" data-xref="エレミヤ書 9:23–24; コリント人への第二の手紙 10:17; ピリピ人への手紙 3:3"> それは、「誇る者は主を誇れ」と書いてあるとおりである。</span>
</div>

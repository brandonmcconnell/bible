<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="コリント人への第一の手紙 1:17; コリント人への第一の手紙 2:13; コリント人への第一の手紙 2:4"> 兄弟たちよ。わたしもまた、あなたがたの所に行ったとき、神のあかしを宣べ伝えるのに、すぐれた言葉や知恵を用いなかった。</span>
<span className="v" id="v2" data-v="2" data-xref="ガラテヤ人への手紙 6:14; ヨハネによる福音書 17:3; コリント人への第一の手紙 1:22–25"> なぜなら、わたしはイエス・キリスト、しかも十字架につけられたキリスト以外のことは、あなたがたの間では何も知るまいと、決心したからである。</span>
<span className="v" id="v3" data-v="3" data-xref="コリント人への第二の手紙 13:4; コリント人への第一の手紙 4:10–13; コリント人への第二の手紙 12:5–10"> わたしがあなたがたの所に行った時には、弱くかつ恐れ、ひどく不安であった。</span>
<span className="v" id="v4" data-v="4" data-xref="コリント人への第一の手紙 4:20; テサロニケ人への第一の手紙 1:5; コリント人への第一の手紙 1:17"> そして、わたしの言葉もわたしの宣教も、巧みな知恵の言葉によらないで、霊と力との証明によったのである。</span>
<span className="v" id="v5" data-v="5" data-xref="コリント人への第二の手紙 4:7; コリント人への第二の手紙 12:9; コリント人への第二の手紙 6:7"> それは、あなたがたの信仰が人の知恵によらないで、神の力によるものとなるためであった。</span>
</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="ヘブル人への手紙 5:14; ヤコブの手紙 3:15; コリント人への第二の手紙 4:4"> しかしわたしたちは、円熟している者の間では、知恵を語る。この知恵は、この世の者の知恵ではなく、この世の滅び行く支配者たちの知恵でもない。</span>
<span className="v" id="v7" data-v="7" data-xref="コロサイ人への手紙 1:26–27; ペテロの第二の手紙 1:3; マタイによる福音書 11:25"> むしろ、わたしたちが語るのは、隠された奥義としての神の知恵である。それは神が、わたしたちの受ける栄光のために、世の始まらぬ先から、あらかじめ定めておかれたものである。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行伝 13:27; ヤコブの手紙 2:1; 使徒行伝 7:2"> この世の支配者たちのうちで、この知恵を知っていた者は、ひとりもいなかった。もし知っていたなら、栄光の主を十字架につけはしなかったであろう。</span>
<span className="v" id="v9" data-v="9" data-xref="イザヤ書 64:4; 詩篇 31:19; ヤコブの手紙 1:12"> しかし、聖書に書いてあるとおり、<br /><span className="pl pl-1">「目がまだ見ず、耳がまだ聞かず、</span><br /><span className="pl pl-1">人の心に思い浮びもしなかったことを、</span><br /><span className="pl pl-1">神は、ご自分を愛する者たちのために備えられた」</span><br />のである。</span>
<span className="v" id="v10" data-v="10" data-xref="ヨハネによる福音書 14:26; エペソ人への手紙 3:5; ルカによる福音書 10:21"> そして、それを神は、御霊によってわたしたちに啓示して下さったのである。御霊はすべてのものをきわめ、神の深みまでもきわめるのだからである。</span>
<span className="v" id="v11" data-v="11" data-xref="箴言 20:27; コリント人への第一の手紙 2:10; ローマ人への手紙 11:33–34"> いったい、人間の思いは、その内にある人間の霊以外に、だれが知っていようか。それと同じように神の思いも、神の御霊以外には、知るものはない。</span>
<span className="v" id="v12" data-v="12" data-xref="ヨハネの第一の手紙 2:27; ローマ人への手紙 8:5–6; ヨハネの第一の手紙 2:20"> ところが、わたしたちが受けたのは、この世の霊ではなく、神からの霊である。それによって、神から賜わった恵みを悟るためである。</span>
<span className="v" id="v13" data-v="13" data-xref="コリント人への第一の手紙 2:4; コリント人への第一の手紙 2:14; コリント人への第一の手紙 1:17"> この賜物について語るにも、わたしたちは人間の知恵が教える言葉を用いないで、御霊の教える言葉を用い、霊によって霊のことを解釈するのである。</span>
<span className="v" id="v14" data-v="14" data-xref="コリント人への第一の手紙 1:18; ローマ人への手紙 8:5–8; マタイによる福音書 13:11–17"> 生れながらの人は、神の御霊の賜物を受けいれない。それは彼には愚かなものだからである。また、御霊によって判断されるべきであるから、彼はそれを理解することができない。</span>
<span className="v" id="v15" data-v="15" data-xref="テサロニケ人への第一の手紙 5:21; 箴言 28:5; ヘブル人への手紙 5:14"> しかし、霊の人は、すべてのものを判断するが、自分自身はだれからも判断されることはない。</span>
<span className="v" id="v16" data-v="16" data-xref="イザヤ書 40:13–14; ローマ人への手紙 11:34; ヨハネによる福音書 16:13–16"> 「だれが主の思いを知って、彼を教えることができようか」。しかし、わたしたちはキリストの思いを持っている。</span>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ペテロの第一の手紙 4:10; テトスヘの手紙 1:7; テモテヘの第一の手紙 3:9"> このようなわけだから、人はわたしたちを、キリストに仕える者、神の奥義を管理している者と見るがよい。</span>
<span className="v" id="v2" data-v="2" data-xref="マタイによる福音書 25:21; ルカによる福音書 12:42; ルカによる福音書 16:10–12"> この場合、管理者に要求されているのは、忠実であることである。</span>
<span className="v" id="v3" data-v="3" data-xref="ヨハネによる福音書 7:24; コリント人への第一の手紙 2:15; サムエル記上 16:7"> わたしはあなたがたにさばかれたり、人間の裁判にかけられたりしても、なんら意に介しない。いや、わたしは自分をさばくこともしない。</span>
<span className="v" id="v4" data-v="4" data-xref="詩篇 143:2; ヨハネの第一の手紙 3:20–21; 詩篇 130:3"> わたしは自ら省みて、なんらやましいことはないが、それで義とされているわけではない。わたしをさばくかたは、主である。</span>
<span className="v" id="v5" data-v="5" data-xref="ヤコブの手紙 5:7; コリント人への第二の手紙 5:10; コリント人への第一の手紙 3:13"> だから、主がこられるまでは、何事についても、先走りをしてさばいてはいけない。主は暗い中に隠れていることを明るみに出し、心の中で企てられていることを、あらわにされるであろう。その時には、神からそれぞれほまれを受けるであろう。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="コリント人への第二の手紙 12:6; コリント人への第二の手紙 11:4; コリント人への第二の手紙 12:19"> 兄弟たちよ。これらのことをわたし自身とアポロとに当てはめて言って聞かせたが、それはあなたがたが、わたしたちを例にとって、「しるされている定めを越えない」ことを学び、ひとりの人をあがめ、ほかの人を見さげて高ぶることのないためである。</span>
<span className="v" id="v7" data-v="7" data-xref="ヨハネによる福音書 3:27; ペテロの第一の手紙 4:10; ヤコブの手紙 1:17"> いったい、あなたを偉くしているのは、だれなのか。あなたの持っているもので、もらっていないものがあるか。もしもらっているなら、なぜもらっていないもののように誇るのか。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="ルカによる福音書 6:25; 箴言 13:7; コリント人への第一の手紙 5:6"> あなたがたは、すでに満腹しているのだ。すでに富み栄えているのだ。わたしたちを差しおいて、王になっているのだ。ああ、王になっていてくれたらと思う。そうであったなら、わたしたちも、あなたがたと共に王になれたであろう。</span>
<span className="v" id="v9" data-v="9" data-xref="ヘブル人への手紙 10:33; ローマ人への手紙 8:36; コリント人への第二の手紙 4:8–12"> わたしはこう考える。神はわたしたち使徒を死刑囚のように、最後に出場する者として引き出し、こうしてわたしたちは、全世界に、天使にも人々にも見せ物にされたのだ。</span>
<span className="v" id="v10" data-v="10" data-xref="コリント人への第一の手紙 2:3; 使徒行伝 26:24; コリント人への第一の手紙 3:18"> わたしたちはキリストのゆえに愚かな者となり、あなたがたはキリストにあって賢い者となっている。わたしたちは弱いが、あなたがたは強い。あなたがたは尊ばれ、わたしたちは卑しめられている。</span>
<span className="v" id="v11" data-v="11" data-xref="ローマ人への手紙 8:35; コリント人への第二の手紙 11:23–27; ピリピ人への手紙 4:12"> 今の今まで、わたしたちは飢え、かわき、裸にされ、打たれ、宿なしであり、</span>
<span className="v" id="v12" data-v="12" data-xref="ペテロの第一の手紙 3:9; マタイによる福音書 5:11; ペテロの第一の手紙 4:12–14"> 苦労して自分の手で働いている。はずかしめられては祝福し、迫害されては耐え忍び、</span>
<span className="v" id="v13" data-v="13" data-xref="哀歌 3:45; 使徒行伝 22:22"> ののしられては優しい言葉をかけている。わたしたちは今に至るまで、この世のちりのように、人間のくずのようにされている。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="テサロニケ人への第一の手紙 2:11; コリント人への第一の手紙 4:15; ヨハネの第三の手紙 1:4"> わたしがこのようなことを書くのは、あなたがたをはずかしめるためではなく、むしろ、わたしの愛児としてさとすためである。</span>
<span className="v" id="v15" data-v="15" data-xref="ガラテヤ人への手紙 4:19; コリント人への第一の手紙 3:10; コリント人への第一の手紙 9:14"> たといあなたがたに、キリストにある養育掛が一万人あったとしても、父が多くあるのではない。キリスト・イエスにあって、福音によりあなたがたを生んだのは、わたしなのである。</span>
<span className="v" id="v16" data-v="16" data-xref="コリント人への第一の手紙 11:1; テサロニケ人への第二の手紙 3:9; ピリピ人への手紙 3:17"> そこで、あなたがたに勧める。わたしにならう者となりなさい。</span>
<span className="v" id="v17" data-v="17" data-xref="テモテヘの第一の手紙 1:2; コリント人への第一の手紙 16:10; コリント人への第一の手紙 7:17"> このことのために、わたしは主にあって愛する忠実なわたしの子テモテを、あなたがたの所につかわした。彼は、キリスト・イエスにおけるわたしの生活のしかたを、わたしが至る所の教会で教えているとおりに、あなたがたに思い起させてくれるであろう。</span>
<span className="v" id="v18" data-v="18" data-xref="コリント人への第一の手紙 4:6–8; コリント人への第一の手紙 5:2; コリント人への第一の手紙 4:21"> しかしある人々は、わたしがあなたがたの所に来ることはあるまいとみて、高ぶっているということである。</span>
<span className="v" id="v19" data-v="19" data-xref="コリント人への第二の手紙 13:1–4; 使徒行伝 18:21; 使徒行伝 19:21"> しかし主のみこころであれば、わたしはすぐにでもあなたがたの所に行って、高ぶっている者たちの言葉ではなく、その力を見せてもらおう。</span>
<span className="v" id="v20" data-v="20" data-xref="コリント人への第一の手紙 2:4; テサロニケ人への第一の手紙 1:5; コリント人への第二の手紙 10:4–5"> 神の国は言葉ではなく、力である。</span>
<span className="v" id="v21" data-v="21" data-xref="コリント人への第二の手紙 13:2; コリント人への第二の手紙 13:10; テサロニケ人への第一の手紙 2:7"> あなたがたは、どちらを望むのか。わたしがむちをもって、あなたがたの所に行くことか、それとも、愛と柔和な心とをもって行くことであるか。</span>

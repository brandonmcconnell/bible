<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヘブル人への手紙 5:13; コリント人への第一の手紙 2:14–15; エペソ人への手紙 4:13–14"> 兄弟たちよ。わたしはあなたがたには、霊の人に対するように話すことができず、むしろ、肉に属する者、すなわち、キリストにある幼な子に話すように話した。</span>
<span className="v" id="v2" data-v="2" data-xref="ヘブル人への手紙 5:11–14; ヨハネによる福音書 16:12; ペテロの第一の手紙 2:2"> あなたがたに乳を飲ませて、堅い食物は与えなかった。食べる力が、まだあなたがたになかったからである。今になってもその力がない。</span>
<span className="v" id="v3" data-v="3" data-xref="ヤコブの手紙 3:16; ガラテヤ人への手紙 5:15; テトスヘの手紙 3:3"> あなたがたはまだ、肉の人だからである。あなたがたの間に、ねたみや争いがあるのは、あなたがたが肉の人であって、普通の人間のように歩いているためではないか。</span>
<span className="v" id="v4" data-v="4" data-xref="コリント人への第一の手紙 1:12; コリント人への第一の手紙 3:3; コリント人への第一の手紙 4:6"> すなわち、ある人は「わたしはパウロに」と言い、ほかの人は「わたしはアポロに」と言っているようでは、あなたがたは普通の人間ではないか。</span>
<span className="v" id="v5" data-v="5" data-xref="コリント人への第二の手紙 6:4; コリント人への第二の手紙 6:1; ペテロの第一の手紙 4:10"> アポロは、いったい、何者か。また、パウロは何者か。あなたがたを信仰に導いた人にすぎない。しかもそれぞれ、主から与えられた分に応じて仕えているのである。</span>
<span className="v" id="v6" data-v="6" data-xref="コリント人への第一の手紙 3:9–10; 箴言 11:25; コリント人への第二の手紙 10:14–15"> わたしは植え、アポロは水をそそいだ。しかし成長させて下さるのは、神である。</span>
<span className="v" id="v7" data-v="7" data-xref="ヨハネによる福音書 15:5; ガラテヤ人への手紙 6:3; 詩篇 115:1"> だから、植える者も水をそそぐ者も、ともに取るに足りない。大事なのは、成長させて下さる神のみである。</span>
<span className="v" id="v8" data-v="8" data-xref="ローマ人への手紙 2:6; マタイによる福音書 16:27; ヨハネの第二の手紙 1:8"> 植える者と水をそそぐ者とは一つであって、それぞれその働きに応じて報酬を得るであろう。</span>
<span className="v" id="v9" data-v="9" data-xref="ペテロの第一の手紙 2:5; エペソ人への手紙 2:20–22; コリント人への第二の手紙 6:1"> わたしたちは神の同労者である。あなたがたは神の畑であり、神の建物である。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="コリント人への第一の手紙 3:11; エペソ人への手紙 2:20; ローマ人への手紙 15:20"> 神から賜わった恵みによって、わたしは熟練した建築師のように、土台をすえた。そして他の人がその上に家を建てるのである。しかし、どういうふうに建てるか、それぞれ気をつけるがよい。</span>
<span className="v" id="v11" data-v="11" data-xref="エペソ人への手紙 2:20; イザヤ書 28:16; テモテヘの第二の手紙 2:19"> なぜなら、すでにすえられている土台以外のものをすえることは、だれにもできない。そして、この土台はイエス・キリストである。</span>
<span className="v" id="v12" data-v="12" data-xref="テモテヘの第二の手紙 4:3; テモテヘの第二の手紙 3:7; テモテヘの第二の手紙 2:20"> この土台の上に、だれかが金、銀、宝石、木、草、または、わらを用いて建てるならば、</span>
<span className="v" id="v13" data-v="13" data-xref="ペテロの第一の手紙 1:7; コリント人への第一の手紙 3:14–15; ヨハネの黙示録 20:12"> それぞれの仕事は、はっきりとわかってくる。すなわち、かの日は火の中に現れて、それを明らかにし、またその火は、それぞれの仕事がどんなものであるかを、ためすであろう。</span>
<span className="v" id="v14" data-v="14" data-xref="コリント人への第一の手紙 3:8; マタイによる福音書 25:21–23; コリント人への第一の手紙 4:5"> もしある人の建てた仕事がそのまま残れば、その人は報酬を受けるが、</span>
<span className="v" id="v15" data-v="15" data-xref="ヨハネの第二の手紙 1:8; コリント人への第一の手紙 3:12–13; ユダの手紙 1:23"> その仕事が焼けてしまえば、損失を被るであろう。しかし彼自身は、火の中をくぐってきた者のようにではあるが、救われるであろう。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="コリント人への第一の手紙 6:19; エゼキエル書 36:27; コリント人への第二の手紙 6:16"> あなたがたは神の宮であって、神の御霊が自分のうちに宿っていることを知らないのか。</span>
<span className="v" id="v17" data-v="17" data-xref="コリント人への第一の手紙 6:18–20; エゼキエル書 43:12; 民数記 19:20"> もし人が、神の宮を破壊するなら、神はその人を滅ぼすであろう。なぜなら、神の宮は聖なるものであり、そして、あなたがたはその宮なのだからである。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="箴言 3:5; イザヤ書 5:21; ガラテヤ人への手紙 6:3"> だれも自分を欺いてはならない。もしあなたがたのうちに、自分がこの世の知者だと思う人がいるなら、その人は知者になるために愚かになるがよい。</span>
<span className="v" id="v19" data-v="19" data-xref="ヨブ記 5:13; 詩篇 141:10; コリント人への第一の手紙 1:19–20"> なぜなら、この世の知恵は、神の前では愚かなものだからである。「神は、知者たちをその悪知恵によって捕える」と書いてあり、</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 94:11; コロサイ人への手紙 2:8; ローマ人への手紙 1:21"> 更にまた、「主は、知者たちの論議のむなしいことをご存じである」と書いてある。</span>
<span className="v" id="v21" data-v="21" data-xref="ローマ人への手紙 8:32; ローマ人への手紙 8:28; エレミヤ書 9:23–24"> だから、だれも人間を誇ってはいけない。すべては、あなたがたのものなのである。</span>
<span className="v" id="v22" data-v="22" data-xref="エペソ人への手紙 4:11–12; ピリピ人への手紙 1:21; コリント人への第一の手紙 9:19–22"> パウロも、アポロも、ケパも、世界も、生も、死も、現在のものも、将来のものも、ことごとく、あなたがたのものである。</span>
<span className="v" id="v23" data-v="23" data-xref="ガラテヤ人への手紙 3:29; コリント人への第一の手紙 11:3; ヨハネによる福音書 17:9–10"> そして、あなたがたはキリストのもの、キリストは神のものである。</span>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ローマ人への手紙 12:13; コリント人への第二の手紙 8:1–9; コリント人への第二の手紙 9:12–15"> 聖徒たちへの献金については、わたしはガラテヤの諸教会に命じておいたが、あなたがたもそのとおりにしなさい。</span>
<span className="v" id="v2" data-v="2" data-xref="マラキ書 3:9–10; 申命記 15:11–14; 申命記 8:18"> 一週の初めの日ごとに、あなたがたはそれぞれ、いくらでも収入に応じて手もとにたくわえておき、わたしが着いた時になって初めて集めることのないようにしなさい。</span>
<span className="v" id="v3" data-v="3" data-xref="コリント人への第二の手紙 8:6; コリント人への第一の手紙 11:34; コリント人への第一の手紙 4:19–21"> わたしが到着したら、あなたがたが選んだ人々に手紙をつけ、あなたがたの贈り物を持たせて、エルサレムに送り出すことにしよう。</span>
<span className="v" id="v4" data-v="4" data-xref="コリント人への第二の手紙 8:4; コリント人への第二の手紙 8:19; ローマ人への手紙 15:25"> もしわたしも行く方がよければ、一緒に行くことになろう。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行伝 19:21; コリント人への第一の手紙 4:19; コリント人への第二の手紙 1:15–17"> わたしは、マケドニヤを通過してから、あなたがたのところに行くことになろう。マケドニヤは通過するだけだが、</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行伝 15:3; ローマ人への手紙 15:24; 使徒行伝 20:38"> あなたがたの所では、たぶん滞在するようになり、あるいは冬を過ごすかも知れない。そうなれば、わたしがどこへゆくにしても、あなたがたに送ってもらえるだろう。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行伝 18:21; コリント人への第一の手紙 4:19; ヤコブの手紙 4:15"> わたしは今、あなたがたに旅のついでに会うことは好まない。もし主のお許しがあれば、しばらくあなたがたの所に滞在したいと望んでいる。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行伝 2:1; 出エジプト記 23:16; 使徒行伝 18:19"> しかし五旬節までは、エペソに滞在するつもりだ。というのは、有力な働きの門がわたしのために大きく開かれているし、</span>
<span className="v" id="v9" data-v="9" data-xref="コリント人への第二の手紙 2:12; 使徒行伝 14:27; コロサイ人への手紙 4:3"> また敵対する者も多いからである。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="コリント人への第一の手紙 15:58; テサロニケ人への第一の手紙 3:2; ローマ人への手紙 16:21"> もしテモテが着いたら、あなたがたの所で不安なしに過ごせるようにしてあげてほしい。彼はわたしと同様に、主のご用にあたっているのだから。</span>
<span className="v" id="v11" data-v="11" data-xref="テモテヘの第一の手紙 4:12; 使徒行伝 15:33; テトスヘの手紙 2:15"> だれも彼を軽んじてはいけない。そして、わたしの所に来るように、どうか彼を安らかに送り出してほしい。わたしは彼が兄弟たちと一緒に来るのを待っている。</span>
<span className="v" id="v12" data-v="12" data-xref="コリント人への第一の手紙 1:12; コリント人への第一の手紙 3:5; テトスヘの手紙 3:4"> 兄弟アポロについては、兄弟たちと一緒にあなたがたの所に行くように、たびたび勧めてみた。しかし彼には、今行く意志は、全くない。適当な機会があれば、行くだろう。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="ヨシュア記 1:9; エペソ人への手紙 6:13–18; エペソ人への手紙 6:10"> 目をさましていなさい。信仰に立ちなさい。男らしく、強くあってほしい。</span>
<span className="v" id="v14" data-v="14" data-xref="ヨハネによる福音書 13:34–35; ペテロの第一の手紙 4:8; テモテヘの第一の手紙 1:5"> いっさいのことを、愛をもって行いなさい。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="コリント人への第一の手紙 1:16; ローマ人への手紙 16:5; ローマ人への手紙 16:2"> 兄弟たちよ。あなたがたに勧める。あなたがたが知っているように、ステパナの家はアカヤの初穂であって、彼らは身をもって聖徒に奉仕してくれた。</span>
<span className="v" id="v16" data-v="16" data-xref="ヘブル人への手紙 13:17; テサロニケ人への第一の手紙 5:12; ヨハネの第三の手紙 1:8"> どうか、このような人々と、またすべて彼らと共に働き共に労する人々とに、従ってほしい。</span>
<span className="v" id="v17" data-v="17" data-xref="コリント人への第二の手紙 11:9; ピリピ人への手紙 2:30; ピレモンヘの手紙 1:13"> わたしは、ステパナとポルトナトとアカイコとがきてくれたのを喜んでいる。彼らはあなたがたの足りない所を満たし、</span>
<span className="v" id="v18" data-v="18" data-xref="ピレモンヘの手紙 1:7; コリント人への第二の手紙 7:13; テサロニケ人への第一の手紙 5:12"> わたしの心とあなたがたの心とを、安らかにしてくれた。こうした人々は、重んじなければならない。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="使徒行伝 18:2; ピレモンヘの手紙 1:2; ローマ人への手紙 16:3–5"> アジヤの諸教会から、あなたがたによろしく。アクラとプリスカとその家の教会から、主にあって心からよろしく。</span>
<span className="v" id="v20" data-v="20" data-xref="ローマ人への手紙 16:16; テサロニケ人への第一の手紙 5:26; ペテロの第一の手紙 5:14"> すべての兄弟たちから、よろしく。あなたがたも互に、きよい接吻をもってあいさつをかわしなさい。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="コロサイ人への手紙 4:18; ガラテヤ人への手紙 6:11; テサロニケ人への第二の手紙 3:17"> ここでパウロが、手ずからあいさつをしるす。</span>
<span className="v" id="v22" data-v="22" data-xref="エペソ人への手紙 6:24; ヨハネによる福音書 14:21; コリント人への第二の手紙 5:14–15"> もし主を愛さない者があれば、のろわれよ。マラナ・タ（われらの主よ、きたりませ）。</span>
<span className="v" id="v23" data-v="23" data-xref="ローマ人への手紙 16:20; ローマ人への手紙 16:23"> 主イエスの恵みが、あなたがたと共にあるように。</span>
<span className="v" id="v24" data-v="24" data-xref="コリント人への第一の手紙 14:16; ヨハネの黙示録 3:19; コリント人への第二の手紙 12:15"> わたしの愛が、キリスト・イエスにあって、あなたがた一同と共にあるように。</span>
</div>

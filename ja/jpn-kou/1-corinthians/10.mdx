<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出エジプト記 14:29; ネヘミヤ書 9:11–12; 詩篇 78:13–14"> 兄弟たちよ。このことを知らずにいてもらいたくない。わたしたちの先祖はみな雲の下におり、みな海を通り、</span>
<span className="v" id="v2" data-v="2" data-xref="ヘブル人への手紙 3:2–3; コリント人への第一の手紙 1:13–16; 出エジプト記 14:31"> みな雲の中、海の中で、モーセにつくバプテスマを受けた。</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 8:3; ネヘミヤ書 9:15; 出エジプト記 16:35"> また、みな同じ霊の食物を食べ、</span>
<span className="v" id="v4" data-v="4" data-xref="出エジプト記 17:6; ヨハネによる福音書 7:37; イザヤ書 48:21"> みな同じ霊の飲み物を飲んだ。すなわち、彼らについてきた霊の岩から飲んだのであるが、この岩はキリストにほかならない。</span>
<span className="v" id="v5" data-v="5" data-xref="ヘブル人への手紙 3:17; ユダの手紙 1:5; 民数記 14:37"> しかし、彼らの中の大多数は、神のみこころにかなわなかったので、荒野で滅ぼされてしまった。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="ユダの手紙 1:7; コリント人への第一の手紙 10:11; ヘブル人への手紙 4:11"> これらの出来事は、わたしたちに対する警告であって、彼らが悪をむさぼったように、わたしたちも悪をむさぼることのないためなのである。</span>
<span className="v" id="v7" data-v="7" data-xref="出エジプト記 32:6–8; 詩篇 106:19–20; コリント人への第一の手紙 6:9"> だから、彼らの中のある者たちのように、偶像礼拝者になってはならない。すなわち、「民は座して飲み食いをし、また立って踊り戯れた」と書いてある。</span>
<span className="v" id="v8" data-v="8" data-xref="民数記 25:1–9; コリント人への第一の手紙 6:18; 詩篇 106:29"> また、ある者たちがしたように、わたしたちは不品行をしてはならない。不品行をしたため倒された者が、一日に二万三千人もあった。</span>
<span className="v" id="v9" data-v="9" data-xref="民数記 21:5–6; 詩篇 78:18; ヘブル人への手紙 3:8–11"> また、ある者たちがしたように、わたしたちは主を試みてはならない。主を試みた者は、へびに殺された。</span>
<span className="v" id="v10" data-v="10" data-xref="民数記 14:2; 民数記 16:41; 民数記 14:37"> また、ある者たちがつぶやいたように、つぶやいてはならない。つぶやいた者は、「死の使」に滅ぼされた。</span>
<span className="v" id="v11" data-v="11" data-xref="ローマ人への手紙 15:4; ローマ人への手紙 13:11; コリント人への第一の手紙 9:10"> これらの事が彼らに起ったのは、他に対する警告としてであって、それが書かれたのは、世の終りに臨んでいるわたしたちに対する訓戒のためである。</span>
<span className="v" id="v12" data-v="12" data-xref="ローマ人への手紙 11:20; ペテロの第二の手紙 3:17; 箴言 16:18"> だから、立っていると思う者は、倒れないように気をつけるがよい。</span>
<span className="v" id="v13" data-v="13" data-xref="ペテロの第二の手紙 2:9; テモテヘの第二の手紙 4:18; テサロニケ人への第二の手紙 3:3"> あなたがたの会った試錬で、世の常でないものはない。神は真実である。あなたがたを耐えられないような試錬に会わせることはないばかりか、試錬と同時に、それに耐えられるように、のがれる道も備えて下さるのである。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="ヨハネの黙示録 21:8; ヨハネの第一の手紙 5:21; ペテロの第一の手紙 2:11"> それだから、愛する者たちよ。偶像礼拝を避けなさい。</span>
<span className="v" id="v15" data-v="15" data-xref="コリント人への第一の手紙 8:1; テサロニケ人への第一の手紙 5:21; コリント人への第一の手紙 11:13"> 賢明なあなたがたに訴える。わたしの言うことを、自ら判断してみるがよい。</span>
<span className="v" id="v16" data-v="16" data-xref="マタイによる福音書 26:26–28; コリント人への第一の手紙 11:23–29; 使徒行伝 2:42"> わたしたちが祝福する祝福の杯、それはキリストの血にあずかることではないか。わたしたちがさくパン、それはキリストのからだにあずかることではないか。</span>
<span className="v" id="v17" data-v="17" data-xref="ローマ人への手紙 12:5; コロサイ人への手紙 3:15; コリント人への第一の手紙 12:27"> パンが一つであるから、わたしたちは多くいても、一つのからだなのである。みんなの者が一つのパンを共にいただくからである。</span>
<span className="v" id="v18" data-v="18" data-xref="ピリピ人への手紙 3:3–5; ガラテヤ人への手紙 6:16; レビ記 7:6"> 肉によるイスラエルを見るがよい。供え物を食べる人たちは、祭壇にあずかるのではないか。</span>
<span className="v" id="v19" data-v="19" data-xref="コリント人への第一の手紙 8:4; コリント人への第一の手紙 3:7; コリント人への第一の手紙 13:2"> すると、なんと言ったらよいか。偶像にささげる供え物は、何か意味があるのか。また、偶像は何かほんとうにあるものか。</span>
<span className="v" id="v20" data-v="20" data-xref="ヨハネの黙示録 9:20; 詩篇 106:37–39; 申命記 32:16–17"> そうではない。人々が供える物は、悪霊ども、すなわち、神ならぬ者に供えるのである。わたしは、あなたがたが悪霊の仲間になることを望まない。</span>
<span className="v" id="v21" data-v="21" data-xref="マタイによる福音書 6:24; 列王紀上 18:21; コリント人への第二の手紙 6:15–17"> 主の杯と悪霊どもの杯とを、同時に飲むことはできない。主の食卓と悪霊どもの食卓とに、同時にあずかることはできない。</span>
<span className="v" id="v22" data-v="22" data-xref="申命記 32:21; 申命記 32:16; ヘブル人への手紙 10:31"> それとも、わたしたちは主のねたみを起そうとするのか。わたしたちは、主よりも強いのだろうか。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="コリント人への第一の手紙 6:12; コリント人への第一の手紙 8:9; エペソ人への手紙 4:29"> すべてのことは許されている。しかし、すべてのことが益になるわけではない。すべてのことは許されている。しかし、すべてのことが人の徳を高めるのではない。</span>
<span className="v" id="v24" data-v="24" data-xref="ローマ人への手紙 15:1–2; コリント人への第一の手紙 10:33; ピリピ人への手紙 2:4–5"> だれでも、自分の益を求めないで、ほかの人の益を求めるべきである。</span>
<span className="v" id="v25" data-v="25" data-xref="テモテヘの第一の手紙 4:4; コリント人への第一の手紙 8:7; テトスヘの手紙 1:15"> すべて市場で売られている物は、いちいち良心に問うことをしないで、食べるがよい。</span>
<span className="v" id="v26" data-v="26" data-xref="詩篇 24:1; 出エジプト記 19:5; 詩篇 50:12"> 地とそれに満ちている物とは、主のものだからである。</span>
<span className="v" id="v27" data-v="27" data-xref="コリント人への第一の手紙 10:25; ルカによる福音書 10:7–8; コリント人への第一の手紙 5:9–11"> もしあなたがたが、不信者のだれかに招かれて、そこに行こうと思う場合、自分の前に出される物はなんでも、いちいち良心に問うことをしないで、食べるがよい。</span>
<span className="v" id="v28" data-v="28" data-xref="コリント人への第一の手紙 8:10–13; コリント人への第一の手紙 8:7; コリント人への第一の手紙 10:26"> しかし、だれかがあなたがたに、これはささげ物の肉だと言ったなら、それを知らせてくれた人のために、また良心のために、食べないがよい。</span>
<span className="v" id="v29" data-v="29" data-xref="コリント人への第一の手紙 9:19; ローマ人への手紙 14:15–21; コリント人への第一の手紙 8:9–13"> 良心と言ったのは、自分の良心ではなく、他人の良心のことである。なぜなら、わたしの自由が、どうして他人の良心によって左右されることがあろうか。</span>
<span className="v" id="v30" data-v="30" data-xref="ローマ人への手紙 14:6; テモテヘの第一の手紙 4:3–4"> もしわたしが感謝して食べる場合、その感謝する物について、どうして人のそしりを受けるわけがあろうか。</span>
<span className="v" id="v31" data-v="31" data-xref="コロサイ人への手紙 3:17; コロサイ人への手紙 3:23; ペテロの第一の手紙 4:11"> だから、飲むにも食べるにも、また何事をするにも、すべて神の栄光のためにすべきである。</span>
<span className="v" id="v32" data-v="32" data-xref="使徒行伝 20:28; コリント人への第一の手紙 10:33; ローマ人への手紙 14:13"> ユダヤ人にもギリシヤ人にも神の教会にも、つまずきになってはいけない。</span>
<span className="v" id="v33" data-v="33" data-xref="コリント人への第一の手紙 10:24; ガラテヤ人への手紙 1:10; コリント人への第一の手紙 9:19–23"> わたしもまた、何事にもすべての人に喜ばれるように努め、多くの人が救われるために、自分の益ではなく彼らの益を求めている。</span>
</div>

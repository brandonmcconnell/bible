<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ダニエル書 1:1; エレミヤ書 25:1; エレミヤ書 25:9"> エホヤキムの世にバビロンの王ネブカデネザルが上ってきたので、エホヤキムは彼に隷属して三年を経たが、ついに翻って彼にそむいた。</span>
<span className="v" id="v2" data-v="2" data-xref="エレミヤ書 35:11; 列王紀下 23:27; 列王紀下 21:12–14"> 主はカルデヤびとの略奪隊、スリヤびとの略奪隊、モアブびとの略奪隊、アンモンびとの略奪隊をつかわしてエホヤキムを攻められた。すなわちユダを攻め、これを滅ぼすために彼らをつかわされた。主がそのしもべである預言者たちによって語られた言葉のとおりである。</span>
<span className="v" id="v3" data-v="3" data-xref="列王紀下 18:25; 列王紀下 21:2–11; 列王紀下 23:26–27"> これは全く主の命によってユダに臨んだもので、ユダを主の目の前から払い除くためであった。すなわちマナセがすべておこなったその罪のため、</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀下 21:16; 詩篇 106:38; 民数記 35:33"> また彼が罪なき人の血を流し、罪なき人の血をエルサレムに満たしたためであって、主はその罪をゆるそうとはされなかった。</span>
<span className="v" id="v5" data-v="5" data-xref="歴代志下 36:8; エレミヤ書 26:1–24; エレミヤ書 22:13–17"> エホヤキムのその他の事績と、彼がおこなったすべての事は、ユダの王の歴代志の書にしるされているではないか。</span>
<span className="v" id="v6" data-v="6" data-xref="エレミヤ書 22:18–19; 歴代志下 36:6; エレミヤ書 36:30"> エホヤキムは先祖たちとともに眠り、その子エホヤキンが代って王となった。</span>
<span className="v" id="v7" data-v="7" data-xref="エレミヤ書 37:5–7; エレミヤ書 46:2; 創世記 15:18"> エジプトの王は再びその国から出てこなかった。バビロンの王がエジプトの川からユフラテ川まで、すべてエジプトの王に属するものを取ったからである。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="歴代志下 36:9; 歴代志上 3:16; エレミヤ書 37:1"> エホヤキンは王となった時十八歳で、エルサレムで三か月の間、世を治めた。母はエルサレムのエルナタンの娘で、名をネホシタといった。</span>
<span className="v" id="v9" data-v="9"> エホヤキンはすべてその父がおこなったように主の目の前に悪を行った。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="列王紀下 25:2; ダニエル書 1:1–2"> そのころ、バビロンの王ネブカデネザルの家来たちはエルサレムに攻め上って、町を囲んだ。</span>
<span className="v" id="v11" data-v="11"> その家来たちが町を囲んでいたとき、バビロンの王ネブカデネザルもまた町に攻めてきた。</span>
<span className="v" id="v12" data-v="12" data-xref="エレミヤ書 24:1; エレミヤ書 52:28; 列王紀下 25:27"> ユダの王エホヤキンはその母、その家来、そのつかさたち、および侍従たちと共に出て、バビロンの王に降服したので、バビロンの王は彼を捕虜とした。これはネブカデネザルの治世の第八年であった。</span>
<span className="v" id="v13" data-v="13" data-xref="イザヤ書 39:6; 列王紀下 20:17; エレミヤ書 20:5"> 彼はまた主の宮のもろもろの宝物および王の家の宝物をことごとく持ち出し、イスラエルの王ソロモンが造って主の神殿に置いたもろもろの金の器を切りこわした。主が言われたとおりである。</span>
<span className="v" id="v14" data-v="14" data-xref="エレミヤ書 52:28; 列王紀下 25:12; 列王紀下 24:16"> 彼はまたエルサレムのすべての市民、およびすべてのつかさとすべての勇士、ならびにすべての木工と鍛冶一万人を捕えて行った。残った者は国の民の貧しい者のみであった。</span>
<span className="v" id="v15" data-v="15" data-xref="歴代志下 36:10; エレミヤ書 22:24–28; エステル記 2:6"> さらに彼はエホヤキンをバビロンに捕えて行き、また王の母、王の妻たち、および侍従と国のうちのおもな人々をも、エルサレムからバビロンへ捕えて行った。</span>
<span className="v" id="v16" data-v="16" data-xref="エレミヤ書 52:28; 列王紀下 24:14; エレミヤ書 29:2"> またバビロンの王はすべて勇敢な者七千人、木工と鍛冶一千人ならびに強くて良く戦う者をみな捕えてバビロンへ連れて行った。</span>
<span className="v" id="v17" data-v="17" data-xref="エレミヤ書 37:1; 歴代志下 36:4; 列王紀下 23:34"> そしてバビロンの王はエホヤキンの父の兄弟マッタニヤを王としてエホヤキンに代え、名をゼデキヤと改めた。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="列王紀下 23:31; エレミヤ書 52:1–11; エレミヤ書 37:1"> ゼデキヤは二十一歳で王となり、エルサレムで十一年の間、世を治めた。母はリブナのエレミヤの娘で、名をハムタルといった。</span>
<span className="v" id="v19" data-v="19" data-xref="列王紀下 23:37; エレミヤ書 24:8; エゼキエル書 21:25"> ゼデキヤはすべてエホヤキムがおこなったように主の目の前に悪を行った。</span>
<span className="v" id="v20" data-v="20" data-xref="歴代志下 36:13; テサロニケ人への第二の手紙 2:9–11; エレミヤ書 38:17–21"> エルサレムとユダにこのような事の起ったのは主の怒りによるので、主はついに彼らをみ前から払いすてられた。<br />さてゼデキヤはバビロンの王にそむいた。</span>
</div>

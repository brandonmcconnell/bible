<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="エレミヤ書 52:4–11; 歴代志上 6:15; エレミヤ書 34:1–6"> そこでゼデキヤの治世の第九年の十月十日に、バビロンの王ネブカデネザルはもろもろの軍勢を率い、エルサレムにきて、これにむかって陣を張り、周囲にとりでを築いてこれを攻めた。</span>
<span className="v" id="v2" data-v="2"> こうして町は囲まれて、ゼデキヤ王の第十一年にまで及んだが、</span>
<span className="v" id="v3" data-v="3" data-xref="エレミヤ書 52:6; エゼキエル書 5:12; エレミヤ書 38:2"> その四月九日になって、町のうちにききんが激しくなり、その地の民に食物がなくなった。</span>
<span className="v" id="v4" data-v="4" data-xref="エゼキエル書 33:21; 列王紀下 25:5; エレミヤ書 39:2–7"> 町の一角がついに破れたので、王はすべての兵士とともに、王の園のかたわらにある二つの城壁のあいだの門の道から夜のうちに逃げ出して、カルデヤびとが町を囲んでいる間に、アラバの方へ落ち延びた。</span>
<span className="v" id="v5" data-v="5" data-xref="イザヤ書 30:16; エレミヤ書 39:5; アモス書 2:14–16"> しかしカルデヤびとの軍勢は王を追い、エリコの平地で彼に追いついた。彼の軍勢はみな彼を離れて散り去ったので、</span>
<span className="v" id="v6" data-v="6" data-xref="列王紀下 23:33; エレミヤ書 34:21–22; エレミヤ書 21:7"> カルデヤびとは王を捕え、彼をリブラにいるバビロンの王のもとへ引いていって彼の罪を定め、</span>
<span className="v" id="v7" data-v="7" data-xref="エレミヤ書 32:4–5; 士師記 16:21; エレミヤ書 39:6–7"> ゼデキヤの子たちをゼデキヤの目の前で殺し、ゼデキヤの目をえぐり、足かせをかけてバビロンへ連れて行った。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="エレミヤ書 52:12–16; エレミヤ書 40:1–4; 哀歌 4:12"> バビロンの王ネブカデネザルの第十九年の五月七日に、バビロンの王の臣、侍衛の長ネブザラダンがエルサレムにきて、</span>
<span className="v" id="v9" data-v="9" data-xref="アモス書 2:5; 詩篇 74:3–7; 列王紀上 9:8"> 主の宮と王の家とエルサレムのすべての家を焼いた。すなわち火をもってすべての大きな家を焼いた。</span>
<span className="v" id="v10" data-v="10" data-xref="ネヘミヤ書 1:3; エレミヤ書 39:8; エレミヤ書 52:14–23"> また侍衛の長と共にいたカルデヤびとのすべての軍勢はエルサレムの周囲の城壁を破壊した。</span>
<span className="v" id="v11" data-v="11" data-xref="エゼキエル書 5:2; エレミヤ書 15:1–2; エレミヤ書 39:9"> そして侍衛の長ネブザラダンは、町に残された民およびバビロン王に降服した者と残りの群衆を捕え移した。</span>
<span className="v" id="v12" data-v="12" data-xref="エレミヤ書 40:7; 列王紀下 24:14; エゼキエル書 33:24"> ただし侍衛の長はその地の貧しい者を残して、ぶどうを作る者とし、農夫とした。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="歴代志下 36:18; 哀歌 1:10; 列王紀下 20:17"> カルデヤびとはまた主の宮の青銅の柱と、主の宮の洗盤の台と、青銅の海を砕いて、その青銅をバビロンに運び、</span>
<span className="v" id="v14" data-v="14" data-xref="出エジプト記 27:3; 列王紀上 7:47–50; 出エジプト記 38:3"> またつぼと、十能と、心切りばさみと、香を盛る皿およびすべて神殿の務に用いる青銅の器、</span>
<span className="v" id="v15" data-v="15" data-xref="ダニエル書 5:2–3; 民数記 7:13–14; 列王紀上 7:48–51"> また心取り皿と鉢を取り去った。侍衛の長はまた金で作った物と銀で作った物を取り去った。</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀上 7:47"> ソロモンが主の宮のために造った二つの柱と、一つの海と洗盤の台など、これらのもろもろの器の青銅の重さは量ることができなかった。</span>
<span className="v" id="v17" data-v="17" data-xref="列王紀上 7:15–22; エレミヤ書 52:21–23"> 一つの柱の高さは十八キュビトで、その上に青銅の柱頭があり、柱頭の高さは三キュビトで、柱頭の周囲に網細工とざくろがあって、みな青銅であった。他の柱もその網細工もこれと同じであった。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="エレミヤ書 29:25; エズラ記 7:1; エレミヤ書 21:1"> 侍衛の長は祭司長セラヤと次席の祭司ゼパニヤと三人の門を守る者を捕え、</span>
<span className="v" id="v19" data-v="19" data-xref="エステル記 1:14"> また兵士をつかさどるひとりの役人と、王の前にはべる者のうち、町で見つかった者五人と、その地の民を募った軍勢の長の書記官と、町で見つかったその地の民六十人を町から捕え去った。</span>
<span className="v" id="v20" data-v="20" data-xref="哀歌 4:16; エレミヤ書 52:26–27; 列王紀下 23:33"> 侍衛の長ネブザラダンは彼らを捕えて、リブラにいるバビロンの王のもとへ連れて行ったので、</span>
<span className="v" id="v21" data-v="21" data-xref="申命記 28:64; 列王紀下 23:27; 申命記 4:26"> バビロンの王はハマテの地のリブラで彼らを撃ち殺した。このようにしてユダはその地から捕え移された。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="エレミヤ書 39:14; 列王紀下 22:12; エレミヤ書 41:2"> さてバビロンの王ネブカデネザルはユダの地に残してとどまらせた民の上に、シャパンの子アヒカムの子であるゲダリヤを立てて総督とした。</span>
<span className="v" id="v23" data-v="23" data-xref="エレミヤ書 40:7–9; エレミヤ書 40:11–12; ヨシュア記 18:26"> 時に軍勢の長たちおよびその部下の人々は、バビロンの王がゲダリヤを総督としたことを聞いて、ミヅパにいるゲダリヤのもとにきた。すなわちネタニヤの子イシマエル、カレヤの子ヨハナン、ネトパびとタンホメテの子セラヤ、マアカびとの子ヤザニヤおよびその部下の人々がゲダリヤのもとにきた。</span>
<span className="v" id="v24" data-v="24" data-xref="エレミヤ書 40:9–10; エレミヤ書 43:6; サムエル記下 19:23"> ゲダリヤは彼らとその部下の人々に誓って言った、「あなたがたはカルデヤびとのしもべとなることを恐れてはならない。この地に住んで、バビロンの王に仕えなさい。そうすればあなたがたは幸福を得るでしょう」。</span>
<span className="v" id="v25" data-v="25" data-xref="ゼカリヤ書 7:5; ゼカリヤ書 8:19; エレミヤ書 40:15"> ところが七月になって、王の血統のエリシャマの子であるネタニヤの子イシマエルは十人の者と共にきて、ゲダリヤを撃ち殺し、また彼と共にミヅパにいたユダヤ人と、カルデヤびとを殺した。</span>
<span className="v" id="v26" data-v="26" data-xref="エレミヤ書 43:4–7; エレミヤ書 41:16–18; エレミヤ書 42:14–22"> そのため、大小の民および軍勢の長たちは、みな立ってエジプトへ行った。彼らはカルデヤびとを恐れたからである。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="エレミヤ書 52:31–34; 創世記 40:20; 創世記 40:13"> ユダの王エホヤキンが捕え移されて後三十七年の十二月二十七日、すなわちバビロンの王エビルメロダクの治世の第一年に、王はユダの王エホヤキンを獄屋から出して</span>
<span className="v" id="v28" data-v="28" data-xref="ダニエル書 2:37; エレミヤ書 27:6–11; ダニエル書 5:18–19"> ねんごろに彼を慰め、その位を彼と共にバビロンにいる王たちの位よりも高くした。</span>
<span className="v" id="v29" data-v="29" data-xref="サムエル記下 9:7; イザヤ書 61:3; 創世記 41:42"> こうしてエホヤキンはその獄屋の衣を脱ぎ、一生の間、常に王の前で食事した。</span>
<span className="v" id="v30" data-v="30" data-xref="ルカによる福音書 11:3; マタイによる福音書 6:11; ネヘミヤ書 11:23"> 彼は一生の間、たえず日々の分を王から賜わって、その食物とした。</span>
</div>

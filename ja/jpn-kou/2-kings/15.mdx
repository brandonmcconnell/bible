<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歴代志下 26:3–4; 列王紀下 14:21; 歴代志下 26:1"> イスラエルの王ヤラベアムの第二十七年に、ユダの王アマジヤの子アザリヤが王となった。</span>
<span className="v" id="v2" data-v="2" data-xref="歴代志下 26:3–4"> 彼が王となった時は十六歳で、五十二年の間エルサレムで世を治めた。その母はエルサレムの出身で、名をエコリアといった。</span>
<span className="v" id="v3" data-v="3" data-xref="列王紀下 14:3–4; 列王紀下 12:2–3; 歴代志下 26:4"> 彼は主の目にかなう事を行い、すべての事を父アマジヤが行ったようにおこなった。</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀下 15:35; 列王紀下 14:4; 列王紀下 12:3"> ただし高き所は除かなかったので、民はなおその高き所で犠牲をささげ、香をたいた。</span>
<span className="v" id="v5" data-v="5" data-xref="レビ記 13:46; 民数記 12:14; 列王紀下 7:3"> 主が王を撃たれたので、その死ぬ日まで、らい病人となって、離れ家に住んだ。王の子ヨタムが家の事を管理し、国の民をさばいた。</span>
<span className="v" id="v6" data-v="6" data-xref="歴代志下 26:5–15; 列王紀下 14:18"> アザリヤのその他の事績と、彼がしたすべての事は、ユダの王の歴代志の書にしるされているではないか。</span>
<span className="v" id="v7" data-v="7" data-xref="歴代志下 26:23; イザヤ書 6:1"> アザリヤはその先祖たちと共に眠ったので、彼をダビデの町にその先祖たちと共に葬った。その子ヨタムが代って王となった。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="列王紀下 14:16–17; 列王紀下 14:29–1; 列王紀下 14:21"> ユダの王アザリヤの第三十八年にヤラベアムの子ゼカリヤがサマリヤでイスラエルの王となり、六か月世を治めた。</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀下 14:24; 列王紀下 13:2; 列王紀下 13:11"> 彼はその先祖たちがおこなったように主の目の前に悪を行い、イスラエルに罪を犯させたネバテの子ヤラベアムの罪を離れなかった。</span>
<span className="v" id="v10" data-v="10" data-xref="列王紀上 15:28; 列王紀下 15:14; 列王紀下 9:24"> ヤベシの子シャルムが徒党を結んで彼に敵し、イブレアムで彼を撃ち殺し、彼に代って王となった。</span>
<span className="v" id="v11" data-v="11" data-xref="列王紀下 14:28"> ゼカリヤのその他の事績は、イスラエルの王の歴代志の書にしるされている。</span>
<span className="v" id="v12" data-v="12" data-xref="列王紀下 10:30; マルコによる福音書 13:31; 列王紀下 13:13"> 主はかつてエヒウに、「あなたの子孫は四代までイスラエルの位に座するであろう」と告げられたが、はたしてそのとおりになった。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="列王紀下 15:1; マタイによる福音書 1:8–9; 列王紀下 15:8"> ヤベシの子シャルムはユダの王ウジヤの第三十九年に王となり、サマリヤで一か月世を治めた。</span>
<span className="v" id="v14" data-v="14" data-xref="列王紀上 14:17; 列王紀上 16:17; 列王紀上 16:15"> 時にガデの子メナヘムがテルザからサマリヤに上ってきて、ヤベシの子シャルムをサマリヤで撃ち殺し、彼に代って王となった。</span>
<span className="v" id="v15" data-v="15" data-xref="列王紀上 14:19; 列王紀上 14:29; 列王紀下 15:11"> シャルムのその他の事績と、彼が徒党を結んだ事は、イスラエルの王の歴代志の書にしるされている。</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀下 8:12; 列王紀上 4:24; ホセア書 13:16"> その時メナヘムはテルザから進んでいって、タップアと、そのうちにいるすべての者、およびその領域を撃った。すなわち彼らが彼のために開かなかったので、これを撃って、そのうちの妊娠の女をことごとく引き裂いた。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17"> ユダの王アザリヤの第三十九年に、ガデの子メナヘムはイスラエルの王となり、サマリヤで十年の間、世を治めた。</span>
<span className="v" id="v18" data-v="18"> 彼は主の目の前に悪を行い、イスラエルに罪を犯させたネバテの子ヤラベアムの罪を一生の間、離れなかった。</span>
<span className="v" id="v19" data-v="19" data-xref="列王紀下 14:5; 歴代志上 5:25–26; 列王紀下 18:16"> 時にアッスリヤの王プルが国に攻めてきたので、メナヘムは銀一千タラントをプルに与えた。これは彼がプルの助けを得て、国を自分の手のうちに強くするためであった。</span>
<span className="v" id="v20" data-v="20" data-xref="列王紀下 18:14–17; 列王紀下 23:35; 列王紀下 17:3–4"> すなわちメナヘムはその銀をイスラエルのすべての富める者に課し、その人々におのおの銀五十シケルを出させてアッスリヤの王に与えた。こうしてアッスリヤの王は国にとどまらないで帰っていった。</span>
<span className="v" id="v21" data-v="21"> メナヘムのその他の事績と彼がしたすべての事は、イスラエルの王の歴代志の書にしるされているではないか。</span>
<span className="v" id="v22" data-v="22"> メナヘムは先祖たちと共に眠り、その子ペカヒヤが代って王となった。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="列王紀上 15:25; 列王紀上 22:51; ヨブ記 20:5"> メナヘムの子ペカヒヤはユダの王アザリヤの第五十年に、サマリヤでイスラエルの王となり、二年の間、世を治めた。</span>
<span className="v" id="v24" data-v="24" data-xref="列王紀下 15:9; 列王紀下 15:18"> 彼は主の目の前に悪を行い、イスラエルに罪を犯せたネバテの子ヤラベアムの罪を離れなかった。</span>
<span className="v" id="v25" data-v="25" data-xref="歴代志下 28:6; 列王紀下 9:14; 列王紀上 16:9"> 時に彼の副官であったレマリヤのペカが、ギレアデびと五十人と共に徒党を結んで彼に敵し、サマリヤの、王の宮殿の天守で彼を撃ち殺した。すなわちペカは彼を殺し、彼に代って王となった。</span>
<span className="v" id="v26" data-v="26"> ペカヒヤのその他の事績と彼がしたすべての事は、イスラエルの王の歴代志の書にしるされている。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="イザヤ書 7:4; イザヤ書 7:1; 列王紀下 15:23"> レマリヤの子ペカはユダの王アザリヤの第五十二年に、サマリヤでイスラエルの王となり、二十年の間、世を治めた。</span>
<span className="v" id="v28" data-v="28" data-xref="列王紀下 15:18; 列王紀下 13:6; 列王紀下 15:9"> 彼は主の目の前に悪をおこない、イスラエルに罪を犯させたネバテの子ヤラベアムの罪を離れなかった。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="歴代志上 5:26; 列王紀下 17:6; 列王紀下 16:7"> イスラエルの王ペカの世に、アッスリヤの王テグラテピレセルが来て、イヨン、アベル・ベテマアカ、ヤノア、ケデシ、ハゾル、ギレアデ、ガリラヤ、ナフタリの全地を取り、人々をアッスリヤへ捕え移した。</span>
<span className="v" id="v30" data-v="30" data-xref="列王紀下 17:1; 歴代志下 28:4–6; 列王紀下 16:1"> 時にエラの子ホセアは徒党を結んで、レマリヤの子ペカに敵し、彼を撃ち殺し、彼に代って王となった。これはウジヤの子ヨタムの第二十年であった。</span>
<span className="v" id="v31" data-v="31"> ペカのその他の事績と彼がしたすべての事は、イスラエルの王の歴代志の書にしるされている。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="歴代志上 3:12; 列王紀下 15:7; 歴代志下 27:1–9"> レマリヤの子イスラエルの王ペカの第二年に、ユダの王ウジヤの子ヨタムが王となった。</span>
<span className="v" id="v33" data-v="33" data-xref="歴代志下 27:1"> 彼は王となった時二十五歳であったが、エルサレムで十六年の間、世を治めた。母はザドクの娘で、名をエルシャといった。</span>
<span className="v" id="v34" data-v="34" data-xref="歴代志下 26:4–5; 列王紀下 15:3–4; 歴代志下 27:2"> 彼は主の目にかなう事を行い、すべて父ウジヤの行ったようにおこなった。</span>
<span className="v" id="v35" data-v="35" data-xref="列王紀下 12:3; 歴代志下 23:20; 歴代志下 27:3–9"> ただし高き所は除かなかったので、民はなおその高き所で犠牲をささげ、香をたいた。彼は主の宮の上の門を建てた。</span>
<span className="v" id="v36" data-v="36" data-xref="歴代志下 27:4–9; 列王紀下 15:6–7"> ヨタムのその他の事績と彼がしたすべての事は、ユダの王の歴代志の書にしるされているではないか。</span>
<span className="v" id="v37" data-v="37" data-xref="列王紀下 16:5; イザヤ書 7:1; ルカによる福音書 21:28"> そのころ、主はスリヤの王レヂンとレマリヤの子ペカをユダに攻めこさせられた。</span>
<span className="v" id="v38" data-v="38" data-xref="列王紀上 14:20; 列王紀上 14:31; 列王紀下 16:1"> ヨタムは先祖たちと共に眠って、その先祖ダビデの町に先祖たちと共に葬られ、その子アハズが代って王となった。</span>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="エレミヤ書 41:1; 列王紀下 25:25; 歴代志下 22:10–12"> さてアハジヤの母アタリヤはその子の死んだのを見て、立って王の一族をことごとく滅ぼしたが、</span>
<span className="v" id="v2" data-v="2" data-xref="エレミヤ書 33:26; エレミヤ書 35:2; イザヤ書 7:6–7"> ヨラム王の娘で、アハジヤの姉妹であるエホシバはアハジヤの子ヨアシを、殺されようとしている王の子たちのうちから盗み取り、彼とそのうばとを寝室に入れて、アタリヤに隠したので、彼はついに殺されなかった。</span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 12:8; 歴代志下 22:12; マラキ書 3:15"> ヨアシはうばと共に六年の間、主の宮に隠れていたが、その間アタリヤが国を治めた。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="列王紀下 11:19; 列王紀下 11:9; 列王紀下 11:17"> 第七年になってエホヤダは人をつかわして、カリびとと近衛兵との大将たちを招きよせ、主の宮にいる自分のもとにこさせ、彼らと契約を結び、主の宮で彼らに誓いをさせて王の子を見せ、</span>
<span className="v" id="v5" data-v="5" data-xref="歴代志上 9:25; エゼキエル書 44:2–3; 歴代志上 23:32"> 命じて言った、「あなたがたのする事はこれです、すなわち、安息日に非番となって王の家を守るあなたがたの三分の一は、</span>
<span className="v" id="v6" data-v="6" data-xref="歴代志下 23:4–5; 歴代志上 26:13–19"> 宮殿を守らなければならない。（他の三分の一はスルの門におり、三分の一は近衛兵のうしろの門におる）。</span>
<span className="v" id="v7" data-v="7" data-xref="歴代志下 23:6; 列王紀下 11:5"> すべて安息日に当番で主の宮を守るあなたがたの二つの部隊は、</span>
<span className="v" id="v8" data-v="8" data-xref="民数記 27:17; 歴代志下 23:7; 列王紀上 2:28–31"> おのおのの武器を手に取って王のまわりに立たなければならない。すべて列に近よる者は殺されなければならない。あなたがたは王が出る時にも、はいる時にも王と共にいなければならない」。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="歴代志下 23:8; 列王紀下 11:4; 歴代志上 26:26"> そこでその大将たちは祭司エホヤダがすべて命じたとおりにおこなった。すなわち彼らはおのおの安息日に非番となる者と、安息日に当番となる者とを率いて祭司エホヤダのもとにきたので、</span>
<span className="v" id="v10" data-v="10" data-xref="サムエル記下 8:7; 歴代志上 18:7; 歴代志下 5:1"> 祭司は主の宮にあるダビデ王のやりと盾を大将たちに渡した。</span>
<span className="v" id="v11" data-v="11" data-xref="列王紀下 11:8; エゼキエル書 8:16; 列王紀下 11:10"> 近衛兵はおのおの手に武器をとって主の宮の南側から北側まで、祭壇と宮を取り巻いて立った。</span>
<span className="v" id="v12" data-v="12" data-xref="出エジプト記 25:16; サムエル記上 10:24; 列王紀上 1:39"> そこでエホヤダは王の子をつれ出して冠をいただかせ、律法の書を渡し、彼を王と宣言して油を注いだので、人々は手を打って「王万歳」と言った。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="歴代志下 23:12–15"> アタリヤは近衛兵と民の声を聞いて、主の宮に入り、民のところへ行って、</span>
<span className="v" id="v14" data-v="14" data-xref="歴代志下 34:31; 列王紀下 23:3; 列王紀下 9:23"> 見ると、王は慣例にしたがって柱のかたわらに立ち、王のかたわらには大将たちとラッパ手たちが立ち、また国の民は皆喜んでラッパを吹いていたので、アタリヤはその衣を裂いて、「反逆です、反逆です」と叫んだ。</span>
<span className="v" id="v15" data-v="15" data-xref="エゼキエル書 9:7; 歴代志下 23:14; 歴代志下 23:9"> その時祭司エホヤダは軍勢を指揮していた大将たちに命じて、「彼女を列の間をとおって出て行かせ、彼女に従う者をつるぎをもって殺しなさい」と言った。これは祭司がさきに「彼女を主の宮で殺してはならない」と言ったからである。</span>
<span className="v" id="v16" data-v="16" data-xref="創世記 9:6; 歴代志下 23:15; マタイによる福音書 7:2"> そこで彼らは彼女を捕え、王の家の馬道へ連れて行ったが、彼女はついにそこで殺された。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="サムエル記下 5:3; 歴代志下 15:12–14; 歴代志下 34:31"> かくてエホヤダは主と王および民との間に、皆主の民となるという契約を立てさせ、また王と民との間にもそれを立てさせた。</span>
<span className="v" id="v18" data-v="18" data-xref="申命記 12:3; 列王紀下 10:26; 列王紀上 18:40"> そこで国の民は皆バアルの宮に行って、これをこわし、その祭壇とその像を打ち砕き、バアルの祭司マッタンをその祭壇の前で殺した。そして祭司は主の宮に管理人を置いた。</span>
<span className="v" id="v19" data-v="19" data-xref="エレミヤ書 17:25; エレミヤ書 22:4; 歴代志下 23:19"> 次いでエホヤダは大将たちと、カリびとと、近衛兵と国のすべての民を率いて、主の宮から王を導き下り、近衛兵の門の道から王の家に入り、王の位に座せしめた。</span>
<span className="v" id="v20" data-v="20" data-xref="箴言 11:10; 箴言 29:2; 列王紀下 11:14"> こうして国の民は皆喜び、町はアタリヤが王の家でつるぎをもって殺されてのち、おだやかになった。</span>
<span className="v" id="v21" data-v="21" data-xref="歴代志下 24:1–14; 列王紀下 22:1; 列王紀下 11:4"> ヨアシは位についた時七歳であった。</span>
</div>

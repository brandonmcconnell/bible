<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歴代志下 28:27–1; マタイによる福音書 1:9–10; 歴代志上 3:13"> イスラエルの王エラの子ホセアの第三年にユダの王アハズの子ヒゼキヤが王となった。</span>
<span className="v" id="v2" data-v="2" data-xref="歴代志下 29:1–2"> 彼は王となった時二十五歳で、エルサレムで二十九年の間、世を治めた。その母はゼカリヤの娘で、名をアビといった。</span>
<span className="v" id="v3" data-v="3" data-xref="列王紀下 20:3; 列王紀上 11:4; 歴代志下 31:20–21"> ヒゼキヤはすべて先祖ダビデがおこなったように主の目にかなう事を行い、</span>
<span className="v" id="v4" data-v="4" data-xref="歴代志下 31:1; 民数記 21:8–9; 列王紀下 18:22"> 高き所を除き、石柱をこわし、アシラ像を切り倒し、モーセの造った青銅のへびを打ち砕いた。イスラエルの人々はこの時までそのへびに向かって香をたいていたからである。人々はこれをネホシタンと呼んだ。</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀下 23:25; 列王紀下 19:10; マタイによる福音書 27:43"> ヒゼキヤはイスラエルの神、主に信頼した。そのために彼のあとにも彼の先にも、ユダのすべての王のうちに彼に及ぶ者はなかった。</span>
<span className="v" id="v6" data-v="6" data-xref="ヨシュア記 23:8; 申命記 10:20; ヨハネによる福音書 14:15"> すなわち彼は固く主に従って離れることなく、主がモーセに命じられた命令を守った。</span>
<span className="v" id="v7" data-v="7" data-xref="ローマ人への手紙 8:31; 創世記 39:2–3; 列王紀下 16:7"> 主が彼と共におられたので、すべて彼が出て戦うところで功をあらわした。彼はアッスリヤの王にそむいて、彼に仕えなかった。</span>
<span className="v" id="v8" data-v="8" data-xref="イザヤ書 14:29; 列王紀下 17:9; 歴代志下 28:18"> 彼はペリシテびとを撃ち敗って、ガザとその領域にまで達し、見張台から堅固な町にまで及んだ。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="ホセア書 10:14; 列王紀下 17:3–23; 列王紀下 18:1"> ヒゼキヤ王の第四年すなわちイスラエルの王エラの子ホセアの第七年に、アッスリヤの王シャルマネセルはサマリヤに攻め上って、これを囲んだが、</span>
<span className="v" id="v10" data-v="10" data-xref="アモス書 6:7; アモス書 9:1–4; ミカ書 1:6–9"> 三年の後ついにこれを取った。サマリヤが取られたのはヒゼキヤの第六年で、それはイスラエルの王ホセアの第九年であった。</span>
<span className="v" id="v11" data-v="11" data-xref="歴代志上 5:26; 列王紀下 17:6; イザヤ書 37:12"> アッスリヤの王はイスラエルの人々をアッスリヤに捕えていって、ハラと、ゴザンの川ハボルのほとりと、メデアの町々に置いた。</span>
<span className="v" id="v12" data-v="12" data-xref="ペテロの第一の手紙 4:17; ペテロの第一の手紙 2:8; ミカ書 3:4"> これは彼らがその神、主の言葉にしたがわず、その契約を破り、主のしもべモーセの命じたすべての事に耳を傾けず、また行わなかったからである。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="イザヤ書 36:1–22; 歴代志下 32:1–23; イザヤ書 7:17–25"> ヒゼキヤ王の第十四年にアッスリヤの王セナケリブが攻め上ってユダのすべての堅固な町々を取ったので、</span>
<span className="v" id="v14" data-v="14" data-xref="列王紀下 18:7; ルカによる福音書 14:32; 列王紀上 20:4"> ユダの王ヒゼキヤは人をラキシにつかわしてアッスリヤの王に言った、「わたしは罪を犯しました。どうぞ引き上げてください。わたしに課せられることはなんでもいたします」。アッスリヤの王は銀三百タラントと金三十タラントをユダの王ヒゼキヤに課した。</span>
<span className="v" id="v15" data-v="15" data-xref="列王紀下 16:8; 列王紀上 15:18–19; 列王紀下 12:18"> ヒゼキヤは主の宮と王の家の倉とにある銀をことごとく彼に与えた。</span>
<span className="v" id="v16" data-v="16" data-xref="歴代志下 29:3; 列王紀上 6:31–35"> この時ユダの王ヒゼキヤはまた主の神殿の戸および柱から自分が着せた金をはぎ取って、アッスリヤの王に与えた。</span>
<span className="v" id="v17" data-v="17" data-xref="イザヤ書 20:1; 列王紀下 20:20; イザヤ書 7:3"> アッスリヤの王はまたタルタン、ラブサリスおよびラブシャケを、ラキシから大軍を率いてエルサレムにいるヒゼキヤ王のもとにつかわした。彼らは上ってエルサレムに来た。彼らはエルサレムに着くと、布さらし場に行く大路に沿っている上の池の水道のかたわらへ行って、そこに立った。</span>
<span className="v" id="v18" data-v="18" data-xref="列王紀下 19:2; イザヤ書 36:3; サムエル記下 8:16–17"> そして彼らが王を呼んだので、ヒルキヤの子である宮内卿エリアキム、書記官セブナ、およびアサフの子である史官ヨアが彼らのところに出てきた。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="イザヤ書 36:4; 列王紀下 19:10; イザヤ書 10:8–14"> ラブシャケは彼らに言った、「ヒゼキヤに言いなさい、『大王、アッスリヤの王はこう仰せられる。あなたが頼みとする者は何か。</span>
<span className="v" id="v20" data-v="20" data-xref="箴言 21:30–31"> 口先だけの言葉が戦争をする計略と力だと考えるのか。あなたは今だれにたよって、わたしにそむいたのか。</span>
<span className="v" id="v21" data-v="21" data-xref="イザヤ書 30:7; エゼキエル書 29:6–7; イザヤ書 30:2–3"> 今あなたは、あの折れかけている葦のつえ、エジプトを頼みとしているが、それは人がよりかかる時、その人の手を刺し通すであろう。エジプトの王パロはすべて寄り頼む者にそのようにする。</span>
<span className="v" id="v22" data-v="22" data-xref="歴代志下 31:1; 列王紀下 18:4–5; マタイによる福音書 27:43"> しかしあなたがもし「われわれは、われわれの神、主を頼む」とわたしに言うのであれば、その神はヒゼキヤがユダとエルサレムに告げて、「あなたがたはエルサレムで、この祭壇の前に礼拝しなければならない」と言って、その高き所と祭壇とを除いた者ではないか。</span>
<span className="v" id="v23" data-v="23" data-xref="サムエル記上 17:42; 列王紀上 20:10; ネヘミヤ書 4:2–5"> さあ、わたしの主君アッスリヤの王とかけをせよ。もしあなたの方に乗る人があるならば、わたしは馬二千頭を与えよう。</span>
<span className="v" id="v24" data-v="24" data-xref="イザヤ書 10:8; 申命記 17:16; イザヤ書 36:6"> あなたはエジプトを頼み、戦車と騎兵を請い求めているが、わたしの主君の家来のうちの最も小さい一隊長でさえ、どうして撃退することができようか。</span>
<span className="v" id="v25" data-v="25" data-xref="列王紀下 19:6; イザヤ書 10:5–6; 列王紀下 19:22–37"> わたしがこの所を滅ぼすために上ってきたのは、主の許しなしにしたことであろうか。主がわたしにこの地に攻め上ってこれを滅ぼせと言われたのだ』」。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="エズラ記 4:7; ダニエル書 2:4; イザヤ書 36:11–12"> その時ヒルキヤの子エリアキムおよびセブナとヨアはラブシャケに言った、「どうぞ、アラム語でしもべどもに話してください。わたしたちは、それがわかるからです。城壁の上にいる民の聞いているところで、わたしたちにユダヤの言葉で話さないでください」。</span>
<span className="v" id="v27" data-v="27" data-xref="詩篇 73:8; 哀歌 4:5; エゼキエル書 4:15"> しかしラブシャケは彼らに言った、「わたしの主君は、あなたの主君とあなたにだけでなく、城壁の上に座している人々にも、この言葉を告げるためにわたしをつかわしたのではないか。彼らも、あなたがたと共に自分の糞尿を食い飲みするに至るであろう」。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="イザヤ書 36:13–18; イザヤ書 10:8–13; エゼキエル書 29:3"> そしてラブシャケは立ちあがり、ユダヤの言葉で大声に呼ばわって言った。「大王、アッスリヤの王の言葉を聞け。</span>
<span className="v" id="v29" data-v="29" data-xref="歴代志下 32:15; テサロニケ人への第二の手紙 2:8; 歴代志下 32:11"> 王はこう仰せられる、『あなたがたはヒゼキヤに欺かれてはならない。彼はあなたがたをわたしの手から救いだすことはできない。</span>
<span className="v" id="v30" data-v="30" data-xref="詩篇 125:1–2; ルカによる福音書 23:35; 列王紀下 19:32–34"> ヒゼキヤが「主は必ずわれわれを救い出される。この町はアッスリヤ王の手に陥ることはない」と言っても、あなたがたは主を頼みとしてはならない』。</span>
<span className="v" id="v31" data-v="31" data-xref="列王紀上 4:25; 列王紀上 4:20; ゼカリヤ書 3:10"> あなたがたはヒゼキヤの言葉を聞いてはならない。アッスリヤの王はこう仰せられる、『あなたがたはわたしと和解して、わたしに降服せよ。そうすればあなたがたはおのおの自分のぶどうの実を食べ、おのおの自分のいちじくの実を食べ、おのおの自分の井戸の水を飲むことができるであろう。</span>
<span className="v" id="v32" data-v="32" data-xref="申命記 8:7–9; 出エジプト記 3:8; 申命記 11:12"> やがてわたしが来て、あなたがたを一つの国へ連れて行く。それはあなたがたの国のように穀物とぶどう酒のある地、パンとぶどう畑のある地、オリブの木と蜜のある地である。あなたがたは生きながらえることができ、死ぬことはない。ヒゼキヤが「主はわれわれを救われる」と言って、あなたがたを惑わしても彼に聞いてはならない。</span>
<span className="v" id="v33" data-v="33" data-xref="イザヤ書 10:10–11; 列王紀下 19:12–13; 歴代志下 32:19"> 諸国民の神々のうち、どの神がその国をアッスリヤの王の手から救ったか。</span>
<span className="v" id="v34" data-v="34" data-xref="イザヤ書 10:9; 列王紀下 17:23–33; エレミヤ書 49:23"> ハマテやアルパデの神々はどこにいるのか。セパルワイム、ヘナおよびイワの神々はどこにいるのか。彼らはサマリヤをわたしの手から救い出したか。</span>
<span className="v" id="v35" data-v="35" data-xref="ダニエル書 3:15; イザヤ書 10:15; 出エジプト記 5:2"> 国々のすべての神々のうち、その国をわたしの手から救い出した者があったか。主がどうしてエルサレムをわたしの手から救い出すことができよう』」。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="アモス書 5:13; 箴言 9:7; マタイによる福音書 7:6"> しかし民は黙して、ひと言も彼に答えなかった。王が命じて「彼に答えてはならない」と言っておいたからである。</span>
<span className="v" id="v37" data-v="37" data-xref="列王紀下 22:11; 創世記 37:29; 列王紀下 5:7"> こうしてヒルキヤの子である宮内卿エリアキム、書記官セブナ、およびアサフの子である史官ヨアは衣を裂き、ヒゼキヤのもとに来て、ラブシャケの言葉を彼に告げた。</span>
</div>
</div>

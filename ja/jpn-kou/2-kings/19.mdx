<span className="v" id="v1" data-v="1" data-xref="列王紀上 21:27; 列王紀下 18:37; 歴代志下 32:20–22"> ヒゼキヤ王はこれを聞いて、衣を裂き、荒布を身にまとって主に宮に入り、</span>
<span className="v" id="v2" data-v="2" data-xref="イザヤ書 1:1; イザヤ書 2:1; マタイによる福音書 4:14"> 宮内卿エリアキムと書記官セブナおよび祭司のうちの年長者たちに荒布をまとわせて、アモツの子預言者イザヤのもとにつかわした。</span>
<span className="v" id="v3" data-v="3" data-xref="エレミヤ書 30:5–7; イザヤ書 66:9; ホセア書 13:13"> 彼らはイザヤに言った、「ヒゼキヤはこう申されます、『きょうは悩みと、懲しめと、はずかしめの日です。胎児がまさに生れようとして、これを産み出す力がないのです。</span>
<span className="v" id="v4" data-v="4" data-xref="サムエル記下 16:12; ローマ人への手紙 9:27; ヨシュア記 14:12"> あなたの神、主はラブシャケがその主君アッスリヤの王につかわされて、生ける神をそしったもろもろの言葉を聞かれたかもしれません。そしてあなたの神、主はその聞いた言葉をとがめられるかもしれません。それゆえ、この残っている者のために祈をささげてください』」。</span>
<span className="v" id="v5" data-v="5"> ヒゼキヤ王の家来たちがイザヤのもとに来たとき、</span>
<span className="v" id="v6" data-v="6" data-xref="列王紀下 18:35; 列王紀下 18:17; イザヤ書 37:6–38"> イザヤは彼らに言った、「あなたがたの主君にこう言いなさい、『主はこう仰せられる、アッスリヤの王の家来たちが、わたしをそしった言葉を聞いて恐れるには及ばない。</span>
<span className="v" id="v7" data-v="7" data-xref="オバデヤ書 1:1; 列王紀下 7:6; 詩篇 18:14–15"> 見よ、わたしは一つの霊を彼らのうちに送って、一つのうわさを聞かせ、彼を自分の国へ帰らせて、自分の国でつるぎに倒れさせるであろう』」。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="列王紀下 18:14; ヨシュア記 10:29; ヨシュア記 12:11"> ラブシャケは引き返して、アッスリヤの王がリブナを攻めているところへ行った。彼が王のラキシを去ったことを聞いたからである。</span>
<span className="v" id="v9" data-v="9" data-xref="サムエル記上 23:27; イザヤ書 37:9; 列王紀下 18:17"> この時アッスリヤの王はエチオピヤの王テルハカについて、「彼はあなたと戦うために出てきた」と人々がいうのを聞いたので、再び使者をヒゼキヤにつかわして言った、</span>
<span className="v" id="v10" data-v="10" data-xref="列王紀下 18:5; 列王紀下 18:29–30; 歴代志下 32:15–19"> 「ユダの王ヒゼキヤにこう言いなさい、『あなたは、エルサレムはアッスリヤの王の手に陥ることはない、と言うあなたの信頼する神に欺かれてはならない。</span>
<span className="v" id="v11" data-v="11" data-xref="イザヤ書 10:8–11; 歴代志下 32:13–14; 列王紀下 19:17–18"> あなたはアッスリヤの王たちがもろもろの国々にした事、彼らを全く滅ぼした事を聞いている。どうしてあなたが救われることができようか。</span>
<span className="v" id="v12" data-v="12" data-xref="列王紀下 17:6; 創世記 11:31; エゼキエル書 27:23"> わたしの父たちはゴザン、ハラン、レゼフ、およびテラサルにいたエデンの人々を滅ぼしたが、その国々の神々は彼らを救ったか。</span>
<span className="v" id="v13" data-v="13" data-xref="列王紀下 18:34; 列王紀下 17:24; イザヤ書 11:11"> ハマテの王、アルパデの王、セパルワイムの町の王、ヘナの王およびイワの王はどこにいるのか』」。</span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="イザヤ書 37:14; 詩篇 91:1–2; 詩篇 123:1–4"> ヒゼキヤは使者の手から手紙を受け取ってそれを読み、主の宮にのぼっていって、主の前にそれをひろげ、</span>
<span className="v" id="v15" data-v="15" data-xref="イザヤ書 44:6; 列王紀下 5:15; ダニエル書 4:34–35"> そしてヒゼキヤは主の前に祈って言った、「ケルビムの上に座しておられるイスラエルの神、主よ、地のすべての国のうちで、ただあなただけが神でいらせられます。あなたは天と地を造られました。</span>
<span className="v" id="v16" data-v="16" data-xref="歴代志下 6:40; 詩篇 31:2; 列王紀下 19:4"> 主よ、耳を傾けて聞いてください。主よ、目を開いてごらんください。セナケリブが生ける神をそしるために書き送った言葉をお聞きください。</span>
<span className="v" id="v17" data-v="17" data-xref="歴代志上 5:26; ヨブ記 9:2; コリント人への第一の手紙 14:25"> 主よ、まことにアッスリヤの王たちはもろもろの民とその国々を滅ぼし、</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行伝 17:29; イザヤ書 44:9–20; エレミヤ書 10:3–9"> またその神々を火に投げ入れました。それらは神ではなく、人の手の作ったもので、木や石だから滅ぼされたのです。</span>
<span className="v" id="v19" data-v="19" data-xref="詩篇 83:18; 列王紀上 8:43; 詩篇 67:1–2"> われわれの神、主よ、どうぞ、今われわれを彼の手から救い出してください。そうすれば地の国々は皆、主であるあなただけが神でいらせられることを知るようになるでしょう」。</span>
<span className="v" id="v20" data-v="20" data-xref="列王紀下 20:5; 歴代志下 32:20–21; エレミヤ書 33:3"> その時アモツの子イザヤは人をつかわしてヒゼキヤに言った、「イスラエルの神、主はこう仰せられる、『アッスリヤの王セナケリブについてあなたがわたしに祈ったことは聞いた』。</span>
<span className="v" id="v21" data-v="21" data-xref="哀歌 2:13; ヨブ記 16:4; エレミヤ書 14:17"> 主が彼について語られた言葉はこうである、<br /><span className="pl pl-1">『処女であるシオンの娘は</span><br /><span className="pl pl-1">あなたを侮り、あなたをあざける。</span><br /><span className="pl pl-1">エルサレムの娘は</span><br /><span className="pl pl-1">あなたのうしろで頭を振る。</span></span>
<span className="v" id="v22" data-v="22" data-xref="イザヤ書 5:24; 詩篇 71:22; イザヤ書 30:11–12"> <span className="pl pl-1">あなたはだれをそしり、だれをののしったのか。</span><br /><span className="pl pl-1">あなたはだれにむかって声をあげ、</span><br /><span className="pl pl-1">目を高くあげたのか。</span><br /><span className="pl pl-1">イスラエルの聖者にむかってしたのだ。</span></span>
<span className="v" id="v23" data-v="23" data-xref="列王紀下 18:17; 詩篇 20:7; イザヤ書 10:18"> <span className="pl pl-1">あなたは使者をもって主をそしって言った、</span><br /><span className="pl pl-1">「わたしは多くの戦車をひきいて山々の頂にのぼり、</span><br /><span className="pl pl-1">レバノンの奥に行き、</span><br /><span className="pl pl-1">たけの高い香柏と最も良いいとすぎを切り倒し、</span><br /><span className="pl pl-1">またその果の野営地に行き、</span><br /><span className="pl pl-1">その密林にはいった。</span></span>
<span className="v" id="v24" data-v="24" data-xref="イザヤ書 19:6; 出エジプト記 15:9; サムエル記下 17:13"> <span className="pl pl-1">わたしは井戸を掘って外国の水を飲んだ。</span><br /><span className="pl pl-1">わたしは足の裏で、</span><br /><span className="pl pl-1">エジプトのすべての川を踏みからした」。</span></span>
<span className="v" id="v25" data-v="25" data-xref="イザヤ書 45:7; イザヤ書 10:5–6; イザヤ書 37:26–27"> <span className="pl pl-1">あなたは聞かなかったか、</span><br /><span className="pl pl-1">昔わたしがこれを定めたことを。</span><br /><span className="pl pl-1">堅固な町々をあなたが荒塚とすることも、</span><br /><span className="pl pl-1">いにしえの日からわたしが計画して</span><br /><span className="pl pl-1">今これをおこなうのだ。</span></span>
<span className="v" id="v26" data-v="26" data-xref="エレミヤ書 51:30; 詩篇 102:11; エレミヤ書 51:32"> <span className="pl pl-1">そのうちに住む民は力弱くおののき、恥をいだいて、</span><br /><span className="pl pl-1">野の草のように、青菜のようになり、</span><br /><span className="pl pl-1">育たないで枯れる屋根の草のようになった。</span></span>
<span className="v" id="v27" data-v="27" data-xref="イザヤ書 37:28–29; エレミヤ書 23:23–24; 詩篇 139:1–11"> <span className="pl pl-1">わたしはあなたのすわること、出入りすること、</span><br /><span className="pl pl-1">わたしにむかって怒り叫んだことをも知っている。</span></span>
<span className="v" id="v28" data-v="28" data-xref="エゼキエル書 29:4; エゼキエル書 38:4; 列王紀下 19:33"> <span className="pl pl-1">あなたがわたしにむかって怒り叫んだことと、</span><br /><span className="pl pl-1">あなたの高慢がわたしの耳にはいったため、</span><br /><span className="pl pl-1">わたしはあなたの鼻に輪をつけ、</span><br /><span className="pl pl-1">あなたの口にくつわをはめて、</span><br /><span className="pl pl-1">あなたをもときた道へ引きもどすであろう』。</span></span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="レビ記 25:20–22; 列王紀下 20:8–9; 出エジプト記 3:12"> 『あなたに与えるしるしはこれである。すなわち、ことしは落ち穂からはえたものを食べ、二年目にはまたその落ち穂からはえたものを食べ、三年目には種をまき、刈り入れ、ぶどう畑を作ってその実を食べるであろう。</span>
<span className="v" id="v30" data-v="30" data-xref="列王紀下 19:4; イザヤ書 27:6; 歴代志下 32:22–23"> ユダの家ののがれて残る者は再び下に根を張り、上に実を結ぶであろう。</span>
<span className="v" id="v31" data-v="31" data-xref="イザヤ書 9:7; ローマ人への手紙 11:5; ローマ人への手紙 9:27"> すなわち残る者がエルサレムから出てき、のがれた者がシオンの山から出て来るであろう。主の熱心がこれをされるであろう』。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="イザヤ書 8:7–10; サムエル記下 20:15; イザヤ書 37:33–35"> それゆえ、主はアッスリヤの王について、こう仰せられる、『彼はこの町にこない、またここに矢を放たない、盾をもってその前に来ることなく、また塁を築いてこれを攻めることはない。</span>
<span className="v" id="v33" data-v="33" data-xref="列王紀下 19:28; 列王紀下 19:36"> 彼は来た道を帰って、この町に、はいることはない。主がこれを言う。</span>
<span className="v" id="v34" data-v="34" data-xref="列王紀上 11:12–13; 列王紀下 20:6; 列王紀上 15:4"> わたしは自分のため、またわたしのしもべダビデのためにこの町を守って、これを救うであろう』」。</span>
</div>
<div className="bp">

<span className="v" id="v36" data-v="36" data-xref="ヨナ書 1:2; 列王紀下 19:7; 列王紀下 19:33"> アッスリヤの王セナケリブは立ち去り、帰って行ってニネベにいたが、</span>
<span className="v" id="v37" data-v="37" data-xref="エズラ記 4:2; 創世記 8:4; 列王紀下 19:7"> その神ニスロクの神殿で礼拝していた時、その子アデランメレクとシャレゼルが、つるぎをもって彼を殺し、ともにアララテの地へ逃げて行った。そこでその子エサルハドンが代って王となった。</span>

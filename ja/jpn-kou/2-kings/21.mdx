<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="イザヤ書 62:4; 歴代志下 32:33–9; マタイによる福音書 1:10"> マナセは十二歳で王となり、五十五年の間、エルサレムで世を治めた。母の名はヘフジバといった。</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 12:31; 歴代志下 36:14; 歴代志下 33:2–4"> マナセは主がイスラエルの人々の前から追い払われた国々の民の憎むべきおこないにならって、主の目の前に悪をおこなった。</span>
<span className="v" id="v3" data-v="3" data-xref="列王紀下 18:4; 列王紀下 17:16; 申命記 17:3"> 彼は父ヒゼキヤがこわした高き所を建て直し、またイスラエルの王アハブがしたようにバアルのために祭壇を築き、アシラ像を造り、かつ天の万象を拝んで、これに仕えた。</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀上 8:29; サムエル記下 7:13; エレミヤ書 32:34"> また主の宮のうちに数個の祭壇を築いた。これは主が「わたしの名をエルサレムに置こう」と言われたその宮である。</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀上 7:12; 列王紀下 23:4; 列王紀下 23:12"> 彼はまた主の宮の二つの庭に天の万象のために祭壇を築いた。</span>
<span className="v" id="v6" data-v="6" data-xref="列王紀下 17:17; レビ記 19:31; レビ記 18:21"> またその子を火に焼いてささげ物とし、占いをし、魔術を行い、口寄せと魔法使を用い、主の目の前に多くの悪を行って、主の怒りを引き起した。</span>
<span className="v" id="v7" data-v="7" data-xref="歴代志下 7:16; 列王紀上 9:3; サムエル記下 7:13"> 彼はまたアシラの彫像を作って主の宮に置いた。主はこの宮についてダビデとその子ソロモンに言われたことがある、「わたしはこの宮と、わたしがイスラエルのすべての部族のうちから選んだエルサレムとに、わたしの名を永遠に置く。</span>
<span className="v" id="v8" data-v="8" data-xref="サムエル記下 7:10; 申命記 5:28–29; 詩篇 81:11–16"> もし、彼らがわたしが命じたすべての事、およびわたしのしもべモーセが命じたすべての律法を守り行うならば、イスラエルの足を、わたしが彼らの先祖たちに与えた地から、重ねて迷い出させないであろう」。</span>
<span className="v" id="v9" data-v="9" data-xref="箴言 29:12; ネヘミヤ書 9:26; 列王紀上 14:16"> しかし彼らは聞きいれなかった。マナセが人々をいざなって悪を行ったことは、主がイスラエルの人々の前に滅ぼされた国々の民よりもはなはだしかった。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="マタイによる福音書 23:34–37; 歴代志下 33:10; 歴代志下 36:15"> そこで主はそのしもべである預言者たちによって言われた、</span>
<span className="v" id="v11" data-v="11" data-xref="列王紀下 24:3–4; 列王紀上 21:26; 列王紀下 21:9"> 「ユダの王マナセがこれらの憎むべき事を行い、彼の先にあったアモリびとの行ったすべての事よりも悪い事を行い、またその偶像をもってユダに罪を犯させたので、</span>
<span className="v" id="v12" data-v="12" data-xref="エレミヤ書 19:3; サムエル記上 3:11; ダニエル書 9:12"> イスラエルの神、主はこう仰せられる、見よ、わたしはエルサレムとユダに災をくだそうとしている。これを聞く者は、その耳が二つながら鳴るであろう。</span>
<span className="v" id="v13" data-v="13" data-xref="アモス書 7:7–8; 哀歌 2:8; イザヤ書 34:11"> わたしはサマリヤをはかった測りなわと、アハブの家に用いた下げ振りをエルサレムにほどこし、人が皿をぬぐい、これをぬぐって伏せるように、エルサレムをぬぐい去る。</span>
<span className="v" id="v14" data-v="14" data-xref="エレミヤ書 23:33; 列王紀下 19:4; 詩篇 89:38–45"> わたしは、わたしの嗣業の民の残りを捨て、彼らを敵の手に渡す。彼らはもろもろの敵のえじきとなり、略奪にあうであろう。</span>
<span className="v" id="v15" data-v="15" data-xref="エゼキエル書 20:30; 申命記 31:27; エゼキエル書 20:21"> これは彼らの先祖たちがエジプトを出た日から今日に至るまで、彼らがわたしの目の前に悪を行って、わたしを怒らせたためである」。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="民数記 35:33; 歴代志下 33:9; 列王紀下 21:11"> マナセはまた主の目の前に悪を行って、ユダに罪を犯させたその罪のほかに、罪なき者の血を多く流して、エルサレムのこの果から、かの果にまで満たした。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="列王紀下 20:20–21; 歴代志下 33:1–20"> マナセのその他の事績と、彼がおこなったすべての事およびその犯した罪は、ユダの王の歴代志の書にしるされているではないか。</span>
<span className="v" id="v18" data-v="18" data-xref="歴代志下 33:20; 列王紀下 21:26; 歴代志下 32:33"> マナセは先祖たちと共に眠って、その家の園すなわちウザの園に葬られ、その子アモンが代って王となった。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="歴代志下 33:21–23; 列王紀上 22:51; 歴代志上 3:14"> アモンは王となった時二十二歳であって、エルサレムで二年の間、世を治めた。母はヨテバのハルツの娘で、名をメシュレメテといった。</span>
<span className="v" id="v20" data-v="20" data-xref="マタイによる福音書 23:32; 列王紀下 21:11; 使徒行伝 7:51"> アモンはその父マナセのおこなったように、主の目の前に悪を行った。</span>
<span className="v" id="v21" data-v="21"> すなわち彼はすべてその父の歩んだ道に歩み、父の仕えた偶像に仕えて、これを拝み、</span>
<span className="v" id="v22" data-v="22" data-xref="列王紀下 22:17; 列王紀上 11:33; 歴代志上 28:9"> 先祖たちの神、主を捨てて、主の道に歩まなかった。</span>
<span className="v" id="v23" data-v="23" data-xref="列王紀下 12:20; 列王紀下 14:19; 歴代志下 33:24–25"> アモンの家来たちはついに彼に敵して徒党を結び、王をその家で殺したが、</span>
<span className="v" id="v24" data-v="24" data-xref="列王紀下 14:5; 列王紀下 11:17; 列王紀下 14:21"> 国の民は、アモン王に敵して徒党を結んだ者をことごとく撃ち殺した。そして国の民はアモンの子ヨシヤを王としてアモンに代らせた。</span>
<span className="v" id="v25" data-v="25" data-xref="列王紀下 20:20; 列王紀下 21:17"> アモンのその他の事績は、ユダの王の歴代志の書にしるされているではないか。</span>
<span className="v" id="v26" data-v="26" data-xref="列王紀下 21:18; マタイによる福音書 1:10; 列王紀上 13:5"> アモンはウザの園にある墓に葬られ、その子ヨシヤが代って王となった。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="イザヤ書 38:1–22; 歴代志下 32:24–26; ピリピ人への手紙 2:27"> そのころ、ヒゼキヤは病気になって死にかかっていた。アモツの子預言者イザヤは彼のところにきて言った、「主はこう仰せられます、『家の人に遺言をなさい。あなたは死にます。生きながらえることはできません』」。</span>
<span className="v" id="v2" data-v="2" data-xref="詩篇 50:15; マタイによる福音書 6:6; イザヤ書 38:2–3"> そこでヒゼキヤは顔を壁に向けて主に祈って言った、</span>
<span className="v" id="v3" data-v="3" data-xref="ネヘミヤ書 13:14; ネヘミヤ書 13:22; ネヘミヤ書 5:19"> 「ああ主よ、わたしが真実を真心をもってあなたの前に歩み、あなたの目にかなうことをおこなったのをどうぞ思い起してください」。そしてヒゼキヤは激しく泣いた。</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀下 22:14; 列王紀上 7:8"> イザヤがまだ中庭を出ないうちに主の言葉が彼に臨んだ、</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 66:19–20; イザヤ書 38:5; サムエル記上 9:16"> 「引き返して、わたしの民の君ヒゼキヤに言いなさい、『あなたの父ダビデの神、主はこう仰せられる、わたしはあなたの祈を聞き、あなたの涙を見た。見よ、わたしはあなたをいやす。三日目にはあなたは主の宮に上るであろう。</span>
<span className="v" id="v6" data-v="6" data-xref="列王紀下 19:34; 使徒行伝 27:24; イザヤ書 10:24"> かつ、わたしはあなたのよわいを十五年増す。わたしはあなたと、この町とをアッスリヤの王の手から救い、わたしの名のため、またわたしのしもべダビデのためにこの町を守るであろう』」。</span>
<span className="v" id="v7" data-v="7" data-xref="イザヤ書 38:21; 列王紀下 2:20–22; 列王紀下 4:41"> そしてイザヤは言った、「干しいちじくのひとかたまりを持ってきて、それを腫物につけさせなさい。そうすれば直るでしょう」。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="士師記 6:17; イザヤ書 7:11; 列王紀下 19:29"> ヒゼキヤはイザヤに言った、「主がわたしをいやされる事と、三日目にわたしが主の家に上ることについて、どんなしるしがありましょうか」。</span>
<span className="v" id="v9" data-v="9" data-xref="イザヤ書 38:7–8; マルコによる福音書 8:11–12; マタイによる福音書 16:1–4"> イザヤは言った、「主が約束されたことを行われることについては、主からこのしるしを得られるでしょう。すなわち日影が十度進むか、あるいは十度退くかです」。</span>
<span className="v" id="v10" data-v="10" data-xref="列王紀下 3:18; 列王紀下 2:10; ヨハネによる福音書 14:12"> ヒゼキヤは答えた、「日影が十度進むことはたやすい事です。むしろ日影を十度退かせてください」。</span>
<span className="v" id="v11" data-v="11" data-xref="イザヤ書 38:8; ヨシュア記 10:12–14; 歴代志下 32:24"> そこで預言者イザヤが主に呼ばわると、アハズの日時計の上に進んだ日影を、十度退かせられた。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="イザヤ書 39:1–8; 歴代志下 32:31; イザヤ書 13:1"> そのころ、バラダンの子であるバビロンの王メロダクバラダンは、手紙と贈り物を持たせて使節をヒゼキヤにつかわした。これはヒゼキヤが病んでいることを聞いたからである。</span>
<span className="v" id="v13" data-v="13" data-xref="イザヤ書 39:2; 歴代志下 32:25–27; 列王紀上 10:15"> ヒゼキヤは彼らを喜び迎えて、宝物の蔵、金銀、香料、貴重な油および武器倉、ならびにその倉庫にあるすべての物を彼らに見せた。家にある物も、国にある物も、ヒゼキヤが彼らに見せない物は一つもなかった。</span>
<span className="v" id="v14" data-v="14" data-xref="イザヤ書 13:5; サムエル記下 12:7–15; 列王紀下 5:25–26"> その時、預言者イザヤはヒゼキヤ王のもとにきて言った、「あの人々は何を言いましたか。どこからきたのですか」。ヒゼキヤは言った、「彼らは遠い国から、バビロンからきたのです」。</span>
<span className="v" id="v15" data-v="15" data-xref="ヨブ記 31:33; ヨシュア記 7:19; 列王紀下 20:13"> イザヤは言った、「彼らはあなたの家で何を見ましたか」。ヒゼキヤは答えて言った、「わたしの家にある物を皆見ました。わたしの倉庫のうちには、わたしが彼らに見せない物は一つもありません」。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="列王紀上 22:19; 列王紀下 7:1; イザヤ書 1:10"> そこでイザヤはヒゼキヤに言った、「主の言葉を聞きなさい、</span>
<span className="v" id="v17" data-v="17" data-xref="列王紀下 24:13; 歴代志下 36:10; エレミヤ書 52:17–19"> 『主は言われる、見よ、すべてあなたの家にある物、および、あなたの先祖たちが今日までに積みたくわえた物の、バビロンに運び去られる日が来る。何も残るものはないであろう。</span>
<span className="v" id="v18" data-v="18" data-xref="歴代志下 33:11; 列王紀下 24:12; ダニエル書 1:3"> また、あなたの身から出るあなたの子たちも連れ去られ、バビロンの王の宮殿で宦官となるであろう』」。</span>
<span className="v" id="v19" data-v="19" data-xref="サムエル記上 3:18; ゼカリヤ書 8:19; ルカによる福音書 2:10"> ヒゼキヤはイザヤに言った、「あなたが言われた主の言葉は結構です」。彼は「せめて自分が世にあるあいだ、平和と安全があれば良いことではなかろうか」と思ったからである。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="ネヘミヤ書 3:16; 歴代志下 32:32; 歴代志下 32:4"> ヒゼキヤのその他の事績とその武勇および、彼が貯水池と水道を作って、町に水を引いた事は、ユダの王の歴代志の書にしるされているではないか。</span>
<span className="v" id="v21" data-v="21" data-xref="歴代志下 32:33; 列王紀上 14:31; 歴代志下 26:23"> ヒゼキヤはその先祖たちと共に眠って、その子マナセが代って王となった。</span>
</div>

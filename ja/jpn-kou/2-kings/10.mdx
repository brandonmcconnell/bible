<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士師記 8:30; 列王紀上 13:32; 列王紀上 21:8–14"> アハブはサマリヤに七十人の子供があった。エヒウは手紙をしたためてサマリヤに送り、町のつかさたちと、長老たちと、アハブの子供の守役たちとに伝えて言った、</span>
<span className="v" id="v2" data-v="2" data-xref="列王紀下 5:6"> 「あなたがたの主君の子供たちがあなたがたと共におり、また戦車も馬も、堅固な町も武器もあるのだから、この手紙があなたがたのもとに届いたならば、すぐ、</span>
<span className="v" id="v3" data-v="3" data-xref="サムエル記下 2:8–9; 列王紀上 12:20–21; サムエル記下 2:12–17"> あなたがたは主君の子供たちのうち最もすぐれた、最も適当な者を選んで、その父の位にすえ、主君の家のために戦いなさい」。</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀下 9:24; 列王紀下 9:27; イザヤ書 27:4"> 彼らは大いに恐れて言った、「ふたりの王たちがすでに彼に当ることができなかったのに、われわれがどうして当ることができよう」。</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀上 20:32; 列王紀上 20:4; ヨシュア記 9:11"> そこで宮廷のつかさ、町のつかさ、長老たちと守役たちはエヒウに人をつかわして言った、「わたしたちは、あなたのしもべです。すべてあなたが命じられる事をいたします。わたしたちは王を立てることを好みません。あなたがよいと思われることをしてください」。</span>
<span className="v" id="v6" data-v="6" data-xref="ヨハネの黙示録 2:20–23; 申命記 5:9; 民数記 25:4"> そこでエヒウは再び彼らに手紙を書き送って言った、「もしあなたがたが、わたしに味方し、わたしに従おうとするならば、あなたがたの主君の子供たちの首を取って、あすの今ごろエズレルにいるわたしのもとに持ってきなさい」。そのころ、王の子供たち七十人は彼らを育てていた町のおもだった人々と共にいた。</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀上 21:21; 列王紀下 11:1; 列王紀下 10:9"> 彼らはその手紙を受け取ると、王の子供たちを捕えて、その七十人をことごとく殺し、その首をかごにつめて、エズレルにいるエヒウのもとに送った。</span>
<span className="v" id="v8" data-v="8" data-xref="申命記 21:23; サムエル記下 11:18–21; マルコによる福音書 6:28"> 使者が来て、エヒウに告げ、「人々が王の子供たちの首を持ってきました」と言うと、「あくる朝までそれを門の入口に、ふた山に積んでおけ」と言った。</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀下 9:14–24; イザヤ書 5:3; ホセア書 1:4"> 朝になると、彼は出て行って立ち、すべての民に言った、「あなたがたは正しい。主君にそむいて彼を殺したのはわたしです。しかしこのすべての者どもを殺したのはだれですか。</span>
<span className="v" id="v10" data-v="10" data-xref="列王紀上 21:29; 列王紀上 21:19; 列王紀下 9:7–10"> これであなたがたは、主がアハブの家について告げられた主の言葉は一つも地に落ちないことを知りなさい。主は、そのしもべエリヤによってお告げになった事をなし遂げられたのです」。</span>
<span className="v" id="v11" data-v="11" data-xref="ヨブ記 18:19; 列王紀上 18:19; 列王紀上 22:6"> こうしてエヒウは、アハブの家に属する者でエズレルに残っている者をことごとく殺し、またそのすべてのおもだった者、その親しい者およびその祭司たちを殺して、彼に属する者はひとりも残さなかった。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12"> さてエヒウは立ってサマリヤへ行ったが、途中、牧者の集まり場で、</span>
<span className="v" id="v13" data-v="13" data-xref="列王紀下 8:29; 列王紀下 8:24; 歴代志下 21:17"> ユダの王アハジヤの身内の人々に会い、「あなたがたはどなたですか」と言うと、「わたしたちはアハジヤの身内の者ですが、王の子供たちと、王母の子供たちの安否を問うために下ってきたのです」と答えたので、</span>
<span className="v" id="v14" data-v="14" data-xref="歴代志下 22:10; 列王紀下 10:6; 列王紀下 10:10–11"> エヒウは「彼らをいけどれ」と命じた。そこで彼らをいけどって、集まり場の穴のかたわらで彼ら四十二人をことごとく殺し、ひとりをも残さなかった。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="エレミヤ書 35:14–19; エズラ記 10:19; エゼキエル書 17:18"> エヒウはそこを立って行ったが、自分を迎えにきたレカブの子ヨナダブに会ったので、彼にあいさつして、「あなたの心は、わたしがあなたに対するように真実ですか」と言うと、ヨナダブは「真実です」と答えた。するとエヒウは「それならば、あなたの手をわたしに伸べなさい」と言ったので、その手を伸べると、彼を引いて自分の車に上らせ、</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀上 19:10; マタイによる福音書 6:5; 列王紀下 10:31"> 「わたしと一緒にきて、わたしが主に熱心なのを見なさい」と言った。そして彼を自分の車に乗せ、</span>
<span className="v" id="v17" data-v="17" data-xref="列王紀下 9:8; 歴代志下 22:8; マラキ書 4:1"> サマリヤへ行って、アハブに属する者で、サマリヤに残っている者をことごとく殺して、その一族を滅ぼした。主がエリヤにお告げになった言葉のとおりである。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="列王紀上 16:31–32; 列王紀下 3:2; ローマ人への手紙 3:8"> 次いでエヒウは民をことごとく集めて彼らに言った、「アハブは少しばかりバアルに仕えたが、エヒウは大いにこれに仕えるであろう。</span>
<span className="v" id="v19" data-v="19" data-xref="列王紀上 22:6; 列王紀上 18:19; コリント人への第二の手紙 11:3"> それゆえ、今バアルのすべての預言者、すべての礼拝者、すべての祭司をわたしのもとに召しなさい。ひとりもこない者のないようにしなさい。わたしは大いなる犠牲をバアルにささげようとしている。すべてこない者は生かしておかない」。しかしエヒウはバアルの礼拝者たちを滅ぼすために偽ってこうしたのである。</span>
<span className="v" id="v20" data-v="20" data-xref="ヨエル書 1:14; 出エジプト記 32:5; 列王紀上 18:19–20"> そしてエヒウは「バアルのために聖会を催しなさい」と命じたので、彼らはこれを布告した。</span>
<span className="v" id="v21" data-v="21" data-xref="列王紀上 16:32; 列王紀下 11:18; ヨエル書 3:2"> エヒウはあまねくイスラエルに人をつかわしたので、バアルの礼拝者たちはことごとく来た。こないで残った者はひとりもなかった。彼らはバアルの宮にはいったので、バアルの宮は端から端までいっぱいになった。</span>
<span className="v" id="v22" data-v="22" data-xref="出エジプト記 28:2; マタイによる福音書 22:11–12"> その時エヒウは衣装をつかさどる者に「祭服を取り出してバアルのすべての礼拝者に与えよ」と言ったので、彼らのために祭服を取り出した。</span>
<span className="v" id="v23" data-v="23" data-xref="マタイによる福音書 13:30; マタイによる福音書 25:32–33; マタイによる福音書 13:41"> そしてエヒウはレカブの子ヨナダブと共にバアルの宮に入り、バアルの礼拝者たちに言った、「調べてみて、ここにはただバアルの礼拝者のみで、主のしもべはひとりも、あなたがたのうちにいないようにしなさい」。</span>
<span className="v" id="v24" data-v="24" data-xref="列王紀上 20:30–42"> こうして彼は犠牲と燔祭とをささげるためにはいった。<br />さてエヒウは八十人の者を外に置いて言った、「わたしがあなたがたの手に渡す者をひとりでも逃す者は、自分の命をもってその人の命に換えなければならない」。</span>
<span className="v" id="v25" data-v="25" data-xref="ヨハネの黙示録 16:6–7; エゼキエル書 22:21–22; 列王紀上 18:40"> こうして燔祭をささげることが終ったとき、エヒウはその侍衛と将校たちに言った、「はいって彼らを殺せ。ひとりも逃がしてはならない」。侍衛と将校たちはつるぎをもって彼らを撃ち殺し、それを投げ出して、バアルの宮の本殿に入り、</span>
<span className="v" id="v26" data-v="26" data-xref="列王紀上 14:23; 列王紀下 3:2; 列王紀下 19:18"> バアルの宮にある柱の像を取り出して、それを焼いた。</span>
<span className="v" id="v27" data-v="27" data-xref="ダニエル書 3:29; エズラ記 6:11; ダニエル書 2:5"> また彼らはバアルの石柱をこわし、バアルの宮をこわして、かわやとしたが今日まで残っている。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28"> このようにエヒウはイスラエルのうちからバアルを一掃した。</span>
<span className="v" id="v29" data-v="29" data-xref="列王紀上 12:28–30; 列王紀上 14:16; 列王紀上 13:33–34"> しかしエヒウはイスラエルに罪を犯させたネバテの子ヤラベアムの罪、すなわちベテルとダンにある金の子牛に仕えることをやめなかった。</span>
<span className="v" id="v30" data-v="30" data-xref="列王紀下 10:35; 列王紀下 13:1; 列王紀下 13:10"> 主はエヒウに言われた、「あなたはわたしの目にかなう事を行うにあたって、よくそれを行い、またわたしの心にあるすべての事をアハブの家にしたので、あなたの子孫は四代までイスラエルの位に座するであろう」。</span>
<span className="v" id="v31" data-v="31" data-xref="列王紀下 10:29; 箴言 4:23; ヘブル人への手紙 2:1"> しかしエヒウはイスラエルの神、主の律法を心をつくして守り行おうとはせず、イスラエルに罪を犯させたヤラベアムの罪を離れなかった。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="列王紀下 8:12; 列王紀上 19:17; 列王紀下 13:22"> この時にあたって、主はイスラエルの領地を切り取ることを始められた。すなわちハザエルはイスラエルのすべての領域を侵し、</span>
<span className="v" id="v33" data-v="33" data-xref="アモス書 1:3–4; 申命記 2:36; ヨシュア記 13:9–12"> ヨルダンの東で、ギレアデの全地、カドびと、ルベンびと、マナセびとの地を侵し、アルノン川のほとりにあるアロエルからギレアデとバシャンに及んだ。</span>
<span className="v" id="v34" data-v="34" data-xref="列王紀上 11:41; 列王紀上 14:29; 列王紀上 14:19"> エヒウのその他の事績と、彼がしたすべての事およびその武勇は、ことごとくイスラエルの王の歴代志の書にしるされているではないか。</span>
<span className="v" id="v35" data-v="35" data-xref="列王紀上 14:20; 列王紀上 14:31; 列王紀上 1:21"> エヒウはその先祖たちと共に眠ったので、彼をサマリヤに葬った。その子エホアハズが代って王となった。</span>
<span className="v" id="v36" data-v="36"> エヒウがサマリヤでイスラエルを治めたのは二十八年であった。</span>
</div>

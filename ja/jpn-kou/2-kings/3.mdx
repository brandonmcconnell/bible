<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀下 1:17; 列王紀上 22:51; 列王紀下 8:16"> ユダの王ヨシャパテの第十八年にアハブの子ヨラムはサマリヤでイスラエルの王となり、十二年世を治めた。</span>
<span className="v" id="v2" data-v="2" data-xref="列王紀下 10:18; 列王紀下 10:26–28; 列王紀上 21:25"> 彼は主の目の前に悪をおこなったが、その父母のようではなかった。彼がその父の造ったバアルの石柱を除いたからである。</span>
<span className="v" id="v3" data-v="3" data-xref="列王紀上 14:16; 列王紀上 15:34; 列王紀下 15:18"> しかし彼はイスラエルに罪を犯させたネバテの子ヤラベアムの罪につき従って、それを離れなかった。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="サムエル記下 8:2; 創世記 26:13–14; ヨブ記 1:3"> モアブの王メシャは羊の飼育者で、十万の小羊と、十万の雄羊の毛とを年々イスラエルの王に納めていたが、</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀下 1:1; 列王紀下 8:20; 歴代志下 21:8–10"> アハブが死んだ後、モアブの王はイスラエルの王にそむいた。</span>
<span className="v" id="v6" data-v="6" data-xref="サムエル記下 24:1–25; サムエル記上 11:8; サムエル記上 15:4"> そこでヨラム王はその時サマリヤを出て、イスラエルびとをことごとく集め、</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀上 22:4; 歴代志下 22:10–12; 歴代志下 18:3"> また、人をユダの王ヨシャパテにつかわし、「モアブの王はわたしにそむきました。あなたはモアブと戦うために、わたしと一緒に行かれませんか」と言わせた。彼は言った、「行きましょう。わたしはあなたと一つです。わたしの民はあなたの民と一つです。わたしの馬はあなたの馬と一つです」。</span>
<span className="v" id="v8" data-v="8" data-xref="マラキ書 1:2–3; 民数記 21:4"> 彼はまた言った、「われわれはどの道を上るのですか」。ヨラムは答えた、「エドムの荒野の道を上りましょう」。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="列王紀上 22:47; 民数記 20:2; 出エジプト記 17:1"> こうしてイスラエルの王はユダの王およびエドムの王と共に出て行った。しかし彼らは回り道をして、七日の間進んだが、軍勢とそれに従う家畜の飲む水がなかったので、</span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 78:34–36; イザヤ書 51:20; イザヤ書 8:21"> イスラエルの王は言った、「ああ、主は、この三人の王をモアブの手に渡そうとして召し集められたのだ」。</span>
<span className="v" id="v11" data-v="11" data-xref="列王紀上 22:7; 列王紀上 19:21; 列王紀下 3:3"> ヨシャパテは言った、「われわれが主に問うことのできる主の預言者はここにいませんか」。イスラエルの王のひとりの家来が答えた、「エリヤの手に水を注いだシャパテの子エリシャがここにいます」。</span>
<span className="v" id="v12" data-v="12" data-xref="列王紀下 5:15; 列王紀下 2:21; イザヤ書 60:14"> ヨシャパテは言った、「主の言葉が彼にあります」。そこでイスラエルの王とヨシャパテとエドムの王とは彼のもとへ下っていった。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="列王紀上 22:6; 列王紀上 18:19; 列王紀上 22:10–11"> エリシャはイスラエルの王に言った、「わたしはあなたとなんのかかわりがありますか。あなたの父上の預言者たちと母上の預言者たちの所へ行きなさい」。イスラエルの王は彼に言った、「いいえ、主がこの三人の王をモアブの手に渡そうとして召し集められたのです」。</span>
<span className="v" id="v14" data-v="14" data-xref="列王紀下 5:16; 列王紀上 17:1; 歴代志下 19:3–4"> エリシャは言った、「わたしの仕える万軍の主は生きておられます。わたしはユダの王ヨシャパテのためにするのでなければ、あなたを顧み、あなたに会うことはしないのだが、</span>
<span className="v" id="v15" data-v="15" data-xref="サムエル記上 16:23; エペソ人への手紙 5:18–19; エゼキエル書 1:3"> いま楽人をわたしの所に連れてきなさい」。そこで楽人が楽を奏すると、主の手が彼に臨んで、</span>
<span className="v" id="v16" data-v="16" data-xref="民数記 2:16–18; 列王紀下 4:3"> 彼は言った、「主はこう仰せられる、『わたしはこの谷を水たまりで満たそう』。</span>
<span className="v" id="v17" data-v="17" data-xref="詩篇 107:35; イザヤ書 41:17–18; イザヤ書 48:21"> これは主がこう仰せられるからである、『あなたがたは風も雨も見ないのに、この谷に水が満ちて、あなたがたと、その家畜および獣が飲むであろう』。</span>
<span className="v" id="v18" data-v="18" data-xref="エレミヤ書 32:27; ルカによる福音書 1:37; エレミヤ書 32:17"> これは主の目には小さい事である。主はモアブびとをも、あなたがたの手に渡される。</span>
<span className="v" id="v19" data-v="19" data-xref="列王紀下 13:17; 申命記 20:19–20; 士師記 6:16"> そしてあなたがたはすべての堅固な町と、すべての良い町を撃ち、すべての良い木を切り倒し、すべての水の井戸をふさぎ、石をもって地のすべての良い所を荒すであろう」。</span>
<span className="v" id="v20" data-v="20" data-xref="出エジプト記 29:39–40; ダニエル書 9:21; 列王紀上 18:36"> あくる朝になって、供え物をささげる時に、水がエドムの方から流れてきて、水は国に満ちた。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="エペソ人への手紙 6:14; 列王紀上 20:11"> さてモアブびとは皆、王たちが自分たちを攻めるために上ってきたのを聞いたので、よろいを着ることのできる者を、老いも若きもことごとく召集して、国境に配置したが、</span>
<span className="v" id="v22" data-v="22"> 朝はやく起きて、太陽がのぼって水を照したとき、モアブびとは目の前に血のように赤い水を見たので、</span>
<span className="v" id="v23" data-v="23" data-xref="士師記 5:30; 出エジプト記 15:9; イザヤ書 10:14"> 彼らは言った、「これは血だ、きっと王たちが互に戦って殺し合ったのだ。だから、モアブよ、ぶんどりに行きなさい」。</span>
<span className="v" id="v24" data-v="24" data-xref="テサロニケ人への第一の手紙 5:3–4; ヨシュア記 8:20–22; 士師記 20:40–46"> しかしモアブびとがイスラエルの陣営に行くと、イスラエルびとは立ちあがってモアブびとを撃ったので、彼らはイスラエルの前から逃げ去った。イスラエルびとは進んで、モアブびとを撃ち、その国にはいって、</span>
<span className="v" id="v25" data-v="25" data-xref="イザヤ書 16:7; エレミヤ書 48:36; エレミヤ書 48:31"> 町々を滅ぼし、おのおの石を一つずつ、地のすべての良い所に投げて、これに満たし、水の井戸をことごとくふさぎ、良い木をことごとく切り倒して、ただキル・ハラセテはその名を残すのみとなったが、石を投げる者がこれを囲んで撃ち滅ぼした。</span>
<span className="v" id="v26" data-v="26" data-xref="列王紀下 3:9; アモス書 2:1"> モアブの王は戦いがあまりに激しく、当りがたいのを見て、つるぎを抜く者七百人を率い、エドムの王の所に突き入ろうとしたが、果さなかったので、</span>
<span className="v" id="v27" data-v="27" data-xref="ミカ書 6:7; 申命記 12:31; 士師記 11:31"> 自分の位を継ぐべきその長子をとって城壁の上で燔祭としてささげた。その時イスラエルに大いなる憤りが臨んだので、彼らは彼をすてて自分の国に帰った。</span>
</div>

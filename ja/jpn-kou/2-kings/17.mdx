<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀下 15:30"> ユダの王アハズの第十二年にエラの子ホセアが王となり、サマリヤで九年の間、イスラエルを治めた。</span>
<span className="v" id="v2" data-v="2" data-xref="列王紀下 3:2; 列王紀下 13:11; 歴代志下 30:5–11"> 彼は主の目の前に悪を行ったが、彼以前のイスラエルの王たちのようではなかった。</span>
<span className="v" id="v3" data-v="3" data-xref="ホセア書 10:14; 列王紀下 15:19; 列王紀下 19:36–37"> アッスリヤの王シャルマネセルが攻め上ったので、ホセアは彼に隷属して、みつぎを納めたが、</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀下 18:21; 列王紀下 24:20; エゼキエル書 17:13–19"> アッスリヤの王はホセアがついに自分にそむいたのを知った。それはホセアが使者をエジプトの王ソにつかわし、また年々納めていたみつぎを、アッスリヤの王に納めなかったからである。そこでアッスリヤの王は彼を監禁し、獄屋につないだ。</span>
<span className="v" id="v5" data-v="5" data-xref="ホセア書 13:16; 列王紀下 25:1–3; 列王紀下 18:9"> そしてアッスリヤの王は攻め上って国中を侵し、サマリヤに上ってきて三年の間、これを攻め囲んだ。</span>
<span className="v" id="v6" data-v="6" data-xref="歴代志上 5:26; ホセア書 13:16; 申命記 28:64"> ホセアの第九年になって、アッスリヤの王はついにサマリヤを取り、イスラエルの人々をアッスリヤに捕えていって、ハラと、ゴザンの川ハボルのほとりと、メデアの町々においた。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="ヨシュア記 23:16; 詩篇 106:35–41; ネヘミヤ書 9:26"> この事が起ったのは、イスラエルの人々が、自分たちをエジプトの地から導き上って、エジプトの王パロの手をのがれさせられたその神、主にむかって罪を犯し、他の神々を敬い、</span>
<span className="v" id="v8" data-v="8" data-xref="レビ記 18:3; 列王紀下 16:3; 申命記 18:9"> 主がイスラエルの人々の前から追い払われた異邦人のならわしに従って歩み、またイスラエルの王たちが定めたならわしに従って歩んだからである。</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀下 18:8; ヨブ記 31:27; 申命記 13:6"> イスラエルの人々はその神、主にむかって正らぬ事をひそかに行い、見張台から堅固な町に至るまで、すべての町々に高き所を建て、</span>
<span className="v" id="v10" data-v="10" data-xref="列王紀上 14:23; ミカ書 5:14; 出エジプト記 34:13"> またすべての高い丘の上、すべての青木の下に石の柱とアシラ像を立て、</span>
<span className="v" id="v11" data-v="11" data-xref="歴代志下 28:25; 列王紀下 21:6; エレミヤ書 44:17"> 主が彼らの前から捕え移された異邦人がしたように、すべての高き所で香をたき、悪事を行って、主を怒らせた。</span>
<span className="v" id="v12" data-v="12" data-xref="申命記 12:4; 出エジプト記 20:3–5; 申命記 4:23–25"> また主が彼らに「あなたがたはこの事をしてはならない」と言われたのに偶像に仕えた。</span>
<span className="v" id="v13" data-v="13" data-xref="エレミヤ書 35:15; サムエル記上 9:9; エレミヤ書 18:11"> 主はすべての預言者、すべての先見者によってイスラエルとユダを戒め、「翻って、あなたがたの悪い道を離れ、わたしがあなたがたの先祖たちに命じ、またわたしのしもべである預言者たちによってあなたがたに伝えたすべての律法のとおりに、わたしの戒めと定めとを守れ」と仰せられたが、</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 31:27; 使徒行伝 7:51; 詩篇 106:24"> 彼らは聞きいれず、彼らの先祖たちがその神、主を信じないで、強情であったように、彼らは強情であった。</span>
<span className="v" id="v15" data-v="15" data-xref="申命記 12:30–31; 申命記 32:21; ローマ人への手紙 1:21–23"> そして彼らは主の定めを捨て、主が彼らの先祖たちと結ばれた契約を破り、また彼らに与えられた警告を軽んじ、かつむなしい偶像に従ってむなしくなり、また周囲の異邦人に従った。これは主が、彼らのようにおこなってはならないと彼らに命じられたものである。</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀上 14:23; 列王紀上 16:31; 列王紀上 14:15"> 彼らはその神、主のすべての戒めを捨て、自分のために二つの子牛の像を鋳て造り、またアシラ像を造り、天の万象を拝み、かつバアルに仕え、</span>
<span className="v" id="v17" data-v="17" data-xref="列王紀下 21:6; 列王紀下 16:3; 申命記 18:10–12"> またそのむすこ、娘を火に焼いてささげ物とし、占いおよびまじないをなし、主の目の前に悪をおこなうことに身をゆだねて、主を怒らせた。</span>
<span className="v" id="v18" data-v="18" data-xref="列王紀上 12:20; 列王紀上 11:13; ホセア書 11:12"> それゆえ、主は大いにイスラエルを怒り、彼らをみ前から除かれたので、ユダの部族のほか残った者はなかった。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="列王紀下 16:3; 列王紀上 14:22–23; エゼキエル書 16:51–52"> ところがユダもまたその神、主の戒めを守らず、イスラエルが定めたならわしに歩んだので、</span>
<span className="v" id="v20" data-v="20" data-xref="列王紀下 15:29; エレミヤ書 6:30; 列王紀下 13:3"> 主はイスラエルの子孫をことごとく捨て、彼らを苦しめ、彼らを略奪者の手にわたして、ついに彼らをみ前から打ちすてられた。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="列王紀上 11:11; 列王紀上 11:31; 列王紀上 14:16"> 主はイスラエルをダビデの家から裂き離されたので、イスラエルはネバテの子ヤラベアムを王としたが、ヤラベアムはイスラエルに、主に従うことをやめさせ、大きな罪を犯させた。</span>
<span className="v" id="v22" data-v="22" data-xref="列王紀下 3:3; 列王紀下 13:6; 列王紀下 13:11"> イスラエルの人々がヤラベアムのおこなったすべての罪をおこない続けて、それを離れなかったので、</span>
<span className="v" id="v23" data-v="23" data-xref="列王紀下 17:6; 列王紀下 17:13; 列王紀下 17:20"> ついに主はそのしもべである預言者たちによって言われたように、イスラエルをみ前から除き去られた。こうしてイスラエルは自分の国からアッスリヤに移されて今日に至っている。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="列王紀下 18:34; 列王紀下 17:30–31; マタイによる福音書 10:5"> かくてアッスリヤの王はバビロン、クタ、アワ、ハマテおよびセパルワイムから人々をつれてきて、これをイスラエルの人々の代りにサマリヤの町々におらせたので、その人々はサマリヤを領有して、その町々に住んだ。</span>
<span className="v" id="v25" data-v="25" data-xref="列王紀下 17:32; 列王紀下 17:34; 列王紀下 17:41"> 彼らがそこに住み始めた時、主を敬うことをしなかったので、主は彼らのうちにししを送り、ししは彼らのうちの数人を殺した。</span>
<span className="v" id="v26" data-v="26" data-xref="列王紀下 17:27; サムエル記上 8:9; アモス書 8:14"> そこで人々はアッスリヤの王に告げて言った、「あなたが移してサマリヤの町々におらせられたあの国々の民は、その地の神のおきてを知らないゆえに、その神は彼らのうちにししを送り、ししは彼らを殺した。これは彼らが、その地の神のおきてを知らないためです」。</span>
<span className="v" id="v27" data-v="27" data-xref="士師記 17:13; 列王紀上 12:31; 列王紀上 13:2"> アッスリヤの王は命じて言った、「あなたがたがあそこから移した祭司のひとりをあそこへ連れて行きなさい。彼をあそこへやって住まわせ、その国の神のおきてをその人々に教えさせなさい」。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="列王紀上 12:29–32; イザヤ書 29:13; マタイによる福音書 15:14"> そこでサマリヤから移された祭司のひとりが来てベテルに住み、どのように主を敬うべきかを彼らに教えた。</span>
<span className="v" id="v29" data-v="29" data-xref="列王紀上 12:31; ミカ書 4:5; 列王紀上 13:32"> しかしその民はおのおの自分の神々を造って、それをサマリヤびとが造った高き所の家に安置した。民は皆住んでいる町々でそのようにおこなった。</span>
<span className="v" id="v30" data-v="30" data-xref="列王紀下 17:24"> すなわちバビロンの人々はスコテ・ベノテを造り、クタの人々はネルガルを造り、ハマテの人々はアシマを造り、</span>
<span className="v" id="v31" data-v="31" data-xref="列王紀下 17:24; 列王紀下 17:17; 列王紀下 19:37"> アワの人々はニブハズとタルタクを造り、セパルワイムびとはその子を火に焼いて、セパルワイムの神アデランメレクおよびアナンメレクにささげた。</span>
<span className="v" id="v32" data-v="32" data-xref="列王紀上 12:31; 列王紀下 17:29; 列王紀上 13:33"> 彼はまた主を敬い、自分たちのうちから一般の民を立てて高き所の祭司としたので、その人々は高き所の家で勤めをした。</span>
<span className="v" id="v33" data-v="33" data-xref="列王紀下 17:41; ルカによる福音書 16:13; マタイによる福音書 6:24"> このように彼らは主を敬ったが、また彼らが出てきた国々のならわしにしたがって、自分たちの神々にも仕えた。</span>
<span className="v" id="v34" data-v="34" data-xref="創世記 32:28; 創世記 35:10; 列王紀下 17:27–28"> 今日に至るまで彼らは先のならわしにしたがっておこなっている。<br />彼らは主を敬わず、また主がイスラエルと名づけられたヤコブの子孫に命じられた定めにも、おきてにも、律法にも、戒めにも従わない。</span>
<span className="v" id="v35" data-v="35" data-xref="士師記 6:10; ヨシュア記 23:16; ヨシュア記 23:7"> 主はかつて彼らと契約を結び、彼らに命じて言われた、「あなたがたは他の神々を敬ってはならない。また彼らを拝み、彼らに仕え、彼らに犠牲をささげてはならない。</span>
<span className="v" id="v36" data-v="36" data-xref="出エジプト記 6:6; 申命記 6:13; レビ記 19:32"> ただ大きな力と伸べた腕とをもって、あなたがたをエジプトの地から導き上った主をのみ敬い、これを拝み、これに犠牲をささげなければならない。</span>
<span className="v" id="v37" data-v="37" data-xref="レビ記 19:37; 申命記 5:31–2; 申命記 4:44–45"> またあなたがたのために書きしるされた定めと、おきてと、律法と、戒めとを、慎んで常に守らなければならない。他の神々を敬ってはならない。</span>
<span className="v" id="v38" data-v="38" data-xref="申命記 4:23; 申命記 6:12; 申命記 8:14–18"> わたしがあなたがたと結んだ契約を忘れてはならない。また他の神々を敬ってはならない。</span>
<span className="v" id="v39" data-v="39" data-xref="ルカによる福音書 1:74–75; サムエル記上 12:24; マタイによる福音書 10:28"> ただあなたがたの神、主を敬わなければならない。主はあなたがたをそのすべての敵の手から救い出されるであろう」。</span>
<span className="v" id="v40" data-v="40" data-xref="申命記 4:28; 列王紀下 17:8; エレミヤ書 13:23"> しかし彼らは聞きいれず、かえって先のならわしにしたがっておこなった。</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="マタイによる福音書 6:24; ゼパニヤ書 1:5; 列王紀上 18:21"> このように、これらの民は主を敬い、またその刻んだ像にも仕えたが、その子たちも、孫たちも同様であって、彼らはその先祖がおこなったように今日までおこなっている。</span>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀下 11:21; 列王紀下 8:26; 列王紀下 11:4"> ユダの王アハジヤの子ヨアシの第二十三年にエヒウの子エホアハズはサマリヤでイスラエルの王となり、十七年世を治めた。</span>
<span className="v" id="v2" data-v="2" data-xref="列王紀上 12:26–33; 列王紀上 14:16; 列王紀下 10:29"> 彼は主の目の前に悪を行い、イスラエルに罪を犯させたネバテの子ヤラベアムの罪を行いつづけて、それを離れなかった。</span>
<span className="v" id="v3" data-v="3" data-xref="列王紀上 19:17; 列王紀下 13:24–25; 士師記 2:14"> そこで主はイスラエルに対して怒りを発し、エホアハズの治世の間、絶えずイスラエルをスリヤの王ハザエルの手にわたし、またハザエルの子ベネハダデの手にわたされた。</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀下 14:26; 出エジプト記 3:7; 詩篇 78:34"> しかしエホアハズが主に願い求めたので、主はついにこれを聞きいれられた。スリヤの王によって悩まされたイスラエルの悩みを見られたからである。</span>
<span className="v" id="v5" data-v="5" data-xref="ネヘミヤ書 9:27; 列王紀下 14:25; 列王紀下 14:27"> それで主がひとりの救助者をイスラエルに賜わったので、イスラエルの人々はスリヤびとの手をのがれ、前のように自分たちの天幕に住むようになった。</span>
<span className="v" id="v6" data-v="6" data-xref="列王紀上 16:33; 列王紀下 13:2; 申命記 7:5"> それにもかかわらず、彼らはイスラエルに罪を犯させたヤラベアムの家の罪を離れず、それを行いつづけた。またアシラの像もサマリヤに立ったままであった。</span>
<span className="v" id="v7" data-v="7" data-xref="アモス書 1:3; 列王紀下 10:32; 列王紀上 20:15"> さきにスリヤの王が彼らを滅ぼし、踏み砕くちりのようにしたのでエホアハズの軍勢で残ったものは、ただ騎兵五十人、戦車十両、歩兵一万人のみであった。</span>
<span className="v" id="v8" data-v="8" data-xref="列王紀上 11:4; 列王紀上 14:29; 列王紀上 14:31"> エホアハズその他の事績と、彼がしたすべての事およびその武勇は、イスラエルの王の歴代志の書にしるされているではないか。</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀下 10:35; 列王紀下 13:13; 列王紀下 14:8"> エホアハズは先祖たちと共に眠ったので、彼をサマリヤに葬った。その子ヨアシが代って王となった。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10"> ユダの王ヨアシの第三十七年に、エホアハズの子ヨアシはサマリヤでイスラエルの王となり、十六年世を治めた。</span>
<span className="v" id="v11" data-v="11" data-xref="列王紀下 13:2; 列王紀下 10:29; 列王紀下 3:3"> 彼は主の目の前に悪を行い、イスラエルに罪を犯させたネバテの子ヤラベアムのもろもろの罪を離れず、それに歩んだ。</span>
<span className="v" id="v12" data-v="12" data-xref="列王紀下 13:14–25; 列王紀下 14:8–16; 歴代志下 25:17–24"> ヨアシのその他の事績と、彼がしたすべての事およびユダの王アマジヤと戦ったその武勇は、イスラエルの王の歴代志の書にしるされているではないか。</span>
<span className="v" id="v13" data-v="13" data-xref="列王紀上 1:21; 列王紀下 14:28–29; 列王紀上 2:10"> ヨアシは先祖たちと共に眠って、ヤラベアムがその位に座した。そしてヨアシはイスラエルの王たちと同じくサマリヤに葬られた。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="列王紀下 2:12; ピリピ人への手紙 2:26; 創世記 48:1"> さてエリシャは死ぬ病気にかかっていたが、イスラエルの王ヨアシは下ってきて彼の顔の上に涙を流し、「わが父よ、わが父よ、イスラエルの戦車よ、その騎兵よ」と言った。</span>
<span className="v" id="v15" data-v="15"> エリシャは彼に「弓と矢を取りなさい」と言ったので、弓と矢を取った。</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀下 4:34; 創世記 49:24; 詩篇 144:1"> エリシャはまたイスラエルの王に「弓に手をかけなさい」と言ったので、手をかけた。するとエリシャは自分の手を王の手の上におき、</span>
<span className="v" id="v17" data-v="17" data-xref="列王紀上 20:26; 列王紀下 5:10–14; コリント人への第一の手紙 1:18"> 「東向きの窓をあけなさい」と言ったので、それをあけると、エリシャはまた「射なさい」と言った。彼が射ると、エリシャは言った、「主の救の矢、スリヤに対する救の矢。あなたはアペクでスリヤびとを撃ち破り、彼らを滅ぼしつくすであろう」。</span>
<span className="v" id="v18" data-v="18" data-xref="列王紀下 4:6; 出エジプト記 17:11; イザヤ書 20:2–4"> エリシャはまた「矢を取りなさい」と言ったので、それを取った。エリシャはまたイスラエルの王に「それをもって地を射なさい」と言ったので、三度射てやめた。</span>
<span className="v" id="v19" data-v="19" data-xref="列王紀下 13:25; 民数記 16:15; 列王紀下 4:40"> すると神の人は怒って言った、「あなたは五度も六度も射るべきであった。そうしたならば、あなたはスリヤを撃ち破り、それを滅ぼしつくすことができたであろう。しかし今あなたはそうしなかったので、スリヤを撃ち破ることはただ三度だけであろう」。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="列王紀下 24:2; 列王紀下 3:7; 列王紀下 6:23"> こうしてエリシャは死んで葬られた。さてモアブの略奪隊は年が改まるごとに、国にはいって来るのを常とした。</span>
<span className="v" id="v21" data-v="21" data-xref="エゼキエル書 37:1–10; 使徒行伝 19:12; ヨハネによる福音書 5:28–29"> 時に、ひとりの人を葬ろうとする者があったが、略奪隊を見たので、その人をエリシャの墓に投げ入れて去った。その人はエリシャの骨に触れるとすぐ生きかえって立ちあがった。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="列王紀下 8:12; 列王紀下 13:3–7; 詩篇 106:40–42"> スリヤの王ハザエルはエホアハズの一生の間、イスラエルを悩ましたが、</span>
<span className="v" id="v23" data-v="23" data-xref="詩篇 105:8; 列王紀下 14:27; ミカ書 7:18–20"> 主はアブラハム、イサク、ヤコブと結ばれた契約のゆえにイスラエルを恵み、これをあわれみ、これを顧みて滅ぼすことを好まず、なおこれをみ前から捨てられなかった。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="詩篇 125:3; ルカによる福音書 18:7"> スリヤの王ハザエルはついに死んで、その子ベネハダデが代って王となった。</span>
<span className="v" id="v25" data-v="25" data-xref="列王紀下 13:18–19; 列王紀下 10:32; 列王紀下 14:25"> そこでエホアハズの子ヨアシは、父エホアハズがハザエルに攻め取られた町々を、ハザエルの子ベネハダデの手から取り返した。すなわちヨアシは三度彼を撃ち破って、イスラエルの町々を取り返した。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マタイによる福音書 18:25; 列王紀下 2:3; ネヘミヤ書 5:2–5"> 預言者のともがらの、ひとりの妻がエリシャに呼ばわって言った、「あなたのしもべであるわたしの夫が死にました。ごぞんじのように、あなたのしもべは主を恐れる者でありましたが、今、債主がきて、わたしのふたりの子供を取って奴隷にしようとしているのです」。</span>
<span className="v" id="v2" data-v="2" data-xref="列王紀上 17:12; ヤコブの手紙 2:5; 列王紀下 6:26–27"> エリシャは彼女に言った、「あなたのために何をしましょうか。あなたの家にどんな物があるか、言いなさい」。彼女は言った、「一びんの油のほかは、はしための家に何もありません」。</span>
<span className="v" id="v3" data-v="3" data-xref="ヨハネによる福音書 2:7; 詩篇 81:10; ヨハネによる福音書 16:24"> 彼は言った、「ほかへ行って、隣の人々から器を借りなさい。あいた器を借りなさい。少しばかりではいけません。</span>
<span className="v" id="v4" data-v="4" data-xref="マルコによる福音書 8:5–9; マタイによる福音書 6:6; エペソ人への手紙 3:20"> そして内にはいって、あなたの子供たちと一緒に戸の内に閉じこもり、そのすべての器に油をついで、いっぱいになったとき、一つずつそれを取りのけておきなさい」。</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀下 5:11; ヘブル人への手紙 11:7–8; 列王紀上 17:15–16"> 彼女は彼を離れて去り、子供たちと一緒に戸の内に閉じこもり、子供たちの持って来る器に油をついだ。</span>
<span className="v" id="v6" data-v="6" data-xref="マタイによる福音書 14:20; 列王紀下 13:19; ルカによる福音書 6:19"> 油が満ちたとき、彼女は子供に「もっと器を持ってきなさい」と言ったが、子供が「器はもうありません」と言ったので、油はとまった。</span>
<span className="v" id="v7" data-v="7" data-xref="テサロニケ人への第二の手紙 3:7–12; 列王紀上 12:22; ローマ人への手紙 12:17"> そこで彼女は神の人のところにきて告げたので、彼は言った、「行って、その油を売って負債を払いなさい。あなたと、あなたの子供たちはその残りで暮すことができます」。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="ヨシュア記 19:18; 創世記 19:3; 列王紀下 4:11–12"> ある日エリシャはシュネムへ行ったが、そこにひとりの裕福な婦人がいて、しきりに彼に食事をすすめたので、彼はそこを通るごとに、そこに寄って食事をした。</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀上 17:24; 箴言 31:10–11; 列王紀下 4:7"> その女は夫に言った、「いつもわたしたちの所を通るあの人は確かに神の聖なる人です。</span>
<span className="v" id="v10" data-v="10" data-xref="ローマ人への手紙 12:13; マタイによる福音書 10:41–42; マタイによる福音書 25:40"> わたしたちは屋上に壁のある一つの小さいへやを造り、そこに寝台と机といすと燭台とを彼のために備えましょう。そうすれば彼がわたしたちの所に来るとき、そこに、はいることができます」。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11"> さて、ある日エリシャはそこにきて、そのへやにはいり、そこに休んだが、</span>
<span className="v" id="v12" data-v="12" data-xref="列王紀下 8:4–5; 列王紀下 3:11; 列王紀下 4:29–31"> 彼はそのしもべゲハジに「このシュネムの女を呼んできなさい」と言った。彼がその女を呼ぶと、彼女はきてエリシャの前に立ったので、</span>
<span className="v" id="v13" data-v="13" data-xref="テモテヘの第二の手紙 1:16–18; ピリピ人への手紙 4:18–19; ヘブル人への手紙 6:10"> エリシャはゲハジに言った、「彼女に言いなさい、『あなたはこんなにねんごろに、わたしたちのために心を用いられたが、あなたのためには何をしたらよいでしょうか。王または軍勢の長にあなたの事をよろしく頼むことをお望みですか』」。彼女は答えて言った、「わたしは自分の民のうちに住んでいます」。</span>
<span className="v" id="v14" data-v="14" data-xref="ルカによる福音書 1:7; 創世記 15:2–3; サムエル記上 1:8"> エリシャは言った、「それでは彼女のために何をしようか」。ゲハジは言った、「彼女には子供がなく、その夫は老いています」。</span>
<span className="v" id="v15" data-v="15"> するとエリシャが「彼女を呼びなさい」と言ったので、彼女を呼ぶと、来て戸口に立った。</span>
<span className="v" id="v16" data-v="16" data-xref="創世記 18:10; ルカによる福音書 1:13; 列王紀下 4:28"> エリシャは言った、「来年の今ごろ、あなたはひとりの子を抱くでしょう」。彼女は言った、「いいえ、わが主よ、神の人よ、はしためを欺かないでください」。</span>
<span className="v" id="v17" data-v="17" data-xref="詩篇 113:9; ルカによる福音書 1:36; 創世記 21:1"> しかし女はついに身ごもって、エリシャが彼女に言ったように、次の年のそのころに子を産んだ。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="ルツ記 2:4"> その子が成長して、ある日、刈入れびとの所へ出ていって、父のもとへ行ったが、</span>
<span className="v" id="v19" data-v="19" data-xref="ヨブ記 14:1–2; エレミヤ書 4:19"> 父にむかって「頭が、頭が」と言ったので、父はしもべに「彼を母のもとへ背負っていきなさい」と言った。</span>
<span className="v" id="v20" data-v="20" data-xref="ルカによる福音書 7:12; ヨハネによる福音書 11:3; ヨハネによる福音書 11:14"> 彼を背負って母のもとへ行くと、昼まで母のひざの上にすわっていたが、ついに死んだ。</span>
<span className="v" id="v21" data-v="21" data-xref="列王紀下 4:32; 列王紀下 4:10; 列王紀下 4:7"> 母は上がっていって、これを神の人の寝台の上に置き、戸を閉じて出てきた。</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行伝 9:38; 列王紀下 4:26; ヨハネによる福音書 11:3"> そして夫を呼んで言った、「どうぞ、しもべひとりと、ろば一頭をわたしにかしてください。急いで神の人の所へ行って、また帰ってきます」。</span>
<span className="v" id="v23" data-v="23" data-xref="民数記 10:10; 民数記 28:11; 歴代志上 23:31"> 夫は言った、「どうしてきょう彼の所へ行こうとするのか。きょうは、ついたちでもなく、安息日でもない」。彼女は言った、「よろしいのです」。</span>
<span className="v" id="v24" data-v="24" data-xref="出エジプト記 4:20; 列王紀上 13:13; サムエル記上 25:19–20"> そして彼女はろばにくらを置いて、しもべに言った、「速く駆けさせなさい。わたしが命じる時でなければ、歩調をゆるめてはなりません」。</span>
<span className="v" id="v25" data-v="25" data-xref="列王紀下 2:25; イザヤ書 35:2; 列王紀上 18:19"> こうして彼女は出発してカルメル山へ行き、神の人の所へ行った。<br />神の人は彼女の近づいてくるのを見て、しもべゲハジに言った、「向こうから、あのシュネムの女が来る。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行伝 15:36; 列王紀下 4:23; サムエル記上 17:18"> すぐ走って行って、彼女を迎えて言いなさい、『あなたは無事ですか。あなたの夫は無事ですか。あなたの子供は無事ですか』」。彼女は答えた、「無事です」。</span>
<span className="v" id="v27" data-v="27" data-xref="サムエル記下 7:3; 創世記 18:17; アモス書 3:7"> ところが彼女は山にきて、神の人の所へくるとエリシャの足にすがりついた。ゲハジが彼女を追いのけようと近よった時、神の人は言った、「かまわずにおきなさい。彼女は心に苦しみがあるのだから。主はそれを隠して、まだわたしにお告げにならないのだ」。</span>
<span className="v" id="v28" data-v="28" data-xref="創世記 30:1; 列王紀下 4:16"> そこで彼女は言った、「わたしがあなたに子を求めましたか。わたしを欺かないでくださいと言ったではありませんか」。</span>
<span className="v" id="v29" data-v="29" data-xref="列王紀下 2:14; 列王紀上 18:46; 出エジプト記 14:16"> エリシャはゲハジに言った、「腰をひきからげ、わたしのつえを手に持って行きなさい。だれに会っても、あいさつしてはならない。またあなたにあいさつする者があっても、それに答えてはならない。わたしのつえを子供の顔の上に置きなさい」。</span>
<span className="v" id="v30" data-v="30" data-xref="ルツ記 1:16–18; 列王紀下 2:2; 出エジプト記 33:12–16"> 子供の母は言った、「主は生きておられます。あなたも生きておられます。わたしはあなたを離れません」。そこでエリシャはついに立ちあがって彼女のあとについて行った。</span>
<span className="v" id="v31" data-v="31" data-xref="ヨハネによる福音書 11:11; マルコによる福音書 5:39; マルコによる福音書 9:19–29"> ゲハジは彼らの先に行って、つえを子供の顔の上に置いたが、なんの声もなく、生きかえったしるしもなかったので、帰ってきてエリシャに会い、彼に告げて「子供はまだ目をさましません」と言った。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="ルカによる福音書 8:52–53; ヨハネによる福音書 11:17; 列王紀上 17:17"> エリシャが家にはいって見ると、子供は死んで、寝台の上に横たわっていたので、</span>
<span className="v" id="v33" data-v="33" data-xref="マタイによる福音書 6:6; 列王紀下 4:4; 使徒行伝 9:40"> 彼ははいって戸を閉じ、彼らふたりだけ内にいて主に祈った。</span>
<span className="v" id="v34" data-v="34" data-xref="列王紀上 17:21; 使徒行伝 20:10"> そしてエリシャが上がって子供の上に伏し、自分の口を子供の口の上に、自分の目を子供の目の上に、自分の両手を子供の両手の上にあて、その身を子供の上に伸ばしたとき、子供のからだは暖かになった。</span>
<span className="v" id="v35" data-v="35" data-xref="列王紀下 8:5; 列王紀下 13:21; 列王紀上 17:22"> こうしてエリシャは再び起きあがって、家の中をあちらこちらと歩み、また上がって、その身を子供の上に伸ばすと、子供は七たびくしゃみをして目を開いた。</span>
<span className="v" id="v36" data-v="36" data-xref="ヘブル人への手紙 11:35; 列王紀上 17:23; ルカによる福音書 7:15"> エリシャはただちにゲハジを呼んで、「あのシュネムの女を呼べ」と言ったので、彼女を呼んだ。彼女がはいってくるとエリシャは言った、「あなたの子供をつれて行きなさい」。</span>
<span className="v" id="v37" data-v="37" data-xref="ヘブル人への手紙 11:35; 列王紀下 2:15; 列王紀上 17:24"> 彼女ははいってきて、エリシャの足もとに伏し、地に身をかがめた。そしてその子供を取りあげて出ていった。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="列王紀下 8:1; 列王紀下 2:3; 列王紀下 2:1"> エリシャはギルガルに帰ったが、その地にききんがあった。預言者のともがらが彼の前に座していたので、エリシャはそのしもべに言った、「大きなかまをすえて、預言者のともがらのために野菜の煮物をつくりなさい」。</span>
<span className="v" id="v39" data-v="39" data-xref="エレミヤ書 2:21; イザヤ書 5:4; マタイによる福音書 15:13"> 彼らのうちのひとりが畑に出ていって青物をつんだが、つる草のあるのを見て、その野うりを一包つんできて、煮物のかまの中に切り込んだ。彼らはそれが何であるかを知らなかったからである。</span>
<span className="v" id="v40" data-v="40" data-xref="マルコによる福音書 16:18; 出エジプト記 15:23; 出エジプト記 10:17"> やがてこれを盛って人々に食べさせようとしたが、彼らがその煮物を食べようとした時、叫んで、「ああ神の人よ、かまの中に、たべると死ぬものがはいっています」と言って、食べることができなかったので、</span>
<span className="v" id="v41" data-v="41" data-xref="列王紀下 2:21; 出エジプト記 15:25; コリント人への第一の手紙 1:25"> エリシャは「それでは粉を持って来なさい」と言って、それをかまに投げ入れ、「盛って人々に食べさせなさい」と言った。かまの中には、なんの毒物もなくなった。</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="サムエル記上 9:7; ヨハネによる福音書 6:9; マタイによる福音書 14:16–21"> その時、バアル・シャリシャから人がきて、初穂のパンと、大麦のパン二十個と、新穀一袋とを神の人のもとに持ってきたので、エリシャは「人々に与えて食べさせなさい」と言ったが、</span>
<span className="v" id="v43" data-v="43" data-xref="ルカによる福音書 9:13; マタイによる福音書 14:20; ヨハネによる福音書 6:9"> その召使は言った、「どうしてこれを百人の前に供えるのですか」。しかし彼は言った、「人々に与えて食べさせなさい。主はこう言われる、『彼らは食べてなお余すであろう』」。</span>
<span className="v" id="v44" data-v="44"> そこで彼はそれを彼らの前に供えたので、彼らは食べてなお余した。主の言葉のとおりであった。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 5:24; ヘブル人への手紙 11:5; 列王紀上 19:16–21"> 主がつむじ風をもってエリヤを天に上らせようとされた時、エリヤはエリシャと共にギルガルを出て行った。</span>
<span className="v" id="v2" data-v="2" data-xref="列王紀下 2:6; ルツ記 1:15–18; 列王紀下 4:30"> エリヤはエリシャに言った、「どうぞ、ここにとどまってください。主はわたしをベテルにつかわされるのですから」。しかしエリシャは言った、「主は生きておられます。またあなたも生きておられます。わたしはあなたを離れません」。そして彼らはベテルへ下った。</span>
<span className="v" id="v3" data-v="3" data-xref="列王紀下 4:1; 列王紀下 4:38; 列王紀下 9:1"> ベテルにいる預言者のともがらが、エリシャのもとに出てきて彼に言った、「主がきょう、あなたの師事する主人をあなたから取られるのを知っていますか」。彼は言った、「はい、知っています。あなたがたは黙っていてください」。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="列王紀下 2:2; ヨシュア記 6:26; 列王紀上 16:34"> エリヤは彼に言った、「エリシャよ、どうぞ、ここにとどまってください。主はわたしをエリコにつかわされるのですから」。しかしエリシャは言った、「主は生きておられます。またあなたも生きておられます。わたしはあなたを離れません」。そして彼らはエリコへ行った。</span>
<span className="v" id="v5" data-v="5" data-xref="列王紀下 2:3; ヨシュア記 1:1–2; 使徒行伝 1:11"> エリコにいた預言者のともがらが、エリシャのもとにきて彼に言った、「主がきょう、あなたの師事する主人をあなたから取られるのを知っていますか」。彼は言った、「はい、知っています。あなたがたは黙っていてください」。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="列王紀下 2:2; ヨシュア記 3:15"> エリヤはまた彼に言った、「どうぞ、ここにとどまってください。主はわたしをヨルダンにつかわされるのですから」。しかし彼は言った、「主は生きておられます。またあなたも生きておられます。わたしはあなたを離れません」。そしてふたりは進んで行った。</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀上 18:13; 列王紀下 2:17; 列王紀上 18:4"> 預言者のともがら五十人も行って、彼らにむかって、はるかに離れて立っていた。彼らふたりは、ヨルダンのほとりに立ったが、</span>
<span className="v" id="v8" data-v="8" data-xref="列王紀上 19:19; 出エジプト記 14:21–22; ヨシュア記 3:14–17"> エリヤは外套を取り、それを巻いて水を打つと、水が左右に分れたので、ふたりはかわいた土の上を渡ることができた。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="民数記 11:17; 申命記 21:17; ヨハネによる福音書 16:7"> 彼らが渡ったとき、エリヤはエリシャに言った、「わたしが取られて、あなたを離れる前に、あなたのしてほしい事を求めなさい」。エリシャは言った、「どうぞ、あなたの霊の二つの分をわたしに継がせてください」。</span>
<span className="v" id="v10" data-v="10" data-xref="マルコによる福音書 11:22–24; 列王紀下 2:12; ヨハネによる福音書 16:24"> エリヤは言った、「あなたはむずかしい事を求める。あなたがもし、わたしが取られて、あなたを離れるのを見るならば、そのようになるであろう。しかし見ないならば、そのようにはならない」。</span>
<span className="v" id="v11" data-v="11" data-xref="列王紀下 6:17; 詩篇 104:3–4; ヘブル人への手紙 1:14"> 彼らが進みながら語っていた時、火の車と火の馬があらわれて、ふたりを隔てた。そしてエリヤはつむじ風に乗って天にのぼった。</span>
<span className="v" id="v12" data-v="12" data-xref="列王紀下 13:14; イザヤ書 37:21; マルコによる福音書 16:19"> エリシャはこれを見て「わが父よ、わが父よ、イスラエルの戦車よ、その騎兵よ」と叫んだが、再び彼を見なかった。<br />そこでエリシャは自分の着物をつかんで、それを二つに裂き、</span>
<span className="v" id="v13" data-v="13" data-xref="列王紀上 19:19; 列王紀下 2:8; 列王紀上 9:26"> またエリヤの身から落ちた外套を取り上げ、帰ってきてヨルダンの岸に立った。</span>
<span className="v" id="v14" data-v="14" data-xref="ヨハネによる福音書 14:12; 詩篇 42:10; 詩篇 115:2"> そしてエリヤの身から落ちたその外套を取って水を打ち、「エリヤの神、主はどこにおられますか」と言い、彼が水を打つと、水は左右に分れたので、エリシャは渡った。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="ペテロの第一の手紙 4:14; 使徒行伝 1:8; ヨシュア記 3:7"> エリコにいる預言者のともがらは彼の近づいて来るのを見て、「エリヤの霊がエリシャの上にとどまっている」と言った。そして彼らは来て彼を迎え、その前に地に伏して、</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀上 18:12; 使徒行伝 8:39; コリント人への第二の手紙 12:2–3"> 彼に言った、「しもべらの所に力の強い者が五十人います。どうぞ彼らをつかわして、あなたの主人を尋ねさせてください。主の霊が彼を引きあげて、彼を山か谷に投げたのかも知れません」。エリシャは「つかわしてはならない」と言ったが、</span>
<span className="v" id="v17" data-v="17" data-xref="列王紀下 8:11; ヘブル人への手紙 11:5; ローマ人への手紙 10:2"> 彼の恥じるまで、しいたので、彼は「つかわしなさい」と言った。それで彼らは五十人の者をつかわし、三日の間尋ねたが、彼を見いださなかった。</span>
<span className="v" id="v18" data-v="18"> エリシャのなおエリコにとどまっている時、彼らが帰ってきたので、エリシャは彼らに言った、「わたしは、あなたがたに、行ってはならないと告げたではないか」。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="出エジプト記 23:26; 申命記 28:2–4; 申命記 28:11"> 町の人々はエリシャに言った、「見られるとおり、この町の場所は良いが水が悪いので、この地は流産を起すのです」。</span>
<span className="v" id="v20" data-v="20" data-xref="士師記 9:45; ゼパニヤ書 2:9; エゼキエル書 47:11"> エリシャは言った、「新しい皿に塩を盛って、わたしに持ってきなさい」。彼らは持ってきた。</span>
<span className="v" id="v21" data-v="21" data-xref="出エジプト記 15:25–26; 列王紀下 4:41; レビ記 2:13"> エリシャは水の源へ出て行って、塩をそこに投げ入れて言った、「主はこう仰せられる、『わたしはこの水を良い水にした。もはやここには死も流産も起らないであろう』」。</span>
<span className="v" id="v22" data-v="22"> こうしてその水はエリシャの言ったとおりに良い水になって今日に至っている。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="歴代志下 36:16; ヨブ記 19:18; ヨブ記 30:1"> 彼はそこからベテルへ上ったが、上って行く途中、小さい子供らが町から出てきて彼をあざけり、彼にむかって「はげ頭よ、のぼれ。はげ頭よ、のぼれ」と言ったので、</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行伝 13:9–11; 使徒行伝 5:5; ホセア書 13:8"> 彼はふり返って彼らを見、主の名をもって彼らをのろった。すると林の中から二頭の雌ぐまが出てきて、その子供らのうち四十二人を裂いた。</span>
<span className="v" id="v25" data-v="25" data-xref="列王紀下 4:25; 列王紀上 18:19–20; 列王紀上 18:42"> 彼はそこからカルメル山へ行き、そこからサマリヤに帰った。</span>
</div>

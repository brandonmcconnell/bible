<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歴代志上 3:11; 列王紀下 11:21; 列王紀下 11:1–4"> ヨアシはエヒウの第七年に位につき、エルサレムで四十年の間、世を治めた。その母はベエルシバの出身で、名をヂビアといった。</span>
<span className="v" id="v2" data-v="2" data-xref="歴代志下 24:17–22; 歴代志下 26:4; 歴代志下 25:2"> ヨアシは一生の間、主の目にかなう事をおこなった。祭司エホヤダが彼を教えたからである。</span>
<span className="v" id="v3" data-v="3" data-xref="列王紀下 14:4; 列王紀上 22:43; 列王紀上 15:14"> しかし高き所は除かなかったので、民はなおその高き所で犠牲をささげ、香をたいた。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="列王紀下 22:4; 出エジプト記 35:5; 歴代志上 29:3–9"> ヨアシは祭司たちに言った、「すべて主の宮に聖別してささげる銀、すなわちおのおのが課せられて、割当にしたがって人々の出す銀、および人々が心から願って主の宮の持ってくる銀は、</span>
<span className="v" id="v5" data-v="5" data-xref="イザヤ書 58:12; 列王紀上 11:27; 列王紀下 22:5–6"> これを祭司たちがおのおのその知る人から受け取り、どこでも主の宮に破れの見える時は、それをもってその破れを繕わなければならない」。</span>
<span className="v" id="v6" data-v="6" data-xref="歴代志下 29:34; ペテロの第一の手紙 5:2; イザヤ書 56:10–12"> ところがヨアシ王の二十三年に至るまで、祭司たちは主の宮の破れを繕わなかった。</span>
<span className="v" id="v7" data-v="7" data-xref="歴代志下 24:16; 歴代志下 24:5–14; 列王紀下 11:4"> それで、ヨアシ王は祭司エホヤダおよび他の祭司たちを召して言った、「なぜ、あなたがたは主の宮の破れを繕わないのか。あなたがたはもはや知人から銀を受けてはならない。主の宮の破れを繕うためにそれを渡しなさい」。</span>
<span className="v" id="v8" data-v="8"> 祭司たちは重ねて民から銀を受けない事と、主の宮の破れを繕わない事とに同意した。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="マルコによる福音書 12:41; 詩篇 84:10; エレミヤ書 35:4"> そこで祭司エホヤダは一つの箱を取り、そのふたに穴をあけて、それを主の宮の入口の右側、祭壇のかたわらに置いた。そして門を守る祭司たちは主の宮にはいってくる銀をことごとくその中に入れた。</span>
<span className="v" id="v10" data-v="10" data-xref="サムエル記下 8:17; 列王紀下 22:12; 列王紀下 19:2"> こうしてその箱の中に銀が多くなったのを見ると、王の書記官と大祭司が上ってきて、主の宮にある銀を数えて袋に詰めた。</span>
<span className="v" id="v11" data-v="11" data-xref="列王紀下 22:5–6; 歴代志下 24:11–12; 歴代志下 34:9–11"> そしてその数えた銀を、工事をつかさどる主の宮の監督者の手にわたしたので、彼らはそれを主の宮に働く木工と建築師に払い、</span>
<span className="v" id="v12" data-v="12" data-xref="列王紀下 22:5–6; 列王紀上 5:17–18; エズラ記 3:7"> 石工および石切りに払い、またそれをもって主の宮の破れを繕う材木と切り石を買い、主の宮を繕うために用いるすべての物のために費した。</span>
<span className="v" id="v13" data-v="13" data-xref="歴代志下 24:14; 列王紀上 7:48–50; エズラ記 1:9–11"> ただし、主の宮にはいってくるその銀をもって主の宮のために銀のたらい、心切りばさみ、鉢、ラッパ、金の器、銀の器などを造ることはしなかった。</span>
<span className="v" id="v14" data-v="14"> ただこれを工事をする者に渡して、それで主の宮を繕わせた。</span>
<span className="v" id="v15" data-v="15" data-xref="列王紀下 22:7; ヨハネの第三の手紙 1:5; コリント人への第一の手紙 4:2–3"> またその銀を渡して工事をする者に払わせた人々と計算することはしなかった。彼らは正直に事をおこなったからである。</span>
<span className="v" id="v16" data-v="16" data-xref="レビ記 7:7; レビ記 5:15–18; レビ記 4:24"> 愆祭の銀と罪祭の銀は主の宮に、はいらないで、祭司に帰した。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="歴代志下 24:23–24; ルカによる福音書 9:53; エレミヤ書 42:15"> そのころ、スリヤの王ハザエルが上ってきて、ガテを攻めてこれを取った。そしてハザエルがエルサレムに攻め上ろうとして、その顔を向けたとき、</span>
<span className="v" id="v18" data-v="18" data-xref="列王紀上 15:18; 列王紀下 18:15–16; 列王紀下 12:4"> ユダの王ヨアシはその先祖、ユダの王ヨシャパテ、ヨラム、アハジヤが聖別してささげたすべての物、およびヨアシ自身が聖別してささげた物、ならびに主の宮の倉と、主の宮にある金をことごとく取って、スリヤ王のハザエルに贈ったので、ハザエルはエルサレムを離れ去った。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="列王紀上 14:29; 列王紀上 14:19; 列王紀上 11:41"> ヨアシのその他の事績および彼がしたすべての事は、ユダの王の歴代志の書にしるされているではないか。</span>
<span className="v" id="v20" data-v="20" data-xref="歴代志下 24:24–27; 列王紀下 14:5; サムエル記下 5:9"> ヨアシの家来たちは立って徒党を結び、シラに下る道にあるミロの家でヨアシを殺した。</span>
<span className="v" id="v21" data-v="21" data-xref="列王紀下 14:1; 歴代志下 24:26–27"> すなわちその家来シメアテの子ヨザカルと、ショメルの子ヨザバデが彼を撃って殺し、彼をその先祖と同じく、ダビデの町に葬った。その子アマジヤが代って王となった。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀下 13:10; 歴代志下 25:1–4; 列王紀下 14:15"> イスラエルの王エホアハズの子ヨアシの第二年に、ユダの王ヨアシの子アマジヤが王となった。</span>
<span className="v" id="v2" data-v="2"> 彼は王となった時二十五歳で、二十九年の間エルサレムで世を治めた。その母はエルサレムの出身で、名をエホアダンといった。</span>
<span className="v" id="v3" data-v="3" data-xref="歴代志下 25:2–3; ゼカリヤ書 1:4–6; 列王紀上 11:4"> アマジヤは主の目にかなう事をおこなったが、先祖ダビデのようではなかった。彼はすべての事を父ヨアシがおこなったようにおこなった。</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀下 12:3; 列王紀下 16:4; 列王紀下 15:35"> ただし高き所は除かなかったので、民はなおその高き所で犠牲をささげ、香をたいた。</span>
<span className="v" id="v5" data-v="5" data-xref="歴代志下 25:3–4; 列王紀下 12:20–21; 民数記 35:33"> 彼は国が彼の手のうちに強くなった時、父ヨアシ王を殺害した家来たちを殺したが、</span>
<span className="v" id="v6" data-v="6" data-xref="申命記 24:16; エゼキエル書 18:20; エゼキエル書 18:4"> その殺害者の子供たちは殺さなかった。これはモーセの律法の書にしるされている所に従ったのであって、そこに主は命じて「父は子のゆえに殺さるべきではない。子は父のゆえに殺さるべきではない。おのおの自分の罪のゆえに殺さるべきである」と言われている。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="サムエル記下 8:13; 歴代志上 18:12; ヨシュア記 15:38"> アマジヤはまた塩の谷でエドムびと一万人を殺した。またセラを攻め取って、その名をヨクテルと名づけたが、今日までそのとおりである。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="歴代志下 25:17–24; サムエル記下 2:14–17; 列王紀下 14:11"> そこでアマジヤがエヒウの子エホアハズの子であるイスラエルの王ヨアシに使者をつかわして、「さあ、われわれは互に顔を合わせよう」と言わせたので、</span>
<span className="v" id="v9" data-v="9" data-xref="士師記 9:8–15; 列王紀上 4:33; 歴代志下 33:11"> イスラエルの王ヨアシはユダの王アマジヤに言い送った、「かつてレバノンのいばらがレバノンの香柏に、『あなたの娘をわたしのむすこの妻にください』と言い送ったことがあったが、レバノンの野獣がとおって、そのいばらを踏み倒した。</span>
<span className="v" id="v10" data-v="10" data-xref="歴代志下 26:16; 申命記 8:14; 歴代志下 32:25"> あなたは大いにエドムを撃って、心にたかぶっているが、その栄誉に満足して家にとどまりなさい。何ゆえ、あなたは災をひき起して、自分もユダも共に滅びるような事をするのですか」。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="ヨシュア記 19:38; 歴代志下 25:16; ヨシュア記 15:10"> しかしアマジヤが聞きいれなかったので、イスラエルの王ヨアシは上ってきた。そこで彼とユダの王アマジヤはユダのベテシメシで互に顔をあわせたが、</span>
<span className="v" id="v12" data-v="12" data-xref="サムエル記下 18:17; サムエル記上 4:10; 列王紀上 22:36"> ユダはイスラエルに敗られて、おのおのその天幕に逃げ帰った。</span>
<span className="v" id="v13" data-v="13" data-xref="ネヘミヤ書 8:16; ネヘミヤ書 12:39; ゼカリヤ書 14:10"> イスラエルの王ヨアシはアハジヤの子ヨアシの子であるユダの王アマジヤをベテシメシで捕え、エルサレムにきて、エルサレムの城壁をエフライムの門から隅の門まで、おおよそ四百キュビトにわたってこわし、</span>
<span className="v" id="v14" data-v="14" data-xref="列王紀上 14:26; 列王紀上 7:51; 列王紀上 15:18"> また主の宮と王の家の倉にある金銀およびもろもろの器をことごとく取り、かつ人質をとってサマリヤに帰った。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="列王紀下 13:12–13; 列王紀上 14:19–20; 列王紀下 10:34–35"> ヨアシのその他の事績と、その武勇および彼がユダの王アマジヤと戦った事は、イスラエルの王の歴代志の書にしるされているではないか。</span>
<span className="v" id="v16" data-v="16" data-xref="列王紀下 13:9; 列王紀下 13:13; 列王紀上 1:21"> ヨアシはその先祖たちと共に眠って、イスラエルの王たちと共にサマリヤに葬られ、その子ヤラベアムが代って王となった。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="歴代志下 25:25–28; 列王紀下 13:10; 列王紀下 14:23"> ヨアシの子であるユダの王アマジヤは、エホアハズの子であるイスラエルの王ヨアシが死んで後、なお十五年生きながらえた。</span>
<span className="v" id="v18" data-v="18" data-xref="列王紀上 11:41; 列王紀上 14:29; 列王紀下 13:8"> アマジヤのその他の事績は、ユダの王の歴代志の書にしるされているではないか。</span>
<span className="v" id="v19" data-v="19" data-xref="ヨシュア記 10:31; 列王紀下 15:25; 列王紀下 12:20–21"> 時に人々がエルサレムで徒党を結び、彼に敵対したので、彼はラキシに逃げていったが、その人々はラキシに人をつかわして彼をそこで殺させた。</span>
<span className="v" id="v20" data-v="20" data-xref="列王紀下 9:28; 列王紀下 12:21; 歴代志下 33:20"> 人々は彼を馬に載せて運んできて、エルサレムで彼を先祖たちと共にダビデの町に葬った。</span>
<span className="v" id="v21" data-v="21" data-xref="列王紀下 21:24; マタイによる福音書 1:8–9; 列王紀下 15:13"> そしてユダの民は皆アザリヤを父アマジヤの代りに王とした。時に年十六歳であった。</span>
<span className="v" id="v22" data-v="22" data-xref="列王紀下 16:6; 列王紀上 9:26; 申命記 2:8"> 彼はエラテの町を建てて、これをユダに復帰させた。これはかの王がその先祖たちと共に眠った後であった。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="ホセア書 1:1; アモス書 7:9–11; アモス書 1:1"> ユダの王ヨアシの子アマジヤの第十五年に、イスラエルの王ヨアシの子ヤラべアムがサマリヤで王となって四十一年の間、世を治めた。</span>
<span className="v" id="v24" data-v="24" data-xref="列王紀下 13:6; 列王紀下 13:11; 創世記 38:7"> 彼は主の目の前に悪を行い、イスラエルに罪を犯させたネバテの子ヤラベアムの罪を離れなかった。</span>
<span className="v" id="v25" data-v="25" data-xref="申命記 3:17; マタイによる福音書 12:39–40; ヨシュア記 19:13"> 彼はハマテの入口からアラバの海まで、イスラエルの領域を回復した。イスラエルの神、主がガテヘペルのアミッタイの子である、そのしもべ預言者ヨナによって言われた言葉のとおりである。</span>
<span className="v" id="v26" data-v="26" data-xref="申命記 32:36; 出エジプト記 3:7; 列王紀下 13:4"> 主はイスラエルの悩みの非常に激しいのを見られた。そこにはつながれた者も、自由な者もいなくなり、またイスラエルを助ける者もいなかった。</span>
<span className="v" id="v27" data-v="27" data-xref="列王紀下 13:23; 列王紀下 13:5; ローマ人への手紙 11:2–12"> しかし主はイスラエルの名を天が下から消し去ろうとは言われなかった。そして彼らをヨアシの子ヤラベアムの手によって救われた。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="列王紀上 11:24; 歴代志上 18:5–6; サムエル記下 8:6"> ヤラベアムのその他の事績と、彼がしたすべての事およびその武勇、すなわち彼が戦争をした事および、かつてユダに属していたダマスコとハマテを、イスラエルに復帰させた事は、イスラエルの王の歴代志の書にしるされているではないか。</span>
<span className="v" id="v29" data-v="29" data-xref="列王紀下 15:8"> ヤラベアムはその先祖であるイスラエルの王たちと共に眠って、その子ゼカリヤが代って王となった。</span>
</div>

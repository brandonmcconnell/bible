<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨハネによる福音書 1:12; ガラテヤ人への手紙 3:26; コリント人への第二の手紙 6:18"> わたしたちが神の子と呼ばれるためには、どんなに大きな愛を父から賜わったことか、よく考えてみなさい。わたしたちは、すでに神の子なのである。世がわたしたちを知らないのは、父を知らなかったからである。</span>
<span className="v" id="v2" data-v="2" data-xref="ピリピ人への手紙 3:21; コロサイ人への手紙 3:4; コリント人への第一の手紙 13:12"> 愛する者たちよ。わたしたちは今や神の子である。しかし、わたしたちがどうなるのか、まだ明らかではない。彼が現れる時、わたしたちは、自分たちが彼に似るものとなることを知っている。そのまことの御姿を見るからである。</span>
<span className="v" id="v3" data-v="3" data-xref="コリント人への第二の手紙 7:1; ヨハネの第一の手紙 2:6; ペテロの第二の手紙 3:14"> 彼についてこの望みをいだいている者は皆、彼がきよくあられるように、自らをきよくする。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネの第一の手紙 5:17; ローマ人への手紙 3:20; ローマ人への手紙 4:15"> すべて罪を犯す者は、不法を行う者である。罪は不法である。</span>
<span className="v" id="v5" data-v="5" data-xref="コリント人への第二の手紙 5:21; ヘブル人への手紙 9:28; ペテロの第一の手紙 3:18"> あなたがたが知っているとおり、彼は罪をとり除くために現れたのであって、彼にはなんらの罪がない。</span>
<span className="v" id="v6" data-v="6" data-xref="ヨハネの第三の手紙 1:11; ヨハネの第一の手紙 2:4; ヨハネの第一の手紙 3:9"> すべて彼におる者は、罪を犯さない。すべて罪を犯す者は彼を見たこともなく、知ったこともない者である。</span>
<span className="v" id="v7" data-v="7" data-xref="ヨハネの第一の手紙 2:29; ペテロの第一の手紙 1:15–16; ローマ人への手紙 2:13"> 子たちよ。だれにも惑わされてはならない。彼が義人であると同様に、義を行う者は義人である。</span>
<span className="v" id="v8" data-v="8" data-xref="ヘブル人への手紙 2:14; ヨハネによる福音書 8:44; コロサイ人への手紙 2:15"> 罪を犯す者は、悪魔から出た者である。悪魔は初めから罪を犯しているからである。神の子が現れたのは、悪魔のわざを滅ぼしてしまうためである。</span>
<span className="v" id="v9" data-v="9" data-xref="ヨハネの第一の手紙 5:18; ペテロの第一の手紙 1:23; ヨハネによる福音書 1:13"> すべて神から生れた者は、罪を犯さない。神の種が、その人のうちにとどまっているからである。また、その人は、神から生れた者であるから、罪を犯すことができない。</span>
<span className="v" id="v10" data-v="10" data-xref="ヨハネの第一の手紙 4:8; ヨハネの第三の手紙 1:11; ルカによる福音書 6:35"> 神の子と悪魔の子との区別は、これによって明らかである。すなわち、すべて義を行わない者は、神から出た者ではない。兄弟を愛さない者も、同様である。</span>
<span className="v" id="v11" data-v="11" data-xref="ヨハネによる福音書 15:12; ヨハネの第二の手紙 1:5; ヨハネの第一の手紙 4:7"> わたしたちは互に愛し合うべきである。これが、あなたがたの初めから聞いていたおとずれである。</span>
<span className="v" id="v12" data-v="12" data-xref="ヘブル人への手紙 11:4; 創世記 4:4–15; 箴言 29:27"> カインのようになってはいけない。彼は悪しき者から出て、その兄弟を殺したのである。なぜ兄弟を殺したのか。彼のわざが悪く、その兄弟のわざは正しかったからである。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="ヨハネによる福音書 15:18–19; ヨハネによる福音書 17:14; ルカによる福音書 21:17"> 兄弟たちよ。世があなたがたを憎んでも、驚くには及ばない。</span>
<span className="v" id="v14" data-v="14" data-xref="ヨハネによる福音書 13:35; ヨハネの第一の手紙 5:2; ヨハネの第一の手紙 4:20–21"> わたしたちは、兄弟を愛しているので、死からいのちへ移ってきたことを、知っている。愛さない者は、死のうちにとどまっている。</span>
<span className="v" id="v15" data-v="15" data-xref="マタイによる福音書 5:21–22; 箴言 26:24–26; ヨハネの黙示録 21:8"> あなたがたが知っているとおり、すべて兄弟を憎む者は人殺しであり、人殺しはすべて、そのうちに永遠のいのちをとどめてはいない。</span>
<span className="v" id="v16" data-v="16" data-xref="ヨハネの第一の手紙 4:9–11; エペソ人への手紙 5:2; ヨハネによる福音書 13:34"> 主は、わたしたちのためにいのちを捨てて下さった。それによって、わたしたちは愛ということを知った。それゆえに、わたしたちもまた、兄弟のためにいのちを捨てるべきである。</span>
<span className="v" id="v17" data-v="17" data-xref="ヘブル人への手紙 13:16; イザヤ書 58:7–10; 申命記 15:7–11"> 世の富を持っていながら、兄弟が困っているのを見て、あわれみの心を閉じる者には、どうして神の愛が、彼のうちにあろうか。</span>
<span className="v" id="v18" data-v="18" data-xref="ヤコブの手紙 2:15–16; ローマ人への手紙 12:9; ペテロの第一の手紙 1:22"> 子たちよ。わたしたちは言葉や口先だけで愛するのではなく、行いと真実とをもって愛し合おうではないか。</span>
<span className="v" id="v19" data-v="19" data-xref="ヘブル人への手紙 10:22; ヨハネの第一の手紙 3:21; ヘブル人への手紙 6:10–11"> それによって、わたしたちが真理から出たものであることがわかる。そして、神のみまえに心を安んじていよう。</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 139:1–4; エレミヤ書 17:10; ヘブル人への手紙 4:13"> なぜなら、たといわたしたちの心に責められるようなことがあっても、神はわたしたちの心よりも大いなるかたであって、すべてをご存じだからである。</span>
<span className="v" id="v21" data-v="21" data-xref="ヨハネの第一の手紙 2:28; ヘブル人への手紙 4:16; コリント人への第二の手紙 1:12"> 愛する者たちよ。もし心に責められるようなことがなければ、わたしたちは神に対して確信を持つことができる。</span>
<span className="v" id="v22" data-v="22" data-xref="ヨハネによる福音書 15:7; ヨハネによる福音書 9:31; ヨハネの第一の手紙 5:14"> そして、願い求めるものは、なんでもいただけるのである。それは、わたしたちが神の戒めを守り、みこころにかなうことを、行っているからである。</span>
<span className="v" id="v23" data-v="23" data-xref="ヨハネによる福音書 6:29; ヨハネによる福音書 13:34; ペテロの第一の手紙 1:22"> その戒めというのは、神の子イエス・キリストの御名を信じ、わたしたちに命じられたように、互に愛し合うべきことである。</span>
<span className="v" id="v24" data-v="24" data-xref="コリント人への第一の手紙 3:16; ヨハネの第一の手紙 4:15–16; ヨハネの第一の手紙 4:12–13"> 神の戒めを守る人は、神におり、神もまたその人にいます。そして、神がわたしたちのうちにいますことは、神がわたしたちに賜わった御霊によって知るのである。</span>

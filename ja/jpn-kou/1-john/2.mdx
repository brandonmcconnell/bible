<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="テモテヘの第一の手紙 2:5; ローマ人への手紙 8:34; ヨハネによる福音書 14:6"> わたしの子たちよ。これらのことを書きおくるのは、あなたがたが罪を犯さないようになるためである。もし、罪を犯す者があれば、父のみもとには、わたしたちのために助け主、すなわち、義なるイエス・キリストがおられる。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネの第一の手紙 4:14; ペテロの第一の手紙 3:18; ヨハネの第一の手紙 4:10"> 彼は、わたしたちの罪のための、あがないの供え物である。ただ、わたしたちの罪のためばかりではなく、全世界の罪のためである。</span>
<span className="v" id="v3" data-v="3" data-xref="ヨハネによる福音書 14:15; ヨハネによる福音書 15:10; ルカによる福音書 6:46"> もし、わたしたちが彼の戒めを守るならば、それによって彼を知っていることを悟るのである。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネの第一の手紙 1:6; テトスヘの手紙 1:16; ヤコブの手紙 2:14–16"> 「彼を知っている」と言いながら、その戒めを守らない者は、偽り者であって、真理はその人のうちにない。</span>
<span className="v" id="v5" data-v="5" data-xref="ヨハネによる福音書 14:23; ヨハネによる福音書 14:21; ヨハネの第一の手紙 4:12–13"> しかし、彼の御言を守る者があれば、その人のうちに、神の愛が真に全うされるのである。それによって、わたしたちが彼にあることを知るのである。</span>
<span className="v" id="v6" data-v="6" data-xref="ペテロの第一の手紙 2:21; ヨハネによる福音書 13:15; コリント人への第一の手紙 11:1"> 「彼におる」と言う者は、彼が歩かれたように、その人自身も歩くべきである。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="ヨハネの第一の手紙 3:11; レビ記 19:18; マルコによる福音書 12:29–34"> 愛する者たちよ。わたしがあなたがたに書きおくるのは、新しい戒めではなく、あなたがたが初めから受けていた古い戒めである。その古い戒めとは、あなたがたがすでに聞いた御言である。</span>
<span className="v" id="v8" data-v="8" data-xref="エペソ人への手紙 5:8; ローマ人への手紙 13:12; ヨハネによる福音書 13:34"> しかも、新しい戒めを、あなたがたに書きおくるのである。そして、それは、彼にとってもあなたがたにとっても、真理なのである。なぜなら、やみは過ぎ去り、まことの光がすでに輝いているからである。</span>
<span className="v" id="v9" data-v="9" data-xref="ヨハネの第一の手紙 4:20; ヨハネの第一の手紙 2:11; ヨハネの第一の手紙 3:13–17"> 「光の中にいる」と言いながら、その兄弟を憎む者は、今なお、やみの中にいるのである。</span>
<span className="v" id="v10" data-v="10" data-xref="ヨハネの第一の手紙 3:14; ローマ人への手紙 9:32–33; ローマ人への手紙 14:13"> 兄弟を愛する者は、光におるのであって、つまずくことはない。</span>
<span className="v" id="v11" data-v="11" data-xref="ヨハネによる福音書 12:35; テトスヘの手紙 3:3; ヨハネの第一の手紙 1:6"> 兄弟を憎む者は、やみの中におり、やみの中を歩くのであって、自分ではどこへ行くのかわからない。やみが彼の目を見えなくしたからである。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="使徒行伝 10:43; 使徒行伝 13:38; エペソ人への手紙 1:7"> 子たちよ。あなたがたにこれを書きおくるのは、御名のゆえに、あなたがたの多くの罪がゆるされたからである。</span>
<span className="v" id="v13" data-v="13" data-xref="ヨハネによる福音書 14:7; ヨハネの第一の手紙 2:14; ルカによる福音書 10:22"> 父たちよ。あなたがたに書きおくるのは、あなたがたが、初めからいますかたを知ったからである。若者たちよ。あなたがたに書きおくるのは、あなたがたが、悪しき者にうち勝ったからである。</span>
<span className="v" id="v14" data-v="14" data-xref="詩篇 119:11; ヨハネの第一の手紙 2:13; コロサイ人への手紙 3:16"> 子供たちよ。あなたがたに書きおくったのは、あなたがたが父を知ったからである。父たちよ。あなたがたに書きおくったのは、あなたがたが、初めからいますかたを知ったからである。若者たちよ。あなたがたに書きおくったのは、あなたがたが強い者であり、神の言があなたがたに宿り、そして、あなたがたが悪しき者にうち勝ったからである。</span>
<span className="v" id="v15" data-v="15" data-xref="ヤコブの手紙 4:4; ローマ人への手紙 12:2; マタイによる福音書 6:24"> 世と世にあるものとを、愛してはいけない。もし、世を愛する者があれば、父の愛は彼のうちにない。</span>
<span className="v" id="v16" data-v="16" data-xref="ローマ人への手紙 13:14; ガラテヤ人への手紙 5:17; 詩篇 119:36–37"> すべて世にあるもの、すなわち、肉の欲、目の欲、持ち物の誇は、父から出たものではなく、世から出たものである。</span>
<span className="v" id="v17" data-v="17" data-xref="マタイによる福音書 24:35; ローマ人への手紙 12:2; コリント人への第一の手紙 7:31"> 世と世の欲とは過ぎ去る。しかし、神の御旨を行う者は、永遠にながらえる。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="ヨハネの第一の手紙 4:3; ヨハネの第二の手紙 1:7; マタイによる福音書 24:24"> 子供たちよ。今は終りの時である。あなたがたがかねて反キリストが来ると聞いていたように、今や多くの反キリストが現れてきた。それによって今が終りの時であることを知る。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行伝 20:30; コリント人への第一の手紙 11:19; ルカによる福音書 8:13"> 彼らはわたしたちから出て行った。しかし、彼らはわたしたちに属する者ではなかったのである。もし属する者であったなら、わたしたちと一緒にとどまっていたであろう。しかし、出て行ったのは、元来、彼らがみなわたしたちに属さない者であることが、明らかにされるためである。</span>
<span className="v" id="v20" data-v="20" data-xref="ヨハネによる福音書 14:26; ヨハネの第一の手紙 2:27; コリント人への第二の手紙 1:21–22"> しかし、あなたがたは聖なる者に油を注がれているので、あなたがたすべてが、そのことを知っている。</span>
<span className="v" id="v21" data-v="21" data-xref="ペテロの第二の手紙 1:12; ユダの手紙 1:5; 箴言 1:5"> わたしが書きおくったのは、あなたがたが真理を知らないからではなく、それを知っているからであり、また、すべての偽りは真理から出るものでないことを、知っているからである。</span>
<span className="v" id="v22" data-v="22" data-xref="ヨハネの第二の手紙 1:7; ヨハネの第一の手紙 4:3; ヨハネの第一の手紙 2:18"> 偽り者とは、だれであるか。イエスのキリストであることを否定する者ではないか。父と御子とを否定する者は、反キリストである。</span>
<span className="v" id="v23" data-v="23" data-xref="ヨハネの第一の手紙 4:15; ヨハネによる福音書 8:19; ヨハネによる福音書 5:23"> 御子を否定する者は父を持たず、御子を告白する者は、また父をも持つのである。</span>
<span className="v" id="v24" data-v="24" data-xref="ヨハネによる福音書 14:23; ヨハネによる福音書 15:9–10; ヨハネの第一の手紙 4:13"> 初めから聞いたことが、あなたがたのうちに、とどまるようにしなさい。初めから聞いたことが、あなたがたのうちにとどまっておれば、あなたがたも御子と父とのうちに、とどまることになる。</span>
<span className="v" id="v25" data-v="25" data-xref="ヨハネによる福音書 10:28; テトスヘの手紙 3:7; ユダの手紙 1:21"> これが、彼自らわたしたちに約束された約束であって、すなわち、永遠のいのちである。</span>
<span className="v" id="v26" data-v="26" data-xref="ペテロの第二の手紙 2:1–3; ヨハネの第二の手紙 1:7; 使徒行伝 20:29–30"> わたしは、あなたがたを惑わす者たちについて、これらのことを書きおくった。</span>
<span className="v" id="v27" data-v="27" data-xref="ヨハネによる福音書 14:26; ヨハネの第一の手紙 2:20–21; コリント人への第一の手紙 2:13"> あなたがたのうちには、キリストからいただいた油がとどまっているので、だれにも教えてもらう必要はない。この油が、すべてのことをあなたがたに教える。それはまことであって、偽りではないから、その油が教えたように、あなたがたは彼のうちにとどまっていなさい。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="ヨハネの第一の手紙 4:17; マルコによる福音書 8:38; ヨハネの第一の手紙 3:2"> そこで、子たちよ。キリストのうちにとどまっていなさい。それは、彼が現れる時に、確信を持ち、その来臨に際して、みまえに恥じいることがないためである。</span>
<span className="v" id="v29" data-v="29" data-xref="ヨハネによる福音書 3:3–5; ヨハネの第一の手紙 3:7; ヨハネの第一の手紙 5:1"> 彼の義なるかたであることがわかれば、義を行う者はみな彼から生れたものであることを、知るであろう。</span>
</div>

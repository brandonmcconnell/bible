<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨハネによる福音書 1:12–13; ヨハネによる福音書 8:42; ヨハネの第一の手紙 2:29"> すべてイエスのキリストであることを信じる者は、神から生れた者である。すべて生んで下さったかたを愛する者は、そのかたから生れた者をも愛するのである。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネによる福音書 13:34–35; ヨハネの第一の手紙 2:5; ヨハネの第一の手紙 3:22–24"> 神を愛してその戒めを行えば、それによってわたしたちは、神の子たちを愛していることを知るのである。</span>
<span className="v" id="v3" data-v="3" data-xref="ヨハネによる福音書 14:15; ヨハネによる福音書 15:10; ヨハネによる福音書 14:21–24"> 神を愛するとは、すなわち、その戒めを守ることである。そして、その戒めはむずかしいものではない。</span>
<span className="v" id="v4" data-v="4" data-xref="コリント人への第一の手紙 15:57; ヨハネの第一の手紙 4:4; ヨハネによる福音書 16:33"> なぜなら、すべて神から生れた者は、世に勝つからである。そして、わたしたちの信仰こそ、世に勝たしめた勝利の力である。</span>
<span className="v" id="v5" data-v="5" data-xref="ヨハネの第一の手紙 4:15; ヨハネの第一の手紙 5:1"> 世に勝つ者はだれか。イエスを神の子と信じる者ではないか。</span>
<span className="v" id="v6" data-v="6" data-xref="ヨハネによる福音書 15:26; ヘブル人への手紙 9:14; ヨハネによる福音書 16:13"> このイエス・キリストは、水と血とをとおってこられたかたである。水によるだけではなく、水と血とによってこられたのである。そのあかしをするものは、御霊である。御霊は真理だからである。</span>
<span className="v" id="v7" data-v="7" data-xref="マタイによる福音書 28:19; コリント人への第二の手紙 13:14; 使徒行伝 5:32"> あかしをするものが、三つある。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨハネの第一の手紙 5:6–7; ヨハネによる福音書 15:26; ペテロの第一の手紙 3:21"> 御霊と水と血とである。そして、この三つのものは一致する。</span>
<span className="v" id="v9" data-v="9" data-xref="マタイによる福音書 3:16–17; マタイによる福音書 17:5; 使徒行伝 17:31"> わたしたちは人間のあかしを受けいれるが、しかし、神のあかしはさらにまさっている。神のあかしというのは、すなわち、御子について立てられたあかしである。</span>
<span className="v" id="v10" data-v="10" data-xref="ローマ人への手紙 8:16; ガラテヤ人への手紙 4:6; ヨハネによる福音書 3:33"> 神の子を信じる者は、自分のうちにこのあかしを持っている。神を信じない者は、神を偽り者とする。神が御子についてあかしせられたそのあかしを、信じていないからである。</span>
<span className="v" id="v11" data-v="11" data-xref="ローマ人への手紙 6:23; ヨハネの第一の手紙 2:25; ヨハネによる福音書 3:36"> そのあかしとは、神が永遠のいのちをわたしたちに賜わり、かつ、そのいのちが御子のうちにあるということである。</span>
<span className="v" id="v12" data-v="12" data-xref="ヨハネによる福音書 3:36; ヨハネによる福音書 5:24; ヨハネによる福音書 1:12"> 御子を持つ者はいのちを持ち、神の御子を持たない者はいのちを持っていない。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="ヨハネによる福音書 20:31; ヨハネによる福音書 1:12; ペテロの第二の手紙 1:10–11"> これらのことをあなたがたに書きおくったのは、神の子の御名を信じるあなたがたに、永遠のいのちを持っていることを、悟らせるためである。</span>
<span className="v" id="v14" data-v="14" data-xref="ヨハネによる福音書 14:13; エレミヤ書 33:3; エレミヤ書 29:12–13"> わたしたちが神に対していだいている確信は、こうである。すなわち、わたしたちが何事でも神の御旨に従って願い求めるなら、神はそれを聞きいれて下さるということである。</span>
<span className="v" id="v15" data-v="15" data-xref="ルカによる福音書 11:9–10; マルコによる福音書 11:24; 箴言 15:29"> そして、わたしたちが願い求めることは、なんでも聞きいれて下さるとわかれば、神に願い求めたことはすでにかなえられたことを、知るのである。</span>
<span className="v" id="v16" data-v="16" data-xref="ヘブル人への手紙 6:4–6; サムエル記上 2:25; エレミヤ書 11:14"> もしだれかが死に至ることのない罪を犯している兄弟を見たら、神に願い求めなさい。そうすれば神は、死に至ることのない罪を犯している人々には、いのちを賜わるであろう。死に至る罪がある。これについては、願い求めよ、とは言わない。</span>
<span className="v" id="v17" data-v="17" data-xref="ヨハネの第一の手紙 3:4; ヨハネの第一の手紙 5:16; ヤコブの手紙 4:7–10"> 不義はすべて、罪である。しかし、死に至ることのない罪もある。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="ヨハネの第一の手紙 3:9; ヨハネの第一の手紙 5:4; ヨハネの第一の手紙 5:1"> すべて神から生れた者は罪を犯さないことを、わたしたちは知っている。神から生れたかたが彼を守っていて下さるので、悪しき者が手を触れるようなことはない。</span>
<span className="v" id="v19" data-v="19" data-xref="コリント人への第二の手紙 4:4; ヨハネの第一の手紙 4:4–6; エペソ人への手紙 2:2"> また、わたしたちは神から出た者であり、全世界は悪しき者の配下にあることを、知っている。</span>
<span className="v" id="v20" data-v="20" data-xref="ヨハネによる福音書 17:3; ルカによる福音書 24:45; ヨハネによる福音書 14:9"> さらに、神の子がきて、真実なかたを知る知力をわたしたちに授けて下さったことも、知っている。そして、わたしたちは、真実なかたにおり、御子イエス・キリストにおるのである。このかたは真実な神であり、永遠のいのちである。</span>
<span className="v" id="v21" data-v="21" data-xref="コリント人への第一の手紙 10:14; コリント人への第一の手紙 10:7; 出エジプト記 20:3–4"> 子たちよ。気をつけて、偶像を避けなさい。</span>
</div>

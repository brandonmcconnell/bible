<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ホセア書 5:1; マラキ書 1:6; エレミヤ書 13:13"> 祭司たちよ、今この命令があなたがたに与えられる。</span>
<span className="v" id="v2" data-v="2" data-xref="ルカによる福音書 17:18; ヨハネの黙示録 14:7; 詩篇 69:22"> 万軍の主は言われる、あなたがたがもし聞き従わず、またこれを心に留めず、わが名に栄光を帰さないならば、わたしはあなたがたの上に、のろいを送り、またあなたがたの祝福をのろいに変える。あなたがたは、これを心に留めないので、わたしはすでにこれをのろった。</span>
<span className="v" id="v3" data-v="3" data-xref="ナホム書 3:6; マラキ書 2:9; ヨブ記 20:7"> 見よ、わたしはあなたがたの子孫を責める。またあなたがたの犠牲の糞を、あなたがたの顔の上にまき散らし、あなたがたをわたしの前から退ける。</span>
<span className="v" id="v4" data-v="4" data-xref="民数記 3:12; エゼキエル書 38:23; マタイによる福音書 3:12"> こうしてわたしが、この命令をあなたがたに与えたのは、レビと結んだわが契約が、保たれるためであることを、あなたがたが知るためであると、万軍の主は言われる。</span>
<span className="v" id="v5" data-v="5" data-xref="民数記 25:12–13; エゼキエル書 34:25; エゼキエル書 37:26"> 彼と結んだわが契約は、生命と平安との契約であって、わたしがこれを彼に与えたのは、彼にわたしを恐れさせるためである。彼はすでにわたしを恐れ、わが名の前におののいた。</span>
<span className="v" id="v6" data-v="6" data-xref="ダニエル書 12:3; テモテヘの第二の手紙 2:15–16; ヨハネの黙示録 14:5"> 彼の口には、まことの律法があり、そのくちびるには、不義が見られなかった。彼は平安と公義とをもって、わたしと共に歩み、また多くの人を不義から立ち返らせた。</span>
<span className="v" id="v7" data-v="7" data-xref="テモテヘの第二の手紙 2:24–25; レビ記 10:11; 申命記 21:5"> 祭司のくちびるは知識を保ち、人々が彼の口から律法を尋ねるのが当然である。彼は万軍の主の使者だからだ。</span>
<span className="v" id="v8" data-v="8" data-xref="ネヘミヤ書 13:29; エレミヤ書 18:15; イザヤ書 30:11"> ところが、あなたがたは道を離れ、多くの人を教えてつまずかせ、レビの契約を破ったと、万軍の主は言われる。</span>
<span className="v" id="v9" data-v="9" data-xref="サムエル記上 2:30; 申命記 1:17; マタイによる福音書 19:17–18"> あなたがたはわたしの道を守らず、律法を教えるに当って、人にかたよったがために、あなたがたをすべての民の前に侮られ、卑しめられるようにする」。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="詩篇 100:3; マラキ書 2:11; コリント人への第一の手紙 8:6"> われわれの父は皆一つではないか。われわれを造った神は一つではないか。なにゆえ、われわれは先祖たちの契約を破って、おのおのその兄弟に偽りを行うのか。</span>
<span className="v" id="v11" data-v="11" data-xref="コリント人への第二の手紙 6:14–18; エズラ記 9:1–2; ネヘミヤ書 13:23–29"> ユダは偽りを行い、イスラエルおよびエルサレムの中には憎むべき事が行われた。すなわちユダは主が愛しておられる聖所を汚して、他の神に仕える女をめとった。</span>
<span className="v" id="v12" data-v="12" data-xref="レビ記 18:29; レビ記 20:3; エゼキエル書 24:21"> どうか、主がこうした事を行う人をば、証言する者も、答弁する者も、また万軍の主にささげ物をする者をも、ヤコブの幕屋から断たれるように。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="イザヤ書 1:11–15; エレミヤ書 14:12; 詩篇 78:34–37"> あなたがたはまたこのような事をする。すなわち神がもはやささげ物をかえりみず、またこれをあなたがたの手から、喜んで受けられないために、あなたがたは涙と、泣くことと、嘆きとをもって、主の祭壇をおおい、</span>
<span className="v" id="v14" data-v="14" data-xref="マラキ書 2:15; 伝道の書 9:9; イザヤ書 54:6"> 「なぜ神は受けられないのか」と尋ねる。これは主があなたと、あなたの若い時の妻との間の、契約の証人だったからである。彼女は、あなたの連れ合い、契約によるあなたの妻であるのに、あなたは彼女を裏切った。</span>
<span className="v" id="v15" data-v="15" data-xref="マタイによる福音書 19:4–6; マラキ書 2:14; マルコによる福音書 10:6–8"> 一つ神は、われわれのために命の霊を造り、これをささえられたではないか。彼は何を望まれるか。神を敬う子孫であるゆえ、あなたがたはみずから慎んで、その若い時の妻を裏切ってはならない。</span>
<span className="v" id="v16" data-v="16" data-xref="マタイによる福音書 19:3–9; マタイによる福音書 5:31–32; マルコによる福音書 10:2–12"> イスラエルの神、主は言われる、「わたしは離縁する者を憎み、また、しえたげをもってその衣をおおう人を憎むと、万軍の主は言われる。ゆえにみずから慎んで、裏切ることをしてはならない」。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="イザヤ書 43:24; ペテロの第二の手紙 3:3–4; 伝道の書 8:11"> あなたがたは言葉をもって主を煩わした。しかしあなたがたは言う、「われわれはどんなふうに、彼を煩わしたか」。それはあなたがたが「すべて悪を行う者は主の目に良く見え、かつ彼に喜ばれる」と言い、また「さばきを行う神はどこにあるか」と言うからである。</span>
</div>

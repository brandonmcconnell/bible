<span className="v" id="v1" data-v="1" data-xref="イザヤ書 3:26; エズラ記 4:20; 列王紀上 4:21"> <span className="pl pl-1">ああ、むかしは、</span><br /><span className="pl pl-1">民の満ちみちていたこの都、</span><br /><span className="pl pl-1">国々の民のうちで大いなる者であったこの町、</span><br /><span className="pl pl-1">今は寂しいさまで座し、やもめのようになった。</span><br /><span className="pl pl-1">もろもろの町のうちで女王であった者、</span><br /><span className="pl pl-1">今は奴隷となった。</span></span>
<span className="v" id="v2" data-v="2" data-xref="詩篇 6:6; ミカ書 7:5; 詩篇 77:2–6"> <span className="pl pl-1">これは夜もすがらいたく泣き悲しみ、</span><br /><span className="pl pl-1">そのほおには涙が流れている。</span><br /><span className="pl pl-1">そのすべての愛する者のうちには、</span><br /><span className="pl pl-1">これを慰める者はひとりもなく、</span><br /><span className="pl pl-1">そのすべての友はこれにそむいて、その敵となった。</span></span>
<span className="v" id="v3" data-v="3" data-xref="申命記 28:64–67; 哀歌 2:9; アモス書 9:1–4"> <span className="pl pl-1">ユダは悩みのゆえに、</span><br /><span className="pl pl-1">また激しい苦役のゆえに、のがれて行って、</span><br /><span className="pl pl-1">もろもろの国民のうちに住んでいるが、安息を得ず、</span><br /><span className="pl pl-1">これを追う者がみな追いついてみると、</span><br /><span className="pl pl-1">悩みのうちにあった。</span></span>
<span className="v" id="v4" data-v="4" data-xref="エレミヤ書 9:11; ヨエル書 1:8–13; エレミヤ書 10:22"> <span className="pl pl-1">シオンの道は祭に上ってくる者のないために悲しみ、</span><br /><span className="pl pl-1">その門はことごとく荒れ、</span><br /><span className="pl pl-1">その祭司たちは嘆き、</span><br /><span className="pl pl-1">そのおとめたちは引かれて行き、</span><br /><span className="pl pl-1">シオンはみずからいたく苦しむ。</span></span>
<span className="v" id="v5" data-v="5" data-xref="申命記 32:15–27; エレミヤ書 30:14–15; エゼキエル書 9:9"> <span className="pl pl-1">そのあだはかしらとなり、その敵は栄えている。</span><br /><span className="pl pl-1">そのとがが多いので、</span><br /><span className="pl pl-1">主がこれを悩まされたからである。</span><br /><span className="pl pl-1">その幼な子たちは捕われて、あだの前に行った。</span></span>
<span className="v" id="v6" data-v="6" data-xref="エゼキエル書 24:25; エレミヤ書 13:18; 申命記 28:25"> <span className="pl pl-1">シオンの娘の栄華はことごとく彼女を離れ去り、</span><br /><span className="pl pl-1">その君たちは牧草を得ない、しかのようになり、</span><br /><span className="pl pl-1">自分を追う者の前に力なく逃げ去った。</span></span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 79:4; 申命記 4:34–37; 詩篇 42:4"> <span className="pl pl-1">エルサレムはその悩みと苦しみの日に、</span><br /><span className="pl pl-1">昔から持っていたもろもろの宝を思い出す。</span><br /><span className="pl pl-1">その民があだの手に陥り、</span><br /><span className="pl pl-1">だれもこれを助ける者のない時、</span><br /><span className="pl pl-1">あだはこれを見て、その滅びをあざ笑った。</span></span>
<span className="v" id="v8" data-v="8" data-xref="イザヤ書 59:2–13; 哀歌 1:20–22; エレミヤ書 13:26"> <span className="pl pl-1">エルサレムは、はなはだしく罪を犯したので、</span><br /><span className="pl pl-1">汚れたものとなった。</span><br /><span className="pl pl-1">これを尊んだ者も皆その裸を見たので、</span><br /><span className="pl pl-1">これを卑しめる。</span><br /><span className="pl pl-1">これもまたみずから嘆き、顔をそむける。</span></span>
<span className="v" id="v9" data-v="9" data-xref="申命記 32:29; イザヤ書 47:7; 詩篇 25:18"> <span className="pl pl-1">その汚れはその衣のすそにあり、</span><br /><span className="pl pl-1">これはその終りを思わなかった。</span><br /><span className="pl pl-1">それゆえ、これは驚くばかりに落ちぶれ、</span><br /><span className="pl pl-1">これを慰める者はひとりもない。</span><br /><span className="pl pl-1">「主よ、わが悩みを顧みてください、</span><br /><span className="pl pl-1">敵は勝ち誇っていますから」。</span></span>
<span className="v" id="v10" data-v="10" data-xref="申命記 23:3; エレミヤ書 51:51; 詩篇 74:4–8"> <span className="pl pl-1">敵は手を伸べて、その財宝をことごとく奪った。</span><br /><span className="pl pl-1">あなたがさきに異邦人らはあなたの公会に、</span><br /><span className="pl pl-1">はいってはならないと命じられたのに、</span><br /><span className="pl pl-1">彼らがその聖所にはいるのをシオンは見た。</span></span>
<span className="v" id="v11" data-v="11" data-xref="エレミヤ書 52:6; エレミヤ書 38:9; 哀歌 2:12"> <span className="pl pl-1">その民はみな嘆いて食物を求め、</span><br /><span className="pl pl-1">その命をささえるために、財宝を食物にかえた。</span><br /><span className="pl pl-1">「主よ、みそなわして、</span><br /><span className="pl pl-1">わたしの卑しめられるのを顧みてください」。</span></span>
<span className="v" id="v12" data-v="12" data-xref="ルカによる福音書 23:28–31; ダニエル書 9:12; エレミヤ書 30:24"> <span className="pl pl-1">「すべて道行く人よ、</span><br /><span className="pl pl-1">あなたがたはなんとも思わないのか。</span><br /><span className="pl pl-1">主がその激しい怒りの日にわたしを悩まして、</span><br /><span className="pl pl-1">わたしにくだされた苦しみのような苦しみが、</span><br /><span className="pl pl-1">また世にあるだろうか、尋ねて見よ。</span></span>
<span className="v" id="v13" data-v="13" data-xref="ヨブ記 30:30; ハバクク書 3:16; エゼキエル書 17:20"> <span className="pl pl-1">主は上から火を送り、</span><br /><span className="pl pl-1">それをわが骨にくだし、</span><br /><span className="pl pl-1">網を張ってわが足を捕え、</span><br /><span className="pl pl-1">わたしを引き返させ、</span><br /><span className="pl pl-1">ひねもす心わびしく、かつ病み衰えさせられた。</span></span>
<span className="v" id="v14" data-v="14" data-xref="申命記 28:48; イザヤ書 47:6; 箴言 5:22"> <span className="pl pl-1">わたしのとがは、つかねられて、</span><br /><span className="pl pl-1">一つのくびきとせられ、</span><br /><span className="pl pl-1">主のみ手により固く締められて、</span><br /><span className="pl pl-1">わたしの首におかれ、</span><br /><span className="pl pl-1">わたしの力を衰えさせられた。</span><br /><span className="pl pl-1">主はわたしを、立ちむかい得ざる者の手に渡された。</span></span>

<span className="v" id="v16" data-v="16" data-xref="哀歌 1:2; エレミヤ書 13:17; 詩篇 119:136"> <span className="pl pl-1">このために、わたしは泣き悲しみ、</span><br /><span className="pl pl-1">わたしの目は涙であふれる。</span><br /><span className="pl pl-1">わたしを慰める者、わたしを勇気づける者が</span><br /><span className="pl pl-1">わたしから遠く離れたからである。</span><br /><span className="pl pl-1">わが子らは敵が勝ったために、</span><br /><span className="pl pl-1">わびしい者となった」。</span></span>
<span className="v" id="v17" data-v="17" data-xref="イザヤ書 1:15; エレミヤ書 4:31; 哀歌 1:9"> <span className="pl pl-1">シオンは手を伸ばしても、</span><br /><span className="pl pl-1">これを慰める者はひとりもない。</span><br /><span className="pl pl-1">ヤコブについては、主は命じて、</span><br /><span className="pl pl-1">その周囲の者を、これがあだとせられた。</span><br /><span className="pl pl-1">エルサレムは彼らの中にあって、</span><br /><span className="pl pl-1">汚れた物のようになった。</span></span>

<span className="v" id="v19" data-v="19" data-xref="哀歌 1:2; 哀歌 1:11; 哀歌 2:20"> <span className="pl pl-1">わたしはわが愛する者を呼んだが、</span><br /><span className="pl pl-1">彼らはわたしを欺いた。</span><br /><span className="pl pl-1">わが祭司および長老たちは、その命をささえようと、</span><br /><span className="pl pl-1">食物を求めている間に、町のうちで息絶えた。</span></span>

<span className="v" id="v21" data-v="21" data-xref="哀歌 1:8; 哀歌 2:15; 哀歌 1:16"> <span className="pl pl-1">わたしがどんなに嘆くかを聞いてください。</span><br /><span className="pl pl-1">わたしを慰める者はひとりもなく、</span><br /><span className="pl pl-1">敵はみなわたしの悩みを聞いて、</span><br /><span className="pl pl-1">あなたがこれをなされたのを喜んだ。</span><br /><span className="pl pl-1">あなたがさきに告げ知らせたその日をきたらせ、</span><br /><span className="pl pl-1">彼らをも、わたしのようにしてください。</span></span>
<span className="v" id="v22" data-v="22" data-xref="エレミヤ書 8:18; 詩篇 109:14–15; ヨハネの黙示録 6:10"> <span className="pl pl-1">彼らの悪をことごとくあなたの前にあらわし、</span><br /><span className="pl pl-1">さきにわがもろもろのとがのために、</span><br /><span className="pl pl-1">わたしに行われたように、彼らにも行ってください。</span><br /><span className="pl pl-1">わが嘆きは多く、</span><br /><span className="pl pl-1">わが心は弱りはてているからです」。</span></span>

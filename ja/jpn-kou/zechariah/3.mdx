<span className="v" id="v1" data-v="1" data-xref="ペテロの第一の手紙 5:8; ルカによる福音書 22:31; 詩篇 109:6"> 時に主は大祭司ヨシュアが、主の使の前に立ち、サタンがその右に立って、これを訴えているのをわたしに示された。</span>
<span className="v" id="v2" data-v="2" data-xref="アモス書 4:11; ユダの手紙 1:23; ユダの手紙 1:9"> 主はサタンに言われた、「サタンよ、主はあなたを責めるのだ。すなわちエルサレムを選んだ主はあなたを責めるのだ。これは火の中から取り出した燃えさしではないか」。</span>
<span className="v" id="v3" data-v="3" data-xref="イザヤ書 64:6; ヨハネの黙示録 19:8; エズラ記 9:15"> ヨシュアは汚れた衣を着て、み使の前に立っていたが、</span>
<span className="v" id="v4" data-v="4" data-xref="ルカによる福音書 15:22; イザヤ書 61:10; エゼキエル書 36:25"> み使は自分の前に立っている者どもに言った、「彼の汚れた衣を脱がせなさい」。またヨシュアに向かって言った、「見よ、わたしはあなたの罪を取り除いた。あなたに祭服を着せよう」。</span>
<span className="v" id="v5" data-v="5" data-xref="ゼカリヤ書 6:11; 出エジプト記 29:6; ヨブ記 29:14"> わたしは言った、「清い帽子を頭にかぶらせなさい」。そこで清い帽子を頭にかぶらせ、衣を彼に着せた。主の使はかたわらに立っていた。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="創世記 28:13–17; 創世記 22:15–16; ゼカリヤ書 3:1"> 主の使は、ヨシュアを戒めて言った、</span>
<span className="v" id="v7" data-v="7" data-xref="マタイによる福音書 19:28; 創世記 26:5; テモテヘの第二の手紙 4:1–2"> 「万軍の主は、こう仰せられる、あなたがもし、わたしの道に歩み、わたしの務を守るならば、わたしの家をつかさどり、わたしの庭を守ることができる。わたしはまた、ここに立っている者どもの中に行き来することを得させる。</span>
<span className="v" id="v8" data-v="8" data-xref="エレミヤ書 23:5; イザヤ書 11:1; ゼカリヤ書 6:12"> 大祭司ヨシュアよ、あなたも、あなたの前にすわっている同僚たちも聞きなさい。彼らはよいしるしとなるべき人々だからである。見よ、わたしはわたしのしもべなる枝を生じさせよう。</span>
<span className="v" id="v9" data-v="9" data-xref="ゼカリヤ書 4:10; エレミヤ書 50:20; イザヤ書 28:16"> 万軍の主は言われる、見よ、ヨシュアの前にわたしが置いた石の上に、すなわち七つの目をもっているこの一つの石の上に、わたしはみずから文字を彫刻する。そしてわたしはこの地の罪を、一日の内に取り除く。</span>
<span className="v" id="v10" data-v="10" data-xref="列王紀上 4:25; ミカ書 4:4; ゼカリヤ書 2:11"> 万軍の主は言われる、その日には、あなたがたはめいめいその隣り人を招いて、ぶどうの木の下、いちじくの木の下に座すのである」。</span>

<span className="v" id="v1" data-v="1" data-xref="エレミヤ書 31:26; ダニエル書 8:18; ゼカリヤ書 1:9"> わたしと語った天の使がまた来て、わたしを呼びさました。わたしは眠りから呼びさまされた人のようであった。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネの黙示録 4:5; ヨハネの黙示録 1:12; マタイによる福音書 5:14–16"> 彼がわたしに向かって「何を見るか」と言ったので、わたしは言った、「わたしが見ていると、すべて金で造られた燭台が一つあって、その上に油を入れる器があり、また燭台の上に七つのともしび皿があり、そのともしび皿は燭台の上にあって、これにおのおの七本ずつの管があります。</span>
<span className="v" id="v3" data-v="3" data-xref="ヨハネの黙示録 11:4; ゼカリヤ書 4:14; ローマ人への手紙 11:17"> また燭台のかたわらに、オリブの木が二本あって、一本は油をいれる器の右にあり、一本はその左にあります」。</span>
<span className="v" id="v4" data-v="4" data-xref="ゼカリヤ書 6:4; ゼカリヤ書 1:9; ゼカリヤ書 1:19"> わたしはまたわたしと語る天の使に言った、「わが主よ、これらはなんですか」。</span>
<span className="v" id="v5" data-v="5" data-xref="ゼカリヤ書 4:13; ゼカリヤ書 1:9; ダニエル書 2:30"> わたしと語る天の使は答えて、「あなたはそれがなんであるか知らないのですか」と言ったので、わたしは「わが主よ、知りません」と言った。</span>
<span className="v" id="v6" data-v="6" data-xref="歴代志下 32:7–8; コリント人への第二の手紙 10:4–5; コリント人への第一の手紙 2:4–5"> すると彼はわたしに言った、「ゼルバベルに、主がお告げになる言葉はこれです。万軍の主は仰せられる、これは権勢によらず、能力によらず、わたしの霊によるのである。</span>
<span className="v" id="v7" data-v="7" data-xref="エレミヤ書 51:25; ゼカリヤ書 4:9; ミカ書 4:1"> 大いなる山よ、おまえは何者か。おまえはゼルバベルの前に平地となる。彼は『恵みあれ、これに恵みあれ』と呼ばわりながら、かしら石を引き出すであろう」。</span>
<span className="v" id="v8" data-v="8"> 主の言葉がわたしに臨んで言うには、</span>
<span className="v" id="v9" data-v="9" data-xref="エズラ記 6:14–15; ゼカリヤ書 6:12–13; ゼカリヤ書 6:15"> 「ゼルバベルの手はこの宮の礎をすえた。彼の手はこれを完成する。その時あなたがたは万軍の主が、わたしをあなたがたにつかわされたことを知る。</span>
<span className="v" id="v10" data-v="10" data-xref="ヨブ記 8:7; コリント人への第一の手紙 1:28–29; 歴代志下 16:9"> だれでも小さい事の日をいやしめた者は、ゼルバベルの手に、下げ振りのあるのを見て、喜ぶ。<br />これらの七つのものは、あまねく全地を行き来する主の目である」。</span>
<span className="v" id="v11" data-v="11" data-xref="ゼカリヤ書 4:3; ヨハネの黙示録 11:4"> わたしはまた彼に尋ねて、「燭台の左右にある、この二本のオリブの木はなんですか」と言い、</span>
<span className="v" id="v12" data-v="12" data-xref="ヨハネの黙示録 11:4; マタイによる福音書 20:23; ハガイ書 1:1"> 重ねてまた「この二本の金の管によって、油をそれから注ぎ出すオリブの二枝はなんですか」と言うと、</span>
<span className="v" id="v13" data-v="13" data-xref="ゼカリヤ書 4:5; ヘブル人への手紙 5:11–12"> 彼はわたしに答えて、「あなたはそれがなんであるか知らないのですか」と言ったので、「わが主よ、知りません」と言った。</span>
<span className="v" id="v14" data-v="14" data-xref="ヨハネの黙示録 11:4; イザヤ書 61:1–3; ダニエル書 9:24–26"> すると彼は言った、「これらはふたりの油そそがれた者で、全地の主のかたわらに立つ者です」。</span>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 万軍の主の言葉がわたしに臨んだ、</span>
<span className="v" id="v2" data-v="2" data-xref="ヨエル書 2:18; ゼカリヤ書 1:14–16; イザヤ書 42:13–14"> 「万軍の主は、こう仰せられる、『わたしはシオンのために、大いなるねたみを起し、またこれがために、大いなる憤りをもってねたむ』。</span>
<span className="v" id="v3" data-v="3" data-xref="ゼカリヤ書 1:16; ゼカリヤ書 2:10–11; ヨハネによる福音書 1:14"> 主はこう仰せられる、『わたしはシオンに帰って、エルサレムの中に住む。エルサレムは忠信な町ととなえられ、万軍の主の山は聖なる山と、となえられる』。</span>
<span className="v" id="v4" data-v="4" data-xref="イザヤ書 65:20–22; ヨブ記 5:26; 哀歌 5:11–15"> 万軍の主は、こう仰せられる、『エルサレムの街路には再び老いた男、老いた女が座するようになる。みな年寄の人々で、おのおのつえを手に持つ。</span>
<span className="v" id="v5" data-v="5" data-xref="エレミヤ書 31:13; マタイによる福音書 11:16–17; エレミヤ書 30:19–20"> またその町の街路には、男の子、女の子が満ちて、街路に遊び戯れる』。</span>
<span className="v" id="v6" data-v="6" data-xref="エレミヤ書 32:27; ローマ人への手紙 4:20–21; 民数記 11:22–23"> 万軍の主は、こう仰せられる、『その日には、たとい、この民の残れる者の目に、不思議な事であっても、それはわたしの目にも、不思議な事であろうか』と万軍の主は言われる。</span>
<span className="v" id="v7" data-v="7" data-xref="エレミヤ書 31:8; ローマ人への手紙 11:25–27; マラキ書 1:11"> 万軍の主は、こう仰せられる、『見よ、わが民を東の国から、また西の国から救い出し、</span>
<span className="v" id="v8" data-v="8" data-xref="エゼキエル書 36:28; エゼキエル書 11:20; エレミヤ書 31:33"> 彼らを連れてきて、エルサレムに住まわせ、彼らはわが民となり、わたしは彼らの神となって、共に真実と正義とをもって立つ』」。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="イザヤ書 35:4; 歴代志上 22:13; エズラ記 5:1–2"> 万軍の主は、こう仰せられる、「万軍の主の家である宮を建てるために、その礎をすえた日からこのかた、預言者たちの口から出たこれらの言葉を、きょう聞く者よ、あなたがたの手を強くせよ。</span>
<span className="v" id="v10" data-v="10" data-xref="ハガイ書 1:6–11; ハガイ書 2:16–18; アモス書 3:6"> この日の以前には、人も働きの価を得ず、獣も働きの価を得ず、また出る者もはいる者も、あだのために安全ではなかった。わたしはまた人々を相たがいにそむかせた。</span>
<span className="v" id="v11" data-v="11" data-xref="イザヤ書 12:1; ハガイ書 2:19; ゼカリヤ書 8:8–9"> しかし今は、わたしのこの民の残れる者に対することは、さきの日のようではないと、万軍の主は言われる。</span>
<span className="v" id="v12" data-v="12" data-xref="レビ記 26:4–5; 申命記 33:13; 創世記 27:28"> そこには、平和と繁栄との種がまかれるからである。すなわちぶどうの木は実を結び、地は産物を出し、天は露を与える。わたしはこの民の残れる者に、これをことごとく与える。</span>
<span className="v" id="v13" data-v="13" data-xref="ゼパニヤ書 3:20; ゼカリヤ書 8:9; 詩篇 72:17"> ユダの家およびイスラエルの家よ、あなたがたが、国々の民の中に、のろいとなっていたように、わたしはあなたがたを救って祝福とする。恐れてはならない。あなたがたの手を強くせよ」。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="エレミヤ書 31:28; エゼキエル書 24:14; エレミヤ書 4:28"> 万軍の主は、こう仰せられる、「あなたがたの先祖が、わたしを怒らせた時に、災を下そうと思って、これをやめなかったように、――万軍の主は言われる――</span>
<span className="v" id="v15" data-v="15" data-xref="ゼカリヤ書 8:13; ミカ書 7:18–20; ルカによる福音書 12:32"> そのように、わたしはまた今日、エルサレムとユダの家に恵みを与えよう。恐れてはならない。</span>
<span className="v" id="v16" data-v="16" data-xref="エペソ人への手紙 4:25; ゼカリヤ書 7:9; 詩篇 15:2"> あなたがたのなすべき事はこれである。あなたがたは互に真実を語り、またあなたがたの門で、真実と平和のさばきとを、行わなければならない。</span>
<span className="v" id="v17" data-v="17" data-xref="箴言 6:16–19; ミカ書 2:1–3; エレミヤ書 44:4"> あなたがたは、互に人を害することを、心に図ってはならない。偽りの誓いを好んではならない。わたしはこれらの事を憎むからであると、主は言われる」。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18"> 万軍の主の言葉がわたしに臨んだ、</span>
<span className="v" id="v19" data-v="19" data-xref="ゼカリヤ書 8:16; エレミヤ書 39:2; ゼカリヤ書 7:5"> 「万軍の主は、こう仰せられる、四月の断食と、五月の断食と、七月の断食と、十月の断食とは、ユダの家の喜び楽しみの時となり、よき祝の時となる。ゆえにあなたがたは、真実と平和とを愛せよ。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="イザヤ書 2:2–3; ミカ書 4:1–2; ゼカリヤ書 2:11"> 万軍の主は、こう仰せられる、もろもろの民および多くの町の住民、すなわち、一つの町の住民は、他の町の人々のところに行き、</span>
<span className="v" id="v21" data-v="21" data-xref="ゼカリヤ書 7:2; ホセア書 6:3; 詩篇 146:1–2"> 『われわれは、ただちに行って、主の恵みを請い、万軍の主に呼び求めよう』と言うと、『わたしも行こう』と言う。</span>
<span className="v" id="v22" data-v="22" data-xref="ゼカリヤ書 8:21; イザヤ書 60:3–22; ヨハネの黙示録 21:24"> 多くの民および強い国民はエルサレムに来て、万軍の主を求め、主の恵みを請う。</span>
<span className="v" id="v23" data-v="23" data-xref="イザヤ書 55:5; コリント人への第一の手紙 14:25; イザヤ書 60:3"> 万軍の主は、こう仰せられる、その日には、もろもろの国ことばの民の中から十人の者が、ひとりのユダヤ人の衣のすそをつかまえて、『あなたがたと一緒に行こう。神があなたがたと共にいますことを聞いたから』と言う」。</span>
</div>

<span className="v" id="v1" data-v="1" data-xref="エレミヤ書 22:6–7; エレミヤ書 22:23; ルカによる福音書 21:23–24"> <span className="pl pl-1">レバノンよ、おまえの門を開き、</span><br /><span className="pl pl-1">おまえの香柏を火に焼き滅ぼさせよ。</span></span>
<span className="v" id="v2" data-v="2" data-xref="イザヤ書 2:12–17; エゼキエル書 31:17; イザヤ書 10:33–34"> <span className="pl pl-1">いとすぎよ、泣き叫べ。</span><br /><span className="pl pl-1">香柏は倒れ、</span><br /><span className="pl pl-1">みごとな木は、そこなわれたからである。</span><br /><span className="pl pl-1">バシャンのかしよ、泣き叫べ。</span><br /><span className="pl pl-1">茂った林は倒れたからである。</span></span>
<span className="v" id="v3" data-v="3" data-xref="エレミヤ書 50:44; エレミヤ書 25:34–36; ゼカリヤ書 11:8"> <span className="pl pl-1">聞け、牧者の泣き叫ぶ声を。</span><br /><span className="pl pl-1">彼らの栄えが消え去ったからである。</span><br /><span className="pl pl-1">聞け、ししのほえる声を。</span><br /><span className="pl pl-1">ヨルダンの草むらが荒れ果てたからである。</span></span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="ゼカリヤ書 11:7; マタイによる福音書 23:37; ローマ人への手紙 15:8"> わが神、主はこう仰せられた、「ほふらるべき羊の群れの牧者となれ。</span>
<span className="v" id="v5" data-v="5" data-xref="エレミヤ書 50:7; ホセア書 12:8; テモテヘの第一の手紙 6:5–10"> これを買う者は、これをほふっても罰せられない。これを売る者は言う、『主はほむべきかな、わたしは富んだ』と。そしてその牧者は、これをあわれまない。</span>
<span className="v" id="v6" data-v="6" data-xref="エレミヤ書 13:14; マタイによる福音書 22:7; イザヤ書 9:19–21"> わたしは、もはやこの地の住民をあわれまないと、主は言われる。見よ、わたしは人をおのおのその牧者の手に渡し、おのおのその王の手に渡す。彼らは地を荒す。わたしは彼らの手からこれを救い出さない」。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="ゼカリヤ書 11:14; ゼカリヤ書 11:4; イザヤ書 11:4"> わたしは羊の商人のために、ほふらるべき羊の群れの牧者となった。わたしは二本のつえを取り、その一本を恵みと名づけ、一本を結びと名づけて、その羊を牧した。</span>
<span className="v" id="v8" data-v="8" data-xref="イザヤ書 49:7; マタイによる福音書 23:34–36; ヨハネによる福音書 15:18"> わたしは一か月に牧者三人を滅ぼした。わたしは彼らに、がまんしきれなくなったが、彼らもまた、わたしを忌みきらった。</span>
<span className="v" id="v9" data-v="9" data-xref="エレミヤ書 43:11; マタイによる福音書 13:10–11; マタイによる福音書 21:19"> それでわたしは言った、「わたしはあなたがたの牧者とならない。死ぬ者は死に、滅びる者は滅び、残った者はたがいにその肉を食いあうがよい」。</span>
<span className="v" id="v10" data-v="10" data-xref="ゼカリヤ書 11:7; 詩篇 89:39; ヘブル人への手紙 8:8–13"> わたしは恵みというつえを取って、これを折った。これはわたしがもろもろの民と結んだ契約を、廃するためであった。</span>
<span className="v" id="v11" data-v="11" data-xref="ゼパニヤ書 3:12; ルカによる福音書 2:38; 申命記 31:21"> そしてこれは、その日に廃された。そこで、わたしに目を注いでいた羊の商人らは、これが主の言葉であったことを知った。</span>
<span className="v" id="v12" data-v="12" data-xref="マタイによる福音書 26:15; 出エジプト記 21:32; ルカによる福音書 22:3–6"> わたしは彼らに向かって、「あなたがたがもし、よいと思うならば、わたしに賃銀を払いなさい。もし、いけなければやめなさい」と言ったので、彼らはわたしの賃銀として、銀三十シケルを量った。</span>
<span className="v" id="v13" data-v="13" data-xref="マタイによる福音書 27:3–10; 使徒行伝 1:18–19; イザヤ書 53:2–3"> 主はわたしに言われた、「彼らによって、わたしが値積られたその尊い価を、宮のさいせん箱に投げ入れよ」。わたしは銀三十シケルを取って、これを主の宮のさいせん箱に投げ入れた。</span>
<span className="v" id="v14" data-v="14" data-xref="イザヤ書 9:21; イザヤ書 11:13; 使徒行伝 23:7–10"> そしてわたしは結びという第二のつえを折った。これはユダとイスラエルの間の、兄弟関係を廃するためであった。</span>
</div>
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="イザヤ書 6:10–12; ルカによる福音書 11:40; エレミヤ書 2:26–27"> 主はわたしに言われた、「おまえはまた愚かな牧者の器を取れ。</span>
<span className="v" id="v16" data-v="16" data-xref="エゼキエル書 34:2–6; エレミヤ書 23:2; マタイによる福音書 23:2–4"> 見よ、わたしは地にひとりの牧者を起す。彼は滅ぼされる者を顧みず、迷える者を尋ねず、傷ついた者をいやさず、健やかな者を養わず、肥えた者の肉を食らい、そのひずめをさえ裂く者である。</span>
<span className="v" id="v17" data-v="17" data-xref="エレミヤ書 23:1; エゼキエル書 13:3; コリント人への第一の手紙 8:4"> <span className="pl pl-1">その羊の群れを捨てる愚かな牧者はわざわいだ。</span><br /><span className="pl pl-1">どうか、つるぎがその腕を撃ち、</span><br /><span className="pl pl-1">その右の目を撃つように。</span><br /><span className="pl pl-1">その腕は全く衰え、</span><br /><span className="pl pl-1">その右の目は全く見えなくなるように」。</span></span>
</div>

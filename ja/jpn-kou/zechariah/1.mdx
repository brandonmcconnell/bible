<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ネヘミヤ書 12:4; ゼカリヤ書 7:1; ゼカリヤ書 1:7"> ダリヨスの第二年の八月に、主の言葉がイドの子ベレキヤの子である預言者ゼカリヤに臨んだ、</span>
<span className="v" id="v2" data-v="2" data-xref="エレミヤ書 44:6; 哀歌 5:7; エゼキエル書 22:31"> 「主はあなたがたの先祖たちに対して、いたくお怒りになった。</span>
<span className="v" id="v3" data-v="3" data-xref="マラキ書 3:7; エレミヤ書 3:22; エレミヤ書 4:1"> それゆえ、万軍の主はこう仰せられると、彼らに告げよ。万軍の主は仰せられる、わたしに帰れ、そうすれば、わたしもあなたがたに帰ろうと、万軍の主は仰せられる。</span>
<span className="v" id="v4" data-v="4" data-xref="詩篇 78:8; 詩篇 106:6–7; エレミヤ書 35:15"> あなたがたの先祖たちのようであってはならない。先の預言者たちは、彼らにむかって叫んで言った、『万軍の主はこう仰せられる、悪い道を離れ、悪いおこないを捨てて帰れ』と。しかし彼らは聞きいれず、耳をわたしに傾けなかったと主は言われる。</span>
<span className="v" id="v5" data-v="5" data-xref="伝道の書 12:5; ヨブ記 14:10–12; 伝道の書 12:7"> あなたがたの先祖たち、彼らはどこにいるか。預言者たち、彼らは永遠に生きているのか。</span>
<span className="v" id="v6" data-v="6" data-xref="哀歌 2:17; 申命記 28:15; エゼキエル書 12:25–28"> しかしわたしのしもべである預言者たちに命じたわが言葉と、わが定めとは、あなたがたの先祖たちに及んだではないか。それで彼らは立ち返って言った、『万軍の主がわれわれの道にしたがい、おこないに従って、われわれに、なそうと思い定められたように、そのとおりされたのだ』と」。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="ゼカリヤ書 1:1"> ダリヨスの第二年の十一月、すなわちセバテという月の二十四日に、主の言葉がイドの子ベレキヤの子である預言者ゼカリヤに臨んだ。そしてゼカリヤは言った、</span>
<span className="v" id="v8" data-v="8" data-xref="ヨハネの黙示録 6:4; イザヤ書 55:13; ゼカリヤ書 13:7"> 「わたしは夜、見ていると、ひとりの人が赤馬に乗って、谷間にあるミルトスの木の中に立ち、その後に赤馬、栗毛の馬、白馬がいた。</span>
<span className="v" id="v9" data-v="9" data-xref="ゼカリヤ書 4:4–5; ゼカリヤ書 5:5; ゼカリヤ書 2:3"> その時わたしが『わが主よ、これらはなんですか』と尋ねると、わたしと語る天の使は言った、『これがなんであるか、あなたに示しましょう』。</span>
<span className="v" id="v10" data-v="10" data-xref="ゼカリヤ書 1:11; ゼカリヤ書 6:5–8; ヘブル人への手紙 1:14"> すると、ミルトスの木の中に立っている人が答えて、『これらは地を見回らせるために、主がつかわされた者です』と言うと、</span>
<span className="v" id="v11" data-v="11" data-xref="ゼカリヤ書 1:10; ゼカリヤ書 1:15; 詩篇 103:20–21"> 彼らは答えて、ミルトスの中に立っている主の使に言った、『われわれは地を見回ったが、全地はすべて平穏です』。</span>
<span className="v" id="v12" data-v="12" data-xref="ゼカリヤ書 7:5; エレミヤ書 29:10; 詩篇 102:13"> すると主の使は言った、『万軍の主よ、あなたは、いつまでエルサレムとユダの町々とを、あわれんで下さらないのですか。あなたはお怒りになって、すでに七十年になりました』。</span>
<span className="v" id="v13" data-v="13" data-xref="エレミヤ書 29:10; イザヤ書 40:1–2; エレミヤ書 30:10–22"> 主はわたしと語る天の使に、ねんごろな慰めの言葉をもって答えられた。</span>
<span className="v" id="v14" data-v="14" data-xref="ヨエル書 2:18; イザヤ書 40:1; ゼカリヤ書 1:17"> そこで、わたしと語る天の使は言った、『あなたは呼ばわって言いなさい。万軍の主はこう仰せられます、わたしはエルサレムのため、シオンのために、大いなるねたみを起し、</span>
<span className="v" id="v15" data-v="15" data-xref="エゼキエル書 25:12–17; エレミヤ書 51:24; イザヤ書 54:8"> 安らかにいる国々の民に対して、大いに怒る。なぜなら、わたしが少しばかり怒ったのに、彼らは、大いにこれを悩ましたからであると。</span>
<span className="v" id="v16" data-v="16" data-xref="ゼカリヤ書 8:3; エズラ記 6:14–15; ゼカリヤ書 2:10–11"> それゆえ、主はこう仰せられます、わたしはあわれみをもってエルサレムに帰る。わたしの家はその中に建てられ、測りなわはエルサレムに張られると、万軍の主は仰せられます。</span>
<span className="v" id="v17" data-v="17" data-xref="イザヤ書 51:3; ゼカリヤ書 2:12; ゼパニヤ書 3:15–17"> あなたはまた呼ばわって言いなさい。万軍の主はこう仰せられます、わが町々は再び良い物で満ちあふれ、主は再びシオンを慰め、再びエルサレムを選ぶ』と」。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="ヨシュア記 5:13; 列王紀下 24:1–20; ゼカリヤ書 5:9"> わたしが目をあげて見ていると、見よ、四つの角があった。</span>
<span className="v" id="v19" data-v="19" data-xref="ゼカリヤ書 1:21; ゼカリヤ書 8:14; ゼカリヤ書 2:2"> わたしと語る天の使に「これらはなんですか」と言うと、彼は答えて言った、「これらはユダ、イスラエルおよびエルサレムを散らした角です」。</span>
<span className="v" id="v20" data-v="20" data-xref="ゼカリヤ書 10:3–5; ゼカリヤ書 12:2–6; ゼカリヤ書 9:12–16"> その時、主は四人の鍛冶をわたしに示された。</span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 75:10; ゼカリヤ書 1:19; 詩篇 75:4–5"> わたしが「これらは何をするために来たのですか」と言うと、彼は答えた、「これらの角はユダを散らして、人にその頭をあげさせなかったものですが、この四人の者が来たのは彼らをおどし、かのユダの地にむかって角をあげ、これを散らした国々の民の角を投げうつためです」。</span>

<span className="v" id="v1" data-v="1" data-xref="箴言 24:23; ヤコブの手紙 2:9; レビ記 19:15"> わたしの兄弟たちよ。わたしたちの栄光の主イエス・キリストへの信仰を守るのに、分け隔てをしてはならない。</span>
<span className="v" id="v2" data-v="2" data-xref="ルカによる福音書 15:22; エステル記 3:10; エステル記 8:2"> たとえば、あなたがたの会堂に、金の指輪をはめ、りっぱな着物を着た人がはいって来ると同時に、みすぼらしい着物を着た貧しい人がはいってきたとする。</span>
<span className="v" id="v3" data-v="3" data-xref="コリント人への第二の手紙 8:9; ヤコブの手紙 2:6; ルカによる福音書 7:44–46"> その際、りっぱな着物を着た人に対しては、うやうやしく「どうぞ、こちらの良い席にお掛け下さい」と言い、貧しい人には、「あなたは、そこに立っていなさい。それとも、わたしの足もとにすわっているがよい」と言ったとしたら、</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネによる福音書 7:24; ヨブ記 34:19; マタイによる福音書 7:1–5"> あなたがたは、自分たちの間で差別立てをし、よからぬ考えで人をさばく者になったわけではないか。</span>
<span className="v" id="v5" data-v="5" data-xref="マタイによる福音書 5:3; ルカによる福音書 6:20; ヨハネの黙示録 2:9"> 愛する兄弟たちよ。よく聞きなさい。神は、この世の貧しい人たちを選んで信仰に富ませ、神を愛する者たちに約束された御国の相続者とされたではないか。</span>
<span className="v" id="v6" data-v="6" data-xref="箴言 17:5; コリント人への第一の手紙 11:22; 箴言 14:31"> しかるに、あなたがたは貧しい人をはずかしめたのである。あなたがたをしいたげ、裁判所に引きずり込むのは、富んでいる者たちではないか。</span>
<span className="v" id="v7" data-v="7" data-xref="ピリピ人への手紙 2:9–11; ヨハネの黙示録 13:5–6; テモテヘの第一の手紙 1:13"> あなたがたに対して唱えられた尊い御名を汚すのは、実に彼らではないか。</span>
<span className="v" id="v8" data-v="8" data-xref="レビ記 19:18; ガラテヤ人への手紙 5:14; マタイによる福音書 22:39"> しかし、もしあなたがたが、「自分を愛するように、あなたの隣り人を愛せよ」という聖書の言葉に従って、このきわめて尊い律法を守るならば、それは良いことである。</span>
<span className="v" id="v9" data-v="9" data-xref="レビ記 19:15; ヤコブの手紙 2:1–4; ヨハネの第一の手紙 3:4"> しかし、もし分け隔てをするならば、あなたがたは罪を犯すことになり、律法によって違反者として宣告される。</span>
<span className="v" id="v10" data-v="10" data-xref="ガラテヤ人への手紙 3:10; マタイによる福音書 5:18–19; 申命記 27:26"> なぜなら、律法をことごとく守ったとしても、その一つの点にでも落ち度があれば、全体を犯したことになるからである。</span>
<span className="v" id="v11" data-v="11" data-xref="出エジプト記 20:13–14; マタイによる福音書 5:21–28; 申命記 5:17–18"> たとえば、「姦淫するな」と言われたかたは、また「殺すな」とも仰せになった。そこで、たとい姦淫はしなくても、人殺しをすれば、律法の違反者になったことになる。</span>
<span className="v" id="v12" data-v="12" data-xref="ヤコブの手紙 1:25; ヤコブの手紙 2:8; ペテロの第二の手紙 1:4–8"> だから、自由の律法によってさばかるべき者らしく語り、かつ行いなさい。</span>
<span className="v" id="v13" data-v="13" data-xref="マタイによる福音書 5:7; マタイによる福音書 6:15; 箴言 21:13"> あわれみを行わなかった者に対しては、仮借のないさばきが下される。あわれみは、さばきにうち勝つ。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="マタイによる福音書 7:26–27; マタイによる福音書 7:21–23; ヤコブの手紙 1:22–25"> わたしの兄弟たちよ。ある人が自分には信仰があると称していても、もし行いがなかったら、なんの役に立つか。その信仰は彼を救うことができるか。</span>
<span className="v" id="v15" data-v="15" data-xref="ルカによる福音書 3:11; マタイによる福音書 25:35–40; イザヤ書 58:7"> ある兄弟または姉妹が裸でいて、その日の食物にもこと欠いている場合、</span>
<span className="v" id="v16" data-v="16" data-xref="箴言 3:27–28; ヨハネの第一の手紙 3:16–18; マタイによる福音書 25:42–45"> あなたがたのうち、だれかが、「安らかに行きなさい。暖まって、食べ飽きなさい」と言うだけで、そのからだに必要なものを何ひとつ与えなかったとしたら、なんの役に立つか。</span>
<span className="v" id="v17" data-v="17" data-xref="ヤコブの手紙 2:26; ペテロの第二の手紙 1:5–9; ヤコブの手紙 2:19–20"> 信仰も、それと同様に、行いを伴わなければ、それだけでは死んだものである。</span>
<span className="v" id="v18" data-v="18" data-xref="ヤコブの手紙 3:13; ヤコブの手紙 2:14; ガラテヤ人への手紙 5:6"> しかし、「ある人には信仰があり、またほかの人には行いがある」と言う者があろう。それなら、行いのないあなたの信仰なるものを見せてほしい。そうしたら、わたしの行いによって信仰を見せてあげよう。</span>
<span className="v" id="v19" data-v="19" data-xref="ルカによる福音書 4:34; マルコによる福音書 1:24; マタイによる福音書 8:29"> あなたは、神はただひとりであると信じているのか。それは結構である。悪霊どもでさえ、信じておののいている。</span>
<span className="v" id="v20" data-v="20" data-xref="ヤコブの手紙 2:17; ヤコブの手紙 2:26; 箴言 12:11"> ああ、愚かな人よ。行いを伴わない信仰のむなしいことを知りたいのか。</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 22:16–18; 創世記 22:9–12; ヨハネによる福音書 8:39"> わたしたちの父祖アブラハムは、その子イサクを祭壇にささげた時、行いによって義とされたのではなかったか。</span>
<span className="v" id="v22" data-v="22" data-xref="テサロニケ人への第一の手紙 1:3; ヘブル人への手紙 11:17–19; ガラテヤ人への手紙 5:6"> あなたが知っているとおり、彼においては、信仰が行いと共に働き、その行いによって信仰が全うされ、</span>
<span className="v" id="v23" data-v="23" data-xref="創世記 15:6; イザヤ書 41:8; 歴代志下 20:7"> こうして、「アブラハムは神を信じた。それによって、彼は義と認められた」という聖書の言葉が成就し、そして、彼は「神の友」と唱えられたのである。</span>
<span className="v" id="v24" data-v="24" data-xref="ヤコブの手紙 2:21–22; ヤコブの手紙 2:15–18; 詩篇 60:12"> これでわかるように、人が義とされるのは、行いによるのであって、信仰だけによるのではない。</span>
<span className="v" id="v25" data-v="25" data-xref="ヘブル人への手紙 11:31; ヨシュア記 6:22–25; ヨシュア記 2:19–21"> 同じように、かの遊女ラハブでさえも、使者たちをもてなし、彼らを別な道から送り出した時、行いによって義とされたではないか。</span>
<span className="v" id="v26" data-v="26" data-xref="ヤコブの手紙 2:20; ヤコブの手紙 2:17; ヤコブの手紙 2:14"> 霊魂のないからだが死んだものであると同様に、行いのない信仰も死んだものなのである。</span>

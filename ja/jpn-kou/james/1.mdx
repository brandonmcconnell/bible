<div className="bible-chapter" lang="ja" dir="ltr" data-lang="ja" data-translation="jpn-kou" data-translation-id="jpn_kou" data-translation-label="口語訳" data-book="JAS" data-book-slug="james" data-book-name="ヤコブの手紙" data-chapter="1" data-verses="27">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="エゼキエル書 12:15; ペテロの第一の手紙 1:1; ヨハネによる福音書 7:35"> 神と主イエス・キリストとの僕ヤコブから、離散している十二部族の人々へ、あいさつをおくる。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="ペテロの第一の手紙 1:6–8; ヤコブの手紙 1:12; コリント人への第二の手紙 12:9–10"> わたしの兄弟たちよ。あなたがたが、いろいろな試錬に会った場合、それをむしろ非常に喜ばしいことと思いなさい。</span>
<span className="v" id="v3" data-v="3" data-xref="ローマ人への手紙 5:3–4; ヘブル人への手紙 10:36; コロサイ人への手紙 1:11"> あなたがたの知っているとおり、信仰がためされることによって、忍耐が生み出されるからである。</span>
<span className="v" id="v4" data-v="4" data-xref="ルカによる福音書 21:19; ペテロの第一の手紙 5:10; マタイによる福音書 5:48"> だから、なんら欠点のない、完全な、でき上がった人となるように、その忍耐力を十分に働かせるがよい。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="箴言 2:3–6; ヨハネによる福音書 15:7; 箴言 3:5–7"> あなたがたのうち、知恵に不足している者があれば、その人は、とがめもせずに惜しみなくすべての人に与える神に、願い求めるがよい。そうすれば、与えられるであろう。</span>
<span className="v" id="v6" data-v="6" data-xref="マタイによる福音書 21:21–22; ヘブル人への手紙 11:6; マルコによる福音書 11:22–24"> ただ、疑わないで、信仰をもって願い求めなさい。疑う人は、風の吹くままに揺れ動く海の波に似ている。</span>
<span className="v" id="v7" data-v="7" data-xref="ヤコブの手紙 4:3; イザヤ書 58:3–4; 箴言 21:27"> そういう人は、主から何かをいただけるもののように思うべきではない。</span>
<span className="v" id="v8" data-v="8" data-xref="列王紀上 18:21; マタイによる福音書 6:24; ヤコブの手紙 4:8"> そんな人間は、二心の者であって、そのすべての行動に安定がない。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="エレミヤ書 9:23–24; ヤコブの手紙 2:5–6; 箴言 19:1"> 低い身分の兄弟は、自分が高くされたことを喜びなさい。</span>
<span className="v" id="v10" data-v="10" data-xref="ペテロの第一の手紙 1:24; ヨハネの第一の手紙 2:17; ヨブ記 14:2"> また、富んでいる者は、自分が低くされたことを喜ぶがよい。富んでいる者は、草花のように過ぎ去るからである。</span>
<span className="v" id="v11" data-v="11" data-xref="イザヤ書 40:7–8; 詩篇 37:35–36; 詩篇 49:6–14"> たとえば、太陽が上って熱風をおくると、草を枯らす。そしてその花は落ち、その美しい姿は消えうせてしまう。それと同じように、富んでいる者も、その一生の旅なかばで没落するであろう。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="ペテロの第一の手紙 5:10; ペテロの第一の手紙 1:6–8; ヨハネの黙示録 2:10"> 試錬を耐え忍ぶ人は、さいわいである。それを忍びとおしたなら、神を愛する者たちに約束されたいのちの冠を受けるであろう。</span>
<span className="v" id="v13" data-v="13" data-xref="ハバクク書 2:12–13; ヤコブの手紙 1:12; ローマ人への手紙 9:19–20"> だれでも誘惑に会う場合、「この誘惑は、神からきたものだ」と言ってはならない。神は悪の誘惑に陥るようなかたではなく、また自ら進んで人を誘惑することもなさらない。</span>
<span className="v" id="v14" data-v="14" data-xref="マルコによる福音書 7:21–22; エペソ人への手紙 4:22; マタイによる福音書 15:18"> 人が誘惑に陥るのは、それぞれ、欲に引かれ、さそわれるからである。</span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 7:14; ヨブ記 15:35; ローマ人への手紙 5:12–21"> 欲がはらんで罪を生み、罪が熟して死を生み出す。</span>
<span className="v" id="v16" data-v="16" data-xref="ガラテヤ人への手紙 6:7; ヤコブの手紙 1:19; ピリピ人への手紙 2:12"> 愛する兄弟たちよ。思い違いをしてはいけない。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="ヨハネによる福音書 3:27; マタイによる福音書 7:11; ヘブル人への手紙 13:8"> あらゆる良い贈り物、あらゆる完全な賜物は、上から、光の父から下って来る。父には、変化とか回転の影とかいうものはない。</span>
<span className="v" id="v18" data-v="18" data-xref="ローマ人への手紙 8:29–31; ペテロの第一の手紙 1:23; ヨハネによる福音書 3:3–5"> 父は、わたしたちを、いわば被造物の初穂とするために、真理の言葉によって御旨のままに、生み出して下さったのである。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="箴言 17:27; 箴言 21:23; 箴言 14:29"> 愛する兄弟たちよ。このことを知っておきなさい。人はすべて、聞くに早く、語るにおそく、怒るにおそくあるべきである。</span>
<span className="v" id="v20" data-v="20" data-xref="テモテヘの第二の手紙 2:24–25; エペソ人への手紙 4:26; ヤコブの手紙 3:17–18"> 人の怒りは、神の義を全うするものではないからである。</span>
<span className="v" id="v21" data-v="21" data-xref="エペソ人への手紙 4:22; エペソ人への手紙 1:13; ペテロの第一の手紙 2:11"> だから、すべての汚れや、はなはだしい悪を捨て去って、心に植えつけられている御言を、すなおに受け入れなさい。御言には、あなたがたのたましいを救う力がある。</span>
<span className="v" id="v22" data-v="22" data-xref="ローマ人への手紙 2:13; ルカによる福音書 6:46–48; ヨハネによる福音書 13:17"> そして、御言を行う人になりなさい。おのれを欺いて、ただ聞くだけの者となってはいけない。</span>
<span className="v" id="v23" data-v="23" data-xref="マタイによる福音書 7:26–27; エゼキエル書 33:31–32; ヤコブの手紙 2:14–26"> おおよそ御言を聞くだけで行わない人は、ちょうど、自分の生れつきの顔を鏡に映して見る人のようである。</span>
<span className="v" id="v24" data-v="24" data-xref="ペテロの第二の手紙 3:11; ルカによる福音書 1:66; ルカによる福音書 7:39"> 彼は自分を映して見てそこから立ち去ると、そのとたんに、自分の姿がどんなであったかを忘れてしまう。</span>
<span className="v" id="v25" data-v="25" data-xref="ルカによる福音書 11:28; ヨハネによる福音書 13:17; コリント人への第二の手紙 3:17–18"> これに反して、完全な自由の律法を一心に見つめてたゆまない人は、聞いて忘れてしまう人ではなくて、実際に行う人である。こういう人は、その行いによって祝福される。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="エペソ人への手紙 4:29; 詩篇 141:3; ペテロの第一の手紙 3:10"> もし人が信心深い者だと自任しながら、舌を制することをせず、自分の心を欺いているならば、その人の信心はむなしいものである。</span>
<span className="v" id="v27" data-v="27" data-xref="イザヤ書 1:16–17; ヨハネの第一の手紙 3:17–19; ガラテヤ人への手紙 6:9–10"> 父なる神のみまえに清く汚れのない信心とは、困っている孤児や、やもめを見舞い、自らは世の汚れに染まずに、身を清く保つことにほかならない。</span>
</div>
</div>

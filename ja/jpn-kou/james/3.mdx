<span className="v" id="v1" data-v="1" data-xref="ルカによる福音書 12:47–48; テモテヘの第一の手紙 1:7; ペテロの第一の手紙 5:3"> わたしの兄弟たちよ。あなたがたのうち多くの者は、教師にならないがよい。わたしたち教師が、他の人たちよりも、もっときびしいさばきを受けることが、よくわかっているからである。</span>
<span className="v" id="v2" data-v="2" data-xref="ヤコブの手紙 1:26; 箴言 13:3; ペテロの第一の手紙 3:10"> わたしたちは皆、多くのあやまちを犯すものである。もし、言葉の上であやまちのない人があれば、そういう人は、全身をも制御することのできる完全な人である。</span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 32:9; 詩篇 39:1; ヤコブの手紙 1:26"> 馬を御するために、その口にくつわをはめるなら、その全身を引きまわすことができる。</span>
<span className="v" id="v4" data-v="4" data-xref="詩篇 107:25–27; マタイによる福音書 8:24; 使徒行伝 27:14–38"> また船を見るがよい。船体が非常に大きく、また激しい風に吹きまくられても、ごく小さなかじ一つで、操縦者の思いのままに運転される。</span>
<span className="v" id="v5" data-v="5" data-xref="箴言 18:21; エレミヤ書 9:3–8; 箴言 12:18"> それと同じく、舌は小さな器官ではあるが、よく大言壮語する。見よ、ごく小さな火でも、非常に大きな森を燃やすではないか。</span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 120:2–3; 箴言 16:27; マルコによる福音書 7:15"> 舌は火である。不義の世界である。舌は、わたしたちの器官の一つとしてそなえられたものであるが、全身を汚し、生存の車輪を燃やし、自らは地獄の火で焼かれる。</span>
<span className="v" id="v7" data-v="7" data-xref="マルコによる福音書 5:4"> あらゆる種類の獣、鳥、這うもの、海の生物は、すべて人類に制せられるし、また制せられてきた。</span>
<span className="v" id="v8" data-v="8" data-xref="ローマ人への手紙 3:13; 詩篇 140:3; 詩篇 55:21"> ところが、舌を制しうる人は、ひとりもいない。それは、制しにくい悪であって、死の毒に満ちている。</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 10:7; 創世記 1:26–27; 詩篇 62:4"> わたしたちは、この舌で父なる主をさんびし、また、その同じ舌で、神にかたどって造られた人間をのろっている。</span>
<span className="v" id="v10" data-v="10" data-xref="ローマ人への手紙 12:14; ペテロの第一の手紙 3:9; コリント人への第一の手紙 3:3"> 同じ口から、さんびとのろいとが出て来る。わたしの兄弟たちよ。このような事は、あるべきでない。</span>
<span className="v" id="v11" data-v="11"> 泉が、甘い水と苦い水とを、同じ穴からふき出すことがあろうか。</span>
<span className="v" id="v12" data-v="12" data-xref="ルカによる福音書 6:43–44; マタイによる福音書 12:33; マタイによる福音書 7:16–20"> わたしの兄弟たちよ。いちじくの木がオリブの実を結び、ぶどうの木がいちじくの実を結ぶことができようか。塩水も、甘い水を出すことはできない。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="ガラテヤ人への手紙 5:23; ヤコブの手紙 3:17; マタイによる福音書 5:5"> あなたがたのうちで、知恵があり物わかりのよい人は、だれであるか。その人は、知恵にかなう柔和な行いをしていることを、よい生活によって示すがよい。</span>
<span className="v" id="v14" data-v="14" data-xref="ヤコブの手紙 3:16; コリント人への第一の手紙 13:4; ピリピ人への手紙 2:3"> しかし、もしあなたがたの心の中に、苦々しいねたみや党派心をいだいているのなら、誇り高ぶってはならない。また、真理にそむいて偽ってはならない。</span>
<span className="v" id="v15" data-v="15" data-xref="ヤコブの手紙 3:17; ヤコブの手紙 1:17; コリント人への第一の手紙 3:19"> そのような知恵は、上から下ってきたものではなくて、地につくもの、肉に属するもの、悪魔的なものである。</span>
<span className="v" id="v16" data-v="16" data-xref="ヤコブの手紙 3:14; コリント人への第一の手紙 3:3; コリント人への第一の手紙 14:33"> ねたみと党派心とのあるところには、混乱とあらゆる忌むべき行為とがある。</span>
<span className="v" id="v17" data-v="17" data-xref="ガラテヤ人への手紙 5:22–23; 箴言 2:6; コリント人への第一の手紙 13:4–7"> しかし上からの知恵は、第一に清く、次に平和、寛容、温順であり、あわれみと良い実とに満ち、かたより見ず、偽りがない。</span>
<span className="v" id="v18" data-v="18" data-xref="マタイによる福音書 5:9; ホセア書 10:12; ピリピ人への手紙 1:11"> 義の実は、平和を造り出す人たちによって、平和のうちにまかれるものである。</span>

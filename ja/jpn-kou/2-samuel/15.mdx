<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀上 1:5; サムエル記下 12:11; サムエル記上 8:11"> この後、アブサロムは自分のために戦車と馬、および自分の前に駆ける者五十人を備えた。</span>
<span className="v" id="v2" data-v="2" data-xref="出エジプト記 18:14; ルツ記 4:1; ヨブ記 24:14"> アブサロムは早く起きて門の道のかたわらに立つのを常とした。人が訴えがあって王に裁判を求めに来ると、アブサロムはその人を呼んで言った、「あなたはどの町の者ですか」。その人が「しもべはイスラエルのこれこれの部族のものです」と言うと、</span>
<span className="v" id="v3" data-v="3" data-xref="サムエル記下 8:15; エゼキエル書 22:7; ペテロの第一の手紙 2:17"> アブサロムはその人に言った、「見よ、あなたの要求は良く、また正しい。しかしあなたのことを聞くべき人は王がまだ立てていない」。</span>
<span className="v" id="v4" data-v="4" data-xref="士師記 9:29; 士師記 9:1–5; 箴言 27:2"> アブサロムはまた言った、「ああ、わたしがこの地のさばきびとであったならばよいのに。そうすれば訴え、または申立てのあるものは、皆わたしの所にきて、わたしはこれに公平なさばきを行うことができるのだが」。</span>
<span className="v" id="v5" data-v="5" data-xref="サムエル記下 14:33; 詩篇 55:21; 箴言 26:25"> そして人が彼に敬礼しようとして近づくと、彼は手を伸べ、その人を抱きかかえて口づけした。</span>
<span className="v" id="v6" data-v="6" data-xref="ローマ人への手紙 16:18; ペテロの第二の手紙 2:3; 箴言 11:9"> アブサロムは王にさばきを求めて来るすべてのイスラエルびとにこのようにした。こうしてアブサロムはイスラエルの人々の心を自分のものとした。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="イザヤ書 58:4; サムエル記上 16:13; サムエル記上 16:1–2"> そして四年の終りに、アブサロムは王に言った、「どうぞわたしを行かせ、ヘブロンで、かつて主に立てた誓いを果させてください。</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 28:20–21; サムエル記下 13:37–38; サムエル記上 1:11"> それは、しもべがスリヤのゲシュルにいた時、誓いを立てて、『もし主がほんとうにわたしをエルサレムに連れ帰ってくださるならば、わたしは主に礼拝をささげます』と言ったからです」。</span>
<span className="v" id="v9" data-v="9"> 王が彼に、「安らかに行きなさい」と言ったので、彼は立ってヘブロンへ行った。</span>
<span className="v" id="v10" data-v="10" data-xref="歴代志上 12:38; サムエル記下 5:5; サムエル記下 3:2–3"> そしてアブサロムは密使をイスラエルのすべての部族のうちにつかわして言った、「ラッパの響きを聞くならば、『アブサロムがヘブロンで王となった』と言いなさい」。</span>
<span className="v" id="v11" data-v="11" data-xref="サムエル記上 9:13; サムエル記上 22:15; ローマ人への手紙 16:18–19"> 二百人の招かれた者がエルサレムからアブサロムと共に行った。彼らは何心なく行き、何事をも知らなかった。</span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 41:9; サムエル記下 15:31; ヨシュア記 15:51"> アブサロムは犠牲をささげている間に人をつかわして、ダビデの議官ギロびとアヒトペルを、その町ギロから呼び寄せた。徒党は強く、民はしだいにアブサロムに加わった。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="士師記 9:3; マタイによる福音書 27:22; サムエル記下 15:6"> ひとりの使者がダビデのところにきて、「イスラエルの人々の心はアブサロムに従いました」と言った。</span>
<span className="v" id="v14" data-v="14" data-xref="サムエル記下 19:9; エゼキエル書 46:18; 詩篇 55:3–11"> ダビデは、自分と一緒にエルサレムにいるすべての家来に言った、「立て、われわれは逃げよう。そうしなければアブサロムの前からのがれることはできなくなるであろう。急いで行くがよい。さもないと、彼らが急ぎ追いついて、われわれに害をこうむらせ、つるぎをもって町を撃つであろう」。</span>
<span className="v" id="v15" data-v="15" data-xref="ヨハネによる福音書 6:66–69; 箴言 18:24; ルカによる福音書 22:28–29"> 王のしもべたちは王に言った、「しもべたちは、わが主君、王の選ばれる所をすべて行います」。</span>
<span className="v" id="v16" data-v="16" data-xref="サムエル記下 16:21–22; サムエル記下 20:3; 詩篇 3:1"> こうして王は出て行き、その全家は彼に従った。王は十人のめかけを残して家を守らせた。</span>
<span className="v" id="v17" data-v="17" data-xref="詩篇 3:1–2; 伝道の書 10:7; 詩篇 66:12"> 王は出て行き、民はみな彼に従った。彼らは町はずれの家にとどまった。</span>
<span className="v" id="v18" data-v="18" data-xref="サムエル記下 8:18; サムエル記上 30:14; サムエル記下 20:7"> 彼のしもべたちは皆、彼のかたわらを進み、すべてのケレテびとと、すべてのペレテびと、および彼に従ってガテからきた六百人のガテびとは皆、王の前に進んだ。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="サムエル記下 18:2; ルツ記 1:11–13"> 時に王はガテびとイッタイに言った、「どうしてあなたもまた、われわれと共に行くのですか。あなたは帰って王と共にいなさい。あなたは外国人で、また自分の国から追放された者だからです。</span>
<span className="v" id="v20" data-v="20" data-xref="サムエル記上 23:13; サムエル記下 2:6; ヨハネによる福音書 1:17"> あなたは、きのう来たばかりです。わたしは自分の行く所を知らずに行くのに、どうしてきょう、あなたを、われわれと共にさまよわせてよいでしょう。あなたは帰りなさい。あなたの兄弟たちも連れて帰りなさい。どうぞ主が恵みと真実をあなたに示してくださるように」。</span>
<span className="v" id="v21" data-v="21" data-xref="ルツ記 1:16–17; 箴言 17:17; 列王紀下 4:30"> しかしイッタイは王に答えた、「主は生きておられる。わが君、王は生きておられる。わが君、王のおられる所に、死ぬも生きるも、しもべもまたそこにおります」。</span>
<span className="v" id="v22" data-v="22"> ダビデはイッタイに言った、「では進んで行きなさい」。そこでガテびとイッタイは進み、また彼のすべての従者および彼と共にいた子どもたちも皆、進んだ。</span>
<span className="v" id="v23" data-v="23" data-xref="サムエル記下 16:2; 列王紀上 2:37; ヨハネによる福音書 18:1"> 国中みな大声で泣いた。民はみな進んだ。王もまたキデロンの谷を渡って進み、民は皆進んで荒野の方に向かった。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="民数記 4:15; サムエル記下 8:17; サムエル記下 20:25"> そしてアビヤタルも上ってきた。見よ、ザドクおよび彼と共にいるすべてのレビびともまた、神の契約の箱をかいてきた。彼らは神の箱をおろして、民がことごとく町を出てしまうのを待った。</span>
<span className="v" id="v25" data-v="25" data-xref="エレミヤ書 25:30; 詩篇 26:8; 詩篇 43:3–4"> そこで王はザドクに言った、「神の箱を町にかきもどすがよい。もしわたしが主の前に恵みを得るならば、主はわたしを連れ帰って、わたしにその箱とそのすまいとを見させてくださるであろう。</span>
<span className="v" id="v26" data-v="26" data-xref="サムエル記上 3:18; サムエル記下 22:20; 列王紀上 10:9"> しかしもし主が、『わたしはおまえを喜ばない』とそう言われるのであれば、どうぞ主が良しと思われることをわたしにしてくださるように。わたしはここにおります」。</span>
<span className="v" id="v27" data-v="27" data-xref="サムエル記上 9:9; サムエル記下 17:17; サムエル記下 24:11"> 王はまた祭司ザドクに言った、「見よ、あなたもアビヤタルも、ふたりの子たち、すなわちあなたの子アヒマアズとアビヤタルの子ヨナタンを連れて、安らかに町に帰りなさい。</span>
<span className="v" id="v28" data-v="28" data-xref="サムエル記下 17:16; サムエル記下 15:23; サムエル記下 17:1"> わたしはあなたがたから言葉があって知らせをうけるまで、荒野の渡し場にとどまります」。</span>
<span className="v" id="v29" data-v="29"> そこでザドクとアビヤタルは神の箱をエルサレムにかきもどり、そこにとどまった。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="エステル記 6:12; サムエル記下 19:4; ルカによる福音書 19:41"> ダビデはオリブ山の坂道を登ったが、登る時に泣き、その頭をおおい、はだしで行った。彼と共にいる民もみな頭をおおって登り、泣きながら登った。</span>
<span className="v" id="v31" data-v="31" data-xref="サムエル記下 17:14; サムエル記下 17:23; ヤコブの手紙 3:15"> 時に、「アヒトペルがアブサロムと共謀した者のうちにいる」とダビデに告げる人があったのでダビデは言った、「主よ、どうぞアヒトペルの計略を愚かなものにしてください」。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="ヨシュア記 16:2; サムエル記下 1:2; 詩篇 3:3–5"> ダビデが山の頂にある神を礼拝する場所にきた時、見よ、アルキびとホシャイはその上着を裂き、頭に土をかぶり、来てダビデを迎えた。</span>
<span className="v" id="v33" data-v="33" data-xref="サムエル記下 19:35"> ダビデは彼に言った、「もしあなたがわたしと共に進むならば、わたしの重荷となるであろう。</span>
<span className="v" id="v34" data-v="34" data-xref="ヨシュア記 8:2; サムエル記下 16:16–19; マタイによる福音書 10:16"> しかしもしあなたが町に帰ってアブサロムに向かい、『王よ、わたしはあなたのしもべとなります。わたしがこれまで、あなたの父のしもべであったように、わたしは今あなたのしもべとなります』と言うならば、あなたはわたしのためにアヒトペルの計略を破ることができるであろう。</span>
<span className="v" id="v35" data-v="35" data-xref="サムエル記下 17:15–16"> 祭司たち、ザドクとアビヤタルとは、あなたと共にあそこにいるではないか。それゆえ、あなたは王の家から聞くことをことごとく祭司たち、ザドクとアビヤタルとに告げなさい。</span>
<span className="v" id="v36" data-v="36" data-xref="サムエル記下 17:17; サムエル記下 15:27; サムエル記下 18:19–33"> あそこには彼らと共にそのふたりの子たち、すなわちザドクの子アヒマアズとアビヤタルの子ヨナタンとがいる。あなたがたは聞いたことをことごとく彼らの手によってわたしに通報しなさい」。</span>
<span className="v" id="v37" data-v="37" data-xref="サムエル記下 16:15–16; 歴代志上 27:33"> そこでダビデの友ホシャイは町にはいった。その時アブサロムはすでにエルサレムにはいっていた。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="イザヤ書 59:7–8; 詩篇 109:2–4; 詩篇 3:3–5"> 時にアヒトペルはアブサロムに言った、「わたしに一万二千の人を選び出させてください。わたしは立って、今夜ダビデのあとを追い、</span>
<span className="v" id="v2" data-v="2" data-xref="サムエル記下 16:14; 列王紀上 22:31; ゼカリヤ書 13:7"> 彼が疲れて手が弱くなっているところを襲って、彼をあわてさせましょう。そして彼と共にいる民がみな逃げるとき、わたしは王ひとりを撃ち取り、</span>
<span className="v" id="v3" data-v="3" data-xref="テサロニケ人への第一の手紙 5:3; イザヤ書 48:22; イザヤ書 57:21"> すべての民を花嫁がその夫のもとに帰るようにあなたに帰らせましょう。あなたが求めておられるのはただひとりの命だけですから、民はみな穏やかになるでしょう」。</span>
<span className="v" id="v4" data-v="4" data-xref="サムエル記上 18:20–21; ローマ人への手紙 1:32; 歴代志下 30:4"> この言葉はアブサロムとイスラエルのすべての長老の心にかなった。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="サムエル記下 15:32–37; サムエル記下 16:16–19"> そこでアブサロムは言った、「アルキびとホシャイをも呼びよせなさい。われわれは彼の言うことを聞きましょう」。</span>
<span className="v" id="v6" data-v="6"> ホシャイがアブサロムのもとにきた時、アブサロムは彼に言った、「アヒトペルはこのように言った。われわれは彼の言葉のように行うべきか。いけないのであれば、言いなさい」。</span>
<span className="v" id="v7" data-v="7" data-xref="箴言 31:8"> ホシャイはアブサロムに言った、「このたびアヒトペルが授けた計りごとは良くありません」。</span>
<span className="v" id="v8" data-v="8" data-xref="ホセア書 13:8; サムエル記上 16:18; ヘブル人への手紙 11:32–34"> ホシャイはまた言った、「ごぞんじのように、あなたの父とその従者たちとは勇士です。その上彼らは、野で子を奪われた熊のように、ひどく怒っています。また、あなたの父はいくさびとですから、民と共に宿らないでしょう。</span>
<span className="v" id="v9" data-v="9" data-xref="サムエル記上 24:3; サムエル記上 14:14–15; 士師記 20:32–33"> 彼は今でも穴の中か、どこかほかの所にかくれています。もし民のうちの幾人かが手始めに倒れるならば、それを聞く者はだれでも、『アブサロムに従う民のうちに戦死者があった』と言うでしょう。</span>
<span className="v" id="v10" data-v="10" data-xref="ヨシュア記 2:9–11; 出エジプト記 15:15; 創世記 49:9"> そうすれば、ししの心のような心のある勇ましい人であっても、恐れて消え去ってしまうでしょう。それはイスラエルのすべての人が、あなたの父の勇士であること、また彼と共にいる者が、勇ましい人々であることを知っているからです。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 22:17; 士師記 20:1; 詩篇 9:16"> ところでわたしの計りごとは、イスラエルをダンからベエルシバまで、海べの砂のように多くあなたのもとに集めて、あなたみずから戦いに臨むことです。</span>
<span className="v" id="v12" data-v="12" data-xref="サムエル記上 23:23; オバデヤ書 1:3; 列王紀上 20:10"> こうしてわれわれは彼の見つかる場所で彼を襲い、つゆが地におりるように彼の上に下る。そして彼および彼と共にいるすべての人をひとりも残さないでしょう。</span>
<span className="v" id="v13" data-v="13" data-xref="マタイによる福音書 24:2; ミカ書 1:6"> もし彼がいずれかの町に退くならば、全イスラエルはその町になわをかけ、われわれはそれを谷に引き倒して、そこに一つの小石も見られないようにするでしょう」。</span>
<span className="v" id="v14" data-v="14" data-xref="サムエル記下 15:34; コリント人への第一の手紙 1:19–20; 箴言 19:21"> アブサロムとイスラエルの人々はみな、「アルキびとホシャイの計りごとは、アヒトペルの計りごとよりもよい」と言った。それは主がアブサロムに災を下そうとして、アヒトペルの良い計りごとを破ることを定められたからである。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="サムエル記下 15:35–36"> そこでホシャイは祭司たち、ザドクとアビヤタルとに言った、「アヒトペルはアブサロムとイスラエルの長老たちのためにこういう計りごとをした。またわたしはこういう計りごとをした。</span>
<span className="v" id="v16" data-v="16" data-xref="サムエル記下 15:28; コリント人への第一の手紙 15:54; コリント人への第二の手紙 5:4"> それゆえ、あなたがたはすみやかに人をつかわしてダビデに告げ、『今夜、荒野の渡し場に宿らないで、必ず渡って行きなさい。さもないと王および共にいる民はみな、滅ぼされるでしょう』と言いなさい」。</span>
<span className="v" id="v17" data-v="17" data-xref="サムエル記下 15:36; ヨシュア記 18:16; サムエル記下 15:27"> 時に、ヨナタンとアヒマアズはエンロゲルで待っていた。ひとりのつかえめが行って彼らに告げ、彼らは行ってダビデ王に告げるのが常であった。それは彼らが町にはいるのを見られないようにするためである。</span>
<span className="v" id="v18" data-v="18" data-xref="サムエル記下 3:16; サムエル記下 16:5; サムエル記下 19:16"> ところがひとりの若者が彼らを見てアブサロムに告げたので、彼らふたりは急いで去り、バホリムの、あるひとりの人の家にきた。その人の庭に井戸があって、彼らはその中に下ったので、</span>
<span className="v" id="v19" data-v="19" data-xref="出エジプト記 1:19; ヨシュア記 2:4–24"> 女はおおいを取ってきて井戸の口の上にひろげ、麦をその上にまき散らした。それゆえその事は何も知れなかった。</span>
<span className="v" id="v20" data-v="20" data-xref="出エジプト記 1:19; ヨシュア記 2:22–23; サムエル記上 19:12–17"> アブサロムのしもべたちはその女の家にきて言った、「アヒマアズとヨナタンはどこにいますか」。女は彼らに言った、「あの人々は小川を渡って行きました」。彼らは尋ねたが見当らなかったのでエルサレムに帰った。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="サムエル記下 17:15–16"> 彼らが去った後、人々は井戸から上り、行ってダビデ王に告げた。すなわち彼らはダビデに言った、「立って、すみやかに川を渡りなさい。アヒトペルがあなたがたに対してこういう計りごとをしたからです」。</span>
<span className="v" id="v22" data-v="22" data-xref="マタイによる福音書 10:16; ヨハネによる福音書 18:9; 箴言 27:12"> そこでダビデは立って、共にいるすべての民と一緒にヨルダンを渡った。夜明けには、ヨルダンを渡らない者はひとりもなかった。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="マタイによる福音書 27:5; 列王紀下 20:1; サムエル記下 15:12"> アヒトペルは、自分の計りごとが行われないのを見て、ろばにくらを置き、立って自分の町に行き、その家に帰った。そして家の人に遺言してみずからくびれて死に、その父の墓に葬られた。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="創世記 32:2; サムエル記下 2:8; ヨシュア記 13:26"> ダビデはマハナイムにきた。またアブサロムは自分と共にいるイスラエルのすべての人々と一緒にヨルダンを渡った。</span>
<span className="v" id="v25" data-v="25" data-xref="歴代志上 2:13; サムエル記下 19:13; サムエル記下 20:9–12"> アブサロムはアマサをヨアブの代りに軍の長とした。アマサはかのナハシの娘でヨアブの母ゼルヤの妹であるアビガルをめとったイシマエルびと、名はイトラという人の子である。</span>
<span className="v" id="v26" data-v="26" data-xref="ヨシュア記 17:1; 申命記 3:15; 民数記 32:1–42"> そしてイスラエルとアブサロムはギレアデの地に陣取った。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="列王紀上 2:7; サムエル記下 10:1–2; サムエル記下 9:4"> ダビデがマハナイムにきた時、アンモンの人々のうちのラバのナハシの子ショビと、ロ・デバルのアンミエルの子マキル、およびロゲリムのギレアデびとバルジライは、</span>
<span className="v" id="v28" data-v="28" data-xref="サムエル記上 25:18; オバデヤ書 1:3; サムエル記下 16:1–2"> 寝床と鉢、土器、小麦、大麦、粉、いり麦、豆、レンズ豆、</span>
<span className="v" id="v29" data-v="29" data-xref="サムエル記下 16:2; イザヤ書 21:14; サムエル記下 16:14"> 蜜、凝乳、羊、乾酪をダビデおよび共にいる民が食べるために持ってきた。それは彼らが、「民は荒野で飢え疲れかわいている」と思ったからである。</span>
</div>

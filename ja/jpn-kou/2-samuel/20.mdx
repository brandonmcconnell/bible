<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀上 12:16; 歴代志下 10:16; 申命記 13:13"> さて、その所にひとりのよこしまな人があって、名をシバといった。ビクリの子で、ベニヤミンびとであった。彼はラッパを吹いて言った、「われわれはダビデのうちに分がない。またエッサイの子のうちに嗣業を持たない。イスラエルよ、おのおのその天幕に帰りなさい」。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネによる福音書 6:66–68; 使徒行伝 11:23; サムエル記下 19:15"> そこでイスラエルの人々は皆ダビデに従う事をやめて、ビクリの子シバに従った。しかしユダの人々はその王につき従って、ヨルダンからエルサレムへ行った。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="サムエル記下 16:21–22; サムエル記下 15:16; 創世記 40:3"> ダビデはエルサレムの自分の家にきた。そして王は家を守るために残しておいた十人のめかけたちを取って、一つの家に入れて守り、また養ったが、彼女たちの所には、はいらなかった。彼女たちは死ぬ日まで閉じこめられ一生、寡婦としてすごした。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="サムエル記下 19:13; サムエル記下 17:25; 歴代志上 2:17"> 王はアマサに言った、「わたしのため三日のうちにユダの人々を呼び集めて、ここにきなさい」。</span>
<span className="v" id="v5" data-v="5" data-xref="サムエル記下 19:13; サムエル記上 13:8"> アマサはユダを呼び集めるために行ったが、彼は定められた時よりもおくれた。</span>
<span className="v" id="v6" data-v="6" data-xref="サムエル記下 21:17; サムエル記下 11:11; 列王紀上 1:33"> ダビデはアビシャイに言った、「ビクリの子シバは今われわれにアブサロムよりも多くの害をするであろう。あなたの主君の家来たちを率いて、彼のあとを追いなさい。さもないと彼は堅固な町々を獲て、われわれを悩ますであろう」。</span>
<span className="v" id="v7" data-v="7" data-xref="サムエル記下 8:18; 列王紀上 1:38; サムエル記下 20:23"> こうしてヨアブとケレテびととペレテびと、およびすべての勇士はアビシャイに従って出た。すなわち彼らはエルサレムを出て、ビクリの子シバのあとを追った。</span>
<span className="v" id="v8" data-v="8" data-xref="サムエル記下 3:30; サムエル記下 2:13; サムエル記下 20:4–5"> 彼らがギベオンにある大石のところにいた時、アマサがきて彼らに会った。時にヨアブは軍服を着て、帯をしめ、その上にさやに納めたつるぎを腰に結んで帯びていたが、彼が進み出た時つるぎは抜け落ちた。</span>
<span className="v" id="v9" data-v="9" data-xref="ルカによる福音書 22:47–48; マタイによる福音書 26:48–49; ミカ書 7:2"> ヨアブはアマサに、「兄弟よ、あなたは安らかですか」と言って、ヨアブは右の手をもってアマサのひげを捕えて彼に口づけしようとしたが、</span>
<span className="v" id="v10" data-v="10" data-xref="サムエル記下 2:23; サムエル記下 3:27; 士師記 3:21"> アマサはヨアブの手につるぎがあることに気づかなかったので、ヨアブはそれをもってアマサの腹部を刺して、そのはらわたを地に流し出し、重ねて撃つこともなく彼を殺した。<br />こうしてヨアブとその兄弟アビシャイはビクリの子シバのあとを追った。</span>
<span className="v" id="v11" data-v="11" data-xref="サムエル記下 20:13; サムエル記下 20:21; 列王紀下 9:32"> 時にヨアブの若者のひとりがアマサのかたわらに立って言った、「ヨアブに味方する者、ダビデにつく者はヨアブのあとに従いなさい」。</span>
<span className="v" id="v12" data-v="12" data-xref="箴言 24:21–22; 詩篇 9:16; サムエル記下 17:25"> アマサは血に染んで大路の中にころがっていたので、そのそばに来る者はみな彼を見て立ちどまった。この人は民がみな立ちどまるのを見て、アマサを大路から畑に移し、衣服をその上にかけた。</span>
<span className="v" id="v13" data-v="13" data-xref="サムエル記上 6:12; イザヤ書 7:3; 列王紀下 18:17"> アマサが大路から移されたので、民は皆ヨアブに従って進み、ビクリの子シバのあとを追った。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="列王紀下 15:29; 列王紀上 15:20; 歴代志下 16:4"> シバはイスラエルのすべての部族のうちを通ってベテマアカのアベルにきた。ビクリびとは皆、集まってきて彼に従った。</span>
<span className="v" id="v15" data-v="15" data-xref="列王紀下 19:32; エレミヤ書 32:24; 列王紀上 15:20"> そこでヨアブと共にいたすべての人々がきて、彼をベテマアカのアベルに囲み、町に向かって土塁を築いた。それはとりでに向かって立てられた。こうして彼らは城壁をくずそうとしてこれを撃った。</span>
<span className="v" id="v16" data-v="16" data-xref="サムエル記下 14:2; 伝道の書 9:14–18; サムエル記上 25:32–33"> その時、ひとりの賢い女が町から呼ばわった、「あなたがたは聞きなさい。あなたがたは聞きなさい。ヨアブに、『ここにきてください。わたしはあなたに言うことがあります』と言ってください」。</span>
<span className="v" id="v17" data-v="17" data-xref="サムエル記下 14:12; サムエル記上 25:24"> 彼がその女に近寄ると、女は「あなたがヨアブですか」と言った。彼は「そうです」と答えた。すると女は彼に「はしための言葉をお聞きください」と言ったので、「聞きましょう」と彼は言った。</span>
<span className="v" id="v18" data-v="18" data-xref="申命記 20:10–11"> そこで女は言った、「昔、人々はいつも、『アベルで尋ねなさい』と言って、事を定めました。</span>
<span className="v" id="v19" data-v="19" data-xref="サムエル記上 26:19; サムエル記下 21:3; サムエル記下 17:16"> わたしはイスラエルのうちの平和な、忠誠な者です。そうであるのに、あなたはイスラエルのうちで母ともいうべき町を滅ぼそうとしておられます。どうして主の嗣業を、のみ尽そうとされるのですか」。</span>
<span className="v" id="v20" data-v="20" data-xref="ルカによる福音書 10:29; 箴言 28:13; エレミヤ書 17:9"> ヨアブは答えた、「いいえ、決してそうではなく、わたしが、のみ尽したり、滅ぼしたりすることはありません。</span>
<span className="v" id="v21" data-v="21" data-xref="サムエル記上 26:9; 士師記 2:9; サムエル記下 17:2–3"> 事実はそうではなく、エフライムの山地の人ビクリの子、名をシバという者が手をあげて王ダビデにそむいたのです。あなたがたが彼ひとりを渡すならば、わたしはこの町を去ります」。女はヨアブに言った、「彼の首は城壁の上からあなたの所へ投げられるでしょう」。</span>
<span className="v" id="v22" data-v="22" data-xref="サムエル記下 20:1; 伝道の書 7:19; サムエル記下 11:6–21"> こうしてこの女が知恵をもって、すべての民の所に行ったので、彼らはビクリの子シバの首をはねてヨアブの所へ投げ出した。そこでヨアブはラッパを吹きならしたので、人々は散って町を去り、おのおの家に帰った。ヨアブはエルサレムにいる王のもとに帰った。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="サムエル記下 8:16–18; 歴代志上 18:15–17; 列王紀上 4:3–6"> ヨアブはイスラエルの全軍の長であった。エホヤダの子ベナヤはケレテびと、およびペレテびとの長、</span>
<span className="v" id="v24" data-v="24" data-xref="列王紀上 4:3; 列王紀上 12:18; 列王紀上 4:6"> アドラムは徴募人の長、アヒルデの子ヨシャパテは史官、</span>
<span className="v" id="v25" data-v="25" data-xref="列王紀上 4:4; サムエル記下 8:17; 歴代志上 18:16"> シワは書記官、ザドクとアビヤタルとは祭司。</span>
<span className="v" id="v26" data-v="26" data-xref="サムエル記下 23:38; 出エジプト記 2:14; 創世記 41:45"> またヤイルびとイラはダビデの祭司であった。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="サムエル記上 30:31; サムエル記上 23:4; 創世記 32:2"> この後、ダビデは主に問うて言った、「わたしはユダの一つの町に上るべきでしょうか」。主は彼に言われた、「上りなさい」。ダビデは言った、「どこへ上るべきでしょうか」。主は言われた、「ヘブロンへ」。</span>
<span className="v" id="v2" data-v="2" data-xref="サムエル記上 25:42–43; サムエル記上 30:5; ルカによる福音書 22:28–29"> そこでダビデはその所へ上った。彼のふたりの妻、エズレルの女アヒノアムと、カルメルびとナバルの妻であったアビガイルも上った。</span>
<span className="v" id="v3" data-v="3" data-xref="サムエル記上 30:1; 歴代志上 12:1–7; サムエル記上 27:2–3"> ダビデはまた自分と共にいた人々を、皆その家族と共に連れて上った。そして彼らはヘブロンの町々に住んだ。</span>
<span className="v" id="v4" data-v="4" data-xref="サムエル記下 5:5; サムエル記上 31:11–13; サムエル記下 5:3"> 時にユダの人々がきて、その所でダビデに油を注ぎ、ユダの家の王とした。<br />人々がダビデに告げて、「サウルを葬ったのはヤベシ・ギレアデの人々である」と言ったので、</span>
<span className="v" id="v5" data-v="5" data-xref="サムエル記上 23:21; 詩篇 115:15; ルツ記 2:20"> ダビデは使者をヤベシ・ギレアデの人々につかわして彼らに言った、「あなたがたは、主君サウルにこの忠誠をあらわして彼を葬った。どうぞ主があなたがたを祝福されるように。</span>
<span className="v" id="v6" data-v="6" data-xref="箴言 14:22; 出エジプト記 34:6; マタイによる福音書 5:44"> どうぞ主がいまあなたがたに、いつくしみと真実を示されるように。あなたがたが、この事をしたので、わたしもまたあなたがたに好意を示すであろう。</span>
<span className="v" id="v7" data-v="7" data-xref="エペソ人への手紙 6:10; サムエル記下 10:12; 創世記 15:1"> 今あなたがたは手を強くし、雄々しくあれ。あなたがたの主君サウルは死に、ユダの家がわたしに油を注いで、彼らの王としたからである」。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="サムエル記上 14:50; 創世記 32:2; サムエル記下 3:7–8"> さてサウルの軍の長、ネルの子アブネルは、さきにサウルの子イシボセテを取り、マハナイムに連れて渡り、</span>
<span className="v" id="v9" data-v="9" data-xref="ヨシュア記 19:18; ヨシュア記 13:8–11; 民数記 1:40"> 彼をギレアデ、アシュルびと、エズレル、エフライム、ベニヤミンおよび全イスラエルの王とした。</span>
<span className="v" id="v10" data-v="10"> サウルの子イシボセテはイスラエルの王となった時、四十歳であって、二年の間、世を治めたが、ユダの家はダビデに従った。</span>
<span className="v" id="v11" data-v="11" data-xref="列王紀上 2:11; サムエル記下 5:4–5; 歴代志上 3:4"> ダビデがヘブロンにいてユダの家の王であった日数は七年と六か月であった。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="ヨシュア記 18:25; ヨシュア記 10:2; ヨシュア記 9:3"> ネルの子アブネル、およびサウルの子イシボセテの家来たちはマハナイムを出てギベオンへ行った。</span>
<span className="v" id="v13" data-v="13" data-xref="サムエル記下 8:16; 歴代志上 2:16; サムエル記下 20:23"> ゼルヤの子ヨアブとダビデの家来たちも出ていって、ギベオンの池のそばで彼らと出会い、一方は池のこちら側に、一方は池のあちら側にすわった。</span>
<span className="v" id="v14" data-v="14" data-xref="サムエル記下 2:17; 箴言 10:23; 箴言 17:14"> アブネルはヨアブに言った、「さあ、若者たちを立たせて、われわれの前で勝負をさせよう」。ヨアブは言った、「彼らを立たせよう」。</span>
<span className="v" id="v15" data-v="15"> こうしてサウルの子イシボセテとベニヤミンびととのために十二人、およびダビデの家来たち十二人を数えて出した。彼らは立って進み、</span>
<span className="v" id="v16" data-v="16"> おのおの相手の頭を捕え、つるぎを相手のわき腹に刺し、こうして彼らは共に倒れた。それゆえ、その所はヘルカテ・ハヅリムと呼ばれた。それはギベオンにある。</span>
<span className="v" id="v17" data-v="17" data-xref="サムエル記下 3:1"> その日、戦いはひじょうに激しく、アブネルとイスラエルの人々はダビデの家来たちの前に敗れた。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="歴代志上 12:8; ハバクク書 3:19; 雅歌 8:14"> その所にゼルヤの三人の子、ヨアブ、アビシャイ、およびアサヘルがいたが、アサヘルは足の早いこと、野のかもしかのようであった。</span>
<span className="v" id="v19" data-v="19" data-xref="サムエル記下 2:21; ヨシュア記 1:7; 箴言 4:27"> アサヘルはアブネルのあとを追っていったが、行くのに右にも左にも曲ることなく、アブネルのあとに走った。</span>
<span className="v" id="v20" data-v="20"> アブネルは後をふりむいて言った、「あなたはアサヘルであったか」。アサヘルは答えた、「わたしです」。</span>
<span className="v" id="v21" data-v="21" data-xref="士師記 14:19"> アブネルは彼に言った、「右か左に曲って、若者のひとりを捕え、そのよろいを奪いなさい」。しかしアサヘルはアブネルを追うことをやめず、ほかに向かおうともしなかった。</span>
<span className="v" id="v22" data-v="22" data-xref="サムエル記下 3:27; 箴言 29:1; 列王紀下 14:10–12"> アブネルはふたたびアサヘルに言った、「わたしを追うことをやめて、ほかに向かいなさい。あなたを地に撃ち倒すことなど、どうしてわたしにできようか。それをすれば、わたしは、どうしてあなたの兄ヨアブに顔を合わせることができようか」。</span>
<span className="v" id="v23" data-v="23" data-xref="サムエル記下 3:27; サムエル記下 4:6; サムエル記下 5:6"> それでもなお彼は、ほかに向かうことを拒んだので、アブネルは、やりの石突きで彼の腹を突いたので、やりはその背中に出た。彼はそこに倒れて、その場で死んだ。そしてアサヘルが倒れて死んでいる場所に来る者は皆立ちとどまった。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24"> しかしヨアブとアビシャイとは、なおアブネルのあとを追ったが、彼らがギベオンの荒野の道のほとり、ギアの前にあるアンマの山にきた時、日は暮れた。</span>
<span className="v" id="v25" data-v="25"> ベニヤミンの人々はアブネルのあとについてきて、集まり、一隊となって、一つの山の頂に立った。</span>
<span className="v" id="v26" data-v="26" data-xref="エレミヤ書 46:14; エレミヤ書 46:10; 使徒行伝 7:26"> その時アブネルはヨアブに呼ばわって言った、「いつまでもつるぎをもって滅ぼそうとするのか。あなたはその結果の悲惨なのを知らないのか。いつまで民にその兄弟を追うことをやめよと命じないのか」。</span>
<span className="v" id="v27" data-v="27" data-xref="箴言 17:14; サムエル記下 2:14; 箴言 15:1"> ヨアブは言った、「神は生きておられる。もしあなたが言いださなかったならば、民はおのおのその兄弟を追わずに、朝のうちに去っていたであろう」。</span>
<span className="v" id="v28" data-v="28"> こうしてヨアブは角笛を吹いたので、民はみな立ちとどまって、もはやイスラエルのあとを追わず、また重ねて戦わなかった。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="サムエル記下 2:8; 雅歌 2:17"> アブネルとその従者たちは、夜もすがら、アラバを通って行き、ヨルダンを渡り、昼まで行進を続けてマハナイムに着いた。</span>
<span className="v" id="v30" data-v="30"> ヨアブはアブネルを追うことをやめて帰り、民をみな集めたが、ダビデの家来たち十九人とアサヘルとが見当らなかった。</span>
<span className="v" id="v31" data-v="31" data-xref="サムエル記下 3:1; 列王紀上 20:11"> しかし、ダビデの家来たちは、アブネルの従者であるベニヤミンの人々三百六十人を撃ち殺した。</span>
<span className="v" id="v32" data-v="32" data-xref="歴代志上 2:13–16; サムエル記上 17:58; 歴代志下 21:1"> 人々はアサヘルを取り上げてベツレヘムにあるその父の墓に葬った。ヨアブとその従者たちは、夜もすがら行って、夜明けにヘブロンに着いた。</span>
</div>

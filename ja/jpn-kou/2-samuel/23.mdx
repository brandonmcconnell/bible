<span className="v" id="v2" data-v="2" data-xref="ペテロの第二の手紙 1:21; マタイによる福音書 22:43; マルコによる福音書 12:36"> <span className="pl pl-1">「主の霊はわたしによって語る、</span><br /><span className="pl pl-1">その言葉はわたしの舌の上にある。</span></span>

<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="歴代志上 27:2; 歴代志上 11:11–47; 歴代志上 27:32"> ダビデの勇士たちの名は次のとおりである。タクモンびとヨセブ・バッセベテはかの三人のうちの長であったが、彼はいちじに八百人に向かって、やりをふるい、それを殺した。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="歴代志上 27:4; 歴代志上 11:12–14; サムエル記上 17:26"> 彼の次はアホアびとドドの子エレアザルであって、三勇士のひとりである。彼は、戦おうとしてそこに集まったペリシテびとに向かって戦いをいどみ、イスラエルの人々が退いた時、ダビデと共にいたが、</span>
<span className="v" id="v10" data-v="10" data-xref="サムエル記上 19:5; サムエル記上 11:13; 士師記 15:14"> 立ってペリシテびとを撃ち、ついに手が疲れ、手がつるぎに着いて離れないほどになった。その日、主は大いなる勝利を与えられた。民は彼のあとに帰ってきて、ただ殺された者をはぎ取るばかりであった。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="歴代志上 11:13–14; 歴代志上 11:27; サムエル記下 23:33"> 彼の次はハラルびとアゲの子シャンマであった。ある時、ペリシテびとはレヒに集まった。そこに一面にレンズ豆を作った地所があった。民はペリシテびとの前から逃げたが、</span>
<span className="v" id="v12" data-v="12" data-xref="箴言 21:31; サムエル記下 23:10; 詩篇 3:8"> 彼はその地所の中に立って、これを防ぎ、ペリシテびとを殺した。そして主は大いなる救を与えられた。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="サムエル記上 22:1; サムエル記下 5:18; ヨシュア記 12:15"> 三十人の長たちのうちの三人は下って行って刈入れのころに、アドラムのほら穴にいるダビデのもとにきた。時にペリシテびとの一隊はレパイムの谷に陣を取っていた。</span>
<span className="v" id="v14" data-v="14" data-xref="サムエル記上 22:4–5; サムエル記上 13:4; サムエル記上 10:5"> その時ダビデは要害におり、ペリシテびとの先陣はベツレヘムにあったが、</span>
<span className="v" id="v15" data-v="15" data-xref="ヨハネによる福音書 4:14; 詩篇 42:1–2; イザヤ書 41:17"> ダビデは、せつに望んで、「だれかベツレヘムの門のかたわらにある井戸の水をわたしに飲ませてくれるとよいのだが」と言った。</span>
<span className="v" id="v16" data-v="16" data-xref="創世記 35:14; コリント人への第二の手紙 5:14; ピリピ人への手紙 2:17"> そこでその三人の勇士たちはペリシテびとの陣を突き通って、ベツレヘムの門のかたわらにある井戸の水を汲み取って、ダビデのもとに携えてきた。しかしダビデはそれを飲もうとはせず、主の前にそれを注いで、</span>
<span className="v" id="v17" data-v="17" data-xref="レビ記 17:10; マルコによる福音書 14:24; コリント人への第一の手紙 15:30"> 言った、「主よ、わたしは断じて飲むことをいたしません。いのちをかけて行った人々の血を、どうしてわたしは飲むことができましょう」。こうして彼はそれを飲もうとはしなかった。三勇士はこれらのことを行った。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="サムエル記下 10:10; サムエル記下 10:14; 歴代志上 11:20–21"> ゼルヤの子ヨアブの兄弟アビシャイは三十人の長であった。彼は三百人に向かって、やりをふるい、それを殺した。そして、彼は三人と共に名を得た。</span>
<span className="v" id="v19" data-v="19" data-xref="マタイによる福音書 13:8; マタイによる福音書 13:23; コリント人への第一の手紙 15:41"> 彼は三十人のうち最も尊ばれた者で、彼らの長となった。しかし、かの三人には及ばなかった。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="サムエル記下 8:18; ヨシュア記 15:21; サムエル記下 20:23"> エホヤダの子ベナヤはカブジエル出身の勇士であって、多くのてがらを立てた。彼はモアブのアリエルのふたりの子を撃ち殺した。彼はまた雪の日に下っていって、穴の中でししを撃ち殺した。</span>
<span className="v" id="v21" data-v="21" data-xref="サムエル記上 17:51; 歴代志上 11:23; コロサイ人への手紙 2:15"> 彼はまた姿のうるわしいエジプトびとを撃ち殺した。そのエジプトびとは手にやりを持っていたが、ベナヤはつえをとってその所に下っていき、エジプトびとの手からやりをもぎとって、そのやりをもって殺した。</span>
<span className="v" id="v22" data-v="22"> エホヤダの子ベナヤはこれらの事をして三勇士と共に名を得た。</span>
<span className="v" id="v23" data-v="23" data-xref="サムエル記下 20:23; 歴代志上 27:6; サムエル記上 22:14"> 彼は三十人のうちに有名であったが、かの三人には及ばなかった。ダビデは彼を侍衛の長とした。</span>
</div>
<div className="bp">

<span className="v" id="v25" data-v="25" data-xref="士師記 7:1; 歴代志上 11:27–28"> ハロデ出身のシャンマ。ハロデ出身のエリカ。</span>

<span className="v" id="v27" data-v="27" data-xref="ヨシュア記 21:18; 歴代志上 11:19; 歴代志上 11:28"> アナトテ出身のアビエゼル。ホシャびとメブンナイ。</span>
<span className="v" id="v28" data-v="28" data-xref="歴代志上 27:13; 列王紀下 25:23; 歴代志上 11:30"> アホアびとザルモン。ネトパ出身のマハライ。</span>

<span className="v" id="v38" data-v="38" data-xref="歴代志上 2:53; サムエル記下 20:26; 歴代志上 11:40"> イテルびとイラ。イテルびとガレブ。</span>

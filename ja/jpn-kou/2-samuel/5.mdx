<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歴代志上 11:1–3; サムエル記下 19:13; 創世記 29:14"> イスラエルのすべての部族はヘブロンにいるダビデのもとにきて言った、「われわれは、あなたの骨肉です。</span>
<span className="v" id="v2" data-v="2" data-xref="マタイによる福音書 2:6; ミカ書 5:4; エゼキエル書 34:23"> 先にサウルがわれわれの王であった時にも、あなたはイスラエルを率いて出入りされました。そして主はあなたに、『あなたはわたしの民イスラエルを牧するであろう。またあなたはイスラエルの君となるであろう』と言われました」。</span>
<span className="v" id="v3" data-v="3" data-xref="サムエル記下 2:4; サムエル記上 16:13; サムエル記上 23:18"> このようにイスラエルの長老たちが皆、ヘブロンにいる王のもとにきたので、ダビデ王はヘブロンで主の前に彼らと契約を結んだ。そして彼らはダビデに油を注いでイスラエルの王とした。</span>
<span className="v" id="v4" data-v="4" data-xref="歴代志上 29:27; ルカによる福音書 3:23; 列王紀上 2:11"> ダビデは王となったとき三十歳で、四十年の間、世を治めた。</span>
<span className="v" id="v5" data-v="5" data-xref="サムエル記下 2:11; 歴代志上 3:4; 列王紀上 2:11"> すなわちヘブロンで七年六か月ユダを治め、またエルサレムで三十三年、全イスラエルとユダを治めた。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="士師記 1:8; エレミヤ書 37:10; 歴代志上 11:4–9"> 王とその従者たちとはエルサレムへ行って、その地の住民エブスびとを攻めた。エブスびとはダビデに言った、「あなたはけっして、ここに攻め入ることはできない。かえって、めしいや足なえでも、あなたを追い払うであろう」。彼らが「ダビデはここに攻め入ることはできない」と思ったからである。</span>
<span className="v" id="v7" data-v="7" data-xref="列王紀上 2:10; サムエル記下 6:16; サムエル記下 6:12"> ところがダビデはシオンの要害を取った。これがダビデの町である。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨシュア記 15:16–17; 歴代志上 11:6–9; サムエル記上 17:25"> その日ダビデは、「だれでもエブスびとを撃とうとする人は、水をくみ上げる縦穴を上って行って、ダビデが心に憎んでいる足なえやめしいを撃て」と言った。それゆえに人々は、「めしいや足なえは、宮にはいってはならない」と言いならわしている。</span>
<span className="v" id="v9" data-v="9" data-xref="列王紀上 9:15; 列王紀上 9:24; 歴代志下 32:5"> ダビデはその要害に住んで、これをダビデの町と名づけた。またダビデはミロから内の周囲に城壁を築いた。</span>
<span className="v" id="v10" data-v="10" data-xref="サムエル記下 3:1; ローマ人への手紙 8:31; 詩篇 46:11"> こうしてダビデはますます大いなる者となり、かつ万軍の神、主が彼と共におられた。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="歴代志上 14:1; 列王紀上 5:1–2; 列王紀上 5:18"> ツロの王ヒラムはダビデに使者をつかわして、香柏および大工と石工を送った。彼らはダビデのために家を建てた。</span>
<span className="v" id="v12" data-v="12" data-xref="サムエル記下 7:16; 列王紀上 10:9; 歴代志上 14:2"> そしてダビデは主が自分を堅く立ててイスラエルの王とされたこと、主がその民イスラエルのためにその王国を興されたことを悟った。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="歴代志上 3:9; 申命記 17:17; 歴代志下 13:21"> ダビデはヘブロンからきて後、さらにエルサレムで妻とそばめを入れたので、むすこと娘がまたダビデに生れた。</span>
<span className="v" id="v14" data-v="14" data-xref="歴代志上 3:5–9; ルカによる福音書 2:31; 歴代志上 14:4"> エルサレムで彼に生れた者の名は次のとおりである。シャンムア、ショバブ、ナタン、ソロモン、</span>
<span className="v" id="v15" data-v="15" data-xref="歴代志上 3:6; 歴代志上 14:5"> イブハル、エリシュア、ネペグ、ヤピア、</span>
<span className="v" id="v16" data-v="16" data-xref="歴代志上 3:8; 歴代志上 14:7"> エリシャマ、エリアダ、およびエリペレテ。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="サムエル記下 23:14; 歴代志上 14:8–9; 歴代志上 11:16"> さてペリシテびとは、ダビデが油を注がれてイスラエルの王になったことを聞き、みな上ってきてダビデを捜したが、ダビデはそれを聞いて要害に下って行った。</span>
<span className="v" id="v18" data-v="18" data-xref="ヨシュア記 15:8; サムエル記下 23:13; 創世記 14:5"> ペリシテびとはきて、レパイムの谷に広がっていた。</span>
<span className="v" id="v19" data-v="19" data-xref="サムエル記下 2:1; サムエル記上 23:2; サムエル記下 5:23"> ダビデは主に問うて言った、「ペリシテびとに向かって上るべきでしょうか。あなたは彼らをわたしの手に渡されるでしょうか」。主はダビデに言われた、「上るがよい。わたしはかならずペリシテびとをあなたの手に渡すであろう」。</span>
<span className="v" id="v20" data-v="20" data-xref="イザヤ書 28:21"> そこでダビデはバアル・ペラジムへ行って、彼らをその所で撃ち破り、そして言った、「主は、破り出る水のように、敵をわたしの前に破られた」。それゆえにその所の名はバアル・ペラジムと呼ばれている。</span>
<span className="v" id="v21" data-v="21" data-xref="歴代志上 14:11–12; 申命記 7:5; サムエル記上 5:2–6"> ペリシテびとはその所に彼らの偶像を捨てて行ったので、ダビデとその従者たちはそれを運び去った。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="歴代志上 14:13; サムエル記下 5:18; 列王紀上 20:22"> ペリシテびとが、ふたたび上ってきて、レパイムの谷に広がったので、</span>
<span className="v" id="v23" data-v="23" data-xref="歴代志上 14:14; マタイによる福音書 9:29–30; マタイによる福音書 8:23–25"> ダビデは主に問うたが、主は言われた、「上ってはならない。彼らのうしろに回り、バルサムの木の前から彼らを襲いなさい。</span>
<span className="v" id="v24" data-v="24" data-xref="列王紀下 7:6; 士師記 4:14; 士師記 7:15"> バルサムの木の上に行進の音が聞えたならば、あなたは奮い立たなければならない。その時、主があなたの前に出て、ペリシテびとの軍勢を撃たれるからである」。</span>
<span className="v" id="v25" data-v="25" data-xref="歴代志上 14:16; ヨシュア記 16:10; イザヤ書 28:21"> ダビデは、主が命じられたようにして、ペリシテびとを撃ち、ゲバからゲゼルに及んだ。</span>
</div>
</div>

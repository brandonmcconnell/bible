<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歴代志上 3:9; サムエル記下 3:2–3; サムエル記下 13:15"> さてダビデの子アブサロムには名をタマルという美しい妹があったが、その後ダビデの子アムノンはこれを恋した。</span>
<span className="v" id="v2" data-v="2" data-xref="コリント人への第二の手紙 7:10; 列王紀上 21:4; 雅歌 5:8"> アムノンは妹タマルのために悩んでついにわずらった。それはタマルが処女であって、アムノンは彼女に何事もすることができないと思ったからである。</span>
<span className="v" id="v3" data-v="3" data-xref="サムエル記上 16:9; コリント人への第一の手紙 3:19; ヤコブの手紙 3:15"> ところがアムノンにはひとりの友だちがあった。名をヨナダブといい、ダビデの兄弟シメアの子である。ヨナダブはひじょうに賢い人であった。</span>
<span className="v" id="v4" data-v="4" data-xref="レビ記 20:17; レビ記 18:9; エステル記 5:13–14"> 彼はアムノンに言った、「王子よ、あなたは、どうして朝ごとに、そんなにやせ衰えるのですか。わたしに話さないのですか」。アムノンは彼に言った、「わたしは兄弟アブサロムの妹タマルを恋しているのです」。</span>
<span className="v" id="v5" data-v="5" data-xref="マルコによる福音書 6:24–25; 箴言 19:27; 使徒行伝 23:15"> ヨナダブは彼に言った、「あなたは病と偽り、寝床に横たわって、あなたの父がきてあなたを見るとき彼に言いなさい、『どうぞ、わたしの妹タマルをこさせ、わたしの所に食物を運ばせてください。そして彼女がわたしの目の前で食物をととのえ、彼女の手からわたしが食べることのできるようにさせてください』」。</span>
<span className="v" id="v6" data-v="6" data-xref="創世記 18:6; マタイによる福音書 13:33"> そこでアムノンは横になって病と偽ったが、王がきて彼を見た時、アムノンは王に言った、「どうぞわたしの妹タマルをこさせ、わたしの目の前で二つの菓子を作らせて、彼女の手からわたしが食べることのできるようにしてください」。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7"> ダビデはタマルの家に人をつかわして言わせた、「あなたの兄アムノンの家へ行って、彼のために食物をととのえなさい」。</span>
<span className="v" id="v8" data-v="8"> そこでタマルはその兄アムノンの家へ行ったところ、アムノンは寝ていた。タマルは粉を取って、これをこね、彼の目の前で、菓子を作り、その菓子を焼き、</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 45:1; ヨハネによる福音書 3:20; 士師記 3:19"> なべを取って彼の前にそれをあけた。しかし彼は食べることを拒んだ。そしてアムノンは、「みな、わたしを離れて出てください」と言ったので、皆、彼を離れて出た。</span>
<span className="v" id="v10" data-v="10"> アムノンはタマルに言った、「食物を寝室に持ってきてください。わたしはあなたの手から食べます」。そこでタマルは自分の作った菓子をとって、寝室にはいり兄アムノンの所へ持っていった。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 39:11–12"> タマルが彼に食べさせようとして近くに持って行った時、彼はタマルを捕えて彼女に言った、「妹よ、来て、わたしと寝なさい」。</span>
<span className="v" id="v12" data-v="12" data-xref="士師記 19:23; レビ記 20:17; 士師記 20:6"> タマルは言った、「いいえ、兄上よ、わたしをはずかしめてはなりません。このようなことはイスラエルでは行われません。この愚かなことをしてはなりません。</span>
<span className="v" id="v13" data-v="13" data-xref="士師記 19:24; 創世記 20:12; 創世記 19:8"> わたしの恥をわたしはどこへ持って行くことができましょう。あなたはイスラエルの愚か者のひとりとなるでしょう。それゆえ、どうぞ王に話してください。王がわたしをあなたに与えないことはないでしょう」。</span>
<span className="v" id="v14" data-v="14" data-xref="サムエル記下 12:11; エステル記 7:8; 士師記 20:5"> しかしアムノンは彼女の言うことを聞こうともせず、タマルよりも強かったので、タマルをはずかしめてこれと共に寝た。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="エゼキエル書 23:17"> それからアムノンは、ひじょうに深くタマルを憎むようになった。彼女を憎む憎しみは、彼女を恋した恋よりも大きかった。アムノンは彼女に言った、「立って、行きなさい」。</span>
<span className="v" id="v16" data-v="16"> タマルはアムノンに言った、「いいえ、兄上よ、わたしを返すことは、あなたがさきにわたしになさった事よりも大きい悪です」。しかしアムノンは彼女の言うことを聞こうともせず、</span>
<span className="v" id="v17" data-v="17"> 彼に仕えている若者を呼んで言った、「この女をわたしの所から外におくり出し、そのあとに戸を閉ざすがよい」。</span>
<span className="v" id="v18" data-v="18" data-xref="士師記 5:30; 創世記 37:3; 詩篇 45:13–14"> この時、タマルは長そでの着物を着ていた。昔、王の姫たちの処女である者はこのような着物を着たからである。アムノンのしもべは彼女を外に出して、そのあとに戸を閉ざした。</span>
<span className="v" id="v19" data-v="19" data-xref="ヨシュア記 7:6; エレミヤ書 2:37; サムエル記下 1:11"> タマルは灰を頭にかぶり、着ていた長そでの着物を裂き、手を頭にのせて、叫びながら去って行った。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="ローマ人への手紙 12:19; 創世記 46:15; 創世記 34:2"> 兄アブサロムは彼女に言った、「兄アムノンがあなたと一緒にいたのか。しかし妹よ、今は黙っていなさい。彼はあなたの兄です。この事を心にとめなくてよろしい」。こうしてタマルは兄アブサロムの家に寂しく住んでいた。</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 34:7; サムエル記下 3:28–29; サムエル記上 2:29"> ダビデ王はこれらの事をことごとく聞いて、ひじょうに怒った。</span>
<span className="v" id="v22" data-v="22" data-xref="レビ記 19:17–18; 創世記 31:24; 創世記 24:50"> アブサロムはアムノンに良いことも悪いことも語ることをしなかった。それはアムノンがアブサロムの妹タマルをはずかしめたので、アブサロムが彼を憎んでいたからである。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="創世記 38:12–13; サムエル記上 25:4; 歴代志下 26:10"> 満二年の後、アブサロムはエフライムの近くにあるバアル・ハゾルで羊の毛を切らせていた時、王の子たちをことごとく招いた。</span>
<span className="v" id="v24" data-v="24" data-xref="サムエル記下 11:8–15; エレミヤ書 41:6–7; 詩篇 55:21"> そしてアブサロムは王のもとにきて言った、「見よ、しもべは羊の毛を切らせております。どうぞ王も王の家来たちも、しもべと共にきてください」。</span>
<span className="v" id="v25" data-v="25" data-xref="ルカによる福音書 14:23; 士師記 19:7–10; サムエル記下 14:22"> 王はアブサロムに言った、「いいえ、わが子よ、われわれが皆行ってはならない。あなたの重荷になるといけないから」。アブサロムはダビデにしいて願った。しかしダビデは行くことを承知せず彼に祝福を与えた。</span>
<span className="v" id="v26" data-v="26" data-xref="サムエル記下 20:9; サムエル記下 3:27; サムエル記下 11:13–15"> そこでアブサロムは言った、「それでは、どうぞわたしの兄アムノンをわれわれと共に行かせてください」。王は彼に言った、「どうして彼があなたと共に行かなければならないのか」。</span>
<span className="v" id="v27" data-v="27" data-xref="箴言 26:24–26"> しかしアブサロムは彼にしいて願ったので、ついにアムノンと王の子たちを皆、アブサロムと共に行かせた。</span>
<span className="v" id="v28" data-v="28" data-xref="士師記 19:6; 士師記 19:22; 士師記 19:9"> そこでアブサロムは若者たちに命じて言った、「アムノンが酒を飲んで、心楽しくなった時を見すまし、わたしがあなたがたに、『アムノンを撃て』と言う時、彼を殺しなさい。恐れることはない。わたしが命じるのではないか。雄々しくしなさい。勇ましくしなさい」。</span>
<span className="v" id="v29" data-v="29" data-xref="サムエル記下 18:9; 列王紀上 1:33; 列王紀下 1:9–12"> アブサロムの若者たちはアブサロムの命じたようにアムノンにおこなったので、王の子たちは皆立って、おのおのその騾馬に乗って逃げた。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30"> 彼らがまだ着かないうちに、「アブサロムは王の子たちをことごとく殺して、ひとりも残っている者がない」という知らせがダビデに達したので、</span>
<span className="v" id="v31" data-v="31" data-xref="サムエル記下 1:11; サムエル記下 12:16; ヨブ記 1:20"> 王は立ち、その着物を裂いて、地に伏した。そのかたわらに立っていた家来たちも皆その着物を裂いた。</span>
<span className="v" id="v32" data-v="32" data-xref="サムエル記上 16:9; サムエル記下 13:3; 創世記 27:41"> しかしダビデの兄弟シメアの子ヨナダブは言った、「わが主よ、王の子たちである若者たちがみな殺されたと、お考えになってはなりません。アムノンだけが死んだのです。これは彼がアブサロムの妹タマルをはずかしめた日から、アブサロムの命によって定められていたことなのです。</span>
<span className="v" id="v33" data-v="33" data-xref="サムエル記下 19:19"> それゆえ、わが主、王よ、王の子たちが皆死んだと思って、この事を心にとめられてはなりません。アムノンだけが死んだのです」。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="創世記 4:8–14; 箴言 28:17; アモス書 5:19"> アブサロムはのがれた。時に見張りをしていた若者が目をあげて見ると、山のかたわらのホロナイムの道から多くの民の来るのが見えた。</span>
<span className="v" id="v35" data-v="35"> ヨナダブは王に言った、「見よ、王の子たちがきました。しもべの言ったとおりです」。</span>
<span className="v" id="v36" data-v="36" data-xref="サムエル記下 18:33; サムエル記下 12:21; サムエル記下 13:15"> 彼が語ることを終った時、王の子たちはきて声をあげて泣いた。王もその家来たちも皆、非常にはげしく泣いた。</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="サムエル記下 3:3; サムエル記下 14:32; サムエル記下 13:34"> しかしアブサロムはのがれて、ゲシュルの王アミホデの子タルマイのもとに行った。ダビデは日々その子のために悲しんだ。</span>
<span className="v" id="v38" data-v="38" data-xref="サムエル記下 15:8; サムエル記下 14:23; サムエル記下 14:32"> アブサロムはのがれてゲシュルに行き、三年の間そこにいた。</span>
<span className="v" id="v39" data-v="39" data-xref="創世記 24:67; 創世記 38:12; 創世記 37:35"> 王は心に、アブサロムに会うことを、せつに望んだ。アムノンは死んでしまい、ダビデが彼のことはあきらめていたからである。</span>
</div>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="箴言 16:7; ルカによる福音書 1:74–75; 列王紀上 5:4"> さて、王が自分の家に住み、また主が周囲の敵をことごとく打ち退けて彼に安息を賜わった時、</span>
<span className="v" id="v2" data-v="2" data-xref="歴代志上 16:1; サムエル記下 5:11; ハガイ書 1:4"> 王は預言者ナタンに言った、「見よ、今わたしは、香柏の家に住んでいるが、神の箱はなお幕屋のうちにある」。</span>
<span className="v" id="v3" data-v="3" data-xref="歴代志上 22:7; 列王紀上 8:17–18; 列王紀下 4:27"> ナタンは王に言った、「主があなたと共におられますから、行って、すべてあなたの心にあるところを行いなさい」。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="歴代志上 17:3; 民数記 12:6; アモス書 3:7"> その夜、主の言葉がナタンに臨んで言った、</span>
<span className="v" id="v5" data-v="5" data-xref="歴代志上 23:3–32; 列王紀上 5:3–4; 列王紀上 8:16–19"> 「行って、わたしのしもべダビデに言いなさい、『主はこう仰せられる。あなたはわたしの住む家を建てようとするのか。</span>
<span className="v" id="v6" data-v="6" data-xref="列王紀上 8:16; ヨシュア記 18:1; 出エジプト記 40:18–19"> わたしはイスラエルの人々をエジプトから導き出した日から今日まで、家に住まわず、天幕をすまいとして歩んできた。</span>
<span className="v" id="v7" data-v="7" data-xref="歴代志上 17:6; サムエル記下 5:2; レビ記 26:11–12"> わたしがイスラエルのすべての人々と共に歩んだすべての所で、わたしがわたしの民イスラエルを牧することを命じたイスラエルのさばきづかさのひとりに、ひと言でも「どうしてあなたがたはわたしのために香柏の家を建てないのか」と、言ったことがあるであろうか』。</span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 78:70–71; サムエル記下 6:21; サムエル記下 12:7"> それゆえ、今あなたは、わたしのしもべダビデにこう言いなさい、『万軍の主はこう仰せられる。わたしはあなたを牧場から、羊に従っている所から取って、わたしの民イスラエルの君とし、</span>
<span className="v" id="v9" data-v="9" data-xref="サムエル記下 5:10; 歴代志上 17:8; サムエル記上 18:14"> あなたがどこへ行くにも、あなたと共におり、あなたのすべての敵をあなたの前から断ち去った。わたしはまた地上の大いなる者の名のような大いなる名をあなたに得させよう。</span>
<span className="v" id="v10" data-v="10" data-xref="アモス書 9:15; 歴代志上 17:9; エレミヤ書 24:6"> そしてわたしの民イスラエルのために一つの所を定めて、彼らを植えつけ、彼らを自分の所に住ませ、重ねて動くことのないようにするであろう。</span>
<span className="v" id="v11" data-v="11" data-xref="サムエル記下 7:27; サムエル記下 7:1; 歴代志上 17:10"> また前のように、わたしがわたしの民イスラエルの上にさばきづかさを立てた日からこのかたのように、悪人が重ねてこれを悩ますことはない。わたしはあなたのもろもろの敵を打ち退けて、あなたに安息を与えるであろう。主はまた「あなたのために家を造る」と仰せられる。</span>
<span className="v" id="v12" data-v="12" data-xref="列王紀上 8:20; 使徒行伝 2:30; 使徒行伝 13:36"> あなたが日が満ちて、先祖たちと共に眠る時、わたしはあなたの身から出る子を、あなたのあとに立てて、その王国を堅くするであろう。</span>
<span className="v" id="v13" data-v="13" data-xref="ルカによる福音書 1:31–33; 列王紀上 8:19; サムエル記下 7:16"> 彼はわたしの名のために家を建てる。わたしは長くその国の位を堅くしよう。</span>
<span className="v" id="v14" data-v="14" data-xref="ヘブル人への手紙 1:5; ヨハネの黙示録 3:19; 歴代志上 17:13"> わたしは彼の父となり、彼はわたしの子となるであろう。もし彼が罪を犯すならば、わたしは人のつえと人の子のむちをもって彼を懲らす。</span>
<span className="v" id="v15" data-v="15" data-xref="サムエル記上 15:23; サムエル記上 15:28; 詩篇 89:28"> しかしわたしはわたしのいつくしみを、わたしがあなたの前から除いたサウルから取り去ったように、彼からは取り去らない。</span>
<span className="v" id="v16" data-v="16" data-xref="ルカによる福音書 1:32–33; 詩篇 89:36–37; サムエル記下 7:13"> あなたの家と王国はわたしの前に長く保つであろう。あなたの位は長く堅うせられる』」。</span>
<span className="v" id="v17" data-v="17" data-xref="歴代志上 17:15; 使徒行伝 20:27; コリント人への第一の手紙 15:3"> ナタンはすべてこれらの言葉のように、またすべてこの幻のようにダビデに語った。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="詩篇 8:4; 歴代志上 17:16; サムエル記上 18:18"> その時ダビデ王は、はいって主の前に座して言った、「主なる神よ、わたしがだれ、わたしの家が何であるので、あなたはこれまでわたしを導かれたのですか。</span>
<span className="v" id="v19" data-v="19" data-xref="イザヤ書 55:8–9; 歴代志上 17:17; 詩篇 36:7"> 主なる神よ、これはなおあなたの目には小さい事です。主なる神よ、あなたはまたしもべの家の、はるか後の事を語って、きたるべき代々のことを示されました。</span>
<span className="v" id="v20" data-v="20" data-xref="ヨハネによる福音書 21:17; サムエル記上 16:7; 詩篇 139:1"> ダビデはこの上なにをあなたに申しあげることができましょう。主なる神よ、あなたはしもべを知っておられるのです。</span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 115:1; 詩篇 138:2; エペソ人への手紙 1:9"> あなたの約束のゆえに、またあなたの心に従って、あなたはこのもろもろの大いなる事を行い、しもべにそれを知らせられました。</span>
<span className="v" id="v22" data-v="22" data-xref="詩篇 86:10; 出エジプト記 15:11; 詩篇 86:8"> 主なる神よ、あなたは偉大です。それは、われわれがすべて耳に聞いたところによれば、あなたのような者はなく、またあなたのほかに神はないからです。</span>
<span className="v" id="v23" data-v="23" data-xref="申命記 9:26; 申命記 10:21; 申命記 15:15"> 地のどの国民が、あなたの民イスラエルのようでありましょうか。これは神が行って、自分のためにあがなって民とし、自らの名をあげられたもの、また彼らのために大いなる恐るべきことをなし、その民の前から国びととその神々とを追い出されたものです。</span>
<span className="v" id="v24" data-v="24" data-xref="申命記 26:18; ペテロの第一の手紙 2:10; 創世記 17:7"> そしてあなたの民イスラエルを永遠にあなたの民として、自分のために、定められました。主よ、あなたは彼らの神となられたのです。</span>
<span className="v" id="v25" data-v="25" data-xref="詩篇 119:49; エゼキエル書 36:37; 創世記 32:12"> 主なる神よ、今あなたが、しもべとしもべの家とについて語られた言葉を長く堅うして、あなたの言われたとおりにしてください。</span>
<span className="v" id="v26" data-v="26" data-xref="歴代志上 17:23–24; 詩篇 72:18–19; マタイによる福音書 6:9"> そうすれば、あなたの名はとこしえにあがめられて、『万軍の主はイスラエルの神である』と言われ、あなたのしもべダビデの家は、あなたの前に堅く立つことができましょう。</span>
<span className="v" id="v27" data-v="27" data-xref="歴代志上 17:25–26; 詩篇 10:17; ルツ記 4:4"> 万軍の主、イスラエルの神よ、あなたはしもべに示して、『おまえのために家を建てよう』と言われました。それゆえ、しもべはこの祈をあなたにささげる勇気を得たのです。</span>
<span className="v" id="v28" data-v="28" data-xref="ヨハネによる福音書 17:17; 出エジプト記 34:6; 民数記 23:19"> 主なる神よ、あなたは神にましまし、あなたの言葉は真実です。あなたはこの良き事をしもべに約束されました。</span>
<span className="v" id="v29" data-v="29" data-xref="民数記 6:24–26; 歴代志上 17:27; 詩篇 115:12–15"> どうぞ今、しもべの家を祝福し、あなたの前に長くつづかせてくださるように。主なる神よ、あなたがそれを言われたのです。どうぞあなたの祝福によって、しもべの家がながく祝福されますように」。</span>
</div>

<span className="v" id="v1" data-v="1" data-xref="サムエル記上 27:6; サムエル記上 31:6; サムエル記上 30:17–26"> サウルが死んだ後、ダビデはアマレクびとを撃って帰り、ふつかの間チクラグにとどまっていたが、</span>
<span className="v" id="v2" data-v="2" data-xref="サムエル記上 4:12; サムエル記下 4:10; ヨシュア記 7:6"> 三日目となって、ひとりの人が、その着物を裂き、頭に土をかぶって、サウルの陣営からきた。そしてダビデのもとにきて、地に伏して拝した。</span>
<span className="v" id="v3" data-v="3" data-xref="ヨブ記 1:15–19; 列王紀下 5:25"> ダビデは彼に言った、「あなたはどこからきたのか」。彼はダビデに言った、「わたしはイスラエルの陣営から、のがれてきたのです」。</span>
<span className="v" id="v4" data-v="4" data-xref="サムエル記上 4:16; サムエル記上 31:1–6; 歴代志上 10:1–6"> ダビデは彼に言った、「様子はどうであったか話しなさい」。彼は答えた、「民は戦いから逃げ、民の多くは倒れて死に、サウルとその子ヨナタンもまた死にました」。</span>
<span className="v" id="v5" data-v="5" data-xref="箴言 25:2; 箴言 14:15"> ダビデは自分と話している若者に言った、「あなたはサウルとその子ヨナタンが死んだのを、どうして知ったのか」。</span>
<span className="v" id="v6" data-v="6" data-xref="サムエル記上 28:4; サムエル記下 1:21; 歴代志上 10:4–6"> 彼に話している若者は言った、「わたしは、はからずも、ギルボア山にいましたが、サウルはそのやりによりかかっており、戦車と騎兵とが彼に攻め寄ろうとしていました。</span>
<span className="v" id="v7" data-v="7" data-xref="サムエル記上 22:12; サムエル記下 9:6; 士師記 9:54"> その時、彼はうしろを振り向いてわたしを見、わたしを呼びましたので、『ここにいます』とわたしは答えました。</span>
<span className="v" id="v8" data-v="8" data-xref="サムエル記上 30:17; サムエル記上 30:13; サムエル記上 30:1"> 彼は『おまえはだれか』と言いましたので、『アマレクびとです』と答えました。</span>
<span className="v" id="v9" data-v="9"> 彼はまたわたしに言いました、『そばにきて殺してください。わたしは苦しみに耐えない。まだ命があるからです』。</span>
<span className="v" id="v10" data-v="10" data-xref="マタイによる福音書 7:2; 士師記 9:54; 列王紀下 11:12"> そこで、わたしはそのそばにいって彼を殺しました。彼がすでに倒れて、生きることのできないのを知ったからです。そしてわたしは彼の頭にあった冠と、腕につけていた腕輪とを取って、それをわが主のもとに携えてきたのです」。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="サムエル記下 13:31; 創世記 37:29; サムエル記下 3:31"> そのときダビデは自分の着物をつかんでそれを裂き、彼と共にいた人々も皆同じようにした。</span>
<span className="v" id="v12" data-v="12" data-xref="箴言 24:17; 詩篇 35:13–14; マタイによる福音書 5:44"> 彼らはサウルのため、またその子ヨナタンのため、また主の民のため、またイスラエルの家のために悲しみ泣いて、夕暮まで食を断った。それは彼らがつるぎに倒れたからである。</span>
<span className="v" id="v13" data-v="13" data-xref="サムエル記下 1:8"> ダビデは自分と話していた若者に言った、「あなたはどこの人ですか」。彼は言った、「アマレクびとで、寄留の他国人の子です」。</span>
<span className="v" id="v14" data-v="14" data-xref="サムエル記上 26:9; サムエル記上 31:4; ペテロの第二の手紙 2:10"> ダビデはまた彼に言った、「どうしてあなたは手を伸べて主の油を注がれた者を殺すことを恐れなかったのですか」。</span>
<span className="v" id="v15" data-v="15" data-xref="列王紀上 2:34; 士師記 8:20; サムエル記下 4:10–12"> ダビデはひとりの若者を呼び、「近寄って彼を撃て」と言った。そこで彼を撃ったので死んだ。</span>
<span className="v" id="v16" data-v="16" data-xref="マタイによる福音書 27:25; ルカによる福音書 19:22; レビ記 20:9"> ダビデは彼に言った、「あなたの流した血の責めはあなたに帰する。あなたが自分の口から、『わたしは主の油を注がれた者を殺した』と言って、自身にむかって証拠を立てたからである」。</span>
</div>
<div className="bp poetry">
<span className="v" id="v17" data-v="17" data-xref="歴代志下 35:25; サムエル記下 1:19; 創世記 50:11"> ダビデはこの悲しみの歌をもって、サウルとその子ヨナタンのために哀悼した。――</span>
<span className="v" id="v18" data-v="18" data-xref="ヨシュア記 10:13; 創世記 49:8; 申命記 4:10"> これは、ユダの人々に教えるための弓の歌で、ヤシャルの書にしるされている。――彼は言った、</span>
<span className="v" id="v19" data-v="19" data-xref="サムエル記下 1:27; サムエル記下 1:25; 申命記 4:7–8"> <span className="pl pl-1">「イスラエルよ、あなたの栄光は、</span><br /><span className="pl pl-1">あなたの高き所で殺された。</span><br /><span className="pl pl-1">ああ、勇士たちは、ついに倒れた。</span></span>
<span className="v" id="v20" data-v="20" data-xref="ミカ書 1:10; サムエル記上 18:6; 士師記 11:34"> <span className="pl pl-1">ガテにこの事を告げてはいけない。</span><br /><span className="pl pl-1">アシケロンのちまたに伝えてはならない。</span><br /><span className="pl pl-1">おそらくはペリシテびとの娘たちが喜び、</span><br /><span className="pl pl-1">割礼なき者の娘たちが勝ちほこるであろう。</span></span>
<span className="v" id="v21" data-v="21" data-xref="サムエル記上 31:1; イザヤ書 21:5; サムエル記上 10:1"> <span className="pl pl-1">ギルボアの山よ、</span><br /><span className="pl pl-1">露はおまえの上におりるな。</span><br /><span className="pl pl-1">死の野よ、</span><br /><span className="pl pl-1">雨もおまえの上に降るな。</span><br /><span className="pl pl-1">その所に勇士たちの盾は捨てられ、</span><br /><span className="pl pl-1">サウルの盾は油を塗らずに捨てられた。</span></span>
<span className="v" id="v22" data-v="22" data-xref="サムエル記上 18:4; イザヤ書 34:6–7; サムエル記上 14:6–14"> <span className="pl pl-1">殺した者の血を飲まずには、</span><br /><span className="pl pl-1">ヨナタンの弓は退かず、</span><br /><span className="pl pl-1">勇士の脂肪を食べないでは、</span><br /><span className="pl pl-1">サウルのつるぎは、むなしくは帰らなかった。</span></span>
<span className="v" id="v23" data-v="23" data-xref="エレミヤ書 4:13; 士師記 14:18; 哀歌 4:19"> <span className="pl pl-1">サウルとヨナタンとは、愛され、かつ喜ばれた。</span><br /><span className="pl pl-1">彼らは生きるにも、死ぬにも離れず、</span><br /><span className="pl pl-1">わしよりも早く、</span><br /><span className="pl pl-1">ししよりも強かった。</span></span>
<span className="v" id="v24" data-v="24" data-xref="ペテロの第一の手紙 3:3–5; エレミヤ書 2:32; 士師記 5:30"> <span className="pl pl-1">イスラエルの娘たちよ、サウルのために泣け。</span><br /><span className="pl pl-1">彼は緋色の着物をもって、</span><br /><span className="pl pl-1">はなやかにあなたがたを装い、</span><br /><span className="pl pl-1">あなたがたの着物に金の飾りをつけた。</span></span>
<span className="v" id="v25" data-v="25" data-xref="サムエル記下 1:19; サムエル記下 1:27; 士師記 5:18"> <span className="pl pl-1">ああ、勇士たちは戦いのさなかに倒れた。</span><br /><span className="pl pl-1">ヨナタンは、あなたの高き所で殺された。</span></span>
<span className="v" id="v26" data-v="26" data-xref="サムエル記上 20:17; サムエル記上 23:16; サムエル記上 20:41"> <span className="pl pl-1">わが兄弟ヨナタンよ、あなたのためわたしは悲しむ。</span><br /><span className="pl pl-1">あなたはわたしにとって、いとも楽しい者であった。</span><br /><span className="pl pl-1">あなたがわたしを愛するのは世の常のようでなく、</span><br /><span className="pl pl-1">女の愛にもまさっていた。</span></span>
<span className="v" id="v27" data-v="27" data-xref="サムエル記下 1:25; サムエル記下 1:19; エゼキエル書 39:9–10"> <span className="pl pl-1">ああ、勇士たちは倒れた。</span><br /><span className="pl pl-1">戦いの器はうせた」。</span></span>
</div>

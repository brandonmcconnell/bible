<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歴代志上 20:1; 列王紀上 20:26; 列王紀上 20:22"> 春になって、王たちが戦いに出るに及んで、ダビデはヨアブおよび自分と共にいる家来たち、並びにイスラエルの全軍をつかわした。彼らはアンモンの人々を滅ぼし、ラバを包囲した。しかしダビデはエルサレムにとどまっていた。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="マタイによる福音書 5:28; 詩篇 119:37; ヨブ記 31:1"> さて、ある日の夕暮、ダビデは床から起き出て、王の家の屋上を歩いていたが、屋上から、ひとりの女がからだを洗っているのを見た。その女は非常に美しかった。</span>
<span className="v" id="v3" data-v="3" data-xref="サムエル記下 23:39; 歴代志上 3:5; ヤコブの手紙 1:14–15"> ダビデは人をつかわしてその女のことを探らせたが、ある人は言った、「これはエリアムの娘で、ヘテびとウリヤの妻バテシバではありませんか」。</span>
<span className="v" id="v4" data-v="4" data-xref="レビ記 18:19; ヤコブの手紙 1:14–15; 詩篇 51:1–19"> そこでダビデは使者をつかわして、その女を連れてきた。女は彼の所にきて、彼はその女と寝た。（女は身の汚れを清めていたのである。）こうして女はその家に帰った。</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 22:22; 箴言 6:34"> 女は妊娠したので、人をつかわしてダビデに告げて言った、「わたしは子をはらみました」。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="箴言 28:13; 創世記 4:7; サムエル記上 15:30"> そこでダビデはヨアブに、「ヘテびとウリヤをわたしの所につかわせ」と言ってやったので、ヨアブはウリヤをダビデの所につかわした。</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 37:14; サムエル記上 17:22; 創世記 29:6"> ウリヤがダビデの所にきたので、ダビデは、ヨアブはどうしているか、民はどうしているか、戦いはうまくいっているかとたずねた。</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 18:4; 創世記 43:34; イザヤ書 29:15"> そしてダビデはウリヤに言った、「あなたの家に行って、足を洗いなさい」。ウリヤは王の家を出ていったが、王の贈り物が彼の後に従った。</span>
<span className="v" id="v9" data-v="9" data-xref="箴言 21:30; ヨブ記 5:12–14"> しかしウリヤは王の家の入口で主君の家来たちと共に寝て、自分の家に帰らなかった。</span>
<span className="v" id="v10" data-v="10"> 人々がダビデに、「ウリヤは自分の家に帰りませんでした」と告げたので、ダビデはウリヤに言った、「旅から帰ってきたのではないか。どうして家に帰らなかったのか」。</span>
<span className="v" id="v11" data-v="11" data-xref="サムエル記下 7:2; サムエル記下 20:6; サムエル記下 7:6"> ウリヤはダビデに言った、「神の箱も、イスラエルも、ユダも、小屋の中に住み、わたしの主人ヨアブと、わが主君の家来たちが野のおもてに陣を取っているのに、わたしはどうして家に帰って食い飲みし、妻と寝ることができましょう。あなたは生きておられます。あなたの魂は生きています。わたしはこの事をいたしません」。</span>
<span className="v" id="v12" data-v="12" data-xref="エレミヤ書 2:37; エレミヤ書 2:22–23"> ダビデはウリヤに言った、「きょうも、ここにとどまりなさい。わたしはあす、あなたを去らせましょう」。そこでウリヤはその日と次の日エルサレムにとどまった。</span>
<span className="v" id="v13" data-v="13" data-xref="ハバクク書 2:15; 創世記 19:32–35; 箴言 20:1"> ダビデは彼を招いて自分の前で食い飲みさせ、彼を酔わせた。夕暮になって彼は出ていって、その床に、主君の家来たちと共に寝た。そして自分の家には下って行かなかった。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="エレミヤ書 17:9; 列王紀上 21:8–10; 詩篇 19:13"> 朝になってダビデはヨアブにあてた手紙を書き、ウリヤの手に託してそれを送った。</span>
<span className="v" id="v15" data-v="15" data-xref="サムエル記下 12:9; 詩篇 51:4; エレミヤ書 20:13"> 彼はその手紙に、「あなたがたはウリヤを激しい戦いの最前線に出し、彼の後から退いて、彼を討死させよ」と書いた。</span>
<span className="v" id="v16" data-v="16" data-xref="箴言 29:12; サムエル記上 22:17–19; 使徒行伝 5:29"> ヨアブは町を囲んでいたので、勇士たちがいると知っていた場所にウリヤを置いた。</span>
<span className="v" id="v17" data-v="17" data-xref="サムエル記下 12:9; 詩篇 51:14"> 町の人々が出てきてヨアブと戦ったので、民のうち、ダビデの家来たちにも、倒れるものがあり、ヘテびとウリヤも死んだ。</span>
<span className="v" id="v18" data-v="18"> ヨアブは人をつかわして戦いのことをつぶさにダビデに告げた。</span>
<span className="v" id="v19" data-v="19"> ヨアブはその使者に命じて言った、「あなたが戦いのことをつぶさに王に語り終ったとき、</span>
<span className="v" id="v20" data-v="20"> もし王が怒りを起して、『あなたがたはなぜ戦おうとしてそんなに町に近づいたのか。彼らが城壁の上から射るのを知らなかったのか。</span>
<span className="v" id="v21" data-v="21" data-xref="士師記 7:1; 士師記 9:50–54; サムエル記下 3:27"> エルベセテの子アビメレクを撃ったのはだれか。ひとりの女が城壁の上から石うすの上石を投げて彼をテベツで殺したのではなかったか。あなたがたはなぜそんなに城壁に近づいたのか』と言われたならば、その時あなたは、『あなたのしもべ、ヘテびとウリヤもまた死にました』と言いなさい」。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22"> こうして使者は行き、ダビデのもとにきて、ヨアブが言いつかわしたことをことごとく告げた。</span>
<span className="v" id="v23" data-v="23"> 使者はダビデに言った、「敵はわれわれよりも有利な位置を占め、出てきてわれわれを野で攻めましたが、われわれは町の入口まで彼らを追い返しました。</span>
<span className="v" id="v24" data-v="24"> その時、射手どもは城壁からあなたの家来たちを射ましたので、王の家来のある者は死に、また、あなたの家来ヘテびとウリヤも死にました」。</span>
<span className="v" id="v25" data-v="25" data-xref="サムエル記下 12:26; ヨシュア記 7:8–9; 伝道の書 9:1–3"> ダビデは使者に言った、「あなたはヨアブにこう言いなさい、『この事で心配することはない。つるぎはこれをも彼をも同じく滅ぼすからである。強く町を攻めて戦い、それを攻め落しなさい』と。そしてヨアブを励ましなさい」。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="サムエル記下 14:2; 創世記 27:41; サムエル記下 3:31"> ウリヤの妻は夫ウリヤが死んだことを聞いて、夫のために悲しんだ。</span>
<span className="v" id="v27" data-v="27" data-xref="詩篇 51:4–5; サムエル記下 12:9; 申命記 22:29"> その喪が過ぎた時、ダビデは人をつかわして彼女を自分の家に召し入れた。彼女は彼の妻となって男の子を産んだ。しかしダビデがしたこの事は主を怒らせた。</span>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歴代志上 21:1; 歴代志上 27:23–24; ヤコブの手紙 1:13–14"> 主は再びイスラエルに向かって怒りを発し、ダビデを感動して彼らに逆らわせ、「行ってイスラエルとユダとを数えよ」と言われた。</span>
<span className="v" id="v2" data-v="2" data-xref="サムエル記下 3:10; 士師記 20:1; サムエル記下 20:23"> そこで王はヨアブおよびヨアブと共にいる軍の長たちに言った、「イスラエルのすべての部族のうちを、ダンからベエルシバまで行き巡って民を数え、わたしに民の数を知らせなさい」。</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 1:11; 詩篇 115:14; 箴言 14:28"> ヨアブは王に言った、「どうぞあなたの神、主が、民を今よりも百倍に増してくださいますように。そして王、わが主がまのあたり、それを見られますように。しかし王、わが主は何ゆえにこの事を喜ばれるのですか」。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行伝 5:29; 伝道の書 8:4; 歴代志上 21:4"> しかし王の言葉がヨアブと軍の長たちとに勝ったので、ヨアブと軍の長たちとは王の前を退き、イスラエルの民を数えるために出て行った。</span>
<span className="v" id="v5" data-v="5" data-xref="ヨシュア記 13:9; 申命記 2:36; ヨシュア記 13:16"> 彼らはヨルダンを渡り、アロエルから、すなわち谷の中にある町から始めて、ガドに向かい、ヤゼルに進んだ。</span>
<span className="v" id="v6" data-v="6" data-xref="ヨシュア記 19:28; 創世記 31:47–48; 士師記 18:28–29"> それからギレアデに行き、またヘテびとの地にあるカデシに行き、それからダンに至り、ダンからシドンにまわり、</span>
<span className="v" id="v7" data-v="7" data-xref="ヨシュア記 19:29; ヨシュア記 11:3; 創世記 21:22–33"> またツロの要害に行き、ヒビびと、およびカナンびとのすべての町に行き、ユダのネゲブに出てベエルシバへ行った。</span>
<span className="v" id="v8" data-v="8"> こうして彼らは国をあまねく行き巡って、九か月と二十日を経てエルサレムにきた。</span>
<span className="v" id="v9" data-v="9" data-xref="歴代志上 27:23–24; 歴代志上 21:5–6; 民数記 1:44–46"> そしてヨアブは民の総数を王に告げた。すなわちイスラエルには、つるぎを抜く勇士たちが八十万あった。ただしユダの人々は五十万であった。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="サムエル記下 12:13; サムエル記上 13:13; 箴言 28:13"> しかしダビデは民を数えた後、心に責められた。そこでダビデは主に言った、「わたしはこれをおこなって大きな罪を犯しました。しかし主よ、今どうぞしもべの罪を取り去ってください。わたしはひじょうに愚かなことをいたしました」。</span>
<span className="v" id="v11" data-v="11" data-xref="サムエル記上 22:5; サムエル記上 9:9; 歴代志上 29:29"> ダビデが朝起きたとき、主の言葉はダビデの先見者である預言者ガデに臨んで言った、</span>
<span className="v" id="v12" data-v="12" data-xref="ヘブル人への手紙 12:6–10; ヨハネの黙示録 3:19; 箴言 3:12"> 「行ってダビデに言いなさい、『主はこう仰せられる、「わたしは三つのことを示す。あなたはその一つを選ぶがよい。わたしはそれをあなたに行うであろう」と』」。</span>
<span className="v" id="v13" data-v="13" data-xref="歴代志上 21:12; レビ記 26:25; サムエル記下 21:1"> ガデはダビデのもとにきて、彼に言った、「あなたの国に三年のききんをこさせようか。あなたが敵に追われて三か月敵の前に逃げるようにしようか。それとも、あなたの国に三日の疫病をおくろうか。あなたは考えて、わたしがどの答を、わたしをつかわされた方になすべきかを決めなさい」。</span>
<span className="v" id="v14" data-v="14" data-xref="詩篇 51:1; 詩篇 119:156; 歴代志上 21:13"> ダビデはガデに言った、「わたしはひじょうに悩んでいますが、主のあわれみは大きいゆえ、われわれを主の手に陥らせてください。わたしを人の手には陥らせないでください」。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="歴代志上 21:14; 歴代志上 27:24; 民数記 25:9"> そこで主は朝から定めの時まで疫病をイスラエルに下された。ダンからベエルシバまでに民の死んだ者は七万人あった。</span>
<span className="v" id="v16" data-v="16" data-xref="ヨエル書 2:13–14; 創世記 6:6; 出エジプト記 12:23"> 天の使が手をエルサレムに伸べてこれを滅ぼそうとしたが、主はこの害悪を悔い、民を滅ぼしている天の使に言われた、「もはや、じゅうぶんである。今あなたの手をとどめるがよい」。その時、主の使はエブスびとアラウナの打ち場のかたわらにいた。</span>
<span className="v" id="v17" data-v="17" data-xref="詩篇 74:1; 歴代志上 21:16–17; サムエル記下 24:10"> ダビデは民を撃っている天の使を見た時、主に言った、「わたしは罪を犯しました。わたしは悪を行いました。しかしこれらの羊たちは何をしたのですか。どうぞあなたの手をわたしとわたしの父の家に向けてください」。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="歴代志上 21:18–30; サムエル記下 24:11"> その日ガデはダビデのところにきて彼に言った、「上って行ってエブスびとアラウナの打ち場で主に祭壇を建てなさい」。</span>
<span className="v" id="v19" data-v="19" data-xref="ヘブル人への手紙 11:8; ネヘミヤ書 9:26; 歴代志下 36:16"> ダビデはガデの言葉に従い、主の命じられたように上って行った。</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 18:2; ルツ記 2:10; 歴代志上 21:20–21"> アラウナは見おろして、王とそのしもべたちが自分の方に進んでくるのを見たので、アラウナは出てきて王の前に地にひれ伏して拝した。</span>
<span className="v" id="v21" data-v="21" data-xref="歴代志上 21:22; 民数記 25:8; サムエル記下 21:3–14"> そしてアラウナは言った、「どうして王わが主は、しもべの所にこられましたか」。ダビデは言った、「あなたから打ち場を買い取り、主に祭壇を築いて民に下る災をとどめるためです」。</span>
<span className="v" id="v22" data-v="22" data-xref="列王紀上 19:21; サムエル記上 6:14; 歴代志上 21:22"> アラウナはダビデに言った、「どうぞ王、わが主のよいと思われる物を取ってささげてください。燔祭にする牛もあります。たきぎにする打穀機も牛のくびきもあります。</span>
<span className="v" id="v23" data-v="23" data-xref="エゼキエル書 20:40–41; イザヤ書 32:8; 詩篇 20:3–4"> 王よ、アラウナはこれをことごとく王にささげます」。アラウナはまた王に、「あなたの神、主があなたを受けいれられますように」と言った。</span>
<span className="v" id="v24" data-v="24" data-xref="歴代志上 21:24–25; マラキ書 1:12–14; 創世記 23:13"> しかし王はアラウナに言った、「いいえ、代価を支払ってそれをあなたから買い取ります。わたしは費用をかけずに燔祭をわたしの神、主にささげることはしません」。こうしてダビデは銀五十シケルで打ち場と牛とを買い取った。</span>
<span className="v" id="v25" data-v="25" data-xref="サムエル記下 21:14; 哀歌 3:32–33; 創世記 8:20"> ダビデはその所で主に祭壇を築き、燔祭と酬恩祭をささげた。そこで主はその地のために祈を聞かれたので、災がイスラエルに下ることはとどまった。</span>
</div>

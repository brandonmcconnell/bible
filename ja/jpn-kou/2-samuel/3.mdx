<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王紀上 14:30; 箴言 4:18–19; ヨブ記 8:7"> サウルの家とダビデの家との間の戦争は久しく続き、ダビデはますます強くなり、サウルの家はますます弱くなった。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="歴代志上 3:1–4; 創世記 49:3–4; サムエル記下 13:1–29"> ヘブロンでダビデに男の子が生れた。彼の長子はエズレルの女アヒノアムの産んだアムノン、</span>
<span className="v" id="v3" data-v="3" data-xref="サムエル記上 27:8; 歴代志上 3:1; 申命記 3:14"> その次はカルメルびとナバルの妻であったアビガイルの産んだキレアブ、第三はゲシュルの王タルマイの娘マアカの子アブサロム、</span>
<span className="v" id="v4" data-v="4" data-xref="列王紀上 2:13–25; 列王紀上 1:5–18"> 第四はハギテの子アドニヤ、第五はアビタルの子シパテヤ、</span>
<span className="v" id="v5" data-v="5"> 第六はダビデの妻エグラの産んだイテレアム。これらの子がヘブロンでダビデに生れた。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="サムエル記下 2:8–9; 歴代志下 25:8; イザヤ書 8:9–10"> サウルの家とダビデの家とが戦いを続けている間に、アブネルはサウルの家で、強くなってきた。</span>
<span className="v" id="v7" data-v="7" data-xref="サムエル記下 21:8–11; 列王紀上 2:21–22; サムエル記下 12:8"> さてサウルには、ひとりのそばめがあった。その名をリヅパといい、アヤの娘であったが、イシボセテはアブネルに言った、「あなたはなぜわたしの父のそばめのところにはいったのですか」。</span>
<span className="v" id="v8" data-v="8" data-xref="サムエル記下 9:8; サムエル記下 16:9; マルコによる福音書 6:18–19"> アブネルはイシボセテの言葉を聞き、非常に怒って言った、「わたしはユダの犬のかしらですか。わたしはきょう、あなたの父サウルの家と、その兄弟と、その友人とに忠誠をあらわして、あなたをダビデの手に渡すことをしなかったのに、あなたはきょう、女の事のあやまちを挙げてわたしを責められる。</span>
<span className="v" id="v9" data-v="9" data-xref="サムエル記上 15:28; 列王紀上 19:2; ルツ記 1:17"> 主がダビデに誓われたことを、わたしが彼のためになし遂げないならば、神がアブネルをいくえにも罰しられるように。</span>
<span className="v" id="v10" data-v="10" data-xref="士師記 20:1; サムエル記上 3:20; 列王紀上 4:25"> すなわち王国をサウルの家から移し、ダビデの位をダンからベエルシバに至るまで、イスラエルとユダの上に立たせられるであろう」。</span>
<span className="v" id="v11" data-v="11"> イシボセテはアブネルを恐れたので、ひと言も彼に答えることができなかった。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="歴代志上 12:38–40; サムエル記下 3:21; ルカによる福音書 16:5–8"> アブネルはヘブロンにいるダビデのもとに使者をつかわして言った、「国はだれのものですか。わたしと契約を結びなさい。わたしはあなたに力添えして、イスラエルをことごとくあなたのものにしましょう」。</span>
<span className="v" id="v13" data-v="13" data-xref="創世記 43:3; サムエル記上 19:11–17; 創世記 44:23"> ダビデは言った、「よろしい。わたしは、あなたと契約を結びましょう。ただし一つの事をあなたに求めます。あなたがきてわたしの顔を見るとき、まずサウルの娘ミカルを連れて来るのでなければ、わたしの顔を見ることはできません」。</span>
<span className="v" id="v14" data-v="14" data-xref="サムエル記上 18:27; サムエル記上 18:25; サムエル記下 2:10"> それからダビデは使者をサウルの子イシボセテにつかわして言った、「ペリシテびとの陽の皮一百をもってめとったわたしの妻ミカルを引き渡しなさい」。</span>
<span className="v" id="v15" data-v="15" data-xref="サムエル記上 25:44"> そこでイシボセテは人をやって彼女をその夫、ライシの子パルテエルから取ったので、</span>
<span className="v" id="v16" data-v="16" data-xref="サムエル記下 16:5; サムエル記下 19:16; 列王紀上 2:8"> その夫は彼女と共に行き、泣きながら彼女のあとについて、バホリムまで行ったが、アブネルが彼に「帰って行け」と言ったので彼は帰った。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17"> アブネルはイスラエルの長老たちと協議して言った、「あなたがたは以前からダビデをあなたがたの王とすることを求めていましたが、</span>
<span className="v" id="v18" data-v="18" data-xref="サムエル記上 15:28; 詩篇 89:19–23; サムエル記上 9:16"> 今それをしなさい。主がダビデについて、『わたしのしもべダビデの手によって、わたしの民イスラエルをペリシテびとの手、およびもろもろの敵の手から救い出すであろう』と言われたからです」。</span>
<span className="v" id="v19" data-v="19" data-xref="歴代志上 12:29; サムエル記上 10:20–21; 詩篇 68:27"> アブネルはまたベニヤミンにも語った。そしてアブネルは、イスラエルとベニヤミンの全家が良いと思うことをみな、ヘブロンでダビデに告げようとして出発した。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="創世記 31:54; 創世記 26:30; エステル記 1:3"> アブネルが二十人を従えてヘブロンにいるダビデのもとに行った時、ダビデはアブネルと彼に従っている従者たちのために酒宴を設けた。</span>
<span className="v" id="v21" data-v="21" data-xref="サムエル記下 3:12; 列王紀上 11:37; サムエル記下 3:10"> アブネルはダビデに言った、「わたしは立って行き、イスラエルをことごとく、わが主、王のもとに集めて、あなたと契約を結ばせ、あなたの望むものをことごとく治められるようにいたしましょう」。こうしてダビデはアブネルを送り帰らせたので彼は安全に去って行った。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22"> ちょうどその時、ダビデの家来たちはヨアブと共に多くのぶんどり物を携えて略奪から帰ってきた。しかしアブネルはヘブロンのダビデのもとにはいなかった。ダビデが彼を帰らせて彼が安全に去ったからである。</span>
<span className="v" id="v23" data-v="23"> ヨアブおよび彼と共にいた軍勢がみな帰ってきたとき、人々はヨアブに言った、「ネルの子アブネルが王のもとにきたが、王が彼を帰らせたので彼は安全に去った」。</span>
<span className="v" id="v24" data-v="24" data-xref="サムエル記下 3:8; サムエル記下 19:5–7; ヨハネによる福音書 18:35"> そこでヨアブは王のもとに行って言った、「あなたは何をなさったのですか。アブネルがあなたの所にきたのに、あなたはどうして、彼を返し去らせられたのですか。</span>
<span className="v" id="v25" data-v="25" data-xref="申命記 28:6; イザヤ書 37:28; 民数記 27:17"> ネルの子アブネルがあなたを欺くためにきたこと、そしてあなたの出入りを知り、またあなたのなさっていることを、ことごとく知るためにきたことをあなたはごぞんじです」。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="箴言 26:23–26; 箴言 27:4–6"> ヨアブはダビデの所から出てきて、使者をつかわし、アブネルを追わせたので、彼らはシラの井戸から彼を連れて帰った。しかしダビデはその事を知らなかった。</span>
<span className="v" id="v27" data-v="27" data-xref="列王紀上 2:5; サムエル記下 20:9–10; 列王紀上 2:32"> アブネルがヘブロンに帰ってきたとき、ヨアブはひそかに語ろうといって彼を門のうちに連れて行き、その所で彼の腹を刺して死なせ、自分の兄弟アサヘルの血を報いた。</span>
<span className="v" id="v28" data-v="28" data-xref="民数記 35:33; 出エジプト記 21:12; 創世記 9:6"> その後ダビデはこの事を聞いて言った、「わたしとわたしの王国とは、ネルの子アブネルの血に関して、主の前に永久に罪はない。</span>
<span className="v" id="v29" data-v="29" data-xref="サムエル記下 1:16; 詩篇 109:8–19; レビ記 13:44–46"> どうぞ、その罪がヨアブの頭と、その父の全家に帰するように。またヨアブの家には流出を病む者、らい病人、つえにたよる者、つるぎに倒れる者、または食物の乏しい者が絶えないように」。</span>
<span className="v" id="v30" data-v="30" data-xref="箴言 28:17; 使徒行伝 28:4; サムエル記下 2:19–23"> こうしてヨアブとその弟アビシャイとはアブネルを殺したが、それは彼がギベオンの戦いで彼らの兄弟アサヘルを殺したためであった。</span>
</div>
<div className="bp poetry">
<span className="v" id="v31" data-v="31" data-xref="創世記 37:34; サムエル記下 1:11; サムエル記下 1:2"> ダビデはヨアブおよび自分と共にいるすべての民に言った、「あなたがたは着物を裂き、荒布をまとい、アブネルの前に嘆きながら行きなさい」。そしてダビデ王はその棺のあとに従った。</span>
<span className="v" id="v32" data-v="32" data-xref="箴言 24:17; ヨブ記 31:28; サムエル記上 30:4"> 人々はアブネルをヘブロンに葬った。王はアブネルの墓で声をあげて泣き、民もみな泣いた。</span>
<span className="v" id="v33" data-v="33" data-xref="サムエル記下 1:17; 歴代志下 35:25; ルカによる福音書 12:19–20"> 王はアブネルのために悲しみの歌を作って言った、<br /><span className="pl pl-1">「愚かな人の死ぬように、</span><br /><span className="pl pl-1">アブネルがどうして死んだのか。</span></span>
<span className="v" id="v34" data-v="34" data-xref="士師記 16:21; サムエル記下 1:12; ヨブ記 24:14"> <span className="pl pl-1">あなたの手は縛られず、</span><br /><span className="pl pl-1">足には足かせもかけられないのに、</span><br /><span className="pl pl-1">悪人の前に倒れる人のように、</span><br /><span className="pl pl-1">あなたは倒れた」。</span><br />そして民は皆、ふたたび彼のために泣いた。</span>
<span className="v" id="v35" data-v="35" data-xref="サムエル記下 12:17; サムエル記下 1:12; ルツ記 1:17"> 民はみなきて、日のあるうちに、ダビデにパンを食べさせようとしたが、ダビデは誓って言った、「もしわたしが日の入る前に、パンでも、ほかのものでも味わうならば、神がわたしをいくえにも罰しられるように」。</span>
<span className="v" id="v36" data-v="36" data-xref="マルコによる福音書 7:37; 詩篇 62:9; マルコによる福音書 15:11–13"> 民はみなそれを見て満足した。すべて王のすることは民を満足させた。</span>
<span className="v" id="v37" data-v="37"> その日すべての民およびイスラエルは皆、ネルの子アブネルを殺したのは、王の意思によるものでないことを知った。</span>
<span className="v" id="v38" data-v="38" data-xref="ヨブ記 32:9; サムエル記下 2:8; サムエル記下 3:12"> 王はその家来たちに言った、「この日イスラエルで、ひとりの偉大なる将軍が倒れたのをあなたがたは知らないのか。</span>
<span className="v" id="v39" data-v="39" data-xref="列王紀上 2:33–34; 詩篇 101:8; 詩篇 28:4"> わたしは油を注がれた王であるけれども、今日なお弱い。ゼルヤの子であるこれらの人々はわたしの手におえない。どうぞ主が悪を行う者に、その悪にしたがって報いられるように」。</span>
</div>

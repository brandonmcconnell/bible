<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="コリント人への第二の手紙 5:7; コリント人への第二の手紙 4:18; ローマ人への手紙 8:24–25"> さて、信仰とは、望んでいる事がらを確信し、まだ見ていない事実を確認することである。</span>
<span className="v" id="v2" data-v="2" data-xref="ヘブル人への手紙 11:39; ヘブル人への手紙 11:4"> 昔の人たちは、この信仰のゆえに賞賛された。</span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 33:6; ペテロの第二の手紙 3:5; ヨハネによる福音書 1:3"> 信仰によって、わたしたちは、この世界が神の言葉で造られたのであり、したがって、見えるものは現れているものから出てきたのでないことを、悟るのである。</span>
<span className="v" id="v4" data-v="4" data-xref="ヘブル人への手紙 12:24; 創世記 4:3–5; ヨハネの第一の手紙 3:11–12"> 信仰によって、アベルはカインよりもまさったいけにえを神にささげ、信仰によって義なる者と認められた。神が、彼の供え物をよしとされたからである。彼は死んだが、信仰によって今もなお語っている。</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 5:21–24; ユダの手紙 1:14; ヘブル人への手紙 11:6"> 信仰によって、エノクは死を見ないように天に移された。神がお移しになったので、彼は見えなくなった。彼が移される前に、神に喜ばれた者と、あかしされていたからである。</span>
<span className="v" id="v6" data-v="6" data-xref="箴言 8:17; エレミヤ書 29:13–14; マタイによる福音書 6:33"> 信仰がなくては、神に喜ばれることはできない。なぜなら、神に来る者は、神のいますことと、ご自身を求める者に報いて下さることとを、必ず信じるはずだからである。</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 6:13–1; ペテロの第一の手紙 3:20; エゼキエル書 14:14"> 信仰によって、ノアはまだ見ていない事がらについて御告げを受け、恐れかしこみつつ、その家族を救うために箱舟を造り、その信仰によって世の罪をさばき、そして、信仰による義を受け継ぐ者となった。</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 12:1–4; 使徒行伝 7:2–4; マタイによる福音書 7:24–25"> 信仰によって、アブラハムは、受け継ぐべき地に出て行けとの召しをこうむった時、それに従い、行く先を知らないで出て行った。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 12:8; 創世記 13:18; 創世記 13:3"> 信仰によって、他国にいるようにして約束の地に宿り、同じ約束を継ぐイサク、ヤコブと共に、幕屋に住んだ。</span>
<span className="v" id="v10" data-v="10" data-xref="ヘブル人への手紙 13:14; ピリピ人への手紙 3:20; ヘブル人への手紙 12:22"> 彼は、ゆるがぬ土台の上に建てられた都を、待ち望んでいたのである。その都をもくろみ、また建てたのは、神である。</span>
<span className="v" id="v11" data-v="11" data-xref="ローマ人への手紙 4:20–21; ヘブル人への手紙 10:23; 創世記 18:11–14"> 信仰によって、サラもまた、年老いていたが、種を宿す力を与えられた。約束をなさったかたは真実であると、信じていたからである。</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 22:17; 創世記 32:12; 創世記 15:5"> このようにして、ひとりの死んだと同様な人から、天の星のように、海べの数えがたい砂のように、おびただしい人が生れてきたのである。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="創世記 23:4; 詩篇 39:12; ヘブル人への手紙 11:27"> これらの人はみな、信仰をいだいて死んだ。まだ約束のものは受けていなかったが、はるかにそれを望み見て喜び、そして、地上では旅人であり寄留者であることを、自ら言いあらわした。</span>
<span className="v" id="v14" data-v="14" data-xref="コリント人への第二の手紙 4:18–7; ヘブル人への手紙 11:16; ヘブル人への手紙 13:14"> そう言いあらわすことによって、彼らがふるさとを求めていることを示している。</span>
<span className="v" id="v15" data-v="15" data-xref="創世記 24:6–8; 創世記 12:10; 創世記 32:9–11"> もしその出てきた所のことを考えていたなら、帰る機会はあったであろう。</span>
<span className="v" id="v16" data-v="16" data-xref="ヘブル人への手紙 13:14; ヘブル人への手紙 11:10; ピリピ人への手紙 3:20"> しかし実際、彼らが望んでいたのは、もっと良い、天にあるふるさとであった。だから神は、彼らの神と呼ばれても、それを恥とはされなかった。事実、神は彼らのために、都を用意されていたのである。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="創世記 22:16; 創世記 22:1–12; ヤコブの手紙 2:21–24"> 信仰によって、アブラハムは、試錬を受けたとき、イサクをささげた。すなわち、約束を受けていた彼が、そのひとり子をささげたのである。</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 21:12; ローマ人への手紙 9:7; 創世記 17:19"> この子については、「イサクから出る者が、あなたの子孫と呼ばれるであろう」と言われていたのであった。</span>
<span className="v" id="v19" data-v="19" data-xref="ローマ人への手紙 4:17–21; マタイによる福音書 9:28; エペソ人への手紙 3:20"> 彼は、神が死人の中から人をよみがえらせる力がある、と信じていたのである。だから彼は、いわば、イサクを生きかえして渡されたわけである。</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 27:27–40; 創世記 28:2–3"> 信仰によって、イサクは、きたるべきことについて、ヤコブとエサウとを祝福した。</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 47:31–1; 創世記 48:5–22"> 信仰によって、ヤコブは死のまぎわに、ヨセフの子らをひとりびとり祝福し、そしてそのつえのかしらによりかかって礼拝した。</span>
<span className="v" id="v22" data-v="22" data-xref="出エジプト記 13:19; 創世記 50:24–25; ヨシュア記 24:32"> 信仰によって、ヨセフはその臨終に、イスラエルの子らの出て行くことを思い、自分の骨のことについてさしずした。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="出エジプト記 1:22; 出エジプト記 1:16; ヘブル人への手紙 13:6"> 信仰によって、モーセの生れたとき、両親は、三か月のあいだ彼を隠した。それは、彼らが子供のうるわしいのを見たからである。彼らはまた、王の命令をも恐れなかった。</span>
<span className="v" id="v24" data-v="24" data-xref="出エジプト記 2:10–11; 使徒行伝 7:21–24"> 信仰によって、モーセは、成人したとき、パロの娘の子と言われることを拒み、</span>
<span className="v" id="v25" data-v="25" data-xref="詩篇 84:10; テモテヘの第二の手紙 2:3–10; ヨブ記 36:21"> 罪のはかない歓楽にふけるよりは、むしろ神の民と共に虐待されることを選び、</span>
<span className="v" id="v26" data-v="26" data-xref="ヘブル人への手紙 10:35; ヘブル人への手紙 11:6; ペテロの第一の手紙 4:14"> キリストのゆえに受けるそしりを、エジプトの宝にまさる富と考えた。それは、彼が報いを望み見ていたからである。</span>
<span className="v" id="v27" data-v="27" data-xref="コリント人への第二の手紙 4:18; ヘブル人への手紙 11:13; ヘブル人への手紙 11:1"> 信仰によって、彼は王の憤りをも恐れず、エジプトを立ち去った。彼は、見えないかたを見ているようにして、忍びとおした。</span>
<span className="v" id="v28" data-v="28" data-xref="出エジプト記 12:21–30; ヘブル人への手紙 9:19; ヘブル人への手紙 12:24"> 信仰によって、滅ぼす者が、長子らに手を下すことのないように、彼は過越を行い血を塗った。</span>
<span className="v" id="v29" data-v="29" data-xref="出エジプト記 14:13–21; 詩篇 106:9–11; 詩篇 78:13"> 信仰によって、人々は紅海をかわいた土地をとおるように渡ったが、同じことを企てたエジプト人はおぼれ死んだ。</span>
<span className="v" id="v30" data-v="30" data-xref="ヨシュア記 6:3–20; コリント人への第二の手紙 10:4–5"> 信仰によって、エリコの城壁は、七日にわたってまわったために、くずれおちた。</span>
<span className="v" id="v31" data-v="31" data-xref="ヤコブの手紙 2:25; ヨシュア記 6:22–25; マタイによる福音書 1:5"> 信仰によって、遊女ラハブは、探りにきた者たちをおだやかに迎えたので、不従順な者どもと一緒に滅びることはなかった。</span>
<span className="v" id="v32" data-v="32" data-xref="サムエル記上 16:1; サムエル記上 1:20; サムエル記上 16:13"> このほか、何を言おうか。もしギデオン、バラク、サムソン、エフタ、ダビデ、サムエル及び預言者たちについて語り出すなら、時間が足りないであろう。</span>
<span className="v" id="v33" data-v="33" data-xref="詩篇 144:1–2; ヘブル人への手紙 6:12–15; ヘブル人への手紙 10:36"> 彼らは信仰によって、国々を征服し、義を行い、約束のものを受け、ししの口をふさぎ、</span>
<span className="v" id="v34" data-v="34" data-xref="列王紀下 6:16–18; コリント人への第二の手紙 12:9–10; サムエル記上 17:51–52"> 火の勢いを消し、つるぎの刃をのがれ、弱いものは強くされ、戦いの勇者となり、他国の軍を退かせた。</span>
<span className="v" id="v35" data-v="35" data-xref="列王紀下 4:27–37; 列王紀上 17:22–24; ピリピ人への手紙 3:11"> 女たちは、その死者たちをよみがえらさせてもらった。ほかの者は、更にまさったいのちによみがえるために、拷問の苦しみに甘んじ、放免されることを願わなかった。</span>
<span className="v" id="v36" data-v="36" data-xref="エレミヤ書 20:2; 創世記 39:20; エレミヤ書 37:15–21"> なおほかの者たちは、あざけられ、むち打たれ、しばり上げられ、投獄されるほどのめに会った。</span>
<span className="v" id="v37" data-v="37" data-xref="歴代志下 24:21; エレミヤ書 26:23; 列王紀上 19:10"> あるいは、石で打たれ、さいなまれ、のこぎりで引かれ、つるぎで切り殺され、羊の皮や、やぎの皮を着て歩きまわり、無一物になり、悩まされ、苦しめられ、</span>
<span className="v" id="v38" data-v="38" data-xref="列王紀上 18:4; サムエル記上 22:1; 列王紀上 19:9"> （この世は彼らの住む所ではなかった）、荒野と山の中と岩の穴と土の穴とを、さまよい続けた。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="ルカによる福音書 10:23–24; ヘブル人への手紙 11:13; ヘブル人への手紙 11:2"> さて、これらの人々はみな、信仰によってあかしされたが、約束のものは受けなかった。</span>
<span className="v" id="v40" data-v="40" data-xref="ヨハネの黙示録 6:11; ヘブル人への手紙 8:6; ヘブル人への手紙 10:11–14"> 神はわたしたちのために、さらに良いものをあらかじめ備えて下さっているので、わたしたちをほかにしては彼らが全うされることはない。</span>
</div>

<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="ヘブル人への手紙 1:3; コロサイ人への手紙 3:1; ヨハネの黙示録 3:21"> 以上述べたことの要点は、このような大祭司がわたしたちのためにおられ、天にあって大能者の御座の右に座し、</span>
<span className="v" id="v2" data-v="2" data-xref="出エジプト記 33:7; コリント人への第二の手紙 5:1; ヘブル人への手紙 9:23–24"> 人間によらず主によって設けられた真の幕屋なる聖所で仕えておられる、ということである。</span>
<span className="v" id="v3" data-v="3" data-xref="エペソ人への手紙 5:2; ヘブル人への手紙 5:1; ヘブル人への手紙 9:14"> おおよそ、大祭司が立てられるのは、供え物やいけにえをささげるためにほかならない。したがって、この大祭司もまた、何かささぐべき物を持っておられねばならない。</span>
<span className="v" id="v4" data-v="4" data-xref="ヘブル人への手紙 7:11–15; ヘブル人への手紙 5:1; 民数記 17:12–13"> そこで、もし彼が地上におられたなら、律法にしたがって供え物をささげる祭司たちが、現にいるのだから、彼は祭司ではあり得なかったであろう。</span>
<span className="v" id="v5" data-v="5" data-xref="出エジプト記 25:40; コロサイ人への手紙 2:17; ヘブル人への手紙 10:1"> 彼らは、天にある聖所のひな型と影とに仕えている者にすぎない。それについては、モーセが幕屋を建てようとしたとき、御告げを受け、「山で示された型どおりに、注意してそのいっさいを作りなさい」と言われたのである。</span>
<span className="v" id="v6" data-v="6" data-xref="ヘブル人への手紙 7:22; ガラテヤ人への手紙 3:16–21; ヘブル人への手紙 12:24"> ところがキリストは、はるかにすぐれた務を得られたのである。それは、さらにまさった約束に基いて立てられた、さらにまさった契約の仲保者となられたことによる。</span>
<span className="v" id="v7" data-v="7" data-xref="ヘブル人への手紙 7:11; ガラテヤ人への手紙 3:21; ヘブル人への手紙 7:18"> もし初めの契約に欠けたところがなかったなら、あとのものが立てられる余地はなかったであろう。</span>
<span className="v" id="v8" data-v="8" data-xref="エレミヤ書 31:31–34; ヘブル人への手紙 10:16–17; ヘブル人への手紙 12:24"> ところが、神は彼らを責めて言われた、<br /><span className="pl pl-1">「主は言われる、見よ、</span><br /><span className="pl pl-1">わたしがイスラエルの家およびユダの家と、</span><br /><span className="pl pl-1">新しい契約を結ぶ日が来る。</span></span>
<span className="v" id="v9" data-v="9" data-xref="エレミヤ書 31:32; ガラテヤ人への手紙 4:24; マルコによる福音書 8:23"> <span className="pl pl-1">それは、わたしが彼らの先祖たちの手をとって、</span><br /><span className="pl pl-1">エジプトの地から導き出した日に、</span><br /><span className="pl pl-1">彼らと結んだ契約のようなものではない。</span><br /><span className="pl pl-1">彼らがわたしの契約にとどまることをしないので、</span><br /><span className="pl pl-1">わたしも彼らをかえりみなかったからであると、</span><br /><span className="pl pl-1">主が言われる。</span></span>
<span className="v" id="v10" data-v="10" data-xref="エゼキエル書 36:26–28; エレミヤ書 31:33; エゼキエル書 11:19–20"> <span className="pl pl-1">わたしが、それらの日の後、イスラエルの家と立てようとする契約はこれである、と主が言われる。</span><br /><span className="pl pl-1">すなわち、わたしの律法を彼らの思いの中に入れ、</span><br /><span className="pl pl-1">彼らの心に書きつけよう。</span><br /><span className="pl pl-1">こうして、わたしは彼らの神となり、</span><br /><span className="pl pl-1">彼らはわたしの民となるであろう。</span></span>
<span className="v" id="v11" data-v="11" data-xref="エレミヤ書 31:34; イザヤ書 54:13; ヨハネによる福音書 6:45"> <span className="pl pl-1">彼らは、それぞれ、その同胞に、</span><br /><span className="pl pl-1">また、それぞれ、その兄弟に、</span><br /><span className="pl pl-1">主を知れ、と言って教えることはなくなる。</span><br /><span className="pl pl-1">なぜなら、大なる者から小なる者に至るまで、</span><br /><span className="pl pl-1">彼らはことごとく、</span><br /><span className="pl pl-1">わたしを知るようになるからである。</span></span>
<span className="v" id="v12" data-v="12" data-xref="ヘブル人への手紙 10:16–17; イザヤ書 43:25; ローマ人への手紙 11:27"> <span className="pl pl-1">わたしは、彼らの不義をあわれみ、</span><br /><span className="pl pl-1">もはや、彼らの罪を思い出すことはしない」。</span></span>
</div>

<span className="v" id="v1" data-v="1" data-xref="ルカによる福音書 8:15; ペテロの第二の手紙 1:12–13; 箴言 7:1–2"> こういうわけだから、わたしたちは聞かされていることを、いっそう強く心に留めねばならない。そうでないと、おし流されてしまう。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行伝 7:53; ガラテヤ人への手紙 3:19; ヘブル人への手紙 10:28"> というのは、御使たちをとおして語られた御言が効力を持ち、あらゆる罪過と不従順とに対して正当な報いが加えられたとすれば、</span>
<span className="v" id="v3" data-v="3" data-xref="ヘブル人への手紙 10:28–29; ヘブル人への手紙 12:25; ヘブル人への手紙 5:9"> わたしたちは、こんなに尊い救をなおざりにしては、どうして報いをのがれることができようか。この救は、初め主によって語られたものであって、聞いた人々からわたしたちにあかしされ、</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行伝 14:3; エペソ人への手紙 1:5; マルコによる福音書 16:20"> さらに神も、しるしと不思議とさまざまな力あるわざとにより、また、御旨に従い聖霊を各自に賜うことによって、あかしをされたのである。</span>
</div>
<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="ヨハネの黙示録 11:15; ペテロの第二の手紙 3:13; ヘブル人への手紙 6:5"> いったい、神は、わたしたちがここで語っているきたるべき世界を、御使たちに服従させることは、なさらなかった。</span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 8:4–8; 詩篇 144:3; ヨブ記 7:17–18"> 聖書はある箇所で、こうあかししている、<br /><span className="pl pl-1">「人間が何者だから、</span><br /><span className="pl pl-1">これを御心に留められるのだろうか。</span><br /><span className="pl pl-1">人の子が何者だから、</span><br /><span className="pl pl-1">これをかえりみられるのだろうか。</span></span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 8:5; ピリピ人への手紙 2:6–7"> <span className="pl pl-1">あなたは、しばらくの間、</span><br /><span className="pl pl-1">彼を御使たちよりも低い者となし、</span><br /><span className="pl pl-1">栄光とほまれとを冠として彼に与え、</span></span>
<span className="v" id="v8" data-v="8" data-xref="ヨハネによる福音書 13:3; コリント人への第一の手紙 15:27; 詩篇 8:6"> <span className="pl pl-1">万物をその足の下に服従させて下さった」。</span><br />「万物を彼に服従させて下さった」という以上、服従しないものは、何ひとつ残されていないはずである。しかし、今もなお万物が彼に服従している事実を、わたしたちは見ていない。</span>
<span className="v" id="v9" data-v="9" data-xref="ピリピ人への手紙 2:7–9; ヨハネの黙示録 5:9; ヨハネの第一の手紙 4:9–10"> ただ、「しばらくの間、御使たちよりも低い者とされた」イエスが、死の苦しみのゆえに、栄光とほまれとを冠として与えられたのを見る。それは、彼が神の恵みによって、すべての人のために死を味わわれるためであった。</span>
<span className="v" id="v10" data-v="10" data-xref="ローマ人への手紙 11:36; 使徒行伝 5:31; ルカによる福音書 24:46"> なぜなら、万物の帰すべきかた、万物を造られたかたが、多くの子らを栄光に導くのに、彼らの救の君を、苦難をとおして全うされたのは、彼にふさわしいことであったからである。</span>
<span className="v" id="v11" data-v="11" data-xref="ヘブル人への手紙 10:10; ヘブル人への手紙 13:12; ヘブル人への手紙 10:14"> 実に、きよめるかたも、きよめられる者たちも、皆ひとりのかたから出ている。それゆえに主は、彼らを兄弟と呼ぶことを恥とされない。</span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 22:22; 詩篇 40:10; ヨハネによる福音書 18:20"> すなわち、<br /><span className="pl pl-1">「わたしは、御名をわたしの兄弟たちに告げ知らせ、</span><br /><span className="pl pl-1">教会の中で、あなたをほめ歌おう」</span><br />と言い、</span>
<span className="v" id="v13" data-v="13" data-xref="イザヤ書 8:17–18; イザヤ書 12:2; 詩篇 91:2"> また、<br /><span className="pl pl-1">「わたしは、彼により頼む」、</span><br />また、<br /><span className="pl pl-1">「見よ、わたしと、神がわたしに賜わった子らとは」</span><br />と言われた。</span>
<span className="v" id="v14" data-v="14" data-xref="テモテヘの第二の手紙 1:10; ローマ人への手紙 8:3; コロサイ人への手紙 2:15"> このように、子たちは血と肉とに共にあずかっているので、イエスもまた同様に、それらをそなえておられる。それは、死の力を持つ者、すなわち悪魔を、ご自分の死によって滅ぼし、</span>
<span className="v" id="v15" data-v="15" data-xref="ローマ人への手紙 8:15; テモテヘの第二の手紙 1:7; ルカによる福音書 1:74–75"> 死の恐怖のために一生涯、奴隷となっていた者たちを、解き放つためである。</span>
<span className="v" id="v16" data-v="16" data-xref="ガラテヤ人への手紙 3:29; ガラテヤ人への手紙 3:16; ローマ人への手紙 4:16–25"> 確かに、彼は天使たちを助けることはしないで、アブラハムの子孫を助けられた。</span>
<span className="v" id="v17" data-v="17" data-xref="ヘブル人への手紙 4:14–2; ピリピ人への手紙 2:7–8; ヘブル人への手紙 2:14"> そこで、イエスは、神のみまえにあわれみ深い忠実な大祭司となって、民の罪をあがなうために、あらゆる点において兄弟たちと同じようにならねばならなかった。</span>
<span className="v" id="v18" data-v="18" data-xref="コリント人への第一の手紙 10:13; ヘブル人への手紙 4:15–16; ユダの手紙 1:24"> 主ご自身、試錬を受けて苦しまれたからこそ、試錬の中にある者たちを助けることができるのである。</span>

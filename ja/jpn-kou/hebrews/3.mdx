<span className="v" id="v1" data-v="1" data-xref="テモテヘの第二の手紙 1:9; ピリピ人への手紙 3:14; ヘブル人への手紙 4:14–15"> そこで、天の召しにあずかっている聖なる兄弟たちよ。あなたがたは、わたしたちが告白する信仰の使者また大祭司なるイエスを、思いみるべきである。</span>
<span className="v" id="v2" data-v="2" data-xref="民数記 12:7; テモテヘの第一の手紙 3:15; エペソ人への手紙 2:22"> 彼は、モーセが神の家の全体に対して忠実であったように、自分を立てたかたに対して忠実であられた。</span>
<span className="v" id="v3" data-v="3" data-xref="コリント人への第一の手紙 3:9; ペテロの第一の手紙 2:5–7; ゼカリヤ書 6:12–13"> おおよそ、家を造る者が家そのものよりもさらに尊ばれるように、彼は、モーセ以上に、大いなる光栄を受けるにふさわしい者とされたのである。</span>
<span className="v" id="v4" data-v="4" data-xref="ヘブル人への手紙 3:3; ヘブル人への手紙 1:2; エステル記 2:10"> 家はすべて、だれかによって造られるものであるが、すべてのものを造られたかたは、神である。</span>
<span className="v" id="v5" data-v="5" data-xref="民数記 12:7; ヘブル人への手紙 3:2; 出エジプト記 14:31"> さて、モーセは、後に語らるべき事がらについてあかしをするために、仕える者として、神の家の全体に対して忠実であったが、</span>
<span className="v" id="v6" data-v="6" data-xref="コリント人への第二の手紙 6:16; コリント人への第一の手紙 3:16; ヘブル人への手紙 10:35"> キリストは御子として、神の家を治めるのに忠実であられたのである。もしわたしたちが、望みの確信と誇とを最後までしっかりと持ち続けるなら、わたしたちは神の家なのである。</span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 95:7–11; ヘブル人への手紙 3:15; イザヤ書 55:3"> だから、聖霊が言っているように、<br /><span className="pl pl-1">「きょう、あなたがたがみ声を聞いたなら、</span></span>
<span className="v" id="v8" data-v="8" data-xref="箴言 28:14; 出エジプト記 17:7; ゼカリヤ書 7:11–12"> <span className="pl pl-1">荒野における試錬の日に、</span><br /><span className="pl pl-1">神にそむいた時のように、</span><br /><span className="pl pl-1">あなたがたの心を、かたくなにしてはいけない。</span></span>
<span className="v" id="v9" data-v="9" data-xref="使徒行伝 7:36; 申命記 4:9; 出エジプト記 19:4"> <span className="pl pl-1">あなたがたの先祖たちは、</span><br /><span className="pl pl-1">そこでわたしを試みためし、</span></span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 95:10; テサロニケ人への第二の手紙 2:10–12; 詩篇 67:2"> <span className="pl pl-1">しかも、四十年の間わたしのわざを見たのである。</span><br /><span className="pl pl-1">だから、わたしはその時代の人々に対して、</span><br /><span className="pl pl-1">いきどおって言った、</span><br /><span className="pl pl-1">彼らの心は、いつも迷っており、</span><br /><span className="pl pl-1">彼らは、わたしの道を認めなかった。</span></span>
<span className="v" id="v11" data-v="11" data-xref="申命記 1:34–35; ヘブル人への手紙 4:3; 民数記 32:10–13"> <span className="pl pl-1">そこで、わたしは怒って、彼らをわたしの安息にはいらせることはしない、と誓った」。</span></span>
<span className="v" id="v12" data-v="12" data-xref="エレミヤ書 17:5; エレミヤ書 7:24; エレミヤ書 17:9"> <span className="pl pl-1">兄弟たちよ。気をつけなさい。あなたがたの中には、あるいは、不信仰な悪い心をいだいて、生ける神から離れ去る者があるかも知れない。</span></span>
<span className="v" id="v13" data-v="13" data-xref="テサロニケ人への第一の手紙 5:11; ヘブル人への手紙 10:24–25; テモテヘの第二の手紙 4:2"> <span className="pl pl-1">あなたがたの中に、罪の惑わしに陥って、心をかたくなにする者がないように、「きょう」といううちに、日々、互に励まし合いなさい。</span></span>
<span className="v" id="v14" data-v="14" data-xref="ヘブル人への手紙 3:6; ヘブル人への手紙 6:11; ヘブル人への手紙 12:10"> <span className="pl pl-1">もし最初の確信を、最後までしっかりと持ち続けるならば、わたしたちはキリストにあずかる者となるのである。</span></span>
<span className="v" id="v15" data-v="15" data-xref="ヘブル人への手紙 3:7–8; 詩篇 95:7; ヘブル人への手紙 10:38"> <span className="pl pl-1">それについて、こう言われている、</span><br /><span className="pl pl-1">「きょう、み声を聞いたなら、</span><br /><span className="pl pl-1">神にそむいた時のように、</span><br /><span className="pl pl-1">あなたがたの心を、かたくなにしてはいけない」。</span></span>
<span className="v" id="v16" data-v="16" data-xref="民数記 14:2; 民数記 14:30; 民数記 26:65"> <span className="pl pl-1">すると、聞いたのにそむいたのは、だれであったのか。モーセに率いられて、エジプトから出て行ったすべての人々ではなかったか。</span></span>
<span className="v" id="v17" data-v="17" data-xref="民数記 14:29; 民数記 26:64–65; 民数記 14:32–33"> <span className="pl pl-1">また、四十年の間、神がいきどおられたのはだれに対してであったか。罪を犯して、その死かばねを荒野にさらした者たちに対してではなかったか。</span></span>
<span className="v" id="v18" data-v="18" data-xref="民数記 14:30; ヘブル人への手紙 4:6; 申命記 1:34–35"> <span className="pl pl-1">また、神が、わたしの安息に、はいらせることはしない、と誓われたのは、だれに向かってであったか。不従順な者に向かってではなかったか。</span></span>
<span className="v" id="v19" data-v="19" data-xref="ユダの手紙 1:5; ヨハネによる福音書 3:36; マルコによる福音書 16:16"> <span className="pl pl-1">こうして、彼らがはいることのできなかったのは、不信仰のゆえであることがわかる。</span></span>

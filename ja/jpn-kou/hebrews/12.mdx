<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="テモテヘの第二の手紙 4:7; コリント人への第一の手紙 9:24–27; ピリピ人への手紙 2:16"> こういうわけで、わたしたちは、このような多くの証人に雲のように囲まれているのであるから、いっさいの重荷と、からみつく罪とをかなぐり捨てて、わたしたちの参加すべき競走を、耐え忍んで走りぬこうではないか。</span>
<span className="v" id="v2" data-v="2" data-xref="ミカ書 7:7; ペテロの第一の手紙 3:18; ペテロの第一の手紙 2:23–24"> 信仰の導き手であり、またその完成者であるイエスを仰ぎ見つつ、走ろうではないか。彼は、自分の前におかれている喜びのゆえに、恥をもいとわないで十字架を忍び、神の御座の右に座するに至ったのである。</span>
<span className="v" id="v3" data-v="3" data-xref="ガラテヤ人への手紙 6:9; コリント人への第二の手紙 4:16; ヨハネの黙示録 2:3"> あなたがたは、弱り果てて意気そそうしないために、罪人らのこのような反抗を耐え忍んだかたのことを、思いみるべきである。</span>
<span className="v" id="v4" data-v="4" data-xref="コリント人への第一の手紙 10:13; ヨハネの黙示録 2:13; ヘブル人への手紙 10:32–34"> あなたがたは、罪と取り組んで戦う時、まだ血を流すほどの抵抗をしたことがない。</span>
<span className="v" id="v5" data-v="5" data-xref="箴言 3:11–12; ヨブ記 5:17–18; ヨハネの黙示録 3:19"> また子たちに対するように、あなたがたに語られたこの勧めの言葉を忘れている、<br /><span className="pl pl-1">「わたしの子よ、</span><br /><span className="pl pl-1">主の訓練を軽んじてはいけない。</span><br /><span className="pl pl-1">主に責められるとき、弱り果ててはならない。</span></span>
<span className="v" id="v6" data-v="6" data-xref="ヨハネの黙示録 3:19; 箴言 3:12; 詩篇 119:75"> <span className="pl pl-1">主は愛する者を訓練し、</span><br /><span className="pl pl-1">受けいれるすべての子を、</span><br /><span className="pl pl-1">むち打たれるのである」。</span></span>
<span className="v" id="v7" data-v="7" data-xref="箴言 19:18; 申命記 8:5; 箴言 13:24"> <span className="pl pl-1">あなたがたは訓練として耐え忍びなさい。神はあなたがたを、子として取り扱っておられるのである。いったい、父に訓練されない子があるだろうか。</span></span>
<span className="v" id="v8" data-v="8" data-xref="ヘブル人への手紙 12:6; ペテロの第一の手紙 5:9–10; 詩篇 73:1"> <span className="pl pl-1">だれでも受ける訓練が、あなたがたに与えられないとすれば、それこそ、あなたがたは私生子であって、ほんとうの子ではない。</span></span>
<span className="v" id="v9" data-v="9" data-xref="民数記 16:22; 民数記 27:16; イザヤ書 42:5"> <span className="pl pl-1">その上、肉親の父はわたしたちを訓練するのに、なお彼をうやまうとすれば、なおさら、わたしたちは、たましいの父に服従して、真に生きるべきではないか。</span></span>
<span className="v" id="v10" data-v="10" data-xref="ペテロの第二の手紙 1:4; レビ記 11:44–45; テトスヘの手紙 2:14"> <span className="pl pl-1">肉親の父は、しばらくの間、自分の考えに従って訓練を与えるが、たましいの父は、わたしたちの益のため、そのきよさにあずからせるために、そうされるのである。</span></span>
<span className="v" id="v11" data-v="11" data-xref="ローマ人への手紙 5:3–5; コリント人への第二の手紙 4:17; ヘブル人への手紙 12:5–6"> <span className="pl pl-1">すべての訓練は、当座は、喜ばしいものとは思われず、むしろ悲しいものと思われる。しかし後になれば、それによって鍛えられる者に、平安な義の実を結ばせるようになる。</span></span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="イザヤ書 35:3; ヘブル人への手紙 12:3; テサロニケ人への第一の手紙 5:14"> それだから、あなたがたのなえた手と、弱くなっているひざとを、まっすぐにしなさい。</span>
<span className="v" id="v13" data-v="13" data-xref="箴言 4:26–27; イザヤ書 35:3; ガラテヤ人への手紙 6:1"> また、足のなえている者が踏みはずすことなく、むしろいやされるように、あなたがたの足のために、まっすぐな道をつくりなさい。</span>
<span className="v" id="v14" data-v="14" data-xref="コリント人への第二の手紙 7:1; ペテロの第一の手紙 1:15–16; テサロニケ人への第一の手紙 4:7"> すべての人と相和し、また、自らきよくなるように努めなさい。きよくならなければ、だれも主を見ることはできない。</span>
<span className="v" id="v15" data-v="15" data-xref="ヘブル人への手紙 3:12; 申命記 29:18; ガラテヤ人への手紙 5:4"> 気をつけて、神の恵みからもれることがないように、また、苦い根がはえ出て、あなたがたを悩まし、それによって多くの人が汚されることのないようにしなさい。</span>
<span className="v" id="v16" data-v="16" data-xref="創世記 25:31–34; コリント人への第一の手紙 6:15–20; ヨハネの黙示録 22:15"> また、一杯の食のために長子の権利を売ったエサウのように、不品行な俗悪な者にならないようにしなさい。</span>
<span className="v" id="v17" data-v="17" data-xref="箴言 1:24–31; マタイによる福音書 25:11–12; マタイによる福音書 7:23"> あなたがたの知っているように、彼はその後、祝福を受け継ごうと願ったけれども、捨てられてしまい、涙を流してそれを求めたが、悔改めの機会を得なかったのである。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="申命記 4:11; 出エジプト記 24:17; 出エジプト記 20:18"> あなたがたが近づいているのは、手で触れることができ、火が燃え、黒雲や暗やみやあらしにつつまれ、</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 18:16; コリント人への第一の手紙 15:52; 申命記 4:12"> また、ラッパの響や、聞いた者たちがそれ以上、耳にしたくないと願ったような言葉がひびいてきた山ではない。</span>
<span className="v" id="v20" data-v="20" data-xref="出エジプト記 19:12–13; 出エジプト記 19:16; ガラテヤ人への手紙 3:10"> そこでは、彼らは、「けものであっても、山に触たら、石で打ち殺されてしまえ」という命令の言葉に、耐えることができなかったのである。</span>
<span className="v" id="v21" data-v="21" data-xref="出エジプト記 19:16; 申命記 9:19; イザヤ書 6:3–5"> その光景が恐ろしかったのでモーセさえも、「わたしは恐ろしさのあまり、おののいている」と言ったほどである。</span>
<span className="v" id="v22" data-v="22" data-xref="ガラテヤ人への手紙 4:26; ピリピ人への手紙 3:20; ヨハネの黙示録 14:1"> しかしあなたがたが近づいているのは、シオンの山、生ける神の都、天にあるエルサレム、無数の天使の祝会、</span>
<span className="v" id="v23" data-v="23" data-xref="ヤコブの手紙 1:18; ヘブル人への手紙 11:40; ルカによる福音書 10:20"> 天に登録されている長子たちの教会、万民の審判者なる神、全うされた義人の霊、</span>
<span className="v" id="v24" data-v="24" data-xref="ヘブル人への手紙 9:15; ヘブル人への手紙 11:28; ヘブル人への手紙 11:4"> 新しい契約の仲保者イエス、ならびに、アベルの血よりも力強く語るそそがれた血である。</span>
<span className="v" id="v25" data-v="25" data-xref="ヘブル人への手紙 8:5; 申命記 30:17; ヘブル人への手紙 2:1–3"> あなたがたは、語っておられるかたを拒むことがないように、注意しなさい。もし地上で御旨を告げた者を拒んだ人々が、罰をのがれることができなかったなら、天から告げ示すかたを退けるわたしたちは、なおさらそうなるのではないか。</span>
<span className="v" id="v26" data-v="26" data-xref="ハガイ書 2:6–7; イザヤ書 13:13; 出エジプト記 19:18"> あの時には、御声が地を震わせた。しかし今は、約束して言われた、「わたしはもう一度、地ばかりでなく天をも震わそう」。</span>
<span className="v" id="v27" data-v="27" data-xref="コリント人への第一の手紙 7:31; マタイによる福音書 24:35; ペテロの第二の手紙 3:10–11"> この「もう一度」という言葉は、震われないものが残るために、震われるものが、造られたものとして取り除かれることを示している。</span>
<span className="v" id="v28" data-v="28" data-xref="ローマ人への手紙 12:1–2; ヘブル人への手紙 13:15; ダニエル書 2:44"> このように、わたしたちは震われない国を受けているのだから、感謝をしようではないか。そして感謝しつつ、恐れかしこみ、神に喜ばれるように、仕えていこう。</span>
<span className="v" id="v29" data-v="29" data-xref="申命記 4:24; 申命記 9:3; ヘブル人への手紙 10:27"> わたしたちの神は、実に、焼きつくす火である。</span>

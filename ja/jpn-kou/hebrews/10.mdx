<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="ヘブル人への手紙 8:5; ヘブル人への手紙 9:11; コロサイ人への手紙 2:17"> いったい、律法はきたるべき良いことの影をやどすにすぎず、そのものの真のかたちをそなえているものではないから、年ごとに引きつづきささげられる同じようないけにえによっても、みまえに近づいて来る者たちを、全うすることはできないのである。</span>
<span className="v" id="v2" data-v="2" data-xref="イザヤ書 43:25; ミカ書 7:19; 詩篇 103:12"> もしできたとすれば、儀式にたずさわる者たちは、一度きよめられた以上、もはや罪の自覚がなくなるのであるから、ささげ物をすることがやんだはずではあるまいか。</span>
<span className="v" id="v3" data-v="3" data-xref="ヘブル人への手紙 9:7; 出エジプト記 30:10; レビ記 23:27–28"> しかし実際は、年ごとに、いけにえによって罪の思い出がよみがえって来るのである。</span>
<span className="v" id="v4" data-v="4" data-xref="ヘブル人への手紙 10:11; イザヤ書 1:11–15; ミカ書 6:6–8"> なぜなら、雄牛ややぎなどの血は、罪を除き去ることができないからである。</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 40:6–8; イザヤ書 1:11; イザヤ書 7:14"> それだから、キリストがこの世にこられたとき、次のように言われた、<br /><span className="pl pl-1">「あなたは、いけにえやささげ物を望まれないで、</span><br /><span className="pl pl-1">わたしのために、からだを備えて下さった。</span></span>
<span className="v" id="v6" data-v="6" data-xref="マラキ書 1:10; マタイによる福音書 3:17; 詩篇 147:11"> <span className="pl pl-1">あなたは燔祭や罪祭を好まれなかった。</span></span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 40:7–8; ヨハネによる福音書 4:34; ヨハネによる福音書 6:38"> <span className="pl pl-1">その時、わたしは言った、</span><br /><span className="pl pl-1">『神よ、わたしにつき、</span><br /><span className="pl pl-1">巻物の書物に書いてあるとおり、</span><br /><span className="pl pl-1">見よ、御旨を行うためにまいりました』」。</span></span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="ヘブル人への手紙 10:5; マルコによる福音書 12:33"> ここで、初めに、「あなたは、いけにえとささげ物と燔祭と罪祭と（すなわち、律法に従ってささげられるもの）を望まれず、好まれもしなかった」とあり、</span>
<span className="v" id="v9" data-v="9" data-xref="ヘブル人への手紙 7:18–19; ヘブル人への手紙 12:27–28; ヘブル人への手紙 10:7"> 次に、「見よ、わたしは御旨を行うためにまいりました」とある。すなわち、彼は、後のものを立てるために、初めのものを廃止されたのである。</span>
<span className="v" id="v10" data-v="10" data-xref="ヘブル人への手紙 10:14; ヘブル人への手紙 10:12; コリント人への第一の手紙 6:11"> この御旨に基きただ一度イエス・キリストのからだがささげられたことによって、わたしたちはきよめられたのである。</span>
</div>
<div className="bp poetry">
<span className="v" id="v11" data-v="11" data-xref="ヘブル人への手紙 5:1; 民数記 28:3; ヘブル人への手紙 10:4"> こうして、すべての祭司は立って日ごとに儀式を行い、たびたび同じようないけにえをささげるが、それらは決して罪を除き去ることはできない。</span>
<span className="v" id="v12" data-v="12" data-xref="ヘブル人への手紙 1:3; コロサイ人への手紙 3:1; ローマ人への手紙 8:34"> しかるに、キリストは多くの罪のために一つの永遠のいけにえをささげた後、神の右に座し、</span>
<span className="v" id="v13" data-v="13" data-xref="ヘブル人への手紙 1:13; 詩篇 110:1; ルカによる福音書 20:43"> それから、敵をその足台とするときまで、待っておられる。</span>
<span className="v" id="v14" data-v="14" data-xref="ヘブル人への手紙 7:25; ヘブル人への手紙 10:1; ヘブル人への手紙 9:14"> 彼は一つのささげ物によって、きよめられた者たちを永遠に全うされたのである。</span>
<span className="v" id="v15" data-v="15" data-xref="ヘブル人への手紙 3:7; ヨハネの黙示録 2:11; ヨハネの黙示録 3:6"> 聖霊もまた、わたしたちにあかしをして、</span>
<span className="v" id="v16" data-v="16" data-xref="エレミヤ書 31:33–34; ヘブル人への手紙 8:8–12; ローマ人への手紙 11:27"> <span className="pl pl-1">「わたしが、それらの日の後、</span><br /><span className="pl pl-1">彼らに対して立てようとする契約はこれであると、</span><br /><span className="pl pl-1">主が言われる。</span><br /><span className="pl pl-1">わたしの律法を彼らの心に与え、</span><br /><span className="pl pl-1">彼らの思いのうちに書きつけよう」</span><br />と言い、</span>
<span className="v" id="v17" data-v="17" data-xref="エレミヤ書 31:34; ヘブル人への手紙 8:12"> さらに、「もはや、彼らの罪と彼らの不法とを、思い出すことはしない」と述べている。</span>
<span className="v" id="v18" data-v="18" data-xref="ヘブル人への手紙 10:2; ヘブル人への手紙 10:14"> これらのことに対するゆるしがある以上、罪のためのささげ物は、もはやあり得ない。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="エペソ人への手紙 2:18; ヘブル人への手紙 9:12; ヘブル人への手紙 4:16"> 兄弟たちよ。こういうわけで、わたしたちはイエスの血によって、はばかることなく聖所にはいることができ、</span>
<span className="v" id="v20" data-v="20" data-xref="ヨハネによる福音書 14:6; ヨハネによる福音書 10:9; ヘブル人への手紙 9:3"> 彼の肉体なる幕をとおり、わたしたちのために開いて下さった新しい生きた道をとおって、はいって行くことができるのであり、</span>
<span className="v" id="v21" data-v="21" data-xref="ヘブル人への手紙 2:17; ヘブル人への手紙 4:14–16; ヘブル人への手紙 8:1"> さらに、神の家を治める大いなる祭司があるのだから、</span>
<span className="v" id="v22" data-v="22" data-xref="エゼキエル書 36:25; ヨハネによる福音書 3:5; エペソ人への手紙 5:26"> 心はすすがれて良心のとがめを去り、からだは清い水で洗われ、まごころをもって信仰の確信に満たされつつ、みまえに近づこうではないか。</span>
<span className="v" id="v23" data-v="23" data-xref="テサロニケ人への第一の手紙 5:24; コリント人への第一の手紙 1:9; テサロニケ人への第二の手紙 3:3"> また、約束をして下さったのは忠実なかたであるから、わたしたちの告白する望みを、動くことなくしっかりと持ち続け、</span>
<span className="v" id="v24" data-v="24" data-xref="テサロニケ人への第一の手紙 5:11; ヨハネの第一の手紙 3:18; ヘブル人への手紙 13:1"> 愛と善行とを励むように互に努め、</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行伝 2:42; テサロニケ人への第一の手紙 5:11; マタイによる福音書 18:20"> ある人たちがいつもしているように、集会をやめることはしないで互に励まし、かの日が近づいているのを見て、ますます、そうしようではないか。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="ペテロの第二の手紙 2:20–22; ヘブル人への手紙 6:4–6; ヨハネによる福音書 9:41"> もしわたしたちが、真理の知識を受けたのちにもなお、ことさらに罪を犯しつづけるなら、罪のためのいけにえは、もはやあり得ない。</span>
<span className="v" id="v27" data-v="27" data-xref="イザヤ書 26:11; ヘブル人への手紙 2:3; ゼパニヤ書 1:18"> ただ、さばきと、逆らう者たちを焼きつくす激しい火とを、恐れつつ待つことだけがある。</span>
<span className="v" id="v28" data-v="28" data-xref="ヘブル人への手紙 2:2; 申命記 19:15; 申命記 17:2–13"> モーセの律法を無視する者が、あわれみを受けることなしに、二、三の人の証言に基いて死刑に処せられるとすれば、</span>
<span className="v" id="v29" data-v="29" data-xref="ヘブル人への手紙 6:6; エペソ人への手紙 4:30; イザヤ書 63:10"> 神の子を踏みつけ、自分がきよめられた契約の血を汚れたものとし、さらに恵みの御霊を侮る者は、どんなにか重い刑罰に価することであろう。</span>
<span className="v" id="v30" data-v="30" data-xref="申命記 32:35–36; ローマ人への手紙 12:19; ナホム書 1:2"> 「復讐はわたしのすることである。わたし自身が報復する」と言われ、また「主はその民をさばかれる」と言われたかたを、わたしたちは知っている。</span>
<span className="v" id="v31" data-v="31" data-xref="マタイによる福音書 10:28; ルカによる福音書 12:5; ヘブル人への手紙 12:29"> 生ける神のみ手のうちに落ちるのは、恐ろしいことである。</span>
</div>
<div className="bp poetry">
<span className="v" id="v32" data-v="32" data-xref="ヘブル人への手紙 6:4; ヘブル人への手紙 12:4; テモテヘの第二の手紙 2:3–13"> あなたがたは、光に照されたのち、苦しい大きな戦いによく耐えた初めのころのことを、思い出してほしい。</span>
<span className="v" id="v33" data-v="33" data-xref="コリント人への第一の手紙 4:9; ピリピ人への手紙 4:14; ヘブル人への手紙 11:36"> そしられ苦しめられて見せ物にされたこともあれば、このようなめに会った人々の仲間にされたこともあった。</span>
<span className="v" id="v34" data-v="34" data-xref="ペテロの第一の手紙 1:4; テモテヘの第二の手紙 1:16; マタイによる福音書 5:11–12"> さらに獄に入れられた人々を思いやり、また、もっとまさった永遠の宝を持っていることを知って、自分の財産が奪われても喜んでそれを忍んだ。</span>
<span className="v" id="v35" data-v="35" data-xref="コリント人への第一の手紙 15:58; ガラテヤ人への手紙 6:8–10; ヘブル人への手紙 3:6"> だから、あなたがたは自分の持っている確信を放棄してはいけない。その確信には大きな報いが伴っているのである。</span>
<span className="v" id="v36" data-v="36" data-xref="ヘブル人への手紙 12:1; 詩篇 37:7; ヤコブの手紙 5:7–11"> 神の御旨を行って約束のものを受けるため、あなたがたに必要なのは、忍耐である。</span>
<span className="v" id="v37" data-v="37" data-xref="ヤコブの手紙 5:7–9; ハバクク書 2:3–4; ルカによる福音書 18:8"> <span className="pl pl-1">「もうしばらくすれば、</span><br /><span className="pl pl-1">きたるべきかたがお見えになる。</span><br /><span className="pl pl-1">遅くなることはない。</span></span>
<span className="v" id="v38" data-v="38" data-xref="ガラテヤ人への手紙 3:11; ハバクク書 2:4; ローマ人への手紙 1:17"> <span className="pl pl-1">わが義人は、信仰によって生きる。</span><br /><span className="pl pl-1">もし信仰を捨てるなら、</span><br /><span className="pl pl-1">わたしのたましいはこれを喜ばない」。</span></span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="ヨハネの第一の手紙 5:5; ペテロの第一の手紙 1:5; マルコによる福音書 16:16"> しかしわたしたちは、信仰を捨てて滅びる者ではなく、信仰に立って、いのちを得る者である。</span>
</div>

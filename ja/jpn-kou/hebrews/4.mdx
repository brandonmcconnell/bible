<span className="v" id="v1" data-v="1" data-xref="ヘブル人への手紙 12:15; ヘブル人への手紙 4:9; 箴言 28:14"> それだから、神の安息にはいるべき約束が、まだ存続しているにかかわらず、万一にも、はいりそこなう者が、あなたがたの中から出ることがないように、注意しようではないか。</span>
<span className="v" id="v2" data-v="2" data-xref="テサロニケ人への第一の手紙 2:13; ローマ人への手紙 10:16–17; ヘブル人への手紙 11:6"> というのは、彼らと同じく、わたしたちにも福音が伝えられているのである。しかし、その聞いた御言は、彼らには無益であった。それが、聞いた者たちに、信仰によって結びつけられなかったからである。</span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 95:11; マタイによる福音書 11:28–29; ペテロの第一の手紙 1:20"> ところが、わたしたち信じている者は、安息にはいることができる。それは、<br /><span className="pl pl-1">「わたしが怒って、</span><br /><span className="pl pl-1">彼らをわたしの安息に、はいらせることはしないと、誓ったように」</span><br />と言われているとおりである。しかも、みわざは世の初めに、でき上がっていた。</span>
<span className="v" id="v4" data-v="4" data-xref="出エジプト記 20:11; 出エジプト記 31:17; 創世記 2:1–2"> すなわち、聖書のある箇所で、七日目のことについて、「神は、七日目にすべてのわざをやめて休まれた」と言われており、</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 95:11; ヘブル人への手紙 4:3; ヘブル人への手紙 3:11"> またここで、「彼らをわたしの安息に、はいらせることはしない」と言われている。</span>
<span className="v" id="v6" data-v="6" data-xref="マタイによる福音書 21:43; ヘブル人への手紙 3:18–19; 使徒行伝 13:46–47"> そこで、その安息にはいる機会が、人々になお残されているのであり、しかも、初めに福音を伝えられた人々は、不従順のゆえに、はいることをしなかったのであるから、</span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 95:7; ヘブル人への手紙 3:7–8; ヘブル人への手紙 3:15"> 神は、あらためて、ある日を「きょう」として定め、長く時がたってから、先に引用したとおり、<br /><span className="pl pl-1">「きょう、み声を聞いたなら、</span><br /><span className="pl pl-1">あなたがたの心を、かたくなにしてはいけない」</span><br />とダビデをとおして言われたのである。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨシュア記 1:15; ヨシュア記 22:4; 申命記 12:9"> もしヨシュアが彼らを休ませていたとすれば、神はあとになって、ほかの日のことについて語られたはずはない。</span>
<span className="v" id="v9" data-v="9" data-xref="ペテロの第一の手紙 2:10; ヨハネの黙示録 21:4; ヨハネの黙示録 7:14–17"> こういうわけで、安息日の休みが、神の民のためにまだ残されているのである。</span>
<span className="v" id="v10" data-v="10" data-xref="ヨハネの黙示録 14:13; ヘブル人への手紙 4:3–4; ペテロの第一の手紙 4:1–2"> なぜなら、神の安息にはいった者は、神がみわざをやめて休まれたように、自分もわざを休んだからである。</span>
<span className="v" id="v11" data-v="11" data-xref="マタイによる福音書 11:28–30; ルカによる福音書 13:24; ヘブル人への手紙 3:18–1"> したがって、わたしたちは、この安息にはいるように努力しようではないか。そうでないと、同じような不従順の悪例にならって、落ちて行く者が出るかもしれない。</span>
<span className="v" id="v12" data-v="12" data-xref="エレミヤ書 23:29; イザヤ書 55:11; エペソ人への手紙 6:17"> というのは、神の言は生きていて、力があり、もろ刃のつるぎよりも鋭くて、精神と霊魂と、関節と骨髄とを切り離すまでに刺しとおして、心の思いと志とを見分けることができる。</span>
<span className="v" id="v13" data-v="13" data-xref="コリント人への第一の手紙 4:5; 詩篇 33:13–15; 箴言 15:3"> そして、神のみまえには、あらわでない被造物はひとつもなく、すべてのものは、神の目には裸であり、あらわにされているのである。この神に対して、わたしたちは言い開きをしなくてはならない。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="ヘブル人への手紙 9:24; ヘブル人への手紙 12:2; ヘブル人への手紙 9:12"> さて、わたしたちには、もろもろの天をとおって行かれた大祭司なる神の子イエスがいますのであるから、わたしたちの告白する信仰をかたく守ろうではないか。</span>
<span className="v" id="v15" data-v="15" data-xref="ヘブル人への手紙 2:17–18; コリント人への第二の手紙 5:21; イザヤ書 53:4–5"> この大祭司は、わたしたちの弱さを思いやることのできないようなかたではない。罪は犯されなかったが、すべてのことについて、わたしたちと同じように試錬に会われたのである。</span>
<span className="v" id="v16" data-v="16" data-xref="エペソ人への手紙 3:12; ヘブル人への手紙 7:25; ヘブル人への手紙 10:19–23"> だから、わたしたちは、あわれみを受け、また、恵みにあずかって時機を得た助けを受けるために、はばかることなく恵みの御座に近づこうではないか。</span>
</div>

<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="ヨハネの第一の手紙 4:20–1; ペテロの第一の手紙 3:8; ペテロの第一の手紙 1:22"> 兄弟愛を続けなさい。</span>
<span className="v" id="v2" data-v="2" data-xref="マタイによる福音書 25:35; 創世記 18:1–3; ペテロの第一の手紙 4:9"> 旅人をもてなすことを忘れてはならない。このようにして、ある人々は、気づかないで御使たちをもてなした。</span>
<span className="v" id="v3" data-v="3" data-xref="マタイによる福音書 25:36; ヘブル人への手紙 10:34; ローマ人への手紙 12:15"> 獄につながれている人たちを、自分も一緒につながれている心持で思いやりなさい。また、自分も同じ肉体にある者だから、苦しめられている人たちのことを、心にとめなさい。</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 2:24; 箴言 5:15–23; ガラテヤ人への手紙 5:19"> すべての人は、結婚を重んずべきである。また寝床を汚してはならない。神は、不品行な者や姦淫をする者をさばかれる。</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 31:8; ヨシュア記 1:5; 申命記 31:6"> 金銭を愛することをしないで、自分の持っているもので満足しなさい。主は、「わたしは、決してあなたを離れず、あなたを捨てない」と言われた。</span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 118:6–9; イザヤ書 41:10; ローマ人への手紙 8:31"> だから、わたしたちは、はばからずに言おう、<br /><span className="pl pl-1">「主はわたしの助け主である。</span><br /><span className="pl pl-1">わたしには恐れはない。</span><br /><span className="pl pl-1">人は、わたしに何ができようか」。</span></span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="テサロニケ人への第一の手紙 5:12–13; ヘブル人への手紙 13:17; ピリピ人への手紙 3:17"> 神の言をあなたがたに語った指導者たちのことを、いつも思い起しなさい。彼らの生活の最後を見て、その信仰にならいなさい。</span>
<span className="v" id="v8" data-v="8" data-xref="マラキ書 3:6; ヤコブの手紙 1:17; ヨハネの黙示録 1:8"> イエス・キリストは、きのうも、きょうも、いつまでも変ることがない。</span>
<span className="v" id="v9" data-v="9" data-xref="エペソ人への手紙 4:14; テモテヘの第一の手紙 6:3–5; エペソ人への手紙 5:6"> さまざまな違った教によって、迷わされてはならない。食物によらず、恵みによって、心を強くするがよい。食物によって歩いた者は、益を得ることがなかった。</span>
<span className="v" id="v10" data-v="10" data-xref="コリント人への第一の手紙 5:7–8; コリント人への第一の手紙 10:20; コリント人への第一の手紙 9:13"> わたしたちには一つの祭壇がある。幕屋で仕えている者たちは、その祭壇の食物をたべる権利はない。</span>
<span className="v" id="v11" data-v="11" data-xref="レビ記 16:27; 出エジプト記 29:14; レビ記 9:11"> なぜなら、大祭司によって罪のためにささげられるけものの血は、聖所のなかに携えて行かれるが、そのからだは、営所の外で焼かれてしまうからである。</span>
<span className="v" id="v12" data-v="12" data-xref="ヘブル人への手紙 9:12–14; ヨハネによる福音書 19:17–18; 使徒行伝 7:58"> だから、イエスもまた、ご自分の血で民をきよめるために、門の外で苦難を受けられたのである。</span>
<span className="v" id="v13" data-v="13" data-xref="ヘブル人への手紙 11:26; ペテロの第一の手紙 4:14–16; 使徒行伝 5:41"> したがって、わたしたちも、彼のはずかしめを身に負い、営所の外に出て、みもとに行こうではないか。</span>
<span className="v" id="v14" data-v="14" data-xref="ピリピ人への手紙 3:20; コロサイ人への手紙 3:1–3; ヘブル人への手紙 11:12–16"> この地上には、永遠の都はない。きたらんとする都こそ、わたしたちの求めているものである。</span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 107:21–22; 詩篇 50:14; ローマ人への手紙 12:1"> だから、わたしたちはイエスによって、さんびのいけにえ、すなわち、彼の御名をたたえるくちびるの実を、たえず神にささげようではないか。</span>
<span className="v" id="v16" data-v="16" data-xref="テサロニケ人への第二の手紙 3:13; ガラテヤ人への手紙 6:10; ローマ人への手紙 12:13"> そして、善を行うことと施しをすることとを、忘れてはいけない。神は、このようないけにえを喜ばれる。</span>
<span className="v" id="v17" data-v="17" data-xref="テサロニケ人への第一の手紙 5:12–13; テモテヘの第一の手紙 5:17; ヘブル人への手紙 13:7"> あなたがたの指導者たちの言うことを聞きいれて、従いなさい。彼らは、神に言いひらきをすべき者として、あなたがたのたましいのために、目をさましている。彼らが嘆かないで、喜んでこのことをするようにしなさい。そうでないと、あなたがたの益にならない。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="テサロニケ人への第一の手紙 5:25; テサロニケ人への第二の手紙 3:1; コロサイ人への手紙 4:3"> わたしたちのために、祈ってほしい。わたしたちは明らかな良心を持っていると信じており、何事についても、正しく行動しようと願っている。</span>
<span className="v" id="v19" data-v="19" data-xref="ピレモンヘの手紙 1:22; ローマ人への手紙 1:10–12; ローマ人への手紙 15:31–32"> わたしがあなたがたの所に早く帰れるため、祈ってくれるように、特にお願いする。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="ヨハネによる福音書 10:11; ヘブル人への手紙 10:22; 詩篇 23:1"> 永遠の契約の血による羊の大牧者、わたしたちの主イエスを、死人の中から引き上げられた平和の神が、</span>
<span className="v" id="v21" data-v="21" data-xref="ピリピ人への手紙 2:13; テサロニケ人への第二の手紙 2:17; ピリピ人への手紙 4:13"> イエス・キリストによって、みこころにかなうことをわたしたちにして下さり、あなたがたが御旨を行うために、すべての良きものを備えて下さるようにこい願う。栄光が、世々限りなく神にあるように、アァメン。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="ヘブル人への手紙 3:1; ペテロの第一の手紙 5:12; コリント人への第二の手紙 6:1"> 兄弟たちよ。どうかわたしの勧めの言葉を受けいれてほしい。わたしは、ただ手みじかに書いたのだから。</span>
<span className="v" id="v23" data-v="23" data-xref="ピレモンヘの手紙 1:1; テサロニケ人への第一の手紙 3:2; テモテヘの第二の手紙 1:8"> わたしたちの兄弟テモテがゆるされたことを、お知らせする。もし彼が早く来れば、彼と一緒にわたしはあなたがたに会えるだろう。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="ヘブル人への手紙 13:7; ヘブル人への手紙 13:17; 使徒行伝 18:2"> あなたがたの指導者一同と聖徒たち一同に、よろしく伝えてほしい。イタリヤからきた人々から、あなたがたによろしく。</span>
</div>

</div>

<span className="v" id="v1" data-v="1" data-xref="ペテロの第二の手紙 1:20–21; ヨエル書 2:28; 民数記 12:6–8"> 神は、むかしは、預言者たちにより、いろいろな時に、いろいろな方法で、先祖たちに語られたが、</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネによる福音書 1:3; コリント人への第一の手紙 8:6; コロサイ人への手紙 1:16–18"> この終りの時には、御子によって、わたしたちに語られたのである。神は御子を万物の相続者と定め、また、御子によって、もろもろの世界を造られた。</span>
<span className="v" id="v3" data-v="3" data-xref="コロサイ人への手紙 1:15–17; ヨハネの黙示録 4:11; ヨハネによる福音書 14:9–10"> 御子は神の栄光の輝きであり、神の本質の真の姿であって、その力ある言葉をもって万物を保っておられる。そして罪のきよめのわざをなし終えてから、いと高き所にいます大能者の右に、座につかれたのである。</span>
<span className="v" id="v4" data-v="4" data-xref="エペソ人への手紙 1:21; ピリピ人への手紙 2:9–11; ペテロの第一の手紙 3:22"> 御子は、その受け継がれた名が御使たちの名にまさっているので、彼らよりもすぐれた者となられた。</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 2:7; 使徒行伝 13:33; ヘブル人への手紙 5:5"> いったい、神は御使たちのだれに対して、<br /><span className="pl pl-1">「あなたこそは、わたしの子。</span><br /><span className="pl pl-1">きょう、わたしはあなたを生んだ」</span><br />と言い、さらにまた、<br /><span className="pl pl-1">「わたしは彼の父となり、</span><br /><span className="pl pl-1">彼はわたしの子となるであろう」</span><br />と言われたことがあるか。</span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 97:7; コロサイ人への手紙 1:18; 申命記 32:43"> さらにまた、神は、その長子を世界に導き入れるに当って、<br /><span className="pl pl-1">「神の御使たちはことごとく、彼を拝すべきである」</span><br />と言われた。</span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 104:4; ヘブル人への手紙 1:14; 列王紀下 6:17"> また、御使たちについては、<br /><span className="pl pl-1">「神は、御使たちを風とし、</span><br /><span className="pl pl-1">ご自分に仕える者たちを炎とされる」</span><br />と言われているが、</span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 45:6–7; イザヤ書 9:6–7; エレミヤ書 23:5–6"> 御子については、<br /><span className="pl pl-1">「神よ、あなたの御座は、世々限りなく続き、</span><br /><span className="pl pl-1">あなたの支配のつえは、公平のつえである。</span></span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 45:7; 詩篇 23:5; イザヤ書 61:3"> <span className="pl pl-1">あなたは義を愛し、不法を憎まれた。</span><br /><span className="pl pl-1">それゆえに、神、あなたの神は、喜びのあぶらを、</span><br /><span className="pl pl-1">あなたの友に注ぐよりも多く、あなたに注がれた」</span><br />と言い、</span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 102:25–27; 創世記 1:1; ヨハネによる福音書 1:1–3"> さらに、<br /><span className="pl pl-1">「主よ、あなたは初めに、地の基をおすえになった。</span><br /><span className="pl pl-1">もろもろの天も、み手のわざである。</span></span>
<span className="v" id="v11" data-v="11" data-xref="イザヤ書 51:6; マルコによる福音書 13:31; ルカによる福音書 21:33"> <span className="pl pl-1">これらのものは滅びてしまうが、</span><br /><span className="pl pl-1">あなたは、いつまでもいますかたである。</span><br /><span className="pl pl-1">すべてのものは衣のように古び、</span></span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 102:26–27; ヘブル人への手紙 13:8; ヨハネによる福音書 8:58"> <span className="pl pl-1">それらをあなたは、外套のように巻かれる。</span><br /><span className="pl pl-1">これらのものは、衣のように変るが、</span><br /><span className="pl pl-1">あなたは、いつも変ることがなく、</span><br /><span className="pl pl-1">あなたのよわいは、尽きることがない」</span><br />とも言われている。</span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 110:1; マルコによる福音書 12:36; マタイによる福音書 22:44"> 神は、御使たちのだれに対して、<br /><span className="pl pl-1">「あなたの敵を、あなたの足台とするときまでは、</span><br /><span className="pl pl-1">わたしの右に座していなさい」</span><br />と言われたことがあるか。</span>
<span className="v" id="v14" data-v="14" data-xref="詩篇 34:7; 詩篇 103:20–21; 詩篇 91:11–12"> 御使たちはすべて仕える霊であって、救を受け継ぐべき人々に奉仕するため、つかわされたものではないか。</span>

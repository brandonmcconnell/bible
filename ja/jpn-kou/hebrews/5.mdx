<span className="v" id="v1" data-v="1" data-xref="ヘブル人への手紙 8:3; ヘブル人への手紙 10:11; ヘブル人への手紙 7:27"> 大祭司なるものはすべて、人間の中から選ばれて、罪のために供え物といけにえとをささげるように、人々のために神に仕える役に任じられた者である。</span>
<span className="v" id="v2" data-v="2" data-xref="ヘブル人への手紙 4:15; ヘブル人への手紙 2:18; コリント人への第二の手紙 12:9–10"> 彼は自分自身、弱さを身に負うているので、無知な迷っている人々を、思いやることができると共に、</span>
<span className="v" id="v3" data-v="3" data-xref="レビ記 9:7; ヘブル人への手紙 9:7; レビ記 16:6"> その弱さのゆえに、民のためだけではなく自分自身のためにも、罪についてささげものをしなければならないのである。</span>
<span className="v" id="v4" data-v="4" data-xref="出エジプト記 28:1; 民数記 16:40; 民数記 16:5"> かつ、だれもこの栄誉ある務を自分で得るのではなく、アロンの場合のように、神の召しによって受けるのである。</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 2:7; ヨハネによる福音書 8:54; 使徒行伝 13:33"> 同様に、キリストもまた、大祭司の栄誉を自分で得たのではなく、<br /><span className="pl pl-1">「あなたこそは、わたしの子。</span><br /><span className="pl pl-1">きょう、わたしはあなたを生んだ」</span><br />と言われたかたから、お受けになったのである。</span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 110:4; ヘブル人への手紙 7:17; ヘブル人への手紙 7:21"> また、ほかの箇所でこう言われている、<br /><span className="pl pl-1">「あなたこそは、永遠に、</span><br /><span className="pl pl-1">メルキゼデクに等しい祭司である」。</span></span>
<span className="v" id="v7" data-v="7" data-xref="マルコによる福音書 14:32–39; ルカによる福音書 22:41–44; ヨハネによる福音書 17:1"> <span className="pl pl-1">キリストは、その肉の生活の時には、激しい叫びと涙とをもって、ご自分を死から救う力のあるかたに、祈と願いとをささげ、そして、その深い信仰のゆえに聞きいれられたのである。</span></span>
<span className="v" id="v8" data-v="8" data-xref="ピリピ人への手紙 2:8; ヘブル人への手紙 10:5–9; ヨハネによる福音書 4:34"> <span className="pl pl-1">彼は御子であられたにもかかわらず、さまざまの苦しみによって従順を学び、</span></span>
<span className="v" id="v9" data-v="9" data-xref="ヘブル人への手紙 2:10; ヘブル人への手紙 9:12; ヘブル人への手紙 9:15"> <span className="pl pl-1">そして、全き者とされたので、彼に従順であるすべての人に対して、永遠の救の源となり、</span></span>
<span className="v" id="v10" data-v="10" data-xref="ヘブル人への手紙 5:5–6; ヘブル人への手紙 6:20"> <span className="pl pl-1">神によって、メルキゼデクに等しい大祭司と、となえられたのである。</span></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="マタイによる福音書 13:15; 使徒行伝 28:27; ペテロの第二の手紙 3:16"> このことについては、言いたいことがたくさんあるが、あなたがたの耳が鈍くなっているので、それを説き明かすことはむずかしい。</span>
<span className="v" id="v12" data-v="12" data-xref="ヘブル人への手紙 6:1; コリント人への第一の手紙 3:1–3; ペテロの第一の手紙 2:2"> あなたがたは、久しい以前からすでに教師となっているはずなのに、もう一度神の言の初歩を、人から手ほどきしてもらわねばならない始末である。あなたがたは堅い食物ではなく、乳を必要としている。</span>
<span className="v" id="v13" data-v="13" data-xref="コリント人への第一の手紙 14:20; ペテロの第一の手紙 2:2; テモテヘの第二の手紙 3:16"> すべて乳を飲んでいる者は、幼な子なのだから、義の言葉を味わうことができない。</span>
<span className="v" id="v14" data-v="14" data-xref="コリント人への第一の手紙 2:14–15; テサロニケ人への第一の手紙 5:21; エペソ人への手紙 1:18"> しかし、堅い食物は、善悪を見わける感覚を実際に働かせて訓練された成人のとるべきものである。</span>

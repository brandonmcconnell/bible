<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出エジプト記 25:8; ヘブル人への手紙 9:10–11; ヘブル人への手紙 8:2"> さて、初めの契約にも、礼拝についてのさまざまな規定と、地上の聖所とがあった。</span>
<span className="v" id="v2" data-v="2" data-xref="出エジプト記 40:4; レビ記 24:5–8; 出エジプト記 26:35"> すなわち、まず幕屋が設けられ、その前の場所には燭台と机と供えのパンとが置かれていた。これが、聖所と呼ばれた。</span>
<span className="v" id="v3" data-v="3" data-xref="出エジプト記 26:31–33; 出エジプト記 40:3; マタイによる福音書 27:51"> また第二の幕の後に、別の場所があり、それは至聖所と呼ばれた。</span>
<span className="v" id="v4" data-v="4" data-xref="民数記 17:10; 歴代志下 5:10; 出エジプト記 40:3"> そこには金の香壇と全面金でおおわれた契約の箱とが置かれ、その中にはマナのはいっている金のつぼと、芽を出したアロンのつえと、契約の石板とが入れてあり、</span>
<span className="v" id="v5" data-v="5" data-xref="レビ記 16:2; 民数記 7:89; 出エジプト記 25:17–22"> 箱の上には栄光に輝くケルビムがあって、贖罪所をおおっていた。これらのことについては、今ここで、いちいち述べることができない。</span>
<span className="v" id="v6" data-v="6" data-xref="民数記 28:3; 出エジプト記 27:21; ルカによる福音書 1:8–11"> これらのものが、以上のように整えられた上で、祭司たちは常に幕屋の前の場所にはいって礼拝をするのであるが、</span>
<span className="v" id="v7" data-v="7" data-xref="レビ記 16:34; レビ記 5:18; ヘブル人への手紙 10:19–20"> 幕屋の奥には大祭司が年に一度だけはいるのであり、しかも自分自身と民とのあやまちのためにささげる血をたずさえないで行くことはない。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨハネによる福音書 14:6; ヘブル人への手紙 3:7; ヘブル人への手紙 10:19–22"> それによって聖霊は、前方の幕屋が存在している限り、聖所にはいる道はまだ開かれていないことを、明らかに示している。</span>
<span className="v" id="v9" data-v="9" data-xref="ペテロの第一の手紙 3:21; ヘブル人への手紙 5:1; ローマ人への手紙 5:14"> この幕屋というのは今の時代に対する比喩である。すなわち、供え物やいけにえはささげられるが、儀式にたずさわる者の良心を全うすることはできない。</span>
<span className="v" id="v10" data-v="10" data-xref="エペソ人への手紙 2:15; コロサイ人への手紙 2:16; レビ記 11:2–47"> それらは、ただ食物と飲み物と種々の洗いごとに関する行事であって、改革の時まで課せられている肉の規定にすぎない。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="ヘブル人への手紙 9:23–24; コリント人への第二の手紙 5:1; ヘブル人への手紙 8:1–2"> しかしキリストがすでに現れた祝福の大祭司としてこられたとき、手で造られず、この世界に属さない、さらに大きく、完全な幕屋をとおり、</span>
<span className="v" id="v12" data-v="12" data-xref="ヘブル人への手紙 10:4; ペテロの第一の手紙 1:18–19; ヘブル人への手紙 9:15"> かつ、やぎと子牛との血によらず、ご自身の血によって、一度だけ聖所にはいられ、それによって永遠のあがないを全うされたのである。</span>
<span className="v" id="v13" data-v="13" data-xref="民数記 19:2–21; レビ記 16:14–16; 使徒行伝 15:9"> もし、やぎや雄牛の血や雌牛の灰が、汚れた人たちの上にまきかけられて、肉体をきよめ聖別するとすれば、</span>
<span className="v" id="v14" data-v="14" data-xref="ヘブル人への手紙 10:22; ペテロの第一の手紙 1:19; ヨハネの第一の手紙 1:7"> 永遠の聖霊によって、ご自身を傷なき者として神にささげられたキリストの血は、なおさら、わたしたちの良心をきよめて死んだわざを取り除き、生ける神に仕える者としないであろうか。</span>
<span className="v" id="v15" data-v="15" data-xref="ローマ人への手紙 3:24–26; ローマ人への手紙 8:30; ローマ人への手紙 8:28"> それだから、キリストは新しい契約の仲保者なのである。それは、彼が初めの契約のもとで犯した罪過をあがなうために死なれた結果、召された者たちが、約束された永遠の国を受け継ぐためにほかならない。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="ヤコブの手紙 2:10; コリント人への第一の手紙 15:22; ローマ人への手紙 5:12"> いったい、遺言には、遺言者の死の証明が必要である。</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 48:21; ヨハネによる福音書 14:27; ガラテヤ人への手紙 3:15"> 遺言は死によってのみその効力を生じ、遺言者が生きている間は、効力がない。</span>
<span className="v" id="v18" data-v="18" data-xref="出エジプト記 24:3–8; ヘブル人への手紙 9:14; ヘブル人への手紙 9:22"> だから、初めの契約も、血を流すことなしに成立したのではない。</span>
<span className="v" id="v19" data-v="19" data-xref="出エジプト記 24:5–11; 民数記 19:6; ヘブル人への手紙 10:4"> すなわち、モーセが、律法に従ってすべての戒めを民全体に宣言したとき、水と赤色の羊毛とヒソプとの外に、子牛とやぎとの血を取って、契約書と民全体とにふりかけ、</span>
<span className="v" id="v20" data-v="20" data-xref="出エジプト記 24:8; マタイによる福音書 26:28; ヘブル人への手紙 13:20"> そして、「これは、神があなたがたに対して立てられた契約の血である」と言った。</span>
<span className="v" id="v21" data-v="21" data-xref="レビ記 8:15; レビ記 8:19; 出エジプト記 29:36"> 彼はまた、幕屋と儀式用の器具いっさいにも、同様に血をふりかけた。</span>
<span className="v" id="v22" data-v="22" data-xref="レビ記 17:11; レビ記 6:7; レビ記 4:35"> こうして、ほとんどすべての物が、律法に従い、血によってきよめられたのである。血を流すことなしには、罪のゆるしはあり得ない。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="ペテロの第一の手紙 1:19–21; ヘブル人への手紙 10:4; ヘブル人への手紙 9:14"> このように、天にあるもののひな型は、これらのものできよめられる必要があるが、天にあるものは、これらより更にすぐれたいけにえで、きよめられねばならない。</span>
<span className="v" id="v24" data-v="24" data-xref="ヘブル人への手紙 12:2; ヘブル人への手紙 9:11–12; ヘブル人への手紙 9:23"> ところが、キリストは、ほんとうのものの模型にすぎない、手で造った聖所にはいらないで、上なる天にはいり、今やわたしたちのために神のみまえに出て下さったのである。</span>
<span className="v" id="v25" data-v="25" data-xref="ヘブル人への手紙 9:12; ヘブル人への手紙 9:7; ヘブル人への手紙 9:14"> 大祭司は、年ごとに、自分以外のものの血をたずさえて聖所にはいるが、キリストは、そのように、たびたびご自身をささげられるのではなかった。</span>
<span className="v" id="v26" data-v="26" data-xref="ヘブル人への手紙 9:12; ペテロの第一の手紙 1:20; ヘブル人への手紙 1:2"> もしそうだとすれば、世の初めから、たびたび苦難を受けねばならなかったであろう。しかし事実、ご自身をいけにえとしてささげて罪を取り除くために、世の終りに、一度だけ現れたのである。</span>
<span className="v" id="v27" data-v="27" data-xref="コリント人への第二の手紙 5:10; 伝道の書 12:7; 伝道の書 12:14"> そして、一度だけ死ぬことと、死んだ後さばきを受けることとが、人間に定まっているように、</span>
<span className="v" id="v28" data-v="28" data-xref="テトスヘの手紙 2:13; ペテロの第一の手紙 2:24; ローマ人への手紙 6:10"> キリストもまた、多くの人の罪を負うために、一度だけご自身をささげられた後、彼を待ち望んでいる人々に、罪を負うためではなしに二度目に現れて、救を与えられるのである。</span>
</div>

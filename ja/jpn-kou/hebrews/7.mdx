<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 14:18–20; 詩篇 57:2; ヘブル人への手紙 6:20"> このメルキゼデクはサレムの王であり、いと高き神の祭司であったが、王たちを撃破して帰るアブラハムを迎えて祝福し、</span>
<span className="v" id="v2" data-v="2" data-xref="民数記 18:21; 詩篇 85:10–11; サムエル記上 8:17"> それに対して、アブラハムは彼にすべての物の十分の一を分け与えたのである。その名の意味は、第一に義の王、次にまたサレムの王、すなわち平和の王である。</span>
<span className="v" id="v3" data-v="3" data-xref="ヘブル人への手紙 7:17; ヘブル人への手紙 7:23–28; 出エジプト記 6:20–27"> 彼には父がなく、母がなく、系図がなく、生涯の初めもなく、生命の終りもなく、神の子のようであって、いつまでも祭司なのである。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="創世記 14:20; 使徒行伝 2:29; 使徒行伝 7:8–9"> そこで、族長のアブラハムが最もよいぶんどり品の十分の一を与えたのだから、この人がどんなにすぐれた人物であったかが、あなたがたにわかるであろう。</span>
<span className="v" id="v5" data-v="5" data-xref="レビ記 27:30–33; 歴代志下 31:4–6; 民数記 18:21–32"> さて、レビの子のうちで祭司の務をしている者たちは、兄弟である民から、同じくアブラハムの子孫であるにもかかわらず、十分の一を取るように、律法によって命じられている。</span>
<span className="v" id="v6" data-v="6" data-xref="ローマ人への手紙 4:13; ヘブル人への手紙 7:3–4; 創世記 13:14–17"> ところが、彼らの血統に属さないこの人が、アブラハムから十分の一を受けとり、約束を受けている者を祝福したのである。</span>
<span className="v" id="v7" data-v="7" data-xref="歴代志下 30:27; 創世記 48:15–20; テモテヘの第一の手紙 3:16"> 言うまでもなく、小なる者が大なる者から祝福を受けるのである。</span>
<span className="v" id="v8" data-v="8" data-xref="ヘブル人への手紙 6:20; ヘブル人への手紙 5:6; ヨハネの黙示録 1:18"> その上、一方では死ぬべき人間が、十分の一を受けているが、他方では「彼は生きている者」とあかしされた人が、それを受けている。</span>
<span className="v" id="v9" data-v="9" data-xref="ローマ人への手紙 5:12; 創世記 14:20; ヘブル人への手紙 7:4"> そこで、十分の一を受けるべきレビでさえも、アブラハムを通じて十分の一を納めた、と言える。</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 35:11; ヘブル人への手紙 7:5; 創世記 46:26"> なぜなら、メルキゼデクがアブラハムを迎えた時には、レビはまだこの父祖の腰の中にいたからである。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="ヘブル人への手紙 8:7; ガラテヤ人への手紙 2:21; ガラテヤ人への手紙 4:9"> もし全うされることがレビ系の祭司制によって可能であったら――民は祭司制の下に律法を与えられたのであるが――なんの必要があって、なお、「アロンに等しい」と呼ばれない、別な「メルキゼデクに等しい」祭司が立てられるのであるか。</span>
<span className="v" id="v12" data-v="12" data-xref="エレミヤ書 31:31–34; イザヤ書 66:21; エゼキエル書 16:61"> 祭司制に変更があれば、律法にも必ず変更があるはずである。</span>
<span className="v" id="v13" data-v="13" data-xref="ヘブル人への手紙 7:11; ヘブル人への手紙 7:14; 民数記 17:5"> さて、これらのことは、いまだかつて祭壇に奉仕したことのない、他の部族に関して言われているのである。</span>
<span className="v" id="v14" data-v="14" data-xref="ミカ書 5:2; イザヤ書 11:1; ルカによる福音書 3:33"> というのは、わたしたちの主がユダ族の中から出られたことは、明らかであるが、モーセは、この部族について、祭司に関することでは、ひとことも言っていない。</span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 110:4; ヘブル人への手紙 7:17–21; ヘブル人への手紙 7:3"> そしてこの事は、メルキゼデクと同様な、ほかの祭司が立てられたことによって、ますます明白になる。</span>
<span className="v" id="v16" data-v="16" data-xref="ヨハネの黙示録 1:18; コロサイ人への手紙 2:20; ヘブル人への手紙 7:28"> 彼は、肉につける戒めの律法によらないで、朽ちることのないいのちの力によって立てられたのである。</span>
<span className="v" id="v17" data-v="17" data-xref="詩篇 110:4; ヘブル人への手紙 5:6; ヘブル人への手紙 7:21"> それについては、聖書に「あなたこそは、永遠に、メルキゼデクに等しい祭司である」とあかしされている。</span>
<span className="v" id="v18" data-v="18" data-xref="ローマ人への手紙 8:3; 使徒行伝 13:39; ガラテヤ人への手紙 4:9"> このようにして、一方では、前の戒めが弱くかつ無益であったために無効になると共に、</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行伝 13:39; ヘブル人への手紙 4:16; ヘブル人への手紙 9:9"> （律法は、何事をも全うし得なかったからである）、他方では、さらにすぐれた望みが現れてきて、わたしたちを神に近づかせるのである。</span>
<span className="v" id="v20" data-v="20" data-xref="民数記 18:7; ヘブル人への手紙 5:6; 詩篇 110:4"> その上に、このことは誓いをもってなされた。人々は、誓いをしないで祭司とされるのであるが、</span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 110:4; ヘブル人への手紙 7:17; ヘブル人への手紙 6:16–18"> この人の場合は、次のような誓いをもってされたのである。すなわち、彼について、こう言われている、「主は誓われたが、心を変えることをされなかった。あなたこそは、永遠に祭司である」。</span>
<span className="v" id="v22" data-v="22" data-xref="コリント人への第一の手紙 11:25; 創世記 44:32; ヘブル人への手紙 8:6–12"> このようにして、イエスは更にすぐれた契約の保証となられたのである。</span>
<span className="v" id="v23" data-v="23" data-xref="ネヘミヤ書 12:10–11; 歴代志上 6:3–14; ヘブル人への手紙 7:8"> かつ、死ということがあるために、務を続けることができないので、多くの人々が祭司に立てられるのである。</span>
<span className="v" id="v24" data-v="24" data-xref="ヨハネによる福音書 12:34; ヘブル人への手紙 7:28; イザヤ書 9:6–7"> しかし彼は、永遠にいますかたであるので、変らない祭司の務を持ちつづけておられるのである。</span>
<span className="v" id="v25" data-v="25" data-xref="ローマ人への手紙 8:34; ヨハネの第一の手紙 2:1–2; テモテヘの第一の手紙 2:5"> そこでまた、彼は、いつも生きていて彼らのためにとりなしておられるので、彼によって神に来る人々を、いつも救うことができるのである。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="コリント人への第二の手紙 5:21; ヘブル人への手紙 4:14–15; ペテロの第一の手紙 2:22"> このように、聖にして、悪も汚れもなく、罪人とは区別され、かつ、もろもろの天よりも高くされている大祭司こそ、わたしたちにとってふさわしいかたである。</span>
<span className="v" id="v27" data-v="27" data-xref="ヘブル人への手紙 9:28; ヘブル人への手紙 9:12; ヘブル人への手紙 9:14"> 彼は、ほかの大祭司のように、まず自分の罪のため、次に民の罪のために、日々、いけにえをささげる必要はない。なぜなら、自分をささげて、一度だけ、それをされたからである。</span>
<span className="v" id="v28" data-v="28" data-xref="ヘブル人への手紙 2:10; ヘブル人への手紙 7:21; ヘブル人への手紙 1:2"> 律法は、弱さを身に負う人間を立てて大祭司とするが、律法の後にきた誓いの御言は、永遠に全うされた御子を立てて、大祭司としたのである。</span>
</div>

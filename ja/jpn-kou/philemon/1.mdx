<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="コロサイ人への手紙 1:1; エペソ人への手紙 3:1; ピレモンヘの手紙 1:9"> キリスト・イエスの囚人パウロと兄弟テモテから、わたしたちの愛する同労者ピレモン、</span>
<span className="v" id="v2" data-v="2" data-xref="ピリピ人への手紙 2:25; コロサイ人への手紙 4:17; ローマ人への手紙 16:5"> 姉妹アピヤ、わたしたちの戦友アルキポ、ならびに、あなたの家にある教会へ。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="ローマ人への手紙 1:7; エペソ人への手紙 1:2; コリント人への第二の手紙 13:14"> わたしたちの父なる神と主イエス・キリストから、恵みと平安とが、あなたがたにあるように。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="ローマ人への手紙 1:8; エペソ人への手紙 1:16; テサロニケ人への第二の手紙 1:3"> わたしは、祈の時にあなたをおぼえて、いつもわたしの神に感謝している。</span>
<span className="v" id="v5" data-v="5" data-xref="コロサイ人への手紙 1:4; エペソ人への手紙 1:15; コリント人への第一の手紙 16:1"> それは、主イエスに対し、また、すべての聖徒に対するあなたの愛と信仰とについて、聞いているからである。</span>
<span className="v" id="v6" data-v="6" data-xref="ピリピ人への手紙 1:9–11; ペテロの第二の手紙 1:8; コロサイ人への手紙 1:9"> どうか、あなたの信仰の交わりが強められて、わたしたちの間でキリストのためになされているすべての良いことが、知られて来るようになってほしい。</span>
<span className="v" id="v7" data-v="7" data-xref="コリント人への第二の手紙 7:13; テサロニケ人への第一の手紙 3:9; コリント人への第二の手紙 7:4"> 兄弟よ。わたしは、あなたの愛によって多くの喜びと慰めとを与えられた。聖徒たちの心が、あなたによって力づけられたからである。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="テサロニケ人への第一の手紙 2:6; コリント人への第二の手紙 10:8; コリント人への第二の手紙 3:12"> こういうわけで、わたしは、キリストにあってあなたのなすべき事を、きわめて率直に指示してもよいと思うが、</span>
<span className="v" id="v9" data-v="9" data-xref="コリント人への第二の手紙 5:20; エペソ人への手紙 4:1; ローマ人への手紙 12:1"> むしろ、愛のゆえにお願いする。すでに老年になり、今またキリスト・イエスの囚人となっているこのパウロが、</span>
<span className="v" id="v10" data-v="10" data-xref="コロサイ人への手紙 4:9; コリント人への第一の手紙 4:15; テモテヘの第一の手紙 1:2"> 捕われの身で産んだわたしの子供オネシモについて、あなたにお願いする。</span>
<span className="v" id="v11" data-v="11" data-xref="テモテヘの第二の手紙 4:11; ヨブ記 30:1–2; ペテロの第一の手紙 2:10"> 彼は以前は、あなたにとって無益な者であったが、今は、あなたにも、わたしにも、有益な者になった。</span>
<span className="v" id="v12" data-v="12" data-xref="マタイによる福音書 6:14–15; エレミヤ書 31:20; マルコによる福音書 11:25"> 彼をあなたのもとに送りかえす。彼はわたしの心である。</span>
<span className="v" id="v13" data-v="13" data-xref="ピリピ人への手紙 1:7; エペソ人への手紙 3:1; コリント人への第一の手紙 16:17"> わたしは彼を身近に引きとめておいて、わたしが福音のために捕われている間、あなたに代って仕えてもらいたかったのである。</span>
<span className="v" id="v14" data-v="14" data-xref="コリント人への第二の手紙 9:7; 歴代志上 29:17; ペテロの第一の手紙 5:2–3"> しかし、わたしは、あなたの承諾なしには何もしたくない。あなたが強制されて良い行いをするのではなく、自発的にすることを願っている。</span>
<span className="v" id="v15" data-v="15" data-xref="創世記 50:20; 創世記 45:5–8; イザヤ書 20:6"> 彼がしばらくの間あなたから離れていたのは、あなたが彼をいつまでも留めておくためであったかも知れない。</span>
<span className="v" id="v16" data-v="16" data-xref="コロサイ人への手紙 3:22; マタイによる福音書 23:8; コリント人への第一の手紙 7:22"> しかも、もはや奴隷としてではなく、奴隷以上のもの、愛する兄弟としてである。とりわけ、わたしにとってそうであるが、ましてあなたにとっては、肉においても、主にあっても、それ以上であろう。</span>
<span className="v" id="v17" data-v="17" data-xref="コリント人への第二の手紙 8:23; マタイによる福音書 10:40; ピレモンヘの手紙 1:12"> そこで、もしわたしをあなたの信仰の友と思ってくれるなら、わたし同様に彼を受けいれてほしい。</span>
<span className="v" id="v18" data-v="18" data-xref="イザヤ書 53:4–7"> もし、彼があなたに何か不都合なことをしたか、あるいは、何か負債があれば、それをわたしの借りにしておいてほしい。</span>
<span className="v" id="v19" data-v="19" data-xref="ガラテヤ人への手紙 6:11; ガラテヤ人への手紙 5:2; コリント人への第一の手紙 4:15"> このパウロが手ずからしるす、わたしがそれを返済する。この際、あなたが、あなた自身をわたしに負うていることについては、何も言うまい。</span>
<span className="v" id="v20" data-v="20" data-xref="ヨハネの第三の手紙 1:4; ピレモンヘの手紙 1:7; ピレモンヘの手紙 1:12"> 兄弟よ。わたしはあなたから、主にあって何か益を得たいものである。わたしの心を、主にあって力づけてもらいたい。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="テサロニケ人への第二の手紙 3:4; コリント人への第二の手紙 2:3; コリント人への第二の手紙 7:16"> わたしはあなたの従順を堅く信じて、この手紙を書く。あなたは、確かにわたしが言う以上のことをしてくれるだろう。</span>
<span className="v" id="v22" data-v="22" data-xref="コリント人への第二の手紙 1:11; ピリピ人への手紙 2:24; ヨハネの第二の手紙 1:12"> ついでにお願いするが、わたしのために宿を用意しておいてほしい。あなたがたの祈によって、あなたがたの所に行かせてもらえるように望んでいるのだから。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="コロサイ人への手紙 1:7; ローマ人への手紙 16:7; コロサイ人への手紙 4:12"> キリスト・イエスにあって、わたしと共に捕われの身になっているエパフラスから、あなたによろしく。</span>
<span className="v" id="v24" data-v="24" data-xref="テモテヘの第二の手紙 4:10–11; コロサイ人への手紙 4:14; コロサイ人への手紙 4:10"> わたしの同労者たち、マルコ、アリスタルコ、デマス、ルカからも、よろしく。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="テモテヘの第二の手紙 4:22; ローマ人への手紙 16:23; ローマ人への手紙 16:20"> 主イエス・キリストの恵みが、あなたがたの霊と共にあるように。</span>
</div>
</div>

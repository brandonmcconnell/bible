<span className="v" id="v1" data-v="1" data-xref="マタイの福音書 7:15; ユダの手紙 1:4; Deuteronomy 13:1–3"> しかし、イスラエルの中には、にせ預言者も出ました。同じように、あなたがたの中にも、にせ教師が現われるようになります。彼らは、滅びをもたらす異端をひそかに持ち込み、自分たちを買い取ってくださった主を否定するようなことさえして、自分たちの身にすみやかな滅びを招いています。</span>
<span className="v" id="v2" data-v="2" data-xref="ローマ人への手紙 2:24; ユダの手紙 1:10; ペテロの手紙第一 2:12"> そして、多くの者が彼らの好色にならい、そのために真理の道がそしりを受けるのです。</span>
<span className="v" id="v3" data-v="3" data-xref="コリント人への手紙第二 2:17; Deuteronomy 32:35; ローマ人への手紙 16:18"> また彼らは、貪欲なので、作り事のことばをもってあなたがたを食い物にします。彼らに対するさばきは、昔から怠りなく行なわれており、彼らが滅ぼされないままでいることはありません。</span>
<span className="v" id="v4" data-v="4" data-xref="ユダの手紙 1:6; マタイの福音書 25:41; ローマ人への手紙 8:32"> 神は、罪を犯した御使いたちを、容赦せず、地獄に引き渡し、さばきの時まで暗やみの穴の中に閉じ込めてしまわれました。</span>
<span className="v" id="v5" data-v="5" data-xref="ヘブル人への手紙 11:7; ペテロの手紙第二 3:6; ユダの手紙 1:14–15"> また、昔の世界を赦さず、義を宣べ伝えたノアたち八人の者を保護し、不敬虔な世界に洪水を起こされました。</span>
<span className="v" id="v6" data-v="6" data-xref="ユダの手紙 1:7; ルカの福音書 17:28–30; Deuteronomy 29:23"> また、ソドムとゴモラの町を破滅に定めて灰にし、以後の不敬虔な者へのみせしめとされました。</span>
<span className="v" id="v7" data-v="7" data-xref="Genesis 19:16; Genesis 19:29; Genesis 19:7–8"> また、無節操な者たちの好色なふるまいによって悩まされていた義人ロトを救い出されました。</span>
<span className="v" id="v8" data-v="8" data-xref="Psalms 119:158; Ezekiel 9:4; Psalms 119:136"> というのは、この義人は、彼らの間に住んでいましたが、不法な行ないを見聞きして、日々その正しい心を痛めていたからです。</span>
<span className="v" id="v9" data-v="9" data-xref="Psalms 34:15–19; コリント人への手紙第一 10:13; ヨハネの黙示録 3:10"> これらのことでわかるように、主は、敬虔な者たちを誘惑から救い出し、不義な者どもを、さばきの日まで、懲罰のもとに置くことを心得ておられるのです。</span>
<span className="v" id="v10" data-v="10" data-xref="ユダの手紙 1:16; ユダの手紙 1:10; ユダの手紙 1:18"> 汚れた情欲を燃やし、肉に従って歩み、権威を侮る者たちに対しては、特にそうなのです。彼らは、大胆不敵な、尊大な者たちで、栄誉ある人たちをそしって、恐れるところがありません。</span>
<span className="v" id="v11" data-v="11" data-xref="ユダの手紙 1:9; テサロニケ人への手紙第二 1:7; Psalms 104:4"> それに比べると、御使いたちは、勢いにも力にもまさっているにもかかわらず、主の御前に彼らをそしって訴えることはしません。</span>
<span className="v" id="v12" data-v="12" data-xref="ユダの手紙 1:10; Jeremiah 12:3; ガラテヤ人への手紙 6:8"> ところがこの者どもは、捕えられ殺されるために自然に生まれついた、理性のない動物と同じで、自分が知りもしないことをそしるのです。それで動物が滅ぼされるように、彼らも滅ぼされてしまうのです。</span>
<span className="v" id="v13" data-v="13" data-xref="ローマ人への手紙 13:13; ローマ人への手紙 2:8–9; ヘブル人への手紙 2:2–3"> 彼らは不義の報いとして損害を受けるのです。彼らは昼のうちから飲み騒ぐことを楽しみと考えています。彼らは、しみや傷のようなもので、あなたがたといっしょに宴席に連なるときに自分たちのだましごとを楽しんでいるのです。</span>
<span className="v" id="v14" data-v="14" data-xref="ペテロの手紙第二 2:3; ペテロの手紙第二 2:18; エペソ人への手紙 2:3"> その目は淫行に満ちており、罪に関しては飽くことを知らず、心の定まらない者たちを誘惑し、その心は欲に目がありません。彼らはのろいの子です。</span>
<span className="v" id="v15" data-v="15" data-xref="ヨハネの黙示録 2:14; ユダの手紙 1:11; Deuteronomy 23:4–5"> 彼らは正しい道を捨ててさまよっています。不義の報酬を愛したベオルの子バラムの道に従ったのです。</span>
<span className="v" id="v16" data-v="16" data-xref="Numbers 22:21–33; Ecclesiastes 7:25; ルカの福音書 16:11"> しかし、バラムは自分の罪をとがめられました。ものを言うことのないろばが、人間の声でものを言い、この預言者の気違いざたをはばんだのです。</span>
<span className="v" id="v17" data-v="17" data-xref="ユダの手紙 1:12–13; エペソ人への手紙 4:14; Jeremiah 14:3"> この人たちは、水のない泉、突風に吹き払われる霧です。彼らに用意されているものは、まっ暗なやみです。</span>
<span className="v" id="v18" data-v="18" data-xref="ペテロの手紙第二 2:20; ユダの手紙 1:15–16; ローマ人への手紙 13:13"> 彼らは、むなしい大言壮語を吐いており、誤った生き方をしていて、ようやくそれをのがれようとしている人々を肉欲と好色によって誘惑し、</span>
<span className="v" id="v19" data-v="19" data-xref="ヨハネの福音書 8:34; ローマ人への手紙 6:16–22; ガラテヤ人への手紙 5:13"> その人たちに自由を約束しながら、自分自身が滅びの奴隷なのです。人はだれかに征服されれば、その征服者の奴隷となったのです。</span>
<span className="v" id="v20" data-v="20" data-xref="ヘブル人への手紙 10:26–27; ヘブル人への手紙 6:4–8; ピリピ人への手紙 3:19"> 主であり救い主であるイエス・キリストを知ることによって世の汚れからのがれ、その後再びそれに巻き込まれて征服されるなら、そのような人たちの終わりの状態は、初めの状態よりももっと悪いものとなります。</span>
<span className="v" id="v21" data-v="21" data-xref="Ezekiel 18:24; ヘブル人への手紙 6:4–6; ヤコブの手紙 4:17"> 義の道を知っていながら、自分に伝えられたそのきよい命令にそむくよりは、それを知らなかったほうが、彼らにとってよかったのです。</span>
<span className="v" id="v22" data-v="22" data-xref="Proverbs 26:11"> 彼らに起こったことは、「犬は自分の吐いた物に戻る。」とか、「豚は身を洗って、またどろの中にころがる。」とかいう、ことわざどおりです。</span>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="テモテへの手紙第二 1:6; ペテロの手紙第二 1:12–15; ペテロの手紙第一 1:22"> 愛する人たち。いま私がこの第二の手紙をあなたがたに書き送るのは、これらの手紙により、記憶を呼びさまさせて、あなたがたの純真な心を奮い立たせるためなのです。</span>
<span className="v" id="v2" data-v="2" data-xref="ユダの手紙 1:17; ペテロの手紙第二 2:21; ルカの福音書 1:70"> それは、聖なる預言者たちによって前もって語られたみことばと、あなたがたの使徒たちが語った、主であり救い主である方の命令とを思い起こさせるためなのです。</span>
<span className="v" id="v3" data-v="3" data-xref="ユダの手紙 1:18; テモテへの手紙第一 4:1–2; ペテロの手紙第二 2:10"> まず第一に、次のことを知っておきなさい。終わりの日に、あざける者どもがやって来てあざけり、自分たちの欲望に従って生活し、</span>
<span className="v" id="v4" data-v="4" data-xref="Jeremiah 17:15; Malachi 2:17; Jeremiah 5:12–13"> 次のように言うでしょう。「キリストの来臨の約束はどこにあるのか。先祖たちが眠った時からこのかた、何事も創造の初めからのままではないか。」</span>
<span className="v" id="v5" data-v="5" data-xref="ヘブル人への手紙 11:3; Genesis 1:9; Psalms 24:2"> こう言い張る彼らは、次のことを見落としています。すなわち、天は古い昔からあり、地は神のことばによって水から出て、水によって成ったのであって、</span>
<span className="v" id="v6" data-v="6" data-xref="マタイの福音書 24:38–39; ペテロの手紙第二 2:5; ルカの福音書 17:27"> 当時の世界は、その水により、洪水におおわれて滅びました。</span>
<span className="v" id="v7" data-v="7" data-xref="ペテロの手紙第二 3:10; Isaiah 51:6; ペテロの手紙第二 3:12"> しかし、今の天と地は、同じみことばによって、火に焼かれるためにとっておかれ、不敬虔な者どものさばきと滅びとの日まで、保たれているのです。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="Psalms 90:4; ローマ人への手紙 11:25; コリント人への手紙第一 12:1"> しかし、愛する人たち。あなたがたは、この一事を見落としてはいけません。すなわち、主の御前では、一日は千年のようであり、千年は一日のようです。</span>
<span className="v" id="v9" data-v="9" data-xref="テモテへの手紙第一 2:4; ローマ人への手紙 2:4; Habakkuk 2:3"> 主は、ある人たちがおそいと思っているように、その約束のことを遅らせておられるのではありません。かえって、あなたがたに対して忍耐深くあられるのであって、ひとりでも滅びることを望まず、すべての人が悔い改めに進むことを望んでおられるのです。</span>
<span className="v" id="v10" data-v="10" data-xref="ヨハネの黙示録 21:1; マタイの福音書 24:35; ペテロの手紙第二 3:7"> しかし、主の日は、盗人のようにやって来ます。その日には、天は大きな響きをたてて消えうせ、天の万象は焼けてくずれ去り、地と地のいろいろなわざは焼き尽くされます。</span>
<span className="v" id="v11" data-v="11" data-xref="ペテロの手紙第一 1:15; ピリピ人への手紙 1:27; ペテロの手紙第一 2:12"> このように、これらのものはみな、くずれ落ちるものだとすれば、あなたがたは、どれほどきよい生き方をする敬虔な人でなければならないことでしょう。</span>
<span className="v" id="v12" data-v="12" data-xref="ペテロの手紙第二 3:10; Isaiah 34:4; Micah 1:4"> そのようにして、神の日の来るのを待ち望み、その日の来るのを早めなければなりません。その日が来れば、そのために、天は燃えてくずれ、天の万象は焼け溶けてしまいます。</span>
<span className="v" id="v13" data-v="13" data-xref="Isaiah 65:17; ヨハネの黙示録 21:1; Isaiah 66:22"> しかし、私たちは、神の約束に従って、正義の住む新しい天と新しい地を待ち望んでいます。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="テサロニケ人への手紙第一 5:23; テサロニケ人への手紙第一 3:13; ピリピ人への手紙 1:10"> そういうわけで、愛する人たち。このようなことを待ち望んでいるあなたがたですから、しみも傷もない者として、平安をもって御前に出られるように、励みなさい。</span>
<span className="v" id="v15" data-v="15" data-xref="ローマ人への手紙 2:4; ペテロの手紙第二 3:9; テモテへの手紙第一 1:16"> また、私たちの主の忍耐は救いであると考えなさい。それは、私たちの愛する兄弟パウロも、その与えられた知恵に従って、あなたがたに書き送ったとおりです。</span>
<span className="v" id="v16" data-v="16" data-xref="マタイの福音書 15:6; ヘブル人への手紙 5:11; ヤコブの手紙 1:8"> その中で、ほかのすべての手紙でもそうなのですが、このことについて語っています。その手紙の中には理解しにくいところもあります。無知な、心の定まらない人たちは、聖書の他の個所のばあいもそうするのですが、それらの手紙を曲解し、自分自身に滅びを招いています。</span>
<span className="v" id="v17" data-v="17" data-xref="ヘブル人への手紙 3:14; コロサイ人への手紙 2:8; コリント人への手紙第二 11:13–15"> 愛する人たち。そういうわけですから、このことをあらかじめ知っておいて、よく気をつけ、無節操な者たちの迷いに誘い込まれて自分自身の堅実さを失うことにならないようにしなさい。</span>
<span className="v" id="v18" data-v="18" data-xref="コロサイ人への手紙 1:10; エペソ人への手紙 4:15; ペテロの手紙第一 2:2"> 私たちの主であり救い主であるイエス・キリストの恵みと知識において成長しなさい。このキリストに、栄光が、今も永遠の日に至るまでもありますように。アーメン。</span>

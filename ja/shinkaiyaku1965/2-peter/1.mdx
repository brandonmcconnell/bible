<span className="v" id="v1" data-v="1" data-xref="テトスへの手紙 2:13; ローマ人への手紙 3:21–26; テトスへの手紙 1:4"> イエス・キリストのしもべであり使徒であるシモン・ペテロから、私たちの神であり救い主であるイエス・キリストの義によって私たちと同じ尊い信仰を受けた方々へ。</span>
<span className="v" id="v2" data-v="2" data-xref="ペテロの手紙第二 3:18; ヨハネの福音書 17:3; ピリピ人への手紙 3:8"> 神と私たちの主イエスを知ることによって、恵みと平安が、あなたがたの上にますます豊かにされますように。</span>
<span className="v" id="v3" data-v="3" data-xref="ペテロの手紙第一 5:10; テモテへの手紙第二 1:9; ローマ人への手紙 8:28–30"> というのは、私たちをご自身の栄光と徳によってお召しになった方を私たちが知ったことによって、主イエスの、神としての御力は、いのちと敬虔に関するすべてのことを私たちに与えるからです。</span>
<span className="v" id="v4" data-v="4" data-xref="エペソ人への手紙 4:23–24; Ezekiel 36:25–27; コリント人への手紙第二 3:18"> その栄光と徳によって、尊い、すばらしい約束が私たちに与えられました。それは、あなたがたが、その約束のゆえに、世にある欲のもたらす滅びを免れ、神のご性質にあずかる者となるためです。</span>
<span className="v" id="v5" data-v="5" data-xref="ピリピ人への手紙 4:8; Proverbs 4:23; ペテロの手紙第二 3:18"> こういうわけですから、あなたがたは、あらゆる努力をして、信仰には徳を、徳には知識を、</span>
<span className="v" id="v6" data-v="6" data-xref="ヘブル人への手紙 10:36; ローマ人への手紙 5:3–4; ルカの福音書 21:19"> 知識には自制を、自制には忍耐を、忍耐には敬虔を、</span>
<span className="v" id="v7" data-v="7" data-xref="ヘブル人への手紙 13:1; ローマ人への手紙 12:10; テサロニケ人への手紙第一 3:12"> 敬虔には兄弟愛を、兄弟愛には愛を加えなさい。</span>
<span className="v" id="v8" data-v="8" data-xref="テトスへの手紙 3:14; ヨハネの福音書 15:2; ヘブル人への手紙 6:12"> これらがあなたがたに備わり、ますます豊かになるなら、あなたがたは、私たちの主イエス・キリストを知る点で、役に立たない者とか、実を結ばない者になることはありません。</span>
<span className="v" id="v9" data-v="9" data-xref="ペテロの手紙第二 2:18–20; エペソ人への手紙 5:26; テトスへの手紙 2:14"> これらを備えていない者は、近視眼であり、盲目であって、自分の以前の罪がきよめられたことを忘れてしまったのです。</span>
<span className="v" id="v10" data-v="10" data-xref="ペテロの手紙第二 3:17; ルカの福音書 6:47–49; ヘブル人への手紙 6:11"> ですから、兄弟たちよ。ますます熱心に、あなたがたの召されたことと選ばれたこととを確かなものとしなさい。これらのことを行なっていれば、つまずくことなど決してありません。</span>
<span className="v" id="v11" data-v="11" data-xref="ヨハネの黙示録 5:10; マタイの福音書 25:34; ヨハネの黙示録 3:21"> このようにあなたがたは、私たちの主であり救い主であるイエス・キリストの永遠の御国にはいる恵みを豊かに加えられるのです。</span>
<span className="v" id="v12" data-v="12" data-xref="ヨハネの手紙第一 2:21; ローマ人への手紙 15:14–15; ピリピ人への手紙 3:1"> ですから、すでにこれらのことを知っており、現に持っている真理に堅く立っているあなたがたであるとはいえ、私はいつもこれらのことを、あなたがたに思い起こさせようとするのです。</span>
<span className="v" id="v13" data-v="13" data-xref="ペテロの手紙第二 3:1; ペテロの手紙第二 1:14; ヘブル人への手紙 13:3"> 私が地上の幕屋にいる間は、これらのことを思い起こさせることによって、あなたがたを奮い立たせることを、私のなすべきことと思っています。</span>
<span className="v" id="v14" data-v="14" data-xref="テモテへの手紙第二 4:6; ヨハネの福音書 21:18–19; Deuteronomy 31:14"> それは、私たちの主イエス・キリストも、私にはっきりお示しになったとおり、私がこの幕屋を脱ぎ捨てるのが間近に迫っているのを知っているからです。</span>
<span className="v" id="v15" data-v="15" data-xref="Deuteronomy 31:19–29; Psalms 71:18; Joshua 24:24–29"> また、私の去った後に、あなたがたがいつでもこれらのことを思い起こせるよう、私は努めたいのです。</span>
<span className="v" id="v16" data-v="16" data-xref="ヨハネの手紙第一 4:14; ヨハネの福音書 1:14; テモテへの手紙第一 1:4"> 私たちは、あなたがたに、私たちの主イエス・キリストの力と来臨とを知らせましたが、それは、うまく考え出した作り話に従ったのではありません。この私たちは、キリストの威光の目撃者なのです。</span>
<span className="v" id="v17" data-v="17" data-xref="マルコの福音書 9:7; マタイの福音書 17:5; マタイの福音書 3:17"> キリストが父なる神から誉れと栄光をお受けになったとき、おごそかな、栄光の神から、こういう御声がかかりました。「これはわたしの愛する子、わたしの喜ぶ者である。」</span>
<span className="v" id="v18" data-v="18" data-xref="マタイの福音書 17:6; Joshua 5:15; Exodus 3:5"> 私たちは聖なる山で主イエスとともにいたので、天からかかったこの御声を、自分自身で聞いたのです。</span>
<span className="v" id="v19" data-v="19" data-xref="ヨハネの黙示録 22:16; Isaiah 9:2; Psalms 119:105"> また、私たちは、さらに確かな預言のみことばを持っています。夜明けとなって、明けの明星があなたがたの心の中に上るまでは、暗い所を照らすともしびとして、それに目を留めているとよいのです。</span>
<span className="v" id="v20" data-v="20" data-xref="ペテロの手紙第二 3:3; ローマ人への手紙 12:6; ローマ人への手紙 6:6"> それには何よりも次のことを知っていなければいけません。すなわち、聖書の預言はみな、人の私的解釈を施してはならない、ということです。</span>
<span className="v" id="v21" data-v="21" data-xref="テモテへの手紙第二 3:15–17; ペテロの手紙第一 1:11; 2 Samuel 23:2"> なぜなら、預言は決して人間の意志によってもたらされたのではなく、聖霊に動かされた人たちが、神からのことばを語ったのだからです。</span>

<span className="v" id="v1" data-v="1" data-xref="ヨハネの手紙第一 3:18; ローマ人への手紙 16:23; コリント人への手紙第一 1:14"> 長老から、愛するガイオへ。私はあなたをほんとうに愛しています。</span>
<span className="v" id="v2" data-v="2" data-xref="ペテロの手紙第二 1:3–9; ペテロの手紙第二 3:18; コロサイ人への手紙 1:4–6"> 愛する者よ。あなたが、たましいに幸いを得ているようにすべての点でも幸いを得、また健康であるように祈ります。</span>
<span className="v" id="v3" data-v="3" data-xref="ヨハネの手紙第二 1:4; ヨハネの手紙第二 1:2; Psalms 119:11"> 兄弟たちがやって来ては、あなたが真理に歩んでいるその真実を証言してくれるので、私は非常に喜んでいます。</span>
<span className="v" id="v4" data-v="4" data-xref="ガラテヤ人への手紙 4:19; テモテへの手紙第二 1:2; Proverbs 23:24"> 私の子どもたちが真理に歩んでいることを聞くことほど、私にとって大きな喜びはありません。</span>
<span className="v" id="v5" data-v="5" data-xref="ガラテヤ人への手紙 6:10; ルカの福音書 12:42; ルカの福音書 16:10–12"> 愛する者よ。あなたが、旅をしているあの兄弟たちのために行なっているいろいろなことは、真実な行ないです。</span>
<span className="v" id="v6" data-v="6" data-xref="テサロニケ人への手紙第一 2:12; テトスへの手紙 3:13; 使徒の働き 15:3"> 彼らは教会の集まりであなたの愛についてあかししました。あなたが神にふさわしいしかたで彼らを次の旅に送り出してくれるなら、それはりっぱなことです。</span>
<span className="v" id="v7" data-v="7" data-xref="コリント人への手紙第二 4:5; ヨハネの黙示録 2:3; 2 Kings 5:15–16"> 彼らは御名のために出て行きました。異邦人からは何も受けていません。</span>
<span className="v" id="v8" data-v="8" data-xref="コリント人への手紙第一 3:5–9; コリント人への手紙第一 16:10–11; コリント人への手紙第二 7:2–3"> ですから、私たちはこのような人々をもてなすべきです。そうすれば、私たちは真理のために彼らの同労者となれるのです。</span>
<span className="v" id="v9" data-v="9" data-xref="テトスへの手紙 1:7–16; ルカの福音書 22:24–27; マタイの福音書 23:4–8"> 私は教会に対して少しばかり書き送ったのですが、彼らの中でかしらになりたがっているデオテレペスが、私たちの言うことを聞き入れません。</span>
<span className="v" id="v10" data-v="10" data-xref="Isaiah 66:5; コリント人への手紙第二 13:2; ルカの福音書 6:22"> それで、私が行ったら、彼のしている行為を取り上げるつもりです。彼は意地悪いことばで私たちをののしり、それでもあきたらずに、自分が兄弟たちを受け入れないばかりか、受け入れたいと思う人々の邪魔をし、教会から追い出しているのです。</span>
<span className="v" id="v11" data-v="11" data-xref="Isaiah 1:16–17; Psalms 37:27; エペソ人への手紙 5:1"> 愛する者よ。悪を見ならわないで、善を見ならいなさい。善を行なう者は神から出た者であり、悪を行なう者は神を見たことのない者です。</span>
<span className="v" id="v12" data-v="12" data-xref="テモテへの手紙第一 3:7; ヨハネの福音書 21:24; 使徒の働き 22:12"> デメテリオはみなの人からも、また真理そのものからも証言されています。私たちも証言します。私たちの証言が真実であることは、あなたも知っているところです。</span>
<span className="v" id="v13" data-v="13" data-xref="ヨハネの手紙第二 1:12"> あなたに書き送りたいことがたくさんありましたが、筆と墨でしたくはありません。</span>
<span className="v" id="v14" data-v="14" data-xref="Genesis 43:23; エペソ人への手紙 6:23; ローマ人への手紙 16:1–16"> 間もなくあなたに会いたいと思います。そして顔を合わせて話し合いましょう。</span>
<span className="v" id="v15" data-v="15" data-xref="ヨハネの福音書 10:3"> 平安があなたにありますように。友人たちが、あなたによろしくと言っています。そちらの友人たちひとりひとりによろしくと言ってください。</span>

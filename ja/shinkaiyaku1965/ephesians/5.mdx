<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨハネの手紙第一 4:11; ペテロの手紙第一 1:15–16; エペソ人への手紙 4:32"> ですから、愛されている子どもらしく、神にならう者となりなさい。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネの福音書 13:34; ガラテヤ人への手紙 2:20; コロサイ人への手紙 3:14"> また、愛のうちに歩みなさい。キリストもあなたがたを愛して、私たちのために、ご自身を神へのささげ物、また供え物とし、香ばしいかおりをおささげになりました。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="コロサイ人への手紙 3:5; エペソ人への手紙 5:5; ガラテヤ人への手紙 5:19–21"> あなたがたの間では、聖徒にふさわしく、不品行も、どんな汚れも、またむさぼりも、口にすることさえいけません。</span>
<span className="v" id="v4" data-v="4" data-xref="コロサイ人への手紙 3:8; エペソ人への手紙 4:29; テサロニケ人への手紙第一 5:18"> また、みだらなことや、愚かな話や、下品な冗談を避けなさい。そのようなことは良くないことです。むしろ、感謝しなさい。</span>
<span className="v" id="v5" data-v="5" data-xref="ガラテヤ人への手紙 5:21; コリント人への手紙第一 6:9–10; エペソ人への手紙 5:3"> あなたがたがよく見て知っているとおり、不品行な者や、汚れた者や、むさぼる者――これが偶像礼拝者です。――こういう人はだれも、キリストと神との御国を相続することができません。</span>
<span className="v" id="v6" data-v="6" data-xref="ローマ人への手紙 1:18; コロサイ人への手紙 2:8; マタイの福音書 24:4"> むなしいことばに、だまされてはいけません。こういう行ないのゆえに、神の怒りは不従順な子らに下るのです。</span>
<span className="v" id="v7" data-v="7" data-xref="ヨハネの黙示録 18:4; エペソ人への手紙 5:11; テモテへの手紙第一 5:22"> ですから、彼らの仲間になってはいけません。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨハネの福音書 8:12; ヨハネの手紙第一 1:7; 使徒の働き 26:18"> あなたがたは、以前は暗やみでしたが、今は、主にあって、光となりました。光の子どもらしく歩みなさい。</span>
<span className="v" id="v9" data-v="9" data-xref="ヨハネの手紙第一 3:9–10; ガラテヤ人への手紙 5:22–23; ヨハネの手紙第三 1:11"> ――光の結ぶ実は、あらゆる善意と正義と真実なのです。――</span>
<span className="v" id="v10" data-v="10" data-xref="ローマ人への手紙 12:1–2; ヘブル人への手紙 12:28; Psalms 19:14"> そのためには、主に喜ばれることが何であるかを見分けなさい。</span>
<span className="v" id="v11" data-v="11" data-xref="ローマ人への手紙 13:12; テモテへの手紙第一 5:20; テサロニケ人への手紙第二 3:6"> 実を結ばない暗やみのわざに仲間入りしないで、むしろ、それを明るみに出しなさい。</span>
<span className="v" id="v12" data-v="12" data-xref="エペソ人への手紙 5:3; Jeremiah 23:24; Ecclesiastes 12:14"> なぜなら、彼らがひそかに行なっていることは、口にするのも恥ずかしいことだからです。</span>
<span className="v" id="v13" data-v="13" data-xref="ヨハネの福音書 3:20–21; コリント人への手紙第一 4:5; Hosea 2:10"> けれども、明るみに引き出されるものは、みな、光によって明らかにされます。</span>
<span className="v" id="v14" data-v="14" data-xref="Isaiah 60:1; ローマ人への手紙 13:11–12; Isaiah 26:19"> 明らかにされたものはみな、光だからです。それで、こう言われています。<br />「眠っている人よ。目をさませ。<br />死者の中から起き上がれ。<br />そうすれば、キリストが、あなたを照らされる。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="コロサイ人への手紙 4:5; ヤコブの手紙 3:13; ピリピ人への手紙 1:27"> そういうわけですから、賢くない人のようにではなく、賢い人のように歩んでいるかどうか、よくよく注意し、</span>
<span className="v" id="v16" data-v="16" data-xref="コロサイ人への手紙 4:5; Amos 5:13; ヨハネの福音書 12:35"> 機会を十分に生かして用いなさい。悪い時代だからです。</span>
<span className="v" id="v17" data-v="17" data-xref="ローマ人への手紙 12:2; テサロニケ人への手紙第一 5:18; コロサイ人への手紙 1:9"> ですから、愚かにならないで、主のみこころは何であるかを、よく悟りなさい。</span>
<span className="v" id="v18" data-v="18" data-xref="Proverbs 20:1; ルカの福音書 1:15; ローマ人への手紙 13:13"> また、酒に酔ってはいけません。そこには放蕩があるからです。御霊に満たされなさい。</span>
<span className="v" id="v19" data-v="19" data-xref="コロサイ人への手紙 3:16; コリント人への手紙第一 14:26; Psalms 95:2"> 詩と賛美と霊の歌とをもって、互いに語り、主に向かって、心から歌い、また賛美しなさい。</span>
<span className="v" id="v20" data-v="20" data-xref="コロサイ人への手紙 3:17; テサロニケ人への手紙第一 5:18; ヘブル人への手紙 13:15"> いつでも、すべてのことについて、私たちの主イエス・キリストの名によって父なる神に感謝しなさい。</span>
<span className="v" id="v21" data-v="21" data-xref="ピリピ人への手紙 2:3; エペソ人への手紙 5:24; エペソ人への手紙 5:22"> キリストを恐れ尊んで、互いに従いなさい。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="コロサイ人への手紙 3:18–1; ペテロの手紙第一 3:1–6; テトスへの手紙 2:5"> 妻たちよ。あなたがたは、主に従うように、自分の夫に従いなさい。</span>
<span className="v" id="v23" data-v="23" data-xref="コリント人への手紙第一 11:3–10; コロサイ人への手紙 1:18; エペソ人への手紙 1:22–23"> なぜなら、キリストは教会のかしらであって、ご自身がそのからだの救い主であられるように、夫は妻のかしらであるからです。</span>
<span className="v" id="v24" data-v="24" data-xref="エペソ人への手紙 5:33; コロサイ人への手紙 3:20; テトスへの手紙 2:7"> 教会がキリストに従うように、妻も、すべてのことにおいて、夫に従うべきです。</span>
<span className="v" id="v25" data-v="25" data-xref="ペテロの手紙第一 3:7; コロサイ人への手紙 3:19; エペソ人への手紙 5:28"> 夫たちよ。キリストが教会を愛し、教会のためにご自身をささげられたように、あなたがたも、自分の妻を愛しなさい。</span>
<span className="v" id="v26" data-v="26" data-xref="ヘブル人への手紙 10:22; ヨハネの福音書 15:3; Ezekiel 36:25"> キリストがそうされたのは、みことばにより、水の洗いをもって、教会をきよめて聖なるものとするためであり、</span>
<span className="v" id="v27" data-v="27" data-xref="コロサイ人への手紙 1:22; ヘブル人への手紙 9:14; ペテロの手紙第一 1:19"> ご自身で、しみや、しわや、そのようなものの何一つない、きよく傷のないものとなった栄光の教会を、ご自分の前に立たせるためです。</span>
<span className="v" id="v28" data-v="28" data-xref="エペソ人への手紙 5:25; マタイの福音書 19:5; Genesis 2:21–24"> そのように、夫も自分の妻を自分のからだのように愛さなければなりません。自分の妻を愛する者は自分を愛しているのです。</span>
<span className="v" id="v29" data-v="29" data-xref="Ezekiel 34:14–15; エペソ人への手紙 5:31; Ecclesiastes 4:5"> だれも自分の身を憎んだ者はいません。かえって、これを養い育てます。それはキリストが教会をそうされたのと同じです。</span>
<span className="v" id="v30" data-v="30" data-xref="コリント人への手紙第一 6:15; コリント人への手紙第一 12:12–27; ローマ人への手紙 12:5"> 私たちはキリストのからだの部分だからです。</span>
<span className="v" id="v31" data-v="31" data-xref="Genesis 2:24; マタイの福音書 19:5; マルコの福音書 10:7–8"> 「それゆえ、人はその父と母を離れ、妻と結ばれ、ふたりは一心同体となる。」</span>
<span className="v" id="v32" data-v="32" data-xref="ヨハネの黙示録 21:2; コリント人への手紙第二 11:2; Isaiah 54:5"> この奥義は偉大です。私は、キリストと教会とをさして言っているのです。</span>
<span className="v" id="v33" data-v="33" data-xref="ペテロの手紙第一 3:2–7; Esther 1:20; エペソ人への手紙 5:25"> それはそうとして、あなたがたも、おのおの自分の妻を自分と同様に愛しなさい。妻もまた自分の夫を敬いなさい。</span>
</div>

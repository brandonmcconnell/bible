<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="コロサイ人への手紙 1:24; テモテへの手紙第二 1:8; ピリピ人への手紙 1:13–16"> こういうわけで、あなたがた異邦人のためにキリスト・イエスの囚人となった私パウロが言います。</span>
<span className="v" id="v2" data-v="2" data-xref="コロサイ人への手紙 1:25–27; テモテへの手紙第一 1:11; テモテへの手紙第二 1:11"> あなたがたのためにと私がいただいた、神の恵みによる私の務めについて、あなたがたはすでに聞いたことでしょう。</span>
<span className="v" id="v3" data-v="3" data-xref="ガラテヤ人への手紙 1:12; ローマ人への手紙 16:25; エペソ人への手紙 1:9–11"> 先に簡単に書いたとおり、この奥義は、啓示によって私に知らされたのです。</span>
<span className="v" id="v4" data-v="4" data-xref="コロサイ人への手紙 4:3; コリント人への手紙第一 4:1; コリント人への手紙第二 11:6"> それを読めば、私がキリストの奥義をどう理解しているかがよくわかるはずです。</span>
<span className="v" id="v5" data-v="5" data-xref="ペテロの手紙第一 1:10–12; ペテロの手紙第二 3:2; テトスへの手紙 1:1–3"> この奥義は、今は、御霊によって、キリストの聖なる使徒たちと預言者たちに啓示されていますが、前の時代には、今と同じようには人々に知らされていませんでした。</span>
<span className="v" id="v6" data-v="6" data-xref="ガラテヤ人への手紙 3:26–29; ヨハネの手紙第一 1:3; ヨハネの手紙第一 2:25"> その奥義とは、福音により、キリスト・イエスにあって、異邦人もまた共同の相続者となり、ともに一つのからだに連なり、ともに約束にあずかる者となるということです。</span>
<span className="v" id="v7" data-v="7" data-xref="エペソ人への手紙 1:19; エペソ人への手紙 3:20; エペソ人への手紙 3:2"> 私は、神の力の働きにより、自分に与えられた神の恵みの賜物によって、この福音に仕える者とされました。</span>
<span className="v" id="v8" data-v="8" data-xref="コロサイ人への手紙 1:27; コリント人への手紙第一 15:9; エペソ人への手紙 2:7"> すべての聖徒たちのうちで一番小さな私に、この恵みが与えられたのは、私がキリストの測りがたい富を異邦人に宣べ伝え、</span>
<span className="v" id="v9" data-v="9" data-xref="コロサイ人への手紙 1:26; マタイの福音書 13:35; テモテへの手紙第二 1:9"> また、万物を創造された神の中に世々隠されていた奥義を実行に移す務めが何であるかを明らかにするためにほかなりません。</span>
<span className="v" id="v10" data-v="10" data-xref="ペテロの手紙第一 1:12; エペソ人への手紙 6:12; コリント人への手紙第一 2:7"> これは、今、天にある支配と権威とに対して、教会を通して、神の豊かな知恵が示されるためであって、</span>
<span className="v" id="v11" data-v="11" data-xref="テモテへの手紙第二 1:9; エペソ人への手紙 1:11; エペソ人への手紙 1:4"> 私たちの主キリスト・イエスにおいて実現された神の永遠のご計画に沿ったことです。</span>
<span className="v" id="v12" data-v="12" data-xref="エペソ人への手紙 2:18; ローマ人への手紙 5:2; ヘブル人への手紙 4:14–16"> 私たちはこのキリストにあり、キリストを信じる信仰によって大胆に確信をもって神に近づくことができるのです。</span>
<span className="v" id="v13" data-v="13" data-xref="コロサイ人への手紙 1:24; テサロニケ人への手紙第二 3:13; コリント人への手紙第二 1:6"> ですから、私があなたがたのために受けている苦難のゆえに落胆することのないようお願いします。私の受けている苦しみは、そのまま、あなたがたの光栄なのです。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="Psalms 95:6; エペソ人への手紙 1:16–19; ピリピ人への手紙 2:10"> こういうわけで、私はひざをかがめて、</span>
<span className="v" id="v15" data-v="15" data-xref="エペソ人への手紙 1:10; ヨハネの黙示録 5:8–14; エペソ人への手紙 1:21"> 天上と地上で家族と呼ばれるすべてのものの名の元である父の前に祈ります。</span>
<span className="v" id="v16" data-v="16" data-xref="コロサイ人への手紙 1:11; ピリピ人への手紙 4:13; Isaiah 40:29–31"> どうか父が、その栄光の豊かさに従い、御霊により、力をもって、あなたがたの内なる人を強くしてくださいますように。</span>
<span className="v" id="v17" data-v="17" data-xref="コロサイ人への手紙 2:7; ヨハネの手紙第一 4:16; ヨハネの福音書 14:23"> こうしてキリストが、あなたがたの信仰によって、あなたがたの心のうちに住んでいてくださいますように。また、愛に根ざし、愛に基礎を置いているあなたがたが、</span>
<span className="v" id="v18" data-v="18" data-xref="Psalms 103:11–12; Job 11:7–9; エペソ人への手紙 1:18–23"> すべての聖徒とともに、その広さ、長さ、高さ、深さがどれほどであるかを理解する力を持つようになり、</span>
<span className="v" id="v19" data-v="19" data-xref="エペソ人への手紙 1:23; コロサイ人への手紙 2:9–10; コロサイ人への手紙 1:10"> 人知をはるかに越えたキリストの愛を知ることができますように。こうして、神ご自身の満ち満ちたさまにまで、あなたがたが満たされますように。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="コリント人への手紙第二 9:8; ローマ人への手紙 4:21; Jeremiah 32:27"> どうか、私たちのうちに働く力によって、私たちの願うところ、思うところのすべてを越えて豊かに施すことのできる方に、</span>
<span className="v" id="v21" data-v="21" data-xref="ユダの手紙 1:25; ローマ人への手紙 11:36; ペテロの手紙第二 3:18"> 教会により、またキリスト・イエスにより、栄光が、世々にわたって、とこしえまでありますように。アーメン。</span>
</div>

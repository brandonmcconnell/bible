<span className="v" id="v1" data-v="1" data-xref="コロサイ人への手紙 1:10; ピリピ人への手紙 1:27; テサロニケ人への手紙第一 2:12"> さて、主の囚人である私はあなたがたに勧めます。召されたあなたがたは、その召しにふさわしく歩みなさい。</span>
<span className="v" id="v2" data-v="2" data-xref="コロサイ人への手紙 3:12–13; コリント人への手紙第一 13:7; コリント人への手紙第一 13:4–5"> 謙遜と柔和の限りを尽くし、寛容を示し、愛をもって互いに忍び合い、</span>
<span className="v" id="v3" data-v="3" data-xref="コリント人への手紙第一 1:10; コロサイ人への手紙 3:13–15; コリント人への手紙第一 12:12–13"> 平和のきずなで結ばれて御霊の一致を熱心に保ちなさい。</span>
<span className="v" id="v4" data-v="4" data-xref="エペソ人への手紙 2:18; ローマ人への手紙 12:4–5; コリント人への手紙第一 12:4–13"> からだは一つ、御霊は一つです。あなたがたが召されたとき、召しのもたらした望みが一つであったのと同じです。</span>
<span className="v" id="v5" data-v="5" data-xref="コリント人への手紙第一 8:6; コリント人への手紙第一 12:13; ペテロの手紙第一 3:21"> 主は一つ、信仰は一つ、バプテスマは一つです。</span>
<span className="v" id="v6" data-v="6" data-xref="ローマ人への手紙 11:36; Malachi 2:10; コリント人への手紙第一 8:6"> すべてのものの上にあり、すべてのものを貫き、すべてのもののうちにおられる、すべてのものの父なる神は一つです。</span>
<span className="v" id="v7" data-v="7" data-xref="ペテロの手紙第一 4:10; ローマ人への手紙 12:3; コリント人への手紙第一 12:7–11"> しかし、私たちはひとりひとり、キリストの賜物の量りに従って恵みを与えられました。</span>
<span className="v" id="v8" data-v="8" data-xref="Psalms 68:18; コロサイ人への手紙 2:15; 1 Samuel 30:26"> そこで、こう言われています。 「高い所に上られたとき、 彼は多くの捕虜を引き連れ、 人々に賜物を分け与えられた。」</span>
<span className="v" id="v9" data-v="9" data-xref="ヨハネの福音書 3:13; マタイの福音書 12:40; Proverbs 30:4"> ――この「上られた。」ということばは、彼がまず地の低い所に下られた、ということでなくて何でしょう。</span>
<span className="v" id="v10" data-v="10" data-xref="ヘブル人への手紙 7:26; ヘブル人への手紙 4:14; エペソ人への手紙 1:20–23"> この下られた方自身が、すべてのものを満たすために、もろもろの天よりも高く上られた方なのです。――</span>
<span className="v" id="v11" data-v="11" data-xref="Jeremiah 3:15; コリント人への手紙第一 12:28–29; エペソ人への手紙 2:20"> こうして、キリストご自身が、ある人を使徒、ある人を預言者、ある人を伝道者、ある人を牧師また教師として、お立てになったのです。</span>
<span className="v" id="v12" data-v="12" data-xref="テサロニケ人への手紙第一 5:11–14; エペソ人への手紙 4:16; コリント人への手紙第一 12:27"> それは、聖徒たちを整えて奉仕の働きをさせ、キリストのからだを建て上げるためであり、</span>
<span className="v" id="v13" data-v="13" data-xref="コロサイ人への手紙 1:28; ヨハネの福音書 17:21; エペソ人への手紙 4:5"> ついに、私たちがみな、信仰の一致と神の御子に関する知識の一致とに達し、完全におとなになって、キリストの満ち満ちた身たけにまで達するためです。</span>
<span className="v" id="v14" data-v="14" data-xref="ヘブル人への手紙 13:9; ローマ人への手紙 16:17–18; コリント人への手紙第一 14:20"> それは、私たちがもはや、子どもではなくて、人の悪巧みや、人を欺く悪賢い策略により、教えの風に吹き回されたり、波にもてあそばれたりすることがなく、</span>
<span className="v" id="v15" data-v="15" data-xref="ヨハネの手紙第一 3:18; エペソ人への手紙 4:25; Zechariah 8:16"> むしろ、愛をもって真理を語り、あらゆる点において成長し、かしらなるキリストに達することができるためなのです。</span>
<span className="v" id="v16" data-v="16" data-xref="コロサイ人への手紙 2:19; ヨハネの福音書 15:5; コロサイ人への手紙 2:2"> キリストによって、からだ全体は、一つ一つの部分がその力量にふさわしく働く力により、また、備えられたあらゆる結び目によって、しっかりと組み合わされ、結び合わされ、成長して、愛のうちに建てられるのです。</span>
<span className="v" id="v17" data-v="17" data-xref="ローマ人への手紙 1:21; ペテロの手紙第一 4:3–4; テサロニケ人への手紙第一 4:1–2"> そこで私は、主にあって言明し、おごそかに勧めます。もはや、異邦人がむなしい心で歩んでいるように歩んではなりません。</span>
<span className="v" id="v18" data-v="18" data-xref="マタイの福音書 13:15; エペソ人への手紙 2:12; ローマ人への手紙 1:21–23"> 彼らは、その知性において暗くなり、彼らのうちにある無知と、かたくなな心とのゆえに、神のいのちから遠く離れています。</span>
<span className="v" id="v19" data-v="19" data-xref="コロサイ人への手紙 3:5; ローマ人への手紙 1:24–26; テモテへの手紙第一 4:2"> 道徳的に無感覚となった彼らは、好色に身をゆだねて、あらゆる不潔な行ないをむさぼるようになっています。</span>
<span className="v" id="v20" data-v="20" data-xref="テトスへの手紙 2:11–14; ヨハネの福音書 6:45; マタイの福音書 11:29"> しかし、あなたがたはキリストのことを、このようには学びませんでした。</span>
<span className="v" id="v21" data-v="21" data-xref="ヨハネの手紙第一 5:20; エペソ人への手紙 1:13; ヘブル人への手紙 3:7–8"> ただし、ほんとうにあなたがたがキリストに聞き、キリストにあって教えられているのならばです。まさしく真理はイエスにあるのですから。</span>
<span className="v" id="v22" data-v="22" data-xref="ローマ人への手紙 6:6; ヘブル人への手紙 12:1; ヤコブの手紙 1:21"> その教えとは、あなたがたの以前の生活について言うならば、人を欺く情欲によって滅びて行く古い人を脱ぎ捨てるべきこと、</span>
<span className="v" id="v23" data-v="23" data-xref="ローマ人への手紙 12:2; ローマ人への手紙 8:6; Psalms 51:10"> またあなたがたが心の霊において新しくされ、</span>
<span className="v" id="v24" data-v="24" data-xref="コロサイ人への手紙 3:10–14; コリント人への手紙第二 5:17; エペソ人への手紙 2:10"> 真理に基づく義と聖をもって神にかたどり造り出された、新しい人を身に着るべきことでした。</span>
<span className="v" id="v25" data-v="25" data-xref="コロサイ人への手紙 3:9; Zechariah 8:16; Proverbs 12:22"> ですから、あなたがたは偽りを捨て、おのおの隣人に対して真実を語りなさい。私たちはからだの一部分として互いにそれぞれのものだからです。</span>
<span className="v" id="v26" data-v="26" data-xref="ヤコブの手紙 1:19; Psalms 4:4; Psalms 37:8"> 怒っても、罪を犯してはなりません。日が暮れるまで憤ったままでいてはいけません。</span>
<span className="v" id="v27" data-v="27" data-xref="ヤコブの手紙 4:7; ペテロの手紙第一 5:8; エペソ人への手紙 6:16"> 悪魔に機会を与えないようにしなさい。</span>
<span className="v" id="v28" data-v="28" data-xref="テモテへの手紙第一 6:18; テサロニケ人への手紙第一 4:11–12; ガラテヤ人への手紙 6:10"> 盗みをしている者は、もう盗んではいけません。かえって、困っている人に施しをするため、自分の手をもって正しい仕事をし、ほねおって働きなさい。</span>
<span className="v" id="v29" data-v="29" data-xref="コロサイ人への手紙 4:6; テサロニケ人への手紙第一 5:11; Ecclesiastes 10:12"> 悪いことばを、いっさい口から出してはいけません。ただ、必要なとき、人の徳を養うのに役立つことばを話し、聞く人に恵みを与えなさい。</span>
<span className="v" id="v30" data-v="30" data-xref="テサロニケ人への手紙第一 5:19; Isaiah 63:10; エペソ人への手紙 1:13–14"> 神の聖霊を悲しませてはいけません。あなたがたは、贖いの日のために、聖霊によって証印を押されているのです。</span>
<span className="v" id="v31" data-v="31" data-xref="コロサイ人への手紙 3:8; Ecclesiastes 7:9; テトスへの手紙 3:2–3"> 無慈悲、憤り、怒り、叫び、そしりなどを、いっさいの悪意とともに、みな捨て去りなさい。</span>
<span className="v" id="v32" data-v="32" data-xref="コロサイ人への手紙 3:12–13; マタイの福音書 6:14–15; マルコの福音書 11:25"> お互いに親切にし、心の優しい人となり、神がキリストにおいてあなたがたを赦してくださったように、互いに赦し合いなさい。</span>

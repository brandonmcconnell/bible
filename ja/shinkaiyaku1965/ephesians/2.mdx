<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="コロサイ人への手紙 2:13; エペソ人への手紙 2:5–6; コロサイ人への手紙 3:1–4"> あなたがたは自分の罪過と罪との中に死んでいた者であって、</span>
<span className="v" id="v2" data-v="2" data-xref="エペソ人への手紙 6:12; ヨハネの手紙第一 5:19; エペソ人への手紙 2:3"> そのころは、それらの罪の中にあってこの世の流れに従い、空中の権威を持つ支配者として今も不従順の子らの中に働いている霊に従って、歩んでいました。</span>
<span className="v" id="v3" data-v="3" data-xref="テトスへの手紙 3:3; エペソ人への手紙 4:22; ガラテヤ人への手紙 5:16–24"> 私たちもみな、かつては不従順の子らの中にあって、自分の肉の欲の中に生き、肉と心の望むままを行ない、ほかの人たちと同じように、生まれながら御怒りを受けるべき子らでした。</span>
<span className="v" id="v4" data-v="4" data-xref="ペテロの手紙第一 1:3; エペソ人への手紙 1:7; Psalms 86:15"> しかし、あわれみ豊かな神は、私たちを愛してくださったその大きな愛のゆえに、</span>
<span className="v" id="v5" data-v="5" data-xref="ローマ人への手紙 3:24; エペソ人への手紙 2:8; ローマ人への手紙 5:10"> 罪過の中に死んでいたこの私たちをキリストとともに生かし、――あなたがたが救われたのは、ただ恵みによるのです。――</span>
<span className="v" id="v6" data-v="6" data-xref="コロサイ人への手紙 3:1–3; エペソ人への手紙 1:3; ローマ人への手紙 6:4–5"> キリスト・イエスにおいて、ともによみがえらせ、ともに天の所にすわらせてくださいました。</span>
<span className="v" id="v7" data-v="7" data-xref="テモテへの手紙第一 1:16–17; テトスへの手紙 3:4; エペソ人への手紙 2:4"> それは、あとに来る世々において、このすぐれて豊かな御恵みを、キリスト・イエスにおいて私たちに賜わる慈愛によって明らかにお示しになるためでした。</span>
<span className="v" id="v8" data-v="8" data-xref="ローマ人への手紙 3:22–26; エペソ人への手紙 2:5; ローマ人への手紙 4:16"> あなたがたは、恵みのゆえに、信仰によって救われたのです。それは、自分自身から出たことではなく、神からの賜物です。</span>
<span className="v" id="v9" data-v="9" data-xref="テモテへの手紙第二 1:9; ローマ人への手紙 11:6; テトスへの手紙 3:3–5"> 行ないによるのではありません。だれも誇ることのないためです。</span>
<span className="v" id="v10" data-v="10" data-xref="ピリピ人への手紙 2:13; コロサイ人への手紙 1:10; ヘブル人への手紙 13:21"> 私たちは神の作品であって、良い行ないをするためにキリスト・イエスにあって造られたのです。神は、私たちが良い行ないに歩むように、その良い行ないをもあらかじめ備えてくださったのです。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="コロサイ人への手紙 2:11; コロサイ人への手紙 2:13; コロサイ人への手紙 3:11"> ですから、思い出してください。あなたがたは、以前は肉において異邦人でした。すなわち、肉において人の手による、いわゆる割礼を持つ人々からは、無割礼の人々と呼ばれる者であって、</span>
<span className="v" id="v12" data-v="12" data-xref="ガラテヤ人への手紙 4:8; コロサイ人への手紙 1:21; Jeremiah 31:31–34"> そのころのあなたがたは、キリストから離れ、イスラエルの国から除外され、約束の契約については他国人であり、この世にあって望みもなく、神もない人たちでした。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒の働き 2:39; コロサイ人への手紙 1:20–22; コロサイ人への手紙 1:13–14"> しかし、以前は遠く離れていたあなたがたも、今ではキリスト・イエスの中にあることにより、キリストの血によって近い者とされたのです。</span>
<span className="v" id="v14" data-v="14" data-xref="ガラテヤ人への手紙 3:28; コロサイ人への手紙 3:11; コロサイ人への手紙 3:15"> キリストこそ私たちの平和であり、二つのものを一つにし、隔ての壁を打ちこわし、</span>
<span className="v" id="v15" data-v="15" data-xref="コロサイ人への手紙 2:14; ガラテヤ人への手紙 3:10; コロサイ人への手紙 1:21–22"> ご自分の肉において、敵意を廃棄された方です。敵意とは、さまざまの規定から成り立っている戒めの律法なのです。このことは、二つのものをご自身において新しいひとりの人に造り上げて、平和を実現するためであり、</span>
<span className="v" id="v16" data-v="16" data-xref="コロサイ人への手紙 1:20–22; ローマ人への手紙 5:10; コリント人への手紙第二 5:18–21"> また、両者を一つのからだとして、十字架によって神と和解させるためなのです。敵意は十字架によって葬り去られました。</span>
<span className="v" id="v17" data-v="17" data-xref="Isaiah 57:19–21; 使徒の働き 10:36; ローマ人への手紙 5:1"> それからキリストは来られて、遠くにいたあなたがたに平和を宣べ、近くにいた人たちにも平和を宣べられました。</span>
<span className="v" id="v18" data-v="18" data-xref="コリント人への手紙第一 12:13; エペソ人への手紙 3:12; ローマ人への手紙 5:2"> 私たちは、このキリストによって、両者ともに一つの御霊において、父のみもとに近づくことができるのです。</span>
<span className="v" id="v19" data-v="19" data-xref="ピリピ人への手紙 3:20; ヨハネの手紙第一 3:1; ガラテヤ人への手紙 6:10"> こういうわけで、あなたがたは、もはや他国人でも寄留者でもなく、今は聖徒たちと同じ国民であり、神の家族なのです。</span>
<span className="v" id="v20" data-v="20" data-xref="ペテロの手紙第一 2:4–5; Isaiah 28:16; ペテロの手紙第一 2:7–8"> あなたがたは使徒と預言者という土台の上に建てられており、キリスト・イエスご自身がその礎石です。</span>
<span className="v" id="v21" data-v="21" data-xref="コリント人への手紙第一 3:16–17; コリント人への手紙第一 3:9; コリント人への手紙第二 6:16"> この方にあって、組み合わされた建物の全体が成長し、主にある聖なる宮となるのであり、</span>
<span className="v" id="v22" data-v="22" data-xref="ペテロの手紙第一 2:4–5; コリント人への手紙第一 3:16; ヨハネの手紙第一 4:16"> このキリストにあって、あなたがたもともに建てられ、御霊によって神の御住まいとなるのです。</span>

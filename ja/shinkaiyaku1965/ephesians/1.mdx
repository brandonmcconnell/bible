<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="コロサイ人への手紙 1:2; コリント人への手紙第二 1:1; コリント人への手紙第一 1:1–2"> 神のみこころによるキリスト・イエスの使徒パウロから、キリスト・イエスにある忠実なエペソの聖徒たちへ。</span>
<span className="v" id="v2" data-v="2" data-xref="ローマ人への手紙 1:7; ガラテヤ人への手紙 1:3; テトスへの手紙 1:4"> 私たちの父なる神と主イエス・キリストから、恵みと平安があなたがたの上にありますように。</span>
<span className="v" id="v3" data-v="3" data-xref="ペテロの手紙第一 1:3; コリント人への手紙第二 1:3; エペソ人への手紙 2:6"> 私たちの主イエス・キリストの父なる神がほめたたえられますように。神はキリストにおいて、天にあるすべての霊的祝福をもって私たちを祝福してくださいました。</span>
<span className="v" id="v4" data-v="4" data-xref="テモテへの手紙第二 1:9; ローマ人への手紙 8:28–30; エペソ人への手紙 2:10"> すなわち、神は私たちを世界の基の置かれる前からキリストのうちに選び、御前できよく、傷のない者にしようとされました。</span>
<span className="v" id="v5" data-v="5" data-xref="ローマ人への手紙 8:29–30; エペソ人への手紙 1:11; ガラテヤ人への手紙 4:5–6"> 神は、ただみこころのままに、私たちをイエス・キリストによってご自分の子にしようと、愛をもってあらかじめ定めておられたのです。</span>
<span className="v" id="v6" data-v="6" data-xref="ローマ人への手紙 3:22–26; エペソ人への手紙 1:12; コロサイ人への手紙 1:13"> それは、神がその愛する方によって私たちに与えてくださった恵みの栄光が、ほめたたえられるためです。</span>
<span className="v" id="v7" data-v="7" data-xref="ペテロの手紙第一 2:24; ローマ人への手紙 3:24; ヨハネの手紙第一 1:7–9"> 私たちは、この御子のうちにあって、御子の血による贖い、すなわち罪の赦しを受けているのです。これは神の豊かな恵みによることです。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨハネの黙示録 5:12; エペソ人への手紙 3:10; ローマ人への手紙 5:15"> 神はこの恵みを私たちの上にあふれさせ、あらゆる知恵と思慮深さをもって、</span>
<span className="v" id="v9" data-v="9" data-xref="コロサイ人への手紙 1:26–28; ローマ人への手紙 16:25–27; エペソ人への手紙 3:3–9"> みこころの奥義を私たちに知らせてくださいました。それは、神が御子においてあらかじめお立てになったご計画によることであって、</span>
<span className="v" id="v10" data-v="10" data-xref="コロサイ人への手紙 1:20; ピリピ人への手紙 2:9–10; ガラテヤ人への手紙 4:4"> 時がついに満ちて、この時のためのみこころが実行に移され、天にあるものも地にあるものも、いっさいのものが、キリストにあって一つに集められることなのです。このキリストにあって、</span>
<span className="v" id="v11" data-v="11" data-xref="ローマ人への手紙 8:28; ペテロの手紙第一 1:4; Isaiah 46:10–11"> 私たちは彼にあって御国を受け継ぐ者ともなったのです。私たちは、みこころによりご計画のままをみな実現される方の目的に従って、このようにあらかじめ定められていたのです。</span>
<span className="v" id="v12" data-v="12" data-xref="エペソ人への手紙 1:6; Jeremiah 17:5–7; エペソ人への手紙 1:13–14"> それは、前からキリストに望みを置いていた私たちが、神の栄光をほめたたえる者となるためです。</span>
<span className="v" id="v13" data-v="13" data-xref="コリント人への手紙第二 1:22; エペソ人への手紙 4:30; テモテへの手紙第二 2:19"> またあなたがたも、キリストにあって、真理のことば、すなわちあなたがたの救いの福音を聞き、またそれを信じたことによって、約束の聖霊をもって証印を押されました。</span>
<span className="v" id="v14" data-v="14" data-xref="コリント人への手紙第二 1:22; コリント人への手紙第二 5:5; エペソ人への手紙 4:30"> 聖霊は私たちが御国を受け継ぐことの保証であられます。これは神の民の贖いのためであり、神の栄光がほめたたえられるためです。</span>
<span className="v" id="v15" data-v="15" data-xref="ピレモンへの手紙 1:5; コロサイ人への手紙 1:3–4; テサロニケ人への手紙第二 1:3"> こういうわけで、私は主イエスに対するあなたがたの信仰と、すべての聖徒に対する愛とを聞いて、</span>
<span className="v" id="v16" data-v="16" data-xref="ローマ人への手紙 1:8–9; コロサイ人への手紙 1:9; コロサイ人への手紙 1:3"> あなたがたのために絶えず感謝をささげ、あなたがたのことを覚えて祈っています。</span>
<span className="v" id="v17" data-v="17" data-xref="Isaiah 11:2; ヤコブの手紙 3:17–18; コロサイ人への手紙 1:9–10"> どうか、私たちの主イエス・キリストの神、すなわち栄光の父が、神を知るための知恵と啓示の御霊を、あなたがたに与えてくださいますように。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒の働き 26:18; コリント人への手紙第二 4:6; ルカの福音書 24:45"> また、あなたがたの心の目がはっきり見えるようになって、神の召しによって与えられる望みがどのようなものか、聖徒の受け継ぐものがどのように栄光に富んだものか、</span>
<span className="v" id="v19" data-v="19" data-xref="ピリピ人への手紙 2:13; エペソ人への手紙 3:20; コロサイ人への手紙 2:12"> また、神の全能の力の働きによって私たち信じる者に働く神のすぐれた力がどのように偉大なものであるかを、あなたがたが知ることができますように。</span>
<span className="v" id="v20" data-v="20" data-xref="ヘブル人への手紙 10:12; マルコの福音書 16:19; Psalms 110:1"> 神は、その全能の力をキリストのうちに働かせて、キリストを死者の中からよみがえらせ、天上においてご自分の右の座に着かせて、</span>
<span className="v" id="v21" data-v="21" data-xref="ピリピ人への手紙 2:9–11; コロサイ人への手紙 2:10; コロサイ人への手紙 1:15–16"> すべての支配、権威、権力、主権の上に、また、今の世ばかりでなく、次に来る世においてもとなえられる、すべての名の上に高く置かれました。</span>
<span className="v" id="v22" data-v="22" data-xref="コロサイ人への手紙 1:18; コロサイ人への手紙 2:10; コリント人への手紙第一 15:25–27"> また、神は、いっさいのものをキリストの足の下に従わせ、いっさいのものの上に立つかしらであるキリストを、教会にお与えになりました。</span>
<span className="v" id="v23" data-v="23" data-xref="コロサイ人への手紙 1:18–19; ヨハネの福音書 1:16; コロサイ人への手紙 2:9–10"> 教会はキリストのからだであり、いっさいのものをいっさいのものによって満たす方の満ちておられるところです。</span>

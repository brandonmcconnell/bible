<span className="v" id="v1" data-v="1" data-xref="コロサイ人への手紙 3:20–25; Proverbs 23:22; Proverbs 6:20"> 子どもたちよ。主にあって両親に従いなさい。これは正しいことだからです。</span>
<span className="v" id="v2" data-v="2" data-xref="Exodus 20:12; Deuteronomy 27:16; マタイの福音書 15:4–6"> 「あなたの父と母を敬え。」これは第一の戒めであり、約束を伴ったものです。すなわち、</span>
<span className="v" id="v3" data-v="3" data-xref="Deuteronomy 5:16; Deuteronomy 4:40; Deuteronomy 12:28"> 「そうしたら、あなたはしあわせになり、地上で長生きする。」という約束です。</span>
<span className="v" id="v4" data-v="4" data-xref="コロサイ人への手紙 3:21; Proverbs 22:6; Proverbs 29:15"> 父たちよ。あなたがたも、子どもをおこらせてはいけません。かえって、主の教育と訓戒によって育てなさい。</span>
<span className="v" id="v5" data-v="5" data-xref="ペテロの手紙第一 2:18–21; テトスへの手紙 2:9–10; コロサイ人への手紙 3:17–24"> 奴隷たちよ。あなたがたは、キリストに従うように、恐れおののいて真心から地上の主人に従いなさい。</span>
<span className="v" id="v6" data-v="6" data-xref="コロサイ人への手紙 3:22–23; テサロニケ人への手紙第一 2:4; ガラテヤ人への手紙 1:10"> 人のごきげんとりのような、うわべだけの仕え方でなく、キリストのしもべとして、心から神のみこころを行ない、</span>
<span className="v" id="v7" data-v="7" data-xref="コロサイ人への手紙 3:23; エペソ人への手紙 6:5–6; コリント人への手紙第一 10:31"> 人にではなく、主に仕えるように、善意をもって仕えなさい。</span>
<span className="v" id="v8" data-v="8" data-xref="コロサイ人への手紙 3:24; ルカの福音書 14:14; Proverbs 11:18"> 良いことを行なえば、奴隷であっても自由人であっても、それぞれその報いを主から受けることをあなたがたは知っています。</span>
<span className="v" id="v9" data-v="9" data-xref="コロサイ人への手紙 3:25–1; 使徒の働き 10:34; ローマ人への手紙 2:11"> 主人たちよ。あなたがたも、奴隷に対して同じようにふるまいなさい。おどすことはやめなさい。あなたがたは、彼らとあなたがたとの主が天におられ、主は人を差別されることがないことを知っているのですから。</span>
<span className="v" id="v10" data-v="10" data-xref="ピリピ人への手紙 4:13; Isaiah 40:31; Joshua 1:9"> 終わりに言います。主にあって、その大能の力によって強められなさい。</span>
<span className="v" id="v11" data-v="11" data-xref="コリント人への手紙第二 10:4; ローマ人への手紙 13:12; エペソ人への手紙 6:13"> 悪魔の策略に対して立ち向かうことができるために、神のすべての武具を身に着けなさい。</span>
<span className="v" id="v12" data-v="12" data-xref="コロサイ人への手紙 1:13; コリント人への手紙第二 4:4; エペソ人への手紙 2:2"> 私たちの格闘は血肉に対するものではなく、主権、力、この暗やみの世界の支配者たち、また、天にいるもろもろの悪霊に対するものです。</span>
<span className="v" id="v13" data-v="13" data-xref="コリント人への手紙第二 10:4; ルカの福音書 21:36; エペソ人への手紙 6:11–17"> ですから、邪悪な日に際して対抗できるように、また、いっさいを成し遂げて、堅く立つことができるように、神のすべての武具をとりなさい。</span>
<span className="v" id="v14" data-v="14" data-xref="Isaiah 59:17; テサロニケ人への手紙第一 5:8; Isaiah 11:5"> では、しっかりと立ちなさい。腰には真理の帯を締め、胸には正義の胸当てを着け、</span>
<span className="v" id="v15" data-v="15" data-xref="Isaiah 52:7; ローマ人への手紙 10:15; コリント人への手紙第二 5:18–21"> 足には平和の福音の備えをはきなさい。</span>
<span className="v" id="v16" data-v="16" data-xref="ペテロの手紙第一 5:8–9; ヨハネの手紙第一 5:4–5; Proverbs 18:10"> これらすべてのものの上に、信仰の大盾を取りなさい。それによって、悪い者が放つ火矢を、みな消すことができます。</span>
<span className="v" id="v17" data-v="17" data-xref="ヘブル人への手紙 4:12; Isaiah 59:17; ヨハネの黙示録 19:15"> 救いのかぶとをかぶり、また御霊の与える剣である、神のことばを受け取りなさい。</span>
<span className="v" id="v18" data-v="18" data-xref="テサロニケ人への手紙第一 5:17; コロサイ人への手紙 4:2; ピリピ人への手紙 4:6"> すべての祈りと願いを用いて、どんなときにも御霊によって祈りなさい。そのためには絶えず目をさましていて、すべての聖徒のために、忍耐の限りを尽くし、また祈りなさい。</span>
<span className="v" id="v19" data-v="19" data-xref="コロサイ人への手紙 4:3; 使徒の働き 4:29; テサロニケ人への手紙第二 3:1"> また、私が口を開くとき、語るべきことばが与えられ、福音の奥義を大胆に知らせることができるように私のためにも祈ってください。</span>
<span className="v" id="v20" data-v="20" data-xref="コリント人への手紙第二 5:20; コロサイ人への手紙 4:4; テモテへの手紙第二 2:9"> 私は鎖につながれて、福音のために大使の役を果たしています。鎖につながれていても、語るべきことを大胆に語れるように、祈ってください。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒の働き 20:4; テモテへの手紙第二 4:12; テトスへの手紙 3:12"> あなたがたにも私の様子や、私が何をしているかなどを知っていただくために、主にあって愛する兄弟であり、忠実な奉仕者であるテキコが、一部始終を知らせるでしょう。</span>
<span className="v" id="v22" data-v="22" data-xref="ピリピ人への手紙 2:25; コロサイ人への手紙 4:7–8; テサロニケ人への手紙第二 2:17"> テキコをあなたがたのもとに遣わしたのは、ほかでもなく、あなたがたが私たちの様子を知り、また彼によって心に励ましを受けるためです。</span>
<span className="v" id="v23" data-v="23" data-xref="ガラテヤ人への手紙 6:16; ガラテヤ人への手紙 5:6; ペテロの手紙第一 5:14"> どうか、父なる神と主イエス・キリストから、平安と信仰に伴う愛とが兄弟たちの上にありますように。</span>
<span className="v" id="v24" data-v="24" data-xref="マタイの福音書 22:37; コリント人への手紙第二 8:12; マタイの福音書 6:13"> 私たちの主イエス・キリストを朽ちぬ愛をもって愛するすべての人の上に、恵みがありますように。</span>

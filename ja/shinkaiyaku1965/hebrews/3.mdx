<span className="v" id="v1" data-v="1" data-xref="テモテへの手紙第二 1:9; ピリピ人への手紙 3:14; ヘブル人への手紙 4:14–15"> そういうわけですから、天の召しにあずかっている聖なる兄弟たち。私たちの告白する信仰の使徒であり、大祭司であるイエスのことを考えなさい。</span>
<span className="v" id="v2" data-v="2" data-xref="Numbers 12:7; テモテへの手紙第一 3:15; エペソ人への手紙 2:22"> モーセが神の家全体のために忠実であったのと同様に、イエスはご自分を立てた方に対して忠実なのです。</span>
<span className="v" id="v3" data-v="3" data-xref="コリント人への手紙第一 3:9; ペテロの手紙第一 2:5–7; Zechariah 6:12–13"> 家よりも、家を建てる者が大きな栄誉を持つのと同様に、イエスはモーセよりも大きな栄光を受けるのにふさわしいとされました。</span>
<span className="v" id="v4" data-v="4" data-xref="ヘブル人への手紙 3:3; ヘブル人への手紙 1:2; Esther 2:10"> 家はそれぞれ、だれかが建てるのですが、すべてのものを造られた方は、神です。</span>
<span className="v" id="v5" data-v="5" data-xref="Numbers 12:7; ヘブル人への手紙 3:2; Exodus 14:31"> モーセは、しもべとして神の家全体のために忠実でした。それは、後に語られる事をあかしするためでした。</span>
<span className="v" id="v6" data-v="6" data-xref="コリント人への手紙第二 6:16; コリント人への手紙第一 3:16; ヘブル人への手紙 10:35"> しかし、キリストは御子として神の家を忠実に治められるのです。もし私たちが、確信と、希望による誇りとを、終わりまでしっかりと持ち続けるならば、私たちが神の家なのです。</span>
<span className="v" id="v7" data-v="7" data-xref="Psalms 95:7–11; ヘブル人への手紙 3:15; Isaiah 55:3"> ですから、聖霊が言われるとおりです。 「きょう、もし御声を聞くならば、</span>
<span className="v" id="v8" data-v="8" data-xref="Proverbs 28:14; Exodus 17:7; Zechariah 7:11–12"> 荒野での試みの日に 御怒りを引き起こしたときのように、 心をかたくなにしてはならない。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒の働き 7:36; Deuteronomy 4:9; Exodus 19:4"> あなたがたの先祖たちは、 そこでわたしを試みて証拠を求め、 四十年の間、わたしのわざを見た。</span>
<span className="v" id="v10" data-v="10" data-xref="Psalms 95:10; テサロニケ人への手紙第二 2:10–12; Psalms 67:2"> だから、わたしはその時代を憤って言った。 彼らは常に心が迷い、 わたしの道を悟らなかった。</span>
<span className="v" id="v11" data-v="11" data-xref="Deuteronomy 1:34–35; ヘブル人への手紙 4:3; Numbers 32:10–13"> わたしは、怒りをもって誓ったように、 決して彼らをわたしの安息にはいらせない。」</span>
<span className="v" id="v12" data-v="12" data-xref="Jeremiah 17:5; Jeremiah 7:24; Jeremiah 17:9"> 兄弟たち。あなたがたの中では、だれも悪い不信仰の心になって生ける神から離れる者がないように気をつけなさい。</span>
<span className="v" id="v13" data-v="13" data-xref="テサロニケ人への手紙第一 5:11; ヘブル人への手紙 10:24–25; テモテへの手紙第二 4:2"> 「きょう。」と言われている間に、日々互いに励まし合って、だれも罪に惑わされてかたくなにならないようにしなさい。</span>
<span className="v" id="v14" data-v="14" data-xref="ヘブル人への手紙 3:6; ヘブル人への手紙 6:11; ヘブル人への手紙 12:10"> もし最初の確信を終わりまでしっかり保ちさえすれば、私たちは、キリストにあずかる者となるのです。</span>
<span className="v" id="v15" data-v="15" data-xref="ヘブル人への手紙 3:7–8; Psalms 95:7; ヘブル人への手紙 10:38"> 「きょう、もし御声を聞くならば、 御怒りを引き起こしたときのように、 心をかたくなにしてはならない。」 と言われているからです。</span>
<span className="v" id="v16" data-v="16" data-xref="Numbers 14:2; Numbers 14:30; Numbers 26:65"> 聞いていながら、御怒りを引き起こしたのはだれでしたか。モーセに率いられてエジプトを出た人々の全部ではありませんか。</span>
<span className="v" id="v17" data-v="17" data-xref="Numbers 14:29; Numbers 26:64–65; Numbers 14:32–33"> 神は四十年の間だれを怒っておられたのですか。罪を犯した人々、しかばねを荒野にさらした、あの人たちをではありませんか。</span>
<span className="v" id="v18" data-v="18" data-xref="Numbers 14:30; ヘブル人への手紙 4:6; Deuteronomy 1:34–35"> また、わたしの安息にはいらせないと神が誓われたのは、ほかでもない、従おうとしなかった人たちのことではありませんか。</span>
<span className="v" id="v19" data-v="19" data-xref="ユダの手紙 1:5; ヨハネの福音書 3:36; マルコの福音書 16:16"> それゆえ、彼らが安息にはいれなかったのは、不信仰のためであったことがわかります。</span>

<span className="v" id="v1" data-v="1" data-xref="ヘブル人への手紙 12:15; ヘブル人への手紙 4:9; Proverbs 28:14"> こういうわけで、神の安息にはいるための約束はまだ残っているのですから、あなたがたのうちのひとりでも、万が一にもこれにはいれないようなことのないように、私たちは恐れる心を持とうではありませんか。</span>
<span className="v" id="v2" data-v="2" data-xref="テサロニケ人への手紙第一 2:13; ローマ人への手紙 10:16–17; ヘブル人への手紙 11:6"> 福音を説き聞かされていることは、私たちも彼らと同じなのです。ところが、その聞いたみことばも、彼らには益になりませんでした。みことばが、それを聞いた人たちに、信仰によって、結びつけられなかったからです。</span>
<span className="v" id="v3" data-v="3" data-xref="Psalms 95:11; マタイの福音書 11:28–29; ペテロの手紙第一 1:20"> 信じた私たちは安息にはいるのです。<br />「わたしは、怒りをもって誓ったように、<br />決して彼らをわたしの安息にはいらせない。」<br />と神が言われたとおりです。みわざは創世の初めから、もう終わっているのです。</span>
<span className="v" id="v4" data-v="4" data-xref="Exodus 20:11; Exodus 31:17; Genesis 2:1–2"> というのは、神は七日目について、ある個所で、「そして、神は、すべてのみわざを終えて七日目に休まれた。」と言われました。</span>
<span className="v" id="v5" data-v="5" data-xref="Psalms 95:11; ヘブル人への手紙 4:3; ヘブル人への手紙 3:11"> そして、ここでは、「決して彼らをわたしの安息にはいらせない。」と言われたのです。</span>
<span className="v" id="v6" data-v="6" data-xref="マタイの福音書 21:43; ヘブル人への手紙 3:18–19; 使徒の働き 13:46–47"> こういうわけで、その安息にはいる人々がまだ残っており、前に福音を説き聞かされた人々は、不従順のゆえにはいれなかったのですから、</span>
<span className="v" id="v7" data-v="7" data-xref="Psalms 95:7; ヘブル人への手紙 3:7–8; ヘブル人への手紙 3:15"> 神は再びある日を「きょう。」と定めて、長い年月の後に、前に言われたと同じように、ダビデを通して、<br />「きょう、もし御声を聞くならば、<br />あなたがたの心をかたくなにしてはならない。」<br />と語られたのです。</span>
<span className="v" id="v8" data-v="8" data-xref="Joshua 1:15; Joshua 22:4; Deuteronomy 12:9"> もしヨシュアが彼らに安息を与えたのであったら、神はそのあとで別の日のことを話されることはなかったでしょう。</span>
<span className="v" id="v9" data-v="9" data-xref="ペテロの手紙第一 2:10; ヨハネの黙示録 21:4; ヨハネの黙示録 7:14–17"> したがって、安息日の休みは、神の民のためにまだ残っているのです。</span>
<span className="v" id="v10" data-v="10" data-xref="ヨハネの黙示録 14:13; ヘブル人への手紙 4:3–4; ペテロの手紙第一 4:1–2"> 神の安息にはいった者ならば、神がご自分のわざを終えて休まれたように、自分のわざを終えて休んだはずです。</span>
<span className="v" id="v11" data-v="11" data-xref="マタイの福音書 11:28–30; ルカの福音書 13:24; ヘブル人への手紙 3:18–1"> ですから、私たちは、この安息にはいるよう力を尽くして努め、あの不従順の例にならって落後する者が、ひとりもいないようにしようではありませんか。</span>
<span className="v" id="v12" data-v="12" data-xref="Jeremiah 23:29; Isaiah 55:11; エペソ人への手紙 6:17"> 神のことばは生きていて、力があり、両刃の剣よりも鋭く、たましいと霊、関節と骨髄の分かれ目さえも刺し通し、心のいろいろな考えやはかりごとを判別することができます。</span>
<span className="v" id="v13" data-v="13" data-xref="コリント人への手紙第一 4:5; Psalms 33:13–15; Proverbs 15:3"> 造られたもので、神の前で隠れおおせるものは何一つなく、神の目には、すべてが裸であり、さらけ出されています。私たちはこの神に対して弁明をするのです。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="ヘブル人への手紙 9:24; ヘブル人への手紙 12:2; ヘブル人への手紙 9:12"> さて、私たちのためには、もろもろの天を通られた偉大な大祭司である神の子イエスがおられるのですから、私たちの信仰の告白を堅く保とうではありませんか。</span>
<span className="v" id="v15" data-v="15" data-xref="ヘブル人への手紙 2:17–18; コリント人への手紙第二 5:21; Isaiah 53:4–5"> 私たちの大祭司は、私たちの弱さに同情できない方ではありません。罪は犯されませんでしたが、すべての点で、私たちと同じように、試みに会われたのです。</span>
<span className="v" id="v16" data-v="16" data-xref="エペソ人への手紙 3:12; ヘブル人への手紙 7:25; ヘブル人への手紙 10:19–23"> ですから、私たちは、あわれみを受け、また恵みをいただいて、おりにかなった助けを受けるために、大胆に恵みの御座に近づこうではありませんか。</span>
</div>

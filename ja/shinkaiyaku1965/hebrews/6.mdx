<span className="v" id="v1" data-v="1" data-xref="ヘブル人への手紙 5:12–14; コリント人への手紙第二 7:1; ヘブル人への手紙 9:14"> ですから、私たちは、キリストについての初歩の教えをあとにして、成熟を目ざして進もうではありませんか。死んだ行ないからの回心、神に対する信仰、</span>
<span className="v" id="v2" data-v="2" data-xref="コリント人への手紙第一 15:13–57; 使徒の働き 17:31–32; ローマ人への手紙 6:3–5"> きよめの洗いについての教え、手を置く儀式、死者の復活、とこしえのさばきなど基礎的なことを再びやり直したりしないようにしましょう。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒の働き 18:21; コリント人への手紙第一 16:7; コリント人への手紙第一 4:19"> 神がお許しになるならば、私たちはそうすべきです。</span>
<span className="v" id="v4" data-v="4" data-xref="ヘブル人への手紙 10:26–29; ペテロの手紙第二 2:20–22; マタイの福音書 5:13"> 一度光を受けて天からの賜物の味を知り、聖霊にあずかる者となり、</span>
<span className="v" id="v5" data-v="5" data-xref="ペテロの手紙第一 2:3; ルカの福音書 8:13; マタイの福音書 13:20–21"> 神のすばらしいみことばと、後にやがて来る世の力とを味わったうえで、</span>
<span className="v" id="v6" data-v="6" data-xref="ペテロの手紙第二 2:21; ヘブル人への手紙 10:29; ヘブル人への手紙 6:4"> しかも堕落してしまうならば、そういう人々をもう一度悔い改めに立ち返らせることはできません。彼らは、自分で神の子をもう一度十字架にかけて、恥辱を与える人たちだからです。</span>
<span className="v" id="v7" data-v="7" data-xref="Hosea 10:12; Isaiah 44:3; Psalms 65:9–13"> 土地は、その上にしばしば降る雨を吸い込んで、これを耕す人たちのために有用な作物を生じるなら、神の祝福にあずかります。</span>
<span className="v" id="v8" data-v="8" data-xref="Genesis 3:17–18; ヨハネの福音書 15:6; ルカの福音書 13:7–9"> しかし、いばらやあざみなどを生えさせるなら、無用なものであって、やがてのろいを受け、ついには焼かれてしまいます。</span>
<span className="v" id="v9" data-v="9" data-xref="ヘブル人への手紙 10:39; コリント人への手紙第二 7:10; ヘブル人への手紙 6:4–6"> だが、愛する人たち。私たちはこのように言いますが、あなたがたについては、もっと良いことを確信しています。それは救いにつながることです。</span>
<span className="v" id="v10" data-v="10" data-xref="マタイの福音書 10:42; ヘブル人への手紙 13:16; ガラテヤ人への手紙 6:10"> 神は正しい方であって、あなたがたの行ないを忘れず、あなたがたがこれまで聖徒たちに仕え、また今も仕えて神の御名のために示したあの愛をお忘れにならないのです。</span>
<span className="v" id="v11" data-v="11" data-xref="ペテロの手紙第二 1:5–8; ヘブル人への手紙 3:6; ローマ人への手紙 5:2–5"> そこで、私たちは、あなたがたひとりひとりが、同じ熱心さを示して、最後まで、私たちの希望について十分な確信を持ち続けてくれるように切望します。</span>
<span className="v" id="v12" data-v="12" data-xref="ヘブル人への手紙 13:7; ヘブル人への手紙 10:36; ヨハネの手紙第一 2:25"> それは、あなたがたがなまけずに、信仰と忍耐によって約束のものを相続するあの人たちに、ならう者となるためです。</span>
<span className="v" id="v13" data-v="13" data-xref="Genesis 22:15–18; ルカの福音書 1:73; Jeremiah 22:5"> 神は、アブラハムに約束されるとき、ご自分よりすぐれたものをさして誓うことがありえないため、ご自分をさして誓い、</span>
<span className="v" id="v14" data-v="14" data-xref="Genesis 22:17; Deuteronomy 1:10; Nehemiah 9:23"> こう言われました。「わたしは必ずあなたを祝福し、あなたを大いにふやす。」</span>
<span className="v" id="v15" data-v="15" data-xref="Genesis 12:2–3; ローマ人への手紙 4:17–25; Exodus 1:7"> こうして、アブラハムは、忍耐の末に、約束のものを得ました。</span>
<span className="v" id="v16" data-v="16" data-xref="Exodus 22:11; ヘブル人への手紙 6:13; Genesis 31:53"> 確かに、人間は自分よりすぐれた者をさして誓います。そして、確証のための誓いというものは、人間のすべての反論をやめさせます。</span>
<span className="v" id="v17" data-v="17" data-xref="ヘブル人への手紙 6:18; Proverbs 19:21; Isaiah 55:11"> そこで、神は約束の相続者たちに、ご計画の変わらないことをさらにはっきり示そうと思い、誓いをもって保証されたのです。</span>
<span className="v" id="v18" data-v="18" data-xref="Numbers 23:19; テトスへの手紙 1:2; 1 Samuel 15:29"> それは、変えることのできない二つの事がらによって、――神は、これらの事がらのゆえに、偽ることができません。――前に置かれている望みを捕えるためにのがれて来た私たちが、力強い励ましを受けるためです。</span>
<span className="v" id="v19" data-v="19" data-xref="Psalms 43:5; ローマ人への手紙 5:5–10; ヘブル人への手紙 9:7"> この望みは、私たちのたましいのために、安全で確かな錨の役を果たし、またこの望みは幕の内側にはいるのです。</span>
<span className="v" id="v20" data-v="20" data-xref="ヘブル人への手紙 4:14; ヘブル人への手紙 3:1; ヘブル人への手紙 5:6"> イエスは私たちの先駆けとしてそこにはいり、永遠にメルキゼデクの位に等しい大祭司となられました。</span>

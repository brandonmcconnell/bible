<span className="v" id="v1" data-v="1" data-xref="ヨハネの手紙第一 4:20–1; ペテロの手紙第一 3:8; ペテロの手紙第一 1:22"> 兄弟愛をいつも持っていなさい。</span>
<span className="v" id="v2" data-v="2" data-xref="マタイの福音書 25:35; Genesis 18:1–3; ペテロの手紙第一 4:9"> 旅人をもてなすことを忘れてはいけません。こうして、ある人々は御使いたちを、それとは知らずにもてなしました。</span>
<span className="v" id="v3" data-v="3" data-xref="マタイの福音書 25:36; ヘブル人への手紙 10:34; ローマ人への手紙 12:15"> 牢につながれている人々を、自分も牢にいる気持ちで思いやり、また、自分も肉体を持っているのですから、苦しめられている人々を思いやりなさい。</span>
<span className="v" id="v4" data-v="4" data-xref="Genesis 2:24; Proverbs 5:15–23; ガラテヤ人への手紙 5:19"> 結婚がすべての人に尊ばれるようにしなさい。寝床を汚してはいけません。なぜなら、神は不品行な者と姦淫を行なう者とをさばかれるからです。</span>
<span className="v" id="v5" data-v="5" data-xref="Deuteronomy 31:8; Joshua 1:5; Deuteronomy 31:6"> 金銭を愛する生活をしてはいけません。いま持っているもので満足しなさい。主ご自身がこう言われるのです。「わたしは決してあなたを離れず、また、あなたを捨てない。」</span>
<span className="v" id="v6" data-v="6" data-xref="Psalms 118:6–9; Isaiah 41:10; ローマ人への手紙 8:31"> そこで、私たちは確信に満ちてこう言います。 「主は私の助け手です。私は恐れません。 人間が、私に対して何ができましょう。」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="テサロニケ人への手紙第一 5:12–13; ヘブル人への手紙 13:17; ピリピ人への手紙 3:17"> 神のみことばをあなたがたに話した指導者たちのことを、思い出しなさい。彼らの生活の結末をよく見て、その信仰にならいなさい。</span>
<span className="v" id="v8" data-v="8" data-xref="Malachi 3:6; ヤコブの手紙 1:17; ヨハネの黙示録 1:8"> イエス・キリストは、きのうもきょうも、いつまでも、同じです。</span>
<span className="v" id="v9" data-v="9" data-xref="エペソ人への手紙 4:14; テモテへの手紙第一 6:3–5; エペソ人への手紙 5:6"> さまざまの異なった教えによって迷わされてはなりません。食物によってではなく、恵みによって心を強めるのは良いことです。食物に気を取られた者は益を得ませんでした。</span>
<span className="v" id="v10" data-v="10" data-xref="コリント人への手紙第一 5:7–8; コリント人への手紙第一 10:20; コリント人への手紙第一 9:13"> 私たちには一つの祭壇があります。幕屋で仕える者たちには、この祭壇から食べる権利がありません。</span>
<span className="v" id="v11" data-v="11" data-xref="Leviticus 16:27; Exodus 29:14; Leviticus 9:11"> 動物の血は、罪のための供え物として、大祭司によって聖所の中まで持って行かれますが、からだは宿営の外で焼かれるからです。</span>
<span className="v" id="v12" data-v="12" data-xref="ヘブル人への手紙 9:12–14; ヨハネの福音書 19:17–18; 使徒の働き 7:58"> ですから、イエスも、ご自分の血によって民をきよめるために、門の外で苦しみを受けられました。</span>
<span className="v" id="v13" data-v="13" data-xref="ヘブル人への手紙 11:26; ペテロの手紙第一 4:14–16; 使徒の働き 5:41"> ですから、私たちは、キリストのはずかしめを身に負って、宿営の外に出て、みもとに行こうではありませんか。</span>
<span className="v" id="v14" data-v="14" data-xref="ピリピ人への手紙 3:20; コロサイ人への手紙 3:1–3; ヘブル人への手紙 11:12–16"> 私たちは、この地上に永遠の都を持っているのではなく、むしろ後に来ようとしている都を求めているのです。</span>
<span className="v" id="v15" data-v="15" data-xref="Psalms 107:21–22; Psalms 50:14; ローマ人への手紙 12:1"> ですから、私たちはキリストを通して、賛美のいけにえ、すなわち御名をたたえるくちびるの果実を、神に絶えずささげようではありませんか。</span>
<span className="v" id="v16" data-v="16" data-xref="テサロニケ人への手紙第二 3:13; ガラテヤ人への手紙 6:10; ローマ人への手紙 12:13"> 善を行なうことと、持ち物を人に分けることとを怠ってはいけません。神はこのようないけにえを喜ばれるからです。</span>
<span className="v" id="v17" data-v="17" data-xref="テサロニケ人への手紙第一 5:12–13; テモテへの手紙第一 5:17; ヘブル人への手紙 13:7"> あなたがたの指導者たちの言うことを聞き、また服従しなさい。この人々は神に弁明する者であって、あなたがたのたましいのために見張りをしているのです。ですから、この人たちが喜んでそのことをし、嘆いてすることにならないようにしなさい。そうでないと、あなたがたの益にならないからです。</span>
<span className="v" id="v18" data-v="18" data-xref="テサロニケ人への手紙第一 5:25; テサロニケ人への手紙第二 3:1; コロサイ人への手紙 4:3"> 私たちのために祈ってください。私たちは、正しい良心を持っていると確信しており、何事についても正しく行動しようと願っているからです。</span>
<span className="v" id="v19" data-v="19" data-xref="ピレモンへの手紙 1:22; ローマ人への手紙 1:10–12; ローマ人への手紙 15:31–32"> また、もっと祈ってくださるよう特にお願いします。それだけ、私があなたがたのところに早く帰れるようになるからです。</span>
<span className="v" id="v20" data-v="20" data-xref="ヨハネの福音書 10:11; ヘブル人への手紙 10:22; Psalms 23:1"> 永遠の契約の血による羊の大牧者、私たちの主イエスを死者の中から導き出された平和の神が、</span>
<span className="v" id="v21" data-v="21" data-xref="ピリピ人への手紙 2:13; テサロニケ人への手紙第二 2:17; ピリピ人への手紙 4:13"> イエス・キリストにより、御前でみこころにかなうことを私たちのうちに行ない、あなたがたがみこころを行なうことができるために、すべての良いことについて、あなたがたを完全な者としてくださいますように。どうか、キリストに栄光が世々限りなくありますように。アーメン。</span>
<span className="v" id="v22" data-v="22" data-xref="ヘブル人への手紙 3:1; ペテロの手紙第一 5:12; コリント人への手紙第二 6:1"> 兄弟たち。このような勧めのことばを受けてください。私はただ手短に書きました。</span>
<span className="v" id="v23" data-v="23" data-xref="ピレモンへの手紙 1:1; テサロニケ人への手紙第一 3:2; テモテへの手紙第二 1:8"> 私たちの兄弟テモテが釈放されたことをお知らせします。もし彼が早く来れば、私は彼といっしょにあなたがたに会えるでしょう。</span>
<span className="v" id="v24" data-v="24" data-xref="ヘブル人への手紙 13:7; ヘブル人への手紙 13:17; 使徒の働き 18:2"> すべてのあなたがたの指導者たち、また、すべての聖徒たちによろしく言ってください。イタリヤから来た人たちが、あなたがたによろしくと言っています。</span>
<span className="v" id="v25" data-v="25" data-xref="コロサイ人への手紙 4:18; テモテへの手紙第二 4:22; テトスへの手紙 3:15"> 恵みが、あなたがたすべてとともにありますように。</span>

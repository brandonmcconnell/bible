<span className="v" id="v1" data-v="1" data-xref="Exodus 25:8; ヘブル人への手紙 9:10–11; ヘブル人への手紙 8:2"> 初めの契約にも礼拝の規定と地上の聖所とがありました。</span>
<span className="v" id="v2" data-v="2" data-xref="Exodus 40:4; Leviticus 24:5–8; Exodus 26:35"> 幕屋が設けられ、その前部の所には、燭台と机と供えのパンがありました。聖所と呼ばれる所です。</span>
<span className="v" id="v3" data-v="3" data-xref="Exodus 26:31–33; Exodus 40:3; マタイの福音書 27:51"> また、第二の垂れ幕のうしろには、至聖所と呼ばれる幕屋が設けられ、</span>
<span className="v" id="v4" data-v="4" data-xref="Numbers 17:10; 2 Chronicles 5:10; Exodus 40:3"> そこには金の香壇と、全面を金でおおわれた契約の箱があり、箱の中には、マナのはいった金のつぼ、芽を出したアロンの杖、契約の二つの板がありました。</span>
<span className="v" id="v5" data-v="5" data-xref="Leviticus 16:2; Numbers 7:89; Exodus 25:17–22"> また、箱の上には、贖罪蓋を翼でおおっている栄光のケルビムがありました。しかしこれらについては、今いちいち述べることができません。</span>
<span className="v" id="v6" data-v="6" data-xref="Numbers 28:3; Exodus 27:21; ルカの福音書 1:8–11"> さて、これらの物が以上のように整えられた上で、前の幕屋には、祭司たちがいつもはいって礼拝を行なうのですが、</span>
<span className="v" id="v7" data-v="7" data-xref="Leviticus 16:34; Leviticus 5:18; ヘブル人への手紙 10:19–20"> 第二の幕屋には、大祭司だけが年に一度だけはいります。そのとき、血を携えずにはいるようなことはありません。その血は、自分のために、また、民が知らずに犯した罪のためにささげるものです。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨハネの福音書 14:6; ヘブル人への手紙 3:7; ヘブル人への手紙 10:19–22"> これによって聖霊は次のことを示しておられます。すなわち、前の幕屋が存続しているかぎり、まことの聖所への道は、まだ明らかにされていないということです。</span>
<span className="v" id="v9" data-v="9" data-xref="ペテロの手紙第一 3:21; ヘブル人への手紙 5:1; ローマ人への手紙 5:14"> この幕屋はその当時のための比喩です。それに従って、ささげ物といけにえとがささげられますが、それらは礼拝する者の良心を完全にすることはできません。</span>
<span className="v" id="v10" data-v="10" data-xref="エペソ人への手紙 2:15; コロサイ人への手紙 2:16; Leviticus 11:2–47"> それらは、ただ食物と飲み物と種々の洗いに関するもので、新しい秩序の立てられる時まで課せられた、からだに関する規定にすぎないからです。</span>
<span className="v" id="v11" data-v="11" data-xref="ヘブル人への手紙 9:23–24; コリント人への手紙第二 5:1; ヘブル人への手紙 8:1–2"> しかしキリストは、すでに成就したすばらしい事がらの大祭司として来られ、手で造った物でない、言い替えれば、この造られた物とは違った、さらに偉大な、さらに完全な幕屋を通り、</span>
<span className="v" id="v12" data-v="12" data-xref="ヘブル人への手紙 10:4; ペテロの手紙第一 1:18–19; ヘブル人への手紙 9:15"> また、やぎと子牛との血によってではなく、ご自分の血によって、ただ一度、まことの聖所にはいり、永遠の贖いを成し遂げられたのです。</span>
<span className="v" id="v13" data-v="13" data-xref="Numbers 19:2–21; Leviticus 16:14–16; 使徒の働き 15:9"> もし、やぎと雄牛の血、また雌牛の灰を汚れた人々に注ぎかけると、それがきよめの働きをして肉体をきよいものにするとすれば、</span>
<span className="v" id="v14" data-v="14" data-xref="ヘブル人への手紙 10:22; ペテロの手紙第一 1:19; ヨハネの手紙第一 1:7"> まして、キリストが傷のないご自身を、とこしえの御霊によって神におささげになったその血は、どんなにか私たちの良心をきよめて死んだ行ないから離れさせ、生ける神に仕える者とすることでしょう。</span>
<span className="v" id="v15" data-v="15" data-xref="ローマ人への手紙 3:24–26; ローマ人への手紙 8:30; ローマ人への手紙 8:28"> こういうわけで、キリストは新しい契約の仲介者です。それは、初めの契約のときの違反を贖うための死が実現したので、召された者たちが永遠の資産の約束を受けることができるためなのです。</span>
<span className="v" id="v16" data-v="16" data-xref="ヤコブの手紙 2:10; コリント人への手紙第一 15:22; ローマ人への手紙 5:12"> 遺言には、遺言者の死亡証明が必要です。</span>
<span className="v" id="v17" data-v="17" data-xref="Genesis 48:21; ヨハネの福音書 14:27; ガラテヤ人への手紙 3:15"> 遺言は、人が死んだとき初めて有効になるのであって、遺言者が生きている間は、決して効力はありません。</span>
<span className="v" id="v18" data-v="18" data-xref="Exodus 24:3–8; ヘブル人への手紙 9:14; ヘブル人への手紙 9:22"> したがって、初めの契約も血なしに成立したのではありません。</span>
<span className="v" id="v19" data-v="19" data-xref="Exodus 24:5–11; Numbers 19:6; ヘブル人への手紙 10:4"> モーセは、律法に従ってすべての戒めを民全体に語って後、水と赤い色の羊の毛とヒソプとのほかに、子牛とやぎの血を取って、契約の書自体にも民の全体にも注ぎかけ、</span>
<span className="v" id="v20" data-v="20" data-xref="Exodus 24:8; マタイの福音書 26:28; ヘブル人への手紙 13:20"> 「これは神があなたがたに対して立てられた契約の血である。」と言いました。</span>
<span className="v" id="v21" data-v="21" data-xref="Leviticus 8:15; Leviticus 8:19; Exodus 29:36"> また彼は、幕屋と礼拝のすべての器具にも同様に血を注ぎかけました。</span>
<span className="v" id="v22" data-v="22" data-xref="Leviticus 17:11; Leviticus 6:7; Leviticus 4:35"> それで、律法によれば、すべてのものは血によってきよめられる、と言ってよいでしょう。また、血を注ぎ出すことがなければ、罪の赦しはないのです。</span>
<span className="v" id="v23" data-v="23" data-xref="ペテロの手紙第一 1:19–21; ヘブル人への手紙 10:4; ヘブル人への手紙 9:14"> ですから、天にあるものにかたどったものは、これらのものによってきよめられる必要がありました。しかし天にあるもの自体は、これよりもさらにすぐれたいけにえで、きよめられなければなりません。</span>
<span className="v" id="v24" data-v="24" data-xref="ヘブル人への手紙 12:2; ヘブル人への手紙 9:11–12; ヘブル人への手紙 9:23"> キリストは、本物の模型にすぎない、手で造った聖所にはいられたのではなく、天そのものにはいられたのです。そして、今、私たちのために神の御前に現われてくださるのです。</span>
<span className="v" id="v25" data-v="25" data-xref="ヘブル人への手紙 9:12; ヘブル人への手紙 9:7; ヘブル人への手紙 9:14"> それも、年ごとに自分の血でない血を携えて聖所にはいる大祭司とは違って、キリストは、ご自分を幾度もささげることはなさいません。</span>
<span className="v" id="v26" data-v="26" data-xref="ヘブル人への手紙 9:12; ペテロの手紙第一 1:20; ヘブル人への手紙 1:2"> もしそうでなかったら、世の初めから幾度も苦難を受けなければならなかったでしょう。しかしキリストは、ただ一度、今の世の終わりに、ご自身をいけにえとして罪を取り除くために、来られたのです。</span>
<span className="v" id="v27" data-v="27" data-xref="コリント人への手紙第二 5:10; Ecclesiastes 12:7; Ecclesiastes 12:14"> そして、人間には、一度死ぬことと死後にさばきを受けることが定まっているように、</span>
<span className="v" id="v28" data-v="28" data-xref="テトスへの手紙 2:13; ペテロの手紙第一 2:24; ローマ人への手紙 6:10"> キリストも、多くの人の罪を負うために一度、ご自身をささげられましたが、二度目は、罪を負うためではなく、彼を待ち望んでいる人々の救いのために来られるのです。</span>

<span className="v" id="v1" data-v="1" data-xref="ヘブル人への手紙 8:3; ヘブル人への手紙 10:11; ヘブル人への手紙 7:27"> 大祭司はみな、人々の中から選ばれ、神に仕える事がらについて人々に代わる者として、任命を受けたのです。それは、罪のために、ささげ物といけにえとをささげるためです。</span>
<span className="v" id="v2" data-v="2" data-xref="ヘブル人への手紙 4:15; ヘブル人への手紙 2:18; コリント人への手紙第二 12:9–10"> 彼は、自分自身も弱さを身にまとっているので、無知な迷っている人々を思いやることができるのです。</span>
<span className="v" id="v3" data-v="3" data-xref="Leviticus 9:7; ヘブル人への手紙 9:7; Leviticus 16:6"> そしてまた、その弱さのゆえに、民のためだけでなく、自分のためにも、罪のためのささげ物をしなければなりません。</span>
<span className="v" id="v4" data-v="4" data-xref="Exodus 28:1; Numbers 16:40; Numbers 16:5"> まただれでも、この名誉は自分で得るのではなく、アロンのように神に召されて受けるのです。</span>
<span className="v" id="v5" data-v="5" data-xref="Psalms 2:7; ヨハネの福音書 8:54; 使徒の働き 13:33"> 同様に、キリストも大祭司となる栄誉を自分で得られたのではなく、彼に、 「あなたは、わたしの子。 きょう、わたしがあなたを生んだ。」 と言われた方が、それをお与えになったのです。</span>
<span className="v" id="v6" data-v="6" data-xref="Psalms 110:4; ヘブル人への手紙 7:17; ヘブル人への手紙 7:21"> 別の個所で、こうも言われます。 「あなたは、とこしえに、 メルキゼデクの位に等しい祭司である。」</span>
<span className="v" id="v7" data-v="7" data-xref="マルコの福音書 14:32–39; ルカの福音書 22:41–44; ヨハネの福音書 17:1"> キリストは、人としてこの世におられたとき、自分を死から救うことのできる方に向かって、大きな叫び声と涙とをもって祈りと願いをささげ、そしてその敬虔のゆえに聞き入れられました。</span>
<span className="v" id="v8" data-v="8" data-xref="ピリピ人への手紙 2:8; ヘブル人への手紙 10:5–9; ヨハネの福音書 4:34"> キリストは御子であられるのに、お受けになった多くの苦しみによって従順を学び、</span>
<span className="v" id="v9" data-v="9" data-xref="ヘブル人への手紙 2:10; ヘブル人への手紙 9:12; ヘブル人への手紙 9:15"> 完全な者とされ、彼に従うすべての人々に対して、とこしえの救いを与える者となり、</span>
<span className="v" id="v10" data-v="10" data-xref="ヘブル人への手紙 5:5–6; ヘブル人への手紙 6:20"> 神によって、メルキゼデクの位に等しい大祭司ととなえられたのです。</span>
<span className="v" id="v11" data-v="11" data-xref="マタイの福音書 13:15; 使徒の働き 28:27; ペテロの手紙第二 3:16"> この方について、私たちは話すべきことをたくさん持っていますが、あなたがたの耳が鈍くなっているため、説き明かすことが困難です。</span>
<span className="v" id="v12" data-v="12" data-xref="ヘブル人への手紙 6:1; コリント人への手紙第一 3:1–3; ペテロの手紙第一 2:2"> あなたがたは年数からすれば教師になっていなければならないにもかかわらず、神のことばの初歩をもう一度だれかに教えてもらう必要があるのです。あなたがたは堅い食物ではなく、乳を必要とするようになっています。</span>
<span className="v" id="v13" data-v="13" data-xref="コリント人への手紙第一 14:20; ペテロの手紙第一 2:2; テモテへの手紙第二 3:16"> まだ乳ばかり飲んでいるような者はみな、義の教えに通じてはいません。幼子なのです。</span>
<span className="v" id="v14" data-v="14" data-xref="コリント人への手紙第一 2:14–15; テサロニケ人への手紙第一 5:21; エペソ人への手紙 1:18"> しかし、堅い食物はおとなの物であって、経験によって良い物と悪い物とを見分ける感覚を訓練された人たちの物です。</span>

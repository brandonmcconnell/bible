<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="コリント人への手紙第二 5:7; コリント人への手紙第二 4:18; ローマ人への手紙 8:24–25"> 信仰は望んでいる事がらを保証し、目に見えないものを確信させるものです。</span>
<span className="v" id="v2" data-v="2" data-xref="ヘブル人への手紙 11:39; ヘブル人への手紙 11:4"> 昔の人々はこの信仰によって称賛されました。</span>
<span className="v" id="v3" data-v="3" data-xref="Psalms 33:6; ペテロの手紙第二 3:5; ヨハネの福音書 1:3"> 信仰によって、私たちは、この世界が神のことばで造られたことを悟り、したがって、見えるものが目に見えるものからできたのではないことを悟るのです。</span>
<span className="v" id="v4" data-v="4" data-xref="ヘブル人への手紙 12:24; Genesis 4:3–5; ヨハネの手紙第一 3:11–12"> 信仰によって、アベルはカインよりもすぐれたいけにえを神にささげ、そのいけにえによって彼が義人であることの証明を得ました。神が、彼のささげ物を良いささげ物だとあかししてくださったからです。彼は死にましたが、その信仰によって、今もなお語っています。</span>
<span className="v" id="v5" data-v="5" data-xref="Genesis 5:21–24; ユダの手紙 1:14; ヘブル人への手紙 11:6"> 信仰によって、エノクは死を見ることのないように移されました。神に移されて、見えなくなりました。移される前に、彼は神に喜ばれていることが、あかしされていました。</span>
<span className="v" id="v6" data-v="6" data-xref="Proverbs 8:17; Jeremiah 29:13–14; マタイの福音書 6:33"> 信仰がなくては、神に喜ばれることはできません。神に近づく者は、神がおられることと、神を求める者には報いてくださる方であることとを、信じなければならないのです。</span>
<span className="v" id="v7" data-v="7" data-xref="Genesis 6:13–1; ペテロの手紙第一 3:20; Ezekiel 14:14"> 信仰によって、ノアは、まだ見ていない事がらについて神から警告を受けたとき、恐れかしこんで、その家族の救いのために箱舟を造り、その箱舟によって、世の罪を定め、信仰による義を相続する者となりました。</span>
<span className="v" id="v8" data-v="8" data-xref="Genesis 12:1–4; 使徒の働き 7:2–4; マタイの福音書 7:24–25"> 信仰によって、アブラハムは、相続財産として受け取るべき地に出て行けとの召しを受けたとき、これに従い、どこに行くのかを知らないで、出て行きました。</span>
<span className="v" id="v9" data-v="9" data-xref="Genesis 12:8; Genesis 13:18; Genesis 13:3"> 信仰によって、彼は約束された地に他国人のようにして住み、同じ約束をともに相続するイサクやヤコブとともに天幕生活をしました。</span>
<span className="v" id="v10" data-v="10" data-xref="ヘブル人への手紙 13:14; ピリピ人への手紙 3:20; ヘブル人への手紙 12:22"> 彼は、堅い基礎の上に建てられた都を待ち望んでいたからです。その都を設計し建設されたのは神です。</span>
<span className="v" id="v11" data-v="11" data-xref="ローマ人への手紙 4:20–21; ヘブル人への手紙 10:23; Genesis 18:11–14"> 信仰によって、サラも、すでにその年を過ぎた身であるのに、子を宿す力を与えられました。彼女は約束してくださった方を真実な方と考えたからです。</span>
<span className="v" id="v12" data-v="12" data-xref="Genesis 22:17; Genesis 32:12; Genesis 15:5"> そこで、ひとりの、しかも死んだも同様のアブラハムから、天の星のように、また海べの数えきれない砂のように数多い子孫が生まれたのです。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="Genesis 23:4; Psalms 39:12; ヘブル人への手紙 11:27"> これらの人々はみな、信仰の人々として死にました。約束のものを手に入れることはありませんでしたが、はるかにそれを見て喜び迎え、地上では旅人であり寄留者であることを告白していたのです。</span>
<span className="v" id="v14" data-v="14" data-xref="コリント人への手紙第二 4:18–7; ヘブル人への手紙 11:16; ヘブル人への手紙 13:14"> 彼らはこのように言うことによって、自分の故郷を求めていることを示しています。</span>
<span className="v" id="v15" data-v="15" data-xref="Genesis 24:6–8; Genesis 12:10; Genesis 32:9–11"> もし、出て来た故郷のことを思っていたのであれば、帰る機会はあったでしょう。</span>
<span className="v" id="v16" data-v="16" data-xref="ヘブル人への手紙 13:14; ヘブル人への手紙 11:10; ピリピ人への手紙 3:20"> しかし、事実、彼らは、さらにすぐれた故郷、すなわち天の故郷にあこがれていたのです。それゆえ、神は彼らの神と呼ばれることを恥となさいませんでした。事実、神は彼らのために都を用意しておられました。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="Genesis 22:16; Genesis 22:1–12; ヤコブの手紙 2:21–24"> 信仰によって、アブラハムは、試みられたときイサクをささげました。彼は約束を与えられていましたが、自分のただひとりの子をささげたのです。</span>
<span className="v" id="v18" data-v="18" data-xref="Genesis 21:12; ローマ人への手紙 9:7; Genesis 17:19"> 神はアブラハムに対して、「イサクから出る者があなたの子孫と呼ばれる。」と言われたのですが、</span>
<span className="v" id="v19" data-v="19" data-xref="ローマ人への手紙 4:17–21; マタイの福音書 9:28; エペソ人への手紙 3:20"> 彼は、神には人を死者の中からよみがえらせることもできる、と考えました。それで彼は、死者の中からイサクを取り戻したのです。これは型です。</span>
<span className="v" id="v20" data-v="20" data-xref="Genesis 27:27–40; Genesis 28:2–3"> 信仰によって、イサクは未来のことについて、ヤコブとエサウを祝福しました。</span>
<span className="v" id="v21" data-v="21" data-xref="Genesis 47:31–1; Genesis 48:5–22"> 信仰によって、ヤコブは死ぬとき、ヨセフの子どもたちをひとりひとり祝福し、また自分の杖のかしらに寄りかかって礼拝しました。</span>
<span className="v" id="v22" data-v="22" data-xref="Exodus 13:19; Genesis 50:24–25; Joshua 24:32"> 信仰によって、ヨセフは臨終のとき、イスラエルの子孫の脱出を語り、自分の骨について指図しました。</span>
<span className="v" id="v23" data-v="23" data-xref="Exodus 1:22; Exodus 1:16; ヘブル人への手紙 13:6"> 信仰によって、モーセは生まれてから、両親によって三か月の間隠されていました。彼らはその子の美しいのを見たからです。彼らは王の命令をも恐れませんでした。</span>
<span className="v" id="v24" data-v="24" data-xref="Exodus 2:10–11; 使徒の働き 7:21–24"> 信仰によって、モーセは成人したとき、パロの娘の子と呼ばれることを拒み、</span>
<span className="v" id="v25" data-v="25" data-xref="Psalms 84:10; テモテへの手紙第二 2:3–10; Job 36:21"> はかない罪の楽しみを受けるよりは、むしろ神の民とともに苦しむことを選び取りました。</span>
<span className="v" id="v26" data-v="26" data-xref="ヘブル人への手紙 10:35; ヘブル人への手紙 11:6; ペテロの手紙第一 4:14"> 彼は、キリストのゆえに受けるそしりを、エジプトの宝にまさる大きな富と思いました。彼は報いとして与えられるものから目を離さなかったのです。</span>
<span className="v" id="v27" data-v="27" data-xref="コリント人への手紙第二 4:18; ヘブル人への手紙 11:13; ヘブル人への手紙 11:1"> 信仰によって、彼は、王の怒りを恐れないで、エジプトを立ち去りました。目に見えない方を見るようにして、忍び通したからです。</span>
<span className="v" id="v28" data-v="28" data-xref="Exodus 12:21–30; ヘブル人への手紙 9:19; ヘブル人への手紙 12:24"> 信仰によって、初子を滅ぼす者が彼らに触れることのないように、彼は過越と血の注ぎとを行ないました。</span>
<span className="v" id="v29" data-v="29" data-xref="Exodus 14:13–21; Psalms 106:9–11; Psalms 78:13"> 信仰によって、彼らは、かわいた陸地を行くのと同様に紅海を渡りました。エジプト人は、同じようにしようとしましたが、のみこまれてしまいました。</span>
<span className="v" id="v30" data-v="30" data-xref="Joshua 6:3–20; コリント人への手紙第二 10:4–5"> 信仰によって、人々が七日の間エリコの城の周囲を回ると、その城壁はくずれ落ちました。</span>
<span className="v" id="v31" data-v="31" data-xref="ヤコブの手紙 2:25; Joshua 6:22–25; マタイの福音書 1:5"> 信仰によって、遊女ラハブは、偵察に来た人たちを穏やかに受け入れたので、不従順な人たちといっしょに滅びることを免れました。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="1 Samuel 16:1; 1 Samuel 1:20; 1 Samuel 16:13"> これ以上、何を言いましょうか。もし、ギデオン、バラク、サムソン、エフタ、またダビデ、サムエル、預言者たちについても話すならば、時が足りないでしょう。</span>
<span className="v" id="v33" data-v="33" data-xref="Psalms 144:1–2; ヘブル人への手紙 6:12–15; ヘブル人への手紙 10:36"> 彼らは、信仰によって、国々を征服し、正しいことを行ない、約束のものを得、ししの口をふさぎ、</span>
<span className="v" id="v34" data-v="34" data-xref="2 Kings 6:16–18; コリント人への手紙第二 12:9–10; 1 Samuel 17:51–52"> 火の勢いを消し、剣の刃をのがれ、弱い者なのに強くされ、戦いの勇士となり、他国の陣営を陥れました。</span>
<span className="v" id="v35" data-v="35" data-xref="2 Kings 4:27–37; 1 Kings 17:22–24; ピリピ人への手紙 3:11"> 女たちは、死んだ者をよみがえらせていただきました。またほかの人たちは、さらにすぐれたよみがえりを得るために、釈放されることを願わないで拷問を受けました。</span>
<span className="v" id="v36" data-v="36" data-xref="Jeremiah 20:2; Genesis 39:20; Jeremiah 37:15–21"> また、ほかの人たちは、あざけられ、むちで打たれ、さらに鎖につながれ、牢に入れられるめに会い、</span>
<span className="v" id="v37" data-v="37" data-xref="2 Chronicles 24:21; Jeremiah 26:23; 1 Kings 19:10"> また、石で打たれ、試みを受け、のこぎりで引かれ、剣で切り殺され、羊ややぎの皮を着て歩き回り、乏しくなり、悩まされ、苦しめられ、</span>
<span className="v" id="v38" data-v="38" data-xref="1 Kings 18:4; 1 Samuel 22:1; 1 Kings 19:9"> ――この世は彼らにふさわしい所ではありませんでした。――荒野と山とほら穴と地の穴とをさまよいました。</span>
<span className="v" id="v39" data-v="39" data-xref="ルカの福音書 10:23–24; ヘブル人への手紙 11:13; ヘブル人への手紙 11:2"> この人々はみな、その信仰によってあかしされましたが、約束されたものは得ませんでした。</span>
<span className="v" id="v40" data-v="40" data-xref="ヨハネの黙示録 6:11; ヘブル人への手紙 8:6; ヘブル人への手紙 10:11–14"> 神は私たちのために、さらにすぐれたものをあらかじめ用意しておられたので、彼らが私たちと別に全うされるということはなかったのです。</span>
</div>

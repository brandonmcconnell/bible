<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="Genesis 14:18–20; Psalms 57:2; ヘブル人への手紙 6:20"> このメルキゼデクは、サレムの王で、すぐれて高い神の祭司でしたが、アブラハムが王たちを打ち破って帰るのを出迎えて祝福しました。</span>
<span className="v" id="v2" data-v="2" data-xref="Numbers 18:21; Psalms 85:10–11; 1 Samuel 8:17"> またアブラハムは彼に、すべての戦利品の十分の一を分けました。まず彼は、その名を訳すと義の王であり、次に、サレムの王、すなわち平和の王です。</span>
<span className="v" id="v3" data-v="3" data-xref="ヘブル人への手紙 7:17; ヘブル人への手紙 7:23–28; Exodus 6:20–27"> 父もなく、母もなく、系図もなく、その生涯の初めもなく、いのちの終わりもなく、神の子に似た者とされ、いつまでも祭司としてとどまっているのです。</span>
<span className="v" id="v4" data-v="4" data-xref="Genesis 14:20; 使徒の働き 2:29; 使徒の働き 7:8–9"> その人がどんなに偉大であるかを、よく考えてごらんなさい。族長であるアブラハムでさえ、彼に一番良い戦利品の十分の一を与えたのです。</span>
<span className="v" id="v5" data-v="5" data-xref="Leviticus 27:30–33; 2 Chronicles 31:4–6; Numbers 18:21–32"> レビの子らの中で祭司職を受ける者たちは、自分もアブラハムの子孫でありながら、民から、すなわち彼らの兄弟たちから、十分の一を徴集するようにと、律法の中で命じられています。</span>
<span className="v" id="v6" data-v="6" data-xref="ローマ人への手紙 4:13; ヘブル人への手紙 7:3–4; Genesis 13:14–17"> ところが、レビ族の系図にない者が、アブラハムから十分の一を取って、約束を受けた人を祝福したのです。</span>
<span className="v" id="v7" data-v="7" data-xref="2 Chronicles 30:27; Genesis 48:15–20; テモテへの手紙第一 3:16"> いうまでもなく、下位の者が上位の者から祝福されるのです。</span>
<span className="v" id="v8" data-v="8" data-xref="ヘブル人への手紙 6:20; ヘブル人への手紙 5:6; ヨハネの黙示録 1:18"> 一方では、死ぬべき人間が十分の一を受けていますが、他のばあいは、彼は生きているとあかしされている者が受けるのです。</span>
<span className="v" id="v9" data-v="9" data-xref="ローマ人への手紙 5:12; Genesis 14:20; ヘブル人への手紙 7:4"> また、いうならば、十分の一を受け取るレビでさえアブラハムを通して十分の一を納めているのです。</span>
<span className="v" id="v10" data-v="10" data-xref="Genesis 35:11; ヘブル人への手紙 7:5; Genesis 46:26"> というのは、メルキゼデクがアブラハムを出迎えたときには、レビはまだ父の腰の中にいたからです。</span>
<span className="v" id="v11" data-v="11" data-xref="ヘブル人への手紙 8:7; ガラテヤ人への手紙 2:21; ガラテヤ人への手紙 4:9"> さて、もしレビ系の祭司職によって完全に到達できたのだったら、――民はそれを基礎として律法を与えられたのです。――それ以上何の必要があって、アロンの位でなく、メルキゼデクの位に等しいと呼ばれる他の祭司が立てられたのでしょうか。</span>
<span className="v" id="v12" data-v="12" data-xref="Jeremiah 31:31–34; Isaiah 66:21; Ezekiel 16:61"> 祭司職が変われば、律法も必ず変わらなければなりませんが、</span>
<span className="v" id="v13" data-v="13" data-xref="ヘブル人への手紙 7:11; ヘブル人への手紙 7:14; Numbers 17:5"> 私たちが今まで論じて来たその方は、祭壇に仕える者を出したことのない別の部族に属しておられるのです。</span>
<span className="v" id="v14" data-v="14" data-xref="Micah 5:2; Isaiah 11:1; ルカの福音書 3:33"> 私たちの主が、ユダ族から出られたことは明らかですが、モーセは、この部族については、祭司に関することを何も述べていません。</span>
<span className="v" id="v15" data-v="15" data-xref="Psalms 110:4; ヘブル人への手紙 7:17–21; ヘブル人への手紙 7:3"> もしメルキゼデクに等しい、別の祭司が立てられるのなら、以上のことは、いよいよ明らかになります。</span>
<span className="v" id="v16" data-v="16" data-xref="ヨハネの黙示録 1:18; コロサイ人への手紙 2:20; ヘブル人への手紙 7:28"> その祭司は、肉についての戒めである律法にはよらないで、朽ちることのない、いのちの力によって祭司となったのです。</span>
<span className="v" id="v17" data-v="17" data-xref="Psalms 110:4; ヘブル人への手紙 5:6; ヘブル人への手紙 7:21"> この方については、こうあかしされています。 「あなたは、とこしえに、 メルキゼデクの位に等しい祭司である。」</span>
<span className="v" id="v18" data-v="18" data-xref="ローマ人への手紙 8:3; 使徒の働き 13:39; ガラテヤ人への手紙 4:9"> 一方で、前の戒めは、弱く無益なために、廃止されましたが、</span>
<span className="v" id="v19" data-v="19" data-xref="使徒の働き 13:39; ヘブル人への手紙 4:16; ヘブル人への手紙 9:9"> ――律法は何事も全うしなかったのです。――他方で、さらにすぐれた希望が導き入れられました。私たちはこれによって神に近づくのです。</span>
<span className="v" id="v20" data-v="20" data-xref="Numbers 18:7; ヘブル人への手紙 5:6; Psalms 110:4"> また、そのためには、はっきりと誓いがなされています。</span>
<span className="v" id="v21" data-v="21" data-xref="Psalms 110:4; ヘブル人への手紙 7:17; ヘブル人への手紙 6:16–18"> ――彼らのばあいは、誓いなしに祭司となるのですが、主のばあいには、主に対して次のように言われた方の誓いがあります。 「主は誓ってこう言われ、 みこころを変えられることはない。 『あなたはとこしえに祭司である。』」――</span>
<span className="v" id="v22" data-v="22" data-xref="コリント人への手紙第一 11:25; Genesis 44:32; ヘブル人への手紙 8:6–12"> そのようにして、イエスは、さらにすぐれた契約の保証となられたのです。</span>
<span className="v" id="v23" data-v="23" data-xref="Nehemiah 12:10–11; 1 Chronicles 6:3–14; ヘブル人への手紙 7:8"> また、彼らのばあいは、死ということがあるため、務めにいつまでもとどまることができず、大ぜいの者が祭司となりました。</span>
<span className="v" id="v24" data-v="24" data-xref="ヨハネの福音書 12:34; ヘブル人への手紙 7:28; Isaiah 9:6–7"> しかし、キリストは永遠に存在されるのであって、変わることのない祭司の務めを持っておられます。</span>
<span className="v" id="v25" data-v="25" data-xref="ローマ人への手紙 8:34; ヨハネの手紙第一 2:1–2; テモテへの手紙第一 2:5"> したがって、ご自分によって神に近づく人々を、完全に救うことがおできになります。キリストはいつも生きていて、彼らのために、とりなしをしておられるからです。</span>
<span className="v" id="v26" data-v="26" data-xref="コリント人への手紙第二 5:21; ヘブル人への手紙 4:14–15; ペテロの手紙第一 2:22"> また、このようにきよく、悪も汚れもなく、罪人から離れ、また、天よりも高くされた大祭司こそ、私たちにとってまさに必要な方です。</span>
<span className="v" id="v27" data-v="27" data-xref="ヘブル人への手紙 9:28; ヘブル人への手紙 9:12; ヘブル人への手紙 9:14"> ほかの大祭司たちとは違い、キリストには、まず自分の罪のために、その次に、民の罪のために毎日いけにえをささげる必要はありません。というのは、キリストは自分自身をささげ、ただ一度でこのことを成し遂げられたからです。</span>
<span className="v" id="v28" data-v="28" data-xref="ヘブル人への手紙 2:10; ヘブル人への手紙 7:21; ヘブル人への手紙 1:2"> 律法は弱さを持つ人間を大祭司に立てますが、律法のあとから来た誓いのみことばは、永遠に全うされた御子を立てるのです。</span>

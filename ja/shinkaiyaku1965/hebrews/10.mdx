<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヘブル人への手紙 8:5; ヘブル人への手紙 9:11; コロサイ人への手紙 2:17"> 律法には、後に来るすばらしいものの影はあっても、その実物はないのですから、律法は、年ごとに絶えずささげられる同じいけにえによって神に近づいて来る人々を、完全にすることができないのです。</span>
<span className="v" id="v2" data-v="2" data-xref="Isaiah 43:25; Micah 7:19; Psalms 103:12"> もしそれができたのであったら、礼拝する人々は、一度きよめられた者として、もはや罪を意識しなかったはずであり、したがって、ささげ物をすることは、やんだはずです。</span>
<span className="v" id="v3" data-v="3" data-xref="ヘブル人への手紙 9:7; Exodus 30:10; Leviticus 23:27–28"> ところがかえって、これらのささげ物によって、罪が年ごとに思い出されるのです。</span>
<span className="v" id="v4" data-v="4" data-xref="ヘブル人への手紙 10:11; Isaiah 1:11–15; Micah 6:6–8"> 雄牛とやぎの血は、罪を除くことができません。</span>
<span className="v" id="v5" data-v="5" data-xref="Psalms 40:6–8; Isaiah 1:11; Isaiah 7:14"> ですから、キリストは、この世界に来て、こう言われるのです。 「あなたは、いけにえやささげ物を望まないで、 わたしのために、からだを造ってくださいました。</span>
<span className="v" id="v6" data-v="6" data-xref="Malachi 1:10; マタイの福音書 3:17; Psalms 147:11"> あなたは全焼のいけにえと 罪のためのいけにえとで 満足されませんでした。</span>
<span className="v" id="v7" data-v="7" data-xref="Psalms 40:7–8; ヨハネの福音書 4:34; ヨハネの福音書 6:38"> そこでわたしは言いました。 『さあ、わたしは来ました。 聖書のある巻に、 わたしについてしるされているとおり、 神よ、あなたのみこころを行なうために。』」</span>
<span className="v" id="v8" data-v="8" data-xref="ヘブル人への手紙 10:5; マルコの福音書 12:33"> すなわち、初めには、「あなたは、いけにえとささげ物、全焼のいけにえと罪のためのいけにえ（すなわち、律法に従ってささげられる、いろいろの物）を望まず、またそれらで満足されませんでした。」と言い、</span>
<span className="v" id="v9" data-v="9" data-xref="ヘブル人への手紙 7:18–19; ヘブル人への手紙 12:27–28; ヘブル人への手紙 10:7"> また、「さあ、わたしはあなたのみこころを行なうために来ました。」と言われたのです。後者が立てられるために、前者が廃止されるのです。</span>
<span className="v" id="v10" data-v="10" data-xref="ヘブル人への手紙 10:14; ヘブル人への手紙 10:12; コリント人への手紙第一 6:11"> このみこころに従って、イエス・キリストのからだが、ただ一度だけささげられたことにより、私たちはきよめられたものとされているのです。</span>
<span className="v" id="v11" data-v="11" data-xref="ヘブル人への手紙 5:1; Numbers 28:3; ヘブル人への手紙 10:4"> また、すべて祭司は毎日立って礼拝の務めをなし、同じいけにえをくり返しささげますが、それらは決して罪を除き去ることができません。</span>
<span className="v" id="v12" data-v="12" data-xref="ヘブル人への手紙 1:3; コロサイ人への手紙 3:1; ローマ人への手紙 8:34"> しかし、キリストは、罪のために一つの永遠のいけにえをささげて後、神の右の座に着き、</span>
<span className="v" id="v13" data-v="13" data-xref="ヘブル人への手紙 1:13; Psalms 110:1; ルカの福音書 20:43"> それからは、その敵がご自分の足台となるのを待っておられるのです。</span>
<span className="v" id="v14" data-v="14" data-xref="ヘブル人への手紙 7:25; ヘブル人への手紙 10:1; ヘブル人への手紙 9:14"> キリストはきよめられる人々を、一つのささげ物によって、永遠に全うされたのです。</span>
<span className="v" id="v15" data-v="15" data-xref="ヘブル人への手紙 3:7; ヨハネの黙示録 2:11; ヨハネの黙示録 3:6"> 聖霊も私たちに次のように言って、あかしされます。</span>
<span className="v" id="v16" data-v="16" data-xref="Jeremiah 31:33–34; ヘブル人への手紙 8:8–12; ローマ人への手紙 11:27"> 「それらの日の後、わたしが、 彼らと結ぼうとしている契約は、これであると、 主は言われる。 わたしは、わたしの律法を彼らの心に置き、 彼らの思いに書きつける。」 またこう言われます。</span>
<span className="v" id="v17" data-v="17" data-xref="Jeremiah 31:34; ヘブル人への手紙 8:12"> 「わたしは、もはや決して彼らの罪と不法とを思い出すことはしない。」</span>
<span className="v" id="v18" data-v="18" data-xref="ヘブル人への手紙 10:2; ヘブル人への手紙 10:14"> これらのことが赦されるところでは、罪のためのささげ物はもはや無用です。</span>
<span className="v" id="v19" data-v="19" data-xref="エペソ人への手紙 2:18; ヘブル人への手紙 9:12; ヘブル人への手紙 4:16"> こういうわけですから、兄弟たち。私たちは、イエスの血によって、大胆にまことの聖所にはいることができるのです。</span>
<span className="v" id="v20" data-v="20" data-xref="ヨハネの福音書 14:6; ヨハネの福音書 10:9; ヘブル人への手紙 9:3"> イエスはご自分の肉体という垂れ幕を通して、私たちのためにこの新しい生ける道を設けてくださったのです。</span>
<span className="v" id="v21" data-v="21" data-xref="ヘブル人への手紙 2:17; ヘブル人への手紙 4:14–16; ヘブル人への手紙 8:1"> また、私たちには、神の家をつかさどる、この偉大な祭司があります。</span>
<span className="v" id="v22" data-v="22" data-xref="Ezekiel 36:25; ヨハネの福音書 3:5; エペソ人への手紙 5:26"> そのようなわけで、私たちは、心に血の注ぎを受けて邪悪な良心をきよめられ、からだをきよい水で洗われたのですから、全き信仰をもって、真心から神に近づこうではありませんか。</span>
<span className="v" id="v23" data-v="23" data-xref="テサロニケ人への手紙第一 5:24; コリント人への手紙第一 1:9; テサロニケ人への手紙第二 3:3"> 約束された方は真実な方ですから、私たちは動揺しないで、しっかりと希望を告白しようではありませんか。</span>
<span className="v" id="v24" data-v="24" data-xref="テサロニケ人への手紙第一 5:11; ヨハネの手紙第一 3:18; ヘブル人への手紙 13:1"> また、互いに勧め合って、愛と善行を促すように注意し合おうではありませんか。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒の働き 2:42; テサロニケ人への手紙第一 5:11; マタイの福音書 18:20"> ある人々のように、いっしょに集まることをやめたりしないで、かえって励まし合い、かの日が近づいているのを見て、ますますそうしようではありませんか。</span>
<span className="v" id="v26" data-v="26" data-xref="ペテロの手紙第二 2:20–22; ヘブル人への手紙 6:4–6; ヨハネの福音書 9:41"> もし私たちが、真理の知識を受けて後、ことさらに罪を犯し続けるならば、罪のためのいけにえは、もはや残されていません。</span>
<span className="v" id="v27" data-v="27" data-xref="Isaiah 26:11; ヘブル人への手紙 2:3; Zephaniah 1:18"> ただ、さばきと、逆らう人たちを焼き尽くす激しい火とを、恐れながら待つよりほかはないのです。</span>
<span className="v" id="v28" data-v="28" data-xref="ヘブル人への手紙 2:2; Deuteronomy 19:15; Deuteronomy 17:2–13"> だれでもモーセの律法を無視する者は、二、三の証人のことばに基づいて、あわれみを受けることなく死刑に処せられます。</span>
<span className="v" id="v29" data-v="29" data-xref="ヘブル人への手紙 6:6; エペソ人への手紙 4:30; Isaiah 63:10"> まして、神の御子を踏みつけ、自分をきよめた契約の血を汚れたものとみなし、恵みの御霊を侮る者は、どんなに重い処罰に値するか、考えてみなさい。</span>
<span className="v" id="v30" data-v="30" data-xref="Deuteronomy 32:35–36; ローマ人への手紙 12:19; Nahum 1:2"> 私たちは、「復讐はわたしのすることである。わたしが報いをする。」、また、「主がその民をさばかれる。」と言われる方を知っています。</span>
<span className="v" id="v31" data-v="31" data-xref="マタイの福音書 10:28; ルカの福音書 12:5; ヘブル人への手紙 12:29"> 生ける神の手の中に陥ることは恐ろしいことです。</span>
<span className="v" id="v32" data-v="32" data-xref="ヘブル人への手紙 6:4; ヘブル人への手紙 12:4; テモテへの手紙第二 2:3–13"> あなたがたは、光に照らされて後、苦難に会いながら激しい戦いに耐えた初めのころを、思い起こしなさい。</span>
<span className="v" id="v33" data-v="33" data-xref="コリント人への手紙第一 4:9; ピリピ人への手紙 4:14; ヘブル人への手紙 11:36"> 人々の目の前で、そしりと苦しみとを受けた者もあれば、このようなめに会った人々の仲間になった者もありました。</span>
<span className="v" id="v34" data-v="34" data-xref="ペテロの手紙第一 1:4; テモテへの手紙第二 1:16; マタイの福音書 5:11–12"> あなたがたは、捕えられている人々を思いやり、また、もっとすぐれた、いつまでも残る財産を持っていることを知っていたので、自分の財産が奪われても、喜んで忍びました。</span>
<span className="v" id="v35" data-v="35" data-xref="コリント人への手紙第一 15:58; ガラテヤ人への手紙 6:8–10; ヘブル人への手紙 3:6"> ですから、あなたがたの確信を投げ捨ててはなりません。それは大きな報いをもたらすものなのです。</span>
<span className="v" id="v36" data-v="36" data-xref="ヘブル人への手紙 12:1; Psalms 37:7; ヤコブの手紙 5:7–11"> あなたがたが神のみこころを行なって、約束のものを手に入れるために必要なのは忍耐です。</span>
<span className="v" id="v37" data-v="37" data-xref="ヤコブの手紙 5:7–9; Habakkuk 2:3–4; ルカの福音書 18:8"> 「もうしばらくすれば、 来るべき方が来られる。おそくなることはない。</span>
<span className="v" id="v38" data-v="38" data-xref="ガラテヤ人への手紙 3:11; Habakkuk 2:4; ローマ人への手紙 1:17"> わたしの義人は信仰によって生きる。 もし、恐れ退くなら、 わたしのこころは彼を喜ばない。」</span>
<span className="v" id="v39" data-v="39" data-xref="ヨハネの手紙第一 5:5; ペテロの手紙第一 1:5; マルコの福音書 16:16"> 私たちは、恐れ退いて滅びる者ではなく、信じていのちを保つ者です。</span>

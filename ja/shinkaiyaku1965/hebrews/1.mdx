<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ペテロの手紙第二 1:20–21; Joel 2:28; Numbers 12:6–8"> 神は、むかし先祖たちに、預言者たちを通して、多くの部分に分け、また、いろいろな方法で語られましたが、</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネの福音書 1:3; コリント人への手紙第一 8:6; コロサイ人への手紙 1:16–18"> この終わりの時には、御子によって、私たちに語られました。神は、御子を万物の相続者とし、また御子によって世界を造られました。</span>
<span className="v" id="v3" data-v="3" data-xref="コロサイ人への手紙 1:15–17; ヨハネの黙示録 4:11; ヨハネの福音書 14:9–10"> 御子は神の栄光の輝き、また神の本質の完全な現われであり、その力あるみことばによって万物を保っておられます。また、罪のきよめを成し遂げて、すぐれて高い所の大能者の右の座に着かれました。</span>
<span className="v" id="v4" data-v="4" data-xref="エペソ人への手紙 1:21; ピリピ人への手紙 2:9–11; ペテロの手紙第一 3:22"> 御子は、御使いたちよりもさらにすぐれた御名を相続されたように、それだけ御使いよりもまさるものとなられました。</span>
<span className="v" id="v5" data-v="5" data-xref="Psalms 2:7; 使徒の働き 13:33; ヘブル人への手紙 5:5"> 神は、かつてどの御使いに向かって、こう言われたでしょう。 「あなたは、わたしの子。 きょう、わたしがあなたを生んだ。」 またさらに、 「わたしは彼の父となり、 彼はわたしの子となる。」</span>
<span className="v" id="v6" data-v="6" data-xref="Psalms 97:7; コロサイ人への手紙 1:18; Deuteronomy 32:43"> さらに、長子をこの世界にお送りになるとき、こう言われました。 「神の御使いはみな、彼を拝め。」</span>
<span className="v" id="v7" data-v="7" data-xref="Psalms 104:4; ヘブル人への手紙 1:14; 2 Kings 6:17"> また御使いについては、 「神は、御使いたちを風とし、 仕える者たちを炎とされる。」 と言われましたが、</span>
<span className="v" id="v8" data-v="8" data-xref="Psalms 45:6–7; Isaiah 9:6–7; Jeremiah 23:5–6"> 御子については、こう言われます。 「神よ。あなたの御座は世々限りなく、 あなたの御国の杖こそ、まっすぐな杖です。</span>
<span className="v" id="v9" data-v="9" data-xref="Psalms 45:7; Psalms 23:5; Isaiah 61:3"> あなたは義を愛し、不正を憎まれます。 それゆえ、神よ。あなたの神は、 あふれるばかりの喜びの油を、 あなたとともに立つ者にまして、 あなたに注ぎなさいました。」</span>
<span className="v" id="v10" data-v="10" data-xref="Psalms 102:25–27; Genesis 1:1; ヨハネの福音書 1:1–3"> またこう言われます。 「主よ。あなたは、初めに 地の基を据えられました。 天も、あなたの御手のわざです。</span>
<span className="v" id="v11" data-v="11" data-xref="Isaiah 51:6; マルコの福音書 13:31; ルカの福音書 21:33"> これらのものは滅びます。 しかし、あなたはいつまでもながらえられます。 すべてのものは着物のように古びます。</span>
<span className="v" id="v12" data-v="12" data-xref="Psalms 102:26–27; ヘブル人への手紙 13:8; ヨハネの福音書 8:58"> あなたはこれらを、外套のように巻かれます。 これらを、着物のように取り替えられます。 しかし、あなたは変わることがなく、 あなたの年は尽きることがありません。」</span>
<span className="v" id="v13" data-v="13" data-xref="Psalms 110:1; マルコの福音書 12:36; マタイの福音書 22:44"> 神は、かつてどの御使いに向かって、こう言われたでしょう。 「わたしがあなたの敵を あなたの足台とするまでは、 わたしの右の座に着いていなさい。」</span>
<span className="v" id="v14" data-v="14" data-xref="Psalms 34:7; Psalms 103:20–21; Psalms 91:11–12"> 御使いはみな、仕える霊であって、救いの相続者となる人々に仕えるため遣わされたのではありませんか。</span>

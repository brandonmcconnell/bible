<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="エペソ人への手紙 4:31; ヤコブの手紙 1:21; ヤコブの手紙 4:11"> ですから、あなたがたは、すべての悪意、すべてのごまかし、いろいろな偽善やねたみ、すべての悪口を捨てて、</span>
<span className="v" id="v2" data-v="2" data-xref="ヘブル人への手紙 5:12–13; エペソ人への手紙 4:15; ペテロの手紙第二 3:18"> 生まれたばかりの乳飲み子のように、純粋な、みことばの乳を慕い求めなさい。それによって成長し、救いを得るためです。</span>
<span className="v" id="v3" data-v="3" data-xref="Psalms 34:8; ヘブル人への手紙 6:5–6; Psalms 63:5"> あなたがたはすでに、主がいつくしみ深い方であることを味わっているのです。</span>
<span className="v" id="v4" data-v="4" data-xref="Psalms 118:22–23; 使徒の働き 4:11–12; ペテロの手紙第一 2:7"> 主のもとに来なさい。主は、人には捨てられたが、神の目には、選ばれた、尊い、生ける石です。</span>
<span className="v" id="v5" data-v="5" data-xref="エペソ人への手紙 2:20–22; ペテロの手紙第一 2:9; コリント人への手紙第一 3:9"> あなたがたも生ける石として、霊の家に築き上げられなさい。そして、きよい祭司として、イエス・キリストを通して、神に喜ばれる霊のいけにえをささげなさい。</span>
<span className="v" id="v6" data-v="6" data-xref="Isaiah 28:16; ローマ人への手紙 9:32–33; ペテロの手紙第一 2:4"> なぜなら、聖書にこうあるからです。<br />「見よ。わたしはシオンに、選ばれた石、<br />尊い礎石を置く。<br />彼に信頼する者は、<br />決して失望させられることがない。」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="Psalms 118:22–23; マルコの福音書 12:10–11; 使徒の働き 4:11–12"> したがって、より頼んでいるあなたがたには尊いものですが、より頼んでいない人々にとっては、「家を建てる者たちが捨てた石、それが礎の石となった。」のであって、</span>
<span className="v" id="v8" data-v="8" data-xref="Isaiah 8:14; コリント人への手紙第一 1:23; ローマ人への手紙 9:32–33"> 「つまずきの石、妨げの岩。」なのです。彼らがつまずくのは、みことばに従わないからですが、またそうなるように定められていたのです。</span>
<span className="v" id="v9" data-v="9" data-xref="Exodus 19:5–6; Deuteronomy 7:6; ヨハネの黙示録 1:6"> しかし、あなたがたは、選ばれた種族、王である祭司、きよい国民、神の所有とされた民です。それは、あなたがたを、やみの中から、ご自分の驚くべき光の中に招いてくださった方のすばらしいみわざを、あなたがたが宣べ伝えるためなのです。</span>
<span className="v" id="v10" data-v="10" data-xref="Hosea 2:23; ヘブル人への手紙 4:16; Hosea 1:9–10"> あなたがたは、以前は神の民ではなかったのに、今は神の民であり、以前はあわれみを受けない者であったのに、今はあわれみを受けた者です。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="ヨハネの手紙第一 2:15–17; ガラテヤ人への手紙 5:24; ペテロの手紙第一 4:2"> 愛する者たちよ。あなたがたにお勧めします。旅人であり寄留者であるあなたがたは、たましいに戦いをいどむ肉の欲を遠ざけなさい。</span>
<span className="v" id="v12" data-v="12" data-xref="ペテロの手紙第一 3:16; マタイの福音書 5:16; テトスへの手紙 2:7–8"> 異邦人の中にあって、りっぱにふるまいなさい。そうすれば、彼らは、何かのことであなたがたを悪人呼ばわりしていても、あなたがたのそのりっぱな行ないを見て、おとずれの日に神をほめたたえるようになります。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="テトスへの手紙 3:1; ローマ人への手紙 13:1–7; テモテへの手紙第一 2:1–2"> 人の立てたすべての制度に、主のゆえに従いなさい。それが主権者である王であっても、</span>
<span className="v" id="v14" data-v="14" data-xref="ローマ人への手紙 13:3–4"> また、悪を行なう者を罰し、善を行なう者をほめるように王から遣わされた総督であっても、そうしなさい。</span>
<span className="v" id="v15" data-v="15" data-xref="ペテロの手紙第一 3:17; テトスへの手紙 2:8; マタイの福音書 7:26"> というのは、善を行なって、愚かな人々の無知の口を封じることは、神のみこころだからです。</span>
<span className="v" id="v16" data-v="16" data-xref="ガラテヤ人への手紙 5:13; ローマ人への手紙 6:22; ローマ人への手紙 6:18"> あなたがたは自由人として行動しなさい。その自由を、悪の口実に用いないで、神の奴隷として用いなさい。</span>
<span className="v" id="v17" data-v="17" data-xref="Proverbs 24:21; ローマ人への手紙 12:10; ローマ人への手紙 13:7"> すべての人を敬いなさい。兄弟たちを愛し、神を恐れ、王を尊びなさい。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="テトスへの手紙 2:9–10; エペソ人への手紙 6:5–7; コロサイ人への手紙 3:22–25"> しもべたちよ。尊敬の心を込めて主人に服従しなさい。善良で優しい主人に対してだけでなく、横暴な主人に対しても従いなさい。</span>
<span className="v" id="v19" data-v="19" data-xref="マタイの福音書 5:10–12; ペテロの手紙第一 3:14–17; ペテロの手紙第一 2:20"> 人がもし、不当な苦しみを受けながらも、神の前における良心のゆえに、悲しみをこらえるなら、それは喜ばれることです。</span>
<span className="v" id="v20" data-v="20" data-xref="ペテロの手紙第一 2:19; ペテロの手紙第一 3:17; マタイの福音書 5:10–12"> 罪を犯したために打ちたたかれて、それを耐え忍んだからといって、何の誉れになるでしょう。けれども、善を行なっていて苦しみを受け、それを耐え忍ぶとしたら、それは、神に喜ばれることです。</span>
<span className="v" id="v21" data-v="21" data-xref="ヨハネの手紙第一 2:6; マタイの福音書 16:24; ヨハネの福音書 13:15"> あなたがたが召されたのは、実にそのためです。キリストも、あなたがたのために苦しみを受け、その足跡に従うようにと、あなたがたに模範を残されました。</span>
<span className="v" id="v22" data-v="22" data-xref="Isaiah 53:9; コリント人への手紙第二 5:21; ヘブル人への手紙 4:15"> キリストは罪を犯したことがなく、その口に何の偽りも見いだされませんでした。</span>
<span className="v" id="v23" data-v="23" data-xref="Isaiah 53:7; ペテロの手紙第一 4:19; ヘブル人への手紙 12:3"> ののしられても、ののしり返さず、苦しめられても、おどすことをせず、正しくさばかれる方にお任せになりました。</span>
<span className="v" id="v24" data-v="24" data-xref="Isaiah 53:4–6; マタイの福音書 8:17; ローマ人への手紙 6:11"> そして自分から十字架の上で、私たちの罪をその身に負われました。それは、私たちが罪を離れ、義のために生きるためです。キリストの打ち傷のゆえに、あなたがたは、いやされたのです。</span>
<span className="v" id="v25" data-v="25" data-xref="Isaiah 53:6; Ezekiel 34:6; ルカの福音書 15:4–6"> あなたがたは、羊のようにさまよっていましたが、今は、自分のたましいの牧者であり監督者である方のもとに帰ったのです。</span>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ガラテヤ人への手紙 5:24; ペテロの手紙第一 3:18; コロサイ人への手紙 3:3–5"> このように、キリストは肉体において苦しみを受けられたのですから、あなたがたも同じ心構えで自分自身を武装しなさい。肉体において苦しみを受けた人は、罪とのかかわりを断ちました。</span>
<span className="v" id="v2" data-v="2" data-xref="エペソ人への手紙 4:22–24; ペテロの手紙第一 1:14; テトスへの手紙 3:3–8"> こうしてあなたがたは、地上の残された時を、もはや人間の欲望のためではなく、神のみこころのために過ごすようになるのです。</span>
<span className="v" id="v3" data-v="3" data-xref="コリント人への手紙第一 6:11; エペソ人への手紙 5:18; テサロニケ人への手紙第一 4:5"> あなたがたは、異邦人たちがしたいと思っていることを行ない、好色、情欲、酔酒、遊興、宴会騒ぎ、忌むべき偶像礼拝などにふけったものですが、それは過ぎ去った時で、もう十分です。</span>
<span className="v" id="v4" data-v="4" data-xref="ペテロの手紙第一 3:16; ペテロの手紙第一 2:12; ユダの手紙 1:10"> 彼らは、あなたがたが自分たちといっしょに度を過ごした放蕩に走らないので不思議に思い、また悪口を言います。</span>
<span className="v" id="v5" data-v="5" data-xref="ヤコブの手紙 5:9; 使徒の働き 10:42; テモテへの手紙第二 4:1"> 彼らは、生きている人々をも死んだ人々をも、すぐにもさばこうとしている方に対し、申し開きをしなければなりません。</span>
<span className="v" id="v6" data-v="6" data-xref="ローマ人への手紙 8:2; ペテロの手紙第一 3:19; ローマ人への手紙 8:9–11"> というのは、死んだ人々にも福音が宣べ伝えられていたのですが、それはその人々が肉体においては人間としてさばきを受けるが、霊においては神によって生きるためでした。</span>
<span className="v" id="v7" data-v="7" data-xref="ヤコブの手紙 5:8–9; ペテロの手紙第一 1:13; ペテロの手紙第一 5:8"> 万物の終わりが近づきました。ですから、祈りのために、心を整え身を慎みなさい。</span>
<span className="v" id="v8" data-v="8" data-xref="Proverbs 10:12; コロサイ人への手紙 3:14; Proverbs 17:9"> 何よりもまず、互いに熱心に愛し合いなさい。愛は多くの罪をおおうからです。</span>
<span className="v" id="v9" data-v="9" data-xref="ヘブル人への手紙 13:2; ローマ人への手紙 12:13; ピリピ人への手紙 2:14"> つぶやかないで、互いに親切にもてなし合いなさい。</span>
<span className="v" id="v10" data-v="10" data-xref="ローマ人への手紙 12:6–8; コリント人への手紙第一 12:4–11; コリント人への手紙第一 4:1–2"> それぞれが賜物を受けているのですから、神のさまざまな恵みの良い管理者として、その賜物を用いて、互いに仕え合いなさい。</span>
<span className="v" id="v11" data-v="11" data-xref="コリント人への手紙第一 10:31; エペソ人への手紙 6:10; ペテロの手紙第一 4:10"> 語る人があれば、神のことばにふさわしく語り、奉仕する人があれば、神が豊かに備えてくださる力によって、それにふさわしく奉仕しなさい。それは、すべてのことにおいて、イエス・キリストを通して神があがめられるためです。栄光と支配が世々限りなくキリストにありますように。アーメン。</span>
<span className="v" id="v12" data-v="12" data-xref="テモテへの手紙第二 3:12; ペテロの手紙第一 1:6–7; ペテロの手紙第一 5:9"> 愛する者たち。あなたがたを試みるためにあなたがたの間に燃えさかる火の試練を、何か思いがけないことが起こったかのように驚き怪しむことなく、</span>
<span className="v" id="v13" data-v="13" data-xref="ローマ人への手紙 8:17; ヤコブの手紙 1:2–3; ローマ人への手紙 5:3"> むしろ、キリストの苦しみにあずかれるのですから、喜んでいなさい。それは、キリストの栄光が現われるときにも、喜びおどる者となるためです。</span>
<span className="v" id="v14" data-v="14" data-xref="ペテロの手紙第一 3:14; ルカの福音書 6:22; マタイの福音書 5:11"> もしキリストの名のために非難を受けるなら、あなたがたは幸いです。なぜなら、栄光の御霊、すなわち神の御霊が、あなたがたの上にとどまってくださるからです。</span>
<span className="v" id="v15" data-v="15" data-xref="テサロニケ人への手紙第二 3:11; テサロニケ人への手紙第一 4:11; テモテへの手紙第一 5:13"> あなたがたのうちのだれも、人殺し、盗人、悪を行なう者、みだりに他人に干渉する者として苦しみを受けるようなことがあってはなりません。</span>
<span className="v" id="v16" data-v="16" data-xref="ペテロの手紙第一 3:17–18; ピリピ人への手紙 1:29; ペテロの手紙第一 4:19"> しかし、キリスト者として苦しみを受けるのなら、恥じることはありません。かえって、この名のゆえに神をあがめなさい。</span>
<span className="v" id="v17" data-v="17" data-xref="Jeremiah 25:29; テサロニケ人への手紙第二 1:8; ローマ人への手紙 2:9"> なぜなら、さばきが神の家から始まる時が来ているからです。さばきが、まず私たちから始まるのだとしたら、神の福音に従わない人たちの終わりは、どうなることでしょう。</span>
<span className="v" id="v18" data-v="18" data-xref="Proverbs 11:31; Ezekiel 18:24; ルカの福音書 23:31"> 義人がかろうじて救われるのだとしたら、神を敬わない者や罪人たちは、いったいどうなるのでしょう。</span>
<span className="v" id="v19" data-v="19" data-xref="Psalms 37:5; テモテへの手紙第二 1:12; ペテロの手紙第一 3:17"> ですから、神のみこころに従ってなお苦しみに会っている人々は、善を行なうにあたって、真実であられる創造者に自分のたましいをお任せしなさい。</span>

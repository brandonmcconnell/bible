<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヤコブの手紙 1:1; 使徒の働き 2:5–11; ヘブル人への手紙 11:13"> イエス・キリストの使徒ペテロから、ポント、ガラテヤ、カパドキヤ、アジヤ、ビテニヤに散って寄留している、選ばれた人々、すなわち、</span>
<span className="v" id="v2" data-v="2" data-xref="テサロニケ人への手紙第二 2:13; エペソ人への手紙 1:4–5; ヘブル人への手紙 12:24"> 父なる神の予知に従い、御霊のきよめによって、イエス・キリストに従うように、またその血の注ぎかけを受けるように選ばれた人々へ。どうか、恵みと平安が、あなたがたの上にますます豊かにされますように。</span>
<span className="v" id="v3" data-v="3" data-xref="ペテロの手紙第一 1:23; ヨハネの手紙第一 5:4; ローマ人への手紙 15:13"> 私たちの主イエス・キリストの父なる神がほめたたえられますように。神は、ご自分の大きなあわれみのゆえに、イエス・キリストが死者の中からよみがえられたことによって、私たちを新しく生まれさせて、生ける望みを持つようにしてくださいました。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネの黙示録 21:27; ヘブル人への手紙 9:15; ペテロの手紙第一 5:4"> また、朽ちることも汚れることも、消えて行くこともない資産を受け継ぐようにしてくださいました。これはあなたがたのために、天にたくわえられているのです。</span>
<span className="v" id="v5" data-v="5" data-xref="ピリピ人への手紙 1:6; エペソ人への手紙 2:8; テサロニケ人への手紙第二 2:13–14"> あなたがたは、信仰により、神の御力によって守られており、終わりのときに現わされるように用意されている救いをいただくのです。</span>
<span className="v" id="v6" data-v="6" data-xref="ヤコブの手紙 1:2; ペテロの手紙第一 5:10; ローマ人への手紙 12:12"> そういうわけで、あなたがたは大いに喜んでいます。ただ、いましばらくの間は、やむをえず、さまざまの試練のために、悩まされていますが、</span>
<span className="v" id="v7" data-v="7" data-xref="Job 23:10; Isaiah 48:10; ペテロの手紙第一 4:12"> 信仰の試練は、火を通して精練されてもなお朽ちて行く金よりも尊いのであって、イエス・キリストの現われのときに称賛と光栄と栄誉に至るものであることがわかります。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨハネの福音書 20:29; コリント人への手紙第二 5:7; ローマ人への手紙 15:13"> あなたがたはイエス・キリストを見たことはないけれども愛しており、いま見てはいないけれども信じており、ことばに尽くすことのできない、栄えに満ちた喜びにおどっています。</span>
<span className="v" id="v9" data-v="9" data-xref="ローマ人への手紙 6:22; ヤコブの手紙 1:21; ヘブル人への手紙 11:13"> これは、信仰の結果である、たましいの救いを得ているからです。</span>
<span className="v" id="v10" data-v="10" data-xref="マタイの福音書 13:17; ルカの福音書 10:24; ルカの福音書 24:25–27"> この救いについては、あなたがたに対する恵みについて預言した預言者たちも、熱心に尋ね、細かく調べました。</span>
<span className="v" id="v11" data-v="11" data-xref="Isaiah 52:13–14; ペテロの手紙第二 1:21; ルカの福音書 24:25–27"> 彼らは、自分たちのうちにおられるキリストの御霊が、キリストの苦難とそれに続く栄光を前もってあかしされたとき、だれを、また、どのような時をさして言われたのかを調べたのです。</span>
<span className="v" id="v12" data-v="12" data-xref="ヨハネの福音書 15:26; コリント人への手紙第一 2:10; エペソ人への手紙 3:10"> 彼らは、それらのことが、自分たちのためではなく、あなたがたのための奉仕であるとの啓示を受けました。そして今や、それらのことは、天から送られた聖霊によってあなたがたに福音を語った人々を通して、あなたがたに告げ知らされたのです。それは御使いたちもはっきり見たいと願っていることなのです。</span>
<span className="v" id="v13" data-v="13" data-xref="ペテロの手紙第一 5:8; ルカの福音書 12:35; ペテロの手紙第一 4:7"> ですから、あなたがたは、心を引き締め、身を慎み、イエス・キリストの現われのときあなたがたにもたらされる恵みを、ひたすら待ち望みなさい。</span>
<span className="v" id="v14" data-v="14" data-xref="ローマ人への手紙 12:2; テトスへの手紙 3:3–5; ペテロの手紙第一 4:2–3"> 従順な子どもとなり、以前あなたがたが無知であったときのさまざまな欲望に従わず、</span>
<span className="v" id="v15" data-v="15" data-xref="マタイの福音書 5:48; コリント人への手紙第二 7:1; ヘブル人への手紙 12:14"> あなたがたを召してくださった聖なる方にならって、あなたがた自身も、あらゆる行ないにおいてきよくなりなさい。</span>
<span className="v" id="v16" data-v="16" data-xref="Leviticus 11:44; Leviticus 19:2; Leviticus 20:7"> それは、「わたしが聖であるから、あなたがたも、聖でなければならない。」と書いてあるからです。</span>
<span className="v" id="v17" data-v="17" data-xref="使徒の働き 10:34–35; 2 Chronicles 19:7; マタイの福音書 6:9"> また、人をそれぞれのわざに従って公平にさばかれる方を父と呼んでいるのなら、あなたがたが地上にしばらくとどまっている間の時を、恐れかしこんで過ごしなさい。</span>
<span className="v" id="v18" data-v="18" data-xref="コリント人への手紙第一 6:20; テトスへの手紙 2:14; Psalms 49:7–8"> ご承知のように、あなたがたが先祖から伝わったむなしい生き方から贖い出されたのは、銀や金のような朽ちる物にはよらず、</span>
<span className="v" id="v19" data-v="19" data-xref="ヨハネの手紙第一 1:7; ペテロの手紙第一 2:22–24; ヨハネの福音書 1:29"> 傷もなく汚れもない小羊のようなキリストの、尊い血によったのです。</span>
<span className="v" id="v20" data-v="20" data-xref="エペソ人への手紙 1:4; テモテへの手紙第二 1:9–10; ヘブル人への手紙 9:26"> キリストは、世の始まる前から知られていましたが、この終わりの時に、あなたがたのために、現われてくださいました。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒の働き 2:24; ヘブル人への手紙 2:9; ヨハネの福音書 12:44"> あなたがたは、死者の中からこのキリストをよみがえらせて彼に栄光を与えられた神を、キリストによって信じる人々です。このようにして、あなたがたの信仰と希望は神にかかっているのです。</span>
<span className="v" id="v22" data-v="22" data-xref="テモテへの手紙第一 1:5; ヘブル人への手紙 13:1; ローマ人への手紙 12:9–10"> あなたがたは、真理に従うことによって、たましいをきよめ、偽りのない兄弟愛を抱くようになったのですから、互いに心から熱く愛し合いなさい。</span>
<span className="v" id="v23" data-v="23" data-xref="ペテロの手紙第一 1:3; ヘブル人への手紙 4:12; ヨハネの福音書 1:13"> あなたがたが新しく生まれたのは、朽ちる種からではなく、朽ちない種からであり、生ける、いつまでも変わることのない、神のことばによるのです。</span>
<span className="v" id="v24" data-v="24" data-xref="Isaiah 40:6–8; Psalms 103:15; ヤコブの手紙 4:14"> 「人はみな草のようで、 その栄えは、みな草の花のようだ。 草はしおれ、 花は散る。</span>
<span className="v" id="v25" data-v="25" data-xref="Isaiah 40:8; マタイの福音書 5:18; Psalms 119:89"> しかし、主のことばは、 とこしえに変わることがない。」 とあるからです。あなたがたに宣べ伝えられた福音のことばがこれです。</span>

<span className="v" id="v1" data-v="1" data-xref="コロサイ人への手紙 3:18; エペソ人への手紙 5:33; エペソ人への手紙 5:22–24"> 同じように、妻たちよ。自分の夫に服従しなさい。たとい、みことばに従わない夫であっても、妻の無言のふるまいによって、神のものとされるようになるためです。</span>
<span className="v" id="v2" data-v="2" data-xref="ペテロの手紙第一 2:12; ペテロの手紙第一 1:15; ピリピ人への手紙 1:27"> それは、あなたがたの、神を恐れかしこむ清い生き方を彼らが見るからです。</span>
<span className="v" id="v3" data-v="3" data-xref="テモテへの手紙第一 2:9–10; ローマ人への手紙 12:2; Isaiah 3:18–24"> あなたがたは、髪を編んだり、金の飾りをつけたり、着物を着飾るような外面的なものでなく、</span>
<span className="v" id="v4" data-v="4" data-xref="コロサイ人への手紙 3:12; 1 Samuel 16:7; ローマ人への手紙 2:29"> むしろ、柔和で穏やかな霊という朽ちることのないものを持つ、心の中の隠れた人がらを飾りにしなさい。これこそ、神の御前に価値あるものです。</span>
<span className="v" id="v5" data-v="5" data-xref="テトスへの手紙 2:3–4; テモテへの手紙第一 5:5; ルカの福音書 2:37"> むかし神に望みを置いた敬虔な婦人たちも、このように自分を飾って、夫に従ったのです。</span>
<span className="v" id="v6" data-v="6" data-xref="Genesis 18:12; ローマ人への手紙 9:7–9; Isaiah 57:11"> たとえばサラも、アブラハムを主と呼んで彼に従いました。あなたがたも、どんなことをも恐れないで善を行なえば、サラの子となるのです。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="コロサイ人への手紙 3:19; Genesis 2:23–24; マタイの福音書 19:3–9"> 同じように、夫たちよ。妻が女性であって、自分よりも弱い器だということをわきまえて妻とともに生活し、いのちの恵みをともに受け継ぐ者として尊敬しなさい。それは、あなたがたの祈りが妨げられないためです。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="ローマ人への手紙 12:10; エペソ人への手紙 4:31–2; ペテロの手紙第一 1:22"> 最後に申します。あなたがたはみな、心を一つにし、同情し合い、兄弟愛を示し、あわれみ深く、謙遜でありなさい。</span>
<span className="v" id="v9" data-v="9" data-xref="Proverbs 20:22; ローマ人への手紙 12:17; ローマ人への手紙 12:14"> 悪をもって悪に報いず、侮辱をもって侮辱に報いず、かえって祝福を与えなさい。あなたがたは祝福を受け継ぐために召されたのだからです。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="Psalms 34:12–16; ヤコブの手紙 1:26; ペテロの手紙第一 2:1"> 「いのちを愛し、<br />幸いな日々を過ごしたいと思う者は、<br />舌を押えて悪を言わず、<br />くちびるを閉ざして偽りを語らず、</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="マタイの福音書 5:9; Psalms 34:14; ヘブル人への手紙 12:14"> 悪から遠ざかって善を行ない、<br />平和を求めてこれを追い求めよ。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="Psalms 34:15–16; ヨハネの福音書 9:31; Proverbs 15:29"> 主の目は義人の上に注がれ、<br />主の耳は彼らの祈りに傾けられる。<br />しかし主の顔は、<br />悪を行なう者に立ち向かう。」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="Proverbs 16:7; ローマ人への手紙 8:28; テサロニケ人への手紙第一 5:15"> もし、あなたがたが善に熱心であるなら、だれがあなたがたに害を加えるでしょう。</span>
<span className="v" id="v14" data-v="14" data-xref="マタイの福音書 10:28; ペテロの手紙第一 2:19–20; マタイの福音書 5:10–12"> いや、たとい義のために苦しむことがあるにしても、それは幸いなことです。彼らの脅かしを恐れたり、それによって心を動揺させたりしてはいけません。</span>
<span className="v" id="v15" data-v="15" data-xref="コロサイ人への手紙 4:6; テモテへの手紙第二 2:25–26; ルカの福音書 21:14–15"> むしろ、心の中でキリストを主としてあがめなさい。そして、あなたがたのうちにある希望について説明を求める人には、だれにでもいつでも弁明できる用意をしていなさい。</span>
<span className="v" id="v16" data-v="16" data-xref="ペテロの手紙第一 2:12; ヘブル人への手紙 13:18; ペテロの手紙第一 2:15"> ただし、優しく、慎み恐れて、また、正しい良心をもって弁明しなさい。そうすれば、キリストにあるあなたがたの正しい生き方をののしる人たちが、あなたがたをそしったことで恥じ入るでしょう。</span>
<span className="v" id="v17" data-v="17" data-xref="ペテロの手紙第一 3:14; ペテロの手紙第一 4:19; マタイの福音書 26:39"> もし、神のみこころなら、善を行なって苦しみを受けるのが、悪を行なって苦しみを受けるよりよいのです。</span>
<span className="v" id="v18" data-v="18" data-xref="ヘブル人への手紙 9:28; ヘブル人への手紙 9:26; コリント人への手紙第二 5:21"> キリストも一度罪のために死なれました。正しい方が悪い人々の身代わりとなったのです。それは、肉においては死に渡され、霊においては生かされて、私たちを神のみもとに導くためでした。</span>
<span className="v" id="v19" data-v="19" data-xref="ペテロの手紙第一 4:6; Isaiah 61:1; Isaiah 42:7"> その霊において、キリストは捕われの霊たちのところに行ってみことばを宣べられたのです。</span>
<span className="v" id="v20" data-v="20" data-xref="ヘブル人への手紙 11:7; ペテロの手紙第二 2:5; Genesis 6:3"> 昔、ノアの時代に、箱舟が造られていた間、神が忍耐して待っておられたときに、従わなかった霊たちのことです。わずか八人の人々が、この箱舟の中で、水を通って救われたのです。</span>
<span className="v" id="v21" data-v="21" data-xref="マルコの福音書 16:16; Ezekiel 36:25–26; 使徒の働き 2:38"> そのことは、今あなたがたを救うバプテスマをあらかじめ示した型なのです。バプテスマは肉体の汚れを取り除くものではなく、正しい良心の神への誓いであり、イエス・キリストの復活によるものです。</span>
<span className="v" id="v22" data-v="22" data-xref="ヘブル人への手紙 9:24; ヘブル人への手紙 12:2; ヘブル人への手紙 10:12"> キリストは天に上り、御使いたち、および、もろもろの権威と権力を従えて、神の右の座におられます。</span>

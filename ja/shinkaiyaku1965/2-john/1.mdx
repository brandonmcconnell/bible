<span className="v" id="v1" data-v="1" data-xref="テモテへの手紙第一 2:4; ヨハネの手紙第一 3:18; ヨハネの福音書 8:32"> 長老から、選ばれた夫人とその子どもたちへ。私はあなたがたをほんとうに愛しています。私だけでなく、真理を知っている人々がみな、そうです。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネの手紙第一 2:14; ヨハネの手紙第一 1:8; ヨハネの手紙第一 2:17"> このことは、私たちのうちに宿る真理によることです。そして真理はいつまでも私たちとともにあります。</span>
<span className="v" id="v3" data-v="3" data-xref="ヨハネの手紙第一 4:10; ローマ人への手紙 1:7; テモテへの手紙第一 1:14"> 真理と愛のうちに、御父と御父の御子イエス・キリストから来る恵みとあわれみと平安は、私たちとともにあります。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネの手紙第三 1:3–4; エペソ人への手紙 5:8; エペソ人への手紙 5:2"> あなたの子どもたちの中に、御父から私たちが受けた命令のとおりに真理のうちを歩んでいる人たちがあるのを知って、私は非常に喜んでいます。</span>
<span className="v" id="v5" data-v="5" data-xref="ヨハネの手紙第一 3:11; ヨハネの福音書 13:34–35; ヨハネの福音書 15:12"> そこで夫人よ。お願いしたいことがあります。それは私が新しい命令を書くのではなく、初めから私たちが持っていたものなのですが、私たちが互いに愛し合うということです。</span>
<span className="v" id="v6" data-v="6" data-xref="ヨハネの手紙第一 5:3; ヨハネの手紙第一 2:24; ヨハネの福音書 15:10"> 愛とは、御父の命令に従って歩むことであり、命令とは、あなたがたが初めから聞いているとおり、愛のうちを歩むことです。</span>
<span className="v" id="v7" data-v="7" data-xref="ヨハネの手紙第一 2:26; ヨハネの手紙第一 4:1–3; ヨハネの手紙第一 2:18–22"> なぜお願いするかと言えば、人を惑わす者、すなわち、イエス・キリストが人として来られたことを告白しない者が大ぜい世に出て行ったからです。こういう者は惑わす者であり、反キリストです。</span>
<span className="v" id="v8" data-v="8" data-xref="ヘブル人への手紙 10:35; ヨハネの黙示録 3:11; コリント人への手紙第一 3:14"> よく気をつけて、私たちの労苦の実をだいなしにすることなく、豊かな報いを受けるようになりなさい。</span>
<span className="v" id="v9" data-v="9" data-xref="ヨハネの福音書 7:16–17; コロサイ人への手紙 3:16; ヨハネの手紙第一 2:22–24"> だれでも行き過ぎをして、キリストの教えのうちにとどまらない者は、神を持っていません。その教えのうちにとどまっている者は、御父をも御子をも持っています。</span>
<span className="v" id="v10" data-v="10" data-xref="テトスへの手紙 3:10; ローマ人への手紙 16:17–18; テサロニケ人への手紙第二 3:6"> あなたがたのところに来る人で、この教えを持って来ない者は、家に受け入れてはいけません。その人にあいさつのことばをかけてもいけません。</span>
<span className="v" id="v11" data-v="11" data-xref="テモテへの手紙第一 5:22; エペソ人への手紙 5:11; ヨハネの黙示録 18:4"> そういう人にあいさつすれば、その悪い行ないをともにすることになります。</span>
<span className="v" id="v12" data-v="12" data-xref="ヨハネの手紙第三 1:13–14; ヨハネの福音書 16:12; コリント人への手紙第一 16:5–7"> あなたがたに書くべきことがたくさんありますが、紙と墨でしたくはありません。あなたがたのところに行って、顔を合わせて語りたいと思います。私たちの喜びが全きものとなるためにです。</span>
<span className="v" id="v13" data-v="13" data-xref="ペテロの手紙第一 5:13; ヨハネの手紙第二 1:1–13"> 選ばれたあなたの姉妹の子どもたちが、あなたによろしくと言っています。</span>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ローマ人への手紙 15:1; コリント人への手紙第一 8:7–13; コリント人への手紙第一 9:22"> あなたがたは信仰の弱い人を受け入れなさい。その意見をさばいてはいけません。</span>
<span className="v" id="v2" data-v="2" data-xref="テモテへの手紙第一 4:4; ローマ人への手紙 14:22–23; ローマ人への手紙 14:14"> 何でも食べてよいと信じている人もいますが、弱い人は野菜よりほかには食べません。</span>
<span className="v" id="v3" data-v="3" data-xref="ローマ人への手紙 14:10; コロサイ人への手紙 2:16–17; ルカの福音書 18:9"> 食べる人は食べない人を侮ってはいけないし、食べない人も食べる人をさばいてはいけません。神がその人を受け入れてくださったからです。</span>
<span className="v" id="v4" data-v="4" data-xref="ヤコブの手紙 4:11–12; ローマ人への手紙 9:20; ローマ人への手紙 8:31–39"> あなたはいったいだれなので、他人のしもべをさばくのですか。しもべが立つのも倒れるのも、その主人の心次第です。このしもべは立つのです。なぜなら、主には、彼を立たせることができるからです。</span>
<span className="v" id="v5" data-v="5" data-xref="コロサイ人への手紙 2:16–17; ローマ人への手紙 14:23; ガラテヤ人への手紙 4:9–10"> ある日を、他の日に比べて、大事だと考える人もいますが、どの日も同じだと考える人もいます。それぞれ自分の心の中で確信を持ちなさい。</span>
<span className="v" id="v6" data-v="6" data-xref="コリント人への手紙第一 10:30–31; テモテへの手紙第一 4:3–5; マタイの福音書 14:19"> 日を守る人は、主のために守っています。食べる人は、主のために食べています。なぜなら、神に感謝しているからです。食べない人も、主のために食べないのであって、神に感謝しているのです。</span>
<span className="v" id="v7" data-v="7" data-xref="ペテロの手紙第一 4:2; コリント人への手紙第二 5:15; コリント人への手紙第一 6:19–20"> 私たちの中でだれひとりとして、自分のために生きている者はなく、また自分のために死ぬ者もありません。</span>
<span className="v" id="v8" data-v="8" data-xref="ピリピ人への手紙 1:20; テサロニケ人への手紙第一 5:10; コリント人への手紙第一 15:23"> もし生きるなら、主のために生き、もし死ぬなら、主のために死ぬのです。ですから、生きるにしても、死ぬにしても、私たちは主のものです。</span>
<span className="v" id="v9" data-v="9" data-xref="ヨハネの黙示録 1:18; ルカの福音書 24:26; ヘブル人への手紙 12:2"> キリストは、死んだ人にとっても、生きている人にとっても、その主となるために、死んで、また生きられたのです。</span>
<span className="v" id="v10" data-v="10" data-xref="コリント人への手紙第二 5:10; コリント人への手紙第一 4:5; Ecclesiastes 12:14"> それなのに、なぜ、あなたは自分の兄弟をさばくのですか。また、自分の兄弟を侮るのですか。私たちはみな、神のさばきの座に立つようになるのです。</span>
<span className="v" id="v11" data-v="11" data-xref="Isaiah 45:22–25; ピリピ人への手紙 2:10–11; Psalms 72:11"> 次のように書かれているからです。<br />「主は言われる。わたしは生きている。<br />すべてのひざは、わたしの前にひざまずき、<br />すべての舌は、神をほめたたえる。」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="ペテロの手紙第一 4:5; マタイの福音書 12:36; マタイの福音書 16:27"> こういうわけですから、私たちは、おのおの自分のことを神の御前に申し開きすることになります。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="コリント人への手紙第二 6:3; ヤコブの手紙 4:11; コリント人への手紙第一 8:9–13"> ですから、私たちは、もはや互いにさばき合うことのないようにしましょう。いや、それ以上に、兄弟にとって妨げになるもの、つまずきになるものを置かないように決心しなさい。</span>
<span className="v" id="v14" data-v="14" data-xref="テトスへの手紙 1:15; ローマ人への手紙 14:2; テモテへの手紙第一 4:4"> 主イエスにあって、私が知り、また確信していることは、それ自体で汚れているものは何一つないということです。ただ、これは汚れていると認める人にとっては、それは汚れたものなのです。</span>
<span className="v" id="v15" data-v="15" data-xref="コリント人への手紙第一 8:11–12; ピリピ人への手紙 2:2–4; ガラテヤ人への手紙 5:13"> もし、食べ物のことで、あなたの兄弟が心を痛めているのなら、あなたはもはや愛によって行動しているのではありません。キリストが代わりに死んでくださったほどの人を、あなたの食べ物のことで、滅ぼさないでください。</span>
<span className="v" id="v16" data-v="16" data-xref="ローマ人への手紙 12:17; テサロニケ人への手紙第一 5:22; コリント人への手紙第一 10:29–30"> ですから、あなたがたが良いとしている事がらによって、そしられないようにしなさい。</span>
<span className="v" id="v17" data-v="17" data-xref="マタイの福音書 6:33; ローマ人への手紙 15:13; コリント人への手紙第一 4:20"> なぜなら、神の国は飲み食いのことではなく、義と平和と聖霊による喜びだからです。</span>
<span className="v" id="v18" data-v="18" data-xref="コリント人への手紙第二 8:21; コリント人への手紙第二 5:11; ペテロの手紙第一 2:20"> このようにキリストに仕える人は、神に喜ばれ、また人々にも認められるのです。</span>
<span className="v" id="v19" data-v="19" data-xref="エペソ人への手紙 4:29; ローマ人への手紙 12:18; Psalms 34:14"> そういうわけですから、私たちは、平和に役立つことと、お互いの霊的成長に役立つこととを追い求めましょう。</span>
<span className="v" id="v20" data-v="20" data-xref="ローマ人への手紙 14:14–15; マタイの福音書 18:6; テトスへの手紙 1:15"> 食べ物のことで神のみわざを破壊してはいけません。すべての物はきよいのです。しかし、それを食べて人につまずきを与えるような人のばあいは、悪いのです。</span>
<span className="v" id="v21" data-v="21" data-xref="コリント人への手紙第一 8:13; ローマ人への手紙 14:13; ローマ人への手紙 15:1–2"> 肉を食べず、ぶどう酒を飲まず、そのほか兄弟のつまずきになることをしないのは良いことなのです。</span>
<span className="v" id="v22" data-v="22" data-xref="ヨハネの手紙第一 3:21; ローマ人への手紙 14:5; ヤコブの手紙 3:13"> あなたの持っている信仰は、神の御前でそれを自分の信仰として保ちなさい。自分が、良いと認めていることによって、さばかれない人は幸福です。</span>
<span className="v" id="v23" data-v="23" data-xref="ヘブル人への手紙 11:6; テトスへの手紙 1:15; コリント人への手紙第一 11:29–31"> しかし、疑いを感じる人が食べるなら、罪に定められます。なぜなら、それが信仰から出ていないからです。信仰から出ていないことは、みな罪です。</span>

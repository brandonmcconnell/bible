<span className="v" id="v1" data-v="1" data-xref="ルカの福音書 6:37; ローマ人への手紙 2:3; ヨハネの福音書 8:7–9"> ですから、すべて他人をさばく人よ。あなたに弁解の余地はありません。あなたは、他人をさばくことによって、自分自身を罪に定めています。さばくあなたが、それと同じことを行なっているからです。</span>
<span className="v" id="v2" data-v="2" data-xref="Psalms 9:7–8; Zephaniah 3:5; Psalms 145:17"> 私たちは、そのようなことを行なっている人々に下る神のさばきが正しいことを知っています。</span>
<span className="v" id="v3" data-v="3" data-xref="Proverbs 16:5; ルカの福音書 12:14; ローマ人への手紙 1:32–1"> そのようなことをしている人々をさばきながら、自分で同じことをしている人よ。あなたは、自分は神のさばきを免れるのだとでも思っているのですか。</span>
<span className="v" id="v4" data-v="4" data-xref="ペテロの手紙第二 3:9; Isaiah 30:18; Exodus 34:6"> それとも、神の慈愛があなたを悔い改めに導くことも知らないで、その豊かな慈愛と忍耐と寛容とを軽んじているのですか。</span>
<span className="v" id="v5" data-v="5" data-xref="Ecclesiastes 12:14; ローマ人への手紙 1:18; ローマ人への手紙 2:2–3"> ところが、あなたは、かたくなさと悔い改めのない心のゆえに、御怒りの日、すなわち、神の正しいさばきの現われる日の御怒りを自分のために積み上げているのです。</span>
<span className="v" id="v6" data-v="6" data-xref="Psalms 62:12; Jeremiah 32:19; マタイの福音書 16:27"> 神は、ひとりひとりに、その人の行ないに従って報いをお与えになります。</span>
<span className="v" id="v7" data-v="7" data-xref="テモテへの手紙第二 4:7–8; ルカの福音書 8:15; テモテへの手紙第二 1:10"> 忍耐をもって善を行ない、栄光と誉れと不滅のものとを求める者には、永遠のいのちを与え、</span>
<span className="v" id="v8" data-v="8" data-xref="ヨハネの福音書 3:18–21; テサロニケ人への手紙第二 1:8; テモテへの手紙第一 6:3–4"> 党派心を持ち、真理に従わないで不義に従う者には、怒りと憤りを下されるのです。</span>
<span className="v" id="v9" data-v="9" data-xref="ペテロの手紙第一 4:17; Ezekiel 18:4; ローマ人への手紙 1:16"> 患難と苦悩とは、ユダヤ人をはじめギリシヤ人にも、悪を行なうすべての者の上に下り、</span>
<span className="v" id="v10" data-v="10" data-xref="Isaiah 32:17; Isaiah 26:12; Numbers 6:26"> 栄光と誉れと平和は、ユダヤ人をはじめギリシヤ人にも、善を行なうすべての者の上にあります。</span>
<span className="v" id="v11" data-v="11" data-xref="Deuteronomy 10:17; 使徒の働き 10:34; 2 Chronicles 19:7"> 神にはえこひいきなどはないからです。</span>
<span className="v" id="v12" data-v="12" data-xref="コリント人への手紙第一 9:21; ガラテヤ人への手紙 3:10; ガラテヤ人への手紙 2:16–19"> 律法なしに罪を犯した者はすべて、律法なしに滅び、律法の下にあって罪を犯した者はすべて、律法によってさばかれます。</span>
<span className="v" id="v13" data-v="13" data-xref="ヤコブの手紙 1:22–25; ヨハネの手紙第一 3:7; ヤコブの手紙 2:21–25"> それは、律法を聞く者が神の前に正しいのではなく、律法を行なう者が正しいと認められるからです。</span>
<span className="v" id="v14" data-v="14" data-xref="ローマ人への手紙 2:12; ローマ人への手紙 1:19–20; ローマ人への手紙 2:27"> ――律法を持たない異邦人が、生まれつきのままで律法の命じる行ないをするばあいは、律法を持たなくても、自分自身が自分に対する律法なのです。</span>
<span className="v" id="v15" data-v="15" data-xref="コリント人への手紙第二 5:11; コリント人への手紙第二 1:12; ローマ人への手紙 1:18–19"> 彼らはこのようにして、律法の命じる行ないが彼らの心に書かれていることを示しています。彼らの良心もいっしょになってあかしし、また、彼らの思いは互いに責め合ったり、また、弁明し合ったりしています。――</span>
<span className="v" id="v16" data-v="16" data-xref="Ecclesiastes 12:14; コリント人への手紙第一 4:5; 使徒の働き 17:31"> 私の福音によれば、神のさばきは、神がキリスト・イエスによって人々の隠れたことをさばかれる日に、行なわれるのです。</span>
<span className="v" id="v17" data-v="17" data-xref="ローマ人への手紙 2:23; Micah 3:11; Isaiah 48:1–2"> もし、あなたが自分をユダヤ人ととなえ、律法を持つことに安んじ、神を誇り、</span>
<span className="v" id="v18" data-v="18" data-xref="テサロニケ人への手紙第一 5:21; Deuteronomy 4:8; ヤコブの手紙 4:17"> みこころを知り、なすべきことが何であるかを律法に教えられてわきまえ、</span>
<span className="v" id="v19" data-v="19" data-xref="ヨハネの黙示録 3:17–18; マタイの福音書 15:14; Isaiah 49:6"> また、知識と真理の具体的な形として律法を持っているため、盲人の案内人、やみの中にいる者の光、愚かな者の導き手、幼子の教師だと自任しているのなら、</span>
<span className="v" id="v21" data-v="21" data-xref="コリント人への手紙第一 9:27; マタイの福音書 23:3–28; ルカの福音書 12:47"> どうして、人を教えながら、自分自身を教えないのですか。盗むなと説きながら、自分は盗むのですか。</span>
<span className="v" id="v22" data-v="22" data-xref="Malachi 3:8; マタイの福音書 12:39; マルコの福音書 11:17"> 姦淫するなと言いながら、自分は姦淫するのですか。偶像を忌みきらいながら、自分は神殿の物をかすめるのですか。</span>
<span className="v" id="v23" data-v="23" data-xref="ヤコブの手紙 4:16–17; ローマ人への手紙 2:17; ローマ人への手紙 3:2"> 律法を誇りとしているあなたが、どうして律法に違反して、神を侮るのですか。</span>
<span className="v" id="v24" data-v="24" data-xref="Ezekiel 36:20–23; Isaiah 52:5; ペテロの手紙第二 2:2"> これは、「神の名は、あなたがたのゆえに、異邦人の中でけがされている。」と書いてあるとおりです。</span>
<span className="v" id="v25" data-v="25" data-xref="Jeremiah 4:4; ガラテヤ人への手紙 5:3–6; 使徒の働き 7:51"> もし律法を守るなら、割礼には価値があります。しかし、もしあなたが律法にそむいているなら、あなたの割礼は、無割礼になったのです。</span>
<span className="v" id="v26" data-v="26" data-xref="コロサイ人への手紙 2:11; コリント人への手紙第一 7:18–19; ローマ人への手紙 8:4"> もし割礼を受けていない人が律法の規定を守るなら、割礼を受けていなくても、割礼を受けている者とみなされないでしょうか。</span>
<span className="v" id="v27" data-v="27" data-xref="マタイの福音書 12:41–42; ローマ人への手紙 2:29; コリント人への手紙第二 3:6"> また、からだに割礼を受けていないで律法を守る者が、律法の文字と割礼がありながら律法にそむいているあなたを、さばくことにならないでしょうか。</span>
<span className="v" id="v28" data-v="28" data-xref="ガラテヤ人への手紙 6:15; マタイの福音書 3:9; ローマ人への手紙 9:6–8"> 外見上のユダヤ人がユダヤ人なのではなく、外見上のからだの割礼が割礼なのではありません。</span>
<span className="v" id="v29" data-v="29" data-xref="Deuteronomy 30:6; ピリピ人への手紙 3:3; Deuteronomy 10:16"> かえって人目に隠れたユダヤ人がユダヤ人であり、文字ではなく、御霊による、心の割礼こそ割礼です。その誉れは、人からではなく、神から来るものです。</span>

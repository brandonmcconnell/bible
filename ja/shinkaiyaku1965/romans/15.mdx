<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="テサロニケ人への手紙第一 5:14; ローマ人への手紙 14:1; ガラテヤ人への手紙 6:1–2"> 私たち力のある者は、力のない人たちの弱さをになうべきです。自分を喜ばせるべきではありません。</span>
<span className="v" id="v2" data-v="2" data-xref="ローマ人への手紙 14:19; コリント人への手紙第一 10:24; ピリピ人への手紙 2:4–5"> 私たちはひとりひとり、隣人を喜ばせ、その徳を高め、その人の益となるようにすべきです。</span>
<span className="v" id="v3" data-v="3" data-xref="Psalms 69:9; ピリピ人への手紙 2:8; ヨハネの福音書 4:34"> キリストでさえ、ご自身を喜ばせることはなさらなかったのです。むしろ、「あなたをそしる人々のそしりは、わたしの上にふりかかった。」と書いてあるとおりです。</span>
<span className="v" id="v4" data-v="4" data-xref="コリント人への手紙第一 10:11; テモテへの手紙第二 3:16–17; ローマ人への手紙 4:23–24"> 昔書かれたものは、すべて私たちを教えるために書かれたのです。それは、聖書の与える忍耐と励ましによって、希望を持たせるためなのです。</span>
<span className="v" id="v5" data-v="5" data-xref="ピリピ人への手紙 2:4–5; ペテロの手紙第一 3:8; ローマ人への手紙 12:16"> どうか、忍耐と励ましの神が、あなたがたを、キリスト・イエスにふさわしく、互いに同じ思いを持つようにしてくださいますように。</span>
<span className="v" id="v6" data-v="6" data-xref="ヨハネの福音書 10:29–30; ヨハネの黙示録 1:6; エペソ人への手紙 1:3"> それは、あなたがたが、心を一つにし、声を合わせて、私たちの主イエス・キリストの父なる神をほめたたえるためです。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="マタイの福音書 10:40; ヨハネの福音書 13:34; ローマ人への手紙 5:2"> こういうわけですから、キリストが神の栄光のために、私たちを受け入れてくださったように、あなたがたも互いに受け入れなさい。</span>
<span className="v" id="v8" data-v="8" data-xref="ガラテヤ人への手紙 4:4–5; マタイの福音書 15:24; ヨハネの福音書 1:11"> 私は言います。キリストは、神の真理を現わすために、割礼のある者のしもべとなられました。それは先祖たちに与えられた約束を保証するためであり、</span>
<span className="v" id="v9" data-v="9" data-xref="2 Samuel 22:50; Psalms 18:49; ローマ人への手紙 3:29"> また異邦人も、あわれみのゆえに、神をあがめるようになるためです。こう書かれているとおりです。<br />「それゆえ、私は異邦人の中で、<br />あなたをほめたたえ、<br />あなたの御名をほめ歌おう。」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="Psalms 67:3–4; Deuteronomy 32:43; Isaiah 42:10–12"> また、こうも言われています。<br />「異邦人よ。主の民とともに喜べ。」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="Psalms 117:1"> さらにまた、<br />「すべての異邦人よ。主をほめよ。<br />もろもろの国民よ。主をたたえよ。」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="Isaiah 11:10; Isaiah 11:1; マタイの福音書 12:21"> さらにまた、イザヤがこう言っています。<br />「エッサイの根が起こる。<br />異邦人を治めるために立ち上がる方である。<br />異邦人はこの方に望みをかける。」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="テサロニケ人への手紙第二 2:16–17; ローマ人への手紙 12:12; コリント人への手紙第二 9:8"> どうか、望みの神が、あなたがたを信仰によるすべての喜びと平和をもって満たし、聖霊の力によって望みにあふれさせてくださいますように。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="コロサイ人への手紙 3:16; ペテロの手紙第二 1:12; ヨハネの手紙第一 2:21"> 私の兄弟たちよ。あなたがた自身が善意にあふれ、すべての知恵に満たされ、また互いに訓戒し合うことができることを、この私は確信しています。</span>
<span className="v" id="v15" data-v="15" data-xref="ローマ人への手紙 12:3; コリント人への手紙第一 15:10; ローマ人への手紙 1:5"> ただ私が所々、かなり大胆に書いたのは、あなたがたにもう一度思い起こしてもらうためでした。</span>
<span className="v" id="v16" data-v="16" data-xref="ローマ人への手紙 11:13; ローマ人への手紙 1:1; 使徒の働き 9:15"> それも私が、異邦人のためにキリスト・イエスの仕え人となるために、神から恵みをいただいているからです。私は神の福音をもって、祭司の務めを果たしています。それは異邦人を、聖霊によってきよめられた、神に受け入れられる供え物とするためです。</span>
<span className="v" id="v17" data-v="17" data-xref="コリント人への手紙第二 2:14–16; コリント人への手紙第二 12:11–21; ヘブル人への手紙 5:1"> それで、神に仕えることに関して、私はキリスト・イエスにあって誇りを持っているのです。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒の働き 15:12; ローマ人への手紙 1:5; 使徒の働き 21:19"> 私は、キリストが異邦人を従順にならせるため、この私を用いて成し遂げてくださったこと以外に、何かを話そうなどとはしません。キリストは、ことばと行ないにより、</span>
<span className="v" id="v19" data-v="19" data-xref="コリント人への手紙第二 12:12; ヘブル人への手紙 2:4; 使徒の働き 19:11–12"> また、しるしと不思議をなす力により、さらにまた、御霊の力によって、それを成し遂げてくださいました。その結果、私はエルサレムから始めて、ずっと回ってイルリコに至るまで、キリストの福音をくまなく伝えました。</span>
<span className="v" id="v20" data-v="20" data-xref="コリント人への手紙第二 10:13–16; コリント人への手紙第一 3:9–15; エペソ人への手紙 2:20–22"> このように、私は、他人の土台の上に建てないように、キリストの御名がまだ語られていない所に福音を宣べ伝えることを切に求めたのです。</span>
<span className="v" id="v21" data-v="21" data-xref="Isaiah 52:15; Isaiah 65:1"> それは、こう書いてあるとおりです。<br />「彼のことを伝えられなかった人々が<br />見るようになり、<br />聞いたことのなかった人々が<br />悟るようになる。」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="ローマ人への手紙 1:13; テサロニケ人への手紙第一 2:17–18"> そういうわけで、私は、あなたがたのところに行くのを幾度も妨げられましたが、</span>
<span className="v" id="v23" data-v="23" data-xref="ローマ人への手紙 15:32; ローマ人への手紙 1:10–12; ローマ人への手紙 15:29"> 今は、もうこの地方には私の働くべき所がなくなりましたし、また、イスパニヤに行くばあいは、あなたがたのところに立ち寄ることを多年希望していましたので、</span>
<span className="v" id="v24" data-v="24" data-xref="ローマ人への手紙 15:28; ローマ人への手紙 1:12; 使徒の働き 15:3"> ――というのは、途中あなたがたに会い、まず、しばらくの間あなたがたとともにいて心を満たされてから、あなたがたに送られ、そこへ行きたいと望んでいるからです。――</span>
<span className="v" id="v25" data-v="25" data-xref="使徒の働き 24:17; 使徒の働き 19:21; 使徒の働き 20:22"> ですが、今は、聖徒たちに奉仕するためにエルサレムへ行こうとしています。</span>
<span className="v" id="v26" data-v="26" data-xref="コリント人への手紙第二 8:1–9; 使徒の働き 11:27–30; コリント人への手紙第二 9:2"> それは、マケドニヤとアカヤでは、喜んでエルサレムの聖徒たちの中の貧しい人たちのために醵金することにしたからです。</span>
<span className="v" id="v27" data-v="27" data-xref="コリント人への手紙第一 9:11; ガラテヤ人への手紙 6:6; ピレモンへの手紙 1:19"> 彼らは確かに喜んでそれをしたのですが、同時にまた、その人々に対してはその義務があるのです。異邦人は霊的なことでは、その人々からもらいものをしたのですから、物質的な物をもって彼らに奉仕すべきです。</span>
<span className="v" id="v28" data-v="28" data-xref="ローマ人への手紙 15:24; ピリピ人への手紙 4:17; コロサイ人への手紙 1:6"> それで、私はこのことを済ませ、彼らにこの実を確かに渡してから、あなたがたのところを通ってイスパニヤに行くことにします。</span>
<span className="v" id="v29" data-v="29" data-xref="エペソ人への手紙 4:13; ローマ人への手紙 1:10–12; Psalms 16:11"> あなたがたのところに行くときは、キリストの満ちあふれる祝福をもって行くことと信じています。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="コロサイ人への手紙 4:12; コリント人への手紙第二 1:11; コリント人への手紙第二 4:11"> 兄弟たち。私たちの主イエス・キリストによって、また、御霊の愛によって切にお願いします。私のために、私とともに力を尽くして神に祈ってください。</span>
<span className="v" id="v31" data-v="31" data-xref="テサロニケ人への手紙第二 3:2; コリント人への手紙第二 8:4; コリント人への手紙第二 9:1"> 私がユダヤにいる不信仰な人々から救い出され、またエルサレムに対する私の奉仕が聖徒たちに受け入れられるものとなりますように。</span>
<span className="v" id="v32" data-v="32" data-xref="コリント人への手紙第一 16:18; ピレモンへの手紙 1:20; ピレモンへの手紙 1:7"> その結果として、神のみこころにより、喜びをもってあなたがたのところへ行き、あなたがたの中で、ともにいこいを得ることができますように。</span>
<span className="v" id="v33" data-v="33" data-xref="コリント人への手紙第二 13:11; ピリピ人への手紙 4:9; テサロニケ人への手紙第一 5:23"> どうか、平和の神が、あなたがたすべてとともにいてくださいますように。アーメン。</span>
</div>

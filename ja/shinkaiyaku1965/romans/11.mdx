<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="コリント人への手紙第二 11:22; 1 Samuel 12:22; ピリピ人への手紙 3:5"> すると、神はご自分の民を退けてしまわれたのですか。絶対にそんなことはありません。この私もイスラエル人で、アブラハムの子孫に属し、ベニヤミン族の出身です。</span>
<span className="v" id="v2" data-v="2" data-xref="Psalms 94:14; ローマ人への手紙 8:29–30; Exodus 32:1"> 神は、あらかじめ知っておられたご自分の民を退けてしまわれたのではありません。それともあなたがたは、聖書がエリヤに関する個所で言っていることを、知らないのですか。彼はイスラエルを神に訴えてこう言いました。</span>
<span className="v" id="v3" data-v="3" data-xref="1 Kings 19:10–18; 1 Kings 18:13; Nehemiah 9:26"> 「主よ。彼らはあなたの預言者たちを殺し、あなたの祭壇をこわし、私だけが残されました。彼らはいま私のいのちを取ろうとしています。」</span>
<span className="v" id="v4" data-v="4" data-xref="1 Kings 19:18; Numbers 25:3; Zephaniah 1:4"> ところが彼に対して何とお答えになりましたか。「バアルにひざをかがめていない男子七千人が、わたしのために残してある。」</span>
<span className="v" id="v5" data-v="5" data-xref="ローマ人への手紙 9:27; エペソ人への手紙 1:5–6; ローマ人への手紙 9:11"> それと同じように、今も、恵みの選びによって残された者がいます。</span>
<span className="v" id="v6" data-v="6" data-xref="ガラテヤ人への手紙 2:21; ローマ人への手紙 4:4–5; テモテへの手紙第二 1:9"> もし恵みによるのであれば、もはや行ないによるのではありません。もしそうでなかったら、恵みが恵みでなくなります。</span>
<span className="v" id="v7" data-v="7" data-xref="ローマ人への手紙 9:18; ローマ人への手紙 11:5; コリント人への手紙第二 4:4"> では、どうなるのでしょう。イスラエルは追い求めていたものを獲得できませんでした。選ばれた者は獲得しましたが、他の者は、かたくなにされたのです。</span>
<span className="v" id="v8" data-v="8" data-xref="Deuteronomy 29:4; Isaiah 29:10; Ezekiel 12:2"> こう書かれているとおりです。<br />「神は、彼らに鈍い心と<br />見えない目と聞こえない耳を与えられた。<br />今日に至るまで。」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="Psalms 69:22–23; ルカの福音書 12:20; Psalms 28:4"> ダビデもこう言います。<br />「彼らの食卓は、彼らにとって<br />わなとなり、網となり、<br />つまずきとなり、報いとなれ。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="Psalms 69:23; Deuteronomy 28:64–68; ペテロの手紙第二 2:4"> その目はくらんで見えなくなり、<br />その背はいつまでもかがんでおれ。」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="使徒の働き 13:46–48; ローマ人への手紙 11:31; ローマ人への手紙 10:19"> では、尋ねましょう。彼らがつまずいたのは倒れるためなのでしょうか。絶対にそんなことはありません。かえって、彼らの違反によって、救いが異邦人に及んだのです。それは、イスラエルにねたみを起こさせるためです。</span>
<span className="v" id="v12" data-v="12" data-xref="ローマ人への手紙 11:25; コロサイ人への手紙 1:27; ローマ人への手紙 11:15"> もし彼らの違反が世界の富となり、彼らの失敗が異邦人の富となるのなら、彼らの完成は、それ以上の、どんなにかすばらしいものを、もたらすことでしょう。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒の働き 9:15; テモテへの手紙第二 1:11–12; エペソ人への手紙 3:8"> そこで、異邦人の方々に言いますが、私は異邦人の使徒ですから、自分の務めを重んじています。</span>
<span className="v" id="v14" data-v="14" data-xref="コリント人への手紙第一 7:16; テモテへの手紙第一 4:16; ローマ人への手紙 9:3"> そして、それによって何とか私の同国人にねたみを引き起こさせて、その中の幾人でも救おうと願っているのです。</span>
<span className="v" id="v15" data-v="15" data-xref="エペソ人への手紙 1:10; ローマ人への手紙 5:10–11; コロサイ人への手紙 1:20–21"> もし彼らの捨てられることが世界の和解であるとしたら、彼らの受け入れられることは、死者の中から生き返ることでなくて何でしょう。</span>
<span className="v" id="v16" data-v="16" data-xref="Ezekiel 44:30; ヤコブの手紙 1:18; Proverbs 3:9"> 初物がきよければ、粉の全部がきよいのです。根がきよければ、枝もきよいのです。</span>
<span className="v" id="v17" data-v="17" data-xref="エペソ人への手紙 2:11–13; エペソ人への手紙 3:6; マタイの福音書 21:43"> もしも、枝の中のあるものが折られて、野生種のオリーブであるあなたがその枝に混じってつがれ、そしてオリーブの根の豊かな養分をともに受けているのだとしたら、</span>
<span className="v" id="v18" data-v="18" data-xref="コリント人への手紙第一 10:12; ローマ人への手紙 11:20; エペソ人への手紙 2:19–20"> あなたはその枝に対して誇ってはいけません。誇ったとしても、あなたが根をささえているのではなく、根があなたをささえているのです。</span>
<span className="v" id="v19" data-v="19" data-xref="ローマ人への手紙 11:17; ローマ人への手紙 11:11–12; ローマ人への手紙 11:23–24"> 枝が折られたのは、私がつぎ合わされるためだ、とあなたは言うでしょう。</span>
<span className="v" id="v20" data-v="20" data-xref="ローマ人への手紙 12:16; コリント人への手紙第二 1:24; コリント人への手紙第一 10:12"> そのとおりです。彼らは不信仰によって折られ、あなたは信仰によって立っています。高ぶらないで、かえって恐れなさい。</span>
<span className="v" id="v21" data-v="21" data-xref="ペテロの手紙第二 2:4–9; Jeremiah 25:29; Jeremiah 49:12"> もし神が台木の枝を惜しまれなかったとすれば、あなたをも惜しまれないでしょう。</span>
<span className="v" id="v22" data-v="22" data-xref="ヘブル人への手紙 3:14; ヘブル人への手紙 3:6; コリント人への手紙第一 15:2"> 見てごらんなさい。神のいつくしみときびしさを。倒れた者の上にあるのは、きびしさです。あなたの上にあるのは、神のいつくしみです。ただし、あなたがそのいつくしみの中にとどまっていればであって、そうでなければ、あなたも切り落とされるのです。</span>
<span className="v" id="v23" data-v="23" data-xref="コリント人への手紙第二 3:16; Zechariah 12:10; マタイの福音書 23:39"> 彼らであっても、もし不信仰を続けなければ、つぎ合わされるのです。神は、彼らを再びつぎ合わすことができるのです。</span>
<span className="v" id="v24" data-v="24" data-xref="ローマ人への手紙 11:17–18; ローマ人への手紙 11:30"> もしあなたが、野生種であるオリーブの木から切り取られ、もとの性質に反して、栽培されたオリーブの木につがれたのであれば、これらの栽培種のものは、もっとたやすく自分の台木につがれるはずです。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="ルカの福音書 21:24; コリント人への手紙第二 3:14–16; ローマ人への手紙 16:25"> 兄弟たち。私はあなたがたに、ぜひこの奥義を知っていていただきたい。それは、あなたがたが自分で自分を賢いと思うことがないようにするためです。その奥義とは、イスラエル人の一部がかたくなになったのは異邦人の完成のなる時までであり、</span>
<span className="v" id="v26" data-v="26" data-xref="Isaiah 59:20; Jeremiah 31:31–37; Psalms 14:7"> こうして、イスラエルはみな救われる、ということです。こう書かれているとおりです。<br />「救う者がシオンから出て、<br />ヤコブから不敬虔を取り払う。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="Jeremiah 31:31–34; Isaiah 59:21; Ezekiel 36:25–29"> これこそ、彼らに与えたわたしの契約である。<br />それは、わたしが彼らの罪を取り除く時である。」</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="Deuteronomy 10:15; Deuteronomy 7:7–8; マタイの福音書 21:43"> 彼らは、福音によれば、あなたがたのゆえに、神に敵対している者ですが、選びによれば、先祖たちのゆえに、愛されている者なのです。</span>
<span className="v" id="v29" data-v="29" data-xref="ヘブル人への手紙 7:21; Numbers 23:19; Malachi 3:6"> 神の賜物と召命とは変わることがありません。</span>
<span className="v" id="v30" data-v="30" data-xref="コロサイ人への手紙 3:7; エペソ人への手紙 2:1–2; コリント人への手紙第一 7:25"> ちょうどあなたがたが、かつては神に不従順であったが、今は、彼らの不従順のゆえに、あわれみを受けているのと同様に、</span>
<span className="v" id="v31" data-v="31" data-xref="ローマ人への手紙 11:15; ローマ人への手紙 10:16; ローマ人への手紙 11:25"> 彼らも、今は不従順になっていますが、それは、あなたがたの受けたあわれみによって、今や、彼ら自身もあわれみを受けるためなのです。</span>
<span className="v" id="v32" data-v="32" data-xref="ガラテヤ人への手紙 3:22; ローマ人への手紙 3:9; テモテへの手紙第一 2:4–6"> なぜなら、神は、すべての人をあわれもうとして、すべての人を不従順のうちに閉じ込められたからです。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="Job 5:9; Job 11:7–9; Psalms 92:5"> ああ、神の知恵と知識との富は、何と底知れず深いことでしょう。そのさばきは、何と知り尽くしがたく、その道は、何と測り知りがたいことでしょう。</span>
<span className="v" id="v34" data-v="34" data-xref="Isaiah 40:13; コリント人への手紙第一 2:16; Job 15:8"> なぜなら、だれが主のみこころを知ったのですか。また、だれが主のご計画にあずかったのですか。</span>
<span className="v" id="v35" data-v="35" data-xref="Job 41:11; Job 35:7; コリント人への手紙第一 4:7"> また、だれが、まず主に与えて報いを受けるのですか。</span>
<span className="v" id="v36" data-v="36" data-xref="コロサイ人への手紙 1:15–17; コリント人への手紙第一 8:6; ヘブル人への手紙 2:10"> というのは、すべてのことが、神から発し、神によって成り、神に至るからです。どうか、この神に、栄光がとこしえにありますように。アーメン。</span>
</div>

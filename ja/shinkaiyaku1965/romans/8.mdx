<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨハネの福音書 3:18–19; コリント人への手紙第二 5:17; ガラテヤ人への手紙 3:13"> こういうわけで、今は、キリスト・イエスにある者が罪に定められることは決してありません。</span>
<span className="v" id="v2" data-v="2" data-xref="ローマ人への手紙 6:14; コリント人への手紙第二 3:17; ローマ人への手紙 6:18"> なぜなら、キリスト・イエスにある、いのちの御霊の原理が、罪と死の原理から、あなたを解放したからです。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒の働き 13:39; ガラテヤ人への手紙 4:4–5; ヘブル人への手紙 7:18–19"> 肉によって無力になったため、律法にはできなくなっていることを、神はしてくださいました。神はご自分の御子を、罪のために、罪深い肉と同じような形でお遣わしになり、肉において罪を処罰されたのです。</span>
<span className="v" id="v4" data-v="4" data-xref="ガラテヤ人への手紙 5:16; ガラテヤ人への手紙 5:22–25; コロサイ人への手紙 1:22"> それは、肉に従って歩まず、御霊に従って歩む私たちの中に、律法の要求が全うされるためなのです。</span>
<span className="v" id="v5" data-v="5" data-xref="コリント人への手紙第一 2:14; ガラテヤ人への手紙 5:19–25; ヨハネの福音書 3:6"> 肉に従う者は肉的なことをもっぱら考えますが、御霊に従う者は御霊に属することをひたすら考えます。</span>
<span className="v" id="v6" data-v="6" data-xref="ガラテヤ人への手紙 6:8; ローマ人への手紙 8:7; ローマ人への手紙 8:13"> 肉の思いは死であり、御霊による思いは、いのちと平安です。</span>
<span className="v" id="v7" data-v="7" data-xref="コリント人への手紙第一 2:14; ヨハネの手紙第一 2:15–16; ヤコブの手紙 4:4"> というのは、肉の思いは神に対して反抗するものだからです。それは神の律法に服従しません。いや、服従できないのです。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨハネの福音書 3:5–6; ヘブル人への手紙 11:5–6; ローマ人への手紙 8:9"> 肉にある者は神を喜ばせることができません。</span>
<span className="v" id="v9" data-v="9" data-xref="ガラテヤ人への手紙 4:6; コリント人への手紙第一 3:16; テモテへの手紙第二 1:14"> けれども、もし神の御霊があなたがたのうちに住んでおられるなら、あなたがたは肉の中にではなく、御霊の中にいるのです。キリストの御霊を持たない人は、キリストのものではありません。</span>
<span className="v" id="v10" data-v="10" data-xref="エペソ人への手紙 3:17; ガラテヤ人への手紙 2:20; コリント人への手紙第二 5:21"> もしキリストがあなたがたのうちにおられるなら、からだは罪のゆえに死んでいても、霊が、義のゆえに生きています。</span>
<span className="v" id="v11" data-v="11" data-xref="コリント人への手紙第二 4:14; ローマ人への手紙 6:4–5; コリント人への手紙第二 4:11"> もしイエスを死者の中からよみがえらせた方の御霊が、あなたがたのうちに住んでおられるなら、キリスト・イエスを死者の中からよみがえらせた方は、あなたがたのうちに住んでおられる御霊によって、あなたがたの死ぬべきからだをも生かしてくださるのです。</span>
<span className="v" id="v12" data-v="12" data-xref="ローマ人への手紙 6:2–15; コリント人への手紙第一 6:19–20; ペテロの手紙第一 4:2–3"> ですから、兄弟たち。私たちは、肉に従って歩む責任を、肉に対して負ってはいません。</span>
<span className="v" id="v13" data-v="13" data-xref="ガラテヤ人への手紙 6:8; ペテロの手紙第一 2:11; コリント人への手紙第一 9:27"> もし肉に従って生きるなら、あなたがたは死ぬのです。しかし、もし御霊によって、からだの行ないを殺すなら、あなたがたは生きるのです。</span>
<span className="v" id="v14" data-v="14" data-xref="ガラテヤ人への手紙 5:18; ヨハネの福音書 1:12; ガラテヤ人への手紙 3:26"> 神の御霊に導かれる人は、だれでも神の子どもです。</span>
<span className="v" id="v15" data-v="15" data-xref="ガラテヤ人への手紙 4:5–7; テモテへの手紙第二 1:7; コリント人への手紙第一 2:12"> あなたがたは、人を再び恐怖に陥れるような、奴隷の霊を受けたのではなく、子としてくださる御霊を受けたのです。私たちは御霊によって、「アバ、父。」と呼びます。</span>
<span className="v" id="v16" data-v="16" data-xref="ヨハネの手紙第一 4:13; コリント人への手紙第二 1:22; コリント人への手紙第二 5:5"> 私たちが神の子どもであることは、御霊ご自身が、私たちの霊とともに、あかししてくださいます。</span>
<span className="v" id="v17" data-v="17" data-xref="ガラテヤ人への手紙 4:7; ガラテヤ人への手紙 3:29; エペソ人への手紙 3:6"> もし子どもであるなら、相続人でもあります。私たちがキリストと、栄光をともに受けるために苦難をともにしているなら、私たちは神の相続人であり、キリストとの共同相続人であります。</span>
<span className="v" id="v18" data-v="18" data-xref="コリント人への手紙第二 4:17–18; ペテロの手紙第一 4:13; ペテロの手紙第一 1:5–7"> 今の時のいろいろの苦しみは、将来私たちに啓示されようとしている栄光に比べれば、取るに足りないものと私は考えます。</span>
<span className="v" id="v19" data-v="19" data-xref="Malachi 3:17–18; ローマ人への手紙 8:23; ヨハネの手紙第一 3:2"> 被造物も、切実な思いで神の子どもたちの現われを待ち望んでいるのです。</span>
<span className="v" id="v20" data-v="20" data-xref="Genesis 3:17–19; Genesis 5:29; ローマ人への手紙 8:22"> それは、被造物が虚無に服したのが自分の意志ではなく、服従させた方によるのであって、望みがあるからです。</span>
<span className="v" id="v21" data-v="21" data-xref="ヨハネの黙示録 22:3–5; 使徒の働き 3:21; ペテロの手紙第二 3:13"> 被造物自体も、滅びの束縛から解放され、神の子どもたちの栄光の自由の中に入れられます。</span>
<span className="v" id="v22" data-v="22" data-xref="Jeremiah 12:4; Jeremiah 12:11; ヨハネの福音書 16:21"> 私たちは、被造物全体が今に至るまで、ともにうめきともに産みの苦しみをしていることを知っています。</span>
<span className="v" id="v23" data-v="23" data-xref="ピリピ人への手紙 3:20–21; コリント人への手紙第二 5:2–5; ヘブル人への手紙 9:28"> そればかりでなく、御霊の初穂をいただいている私たち自身も、心の中でうめきながら、子にしていただくこと、すなわち、私たちのからだの贖われることを待ち望んでいます。</span>
<span className="v" id="v24" data-v="24" data-xref="コリント人への手紙第二 5:7; ヘブル人への手紙 11:1; コリント人への手紙第二 4:18"> 私たちは、この望みによって救われているのです。目に見える望みは、望みではありません。だれでも目で見ていることを、どうしてさらに望むでしょう。</span>
<span className="v" id="v25" data-v="25" data-xref="ローマ人への手紙 12:12; ヘブル人への手紙 10:36; Psalms 27:14"> もしまだ見ていないものを望んでいるのなら、私たちは、忍耐をもって熱心に待ちます。</span>
<span className="v" id="v26" data-v="26" data-xref="マタイの福音書 10:20; エペソ人への手紙 6:18; ガラテヤ人への手紙 4:6"> 御霊も同じようにして、弱い私たちを助けてくださいます。私たちは、どのように祈ったらよいかわからないのですが、御霊ご自身が、言いようもない深いうめきによって、私たちのためにとりなしてくださいます。</span>
<span className="v" id="v27" data-v="27" data-xref="Jeremiah 17:10; ヨハネの手紙第一 5:14–15; エペソ人への手紙 2:18"> 人間の心を探り窮める方は、御霊の思いが何かをよく知っておられます。なぜなら、御霊は、神のみこころに従って、聖徒のためにとりなしをしてくださるからです。</span>
<span className="v" id="v28" data-v="28" data-xref="ペテロの手紙第一 5:10; ヤコブの手紙 1:12; Genesis 50:20"> 神を愛する人々、すなわち、神のご計画に従って召された人々のためには、神がすべてのことを働かせて益としてくださることを、私たちは知っています。</span>
<span className="v" id="v29" data-v="29" data-xref="エペソ人への手紙 1:4–5; Jeremiah 1:5; エペソ人への手紙 1:11"> なぜなら、神は、あらかじめ知っておられる人々を、御子のかたちと同じ姿にあらかじめ定められたからです。それは、御子が多くの兄弟たちの中で長子となられるためです。</span>
<span className="v" id="v30" data-v="30" data-xref="ヨハネの黙示録 17:14; ローマ人への手紙 8:28; エペソ人への手紙 1:11"> 神はあらかじめ定めた人々をさらに召し、召した人々をさらに義と認め、義と認めた人々にはさらに栄光をお与えになりました。</span>
<span className="v" id="v31" data-v="31" data-xref="Psalms 118:6; Jeremiah 1:19; Psalms 56:11"> では、これらのことからどう言えるでしょう。神が私たちの味方であるなら、だれが私たちに敵対できるでしょう。</span>
<span className="v" id="v32" data-v="32" data-xref="ヨハネの福音書 3:16; ローマ人への手紙 8:28; Psalms 84:11"> 私たちすべてのために、ご自分の御子をさえ惜しまずに死に渡された方が、どうして、御子といっしょにすべてのものを、私たちに恵んでくださらないことがありましょう。</span>
<span className="v" id="v33" data-v="33" data-xref="ヨハネの黙示録 12:10–11; Isaiah 50:8–9; Isaiah 54:17"> 神に選ばれた人々を訴えるのはだれですか。神が義と認めてくださるのです。</span>
<span className="v" id="v34" data-v="34" data-xref="ヘブル人への手紙 7:25; ローマ人への手紙 8:27; ヘブル人への手紙 9:24"> 罪に定めようとするのはだれですか。死んでくださった方、いや、よみがえられた方であるキリスト・イエスが、神の右の座に着き、私たちのためにとりなしていてくださるのです。</span>
<span className="v" id="v35" data-v="35" data-xref="ヨハネの福音書 10:28; Psalms 103:17; ヨハネの福音書 16:33"> 私たちをキリストの愛から引き離すのはだれですか。患難ですか、苦しみですか、迫害ですか、飢えですか、裸ですか、危険ですか、剣ですか。</span>
<span className="v" id="v36" data-v="36" data-xref="Psalms 44:22; Isaiah 53:7; コリント人への手紙第一 15:30"> 「あなたのために、私たちは一日中、 死に定められている。 私たちは、ほふられる羊とみなされた。」 と書いてあるとおりです。</span>
<span className="v" id="v37" data-v="37" data-xref="コリント人への手紙第一 15:57; ヨハネの手紙第一 4:4; コリント人への手紙第二 2:14"> しかし、私たちは、私たちを愛してくださった方によって、これらすべてのことの中にあっても、圧倒的な勝利者となるのです。</span>
<span className="v" id="v38" data-v="38" data-xref="ヨハネの福音書 10:28; ローマ人への手紙 14:8; テモテへの手紙第二 1:12"> 私はこう確信しています。死も、いのちも、御使いも、権威ある者も、今あるものも、後に来るものも、力ある者も、</span>
<span className="v" id="v39" data-v="39" data-xref="ヨハネの福音書 10:28–30; ローマ人への手紙 8:35; ローマ人への手紙 5:8"> 高さも、深さも、そのほかのどんな被造物も、私たちの主キリスト・イエスにある神の愛から、私たちを引き離すことはできません。</span>

<span className="v" id="v1" data-v="1" data-xref="使徒の働き 9:15; ローマ人への手紙 15:16; コリント人への手紙第一 1:1"> 神の福音のために選び分けられ、使徒として召されたキリスト・イエスのしもべパウロ、</span>
<span className="v" id="v2" data-v="2" data-xref="テトスへの手紙 1:2; ルカの福音書 1:70; ローマ人への手紙 3:21"> ――この福音は、神がその預言者たちを通して、聖書において前から約束されたもので、</span>
<span className="v" id="v3" data-v="3" data-xref="マタイの福音書 1:1; ガラテヤ人への手紙 4:4; Jeremiah 23:5–6"> 御子に関することです。御子は、肉によればダビデの子孫として生まれ、</span>
<span className="v" id="v4" data-v="4" data-xref="ヘブル人への手紙 9:14; ヘブル人への手紙 5:5–6; エペソ人への手紙 1:19–23"> きよい御霊によれば、死者の中からの復活により、大能によって公に神の御子として示された方、私たちの主イエス・キリストです。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒の働き 9:15; ローマ人への手紙 16:26; 使徒の働き 6:7"> このキリストによって、私たちは恵みと使徒の務めを受けました。それは、御名のためにあらゆる国の人々の中に信仰の従順をもたらすためなのです。</span>
<span className="v" id="v6" data-v="6" data-xref="ペテロの手紙第一 2:9; ヨハネの黙示録 17:14; ペテロの手紙第二 1:10"> あなたがたも、それらの人々の中にあって、イエス・キリストによって召された人々です。――このパウロから、</span>
<span className="v" id="v7" data-v="7" data-xref="コロサイ人への手紙 1:2; ユダの手紙 1:1–2; エペソ人への手紙 1:2"> ローマにいるすべての、神に愛されている人々、召された聖徒たちへ。 私たちの父なる神と主イエス・キリストから恵みと平安があなたがたの上にありますように。</span>
<span className="v" id="v8" data-v="8" data-xref="ローマ人への手紙 16:19; コリント人への手紙第一 1:4; テサロニケ人への手紙第一 1:8–9"> まず第一に、あなたがたすべてのために、私はイエス・キリストによって私の神に感謝します。それは、あなたがたの信仰が全世界に言い伝えられているからです。</span>
<span className="v" id="v9" data-v="9" data-xref="エペソ人への手紙 6:18; テモテへの手紙第二 1:3; エペソ人への手紙 1:16–19"> 私が御子の福音を宣べ伝えつつ霊をもって仕えている神があかししてくださることですが、私はあなたがたのことを思わぬ時はなく、</span>
<span className="v" id="v10" data-v="10" data-xref="ローマ人への手紙 15:30–32; 使徒の働き 18:21; ピレモンへの手紙 1:22"> いつも祈りのたびごとに、神のみこころによって、何とかして、今度はついに道が開かれて、あなたがたのところに行けるようにと願っています。</span>
<span className="v" id="v11" data-v="11" data-xref="ペテロの手紙第二 1:12; ローマ人への手紙 16:25; ローマ人への手紙 15:29"> 私があなたがたに会いたいと切に望むのは、御霊の賜物をいくらかでもあなたがたに分けて、あなたがたを強くしたいからです。</span>
<span className="v" id="v12" data-v="12" data-xref="テサロニケ人への手紙第一 3:7–10; ヨハネの手紙第三 1:3–4; コリント人への手紙第二 7:13"> というよりも、あなたがたの間にいて、あなたがたと私との互いの信仰によって、ともに励ましを受けたいのです。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒の働き 19:21; ピリピ人への手紙 4:17; テモテへの手紙第二 4:17"> 兄弟たち。ぜひ知っておいていただきたい。私はあなたがたの中でも、ほかの国の人々の中で得たと同じように、いくらかの実を得ようと思って、何度もあなたがたのところに行こうとしたのですが、今なお妨げられているのです。</span>
<span className="v" id="v14" data-v="14" data-xref="コリント人への手紙第一 9:16–23; 使徒の働き 9:15; コロサイ人への手紙 3:11"> 私は、ギリシヤ人にも未開人にも、知識のある人にも知識のない人にも、返さなければならない負債を負っています。</span>
<span className="v" id="v15" data-v="15" data-xref="ローマ人への手紙 15:20; Isaiah 6:8; コリント人への手紙第一 9:17"> ですから、私としては、ローマにいるあなたがたにも、ぜひ福音を伝えたいのです。</span>
<span className="v" id="v16" data-v="16" data-xref="マルコの福音書 8:38; テモテへの手紙第二 1:8; ペテロの手紙第一 4:16"> 私は福音を恥とは思いません。福音は、ユダヤ人をはじめギリシヤ人にも、信じるすべての人にとって、救いを得させる神の力です。</span>
<span className="v" id="v17" data-v="17" data-xref="Habakkuk 2:4; ガラテヤ人への手紙 3:11; ヘブル人への手紙 10:38"> なぜなら、福音のうちには神の義が啓示されていて、その義は、信仰に始まり信仰に進ませるからです。「義人は信仰によって生きる。」と書いてあるとおりです。</span>
<span className="v" id="v18" data-v="18" data-xref="エペソ人への手紙 5:6; テモテへの手紙第一 4:1–2; ローマ人への手紙 1:32"> というのは、不義をもって真理をはばんでいる人々のあらゆる不敬虔と不正に対して、神の怒りが天から啓示されているからです。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒の働き 14:16–17; Psalms 19:1–6; ローマ人への手紙 1:20"> なぜなら、神について知りうることは、彼らに明らかであるからです。それは神が明らかにされたのです。</span>
<span className="v" id="v20" data-v="20" data-xref="ローマ人への手紙 1:19; Isaiah 40:26; Psalms 19:1–6"> 神の、目に見えない本性、すなわち神の永遠の力と神性は、世界の創造された時からこのかた、被造物によって知られ、はっきりと認められるのであって、彼らに弁解の余地はないのです。</span>
<span className="v" id="v21" data-v="21" data-xref="エペソ人への手紙 4:17–18; 2 Kings 17:15; Jeremiah 2:5"> というのは、彼らは、神を知っていながら、その神を神としてあがめず、感謝もせず、かえってその思いはむなしくなり、その無知な心は暗くなったからです。</span>
<span className="v" id="v22" data-v="22" data-xref="コリント人への手紙第一 1:19–21; ローマ人への手紙 11:25; Proverbs 26:12"> 彼らは、自分では知者であると言いながら、愚かな者となり、</span>
<span className="v" id="v23" data-v="23" data-xref="Psalms 106:20; Jeremiah 2:11; 使徒の働き 17:29"> 不滅の神の御栄えを、滅ぶべき人間や、鳥、獣、はうもののかたちに似た物と代えてしまいました。</span>
<span className="v" id="v24" data-v="24" data-xref="Psalms 81:11–12; 使徒の働き 7:42; 使徒の働き 14:16"> それゆえ、神は、彼らをその心の欲望のままに汚れに引き渡され、そのために彼らは、互いにそのからだをはずかしめるようになりました。</span>
<span className="v" id="v25" data-v="25" data-xref="Habakkuk 2:18; Jeremiah 13:25; ヨハネの手紙第一 2:15–16"> それは、彼らが神の真理を偽りと取り代え、造り主の代わりに造られた物を拝み、これに仕えたからです。造り主こそ、とこしえにほめたたえられる方です。アーメン。</span>
<span className="v" id="v26" data-v="26" data-xref="ユダの手紙 1:7; テモテへの手紙第一 1:10; ローマ人への手紙 1:24"> こういうわけで、神は彼らを恥ずべき情欲に引き渡されました。すなわち、女は自然の用を不自然なものに代え、</span>
<span className="v" id="v27" data-v="27" data-xref="Leviticus 20:13; Leviticus 18:22; ローマ人への手紙 1:23–24"> 同じように、男も、女の自然な用を捨てて男どうしで情欲に燃え、男が男と恥ずべきことを行なうようになり、こうしてその誤りに対する当然の報いを自分の身に受けているのです。</span>
<span className="v" id="v28" data-v="28" data-xref="テサロニケ人への手紙第二 2:10–12; ローマ人への手紙 1:21; テトスへの手紙 1:16"> また、彼らが神を知ろうとしたがらないので、神は彼らを良くない思いに引き渡され、そのため彼らは、してはならないことをするようになりました。</span>
<span className="v" id="v29" data-v="29" data-xref="コリント人への手紙第二 12:20; Proverbs 16:28; Psalms 41:7"> 彼らは、あらゆる不義と悪とむさぼりと悪意とに満ちた者、ねたみと殺意と争いと欺きと悪だくみとでいっぱいになった者、陰口を言う者、</span>
<span className="v" id="v30" data-v="30" data-xref="テモテへの手紙第二 3:2; ユダの手紙 1:16; ペテロの手紙第二 2:18"> そしる者、神を憎む者、人を人と思わぬ者、高ぶる者、大言壮語する者、悪事をたくらむ者、親に逆らう者、</span>
<span className="v" id="v31" data-v="31" data-xref="テモテへの手紙第二 3:3; Proverbs 18:2; ローマ人への手紙 3:11"> わきまえのない者、約束を破る者、情け知らずの者、慈愛のない者です。</span>
<span className="v" id="v32" data-v="32" data-xref="ローマ人への手紙 2:1–5; ローマ人への手紙 1:21; ローマ人への手紙 6:21"> 彼らは、そのようなことを行なえば、死罪に当たるという神の定めを知っていながら、それを行なっているだけでなく、それを行なう者に心から同意しているのです。</span>

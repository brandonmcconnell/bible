<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ローマ人への手紙 2:25–29; Genesis 25:32; Ecclesiastes 6:11"> では、ユダヤ人のすぐれたところは、いったい何ですか。割礼にどんな益があるのですか。</span>
<span className="v" id="v2" data-v="2" data-xref="ローマ人への手紙 9:4; 使徒の働き 7:38; コリント人への手紙第一 9:17"> それは、あらゆる点から見て、大いにあります。第一に、彼らは神のいろいろなおことばをゆだねられています。</span>
<span className="v" id="v3" data-v="3" data-xref="テモテへの手紙第二 2:13; ヘブル人への手紙 4:2; ローマ人への手紙 9:6"> では、いったいどうなのですか。彼らのうちに不真実な者があったら、その不真実によって、神の真実が無に帰することになるでしょうか。</span>
<span className="v" id="v4" data-v="4" data-xref="Psalms 51:4; Psalms 116:11; ガラテヤ人への手紙 2:17"> 絶対にそんなことはありません。たとい、すべての人を偽り者としても、神は真実な方であるとすべきです。それは、 「あなたが、そのみことばによって正しいとされ、さばかれるときには勝利を得られるため。」 と書いてあるとおりです。</span>
<span className="v" id="v5" data-v="5" data-xref="ローマ人への手紙 6:19; ガラテヤ人への手紙 3:15; ローマ人への手紙 9:18–20"> しかし、もし私たちの不義が神の義を明らかにするとしたら、どうなるでしょうか。人間的な言い方をしますが、怒りを下す神は不正なのでしょうか。</span>
<span className="v" id="v6" data-v="6" data-xref="Genesis 18:25; 使徒の働き 17:31; Job 8:3"> 絶対にそんなことはありません。もしそうだとしたら、神はいったいどのように世をさばかれるのでしょう。</span>
<span className="v" id="v7" data-v="7" data-xref="ローマ人への手紙 3:4; ローマ人への手紙 9:19–20; 使徒の働き 13:27–29"> でも、私の偽りによって、神の真理がますます明らかにされて神の栄光となるのであれば、なぜ私がなお罪人としてさばかれるのでしょうか。</span>
<span className="v" id="v8" data-v="8" data-xref="ローマ人への手紙 6:1; ローマ人への手紙 6:15; ローマ人への手紙 5:20"> 「善を現わすために、悪をしようではないか。」と言ってはいけないのでしょうか。――私たちはこの点でそしられるのです。ある人たちは、それが私たちのことばだと言っていますが、――もちろんこのように論じる者どもは当然罪に定められるのです。</span>
<span className="v" id="v9" data-v="9" data-xref="ガラテヤ人への手紙 3:22; ローマ人への手紙 6:15; Isaiah 65:5"> では、どうなのでしょう。私たちは他の者にまさっているのでしょうか。決してそうではありません。私たちは前に、ユダヤ人もギリシヤ人も、すべての人が罪の下にあると責めたのです。</span>
<span className="v" id="v10" data-v="10" data-xref="Psalms 53:1–3; Psalms 14:1–3; ローマ人への手紙 3:23"> それは、次のように書いてあるとおりです。 「義人はいない。ひとりもいない。</span>
<span className="v" id="v11" data-v="11" data-xref="Psalms 14:2–4; Psalms 53:2; テトスへの手紙 3:3"> 悟りのある人はいない。神を求める人はいない。</span>
<span className="v" id="v12" data-v="12" data-xref="Psalms 14:3; Ecclesiastes 7:20; Isaiah 64:6"> すべての人が迷い出て、 みな、ともに無益な者となった。 善を行なう人はいない。ひとりもいない。」</span>
<span className="v" id="v13" data-v="13" data-xref="Psalms 5:9; Psalms 140:3; マタイの福音書 23:27–28"> 「彼らののどは、開いた墓であり、 彼らはその舌で欺く。」 「彼らのくちびるの下には、まむしの毒があり、」</span>
<span className="v" id="v14" data-v="14" data-xref="Psalms 10:7; Psalms 109:17–18; Psalms 59:12"> 「彼らの口は、のろいと苦さで満ちている。」</span>
<span className="v" id="v15" data-v="15" data-xref="Isaiah 59:7–8; Proverbs 1:16; Proverbs 6:18"> 「彼らの足は血を流すのに速く、</span>
<span className="v" id="v16" data-v="16"> 彼らの道には破壊と悲惨がある。</span>
<span className="v" id="v17" data-v="17" data-xref="Isaiah 59:8; ローマ人への手紙 5:1; ルカの福音書 1:79"> また、彼らは平和の道を知らない。」</span>
<span className="v" id="v18" data-v="18" data-xref="Psalms 36:1; Proverbs 23:17; Proverbs 16:6"> 「彼らの目の前には、神に対する恐れがない。」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="ガラテヤ人への手紙 3:10; ガラテヤ人への手紙 3:22–23; ローマ人への手紙 2:12–18"> さて、私たちは、律法の言うことはみな、律法の下にある人々に対して言われていることを知っています。それは、すべての口がふさがれて、全世界が神のさばきに服するためです。</span>
<span className="v" id="v20" data-v="20" data-xref="ガラテヤ人への手紙 2:16; 使徒の働き 13:39; ローマ人への手紙 3:28"> なぜなら、律法を行なうことによっては、だれひとり神の前に義と認められないからです。律法によっては、かえって罪の意識が生じるのです。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒の働き 10:43; Jeremiah 33:16; ピリピ人への手紙 3:9"> しかし、今は、律法とは別に、しかも律法と預言者によってあかしされて、神の義が示されました。</span>
<span className="v" id="v22" data-v="22" data-xref="ローマ人への手紙 10:12; ガラテヤ人への手紙 3:28; ローマ人への手紙 8:1"> すなわち、イエス・キリストを信じる信仰による神の義であって、それはすべての信じる人に与えられ、何の差別もありません。</span>
<span className="v" id="v23" data-v="23" data-xref="Ecclesiastes 7:20; ヨハネの手紙第一 1:8–10; ローマ人への手紙 3:9"> すべての人は、罪を犯したので、神からの栄誉を受けることができず、</span>
<span className="v" id="v24" data-v="24" data-xref="ペテロの手紙第一 1:18–19; テトスへの手紙 3:5–7; コロサイ人への手紙 1:14"> ただ、神の恵みにより、キリスト・イエスによる贖いのゆえに、価なしに義と認められるのです。</span>
<span className="v" id="v25" data-v="25" data-xref="ローマ人への手紙 3:23–24; ペテロの手紙第一 1:18–20; ヨハネの手紙第一 4:10"> 神は、キリスト・イエスを、その血による、また信仰による、なだめの供え物として、公にお示しになりました。それは、ご自身の義を現わすためです。というのは、今までに犯されて来た罪を神の忍耐をもって見のがして来られたからです。</span>
<span className="v" id="v26" data-v="26" data-xref="Deuteronomy 32:4; ローマ人への手紙 4:5; ローマ人への手紙 3:30"> それは、今の時にご自身の義を現わすためであり、こうして神ご自身が義であり、また、イエスを信じる者を義とお認めになるためなのです。</span>
<span className="v" id="v27" data-v="27" data-xref="ローマ人への手紙 4:2; ローマ人への手紙 2:23; コリント人への手紙第一 1:29–31"> それでは、私たちの誇りはどこにあるのでしょうか。それはすでに取り除かれました。どういう原理によってでしょうか。行ないの原理によってでしょうか。そうではなく、信仰の原理によってです。</span>
<span className="v" id="v28" data-v="28" data-xref="ガラテヤ人への手紙 2:16; ガラテヤ人への手紙 3:8; テトスへの手紙 3:7"> 人が義と認められるのは、律法の行ないによるのではなく、信仰によるというのが、私たちの考えです。</span>
<span className="v" id="v29" data-v="29" data-xref="コロサイ人への手紙 3:11; エペソ人への手紙 3:6; Zechariah 2:11"> それとも、神はユダヤ人だけの神でしょうか。異邦人にとっても神ではないのでしょうか。確かに神は、異邦人にとっても、神です。</span>
<span className="v" id="v30" data-v="30" data-xref="ガラテヤ人への手紙 3:8; ガラテヤ人への手紙 3:20; ピリピ人への手紙 3:3"> 神が唯一ならばそうです。この神は、割礼のある者を信仰によって義と認めてくださるとともに、割礼のない者をも、信仰によって義と認めてくださるのです。</span>
<span className="v" id="v31" data-v="31" data-xref="ガラテヤ人への手紙 2:21; マタイの福音書 5:17; ローマ人への手紙 13:8–10"> それでは、私たちは信仰によって律法を無効にすることになるのでしょうか。絶対にそんなことはありません。かえって、律法を確立することになるのです。</span>
</div>

<span className="v" id="v1" data-v="1" data-xref="ペテロの手紙第一 2:5; ローマ人への手紙 6:13; ヘブル人への手紙 13:15–16"> そういうわけですから、兄弟たち。私は、神のあわれみのゆえに、あなたがたにお願いします。あなたがたのからだを、神に受け入れられる、きよい、生きた供え物としてささげなさい。それこそ、あなたがたの霊的な礼拝です。</span>
<span className="v" id="v2" data-v="2" data-xref="ペテロの手紙第一 1:14; エペソ人への手紙 4:22–24; コリント人への手紙第二 5:17"> この世と調子を合わせてはいけません。いや、むしろ、神のみこころは何か、すなわち、何が良いことで、神に受け入れられ、完全であるのかをわきまえ知るために、心の一新によって自分を変えなさい。</span>
<span className="v" id="v3" data-v="3" data-xref="ガラテヤ人への手紙 6:3; ピリピ人への手紙 2:3–8; Proverbs 26:12"> 私は、自分に与えられた恵みによって、あなたがたひとりひとりに言います。だれでも、思うべき限度を越えて思い上がってはいけません。いや、むしろ、神がおのおのに分け与えてくださった信仰の量りに応じて、慎み深い考え方をしなさい。</span>
<span className="v" id="v4" data-v="4" data-xref="コリント人への手紙第一 12:27; コリント人への手紙第一 12:12–14; エペソ人への手紙 4:15–16"> 一つのからだには多くの器官があって、すべての器官が同じ働きはしないのと同じように、</span>
<span className="v" id="v5" data-v="5" data-xref="コリント人への手紙第一 12:20; コリント人への手紙第一 10:17; コリント人への手紙第一 12:27–28"> 大ぜいいる私たちも、キリストにあって一つのからだであり、ひとりひとり互いに器官なのです。</span>
<span className="v" id="v6" data-v="6" data-xref="ペテロの手紙第一 4:10–11; コリント人への手紙第一 7:7; コリント人への手紙第一 12:28–31"> 私たちは、与えられた恵みに従って、異なった賜物を持っているので、もしそれが預言であれば、その信仰に応じて預言しなさい。</span>
<span className="v" id="v7" data-v="7" data-xref="エペソ人への手紙 4:11; テモテへの手紙第二 4:2; 使徒の働き 13:1"> 奉仕であれば奉仕し、教える人であれば教えなさい。</span>
<span className="v" id="v8" data-v="8" data-xref="コリント人への手紙第二 9:7; テモテへの手紙第一 5:17; コリント人への手紙第一 12:28"> 勧めをする人であれば勧め、分け与える人は惜しまずに分け与え、指導する人は熱心に指導し、慈善を行なう人は喜んでそれをしなさい。</span>
<span className="v" id="v9" data-v="9" data-xref="Psalms 34:14; ペテロの手紙第一 4:8; テモテへの手紙第一 1:5"> 愛には偽りがあってはなりません。悪を憎み、善に親しみなさい。</span>
<span className="v" id="v10" data-v="10" data-xref="ピリピ人への手紙 2:3; ヨハネの福音書 13:34–35; ヘブル人への手紙 13:1"> 兄弟愛をもって心から互いに愛し合い、尊敬をもって互いに人を自分よりまさっていると思いなさい。</span>
<span className="v" id="v11" data-v="11" data-xref="ヘブル人への手紙 6:10–11; 使徒の働き 18:25; ヨハネの黙示録 3:15–16"> 勤勉で怠らず、霊に燃え、主に仕えなさい。</span>
<span className="v" id="v12" data-v="12" data-xref="ローマ人への手紙 15:13; ヘブル人への手紙 10:36; Psalms 62:8"> 望みを抱いて喜び、患難に耐え、絶えず祈りに励みなさい。</span>
<span className="v" id="v13" data-v="13" data-xref="ヘブル人への手紙 13:16; コリント人への手紙第二 9:12; ヨハネの手紙第一 3:17"> 聖徒の入用に協力し、旅人をもてなしなさい。</span>
<span className="v" id="v14" data-v="14" data-xref="ペテロの手紙第一 3:9; マタイの福音書 5:44; テサロニケ人への手紙第一 5:15"> あなたがたを迫害する者を祝福しなさい。祝福すべきであって、のろってはいけません。</span>
<span className="v" id="v15" data-v="15" data-xref="コリント人への手紙第一 12:26; ヘブル人への手紙 13:3; Psalms 35:13–14"> 喜ぶ者といっしょに喜び、泣く者といっしょに泣きなさい。</span>
<span className="v" id="v16" data-v="16" data-xref="ペテロの手紙第一 3:8; Proverbs 3:7; ヤコブの手紙 3:13–17"> 互いに一つ心になり、高ぶった思いを持たず、かえって身分の低い者に順応しなさい。自分こそ知者だなどと思ってはいけません。</span>
<span className="v" id="v17" data-v="17" data-xref="Proverbs 20:22; テサロニケ人への手紙第一 5:15; マタイの福音書 5:39"> だれに対してでも、悪に悪を報いることをせず、すべての人が良いと思うことを図りなさい。</span>
<span className="v" id="v18" data-v="18" data-xref="ヘブル人への手紙 12:14; マタイの福音書 5:9; ローマ人への手紙 14:19"> あなたがたは、自分に関する限り、すべての人と平和を保ちなさい。</span>
<span className="v" id="v19" data-v="19" data-xref="Deuteronomy 32:35; ヘブル人への手紙 10:30; Proverbs 24:29"> 愛する人たち。自分で復讐してはいけません。神の怒りに任せなさい。それは、こう書いてあるからです。「復讐はわたしのすることである。わたしが報いをする、と主は言われる。」</span>
<span className="v" id="v20" data-v="20" data-xref="Proverbs 25:21–22; マタイの福音書 5:44; ルカの福音書 6:27"> もしあなたの敵が飢えたなら、彼に食べさせなさい。渇いたなら、飲ませなさい。そうすることによって、あなたは彼の頭に燃える炭火を積むことになるのです。</span>
<span className="v" id="v21" data-v="21" data-xref="ペテロの手紙第一 3:9; ルカの福音書 6:27–30; Proverbs 16:32"> 悪に負けてはいけません。かえって、善をもって悪に打ち勝ちなさい。</span>

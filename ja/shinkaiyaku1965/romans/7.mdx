<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ローマ人への手紙 6:14; ローマ人への手紙 7:6; ローマ人への手紙 6:3"> それとも、兄弟たち。あなたがたは、律法が人に対して権限を持つのは、その人の生きている期間だけだ、ということを知らないのですか。――私は律法を知っている人々に言っているのです。――</span>
<span className="v" id="v2" data-v="2" data-xref="Genesis 2:23–24; コリント人への手紙第一 7:39; コリント人への手紙第一 7:4"> 夫のある女は、夫が生きている間は、律法によって夫に結ばれています。しかし、夫が死ねば、夫に関する律法から解放されます。</span>
<span className="v" id="v3" data-v="3" data-xref="Exodus 20:14; マタイの福音書 5:32; マルコの福音書 10:6–12"> ですから、夫が生きている間に他の男に行けば、姦淫の女と呼ばれるのですが、夫が死ねば、律法から解放されており、たとい他の男に行っても、姦淫の女ではありません。</span>
<span className="v" id="v4" data-v="4" data-xref="ペテロの手紙第一 2:24; ガラテヤ人への手紙 5:22–23; Isaiah 54:5"> 私の兄弟たちよ。それと同じように、あなたがたも、キリストのからだによって、律法に対しては死んでいるのです。それは、あなたがたが他の人、すなわち死者の中からよみがえった方と結ばれて、神のために実を結ぶようになるためです。</span>
<span className="v" id="v5" data-v="5" data-xref="エペソ人への手紙 2:3; ガラテヤ人への手紙 5:16–17; ガラテヤ人への手紙 5:24"> 私たちが肉にあったときは、律法による数々の罪の欲情が私たちのからだの中に働いていて、死のために実を結びました。</span>
<span className="v" id="v6" data-v="6" data-xref="ガラテヤ人への手紙 3:23–25; コリント人への手紙第二 3:6; ローマ人への手紙 7:4"> しかし、今は、私たちは自分を捕えていた律法に対して死んだので、それから解放され、その結果、古い文字にはよらず、新しい御霊によって仕えているのです。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="ローマ人への手紙 3:20; ローマ人への手紙 4:15; コリント人への手紙第一 15:56"> それでは、どういうことになりますか。律法は罪なのでしょうか。絶対にそんなことはありません。ただ、律法によらないでは、私は罪を知ることがなかったでしょう。律法が、「むさぼってはならない。」と言わなかったら、私はむさぼりを知らなかったでしょう。</span>
<span className="v" id="v8" data-v="8" data-xref="ローマ人への手紙 7:11; コリント人への手紙第一 15:56; ローマ人への手紙 4:15"> しかし、罪はこの戒めによって機会を捕え、私のうちにあらゆるむさぼりを引き起こしました。律法がなければ、罪は死んだものです。</span>
<span className="v" id="v9" data-v="9" data-xref="ガラテヤ人への手紙 3:10; ローマ人への手紙 8:7; ヤコブの手紙 2:10–11"> 私はかつて律法なしに生きていましたが、戒めが来たときに、罪が生き、私は死にました。</span>
<span className="v" id="v10" data-v="10" data-xref="コリント人への手紙第二 3:7; ローマ人への手紙 10:5; Leviticus 18:5"> それで私には、いのちに導くはずのこの戒めが、かえって死に導くものであることが、わかりました。</span>
<span className="v" id="v11" data-v="11" data-xref="Genesis 3:13; ローマ人への手紙 7:8; ヘブル人への手紙 3:13"> それは、戒めによって機会を捕えた罪が私を欺き、戒めによって私を殺したからです。</span>
<span className="v" id="v12" data-v="12" data-xref="テモテへの手紙第一 1:8; Psalms 119:137; Psalms 19:7–12"> ですから、律法は聖なるものであり、戒めも聖であり、正しく、また良いものなのです。</span>
<span className="v" id="v13" data-v="13" data-xref="ヤコブの手紙 1:13–15; ガラテヤ人への手紙 3:21; ローマ人への手紙 8:3"> では、この良いものが、私に死をもたらしたのでしょうか。絶対にそんなことはありません。それはむしろ、罪なのです。罪は、この良いもので私に死をもたらすことによって、罪として明らかにされ、戒めによって、極度に罪深いものとなりました。</span>
<span className="v" id="v14" data-v="14" data-xref="1 Kings 21:25; 2 Kings 17:17; ローマ人への手紙 7:18"> 私たちは、律法が霊的なものであることを知っています。しかし、私は罪ある人間であり、売られて罪の下にある者です。</span>
<span className="v" id="v15" data-v="15" data-xref="ガラテヤ人への手紙 5:17; ローマ人への手紙 7:19–20; Ecclesiastes 7:20"> 私には、自分のしていることがわかりません。私は自分がしたいと思うことをしているのではなく、自分が憎むことを行なっているからです。</span>
<span className="v" id="v16" data-v="16" data-xref="ローマ人への手紙 7:12; ローマ人への手紙 7:14; テモテへの手紙第一 1:8"> もし自分のしたくないことをしているとすれば、律法は良いものであることを認めているわけです。</span>
<span className="v" id="v17" data-v="17" data-xref="ローマ人への手紙 7:20; ピリピ人への手紙 3:8–9; ローマ人への手紙 7:18"> ですから、それを行なっているのは、もはや私ではなく、私のうちに住みついている罪なのです。</span>
<span className="v" id="v18" data-v="18" data-xref="ヨハネの福音書 3:6; Psalms 51:5; ガラテヤ人への手紙 5:17"> 私は、私のうち、すなわち、私の肉のうちに善が住んでいないのを知っています。私には善をしたいという願いがいつもあるのに、それを実行することがないからです。</span>
<span className="v" id="v19" data-v="19" data-xref="ローマ人への手紙 7:15"> 私は、自分でしたいと思う善を行なわないで、かえって、したくない悪を行なっています。</span>
<span className="v" id="v20" data-v="20" data-xref="ローマ人への手紙 7:17"> もし私が自分でしたくないことをしているのであれば、それを行なっているのは、もはや私ではなくて、私のうちに住む罪です。</span>
<span className="v" id="v21" data-v="21" data-xref="ローマ人への手紙 6:14; ローマ人への手紙 7:23; Psalms 119:133"> そういうわけで、私は、善をしたいと願っているのですが、その私に悪が宿っているという原理を見いだすのです。</span>
<span className="v" id="v22" data-v="22" data-xref="Psalms 1:2; Psalms 40:8; Psalms 119:35"> すなわち、私は、内なる人としては、神の律法を喜んでいるのに、</span>
<span className="v" id="v23" data-v="23" data-xref="ガラテヤ人への手紙 5:17; ヤコブの手紙 4:1; ローマ人への手紙 8:2"> 私のからだの中には異なった律法があって、それが私の心の律法に対して戦いをいどみ、私を、からだの中にある罪の律法のとりこにしているのを見いだすのです。</span>
<span className="v" id="v24" data-v="24" data-xref="ローマ人への手紙 6:6; テモテへの手紙第二 4:18; テトスへの手紙 2:14"> 私は、ほんとうにみじめな人間です。だれがこの死の、からだから、私を救い出してくれるのでしょうか。</span>
<span className="v" id="v25" data-v="25" data-xref="ガラテヤ人への手紙 5:17–24; コロサイ人への手紙 3:17; コリント人への手紙第二 12:9–10"> 私たちの主イエス・キリストのゆえに、ただ神に感謝します。ですから、この私は、心では神の律法に仕え、肉では罪の律法に仕えているのです。</span>

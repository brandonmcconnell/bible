<span className="v" id="v1" data-v="1" data-xref="Isaiah 32:17; ローマ人への手紙 15:13; ヨハネの福音書 16:33"> ですから、信仰によって義と認められた私たちは、私たちの主イエス・キリストによって、神との平和を持っています。</span>
<span className="v" id="v2" data-v="2" data-xref="エペソ人への手紙 2:18; エペソ人への手紙 3:12; ローマ人への手紙 12:12"> またキリストによって、いま私たちの立っているこの恵みに信仰によって導き入れられた私たちは、神の栄光を望んで大いに喜んでいます。</span>
<span className="v" id="v3" data-v="3" data-xref="ヤコブの手紙 1:2–3; ヤコブの手紙 1:12; ペテロの手紙第一 3:14"> そればかりではなく、患難さえも喜んでいます。それは、患難が忍耐を生み出し、</span>
<span className="v" id="v4" data-v="4" data-xref="ペテロの手紙第一 5:10; ヤコブの手紙 1:12; コリント人への手紙第二 4:8–12"> 忍耐が練られた品性を生み出し、練られた品性が希望を生み出すと知っているからです。</span>
<span className="v" id="v5" data-v="5" data-xref="ガラテヤ人への手紙 4:6; エペソ人への手紙 3:16–19; ピリピ人への手紙 1:20"> この希望は失望に終わることがありません。なぜなら、私たちに与えられた聖霊によって、神の愛が私たちの心に注がれているからです。</span>
<span className="v" id="v6" data-v="6" data-xref="エペソ人への手紙 2:1–5; ローマ人への手紙 5:8; コロサイ人への手紙 2:13"> 私たちがまだ弱かったとき、キリストは定められた時に、不敬虔な者のために死んでくださいました。</span>
<span className="v" id="v7" data-v="7" data-xref="ヨハネの福音書 15:13; ヨハネの手紙第一 3:16; ローマ人への手紙 16:4"> 正しい人のためにでも死ぬ人はほとんどありません。情け深い人のためには、進んで死ぬ人があるいはいるでしょう。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨハネの福音書 15:13; ヨハネの福音書 3:16; ローマ人への手紙 5:6"> しかし私たちがまだ罪人であったとき、キリストが私たちのために死んでくださったことにより、神は私たちに対するご自身の愛を明らかにしておられます。</span>
<span className="v" id="v9" data-v="9" data-xref="テサロニケ人への手紙第一 1:10; ローマ人への手紙 8:1; エペソ人への手紙 2:13"> ですから、今すでにキリストの血によって義と認められた私たちが、彼によって神の怒りから救われるのは、なおさらのことです。</span>
<span className="v" id="v10" data-v="10" data-xref="コリント人への手紙第二 5:18–19; コリント人への手紙第二 4:10–11; ローマ人への手紙 8:32"> もし敵であった私たちが、御子の死によって神と和解させられたのなら、和解させられた私たちが、彼のいのちによって救いにあずかるのは、なおさらのことです。</span>
<span className="v" id="v11" data-v="11" data-xref="コリント人への手紙第二 5:18–19; ローマ人への手紙 5:10; Isaiah 61:10"> そればかりでなく、私たちのために今や和解を成り立たせてくださった私たちの主イエス・キリストによって、私たちは神を大いに喜んでいるのです。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="コリント人への手紙第一 15:21–22; ローマ人への手紙 5:19; ローマ人への手紙 6:23"> そういうわけで、ちょうどひとりの人によって罪が世界にはいり、罪によって死がはいり、こうして死が全人類に広がったのと同様に、――それというのも全人類が罪を犯したからです。</span>
<span className="v" id="v13" data-v="13" data-xref="ローマ人への手紙 4:15; コリント人への手紙第一 15:56; ヨハネの手紙第一 3:4"> というのは、律法が与えられるまでの時期にも罪は世にあったからです。しかし罪は、何かの律法がなければ、認められないものです。</span>
<span className="v" id="v14" data-v="14" data-xref="コリント人への手紙第一 15:45; ローマ人への手紙 5:17; ヘブル人への手紙 9:27"> ところが死は、アダムからモーセまでの間も、アダムの違反と同じようには罪を犯さなかった人々をさえ支配しました。アダムはきたるべき方のひな型です。</span>
<span className="v" id="v15" data-v="15" data-xref="ローマ人への手紙 6:23; エペソ人への手紙 2:8; ローマ人への手紙 5:12"> ただし、恵みには違反のばあいとは違う点があります。もしひとりの違反によって多くの人が死んだとすれば、それにもまして、神の恵みとひとりの人イエス・キリストの恵みによる賜物とは、多くの人々に満ちあふれるのです。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒の働き 13:38–39; Isaiah 1:18; Isaiah 44:22"> また、賜物には、罪を犯したひとりによるばあいと違った点があります。さばきのばあいは、一つの違反のために罪に定められたのですが、恵みのばあいは、多くの違反が義と認められるからです。</span>
<span className="v" id="v17" data-v="17" data-xref="コリント人への手紙第一 15:21–22; コリント人への手紙第一 15:49; ローマ人への手紙 5:12"> もしひとりの人の違反により、ひとりによって死が支配するようになったとすれば、なおさらのこと、恵みと義の賜物とを豊かに受けている人々は、ひとりの人イエス・キリストにより、いのちにあって支配するのです。</span>
<span className="v" id="v18" data-v="18" data-xref="コリント人への手紙第一 15:22; ローマ人への手紙 5:12; ローマ人への手紙 5:15"> こういうわけで、ちょうど一つの違反によってすべての人が罪に定められたのと同様に、一つの義の行為によってすべての人が義と認められて、いのちを与えられるのです。</span>
<span className="v" id="v19" data-v="19" data-xref="ローマ人への手紙 5:18; コリント人への手紙第二 5:21; ピリピ人への手紙 2:8"> すなわち、ちょうどひとりの人の不従順によって多くの人が罪人とされたのと同様に、ひとりの従順によって多くの人が義人とされるのです。</span>
<span className="v" id="v20" data-v="20" data-xref="ローマ人への手紙 6:1; テトスへの手紙 3:3–7; ローマ人への手紙 6:14"> 律法がはいって来たのは、違反が増し加わるためです。しかし、罪の増し加わるところには、恵みも満ちあふれました。</span>
<span className="v" id="v21" data-v="21" data-xref="テトスへの手紙 2:11; ローマ人への手紙 5:14; ローマ人への手紙 8:10"> それは、罪が死によって支配したように、恵みが、私たちの主イエス・キリストにより、義の賜物によって支配し、永遠のいのちを得させるためなのです。</span>

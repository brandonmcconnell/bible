<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="Isaiah 51:2; ローマ人への手紙 4:16; コリント人への手紙第二 11:22"> それでは、肉による私たちの先祖アブラハムのばあいは、どうでしょうか。</span>
<span className="v" id="v2" data-v="2" data-xref="コリント人への手紙第一 1:31; コリント人への手紙第二 11:30; ピリピ人への手紙 3:9"> もしアブラハムが行ないによって義と認められたのなら、彼は誇ることができます。しかし、神の御前では、そうではありません。</span>
<span className="v" id="v3" data-v="3" data-xref="Genesis 15:6; ヤコブの手紙 2:23; ガラテヤ人への手紙 3:6–8"> 聖書は何と言っていますか。「それでアブラハムは神を信じた。それが彼の義とみなされた。」とあります。</span>
<span className="v" id="v4" data-v="4" data-xref="ローマ人への手紙 11:6; ローマ人への手紙 9:32; ローマ人への手紙 11:35"> 働く者のばあいに、その報酬は恵みでなくて、当然支払うべきものとみなされます。</span>
<span className="v" id="v5" data-v="5" data-xref="ピリピ人への手紙 3:9; ローマ人への手紙 3:22; テトスへの手紙 3:3–7"> 何の働きもない者が、不敬虔な者を義と認めてくださる方を信じるなら、その信仰が義とみなされるのです。</span>
<span className="v" id="v6" data-v="6" data-xref="テモテへの手紙第二 1:9; ピリピ人への手紙 3:9; コリント人への手紙第一 1:30"> ダビデもまた、行ないとは別の道で神によって義と認められる人の幸いを、こう言っています。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="Psalms 32:1–2; Psalms 130:3–4; ルカの福音書 7:47–50"> 「不法を赦され、罪をおおわれた人たちは、<br />幸いである。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="Psalms 32:2; ペテロの手紙第一 2:24; コリント人への手紙第二 5:19–20"> 主が罪を認めない人は幸いである。」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="ガラテヤ人への手紙 3:14; コロサイ人への手紙 3:11; ガラテヤ人への手紙 3:26–28"> それでは、この幸いは、割礼のある者にだけ与えられるのでしょうか。それとも、割礼のない者にも与えられるのでしょうか。私たちは、「アブラハムには、その信仰が義とみなされた。」と言っていますが、</span>
<span className="v" id="v10" data-v="10" data-xref="ガラテヤ人への手紙 6:15; ガラテヤ人への手紙 5:6; Genesis 17:10"> どのようにして、その信仰が義とみなされたのでしょうか。割礼を受けてからでしょうか。まだ割礼を受けていないときにでしょうか。割礼を受けてからではなく、割礼を受けていないときにです。</span>
<span className="v" id="v11" data-v="11" data-xref="ローマ人への手紙 3:22; ルカの福音書 19:9; コリント人への手紙第二 1:22"> 彼は、割礼を受けていないとき信仰によって義と認められたことの証印として、割礼というしるしを受けたのです。それは、彼が、割礼を受けないままで信じて義と認められるすべての人の父となり、</span>
<span className="v" id="v12" data-v="12" data-xref="Song of Solomon 1:8; ヨハネの福音書 8:39–40; Proverbs 2:20"> また割礼のある者の父となるためです。すなわち、割礼を受けているだけではなく、私たちの父アブラハムが無割礼のときに持った信仰の足跡に従って歩む者の父となるためです。</span>
<span className="v" id="v13" data-v="13" data-xref="ガラテヤ人への手紙 3:29; Genesis 22:17–18; Genesis 28:14"> というのは、世界の相続人となるという約束が、アブラハムに、あるいはまた、その子孫に与えられたのは、律法によってではなく、信仰の義によったからです。</span>
<span className="v" id="v14" data-v="14" data-xref="ガラテヤ人への手紙 3:18–24; ピリピ人への手紙 3:9; ローマ人への手紙 4:16"> もし律法による者が相続人であるとするなら、信仰はむなしくなり、約束は無効になってしまいます。</span>
<span className="v" id="v15" data-v="15" data-xref="ローマ人への手紙 5:13; ガラテヤ人への手紙 3:10; ローマ人への手紙 3:19–20"> 律法は怒りを招くものであり、律法のないところには違反もありません。</span>
<span className="v" id="v16" data-v="16" data-xref="ローマ人への手紙 3:24–26; エペソ人への手紙 2:8; ガラテヤ人への手紙 3:22"> そのようなわけで、世界の相続人となることは、信仰によるのです。それは、恵みによるためであり、こうして約束がすべての子孫に、すなわち、律法を持っている人々にだけでなく、アブラハムの信仰にならう人々にも保証されるためなのです。「わたしは、あなたをあらゆる国の人々の父とした。」と書いてあるとおりに、アブラハムは私たちすべての者の父なのです。</span>
<span className="v" id="v17" data-v="17" data-xref="コリント人への手紙第一 1:28; Genesis 17:4–5; ヨハネの福音書 5:21"> このことは、彼が信じた神、すなわち死者を生かし、無いものを有るもののようにお呼びになる方の御前で、そうなのです。</span>
<span className="v" id="v18" data-v="18" data-xref="ローマ人への手紙 8:24; Genesis 15:5–6; 使徒の働き 27:25"> 彼は望みえないときに望みを抱いて信じました。それは、「あなたの子孫はこのようになる。」と言われていたとおりに、彼があらゆる国の人々の父となるためでした。</span>
<span className="v" id="v19" data-v="19" data-xref="ヘブル人への手紙 11:11–19; ローマ人への手紙 4:20–21; Genesis 17:17"> アブラハムは、およそ百歳になって、自分のからだが死んだも同然であることと、サラの胎の死んでいることとを認めても、その信仰は弱りませんでした。</span>
<span className="v" id="v20" data-v="20" data-xref="ルカの福音書 1:45; コリント人への手紙第一 16:13; Daniel 10:19"> 彼は、不信仰によって神の約束を疑うようなことをせず、反対に、信仰がますます強くなって、神に栄光を帰し、</span>
<span className="v" id="v21" data-v="21" data-xref="ルカの福音書 1:37; Jeremiah 32:27; Genesis 18:14"> 神には約束されたことを成就する力があることを堅く信じました。</span>
<span className="v" id="v22" data-v="22" data-xref="ローマ人への手紙 4:6; ローマ人への手紙 4:3"> だからこそ、それが彼の義とみなされたのです。</span>
<span className="v" id="v23" data-v="23" data-xref="コリント人への手紙第一 10:11; ローマ人への手紙 15:4; コリント人への手紙第一 10:6"> しかし、「彼の義とみなされた。」と書いてあるのは、ただ彼のためだけでなく、</span>
<span className="v" id="v24" data-v="24" data-xref="使徒の働き 2:24; ペテロの手紙第一 1:21; 使徒の働き 13:30"> また私たちのためです。すなわち、私たちの主イエスを死者の中からよみがえらせた方を信じる私たちも、その信仰を義とみなされるのです。</span>
<span className="v" id="v25" data-v="25" data-xref="ヨハネの手紙第一 4:9–10; Isaiah 53:5–6; コリント人への手紙第二 5:21"> 主イエスは、私たちの罪のために死に渡され、私たちが義と認められるために、よみがえられたからです。</span>
</div>

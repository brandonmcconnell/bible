<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒の働き 18:18; ペテロの手紙第一 1:22–23; テモテへの手紙第一 5:9–10"> ケンクレヤにある教会の執事で、私たちの姉妹であるフィベを、あなたがたに推薦します。</span>
<span className="v" id="v2" data-v="2" data-xref="ピリピ人への手紙 2:29; ピリピ人への手紙 1:27; マタイの福音書 10:40–42"> どうぞ、聖徒にふさわしいしかたで、主にあってこの人を歓迎し、あなたがたの助けを必要とすることは、どんなことでも助けてあげてください。この人は、多くの人を助け、また私自身をも助けてくれた人です。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="コリント人への手紙第一 16:19; テモテへの手紙第二 4:19; 使徒の働き 18:26"> キリスト・イエスにあって私の同労者であるプリスカとアクラによろしく伝えてください。</span>
<span className="v" id="v4" data-v="4" data-xref="ピリピ人への手紙 2:30; ヨハネの手紙第一 3:16; コリント人への手紙第一 16:1"> この人たちは、自分のいのちの危険を冒して私のいのちを守ってくれたのです。この人たちには、私だけでなく、異邦人のすべての教会も感謝しています。</span>
<span className="v" id="v5" data-v="5" data-xref="コロサイ人への手紙 4:15; ピレモンへの手紙 1:2; コリント人への手紙第一 16:19"> またその家の教会によろしく伝えてください。私の愛するエパネトによろしく。この人はアジヤでキリストを信じた最初の人です。</span>
<span className="v" id="v6" data-v="6" data-xref="ローマ人への手紙 16:12; マタイの福音書 27:55; テモテへの手紙第一 5:10"> あなたがたのために非常に労苦したマリヤによろしく。</span>
<span className="v" id="v7" data-v="7" data-xref="ローマ人への手紙 16:11; ローマ人への手紙 16:21; ピレモンへの手紙 1:23"> 私の同国人で私といっしょに投獄されたことのある、アンドロニコとユニアスにもよろしく。この人々は使徒たちの間によく知られている人々で、また私より先にキリストにある者となったのです。</span>
<span className="v" id="v8" data-v="8" data-xref="ピリピ人への手紙 4:1; ヨハネの手紙第一 3:14; ローマ人への手紙 16:5"> 主にあって私の愛するアムプリアトによろしく。</span>
<span className="v" id="v9" data-v="9" data-xref="ローマ人への手紙 16:2–3; ローマ人への手紙 16:21"> キリストにあって私たちの同労者であるウルバノと、私の愛するスタキスとによろしく。</span>
<span className="v" id="v10" data-v="10" data-xref="ローマ人への手紙 14:18; ペテロの手紙第一 1:7; Deuteronomy 8:2"> キリストにあって練達したアペレによろしく。アリストブロの家の人たちによろしく。</span>
<span className="v" id="v11" data-v="11" data-xref="ローマ人への手紙 16:21; ローマ人への手紙 16:7"> 私の同国人ヘロデオンによろしく。ナルキソの家の主にある人たちによろしく。</span>
<span className="v" id="v12" data-v="12" data-xref="テサロニケ人への手紙第一 5:12–13; ヘブル人への手紙 6:10–11; コリント人への手紙第一 15:58"> 主にあって労している、ツルパナとツルポサによろしく。主にあって非常に労苦した愛するペルシスによろしく。</span>
<span className="v" id="v13" data-v="13" data-xref="マルコの福音書 15:21; テモテへの手紙第一 5:2; ヨハネの手紙第二 1:1"> 主にあって選ばれた人ルポスによろしく。また彼と私との母によろしく。</span>
<span className="v" id="v14" data-v="14" data-xref="コロサイ人への手紙 1:2; ローマ人への手紙 8:29; ヘブル人への手紙 3:1"> アスンクリト、フレゴン、ヘルメス、パトロバ、ヘルマスおよびその人たちといっしょにいる兄弟たちによろしく。</span>
<span className="v" id="v15" data-v="15" data-xref="ローマ人への手紙 16:2; ローマ人への手紙 1:7; ローマ人への手紙 16:14"> フィロロゴとユリヤ、ネレオとその姉妹、オルンパおよびその人たちといっしょにいるすべての聖徒たちによろしく。</span>
<span className="v" id="v16" data-v="16" data-xref="テサロニケ人への手紙第一 5:26; コリント人への手紙第一 16:20; コリント人への手紙第二 13:12"> あなたがたはきよい口づけをもって互いのあいさつをかわしなさい。キリストの教会はみな、あなたがたによろしくと言っています。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="ユダの手紙 1:19; テサロニケ人への手紙第二 3:6; テモテへの手紙第一 6:3–5"> 兄弟たち。私はあなたがたに願います。あなたがたの学んだ教えにそむいて、分裂とつまずきを引き起こす人たちを警戒してください。彼らから遠ざかりなさい。</span>
<span className="v" id="v18" data-v="18" data-xref="コロサイ人への手紙 2:4; マタイの福音書 7:15; テモテへの手紙第一 6:5"> そういう人たちは、私たちの主キリストに仕えないで、自分の欲に仕えているのです。彼らは、なめらかなことば、へつらいのことばをもって純朴な人たちの心をだましているのです。</span>
<span className="v" id="v19" data-v="19" data-xref="マタイの福音書 10:16; コリント人への手紙第一 14:20; ピリピ人への手紙 2:15"> あなたがたの従順はすべての人に知られているので、私はあなたがたのことを喜んでいます。しかし、私は、あなたがたが善にはさとく、悪にはうとくあってほしい、と望んでいます。</span>
<span className="v" id="v20" data-v="20" data-xref="ルカの福音書 10:19; ヨハネの手紙第一 3:8; Genesis 3:15"> 平和の神は、すみやかに、あなたがたの足でサタンを踏み砕いてくださいます。<br />どうか、私たちの主イエスの恵みが、あなたがたとともにありますように。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="使徒の働き 20:4; 使徒の働き 17:5; 使徒の働き 13:1"> 私の同労者テモテが、あなたがたによろしくと言っています。また私の同国人ルキオとヤソンとソシパテロがよろしくと言っています。</span>
<span className="v" id="v22" data-v="22" data-xref="ガラテヤ人への手紙 6:11; コリント人への手紙第一 16:21; ローマ人への手紙 16:8"> この手紙を筆記した私、テルテオも、主にあってあなたがたにごあいさつ申し上げます。</span>
<span className="v" id="v23" data-v="23" data-xref="コリント人への手紙第一 1:14; 使徒の働き 19:22; テモテへの手紙第二 4:20"> 私と全教会との家主であるガイオも、あなたがたによろしくと言っています。市の収入役であるエラストと兄弟クワルトもよろしくと言っています。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24"> 私の福音とイエス・キリストの宣教によって、すなわち、世々にわたって長い間隠されていたが、今や現わされて、永遠の神の命令に従い、預言者たちの書によって、信仰の従順に導くためにあらゆる国の人々に知らされた奥義の啓示によって、あなたがたを堅く立たせることができる方、</span>
<span className="v" id="v27" data-v="27" data-xref="テモテへの手紙第一 1:17; ローマ人への手紙 11:36; ヨハネの黙示録 7:10–12"> 知恵に富む唯一の神に、イエス・キリストによって、御栄えがとこしえまでありますように。アーメン。</span>
</div>

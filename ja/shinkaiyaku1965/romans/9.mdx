<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="テモテへの手紙第一 2:7; ローマ人への手紙 1:9; ガラテヤ人への手紙 1:20"> 私はキリストにあって真実を言い、偽りを言いません。次のことは、私の良心も、聖霊によってあかししています。</span>
<span className="v" id="v2" data-v="2" data-xref="ピリピ人への手紙 3:18; Psalms 119:136; Jeremiah 13:17"> 私には大きな悲しみがあり、私の心には絶えず痛みがあります。</span>
<span className="v" id="v3" data-v="3" data-xref="Exodus 32:32; Esther 8:6; ローマ人への手紙 11:14"> もしできることなら、私の同胞、肉による同国人のために、この私がキリストから引き離されて、のろわれた者となることさえ願いたいのです。</span>
<span className="v" id="v4" data-v="4" data-xref="エペソ人への手紙 2:12; Psalms 147:19; ローマ人への手紙 9:6"> 彼らはイスラエル人です。子とされることも、栄光も、契約も、律法を与えられることも、礼拝も、約束も彼らのものです。</span>
<span className="v" id="v5" data-v="5" data-xref="ヨハネの福音書 10:30; ヨハネの福音書 1:1–3; コロサイ人への手紙 1:16–19"> 先祖たちも彼らのものです。またキリストも、人としては彼らから出られたのです。このキリストは万物の上にあり、とこしえにほめたたえられる神です。アーメン。</span>
<span className="v" id="v6" data-v="6" data-xref="ローマ人への手紙 2:28–29; ガラテヤ人への手紙 6:16; ローマ人への手紙 11:1–2"> しかし、神のみことばが無効になったわけではありません。なぜなら、イスラエルから出る者がみな、イスラエルなのではなく、</span>
<span className="v" id="v7" data-v="7" data-xref="Genesis 21:12; ヘブル人への手紙 11:18; ヨハネの福音書 8:37–39"> アブラハムから出たからといって、すべてが子どもなのではなく、「イサクから出る者があなたの子孫と呼ばれる。」のだからです。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨハネの福音書 1:13; ローマ人への手紙 4:11–16; ガラテヤ人への手紙 3:26–29"> すなわち、肉の子どもがそのまま神の子どもではなく、約束の子どもが子孫とみなされるのです。</span>
<span className="v" id="v9" data-v="9" data-xref="Genesis 18:10; Genesis 18:14; Genesis 17:21"> 約束のみことばはこうです。「私は来年の今ごろ来ます。そして、サラは男の子を産みます。」</span>
<span className="v" id="v10" data-v="10" data-xref="Genesis 25:21–23; ルカの福音書 16:26; ローマ人への手紙 5:11"> このことだけでなく、私たちの先祖イサクひとりによってみごもったリベカのこともあります。</span>
<span className="v" id="v11" data-v="11" data-xref="テモテへの手紙第二 1:9; エペソ人への手紙 1:4–5; ペテロの手紙第二 1:10"> その子どもたちは、まだ生まれてもおらず、善も悪も行なわないうちに、神の選びの計画の確かさが、行ないにはよらず、召してくださる方によるようにと、</span>
<span className="v" id="v12" data-v="12" data-xref="Genesis 25:22–23; 2 Samuel 8:14; 1 Kings 22:47"> 「兄は弟に仕える。」と彼女に告げられたのです。</span>
<span className="v" id="v13" data-v="13" data-xref="Malachi 1:2–3; Deuteronomy 21:15; Genesis 29:33"> 「わたしはヤコブを愛し、エサウを憎んだ。」と書いてあるとおりです。</span>
<span className="v" id="v14" data-v="14" data-xref="2 Chronicles 19:7; Psalms 145:17; Deuteronomy 32:4"> それでは、どういうことになりますか。神に不正があるのですか。絶対にそんなことはありません。</span>
<span className="v" id="v15" data-v="15" data-xref="Exodus 33:19; ローマ人への手紙 9:16; Micah 7:18"> 神はモーセに、「わたしは自分のあわれむ者をあわれみ、自分のいつくしむ者をいつくしむ。」と言われました。</span>
<span className="v" id="v16" data-v="16" data-xref="エペソ人への手紙 2:8; マタイの福音書 11:25–26; ペテロの手紙第一 2:9–10"> したがって、事は人間の願いや努力によるのではなく、あわれんでくださる神によるのです。</span>
<span className="v" id="v17" data-v="17" data-xref="Exodus 9:16; Proverbs 16:4; Exodus 14:17–18"> 聖書はパロに、「わたしがあなたを立てたのは、あなたにおいてわたしの力を示し、わたしの名を全世界に告げ知らせるためである。」と言っています。</span>
<span className="v" id="v18" data-v="18" data-xref="Joshua 11:20; Exodus 4:21; ローマ人への手紙 9:15–16"> こういうわけで、神は、人をみこころのままにあわれみ、またみこころのままにかたくなにされるのです。</span>
<span className="v" id="v19" data-v="19" data-xref="Daniel 4:35; 2 Chronicles 20:6; コリント人への手紙第一 15:12"> すると、あなたはこう言うでしょう。「それなのになぜ、神は人を責められるのですか。だれが神のご計画に逆らうことができましょう。」</span>
<span className="v" id="v20" data-v="20" data-xref="Isaiah 29:16; Isaiah 45:9–11; Isaiah 64:8"> しかし、人よ。神に言い逆らうあなたは、いったい何ですか。形造られた者が形造った者に対して、「あなたはなぜ、私をこのようなものにしたのですか。」と言えるでしょうか。</span>
<span className="v" id="v21" data-v="21" data-xref="Isaiah 64:8; Proverbs 16:4; テモテへの手紙第二 2:20–21"> 陶器を作る者は、同じ土のかたまりから、尊いことに用いる器でも、また、つまらないことに用いる器でも作る権利を持っていないのでしょうか。</span>
<span className="v" id="v22" data-v="22" data-xref="Proverbs 16:4; ユダの手紙 1:4; ローマ人への手紙 9:21"> ですが、もし神が、怒りを示してご自分の力を知らせようと望んでおられるのに、その滅ぼされるべき怒りの器を、豊かな寛容をもって忍耐してくださったとしたら、どうでしょうか。</span>
<span className="v" id="v23" data-v="23" data-xref="ローマ人への手紙 2:4; ペテロの手紙第一 1:2–5; コロサイ人への手紙 1:27"> それも、神が栄光のためにあらかじめ用意しておられたあわれみの器に対して、その豊かな栄光を知らせてくださるためになのです。</span>
<span className="v" id="v24" data-v="24" data-xref="コロサイ人への手紙 3:11; 使徒の働き 13:47–48; エペソ人への手紙 3:6–8"> 神は、このあわれみの器として、私たちを、ユダヤ人の中からだけでなく、異邦人の中からも召してくださったのです。</span>
<span className="v" id="v25" data-v="25" data-xref="Hosea 2:23; ペテロの手紙第一 2:10; ヨハネの福音書 16:27"> それは、ホセアの書でも言っておられるとおりです。 「わたしは、わが民でない者をわが民と呼び、 愛さなかった者を愛する者と呼ぶ。</span>
<span className="v" id="v26" data-v="26" data-xref="Hosea 1:9–10; ヨハネの手紙第一 3:1–3; ガラテヤ人への手紙 3:26"> 『あなたがたは、わたしの民ではない。』と、 わたしが言ったその場所で、彼らは、 生ける神の子どもと呼ばれる。」</span>
<span className="v" id="v27" data-v="27" data-xref="Isaiah 10:20–23; ローマ人への手紙 11:4–6; Isaiah 1:9"> また、イスラエルについては、イザヤがこう叫んでいます。 「たといイスラエルの子どもたちの数は、 海べの砂のようであっても、 救われるのは、残された者である。</span>
<span className="v" id="v28" data-v="28" data-xref="Isaiah 10:23; ヨハネの黙示録 19:11; 使徒の働き 17:31"> 主は、みことばを完全に、しかも敏速に、 地上に成し遂げられる。」</span>
<span className="v" id="v29" data-v="29" data-xref="Isaiah 1:9; Isaiah 13:19; Amos 4:11"> また、イザヤがこう預言したとおりです。 「もし万軍の主が、私たちに 子孫を残されなかったら、 私たちはソドムのようになり、 ゴモラと同じものとされたであろう。」</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="ピリピ人への手紙 3:9; ヘブル人への手紙 11:7; ガラテヤ人への手紙 2:16"> では、どういうことになりますか。義を追い求めなかった異邦人は義を得ました。すなわち、信仰による義です。</span>
<span className="v" id="v31" data-v="31" data-xref="ローマ人への手紙 11:7; ローマ人への手紙 3:20; ヤコブの手紙 2:10–11"> しかし、イスラエルは、義の律法を追い求めながら、その律法に到達しませんでした。</span>
<span className="v" id="v32" data-v="32" data-xref="コリント人への手紙第一 1:23; ペテロの手紙第一 2:8; ルカの福音書 7:23"> なぜでしょうか。信仰によって追い求めることをしないで、行ないによるかのように追い求めたからです。彼らは、つまずきの石につまずいたのです。</span>
<span className="v" id="v33" data-v="33" data-xref="Isaiah 28:16; Isaiah 8:14–15; ローマ人への手紙 10:11"> それは、こう書かれているとおりです。 「見よ。わたしは、 シオンに、つまずきの石、妨げの岩を置く。 彼に信頼する者は、 失望させられることがない。」</span>
</div>

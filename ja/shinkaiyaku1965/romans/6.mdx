<span className="v" id="v1" data-v="1" data-xref="ペテロの手紙第一 2:16; ガラテヤ人への手紙 5:13; ローマ人への手紙 6:15"> それでは、どういうことになりますか。恵みが増し加わるために、私たちは罪の中にとどまるべきでしょうか。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネの手紙第一 3:9; コロサイ人への手紙 3:3; ローマ人への手紙 7:4"> 絶対にそんなことはありません。罪に対して死んだ私たちが、どうして、なおもその中に生きていられるでしょう。</span>
<span className="v" id="v3" data-v="3" data-xref="ガラテヤ人への手紙 3:27; ガラテヤ人への手紙 2:20–21; ローマ人への手紙 6:8"> それとも、あなたがたは知らないのですか。キリスト・イエスにつくバプテスマを受けた私たちはみな、その死にあずかるバプテスマを受けたのではありませんか。</span>
<span className="v" id="v4" data-v="4" data-xref="コリント人への手紙第二 5:17; コロサイ人への手紙 3:10; エペソ人への手紙 4:22–24"> 私たちは、キリストの死にあずかるバプテスマによって、キリストとともに葬られたのです。それは、キリストが御父の栄光によって死者の中からよみがえられたように、私たちも、いのちにあって新しい歩みをするためです。</span>
<span className="v" id="v5" data-v="5" data-xref="ピリピ人への手紙 3:10–11; コリント人への手紙第二 4:10; コロサイ人への手紙 2:12"> もし私たちが、キリストにつぎ合わされて、キリストの死と同じようになっているのなら、必ずキリストの復活とも同じようになるからです。</span>
<span className="v" id="v6" data-v="6" data-xref="ガラテヤ人への手紙 2:20; エペソ人への手紙 4:22; ガラテヤ人への手紙 5:24"> 私たちの古い人がキリストとともに十字架につけられたのは、罪のからだが滅びて、私たちがもはやこれからは罪の奴隷でなくなるためであることを、私たちは知っています。</span>
<span className="v" id="v7" data-v="7" data-xref="ペテロの手紙第一 4:1; コロサイ人への手紙 3:1–3; ローマ人への手紙 7:4"> 死んでしまった者は、罪から解放されているのです。</span>
<span className="v" id="v8" data-v="8" data-xref="テモテへの手紙第二 2:11–12; コロサイ人への手紙 3:3–4; コリント人への手紙第二 4:10–14"> もし私たちがキリストとともに死んだのであれば、キリストとともに生きることにもなる、と信じます。</span>
<span className="v" id="v9" data-v="9" data-xref="ローマ人への手紙 6:14; ヨハネの黙示録 1:18; 使徒の働き 2:24–28"> キリストは死者の中からよみがえって、もはや死ぬことはなく、死はもはやキリストを支配しないことを、私たちは知っています。</span>
<span className="v" id="v10" data-v="10" data-xref="コリント人への手紙第二 5:21; ペテロの手紙第一 4:6; ペテロの手紙第一 3:18"> なぜなら、キリストが死なれたのは、ただ一度罪に対して死なれたのであり、キリストが生きておられるのは、神に対して生きておられるのだからです。</span>
<span className="v" id="v11" data-v="11" data-xref="コロサイ人への手紙 3:3–5; コリント人への手紙第一 6:20; ローマ人への手紙 6:2"> このように、あなたがたも、自分は罪に対しては死んだ者であり、神に対してはキリスト・イエスにあって生きた者だと、思いなさい。</span>
<span className="v" id="v12" data-v="12" data-xref="ガラテヤ人への手紙 5:16; ローマ人への手紙 6:16; ローマ人への手紙 8:13"> ですから、あなたがたの死ぬべきからだを罪の支配にゆだねて、その情欲に従ってはいけません。</span>
<span className="v" id="v13" data-v="13" data-xref="ローマ人への手紙 12:1; ローマ人への手紙 6:16; コロサイ人への手紙 3:5"> また、あなたがたの手足を不義の器として罪にささげてはいけません。むしろ、死者の中から生かされた者として、あなたがた自身とその手足を義の器として神にささげなさい。</span>
<span className="v" id="v14" data-v="14" data-xref="ガラテヤ人への手紙 5:18; ローマ人への手紙 8:2; ローマ人への手紙 7:4–11"> というのは、罪はあなたがたを支配することがないからです。なぜなら、あなたがたは律法の下にはなく、恵みの下にあるからです。</span>
<span className="v" id="v15" data-v="15" data-xref="テトスへの手紙 2:11–14; エペソ人への手紙 2:8–10; ローマ人への手紙 6:1–2"> それではどうなのでしょう。私たちは、律法の下にではなく、恵みの下にあるのだから罪を犯そう、ということになるのでしょうか。絶対にそんなことはありません。</span>
<span className="v" id="v16" data-v="16" data-xref="ヨハネの福音書 8:34; マタイの福音書 6:24; Joshua 24:15"> あなたがたはこのことを知らないのですか。あなたがたが自分の身をささげて奴隷として服従すれば、その服従する相手の奴隷であって、あるいは罪の奴隷となって死に至り、あるいは従順の奴隷となって義に至るのです。</span>
<span className="v" id="v17" data-v="17" data-xref="ペテロの手紙第一 2:9; テモテへの手紙第二 1:13; ローマ人への手紙 1:8"> 神に感謝すべきことには、あなたがたは、もとは罪の奴隷でしたが、伝えられた教えの規準に心から服従し、</span>
<span className="v" id="v18" data-v="18" data-xref="ローマ人への手紙 6:22; ローマ人への手紙 8:2; ガラテヤ人への手紙 5:1"> 罪から解放されて、義の奴隷となったのです。</span>
<span className="v" id="v19" data-v="19" data-xref="ローマ人への手紙 6:13; ペテロの手紙第一 4:2–4; コロサイ人への手紙 3:5–7"> あなたがたにある肉の弱さのために、私は人間的な言い方をしています。あなたがたは、以前は自分の手足を汚れと不法の奴隷としてささげて、不法に進みましたが、今は、その手足を義の奴隷としてささげて、聖潔に進みなさい。</span>
<span className="v" id="v20" data-v="20" data-xref="ローマ人への手紙 6:16–17; ヨハネの福音書 8:34"> 罪の奴隷であった時は、あなたがたは義については、自由にふるまっていました。</span>
<span className="v" id="v21" data-v="21" data-xref="ローマ人への手紙 1:32; ローマ人への手紙 7:5; ローマ人への手紙 6:23"> その当時、今ではあなたがたが恥じているそのようなものから、何か良い実を得たでしょうか。それらのものの行き着く所は死です。</span>
<span className="v" id="v22" data-v="22" data-xref="ペテロの手紙第一 2:16; ローマ人への手紙 6:18; ローマ人への手紙 8:2"> しかし今は、罪から解放されて神の奴隷となり、聖潔に至る実を得たのです。その行き着く所は永遠のいのちです。</span>
<span className="v" id="v23" data-v="23" data-xref="ヨハネの福音書 3:36; ローマ人への手紙 5:12; ヤコブの手紙 1:15"> 罪から来る報酬は死です。しかし、神の下さる賜物は、私たちの主キリスト・イエスにある永遠のいのちです。</span>

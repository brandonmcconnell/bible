<span className="v" id="v1" data-v="1" data-xref="ルカの福音書 23:24; Genesis 49:10; ルカの福音書 9:7"> 皇帝テベリオの治世の第十五年、ポンテオ・ピラトがユダヤの総督、ヘロデがガリラヤの国主、その兄弟ピリポがイツリヤとテラコニテ地方の国主、ルサニヤがアビレネの国主であり、</span>
<span className="v" id="v2" data-v="2" data-xref="使徒の働き 4:6; ヨハネの福音書 18:24; ルカの福音書 1:80"> アンナスとカヤパが大祭司であったころ、神のことばが、荒野でザカリヤの子ヨハネに下った。</span>
<span className="v" id="v3" data-v="3" data-xref="ルカの福音書 1:77; マタイの福音書 3:5–6; 使徒の働き 13:24"> そこでヨハネは、ヨルダン川のほとりのすべての地方に行って、罪が赦されるための悔い改めに基づくバプテスマを説いた。</span>
<span className="v" id="v4" data-v="4" data-xref="Isaiah 40:3–5; ヨハネの福音書 1:23; ルカの福音書 1:76–79"> そのことは預言者イザヤのことばの書に書いてあるとおりである。 「荒野で叫ぶ者の声がする。 『主の道を用意し、 主の通られる道をまっすぐにせよ。</span>
<span className="v" id="v5" data-v="5" data-xref="Isaiah 40:4; Isaiah 42:16; Isaiah 45:2"> すべての谷はうずめられ、 すべての山と丘とは低くされ、 曲がった所はまっすぐになり、 でこぼこ道は平らになる。</span>
<span className="v" id="v6" data-v="6" data-xref="Isaiah 52:10; Isaiah 40:5; Psalms 98:2–3"> こうして、あらゆる人が、 神の救いを見るようになる。』」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="マタイの福音書 23:33; マタイの福音書 12:34; テサロニケ人への手紙第一 1:10"> それで、ヨハネは、彼からバプテスマを受けようとして出て来た群衆に言った。「まむしのすえたち。だれが必ず来る御怒りをのがれるように教えたのか。</span>
<span className="v" id="v8" data-v="8" data-xref="Ezekiel 18:27–31; 使徒の働き 26:20; Isaiah 1:16–18"> それならそれで、悔い改めにふさわしい実を結びなさい。『われわれの先祖はアブラハムだ。』などと心の中で言い始めてはいけません。よく言っておくが、神は、こんな石ころからでも、アブラハムの子孫を起こすことがおできになるのです。</span>
<span className="v" id="v9" data-v="9" data-xref="マタイの福音書 7:19; ヨハネの福音書 15:6; ルカの福音書 13:9"> 斧もすでに木の根元に置かれています。だから、良い実を結ばない木は、みな切り倒されて、火に投げ込まれます。」</span>
<span className="v" id="v10" data-v="10" data-xref="使徒の働き 2:37; ルカの福音書 3:14; 使徒の働き 16:30"> 群衆はヨハネに尋ねた。「それでは、私たちはどうすればよいのでしょう。」</span>
<span className="v" id="v11" data-v="11" data-xref="Isaiah 58:7–11; ヨハネの手紙第一 3:17; テモテへの手紙第一 6:18"> 彼は答えて言った。「下着を二枚持っている者は、一つも持たない者に分けなさい。食べ物を持っている者も、そうしなさい。」</span>
<span className="v" id="v12" data-v="12" data-xref="ルカの福音書 7:29; ルカの福音書 15:1–2; ルカの福音書 18:13"> 取税人たちも、バプテスマを受けに出て来て、言った。「先生。私たちはどうすればよいのでしょう。」</span>
<span className="v" id="v13" data-v="13" data-xref="ルカの福音書 19:8; エペソ人への手紙 4:28; コリント人への手紙第一 6:10"> ヨハネは彼らに言った。「決められたもの以上には、何も取り立ててはいけません。」</span>
<span className="v" id="v14" data-v="14" data-xref="ヘブル人への手紙 13:5–6; Exodus 20:16; Exodus 23:1"> 兵士たちも、彼に尋ねて言った。「私たちはどうすればよいのでしょうか。」ヨハネは言った。「だれからも、力ずくで金をゆすったり、無実の者を責めたりしてはいけません。自分の給料で満足しなさい。」</span>
<span className="v" id="v15" data-v="15" data-xref="ヨハネの福音書 10:24; ヨハネの福音書 3:28–29; ヨハネの福音書 1:19–28"> 民衆は救い主を待ち望んでおり、みな心の中で、ヨハネについて、もしかするとこの方がキリストではあるまいか、と考えていたので、</span>
<span className="v" id="v16" data-v="16" data-xref="マタイの福音書 3:11; 使徒の働き 1:5; 使徒の働き 11:15–16"> ヨハネはみなに答えて言った。「私は水であなたがたにバプテスマを授けています。しかし、私よりもさらに力のある方がおいでになります。私などは、その方のくつのひもを解く値うちもありません。その方は、あなたがたに聖霊と火とのバプテスマをお授けになります。</span>
<span className="v" id="v17" data-v="17" data-xref="Jeremiah 15:7; マタイの福音書 13:30; Micah 4:12"> また手に箕を持って脱穀場をことごとくきよめ、麦を倉に納め、殻を消えない火で焼き尽くされます。」</span>
<span className="v" id="v18" data-v="18" data-xref="ヨハネの福音書 3:29–36; ヨハネの福音書 1:34; ヨハネの福音書 1:29"> ヨハネは、そのほかにも多くのことを教えて、民衆に福音を知らせた。</span>
<span className="v" id="v19" data-v="19" data-xref="ルカの福音書 3:1; マタイの福音書 11:2; マルコの福音書 6:17–18"> さて国主ヘロデは、その兄弟の妻ヘロデヤのことについて、また、自分の行なった悪事のすべてを、ヨハネに責められたので、</span>
<span className="v" id="v20" data-v="20" data-xref="2 Chronicles 24:17–22; ヨハネの福音書 3:24; テサロニケ人への手紙第一 2:15–16"> ヨハネを牢に閉じ込め、すべての悪事にもう一つこの悪事を加えた。</span>
<span className="v" id="v21" data-v="21" data-xref="ヨハネの福音書 1:32–34; マタイの福音書 3:13–17; ヨハネの福音書 12:27–28"> さて、民衆がみなバプテスマを受けていたころ、イエスもバプテスマをお受けになり、そして祈っておられると、天が開け、</span>
<span className="v" id="v22" data-v="22" data-xref="Psalms 2:7; ペテロの手紙第二 1:17–18; ヨハネの福音書 1:32"> 聖霊が、鳩のような形をして、自分の上に下られるのをご覧になった。また、天から声がした。「あなたは、わたしの愛する子、わたしはあなたを喜ぶ。」</span>
<span className="v" id="v23" data-v="23" data-xref="ルカの福音書 4:22; マタイの福音書 13:55; Numbers 4:3"> 教えを始められたとき、イエスはおよそ三十歳で、人々からヨセフの子と思われていた。このヨセフは、ヘリの子、順次さかのぼって、</span>
<span className="v" id="v24" data-v="24"> マタテの子、レビの子、メルキの子、ヤンナイの子、ヨセフの子、</span>
<span className="v" id="v25" data-v="25"> マタテヤの子、アモスの子、ナホムの子、エスリの子、ナンガイの子、</span>
<span className="v" id="v26" data-v="26"> マハテの子、マタテヤの子、シメイの子、ヨセクの子、ヨダの子、</span>
<span className="v" id="v27" data-v="27" data-xref="マタイの福音書 1:12"> ヨハナンの子、レサの子、ゾロバベルの子、サラテルの子、ネリの子、</span>
<span className="v" id="v28" data-v="28"> メルキの子、アデイの子、コサムの子、エルマダムの子、エルの子、</span>
<span className="v" id="v29" data-v="29"> ヨシュアの子、エリエゼルの子、ヨリムの子、マタテの子、レビの子、</span>
<span className="v" id="v30" data-v="30"> シメオンの子、ユダの子、ヨセフの子、ヨナムの子、エリヤキムの子、</span>
<span className="v" id="v31" data-v="31" data-xref="1 Chronicles 3:5; 2 Samuel 5:14; Zechariah 12:12"> メレヤの子、メナの子、マタタの子、ナタンの子、ダビデの子、</span>
<span className="v" id="v32" data-v="32" data-xref="Ruth 4:18–22; マタイの福音書 1:3–6; Isaiah 11:1–2"> エッサイの子、オベデの子、ボアズの子、サラの子、ナアソンの子、</span>
<span className="v" id="v33" data-v="33" data-xref="Ruth 4:19–20; Genesis 49:8; Genesis 38:29"> アミナダブの子、アデミンの子、アルニの子、エスロンの子、パレスの子、ユダの子、</span>
<span className="v" id="v34" data-v="34" data-xref="Genesis 21:3; Joshua 24:2; 1 Chronicles 1:24–28"> ヤコブの子、イサクの子、アブラハムの子、テラの子、ナホルの子、</span>
<span className="v" id="v35" data-v="35" data-xref="Genesis 11:12–21; Genesis 10:24–25"> セルグの子、レウの子、ペレグの子、エベルの子、サラの子、</span>
<span className="v" id="v36" data-v="36" data-xref="Genesis 5:28–32; Genesis 10:21–22; Genesis 9:1"> カイナンの子、アルパクサデの子、セムの子、ノアの子、ラメクの子、</span>
<span className="v" id="v37" data-v="37" data-xref="1 Chronicles 1:1–3; Genesis 5:6–28"> メトセラの子、エノクの子、ヤレデの子、マハラレルの子、カイナンの子、</span>
<span className="v" id="v38" data-v="38" data-xref="Genesis 2:7; Isaiah 64:8; コリント人への手紙第一 15:45"> エノスの子、セツの子、アダムの子、このアダムは神の子である。</span>

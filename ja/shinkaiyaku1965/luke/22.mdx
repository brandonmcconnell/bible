<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="Exodus 12:6–23; マタイの福音書 26:2–5; ヨハネの福音書 11:55–57"> さて、過越の祭りといわれる、種なしパンの祝いが近づいていた。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネの福音書 11:47–53; マタイの福音書 12:14; ルカの福音書 20:19"> 祭司長、律法学者たちは、イエスを殺すための良い方法を捜していた。というのは、彼らは民衆を恐れていたからである。</span>
<span className="v" id="v3" data-v="3" data-xref="ヨハネの福音書 13:2; マルコの福音書 14:10–11; ヨハネの福音書 13:26–27"> さて、十二弟子のひとりで、イスカリオテと呼ばれるユダに、サタンがはいった。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒の働き 4:1; 使徒の働き 5:24; ルカの福音書 22:52"> ユダは出かけて行って、祭司長たちや宮の守衛長たちと、どのようにしてイエスを彼らに引き渡そうかと相談した。</span>
<span className="v" id="v5" data-v="5" data-xref="マタイの福音書 26:15–16; 使徒の働き 1:18; マタイの福音書 27:3–5"> 彼らは喜んで、ユダに金をやる約束をした。</span>
<span className="v" id="v6" data-v="6" data-xref="マルコの福音書 14:2; マタイの福音書 26:5"> ユダは承知した。そして群衆のいないときにイエスを彼らに引き渡そうと機会をねらっていた。</span>
<span className="v" id="v7" data-v="7" data-xref="Exodus 12:18; マルコの福音書 14:12–16; コリント人への手紙第一 5:7"> さて、過越の小羊のほふられる、種なしパンの日が来た。</span>
<span className="v" id="v8" data-v="8" data-xref="マルコの福音書 14:13–16; 使徒の働き 4:19; 使徒の働き 4:13"> イエスは、こう言ってペテロとヨハネを遣わされた。「わたしたちの過越の食事ができるように、準備をしに行きなさい。」</span>
<span className="v" id="v9" data-v="9"> 彼らはイエスに言った。「どこに準備しましょうか。」</span>
<span className="v" id="v10" data-v="10" data-xref="ヨハネの福音書 16:4; マタイの福音書 26:18–19; 使徒の働き 8:26–29"> イエスは言われた。「町にはいると、水がめを運んでいる男に会うから、その人がはいる家にまでついて行きなさい。</span>
<span className="v" id="v11" data-v="11" data-xref="ヨハネの福音書 11:28; ヨハネの黙示録 3:20; ルカの福音書 19:34"> そして、その家の主人に、『弟子たちといっしょに過越の食事をする客間はどこか、と先生があなたに言っておられる。』と言いなさい。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒の働き 16:14–15; 使徒の働き 1:13; ヨハネの福音書 2:25"> すると主人は、席が整っている二階の大広間を見せてくれます。そこで準備をしなさい。」</span>
<span className="v" id="v13" data-v="13" data-xref="ルカの福音書 21:33; ルカの福音書 19:32; ヨハネの福音書 2:5"> 彼らが出かけて見ると、イエスの言われたとおりであった。それで、彼らは過越の食事の用意をした。</span>
<span className="v" id="v14" data-v="14" data-xref="マタイの福音書 26:20; マルコの福音書 14:17; Deuteronomy 16:6–7"> さて時間になって、イエスは食卓に着かれ、使徒たちもイエスといっしょに席に着いた。</span>
<span className="v" id="v15" data-v="15" data-xref="ルカの福音書 12:50; ヨハネの福音書 4:34; ヨハネの福音書 17:1"> イエスは言われた。「わたしは、苦しみを受ける前に、あなたがたといっしょに、この過越の食事をすることをどんなに望んでいたことか。</span>
<span className="v" id="v16" data-v="16" data-xref="ルカの福音書 14:15; ヨハネの黙示録 19:9; ルカの福音書 22:30"> あなたがたに言いますが、過越が神の国において成就するまでは、わたしはもはや二度と過越の食事をすることはありません。」</span>
<span className="v" id="v17" data-v="17" data-xref="ルカの福音書 22:19; Psalms 116:13; Deuteronomy 8:10"> そしてイエスは、杯を取り、感謝をささげて後、言われた。「これを取って、互いに分けて飲みなさい。</span>
<span className="v" id="v18" data-v="18" data-xref="マタイの福音書 26:29; ルカの福音書 22:16; マルコの福音書 14:25"> あなたがたに言いますが、今から、神の国が来る時までは、わたしはもはや、ぶどうの実で造った物を飲むことはありません。」</span>
<span className="v" id="v19" data-v="19" data-xref="コリント人への手紙第一 11:23–29; コリント人への手紙第一 10:16; マルコの福音書 14:22–24"> それから、パンを取り、感謝をささげてから、裂いて、弟子たちに与えて言われた。「これは、あなたがたのために与える、わたしのからだです。わたしを覚えてこれを行ないなさい。」</span>
<span className="v" id="v20" data-v="20" data-xref="マタイの福音書 26:28; コリント人への手紙第一 11:25; Zechariah 9:11"> 食事の後、杯も同じようにして言われた。「この杯は、あなたがたのために流されるわたしの血による新しい契約です。</span>
<span className="v" id="v21" data-v="21" data-xref="Psalms 41:9; ヨハネの福音書 13:26; ヨハネの福音書 13:21–22"> しかし、見なさい。わたしを裏切る者の手が、わたしとともに食卓にあります。</span>
<span className="v" id="v22" data-v="22" data-xref="使徒の働き 2:23; Psalms 109:6–15; Psalms 55:12–15"> 人の子は、定められたとおりに去って行きます。しかし、人の子を裏切るような人間はのろわれます。」</span>
<span className="v" id="v23" data-v="23" data-xref="ヨハネの福音書 13:22–25; マルコの福音書 14:19; マタイの福音書 26:22"> そこで弟子たちは、そんなことをしようとしている者は、いったいこの中のだれなのかと、互いに議論をし始めた。</span>
<span className="v" id="v24" data-v="24" data-xref="ルカの福音書 9:46; マルコの福音書 9:34; マルコの福音書 10:37–41"> また、彼らの間には、この中でだれが一番偉いだろうかという論議も起こった。</span>
<span className="v" id="v25" data-v="25" data-xref="マタイの福音書 20:25–28; マルコの福音書 10:41–45"> すると、イエスは彼らに言われた。「異邦人の王たちは人々を支配し、また人々の上に権威を持つ者は守護者と呼ばれています。</span>
<span className="v" id="v26" data-v="26" data-xref="ペテロの手紙第一 5:5; ルカの福音書 9:48; マタイの福音書 18:3–5"> だが、あなたがたは、それではいけません。あなたがたの間で一番偉い人は一番年の若い者のようになりなさい。また、治める人は仕える人のようでありなさい。</span>
<span className="v" id="v27" data-v="27" data-xref="マタイの福音書 20:28; ルカの福音書 12:37; ヨハネの福音書 13:5–16"> 食卓に着く人と給仕する者と、どちらが偉いでしょう。むろん、食卓に着く人でしょう。しかしわたしは、あなたがたのうちにあって給仕する者のようにしています。</span>
<span className="v" id="v28" data-v="28" data-xref="ヘブル人への手紙 2:18; ヘブル人への手紙 4:15; 使徒の働き 1:25"> けれども、あなたがたこそ、わたしのさまざまの試練の時にも、わたしについて来てくれた人たちです。</span>
<span className="v" id="v29" data-v="29" data-xref="マタイの福音書 25:34; テモテへの手紙第二 2:12; ヤコブの手紙 2:5"> わたしの父がわたしに王権を与えてくださったように、わたしもあなたがたに王権を与えます。</span>
<span className="v" id="v30" data-v="30" data-xref="マタイの福音書 19:28; マタイの福音書 8:11; ヨハネの黙示録 2:26–27"> それであなたがたは、わたしの国でわたしの食卓に着いて食事をし、王座に着いて、イスラエルの十二の部族をさばくのです。</span>
<span className="v" id="v31" data-v="31" data-xref="ペテロの手紙第一 5:8; Zechariah 3:1; Job 1:6–12"> シモン、シモン。見なさい。サタンが、あなたがたを麦のようにふるいにかけることを願って聞き届けられました。</span>
<span className="v" id="v32" data-v="32" data-xref="ペテロの手紙第一 5:8–10; ヨハネの福音書 21:15–17; ヨハネの福音書 17:9–11"> しかし、わたしは、あなたの信仰がなくならないように、あなたのために祈りました。だからあなたは、立ち直ったら、兄弟たちを力づけてやりなさい。」</span>
<span className="v" id="v33" data-v="33" data-xref="マルコの福音書 14:31; マタイの福音書 26:33–35; マルコの福音書 14:29"> シモンはイエスに言った。「主よ。ごいっしょになら、牢であろうと、死であろうと、覚悟はできております。」</span>
<span className="v" id="v34" data-v="34" data-xref="ヨハネの福音書 13:38; マタイの福音書 26:34; マルコの福音書 14:30"> しかし、イエスは言われた。「ペテロ。あなたに言いますが、きょう鶏が鳴くまでに、あなたは三度、わたしを知らないと言います。」</span>
<span className="v" id="v35" data-v="35" data-xref="マタイの福音書 10:9–10; ルカの福音書 10:4; Psalms 23:1"> それから、弟子たちに言われた。「わたしがあなたがたを、財布も旅行袋もくつも持たせずに旅に出したとき、何か足りない物がありましたか。」彼らは言った。「いいえ。何もありませんでした。」</span>
<span className="v" id="v36" data-v="36" data-xref="マタイの福音書 10:22–25; テサロニケ人への手紙第一 3:4; テサロニケ人への手紙第一 2:14–15"> そこで言われた。「しかし、今は、財布のある者は財布を持ち、同じく袋を持ち、剣のない者は着物を売って剣を買いなさい。</span>
<span className="v" id="v37" data-v="37" data-xref="Isaiah 53:12; ルカの福音書 23:32; コリント人への手紙第二 5:21"> あなたがたに言いますが、『彼は罪人たちの中に数えられた。』と書いてあるこのことが、わたしに必ず実現するのです。わたしにかかわることは実現します。」</span>
<span className="v" id="v38" data-v="38" data-xref="ルカの福音書 22:49; マタイの福音書 26:52–54; ヨハネの福音書 18:36"> 彼らは言った。「主よ。このとおり、ここに剣が二振りあります。」イエスは彼らに、「それで十分。」と言われた。</span>
<span className="v" id="v39" data-v="39" data-xref="ルカの福音書 21:37; ヨハネの福音書 18:1–2; マタイの福音書 21:1"> それからイエスは出て、いつものようにオリーブ山に行かれ、弟子たちも従った。</span>
<span className="v" id="v40" data-v="40" data-xref="マタイの福音書 6:13; マタイの福音書 26:36–46; ルカの福音書 22:46"> いつもの場所に着いたとき、イエスは彼らに、「誘惑に陥らないように祈っていなさい。」と言われた。</span>
<span className="v" id="v41" data-v="41" data-xref="マタイの福音書 26:39; マルコの福音書 14:35; ルカの福音書 18:11"> そしてご自分は、弟子たちから石を投げて届くほどの所に離れて、ひざまずいて、こう祈られた。</span>
<span className="v" id="v42" data-v="42" data-xref="ヨハネの福音書 12:27–28; マタイの福音書 26:39; マタイの福音書 26:42"> 「父よ。みこころならば、この杯をわたしから取りのけてください。しかし、わたしの願いではなく、みこころのとおりにしてください。」</span>
<span className="v" id="v43" data-v="43" data-xref="マタイの福音書 4:11; マタイの福音書 26:53; Psalms 91:11–12"> すると、御使いが天からイエスに現われて、イエスを力づけた。</span>
<span className="v" id="v44" data-v="44" data-xref="Lamentations 1:12; ヘブル人への手紙 5:7; Psalms 22:12–21"> イエスは、苦しみもだえて、いよいよ切に祈られた。汗が血のしずくのように地に落ちた。</span>
<span className="v" id="v45" data-v="45" data-xref="マルコの福音書 14:40–41; マタイの福音書 26:43; マタイの福音書 26:40"> イエスは祈り終わって立ち上がり、弟子たちのところに来て見ると、彼らは悲しみの果てに、眠り込んでしまっていた。</span>
<span className="v" id="v46" data-v="46" data-xref="ルカの福音書 22:40; Jonah 1:6; ルカの福音書 21:34–36"> それで、彼らに言われた。「なぜ、眠っているのか。起きて、誘惑に陥らないように祈っていなさい。」</span>
<span className="v" id="v47" data-v="47" data-xref="マルコの福音書 14:41–50; ヨハネの福音書 18:2–11; ルカの福音書 22:3–6"> イエスがまだ話をしておられるとき、群衆がやって来た。十二弟子のひとりで、ユダという者が、先頭に立っていた。ユダはイエスに口づけしようとして、みもとに近づいた。</span>
<span className="v" id="v48" data-v="48" data-xref="マルコの福音書 14:44–46; 2 Samuel 20:9–10; Proverbs 27:6"> だが、イエスは彼に、「ユダ。口づけで、人の子を裏切ろうとするのか。」と言われた。</span>
<span className="v" id="v49" data-v="49" data-xref="ルカの福音書 22:38"> イエスの回りにいた者たちは、事の成り行きを見て、「主よ。剣で撃ちましょうか。」と言った。</span>
<span className="v" id="v50" data-v="50" data-xref="ヨハネの福音書 18:10–11; マルコの福音書 14:47; ローマ人への手紙 12:19"> そしてそのうちのある者が、大祭司のしもべに撃ってかかり、その右の耳を切り落とした。</span>
<span className="v" id="v51" data-v="51" data-xref="ローマ人への手紙 12:21; コリント人への手紙第二 10:1; ペテロの手紙第一 2:21–23"> するとイエスは、「やめなさい。それまで。」と言われた。そして、耳にさわって彼を直してやられた。</span>
<span className="v" id="v52" data-v="52" data-xref="ルカの福音書 22:4; マルコの福音書 14:48–49; ヨハネの福音書 17:12"> そして押しかけて来た祭司長、宮の守衛長、長老たちに言われた。「まるで強盗にでも向かうように、剣や棒を持ってやって来たのですか。</span>
<span className="v" id="v53" data-v="53" data-xref="ヨハネの福音書 12:27; エペソ人への手紙 6:12; 使徒の働き 26:18"> あなたがたは、わたしが毎日宮でいっしょにいる間は、わたしに手出しもしなかった。しかし、今はあなたがたの時です。暗やみの力です。」</span>
<span className="v" id="v54" data-v="54" data-xref="マルコの福音書 14:53–54; マタイの福音書 26:57–58; ヨハネの福音書 18:12–17"> 彼らはイエスを捕え、引いて行って、大祭司の家に連れて来た。ペテロは、遠く離れてついて行った。</span>
<span className="v" id="v55" data-v="55" data-xref="Psalms 26:4–5; コリント人への手紙第二 6:15–17; マルコの福音書 14:66–72"> 彼らは中庭の真中に火をたいて、みなすわり込んだので、ペテロも中に混じって腰をおろした。</span>
<span className="v" id="v56" data-v="56" data-xref="ヨハネの福音書 18:17; マルコの福音書 14:6; マルコの福音書 14:17"> すると、女中が、火あかりの中にペテロのすわっているのを見つけ、まじまじと見て言った。「この人も、イエスといっしょにいました。」</span>
<span className="v" id="v57" data-v="57" data-xref="ヨハネの手紙第一 1:9; ヨハネの福音書 18:25; マタイの福音書 26:70"> ところが、ペテロはそれを打ち消して、「いいえ、私はあの人を知りません。」と言った。</span>
<span className="v" id="v58" data-v="58" data-xref="ヨハネの福音書 18:25; マタイの福音書 26:71–72; マルコの福音書 14:69–70"> しばらくして、ほかの男が彼を見て、「あなたも、彼らの仲間だ。」と言った。しかし、ペテロは、「いや、違います。」と言った。</span>
<span className="v" id="v59" data-v="59" data-xref="ヨハネの福音書 18:26–27; マルコの福音書 14:69–70; マタイの福音書 26:73–74"> それから一時間ほどたつと、また別の男が、「確かにこの人も彼といっしょだった。この人もガリラヤ人だから。」と言い張った。</span>
<span className="v" id="v60" data-v="60" data-xref="マタイの福音書 26:74–75; ルカの福音書 22:34; マルコの福音書 14:71–72"> しかしペテロは、「あなたの言うことは私にはわかりません。」と言った。それといっしょに、彼がまだ言い終えないうちに、鶏が鳴いた。</span>
<span className="v" id="v61" data-v="61" data-xref="ルカの福音書 22:34; Isaiah 57:15–18; Jeremiah 31:18–20"> 主が振り向いてペテロを見つめられた。ペテロは、「きょう、鶏が鳴くまでに、あなたは、三度わたしを知らないと言う。」と言われた主のおことばを思い出した。</span>
<span className="v" id="v62" data-v="62" data-xref="マタイの福音書 26:75; コリント人への手紙第一 10:12; マルコの福音書 14:72"> 彼は、外に出て、激しく泣いた。</span>
<span className="v" id="v63" data-v="63" data-xref="ヨハネの福音書 18:22; マルコの福音書 14:55–65; Job 16:9–10"> さて、イエスの監視人どもは、イエスをからかい、むちでたたいた。</span>
<span className="v" id="v64" data-v="64" data-xref="Judges 16:25; Judges 16:21"> そして目隠しをして、「言い当ててみろ。今たたいたのはだれか。」と聞いたりした。</span>
<span className="v" id="v65" data-v="65" data-xref="ルカの福音書 12:10; マタイの福音書 12:31–32; マタイの福音書 27:39"> また、そのほかさまざまな悪口をイエスに浴びせた。</span>
<span className="v" id="v66" data-v="66" data-xref="マタイの福音書 27:1; マルコの福音書 15:1; 使徒の働き 22:5"> 夜が明けると、民の長老会、それに祭司長、律法学者たちが、集まった。彼らはイエスを議会に連れ出し、</span>
<span className="v" id="v67" data-v="67" data-xref="マタイの福音書 11:3–5; ヨハネの福音書 8:43–45; マタイの福音書 26:63–68"> こう言った。「あなたがキリストなら、そうだと言いなさい。」しかしイエスは言われた。「わたしが言っても、あなたがたは決して信じないでしょうし、</span>

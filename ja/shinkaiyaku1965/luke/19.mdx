<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="Joshua 6:1–27; ルカの福音書 18:35; 2 Kings 2:18–22"> それからイエスは、エリコにはいって、町をお通りになった。</span>
<span className="v" id="v2" data-v="2" data-xref="ルカの福音書 18:24–27; 2 Chronicles 17:5–6"> ここには、ザアカイという人がいたが、彼は取税人のかしらで、金持ちであった。</span>
<span className="v" id="v3" data-v="3" data-xref="ルカの福音書 23:8; ルカの福音書 9:7–9; ヨハネの福音書 12:21"> 彼は、イエスがどんな方か見ようとしたが、背が低かったので、群衆のために見ることができなかった。</span>
<span className="v" id="v4" data-v="4" data-xref="Isaiah 9:10; ルカの福音書 5:19; 1 Kings 10:27"> それで、イエスを見るために、前方に走り出て、いちじく桑の木に登った。ちょうどイエスがそこを通り過ぎようとしておられたからである。</span>
<span className="v" id="v5" data-v="5" data-xref="ヨハネの黙示録 3:20; ヨハネの福音書 14:23; ヘブル人への手紙 13:2"> イエスは、ちょうどそこに来られて、上を見上げて彼に言われた。「ザアカイ。急いで降りて来なさい。きょうは、あなたの家に泊まることにしてあるから。」</span>
<span className="v" id="v6" data-v="6" data-xref="ルカの福音書 5:29; 使徒の働き 16:34; 使徒の働き 16:15"> ザアカイは、急いで降りて来て、そして大喜びでイエスを迎えた。</span>
<span className="v" id="v7" data-v="7" data-xref="ルカの福音書 15:2; ルカの福音書 7:39; ルカの福音書 7:34"> これを見て、みなは、「あの方は罪人のところに行って客となられた。」と言ってつぶやいた。</span>
<span className="v" id="v8" data-v="8" data-xref="2 Samuel 12:6; Numbers 5:7; ルカの福音書 18:22–23"> ところがザアカイは立って、主に言った。「主よ。ご覧ください。私の財産の半分を貧しい人たちに施します。また、だれからでも、私がだまし取った物は、四倍にして返します。」</span>
<span className="v" id="v9" data-v="9" data-xref="ガラテヤ人への手紙 3:7; ルカの福音書 13:16; ローマ人への手紙 4:16"> イエスは、彼に言われた。「きょう、救いがこの家に来ました。この人もアブラハムの子なのですから。</span>
<span className="v" id="v10" data-v="10" data-xref="Ezekiel 34:16; マタイの福音書 1:21; テモテへの手紙第一 1:13–16"> 人の子は、失われた人を捜して救うために来たのです。」</span>
<span className="v" id="v11" data-v="11" data-xref="ルカの福音書 17:20; 使徒の働き 1:6; テサロニケ人への手紙第二 2:1–3"> 人々がこれらのことに耳を傾けているとき、イエスは、続けて一つのたとえを話された。それは、イエスがエルサレムに近づいておられ、そのため人々は神の国がすぐにでも現われるように思っていたからである。</span>
<span className="v" id="v12" data-v="12" data-xref="マタイの福音書 25:14–30; ルカの福音書 19:12–27; ルカの福音書 20:9"> それで、イエスはこう言われた。 「ある身分の高い人が、遠い国に行った。王位を受けて帰るためであった。</span>
<span className="v" id="v13" data-v="13" data-xref="マタイの福音書 25:14–15; ヨハネの福音書 12:26; コリント人への手紙第一 12:7–11"> 彼は自分の十人のしもべを呼んで、十ミナを与え、彼らに言った。『私が帰るまで、これで商売しなさい。』</span>
<span className="v" id="v14" data-v="14" data-xref="1 Samuel 8:7; 使徒の働き 7:51–52; 使徒の働き 3:14–15"> しかし、その国民たちは、彼を憎んでいたので、あとから使いをやり、『この人に、私たちの王にはなってもらいたくありません。』と言った。</span>
<span className="v" id="v15" data-v="15" data-xref="コリント人への手紙第一 4:1–5; ローマ人への手紙 14:10–12; Psalms 2:4–6"> さて、彼が王位を受けて帰って来たとき、金を与えておいたしもべたちがどんな商売をしたかを知ろうと思い、彼らを呼び出すように言いつけた。</span>
<span className="v" id="v16" data-v="16" data-xref="ヤコブの手紙 2:18–26; テモテへの手紙第二 4:7–8; コリント人への手紙第一 15:10"> さて、最初の者が現われて言った。『ご主人さま。あなたの一ミナで、十ミナをもうけました。』</span>
<span className="v" id="v17" data-v="17" data-xref="ルカの福音書 16:10; マタイの福音書 25:21; ヨハネの黙示録 2:26–29"> 主人は彼に言った。『よくやった。良いしもべだ。あなたはほんの小さな事にも忠実だったから、十の町を支配する者になりなさい。』</span>
<span className="v" id="v18" data-v="18" data-xref="マルコの福音書 4:20; マタイの福音書 13:23; コリント人への手紙第二 8:12"> 二番目の者が来て言った。『ご主人さま。あなたの一ミナで、五ミナをもうけました。』</span>
<span className="v" id="v19" data-v="19" data-xref="コリント人への手紙第一 15:58; コリント人への手紙第一 15:41–42; コリント人への手紙第一 3:8"> 主人はこの者にも言った。『あなたも五つの町を治めなさい。』</span>
<span className="v" id="v20" data-v="20" data-xref="マタイの福音書 25:24; Proverbs 26:13–16; ヤコブの手紙 4:17"> もうひとりが来て言った。『ご主人さま。さあ、ここにあなたの一ミナがございます。私はふろしきに包んでしまっておきました。</span>
<span className="v" id="v21" data-v="21" data-xref="マタイの福音書 25:24–25; ローマ人への手紙 8:7; ヨハネの手紙第一 4:18"> あなたは計算の細かい、きびしい方ですから、恐ろしゅうございました。あなたはお預けにならなかったものをも取り立て、お蒔きにならなかったものをも刈り取る方ですから。』</span>
<span className="v" id="v22" data-v="22" data-xref="2 Samuel 1:16; マタイの福音書 12:37; Job 15:5–6"> 主人はそのしもべに言った。『悪いしもべだ。私はあなたのことばによって、あなたをさばこう。あなたは、私が預けなかったものを取り立て、蒔かなかったものを刈り取るきびしい人間だと知っていた、というのか。</span>
<span className="v" id="v23" data-v="23" data-xref="Exodus 22:25–27; ローマ人への手紙 2:4–5; Deuteronomy 23:19–20"> だったら、なぜ私の金を銀行に預けておかなかったのか。そうすれば私は帰って来たときに、それを利息といっしょに受け取れたはずだ。』</span>
<span className="v" id="v24" data-v="24" data-xref="ルカの福音書 16:2; ルカの福音書 12:20"> そして、そばに立っていた者たちに言った。『その一ミナを彼から取り上げて、十ミナ持っている人にやりなさい。』</span>
<span className="v" id="v25" data-v="25" data-xref="ルカの福音書 16:2; 2 Samuel 7:19; Isaiah 55:8–9"> すると彼らは、『ご主人さま。その人は十ミナも持っています。』と言った。</span>
<span className="v" id="v26" data-v="26" data-xref="ヨハネの手紙第二 1:8; ルカの福音書 8:18; マタイの福音書 21:43"> 彼は言った。『あなたがたに言うが、だれでも持っている者は、さらに与えられ、持たない者からは、持っている物までも取り上げられるのです。</span>
<span className="v" id="v27" data-v="27" data-xref="ルカの福音書 19:14; Psalms 21:8–9; マタイの福音書 22:7"> ただ、私が王になるのを望まなかったこの敵どもは、みなここに連れて来て、私の目の前で殺してしまえ。』」</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="ルカの福音書 9:51; ヘブル人への手紙 12:2; ペテロの手紙第一 4:1"> これらのことを話して後、イエスは、さらに進んで、エルサレムへと上って行かれた。</span>
<span className="v" id="v29" data-v="29" data-xref="使徒の働き 1:12; マタイの福音書 21:17; マタイの福音書 21:1–11"> オリーブという山のふもとのベテパゲとベタニヤに近づかれたとき、イエスはふたりの弟子を使いに出して、</span>
<span className="v" id="v30" data-v="30" data-xref="ルカの福音書 22:8–13; ルカの福音書 19:32; 1 Samuel 10:2–9"> 言われた。「向こうの村に行きなさい。そこにはいると、まだだれも乗ったことのない、ろばの子がつないであるのに気がつくでしょう。それをほどいて連れて来なさい。</span>
<span className="v" id="v31" data-v="31" data-xref="Psalms 24:1; Psalms 50:10–12; マルコの福音書 11:3–6"> もし、『なぜ、ほどくのか。』と尋ねる人があったら、こう言いなさい。『主がお入用なのです。』」</span>
<span className="v" id="v32" data-v="32" data-xref="ルカの福音書 22:13"> 使いに出されたふたりが行って見ると、イエスが話されたとおりであった。</span>
<span className="v" id="v33" data-v="33"> 彼らがろばの子をほどいていると、その持ち主が、「なぜ、このろばの子をほどくのか。」と彼らに言った。</span>
<span className="v" id="v34" data-v="34" data-xref="Zechariah 9:9; ヨハネの福音書 10:35; コリント人への手紙第二 8:9"> 弟子たちは、「主がお入用なのです。」と言った。</span>
<span className="v" id="v35" data-v="35" data-xref="マルコの福音書 11:7–8; マタイの福音書 21:7; ヨハネの福音書 12:14"> そしてふたりは、それをイエスのもとに連れて来た。そして、そのろばの子の上に自分たちの上着を敷いて、イエスをお乗せした。</span>
<span className="v" id="v36" data-v="36" data-xref="2 Kings 9:13; マタイの福音書 21:8"> イエスが進んで行かれると、人々は道に自分たちの上着を敷いた。</span>
<span className="v" id="v37" data-v="37" data-xref="ヨハネの福音書 12:12–13; Ezra 3:10–13; マタイの福音書 21:1"> イエスがすでにオリーブ山のふもとに近づかれたとき、弟子たちの群れはみな、自分たちの見たすべての力あるわざのことで、喜んで大声に神を賛美し始め、</span>
<span className="v" id="v38" data-v="38" data-xref="Zechariah 9:9; ルカの福音書 13:35; Psalms 118:22–26"> こう言った。 「祝福あれ。 主の御名によって来られる王に。 天には平和。 栄光は、いと高き所に。」</span>
<span className="v" id="v39" data-v="39" data-xref="使徒の働き 4:1–2; マタイの福音書 23:13; 使徒の働き 4:16–18"> するとパリサイ人のうちのある者たちが、群衆の中から、イエスに向かって、「先生。お弟子たちをしかってください。」と言った。</span>
<span className="v" id="v40" data-v="40" data-xref="Habakkuk 2:11; Isaiah 55:12; マタイの福音書 3:9"> イエスは答えて言われた。「わたしは、あなたがたに言います。もしこの人たちが黙れば、石が叫びます。」</span>
<span className="v" id="v41" data-v="41" data-xref="ルカの福音書 13:34–35; ヨハネの福音書 11:35; Psalms 119:136"> エルサレムに近くなったころ、都を見られたイエスは、その都のために泣いて、</span>
<span className="v" id="v42" data-v="42" data-xref="Deuteronomy 32:29; ヘブル人への手紙 10:26–29; Isaiah 48:18"> 言われた。「おまえも、もし、この日のうちに、平和のことを知っていたのなら。しかし今は、そのことがおまえの目から隠されている。</span>
<span className="v" id="v43" data-v="43" data-xref="ルカの福音書 21:20–24; Isaiah 29:1–4; Ezekiel 4:2"> やがておまえの敵が、おまえに対して塁を築き、回りを取り巻き、四方から攻め寄せ、</span>
<span className="v" id="v44" data-v="44" data-xref="ルカの福音書 21:6; ルカの福音書 13:34–35; ヨハネの福音書 3:18–21"> そしておまえとその中の子どもたちを地にたたきつけ、おまえの中で、一つの石もほかの石の上に積まれたままでは残されない日が、やって来る。それはおまえが、神の訪れの時を知らなかったからだ。」</span>
<span className="v" id="v45" data-v="45" data-xref="マタイの福音書 21:12–13; マルコの福音書 11:15–17; ヨハネの福音書 2:13–17"> 宮にはいられたイエスは、商売人たちを追い出し始め、</span>
<span className="v" id="v46" data-v="46" data-xref="Isaiah 56:7; Jeremiah 7:11; Psalms 93:5"> こう言われた。「『わたしの家は、祈りの家でなければならない。』と書いてある。それなのに、あなたがたはそれを強盗の巣にした。」</span>
<span className="v" id="v47" data-v="47" data-xref="マルコの福音書 11:18; マタイの福音書 26:55; マルコの福音書 11:27–33"> イエスは毎日、宮で教えておられた。祭司長、律法学者、民のおもだった者たちは、イエスを殺そうとねらっていたが、</span>
<span className="v" id="v48" data-v="48" data-xref="Nehemiah 8:3; 使徒の働き 16:14; ヨハネの福音書 7:46–49"> どうしてよいかわからなかった。民衆がみな、熱心にイエスの話に耳を傾けていたからである。</span>

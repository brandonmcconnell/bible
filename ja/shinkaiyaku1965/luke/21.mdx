<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マルコの福音書 12:41–44; ヨハネの福音書 8:20; マタイの福音書 27:6"> さてイエスが、目を上げてご覧になると、金持ちたちが献金箱に献金を投げ入れていた。</span>
<span className="v" id="v2" data-v="2" data-xref="マルコの福音書 12:42"> また、ある貧しいやもめが、そこにレプタ銅貨二つを投げ入れているのをご覧になった。</span>
<span className="v" id="v3" data-v="3" data-xref="コリント人への手紙第二 8:12; 使徒の働き 10:34; コリント人への手紙第二 8:2–3"> それでイエスは言われた。「わたしは真実をあなたがたに告げます。この貧しいやもめは、どの人よりもたくさん投げ入れました。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒の働き 2:44–45; ルカの福音書 15:12; 使徒の働き 4:34"> みなは、あり余る中から献金を投げ入れたのに、この女は、乏しい中から、持っていた生活費の全部を投げ入れたからです。」</span>
<span className="v" id="v5" data-v="5" data-xref="ヨハネの福音書 2:20; マタイの福音書 24:1–51; マルコの福音書 13:1–37"> 宮がすばらしい石や奉納物で飾ってあると話していた人々があった。するとイエスはこう言われた。</span>
<span className="v" id="v6" data-v="6" data-xref="マタイの福音書 24:2; マルコの福音書 13:2; Lamentations 5:18"> 「あなたがたの見ているこれらの物について言えば、石がくずされずに積まれたまま残ることのない日がやって来ます。」</span>
<span className="v" id="v7" data-v="7" data-xref="使徒の働き 1:6–7; マルコの福音書 13:14; マルコの福音書 13:3–4"> 彼らは、イエスに質問して言った。「先生。それでは、これらのことは、いつ起こるのでしょう。これらのことが起こるときは、どんな前兆があるのでしょう。」</span>
<span className="v" id="v8" data-v="8" data-xref="ヨハネの手紙第一 4:1; マルコの福音書 13:5–6; エペソ人への手紙 5:6"> イエスは言われた。「惑わされないように気をつけなさい。わたしの名を名のる者が大ぜい現われ、『私がそれだ。』とか『時は近づいた。』とか言います。そんな人々のあとについて行ってはなりません。</span>
<span className="v" id="v9" data-v="9" data-xref="ルカの福音書 21:28; マタイの福音書 24:6–8; マルコの福音書 13:7–8"> 戦争や暴動のことを聞いても、こわがってはいけません。それは、初めに必ず起こることです。だが、終わりは、すぐには来ません。」</span>
<span className="v" id="v10" data-v="10" data-xref="使徒の働き 2:19–20; マルコの福音書 13:8; 2 Chronicles 15:5–6"> それから、イエスは彼らに言われた。「民族は民族に、国は国に敵対して立ち上がり、</span>
<span className="v" id="v11" data-v="11" data-xref="マタイの福音書 24:29–30; ルカの福音書 21:25–27"> 大地震があり、方々に疫病やききんが起こり、恐ろしいことや天からのすさまじい前兆が現われます。</span>
<span className="v" id="v12" data-v="12" data-xref="ペテロの手紙第一 4:12–14; 使徒の働き 5:40; 使徒の働き 22:30"> しかし、これらのすべてのことの前に、人々はあなたがたを捕えて迫害し、会堂や牢に引き渡し、わたしの名のために、あなたがたを王たちや総督たちの前に引き出すでしょう。</span>
<span className="v" id="v13" data-v="13" data-xref="ピリピ人への手紙 1:12; ピリピ人への手紙 1:28; テサロニケ人への手紙第二 1:5"> それはあなたがたのあかしをする機会となります。</span>
<span className="v" id="v14" data-v="14" data-xref="ルカの福音書 12:11–12; マルコの福音書 13:11; マタイの福音書 10:19–20"> それで、どう弁明するかは、あらかじめ考えないことに、心を定めておきなさい。</span>
<span className="v" id="v15" data-v="15" data-xref="Jeremiah 1:9; エペソ人への手紙 6:19; ルカの福音書 12:12"> どんな反対者も、反論もできず、反証もできないようなことばと知恵を、わたしがあなたがたに与えます。</span>
<span className="v" id="v16" data-v="16" data-xref="ルカの福音書 12:53; ヨハネの黙示録 6:9; Micah 7:5–6"> しかしあなたがたは、両親、兄弟、親族、友人たちにまで裏切られます。中には殺される者もあり、</span>
<span className="v" id="v17" data-v="17" data-xref="ヨハネの福音書 15:19; ルカの福音書 6:22; ヨハネの福音書 15:21"> わたしの名のために、みなの者に憎まれます。</span>
<span className="v" id="v18" data-v="18" data-xref="マタイの福音書 10:30; 1 Samuel 14:45; ルカの福音書 12:7"> しかし、あなたがたの髪の毛一筋も失われることはありません。</span>
<span className="v" id="v19" data-v="19" data-xref="ヘブル人への手紙 10:36; マタイの福音書 10:22; ヤコブの手紙 1:3"> あなたがたは、忍耐によって、自分のいのちを勝ち取ることができます。</span>
<span className="v" id="v20" data-v="20" data-xref="ルカの福音書 19:43; Daniel 9:27; マルコの福音書 13:14"> しかし、エルサレムが軍隊に囲まれるのを見たら、そのときには、その滅亡が近づいたことを悟りなさい。</span>
<span className="v" id="v21" data-v="21" data-xref="Jeremiah 6:1; Genesis 19:17; ルカの福音書 17:31–33"> そのとき、ユダヤにいる人々は山へ逃げなさい。都の中にいる人々は、そこから立ちのきなさい。いなかにいる者たちは、都にはいってはいけません。</span>
<span className="v" id="v22" data-v="22" data-xref="Hosea 9:7; Isaiah 65:12–16; Isaiah 63:4"> これは、書かれているすべてのことが成就する報復の日だからです。</span>
<span className="v" id="v23" data-v="23" data-xref="マルコの福音書 13:17; マタイの福音書 24:19; ルカの福音書 23:29"> その日、悲惨なのは身重の女と乳飲み子を持つ女です。この地に大きな苦難が臨み、この民に御怒りが臨むからです。</span>
<span className="v" id="v24" data-v="24" data-xref="ローマ人への手紙 11:25; ヨハネの黙示録 11:2; Isaiah 63:18"> 人々は、剣の刃に倒れ、捕虜となってあらゆる国に連れて行かれ、異邦人の時の終わるまで、エルサレムは異邦人に踏み荒らされます。</span>
<span className="v" id="v25" data-v="25" data-xref="Isaiah 13:10; Joel 2:30–31; ヨハネの黙示録 6:12–14"> そして、日と月と星には、前兆が現われ、地上では、諸国の民が、海と波が荒れどよめくために不安に陥って悩み、</span>
<span className="v" id="v26" data-v="26" data-xref="マタイの福音書 24:29; Deuteronomy 28:65–67; ペテロの手紙第二 3:10–12"> 人々は、その住むすべての所を襲おうとしていることを予想して、恐ろしさのあまり気を失います。天の万象が揺り動かされるからです。</span>
<span className="v" id="v27" data-v="27" data-xref="マタイの福音書 24:30; ヨハネの黙示録 1:7; マルコの福音書 13:26"> そのとき、人々は、人の子が力と輝かしい栄光を帯びて雲に乗って来るのを見るのです。</span>
<span className="v" id="v28" data-v="28" data-xref="ローマ人への手紙 8:23; Isaiah 60:1–2; エペソ人への手紙 4:30"> これらのことが起こり始めたなら、からだをまっすぐにし、頭を上に上げなさい。贖いが近づいたのです。」</span>
<span className="v" id="v29" data-v="29" data-xref="マタイの福音書 24:32–35; マルコの福音書 13:28–30"> それからイエスは、人々にたとえを話された。「いちじくの木や、すべての木を見なさい。</span>
<span className="v" id="v30" data-v="30" data-xref="ルカの福音書 12:57"> 木の芽が出ると、それを見て夏の近いことがわかります。</span>
<span className="v" id="v31" data-v="31" data-xref="ヤコブの手紙 5:9; ヘブル人への手紙 10:37; ペテロの手紙第一 4:7"> そのように、これらのことが起こるのを見たら、神の国は近いと知りなさい。</span>
<span className="v" id="v32" data-v="32" data-xref="マルコの福音書 13:30; マタイの福音書 24:34; マタイの福音書 23:36"> まことに、あなたがたに告げます。すべてのことが起こってしまうまでは、この時代は過ぎ去りません。</span>
<span className="v" id="v33" data-v="33" data-xref="Isaiah 40:8; マルコの福音書 13:31; マタイの福音書 24:35"> この天地は滅びます。しかし、わたしのことばは決して滅びることがありません。</span>
<span className="v" id="v34" data-v="34" data-xref="マルコの福音書 4:19; ルカの福音書 12:45–46; ルカの福音書 12:40"> あなたがたの心が、放蕩や深酒やこの世の煩いのために沈み込んでいるところに、その日がわなのように、突然あなたがたに臨むことのないように、よく気をつけていなさい。</span>
<span className="v" id="v35" data-v="35" data-xref="ヨハネの黙示録 16:15; Psalms 11:6; Jeremiah 48:43–44"> その日は、全地の表に住むすべての人に臨むからです。</span>
<span className="v" id="v36" data-v="36" data-xref="ヨハネの手紙第一 2:28; マタイの福音書 25:13; ペテロの手紙第一 5:8"> しかし、あなたがたは、やがて起ころうとしているこれらすべてのことからのがれ、人の子の前に立つことができるように、いつも油断せずに祈っていなさい。」</span>
<span className="v" id="v37" data-v="37" data-xref="ルカの福音書 22:39; マルコの福音書 11:19; マタイの福音書 21:17"> さてイエスは、昼は宮で教え、夜はいつも外に出てオリーブという山で過ごされた。</span>
<span className="v" id="v38" data-v="38" data-xref="ヨハネの福音書 8:1–2"> 民衆はみな朝早く起きて、教えを聞こうとして、宮におられるイエスのもとに集まって来た。</span>

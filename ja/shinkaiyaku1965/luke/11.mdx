<span className="v" id="v1" data-v="1" data-xref="Psalms 19:14; ルカの福音書 22:39–45; ローマ人への手紙 8:26–27"> さて、イエスはある所で祈っておられた。その祈りが終わると、弟子のひとりが、イエスに言った。「主よ。ヨハネが弟子たちに教えたように、私たちにも祈りを教えてください。」</span>
<span className="v" id="v2" data-v="2" data-xref="マタイの福音書 6:6–15; Ecclesiastes 5:2; Psalms 72:18–19"> そこでイエスは、彼らに言われた。「祈るときには、こう言いなさい。 『父よ。御名があがめられますように。 御国が来ますように。</span>
<span className="v" id="v3" data-v="3" data-xref="マタイの福音書 6:11; マタイの福音書 6:34; Proverbs 30:8"> 私たちの日ごとの糧を毎日お与えください。</span>
<span className="v" id="v4" data-v="4" data-xref="マタイの福音書 6:12–15; マタイの福音書 26:41; Isaiah 43:25–26"> 私たちの罪をお赦しください。私たちも私たちに負いめのある者をみな赦します。 私たちを試みに会わせないでください。』」</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="ルカの福音書 18:1–8"> また、イエスはこう言われた。「あなたがたのうち、だれかに友だちがいるとして、真夜中にその人のところに行き、『君。パンを三つ貸してくれ。</span>
<span className="v" id="v6" data-v="6"> 友人が旅の途中、私のうちへ来たのだが、出してやるものがないのだ。』と言ったとします。</span>
<span className="v" id="v7" data-v="7" data-xref="ルカの福音書 13:25; ガラテヤ人への手紙 6:17; ルカの福音書 7:6"> すると、彼は家の中からこう答えます。『めんどうをかけないでくれ。もう戸締まりもしてしまったし、子どもたちも私も寝ている。起きて、何かをやることはできない。』</span>
<span className="v" id="v8" data-v="8" data-xref="Genesis 32:26; コロサイ人への手紙 4:12; ローマ人への手紙 15:30"> あなたがたに言いますが、彼は友だちだからということで起きて何かを与えることはしないにしても、あくまで頼み続けるなら、そのためには起き上がって、必要な物を与えるでしょう。</span>
<span className="v" id="v9" data-v="9" data-xref="マルコの福音書 11:24; ヨハネの福音書 16:23–24; マタイの福音書 21:22"> わたしは、あなたがたに言います。求めなさい。そうすれば与えられます。捜しなさい。そうすれば見つかります。たたきなさい。そうすれば開かれます。</span>
<span className="v" id="v10" data-v="10" data-xref="ヤコブの手紙 4:3; Lamentations 3:54–58; Psalms 31:22"> だれであっても、求める者は受け、捜す者は見つけ出し、たたく者には開かれます。</span>
<span className="v" id="v11" data-v="11" data-xref="マタイの福音書 7:9; Isaiah 49:15"> あなたがたの中で、子どもが魚を下さいと言うときに、魚の代わりに蛇を与えるような父親が、いったいいるでしょうか。</span>
<span className="v" id="v12" data-v="12" data-xref="ヨハネの黙示録 9:10; ルカの福音書 10:19; Ezekiel 2:6"> 卵を下さいと言うのに、だれが、さそりを与えるでしょう。</span>
<span className="v" id="v13" data-v="13" data-xref="マタイの福音書 7:11; Isaiah 44:3–4; ローマ人への手紙 8:32"> してみると、あなたがたも、悪い者ではあっても、自分の子どもには良い物を与えることを知っているのです。とすれば、なおのこと、天の父が、求める人たちに、どうして聖霊を下さらないことがありましょう。」</span>
<span className="v" id="v14" data-v="14" data-xref="マタイの福音書 12:22–24; マタイの福音書 9:32–34; マルコの福音書 7:32–37"> イエスは悪霊、それもおしの悪霊を追い出しておられた。悪霊が出て行くと、おしがものを言い始めたので、群衆は驚いた。</span>
<span className="v" id="v15" data-v="15" data-xref="マタイの福音書 9:34; マタイの福音書 12:24–30; ヨハネの福音書 8:48"> しかし、彼らのうちには、「悪霊どものかしらベルゼブルによって、悪霊どもを追い出しているのだ。」と言う者もいた。</span>
<span className="v" id="v16" data-v="16" data-xref="ヨハネの福音書 6:30; コリント人への手紙第一 1:22; マルコの福音書 8:11–12"> また、イエスをためそうとして、彼に天からのしるしを求める者もいた。</span>
<span className="v" id="v17" data-v="17" data-xref="マルコの福音書 3:23–27; マタイの福音書 12:25–29; Isaiah 19:2–3"> しかし、イエスは、彼らの心を見抜いて言われた。「どんな国でも、内輪もめしたら荒れすたれ、家にしても、内輪で争えばつぶれます。</span>
<span className="v" id="v18" data-v="18" data-xref="マタイの福音書 12:26; マタイの福音書 12:31–34; ルカの福音書 11:15"> サタンも、もし仲間割れしたのだったら、どうしてサタンの国が立ち行くことができましょう。それなのにあなたがたは、わたしがベルゼブルによって悪霊どもを追い出していると言います。</span>
<span className="v" id="v19" data-v="19" data-xref="ルカの福音書 9:49; Job 15:6; ローマ人への手紙 3:19"> もしもわたしが、ベルゼブルによって悪霊どもを追い出しているのなら、あなたがたの仲間は、だれによって追い出すのですか。だから、あなたがたの仲間が、あなたがたをさばく人となるのです。</span>
<span className="v" id="v20" data-v="20" data-xref="Exodus 8:19; マタイの福音書 12:28; ルカの福音書 10:9"> しかし、わたしが、神の指によって悪霊どもを追い出しているのなら、神の国はあなたがたに来ているのです。</span>
<span className="v" id="v21" data-v="21" data-xref="マルコの福音書 3:27; マタイの福音書 12:29"> 強い人が十分に武装して自分の家を守っているときには、その持ち物は安全です。</span>
<span className="v" id="v22" data-v="22" data-xref="Isaiah 49:24–25; Isaiah 53:12; ヨハネの手紙第一 3:8"> しかし、もっと強い者が襲って来て彼に打ち勝つと、彼の頼みにしていた武具を奪い、分捕り品を分けます。</span>
<span className="v" id="v23" data-v="23" data-xref="マタイの福音書 12:30; ルカの福音書 9:50; マルコの福音書 9:40"> わたしの味方でない者はわたしに逆らう者であり、わたしとともに集めない者は散らす者です。</span>
<span className="v" id="v24" data-v="24" data-xref="マタイの福音書 12:43–45; ペテロの手紙第一 5:8; Job 2:2"> 汚れた霊が人から出て行って、水のない所をさまよいながら、休み場を捜します。一つも見つからないので、『出て来た自分の家に帰ろう。』と言います。</span>
<span className="v" id="v25" data-v="25" data-xref="テサロニケ人への手紙第二 2:9–12; ペテロの手紙第二 2:10–19; ユダの手紙 1:8–13"> 帰って見ると、家は、掃除をしてきちんとかたづいていました。</span>
<span className="v" id="v26" data-v="26" data-xref="ヨハネの福音書 5:14; マタイの福音書 12:45; ペテロの手紙第二 2:20–22"> そこで、出かけて行って、自分よりも悪いほかの霊を七つ連れて来て、みなはいり込んでそこに住みつくのです。そうなると、その人の後の状態は、初めよりもさらに悪くなります。」</span>
<span className="v" id="v27" data-v="27" data-xref="ルカの福音書 1:42; ルカの福音書 1:48; ルカの福音書 23:29"> イエスが、これらのことを話しておられると、群衆の中から、ひとりの女が声を張り上げてイエスに言った。「あなたを産んだ腹、あなたが吸った乳房は幸いです。」</span>
<span className="v" id="v28" data-v="28" data-xref="ルカの福音書 6:47–48; ルカの福音書 8:21; Psalms 112:1"> しかし、イエスは言われた。「いや、幸いなのは、神のことばを聞いてそれを守る人たちです。」</span>
<span className="v" id="v29" data-v="29" data-xref="ルカの福音書 11:16; マルコの福音書 8:11–12; コリント人への手紙第一 1:22"> さて、群衆の数がふえて来ると、イエスは話し始められた。「この時代は悪い時代です。しるしを求めているが、ヨナのしるしのほかには、しるしは与えられません。</span>
<span className="v" id="v30" data-v="30" data-xref="マタイの福音書 12:40–42; Jonah 1:17; Jonah 3:2–10"> というのは、ヨナがニネベの人々のために、しるしとなったように、人の子がこの時代のために、しるしとなるからです。</span>
<span className="v" id="v31" data-v="31" data-xref="2 Chronicles 9:1; 1 Kings 10:1–13; ローマ人への手紙 2:27"> 南の女王が、さばきのときに、この時代の人々とともに立って、彼らを罪に定めます。なぜなら、彼女はソロモンの知恵を聞くために地の果てから来たからです。しかし、見なさい。ここにソロモンよりもまさった者がいるのです。</span>
<span className="v" id="v32" data-v="32" data-xref="ヘブル人への手紙 7:26; ルカの福音書 11:31; Jonah 3:5–4"> ニネベの人々が、さばきのときに、この時代の人々とともに立って、この人々を罪に定めます。なぜなら、ニネベの人々はヨナの説教で悔い改めたからです。しかし、見なさい。ここにヨナよりもまさった者がいるのです。</span>
<span className="v" id="v33" data-v="33" data-xref="ルカの福音書 8:16–17; マルコの福音書 4:21–22; マタイの福音書 5:15–16"> だれも、あかりをつけてから、それを穴倉や、枡の下に置く者はいません。燭台の上に置きます。はいって来る人々に、その光が見えるためです。</span>
<span className="v" id="v34" data-v="34" data-xref="マタイの福音書 6:22–23; 使徒の働き 26:18; Jeremiah 5:21"> からだのあかりは、あなたの目です。目が健全なら、あなたの全身も明るいが、しかし、目が悪いと、からだも暗くなります。</span>
<span className="v" id="v35" data-v="35" data-xref="Proverbs 16:25; ペテロの手紙第二 1:9; ヤコブの手紙 3:13–17"> だから、あなたのうちの光が、暗やみにならないように、気をつけなさい。</span>
<span className="v" id="v36" data-v="36" data-xref="Proverbs 20:27; Proverbs 6:23; Proverbs 4:18–19"> もし、あなたの全身が明るくて何の暗い部分もないなら、その全身はちょうどあかりが輝いて、あなたを照らすときのように明るく輝きます。」</span>
<span className="v" id="v37" data-v="37" data-xref="ルカの福音書 7:36; コリント人への手紙第一 9:19–23; ルカの福音書 14:1"> イエスが話し終えられると、ひとりのパリサイ人が、食事をいっしょにしてください、とお願いした。そこでイエスは家にはいって、食卓に着かれた。</span>
<span className="v" id="v38" data-v="38" data-xref="マタイの福音書 15:2–3; マルコの福音書 7:2–5; ヨハネの福音書 3:25"> そのパリサイ人は、イエスが食事の前に、まずきよめの洗いをなさらないのを見て、驚いた。</span>
<span className="v" id="v39" data-v="39" data-xref="テトスへの手紙 1:15; Proverbs 30:12; Genesis 6:5"> すると、主は言われた。「なるほど、あなたがたパリサイ人は、杯や大皿の外側はきよめるが、その内側は、強奪と邪悪とでいっぱいです。</span>
<span className="v" id="v40" data-v="40" data-xref="ルカの福音書 12:20; コリント人への手紙第一 15:36; マタイの福音書 23:26"> 愚かな人たち。外側を造られた方は、内側も造られたのではありませんか。</span>
<span className="v" id="v41" data-v="41" data-xref="ルカの福音書 12:33; ヤコブの手紙 1:27; テトスへの手紙 1:15"> とにかく、うちのものを施しに用いなさい。そうすれば、いっさいが、あなたがたにとってきよいものとなります。</span>
<span className="v" id="v42" data-v="42" data-xref="マタイの福音書 23:23; ルカの福音書 18:12; Proverbs 21:3"> だが、忌まわしいものだ。パリサイ人。あなたがたは、はっか、うん香、あらゆる野菜などの十分の一を納めているが、公義と神への愛とはなおざりにしています。これこそ、実行しなければならない事がらです。ただし他のほうも、なおざりにしてはいけません。</span>
<span className="v" id="v43" data-v="43" data-xref="ルカの福音書 20:46; マルコの福音書 12:38–39; ルカの福音書 14:7–11"> 忌まわしいものだ。パリサイ人。あなたがたは、会堂の上席や、市場であいさつされることが好きです。</span>
<span className="v" id="v44" data-v="44" data-xref="マタイの福音書 23:27–28; Psalms 5:9; 使徒の働き 23:3"> 忌まわしいことだ。あなたがたは、人目につかぬ墓のようで、その上を歩く人々も気がつかない。」</span>
<span className="v" id="v45" data-v="45" data-xref="ヨハネの福音書 9:40; マタイの福音書 22:35; Jeremiah 6:10"> すると、ある律法の専門家が、答えて言った。「先生。そのようなことを言われることは、私たちをも侮辱することです。」</span>
<span className="v" id="v46" data-v="46" data-xref="ルカの福音書 11:52; Isaiah 10:1; マタイの福音書 23:2–4"> しかし、イエスは言われた。「あなたがた律法の専門家たちも忌まわしいものだ。あなたがたは、人々には負いきれない荷物を負わせるが、自分は、その荷物に指一本もさわろうとはしない。</span>
<span className="v" id="v47" data-v="47" data-xref="テサロニケ人への手紙第一 2:15; 使徒の働き 7:51; マタイの福音書 23:29–33"> 忌まわしいことだ。あなたがたは、預言者たちの墓を建てている。しかし、あなたがたの先祖は預言者たちを殺したのです。</span>
<span className="v" id="v48" data-v="48" data-xref="ヤコブの手紙 5:10; マタイの福音書 23:31; 2 Chronicles 36:16"> そのようにして、あなたがたは、自分の先祖のしたことの証人となり、それを認めています。なぜなら、あなたがたの先祖が預言者たちを殺し、あなたがたがその墓を建てているからです。</span>
<span className="v" id="v49" data-v="49" data-xref="コリント人への手紙第一 1:30; コロサイ人への手紙 2:3; エペソ人への手紙 4:11"> だから、神の知恵もこう言いました。『わたしは預言者たちや使徒たちを彼らに遣わすが、彼らは、そのうちのある者を殺し、ある者を迫害する。</span>
<span className="v" id="v50" data-v="50" data-xref="Genesis 9:5–6; ヨハネの黙示録 18:20–24; 2 Kings 24:4"> それは、アベルの血から、祭壇と神の家との間で殺されたザカリヤの血に至るまでの、世の初めから流されたすべての預言者の血の責任を、この時代が問われるためである。そうだ。わたしは言う。この時代はその責任を問われる。』</span>
<span className="v" id="v51" data-v="51" data-xref="2 Chronicles 24:20–22; マタイの福音書 23:35; ヘブル人への手紙 11:4"> 忌まわしいものだ。律法の専門家たち。あなたがたは、知識のかぎを持ち去り、自分もはいらず、はいろうとする人々をも妨げたのです。」</span>
<span className="v" id="v53" data-v="53" data-xref="コリント人への手紙第一 13:5; Jeremiah 20:10; ルカの福音書 20:20"> イエスがそこを出て行かれると、律法学者、パリサイ人たちのイエスに対する激しい敵対と、いろいろのことについてのしつこい質問攻めとが始まった。</span>
<span className="v" id="v54" data-v="54" data-xref="マルコの福音書 12:13; マタイの福音書 22:15; マタイの福音書 22:35"> 彼らは、イエスの口から出ることに、言いがかりをつけようと、ひそかに計った。</span>

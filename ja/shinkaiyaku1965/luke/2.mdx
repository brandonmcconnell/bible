<span className="v" id="v1" data-v="1" data-xref="ルカの福音書 3:1; マタイの福音書 24:14; 使徒の働き 25:21"> そのころ、全世界の住民登録をせよという勅令が、皇帝アウグストから出た。</span>
<span className="v" id="v2" data-v="2" data-xref="ルカの福音書 3:1; マタイの福音書 4:24; 使徒の働き 26:30"> これは、クレニオがシリヤの総督であったときの最初の住民登録であった。</span>
<span className="v" id="v3" data-v="3"> それで、人々はみな、登録のために、それぞれ自分の町に向かって行った。</span>
<span className="v" id="v4" data-v="4" data-xref="Micah 5:2; ヨハネの福音書 7:42; 1 Samuel 16:1"> ヨセフもガリラヤの町ナザレから、ユダヤのベツレヘムというダビデの町へ上って行った。彼は、ダビデの家系であり血筋でもあったので、</span>
<span className="v" id="v5" data-v="5" data-xref="Deuteronomy 22:22–27; マタイの福音書 1:18–19"> 身重になっているいいなずけの妻マリヤもいっしょに登録するためであった。</span>
<span className="v" id="v6" data-v="6" data-xref="Psalms 33:11; ヨハネの黙示録 12:1–5; Micah 5:2"> ところが、彼らがそこにいる間に、マリヤは月が満ちて、</span>
<span className="v" id="v7" data-v="7" data-xref="ガラテヤ人への手紙 4:4; コリント人への手紙第二 8:9; Isaiah 53:2–3"> 男子の初子を産んだ。それで、布にくるんで、飼葉おけに寝かせた。宿屋には彼らのいる場所がなかったからである。</span>
<span className="v" id="v8" data-v="8" data-xref="Genesis 31:39–40; Psalms 78:70–71; 1 Samuel 17:34–35"> さて、この土地に、羊飼いたちが、野宿で夜番をしながら羊の群れを見守っていた。</span>
<span className="v" id="v9" data-v="9" data-xref="Isaiah 60:1; コリント人への手紙第二 3:18; 1 Kings 8:11"> すると、主の使いが彼らのところに来て、主の栄光が回りを照らしたので、彼らはひどく恐れた。</span>
<span className="v" id="v10" data-v="10" data-xref="Isaiah 40:9; Isaiah 61:1; Isaiah 52:7"> 御使いは彼らに言った。「恐れることはありません。今、私はこの民全体のためのすばらしい喜びを知らせに来たのです。</span>
<span className="v" id="v11" data-v="11" data-xref="Isaiah 9:6; マタイの福音書 1:21; 使徒の働き 2:36"> きょうダビデの町で、あなたがたのために、救い主がお生まれになりました。この方こそ主キリストです。</span>
<span className="v" id="v12" data-v="12" data-xref="Isaiah 7:14; Isaiah 53:1–2; Isaiah 7:11"> あなたがたは、布にくるまって飼葉おけに寝ておられるみどりごを見つけます。これが、あなたがたのためのしるしです。」</span>
<span className="v" id="v13" data-v="13" data-xref="Psalms 103:20–21; ヨハネの黙示録 5:11; Psalms 148:2"> すると、たちまち、その御使いといっしょに、多くの天の軍勢が現われて、神を賛美して言った。</span>
<span className="v" id="v14" data-v="14" data-xref="ローマ人への手紙 5:1; ルカの福音書 19:38; コロサイ人への手紙 1:20"> 「いと高き所に、栄光が、神にあるように。 地の上に、平和が、 御心にかなう人々にあるように。」</span>
<span className="v" id="v15" data-v="15" data-xref="ペテロの手紙第一 3:22; マタイの福音書 2:1–2; マタイの福音書 2:9–11"> 御使いたちが彼らを離れて天に帰ったとき、羊飼いたちは互いに話し合った。「さあ、ベツレヘムに行って、主が私たちに知らせてくださったこの出来事を見て来よう。」</span>
<span className="v" id="v16" data-v="16" data-xref="ルカの福音書 19:32; ルカの福音書 2:12; ルカの福音書 2:7"> そして急いで行って、マリヤとヨセフと、飼葉おけに寝ておられるみどりごとを捜し当てた。</span>
<span className="v" id="v17" data-v="17" data-xref="Psalms 66:16; ルカの福音書 8:39; Psalms 71:17–18"> それを見たとき、羊飼いたちは、この幼子について告げられたことを知らせた。</span>
<span className="v" id="v18" data-v="18" data-xref="ルカの福音書 2:47; ルカの福音書 4:36; ルカの福音書 1:65–66"> それを聞いた人たちはみな、羊飼いの話したことに驚いた。</span>
<span className="v" id="v19" data-v="19" data-xref="ルカの福音書 2:51; ルカの福音書 1:66; Proverbs 4:4"> しかしマリヤは、これらのことをすべて心に納めて、思いを巡らしていた。</span>
<span className="v" id="v20" data-v="20" data-xref="Psalms 106:48; Isaiah 29:19; 使徒の働き 11:18"> 羊飼いたちは、見聞きしたことが、全部御使いの話のとおりだったので、神をあがめ、賛美しながら帰って行った。</span>
<span className="v" id="v21" data-v="21" data-xref="ルカの福音書 1:31; Genesis 17:12; ガラテヤ人への手紙 4:4–5"> 八日が満ちて幼子に割礼を施す日となり、幼子はイエスという名で呼ばれることになった。胎内に宿る前に御使いがつけた名である。</span>
<span className="v" id="v22" data-v="22" data-xref="Leviticus 12:1–8"> さて、モーセの律法による彼らのきよめの期間が満ちたとき、両親は幼子を主にささげるために、エルサレムへ連れて行った。</span>
<span className="v" id="v23" data-v="23" data-xref="Exodus 13:2; Exodus 22:29; Numbers 3:13"> ――それは、主の律法に「母の胎を開く男子の初子は、すべて、主に聖別された者、と呼ばれなければならない。」と書いてあるとおりであった。――</span>
<span className="v" id="v24" data-v="24" data-xref="Leviticus 12:6–8; Leviticus 12:2; コリント人への手紙第二 8:9"> また、主の律法に「山ばと一つがい、または、家ばとのひな二羽。」と定められたところに従って犠牲をささげるためであった。</span>
<span className="v" id="v25" data-v="25" data-xref="Isaiah 25:9; ルカの福音書 2:38; ルカの福音書 1:6"> そのとき、エルサレムにシメオンという人がいた。この人は正しい、敬虔な人で、イスラエルの慰められることを待ち望んでいた。聖霊が彼の上にとどまっておられた。</span>
<span className="v" id="v26" data-v="26" data-xref="ヨハネの福音書 8:51; ヘブル人への手紙 11:5; ルカの福音書 9:27"> また、主のキリストを見るまでは、決して死なないと、聖霊のお告げを受けていた。</span>
<span className="v" id="v27" data-v="27" data-xref="マタイの福音書 4:1; ルカの福音書 2:41; ルカの福音書 2:51"> 彼が御霊に感じて宮にはいると、幼子イエスを連れた両親が、その子のために律法の慣習を守るために、はいって来た。</span>
<span className="v" id="v28" data-v="28" data-xref="ルカの福音書 1:64; ルカの福音書 2:20; ルカの福音書 2:13–14"> すると、シメオンは幼子を腕に抱き、神をほめたたえて言った。</span>
<span className="v" id="v29" data-v="29" data-xref="ヨハネの黙示録 14:13; Genesis 15:15; ピリピ人への手紙 1:23"> 「主よ。今こそあなたは、あなたのしもべを、 みことばどおり、安らかに去らせてくださいます。</span>
<span className="v" id="v30" data-v="30" data-xref="Isaiah 49:6; ルカの福音書 2:10–11; ルカの福音書 3:6"> 私の目があなたの御救いを見たからです。</span>
<span className="v" id="v31" data-v="31" data-xref="Isaiah 62:1–2; Isaiah 42:1–4; Psalms 98:2–3"> 御救いはあなたが 万民の前に備えられたもので、</span>
<span className="v" id="v32" data-v="32" data-xref="Isaiah 60:1–3; Isaiah 49:6; 使徒の働き 26:23"> 異邦人を照らす啓示の光、 御民イスラエルの光栄です。」</span>
<span className="v" id="v33" data-v="33" data-xref="ルカの福音書 1:65–66; Isaiah 8:18; ルカの福音書 2:48"> 父と母は、幼子についていろいろ語られる事に驚いた。</span>
<span className="v" id="v34" data-v="34" data-xref="コリント人への手紙第一 1:23; ペテロの手紙第一 2:7–8; Isaiah 8:14–15"> また、シメオンは両親を祝福し、母マリヤに言った。「ご覧なさい。この子は、イスラエルの多くの人が倒れ、また、立ち上がるために定められ、また、反対を受けるしるしとして定められています。</span>
<span className="v" id="v35" data-v="35" data-xref="Deuteronomy 8:2; コリント人への手紙第一 11:19; マタイの福音書 12:24–35"> 剣があなたの心さえも刺し貫くでしょう。それは多くの人の心の思いが現われるためです。」</span>
<span className="v" id="v36" data-v="36" data-xref="Exodus 15:20; Genesis 30:13; 使徒の働き 21:9"> また、アセル族のパヌエルの娘で女預言者のアンナという人がいた。この人は非常に年をとっていた。処女の時代のあと七年間、夫とともに住み、</span>
<span className="v" id="v37" data-v="37" data-xref="テモテへの手紙第一 5:5; Psalms 23:6; 使徒の働き 14:23"> その後やもめになり、八十四歳になっていた。そして宮を離れず、夜も昼も、断食と祈りをもって神に仕えていた。</span>
<span className="v" id="v38" data-v="38" data-xref="ルカの福音書 2:25; コリント人への手紙第二 9:15; マルコの福音書 15:43"> ちょうどこのとき、彼女もそこにいて、神に感謝をささげ、そして、エルサレムの贖いを待ち望んでいるすべての人々に、この幼子のことを語った。</span>
<span className="v" id="v39" data-v="39" data-xref="ルカの福音書 2:4; ガラテヤ人への手紙 4:4–5; Deuteronomy 12:32"> さて、彼らは主の律法による定めをすべて果たしたので、ガリラヤの自分たちの町ナザレに帰った。</span>
<span className="v" id="v40" data-v="40" data-xref="ルカの福音書 2:52; ルカの福音書 1:80; Isaiah 11:1–5"> 幼子は成長し、強くなり、知恵に満ちて行った。神の恵みがその上にあった。</span>
<span className="v" id="v41" data-v="41" data-xref="Exodus 12:14; Numbers 28:16; Deuteronomy 12:18"> さて、イエスの両親は、過越の祭りには毎年エルサレムに行った。</span>
<span className="v" id="v42" data-v="42"> イエスが十二歳になられたときも、両親は祭りの慣習に従って都へ上り、</span>
<span className="v" id="v43" data-v="43" data-xref="2 Chronicles 30:21–23; Exodus 12:15; 2 Chronicles 25:17"> 祭りの期間を過ごしてから、帰路についたが、少年イエスはエルサレムにとどまっておられた。両親はそれに気づかなかった。</span>
<span className="v" id="v44" data-v="44" data-xref="Psalms 122:1–4; Isaiah 2:3; Psalms 42:4"> イエスが一行の中にいるものと思って、一日の道のりを行った。それから、親族や知人の中を捜し回ったが、</span>
<span className="v" id="v45" data-v="45"> 見つからなかったので、イエスを捜しながら、エルサレムまで引き返した。</span>
<span className="v" id="v46" data-v="46" data-xref="ルカの福音書 5:17; Isaiah 49:1–2; Isaiah 50:4"> そしてようやく三日の後に、イエスが宮で教師たちの真中にすわって、話を聞いたり質問したりしておられるのを見つけた。</span>
<span className="v" id="v47" data-v="47" data-xref="マタイの福音書 7:28; ルカの福音書 4:32; Psalms 119:99"> 聞いていた人々はみな、イエスの知恵と答えに驚いていた。</span>
<span className="v" id="v48" data-v="48" data-xref="ルカの福音書 2:49; マタイの福音書 12:46; ルカの福音書 3:23"> 両親は彼を見て驚き、母は言った。「まあ、あなたはなぜ私たちにこんなことをしたのです。見なさい。父上も私も、心配してあなたを捜し回っていたのです。」</span>
<span className="v" id="v49" data-v="49" data-xref="ヨハネの福音書 6:38; ヨハネの福音書 8:29; Malachi 3:1"> するとイエスは両親に言われた。「どうしてわたしをお捜しになったのですか。わたしが必ず自分の父の家にいることを、ご存じなかったのですか。」</span>
<span className="v" id="v50" data-v="50" data-xref="ルカの福音書 18:34; ルカの福音書 9:45; マルコの福音書 9:32"> しかし両親には、イエスの話されたことばの意味がわからなかった。</span>
<span className="v" id="v51" data-v="51" data-xref="ルカの福音書 2:19; Daniel 7:28; Genesis 37:11"> それからイエスは、いっしょに下って行かれ、ナザレに帰って、両親に仕えられた。母はこれらのことをみな、心に留めておいた。</span>
<span className="v" id="v52" data-v="52" data-xref="ルカの福音書 2:40; Proverbs 3:3–4; 1 Samuel 2:26"> イエスはますます知恵が進み、背たけも大きくなり、神と人とに愛された。</span>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マルコの福音書 6:7–13; ルカの福音書 9:52; Numbers 11:24–26"> その後、主は、別に七十人を定め、ご自分が行くつもりのすべての町や村へ、ふたりずつ先にお遣わしになった。</span>
<span className="v" id="v2" data-v="2" data-xref="マタイの福音書 9:36–38; ヨハネの福音書 4:35–38; コリント人への手紙第一 3:6–9"> そして、彼らに言われた。「実りは多いが、働き手が少ない。だから、収穫の主に、収穫のために働き手を送ってくださるように祈りなさい。</span>
<span className="v" id="v3" data-v="3" data-xref="マタイの福音書 10:16; 使徒の働き 20:29; Ezekiel 2:3–6"> さあ、行きなさい。いいですか。わたしがあなたがたを遣わすのは、狼の中に小羊を送り出すようなものです。</span>
<span className="v" id="v4" data-v="4" data-xref="ルカの福音書 22:35; 2 Kings 4:29; ルカの福音書 10:4–12"> 財布も旅行袋も持たず、くつもはかずに行きなさい。だれにも、道であいさつしてはいけません。</span>
<span className="v" id="v5" data-v="5" data-xref="1 Samuel 25:6; マタイの福音書 10:12–13; Isaiah 57:19"> どんな家にはいっても、まず、『この家に平安があるように。』と言いなさい。</span>
<span className="v" id="v6" data-v="6" data-xref="テサロニケ人への手紙第二 3:16; コリント人への手紙第二 2:15–16; エペソ人への手紙 5:6"> もしそこに平安の子がいたら、あなたがたの祈った平安は、その人の上にとどまります。だが、もしいないなら、その平安はあなたがたに返って来ます。</span>
<span className="v" id="v7" data-v="7" data-xref="テモテへの手紙第一 5:17–18; マタイの福音書 10:10–11; ガラテヤ人への手紙 6:6"> その家に泊まっていて、出してくれる物を飲み食いしなさい。働く者が報酬を受けるのは、当然だからです。家から家へと渡り歩いてはいけません。</span>
<span className="v" id="v8" data-v="8" data-xref="コリント人への手紙第一 10:27; マタイの福音書 10:40; ルカの福音書 10:10"> どの町にはいっても、あなたがたを受け入れてくれたら、出される物を食べなさい。</span>
<span className="v" id="v9" data-v="9" data-xref="マタイの福音書 3:2; ヨハネの福音書 3:5; ルカの福音書 10:11"> そして、その町の病人を直し、彼らに、『神の国が、あなたがたに近づいた。』と言いなさい。</span>
<span className="v" id="v10" data-v="10" data-xref="使徒の働き 18:6; マタイの福音書 10:14; 使徒の働き 13:51"> しかし、町にはいっても、人々があなたがたを受け入れないならば、大通りに出て、こう言いなさい。</span>
<span className="v" id="v11" data-v="11" data-xref="ルカの福音書 10:9; 使徒の働き 13:51; 使徒の働き 13:26"> 『私たちは足についたこの町のちりも、あなたがたにぬぐい捨てて行きます。しかし、神の国が近づいたことは承知していなさい。』</span>
<span className="v" id="v12" data-v="12" data-xref="マタイの福音書 10:15; マタイの福音書 11:24; Lamentations 4:6"> あなたがたに言うが、その日には、その町よりもソドムのほうがまだ罰が軽いのです。</span>
<span className="v" id="v13" data-v="13" data-xref="Isaiah 23:1–18; Joel 3:4–8; Ezekiel 26:1–26"> ああコラジン。ああベツサイダ。おまえたちの間に起こった力あるわざが、もしもツロとシドンでなされたのだったら、彼らはとうの昔に荒布をまとい、灰の中にすわって、悔い改めていただろう。</span>
<span className="v" id="v14" data-v="14" data-xref="ヨハネの福音書 15:22–25; ローマ人への手紙 2:1; ルカの福音書 12:47–48"> しかし、さばきの日には、そのツロとシドンのほうが、まだおまえたちより罰が軽いのだ。</span>
<span className="v" id="v15" data-v="15" data-xref="Isaiah 14:13–15; マタイの福音書 4:13; ルカの福音書 13:28"> カペナウム。どうしておまえが天に上げられることがありえよう。ハデスにまで落とされるのだ。</span>
<span className="v" id="v16" data-v="16" data-xref="ヨハネの福音書 13:20; マタイの福音書 10:40; テサロニケ人への手紙第一 4:8"> あなたがたに耳を傾ける者は、わたしに耳を傾ける者であり、あなたがたを拒む者は、わたしを拒む者です。わたしを拒む者は、わたしを遣わされた方を拒む者です。」</span>
<span className="v" id="v17" data-v="17" data-xref="ローマ人への手紙 16:20; マルコの福音書 16:17; ルカの福音書 9:1"> さて、七十人が喜んで帰って来て、こう言った。「主よ。あなたの御名を使うと、悪霊どもでさえ、私たちに服従します。」</span>
<span className="v" id="v18" data-v="18" data-xref="ヨハネの黙示録 12:7–9; Isaiah 14:12; ヨハネの黙示録 9:1"> イエスは言われた。「わたしが見ていると、サタンが、いなずまのように天から落ちました。</span>
<span className="v" id="v19" data-v="19" data-xref="Psalms 91:13; マルコの福音書 16:18; ローマ人への手紙 16:20"> 確かに、わたしは、あなたがたに、蛇やさそりを踏みつけ、敵のあらゆる力に打ち勝つ権威を授けたのです。だから、あなたがたに害を加えるものは何一つありません。</span>
<span className="v" id="v20" data-v="20" data-xref="ヨハネの黙示録 20:15; ヨハネの黙示録 20:12; ヘブル人への手紙 12:23"> だがしかし、悪霊どもがあなたがたに服従するからといって、喜んではなりません。ただあなたがたの名が天に書きしるされていることを喜びなさい。」</span>
<span className="v" id="v21" data-v="21" data-xref="コリント人への手紙第二 4:3; マタイの福音書 13:11–16; マタイの福音書 11:25–27"> ちょうどこのとき、イエスは、聖霊によって喜びにあふれて言われた。「天地の主であられる父よ。あなたをほめたたえます。これらのことを、賢い者や知恵のある者には隠して、幼子たちに現わしてくださいました。そうです、父よ。これがみこころにかなったことでした。</span>
<span className="v" id="v22" data-v="22" data-xref="マタイの福音書 11:27; ヨハネの福音書 1:18; ヨハネの福音書 6:44–46"> すべてのものが、わたしの父から、わたしに渡されています。それで、子がだれであるかは、父のほかには知る者がありません。また父がだれであるかは、子と、子が父を知らせようと心に定めた人たちのほかは、だれも知る者がありません。」</span>
<span className="v" id="v23" data-v="23" data-xref="マタイの福音書 13:16–17"> それからイエスは、弟子たちのほうに向いて、ひそかに言われた。「あなたがたの見ていることを見る目は幸いです。</span>
<span className="v" id="v24" data-v="24" data-xref="ヨハネの福音書 8:56; ヘブル人への手紙 11:13; ペテロの手紙第一 1:10–12"> あなたがたに言いますが、多くの預言者や王たちがあなたがたの見ていることを見たいと願ったのに、見られなかったのです。また、あなたがたの聞いていることを聞きたいと願ったのに、聞けなかったのです。」</span>
<span className="v" id="v25" data-v="25" data-xref="マタイの福音書 22:34–39; ルカの福音書 18:18; マタイの福音書 19:16–19"> すると、ある律法の専門家が立ち上がり、イエスをためそうとして言った。「先生。何をしたら永遠のいのちを自分のものとして受けることができるでしょうか。」</span>
<span className="v" id="v26" data-v="26" data-xref="ローマ人への手紙 10:5; Isaiah 8:20; ガラテヤ人への手紙 3:21–22"> イエスは言われた。「律法には、何と書いてありますか。あなたはどう読んでいますか。」</span>
<span className="v" id="v27" data-v="27" data-xref="マルコの福音書 12:30–31; マタイの福音書 22:37–40; Deuteronomy 6:5"> すると彼は答えて言った。「『心を尽くし、思いを尽くし、力を尽くし、知性を尽くして、あなたの神である主を愛せよ。』また『あなたの隣人をあなた自身のように愛せよ。』とあります。」</span>
<span className="v" id="v28" data-v="28" data-xref="Ezekiel 20:11; Leviticus 18:5; マタイの福音書 19:17"> イエスは言われた。「そのとおりです。それを実行しなさい。そうすれば、いのちを得ます。」</span>
<span className="v" id="v29" data-v="29" data-xref="ルカの福音書 16:15; ローマ人への手紙 4:2; Leviticus 19:34"> しかし彼は、自分の正しさを示そうとしてイエスに言った。「では、私の隣人とは、だれのことですか。」</span>
<span className="v" id="v30" data-v="30" data-xref="Psalms 88:4; ルカの福音書 18:31; Lamentations 2:12"> イエスは答えて言われた。 「ある人が、エルサレムからエリコへ下る道で、強盗に襲われた。強盗どもは、その人の着物をはぎ取り、なぐりつけ、半殺しにして逃げて行った。</span>
<span className="v" id="v31" data-v="31" data-xref="ヨハネの手紙第一 3:16–18; Psalms 69:20; Jeremiah 5:31"> たまたま、祭司がひとり、その道を下って来たが、彼を見ると、反対側を通り過ぎて行った。</span>
<span className="v" id="v32" data-v="32" data-xref="Proverbs 27:10; 使徒の働き 18:17; Psalms 109:25"> 同じようにレビ人も、その場所に来て彼を見ると、反対側を通り過ぎて行った。</span>
<span className="v" id="v33" data-v="33" data-xref="1 Kings 8:50; Jeremiah 38:7–13; ルカの福音書 7:13"> ところが、あるサマリヤ人が、旅の途中、そこに来合わせ、彼を見てかわいそうに思い、</span>
<span className="v" id="v34" data-v="34" data-xref="ローマ人への手紙 12:20; Psalms 147:3; テサロニケ人への手紙第一 5:15"> 近寄って傷にオリーブ油とぶどう酒を注いで、ほうたいをし、自分の家畜に乗せて宿屋に連れて行き、介抱してやった。</span>
<span className="v" id="v35" data-v="35" data-xref="Proverbs 19:17; ルカの福音書 14:13; ローマ人への手紙 16:23"> 次の日、彼はデナリ二つを取り出し、宿屋の主人に渡して言った。『介抱してあげてください。もっと費用がかかったら、私が帰りに払います。』</span>
<span className="v" id="v36" data-v="36" data-xref="ルカの福音書 7:42; マタイの福音書 21:28–31; マタイの福音書 17:25"> この三人の中でだれが、強盗に襲われた者の隣人になったと思いますか。」</span>
<span className="v" id="v37" data-v="37" data-xref="ヨハネの手紙第一 3:16–18; Micah 6:8; ペテロの手紙第一 2:21"> 彼は言った。「その人にあわれみをかけてやった人です。」するとイエスは言われた。「あなたも行って同じようにしなさい。」</span>
<span className="v" id="v38" data-v="38" data-xref="ヨハネの福音書 11:19–20; ヨハネの福音書 11:1–5; ヨハネの福音書 12:1–3"> さて、彼らが旅を続けているうち、イエスがある村にはいられると、マルタという女が喜んで家にお迎えした。</span>
<span className="v" id="v39" data-v="39" data-xref="Proverbs 8:34; ルカの福音書 8:35; ヨハネの福音書 12:3"> 彼女にマリヤという妹がいたが、主の足もとにすわって、みことばに聞き入っていた。</span>
<span className="v" id="v40" data-v="40" data-xref="ヨハネの福音書 6:27; ルカの福音書 12:29; マタイの福音書 14:15"> ところが、マルタは、いろいろともてなしのために気が落ち着かず、みもとに来て言った。「主よ。妹が私だけにおもてなしをさせているのを、何ともお思いにならないのでしょうか。私の手伝いをするように、妹におっしゃってください。」</span>
<span className="v" id="v41" data-v="41" data-xref="ピリピ人への手紙 4:6; ルカの福音書 21:34; マタイの福音書 6:25–34"> 主は答えて言われた。「マルタ、マルタ。あなたは、いろいろなことを心配して、気を使っています。</span>
<span className="v" id="v42" data-v="42" data-xref="Psalms 27:4; Psalms 16:5–6; ヨハネの福音書 10:27–28"> しかし、どうしても必要なことはわずかです。いや、一つだけです。マリヤはその良いほうを選んだのです。彼女からそれを取り上げてはいけません。」</span>

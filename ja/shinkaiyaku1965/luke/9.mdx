<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨハネの福音書 14:12; ルカの福音書 10:19; マタイの福音書 16:19"> イエスは、十二人を呼び集めて、彼らに、すべての悪霊を追い出し、病気を直すための、力と権威とをお授けになった。</span>
<span className="v" id="v2" data-v="2" data-xref="マタイの福音書 10:7–8; ルカの福音書 10:9; マタイの福音書 3:2"> それから、神の国を宣べ伝え、病気を直すために、彼らを遣わされた。</span>
<span className="v" id="v3" data-v="3" data-xref="ルカの福音書 22:35; Psalms 37:3; ルカの福音書 10:4–12"> イエスは、こう言われた。「旅のために何も持って行かないようにしなさい。杖も、袋も、パンも、金も。また下着も、二枚は、いりません。</span>
<span className="v" id="v4" data-v="4" data-xref="マタイの福音書 10:11; マルコの福音書 6:10; ルカの福音書 10:5–8"> どんな家にはいっても、そこにとどまり、そこから次の旅に出かけなさい。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒の働き 13:51; 使徒の働き 18:6; マルコの福音書 6:11"> 人々があなたがたを受け入れないばあいは、その町を出て行くときに、彼らに対する証言として、足のちりを払い落としなさい。」</span>
<span className="v" id="v6" data-v="6" data-xref="使徒の働き 4:30; マルコの福音書 16:20; 使徒の働き 5:15"> 十二人は出かけて行って、村から村へと回りながら、至る所で福音を宣べ伝え、病気を直した。</span>
<span className="v" id="v7" data-v="7" data-xref="マルコの福音書 6:14–28; マタイの福音書 14:1–12; ルカの福音書 3:1"> さて、国主ヘロデは、このすべての出来事を聞いて、ひどく当惑していた。それは、ある人々が、「ヨハネが死人の中からよみがえったのだ。」と言い、</span>
<span className="v" id="v8" data-v="8" data-xref="ヨハネの福音書 1:21; ルカの福音書 9:19; マルコの福音書 6:15"> ほかの人々は、「エリヤが現われたのだ。」と言い、さらに別の人々は、「昔の預言者のひとりがよみがえったのだ。」と言っていたからである。</span>
<span className="v" id="v9" data-v="9" data-xref="ルカの福音書 23:8; ルカの福音書 13:31–32"> ヘロデは言った。「ヨハネなら、私が首をはねたのだ。そうしたことがうわさされているこの人は、いったいだれなのだろう。」ヘロデはイエスに会ってみようとした。</span>
<span className="v" id="v10" data-v="10" data-xref="マタイの福音書 11:21; ヘブル人への手紙 13:17; マタイの福音書 14:13–21"> さて、使徒たちは帰って来て、自分たちのして来たことを報告した。それからイエスは彼らを連れてベツサイダという町へひそかに退かれた。</span>
<span className="v" id="v11" data-v="11" data-xref="ルカの福音書 9:2; ルカの福音書 5:31; ヘブル人への手紙 4:16"> ところが、多くの群衆がこれを知って、ついて来た。それで、イエスは喜んで彼らを迎え、神の国のことを話し、また、いやしの必要な人たちをおいやしになった。</span>
<span className="v" id="v12" data-v="12" data-xref="ヨハネの福音書 6:1; ヨハネの福音書 6:5–15; Hosea 13:5"> そのうち、日も暮れ始めたので、十二人はみもとに来て、「この群衆を解散させてください。そして回りの村や部落にやって、宿をとらせ、何か食べることができるようにさせてください。私たちは、こんな人里離れた所にいるのですから。」と言った。</span>
<span className="v" id="v13" data-v="13" data-xref="Proverbs 11:24–25; ヨハネの福音書 6:5–9; 2 Kings 4:42–43"> しかしイエスは、彼らに言われた。「あなたがたで、何か食べる物を上げなさい。」彼らは言った。「私たちには五つのパンと二匹の魚のほか何もありません。私たちが出かけて行って、この民全体のために食物を買うのでしょうか。」</span>
<span className="v" id="v14" data-v="14" data-xref="マルコの福音書 8:6; コリント人への手紙第一 14:40; マルコの福音書 6:39–40"> それは、男だけでおよそ五千人もいたからである。しかしイエスは、弟子たちに言われた。「人々を、五十人ぐらいずつ組にしてすわらせなさい。」</span>
<span className="v" id="v15" data-v="15"> 弟子たちは、そのようにして、全部をすわらせた。</span>
<span className="v" id="v16" data-v="16" data-xref="マタイの福音書 14:19; テモテへの手紙第一 4:4–5; マタイの福音書 15:36"> するとイエスは、五つのパンと二匹の魚を取り、天を見上げて、それらを祝福して裂き、群衆に配るように弟子たちに与えられた。</span>
<span className="v" id="v17" data-v="17" data-xref="2 Kings 4:44; マタイの福音書 15:37–38; ヨハネの福音書 6:11–13"> 人々はみな、食べて満腹した。そして、余ったパン切れを取り集めると、十二かごあった。</span>
<span className="v" id="v18" data-v="18" data-xref="マタイの福音書 16:13–16; ルカの福音書 11:1; マタイの福音書 26:36"> さて、イエスがひとりで祈っておられたとき、弟子たちがいっしょにいた。イエスは彼らに尋ねて言われた。「群衆はわたしのことをだれだと言っていますか。」</span>
<span className="v" id="v19" data-v="19" data-xref="Malachi 4:5; ルカの福音書 9:7–8; マタイの福音書 14:2"> 彼らは、答えて言った。「バプテスマのヨハネだと言っています。ある者はエリヤだと言い、またほかの人々は、昔の預言者のひとりが生き返ったのだとも言っています。」</span>
<span className="v" id="v20" data-v="20" data-xref="マタイの福音書 16:15–17; ヨハネの福音書 4:29; ヨハネの福音書 7:41"> イエスは、彼らに言われた。「では、あなたがたは、わたしをだれだと言いますか。」ペテロが答えて言った。「神のキリストです。」</span>
<span className="v" id="v21" data-v="21" data-xref="マタイの福音書 16:20; マタイの福音書 17:9; マルコの福音書 8:30–31"> するとイエスは、このことをだれにも話さないようにと、彼らを戒めて命じられた。</span>
<span className="v" id="v22" data-v="22" data-xref="Isaiah 53:1–12; ルカの福音書 24:7; ルカの福音書 18:31–34"> そして言われた。「人の子は、必ず多くの苦しみを受け、長老、祭司長、律法学者たちに捨てられ、殺され、そして三日目によみがえらねばならないのです。」</span>
<span className="v" id="v23" data-v="23" data-xref="マタイの福音書 10:38–39; ルカの福音書 14:26–27; ローマ人への手紙 8:13"> イエスは、みなの者に言われた。「だれでもわたしについて来たいと思うなら、自分を捨て、日々自分の十字架を負い、そしてわたしについて来なさい。</span>
<span className="v" id="v24" data-v="24" data-xref="ルカの福音書 17:33; ヨハネの福音書 12:25; 使徒の働き 20:23–24"> 自分のいのちを救おうと思う者は、それを失い、わたしのために自分のいのちを失う者は、それを救うのです。</span>
<span className="v" id="v25" data-v="25" data-xref="マルコの福音書 8:36; マタイの福音書 16:26; Psalms 49:6–8"> 人は、たとい全世界を手に入れても、自分自身を失い、損じたら、何の得がありましょう。</span>
<span className="v" id="v26" data-v="26" data-xref="マタイの福音書 10:32–33; テモテへの手紙第二 2:12; ルカの福音書 12:8–9"> もしだれでも、わたしとわたしのことばとを恥と思うなら、人の子も、自分と父と聖なる御使いとの栄光を帯びて来るときには、そのような人のことを恥とします。</span>
<span className="v" id="v27" data-v="27" data-xref="マタイの福音書 16:28; マルコの福音書 9:1; ヨハネの福音書 21:22–23"> しかし、わたしは真実をあなたがたに告げます。ここに立っている人々の中には、神の国を見るまでは、決して死を味わわない者たちがいます。」</span>
<span className="v" id="v28" data-v="28" data-xref="マタイの福音書 17:1–13; マタイの福音書 26:37–39; マルコの福音書 14:33–36"> これらの教えがあってから八日ほどして、イエスは、ペテロとヨハネとヤコブとを連れて、祈るために、山に登られた。</span>
<span className="v" id="v29" data-v="29" data-xref="マタイの福音書 17:2; マルコの福音書 9:2–3; Exodus 34:29–35"> 祈っておられると、御顔の様子が変わり、御衣は白く光り輝いた。</span>
<span className="v" id="v30" data-v="30" data-xref="ヘブル人への手紙 3:3–6; コリント人への手紙第二 3:7–11; ルカの福音書 1:17"> しかも、ふたりの人がイエスと話し合っているではないか。それはモーセとエリヤであって、</span>
<span className="v" id="v31" data-v="31" data-xref="ピリピ人への手紙 3:21; ペテロの手紙第一 1:11–12; ペテロの手紙第一 5:10"> 栄光のうちに現われて、イエスがエルサレムで遂げようとしておられるご最期についていっしょに話していたのである。</span>
<span className="v" id="v32" data-v="32" data-xref="Daniel 8:18; ヨハネの福音書 1:14; Daniel 10:9"> ペテロと仲間たちは、眠くてたまらなかったが、はっきり目がさめると、イエスの栄光と、イエスといっしょに立っているふたりの人を見た。</span>
<span className="v" id="v33" data-v="33" data-xref="マルコの福音書 9:5–6; マルコの福音書 10:38; Psalms 4:6–7"> それから、ふたりがイエスと別れようとしたとき、ペテロがイエスに言った。「先生。ここにいることは、すばらしいことです。私たちが三つの幕屋を造ります。あなたのために一つ、モーセのために一つ、エリヤのために一つ。」ペテロは何を言うべきかを知らなかったのである。</span>
<span className="v" id="v34" data-v="34" data-xref="Exodus 40:34–38; マタイの福音書 17:5–7; Judges 13:22"> 彼がこう言っているうちに、雲がわき起こってその人々をおおった。彼らが雲に包まれると、弟子たちは恐ろしくなった。</span>
<span className="v" id="v35" data-v="35" data-xref="ルカの福音書 3:22; 使徒の働き 3:22–23; マタイの福音書 3:17"> すると雲の中から、「これは、わたしの愛する子、わたしの選んだ者である。彼の言うことを聞きなさい。」と言う声がした。</span>
<span className="v" id="v36" data-v="36" data-xref="マタイの福音書 17:9; マルコの福音書 9:9–10; マルコの福音書 9:6"> この声がしたとき、そこに見えたのはイエスだけであった。彼らは沈黙を守り、その当時は、自分たちの見たこのことをいっさい、だれにも話さなかった。</span>
<span className="v" id="v37" data-v="37" data-xref="マタイの福音書 17:14–20; マルコの福音書 9:14–29"> 次の日、一行が山から降りて来ると、大ぜいの人の群れがイエスを迎えた。</span>
<span className="v" id="v38" data-v="38" data-xref="Zechariah 12:10; ヨハネの福音書 4:47; ルカの福音書 7:12"> すると、群衆の中から、ひとりの人が叫んで言った。「先生。お願いです。息子を見てやってください。ひとり息子です。</span>
<span className="v" id="v39" data-v="39" data-xref="マルコの福音書 9:20; ルカの福音書 8:29; ルカの福音書 4:35"> ご覧ください。霊がこの子に取りつきますと、突然叫び出すのです。そしてひきつけさせてあわを吹かせ、かき裂いて、なかなか離れようとしません。</span>
<span className="v" id="v40" data-v="40" data-xref="ルカの福音書 9:1; 使徒の働き 19:13–16; ルカの福音書 10:17–19"> お弟子たちに、この霊を追い出してくださるようお願いしたのですが、お弟子たちにはできませんでした。」</span>
<span className="v" id="v41" data-v="41" data-xref="Deuteronomy 32:5; ローマ人への手紙 2:4; ヨハネの福音書 20:27"> イエスは答えて言われた。「ああ、不信仰な、曲がった今の世だ。いつまで、あなたがたといっしょにいて、あなたがたにがまんしていなければならないのでしょう。あなたの子をここに連れて来なさい。」</span>
<span className="v" id="v42" data-v="42" data-xref="マルコの福音書 9:26–27; ルカの福音書 7:15; ヨハネの黙示録 12:12"> その子が近づいて来る間にも、悪霊は彼を打ち倒して、激しくひきつけさせてしまった。それで、イエスは汚れた霊をしかって、その子をいやし、父親に渡された。</span>
<span className="v" id="v43" data-v="43" data-xref="ルカの福音書 9:43–45; ルカの福音書 5:26; マタイの福音書 17:22"> 人々はみな、神のご威光に驚嘆した。 イエスのなさったすべてのことに、人々がみな驚いていると、イエスは弟子たちにこう言われた。</span>
<span className="v" id="v44" data-v="44" data-xref="ルカの福音書 9:22; 使徒の働き 2:23; ルカの福音書 2:19"> 「このことばを、しっかりと耳に入れておきなさい。人の子は、いまに人々の手に渡されます。」</span>
<span className="v" id="v45" data-v="45" data-xref="ルカの福音書 18:34; ルカの福音書 2:50; ヨハネの福音書 12:16"> しかし、弟子たちは、このみことばが理解できなかった。このみことばの意味は、わからないように、彼らから隠されていたのである。また彼らは、このみことばについてイエスに尋ねるのを恐れた。</span>
<span className="v" id="v46" data-v="46" data-xref="マタイの福音書 18:1–5; マルコの福音書 9:33–37; マタイの福音書 20:20–22"> さて、弟子たちの間に、自分たちの中で、だれが一番偉いかという議論が持ち上がった。</span>
<span className="v" id="v47" data-v="47" data-xref="Psalms 139:23; ヨハネの福音書 16:30; ルカの福音書 5:22"> しかしイエスは、彼らの心の中の考えを知っておられて、ひとりの子どもの手を取り、自分のそばに立たせ、</span>
<span className="v" id="v48" data-v="48" data-xref="ペテロの手紙第一 5:6; ルカの福音書 14:11; マルコの福音書 9:37"> 彼らに言われた。「だれでも、このような子どもを、わたしの名のゆえに受け入れる者は、わたしを受け入れる者です。また、わたしを受け入れる者は、わたしを遣わされた方を受け入れる者です。あなたがたすべての中で一番小さい者が一番偉いのです。」</span>
<span className="v" id="v49" data-v="49" data-xref="マルコの福音書 9:38–40; Numbers 11:27–29; マルコの福音書 10:13–14"> ヨハネが答えて言った。「先生。私たちは、先生の名を唱えて悪霊を追い出している者を見ましたが、やめさせました。私たちの仲間ではないので、やめさせたのです。」</span>
<span className="v" id="v50" data-v="50" data-xref="マタイの福音書 12:30; ルカの福音書 11:23; コリント人への手紙第一 12:3"> しかしイエスは、彼に言われた。「やめさせることはありません。あなたがたに反対しない者は、あなたがたの味方です。」</span>
<span className="v" id="v51" data-v="51" data-xref="Isaiah 50:5–9; マルコの福音書 16:19; ルカの福音書 13:22"> さて、天に上げられる日が近づいて来たころ、イエスは、エルサレムに行こうとして御顔をまっすぐ向けられ、</span>
<span className="v" id="v52" data-v="52" data-xref="マタイの福音書 10:5; ルカの福音書 17:16; ルカの福音書 10:1"> ご自分の前に使いを出された。彼らは行って、サマリヤ人の町にはいり、イエスのために準備した。</span>
<span className="v" id="v53" data-v="53" data-xref="ヨハネの福音書 4:9; ヨハネの福音書 4:40–42; ルカの福音書 9:48"> しかし、イエスは御顔をエルサレムに向けて進んでおられたので、サマリヤ人はイエスを受け入れなかった。</span>
<span className="v" id="v54" data-v="54" data-xref="2 Kings 1:10–14; ヤコブの手紙 3:14–18; ヤコブの手紙 1:19–20"> 弟子のヤコブとヨハネが、これを見て言った。「主よ。私たちが天から火を呼び下して、彼らを焼き滅ぼしましょうか。」</span>
<span className="v" id="v55" data-v="55" data-xref="ヨハネの黙示録 3:19; ペテロの手紙第一 3:9; Jeremiah 17:9"> しかし、イエスは振り向いて、彼らを戒められた。</span>
<span className="v" id="v56" data-v="56" data-xref="マタイの福音書 20:28; ローマ人への手紙 12:21; ヨハネの福音書 3:17"> そして一行は別の村に行った。</span>
<span className="v" id="v57" data-v="57" data-xref="マタイの福音書 8:19–22; ヨハネの福音書 13:37; ルカの福音書 9:57–60"> さて、彼らが道を進んで行くと、ある人がイエスに言った。「私はあなたのおいでになる所なら、どこにでもついて行きます。」</span>
<span className="v" id="v58" data-v="58" data-xref="マタイの福音書 8:20; ルカの福音書 14:26–33; ヤコブの手紙 2:5"> すると、イエスは彼に言われた。「狐には穴があり、空の鳥には巣があるが、人の子には枕する所もありません。」</span>
<span className="v" id="v59" data-v="59" data-xref="マタイの福音書 16:24; マタイの福音書 6:33; 1 Kings 19:20"> イエスは別の人に、こう言われた。「わたしについて来なさい。」しかしその人は言った。「まず行って、私の父を葬ることを許してください。」</span>
<span className="v" id="v60" data-v="60" data-xref="テモテへの手紙第二 2:3–4; テモテへの手紙第一 5:6; ヨハネの福音書 21:15–17"> すると彼に言われた。「死人たちに彼らの中の死人たちを葬らせなさい。あなたは出て行って、神の国を言い広めなさい。」</span>
<span className="v" id="v61" data-v="61" data-xref="ルカの福音書 14:26; ルカの福音書 14:18–20; 1 Kings 19:20"> 別の人はこう言った。「主よ。あなたに従います。ただその前に、家の者にいとまごいに帰らせてください。」</span>
<span className="v" id="v62" data-v="62" data-xref="ピリピ人への手紙 3:13; ヘブル人への手紙 10:38; ペテロの手紙第二 2:20–22"> するとイエスは彼に言われた。「だれでも、手を鋤につけてから、うしろを見る者は、神の国にふさわしくありません。」</span>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="コロサイ人への手紙 4:2; ローマ人への手紙 12:12; テサロニケ人への手紙第一 5:17"> いつでも祈るべきであり、失望してはならないことを教えるために、イエスは彼らにたとえを話された。</span>
<span className="v" id="v2" data-v="2" data-xref="Proverbs 29:7; Psalms 8:1–4; ルカの福音書 18:4"> 「ある町に、神を恐れず、人を人とも思わない裁判官がいた。</span>
<span className="v" id="v3" data-v="3" data-xref="Isaiah 1:17; Jeremiah 5:28; Deuteronomy 27:19"> その町に、ひとりのやもめがいたが、彼のところにやって来ては、『私の相手をさばいて、私を守ってください。』と言っていた。</span>
<span className="v" id="v4" data-v="4" data-xref="ヘブル人への手紙 4:12–13; ルカの福音書 16:3; ルカの福音書 12:17"> 彼は、しばらくは取り合わないでいたが、後には心ひそかに『私は神を恐れず人を人とも思わないが、</span>
<span className="v" id="v5" data-v="5" data-xref="ルカの福音書 11:8; ルカの福音書 18:39; Judges 16:16"> どうも、このやもめは、うるさくてしかたがないから、この女のために裁判をしてやることにしよう。でないと、ひっきりなしにやって来てうるさくてしかたがない。』と言った。」</span>
<span className="v" id="v6" data-v="6" data-xref="ルカの福音書 7:13"> 主は言われた。「不正な裁判官の言っていることを聞きなさい。</span>
<span className="v" id="v7" data-v="7" data-xref="ヘブル人への手紙 10:35–37; ペテロの手紙第二 3:9; ルカの福音書 11:13"> まして神は、夜昼神を呼び求めている選民のためにさばきをつけないで、いつまでもそのことを放っておかれることがあるでしょうか。</span>
<span className="v" id="v8" data-v="8" data-xref="ヘブル人への手紙 10:23–26; ペテロの手紙第二 3:8–9; マタイの福音書 24:9–13"> あなたがたに言いますが、神は、すみやかに彼らのために正しいさばきをしてくださいます。しかし、人の子が来たとき、はたして地上に信仰が見られるでしょうか。」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="ルカの福音書 16:15; Proverbs 30:12; Isaiah 65:5"> 自分を義人だと自任し、他の人々を見下している者たちに対しては、イエスはこのようなたとえを話された。</span>
<span className="v" id="v10" data-v="10" data-xref="マタイの福音書 21:31–32; 1 Kings 8:30; 2 Kings 20:5"> 「ふたりの人が、祈るために宮に上った。ひとりはパリサイ人で、もうひとりは取税人であった。</span>
<span className="v" id="v11" data-v="11" data-xref="マタイの福音書 6:5; Isaiah 65:5; ヨハネの黙示録 3:17"> パリサイ人は、立って、心の中でこんな祈りをした。『神よ。私はほかの人々のようにゆする者、不正な者、姦淫する者ではなく、ことにこの取税人のようではないことを、感謝します。</span>
<span className="v" id="v12" data-v="12" data-xref="ルカの福音書 11:42; マタイの福音書 23:23–24; マタイの福音書 9:14"> 私は週に二度断食し、自分の受けるものはみな、その十分の一をささげております。』</span>
<span className="v" id="v13" data-v="13" data-xref="Ezra 9:6; ヨハネの手紙第一 1:8–10; テモテへの手紙第一 1:15"> ところが、取税人は遠く離れて立ち、目を天に向けようともせず、自分の胸をたたいて言った。『神さま。こんな罪人の私をあわれんでください。』</span>
<span className="v" id="v14" data-v="14" data-xref="ルカの福音書 14:11; ルカの福音書 16:15; ヤコブの手紙 4:10"> あなたがたに言うが、この人のほうが、前の人よりも、義と認められ、家に帰って行きました。なぜなら、だれでも自分を高くする者は低くされ、自分を低くする者は高くされるからです。」</span>
<span className="v" id="v15" data-v="15" data-xref="マルコの福音書 10:13–16; マタイの福音書 19:13–15; 1 Samuel 1:24"> イエスにさわっていただこうとして、人々がその幼子たちを、みもとに連れて来た。ところが、弟子たちがそれを見てしかった。</span>
<span className="v" id="v16" data-v="16" data-xref="マタイの福音書 18:3–4; コリント人への手紙第一 14:20; コリント人への手紙第一 7:14"> しかしイエスは、幼子たちを呼び寄せて、こう言われた。「子どもたちをわたしのところに来させなさい。止めてはいけません。神の国は、このような者たちのものです。</span>
<span className="v" id="v17" data-v="17" data-xref="マタイの福音書 18:3; マルコの福音書 10:15; Psalms 131:1–2"> まことに、あなたがたに告げます。子どものように神の国を受け入れる者でなければ、決してそこに、はいることはできません。」</span>
<span className="v" id="v18" data-v="18" data-xref="マルコの福音書 10:17–31; 使徒の働き 16:30; マタイの福音書 19:16–30"> またある役人が、イエスに質問して言った。「尊い先生。私は何をしたら、永遠のいのちを自分のものとして受けることができるでしょうか。」</span>
<span className="v" id="v19" data-v="19" data-xref="Job 15:14–16; ヤコブの手紙 1:17; ヘブル人への手紙 7:26"> イエスは彼に言われた。「なぜ、わたしを『尊い』と言うのですか。尊い方は、神おひとりのほかにはだれもありません。</span>
<span className="v" id="v20" data-v="20" data-xref="Exodus 20:12–17; Deuteronomy 5:16–21; ローマ人への手紙 13:9"> 戒めはあなたもよく知っているはずです。『姦淫してはならない。殺してはならない。盗んではならない。偽証を立ててはならない。父と母を敬え。』」</span>
<span className="v" id="v21" data-v="21" data-xref="ピリピ人への手紙 3:6; ローマ人への手紙 10:2–3; マルコの福音書 10:20–21"> すると彼は言った。「そのようなことはみな、小さい時から守っております。」</span>
<span className="v" id="v22" data-v="22" data-xref="ルカの福音書 12:33; テモテへの手紙第一 6:18–19; マタイの福音書 19:21"> イエスはこれを聞いて、その人に言われた。「あなたには、まだ一つだけ欠けたものがあります。あなたの持ち物を全部売り払い、貧しい人々に分けてやりなさい。そうすれば、あなたは天に宝を積むことになります。そのうえで、わたしについて来なさい。」</span>
<span className="v" id="v23" data-v="23" data-xref="Ezekiel 33:31; ヨハネの手紙第一 2:15; Job 31:24–25"> すると彼は、これを聞いて、非常に悲しんだ。たいへんな金持ちだったからである。</span>
<span className="v" id="v24" data-v="24" data-xref="Proverbs 30:9; ヤコブの手紙 2:5–7; マルコの福音書 10:23–27"> イエスは彼を見てこう言われた。「裕福な者が神の国にはいることは、何とむずかしいことでしょう。</span>
<span className="v" id="v25" data-v="25" data-xref="マタイの福音書 23:24"> 金持ちが神の国にはいるよりは、らくだが針の穴を通るほうがもっとやさしい。」</span>
<span className="v" id="v26" data-v="26" data-xref="ルカの福音書 13:23"> これを聞いた人々が言った。「それでは、だれが救われることができるでしょう。」</span>
<span className="v" id="v27" data-v="27" data-xref="Jeremiah 32:17; マタイの福音書 19:26; ルカの福音書 1:37"> イエスは言われた。「人にはできないことが、神にはできるのです。」</span>
<span className="v" id="v28" data-v="28" data-xref="マルコの福音書 10:28; ピリピ人への手紙 3:7; マタイの福音書 19:27"> すると、ペテロが言った。「ご覧ください。私たちは自分の家を捨てて従ってまいりました。」</span>
<span className="v" id="v29" data-v="29" data-xref="マルコの福音書 10:29–31; マタイの福音書 10:37–39; ルカの福音書 14:26–28"> イエスは彼らに言われた。「まことに、あなたがたに告げます。神の国のために、家、妻、兄弟、両親、子どもを捨てた者で、だれひとりとして、</span>
<span className="v" id="v30" data-v="30" data-xref="ヘブル人への手紙 13:5–6; Job 42:10; ヨハネの黙示録 2:17"> この世にあってその幾倍かを受けない者はなく、後の世で永遠のいのちを受けない者はありません。」</span>
<span className="v" id="v31" data-v="31" data-xref="マタイの福音書 20:17–19; Isaiah 53:1–12; Psalms 22:1–31"> さてイエスは、十二弟子をそばに呼んで、彼らに話された。「さあ、これから、わたしたちはエルサレムに向かって行きます。人の子について預言者たちが書いているすべてのことが実現されるのです。</span>
<span className="v" id="v32" data-v="32" data-xref="ルカの福音書 23:11; Isaiah 50:6; Isaiah 53:3"> 人の子は異邦人に引き渡され、そして彼らにあざけられ、はずかしめられ、つばきをかけられます。</span>
<span className="v" id="v33" data-v="33" data-xref="コリント人への手紙第一 15:3–4; ルカの福音書 24:7; マタイの福音書 27:63"> 彼らは人の子をむちで打ってから殺します。しかし、人の子は三日目によみがえります。」</span>
<span className="v" id="v34" data-v="34" data-xref="ルカの福音書 9:45; マルコの福音書 9:32; ルカの福音書 24:25"> しかし弟子たちには、これらのことが何一つわからなかった。彼らには、このことばは隠されていて、話された事が理解できなかった。</span>
<span className="v" id="v35" data-v="35" data-xref="マタイの福音書 20:29–34; マルコの福音書 10:46–52; ルカの福音書 16:20–21"> イエスがエリコに近づかれたころ、ある盲人が、道ばたにすわり、物ごいをしていた。</span>
<span className="v" id="v36" data-v="36" data-xref="マタイの福音書 21:10–11; ルカの福音書 15:26"> 群衆が通って行くのを耳にして、これはいったい何事ですか、と尋ねた。</span>
<span className="v" id="v37" data-v="37" data-xref="マタイの福音書 2:23; ヨハネの福音書 19:19; ヨハネの福音書 12:35–36"> ナザレのイエスがお通りになるのだ、と知らせると、</span>
<span className="v" id="v38" data-v="38" data-xref="マタイの福音書 9:27; ルカの福音書 18:39; マタイの福音書 15:22"> 彼は大声で、「ダビデの子のイエスさま。私をあわれんでください。」と言った。</span>
<span className="v" id="v39" data-v="39" data-xref="Genesis 32:26–28; Psalms 141:1; ルカの福音書 18:15"> 彼を黙らせようとして、先頭にいた人々がたしなめたが、盲人は、ますます「ダビデの子よ。私をあわれんでください。」と叫び立てた。</span>
<span className="v" id="v40" data-v="40" data-xref="マタイの福音書 20:31–34; マルコの福音書 10:48–52"> イエスは立ち止まって、彼をそばに連れて来るように言いつけられた。</span>
<span className="v" id="v41" data-v="41" data-xref="1 Kings 3:5–15; マタイの福音書 20:21–22; ピリピ人への手紙 4:6"> 彼が近寄って来たので、「わたしに何をしてほしいのか。」と尋ねられると、彼は、「主よ。目が見えるようになることです。」と言った。</span>
<span className="v" id="v42" data-v="42" data-xref="マタイの福音書 8:3; ルカの福音書 8:48; ルカの福音書 17:19"> イエスが彼に、「見えるようになれ。あなたの信仰があなたを直したのです。」と言われると、</span>
<span className="v" id="v43" data-v="43" data-xref="Psalms 146:8; テサロニケ人への手紙第二 1:10–12; Isaiah 43:21"> 彼はたちどころに目が見えるようになり、神をあがめながらイエスについて行った。これを見て民はみな神を賛美した。</span>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ペテロの手紙第一 2:1; コリント人への手紙第一 5:7–8; ヤコブの手紙 3:17"> そうこうしている間に、おびただしい数の群衆が集まって来て、互いに足を踏み合うほどになった。イエスはまず弟子たちに対して、話しだされた。「パリサイ人のパン種に気をつけなさい。それは彼らの偽善のことです。</span>
<span className="v" id="v2" data-v="2" data-xref="マルコの福音書 4:22; ルカの福音書 8:17; コリント人への手紙第二 5:10"> おおいかぶされているもので、現わされないものはなく、隠されているもので、知られずに済むものはありません。</span>
<span className="v" id="v3" data-v="3" data-xref="マタイの福音書 10:27; マタイの福音書 12:36; Ecclesiastes 10:20"> ですから、あなたがたが暗やみで言ったことが、明るみで聞かれ、家の中でささやいたことが、屋上で言い広められます。</span>
<span className="v" id="v4" data-v="4" data-xref="マタイの福音書 10:28; Jeremiah 1:8; ヨハネの黙示録 2:10"> そこで、わたしの友であるあなたがたに言います。からだを殺しても、あとはそれ以上何もできない人間たちを恐れてはいけません。</span>
<span className="v" id="v5" data-v="5" data-xref="ペテロの手紙第二 2:4; マタイの福音書 10:28; ヨハネの黙示録 14:7"> 恐れなければならない方を、あなたがたに教えてあげましょう。殺したあとで、ゲヘナに投げ込む権威を持っておられる方を恐れなさい。そうです。あなたがたに言います。この方を恐れなさい。</span>
<span className="v" id="v6" data-v="6" data-xref="ルカの福音書 12:24; Psalms 145:15–16; Psalms 147:9"> 五羽の雀は二アサリオンで売っているでしょう。そんな雀の一羽でも、神の御前には忘れられてはいません。</span>
<span className="v" id="v7" data-v="7" data-xref="マタイの福音書 10:30–31; マタイの福音書 6:26; Isaiah 43:3–4"> それどころか、あなたがたの頭の毛さえも、みな数えられています。恐れることはありません。あなたがたは、たくさんの雀よりもすぐれた者です。</span>
<span className="v" id="v8" data-v="8" data-xref="マタイの福音書 10:32–33; ヨハネの手紙第一 2:23; ローマ人への手紙 10:9–10"> そこで、あなたがたに言います。だれでも、わたしを人の前で認める者は、人の子もまた、その人を神の御使いたちの前で認めます。</span>
<span className="v" id="v9" data-v="9" data-xref="テモテへの手紙第二 2:12; ルカの福音書 9:26; マルコの福音書 8:38"> しかし、わたしを人の前で知らないと言う者は、神の御使いたちの前で知らないと言われます。</span>
<span className="v" id="v10" data-v="10" data-xref="マタイの福音書 12:31–32; ヨハネの手紙第一 5:16; テモテへの手紙第一 1:13"> たとい、人の子をそしることばを使う者があっても、赦されます。しかし、聖霊をけがす者は赦されません。</span>
<span className="v" id="v11" data-v="11" data-xref="マタイの福音書 10:17–20; ルカの福音書 21:12–14; 使徒の働き 4:5–7"> また、人々があなたがたを、会堂や役人や権力者などのところに連れて行ったとき、何をどう弁明しようか、何を言おうかと心配するには及びません。</span>
<span className="v" id="v12" data-v="12" data-xref="ルカの福音書 21:15; マタイの福音書 10:20; 使徒の働き 4:8"> 言うべきことは、そのときに聖霊が教えてくださるからです。」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="ルカの福音書 6:45; テモテへの手紙第一 6:5; Ezekiel 33:31"> 群衆の中のひとりが、「先生。私と遺産を分けるように私の兄弟に話してください。」と言った。</span>
<span className="v" id="v14" data-v="14" data-xref="ローマ人への手紙 2:3; ローマ人への手紙 2:1; ローマ人への手紙 9:20"> すると彼に言われた。「いったいだれが、わたしをあなたがたの裁判官や調停者に任命したのですか。」</span>
<span className="v" id="v15" data-v="15" data-xref="ヘブル人への手紙 13:5; テモテへの手紙第一 6:6–10; Psalms 119:36–37"> そして人々に言われた。「どんな貪欲にも注意して、よく警戒しなさい。なぜなら、いくら豊かな人でも、その人のいのちは財産にあるのではないからです。」</span>
<span className="v" id="v16" data-v="16" data-xref="Genesis 26:12–14; Hosea 2:8; Genesis 41:47–49"> それから人々にたとえを話された。<br />「ある金持ちの畑が豊作であった。</span>
<span className="v" id="v17" data-v="17" data-xref="マタイの福音書 5:42; Isaiah 58:7; ローマ人への手紙 12:13"> そこで彼は、心の中でこう言いながら考えた。『どうしよう。作物をたくわえておく場所がない。』</span>
<span className="v" id="v18" data-v="18" data-xref="ヤコブの手紙 3:15; ヤコブの手紙 4:15; ルカの福音書 12:21"> そして言った。『こうしよう。あの倉を取りこわして、もっと大きいのを建て、穀物や財産はみなそこにしまっておこう。</span>
<span className="v" id="v19" data-v="19" data-xref="Proverbs 27:1; ヤコブの手紙 4:13–15; コリント人への手紙第一 15:32"> そして、自分のたましいにこう言おう。「たましいよ。これから先何年分もいっぱい物がためられた。さあ、安心して、食べて、飲んで、楽しめ。」』</span>
<span className="v" id="v20" data-v="20" data-xref="Job 27:8; Jeremiah 17:11; テモテへの手紙第一 6:7"> しかし神は彼に言われた。『愚か者。おまえのたましいは、今夜おまえから取り去られる。そうしたら、おまえが用意した物は、いったいだれのものになるのか。』</span>
<span className="v" id="v21" data-v="21" data-xref="マタイの福音書 6:19–20; ルカの福音書 12:33; ヤコブの手紙 2:5"> 自分のためにたくわえても、神の前に富まない者はこのとおりです。」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="マタイの福音書 6:25–34; ピリピ人への手紙 4:6; ヘブル人への手紙 13:5"> それから弟子たちに言われた。「だから、わたしはあなたがたに言います。いのちのことで何を食べようかと心配したり、からだのことで何を着ようかと心配したりするのはやめなさい。</span>
<span className="v" id="v23" data-v="23" data-xref="Job 2:6; Proverbs 13:8; Job 2:4"> いのちは食べ物よりたいせつであり、からだは着物よりたいせつだからです。</span>
<span className="v" id="v24" data-v="24" data-xref="マタイの福音書 10:31; Psalms 147:9; ルカの福音書 12:7"> 烏のことを考えてみなさい。蒔きもせず、刈り入れもせず、納屋も倉もありません。けれども、神が彼らを養っていてくださいます。あなたがたは、鳥よりも、はるかにすぐれたものです。</span>
<span className="v" id="v25" data-v="25" data-xref="マタイの福音書 6:27; マタイの福音書 5:36; ルカの福音書 19:3"> あなたがたのうちのだれが、心配したからといって、自分のいのちを少しでも延ばすことができますか。</span>
<span className="v" id="v26" data-v="26" data-xref="ペテロの手紙第一 5:7; Psalms 39:6; Ecclesiastes 7:13"> こんな小さなことさえできないで、なぜほかのことまで心配するのですか。</span>
<span className="v" id="v27" data-v="27" data-xref="マタイの福音書 6:28–30; ルカの福音書 12:24; 1 Kings 10:1–13"> ゆりの花のことを考えてみなさい。どうして育つのか。紡ぎもせず、織りもしないのです。しかし、わたしはあなたがたに言います。栄華を窮めたソロモンでさえ、このような花の一つほどにも着飾ってはいませんでした。</span>
<span className="v" id="v28" data-v="28" data-xref="マタイの福音書 14:31; Isaiah 40:6; マタイの福音書 6:30"> しかし、きょうは野にあって、あすは炉に投げ込まれる草をさえ、神はこのように装ってくださるのです。ましてあなたがたには、どんなによくしてくださることでしょう。ああ、信仰の薄い人たち。</span>
<span className="v" id="v29" data-v="29" data-xref="マタイの福音書 6:31; ルカの福音書 12:22; ルカの福音書 22:35"> 何を食べたらよいか、何を飲んだらよいか、と捜し求めることをやめ、気をもむことをやめなさい。</span>
<span className="v" id="v30" data-v="30" data-xref="マタイの福音書 6:32; マタイの福音書 6:8; エペソ人への手紙 4:17"> これらはみな、この世の異邦人たちが切に求めているものです。しかし、あなたがたの父は、それがあなたがたにも必要であることを知っておられます。</span>
<span className="v" id="v31" data-v="31" data-xref="マタイの福音書 6:33; ヘブル人への手紙 13:5; Psalms 34:9"> 何はともあれ、あなたがたは、神の国を求めなさい。そうすれば、これらの物は、それに加えて与えられます。</span>
<span className="v" id="v32" data-v="32" data-xref="ヘブル人への手紙 12:28; ペテロの手紙第一 1:3–5; ヨハネの黙示録 1:6"> 小さな群れよ。恐れることはありません。あなたがたの父である神は、喜んであなたがたに御国をお与えになるからです。</span>
<span className="v" id="v33" data-v="33" data-xref="マタイの福音書 19:21; 使徒の働き 4:34–35; 使徒の働き 2:45"> 持ち物を売って、施しをしなさい。自分のために、古くならない財布を作り、朽ちることのない宝を天に積み上げなさい。そこには、盗人も近寄らず、しみもいためることがありません。</span>
<span className="v" id="v34" data-v="34" data-xref="コロサイ人への手紙 3:1–3; マタイの福音書 6:21; ピリピ人への手紙 3:20"> あなたがたの宝のあるところに、あなたがたの心もあるからです。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="ペテロの手紙第一 1:13; エペソ人への手紙 6:14; マタイの福音書 25:4–10"> 腰に帯を締め、あかりをともしていなさい。</span>
<span className="v" id="v36" data-v="36" data-xref="ユダの手紙 1:20–21; ヤコブの手紙 5:7–8; ヨハネの黙示録 3:20"> 主人が婚礼から帰って来て戸をたたいたら、すぐに戸をあけようと、その帰りを待ち受けている人たちのようでありなさい。</span>
<span className="v" id="v37" data-v="37" data-xref="ペテロの手紙第二 3:14; マタイの福音書 24:42; ヨハネの福音書 13:4–5"> 帰って来た主人に、目をさましているところを見られるしもべたちは幸いです。まことに、あなたがたに告げます。主人のほうが帯を締め、そのしもべたちを食卓に着かせ、そばにいて給仕をしてくれます。</span>
<span className="v" id="v38" data-v="38" data-xref="テサロニケ人への手紙第一 5:4–5; マタイの福音書 25:6"> 主人が真夜中に帰っても、夜明けに帰っても、いつでもそのようであることを見られるなら、そのしもべたちは幸いです。</span>
<span className="v" id="v39" data-v="39" data-xref="ペテロの手紙第二 3:10; ヨハネの黙示録 3:3; ヨハネの黙示録 16:15"> このことを知っておきなさい。もしも家の主人が、どろぼうの来る時間を知っていたなら、おめおめと自分の家に押し入られはしなかったでしょう。</span>
<span className="v" id="v40" data-v="40" data-xref="テサロニケ人への手紙第一 5:6; マタイの福音書 25:13; ローマ人への手紙 13:11"> あなたがたも用心していなさい。人の子は、思いがけない時に来るのですから。」</span>
<span className="v" id="v41" data-v="41" data-xref="マルコの福音書 13:37; ペテロの手紙第一 4:7; ペテロの手紙第一 5:8"> そこで、ペテロが言った。「主よ。このたとえは私たちのために話してくださるのですか。それともみなのためなのですか。」</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="マタイの福音書 24:45–46; ペテロの手紙第一 5:1–4; ヘブル人への手紙 13:17"> 主は言われた。「では、主人から、その家のしもべたちを任されて、食事時には彼らに食べ物を与える忠実な思慮深い管理人とは、いったいだれでしょう。</span>
<span className="v" id="v43" data-v="43"> 主人が帰って来たときに、そのようにしているのを見られるしもべは幸いです。</span>
<span className="v" id="v44" data-v="44" data-xref="ルカの福音書 22:29–30; マタイの福音書 24:47; ルカの福音書 19:17–19"> わたしは真実をあなたがたに告げます。主人は彼に自分の全財産を任せるようになります。</span>
<span className="v" id="v45" data-v="45" data-xref="マタイの福音書 24:48–50; ヨハネの黙示録 18:7–8; ピリピ人への手紙 3:18–19"> ところが、もし、そのしもべが、『主人の帰りはまだだ。』と心の中で思い、下男や下女を打ちたたき、食べたり飲んだり、酒に酔ったりし始めると、</span>
<span className="v" id="v46" data-v="46" data-xref="ルカの福音書 12:40; マタイの福音書 24:51; Psalms 11:5"> しもべの主人は、思いがけない日の思わぬ時間に帰って来ます。そして、彼をきびしく罰して、不忠実な者どもと同じめに会わせるに違いありません。</span>
<span className="v" id="v47" data-v="47" data-xref="ヤコブの手紙 4:17; ヨハネの福音書 9:41; ヨハネの福音書 12:48"> 主人の心を知りながら、その思いどおりに用意もせず、働きもしなかったしもべは、ひどくむち打たれます。</span>
<span className="v" id="v48" data-v="48" data-xref="ヤコブの手紙 3:1; Leviticus 5:17; ルカの福音書 16:10–12"> しかし、知らずにいたために、むち打たれるようなことをしたしもべは、打たれても、少しで済みます。すべて、多く与えられた者は多く求められ、多く任された者は多く要求されます。</span>
</div>
<div className="bp">
<span className="v" id="v49" data-v="49" data-xref="Malachi 4:1; ルカの福音書 12:51–52; マタイの福音書 3:10–12"> わたしが来たのは、地に火を投げ込むためです。だから、その火が燃えていたらと、どんなに願っていることでしょう。</span>
<span className="v" id="v50" data-v="50" data-xref="ヨハネの福音書 12:27–28; ヨハネの福音書 19:30; ヨハネの福音書 7:6–8"> しかし、わたしには受けるバプテスマがあります。それが成し遂げられるまでは、どんなに苦しむことでしょう。</span>
<span className="v" id="v51" data-v="51" data-xref="マタイの福音書 10:34–36; ルカの福音書 12:49; マタイの福音書 24:7–10"> あなたがたは、地に平和を与えるためにわたしが来たと思っているのですか。そうではありません。あなたがたに言いますが、むしろ、分裂です。</span>
<span className="v" id="v52" data-v="52" data-xref="使徒の働き 14:1–4; ヨハネの福音書 15:18–21; Micah 7:5–6"> 今から、一家五人は、三人がふたりに、ふたりが三人に対抗して分かれるようになります。</span>
<span className="v" id="v53" data-v="53" data-xref="Micah 7:6; マタイの福音書 10:21–22; マタイの福音書 24:10"> 父は息子に、息子は父に対抗し、母は娘に、娘は母に対抗し、しゅうとめは嫁に、嫁はしゅうとめに対抗して分かれるようになります。」</span>
</div>
<div className="bp">
<span className="v" id="v54" data-v="54" data-xref="マタイの福音書 16:2–4; 1 Kings 18:44–45"> 群衆にもこう言われた。「あなたがたは、西に雲が起こるのを見るとすぐに、『にわか雨が来るぞ。』と言い、事実そのとおりになります。</span>
<span className="v" id="v55" data-v="55" data-xref="Job 37:17; マタイの福音書 20:12"> また南風が吹きだすと、『暑い日になるぞ。』と言い、事実そのとおりになります。</span>
<span className="v" id="v56" data-v="56" data-xref="マタイの福音書 16:3; マタイの福音書 24:32–33; マタイの福音書 11:25"> 偽善者たち。あなたがたは地や空の現象を見分けることを知りながら、どうして今のこの時代を見分けることができないのですか。</span>
<span className="v" id="v57" data-v="57" data-xref="Deuteronomy 32:29; ヨハネの福音書 7:24; 使徒の働き 13:26–38"> また、なぜ自分から進んで、何が正しいかを判断しないのですか。</span>
<span className="v" id="v58" data-v="58" data-xref="Proverbs 25:8–9; マタイの福音書 5:23–26; ルカの福音書 13:24–28"> あなたを告訴する者といっしょに役人の前に行くときは、途中でも、熱心に彼と和解するよう努めなさい。そうでないと、その人はあなたを裁判官のもとにひっぱって行きます。裁判官は執行人に引き渡し、執行人は牢に投げ込んでしまいます。</span>
<span className="v" id="v59" data-v="59" data-xref="マルコの福音書 12:42; マタイの福音書 18:34; マタイの福音書 25:46"> あなたに言います。最後の一レプタを支払うまでは、そこから決して出られないのです。」</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨハネの福音書 20:1–2; マルコの福音書 16:1–8; マタイの福音書 28:1–8"> 週の初めの日の明け方早く、女たちは、準備しておいた香料を持って墓に着いた。</span>
<span className="v" id="v2" data-v="2" data-xref="マルコの福音書 16:3–4; マタイの福音書 27:60–66; マルコの福音書 15:46–47"> 見ると、石が墓からわきにころがしてあった。</span>
<span className="v" id="v3" data-v="3" data-xref="ルカの福音書 24:23; ヨハネの福音書 20:6–7; マタイの福音書 16:5"> はいって見ると、主イエスのからだはなかった。</span>
<span className="v" id="v4" data-v="4" data-xref="マルコの福音書 16:5; ヨハネの福音書 20:11–12; 使徒の働き 1:10"> そのため女たちが途方にくれていると、見よ、まばゆいばかりの衣を着たふたりの人が、女たちの近くに来た。</span>
<span className="v" id="v5" data-v="5" data-xref="マルコの福音書 16:5–6; マタイの福音書 28:3–5; ヨハネの黙示録 1:18"> 恐ろしくなって、地面に顔を伏せていると、その人たちはこう言った。「あなたがたは、なぜ生きている方を死人の中で捜すのですか。</span>
<span className="v" id="v6" data-v="6" data-xref="マタイの福音書 17:22–23; ルカの福音書 9:22; マルコの福音書 8:31"> ここにはおられません。よみがえられたのです。まだガリラヤにおられたころ、お話しになったことを思い出しなさい。</span>
<span className="v" id="v7" data-v="7" data-xref="マタイの福音書 16:21"> 人の子は必ず罪人らの手に引き渡され、十字架につけられ、三日目によみがえらなければならない、と言われたでしょう。」</span>
<span className="v" id="v8" data-v="8" data-xref="ヨハネの福音書 12:16; ヨハネの福音書 14:26; ヨハネの福音書 2:19–22"> 女たちはイエスのみことばを思い出した。</span>
<span className="v" id="v9" data-v="9" data-xref="ルカの福音書 24:22–24; マルコの福音書 16:7–8; マタイの福音書 28:7–8"> そして、墓から戻って、十一弟子とそのほかの人たち全部に、一部始終を報告した。</span>
<span className="v" id="v10" data-v="10" data-xref="マタイの福音書 27:56; ヨハネの福音書 20:11–18; ルカの福音書 8:2–3"> この女たちは、マグダラのマリヤとヨハンナとヤコブの母マリヤとであった。彼女たちといっしょにいたほかの女たちも、このことを使徒たちに話した。</span>
<span className="v" id="v11" data-v="11" data-xref="Job 9:16; マルコの福音書 16:11; Genesis 19:14"> ところが使徒たちにはこの話はたわごとと思われたので、彼らは女たちを信用しなかった。</span>
<span className="v" id="v12" data-v="12" data-xref="ヨハネの福音書 20:3–10"> ［しかしペテロは、立ち上がると走って墓へ行き、かがんでのぞき込んだところ、亜麻布だけがあった。それで、この出来事に驚いて家に帰った。］</span>
<span className="v" id="v13" data-v="13" data-xref="ルカの福音書 24:18; マルコの福音書 16:12–13"> ちょうどこの日、ふたりの弟子が、エルサレムから十一キロメートル余り離れたエマオという村に行く途中であった。</span>
<span className="v" id="v14" data-v="14" data-xref="ルカの福音書 6:45; Deuteronomy 6:7; Malachi 3:6"> そして、ふたりでこのいっさいの出来事について話し合っていた。</span>
<span className="v" id="v15" data-v="15" data-xref="マタイの福音書 18:20; ヨハネの福音書 14:18–19; ルカの福音書 24:36"> 話し合ったり、論じ合ったりしているうちに、イエスご自身が近づいて、彼らとともに道を歩いておられた。</span>
<span className="v" id="v16" data-v="16" data-xref="ヨハネの福音書 20:14; ヨハネの福音書 21:4; ルカの福音書 24:31"> しかしふたりの目はさえぎられていて、イエスだとはわからなかった。</span>
<span className="v" id="v17" data-v="17" data-xref="ヨハネの福音書 16:20–22; ヨハネの福音書 16:6; Ezekiel 9:4–6"> イエスは彼らに言われた。「歩きながらふたりで話し合っているその話は、何のことですか。」すると、ふたりは暗い顔つきになって、立ち止まった。</span>
<span className="v" id="v18" data-v="18" data-xref="ヨハネの福音書 19:25"> クレオパというほうが答えて言った。「エルサレムにいながら、近ごろそこで起こった事を、あなただけが知らなかったのですか。」</span>
<span className="v" id="v19" data-v="19" data-xref="マタイの福音書 21:11; 使徒の働き 7:22; ヨハネの福音書 4:19"> イエスが、「どんな事ですか。」と聞かれると、ふたりは答えた。「ナザレ人イエスのことです。この方は、神とすべての民の前で、行ないにもことばにも力のある預言者でした。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒の働き 3:13–15; 使徒の働き 4:8–10; ルカの福音書 23:13"> それなのに、私たちの祭司長や指導者たちは、この方を引き渡して、死刑に定め、十字架につけたのです。</span>
<span className="v" id="v21" data-v="21" data-xref="ルカの福音書 1:68; ペテロの手紙第一 1:18–19; ルカの福音書 2:38"> しかし私たちは、この方こそイスラエルを贖ってくださるはずだ、と望みをかけていました。事実、そればかりでなく、その事があってから三日目になりますが、</span>
<span className="v" id="v22" data-v="22" data-xref="マルコの福音書 16:9–10; マタイの福音書 28:7–8; ヨハネの福音書 20:1–2"> また仲間の女たちが私たちを驚かせました。その女たちは朝早く墓に行ってみましたが、</span>
<span className="v" id="v23" data-v="23"> イエスのからだが見当たらないので、戻って来ました。そして御使いたちの幻を見たが、御使いたちがイエスは生きておられると告げた、と言うのです。</span>
<span className="v" id="v24" data-v="24" data-xref="ルカの福音書 24:12; ヨハネの福音書 20:1–10"> それで、仲間の何人かが墓に行ってみたのですが、はたして女たちの言ったとおりで、イエスさまは見当たらなかった、というのです。」</span>
<span className="v" id="v25" data-v="25" data-xref="マルコの福音書 7:18; マルコの福音書 9:19; ヘブル人への手紙 5:11–12"> するとイエスは言われた。「ああ、愚かな人たち。預言者たちの言ったすべてを信じない、心の鈍い人たち。</span>
<span className="v" id="v26" data-v="26" data-xref="ペテロの手紙第一 1:11; Isaiah 53:1–12; Zechariah 13:7"> キリストは、必ず、そのような苦しみを受けて、それから、彼の栄光にはいるはずではなかったのですか。」</span>
<span className="v" id="v27" data-v="27" data-xref="Isaiah 7:14; ルカの福音書 24:44; Deuteronomy 18:15"> それから、イエスは、モーセおよびすべての預言者から始めて、聖書全体の中で、ご自分について書いてある事がらを彼らに説き明かされた。</span>
<span className="v" id="v28" data-v="28" data-xref="マルコの福音書 6:48; Genesis 19:2; Genesis 32:26"> 彼らは目的の村に近づいたが、イエスはまだ先へ行きそうなご様子であった。</span>
<span className="v" id="v29" data-v="29" data-xref="2 Kings 4:8; ルカの福音書 14:23; Genesis 19:3"> それで、彼らが、「いっしょにお泊まりください。そろそろ夕刻になりますし、日もおおかた傾きましたから。」と言って無理に願ったので、イエスは彼らといっしょに泊まるために中にはいられた。</span>
<span className="v" id="v30" data-v="30" data-xref="マタイの福音書 14:19; ルカの福音書 24:35; マタイの福音書 15:36"> 彼らとともに食卓に着かれると、イエスはパンを取って祝福し、裂いて彼らに渡された。</span>
<span className="v" id="v31" data-v="31" data-xref="ルカの福音書 24:16; ヨハネの福音書 8:59; ルカの福音書 4:30"> それで、彼らの目が開かれ、イエスだとわかった。するとイエスは、彼らには見えなくなった。</span>
<span className="v" id="v32" data-v="32" data-xref="ルカの福音書 24:45; Jeremiah 23:29; ヘブル人への手紙 4:12"> そこでふたりは話し合った。「道々お話しになっている間も、聖書を説明してくださった間も、私たちの心はうちに燃えていたではないか。」</span>
<span className="v" id="v33" data-v="33" data-xref="マルコの福音書 16:13; ヨハネの福音書 20:19–26; 使徒の働き 1:14"> すぐさまふたりは立って、エルサレムに戻ってみると、十一使徒とその仲間が集まって、</span>
<span className="v" id="v34" data-v="34" data-xref="コリント人への手紙第一 15:5; マルコの福音書 16:7; ルカの福音書 22:54–62"> 「ほんとうに主はよみがえって、シモンにお姿を現わされた。」と言っていた。</span>
<span className="v" id="v35" data-v="35" data-xref="マルコの福音書 16:12–13; 使徒の働き 2:42; ルカの福音書 24:30–31"> 彼らも、道であったいろいろなことや、パンを裂かれたときにイエスだとわかった次第を話した。</span>
<span className="v" id="v36" data-v="36" data-xref="テサロニケ人への手紙第二 3:16; Isaiah 57:18; マルコの福音書 16:14"> これらのことを話している間に、イエスご自身が彼らの真中に立たれた。</span>
<span className="v" id="v37" data-v="37" data-xref="1 Samuel 28:13; マタイの福音書 14:26–27; Job 4:14–16"> 彼らは驚き恐れて、霊を見ているのだと思った。</span>
<span className="v" id="v38" data-v="38" data-xref="Jeremiah 4:14; ヘブル人への手紙 4:13; Daniel 4:19"> すると、イエスは言われた。「なぜ取り乱しているのですか。どうして心に疑いを起こすのですか。</span>
<span className="v" id="v39" data-v="39" data-xref="ヨハネの福音書 20:27; ヨハネの手紙第一 1:1; Ecclesiastes 12:7"> わたしの手やわたしの足を見なさい。まさしくわたしです。わたしにさわって、よく見なさい。霊ならこんな肉や骨はありません。わたしは持っています。」</span>
<span className="v" id="v40" data-v="40"> それでも、彼らは、うれしさのあまりまだ信じられず、不思議がっているので、イエスは、「ここに何か食べ物がありますか。」と言われた。</span>
<span className="v" id="v42" data-v="42"> それで、焼いた魚を一切れ差し上げると、</span>
<span className="v" id="v43" data-v="43" data-xref="使徒の働き 10:41"> イエスは、彼らの前で、それを取って召し上がった。</span>
<span className="v" id="v44" data-v="44" data-xref="Zechariah 12:10; ルカの福音書 24:26–27; Zechariah 9:9"> さて、そこでイエスは言われた。「わたしがまだあなたがたといっしょにいたころ、あなたがたに話したことばはこうです。わたしについてモーセの律法と預言者と詩篇とに書いてあることは、必ず全部成就するということでした。」</span>
<span className="v" id="v45" data-v="45" data-xref="使徒の働き 16:14; ヨハネの手紙第一 5:20; Psalms 119:18"> そこで、イエスは、聖書を悟らせるために彼らの心を開いて、</span>
<span className="v" id="v46" data-v="46" data-xref="Isaiah 53:2–12; Isaiah 50:6; ルカの福音書 24:44"> こう言われた。「次のように書いてあります。キリストは苦しみを受け、三日目に死人の中からよみがえり、</span>
<span className="v" id="v47" data-v="47" data-xref="使徒の働き 5:31; Isaiah 49:6; 使徒の働き 2:38"> その名によって、罪の赦しを得させる悔い改めが、エルサレムから始まってあらゆる国の人々に宣べ伝えられる。</span>
<span className="v" id="v48" data-v="48" data-xref="使徒の働き 1:8; 使徒の働き 2:32; 使徒の働き 13:31"> あなたがたは、これらのことの証人です。</span>
<span className="v" id="v49" data-v="49" data-xref="使徒の働き 1:8; 使徒の働き 1:4; Joel 2:28–32"> さあ、わたしは、わたしの父の約束してくださったものをあなたがたに送ります。あなたがたは、いと高き所から力を着せられるまでは、都にとどまっていなさい。」</span>
<span className="v" id="v50" data-v="50" data-xref="使徒の働き 1:12; マタイの福音書 21:17; マルコの福音書 11:1"> それから、イエスは、彼らをベタニヤまで連れて行き、手を上げて祝福された。</span>
<span className="v" id="v51" data-v="51" data-xref="使徒の働き 1:9; マルコの福音書 16:19; 2 Kings 2:11"> そして祝福しながら、彼らから離れて行かれた。</span>
<span className="v" id="v52" data-v="52" data-xref="マタイの福音書 28:9; ヨハネの福音書 16:22; Psalms 30:11"> 彼らは、非常な喜びを抱いてエルサレムに帰り、</span>
<span className="v" id="v53" data-v="53" data-xref="マルコの福音書 16:20; 使徒の働き 2:46–47; 使徒の働き 5:41–42"> いつも宮にいて神をほめたたえていた。</span>

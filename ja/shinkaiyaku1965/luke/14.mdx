<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マルコの福音書 3:2; ルカの福音書 20:20; Psalms 62:4"> ある安息日に、食事をしようとして、パリサイ派のある指導者の家にはいられたとき、みんながじっとイエスを見つめていた。</span>
<span className="v" id="v2" data-v="2"> そこには、イエスの真正面に、水腫をわずらっている人がいた。</span>
<span className="v" id="v3" data-v="3" data-xref="マタイの福音書 12:10; マルコの福音書 3:4; ルカの福音書 13:14–16"> イエスは、律法の専門家、パリサイ人たちに、「安息日に病気を直すことは正しいことですか、それともよくないことですか。」と言われた。</span>
<span className="v" id="v4" data-v="4" data-xref="マタイの福音書 22:46; マタイの福音書 21:25–27"> しかし、彼らは黙っていた。それで、イエスはその人を抱いて直してやり、そしてお帰しになった。</span>
<span className="v" id="v5" data-v="5" data-xref="ルカの福音書 13:15; Exodus 23:4–5; マタイの福音書 12:11–12"> それから、彼らに言われた。「自分の息子や牛が井戸に落ちたのに、安息日だからといって、すぐに引き上げてやらない者があなたがたのうちにいるでしょうか。」</span>
<span className="v" id="v6" data-v="6" data-xref="ルカの福音書 20:40; ルカの福音書 21:15; 使徒の働き 6:10"> 彼らは答えることができなかった。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="ピリピ人への手紙 2:3; ルカの福音書 11:43; マタイの福音書 23:6"> 招かれた人々が上座を選んでいる様子に気づいておられたイエスは、彼らにたとえを話された。</span>
<span className="v" id="v8" data-v="8" data-xref="Proverbs 25:6–7"> 「婚礼の披露宴に招かれたときには、上座にすわってはいけません。あなたより身分の高い人が、招かれているかもしれないし、</span>
<span className="v" id="v9" data-v="9" data-xref="Proverbs 16:18; Proverbs 11:2; Proverbs 3:35"> あなたやその人を招いた人が来て、『この人に席を譲ってください。』とあなたに言うなら、そのときあなたは恥をかいて、末席に着かなければならないでしょう。</span>
<span className="v" id="v10" data-v="10" data-xref="Proverbs 25:6–7; Proverbs 15:33; 1 Samuel 15:17"> 招かれるようなことがあって、行ったなら、末席に着きなさい。そうしたら、あなたを招いた人が来て、『どうぞもっと上席にお進みください。』と言うでしょう。そのときは、満座の中で面目を施すことになります。</span>
<span className="v" id="v11" data-v="11" data-xref="ルカの福音書 18:14; マタイの福音書 23:12; Proverbs 29:23"> なぜなら、だれでも自分を高くする者は低くされ、自分を低くする者は高くされるからです。」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="マタイの福音書 5:46; ヤコブの手紙 2:1–6; ルカの福音書 6:32–36"> また、イエスは、自分を招いてくれた人にも、こう話された。「昼食や夕食のふるまいをするなら、友人、兄弟、親族、近所の金持ちなどを呼んではいけません。でないと、今度は彼らがあなたを招いて、お返しすることになるからです。</span>
<span className="v" id="v13" data-v="13" data-xref="ルカの福音書 14:21; Isaiah 58:10; Proverbs 14:31"> 祝宴を催すばあいには、むしろ、貧しい人、不具の人、足なえ、盲人たちを招きなさい。</span>
<span className="v" id="v14" data-v="14" data-xref="Proverbs 19:17; 使徒の働き 24:15; ヨハネの福音書 5:29"> その人たちはお返しができないので、あなたは幸いです。義人の復活のときお返しを受けるからです。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="ヨハネの黙示録 19:9; ルカの福音書 22:30; ルカの福音書 13:29"> イエスといっしょに食卓に着いていた客のひとりはこれを聞いて、イエスに、「神の国で食事する人は、何と幸いなことでしょう。」と言った。</span>
<span className="v" id="v16" data-v="16" data-xref="マタイの福音書 22:2–14; ヨハネの黙示録 22:17; Isaiah 55:1–7"> するとイエスはこう言われた。<br />「ある人が盛大な宴会を催し、大ぜいの人を招いた。</span>
<span className="v" id="v17" data-v="17" data-xref="マタイの福音書 11:27–29; マタイの福音書 10:1–4; マタイの福音書 22:3–4"> 宴会の時刻になったのでしもべをやり、招いておいた人々に、『さあ、おいでください。もうすっかり、用意ができましたから。』と言わせた。</span>
<span className="v" id="v18" data-v="18" data-xref="テモテへの手紙第一 6:9–10; ルカの福音書 17:26–31; ルカの福音書 18:24"> ところが、みな同じように断わり始めた。最初の人はこう言った。『畑を買ったので、どうしても見に出かけなければなりません。すみませんが、お断わりさせていただきます。』</span>
<span className="v" id="v19" data-v="19"> もうひとりはこう言った。『五くびきの牛を買ったので、それをためしに行くところです。すみませんが、お断わりさせていただきます。』</span>
<span className="v" id="v20" data-v="20" data-xref="Deuteronomy 24:5; コリント人への手紙第一 7:33; ルカの福音書 14:26–28"> また、別の人はこう言った。『結婚したので、行くことができません。』</span>
<span className="v" id="v21" data-v="21" data-xref="ルカの福音書 14:13; マタイの福音書 11:5; ルカの福音書 14:24"> しもべは帰って、このことを主人に報告した。すると、おこった主人は、そのしもべに言った。『急いで町の大通りや路地に出て行って、貧しい人や、不具の人や、盲人や、足なえをここに連れて来なさい。』</span>
<span className="v" id="v22" data-v="22" data-xref="ヨハネの福音書 14:2; エペソ人への手紙 3:8; テモテへの手紙第一 2:5–6"> しもべは言った。『ご主人さま。仰せのとおりにいたしました。でも、まだ席があります。』</span>
<span className="v" id="v23" data-v="23" data-xref="マタイの福音書 22:9–10; コロサイ人への手紙 1:28; 使徒の働き 13:47–48"> 主人は言った。『街道や垣根のところに出かけて行って、この家がいっぱいになるように、無理にでも人々を連れて来なさい。</span>
<span className="v" id="v24" data-v="24" data-xref="マタイの福音書 21:43; 使徒の働き 13:46; ヨハネの福音書 8:24"> 言っておくが、あの招待されていた人たちの中で、私の食事を味わう者は、ひとりもいないのです。』」</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="ヨハネの福音書 6:24–27; ルカの福音書 12:1"> さて、大ぜいの群衆が、イエスといっしょに歩いていたが、イエスは彼らのほうに向いて言われた。</span>
<span className="v" id="v26" data-v="26" data-xref="マタイの福音書 10:37; ヨハネの福音書 12:25; ピリピ人への手紙 3:8"> 「わたしのもとに来て、自分の父、母、妻、子、兄弟、姉妹、そのうえ自分のいのちまでも憎まない者は、わたしの弟子になることができません。</span>
<span className="v" id="v27" data-v="27" data-xref="マタイの福音書 10:38; ルカの福音書 9:23–25; マルコの福音書 8:34–37"> 自分の十字架を負ってわたしについて来ない者は、わたしの弟子になることはできません。</span>
<span className="v" id="v28" data-v="28" data-xref="Proverbs 24:27; マタイの福音書 10:22; Joshua 24:19–24"> 塔を築こうとするとき、まずすわって、完成に十分な金があるかどうか、その費用を計算しない者が、あなたがたのうちにひとりでもあるでしょうか。</span>
<span className="v" id="v29" data-v="29"> 基礎を築いただけで完成できなかったら、見ていた人はみな彼をあざ笑って、</span>
<span className="v" id="v30" data-v="30" data-xref="ヘブル人への手紙 6:11; ヨハネの手紙第二 1:8; コリント人への手紙第一 3:11–14"> 『この人は、建て始めはしたものの、完成できなかった。』と言うでしょう。</span>
<span className="v" id="v31" data-v="31" data-xref="Proverbs 20:18; Proverbs 25:8; 2 Kings 18:20–22"> また、どんな王でも、ほかの王と戦いを交えようとするときは、二万人を引き連れて向かって来る敵を、一万人で迎え撃つことができるかどうかを、まずすわって、考えずにいられましょうか。</span>
<span className="v" id="v32" data-v="32" data-xref="使徒の働き 12:20; ヤコブの手紙 4:6–10; ルカの福音書 12:58"> もし見込みがなければ、敵がまだ遠くに離れている間に、使者を送って講和を求めるでしょう。</span>
<span className="v" id="v33" data-v="33" data-xref="ピリピ人への手紙 3:7–8; ヨハネの手紙第一 2:15–16; ルカの福音書 5:28"> そういうわけで、あなたがたはだれでも、自分の財産全部を捨てないでは、わたしの弟子になることはできません。</span>
<span className="v" id="v34" data-v="34" data-xref="マタイの福音書 5:13; コロサイ人への手紙 4:6; マルコの福音書 9:49–50"> ですから、塩は良いものですが、もしその塩が塩けをなくしたら、何によってそれに味をつけるのでしょうか。</span>
<span className="v" id="v35" data-v="35" data-xref="マタイの福音書 11:15; ルカの福音書 9:44; ヨハネの黙示録 2:11"> 土地にも肥やしにも役立たず、外に投げ捨てられてしまいます。聞く耳のある人は聞きなさい。」</span>
</div>

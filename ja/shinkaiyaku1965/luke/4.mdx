<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マタイの福音書 4:1–11; 使徒の働き 10:38; マルコの福音書 1:12–13"> さて、聖霊に満ちたイエスは、ヨルダンから帰られた。そして御霊に導かれて荒野におり、</span>
<span className="v" id="v2" data-v="2" data-xref="Exodus 34:28; ヘブル人への手紙 4:15; Deuteronomy 9:9"> 四十日間、悪魔の試みに会われた。その間何も食べず、その時が終わると、空腹を覚えられた。</span>
<span className="v" id="v3" data-v="3" data-xref="マタイの福音書 4:3; ルカの福音書 3:22"> そこで、悪魔はイエスに言った。「あなたが神の子なら、この石に、パンになれと言いつけなさい。」</span>
<span className="v" id="v4" data-v="4" data-xref="Deuteronomy 8:3; マタイの福音書 4:4; マタイの福音書 6:31"> イエスは答えられた。「『人はパンだけで生きるのではない。』と書いてある。」</span>
<span className="v" id="v5" data-v="5" data-xref="ヨハネの手紙第一 2:15–16; コリント人への手紙第一 15:52; マタイの福音書 4:8"> また、悪魔はイエスを連れて行き、またたくまに世界の国々を全部見せて、</span>
<span className="v" id="v6" data-v="6" data-xref="ヨハネの福音書 12:31; ヨハネの手紙第一 5:19; ヨハネの福音書 14:30"> こう言った。「この、国々のいっさいの権力と栄光とをあなたに差し上げましょう。それは私に任されているので、私がこれと思う人に差し上げるのです。</span>
<span className="v" id="v7" data-v="7" data-xref="ルカの福音書 8:28; Psalms 72:11; Isaiah 45:14"> ですから、もしあなたが私を拝むなら、すべてをあなたのものとしましょう。」</span>
<span className="v" id="v8" data-v="8" data-xref="Deuteronomy 6:13; Deuteronomy 10:20; マタイの福音書 4:10"> イエスは答えて言われた。「『あなたの神である主を拝み、主にだけ仕えなさい。』と書いてある。」</span>
<span className="v" id="v9" data-v="9" data-xref="マタイの福音書 4:5–6; ルカの福音書 4:3; マタイの福音書 8:29"> また、悪魔はイエスをエルサレムに連れて行き、神殿の頂に立たせて、こう言った。「あなたが神の子なら、ここから飛び降りなさい。</span>
<span className="v" id="v10" data-v="10" data-xref="Psalms 91:11–12; ヘブル人への手紙 1:14; コリント人への手紙第二 11:14"> 『神は、御使いたちに命じてあなたを守らせる。』とも、</span>
<span className="v" id="v11" data-v="11" data-xref="Psalms 91:12"> 『あなたの足が石に打ち当たることのないように、彼らの手で、あなたをささえさせる。』とも書いてあるからです。」</span>
<span className="v" id="v12" data-v="12" data-xref="Deuteronomy 6:16; ヘブル人への手紙 3:8–9; コリント人への手紙第一 10:9"> するとイエスは答えて言われた。「『あなたの神である主を試みてはならない。』と言われている。」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="ヘブル人への手紙 4:15; ヤコブの手紙 4:7; マタイの福音書 4:11"> 誘惑の手を尽くしたあとで、悪魔はしばらくの間イエスから離れた。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="マタイの福音書 4:23–25; 使徒の働き 10:37; マタイの福音書 4:12"> イエスは御霊の力を帯びてガリラヤに帰られた。すると、その評判が回り一帯に、くまなく広まった。</span>
<span className="v" id="v15" data-v="15" data-xref="マタイの福音書 4:23; マタイの福音書 9:8; マタイの福音書 9:35"> イエスは、彼らの会堂で教え、みなの人にあがめられた。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="使徒の働き 17:2; 使徒の働き 13:14–16; マタイの福音書 2:23"> それから、イエスはご自分の育ったナザレに行き、いつものとおり安息日に会堂にはいり、朗読しようとして立たれた。</span>
<span className="v" id="v17" data-v="17" data-xref="Isaiah 61:1–3; 使徒の働き 13:15; 使徒の働き 7:42"> すると、預言者イザヤの書が手渡されたので、その書を開いて、こう書いてある所を見つけられた。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="Isaiah 61:1; マタイの福音書 11:5; Psalms 146:7–8"> 「わたしの上に主の御霊がおられる。<br />主が、貧しい人々に福音を伝えるようにと、<br />わたしに油を注がれたのだから。<br />主はわたしを遣わされた。<br />捕われ人には赦免を、<br />盲人には目の開かれることを告げるために。<br />しいたげられている人々を自由にし、</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="Isaiah 61:2; Isaiah 63:4; コリント人への手紙第二 6:1"> 主の恵みの年を告げ知らせるために。」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="ルカの福音書 4:17; ヨハネの福音書 8:2; ルカの福音書 19:48"> イエスは書を巻き、係りの者に渡してすわられた。会堂にいるみなの目がイエスに注がれた。</span>
<span className="v" id="v21" data-v="21" data-xref="ヨハネの福音書 4:25–26; 使徒の働き 3:18; 使徒の働き 2:16–18"> イエスは人々にこう言って話し始められた。「きょう、聖書のこのみことばが、あなたがたが聞いたとおり実現しました。」</span>
<span className="v" id="v22" data-v="22" data-xref="マタイの福音書 13:54–56; Psalms 45:2; 使徒の働き 6:10"> みなイエスをほめ、その口から出て来る恵みのことばに驚いた。そしてまた、「この人は、ヨセフの子ではないか。」と彼らは言った。</span>
<span className="v" id="v23" data-v="23" data-xref="ヨハネの福音書 4:46–53; マタイの福音書 11:23–24; マルコの福音書 2:1–12"> イエスは言われた。「きっとあなたがたは、『医者よ。自分を直せ。』というたとえを引いて、カペナウムで行なわれたと聞いていることを、あなたの郷里のここでもしてくれ、と言うでしょう。」</span>
<span className="v" id="v24" data-v="24" data-xref="マタイの福音書 13:57; ヨハネの福音書 4:44; マルコの福音書 6:4–5"> また、こう言われた。「まことに、あなたがたに告げます。預言者はだれでも、自分の郷里では歓迎されません。</span>
<span className="v" id="v25" data-v="25" data-xref="ヤコブの手紙 5:17; 1 Kings 17:1; マタイの福音書 20:15"> わたしが言うのは真実のことです。エリヤの時代に、三年六か月の間天が閉じて、全国に大ききんが起こったとき、イスラエルにもやもめは多くいたが、</span>
<span className="v" id="v26" data-v="26" data-xref="1 Kings 17:9–24; マタイの福音書 11:21; Obadiah 1:20"> エリヤはだれのところにも遣わされず、シドンのサレプタにいたやもめ女にだけ遣わされたのです。</span>
<span className="v" id="v27" data-v="27" data-xref="2 Kings 5:1–27; ヨハネの福音書 17:12; マタイの福音書 12:4"> また、預言者エリシャのときに、イスラエルには、らい病人がたくさんいたが、そのうちのだれもきよめられないで、シリヤ人ナアマンだけがきよめられました。」</span>
<span className="v" id="v28" data-v="28" data-xref="使徒の働き 5:33; 2 Chronicles 24:20–21; Jeremiah 38:6"> これらのことを聞くと、会堂にいた人たちはみな、ひどく怒り、</span>
<span className="v" id="v29" data-v="29" data-xref="ヨハネの福音書 8:59; 使徒の働き 21:28–32; Numbers 15:35"> 立ち上がってイエスを町の外に追い出し、町が立っていた丘のがけのふちまで連れて行き、そこから投げ落とそうとした。</span>
<span className="v" id="v30" data-v="30" data-xref="ヨハネの福音書 10:39; ヨハネの福音書 8:59; ヨハネの福音書 18:6–7"> しかしイエスは、彼らの真中を通り抜けて、行ってしまわれた。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="マルコの福音書 1:21–28; マタイの福音書 4:13; 使徒の働き 13:50–2"> それからイエスは、ガリラヤの町カペナウムに下られた。そして、安息日ごとに、人々を教えられた。</span>
<span className="v" id="v32" data-v="32" data-xref="ルカの福音書 4:36; マタイの福音書 7:28–29; ヨハネの福音書 6:63"> 人々は、その教えに驚いた。そのことばに権威があったからである。</span>
<span className="v" id="v33" data-v="33" data-xref="マルコの福音書 1:23"> また、会堂に、汚れた悪霊につかれた人がいて、大声でわめいた。</span>
<span className="v" id="v34" data-v="34" data-xref="マルコの福音書 1:24; ヤコブの手紙 2:19; マタイの福音書 8:29"> 「ああ、ナザレ人のイエス。いったい私たちに何をしようというのです。あなたは私たちを滅ぼしに来たのでしょう。私はあなたがどなたか知っています。神の聖者です。」</span>
<span className="v" id="v35" data-v="35" data-xref="ルカの福音書 4:41; ルカの福音書 4:39; マタイの福音書 8:26"> イエスは彼をしかって、「黙れ。その人から出て行け。」と言われた。するとその悪霊は人々の真中で、その人を投げ倒して出て行ったが、その人は別に何の害も受けなかった。</span>
<span className="v" id="v36" data-v="36" data-xref="ルカの福音書 4:32; ペテロの手紙第一 3:22; マタイの福音書 12:22–23"> 人々はみな驚いて、互いに話し合った。「今のおことばはどうだ。権威と力とでお命じになったので、汚れた霊でも出て行ったのだ。」</span>
<span className="v" id="v37" data-v="37" data-xref="マルコの福音書 1:45; ルカの福音書 4:14; Isaiah 52:13"> こうしてイエスのうわさは、回りの地方の至る所に広まった。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="マタイの福音書 8:14–15; マルコの福音書 1:29–31; ヨハネの福音書 11:22"> イエスは立ち上がって会堂を出て、シモンの家にはいられた。すると、シモンのしゅうとめが、ひどい熱で苦しんでいた。人々は彼女のためにイエスにお願いした。</span>
<span className="v" id="v39" data-v="39" data-xref="ルカの福音書 4:41; ルカの福音書 4:35; ルカの福音書 8:24"> イエスがその枕もとに来て、熱をしかりつけられると、熱がひき、彼女はすぐに立ち上がって彼らをもてなし始めた。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="マルコの福音書 1:32–34; マタイの福音書 8:16–17; マルコの福音書 5:23"> 日が暮れると、いろいろな病気で弱っている者をかかえた人たちがみな、その病人をみもとに連れて来た。イエスは、ひとりひとりに手を置いて、いやされた。</span>
<span className="v" id="v41" data-v="41" data-xref="マルコの福音書 1:34; ヤコブの手紙 2:19; ルカの福音書 4:34–35"> また、悪霊どもも、「あなたこそ神の子です。」と大声で叫びながら、多くの人から出て行った。イエスは、悪霊どもをしかって、ものを言うのをお許しにならなかった。彼らはイエスがキリストであることを知っていたからである。</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="ルカの福音書 6:12; マルコの福音書 1:35–38; ヨハネの福音書 4:34"> 朝になって、イエスは寂しい所に出て行かれた。群衆は、イエスを捜し回って、みもとに来ると、イエスが自分たちから離れて行かないよう引き止めておこうとした。</span>
<span className="v" id="v43" data-v="43" data-xref="マルコの福音書 1:38–39; テモテへの手紙第二 4:2; ヨハネの福音書 9:4"> しかしイエスは、彼らにこう言われた。「ほかの町々にも、どうしても神の国の福音を宣べ伝えなければなりません。わたしは、そのために遣わされたのですから。」</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="マタイの福音書 4:23; マルコの福音書 1:39; ルカの福音書 4:15"> そしてユダヤの諸会堂で、福音を告げ知らせておられた。</span>
</div>
</div>

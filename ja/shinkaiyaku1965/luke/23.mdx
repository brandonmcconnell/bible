<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マタイの福音書 27:1–2; マタイの福音書 27:11–14; ルカの福音書 22:66"> そこで、彼らは全員が立ち上がり、イエスをピラトのもとに連れて行った。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒の働き 17:6–7; ヨハネの福音書 19:12; ルカの福音書 23:14"> そしてイエスについて訴え始めた。彼らは言った。「この人はわが国民を惑わし、カイザルに税金を納めることを禁じ、自分は王キリストだと言っていることがわかりました。」</span>
<span className="v" id="v3" data-v="3" data-xref="ヨハネの福音書 1:49; テモテへの手紙第一 6:13; ルカの福音書 22:70"> するとピラトはイエスに、「あなたは、ユダヤ人の王ですか。」と尋ねた。イエスは答えて、「そのとおりです。」と言われた。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネの福音書 18:38; ルカの福音書 23:14–15; ルカの福音書 23:22"> ピラトは祭司長たちや群衆に、「この人には何の罪も見つからない。」と言った。</span>
<span className="v" id="v5" data-v="5" data-xref="マルコの福音書 1:14; ヨハネの福音書 1:43; ヨハネの福音書 2:11"> しかし彼らはあくまで言い張って、「この人は、ガリラヤからここまで、ユダヤ全土で教えながら、この民を扇動しているのです。」と言った。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒の働き 5:37; ルカの福音書 13:1"> それを聞いたピラトは、この人はガリラヤ人かと尋ねて、</span>
<span className="v" id="v7" data-v="7" data-xref="ルカの福音書 3:1; ルカの福音書 13:31; マタイの福音書 14:1"> ヘロデの支配下にあるとわかると、イエスをヘロデのところに送った。ヘロデもそのころエルサレムにいたからである。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="ルカの福音書 9:7–9; マタイの福音書 14:1; マルコの福音書 6:14"> ヘロデはイエスを見ると非常に喜んだ。ずっと前からイエスのことを聞いていたので、イエスに会いたいと思っていたし、イエスの行なう何かの奇蹟を見たいと考えていたからである。</span>
<span className="v" id="v9" data-v="9" data-xref="マタイの福音書 27:14; マタイの福音書 7:6; ペテロの手紙第一 2:23"> それで、いろいろと質問したが、イエスは彼に何もお答えにならなかった。</span>
<span className="v" id="v10" data-v="10" data-xref="ルカの福音書 11:53; ルカの福音書 23:14–15; ルカの福音書 23:5"> 祭司長たちと律法学者たちは立って、イエスを激しく訴えていた。</span>
<span className="v" id="v11" data-v="11" data-xref="マルコの福音書 15:16–20; マタイの福音書 27:27–30; Psalms 69:19–20"> ヘロデは、自分の兵士たちといっしょにイエスを侮辱したり嘲弄したりしたあげく、はでな衣を着せて、ピラトに送り返した。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒の働き 4:27; ヨハネの黙示録 17:13–14; Psalms 83:4–6"> この日、ヘロデとピラトは仲よくなった。それまでは互いに敵対していたのである。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="マルコの福音書 15:14; マタイの福音書 27:21–23; ヨハネの福音書 18:38"> ピラトは祭司長たちと指導者たちと民衆とを呼び集め、</span>
<span className="v" id="v14" data-v="14" data-xref="Daniel 6:4; ヘブル人への手紙 7:26; ルカの福音書 23:1–2"> こう言った。「あなたがたは、この人を、民衆を惑わす者として、私のところに連れて来たけれども、私があなたがたの前で取り調べたところ、あなたがたが訴えているような罪は別に何も見つかりません。</span>
<span className="v" id="v15" data-v="15"> ヘロデとても同じです。彼は私たちにこの人を送り返しました。見なさい。この人は、死罪に当たることは、何一つしていません。</span>
<span className="v" id="v16" data-v="16" data-xref="マタイの福音書 27:26; ルカの福音書 23:22; マルコの福音書 15:15"> だから私は、懲らしめたうえで、釈放します。」</span>
<span className="v" id="v17" data-v="17"> しかし彼らは、声をそろえて叫んだ。「この人を除け。バラバを釈放しろ。」</span>
<span className="v" id="v19" data-v="19" data-xref="使徒の働き 3:14; ルカの福音書 23:5; ルカの福音書 23:2"> バラバとは、都に起こった暴動と人殺しのかどで、牢にはいっていた者である。</span>
<span className="v" id="v20" data-v="20" data-xref="マルコの福音書 15:15; マタイの福音書 14:8–9; マタイの福音書 27:19"> ピラトは、イエスを釈放しようと思って、彼らに、もう一度呼びかけた。</span>
<span className="v" id="v21" data-v="21" data-xref="マタイの福音書 27:22–25; マルコの福音書 15:13; ヨハネの福音書 19:15"> しかし、彼らは叫び続けて、「十字架だ。十字架につけろ。」と言った。</span>
<span className="v" id="v22" data-v="22" data-xref="ルカの福音書 23:14; ルカの福音書 23:20; ペテロの手紙第一 3:18"> しかしピラトは三度目に彼らにこう言った。「あの人がどんな悪いことをしたというのか。あの人には、死に当たる罪は、何も見つかりません。だから私は、懲らしめたうえで、釈放します。」</span>
<span className="v" id="v23" data-v="23" data-xref="Zechariah 11:8; Psalms 57:4; Psalms 22:12–13"> ところが、彼らはあくまで主張し続け、十字架につけるよう大声で要求した。そしてついにその声が勝った。</span>
<span className="v" id="v24" data-v="24" data-xref="マタイの福音書 27:26; Exodus 23:2; Proverbs 17:15"> ピラトは、彼らの要求どおりにすることを宣告した。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒の働き 3:14; マルコの福音書 15:6–7; マルコの福音書 15:15"> すなわち、暴動と人殺しのかどで牢にはいっていた男を願いどおりに釈放し、イエスを彼らに引き渡して好きなようにさせた。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="マタイの福音書 27:32–44; マルコの福音書 15:21–32; 使徒の働き 6:9"> 彼らは、イエスを引いて行く途中、いなかから出て来たシモンというクレネ人をつかまえ、この人に十字架を負わせてイエスのうしろから運ばせた。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="ルカの福音書 8:52; ルカの福音書 8:2; マルコの福音書 15:40"> 大ぜいの民衆やイエスのことを嘆き悲しむ女たちの群れが、イエスのあとについて行った。</span>
<span className="v" id="v28" data-v="28" data-xref="Song of Solomon 8:4; Song of Solomon 5:8; Song of Solomon 1:5"> しかしイエスは、女たちのほうに向いて、こう言われた。「エルサレムの娘たち。わたしのことで泣いてはいけない。むしろ自分自身と、自分の子どもたちのことのために泣きなさい。</span>
<span className="v" id="v29" data-v="29" data-xref="マタイの福音書 24:19; ルカの福音書 21:23–24; マルコの福音書 13:17–19"> なぜなら人々が、『不妊の女、子を産んだことのない胎、飲ませたことのない乳房は、幸いだ。』と言う日が来るのですから。</span>
<span className="v" id="v30" data-v="30" data-xref="ヨハネの黙示録 6:16; Hosea 10:8; Isaiah 2:19"> そのとき、人々は山に向かって、『われわれの上に倒れかかってくれ。』と言い、丘に向かって、『われわれをおおってくれ。』と言い始めます。</span>
<span className="v" id="v31" data-v="31" data-xref="ペテロの手紙第一 4:17–18; ヨハネの福音書 15:6; Proverbs 11:31"> 彼らが生木にこのようなことをするのなら、枯れ木には、いったい、何が起こるでしょう。」</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="マルコの福音書 15:27; Isaiah 53:12; マタイの福音書 27:38"> ほかにもふたりの犯罪人が、イエスとともに死刑にされるために、引かれて行った。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="マルコの福音書 15:22–23; ヨハネの福音書 19:17–18; ヨハネの福音書 18:32"> 「どくろ」と呼ばれている所に来ると、そこで彼らは、イエスと犯罪人とを十字架につけた。犯罪人のひとりは右に、ひとりは左に。</span>
<span className="v" id="v34" data-v="34" data-xref="マタイの福音書 5:44; 使徒の働き 7:60; ペテロの手紙第一 3:9"> そのとき、イエスはこう言われた。「父よ。彼らをお赦しください。彼らは、何をしているのか自分でわからないのです。」彼らは、くじを引いて、イエスの着物を分けた。</span>
<span className="v" id="v35" data-v="35" data-xref="Psalms 22:17; Isaiah 42:1; ペテロの手紙第一 2:4"> 民衆はそばに立ってながめていた。指導者たちもあざ笑って言った。「あれは他人を救った。もし、神のキリストで、選ばれた者なら、自分を救ってみろ。」</span>
<span className="v" id="v36" data-v="36" data-xref="Psalms 69:21; マタイの福音書 27:48; マタイの福音書 27:34"> 兵士たちもイエスをあざけり、そばに寄って来て、酸いぶどう酒を差し出し、</span>
<span className="v" id="v37" data-v="37"> 「ユダヤ人の王なら、自分を救え。」と言った。</span>
<span className="v" id="v38" data-v="38" data-xref="マルコの福音書 15:26; マタイの福音書 27:37; ヨハネの福音書 19:19–22"> 「これはユダヤ人の王。」と書いた札もイエスの頭上に掲げてあった。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="マタイの福音書 27:44; マルコの福音書 15:32; ルカの福音書 23:35"> 十字架にかけられていた犯罪人のひとりはイエスに悪口を言い、「あなたはキリストではないか。自分と私たちを救え。」と言った。</span>
<span className="v" id="v40" data-v="40" data-xref="エペソ人への手紙 5:11; ルカの福音書 12:5; ヨハネの黙示録 15:4"> ところが、もうひとりのほうが答えて、彼をたしなめて言った。「おまえは神をも恐れないのか。おまえも同じ刑罰を受けているではないか。</span>
<span className="v" id="v41" data-v="41" data-xref="Leviticus 26:40–41; Ezra 9:13; ペテロの手紙第一 1:19"> われわれは、自分のしたことの報いを受けているのだからあたりまえだ。だがこの方は、悪いことは何もしなかったのだ。」</span>
<span className="v" id="v42" data-v="42" data-xref="ローマ人への手紙 10:9–14; 使徒の働き 16:31; ヨハネの手紙第一 5:11–13"> そして言った。「イエスさま。あなたの御国の位にお着きになるときには、私を思い出してください。」</span>
<span className="v" id="v43" data-v="43" data-xref="ヨハネの黙示録 2:7; Psalms 50:15; テモテへの手紙第一 1:15–16"> イエスは、彼に言われた。「まことに、あなたに告げます。あなたはきょう、わたしとともにパラダイスにいます。」</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="マタイの福音書 27:45; マルコの福音書 15:33–34; Amos 8:9"> そのときすでに十二時ごろになっていたが、全地が暗くなって、三時まで続いた。</span>
<span className="v" id="v45" data-v="45" data-xref="ヘブル人への手紙 10:19–22; マタイの福音書 27:51; ヘブル人への手紙 9:3–8"> 太陽は光を失っていた。また、神殿の幕は真二つに裂けた。</span>
<span className="v" id="v46" data-v="46" data-xref="Psalms 31:5; 使徒の働き 7:59; ヨハネの福音書 19:30"> イエスは大声で叫んで、言われた。「父よ。わが霊を御手にゆだねます。」こう言って、息を引き取られた。</span>
<span className="v" id="v47" data-v="47" data-xref="マタイの福音書 27:54; マルコの福音書 15:39; ルカの福音書 23:41"> この出来事を見た百人隊長は、神をほめたたえ、「ほんとうに、この人は正しい方であった。」と言った。</span>
<span className="v" id="v48" data-v="48" data-xref="ルカの福音書 18:13; 使徒の働き 2:37; Jeremiah 31:19"> また、この光景を見に集まっていた群衆もみな、こういういろいろの出来事を見たので、胸をたたいて悲しみながら帰った。</span>
<span className="v" id="v49" data-v="49" data-xref="ルカの福音書 8:2; Psalms 38:11; ルカの福音書 23:55"> しかし、イエスの知人たちと、ガリラヤからイエスについて来ていた女たちとはみな、遠く離れて立ち、これらのことを見ていた。</span>
</div>
<div className="bp">
<span className="v" id="v50" data-v="50" data-xref="ヨハネの福音書 19:38–42; 使徒の働き 11:24; 使徒の働き 10:22"> さてここに、ヨセフという、議員のひとりで、りっぱな、正しい人がいた。</span>
<span className="v" id="v51" data-v="51" data-xref="ルカの福音書 2:25; ルカの福音書 2:38; Isaiah 8:12"> この人は議員たちの計画や行動には同意しなかった。彼は、アリマタヤというユダヤ人の町の人で、神の国を待ち望んでいた。</span>
<span className="v" id="v52" data-v="52" data-xref="ヨハネの福音書 19:38–42"> この人が、ピラトのところに行って、イエスのからだの下げ渡しを願った。</span>
<span className="v" id="v53" data-v="53" data-xref="マタイの福音書 27:59–60; Isaiah 53:9; マルコの福音書 15:46"> それから、イエスを取り降ろして、亜麻布で包み、そして、まだだれをも葬ったことのない、岩に掘られた墓にイエスを納めた。</span>
<span className="v" id="v54" data-v="54" data-xref="マタイの福音書 27:62; ヨハネの福音書 19:31; マルコの福音書 15:42"> この日は準備の日で、もう安息日が始まろうとしていた。</span>
<span className="v" id="v55" data-v="55" data-xref="ルカの福音書 23:49; マタイの福音書 27:61; マルコの福音書 15:47"> ガリラヤからイエスといっしょに出て来た女たちは、ヨセフについて行って、墓と、イエスのからだの納められる様子を見届けた。</span>
<span className="v" id="v56" data-v="56" data-xref="ルカの福音書 24:1; マルコの福音書 16:1; Deuteronomy 5:14"> そして、戻って来て、香料と香油を用意した。<br />安息日には、戒めに従って、休んだが、</span>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マルコの福音書 1:16–20; マタイの福音書 4:18–22; マルコの福音書 3:9"> 群衆がイエスに押し迫るようにして神のことばを聞いたとき、イエスはゲネサレ湖の岸べに立っておられたが、</span>
<span className="v" id="v2" data-v="2" data-xref="マルコの福音書 1:19; マタイの福音書 4:21"> 岸べに小舟が二そうあるのをご覧になった。漁師たちは、その舟から降りて網を洗っていた。</span>
<span className="v" id="v3" data-v="3" data-xref="マタイの福音書 4:18; マタイの福音書 13:1–2; ヨハネの福音書 1:41–42"> イエスは、そのうちの一つの、シモンの持ち舟に乗り、陸から少し漕ぎ出すように頼まれた。そしてイエスはすわって、舟から群衆を教えられた。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネの福音書 21:6; マタイの福音書 17:27"> 話が終わると、シモンに、「深みに漕ぎ出して、網をおろして魚をとりなさい。」と言われた。</span>
<span className="v" id="v5" data-v="5" data-xref="ヨハネの福音書 2:5; ヨハネの福音書 15:14; ルカの福音書 6:46–48"> するとシモンが答えて言った。「先生。私たちは、夜通し働きましたが、何一つとれませんでした。でもおことばどおり、網をおろしてみましょう。」</span>
<span className="v" id="v6" data-v="6" data-xref="コリント人への手紙第一 15:58; ヨハネの福音書 21:6–11; Ecclesiastes 11:6"> そして、そのとおりにすると、たくさんの魚がはいり、網は破れそうになった。</span>
<span className="v" id="v7" data-v="7" data-xref="ガラテヤ人への手紙 6:2; ピリピ人への手紙 4:3; 使徒の働き 11:25"> そこで別の舟にいた仲間の者たちに合図をして、助けに来てくれるように頼んだ。彼らがやって来て、そして魚を両方の舟いっぱいに上げたところ、二そうとも沈みそうになった。</span>
<span className="v" id="v8" data-v="8" data-xref="Isaiah 6:5; Job 42:5–6; ヨハネの黙示録 1:17"> これを見たシモン・ペテロは、イエスの足もとにひれ伏して、「主よ。私のような者から離れてください。私は、罪深い人間ですから。」と言った。</span>
<span className="v" id="v9" data-v="9" data-xref="ルカの福音書 4:32; Psalms 8:8; マルコの福音書 9:6"> それは、大漁のため、彼もいっしょにいたみなの者も、ひどく驚いたからである。</span>
<span className="v" id="v10" data-v="10" data-xref="マタイの福音書 4:19; マタイの福音書 13:47; Ezekiel 47:9–10"> シモンの仲間であったゼベダイの子ヤコブやヨハネも同じであった。イエスはシモンにこう言われた。「こわがらなくてもよい。これから後、あなたは人間をとるようになるのです。」</span>
<span className="v" id="v11" data-v="11" data-xref="マタイの福音書 4:20; ルカの福音書 5:28; マタイの福音書 19:27"> 彼らは、舟を陸に着けると、何もかも捨てて、イエスに従った。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="Psalms 50:15; ルカの福音書 17:16; マタイの福音書 8:2–4"> さて、イエスがある町におられたとき、全身らい病の人がいた。イエスを見ると、ひれ伏してお願いした。「主よ。お心一つで、私はきよくしていただけます。」</span>
<span className="v" id="v13" data-v="13" data-xref="マタイの福音書 9:29–30; ヨハネの福音書 4:50–53; Hosea 14:4"> イエスは手を伸ばして、彼にさわり、「わたしの心だ。きよくなれ。」と言われた。すると、すぐに、そのらい病が消えた。</span>
<span className="v" id="v14" data-v="14" data-xref="Leviticus 14:2–32; ルカの福音書 17:14; マルコの福音書 1:44"> イエスは、彼にこう命じられた。「だれにも話してはいけない。ただ祭司のところに行って、自分を見せなさい。そして人々へのあかしのため、モーセが命じたように、あなたのきよめの供え物をしなさい。」</span>
<span className="v" id="v15" data-v="15" data-xref="マタイの福音書 15:30–31; ルカの福音書 12:1; マルコの福音書 1:45–2"> しかし、イエスのうわさは、ますます広まり、多くの人の群れが、話を聞きに、また、病気を直してもらいに集まって来た。</span>
<span className="v" id="v16" data-v="16" data-xref="ルカの福音書 6:12; マルコの福音書 1:35–36; マタイの福音書 14:23"> しかし、イエスご自身は、よく荒野に退いて祈っておられた。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="ルカの福音書 6:19; ルカの福音書 8:46; マタイの福音書 11:5"> ある日のこと、イエスが教えておられると、パリサイ人と律法の教師たちも、そこにすわっていた。彼らは、ガリラヤとユダヤとのすべての村々や、エルサレムから来ていた。イエスは、主の御力をもって、病気を直しておられた。</span>
<span className="v" id="v18" data-v="18" data-xref="マルコの福音書 2:3–12; マタイの福音書 9:2–8; ヨハネの福音書 5:5–6"> するとそこに、男たちが、中風をわずらっている人を、床のままで運んで来た。そして、何とかして家の中に運び込み、イエスの前に置こうとしていた。</span>
<span className="v" id="v19" data-v="19" data-xref="マルコの福音書 2:4; マタイの福音書 10:27; マタイの福音書 24:17"> しかし、大ぜい人がいて、どうにも病人を運び込む方法が見つからないので、屋上に上って屋根の瓦をはがし、そこから彼の寝床を、ちょうど人々の真中のイエスの前に、つり降ろした。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒の働き 14:9; マタイの福音書 9:2; マルコの福音書 2:5"> 彼らの信仰を見て、イエスは「友よ。あなたの罪は赦されました。」と言われた。</span>
<span className="v" id="v21" data-v="21" data-xref="Isaiah 43:25; マルコの福音書 2:6–7; ルカの福音書 7:49"> ところが、律法学者、パリサイ人たちは、理屈を言い始めた。「神をけがすことを言うこの人は、いったい何者だ。神のほかに、だれが罪を赦すことができよう。」</span>
<span className="v" id="v22" data-v="22" data-xref="ルカの福音書 24:38; Isaiah 66:18; Psalms 139:2"> その理屈を見抜いておられたイエスは、彼らに言われた。「なぜ、心の中でそんな理屈を言っているのか。</span>
<span className="v" id="v23" data-v="23" data-xref="マルコの福音書 2:9; マタイの福音書 9:5"> 『あなたの罪は赦された。』と言うのと、『起きて歩け。』と言うのと、どちらがやさしいか。</span>
<span className="v" id="v24" data-v="24" data-xref="ヨハネの黙示録 1:13; Isaiah 53:11; ルカの福音書 8:54"> 人の子が地上で罪を赦す権威を持っていることを、あなたがたに悟らせるために。」と言って、中風の人に、「あなたに命じる。起きなさい。寝床をたたんで、家に帰りなさい。」と言われた。</span>
<span className="v" id="v25" data-v="25" data-xref="ヨハネの福音書 9:24; ルカの福音書 5:13; Psalms 107:20–22"> すると彼は、たちどころに人々の前で立ち上がり、寝ていた床をたたんで、神をあがめながら自分の家に帰った。</span>
<span className="v" id="v26" data-v="26" data-xref="マタイの福音書 9:8; マタイの福音書 12:23; ルカの福音書 7:16"> 人々はみな、ひどく驚き、神をあがめ、恐れに満たされて、「私たちは、きょう、驚くべきことを見た。」と言った。</span>
<span className="v" id="v27" data-v="27" data-xref="マルコの福音書 2:13–22; マタイの福音書 9:9–17; ヨハネの福音書 1:43"> この後、イエスは出て行き、収税所にすわっているレビという取税人に目を留めて、「わたしについて来なさい。」と言われた。</span>
<span className="v" id="v28" data-v="28" data-xref="ルカの福音書 5:11; マタイの福音書 19:22–27; 1 Kings 19:19–21"> するとレビは、何もかも捨て、立ち上がってイエスに従った。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="マルコの福音書 2:15; ルカの福音書 15:1; コリント人への手紙第一 10:27"> そこでレビは、自分の家でイエスのために大ぶるまいをしたが、取税人たちや、ほかに大ぜいの人たちが食卓に着いていた。</span>
<span className="v" id="v30" data-v="30" data-xref="マタイの福音書 21:28–32; ルカの福音書 5:17; マルコの福音書 7:3"> すると、パリサイ人やその派の律法学者たちが、イエスの弟子たちに向かって、つぶやいて言った。「なぜ、あなたがたは、取税人や罪人どもといっしょに飲み食いするのですか。」</span>
<span className="v" id="v31" data-v="31" data-xref="マルコの福音書 2:17; マタイの福音書 9:12–13; Jeremiah 8:22"> そこで、イエスは答えて言われた。「医者を必要とするのは丈夫な者ではなく、病人です。</span>
<span className="v" id="v32" data-v="32" data-xref="ルカの福音書 19:10; ルカの福音書 15:10; テモテへの手紙第一 1:15–16"> わたしは正しい人を招くためではなく、罪人を招いて、悔い改めさせるために来たのです。」</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="マタイの福音書 9:14–17; マルコの福音書 2:18–22; ヨハネの福音書 3:25"> 彼らはイエスに言った。「ヨハネの弟子たちは、よく断食をしており、祈りもしています。また、パリサイ人の弟子たちも同じなのに、あなたの弟子たちは食べたり飲んだりしています。」</span>
<span className="v" id="v34" data-v="34" data-xref="ヨハネの福音書 3:29; コリント人への手紙第二 11:2; Isaiah 54:5"> イエスは彼らに言われた。「花婿がいっしょにいるのに、花婿につき添う友だちに断食させることが、あなたがたにできますか。</span>
<span className="v" id="v35" data-v="35" data-xref="ルカの福音書 17:22; 使徒の働き 14:23; 使徒の働き 3:21"> しかし、やがてその時が来て、花婿が取り去られたら、その日には彼らは断食します。」</span>
<span className="v" id="v36" data-v="36" data-xref="マタイの福音書 9:16–17; マルコの福音書 2:21–22; コリント人への手紙第二 6:16"> イエスはまた一つのたとえを彼らに話された。「だれも、新しい着物から布切れを引き裂いて、古い着物に継ぎをするようなことはしません。そんなことをすれば、その新しい着物を裂くことになるし、また新しいのを引き裂いた継ぎ切れも、古い物には合わないのです。</span>
<span className="v" id="v37" data-v="37" data-xref="Joshua 9:13; Psalms 119:83; Joshua 9:4"> また、だれも新しいぶどう酒を古い皮袋に入れるようなことはしません。そんなことをすれば、新しいぶどう酒は皮袋を張り裂き、ぶどう酒は流れ出て、皮袋もだめになってしまいます。</span>
<span className="v" id="v38" data-v="38" data-xref="ヘブル人への手紙 8:8–13; コリント人への手紙第二 5:17; Ezekiel 36:26"> 新しいぶどう酒は新しい皮袋に入れなければなりません。</span>
<span className="v" id="v39" data-v="39" data-xref="ヘブル人への手紙 11:39; マルコの福音書 7:7–13; Jeremiah 6:16"> また、だれでも古いぶどう酒を飲んでから、新しい物を望みはしません。『古い物は良い。』と言うのです。」</span>
</div>

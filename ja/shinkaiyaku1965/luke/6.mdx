<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="Deuteronomy 23:25; マルコの福音書 2:23–28; マタイの福音書 12:1–8"> ある安息日に、イエスが麦畑を通っておられたとき、弟子たちは麦の穂を摘んで、手でもみ出しては食べていた。</span>
<span className="v" id="v2" data-v="2" data-xref="マタイの福音書 12:2; ヨハネの福音書 5:16; ヨハネの福音書 5:9–11"> すると、あるパリサイ人たちが言った。「なぜ、あなたがたは、安息日にしてはならないことをするのですか。」</span>
<span className="v" id="v3" data-v="3" data-xref="1 Samuel 21:3–6; マルコの福音書 2:25–26; マタイの福音書 12:3–5"> イエスは彼らに答えて言われた。「あなたがたは、ダビデが連れの者といっしょにいて、ひもじかったときにしたことを読まなかったのですか。</span>
<span className="v" id="v4" data-v="4" data-xref="Leviticus 24:5–9"> ダビデは神の家にはいって、祭司以外の者はだれも食べてはならない供えのパンを取って、自分も食べたし、供の者にも与えたではありませんか。」</span>
<span className="v" id="v5" data-v="5" data-xref="マルコの福音書 2:27; ヨハネの黙示録 1:10; マルコの福音書 9:7"> そして、彼らに言われた。「人の子は、安息日の主です。」</span>
<span className="v" id="v6" data-v="6" data-xref="マルコの福音書 3:1–6; マタイの福音書 12:9–14; ルカの福音書 4:31"> 別の安息日に、イエスは会堂にはいって教えておられた。そこに右手のなえた人がいた。</span>
<span className="v" id="v7" data-v="7" data-xref="ルカの福音書 20:20; Psalms 38:12; ルカの福音書 13:14"> そこで律法学者、パリサイ人たちは、イエスが安息日に人を直すかどうか、じっと見ていた。彼を訴える口実を見つけるためであった。</span>
<span className="v" id="v8" data-v="8" data-xref="Isaiah 42:4; マタイの福音書 9:4; ルカの福音書 5:22"> イエスは彼らの考えをよく知っておられた。それで、手のなえた人に、「立って、真中に出なさい。」と言われた。その人は、起き上がって、そこに立った。</span>
<span className="v" id="v9" data-v="9" data-xref="マルコの福音書 3:4; マタイの福音書 12:12–13; ルカの福音書 14:3"> イエスは人々に言われた。「あなたがたに聞きますが、安息日にしてよいのは、善を行なうことなのか、それとも悪を行なうことなのか。いのちを救うことなのか、それとも失うことなのか、どうですか。」</span>
<span className="v" id="v10" data-v="10" data-xref="Exodus 4:6–7; マルコの福音書 3:5; ヨハネの福音書 5:8"> そして、みなの者を見回してから、その人に、「手を伸ばしなさい。」と言われた。そのとおりにすると、彼の手は元どおりになった。</span>
<span className="v" id="v11" data-v="11" data-xref="Psalms 2:1–2; 使徒の働き 5:33; Ecclesiastes 9:3"> すると彼らはすっかり分別を失ってしまって、イエスをどうしてやろうかと話し合った。</span>
<span className="v" id="v12" data-v="12" data-xref="ヘブル人への手紙 5:7; マルコの福音書 6:46; マルコの福音書 1:35"> このころ、イエスは祈るために山に行き、神に祈りながら夜を明かされた。</span>
<span className="v" id="v13" data-v="13" data-xref="マルコの福音書 3:13–19; マタイの福音書 9:36–4; ヨハネの黙示録 21:14"> 夜明けになって、弟子たちを呼び寄せ、その中から十二人を選び、彼らに使徒という名をつけられた。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒の働き 1:13; マタイの福音書 4:21; マタイの福音書 4:18"> すなわち、ペテロという名をいただいたシモンとその兄弟アンデレ、ヤコブとヨハネ、ピリポとバルトロマイ、</span>
<span className="v" id="v15" data-v="15" data-xref="マタイの福音書 9:9; マルコの福音書 3:18; 使徒の働き 1:13"> マタイとトマス、アルパヨの子ヤコブと熱心党員と呼ばれるシモン、</span>
<span className="v" id="v16" data-v="16" data-xref="ヨハネの福音書 14:22; ヨハネの福音書 6:70–71; マルコの福音書 3:18"> ヤコブの子ユダとイエスを裏切ったイスカリオテ・ユダである。</span>
<span className="v" id="v17" data-v="17" data-xref="マタイの福音書 11:21; マタイの福音書 4:23–25; Psalms 107:17–20"> それから、イエスは、彼らとともに山を下り、平らな所にお立ちになったが、多くの弟子たちの群れや、ユダヤ全土、エルサレム、さてはツロやシドンの海べから来た大ぜいの民衆がそこにいた。</span>
<span className="v" id="v18" data-v="18" data-xref="マタイの福音書 17:15; マタイの福音書 15:22; 使徒の働き 5:16"> イエスの教えを聞き、また病気を直していただくために来た人々である。また、汚れた霊に悩まされていた人たちもいやされた。</span>
<span className="v" id="v19" data-v="19" data-xref="マタイの福音書 14:36; マルコの福音書 3:10; 使徒の働き 5:15–16"> 群衆のだれもが何とかしてイエスにさわろうとしていた。大きな力がイエスから出て、すべての人をいやしたからである。</span>
<span className="v" id="v20" data-v="20" data-xref="ヤコブの手紙 2:5; ルカの福音書 6:20–24; コリント人への手紙第二 8:9"> イエスは目を上げて弟子たちを見つめながら、話しだされた。「貧しい者は幸いです。神の国はあなたがたのものですから。</span>
<span className="v" id="v21" data-v="21" data-xref="ヨハネの福音書 6:35; マタイの福音書 5:6; ヤコブの手紙 1:12"> いま飢えている者は幸いです。あなたがたは、やがて飽くことができますから。 いま泣いている者は幸いです。あなたがたは、いまに笑うようになりますから。</span>
<span className="v" id="v22" data-v="22" data-xref="マタイの福音書 5:10–12; マタイの福音書 10:22; ペテロの手紙第一 4:12–16"> 人の子のために、人々があなたがたを憎むとき、また、あなたがたを除名し、はずかしめ、あなたがたの名をあしざまにけなすとき、あなたがたは幸いです。</span>
<span className="v" id="v23" data-v="23" data-xref="使徒の働き 5:41; ヨハネの黙示録 21:7; ヨハネの黙示録 3:12"> その日には、喜びなさい。おどり上がって喜びなさい。天ではあなたがたの報いは大きいからです。彼らの先祖も、預言者たちをそのように扱ったのです。</span>
<span className="v" id="v24" data-v="24" data-xref="マタイの福音書 6:2; ヤコブの手紙 5:1–6; Psalms 49:6–7"> しかし、富んでいるあなたがたは、哀れな者です。慰めを、すでに受けているからです。</span>
<span className="v" id="v25" data-v="25" data-xref="Isaiah 65:13; ヤコブの手紙 4:9; Proverbs 14:13"> いま食べ飽きているあなたがたは、哀れな者です。やがて、飢えるようになるからです。いま笑っているあなたがたは、哀れな者です。やがて悲しみ泣くようになるからです。</span>
<span className="v" id="v26" data-v="26" data-xref="ヨハネの福音書 15:19; ヤコブの手紙 4:4; マタイの福音書 7:15"> みなの人にほめられるときは、あなたがたは哀れな者です。彼らの先祖は、にせ預言者たちをそのように扱ったからです。</span>
<span className="v" id="v27" data-v="27" data-xref="テサロニケ人への手紙第一 5:15; ルカの福音書 6:35; ローマ人への手紙 12:17–21"> しかし、いま聞いているあなたがたに、わたしはこう言います。あなたの敵を愛しなさい。あなたを憎む者に善を行ないなさい。</span>
<span className="v" id="v28" data-v="28" data-xref="ペテロの手紙第一 3:9; コリント人への手紙第一 4:12; ローマ人への手紙 12:14"> あなたをのろう者を祝福しなさい。あなたを侮辱する者のために祈りなさい。</span>
<span className="v" id="v29" data-v="29" data-xref="ヘブル人への手紙 10:34; マタイの福音書 5:39–42; コリント人への手紙第二 11:20"> あなたの片方の頬を打つ者には、ほかの頬をも向けなさい。上着を奪い取る者には、下着も拒んではいけません。</span>
<span className="v" id="v30" data-v="30" data-xref="Deuteronomy 15:7–10; コリント人への手紙第二 9:6–14; マタイの福音書 6:12"> すべて求める者には与えなさい。奪い取る者からは取り戻してはいけません。</span>
<span className="v" id="v31" data-v="31" data-xref="マタイの福音書 7:12; ガラテヤ人への手紙 5:14; マタイの福音書 22:39"> 自分にしてもらいたいと望むとおり、人にもそのようにしなさい。</span>
<span className="v" id="v32" data-v="32" data-xref="マタイの福音書 5:46–47; ペテロの手紙第一 2:19–20"> 自分を愛する者を愛したからといって、あなたがたに何の良いところがあるでしょう。罪人たちでさえ、自分を愛する者を愛しています。</span>
<span className="v" id="v33" data-v="33"> 自分に良いことをしてくれる者に良いことをしたからといって、あなたがたに何の良いところがあるでしょう。罪人たちでさえ、同じことをしています。</span>
<span className="v" id="v34" data-v="34" data-xref="マタイの福音書 5:42; ルカの福音書 14:12–14; ルカの福音書 6:35"> 返してもらうつもりで人に貸してやったからといって、あなたがたに何の良いところがあるでしょう。貸した分を取り返すつもりなら、罪人たちでさえ、罪人たちに貸しています。</span>
<span className="v" id="v35" data-v="35" data-xref="マタイの福音書 5:44–45; ヨハネの福音書 13:35; Proverbs 19:17"> ただ、自分の敵を愛しなさい。彼らによくしてやり、返してもらうことを考えずに貸しなさい。そうすれば、あなたがたの受ける報いはすばらしく、あなたがたは、いと高き方の子どもになれます。なぜなら、いと高き方は、恩知らずの悪人にも、あわれみ深いからです。</span>
<span className="v" id="v36" data-v="36" data-xref="エペソ人への手紙 5:1–2; マタイの福音書 5:48; ペテロの手紙第一 1:15–16"> あなたがたの天の父があわれみ深いように、あなたがたも、あわれみ深くしなさい。</span>
<span className="v" id="v37" data-v="37" data-xref="エペソ人への手紙 4:32; ヤコブの手紙 5:9; マタイの福音書 7:1–5"> さばいてはいけません。そうすれば、自分もさばかれません。人を罪に定めてはいけません。そうすれば、自分も罪に定められません。赦しなさい。そうすれば、自分も赦されます。</span>
<span className="v" id="v38" data-v="38" data-xref="コリント人への手紙第二 9:6–8; Deuteronomy 15:10; マルコの福音書 4:24"> 与えなさい。そうすれば、自分も与えられます。人々は量りをよくして、押しつけ、揺すり入れ、あふれるまでにして、ふところに入れてくれるでしょう。あなたがたは、人を量る量りで、自分も量り返してもらうからです。」</span>
<span className="v" id="v39" data-v="39" data-xref="マタイの福音書 15:14; テモテへの手紙第二 3:13; テモテへの手紙第一 6:3–5"> イエスはまた一つのたとえを話された。「いったい、盲人に盲人の手引きができるでしょうか。ふたりとも穴に落ち込まないでしょうか。</span>
<span className="v" id="v40" data-v="40" data-xref="ヨハネの福音書 13:16; マタイの福音書 10:24–25; ヨハネの福音書 15:20"> 弟子は師以上には出られません。しかし十分訓練を受けた者はみな、自分の師ぐらいにはなるのです。</span>
<span className="v" id="v41" data-v="41" data-xref="ヨハネの福音書 8:7; ヤコブの手紙 1:24; ローマ人への手紙 2:1"> あなたは、兄弟の目にあるちりが見えながら、どうして自分の目にある梁には気がつかないのですか。</span>
<span className="v" id="v42" data-v="42" data-xref="ローマ人への手紙 2:21–29; テサロニケ人への手紙第一 2:10–12; Psalms 51:9–13"> 自分の目にある梁が見えずに、どうして兄弟に、『兄弟。あなたの目のちりを取らせてください。』と言えますか。偽善者たち。まず自分の目から梁を取りのけなさい。そうしてこそ、兄弟の目のちりがはっきり見えて、取りのけることができるのです。</span>
<span className="v" id="v43" data-v="43" data-xref="Jeremiah 2:21; マタイの福音書 12:33; マタイの福音書 7:16–20"> 悪い実を結ぶ良い木はないし、良い実を結ぶ悪い木もありません。</span>
<span className="v" id="v44" data-v="44" data-xref="マタイの福音書 12:33; ヤコブの手紙 3:12; ガラテヤ人への手紙 5:19–23"> 木はどれでも、その実によってわかるものです。いばらからいちじくは取れず、野ばらからぶどうを集めることはできません。</span>
<span className="v" id="v45" data-v="45" data-xref="Proverbs 4:23; マタイの福音書 12:34–37; エペソ人への手紙 4:29"> 良い人は、その心の良い倉から良い物を出し、悪い人は、悪い倉から悪い物を出します。なぜなら人の口は、心に満ちているものを話すからです。</span>
<span className="v" id="v46" data-v="46" data-xref="ガラテヤ人への手紙 6:7; Malachi 1:6; マタイの福音書 7:21–23"> なぜ、わたしを『主よ、主よ。』と呼びながら、わたしの言うことを行なわないのですか。</span>
<span className="v" id="v47" data-v="47" data-xref="ヤコブの手紙 1:22–25; マタイの福音書 7:24–27; ルカの福音書 11:28"> わたしのもとに来て、わたしのことばを聞き、それを行なう人たちがどんな人に似ているか、あなたがたに示しましょう。</span>
<span className="v" id="v48" data-v="48" data-xref="コリント人への手紙第一 3:10–15; Psalms 62:2; マタイの福音書 7:25–26"> その人は、地面を深く掘り下げ、岩の上に土台を据えて、それから家を建てた人に似ています。洪水になり、川の水がその家に押し寄せたときも、しっかり建てられていたから、びくともしませんでした。</span>
<span className="v" id="v49" data-v="49" data-xref="Ezekiel 33:31; ヤコブの手紙 1:22–26; マタイの福音書 23:3"> 聞いても実行しない人は、土台なしで地面に家を建てた人に似ています。川の水が押し寄せると、家は一ぺんに倒れてしまい、そのこわれ方はひどいものとなりました。」</span>

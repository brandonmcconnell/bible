<span className="v" id="v1" data-v="1" data-xref="ペテロの手紙第一 4:17–18; Lamentations 2:20; Ezekiel 9:5–7"> ちょうどそのとき、ある人たちがやって来て、イエスに報告した。ピラトがガリラヤ人たちの血をガリラヤ人たちのささげるいけにえに混ぜたというのである。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネの福音書 9:2; 使徒の働き 28:4; Job 22:5–16"> イエスは彼らに答えて言われた。「そのガリラヤ人たちがそのような災難を受けたから、ほかのどのガリラヤ人よりも罪深い人たちだったとでも思うのですか。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒の働き 3:19; マタイの福音書 3:2; 使徒の働き 2:38–40"> そうではない。わたしはあなたがたに言います。あなたがたも悔い改めないなら、みな同じように滅びます。</span>
<span className="v" id="v4" data-v="4" data-xref="Nehemiah 3:15; Job 1:19; ヨハネの福音書 9:11"> また、シロアムの塔が倒れ落ちて死んだあの十八人は、エルサレムに住んでいるだれよりも罪深い人たちだったとでも思うのですか。</span>
<span className="v" id="v5" data-v="5" data-xref="Ezekiel 18:30; ルカの福音書 13:3; Isaiah 28:10–13"> そうではない。わたしはあなたがたに言います。あなたがたも悔い改めないなら、みな同じように滅びます。」</span>
<span className="v" id="v6" data-v="6" data-xref="ヨハネの福音書 15:16; Isaiah 5:1–4; ガラテヤ人への手紙 5:22"> イエスはこのようなたとえを話された。 「ある人が、ぶどう園にいちじくの木を植えておいた。実を取りに来たが、何も見つからなかった。</span>
<span className="v" id="v7" data-v="7" data-xref="マタイの福音書 7:19; ルカの福音書 3:9; ヨハネの福音書 15:6"> そこで、ぶどう園の番人に言った。『見なさい。三年もの間、やって来ては、このいちじくの実のなるのを待っているのに、なっていたためしがない。これを切り倒してしまいなさい。何のために土地をふさいでいるのですか。』</span>
<span className="v" id="v8" data-v="8" data-xref="ペテロの手紙第二 3:9; Joel 2:17; ローマ人への手紙 10:1"> 番人は答えて言った。『ご主人。どうか、ことし一年そのままにしてやってください。木の回りを掘って、肥やしをやってみますから。</span>
<span className="v" id="v9" data-v="9" data-xref="ヨハネの福音書 15:2; テサロニケ人への手紙第一 2:15; ヘブル人への手紙 6:8"> もしそれで来年、実を結べばよし、それでもだめなら、切り倒してください。』」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="マタイの福音書 4:23; ルカの福音書 4:44; ルカの福音書 4:15–16"> イエスは安息日に、ある会堂で教えておられた。</span>
<span className="v" id="v11" data-v="11" data-xref="ルカの福音書 8:2; ルカの福音書 8:27; ルカの福音書 13:16"> すると、そこに十八年も病の霊につかれ、腰が曲がって、全然伸ばすことのできない女がいた。</span>
<span className="v" id="v12" data-v="12" data-xref="Psalms 107:20; マタイの福音書 8:16; ルカの福音書 6:8–10"> イエスは、その女を見て、呼び寄せ、「あなたの病気はいやされました。」と言って、</span>
<span className="v" id="v13" data-v="13" data-xref="Psalms 107:20–22; マルコの福音書 16:18; マルコの福音書 5:23"> 手を置かれると、女はたちどころに腰が伸びて、神をあがめた。</span>
<span className="v" id="v14" data-v="14" data-xref="Exodus 20:9; マタイの福音書 12:2; ヨハネの福音書 9:14–16"> すると、それを見た会堂管理者は、イエスが安息日にいやされたのを憤って、群衆に言った。「働いてよい日は六日です。その間に来て直してもらうがよい。安息日には、いけないのです。」</span>
<span className="v" id="v15" data-v="15" data-xref="ルカの福音書 14:5; ヨハネの福音書 7:21–24; 使徒の働き 13:9–10"> しかし、主は彼に答えて言われた。「偽善者たち。あなたがたは、安息日に、牛やろばを小屋からほどき、水を飲ませに連れて行くではありませんか。</span>
<span className="v" id="v16" data-v="16" data-xref="マルコの福音書 2:27; テモテへの手紙第二 2:26; ルカの福音書 19:9"> この女はアブラハムの娘なのです。それを十八年もの間サタンが縛っていたのです。安息日だからといってこの束縛を解いてやってはいけないのですか。」</span>
<span className="v" id="v17" data-v="17" data-xref="ペテロの手紙第一 3:16; Psalms 132:18; Isaiah 45:24"> こう話されると、反対していた者たちはみな、恥じ入り、群衆はみな、イエスのなさったすべての輝かしいみわざを喜んだ。</span>
<span className="v" id="v18" data-v="18" data-xref="マルコの福音書 4:30–34; ルカの福音書 17:21; マタイの福音書 13:31–32"> そこで、イエスはこう言われた。「神の国は、何に似ているでしょう。何に比べたらよいでしょう。</span>
<span className="v" id="v19" data-v="19" data-xref="Daniel 4:12; Daniel 4:21; Daniel 2:44–45"> それは、からし種のようなものです。それを取って庭に蒔いたところ、生長して木になり、空の鳥が枝に巣を作りました。」</span>
<span className="v" id="v20" data-v="20"> またこう言われた。「神の国を何に比べましょう。</span>
<span className="v" id="v21" data-v="21" data-xref="マタイの福音書 13:33; コリント人への手紙第一 5:6; テサロニケ人への手紙第一 5:23–24"> パン種のようなものです。女がパン種を取って、三サトンの粉に混ぜたところ、全体がふくれました。」</span>
<span className="v" id="v22" data-v="22" data-xref="ルカの福音書 9:51; マタイの福音書 9:35; マルコの福音書 10:32–34"> イエスは、町々村々を次々に教えながら通り、エルサレムへの旅を続けられた。</span>
<span className="v" id="v23" data-v="23" data-xref="マタイの福音書 7:14; マタイの福音書 22:14; ヨハネの福音書 21:21–22"> すると、「主よ。救われる者は少ないのですか。」と言う人があった。イエスは、人々に言われた。</span>
<span className="v" id="v24" data-v="24" data-xref="マタイの福音書 7:13–14; ペテロの手紙第二 1:10; コリント人への手紙第一 9:24–27"> 「努力して狭い門からはいりなさい。なぜなら、あなたがたに言いますが、はいろうとしても、はいれなくなる人が多いのですから。</span>
<span className="v" id="v25" data-v="25" data-xref="マタイの福音書 25:10–12; ルカの福音書 13:27; マタイの福音書 7:21–23"> 家の主人が、立ち上がって、戸をしめてしまってからでは、外に立って、『ご主人さま。あけてください。』と言って、戸をいくらたたいても、もう主人は、『あなたがたがどこの者か、私は知らない。』と答えるでしょう。</span>
<span className="v" id="v26" data-v="26" data-xref="Isaiah 58:2; テトスへの手紙 1:16; テモテへの手紙第二 3:5"> すると、あなたがたは、こう言い始めるでしょう。『私たちは、ごいっしょに、食べたり飲んだりいたしましたし、私たちの大通りで教えていただきました。』</span>
<span className="v" id="v27" data-v="27" data-xref="Psalms 6:8; マタイの福音書 25:41; マタイの福音書 7:22–23"> だが、主人はこう言うでしょう。『私はあなたがたがどこの者だか知りません。不正を行なう者たち。みな出て行きなさい。』</span>
<span className="v" id="v28" data-v="28" data-xref="マタイの福音書 8:11–12; マタイの福音書 22:13; マタイの福音書 25:30"> 神の国にアブラハムやイサクやヤコブや、すべての預言者たちがはいっているのに、あなたがたは外に投げ出されることになったとき、そこで泣き叫んだり、歯ぎしりしたりするのです。</span>
<span className="v" id="v29" data-v="29" data-xref="Isaiah 43:6; Isaiah 66:18–20; Isaiah 49:6"> 人々は、東からも西からも、また南からも北からも来て、神の国で食卓に着きます。</span>
<span className="v" id="v30" data-v="30" data-xref="マタイの福音書 19:30; マルコの福音書 10:31; マタイの福音書 20:16"> いいですか、今しんがりの者があとで先頭になり、いま先頭の者がしんがりになるのです。」</span>
<span className="v" id="v31" data-v="31" data-xref="Nehemiah 6:9–11; Psalms 11:1–2; マタイの福音書 14:1"> ちょうどそのとき、何人かのパリサイ人が近寄って来て、イエスに言った。「ここから出てほかの所へ行きなさい。ヘロデがあなたを殺そうと思っています。」</span>
<span className="v" id="v32" data-v="32" data-xref="ヘブル人への手紙 2:10; ヘブル人への手紙 5:9; ヨハネの福音書 17:4–5"> イエスは言われた。「行って、あの狐にこう言いなさい。『よく見なさい。わたしは、きょうと、あすとは、悪霊どもを追い出し、病人を直し、三日目に全うされます。</span>
<span className="v" id="v33" data-v="33" data-xref="ルカの福音書 9:53; マタイの福音書 21:11; 使徒の働き 13:27"> だが、わたしは、きょうもあすも次の日も進んで行かなければなりません。なぜなら、預言者がエルサレム以外の所で死ぬことはありえないからです。』</span>
<span className="v" id="v34" data-v="34" data-xref="マタイの福音書 23:37–39; Deuteronomy 32:11–12; 使徒の働き 7:52"> ああ、エルサレム、エルサレム。預言者たちを殺し、自分に遣わされた人たちを石で打つ者、わたしは、めんどりがひなを翼の下にかばうように、あなたの子らを幾たび集めようとしたことか。それなのに、あなたがたはそれを好まなかった。</span>
<span className="v" id="v35" data-v="35" data-xref="Psalms 118:26; マルコの福音書 11:9–10; マタイの福音書 21:9"> 見なさい。あなたがたの家は荒れ果てたままに残される。わたしはあなたがたに言います。『祝福あれ。主の御名によって来られる方に。』とあなたがたの言うときが来るまでは、あなたがたは決してわたしを見ることができません。」</span>
</div>

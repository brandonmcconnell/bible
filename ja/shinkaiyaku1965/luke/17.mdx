<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マタイの福音書 18:7; ローマ人への手紙 14:13; コリント人への手紙第一 11:19"> イエスは弟子たちにこう言われた。「つまずきが起こるのは避けられない。だが、つまずきを起こさせる者は、忌まわしいものです。</span>
<span className="v" id="v2" data-v="2" data-xref="マルコの福音書 9:42; マタイの福音書 18:14; マタイの福音書 18:3–6"> この小さい者たちのひとりに、つまずきを与えるようであったら、そんな者は石臼を首にゆわえつけられて、海に投げ込まれたほうがましです。</span>
<span className="v" id="v3" data-v="3" data-xref="Leviticus 19:17; マタイの福音書 18:21; マタイの福音書 18:15–17"> 気をつけていなさい。もし兄弟が罪を犯したなら、彼を戒めなさい。そして悔い改めれば、赦しなさい。</span>
<span className="v" id="v4" data-v="4" data-xref="コロサイ人への手紙 3:12–13; マタイの福音書 18:21–22; ローマ人への手紙 12:20"> かりに、あなたに対して一日に七度罪を犯しても、『悔い改めます。』と言って七度あなたのところに来るなら、赦してやりなさい。」</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="マルコの福音書 9:24; ヘブル人への手紙 12:2; ピリピ人への手紙 4:13"> 使徒たちは主に言った。「私たちの信仰を増してください。」</span>
<span className="v" id="v6" data-v="6" data-xref="マタイの福音書 17:20; マタイの福音書 21:21; マルコの福音書 9:23"> しかし主は言われた。「もしあなたがたに、からし種ほどの信仰があったなら、この桑の木に、『根こそぎ海の中に植われ。』と言えば、言いつけどおりになるのです。</span>
<span className="v" id="v7" data-v="7" data-xref="マタイの福音書 12:11; ルカの福音書 13:15; ルカの福音書 14:5"> ところで、あなたがたのだれかに、耕作か羊飼いをするしもべがいるとして、そのしもべが野らから帰って来たとき、『さあ、さあ、ここに来て、食事をしなさい。』としもべに言うでしょうか。</span>
<span className="v" id="v8" data-v="8" data-xref="ルカの福音書 12:37; Genesis 43:16; 2 Samuel 12:20"> かえって、『私の食事の用意をし、帯を締めて私の食事が済むまで給仕しなさい。あとで、自分の食事をしなさい。』と言わないでしょうか。</span>
<span className="v" id="v9" data-v="9"> しもべが言いつけられたことをしたからといって、そのしもべに感謝するでしょうか。</span>
<span className="v" id="v10" data-v="10" data-xref="コリント人への手紙第一 9:16–17; Job 22:2–3; ペテロの手紙第一 5:5–6"> あなたがたもそのとおりです。自分に言いつけられたことをみな、してしまったら、『私たちは役に立たないしもべです。なすべきことをしただけです。』と言いなさい。」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="ルカの福音書 9:51–52; ヨハネの福音書 4:3–4"> そのころイエスはエルサレムに上られる途中、サマリヤとガリラヤの境を通られた。</span>
<span className="v" id="v12" data-v="12" data-xref="Leviticus 13:45–46; ルカの福音書 5:12; 2 Kings 7:3"> ある村にはいると、十人のらい病人がイエスに出会った。彼らは遠く離れた所に立って、</span>
<span className="v" id="v13" data-v="13" data-xref="マタイの福音書 15:22; マタイの福音書 20:30–31; マタイの福音書 9:27"> 声を張り上げて、「イエスさま、先生。どうぞあわれんでください。」と言った。</span>
<span className="v" id="v14" data-v="14" data-xref="ルカの福音書 5:14; Leviticus 13:1–46; 2 Kings 5:14"> イエスはこれを見て、言われた。「行きなさい。そして自分を祭司に見せなさい。」彼らは行く途中でいやされた。</span>
<span className="v" id="v15" data-v="15" data-xref="Psalms 30:11–12; Psalms 103:1–4; Psalms 118:18–19"> そのうちのひとりは、自分のいやされたことがわかると、大声で神をほめたたえながら引き返して来て、</span>
<span className="v" id="v16" data-v="16" data-xref="使徒の働き 8:5–25; マタイの福音書 10:5; ヨハネの黙示録 19:10"> イエスの足もとにひれ伏して感謝した。彼はサマリヤ人であった。</span>
<span className="v" id="v17" data-v="17" data-xref="ローマ人への手紙 1:21; Psalms 106:13; Genesis 3:9"> そこでイエスは言われた。「十人いやされたのではないか。九人はどこにいるのか。</span>
<span className="v" id="v18" data-v="18" data-xref="Psalms 50:23; マタイの福音書 15:24–28; Psalms 106:13"> 神をあがめるために戻って来た者は、この外国人のほかには、だれもいないのか。」</span>
<span className="v" id="v19" data-v="19" data-xref="ルカの福音書 7:50; ルカの福音書 8:48; マルコの福音書 10:52"> それからその人に言われた。「立ち上がって、行きなさい。あなたの信仰が、あなたを直したのです。」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="ヨハネの福音書 18:36; ルカの福音書 19:11; Daniel 2:44"> さて、神の国はいつ来るのか、とパリサイ人たちに尋ねられたとき、イエスは答えて言われた。「神の国は、人の目で認められるようにして来るものではありません。</span>
<span className="v" id="v21" data-v="21" data-xref="マタイの福音書 12:28; ローマ人への手紙 14:17; マルコの福音書 13:21"> 『そら、ここにある。』とか、『あそこにある。』とか言えるようなものではありません。いいですか。神の国は、あなたがたのただ中にあるのです。」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="ルカの福音書 5:35; マタイの福音書 9:15; ヨハネの福音書 8:21–24"> イエスは弟子たちに言われた。「人の子の日を一日でも見たいと願っても、見られない時が来ます。</span>
<span className="v" id="v23" data-v="23" data-xref="ルカの福音書 21:8; マタイの福音書 24:23–26; ルカの福音書 17:21"> 人々が『こちらだ。』とか、『あちらだ。』とか言っても行ってはなりません。あとを追いかけてはなりません。</span>
<span className="v" id="v24" data-v="24" data-xref="マタイの福音書 24:27; マタイの福音書 24:30; Malachi 4:1–2"> いなずまが、ひらめいて、天の端から天の端へと輝くように、人の子は、人の子の日には、ちょうどそのようであるからです。</span>
<span className="v" id="v25" data-v="25" data-xref="マタイの福音書 16:21; ルカの福音書 9:22; マルコの福音書 8:31"> しかし、人の子はまず、多くの苦しみを受け、この時代に捨てられなければなりません。</span>
<span className="v" id="v26" data-v="26" data-xref="マタイの福音書 24:37–39; ルカの福音書 17:24; Genesis 7:7–23"> 人の子の日に起こることは、ちょうど、ノアの日に起こったことと同様です。</span>
<span className="v" id="v27" data-v="27" data-xref="ルカの福音書 12:19–20; テサロニケ人への手紙第一 5:1–3; ルカの福音書 16:19–23"> ノアが箱舟にはいるその日まで、人々は、食べたり、飲んだり、めとったり、とついだりしていたが、洪水が来て、すべての人を滅ぼしてしまいました。</span>
<span className="v" id="v28" data-v="28" data-xref="Ezekiel 16:49–50; Genesis 18:20–21; ヤコブの手紙 5:1–5"> また、ロトの時代にあったことと同様です。人々は食べたり、飲んだり、売ったり、買ったり、植えたり、建てたりしていたが、</span>
<span className="v" id="v29" data-v="29" data-xref="ペテロの手紙第二 2:6; Zephaniah 2:9; ユダの手紙 1:7"> ロトがソドムから出て行くと、その日に、火と硫黄が天から降って、すべての人を滅ぼしてしまいました。</span>
<span className="v" id="v30" data-v="30" data-xref="コリント人への手紙第一 1:7; テサロニケ人への手紙第二 1:7; ヨハネの黙示録 1:7"> 人の子の現われる日にも、全くそのとおりです。</span>
<span className="v" id="v31" data-v="31" data-xref="ルカの福音書 21:21; マルコの福音書 13:14–16; Jeremiah 45:5"> その日には、屋上にいる者は家に家財があっても、取り出しに降りてはいけません。同じように、畑にいる者も家に帰ってはいけません。</span>
<span className="v" id="v32" data-v="32" data-xref="Genesis 19:26; ヘブル人への手紙 10:38–39; ペテロの手紙第二 2:18–22"> ロトの妻を思い出しなさい。</span>
<span className="v" id="v33" data-v="33" data-xref="マルコの福音書 8:35–37; マタイの福音書 10:39; ヨハネの福音書 12:25"> 自分のいのちを救おうと努める者はそれを失い、それを失う者はいのちを保ちます。</span>
<span className="v" id="v34" data-v="34" data-xref="マタイの福音書 24:40–41; ペテロの手紙第二 2:9; Malachi 3:16–18"> あなたがたに言いますが、その夜、同じ寝台で男がふたり寝ていると、ひとりは取られ、他のひとりは残されます。</span>
<span className="v" id="v35" data-v="35" data-xref="マタイの福音書 24:41; Exodus 11:5; Judges 16:21"> 女がふたりいっしょに臼をひいていると、ひとりは取られ、他のひとりは残されます。」</span>
<span className="v" id="v36" data-v="36"> 弟子たちは答えて言った。「主よ。どこでですか。」主は言われた。「死体のある所、そこに、はげたかも集まります。」</span>
</div>

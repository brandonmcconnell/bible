<span className="v" id="v1" data-v="1" data-xref="テモテへの手紙第一 1:15; マタイの福音書 9:10–13; ルカの福音書 5:29–32"> さて、取税人、罪人たちがみな、イエスの話を聞こうとして、みもとに近寄って来た。</span>
<span className="v" id="v2" data-v="2" data-xref="マタイの福音書 9:11; ルカの福音書 19:7; ルカの福音書 7:39"> すると、パリサイ人、律法学者たちは、つぶやいてこう言った。「この人は、罪人たちを受け入れて、食事までいっしょにする。」</span>
<span className="v" id="v3" data-v="3"> そこでイエスは、彼らにこのようなたとえを話された。</span>
<span className="v" id="v4" data-v="4" data-xref="Ezekiel 34:16; Ezekiel 34:11–12; マタイの福音書 18:12–14"> 「あなたがたのうちに羊を百匹持っている人がいて、そのうちの一匹をなくしたら、その人は九十九匹を野原に残して、いなくなった一匹を見つけるまで捜し歩かないでしょうか。</span>
<span className="v" id="v5" data-v="5" data-xref="ヘブル人への手紙 12:2; ルカの福音書 19:9; Isaiah 46:3–4"> 見つけたら、大喜びでその羊をかついで、</span>
<span className="v" id="v6" data-v="6" data-xref="ルカの福音書 15:10; ルカの福音書 15:24; ペテロの手紙第一 2:25"> 帰って来て、友だちや近所の人たちを呼び集め、『いなくなった羊を見つけましたから、いっしょに喜んでください。』と言うでしょう。</span>
<span className="v" id="v7" data-v="7" data-xref="ルカの福音書 5:32; ルカの福音書 15:10; ルカの福音書 15:32"> あなたがたに言いますが、それと同じように、ひとりの罪人が悔い改めるなら、悔い改める必要のない九十九人の正しい人にまさる喜びが天にあるのです。</span>
<span className="v" id="v8" data-v="8" data-xref="ルカの福音書 19:10; Ezekiel 34:12; ヨハネの福音書 10:16"> また、女の人が銀貨を十枚持っていて、もしその一枚をなくしたら、あかりをつけ、家を掃いて、見つけるまで念入りに捜さないでしょうか。</span>
<span className="v" id="v9" data-v="9" data-xref="ルカの福音書 15:6–7"> 見つけたら、友だちや近所の女たちを呼び集めて、『なくした銀貨を見つけましたから、いっしょに喜んでください。』と言うでしょう。</span>
<span className="v" id="v10" data-v="10" data-xref="ルカの福音書 15:7; コリント人への手紙第二 7:10; Ezekiel 33:11"> あなたがたに言いますが、それと同じように、ひとりの罪人が悔い改めるなら、神の御使いたちに喜びがわき起こるのです。」</span>
<span className="v" id="v11" data-v="11" data-xref="マタイの福音書 21:23–31"> またこう話された。 「ある人に息子がふたりあった。</span>
<span className="v" id="v12" data-v="12" data-xref="Deuteronomy 21:16–17; マルコの福音書 12:44; ルカの福音書 15:30"> 弟が父に、『おとうさん。私に財産の分け前を下さい。』と言った。それで父は、身代をふたりに分けてやった。</span>
<span className="v" id="v13" data-v="13" data-xref="Proverbs 29:3; Jeremiah 2:5; Proverbs 21:17"> それから、幾日もたたぬうちに、弟は、何もかもまとめて遠い国に旅立った。そして、そこで放蕩して湯水のように財産を使ってしまった。</span>
<span className="v" id="v14" data-v="14" data-xref="2 Chronicles 33:11; Amos 8:9–12; Hosea 2:9–14"> 何もかも使い果たしたあとで、その国に大ききんが起こり、彼は食べるにも困り始めた。</span>
<span className="v" id="v15" data-v="15" data-xref="テトスへの手紙 3:3; テモテへの手紙第二 2:25–26; Isaiah 1:5"> それで、その国のある人のもとに身を寄せたところ、その人は彼を畑にやって、豚の世話をさせた。</span>
<span className="v" id="v16" data-v="16" data-xref="ローマ人への手紙 6:19–21; Lamentations 4:5; Hosea 12:1"> 彼は豚の食べるいなご豆で腹を満たしたいほどであったが、だれひとり彼に与えようとはしなかった。</span>
<span className="v" id="v17" data-v="17" data-xref="Ezekiel 18:28; エペソ人への手紙 2:4–5; ルカの福音書 15:18–19"> しかし、我に返ったとき彼は、こう言った。『父のところには、パンのあり余っている雇い人が大ぜいいるではないか。それなのに、私はここで、飢え死にしそうだ。</span>
<span className="v" id="v18" data-v="18" data-xref="Lamentations 3:40; ヨハネの手紙第一 1:8–10; ルカの福音書 15:21"> 立って、父のところに行って、こう言おう。「おとうさん。私は天に対して罪を犯し、またあなたの前に罪を犯しました。</span>
<span className="v" id="v19" data-v="19" data-xref="Job 42:6; ルカの福音書 5:8; Psalms 84:10"> もう私は、あなたの子と呼ばれる資格はありません。雇い人のひとりにしてください。」』</span>
<span className="v" id="v20" data-v="20" data-xref="Psalms 103:10–13; Psalms 86:5; Psalms 86:15"> こうして彼は立ち上がって、自分の父のもとに行った。ところが、まだ家までは遠かったのに、父親は彼を見つけ、かわいそうに思い、走り寄って彼を抱き、口づけした。</span>
<span className="v" id="v21" data-v="21" data-xref="Psalms 51:4; ルカの福音書 15:18–19; Jeremiah 3:13"> 息子は言った。『おとうさん。私は天に対して罪を犯し、またあなたの前に罪を犯しました。もう私は、あなたの子と呼ばれる資格はありません。』</span>
<span className="v" id="v22" data-v="22" data-xref="Genesis 41:42; Esther 8:2; ヨハネの黙示録 6:11"> ところが父親は、しもべたちに言った。『急いで一番良い着物を持って来て、この子に着せなさい。それから、手に指輪をはめさせ、足にくつをはかせなさい。</span>
<span className="v" id="v23" data-v="23" data-xref="Isaiah 25:6; マタイの福音書 22:2–14; Psalms 63:5"> そして肥えた子牛を引いて来てほふりなさい。食べて祝おうではないか。</span>
<span className="v" id="v24" data-v="24" data-xref="エペソ人への手紙 2:5; Ezekiel 34:16; ルカの福音書 19:10"> この息子は、死んでいたのが生き返り、いなくなっていたのが見つかったのだから。』そして彼らは祝宴を始めた。</span>
<span className="v" id="v25" data-v="25" data-xref="Psalms 150:4; Jeremiah 31:4; ルカの福音書 15:11–12"> ところで、兄息子は畑にいたが、帰って来て家に近づくと、音楽や踊りの音が聞こえて来た。それで、</span>
<span className="v" id="v26" data-v="26"> しもべのひとりを呼んで、これはいったい何事かと尋ねると、</span>
<span className="v" id="v27" data-v="27" data-xref="使徒の働き 9:17; ピレモンへの手紙 1:16; 使徒の働き 22:13"> しもべは言った。『弟さんがお帰りになったのです。無事な姿をお迎えしたというので、おとうさんが、肥えた子牛をほふらせなさったのです。』</span>
<span className="v" id="v28" data-v="28" data-xref="Jonah 4:9; 1 Samuel 18:8; Jonah 4:1–4"> すると、兄はおこって、家にはいろうともしなかった。それで、父が出て来て、いろいろなだめてみた。</span>
<span className="v" id="v29" data-v="29" data-xref="ルカの福音書 18:11–12; Zechariah 7:3; Isaiah 65:5"> しかし兄は父にこう言った。『ご覧なさい。長年の間、私はおとうさんに仕え、戒めを破ったことは一度もありません。その私には、友だちと楽しめと言って、子山羊一匹下さったことがありません。</span>
<span className="v" id="v30" data-v="30" data-xref="Proverbs 29:3; ルカの福音書 15:12–13; ルカの福音書 15:32"> それなのに、遊女におぼれてあなたの身代を食いつぶして帰って来たこのあなたの息子のためには、肥えた子牛をほふらせなさったのですか。』</span>
<span className="v" id="v31" data-v="31" data-xref="マルコの福音書 7:27–28; ローマ人への手紙 9:4; ローマ人への手紙 11:1"> 父は彼に言った。『おまえはいつも私といっしょにいる。私のものは、全部おまえのものだ。</span>
<span className="v" id="v32" data-v="32" data-xref="エペソ人への手紙 2:1–10; ルカの福音書 15:24; Isaiah 35:10"> だがおまえの弟は、死んでいたのが生き返って来たのだ。いなくなっていたのが見つかったのだから、楽しんで喜ぶのは当然ではないか。』」</span>

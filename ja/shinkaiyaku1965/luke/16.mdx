<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ペテロの手紙第一 4:10; マタイの福音書 25:14–30; ヤコブの手紙 4:3"> イエスは、弟子たちにも、こういう話をされた。<br />「ある金持ちにひとりの管理人がいた。この管理人が主人の財産を乱費している、という訴えが出された。</span>
<span className="v" id="v2" data-v="2" data-xref="Ecclesiastes 11:9–10; ペテロの手紙第一 4:5; ヨハネの黙示録 20:12"> 主人は、彼を呼んで言った。『おまえについてこんなことを聞いたが、何ということをしてくれたのだ。もう管理を任せておくことはできないから、会計の報告を出しなさい。』</span>
<span className="v" id="v3" data-v="3" data-xref="Jeremiah 5:31; Isaiah 10:3; Proverbs 18:9"> 管理人は心の中で言った。『主人にこの管理の仕事を取り上げられるが、さてどうしよう。土を掘るには力がないし、こじきをするのは恥ずかしいし。</span>
<span className="v" id="v4" data-v="4" data-xref="Proverbs 30:9; Jeremiah 4:22; ヤコブの手紙 3:15"> ああ、わかった。こうしよう。こうしておけば、いつ管理の仕事をやめさせられても、人がその家に私を迎えてくれるだろう。』</span>
<span className="v" id="v5" data-v="5" data-xref="ルカの福音書 7:41–42; マタイの福音書 18:24"> そこで彼は、主人の債務者たちをひとりひとり呼んで、まず最初の者に、『私の主人に、いくら借りがありますか。』と言うと、</span>
<span className="v" id="v6" data-v="6" data-xref="テトスへの手紙 2:10; ルカの福音書 16:12; ルカの福音書 16:9"> その人は、『油百バテ。』と言った。すると彼は、『さあ、あなたの証文だ。すぐにすわって五十と書きなさい。』と言った。</span>
<span className="v" id="v7" data-v="7" data-xref="Song of Solomon 8:11–12; ルカの福音書 20:9; ルカの福音書 20:12"> それから、別の人に、『さて、あなたは、いくら借りがありますか。』と言うと、『小麦百コル。』と言った。彼は、『さあ、あなたの証文だ。八十と書きなさい。』と言った。</span>
<span className="v" id="v8" data-v="8" data-xref="テサロニケ人への手紙第一 5:5; エペソ人への手紙 5:8; Proverbs 6:6–8"> この世の子らは、自分たちの世のことについては、光の子らよりも抜けめがないものなので、主人は、不正な管理人がこうも抜けめなくやったのをほめた。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="マタイの福音書 19:21; テモテへの手紙第一 6:17–19; Daniel 4:27"> そこで、わたしはあなたがたに言いますが、不正の富で、自分のために友をつくりなさい。そうしておけば、富がなくなったとき、彼らはあなたがたを、永遠の住まいに迎えるのです。</span>
<span className="v" id="v10" data-v="10" data-xref="ルカの福音書 16:11–12; マタイの福音書 25:21; ルカの福音書 19:17"> 小さい事に忠実な人は、大きい事にも忠実であり、小さい事に不忠実な人は、大きい事にも不忠実です。</span>
<span className="v" id="v11" data-v="11" data-xref="ルカの福音書 12:33; ヤコブの手紙 2:5; Proverbs 8:18–19"> ですから、あなたがたが不正の富に忠実でなかったら、だれがあなたがたに、まことの富を任せるでしょう。</span>
<span className="v" id="v12" data-v="12" data-xref="ルカの福音書 19:13–26; マタイの福音書 25:14–29; Job 1:21"> また、あなたがたが他人のものに忠実でなかったら、だれがあなたがたに、あなたがたのものを持たせるでしょう。</span>
<span className="v" id="v13" data-v="13" data-xref="ヨハネの手紙第一 2:15–16; マタイの福音書 6:24; ヤコブの手紙 4:4"> しもべは、ふたりの主人に仕えることはできません。一方を憎んで他方を愛したり、または一方を重んじて他方を軽んじたりするからです。あなたがたは、神にも仕え、また富にも仕えるということはできません。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="ルカの福音書 23:35; ルカの福音書 20:47; Jeremiah 6:13"> さて、金の好きなパリサイ人たちが、一部始終を聞いて、イエスをあざ笑っていた。</span>
<span className="v" id="v15" data-v="15" data-xref="1 Samuel 16:7; Proverbs 21:2; コリント人への手紙第一 4:5"> イエスは彼らに言われた。「あなたがたは、人の前で自分を正しいとする者です。しかし神は、あなたがたの心をご存じです。人間の間であがめられる者は、神の前で憎まれ、きらわれます。</span>
<span className="v" id="v16" data-v="16" data-xref="マタイの福音書 11:9–14; マタイの福音書 21:32; 使徒の働き 3:24–25"> 律法と預言者はヨハネまでです。それ以来、神の国の福音は宣べ伝えられ、だれもかれも、無理にでも、これにはいろうとしています。</span>
<span className="v" id="v17" data-v="17" data-xref="マタイの福音書 5:18; ルカの福音書 21:33; ペテロの手紙第一 1:25"> しかし律法の一画が落ちるよりも、天地の滅びるほうがやさしいのです。</span>
<span className="v" id="v18" data-v="18" data-xref="マタイの福音書 19:9; マルコの福音書 10:11–12; マタイの福音書 5:31–32"> だれでも妻を離別してほかの女と結婚する者は、姦淫を犯す者であり、また、夫から離別された女と結婚する者も、姦淫を犯す者です。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="Ezekiel 16:49; Amos 6:4–6; ルカの福音書 18:24–25"> ある金持ちがいた。いつも紫の衣や細布を着て、毎日ぜいたくに遊び暮らしていた。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="使徒の働き 3:2; 1 Samuel 2:8; ヤコブの手紙 2:5"> ところが、その門前にラザロという全身おできの貧乏人が寝ていて、</span>
<span className="v" id="v21" data-v="21" data-xref="マタイの福音書 15:27; マルコの福音書 7:28; ヨハネの福音書 6:12"> 金持ちの食卓から落ちる物で腹を満たしたいと思っていた。犬もやって来ては、彼のおできをなめていた。</span>
<span className="v" id="v22" data-v="22" data-xref="ペテロの手紙第一 2:24; Psalms 49:16–19; ヤコブの手紙 1:11"> さて、この貧乏人は死んで、御使いたちによってアブラハムのふところに連れて行かれた。金持ちも死んで葬られた。</span>
<span className="v" id="v23" data-v="23" data-xref="ペテロの手紙第二 2:4; ルカの福音書 16:28; マタイの福音書 18:9"> その金持ちは、ハデスで苦しみながら目を上げると、アブラハムが、はるかかなたに見えた。しかも、そのふところにラザロが見えた。</span>
<span className="v" id="v24" data-v="24" data-xref="ヨハネの福音書 4:10; ヨハネの黙示録 22:1; ヨハネの黙示録 7:16–17"> 彼は叫んで言った。『父アブラハムさま。私をあわれんでください。ラザロが指先を水に浸して私の舌を冷やすように、ラザロをよこしてください。私はこの炎の中で、苦しくてたまりません。』</span>
<span className="v" id="v25" data-v="25" data-xref="ルカの福音書 6:24; ヨハネの手紙第一 2:15; Psalms 17:14"> アブラハムは言った。『子よ。思い出してみなさい。おまえは生きている間、良い物を受け、ラザロは生きている間、悪い物を受けていました。しかし、今ここで彼は慰められ、おまえは苦しみもだえているのです。</span>
<span className="v" id="v26" data-v="26" data-xref="ヨハネの福音書 3:36; Psalms 49:14; Psalms 50:22"> そればかりでなく、私たちとおまえたちの間には、大きな淵があります。ここからそちらへ渡ろうとしても、渡れないし、そこからこちらへ越えて来ることもできないのです。』</span>
<span className="v" id="v27" data-v="27"> 彼は言った。『父よ。ではお願いです。ラザロを私の父の家に送ってください。</span>
<span className="v" id="v28" data-v="28" data-xref="使徒の働き 2:40; Psalms 49:12–13; テサロニケ人への手紙第一 4:6"> 私には兄弟が五人ありますが、彼らまでこんな苦しみの場所に来ることのないように、よく言い聞かせてください。』</span>
<span className="v" id="v29" data-v="29" data-xref="使徒の働き 15:21; ルカの福音書 24:27; ルカの福音書 16:16"> しかしアブラハムは言った。『彼らには、モーセと預言者があります。その言うことを聞くべきです。』</span>
<span className="v" id="v30" data-v="30" data-xref="ヨハネの黙示録 16:9–11; ルカの福音書 16:24; ルカの福音書 13:5"> 彼は言った。『いいえ、父アブラハム。もし、だれかが死んだ者の中から彼らのところに行ってやったら、彼らは悔い改めるに違いありません。』</span>
<span className="v" id="v31" data-v="31" data-xref="コリント人への手紙第二 4:3; 使徒の働き 19:8; ヨハネの福音書 11:43–53"> アブラハムは彼に言った。『もしモーセと預言者との教えに耳を傾けないのなら、たといだれかが死人の中から生き返っても、彼らは聞き入れはしない。』」</span>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マタイの福音書 4:23; ローマ人への手紙 10:15; マタイの福音書 9:35"> その後、イエスは、神の国を説き、その福音を宣べ伝えながら、町や村を次から次に旅をしておられた。十二弟子もお供をした。</span>
<span className="v" id="v2" data-v="2" data-xref="マルコの福音書 16:9; マタイの福音書 27:55–56; マルコの福音書 15:40–41"> また、悪霊や病気を直していただいた女たち、すなわち、七つの悪霊を追い出していただいたマグダラの女と呼ばれるマリヤ、</span>
<span className="v" id="v3" data-v="3" data-xref="ヨハネの福音書 4:46–53; コリント人への手紙第二 8:9; 使徒の働き 9:36–39"> ヘロデの執事クーザの妻ヨハンナ、スザンナ、そのほか自分の財産をもって彼らに仕えている大ぜいの女たちもいっしょであった。</span>
<span className="v" id="v4" data-v="4" data-xref="マルコの福音書 4:1–9; マタイの福音書 13:2–9"> さて、大ぜいの人の群れが集まり、また方々の町からも人々がみもとにやって来たので、イエスはたとえを用いて話された。</span>
<span className="v" id="v5" data-v="5" data-xref="ヘブル人への手紙 2:1; ヤコブの手紙 1:23–24; マルコの福音書 4:15"> 「種を蒔く人が種蒔きに出かけた。蒔いているとき、道ばたに落ちた種があった。すると、人に踏みつけられ、空の鳥がそれを食べてしまった。</span>
<span className="v" id="v6" data-v="6" data-xref="ヘブル人への手紙 3:7–8; ルカの福音書 8:13; マルコの福音書 4:5–6"> また、別の種は岩の上に落ち、生え出たが、水分がなかったので、枯れてしまった。</span>
<span className="v" id="v7" data-v="7" data-xref="Jeremiah 4:3; ルカの福音書 8:14; ルカの福音書 21:34"> また、別の種はいばらの真中に落ちた。ところが、いばらもいっしょに生え出て、それを押しふさいでしまった。</span>
<span className="v" id="v8" data-v="8" data-xref="マタイの福音書 11:15; ヨハネの黙示録 2:11; ヨハネの黙示録 2:7"> また、別の種は良い地に落ち、生え出て、百倍の実を結んだ。」 イエスは、これらのことを話しながら「聞く耳のある者は聞きなさい。」と叫ばれた。</span>
<span className="v" id="v9" data-v="9" data-xref="マルコの福音書 4:10; マタイの福音書 13:10; マタイの福音書 13:18"> さて、弟子たちは、このたとえがどんな意味かをイエスに尋ねた。</span>
<span className="v" id="v10" data-v="10" data-xref="Isaiah 6:9; マルコの福音書 4:11; マタイの福音書 11:25"> そこでイエスは言われた。「あなたがたに、神の国の奥義を知ることが許されているが、ほかの者には、たとえで話します。彼らが見ていても見えず、聞いていても悟らないためです。</span>
<span className="v" id="v11" data-v="11" data-xref="マタイの福音書 13:19; マルコの福音書 4:14–20; ヤコブの手紙 1:21"> このたとえの意味はこうです。種は神のことばです。</span>
<span className="v" id="v12" data-v="12" data-xref="テサロニケ人への手紙第二 2:9–14; ヨハネの黙示録 12:9; ヤコブの手紙 1:23–24"> 道ばたに落ちるとは、こういう人たちのことです。みことばを聞いたが、あとから悪魔が来て、彼らが信じて救われることのないように、その人たちの心から、みことばを持ち去ってしまうのです。</span>
<span className="v" id="v13" data-v="13" data-xref="Hosea 6:4; ヨハネの福音書 5:35; Proverbs 12:12"> 岩の上に落ちるとは、こういう人たちのことです。聞いたときには喜んでみことばを受け入れるが、根がないので、しばらくは信じていても、試練のときになると、身を引いてしまうのです。</span>
<span className="v" id="v14" data-v="14" data-xref="ヨハネの手紙第一 2:15–17; テモテへの手紙第一 6:9–10; テモテへの手紙第一 6:17"> いばらの中に落ちるとは、こういう人たちのことです。みことばを聞きはしたが、とかくしているうちに、この世の心づかいや、富や、快楽によってふさがれて、実が熟するまでにならないのです。</span>
<span className="v" id="v15" data-v="15" data-xref="ヘブル人への手紙 10:36; ガラテヤ人への手紙 5:22–26; コロサイ人への手紙 1:10"> しかし、良い地に落ちるとは、こういう人たちのことです。正しい、良い心でみことばを聞くと、それをしっかりと守り、よく耐えて、実を結ばせるのです。</span>
<span className="v" id="v16" data-v="16" data-xref="ルカの福音書 11:33; マタイの福音書 5:15–16; マルコの福音書 4:21–22"> あかりをつけてから、それを器で隠したり、寝台の下に置いたりする者はありません。燭台の上に置きます。はいって来る人々に、その光が見えるためです。</span>
<span className="v" id="v17" data-v="17" data-xref="ルカの福音書 12:2–3; マタイの福音書 10:26; マルコの福音書 4:22"> 隠れているもので、あらわにならぬものはなく、秘密にされているもので、知られず、また現われないものはありません。</span>
<span className="v" id="v18" data-v="18" data-xref="マタイの福音書 13:12; ルカの福音書 19:26; マルコの福音書 4:23–25"> だから、聞き方に注意しなさい。というのは、持っている人は、さらに与えられ、持たない人は、持っていると思っているものまでも取り上げられるからです。」</span>
<span className="v" id="v19" data-v="19" data-xref="マタイの福音書 12:46–50; マルコの福音書 3:31–35; マルコの福音書 3:21"> イエスのところに母と兄弟たちが来たが、群衆のためにそばへ近寄れなかった。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒の働き 1:14; マルコの福音書 6:3; マタイの福音書 13:55–56"> それでイエスに、「あなたのおかあさんと兄弟たちが、あなたに会おうとして、外に立っています。」という知らせがあった。</span>
<span className="v" id="v21" data-v="21" data-xref="ルカの福音書 11:27–28; ヤコブの手紙 1:22; ヨハネの福音書 13:17"> ところが、イエスは人々にこう答えられた。「わたしの母、わたしの兄弟たちとは、神のことばを聞いて行なう人たちです。」</span>
<span className="v" id="v22" data-v="22" data-xref="マタイの福音書 8:23–27; マルコの福音書 4:35–41; マルコの福音書 6:45"> そのころのある日のこと、イエスは弟子たちといっしょに舟に乗り、「さあ、湖の向こう岸へ渡ろう。」と言われた。それで弟子たちは舟を出した。</span>
<span className="v" id="v23" data-v="23" data-xref="Psalms 93:3–4; Psalms 124:2–4; Psalms 148:8"> 舟で渡っている間にイエスはぐっすり眠ってしまわれた。ところが突風が湖に吹きおろして来たので、弟子たちは水をかぶって危険になった。</span>
<span className="v" id="v24" data-v="24" data-xref="Psalms 107:25–29; ルカの福音書 4:39; Psalms 104:6–9"> そこで、彼らは近寄って行ってイエスを起こし、「先生、先生。私たちはおぼれて死にそうです。」と言った。イエスは、起き上がって、風と荒波とをしかりつけられた。すると風も波も治まり、なぎになった。</span>
<span className="v" id="v25" data-v="25" data-xref="マタイの福音書 8:26; Proverbs 30:4; マルコの福音書 4:40–41"> イエスは彼らに、「あなたがたの信仰はどこにあるのです。」と言われた。弟子たちは驚き恐れて互いに言った。「風も水も、お命じになれば従うとは、いったいこの方はどういう方なのだろう。」</span>
<span className="v" id="v26" data-v="26" data-xref="マルコの福音書 5:1–20; マタイの福音書 8:28–34"> こうして彼らは、ガリラヤの向こう側のゲラサ人の地方に着いた。</span>
<span className="v" id="v27" data-v="27" data-xref="マルコの福音書 5:2–5; 1 Samuel 19:24; Numbers 19:16"> イエスが陸に上がられると、この町の者で悪霊につかれている男がイエスに出会った。彼は、長い間着物も着けず、家には住まないで、墓場に住んでいた。</span>
<span className="v" id="v28" data-v="28" data-xref="マタイの福音書 8:29; ペテロの手紙第二 2:4; マルコの福音書 5:6–8"> 彼はイエスを見ると、叫び声をあげ、御前にひれ伏して大声で言った。「いと高き神の子、イエスさま。いったい私に何をしようというのです。お願いです。どうか私を苦しめないでください。」</span>
<span className="v" id="v29" data-v="29" data-xref="マルコの福音書 5:3–5; ルカの福音書 9:39; テモテへの手紙第二 2:25–26"> それは、イエスが、汚れた霊に、この人から出て行け、と命じられたからである。汚れた霊が何回となくこの人を捕えたので、彼は鎖や足かせでつながれて看視されていたが、それでもそれらを断ち切っては悪霊によって荒野に追いやられていたのである。</span>
<span className="v" id="v30" data-v="30" data-xref="マタイの福音書 26:53; ルカの福音書 8:2; マタイの福音書 8:29"> イエスが、「何という名か。」とお尋ねになると、「レギオンです。」と答えた。悪霊が大ぜい彼にはいっていたからである。</span>
<span className="v" id="v31" data-v="31" data-xref="マタイの福音書 25:41; ピリピ人への手紙 2:10–11; Job 2:5"> 悪霊どもはイエスに、底知れぬ所に行け、とはお命じになりませんようにと願った。</span>
<span className="v" id="v32" data-v="32" data-xref="Isaiah 65:4; Isaiah 66:3; ヨハネの黙示録 20:7"> ちょうど、山のそのあたりに、おびただしい豚の群れが飼ってあったので、悪霊どもは、その豚にはいることを許してくださいと願った。イエスはそれを許された。</span>
<span className="v" id="v33" data-v="33" data-xref="ペテロの手紙第一 5:8; ヨハネの福音書 8:44; ルカの福音書 8:22–23"> 悪霊どもは、その人から出て、豚にはいった。すると、豚の群れはいきなりがけを駆け下って湖にはいり、おぼれ死んだ。</span>
<span className="v" id="v34" data-v="34" data-xref="マルコの福音書 5:14; マタイの福音書 8:33; マタイの福音書 28:11"> 飼っていた者たちは、この出来事を見て逃げ出し、町や村々でこの事を告げ知らせた。</span>
<span className="v" id="v35" data-v="35" data-xref="ルカの福音書 10:39; 使徒の働き 22:3; ヨハネの手紙第一 3:8"> 人々が、この出来事を見に来て、イエスのそばに来たところ、イエスの足もとに、悪霊の去った男が着物を着て、正気に返って、すわっていた。人々は恐ろしくなった。</span>
<span className="v" id="v36" data-v="36" data-xref="マタイの福音書 4:24"> 目撃者たちは、悪霊につかれていた人の救われた次第を、その人々に知らせた。</span>
<span className="v" id="v37" data-v="37" data-xref="使徒の働き 16:39; ルカの福音書 8:28; ルカの福音書 10:10–11"> ゲラサ地方の民衆はみな、すっかりおびえてしまい、イエスに自分たちのところから離れていただきたいと願った。そこで、イエスは舟に乗って帰られた。</span>
<span className="v" id="v38" data-v="38" data-xref="使徒の働き 9:13–16; マルコの福音書 5:18–20; Psalms 145:3–12"> そのとき、悪霊を追い出された人が、お供をしたいとしきりに願ったが、イエスはこう言って彼を帰された。</span>
<span className="v" id="v39" data-v="39" data-xref="ルカの福音書 17:15–18; テモテへの手紙第一 5:8; Deuteronomy 10:21"> 「家に帰って、神があなたにどんなに大きなことをしてくださったかを、話して聞かせなさい。」そこで彼は出て行って、イエスが自分にどんなに大きなことをしてくださったかを、町中に言い広めた。</span>
<span className="v" id="v40" data-v="40" data-xref="マタイの福音書 9:1; マルコの福音書 5:21; マルコの福音書 6:20"> さて、イエスが帰られると、群衆は喜んで迎えた。みなイエスを待ちわびていたからである。</span>
<span className="v" id="v41" data-v="41" data-xref="マルコの福音書 5:22–43; ルカの福音書 13:14; 使徒の働き 18:8"> するとそこに、ヤイロという人が来た。この人は会堂管理者であった。彼はイエスの足もとにひれ伏して自分の家に来ていただきたいと願った。</span>
<span className="v" id="v42" data-v="42" data-xref="ルカの福音書 7:12; ルカの福音書 8:45; Job 1:18–19"> 彼には十二歳ぐらいのひとり娘がいて、死にかけていたのである。イエスがお出かけになると、群衆がみもとに押し迫って来た。</span>
<span className="v" id="v43" data-v="43" data-xref="マルコの福音書 5:25–26; マタイの福音書 9:20–22; Leviticus 15:25–33"> ときに、十二年の間長血をわずらった女がいた。だれにも直してもらえなかったこの女は、</span>
<span className="v" id="v44" data-v="44" data-xref="マルコの福音書 5:27–28; Deuteronomy 22:12; 使徒の働き 19:12"> イエスのうしろに近寄って、イエスの着物のふさにさわった。すると、たちどころに出血が止まった。</span>
<span className="v" id="v45" data-v="45" data-xref="マルコの福音書 5:30–32; ルカの福音書 9:13; ルカの福音書 5:5"> イエスは、「わたしにさわったのは、だれですか。」と言われた。みな自分ではないと言ったので、ペテロは、「先生。この大ぜいの人が、ひしめき合って押しているのです。」と言った。</span>
<span className="v" id="v46" data-v="46" data-xref="ルカの福音書 6:19; ルカの福音書 5:17; ペテロの手紙第一 2:9"> しかし、イエスは、「だれかが、わたしにさわったのです。わたしから力が出て行くのを感じたのだから。」と言われた。</span>
<span className="v" id="v47" data-v="47" data-xref="マルコの福音書 5:33; ルカの福音書 17:15–16; コリント人への手紙第一 2:3"> 女は、隠しきれないと知って、震えながら進み出て、御前にひれ伏し、すべての民の前で、イエスにさわったわけと、たちどころにいやされた次第とを話した。</span>
<span className="v" id="v48" data-v="48" data-xref="ルカの福音書 7:50; マタイの福音書 9:22; ヘブル人への手紙 4:2"> そこで、イエスは彼女に言われた。「娘よ。あなたの信仰があなたを直したのです。安心して行きなさい。」</span>
<span className="v" id="v49" data-v="49" data-xref="マルコの福音書 5:35–43; Isaiah 7:12; ルカの福音書 7:6"> イエスがまだ話しておられるときに、会堂管理者の家から人が来て言った。「あなたのお嬢さんはなくなりました。もう、先生を煩わすことはありません。」</span>
<span className="v" id="v50" data-v="50" data-xref="ヨハネの福音書 11:40; ヨハネの福音書 11:25; マルコの福音書 5:36"> これを聞いて、イエスは答えられた。「恐れないで、ただ信じなさい。そうすれば、娘は直ります。」</span>
<span className="v" id="v51" data-v="51" data-xref="マルコの福音書 14:33; マタイの福音書 6:5–6; 1 Kings 17:19–23"> イエスは家にはいられたが、ペテロとヨハネとヤコブ、それに子どもの父と母のほかは、だれもいっしょにはいることをお許しにならなかった。</span>
<span className="v" id="v52" data-v="52" data-xref="ルカの福音書 23:27; ヨハネの福音書 11:4; Zechariah 12:10"> 人々はみな、娘のために泣き悲しんでいた。しかし、イエスは言われた。「泣かなくてもよい。死んだのではない。眠っているのです。」</span>
<span className="v" id="v53" data-v="53" data-xref="ルカの福音書 16:14; Isaiah 53:3; ヨハネの福音書 11:39"> 人々は、娘が死んだことを知っていたので、イエスをあざ笑っていた。</span>
<span className="v" id="v54" data-v="54" data-xref="Jeremiah 31:32; ヨハネの福音書 11:43; マルコの福音書 1:31"> しかしイエスは、娘の手を取って、叫んで言われた。「子どもよ。起きなさい。」</span>
<span className="v" id="v55" data-v="55" data-xref="ヨハネの福音書 11:44; 1 Kings 17:21–23; マルコの福音書 5:43"> すると、娘の霊が戻って、娘はただちに起き上がった。それでイエスは、娘に食事をさせるように言いつけられた。</span>
<span className="v" id="v56" data-v="56" data-xref="マタイの福音書 8:4; マタイの福音書 9:30; ルカの福音書 5:14"> 両親がひどく驚いていると、イエスは、この出来事をだれにも話さないように命じられた。</span>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マタイの福音書 21:23–27; ルカの福音書 19:47–48; 使徒の働き 6:12"> イエスは宮で民衆を教え、福音を宣べ伝えておられたが、ある日、祭司長、律法学者たちが、長老たちといっしょにイエスに立ち向かって、</span>
<span className="v" id="v2" data-v="2" data-xref="Exodus 2:14; マルコの福音書 11:28–33; ヨハネの福音書 2:18"> イエスに言った。「何の権威によって、これらのことをしておられるのですか。あなたにその権威を授けたのはだれですか。それを言ってください。」</span>
<span className="v" id="v3" data-v="3" data-xref="マタイの福音書 15:2–3; ルカの福音書 22:68; コロサイ人への手紙 4:6"> そこで答えて言われた。「わたしも一言尋ねますから、それに答えなさい。</span>
<span className="v" id="v4" data-v="4" data-xref="ルカの福音書 15:18; マタイの福音書 11:7–19; マタイの福音書 17:11–12"> ヨハネのバプテスマは、天から来たのですか、人から出たのですか。」</span>
<span className="v" id="v5" data-v="5" data-xref="ヨハネの福音書 1:34; ヨハネの福音書 1:15–18; ヨハネの福音書 1:30"> すると彼らは、こう言って、互いに論じ合った。「もし、天から、と言えば、それならなぜ、彼を信じなかったか、と言うだろう。</span>
<span className="v" id="v6" data-v="6" data-xref="マタイの福音書 21:26; マタイの福音書 11:9; ヨハネの福音書 10:41"> しかし、もし、人から、と言えば、民衆がみなで私たちを石で打ち殺すだろう。ヨハネを預言者と信じているのだから。」</span>
<span className="v" id="v7" data-v="7" data-xref="Isaiah 29:14; ペテロの手紙第二 3:3; Isaiah 41:28"> そこで、「どこからか知りません。」と答えた。</span>
<span className="v" id="v8" data-v="8" data-xref="Proverbs 26:4–5; マタイの福音書 21:27; マルコの福音書 11:33"> するとイエスは、「わたしも、何の権威によってこれらのことをするのか、あなたがたに話すまい。」と言われた。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="マタイの福音書 21:33–46; マルコの福音書 12:1–12; Isaiah 5:1–7"> また、イエスは、民衆にこのようなたとえを話された。<br />「ある人がぶどう園を造り、それを農夫たちに貸して、長い旅に出た。</span>
<span className="v" id="v10" data-v="10" data-xref="2 Chronicles 36:15–16; Nehemiah 9:26; マタイの福音書 21:34–36"> そして季節になったので、ぶどう園の収穫の分けまえをもらうために、農夫たちのところへひとりのしもべを遣わした。ところが、農夫たちは、そのしもべを袋だたきにし、何も持たせないで送り帰した。</span>
<span className="v" id="v11" data-v="11" data-xref="Hosea 10:1; ヘブル人への手紙 11:36–37; テサロニケ人への手紙第一 2:2"> そこで、別のしもべを遣わしたが、彼らは、そのしもべも袋だたきにし、はずかしめたうえで、何も持たせないで送り帰した。</span>
<span className="v" id="v12" data-v="12"> 彼はさらに三人目のしもべをやったが、彼らは、このしもべにも傷を負わせて追い出した。</span>
<span className="v" id="v13" data-v="13" data-xref="マタイの福音書 3:17; ヨハネの福音書 3:16–17; Jeremiah 36:7"> ぶどう園の主人は言った。『どうしたものか。よし、愛する息子を送ろう。彼らも、この子はたぶん敬ってくれるだろう。』</span>
<span className="v" id="v14" data-v="14" data-xref="ローマ人への手紙 8:17; ヘブル人への手紙 1:2; 使徒の働き 2:23"> ところが、農夫たちはその息子を見て、議論しながら言った。『あれはあと取りだ。あれを殺そうではないか。そうすれば、財産はこちらのものだ。』</span>
<span className="v" id="v15" data-v="15" data-xref="ヘブル人への手紙 13:12; マルコの福音書 12:6–9; マタイの福音書 21:37–40"> そして、彼をぶどう園の外に追い出して、殺してしまった。<br />こうなると、ぶどう園の主人は、どうするでしょう。</span>
<span className="v" id="v16" data-v="16" data-xref="ルカの福音書 19:27; 使徒の働き 13:46; マタイの福音書 21:41"> 彼は戻って来て、この農夫どもを打ち滅ぼし、ぶどう園をほかの人たちに与えてしまいます。」これを聞いた民衆は、「そんなことがあってはなりません。」と言った。</span>
<span className="v" id="v17" data-v="17" data-xref="Psalms 118:22; Isaiah 28:16; 使徒の働き 4:11"> イエスは、彼らを見つめて言われた。「では、<br />『家を建てる者たちの見捨てた石、<br />それが礎の石となった。』<br />と書いてあるのは、何のことでしょう。</span>
<span className="v" id="v18" data-v="18" data-xref="Isaiah 8:14–15; Zechariah 12:3; Daniel 2:44–45"> この石の上に落ちれば、だれでも粉々に砕け、またこの石が人の上に落ちれば、その人を粉みじんに飛び散らしてしまうのです。」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="ルカの福音書 19:47–48; ルカの福音書 20:14; マタイの福音書 21:45–46"> 律法学者、祭司長たちは、イエスが自分たちをさしてこのたとえを話されたと気づいたので、この際イエスに手をかけて捕えようとしたが、やはり民衆を恐れた。</span>
<span className="v" id="v20" data-v="20" data-xref="ルカの福音書 11:54; マタイの福音書 22:15–22; マタイの福音書 27:2"> さて、機会をねらっていた彼らは、義人を装った間者を送り、イエスのことばを取り上げて、総督の支配と権威にイエスを引き渡そう、と計った。</span>
<span className="v" id="v21" data-v="21" data-xref="テサロニケ人への手紙第一 2:4–5; マタイの福音書 26:49–50; マタイの福音書 22:16"> その間者たちは、イエスに質問して言った。「先生。私たちは、あなたがお話しになり、お教えになることは正しく、またあなたは分け隔てなどせず、真理に基づいて神の道を教えておられることを知っています。</span>
<span className="v" id="v22" data-v="22" data-xref="Nehemiah 9:37; マルコの福音書 12:14–17; 使徒の働き 5:37"> ところで、私たちが、カイザルに税金を納めることは、律法にかなっていることでしょうか。かなっていないことでしょうか。」</span>
<span className="v" id="v23" data-v="23" data-xref="マタイの福音書 22:18; コリント人への手紙第一 3:19; ルカの福音書 5:22"> イエスはそのたくらみを見抜いて彼らに言われた。</span>
<span className="v" id="v24" data-v="24" data-xref="マタイの福音書 18:28; 使徒の働き 11:28; 使徒の働き 26:32"> 「デナリ銀貨をわたしに見せなさい。これはだれの肖像ですか。だれの銘ですか。」彼らは、「カイザルのです。」と言った。</span>
<span className="v" id="v25" data-v="25" data-xref="ローマ人への手紙 13:6–7; マルコの福音書 12:17; ペテロの手紙第一 2:13–17"> すると彼らに言われた。「では、カイザルのものはカイザルに返しなさい。そして神のものは神に返しなさい。」</span>
<span className="v" id="v26" data-v="26" data-xref="ルカの福音書 20:20; Proverbs 26:4–5; テトスへの手紙 1:10"> 彼らは、民衆の前でイエスのことばじりをつかむことができず、お答えに驚嘆して黙ってしまった。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="使徒の働き 4:1–2; コリント人への手紙第一 15:12; マルコの福音書 12:18–27"> ところが、復活があることを否定するサドカイ人のある者たちが、イエスのところに来て、質問して、</span>
<span className="v" id="v28" data-v="28" data-xref="Deuteronomy 25:5–10; Genesis 38:8; Genesis 38:11"> こう言った。「先生。モーセは私たちのためにこう書いています。『もし、ある人の兄が妻をめとって死に、しかも子がなかったばあいは、その弟はその女を妻にして、兄のための子をもうけなければならない。』</span>
<span className="v" id="v29" data-v="29" data-xref="Leviticus 20:20; Jeremiah 22:30"> ところで、七人の兄弟がいました。長男は妻をめとりましたが、子どもがなくて死にました。</span>
<span className="v" id="v30" data-v="30"> 次男も、</span>
<span className="v" id="v31" data-v="31"> 三男もその女をめとり、七人とも同じようにして、子どもを残さずに死にました。</span>
<span className="v" id="v32" data-v="32" data-xref="Ecclesiastes 1:4; Ecclesiastes 9:5; ヘブル人への手紙 9:27"> あとで、その女も死にました。</span>
<span className="v" id="v33" data-v="33" data-xref="マタイの福音書 22:24–28; マルコの福音書 12:19–23"> すると復活の際、その女はだれの妻になるでしょうか。七人ともその女を妻としたのですが。」</span>
<span className="v" id="v34" data-v="34" data-xref="ルカの福音書 16:8; ルカの福音書 17:27; ヘブル人への手紙 13:4"> イエスは彼らに言われた。「この世の子らは、めとったり、とついだりするが、</span>
<span className="v" id="v35" data-v="35" data-xref="テサロニケ人への手紙第二 1:5; ヨハネの福音書 5:29; Daniel 12:2–3"> 次の世にはいるのにふさわしく、死人の中から復活するのにふさわしい、と認められる人たちは、めとることも、とつぐこともありません。</span>
<span className="v" id="v36" data-v="36" data-xref="ヨハネの黙示録 21:4; ピリピ人への手紙 3:21; マタイの福音書 22:30"> 彼らはもう死ぬことができないからです。彼らは御使いのようであり、また、復活の子として神の子どもだからです。</span>
<span className="v" id="v37" data-v="37" data-xref="Exodus 3:2–6; マルコの福音書 12:26–27; 使徒の働き 7:30–32"> それに、死人がよみがえることについては、モーセも柴の個所で、主を、『アブラハムの神、イサクの神、ヤコブの神。』と呼んで、このことを示しました。</span>
<span className="v" id="v38" data-v="38" data-xref="ヨハネの福音書 11:25–26; コロサイ人への手紙 3:3–4; ローマ人への手紙 6:10–11"> 神は死んだ者の神ではありません。生きている者の神です。というのは、神に対しては、みなが生きているからです。」</span>
<span className="v" id="v39" data-v="39" data-xref="使徒の働き 23:9; マルコの福音書 12:28–34; マタイの福音書 22:34–40"> 律法学者のうちのある者たちが答えて、「先生。りっぱなお答えです。」と言った。</span>
<span className="v" id="v40" data-v="40" data-xref="マタイの福音書 22:46; マルコの福音書 12:34; Proverbs 26:5"> 彼らはもうそれ以上何も質問する勇気がなかった。</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="マルコの福音書 12:35–37; マタイの福音書 1:1; マタイの福音書 22:41–45"> すると、イエスが彼らに言われた。「どうして人々は、キリストをダビデの子と言うのですか。</span>
<span className="v" id="v42" data-v="42" data-xref="Psalms 110:1; 使徒の働き 2:34–35; ヘブル人への手紙 1:13"> ダビデ自身が詩篇の中でこう言っています。<br />『主は私の主に言われた。</span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="ルカの福音書 19:27; Psalms 110:1; ヨハネの黙示録 19:14–21"> 「わたしが、あなたの敵を<br />あなたの足台とする時まで、<br />わたしの右の座に着いていなさい。」』</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="ヨハネの黙示録 22:16; ルカの福音書 1:31–35; マタイの福音書 1:23"> こういうわけで、ダビデがキリストを主と呼んでいるのに、どうしてキリストがダビデの子でしょう。」</span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="マタイの福音書 15:10; マルコの福音書 12:38–39; マルコの福音書 8:34"> また、民衆がみな耳を傾けているときに、イエスは弟子たちにこう言われた。</span>
<span className="v" id="v46" data-v="46" data-xref="ルカの福音書 11:43; マルコの福音書 12:38–39; ルカの福音書 14:7"> 「律法学者たちには気をつけなさい。彼らは、長い衣をまとって歩き回ったり、広場であいさつされたりすることが好きで、また会堂の上席や宴会の上座が好きです。</span>
<span className="v" id="v47" data-v="47" data-xref="マルコの福音書 12:40; ヤコブの手紙 3:1; テトスへの手紙 1:16"> また、やもめの家を食いつぶし、見えを飾るために長い祈りをします。こういう人たちは人一倍きびしい罰を受けるのです。」</span>
</div>

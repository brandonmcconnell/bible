<span className="v" id="v1" data-v="1" data-xref="コロサイ人への手紙 3:12; ヨハネの手紙第一 4:12; ヨハネの手紙第一 4:7–8"> こういうわけですから、もしキリストにあって励ましがあり、愛の慰めがあり、御霊の交わりがあり、愛情とあわれみがあるなら、</span>
<span className="v" id="v2" data-v="2" data-xref="ローマ人への手紙 12:16; ペテロの手紙第一 3:8–9; コリント人への手紙第一 1:10"> 私の喜びが満たされるように、あなたがたは一致を保ち、同じ愛の心を持ち、心を合わせ、志を一つにしてください。</span>
<span className="v" id="v3" data-v="3" data-xref="ローマ人への手紙 12:10; ガラテヤ人への手紙 5:26; エペソ人への手紙 5:21"> 何事でも自己中心や虚栄からすることなく、へりくだって、互いに人を自分よりもすぐれた者と思いなさい。</span>
<span className="v" id="v4" data-v="4" data-xref="コリント人への手紙第一 10:24; ローマ人への手紙 15:1; ヤコブの手紙 2:8"> 自分のことだけではなく、他の人のことも顧みなさい。</span>
<span className="v" id="v5" data-v="5" data-xref="ヨハネの手紙第一 2:6; マタイの福音書 11:29; ペテロの手紙第一 2:21"> あなたがたの間では、そのような心構えでいなさい。それはキリスト・イエスのうちにも見られるものです。</span>
<span className="v" id="v6" data-v="6" data-xref="ヨハネの福音書 5:18; コリント人への手紙第二 4:4; ヘブル人への手紙 1:3"> キリストは、神の御姿であられる方なのに、神のあり方を捨てることができないとは考えないで、</span>
<span className="v" id="v7" data-v="7" data-xref="コリント人への手紙第二 8:9; マタイの福音書 20:28; ヨハネの福音書 1:14"> ご自分を無にして、仕える者の姿をとり、人間と同じようになられたのです。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨハネの福音書 10:18; ヘブル人への手紙 12:2; ローマ人への手紙 5:19"> キリストは人間と同じようなかたちになり、自分を卑しくし、死にまで従い、実に十字架の死にまでも従われたのです。</span>
<span className="v" id="v9" data-v="9" data-xref="ヨハネの黙示録 19:16; マタイの福音書 28:18; ペテロの手紙第一 3:22"> それゆえ、神は、キリストを高く上げて、すべての名にまさる名をお与えになりました。</span>
<span className="v" id="v10" data-v="10" data-xref="Isaiah 45:23–25; マタイの福音書 28:18; ヨハネの黙示録 5:13–14"> それは、イエスの御名によって、天にあるもの、地にあるもの、地の下にあるもののすべてが、ひざをかがめ、</span>
<span className="v" id="v11" data-v="11" data-xref="ヨハネの手紙第一 4:15; ローマ人への手紙 14:11; ヨハネの福音書 13:13"> すべての口が、「イエス・キリストは主である。」と告白して、父なる神がほめたたえられるためです。</span>
<span className="v" id="v12" data-v="12" data-xref="ペテロの手紙第二 1:5–10; ルカの福音書 13:23–24; コリント人への手紙第一 15:58"> そういうわけですから、愛する人たち、いつも従順であったように、私がいるときだけでなく、私のいない今はなおさら、恐れおののいて自分の救いを達成してください。</span>
<span className="v" id="v13" data-v="13" data-xref="ヘブル人への手紙 13:21; コリント人への手紙第二 3:5; テモテへの手紙第二 1:9"> 神は、みこころのままに、あなたがたのうちに働いて志を立てさせ、事を行なわせてくださるのです。</span>
<span className="v" id="v14" data-v="14" data-xref="ペテロの手紙第一 4:9; コリント人への手紙第一 10:10; ピリピ人への手紙 2:3"> すべてのことを、つぶやかず、疑わずに行ないなさい。</span>
<span className="v" id="v15" data-v="15" data-xref="マタイの福音書 5:14–16; ペテロの手紙第一 2:12; マタイの福音書 5:45"> それは、あなたがたが、非難されるところのない純真な者となり、また、曲がった邪悪な世代の中にあって傷のない神の子どもとなり、</span>
<span className="v" id="v16" data-v="16" data-xref="コリント人への手紙第一 9:26; ガラテヤ人への手紙 2:2; ヨハネの手紙第一 1:1"> いのちのことばをしっかり握って、彼らの間で世の光として輝くためです。そうすれば、私は、自分の努力したことがむだではなく、苦労したこともむだでなかったことを、キリストの日に誇ることができます。</span>
<span className="v" id="v17" data-v="17" data-xref="テモテへの手紙第二 4:6; ローマ人への手紙 15:16; ヘブル人への手紙 13:15–16"> たとい私が、あなたがたの信仰の供え物と礼拝とともに、注ぎの供え物となっても、私は喜びます。あなたがたすべてとともに喜びます。</span>
<span className="v" id="v18" data-v="18" data-xref="ヤコブの手紙 1:2–4; ピリピ人への手紙 4:4; ピリピ人への手紙 3:1"> あなたがたも同じように喜んでください。私といっしょに喜んでください。</span>
<span className="v" id="v19" data-v="19" data-xref="コリント人への手紙第一 4:17; テサロニケ人への手紙第一 3:6–8; テサロニケ人への手紙第一 3:2"> しかし、私もあなたがたのことを知って励ましを受けたいので、早くテモテをあなたがたのところに送りたいと、主イエスにあって望んでいます。</span>
<span className="v" id="v20" data-v="20" data-xref="ピリピ人への手紙 2:2; コリント人への手紙第一 16:10; ピリピ人への手紙 2:22"> テモテのように私と同じ心になって、真実にあなたがたのことを心配している者は、ほかにだれもいないからです。</span>
<span className="v" id="v21" data-v="21" data-xref="コリント人への手紙第一 10:24; マタイの福音書 16:24; ピリピ人への手紙 2:4"> だれもみな自分自身のことを求めるだけで、キリスト・イエスのことを求めてはいません。</span>
<span className="v" id="v22" data-v="22" data-xref="コリント人への手紙第一 4:17; コリント人への手紙第二 2:9; テモテへの手紙第二 1:2"> しかし、テモテのりっぱな働きぶりは、あなたがたの知っているところです。子が父に仕えるようにして、彼は私といっしょに福音に奉仕して来ました。</span>
<span className="v" id="v23" data-v="23" data-xref="1 Samuel 22:3; ピリピ人への手紙 2:19"> ですから、私のことがどうなるかがわかりしだい、彼を遣わしたいと望んでいます。</span>
<span className="v" id="v24" data-v="24" data-xref="ヨハネの手紙第三 1:14; ピレモンへの手紙 1:22; ピリピ人への手紙 1:25–26"> しかし私自身も近いうちに行けることと、主にあって確信しています。</span>
<span className="v" id="v25" data-v="25" data-xref="ピリピ人への手紙 4:18; ピレモンへの手紙 1:1–2; ピリピ人への手紙 4:3"> しかし、私の兄弟、同労者、戦友、またあなたがたの使者として私の窮乏のときに仕えてくれた人エパフロデトは、あなたがたのところに送らねばならないと思っています。</span>
<span className="v" id="v26" data-v="26" data-xref="ローマ人への手紙 12:15; Proverbs 12:25; エペソ人への手紙 3:13"> 彼は、あなたがたすべてを慕い求めており、また、自分の病気のことがあなたがたに伝わったことを気にしているからです。</span>
<span className="v" id="v27" data-v="27" data-xref="Psalms 34:19; ピリピ人への手紙 2:30; Psalms 103:3–4"> ほんとうに、彼は死ぬほどの病気にかかりましたが、神は彼をあわれんでくださいました。彼ばかりでなく私をもあわれんで、私にとって悲しみに悲しみが重なることのないようにしてくださいました。</span>
<span className="v" id="v28" data-v="28" data-xref="ヨハネの福音書 16:22; テモテへの手紙第二 1:4; ピリピ人への手紙 2:26–27"> そこで、私は大急ぎで彼を送ります。あなたがたが彼に再び会って喜び、私も心配が少なくなるためです。</span>
<span className="v" id="v29" data-v="29" data-xref="テサロニケ人への手紙第一 5:12; コリント人への手紙第一 16:18; テモテへの手紙第一 5:17"> ですから、喜びにあふれて、主にあって、彼を迎えてください。また、彼のような人々には尊敬を払いなさい。</span>
<span className="v" id="v30" data-v="30" data-xref="コリント人への手紙第一 16:17; 使徒の働き 20:24; ピリピ人への手紙 4:10"> なぜなら、彼は、キリストの仕事のために、いのちの危険を冒して死ぬばかりになったからです。彼は私に対して、あなたがたが私に仕えることのできなかった分を果たそうとしたのです。</span>

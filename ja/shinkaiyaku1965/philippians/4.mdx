<span className="v" id="v1" data-v="1" data-xref="ピリピ人への手紙 1:27; コリント人への手紙第一 16:13; Psalms 27:14"> そういうわけですから、私の愛し慕う兄弟たち、私の喜び、冠よ。どうか、このように主にあってしっかりと立ってください。私の愛する人たち。</span>
<span className="v" id="v2" data-v="2" data-xref="ヘブル人への手紙 12:14; コリント人への手紙第一 1:10; マルコの福音書 9:50"> ユウオデヤに勧め、スントケに勧めます。あなたがたは、主にあって一致してください。</span>
<span className="v" id="v3" data-v="3" data-xref="ヨハネの黙示録 3:5; ヨハネの黙示録 13:8; ルカの福音書 10:20"> ほんとうに、真の協力者よ。あなたにも頼みます。彼女たちを助けてやってください。この人たちは、いのちの書に名のしるされているクレメンスや、そのほかの私の同労者たちとともに、福音を広めることで私に協力して戦ったのです。</span>
<span className="v" id="v4" data-v="4" data-xref="テサロニケ人への手紙第一 5:16–18; ローマ人への手紙 12:12; ヤコブの手紙 1:2–4"> いつも主にあって喜びなさい。もう一度言います。喜びなさい。</span>
<span className="v" id="v5" data-v="5" data-xref="ヤコブの手紙 5:8–9; マタイの福音書 6:25; テトスへの手紙 3:2"> あなたがたの寛容な心を、すべての人に知らせなさい。主は近いのです。</span>
<span className="v" id="v6" data-v="6" data-xref="Proverbs 3:5–6; ペテロの手紙第一 5:7; マタイの福音書 6:25–33"> 何も思い煩わないで、あらゆるばあいに、感謝をもってささげる祈りと願いによって、あなたがたの願い事を神に知っていただきなさい。</span>
<span className="v" id="v7" data-v="7" data-xref="ヨハネの福音書 14:27; Isaiah 26:3; テサロニケ人への手紙第二 3:16"> そうすれば、人のすべての考えにまさる神の平安が、あなたがたの心と思いをキリスト・イエスにあって守ってくれます。</span>
<span className="v" id="v8" data-v="8" data-xref="ヤコブの手紙 3:17; テトスへの手紙 2:7; ローマ人への手紙 12:9–21"> 最後に、兄弟たち。すべての真実なこと、すべての誉れあること、すべての正しいこと、すべてのきよいこと、すべての愛すべきこと、すべての評判の良いこと、そのほか徳と言われること、称賛に値することがあるならば、そのようなことに心を留めなさい。</span>
<span className="v" id="v9" data-v="9" data-xref="ヤコブの手紙 1:22; ピリピ人への手紙 3:17; テサロニケ人への手紙第一 4:1–8"> あなたがたが私から学び、受け、聞き、また見たことを実行しなさい。そうすれば、平和の神があなたがたとともにいてくださいます。</span>
<span className="v" id="v10" data-v="10" data-xref="コリント人への手紙第二 11:9; ガラテヤ人への手紙 6:6; コリント人への手紙第二 7:6–7"> 私のことを心配してくれるあなたがたの心が、今ついによみがえって来たことを、私は主にあって非常に喜んでいます。あなたがたは心にかけてはいたのですが、機会がなかったのです。</span>
<span className="v" id="v11" data-v="11" data-xref="テモテへの手紙第一 6:6–9; ヘブル人への手紙 13:5–6; マタイの福音書 6:31–34"> 乏しいからこう言うのではありません。私は、どんな境遇にあっても満ち足りることを学びました。</span>
<span className="v" id="v12" data-v="12" data-xref="マタイの福音書 11:29; コリント人への手紙第二 12:7–10; コリント人への手紙第二 11:27"> 私は、貧しさの中にいる道も知っており、豊かさの中にいる道も知っています。また、飽くことにも飢えることにも、富むことにも乏しいことにも、あらゆる境遇に対処する秘訣を心得ています。</span>
<span className="v" id="v13" data-v="13" data-xref="Isaiah 41:10; コリント人への手紙第二 12:9–10; コロサイ人への手紙 1:11"> 私は、私を強くしてくださる方によって、どんなことでもできるのです。</span>
<span className="v" id="v14" data-v="14" data-xref="ヘブル人への手紙 13:16; ピリピ人への手紙 1:7; ヘブル人への手紙 10:34"> それにしても、あなたがたは、よく私と困難を分け合ってくれました。</span>
<span className="v" id="v15" data-v="15" data-xref="ピリピ人への手紙 1:5; コリント人への手紙第二 11:8–12; 使徒の働き 16:40–5"> ピリピの人たち。あなたがたも知っているとおり、私が福音を宣べ伝え始めたころ、マケドニヤを離れて行ったときには、私の働きのために、物をやり取りしてくれた教会は、あなたがたのほかには一つもありませんでした。</span>
<span className="v" id="v16" data-v="16" data-xref="テサロニケ人への手紙第一 2:9; 使徒の働き 17:1; テサロニケ人への手紙第一 2:18"> テサロニケにいたときでさえ、あなたがたは一度ならず二度までも物を送って、私の乏しさを補ってくれました。</span>
<span className="v" id="v17" data-v="17" data-xref="テトスへの手紙 3:14; ヘブル人への手紙 6:10; コリント人への手紙第二 9:9–13"> 私は贈り物を求めているのではありません。私のほしいのは、あなたがたの収支を償わせて余りある霊的祝福なのです。</span>
<span className="v" id="v18" data-v="18" data-xref="ヘブル人への手紙 13:16; ピリピ人への手紙 4:12; コリント人への手紙第二 9:12"> 私は、すべての物を受けて、満ちあふれています。エパフロデトからあなたがたの贈り物を受けたので、満ち足りています。それは香ばしいかおりであって、神が喜んで受けてくださる供え物です。</span>
<span className="v" id="v19" data-v="19" data-xref="コリント人への手紙第二 9:8–11; Psalms 84:11; ペテロの手紙第一 5:10"> また、私の神は、キリスト・イエスにあるご自身の栄光の富をもって、あなたがたの必要をすべて満たしてくださいます。</span>
<span className="v" id="v20" data-v="20" data-xref="ローマ人への手紙 11:36; Psalms 115:1; ヨハネの黙示録 14:7"> どうか、私たちの父なる神に御栄えがとこしえにありますように。アーメン。</span>
<span className="v" id="v21" data-v="21" data-xref="ガラテヤ人への手紙 1:2; ピレモンへの手紙 1:23–24; コロサイ人への手紙 4:10–14"> キリスト・イエスにある聖徒のひとりひとりに、よろしく伝えてください。私といっしょにいる兄弟たちが、あなたがたによろしくと言っています。</span>
<span className="v" id="v22" data-v="22" data-xref="ピリピ人への手紙 1:13; コリント人への手紙第二 13:13; ローマ人への手紙 16:16"> 聖徒たち全員が、そして特に、カイザルの家に属する人々が、よろしくと言っています。</span>
<span className="v" id="v23" data-v="23" data-xref="コリント人への手紙第二 13:14; ローマ人への手紙 16:20; ローマ人への手紙 16:23"> どうか、主イエス・キリストの恵みが、あなたがたの霊とともにありますように。</span>

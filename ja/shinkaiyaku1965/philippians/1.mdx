<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="コリント人への手紙第二 1:1; 使徒の働き 16:12–15; ローマ人への手紙 1:1"> キリスト・イエスのしもべであるパウロとテモテから、ピリピにいるキリスト・イエスにあるすべての聖徒たち、また監督と執事たちへ。</span>
<span className="v" id="v2" data-v="2" data-xref="ローマ人への手紙 1:7; コリント人への手紙第二 1:2; ペテロの手紙第一 1:2"> どうか、私たちの父なる神と主イエス・キリストから、恵みと平安があなたがたの上にありますように。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="コリント人への手紙第一 1:4; テサロニケ人への手紙第一 1:2–3; ピレモンへの手紙 1:4–5"> 私は、あなたがたのことを思うごとに私の神に感謝し、</span>
<span className="v" id="v4" data-v="4" data-xref="テサロニケ人への手紙第一 1:2; ローマ人への手紙 1:9; ヨハネの手紙第二 1:4"> あなたがたすべてのために祈るごとに、いつも喜びをもって祈り、</span>
<span className="v" id="v5" data-v="5" data-xref="ピリピ人への手紙 4:14–15; ピリピ人への手紙 1:7; ヘブル人への手紙 3:14"> あなたがたが、最初の日から今日まで、福音を広めることにあずかって来たことを感謝しています。</span>
<span className="v" id="v6" data-v="6" data-xref="テサロニケ人への手紙第一 5:23–24; ピリピ人への手紙 2:13; エペソ人への手紙 4:12"> あなたがたのうちに良い働きを始められた方は、キリスト・イエスの日が来るまでにそれを完成させてくださることを私は堅く信じているのです。</span>
<span className="v" id="v7" data-v="7" data-xref="コリント人への手紙第二 7:3; ピリピ人への手紙 1:5; コロサイ人への手紙 4:18"> 私があなたがたすべてについてこのように考えるのは正しいのです。あなたがたはみな、私が投獄されているときも、福音を弁明し立証しているときも、私とともに恵みにあずかった人々であり、私は、そのようなあなたがたを、心に覚えているからです。</span>
<span className="v" id="v8" data-v="8" data-xref="ピリピ人への手紙 4:1; ローマ人への手紙 1:9; テモテへの手紙第二 1:4"> 私が、キリスト・イエスの愛の心をもって、どんなにあなたがたすべてを慕っているか、そのあかしをしてくださるのは神です。</span>
<span className="v" id="v9" data-v="9" data-xref="テサロニケ人への手紙第一 3:12; コロサイ人への手紙 1:9; ペテロの手紙第二 1:5–6"> 私は祈っています。あなたがたの愛が真の知識とあらゆる識別力によって、いよいよ豊かになり、</span>
<span className="v" id="v10" data-v="10" data-xref="ローマ人への手紙 12:2; テサロニケ人への手紙第一 3:13; テサロニケ人への手紙第一 5:23"> あなたがたが、真にすぐれたものを見分けることができるようになりますように。またあなたがたが、キリストの日には純真で非難されるところがなく、</span>
<span className="v" id="v11" data-v="11" data-xref="ヘブル人への手紙 12:11; ヨハネの福音書 15:8; ヨハネの福音書 15:4–5"> イエス・キリストによって与えられる義の実に満たされている者となり、神の御栄えと誉れが現わされますように。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="テモテへの手紙第二 2:9; ローマ人への手紙 8:28; 使徒の働き 11:19–21"> さて、兄弟たち。私の身に起こったことが、かえって福音を前進させることになったのを知ってもらいたいと思います。</span>
<span className="v" id="v13" data-v="13" data-xref="テモテへの手紙第二 2:9; エペソ人への手紙 3:1; ピリピ人への手紙 1:7"> 私がキリストのゆえに投獄されている、ということは、親衛隊の全員と、そのほかのすべての人にも明らかになり、</span>
<span className="v" id="v14" data-v="14" data-xref="エペソ人への手紙 6:19–20; テサロニケ人への手紙第一 2:2; ルカの福音書 1:74"> また兄弟たちの大多数は、私が投獄されたことにより、主にあって確信を与えられ、恐れることなく、ますます大胆に神のことばを語るようになりました。</span>
<span className="v" id="v15" data-v="15" data-xref="ローマ人への手紙 16:17–18; ピリピ人への手紙 2:3; コリント人への手紙第二 11:13"> 人々の中にはねたみや争いをもってキリストを宣べ伝える者もいますが、善意をもってする者もいます。</span>
<span className="v" id="v16" data-v="16" data-xref="コリント人への手紙第二 2:17; コリント人への手紙第二 4:1–2; Psalms 69:26"> 一方の人たちは愛をもってキリストを伝え、私が福音を弁証するために立てられていることを認めていますが、</span>
<span className="v" id="v17" data-v="17" data-xref="テモテへの手紙第二 1:11–12; ピリピ人への手紙 2:3; ピリピ人への手紙 1:7"> 他の人たちは純真な動機からではなく、党派心をもって、キリストを宣べ伝えており、投獄されている私をさらに苦しめるつもりなのです。</span>
<span className="v" id="v18" data-v="18" data-xref="ルカの福音書 9:50; マルコの福音書 9:38–40; コリント人への手紙第一 15:11"> すると、どういうことになりますか。つまり、見せかけであろうとも、真実であろうとも、あらゆるしかたで、キリストが宣べ伝えられているのであって、このことを私は喜んでいます。そうです、今からも喜ぶことでしょう。</span>
<span className="v" id="v19" data-v="19" data-xref="ローマ人への手紙 8:28; 使徒の働き 16:7; コリント人への手紙第二 1:11"> というわけは、あなたがたの祈りとイエス・キリストの御霊の助けによって、このことが私の救いとなることを私は知っているからです。</span>
<span className="v" id="v20" data-v="20" data-xref="ペテロの手紙第一 4:16; コリント人への手紙第一 6:20; Isaiah 54:4"> それは、私がどういうばあいにも恥じることなく、いつものように今も大胆に語って、生きるにしても、死ぬにしても、私の身によって、キリストのすばらしさが現わされることを求める私の切なる願いと望みにかなっているのです。</span>
<span className="v" id="v21" data-v="21" data-xref="ガラテヤ人への手紙 2:20; コリント人への手紙第二 5:8; コリント人への手紙第二 5:1"> 私にとっては、生きることはキリスト、死ぬこともまた益です。</span>
<span className="v" id="v22" data-v="22" data-xref="ペテロの手紙第一 4:2; ガラテヤ人への手紙 2:20; ピリピ人への手紙 1:24"> しかし、もしこの肉体のいのちが続くとしたら、私の働きが豊かな実を結ぶことになるので、どちらを選んだらよいのか、私にはわかりません。</span>
<span className="v" id="v23" data-v="23" data-xref="コリント人への手紙第二 5:8; Psalms 17:15; ヨハネの黙示録 14:13"> 私は、その二つのものの間に板ばさみとなっています。私の願いは、世を去ってキリストとともにいることです。実はそのほうが、はるかにまさっています。</span>
<span className="v" id="v24" data-v="24" data-xref="ヨハネの福音書 16:7; ピリピ人への手紙 1:22; ピリピ人への手紙 1:25–26"> しかし、この肉体にとどまることが、あなたがたのためには、もっと必要です。</span>
<span className="v" id="v25" data-v="25" data-xref="ピリピ人への手紙 2:24; コリント人への手紙第二 1:24; エペソ人への手紙 4:11–13"> 私はこのことを確信していますから、あなたがたの信仰の進歩と喜びとのために、私が生きながらえて、あなたがたすべてといっしょにいるようになることを知っています。</span>
<span className="v" id="v26" data-v="26" data-xref="コリント人への手紙第二 1:14; コリント人への手紙第二 5:12; ピリピ人への手紙 3:3"> そうなれば、私はもう一度あなたがたのところに行けるので、私のことに関するあなたがたの誇りは、キリスト・イエスにあって増し加わるでしょう。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="エペソ人への手紙 4:1; コリント人への手紙第一 16:13–14; コリント人への手紙第一 1:10"> ただ、キリストの福音にふさわしく生活しなさい。そうすれば、私が行ってあなたがたに会うにしても、また離れているにしても、私はあなたがたについて、こう聞くことができるでしょう。あなたがたは霊を一つにしてしっかりと立ち、心を一つにして福音の信仰のために、ともに奮闘しており、</span>
<span className="v" id="v28" data-v="28" data-xref="テモテへの手紙第二 1:7–8; テサロニケ人への手紙第二 1:5–6; マタイの福音書 10:28"> また、どんなことがあっても、反対者たちに驚かされることはないと。それは、彼らにとっては滅びのしるしであり、あなたがたにとっては救いのしるしです。これは神から出たことです。</span>
<span className="v" id="v29" data-v="29" data-xref="ヤコブの手紙 1:2; ペテロの手紙第一 4:13; 使徒の働き 5:41"> あなたがたは、キリストのために、キリストを信じる信仰だけでなく、キリストのための苦しみをも賜わったのです。</span>
<span className="v" id="v30" data-v="30" data-xref="テサロニケ人への手紙第一 2:2; 使徒の働き 16:19–40; テモテへの手紙第二 4:7"> あなたがたは、私について先に見たこと、また、私についていま聞いているのと同じ戦いを経験しているのです。</span>
</div>

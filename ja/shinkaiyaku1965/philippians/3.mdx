<span className="v" id="v1" data-v="1" data-xref="ローマ人への手紙 5:11; ピリピ人への手紙 4:4; ヤコブの手紙 1:2"> 最後に、私の兄弟たち。主にあって喜びなさい。前と同じことを書きますが、これは、私には煩わしいことではなく、あなたがたの安全のためにもなることです。</span>
<span className="v" id="v2" data-v="2" data-xref="コリント人への手紙第二 11:13; テトスへの手紙 1:16; ヨハネの黙示録 22:15"> どうか犬に気をつけてください。悪い働き人に気をつけてください。肉体だけの割礼の者に気をつけてください。</span>
<span className="v" id="v3" data-v="3" data-xref="コロサイ人への手紙 2:11; Deuteronomy 30:6; ローマ人への手紙 7:6"> 神の御霊によって礼拝をし、キリスト・イエスを誇り、人間的なものを頼みにしない私たちのほうこそ、割礼の者なのです。</span>
<span className="v" id="v4" data-v="4" data-xref="コリント人への手紙第二 11:18–22"> ただし、私は、人間的なものにおいても頼むところがあります。もし、ほかの人が人間的なものに頼むところがあると思うなら、私は、それ以上です。</span>
<span className="v" id="v5" data-v="5" data-xref="コリント人への手紙第二 11:22; ローマ人への手紙 11:1; 使徒の働き 23:6"> 私は八日目の割礼を受け、イスラエル民族に属し、ベニヤミンの分かれの者です。きっすいのヘブル人で、律法についてはパリサイ人、</span>
<span className="v" id="v6" data-v="6" data-xref="ガラテヤ人への手紙 1:13–14; 使徒の働き 8:3; 使徒の働き 26:9–10"> その熱心は教会を迫害したほどで、律法による義についてならば非難されるところのない者です。</span>
<span className="v" id="v7" data-v="7" data-xref="ルカの福音書 14:33; マタイの福音書 16:26; マタイの福音書 13:44–46"> しかし、私にとって得であったこのようなものをみな、私はキリストのゆえに、損と思うようになりました。</span>
<span className="v" id="v8" data-v="8" data-xref="Jeremiah 9:23–24; ローマ人への手紙 8:18; ピリピ人への手紙 3:7"> それどころか、私の主であるキリスト・イエスを知っていることのすばらしさのゆえに、いっさいのことを損と思っています。私はキリストのためにすべてのものを捨てて、それらをちりあくたと思っています。それは、私には、キリストを得、また、</span>
<span className="v" id="v9" data-v="9" data-xref="コリント人への手紙第二 5:21; コリント人への手紙第一 1:30; ガラテヤ人への手紙 2:16"> キリストの中にある者と認められ、律法による自分の義ではなくて、キリストを信じる信仰による義、すなわち、信仰に基づいて、神から与えられる義を持つことができる、という望みがあるからです。</span>
<span className="v" id="v10" data-v="10" data-xref="ガラテヤ人への手紙 2:20; ローマ人への手紙 8:17; ペテロの手紙第一 4:1–2"> 私は、キリストとその復活の力を知り、またキリストの苦しみにあずかることも知って、キリストの死と同じ状態になり、</span>
<span className="v" id="v11" data-v="11" data-xref="ルカの福音書 20:35–36; ヨハネの黙示録 20:5; 使徒の働き 23:6"> どうにかして、死者の中からの復活に達したいのです。</span>
<span className="v" id="v12" data-v="12" data-xref="テモテへの手紙第一 6:11–12; ペテロの手紙第二 1:5–8; Psalms 138:8"> 私は、すでに得たのでもなく、すでに完全にされているのでもありません。ただ捕えようとして、追求しているのです。そして、それを得るようにとキリスト・イエスが私を捕えてくださったのです。</span>
<span className="v" id="v13" data-v="13" data-xref="ルカの福音書 9:62; ヘブル人への手紙 12:1–2; ピリピ人への手紙 3:12"> 兄弟たちよ。私は、自分はすでに捕えたなどと考えてはいません。ただ、この一事に励んでいます。すなわち、うしろのものを忘れ、ひたむきに前のものに向かって進み、</span>
<span className="v" id="v14" data-v="14" data-xref="コリント人への手紙第一 9:24; ペテロの手紙第一 5:10; ヨハネの黙示録 3:21"> キリスト・イエスにおいて上に召してくださる神の栄冠を得るために、目標を目ざして一心に走っているのです。</span>
<span className="v" id="v15" data-v="15" data-xref="ヨハネの福音書 7:17; ヤコブの手紙 1:4–5; Proverbs 2:3–6"> ですから、成人である者はみな、このような考え方をしましょう。もし、あなたがたがどこかでこれと違った考え方をしているなら、神はそのこともあなたがたに明らかにしてくださいます。</span>
<span className="v" id="v16" data-v="16" data-xref="コロサイ人への手紙 2:6; ヨハネの黙示録 3:3; ヨハネの黙示録 2:4–5"> それはそれとして、私たちはすでに達しているところを基準として、進むべきです。</span>
<span className="v" id="v17" data-v="17" data-xref="ピリピ人への手紙 4:9; コリント人への手紙第一 4:16; ペテロの手紙第一 5:3"> 兄弟たち。私を見ならう者になってください。また、あなたがたと同じように私たちを手本として歩んでいる人たちに、目を留めてください。</span>
<span className="v" id="v18" data-v="18" data-xref="エペソ人への手紙 4:17; Isaiah 8:11; ガラテヤ人への手紙 6:12"> というのは、私はしばしばあなたがたに言って来たし、今も涙をもって言うのですが、多くの人々がキリストの十字架の敵として歩んでいるからです。</span>
<span className="v" id="v19" data-v="19" data-xref="ローマ人への手紙 16:18; ローマ人への手紙 8:5–7; ペテロの手紙第二 2:3"> 彼らの最後は滅びです。彼らの神は彼らの欲望であり、彼らの栄光は彼ら自身の恥なのです。彼らの思いは地上のことだけです。</span>
<span className="v" id="v20" data-v="20" data-xref="エペソ人への手紙 2:19; コロサイ人への手紙 3:1–3; コリント人への手紙第二 4:18–1"> けれども、私たちの国籍は天にあります。そこから主イエス・キリストが救い主としておいでになるのを、私たちは待ち望んでいます。</span>
<span className="v" id="v21" data-v="21" data-xref="ヨハネの手紙第一 3:2; コロサイ人への手紙 3:4; コリント人への手紙第一 15:42–56"> キリストは、万物をご自身に従わせることのできる御力によって、私たちの卑しいからだを、ご自身の栄光のからだと同じ姿に変えてくださるのです。</span>

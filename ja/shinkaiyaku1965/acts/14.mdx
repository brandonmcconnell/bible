<span className="v" id="v1" data-v="1" data-xref="使徒の働き 18:4; 使徒の働き 13:51; 使徒の働き 13:46"> イコニオムでも、ふたりは連れ立ってユダヤ人の会堂にはいり、話をすると、ユダヤ人もギリシヤ人も大ぜいの人々が信仰にはいった。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒の働き 13:50; 使徒の働き 21:27–30; 使徒の働き 14:19"> しかし、信じようとしないユダヤ人たちは、異邦人たちをそそのかして、兄弟たちに対し悪意を抱かせた。</span>
<span className="v" id="v3" data-v="3" data-xref="ヘブル人への手紙 2:4; エペソ人への手紙 6:18–20; 使徒の働き 20:32"> それでも、ふたりは長らく滞在し、主によって大胆に語った。主は、彼らの手にしるしと不思議なわざを行なわせ、御恵みのことばの証明をされた。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒の働き 28:24; 使徒の働き 14:14; ルカの福音書 11:21–23"> ところが、町の人々は二派に分かれ、ある者はユダヤ人の側につき、ある者は使徒たちの側についた。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒の働き 14:19; テモテへの手紙第二 3:11; 使徒の働き 17:5"> 異邦人とユダヤ人が彼らの指導者たちといっしょになって、使徒たちをはずかしめて、石打ちにしようと企てたとき、</span>
<span className="v" id="v6" data-v="6" data-xref="使徒の働き 14:20–21; マタイの福音書 10:23; テモテへの手紙第二 3:11"> ふたりはそれを知って、ルカオニヤの町であるルステラとデルベ、およびその付近の地方に難を避け、</span>
<span className="v" id="v7" data-v="7" data-xref="使徒の働き 14:21; 使徒の働き 16:10; テサロニケ人への手紙第一 2:2"> そこで福音の宣教を続けた。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒の働き 3:2; ヨハネの福音書 9:1–2; ヨハネの福音書 5:3–5"> ルステラでのことであるが、ある足のきかない人がすわっていた。彼は生まれながらの足なえで、歩いたことがなかった。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒の働き 3:4; マタイの福音書 15:28; マタイの福音書 9:28–29"> この人がパウロの話すことに耳を傾けていた。パウロは彼に目を留め、いやされる信仰があるのを見て、</span>
<span className="v" id="v10" data-v="10" data-xref="Isaiah 35:6; ヨハネの福音書 5:8–9; ヨハネの福音書 14:12"> 大声で、「自分の足で、まっすぐに立ちなさい。」と言った。すると彼は飛び上がって、歩き出した。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒の働き 28:6; 使徒の働き 8:10; 使徒の働き 12:22"> パウロのしたことを見た群衆は、声を張り上げ、ルカオニヤ語で、「神々が人間の姿をとって、私たちのところにお下りになったのだ。」と言った。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒の働き 19:35"> そして、バルナバをゼウスと呼び、パウロがおもに話す人であったので、パウロをヘルメスと呼んだ。</span>
<span className="v" id="v13" data-v="13" data-xref="Daniel 2:46; 使徒の働き 10:25"> すると、町の門の前にあるゼウス神殿の祭司は、雄牛数頭と花飾りを門の前に携えて来て、群衆といっしょに、いけにえをささげようとした。</span>
<span className="v" id="v14" data-v="14" data-xref="マタイの福音書 26:65; コリント人への手紙第一 9:5–6; 2 Kings 5:7"> これを聞いた使徒たち、バルナバとパウロは、衣を裂いて、群衆の中に駆け込み、叫びながら、</span>
<span className="v" id="v15" data-v="15" data-xref="使徒の働き 10:26; コリント人への手紙第一 8:4; ヤコブの手紙 5:17"> 言った。「皆さん。どうしてこんなことをするのですか。私たちも皆さんと同じ人間です。そして、あなたがたがこのようなむなしいことを捨てて、天と地と海とその中にあるすべてのものをお造りになった生ける神に立ち返るように、福音を宣べ伝えている者たちです。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒の働き 17:30; Psalms 81:12; ローマ人への手紙 1:28"> 過ぎ去った時代には、神はあらゆる国の人々がそれぞれ自分の道を歩むことを許しておられました。</span>
<span className="v" id="v17" data-v="17" data-xref="ローマ人への手紙 1:19–20; Joel 2:23; Job 5:10"> とはいえ、ご自身のことをあかししないでおられたのではありません。すなわち、恵みをもって、天から雨を降らせ、実りの季節を与え、食物と喜びとで、あなたがたの心を満たしてくださったのです。」</span>
<span className="v" id="v18" data-v="18" data-xref="Jeremiah 44:16–17; Genesis 19:9; Genesis 11:6"> こう言って、ようやくのことで、群衆が彼らにいけにえをささげるのをやめさせた。</span>
<span className="v" id="v19" data-v="19" data-xref="コリント人への手紙第二 11:25; テモテへの手紙第二 3:11; 使徒の働き 13:50–51"> ところが、アンテオケとイコニオムからユダヤ人たちが来て、群衆を抱き込み、パウロを石打ちにし、死んだものと思って、町の外に引きずり出した。</span>
<span className="v" id="v20" data-v="20" data-xref="コリント人への手紙第二 1:9–10; コリント人への手紙第二 6:9; 使徒の働き 14:6"> しかし、弟子たちがパウロを取り囲んでいると、彼は立ち上がって町にはいって行った。その翌日、彼はバルナバとともにデルベに向かった。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒の働き 14:19; 使徒の働き 14:1; 使徒の働き 13:51"> 彼らはその町で福音を宣べ、多くの人を弟子としてから、ルステラとイコニオムとアンテオケとに引き返して、</span>
<span className="v" id="v22" data-v="22" data-xref="ペテロの手紙第一 5:10; テモテへの手紙第二 3:12; ヨハネの福音書 16:33"> 弟子たちの心を強め、この信仰にしっかりとどまるように勧め、「私たちが神の国にはいるには、多くの苦しみを経なければならない。」と言った。</span>
<span className="v" id="v23" data-v="23" data-xref="テトスへの手紙 1:5; 使徒の働き 11:30; ヤコブの手紙 5:14"> また、彼らのために教会ごとに長老たちを選び、断食をして祈って後、彼らをその信じていた主にゆだねた。</span>
<span className="v" id="v24" data-v="24" data-xref="使徒の働き 13:13–14; 使徒の働き 15:38"> ふたりはピシデヤを通ってパンフリヤに着き、</span>
<span className="v" id="v25" data-v="25"> ペルガでみことばを語ってから、アタリヤに下り、</span>
<span className="v" id="v26" data-v="26" data-xref="使徒の働き 15:40; 使徒の働き 11:19; コリント人への手紙第二 1:12"> そこから船でアンテオケに帰った。そこは、彼らがいま成し遂げた働きのために、以前神の恵みにゆだねられて送り出された所であった。</span>
<span className="v" id="v27" data-v="27" data-xref="コリント人への手紙第一 16:9; 使徒の働き 15:12; コロサイ人への手紙 4:3"> そこに着くと、教会の人々を集め、神が彼らとともにいて行なわれたすべてのことと、異邦人に信仰の門を開いてくださったこととを報告した。</span>
<span className="v" id="v28" data-v="28" data-xref="使徒の働き 11:26; 使徒の働き 15:35"> そして、彼らはかなり長い期間を弟子たちとともに過ごした。</span>

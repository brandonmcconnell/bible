<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒の働き 18:23–28; コリント人への手紙第一 16:12; コリント人への手紙第一 1:12"> アポロがコリントにいた間に、パウロは奥地を通ってエペソに来た。そして幾人かの弟子に出会って、</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネの福音書 7:39; 使徒の働き 11:15–17; ガラテヤ人への手紙 3:5"> 「信じたとき、聖霊を受けましたか。」と尋ねると、彼らは、「いいえ、聖霊の与えられることは、聞きもしませんでした。」と答えた。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒の働き 18:25; コリント人への手紙第一 12:13; 使徒の働き 8:16"> 「では、どんなバプテスマを受けたのですか。」と言うと、「ヨハネのバプテスマです。」と答えた。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネの福音書 1:29–34; 使徒の働き 11:16; 使徒の働き 1:5"> そこで、パウロは、「ヨハネは、自分のあとに来られるイエスを信じるように人々に告げて、悔い改めのバプテスマを授けたのです。」と言った。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒の働き 8:12; 使徒の働き 8:16; ローマ人への手紙 6:3–4"> これを聞いたその人々は、主イエスの御名によってバプテスマを受けた。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒の働き 6:6; 使徒の働き 2:4; マルコの福音書 16:17"> パウロが彼らの上に手を置いたとき、聖霊が彼らに臨まれ、彼らは異言を語ったり、預言をしたりした。</span>
<span className="v" id="v7" data-v="7"> その人々は、みなで十二人ほどであった。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="使徒の働き 28:23; 使徒の働き 1:3; 使徒の働き 9:20–22"> それから、パウロは会堂にはいって、三か月の間大胆に語り、神の国について論じて、彼らを説得しようと努めた。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒の働き 19:23; 使徒の働き 9:2; 使徒の働き 18:6–8"> しかし、ある者たちが心をかたくなにして聞き入れず、会衆の前で、この道をののしったので、パウロは彼らから身を引き、弟子たちをも退かせて、毎日ツラノの講堂で論じた。</span>
<span className="v" id="v10" data-v="10" data-xref="使徒の働き 20:31; テモテへの手紙第二 1:15; 使徒の働き 16:6"> これが二年の間続いたので、アジヤに住む者はみな、ユダヤ人もギリシヤ人も主のことばを聞いた。</span>
<span className="v" id="v11" data-v="11" data-xref="マルコの福音書 16:17–20; 使徒の働き 5:12; ローマ人への手紙 15:18–19"> 神はパウロの手によって驚くべき奇蹟を行なわれた。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒の働き 5:15; 2 Kings 13:20–21; マルコの福音書 16:17"> パウロの身に着けている手ぬぐいや前掛けをはずして病人に当てると、その病気は去り、悪霊は出て行った。</span>
<span className="v" id="v13" data-v="13" data-xref="マタイの福音書 12:27; マルコの福音書 9:38; ルカの福音書 11:19"> ところが、諸国を巡回しているユダヤ人の魔よけ祈祷師の中のある者たちも、ためしに、悪霊につかれている者に向かって主イエスの御名をとなえ、「パウロの宣べ伝えているイエスによって、おまえたちに命じる。」と言ってみた。</span>
<span className="v" id="v14" data-v="14"> そういうことをしたのは、ユダヤの祭司長スケワという人の七人の息子たちであった。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒の働き 16:17–18; ルカの福音書 4:33–35; マルコの福音書 1:34"> すると悪霊が答えて、「自分はイエスを知っているし、パウロもよく知っている。けれどおまえたちは何者だ。」と言った。</span>
<span className="v" id="v16" data-v="16" data-xref="ルカの福音書 8:29; マルコの福音書 5:3–4; マルコの福音書 5:15"> そして悪霊につかれている人は、彼らに飛びかかり、ふたりの者を押えつけて、みなを打ち負かしたので、彼らは裸にされ、傷を負ってその家を逃げ出した。</span>
<span className="v" id="v17" data-v="17" data-xref="テサロニケ人への手紙第二 1:12; 使徒の働き 5:5; ピリピ人への手紙 2:9–11"> このことがエペソに住むユダヤ人とギリシヤ人の全部に知れ渡ったので、みな恐れを感じて、主イエスの御名をあがめるようになった。</span>
<span className="v" id="v18" data-v="18" data-xref="ローマ人への手紙 10:10; Psalms 32:5; マタイの福音書 3:6"> そして、信仰にはいった人たちの中から多くの者がやって来て、自分たちのしていることをさらけ出して告白した。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒の働き 13:8; Exodus 32:20; Genesis 35:4"> また魔術を行なっていた多くの者が、その書物をかかえて来て、みなの前で焼き捨てた。その値段を合計してみると、銀貨五万枚になった。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒の働き 12:24; 使徒の働き 6:7; Isaiah 55:11"> こうして、主のことばは驚くほど広まり、ますます力強くなって行った。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="使徒の働き 20:22; 使徒の働き 20:16; 使徒の働き 23:11"> これらのことが一段落すると、パウロは御霊の示しにより、マケドニヤとアカヤを通ったあとでエルサレムに行くことにした。そして、「私はそこに行ってから、ローマも見なければならない。」と言った。</span>
<span className="v" id="v22" data-v="22" data-xref="ローマ人への手紙 16:23; テモテへの手紙第二 4:20; 使徒の働き 16:3"> そこで、自分に仕えている者の中からテモテとエラストのふたりをマケドニヤに送り出したが、パウロ自身は、なおしばらくアジヤにとどまっていた。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="使徒の働き 19:9; 使徒の働き 24:22; コリント人への手紙第二 1:8–10"> そのころ、この道のことから、ただならぬ騒動が持ち上がった。</span>
<span className="v" id="v24" data-v="24" data-xref="テモテへの手紙第一 6:9–10; 使徒の働き 16:16; 使徒の働き 16:19"> それというのは、デメテリオという銀細工人がいて、銀でアルテミス神殿の模型を作り、職人たちにかなりの収入を得させていたが、</span>
<span className="v" id="v25" data-v="25" data-xref="使徒の働き 16:19; Hosea 12:7–8; ヨハネの黙示録 18:11–19"> 彼が、その職人たちや、同業の者たちをも集めて、こう言ったからである。「皆さん。ご承知のように、私たちが繁盛しているのは、この仕事のおかげです。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒の働き 17:29; コリント人への手紙第一 8:4; Isaiah 44:10–20"> ところが、皆さんが見てもいるし聞いてもいるように、あのパウロが、手で作った物など神ではないと言って、エペソばかりか、ほとんどアジヤ全体にわたって、大ぜいの人々を説き伏せ、迷わせているのです。</span>
<span className="v" id="v27" data-v="27" data-xref="Zephaniah 2:11; テモテへの手紙第一 6:5; マタイの福音書 23:13"> これでは、私たちのこの仕事も信用を失う危険があるばかりか、大女神アルテミスの神殿も顧みられなくなり、全アジヤ、全世界の拝むこの大女神のご威光も地に落ちてしまいそうです。」</span>
<span className="v" id="v28" data-v="28" data-xref="ヨハネの黙示録 13:4; ヨハネの黙示録 17:13; 使徒の働き 16:19–24"> そう聞いて、彼らは大いに怒り、「偉大なのはエペソ人のアルテミスだ。」と叫び始めた。</span>
<span className="v" id="v29" data-v="29" data-xref="使徒の働き 20:4; コロサイ人への手紙 4:10; 使徒の働き 27:2"> そして、町中が大騒ぎになり、人々はパウロの同行者であるマケドニヤ人ガイオとアリスタルコを捕え、一団となって劇場へなだれ込んだ。</span>
<span className="v" id="v30" data-v="30" data-xref="使徒の働き 21:39; 2 Samuel 18:2–3; 使徒の働き 17:22–31"> パウロは、その集団の中にはいって行こうとしたが、弟子たちがそうさせなかった。</span>
<span className="v" id="v31" data-v="31" data-xref="使徒の働き 19:10; 使徒の働き 21:12; 使徒の働き 16:6"> アジヤ州の高官で、パウロの友人である人たちも、彼に使いを送って、劇場にはいらないように頼んだ。</span>
<span className="v" id="v32" data-v="32" data-xref="使徒の働き 21:34; 使徒の働き 19:40; マタイの福音書 11:7–9"> ところで、集会は混乱状態に陥り、大多数の者は、なぜ集まったのかさえ知らなかったので、ある者はこのことを叫び、ほかの者は別のことを叫んでいた。</span>
<span className="v" id="v33" data-v="33" data-xref="使徒の働き 12:17; テモテへの手紙第二 4:14; テモテへの手紙第一 1:20"> ユダヤ人たちがアレキサンデルという者を前に押し出したので、群衆の中のある人たちが彼を促すと、彼は手を振って、会衆に弁明しようとした。</span>
<span className="v" id="v34" data-v="34" data-xref="使徒の働き 19:28; マタイの福音書 6:7; ヨハネの黙示録 13:4"> しかし、彼がユダヤ人だとわかると、みなの者がいっせいに声をあげ、「偉大なのはエペソ人のアルテミスだ。」と二時間ばかりも叫び続けた。</span>
<span className="v" id="v35" data-v="35" data-xref="テサロニケ人への手紙第二 2:10–11; テモテへの手紙第一 4:2; エペソ人への手紙 2:12"> 町の書記役は、群衆を押し静めてこう言った。「エペソの皆さん。エペソの町が、大女神アルテミスと天から下ったそのご神体との守護者であることを知らない者が、いったいいるでしょうか。</span>
<span className="v" id="v36" data-v="36" data-xref="Proverbs 14:29; 使徒の働き 5:35–39; Proverbs 25:8"> これは否定できない事実ですから、皆さんは静かにして、軽はずみなことをしないようにしなければいけません。</span>
<span className="v" id="v37" data-v="37" data-xref="コリント人への手紙第二 6:3; ローマ人への手紙 2:22; 使徒の働き 25:8"> 皆さんがここに引き連れて来たこの人たちは、宮を汚した者でもなく、私たちの女神をそしった者でもないのです。</span>
<span className="v" id="v38" data-v="38" data-xref="使徒の働き 13:7; コリント人への手紙第一 6:1; 使徒の働き 18:14"> それで、もしデメテリオとその仲間の職人たちが、だれかに文句があるのなら、裁判の日があるし、地方総督たちもいることですから、互いに訴え出たらよいのです。</span>
<span className="v" id="v39" data-v="39"> もしあなたがたに、これ以上何か要求することがあるなら、正式の議会で決めてもらわなければいけません。</span>
<span className="v" id="v40" data-v="40" data-xref="使徒の働き 17:5–8; マタイの福音書 26:5; 使徒の働き 20:1"> きょうの事件については、正当な理由がないのですから、騒擾罪に問われる恐れがあります。その点に関しては、私たちはこの騒動の弁護はできません。」</span>
<span className="v" id="v41" data-v="41" data-xref="Ecclesiastes 9:17; Psalms 65:7; コリント人への手紙第二 1:8–10"> こう言って、その集まりを解散させた。</span>
</div>

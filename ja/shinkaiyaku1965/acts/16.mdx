<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="テモテへの手紙第二 1:5; テモテへの手紙第二 1:2; コリント人への手紙第一 4:17"> それからパウロはデルベに、次いでルステラに行った。そこにテモテという弟子がいた。信者であるユダヤ婦人の子で、ギリシヤ人を父としていたが、</span>
<span className="v" id="v2" data-v="2" data-xref="テモテへの手紙第一 5:10; テモテへの手紙第二 3:15; 使徒の働き 14:21"> ルステラとイコニオムとの兄弟たちの間で評判の良い人であった。</span>
<span className="v" id="v3" data-v="3" data-xref="ガラテヤ人への手紙 2:3; コリント人への手紙第一 9:20; ガラテヤ人への手紙 5:6"> パウロは、このテモテを連れて行きたかったので、その地方にいるユダヤ人の手前、彼に割礼を受けさせた。彼の父がギリシヤ人であることを、みなが知っていたからである。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒の働き 15:28–29; 使徒の働き 15:2; 使徒の働き 11:30"> さて、彼らは町々を巡回して、エルサレムの使徒たちと長老たちが決めた規定を守らせようと、人々にそれを伝えた。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒の働き 9:31; 使徒の働き 2:47; 使徒の働き 6:7"> こうして諸教会は、その信仰を強められ、日ごとに人数を増して行った。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="使徒の働き 18:23; 使徒の働き 16:7; 使徒の働き 13:2–4"> それから彼らは、アジヤでみことばを語ることを聖霊によって禁じられたので、フルギヤ・ガラテヤの地方を通った。</span>
<span className="v" id="v7" data-v="7" data-xref="ローマ人への手紙 8:9; ピリピ人への手紙 1:19; ガラテヤ人への手紙 4:6"> こうしてムシヤに面した所に来たとき、ビテニヤのほうに行こうとしたが、イエスの御霊がそれをお許しにならなかった。</span>
<span className="v" id="v8" data-v="8" data-xref="コリント人への手紙第二 2:12; テモテへの手紙第二 4:13; 使徒の働き 16:11"> それでムシヤを通って、トロアスに下った。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒の働き 9:10–12; 使徒の働き 19:21; 使徒の働き 18:5"> ある夜、パウロは幻を見た。ひとりのマケドニヤ人が彼の前に立って、「マケドニヤに渡って来て、私たちを助けてください。」と懇願するのであった。</span>
<span className="v" id="v10" data-v="10" data-xref="コリント人への手紙第二 2:12–13; 使徒の働き 14:7; 使徒の働き 16:10–17"> パウロがこの幻を見たとき、私たちはただちにマケドニヤへ出かけることにした。神が私たちを招いて、彼らに福音を宣べさせるのだ、と確信したからである。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="使徒の働き 21:1; 使徒の働き 16:8"> そこで、私たちはトロアスから船に乗り、サモトラケに直航して、翌日ネアポリスに着いた。</span>
<span className="v" id="v12" data-v="12" data-xref="テサロニケ人への手紙第一 2:2; ピリピ人への手紙 1:1; 使徒の働き 20:6"> それからピリピに行ったが、ここはマケドニヤのこの地方第一の町で、植民都市であった。私たちはこの町に幾日か滞在した。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒の働き 13:14; コロサイ人への手紙 1:23; 使徒の働き 17:2"> 安息日に、私たちは町の門を出て、祈り場があると思われた川岸に行き、そこに腰をおろして、集まった女たちに話した。</span>
<span className="v" id="v14" data-v="14" data-xref="エペソ人への手紙 1:17–18; ルカの福音書 24:45; Isaiah 50:5"> テアテラ市の紫布の商人で、神を敬う、ルデヤという女が聞いていたが、主は彼女の心を開いて、パウロの語る事に心を留めるようにされた。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒の働き 11:14; ヘブル人への手紙 13:2; 使徒の働き 16:33"> そして、彼女も、またその家族もバプテスマを受けたとき、彼女は、「私を主に忠実な者とお思いでしたら、どうか、私の家に来てお泊まりください。」と言って頼み、強いてそうさせた。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="Leviticus 19:31; Deuteronomy 18:9–11; Isaiah 8:19"> 私たちが祈り場に行く途中、占いの霊につかれた若い女奴隷に出会った。この女は占いをして、主人たちに多くの利益を得させている者であった。</span>
<span className="v" id="v17" data-v="17" data-xref="ヨハネの福音書 14:6; ペテロの手紙第一 2:16; マルコの福音書 5:7"> 彼女はパウロと私たちのあとについて来て、「この人たちは、いと高き神のしもべたちで、救いの道をあなたがたに宣べ伝えている人たちです。」と叫び続けた。</span>
<span className="v" id="v18" data-v="18" data-xref="マルコの福音書 16:17; ルカの福音書 10:17–19; 使徒の働き 3:6"> 幾日もこんなことをするので、困り果てたパウロは、振り返ってその霊に、「イエス・キリストの御名によって命じる。この女から出て行け。」と言った。すると即座に、霊は出て行った。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="使徒の働き 17:6; 使徒の働き 21:30; 使徒の働き 8:3"> 彼女の主人たちは、もうける望みがなくなったのを見て、パウロとシラスを捕え、役人たちに訴えるため広場へ引き立てて行った。</span>
<span className="v" id="v20" data-v="20" data-xref="ヤコブの手紙 4:4; ヨハネの福音書 15:18–20; 使徒の働き 28:22"> そして、ふたりを長官たちの前に引き出してこう言った。「この者たちはユダヤ人でありまして、私たちの町をかき乱し、</span>
<span className="v" id="v21" data-v="21" data-xref="Esther 3:8; 使徒の働き 26:3; Jeremiah 10:3"> ローマ人である私たちが、採用も実行もしてはならない風習を宣伝しております。」</span>
<span className="v" id="v22" data-v="22" data-xref="テサロニケ人への手紙第一 2:2; コリント人への手紙第二 6:5; コリント人への手紙第二 11:23–25"> 群衆もふたりに反対して立ったので、長官たちは、ふたりの着物をはいでむちで打つように命じ、</span>
<span className="v" id="v23" data-v="23" data-xref="ヨハネの黙示録 2:10; テモテへの手紙第二 2:9; 1 Samuel 23:22–23"> 何度もむちで打たせてから、ふたりを牢に入れて、看守には厳重に番をするように命じた。</span>
<span className="v" id="v24" data-v="24" data-xref="Job 13:27; Job 33:11; Jeremiah 29:26"> この命令を受けた看守は、ふたりを奥の牢に入れ、足に足かせを掛けた。</span>
<span className="v" id="v25" data-v="25" data-xref="テサロニケ人への手紙第一 5:16–18; Psalms 119:62; ヤコブの手紙 1:2"> 真夜中ごろ、パウロとシラスが神に祈りつつ賛美の歌を歌っていると、ほかの囚人たちも聞き入っていた。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒の働き 4:31; 使徒の働き 5:19; 使徒の働き 12:10"> ところが突然、大地震が起こって、獄舎の土台が揺れ動き、たちまちとびらが全部あいて、みなの鎖が解けてしまった。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒の働き 12:19; マタイの福音書 27:5; Judges 9:54"> 目をさました看守は、見ると、牢のとびらがあいているので、囚人たちが逃げてしまったものと思い、剣を抜いて自殺しようとした。</span>
<span className="v" id="v28" data-v="28" data-xref="テサロニケ人への手紙第一 5:15; ルカの福音書 23:34; ルカの福音書 6:27–28"> そこでパウロは大声で、「自害してはいけない。私たちはみなここにいる。」と叫んだ。</span>
<span className="v" id="v29" data-v="29" data-xref="ヨハネの黙示録 3:9; 使徒の働き 24:25; Isaiah 60:14"> 看守はあかりを取り、駆け込んで来て、パウロとシラスとの前に震えながらひれ伏した。</span>
<span className="v" id="v30" data-v="30" data-xref="使徒の働き 2:37; ヨハネの福音書 6:27–29; Isaiah 58:9"> そして、ふたりを外に連れ出して「先生がた。救われるためには、何をしなければなりませんか。」と言った。</span>
<span className="v" id="v31" data-v="31" data-xref="ヨハネの福音書 1:12; 使徒の働き 2:38–39; ヨハネの福音書 3:36"> ふたりは、「主イエスを信じなさい。そうすれば、あなたもあなたの家族も救われます。」と言った。</span>
<span className="v" id="v32" data-v="32" data-xref="ローマ人への手紙 1:16; コロサイ人への手紙 1:27–28; テモテへの手紙第一 1:13–16"> そして、彼とその家の者全部に主のことばを語った。</span>
<span className="v" id="v33" data-v="33" data-xref="コリント人への手紙第一 1:16; 使徒の働き 16:15; 使徒の働き 16:25"> 看守は、その夜、時を移さず、ふたりを引き取り、その打ち傷を洗った。そして、そのあとですぐ、彼とその家の者全部がバプテスマを受けた。</span>
<span className="v" id="v34" data-v="34" data-xref="ローマ人への手紙 15:13; 使徒の働き 2:46; ローマ人への手紙 5:11"> それから、ふたりをその家に案内して、食事のもてなしをし、全家族そろって神を信じたことを心から喜んだ。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="Jeremiah 5:22; Psalms 76:10; 使徒の働き 5:40"> 夜が明けると、長官たちは警吏たちを送って、「あの人たちを釈放せよ。」と言わせた。</span>
<span className="v" id="v36" data-v="36" data-xref="使徒の働き 15:33; ヨハネの福音書 14:27; 1 Samuel 1:17"> そこで看守は、この命令をパウロに伝えて、「長官たちが、あなたがたを釈放するようにと、使いをよこしました。どうぞ、ここを出て、ご無事に行ってください。」と言った。</span>
<span className="v" id="v37" data-v="37" data-xref="使徒の働き 22:25–29; Psalms 58:1–2; マタイの福音書 10:16"> ところが、パウロは、警吏たちにこう言った。「彼らは、ローマ人である私たちを、取り調べもせずに公衆の前でむち打ち、牢に入れてしまいました。それなのに今になって、ひそかに私たちを送り出そうとするのですか。とんでもない。彼ら自身で出向いて来て、私たちを連れ出すべきです。」</span>
<span className="v" id="v38" data-v="38" data-xref="使徒の働き 22:29; マタイの福音書 21:46; マタイの福音書 14:5"> 警吏たちは、このことばを長官たちに報告した。すると長官たちは、ふたりがローマ人であると聞いて恐れ、</span>
<span className="v" id="v39" data-v="39" data-xref="マタイの福音書 8:34; マルコの福音書 5:17; Daniel 6:23"> 自分で出向いて来て、わびを言い、ふたりを外に出して、町から立ち去ってくれるように頼んだ。</span>
<span className="v" id="v40" data-v="40" data-xref="テサロニケ人への手紙第一 3:2–3; 使徒の働き 16:14; 使徒の働き 14:22"> 牢を出たふたりは、ルデヤの家に行った。そして兄弟たちに会い、彼らを励ましてから出て行った。</span>
</div>

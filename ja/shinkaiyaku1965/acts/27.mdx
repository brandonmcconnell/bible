<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒の働き 25:25; 使徒の働き 25:12; 使徒の働き 10:1"> さて、私たちが船でイタリヤへ行くことが決まったとき、パウロと、ほかの数人の囚人は、ユリアスという親衛隊の百人隊長に引き渡された。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒の働き 19:29; ピレモンへの手紙 1:24; コロサイ人への手紙 4:10"> 私たちは、アジヤの沿岸の各地に寄港して行くアドラミテオの船に乗り込んで出帆した。テサロニケのマケドニヤ人アリスタルコも同行した。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒の働き 24:23; 使徒の働き 28:16; 使徒の働き 27:43"> 翌日、シドンに入港した。ユリアスはパウロを親切に取り扱い、友人たちのところへ行って、もてなしを受けることを許した。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒の働き 4:36; 使徒の働き 15:39; 使徒の働き 13:4"> そこから出帆したが、向かい風なので、キプロスの島陰を航行した。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒の働き 6:9; 使徒の働き 13:13; 使徒の働き 15:41"> そしてキリキヤとパンフリヤの沖を航行して、ルキヤのミラに入港した。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒の働き 28:11; 使徒の働き 27:1; 使徒の働き 6:9"> そこに、イタリヤへ行くアレキサンドリヤの船があったので、百人隊長は私たちをそれに乗り込ませた。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒の働き 27:21; テトスへの手紙 1:5; テトスへの手紙 1:12"> 幾日かの間、船の進みはおそく、ようやくのことでクニドの沖に着いたが、風のためにそれ以上進むことができず、サルモネ沖のクレテの島陰を航行し、</span>
<span className="v" id="v8" data-v="8"> その岸に沿って進みながら、ようやく、良い港と呼ばれる所に着いた。その近くにラサヤの町があった。</span>
<span className="v" id="v9" data-v="9" data-xref="Numbers 29:7; Leviticus 23:27–29; Leviticus 16:29–31"> かなりの日数が経過しており、断食の季節もすでに過ぎていたため、もう航海は危険であったので、パウロは人々に注意して、</span>
<span className="v" id="v10" data-v="10" data-xref="Daniel 2:30; 使徒の働き 27:20–26; 使徒の働き 27:41–44"> 「皆さん。この航海では、きっと、積荷や船体だけではなく、私たちの生命にも、危害と大きな損失が及ぶと、私は考えます。」と言った。</span>
<span className="v" id="v11" data-v="11" data-xref="Ezekiel 33:4; ヘブル人への手紙 11:7; Ezekiel 3:17–18"> しかし百人隊長は、パウロのことばよりも、航海士や船長のほうを信用した。</span>
<span className="v" id="v12" data-v="12" data-xref="Psalms 107:30; 使徒の働き 27:8"> また、この港が冬を過ごすのに適していなかったので、大多数の者の意見は、ここを出帆して、できれば何とかして、南西と北西とに面しているクレテの港ピニクスまで行って、そこで冬を過ごしたいということになった。</span>
<span className="v" id="v13" data-v="13" data-xref="ルカの福音書 12:55; Song of Solomon 4:16; Job 37:17"> おりから、穏やかな南風が吹いて来ると、人々はこの時とばかり錨を上げて、クレテの海岸に沿って航行した。</span>
<span className="v" id="v14" data-v="14" data-xref="マルコの福音書 4:37; Psalms 107:25–27; Exodus 14:21–27"> ところが、まもなくユーラクロンという暴風が陸から吹きおろして来て、</span>
<span className="v" id="v15" data-v="15" data-xref="ヤコブの手紙 3:4; 使徒の働き 27:27"> 船はそれに巻き込まれ、風に逆らって進むことができないので、しかたなく吹き流されるままにした。</span>
<span className="v" id="v16" data-v="16"> しかしクラウダという小さな島の陰にはいったので、ようやくのことで小舟を処置することができた。</span>
<span className="v" id="v17" data-v="17" data-xref="使徒の働き 27:29; 使徒の働き 27:26; 使徒の働き 27:41"> 小舟を船に引き上げ、備え綱で船体を巻いた。また、スルテスの浅瀬に乗り上げるのを恐れて、船具をはずして流れるに任せた。</span>
<span className="v" id="v18" data-v="18" data-xref="Jonah 1:5; 使徒の働き 27:38; マタイの福音書 16:26"> 私たちは暴風に激しく翻弄されていたので、翌日、人々は積荷を捨て始め、</span>
<span className="v" id="v19" data-v="19" data-xref="Job 2:4; ルカの福音書 9:24–25; マルコの福音書 8:35–37"> 三日目には、自分の手で船具までも投げ捨てた。</span>
<span className="v" id="v20" data-v="20" data-xref="マタイの福音書 24:29; マタイの福音書 8:24–25; Jeremiah 2:25"> 太陽も星も見えない日が幾日も続き、激しい暴風が吹きまくるので、私たちが助かる最後の望みも今や絶たれようとしていた。</span>
<span className="v" id="v21" data-v="21" data-xref="Genesis 42:22; Psalms 107:5–6; 使徒の働き 27:7"> だれも長いこと食事をとらなかったが、そのときパウロが彼らの中に立って、こう言った。「皆さん。あなたがたは私の忠告を聞き入れて、クレテを出帆しなかったら、こんな危害や損失をこうむらなくて済んだのです。</span>
<span className="v" id="v22" data-v="22" data-xref="使徒の働き 27:25; 使徒の働き 27:36; コリント人への手紙第二 4:8–9"> しかし、今、お勧めします。元気を出しなさい。あなたがたのうち、いのちを失う者はひとりもありません。失われるのは船だけです。</span>
<span className="v" id="v23" data-v="23" data-xref="使徒の働き 23:11; ローマ人への手紙 1:9; テモテへの手紙第二 4:17"> 昨夜、私の主で、私の仕えている神の御使いが、私の前に立って、</span>
<span className="v" id="v24" data-v="24" data-xref="使徒の働き 23:11; テモテへの手紙第二 4:16–17; マタイの福音書 10:28"> こう言いました。『恐れてはいけません。パウロ。あなたは必ずカイザルの前に立ちます。そして、神はあなたと同船している人々をみな、あなたにお与えになったのです。』</span>
<span className="v" id="v25" data-v="25" data-xref="ローマ人への手紙 4:20–21; ルカの福音書 1:45; Numbers 23:19"> ですから、皆さん。元気を出しなさい。すべて私に告げられたとおりになると、私は神によって信じています。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒の働き 28:1; 使徒の働き 27:17; 使徒の働き 27:29"> 私たちは必ず、どこかの島に打ち上げられます。」</span>
<span className="v" id="v27" data-v="27" data-xref="Jonah 1:6; 使徒の働き 27:30; ヨハネの黙示録 18:17"> 十四日目の夜になって、私たちがアドリヤ海を漂っていると、真夜中ごろ、水夫たちは、どこかの陸地に近づいたように感じた。</span>
<span className="v" id="v28" data-v="28"> 水の深さを測ってみると、四十メートルほどであることがわかった。少し進んでまた測ると、三十メートルほどであった。</span>
<span className="v" id="v29" data-v="29" data-xref="使徒の働き 27:17; ヘブル人への手紙 6:19; Deuteronomy 28:67"> どこかで暗礁に乗り上げはしないかと心配して、ともから四つの錨を投げおろし、夜の明けるのを待った。</span>
<span className="v" id="v30" data-v="30" data-xref="使徒の働き 27:16; 使徒の働き 27:32"> ところが、水夫たちは船から逃げ出そうとして、へさきから錨を降ろすように見せかけて、小舟を海に降ろしていたので、</span>
<span className="v" id="v31" data-v="31" data-xref="テサロニケ人への手紙第二 2:13–14; Psalms 91:11–12; Jeremiah 29:11–13"> パウロは百人隊長や兵士たちに、「あの人たちが船にとどまっていなければ、あなたがたも助かりません。」と言った。</span>
<span className="v" id="v32" data-v="32" data-xref="ピリピ人への手紙 3:7–9; ルカの福音書 16:8"> そこで兵士たちは、小舟の綱を断ち切って、そのまま流れ去るのに任せた。</span>
<span className="v" id="v33" data-v="33"> ついに夜の明けかけたころ、パウロは、一同に食事をとることを勧めて、こう言った。「あなたがたは待ちに待って、きょうまで何も食べずに過ごして、十四日になります。</span>
<span className="v" id="v34" data-v="34" data-xref="マタイの福音書 10:30; 1 Kings 1:52; ルカの福音書 21:18"> ですから、私はあなたがたに、食事をとることを勧めます。これであなたがたは助かることになるのです。あなたがたの頭から髪一筋も失われることはありません。」</span>
<span className="v" id="v35" data-v="35" data-xref="マタイの福音書 15:36; コリント人への手紙第一 10:30–31; テモテへの手紙第一 4:3–4"> こう言って、彼はパンを取り、一同の前で神に感謝をささげてから、それを裂いて食べ始めた。</span>
<span className="v" id="v36" data-v="36" data-xref="コリント人への手紙第二 1:4–6; 使徒の働き 27:22; Psalms 27:14"> そこで一同も元気づけられ、みなが食事をとった。</span>
<span className="v" id="v37" data-v="37" data-xref="使徒の働き 2:41; ローマ人への手紙 13:1; ペテロの手紙第一 3:20"> 船にいた私たちは全部で二百七十六人であった。</span>
<span className="v" id="v38" data-v="38" data-xref="Jonah 1:5; マタイの福音書 6:25; 使徒の働き 27:18–19"> 十分食べてから、彼らは麦を海に投げ捨てて、船を軽くした。</span>
<span className="v" id="v39" data-v="39" data-xref="使徒の働き 28:1"> 夜が明けると、どこの陸地かわからないが、砂浜のある入江が目に留まったので、できれば、そこに船を乗り入れようということになった。</span>
<span className="v" id="v40" data-v="40" data-xref="Isaiah 33:23; 使徒の働き 27:29–30"> 錨を切って海に捨て、同時にかじ綱を解き、風に前の帆を上げて、砂浜に向かって進んで行った。</span>
<span className="v" id="v41" data-v="41" data-xref="コリント人への手紙第二 11:25–26; Ezekiel 27:26; 使徒の働き 27:26–29"> ところが、潮流の流れ合う浅瀬に乗り上げて、船を座礁させてしまった。へさきはめり込んで動かなくなり、ともは激しい波に打たれて破れ始めた。</span>
<span className="v" id="v42" data-v="42" data-xref="マルコの福音書 15:15–20; Ecclesiastes 9:3; Psalms 74:20"> 兵士たちは、囚人たちがだれも泳いで逃げないように、殺してしまおうと相談した。</span>
<span className="v" id="v43" data-v="43" data-xref="使徒の働き 27:3; Proverbs 16:7; 使徒の働き 27:11"> しかし百人隊長は、パウロをあくまでも助けようと思って、その計画を押え、泳げる者がまず海に飛び込んで陸に上がるように、</span>
<span className="v" id="v44" data-v="44" data-xref="使徒の働き 27:22; Psalms 107:28–30; ヨハネの福音書 6:39–40"> それから残りの者は、板切れや、その他の、船にある物につかまって行くように命じた。こうして、彼らはみな、無事に陸に上がった。</span>

<span className="v" id="v1" data-v="1" data-xref="テサロニケ人への手紙第一 2:17; ルカの福音書 5:4; 1 Samuel 20:41–42"> 私たちは彼らと別れて出帆し、コスに直航し、翌日ロドスに着き、そこからパタラに渡った。</span>
<span className="v" id="v2" data-v="2" data-xref="Jonah 1:3; 使徒の働き 11:19; 使徒の働き 15:3"> そこにはフェニキヤ行きの船があったので、それに乗って出帆した。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒の働き 21:16; 使徒の働き 4:36; マタイの福音書 4:24"> やがてキプロスが見えて来たが、それを左にして、シリヤに向かって航海を続け、ツロに上陸した。ここで船荷を降ろすことになっていたからである。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒の働き 20:22–23; 使徒の働き 21:10–12; 使徒の働き 20:6–7"> 私たちは弟子たちを見つけ出して、そこに七日間滞在した。彼らは、御霊に示されて、エルサレムに上らぬようにと、しきりにパウロに忠告した。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒の働き 20:36; 使徒の働き 9:40; Psalms 95:6"> しかし、滞在の日数が尽きると、私たちはそこを出て、旅を続けることにした。彼らはみな、妻や子どももいっしょに、町はずれまで私たちを送って来た。そして、ともに海岸にひざまずいて祈ってから、私たちは互いに別れを告げた。</span>
<span className="v" id="v6" data-v="6" data-xref="ヨハネの福音書 19:27; ヨハネの福音書 1:11; コリント人への手紙第二 2:13"> それから私たちは船に乗り込み、彼らは家へ帰って行った。</span>
<span className="v" id="v7" data-v="7" data-xref="ヘブル人への手紙 13:24; 1 Samuel 10:4; 使徒の働き 28:12"> 私たちはツロからの航海を終えて、トレマイに着いた。そこの兄弟たちにあいさつをして、彼らのところに一日滞在した。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒の働き 6:5; 使徒の働き 8:26–40; エペソ人への手紙 4:11"> 翌日そこを立って、カイザリヤに着き、あの七人のひとりである伝道者ピリポの家にはいって、そこに滞在した。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒の働き 2:17; ヨハネの黙示録 2:20; Joel 2:28"> この人には、預言する四人の未婚の娘がいた。</span>
<span className="v" id="v10" data-v="10" data-xref="使徒の働き 11:28; 使徒の働き 21:4; 使徒の働き 20:16"> 幾日かそこに滞在していると、アガボという預言者がユダヤから下って来た。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒の働き 21:33; Jeremiah 13:1–11; 1 Samuel 15:27–28"> 彼は私たちのところに来て、パウロの帯を取り、自分の両手と両足を縛って、「『この帯の持ち主は、エルサレムでユダヤ人に、こんなふうに縛られ、異邦人の手に渡される。』と聖霊がお告げになっています。」と言った。</span>
<span className="v" id="v12" data-v="12" data-xref="マタイの福音書 16:21–23; 使徒の働き 20:22; 使徒の働き 21:4"> 私たちはこれを聞いて、土地の人たちといっしょになって、パウロに、エルサレムには上らないよう頼んだ。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒の働き 20:24; ピリピ人への手紙 2:17; ピリピ人への手紙 1:20–21"> するとパウロは、「あなたがたは、泣いたり、私の心をくじいたりして、いったい何をしているのですか。私は、主イエスの御名のためなら、エルサレムで縛られることばかりでなく、死ぬことさえも覚悟しています。」と答えた。</span>
<span className="v" id="v14" data-v="14" data-xref="ルカの福音書 22:42; マタイの福音書 26:42; マタイの福音書 26:39"> 彼が聞き入れようとしないので、私たちは、「主のみこころのままに。」と言って、黙ってしまった。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒の働き 25:1; 使徒の働き 25:6; 使徒の働き 25:9"> こうして数日たつと、私たちは旅仕度をして、エルサレムに上った。</span>
<span className="v" id="v16" data-v="16" data-xref="Proverbs 16:31; 使徒の働き 21:8; Psalms 92:14"> カイザリヤの弟子たちも幾人か私たちと同行して、古くからの弟子であるキプロス人マナソンのところに案内してくれた。私たちはそこに泊まることになっていたのである。</span>
<span className="v" id="v17" data-v="17" data-xref="使徒の働き 15:4; ローマ人への手紙 15:7; ヘブル人への手紙 13:1–2"> エルサレムに着くと、兄弟たちは喜んで私たちを迎えてくれた。</span>
<span className="v" id="v18" data-v="18" data-xref="ガラテヤ人への手紙 1:19; ガラテヤ人への手紙 2:9; 使徒の働き 15:13"> 次の日、パウロは私たちを連れて、ヤコブを訪問した。そこには長老たちがみな集まっていた。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒の働き 14:27; 使徒の働き 1:17; ローマ人への手紙 15:18–19"> 彼らにあいさつしてから、パウロは彼の奉仕を通して神が異邦人の間でなさったことを、一つ一つ話しだした。</span>
<span className="v" id="v20" data-v="20" data-xref="ローマ人への手紙 10:2; ガラテヤ人への手紙 1:14; 使徒の働き 22:3"> 彼らはそれを聞いて神をほめたたえ、パウロにこう言った。「兄弟よ。ご承知のように、ユダヤ人の中で信仰にはいっている者は幾万となくありますが、みな律法に熱心な人たちです。</span>
<span className="v" id="v21" data-v="21" data-xref="ガラテヤ人への手紙 6:12–15; コリント人への手紙第一 9:19–21; ガラテヤ人への手紙 5:1–6"> ところで、彼らが聞かされていることは、あなたは異邦人の中にいるすべてのユダヤ人に、子どもに割礼を施すな、慣習に従って歩むな、と言って、モーセにそむくように教えているということなのです。</span>
<span className="v" id="v22" data-v="22" data-xref="使徒の働き 15:12; 使徒の働き 15:22; 使徒の働き 19:32"> それで、どうしましょうか。あなたが来たことは、必ず彼らの耳にはいるでしょう。</span>
<span className="v" id="v23" data-v="23" data-xref="使徒の働き 18:18; Numbers 6:2–7"> ですから、私たちの言うとおりにしてください。私たちの中に誓願を立てている者が四人います。</span>
<span className="v" id="v24" data-v="24" data-xref="使徒の働き 21:26; 使徒の働き 24:18; 使徒の働き 18:18"> この人たちを連れて、あなたも彼らといっしょに身を清め、彼らが頭をそる費用を出してやりなさい。そうすれば、あなたについて聞かされていることは根も葉もないことで、あなたも律法を守って正しく歩んでいることが、みなにわかるでしょう。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒の働き 15:29; 使徒の働き 15:19–20"> 信仰にはいった異邦人に関しては、偶像の神に供えた肉と、血と、絞め殺した物と、不品行とを避けるべきであると決定しましたので、私たちはすでに手紙を書きました。」</span>
<span className="v" id="v26" data-v="26" data-xref="使徒の働き 24:18; 使徒の働き 21:24; Numbers 6:13–20"> そこで、パウロはその人たちを引き連れ、翌日、ともに身を清めて宮にはいり、清めの期間が終わって、ひとりひとりのために供え物をささげる日時を告げた。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒の働き 26:21; 使徒の働き 24:18; 使徒の働き 13:50"> ところが、その七日がほとんど終わろうとしていたころ、アジヤから来たユダヤ人たちは、パウロが宮にいるのを見ると、全群衆をあおりたて、彼に手をかけて、</span>
<span className="v" id="v28" data-v="28" data-xref="使徒の働き 24:5–6; 使徒の働き 21:21; 使徒の働き 26:20–21"> こう叫んだ。「イスラエルの人々。手を貸してください。この男は、この民と、律法と、この場所に逆らうことを、至る所ですべての人に教えている者です。そのうえ、ギリシヤ人を宮の中に連れ込んで、この神聖な場所をけがしています。」</span>
<span className="v" id="v29" data-v="29" data-xref="使徒の働き 20:4; テモテへの手紙第二 4:20; 使徒の働き 18:19"> 彼らは前にエペソ人トロピモが町でパウロといっしょにいるのを見かけたので、パウロが彼を宮に連れ込んだのだと思ったのである。</span>
<span className="v" id="v30" data-v="30" data-xref="使徒の働き 26:21; コリント人への手紙第二 11:26; 使徒の働き 16:19–22"> そこで町中が大騒ぎになり、人々は殺到してパウロを捕え、宮の外へ引きずり出した。そして、ただちに宮の門が閉じられた。</span>
<span className="v" id="v31" data-v="31" data-xref="コリント人への手紙第二 11:23–33; 使徒の働き 17:5; 使徒の働き 26:9–10"> 彼らがパウロを殺そうとしていたとき、エルサレム中が混乱状態に陥っているという報告が、ローマ軍の千人隊長に届いた。</span>
<span className="v" id="v32" data-v="32" data-xref="使徒の働き 23:27; Isaiah 3:15; 使徒の働き 5:40"> 彼はただちに、兵士たちと百人隊長たちとを率いて、彼らのところに駆けつけた。人々は千人隊長と兵士たちを見て、パウロを打つのをやめた。</span>
<span className="v" id="v33" data-v="33" data-xref="エペソ人への手紙 6:20; 使徒の働き 21:11; 使徒の働き 20:23"> 千人隊長は近づいてパウロを捕え、二つの鎖につなぐように命じたうえ、パウロが何者なのか、何をしたのか、と尋ねた。</span>
<span className="v" id="v34" data-v="34" data-xref="使徒の働き 19:32; 使徒の働き 23:10; 使徒の働き 22:24"> しかし、群衆がめいめい勝手なことを叫び続けたので、その騒がしさのために確かなことがわからなかった。そこで千人隊長は、パウロを兵営に連れて行くように命令した。</span>
<span className="v" id="v35" data-v="35" data-xref="Habakkuk 1:2–3; Psalms 55:9; Psalms 58:2"> パウロが階段にさしかかったときには、群衆の暴行を避けるために、兵士たちが彼をかつぎ上げなければならなかった。</span>
<span className="v" id="v36" data-v="36" data-xref="ヨハネの福音書 19:15; 使徒の働き 22:22; ルカの福音書 23:18"> 大ぜいの群衆が「彼を除け。」と叫びながら、ついて来たからである。</span>
<span className="v" id="v37" data-v="37" data-xref="使徒の働き 21:34; ルカの福音書 21:15; 使徒の働き 19:30"> 兵営の中に連れ込まれようとしたとき、パウロが千人隊長に、「一言お話ししてもよいでしょうか。」と尋ねると、千人隊長は、「あなたはギリシヤ語を知っているのか。</span>
<span className="v" id="v38" data-v="38" data-xref="マタイの福音書 24:26; 使徒の働き 5:36–37; マタイの福音書 5:11"> するとあなたは、以前暴動を起こして、四千人の刺客を荒野に引き連れて逃げた、あのエジプト人ではないのか。」と言った。</span>
<span className="v" id="v39" data-v="39" data-xref="使徒の働き 22:3; 使徒の働き 9:11; 使徒の働き 23:27"> パウロは答えた。「私はキリキヤのタルソ出身のユダヤ人で、れっきとした町の市民です。お願いです。この人々に話をさせてください。」</span>
<span className="v" id="v40" data-v="40" data-xref="使徒の働き 12:17; 使徒の働き 22:2; ヨハネの福音書 5:2"> 千人隊長がそれを許したので、パウロは階段の上に立ち、民衆に向かって手を振った。そして、すっかり静かになったとき、彼はヘブル語で次のように話した。</span>

<span className="v" id="v1" data-v="1" data-xref="マタイの福音書 24:9; ヨハネの福音書 15:20; マタイの福音書 10:17–18"> そのころ、ヘロデ王は、教会の中のある人々を苦しめようとして、その手を伸ばし、</span>
<span className="v" id="v2" data-v="2" data-xref="ヘブル人への手紙 11:37; マタイの福音書 20:23; マタイの福音書 4:21–22"> ヨハネの兄弟ヤコブを剣で殺した。</span>
<span className="v" id="v3" data-v="3" data-xref="Exodus 23:15; ヨハネの福音書 12:43; 使徒の働き 24:27"> それがユダヤ人の気に入ったのを見て、次にはペテロをも捕えにかかった。それは、種なしパンの祝いの時期であった。</span>
<span className="v" id="v4" data-v="4" data-xref="Proverbs 19:21; ルカの福音書 22:33; ルカの福音書 21:12"> ヘロデはペテロを捕えて牢に入れ、四人一組の兵士四組に引き渡して監視させた。それは、過越の祭りの後に、民の前に引き出す考えであったからである。</span>
<span className="v" id="v5" data-v="5" data-xref="コリント人への手紙第一 12:26; テサロニケ人への手紙第一 5:17; ヤコブの手紙 5:16"> こうしてペテロは牢に閉じ込められていた。教会は彼のために、神に熱心に祈り続けていた。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒の働き 21:33; ヘブル人への手紙 13:6; ピリピ人への手紙 4:6–7"> ところでヘロデが彼を引き出そうとしていた日の前夜、ペテロは二本の鎖につながれてふたりの兵士の間で寝ており、戸口には番兵たちが牢を監視していた。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒の働き 5:19; 使徒の働き 16:26; Psalms 146:7"> すると突然、主の御使いが現われ、光が牢を照らした。御使いはペテロのわき腹をたたいて彼を起こし、「急いで立ち上がりなさい。」と言った。すると、鎖が彼の手から落ちた。</span>
<span className="v" id="v8" data-v="8"> そして御使いが、「帯を締めて、くつをはきなさい。」と言うので、彼はそのとおりにした。すると、「上着を着て、私について来なさい。」と言った。</span>
<span className="v" id="v9" data-v="9" data-xref="Psalms 126:1; ヘブル人への手紙 11:8; Genesis 45:26"> そこで、外に出て、御使いについて行った。彼には御使いのしている事が現実の事だとはわからず、幻を見ているのだと思われた。</span>
<span className="v" id="v10" data-v="10" data-xref="使徒の働き 5:19; 使徒の働き 16:26; Isaiah 45:1–2"> 彼らが、第一、第二の衛所を通り、町に通じる鉄の門まで来ると、門がひとりでに開いた。そこで、彼らは外に出て、ある通りを進んで行くと、御使いは、たちまち彼を離れた。</span>
<span className="v" id="v11" data-v="11" data-xref="Daniel 6:22; Daniel 3:28; ペテロの手紙第二 2:9"> そのとき、ペテロは我に返って言った。「今、確かにわかった。主は御使いを遣わして、ヘロデの手から、また、ユダヤ人たちが待ち構えていたすべての災いから、私を救い出してくださったのだ。」</span>
<span className="v" id="v12" data-v="12" data-xref="ヨハネの手紙第一 5:14–15; 使徒の働き 12:5; マタイの福音書 18:19–20"> こうとわかったので、ペテロは、マルコと呼ばれているヨハネの母マリヤの家へ行った。そこには大ぜいの人が集まって、祈っていた。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒の働き 12:16; ルカの福音書 13:25; ヨハネの福音書 18:16–17"> 彼が入口の戸をたたくと、ロダという女中が応対に出て来た。</span>
<span className="v" id="v14" data-v="14" data-xref="ルカの福音書 24:41; マタイの福音書 28:8"> ところが、ペテロの声だとわかると、喜びのあまり門をあけもしないで、奥へ駆け込み、ペテロが門の外に立っていることをみなに知らせた。</span>
<span className="v" id="v15" data-v="15" data-xref="マタイの福音書 18:10; ルカの福音書 24:11; マルコの福音書 16:14"> 彼らは、「あなたは気が狂っているのだ。」と言ったが、彼女はほんとうだと言い張った。そこで彼らは、「それは彼の御使いだ。」と言っていた。</span>
<span className="v" id="v16" data-v="16"> しかし、ペテロはたたき続けていた。彼らが門をあけると、そこにペテロがいたので、非常に驚いた。</span>
<span className="v" id="v17" data-v="17" data-xref="使徒の働き 21:40; 使徒の働き 13:16; 使徒の働き 19:33"> しかし彼は、手ぶりで彼らを静かにさせ、主がどのようにして牢から救い出してくださったかを、彼らに話して聞かせた。それから、「このことをヤコブと兄弟たちに知らせてください。」と言って、ほかの所へ出て行った。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒の働き 5:22–25; 使徒の働き 16:27; 使徒の働き 19:23"> さて、朝になると、ペテロはどうなったのかと、兵士たちの間に大騒ぎが起こった。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒の働き 16:27; Psalms 37:32–33; ヨハネの福音書 12:10–11"> ヘロデは彼を捜したが見つけることができないので、番兵たちを取り調べ、彼らを処刑するように命じ、そして、ユダヤからカイザリヤに下って行って、そこに滞在した。</span>
<span className="v" id="v20" data-v="20" data-xref="Ezra 3:7; マタイの福音書 11:21–22; Ezekiel 27:17"> さて、ヘロデはツロとシドンの人々に対して強い敵意を抱いていた。そこで彼らはみなでそろって彼をたずね、王の侍従ブラストに取り入って和解を求めた。その地方は王の国から食糧を得ていたからである。</span>
<span className="v" id="v21" data-v="21"> 定められた日に、ヘロデは王服を着けて、王座に着き、彼らに向かって演説を始めた。</span>
<span className="v" id="v22" data-v="22" data-xref="使徒の働き 14:10–13; ヨハネの黙示録 13:4; ユダの手紙 1:16"> そこで民衆は、「神の声だ。人間の声ではない。」と叫び続けた。</span>
<span className="v" id="v23" data-v="23" data-xref="Psalms 115:1; 使徒の働き 10:25–26; テサロニケ人への手紙第二 2:4"> するとたちまち、主の使いがヘロデを打った。ヘロデが神に栄光を帰さなかったからである。彼は虫にかまれて息が絶えた。</span>
<span className="v" id="v24" data-v="24" data-xref="使徒の働き 6:7; 使徒の働き 19:20; テサロニケ人への手紙第二 3:1"> 主のみことばは、ますます盛んになり、広まって行った。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒の働き 12:12; ペテロの手紙第一 5:13; 使徒の働き 15:37"> 任務を果たしたバルナバとサウロは、マルコと呼ばれるヨハネを連れて、エルサレムから帰って来た。</span>

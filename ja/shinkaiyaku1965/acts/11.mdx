<span className="v" id="v1" data-v="1" data-xref="Psalms 22:27; Malachi 1:11; Isaiah 32:15"> さて、使徒たちやユダヤにいる兄弟たちは、異邦人たちも神のみことばを受け入れた、ということを耳にした。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒の働き 10:45; 使徒の働き 10:9; 使徒の働き 15:1"> そこで、ペテロがエルサレムに上ったとき、割礼を受けた者たちは、彼を非難して、</span>
<span className="v" id="v3" data-v="3" data-xref="使徒の働き 10:28; ガラテヤ人への手紙 2:12; ルカの福音書 15:2"> 「あなたは割礼のない人々のところに行って、彼らといっしょに食事をした。」と言った。</span>
<span className="v" id="v4" data-v="4" data-xref="ルカの福音書 1:3; 使徒の働き 14:27; Joshua 22:21–31"> そこでペテロは口を開いて、事の次第を順序正しく説明して言った。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒の働き 10:9–32; 使徒の働き 9:10; 使徒の働き 22:17"> 「私がヨッパの町で祈っていると、うっとりと夢ごこちになり、幻を見ました。四隅をつり下げられた大きな敷布のような入れ物が天から降りて来て、私のところに届いたのです。</span>
<span className="v" id="v6" data-v="6" data-xref="ルカの福音書 4:20; 使徒の働き 3:4"> その中をよく見ると、地の四つ足の獣、野獣、はうもの、空の鳥などが見えました。</span>
<span className="v" id="v7" data-v="7"> そして、『ペテロ。さあ、ほふって食べなさい。』と言う声を聞きました。</span>
<span className="v" id="v8" data-v="8" data-xref="ローマ人への手紙 14:14; Hosea 9:3; コリント人への手紙第一 7:14"> しかし私は、『主よ。それはできません。私はまだ一度も、きよくない物や汚れた物を食べたことがありません。』と言いました。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒の働き 15:9; ヘブル人への手紙 9:13–14; 使徒の働き 10:34–35"> すると、もう一度天から声がして、『神がきよめた物を、きよくないと言ってはならない。』というお答えがありました。</span>
<span className="v" id="v10" data-v="10" data-xref="ヨハネの福音書 21:17; Numbers 24:10; コリント人への手紙第二 12:8"> こんなことが三回あって後、全部の物がまた天へ引き上げられました。</span>
<span className="v" id="v11" data-v="11" data-xref="Exodus 4:27; 使徒の働き 9:10–12; Exodus 4:14"> すると、どうでしょう。ちょうどそのとき、カイザリヤから私のところへ遣わされた三人の人が、私たちのいた家の前に来ていました。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒の働き 8:29; ローマ人への手紙 3:22; テサロニケ人への手紙第二 2:2"> そして御霊は私に、ためらわずにその人たちといっしょに行くように、と言われました。そこで、この六人の兄弟たちも私に同行して、私たちはその人の家にはいって行きました。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒の働き 10:30–32; 使徒の働き 10:3–6; 使徒の働き 9:43"> その人が私たちに告げたところによると、彼は御使いを見ましたが、御使いは彼の家の中に立って、『ヨッパに使いをやって、ペテロと呼ばれるシモンを招きなさい。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒の働き 16:15; 使徒の働き 10:22; 使徒の働き 16:31–34"> その人があなたとあなたの家にいるすべての人を救うことばを話してくれます。』と言ったというのです。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒の働き 19:6; 使徒の働き 10:34–46; 使徒の働き 2:2–12"> そこで私が話し始めていると、聖霊が、あの最初のとき私たちにお下りになったと同じように、彼らの上にもお下りになったのです。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒の働き 1:5; マルコの福音書 1:8; Proverbs 1:23"> 私はそのとき、主が、『ヨハネは水でバプテスマを授けたが、あなたがたは、聖霊によってバプテスマを授けられる。』と言われたみことばを思い起こしました。</span>
<span className="v" id="v17" data-v="17" data-xref="使徒の働き 10:47; ローマ人への手紙 9:20–26; Daniel 4:35"> こういうわけですから、私たちが主イエス・キリストを信じたとき、神が私たちに下さったのと同じ賜物を、彼らにもお授けになったのなら、どうして私などが神のなさることを妨げることができましょう。」</span>
<span className="v" id="v18" data-v="18" data-xref="ローマ人への手紙 10:12–13; コリント人への手紙第二 7:10; Ezekiel 36:26"> 人々はこれを聞いて沈黙し、「それでは、神は、いのちに至る悔い改めを異邦人にもお与えになったのだ。」と言って、神をほめたたえた。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒の働き 4:36; 使徒の働き 21:2; 使徒の働き 15:3"> さて、ステパノのことから起こった迫害によって散らされた人々は、フェニキヤ、キプロス、アンテオケまでも進んで行ったが、ユダヤ人以外の者にはだれにも、みことばを語らなかった。</span>
<span className="v" id="v20" data-v="20" data-xref="マタイの福音書 27:32; 使徒の働き 13:1; コリント人への手紙第一 1:23–24"> ところが、その中にキプロス人とクレネ人が幾人かいて、アンテオケに来てからはギリシヤ人にも語りかけ、主イエスのことを宣べ伝えた。</span>
<span className="v" id="v21" data-v="21" data-xref="ルカの福音書 1:66; 使徒の働き 2:47; 使徒の働き 5:14"> そして、主の御手が彼らとともにあったので、大ぜいの人が信じて主に立ち返った。</span>
<span className="v" id="v22" data-v="22" data-xref="使徒の働き 9:27; 使徒の働き 8:14; 使徒の働き 13:1–3"> この知らせが、エルサレムにある教会に聞こえたので、彼らはバルナバをアンテオケに派遣した。</span>
<span className="v" id="v23" data-v="23" data-xref="コリント人への手紙第一 15:58; 使徒の働き 14:22; 使徒の働き 13:43"> 彼はそこに到着したとき、神の恵みを見て喜び、みなが心を堅く保って、常に主にとどまっているようにと励ました。</span>
<span className="v" id="v24" data-v="24" data-xref="使徒の働き 11:21; 使徒の働き 5:14; 使徒の働き 9:31"> 彼はりっぱな人物で、聖霊と信仰に満ちている人であった。こうして、大ぜいの人が主に導かれた。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒の働き 9:11; 使徒の働き 9:27; 使徒の働き 9:30"> バルナバはサウロを捜しにタルソへ行き、</span>
<span className="v" id="v26" data-v="26" data-xref="ペテロの手紙第一 4:16; 使徒の働き 26:28; ペテロの手紙第一 4:14"> 彼に会って、アンテオケに連れて来た。そして、まる一年の間、彼らは教会に集まり、大ぜいの人たちを教えた。弟子たちは、アンテオケで初めて、キリスト者と呼ばれるようになった。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒の働き 13:1; コリント人への手紙第一 12:28; エペソ人への手紙 4:11"> そのころ、預言者たちがエルサレムからアンテオケに下って来た。</span>
<span className="v" id="v28" data-v="28" data-xref="使徒の働き 21:10; 使徒の働き 18:2; ルカの福音書 3:1"> その中のひとりでアガボという人が立って、世界中に大ききんが起こると御霊によって預言したが、はたしてそれがクラウデオの治世に起こった。</span>
<span className="v" id="v29" data-v="29" data-xref="コリント人への手紙第二 8:12–14; ガラテヤ人への手紙 2:10; コリント人への手紙第二 8:2–4"> そこで、弟子たちは、それぞれの力に応じて、ユダヤに住んでいる兄弟たちに救援の物を送ることに決めた。</span>
<span className="v" id="v30" data-v="30" data-xref="使徒の働き 14:23; 使徒の働き 12:25; 使徒の働き 15:4"> 彼らはそれを実行して、バルナバとサウロの手によって長老たちに送った。</span>

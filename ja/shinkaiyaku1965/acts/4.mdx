<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ルカの福音書 22:4; 使徒の働き 6:12; 使徒の働き 23:6–9"> 彼らが民に話していると、祭司たち、宮の守衛長、またサドカイ人たちがやって来たが、</span>
<span className="v" id="v2" data-v="2" data-xref="使徒の働き 17:18; テサロニケ人への手紙第一 4:13–14; 使徒の働き 24:14–15"> この人たちは、ペテロとヨハネが民を教え、イエスのことを例にあげて死者の復活を宣べ伝えているのに、困り果て、</span>
<span className="v" id="v3" data-v="3" data-xref="使徒の働き 5:18; マタイの福音書 10:16–17; 使徒の働き 16:19–24"> 彼らに手をかけて捕えた。そして翌日まで留置することにした。すでに夕方だったからである。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒の働き 2:41; コリント人への手紙第二 2:14–17; テモテへの手紙第二 2:9–10"> しかし、みことばを聞いた人々が大ぜい信じ、男の数が五千人ほどになった。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒の働き 4:8; マタイの福音書 27:1–2; ルカの福音書 20:1"> 翌日、民の指導者、長老、学者たちは、エルサレムに集まった。</span>
<span className="v" id="v6" data-v="6" data-xref="ルカの福音書 3:2; ヨハネの福音書 18:24; マタイの福音書 26:3"> 大祭司アンナス、カヤパ、ヨハネ、アレキサンデル、そのほか大祭司の一族もみな出席した。</span>
<span className="v" id="v7" data-v="7" data-xref="マタイの福音書 21:23; マルコの福音書 11:28; 使徒の働き 5:40"> 彼らは使徒たちを真中に立たせて、「あなたがたは何の権威によって、また、だれの名によってこんなことをしたのか。」と尋問しだした。</span>
<span className="v" id="v8" data-v="8" data-xref="ルカの福音書 12:11–12; マタイの福音書 10:19–20; 使徒の働き 2:4"> そのとき、ペテロは聖霊に満たされて、彼らに言った。「民の指導者たち、ならびに長老の方々。</span>
<span className="v" id="v9" data-v="9" data-xref="ペテロの手紙第一 3:15–17; 使徒の働き 3:7; ヨハネの福音書 10:32"> 私たちがきょう取り調べられているのが、病人に行なった良いわざについてであり、その人が何によっていやされたか、ということのためであるなら、</span>
<span className="v" id="v10" data-v="10" data-xref="使徒の働き 5:29–32; 使徒の働き 3:6; 使徒の働き 2:36"> 皆さんも、またイスラエルのすべての人々も、よく知ってください。この人が直って、あなたがたの前に立っているのは、あなたがたが十字架につけ、神が死者の中からよみがえらせたナザレ人イエス・キリストの御名によるのです。</span>
<span className="v" id="v11" data-v="11" data-xref="Psalms 118:22–23; Isaiah 28:16; マルコの福音書 12:10–12"> 『あなたがた家を建てる者たちに捨てられた石が、礎の石となった。』というのはこの方のことです。</span>
<span className="v" id="v12" data-v="12" data-xref="ヨハネの福音書 14:6; コリント人への手紙第一 3:11; ヨハネの福音書 3:36"> この方以外には、だれによっても救いはありません。世界中でこの御名のほかには、私たちが救われるべき名としては、どのような名も、人間に与えられていないからです。」</span>
<span className="v" id="v13" data-v="13" data-xref="コリント人への手紙第一 1:27; ヨハネの福音書 7:15; マタイの福音書 11:25"> 彼らはペテロとヨハネとの大胆さを見、またふたりが無学な、普通の人であるのを知って驚いたが、ふたりがイエスとともにいたのだ、ということがわかって来た。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒の働き 19:36; 使徒の働き 3:8–12; 使徒の働き 4:21"> そればかりでなく、いやされた人がふたりといっしょに立っているのを見ては、返すことばもなかった。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒の働き 26:30–32; 使徒の働き 5:34–42; マタイの福音書 5:22"> 彼らはふたりに議会から退場するように命じ、そして互いに協議した。</span>
<span className="v" id="v16" data-v="16" data-xref="ルカの福音書 21:15; 使徒の働き 6:10; ヨハネの福音書 12:18"> 彼らは言った。「あの人たちをどうしよう。あの人たちによって著しいしるしが行なわれたことは、エルサレムの住民全部に知れ渡っているから、われわれはそれを否定できない。</span>
<span className="v" id="v17" data-v="17" data-xref="使徒の働き 5:28; ローマ人への手紙 15:18–22; 使徒の働き 5:24"> しかし、これ以上民の間に広がらないために、今後だれにもこの名によって語ってはならないと、彼らをきびしく戒めよう。」</span>
<span className="v" id="v18" data-v="18" data-xref="使徒の働き 5:40; ルカの福音書 24:46–48; 使徒の働き 5:20"> そこで彼らを呼んで、いっさいイエスの名によって語ったり教えたりしてはならない、と命じた。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒の働き 5:29; Exodus 1:17; コリント人への手紙第一 10:15"> ペテロとヨハネは彼らに答えて言った。「神に聞き従うより、あなたがたに聞き従うほうが、神の前に正しいかどうか、判断してください。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒の働き 22:15; Jeremiah 20:9; コリント人への手紙第一 9:16–17"> 私たちは、自分の見たこと、また聞いたことを、話さないわけにはいきません。」</span>
<span className="v" id="v21" data-v="21" data-xref="使徒の働き 5:26; マタイの福音書 21:46; ルカの福音書 22:2"> そこで、彼らはふたりをさらにおどしたうえで、釈放した。それはみなの者が、この出来事のゆえに神をあがめていたので、人々の手前、ふたりを罰するすべがなかったからである。</span>
<span className="v" id="v22" data-v="22" data-xref="ヨハネの福音書 5:5; 使徒の働き 9:33; ルカの福音書 13:11"> この奇蹟によっていやされた男は四十歳余りであった。</span>
<span className="v" id="v23" data-v="23" data-xref="コリント人への手紙第二 6:14–17; 使徒の働き 12:11–12; Psalms 119:63"> 釈放されたふたりは、仲間のところへ行き、祭司長たちや長老たちが彼らに言ったことを残らず報告した。</span>
<span className="v" id="v24" data-v="24" data-xref="Exodus 20:11; Jeremiah 32:17; Nehemiah 9:6"> これを聞いた人々はみな、心を一つにして、神に向かい、声を上げて言った。「主よ。あなたは天と地と海とその中のすべてのものを造られた方です。</span>
<span className="v" id="v25" data-v="25" data-xref="Psalms 2:1–6; 使徒の働き 1:16; 使徒の働き 2:30"> あなたは、聖霊によって、あなたのしもべであり私たちの先祖であるダビデの口を通して、こう言われました。 『なぜ異邦人たちは騒ぎ立ち、 もろもろの民はむなしいことを計るのか。</span>
<span className="v" id="v26" data-v="26" data-xref="Psalms 2:2; ヨハネの黙示録 17:12–14; Daniel 9:24"> 地の王たちは立ち上がり、 指導者たちは、主とキリストに反抗して、 一つに組んだ。』</span>
<span className="v" id="v27" data-v="27" data-xref="マタイの福音書 27:2; 使徒の働き 4:30; ルカの福音書 9:22"> 事実、ヘロデとポンテオ・ピラトは、異邦人やイスラエルの民といっしょに、あなたが油を注がれた、あなたの聖なるしもべイエスに逆らってこの都に集まり、</span>
<span className="v" id="v28" data-v="28" data-xref="使徒の働き 2:23; Isaiah 46:10; Genesis 50:20"> あなたの御手とみこころによって、あらかじめお定めになったことを行ないました。</span>
<span className="v" id="v29" data-v="29" data-xref="使徒の働き 4:13; 使徒の働き 14:3; ピリピ人への手紙 1:14"> 主よ。いま彼らの脅かしをご覧になり、あなたのしもべたちにみことばを大胆に語らせてください。</span>
<span className="v" id="v30" data-v="30" data-xref="使徒の働き 4:27; 使徒の働き 3:6; 使徒の働き 5:12"> 御手を伸ばしていやしを行なわせ、あなたの聖なるしもべイエスの御名によって、しるしと不思議なわざを行なわせてください。」</span>
<span className="v" id="v31" data-v="31" data-xref="マタイの福音書 21:22; 使徒の働き 2:2; 使徒の働き 2:4"> 彼らがこう祈ると、その集まっていた場所が震い動き、一同は聖霊に満たされ、神のことばを大胆に語りだした。</span>
<span className="v" id="v32" data-v="32" data-xref="コリント人への手紙第一 1:10; エペソ人への手紙 4:2–6; ペテロの手紙第一 3:8"> 信じた者の群れは、心と思いを一つにして、だれひとりその持ち物を自分のものと言わず、すべてを共有にしていた。</span>
<span className="v" id="v33" data-v="33" data-xref="ヨハネの福音書 1:16; 使徒の働き 1:22; 使徒の働き 1:8"> 使徒たちは、主イエスの復活を非常に力強くあかしし、大きな恵みがそのすべての者の上にあった。</span>
<span className="v" id="v34" data-v="34" data-xref="使徒の働き 2:45; ルカの福音書 12:33; ルカの福音書 16:9"> 彼らの中には、ひとりも乏しい者がなかった。地所や家を持っている者は、それを売り、代金を携えて来て、</span>
<span className="v" id="v35" data-v="35" data-xref="使徒の働き 5:2; 使徒の働き 2:45; コリント人への手紙第二 8:20–21"> 使徒たちの足もとに置き、その金は必要に従っておのおのに分け与えられたからである。</span>
<span className="v" id="v36" data-v="36" data-xref="ガラテヤ人への手紙 2:9; ガラテヤ人への手紙 2:13; ガラテヤ人への手紙 2:1"> キプロス生まれのレビ人で、使徒たちによってバルナバ（訳すと、慰めの子）と呼ばれていたヨセフも、</span>
<span className="v" id="v37" data-v="37" data-xref="使徒の働き 5:1–2; 使徒の働き 4:34–35; マタイの福音書 19:29"> 畑を持っていたので、それを売り、その代金を持って来て、使徒たちの足もとに置いた。</span>

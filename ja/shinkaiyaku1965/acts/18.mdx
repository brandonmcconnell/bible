<span className="v" id="v1" data-v="1" data-xref="コリント人への手紙第一 1:2; テモテへの手紙第二 4:20; コリント人への手紙第二 1:1"> その後、パウロはアテネを去って、コリントへ行った。</span>
<span className="v" id="v2" data-v="2" data-xref="ローマ人への手紙 16:3–4; コリント人への手紙第一 16:19; テモテへの手紙第二 4:19"> ここで、アクラというポント生まれのユダヤ人およびその妻プリスキラに出会った。クラウデオ帝が、すべてのユダヤ人をローマから退去させるように命令したため、近ごろイタリヤから来ていたのである。パウロはふたりのところに行き、</span>
<span className="v" id="v3" data-v="3" data-xref="コリント人への手紙第一 4:12; テサロニケ人への手紙第一 2:9; コリント人への手紙第二 11:9"> 自分も同業者であったので、その家に住んでいっしょに仕事をした。彼らの職業は天幕作りであった。</span>
<span className="v" id="v4" data-v="4" data-xref="コリント人への手紙第二 5:11; 使徒の働き 17:17; 使徒の働き 28:23"> パウロは安息日ごとに会堂で論じ、ユダヤ人とギリシヤ人を承服させようとした。</span>
<span className="v" id="v5" data-v="5" data-xref="コリント人への手紙第二 5:14; 使徒の働き 18:28; 使徒の働き 20:21"> そして、シラスとテモテがマケドニヤから下って来ると、パウロはみことばを教えることに専念し、イエスがキリストであることを、ユダヤ人たちにはっきりと宣言した。</span>
<span className="v" id="v6" data-v="6" data-xref="Ezekiel 33:4; 2 Samuel 1:16; Ezekiel 33:8–9"> しかし、彼らが反抗して暴言を吐いたので、パウロは着物を振り払って、「あなたがたの血は、あなたがたの頭上にふりかかれ。私には責任がない。今から私は異邦人のほうに行く。」と言った。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒の働き 16:14; コロサイ人への手紙 4:11; 使徒の働き 10:2"> そして、そこを去って、神を敬うテテオ・ユストという人の家に行った。その家は会堂の隣であった。</span>
<span className="v" id="v8" data-v="8" data-xref="コリント人への手紙第一 1:13–17; ローマ人への手紙 10:14–17; マルコの福音書 16:15–16"> 会堂管理者クリスポは、一家をあげて主を信じた。また、多くのコリント人も聞いて信じ、バプテスマを受けた。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒の働き 23:11; エペソ人への手紙 6:19–20; 使徒の働き 27:23–25"> ある夜、主は幻によってパウロに、「恐れないで、語り続けなさい。黙ってはいけない。</span>
<span className="v" id="v10" data-v="10" data-xref="コリント人への手紙第二 12:9; Exodus 4:12; Isaiah 41:10"> わたしがあなたとともにいるのだ。だれもあなたを襲って、危害を加える者はない。この町には、わたしの民がたくさんいるから。」と言われた。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒の働き 14:3; 使徒の働き 19:10; 使徒の働き 20:31"> そこでパウロは、一年半ここに腰を据えて、彼らの間で神のことばを教え続けた。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒の働き 13:50; 使徒の働き 18:27; 使徒の働き 13:7"> ところが、ガリオがアカヤの地方総督であったとき、ユダヤ人たちはこぞってパウロに反抗し、彼を法廷に引いて行って、</span>
<span className="v" id="v13" data-v="13" data-xref="使徒の働き 25:8; 使徒の働き 24:5–6; 使徒の働き 6:13"> 「この人は、律法にそむいて神を拝むことを、人々に説き勧めています。」と訴えた。</span>
<span className="v" id="v14" data-v="14" data-xref="ペテロの手紙第一 3:14–15; 使徒の働き 25:11; マルコの福音書 9:19"> パウロが口を開こうとすると、ガリオはユダヤ人に向かってこう言った。「ユダヤ人の諸君。不正事件や悪質な犯罪のことであれば、私は当然、あなたがたの訴えを取り上げもしようが、</span>
<span className="v" id="v15" data-v="15" data-xref="使徒の働き 23:29; 使徒の働き 25:19; テモテへの手紙第一 6:4"> あなたがたの、ことばや名称や律法に関する問題であるなら、自分たちで始末をつけるのがよかろう。私はそのようなことの裁判官にはなりたくない。」</span>
<span className="v" id="v16" data-v="16" data-xref="ヨハネの黙示録 12:16; Psalms 76:10; ローマ人への手紙 13:3–4"> こうして、彼らを法廷から追い出した。</span>
<span className="v" id="v17" data-v="17" data-xref="コリント人への手紙第一 1:1; Amos 6:6; 使徒の働き 17:32"> そこで、みなの者は、会堂管理者ソステネを捕え、法廷の前で打ちたたいた。ガリオは、そのようなことは少しも気にしなかった。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒の働き 21:24; Numbers 6:18; Numbers 6:5–9"> パウロは、なお長らく滞在してから、兄弟たちに別れを告げて、シリヤへ向けて出帆した。プリスキラとアクラも同行した。パウロは一つの誓願を立てていたので、ケンクレヤで髪をそった。</span>
<span className="v" id="v19" data-v="19" data-xref="エペソ人への手紙 1:1; テモテへの手紙第一 1:3; テモテへの手紙第二 1:18"> 彼らがエペソに着くと、パウロはふたりをそこに残し、自分だけ会堂にはいって、ユダヤ人たちと論じた。</span>
<span className="v" id="v20" data-v="20" data-xref="マルコの福音書 1:37–38; コリント人への手紙第一 16:12; 使徒の働き 20:16"> 人々は、もっと長くとどまるように頼んだが、彼は聞き入れないで、</span>
<span className="v" id="v21" data-v="21" data-xref="コリント人への手紙第一 4:19; ヤコブの手紙 4:15; ローマ人への手紙 15:32"> 「神のみこころなら、またあなたがたのところに帰って来ます。」と言って別れを告げ、エペソから船出した。</span>
<span className="v" id="v22" data-v="22" data-xref="使徒の働き 8:40; 使徒の働き 15:4; 使徒の働き 23:23"> それからカイザリヤに上陸してエルサレムに上り、教会にあいさつしてからアンテオケに下って行った。</span>
<span className="v" id="v23" data-v="23" data-xref="使徒の働き 14:22; 使徒の働き 16:6; 使徒の働き 15:41"> そこにしばらくいてから、彼はまた出発し、ガラテヤの地方およびフルギヤを次々に巡って、すべての弟子たちを力づけた。</span>
<span className="v" id="v24" data-v="24" data-xref="コリント人への手紙第一 4:6; テトスへの手紙 3:13; コリント人への手紙第一 3:5–6"> さて、アレキサンドリヤの生まれで、雄弁なアポロというユダヤ人がエペソに来た。彼は聖書に通じていた。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒の働き 19:3; ローマ人への手紙 12:11; Hosea 14:9"> この人は、主の道の教えを受け、霊に燃えて、イエスのことを正確に語り、また教えていたが、ただヨハネのバプテスマしか知らなかった。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒の働き 18:25; 使徒の働き 14:3; コリント人への手紙第一 12:21"> 彼は会堂で大胆に話し始めた。それを聞いていたプリスキラとアクラは、彼を招き入れて、神の道をもっと正確に彼に説明した。</span>
<span className="v" id="v27" data-v="27" data-xref="テサロニケ人への手紙第二 2:13–14; ヤコブの手紙 1:16–18; ペテロの手紙第一 1:2–3"> そして、アポロがアカヤへ渡りたいと思っていたので、兄弟たちは彼を励まし、そこの弟子たちに、彼を歓迎してくれるようにと手紙を書いた。彼はそこに着くと、すでに恵みによって信者になっていた人たちを大いに助けた。</span>
<span className="v" id="v28" data-v="28" data-xref="使徒の働き 18:5; コリント人への手紙第一 15:3–4; 使徒の働き 9:22"> 彼は聖書によって、イエスがキリストであることを証明して、力強く、公然とユダヤ人たちを論破したからである。</span>

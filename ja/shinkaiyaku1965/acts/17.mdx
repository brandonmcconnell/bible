<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="テサロニケ人への手紙第一 1:1; ピリピ人への手紙 4:16; 使徒の働き 20:4"> 彼らはアムピポリスとアポロニヤを通って、テサロニケへ行った。そこには、ユダヤ人の会堂があった。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒の働き 9:20; 使徒の働き 17:17; 使徒の働き 18:4"> パウロはいつもしているように、会堂にはいって行って、三つの安息日にわたり、聖書に基づいて彼らと論じた。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒の働き 18:28; 使徒の働き 9:22; ルカの福音書 24:32"> そして、キリストは苦しみを受け、死者の中からよみがえらなければならないことを説明し、また論証して、「私があなたがたに伝えているこのイエスこそ、キリストなのです。」と言った。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒の働き 17:12; 使徒の働き 13:43; 使徒の働き 14:4"> 彼らのうちの幾人かはよくわかって、パウロとシラスに従った。またほかに、神を敬うギリシヤ人が大ぜいおり、貴婦人たちも少なくなかった。</span>
<span className="v" id="v5" data-v="5" data-xref="ガラテヤ人への手紙 5:26; 使徒の働き 17:13; ローマ人への手紙 16:21"> ところが、ねたみにかられたユダヤ人は、町のならず者をかり集め、暴動を起こして町を騒がせ、またヤソンの家を襲い、ふたりを人々の前に引き出そうとして捜した。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒の働き 24:5; 使徒の働き 16:19–21; 使徒の働き 28:22"> しかし、見つからないので、ヤソンと兄弟たちの幾人かを、町の役人たちのところへひっぱって行き、大声でこう言った。「世界中を騒がせて来た者たちが、ここにもはいり込んでいます。</span>
<span className="v" id="v7" data-v="7" data-xref="ルカの福音書 23:2; 使徒の働き 16:21; ヨハネの福音書 19:12"> それをヤソンが家に迎え入れたのです。彼らはみな、イエスという別の王がいると言って、カイザルの詔勅にそむく行ないをしているのです。」</span>
<span className="v" id="v8" data-v="8" data-xref="マタイの福音書 2:3; ヨハネの福音書 11:48"> こうして、それを聞いた群衆と町の役人たちとを不安に陥れた。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒の働き 17:5"> 彼らは、ヤソンとそのほかの者たちから保証金を取ったうえで釈放した。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="使徒の働き 17:2; テサロニケ人への手紙第一 2:2; 使徒の働き 17:13–14"> 兄弟たちは、すぐさま、夜のうちにパウロとシラスをベレヤへ送り出した。ふたりはそこに着くと、ユダヤ人の会堂にはいって行った。</span>
<span className="v" id="v11" data-v="11" data-xref="Isaiah 34:16; Proverbs 2:1–5; ヨハネの福音書 5:39"> ここのユダヤ人は、テサロニケにいる者たちよりも良い人たちで、非常に熱心にみことばを聞き、はたしてそのとおりかどうかと毎日聖書を調べた。</span>
<span className="v" id="v12" data-v="12" data-xref="エペソ人への手紙 5:14; 使徒の働き 14:1; 使徒の働き 13:50"> そのため、彼らのうちの多くの者が信仰にはいった。その中にはギリシヤの貴婦人や男子も少なくなかった。</span>
<span className="v" id="v13" data-v="13" data-xref="テサロニケ人への手紙第一 2:14–16; Proverbs 28:25; 使徒の働き 6:12"> ところが、テサロニケのユダヤ人たちは、パウロがベレヤでも神のことばを伝えていることを知り、ここにもやって来て、群衆を扇動して騒ぎを起こした。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒の働き 17:10; マタイの福音書 10:23; 使徒の働き 9:25"> そこで兄弟たちは、ただちにパウロを送り出して海べまで行かせたが、シラスとテモテはベレヤに踏みとどまった。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒の働き 18:5; テサロニケ人への手紙第一 3:1; 使徒の働き 18:1"> パウロを案内した人たちは、彼をアテネまで連れて行った。そしてシラスとテモテに一刻も早く来るように、という命令を受けて、帰って行った。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="Psalms 119:158; ペテロの手紙第二 2:7; Psalms 119:136"> さて、アテネでふたりを待っていたパウロは、町が偶像でいっぱいなのを見て、心に憤りを感じた。</span>
<span className="v" id="v17" data-v="17" data-xref="使徒の働き 13:16; 使徒の働き 14:1–4; 使徒の働き 17:2–4"> そこでパウロは、会堂ではユダヤ人や神を敬う人たちと論じ、広場では毎日そこに居合わせた人たちと論じた。</span>
<span className="v" id="v18" data-v="18" data-xref="コリント人への手紙第一 1:20–21; コロサイ人への手紙 2:8; ルカの福音書 11:53"> エピクロス派とストア派の哲学者たちも幾人かいて、パウロと論じ合っていたが、その中のある者たちは、「このおしゃべりは、何を言うつもりなのか。」と言い、ほかの者たちは、「彼は外国の神々を伝えているらしい。」と言った。パウロがイエスと復活とを宣べ伝えたからである。</span>
<span className="v" id="v19" data-v="19" data-xref="マルコの福音書 1:27; 使徒の働き 17:22; 使徒の働き 24:24"> そこで彼らは、パウロをアレオパゴスに連れて行ってこう言った。「あなたの語っているその新しい教えがどんなものであるか、知らせていただけませんか。</span>
<span className="v" id="v20" data-v="20" data-xref="コリント人への手紙第一 1:23; Hosea 8:12; コリント人への手紙第一 2:14"> 私たちにとっては珍しいことを聞かせてくださるので、それがいったいどんなものか、私たちは知りたいのです。」</span>
<span className="v" id="v21" data-v="21" data-xref="テモテへの手紙第二 2:16–17; コロサイ人への手紙 4:5; エペソ人への手紙 5:16"> アテネ人も、そこに住む外国人もみな、何か耳新しいことを話したり、聞いたりすることだけで、日を過ごしていた。</span>
<span className="v" id="v22" data-v="22" data-xref="使徒の働き 25:19; 使徒の働き 19:35; 使徒の働き 17:16"> そこでパウロは、アレオパゴスの真中に立って言った。「アテネの人たち。あらゆる点から見て、私はあなたがたを宗教心にあつい方々だと見ております。</span>
<span className="v" id="v23" data-v="23" data-xref="ヨハネの福音書 4:22; ガラテヤ人への手紙 4:8–9; ヨハネの福音書 17:3"> 私が道を通りながら、あなたがたの拝むものをよく見ているうちに、『知られない神に。』と刻まれた祭壇があるのを見つけました。そこで、あなたがたが知らずに拝んでいるものを、教えましょう。</span>
<span className="v" id="v24" data-v="24" data-xref="1 Kings 8:27; Deuteronomy 10:14; 使徒の働き 7:48"> この世界とその中にあるすべてのものをお造りになった神は、天地の主ですから、手でこしらえた宮などにはお住みになりません。</span>
<span className="v" id="v25" data-v="25" data-xref="Psalms 50:8–13; Genesis 2:7; Isaiah 42:5"> また、何かに不自由なことでもあるかのように、人の手によって仕えられる必要はありません。神は、すべての人に、いのちと息と万物とをお与えになった方だからです。</span>
<span className="v" id="v26" data-v="26" data-xref="Deuteronomy 32:7–8; Genesis 3:20; ローマ人への手紙 5:12–19"> 神は、ひとりの人からすべての国の人々を造り出して、地の全面に住まわせ、それぞれに決められた時代と、その住まいの境界とをお定めになりました。</span>
<span className="v" id="v27" data-v="27" data-xref="Jeremiah 23:23–24; Deuteronomy 4:7; 使徒の働き 14:17"> これは、神を求めさせるためであって、もし探り求めることでもあるなら、神を見いだすこともあるのです。確かに、神は、私たちひとりひとりから遠く離れてはおられません。</span>
<span className="v" id="v28" data-v="28" data-xref="Job 12:10; コロサイ人への手紙 1:17; ヘブル人への手紙 1:3"> 私たちは、神の中に生き、動き、また存在しているのです。あなたがたのある詩人たちも、『私たちもまたその子孫である。』と言ったとおりです。</span>
<span className="v" id="v29" data-v="29" data-xref="Isaiah 40:25; Exodus 20:4; Psalms 115:4–8"> そのように私たちは神の子孫ですから、神を、人間の技術や工夫で造った金や銀や石などの像と同じものと考えてはいけません。</span>
<span className="v" id="v30" data-v="30" data-xref="使徒の働き 14:16; テトスへの手紙 2:11–12; ルカの福音書 24:47"> 神は、そのような無知の時代を見過ごしておられましたが、今は、どこででもすべての人に悔い改めを命じておられます。</span>
<span className="v" id="v31" data-v="31" data-xref="マタイの福音書 25:31–46; ペテロの手紙第二 3:7; ローマ人への手紙 2:16"> なぜなら、神は、お立てになったひとりの人により義をもってこの世界をさばくため、日を決めておられるからです。そして、その方を死者の中からよみがえらせることによって、このことの確証をすべての人にお与えになったのです。」</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="使徒の働き 17:18; 使徒の働き 26:8; 使徒の働き 25:19"> 死者の復活のことを聞くと、ある者たちはあざ笑い、ほかの者たちは、「このことについては、またいつか聞くことにしよう。」と言った。</span>
<span className="v" id="v33" data-v="33"> こうして、パウロは彼らの中から出て行った。</span>
<span className="v" id="v34" data-v="34" data-xref="使徒の働き 17:19; ローマ人への手紙 11:5–6; 使徒の働き 13:48"> しかし、彼につき従って信仰にはいった人たちもいた。それは、アレオパゴスの裁判官デオヌシオ、ダマリスという女、その他の人々であった。</span>
</div>

<span className="v" id="v1" data-v="1" data-xref="Psalms 55:17; 使徒の働き 10:3; 使徒の働き 4:13"> ペテロとヨハネは午後三時の祈りの時間に宮に上って行った。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒の働き 14:8; ヨハネの福音書 9:8; ルカの福音書 16:20"> すると、生まれつき足のきかない男が運ばれて来た。この男は、宮にはいる人たちから施しを求めるために、毎日「美しの門」という名の宮の門に置いてもらっていた。</span>
<span className="v" id="v3" data-v="3"> 彼は、ペテロとヨハネが宮にはいろうとするのを見て、施しを求めた。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒の働き 14:9–10; ヨハネの福音書 11:40; ルカの福音書 4:20"> ペテロは、ヨハネとともに、その男を見つめて、「私たちを見なさい。」と言った。</span>
<span className="v" id="v5" data-v="5"> 男は何かもらえると思って、ふたりに目を注いだ。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒の働き 3:16; 使徒の働き 10:38; 使徒の働き 4:10"> すると、ペテロは、「金銀は私にはない。しかし、私にあるものを上げよう。ナザレのイエス・キリストの名によって、歩きなさい。」と言って、</span>
<span className="v" id="v7" data-v="7" data-xref="マルコの福音書 1:31; マルコの福音書 9:27; 使徒の働き 9:41"> 彼の右手を取って立たせた。するとたちまち、彼の足とくるぶしが強くなり、</span>
<span className="v" id="v8" data-v="8" data-xref="使徒の働き 14:10; Isaiah 35:6; Psalms 107:20–22"> おどり上がってまっすぐに立ち、歩きだした。そして歩いたり、はねたりしながら、神を賛美しつつ、ふたりといっしょに宮にはいって行った。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒の働き 4:21; 使徒の働き 4:16; ルカの福音書 13:17"> 人々はみな、彼が歩きながら、神を賛美しているのを見た。</span>
<span className="v" id="v10" data-v="10" data-xref="使徒の働き 3:2; ヨハネの福音書 5:20; ヨハネの福音書 9:3"> そして、これが、施しを求めるために宮の「美しの門」にすわっていた男だとわかると、この人の身に起こったことに驚き、あきれた。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒の働き 5:12; ヨハネの福音書 10:23; ルカの福音書 8:38"> この人が、ペテロとヨハネにつきまとっている間に、非常に驚いた人々がみないっせいに、ソロモンの廊という回廊にいる彼らのところに、やって来た。</span>
<span className="v" id="v12" data-v="12" data-xref="コリント人への手紙第二 3:5; ヨハネの福音書 3:27–28; Daniel 2:28–30"> ペテロはこれを見て、人々に向かってこう言った。「イスラエル人たち。なぜこのことに驚いているのですか。なぜ、私たちが自分の力とか信仰深さとかによって彼を歩かせたかのように、私たちを見つめるのですか。</span>
<span className="v" id="v13" data-v="13" data-xref="マタイの福音書 22:32; 使徒の働き 7:32; マタイの福音書 27:17–25"> アブラハム、イサク、ヤコブの神、すなわち、私たちの先祖の神は、そのしもべイエスに栄光をお与えになりました。あなたがたは、この方を引き渡し、ピラトが釈放すると決めたのに、その面前でこの方を拒みました。</span>
<span className="v" id="v14" data-v="14" data-xref="マルコの福音書 1:24; 使徒の働き 7:52; ペテロの手紙第一 3:18"> そのうえ、このきよい、正しい方を拒んで、人殺しの男を赦免するように要求し、</span>
<span className="v" id="v15" data-v="15" data-xref="使徒の働き 2:24; ヨハネの黙示録 21:6; 使徒の働き 2:32"> いのちの君を殺しました。しかし、神はこのイエスを死者の中からよみがえらせました。私たちはそのことの証人です。</span>
<span className="v" id="v16" data-v="16" data-xref="マタイの福音書 21:21–22; 使徒の働き 4:10; 使徒の働き 14:9"> そして、このイエスの御名が、その御名を信じる信仰のゆえに、あなたがたがいま見ており知っているこの人を強くしたのです。イエスによって与えられる信仰が、この人を皆さんの目の前で完全なからだにしたのです。</span>
<span className="v" id="v17" data-v="17" data-xref="ルカの福音書 23:34; 使徒の働き 13:27; ヨハネの福音書 16:3"> ですから、兄弟たち。私は知っています。あなたがたは、自分たちの指導者たちと同様に、無知のためにあのような行ないをしたのです。</span>
<span className="v" id="v18" data-v="18" data-xref="Isaiah 53:1–12; 使徒の働き 26:22–23; 使徒の働き 2:23"> しかし、神は、すべての預言者たちの口を通して、キリストの受難をあらかじめ語っておられたことを、このように実現されました。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒の働き 2:38; Isaiah 44:22; Isaiah 43:25"> そういうわけですから、あなたがたの罪をぬぐい去っていただくために、悔い改めて、神に立ち返りなさい。</span>
<span className="v" id="v20" data-v="20" data-xref="マタイの福音書 24:30–36; ヨハネの黙示録 19:11–16; テサロニケ人への手紙第二 2:2"> それは、主の御前から回復の時が来て、あなたがたのためにメシヤと定められたイエスを、主が遣わしてくださるためなのです。</span>
<span className="v" id="v21" data-v="21" data-xref="ローマ人への手紙 8:21; Isaiah 1:26; 使徒の働き 1:11"> このイエスは、神が昔から、聖なる預言者たちの口を通してたびたび語られた、あの万物の改まる時まで、天にとどまっていなければなりません。</span>
<span className="v" id="v22" data-v="22" data-xref="Deuteronomy 18:15–19; 使徒の働き 7:37; ガラテヤ人への手紙 4:4"> モーセはこう言いました。『神である主は、あなたがたのために、私のようなひとりの預言者を、あなたがたの兄弟たちの中からお立てになる。この方があなたがたに語ることはみな聞きなさい。</span>
<span className="v" id="v23" data-v="23" data-xref="Deuteronomy 18:19; ヨハネの福音書 12:48; ヘブル人への手紙 10:28–30"> その預言者に聞き従わない者はだれでも、民の中から滅ぼし絶やされる。』</span>
<span className="v" id="v24" data-v="24" data-xref="使徒の働き 3:21; ルカの福音書 24:27; 1 Samuel 3:20"> また、サムエルをはじめとして、彼に続いて語ったすべての預言者たちも、今の時について宣べました。</span>
<span className="v" id="v25" data-v="25" data-xref="Genesis 22:18; ガラテヤ人への手紙 3:8; 使徒の働き 2:39"> あなたがたは預言者たちの子孫です。また、神がアブラハムに、『あなたの子孫によって、地の諸民族はみな祝福を受ける。』と言って、あなたがたの先祖と結ばれたあの契約の子孫です。</span>
<span className="v" id="v26" data-v="26" data-xref="マタイの福音書 1:21; 使徒の働き 3:22; ユダの手紙 1:24"> 神は、まずそのしもべを立てて、あなたがたにお遣わしになりました。それは、この方があなたがたを祝福して、ひとりひとりをその邪悪な生活から立ち返らせてくださるためなのです。」</span>

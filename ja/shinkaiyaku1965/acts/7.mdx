<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨハネの福音書 18:19–21; マタイの福音書 26:61–62; 使徒の働き 6:13–14"> 大祭司は、「そのとおりか。」と尋ねた。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒の働き 22:1; Genesis 11:31; Psalms 29:3"> そこでステパノは言った。「兄弟たち、父たちよ。聞いてください。私たちの父祖アブラハムが、カランに住む以前まだメソポタミヤにいたとき、栄光の神が彼に現われて、</span>
<span className="v" id="v3" data-v="3" data-xref="Genesis 12:1; ヘブル人への手紙 11:8; Joshua 24:3"> 『あなたの土地とあなたの親族を離れ、わたしがあなたに示す地に行け。』と言われました。</span>
<span className="v" id="v4" data-v="4" data-xref="Genesis 12:4–5; Genesis 11:31–32; Isaiah 41:9"> そこで、アブラハムはカルデヤ人の地を出て、カランに住みました。そして、父の死後、神は彼をそこから今あなたがたの住んでいるこの地にお移しになりましたが、</span>
<span className="v" id="v5" data-v="5" data-xref="Genesis 17:8; Genesis 12:7; Genesis 13:15"> ここでは、足の踏み場となるだけのものさえも、相続財産として彼にお与えになりませんでした。それでも、子どももなかった彼に対して、この地を彼とその子孫に財産として与えることを約束されたのです。</span>
<span className="v" id="v6" data-v="6" data-xref="Genesis 15:13; Exodus 12:40–41; ガラテヤ人への手紙 3:17"> また神は次のようなことを話されました。『彼の子孫は外国に移り住み、四百年間、奴隷にされ、虐待される。』</span>
<span className="v" id="v7" data-v="7" data-xref="Exodus 3:12; Psalms 105:27–36; Nehemiah 9:9–11"> そして、こう言われました。『彼らを奴隷にする国民は、わたしがさばく。その後、彼らはのがれ出て、この所で、わたしを礼拝する。』</span>
<span className="v" id="v8" data-v="8" data-xref="Genesis 35:23–26; Genesis 17:9–14; Genesis 21:1–4"> また神は、アブラハムに割礼の契約をお与えになりました。こうして、彼にイサクが生まれました。彼は八日目にイサクに割礼を施しました。それから、イサクにヤコブが生まれ、ヤコブに十二人の族長が生まれました。</span>
<span className="v" id="v9" data-v="9" data-xref="Genesis 39:2; Psalms 105:17; Isaiah 43:2"> 族長たちはヨセフをねたんで、彼をエジプトに売りとばしました。しかし、神は彼とともにおられ、</span>
<span className="v" id="v10" data-v="10" data-xref="Proverbs 3:4; テモテへの手紙第二 4:18; Proverbs 2:6"> あらゆる患難から彼を救い出し、エジプト王パロの前で、恵みと知恵をお与えになったので、パロは彼をエジプトと王の家全体を治める大臣に任じました。</span>
<span className="v" id="v11" data-v="11" data-xref="Genesis 41:54–57; Genesis 45:11; Genesis 42:5"> ところが、エジプトとカナンとの全地にききんが起こり、大きな災難が襲って来たので、私たちの先祖たちには、食物がなくなりました。</span>
<span className="v" id="v12" data-v="12" data-xref="Genesis 42:1–24; Genesis 43:2"> しかし、ヤコブはエジプトに穀物があると聞いて、初めに私たちの先祖たちを遣わしました。</span>
<span className="v" id="v13" data-v="13" data-xref="Genesis 45:1–18; Genesis 46:31–10"> 二回目のとき、ヨセフは兄弟たちに、自分のことを打ち明け、ヨセフの家族のことがパロに明らかになりました。</span>
<span className="v" id="v14" data-v="14" data-xref="Genesis 46:26–27; Deuteronomy 10:22; Exodus 1:5"> そこで、ヨセフは人をやって、父ヤコブと七十五人の全親族を呼び寄せました。</span>
<span className="v" id="v15" data-v="15" data-xref="Genesis 49:33; Exodus 1:6; Genesis 46:3–7"> ヤコブはエジプトに下り、そこで彼も私たちの先祖たちも死にました。</span>
<span className="v" id="v16" data-v="16" data-xref="Joshua 24:32; Genesis 23:16; Exodus 13:19"> そしてシケムに運ばれ、かねてアブラハムがいくらかの金でシケムのハモルの子から買っておいた墓に葬られました。</span>
<span className="v" id="v17" data-v="17" data-xref="Exodus 1:7–12; 使徒の働き 7:6; 使徒の働き 13:17"> 神がアブラハムにお立てになった約束の時が近づくにしたがって、民はエジプトの中にふえ広がり、</span>
<span className="v" id="v18" data-v="18" data-xref="Exodus 1:8"> ヨセフのことを知らない別の王がエジプトの王位につくときまで続きました。</span>
<span className="v" id="v19" data-v="19" data-xref="Psalms 105:25; Exodus 1:9–22; ヨハネの黙示録 12:4–5"> この王は、私たちの同胞に対して策略を巡らし、私たちの先祖を苦しめて、幼子を捨てさせ、生かしておけないようにしました。</span>
<span className="v" id="v20" data-v="20" data-xref="ヘブル人への手紙 11:23; Exodus 2:2–10; 1 Samuel 16:12"> このようなときに、モーセが生まれたのです。彼は神の目にかなった、かわいらしい子で、三か月の間、父の家で育てられましたが、</span>
<span className="v" id="v21" data-v="21" data-xref="ヘブル人への手紙 11:24; Exodus 2:2–10; Deuteronomy 32:26"> ついに捨てられたのをパロの娘が拾い上げ、自分の子として育てたのです。</span>
<span className="v" id="v22" data-v="22" data-xref="Isaiah 19:11; Daniel 1:17–20; 2 Chronicles 9:22"> モーセはエジプト人のあらゆる学問を教え込まれ、ことばにもわざにも力がありました。</span>
<span className="v" id="v23" data-v="23" data-xref="Exodus 2:11–12; Proverbs 21:1; ヘブル人への手紙 11:24–26"> 四十歳になったころ、モーセはその兄弟であるイスラエル人を、顧みる心を起こしました。</span>
<span className="v" id="v24" data-v="24" data-xref="ヨハネの福音書 18:10–11; 使徒の働き 7:28; ヨハネの福音書 18:25–27"> そして、同胞のひとりが虐待されているのを見て、その人をかばい、エジプト人を打ち倒して、乱暴されているその人の仕返しをしました。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒の働き 15:7; マルコの福音書 9:32; 2 Kings 5:1"> 彼は、自分の手によって神が兄弟たちに救いを与えようとしておられることを、みなが理解してくれるものと思っていましたが、彼らは理解しませんでした。</span>
<span className="v" id="v26" data-v="26" data-xref="Exodus 2:13–15; Proverbs 18:19; ヨハネの手紙第一 3:11–15"> 翌日彼は、兄弟たちが争っているところに現われ、和解させようとして、『あなたがたは、兄弟なのだ。それなのにどうしてお互いに傷つけ合っているのか。』と言いました。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒の働き 7:35; ルカの福音書 12:14; 使徒の働き 7:54"> すると、隣人を傷つけていた者が、モーセを押しのけてこう言いました。『だれがあなたを、私たちの支配者や裁判官にしたのか。</span>
<span className="v" id="v28" data-v="28"> きのうエジプト人を殺したように、私も殺す気か。』</span>
<span className="v" id="v29" data-v="29" data-xref="Exodus 18:2–4; Exodus 2:14–22; Exodus 4:19–20"> このことばを聞いたモーセは、逃げてミデアンの地に身を寄せ、そこで男の子ふたりをもうけました。</span>
<span className="v" id="v30" data-v="30" data-xref="Exodus 3:1–2; 使徒の働き 7:35; Isaiah 43:2"> 四十年たったとき、御使いが、モーセに、シナイ山の荒野で柴の燃える炎の中に現われました。</span>
<span className="v" id="v31" data-v="31" data-xref="Exodus 3:3–4"> その光景を見たモーセは驚いて、それをよく見ようとして近寄ったとき、主の御声が聞こえました。</span>
<span className="v" id="v32" data-v="32" data-xref="Exodus 3:6; マタイの福音書 22:32; Job 4:14"> 『わたしはあなたの先祖の神、アブラハム、イサク、ヤコブの神である。』そこで、モーセは震え上がり、見定める勇気もなくなりました。</span>
<span className="v" id="v33" data-v="33" data-xref="Exodus 3:5; Joshua 5:15; Ecclesiastes 5:1"> すると、主は彼にこう言われたのです。『あなたの足のくつを脱ぎなさい。あなたの立っている所は聖なる地である。</span>
<span className="v" id="v34" data-v="34" data-xref="Exodus 3:7–10; Exodus 4:31; Psalms 106:44"> わたしは、確かにエジプトにいるわたしの民の苦難を見、そのうめき声を聞いたので、彼らを救い出すために下って来た。さあ、行きなさい。わたしはあなたをエジプトに遣わそう。』</span>
<span className="v" id="v35" data-v="35" data-xref="Psalms 118:22–23; ルカの福音書 19:14; Psalms 113:7–8"> 『だれがあなたを支配者や裁判官にしたのか。』と言って人々が拒んだこのモーセを、神は柴の中で彼に現われた御使いの手によって、支配者また解放者としてお遣わしになったのです。</span>
<span className="v" id="v36" data-v="36" data-xref="Exodus 12:41; Exodus 14:21; Exodus 33:1"> この人が、彼らを導き出し、エジプトの地で、紅海で、また四十年間荒野で、不思議なわざとしるしを行ないました。</span>
<span className="v" id="v37" data-v="37" data-xref="Deuteronomy 18:15–19; 使徒の働き 3:22–23; ヨハネの福音書 18:37"> このモーセが、イスラエルの人々に、『神はあなたがたのために、私のようなひとりの預言者を、あなたがたの兄弟たちの中からお立てになる。』と言ったのです。</span>
<span className="v" id="v38" data-v="38" data-xref="ローマ人への手紙 3:2; ヘブル人への手紙 5:12; ペテロの手紙第一 4:11"> また、この人が、シナイ山で彼に語った御使いや私たちの先祖たちとともに、荒野の集会において、生けるみことばを授かり、あなたがたに与えたのです。</span>
<span className="v" id="v39" data-v="39" data-xref="Numbers 14:3–4; Numbers 11:5; Nehemiah 9:16–17"> ところが、私たちの先祖たちは彼に従うことを好まず、かえって彼を退け、エジプトをなつかしく思って、</span>
<span className="v" id="v40" data-v="40" data-xref="Exodus 32:1; Exodus 32:23"> 『私たちに、先立って行く神々を作ってください。私たちをエジプトの地から導き出したモーセは、どうなったのかわかりませんから。』とアロンに言いました。</span>
<span className="v" id="v41" data-v="41" data-xref="Psalms 106:19–21; Nehemiah 9:18; ヨハネの黙示録 9:20"> そのころ彼らは子牛を作り、この偶像に供え物をささげ、彼らの手で作った物を楽しんでいました。</span>
<span className="v" id="v42" data-v="42" data-xref="Amos 5:25–26; Ezekiel 20:39; Jeremiah 19:13"> そこで、神は彼らに背を向け、彼らが天の星に仕えるままにされました。預言者たちの書に書いてあるとおりです。 『イスラエルの家よ。あなたがたは 荒野にいた四十年の間に、 ほふられた獣と供え物とを、 わたしにささげたことがあったか。</span>
<span className="v" id="v43" data-v="43" data-xref="Amos 5:26–27; Exodus 20:4–5; Deuteronomy 5:8–9"> あなたがたは、モロクの幕屋と ロンパの神の星をかついでいた。 それらは、あなたがたが拝むために 作った偶像ではないか。 それゆえ、わたしは、あなたがたを バビロンのかなたへ移す。』</span>
<span className="v" id="v44" data-v="44" data-xref="Exodus 25:40; Exodus 38:21; ヘブル人への手紙 8:5"> 私たちの先祖のためには、荒野にあかしの幕屋がありました。それは、見たとおりの形に造れとモーセに言われた方の命令どおりに、造られていました。</span>
<span className="v" id="v45" data-v="45" data-xref="Psalms 44:2; Joshua 18:1; Joshua 23:9"> 私たちの先祖は、この幕屋を次々に受け継いで、神が先祖たちの前から異邦人を追い払い、その領土を取らせてくださったときには、ヨシュアとともにそれを運び入れ、ついにダビデの時代となりました。</span>
<span className="v" id="v46" data-v="46" data-xref="Psalms 132:1–5; 使徒の働き 13:22; 2 Samuel 7:1–5"> ダビデは神の前に恵みをいただき、ヤコブの神のために御住まいを得たいと願い求めました。</span>
<span className="v" id="v47" data-v="47" data-xref="1 Kings 8:20; 1 Kings 6:37–38; 2 Samuel 7:13"> けれども、神のために家を建てたのはソロモンでした。</span>
<span className="v" id="v48" data-v="48" data-xref="使徒の働き 17:24–25; Isaiah 66:1–2; 1 Kings 8:27"> しかし、いと高き方は、手で造った家にはお住みになりません。預言者が語っているとおりです。</span>
<span className="v" id="v49" data-v="49" data-xref="Isaiah 66:1; Psalms 11:4; ヨハネの福音書 4:21"> 『主は言われる。 天はわたしの王座、 地はわたしの足の足台である。 あなたがたは、どのような家を わたしのために建てようとするのか。 わたしの休む所とは、どこか。</span>
<span className="v" id="v50" data-v="50" data-xref="Jeremiah 32:17; Psalms 33:6–9; 使徒の働き 14:15"> わたしの手が、これらのものを みな、造ったのではないか。』</span>
<span className="v" id="v51" data-v="51" data-xref="Deuteronomy 10:16; エペソ人への手紙 4:30; Isaiah 63:10"> かたくなで、心と耳とに割礼を受けていない人たち。あなたがたは、先祖たちと同様に、いつも聖霊に逆らっているのです。</span>
<span className="v" id="v52" data-v="52" data-xref="マタイの福音書 5:12; 2 Chronicles 36:16; 1 Kings 19:10"> あなたがたの先祖が迫害しなかった預言者がだれかあったでしょうか。彼らは、正しい方が来られることを前もって宣べた人たちを殺したが、今はあなたがたが、この正しい方を裏切る者、殺す者となりました。</span>
<span className="v" id="v53" data-v="53" data-xref="ヘブル人への手紙 2:2; ガラテヤ人への手紙 3:19; 使徒の働き 7:38"> あなたがたは、御使いたちによって定められた律法を受けたが、それを守ったことはありません。」</span>
<span className="v" id="v54" data-v="54" data-xref="使徒の働き 5:33; Psalms 35:16; マタイの福音書 25:30"> 人々はこれを聞いて、はらわたが煮え返る思いで、ステパノに向かって歯ぎしりした。</span>
<span className="v" id="v55" data-v="55" data-xref="マルコの福音書 16:19; ヘブル人への手紙 1:3; コリント人への手紙第二 4:6"> しかし、聖霊に満たされていたステパノは、天を見つめ、神の栄光と、神の右に立っておられるイエスとを見て、</span>
<span className="v" id="v56" data-v="56" data-xref="マタイの福音書 26:64–65; 使徒の働き 10:11; ヨハネの黙示録 11:19"> こう言った。「見なさい。天が開けて、人の子が神の右に立っておられるのが見えます。」</span>
<span className="v" id="v57" data-v="57" data-xref="Zechariah 7:11; Psalms 58:4; 使徒の働き 23:27"> 人々は大声で叫びながら、耳をおおい、いっせいにステパノに殺到した。</span>
<span className="v" id="v58" data-v="58" data-xref="使徒の働き 22:20; 使徒の働き 8:1; 使徒の働き 6:13"> そして彼を町の外に追い出して、石で打ち殺した。証人たちは、自分たちの着物をサウロという青年の足もとに置いた。</span>
<span className="v" id="v59" data-v="59" data-xref="ルカの福音書 23:46; Psalms 31:5; 使徒の働き 22:16"> こうして彼らがステパノに石を投げつけていると、ステパノは主を呼んで、こう言った。「主イエスよ。私の霊をお受けください。」</span>
<span className="v" id="v60" data-v="60" data-xref="マタイの福音書 5:44; ルカの福音書 23:34; コリント人への手紙第一 15:20"> そして、ひざまずいて、大声でこう叫んだ。「主よ。この罪を彼らに負わせないでください。」こう言って、眠りについた。</span>

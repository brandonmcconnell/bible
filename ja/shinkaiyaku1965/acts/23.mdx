<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒の働き 24:16; テモテへの手紙第二 1:3; コリント人への手紙第二 1:12"> パウロは議会を見つめて、こう言った。「兄弟たちよ。私は今日まで、全くきよい良心をもって、神の前に生活して来ました。」</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネの福音書 18:22; 使徒の働き 24:1; Micah 5:1"> すると大祭司アナニヤは、パウロのそばに立っている者たちに、彼の口を打てと命じた。</span>
<span className="v" id="v3" data-v="3" data-xref="Deuteronomy 25:1–2; ヨハネの福音書 7:51; マタイの福音書 23:27–28"> そのとき、パウロはアナニヤに向かってこう言った。「ああ、白く塗った壁。神があなたを打たれる。あなたは、律法に従って私をさばく座に着きながら、律法にそむいて、私を打てと命じるのですか。」</span>
<span className="v" id="v4" data-v="4"> するとそばに立っている者たちが、「あなたは神の大祭司をののしるのか。」と言ったので、</span>
<span className="v" id="v5" data-v="5" data-xref="Exodus 22:28; Ecclesiastes 10:20; ユダの手紙 1:8–9"> パウロが言った。「兄弟たち。私は彼が大祭司だとは知らなかった。確かに、『あなたの民の指導者を悪く言ってはいけない。』と書いてあります。」</span>
<span className="v" id="v6" data-v="6" data-xref="使徒の働き 24:15; 使徒の働き 24:21; 使徒の働き 26:5–8"> しかし、パウロは、彼らの一部がサドカイ人で、一部がパリサイ人であるのを見て取って、議会の中でこう叫んだ。「兄弟たち。私はパリサイ人であり、パリサイ人の子です。私は死者の復活という望みのことで、さばきを受けているのです。」</span>
<span className="v" id="v7" data-v="7" data-xref="Psalms 55:9; ヨハネの福音書 7:40–43; マタイの福音書 10:34"> 彼がこう言うと、パリサイ人とサドカイ人との間に意見の衝突が起こり、議会は二つに割れた。</span>
<span className="v" id="v8" data-v="8" data-xref="ルカの福音書 20:27; マタイの福音書 22:23; マルコの福音書 12:18"> サドカイ人は、復活はなく、御使いも霊もないと言い、パリサイ人は、どちらもあると言っていたからである。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒の働き 22:7; 使徒の働き 22:17–18; ヨハネの福音書 12:29"> 騒ぎがいよいよ大きくなり、パリサイ派のある律法学者たちが立ち上がって激しく論じて、「私たちは、この人に何の悪い点も見いださない。もしかしたら、霊か御使いかが、彼に語りかけたのかもしれない。」と言った。</span>
<span className="v" id="v10" data-v="10" data-xref="ヤコブの手紙 1:19; ヤコブの手紙 3:14–2; 使徒の働き 22:24"> 論争がますます激しくなったので、千人隊長は、パウロが彼らに引き裂かれてしまうのではないかと心配し、兵隊に、下に降りて行って、パウロを彼らの中から力ずくで引き出し、兵営に連れて来るように命じた。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="使徒の働き 18:9; 使徒の働き 19:21; テモテへの手紙第二 4:17"> その夜、主がパウロのそばに立って、「勇気を出しなさい。あなたは、エルサレムでわたしのことをあかししたように、ローマでもあかしをしなければならない。」と言われた。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="使徒の働き 23:30; Isaiah 8:9–10; 使徒の働き 23:21"> 夜が明けると、ユダヤ人たちは徒党を組み、パウロを殺してしまうまでは飲み食いしないと誓い合った。</span>
<span className="v" id="v13" data-v="13" data-xref="ヨハネの福音書 16:2; 2 Samuel 15:31; 2 Samuel 15:12"> この陰謀に加わった者は、四十人以上であった。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒の働き 23:12; Jeremiah 8:12; Isaiah 3:9"> 彼らは、祭司長たち、長老たちのところに行って、こう言った。「私たちは、パウロを殺すまでは何も食べない、と堅く誓い合いました。</span>
<span className="v" id="v15" data-v="15" data-xref="Isaiah 59:7; Psalms 37:32–33; Proverbs 1:16"> そこで、今あなたがたは議会と組んで、パウロのことをもっと詳しく調べるふりをして、彼をあなたがたのところに連れて来るように千人隊長に願い出てください。私たちのほうでは、彼がそこに近づく前に殺す手はずにしています。」</span>
<span className="v" id="v16" data-v="16" data-xref="使徒の働き 23:10; コリント人への手紙第一 3:19; 使徒の働き 23:32"> ところが、パウロの姉妹の子が、この待ち伏せのことを耳にし、兵営にはいってパウロにそれを知らせた。</span>
<span className="v" id="v17" data-v="17" data-xref="Proverbs 22:3; マタイの福音書 8:8–9; マタイの福音書 10:16"> そこでパウロは、百人隊長のひとりを呼んで、「この青年を千人隊長のところに連れて行ってください。お伝えすることがありますから。」と言った。</span>
<span className="v" id="v18" data-v="18" data-xref="エペソ人への手紙 3:1; エペソ人への手紙 4:1; 使徒の働き 28:17"> 百人隊長は、彼を連れて千人隊長のもとに行き、「囚人のパウロが私を呼んで、この青年があなたにお話しすることがあるので、あなたのところに連れて行くようにと頼みました。」と言った。</span>
<span className="v" id="v19" data-v="19" data-xref="Jeremiah 31:32; Esther 9:12; Esther 7:2"> 千人隊長は彼の手を取り、だれもいない所に連れて行って、「私に伝えたいことというのは何か。」と尋ねた。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒の働き 23:14–15; 使徒の働き 23:1; Psalms 12:2"> すると彼はこう言った。「ユダヤ人たちは、パウロについてもっと詳しく調べようとしているかに見せかけて、あす、議会にパウロを連れて来てくださるように、あなたにお願いすることを申し合わせました。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒の働き 23:12–14; 使徒の働き 14:5–6; コリント人への手紙第二 11:26"> どうか、彼らの願いを聞き入れないでください。四十人以上の者が、パウロを殺すまでは飲み食いしない、と誓い合って、彼を待ち伏せしているのです。今、彼らは手はずを整えて、あなたの承諾を待っています。」</span>
<span className="v" id="v22" data-v="22" data-xref="マルコの福音書 1:44; Joshua 2:14"> そこで千人隊長は、「このことを私に知らせたことは、だれにも漏らすな。」と命じて、その青年を帰らせた。</span>
<span className="v" id="v23" data-v="23" data-xref="マタイの福音書 14:25; 使徒の働き 23:33; ルカの福音書 12:38"> そしてふたりの百人隊長を呼び、「今夜九時、カイザリヤに向けて出発できるように、歩兵二百人、騎兵七十人、槍兵二百人を整えよ。」と言いつけた。</span>
<span className="v" id="v24" data-v="24" data-xref="使徒の働き 25:14; 使徒の働き 23:26; 使徒の働き 24:10"> また、パウロを乗せて無事に総督ペリクスのもとに送り届けるように、馬の用意もさせた。</span>
<span className="v" id="v25" data-v="25"> そして、次のような文面の手紙を書いた。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="使徒の働き 15:23; 使徒の働き 26:25; ルカの福音書 1:3"> 「クラウデオ・ルシヤ、つつしんで総督ペリクス閣下にごあいさつ申し上げます。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒の働き 22:25–29; 使徒の働き 21:31–33; 使徒の働き 24:6"> この者が、ユダヤ人に捕えられ、まさに殺されようとしていたとき、彼がローマ市民であることを知りましたので、私は兵隊を率いて行って、彼を助け出しました。</span>
<span className="v" id="v28" data-v="28" data-xref="使徒の働き 22:30"> それから、どんな理由で彼が訴えられたかを知ろうと思い、彼をユダヤ人の議会に出頭させました。</span>
<span className="v" id="v29" data-v="29" data-xref="使徒の働き 26:31; 使徒の働き 25:25; 使徒の働き 18:15"> その結果、彼が訴えられているのは、ユダヤ人の律法に関する問題のためで、死刑や投獄に当たる罪はないことがわかりました。</span>
<span className="v" id="v30" data-v="30" data-xref="使徒の働き 23:35; 使徒の働き 25:16; 使徒の働き 25:5–6"> しかし、この者に対する陰謀があるという情報を得ましたので、私はただちに彼を閣下のもとにお送りし、訴える者たちには、閣下の前で彼のことを訴えるようにと言い渡しておきました。」</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="テモテへの手紙第二 2:3–4; ルカの福音書 7:8; 使徒の働き 23:23–24"> そこで兵士たちは、命じられたとおりにパウロを引き取り、夜中にアンテパトリスまで連れて行き、</span>
<span className="v" id="v32" data-v="32" data-xref="使徒の働き 23:23; 使徒の働き 23:10"> 翌日、騎兵たちにパウロの護送を任せて、兵営に帰った。</span>
<span className="v" id="v33" data-v="33" data-xref="使徒の働き 23:26; 使徒の働き 23:23–24; 使徒の働き 28:16"> 騎兵たちは、カイザリヤに着き、総督に手紙を手渡して、パウロを引き合わせた。</span>
<span className="v" id="v34" data-v="34" data-xref="使徒の働き 21:39; 使徒の働き 25:1; Daniel 2:49"> 総督は手紙を読んでから、パウロに、どの州の者かと尋ね、キリキヤの出であることを知って、</span>
<span className="v" id="v35" data-v="35" data-xref="使徒の働き 23:30; 使徒の働き 25:16; マタイの福音書 27:27"> 「あなたを訴える者が来てから、よく聞くことにしよう。」と言った。そして、ヘロデの官邸に彼を守っておくように命じた。</span>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒の働き 24:11; 使徒の働き 23:2; 使徒の働き 25:2"> 五日の後、大祭司アナニヤは、数人の長老およびテルトロという弁護士といっしょに下って来て、パウロを総督に訴えた。</span>
<span className="v" id="v2" data-v="2" data-xref="Proverbs 29:5; Proverbs 26:28; 使徒の働き 24:26–27"> パウロが呼び出されると、テルトロが訴えを始めてこう言った。<br />「ペリクス閣下。閣下のおかげで、私たちはすばらしい平和を与えられ、また、閣下のご配慮で、この国の改革が進行しておりますが、</span>
<span className="v" id="v3" data-v="3" data-xref="使徒の働き 23:26; 使徒の働き 26:25; ルカの福音書 1:3"> その事実をあらゆる面において、また至る所で認めて、私たちは心から感謝しております。</span>
<span className="v" id="v4" data-v="4" data-xref="ヘブル人への手紙 11:32"> さて、あまりご迷惑をおかけしないように、ごく手短に申し上げますから、ご寛容をもってお聞きくださるようお願いいたします。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒の働き 28:22; 使徒の働き 24:14; 使徒の働き 26:5"> この男は、まるでペストのような存在で、世界中のユダヤ人の間に騒ぎを起こしている者であり、ナザレ人という一派の首領でございます。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒の働き 24:12; 使徒の働き 21:27–32; ヨハネの福音書 18:31"> この男は宮さえもけがそうとしましたので、私たちは彼を捕えました。</span>
<span className="v" id="v7" data-v="7"> 閣下ご自身で、これらすべてのことについて彼をお調べくださいますなら、私たちが彼を訴えております事がらを、おわかりになっていただけるはずです。」</span>
<span className="v" id="v9" data-v="9" data-xref="テサロニケ人への手紙第一 2:16; Micah 7:2–3; Psalms 4:2"> ユダヤ人たちも、この訴えに同調し、全くそのとおりだと言った。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="ペテロの手紙第一 3:15; 1 Samuel 2:25; ルカの福音書 18:2"> そのとき、総督がパウロに、話すようにと合図したので、パウロはこう答えた。<br />「閣下が多年に渡り、この民の裁判をつかさどる方であることを存じておりますので、私は喜んで弁明いたします。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒の働き 24:1; 使徒の働き 21:18; 使徒の働き 23:11"> お調べになればわかることですが、私が礼拝のためにエルサレムに上って来てから、まだ十二日しかたっておりません。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒の働き 25:8; 使徒の働き 28:17; 使徒の働き 24:18"> そして、宮でも会堂でも、また市内でも、私がだれかと論争したり、群衆を騒がせたりするのを見た者はありません。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒の働き 25:7; ペテロの手紙第一 3:16"> いま私を訴えていることについて、彼らは証拠をあげることができないはずです。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒の働き 9:2; ローマ人への手紙 3:21; 使徒の働き 3:13"> しかし、私は、彼らが異端と呼んでいるこの道に従って、私たちの先祖の神に仕えていることを、閣下の前で承認いたします。私は、律法にかなうことと、預言者たちが書いていることとを全部信じています。</span>
<span className="v" id="v15" data-v="15" data-xref="Daniel 12:2; ヨハネの福音書 5:28–29; テサロニケ人への手紙第一 4:14–16"> また、義人も悪人も必ず復活するという、この人たち自身も抱いている望みを、神にあって抱いております。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒の働き 23:1; テモテへの手紙第一 1:5; コリント人への手紙第二 4:2"> そのために、私はいつも、神の前にも人の前にも責められることのない良心を保つように、と最善を尽くしています。</span>
<span className="v" id="v17" data-v="17" data-xref="ガラテヤ人への手紙 2:10; ローマ人への手紙 15:25–28; コリント人への手紙第一 16:1–4"> さて私は、同胞に対して施しをし、また供え物をささげるために、幾年ぶりかで帰って来ました。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒の働き 26:21; 使徒の働き 21:26–30; 使徒の働き 24:12"> その供え物のことで私は清めを受けて宮の中にいたのを彼らに見られたのですが、別に群衆もおらず、騒ぎもありませんでした。ただアジヤから来た幾人かのユダヤ人がおりました。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒の働き 23:30; 使徒の働き 25:16"> もし彼らに、私について何か非難したいことがあるなら、自分で閣下の前に来て訴えるべきです。</span>
<span className="v" id="v20" data-v="20"> でなければ、今ここにいる人々に、議会の前に立っていたときの私にどんな不正を見つけたかを言わせてください。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒の働き 23:6; 使徒の働き 4:2; 使徒の働き 26:6–8"> 彼らの中に立っていたとき、私はただ一言、『死者の復活のことで、私はきょう、あなたがたの前でさばかれているのです。』と叫んだにすぎません。」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="使徒の働き 24:6; 使徒の働き 24:24; 使徒の働き 25:26"> しかしペリクスは、この道について相当詳しい知識を持っていたので、「千人隊長ルシヤが下って来るとき、あなたがたの事件を解決することにしよう。」と言って、裁判を延期した。</span>
<span className="v" id="v23" data-v="23" data-xref="使徒の働き 28:16; 使徒の働き 27:3; Proverbs 16:7"> そして百人隊長に、パウロを監禁するように命じたが、ある程度の自由を与え、友人たちが世話をすることを許した。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="使徒の働き 20:21; ガラテヤ人への手紙 2:16; マルコの福音書 6:20"> 数日後、ペリクスはユダヤ人である妻ドルシラを連れて来て、パウロを呼び出し、キリスト・イエスを信じる信仰について話を聞いた。</span>
<span className="v" id="v25" data-v="25" data-xref="ヨハネの福音書 16:8; ペテロの手紙第一 3:15; 使徒の働き 10:42"> しかし、パウロが正義と節制とやがて来る審判とを論じたので、ペリクスは恐れを感じ、「今は帰ってよい。おりを見て、また呼び出そう。」と言った。</span>
<span className="v" id="v26" data-v="26" data-xref="テモテへの手紙第一 6:9–10; Proverbs 17:23; Isaiah 56:11"> それとともに、彼はパウロから金をもらいたい下心があったので、幾度もパウロを呼び出して話し合った。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒の働き 25:9; 使徒の働き 25:14; 使徒の働き 12:3"> 二年たって後、ポルキオ・フェストがペリクスの後任になったが、ペリクスはユダヤ人に恩を売ろうとして、パウロを牢につないだままにしておいた。</span>
</div>

<span className="v" id="v1" data-v="1" data-xref="使徒の働き 23:34; 使徒の働き 25:5; 使徒の働き 8:40"> フェストは州総督として着任すると、三日後にカイザリヤからエルサレムに上った。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒の働き 25:15; Proverbs 4:16; 使徒の働き 24:1"> すると、祭司長たちとユダヤ人のおもだった者たちが、パウロのことを訴え出て、</span>
<span className="v" id="v3" data-v="3" data-xref="使徒の働き 9:24; 使徒の働き 23:12–15; 1 Samuel 23:19–21"> パウロを取り調べる件について自分たちに好意を持ってくれるように頼み、パウロをエルサレムに呼び寄せていただきたいと彼に懇願した。彼らはパウロを途中で殺害するために待ち伏せをさせていた。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒の働き 24:23"> ところが、フェストは、パウロはカイザリヤに拘置されているし、自分はまもなく出発の予定であると答え、</span>
<span className="v" id="v5" data-v="5" data-xref="使徒の働き 25:25; ヨハネの福音書 18:29–30; 使徒の働き 25:18–19"> 「だから、その男に何か不都合なことがあるなら、あなたがたのうちの有力な人たちが、私といっしょに下って行って、彼を告訴しなさい。」と言った。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒の働き 25:17; 使徒の働き 25:10; マタイの福音書 27:19"> フェストは、彼らのところに八日あるいは十日ばかり滞在しただけで、カイザリヤへ下って行き、翌日、裁判の席に着いて、パウロの出廷を命じた。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒の働き 24:13; ルカの福音書 23:10; 使徒の働き 25:24"> パウロが出て来ると、エルサレムから下って来たユダヤ人たちは、彼を取り囲んで立ち、多くの重い罪状を申し立てたが、それを証拠立てることはできなかった。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒の働き 24:12; 使徒の働き 28:17; コリント人への手紙第二 1:12"> しかしパウロは弁明して、「私は、ユダヤ人の律法に対しても、宮に対しても、またカイザルに対しても、何の罪も犯してはおりません。」と言った。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒の働き 24:27; 使徒の働き 12:3; 使徒の働き 25:20"> ところが、ユダヤ人の歓心を買おうとしたフェストは、パウロに向かって、「あなたはエルサレムに上り、この事件について、私の前で裁判を受けることを願うか。」と尋ねた。</span>
<span className="v" id="v10" data-v="10" data-xref="マタイの福音書 27:18; コリント人への手紙第二 4:2; 使徒の働き 28:18"> すると、パウロはこう言った。「私はカイザルの法廷に立っているのですから、ここで裁判を受けるのが当然です。あなたもよくご存じのとおり、私はユダヤ人にどんな悪いこともしませんでした。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒の働き 28:19; 使徒の働き 26:32; 使徒の働き 25:25"> もし私が悪いことをして、死罪に当たることをしたのでしたら、私は死をのがれようとはしません。しかし、この人たちが私を訴えていることに一つも根拠がないとすれば、だれも私を彼らに引き渡すことはできません。私はカイザルに上訴します。」</span>
<span className="v" id="v12" data-v="12" data-xref="使徒の働き 19:21; ピリピ人への手紙 1:12–14; ピリピ人への手紙 1:20"> そのとき、フェストは陪席の者たちと協議したうえで、こう答えた。「あなたはカイザルに上訴したのだから、カイザルのもとへ行きなさい。」</span>
<span className="v" id="v13" data-v="13" data-xref="使徒の働き 8:40; 使徒の働き 26:1; 使徒の働き 26:27–28"> 数日たってから、アグリッパ王とベルニケが、フェストに敬意を表するためにカイザリヤに来た。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒の働き 24:27"> ふたりがそこに長く滞在していたので、フェストはパウロの一件を王に持ち出してこう言った。「ペリクスが囚人として残して行ったひとりの男がおります。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒の働き 25:1–3; Esther 3:9; ルカの福音書 18:3–5"> 私がエルサレムに行ったとき、祭司たちとユダヤ人の長老たちとが、その男のことを私に訴え出て、罪に定めるように要求しました。</span>
<span className="v" id="v16" data-v="16" data-xref="ヨハネの福音書 7:51; Deuteronomy 19:17–18; 使徒の働き 23:30"> そのとき私は、『被告が、彼を訴えた者の面前で訴えに対して弁明する機会を与えられないで、そのまま引き渡されるということはローマの慣例ではない。』と答えておきました。</span>
<span className="v" id="v17" data-v="17" data-xref="使徒の働き 25:6; 使徒の働き 25:10"> そういうわけで、訴える者たちがここに集まったとき、私は時を移さず、その翌日、裁判の席に着いて、その男を出廷させました。</span>
<span className="v" id="v18" data-v="18"> 訴えた者たちは立ち上がりましたが、私が予期していたような犯罪についての訴えは何一つ申し立てませんでした。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒の働き 23:29; 使徒の働き 18:15; コリント人への手紙第一 15:3–4"> ただ、彼と言い争っている点は、彼ら自身の宗教に関することであり、また、死んでしまったイエスという者のことで、そのイエスが生きているとパウロは主張しているのでした。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒の働き 25:9"> このような問題をどう取り調べたらよいか、私には見当がつかないので、彼に『エルサレムに上り、そこで、この事件について裁判を受けたいのか。』と尋ねたところが、</span>
<span className="v" id="v21" data-v="21" data-xref="テモテへの手紙第二 4:16; ルカの福音書 2:1; 使徒の働き 25:10–11"> パウロは、皇帝の判決を受けるまで保護してほしいと願い出たので、彼をカイザルのもとに送る時まで守っておくように、命じておきました。」</span>
<span className="v" id="v22" data-v="22" data-xref="使徒の働き 9:15; マタイの福音書 10:18; Isaiah 52:15"> すると、アグリッパがフェストに、「私も、その男の話を聞きたいものです。」と言ったので、フェストは、「では、明日お聞きください。」と言った。</span>
<span className="v" id="v23" data-v="23" data-xref="使徒の働き 26:30; 使徒の働き 25:13; ヨハネの手紙第一 2:16"> こういうわけで、翌日、アグリッパとベルニケは、大いに威儀を整えて到着し、千人隊長たちや市の首脳者たちにつき添われて講堂にはいった。そのとき、フェストの命令によってパウロが連れて来られた。</span>
<span className="v" id="v24" data-v="24" data-xref="使徒の働き 22:22; 使徒の働き 25:7; 使徒の働き 25:2–3"> そこで、フェストはこう言った。「アグリッパ王、ならびに、ここに同席の方々。ご覧ください。ユダヤ人がこぞって、一刻も生かしてはおけないと呼ばわり、エルサレムでも、ここでも、私に訴えて来たのは、この人のことです。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒の働き 23:29; 使徒の働き 25:11–12; ルカの福音書 23:4"> 私としては、彼は死に当たることは何一つしていないと思います。しかし、彼自身が皇帝に上訴しましたので、彼をそちらに送ることに決めました。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒の働き 26:2–3"> ところが、彼について、わが君に書き送るべき確かな事がらが一つもないのです。それで皆さんの前に、わけてもアグリッパ王よ、あなたの前に、彼を連れてまいりました。取り調べをしてみたら、何か書き送るべきことが得られましょう。</span>
<span className="v" id="v27" data-v="27" data-xref="ヨハネの福音書 7:51; Proverbs 18:13"> 囚人を送るのに、その訴えの個条を示さないのは、理に合わないと思うのです。」</span>

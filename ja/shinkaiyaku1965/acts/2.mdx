<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ローマ人への手紙 15:6; ピリピ人への手紙 2:2; 使徒の働き 1:13–15"> 五旬節の日になって、みなが一つ所に集まっていた。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒の働き 4:31; 1 Kings 19:11; Psalms 18:10"> すると突然、天から、激しい風が吹いて来るような響きが起こり、彼らのいた家全体に響き渡った。</span>
<span className="v" id="v3" data-v="3" data-xref="マタイの福音書 3:11; ヨハネの福音書 1:32–33; Jeremiah 23:29"> また、炎のような分かれた舌が現われて、ひとりひとりの上にとどまった。</span>
<span className="v" id="v4" data-v="4" data-xref="マルコの福音書 16:17; 使徒の働き 13:52; 使徒の働き 4:31"> すると、みなが聖霊に満たされ、御霊が話させてくださるとおりに、他国のことばで話しだした。</span>
<span className="v" id="v5" data-v="5" data-xref="ルカの福音書 2:25; 使徒の働き 8:2; コロサイ人への手紙 1:23"> さて、エルサレムには、敬虔なユダヤ人たちが、天下のあらゆる国から来て住んでいたが、</span>
<span className="v" id="v6" data-v="6" data-xref="マタイの福音書 2:3; コリント人への手紙第一 16:9; 使徒の働き 2:2"> この物音が起こると、大ぜいの人々が集まって来た。彼らは、それぞれ自分の国のことばで弟子たちが話すのを聞いて、驚きあきれてしまった。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒の働き 2:12; 使徒の働き 1:11; ヨハネの福音書 7:52"> 彼らは驚き怪しんで言った。「どうでしょう。いま話しているこの人たちは、みなガリラヤの人ではありませんか。</span>
<span className="v" id="v8" data-v="8"> それなのに、私たちめいめいの国の国語で話すのを聞くとは、いったいどうしたことでしょう。</span>
<span className="v" id="v9" data-v="9" data-xref="ペテロの手紙第一 1:1; 使徒の働き 18:2; ヨハネの黙示録 1:4"> 私たちは、パルテヤ人、メジヤ人、エラム人、またメソポタミヤ、ユダヤ、カパドキヤ、ポントとアジヤ、</span>
<span className="v" id="v10" data-v="10" data-xref="使徒の働き 16:6; Zechariah 8:23; Zechariah 8:20"> フルギヤとパンフリヤ、エジプトとクレネに近いリビヤ地方などに住む者たち、また滞在中のローマ人たちで、</span>
<span className="v" id="v11" data-v="11" data-xref="コリント人への手紙第一 12:10; Exodus 15:11; Psalms 78:4"> ユダヤ人もいれば改宗者もいる。またクレテ人とアラビヤ人なのに、あの人たちが、私たちのいろいろな国ことばで神の大きなみわざを語るのを聞こうとは。」</span>
<span className="v" id="v12" data-v="12" data-xref="ルカの福音書 15:26; 使徒の働き 17:20; ルカの福音書 18:36"> 人々はみな、驚き惑って、互いに「いったいこれはどうしたことか。」と言った。</span>
<span className="v" id="v13" data-v="13" data-xref="コリント人への手紙第一 14:23; 使徒の働き 2:15; 1 Samuel 1:14"> しかし、ほかに「彼らは甘いぶどう酒に酔っているのだ。」と言ってあざける者たちもいた。</span>
<span className="v" id="v14" data-v="14" data-xref="Isaiah 51:7; Isaiah 51:1; Deuteronomy 27:9"> そこで、ペテロは十一人とともに立って、声を張り上げ、人々にはっきりとこう言った。「ユダヤの人々、ならびにエルサレムに住むすべての人々。あなたがたに知っていただきたいことがあります。どうか、私のことばに耳を貸してください。</span>
<span className="v" id="v15" data-v="15" data-xref="テサロニケ人への手紙第一 5:5–8; 1 Samuel 1:15; マタイの福音書 20:3"> 今は朝の九時ですから、あなたがたの思っているようにこの人たちは酔っているのではありません。</span>
<span className="v" id="v16" data-v="16" data-xref="Joel 2:28–32"> これは、預言者ヨエルによって語られた事です。</span>
<span className="v" id="v17" data-v="17" data-xref="Joel 2:28–32; Isaiah 44:3; テトスへの手紙 3:4–6"> 『神は言われる。 終わりの日に、わたしの霊をすべての人に注ぐ。 すると、あなたがたの息子や娘は預言し、 青年は幻を見、 老人は夢を見る。</span>
<span className="v" id="v18" data-v="18" data-xref="ガラテヤ人への手紙 3:28; コロサイ人への手紙 3:11; コリント人への手紙第一 7:21–22"> その日、わたしのしもべにも、はしためにも、 わたしの霊を注ぐ。 すると、彼らは預言する。</span>
<span className="v" id="v19" data-v="19" data-xref="Joel 2:30–31; Zephaniah 1:14–18; Malachi 4:1–6"> また、わたしは、上は天に不思議なわざを示し、 下は地にしるしを示す。 それは、血と火と立ち上る煙である。</span>
<span className="v" id="v20" data-v="20" data-xref="ペテロの手紙第二 3:10; Amos 8:9; マタイの福音書 24:29"> 主の大いなる輝かしい日が来る前に、 太陽はやみとなり、月は血に変わる。</span>
<span className="v" id="v21" data-v="21" data-xref="ローマ人への手紙 10:12–13; Joel 2:32; Psalms 86:5"> しかし、主の名を呼ぶ者は、みな救われる。』</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="ヨハネの福音書 3:2; ヨハネの福音書 14:10–11; マタイの福音書 12:28"> イスラエルの人たち。このことばを聞いてください。神はナザレ人イエスによって、あなたがたの間で力あるわざと、不思議なわざと、あかしの奇蹟を行なわれました。それらのことによって、神はあなたがたに、この方のあかしをされたのです。これは、あなたがた自身がご承知のように、</span>
<span className="v" id="v23" data-v="23" data-xref="ルカの福音書 22:22; 使徒の働き 4:28; 使徒の働き 3:18"> 神の定めた計画と神の予知とによって引き渡されたこの方を、あなたがたは不法な者の手によって十字架につけて殺しました。</span>
<span className="v" id="v24" data-v="24" data-xref="コリント人への手紙第一 6:14; ペテロの手紙第一 1:21; 使徒の働き 2:32"> しかし神は、この方を死の苦しみから解き放って、よみがえらせました。この方が死につながれていることなど、ありえないからです。</span>
<span className="v" id="v25" data-v="25" data-xref="Psalms 16:8–11; Isaiah 41:13; Psalms 62:6"> ダビデはこの方について、こう言っています。 『私はいつも、自分の目の前に主を見ていた。 主は、私が動かされないように、 私の右におられるからである。</span>
<span className="v" id="v26" data-v="26" data-xref="Psalms 16:9; Psalms 63:5; Psalms 71:23"> それゆえ、私の心は楽しみ、 私の舌は大いに喜んだ。 さらに私の肉体も望みの中に安らう。</span>
<span className="v" id="v27" data-v="27" data-xref="Psalms 16:10; 使徒の働き 2:31; ヨハネの黙示録 1:18"> あなたは私のたましいをハデスに捨てて置かず、 あなたの聖者が朽ち果てるのを お許しにならないからである。</span>
<span className="v" id="v28" data-v="28" data-xref="Psalms 16:11; Psalms 25:4; Psalms 21:6"> あなたは、私にいのちの道を知らせ、 御顔を示して、私を喜びで満たしてくださる。』</span>
<span className="v" id="v29" data-v="29" data-xref="使徒の働き 13:36; 1 Kings 2:10; 使徒の働き 7:8–9"> 兄弟たち。先祖ダビデについては、私はあなたがたに、確信をもって言うことができます。彼は死んで葬られ、その墓は今日まで私たちのところにあります。</span>
<span className="v" id="v30" data-v="30" data-xref="Psalms 132:11–18; Psalms 89:3–4; Jeremiah 33:14–15"> 彼は預言者でしたから、神が彼の子孫のひとりを彼の王位に着かせると誓って言われたことを知っていたのです。</span>
<span className="v" id="v31" data-v="31" data-xref="使徒の働き 2:27; Psalms 16:10; 使徒の働き 13:35"> それで後のことを予見して、キリストの復活について、『彼はハデスに捨てて置かれず、その肉体は朽ち果てない。』と語ったのです。</span>
<span className="v" id="v32" data-v="32" data-xref="使徒の働き 3:15; 使徒の働き 1:8; 使徒の働き 1:22"> 神はこのイエスをよみがえらせました。私たちはみな、そのことの証人です。</span>
<span className="v" id="v33" data-v="33" data-xref="使徒の働き 1:4; 使徒の働き 5:31; 使徒の働き 2:17"> ですから、神の右に上げられたイエスが、御父から約束された聖霊を受けて、今あなたがたが見聞きしているこの聖霊をお注ぎになったのです。</span>
<span className="v" id="v34" data-v="34" data-xref="Psalms 110:1; マタイの福音書 22:42–45; ヘブル人への手紙 1:13"> ダビデは天に上ったわけではありません。彼は自分でこう言っています。 『主は私の主に言われた。</span>
<span className="v" id="v35" data-v="35" data-xref="ヨハネの黙示録 19:19–3; ローマ人への手紙 16:20; Isaiah 60:14"> わたしがあなたの敵をあなたの足台とするまでは わたしの右の座に着いていなさい。』</span>
<span className="v" id="v36" data-v="36" data-xref="使徒の働き 5:30–31; ローマ人への手紙 14:8–12; コリント人への手紙第二 5:10"> ですから、イスラエルのすべての人々は、このことをはっきりと知らなければなりません。すなわち、神が、今や主ともキリストともされたこのイエスを、あなたがたは十字架につけたのです。」</span>
<span className="v" id="v37" data-v="37" data-xref="ルカの福音書 3:10; 使徒の働き 22:10; ヘブル人への手紙 4:12–13"> 人々はこれを聞いて心を刺され、ペテロとほかの使徒たちに、「兄弟たち。私たちはどうしたらよいでしょうか。」と言った。</span>
<span className="v" id="v38" data-v="38" data-xref="使徒の働き 22:16; マルコの福音書 16:16; 使徒の働き 8:12"> そこでペテロは彼らに答えた。「悔い改めなさい。そして、それぞれ罪を赦していただくために、イエス・キリストの名によってバプテスマを受けなさい。そうすれば、賜物として聖霊を受けるでしょう。</span>
<span className="v" id="v39" data-v="39" data-xref="Isaiah 44:3; Genesis 17:7–8; ローマ人への手紙 8:30"> なぜなら、この約束は、あなたがたと、その子どもたち、ならびにすべての遠くにいる人々、すなわち、私たちの神である主がお召しになる人々に与えられているからです。」</span>
<span className="v" id="v40" data-v="40" data-xref="ピリピ人への手紙 2:15; Deuteronomy 32:5; マタイの福音書 17:17"> ペテロは、このほかにも多くのことばをもって、あかしをし、「この曲がった時代から救われなさい。」と言って彼らに勧めた。</span>
<span className="v" id="v41" data-v="41" data-xref="使徒の働き 4:4; 使徒の働き 2:47; 使徒の働き 16:31–34"> そこで、彼のことばを受け入れた者は、バプテスマを受けた。その日、三千人ほどが弟子に加えられた。</span>
<span className="v" id="v42" data-v="42" data-xref="ヘブル人への手紙 10:25; 使徒の働き 1:14; ヨハネの手紙第一 1:3"> そして、彼らは使徒たちの教えを堅く守り、交わりをし、パンを裂き、祈りをしていた。</span>
<span className="v" id="v43" data-v="43" data-xref="ルカの福音書 7:16; ヨハネの福音書 14:12; ルカの福音書 8:37"> そして、一同の心に恐れが生じ、使徒たちによって、多くの不思議なわざとあかしの奇蹟が行なわれた。</span>
<span className="v" id="v44" data-v="44" data-xref="使徒の働き 4:32; ヨハネの手紙第一 3:16–18; コリント人への手紙第二 8:14–15"> 信者となった者たちはみないっしょにいて、いっさいの物を共有にしていた。</span>
<span className="v" id="v45" data-v="45" data-xref="ヨハネの手紙第一 3:17; テモテへの手紙第一 6:18–19; ヤコブの手紙 2:14–16"> そして、資産や持ち物を売っては、それぞれの必要に応じて、みなに分配していた。</span>
<span className="v" id="v46" data-v="46" data-xref="使徒の働き 5:42; 使徒の働き 20:7; 使徒の働き 2:42"> そして毎日、心を一つにして宮に集まり、家でパンを裂き、喜びと真心をもって食事をともにし、</span>
<span className="v" id="v47" data-v="47" data-xref="使徒の働き 16:5; 使徒の働き 5:13–14; 使徒の働き 2:41"> 神を賛美し、すべての民に好意を持たれた。主も毎日救われる人々を仲間に加えてくださった。</span>
</div>

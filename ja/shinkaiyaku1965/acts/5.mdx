<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="Leviticus 10:1–3; テモテへの手紙第二 2:20; マタイの福音書 13:47–48"> ところが、アナニヤという人は、妻のサッピラとともにその持ち物を売り、</span>
<span className="v" id="v2" data-v="2" data-xref="使徒の働き 4:37; ペテロの手紙第二 2:14–15; マタイの福音書 23:5"> 妻も承知のうえで、その代金の一部を残しておき、ある部分を持って来て、使徒たちの足もとに置いた。</span>
<span className="v" id="v3" data-v="3" data-xref="Jeremiah 23:24; Isaiah 29:15; ヨハネの福音書 13:2"> そこで、ペテロがこう言った。「アナニヤ。どうしてあなたはサタンに心を奪われ、聖霊を欺いて、地所の代金の一部を自分のために残しておいたのか。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒の働き 5:3; Joshua 7:25–26; 2 Kings 5:25–27"> それはもともとあなたのものであり、売ってからもあなたの自由になったのではないか。なぜこのようなことをたくらんだのか。あなたは人を欺いたのではなく、神を欺いたのだ。」</span>
<span className="v" id="v5" data-v="5" data-xref="使徒の働き 5:10–11; 使徒の働き 2:43; 使徒の働き 5:13"> アナニヤはこのことばを聞くと、倒れて息が絶えた。そして、これを聞いたすべての人に、非常な恐れが生じた。</span>
<span className="v" id="v6" data-v="6" data-xref="ヨハネの福音書 19:40; 2 Samuel 18:17; Deuteronomy 21:23"> 青年たちは立って、彼を包み、運び出して葬った。</span>
<span className="v" id="v7" data-v="7"> 三時間ほどたって、彼の妻はこの出来事を知らずにはいって来た。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒の働き 5:2"> ペテロは彼女にこう言った。「あなたがたは地所をこの値段で売ったのですか。私に言いなさい。」彼女は「はい。その値段です。」と言った。</span>
<span className="v" id="v9" data-v="9" data-xref="コリント人への手紙第一 10:9; 使徒の働き 5:3–4; Psalms 95:8–11"> そこで、ペテロは彼女に言った。「どうしてあなたがたは心を合わせて、主の御霊を試みたのですか。見なさい、あなたの夫を葬った者たちが、戸口に来ていて、あなたをも運び出します。」</span>
<span className="v" id="v10" data-v="10" data-xref="使徒の働き 5:5"> すると彼女は、たちまちペテロの足もとに倒れ、息が絶えた。はいって来た青年たちは、彼女が死んだのを見て、運び出し、夫のそばに葬った。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒の働き 5:5; コリント人への手紙第一 10:11–12; 使徒の働き 19:17"> そして、教会全体と、このことを聞いたすべての人たちとに、非常な恐れが生じた。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒の働き 19:11; コリント人への手紙第二 12:12; ヘブル人への手紙 2:4"> また、使徒たちの手によって、多くのしるしと不思議なわざが人々の間で行なわれた。みなは一つ心になってソロモンの廊にいた。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒の働き 2:47; 使徒の働き 4:21; ヨハネの福音書 12:42"> ほかの人々は、ひとりもこの交わりに加わろうとしなかったが、その人々は彼らを尊敬していた。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒の働き 2:47; 使徒の働き 4:4; Isaiah 55:11–13"> そればかりか、主を信じる者は男も女もますますふえていった。</span>
<span className="v" id="v15" data-v="15" data-xref="マタイの福音書 14:36; 使徒の働き 19:11–12; ヨハネの福音書 14:12"> ついに、人々は病人を大通りへ運び出し、寝台や寝床の上に寝かせ、ペテロが通りかかるときには、せめてその影でも、だれかにかかるようにするほどになった。</span>
<span className="v" id="v16" data-v="16" data-xref="マルコの福音書 16:17–18; マルコの福音書 2:3–4; マタイの福音書 15:30–31"> また、エルサレムの付近の町々から、大ぜいの人が、病人や、汚れた霊に苦しめられている人などを連れて集まって来たが、その全部がいやされた。</span>
<span className="v" id="v17" data-v="17" data-xref="使徒の働き 13:45; 使徒の働き 7:9; 使徒の働き 17:5"> そこで、大祭司とその仲間たち全部、すなわちサドカイ派の者はみな、ねたみに燃えて立ち上がり、</span>
<span className="v" id="v18" data-v="18" data-xref="使徒の働き 4:3; ルカの福音書 21:12; コリント人への手紙第二 11:23"> 使徒たちを捕え、留置場に入れた。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒の働き 16:26; Psalms 34:7; 使徒の働き 12:7–11"> ところが、夜、主の使いが牢の戸を開き、彼らを連れ出し、</span>
<span className="v" id="v20" data-v="20" data-xref="ヨハネの福音書 6:63; ヨハネの福音書 6:68; ヨハネの手紙第一 5:11–12"> 「行って宮の中に立ち、人々にこのいのちのことばを、ことごとく語りなさい。」と言った。</span>
<span className="v" id="v21" data-v="21" data-xref="ヨハネの福音書 8:2; 使徒の働き 22:15; 使徒の働き 12:18–19"> 彼らはこれを聞くと、夜明けごろ宮にはいって教え始めた。一方、大祭司とその仲間たちは集まって来て、議会とイスラエル人のすべての長老を召集し、使徒たちを引き出して来させるために、人を獄舎にやった。</span>
<span className="v" id="v22" data-v="22"> ところが役人たちが行ってみると、牢の中には彼らがいなかったので、引き返してこう報告した。</span>
<span className="v" id="v23" data-v="23" data-xref="Psalms 2:4; Psalms 33:10; Daniel 6:22–24"> 「獄舎は完全にしまっており、番人たちが戸口に立っていましたが、あけてみると、中にはだれもおりませんでした。」</span>
<span className="v" id="v24" data-v="24" data-xref="使徒の働き 4:1; 使徒の働き 5:26; ヨハネの福音書 12:19"> 宮の守衛長や祭司長たちは、このことばを聞いて、いったいこれはどうなって行くのかと、使徒たちのことで当惑した。</span>
<span className="v" id="v25" data-v="25"> そこへ、ある人がやって来て、「大変です。あなたがたが牢に入れた人たちが、宮の中に立って、人々を教えています。」と告げた。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒の働き 5:13; 使徒の働き 4:21; マタイの福音書 26:5"> そこで、宮の守衛長は役人たちといっしょに出て行き、使徒たちを連れて来た。しかし、手荒なことはしなかった。人々に石で打ち殺されるのを恐れたからである。</span>
<span className="v" id="v27" data-v="27" data-xref="マタイの福音書 5:22; 使徒の働き 4:7; ルカの福音書 22:66"> 彼らが使徒たちを連れて来て議会の中に立たせると、大祭司は使徒たちを問いただして、</span>
<span className="v" id="v28" data-v="28" data-xref="マタイの福音書 27:25; 使徒の働き 7:52; 使徒の働き 4:10–11"> 言った。「あの名によって教えてはならないときびしく命じておいたのに、何ということだ。エルサレム中にあなたがたの教えを広めてしまい、そのうえ、あの人の血の責任をわれわれに負わせようとしているではないか。」</span>
<span className="v" id="v29" data-v="29" data-xref="使徒の働き 4:19; 1 Samuel 15:24; マルコの福音書 7:7–9"> ペテロをはじめ使徒たちは答えて言った。「人に従うより、神に従うべきです。</span>
<span className="v" id="v30" data-v="30" data-xref="ガラテヤ人への手紙 3:13; ペテロの手紙第一 2:24; 使徒の働き 10:39"> 私たちの先祖の神は、あなたがたが十字架にかけて殺したイエスを、よみがえらせたのです。</span>
<span className="v" id="v31" data-v="31" data-xref="ルカの福音書 24:47; 使徒の働き 2:33; ヘブル人への手紙 2:10"> そして神は、イスラエルに悔い改めと罪の赦しを与えるために、このイエスを君とし、救い主として、ご自分の右に上げられました。</span>
<span className="v" id="v32" data-v="32" data-xref="ヨハネの福音書 15:26–27; ヘブル人への手紙 2:3–4; 使徒の働き 1:8"> 私たちはそのことの証人です。神がご自分に従う者たちにお与えになった聖霊もそのことの証人です。」</span>
<span className="v" id="v33" data-v="33" data-xref="使徒の働き 7:54; 使徒の働き 2:37; ルカの福音書 4:28–29"> 彼らはこれを聞いて怒り狂い、使徒たちを殺そうと計った。</span>
<span className="v" id="v34" data-v="34" data-xref="使徒の働き 22:3; ルカの福音書 2:46; ルカの福音書 5:17"> ところが、すべての人に尊敬されている律法学者で、ガマリエルというパリサイ人が議会の中に立ち、使徒たちをしばらく外に出させるように命じた。</span>
<span className="v" id="v35" data-v="35" data-xref="使徒の働き 22:26; Jeremiah 26:19; マタイの福音書 27:19"> それから、議員たちに向かってこう言った。「イスラエルの皆さん。この人々をどう扱うか、よく気をつけてください。</span>
<span className="v" id="v36" data-v="36" data-xref="使徒の働き 8:9; ペテロの手紙第二 2:2; ガラテヤ人への手紙 6:3"> というのは、先ごろチゥダが立ち上がって、自分を何か偉い者のように言い、彼に従った男の数が四百人ほどありましたが、結局、彼は殺され、従った者はみな散らされて、あとかたもなくなりました。</span>
<span className="v" id="v37" data-v="37" data-xref="ルカの福音書 2:1–2; Psalms 7:14–15; マタイの福音書 26:52"> その後、人口調査のとき、ガリラヤ人ユダが立ち上がり、民衆をそそのかして反乱を起こしましたが、自分は滅び、従った者たちもみな散らされてしまいました。</span>
<span className="v" id="v38" data-v="38" data-xref="マタイの福音書 15:13; Lamentations 3:37; Isaiah 8:9–10"> そこで今、あなたがたに申したいのです。あの人たちから手を引き、放っておきなさい。もし、その計画や行動が人から出たものならば、自滅してしまうでしょう。</span>
<span className="v" id="v39" data-v="39" data-xref="Proverbs 21:30; Isaiah 46:10; マタイの福音書 16:18"> しかし、もし神から出たものならば、あなたがたには彼らを滅ぼすことはできないでしょう。もしかすれば、あなたがたは神に敵対する者になってしまいます。」彼らは彼に説得され、</span>
<span className="v" id="v40" data-v="40" data-xref="マタイの福音書 10:17; 使徒の働き 5:28; 使徒の働き 4:17–21"> 使徒たちを呼んで、彼らをむちで打ち、イエスの名によって語ってはならないと言い渡したうえで釈放した。</span>
<span className="v" id="v41" data-v="41" data-xref="ヤコブの手紙 1:2; ペテロの手紙第一 4:13–16; ルカの福音書 6:22"> そこで、使徒たちは、御名のためにはずかしめられるに値する者とされたことを喜びながら、議会から出て行った。</span>
<span className="v" id="v42" data-v="42" data-xref="使徒の働き 2:46; 使徒の働き 20:20; ルカの福音書 21:37"> そして、毎日、宮や家々で教え、イエスがキリストであることを宣べ伝え続けた。</span>

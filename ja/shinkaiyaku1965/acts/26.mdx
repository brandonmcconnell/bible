<span className="v" id="v1" data-v="1" data-xref="使徒の働き 9:15; Proverbs 1:24; 使徒の働き 26:2"> すると、アグリッパがパウロに、「あなたは、自分の言い分を申し述べてよろしい。」と言った。そこでパウロは、手を差し伸べて弁明し始めた。</span>
<span className="v" id="v2" data-v="2"> 「アグリッパ王。私がユダヤ人に訴えられているすべてのことについて、きょう、あなたの前で弁明できることを、幸いに存じます。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒の働き 6:14; 使徒の働き 26:26; 使徒の働き 26:7"> 特に、あなたがユダヤ人の慣習や問題に精通しておられるからです。どうか、私の申し上げることを、忍耐をもってお聞きくださるよう、お願いいたします。</span>
<span className="v" id="v4" data-v="4" data-xref="ガラテヤ人への手紙 1:13; テモテへの手紙第二 3:10; ピリピ人への手紙 3:5"> では申し述べますが、私が最初から私の国民の中で、またエルサレムにおいて過ごした若い時からの生活ぶりは、すべてのユダヤ人の知っているところです。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒の働き 23:6; 使徒の働き 22:3; 使徒の働き 24:5"> 彼らは以前から私を知っていますので、証言するつもりならできることですが、私は、私たちの宗教の最も厳格な派に従って、パリサイ人として生活してまいりました。</span>
<span className="v" id="v6" data-v="6" data-xref="テトスへの手紙 2:13; 使徒の働き 24:15; 使徒の働き 28:20"> そして今、神が私たちの先祖に約束されたものを待ち望んでいることで、私は裁判を受けているのです。</span>
<span className="v" id="v7" data-v="7" data-xref="ヤコブの手紙 1:1; ピリピ人への手紙 3:11; テモテへの手紙第一 5:5"> 私たちの十二部族は、夜も昼も熱心に神に仕えながら、その約束のものを得たいと望んでおります。王よ。私は、この希望のためにユダヤ人から訴えられているのです。</span>
<span className="v" id="v8" data-v="8" data-xref="コリント人への手紙第一 15:12–20; 使徒の働き 4:2; 使徒の働き 17:31–32"> 神が死者をよみがえらせるということを、あなたがたは、なぜ信じがたいこととされるのでしょうか。</span>
<span className="v" id="v9" data-v="9" data-xref="テモテへの手紙第一 1:13; 使徒の働き 22:8; ピリピ人への手紙 3:6"> 以前は、私自身も、ナザレ人イエスの名に強硬に敵対すべきだと考えていました。</span>
<span className="v" id="v10" data-v="10" data-xref="使徒の働き 8:3; 使徒の働き 9:13–14; 使徒の働き 9:21"> そして、それをエルサレムで実行しました。祭司長たちから権限を授けられた私は、多くの聖徒たちを牢に入れ、彼らが殺されるときには、それに賛成の票を投じました。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒の働き 22:19; マタイの福音書 10:17; 使徒の働き 13:45"> また、すべての会堂で、しばしば彼らを罰しては、強いて御名をけがすことばを言わせようとし、彼らに対する激しい怒りに燃えて、ついには国外の町々にまで彼らを追跡して行きました。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒の働き 26:10; 使徒の働き 22:5–11; 使徒の働き 9:1–8"> このようにして、私は祭司長たちから権限と委任を受けて、ダマスコへ出かけて行きますと、</span>
<span className="v" id="v13" data-v="13" data-xref="マタイの福音書 17:2; ヨハネの黙示録 21:23; ヨハネの黙示録 1:16"> その途中、正午ごろ、王よ、私は天からの光を見ました。それは太陽よりも明るく輝いて、私と同行者たちとの回りを照らしたのです。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒の働き 21:40; 使徒の働き 22:2; 使徒の働き 9:7"> 私たちはみな地に倒れましたが、そのとき声があって、ヘブル語で私にこう言うのが聞こえました。『サウロ、サウロ。なぜわたしを迫害するのか。とげのついた棒をけるのは、あなたにとって痛いことだ。』</span>
<span className="v" id="v15" data-v="15" data-xref="ヨハネの福音書 15:20–21; マタイの福音書 25:45; Exodus 16:8"> 私が『主よ。あなたはどなたですか。』と言いますと、主がこう言われました。『わたしは、あなたが迫害しているイエスである。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒の働き 22:14–15; Ezekiel 2:1; Daniel 10:11"> 起き上がって、自分の足で立ちなさい。わたしがあなたに現われたのは、あなたが見たこと、また、これから後わたしがあなたに現われて示そうとすることについて、あなたを奉仕者、また証人に任命するためである。</span>
<span className="v" id="v17" data-v="17" data-xref="使徒の働き 9:15; テモテへの手紙第一 2:7; Jeremiah 1:19"> わたしは、この民と異邦人との中からあなたを救い出し、彼らのところに遣わす。</span>
<span className="v" id="v18" data-v="18" data-xref="ペテロの手紙第一 2:9; エペソ人への手紙 1:18; エペソ人への手紙 5:8"> それは彼らの目を開いて、暗やみから光に、サタンの支配から神に立ち返らせ、わたしを信じる信仰によって、彼らに罪の赦しを得させ、聖別された人々の中にあって御国を受け継がせるためである。』</span>
<span className="v" id="v19" data-v="19" data-xref="Isaiah 50:5; ガラテヤ人への手紙 1:16; Ezekiel 2:7–8"> こういうわけで、アグリッパ王よ、私は、この天からの啓示にそむかず、</span>
<span className="v" id="v20" data-v="20" data-xref="マタイの福音書 3:8; 使徒の働き 3:19; 使徒の働き 2:38"> ダマスコにいる人々をはじめエルサレムにいる人々に、またユダヤの全地方に、さらに異邦人にまで、悔い改めて神に立ち返り、悔い改めにふさわしい行ないをするようにと宣べ伝えて来たのです。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒の働き 21:30–31; 使徒の働き 21:27; 使徒の働き 25:3"> そのために、ユダヤ人たちは私を宮の中で捕え、殺そうとしたのです。</span>
<span className="v" id="v22" data-v="22" data-xref="使徒の働き 24:14; ヨハネの福音書 5:46; ローマ人への手紙 3:21"> こうして、私はこの日に至るまで神の助けを受け、堅く立って、小さい者にも大きい者にもあかしをしているのです。そして、預言者たちやモーセが、後に起こるはずだと語ったこと以外は何も話しませんでした。</span>
<span className="v" id="v23" data-v="23" data-xref="Isaiah 53:1–12; ルカの福音書 24:26; コロサイ人への手紙 1:18"> すなわち、キリストは苦しみを受けること、また、死者の中からの復活によって、この民と異邦人とに最初に光を宣べ伝える、ということです。」</span>
<span className="v" id="v24" data-v="24" data-xref="コリント人への手紙第一 2:13–14; コリント人への手紙第一 1:23; コリント人への手紙第一 4:10"> パウロがこのように弁明していると、フェストが大声で、「気が狂っているぞ。パウロ。博学があなたの気を狂わせている。」と言った。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒の働き 23:26; テトスへの手紙 1:9; テトスへの手紙 2:7–8"> するとパウロは次のように言った。「フェスト閣下。気は狂っておりません。私は、まじめな真理のことばを話しています。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒の働き 26:2–3; 使徒の働き 2:1–12; Isaiah 30:20"> 王はこれらのことをよく知っておられるので、王に対して私は率直に申し上げているのです。これらのことは片隅で起こった出来事ではありませんから、そのうちの一つでも王の目に留まらなかったものはないと信じます。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒の働き 26:22–23"> アグリッパ王。あなたは預言者を信じておられますか。もちろん信じておられると思います。」</span>
<span className="v" id="v28" data-v="28" data-xref="使徒の働き 11:26; マタイの福音書 10:18; 使徒の働き 26:29"> するとアグリッパはパウロに、「あなたは、わずかなことばで、私をキリスト者にしようとしている。」と言った。</span>
<span className="v" id="v29" data-v="29" data-xref="エペソ人への手紙 6:20; コロサイ人への手紙 1:28; ローマ人への手紙 10:1"> パウロはこう答えた。「ことばが少なかろうと、多かろうと、私が神に願うことは、あなたばかりでなく、きょう私の話を聞いている人がみな、この鎖は別として、私のようになってくださることです。」</span>
<span className="v" id="v30" data-v="30" data-xref="使徒の働き 18:15; 使徒の働き 28:22; 使徒の働き 25:23"> ここで王と総督とベルニケ、および同席の人々が立ち上がった。</span>
<span className="v" id="v31" data-v="31" data-xref="使徒の働き 23:29; 使徒の働き 23:9; 使徒の働き 28:18"> 彼らは退場してから、互いに話し合って言った。「あの人は、死や投獄に相当することは何もしていない。」</span>
<span className="v" id="v32" data-v="32" data-xref="使徒の働き 28:18; 使徒の働き 25:11–12; 使徒の働き 25:25"> またアグリッパはフェストに、「この人は、もしカイザルに上訴しなかったら、釈放されたであろうに。」と言った。</span>

<span className="v" id="v1" data-v="1" data-xref="使徒の働き 27:1; マタイの福音書 8:5–13; マタイの福音書 27:27"> さて、カイザリヤにコルネリオという人がいて、イタリヤ隊という部隊の百人隊長であった。</span>
<span className="v" id="v2" data-v="2" data-xref="マタイの福音書 7:7–8; 使徒の働き 10:4; 使徒の働き 10:22"> 彼は敬虔な人で、全家族とともに神を恐れかしこみ、ユダヤの人々に多くの施しをなし、いつも神に祈りをしていたが、</span>
<span className="v" id="v3" data-v="3" data-xref="Daniel 9:20–21; 使徒の働き 3:1; 使徒の働き 5:19"> ある日の午後三時ごろ、幻の中で、はっきりと神の御使いを見た。御使いは彼のところに来て、「コルネリオ。」と呼んだ。</span>
<span className="v" id="v4" data-v="4" data-xref="ピリピ人への手紙 4:6; ヘブル人への手紙 6:10; 使徒の働き 10:31"> 彼は、御使いを見つめていると、恐ろしくなって、「主よ。何でしょうか。」と答えた。すると御使いはこう言った。「あなたの祈りと施しは神の前に立ち上って、覚えられています。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒の働き 16:9; 使徒の働き 9:38; 使徒の働き 15:7"> さあ今、ヨッパに人をやって、シモンという人を招きなさい。彼の名はペテロとも呼ばれています。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒の働き 9:43; 使徒の働き 11:13–14; ローマ人への手紙 10:14–17"> この人は皮なめしのシモンという人の家に泊まっていますが、その家は海べにあります。」</span>
<span className="v" id="v7" data-v="7" data-xref="ピレモンへの手紙 1:16; 1 Samuel 14:6–7; マタイの福音書 8:9–10"> 御使いが彼にこう語って立ち去ると、コルネリオはそのしもべたちの中のふたりと、側近の部下の中の敬虔な兵士ひとりとを呼び寄せ、</span>
<span className="v" id="v8" data-v="8" data-xref="使徒の働き 9:36; Psalms 119:59–60; 使徒の働き 10:33"> 全部のことを説明してから、彼らをヨッパへ遣わした。</span>
<span className="v" id="v9" data-v="9" data-xref="Zephaniah 1:5; Psalms 55:17; 1 Samuel 9:25"> その翌日、この人たちが旅を続けて、町の近くまで来たころ、ペテロは祈りをするために屋上に上った。昼の十二時ごろであった。</span>
<span className="v" id="v10" data-v="10" data-xref="使徒の働き 22:17; ヨハネの黙示録 4:2–3; コリント人への手紙第二 12:2–4"> すると彼は非常に空腹を覚え、食事をしたくなった。ところが、食事の用意がされている間に、彼はうっとりと夢ごこちになった。</span>
<span className="v" id="v11" data-v="11" data-xref="エペソ人への手紙 3:6; ヨハネの福音書 1:51; ローマ人への手紙 16:25–26"> 見ると、天が開けており、大きな敷布のような入れ物が、四隅をつるされて地上に降りて来た。</span>
<span className="v" id="v12" data-v="12" data-xref="Genesis 7:8–9; ヨハネの福音書 7:37; コリント人への手紙第一 6:9–11"> その中には、地上のあらゆる種類の四つ足の動物や、はうもの、また、空の鳥などがいた。</span>
<span className="v" id="v13" data-v="13" data-xref="ヨハネの福音書 4:31–34; Jeremiah 35:2–5; 使徒の働き 10:10"> そして、彼に、「ペテロ。さあ、ほふって食べなさい。」という声が聞こえた。</span>
<span className="v" id="v14" data-v="14" data-xref="Leviticus 20:25; Ezekiel 4:14; Daniel 1:8"> しかしペテロは言った。「主よ。それはできません。私はまだ一度も、きよくない物や汚れた物を食べたことがありません。」</span>
<span className="v" id="v15" data-v="15" data-xref="コリント人への手紙第一 10:25; マタイの福音書 15:11; テトスへの手紙 1:15"> すると、再び声があって、彼にこう言った。「神がきよめた物を、きよくないと言ってはならない。」</span>
<span className="v" id="v16" data-v="16" data-xref="Genesis 41:32; ヨハネの福音書 21:17; コリント人への手紙第二 13:1"> こんなことが三回あって後、その入れ物はすぐ天に引き上げられた。</span>
<span className="v" id="v17" data-v="17" data-xref="ヨハネの福音書 13:12; 使徒の働き 10:7–19; 使徒の働き 5:24"> ペテロが、いま見た幻はいったいどういうことだろう、と思い惑っていると、ちょうどそのとき、コルネリオから遣わされた人たちが、シモンの家をたずね当てて、その門口に立っていた。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒の働き 10:5–6; 使徒の働き 11:11"> そして、声をかけて、ペテロと呼ばれるシモンという人がここに泊まっているだろうかと尋ねていた。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒の働き 8:29; 使徒の働き 11:12; 使徒の働き 21:4"> ペテロが幻について思い巡らしているとき、御霊が彼にこう言われた。「見なさい。三人の人があなたをたずねて来ています。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒の働き 15:7–9; Zechariah 2:9–11; Isaiah 48:16"> さあ、下に降りて行って、ためらわずに、彼らといっしょに行きなさい。彼らを遣わしたのはわたしです。」</span>
<span className="v" id="v21" data-v="21" data-xref="ヨハネの福音書 1:38–39; マルコの福音書 10:51; 使徒の働き 10:29"> そこでペテロは、その人たちのところへ降りて行って、こう言った。「あなたがたのたずねているペテロは、私です。どんなご用でおいでになったのですか。」</span>
<span className="v" id="v22" data-v="22" data-xref="使徒の働き 11:14; 使徒の働き 10:2; 使徒の働き 22:12"> すると彼らはこう言った。「百人隊長コルネリオという正しい人で、神を恐れかしこみ、ユダヤの全国民に評判の良い人が、あなたを自分の家にお招きして、あなたからお話を聞くように、聖なる御使いによって示されました。」</span>
<span className="v" id="v23" data-v="23" data-xref="使徒の働き 10:45; 使徒の働き 11:12; ペテロの手紙第一 4:9"> それで、ペテロは、彼らを中に入れて泊まらせた。 明くる日、ペテロは、立って彼らといっしょに出かけた。ヨッパの兄弟たちも数人同行した。</span>
<span className="v" id="v24" data-v="24" data-xref="使徒の働き 8:40; Zechariah 8:20–23; Zechariah 3:10"> その翌日、彼らはカイザリヤに着いた。コルネリオは、親族や親しい友人たちを呼び集め、彼らを待っていた。</span>
<span className="v" id="v25" data-v="25" data-xref="ヨハネの黙示録 19:10; ヨハネの黙示録 22:8–9; Daniel 2:46"> ペテロが着くと、コルネリオは出迎えて、彼の足もとにひれ伏して拝んだ。</span>
<span className="v" id="v26" data-v="26" data-xref="ヨハネの黙示録 19:10; ヨハネの黙示録 22:8–9; 使徒の働き 14:14–15"> するとペテロは彼を起こして、「お立ちなさい。私もひとりの人間です。」と言った。</span>
<span className="v" id="v27" data-v="27" data-xref="コリント人への手紙第二 2:12; ヨハネの福音書 4:35; 使徒の働き 10:24"> それから、コルネリオとことばをかわしながら家にはいり、多くの人が集まっているのを見て、</span>
<span className="v" id="v28" data-v="28" data-xref="ヨハネの福音書 4:9; エペソ人への手紙 3:6–7; ガラテヤ人への手紙 2:12–14"> 彼らにこう言った。「ご承知のとおり、ユダヤ人が外国人の仲間にはいったり、訪問したりするのは、律法にかなわないことです。ところが、神は私に、どんな人のことでも、きよくないとか、汚れているとか言ってはならないことを示してくださいました。</span>
<span className="v" id="v29" data-v="29" data-xref="Psalms 119:60; ペテロの手紙第一 3:15; 使徒の働き 10:19–20"> それで、お迎えを受けたとき、ためらわずに来たのです。そこで、お尋ねしますが、あなたがたは、いったいどういうわけで私をお招きになったのですか。」</span>
<span className="v" id="v30" data-v="30" data-xref="使徒の働き 10:3; Daniel 9:20–21; Nehemiah 9:1–3"> するとコルネリオがこう言った。「四日前のこの時刻に、私が家で午後三時の祈りをしていますと、どうでしょう、輝いた衣を着た人が、私の前に立って、</span>
<span className="v" id="v31" data-v="31" data-xref="使徒の働き 10:4; Daniel 9:23; ルカの福音書 1:13"> こう言いました。『コルネリオ。あなたの祈りは聞き入れられ、あなたの施しは神の前に覚えられている。</span>
<span className="v" id="v32" data-v="32"> それで、ヨッパに人をやってシモンを招きなさい。彼の名はペテロとも呼ばれている。この人は海べにある、皮なめしのシモンの家に泊まっている。』</span>
<span className="v" id="v33" data-v="33" data-xref="ヤコブの手紙 1:19; ガラテヤ人への手紙 4:14; 2 Chronicles 30:12"> それで、私はすぐあなたのところへ人を送ったのですが、よくおいでくださいました。いま私たちは、主があなたにお命じになったすべてのことを伺おうとして、みな神の御前に出ております。」</span>
<span className="v" id="v34" data-v="34" data-xref="ローマ人への手紙 2:11; 2 Chronicles 19:7; Deuteronomy 10:17"> そこでペテロは、口を開いてこう言った。 「これで私は、はっきりわかりました。神はかたよったことをなさらず、</span>
<span className="v" id="v35" data-v="35" data-xref="ヨハネの手紙第一 2:29; 使徒の働き 10:2; ローマ人への手紙 10:12–13"> どの国の人であっても、神を恐れかしこみ、正義を行なう人なら、神に受け入れられるのです。</span>
<span className="v" id="v36" data-v="36" data-xref="マタイの福音書 28:18; 使徒の働き 2:36; ヨハネの黙示録 17:14"> 神はイエス・キリストによって、平和を宣べ伝え、イスラエルの子孫にみことばをお送りになりました。このイエス・キリストはすべての人の主です。</span>
<span className="v" id="v37" data-v="37" data-xref="ルカの福音書 4:14; 使徒の働き 2:22; 使徒の働き 28:22"> あなたがたは、ヨハネが宣べ伝えたバプテスマの後、ガリラヤから始まって、ユダヤ全土に起こった事がらを、よくご存じです。</span>
<span className="v" id="v38" data-v="38" data-xref="ルカの福音書 4:18; 使徒の働き 2:22; Isaiah 61:1–3"> それは、ナザレのイエスのことです。神はこの方に聖霊と力を注がれました。このイエスは、神がともにおられたので、巡り歩いて良いわざをなし、また悪魔に制せられているすべての者をいやされました。</span>
<span className="v" id="v39" data-v="39" data-xref="ルカの福音書 24:48; 使徒の働き 1:8; 使徒の働き 10:41"> 私たちは、イエスがユダヤ人の地とエルサレムとで行なわれたすべてのことの証人です。人々はこの方を木にかけて殺しました。</span>
<span className="v" id="v40" data-v="40" data-xref="ペテロの手紙第一 1:21; 使徒の働き 13:30–31; コリント人への手紙第一 15:3–4"> しかし、神はこのイエスを三日目によみがえらせ、現われさせてくださいました。</span>
<span className="v" id="v41" data-v="41" data-xref="ヨハネの福音書 14:22; 使徒の働き 10:39; ヨハネの福音書 21:13"> しかし、それはすべての人々にではなく、神によって前もって選ばれた証人である私たちにです。私たちは、イエスが死者の中からよみがえられて後、ごいっしょに食事をしました。</span>
<span className="v" id="v42" data-v="42" data-xref="コリント人への手紙第二 5:10; テモテへの手紙第二 4:1; ペテロの手紙第一 4:5"> イエスは私たちに命じて、このイエスこそ生きている者と死んだ者とのさばき主として、神によって定められた方であることを人々に宣べ伝え、そのあかしをするように、言われたのです。</span>
<span className="v" id="v43" data-v="43" data-xref="Zechariah 13:1; 使徒の働き 2:38; Isaiah 53:11"> イエスについては、預言者たちもみな、この方を信じる者はだれでも、その名によって罪の赦しが受けられる、とあかししています。」</span>
<span className="v" id="v44" data-v="44" data-xref="使徒の働き 11:15; 使徒の働き 19:6; 使徒の働き 15:8"> ペテロがなおもこれらのことばを話し続けているとき、みことばに耳を傾けていたすべての人々に、聖霊がお下りになった。</span>
<span className="v" id="v45" data-v="45" data-xref="使徒の働き 10:23; 使徒の働き 2:38; ガラテヤ人への手紙 3:13–14"> 割礼を受けている信者で、ペテロといっしょに来た人たちは、異邦人にも聖霊の賜物が注がれたので驚いた。</span>
<span className="v" id="v46" data-v="46" data-xref="使徒の働き 19:6; 使徒の働き 2:4; マルコの福音書 16:17"> 彼らが異言を話し、神を賛美するのを聞いたからである。そこでペテロはこう言った。</span>
<span className="v" id="v47" data-v="47" data-xref="使徒の働き 8:36; ローマ人への手紙 10:12; 使徒の働き 11:15–17"> 「この人たちは、私たちと同じように、聖霊を受けたのですから、いったいだれが、水をさし止めて、この人たちにバプテスマを受けさせないようにすることができましょうか。」</span>
<span className="v" id="v48" data-v="48" data-xref="使徒の働き 2:38; 使徒の働き 8:16; ガラテヤ人への手紙 3:27"> そして、イエス・キリストの御名によってバプテスマを受けるように彼らに命じた。彼らは、ペテロに数日間滞在するように願った。</span>

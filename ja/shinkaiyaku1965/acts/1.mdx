<span className="v" id="v1" data-v="1" data-xref="ルカの福音書 1:3; ルカの福音書 24:19; マタイの福音書 4:23–24"> テオピロよ。私は前の書で、イエスが行ない始め、教え始められたすべてのことについて書き、</span>
<span className="v" id="v2" data-v="2" data-xref="使徒の働き 1:9; ヨハネの福音書 20:21; Isaiah 59:20–21"> お選びになった使徒たちに聖霊によって命じてから、天に上げられた日のことにまで及びました。</span>
<span className="v" id="v3" data-v="3" data-xref="コリント人への手紙第一 15:5–7; 使徒の働き 13:31; ヨハネの福音書 20:26"> イエスは苦しみを受けた後、四十日の間、彼らに現われて、神の国のことを語り、数多くの確かな証拠をもって、ご自分が生きていることを使徒たちに示された。</span>
<span className="v" id="v4" data-v="4" data-xref="ルカの福音書 24:49; ヨハネの福音書 14:16; ヨハネの福音書 15:26"> 彼らといっしょにいるとき、イエスは彼らにこう命じられた。「エルサレムを離れないで、わたしから聞いた父の約束を待ちなさい。</span>
<span className="v" id="v5" data-v="5" data-xref="マタイの福音書 3:11; 使徒の働き 11:15–16; ルカの福音書 3:16"> ヨハネは水でバプテスマを授けたが、もう間もなく、あなたがたは聖霊のバプテスマを受けるからです。」</span>
<span className="v" id="v6" data-v="6" data-xref="ルカの福音書 19:11; ルカの福音書 17:20; Daniel 7:27"> そこで、彼らは、いっしょに集まったとき、イエスにこう尋ねた。「主よ。今こそ、イスラエルのために国を再興してくださるのですか。」</span>
<span className="v" id="v7" data-v="7" data-xref="マタイの福音書 24:36; テサロニケ人への手紙第一 5:1–2; マルコの福音書 13:32"> イエスは言われた。「いつとか、どんなときとかいうことは、あなたがたは知らなくてもよいのです。それは、父がご自分の権威をもってお定めになっています。</span>
<span className="v" id="v8" data-v="8" data-xref="マタイの福音書 28:19; マルコの福音書 16:15; ローマ人への手紙 15:19"> しかし、聖霊があなたがたの上に臨まれるとき、あなたがたは力を受けます。そして、エルサレム、ユダヤとサマリヤの全土、および地の果てにまで、わたしの証人となります。」</span>
<span className="v" id="v9" data-v="9" data-xref="Daniel 7:13; ルカの福音書 24:50–51; マルコの福音書 16:19"> こう言ってから、イエスは彼らが見ている間に上げられ、雲に包まれて、見えなくなられた。</span>
<span className="v" id="v10" data-v="10" data-xref="ルカの福音書 24:4; ヨハネの福音書 20:12; ヨハネの黙示録 7:14"> イエスが上って行かれるとき、弟子たちは天を見つめていた。すると、見よ、白い衣を着た人がふたり、彼らのそばに立っていた。</span>
<span className="v" id="v11" data-v="11" data-xref="ヨハネの黙示録 1:7; テサロニケ人への手紙第一 4:16; マルコの福音書 13:26"> そして、こう言った。「ガリラヤの人たち。なぜ天を見上げて立っているのですか。あなたがたを離れて天に上げられたこのイエスは、天に上って行かれるのをあなたがたが見たときと同じ有様で、またおいでになります。」</span>
<span className="v" id="v12" data-v="12" data-xref="ルカの福音書 24:52; マタイの福音書 21:1; ルカの福音書 24:50"> そこで、彼らはオリーブという山からエルサレムに帰った。この山はエルサレムの近くにあって、安息日の道のりほどの距離であった。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒の働き 20:8; ルカの福音書 22:12; マルコの福音書 14:15"> 彼らは町にはいると、泊まっている屋上の間に上がった。この人々は、ペテロとヨハネとヤコブとアンデレ、ピリポとトマス、バルトロマイとマタイ、アルパヨの子ヤコブと熱心党員シモンとヤコブの子ユダであった。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒の働き 6:4; エペソ人への手紙 6:18; コロサイ人への手紙 4:2"> この人たちは、婦人たちやイエスの母マリヤ、およびイエスの兄弟たちとともに、みな心を合わせ、祈りに専念していた。</span>
<span className="v" id="v15" data-v="15" data-xref="コリント人への手紙第一 15:6; 使徒の働き 21:20; ヨハネの黙示録 3:4"> そのころ、百二十名ほどの兄弟たちが集まっていたが、ペテロはその中に立ってこう言った。</span>
<span className="v" id="v16" data-v="16" data-xref="Psalms 41:9; ヨハネの福音書 13:18; Psalms 55:12–15"> 「兄弟たち。イエスを捕えた者どもの手引きをしたユダについて、聖霊がダビデの口を通して預言された聖書のことばは、成就しなければならなかったのです。</span>
<span className="v" id="v17" data-v="17" data-xref="使徒の働き 1:25; マルコの福音書 3:19; ヨハネの福音書 17:12"> ユダは私たちの仲間として数えられており、この務めを受けていました。</span>
<span className="v" id="v18" data-v="18" data-xref="マタイの福音書 27:3–10; マタイの福音書 26:14–15; Psalms 55:23"> （ところがこの男は、不正なことをして得た報酬で地所を手に入れたが、まっさかさまに落ち、からだは真二つに裂け、はらわたが全部飛び出してしまった。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒の働き 2:22; マタイの福音書 28:15; 使徒の働き 21:40"> このことが、エルサレムの住民全部に知れて、その地所は彼らの国語でアケルダマ、すなわち『血の地所』と呼ばれるようになった。）</span>
<span className="v" id="v20" data-v="20" data-xref="Psalms 69:25; Psalms 109:8–15; 使徒の働き 1:25"> 実は詩篇には、こう書いてあるのです。『彼の住まいは荒れ果てよ、そこには住む者がいなくなれ。』また、『その職は、ほかの人に取らせよ。』</span>
<span className="v" id="v21" data-v="21" data-xref="ヨハネの福音書 15:27; ルカの福音書 10:1–2; Numbers 27:17"> ですから、主イエスが私たちといっしょに生活された間、</span>
<span className="v" id="v22" data-v="22" data-xref="使徒の働き 1:2; 使徒の働き 4:33; 使徒の働き 1:8–9"> すなわち、ヨハネのバプテスマから始まって、私たちを離れて天に上げられた日までの間、いつも私たちと行動をともにした者の中から、だれかひとりが、私たちとともにイエスの復活の証人とならなければなりません。」</span>
<span className="v" id="v23" data-v="23" data-xref="使徒の働き 15:22; 使徒の働き 1:26"> そこで、彼らは、バルサバと呼ばれ別名をユストというヨセフと、マッテヤとのふたりを立てた。</span>
<span className="v" id="v24" data-v="24" data-xref="1 Samuel 16:7; 使徒の働き 15:8; ヘブル人への手紙 4:13"> そして、こう祈った。「すべての人の心を知っておられる主よ。</span>
<span className="v" id="v25" data-v="25" data-xref="コリント人への手紙第一 9:2; ヨハネの福音書 6:70–71; ヨハネの福音書 17:12"> この務めと使徒職の地位を継がせるために、このふたりのうちのどちらをお選びになるか、お示しください。ユダは自分のところへ行くために脱落して行きましたから。」</span>
<span className="v" id="v26" data-v="26" data-xref="Leviticus 16:8; Joshua 18:10; 1 Samuel 14:41–42"> そしてふたりのためにくじを引くと、くじはマッテヤに当たったので、彼は十一人の使徒たちに加えられた。</span>

<span className="v" id="v1" data-v="1" data-xref="使徒の働き 27:26; 使徒の働き 27:44; 使徒の働き 27:39"> こうして救われてから、私たちは、ここがマルタと呼ばれる島であることを知った。</span>
<span className="v" id="v2" data-v="2" data-xref="ローマ人への手紙 1:14; ヘブル人への手紙 13:2; コロサイ人への手紙 3:11"> 島の人々は私たちに非常に親切にしてくれた。おりから雨が降りだして寒かったので、彼らは火をたいて私たちみなをもてなしてくれた。</span>
<span className="v" id="v3" data-v="3" data-xref="マタイの福音書 23:33; マタイの福音書 12:34; 使徒の働き 28:4"> パウロがひとかかえの柴をたばねて火にくべると、熱気のために、一匹のまむしがはい出して来て、彼の手に取りついた。</span>
<span className="v" id="v4" data-v="4" data-xref="ルカの福音書 13:2; ルカの福音書 13:4; ヨハネの福音書 7:24"> 島の人々は、この生き物がパウロの手から下がっているのを見て、「この人はきっと人殺しだ。海からはのがれたが、正義の女神はこの人を生かしてはおかないのだ。」と互いに話し合った。</span>
<span className="v" id="v5" data-v="5" data-xref="ルカの福音書 10:19; マルコの福音書 16:18; Psalms 91:13"> しかし、パウロは、その生き物を火の中に振り落として、何の害も受けなかった。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒の働き 12:22; 使徒の働き 14:11–13; マタイの福音書 21:9"> 島の人々は、彼が今にも、はれ上がって来るか、または、倒れて急死するだろうと待っていた。しかし、いくら待っても、彼に少しも変わった様子が見えないので、彼らは考えを変えて、「この人は神さまだ。」と言いだした。</span>
<span className="v" id="v7" data-v="7" data-xref="マタイの福音書 10:40–41; ルカの福音書 19:6–9; 使徒の働き 28:2"> さて、その場所の近くに、島の首長でポプリオという人の領地があった。彼はそこに私たちを招待して、三日間手厚くもてなしてくれた。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒の働き 9:40; マルコの福音書 6:5; ヤコブの手紙 5:14–16"> たまたまポプリオの父が、熱病と下痢とで床に着いていた。そこでパウロは、その人のもとに行き、祈ってから、彼の上に手を置いて直してやった。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒の働き 5:12; マルコの福音書 6:54–56; 使徒の働き 5:15"> このことがあってから、島のほかの病人たちも来て、直してもらった。</span>
<span className="v" id="v10" data-v="10" data-xref="テサロニケ人への手紙第一 2:6; ピリピ人への手紙 4:11–12; マタイの福音書 6:31–34"> それで彼らは、私たちを非常に尊敬し、私たちが出帆するときには、私たちに必要な品々を用意してくれた。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒の働き 27:6; コリント人への手紙第一 8:4; Isaiah 45:20"> 三か月後に、私たちは、この島で冬を過ごしていた、船首にデオスクロイの飾りのある、アレキサンドリヤの船で出帆した。</span>
<span className="v" id="v12" data-v="12"> シラクサに寄港して、三日間とどまり、</span>
<span className="v" id="v13" data-v="13" data-xref="使徒の働き 27:13"> そこから回って、レギオンに着いた。一日たつと、南風が吹き始めたので、二日目にはポテオリに入港した。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒の働き 21:4; 使徒の働き 20:6; 使徒の働き 19:1"> ここで、私たちは兄弟たちに会い、勧められるままに彼らのところに七日間滞在した。こうして、私たちはローマに到着した。</span>
<span className="v" id="v15" data-v="15" data-xref="ヘブル人への手紙 13:3; ローマ人への手紙 15:24; Exodus 4:14"> 私たちのことを聞いた兄弟たちは、ローマからアピオ・ポロとトレス・タベルネまで出迎えに来てくれた。パウロは彼らに会って、神に感謝し、勇気づけられた。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒の働き 27:3; 使徒の働き 24:23; 使徒の働き 28:30–31"> 私たちがローマにはいると、パウロは番兵付きで自分だけの家に住むことが許された。</span>
<span className="v" id="v17" data-v="17" data-xref="使徒の働き 25:8; 使徒の働き 6:14; 使徒の働き 25:10"> 三日の後、パウロはユダヤ人のおもだった人たちを呼び集め、彼らが集まったときに、こう言った。「兄弟たち。私は、私の国民に対しても、先祖の慣習に対しても、何一つそむくことはしていないのに、エルサレムで囚人としてローマ人の手に渡されました。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒の働き 26:31–32; 使徒の働き 23:29; 使徒の働き 22:24–25"> ローマ人は私を取り調べましたが、私を死刑にする理由が何もなかったので、私を釈放しようと思ったのです。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒の働き 26:32; 使徒の働き 25:21; 使徒の働き 25:10–12"> ところが、ユダヤ人たちが反対したため、私はやむなくカイザルに上訴しました。それは、私の同胞を訴えようとしたのではありません。</span>
<span className="v" id="v20" data-v="20" data-xref="エペソ人への手紙 6:20; テモテへの手紙第二 2:9; 使徒の働き 26:6–7"> このようなわけで、私は、あなたがたに会ってお話ししようと思い、お招きしました。私はイスラエルの望みのためにこの鎖につながれているのです。」</span>
<span className="v" id="v21" data-v="21" data-xref="Isaiah 54:17; Isaiah 41:11; Isaiah 50:8"> すると、彼らはこう言った。「私たちは、あなたのことについて、ユダヤから何の知らせも受けておりません。また、当地に来た兄弟たちの中で、あなたについて悪いことを告げたり、話したりした者はおりません。</span>
<span className="v" id="v22" data-v="22" data-xref="ペテロの手紙第一 2:12; 使徒の働き 24:14; ペテロの手紙第一 3:16"> 私たちは、あなたが考えておられることを、直接あなたから聞くのがよいと思っています。この宗派については、至る所で非難があることを私たちは知っているからです。」</span>
<span className="v" id="v23" data-v="23" data-xref="使徒の働き 17:2–3; 使徒の働き 19:8; 使徒の働き 18:28"> そこで、彼らは日を定めて、さらに大ぜいでパウロの宿にやって来た。彼は朝から晩まで語り続けた。神の国のことをあかしし、また、モーセの律法と預言者たちの書によって、イエスのことについて彼らを説得しようとした。</span>
<span className="v" id="v24" data-v="24" data-xref="使徒の働き 14:4; 使徒の働き 17:4–5; 使徒の働き 19:8–9"> ある人々は彼の語る事を信じたが、ある人々は信じようとしなかった。</span>
<span className="v" id="v25" data-v="25" data-xref="マタイの福音書 15:7; ペテロの手紙第二 1:21; マルコの福音書 7:6"> こうして、彼らは、お互いの意見が一致せずに帰りかけたので、パウロは一言、次のように言った。「聖霊が預言者イザヤを通してあなたがたの先祖に語られたことは、まさにそのとおりでした。</span>
<span className="v" id="v26" data-v="26" data-xref="Isaiah 6:9–10; Ezekiel 12:2; Isaiah 42:19–20"> 『この民のところに行って、告げよ。 あなたがたは確かに聞きはするが、 決して悟らない。 確かに見てはいるが、決してわからない。</span>
<span className="v" id="v27" data-v="27" data-xref="Isaiah 6:10"> この民の心は鈍くなり、 その耳は遠く、 その目はつぶっているからである。 それは、彼らがその目で見、 その耳で聞き、 その心で悟って、立ち返り、 わたしにいやされることのないためである。』</span>
<span className="v" id="v28" data-v="28" data-xref="ルカの福音書 2:30–32; 使徒の働き 26:17–18; ローマ人への手紙 3:29–30"> ですから、承知しておいてください。神のこの救いは、異邦人に送られました。彼らは、耳を傾けるでしょう。」</span>
<span className="v" id="v29" data-v="29"> こうしてパウロは満二年の間、自費で借りた家に住み、たずねて来る人たちをみな迎えて、</span>
<span className="v" id="v31" data-v="31" data-xref="使徒の働き 4:29; エペソ人への手紙 6:19–20; マタイの福音書 4:23"> 大胆に、少しも妨げられることなく、神の国を宣べ伝え、主イエス・キリストのことを教えた。</span>

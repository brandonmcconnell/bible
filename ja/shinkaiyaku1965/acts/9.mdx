<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒の働き 8:3; テモテへの手紙第一 1:13; ガラテヤ人への手紙 1:13"> さてサウロは、なおも主の弟子たちに対する脅かしと殺害の意に燃えて、大祭司のところに行き、</span>
<span className="v" id="v2" data-v="2" data-xref="使徒の働き 19:9; 使徒の働き 19:23; 使徒の働き 24:14"> ダマスコの諸会堂あての手紙を書いてくれるよう頼んだ。それは、この道の者であれば男でも女でも、見つけ次第縛り上げてエルサレムに引いて来るためであった。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒の働き 26:12–13; コリント人への手紙第一 15:8; 使徒の働き 22:6"> ところが、道を進んで行って、ダマスコの近くまで来たとき、突然、天からの光が彼を巡り照らした。</span>
<span className="v" id="v4" data-v="4" data-xref="Zechariah 2:8; Genesis 22:11; ローマ人への手紙 11:22"> 彼は地に倒れて、「サウロ、サウロ。なぜわたしを迫害するのか。」という声を聞いた。</span>
<span className="v" id="v5" data-v="5" data-xref="テモテへの手紙第一 1:13; 1 Samuel 3:4–10; Job 9:4"> 彼が、「主よ。あなたはどなたですか。」と言うと、お答えがあった。「わたしは、あなたが迫害しているイエスである。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒の働き 22:10; 使徒の働き 26:16; テモテへの手紙第一 1:14–16"> 立ち上がって、町にはいりなさい。そうすれば、あなたのしなければならないことが告げられるはずです。」</span>
<span className="v" id="v7" data-v="7" data-xref="使徒の働き 22:9; Daniel 10:7; 使徒の働き 26:13–14"> 同行していた人たちは、声は聞こえても、だれも見えないので、ものも言えずに立っていた。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒の働き 22:11; 使徒の働き 9:18; 2 Kings 6:17–20"> サウロは地面から立ち上がったが、目は開いていても何も見えなかった。そこで人々は彼の手を引いて、ダマスコへ連れて行った。</span>
<span className="v" id="v9" data-v="9" data-xref="Jonah 3:6–8; Esther 4:16; 2 Chronicles 33:12–13"> 彼は三日の間、目が見えず、また飲み食いもしなかった。</span>
<span className="v" id="v10" data-v="10" data-xref="Genesis 22:1; 使徒の働き 10:3; 使徒の働き 22:12"> さて、ダマスコにアナニヤという弟子がいた。主が彼に幻の中で、「アナニヤよ。」と言われたので、「主よ。ここにおります。」と答えた。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒の働き 21:39; 使徒の働き 22:3; 使徒の働き 9:30"> すると主はこう言われた。「立って、『まっすぐ』という街路に行き、サウロというタルソ人をユダの家に尋ねなさい。そこで、彼は祈っています。</span>
<span className="v" id="v12" data-v="12" data-xref="マルコの福音書 5:23; 使徒の働き 9:10; 使徒の働き 9:17–18"> 彼は、アナニヤという者がはいって来て、自分の上に手を置くと、目が再び見えるようになるのを、幻で見たのです。」</span>
<span className="v" id="v13" data-v="13" data-xref="テモテへの手紙第一 1:13–15; 使徒の働き 8:3; 使徒の働き 22:19–20"> しかし、アナニヤはこう答えた。「主よ。私は多くの人々から、この人がエルサレムで、あなたの聖徒たちにどんなにひどいことをしたかを聞きました。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒の働き 9:21; 使徒の働き 7:59; テモテへの手紙第二 2:22"> 彼はここでも、あなたの御名を呼ぶ者たちをみな捕縛する権限を、祭司長たちから授けられているのです。」</span>
<span className="v" id="v15" data-v="15" data-xref="ガラテヤ人への手紙 1:15–16; エペソ人への手紙 3:7–8; テモテへの手紙第二 4:16–17"> しかし、主はこう言われた。「行きなさい。あの人はわたしの名を、異邦人、王たち、イスラエルの子孫の前に運ぶ、わたしの選びの器です。</span>
<span className="v" id="v16" data-v="16" data-xref="テサロニケ人への手紙第一 3:3; 使徒の働き 21:11; コリント人への手紙第二 6:4"> 彼がわたしの名のために、どんなに苦しまなければならないかを、わたしは彼に示すつもりです。」</span>
<span className="v" id="v17" data-v="17" data-xref="使徒の働き 8:17; 使徒の働き 6:6; 使徒の働き 2:4"> そこでアナニヤは出かけて行って、その家にはいり、サウロの上に手を置いてこう言った。「兄弟サウロ。あなたが来る途中でお現われになった主イエスが、私を遣わされました。あなたが再び見えるようになり、聖霊に満たされるためです。」</span>
<span className="v" id="v18" data-v="18" data-xref="コリント人への手紙第二 3:14; 使徒の働き 22:16; 使徒の働き 2:38"> するとただちに、サウロの目からうろこのような物が落ちて、目が見えるようになった。彼は立ち上がって、バプテスマを受け、</span>
<span className="v" id="v19" data-v="19" data-xref="使徒の働き 26:20; 1 Samuel 30:12; ガラテヤ人への手紙 1:17"> 食事をして元気づいた。 サウロは数日の間、ダマスコの弟子たちとともにいた。</span>
<span className="v" id="v20" data-v="20" data-xref="ヨハネの福音書 20:28; ガラテヤ人への手紙 2:20; ヨハネの手紙第一 4:14–15"> そしてただちに、諸会堂で、イエスは神の子であると宣べ伝え始めた。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒の働き 9:13–14; 使徒の働き 8:3; テサロニケ人への手紙第二 1:10"> これを聞いた人々はみな、驚いてこう言った。「この人はエルサレムで、この御名を呼ぶ者たちを滅ぼした者ではありませんか。ここへやって来たのも、彼らを縛って、祭司長たちのところへ引いて行くためではないのですか。」</span>
<span className="v" id="v22" data-v="22" data-xref="使徒の働き 18:5; Isaiah 40:29; ルカの福音書 21:15"> しかしサウロはますます力を増し、イエスがキリストであることを証明して、ダマスコに住むユダヤ人たちをうろたえさせた。</span>
<span className="v" id="v23" data-v="23" data-xref="ガラテヤ人への手紙 1:17–18; テサロニケ人への手紙第一 2:15–16; 使徒の働き 14:19"> 多くの日数がたって後、ユダヤ人たちはサウロを殺す相談をしたが、</span>
<span className="v" id="v24" data-v="24" data-xref="コリント人への手紙第二 11:32; 使徒の働き 25:3; 使徒の働き 20:3"> その陰謀はサウロに知られてしまった。彼らはサウロを殺してしまおうと、昼も夜も町の門を全部見張っていた。</span>
<span className="v" id="v25" data-v="25" data-xref="Joshua 2:15; コリント人への手紙第二 11:33; 1 Samuel 19:11–12"> そこで、彼の弟子たちは、夜中に彼をかごに乗せ、町の城壁伝いにつり降ろした。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒の働き 26:20; ガラテヤ人への手紙 1:17–19; 使徒の働き 9:19"> サウロはエルサレムに着いて、弟子たちの仲間にはいろうと試みたが、みなは彼を弟子だとは信じないで、恐れていた。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒の働き 4:36; 使徒の働き 4:29; 使徒の働き 4:13"> ところが、バルナバは彼を引き受けて、使徒たちのところへ連れて行き、彼がダマスコへ行く途中で主を見た様子や、主が彼に向かって語られたこと、また彼がダマスコでイエスの御名を大胆に宣べた様子などを彼らに説明した。</span>
<span className="v" id="v28" data-v="28" data-xref="使徒の働き 1:21; Numbers 27:16–17; Psalms 121:8"> それからサウロは、エルサレムで弟子たちとともにいて自由に出はいりし、主の御名によって大胆に語った。</span>
<span className="v" id="v29" data-v="29" data-xref="使徒の働き 6:1; ユダの手紙 1:9; 使徒の働き 11:20"> そして、ギリシヤ語を使うユダヤ人たちと語ったり、論じたりしていた。しかし、彼らはサウロを殺そうとねらっていた。</span>
<span className="v" id="v30" data-v="30" data-xref="使徒の働き 11:25; 使徒の働き 8:40; 使徒の働き 9:11"> 兄弟たちはそれと知って、彼をカイザリヤに連れて下り、タルソへ送り出した。</span>
<span className="v" id="v31" data-v="31" data-xref="Psalms 111:10; ヨハネの福音書 14:16–18; Isaiah 33:6"> こうして教会は、ユダヤ、ガリラヤ、サマリヤの全地にわたり築き上げられて平安を保ち、主を恐れかしこみ、聖霊に励まされて前進し続けたので、信者の数がふえて行った。</span>
<span className="v" id="v32" data-v="32" data-xref="使徒の働き 9:13; 使徒の働き 8:25; Proverbs 2:8"> さて、ペテロはあらゆる所を巡回したが、ルダに住む聖徒たちのところへも下って行った。</span>
<span className="v" id="v33" data-v="33" data-xref="ルカの福音書 13:16; ヨハネの福音書 5:5; マルコの福音書 2:3–11"> 彼はそこで、八年の間も床に着いているアイネヤという人に出会った。彼は中風であった。</span>
<span className="v" id="v34" data-v="34" data-xref="マタイの福音書 9:6; 使徒の働き 3:12; 使徒の働き 3:6"> ペテロは彼にこう言った。「アイネヤ。イエス・キリストがあなたをいやしてくださるのです。立ち上がりなさい。そして自分で床を整えなさい。」すると彼はただちに立ち上がった。</span>
<span className="v" id="v35" data-v="35" data-xref="使徒の働き 11:21; 使徒の働き 9:42; 1 Chronicles 5:16"> ルダとサロンに住む人々はみな、アイネヤを見て、主に立ち返った。</span>
<span className="v" id="v36" data-v="36" data-xref="テトスへの手紙 3:8; テトスへの手紙 2:7; 2 Chronicles 2:16"> ヨッパにタビタ（ギリシヤ語に訳せば、ドルカス）という女の弟子がいた。この女は、多くの良いわざと施しをしていた。</span>
<span className="v" id="v37" data-v="37" data-xref="使徒の働き 1:13; 使徒の働き 20:8; ヨハネの福音書 11:36–37"> ところが、そのころ彼女は病気になって死に、人々はその遺体を洗って、屋上の間に置いた。</span>
<span className="v" id="v38" data-v="38" data-xref="使徒の働き 9:36; 使徒の働き 11:26; 使徒の働き 9:32"> ルダはヨッパに近かったので、弟子たちは、ペテロがそこにいると聞いて、人をふたり彼のところへ送って、「すぐに来てください。」と頼んだ。</span>
<span className="v" id="v39" data-v="39" data-xref="Proverbs 10:7; Proverbs 31:30–31; テサロニケ人への手紙第一 1:3"> そこでペテロは立って、いっしょに出かけた。ペテロが到着すると、彼らは屋上の間に案内した。やもめたちはみな泣きながら、彼のそばに来て、ドルカスがいっしょにいたころ作ってくれた下着や上着の数々を見せるのであった。</span>
<span className="v" id="v40" data-v="40" data-xref="マタイの福音書 9:25; マルコの福音書 5:40–42; ルカの福音書 8:54"> ペテロはみなの者を外に出し、ひざまずいて祈った。そしてその遺体のほうを向いて、「タビタ。起きなさい。」と言った。すると彼女は目をあけ、ペテロを見て起き上がった。</span>
<span className="v" id="v41" data-v="41" data-xref="マルコの福音書 1:31; 使徒の働き 6:1; Genesis 45:26"> そこで、ペテロは手を貸して彼女を立たせた。そして聖徒たちとやもめたちとを呼んで、生きている彼女を見せた。</span>
<span className="v" id="v42" data-v="42" data-xref="ヨハネの福音書 12:44; ヨハネの福音書 12:11; ヨハネの福音書 11:45"> このことがヨッパ中に知れ渡り、多くの人々が主を信じた。</span>
<span className="v" id="v43" data-v="43" data-xref="使徒の働き 10:6; 使徒の働き 10:32"> そして、ペテロはしばらくの間、ヨッパで、皮なめしのシモンという人の家に泊まっていた。</span>

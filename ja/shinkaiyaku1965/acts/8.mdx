<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒の働き 22:20; Daniel 3:16–18; 使徒の働き 5:40"> サウロは、ステパノを殺すことに賛成していた。その日、エルサレムの教会に対する激しい迫害が起こり、使徒たち以外の者はみな、ユダヤとサマリヤの諸地方に散らされた。</span>
<span className="v" id="v2" data-v="2" data-xref="Genesis 50:10–11; Genesis 23:2; Jeremiah 22:18"> 敬虔な人たちはステパノを葬り、彼のために非常に悲しんだ。</span>
<span className="v" id="v3" data-v="3" data-xref="テモテへの手紙第一 1:13; ガラテヤ人への手紙 1:13; コリント人への手紙第一 15:9"> サウロは教会を荒らし、家々にはいって、男も女も引きずり出し、次々に牢に入れた。</span>
<span className="v" id="v4" data-v="4" data-xref="マタイの福音書 10:23; 使徒の働き 11:19; 使徒の働き 8:1"> 他方、散らされた人たちは、みことばを宣べながら、巡り歩いた。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒の働き 6:5; 使徒の働き 21:8; 使徒の働き 8:35–36"> ピリポはサマリヤの町に下って行き、人々にキリストを宣べ伝えた。</span>
<span className="v" id="v6" data-v="6" data-xref="ヨハネの福音書 4:41–42; 2 Chronicles 30:12; マタイの福音書 20:15–16"> 群衆はピリポの話を聞き、その行なっていたしるしを見て、みなそろって、彼の語ることに耳を傾けた。</span>
<span className="v" id="v7" data-v="7" data-xref="マタイの福音書 10:1; 使徒の働き 14:8–10; マルコの福音書 16:17–18"> 汚れた霊につかれた多くの人たちからは、その霊が大声で叫んで出て行くし、大ぜいの中風の者や足のきかない者は直ったからである。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒の働き 13:52; 使徒の働き 13:48; 使徒の働き 8:39"> それでその町に大きな喜びが起こった。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒の働き 13:6; 使徒の働き 5:36; ヨハネの福音書 7:18"> ところが、この町にシモンという人がいた。彼は以前からこの町で魔術を行なって、サマリヤの人々を驚かし、自分は偉大な者だと話していた。</span>
<span className="v" id="v10" data-v="10" data-xref="Jeremiah 31:34; ペテロの手紙第二 2:2; ヨハネの黙示録 13:3"> 小さな者から大きな者に至るまで、あらゆる人々が彼に関心を抱き、「この人こそ、大能と呼ばれる、神の力だ。」と言っていた。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒の働き 8:9; ガラテヤ人への手紙 3:1; Isaiah 44:25"> 人々が彼に関心を抱いたのは、長い間、その魔術に驚かされていたからである。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒の働き 2:38; 使徒の働き 1:3; マタイの福音書 28:19"> しかし、ピリポが神の国とイエス・キリストの御名について宣べるのを信じた彼らは、男も女もバプテスマを受けた。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒の働き 8:6–7; ヨハネの福音書 5:20; 使徒の働き 19:11"> シモン自身も信じて、バプテスマを受け、いつもピリポについていた。そして、しるしとすばらしい奇蹟が行なわれるのを見て、驚いていた。</span>
<span className="v" id="v14" data-v="14" data-xref="テサロニケ人への手紙第一 2:13; テサロニケ人への手紙第一 3:2; ガラテヤ人への手紙 2:9"> さて、エルサレムにいる使徒たちは、サマリヤの人々が神のことばを受け入れたと聞いて、ペテロとヨハネを彼らのところへ遣わした。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒の働き 2:38; ヨハネの福音書 16:23–24; ヨハネの福音書 14:13–14"> ふたりは下って行って、人々が聖霊を受けるように祈った。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒の働き 2:38; 使徒の働き 19:2; マタイの福音書 28:19"> 彼らは主イエスの御名によってバプテスマを受けていただけで、聖霊がまだだれにも下っておられなかったからである。</span>
<span className="v" id="v17" data-v="17" data-xref="使徒の働き 19:6; 使徒の働き 6:6; テモテへの手紙第二 1:6"> ふたりが彼らの上に手を置くと、彼らは聖霊を受けた。</span>
<span className="v" id="v18" data-v="18" data-xref="テモテへの手紙第一 6:5; マタイの福音書 10:8; 2 Kings 8:9"> 使徒たちが手を置くと聖霊が与えられるのを見たシモンは、使徒たちのところに金を持って来て、</span>
<span className="v" id="v19" data-v="19" data-xref="ルカの福音書 14:7–11; ヨハネの手紙第三 1:9; ヨハネの福音書 5:44"> 「私が手を置いた者がだれでも聖霊を受けられるように、この権威を私にも下さい。」と言った。</span>
<span className="v" id="v20" data-v="20" data-xref="Daniel 5:17; マタイの福音書 10:8; 使徒の働き 2:38"> ペテロは彼に向かって言った。「あなたの金は、あなたとともに滅びるがよい。あなたは金で神の賜物を手に入れようと思っているからです。</span>
<span className="v" id="v21" data-v="21" data-xref="ヘブル人への手紙 4:13; Psalms 36:1; マタイの福音書 6:22–24"> あなたは、このことについては何の関係もないし、それにあずかることもできません。あなたの心が神の前に正しくないからです。</span>
<span className="v" id="v22" data-v="22" data-xref="テモテへの手紙第二 2:25–26; Daniel 4:27; ヘブル人への手紙 4:12"> だから、この悪事を悔い改めて、主に祈りなさい。あるいは、心に抱いた思いが赦されるかもしれません。</span>
<span className="v" id="v23" data-v="23" data-xref="Isaiah 58:6; Proverbs 5:22; ヨハネの福音書 8:34"> あなたはまだ苦い胆汁と不義のきずなの中にいることが、私にはよくわかっています。」</span>
<span className="v" id="v24" data-v="24" data-xref="Exodus 8:8; Numbers 21:7; Job 42:8"> シモンは答えて言った。「あなたがたの言われた事が何も私に起こらないように、私のために主に祈ってください。」</span>
<span className="v" id="v25" data-v="25" data-xref="使徒の働き 20:21; 使徒の働き 26:22–23; 使徒の働き 1:8"> このようにして、使徒たちはおごそかにあかしをし、また主のことばを語って後、エルサレムへの帰途につき、サマリヤ人の多くの村でも福音を宣べ伝えた。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒の働き 5:19; ヘブル人への手紙 1:14; 2 Kings 1:3"> ところが、主の使いがピリポに向かってこう言った。「立って南へ行き、エルサレムからガザに下る道に出なさい。」（このガザは今、荒れ果てている。）</span>
<span className="v" id="v27" data-v="27" data-xref="Zephaniah 3:10; Psalms 68:31; Isaiah 56:3–8"> そこで、彼は立って出かけた。すると、そこに、エチオピヤ人の女王カンダケの高官で、女王の財産全部を管理していた宦官のエチオピヤ人がいた。彼は礼拝のためエルサレムに上り、</span>
<span className="v" id="v28" data-v="28" data-xref="コロサイ人への手紙 3:16; Isaiah 1:1; 使徒の働き 28:25"> いま帰る途中であった。彼は馬車に乗って、預言者イザヤの書を読んでいた。</span>
<span className="v" id="v29" data-v="29" data-xref="使徒の働き 10:19; 使徒の働き 11:12; 使徒の働き 20:22–23"> 御霊がピリポに「近寄って、あの馬車といっしょに行きなさい。」と言われた。</span>
<span className="v" id="v30" data-v="30" data-xref="ルカの福音書 24:44–45; ヨハネの福音書 5:39; エペソ人への手紙 5:17"> そこでピリポが走って行くと、預言者イザヤの書を読んでいるのが聞こえたので、「あなたは、読んでいることが、わかりますか。」と言った。</span>
<span className="v" id="v31" data-v="31" data-xref="ローマ人への手紙 10:14; Psalms 73:16–17; Isaiah 29:18–19"> すると、その人は、「導く人がなければ、どうしてわかりましょう。」と言った。そして馬車に乗っていっしょにすわるように、ピリポに頼んだ。</span>
<span className="v" id="v32" data-v="32" data-xref="Isaiah 53:7–8; ペテロの手紙第一 2:21–24; Jeremiah 51:40"> 彼が読んでいた聖書の個所には、こう書いてあった。 「ほふり場に連れて行かれる羊のように、 また、黙々として 毛を刈る者の前に立つ小羊のように、 彼は口を開かなかった。</span>
<span className="v" id="v33" data-v="33" data-xref="Isaiah 53:12; Isaiah 53:8; Zechariah 13:7"> 彼は、卑しめられ、そのさばきも取り上げられた。 彼の時代のことを、だれが話すことができようか。 彼のいのちは地上から取り去られたのである。」</span>
<span className="v" id="v34" data-v="34" data-xref="マタイの福音書 15:15; マタイの福音書 13:36; マタイの福音書 2:2–4"> 宦官はピリポに向かって言った。「預言者はだれについて、こう言っているのですか。どうか教えてください。自分についてですか。それとも、だれかほかの人についてですか。」</span>
<span className="v" id="v35" data-v="35" data-xref="ルカの福音書 24:27; 使徒の働き 18:28; 使徒の働き 28:23"> ピリポは口を開き、この聖句から始めて、イエスのことを彼に宣べ伝えた。</span>
<span className="v" id="v36" data-v="36" data-xref="使徒の働き 10:47; ヨハネの福音書 3:5; テトスへの手紙 3:5–6"> 道を進んで行くうちに、水のある所に来たので、宦官は言った。「ご覧なさい。水があります。私がバプテスマを受けるのに、何かさしつかえがあるでしょうか。」</span>
<span className="v" id="v37" data-v="37"> そして馬車を止めさせ、ピリポも宦官も水の中へ降りて行き、ピリポは宦官にバプテスマを授けた。</span>
<span className="v" id="v39" data-v="39" data-xref="1 Kings 18:12; 2 Kings 2:16; Ezekiel 8:3"> 水から上がって来たとき、主の霊がピリポを連れ去られたので、宦官はそれから後彼を見なかったが、喜びながら帰って行った。</span>
<span className="v" id="v40" data-v="40" data-xref="使徒の働き 21:8; 使徒の働き 23:23; 使徒の働き 23:33"> それからピリポはアゾトに現われ、すべての町々を通って福音を宣べ伝え、カイザリヤに行った。</span>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ガラテヤ人への手紙 5:6; 使徒の働き 15:5; Leviticus 12:3"> さて、ある人々がユダヤから下って来て、兄弟たちに、「モーセの慣習に従って割礼を受けなければ、あなたがたは救われない。」と教えていた。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒の働き 15:22–23; 使徒の働き 15:6–7; ガラテヤ人への手紙 2:1–2"> そしてパウロやバルナバと彼らとの間に激しい対立と論争が生じたので、パウロとバルナバと、その仲間のうちの幾人かが、この問題について使徒たちや長老たちと話し合うために、エルサレムに上ることになった。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒の働き 14:27; 使徒の働き 21:5; コリント人への手紙第一 16:11"> 彼らは教会の人々に見送られ、フェニキヤとサマリヤを通る道々で、異邦人の改宗のことを詳しく話したので、すべての兄弟たちに大きな喜びをもたらした。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒の働き 14:27; 使徒の働き 15:12; 使徒の働き 15:3"> エルサレムに着くと、彼らは教会と使徒たちと長老たちに迎えられ、神が彼らとともにいて行なわれたことを、みなに報告した。</span>
<span className="v" id="v5" data-v="5" data-xref="ガラテヤ人への手紙 5:1–3; ピリピ人への手紙 3:5–8; 使徒の働き 15:1"> しかし、パリサイ派の者で信者になった人々が立ち上がり、「異邦人にも割礼を受けさせ、また、モーセの律法を守ることを命じるべきである。」と言った。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="Proverbs 15:22; ヘブル人への手紙 13:7; ヘブル人への手紙 13:17"> そこで使徒たちと長老たちは、この問題を検討するために集まった。</span>
<span className="v" id="v7" data-v="7" data-xref="ローマ人への手紙 10:17–18; ガラテヤ人への手紙 2:7–9; 1 Chronicles 28:4–5"> 激しい論争があって後、ペテロが立ち上がって言った。「兄弟たち。ご存じのとおり、神は初めのころ、あなたがたの間で事をお決めになり、異邦人が私の口から福音のことばを聞いて信じるようにされたのです。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒の働き 1:24; 使徒の働き 10:47; 使徒の働き 14:3"> そして、人の心の中を知っておられる神は、私たちに与えられたと同じように異邦人にも聖霊を与えて、彼らのためにあかしをし、</span>
<span className="v" id="v9" data-v="9" data-xref="エペソ人への手紙 3:6; ガラテヤ人への手紙 5:6; 使徒の働き 10:28"> 私たちと彼らとに何の差別もつけず、彼らの心を信仰によってきよめてくださったのです。</span>
<span className="v" id="v10" data-v="10" data-xref="ガラテヤ人への手紙 5:1; マタイの福音書 23:4; ガラテヤ人への手紙 4:9"> それなのに、なぜ、今あなたがたは、私たちの先祖も私たちも負いきれなかったくびきを、あの弟子たちの首に掛けて、神を試みようとするのです。</span>
<span className="v" id="v11" data-v="11" data-xref="ローマ人への手紙 3:24; テトスへの手紙 3:4–7; テトスへの手紙 2:11"> 私たちが主イエスの恵みによって救われたことを私たちは信じますが、あの人たちもそうなのです。」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="使徒の働き 14:27; 使徒の働き 15:4; 使徒の働き 21:19"> すると、全会衆は沈黙してしまった。そして、バルナバとパウロが、彼らを通して神が異邦人の間で行なわれたしるしと不思議なわざについて話すのに、耳を傾けた。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒の働き 12:17; ガラテヤ人への手紙 2:12; ヤコブの手紙 1:1"> ふたりが話し終えると、ヤコブがこう言った。「兄弟たち。私の言うことを聞いてください。</span>
<span className="v" id="v14" data-v="14" data-xref="ペテロの手紙第二 1:1; 使徒の働き 15:7–9; ルカの福音書 2:31–32"> 神が初めに、どのように異邦人を顧みて、その中から御名をもって呼ばれる民をお召しになったかは、シメオンが説明したとおりです。</span>
<span className="v" id="v15" data-v="15" data-xref="ローマ人への手紙 15:8–12; 使徒の働き 13:47"> 預言者たちのことばもこれと一致しており、それにはこう書いてあります。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="Amos 9:11–12; Psalms 89:35–49; ルカの福音書 1:31–33"> 『この後、わたしは帰って来て、<br />倒れたダビデの幕屋を建て直す。<br />すなわち、廃墟と化した幕屋を建て直し、<br />それを元どおりにする。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="Zechariah 2:11; Zechariah 8:20–23; Isaiah 65:1"> それは、残った人々、すなわち、<br />わたしの名で呼ばれる異邦人がみな、<br />主を求めるようになるためである。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="エペソ人への手紙 1:4; エペソ人への手紙 3:9; Isaiah 46:9–10"> 大昔からこれらのことを知らせておられる主が、<br />こう言われる。』</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="使徒の働き 15:28; ガラテヤ人への手紙 1:7–10; 使徒の働き 15:24"> そこで、私の判断では、神に立ち返る異邦人を悩ませてはいけません。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒の働き 15:29; ヨハネの黙示録 2:20; Leviticus 3:17"> ただ、偶像に供えて汚れた物と不品行と絞め殺した物と血とを避けるように書き送るべきだと思います。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒の働き 13:15; 使徒の働き 13:27; コリント人への手紙第二 3:14–15"> 昔から、町ごとにモーセの律法を宣べる者がいて、それが安息日ごとに諸会堂で読まれているからです。」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="使徒の働き 15:27; 使徒の働き 15:40; テサロニケ人への手紙第一 1:1"> そこで使徒たちと長老たち、また、全教会もともに、彼らの中から人を選んで、パウロやバルナバといっしょにアンテオケへ送ることを決議した。選ばれたのは兄弟たちの中の指導者たちで、バルサバと呼ばれるユダおよびシラスであった。</span>
<span className="v" id="v23" data-v="23" data-xref="使徒の働き 23:26; ヤコブの手紙 1:1; ガラテヤ人への手紙 1:21"> 彼らはこの人たちに託して、こう書き送った。「使徒および長老たちは、アンテオケ、シリヤ、キリキヤにいる異邦人の兄弟たちに、あいさつをいたします。</span>
<span className="v" id="v24" data-v="24" data-xref="ガラテヤ人への手紙 5:12; ガラテヤ人への手紙 5:10; 使徒の働き 15:1"> 私たちの中のある者たちが、私たちからは何も指示を受けていないのに、いろいろなことを言ってあなたがたを動揺させ、あなたがたの心を乱したことを聞きました。</span>
<span className="v" id="v25" data-v="25" data-xref="ペテロの手紙第二 3:15; 使徒の働き 1:14; 使徒の働き 15:2"> そこで、私たちは人々を選び、私たちの愛するバルナバおよびパウロといっしょに、あなたがたのところへ送ることに衆議一決しました。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒の働き 14:19; 使徒の働き 9:23–25; ピリピ人への手紙 2:29–30"> このバルナバとパウロは、私たちの主イエス・キリストの御名のために、いのちを投げ出した人たちです。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒の働き 15:22; 使徒の働き 15:32; ヨハネの手紙第三 1:13"> こういうわけで、私たちはユダとシラスを送りました。彼らは口頭で同じ趣旨のことを伝えるはずです。</span>
<span className="v" id="v28" data-v="28" data-xref="ヨハネの福音書 16:13; ヨハネの黙示録 2:24; マタイの福音書 11:30"> 聖霊と私たちは、次のぜひ必要な事のほかは、あなたがたにその上、どんな重荷も負わせないことを決めました。</span>
<span className="v" id="v29" data-v="29" data-xref="使徒の働き 15:20; 使徒の働き 21:25; ヨハネの黙示録 2:14"> すなわち、偶像に供えた物と、血と、絞め殺した物と、不品行とを避けることです。これらのことを注意深く避けていれば、それで結構です。以上。」</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="使徒の働き 16:4; 使徒の働き 6:2; 使徒の働き 23:33"> さて、一行は送り出されて、アンテオケに下り、教会の人々を集めて、手紙を手渡した。</span>
<span className="v" id="v31" data-v="31" data-xref="ガラテヤ人への手紙 2:4–5; ピリピ人への手紙 3:3; ガラテヤ人への手紙 5:1"> それを読んだ人々は、その励ましによって喜んだ。</span>
<span className="v" id="v32" data-v="32" data-xref="使徒の働き 11:23; 使徒の働き 14:22; 使徒の働き 13:1"> ユダもシラスも預言者であったので、多くのことばをもって兄弟たちを励まし、また力づけた。</span>
<span className="v" id="v33" data-v="33" data-xref="コリント人への手紙第一 16:11; 使徒の働き 16:36; ヘブル人への手紙 11:31"> 彼らは、しばらく滞在して後、兄弟たちの平安のあいさつに送られて、彼らを送り出した人々のところへ帰って行った。</span>
<span className="v" id="v34" data-v="34"> パウロとバルナバはアンテオケにとどまって、ほかの多くの人々とともに、主のみことばを教え、宣べ伝えた。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="使徒の働き 14:6; 使徒の働き 13:4; 使徒の働き 13:51"> 幾日かたって後、パウロはバルナバにこう言った。「先に主のことばを伝えたすべての町々の兄弟たちのところに、またたずねて行って、どうしているか見て来ようではありませんか。」</span>
<span className="v" id="v37" data-v="37" data-xref="使徒の働き 12:12; ピレモンへの手紙 1:24; 使徒の働き 13:5"> ところが、バルナバは、マルコとも呼ばれるヨハネもいっしょに連れて行くつもりであった。</span>
<span className="v" id="v38" data-v="38" data-xref="使徒の働き 13:13; Proverbs 25:19; ルカの福音書 14:27–34"> しかしパウロは、パンフリヤで一行から離れてしまい、仕事のために同行しなかったような者はいっしょに連れて行かないほうがよいと考えた。</span>
<span className="v" id="v39" data-v="39" data-xref="コロサイ人への手紙 4:10; Ecclesiastes 7:20; 使徒の働き 4:36"> そして激しい反目となり、その結果、互いに別行動をとることになって、バルナバはマルコを連れて、船でキプロスに渡って行った。</span>
<span className="v" id="v40" data-v="40" data-xref="使徒の働き 15:22; 使徒の働き 14:26; 使徒の働き 11:23"> パウロはシラスを選び、兄弟たちから主の恵みにゆだねられて出発した。</span>
<span className="v" id="v41" data-v="41" data-xref="使徒の働き 15:23; ガラテヤ人への手紙 1:21; 使徒の働き 15:32"> そして、シリヤおよびキリキヤを通り、諸教会を力づけた。</span>
</div>
</div>

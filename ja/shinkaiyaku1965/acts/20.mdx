<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="コリント人への手紙第二 7:5; 使徒の働き 19:21; テモテへの手紙第一 1:3"> 騒ぎが治まると、パウロは弟子たちを呼び集めて励まし、別れを告げて、マケドニヤへ向かって出発した。</span>
<span className="v" id="v2" data-v="2" data-xref="テサロニケ人への手紙第一 2:3; テサロニケ人への手紙第一 4:1; コロサイ人への手紙 1:28"> そして、その地方を通り、多くの勧めをして兄弟たちを励ましてから、ギリシヤに来た。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒の働き 20:19; コリント人への手紙第二 11:26; 使徒の働き 9:23–24"> パウロはここで三か月を過ごしたが、そこからシリヤに向けて船出しようというときに、彼に対するユダヤ人の陰謀があったため、彼はマケドニヤを経て帰ることにした。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒の働き 19:29; エペソ人への手紙 6:21; テモテへの手紙第二 4:20"> プロの子であるベレヤ人ソパテロ、テサロニケ人アリスタルコとセクンド、デルベ人ガイオ、テモテ、アジヤ人テキコとトロピモは、パウロに同行していたが、</span>
<span className="v" id="v5" data-v="5" data-xref="使徒の働き 16:8; 使徒の働き 16:10–11; テモテへの手紙第二 4:13"> 彼らは先発して、トロアスで私たちを待っていた。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒の働き 12:3; 使徒の働き 16:12; Exodus 23:15"> 種なしパンの祝いが過ぎてから、私たちはピリピから船出し、五日かかってトロアスで彼らと落ち合い、そこに七日間滞在した。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="コリント人への手紙第一 16:2; 使徒の働き 2:42; ヨハネの福音書 20:19"> 週の初めの日に、私たちはパンを裂くために集まった。そのときパウロは、翌日出発することにしていたので、人々と語り合い、夜中まで語り続けた。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒の働き 1:13; ルカの福音書 22:12"> 私たちが集まっていた屋上の間には、ともしびがたくさんともしてあった。</span>
<span className="v" id="v9" data-v="9" data-xref="マルコの福音書 13:36; マタイの福音書 26:40–41; Jonah 1:5–6"> ユテコというひとりの青年が窓のところに腰を掛けていたが、ひどく眠けがさし、パウロの話が長く続くので、とうとう眠り込んでしまって、三階から下に落ちた。抱き起こしてみると、もう死んでいた。</span>
<span className="v" id="v10" data-v="10" data-xref="マルコの福音書 5:39; マタイの福音書 9:23–24; 1 Kings 17:21–22"> パウロは降りて来て、彼の上に身をかがめ、彼を抱きかかえて、「心配することはない。まだいのちがあります。」と言った。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒の働き 20:7; 使徒の働き 20:9"> そして、また上がって行き、パンを裂いて食べてから、明け方まで長く話し合って、それから出発した。</span>
<span className="v" id="v12" data-v="12" data-xref="テサロニケ人への手紙第二 2:16; テサロニケ人への手紙第一 5:14; コリント人への手紙第二 1:4"> 人々は生き返った青年を家に連れて行き、ひとかたならず慰められた。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="マルコの福音書 6:46; マルコの福音書 1:35; マルコの福音書 6:31–33"> さて、私たちは先に船に乗り込んで、アソスに向けて出帆した。そしてアソスでパウロを船に乗せることにしていた。パウロが、自分は陸路をとるつもりで、そう決めておいたからである。</span>
<span className="v" id="v14" data-v="14"> こうして、パウロはアソスで私たちと落ち合い、私たちは彼を船に乗せてミテレネに着いた。</span>
<span className="v" id="v15" data-v="15" data-xref="テモテへの手紙第二 4:20; 使徒の働き 20:17"> そこから出帆して、翌日キヨスの沖に達し、次の日サモスに立ち寄り、その翌日ミレトに着いた。</span>
<span className="v" id="v16" data-v="16" data-xref="コリント人への手紙第一 16:8; 使徒の働き 2:1; 使徒の働き 19:21"> それはパウロが、アジヤで時間を取られないようにと、エペソには寄港しないで行くことに決めていたからである。彼は、できれば五旬節の日にはエルサレムに着いていたい、と旅路を急いでいたのである。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="テトスへの手紙 1:5; 使徒の働き 11:30; テモテへの手紙第一 5:17"> パウロは、ミレトからエペソに使いを送って、教会の長老たちを呼んだ。</span>
<span className="v" id="v18" data-v="18" data-xref="テサロニケ人への手紙第一 1:5–6; 使徒の働き 18:19; 使徒の働き 19:1"> 彼らが集まって来たとき、パウロはこう言った。<br />「皆さんは、私がアジヤに足を踏み入れた最初の日から、私がいつもどんなふうにあなたがたと過ごして来たか、よくご存じです。</span>
<span className="v" id="v19" data-v="19" data-xref="コロサイ人への手紙 3:24; コリント人への手紙第二 2:4; ローマ人への手紙 12:11"> 私は謙遜の限りを尽くし、涙をもって、またユダヤ人の陰謀によりわが身にふりかかる数々の試練の中で、主に仕えました。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒の働き 20:27; テモテへの手紙第二 4:2; 使徒の働き 5:42"> 益になることは、少しもためらわず、あなたがたに知らせました。人々の前でも、家々でも、あなたがたを教え、</span>
<span className="v" id="v21" data-v="21" data-xref="使徒の働き 2:38; 使徒の働き 11:18; ヨハネの手紙第一 5:11–13"> ユダヤ人にもギリシヤ人にも、神に対する悔い改めと、私たちの主イエスに対する信仰とをはっきりと主張したのです。</span>
<span className="v" id="v22" data-v="22" data-xref="ヤコブの手紙 4:14; コリント人への手紙第二 5:14; ペテロの手紙第二 1:14"> いま私は、心を縛られて、エルサレムに上る途中です。そこで私にどんなことが起こるのかわかりません。</span>
<span className="v" id="v23" data-v="23" data-xref="使徒の働き 9:16; テサロニケ人への手紙第一 3:3; 使徒の働き 21:4"> ただわかっているのは、聖霊がどの町でも私にはっきりとあかしされて、なわめと苦しみが私を待っていると言われることです。</span>
<span className="v" id="v24" data-v="24" data-xref="テモテへの手紙第二 4:6–8; コリント人への手紙第二 4:1; コリント人への手紙第二 12:10"> けれども、私が自分の走るべき行程を走り尽くし、主イエスから受けた、神の恵みの福音をあかしする任務を果たし終えることができるなら、私のいのちは少しも惜しいとは思いません。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒の働き 28:31; 使徒の働き 20:38; マタイの福音書 4:23"> 皆さん。御国を宣べ伝えてあなたがたの中を巡回した私の顔を、あなたがたはもう二度と見ることがないことを、いま私は知っています。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒の働き 18:6; Ezekiel 3:18–21; Ezekiel 33:2–9"> ですから、私はきょうここで、あなたがたに宣言します。私は、すべての人たちが受けるさばきについて責任がありません。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒の働き 20:20; テサロニケ人への手紙第一 2:4; ガラテヤ人への手紙 1:7–10"> 私は、神のご計画の全体を、余すところなくあなたがたに知らせておいたからです。</span>
<span className="v" id="v28" data-v="28" data-xref="ペテロの手紙第一 5:2–3; テモテへの手紙第一 4:16; Isaiah 40:11"> あなたがたは自分自身と群れの全体とに気を配りなさい。聖霊は、神がご自身の血をもって買い取られた神の教会を牧させるために、あなたがたを群れの監督にお立てになったのです。</span>
<span className="v" id="v29" data-v="29" data-xref="マタイの福音書 7:15; ペテロの手紙第二 2:1; ヨハネの福音書 10:12"> 私が出発したあと、狂暴な狼があなたがたの中にはいり込んで来て、群れを荒らし回ることを、私は知っています。</span>
<span className="v" id="v30" data-v="30" data-xref="テモテへの手紙第一 1:19–20; テモテへの手紙第二 4:3–4; Proverbs 23:33"> あなたがた自身の中からも、いろいろな曲がったことを語って、弟子たちを自分のほうに引き込もうとする者たちが起こるでしょう。</span>
<span className="v" id="v31" data-v="31" data-xref="使徒の働き 19:8; 使徒の働き 20:19; 使徒の働き 19:10"> ですから、目をさましていなさい。私が三年の間、夜も昼も、涙とともにあなたがたひとりひとりを訓戒し続けて来たことを、思い出してください。</span>
<span className="v" id="v32" data-v="32" data-xref="コロサイ人への手紙 1:12; エペソ人への手紙 1:14; コロサイ人への手紙 3:24"> いま私は、あなたがたを神とその恵みのみことばとにゆだねます。みことばは、あなたがたを育成し、すべての聖別された人々の中にあって御国を継がせることができるのです。</span>
<span className="v" id="v33" data-v="33" data-xref="コリント人への手紙第二 11:9; コリント人への手紙第一 9:12; コリント人への手紙第一 9:18"> 私は、人の金銀や衣服をむさぼったことはありません。</span>
<span className="v" id="v34" data-v="34" data-xref="使徒の働き 18:3; コリント人への手紙第一 4:12; テサロニケ人への手紙第二 3:8–9"> あなたがた自身が知っているとおり、この両手は、私の必要のためにも、私とともにいる人たちのためにも、働いて来ました。</span>
<span className="v" id="v35" data-v="35" data-xref="ヘブル人への手紙 13:16; Proverbs 19:17; コリント人への手紙第二 9:6–12"> このように労苦して弱い者を助けなければならないこと、また、主イエスご自身が、『受けるよりも与えるほうが幸いである。』と言われたみことばを思い出すべきことを、私は、万事につけ、あなたがたに示して来たのです。」</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="使徒の働き 21:5; ルカの福音書 22:41; ピリピ人への手紙 4:6"> こう言い終わって、パウロはひざまずき、みなの者とともに祈った。</span>
<span className="v" id="v37" data-v="37" data-xref="テモテへの手紙第二 1:4; コリント人への手紙第一 16:20; テサロニケ人への手紙第一 5:26"> みなは声をあげて泣き、パウロの首を抱いて幾度も口づけし、</span>
<span className="v" id="v38" data-v="38" data-xref="使徒の働き 15:3; コリント人への手紙第一 16:11; 使徒の働き 20:25"> 彼が、「もう二度と私の顔を見ることがないでしょう。」と言ったことばによって、特に心を痛めた。それから、彼らはパウロを船まで見送った。</span>
</div>

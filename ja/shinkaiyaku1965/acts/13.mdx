<span className="v" id="v1" data-v="1" data-xref="使徒の働き 4:36; 使徒の働き 15:35; 使徒の働き 11:22–27"> さて、アンテオケには、そこにある教会に、バルナバ、ニゲルと呼ばれるシメオン、クレネ人ルキオ、国主ヘロデの乳兄弟マナエン、サウロなどという預言者や教師がいた。</span>
<span className="v" id="v2" data-v="2" data-xref="ガラテヤ人への手紙 1:15; 使徒の働き 9:15; コリント人への手紙第一 12:11"> 彼らが主を礼拝し、断食をしていると、聖霊が、「バルナバとサウロをわたしのために聖別して、わたしが召した任務につかせなさい。」と言われた。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒の働き 6:6; テモテへの手紙第二 2:2; 使徒の働き 13:2"> そこで彼らは、断食と祈りをして、ふたりの上に手を置いてから、送り出した。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒の働き 4:36; 使徒の働き 13:2; 使徒の働き 11:19"> ふたりは聖霊に遣わされて、セルキヤに下り、そこから船でキプロスに渡った。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒の働き 13:14; 使徒の働き 13:46; 使徒の働き 14:1"> サラミスに着くと、ユダヤ人の諸会堂で神のことばを宣べ始めた。彼らはヨハネを助手として連れていた。</span>
<span className="v" id="v6" data-v="6" data-xref="マタイの福音書 7:15; ヨハネの手紙第一 4:1; コリント人への手紙第二 11:13"> 島全体を巡回して、パポスまで行ったところ、にせ預言者で、名をバルイエスというユダヤ人の魔術師に出会った。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒の働き 19:38; 使徒の働き 13:12; 使徒の働き 18:12"> この男は地方総督セルギオ・パウロのもとにいた。この総督は賢明な人であって、バルナバとサウロを招いて、神のことばを聞きたいと思っていた。</span>
<span className="v" id="v8" data-v="8" data-xref="テモテへの手紙第二 3:8; 使徒の働き 13:6–7; テモテへの手紙第二 4:14–15"> ところが、魔術師エルマ（エルマという名を訳すと魔術師）は、ふたりに反対して、総督を信仰の道から遠ざけようとした。</span>
<span className="v" id="v9" data-v="9" data-xref="Micah 3:8; 使徒の働き 4:8; 使徒の働き 2:4"> しかし、サウロ、別名でパウロは、聖霊に満たされ、彼をにらみつけて、</span>
<span className="v" id="v10" data-v="10" data-xref="ヨハネの福音書 8:44; コリント人への手紙第二 11:3; マタイの福音書 13:38"> 言った。「ああ、あらゆる偽りとよこしまに満ちた者、悪魔の子、すべての正義の敵。おまえは、主のまっすぐな道を曲げることをやめないのか。</span>
<span className="v" id="v11" data-v="11" data-xref="Exodus 9:3; Psalms 32:4; ヘブル人への手紙 10:31"> 見よ。主の御手が今、おまえの上にある。おまえは盲になって、しばらくの間、日の光を見ることができなくなる。」と言った。するとたちまち、かすみとやみが彼をおおったので、彼は手を引いてくれる人を捜し回った。</span>
<span className="v" id="v12" data-v="12" data-xref="コリント人への手紙第二 10:4–5; 使徒の働き 13:7; ルカの福音書 4:22"> この出来事を見た総督は、主の教えに驚嘆して信仰にはいった。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒の働き 15:38; 使徒の働き 2:10; 使徒の働き 14:24–25"> パウロの一行は、パポスから船出して、パンフリヤのペルガに渡った。ここでヨハネは一行から離れて、エルサレムに帰った。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒の働き 16:13; 使徒の働き 14:19; 使徒の働き 13:5"> しかし彼らは、ペルガから進んでピシデヤのアンテオケに行き、安息日に会堂にはいって席に着いた。</span>
<span className="v" id="v15" data-v="15" data-xref="ヘブル人への手紙 13:22; 使徒の働き 15:21; マルコの福音書 5:22"> 律法と預言者の朗読があって後、会堂の管理者たちが、彼らのところに人をやってこう言わせた。「兄弟たち。あなたがたのうちどなたか、この人たちのために奨励のことばがあったら、どうぞお話しください。」</span>
<span className="v" id="v16" data-v="16" data-xref="使徒の働き 12:17; 使徒の働き 13:26; 使徒の働き 10:2"> そこでパウロが立ち上がり、手を振りながら言った。「イスラエルの人たち、ならびに神を恐れかしこむ方々。よく聞いてください。</span>
<span className="v" id="v17" data-v="17" data-xref="Deuteronomy 7:6–8; Isaiah 63:9–14; Psalms 105:23–24"> この民イスラエルの神は、私たちの先祖たちを選び、民がエジプトの地に滞在していた間にこれを強大にし、御腕を高く上げて、彼らをその地から導き出してくださいました。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒の働き 7:36; Psalms 95:8–11; Psalms 106:13–29"> そして約四十年間、荒野で彼らを養われました。</span>
<span className="v" id="v19" data-v="19" data-xref="Deuteronomy 7:1; Psalms 78:55; 使徒の働き 7:45"> それからカナンの地で、七つの民を滅ぼし、その地を相続財産として分配されました。これが、約四百五十年間のことです。</span>
<span className="v" id="v20" data-v="20" data-xref="Judges 2:16; 1 Samuel 3:20; 2 Kings 23:22"> その後、預言者サムエルの時代までは、さばき人たちをお遣わしになりました。</span>
<span className="v" id="v21" data-v="21" data-xref="1 Samuel 10:1; 1 Samuel 15:1; 1 Samuel 12:12–19"> それから彼らが王をほしがったので、神はベニヤミン族の人、キスの子サウロを四十年間お与えになりました。</span>
<span className="v" id="v22" data-v="22" data-xref="1 Samuel 13:13–14; 1 Kings 15:5; Psalms 78:70–72"> それから、彼を退けて、ダビデを立てて王とされましたが、このダビデについてあかしして、こう言われました。『わたしはエッサイの子ダビデを見いだした。彼はわたしの心にかなった者で、わたしのこころを余すところなく実行する。』</span>
<span className="v" id="v23" data-v="23" data-xref="マタイの福音書 1:1; Psalms 132:11; ヨハネの黙示録 22:16"> 神は、このダビデの子孫から、約束に従って、イスラエルに救い主イエスをお送りになりました。</span>
<span className="v" id="v24" data-v="24" data-xref="使徒の働き 1:22; ヨハネの福音書 1:6–8; ルカの福音書 3:2–20"> この方がおいでになる前に、ヨハネがイスラエルのすべての民に、前もって悔い改めのバプテスマを宣べ伝えていました。</span>
<span className="v" id="v25" data-v="25" data-xref="マタイの福音書 3:11; マルコの福音書 1:7; ヨハネの福音書 1:26–27"> ヨハネは、その一生を終えようとするころ、こう言いました。『あなたがたは、私をだれと思うのですか。私はその方ではありません。ご覧なさい。その方は私のあとからおいでになります。私は、その方のくつのひもを解く値うちもありません。』</span>
<span className="v" id="v26" data-v="26" data-xref="ルカの福音書 1:77; ローマ人への手紙 1:16; ルカの福音書 1:69"> 兄弟の方々、アブラハムの子孫の方々、ならびに皆さんの中で神を恐れかしこむ方々。この救いのことばは、私たちに送られているのです。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒の働き 3:17; ルカの福音書 24:24–27; ルカの福音書 24:20"> エルサレムに住む人々とその指導者たちは、このイエスを認めず、また安息日ごとに読まれる預言者のことばを理解せず、イエスを罪に定めて、その預言を成就させてしまいました。</span>
<span className="v" id="v28" data-v="28" data-xref="ルカの福音書 23:21–25; ルカの福音書 23:14–16; ヨハネの福音書 19:4"> そして、死罪に当たる何の理由も見いだせなかったのに、イエスを殺すことをピラトに強要したのです。</span>
<span className="v" id="v29" data-v="29" data-xref="ルカの福音書 23:53; ヨハネの福音書 19:28; ヨハネの福音書 19:30"> こうして、イエスについて書いてあることを全部成し終えて後、イエスを十字架から取り降ろして墓の中に納めました。</span>
<span className="v" id="v30" data-v="30" data-xref="使徒の働き 2:24; 使徒の働き 17:31; マタイの福音書 28:6"> しかし、神はこの方を死者の中からよみがえらせたのです。</span>
<span className="v" id="v31" data-v="31" data-xref="ルカの福音書 24:48; 使徒の働き 1:3; 使徒の働き 1:11"> イエスは、ご自分といっしょにガリラヤからエルサレムに上った人たちに、幾日もお現われになりました。きょう、その人たちがこの民に対してイエスの証人となっています。</span>
<span className="v" id="v32" data-v="32" data-xref="ローマ人への手紙 4:13; 使徒の働き 26:6; Ezekiel 34:23"> 私たちは、神が先祖たちに対してなされた約束について、あなたがたに良い知らせをしているのです。</span>
<span className="v" id="v33" data-v="33" data-xref="Psalms 2:7; ヘブル人への手紙 5:5; ヘブル人への手紙 1:5–6"> 神は、イエスをよみがえらせ、それによって、私たち子孫にその約束を果たされました。詩篇の第二篇に、『あなたは、わたしの子。きょう、わたしがあなたを生んだ。』と書いてあるとおりです。</span>
<span className="v" id="v34" data-v="34" data-xref="Isaiah 55:3; Psalms 89:2–4; ローマ人への手紙 6:9"> 神がイエスを死者の中からよみがえらせて、もはや朽ちることのない方とされたことについては、『わたしはダビデに約束した聖なる確かな祝福を、あなたがたに与える。』というように言われていました。</span>
<span className="v" id="v35" data-v="35" data-xref="Psalms 16:10; 使徒の働き 2:27–31; Psalms 49:9"> ですから、ほかの所でこう言っておられます。『あなたは、あなたの聖者を朽ち果てるままにはしておかれない。』</span>
<span className="v" id="v36" data-v="36" data-xref="使徒の働き 2:29; 2 Samuel 7:12; 1 Kings 2:10"> ダビデは、その生きていた時代において神のみこころに仕えて後、死んで先祖の仲間に加えられ、ついに朽ち果てました。</span>
<span className="v" id="v37" data-v="37" data-xref="使徒の働き 13:30; 使徒の働き 2:24"> しかし、神がよみがえらせた方は、朽ちることがありませんでした。</span>
<span className="v" id="v38" data-v="38" data-xref="ルカの福音書 24:47; ヨハネの手紙第一 2:12; コリント人への手紙第二 5:18–21"> ですから、兄弟たち。あなたがたに罪の赦しが宣べられているのはこの方によるということを、よく知っておいてください。</span>
<span className="v" id="v39" data-v="39" data-xref="ローマ人への手紙 10:4; ガラテヤ人への手紙 2:16; ローマ人への手紙 8:3"> モーセの律法によっては解放されることのできなかったすべての点について、信じる者はみな、この方によって、解放されるのです。</span>
<span className="v" id="v40" data-v="40" data-xref="Malachi 4:1; ヘブル人への手紙 3:12; Malachi 3:2"> ですから、預言者に言われているような事が、あなたがたの上に起こらないように気をつけなさい。</span>
<span className="v" id="v41" data-v="41" data-xref="Habakkuk 1:5; ペテロの手紙第一 4:17; ローマ人への手紙 11:7–14"> 『見よ。あざける者たち。驚け。そして滅びよ。 わたしはおまえたちの時代に一つのことをする。 それは、おまえたちに、どんなに説明しても、 とうてい信じられないほどのことである。』」</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="使徒の働き 28:28; 使徒の働き 10:33; マタイの福音書 19:30"> ふたりが会堂を出るとき、人々は、次の安息日にも同じことについて話してくれるように頼んだ。</span>
<span className="v" id="v43" data-v="43" data-xref="使徒の働き 11:23; 使徒の働き 14:22; エペソ人への手紙 2:8"> 会堂の集会が終わってからも、多くのユダヤ人と神を敬う改宗者たちが、パウロとバルナバについて来たので、ふたりは彼らと話し合って、いつまでも神の恵みにとどまっているように勧めた。</span>
<span className="v" id="v44" data-v="44" data-xref="Psalms 110:3; Genesis 49:10; Isaiah 11:10"> 次の安息日には、ほとんど町中の人が、神のことばを聞きに集まって来た。</span>
<span className="v" id="v45" data-v="45" data-xref="ユダの手紙 1:10; 使徒の働き 18:6; 使徒の働き 5:17"> しかし、この群衆を見たユダヤ人たちは、ねたみに燃え、パウロの話に反対して、口ぎたなくののしった。</span>
<span className="v" id="v46" data-v="46" data-xref="使徒の働き 28:28; マタイの福音書 21:43; 使徒の働き 18:5–6"> そこでパウロとバルナバは、はっきりとこう宣言した。「神のことばは、まずあなたがたに語られなければならなかったのです。しかし、あなたがたはそれを拒んで、自分自身を永遠のいのちにふさわしくない者と決めたのです。見なさい。私たちは、これからは異邦人のほうへ向かいます。</span>
<span className="v" id="v47" data-v="47" data-xref="Isaiah 49:6; Isaiah 42:6; ルカの福音書 2:32"> なぜなら、主は私たちに、こう命じておられるからです。 『わたしはあなたを立てて、異邦人の光とした。 あなたが地の果てまでも救いをもたらすためである。』」</span>
<span className="v" id="v48" data-v="48" data-xref="ローマ人への手紙 8:29–30; エペソ人への手紙 1:4; ローマ人への手紙 11:7"> 異邦人たちは、それを聞いて喜び、主のみことばを賛美した。そして、永遠のいのちに定められていた人たちは、みな、信仰にはいった。</span>
<span className="v" id="v49" data-v="49" data-xref="使徒の働き 12:24; 使徒の働き 19:10; 使徒の働き 19:26"> こうして、主のみことばは、この地方全体に広まった。</span>
<span className="v" id="v50" data-v="50" data-xref="使徒の働き 14:19; 使徒の働き 13:45; 使徒の働き 14:2"> ところが、ユダヤ人たちは、神を敬う貴婦人たちや町の有力者たちを扇動して、パウロとバルナバを迫害させ、ふたりをその地方から追い出した。</span>
<span className="v" id="v51" data-v="51" data-xref="マタイの福音書 10:14; 使徒の働き 18:6; ルカの福音書 9:5"> ふたりは、彼らに対して足のちりを払い落として、イコニオムへ行った。</span>
<span className="v" id="v52" data-v="52" data-xref="ローマ人への手紙 15:13; テサロニケ人への手紙第一 1:6; 使徒の働き 4:31"> 弟子たちは喜びと聖霊に満たされていた。</span>

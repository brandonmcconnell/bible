<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="コリント人への手紙第二 12:9–10; エペソ人への手紙 6:10; テモテへの手紙第二 1:7"> そこで、わが子よ。キリスト・イエスにある恵みによって強くなりなさい。</span>
<span className="v" id="v2" data-v="2" data-xref="テモテへの手紙第二 1:13–14; テモテへの手紙第一 4:6; テモテへの手紙第一 6:12"> 多くの証人の前で私から聞いたことを、他の人にも教える力のある忠実な人たちにゆだねなさい。</span>
<span className="v" id="v3" data-v="3" data-xref="ヘブル人への手紙 12:2–3; ヤコブの手紙 1:12; テモテへの手紙第二 4:5"> キリスト・イエスのりっぱな兵士として、私と苦しみをともにしてください。</span>
<span className="v" id="v4" data-v="4" data-xref="テサロニケ人への手紙第一 2:4; ルカの福音書 8:14; ペテロの手紙第二 2:20"> 兵役についていながら、日常生活のことに掛かり合っている者はだれもありません。それは徴募した者を喜ばせるためです。</span>
<span className="v" id="v5" data-v="5" data-xref="コリント人への手紙第一 9:24–27; ヨハネの黙示録 3:11; テモテへの手紙第二 4:7–8"> また、競技をするときも、規定に従って競技をしなければ栄冠を得ることはできません。</span>
<span className="v" id="v6" data-v="6" data-xref="ヘブル人への手紙 10:36; コリント人への手紙第一 9:7–11; コリント人への手紙第一 3:6–9"> 労苦した農夫こそ、まず第一に収穫の分け前にあずかるべきです。</span>
<span className="v" id="v7" data-v="7" data-xref="ヤコブの手紙 1:5; ヨハネの手紙第一 5:20; ルカの福音書 24:45"> 私が言っていることをよく考えなさい。主はすべてのことについて、理解する力をあなたに必ず与えてくださいます。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒の働き 2:24; ローマ人への手紙 2:16; コリント人への手紙第一 15:11–20"> 私の福音に言うとおり、ダビデの子孫として生まれ、死者の中からよみがえったイエス・キリストを、いつも思っていなさい。</span>
<span className="v" id="v9" data-v="9" data-xref="ピリピ人への手紙 1:7; 使徒の働き 28:31; テモテへの手紙第二 1:8"> 私は、福音のために、苦しみを受け、犯罪者のようにつながれています。しかし、神のことばは、つながれてはいません。</span>
<span className="v" id="v10" data-v="10" data-xref="ペテロの手紙第一 5:10; コロサイ人への手紙 1:24; テモテへの手紙第二 2:3"> ですから、私は選ばれた人たちのために、すべてのことを耐え忍びます。それは、彼らもまたキリスト・イエスにある救いと、それとともに、とこしえの栄光を受けるようになるためです。</span>
<span className="v" id="v11" data-v="11" data-xref="ローマ人への手紙 6:8; コロサイ人への手紙 3:3–4; ローマ人への手紙 6:5"> 次のことばは信頼すべきことばです。「もし私たちが、彼とともに死んだのなら、彼とともに生きるようになる。</span>
<span className="v" id="v12" data-v="12" data-xref="ローマ人への手紙 8:17; マタイの福音書 10:33; ヨハネの黙示録 20:4"> もし耐え忍んでいるなら、彼とともに治めるようになる。もし彼を否んだなら、彼もまた私たちを否まれる。</span>
<span className="v" id="v13" data-v="13" data-xref="Numbers 23:19; ローマ人への手紙 3:3; テサロニケ人への手紙第二 3:3"> 私たちは真実でなくても、彼は常に真実である。彼にはご自身を否むことができないからである。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="テトスへの手紙 3:9–11; テモテへの手紙第二 2:23; テモテへの手紙第二 4:1"> これらのことを人々に思い出させなさい。そして何の益にもならず、聞いている人々を滅ぼすことになるような、ことばについての論争などしないように、神の御前できびしく命じなさい。</span>
<span className="v" id="v15" data-v="15" data-xref="テサロニケ人への手紙第一 2:4; ペテロの手紙第二 1:10; テモテへの手紙第一 4:6"> あなたは熟練した者、すなわち、真理のみことばをまっすぐに説き明かす、恥じることのない働き人として、自分を神にささげるよう、努め励みなさい。</span>
<span className="v" id="v16" data-v="16" data-xref="テトスへの手紙 3:9; テモテへの手紙第一 6:20; テモテへの手紙第二 2:14"> 俗悪なむだ話を避けなさい。人々はそれによってますます不敬虔に深入りし、</span>
<span className="v" id="v17" data-v="17" data-xref="テモテへの手紙第一 1:20; Nahum 3:15; ヤコブの手紙 5:3"> 彼らの話は癌のように広がるのです。ヒメナオとピレトはその仲間です。</span>
<span className="v" id="v18" data-v="18" data-xref="コリント人への手紙第一 15:12; テモテへの手紙第一 1:19; ヘブル人への手紙 3:10"> 彼らは真理からはずれてしまい、復活がすでに起こったと言って、ある人々の信仰をくつがえしているのです。</span>
<span className="v" id="v19" data-v="19" data-xref="ヨハネの福音書 10:14; コリント人への手紙第一 8:3; Nahum 1:7"> それにもかかわらず、神の不動の礎は堅く置かれていて、それに次のような銘が刻まれています。「主はご自分に属する者を知っておられる。」また、「主の御名を呼ぶ者は、だれでも不義を離れよ。」</span>
<span className="v" id="v20" data-v="20" data-xref="ローマ人への手紙 9:21–23; ペテロの手紙第一 2:5; テモテへの手紙第一 3:15"> 大きな家には、金や銀の器だけでなく、木や土の器もあります。また、ある物は尊いことに、ある物は卑しいことに用います。</span>
<span className="v" id="v21" data-v="21" data-xref="テモテへの手紙第二 3:17; エペソ人への手紙 2:10; コリント人への手紙第二 7:1"> ですから、だれでも自分自身をきよめて、これらのことを離れるなら、その人は尊いことに使われる器となります。すなわち、きよめられたもの、主人にとって有益なもの、あらゆる良いわざに間に合うものとなるのです。</span>
<span className="v" id="v22" data-v="22" data-xref="ペテロの手紙第一 2:11; ペテロの手紙第一 3:11; コリント人への手紙第一 6:18"> それで、あなたは、若い時の情欲を避け、きよい心で主を呼び求める人たちとともに、義と信仰と愛と平和を追い求めなさい。</span>
<span className="v" id="v23" data-v="23" data-xref="テモテへの手紙第二 2:14; テトスへの手紙 3:9; テモテへの手紙第一 4:7"> 愚かで、無知な思弁を避けなさい。それが争いのもとであることは、あなたが知っているとおりです。</span>
<span className="v" id="v24" data-v="24" data-xref="テトスへの手紙 3:2; ヤコブの手紙 1:19–20; テモテへの手紙第一 3:2–3"> 主のしもべが争ってはいけません。むしろ、すべての人に優しくし、よく教え、よく忍び、</span>
<span className="v" id="v25" data-v="25" data-xref="使徒の働き 11:18; ガラテヤ人への手紙 6:1; テモテへの手紙第一 2:4"> 反対する人たちを柔和な心で訓戒しなさい。もしかすると、神は彼らに悔い改めの心を与えて真理を悟らせ、</span>
<span className="v" id="v26" data-v="26" data-xref="テモテへの手紙第一 3:7; Isaiah 49:25–26; Psalms 124:7"> 一時は悪魔に捕えられて思うままになっていた人々でも、目ざめてそのわなをのがれることもあるでしょう。</span>

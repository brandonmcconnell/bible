<span className="v" id="v1" data-v="1" data-xref="ペテロの手紙第二 3:3; テモテへの手紙第二 4:3; テモテへの手紙第一 4:1–3"> 終わりの日には困難な時代がやって来ることをよく承知しておきなさい。</span>
<span className="v" id="v2" data-v="2" data-xref="ピリピ人への手紙 2:21; ローマ人への手紙 1:29–31; ユダの手紙 1:16"> そのときに人々は、自分を愛する者、金を愛する者、大言壮語する者、不遜な者、神をけがす者、両親に従わない者、感謝することを知らない者、汚れた者になり、</span>
<span className="v" id="v3" data-v="3" data-xref="ユダの手紙 1:18; ローマ人への手紙 1:31; マタイの福音書 10:21"> 情け知らずの者、和解しない者、そしる者、節制のない者、粗暴な者、善を好まない者になり、</span>
<span className="v" id="v4" data-v="4" data-xref="ピリピ人への手紙 3:18–19; テモテへの手紙第一 3:6; ユダの手紙 1:4"> 裏切る者、向こう見ずな者、慢心する者、神よりも快楽を愛する者になり、</span>
<span className="v" id="v5" data-v="5" data-xref="Isaiah 29:13; テトスへの手紙 1:16; マタイの福音書 23:27–28"> 敬虔のかたちをしていても、その実を否定する者になるからです。こういう人々を避けなさい。</span>
<span className="v" id="v6" data-v="6" data-xref="ユダの手紙 1:4; ペテロの手紙第二 3:17; テトスへの手紙 3:3"> こういう人々の中には、家々にはいり込み、愚かな女たちをたぶらかしている者がいます。その女たちは、さまざまの情欲に引き回されて罪に罪を重ね、</span>
<span className="v" id="v7" data-v="7" data-xref="テモテへの手紙第二 4:3–4; エペソ人への手紙 4:14; テモテへの手紙第一 2:4"> いつも学んではいるが、いつになっても真理を知ることのできない者たちです。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒の働き 13:8–11; ヨハネの黙示録 2:20; テモテへの手紙第一 6:5"> また、こういう人々は、ちょうどヤンネとヤンブレがモーセに逆らったように、真理に逆らうのです。彼らは知性の腐った、信仰の失格者です。</span>
<span className="v" id="v9" data-v="9" data-xref="テモテへの手紙第二 3:8; Exodus 7:12; Jeremiah 28:15–17"> でも、彼らはもうこれ以上に進むことはできません。彼らの愚かさは、あのふたりのばあいのように、すべての人にはっきりわかるからです。</span>
<span className="v" id="v10" data-v="10" data-xref="テモテへの手紙第一 6:11; テトスへの手紙 2:7; ペテロの手紙第二 1:5–7"> しかし、あなたは、私の教え、行動、計画、信仰、寛容、愛、忍耐に、</span>
<span className="v" id="v11" data-v="11" data-xref="Psalms 34:19; 使徒の働き 14:5–6; コリント人への手紙第二 11:23–28"> またアンテオケ、イコニオム、ルステラで私にふりかかった迫害や苦難にも、よくついて来てくれました。何というひどい迫害に私は耐えて来たことでしょう。しかし、主はいっさいのことから私を救い出してくださいました。</span>
<span className="v" id="v12" data-v="12" data-xref="ペテロの手紙第一 3:14; ペテロの手紙第一 4:12–16; ペテロの手紙第一 2:20–21"> 確かに、キリスト・イエスにあって敬虔に生きようと願う者はみな、迫害を受けます。</span>
<span className="v" id="v13" data-v="13" data-xref="テモテへの手紙第一 4:1; ペテロの手紙第二 2:20; テトスへの手紙 3:3"> しかし、悪人や詐欺師たちは、だましたりだまされたりしながら、ますます悪に落ちて行くのです。</span>
<span className="v" id="v14" data-v="14" data-xref="テサロニケ人への手紙第一 2:13; テモテへの手紙第二 2:2; テモテへの手紙第二 1:13"> けれどもあなたは、学んで確信したところにとどまっていなさい。あなたは自分が、どの人たちからそれを学んだかを知っており、</span>
<span className="v" id="v15" data-v="15" data-xref="Psalms 119:98–99; ルカの福音書 24:45; Proverbs 22:6"> また、幼いころから聖書に親しんで来たことを知っているからです。聖書はあなたに知恵を与えてキリスト・イエスに対する信仰による救いを受けさせることができるのです。</span>
<span className="v" id="v16" data-v="16" data-xref="ローマ人への手紙 15:4; ヘブル人への手紙 4:12; ペテロの手紙第二 1:19–21"> 聖書はすべて、神の霊感によるもので、教えと戒めと矯正と義の訓練とのために有益です。</span>
<span className="v" id="v17" data-v="17" data-xref="テモテへの手紙第二 2:21; エペソ人への手紙 2:10; コリント人への手紙第二 9:8"> それは、神の人が、すべての良い働きのためにふさわしい十分に整えられた者となるためです。</span>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マタイの福音書 27:1–2; ルカの福音書 23:1–5; ルカの福音書 22:66"> 夜が明けるとすぐに、祭司長たちをはじめ、長老、律法学者たちと、全議会とは協議をこらしたすえ、イエスを縛って連れ出し、ピラトに引き渡した。</span>
<span className="v" id="v2" data-v="2" data-xref="マタイの福音書 2:2; マタイの福音書 27:11–14; テモテへの手紙第一 6:13"> ピラトはイエスに尋ねた。「あなたは、ユダヤ人の王ですか。」イエスは答えて言われた。「そのとおりです。」</span>
<span className="v" id="v3" data-v="3" data-xref="Isaiah 53:7; マルコの福音書 15:5; ヨハネの福音書 18:29–31"> そこで、祭司長たちはイエスをきびしく訴えた。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネの福音書 19:10; マタイの福音書 27:13; マタイの福音書 26:62"> ピラトはもう一度イエスに尋ねて言った。「何も答えないのですか。見なさい。彼らはあんなにまであなたを訴えているのです。」</span>
<span className="v" id="v5" data-v="5" data-xref="Isaiah 53:7; Zechariah 3:8; Psalms 71:7"> それでも、イエスは何もお答えにならなかった。それにはピラトも驚いた。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="ヨハネの福音書 18:39–40; 使徒の働き 25:9; 使徒の働き 24:27"> ところでピラトは、その祭りには、人々の願う囚人をひとりだけ赦免するのを例としていた。</span>
<span className="v" id="v7" data-v="7" data-xref="ルカの福音書 23:18–19; マタイの福音書 27:16; ルカの福音書 23:25"> たまたま、バラバという者がいて、暴動のとき人殺しをした暴徒たちといっしょに牢にはいっていた。</span>
<span className="v" id="v8" data-v="8"> それで、群衆は進んで行って、いつものようにしてもらうことを、ピラトに要求し始めた。</span>
<span className="v" id="v9" data-v="9" data-xref="ヨハネの福音書 19:14–16; ヨハネの福音書 19:4–5; ヨハネの福音書 18:39"> そこでピラトは、彼らに答えて、「このユダヤ人の王を釈放してくれというのか。」と言った。</span>
<span className="v" id="v10" data-v="10" data-xref="Proverbs 27:4; テトスへの手紙 3:3; Genesis 4:4–6"> ピラトは、祭司長たちが、ねたみからイエスを引き渡したことに、気づいていたからである。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒の働き 3:14; ヨハネの福音書 18:40; Hosea 5:1"> しかし、祭司長たちは群衆を扇動して、むしろバラバを釈放してもらいたいと言わせた。</span>
<span className="v" id="v12" data-v="12" data-xref="Jeremiah 23:5–6; Isaiah 9:6–7; Zechariah 9:9"> そこで、ピラトはもう一度答えて、「ではいったい、あなたがたがユダヤ人の王と呼んでいるあの人を、私にどうせよというのか。」と言った。</span>
<span className="v" id="v13" data-v="13"> すると彼らはまたも「十字架につけろ。」と叫んだ。</span>
<span className="v" id="v14" data-v="14" data-xref="ルカの福音書 23:41; ルカの福音書 23:23–24; Isaiah 53:3"> だが、ピラトは彼らに、「あの人がどんな悪い事をしたというのか。」と言った。しかし、彼らはますます激しく「十字架につけろ。」と叫んだ。</span>
<span className="v" id="v15" data-v="15" data-xref="ヨハネの福音書 19:1; マタイの福音書 27:26; Isaiah 50:6"> それで、ピラトは群衆のきげんをとろうと思い、バラバを釈放した。そして、イエスをむち打って後、十字架につけるようにと引き渡した。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="ヨハネの福音書 19:9; マタイの福音書 27:27–31; ヨハネの福音書 18:28"> 兵士たちはイエスを、邸宅、すなわち総督官邸の中に連れて行き、全部隊を呼び集めた。</span>
<span className="v" id="v17" data-v="17" data-xref="マタイの福音書 27:28–30; ヨハネの福音書 19:2–5; ルカの福音書 23:11"> そしてイエスに紫の衣を着せ、いばらの冠を編んでかぶらせ、</span>
<span className="v" id="v18" data-v="18" data-xref="マタイの福音書 27:42–43; マルコの福音書 15:2; Genesis 37:10"> それから、「ユダヤ人の王さま。ばんざい。」と叫んであいさつをし始めた。</span>
<span className="v" id="v19" data-v="19" data-xref="マルコの福音書 14:65; Isaiah 53:3–5; ルカの福音書 23:11"> また、葦の棒でイエスの頭をたたいたり、つばきをかけたり、ひざまずいて拝んだりしていた。</span>
<span className="v" id="v20" data-v="20" data-xref="ヨハネの福音書 19:16; マタイの福音書 27:31"> 彼らはイエスを嘲弄したあげく、その紫の衣を脱がせて、もとの着物をイエスに着せた。それから、イエスを十字架につけるために連れ出した。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="マタイの福音書 27:32; ルカの福音書 23:26; ローマ人への手紙 16:13"> そこへ、アレキサンデルとルポスとの父で、シモンというクレネ人が、いなかから出て来て通りかかったので、彼らはイエスの十字架を、むりやりに彼に背負わせた。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="マタイの福音書 27:33–44; ヨハネの福音書 19:17–27; ルカの福音書 23:27–38"> そして、彼らはイエスをゴルゴタの場所（訳すと、「どくろ」の場所）へ連れて行った。</span>
<span className="v" id="v23" data-v="23" data-xref="マタイの福音書 27:34; ヨハネの福音書 19:28–30; ルカの福音書 23:36"> そして彼らは、没薬を混ぜたぶどう酒をイエスに与えようとしたが、イエスはお飲みにならなかった。</span>
<span className="v" id="v24" data-v="24" data-xref="ルカの福音書 23:34; ヨハネの福音書 19:23–24; マタイの福音書 27:35–36"> それから、彼らは、イエスを十字架につけた。そして、だれが何を取るかをくじ引きで決めたうえで、イエスの着物を分けた。</span>
<span className="v" id="v25" data-v="25" data-xref="ヨハネの福音書 19:14; マルコの福音書 15:33; マタイの福音書 27:45"> 彼らがイエスを十字架につけたのは、午前九時であった。</span>
<span className="v" id="v26" data-v="26" data-xref="マタイの福音書 27:37; マタイの福音書 2:2; ヨハネの福音書 19:18–22"> イエスの罪状書きには、「ユダヤ人の王。」と書いてあった。</span>
<span className="v" id="v27" data-v="27" data-xref="ルカの福音書 23:32–33; マタイの福音書 27:38; ヨハネの福音書 19:18"> また彼らは、イエスとともにふたりの強盗を、ひとりは右に、ひとりは左に、十字架につけた。</span>
<span className="v" id="v28" data-v="28"> 道を行く人々は、頭を振りながらイエスをののしって言った。「おお、神殿を打ちこわして三日で建てる人よ。</span>
<span className="v" id="v30" data-v="30"> 十字架から降りて来て、自分を救ってみろ。」</span>
<span className="v" id="v31" data-v="31" data-xref="ヨハネの福音書 12:23–24; マタイの福音書 27:41–43; ルカの福音書 23:35–37"> また、祭司長たちも同じように、律法学者たちといっしょになって、イエスをあざけって言った。「他人は救ったが、自分は救えない。</span>
<span className="v" id="v32" data-v="32" data-xref="マタイの福音書 27:44; ルカの福音書 23:39–43; Zechariah 9:9"> キリスト、イスラエルの王さま。たった今、十字架から降りてもらおうか。われわれは、それを見たら信じるから。」また、イエスといっしょに十字架につけられた者たちもイエスをののしった。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="マタイの福音書 27:45; ルカの福音書 23:44–45; Amos 8:9–10"> さて、十二時になったとき、全地が暗くなって、午後三時まで続いた。</span>
<span className="v" id="v34" data-v="34" data-xref="Psalms 22:1; マタイの福音書 27:46; ヘブル人への手紙 5:7"> そして、三時に、イエスは大声で、「エロイ、エロイ、ラマ、サバクタニ。」と叫ばれた。それは訳すと「わが神、わが神。どうしてわたしをお見捨てになったのですか。」という意味である。</span>
<span className="v" id="v35" data-v="35" data-xref="マタイの福音書 27:47–49; マルコの福音書 9:11–13; マタイの福音書 17:11–13"> そばに立っていた幾人かが、これを聞いて、「そら、エリヤを呼んでいる。」と言った。</span>
<span className="v" id="v36" data-v="36" data-xref="Psalms 69:21; マルコの福音書 15:23; ヨハネの福音書 19:28–30"> すると、ひとりが走って行って、海綿に酸いぶどう酒を含ませ、それを葦の棒につけて、イエスに飲ませようとしながら言った。「エリヤがやって来て、彼を降ろすかどうか、私たちは見ることにしよう。」</span>
<span className="v" id="v37" data-v="37" data-xref="ヨハネの福音書 19:30; ルカの福音書 23:46; マタイの福音書 27:50"> それから、イエスは大声をあげて息を引き取られた。</span>
<span className="v" id="v38" data-v="38" data-xref="ヘブル人への手紙 10:19–23; ルカの福音書 23:45; ヘブル人への手紙 9:3–12"> 神殿の幕が上から下まで真二つに裂けた。</span>
<span className="v" id="v39" data-v="39" data-xref="マタイの福音書 27:54; ルカの福音書 23:47–48; マタイの福音書 27:43"> イエスの正面に立っていた百人隊長は、イエスがこのように息を引き取られたのを見て、「この方はまことに神の子であった。」と言った。</span>
<span className="v" id="v40" data-v="40" data-xref="ルカの福音書 23:49; ルカの福音書 8:2–3; マタイの福音書 27:55–56"> また、遠くのほうから見ていた女たちもいた。その中にマグダラのマリヤと、小ヤコブとヨセの母マリヤと、またサロメもいた。</span>
<span className="v" id="v41" data-v="41" data-xref="ルカの福音書 8:2–3; マタイの福音書 27:55–56"> イエスがガリラヤにおられたとき、いつもつき従って仕えていた女たちである。このほかにも、イエスといっしょにエルサレムに上って来た女たちがたくさんいた。</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="ルカの福音書 23:50–56; ヨハネの福音書 19:38–42; ヨハネの福音書 19:31"> すっかり夕方になった。その日は備えの日、すなわち安息日の前日であったので、</span>
<span className="v" id="v43" data-v="43" data-xref="ルカの福音書 2:38; ルカの福音書 2:25; ルカの福音書 23:51"> アリマタヤのヨセフは、思い切ってピラトのところに行き、イエスのからだの下げ渡しを願った。ヨセフは有力な議員であり、みずからも神の国を待ち望んでいた人であった。</span>
<span className="v" id="v44" data-v="44" data-xref="ヨハネの福音書 19:31–37"> ピラトは、イエスがもう死んだのかと驚いて、百人隊長を呼び出し、イエスがすでに死んでしまったかどうかを問いただした。</span>
<span className="v" id="v45" data-v="45" data-xref="マタイの福音書 27:58; ヨハネの福音書 19:38; マルコの福音書 15:39"> そして、百人隊長からそうと確かめてから、イエスのからだをヨセフに与えた。</span>
<span className="v" id="v46" data-v="46" data-xref="Isaiah 53:9; マタイの福音書 27:59–60; Isaiah 22:16"> そこで、ヨセフは亜麻布を買い、イエスを取り降ろしてその亜麻布に包み、岩を掘って造った墓に納めた。墓の入口には石をころがしかけておいた。</span>
<span className="v" id="v47" data-v="47" data-xref="マルコの福音書 15:40; マルコの福音書 16:1; ルカの福音書 23:55–2"> マグダラのマリヤとヨセの母マリヤとは、イエスの納められる所をよく見ていた。</span>
</div>

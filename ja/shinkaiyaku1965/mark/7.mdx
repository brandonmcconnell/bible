<span className="v" id="v1" data-v="1" data-xref="マタイの福音書 15:1–20; マルコの福音書 3:22; ルカの福音書 5:17"> さて、パリサイ人たちと幾人かの律法学者がエルサレムから来ていて、イエスの回りに集まった。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒の働き 10:28; マタイの福音書 7:3–5; ローマ人への手紙 14:14"> イエスの弟子のうちに、汚れた手で、すなわち洗わない手でパンを食べている者があるのを見て、</span>
<span className="v" id="v3" data-v="3" data-xref="ガラテヤ人への手紙 1:14; マルコの福音書 7:13; コロサイ人への手紙 2:8"> ――パリサイ人をはじめユダヤ人はみな、昔の人たちの言い伝えを堅く守って、手をよく洗わないでは食事をせず、</span>
<span className="v" id="v4" data-v="4" data-xref="ヘブル人への手紙 9:10; マタイの福音書 23:25; ルカの福音書 11:38–39"> また、市場から帰ったときには、からだをきよめてからでないと食事をしない。まだこのほかにも、杯、水差し、銅器を洗うことなど、堅く守るように伝えられた、しきたりがたくさんある。――</span>
<span className="v" id="v5" data-v="5" data-xref="テサロニケ人への手紙第二 3:6; 使徒の働き 21:21; マタイの福音書 15:2"> パリサイ人と律法学者たちは、イエスに尋ねた。「なぜ、あなたの弟子たちは、昔の人たちの言い伝えに従って歩まないで、汚れた手でパンを食べるのですか。」</span>
<span className="v" id="v6" data-v="6" data-xref="Isaiah 29:13; テトスへの手紙 1:16; マタイの福音書 15:7–9"> イエスは彼らに言われた。「イザヤはあなたがた偽善者について預言をして、こう書いているが、まさにそのとおりです。 『この民は、口先ではわたしを敬うが、 その心は、わたしから遠く離れている。</span>
<span className="v" id="v7" data-v="7" data-xref="Isaiah 29:13; マタイの福音書 15:9; ヤコブの手紙 1:26"> 彼らが、わたしを拝んでも、むだなことである。 人間の教えを、教えとして教えるだけだから。』</span>
<span className="v" id="v8" data-v="8" data-xref="マルコの福音書 7:3–4; Isaiah 1:12"> あなたがたは、神の戒めを捨てて、人間の言い伝えを堅く守っている。」</span>
<span className="v" id="v9" data-v="9" data-xref="Jeremiah 44:16–17; ガラテヤ人への手紙 2:21; Isaiah 29:13"> また言われた。「あなたがたは、自分たちの言い伝えを守るために、よくも神の戒めをないがしろにしたものです。</span>
<span className="v" id="v10" data-v="10" data-xref="Exodus 21:17; Exodus 20:12; Deuteronomy 5:16"> モーセは、『あなたの父と母を敬え。』また『父や母をののしる者は、死刑に処せられる。』と言っています。</span>
<span className="v" id="v11" data-v="11" data-xref="マタイの福音書 23:18; テモテへの手紙第一 5:4–8; マタイの福音書 15:5"> それなのに、あなたがたは、もし人が父や母に向かって、私からあなたのために上げられる物は、コルバン（すなわち、ささげ物）になりました、と言えば、</span>
<span className="v" id="v12" data-v="12"> その人には、父や母のために、もはや何もさせないようにしています。</span>
<span className="v" id="v13" data-v="13" data-xref="マルコの福音書 7:9; テトスへの手紙 1:14; マタイの福音書 5:17–20"> こうしてあなたがたは、自分たちが受け継いだ言い伝えによって、神のことばを空文にしています。そして、これと同じようなことを、たくさんしているのです。」</span>
<span className="v" id="v14" data-v="14" data-xref="マタイの福音書 15:10; Isaiah 6:9; Proverbs 8:5"> イエスは再び群衆を呼び寄せて言われた。「みな、わたしの言うことを聞いて、悟るようになりなさい。</span>
<span className="v" id="v15" data-v="15" data-xref="Proverbs 4:23; Leviticus 11:42–47; テトスへの手紙 1:15"> 外側から人にはいって、人を汚すことのできる物は何もありません。人から出て来るものが、人を汚すものなのです。</span>
<span className="v" id="v16" data-v="16"> イエスが群衆を離れて、家にはいられると、弟子たちは、このたとえについて尋ねた。</span>
<span className="v" id="v18" data-v="18" data-xref="マタイの福音書 15:16–17; ヘブル人への手紙 5:11; Isaiah 28:9–10"> イエスは言われた。「あなたがたまで、そんなにわからないのですか。外側から人にはいって来る物は人を汚すことができない、ということがわからないのですか。</span>
<span className="v" id="v19" data-v="19" data-xref="マタイの福音書 15:17; コリント人への手紙第一 6:13; コロサイ人への手紙 2:21–22"> そのような物は、人の心には、はいらないで、腹にはいり、そして、かわやに出されてしまうのです。」イエスは、このように、すべての食物をきよいとされた。</span>
<span className="v" id="v20" data-v="20" data-xref="ヤコブの手紙 3:6; ヤコブの手紙 1:14–15; ヤコブの手紙 4:1"> また言われた。「人から出るもの、これが、人を汚すのです。</span>
<span className="v" id="v21" data-v="21" data-xref="Jeremiah 17:9; ローマ人への手紙 8:7–8; ヤコブの手紙 4:1–3"> 内側から、すなわち、人の心から出て来るものは、悪い考え、不品行、盗み、殺人、</span>
<span className="v" id="v22" data-v="22" data-xref="マタイの福音書 20:15; マタイの福音書 6:23; ペテロの手紙第一 2:15"> 姦淫、貪欲、よこしま、欺き、好色、ねたみ、そしり、高ぶり、愚かさであり、</span>
<span className="v" id="v23" data-v="23" data-xref="マルコの福音書 7:15; テトスへの手紙 1:15; コリント人への手紙第一 3:17"> これらの悪はみな、内側から出て、人を汚すのです。」</span>
<span className="v" id="v24" data-v="24" data-xref="マタイの福音書 15:21–28; マタイの福音書 11:21; Ezekiel 28:2"> イエスは、そこを出てツロの地方へ行かれた。家にはいられたとき、だれにも知られたくないと思われたが、隠れていることはできなかった。</span>
<span className="v" id="v25" data-v="25" data-xref="マタイの福音書 15:22; マルコの福音書 9:17–23; 使徒の働き 10:25–26"> 汚れた霊につかれた小さい娘のいる女が、イエスのことを聞きつけてすぐにやって来て、その足もとにひれ伏した。</span>
<span className="v" id="v26" data-v="26" data-xref="マタイの福音書 15:22; Isaiah 49:12; ガラテヤ人への手紙 3:28"> この女はギリシヤ人で、スロ・フェニキヤの生まれであった。そして、自分の娘から悪霊を追い出してくださるようにイエスに願い続けた。</span>
<span className="v" id="v27" data-v="27" data-xref="マタイの福音書 15:23–28; マタイの福音書 7:6; 使徒の働き 22:21"> するとイエスは言われた。「まず子どもたちに満腹させなければなりません。子どもたちのパンを取り上げて、小犬に投げてやるのはよくないことです。」</span>
<span className="v" id="v28" data-v="28" data-xref="ローマ人への手紙 10:12; ローマ人への手紙 3:29; 使徒の働き 11:17–18"> しかし、女は答えて言った。「主よ。そのとおりです。でも、食卓の下の小犬でも、子どもたちのパンくずをいただきます。」</span>
<span className="v" id="v29" data-v="29" data-xref="Isaiah 66:2; マタイの福音書 5:3; ヨハネの手紙第一 3:8"> そこでイエスは言われた。「そうまで言うのですか。それなら家にお帰りなさい。悪霊はあなたの娘から出て行きました。」</span>
<span className="v" id="v30" data-v="30" data-xref="ヨハネの手紙第一 3:8; ヨハネの福音書 4:50–52"> 女が家に帰ってみると、その子は床の上に伏せっており、悪霊はもう出ていた。</span>
<span className="v" id="v31" data-v="31" data-xref="マルコの福音書 5:20; マタイの福音書 15:29–31; マタイの福音書 4:25"> それから、イエスはツロの地方を去り、シドンを通って、もう一度、デカポリス地方のあたりのガリラヤ湖に来られた。</span>
<span className="v" id="v32" data-v="32" data-xref="ルカの福音書 11:14; マルコの福音書 5:23; マタイの福音書 9:32–33"> 人々は、耳が聞こえず、口のきけない人を連れて来て、彼の上に手を置いてくださるように願った。</span>
<span className="v" id="v33" data-v="33" data-xref="マルコの福音書 8:23; ヨハネの福音書 9:6–7; マルコの福音書 5:40"> そこで、イエスは、その人だけを群衆の中から連れ出し、その両耳に指を差し入れ、それからつばきをして、その人の舌にさわられた。</span>
<span className="v" id="v34" data-v="34" data-xref="ヨハネの福音書 11:41; マルコの福音書 5:41; マルコの福音書 6:41"> そして、天を見上げ、深く嘆息して、その人に「エパタ。」すなわち、「開け。」と言われた。</span>
<span className="v" id="v35" data-v="35" data-xref="Isaiah 35:5–6; Psalms 33:9; マルコの福音書 2:12"> すると彼の耳が開き、舌のもつれもすぐに解け、はっきりと話せるようになった。</span>
<span className="v" id="v36" data-v="36" data-xref="マタイの福音書 8:4; マルコの福音書 8:26; マルコの福音書 3:12"> イエスは、このことをだれにも言ってはならない、と命じられたが、彼らは口止めされればされるほど、かえって言いふらした。</span>
<span className="v" id="v37" data-v="37" data-xref="マルコの福音書 6:51; マルコの福音書 5:42; Exodus 4:10–11"> 人々は非常に驚いて言った。「この方のなさったことは、みなすばらしい。つんぼを聞こえるようにし、おしを話せるようにしてくださった。」</span>

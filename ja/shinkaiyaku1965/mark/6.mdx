<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ルカの福音書 4:16–30; マタイの福音書 13:54–58; マタイの福音書 2:23"> イエスはそこを去って、郷里に行かれた。弟子たちもついて行った。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネの福音書 7:15; ヨハネの福音書 6:42; 使徒の働き 4:13–14"> 安息日になったとき、会堂で教え始められた。それを聞いた多くの人々は驚いて言った。「この人は、こういうことをどこから得たのでしょう。この人に与えられた知恵や、この人の手で行なわれるこのような力あるわざは、いったい何でしょう。</span>
<span className="v" id="v3" data-v="3" data-xref="マタイの福音書 12:46; マタイの福音書 13:55–57; ヨハネの福音書 6:42"> この人は大工ではありませんか。マリヤの子で、ヤコブ、ヨセ、ユダ、シモンの兄弟ではありませんか。その妹たちも、私たちとここに住んでいるではありませんか。」こうして彼らはイエスにつまずいた。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネの福音書 4:44; ルカの福音書 4:24; マタイの福音書 13:57"> イエスは彼らに言われた。「預言者が尊敬されないのは、自分の郷里、親族、家族の間だけです。」</span>
<span className="v" id="v5" data-v="5" data-xref="マタイの福音書 13:58; マルコの福音書 9:23; マルコの福音書 5:23"> それで、そこでは何一つ力あるわざを行なうことができず、少数の病人に手を置いていやされただけであった。</span>
<span className="v" id="v6" data-v="6" data-xref="マタイの福音書 9:35; マタイの福音書 8:10; ルカの福音書 13:22"> イエスは彼らの不信仰に驚かれた。それからイエスは、近くの村々を教えて回られた。</span>
<span className="v" id="v7" data-v="7" data-xref="Ecclesiastes 4:9–10; ルカの福音書 10:17–20; マタイの福音書 10:1–5"> また、十二弟子を呼び、ふたりずつ遣わし始め、彼らに汚れた霊を追い出す権威をお与えになった。</span>
<span className="v" id="v8" data-v="8" data-xref="ルカの福音書 9:3; マタイの福音書 10:9–10; ルカの福音書 10:4"> また、彼らにこう命じられた。「旅のためには、杖一本のほかは、何も持って行ってはいけません。パンも、袋も、胴巻きに金も持って行ってはいけません。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒の働き 12:8; エペソ人への手紙 6:15"> くつは、はきなさい。しかし二枚の下着を着てはいけません。」</span>
<span className="v" id="v10" data-v="10" data-xref="ルカの福音書 10:7–8; ルカの福音書 9:4; マタイの福音書 10:11–13"> また、彼らに言われた。「どこででも一軒の家にはいったら、そこの土地から出て行くまでは、その家にとどまっていなさい。</span>
<span className="v" id="v11" data-v="11" data-xref="マタイの福音書 10:14–15; 使徒の働き 18:6; ルカの福音書 10:10–15"> もし、あなたがたを受け入れない場所、また、あなたがたに聞こうとしない人々なら、そこから出て行くときに、そこの人々に対する証言として、足の裏のちりを払い落としなさい。」</span>
<span className="v" id="v12" data-v="12" data-xref="マタイの福音書 4:17; ルカの福音書 13:3; 使徒の働き 20:21"> こうして十二人が出て行き、悔い改めを説き広め、</span>
<span className="v" id="v13" data-v="13" data-xref="ヤコブの手紙 5:14–15; マルコの福音書 6:7; ルカの福音書 10:17"> 悪霊を多く追い出し、大ぜいの病人に油を塗っていやした。</span>
<span className="v" id="v14" data-v="14" data-xref="ルカの福音書 9:7–9; マルコの福音書 6:14–29; ルカの福音書 23:7–12"> イエスの名が知れ渡ったので、ヘロデ王の耳にもはいった。人々は、「バプテスマのヨハネが死人の中からよみがえったのだ。だから、あんな力が、彼のうちに働いているのだ。」と言っていた。</span>
<span className="v" id="v15" data-v="15" data-xref="マタイの福音書 16:14; Malachi 4:5; マタイの福音書 21:11"> 別の人々は、「彼はエリヤだ。」と言い、さらに別の人々は、「昔の預言者の中のひとりのような預言者だ。」と言っていた。</span>
<span className="v" id="v16" data-v="16" data-xref="ヨハネの黙示録 11:10–13; マタイの福音書 27:4; ルカの福音書 9:9"> しかし、ヘロデはうわさを聞いて、「私が首をはねたあのヨハネが生き返ったのだ。」と言っていた。</span>
<span className="v" id="v17" data-v="17" data-xref="ルカの福音書 3:19–20; マタイの福音書 11:2; ルカの福音書 3:1"> 実は、このヘロデが、自分の兄弟ピリポの妻ヘロデヤのことで、――ヘロデはこの女を妻としていた。――人をやってヨハネを捕え、牢につないだのであった。</span>
<span className="v" id="v18" data-v="18" data-xref="Leviticus 20:21; Leviticus 18:16; 1 Kings 22:14"> これは、ヨハネがヘロデに、「あなたが兄弟の妻を自分のものとしていることは不法です。」と言い張ったからである。</span>
<span className="v" id="v19" data-v="19" data-xref="Ecclesiastes 7:9; エペソ人への手紙 4:26–27; Genesis 39:17–20"> ところが、ヘロデヤはヨハネを恨み、彼を殺したいと思いながら、果たせないでいた。</span>
<span className="v" id="v20" data-v="20" data-xref="マタイの福音書 21:26; マタイの福音書 14:5; 2 Chronicles 24:15–22"> それはヘロデが、ヨハネを正しい聖なる人と知って、彼を恐れ、保護を加えていたからである。また、ヘロデはヨハネの教えを聞くとき、非常に当惑しながらも、喜んで耳を傾けていた。</span>
<span className="v" id="v21" data-v="21" data-xref="Esther 2:18; Genesis 40:20; ペテロの手紙第一 4:3"> ところが、良い機会が訪れた。ヘロデがその誕生日に、重臣や、千人隊長や、ガリラヤのおもだった人などを招いて、祝宴を設けたとき、</span>
<span className="v" id="v22" data-v="22" data-xref="Esther 1:10–12; マタイの福音書 14:6; Daniel 5:2"> ヘロデヤの娘がはいって来て、踊りを踊ったので、ヘロデも列席の人々も喜んだ。そこで王は、この少女に、「何でもほしい物を言いなさい。与えよう。」と言った。</span>
<span className="v" id="v23" data-v="23" data-xref="Esther 7:2; Esther 5:3; Esther 5:6"> また、「おまえの望む物なら、私の国の半分でも、与えよう。」と言って、誓った。</span>
<span className="v" id="v24" data-v="24" data-xref="Job 31:31; Ezekiel 19:2–3; Genesis 27:8–11"> そこで少女は出て行って、「何を願いましょうか。」とその母親に言った。すると母親は、「バプテスマのヨハネの首。」と言った。</span>
<span className="v" id="v25" data-v="25" data-xref="ローマ人への手紙 3:15; Numbers 7:19–89; Numbers 7:13"> そこで少女はすぐに、大急ぎで王の前に行き、こう言って頼んだ。「今すぐに、バプテスマのヨハネの首を盆に載せていただきとうございます。」</span>
<span className="v" id="v26" data-v="26" data-xref="マタイの福音書 27:24–25; マタイの福音書 14:9; マタイの福音書 27:3–5"> 王は非常に心を痛めたが、自分の誓いもあり、列席の人々の手前もあって、少女の願いを退けることを好まなかった。</span>
<span className="v" id="v27" data-v="27" data-xref="マタイの福音書 14:10–11"> そこで王は、すぐに護衛兵をやって、ヨハネの首を持って来るように命令した。護衛兵は行って、牢の中でヨハネの首をはね、</span>
<span className="v" id="v28" data-v="28"> その首を盆に載せて持って来て、少女に渡した。少女は、それを母親に渡した。</span>
<span className="v" id="v29" data-v="29" data-xref="マタイの福音書 14:12; 2 Chronicles 24:16; マタイの福音書 27:57–60"> ヨハネの弟子たちは、このことを聞いたので、やって来て、遺体を引き取り、墓に納めたのであった。</span>
<span className="v" id="v30" data-v="30" data-xref="ルカの福音書 9:10; ルカの福音書 10:17; マタイの福音書 10:2"> さて、使徒たちは、イエスのもとに集まって来て、自分たちのしたこと、教えたことを残らずイエスに報告した。</span>
<span className="v" id="v31" data-v="31" data-xref="マルコの福音書 3:20; ヨハネの福音書 6:1; マルコの福音書 1:45"> そこでイエスは彼らに、「さあ、あなたがただけで、寂しい所へ行って、しばらく休みなさい。」と言われた。人々の出入りが多くて、ゆっくり食事する時間さえなかったからである。</span>
<span className="v" id="v32" data-v="32" data-xref="マルコの福音書 8:2–9; マルコの福音書 6:45; マルコの福音書 4:36"> そこで彼らは、舟に乗って、自分たちだけで寂しい所へ行った。</span>
<span className="v" id="v33" data-v="33" data-xref="ヨハネの福音書 6:2; マタイの福音書 15:29–31; マルコの福音書 6:54–55"> ところが、多くの人々が、彼らの出て行くのを見、それと気づいて、方々の町々からそこへ徒歩で駆けつけ、彼らよりも先に着いてしまった。</span>
<span className="v" id="v34" data-v="34" data-xref="マタイの福音書 9:36; ルカの福音書 9:11; Numbers 27:17"> イエスは、舟から上がられると、多くの群衆をご覧になった。そして彼らが羊飼いのいない羊のようであるのを深くあわれみ、いろいろと教え始められた。</span>
<span className="v" id="v35" data-v="35" data-xref="ヨハネの福音書 6:5–15; ルカの福音書 9:12–17; マタイの福音書 14:15–21"> そのうち、もう時刻もおそくなったので、弟子たちはイエスのところに来て言った。「ここはへんぴな所で、もう時刻もおそくなりました。</span>
<span className="v" id="v36" data-v="36" data-xref="マタイの福音書 15:23; マルコの福音書 3:21; マルコの福音書 5:31"> みんなを解散させてください。そして、近くの部落や村に行って何か食べる物をめいめいで買うようにさせてください。」</span>
<span className="v" id="v37" data-v="37" data-xref="2 Kings 4:42–44; マタイの福音書 15:32–33; マルコの福音書 8:2–3"> すると、彼らに答えて言われた。「あなたがたで、あの人たちに何か食べる物を上げなさい。」そこで弟子たちは言った。「私たちが出かけて行って、二百デナリものパンを買ってあの人たちに食べさせるように、ということでしょうか。」</span>
<span className="v" id="v38" data-v="38" data-xref="マタイの福音書 15:34; マルコの福音書 8:5; ヨハネの福音書 6:9"> するとイエスは彼らに言われた。「パンはどれぐらいありますか。行って見て来なさい。」彼らは確かめて言った。「五つです。それと魚が二匹です。」</span>
<span className="v" id="v39" data-v="39" data-xref="コリント人への手紙第一 14:40; コリント人への手紙第一 14:33; マタイの福音書 15:35"> イエスは、みなを、それぞれ組にして青草の上にすわらせるよう、弟子たちにお命じになった。</span>
<span className="v" id="v40" data-v="40" data-xref="ルカの福音書 9:14–15"> そこで人々は、百人、五十人と固まって席に着いた。</span>
<span className="v" id="v41" data-v="41" data-xref="マタイの福音書 14:19; マルコの福音書 7:34; ルカの福音書 9:16"> するとイエスは、五つのパンと二匹の魚を取り、天を見上げて祝福を求め、パンを裂き、人々に配るように弟子たちに与えられた。また、二匹の魚もみなに分けられた。</span>
<span className="v" id="v42" data-v="42" data-xref="ルカの福音書 9:17; マルコの福音書 8:8–9; マタイの福音書 15:37–38"> 人々はみな、食べて満腹した。</span>
<span className="v" id="v43" data-v="43" data-xref="マルコの福音書 8:19–20"> そして、パン切れを十二のかごにいっぱい取り集め、魚の残りも取り集めた。</span>
<span className="v" id="v44" data-v="44"> パンを食べたのは、男が五千人であった。</span>
<span className="v" id="v45" data-v="45" data-xref="マタイの福音書 14:22–33; ヨハネの福音書 6:15–21; マルコの福音書 6:32"> それからすぐに、イエスは弟子たちを強いて舟に乗り込ませ、先に向こう岸のベツサイダに行かせ、ご自分は、その間に群衆を解散させておられた。</span>
<span className="v" id="v46" data-v="46" data-xref="マルコの福音書 1:35; マタイの福音書 6:6; ルカの福音書 6:12"> それから、群衆に別れ、祈るために、そこを去って山のほうに向かわれた。</span>
<span className="v" id="v47" data-v="47" data-xref="マタイの福音書 14:23; ヨハネの福音書 6:16–17"> 夕方になったころ、舟は湖の真中に出ており、イエスだけが陸地におられた。</span>
<span className="v" id="v48" data-v="48" data-xref="ルカの福音書 24:28; ルカの福音書 12:38; Job 9:8"> イエスは、弟子たちが、向かい風のために漕ぎあぐねているのをご覧になり、夜中の三時ごろ、湖の上を歩いて、彼らに近づいて行かれたが、そのままそばを通り過ぎようとのおつもりであった。</span>
<span className="v" id="v49" data-v="49" data-xref="マタイの福音書 14:25–26; ルカの福音書 24:37; Job 9:8"> しかし、弟子たちは、イエスが湖の上を歩いておられるのを見て、幽霊だと思い、叫び声をあげた。</span>
<span className="v" id="v50" data-v="50" data-xref="マタイの福音書 14:27; ヨハネの福音書 6:19–20; Isaiah 43:2"> というのは、みなイエスを見ておびえてしまったからである。しかし、イエスはすぐに彼らに話しかけ、「しっかりしなさい。わたしだ。恐れることはない。」と言われた。</span>
<span className="v" id="v51" data-v="51" data-xref="Psalms 93:3–4; マルコの福音書 4:39; ヨハネの福音書 6:21"> そして舟に乗り込まれると、風がやんだ。彼らの心中の驚きは非常なものであった。</span>
<span className="v" id="v52" data-v="52" data-xref="マルコの福音書 8:17–21; ルカの福音書 24:25; Isaiah 63:17"> というのは、彼らはまだパンのことから悟るところがなく、その心は堅く閉じていたからである。</span>
<span className="v" id="v53" data-v="53" data-xref="マタイの福音書 14:34–36; ヨハネの福音書 6:24–25; ルカの福音書 5:1"> 彼らは湖を渡って、ゲネサレの地に着き、舟をつないだ。</span>
<span className="v" id="v54" data-v="54" data-xref="Psalms 9:10; ピリピ人への手紙 3:10"> そして、彼らが舟から上がると、人々はすぐにイエスだと気がついて、</span>
<span className="v" id="v55" data-v="55" data-xref="マタイの福音書 4:24; マルコの福音書 2:1–3; マルコの福音書 3:7–11"> そのあたりをくまなく走り回り、イエスがおられると聞いた場所へ、病人を床に載せて運んで来た。</span>
<span className="v" id="v56" data-v="56" data-xref="マタイの福音書 9:20; ルカの福音書 6:19; Numbers 15:38–39"> イエスがはいって行かれると、村でも町でも部落でも、人々は病人たちを広場に寝かせ、そして、せめて、イエスの着物の端にでもさわらせてくださるようにと願った。そして、さわった人々はみな、いやされた。</span>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ルカの福音書 23:56–12; ヨハネの福音書 20:1–10; マタイの福音書 28:1–10"> さて、安息日が終わったので、マグダラのマリヤとヤコブの母マリヤとサロメとは、イエスに油を塗りに行こうと思い、香料を買った。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネの福音書 20:1; ルカの福音書 24:1; マタイの福音書 28:1"> そして、週の初めの日の早朝、日が上ったとき、墓に着いた。</span>
<span className="v" id="v3" data-v="3" data-xref="マルコの福音書 15:46–47; マタイの福音書 27:60–66"> 彼女たちは、「墓の入口からあの石をころがしてくれる人が、だれかいるでしょうか。」とみなで話し合っていた。</span>
<span className="v" id="v4" data-v="4" data-xref="マタイの福音書 28:2–4; ルカの福音書 24:2; ヨハネの福音書 20:1"> ところが、目を上げて見ると、あれほど大きな石だったのに、その石がすでにころがしてあった。</span>
<span className="v" id="v5" data-v="5" data-xref="ヨハネの福音書 20:11–12; ルカの福音書 24:3–5; ヨハネの福音書 20:8"> それで、墓の中にはいったところ、真白な長い衣をまとった青年が右側にすわっているのが見えた。彼女たちは驚いた。</span>
<span className="v" id="v6" data-v="6" data-xref="ヨハネの黙示録 1:17–18; コリント人への手紙第一 15:3–7; ルカの福音書 24:46"> 青年は言った。「驚いてはいけません。あなたがたは、十字架につけられたナザレ人イエスを捜しているのでしょう。あの方はよみがえられました。ここにはおられません。ご覧なさい。ここがあの方の納められた所です。</span>
<span className="v" id="v7" data-v="7" data-xref="マルコの福音書 14:28; マタイの福音書 26:32; マタイの福音書 28:10"> ですから行って、お弟子たちとペテロに、『イエスは、あなたがたより先にガリラヤへ行かれます。前に言われたとおり、そこでお会いできます。』とそう言いなさい。」</span>
<span className="v" id="v8" data-v="8" data-xref="ルカの福音書 24:22–24; ルカの福音書 24:9–11; マルコの福音書 16:5–6"> 女たちは、墓を出て、そこから逃げ去った。すっかり震え上がって、気も転倒していたからである。そしてだれにも何も言わなかった。恐ろしかったからである。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="ヨハネの福音書 20:14–19; ルカの福音書 8:2; ヨハネの福音書 20:12"> ［さて、週の初めの日の朝早くによみがえったイエスは、まずマグダラのマリヤにご自分を現わされた。イエスは、以前に、この女から七つの悪霊を追い出されたのであった。</span>
<span className="v" id="v10" data-v="10" data-xref="ヨハネの福音書 20:18; ルカの福音書 24:17; ヨハネの福音書 16:6"> マリヤはイエスといっしょにいた人たちが嘆き悲しんで泣いているところに行き、そのことを知らせた。</span>
<span className="v" id="v11" data-v="11" data-xref="ルカの福音書 24:11; マルコの福音書 16:13–14; マルコの福音書 9:19"> ところが、彼らは、イエスが生きておられ、お姿をよく見た、と聞いても、それを信じようとはしなかった。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="ルカの福音書 24:13–32; ヨハネの福音書 21:14; ヨハネの福音書 21:1"> その後、彼らのうちのふたりがいなかのほうへ歩いていたおりに、イエスは別の姿でご自分を現わされた。</span>
<span className="v" id="v13" data-v="13" data-xref="ヨハネの福音書 20:25; ルカの福音書 24:33–35; ヨハネの福音書 20:8"> そこでこのふたりも、残りの人たちのところへ行ってこれを知らせたが、彼らはふたりの話も信じなかった。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="コリント人への手紙第一 15:5; ルカの福音書 24:36–43; ヘブル人への手紙 3:7–8"> しかしそれから後になって、イエスは、その十一人が食卓に着いているところに現われて、彼らの不信仰とかたくなな心をお責めになった。それは、彼らが、よみがえられたイエスを見た人たちの言うところを信じなかったからである。</span>
<span className="v" id="v15" data-v="15" data-xref="マタイの福音書 28:19; マルコの福音書 13:10; 使徒の働き 1:8"> それから、イエスは彼らにこう言われた。「全世界に出て行き、すべての造られた者に、福音を宣べ伝えなさい。</span>
<span className="v" id="v16" data-v="16" data-xref="ヨハネの福音書 11:25–26; ヨハネの福音書 3:36; ローマ人への手紙 10:9–14"> 信じてバプテスマを受ける者は、救われます。しかし、信じない者は罪に定められます。</span>
<span className="v" id="v17" data-v="17" data-xref="使徒の働き 5:16; コリント人への手紙第一 12:28; 使徒の働き 8:7"> 信じる人々には次のようなしるしが伴います。すなわち、わたしの名によって悪霊を追い出し、新しいことばを語り、</span>
<span className="v" id="v18" data-v="18" data-xref="ルカの福音書 10:19; ヤコブの手紙 5:14–15; 使徒の働き 28:3–6"> 蛇をもつかみ、たとい毒を飲んでも決して害を受けず、また、病人に手を置けば病人はいやされます。」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="ペテロの手紙第一 3:22; ヘブル人への手紙 1:3; ヘブル人への手紙 12:2"> 主イエスは、彼らにこう話されて後、天に上げられて神の右の座に着かれた。</span>
<span className="v" id="v20" data-v="20" data-xref="コリント人への手紙第一 2:4–5; 使徒の働き 14:3; ローマ人への手紙 15:19"> そこで、彼らは出て行って、至る所で福音を宣べ伝えた。主は彼らとともに働き、みことばに伴うしるしをもって、みことばを確かなものとされた。］<br />別の追加文<br />［さて、女たちは、命じられたすべてのことを、ペテロとその仲間の人々にさっそく知らせた。その後、イエスご自身、彼らによって、きよく、朽ちることのない、永遠の救いのおとずれを、東の果てから、西の果てまで送り届けられた。］</span>
</div>

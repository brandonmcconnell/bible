<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨハネの手紙第一 5:11–12; マタイの福音書 4:3; マタイの福音書 3:17"> 神の子イエス・キリストの福音のはじめ。</span>
<span className="v" id="v2" data-v="2" data-xref="Malachi 3:1; マタイの福音書 11:10; ルカの福音書 1:76"> 預言者イザヤの書にこう書いてある。 「見よ。わたしは使いをあなたの前に遣わし、 あなたの道を整えさせよう。</span>
<span className="v" id="v3" data-v="3" data-xref="Isaiah 40:3–5; マタイの福音書 3:3; ルカの福音書 3:4–6"> 荒野で叫ぶ者の声がする。 『主の道を用意し、主の通られる道をまっすぐにせよ。』」 そのとおりに、</span>
<span className="v" id="v4" data-v="4" data-xref="使徒の働き 19:3–4; マタイの福音書 3:6; 使徒の働き 13:24–25"> バプテスマのヨハネが荒野に現われて、罪が赦されるための悔い改めのバプテスマを説いた。</span>
<span className="v" id="v5" data-v="5" data-xref="Leviticus 26:40–42; 使徒の働き 19:18; マタイの福音書 3:5–6"> そこでユダヤ全国の人々とエルサレムの全住民が彼のところへ行き、自分の罪を告白して、ヨルダン川で彼からバプテスマを受けていた。</span>
<span className="v" id="v6" data-v="6" data-xref="2 Kings 1:8; Leviticus 11:22; マタイの福音書 3:4"> ヨハネは、らくだの毛で織った物を着て、腰に皮の帯を締め、いなごと野蜜を食べていた。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒の働き 13:25; ルカの福音書 3:16; ヨハネの福音書 1:27"> 彼は宣べ伝えて言った。「私よりもさらに力のある方が、あとからおいでになります。私には、かがんでその方のくつのひもを解く値うちもありません。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒の働き 1:5; コリント人への手紙第一 12:13; 使徒の働き 19:4–6"> 私はあなたがたに水でバプテスマを授けましたが、その方は、あなたがたに聖霊のバプテスマをお授けになります。」</span>
<span className="v" id="v9" data-v="9" data-xref="マタイの福音書 3:13–17; マタイの福音書 2:23; ルカの福音書 3:21–22"> そのころ、イエスはガリラヤのナザレから来られ、ヨルダン川で、ヨハネからバプテスマをお受けになった。</span>
<span className="v" id="v10" data-v="10" data-xref="ヨハネの福音書 1:31–34; ルカの福音書 3:22; Isaiah 42:1"> そして、水の中から上がられると、すぐそのとき、天が裂けて御霊が鳩のように自分の上に下られるのを、ご覧になった。</span>
<span className="v" id="v11" data-v="11" data-xref="Isaiah 42:1; マルコの福音書 9:7; マタイの福音書 3:17"> そして天から声がした。「あなたは、わたしの愛する子、わたしはあなたを喜ぶ。」</span>
<span className="v" id="v12" data-v="12" data-xref="マタイの福音書 4:1–11; ルカの福音書 4:1–13"> そしてすぐ、御霊はイエスを荒野に追いやられた。</span>
<span className="v" id="v13" data-v="13" data-xref="ヘブル人への手紙 2:17–18; ヘブル人への手紙 4:15; Exodus 34:28"> イエスは四十日間荒野にいて、サタンの誘惑を受けられた。野の獣とともにおられたが、御使いたちがイエスに仕えていた。</span>
<span className="v" id="v14" data-v="14" data-xref="マタイの福音書 4:23; マタイの福音書 4:12; ルカの福音書 8:1"> ヨハネが捕えられて後、イエスはガリラヤに行き、神の福音を宣べて言われた。</span>
<span className="v" id="v15" data-v="15" data-xref="マタイの福音書 3:2; 使徒の働き 2:36–38; マタイの福音書 4:17"> 「時が満ち、神の国は近くなった。悔い改めて福音を信じなさい。」</span>
<span className="v" id="v16" data-v="16" data-xref="マタイの福音書 4:18–22; ヨハネの福音書 1:40–42; ヨハネの福音書 6:8"> ガリラヤ湖のほとりを通られると、シモンとシモンの兄弟アンデレが湖で網を打っているのをご覧になった。彼らは漁師であった。</span>
<span className="v" id="v17" data-v="17" data-xref="ルカの福音書 5:10; マタイの福音書 4:19–20; 使徒の働き 2:38–41"> イエスは彼らに言われた。「わたしについて来なさい。人間をとる漁師にしてあげよう。」</span>
<span className="v" id="v18" data-v="18" data-xref="ルカの福音書 18:28–30; ルカの福音書 5:11; マルコの福音書 10:28–31"> すると、すぐに、彼らは網を捨て置いて従った。</span>
<span className="v" id="v19" data-v="19" data-xref="マルコの福音書 5:37; 使徒の働き 1:13; マルコの福音書 10:35"> また少し行かれると、ゼベダイの子ヤコブとその兄弟ヨハネをご覧になった。彼らも舟の中で網を繕っていた。</span>
<span className="v" id="v20" data-v="20" data-xref="マタイの福音書 10:37; ルカの福音書 14:26; マルコの福音書 10:29"> すぐに、イエスがお呼びになった。すると彼らは父ゼベダイを雇い人たちといっしょに舟に残して、イエスについて行った。</span>
<span className="v" id="v21" data-v="21" data-xref="マルコの福音書 6:2; マルコの福音書 1:39; マタイの福音書 4:23"> それから、一行はカペナウムにはいった。そしてすぐに、イエスは安息日に会堂にはいって教えられた。</span>
<span className="v" id="v22" data-v="22" data-xref="マタイの福音書 7:28–29; マタイの福音書 13:54; ルカの福音書 4:32"> 人々は、その教えに驚いた。それはイエスが、律法学者たちのようにではなく、権威ある者のように教えられたからである。</span>
<span className="v" id="v23" data-v="23" data-xref="マルコの福音書 9:25; マルコの福音書 7:25; マルコの福音書 1:34"> すると、すぐにまた、その会堂に汚れた霊につかれた人がいて、大声でわめいて言った。</span>
<span className="v" id="v24" data-v="24" data-xref="マタイの福音書 8:29; ヤコブの手紙 2:19; 使徒の働き 3:14"> 「ナザレの人イエス。いったい私たちに何をしようというのです。あなたは私たちを滅ぼしに来たのでしょう。私はあなたがどなたか知っています。神の聖者です。」</span>
<span className="v" id="v25" data-v="25" data-xref="マルコの福音書 1:34; ルカの福音書 4:41; 使徒の働き 16:17"> イエスは彼をしかって、「黙れ。この人から出て行け。」と言われた。</span>
<span className="v" id="v26" data-v="26" data-xref="マルコの福音書 9:26; マルコの福音書 9:20; ルカの福音書 11:22"> すると、その汚れた霊はその人をひきつけさせ、大声をあげて、その人から出て行った。</span>
<span className="v" id="v27" data-v="27" data-xref="マタイの福音書 15:31; マルコの福音書 7:37; ルカの福音書 9:1"> 人々はみな驚いて、互いに論じ合って言った。「これはどうだ。権威のある、新しい教えではないか。汚れた霊をさえ戒められる。すると従うのだ。」</span>
<span className="v" id="v28" data-v="28" data-xref="マタイの福音書 9:31; ルカの福音書 4:37; マルコの福音書 1:45"> こうして、イエスの評判は、すぐに、ガリラヤ全地の至る所に広まった。</span>
<span className="v" id="v29" data-v="29" data-xref="ルカの福音書 4:38–39; マタイの福音書 8:14–15; マルコの福音書 1:21"> イエスは会堂を出るとすぐに、ヤコブとヨハネを連れて、シモンとアンデレの家にはいられた。</span>
<span className="v" id="v30" data-v="30" data-xref="コリント人への手紙第一 9:5; マルコの福音書 5:23; ヨハネの福音書 11:3"> ところが、シモンのしゅうとめが熱病で床に着いていたので、人々はさっそく彼女のことをイエスに知らせた。</span>
<span className="v" id="v31" data-v="31" data-xref="使徒の働き 9:41; Psalms 116:12; マルコの福音書 5:41"> イエスは、彼女に近寄り、その手を取って起こされた。すると熱がひき、彼女は彼らをもてなした。</span>
<span className="v" id="v32" data-v="32" data-xref="マタイの福音書 8:16; マルコの福音書 3:2; ルカの福音書 4:40"> 夕方になった。日が沈むと、人々は病人や悪霊につかれた者をみな、イエスのもとに連れて来た。</span>
<span className="v" id="v33" data-v="33" data-xref="マルコの福音書 1:5; 使徒の働き 13:44"> こうして町中の者が戸口に集まって来た。</span>
<span className="v" id="v34" data-v="34" data-xref="ルカの福音書 4:41; マルコの福音書 3:12; マタイの福音書 4:23"> イエスは、さまざまの病気にかかっている多くの人をお直しになり、また多くの悪霊を追い出された。そして悪霊どもがものを言うのをお許しにならなかった。彼らがイエスをよく知っていたからである。</span>
<span className="v" id="v35" data-v="35" data-xref="ルカの福音書 6:12; ルカの福音書 5:16; ルカの福音書 22:39–46"> さて、イエスは、朝早くまだ暗いうちに起きて、寂しい所へ出て行き、そこで祈っておられた。</span>
<span className="v" id="v36" data-v="36"> シモンとその仲間は、イエスを追って来て、</span>
<span className="v" id="v37" data-v="37" data-xref="ヨハネの福音書 12:19; マルコの福音書 1:5; Zechariah 11:11"> 彼を見つけ、「みんながあなたを捜しております。」と言った。</span>
<span className="v" id="v38" data-v="38" data-xref="ルカの福音書 4:43; ヨハネの福音書 17:8; Isaiah 61:1–3"> イエスは彼らに言われた。「さあ、近くの別の村里へ行こう。そこにも福音を知らせよう。わたしは、そのために出て来たのだから。」</span>
<span className="v" id="v39" data-v="39" data-xref="マタイの福音書 4:23; マルコの福音書 1:21; ルカの福音書 4:43–44"> こうしてイエスは、ガリラヤ全地にわたり、その会堂に行って、福音を告げ知らせ、悪霊を追い出された。</span>
<span className="v" id="v40" data-v="40" data-xref="ルカの福音書 5:12–14; マタイの福音書 8:2–4; Leviticus 13:1–14"> さて、ひとりのらい病人が、イエスのみもとにお願いに来て、ひざまずいて言った。「お心一つで、私はきよくしていただけます。」</span>
<span className="v" id="v41" data-v="41" data-xref="マタイの福音書 9:36; ヘブル人への手紙 2:17; ヘブル人への手紙 4:15"> イエスは深くあわれみ、手を伸ばして、彼にさわって言われた。「わたしの心だ。きよくなれ。」</span>
<span className="v" id="v42" data-v="42" data-xref="ヨハネの福音書 15:3; マルコの福音書 5:29; ヨハネの福音書 4:50–53"> すると、すぐに、そのらい病が消えて、その人はきよくなった。</span>
<span className="v" id="v43" data-v="43" data-xref="マタイの福音書 9:30; マルコの福音書 7:36; ルカの福音書 8:56"> そこでイエスは、彼をきびしく戒めて、すぐに彼を立ち去らせた。</span>
<span className="v" id="v44" data-v="44" data-xref="Leviticus 14:1–32; ルカの福音書 17:14; マタイの福音書 8:4"> そのとき彼にこう言われた。「気をつけて、だれにも何も言わないようにしなさい。ただ行って、自分を祭司に見せなさい。そして、人々へのあかしのために、モーセが命じた物をもって、あなたのきよめの供え物をしなさい。」</span>
<span className="v" id="v45" data-v="45" data-xref="マルコの福音書 2:13; マタイの福音書 9:31; ヨハネの福音書 6:2"> ところが、彼は出て行って、この出来事をふれ回り、言い広め始めた。そのためイエスは表立って町の中にはいることができず、町はずれの寂しい所におられた。しかし、人々は、あらゆる所からイエスのもとにやって来た。</span>

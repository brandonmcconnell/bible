<div className="bible-chapter" lang="ja" dir="ltr" data-lang="ja" data-translation="shinkaiyaku1965" data-translation-id="jpn_loc" data-translation-label="新改訳 1965" data-book="MRK" data-book-slug="mark" data-book-name="マルコの福音書" data-chapter="10" data-verses="52">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨハネの福音書 10:40; マルコの福音書 4:2; ヨハネの福音書 11:7"> イエスは、そこを立って、ユダヤ地方とヨルダンの向こうに行かれた。すると、群衆がまたもみもとに集まって来たので、またいつものように彼らを教えられた。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="コリント人への手紙第一 7:10–11; ルカの福音書 11:53–54; ヨハネの福音書 8:6"> すると、パリサイ人たちがみもとにやって来て、夫が妻を離別することは許されるかどうかと質問した。イエスをためそうとしたのである。</span>
<span className="v" id="v3" data-v="3" data-xref="Isaiah 8:20; ガラテヤ人への手紙 4:21; ルカの福音書 10:25"> イエスは答えて言われた。「モーセはあなたがたに、何と命じていますか。」</span>
<span className="v" id="v4" data-v="4" data-xref="Deuteronomy 24:1–4; マタイの福音書 5:31–32; Isaiah 50:1"> 彼らは言った。「モーセは、離婚状を書いて妻を離別することを許しました。」</span>
<span className="v" id="v5" data-v="5" data-xref="マタイの福音書 19:8; Nehemiah 9:26; 使徒の働き 7:51"> イエスは言われた。「モーセは、あなたがたの心がかたくななので、この命令をあなたがたに書いたのです。</span>
<span className="v" id="v6" data-v="6" data-xref="Genesis 1:27; Genesis 5:2; Genesis 1:1"> しかし、創造の初めから、神は、人を男と女に造られたのです。</span>
<span className="v" id="v7" data-v="7" data-xref="Genesis 2:24; マタイの福音書 19:5–6; エペソ人への手紙 5:31"> それゆえ、人はその父と母を離れて、</span>
<span className="v" id="v8" data-v="8" data-xref="エペソ人への手紙 5:28; Genesis 2:24; コリント人への手紙第一 6:16"> ふたりの者が一心同体になるのです。それで、もはやふたりではなく、ひとりなのです。</span>
<span className="v" id="v9" data-v="9" data-xref="ローマ人への手紙 7:1–3; 1 Chronicles 7:10–13"> こういうわけで、人は、神が結び合わせたものを引き離してはなりません。」</span>
<span className="v" id="v10" data-v="10" data-xref="マルコの福音書 9:33; マルコの福音書 9:28; マルコの福音書 4:10"> 家に戻った弟子たちが、この問題についてイエスに尋ねた。</span>
<span className="v" id="v11" data-v="11" data-xref="マタイの福音書 5:31–32; マタイの福音書 19:9; コリント人への手紙第一 7:10–11"> そこで、イエスは彼らに言われた。「だれでも、妻を離別して別の女を妻にするなら、前の妻に対して姦淫を犯すのです。</span>
<span className="v" id="v12" data-v="12" data-xref="コリント人への手紙第一 7:11; コリント人への手紙第一 7:13"> 妻も、夫を離別して別の男にとつぐなら、姦淫を犯しているのです。」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="マタイの福音書 19:13–15; ルカの福音書 18:15–17; Exodus 10:9–11"> さて、イエスにさわっていただこうとして、人々が子どもたちを、みもとに連れて来た。ところが、弟子たちは彼らをしかった。</span>
<span className="v" id="v14" data-v="14" data-xref="マタイの福音書 19:14; マタイの福音書 18:10; マタイの福音書 18:4"> イエスはそれをご覧になり、憤って、彼らに言われた。「子どもたちを、わたしのところに来させなさい。止めてはいけません。神の国は、このような者たちのものです。</span>
<span className="v" id="v15" data-v="15" data-xref="マタイの福音書 18:3; ルカの福音書 18:17; ヨハネの福音書 3:3–6"> まことに、あなたがたに告げます。子どものように神の国を受け入れる者でなければ、決してそこに、はいることはできません。」</span>
<span className="v" id="v16" data-v="16" data-xref="マルコの福音書 9:36; Isaiah 40:11; ヨハネの福音書 21:15–17"> そしてイエスは子どもたちを抱き、彼らの上に手を置いて祝福された。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="マタイの福音書 19:16–30; ルカの福音書 18:18–30; ローマ人への手紙 2:7"> イエスが道に出て行かれると、ひとりの人が走り寄って、御前にひざまずいて、尋ねた。「尊い先生。永遠のいのちを自分のものとして受けるためには、私は何をしたらよいでしょうか。」</span>
<span className="v" id="v18" data-v="18" data-xref="ルカの福音書 18:19; マタイの福音書 19:17; ローマ人への手紙 3:12"> イエスは彼に言われた。「なぜ、わたしを『尊い』と言うのですか。尊い方は、神おひとりのほかには、だれもありません。</span>
<span className="v" id="v19" data-v="19" data-xref="Exodus 20:12–17; ローマ人への手紙 13:9; ヤコブの手紙 2:11"> 戒めはあなたもよく知っているはずです。『殺してはならない。姦淫してはならない。盗んではならない。偽証を立ててはならない。欺き取ってはならない。父と母を敬え。』」</span>
<span className="v" id="v20" data-v="20" data-xref="Ezekiel 33:31–32; テモテへの手紙第二 3:5; ピリピ人への手紙 3:6"> すると、その人はイエスに言った。「先生。私はそのようなことをみな、小さい時から守っております。」</span>
<span className="v" id="v21" data-v="21" data-xref="マタイの福音書 6:19–21; ヨハネの黙示録 2:4; ルカの福音書 18:22"> イエスは彼を見つめ、その人をいつくしんで言われた。「あなたには、欠けたことが一つあります。帰って、あなたの持ち物をみな売り払い、貧しい人たちに与えなさい。そうすれば、あなたは天に宝を積むことになります。そのうえで、わたしについて来なさい。」</span>
<span className="v" id="v22" data-v="22" data-xref="ヨハネの手紙第一 2:15–16; テモテへの手紙第一 6:9–10; ルカの福音書 12:15"> すると彼は、このことばに顔を曇らせ、悲しみながら立ち去った。なぜなら、この人は多くの財産を持っていたからである。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="コリント人への手紙第一 1:26; ルカの福音書 18:24; マルコの福音書 3:5"> イエスは、見回して、弟子たちに言われた。「裕福な者が神の国にはいることは、何とむずかしいことでしょう。」</span>
<span className="v" id="v24" data-v="24" data-xref="ヤコブの手紙 5:1–3; Proverbs 11:28; Psalms 52:7"> 弟子たちは、イエスのことばに驚いた。しかし、イエスは重ねて、彼らに答えて言われた。「子たちよ。神の国にはいることは、何とむずかしいことでしょう。</span>
<span className="v" id="v25" data-v="25" data-xref="マタイの福音書 19:24–25; ルカの福音書 18:25; マタイの福音書 23:24"> 金持ちが神の国にはいるよりは、らくだが針の穴を通るほうがもっとやさしい。」</span>
<span className="v" id="v26" data-v="26" data-xref="使徒の働き 16:31; コリント人への手紙第二 11:23; ローマ人への手紙 10:9–13"> 弟子たちは、ますます驚いて互いに言った。「それでは、だれが救われることができるのだろうか。」</span>
<span className="v" id="v27" data-v="27" data-xref="マタイの福音書 19:26; Jeremiah 32:27; Job 42:2"> イエスは、彼らをじっと見て言われた。「それは人にはできないことですが、神は、そうではありません。どんなことでも、神にはできるのです。」</span>
<span className="v" id="v28" data-v="28" data-xref="マタイの福音書 19:27–30; ルカの福音書 18:28–30; ルカの福音書 14:33"> ペテロがイエスにこう言い始めた。「ご覧ください。私たちは、何もかも捨てて、あなたに従ってまいりました。」</span>
<span className="v" id="v29" data-v="29" data-xref="コリント人への手紙第一 9:23; マタイの福音書 5:10–11; マルコの福音書 8:35"> イエスは言われた。「まことに、あなたがたに告げます。わたしのために、また福音のために、家、兄弟、姉妹、母、父、子、畑を捨てた者で、</span>
<span className="v" id="v30" data-v="30" data-xref="ルカの福音書 18:30; ピリピ人への手紙 3:8; コリント人への手紙第二 6:10"> その百倍を受けない者はありません。今のこの時代には、家、兄弟、姉妹、母、子、畑を迫害の中で受け、後の世では永遠のいのちを受けます。</span>
<span className="v" id="v31" data-v="31" data-xref="マタイの福音書 19:30; ルカの福音書 13:30; マタイの福音書 20:16"> しかし、先の者があとになり、あとの者が先になることが多いのです。」</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="マタイの福音書 20:17–19; ルカの福音書 18:31–34; ルカの福音書 9:51"> さて、一行は、エルサレムに上る途中にあった。イエスは先頭に立って歩いて行かれた。弟子たちは驚き、また、あとについて行く者たちは恐れを覚えた。すると、イエスは再び十二弟子をそばに呼んで、ご自分に起ころうとしていることを、話し始められた。</span>
<span className="v" id="v33" data-v="33" data-xref="マタイの福音書 27:2; マタイの福音書 20:17–19; マルコの福音書 8:31"> 「さあ、これから、わたしたちはエルサレムに向かって行きます。人の子は、祭司長、律法学者たちに引き渡されるのです。彼らは、人の子を死刑に定め、そして、異邦人に引き渡します。</span>
<span className="v" id="v34" data-v="34" data-xref="マタイの福音書 26:67; マタイの福音書 16:21; マルコの福音書 14:65"> すると彼らはあざけり、つばきをかけ、むち打ち、ついに殺します。しかし、人の子は三日の後に、よみがえります。」</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="マタイの福音書 20:20–28; 2 Samuel 14:4–11; 1 Kings 2:20"> さて、ゼベダイのふたりの子、ヤコブとヨハネが、イエスのところに来て言った。「先生。私たちの頼み事をかなえていただきたいと思います。」</span>
<span className="v" id="v36" data-v="36" data-xref="ヨハネの福音書 15:7; 1 Kings 3:5–15; マルコの福音書 10:51"> イエスは彼らに言われた。「何をしてほしいのですか。」</span>
<span className="v" id="v37" data-v="37" data-xref="マタイの福音書 19:28; マルコの福音書 16:19; ルカの福音書 24:26"> 彼らは言った。「あなたの栄光の座で、ひとりを先生の右に、ひとりを左にすわらせてください。」</span>
<span className="v" id="v38" data-v="38" data-xref="ルカの福音書 12:50; マタイの福音書 20:21–22; Psalms 75:8"> しかし、イエスは彼らに言われた。「あなたがたは自分が何を求めているのか、わかっていないのです。あなたがたは、わたしの飲もうとする杯を飲み、わたしの受けようとするバプテスマを受けることができますか。」</span>
<span className="v" id="v39" data-v="39" data-xref="使徒の働き 12:2; ヨハネの黙示録 1:9; ヨハネの福音書 17:14"> 彼らは「できます。」と言った。イエスは言われた。「なるほどあなたがたは、わたしの飲む杯を飲み、わたしの受けるべきバプテスマを受けはします。</span>
<span className="v" id="v40" data-v="40" data-xref="マタイの福音書 20:23; マタイの福音書 25:34; ヨハネの福音書 17:24"> しかし、わたしの右と左にすわることは、わたしが許すことではありません。それに備えられた人々があるのです。」</span>
<span className="v" id="v41" data-v="41" data-xref="マタイの福音書 20:24; Proverbs 13:10; ローマ人への手紙 12:10"> 十人の者がこのことを聞くと、ヤコブとヨハネのことで腹を立てた。</span>
<span className="v" id="v42" data-v="42" data-xref="ペテロの手紙第一 5:3; ルカの福音書 22:25; マタイの福音書 20:25"> そこで、イエスは彼らを呼び寄せて、言われた。「あなたがたも知っているとおり、異邦人の支配者と認められた者たちは彼らを支配し、また、偉い人たちは彼らの上に権力をふるいます。</span>
<span className="v" id="v43" data-v="43" data-xref="マタイの福音書 23:8–12; ルカの福音書 14:11; マルコの福音書 9:35"> しかし、あなたがたの間では、そうでありません。あなたがたの間で偉くなりたいと思う者は、みなに仕える者になりなさい。</span>
<span className="v" id="v44" data-v="44"> あなたがたの間で人の先に立ちたいと思う者は、みなのしもべになりなさい。</span>
<span className="v" id="v45" data-v="45" data-xref="マタイの福音書 20:28; ピリピ人への手紙 2:5–8; コリント人への手紙第二 8:9"> 人の子が来たのも、仕えられるためではなく、かえって仕えるためであり、また、多くの人のための、贖いの代価として、自分のいのちを与えるためなのです。」</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="ルカの福音書 18:35–1; マタイの福音書 20:29–34; ヨハネの福音書 9:8"> 彼らはエリコに来た。イエスが、弟子たちや多くの群衆といっしょにエリコを出られると、テマイの子のバルテマイという盲人のこじきが、道ばたにすわっていた。</span>
<span className="v" id="v47" data-v="47" data-xref="マルコの福音書 1:24; マタイの福音書 9:27; ヨハネの黙示録 22:16"> ところが、ナザレのイエスだと聞くと、「ダビデの子のイエスさま。私をあわれんでください。」と叫び始めた。</span>
<span className="v" id="v48" data-v="48" data-xref="Jeremiah 29:13; マルコの福音書 7:26–29; ヘブル人への手紙 5:7"> そこで、彼を黙らせようと、大ぜいでたしなめたが、彼はますます、「ダビデの子よ。私をあわれんでください。」と叫び立てた。</span>
<span className="v" id="v49" data-v="49" data-xref="ルカの福音書 18:40; マタイの福音書 20:32–34; ヨハネの福音書 11:28"> すると、イエスは立ち止まって、「あの人を呼んで来なさい。」と言われた。そこで、彼らはその盲人を呼び、「心配しないでよい。さあ、立ちなさい。あなたをお呼びになっている。」と言った。</span>
<span className="v" id="v50" data-v="50" data-xref="ピリピ人への手紙 3:7–9; ヘブル人への手紙 12:1"> すると、盲人は上着を脱ぎ捨て、すぐ立ち上がって、イエスのところに来た。</span>
<span className="v" id="v51" data-v="51" data-xref="ルカの福音書 18:41–43; マルコの福音書 10:36; マタイの福音書 7:7"> そこでイエスは、さらにこう言われた。「わたしに何をしてほしいのか。」すると、盲人は言った。「先生。目が見えるようになることです。」</span>
<span className="v" id="v52" data-v="52" data-xref="マタイの福音書 9:22; 使徒の働き 26:18; マルコの福音書 8:25"> するとイエスは、彼に言われた。「さあ、行きなさい。あなたの信仰があなたを救ったのです。」すると、すぐさま彼は見えるようになり、イエスの行かれる所について行った。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ルカの福音書 22:1–2; Exodus 12:6–20; ヨハネの福音書 13:1"> さて、過越の祭りと種なしパンの祝いが二日後に迫っていたので、祭司長、律法学者たちは、どうしたらイエスをだまして捕え、殺すことができるだろうか、とけんめいであった。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネの福音書 7:40; Proverbs 21:30; ヨハネの福音書 12:19"> 彼らは、「祭りの間はいけない。民衆の騒ぎが起こるといけないから。」と話していた。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="ルカの福音書 7:37–39; ヨハネの福音書 12:1–8; ヨハネの福音書 11:2"> イエスがベタニヤで、らい病人シモンの家におられたとき、食卓に着いておられると、ひとりの女が、純粋で、非常に高価なナルド油のはいった石膏のつぼを持って来て、そのつぼを割り、イエスの頭に注いだ。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネの福音書 12:4–5; マタイの福音書 26:8–9; Malachi 1:12–13"> すると、何人かの者が憤慨して互いに言った。「何のために、香油をこんなにむだにしたのか。</span>
<span className="v" id="v5" data-v="5" data-xref="ヨハネの福音書 13:29; エペソ人への手紙 4:28; コリント人への手紙第一 10:10"> この香油なら、三百デナリ以上に売れて、貧乏な人たちに施しができたのに。」そうして、その女をきびしく責めた。</span>
<span className="v" id="v6" data-v="6" data-xref="テトスへの手紙 3:14; ヘブル人への手紙 10:24; ヘブル人への手紙 13:21"> すると、イエスは言われた。「そのままにしておきなさい。なぜこの人を困らせるのですか。わたしのために、りっぱなことをしてくれたのです。</span>
<span className="v" id="v7" data-v="7" data-xref="Deuteronomy 15:11; マタイの福音書 26:11; ヤコブの手紙 2:14–16"> 貧しい人たちは、いつもあなたがたといっしょにいます。それで、あなたがたがしたいときは、いつでも彼らに良いことをしてやれます。しかし、わたしは、いつもあなたがたといっしょにいるわけではありません。</span>
<span className="v" id="v8" data-v="8" data-xref="コリント人への手紙第二 8:12; ヨハネの福音書 12:7; マルコの福音書 15:42–1"> この女は、自分にできることをしたのです。埋葬の用意にと、わたしのからだに、前もって油を塗ってくれたのです。</span>
<span className="v" id="v9" data-v="9" data-xref="マタイの福音書 26:12–13; マルコの福音書 16:15; マタイの福音書 24:14"> まことに、あなたがたに告げます。世界中のどこででも、福音が宣べ伝えられる所なら、この人のした事も語られて、この人の記念となるでしょう。」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="ルカの福音書 22:3–6; マタイの福音書 26:14–16; ヨハネの福音書 13:2"> ところで、イスカリオテ・ユダは、十二弟子のひとりであるが、イエスを売ろうとして祭司長たちのところへ出向いて行った。</span>
<span className="v" id="v11" data-v="11" data-xref="テモテへの手紙第一 6:10; Hosea 7:3; ユダの手紙 1:11"> 彼らはこれを聞いて喜んで、金をやろうと約束した。そこでユダは、どうしたら、うまいぐあいにイエスを引き渡せるかと、ねらっていた。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="Exodus 12:6; Exodus 12:18; マタイの福音書 26:17–19"> 種なしパンの祝いの第一日、すなわち、過越の小羊をほふる日に、弟子たちはイエスに言った。「過越の食事をなさるのに、私たちは、どこへ行って用意をしましょうか。」</span>
<span className="v" id="v13" data-v="13" data-xref="ルカの福音書 22:10–13; マタイの福音書 26:18–19; ルカの福音書 19:30–33"> そこで、イエスは、弟子のうちふたりを送って、こう言われた。「都にはいりなさい。そうすれば、水がめを運んでいる男に会うから、その人について行きなさい。</span>
<span className="v" id="v14" data-v="14" data-xref="ヨハネの黙示録 3:20; マルコの福音書 11:3; ヨハネの福音書 13:13"> そして、その人がはいって行く家の主人に、『弟子たちといっしょに過越の食事をする、わたしの客間はどこか、と先生が言っておられる。』と言いなさい。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒の働き 1:13; Psalms 110:3; Proverbs 21:1–2"> するとその主人が自分で、席が整って用意のできた二階の広間を見せてくれます。そこでわたしたちのために用意をしなさい。」</span>
<span className="v" id="v16" data-v="16" data-xref="ヨハネの福音書 16:4; ルカの福音書 22:13; ルカの福音書 22:35"> 弟子たちが出かけて行って、都にはいると、まさしくイエスの言われたとおりであった。それで、彼らはそこで過越の食事の用意をした。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="ルカの福音書 22:14; ヨハネの福音書 13:21–26; マタイの福音書 26:20–24"> 夕方になって、イエスは十二弟子といっしょにそこに来られた。</span>
<span className="v" id="v18" data-v="18" data-xref="Psalms 41:9; ヨハネの福音書 6:47; ヨハネの福音書 6:70"> そして、みなが席に着いて、食事をしているとき、イエスは言われた。「まことに、あなたがたに告げます。あなたがたのうちのひとりで、わたしといっしょに食事をしている者が、わたしを裏切ります。」</span>
<span className="v" id="v19" data-v="19" data-xref="ルカの福音書 22:21–23; マタイの福音書 26:22; ヨハネの福音書 13:22"> 弟子たちは悲しくなって、「まさか私ではないでしょう。」とかわるがわるイエスに言いだした。</span>
<span className="v" id="v20" data-v="20" data-xref="ヨハネの福音書 13:26; マタイの福音書 26:23; ヨハネの福音書 6:71"> イエスは言われた。「この十二人の中のひとりで、わたしといっしょに、同じ鉢にパンを浸している者です。</span>
<span className="v" id="v21" data-v="21" data-xref="マタイの福音書 26:24–25; Isaiah 53:1–12; ヨハネの福音書 19:28"> 確かに、人の子は、自分について書いてあるとおりに、去って行きます。しかし、人の子を裏切るような人間はのろわれます。そういう人は生まれなかったほうがよかったのです。」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="マタイの福音書 26:26–29; マルコの福音書 14:24; コリント人への手紙第一 10:16–17"> それから、みなが食事をしているとき、イエスはパンを取り、祝福して後、これを裂き、彼らに与えて言われた。「取りなさい。これはわたしのからだです。」</span>
<span className="v" id="v23" data-v="23" data-xref="マルコの福音書 14:22; マタイの福音書 26:27; コリント人への手紙第一 10:16"> また、杯を取り、感謝をささげて後、彼らに与えられた。彼らはみなその杯から飲んだ。</span>
<span className="v" id="v24" data-v="24" data-xref="Zechariah 9:11; Exodus 24:8; ヨハネの黙示録 7:9–17"> イエスは彼らに言われた。「これはわたしの契約の血です。多くの人のために流されるものです。</span>
<span className="v" id="v25" data-v="25" data-xref="マタイの福音書 26:29; Psalms 104:15; ルカの福音書 22:16–18"> まことに、あなたがたに告げます。神の国で新しく飲むその日までは、わたしはもはや、ぶどうの実で造った物を飲むことはありません。」</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="マタイの福音書 26:30; ルカの福音書 22:39; 使徒の働き 16:25"> そして、賛美の歌を歌ってから、みなでオリーブ山へ出かけて行った。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="Zechariah 13:7; ヨハネの福音書 16:32; マタイの福音書 26:31"> イエスは、弟子たちに言われた。「あなたがたはみな、つまずきます。『わたしが羊飼いを打つ。すると、羊は散り散りになる。』と書いてありますから。</span>
<span className="v" id="v28" data-v="28" data-xref="マタイの福音書 28:16; マルコの福音書 16:7; マタイの福音書 28:7"> しかしわたしは、よみがえってから、あなたがたより先に、ガリラヤへ行きます。」</span>
<span className="v" id="v29" data-v="29" data-xref="マタイの福音書 26:33–35; ルカの福音書 22:33–34; ヨハネの福音書 13:36–38"> すると、ペテロがイエスに言った。「たとい全部の者がつまずいても、私はつまずきません。」</span>
<span className="v" id="v30" data-v="30" data-xref="ヨハネの福音書 13:38; マルコの福音書 14:66–72; Genesis 1:5"> イエスは彼に言われた。「まことに、あなたに告げます。あなたは、きょう、今夜、鶏が二度鳴く前に、わたしを知らないと三度言います。」</span>
<span className="v" id="v31" data-v="31" data-xref="Exodus 19:8; ヨハネの福音書 13:37; Proverbs 16:18"> ペテロは力を込めて言い張った。「たとい、ごいっしょに死ななければならないとしても、私は、あなたを知らないなどとは決して申しません。」みなの者もそう言った。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="マルコの福音書 14:36; マルコの福音書 14:39; Psalms 18:5–6"> ゲツセマネという所に来て、イエスは弟子たちに言われた。「わたしが祈る間、ここにすわっていなさい。」</span>
<span className="v" id="v33" data-v="33" data-xref="ルカの福音書 22:44; ヘブル人への手紙 5:7; マルコの福音書 5:37"> そして、ペテロ、ヤコブ、ヨハネをいっしょに連れて行かれた。イエスは深く恐れもだえ始められた。</span>
<span className="v" id="v34" data-v="34" data-xref="ヨハネの福音書 12:27; マルコの福音書 13:35–37; ペテロの手紙第一 5:8"> そして彼らに言われた。「わたしは悲しみのあまり死ぬほどです。ここを離れないで、目をさましていなさい。」</span>
<span className="v" id="v35" data-v="35" data-xref="マルコの福音書 14:41; Deuteronomy 9:18; ヘブル人への手紙 5:7"> それから、イエスは少し進んで行って、地面にひれ伏し、もしできることなら、この時が自分から過ぎ去るようにと祈り、</span>
<span className="v" id="v36" data-v="36" data-xref="ガラテヤ人への手紙 4:6; ローマ人への手紙 8:15–16; ヨハネの福音書 5:30"> またこう言われた。「アバ、父よ。あなたにおできにならないことはありません。どうぞ、この杯をわたしから取りのけてください。しかし、わたしの願うことではなく、あなたのみこころのままを、なさってください。」</span>
<span className="v" id="v37" data-v="37" data-xref="マタイの福音書 26:40; マルコの福音書 14:29–31; ヘブル人への手紙 12:3"> それから、イエスは戻って来て、彼らの眠っているのを見つけ、ペテロに言われた。「シモン。眠っているのか。一時間でも目をさましていることができなかったのか。</span>
<span className="v" id="v38" data-v="38" data-xref="マタイの福音書 26:41; マタイの福音書 24:42; ルカの福音書 21:36"> 誘惑に陥らないように、目をさまして、祈り続けなさい。心は燃えていても、肉体は弱いのです。」</span>
<span className="v" id="v39" data-v="39" data-xref="マタイの福音書 26:42–44; コリント人への手紙第二 12:8; マタイの福音書 6:7"> イエスは再び離れて行き、前と同じことばで祈られた。</span>
<span className="v" id="v40" data-v="40" data-xref="マルコの福音書 9:33–34; ローマ人への手紙 3:19; Genesis 44:16"> そして、また戻って来て、ご覧になると、彼らは眠っていた。ひどく眠けがさしていたのである。彼らは、イエスにどう言ってよいか、わからなかった。</span>
<span className="v" id="v41" data-v="41" data-xref="マルコの福音書 14:35; マルコの福音書 9:31; ヨハネの福音書 17:1"> イエスは三度目に来て、彼らに言われた。「まだ眠って休んでいるのですか。もう十分です。時が来ました。見なさい。人の子は罪人たちの手に渡されます。</span>
<span className="v" id="v42" data-v="42" data-xref="マタイの福音書 26:46; ヨハネの福音書 18:1–2"> 立ちなさい。さあ、行くのです。見なさい。わたしを裏切る者が近づきました。」</span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="ヨハネの福音書 18:3–11; ルカの福音書 22:47–53; マタイの福音書 26:47–56"> そしてすぐ、イエスがまだ話しておられるうちに、十二弟子のひとりのユダが現われた。剣や棒を手にした群衆もいっしょであった。群衆はみな、祭司長、律法学者、長老たちから差し向けられたものであった。</span>
<span className="v" id="v44" data-v="44" data-xref="マタイの福音書 26:48–50; Proverbs 27:6; Psalms 55:20–21"> イエスを裏切る者は、彼らと前もって次のような合図を決めておいた。「私が口づけをするのが、その人だ。その人をつかまえて、しっかりと引いて行くのだ。」</span>
<span className="v" id="v45" data-v="45" data-xref="マタイの福音書 23:7–10; Malachi 1:6; マルコの福音書 12:14"> それで、彼はやって来るとすぐに、イエスに近寄って、「先生。」と言って、口づけした。</span>
<span className="v" id="v46" data-v="46" data-xref="ヨハネの福音書 18:12; Lamentations 4:20; 使徒の働き 2:23"> すると人々は、イエスに手をかけて捕えた。</span>
<span className="v" id="v47" data-v="47" data-xref="ヨハネの福音書 18:10–11; マタイの福音書 26:51–54; ルカの福音書 22:49–51"> そのとき、イエスのそばに立っていたひとりが、剣を抜いて大祭司のしもべに撃ちかかり、その耳を切り落とした。</span>
<span className="v" id="v48" data-v="48" data-xref="ルカの福音書 22:52–53; 1 Samuel 26:18; 1 Samuel 24:14–15"> イエスは彼らに向かって言われた。「まるで強盗にでも向かうように、剣や棒を持ってわたしを捕えに来たのですか。</span>
<span className="v" id="v49" data-v="49" data-xref="ヨハネの福音書 18:20; ヨハネの福音書 8:2; ルカの福音書 22:37"> わたしは毎日、宮であなたがたといっしょにいて、教えていたのに、あなたがたは、わたしを捕えなかったのです。しかし、こうなったのは聖書のことばが実現するためです。」</span>
<span className="v" id="v50" data-v="50" data-xref="マルコの福音書 14:27; ヨハネの福音書 16:32; Psalms 88:18"> すると、みながイエスを見捨てて、逃げてしまった。</span>
</div>
<div className="bp">
<span className="v" id="v51" data-v="51"> ある青年が、素はだに亜麻布を一枚まとったままで、イエスについて行ったところ、人々は彼を捕えようとした。</span>
<span className="v" id="v52" data-v="52" data-xref="マルコの福音書 13:14–16; Genesis 39:12; Job 2:4"> すると、彼は亜麻布を脱ぎ捨てて、はだかで逃げた。</span>
</div>
<div className="bp">
<span className="v" id="v53" data-v="53" data-xref="マタイの福音書 26:57–68; ヨハネの福音書 18:12–14; ルカの福音書 22:54–62"> 彼らがイエスを大祭司のところに連れて行くと、祭司長、長老、律法学者たちがみな、集まって来た。</span>
<span className="v" id="v54" data-v="54" data-xref="ヨハネの福音書 18:18; マタイの福音書 26:3; ヨハネの福音書 18:25"> ペテロは、遠くからイエスのあとをつけながら、大祭司の庭の中まではいって行った。そして、役人たちといっしょにすわって、火にあたっていた。</span>
<span className="v" id="v55" data-v="55" data-xref="ペテロの手紙第一 3:16–18; マタイの福音書 26:59–60; マタイの福音書 5:22"> さて、祭司長たちと全議会は、イエスを死刑にするために、イエスを訴える証拠をつかもうと努めたが、何も見つからなかった。</span>
<span className="v" id="v56" data-v="56"> イエスに対する偽証をした者は多かったが、一致しなかったのである。</span>
<span className="v" id="v57" data-v="57" data-xref="使徒の働き 6:13–14; マタイの福音書 26:60–61; ヨハネの福音書 2:18–21"> すると、数人が立ち上がって、イエスに対する偽証をして、次のように言った。</span>
<span className="v" id="v58" data-v="58" data-xref="ヨハネの福音書 2:19; ヘブル人への手紙 9:11; コリント人への手紙第二 5:1"> 「私たちは、この人が『わたしは手で造られたこの神殿をこわして、三日のうちに、手で造られない別の神殿を造ってみせる。』と言うのを聞きました。」</span>
<span className="v" id="v59" data-v="59"> しかし、この点でも証言は一致しなかった。</span>
<span className="v" id="v60" data-v="60" data-xref="ヨハネの福音書 19:9–10; マタイの福音書 26:62–63; マルコの福音書 15:3–5"> そこで大祭司が立ち上がり、真中に進み出てイエスに尋ねて言った。「何も答えないのですか。この人たちが、あなたに不利な証言をしていますが、これはどうなのですか。」</span>
<span className="v" id="v61" data-v="61" data-xref="マタイの福音書 26:63–64; マルコの福音書 15:2; Isaiah 53:7"> しかし、イエスは黙ったままで、何もお答えにならなかった。大祭司は、さらにイエスに尋ねて言った。「あなたは、ほむべき方の子、キリストですか。」</span>
<span className="v" id="v62" data-v="62" data-xref="Daniel 7:13–14; Psalms 110:1; ヘブル人への手紙 1:3"> そこでイエスは言われた。「わたしは、それです。人の子が、力ある方の右の座に着き、天の雲に乗って来るのを、あなたがたは見るはずです。」</span>
<span className="v" id="v63" data-v="63" data-xref="マタイの福音書 26:65; Isaiah 36:22–1; Numbers 14:6"> すると、大祭司は、自分の衣を引き裂いて言った。「これでもまだ、証人が必要でしょうか。</span>
<span className="v" id="v64" data-v="64" data-xref="Leviticus 24:16; ヨハネの福音書 10:31–33; ヨハネの福音書 19:7"> あなたがたは、神をけがすこのことばを聞いたのです。どう考えますか。」すると、彼らは全員で、イエスには死刑に当たる罪があると決めた。</span>
<span className="v" id="v65" data-v="65" data-xref="マタイの福音書 26:67–68; 使徒の働き 23:2; Isaiah 50:6"> そうして、ある人々は、イエスにつばきをかけ、御顔をおおい、こぶしでなぐりつけ、「言い当ててみろ。」などと言ったりし始めた。また、役人たちは、イエスを受け取って、平手で打った。</span>

<span className="v" id="v66" data-v="66" data-xref="マルコの福音書 14:54; マタイの福音書 26:69–75; ヨハネの福音書 18:25–27"> ペテロが下の庭にいると、大祭司の女中のひとりが来て、</span>
<span className="v" id="v67" data-v="67" data-xref="マルコの福音書 14:54; マルコの福音書 10:47; マタイの福音書 2:23"> ペテロが火にあたっているのを見かけ、彼をじっと見つめて、言った。「あなたも、あのナザレ人、あのイエスといっしょにいましたね。」</span>
<span className="v" id="v68" data-v="68" data-xref="マルコの福音書 14:29–31; マタイの福音書 26:71–72; ヨハネの福音書 13:36–38"> しかし、ペテロはそれを打ち消して、「何を言っているのか、わからない。見当もつかない。」と言って、出口のほうへと出て行った。</span>
<span className="v" id="v69" data-v="69" data-xref="ルカの福音書 22:58; マルコの福音書 14:38; ガラテヤ人への手紙 6:1"> すると女中は、ペテロを見て、そばに立っていた人たちに、また、「この人はあの仲間です。」と言いだした。</span>
<span className="v" id="v70" data-v="70" data-xref="ルカの福音書 22:59–60; マタイの福音書 26:73–74; 使徒の働き 2:7"> しかし、ペテロは再び打ち消した。しばらくすると、そばに立っていたその人たちが、またペテロに言った。「確かに、あなたはあの仲間だ。ガリラヤ人なのだから。」</span>
<span className="v" id="v71" data-v="71" data-xref="Jeremiah 17:9; コリント人への手紙第一 10:12; 2 Kings 10:32"> しかし、彼はのろいをかけて誓い始め、「私は、あなたがたの話しているその人を知りません。」と言った。</span>
<span className="v" id="v72" data-v="72" data-xref="マルコの福音書 14:30; マルコの福音書 14:68; Ezekiel 7:16"> するとすぐに、鶏が、二度目に鳴いた。そこでペテロは、「鶏が二度鳴く前に、あなたは、わたしを知らないと三度言います。」というイエスのおことばを思い出した。それに思い当たったとき、彼は泣き出した。</span>

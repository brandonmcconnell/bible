<span className="v" id="v1" data-v="1" data-xref="マタイの福音書 24:1–51; Ezekiel 11:22–23; Ezekiel 10:19"> イエスが、宮から出て行かれるとき、弟子のひとりがイエスに言った。「先生。これはまあ、何とみごとな石でしょう。何とすばらしい建物でしょう。」</span>
<span className="v" id="v2" data-v="2" data-xref="ルカの福音書 21:6; マタイの福音書 24:2; 1 Kings 9:7–8"> すると、イエスは彼に言われた。「この大きな建物を見ているのですか。石がくずされずに、積まれたまま残ることは決してありません。」</span>
<span className="v" id="v3" data-v="3" data-xref="マタイの福音書 21:1; マルコの福音書 4:34; マルコの福音書 14:33"> イエスがオリーブ山で宮に向かってすわっておられると、ペテロ、ヤコブ、ヨハネ、アンデレが、ひそかにイエスに質問した。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒の働き 1:6–7; マタイの福音書 24:3; Daniel 12:6"> 「お話しください。いつ、そういうことが起こるのでしょう。また、それがみな実現するようなときには、どんな前兆があるのでしょう。」</span>
<span className="v" id="v5" data-v="5" data-xref="コロサイ人への手紙 2:8; エペソ人への手紙 5:6; Jeremiah 29:8"> そこで、イエスは彼らに話し始められた。「人に惑わされないように気をつけなさい。</span>
<span className="v" id="v6" data-v="6" data-xref="マルコの福音書 13:22; Jeremiah 23:21–25; ヨハネの福音書 8:24"> わたしの名を名のる者が大ぜい現われ、『私こそそれだ。』と言って、多くの人を惑わすでしょう。</span>
<span className="v" id="v7" data-v="7" data-xref="ルカの福音書 21:9–11; ヨハネの福音書 14:27; マタイの福音書 24:6–7"> また、戦争のことや戦争のうわさを聞いても、あわててはいけません。それは必ず起こることです。しかし、終わりが来たのではありません。</span>
<span className="v" id="v8" data-v="8" data-xref="マタイの福音書 24:8; Isaiah 37:3; Psalms 48:6"> 民族は民族に、国は国に敵対して立ち上がり、方々に地震があり、ききんも起こるはずだからです。これらのことは、産みの苦しみの初めです。</span>
<span className="v" id="v9" data-v="9" data-xref="マタイの福音書 10:17–18; ヨハネの福音書 16:2; ピリピ人への手紙 1:29"> だが、あなたがたは、気をつけていなさい。人々は、あなたがたを議会に引き渡し、また、あなたがたは会堂でむち打たれ、また、わたしのゆえに、総督や王たちの前に立たされます。それは彼らに対してあかしをするためです。</span>
<span className="v" id="v10" data-v="10" data-xref="マタイの福音書 24:14; コロサイ人への手紙 1:23; ローマ人への手紙 10:18"> こうして、福音がまずあらゆる民族に宣べ伝えられなければなりません。</span>
<span className="v" id="v11" data-v="11" data-xref="ルカの福音書 21:14–15; ルカの福音書 12:11–12; マタイの福音書 10:19–21"> 彼らに捕えられ、引き渡されたとき、何と言おうかなどと案じるには及びません。ただ、そのとき自分に示されることを、話しなさい。話すのはあなたがたではなく、聖霊です。</span>
<span className="v" id="v12" data-v="12" data-xref="マタイの福音書 10:21; ルカの福音書 12:52–53; ルカの福音書 21:16"> また兄弟は兄弟を死に渡し、父は子を死に渡し、子は両親に逆らって立ち、彼らを死に至らせます。</span>
<span className="v" id="v13" data-v="13" data-xref="ヨハネの福音書 15:18–19; マタイの福音書 10:22; マタイの福音書 24:13"> また、わたしの名のために、あなたがたはみなの者に憎まれます。しかし、最後まで耐え忍ぶ人は救われます。</span>
<span className="v" id="v14" data-v="14" data-xref="Daniel 9:27; Daniel 12:11; Daniel 11:31"> 『荒らす憎むべきもの』が、自分の立ってはならない所に立っているのを見たならば（読者はよく読み取るように。）ユダヤにいる人々は山へ逃げなさい。</span>
<span className="v" id="v15" data-v="15" data-xref="ルカの福音書 17:31–33; ヘブル人への手紙 11:7; ピリピ人への手紙 3:7–8"> 屋上にいる者は降りてはいけません。家から何かを取り出そうとして中にはいってはいけません。</span>
<span className="v" id="v16" data-v="16"> 畑にいる者は着物を取りに戻ってはいけません。</span>
<span className="v" id="v17" data-v="17" data-xref="Lamentations 4:10; ルカの福音書 23:29; Hosea 9:14"> だが、その日、悲惨なのは身重の女と乳飲み子を持つ女です。</span>
<span className="v" id="v18" data-v="18"> ただ、このことが冬に起こらないように祈りなさい。</span>
<span className="v" id="v19" data-v="19" data-xref="Daniel 12:1; Joel 2:2; マタイの福音書 24:21"> その日は、神が天地を創造された初めから、今に至るまで、いまだかつてなかったような、またこれからもないような苦難の日だからです。</span>
<span className="v" id="v20" data-v="20" data-xref="マタイの福音書 24:22; Zechariah 13:8–9; Isaiah 65:8–9"> そして、もし主がその日数を少なくしてくださらないなら、ひとりとして救われる者はないでしょう。しかし、主は、ご自分で選んだ選びの民のために、その日数を少なくしてくださったのです。</span>
<span className="v" id="v21" data-v="21" data-xref="ルカの福音書 21:8; マタイの福音書 24:23–25; マタイの福音書 24:5"> そのとき、あなたがたに、『そら、キリストがここにいる。』とか、『ほら、あそこにいる。』とか言う者があっても、信じてはいけません。</span>
<span className="v" id="v22" data-v="22" data-xref="マタイの福音書 24:24; テサロニケ人への手紙第二 2:8–14; マルコの福音書 13:6"> にせキリスト、にせ預言者たちが現われて、できれば選民を惑わそうとして、しるしや不思議なことをして見せます。</span>
<span className="v" id="v23" data-v="23" data-xref="ペテロの手紙第二 3:17; マルコの福音書 13:5; ヨハネの福音書 14:29"> だから、気をつけていなさい。わたしは、何もかも前もって話しました。</span>
<span className="v" id="v24" data-v="24" data-xref="Isaiah 13:10; 使徒の働き 2:19–20; ヨハネの黙示録 6:12–14"> だが、その日には、その苦難に続いて、太陽は暗くなり、月は光を放たず、</span>
<span className="v" id="v25" data-v="25" data-xref="Isaiah 34:4; ヨハネの黙示録 6:13"> 星は天から落ち、天の万象は揺り動かされます。</span>
<span className="v" id="v26" data-v="26" data-xref="ヨハネの黙示録 1:7; マタイの福音書 16:27; マタイの福音書 24:30"> そのとき、人々は、人の子が偉大な力と栄光を帯びて雲に乗って来るのを見るのです。</span>
<span className="v" id="v27" data-v="27" data-xref="Zechariah 2:6; マタイの福音書 24:31; Deuteronomy 30:4"> そのとき、人の子は、御使いたちを送り、地の果てから天の果てまで、四方からその選びの民を集めます。</span>
<span className="v" id="v28" data-v="28" data-xref="ルカの福音書 21:29–31; マタイの福音書 24:32–33"> いちじくの木から、たとえを学びなさい。枝が柔らかになって、葉が出て来ると、夏の近いことがわかります。</span>
<span className="v" id="v29" data-v="29" data-xref="ペテロの手紙第一 4:17–18; ヤコブの手紙 5:9; Ezekiel 12:25–28"> そのように、これらのことが起こるのを見たら、人の子が戸口まで近づいていると知りなさい。</span>
<span className="v" id="v30" data-v="30" data-xref="マタイの福音書 24:34; ルカの福音書 21:32; マタイの福音書 16:28"> まことに、あなたがたに告げます。これらのことが全部起こってしまうまでは、この時代は過ぎ去りません。</span>
<span className="v" id="v31" data-v="31" data-xref="Isaiah 40:8; Isaiah 51:6; マタイの福音書 24:35"> この天地は滅びます。しかし、わたしのことばは決して滅びることがありません。</span>
<span className="v" id="v32" data-v="32" data-xref="使徒の働き 1:7; マタイの福音書 24:36–42; マタイの福音書 25:13"> ただし、その日、その時がいつであるかは、だれも知りません。天の御使いたちも子も知りません。ただ父だけが知っておられます。</span>
<span className="v" id="v33" data-v="33" data-xref="エペソ人への手紙 6:18; ルカの福音書 12:40; ローマ人への手紙 13:11–12"> 気をつけなさい。目をさまし、注意していなさい。その定めの時がいつだか、あなたがたは知らないからです。</span>
<span className="v" id="v34" data-v="34" data-xref="マタイの福音書 25:14–30; ヨハネの福音書 10:3; ルカの福音書 12:36–40"> それはちょうど、旅に立つ人が、出がけに、しもべたちにはそれぞれ仕事を割り当てて責任を持たせ、門番には目をさましているように言いつけるようなものです。</span>
<span className="v" id="v35" data-v="35" data-xref="マルコの福音書 13:33; マタイの福音書 24:42; マタイの福音書 24:44"> だから、目をさましていなさい。家の主人がいつ帰って来るか、夕方か、夜中か、鶏の鳴くころか、明け方か、わからないからです。</span>
<span className="v" id="v36" data-v="36" data-xref="テサロニケ人への手紙第一 5:6–7; ローマ人への手紙 13:11–14; マタイの福音書 24:48–51"> 主人が不意に帰って来たとき眠っているのを見られないようにしなさい。</span>
<span className="v" id="v37" data-v="37" data-xref="マルコの福音書 13:33; ルカの福音書 12:41–46; マルコの福音書 13:35"> わたしがあなたがたに話していることは、すべての人に言っているのです。目をさましていなさい。」</span>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨハネの福音書 4:47; ルカの福音書 5:18; ルカの福音書 18:35–38"> 数日たって、イエスがカペナウムにまた来られると、家におられることが知れ渡った。</span>
<span className="v" id="v2" data-v="2" data-xref="マルコの福音書 2:13; マルコの福音書 1:45; Psalms 40:9"> それで多くの人が集まったため、戸口のところまですきまもないほどになった。この人たちに、イエスはみことばを話しておられた。</span>
<span className="v" id="v3" data-v="3" data-xref="ルカの福音書 5:18–26; マタイの福音書 9:1–8; マタイの福音書 4:24"> そのとき、ひとりの中風の人が四人の人にかつがれて、みもとに連れて来られた。</span>
<span className="v" id="v4" data-v="4" data-xref="ルカの福音書 5:19; Deuteronomy 22:8"> 群衆のためにイエスに近づくことができなかったので、その人々はイエスのおられるあたりの屋根をはがし、穴をあけて、中風の人を寝かせたままその床をつり降ろした。</span>
<span className="v" id="v5" data-v="5" data-xref="マタイの福音書 9:2; ヤコブの手紙 5:15; マルコの福音書 2:9–10"> イエスは彼らの信仰を見て、中風の人に、「子よ。あなたの罪は赦されました。」と言われた。</span>
<span className="v" id="v6" data-v="6" data-xref="ルカの福音書 5:21–22; マルコの福音書 8:17; コリント人への手紙第二 10:5"> ところが、その場に律法学者が数人すわっていて、心の中で理屈を言った。</span>
<span className="v" id="v7" data-v="7" data-xref="Isaiah 43:25; ルカの福音書 5:21; Micah 7:18"> 「この人は、なぜ、あんなことを言うのか。神をけがしているのだ。神おひとりのほか、だれが罪を赦すことができよう。」</span>
<span className="v" id="v8" data-v="8" data-xref="Psalms 139:2; 使徒の働き 8:22; ルカの福音書 5:22"> 彼らが心の中でこのように理屈を言っているのを、イエスはすぐにご自分の霊で見抜いて、こう言われた。「なぜ、あなたがたは心の中でそんな理屈を言っているのか。</span>
<span className="v" id="v9" data-v="9" data-xref="ルカの福音書 5:22–25; マタイの福音書 9:5"> 中風の人に、『あなたの罪は赦された。』と言うのと、『起きて、寝床をたたんで歩け。』と言うのと、どちらがやさしいか。</span>
<span className="v" id="v10" data-v="10" data-xref="Daniel 7:13–14; マタイの福音書 9:6–8; ヨハネの福音書 5:20–27"> 人の子が地上で罪を赦す権威を持っていることを、あなたがたに知らせるために。」こう言ってから、中風の人に、</span>
<span className="v" id="v11" data-v="11" data-xref="マルコの福音書 1:41; ヨハネの福音書 5:8–10; ヨハネの福音書 6:63"> 「あなたに言う。起きなさい。寝床をたたんで、家に帰りなさい。」と言われた。</span>
<span className="v" id="v12" data-v="12" data-xref="マタイの福音書 9:33; マタイの福音書 9:8; ルカの福音書 7:16"> すると彼は起き上がり、すぐに床を取り上げて、みなの見ている前を出て行った。それでみなの者がすっかり驚いて、「こういうことは、かつて見たことがない。」と言って神をあがめた。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="マルコの福音書 4:1; Proverbs 1:20–22; ルカの福音書 19:48"> イエスはまた湖のほとりに出て行かれた。すると群衆がみな、みもとにやって来たので、彼らに教えられた。</span>
<span className="v" id="v14" data-v="14" data-xref="ルカの福音書 5:27–32; ルカの福音書 6:15; マタイの福音書 9:9–13"> イエスは、道を通りながら、アルパヨの子レビが収税所にすわっているのをご覧になって、「わたしについて来なさい。」と言われた。すると彼は立ち上がって従った。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="ルカの福音書 15:1; ルカの福音書 5:29–30; マタイの福音書 9:10–11"> それから、イエスは、彼の家で食卓に着かれた。取税人や罪人たちも大ぜい、イエスや弟子たちといっしょに食卓に着いていた。こういう人たちが大ぜいいて、イエスに従っていたのである。</span>
<span className="v" id="v16" data-v="16" data-xref="ルカの福音書 19:10; ルカの福音書 19:7; ルカの福音書 18:11"> パリサイ派の律法学者たちは、イエスが罪人や取税人たちといっしょに食事をしておられるのを見て、イエスの弟子たちにこう言った。「なぜ、あの人は取税人や罪人たちといっしょに食事をするのですか。」</span>
<span className="v" id="v17" data-v="17" data-xref="マタイの福音書 9:12–13; ルカの福音書 15:7; ルカの福音書 5:31–32"> イエスはこれを聞いて、彼らにこう言われた。「医者を必要とするのは丈夫な者ではなく、病人です。わたしは正しい人を招くためではなく、罪人を招くために来たのです。」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="ルカの福音書 18:12; マタイの福音書 6:18; マタイの福音書 9:14–17"> ヨハネの弟子たちとパリサイ人たちは断食をしていた。そして、イエスのもとに来て言った。「ヨハネの弟子たちやパリサイ人の弟子たちは断食するのに、あなたの弟子たちはなぜ断食しないのですか。」</span>
<span className="v" id="v19" data-v="19" data-xref="マタイの福音書 25:1–10; Genesis 29:22; Judges 14:10–11"> イエスは彼らに言われた。「花婿が自分たちといっしょにいる間、花婿につき添う友だちが断食できるでしょうか。花婿といっしょにいる時は、断食できないのです。</span>
<span className="v" id="v20" data-v="20" data-xref="ルカの福音書 17:22; ヨハネの黙示録 21:9; Isaiah 54:5"> しかし、花婿が彼らから取り去られる時が来ます。その日には断食します。</span>
<span className="v" id="v21" data-v="21" data-xref="マタイの福音書 9:16; コリント人への手紙第一 10:13; Isaiah 57:16"> だれも、真新しい布切れで古い着物の継ぎをするようなことはしません。そんなことをすれば、新しい継ぎ切れは古い着物を引き裂き、破れはもっとひどくなります。</span>
<span className="v" id="v22" data-v="22" data-xref="マタイの福音書 9:17; Psalms 119:83; ルカの福音書 5:37–38"> また、だれも新しいぶどう酒を古い皮袋に入れるようなことはしません。そんなことをすれば、ぶどう酒は皮袋を張り裂き、ぶどう酒も皮袋もだめになってしまいます。新しいぶどう酒は新しい皮袋に入れるのです。」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="マタイの福音書 12:1–8; Deuteronomy 23:24–25; ルカの福音書 6:1–5"> ある安息日のこと、イエスは麦畑の中を通って行かれた。すると、弟子たちが道々穂を摘み始めた。</span>
<span className="v" id="v24" data-v="24" data-xref="Exodus 20:10; ヘブル人への手紙 12:3; マタイの福音書 12:2"> すると、パリサイ人たちがイエスに言った。「ご覧なさい。なぜ彼らは、安息日なのに、してはならないことをするのですか。」</span>
<span className="v" id="v25" data-v="25" data-xref="1 Samuel 21:3–6; ルカの福音書 10:26; マタイの福音書 22:31"> イエスは彼らに言われた。「ダビデとその連れの者たちが、食物がなくてひもじかったとき、ダビデが何をしたか、読まなかったのですか。</span>
<span className="v" id="v26" data-v="26" data-xref="2 Samuel 8:17; Leviticus 24:5–9; 1 Samuel 21:1"> アビヤタルが大祭司のころ、ダビデは神の家にはいって、祭司以外の者が食べてはならない供えのパンを、自分も食べ、またともにいた者たちにも与えたではありませんか。」</span>
<span className="v" id="v27" data-v="27" data-xref="コロサイ人への手紙 2:16; ルカの福音書 6:9; Deuteronomy 5:14"> また言われた。「安息日は人間のために設けられたのです。人間が安息日のために造られたのではありません。</span>
<span className="v" id="v28" data-v="28" data-xref="マタイの福音書 12:8; ヨハネの黙示録 1:10; ヨハネの福音書 5:17"> 人の子は安息日にも主です。」</span>
</div>

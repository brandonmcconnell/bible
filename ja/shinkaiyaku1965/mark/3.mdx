<span className="v" id="v1" data-v="1" data-xref="マタイの福音書 12:9–14; ルカの福音書 6:6–11; マルコの福音書 1:21"> イエスはまた会堂にはいられた。そこに片手のなえた人がいた。</span>
<span className="v" id="v2" data-v="2" data-xref="Psalms 37:32; ルカの福音書 14:1; ルカの福音書 6:7"> 彼らは、イエスが安息日にその人を直すかどうか、じっと見ていた。イエスを訴えるためであった。</span>
<span className="v" id="v3" data-v="3" data-xref="ピリピ人への手紙 1:28–30; Isaiah 42:4; ルカの福音書 6:8"> イエスは手のなえたその人に、「立って、真中に出なさい。」と言われた。</span>
<span className="v" id="v4" data-v="4" data-xref="ルカの福音書 6:9; マタイの福音書 12:10–12; Hosea 6:6"> それから彼らに、「安息日にしてよいのは、善を行なうことなのか、それとも悪を行なうことなのか。いのちを救うことなのか、それとも殺すことなのか。」と言われた。彼らは黙っていた。</span>
<span className="v" id="v5" data-v="5" data-xref="ルカの福音書 6:10; エペソ人への手紙 4:18; ローマ人への手紙 11:25"> イエスは怒って彼らを見回し、その心のかたくななのを嘆きながら、その人に、「手を伸ばしなさい。」と言われた。彼は手を伸ばした。するとその手が元どおりになった。</span>
<span className="v" id="v6" data-v="6" data-xref="マタイの福音書 22:16; マルコの福音書 12:13; マタイの福音書 12:14"> そこでパリサイ人たちは出て行って、すぐにヘロデ党の者たちといっしょになって、イエスをどうして葬り去ろうかと相談を始めた。</span>
<span className="v" id="v7" data-v="7" data-xref="マタイの福音書 4:25; ルカの福音書 6:17; マタイの福音書 12:15"> それから、イエスは弟子たちとともに湖のほうに退かれた。すると、ガリラヤから出て来た大ぜいの人々がついて行った。またユダヤから、</span>
<span className="v" id="v8" data-v="8" data-xref="Ezekiel 35:15; Isaiah 34:5; マタイの福音書 11:21"> エルサレムから、イドマヤから、ヨルダンの川向こうやツロ、シドンあたりから、大ぜいの人々が、イエスの行なっておられることを聞いて、みもとにやって来た。</span>
<span className="v" id="v9" data-v="9" data-xref="マルコの福音書 5:30; ヨハネの福音書 6:15"> イエスは、大ぜいの人なので、押し寄せて来ないよう、ご自分のために小舟を用意しておくように弟子たちに言いつけられた。</span>
<span className="v" id="v10" data-v="10" data-xref="マタイの福音書 14:36; マルコの福音書 6:56; マタイの福音書 4:23"> それは、多くの人をいやされたので、病気に悩む人たちがみな、イエスにさわろうとして、みもとに押しかけて来たからである。</span>
<span className="v" id="v11" data-v="11" data-xref="ルカの福音書 4:41; マルコの福音書 1:23–24; ルカの福音書 8:28"> また、汚れた霊どもが、イエスを見ると、みもとにひれ伏し、「あなたこそ神の子です。」と叫ぶのであった。</span>
<span className="v" id="v12" data-v="12" data-xref="マタイの福音書 12:16; マルコの福音書 1:25; マルコの福音書 1:34"> イエスは、ご自身のことを知らせないようにと、きびしく彼らを戒められた。</span>
<span className="v" id="v13" data-v="13" data-xref="ルカの福音書 9:1; ルカの福音書 6:12–16; マタイの福音書 10:1–4"> さて、イエスは山に登り、ご自身のお望みになる者たちを呼び寄せられたので、彼らはみもとに来た。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒の働き 1:8; ルカの福音書 9:1–6; ヨハネの福音書 15:16"> そこでイエスは十二弟子を任命された。それは、彼らを身近に置き、また彼らを遣わして福音を宣べさせ、</span>
<span className="v" id="v15" data-v="15"> 悪霊を追い出す権威を持たせるためであった。</span>
<span className="v" id="v16" data-v="16" data-xref="ヨハネの福音書 1:42; 使徒の働き 1:13; マタイの福音書 16:16–18"> こうして、イエスは十二弟子を任命された。そして、シモンにはペテロという名をつけ、</span>
<span className="v" id="v17" data-v="17" data-xref="ヘブル人への手紙 4:12; マルコの福音書 14:33; Jeremiah 23:29"> ゼベダイの子ヤコブとヤコブの兄弟ヨハネ、このふたりにはボアネルゲ、すなわち、雷の子という名をつけられた。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒の働き 1:13; マルコの福音書 2:14; マタイの福音書 9:9"> 次に、アンデレ、ピリポ、バルトロマイ、マタイ、トマス、アルパヨの子ヤコブ、タダイ、熱心党員シモン、</span>
<span className="v" id="v19" data-v="19" data-xref="ヨハネの福音書 6:71; ヨハネの福音書 13:2; 使徒の働き 1:16–25"> イスカリオテ・ユダ。このユダが、イエスを裏切ったのである。</span>
<span className="v" id="v20" data-v="20" data-xref="マルコの福音書 6:31; ヨハネの福音書 4:31–34; マルコの福音書 9:28"> イエスが家に戻られると、また大ぜいの人が集まって来たので、みなは食事する暇もなかった。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒の働き 26:24; ヨハネの福音書 10:20; マルコの福音書 3:31"> イエスの身内の者たちが聞いて、イエスを連れ戻しに出て来た。「気が狂ったのだ。」と言う人たちがいたからである。</span>
<span className="v" id="v22" data-v="22" data-xref="マタイの福音書 15:1; マタイの福音書 10:25; マタイの福音書 9:34"> また、エルサレムから下って来た律法学者たちも、「彼は、ベルゼブルに取りつかれている。」と言い、「悪霊どものかしらによって、悪霊どもを追い出しているのだ。」とも言った。</span>
<span className="v" id="v23" data-v="23" data-xref="ルカの福音書 11:17–23; マタイの福音書 12:25–30; マタイの福音書 13:34"> そこでイエスは彼らをそばに呼んで、たとえによって話された。「サタンがどうしてサタンを追い出せましょう。</span>
<span className="v" id="v24" data-v="24" data-xref="Zechariah 11:14; Isaiah 19:2–3; 2 Samuel 20:6"> もし国が内部で分裂したら、その国は立ち行きません。</span>
<span className="v" id="v25" data-v="25" data-xref="ヤコブの手紙 3:16; Psalms 133:1; ガラテヤ人への手紙 5:15"> また、家が内輪もめをしたら、家は立ち行きません。</span>
<span className="v" id="v26" data-v="26"> サタンも、もし内輪の争いが起こって分裂していれば、立ち行くことができないで滅びます。</span>
<span className="v" id="v27" data-v="27" data-xref="Isaiah 49:24–26; マタイの福音書 12:29; ルカの福音書 11:21–23"> 確かに、強い人の家に押し入って家財を略奪するには、まずその強い人を縛り上げなければなりません。そのあとでその家を略奪できるのです。</span>
<span className="v" id="v28" data-v="28" data-xref="ルカの福音書 12:10; マタイの福音書 12:31–32; ヨハネの手紙第一 5:16"> まことに、あなたがたに告げます。人はその犯すどんな罪も赦していただけます。また、神をけがすことを言っても、それはみな赦していただけます。</span>
<span className="v" id="v29" data-v="29" data-xref="マタイの福音書 12:31–32; ルカの福音書 12:10; テサロニケ人への手紙第二 1:9"> しかし、聖霊をけがす者はだれでも、永遠に赦されず、とこしえの罪に定められます。」</span>
<span className="v" id="v30" data-v="30" data-xref="ヨハネの福音書 10:20; マルコの福音書 3:22"> このように言われたのは、彼らが、「イエスは、汚れた霊につかれている。」と言っていたからである。</span>
<span className="v" id="v31" data-v="31" data-xref="ルカの福音書 8:19–21; マタイの福音書 12:46–50"> さて、イエスの母と兄弟たちが来て、外に立っていて、人をやり、イエスを呼ばせた。</span>
<span className="v" id="v32" data-v="32"> 大ぜいの人がイエスを囲んですわっていたが、「ご覧なさい。あなたのおかあさんと兄弟たちが、外であなたをたずねています。」と言った。</span>
<span className="v" id="v33" data-v="33" data-xref="マルコの福音書 3:21; Deuteronomy 33:9; マルコの福音書 6:3"> すると、イエスは彼らに答えて言われた。「わたしの母とはだれのことですか。また、兄弟たちとはだれのことですか。」</span>
<span className="v" id="v34" data-v="34" data-xref="マタイの福音書 12:49–50; ルカの福音書 11:27–28; ローマ人への手紙 8:29"> そして、自分の回りにすわっている人たちを見回して言われた。「ご覧なさい。わたしの母、わたしの兄弟たちです。</span>
<span className="v" id="v35" data-v="35" data-xref="ヨハネの手紙第一 2:17; マタイの福音書 7:21; ヨハネの手紙第一 3:22–23"> 神のみこころを行なう人はだれでも、わたしの兄弟、姉妹、また母なのです。」</span>

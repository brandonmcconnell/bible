<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ルカの福音書 5:1–3; マルコの福音書 2:13; ルカの福音書 8:4–10"> イエスはまた湖のほとりで教え始められた。おびただしい数の群衆がみもとに集まった。それでイエスは湖の上の舟に乗り、そこに腰をおろされ、群衆はみな岸べの陸地にいた。</span>
<span className="v" id="v2" data-v="2" data-xref="マタイの福音書 13:34–35; マルコの福音書 3:23; マルコの福音書 4:11"> イエスはたとえによって多くのことを教えられた。その教えの中でこう言われた。</span>
<span className="v" id="v3" data-v="3" data-xref="ヤコブの手紙 2:5; マタイの福音書 13:26; マルコの福音書 4:26–29"> 「よく聞きなさい。種を蒔く人が種蒔きに出かけた。</span>
<span className="v" id="v4" data-v="4" data-xref="マタイの福音書 13:19; マルコの福音書 4:15; マタイの福音書 13:4"> 蒔いているとき、種が道ばたに落ちた。すると、鳥が来て食べてしまった。</span>
<span className="v" id="v5" data-v="5" data-xref="Ezekiel 36:26; ルカの福音書 8:6; ルカの福音書 8:13"> また、別の種が土の薄い岩地に落ちた。土が深くなかったので、すぐに芽を出した。</span>
<span className="v" id="v6" data-v="6" data-xref="ヤコブの手紙 1:11; Jeremiah 17:5–8; Jonah 4:8"> しかし日が上ると、焼けて、根がないために枯れてしまった。</span>
<span className="v" id="v7" data-v="7" data-xref="Jeremiah 4:3; ルカの福音書 8:14; Genesis 3:17–18"> また、別の種がいばらの中に落ちた。ところが、いばらが伸びて、それをふさいでしまったので、実を結ばなかった。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨハネの福音書 15:5; コロサイ人への手紙 1:6; マルコの福音書 4:20"> また、別の種が良い地に落ちた。すると芽ばえ、育って、実を結び、三十倍、六十倍、百倍になった。」</span>
<span className="v" id="v9" data-v="9" data-xref="マタイの福音書 11:15; マルコの福音書 4:23–24; ヨハネの黙示録 3:22"> そしてイエスは言われた。「聞く耳のある者は聞きなさい。」</span>
<span className="v" id="v10" data-v="10" data-xref="マタイの福音書 13:10–17; マルコの福音書 4:34; Proverbs 13:20"> さて、イエスだけになったとき、いつもつき従っている人たちが、十二弟子とともに、これらのたとえのことを尋ねた。</span>
<span className="v" id="v11" data-v="11" data-xref="マタイの福音書 11:25; ルカの福音書 8:10; ヨハネの手紙第一 5:20"> そこで、イエスは言われた。「あなたがたには、神の国の奥義が知らされているが、ほかの人たちには、すべてがたとえで言われるのです。</span>
<span className="v" id="v12" data-v="12" data-xref="Isaiah 6:9–10; Isaiah 44:18; マタイの福音書 13:14–15"> それは、『彼らは確かに見るには見るがわからず、聞くには聞くが悟らず、悔い改めて赦されることのないため。』です。」</span>
<span className="v" id="v13" data-v="13" data-xref="ヨハネの黙示録 3:19; マタイの福音書 13:51–52; マルコの福音書 7:17–18"> そして彼らにこう言われた。「このたとえがわからないのですか。そんなことで、いったいどうしてたとえの理解ができましょう。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒の働き 8:4; マタイの福音書 13:19; マタイの福音書 13:37"> 種蒔く人は、みことばを蒔くのです。</span>
<span className="v" id="v15" data-v="15" data-xref="ペテロの手紙第一 5:8; マタイの福音書 13:19; コリント人への手紙第二 2:11"> みことばが道ばたに蒔かれるとは、こういう人たちのことです――みことばを聞くと、すぐサタンが来て、彼らに蒔かれたみことばを持ち去ってしまうのです。</span>
<span className="v" id="v16" data-v="16" data-xref="マルコの福音書 6:20; ルカの福音書 8:13; マタイの福音書 13:20–21"> 同じように、岩地に蒔かれるとは、こういう人たちのことです――みことばを聞くと、すぐに喜んで受けるが、</span>
<span className="v" id="v17" data-v="17" data-xref="マタイの福音書 11:6; テサロニケ人への手紙第一 3:3–5; マタイの福音書 12:31"> 根を張らないで、ただしばらく続くだけです。それで、みことばのために困難や迫害が起こると、すぐにつまずいてしまいます。</span>
<span className="v" id="v18" data-v="18" data-xref="ルカの福音書 8:14; Jeremiah 4:3; マタイの福音書 13:22"> もう一つの、いばらの中に種を蒔かれるとは、こういう人たちのことです――みことばを聞いてはいるが、</span>
<span className="v" id="v19" data-v="19" data-xref="ヨハネの手紙第一 2:15–17; テモテへの手紙第一 6:9–10; テモテへの手紙第一 6:17"> 世の心づかいや、富の惑わし、その他いろいろな欲望がはいり込んで、みことばをふさぐので、実を結びません。</span>
<span className="v" id="v20" data-v="20" data-xref="コロサイ人への手紙 1:10; ルカの福音書 8:15; ヨハネの福音書 15:4–5"> 良い地に蒔かれるとは、みことばを聞いて受け入れ、三十倍、六十倍、百倍の実を結ぶ人たちです。」</span>
<span className="v" id="v21" data-v="21" data-xref="マタイの福音書 5:15; ルカの福音書 11:33; ルカの福音書 8:16"> また言われた。「あかりを持って来るのは枡の下や寝台の下に置くためでしょうか。燭台の上に置くためではありませんか。</span>
<span className="v" id="v22" data-v="22" data-xref="ルカの福音書 8:17; Ecclesiastes 12:14; マタイの福音書 10:26–27"> 隠れているのは、必ず現われるためであり、おおい隠されているのは、明らかにされるためです。</span>
<span className="v" id="v23" data-v="23" data-xref="マルコの福音書 4:9; マタイの福音書 11:15; ヨハネの黙示録 2:29"> 聞く耳のある者は聞きなさい。」</span>
<span className="v" id="v24" data-v="24" data-xref="ヘブル人への手紙 2:1; ルカの福音書 8:18; マタイの福音書 7:2"> また彼らに言われた。「聞いていることによく注意しなさい。あなたがたは、人に量ってあげるその量りで、自分にも量り与えられ、さらにその上に増し加えられます。</span>
<span className="v" id="v25" data-v="25" data-xref="マタイの福音書 13:12; ルカの福音書 8:18; マタイの福音書 25:28–29"> 持っている人は、さらに与えられ、持たない人は、持っているものまでも取り上げられてしまいます。」</span>
<span className="v" id="v26" data-v="26" data-xref="マタイの福音書 13:24; コリント人への手紙第一 3:6–9; ルカの福音書 8:11"> また言われた。「神の国は、人が地に種を蒔くようなもので、</span>
<span className="v" id="v27" data-v="27" data-xref="Ecclesiastes 11:5; テサロニケ人への手紙第二 1:3; コリント人への手紙第一 15:37–38"> 夜は寝て、朝は起き、そうこうしているうちに、種は芽を出して育ちます。どのようにしてか、人は知りません。</span>
<span className="v" id="v28" data-v="28" data-xref="マルコの福音書 4:31–32; Hosea 6:3; ピリピ人への手紙 1:9–11"> 地は人手によらず実をならせるもので、初めに苗、次に穂、次に穂の中に実がはいります。</span>
<span className="v" id="v29" data-v="29" data-xref="Joel 3:13; マタイの福音書 13:30; マタイの福音書 13:40–43"> 実が熟すると、人はすぐにかまを入れます。収穫の時が来たからです。」</span>
<span className="v" id="v30" data-v="30" data-xref="マタイの福音書 13:31–32; ルカの福音書 13:18–21; Lamentations 2:13"> また言われた。「神の国は、どのようなものと言えばよいでしょう。何にたとえたらよいでしょう。</span>
<span className="v" id="v31" data-v="31" data-xref="使徒の働き 19:20; ルカの福音書 13:18–19; Daniel 2:44–45"> それはからし種のようなものです。地に蒔かれるときには、地に蒔かれる種の中で、一番小さいのですが、</span>
<span className="v" id="v32" data-v="32" data-xref="Daniel 4:20–22; Daniel 4:10–14; Ezekiel 31:3–10"> それが蒔かれると、生長してどんな野菜よりも大きくなり、大きな枝を張り、その陰に空の鳥が巣を作れるほどになります。」</span>
<span className="v" id="v33" data-v="33" data-xref="マタイの福音書 13:34–35; ヨハネの福音書 16:12; ヘブル人への手紙 5:11–14"> イエスは、このように多くのたとえで、彼らの聞く力に応じて、みことばを話された。</span>
<span className="v" id="v34" data-v="34" data-xref="ヨハネの福音書 16:25; マルコの福音書 4:10; マタイの福音書 15:15–20"> たとえによらないで話されることはなかった。ただ、ご自分の弟子たちにだけは、すべてのことを解き明かされた。</span>
<span className="v" id="v35" data-v="35" data-xref="マタイの福音書 8:18; ルカの福音書 8:22; ルカの福音書 8:25"> さて、その日のこと、夕方になって、イエスは弟子たちに、「さあ、向こう岸へ渡ろう。」と言われた。</span>
<span className="v" id="v36" data-v="36" data-xref="マルコの福音書 3:9; マルコの福音書 4:1; マルコの福音書 5:2"> そこで弟子たちは、群衆をあとに残し、舟に乗っておられるままで、イエスをお連れした。他の舟もイエスについて行った。</span>
<span className="v" id="v37" data-v="37" data-xref="マタイの福音書 8:23–24; Job 1:19; ルカの福音書 8:22–23"> すると、激しい突風が起こり、舟は波をかぶって水でいっぱいになった。</span>
<span className="v" id="v38" data-v="38" data-xref="ペテロの手紙第一 5:7; ヘブル人への手紙 4:15; Isaiah 54:6–8"> ところがイエスだけは、とものほうで、枕をして眠っておられた。弟子たちはイエスを起こして言った。「先生。私たちがおぼれて死にそうでも、何とも思われないのですか。」</span>
<span className="v" id="v39" data-v="39" data-xref="Psalms 107:29; Psalms 89:9; Psalms 65:7"> イエスは起き上がって、風をしかりつけ、湖に「黙れ、静まれ。」と言われた。すると風はやみ、大なぎになった。</span>
<span className="v" id="v40" data-v="40" data-xref="ルカの福音書 8:25; マタイの福音書 8:26; マタイの福音書 14:31"> イエスは彼らに言われた。「どうしてそんなにこわがるのです。信仰がないのは、どうしたことです。」</span>
<span className="v" id="v41" data-v="41" data-xref="ルカの福音書 8:25; Job 38:11; Psalms 89:7"> 彼らは大きな恐怖に包まれて、互いに言った。「風や湖までが言うことをきくとは、いったいこの方はどういう方なのだろう。」</span>

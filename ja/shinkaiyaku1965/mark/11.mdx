<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マタイの福音書 21:1–11; ヨハネの福音書 12:14–19; ルカの福音書 19:29–40"> さて、彼らがエルサレムの近くに来て、オリーブ山のふもとのベテパゲとベタニヤに近づいたとき、イエスはふたりの弟子を使いに出して、</span>
<span className="v" id="v2" data-v="2" data-xref="マタイの福音書 21:2–3; ルカの福音書 19:30–31"> 言われた。「向こうの村へ行きなさい。村にはいるとすぐ、まだだれも乗ったことのない、ろばの子が、つないであるのに気がつくでしょう。それをほどいて、引いて来なさい。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒の働き 10:36; マルコの福音書 14:15; Psalms 110:3"> もし、『なぜそんなことをするのか。』と言う人があったら、『主がお入用なのです。すぐに、またここに送り返されます。』と言いなさい。」</span>
<span className="v" id="v4" data-v="4" data-xref="マタイの福音書 26:19; ルカの福音書 19:32–34; マタイの福音書 21:6–7"> そこで、出かけて見ると、表通りにある家の戸口に、ろばの子が一匹つないであったので、それをほどいた。</span>
<span className="v" id="v5" data-v="5"> すると、そこに立っていた何人かが言った。「ろばの子をほどいたりして、どうするのですか。」</span>
<span className="v" id="v6" data-v="6"> 弟子たちが、イエスの言われたとおりを話すと、彼らは許してくれた。</span>
<span className="v" id="v7" data-v="7" data-xref="Zechariah 9:9; ルカの福音書 19:35–36; マタイの福音書 21:7–8"> そこで、ろばの子をイエスのところへ引いて行って、自分たちの上着をその上に掛けた。イエスはそれに乗られた。</span>
<span className="v" id="v8" data-v="8" data-xref="Leviticus 23:40"> すると、多くの人が、自分たちの上着を道に敷き、またほかの人々は、木の葉を枝ごと野原から切って来て、道に敷いた。</span>
<span className="v" id="v9" data-v="9" data-xref="Psalms 118:25–26; マタイの福音書 21:9; マタイの福音書 23:39"> そして、前を行く者も、あとに従う者も、叫んでいた。 「ホサナ。 祝福あれ。主の御名によって来られる方に。</span>
<span className="v" id="v10" data-v="10" data-xref="Ezekiel 37:24–25; ルカの福音書 2:14; ルカの福音書 19:38–40"> 祝福あれ。いま来た、われらの父ダビデの国に。 ホサナ。いと高き所に。」</span>
<span className="v" id="v11" data-v="11" data-xref="ヨハネの福音書 8:1–2; ルカの福音書 19:41–45; ルカの福音書 21:37–38"> こうして、イエスはエルサレムに着き、宮にはいられた。そして、すべてを見て回った後、時間ももうおそかったので、十二弟子といっしょにベタニヤに出て行かれた。</span>
<span className="v" id="v12" data-v="12" data-xref="マタイの福音書 21:18–22; マタイの福音書 4:2; ヨハネの福音書 19:28"> 翌日、彼らがベタニヤを出たとき、イエスは空腹を覚えられた。</span>
<span className="v" id="v13" data-v="13" data-xref="マタイの福音書 21:19; ルカの福音書 13:6–9; Isaiah 5:7"> 葉の茂ったいちじくの木が遠くに見えたので、それに何かありはしないかと見に行かれたが、そこに来ると、葉のほかは何もないのに気づかれた。いちじくのなる季節ではなかったからである。</span>
<span className="v" id="v14" data-v="14" data-xref="マタイの福音書 21:19; マタイの福音書 7:19; マタイの福音書 3:10"> イエスは、その木に向かって言われた。「今後、いつまでも、だれもおまえの実を食べることのないように。」弟子たちはこれを聞いていた。</span>
<span className="v" id="v15" data-v="15" data-xref="ヨハネの福音書 2:13–17; マタイの福音書 21:12–16; ルカの福音書 19:45–47"> それから、彼らはエルサレムに着いた。イエスは宮にはいり、宮の中で売り買いしている人々を追い出し始め、両替人の台や、鳩を売る者たちの腰掛けを倒し、</span>
<span className="v" id="v16" data-v="16"> また宮を通り抜けて器具を運ぶことをだれにもお許しにならなかった。</span>
<span className="v" id="v17" data-v="17" data-xref="Isaiah 56:7; Jeremiah 7:11; ルカの福音書 19:46"> そして、彼らに教えて言われた。「『わたしの家は、すべての民の祈りの家と呼ばれる。』と書いてあるではありませんか。それなのに、あなたがたはそれを強盗の巣にしたのです。」</span>
<span className="v" id="v18" data-v="18" data-xref="マタイの福音書 7:28; マルコの福音書 12:12; マルコの福音書 14:1–2"> 祭司長、律法学者たちは聞いて、どのようにしてイエスを殺そうかと相談した。イエスを恐れたからであった。なぜなら、群衆がみなイエスの教えに驚嘆していたからである。</span>
<span className="v" id="v19" data-v="19" data-xref="ルカの福音書 21:37; マルコの福音書 11:11; ヨハネの福音書 12:36"> 夕方になると、イエスとその弟子たちは、いつも都から外に出た。</span>
<span className="v" id="v20" data-v="20" data-xref="マタイの福音書 15:13; マルコの福音書 11:14; ヨハネの福音書 15:6"> 朝早く、通りがかりに見ると、いちじくの木が根まで枯れていた。</span>
<span className="v" id="v21" data-v="21" data-xref="Proverbs 3:33; マタイの福音書 23:7; マタイの福音書 25:41"> ペテロは思い出して、イエスに言った。「先生。ご覧なさい。あなたののろわれたいちじくの木が枯れました。」</span>
<span className="v" id="v22" data-v="22" data-xref="Psalms 62:8; ヨハネの福音書 14:1; マルコの福音書 9:23"> イエスは答えて言われた。「神を信じなさい。</span>
<span className="v" id="v23" data-v="23" data-xref="マタイの福音書 17:20; ヨハネの福音書 15:7; マタイの福音書 21:21"> まことに、あなたがたに告げます。だれでも、この山に向かって、『動いて、海にはいれ。』と言って、心の中で疑わず、ただ、自分の言ったとおりになると信じるなら、そのとおりになります。</span>
<span className="v" id="v24" data-v="24" data-xref="マタイの福音書 21:22; ヨハネの手紙第一 5:14–15; ヨハネの手紙第一 3:22"> だからあなたがたに言うのです。祈って求めるものは何でも、すでに受けたと信じなさい。そうすれば、そのとおりになります。</span>
<span className="v" id="v25" data-v="25" data-xref="マタイの福音書 6:14–15; コロサイ人への手紙 3:13; エペソ人への手紙 4:32"> また立って祈っているとき、だれかに対して恨み事があったら、赦してやりなさい。そうすれば、天におられるあなたがたの父も、あなたがたの罪を赦してくださいます。</span>
<span className="v" id="v26" data-v="26"> 彼らはまたエルサレムに来た。イエスが宮の中を歩いておられると、祭司長、律法学者、長老たちが、イエスのところにやって来た。</span>
<span className="v" id="v28" data-v="28" data-xref="Exodus 2:14; 使徒の働き 7:38–39; Numbers 16:3"> そして、イエスに言った。「何の権威によって、これらのことをしておられるのですか。だれが、あなたにこれらのことをする権威を授けたのですか。」</span>
<span className="v" id="v29" data-v="29" data-xref="ルカの福音書 20:3–8; マタイの福音書 21:24; Isaiah 52:13"> そこでイエスは彼らに言われた。「一言尋ねますから、それに答えなさい。そうすれば、わたしも、何の権威によってこれらのことをしているかを、話しましょう。</span>
<span className="v" id="v30" data-v="30" data-xref="ルカの福音書 3:1–20; ヨハネの福音書 3:25–36; マルコの福音書 1:1–11"> ヨハネのバプテスマは、天から来たのですか、人から出たのですか。答えなさい。」</span>
<span className="v" id="v31" data-v="31" data-xref="ヨハネの福音書 1:29; ヨハネの福音書 1:34; マタイの福音書 21:31–32"> すると、彼らは、こう言いながら、互いに論じ合った。「もし、天から、と言えば、それならなぜ、彼を信じなかったかと言うだろう。</span>
<span className="v" id="v32" data-v="32" data-xref="マタイの福音書 21:46; マルコの福音書 12:12; マタイの福音書 14:5"> だからといって、人から、と言ってよいだろうか。」――彼らは群衆を恐れていたのである。というのは、人々がみな、ヨハネは確かに預言者だと思っていたからである。</span>
<span className="v" id="v33" data-v="33" data-xref="Isaiah 6:9–10; コリント人への手紙第二 4:3–4; テサロニケ人への手紙第二 2:10–12"> そこで彼らは、イエスに答えて、「わかりません。」と言った。そこでイエスは彼らに、「わたしも、何の権威によってこれらのことをするのか、あなたがたに話すまい。」と言われた。</span>

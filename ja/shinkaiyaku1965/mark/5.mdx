<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ルカの福音書 8:26–39; マタイの福音書 8:28–34; マルコの福音書 4:35"> こうして彼らは湖の向こう岸、ゲラサ人の地に着いた。</span>
<span className="v" id="v2" data-v="2" data-xref="マルコの福音書 1:23; Isaiah 65:4; マルコの福音書 5:8"> イエスが舟から上がられると、すぐに、汚れた霊につかれた人が墓場から出て来て、イエスを迎えた。</span>
<span className="v" id="v3" data-v="3" data-xref="Isaiah 65:4; ルカの福音書 8:29; Daniel 4:32–33"> この人は墓場に住みついており、もはやだれも、鎖をもってしても、彼をつないでおくことができなかった。</span>
<span className="v" id="v4" data-v="4" data-xref="ヤコブの手紙 3:7–8"> 彼はたびたび足かせや鎖でつながれたが、鎖を引きちぎり、足かせも砕いてしまったからで、だれにも彼を押えるだけの力がなかったのである。</span>
<span className="v" id="v5" data-v="5" data-xref="Job 2:7–8; 1 Kings 18:28; ヨハネの福音書 8:44"> それで彼は、夜昼となく、墓場や山で叫び続け、石で自分のからだを傷つけていた。</span>
<span className="v" id="v6" data-v="6" data-xref="ヤコブの手紙 2:19; Psalms 66:3; ルカの福音書 4:41"> 彼はイエスを遠くから見つけ、駆け寄って来てイエスを拝し、</span>
<span className="v" id="v7" data-v="7" data-xref="マタイの福音書 8:29; 使徒の働き 16:17; マタイの福音書 26:63"> 大声で叫んで言った。「いと高き神の子、イエスさま。いったい私に何をしようというのですか。神の御名によってお願いします。どうか私を苦しめないでください。」</span>
<span className="v" id="v8" data-v="8" data-xref="マルコの福音書 1:25; マルコの福音書 9:25–26; 使徒の働き 16:18"> それは、イエスが、「汚れた霊よ。この人から出て行け。」と言われたからである。</span>
<span className="v" id="v9" data-v="9" data-xref="ルカの福音書 8:30; マルコの福音書 5:15; マタイの福音書 26:53"> それで、「おまえの名は何か。」とお尋ねになると、「私の名はレギオンです。私たちは大ぜいですから。」と言った。</span>
<span className="v" id="v10" data-v="10" data-xref="マルコの福音書 3:22; マルコの福音書 5:13"> そして、自分たちをこの地方から追い出さないでくださいと懇願した。</span>
<span className="v" id="v11" data-v="11" data-xref="Leviticus 11:7–8; Isaiah 65:4; Isaiah 66:3"> ところで、そこの山腹に、豚の大群が飼ってあった。</span>
<span className="v" id="v12" data-v="12" data-xref="コリント人への手紙第二 2:11; Job 1:10–12; ルカの福音書 22:31–32"> 彼らはイエスに願って言った。「私たちを豚の中に送って、彼らに乗り移らせてください。」</span>
<span className="v" id="v13" data-v="13" data-xref="1 Kings 22:22; ペテロの手紙第一 3:22; Job 2:6"> イエスがそれを許されたので、汚れた霊どもは出て行って、豚に乗り移った。すると、二千匹ほどの豚の群れが、険しいがけを駆け降り、湖へなだれ落ちて、湖におぼれてしまった。</span>
<span className="v" id="v14" data-v="14" data-xref="ルカの福音書 8:34; マタイの福音書 8:33"> 豚を飼っていた者たちは逃げ出して、町や村々でこの事を告げ知らせた。人々は何事が起こったのかと見にやって来た。</span>
<span className="v" id="v15" data-v="15" data-xref="コロサイ人への手紙 1:13; テモテへの手紙第二 1:7; 1 Samuel 6:20–21"> そして、イエスのところに来て、悪霊につかれていた人、すなわちレギオンを宿していた人が、着物を着て、正気に返ってすわっているのを見て、恐ろしくなった。</span>
<span className="v" id="v16" data-v="16"> 見ていた人たちが、悪霊につかれていた人に起こったことや、豚のことを、つぶさに彼らに話して聞かせた。</span>
<span className="v" id="v17" data-v="17" data-xref="マタイの福音書 8:34; マルコの福音書 1:24; ルカの福音書 8:37"> すると、彼らはイエスに、この地方から離れてくださるよう願った。</span>
<span className="v" id="v18" data-v="18" data-xref="ルカの福音書 8:38–39; ピリピ人への手紙 1:23–24; マルコの福音書 5:17"> それでイエスが舟に乗ろうとされると、悪霊につかれていた人が、お供をしたいとイエスに願った。</span>
<span className="v" id="v19" data-v="19" data-xref="Psalms 66:16; ヨハネの福音書 4:29; Isaiah 38:9–20"> しかし、お許しにならないで、彼にこう言われた。「あなたの家、あなたの家族のところに帰り、主があなたに、どんなに大きなことをしてくださったか、どんなにあわれんでくださったかを、知らせなさい。」</span>
<span className="v" id="v20" data-v="20" data-xref="マルコの福音書 7:31; マタイの福音書 4:25"> そこで、彼は立ち去り、イエスが自分にどんなに大きなことをしてくださったかを、デカポリスの地方で言い広め始めた。人々はみな驚いた。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="マタイの福音書 9:1; マルコの福音書 4:1; ルカの福音書 8:40"> イエスが舟でまた向こう岸へ渡られると、大ぜいの人の群れがみもとに集まった。イエスは岸べにとどまっておられた。</span>
<span className="v" id="v22" data-v="22" data-xref="ルカの福音書 13:14; 使徒の働き 18:8; マルコの福音書 5:35–36"> すると、会堂管理者のひとりでヤイロという者が来て、イエスを見て、その足もとにひれ伏し、</span>
<span className="v" id="v23" data-v="23" data-xref="ルカの福音書 13:13; ルカの福音書 4:40; マルコの福音書 16:18"> いっしょうけんめい願ってこう言った。「私の小さい娘が死にかけています。どうか、おいでくださって、娘の上に御手を置いてやってください。娘が直って、助かるようにしてください。」</span>
<span className="v" id="v24" data-v="24" data-xref="マルコの福音書 5:31; マルコの福音書 3:20; ルカの福音書 7:6"> そこで、イエスは彼といっしょに出かけられたが、多くの群衆がイエスについて来て、イエスに押し迫った。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="Leviticus 15:25–27; ルカの福音書 8:43–44; マタイの福音書 9:20–22"> ところで、十二年の間長血をわずらっている女がいた。</span>
<span className="v" id="v26" data-v="26" data-xref="Jeremiah 30:12–13; Jeremiah 8:22; Psalms 108:12"> この女は多くの医者からひどいめに会わされて、自分の持ち物をみな使い果たしてしまったが、何のかいもなく、かえって悪くなる一方であった。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒の働き 19:12; マタイの福音書 14:36; 使徒の働き 5:15"> 彼女は、イエスのことを耳にして、群衆の中に紛れ込み、うしろから、イエスの着物にさわった。</span>
<span className="v" id="v28" data-v="28"> 「お着物にさわることでもできれば、きっと直る。」と考えていたからである。</span>
<span className="v" id="v29" data-v="29" data-xref="マルコの福音書 5:34; Psalms 30:2; マルコの福音書 3:10"> すると、すぐに、血の源がかれて、ひどい痛みが直ったことを、からだに感じた。</span>
<span className="v" id="v30" data-v="30" data-xref="ルカの福音書 6:19; ルカの福音書 8:46; ルカの福音書 5:17"> イエスも、すぐに、自分のうちから力が外に出て行ったことに気づいて、群衆の中を振り向いて、「だれがわたしの着物にさわったのですか。」と言われた。</span>
<span className="v" id="v31" data-v="31" data-xref="ルカの福音書 8:45; ルカの福音書 9:12"> そこで弟子たちはイエスに言った。「群衆があなたに押し迫っているのをご覧になっていて、それでも『だれがわたしにさわったのか。』とおっしゃるのですか。」</span>
<span className="v" id="v32" data-v="32"> イエスは、それをした人を知ろうとして、見回しておられた。</span>
<span className="v" id="v33" data-v="33" data-xref="ルカの福音書 8:47; ルカの福音書 1:29; ルカの福音書 1:12"> 女は恐れおののき、自分の身に起こった事を知り、イエスの前に出てひれ伏し、イエスに真実を余すところなく打ち明けた。</span>
<span className="v" id="v34" data-v="34" data-xref="ルカの福音書 8:48; マタイの福音書 9:22; ルカの福音書 7:50"> そこで、イエスは彼女にこう言われた。「娘よ。あなたの信仰があなたを直したのです。安心して帰りなさい。病気にかからず、すこやかでいなさい。」</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="ルカの福音書 8:49; ヨハネの福音書 11:39; マルコの福音書 5:22"> イエスが、まだ話しておられるときに、会堂管理者の家から人がやって来て言った。「あなたのお嬢さんはなくなりました。なぜ、このうえ先生を煩わすことがありましょう。」</span>
<span className="v" id="v36" data-v="36" data-xref="ルカの福音書 8:50; マタイの福音書 9:28–29; ヨハネの福音書 11:40"> イエスは、その話のことばをそばで聞いて、会堂管理者に言われた。「恐れないで、ただ信じていなさい。」</span>
<span className="v" id="v37" data-v="37" data-xref="使徒の働き 9:40; マルコの福音書 14:33; コリント人への手紙第二 13:1"> そして、ペテロとヤコブとヤコブの兄弟ヨハネのほかは、だれも自分といっしょに行くのをお許しにならなかった。</span>
<span className="v" id="v38" data-v="38" data-xref="マタイの福音書 9:23–24; ルカの福音書 8:52–53; マルコの福音書 5:22"> 彼らはその会堂管理者の家に着いた。イエスは、人々が、取り乱し、大声で泣いたり、わめいたりしているのをご覧になり、</span>
<span className="v" id="v39" data-v="39" data-xref="使徒の働き 20:10; テサロニケ人への手紙第一 5:10; テサロニケ人への手紙第一 4:13–14"> 中にはいって、彼らにこう言われた。「なぜ取り乱して、泣くのですか。子どもは死んだのではない。眠っているのです。」</span>
<span className="v" id="v40" data-v="40" data-xref="Nehemiah 2:19; 2 Kings 4:33; マタイの福音書 9:24–25"> 人々はイエスをあざ笑った。しかし、イエスはみんなを外に出し、ただその子どもの父と母、それにご自分の供の者たちだけを伴って、子どものいる所へはいって行かれた。</span>
<span className="v" id="v41" data-v="41" data-xref="マルコの福音書 1:31; ルカの福音書 7:14–15; ルカの福音書 8:54–55"> そして、その子どもの手を取って、「タリタ、クミ。」と言われた。（訳して言えば、「少女よ。あなたに言う。起きなさい。」という意味である。）</span>
<span className="v" id="v42" data-v="42" data-xref="マルコの福音書 4:41; 使徒の働き 3:10–13; マルコの福音書 7:37"> すると、少女はすぐさま起き上がり、歩き始めた。十二歳にもなっていたからである。彼らはたちまち非常な驚きに包まれた。</span>
<span className="v" id="v43" data-v="43" data-xref="マタイの福音書 8:4; マタイの福音書 9:30; マルコの福音書 1:43"> イエスは、このことをだれにも知らせないようにと、きびしくお命じになり、さらに、少女に食事をさせるように言われた。</span>
</div>

<span className="v" id="v1" data-v="1" data-xref="Isaiah 5:1–4; マルコの福音書 13:34; Song of Solomon 8:11–12"> それからイエスは、たとえを用いて彼らに話し始められた。 「ある人がぶどう園を造って、垣を巡らし、酒ぶねを掘り、やぐらを建て、それを農夫たちに貸して、旅に出かけた。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネの福音書 15:1–8; ヘブル人への手紙 1:1; Jeremiah 44:4"> 季節になると、ぶどう園の収穫の分けまえを受け取りに、しもべを農夫たちのところへ遣わした。</span>
<span className="v" id="v3" data-v="3" data-xref="テサロニケ人への手紙第一 2:15; Nehemiah 9:26; Jeremiah 29:26"> ところが、彼らは、そのしもべをつかまえて袋だたきにし、何も持たせないで送り帰した。</span>
<span className="v" id="v4" data-v="4"> そこで、もう一度別のしもべを遣わしたが、彼らは、頭をなぐり、はずかしめた。</span>
<span className="v" id="v5" data-v="5" data-xref="マタイの福音書 22:6; マタイの福音書 23:37; Nehemiah 9:30"> また別のしもべを遣わしたところが、彼らは、これも殺してしまった。続いて、多くのしもべをやったけれども、彼らは袋だたきにしたり、殺したりした。</span>
<span className="v" id="v6" data-v="6" data-xref="ヘブル人への手紙 1:1–2; マタイの福音書 3:17; ヨハネの福音書 1:34"> その人には、なおもうひとりの者がいた。それは愛する息子であった。彼は、『私の息子なら、敬ってくれるだろう。』と言って、最後にその息子を遣わした。</span>
<span className="v" id="v7" data-v="7" data-xref="Genesis 37:20; マタイの福音書 2:16; 使徒の働き 2:23"> すると、その農夫たちはこう話し合った。『あれはあと取りだ。さあ、あれを殺そうではないか。そうすれば、財産はこちらのものだ。』</span>
<span className="v" id="v8" data-v="8" data-xref="マタイの福音書 21:39; ルカの福音書 20:15; マタイの福音書 21:33"> そして、彼をつかまえて殺してしまい、ぶどう園の外に投げ捨てた。</span>
<span className="v" id="v9" data-v="9" data-xref="ローマ人への手紙 10:20–12; マタイの福音書 21:43; ルカの福音書 19:27"> ところで、ぶどう園の主人は、どうするでしょう。彼は戻って来て、農夫どもを打ち滅ぼし、ぶどう園をほかの人たちに与えてしまいます。</span>
<span className="v" id="v10" data-v="10" data-xref="Psalms 118:22–23; ペテロの手紙第一 2:7–8; Isaiah 28:16"> あなたがたは、次の聖書のことばを読んだことがないのですか。 『家を建てる者たちの見捨てた石、 それが礎の石になった。</span>
<span className="v" id="v11" data-v="11" data-xref="Psalms 118:23; 使徒の働き 3:12–16; Habakkuk 1:5"> これは主のなさったことだ。 私たちの目には、 不思議なことである。』」</span>
<span className="v" id="v12" data-v="12" data-xref="マルコの福音書 11:18; マタイの福音書 22:22; ヨハネの福音書 7:44"> 彼らは、このたとえ話が、自分たちをさして語られたことに気づいたので、イエスを捕えようとしたが、やはり群衆を恐れた。それで、イエスを残して、立ち去った。</span>
<span className="v" id="v13" data-v="13" data-xref="ルカの福音書 20:20–26; ルカの福音書 11:54; マルコの福音書 3:6"> さて、彼らは、イエスに何か言わせて、わなに陥れようとして、パリサイ人とヘロデ党の者数人をイエスのところへ送った。</span>
<span className="v" id="v14" data-v="14" data-xref="テサロニケ人への手紙第一 2:4; ルカの福音書 20:22; ヨハネの福音書 7:18"> 彼らはイエスのところに来て、言った。「先生。私たちは、あなたが真実な方で、だれをもはばからない方だと存じています。あなたは人の顔色を見ず、真理に基づいて神の道を教えておられるからです。ところで、カイザルに税金を納めることは律法にかなっていることでしょうか、かなっていないことでしょうか。納めるべきでしょうか、納めるべきでないのでしょうか。」</span>
<span className="v" id="v15" data-v="15" data-xref="Ezekiel 17:2; ヨハネの黙示録 2:23; マルコの福音書 10:2"> イエスは彼らの擬装を見抜いて言われた。「なぜ、わたしをためすのか。デナリ銀貨を持って来て見せなさい。」</span>
<span className="v" id="v16" data-v="16" data-xref="ルカの福音書 20:24–26; ヨハネの黙示録 3:12; マタイの福音書 22:19–22"> 彼らは持って来た。そこでイエスは彼らに言われた。「これはだれの肖像ですか。だれの銘ですか。」彼らは、「カイザルのです。」と言った。</span>
<span className="v" id="v17" data-v="17" data-xref="ローマ人への手紙 13:7; ペテロの手紙第一 2:17; コリント人への手紙第二 5:14–15"> するとイエスは言われた。「カイザルのものはカイザルに返しなさい。そして神のものは神に返しなさい。」彼らはイエスに驚嘆した。</span>
<span className="v" id="v18" data-v="18" data-xref="マタイの福音書 22:23–33; 使徒の働き 4:1–2; 使徒の働き 23:6–9"> また、復活はないと主張していたサドカイ人たちが、イエスのところに来て、質問した。</span>
<span className="v" id="v19" data-v="19" data-xref="Deuteronomy 25:5–10; Ruth 4:5; Ruth 1:11–13"> 「先生。モーセは私たちのためにこう書いています。『もし、兄が死んで妻をあとに残し、しかも子がないばあいには、その弟はその女を妻にして、兄のための子をもうけなければならない。』</span>
<span className="v" id="v20" data-v="20" data-xref="マタイの福音書 22:25–28; ルカの福音書 20:29–33"> さて、七人の兄弟がいました。長男が妻をめとりましたが、子を残さないで死にました。</span>
<span className="v" id="v21" data-v="21"> そこで次男がその女を妻にしたところ、やはり子を残さずに死にました。三男も同様でした。</span>
<span className="v" id="v22" data-v="22"> こうして、七人とも子を残しませんでした。最後に、女も死にました。</span>
<span className="v" id="v23" data-v="23"> 復活の際、彼らがよみがえるとき、その女はだれの妻なのでしょうか。七人ともその女を妻にしたのですが。」</span>
<span className="v" id="v24" data-v="24" data-xref="ヨハネの福音書 20:9; テモテへの手紙第二 3:15–17; マタイの福音書 22:29"> イエスは彼らに言われた。「そんな思い違いをしているのは、聖書も神の力も知らないからではありませんか。</span>
<span className="v" id="v25" data-v="25" data-xref="ルカの福音書 20:35–36; マタイの福音書 22:30; ヨハネの手紙第一 3:2"> 人が死人の中からよみがえるときには、めとることも、とつぐこともなく、天の御使いたちのようです。</span>
<span className="v" id="v26" data-v="26" data-xref="Exodus 3:2–6; ルカの福音書 20:37; Genesis 17:7–8"> それに、死人がよみがえることについては、モーセの書にある柴の個所で、神がモーセにどう語られたか、あなたがたは読んだことがないのですか。『わたしは、アブラハムの神、イサクの神、ヤコブの神である。』とあります。</span>
<span className="v" id="v27" data-v="27" data-xref="ローマ人への手紙 14:9; ローマ人への手紙 4:17; マルコの福音書 12:24"> 神は死んだ者の神ではありません。生きている者の神です。あなたがたはたいへんな思い違いをしています。」</span>
<span className="v" id="v28" data-v="28" data-xref="マタイの福音書 22:34–40; ルカの福音書 10:25–28; ルカの福音書 20:39"> 律法学者がひとり来て、その議論を聞いていたが、イエスがみごとに答えられたのを知って、イエスに尋ねた。「すべての命令の中で、どれが一番たいせつですか。」</span>
<span className="v" id="v29" data-v="29" data-xref="Deuteronomy 6:4; ルカの福音書 10:27; ガラテヤ人への手紙 3:20"> イエスは答えられた。「一番たいせつなのはこれです。『イスラエルよ。聞け。われらの神である主は、唯一の主である。</span>
<span className="v" id="v30" data-v="30" data-xref="Deuteronomy 6:5"> 心を尽くし、思いを尽くし、知性を尽くし、力を尽くして、あなたの神である主を愛せよ。』</span>
<span className="v" id="v31" data-v="31" data-xref="ローマ人への手紙 13:8–9; マタイの福音書 22:39; Leviticus 19:18"> 次にはこれです。『あなたの隣人をあなた自身のように愛せよ。』この二つより大事な命令は、ほかにありません。」</span>
<span className="v" id="v32" data-v="32" data-xref="Deuteronomy 4:39; Deuteronomy 4:35; Isaiah 46:9"> そこで、この律法学者は、イエスに言った。「先生。そのとおりです。『主は唯一であって、そのほかに、主はない。』と言われたのは、まさにそのとおりです。</span>
<span className="v" id="v33" data-v="33" data-xref="Hosea 6:6; Micah 6:6–8; 1 Samuel 15:22"> また『心を尽くし、知恵を尽くし、力を尽くして主を愛し、また隣人をあなた自身のように愛する。』ことは、どんな全焼のいけにえや供え物よりも、ずっとすぐれています。」</span>
<span className="v" id="v34" data-v="34" data-xref="コロサイ人への手紙 4:6; ルカの福音書 20:40; マタイの福音書 22:46"> イエスは、彼が賢い返事をしたのを見て、言われた。「あなたは神の国から遠くない。」それから後は、だれもイエスにあえて尋ねる者がなかった。</span>
<span className="v" id="v35" data-v="35" data-xref="ルカの福音書 20:41–44; マタイの福音書 22:41–45; マタイの福音書 26:55"> イエスが宮で教えておられたとき、こう言われた。「律法学者たちは、どうしてキリストをダビデの子と言うのですか。</span>
<span className="v" id="v36" data-v="36" data-xref="Psalms 110:1; ヘブル人への手紙 1:13; マタイの福音書 22:43–45"> ダビデ自身、聖霊によって、こう言っています。 『主は私の主に言われた。 「わたしがあなたの敵を あなたの足の下に従わせるまでは、 わたしの右の座に着いていなさい。」』</span>
<span className="v" id="v37" data-v="37" data-xref="ローマ人への手紙 1:3–4; マタイの福音書 11:25; マタイの福音書 1:23"> ダビデ自身がキリストを主と呼んでいるのに、どういうわけでキリストがダビデの子なのでしょう。」大ぜいの群衆は、イエスの言われることを喜んで聞いていた。</span>
<span className="v" id="v38" data-v="38" data-xref="マタイの福音書 23:1–7; ルカの福音書 20:45–47; ルカの福音書 11:43"> イエスはその教えの中でこう言われた。「律法学者たちには気をつけなさい。彼らは、長い衣をまとって歩き回ったり、広場であいさつされたりすることが大好きで、</span>
<span className="v" id="v39" data-v="39" data-xref="ヤコブの手紙 2:2–3"> また会堂の上席や、宴会の上座が大好きです。</span>
<span className="v" id="v40" data-v="40" data-xref="マタイの福音書 23:13; ルカの福音書 20:47; マタイの福音書 23:33"> また、やもめの家を食いつぶし、見えを飾るために長い祈りをします。こういう人たちは人一倍きびしい罰を受けるのです。」</span>
<span className="v" id="v41" data-v="41" data-xref="ルカの福音書 21:1–4; 2 Kings 12:9; ヨハネの福音書 8:20"> それから、イエスは献金箱に向かってすわり、人々が献金箱へ金を投げ入れる様子を見ておられた。多くの金持ちが大金を投げ入れていた。</span>
<span className="v" id="v42" data-v="42"> そこへひとりの貧しいやもめが来て、レプタ銅貨を二つ投げ入れた。それは一コドラントに当たる。</span>
<span className="v" id="v43" data-v="43" data-xref="コリント人への手紙第二 9:6–8; コリント人への手紙第二 8:2; 使徒の働き 11:29"> すると、イエスは弟子たちを呼び寄せて、こう言われた。「まことに、あなたがたに告げます。この貧しいやもめは、献金箱に投げ入れていたどの人よりもたくさん投げ入れました。</span>
<span className="v" id="v44" data-v="44" data-xref="コリント人への手紙第二 8:2–3; ヨハネの手紙第一 3:17; Ezra 2:68–69"> みなは、あり余る中から投げ入れたのに、この女は、乏しい中から、あるだけを全部、生活費の全部を投げ入れたからです。」</span>

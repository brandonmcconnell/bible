<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ルカの福音書 9:27; ヘブル人への手紙 2:9; ルカの福音書 22:30"> イエスは彼らに言われた。「まことに、あなたがたに告げます。ここに立っている人々の中には、神の国が力をもって到来しているのを見るまでは、決して死を味わわない者がいます。」</span>
<span className="v" id="v2" data-v="2" data-xref="ルカの福音書 9:28–36; Isaiah 33:17; マタイの福音書 17:1–8"> それから六日たって、イエスは、ペテロとヤコブとヨハネだけを連れて、高い山に導いて行かれた。そして彼らの目の前で御姿が変わった。</span>
<span className="v" id="v3" data-v="3" data-xref="マタイの福音書 28:3; Daniel 7:9; ヨハネの黙示録 7:14"> その御衣は、非常に白く光り、世のさらし屋では、とてもできないほどの白さであった。</span>
<span className="v" id="v4" data-v="4" data-xref="ルカの福音書 9:30–31; マタイの福音書 17:3–4; 使徒の働き 3:21–24"> また、エリヤが、モーセとともに現われ、彼らはイエスと語り合っていた。</span>
<span className="v" id="v5" data-v="5" data-xref="ピリピ人への手紙 1:23; ヨハネの福音書 14:8–9; ヨハネの黙示録 22:3–4"> すると、ペテロが口出ししてイエスに言った。「先生。私たちがここにいることは、すばらしいことです。私たちが、幕屋を三つ造ります。あなたのために一つ、モーセのために一つ、エリヤのために一つ。」</span>
<span className="v" id="v6" data-v="6" data-xref="ヨハネの黙示録 1:17; Daniel 10:15–19; マルコの福音書 16:5–8"> 実のところ、ペテロは言うべきことがわからなかったのである。彼らは恐怖に打たれたのであった。</span>
<span className="v" id="v7" data-v="7" data-xref="ペテロの手紙第二 1:17; マタイの福音書 3:17; マルコの福音書 1:11"> そのとき雲がわき起こってその人々をおおい、雲の中から、「これは、わたしの愛する子である。彼の言うことを聞きなさい。」という声がした。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒の働き 10:16; 使徒の働き 8:39–40; ルカの福音書 24:31"> 彼らが急いであたりを見回すと、自分たちといっしょにいるのはイエスだけで、そこにはもはやだれも見えなかった。</span>
<span className="v" id="v9" data-v="9" data-xref="マタイの福音書 12:40; マタイの福音書 17:9–13; マルコの福音書 5:43"> さて、山を降りながら、イエスは彼らに、人の子が死人の中からよみがえるときまでは、いま見たことをだれにも話してはならない、と特に命じられた。</span>
<span className="v" id="v10" data-v="10" data-xref="使徒の働き 17:18; ルカの福音書 24:7–8; ルカの福音書 18:33–34"> そこで彼らは、そのおことばを心に堅く留め、死人の中からよみがえると言われたことはどういう意味かを論じ合った。</span>
<span className="v" id="v11" data-v="11" data-xref="Malachi 4:5; Malachi 3:1; マタイの福音書 11:14"> 彼らはイエスに尋ねて言った。「律法学者たちは、まずエリヤが来るはずだと言っていますが、それはなぜでしょうか。」</span>
<span className="v" id="v12" data-v="12" data-xref="Isaiah 53:1–12; Isaiah 50:6; Isaiah 52:14"> イエスは言われた。「エリヤがまず来て、すべてのことを立て直します。では、人の子について、多くの苦しみを受け、さげすまれると書いてあるのは、どうしてなのですか。</span>
<span className="v" id="v13" data-v="13" data-xref="マタイの福音書 14:3–11; マタイの福音書 17:12–13; マタイの福音書 11:14"> しかし、あなたがたに告げます。エリヤはもう来たのです。そして人々は、彼について書いてあるとおりに、好き勝手なことを彼にしたのです。」</span>
<span className="v" id="v14" data-v="14" data-xref="ルカの福音書 9:37–42; マタイの福音書 17:14–20; ルカの福音書 11:53–54"> さて、彼らが、弟子たちのところに帰って来て、見ると、その回りに大ぜいの人の群れがおり、また、律法学者たちが弟子たちと論じ合っていた。</span>
<span className="v" id="v15" data-v="15" data-xref="Exodus 34:30; マルコの福音書 9:2–3"> そしてすぐ、群衆はみな、イエスを見ると驚き、走り寄って来て、あいさつをした。</span>
<span className="v" id="v16" data-v="16" data-xref="ルカの福音書 5:30–32; マルコの福音書 8:11"> イエスは彼らに、「あなたがたは弟子たちと何を議論しているのですか。」と聞かれた。</span>
<span className="v" id="v17" data-v="17" data-xref="マルコの福音書 9:25; ルカの福音書 11:14; ヨハネの福音書 4:47"> すると群衆のひとりが、イエスに答えて言った。「先生。おしの霊につかれた私の息子を、先生のところに連れてまいりました。</span>
<span className="v" id="v18" data-v="18" data-xref="マタイの福音書 17:19–20; マルコの福音書 11:23; マタイの福音書 17:16"> その霊が息子に取りつきますと、所かまわず彼を押し倒します。そして彼はあわを吹き、歯ぎしりして、からだをこわばらせてしまいます。それでお弟子たちに、霊を追い出してくださるようにお願いしたのですが、お弟子たちにはできませんでした。」</span>
<span className="v" id="v19" data-v="19" data-xref="Numbers 14:11; ヨハネの福音書 20:27; Numbers 14:27"> イエスは答えて言われた。「ああ、不信仰な世だ。いつまであなたがたといっしょにいなければならないのでしょう。いつまであなたがたにがまんしていなければならないのでしょう。その子をわたしのところに連れて来なさい。」</span>
<span className="v" id="v20" data-v="20" data-xref="マルコの福音書 1:26; ルカの福音書 4:35; ヨハネの福音書 8:44"> そこで、人々はイエスのところにその子を連れて来た。その子がイエスを見ると、霊はすぐに彼をひきつけさせたので、彼は地面に倒れ、あわを吹きながら、ころげ回った。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒の働き 9:33; 使徒の働き 4:22; マルコの福音書 5:25"> イエスはその子の父親に尋ねられた。「この子がこんなになってから、どのくらいになりますか。」父親は言った。「幼い時からです。</span>
<span className="v" id="v22" data-v="22" data-xref="マタイの福音書 15:22–28; マルコの福音書 5:19; マタイの福音書 20:34"> この霊は、彼を滅ぼそうとして、何度も火の中や水の中に投げ込みました。ただ、もし、おできになるものなら、私たちをあわれんで、お助けください。」</span>
<span className="v" id="v23" data-v="23" data-xref="ヨハネの福音書 11:40; ヘブル人への手紙 11:6; マルコの福音書 11:23"> するとイエスは言われた。「できるものなら、と言うのか。信じる者には、どんなことでもできるのです。」</span>
<span className="v" id="v24" data-v="24" data-xref="ルカの福音書 17:5; ヘブル人への手紙 12:2; エペソ人への手紙 2:8"> するとすぐに、その子の父は叫んで言った。「信じます。不信仰な私をお助けください。」</span>
<span className="v" id="v25" data-v="25" data-xref="使徒の働き 16:18; ルカの福音書 9:42; マルコの福音書 9:15"> イエスは、群衆が駆けつけるのをご覧になると、汚れた霊をしかって言われた。「おしとつんぼの霊。わたしが、おまえに命じる。この子から出て行きなさい。二度と、はいってはいけない。」</span>
<span className="v" id="v26" data-v="26" data-xref="マルコの福音書 9:20; マルコの福音書 1:26; マルコの福音書 9:18"> するとその霊は、叫び声をあげ、その子を激しくひきつけさせて、出て行った。するとその子が死人のようになったので、多くの人々は、「この子は死んでしまった。」と言った。</span>
<span className="v" id="v27" data-v="27" data-xref="マルコの福音書 1:31; 使徒の働き 3:7; マルコの福音書 1:41"> しかし、イエスは、彼の手を取って起こされた。するとその子は立ち上がった。</span>
<span className="v" id="v28" data-v="28" data-xref="マタイの福音書 17:19–20; マルコの福音書 7:17; マタイの福音書 15:15"> イエスが家にはいられると、弟子たちがそっとイエスに尋ねた。「どうしてでしょう。私たちには追い出せなかったのですが。」</span>
<span className="v" id="v29" data-v="29" data-xref="ヤコブの手紙 5:15; Daniel 9:3; マタイの福音書 17:20"> すると、イエスは言われた。「この種のものは、祈りによらなければ、何によっても追い出せるものではありません。」</span>
<span className="v" id="v30" data-v="30" data-xref="マタイの福音書 17:22–23; ルカの福音書 9:43–45; マルコの福音書 6:31–32"> さて、一行はそこを去って、ガリラヤを通って行った。イエスは、人に知られたくないと思われた。</span>
<span className="v" id="v31" data-v="31" data-xref="マタイの福音書 16:21; マルコの福音書 9:12; ルカの福音書 24:44–46"> それは、イエスは弟子たちを教えて、「人の子は人々の手に引き渡され、彼らはこれを殺す。しかし、殺されて、三日の後に、人の子はよみがえる。」と話しておられたからである。</span>
<span className="v" id="v32" data-v="32" data-xref="ルカの福音書 2:50; ルカの福音書 9:45; ルカの福音書 18:34"> しかし、弟子たちは、このみことばが理解できなかった。また、イエスに尋ねるのを恐れていた。</span>
<span className="v" id="v33" data-v="33" data-xref="マタイの福音書 18:1–5; ヘブル人への手紙 4:13; ルカの福音書 9:46–48"> カペナウムに着いた。イエスは、家にはいった後、弟子たちに質問された。「道で何を論じ合っていたのですか。」</span>
<span className="v" id="v34" data-v="34" data-xref="マルコの福音書 9:50; マタイの福音書 20:21–24; マタイの福音書 18:1–5"> 彼らは黙っていた。道々、だれが一番偉いかと論じ合っていたからである。</span>
<span className="v" id="v35" data-v="35" data-xref="マタイの福音書 20:25–28; マルコの福音書 10:42–45; ルカの福音書 22:26"> イエスはおすわりになり、十二弟子を呼んで、言われた。「だれでも人の先に立ちたいと思うなら、みなのしんがりとなり、みなに仕える者となりなさい。」</span>
<span className="v" id="v36" data-v="36" data-xref="マルコの福音書 10:16; マタイの福音書 19:14–15; マタイの福音書 18:2"> それから、イエスは、ひとりの子どもを連れて来て、彼らの真中に立たせ、腕に抱き寄せて、彼らに言われた。</span>
<span className="v" id="v37" data-v="37" data-xref="マタイの福音書 18:3–5; ルカの福音書 10:16; マタイの福音書 10:40–42"> 「だれでも、このような幼子たちのひとりを、わたしの名のゆえに受け入れるならば、わたしを受け入れるのです。また、だれでも、わたしを受け入れるならば、わたしを受け入れるのではなく、わたしを遣わされた方を受け入れるのです。」</span>
<span className="v" id="v38" data-v="38" data-xref="ルカの福音書 9:49–50; Numbers 11:26–29; ルカの福音書 11:19"> ヨハネがイエスに言った。「先生。先生の名を唱えて悪霊を追い出している者を見ましたが、私たちの仲間ではないので、やめさせました。」</span>
<span className="v" id="v39" data-v="39" data-xref="コリント人への手紙第一 12:3; コリント人への手紙第一 13:1–2; マタイの福音書 13:28–29"> しかし、イエスは言われた。「やめさせることはありません。わたしの名を唱えて、力あるわざを行ないながら、すぐあとで、わたしを悪く言える者はないのです。</span>
<span className="v" id="v40" data-v="40" data-xref="マタイの福音書 12:30; ルカの福音書 11:23"> わたしたちに反対しない者は、わたしたちの味方です。</span>
<span className="v" id="v41" data-v="41" data-xref="マタイの福音書 10:42; マタイの福音書 25:40; コリント人への手紙第一 15:23"> あなたがたがキリストの弟子だからというので、あなたがたに水一杯でも飲ませてくれる人は、決して報いを失うことはありません。これは確かなことです。</span>
<span className="v" id="v42" data-v="42" data-xref="マタイの福音書 18:6; ルカの福音書 17:1–2; マタイの福音書 18:10"> また、わたしを信じるこの小さい者たちのひとりにでもつまずきを与えるような者は、むしろ大きい石臼を首にゆわえつけられて、海に投げ込まれたほうがましです。</span>
<span className="v" id="v43" data-v="43" data-xref="マタイの福音書 5:29–30; マタイの福音書 18:8–9; マタイの福音書 25:41"> もし、あなたの手があなたのつまずきとなるなら、それを切り捨てなさい。不具の身でいのちにはいるほうが、両手そろっていてゲヘナの消えぬ火の中に落ち込むよりは、あなたにとってよいことです。</span>
<span className="v" id="v44" data-v="44"> もし、あなたの足があなたのつまずきとなるなら、それを切り捨てなさい。片足でいのちにはいるほうが、両足そろっていてゲヘナに投げ入れられるよりは、あなたにとってよいことです。</span>
<span className="v" id="v46" data-v="46"> もし、あなたの目があなたのつまずきを引き起こすのなら、それをえぐり出しなさい。片目で神の国にはいるほうが、両目そろっていてゲヘナに投げ入れられるよりは、あなたにとってよいことです。</span>
<span className="v" id="v48" data-v="48" data-xref="Isaiah 66:24; マルコの福音書 9:43–45; マタイの福音書 25:41"> そこでは、彼らを食ううじは、尽きることがなく、火は消えることがありません。</span>
<span className="v" id="v49" data-v="49" data-xref="Leviticus 2:13; Ezekiel 43:24"> すべては、火によって、塩けをつけられるのです。</span>
<span className="v" id="v50" data-v="50" data-xref="コロサイ人への手紙 4:6; ローマ人への手紙 12:18; マタイの福音書 5:13"> 塩は、ききめのあるものです。しかし、もし塩に塩けがなくなったら、何によって塩けを取り戻せましょう。あなたがたは、自分自身のうちに塩けを保ちなさい。そして、互いに和合して暮らしなさい。」</span>

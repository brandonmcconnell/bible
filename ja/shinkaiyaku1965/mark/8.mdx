<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マタイの福音書 15:32–39; マルコの福音書 6:34–44"> そのころ、また大ぜいの人の群れが集まっていたが、食べる物がなかったので、イエスは弟子たちを呼んで言われた。</span>
<span className="v" id="v2" data-v="2" data-xref="マタイの福音書 9:36; Micah 7:19; Psalms 103:13"> 「かわいそうに、この群衆はもう三日間もわたしといっしょにいて、食べる物を持っていないのです。</span>
<span className="v" id="v3" data-v="3" data-xref="Isaiah 40:31; Judges 8:4–6; 1 Samuel 30:10–12"> 空腹のまま家に帰らせたら、途中で動けなくなるでしょう。それに遠くから来ている人もいます。」</span>
<span className="v" id="v4" data-v="4" data-xref="2 Kings 4:42–44; 2 Kings 7:2; マルコの福音書 6:52"> 弟子たちは答えた。「こんなへんぴな所で、どこからパンを手に入れて、この人たちに十分食べさせることができましょう。」</span>
<span className="v" id="v5" data-v="5" data-xref="マタイの福音書 14:15–17; マタイの福音書 15:34; ルカの福音書 9:13"> すると、イエスは尋ねられた。「パンはどれぐらいありますか。」弟子たちは、「七つです。」と答えた。</span>
<span className="v" id="v6" data-v="6" data-xref="コロサイ人への手紙 3:17; マタイの福音書 15:35–36; ヨハネの福音書 6:10–11"> すると、イエスは群衆に、地面にすわるようにおっしゃった。それから、七つのパンを取り、感謝をささげてからそれを裂き、人々に配るように弟子たちに与えられたので、弟子たちは群衆に配った。</span>
<span className="v" id="v7" data-v="7" data-xref="マタイの福音書 14:19; ヨハネの福音書 21:5; ルカの福音書 24:41–42"> また、魚が少しばかりあったので、そのために感謝をささげてから、これも配るように言われた。</span>
<span className="v" id="v8" data-v="8" data-xref="2 Kings 4:42–44; Psalms 145:16; マタイの福音書 16:10"> 人々は食べて満腹した。そして余りのパン切れを七つのかごに取り集めた。</span>
<span className="v" id="v9" data-v="9"> 人々はおよそ四千人であった。それからイエスは、彼らを解散させられた。</span>
<span className="v" id="v10" data-v="10" data-xref="マタイの福音書 15:39"> そしてすぐに弟子たちとともに舟に乗り、ダルマヌタ地方へ行かれた。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="コリント人への手紙第一 10:9; マタイの福音書 12:38; Deuteronomy 6:16"> パリサイ人たちがやって来て、イエスに議論をしかけ、天からのしるしを求めた。イエスをためそうとしたのである。</span>
<span className="v" id="v12" data-v="12" data-xref="マタイの福音書 12:39–40; マルコの福音書 7:34; マタイの福音書 16:4"> イエスは、心の中で深く嘆息して、こう言われた。「なぜ、今の時代はしるしを求めるのか。まことに、あなたがたに告げます。今の時代には、しるしは絶対に与えられません。」</span>
<span className="v" id="v13" data-v="13" data-xref="ヨハネの福音書 12:36; 使徒の働き 13:45–46; Psalms 81:12"> イエスは彼らを離れて、また舟に乗って向こう岸へ行かれた。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="マタイの福音書 16:5"> 弟子たちは、パンを持って来るのを忘れ、舟の中には、パンがただ一つしかなかった。</span>
<span className="v" id="v15" data-v="15" data-xref="コリント人への手紙第一 5:6–8; マタイの福音書 16:6; マタイの福音書 16:11–12"> そのとき、イエスは彼らに命じて言われた。「パリサイ人のパン種とヘロデのパン種とに十分気をつけなさい。」</span>
<span className="v" id="v16" data-v="16" data-xref="ルカの福音書 9:46; ルカの福音書 20:5; マタイの福音書 16:7–8"> そこで弟子たちは、パンを持っていないということで、互いに議論し始めた。</span>
<span className="v" id="v17" data-v="17" data-xref="マルコの福音書 6:52; Isaiah 63:17; マルコの福音書 2:8"> それに気づいてイエスは言われた。「なぜ、パンがないといって議論しているのですか。まだわからないのですか、悟らないのですか。心が堅く閉じているのですか。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒の働き 28:26–27; マタイの福音書 13:14–15; Jeremiah 5:21"> 目がありながら見えないのですか。耳がありながら聞こえないのですか。あなたがたは、覚えていないのですか。</span>
<span className="v" id="v19" data-v="19" data-xref="ルカの福音書 9:12–17; マタイの福音書 14:17–21; ヨハネの福音書 6:5–13"> わたしが五千人に五つのパンを裂いて上げたとき、パン切れを取り集めて、幾つのかごがいっぱいになりましたか。」彼らは答えた。「十二です。」</span>
<span className="v" id="v20" data-v="20" data-xref="マタイの福音書 15:34–38; マルコの福音書 8:1–9"> 「四千人に七つのパンを裂いて上げたときは、パン切れを取り集めて幾つのかごがいっぱいになりましたか。」彼らは答えた。「七つです。」</span>
<span className="v" id="v21" data-v="21" data-xref="マルコの福音書 6:52; マタイの福音書 16:11–12; マルコの福音書 8:12"> イエスは言われた。「まだ悟らないのですか。」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="マタイの福音書 11:21; マルコの福音書 6:45; ルカの福音書 10:13"> 彼らはベツサイダに着いた。すると人々が、盲人を連れて来て、さわってやってくださるようにイエスに願った。</span>
<span className="v" id="v23" data-v="23" data-xref="マルコの福音書 7:33; ヨハネの福音書 9:6–7; マルコの福音書 5:23"> イエスは盲人の手を取って村の外に連れて行かれた。そしてその両眼につばきをつけ、両手を彼に当ててやって、「何か見えるか。」と聞かれた。</span>
<span className="v" id="v24" data-v="24" data-xref="Isaiah 32:3; Isaiah 29:18; コリント人への手紙第一 13:9–12"> すると彼は、見えるようになって、「人が見えます。木のようですが、歩いているのが見えます。」と言った。</span>
<span className="v" id="v25" data-v="25" data-xref="ペテロの手紙第一 2:9; ペテロの手紙第二 3:18; Proverbs 4:18"> それから、イエスはもう一度彼の両眼に両手を当てられた。そして、彼が見つめていると、すっかり直り、すべてのものがはっきり見えるようになった。</span>
<span className="v" id="v26" data-v="26" data-xref="マタイの福音書 8:4; マルコの福音書 8:23; マルコの福音書 5:43"> そこでイエスは、彼を家に帰し、「村にはいって行かないように。」と言われた。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="マタイの福音書 16:13–20; ルカの福音書 9:18–20"> それから、イエスは弟子たちとピリポ・カイザリヤの村々へ出かけられた。その途中、イエスは弟子たちに尋ねて言われた。「人々はわたしをだれだと言っていますか。」</span>
<span className="v" id="v28" data-v="28" data-xref="ヨハネの福音書 1:21; マタイの福音書 14:2; Malachi 4:5"> 彼らは答えて言った。「バプテスマのヨハネだと言っています。エリヤだと言う人も、また預言者のひとりだと言う人もいます。」</span>
<span className="v" id="v29" data-v="29" data-xref="ヨハネの手紙第一 4:15; マタイの福音書 16:15–16; ヨハネの手紙第一 5:1"> するとイエスは、彼らに尋ねられた。「では、あなたがたは、わたしをだれだと言いますか。」ペテロが答えてイエスに言った。「あなたは、キリストです。」</span>
<span className="v" id="v30" data-v="30" data-xref="ルカの福音書 9:21; マタイの福音書 16:20; マルコの福音書 9:9"> するとイエスは、自分のことをだれにも言わないようにと、彼らを戒められた。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="マルコの福音書 10:33–34; ヨハネの福音書 2:19; ルカの福音書 24:26"> それから、人の子は必ず多くの苦しみを受け、長老、祭司長、律法学者たちに捨てられ、殺され、三日の後によみがえらなければならないと、弟子たちに教え始められた。</span>
<span className="v" id="v32" data-v="32" data-xref="マタイの福音書 16:22; ヨハネの福音書 16:25; ヨハネの福音書 16:29"> しかも、はっきりとこの事がらを話された。するとペテロは、イエスをわきにお連れして、いさめ始めた。</span>
<span className="v" id="v33" data-v="33" data-xref="マタイの福音書 4:10; ピリピ人への手紙 3:19; ヨハネの手紙第一 2:15"> しかし、イエスは振り向いて、弟子たちを見ながら、ペテロをしかって言われた。「下がれ。サタン。あなたは神のことを思わないで、人のことを思っている。」</span>
<span className="v" id="v34" data-v="34" data-xref="マタイの福音書 10:38; ルカの福音書 14:26–27; ヨハネの福音書 10:27"> それから、イエスは群衆を弟子たちといっしょに呼び寄せて、彼らに言われた。「だれでもわたしについて来たいと思うなら、自分を捨て、自分の十字架を負い、そしてわたしについて来なさい。</span>
<span className="v" id="v35" data-v="35" data-xref="テモテへの手紙第二 2:11–13; コリント人への手紙第一 9:23; ルカの福音書 17:33"> いのちを救おうと思う者はそれを失い、わたしと福音とのためにいのちを失う者はそれを救うのです。</span>
<span className="v" id="v36" data-v="36" data-xref="マタイの福音書 16:26; ルカの福音書 9:25; Psalms 49:17"> 人は、たとい全世界を得ても、いのちを損じたら、何の得がありましょう。</span>
<span className="v" id="v37" data-v="37" data-xref="Psalms 49:7–8; ペテロの手紙第一 1:18–19"> 自分のいのちを買い戻すために、人はいったい何を差し出すことができるでしょう。</span>
<span className="v" id="v38" data-v="38" data-xref="ルカの福音書 12:8–9; ローマ人への手紙 1:16; ヨハネの手紙第一 2:23"> このような姦淫と罪の時代にあって、わたしとわたしのことばを恥じるような者なら、人の子も、父の栄光を帯びて聖なる御使いたちとともに来るときには、そのような人のことを恥じます。」</span>
</div>

<span className="v" id="v1" data-v="1" data-xref="テサロニケ人への手紙第一 5:21; ペテロの手紙第二 2:1; テモテへの手紙第一 4:1"> 愛する者たち。霊だからといって、みな信じてはいけません。それらの霊が神からのものかどうかを、ためしなさい。なぜなら、にせ預言者がたくさん世に出て来たからです。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネの福音書 1:14; コリント人への手紙第一 12:3; テモテへの手紙第一 3:16"> 人となって来たイエス・キリストを告白する霊はみな、神からのものです。それによって神からの霊を知りなさい。</span>
<span className="v" id="v3" data-v="3" data-xref="ヨハネの手紙第一 2:22; ヨハネの手紙第二 1:7; ヨハネの手紙第一 2:18"> イエスを告白しない霊はどれ一つとして神から出たものではありません。それは反キリストの霊です。あなたがたはそれが来ることを聞いていたのですが、今それが世に来ているのです。</span>
<span className="v" id="v4" data-v="4" data-xref="ローマ人への手紙 8:31; ヨハネの手紙第一 5:4; ローマ人への手紙 8:37"> 子どもたちよ。あなたがたは神から出た者です。そして彼らに勝ったのです。あなたがたのうちにおられる方が、この世のうちにいる、あの者よりも力があるからです。</span>
<span className="v" id="v5" data-v="5" data-xref="ヨハネの福音書 8:23; ペテロの手紙第二 2:2–3; ヨハネの福音書 17:14"> 彼らはこの世の者です。ですから、この世のことばを語り、この世もまた彼らの言うことに耳を傾けます。</span>
<span className="v" id="v6" data-v="6" data-xref="ヨハネの福音書 14:17; ヨハネの福音書 10:27; コリント人への手紙第一 2:12–14"> 私たちは神から出た者です。神を知っている者は、私たちの言うことに耳を傾け、神から出ていない者は、私たちの言うことに耳を貸しません。私たちはこれで真理の霊と偽りの霊とを見分けます。</span>
<span className="v" id="v7" data-v="7" data-xref="ヨハネの手紙第一 4:20–1; ヨハネの手紙第一 4:8; ペテロの手紙第一 1:22"> 愛する者たち。私たちは、互いに愛し合いましょう。愛は神から出ているのです。愛のある者はみな神から生まれ、神を知っています。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨハネの手紙第一 4:16; Psalms 86:15; コリント人への手紙第二 13:11"> 愛のない者に、神はわかりません。なぜなら神は愛だからです。</span>
<span className="v" id="v9" data-v="9" data-xref="ヨハネの福音書 3:16; ヨハネの手紙第一 5:11; ローマ人への手紙 8:32"> 神はそのひとり子を世に遣わし、その方によって私たちに、いのちを得させてくださいました。ここに、神の愛が私たちに示されたのです。</span>
<span className="v" id="v10" data-v="10" data-xref="エペソ人への手紙 2:4–5; ローマ人への手紙 5:8–10; ヨハネの手紙第一 4:19"> 私たちが神を愛したのではなく、神が私たちを愛し、私たちの罪のために、なだめの供え物としての御子を遣わされました。ここに愛があるのです。</span>
<span className="v" id="v11" data-v="11" data-xref="ヨハネの福音書 15:12–13; コロサイ人への手紙 3:13; ヨハネの福音書 13:34"> 愛する者たち。神がこれほどまでに私たちを愛してくださったのなら、私たちもまた互いに愛し合うべきです。</span>
<span className="v" id="v12" data-v="12" data-xref="ヨハネの福音書 1:18; ヨハネの手紙第一 2:5; ヨハネの手紙第一 4:17–18"> いまだかつて、だれも神を見た者はありません。もし私たちが互いに愛し合うなら、神は私たちのうちにおられ、神の愛が私たちのうちに全うされるのです。</span>
<span className="v" id="v13" data-v="13" data-xref="エペソ人への手紙 2:20–22; ヨハネの手紙第一 3:24; コリント人への手紙第一 3:16–17"> 神は私たちに御霊を与えてくださいました。それによって、私たちが神のうちにおり、神も私たちのうちにおられることがわかります。</span>
<span className="v" id="v14" data-v="14" data-xref="ヨハネの手紙第一 4:10; ヨハネの福音書 3:16–17; ヨハネの福音書 4:42"> 私たちは、御父が御子を世の救い主として遣わされたのを見て、今そのあかしをしています。</span>
<span className="v" id="v15" data-v="15" data-xref="ローマ人への手紙 10:9; ヨハネの手紙第一 5:5; マタイの福音書 10:32"> だれでも、イエスを神の御子と告白するなら、神はその人のうちにおられ、その人も神のうちにいます。</span>
<span className="v" id="v16" data-v="16" data-xref="ヨハネの手紙第一 3:24; Psalms 36:7–9; ヨハネの手紙第一 3:1"> 私たちは、私たちに対する神の愛を知り、また信じています。神は愛です。愛のうちにいる者は神のうちにおり、神もその人のうちにおられます。</span>
<span className="v" id="v17" data-v="17" data-xref="ヨハネの手紙第一 4:12; ヨハネの手紙第一 2:28; ローマ人への手紙 8:29"> このことによって、愛が私たちにおいても完全なものとなりました。それは私たちが、さばきの日にも大胆さを持つことができるためです。なぜなら、私たちもこの世にあってキリストと同じような者であるからです。</span>
<span className="v" id="v18" data-v="18" data-xref="テモテへの手紙第二 1:7; ローマ人への手紙 8:15; ヨハネの手紙第一 4:12"> 愛には恐れがありません。全き愛は恐れを締め出します。なぜなら恐れには刑罰が伴っているからです。恐れる者の愛は、全きものとなっていないのです。</span>
<span className="v" id="v19" data-v="19" data-xref="ヨハネの手紙第一 4:10; ヨハネの福音書 3:16; ヨハネの福音書 15:16"> 私たちは愛しています。神がまず私たちを愛してくださったからです。</span>
<span className="v" id="v20" data-v="20" data-xref="ヨハネの手紙第一 3:17; ヨハネの手紙第一 2:9; ヨハネの手紙第一 4:12"> 神を愛すると言いながら兄弟を憎んでいるなら、その人は偽り者です。目に見える兄弟を愛していない者に、目に見えない神を愛することはできません。</span>
<span className="v" id="v21" data-v="21" data-xref="マタイの福音書 22:37–39; Leviticus 19:18; ヨハネの手紙第一 3:11"> 神を愛する者は、兄弟をも愛すべきです。私たちはこの命令をキリストから受けています。</span>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨハネの福音書 1:12–13; ヨハネの福音書 8:42; ヨハネの手紙第一 2:29"> イエスがキリストであると信じる者はだれでも、神によって生まれたのです。生んでくださった方を愛する者はだれでも、その方によって生まれた者をも愛します。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネの福音書 13:34–35; ヨハネの手紙第一 2:5; ヨハネの手紙第一 3:22–24"> 私たちが神を愛してその命令を守るなら、そのことによって、私たちが神の子どもたちを愛していることがわかります。</span>
<span className="v" id="v3" data-v="3" data-xref="ヨハネの福音書 14:15; ヨハネの福音書 15:10; ヨハネの福音書 14:21–24"> 神を愛するとは、神の命令を守ることです。その命令は重荷とはなりません。</span>
<span className="v" id="v4" data-v="4" data-xref="コリント人への手紙第一 15:57; ヨハネの手紙第一 4:4; ヨハネの福音書 16:33"> なぜなら、神によって生まれた者はみな、世に勝つからです。私たちの信仰、これこそ、世に打ち勝った勝利です。</span>
<span className="v" id="v5" data-v="5" data-xref="ヨハネの手紙第一 4:15; ヨハネの手紙第一 5:1"> 世に勝つ者とはだれでしょう。イエスを神の御子と信じる者ではありませんか。</span>
<span className="v" id="v6" data-v="6" data-xref="ヨハネの福音書 15:26; ヘブル人への手紙 9:14; ヨハネの福音書 16:13"> このイエス・キリストは、水と血とによって来られた方です。ただ水によってだけでなく、水と血とによって来られたのです。そして、あかしをする方は御霊です。御霊は真理だからです。</span>
<span className="v" id="v7" data-v="7" data-xref="マタイの福音書 28:19; コリント人への手紙第二 13:14; 使徒の働き 5:32"> あかしするものが三つあります。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨハネの手紙第一 5:6–7; ヨハネの福音書 15:26; ペテロの手紙第一 3:21"> 御霊と水と血です。この三つが一つとなるのです。</span>
<span className="v" id="v9" data-v="9" data-xref="マタイの福音書 3:16–17; マタイの福音書 17:5; 使徒の働き 17:31"> もし、私たちが人間のあかしを受け入れるなら、神のあかしはそれにまさるものです。御子についてあかしされたことが神のあかしだからです。</span>
<span className="v" id="v10" data-v="10" data-xref="ローマ人への手紙 8:16; ガラテヤ人への手紙 4:6; ヨハネの福音書 3:33"> 神の御子を信じる者は、このあかしを自分の心の中に持っています。神を信じない者は、神を偽り者とするのです。神が御子についてあかしされたことを信じないからです。</span>
<span className="v" id="v11" data-v="11" data-xref="ローマ人への手紙 6:23; ヨハネの手紙第一 2:25; ヨハネの福音書 3:36"> そのあかしとは、神が私たちに永遠のいのちを与えられたということ、そしてこのいのちが御子のうちにあるということです。</span>
<span className="v" id="v12" data-v="12" data-xref="ヨハネの福音書 3:36; ヨハネの福音書 5:24; ヨハネの福音書 1:12"> 御子を持つ者はいのちを持っており、神の御子を持たない者はいのちを持っていません。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="ヨハネの福音書 20:31; ヨハネの福音書 1:12; ペテロの手紙第二 1:10–11"> 私が神の御子の名を信じているあなたがたに対してこれらのことを書いたのは、あなたがたが永遠のいのちを持っていることを、あなたがたによくわからせるためです。</span>
<span className="v" id="v14" data-v="14" data-xref="ヨハネの福音書 14:13; Jeremiah 33:3; Jeremiah 29:12–13"> 何事でも神のみこころにかなう願いをするなら、神はその願いを聞いてくださるということ、これこそ神に対する私たちの確信です。</span>
<span className="v" id="v15" data-v="15" data-xref="ルカの福音書 11:9–10; マルコの福音書 11:24; Proverbs 15:29"> 私たちの願う事を神が聞いてくださると知れば、神に願ったその事は、すでにかなえられたと知るのです。</span>
<span className="v" id="v16" data-v="16" data-xref="ヘブル人への手紙 6:4–6; 1 Samuel 2:25; Jeremiah 11:14"> だれでも兄弟が死に至らない罪を犯しているのを見たなら、神に求めなさい。そうすれば神はその人のために、死に至らない罪を犯している人々に、いのちをお与えになります。死に至る罪があります。この罪については、願うようにとは言いません。</span>
<span className="v" id="v17" data-v="17" data-xref="ヨハネの手紙第一 3:4; ヨハネの手紙第一 5:16; ヤコブの手紙 4:7–10"> 不正はみな罪ですが、死に至らない罪があります。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="ヨハネの手紙第一 3:9; ヨハネの手紙第一 5:4; ヨハネの手紙第一 5:1"> 神によって生まれた者はだれも罪の中に生きないことを、私たちは知っています。神から生まれた方が彼を守っていてくださるので、悪い者は彼に触れることができないのです。</span>
<span className="v" id="v19" data-v="19" data-xref="コリント人への手紙第二 4:4; ヨハネの手紙第一 4:4–6; エペソ人への手紙 2:2"> 私たちは神からの者であり、全世界は悪い者の支配下にあることを知っています。</span>
<span className="v" id="v20" data-v="20" data-xref="ヨハネの福音書 17:3; ルカの福音書 24:45; ヨハネの福音書 14:9"> しかし、神の御子が来て、真実な方を知る理解力を私たちに与えてくださったことを知っています。それで私たちは、真実な方のうちに、すなわち御子イエス・キリストのうちにいるのです。この方こそ、まことの神、永遠のいのちです。</span>
<span className="v" id="v21" data-v="21" data-xref="コリント人への手紙第一 10:14; コリント人への手紙第一 10:7; Exodus 20:3–4"> 子どもたちよ。偶像を警戒しなさい。</span>
</div>

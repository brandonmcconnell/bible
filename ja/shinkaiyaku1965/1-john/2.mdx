<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="テモテへの手紙第一 2:5; ローマ人への手紙 8:34; ヨハネの福音書 14:6"> 私の子どもたち。私がこれらのことを書き送るのは、あなたがたが罪を犯さないようになるためです。もしだれかが罪を犯したなら、私たちには、御父の御前で弁護してくださる方があります。それは、義なるイエス・キリストです。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネの手紙第一 4:14; ペテロの手紙第一 3:18; ヨハネの手紙第一 4:10"> この方こそ、私たちの罪のための、――私たちの罪だけでなく全世界のための、――なだめの供え物なのです。</span>
<span className="v" id="v3" data-v="3" data-xref="ヨハネの福音書 14:15; ヨハネの福音書 15:10; ルカの福音書 6:46"> もし、私たちが神の命令を守るなら、それによって、私たちは神を知っていることがわかります。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネの手紙第一 1:6; テトスへの手紙 1:16; ヤコブの手紙 2:14–16"> 神を知っていると言いながら、その命令を守らない者は、偽り者であり、真理はその人のうちにありません。</span>
<span className="v" id="v5" data-v="5" data-xref="ヨハネの福音書 14:23; ヨハネの福音書 14:21; ヨハネの手紙第一 4:12–13"> しかし、みことばを守っている者なら、その人のうちには、確かに神の愛が全うされているのです。それによって、私たちが神のうちにいることがわかります。</span>
<span className="v" id="v6" data-v="6" data-xref="ペテロの手紙第一 2:21; ヨハネの福音書 13:15; コリント人への手紙第一 11:1"> 神のうちにとどまっていると言う者は、自分でもキリストが歩まれたように歩まなければなりません。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="ヨハネの手紙第一 3:11; Leviticus 19:18; マルコの福音書 12:29–34"> 愛する者たち。私はあなたがたに新しい命令を書いているのではありません。むしろ、これはあなたがたが初めから持っていた古い命令です。その古い命令とは、あなたがたがすでに聞いている、みことばのことです。</span>
<span className="v" id="v8" data-v="8" data-xref="エペソ人への手紙 5:8; ローマ人への手紙 13:12; ヨハネの福音書 13:34"> しかし、私は新しい命令としてあなたがたに書き送ります。これはキリストにおいて真理であり、あなたがたにとっても真理です。なぜなら、やみが消え去り、まことの光がすでに輝いているからです。</span>
<span className="v" id="v9" data-v="9" data-xref="ヨハネの手紙第一 4:20; ヨハネの手紙第一 2:11; ヨハネの手紙第一 3:13–17"> 光の中にいると言いながら、兄弟を憎んでいる者は、今もなお、やみの中にいるのです。</span>
<span className="v" id="v10" data-v="10" data-xref="ヨハネの手紙第一 3:14; ローマ人への手紙 9:32–33; ローマ人への手紙 14:13"> 兄弟を愛する者は、光の中にとどまり、つまずくことがありません。</span>
<span className="v" id="v11" data-v="11" data-xref="ヨハネの福音書 12:35; テトスへの手紙 3:3; ヨハネの手紙第一 1:6"> 兄弟を憎む者は、やみの中におり、やみの中を歩んでいるのであって、自分がどこへ行くのか知らないのです。やみが彼の目を見えなくしたからです。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="使徒の働き 10:43; 使徒の働き 13:38; エペソ人への手紙 1:7"> 子どもたちよ。私があなたがたに書き送るのは、主の御名によって、あなたがたの罪が赦されたからです。</span>
<span className="v" id="v13" data-v="13" data-xref="ヨハネの福音書 14:7; ヨハネの手紙第一 2:14; ルカの福音書 10:22"> 父たちよ。私があなたがたに書き送るのは、あなたがたが、初めからおられる方を、知ったからです。若い者たちよ。私があなたがたに書き送るのは、あなたがたが悪い者に打ち勝ったからです。</span>
<span className="v" id="v14" data-v="14" data-xref="Psalms 119:11; ヨハネの手紙第一 2:13; コロサイ人への手紙 3:16"> 小さい者たちよ。私があなたがたに書いて来たのは、あなたがたが御父を知ったからです。父たちよ。私があなたがたに書いて来たのは、あなたがたが、初めからおられる方を、知ったからです。若い者たちよ。私があなたがたに書いて来たのは、あなたがたが強い者であり、神のみことばが、あなたがたのうちにとどまり、そして、あなたがたが悪い者に打ち勝ったからです。</span>
<span className="v" id="v15" data-v="15" data-xref="ヤコブの手紙 4:4; ローマ人への手紙 12:2; マタイの福音書 6:24"> 世をも、世にあるものをも、愛してはなりません。もしだれでも世を愛しているなら、その人のうちに御父を愛する愛はありません。</span>
<span className="v" id="v16" data-v="16" data-xref="ローマ人への手紙 13:14; ガラテヤ人への手紙 5:17; Psalms 119:36–37"> すべての世にあるもの、すなわち、肉の欲、目の欲、暮らし向きの自慢などは、御父から出たものではなく、この世から出たものだからです。</span>
<span className="v" id="v17" data-v="17" data-xref="マタイの福音書 24:35; ローマ人への手紙 12:2; コリント人への手紙第一 7:31"> 世と世の欲は滅び去ります。しかし、神のみこころを行なう者は、いつまでもながらえます。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="ヨハネの手紙第一 4:3; ヨハネの手紙第二 1:7; マタイの福音書 24:24"> 小さい者たちよ。今は終わりの時です。あなたがたが反キリストの来ることを聞いていたとおり、今や多くの反キリストが現われています。それによって、今が終わりの時であることがわかります。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒の働き 20:30; コリント人への手紙第一 11:19; ルカの福音書 8:13"> 彼らは私たちの中から出て行きましたが、もともと私たちの仲間ではなかったのです。もし私たちの仲間であったのなら、私たちといっしょにとどまっていたことでしょう。しかし、そうなったのは、彼らがみな私たちの仲間でなかったことが明らかにされるためなのです。</span>
<span className="v" id="v20" data-v="20" data-xref="ヨハネの福音書 14:26; ヨハネの手紙第一 2:27; コリント人への手紙第二 1:21–22"> あなたがたには聖なる方からの注ぎの油があるので、だれでも知識を持っています。</span>
<span className="v" id="v21" data-v="21" data-xref="ペテロの手紙第二 1:12; ユダの手紙 1:5; Proverbs 1:5"> このように書いて来たのは、あなたがたが真理を知らないからではなく、真理を知っているからであり、また、偽りはすべて真理から出てはいないからです。</span>
<span className="v" id="v22" data-v="22" data-xref="ヨハネの手紙第二 1:7; ヨハネの手紙第一 4:3; ヨハネの手紙第一 2:18"> 偽り者とは、イエスがキリストであることを否定する者でなくてだれでしょう。御父と御子を否認する者、それが反キリストです。</span>
<span className="v" id="v23" data-v="23" data-xref="ヨハネの手紙第一 4:15; ヨハネの福音書 8:19; ヨハネの福音書 5:23"> だれでも御子を否認する者は、御父を持たず、御子を告白する者は、御父をも持っているのです。</span>
<span className="v" id="v24" data-v="24" data-xref="ヨハネの福音書 14:23; ヨハネの福音書 15:9–10; ヨハネの手紙第一 4:13"> あなたがたは、初めから聞いたことを、自分たちのうちにとどまらせなさい。もし初めから聞いたことがとどまっているなら、あなたがたも御子および御父のうちにとどまるのです。</span>
<span className="v" id="v25" data-v="25" data-xref="ヨハネの福音書 10:28; テトスへの手紙 3:7; ユダの手紙 1:21"> それがキリストご自身の私たちにお与えになった約束であって、永遠のいのちです。</span>
<span className="v" id="v26" data-v="26" data-xref="ペテロの手紙第二 2:1–3; ヨハネの手紙第二 1:7; 使徒の働き 20:29–30"> 私は、あなたがたを惑わそうとする人たちについて以上のことを書いて来ました。</span>
<span className="v" id="v27" data-v="27" data-xref="ヨハネの福音書 14:26; ヨハネの手紙第一 2:20–21; コリント人への手紙第一 2:13"> あなたがたのばあいは、キリストから受けた油注ぎをいつも自分たちのうちに持っているので、だれからも教えを受ける必要がありません。その油がすべてのことについてあなたがたを教えるように、――その教えは真理であって偽りではありません。――また、その油があなたがたに教えたとおりに、あなたがたはキリストのうちにとどまるのです。</span>
<span className="v" id="v28" data-v="28" data-xref="ヨハネの手紙第一 4:17; マルコの福音書 8:38; ヨハネの手紙第一 3:2"> そこで、子どもたちよ。キリストのうちにとどまっていなさい。それは、キリストが現われるとき、私たちが信頼を持ち、その来臨のときに、御前で恥じ入るということのないためです。</span>
<span className="v" id="v29" data-v="29" data-xref="ヨハネの福音書 3:3–5; ヨハネの手紙第一 3:7; ヨハネの手紙第一 5:1"> もしあなたがたが、神は正しい方であると知っているなら、義を行なう者がみな神から生まれたこともわかるはずです。</span>
</div>

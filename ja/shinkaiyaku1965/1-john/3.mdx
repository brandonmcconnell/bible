<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨハネの福音書 1:12; ガラテヤ人への手紙 3:26; コリント人への手紙第二 6:18"> 私たちが神の子どもと呼ばれるために、――事実、いま私たちは神の子どもです。――御父はどんなにすばらしい愛を与えてくださったことでしょう。世が私たちを知らないのは、御父を知らないからです。</span>
<span className="v" id="v2" data-v="2" data-xref="ピリピ人への手紙 3:21; コロサイ人への手紙 3:4; コリント人への手紙第一 13:12"> 愛する者たち。私たちは、今すでに神の子どもです。後の状態はまだ明らかにされていません。しかし、キリストが現われたなら、私たちはキリストに似た者となることがわかっています。なぜならそのとき、私たちはキリストのありのままの姿を見るからです。</span>
<span className="v" id="v3" data-v="3" data-xref="コリント人への手紙第二 7:1; ヨハネの手紙第一 2:6; ペテロの手紙第二 3:14"> キリストに対するこの望みをいだく者はみな、キリストがきよくあられるように、自分をきよくします。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネの手紙第一 5:17; ローマ人への手紙 3:20; ローマ人への手紙 4:15"> 罪を犯している者はみな、不法を行なっているのです。罪とは律法に逆らうことなのです。</span>
<span className="v" id="v5" data-v="5" data-xref="コリント人への手紙第二 5:21; ヘブル人への手紙 9:28; ペテロの手紙第一 3:18"> キリストが現われたのは罪を取り除くためであったことを、あなたがたは知っています。キリストには何の罪もありません。</span>
<span className="v" id="v6" data-v="6" data-xref="ヨハネの手紙第三 1:11; ヨハネの手紙第一 2:4; ヨハネの手紙第一 3:9"> だれでもキリストのうちにとどまる者は、罪のうちを歩みません。罪のうちを歩む者はだれも、キリストを見てもいないし、知ってもいないのです。</span>
<span className="v" id="v7" data-v="7" data-xref="ヨハネの手紙第一 2:29; ペテロの手紙第一 1:15–16; ローマ人への手紙 2:13"> 子どもたちよ。だれにも惑わされてはいけません。義を行なう者は、キリストが正しくあられるのと同じように正しいのです。</span>
<span className="v" id="v8" data-v="8" data-xref="ヘブル人への手紙 2:14; ヨハネの福音書 8:44; コロサイ人への手紙 2:15"> 罪のうちを歩む者は、悪魔から出た者です。悪魔は初めから罪を犯しているからです。神の子が現われたのは、悪魔のしわざを打ちこわすためです。</span>
<span className="v" id="v9" data-v="9" data-xref="ヨハネの手紙第一 5:18; ペテロの手紙第一 1:23; ヨハネの福音書 1:13"> だれでも神から生まれた者は、罪のうちを歩みません。なぜなら、神の種がその人のうちにとどまっているからです。その人は神から生まれたので、罪のうちを歩むことができないのです。</span>
<span className="v" id="v10" data-v="10" data-xref="ヨハネの手紙第一 4:8; ヨハネの手紙第三 1:11; ルカの福音書 6:35"> そのことによって、神の子どもと悪魔の子どもとの区別がはっきりします。義を行なわない者はだれも、神から出た者ではありません。兄弟を愛さない者もそうです。</span>
<span className="v" id="v11" data-v="11" data-xref="ヨハネの福音書 15:12; ヨハネの手紙第二 1:5; ヨハネの手紙第一 4:7"> 互いに愛し合うべきであるということは、あなたがたが初めから聞いている教えです。</span>
<span className="v" id="v12" data-v="12" data-xref="ヘブル人への手紙 11:4; Genesis 4:4–15; Proverbs 29:27"> カインのようであってはいけません。彼は悪い者から出た者で、兄弟を殺しました。なぜ兄弟を殺したのでしょう。自分の行ないは悪く、兄弟の行ないは正しかったからです。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="ヨハネの福音書 15:18–19; ヨハネの福音書 17:14; ルカの福音書 21:17"> 兄弟たち。世があなたがたを憎んでも、驚いてはいけません。</span>
<span className="v" id="v14" data-v="14" data-xref="ヨハネの福音書 13:35; ヨハネの手紙第一 5:2; ヨハネの手紙第一 4:20–21"> 私たちは、自分が死からいのちに移ったことを知っています。それは、兄弟を愛しているからです。愛さない者は、死のうちにとどまっているのです。</span>
<span className="v" id="v15" data-v="15" data-xref="マタイの福音書 5:21–22; Proverbs 26:24–26; ヨハネの黙示録 21:8"> 兄弟を憎む者はみな、人殺しです。いうまでもなく、だれでも人を殺す者のうちに、永遠のいのちがとどまっていることはないのです。</span>
<span className="v" id="v16" data-v="16" data-xref="ヨハネの手紙第一 4:9–11; エペソ人への手紙 5:2; ヨハネの福音書 13:34"> キリストは、私たちのために、ご自分のいのちをお捨てになりました。それによって私たちに愛がわかったのです。ですから私たちは、兄弟のために、いのちを捨てるべきです。</span>
<span className="v" id="v17" data-v="17" data-xref="ヘブル人への手紙 13:16; Isaiah 58:7–10; Deuteronomy 15:7–11"> 世の富を持ちながら、兄弟が困っているのを見ても、あわれみの心を閉ざすような者に、どうして神の愛がとどまっているでしょう。</span>
<span className="v" id="v18" data-v="18" data-xref="ヤコブの手紙 2:15–16; ローマ人への手紙 12:9; ペテロの手紙第一 1:22"> 子どもたちよ。私たちは、ことばや口先だけで愛することをせず、行ないと真実をもって愛そうではありませんか。</span>
<span className="v" id="v19" data-v="19" data-xref="ヘブル人への手紙 10:22; ヨハネの手紙第一 3:21; ヘブル人への手紙 6:10–11"> それによって、私たちは、自分が真理に属するものであることを知り、そして、神の御前に心を安らかにされるのです。</span>
<span className="v" id="v20" data-v="20" data-xref="Psalms 139:1–4; Jeremiah 17:10; ヘブル人への手紙 4:13"> たとい自分の心が責めてもです。なぜなら、神は私たちの心よりも大きく、そして何もかもご存じだからです。</span>
<span className="v" id="v21" data-v="21" data-xref="ヨハネの手紙第一 2:28; ヘブル人への手紙 4:16; コリント人への手紙第二 1:12"> 愛する者たち。もし自分の心に責められなければ、大胆に神の御前に出ることができ、</span>
<span className="v" id="v22" data-v="22" data-xref="ヨハネの福音書 15:7; ヨハネの福音書 9:31; ヨハネの手紙第一 5:14"> また求めるものは何でも神からいただくことができます。なぜなら、私たちが神の命令を守り、神に喜ばれることを行なっているからです。</span>
<span className="v" id="v23" data-v="23" data-xref="ヨハネの福音書 6:29; ヨハネの福音書 13:34; ペテロの手紙第一 1:22"> 神の命令とは、私たちが御子イエス・キリストの御名を信じ、キリストが命じられたとおりに、私たちが互いに愛し合うことです。</span>
<span className="v" id="v24" data-v="24" data-xref="コリント人への手紙第一 3:16; ヨハネの手紙第一 4:15–16; ヨハネの手紙第一 4:12–13"> 神の命令を守る者は神のうちにおり、神もまたその人のうちにおられます。神が私たちのうちにおられるということは、神が私たちに与えてくださった御霊によって知るのです。</span>
</div>

<span className="v" id="v1" data-v="1" data-xref="使徒の働き 16:9; コリント人への手紙第二 9:2; コリント人への手紙第二 9:4"> さて、兄弟たち。私たちは、マケドニヤの諸教会に与えられた神の恵みを、あなたがたに知らせようと思います。</span>
<span className="v" id="v2" data-v="2" data-xref="ヤコブの手紙 2:5; Proverbs 11:25; コリント人への手紙第二 6:10"> 苦しみゆえの激しい試練の中にあっても、彼らの満ちあふれる喜びは、その極度の貧しさにもかかわらず、あふれ出て、その惜しみなく施す富となったのです。</span>
<span className="v" id="v3" data-v="3" data-xref="Exodus 35:29; Exodus 35:5; Exodus 35:21–22"> 私はあかしします。彼らは自ら進んで、力に応じ、いや力以上にささげ、</span>
<span className="v" id="v4" data-v="4" data-xref="使徒の働き 24:17; ガラテヤ人への手紙 6:10; コリント人への手紙第二 9:1"> 聖徒たちをささえる交わりの恵みにあずかりたいと、熱心に私たちに願ったのです。</span>
<span className="v" id="v5" data-v="5" data-xref="ローマ人への手紙 12:1; ローマ人への手紙 14:7–9; 2 Chronicles 30:12"> そして、私たちの期待以上に、神のみこころに従って、まず自分自身を主にささげ、また、私たちにもゆだねてくれました。</span>
<span className="v" id="v6" data-v="6" data-xref="コリント人への手紙第二 12:18; コリント人への手紙第二 8:19; コリント人への手紙第二 8:4"> それで私たちは、テトスがすでにこの恵みのわざをあなたがたの間で始めていたのですから、それを完了させるよう彼に勧めたのです。</span>
<span className="v" id="v7" data-v="7" data-xref="コリント人への手紙第二 9:8; ペテロの手紙第二 1:5–8; テサロニケ人への手紙第二 1:3"> あなたがたは、すべてのことに、すなわち、信仰にも、ことばにも、知識にも、あらゆる熱心にも、私たちから出てあなたがたの間にある愛にも富んでいるように、この恵みのわざにも富むようになってください。</span>
<span className="v" id="v8" data-v="8" data-xref="コリント人への手紙第一 7:6; ヨハネの手紙第一 3:17–19; ヤコブの手紙 2:14–16"> こうは言っても、私は命令するのではありません。ただ、他の人々の熱心さをもって、あなたがた自身の愛の真実を確かめたいのです。</span>
<span className="v" id="v9" data-v="9" data-xref="ローマ人への手紙 8:32; ピリピ人への手紙 2:6–8; マタイの福音書 20:28"> あなたがたは、私たちの主イエス・キリストの恵みを知っています。すなわち、主は富んでおられたのに、あなたがたのために貧しくなられました。それは、あなたがたが、キリストの貧しさによって富む者となるためです。</span>
<span className="v" id="v10" data-v="10" data-xref="テモテへの手紙第一 6:18–19; ヘブル人への手紙 13:16; コリント人への手紙第二 9:2"> この献金のことについて、私の意見を述べましょう。それはあなたがたの益になることだからです。あなたがたは、このことを昨年から、他に先んじて行なっただけでなく、このことを他に先んじて願った人たちです。</span>
<span className="v" id="v11" data-v="11" data-xref="コリント人への手紙第二 9:2"> ですから、今、それをし遂げなさい。喜んでしようと思ったのですから、持っている物で、それをし遂げることができるはずです。</span>
<span className="v" id="v12" data-v="12" data-xref="マルコの福音書 12:42–44; コリント人への手紙第二 9:7; ルカの福音書 21:1–4"> もし熱意があるならば、持たない物によってではなく、持っている程度に応じて、それは受納されるのです。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒の働き 4:34; ローマ人への手紙 15:26–27"> 私はこのことによって、他の人々には楽をさせ、あなたがたには苦労をさせようとしているのではなく、平等を図っているのです。</span>
<span className="v" id="v14" data-v="14" data-xref="コリント人への手紙第二 9:12; 使徒の働き 4:34"> 今あなたがたの余裕が彼らの欠乏を補うなら、彼らの余裕もまた、あなたがたの欠乏を補うことになるのです。こうして、平等になるのです。</span>
<span className="v" id="v15" data-v="15" data-xref="Exodus 16:18; ルカの福音書 22:35"> 「多く集めた者も余るところがなく、少し集めた者も足りないところがなかった。」と書いてあるとおりです。</span>
<span className="v" id="v16" data-v="16" data-xref="ヨハネの黙示録 17:17; Jeremiah 32:40; コリント人への手紙第二 2:13–14"> 私があなたがたのことを思うのと同じ熱心を、テトスの心にも与えてくださった神に感謝します。</span>
<span className="v" id="v17" data-v="17" data-xref="コリント人への手紙第二 8:6; ヘブル人への手紙 13:22; コリント人への手紙第二 8:10"> 彼は私の勧めを受け入れ、非常な熱意をもって、自分から進んであなたがたのところに行こうとしています。</span>
<span className="v" id="v18" data-v="18" data-xref="コリント人への手紙第二 12:18; コリント人への手紙第二 8:19; コリント人への手紙第一 7:17"> また私たちは、テトスといっしょに、ひとりの兄弟を送ります。この人は、福音の働きによって、すべての教会で称賛されていますが、</span>
<span className="v" id="v19" data-v="19" data-xref="コリント人への手紙第一 16:3–4; コリント人への手紙第二 4:15; コリント人への手紙第二 9:8"> そればかりでなく、彼は、この恵みのわざに携わっている私たちに同伴するよう諸教会の任命を受けたのです。私たちがこの働きをしているのは、主ご自身の栄光のため、また、私たちの誠意を示すためにほかなりません。</span>
<span className="v" id="v20" data-v="20" data-xref="テサロニケ人への手紙第一 5:22; ローマ人への手紙 14:16; エペソ人への手紙 5:15"> 私たちは、この献金の取り扱いについて、だれからも非難されることがないように心がけています。</span>
<span className="v" id="v21" data-v="21" data-xref="ローマ人への手紙 12:17; ペテロの手紙第一 2:12; ピリピ人への手紙 4:8"> それは、主の御前ばかりでなく、人の前でも公明正大なことを示そうと考えているからです。</span>
<span className="v" id="v22" data-v="22" data-xref="ピリピ人への手紙 2:20–22"> また、彼らといっしょに、もうひとりの兄弟を送ります。私たちはこの兄弟が多くのことについて熱心であることを、しばしば認めることができました。彼は今、あなたがたに深い信頼を寄せ、ますます熱心になっています。</span>
<span className="v" id="v23" data-v="23" data-xref="ピリピ人への手紙 2:25; ピレモンへの手紙 1:17; コリント人への手紙第二 8:6"> テトスについて言えば、彼は私の仲間で、あなたがたの間での私の同労者です。兄弟たちについて言えば、彼らは諸教会の使者、キリストの栄光です。</span>
<span className="v" id="v24" data-v="24" data-xref="コリント人への手紙第二 7:14; コリント人への手紙第二 7:4; コリント人への手紙第二 9:2–4"> ですから、あなたがたの愛と、私たちがあなたがたを誇りとしている証拠とを、諸教会の前で、彼らに示してほしいのです。</span>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="テサロニケ人への手紙第二 3:13; ガラテヤ人への手紙 6:9; エペソ人への手紙 3:13"> こういうわけで、私たちは、あわれみを受けてこの務めに任じられているのですから、勇気を失うことなく、</span>
<span className="v" id="v2" data-v="2" data-xref="コリント人への手紙第二 2:17; テサロニケ人への手紙第一 2:3–5; コリント人への手紙第二 5:11"> 恥ずべき隠された事を捨て、悪巧みに歩まず、神のことばを曲げず、真理を明らかにし、神の御前で自分自身をすべての人の良心に推薦しています。</span>
<span className="v" id="v3" data-v="3" data-xref="コリント人への手紙第二 3:14; コリント人への手紙第一 1:18; テサロニケ人への手紙第二 2:9–11"> それでもなお私たちの福音におおいが掛かっているとしたら、それは、滅びる人々のばあいに、おおいが掛かっているのです。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネの福音書 12:40; コリント人への手紙第二 3:14; 使徒の働き 26:18"> そのばあい、この世の神が不信者の思いをくらませて、神のかたちであるキリストの栄光にかかわる福音の光を輝かせないようにしているのです。</span>
<span className="v" id="v5" data-v="5" data-xref="コリント人への手紙第二 1:24; コリント人への手紙第一 1:23; テサロニケ人への手紙第一 2:5–6"> 私たちは自分自身を宣べ伝えるのではなく、主なるキリスト・イエスを宣べ伝えます。私たち自身は、イエスのために、あなたがたに仕えるしもべなのです。</span>
<span className="v" id="v6" data-v="6" data-xref="Isaiah 60:2; Genesis 1:3; ペテロの手紙第一 2:9"> 「光が、やみの中から輝き出よ。」と言われた神は、私たちの心を照らし、キリストの御顔にある神の栄光を知る知識を輝かせてくださったのです。</span>
<span className="v" id="v7" data-v="7" data-xref="コリント人への手紙第二 3:5–6; コリント人への手紙第二 5:1; エペソ人への手紙 2:8–9"> 私たちは、この宝を、土の器の中に入れているのです。それは、この測り知れない力が神のものであって、私たちから出たものでないことが明らかにされるためです。</span>
<span className="v" id="v8" data-v="8" data-xref="ヤコブの手紙 1:2–4; ローマ人への手紙 8:35–37; ペテロの手紙第一 4:12–14"> 私たちは、四方八方から苦しめられますが、窮することはありません。途方にくれていますが、行きづまることはありません。</span>
<span className="v" id="v9" data-v="9" data-xref="Isaiah 43:2; Micah 7:8; Psalms 37:24–25"> 迫害されていますが、見捨てられることはありません。倒されますが、滅びません。</span>
<span className="v" id="v10" data-v="10" data-xref="ローマ人への手紙 6:5; テモテへの手紙第二 2:11; ペテロの手紙第一 4:13"> いつでもイエスの死をこの身に帯びていますが、それは、イエスのいのちが私たちの身において明らかに示されるためです。</span>
<span className="v" id="v11" data-v="11" data-xref="コリント人への手紙第一 15:49; ローマ人への手紙 8:36; Psalms 44:22"> 私たち生きている者は、イエスのために絶えず死に渡されていますが、それは、イエスのいのちが私たちの死ぬべき肉体において明らかに示されるためなのです。</span>
<span className="v" id="v12" data-v="12" data-xref="コリント人への手紙第二 13:9; コリント人への手紙第一 4:10; 使徒の働き 20:24"> こうして、死は私たちのうちに働き、いのちはあなたがたのうちに働くのです。</span>
<span className="v" id="v13" data-v="13" data-xref="Psalms 116:10; ヘブル人への手紙 11:1–40; コリント人への手紙第二 3:12"> 「私は信じた。それゆえに語った。」と書いてあるとおり、それと同じ信仰の霊を持っている私たちも、信じているゆえに語るのです。</span>
<span className="v" id="v14" data-v="14" data-xref="テサロニケ人への手紙第一 4:14; ローマ人への手紙 8:11; ユダの手紙 1:24"> それは、主イエスをよみがえらせた方が、私たちをもイエスとともによみがえらせ、あなたがたといっしょに御前に立たせてくださることを知っているからです。</span>
<span className="v" id="v15" data-v="15" data-xref="ローマ人への手紙 8:28; エペソ人への手紙 3:20–21; コリント人への手紙第二 9:11–12"> すべてのことはあなたがたのためであり、それは、恵みがますます多くの人々に及んで感謝が満ちあふれ、神の栄光が現われるようになるためです。</span>
<span className="v" id="v16" data-v="16" data-xref="Isaiah 40:31; コロサイ人への手紙 3:10; Isaiah 40:29"> ですから、私たちは勇気を失いません。たとい私たちの外なる人は衰えても、内なる人は日々新たにされています。</span>
<span className="v" id="v17" data-v="17" data-xref="ローマ人への手紙 8:18; ペテロの手紙第一 5:10; ローマ人への手紙 5:3–5"> 今の時の軽い患難は、私たちのうちに働いて、測り知れない、重い永遠の栄光をもたらすからです。</span>
<span className="v" id="v18" data-v="18" data-xref="コリント人への手紙第二 5:7; ローマ人への手紙 8:24–25; ヘブル人への手紙 11:1"> 私たちは、見えるものにではなく、見えないものにこそ目を留めます。見えるものは一時的であり、見えないものはいつまでも続くからです。</span>

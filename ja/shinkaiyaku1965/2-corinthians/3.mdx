<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="コリント人への手紙第二 12:11; コリント人への手紙第二 10:12; コリント人への手紙第二 5:12"> 私たちはまたもや自分を推薦しようとしているのでしょうか。それとも、ある人々のように、あなたがたにあてた推薦状とか、あなたがたの推薦状とかが、私たちに必要なのでしょうか。</span>
<span className="v" id="v2" data-v="2" data-xref="コリント人への手紙第一 9:1–2; テサロニケ人への手紙第一 1:8; ローマ人への手紙 1:8"> 私たちの推薦状はあなたがたです。それは私たちの心にしるされていて、すべての人に知られ、また読まれているのです。</span>
<span className="v" id="v3" data-v="3" data-xref="Ezekiel 11:19; Jeremiah 31:33; ヘブル人への手紙 8:10"> あなたがたが私たちの奉仕によるキリストの手紙であり、墨によってではなく、生ける神の御霊によって書かれ、石の板にではなく、人の心の板に書かれたものであることが明らかだからです。</span>
<span className="v" id="v4" data-v="4" data-xref="ピリピ人への手紙 1:6; エペソ人への手紙 3:12; コリント人への手紙第二 2:14"> 私たちはキリストによって、神の御前でこういう確信を持っています。</span>
<span className="v" id="v5" data-v="5" data-xref="コリント人への手紙第二 12:9; ピリピ人への手紙 4:13; コリント人への手紙第一 15:10"> 何事かを自分のしたことと考える資格が私たち自身にあるというのではありません。私たちの資格は神からのものです。</span>
<span className="v" id="v6" data-v="6" data-xref="ヨハネの福音書 6:63; ローマ人への手紙 7:6; Jeremiah 31:31"> 神は私たちに、新しい契約に仕える者となる資格を下さいました。文字に仕える者ではなく、御霊に仕える者です。文字は殺し、御霊は生かすからです。</span>
<span className="v" id="v7" data-v="7" data-xref="コリント人への手紙第二 3:9–11; ローマ人への手紙 10:4; Exodus 31:18"> もし石に刻まれた文字による、死の務めにも栄光があって、モーセの顔の、やがて消え去る栄光のゆえにさえ、イスラエルの人々がモーセの顔を見つめることができなかったほどだとすれば、</span>
<span className="v" id="v8" data-v="8" data-xref="コリント人への手紙第一 3:16; エペソ人への手紙 2:18; ガラテヤ人への手紙 3:14"> まして、御霊の務めには、どれほどの栄光があることでしょう。</span>
<span className="v" id="v9" data-v="9" data-xref="ローマ人への手紙 3:21–22; ヘブル人への手紙 12:18–21; コリント人への手紙第二 5:21"> 罪に定める務めに栄光があるのなら、義とする務めには、なおさら、栄光があふれるのです。</span>
<span className="v" id="v10" data-v="10" data-xref="ペテロの手紙第二 1:17; Haggai 2:7–9; 使徒の働き 26:13"> そして、かつて栄光を受けたものは、このばあい、さらにすぐれた栄光のゆえに、栄光のないものになっているからです。</span>
<span className="v" id="v11" data-v="11" data-xref="ローマ人への手紙 5:20–21; ヘブル人への手紙 8:13; ヘブル人への手紙 7:21–25"> もし消え去るべきものにも栄光があったのなら、永続するものには、なおさら栄光があるはずです。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="コリント人への手紙第二 7:4; 使徒の働き 4:13; ピリピ人への手紙 1:20"> このような望みを持っているので、私たちはきわめて大胆に語ります。</span>
<span className="v" id="v13" data-v="13" data-xref="Exodus 34:33–35; ヘブル人への手紙 10:1–9; エペソ人への手紙 2:14–15"> そして、モーセが、消えうせるものの最後をイスラエルの人々に見せないように、顔におおいを掛けたようなことはしません。</span>
<span className="v" id="v14" data-v="14" data-xref="コリント人への手紙第二 4:3–4; 使徒の働き 26:18; ローマ人への手紙 11:25"> しかし、イスラエルの人々の思いは鈍くなったのです。というのは、今日に至るまで、古い契約が朗読されるときに、同じおおいが掛けられたままで、取りのけられてはいません。なぜなら、それはキリストによって取り除かれるものだからです。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒の働き 13:27–29"> かえって、今日まで、モーセの書が朗読されるときはいつでも、彼らの心にはおおいが掛かっているのです。</span>
<span className="v" id="v16" data-v="16" data-xref="Exodus 34:34; Isaiah 29:18; Isaiah 25:7"> しかし、人が主に向くなら、そのおおいは取り除かれるのです。</span>
<span className="v" id="v17" data-v="17" data-xref="ローマ人への手紙 8:2; ガラテヤ人への手紙 5:13; ヨハネの福音書 8:32"> 主は御霊です。そして、主の御霊のあるところには自由があります。</span>
<span className="v" id="v18" data-v="18" data-xref="コリント人への手紙第二 4:6; エペソ人への手紙 4:22–24; ローマ人への手紙 12:2"> 私たちはみな、顔のおおいを取りのけられて、鏡のように主の栄光を反映させながら、栄光から栄光へと、主と同じかたちに姿を変えられて行きます。これはまさに、御霊なる主の働きによるのです。</span>
</div>

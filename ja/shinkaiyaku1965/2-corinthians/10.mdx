<span className="v" id="v1" data-v="1" data-xref="コリント人への手紙第二 10:10; マタイの福音書 11:29; ガラテヤ人への手紙 5:2"> さて、私パウロは、キリストの柔和と寛容をもって、あなたがたにお勧めします。私は、あなたがたの間にいて、面と向かっているときはおとなしく、離れているあなたがたに対しては強気な者です。</span>
<span className="v" id="v2" data-v="2" data-xref="コリント人への手紙第二 13:10; コリント人への手紙第二 13:2; ガラテヤ人への手紙 5:16–25"> しかし、私は、あなたがたのところに行くときには、私たちを肉に従って歩んでいるかのように考える人々に対して勇敢にふるまおうと思っているその確信によって、強気にふるまうことがなくて済むように願っています。</span>
<span className="v" id="v3" data-v="3" data-xref="コリント人への手紙第二 10:4; ガラテヤ人への手紙 2:20; ペテロの手紙第一 4:1–2"> 私たちは肉にあって歩んではいても、肉に従って戦ってはいません。</span>
<span className="v" id="v4" data-v="4" data-xref="コリント人への手紙第二 6:7; エペソ人への手紙 6:13–18; Jeremiah 1:10"> 私たちの戦いの武器は、肉の物ではなく、神の御前で、要塞をも破るほどに力のあるものです。</span>
<span className="v" id="v5" data-v="5" data-xref="ヘブル人への手紙 4:12; Isaiah 55:7; ペテロの手紙第一 1:14–15"> 私たちは、さまざまの思弁と、神の知識に逆らって立つあらゆる高ぶりを打ち砕き、すべてのはかりごとをとりこにしてキリストに服従させ、</span>
<span className="v" id="v6" data-v="6" data-xref="コリント人への手紙第二 2:9; Numbers 16:26–30; コリント人への手紙第二 7:15"> また、あなたがたの従順が完全になるとき、あらゆる不従順を罰する用意ができているのです。</span>
<span className="v" id="v7" data-v="7" data-xref="コリント人への手紙第二 5:12; ヨハネの福音書 7:24; コリント人への手紙第一 14:37"> あなたがたは、うわべのことだけを見ています。もし自分はキリストに属する者だと確信している人がいるなら、その人は、自分がキリストに属しているように、私たちもまたキリストに属しているということを、もう一度、自分でよく考えなさい。</span>
<span className="v" id="v8" data-v="8" data-xref="コリント人への手紙第二 13:10; コリント人への手紙第二 12:6; ガラテヤ人への手紙 1:1"> あなたがたを倒すためにではなく、立てるために主が私たちに授けられた権威については、たとい私が多少誇りすぎることがあっても、恥とはならないでしょう。</span>
<span className="v" id="v9" data-v="9" data-xref="コリント人への手紙第二 10:10; コリント人への手紙第一 4:19–21; コリント人への手紙第一 4:5"> 私は手紙であなたがたをおどしているかのように見られたくありません。</span>
<span className="v" id="v10" data-v="10" data-xref="コリント人への手紙第一 1:17; Exodus 4:10; ガラテヤ人への手紙 4:13–14"> 彼らは言います。「パウロの手紙は重みがあって力強いが、実際に会ったばあいの彼は弱々しく、その話しぶりは、なっていない。」</span>
<span className="v" id="v11" data-v="11" data-xref="コリント人への手紙第二 12:20; コリント人への手紙第二 13:2–3; コリント人への手紙第二 13:10"> そういう人はよく承知しておきなさい。離れているときに書く手紙のことばがそうなら、いっしょにいるときの行動もそのとおりです。</span>
<span className="v" id="v12" data-v="12" data-xref="Proverbs 27:2; Proverbs 26:12; ルカの福音書 18:11"> 私たちは、自己推薦をしているような人たちの中のだれかと自分を同列に置いたり、比較したりしようなどとは思いません。しかし、彼らが自分たちの間で自分を量ったり、比較したりしているのは、知恵のないことなのです。</span>
<span className="v" id="v13" data-v="13" data-xref="ローマ人への手紙 12:6; ローマ人への手紙 15:20; ペテロの手紙第一 4:10"> 私たちは、限度を越えて誇りはしません。私たちがあなたがたのところまで行くのも、神が私たちに量って割り当ててくださった限度内で行くのです。</span>
<span className="v" id="v14" data-v="14" data-xref="コリント人への手紙第一 4:15; テモテへの手紙第一 1:11; ローマ人への手紙 1:16"> 私たちは、あなたがたのところまでは行かないのに無理に手を伸ばしているのではありません。事実、私たちは、キリストの福音を携えてあなたがたのところにまで行ったのです。</span>
<span className="v" id="v15" data-v="15" data-xref="ローマ人への手紙 15:20; テサロニケ人への手紙第二 1:3; コリント人への手紙第二 10:13"> 私たちは、自分の限度を越えてほかの人の働きを誇ることはしません。ただ、あなたがたの信仰が成長し、あなたがたによって、私たちの領域内で私たちの働きが広げられることを望んでいます。</span>
<span className="v" id="v16" data-v="16" data-xref="ローマ人への手紙 15:24–28; 使徒の働き 19:21"> それは、私たちがあなたがたの向こうの地域にまで福音を宣べ伝えるためであって、決して他の人の領域でなされた働きを誇るためではないのです。</span>
<span className="v" id="v17" data-v="17" data-xref="Jeremiah 9:23–24; コリント人への手紙第一 1:31; ヤコブの手紙 1:9–10"> 誇る者は、主にあって誇りなさい。</span>
<span className="v" id="v18" data-v="18" data-xref="ルカの福音書 16:15; Proverbs 21:2; コリント人への手紙第一 4:5"> 自分で自分を推薦する人でなく、主に推薦される人こそ、受け入れられる人です。</span>

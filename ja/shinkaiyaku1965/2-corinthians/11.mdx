<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="コリント人への手紙第二 11:4; コリント人への手紙第一 1:21; コリント人への手紙第二 11:19"> 私の少しばかりの愚かさをこらえていただきたいと思います。いや、あなたがたはこらえているのです。</span>
<span className="v" id="v2" data-v="2" data-xref="Hosea 2:19–20; エペソ人への手紙 5:26–27; Isaiah 54:5"> というのも、私は神の熱心をもって、熱心にあなたがたのことを思っているからです。私はあなたがたを、清純な処女として、ひとりの人の花嫁に定め、キリストにささげることにしたからです。</span>
<span className="v" id="v3" data-v="3" data-xref="コロサイ人への手紙 2:8; ガラテヤ人への手紙 1:6; エペソ人への手紙 4:14"> しかし、蛇が悪巧みによってエバを欺いたように、万一にもあなたがたの思いが汚されて、キリストに対する真実と貞潔を失うことがあってはと、私は心配しています。</span>
<span className="v" id="v4" data-v="4" data-xref="ガラテヤ人への手紙 1:6–8; コリント人への手紙第一 3:11; テモテへの手紙第一 2:5"> というわけは、ある人が来て、私たちの宣べ伝えなかった別のイエスを宣べ伝えたり、あるいはあなたがたが、前に受けたことのない異なった霊を受けたり、受け入れたことのない異なった福音を受けたりするときも、あなたがたはみごとにこらえているからです。</span>
<span className="v" id="v5" data-v="5" data-xref="コリント人への手紙第二 12:11–12; コリント人への手紙第一 15:10; ガラテヤ人への手紙 2:6–9"> 私は自分をあの大使徒たちに少しでも劣っているとは思いません。</span>
<span className="v" id="v6" data-v="6" data-xref="エペソ人への手紙 3:4; コリント人への手紙第一 1:17; コリント人への手紙第二 4:2"> たとい、話は巧みでないにしても、知識についてはそうではありません。私たちは、すべての点で、いろいろなばあいに、そのことをあなたがたに示して来ました。</span>
<span className="v" id="v7" data-v="7" data-xref="コリント人への手紙第二 12:13; テサロニケ人への手紙第一 2:9; コリント人への手紙第二 10:1"> それとも、あなたがたを高めるために、自分を低くして報酬を受けずに神の福音をあなたがたに宣べ伝えたことが、私の罪だったのでしょうか。</span>
<span className="v" id="v8" data-v="8" data-xref="ピリピ人への手紙 4:18; コリント人への手紙第二 11:9; ピリピ人への手紙 4:14–16"> 私は他の諸教会から奪い取って、あなたがたに仕えるための給料を得たのです。</span>
<span className="v" id="v9" data-v="9" data-xref="テサロニケ人への手紙第二 3:8–9; テサロニケ人への手紙第一 2:9; テサロニケ人への手紙第一 2:6"> あなたがたのところにいて困窮していたときも、私はだれにも負担をかけませんでした。マケドニヤから来た兄弟たちが、私の欠乏を十分に補ってくれたのです。私は、万事につけあなたがたの重荷にならないようにしましたし、今後もそうするつもりです。</span>
<span className="v" id="v10" data-v="10" data-xref="ローマ人への手紙 9:1; ローマ人への手紙 1:9; 使徒の働き 18:12"> 私にあるキリストの真実にかけて言います。アカヤ地方で私のこの誇りが封じられることは決してありません。</span>
<span className="v" id="v11" data-v="11" data-xref="コリント人への手紙第二 12:15; コリント人への手紙第二 6:11–12; コリント人への手紙第二 7:3"> なぜでしょう。私があなたがたを愛していないからでしょうか。神はご存じです。</span>
<span className="v" id="v12" data-v="12" data-xref="コリント人への手紙第一 9:12; コリント人への手紙第一 5:6; コリント人への手紙第二 5:12"> しかし、私は、今していることを今後も、し続けるつもりです。それは、私たちと同じように誇るところがあるとみなされる機会をねらっている者たちから、その機会を断ち切ってしまうためです。</span>
<span className="v" id="v13" data-v="13" data-xref="ガラテヤ人への手紙 1:7; ヨハネの黙示録 2:2; ヨハネの手紙第一 4:1"> こういう者たちは、にせ使徒であり、人を欺く働き人であって、キリストの使徒に変装しているのです。</span>
<span className="v" id="v14" data-v="14" data-xref="ガラテヤ人への手紙 1:8; コリント人への手紙第二 2:11; コリント人への手紙第二 11:3"> しかし、驚くには及びません。サタンさえ光の御使いに変装するのです。</span>
<span className="v" id="v15" data-v="15" data-xref="ピリピ人への手紙 3:19; ヨハネの黙示録 9:11; Isaiah 9:14–15"> ですから、サタンの手下どもが義のしもべに変装したとしても、格別なことはありません。彼らの最後はそのしわざにふさわしいものとなります。</span>
<span className="v" id="v16" data-v="16" data-xref="コリント人への手紙第二 11:1; コリント人への手紙第二 12:6; コリント人への手紙第二 12:11"> くり返して言いますが、だれも、私を愚かと思ってはなりません。しかし、もしそう思うなら、私を愚か者扱いにしなさい。私も少し誇ってみせます。</span>
<span className="v" id="v17" data-v="17" data-xref="コリント人への手紙第一 7:12; ピリピ人への手紙 3:3–6; コリント人への手紙第二 9:4"> これから話すことは、主によって話すのではなく、愚か者としてする思い切った自慢話です。</span>
<span className="v" id="v18" data-v="18" data-xref="コリント人への手紙第一 4:10; コリント人への手紙第二 11:21–23; コリント人への手紙第二 10:12–18"> 多くの人が肉によって誇っているので、私も誇ることにします。</span>
<span className="v" id="v19" data-v="19" data-xref="コリント人への手紙第一 4:10; コリント人への手紙第一 10:15; コリント人への手紙第一 8:1"> あなたがたは賢いのに、よくも喜んで愚か者たちをこらえています。</span>
<span className="v" id="v20" data-v="20" data-xref="ガラテヤ人への手紙 2:4; ガラテヤ人への手紙 4:3; ガラテヤ人への手紙 5:1"> 事実、あなたがたは、だれかに奴隷にされても、食い尽くされても、だまされても、いばられても、顔をたたかれても、こらえているではありませんか。</span>
<span className="v" id="v21" data-v="21" data-xref="コリント人への手紙第二 10:10; コリント人への手紙第二 11:17; コリント人への手紙第二 10:1–2"> 言うのも恥ずかしいことですが、言わなければなりません。私たちは弱かったのです。しかし、人があえて誇ろうとすることなら、――私は愚かになって言いますが、――私もあえて誇りましょう。</span>
<span className="v" id="v22" data-v="22" data-xref="ピリピ人への手紙 3:5; ローマ人への手紙 11:1; ローマ人への手紙 9:4"> 彼らはヘブル人ですか。私もそうです。彼らはイスラエル人ですか。私もそうです。彼らはアブラハムの子孫ですか。私もそうです。</span>
<span className="v" id="v23" data-v="23" data-xref="コリント人への手紙第二 6:4–5; コリント人への手紙第二 1:9–10; コリント人への手紙第二 6:9"> 彼らはキリストのしもべですか。私は狂気したように言いますが、私は彼ら以上にそうなのです。私の労苦は彼らよりも多く、牢に入れられたことも多く、また、むち打たれたことは数えきれず、死に直面したこともしばしばでした。</span>
<span className="v" id="v24" data-v="24" data-xref="マルコの福音書 13:9; Deuteronomy 25:2–3; マタイの福音書 10:17"> ユダヤ人から三十九のむちを受けたことが五度、</span>
<span className="v" id="v25" data-v="25" data-xref="使徒の働き 14:19; 使徒の働き 16:37; ヘブル人への手紙 11:37"> むちで打たれたことが三度、石で打たれたことが一度、難船したことが三度あり、一昼夜、海上を漂ったこともあります。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒の働き 14:5; 使徒の働き 17:5; 使徒の働き 13:50"> 幾度も旅をし、川の難、盗賊の難、同国民から受ける難、異邦人から受ける難、都市の難、荒野の難、海上の難、にせ兄弟の難に会い、</span>
<span className="v" id="v27" data-v="27" data-xref="ピリピ人への手紙 4:12; コリント人への手紙第二 6:5; テサロニケ人への手紙第一 2:9"> 労し苦しみ、たびたび眠られぬ夜を過ごし、飢え渇き、しばしば食べ物もなく、寒さに凍え、裸でいたこともありました。</span>
<span className="v" id="v28" data-v="28" data-xref="コリント人への手紙第一 7:17; ローマ人への手紙 15:16; 使徒の働き 20:18–35"> このような外から来ることのほかに、日々私に押しかかるすべての教会への心づかいがあります。</span>
<span className="v" id="v29" data-v="29" data-xref="コリント人への手紙第一 8:13; コリント人への手紙第一 9:22; ガラテヤ人への手紙 4:8–20"> だれかが弱くて、私が弱くない、ということがあるでしょうか。だれかがつまずいていて、私の心が激しく痛まないでおられましょうか。</span>
<span className="v" id="v30" data-v="30" data-xref="コリント人への手紙第二 12:5–11; Proverbs 25:27; コリント人への手紙第一 2:3"> もしどうしても誇る必要があるなら、私は自分の弱さを誇ります。</span>
<span className="v" id="v31" data-v="31" data-xref="ローマ人への手紙 9:5; エペソ人への手紙 1:3; ヨハネの福音書 10:30"> 主イエス・キリストの父なる神、永遠にほめたたえられる方は、私が偽りを言っていないのをご存じです。</span>
<span className="v" id="v32" data-v="32" data-xref="使徒の働き 9:24–25; コリント人への手紙第二 11:26"> ダマスコではアレタ王の代官が、私を捕えようとしてダマスコの町を監視しました。</span>
<span className="v" id="v33" data-v="33" data-xref="使徒の働き 9:25; 1 Samuel 19:12; Joshua 2:18"> そのとき私は、城壁の窓からかごでつり降ろされ、彼の手をのがれました。</span>

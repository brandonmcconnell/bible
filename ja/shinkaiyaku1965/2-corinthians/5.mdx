<span className="v" id="v1" data-v="1" data-xref="Job 19:25–26; ヨハネの手紙第一 3:2; ペテロの手紙第二 1:13–14"> 私たちの住まいである地上の幕屋がこわれても、神の下さる建物があることを、私たちは知っています。それは、人の手によらない、天にある永遠の家です。</span>
<span className="v" id="v2" data-v="2" data-xref="ローマ人への手紙 8:23; コリント人への手紙第一 15:53–54; コリント人への手紙第二 5:3–4"> 私たちはこの幕屋にあってうめき、この天から与えられる住まいを着たいと望んでいます。</span>
<span className="v" id="v3" data-v="3" data-xref="Genesis 3:7–11; ヨハネの黙示録 16:15; ヨハネの黙示録 3:18"> それを着たなら、私たちは裸の状態になることはないからです。</span>
<span className="v" id="v4" data-v="4" data-xref="コリント人への手紙第一 15:53–54; コリント人への手紙第二 5:2; Isaiah 25:8"> 確かにこの幕屋の中にいる間は、私たちは重荷を負って、うめいています。それは、この幕屋を脱ぎたいと思うからでなく、かえって天からの住まいを着たいからです。そのことによって、死ぬべきものがいのちにのまれてしまうためにです。</span>
<span className="v" id="v5" data-v="5" data-xref="コリント人への手紙第二 1:22; エペソ人への手紙 1:13–14; ローマ人への手紙 8:23"> 私たちをこのことにかなう者としてくださった方は神です。神は、その保証として御霊を下さいました。</span>
<span className="v" id="v6" data-v="6" data-xref="コリント人への手紙第二 5:1; ピリピ人への手紙 3:20–21; ヘブル人への手紙 11:13"> そういうわけで、私たちはいつも心強いのです。ただし、私たちが肉体にいる間は、主から離れているということも知っています。</span>
<span className="v" id="v7" data-v="7" data-xref="ヘブル人への手紙 11:1–27; コリント人への手紙第二 4:18; ローマ人への手紙 8:24–25"> 確かに、私たちは見るところによってではなく、信仰によって歩んでいます。</span>
<span className="v" id="v8" data-v="8" data-xref="ピリピ人への手紙 1:20–24; コリント人への手紙第二 5:6; ヨハネの福音書 14:3"> 私たちはいつも心強いのです。そして、むしろ肉体を離れて、主のみもとにいるほうがよいと思っています。</span>
<span className="v" id="v9" data-v="9" data-xref="コロサイ人への手紙 1:10; ペテロの手紙第二 3:14; ローマ人への手紙 14:18"> そういうわけで、肉体の中にあろうと、肉体を離れていようと、私たちの念願とするところは、主に喜ばれることです。</span>
<span className="v" id="v10" data-v="10" data-xref="マタイの福音書 16:27; ヨハネの黙示録 22:12; エペソ人への手紙 6:8"> なぜなら、私たちはみな、キリストのさばきの座に現われて、善であれ悪であれ、各自その肉体にあってした行為に応じて報いを受けることになるからです。</span>
<span className="v" id="v11" data-v="11" data-xref="ユダの手紙 1:23; ヘブル人への手紙 10:31; テモテへの手紙第二 2:24–26"> こういうわけで、私たちは、主を恐れることを知っているので、人々を説得しようとするのです。私たちのことは、神の御前に明らかです。しかし、あなたがたの良心にも明らかになることが、私の望みです。</span>
<span className="v" id="v12" data-v="12" data-xref="コリント人への手紙第二 3:1; コリント人への手紙第二 1:14; ガラテヤ人への手紙 6:12–14"> 私たちはまたも自分自身をあなたがたに推薦しようとするのではありません。ただ、私たちのことを誇る機会をあなたがたに与えて、心においてではなく、うわべのことで誇る人たちに答えることができるようにさせたいのです。</span>
<span className="v" id="v13" data-v="13" data-xref="コリント人への手紙第二 11:16–17; コリント人への手紙第二 11:1; コリント人への手紙第二 12:6"> もし私たちが気が狂っているとすれば、それはただ神のためであり、もし正気であるとすれば、それはただあなたがたのためです。</span>
<span className="v" id="v14" data-v="14" data-xref="ガラテヤ人への手紙 2:20; ローマ人への手紙 14:7–9; マタイの福音書 10:37–38"> というのは、キリストの愛が私たちを取り囲んでいるからです。私たちはこう考えました。ひとりの人がすべての人のために死んだ以上、すべての人が死んだのです。</span>
<span className="v" id="v15" data-v="15" data-xref="ローマ人への手紙 14:7–9; ペテロの手紙第一 4:2–4; ペテロの手紙第一 1:14–15"> また、キリストがすべての人のために死なれたのは、生きている人々が、もはや自分のためにではなく、自分のために死んでよみがえった方のために生きるためなのです。</span>
<span className="v" id="v16" data-v="16" data-xref="コロサイ人への手紙 3:11; ピリピ人への手紙 3:7–8; ヨハネの福音書 6:63"> ですから、私たちは今後、人間的な標準で人を知ろうとはしません。かつては人間的な標準でキリストを知っていたとしても、今はもうそのような知り方はしません。</span>
<span className="v" id="v17" data-v="17" data-xref="Ezekiel 36:26; エペソ人への手紙 4:22–24; Isaiah 43:18–19"> だれでもキリストのうちにあるなら、その人は新しく造られた者です。古いものは過ぎ去って、見よ、すべてが新しくなりました。</span>
<span className="v" id="v18" data-v="18" data-xref="コロサイ人への手紙 1:20–21; コリント人への手紙第二 5:19–20; ローマ人への手紙 5:10–11"> これらのことはすべて、神から出ているのです。神は、キリストによって、私たちをご自分と和解させ、また和解の務めを私たちに与えてくださいました。</span>
<span className="v" id="v19" data-v="19" data-xref="Isaiah 43:25; Isaiah 44:22; ヨハネの手紙第一 2:1–2"> すなわち、神は、キリストにあって、この世をご自分と和解させ、違反行為の責めを人々に負わせないで、和解のことばを私たちにゆだねられたのです。</span>
<span className="v" id="v20" data-v="20" data-xref="エペソ人への手紙 6:20; ルカの福音書 14:23; Malachi 2:7"> こういうわけで、私たちはキリストの使節なのです。ちょうど神が私たちを通して懇願しておられるようです。私たちは、キリストに代わって、あなたがたに願います。神の和解を受け入れなさい。</span>
<span className="v" id="v21" data-v="21" data-xref="ペテロの手紙第一 2:22–24; ペテロの手紙第一 3:18; ローマ人への手紙 5:19"> 神は、罪を知らない方を、私たちの代わりに罪とされました。それは、私たちが、この方にあって、神の義となるためです。</span>

<span className="v" id="v1" data-v="1" data-xref="テモテへの手紙第二 1:1; ピリピ人への手紙 1:1; エペソ人への手紙 1:1"> 神のみこころによるキリスト・イエスの使徒パウロ、および兄弟テモテから、コリントにある神の教会、ならびにアカヤ全土にいるすべての聖徒たちへ。</span>
<span className="v" id="v2" data-v="2" data-xref="ローマ人への手紙 1:7; エペソ人への手紙 6:23; ピリピ人への手紙 1:2"> 私たちの父なる神と主イエス・キリストから、恵みと平安があなたがたの上にありますように。</span>
<span className="v" id="v3" data-v="3" data-xref="エペソ人への手紙 1:3; ペテロの手紙第一 1:3; ローマ人への手紙 15:5–6"> 私たちの主イエス・キリストの父なる神、慈愛の父、すべての慰めの神がほめたたえられますように。</span>
<span className="v" id="v4" data-v="4" data-xref="テサロニケ人への手紙第一 5:11; Isaiah 51:12; テサロニケ人への手紙第二 2:16–17"> 神は、どのような苦しみのときにも、私たちを慰めてくださいます。こうして、私たちも、自分自身が神から受ける慰めによって、どのような苦しみの中にいる人をも慰めることができるのです。</span>
<span className="v" id="v5" data-v="5" data-xref="コロサイ人への手紙 1:24; ピリピ人への手紙 3:10; コリント人への手紙第二 4:10–11"> それは、私たちにキリストの苦難があふれているように、慰めもまたキリストによってあふれているからです。</span>
<span className="v" id="v6" data-v="6" data-xref="テモテへの手紙第二 2:10; コリント人への手紙第二 1:4; コリント人への手紙第二 4:15–18"> もし私たちが苦しみに会うなら、それはあなたがたの慰めと救いのためです。もし私たちが慰めを受けるなら、それもあなたがたの慰めのためで、その慰めは、私たちが受けている苦難と同じ苦難に耐え抜く力をあなたがたに与えるのです。</span>
<span className="v" id="v7" data-v="7" data-xref="ローマ人への手紙 8:17–18; テサロニケ人への手紙第二 1:4–7; ヤコブの手紙 1:12"> 私たちがあなたがたについて抱いている望みは、動くことがありません。なぜなら、あなたがたが私たちと苦しみをともにしているように、慰めをもともにしていることを、私たちは知っているからです。</span>
<span className="v" id="v8" data-v="8" data-xref="コリント人への手紙第二 4:7–12; コリント人への手紙第一 15:32; コリント人への手紙第一 4:8"> 兄弟たちよ。私たちがアジヤで会った苦しみについて、ぜひ知っておいてください。私たちは、非常に激しい、耐えられないほどの圧迫を受け、ついにいのちさえも危くなり、</span>
<span className="v" id="v9" data-v="9" data-xref="コリント人への手紙第二 3:5; ヘブル人への手紙 11:19; コリント人への手紙第二 4:7"> ほんとうに、自分の心の中で死を覚悟しました。これは、もはや自分自身を頼まず、死者をよみがえらせてくださる神により頼む者となるためでした。</span>
<span className="v" id="v10" data-v="10" data-xref="テモテへの手紙第一 4:10; Psalms 34:19; ペテロの手紙第二 2:9"> ところが神は、これほどの大きな死の危険から、私たちを救い出してくださいました。また将来も救い出してくださいます。なおも救い出してくださるという望みを、私たちはこの神に置いているのです。</span>
<span className="v" id="v11" data-v="11" data-xref="ピリピ人への手紙 1:19; コリント人への手紙第二 4:15; 使徒の働き 12:5"> あなたがたも祈りによって、私たちを助けて協力してくださるでしょう。それは、多くの人々の祈りにより私たちに与えられた恵みについて、多くの人々が感謝をささげるようになるためです。</span>
<span className="v" id="v12" data-v="12" data-xref="コリント人への手紙第二 2:17; コリント人への手紙第一 2:13; ヤコブの手紙 3:13–18"> 私たちがこの世の中で、特にあなたがたに対して、きよさと神から来る誠実さとをもって、人間的な知恵によらず、神の恵みによって行動していることは、私たちの良心のあかしするところであって、これこそ私たちの誇りです。</span>
<span className="v" id="v13" data-v="13" data-xref="コリント人への手紙第二 4:2; ピレモンへの手紙 1:6; コリント人への手紙第二 13:6"> 私たちは、あなたがたへの手紙で、あなたがたが読んで理解できること以外は何も書いていません。そして私は、あなたがたが十分に理解してくれることを望みます。</span>
<span className="v" id="v14" data-v="14" data-xref="ピリピ人への手紙 2:16; コリント人への手紙第一 1:8; テサロニケ人への手紙第一 2:19–20"> あなたがたは、ある程度は、私たちを理解しているのですから、私たちの主イエスの日には、あなたがたが私たちの誇りであるように、私たちもあなたがたの誇りであるということを、さらに十分に理解してくださるよう望むのです。</span>
<span className="v" id="v15" data-v="15" data-xref="コリント人への手紙第一 4:19; ローマ人への手紙 1:11; ローマ人への手紙 15:29"> この確信をもって、私は次のような計画を立てました。まず初めにあなたがたのところへ行くことによって、あなたがたが恵みを二度受けられるようにしようとしたのです。</span>
<span className="v" id="v16" data-v="16" data-xref="コリント人への手紙第一 16:5–7; 使徒の働き 21:5; 使徒の働き 19:21–22"> すなわち、あなたがたのところを通ってマケドニヤに行き、そしてマケドニヤから再びあなたがたのところに帰り、あなたがたに送られてユダヤに行きたいと思ったのです。</span>
<span className="v" id="v17" data-v="17" data-xref="マタイの福音書 5:37; ヤコブの手紙 5:12; コリント人への手紙第二 10:2–3"> そういうわけですから、この計画を立てた私が、どうして軽率でありえたでしょう。それとも、私の計画は人間的な計画であって、私にとっては、「しかり、しかり。」は同時に、「否、否。」なのでしょうか。</span>
<span className="v" id="v18" data-v="18" data-xref="コリント人への手紙第一 1:9; ヨハネの黙示録 3:7; ヨハネの福音書 7:28"> しかし、神の真実にかけて言いますが、あなたがたに対する私たちのことばは、「しかり。」と言って、同時に「否。」と言うようなものではありません。</span>
<span className="v" id="v19" data-v="19" data-xref="ヘブル人への手紙 13:8; ヨハネの黙示録 1:17; ヨハネの手紙第二 1:9"> 私たち、すなわち、私とシルワノとテモテとが、あなたがたに宣べ伝えた神の子キリスト・イエスは、「しかり。」と同時に「否。」であるような方ではありません。この方には「しかり。」だけがあるのです。</span>
<span className="v" id="v20" data-v="20" data-xref="ヨハネの手紙第一 2:24–25; ガラテヤ人への手紙 3:22; ヨハネの黙示録 7:12"> 神の約束はことごとく、この方において「しかり。」となりました。それで私たちは、この方によって「アーメン。」と言い、神に栄光を帰するのです。</span>
<span className="v" id="v21" data-v="21" data-xref="ヨハネの手紙第一 2:27; ペテロの手紙第一 5:10; ヨハネの手紙第一 2:20"> 私たちをあなたがたといっしょにキリストのうちに堅く保ち、私たちに油を注がれた方は神です。</span>
<span className="v" id="v22" data-v="22" data-xref="エペソ人への手紙 4:30; コリント人への手紙第二 5:5; エペソ人への手紙 1:13–14"> 神はまた、確認の印を私たちに押し、保証として、御霊を私たちの心に与えてくださいました。</span>
<span className="v" id="v23" data-v="23" data-xref="ガラテヤ人への手紙 1:20; コリント人への手紙第一 4:21; ローマ人への手紙 1:9"> 私はこのいのちにかけ、神を証人にお呼びして言います。私がまだコリントへ行かないでいるのは、あなたがたに対する思いやりのためです。</span>
<span className="v" id="v24" data-v="24" data-xref="ペテロの手紙第一 5:3; コリント人への手紙第一 15:1; ピリピ人への手紙 1:25–26"> 私たちは、あなたがたの信仰を支配しようとする者ではなく、あなたがたの喜びのために働く協力者です。あなたがたは、信仰に堅く立っているからです。</span>

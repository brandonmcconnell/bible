<span className="v" id="v1" data-v="1" data-xref="テサロニケ人への手紙第一 4:7; ペテロの手紙第一 2:11; Proverbs 8:13"> 愛する者たち。私たちはこのような約束を与えられているのですから、いっさいの霊肉の汚れから自分をきよめ、神を恐れかしこんできよきを全うしようではありませんか。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="使徒の働き 20:33; コリント人への手紙第二 6:12–13; コリント人への手紙第二 11:9"> 私たちに対して心を開いてください。私たちは、だれにも不正をしたことがなく、だれをもそこなったことがなく、だれからも利をむさぼったことがありません。</span>
<span className="v" id="v3" data-v="3" data-xref="コリント人への手紙第二 6:11–12; テサロニケ人への手紙第一 2:8; コリント人への手紙第二 11:11"> 責めるためにこう言うのではありません。前にも言ったように、あなたがたは、私たちとともに死に、ともに生きるために、私たちの心のうちにあるのです。</span>
<span className="v" id="v4" data-v="4" data-xref="コリント人への手紙第二 1:4; コリント人への手紙第二 3:12; ヤコブの手紙 1:2"> 私のあなたがたに対する信頼は大きいのであって、私はあなたがたを大いに誇りとしています。私は慰めに満たされ、どんな苦しみの中にあっても喜びに満ちあふれています。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="コリント人への手紙第二 2:13; Deuteronomy 32:25; 使徒の働き 20:1"> マケドニヤに着いたとき、私たちの身には少しの安らぎもなく、さまざまの苦しみに会って、外には戦い、うちには恐れがありました。</span>
<span className="v" id="v6" data-v="6" data-xref="コリント人への手紙第二 1:3–4; テサロニケ人への手紙第二 2:16–17; コリント人への手紙第二 7:13"> しかし、気落ちした者を慰めてくださる神は、テトスが来たことによって、私たちを慰めてくださいました。</span>
<span className="v" id="v7" data-v="7" data-xref="コリント人への手紙第二 5:2; ユダの手紙 1:3; コリント人への手紙第二 8:16"> ただテトスが来たことばかりでなく、彼があなたがたから受けた慰めによっても、私たちは慰められたのです。あなたがたが私を慕っていること、嘆き悲しんでいること、また私に対して熱意を持っていてくれることを知らされて、私はますます喜びにあふれました。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨハネの黙示録 3:19; Jeremiah 20:7–9; マタイの福音書 26:21–22"> あの手紙によってあなたがたを悲しませたけれども、私はそれを悔いていません。あの手紙がしばらくの間であったにしろあなたがたを悲しませたのを見て、悔いたけれども、</span>
<span className="v" id="v9" data-v="9" data-xref="ルカの福音書 15:7; Jeremiah 31:18–20; コリント人への手紙第二 7:10–11"> 今は喜んでいます。あなたがたが悲しんだからではなく、あなたがたが悲しんで悔い改めたからです。あなたがたは神のみこころに添って悲しんだので、私たちのために何の害も受けなかったのです。</span>
<span className="v" id="v10" data-v="10" data-xref="使徒の働き 3:19; 使徒の働き 11:18; テモテへの手紙第二 2:25–26"> 神のみこころに添った悲しみは、悔いのない、救いに至る悔い改めを生じさせますが、世の悲しみは死をもたらします。</span>
<span className="v" id="v11" data-v="11" data-xref="ローマ人への手紙 14:18; テモテへの手紙第一 5:21–22; テモテへの手紙第二 2:15"> ご覧なさい。神のみこころに添ったその悲しみが、あなたがたのうちに、どれほどの熱心を起こさせたことでしょう。また、弁明、憤り、恐れ、慕う心、熱意を起こさせ、処罰を断行させたことでしょう。あの問題について、あなたがたは、自分たちがすべての点で潔白であることを証明したのです。</span>
<span className="v" id="v12" data-v="12" data-xref="コリント人への手紙第二 2:9; テモテへの手紙第一 3:5; コリント人への手紙第二 2:17"> ですから、私はあなたがたに手紙を書きましたが、それは悪を行なった人のためでもなく、その被害者のためでもなくて、私たちに対するあなたがたの熱心が、神の御前に明らかにされるためであったのです。</span>
<span className="v" id="v13" data-v="13" data-xref="コリント人への手紙第二 7:6; コリント人への手紙第一 12:26; コリント人への手紙第一 16:13"> こういうわけですから、私たちは慰めを受けました。<br />この慰めの上にテトスの喜びが加わって、私たちはなおいっそう喜びました。テトスの心が、あなたがたすべてによって安らぎを与えられたからです。</span>
<span className="v" id="v14" data-v="14" data-xref="コリント人への手紙第二 7:4; テサロニケ人への手紙第二 1:4; コリント人への手紙第二 1:18–20"> 私はテトスに、あなたがたのことを少しばかり誇りましたが、そのことで恥をかかずに済みました。というのは、私たちがあなたがたに語ったことがすべて真実であったように、テトスに対して誇ったことも真実となったからです。</span>
<span className="v" id="v15" data-v="15" data-xref="ピリピ人への手紙 2:12; コリント人への手紙第二 2:9; ヨハネの手紙第一 3:17"> 彼は、あなたがたがみなよく言うことを聞き、恐れおののいて、自分を迎えてくれたことを思い出して、あなたがたへの愛情をますます深めています。</span>
<span className="v" id="v16" data-v="16" data-xref="コリント人への手紙第二 2:3; ピレモンへの手紙 1:8; ピレモンへの手紙 1:21"> 私は、あなたがたに全幅の信頼を寄せることができるのを喜んでいます。</span>

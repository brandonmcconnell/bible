<span className="v" id="v1" data-v="1" data-xref="Proverbs 24:23; ヤコブの手紙 2:9; Leviticus 19:15"> 私の兄弟たち。あなたがたは私たちの栄光の主イエス・キリストを信じる信仰を持っているのですから、人をえこひいきしてはいけません。</span>
<span className="v" id="v2" data-v="2" data-xref="ルカの福音書 15:22; Esther 3:10; Esther 8:2"> あなたがたの会堂に、金の指輪をはめ、りっぱな服装をした人がはいって来、またみすぼらしい服装をした貧しい人もはいって来たとします。</span>
<span className="v" id="v3" data-v="3" data-xref="コリント人への手紙第二 8:9; ヤコブの手紙 2:6; ルカの福音書 7:44–46"> あなたがたが、りっぱな服装をした人に目を留めて、「あなたは、こちらの良い席におすわりなさい。」と言い、貧しい人には、「あなたは、そこで立っていなさい。でなければ、私の足もとにすわりなさい。」と言うとすれば、</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネの福音書 7:24; Job 34:19; マタイの福音書 7:1–5"> あなたがたは、自分たちの間で差別を設け、悪い考え方で人をさばく者になったのではありませんか。</span>
<span className="v" id="v5" data-v="5" data-xref="マタイの福音書 5:3; ルカの福音書 6:20; ヨハネの黙示録 2:9"> よく聞きなさい。愛する兄弟たち。神は、この世の貧しい人たちを選んで信仰に富む者とし、神を愛する者に約束されている御国を相続する者とされたではありませんか。</span>
<span className="v" id="v6" data-v="6" data-xref="Proverbs 17:5; コリント人への手紙第一 11:22; Proverbs 14:31"> それなのに、あなたがたは貧しい人を軽蔑したのです。あなたがたをしいたげるのは富んだ人たちではありませんか。また、あなたがたを裁判所に引いて行くのも彼らではありませんか。</span>
<span className="v" id="v7" data-v="7" data-xref="ピリピ人への手紙 2:9–11; ヨハネの黙示録 13:5–6; テモテへの手紙第一 1:13"> あなたがたがその名で呼ばれている尊い御名をけがすのも彼らではありませんか。</span>
<span className="v" id="v8" data-v="8" data-xref="Leviticus 19:18; ガラテヤ人への手紙 5:14; マタイの福音書 22:39"> もし、ほんとうにあなたがたが、聖書に従って、「あなたの隣人をあなた自身のように愛せよ。」という最高の律法を守るなら、あなたがたの行ないはりっぱです。</span>
<span className="v" id="v9" data-v="9" data-xref="Leviticus 19:15; ヤコブの手紙 2:1–4; ヨハネの手紙第一 3:4"> しかし、もし人をえこひいきするなら、あなたがたは罪を犯しており、律法によって違反者として責められます。</span>
<span className="v" id="v10" data-v="10" data-xref="ガラテヤ人への手紙 3:10; マタイの福音書 5:18–19; Deuteronomy 27:26"> 律法全体を守っても、一つの点でつまずくなら、その人はすべてを犯した者となったのです。</span>
<span className="v" id="v11" data-v="11" data-xref="Exodus 20:13–14; マタイの福音書 5:21–28; Deuteronomy 5:17–18"> なぜなら、「姦淫してはならない。」と言われた方は、「殺してはならない。」とも言われたからです。そこで、姦淫しなくても人殺しをすれば、あなたは律法の違反者となったのです。</span>
<span className="v" id="v12" data-v="12" data-xref="ヤコブの手紙 1:25; ヤコブの手紙 2:8; ペテロの手紙第二 1:4–8"> 自由の律法によってさばかれる者らしく語り、またそのように行ないなさい。</span>
<span className="v" id="v13" data-v="13" data-xref="マタイの福音書 5:7; マタイの福音書 6:15; Proverbs 21:13"> あわれみを示したことのない者に対するさばきは、あわれみのないさばきです。あわれみは、さばきに向かって勝ち誇るのです。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="マタイの福音書 7:26–27; マタイの福音書 7:21–23; ヤコブの手紙 1:22–25"> 私の兄弟たち。だれかが自分には信仰があると言っても、その人に行ないがないなら、何の役に立ちましょう。そのような信仰がその人を救うことができるでしょうか。</span>
<span className="v" id="v15" data-v="15" data-xref="ルカの福音書 3:11; マタイの福音書 25:35–40; Isaiah 58:7"> もし、兄弟また姉妹のだれかが、着る物がなく、また、毎日の食べ物にもこと欠いているようなときに、</span>
<span className="v" id="v16" data-v="16" data-xref="Proverbs 3:27–28; ヨハネの手紙第一 3:16–18; マタイの福音書 25:42–45"> あなたがたのうちだれかが、その人たちに、「安心して行きなさい。暖かになり、十分に食べなさい。」と言っても、もしからだに必要な物を与えないなら、何の役に立つでしょう。</span>
<span className="v" id="v17" data-v="17" data-xref="ヤコブの手紙 2:26; ペテロの手紙第二 1:5–9; ヤコブの手紙 2:19–20"> それと同じように、信仰も、もし行ないがなかったなら、それだけでは、死んだものです。</span>
<span className="v" id="v18" data-v="18" data-xref="ヤコブの手紙 3:13; ヤコブの手紙 2:14; ガラテヤ人への手紙 5:6"> さらに、こう言う人もあるでしょう。「あなたは信仰を持っているが、私は行ないを持っています。行ないのないあなたの信仰を、私に見せてください。私は、行ないによって、私の信仰をあなたに見せてあげます。」</span>
<span className="v" id="v19" data-v="19" data-xref="ルカの福音書 4:34; マルコの福音書 1:24; マタイの福音書 8:29"> あなたは、神はおひとりだと信じています。りっぱなことです。ですが、悪霊どももそう信じて、身震いしています。</span>
<span className="v" id="v20" data-v="20" data-xref="ヤコブの手紙 2:17; ヤコブの手紙 2:26; Proverbs 12:11"> ああ愚かな人よ。あなたは行ないのない信仰がむなしいことを知りたいと思いますか。</span>
<span className="v" id="v21" data-v="21" data-xref="Genesis 22:16–18; Genesis 22:9–12; ヨハネの福音書 8:39"> 私たちの父アブラハムは、その子イサクを祭壇にささげたとき、行ないによって義と認められたではありませんか。</span>
<span className="v" id="v22" data-v="22" data-xref="テサロニケ人への手紙第一 1:3; ヘブル人への手紙 11:17–19; ガラテヤ人への手紙 5:6"> あなたの見ているとおり、彼の信仰は彼の行ないとともに働いたのであり、信仰は行ないによって全うされ、</span>
<span className="v" id="v23" data-v="23" data-xref="Genesis 15:6; Isaiah 41:8; 2 Chronicles 20:7"> そして、「アブラハムは神を信じ、その信仰が彼の義とみなされた。」という聖書のことばが実現し、彼は神の友と呼ばれたのです。</span>
<span className="v" id="v24" data-v="24" data-xref="ヤコブの手紙 2:21–22; ヤコブの手紙 2:15–18; Psalms 60:12"> 人は行ないによって義と認められるのであって、信仰だけによるのではないことがわかるでしょう。</span>
<span className="v" id="v25" data-v="25" data-xref="ヘブル人への手紙 11:31; Joshua 6:22–25; Joshua 2:19–21"> 同様に、遊女ラハブも、使者たちを招き入れ、別の道から送り出したため、その行ないによって義と認められたではありませんか。</span>
<span className="v" id="v26" data-v="26" data-xref="ヤコブの手紙 2:20; ヤコブの手紙 2:17; ヤコブの手紙 2:14"> たましいを離れたからだが、死んだものであるのと同様に、行ないのない信仰は、死んでいるのです。</span>

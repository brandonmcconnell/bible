<span className="v" id="v1" data-v="1" data-xref="ルカの福音書 12:47–48; テモテへの手紙第一 1:7; ペテロの手紙第一 5:3"> 私の兄弟たち。多くの者が教師になってはいけません。ご承知のように、私たち教師は、格別きびしいさばきを受けるのです。</span>
<span className="v" id="v2" data-v="2" data-xref="ヤコブの手紙 1:26; Proverbs 13:3; ペテロの手紙第一 3:10"> 私たちはみな、多くの点で失敗をするものです。もし、ことばで失敗をしない人がいたら、その人は、からだ全体もりっぱに制御できる完全な人です。</span>
<span className="v" id="v3" data-v="3" data-xref="Psalms 32:9; Psalms 39:1; ヤコブの手紙 1:26"> 馬を御するために、くつわをその口にかけると、馬のからだ全体を引き回すことができます。</span>
<span className="v" id="v4" data-v="4" data-xref="Psalms 107:25–27; マタイの福音書 8:24; 使徒の働き 27:14–38"> また、船を見なさい。あのように大きな物が、強い風に押されているときでも、ごく小さなかじによって、かじを取る人の思いどおりの所へ持って行かれるのです。</span>
<span className="v" id="v5" data-v="5" data-xref="Proverbs 18:21; Jeremiah 9:3–8; Proverbs 12:18"> 同様に、舌も小さな器官ですが、大きなことを言って誇るのです。ご覧なさい。あのように小さい火があのような大きい森を燃やします。</span>
<span className="v" id="v6" data-v="6" data-xref="Psalms 120:2–3; Proverbs 16:27; マルコの福音書 7:15"> 舌は火であり、不義の世界です。舌は私たちの器官の一つですが、からだ全体を汚し、人生の車輪を焼き、そしてゲヘナの火によって焼かれます。</span>
<span className="v" id="v7" data-v="7" data-xref="マルコの福音書 5:4"> どのような種類の獣も鳥も、はうものも海の生き物も、人類によって制せられるし、すでに制せられています。</span>
<span className="v" id="v8" data-v="8" data-xref="ローマ人への手紙 3:13; Psalms 140:3; Psalms 55:21"> しかし、舌を制御することは、だれにもできません。それは少しもじっとしていない悪であり、死の毒に満ちています。</span>
<span className="v" id="v9" data-v="9" data-xref="Psalms 10:7; Genesis 1:26–27; Psalms 62:4"> 私たちは、舌をもって、主であり父である方をほめたたえ、同じ舌をもって、神にかたどって造られた人をのろいます。</span>
<span className="v" id="v10" data-v="10" data-xref="ローマ人への手紙 12:14; ペテロの手紙第一 3:9; コリント人への手紙第一 3:3"> 賛美とのろいが同じ口から出て来るのです。私の兄弟たち。このようなことは、あってはなりません。</span>
<span className="v" id="v11" data-v="11"> 泉が甘い水と苦い水を同じ穴からわき上がらせるというようなことがあるでしょうか。</span>
<span className="v" id="v12" data-v="12" data-xref="ルカの福音書 6:43–44; マタイの福音書 12:33; マタイの福音書 7:16–20"> 私の兄弟たち。いちじくの木がオリーブの実をならせたり、ぶどうの木がいちじくの実をならせたりするようなことは、できることでしょうか。塩水が甘い水を出すこともできないことです。</span>
<span className="v" id="v13" data-v="13" data-xref="ガラテヤ人への手紙 5:23; ヤコブの手紙 3:17; マタイの福音書 5:5"> あなたがたのうちで、知恵のある、賢い人はだれでしょうか。その人は、その知恵にふさわしい柔和な行ないを、良い生き方によって示しなさい。</span>
<span className="v" id="v14" data-v="14" data-xref="ヤコブの手紙 3:16; コリント人への手紙第一 13:4; ピリピ人への手紙 2:3"> しかし、もしあなたがたの心の中に、苦いねたみと敵対心があるならば、誇ってはいけません。真理に逆らって偽ることになります。</span>
<span className="v" id="v15" data-v="15" data-xref="ヤコブの手紙 3:17; ヤコブの手紙 1:17; コリント人への手紙第一 3:19"> そのような知恵は、上から来たものではなく、地に属し、肉に属し、悪霊に属するものです。</span>
<span className="v" id="v16" data-v="16" data-xref="ヤコブの手紙 3:14; コリント人への手紙第一 3:3; コリント人への手紙第一 14:33"> ねたみや敵対心のあるところには、秩序の乱れや、あらゆる邪悪な行ないがあるからです。</span>
<span className="v" id="v17" data-v="17" data-xref="ガラテヤ人への手紙 5:22–23; Proverbs 2:6; コリント人への手紙第一 13:4–7"> しかし、上からの知恵は、第一に純真であり、次に平和、寛容、温順であり、また、あわれみと良い実とに満ち、えこひいきがなく、見せかけのないものです。</span>
<span className="v" id="v18" data-v="18" data-xref="マタイの福音書 5:9; Hosea 10:12; ピリピ人への手紙 1:11"> 義の実を結ばせる種は、平和をつくる人によって平和のうちに蒔かれます。</span>

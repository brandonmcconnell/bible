<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="テモテへの手紙第二 3:1–9; ペテロの手紙第二 2:1; コリント人への手紙第二 11:13–15"> しかし、御霊が明らかに言われるように、後の時代になると、ある人たちは惑わす霊と悪霊の教えとに心を奪われ、信仰から離れるようになります。</span>
<span className="v" id="v2" data-v="2" data-xref="エペソ人への手紙 4:19; 使徒の働き 20:30; ローマ人への手紙 16:18"> それは、うそつきどもの偽善によるものです。彼らは良心が麻痺しており、</span>
<span className="v" id="v3" data-v="3" data-xref="ヘブル人への手紙 13:4; テモテへの手紙第一 4:4; ローマ人への手紙 14:6"> 結婚することを禁じたり、食物を断つことを命じたりします。しかし食物は、信仰があり、真理を知っている人が感謝して受けるようにと、神が造られた物です。</span>
<span className="v" id="v4" data-v="4" data-xref="ローマ人への手紙 14:20; コリント人への手紙第一 10:25; ローマ人への手紙 14:14"> 神が造られた物はみな良い物で、感謝して受けるとき、捨てるべき物は何一つありません。</span>
<span className="v" id="v5" data-v="5" data-xref="テモテへの手紙第一 4:3; コリント人への手紙第一 7:14; ルカの福音書 4:4"> 神のことばと祈りとによって、きよめられるからです。</span>
<span className="v" id="v6" data-v="6" data-xref="テトスへの手紙 2:7–10; コロサイ人への手紙 3:16; マタイの福音書 13:52"> これらのことを兄弟たちに教えるなら、あなたはキリスト・イエスのりっぱな奉仕者になります。信仰のことばと、あなたが従って来た良い教えのことばとによって養われているからです。</span>
<span className="v" id="v7" data-v="7" data-xref="テモテへの手紙第二 2:16; テトスへの手紙 2:12; テモテへの手紙第一 1:4"> 俗悪な、年寄り女がするような空想話を避けなさい。むしろ、敬虔のために自分を鍛練しなさい。</span>
<span className="v" id="v8" data-v="8" data-xref="マタイの福音書 6:33; テモテへの手紙第一 6:6; Psalms 37:3–4"> 肉体の鍛練もいくらかは有益ですが、今のいのちと未来のいのちが約束されている敬虔は、すべてに有益です。</span>
<span className="v" id="v9" data-v="9" data-xref="テモテへの手紙第一 1:15"> このことばは、真実であり、そのまま受け入れるに値することばです。</span>
<span className="v" id="v10" data-v="10" data-xref="テモテへの手紙第一 2:4; ヨハネの手紙第一 2:2; テモテへの手紙第一 2:6"> 私たちはそのために労し、また苦心しているのです。それは、すべての人々、ことに信じる人々の救い主である、生ける神に望みを置いているからです。</span>
<span className="v" id="v11" data-v="11" data-xref="テモテへの手紙第一 6:2; テモテへの手紙第二 4:2; テトスへの手紙 2:15"> これらのことを命じ、また教えなさい。</span>
<span className="v" id="v12" data-v="12" data-xref="テトスへの手紙 2:7; テモテへの手紙第二 2:22; テモテへの手紙第二 2:15"> 年が若いからといって、だれにも軽く見られないようにしなさい。かえって、ことばにも、態度にも、愛にも、信仰にも、純潔にも信者の模範になりなさい。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒の働き 6:4; テトスへの手紙 2:15; テモテへの手紙第二 4:2"> 私が行くまで、聖書の朗読と勧めと教えとに専念しなさい。</span>
<span className="v" id="v14" data-v="14" data-xref="テモテへの手紙第二 1:6; ペテロの手紙第一 4:9–11; テモテへの手紙第一 1:18"> 長老たちによる按手を受けたとき、預言によって与えられた、あなたのうちにある聖霊の賜物を軽んじてはいけません。</span>
<span className="v" id="v15" data-v="15" data-xref="マタイの福音書 5:16; ピリピ人への手紙 2:15–16; Psalms 143:5"> これらの務めに心を砕き、しっかりやりなさい。そうすれば、あなたの進歩はすべての人に明らかになるでしょう。</span>
<span className="v" id="v16" data-v="16" data-xref="テトスへの手紙 1:9; テトスへの手紙 2:7; ヨハネの手紙第二 1:8–9"> 自分自身にも、教える事にも、よく気をつけなさい。あくまでそれを続けなさい。そうすれば、自分自身をも、またあなたの教えを聞く人たちをも救うことになります。</span>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="Leviticus 19:32; ペテロの手紙第一 5:5–6; テトスへの手紙 2:2"> 年寄りをしかってはいけません。むしろ、父親に対するように勧めなさい。若い人たちには兄弟に対するように、</span>
<span className="v" id="v2" data-v="2" data-xref="テモテへの手紙第一 4:12; マタイの福音書 12:50; ピリピ人への手紙 4:8"> 年とった婦人たちには母親に対するように、若い女たちには真に混じりけのない心で姉妹に対するように勧めなさい。</span>
<span className="v" id="v3" data-v="3" data-xref="Deuteronomy 27:19; 使徒の働き 6:1; Deuteronomy 10:18"> やもめの中でもほんとうのやもめを敬いなさい。</span>
<span className="v" id="v4" data-v="4" data-xref="エペソ人への手紙 6:1–3; ヨハネの福音書 19:26–27; マタイの福音書 15:4–6"> しかし、もし、やもめに子どもか孫かがいるなら、まずこれらの者に、自分の家の者に敬愛を示し、親の恩に報いる習慣をつけさせなさい。それが神に喜ばれることです。</span>
<span className="v" id="v5" data-v="5" data-xref="テモテへの手紙第一 5:3; ルカの福音書 2:37; コリント人への手紙第一 7:32"> ほんとうのやもめで、身寄りのない人は、望みを神に置いて、昼も夜も、絶えず神に願いと祈りをささげていますが、</span>
<span className="v" id="v6" data-v="6" data-xref="ヤコブの手紙 5:5; ヨハネの黙示録 18:7; ルカの福音書 15:24"> 自堕落な生活をしているやもめは、生きてはいても、もう死んだ者なのです。</span>
<span className="v" id="v7" data-v="7" data-xref="テモテへの手紙第一 4:11; テトスへの手紙 2:15; テモテへの手紙第二 4:1"> 彼女たちがそしりを受けることのないように、これらのことを命じなさい。</span>
<span className="v" id="v8" data-v="8" data-xref="ガラテヤ人への手紙 6:10; コリント人への手紙第二 12:14; ルカの福音書 11:11–13"> もしも親族、ことに自分の家族を顧みない人がいるなら、その人は信仰を捨てているのであって、不信者よりも悪いのです。</span>
<span className="v" id="v9" data-v="9" data-xref="テモテへの手紙第一 3:2; テモテへの手紙第一 5:11; ルカの福音書 2:36–37"> やもめとして名簿に載せるのは、六十歳未満の人でなく、ひとりの夫の妻であった人で、</span>
<span className="v" id="v10" data-v="10" data-xref="テモテへの手紙第一 6:18; テトスへの手紙 3:8; 使徒の働き 9:36"> 良い行ないによって認められている人、すなわち、子どもを育て、旅人をもてなし、聖徒の足を洗い、困っている人を助け、すべての良いわざに務め励んだ人としなさい。</span>
<span className="v" id="v11" data-v="11" data-xref="テモテへの手紙第一 5:14; Hosea 13:6; ヤコブの手紙 5:5"> 若いやもめは断わりなさい。というのは、彼女たちは、キリストにそむいて情欲に引かれると、結婚したがり、</span>
<span className="v" id="v12" data-v="12" data-xref="ガラテヤ人への手紙 1:6; ヤコブの手紙 3:1; コリント人への手紙第一 11:34"> 初めの誓いを捨てたという非難を受けることになるからです。</span>
<span className="v" id="v13" data-v="13" data-xref="Proverbs 20:19; テサロニケ人への手紙第二 3:6–11; 使徒の働き 20:30"> そのうえ、怠けて、家々を遊び歩くことを覚え、ただ怠けるだけでなく、うわさ話やおせっかいをして、話してはいけないことまで話します。</span>
<span className="v" id="v14" data-v="14" data-xref="テトスへの手紙 2:5; テモテへの手紙第一 6:1; テトスへの手紙 2:8"> ですから、私が願うのは、若いやもめは結婚し、子どもを産み、家庭を治め、反対者にそしる機会を与えないことです。</span>
<span className="v" id="v15" data-v="15" data-xref="ペテロの手紙第二 2:2; ユダの手紙 1:4–5; ペテロの手紙第二 2:20–22"> というのは、すでに、道を踏みはずし、サタンのあとについて行った者があるからです。</span>
<span className="v" id="v16" data-v="16" data-xref="テモテへの手紙第一 5:3–5; テモテへの手紙第一 5:8"> もし信者である婦人の身内にやもめがいたら、その人がそのやもめを助け、教会には負担をかけないようにしなさい。そうすれば、教会はほんとうのやもめを助けることができます。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="ヘブル人への手紙 13:17; テサロニケ人への手紙第一 5:12–13; ガラテヤ人への手紙 6:6"> よく指導の任に当たっている長老は、二重に尊敬を受けるにふさわしいとしなさい。みことばと教えのためにほねおっている長老は特にそうです。</span>
<span className="v" id="v18" data-v="18" data-xref="Deuteronomy 25:4; コリント人への手紙第一 9:14; コリント人への手紙第一 9:7–10"> 聖書に「穀物をこなしている牛に、くつこを掛けてはいけない。」また、「働き手が報酬を受けることは当然である。」と言われているからです。</span>
<span className="v" id="v19" data-v="19" data-xref="マタイの福音書 18:16; Deuteronomy 19:15; コリント人への手紙第二 13:1"> 長老に対する訴えは、ふたりか三人の証人がなければ、受理してはいけません。</span>
<span className="v" id="v20" data-v="20" data-xref="テモテへの手紙第二 4:2; テトスへの手紙 1:13; テモテへの手紙第一 1:20"> 罪を犯している者をすべての人の前で責めなさい。ほかの人をも恐れさせるためです。</span>
<span className="v" id="v21" data-v="21" data-xref="ペテロの手紙第二 2:4; テモテへの手紙第二 4:1; テモテへの手紙第一 6:13"> 私は、神とキリスト・イエスと選ばれた御使いたちとの前で、あなたにおごそかに命じます。これらのことを偏見なしに守り、何事もかたよらないで行ないなさい。</span>
<span className="v" id="v22" data-v="22" data-xref="エペソ人への手紙 5:11; テモテへの手紙第一 3:10; テモテへの手紙第一 3:6"> また、だれにでも軽々しく按手をしてはいけません。また、他人の罪にかかわりを持ってはいけません。自分をきよく保ちなさい。</span>
<span className="v" id="v23" data-v="23" data-xref="Psalms 104:15; Proverbs 31:4–7; テモテへの手紙第一 4:4"> これからは水ばかり飲まないで、胃のために、また、たびたび起こる病気のためにも、少量のぶどう酒を用いなさい。</span>
<span className="v" id="v24" data-v="24" data-xref="テモテへの手紙第二 4:10; 使徒の働き 8:18; ガラテヤ人への手紙 5:19–21"> ある人たちの罪は、それがさばきを受ける前から、だれの目にも明らかですが、ある人たちの罪は、あとで明らかになります。</span>
<span className="v" id="v25" data-v="25" data-xref="Proverbs 10:9; ルカの福音書 11:33; Psalms 37:5–6"> 同じように、良い行ないは、だれの目にも明らかですが、そうでないばあいでも、いつまでも隠れたままでいることはありません。</span>

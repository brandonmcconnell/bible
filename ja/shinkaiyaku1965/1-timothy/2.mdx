<span className="v" id="v1" data-v="1" data-xref="テサロニケ人への手紙第二 1:3; マタイの福音書 6:9–10; ヤコブの手紙 5:16"> そこで、まず初めに、このことを勧めます。すべての人のために、また王とすべての高い地位にある人たちのために願い、祈り、とりなし、感謝がささげられるようにしなさい。</span>
<span className="v" id="v2" data-v="2" data-xref="ペテロの手紙第一 2:9–13; Jeremiah 29:7; Ezra 6:10"> それは、私たちが敬虔に、また、威厳をもって、平安で静かな一生を過ごすためです。</span>
<span className="v" id="v3" data-v="3" data-xref="ヘブル人への手紙 13:16; テモテへの手紙第一 1:1; ペテロの手紙第一 2:20"> そうすることは、私たちの救い主である神の御前において良いことであり、喜ばれることなのです。</span>
<span className="v" id="v4" data-v="4" data-xref="Ezekiel 18:32; ペテロの手紙第二 3:9; Ezekiel 18:23"> 神は、すべての人が救われて、真理を知るようになるのを望んでおられます。</span>
<span className="v" id="v5" data-v="5" data-xref="コリント人への手紙第一 8:6; ガラテヤ人への手紙 3:20; ヘブル人への手紙 9:15"> 神は唯一です。また、神と人との間の仲介者も唯一であって、それは人としてのキリスト・イエスです。</span>
<span className="v" id="v6" data-v="6" data-xref="マタイの福音書 20:28; ペテロの手紙第一 3:18; ヨハネの手紙第一 2:1–2"> キリストは、すべての人の贖いの代価として、ご自身をお与えになりました。これが時至ってなされたあかしなのです。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒の働き 9:15; テモテへの手紙第二 1:11; ローマ人への手紙 9:1"> そのあかしのために、私は宣伝者また使徒に任じられ――私は真実を言っており、うそは言いません。――信仰と真理を異邦人に教える教師とされました。</span>
<span className="v" id="v8" data-v="8" data-xref="Psalms 134:2; Psalms 63:4; ヘブル人への手紙 10:22"> ですから、私は願うのです。男は、怒ったり言い争ったりすることなく、どこででもきよい手を上げて祈るようにしなさい。</span>
<span className="v" id="v9" data-v="9" data-xref="ペテロの手紙第一 3:3–5; テトスへの手紙 2:3–5; Psalms 149:4"> 同じように女も、つつましい身なりで、控えめに慎み深く身を飾り、はでな髪の形とか、金や真珠や高価な衣服によってではなく、</span>
<span className="v" id="v10" data-v="10" data-xref="ペテロの手紙第一 2:12; ペテロの手紙第一 3:3–5; ヨハネの黙示録 2:19"> むしろ、神を敬うと言っている女にふさわしく、良い行ないを自分の飾りとしなさい。</span>
<span className="v" id="v11" data-v="11" data-xref="コリント人への手紙第一 14:34–35; エペソ人への手紙 5:22–24; コリント人への手紙第一 11:3"> 女は、静かにして、よく従う心をもって教えを受けなさい。</span>
<span className="v" id="v12" data-v="12" data-xref="コリント人への手紙第一 14:34"> 私は、女が教えたり男を支配したりすることを許しません。ただ、黙っていなさい。</span>
<span className="v" id="v13" data-v="13" data-xref="Genesis 2:18; コリント人への手紙第一 11:8–9; Genesis 1:27"> アダムが初めに造られ、次にエバが造られたからです。</span>
<span className="v" id="v14" data-v="14" data-xref="コリント人への手紙第二 11:3; Genesis 3:6; Genesis 3:12–13"> また、アダムは惑わされなかったが、女は惑わされてしまい、あやまちを犯しました。</span>
<span className="v" id="v15" data-v="15" data-xref="テトスへの手紙 2:12; Genesis 3:15–16; ペテロの手紙第一 4:7"> しかし、女が慎みをもって、信仰と愛ときよさとを保つなら、子を産むことによって救われます。</span>

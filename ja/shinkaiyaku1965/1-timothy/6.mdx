<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="テトスへの手紙 2:5; ペテロの手紙第一 2:17–20; テトスへの手紙 2:8–10"> くびきの下にある奴隷は、自分の主人を十分に尊敬すべき人だと考えなさい。それは神の御名と教えとがそしられないためです。</span>
<span className="v" id="v2" data-v="2" data-xref="コロサイ人への手紙 4:1; テモテへの手紙第一 4:11; Genesis 16:4–5"> 信者である主人を持つ人は、主人が兄弟だからといって軽く見ず、むしろ、ますますよく仕えなさい。なぜなら、その良い奉仕から益を受けるのは信者であり、愛されている人だからです。あなたは、これらのことを教え、また勧めなさい。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="テモテへの手紙第一 1:3; ローマ人への手紙 16:17; テモテへの手紙第一 1:10"> 違ったことを教え、私たちの主イエス・キリストの健全なことばと敬虔にかなう教えとに同意しない人がいるなら、</span>
<span className="v" id="v4" data-v="4" data-xref="テモテへの手紙第二 2:23; テモテへの手紙第二 3:4; テモテへの手紙第一 3:6"> その人は高慢になっており、何一つ悟らず、疑いをかけたり、ことばの争いをしたりする病気にかかっているのです。そこから、ねたみ、争い、そしり、悪意の疑りが生じ、</span>
<span className="v" id="v5" data-v="5" data-xref="テモテへの手紙第二 3:5; テトスへの手紙 1:11; ペテロの手紙第二 2:3"> また、知性が腐ってしまって真理を失った人々、すなわち敬虔を利得の手段と考えている人たちの間には、絶え間のない紛争が生じるのです。</span>
<span className="v" id="v6" data-v="6" data-xref="ヘブル人への手紙 13:5; テモテへの手紙第一 6:8; Proverbs 16:8"> しかし、満ち足りる心を伴う敬虔こそ、大きな利益を受ける道です。</span>
<span className="v" id="v7" data-v="7" data-xref="Job 1:21; Psalms 49:17; ルカの福音書 12:20–21"> 私たちは何一つこの世に持って来なかったし、また何一つ持って出ることもできません。</span>
<span className="v" id="v8" data-v="8" data-xref="ヘブル人への手紙 13:5–6; マタイの福音書 6:11; マタイの福音書 6:25–33"> 衣食があれば、それで満足すべきです。</span>
<span className="v" id="v9" data-v="9" data-xref="ヨハネの手紙第一 2:15–17; Proverbs 15:27; テモテへの手紙第一 3:7"> 金持ちになりたがる人たちは、誘惑とわなと、また人を滅びと破滅に投げ入れる、愚かで、有害な多くの欲とに陥ります。</span>
<span className="v" id="v10" data-v="10" data-xref="Proverbs 1:19; テモテへの手紙第一 6:9; Psalms 32:10"> 金銭を愛することが、あらゆる悪の根だからです。ある人たちは、金を追い求めたために、信仰から迷い出て、非常な苦痛をもって自分を刺し通しました。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="テモテへの手紙第二 2:22; テモテへの手紙第二 3:17; テモテへの手紙第一 4:12"> しかし、神の人よ。あなたは、これらのことを避け、正しさ、敬虔、信仰、愛、忍耐、柔和を熱心に求めなさい。</span>
<span className="v" id="v12" data-v="12" data-xref="ペテロの手紙第一 5:10; テモテへの手紙第一 1:18; コリント人への手紙第一 9:25–26"> 信仰の戦いを勇敢に戦い、永遠のいのちを獲得しなさい。あなたはこのために召され、また、多くの証人たちの前でりっぱな告白をしました。</span>
<span className="v" id="v13" data-v="13" data-xref="ヨハネの福音書 18:36–37; マタイの福音書 27:11; テモテへの手紙第一 5:21"> 私は、すべてのものにいのちを与える神と、ポンテオ・ピラトに対してすばらしい告白をもってあかしされたキリスト・イエスとの御前で、あなたに命じます。</span>
<span className="v" id="v14" data-v="14" data-xref="ペテロの手紙第二 3:14; ペテロの手紙第一 1:7; テサロニケ人への手紙第一 5:23"> 私たちの主イエス・キリストの現われの時まで、あなたは命令を守り、傷のない、非難されるところのない者でありなさい。</span>
<span className="v" id="v15" data-v="15" data-xref="ヨハネの黙示録 19:16; ヨハネの黙示録 17:14; テモテへの手紙第一 1:17"> その現われを、神はご自分の良しとする時に示してくださいます。神は祝福に満ちた唯一の主権者、王の王、主の主、</span>
<span className="v" id="v16" data-v="16" data-xref="テモテへの手紙第一 1:17; ヨハネの福音書 1:18; ヨハネの手紙第一 1:5"> ただひとり死のない方であり、近づくこともできない光の中に住まわれ、人間がだれひとり見たことのない、また見ることのできない方です。誉れと、とこしえの主権は神のものです。アーメン。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="Proverbs 11:28; 使徒の働き 14:17; Proverbs 27:24"> この世で富んでいる人たちに命じなさい。高ぶらないように。また、たよりにならない富に望みを置かないように。むしろ、私たちにすべての物を豊かに与えて楽しませてくださる神に望みを置くように。</span>
<span className="v" id="v18" data-v="18" data-xref="ヘブル人への手紙 13:16; ヨハネの手紙第一 3:17; Psalms 37:3"> また、人の益を計り、良い行ないに富み、惜しまずに施し、喜んで分け与えるように。</span>
<span className="v" id="v19" data-v="19" data-xref="マタイの福音書 6:19–21; テモテへの手紙第一 6:12; テモテへの手紙第二 2:19"> また、まことのいのちを得るために、未来に備えて良い基礎を自分自身のために築き上げるように。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="コロサイ人への手紙 2:8; テモテへの手紙第二 2:16; テモテへの手紙第二 1:12–14"> テモテよ。ゆだねられたものを守りなさい。そして、俗悪なむだ話、また、まちがって「霊知」と呼ばれる反対論を避けなさい。</span>
<span className="v" id="v21" data-v="21" data-xref="テモテへの手紙第二 2:18; テモテへの手紙第一 1:6; テモテへの手紙第二 4:22"> これを公然と主張したある人たちは、信仰からはずれてしまいました。<br />恵みが、あなたがたとともにありますように。</span>
</div>

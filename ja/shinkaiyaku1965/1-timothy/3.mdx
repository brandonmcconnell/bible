<span className="v" id="v1" data-v="1" data-xref="テトスへの手紙 1:7; 使徒の働き 20:28; ペテロの手紙第一 5:2"> 「人がもし監督の職につきたいと思うなら、それはすばらしい仕事を求めることである。」ということばは真実です。</span>
<span className="v" id="v2" data-v="2" data-xref="テトスへの手紙 1:6–9; テモテへの手紙第二 2:24; ローマ人への手紙 12:13"> ですから、監督はこういう人でなければなりません。すなわち、非難されるところがなく、ひとりの妻の夫であり、自分を制し、慎み深く、品位があり、よくもてなし、教える能力があり、</span>
<span className="v" id="v3" data-v="3" data-xref="テトスへの手紙 1:7; エペソ人への手紙 5:18; テトスへの手紙 3:2"> 酒飲みでなく、暴力をふるわず、温和で、争わず、金銭に無欲で、</span>
<span className="v" id="v4" data-v="4" data-xref="テトスへの手紙 1:6; Genesis 18:19; テモテへの手紙第一 3:12"> 自分の家庭をよく治め、十分な威厳をもって子どもを従わせている人です。</span>
<span className="v" id="v5" data-v="5" data-xref="1 Samuel 3:13; エペソ人への手紙 5:24; 使徒の働き 20:28"> ――自分自身の家庭を治めることを知らない人が、どうして神の教会の世話をすることができるでしょう。――</span>
<span className="v" id="v6" data-v="6" data-xref="テモテへの手紙第一 6:4; ヘブル人への手紙 5:12–13; ペテロの手紙第一 2:2"> また、信者になったばかりの人であってはいけません。高慢になって、悪魔と同じさばきを受けることにならないためです。</span>
<span className="v" id="v7" data-v="7" data-xref="コリント人への手紙第二 8:21; テモテへの手紙第二 2:26; コロサイ人への手紙 4:5"> また、教会外の人々にも評判の良い人でなければいけません。そしりを受け、悪魔のわなに陥らないためです。</span>
<span className="v" id="v8" data-v="8" data-xref="ピリピ人への手紙 1:1; テモテへの手紙第一 5:23; 使徒の働き 6:3–6"> 執事もまたこういう人でなければなりません。謹厳で、二枚舌を使わず、大酒飲みでなく、不正な利をむさぼらず、</span>
<span className="v" id="v9" data-v="9" data-xref="テモテへの手紙第一 1:19; ヨハネの手紙第二 1:9–10; テモテへの手紙第一 1:5"> きよい良心をもって信仰の奥義を保っている人です。</span>
<span className="v" id="v10" data-v="10" data-xref="テモテへの手紙第一 5:22; テモテへの手紙第一 3:13; テトスへの手紙 1:6–7"> まず審査を受けさせなさい。そして、非難される点がなければ、執事の職につかせなさい。</span>
<span className="v" id="v11" data-v="11" data-xref="テトスへの手紙 2:3; テトスへの手紙 3:2; テモテへの手紙第一 3:2"> 婦人執事も、威厳があり、悪口を言わず、自分を制し、すべてに忠実な人でなければなりません。</span>
<span className="v" id="v12" data-v="12" data-xref="テモテへの手紙第一 3:2; テモテへの手紙第一 3:4–5; ピリピ人への手紙 1:1"> 執事は、ひとりの妻の夫であって、子どもと家庭をよく治める人でなければなりません。</span>
<span className="v" id="v13" data-v="13" data-xref="マタイの福音書 25:21; ヘブル人への手紙 6:10; 使徒の働き 21:35"> というのは、執事の務めをりっぱに果たした人は、良い地歩を占め、また、キリスト・イエスを信じる信仰について強い確信を持つことができるからです。</span>
<span className="v" id="v14" data-v="14" data-xref="コリント人への手紙第一 11:34; ピレモンへの手紙 1:22; コリント人への手紙第二 1:15–17"> 私は、近いうちにあなたのところに行きたいと思いながらも、この手紙を書いています。</span>
<span className="v" id="v15" data-v="15" data-xref="ペテロの手紙第一 2:5; エペソ人への手紙 2:21–22; テサロニケ人への手紙第一 1:9"> それは、たとい私がおそくなったばあいでも、神の家でどのように行動すべきかを、あなたが知っておくためです。神の家とは生ける神の教会のことであり、その教会は、真理の柱また土台です。</span>
<span className="v" id="v16" data-v="16" data-xref="ヨハネの福音書 1:14; ヘブル人への手紙 1:3; マルコの福音書 16:19"> 確かに偉大なのはこの敬虔の奥義です。 「キリストは肉において現われ、 霊において義と宣言され、 御使いたちに見られ、 諸国民の間に宣べ伝えられ、 世界中で信じられ、 栄光のうちに上げられた。」</span>

<span className="v" id="v1" data-v="1" data-xref="テトスへの手紙 1:3; コロサイ人への手紙 1:27; 使徒の働き 9:15"> 私たちの救い主なる神と私たちの望みなるキリスト・イエスとの命令による、キリスト・イエスの使徒パウロから、</span>
<span className="v" id="v2" data-v="2" data-xref="テトスへの手紙 1:4; テモテへの手紙第二 1:2; コリント人への手紙第一 4:14–17"> 信仰による真実のわが子テモテへ。父なる神と私たちの主なるキリスト・イエスから、恵みとあわれみと平安とがありますように。</span>
<span className="v" id="v3" data-v="3" data-xref="テモテへの手紙第一 6:3; ガラテヤ人への手紙 1:6–7; ヨハネの手紙第二 1:9–10"> 私がマケドニヤに出発するとき、あなたにお願いしたように、あなたは、エペソにずっととどまっていて、ある人たちが違った教えを説いたり、</span>
<span className="v" id="v4" data-v="4" data-xref="テモテへの手紙第一 4:7; テトスへの手紙 1:14; テトスへの手紙 3:9"> 果てしのない空想話と系図とに心を奪われたりしないように命じてください。そのようなものは、論議を引き起こすだけで、信仰による神の救いのご計画の実現をもたらすものではありません。</span>
<span className="v" id="v5" data-v="5" data-xref="テモテへの手紙第一 1:19; ガラテヤ人への手紙 5:22; テモテへの手紙第二 2:22"> この命令は、きよい心と正しい良心と偽りのない信仰とから出て来る愛を、目標としています。</span>
<span className="v" id="v6" data-v="6" data-xref="テトスへの手紙 1:10; テモテへの手紙第二 2:23–24; テトスへの手紙 3:9"> ある人たちはこの目当てを見失い、わき道にそれて無益な議論に走り、</span>
<span className="v" id="v7" data-v="7" data-xref="ローマ人への手紙 1:22; テモテへの手紙第一 6:4; ペテロの手紙第二 2:12"> 律法の教師でありたいと望みながら、自分の言っていることも、また強く主張していることについても理解していません。</span>
<span className="v" id="v8" data-v="8" data-xref="ローマ人への手紙 7:12–13; Psalms 19:7–10; ローマ人への手紙 7:16"> しかし私たちは知っています。律法は、もし次のことを知っていて正しく用いるならば、良いものです。</span>
<span className="v" id="v9" data-v="9" data-xref="ガラテヤ人への手紙 3:19; ペテロの手紙第一 4:18; ローマ人への手紙 5:20"> すなわち、律法は、正しい人のためにあるのではなく、律法を無視する不従順な者、不敬虔な罪人、汚らわしい俗物、父や母を殺す者、人を殺す者、</span>
<span className="v" id="v10" data-v="10" data-xref="コリント人への手紙第一 6:9–10; Leviticus 18:22; テモテへの手紙第二 4:3"> 不品行な者、男色をする者、人を誘拐する者、うそをつく者、偽証をする者などのため、またそのほか健全な教えにそむく事のためにあるのです。</span>
<span className="v" id="v11" data-v="11" data-xref="ガラテヤ人への手紙 2:7; テトスへの手紙 1:3; テモテへの手紙第一 6:15"> 祝福に満ちた神の、栄光の福音によれば、こうなのであって、私はその福音をゆだねられたのです。</span>
<span className="v" id="v12" data-v="12" data-xref="ピリピ人への手紙 4:13; テモテへの手紙第二 4:17; コリント人への手紙第二 12:9–10"> 私は、私を強くしてくださる私たちの主キリスト・イエスに感謝をささげています。なぜなら、キリストは、私をこの務めに任命して、私を忠実な者と認めてくださったからです。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒の働き 8:3; ペテロの手紙第一 2:10; ヘブル人への手紙 6:4–8"> 私は以前は、神をけがす者、迫害する者、暴力をふるう者でした。それでも、信じていないときに知らないでしたことなので、あわれみを受けたのです。</span>
<span className="v" id="v14" data-v="14" data-xref="テモテへの手紙第二 1:13; エペソ人への手紙 1:7–8; コリント人への手紙第一 15:10"> 私たちの主の、この恵みは、キリスト・イエスにある信仰と愛とともに、ますます満ちあふれるようになりました。</span>
<span className="v" id="v15" data-v="15" data-xref="マルコの福音書 2:17; ルカの福音書 19:10; ヨハネの福音書 3:16–17"> 「キリスト・イエスは、罪人を救うためにこの世に来られた。」ということばは、まことであり、そのまま受け入れるに値するものです。私はその罪人のかしらです。</span>
<span className="v" id="v16" data-v="16" data-xref="テモテへの手紙第一 1:13; エペソ人への手紙 2:7; ルカの福音書 7:47"> しかし、そのような私があわれみを受けたのは、イエス・キリストが、今後彼を信じて永遠のいのちを得ようとしている人々の見本にしようと、まず私に対してこの上ない寛容を示してくださったからです。</span>
<span className="v" id="v17" data-v="17" data-xref="エペソ人への手紙 3:20–21; ユダの手紙 1:25; テモテへの手紙第一 6:15–16"> どうか、世々の王、すなわち、滅びることなく、目に見えない唯一の神に、誉れと栄えとが世々限りなくありますように。アーメン。</span>
<span className="v" id="v18" data-v="18" data-xref="テモテへの手紙第一 4:14; テモテへの手紙第一 6:20; テモテへの手紙第二 4:1–3"> 私の子テモテよ。以前あなたについてなされた預言に従って、私はあなたにこの命令をゆだねます。それは、あなたがあの預言によって、信仰と正しい良心を保ち、勇敢に戦い抜くためです。</span>
<span className="v" id="v19" data-v="19" data-xref="テモテへの手紙第一 3:9; ペテロの手紙第一 3:15–16; ヨハネの黙示録 3:10"> ある人たちは、正しい良心を捨てて、信仰の破船に会いました。</span>
<span className="v" id="v20" data-v="20" data-xref="コリント人への手紙第一 5:4–5; テモテへの手紙第二 2:17; コリント人への手紙第一 11:32"> その中には、ヒメナオとアレキサンデルがいます。私は、彼らをサタンに引き渡しました。それは、神をけがしてはならないことを、彼らに学ばせるためです。</span>

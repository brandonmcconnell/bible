<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ガラテヤ人への手紙 5:7–8; コリント人への手紙第二 11:3; ガラテヤ人への手紙 1:6"> ああ愚かなガラテヤ人。十字架につけられたイエス・キリストが、あなたがたの目の前に、あんなにはっきり示されたのに、だれがあなたがたを迷わせたのですか。</span>
<span className="v" id="v2" data-v="2" data-xref="ローマ人への手紙 10:16–17; ガラテヤ人への手紙 3:14; 使徒の働き 15:8"> ただこれだけをあなたがたから聞いておきたい。あなたがたが御霊を受けたのは、律法を行なったからですか。それとも信仰をもって聞いたからですか。</span>
<span className="v" id="v3" data-v="3" data-xref="ガラテヤ人への手紙 5:4–8; ガラテヤ人への手紙 4:7–10; ヘブル人への手紙 7:16–19"> あなたがたはどこまで道理がわからないのですか。御霊で始まったあなたがたが、いま肉によって完成されるというのですか。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネの手紙第二 1:8; コリント人への手紙第一 15:2; ヘブル人への手紙 10:32–39"> あなたがたがあれほどのことを経験したのは、むだだったのでしょうか。万が一にもそんなことはないでしょうが。</span>
<span className="v" id="v5" data-v="5" data-xref="ガラテヤ人への手紙 3:2; 使徒の働き 14:9–10; 使徒の働き 19:11–12"> とすれば、あなたがたに御霊を与え、あなたがたの間で奇蹟を行なわれた方は、あなたがたが律法を行なったから、そうなさったのですか。それともあなたがたが信仰をもって聞いたからですか。</span>
<span className="v" id="v6" data-v="6" data-xref="Genesis 15:6; ローマ人への手紙 4:21–22; ヤコブの手紙 2:23"> アブラハムは神を信じ、それが彼の義とみなされました。それと同じことです。</span>
<span className="v" id="v7" data-v="7" data-xref="ローマ人への手紙 9:7–8; ガラテヤ人への手紙 3:9; ガラテヤ人への手紙 3:26–29"> ですから、信仰による人々こそアブラハムの子孫だと知りなさい。</span>
<span className="v" id="v8" data-v="8" data-xref="Genesis 12:3; Genesis 22:18; Genesis 28:14"> 聖書は、神が異邦人をその信仰によって義と認めてくださることを、前から知っていたので、アブラハムに対し、「あなたによってすべての国民が祝福される。」と前もって福音を告げたのです。</span>
<span className="v" id="v9" data-v="9" data-xref="ローマ人への手紙 4:16; ガラテヤ人への手紙 3:29; ローマ人への手紙 4:24"> そういうわけで、信仰による人々が、信仰の人アブラハムとともに、祝福を受けるのです。</span>
<span className="v" id="v10" data-v="10" data-xref="Deuteronomy 27:26; ローマ人への手紙 8:7; ローマ人への手紙 3:19–20"> というのは、律法の行ないによる人々はすべて、のろいのもとにあるからです。こう書いてあります。「律法の書に書いてある、すべてのことを堅く守って実行しなければ、だれでもみな、のろわれる。」</span>
<span className="v" id="v11" data-v="11" data-xref="Habakkuk 2:4; ローマ人への手紙 1:17; ヘブル人への手紙 10:38"> ところが、律法によって神の前に義と認められる者が、だれもいないということは明らかです。「義人は信仰によって生きる。」のだからです。</span>
<span className="v" id="v12" data-v="12" data-xref="Leviticus 18:5; ローマ人への手紙 10:5–6; Nehemiah 9:29"> しかし律法は、「信仰による。」のではありません。「律法を行なう者はこの律法によって生きる。」のです。</span>
<span className="v" id="v13" data-v="13" data-xref="ペテロの手紙第一 2:24; Deuteronomy 21:23; ヘブル人への手紙 9:12"> キリストは、私たちのためにのろわれたものとなって、私たちを律法ののろいから贖い出してくださいました。なぜなら、「木にかけられる者はすべてのろわれたものである。」と書いてあるからです。</span>
<span className="v" id="v14" data-v="14" data-xref="ガラテヤ人への手紙 3:28–29; コリント人への手紙第一 12:13; Ezekiel 36:26–27"> このことは、アブラハムへの祝福が、キリスト・イエスによって異邦人に及ぶためであり、その結果、私たちが信仰によって約束の御霊を受けるためなのです。</span>
<span className="v" id="v15" data-v="15" data-xref="ヘブル人への手紙 9:17; ローマ人への手紙 6:19; ローマ人への手紙 3:5"> 兄弟たち。人間のばあいにたとえてみましょう。人間の契約でも、いったん結ばれたら、だれもそれを無効にしたり、それにつけ加えたりはしません。</span>
<span className="v" id="v16" data-v="16" data-xref="Genesis 17:7–8; ローマ人への手紙 4:13; ルカの福音書 1:55"> ところで、約束は、アブラハムとそのひとりの子孫に告げられました。神は「子孫たちに」と言って、多数をさすことはせず、ひとりをさして、「あなたの子孫に」と言っておられます。その方はキリストです。</span>
<span className="v" id="v17" data-v="17" data-xref="ヘブル人への手紙 11:39–40; Genesis 15:13; ローマ人への手紙 4:13–14"> 私の言おうとすることはこうです。先に神によって結ばれた契約は、その後四百三十年たってできた律法によって取り消されたり、その約束が無効とされたりすることがないということです。</span>
<span className="v" id="v18" data-v="18" data-xref="ヘブル人への手紙 6:12–15; ガラテヤ人への手紙 2:21; ローマ人への手紙 4:13–16"> なぜなら、相続がもし律法によるのなら、もはや約束によるのではないからです。ところが、神は約束を通してアブラハムに相続の恵みを下さったのです。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒の働き 7:53; ローマ人への手紙 7:7–13; ヘブル人への手紙 2:2"> では、律法とは何でしょうか。それは約束をお受けになった、この子孫が来られるときまで、違反を示すためにつけ加えられたもので、御使いたちを通して仲介者の手で定められたのです。</span>
<span className="v" id="v20" data-v="20" data-xref="テモテへの手紙第一 2:5; Deuteronomy 6:4; Job 9:33"> 仲介者は一方だけに属するものではありません。しかし約束を賜わる神は唯一者です。</span>
<span className="v" id="v21" data-v="21" data-xref="ガラテヤ人への手紙 2:21; ローマ人への手紙 9:31; ローマ人への手紙 3:20–22"> とすると、律法は神の約束に反するのでしょうか。絶対にそんなことはありません。もしも、与えられた律法がいのちを与えることのできるものであったなら、義は確かに律法によるものだったでしょう。</span>
<span className="v" id="v22" data-v="22" data-xref="ローマ人への手紙 11:32; ヘブル人への手紙 9:15; ガラテヤ人への手紙 3:23"> しかし聖書は、逆に、すべての人を罪の下に閉じ込めました。それは約束が、イエス・キリストに対する信仰によって、信じる人々に与えられるためです。</span>
<span className="v" id="v23" data-v="23" data-xref="ガラテヤ人への手紙 5:18; ガラテヤ人への手紙 3:24–25; ガラテヤ人への手紙 3:19"> 信仰が現われる以前には、私たちは律法の監督の下に置かれ、閉じ込められていましたが、それは、やがて示される信仰が得られるためでした。</span>
<span className="v" id="v24" data-v="24" data-xref="ローマ人への手紙 10:4; 使徒の働き 13:38–39; ローマ人への手紙 7:24–25"> こうして、律法は私たちをキリストへ導くための私たちの養育係となりました。私たちが信仰によって義と認められるためなのです。</span>
<span className="v" id="v25" data-v="25" data-xref="ローマ人への手紙 6:14; ローマ人への手紙 7:4; ヘブル人への手紙 10:15–18"> しかし、信仰が現われた以上、私たちはもはや養育係の下にはいません。</span>
<span className="v" id="v26" data-v="26" data-xref="エペソ人への手紙 1:5; コリント人への手紙第二 6:18; ヨハネの福音書 1:12–13"> あなたがたはみな、キリスト・イエスに対する信仰によって、神の子どもです。</span>
<span className="v" id="v27" data-v="27" data-xref="ローマ人への手紙 13:14; コリント人への手紙第一 12:13; ローマ人への手紙 6:3–4"> バプテスマを受けてキリストにつく者とされたあなたがたはみな、キリストをその身に着たのです。</span>
<span className="v" id="v28" data-v="28" data-xref="コリント人への手紙第一 12:12–13; コロサイ人への手紙 3:11; ローマ人への手紙 3:29–30"> ユダヤ人もギリシヤ人もなく、奴隷も自由人もなく、男子も女子もありません。なぜなら、あなたがたはみな、キリスト・イエスにあって、一つだからです。</span>
<span className="v" id="v29" data-v="29" data-xref="エペソ人への手紙 3:6; ローマ人への手紙 9:7–8; ガラテヤ人への手紙 3:7"> もしあなたがたがキリストのものであれば、それによってアブラハムの子孫であり、約束による相続人なのです。</span>

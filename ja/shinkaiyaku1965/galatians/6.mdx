<span className="v" id="v1" data-v="1" data-xref="ローマ人への手紙 15:1; テモテへの手紙第二 2:25; テサロニケ人への手紙第二 3:15"> 兄弟たちよ。もしだれかがあやまちに陥ったなら、御霊の人であるあなたがたは、柔和な心でその人を正してあげなさい。また、自分自身も誘惑に陥らないように気をつけなさい。</span>
<span className="v" id="v2" data-v="2" data-xref="ローマ人への手紙 15:1; テサロニケ人への手紙第一 5:14; ヨハネの福音書 13:34"> 互いの重荷を負い合い、そのようにしてキリストの律法を全うしなさい。</span>
<span className="v" id="v3" data-v="3" data-xref="Proverbs 26:12; コリント人への手紙第一 8:2; コリント人への手紙第一 3:18"> だれでも、りっぱでもない自分を何かりっぱでもあるかのように思うなら、自分を欺いているのです。</span>
<span className="v" id="v4" data-v="4" data-xref="コリント人への手紙第二 13:5; Psalms 26:2; コリント人への手紙第一 11:28"> おのおの自分の行ないをよく調べてみなさい。そうすれば、誇れると思ったことも、ただ自分だけの誇りで、ほかの人に対して誇れることではないでしょう。</span>
<span className="v" id="v5" data-v="5" data-xref="Jeremiah 32:19; ローマ人への手紙 14:10–12; コリント人への手紙第二 5:10–11"> 人にはおのおの、負うべき自分自身の重荷があるのです。</span>
<span className="v" id="v6" data-v="6" data-xref="テモテへの手紙第一 5:17–18; ローマ人への手紙 15:27; Deuteronomy 12:19"> みことばを教えられる人は、教える人とすべての良いものを分け合いなさい。</span>
<span className="v" id="v7" data-v="7" data-xref="コリント人への手紙第二 9:6; Hosea 10:12; Job 4:8"> 思い違いをしてはいけません。神は侮られるような方ではありません。人は種を蒔けば、その刈り取りもすることになります。</span>
<span className="v" id="v8" data-v="8" data-xref="ローマ人への手紙 8:13; ヤコブの手紙 3:18; ペテロの手紙第二 2:19"> 自分の肉のために蒔く者は、肉から滅びを刈り取り、御霊のために蒔く者は、御霊から永遠のいのちを刈り取るのです。</span>
<span className="v" id="v9" data-v="9" data-xref="コリント人への手紙第一 15:58; テサロニケ人への手紙第二 3:13; Isaiah 40:30–31"> 善を行なうのに飽いてはいけません。失望せずにいれば、時期が来て、刈り取ることになります。</span>
<span className="v" id="v10" data-v="10" data-xref="ヘブル人への手紙 13:16; Proverbs 3:27; テサロニケ人への手紙第一 5:15"> ですから、私たちは、機会のあるたびに、すべての人に対して、特に信仰の家族の人たちに善を行ないましょう。</span>
<span className="v" id="v11" data-v="11" data-xref="コリント人への手紙第一 16:21–23; ローマ人への手紙 16:22"> ご覧のとおり、私は今こんなに大きな字で、自分のこの手であなたがたに書いています。</span>
<span className="v" id="v12" data-v="12" data-xref="ガラテヤ人への手紙 5:11; コロサイ人への手紙 2:23; 使徒の働き 15:1"> あなたがたに割礼を強制する人たちは、肉において外見を良くしたい人たちです。彼らはただ、キリストの十字架のために迫害を受けたくないだけなのです。</span>
<span className="v" id="v13" data-v="13" data-xref="ピリピ人への手紙 3:3; コリント人への手紙第一 5:6; ローマ人への手紙 2:17–25"> なぜなら、割礼を受けた人たちは、自分自身が律法を守っていません。それなのに彼らがあなたがたに割礼を受けさせようとするのは、あなたがたの肉を誇りたいためなのです。</span>
<span className="v" id="v14" data-v="14" data-xref="ローマ人への手紙 6:6; Jeremiah 9:23–24; ガラテヤ人への手紙 2:20"> しかし私には、私たちの主イエス・キリストの十字架以外に誇りとするものが決してあってはなりません。この十字架によって、世界は私に対して十字架につけられ、私も世界に対して十字架につけられたのです。</span>
<span className="v" id="v15" data-v="15" data-xref="コリント人への手紙第二 5:17; コロサイ人への手紙 3:10–11; エペソ人への手紙 2:10"> 割礼を受けているか受けていないかは、大事なことではありません。大事なのは新しい創造です。</span>
<span className="v" id="v16" data-v="16" data-xref="ガラテヤ人への手紙 3:29; ローマ人への手紙 9:6–8; ピリピ人への手紙 3:3"> どうか、この基準に従って進む人々、すなわち神のイスラエルの上に、平安とあわれみがありますように。</span>
<span className="v" id="v17" data-v="17" data-xref="コリント人への手紙第二 1:5; コロサイ人への手紙 1:24; コリント人への手紙第二 11:23–25"> これからは、だれも私を煩わさないようにしてください。私は、この身に、イエスの焼き印を帯びているのですから。</span>
<span className="v" id="v18" data-v="18" data-xref="ローマ人への手紙 16:20; テモテへの手紙第二 4:22; ピレモンへの手紙 1:25"> どうか、私たちの主イエス・キリストの恵みが、兄弟たちよ、あなたがたの霊とともにありますように。アーメン。</span>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ガラテヤ人への手紙 4:23; ガラテヤ人への手紙 4:29; Genesis 24:2–3"> ところが、相続人というものは、全財産の持ち主なのに、子どものうちは、奴隷と少しも違わず、</span>
<span className="v" id="v2" data-v="2"> 父の定めた日までは、後見人や管理者の下にあります。</span>
<span className="v" id="v3" data-v="3" data-xref="コロサイ人への手紙 2:20; コロサイ人への手紙 2:8; ガラテヤ人への手紙 4:9"> 私たちもそれと同じで、まだ小さかった時には、この世の幼稚な教えの下に奴隷となっていました。</span>
<span className="v" id="v4" data-v="4" data-xref="Isaiah 7:14; ヨハネの福音書 1:14; ローマ人への手紙 1:3"> しかし定めの時が来たので、神はご自分の御子を遣わし、この方を、女から生まれた者、また律法の下にある者となさいました。</span>
<span className="v" id="v5" data-v="5" data-xref="ヘブル人への手紙 9:15; エペソ人への手紙 1:5; ペテロの手紙第一 1:18–20"> これは律法の下にある者を贖い出すためで、その結果、私たちが子としての身分を受けるようになるためです。</span>
<span className="v" id="v6" data-v="6" data-xref="ローマ人への手紙 8:15–17; ローマ人への手紙 5:5; ローマ人への手紙 8:9"> そして、あなたがたは子であるゆえに、神は「アバ、父。」と呼ぶ、御子の御霊を、私たちの心に遣わしてくださいました。</span>
<span className="v" id="v7" data-v="7" data-xref="ローマ人への手紙 8:16–17; ガラテヤ人への手紙 3:29–2; ガラテヤ人への手紙 3:26"> ですから、あなたがたはもはや奴隷ではなく、子です。子ならば、神による相続人です。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="コリント人への手紙第一 8:4; エペソ人への手紙 2:11–12; テサロニケ人への手紙第二 1:8"> しかし、神を知らなかった当時、あなたがたは本来は神でない神々の奴隷でした。</span>
<span className="v" id="v9" data-v="9" data-xref="コリント人への手紙第一 8:3; ガラテヤ人への手紙 3:3; ローマ人への手紙 8:3"> ところが、今では神を知っているのに、いや、むしろ神に知られているのに、どうしてあの無力、無価値の幼稚な教えに逆戻りして、再び新たにその奴隷になろうとするのですか。</span>
<span className="v" id="v10" data-v="10" data-xref="コロサイ人への手紙 2:16–17; ローマ人への手紙 14:5; Leviticus 23:1–44"> あなたがたは、各種の日と月と季節と年とを守っています。</span>
<span className="v" id="v11" data-v="11" data-xref="テサロニケ人への手紙第一 3:5; ピリピ人への手紙 2:16; ガラテヤ人への手紙 2:2"> あなたがたのために私の労したことは、むだだったのではないか、と私はあなたがたのことを案じています。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="コリント人への手紙第二 2:5; 1 Kings 22:4; Genesis 34:15"> お願いです。兄弟たち。私のようになってください。私もあなたがたのようになったのですから。あなたがたは私に何一つ悪いことをしていません。</span>
<span className="v" id="v13" data-v="13" data-xref="コリント人への手紙第一 2:3; コリント人への手紙第二 12:7–10; コリント人への手紙第二 11:30"> ご承知のとおり、私が最初あなたがたに福音を伝えたのは、私の肉体が弱かったためでした。</span>
<span className="v" id="v14" data-v="14" data-xref="マタイの福音書 10:40; テサロニケ人への手紙第一 2:13; ヘブル人への手紙 13:2"> そして私の肉体には、あなたがたにとって試練となるものがあったのに、あなたがたは軽蔑したり、きらったりしないで、かえって神の御使いのように、またキリスト・イエスご自身であるかのように、私を迎えてくれました。</span>
<span className="v" id="v15" data-v="15" data-xref="ローマ人への手紙 5:2; ヨハネの手紙第一 3:16–18; コロサイ人への手紙 4:13"> それなのに、あなたがたのあの喜びは、今どこにあるのですか。私はあなたがたのためにあかししますが、あなたがたは、もしできれば自分の目をえぐり出して私に与えたいとさえ思ったではありませんか。</span>
<span className="v" id="v16" data-v="16" data-xref="Amos 5:10; Proverbs 9:8; ヨハネの福音書 8:45"> それでは、私は、あなたがたに真理を語ったために、あなたがたの敵になったのでしょうか。</span>
<span className="v" id="v17" data-v="17" data-xref="ローマ人への手紙 16:18; コリント人への手紙第二 11:13–15; ペテロの手紙第二 2:3"> あなたがたに対するあの人々の熱心は正しいものではありません。彼らはあなたがたを自分たちに熱心にならせようとして、あなたがたを福音の恵みから締め出そうとしているのです。</span>
<span className="v" id="v18" data-v="18" data-xref="ピリピ人への手紙 2:12; ヨハネの黙示録 3:19; ピリピ人への手紙 1:27"> 良いことで熱心に慕われるのは、いつであっても良いものです。それは私があなたがたといっしょにいるときだけではありません。</span>
<span className="v" id="v19" data-v="19" data-xref="エペソ人への手紙 4:13; ローマ人への手紙 8:29; ローマ人への手紙 13:14"> 私の子どもたちよ。あなたがたのうちにキリストが形造られるまで、私は再びあなたがたのために産みの苦しみをしています。</span>
<span className="v" id="v20" data-v="20" data-xref="テサロニケ人への手紙第一 2:17–18; コリント人への手紙第一 4:19–21; テサロニケ人への手紙第一 3:9"> それで、今あなたがたといっしょにいることができたら、そしてこんな語調でなく話せたらと思います。あなたがたのことをどうしたらよいかと困っているのです。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="ガラテヤ人への手紙 3:10; ガラテヤ人への手紙 3:23–24; ローマ人への手紙 7:5–6"> 律法の下にいたいと思う人たちは、私に答えてください。あなたがたは律法の言うことを聞かないのですか。</span>
<span className="v" id="v22" data-v="22" data-xref="Genesis 16:15; Genesis 21:10; Genesis 21:1–2"> そこには、アブラハムにふたりの子があって、ひとりは女奴隷から、ひとりは自由の女から生まれた、と書かれています。</span>
<span className="v" id="v23" data-v="23" data-xref="ヘブル人への手紙 11:11; ローマ人への手紙 9:7–8; ガラテヤ人への手紙 4:28–29"> 女奴隷の子は肉によって生まれ、自由の女の子は約束によって生まれたのです。</span>
<span className="v" id="v24" data-v="24" data-xref="Genesis 21:9–13; ヘブル人への手紙 10:15–18; Genesis 16:8"> このことには比喩があります。この女たちは二つの契約です。一つはシナイ山から出ており、奴隷となる子を産みます。その女はハガルです。</span>
<span className="v" id="v25" data-v="25" data-xref="ルカの福音書 19:44; 使徒の働き 1:11; ガラテヤ人への手紙 1:17"> このハガルは、アラビヤにあるシナイ山のことで、今のエルサレムに当たります。なぜなら、彼女はその子どもたちとともに奴隷だからです。</span>
<span className="v" id="v26" data-v="26" data-xref="ヘブル人への手紙 12:22; ピリピ人への手紙 3:20; Micah 4:1–2"> しかし、上にあるエルサレムは自由であり、私たちの母です。</span>
<span className="v" id="v27" data-v="27" data-xref="Isaiah 54:1–5; Psalms 113:9; Ruth 4:14–16"> すなわち、こう書いてあります。<br />「喜べ。子を産まない不妊の女よ。<br />声をあげて呼ばわれ。<br />産みの苦しみを知らない女よ。<br />夫に捨てられた女の産む子どもは、<br />夫のある女の産む子どもよりも多い。」</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="ガラテヤ人への手紙 4:23; ローマ人への手紙 9:8–9; ローマ人への手紙 4:13–18"> 兄弟たちよ。あなたがたはイサクのように約束の子どもです。</span>
<span className="v" id="v29" data-v="29" data-xref="Genesis 21:9; ローマ人への手紙 8:13; ガラテヤ人への手紙 5:11"> しかし、かつて肉によって生まれた者が、御霊によって生まれた者を迫害したように、今もそのとおりです。</span>
<span className="v" id="v30" data-v="30" data-xref="Genesis 21:10–12; ヨハネの福音書 8:35; ローマ人への手紙 8:15–17"> しかし、聖書は何と言っていますか。「奴隷の女とその子どもを追い出せ。奴隷の女の子どもは決して自由の女の子どもとともに相続人になってはならない。」</span>
<span className="v" id="v31" data-v="31" data-xref="ヨハネの福音書 8:36; ヨハネの福音書 1:12–13; ガラテヤ人への手紙 5:1"> こういうわけで、兄弟たちよ。私たちは奴隷の女の子どもではなく、自由の女の子どもです。</span>
</div>

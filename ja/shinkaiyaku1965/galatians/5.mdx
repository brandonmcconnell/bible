<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="コリント人への手紙第二 3:17; ガラテヤ人への手紙 5:13; ペテロの手紙第一 2:16"> キリストは、自由を得させるために、私たちを解放してくださいました。ですから、あなたがたは、しっかり立って、またと奴隷のくびきを負わせられないようにしなさい。</span>
<span className="v" id="v2" data-v="2" data-xref="ガラテヤ人への手紙 5:6; 使徒の働き 15:1; ローマ人への手紙 9:31–32"> よく聞いてください。このパウロがあなたがたに言います。もし、あなたがたが割礼を受けるなら、キリストは、あなたがたにとって、何の益もないのです。</span>
<span className="v" id="v3" data-v="3" data-xref="ガラテヤ人への手紙 3:10; ローマ人への手紙 2:25; ヤコブの手紙 2:10–11"> 割礼を受けるすべての人に、私は再びあかしします。その人は律法の全体を行なう義務があります。</span>
<span className="v" id="v4" data-v="4" data-xref="ローマ人への手紙 9:31–32; ペテロの手紙第二 2:20–22; ローマ人への手紙 11:6"> 律法によって義と認められようとしているあなたがたは、キリストから離れ、恵みから落ちてしまったのです。</span>
<span className="v" id="v5" data-v="5" data-xref="Psalms 130:5; テサロニケ人への手紙第一 1:10; Psalms 62:5"> 私たちは、信仰により、御霊によって、義をいただく望みを熱心に抱いているのです。</span>
<span className="v" id="v6" data-v="6" data-xref="ガラテヤ人への手紙 6:15; コリント人への手紙第一 7:19; ヤコブの手紙 2:14–26"> キリスト・イエスにあっては、割礼を受ける受けないは大事なことではなく、愛によって働く信仰だけが大事なのです。</span>
<span className="v" id="v7" data-v="7" data-xref="コリント人への手紙第一 9:24; ガラテヤ人への手紙 3:1; ヘブル人への手紙 12:1"> あなたがたはよく走っていたのに、だれがあなたがたを妨げて、真理に従わなくさせたのですか。</span>
<span className="v" id="v8" data-v="8" data-xref="ガラテヤ人への手紙 1:6; ローマ人への手紙 8:28"> そのような勧めは、あなたがたを召してくださった方から出たものではありません。</span>
<span className="v" id="v9" data-v="9" data-xref="コリント人への手紙第一 15:33; コリント人への手紙第一 5:6–7; マルコの福音書 8:15"> わずかのパン種が、こねた粉の全体を発酵させるのです。</span>
<span className="v" id="v10" data-v="10" data-xref="ガラテヤ人への手紙 5:12; コリント人への手紙第二 2:3; ガラテヤ人への手紙 1:7"> 私は主にあって、あなたがたが少しも違った考えを持っていないと確信しています。しかし、あなたがたをかき乱す者は、だれであろうと、さばきを受けるのです。</span>
<span className="v" id="v11" data-v="11" data-xref="コリント人への手紙第一 1:23; ガラテヤ人への手紙 6:12; ガラテヤ人への手紙 4:29"> 兄弟たち。もし私が今でも割礼を宣べ伝えているなら、どうして今なお迫害を受けることがありましょう。それなら、十字架のつまずきは取り除かれているはずです。</span>
<span className="v" id="v12" data-v="12" data-xref="ガラテヤ人への手紙 5:10; コリント人への手紙第一 5:13; テトスへの手紙 3:10"> あなたがたをかき乱す者どもは、いっそのこと不具になってしまうほうがよいのです。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="ペテロの手紙第一 2:16; コリント人への手紙第一 9:19; コリント人への手紙第一 8:9"> 兄弟たち。あなたがたは、自由を与えられるために召されたのです。ただ、その自由を肉の働く機会としないで、愛をもって互いに仕えなさい。</span>
<span className="v" id="v14" data-v="14" data-xref="マタイの福音書 7:12; Leviticus 19:18; ガラテヤ人への手紙 6:2"> 律法の全体は、「あなたの隣人をあなた自身のように愛せよ。」という一語をもって全うされるのです。</span>
<span className="v" id="v15" data-v="15" data-xref="コリント人への手紙第一 3:3; ヤコブの手紙 3:14–3; ガラテヤ人への手紙 5:26"> もし互いにかみ合ったり、食い合ったりしているなら、お互いの間で滅ぼされてしまいます。気をつけなさい。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="ガラテヤ人への手紙 5:24–25; ローマ人への手紙 8:12–14; ガラテヤ人への手紙 6:8"> 私は言います。御霊によって歩みなさい。そうすれば、決して肉の欲望を満足させるようなことはありません。</span>
<span className="v" id="v17" data-v="17" data-xref="ローマ人への手紙 8:13; ヨハネの福音書 3:6; ローマ人への手紙 8:5–8"> なぜなら、肉の願うことは御霊に逆らい、御霊は肉に逆らうからです。この二つは互いに対立していて、そのためあなたがたは、自分のしたいと思うことをすることができないのです。</span>
<span className="v" id="v18" data-v="18" data-xref="ローマ人への手紙 8:14; ローマ人への手紙 6:14–15; ガラテヤ人への手紙 5:25"> しかし、御霊によって導かれるなら、あなたがたは律法の下にはいません。</span>
<span className="v" id="v19" data-v="19" data-xref="コリント人への手紙第一 6:9–10; コロサイ人への手紙 3:5–8; マタイの福音書 15:18–19"> 肉の行ないは明白であって、次のようなものです。不品行、汚れ、好色、</span>
<span className="v" id="v20" data-v="20" data-xref="テトスへの手紙 3:10; コリント人への手紙第一 11:19; ヨハネの黙示録 21:8"> 偶像礼拝、魔術、敵意、争い、そねみ、憤り、党派心、分裂、分派、</span>
<span className="v" id="v21" data-v="21" data-xref="コリント人への手紙第一 6:9–10; ローマ人への手紙 8:13; ローマ人への手紙 13:13"> ねたみ、酩酊、遊興、そういった類のものです。前にもあらかじめ言ったように、私は今もあなたがたにあらかじめ言っておきます。こんなことをしている者たちが神の国を相続することはありません。</span>
<span className="v" id="v22" data-v="22" data-xref="コロサイ人への手紙 3:12–17; コリント人への手紙第一 13:4–7; ヨハネの福音書 15:5"> しかし、御霊の実は、愛、喜び、平安、寛容、親切、善意、誠実、</span>
<span className="v" id="v23" data-v="23" data-xref="テモテへの手紙第一 1:9; 使徒の働き 24:25; テトスへの手紙 2:2"> 柔和、自制です。このようなものを禁ずる律法はありません。</span>
<span className="v" id="v24" data-v="24" data-xref="ローマ人への手紙 6:6; ローマ人への手紙 13:14; ローマ人への手紙 8:13"> キリスト・イエスにつく者は、自分の肉を、さまざまの情欲や欲望とともに、十字架につけてしまったのです。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="ガラテヤ人への手紙 5:16; ローマ人への手紙 8:4–5; ローマ人への手紙 8:2"> もし私たちが御霊によって生きるのなら、御霊に導かれて、進もうではありませんか。</span>
<span className="v" id="v26" data-v="26" data-xref="ヤコブの手紙 3:14–16; ピリピ人への手紙 2:1–3; ヤコブの手紙 4:16"> 互いにいどみ合ったり、そねみ合ったりして、虚栄に走ることのないようにしましょう。</span>
</div>

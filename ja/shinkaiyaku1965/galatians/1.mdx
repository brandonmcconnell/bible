<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ガラテヤ人への手紙 1:11–12; コリント人への手紙第一 1:1; ローマ人への手紙 1:1"> 使徒となったパウロ――私が使徒となったのは、人間から出たことでなく、また人間の手を通したことでもなく、イエス・キリストと、キリストを死者の中からよみがえらせた父なる神によったのです。――</span>
<span className="v" id="v2" data-v="2" data-xref="コリント人への手紙第一 16:1; ピリピ人への手紙 4:21; 使徒の働き 16:5–6"> および私とともにいるすべての兄弟たちから、ガラテヤの諸教会へ。</span>
<span className="v" id="v3" data-v="3" data-xref="ヨハネの手紙第二 1:3; コリント人への手紙第二 13:14; ローマ人への手紙 1:7–15"> どうか、私たちの父なる神と主イエス・キリストから、恵みと平安があなたがたの上にありますように。</span>
<span className="v" id="v4" data-v="4" data-xref="マタイの福音書 20:28; ローマ人への手紙 4:25; ガラテヤ人への手紙 2:20"> キリストは、今の悪の世界から私たちを救い出そうとして、私たちの罪のためにご自身をお捨てになりました。私たちの神であり父である方のみこころによったのです。</span>
<span className="v" id="v5" data-v="5" data-xref="ローマ人への手紙 11:36; ユダの手紙 1:25; Psalms 72:19"> どうか、この神に栄光がとこしえにありますように。アーメン。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="コリント人への手紙第二 11:4; ガラテヤ人への手紙 5:7–8; Isaiah 29:13"> 私は、キリストの恵みをもってあなたがたを召してくださったその方を、あなたがたがそんなにも急に見捨てて、ほかの福音に移って行くのに驚いています。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒の働き 15:24; ローマ人への手紙 16:17–18; ガラテヤ人への手紙 5:10"> ほかの福音といっても、もう一つ別に福音があるのではありません。あなたがたをかき乱す者たちがいて、キリストの福音を変えてしまおうとしているだけです。</span>
<span className="v" id="v8" data-v="8" data-xref="コリント人への手紙第二 11:13–14; ガラテヤ人への手紙 1:9; ヨハネの黙示録 22:18–19"> しかし、私たちであろうと、天の御使いであろうと、もし私たちが宣べ伝えた福音に反することをあなたがたに宣べ伝えるなら、その者はのろわれるべきです。</span>
<span className="v" id="v9" data-v="9" data-xref="ローマ人への手紙 16:17; Proverbs 30:6; Deuteronomy 4:2"> 私たちが前に言ったように、今もう一度私は言います。もしだれかが、あなたがたの受けた福音に反することを、あなたがたに宣べ伝えているなら、その者はのろわれるべきです。</span>
<span className="v" id="v10" data-v="10" data-xref="テサロニケ人への手紙第一 2:4; 使徒の働き 5:29; エペソ人への手紙 6:6"> いま私は人に取り入ろうとしているのでしょうか。いや。神に、でしょう。あるいはまた、人の歓心を買おうと努めているのでしょうか。もし私がいまなお人の歓心を買おうとするようなら、私はキリストのしもべとは言えません。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="ガラテヤ人への手紙 1:1; コリント人への手紙第一 2:9–10; コリント人への手紙第一 11:23"> 兄弟たちよ。私はあなたがたに知らせましょう。私が宣べ伝えた福音は、人間によるものではありません。</span>
<span className="v" id="v12" data-v="12" data-xref="ガラテヤ人への手紙 1:16; コリント人への手紙第一 2:10; ガラテヤ人への手紙 1:1"> 私はそれを人間からは受けなかったし、また教えられもしませんでした。ただイエス・キリストの啓示によって受けたのです。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒の働き 8:3; コリント人への手紙第一 15:9; 使徒の働き 22:3–5"> 以前ユダヤ教徒であったころの私の行動は、あなたがたがすでに聞いているところです。私は激しく神の教会を迫害し、これを滅ぼそうとしました。</span>
<span className="v" id="v14" data-v="14" data-xref="コロサイ人への手紙 2:8; 使徒の働き 26:5; ピリピ人への手紙 3:4–6"> また私は、自分と同族で同年輩の多くの者たちに比べ、はるかにユダヤ教に進んでおり、先祖からの伝承に人一倍熱心でした。</span>
<span className="v" id="v15" data-v="15" data-xref="Jeremiah 1:5; Isaiah 49:5; Isaiah 49:1"> けれども、生まれたときから私を選び分け、恵みをもって召してくださった方が、</span>
<span className="v" id="v16" data-v="16" data-xref="マタイの福音書 16:17; エペソ人への手紙 3:5–10; エペソ人への手紙 6:12"> 異邦人の間に御子を宣べ伝えさせるために、御子を私のうちに啓示することをよしとされたとき、私はすぐに、人には相談せず、</span>
<span className="v" id="v17" data-v="17" data-xref="使徒の働き 9:20–25; コリント人への手紙第二 11:32–33; ガラテヤ人への手紙 1:18"> 先輩の使徒たちに会うためにエルサレムにも上らず、アラビヤに出て行き、またダマスコに戻りました。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="使徒の働き 9:22–23; 使徒の働き 9:26–29; 使徒の働き 22:17–18"> それから三年後に、私はケパをたずねてエルサレムに上り、彼のもとに十五日間滞在しました。</span>
<span className="v" id="v19" data-v="19" data-xref="マタイの福音書 13:55; マルコの福音書 6:3; マタイの福音書 12:46"> しかし、主の兄弟ヤコブは別として、ほかの使徒にはだれにも会いませんでした。</span>
<span className="v" id="v20" data-v="20" data-xref="ローマ人への手紙 9:1; コリント人への手紙第二 11:31; コリント人への手紙第二 11:10–11"> 私があなたがたに書いていることには、神の御前で申しますが、偽りはありません。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒の働き 15:41; 使徒の働き 9:30; 使徒の働き 6:9"> それから、私はシリヤおよびキリキヤの地方に行きました。</span>
<span className="v" id="v22" data-v="22" data-xref="テサロニケ人への手紙第一 2:14; ローマ人への手紙 16:7; テサロニケ人への手紙第二 1:1"> しかし、キリストにあるユダヤの諸教会には顔を知られていませんでした。</span>
<span className="v" id="v23" data-v="23" data-xref="コリント人への手紙第一 15:8–10; 使徒の働き 9:13; テモテへの手紙第一 1:13–16"> けれども、「以前私たちを迫害した者が、そのとき滅ぼそうとした信仰を今は宣べ伝えている。」と聞いてだけはいたので、</span>
<span className="v" id="v24" data-v="24" data-xref="マタイの福音書 9:8; 使徒の働き 11:18; ルカの福音書 15:10"> 彼らは私のことで神をあがめていました。</span>
</div>

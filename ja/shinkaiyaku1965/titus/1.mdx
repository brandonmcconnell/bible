<span className="v" id="v1" data-v="1" data-xref="ローマ人への手紙 1:1; テモテへの手紙第一 6:3; テモテへの手紙第二 2:25"> 神のしもべ、また、イエス・キリストの使徒パウロ――私は、神に選ばれた人々の信仰と、敬虔にふさわしい真理の知識とのために使徒とされたのです。</span>
<span className="v" id="v2" data-v="2" data-xref="Numbers 23:19; ヨハネの手紙第一 2:25; テモテへの手紙第二 1:9"> それは、偽ることのない神が、永遠の昔から約束してくださった永遠のいのちの望みに基づくことです。</span>
<span className="v" id="v3" data-v="3" data-xref="テモテへの手紙第一 1:11; テトスへの手紙 3:4–6; テモテへの手紙第一 1:1"> 神は、ご自分の定められた時に、このみことばを宣教によって明らかにされました。私は、この宣教を私たちの救い主なる神の命令によって、ゆだねられたのです。――このパウロから、</span>
<span className="v" id="v4" data-v="4" data-xref="テモテへの手紙第二 1:2; ユダの手紙 1:3; ペテロの手紙第二 1:1"> 同じ信仰による真実のわが子テトスへ。父なる神および私たちの救い主なるキリスト・イエスから、恵みと平安がありますように。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒の働き 14:23; テモテへの手紙第一 1:3; Ecclesiastes 12:9"> 私があなたをクレテに残したのは、あなたが残っている仕事の整理をし、また、私が指図したように、町ごとに長老たちを任命するためでした。</span>
<span className="v" id="v6" data-v="6" data-xref="テモテへの手紙第一 3:2–7; テモテへの手紙第一 3:12; テトスへの手紙 1:6–8"> それには、その人が、非難されるところがなく、ひとりの妻の夫であり、その子どもは不品行を責められたり、反抗的であったりしない信者であることが条件です。</span>
<span className="v" id="v7" data-v="7" data-xref="エペソ人への手紙 5:18; ペテロの手紙第二 2:10; ペテロの手紙第一 4:10"> 監督は神の家の管理者として、非難されるところのない者であるべきです。わがままでなく、短気でなく、酒飲みでなく、けんか好きでなく、不正な利を求めず、</span>
<span className="v" id="v8" data-v="8" data-xref="テモテへの手紙第一 3:2; テトスへの手紙 2:7; 1 Kings 5:7"> かえって、旅人をよくもてなし、善を愛し、慎み深く、正しく、敬虔で、自制心があり、</span>
<span className="v" id="v9" data-v="9" data-xref="テサロニケ人への手紙第二 2:15; テモテへの手紙第二 1:13; テモテへの手紙第一 6:3"> 教えにかなった信頼すべきみことばを、しっかりと守っていなければなりません。それは健全な教えをもって励ましたり、反対する人たちを正したりすることができるためです。</span>
<span className="v" id="v10" data-v="10" data-xref="テモテへの手紙第一 1:6; ヨハネの手紙第一 4:1; ガラテヤ人への手紙 2:4"> 実は、反抗的な者、空論に走る者、人を惑わす者が多くいます。特に、割礼を受けた人々がそうです。</span>
<span className="v" id="v11" data-v="11" data-xref="テモテへの手紙第二 3:6; テモテへの手紙第一 6:5; ローマ人への手紙 3:19"> 彼らの口を封じなければいけません。彼らは、不正な利を得るために、教えてはいけないことを教え、家々を破壊しています。</span>
<span className="v" id="v12" data-v="12" data-xref="ローマ人への手紙 16:18; テモテへの手紙第一 4:2; 使徒の働き 17:28"> 彼らと同国人であるひとりの預言者がこう言いました。 「クレテ人は昔からのうそつき、 悪いけだもの、 なまけ者の食いしんぼう。」</span>
<span className="v" id="v13" data-v="13" data-xref="テトスへの手紙 2:2; テモテへの手紙第一 5:20; テトスへの手紙 2:15"> この証言はほんとうなのです。ですから、きびしく戒めて、人々の信仰を健全にし、</span>
<span className="v" id="v14" data-v="14" data-xref="テモテへの手紙第二 4:4; コロサイ人への手紙 2:22; ガラテヤ人への手紙 4:9"> ユダヤ人の空想話や、真理から離れた人々の戒めには心を寄せないようにさせなさい。</span>
<span className="v" id="v15" data-v="15" data-xref="ローマ人への手紙 14:14; ローマ人への手紙 14:20; コリント人への手紙第一 10:23"> きよい人々には、すべてのものがきよいのです。しかし、汚れた、不信仰な人々には、何一つきよいものはありません。それどころか、その知性と良心までも汚れています。</span>
<span className="v" id="v16" data-v="16" data-xref="ヨハネの手紙第一 2:4; Isaiah 29:13; エペソ人への手紙 5:6"> 彼らは、神を知っていると口では言いますが、行ないでは否定しています。実に忌まわしく、不従順で、どんな良いわざにも不適格です。</span>

<span className="v" id="v1" data-v="1" data-xref="ローマ人への手紙 13:1–7; ペテロの手紙第一 2:13–17; Ecclesiastes 10:4"> あなたは彼らに注意を与えて、支配者たちと権威者たちに服従し、従順で、すべての良いわざを進んでする者とならせなさい。</span>
<span className="v" id="v2" data-v="2" data-xref="エペソ人への手紙 4:31; テモテへの手紙第二 2:24–25; エペソ人への手紙 4:2"> また、だれをもそしらず、争わず、柔和で、すべての人に優しい態度を示す者とならせなさい。</span>
<span className="v" id="v3" data-v="3" data-xref="エペソ人への手紙 2:1–3; ローマ人への手紙 6:17; コロサイ人への手紙 1:21"> 私たちも以前は、愚かな者であり、不従順で、迷った者であり、いろいろな欲情と快楽の奴隷になり、悪意とねたみの中に生活し、憎まれ者であり、互いに憎み合う者でした。</span>
<span className="v" id="v4" data-v="4" data-xref="エペソ人への手紙 2:4–10; テトスへの手紙 2:10–11; テモテへの手紙第一 4:10"> しかし、私たちの救い主なる神のいつくしみと人への愛とが現われたとき、</span>
<span className="v" id="v5" data-v="5" data-xref="エペソ人への手紙 2:8–9; テモテへの手紙第二 1:9; コリント人への手紙第一 6:11"> 神は、私たちが行なった義のわざによってではなく、ご自分のあわれみのゆえに、聖霊による、新生と更新との洗いをもって私たちを救ってくださいました。</span>
<span className="v" id="v6" data-v="6" data-xref="Joel 2:28; ローマ人への手紙 5:5; 使徒の働き 10:45"> 神は、この聖霊を、私たちの救い主なるイエス・キリストによって、私たちに豊かに注いでくださったのです。</span>
<span className="v" id="v7" data-v="7" data-xref="ローマ人への手紙 8:17; テトスへの手紙 2:11; コリント人への手紙第一 6:11"> それは、私たちがキリストの恵みによって義と認められ、永遠のいのちの望みによって、相続人となるためです。</span>
<span className="v" id="v8" data-v="8" data-xref="テトスへの手紙 3:14; テトスへの手紙 1:9; Psalms 16:2–3"> これは信頼できることばですから、私は、あなたがこれらのことについて、確信をもって話すように願っています。それは、神を信じている人々が、良いわざに励むことを心がけるようになるためです。これらのことは良いことであって、人々に有益なことです。</span>
<span className="v" id="v9" data-v="9" data-xref="テモテへの手紙第二 2:14; テモテへの手紙第二 2:23; テモテへの手紙第一 4:7"> しかし、愚かな議論、系図、口論、律法についての論争などを避けなさい。それらは無益で、むだなものです。</span>
<span className="v" id="v10" data-v="10" data-xref="ローマ人への手紙 16:17; ヨハネの手紙第二 1:10; マタイの福音書 18:15–17"> 分派を起こす者は、一、二度戒めてから、除名しなさい。</span>
<span className="v" id="v11" data-v="11" data-xref="ヘブル人への手紙 10:26; ルカの福音書 19:22; マタイの福音書 25:26–28"> このような人は、あなたも知っているとおり、堕落しており、自分で悪いと知りながら罪を犯しているのです。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="テモテへの手紙第二 4:9; テモテへの手紙第二 4:12; コリント人への手紙第一 16:8–9"> 私がアルテマスかテキコをあなたのもとに送ったら、あなたは、何としてでも、ニコポリにいる私のところに来てください。私はそこで冬を過ごすことに決めています。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒の働き 18:24; マタイの福音書 22:35; ヨハネの手紙第三 1:6–8"> ぜひとも、律法学者ゼナスとアポロとが旅に出られるようにし、彼らが不自由しないように世話をしてあげなさい。</span>
<span className="v" id="v14" data-v="14" data-xref="コロサイ人への手紙 1:10; テトスへの手紙 3:8; マタイの福音書 7:19"> 私たち一同も、なくてならないもののために、正しい仕事に励むように教えられなければなりません。それは、実を結ばない者にならないためです。</span>
</div>

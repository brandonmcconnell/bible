<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ペテロの手紙第一 1:5; テサロニケ人への手紙第一 5:23; ペテロの手紙第一 2:9"> イエス・キリストのしもべであり、ヤコブの兄弟であるユダから、父なる神にあって愛され、イエス・キリストのために守られている、召された方々へ。</span>
<span className="v" id="v2" data-v="2" data-xref="ペテロの手紙第二 1:2; ペテロの手紙第一 1:2; ヨハネの黙示録 1:4–6"> どうか、あわれみと平安と愛が、あなたがたの上に、ますます豊かにされますように。</span>
<span className="v" id="v3" data-v="3" data-xref="テモテへの手紙第一 6:12; ピリピ人への手紙 1:27; ユダの手紙 1:20"> 愛する人々。私はあなたがたに、私たちがともに受けている救いについて手紙を書こうとして、あらゆる努力をしていましたが、聖徒にひとたび伝えられた信仰のために戦うよう、あなたがたに勧める手紙を書く必要が生じました。</span>
<span className="v" id="v4" data-v="4" data-xref="ペテロの手紙第二 2:1–3; ガラテヤ人への手紙 2:4; ペテロの手紙第二 2:10"> というのは、ある人々が、ひそかに忍び込んで来たからです。彼らは、このようなさばきに会うと昔から前もってしるされている人々で、不敬虔な者であり、私たちの神の恵みを放縦に変えて、私たちの唯一の支配者であり主であるイエス・キリストを否定する人たちです。</span>
<span className="v" id="v5" data-v="5" data-xref="Numbers 26:64–65; ヘブル人への手紙 3:16–2; コリント人への手紙第一 10:1–12"> あなたがたは、すべてのことをすっかり知っているにしても、私はあなたがたに思い出させたいことがあるのです。それは主が、民をエジプトの地から救い出し、次に、信じない人々を滅ぼされたということです。</span>
<span className="v" id="v6" data-v="6" data-xref="ペテロの手紙第二 2:4; マタイの福音書 25:41; エペソ人への手紙 6:12"> また、主は、自分の領域を守らず、自分のおるべき所を捨てた御使いたちを、大いなる日のさばきのために、永遠の束縛をもって、暗やみの下に閉じ込められました。</span>
<span className="v" id="v7" data-v="7" data-xref="Deuteronomy 29:23; ペテロの手紙第二 2:6; ローマ人への手紙 1:26–27"> また、ソドム、ゴモラおよび周囲の町々も彼らと同じように、好色にふけり、不自然な肉欲を追い求めたので、永遠の火の刑罰を受けて、みせしめにされています。</span>
<span className="v" id="v8" data-v="8" data-xref="ヘブル人への手紙 13:17; ペテロの手紙第一 2:17; ペテロの手紙第二 2:10–12"> それなのに、この人たちもまた同じように、夢見る者であり、肉体を汚し、権威ある者を軽んじ、栄えある者をそしっています。</span>
<span className="v" id="v9" data-v="9" data-xref="Zechariah 3:2; ペテロの手紙第二 2:11; Deuteronomy 34:6"> 御使いのかしらミカエルは、モーセのからだについて、悪魔と論じ、言い争ったとき、あえて相手をののしり、さばくようなことはせず、「主があなたを戒めてくださるように。」と言いました。</span>
<span className="v" id="v10" data-v="10" data-xref="ペテロの手紙第二 2:12; ローマ人への手紙 1:21–22"> しかし、この人たちは、自分には理解もできないことをそしり、わきまえのない動物のように、本能によって知るような事がらの中で滅びるのです。</span>
<span className="v" id="v11" data-v="11" data-xref="ペテロの手紙第二 2:15; ヨハネの手紙第一 3:12; ヨハネの黙示録 2:14"> 忌まわしいことです。彼らは、カインの道を行き、利益のためにバラムの迷いに陥り、コラのようにそむいて滅びました。</span>
<span className="v" id="v12" data-v="12" data-xref="ペテロの手紙第二 2:17–20; マタイの福音書 15:13; Ezekiel 34:8"> 彼らは、あなたがたの愛餐のしみです。恐れげもなくともに宴を張りますが、自分だけを養っている者であり、風に吹き飛ばされる、水のない雲、実を結ばない、枯れに枯れて、根こそぎにされた秋の木、</span>
<span className="v" id="v13" data-v="13" data-xref="ペテロの手紙第二 2:17; ピリピ人への手紙 3:19; Isaiah 57:20"> 自分の恥のあわをわき立たせる海の荒波、さまよう星です。まっ暗なやみが、彼らのために永遠に用意されています。</span>
<span className="v" id="v14" data-v="14" data-xref="Deuteronomy 33:2; Psalms 50:3–5; ヘブル人への手紙 11:5–6"> アダムから七代目のエノクも、彼らについて預言してこう言っています。「見よ。主は千万の聖徒を引き連れて来られる。</span>
<span className="v" id="v15" data-v="15" data-xref="ローマ人への手紙 2:16; Ecclesiastes 11:9; コリント人への手紙第一 4:5"> すべての者にさばきを行ない、不敬虔な者たちの、神を恐れずに犯した行為のいっさいと、また神を恐れない罪人どもが主に言い逆らった無礼のいっさいとについて、彼らを罪に定めるためである。」</span>
<span className="v" id="v16" data-v="16" data-xref="ペテロの手紙第二 2:18; ペテロの手紙第二 2:10; ピリピ人への手紙 2:14"> 彼らはぶつぶつ言う者、不平を鳴らす者で、自分の欲望のままに歩んでいます。その口は大きなことを言い、利益のためにへつらって人をほめるのです。</span>
<span className="v" id="v17" data-v="17" data-xref="ペテロの手紙第二 3:2; ヨハネの手紙第一 4:6; エペソ人への手紙 4:11"> 愛する人々よ。私たちの主イエス・キリストの使徒たちが、前もって語ったことばを思い起こしてください。</span>
<span className="v" id="v18" data-v="18" data-xref="ペテロの手紙第二 3:3; テモテへの手紙第二 4:3; テモテへの手紙第二 3:1–5"> 彼らはあなたがたにこう言いました。「終わりの時には、自分の不敬虔な欲望のままにふるまう、あざける者どもが現われる。」</span>
<span className="v" id="v19" data-v="19" data-xref="コリント人への手紙第一 2:14; Proverbs 18:1; ローマ人への手紙 8:9"> この人たちは、御霊を持たず、分裂を起こし、生まれつきのままの人間です。</span>
<span className="v" id="v20" data-v="20" data-xref="エペソ人への手紙 6:18; ローマ人への手紙 8:26–27; コリント人への手紙第一 14:15"> しかし、愛する人々よ。あなたがたは、自分の持っている最もきよい信仰の上に自分自身を築き上げ、聖霊によって祈り、</span>
<span className="v" id="v21" data-v="21" data-xref="ヨハネの手紙第一 4:16; Lamentations 3:25–26; ヘブル人への手紙 9:28"> 神の愛のうちに自分自身を保ち、永遠のいのちに至らせる、私たちの主イエス・キリストのあわれみを待ち望みなさい。</span>
<span className="v" id="v22" data-v="22" data-xref="ヤコブの手紙 5:19–20; ガラテヤ人への手紙 6:1; ヨハネの手紙第一 5:16–18"> 疑いを抱く人々をあわれみ、</span>
<span className="v" id="v23" data-v="23" data-xref="テモテへの手紙第一 4:16; コリント人への手紙第一 15:33; ヨハネの黙示録 3:4"> 火の中からつかみ出して救い、またある人々を、恐れを感じながらあわれみ、肉によって汚されたその下着さえも忌みきらいなさい。</span>
<span className="v" id="v24" data-v="24" data-xref="テモテへの手紙第二 4:18; エペソ人への手紙 3:20; コロサイ人への手紙 1:22"> あなたがたを、つまずかないように守ることができ、傷のない者として、大きな喜びをもって栄光の御前に立たせることのできる方に、</span>
<span className="v" id="v25" data-v="25" data-xref="テモテへの手紙第一 1:17; ヨハネの黙示録 5:13–14; ペテロの手紙第一 5:10–11"> すなわち、私たちの救い主である唯一の神に、栄光、尊厳、支配、権威が、私たちの主イエス・キリストを通して、永遠の先にも、今も、また世々限りなくありますように。アーメン。</span>

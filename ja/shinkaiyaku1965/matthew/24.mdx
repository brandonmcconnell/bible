<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マルコの福音書 13:1–37; ルカの福音書 21:5–36; Ezekiel 8:6"> イエスが宮を出て行かれるとき、弟子たちが近寄って来て、イエスに宮の建物をさし示した。</span>
<span className="v" id="v2" data-v="2" data-xref="ルカの福音書 19:44; Jeremiah 26:18; Micah 3:12"> そこで、イエスは彼らに答えて言われた。「このすべての物に目をみはっているのでしょう。まことに、あなたがたに告げます。ここでは、石がくずされずに、積まれたまま残ることは決してありません。」</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="マルコの福音書 13:3–4; 使徒の働き 1:7; テサロニケ人への手紙第一 5:1–11"> イエスがオリーブ山ですわっておられると、弟子たちが、ひそかにみもとに来て言った。「お話しください。いつ、そのようなことが起こるのでしょう。あなたの来られる時や世の終わりには、どんな前兆があるのでしょう。」</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネの手紙第一 4:1; Jeremiah 29:8; テサロニケ人への手紙第二 2:3"> そこで、イエスは彼らに答えて言われた。「人に惑わされないように気をつけなさい。</span>
<span className="v" id="v5" data-v="5" data-xref="マタイの福音書 24:11; マタイの福音書 24:24; Jeremiah 14:14"> わたしの名を名のる者が大ぜい現われ、『私こそキリストだ。』と言って、多くの人を惑わすでしょう。</span>
<span className="v" id="v6" data-v="6" data-xref="マルコの福音書 13:7–8; ルカの福音書 21:9; ペテロの手紙第一 3:14–15"> また、戦争のことや、戦争のうわさを聞くでしょうが、気をつけて、あわてないようにしなさい。これらは必ず起こることです。しかし、終わりが来たのではありません。</span>
<span className="v" id="v7" data-v="7" data-xref="ルカの福音書 21:11; ヨハネの黙示録 6:8; Isaiah 19:2"> 民族は民族に、国は国に敵対して立ち上がり、方々にききんと地震が起こります。</span>
<span className="v" id="v8" data-v="8" data-xref="テサロニケ人への手紙第一 5:3; ペテロの手紙第一 4:17–18; Deuteronomy 28:59"> しかし、そのようなことはみな、産みの苦しみの初めなのです。</span>
<span className="v" id="v9" data-v="9" data-xref="ヨハネの福音書 16:2; ヨハネの福音書 15:19–20; ルカの福音書 21:16–17"> そのとき、人々は、あなたがたを苦しいめに会わせ、殺します。また、わたしの名のために、あなたがたはすべての国の人々に憎まれます。</span>
<span className="v" id="v10" data-v="10" data-xref="Micah 7:5–6; ルカの福音書 21:16; マタイの福音書 11:6"> また、そのときは、人々が大ぜいつまずき、互いに裏切り、憎み合います。</span>
<span className="v" id="v11" data-v="11" data-xref="マタイの福音書 24:24; マタイの福音書 7:15; マタイの福音書 24:5"> また、にせ預言者が多く起こって、多くの人々を惑わします。</span>
<span className="v" id="v12" data-v="12" data-xref="ヨハネの黙示録 2:4–5; ヤコブの手紙 4:1–4; ヨハネの黙示録 3:15"> 不法がはびこるので、多くの人たちの愛は冷たくなります。</span>
<span className="v" id="v13" data-v="13" data-xref="マタイの福音書 10:22; マルコの福音書 13:13; ヨハネの黙示録 2:10"> しかし、最後まで耐え忍ぶ者は救われます。</span>
<span className="v" id="v14" data-v="14" data-xref="ヨハネの黙示録 14:6; ローマ人への手紙 10:18; ローマ人への手紙 16:25–26"> この御国の福音は全世界に宣べ伝えられて、すべての国民にあかしされ、それから、終わりの日が来ます。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="Daniel 9:27; Daniel 12:11; マルコの福音書 13:14"> それゆえ、預言者ダニエルによって語られたあの『荒らす憎むべき者』が、聖なる所に立つのを見たならば、（読者はよく読み取るように。）</span>
<span className="v" id="v16" data-v="16" data-xref="Genesis 19:15–17; ルカの福音書 21:21–22; ヘブル人への手紙 11:7"> そのときは、ユダヤにいる人々は山へ逃げなさい。</span>
<span className="v" id="v17" data-v="17" data-xref="ルカの福音書 17:31–33; マルコの福音書 13:15–16; マタイの福音書 10:27"> 屋上にいる者は家の中の物を持ち出そうと下に降りてはいけません。</span>
<span className="v" id="v18" data-v="18"> 畑にいる者は着物を取りに戻ってはいけません。</span>
<span className="v" id="v19" data-v="19" data-xref="ルカの福音書 23:29–30; Deuteronomy 28:53–56; ルカの福音書 21:23"> だが、その日、悲惨なのは身重の女と乳飲み子を持つ女です。</span>
<span className="v" id="v20" data-v="20" data-xref="Exodus 16:29; 使徒の働き 1:12"> ただ、あなたがたの逃げるのが、冬や安息日にならぬよう祈りなさい。</span>
<span className="v" id="v21" data-v="21" data-xref="Daniel 12:1; Joel 2:2; Malachi 4:1"> そのときには、世の初めから、今に至るまで、いまだかつてなかったような、またこれからもないような、ひどい苦難があるからです。</span>
<span className="v" id="v22" data-v="22" data-xref="マルコの福音書 13:20; テモテへの手紙第二 2:10; マタイの福音書 24:31"> もし、その日数が少なくされなかったら、ひとりとして救われる者はないでしょう。しかし、選ばれた者のために、その日数は少なくされます。</span>
<span className="v" id="v23" data-v="23" data-xref="ルカの福音書 21:8; ルカの福音書 17:23–24; Deuteronomy 13:1–3"> そのとき、『そら、キリストがここにいる。』とか、『そこにいる。』とか言う者があっても、信じてはいけません。</span>
<span className="v" id="v24" data-v="24" data-xref="テサロニケ人への手紙第二 2:9–11; マルコの福音書 13:22; ヨハネの黙示録 13:13–14"> にせキリスト、にせ預言者たちが現われて、できれば選民をも惑わそうとして、大きなしるしや不思議なことをして見せます。</span>
<span className="v" id="v25" data-v="25" data-xref="ヨハネの福音書 16:1; ルカの福音書 21:13; Isaiah 48:5–6"> さあ、わたしは、あなたがたに前もって話しました。</span>
<span className="v" id="v26" data-v="26" data-xref="ルカの福音書 3:2–3; Isaiah 40:3; マタイの福音書 3:1"> だから、たとい、『そら、荒野にいらっしゃる。』と言っても、飛び出して行ってはいけません。『そら、へやにいらっしゃる。』と聞いても、信じてはいけません。</span>
<span className="v" id="v27" data-v="27" data-xref="ルカの福音書 17:24–37; Zechariah 9:14; Job 37:3"> 人の子の来るのは、いなずまが東から出て、西にひらめくように、ちょうどそのように来るのです。</span>
<span className="v" id="v28" data-v="28" data-xref="ルカの福音書 17:37; Job 39:27–30; Deuteronomy 28:49"> 死体のある所には、はげたかが集まります。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="Amos 8:9; Joel 3:15; Isaiah 13:10"> だが、これらの日の苦難に続いてすぐに、太陽は暗くなり、月は光を放たず、星は天から落ち、天の万象は揺り動かされます。</span>
<span className="v" id="v30" data-v="30" data-xref="ヨハネの黙示録 1:7; Daniel 7:13; ルカの福音書 21:27"> そのとき、人の子のしるしが天に現われます。すると、地上のあらゆる種族は、悲しみながら、人の子が大能と輝かしい栄光を帯びて天の雲に乗って来るのを見るのです。</span>
<span className="v" id="v31" data-v="31" data-xref="テサロニケ人への手紙第一 4:16; マルコの福音書 13:27; Isaiah 27:13"> 人の子は大きなラッパの響きとともに、御使いたちを遣わします。すると御使いたちは、天の果てから果てまで、四方からその選びの民を集めます。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="マルコの福音書 13:28–29; ルカの福音書 21:29–30"> いちじくの木から、たとえを学びなさい。枝が柔らかになって、葉が出て来ると、夏の近いことがわかります。</span>
<span className="v" id="v33" data-v="33" data-xref="ヤコブの手紙 5:9; ヘブル人への手紙 10:37; Ezekiel 7:2–14"> そのように、これらのことのすべてを見たら、あなたがたは、人の子が戸口まで近づいていると知りなさい。</span>
<span className="v" id="v34" data-v="34" data-xref="マルコの福音書 13:30–31; ルカの福音書 21:32–33; マタイの福音書 16:28"> まことに、あなたがたに告げます。これらのことが全部起こってしまうまでは、この時代は過ぎ去りません。</span>
<span className="v" id="v35" data-v="35" data-xref="Isaiah 40:8; ペテロの手紙第一 1:25; Numbers 23:19"> この天地は滅び去ります。しかし、わたしのことばは決して滅びることがありません。</span>
<span className="v" id="v36" data-v="36" data-xref="マルコの福音書 13:32; 使徒の働き 1:7; マタイの福音書 24:44"> ただし、その日、その時がいつであるかは、だれも知りません。天の御使いたちも子も知りません。ただ父だけが知っておられます。</span>
<span className="v" id="v37" data-v="37" data-xref="ルカの福音書 17:26–27; Genesis 6:1–7; ペテロの手紙第二 2:5"> 人の子が来るのは、ちょうど、ノアの日のようだからです。</span>
<span className="v" id="v38" data-v="38" data-xref="ルカの福音書 17:26–28; ローマ人への手紙 13:13–14; ルカの福音書 14:18–20"> 洪水前の日々は、ノアが箱舟にはいるその日まで、人々は、飲んだり、食べたり、めとったり、とついだりしていました。</span>
<span className="v" id="v39" data-v="39" data-xref="ヨハネの福音書 3:20; マタイの福音書 24:37; 使徒の働き 13:41"> そして、洪水が来てすべての物をさらってしまうまで、彼らはわからなかったのです。人の子が来るのも、そのとおりです。</span>
<span className="v" id="v40" data-v="40" data-xref="ルカの福音書 17:34–37; ペテロの手紙第二 2:7–9; ペテロの手紙第二 2:5"> そのとき、畑にふたりいると、ひとりは取られ、ひとりは残されます。</span>
<span className="v" id="v41" data-v="41" data-xref="Exodus 11:5; Isaiah 47:2; ルカの福音書 17:35"> ふたりの女が臼をひいていると、ひとりは取られ、ひとりは残されます。</span>
<span className="v" id="v42" data-v="42" data-xref="ルカの福音書 21:36; テサロニケ人への手紙第一 5:6; マタイの福音書 25:13"> だから、目をさましていなさい。あなたがたは、自分の主がいつ来られるか、知らないからです。</span>
<span className="v" id="v43" data-v="43" data-xref="ルカの福音書 12:39; マタイの福音書 24:44; テサロニケ人への手紙第一 5:2–6"> しかし、このことは知っておきなさい。家の主人は、どろぼうが夜の何時に来ると知っていたら、目を見張っていたでしょうし、また、おめおめと自分の家に押し入られはしなかったでしょう。</span>
<span className="v" id="v44" data-v="44" data-xref="マタイの福音書 25:10; マタイの福音書 24:42; マタイの福音書 25:13"> だから、あなたがたも用心していなさい。なぜなら、人の子は、思いがけない時に来るのですから。</span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="マタイの福音書 25:21; マタイの福音書 25:23; コリント人への手紙第一 4:1–2"> 主人から、その家のしもべたちを任されて、食事時には彼らに食事をきちんと与えるような忠実な思慮深いしもべとは、いったいだれでしょうか。</span>
<span className="v" id="v46" data-v="46" data-xref="ヨハネの黙示録 16:15; ルカの福音書 12:43; ルカの福音書 12:37"> 主人が帰って来たときに、そのようにしているのを見られるしもべは幸いです。</span>
<span className="v" id="v47" data-v="47" data-xref="マタイの福音書 25:23; マタイの福音書 25:21; ルカの福音書 12:37"> まことに、あなたがたに告げます。その主人は彼に自分の全財産を任せるようになります。</span>
<span className="v" id="v48" data-v="48" data-xref="マタイの福音書 18:32; Isaiah 32:6; ルカの福音書 12:45"> ところが、それが悪いしもべで、『主人はまだまだ帰るまい。』と心の中で思い、</span>
<span className="v" id="v49" data-v="49" data-xref="ヨハネの黙示録 17:6; ヨハネの黙示録 16:6; Micah 3:5"> その仲間を打ちたたき、酒飲みたちと飲んだり食べたりし始めていると、</span>
<span className="v" id="v50" data-v="50" data-xref="テサロニケ人への手紙第一 5:2–3; ヨハネの黙示録 3:3; マタイの福音書 24:42–44"> そのしもべの主人は、思いがけない日の思わぬ時間に帰って来ます。</span>
<span className="v" id="v51" data-v="51" data-xref="マタイの福音書 8:12; マタイの福音書 22:13; ルカの福音書 12:46"> そして、彼をきびしく罰して、その報いを偽善者たちと同じにするに違いありません。しもべはそこで泣いて歯ぎしりするのです。</span>
</div>

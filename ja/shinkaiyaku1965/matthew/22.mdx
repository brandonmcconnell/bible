<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マタイの福音書 20:1–16; マタイの福音書 12:43–45; ルカの福音書 14:16"> イエスはもう一度たとえをもって彼らに話された。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネの黙示録 19:7–9; マタイの福音書 13:24; エペソ人への手紙 5:24–32"> 「天の御国は、王子のために結婚の披露宴を設けた王にたとえることができます。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="ヨハネの黙示録 22:17; ヨハネの福音書 5:40; ルカの福音書 14:15–17"> 王は、招待しておいたお客を呼びに、しもべたちを遣わしたが、彼らは来たがらなかった。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒の働き 13:46; マタイの福音書 21:36; ヨハネの福音書 6:50–57"> それで、もう一度、次のように言いつけて、別のしもべたちを遣わした。『お客に招いておいた人たちにこう言いなさい。「さあ、食事の用意ができました。雄牛も太った家畜もほふって、何もかも整いました。どうぞ宴会にお出かけください。」』</span>
<span className="v" id="v5" data-v="5" data-xref="ヘブル人への手紙 2:3; ルカの福音書 14:18–20; ヨハネの手紙第一 2:15–16"> ところが、彼らは気にもかけず、ある者は畑に、別の者は商売に出て行き、</span>
<span className="v" id="v6" data-v="6" data-xref="ヨハネの福音書 15:19–20; ヨハネの福音書 16:2–3; 使徒の働き 7:51–57"> そのほかの者たちは、王のしもべたちをつかまえて恥をかかせ、そして殺してしまった。</span>
<span className="v" id="v7" data-v="7" data-xref="ルカの福音書 19:27; ペテロの手紙第一 4:17–18; ルカの福音書 21:24"> 王は怒って、兵隊を出して、その人殺しどもを滅ぼし、彼らの町を焼き払った。</span>
<span className="v" id="v8" data-v="8" data-xref="テサロニケ人への手紙第二 1:5; 使徒の働き 13:46; ヨハネの黙示録 3:4"> そのとき、王はしもべたちに言った。『宴会の用意はできているが、招待しておいた人たちは、それにふさわしくなかった。</span>
<span className="v" id="v9" data-v="9" data-xref="ルカの福音書 14:21–24; Proverbs 1:20–23; マルコの福音書 16:15–16"> だから、大通りに行って、出会った者をみな宴会に招きなさい。』</span>
<span className="v" id="v10" data-v="10" data-xref="コリント人への手紙第一 6:9–11; ヨハネの黙示録 19:6–9; コリント人への手紙第二 12:21"> それで、しもべたちは、通りに出て行って、良い人でも悪い人でも出会った者をみな集めたので、宴会場は客でいっぱいになった。</span>
<span className="v" id="v11" data-v="11" data-xref="ヨハネの黙示録 3:4–5; ヨハネの黙示録 19:8; ヘブル人への手紙 4:12–13"> ところで、王が客を見ようとしてはいって来ると、そこに婚礼の礼服を着ていない者がひとりいた。</span>
<span className="v" id="v12" data-v="12" data-xref="1 Samuel 2:9; Job 5:16; マタイの福音書 20:13"> そこで、王は言った。『あなたは、どうして礼服を着ないで、ここにはいって来たのですか。』しかし、彼は黙っていた。</span>
<span className="v" id="v13" data-v="13" data-xref="マタイの福音書 8:12; マタイの福音書 25:30; マタイの福音書 24:51"> そこで、王はしもべたちに、『あれの手足を縛って、外の暗やみに放り出せ。そこで泣いて歯ぎしりするのだ。』と言った。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="ペテロの手紙第二 1:10; ルカの福音書 13:23–24; マタイの福音書 7:13–14"> 招待される者は多いが、選ばれる者は少ないのです。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="ルカの福音書 20:20–26; マルコの福音書 12:13–17; Psalms 2:2"> そのころ、パリサイ人たちは出て来て、どのようにイエスをことばのわなにかけようかと相談した。</span>
<span className="v" id="v16" data-v="16" data-xref="マルコの福音書 3:6; マルコの福音書 8:15; マルコの福音書 12:14"> 彼らはその弟子たちを、ヘロデ党の者たちといっしょにイエスのもとにやって、こう言わせた。「先生。私たちは、あなたが真実な方で、真理に基づいて神の道を教え、だれをもはばからない方だと存じています。あなたは、人の顔色を見られないからです。</span>
<span className="v" id="v17" data-v="17" data-xref="ルカの福音書 2:1; ローマ人への手紙 13:6–7; マタイの福音書 17:25"> それで、どう思われるのか言ってください。税金をカイザルに納めることは、律法にかなっていることでしょうか。かなっていないことでしょうか。」</span>
<span className="v" id="v18" data-v="18" data-xref="ヨハネの福音書 8:6; ルカの福音書 5:22; ヨハネの福音書 2:25"> イエスは彼らの悪意を知って言われた。「偽善者たち。なぜ、わたしをためすのか。</span>
<span className="v" id="v19" data-v="19" data-xref="マタイの福音書 20:2; ヨハネの黙示録 6:6; マタイの福音書 18:28"> 納め金にするお金をわたしに見せなさい。」そこで彼らは、デナリを一枚イエスのもとに持って来た。</span>
<span className="v" id="v20" data-v="20" data-xref="ルカの福音書 20:24"> そこで彼らに言われた。「これは、だれの肖像ですか。だれの銘ですか。」</span>
<span className="v" id="v21" data-v="21" data-xref="ローマ人への手紙 13:7; Proverbs 24:21; 使徒の働き 4:19"> 彼らは、「カイザルのです。」と言った。そこで、イエスは言われた。「それなら、カイザルのものはカイザルに返しなさい。そして神のものは神に返しなさい。」</span>
<span className="v" id="v22" data-v="22" data-xref="マルコの福音書 12:12; マタイの福音書 22:46; ルカの福音書 20:25–26"> 彼らは、これを聞いて驚嘆し、イエスを残して立ち去った。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="使徒の働き 4:1; マルコの福音書 12:18–27; 使徒の働き 23:6–8"> その日、復活はないと言っているサドカイ人たちが、イエスのところに来て、質問して、</span>
<span className="v" id="v24" data-v="24" data-xref="Deuteronomy 25:5–10; ルカの福音書 20:28; Ruth 1:11"> 言った。「先生。モーセは『もし、ある人が子のないままで死んだなら、その弟は兄の妻をめとって、兄のための子をもうけねばならない。』と言いました。</span>
<span className="v" id="v25" data-v="25" data-xref="ルカの福音書 20:29–33; マルコの福音書 12:19–23; ヘブル人への手紙 9:27"> ところで、私たちの間に七人兄弟がありました。長男は結婚しましたが、死んで、子がなかったので、その妻を弟に残しました。</span>
<span className="v" id="v26" data-v="26"> 次男も三男も、七人とも同じようになりました。</span>
<span className="v" id="v27" data-v="27"> そして、最後に、その女も死にました。</span>
<span className="v" id="v28" data-v="28"> すると復活の際には、その女は七人のうちだれの妻なのでしょうか。彼らはみな、その女を妻にしたのです。」</span>
<span className="v" id="v29" data-v="29" data-xref="ヨハネの福音書 20:9; ローマ人への手紙 15:4; ルカの福音書 1:37"> しかし、イエスは彼らに答えて言われた。「そんな思い違いをしているのは、聖書も神の力も知らないからです。</span>
<span className="v" id="v30" data-v="30" data-xref="ルカの福音書 20:34–36; マルコの福音書 12:24–25; マタイの福音書 24:38"> 復活の時には、人はめとることも、とつぐこともなく、天の御使いたちのようです。</span>
<span className="v" id="v31" data-v="31" data-xref="マタイの福音書 12:3; マタイの福音書 21:16; マタイの福音書 21:42"> それに、死人の復活については、神があなたがたに語られた事を、あなたがたは読んだことがないのですか。</span>
<span className="v" id="v32" data-v="32" data-xref="Exodus 3:6; マルコの福音書 12:26–27; ルカの福音書 20:37–38"> 『わたしは、アブラハムの神、イサクの神、ヤコブの神である。』とあります。神は死んだ者の神ではありません。生きている者の神です。」</span>
<span className="v" id="v33" data-v="33" data-xref="マルコの福音書 12:17; マルコの福音書 6:2; ヨハネの福音書 7:46"> 群衆はこれを聞いて、イエスの教えに驚いた。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="マルコの福音書 12:28–31; マタイの福音書 25:3–5; マタイの福音書 12:14"> しかし、パリサイ人たちは、イエスがサドカイ人たちを黙らせたと聞いて、いっしょに集まった。</span>
<span className="v" id="v35" data-v="35" data-xref="ルカの福音書 7:30; ルカの福音書 10:25–37; ルカの福音書 11:52"> そして、彼らのうちのひとりの律法の専門家が、イエスをためそうとして、尋ねた。</span>
<span className="v" id="v36" data-v="36" data-xref="マルコの福音書 12:28–33; マタイの福音書 5:19–20; ルカの福音書 11:42"> 「先生。律法の中で、たいせつな戒めはどれですか。」</span>
<span className="v" id="v37" data-v="37" data-xref="マルコの福音書 12:29–30; ルカの福音書 10:27; Deuteronomy 6:5"> そこで、イエスは彼に言われた。「『心を尽くし、思いを尽くし、知力を尽くして、あなたの神である主を愛せよ。』</span>
<span className="v" id="v38" data-v="38"> これがたいせつな第一の戒めです。</span>
<span className="v" id="v39" data-v="39" data-xref="マルコの福音書 12:31; ルカの福音書 10:27–37; Leviticus 19:18"> 『あなたの隣人をあなた自身のように愛せよ。』という第二の戒めも、それと同じようにたいせつです。</span>
<span className="v" id="v40" data-v="40" data-xref="ローマ人への手紙 13:9; マタイの福音書 7:12; ヨハネの手紙第一 4:19–21"> 律法全体と預言者とが、この二つの戒めにかかっているのです。」</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="ルカの福音書 20:41–44; マルコの福音書 12:35–37; マタイの福音書 22:34"> パリサイ人たちが集まっているときに、イエスは彼らに尋ねて言われた。</span>
<span className="v" id="v42" data-v="42" data-xref="Jeremiah 23:5–6; ヨハネの福音書 6:68–69; マタイの福音書 16:13–17"> 「あなたがたは、キリストについて、どう思いますか。彼はだれの子ですか。」彼らはイエスに言った。「ダビデの子です。」</span>
<span className="v" id="v43" data-v="43" data-xref="2 Samuel 23:2; ヨハネの黙示録 4:2; マルコの福音書 12:36"> イエスは彼らに言われた。「それでは、どうしてダビデは、御霊によって、彼を主と呼び、</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="Psalms 110:1; ヘブル人への手紙 1:13; 使徒の働き 2:34–35"> 『主は私の主に言われた。<br />「わたしがあなたの敵を<br />あなたの足の下に従わせるまでは、<br />わたしの右の座に着いていなさい。」』<br />と言っているのですか。</span>
<span className="v" id="v45" data-v="45" data-xref="ローマ人への手紙 1:3–4; ヨハネの黙示録 22:16; ヨハネの福音書 8:58"> ダビデがキリストを主と呼んでいるのなら、どうして彼はダビデの子なのでしょう。」</span>
<span className="v" id="v46" data-v="46" data-xref="マルコの福音書 12:34; ルカの福音書 20:40; ルカの福音書 14:6"> それで、だれもイエスに一言も答えることができなかった。また、その日以来、もはやだれも、イエスにあえて質問をする者はなかった。</span>
</div>

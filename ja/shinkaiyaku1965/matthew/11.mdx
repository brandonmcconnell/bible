<span className="v" id="v1" data-v="1" data-xref="Isaiah 61:1–3; 使徒の働き 10:38; ルカの福音書 8:1"> イエスはこのように十二弟子に注意を与え、それを終えられると、彼らの町々で教えたり宣べ伝えたりするため、そこを立ち去られた。</span>
<span className="v" id="v2" data-v="2" data-xref="マルコの福音書 6:17; マタイの福音書 14:3; マタイの福音書 9:14"> さて、獄中でキリストのみわざについて聞いたヨハネは、その弟子たちに託して、</span>
<span className="v" id="v3" data-v="3" data-xref="ヨハネの福音書 11:27; Malachi 3:1; Deuteronomy 18:15–18"> イエスにこう言い送った。「おいでになるはずの方は、あなたですか。それとも、私たちは別の方を待つべきでしょうか。」</span>
<span className="v" id="v4" data-v="4"> イエスは答えて、彼らに言われた。「あなたがたは行って、自分たちの聞いたり見たりしていることをヨハネに報告しなさい。</span>
<span className="v" id="v5" data-v="5" data-xref="Isaiah 35:4–6; Isaiah 61:1–3; ルカの福音書 4:18"> 盲人が見、足なえが歩き、らい病人がきよめられ、つんぼの人が聞こえ、死人が生き返り、貧しい者には福音が宣べ伝えられているのです。</span>
<span className="v" id="v6" data-v="6" data-xref="Isaiah 8:14–15; コリント人への手紙第一 2:14; マタイの福音書 26:31"> だれでも、わたしにつまずかない者は幸いです。」</span>
<span className="v" id="v7" data-v="7" data-xref="ヤコブの手紙 1:6; ヨハネの福音書 5:35; マルコの福音書 1:3–5"> この人たちが行ってしまうと、イエスは、ヨハネについて群衆に話しだされた。「あなたがたは、何を見に荒野に出て行ったのですか。風に揺れる葦ですか。</span>
<span className="v" id="v8" data-v="8" data-xref="マタイの福音書 3:4; 2 Kings 1:8; Zechariah 13:4"> でなかったら、何を見に行ったのですか。柔らかい着物を着た人ですか。柔らかい着物を着た人なら王の宮殿にいます。</span>
<span className="v" id="v9" data-v="9" data-xref="ルカの福音書 1:76; マタイの福音書 14:5; マタイの福音書 21:24–26"> でなかったら、なぜ行ったのですか。預言者を見るためですか。そのとおり。だが、わたしが言いましょう。預言者よりもすぐれた者をです。</span>
<span className="v" id="v10" data-v="10" data-xref="Malachi 3:1; Isaiah 40:3; Malachi 4:5"> この人こそ、 『見よ、わたしは使いをあなたの前に遣わし、 あなたの道を、あなたの前に備えさせよう。』 と書かれているその人です。</span>
<span className="v" id="v11" data-v="11" data-xref="ルカの福音書 7:28; エペソ人への手紙 3:8; マタイの福音書 3:11"> まことに、あなたがたに告げます。女から生まれた者の中で、バプテスマのヨハネよりすぐれた人は出ませんでした。しかも、天の御国の一番小さい者でも、彼より偉大です。</span>
<span className="v" id="v12" data-v="12" data-xref="ルカの福音書 16:16; ルカの福音書 13:24; エペソ人への手紙 6:11–13"> バプテスマのヨハネの日以来今日まで、天の御国は激しく攻められています。そして、激しく攻める者たちがそれを奪い取っています。</span>
<span className="v" id="v13" data-v="13" data-xref="マタイの福音書 5:17–18; ローマ人への手紙 3:21; 使徒の働き 13:27"> ヨハネに至るまで、すべての預言者たちと律法とが預言をしたのです。</span>
<span className="v" id="v14" data-v="14" data-xref="Malachi 4:5; マタイの福音書 17:10–13; マルコの福音書 9:11–13"> あなたがたが進んで受け入れるなら、実はこの人こそ、きたるべきエリヤなのです。</span>
<span className="v" id="v15" data-v="15" data-xref="ルカの福音書 8:8; マタイの福音書 13:9; マルコの福音書 4:23"> 耳のある者は聞きなさい。</span>
<span className="v" id="v16" data-v="16" data-xref="ルカの福音書 7:31–35; マタイの福音書 12:34; マタイの福音書 23:36"> この時代は何にたとえたらよいでしょう。市場にすわっている子どもたちのようです。彼らは、ほかの子どもたちに呼びかけて、</span>
<span className="v" id="v17" data-v="17" data-xref="Isaiah 28:9–13; Isaiah 30:29; Jeremiah 9:17–20"> こう言うのです。 『笛を吹いてやっても、君たちは踊らなかった。 弔いの歌を歌ってやっても、悲しまなかった。』</span>
<span className="v" id="v18" data-v="18" data-xref="ルカの福音書 1:15; マタイの福音書 3:4; ヨハネの福音書 10:20"> ヨハネが来て、食べも飲みもしないと、人々は『あれは悪霊につかれているのだ。』と言い、</span>
<span className="v" id="v19" data-v="19" data-xref="マタイの福音書 9:10–11; ルカの福音書 15:1–2; ルカの福音書 19:7"> 人の子が来て食べたり飲んだりしていると、『あれ見よ。食いしんぼうの大酒飲み、取税人や罪人の仲間だ。』と言います。でも、知恵の正しいことは、その行ないが証明します。」</span>
<span className="v" id="v20" data-v="20" data-xref="ルカの福音書 10:13–15; Jeremiah 8:6; テモテへの手紙第二 2:25–26"> それから、イエスは、数々の力あるわざの行なわれた町々が悔い改めなかったので、責め始められた。</span>
<span className="v" id="v21" data-v="21" data-xref="Ezekiel 3:6–7; 使徒の働き 12:20; ルカの福音書 9:10"> 「ああコラジン。ああベツサイダ。おまえたちのうちで行なわれた力あるわざが、もしもツロとシドンで行なわれたのだったら、彼らはとうの昔に荒布をまとい、灰をかぶって悔い改めていたことだろう。</span>
<span className="v" id="v22" data-v="22" data-xref="マタイの福音書 11:24; マタイの福音書 10:15; ヘブル人への手紙 10:26–31"> しかし、そのツロとシドンのほうが、おまえたちに言うが、さばきの日には、まだおまえたちよりは罰が軽いのだ。</span>
<span className="v" id="v23" data-v="23" data-xref="Isaiah 14:13–15; ヨハネの福音書 4:46–54; Genesis 13:13"> カペナウム。どうしておまえが天に上げられることがありえよう。ハデスに落とされるのだ。おまえの中でなされた力あるわざが、もしもソドムでなされたのだったら、ソドムはきょうまで残っていたことだろう。</span>
<span className="v" id="v24" data-v="24" data-xref="マタイの福音書 10:15; マタイの福音書 11:22; マルコの福音書 6:11"> しかし、そのソドムの地のほうが、おまえたちに言うが、さばきの日には、まだおまえよりは罰が軽いのだ。」</span>
<span className="v" id="v25" data-v="25" data-xref="マタイの福音書 21:16; Psalms 8:2; マタイの福音書 16:17"> そのとき、イエスはこう言われた。「天地の主であられる父よ。あなたをほめたたえます。これらのことを、賢い者や知恵のある者には隠して、幼子たちに現わしてくださいました。</span>
<span className="v" id="v26" data-v="26" data-xref="テモテへの手紙第二 1:9; エペソ人への手紙 1:11; Job 33:13"> そうです、父よ。これがみこころにかなったことでした。</span>
<span className="v" id="v27" data-v="27" data-xref="ヨハネの福音書 14:6–9; マタイの福音書 28:18; ルカの福音書 10:22"> すべてのものが、わたしの父から、わたしに渡されています。それで、父のほかには、子を知る者がなく、子と、子が父を知らせようと心に定めた人のほかは、だれも父を知る者がありません。</span>
<span className="v" id="v28" data-v="28" data-xref="マタイの福音書 11:29; ヨハネの福音書 7:37; ヨハネの福音書 6:37"> すべて、疲れた人、重荷を負っている人は、わたしのところに来なさい。わたしがあなたがたを休ませてあげます。</span>
<span className="v" id="v29" data-v="29" data-xref="Jeremiah 6:16; ヨハネの手紙第一 2:6; ピリピ人への手紙 2:7–8"> わたしは心優しく、へりくだっているから、あなたがたもわたしのくびきを負って、わたしから学びなさい。そうすればたましいに安らぎが来ます。</span>
<span className="v" id="v30" data-v="30" data-xref="ヨハネの手紙第一 5:3; ヨハネの福音書 16:33; ピリピ人への手紙 4:13"> わたしのくびきは負いやすく、わたしの荷は軽いからです。」</span>

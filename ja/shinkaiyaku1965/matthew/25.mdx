<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ルカの福音書 12:35–36; ピリピ人への手紙 2:15–16; マタイの福音書 24:42–51"> そこで、天の御国は、たとえて言えば、それぞれがともしびを持って、花婿を出迎える十人の娘のようです。</span>
<span className="v" id="v2" data-v="2" data-xref="Jeremiah 24:2; コリント人への手紙第一 10:1–5; マタイの福音書 13:19–23"> そのうち五人は愚かで、五人は賢かった。</span>
<span className="v" id="v3" data-v="3" data-xref="ヨハネの黙示録 3:15–16; テモテへの手紙第二 3:5; Isaiah 48:1–2"> 愚かな娘たちは、ともしびは持っていたが、油を用意しておかなかった。</span>
<span className="v" id="v4" data-v="4" data-xref="ローマ人への手紙 8:9; ヨハネの手紙第一 2:27; ヨハネの手紙第一 2:20"> 賢い娘たちは、自分のともしびといっしょに、入れ物に油を入れて持っていた。</span>
<span className="v" id="v5" data-v="5" data-xref="Habakkuk 2:3; テサロニケ人への手紙第一 5:6–8; ペテロの手紙第二 3:4–9"> 花婿が来るのが遅れたので、みな、うとうとして眠り始めた。</span>
<span className="v" id="v6" data-v="6" data-xref="ペテロの手紙第二 3:10; マタイの福音書 24:31; マタイの福音書 24:44"> ところが、夜中になって、『そら、花婿だ。迎えに出よ。』と叫ぶ声がした。</span>
<span className="v" id="v7" data-v="7" data-xref="ルカの福音書 12:35; ヨハネの黙示録 3:19–20; ペテロの手紙第二 3:14"> 娘たちは、みな起きて、自分のともしびを整えた。</span>
<span className="v" id="v8" data-v="8" data-xref="Proverbs 13:9; ルカの福音書 12:35; ヘブル人への手紙 4:1"> ところが愚かな娘たちは、賢い娘たちに言った。『油を少し私たちに分けてください。私たちのともしびは消えそうです。』</span>
<span className="v" id="v9" data-v="9" data-xref="Psalms 49:7–9; ヨハネの黙示録 3:17–18; Isaiah 55:6–7"> しかし、賢い娘たちは答えて言った。『いいえ、あなたがたに分けてあげるにはとうてい足りません。それよりも店に行って、自分のをお買いなさい。』</span>
<span className="v" id="v10" data-v="10" data-xref="ルカの福音書 13:25; マタイの福音書 24:44; ルカの福音書 12:36–37"> そこで、買いに行くと、その間に花婿が来た。用意のできていた娘たちは、彼といっしょに婚礼の祝宴に行き、戸がしめられた。</span>
<span className="v" id="v11" data-v="11" data-xref="マタイの福音書 7:21–23; ヘブル人への手紙 12:16–17"> そのあとで、ほかの娘たちも来て、『ご主人さま、ご主人さま。あけてください。』と言った。</span>
<span className="v" id="v12" data-v="12" data-xref="コリント人への手紙第一 8:3; テモテへの手紙第二 2:19; ヨハネの福音書 10:27"> しかし、彼は答えて、『確かなところ、私はあなたがたを知りません。』と言った。</span>
<span className="v" id="v13" data-v="13" data-xref="マタイの福音書 24:42–44; ヨハネの黙示録 16:15; テサロニケ人への手紙第一 5:6"> だから、目をさましていなさい。あなたがたは、その日、その時を知らないからです。</span>
<span className="v" id="v14" data-v="14" data-xref="マルコの福音書 13:34; ルカの福音書 19:12–27; ペテロの手紙第一 4:9–11"> 天の御国は、しもべたちを呼んで、自分の財産を預け、旅に出て行く人のようです。</span>
<span className="v" id="v15" data-v="15" data-xref="マタイの福音書 18:24; ルカの福音書 19:13–14; ルカの福音書 12:48"> 彼は、おのおのその能力に応じて、ひとりには五タラント、ひとりには二タラント、もうひとりには一タラントを渡し、それから旅に出かけた。</span>
<span className="v" id="v16" data-v="16" data-xref="ヨハネの手紙第三 1:5–8; テモテへの手紙第一 6:17–18; テモテへの手紙第二 2:6"> 五タラント預かった者は、すぐに行って、それで商売をして、さらに五タラントもうけた。</span>
<span className="v" id="v17" data-v="17" data-xref="Proverbs 3:9–10; エペソ人への手紙 5:16; ペテロの手紙第一 4:10"> 同様に、二タラント預かった者も、さらに二タラントもうけた。</span>
<span className="v" id="v18" data-v="18" data-xref="ペテロの手紙第二 1:8; Haggai 1:2–4; Malachi 1:10"> ところが、一タラント預かった者は、出て行くと、地を掘って、その主人の金を隠した。</span>
<span className="v" id="v19" data-v="19" data-xref="コリント人への手紙第一 3:12–15; コリント人への手紙第二 5:10; ローマ人への手紙 14:7–12"> さて、よほどたってから、しもべたちの主人が帰って来て、彼らと清算をした。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒の働き 20:24; ルカの福音書 19:16–17; コロサイ人への手紙 1:29"> すると、五タラント預かった者が来て、もう五タラント差し出して言った。『ご主人さま。私に五タラント預けてくださいましたが、ご覧ください。私はさらに五タラントもうけました。』</span>
<span className="v" id="v21" data-v="21" data-xref="マタイの福音書 25:23; ルカの福音書 16:10; ヨハネの福音書 12:26"> その主人は彼に言った。『よくやった。良い忠実なしもべだ。あなたは、わずかな物に忠実だったから、私はあなたにたくさんの物を任せよう。主人の喜びをともに喜んでくれ。』</span>
<span className="v" id="v22" data-v="22" data-xref="コリント人への手紙第二 8:12; コリント人への手紙第二 8:7–8; コリント人への手紙第二 8:1–3"> 二タラントの者も来て言った。『ご主人さま。私は二タラント預かりましたが、ご覧ください。さらに二タラントもうけました。』</span>
<span className="v" id="v23" data-v="23" data-xref="マタイの福音書 25:21; マルコの福音書 14:8–9; マルコの福音書 12:41–44"> その主人は彼に言った。『よくやった。良い忠実なしもべだ。あなたは、わずかな物に忠実だったから、私はあなたにたくさんの物を任せよう。主人の喜びをともに喜んでくれ。』</span>
<span className="v" id="v24" data-v="24" data-xref="ルカの福音書 19:20–22; ルカの福音書 15:29; Malachi 3:14–15"> ところが、一タラント預かっていた者も来て、言った。『ご主人さま。あなたは、蒔かない所から刈り取り、散らさない所から集めるひどい方だとわかっていました。</span>
<span className="v" id="v25" data-v="25" data-xref="テモテへの手紙第二 1:6–7; ローマ人への手紙 8:15; ヨハネの黙示録 21:8"> 私はこわくなり、出て行って、あなたの一タラントを地の中に隠しておきました。さあどうぞ、これがあなたの物です。』</span>
<span className="v" id="v26" data-v="26" data-xref="マタイの福音書 18:32; Job 15:5–6"> ところが、主人は彼に答えて言った。『悪いなまけ者のしもべだ。私が蒔かない所から刈り取り、散らさない所から集めることを知っていたというのか。</span>
<span className="v" id="v27" data-v="27" data-xref="Deuteronomy 23:19–20; ローマ人への手紙 3:19; ユダの手紙 1:15"> だったら、おまえはその私の金を、銀行に預けておくべきだった。そうすれば私は帰って来たときに、利息がついて返してもらえたのだ。</span>
<span className="v" id="v28" data-v="28" data-xref="ルカの福音書 19:24; ルカの福音書 10:42"> だから、そのタラントを彼から取り上げて、それを十タラント持っている者にやりなさい。』</span>
<span className="v" id="v29" data-v="29" data-xref="ルカの福音書 8:18; マルコの福音書 4:25; マタイの福音書 13:12"> だれでも持っている者は、与えられて豊かになり、持たない者は、持っているものまでも取り上げられるのです。</span>
<span className="v" id="v30" data-v="30" data-xref="マタイの福音書 8:12; ヨハネの黙示録 3:15–16; マタイの福音書 13:50"> 役に立たぬしもべは、外の暗やみに追い出しなさい。そこで泣いて歯ぎしりするのです。</span>
<span className="v" id="v31" data-v="31" data-xref="ヨハネの黙示録 1:7; テサロニケ人への手紙第二 1:7–8; マタイの福音書 19:28"> 人の子が、その栄光を帯びて、すべての御使いたちを伴って来るとき、人の子はその栄光の位に着きます。</span>
<span className="v" id="v32" data-v="32" data-xref="Malachi 3:18; マタイの福音書 13:49; コリント人への手紙第二 5:10"> そして、すべての国々の民が、その御前に集められます。彼は、羊飼いが羊と山羊とを分けるように、彼らをより分け、</span>
<span className="v" id="v33" data-v="33" data-xref="Psalms 100:3; ヨハネの福音書 10:26–28; ヨハネの福音書 21:15–17"> 羊を自分の右に、山羊を左に置きます。</span>
<span className="v" id="v34" data-v="34" data-xref="ペテロの手紙第一 1:19–20; ヤコブの手紙 2:5; ヨハネの黙示録 21:7"> そうして、王は、その右にいる者たちに言います。『さあ、わたしの父に祝福された人たち。世の初めから、あなたがたのために備えられた御国を継ぎなさい。</span>
<span className="v" id="v35" data-v="35" data-xref="ヨハネの手紙第一 3:16–19; ヤコブの手紙 2:15–16; Deuteronomy 15:7–11"> あなたがたは、わたしが空腹であったとき、わたしに食べる物を与え、わたしが渇いていたとき、わたしに飲ませ、わたしが旅人であったとき、わたしに宿を貸し、</span>
<span className="v" id="v36" data-v="36" data-xref="ヤコブの手紙 1:27; テモテへの手紙第二 1:16–18; ヤコブの手紙 5:14–15"> わたしが裸のとき、わたしに着る物を与え、わたしが病気をしたとき、わたしを見舞い、わたしが牢にいたとき、わたしをたずねてくれたからです。』</span>
<span className="v" id="v37" data-v="37" data-xref="マタイの福音書 6:3; 1 Chronicles 29:14; ペテロの手紙第一 5:5–6"> すると、その正しい人たちは、答えて言います。『主よ。いつ、私たちは、あなたが空腹なのを見て、食べる物を差し上げ、渇いておられるのを見て、飲ませてあげましたか。</span>
<span className="v" id="v38" data-v="38"> いつ、あなたが旅をしておられるときに、泊まらせてあげ、裸なのを見て、着る物を差し上げましたか。</span>
<span className="v" id="v39" data-v="39"> また、いつ、私たちは、あなたのご病気やあなたが牢におられるのを見て、おたずねしましたか。』</span>
<span className="v" id="v40" data-v="40" data-xref="Proverbs 19:17; Proverbs 14:31; マタイの福音書 10:42"> すると、王は彼らに答えて言います。『まことに、あなたがたに告げます。あなたがたが、これらのわたしの兄弟たち、しかも最も小さい者たちのひとりにしたのは、わたしにしたのです。』</span>
<span className="v" id="v41" data-v="41" data-xref="ペテロの手紙第二 2:4; ユダの手紙 1:6–7; テサロニケ人への手紙第二 1:9"> それから、王はまた、その左にいる者たちに言います。『のろわれた者ども。わたしから離れて、悪魔とその使いたちのために用意された永遠の火にはいれ。</span>
<span className="v" id="v42" data-v="42" data-xref="ヤコブの手紙 2:15–24; ヨハネの福音書 5:23; マタイの福音書 12:30"> おまえたちは、わたしが空腹であったとき、食べる物をくれず、渇いていたときにも飲ませず、</span>
<span className="v" id="v43" data-v="43"> わたしが旅人であったときにも泊まらせず、裸であったときにも着る物をくれず、病気のときや牢にいたときにもたずねてくれなかった。』</span>
<span className="v" id="v44" data-v="44" data-xref="マタイの福音書 7:22; ルカの福音書 10:29; マタイの福音書 25:24–27"> そのとき、彼らも答えて言います。『主よ。いつ、私たちは、あなたが空腹であり、渇き、旅をし、裸であり、病気をし、牢におられるのを見て、お世話をしなかったのでしょうか。』</span>
<span className="v" id="v45" data-v="45" data-xref="Proverbs 21:13; Proverbs 17:5; Proverbs 14:31"> すると、王は彼らに答えて言います。『まことに、おまえたちに告げます。おまえたちが、この最も小さい者たちのひとりにしなかったのは、わたしにしなかったのです。』</span>
<span className="v" id="v46" data-v="46" data-xref="Daniel 12:2; ヨハネの福音書 3:36; ヨハネの福音書 5:29"> こうして、この人たちは永遠の刑罰にはいり、正しい人たちは永遠のいのちにはいるのです。」</span>

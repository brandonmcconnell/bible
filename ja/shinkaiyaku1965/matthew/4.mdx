<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヘブル人への手紙 2:18; ルカの福音書 4:1–13; マルコの福音書 1:12–15"> さて、イエスは、悪魔の試みを受けるため、御霊に導かれて荒野に上って行かれた。</span>
<span className="v" id="v2" data-v="2" data-xref="Deuteronomy 9:18; Exodus 34:28; 1 Kings 19:8"> そして、四十日四十夜断食したあとで、空腹を覚えられた。</span>
<span className="v" id="v3" data-v="3" data-xref="Genesis 3:1–5; テサロニケ人への手紙第一 3:5; Numbers 11:4–6"> すると、試みる者が近づいて来て言った。「あなたが神の子なら、この石がパンになるように、命じなさい。」</span>
<span className="v" id="v4" data-v="4" data-xref="Deuteronomy 8:3; ルカの福音書 4:4; ヨハネの福音書 6:63"> イエスは答えて言われた。「『人はパンだけで生きるのではなく、神の口から出る一つ一つのことばによる。』と書いてある。」</span>
<span className="v" id="v5" data-v="5" data-xref="ルカの福音書 4:9; マタイの福音書 27:53; ヨハネの黙示録 11:2"> すると、悪魔はイエスを聖なる都に連れて行き、神殿の頂に立たせて、</span>
<span className="v" id="v6" data-v="6" data-xref="Psalms 91:11–12; ヘブル人への手紙 1:14; Psalms 34:7"> 言った。「あなたが神の子なら、下に身を投げてみなさい。『神は御使いたちに命じて、その手にあなたをささえさせ、あなたの足が石に打ち当たることのないようにされる。』と書いてありますから。」</span>
<span className="v" id="v7" data-v="7" data-xref="Deuteronomy 6:16; コリント人への手紙第一 10:9; Psalms 78:18"> イエスは言われた。「『あなたの神である主を試みてはならない。』とも書いてある。」</span>
<span className="v" id="v8" data-v="8" data-xref="ヨハネの手紙第一 2:15–16; ヨハネの黙示録 11:15; Psalms 49:16–17"> 今度は悪魔は、イエスを非常に高い山に連れて行き、この世のすべての国々とその栄華を見せて、</span>
<span className="v" id="v9" data-v="9" data-xref="コリント人への手紙第二 4:4; Daniel 5:18–19; ヨハネの福音書 16:11"> 言った。「もしひれ伏して私を拝むなら、これを全部あなたに差し上げましょう。」</span>
<span className="v" id="v10" data-v="10" data-xref="Deuteronomy 6:13–14; Deuteronomy 10:20; Joshua 24:14"> イエスは言われた。「引き下がれ、サタン。『あなたの神である主を拝み、主にだけ仕えよ。』と書いてある。」</span>
<span className="v" id="v11" data-v="11" data-xref="マタイの福音書 26:53; ヘブル人への手紙 1:14; ルカの福音書 22:43"> すると悪魔はイエスを離れて行き、見よ、御使いたちが近づいて来て仕えた。</span>
<span className="v" id="v12" data-v="12" data-xref="マルコの福音書 1:14; ルカの福音書 3:20; マタイの福音書 14:3"> ヨハネが捕えられたと聞いてイエスは、ガリラヤへ立ちのかれた。</span>
<span className="v" id="v13" data-v="13" data-xref="ヨハネの福音書 4:46; マルコの福音書 1:21; マタイの福音書 11:23"> そしてナザレを去って、カペナウムに来て住まわれた。ゼブルンとナフタリとの境にある、湖のほとりの町である。</span>
<span className="v" id="v14" data-v="14" data-xref="Isaiah 9:1–2; マタイの福音書 2:23; ルカの福音書 24:44"> これは、預言者イザヤを通して言われた事が、成就するためであった。すなわち、</span>
<span className="v" id="v15" data-v="15" data-xref="Isaiah 9:1; 2 Kings 15:29; Joshua 21:32"> 「ゼブルンの地とナフタリの地、湖に向かう道、 ヨルダンの向こう岸、異邦人のガリラヤ。</span>
<span className="v" id="v16" data-v="16" data-xref="Isaiah 9:2; Isaiah 42:6–7; Isaiah 60:1–3"> 暗やみの中にすわっていた民は偉大な光を見、 死の地と死の陰にすわっていた人々に、 光が上った。」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="マタイの福音書 3:2; 使徒の働き 2:38; マルコの福音書 1:14–15"> この時から、イエスは宣教を開始して、言われた。「悔い改めなさい。天の御国が近づいたから。」</span>
<span className="v" id="v18" data-v="18" data-xref="ヨハネの福音書 1:40–42; マタイの福音書 10:2; ルカの福音書 6:14"> イエスがガリラヤ湖のほとりを歩いておられたとき、ふたりの兄弟、ペテロと呼ばれるシモンとその兄弟アンデレをご覧になった。彼らは湖で網を打っていた。漁師だったからである。</span>
<span className="v" id="v19" data-v="19" data-xref="マルコの福音書 1:17–18; ヨハネの福音書 12:26; マタイの福音書 16:24"> イエスは彼らに言われた。「わたしについて来なさい。あなたがたを、人間をとる漁師にしてあげよう。」</span>
<span className="v" id="v20" data-v="20" data-xref="マルコの福音書 10:28–31; マタイの福音書 19:27; ルカの福音書 18:28–30"> 彼らはすぐに網を捨てて従った。</span>
<span className="v" id="v21" data-v="21" data-xref="マルコの福音書 1:19–20; マタイの福音書 10:2; マルコの福音書 3:17"> そこからなお行かれると、イエスは、別のふたりの兄弟、ゼベダイの子ヤコブとその兄弟ヨハネが、父ゼベダイといっしょに舟の中で網を繕っているのをご覧になり、ふたりをお呼びになった。</span>
<span className="v" id="v22" data-v="22" data-xref="マタイの福音書 10:37; ルカの福音書 9:59–60; Deuteronomy 33:9–10"> 彼らはすぐに舟も父も残してイエスに従った。</span>
<span className="v" id="v23" data-v="23" data-xref="マタイの福音書 9:35; マルコの福音書 1:39; 使徒の働き 10:38"> イエスはガリラヤ全土を巡って、会堂で教え、御国の福音を宣べ伝え、民の中のあらゆる病気、あらゆるわずらいを直された。</span>
<span className="v" id="v24" data-v="24" data-xref="マタイの福音書 8:6; マタイの福音書 17:15; ルカの福音書 5:15"> イエスのうわさはシリヤ全体に広まった。それで、人々は、さまざまの病気と痛みに苦しむ病人、悪霊につかれた人、てんかん持ちや、中風の者などをみな、みもとに連れて来た。イエスは彼らをお直しになった。</span>
<span className="v" id="v25" data-v="25" data-xref="ルカの福音書 6:17; マルコの福音書 5:20; マルコの福音書 3:7–8"> こうしてガリラヤ、デカポリス、エルサレム、ユダヤおよびヨルダンの向こう岸から大ぜいの群衆がイエスにつき従った。</span>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="Isaiah 40:3–6; ヨハネの福音書 1:6–8; ルカの福音書 1:76"> そのころ、バプテスマのヨハネが現われ、ユダヤの荒野で教えを宣べて、言った。</span>
<span className="v" id="v2" data-v="2" data-xref="マタイの福音書 4:17; マルコの福音書 1:15; Daniel 2:44"> 「悔い改めなさい。天の御国が近づいたから。」</span>
<span className="v" id="v3" data-v="3" data-xref="Isaiah 40:3; Malachi 3:1; ヨハネの福音書 1:23"> この人は預言者イザヤによって、<br />「荒野で叫ぶ者の声がする。『主の道を用意し、主の通られる道をまっすぐにせよ。』」<br />と言われたその人である。</span>
<span className="v" id="v4" data-v="4" data-xref="2 Kings 1:8; Zechariah 13:4; マルコの福音書 1:6"> このヨハネは、らくだの毛の着物を着、腰には皮の帯を締め、その食べ物はいなごと野蜜であった。</span>
<span className="v" id="v5" data-v="5" data-xref="マルコの福音書 1:5; ルカの福音書 3:7; ヨハネの福音書 3:23"> さて、エルサレム、ユダヤ全土、ヨルダン川沿いの全地域の人々がヨハネのところへ出て行き、</span>
<span className="v" id="v6" data-v="6" data-xref="使徒の働き 19:18; マタイの福音書 3:13–16; 使徒の働き 2:38–41"> 自分の罪を告白して、ヨルダン川で彼からバプテスマを受けた。</span>
<span className="v" id="v7" data-v="7" data-xref="マタイの福音書 12:34; テサロニケ人への手紙第一 1:10; ローマ人への手紙 5:9"> しかし、パリサイ人やサドカイ人が大ぜいバプテスマを受けに来るのを見たとき、ヨハネは彼らに言った。「まむしのすえたち。だれが必ず来る御怒りをのがれるように教えたのか。</span>
<span className="v" id="v8" data-v="8" data-xref="ルカの福音書 3:8; 使徒の働き 26:20; ペテロの手紙第二 1:4–8"> それなら、悔い改めにふさわしい実を結びなさい。</span>
<span className="v" id="v9" data-v="9" data-xref="ルカの福音書 3:8; ローマ人への手紙 9:7–8; ガラテヤ人への手紙 3:27–29"> 『われわれの先祖はアブラハムだ。』と心の中で言うような考えではいけません。あなたがたに言っておくが、神は、この石ころからでも、アブラハムの子孫を起こすことがおできになるのです。</span>
<span className="v" id="v10" data-v="10" data-xref="ヨハネの福音書 15:6; ルカの福音書 3:9; マタイの福音書 7:19"> 斧もすでに木の根元に置かれています。だから、良い実を結ばない木は、みな切り倒されて、火に投げ込まれます。</span>
<span className="v" id="v11" data-v="11" data-xref="Isaiah 4:4; ルカの福音書 3:16; 使徒の働き 1:5"> 私は、あなたがたが悔い改めるために、水のバプテスマを授けていますが、私のあとから来られる方は、私よりもさらに力のある方です。私はその方のはきものを脱がせてあげる値うちもありません。その方は、あなたがたに聖霊と火とのバプテスマをお授けになります。</span>
<span className="v" id="v12" data-v="12" data-xref="Malachi 4:1; マタイの福音書 13:30; ルカの福音書 3:17"> 手に箕を持っておられ、ご自分の脱穀場をすみずみまできよめられます。麦を倉に納め、殻を消えない火で焼き尽くされます。」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="ヨハネの福音書 1:32–34; マタイの福音書 2:22; マルコの福音書 1:9–11"> さて、イエスは、ヨハネからバプテスマを受けるために、ガリラヤからヨルダンにお着きになり、ヨハネのところに来られた。</span>
<span className="v" id="v14" data-v="14" data-xref="ヨハネの福音書 3:3–7; 使徒の働き 1:5–8; ヨハネの福音書 13:6–8"> しかし、ヨハネはイエスにそうさせまいとして、言った。「私こそ、あなたからバプテスマを受けるはずですのに、あなたが、私のところにおいでになるのですか。」</span>
<span className="v" id="v15" data-v="15" data-xref="ヨハネの福音書 4:34; ヨハネの福音書 15:10; Psalms 40:7–8"> ところが、イエスは答えて言われた。「今はそうさせてもらいたい。このようにして、すべての正しいことを実行するのは、わたしたちにふさわしいのです。」そこで、ヨハネは承知した。</span>
<span className="v" id="v16" data-v="16" data-xref="Isaiah 11:2; マルコの福音書 1:10; ルカの福音書 3:21–22"> こうして、イエスはバプテスマを受けて、すぐに水から上がられた。すると、天が開け、神の御霊が鳩のように下って、自分の上に来られるのをご覧になった。</span>
<span className="v" id="v17" data-v="17" data-xref="Isaiah 42:1; Psalms 2:7; マタイの福音書 17:5"> また、天からこう告げる声が聞こえた。「これは、わたしの愛する子、わたしはこれを喜ぶ。」</span>
</div>

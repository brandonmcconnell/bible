<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ルカの福音書 9:1–6; マルコの福音書 3:13–15; マルコの福音書 6:7–13"> イエスは十二弟子を呼び寄せて、汚れた霊どもを制する権威をお授けになった。霊どもを追い出し、あらゆる病気、あらゆるわずらいを直すためであった。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="マタイの福音書 4:21; 使徒の働き 1:13; ルカの福音書 5:10"> さて、十二使徒の名は次のとおりである。まず、ペテロと呼ばれるシモンとその兄弟アンデレ、ゼベダイの子ヤコブとその兄弟ヨハネ、</span>
<span className="v" id="v3" data-v="3" data-xref="マルコの福音書 3:18; 使徒の働き 1:13; マルコの福音書 2:14"> ピリポとバルトロマイ、トマスと取税人マタイ、アルパヨの子ヤコブとタダイ、</span>
<span className="v" id="v4" data-v="4" data-xref="マタイの福音書 26:14; マタイの福音書 26:47; ヨハネの福音書 13:2"> 熱心党員シモンとイエスを裏切ったイスカリオテ・ユダである。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="ヨハネの福音書 4:9; 使徒の働き 22:21–23; 2 Kings 17:24–41"> イエスは、この十二人を遣わし、そのとき彼らにこう命じられた。「異邦人の道に行ってはいけません。サマリヤ人の町にはいってはいけません。</span>
<span className="v" id="v6" data-v="6" data-xref="Jeremiah 50:6; Ezekiel 34:6; Isaiah 53:6"> イスラエルの家の滅びた羊のところに行きなさい。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒の働き 28:31; マタイの福音書 3:2; ルカの福音書 9:60"> 行って、『天の御国が近づいた。』と宣べ伝えなさい。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒の働き 3:6; ルカの福音書 10:9; 使徒の働き 4:30"> 病人を直し、死人を生き返らせ、らい病人をきよめ、悪霊を追い出しなさい。あなたがたは、ただで受けたのだから、ただで与えなさい。</span>
<span className="v" id="v9" data-v="9" data-xref="ルカの福音書 22:35; ルカの福音書 9:3–5; ルカの福音書 10:4–12"> 胴巻に金貨や銀貨や銅貨を入れてはいけません。</span>
<span className="v" id="v10" data-v="10" data-xref="ルカの福音書 10:7–12; テモテへの手紙第一 5:17–18; コリント人への手紙第一 9:4–14"> 旅行用の袋も、二枚目の下着も、くつも、杖も持たずに行きなさい。働く者が食べ物を与えられるのは当然だからです。</span>
<span className="v" id="v11" data-v="11" data-xref="ルカの福音書 10:7–8; Job 31:32; Judges 19:16–21"> どんな町や村にはいっても、そこでだれが適当な人かを調べて、そこを立ち去るまで、その人のところにとどまりなさい。</span>
<span className="v" id="v12" data-v="12" data-xref="1 Samuel 25:6; ルカの福音書 10:5–6; 使徒の働き 10:36"> その家にはいるときには、平安を祈るあいさつをしなさい。</span>
<span className="v" id="v13" data-v="13" data-xref="ルカの福音書 10:6; Psalms 35:13; コリント人への手紙第二 2:16"> その家がそれにふさわしい家なら、その平安はきっとその家に来るし、もし、ふさわしい家でないなら、その平安はあなたがたのところに返って来ます。</span>
<span className="v" id="v14" data-v="14" data-xref="ルカの福音書 10:10–11; 使徒の働き 18:6; Nehemiah 5:13"> もしだれも、あなたがたを受け入れず、あなたがたのことばに耳を傾けないなら、その家またはその町を出て行くときに、あなたがたの足のちりを払い落としなさい。</span>
<span className="v" id="v15" data-v="15" data-xref="ペテロの手紙第二 2:6; ヨハネの手紙第一 4:17; ヨハネの福音書 15:22–24"> まことに、あなたがたに告げます。さばきの日には、ソドムとゴモラの地でも、その町よりはまだ罰が軽いのです。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="ルカの福音書 10:3; ピリピ人への手紙 2:15; コリント人への手紙第一 14:20"> いいですか。わたしが、あなたがたを遣わすのは、狼の中に羊を送り出すようなものです。ですから、蛇のようにさとく、鳩のようにすなおでありなさい。</span>
<span className="v" id="v17" data-v="17" data-xref="マルコの福音書 13:9; マタイの福音書 23:34; 使徒の働き 26:11"> 人々には用心しなさい。彼らはあなたがたを議会に引き渡し、会堂でむち打ちますから。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒の働き 5:25–27; マタイの福音書 8:4; Psalms 2:1–6"> また、あなたがたは、わたしのゆえに、総督たちや王たちの前に連れて行かれます。それは、彼らと異邦人たちにあかしをするためです。</span>
<span className="v" id="v19" data-v="19" data-xref="Exodus 4:12; マルコの福音書 13:11–13; テモテへの手紙第二 4:17"> 人々があなたがたを引き渡したとき、どのように話そうか、何を話そうかと心配するには及びません。話すべきことは、そのとき示されるからです。</span>
<span className="v" id="v20" data-v="20" data-xref="ルカの福音書 21:15; 使徒の働き 6:10; ルカの福音書 12:12"> というのは、話すのはあなたがたではなく、あなたがたのうちにあって話されるあなたがたの父の御霊だからです。</span>
<span className="v" id="v21" data-v="21" data-xref="ルカの福音書 21:16–17; Micah 7:5–6; マルコの福音書 13:12–13"> 兄弟は兄弟を死に渡し、父は子を死に渡し、子どもたちは両親に立ち逆らって、彼らを死なせます。</span>
<span className="v" id="v22" data-v="22" data-xref="マタイの福音書 24:13; ヤコブの手紙 1:12; ヨハネの黙示録 2:10"> また、わたしの名のために、あなたがたはすべての人々に憎まれます。しかし、最後まで耐え忍ぶ者は救われます。</span>
<span className="v" id="v23" data-v="23" data-xref="マタイの福音書 16:28; 使徒の働き 8:1; マルコの福音書 13:26"> 彼らがこの町であなたがたを迫害するなら、次の町にのがれなさい。というわけは、確かなことをあなたがたに告げるのですが、人の子が来るときまでに、あなたがたは決してイスラエルの町々を巡り尽くせないからです。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="ヨハネの福音書 15:20; ルカの福音書 6:40; ヨハネの福音書 13:16"> 弟子はその師にまさらず、しもべはその主人にまさりません。</span>
<span className="v" id="v25" data-v="25" data-xref="ルカの福音書 11:15; マタイの福音書 12:24; マタイの福音書 9:34"> 弟子がその師のようになれたら十分だし、しもべがその主人のようになれたら十分です。彼らは家長をベルゼブルと呼ぶぐらいですから、ましてその家族の者のことは、何と呼ぶでしょう。</span>
<span className="v" id="v26" data-v="26" data-xref="ルカの福音書 8:17; マルコの福音書 4:22; Jeremiah 1:8"> だから、彼らを恐れてはいけません。おおわれているもので、現わされないものはなく、隠されているもので知られずに済むものはありません。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒の働き 5:20; ヨハネの福音書 16:13; ヨハネの福音書 16:1"> わたしが暗やみであなたがたに話すことを明るみで言いなさい。また、あなたがたが耳もとで聞くことを屋上で言い広めなさい。</span>
<span className="v" id="v28" data-v="28" data-xref="ルカの福音書 12:4–5; Isaiah 8:12–13; ヨハネの黙示録 2:10"> からだを殺しても、たましいを殺せない人たちなどを恐れてはなりません。そんなものより、たましいもからだも、ともにゲヘナで滅ぼすことのできる方を恐れなさい。</span>
<span className="v" id="v29" data-v="29" data-xref="ルカの福音書 12:6–7; Psalms 104:27–30"> 二羽の雀は一アサリオンで売っているでしょう。しかし、そんな雀の一羽でも、あなたがたの父のお許しなしには地に落ちることはありません。</span>
<span className="v" id="v30" data-v="30" data-xref="ルカの福音書 12:7; 1 Samuel 14:45; 使徒の働き 27:34"> また、あなたがたの頭の毛さえも、みな数えられています。</span>
<span className="v" id="v31" data-v="31" data-xref="ルカの福音書 12:24; Psalms 8:5; マタイの福音書 6:26"> だから恐れることはありません。あなたがたは、たくさんの雀よりもすぐれた者です。</span>
<span className="v" id="v32" data-v="32" data-xref="ヨハネの黙示録 3:5; ローマ人への手紙 10:9–10; ルカの福音書 12:8–9"> ですから、わたしを人の前で認める者はみな、わたしも、天におられるわたしの父の前でその人を認めます。</span>
<span className="v" id="v33" data-v="33" data-xref="テモテへの手紙第二 2:12; ルカの福音書 9:26; ルカの福音書 12:9"> しかし、人の前でわたしを知らないと言うような者なら、わたしも天におられるわたしの父の前で、そんな者は知らないと言います。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="ルカの福音書 12:49–53; 使徒の働き 14:4; 使徒の働き 13:45–50"> わたしが来たのは地に平和をもたらすためだと思ってはなりません。わたしは、平和をもたらすために来たのではなく、剣をもたらすために来たのです。</span>
<span className="v" id="v35" data-v="35" data-xref="Micah 7:5–6; マタイの福音書 10:21; ルカの福音書 21:16"> なぜなら、わたしは人をその父に、娘をその母に、嫁をそのしゅうとめに逆らわせるために来たからです。</span>
<span className="v" id="v36" data-v="36" data-xref="Micah 7:6; Jeremiah 12:6; Psalms 41:9"> さらに、家族の者がその人の敵となります。</span>
<span className="v" id="v37" data-v="37" data-xref="ルカの福音書 14:26; マタイの福音書 22:37; ピリピ人への手紙 3:7–9"> わたしよりも父や母を愛する者は、わたしにふさわしい者ではありません。また、わたしよりも息子や娘を愛する者は、わたしにふさわしい者ではありません。</span>
<span className="v" id="v38" data-v="38" data-xref="ルカの福音書 14:27; マルコの福音書 8:34; マタイの福音書 16:24"> 自分の十字架を負ってわたしについて来ない者は、わたしにふさわしい者ではありません。</span>
<span className="v" id="v39" data-v="39" data-xref="ヨハネの福音書 12:25; マルコの福音書 8:35–36; ルカの福音書 17:33"> 自分のいのちを自分のものとした者はそれを失い、わたしのために自分のいのちを失った者は、それを自分のものとします。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="ヨハネの福音書 13:20; ルカの福音書 9:48; ルカの福音書 10:16"> あなたがたを受け入れる者は、わたしを受け入れるのです。また、わたしを受け入れる者は、わたしを遣わした方を受け入れるのです。</span>
<span className="v" id="v41" data-v="41" data-xref="ヨハネの手紙第三 1:5–8; ヘブル人への手紙 6:10; 2 Kings 4:16–17"> 預言者を預言者だというので受け入れる者は、預言者の受ける報いを受けます。また、義人を義人だということで受け入れる者は、義人の受ける報いを受けます。</span>
<span className="v" id="v42" data-v="42" data-xref="ヘブル人への手紙 6:10; マタイの福音書 25:40; マルコの福音書 9:41–42"> わたしの弟子だというので、この小さい者たちのひとりに、水一杯でも飲ませるなら、まことに、あなたがたに告げます。その人は決して報いに漏れることはありません。」</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マタイの福音書 13:47; マタイの福音書 13:24; Song of Solomon 8:11–12"> 天の御国は、自分のぶどう園で働く労務者を雇いに朝早く出かけた主人のようなものです。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="1 Samuel 2:26; Ecclesiastes 12:1; マタイの福音書 22:19"> 彼は、労務者たちと一日一デナリの約束ができると、彼らをぶどう園にやった。</span>
<span className="v" id="v3" data-v="3" data-xref="テモテへの手紙第一 5:13; 使徒の働き 2:15; マタイの福音書 20:6–7"> それから、九時ごろに出かけてみると、別の人たちが市場に立っており、何もしないでいた。</span>
<span className="v" id="v4" data-v="4" data-xref="コリント人への手紙第一 6:11; ペテロの手紙第一 4:2–3; ルカの福音書 19:7–10"> そこで、彼はその人たちに言った。『あなたがたも、ぶどう園に行きなさい。相当のものを上げるから。』</span>
<span className="v" id="v5" data-v="5" data-xref="ヘブル人への手紙 11:24–26; 使徒の働き 10:3; マルコの福音書 15:33–34"> 彼らは出て行った。それからまた、十二時ごろと三時ごろに出かけて行って、同じようにした。</span>
<span className="v" id="v6" data-v="6" data-xref="ヘブル人への手紙 6:12; ヨハネの福音書 9:4; 使徒の働き 17:21"> また、五時ごろ出かけてみると、別の人たちが立っていたので、彼らに言った。『なぜ、一日中仕事もしないでここにいるのですか。』</span>
<span className="v" id="v7" data-v="7" data-xref="エペソ人への手紙 2:11–12; ヘブル人への手紙 6:10; ヨハネの福音書 9:4"> 彼らは言った。『だれも雇ってくれないからです。』彼は言った。『あなたがたも、ぶどう園に行きなさい。』</span>
<span className="v" id="v8" data-v="8" data-xref="Deuteronomy 24:15; ペテロの手紙第一 4:10; ローマ人への手紙 2:6–10"> こうして、夕方になったので、ぶどう園の主人は、監督に言った。『労務者たちを呼んで、最後に来た者たちから順に、最初に来た者たちにまで、賃金を払ってやりなさい。』</span>
<span className="v" id="v9" data-v="9" data-xref="マタイの福音書 20:6–7; ルカの福音書 23:40–43; マタイの福音書 20:2"> そこで、五時ごろに雇われた者たちが来て、それぞれ一デナリずつもらった。</span>
<span className="v" id="v10" data-v="10"> 最初の者たちがもらいに来て、もっと多くもらえるだろうと思ったが、彼らもやはりひとり一デナリずつであった。</span>
<span className="v" id="v11" data-v="11" data-xref="テサロニケ人への手紙第一 2:16; ルカの福音書 19:7; 使徒の働き 22:21–22"> そこで、彼らはそれを受け取ると、主人に文句をつけて、</span>
<span className="v" id="v12" data-v="12" data-xref="ローマ人への手紙 11:5–6; コリント人への手紙第二 11:23–28; ルカの福音書 12:55"> 言った。『この最後の連中は一時間しか働かなかったのに、あなたは私たちと同じにしました。私たちは一日中、労苦と焼けるような暑さを辛抱したのです。』</span>
<span className="v" id="v13" data-v="13" data-xref="マタイの福音書 26:50; マタイの福音書 22:12; ローマ人への手紙 9:14–15"> しかし、彼はそのひとりに答えて言った。『私はあなたに何も不当なことはしていない。あなたは私と一デナリの約束をしたではありませんか。</span>
<span className="v" id="v14" data-v="14" data-xref="ヨハネの福音書 17:2; ルカの福音書 15:31; マタイの福音書 6:6"> 自分の分を取って帰りなさい。ただ私としては、この最後の人にも、あなたと同じだけ上げたいのです。</span>
<span className="v" id="v15" data-v="15" data-xref="ローマ人への手紙 9:15–24; Deuteronomy 15:9; Jonah 4:1–4"> 自分のものを自分の思うようにしてはいけないという法がありますか。それとも、私が気前がいいので、あなたの目にはねたましく思われるのですか。』</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="マタイの福音書 19:30; マルコの福音書 10:31; マタイの福音書 22:14"> このように、あとの者が先になり、先の者があとになるものです。」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="マルコの福音書 10:32–34; ルカの福音書 18:31–34; マタイの福音書 16:13"> さて、イエスは、エルサレムに上ろうとしておられたが、十二弟子だけを呼んで、道々彼らに話された。</span>
<span className="v" id="v18" data-v="18" data-xref="マタイの福音書 16:21; 使徒の働き 2:23; マタイの福音書 27:1"> 「さあ、これから、わたしたちはエルサレムに向かって行きます。人の子は、祭司長、律法学者たちに引き渡されるのです。彼らは人の子を死刑に定めます。</span>
<span className="v" id="v19" data-v="19" data-xref="マタイの福音書 16:21; マルコの福音書 15:16–20; マタイの福音書 27:27–31"> そして、あざけり、むち打ち、十字架につけるため、異邦人に引き渡します。しかし、人の子は三日目によみがえります。」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="マタイの福音書 4:21; マルコの福音書 10:35–45; マタイの福音書 8:2"> そのとき、ゼベダイの子たちの母が、子どもたちといっしょにイエスのもとに来て、ひれ伏して、お願いがありますと言った。</span>
<span className="v" id="v21" data-v="21" data-xref="マタイの福音書 19:28; マルコの福音書 10:36–37; Esther 5:3"> イエスが彼女に、「どんな願いですか。」と言われると、彼女は言った。「私のこのふたりの息子が、あなたの御国で、ひとりはあなたの右に、ひとりは左にすわれるようにおことばを下さい。」</span>
<span className="v" id="v22" data-v="22" data-xref="マタイの福音書 26:42; ルカの福音書 22:42; マタイの福音書 26:39"> けれども、イエスは答えて言われた。「あなたがたは自分が何を求めているのか、わかっていないのです。わたしが飲もうとしている杯を飲むことができますか。」彼らは「できます。」と言った。</span>
<span className="v" id="v23" data-v="23" data-xref="ヨハネの黙示録 1:9; マタイの福音書 25:34; 使徒の働き 12:2"> イエスは言われた。「あなたがたはわたしの杯を飲みはします。しかし、わたしの右と左にすわることは、このわたしの許すことではなく、わたしの父によってそれに備えられた人々があるのです。」</span>
<span className="v" id="v24" data-v="24" data-xref="ペテロの手紙第一 5:5; ピリピ人への手紙 2:3; マルコの福音書 10:41"> このことを聞いたほかの十人は、このふたりの兄弟のことで腹を立てた。</span>
<span className="v" id="v25" data-v="25" data-xref="ルカの福音書 22:25–27; マタイの福音書 20:25–28; ヨハネの福音書 13:12–17"> そこで、イエスは彼らを呼び寄せて、言われた。「あなたがたも知っているとおり、異邦人の支配者たちは彼らを支配し、偉い人たちは彼らの上に権力をふるいます。</span>
<span className="v" id="v26" data-v="26" data-xref="マルコの福音書 10:43; マルコの福音書 9:35; マルコの福音書 10:45"> あなたがたの間では、そうではありません。あなたがたの間で偉くなりたいと思う者は、みなに仕える者になりなさい。</span>
<span className="v" id="v27" data-v="27" data-xref="ルカの福音書 22:26; マルコの福音書 9:33–35; マタイの福音書 18:4"> あなたがたの間で人の先に立ちたいと思う者は、あなたがたのしもべになりなさい。</span>
<span className="v" id="v28" data-v="28" data-xref="ルカの福音書 22:27; ヘブル人への手紙 9:28; テトスへの手紙 2:14"> 人の子が来たのが、仕えられるためではなく、かえって仕えるためであり、また、多くの人のための、贖いの代価として、自分のいのちを与えるためであるのと同じです。」</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="マルコの福音書 10:46–52; ルカの福音書 18:35–43; マタイの福音書 9:27–31"> 彼らがエリコを出て行くと、大ぜいの群衆がイエスについて行った。</span>
<span className="v" id="v30" data-v="30" data-xref="マルコの福音書 10:46; Isaiah 42:16; マタイの福音書 21:9"> すると、道ばたにすわっていたふたりの盲人が、イエスが通られると聞いて、叫んで言った。「主よ。私たちをあわれんでください。ダビデの子よ。」</span>
<span className="v" id="v31" data-v="31" data-xref="マタイの福音書 19:13; コロサイ人への手紙 4:2; マタイの福音書 7:7–8"> そこで、群衆は彼らを黙らせようとして、たしなめたが、彼らはますます、「主よ。私たちをあわれんでください。ダビデの子よ。」と叫び立てた。</span>
<span className="v" id="v32" data-v="32" data-xref="Ezekiel 36:37; ピリピ人への手紙 4:6; マタイの福音書 20:21"> すると、イエスは立ち止まって、彼らを呼んで言われた。「わたしに何をしてほしいのか。」</span>
<span className="v" id="v33" data-v="33" data-xref="Psalms 119:18; エペソ人への手紙 1:17–19"> 彼らはイエスに言った。「主よ。この目をあけていただきたいのです。」</span>
<span className="v" id="v34" data-v="34" data-xref="ヘブル人への手紙 4:15–16; マタイの福音書 9:29; 使徒の働き 26:18"> イエスはかわいそうに思って、彼らの目にさわられた。すると、すぐさま彼らは見えるようになり、イエスについて行った。</span>
</div>

<span className="v" id="v1" data-v="1" data-xref="ルカの福音書 12:1; ルカの福音書 20:45–46; マタイの福音書 15:10–20"> そのとき、イエスは群衆と弟子たちに話をして、</span>
<span className="v" id="v2" data-v="2" data-xref="ルカの福音書 20:46; マルコの福音書 12:38; Malachi 2:7"> こう言われた。「律法学者、パリサイ人たちは、モーセの座を占めています。</span>
<span className="v" id="v3" data-v="3" data-xref="テモテへの手紙第二 3:5; テトスへの手紙 1:16; ローマ人への手紙 2:19–24"> ですから、彼らがあなたがたに言うことはみな、行ない、守りなさい。けれども、彼らの行ないをまねてはいけません。彼らは言うことは言うが、実行しないからです。</span>
<span className="v" id="v4" data-v="4" data-xref="ルカの福音書 11:46; 使徒の働き 15:10; ガラテヤ人への手紙 6:13"> また、彼らは重い荷をくくって、人の肩に載せ、自分はそれに指一本さわろうとはしません。</span>
<span className="v" id="v5" data-v="5" data-xref="マタイの福音書 6:1–16; ヨハネの福音書 12:43; ピリピ人への手紙 2:3"> 彼らのしていることはみな、人に見せるためです。経札の幅を広くしたり、衣のふさを長くしたりするのもそうです。</span>
<span className="v" id="v6" data-v="6" data-xref="ヨハネの手紙第三 1:9; ルカの福音書 11:43–54; マルコの福音書 12:38–39"> また、宴会の上座や会堂の上席が大好きで、</span>
<span className="v" id="v7" data-v="7" data-xref="ヨハネの福音書 1:38; ヨハネの福音書 1:49; ヨハネの福音書 3:26"> 広場であいさつされたり、人から先生と呼ばれたりすることが好きです。</span>
<span className="v" id="v8" data-v="8" data-xref="ヤコブの手紙 3:1; コリント人への手紙第一 1:12–13; ペテロの手紙第一 5:3"> しかし、あなたがたは先生と呼ばれてはいけません。あなたがたの教師はただひとりしかなく、あなたがたはみな兄弟だからです。</span>
<span className="v" id="v9" data-v="9" data-xref="ヨハネの手紙第一 3:1; ヘブル人への手紙 12:9; Malachi 1:6"> あなたがたは地上のだれかを、われらの父と呼んではいけません。あなたがたの父はただひとり、すなわち天にいます父だけだからです。</span>
<span className="v" id="v10" data-v="10"> また、師と呼ばれてはいけません。あなたがたの師はただひとり、キリストだからです。</span>
<span className="v" id="v11" data-v="11" data-xref="コリント人への手紙第一 9:19; ガラテヤ人への手紙 5:13; ヨハネの福音書 13:14–15"> あなたがたのうちの一番偉大な者は、あなたがたに仕える人でなければなりません。</span>
<span className="v" id="v12" data-v="12" data-xref="ペテロの手紙第一 5:5; ヤコブの手紙 4:6; Proverbs 29:23"> だれでも、自分を高くする者は低くされ、自分を低くする者は高くされます。</span>
<span className="v" id="v13" data-v="13" data-xref="ルカの福音書 11:52; マタイの福音書 23:29; マタイの福音書 23:23"> しかし、わざわいが来ますぞ。偽善の律法学者、パリサイ人たち。あなたがたは、人々から天の御国をさえぎっているのです。自分もはいらず、はいろうとしている人々をもはいらせないのです。</span>
<span className="v" id="v14" data-v="14"> ［わざわいが来ますぞ。偽善の律法学者、パリサイ人たち。あなたがたは、やもめたちの家を食いつぶしていながら、見えのために長い祈りをするからです。ですから、あなたがたは、人一倍ひどい罰を受けます。］</span>
<span className="v" id="v15" data-v="15" data-xref="エペソ人への手紙 2:3; 使徒の働き 13:10; 使徒の働き 13:43"> わざわいが来ますぞ。偽善の律法学者、パリサイ人たち。改宗者をひとりつくるのに、海と陸とを飛び回り、改宗者ができると、その人を自分より倍も悪いゲヘナの子にするからです。</span>
<span className="v" id="v16" data-v="16" data-xref="マタイの福音書 15:14; マタイの福音書 5:33–35; ヤコブの手紙 5:12"> わざわいが来ますぞ。目の見えぬ手引きども。あなたがたはこう言う。『だれでも、神殿をさして誓ったのなら、何でもない。しかし、神殿の黄金をさして誓ったら、その誓いを果たさなければならない。』</span>
<span className="v" id="v17" data-v="17" data-xref="マタイの福音書 23:19; Numbers 16:38–39; Psalms 94:8"> 愚かで、目の見えぬ人たち。黄金と、黄金を神聖なものにする神殿と、どちらがたいせつなのか。</span>
<span className="v" id="v18" data-v="18"> また、こう言う。『だれでも、祭壇をさして誓ったのなら、何でもない。しかし、祭壇の上の供え物をさして誓ったら、その誓いを果たさなければならない。』</span>
<span className="v" id="v19" data-v="19" data-xref="Exodus 29:37; Exodus 30:29"> 目の見えぬ人たち。供え物と、その供え物を神聖なものにする祭壇と、どちらがたいせつなのか。</span>
<span className="v" id="v20" data-v="20"> ですから、祭壇をさして誓う者は、祭壇をも、その上のすべての物をもさして誓っているのです。</span>
<span className="v" id="v21" data-v="21" data-xref="Psalms 26:8; 1 Kings 8:13; 2 Chronicles 6:2"> また、神殿をさして誓う者は、神殿をも、その中に住まわれる方をもさして誓っているのです。</span>
<span className="v" id="v22" data-v="22" data-xref="マタイの福音書 5:34; Psalms 11:4; Isaiah 66:1"> 天をさして誓う者は、神の御座とそこに座しておられる方をさして誓うのです。</span>
<span className="v" id="v23" data-v="23" data-xref="ルカの福音書 11:42; Micah 6:8; Hosea 6:6"> わざわいが来ますぞ。偽善の律法学者、パリサイ人たち。あなたがたは、はっか、いのんど、クミンなどの十分の一を納めているが、律法の中ではるかに重要なもの、すなわち正義もあわれみも誠実もおろそかにしているのです。これこそしなければならないことです。ただし、他のほうもおろそかにしてはいけません。</span>
<span className="v" id="v24" data-v="24" data-xref="マタイの福音書 19:24; マタイの福音書 27:6–8; マタイの福音書 15:2–6"> 目の見えぬ手引きども。あなたがたは、ぶよは、こして除くが、らくだはのみこんでいます。</span>
<span className="v" id="v25" data-v="25" data-xref="ルカの福音書 11:39–40; マタイの福音書 15:19–20; マルコの福音書 7:4–13"> わざわいが来ますぞ。偽善の律法学者、パリサイ人たち。あなたがたは、杯や皿の外側はきよめるが、その中は強奪と放縦でいっぱいです。</span>
<span className="v" id="v26" data-v="26" data-xref="コリント人への手紙第二 7:1; ヤコブの手紙 4:8; ヘブル人への手紙 10:22"> 目の見えぬパリサイ人たち。まず、杯の内側をきよめなさい。そうすれば、外側もきよくなります。</span>
<span className="v" id="v27" data-v="27" data-xref="ルカの福音書 11:44; 使徒の働き 23:3; Numbers 19:16"> わざわいが来ますぞ。偽善の律法学者、パリサイ人たち。あなたがたは白く塗った墓のようなものです。墓はその外側は美しく見えても、内側は、死人の骨や、あらゆる汚れたものがいっぱいなように、</span>
<span className="v" id="v28" data-v="28" data-xref="ルカの福音書 16:15; Psalms 51:6; マタイの福音書 23:5"> あなたがたも、外側は人に正しいと見えても、内側は偽善と不法でいっぱいです。</span>
<span className="v" id="v29" data-v="29" data-xref="ルカの福音書 11:47–48; 使徒の働き 2:29"> わざわいが来ますぞ。偽善の律法学者、パリサイ人たち。あなたがたは預言者の墓を建て、義人の記念碑を飾って、</span>
<span className="v" id="v30" data-v="30" data-xref="Jeremiah 2:30; マタイの福音書 23:34–35; マタイの福音書 21:35–36"> 『私たちが、先祖の時代に生きていたら、預言者たちの血を流すような仲間にはならなかっただろう。』と言います。</span>
<span className="v" id="v31" data-v="31" data-xref="使徒の働き 7:51–52; テサロニケ人への手紙第一 2:15–16; Joshua 24:22"> こうして、預言者を殺した者たちの子孫だと、自分で証言しています。</span>
<span className="v" id="v32" data-v="32" data-xref="Genesis 15:16; Numbers 32:14; テサロニケ人への手紙第一 2:16"> あなたがたも先祖の罪の目盛りの不足分を満たしなさい。</span>
<span className="v" id="v33" data-v="33" data-xref="マタイの福音書 3:7; マタイの福音書 12:34; マタイの福音書 5:22"> おまえたち蛇ども、まむしのすえども。おまえたちは、ゲヘナの刑罰をどうしてのがれることができよう。</span>
<span className="v" id="v34" data-v="34" data-xref="マタイの福音書 10:16–17; マタイの福音書 13:52; コロサイ人への手紙 1:28"> だから、わたしが預言者、知者、律法学者たちを遣わすと、おまえたちはそのうちのある者を殺し、十字架につけ、またある者を会堂でむち打ち、町から町へと迫害して行くのです。</span>
<span className="v" id="v35" data-v="35" data-xref="2 Chronicles 24:20–22; Zechariah 1:1; ヘブル人への手紙 11:4"> それは、義人アベルの血からこのかた、神殿と祭壇との間で殺されたバラキヤの子ザカリヤの血に至るまで、地上で流されるすべての正しい血の報復があなたがたの上に来るためです。</span>
<span className="v" id="v36" data-v="36" data-xref="マタイの福音書 10:23; マタイの福音書 24:34; マルコの福音書 13:30–31"> まことに、あなたがたに告げます。これらの報いはみな、この時代の上に来ます。</span>
<span className="v" id="v37" data-v="37" data-xref="ルカの福音書 13:34–35; Ruth 2:12; Psalms 91:4"> ああ、エルサレム、エルサレム。預言者たちを殺し、自分に遣わされた人たちを石で打つ者。わたしは、めんどりがひなを翼の下に集めるように、あなたの子らを幾たび集めようとしたことか。それなのに、あなたがたはそれを好まなかった。</span>
<span className="v" id="v38" data-v="38" data-xref="Jeremiah 22:5; ルカの福音書 13:35; ルカの福音書 21:24"> 見なさい。あなたがたの家は荒れ果てたままに残される。</span>
<span className="v" id="v39" data-v="39" data-xref="Psalms 118:26; マタイの福音書 21:9; ローマ人への手紙 11:25"> あなたがたに告げます。『祝福あれ。主の御名によって来られる方に。』とあなたがたが言うときまで、あなたがたは今後決してわたしを見ることはありません。」</span>

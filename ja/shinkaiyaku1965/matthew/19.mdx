<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨハネの福音書 10:40; マタイの福音書 19:1–9; マタイの福音書 7:28"> イエスはこの話を終えると、ガリラヤを去って、ヨルダンの向こうにあるユダヤ地方に行かれた。</span>
<span className="v" id="v2" data-v="2" data-xref="マタイの福音書 12:15; マルコの福音書 6:55–56; マタイの福音書 15:30–31"> すると、大ぜいの群衆がついて来たので、そこで彼らをおいやしになった。</span>
<span className="v" id="v3" data-v="3" data-xref="マルコの福音書 10:2; ヘブル人への手紙 3:9; マタイの福音書 16:1"> パリサイ人たちがみもとにやって来て、イエスを試みて、こう言った。「何か理由があれば、妻を離別することは律法にかなっているでしょうか。」</span>
<span className="v" id="v4" data-v="4" data-xref="Genesis 2:23; Genesis 1:27; Genesis 5:2"> イエスは答えて言われた。「創造者は、初めから人を男と女に造って、</span>
<span className="v" id="v5" data-v="5" data-xref="Genesis 2:21–24; コリント人への手紙第一 7:4; コリント人への手紙第一 7:2"> 『それゆえ、人はその父と母を離れて、その妻と結ばれ、ふたりの者が一心同体になるのだ。』と言われたのです。それを、あなたがたは読んだことがないのですか。</span>
<span className="v" id="v6" data-v="6" data-xref="ヘブル人への手紙 13:4; マルコの福音書 10:9; コリント人への手紙第一 7:10–14"> それで、もはやふたりではなく、ひとりなのです。こういうわけで、人は、神が結び合わせたものを引き離してはなりません。」</span>
<span className="v" id="v7" data-v="7" data-xref="Deuteronomy 24:1–4; マタイの福音書 5:31; マルコの福音書 10:4"> 彼らはイエスに言った。「では、モーセはなぜ、離婚状を渡して妻を離別せよ、と命じたのですか。」</span>
<span className="v" id="v8" data-v="8" data-xref="Malachi 2:13–14; Genesis 2:24; マルコの福音書 10:5"> イエスは彼らに言われた。「モーセは、あなたがたの心がかたくななので、その妻を離別することをあなたがたに許したのです。しかし、初めからそうだったのではありません。</span>
<span className="v" id="v9" data-v="9" data-xref="マタイの福音書 5:32; ルカの福音書 16:18; コリント人への手紙第一 7:39"> まことに、あなたがたに告げます。だれでも、不貞のためでなくて、その妻を離別し、別の女を妻にする者は姦淫を犯すのです。」</span>
<span className="v" id="v10" data-v="10" data-xref="コリント人への手紙第一 7:32–35; Proverbs 19:13–14; Proverbs 21:19"> 弟子たちはイエスに言った。「もし妻に対する夫の立場がそんなものなら、結婚しないほうがましです。」</span>
<span className="v" id="v11" data-v="11" data-xref="コリント人への手紙第一 7:17; コリント人への手紙第一 7:35; コリント人への手紙第一 7:7–9"> しかし、イエスは言われた。「そのことばは、だれでも受け入れることができるわけではありません。ただ、それが許されている者だけができるのです。</span>
<span className="v" id="v12" data-v="12" data-xref="コリント人への手紙第一 7:32–38; コリント人への手紙第一 9:5; Isaiah 56:3–4"> というのは、母の胎内から、そのように生まれついた独身者がいます。また、人から独身者にさせられた者もいます。また、天の御国のために、自分から独身者になった者もいるからです。それができる者はそれを受け入れなさい。」</span>
<span className="v" id="v13" data-v="13" data-xref="マルコの福音書 10:13–16; ルカの福音書 18:15–17; マタイの福音書 18:2–5"> そのとき、イエスに手を置いて祈っていただくために、子どもたちが連れて来られた。ところが、弟子たちは彼らをしかった。</span>
<span className="v" id="v14" data-v="14" data-xref="マタイの福音書 18:3; ルカの福音書 18:16–17; コリント人への手紙第一 14:20"> しかし、イエスは言われた。「子どもたちを許してやりなさい。邪魔をしないでわたしのところに来させなさい。天の御国はこのような者たちの国なのです。」</span>
<span className="v" id="v15" data-v="15" data-xref="マルコの福音書 10:16; テモテへの手紙第二 3:15; コリント人への手紙第一 7:14"> そして、手を彼らの上に置いてから、そこを去って行かれた。</span>
<span className="v" id="v16" data-v="16" data-xref="マルコの福音書 10:17–30; ヨハネの福音書 3:15; ユダの手紙 1:21"> すると、ひとりの人がイエスのもとに来て言った。「先生。永遠のいのちを得るためには、どんな良いことをしたらよいのでしょうか。」</span>
<span className="v" id="v17" data-v="17" data-xref="Leviticus 18:5; ルカの福音書 10:26–28; ガラテヤ人への手紙 3:11–13"> イエスは彼に言われた。「なぜ、良いことについて、わたしに尋ねるのですか。良い方は、ひとりだけです。もし、いのちにはいりたいと思うなら、戒めを守りなさい。」</span>
<span className="v" id="v18" data-v="18" data-xref="Deuteronomy 5:16–21; Exodus 20:12–17; マルコの福音書 10:19"> 彼は「どの戒めですか。」と言った。そこで、イエスは言われた。「殺してはならない。姦淫してはならない。盗んではならない。偽証をしてはならない。</span>
<span className="v" id="v19" data-v="19" data-xref="Leviticus 19:18; Exodus 20:12; マタイの福音書 22:39"> 父と母を敬え。あなたの隣人をあなた自身のように愛せよ。」</span>
<span className="v" id="v20" data-v="20" data-xref="ガラテヤ人への手紙 3:24; マルコの福音書 10:20–21; ピリピ人への手紙 3:6"> この青年はイエスに言った。「そのようなことはみな、守っております。何がまだ欠けているのでしょうか。」</span>
<span className="v" id="v21" data-v="21" data-xref="マルコの福音書 10:21; ルカの福音書 18:22; ルカの福音書 12:33"> イエスは、彼に言われた。「もし、あなたが完全になりたいなら、帰って、あなたの持ち物を売り払って貧しい人たちに与えなさい。そうすれば、あなたは天に宝を積むことになります。そのうえで、わたしについて来なさい。」</span>
<span className="v" id="v22" data-v="22" data-xref="マタイの福音書 6:24; Ezekiel 33:31; マタイの福音書 13:22"> ところが、青年はこのことばを聞くと、悲しんで去って行った。この人は多くの財産を持っていたからである。</span>
<span className="v" id="v23" data-v="23" data-xref="テモテへの手紙第一 6:9–10; マタイの福音書 13:22; マルコの福音書 10:23"> それから、イエスは弟子たちに言われた。「まことに、あなたがたに告げます。金持ちが天の御国にはいるのはむずかしいことです。</span>
<span className="v" id="v24" data-v="24" data-xref="ヨハネの福音書 5:44; ルカの福音書 18:25; マルコの福音書 10:24–25"> まことに、あなたがたにもう一度、告げます。金持ちが神の国にはいるよりは、らくだが針の穴を通るほうがもっとやさしい。」</span>
<span className="v" id="v25" data-v="25" data-xref="ローマ人への手紙 10:13; マタイの福音書 24:22; ローマ人への手紙 11:5–7"> 弟子たちは、これを聞くと、たいへん驚いて言った。「それでは、だれが救われることができるのでしょう。」</span>
<span className="v" id="v26" data-v="26" data-xref="Jeremiah 32:27; ルカの福音書 1:37; Job 42:2"> イエスは彼らをじっと見て言われた。「それは人にはできないことです。しかし、神にはどんなことでもできます。」</span>
<span className="v" id="v27" data-v="27" data-xref="ピリピ人への手紙 3:8; ルカの福音書 18:28; ルカの福音書 5:11"> そのとき、ペテロはイエスに答えて言った。「ご覧ください。私たちは、何もかも捨てて、あなたに従ってまいりました。私たちは何がいただけるでしょうか。」</span>
<span className="v" id="v28" data-v="28" data-xref="ルカの福音書 22:28–30; コリント人への手紙第一 6:2–3; マタイの福音書 25:31"> そこで、イエスは彼らに言われた。「まことに、あなたがたに告げます。世が改まって人の子がその栄光の座に着く時、わたしに従って来たあなたがたも十二の座に着いて、イスラエルの十二の部族をさばくのです。</span>
<span className="v" id="v29" data-v="29" data-xref="ルカの福音書 18:29–30; マルコの福音書 10:29–30; ピリピ人への手紙 3:8"> また、わたしの名のために、家、兄弟、姉妹、父、母、子、あるいは畑を捨てた者はすべて、その幾倍もを受け、また永遠のいのちを受け継ぎます。</span>
<span className="v" id="v30" data-v="30" data-xref="マタイの福音書 20:16; ルカの福音書 13:30; マルコの福音書 10:31"> ただ、先の者があとになり、あとの者が先になることが多いのです。</span>

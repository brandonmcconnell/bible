<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マルコの福音書 3:22; マタイの福音書 23:2; ルカの福音書 5:21"> そのころ、パリサイ人や律法学者たちが、エルサレムからイエスのところに来て、言った。</span>
<span className="v" id="v2" data-v="2" data-xref="ルカの福音書 11:38; マルコの福音書 7:2; コロサイ人への手紙 2:20–23"> 「あなたの弟子たちは、なぜ昔の先祖たちの言い伝えを犯すのですか。パンを食べるときに手を洗っていないではありませんか。」</span>
<span className="v" id="v3" data-v="3" data-xref="コロサイ人への手紙 2:23; テトスへの手紙 1:14; コロサイ人への手紙 2:8"> そこで、イエスは彼らに答えて言われた。「なぜ、あなたがたも、自分たちの言い伝えのために神の戒めを犯すのですか。</span>
<span className="v" id="v4" data-v="4" data-xref="Exodus 20:12; Leviticus 20:9; Exodus 21:17"> 神は『あなたの父と母を敬え。』また『父や母をののしる者は、死刑に処せられる。』と言われたのです。</span>
<span className="v" id="v5" data-v="5" data-xref="マルコの福音書 7:10–13; 使徒の働き 5:29; マタイの福音書 23:16–18"> それなのに、あなたがたは、『だれでも、父や母に向かって、私からあなたのために差し上げられる物は、供え物になりましたと言う者は、</span>
<span className="v" id="v6" data-v="6" data-xref="テモテへの手紙第一 5:8; Jeremiah 8:8; マルコの福音書 7:13"> その物をもって父や母を尊んではならない。』と言っています。こうしてあなたがたは、自分たちの言い伝えのために、神のことばを無にしてしまいました。</span>
<span className="v" id="v7" data-v="7" data-xref="マルコの福音書 7:6; マタイの福音書 23:23–29; 使徒の働き 28:25–27"> 偽善者たち。イザヤはあなたがたについて預言しているが、まさにそのとおりです。</span>
<span className="v" id="v8" data-v="8" data-xref="Isaiah 29:13; Ezekiel 33:31; 使徒の働き 8:21"> 『この民は、口先ではわたしを敬うが、 その心は、わたしから遠く離れている。</span>
<span className="v" id="v9" data-v="9" data-xref="Isaiah 29:13; マルコの福音書 7:7; テモテへの手紙第一 1:4"> 彼らが、わたしを拝んでも、むだなことである。 人間の教えを、教えとして教えるだけだから。』」</span>
<span className="v" id="v10" data-v="10" data-xref="マルコの福音書 7:14–15; ルカの福音書 20:45–47; ルカの福音書 24:45"> イエスは群衆を呼び寄せて言われた。「聞いて悟りなさい。</span>
<span className="v" id="v11" data-v="11" data-xref="マルコの福音書 7:15; マタイの福音書 15:18–20; ヤコブの手紙 3:5–8"> 口にはいる物は人を汚しません。しかし、口から出るもの、これが人を汚します。」</span>
<span className="v" id="v12" data-v="12" data-xref="1 Kings 22:13–14; コリント人への手紙第一 10:32–33; ガラテヤ人への手紙 2:5"> そのとき、弟子たちが、近寄って来て、イエスに言った。「パリサイ人が、みことばを聞いて、腹を立てたのをご存じですか。」</span>
<span className="v" id="v13" data-v="13" data-xref="ヨハネの福音書 15:2; Isaiah 60:21; ヨハネの福音書 15:6"> しかし、イエスは答えて言われた。「わたしの天の父がお植えにならなかった木は、みな根こそぎにされます。</span>
<span className="v" id="v14" data-v="14" data-xref="ルカの福音書 6:39; Isaiah 56:10; マタイの福音書 23:16–24"> 彼らのことは放っておきなさい。彼らは盲人を手引きする盲人です。もし、盲人が盲人を手引きするなら、ふたりとも穴に落ち込むのです。」</span>
<span className="v" id="v15" data-v="15" data-xref="マタイの福音書 13:36; マルコの福音書 4:34; ヨハネの福音書 16:29"> そこで、ペテロは、イエスに答えて言った。「私たちに、そのたとえを説明してください。」</span>
<span className="v" id="v16" data-v="16" data-xref="マタイの福音書 16:9; マルコの福音書 7:18; マルコの福音書 9:32"> イエスは言われた。「あなたがたも、まだわからないのですか。</span>
<span className="v" id="v17" data-v="17" data-xref="ルカの福音書 6:45; コリント人への手紙第一 6:13; マタイの福音書 7:19–20"> 口にはいる物はみな、腹にはいり、かわやに捨てられることを知らないのですか。</span>
<span className="v" id="v18" data-v="18" data-xref="Proverbs 15:28; マタイの福音書 12:34; ヤコブの手紙 3:6–10"> しかし、口から出るものは、心から出て来ます。それは人を汚します。</span>
<span className="v" id="v19" data-v="19" data-xref="マルコの福音書 7:21–23; ガラテヤ人への手紙 5:19–21; Jeremiah 17:9"> 悪い考え、殺人、姦淫、不品行、盗み、偽証、ののしりは心から出て来るからです。</span>
<span className="v" id="v20" data-v="20" data-xref="マルコの福音書 7:3–4; エペソ人への手紙 5:3–6; コリント人への手紙第一 6:18–20"> これらは、人を汚すものです。しかし、洗わない手で食べることは人を汚しません。」</span>
<span className="v" id="v21" data-v="21" data-xref="マルコの福音書 7:24–30; マタイの福音書 11:21–23; Judges 1:31"> それから、イエスはそこを去って、ツロとシドンの地方に立ちのかれた。</span>
<span className="v" id="v22" data-v="22" data-xref="マタイの福音書 9:27; マルコの福音書 7:25–26; マタイの福音書 17:15"> すると、その地方のカナン人の女が出て来て、叫び声をあげて言った。「主よ。ダビデの子よ。私をあわれんでください。娘が、ひどく悪霊に取りつかれているのです。」</span>
<span className="v" id="v23" data-v="23" data-xref="マタイの福音書 14:15; マルコの福音書 10:47–48; Lamentations 3:8"> しかし、イエスは彼女に一言もお答えにならなかった。そこで、弟子たちはみもとに来て、「あの女を帰してやってください。叫びながらあとについて来るのです。」と言ってイエスに願った。</span>
<span className="v" id="v24" data-v="24" data-xref="マタイの福音書 10:5–6; ローマ人への手紙 15:8; Jeremiah 50:6–7"> しかし、イエスは答えて、「わたしは、イスラエルの家の滅びた羊以外のところには遣わされていません。」と言われた。</span>
<span className="v" id="v25" data-v="25" data-xref="Genesis 32:26; マタイの福音書 20:31; マタイの福音書 14:33"> しかし、その女は来て、イエスの前にひれ伏して、「主よ。私をお助けください。」と言った。</span>
<span className="v" id="v26" data-v="26" data-xref="マルコの福音書 7:27–28; マタイの福音書 7:6; ピリピ人への手紙 3:2"> すると、イエスは答えて、「子どもたちのパンを取り上げて、小犬に投げてやるのはよくないことです。」と言われた。</span>
<span className="v" id="v27" data-v="27" data-xref="エペソ人への手紙 3:8; ルカの福音書 16:21; Job 40:4–5"> しかし、女は言った。「主よ。そのとおりです。ただ、小犬でも主人の食卓から落ちるパンくずはいただきます。」</span>
<span className="v" id="v28" data-v="28" data-xref="マルコの福音書 9:23–24; マタイの福音書 8:13; Psalms 145:19"> そのとき、イエスは彼女に答えて言われた。「ああ、あなたの信仰はりっぱです。その願いどおりになるように。」すると、彼女の娘はその時から直った。</span>
<span className="v" id="v29" data-v="29" data-xref="マタイの福音書 4:18; ヨハネの福音書 6:1; マタイの福音書 5:1"> それから、イエスはそこを去って、ガリラヤ湖の岸を行き、山に登って、そこにすわっておられた。</span>
<span className="v" id="v30" data-v="30" data-xref="ルカの福音書 6:17–19; 使徒の働き 5:15–16; マタイの福音書 14:35–36"> すると、大ぜいの人の群れが、足なえ、不具者、盲人、おしの人、そのほかたくさんの人をみもとに連れて来た。そして、彼らをイエスの足もとに置いたので、イエスは彼らをおいやしになった。</span>
<span className="v" id="v31" data-v="31" data-xref="マタイの福音書 9:8; ルカの福音書 18:43; ルカの福音書 17:15–18"> それで、群衆は、おしがものを言い、不具者が直り、足なえが歩き、盲人が見えるようになったのを見て、驚いた。そして、彼らはイスラエルの神をあがめた。</span>
<span className="v" id="v32" data-v="32" data-xref="使徒の働き 27:33; ルカの福音書 12:29–30; マタイの福音書 9:36"> イエスは弟子たちを呼び寄せて言われた。「かわいそうに、この群衆はもう三日間もわたしといっしょにいて、食べる物を持っていないのです。彼らを空腹のままで帰らせたくありません。途中で動けなくなるといけないから。」</span>
<span className="v" id="v33" data-v="33" data-xref="マルコの福音書 6:37; マタイの福音書 14:15; マルコの福音書 8:4–5"> そこで弟子たちは言った。「このへんぴな所で、こんなに大ぜいの人に、十分食べさせるほどたくさんのパンが、どこから手にはいるでしょう。」</span>
<span className="v" id="v34" data-v="34" data-xref="マタイの福音書 16:9–10; ルカの福音書 24:41–42; ヨハネの福音書 21:9–10"> すると、イエスは彼らに言われた。「どれぐらいパンがありますか。」彼らは言った。「七つです。それに、小さい魚が少しあります。」</span>
<span className="v" id="v35" data-v="35" data-xref="ルカの福音書 9:14–16; マルコの福音書 6:39–40; ヨハネの福音書 6:10"> すると、イエスは群衆に、地面にすわるように命じられた。</span>
<span className="v" id="v36" data-v="36" data-xref="ルカの福音書 22:19; ローマ人への手紙 14:6; ヨハネの福音書 6:11"> それから、七つのパンと魚とを取り、感謝をささげてからそれを裂き、弟子たちに与えられた。そして、弟子たちは群衆に配った。</span>
<span className="v" id="v37" data-v="37" data-xref="マルコの福音書 8:19–21; マタイの福音書 16:9–10; マタイの福音書 15:33"> 人々はみな、食べて満腹した。そして、パン切れの余りを取り集めると、七つのかごにいっぱいあった。</span>
<span className="v" id="v38" data-v="38"> 食べた者は、女と子どもを除いて、男四千人であった。</span>
<span className="v" id="v39" data-v="39" data-xref="マルコの福音書 8:10; マタイの福音書 14:22"> それから、イエスは群衆を解散させて舟に乗り、マガダン地方に行かれた。</span>

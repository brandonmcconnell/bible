<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マルコの福音書 9:33–37; ルカの福音書 9:46–48; マタイの福音書 20:20–28"> そのとき、弟子たちがイエスのところに来て言った。「それでは、天の御国では、だれが一番偉いのでしょうか。」</span>
<span className="v" id="v2" data-v="2" data-xref="マタイの福音書 19:13–14; マルコの福音書 9:36–37; 1 Kings 3:7"> そこで、イエスは小さい子どもを呼び寄せ、彼らの真中に立たせて、</span>
<span className="v" id="v3" data-v="3" data-xref="マルコの福音書 10:14–15; ペテロの手紙第一 2:2; マタイの福音書 19:14"> 言われた。「まことに、あなたがたに告げます。あなたがたも悔い改めて子どもたちのようにならない限り、決して天の御国には、はいれません。</span>
<span className="v" id="v4" data-v="4" data-xref="ヤコブの手紙 4:10; ルカの福音書 14:11; マルコの福音書 10:43"> だから、この子どものように、自分を低くする者が、天の御国で一番偉い人です。</span>
<span className="v" id="v5" data-v="5" data-xref="マタイの福音書 25:40; マルコの福音書 9:37; ヨハネの福音書 13:20"> また、だれでも、このような子どものひとりを、わたしの名のゆえに受け入れる者は、わたしを受け入れるのです。</span>
<span className="v" id="v6" data-v="6" data-xref="マルコの福音書 9:42; ルカの福音書 17:1–2; マタイの福音書 18:10"> しかし、わたしを信じるこの小さい者たちのひとりにでもつまずきを与えるような者は、大きい石臼を首にかけられて、湖の深みでおぼれ死んだほうがましです。</span>
<span className="v" id="v7" data-v="7" data-xref="ルカの福音書 17:1; コリント人への手紙第一 11:19; マタイの福音書 26:24"> つまずきを与えるこの世は忌まわしいものです。つまずきが起こることは避けられないが、つまずきをもたらす者は忌まわしいものです。</span>
<span className="v" id="v8" data-v="8" data-xref="マタイの福音書 5:29–30; ピリピ人への手紙 3:8–9; ローマ人への手紙 13:12"> もし、あなたの手か足の一つがあなたをつまずかせるなら、それを切って捨てなさい。片手片足でいのちにはいるほうが、両手両足そろっていて永遠の火に投げ入れられるよりは、あなたにとってよいことです。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒の働き 14:22; マタイの福音書 18:8; マタイの福音書 5:29"> また、もし、あなたの一方の目が、あなたをつまずかせるなら、それをえぐり出して捨てなさい。片目でいのちにはいるほうが、両目そろっていて燃えるゲヘナに投げ入れられるよりは、あなたにとってよいことです。</span>
<span className="v" id="v10" data-v="10" data-xref="Psalms 91:11; Psalms 34:7; ヘブル人への手紙 1:14"> あなたがたは、この小さい者たちを、ひとりでも見下げたりしないように気をつけなさい。まことに、あなたがたに告げます。彼らの天の御使いたちは、天におられるわたしの父の御顔をいつも見ているからです。</span>
<span className="v" id="v11" data-v="11"> ［人の子は、滅んでいる者を救うために来たのです。］</span>
<span className="v" id="v12" data-v="12" data-xref="Ezekiel 34:12; ルカの福音書 15:4–7; Ezekiel 34:16"> あなたがたはどう思いますか。もし、だれかが百匹の羊を持っていて、そのうちの一匹が迷い出たとしたら、その人は九十九匹を山に残して、迷った一匹を捜しに出かけないでしょうか。</span>
<span className="v" id="v13" data-v="13" data-xref="Zephaniah 3:17; ルカの福音書 15:5–10; ヤコブの手紙 2:13"> そして、もし、いたとなれば、まことに、あなたがたに告げます。その人は迷わなかった九十九匹の羊以上にこの一匹を喜ぶのです。</span>
<span className="v" id="v14" data-v="14" data-xref="ヨハネの福音書 17:12; ヨハネの福音書 6:39–40; ペテロの手紙第二 3:9"> このように、この小さい者たちのひとりが滅びることは、天にいますあなたがたの父のみこころではありません。</span>
<span className="v" id="v15" data-v="15" data-xref="Leviticus 19:17; ルカの福音書 17:3–4; ガラテヤ人への手紙 6:1"> また、もし、あなたの兄弟が罪を犯したなら、行って、ふたりだけのところで責めなさい。もし聞き入れたら、あなたは兄弟を得たのです。</span>
<span className="v" id="v16" data-v="16" data-xref="Deuteronomy 19:15; コリント人への手紙第二 13:1; ヨハネの福音書 8:17"> もし聞き入れないなら、ほかにひとりかふたりをいっしょに連れて行きなさい。ふたりか三人の証人の口によって、すべての事実が確認されるためです。</span>
<span className="v" id="v17" data-v="17" data-xref="テサロニケ人への手紙第二 3:6; コリント人への手紙第一 5:9–7; テサロニケ人への手紙第二 3:14–15"> それでもなお、言うことを聞き入れようとしないなら、教会に告げなさい。教会の言うことさえも聞こうとしないなら、彼を異邦人か取税人のように扱いなさい。</span>
<span className="v" id="v18" data-v="18" data-xref="マタイの福音書 16:19; コリント人への手紙第二 2:10; ヨハネの福音書 20:23"> まことに、あなたがたに告げます。何でもあなたがたが地上でつなぐなら、それは天においてもつながれており、あなたがたが地上で解くなら、それは天においても解かれているのです。</span>
<span className="v" id="v19" data-v="19" data-xref="マタイの福音書 7:7; ヨハネの手紙第一 5:14–16; マルコの福音書 11:24"> まことに、あなたがたにもう一度、告げます。もし、あなたがたのうちふたりが、どんな事でも、地上で心を一つにして祈るなら、天におられるわたしの父は、それをかなえてくださいます。</span>
<span className="v" id="v20" data-v="20" data-xref="コリント人への手紙第一 5:4; ヨハネの黙示録 21:3; マタイの福音書 28:20"> ふたりでも三人でも、わたしの名において集まる所には、わたしもその中にいるからです。」</span>
<span className="v" id="v21" data-v="21" data-xref="ルカの福音書 17:3–4; マタイの福音書 18:15"> そのとき、ペテロがみもとに来て言った。「主よ。兄弟が私に対して罪を犯したばあい、何度まで赦すべきでしょうか。七度まででしょうか。」</span>
<span className="v" id="v22" data-v="22" data-xref="コロサイ人への手紙 3:13; マルコの福音書 11:25; マタイの福音書 6:14–15"> イエスは言われた。「七度まで、などとはわたしは言いません。七度を七十倍するまでと言います。</span>
<span className="v" id="v23" data-v="23" data-xref="マタイの福音書 13:24; ローマ人への手紙 14:12; マタイの福音書 3:2"> このことから、天の御国は、地上の王にたとえることができます。 王はそのしもべたちと清算をしたいと思った。</span>
<span className="v" id="v24" data-v="24" data-xref="Psalms 38:4; Psalms 130:3–4; ルカの福音書 16:5"> 清算が始まると、まず一万タラントの借りのあるしもべが、王のところに連れて来られた。</span>
<span className="v" id="v25" data-v="25" data-xref="2 Kings 4:1; Nehemiah 5:5; ルカの福音書 7:42"> しかし、彼は返済することができなかったので、その主人は彼に、自分も妻子も持ち物全部も売って返済するように命じた。</span>
<span className="v" id="v26" data-v="26" data-xref="マタイの福音書 18:29; ルカの福音書 7:43; マタイの福音書 8:2"> それで、このしもべは、主人の前にひれ伏して、『どうかご猶予ください。そうすれば全部お払いいたします。』と言った。</span>
<span className="v" id="v27" data-v="27" data-xref="Psalms 145:8; Nehemiah 9:17; Psalms 86:15"> しもべの主人は、かわいそうに思って、彼を赦し、借金を免除してやった。</span>
<span className="v" id="v28" data-v="28" data-xref="マタイの福音書 20:2; Ezekiel 45:9; Deuteronomy 15:2"> ところが、そのしもべは、出て行くと、同じしもべ仲間で、彼から百デナリの借りのある者に出会った。彼はその人をつかまえ、首を絞めて、『借金を返せ。』と言った。</span>
<span className="v" id="v29" data-v="29" data-xref="マタイの福音書 18:26; マタイの福音書 6:12; ピレモンへの手紙 1:18–19"> 彼の仲間は、ひれ伏して、『もう少し待ってくれ。そうしたら返すから。』と言って頼んだ。</span>
<span className="v" id="v30" data-v="30" data-xref="1 Kings 22:27; 1 Kings 21:27–29"> しかし彼は承知せず、連れて行って、借金を返すまで牢に投げ入れた。</span>
<span className="v" id="v31" data-v="31" data-xref="ローマ人への手紙 12:15; ヘブル人への手紙 13:3; マルコの福音書 3:5"> 彼の仲間たちは事の成り行きを見て、非常に悲しみ、行って、その一部始終を主人に話した。</span>
<span className="v" id="v32" data-v="32" data-xref="ルカの福音書 19:22; マタイの福音書 25:26; ローマ人への手紙 3:19"> そこで、主人は彼を呼びつけて言った。『悪いやつだ。おまえがあんなに頼んだからこそ借金全部を赦してやったのだ。</span>
<span className="v" id="v33" data-v="33" data-xref="コロサイ人への手紙 3:13; マタイの福音書 6:12; エペソ人への手紙 4:32–2"> 私がおまえをあわれんでやったように、おまえも仲間をあわれんでやるべきではないか。』</span>
<span className="v" id="v34" data-v="34" data-xref="マタイの福音書 5:25–26; ヤコブの手紙 2:13; ルカの福音書 12:58–59"> こうして、主人は怒って、借金を全部返すまで、彼を獄吏に引き渡した。</span>
<span className="v" id="v35" data-v="35" data-xref="マタイの福音書 6:14–15; ヤコブの手紙 2:13; ルカの福音書 6:37–38"> あなたがたもそれぞれ、心から兄弟を赦さないなら、天のわたしの父も、あなたがたに、このようになさるのです。」</span>

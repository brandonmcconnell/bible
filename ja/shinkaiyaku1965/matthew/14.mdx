<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ルカの福音書 3:1; マルコの福音書 8:15; ルカの福音書 9:7–9"> そのころ、国主ヘロデは、イエスのうわさを聞いて、</span>
<span className="v" id="v2" data-v="2" data-xref="マタイの福音書 16:14; ヨハネの福音書 10:41; マルコの福音書 8:28"> 侍従たちに言った。「あれはバプテスマのヨハネだ。ヨハネが死人の中からよみがえったのだ。だから、あんな力が彼のうちに働いているのだ。」</span>
<span className="v" id="v3" data-v="3" data-xref="マルコの福音書 6:17; ルカの福音書 3:19–20; マタイの福音書 4:12"> 実は、このヘロデは、自分の兄弟ピリポの妻ヘロデヤのことで、ヨハネを捕えて縛り、牢に入れたのであった。</span>
<span className="v" id="v4" data-v="4" data-xref="Leviticus 20:21; Leviticus 18:16; マルコの福音書 6:18"> それは、ヨハネが彼に、「あなたが彼女をめとるのは不法です。」と言い張ったからである。</span>
<span className="v" id="v5" data-v="5" data-xref="マタイの福音書 21:26; マタイの福音書 11:9; マルコの福音書 6:19–20"> ヘロデはヨハネを殺したかったが、群衆を恐れた。というのは、彼らはヨハネを預言者と認めていたからである。</span>
<span className="v" id="v6" data-v="6" data-xref="マルコの福音書 6:21–23; Genesis 40:20; Hosea 1:5–6"> たまたまヘロデの誕生祝いがあって、ヘロデヤの娘がみなの前で踊りを踊ってヘロデを喜ばせた。</span>
<span className="v" id="v7" data-v="7" data-xref="Esther 5:3; Esther 5:6; Esther 7:2"> それで、彼は、その娘に、願う物は何でも必ず上げると、誓って堅い約束をした。</span>
<span className="v" id="v8" data-v="8" data-xref="マルコの福音書 6:24; Proverbs 29:10; Proverbs 1:16"> ところが、娘は母親にそそのかされて、こう言った。「今ここに、バプテスマのヨハネの首を盆に載せて私に下さい。」</span>
<span className="v" id="v9" data-v="9" data-xref="ヨハネの福音書 19:12–16; 1 Samuel 14:28; マルコの福音書 6:26"> 王は心を痛めたが、自分の誓いもあり、また列席の人々の手前もあって、与えるように命令した。</span>
<span className="v" id="v10" data-v="10" data-xref="マタイの福音書 17:12; マタイの福音書 21:35–36; ルカの福音書 9:9"> 彼は人をやって、牢の中でヨハネの首をはねさせた。</span>
<span className="v" id="v11" data-v="11" data-xref="ヨハネの黙示録 16:6; Genesis 49:7; Ezekiel 16:3–4"> そして、その首は盆に載せて運ばれ、少女に与えられたので、少女はそれを母親のところに持って行った。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒の働き 8:2; マタイの福音書 27:58–61"> それから、ヨハネの弟子たちがやって来て、死体を引き取って葬った。そして、イエスのところに行って報告した。</span>
<span className="v" id="v13" data-v="13" data-xref="ルカの福音書 9:10–17; マタイの福音書 14:1–2; マルコの福音書 6:30–44"> イエスはこのことを聞かれると、舟でそこを去り、自分だけで寂しい所に行かれた。すると、群衆がそれと聞いて、町々から、歩いてイエスのあとを追った。</span>
<span className="v" id="v14" data-v="14" data-xref="ヘブル人への手紙 4:15; マタイの福音書 9:36; ヘブル人への手紙 2:17"> イエスは舟から上がられると、多くの群衆を見られ、彼らを深くあわれんで、彼らの病気を直された。</span>
<span className="v" id="v15" data-v="15" data-xref="マタイの福音書 15:23; マルコの福音書 8:3; マルコの福音書 6:35–36"> 夕方になったので、弟子たちはイエスのところに来て言った。「ここは寂しい所ですし、時刻ももう回っています。ですから群衆を解散させてください。そして村に行ってめいめいで食物を買うようにさせてください。」</span>
<span className="v" id="v16" data-v="16" data-xref="2 Kings 4:42–44; コリント人への手紙第二 8:2–3; Ecclesiastes 11:2"> しかし、イエスは言われた。「彼らが出かけて行く必要はありません。あなたがたで、あの人たちに何か食べる物を上げなさい。」</span>
<span className="v" id="v17" data-v="17" data-xref="マタイの福音書 15:33–34; マルコの福音書 6:37–38; ルカの福音書 9:13"> しかし、弟子たちはイエスに言った。「ここには、パンが五つと魚が二匹よりほかありません。」</span>
<span className="v" id="v18" data-v="18"> すると、イエスは言われた。「それを、ここに持って来なさい。」</span>
<span className="v" id="v19" data-v="19" data-xref="マルコの福音書 8:6–7; ルカの福音書 24:30; 1 Samuel 9:13"> そしてイエスは、群衆に命じて草の上にすわらせ、五つのパンと二匹の魚を取り、天を見上げて、それらを祝福し、パンを裂いてそれを弟子たちに与えられたので、弟子たちは群衆に配った。</span>
<span className="v" id="v20" data-v="20" data-xref="Exodus 16:12; マルコの福音書 6:42–44; マタイの福音書 16:8–10"> 人々はみな、食べて満腹した。そして、パン切れの余りを取り集めると、十二のかごにいっぱいあった。</span>
<span className="v" id="v21" data-v="21" data-xref="ピリピ人への手紙 4:19; コリント人への手紙第二 9:8–11; 使徒の働き 4:4"> 食べた者は、女と子どもを除いて、男五千人ほどであった。</span>
<span className="v" id="v22" data-v="22" data-xref="マルコの福音書 6:45–51; ヨハネの福音書 6:15–21; マタイの福音書 15:39"> それからすぐ、イエスは弟子たちを強いて舟に乗り込ませて、自分より先に向こう岸へ行かせ、その間に群衆を帰してしまわれた。</span>
<span className="v" id="v23" data-v="23" data-xref="ルカの福音書 6:12; マルコの福音書 6:46; マタイの福音書 26:36"> 群衆を帰したあとで、祈るために、ひとりで山に登られた。夕方になったが、まだそこに、ひとりでおられた。</span>
<span className="v" id="v24" data-v="24" data-xref="ヨハネの福音書 6:18; マルコの福音書 6:48; マタイの福音書 8:24"> しかし、舟は、陸からもう何キロメートルも離れていたが、風が向かい風なので、波に悩まされていた。</span>
<span className="v" id="v25" data-v="25" data-xref="Job 9:8; ヨハネの福音書 6:19; マルコの福音書 6:48"> すると、夜中の三時ごろ、イエスは湖の上を歩いて、彼らのところに行かれた。</span>
<span className="v" id="v26" data-v="26" data-xref="マルコの福音書 6:49–50; ヨハネの黙示録 1:17; ルカの福音書 1:11–12"> 弟子たちは、イエスが湖の上を歩いておられるのを見て、「あれは幽霊だ。」と言って、おびえてしまい、恐ろしさのあまり、叫び声を上げた。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒の働き 23:11; ヨハネの黙示録 1:17–18; ヨハネの福音書 16:33"> しかし、イエスはすぐに彼らに話しかけ、「しっかりしなさい。わたしだ。恐れることはない。」と言われた。</span>
<span className="v" id="v28" data-v="28" data-xref="ヨハネの福音書 6:68; ローマ人への手紙 12:3; マタイの福音書 26:33–35"> すると、ペテロが答えて言った。「主よ。もし、あなたでしたら、私に、水の上を歩いてここまで来い、とお命じになってください。」</span>
<span className="v" id="v29" data-v="29" data-xref="ピリピ人への手紙 4:13; マルコの福音書 9:23; 使徒の働き 3:16"> イエスは「来なさい。」と言われた。そこで、ペテロは舟から出て、水の上を歩いてイエスのほうに行った。</span>
<span className="v" id="v30" data-v="30" data-xref="Lamentations 3:54–57; テモテへの手紙第二 4:16–17; マルコの福音書 14:38"> ところが、風を見て、こわくなり、沈みかけたので叫び出し、「主よ。助けてください。」と言った。</span>
<span className="v" id="v31" data-v="31" data-xref="ヤコブの手紙 1:6–8; Psalms 138:7; Genesis 22:14"> そこで、イエスはすぐに手を伸ばして、彼をつかんで言われた。「信仰の薄い人だな。なぜ疑うのか。」</span>
<span className="v" id="v32" data-v="32" data-xref="Psalms 107:29–30; マルコの福音書 4:41; ヨハネの福音書 6:21"> そして、ふたりが舟に乗り移ると、風がやんだ。</span>
<span className="v" id="v33" data-v="33" data-xref="ヨハネの福音書 11:27; Psalms 2:7; ローマ人への手紙 1:4"> そこで、舟の中にいた者たちは、イエスを拝んで、「確かにあなたは神の子です。」と言った。</span>
<span className="v" id="v34" data-v="34" data-xref="マルコの福音書 6:53–56; ルカの福音書 5:1; ヨハネの福音書 6:24–25"> 彼らは湖を渡ってゲネサレの地に着いた。</span>
<span className="v" id="v35" data-v="35" data-xref="マタイの福音書 4:24–25; マルコの福音書 6:55; マルコの福音書 1:28–34"> すると、その地の人々は、イエスと気がついて、付近の地域にくまなく知らせ、病人という病人をみな、みもとに連れて来た。</span>
<span className="v" id="v36" data-v="36" data-xref="ルカの福音書 6:19; マルコの福音書 3:10; Exodus 28:33–43"> そして、せめて彼らに、着物のふさにでもさわらせてやってくださいと、イエスにお願いした。そして、さわった人々はみな、いやされた。</span>

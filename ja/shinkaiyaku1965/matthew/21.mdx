<span className="v" id="v1" data-v="1" data-xref="Zechariah 14:4; マルコの福音書 11:1–10; ルカの福音書 21:37"> それから、彼らはエルサレムに近づき、オリーブ山のふもとのベテパゲまで来た。そのとき、イエスは、弟子をふたり使いに出して、</span>
<span className="v" id="v2" data-v="2" data-xref="ルカの福音書 19:30–32; マルコの福音書 11:2–3; ヨハネの福音書 2:5–8"> 言われた。「向こうの村へ行きなさい。そうするとすぐに、ろばがつながれていて、いっしょにろばの子がいるのに気がつくでしょう。それをほどいて、わたしのところに連れて来なさい。</span>
<span className="v" id="v3" data-v="3" data-xref="コリント人への手紙第二 8:1–2; 使徒の働き 17:25; コリント人への手紙第二 8:9"> もしだれかが何か言ったら、『主がお入用なのです。』と言いなさい。そうすれば、すぐに渡してくれます。」</span>
<span className="v" id="v4" data-v="4" data-xref="Zechariah 9:9; ヨハネの福音書 12:15; マタイの福音書 1:22"> これは、預言者を通して言われた事が成就するために起こったのである。</span>
<span className="v" id="v5" data-v="5" data-xref="Zechariah 9:9–10; Isaiah 62:11; Isaiah 12:6"> 「シオンの娘に伝えなさい。 『見よ。あなたの王が、 あなたのところにお見えになる。 柔和で、ろばの背に乗って、 それも、荷物を運ぶろばの子に乗って。』」</span>
<span className="v" id="v6" data-v="6" data-xref="Exodus 39:43; ヨハネの福音書 15:14; Exodus 40:16"> そこで、弟子たちは行って、イエスが命じられたとおりにした。</span>
<span className="v" id="v7" data-v="7" data-xref="2 Kings 9:13; マルコの福音書 11:4–8; ルカの福音書 19:32–35"> そして、ろばと、ろばの子とを連れて来て、自分たちの上着をその上に掛けた。イエスはそれに乗られた。</span>
<span className="v" id="v8" data-v="8" data-xref="2 Kings 9:13; ヨハネの福音書 12:13; Leviticus 23:40"> すると、群衆のうち大ぜいの者が、自分たちの上着を道に敷き、また、ほかの人々は、木の枝を切って来て、道に敷いた。</span>
<span className="v" id="v9" data-v="9" data-xref="Psalms 118:24–26; ルカの福音書 2:14; ヨハネの福音書 12:13–15"> そして、群衆は、イエスの前を行く者も、あとに従う者も、こう言って叫んでいた。 「ダビデの子にホサナ。 祝福あれ。主の御名によって来られる方に。 ホサナ。いと高き所に。」</span>
<span className="v" id="v10" data-v="10" data-xref="使徒の働き 9:5; Ruth 1:19; ヨハネの福音書 12:16–19"> こうして、イエスがエルサレムにはいられると、都中がこぞって騒ぎ立ち、「この方は、どういう方なのか。」と言った。</span>
<span className="v" id="v11" data-v="11" data-xref="ヨハネの福音書 6:14; ルカの福音書 7:16; ヨハネの福音書 7:40"> 群衆は、「この方は、ガリラヤのナザレの、預言者イエスだ。」と言った。</span>
<span className="v" id="v12" data-v="12" data-xref="ヨハネの福音書 2:14–17; ルカの福音書 19:45–47; マルコの福音書 11:15–18"> それから、イエスは宮にはいって、宮の中で売り買いする者たちをみな追い出し、両替人の台や、鳩を売る者たちの腰掛けを倒された。</span>
<span className="v" id="v13" data-v="13" data-xref="Jeremiah 7:11; Isaiah 56:7; ルカの福音書 19:46"> そして彼らに言われた。「『わたしの家は祈りの家と呼ばれる。』と書いてある。それなのに、あなたがたはそれを強盗の巣にしている。」</span>
<span className="v" id="v14" data-v="14" data-xref="使徒の働き 3:1–9; 使徒の働き 10:38; マタイの福音書 11:4–5"> また、宮の中で、盲人や足なえがみもとに来たので、イエスは彼らをいやされた。</span>
<span className="v" id="v15" data-v="15" data-xref="マタイの福音書 21:9; ルカの福音書 19:39–40; Isaiah 26:11"> ところが、祭司長、律法学者たちは、イエスのなさった驚くべきいろいろのことを見、また宮の中で子どもたちが「ダビデの子にホサナ。」と言って叫んでいるのを見て腹を立てた。</span>
<span className="v" id="v16" data-v="16" data-xref="Psalms 8:2; マタイの福音書 11:25; ルカの福音書 19:39–40"> そしてイエスに言った。「あなたは、子どもたちが何と言っているか、お聞きですか。」イエスは言われた。「聞いています。『あなたは幼子と乳飲み子たちの口に賛美を用意された。』とあるのを、あなたがたは読まなかったのですか。」</span>
<span className="v" id="v17" data-v="17" data-xref="ヨハネの福音書 11:18; マルコの福音書 11:11; ルカの福音書 24:50"> イエスは彼らをあとに残し、都を出てベタニヤに行き、そこに泊まられた。</span>
<span className="v" id="v18" data-v="18" data-xref="マタイの福音書 4:2; ヘブル人への手紙 4:15; マタイの福音書 12:1"> 翌朝、イエスは都に帰る途中、空腹を覚えられた。</span>
<span className="v" id="v19" data-v="19" data-xref="ヨハネの福音書 15:6; マルコの福音書 11:14; テトスへの手紙 1:16"> 道ばたにいちじくの木が見えたので、近づいて行かれたが、葉のほかは何もないのに気づかれた。それで、イエスはその木に「おまえの実は、もういつまでも、ならないように。」と言われた。すると、たちまちいちじくの木は枯れた。</span>
<span className="v" id="v20" data-v="20" data-xref="Isaiah 40:6–8; マルコの福音書 11:20–21; ヤコブの手紙 1:10–11"> 弟子たちは、これを見て、驚いて言った。「どうして、こうすぐにいちじくの木が枯れたのでしょうか。」</span>
<span className="v" id="v21" data-v="21" data-xref="ヤコブの手紙 1:6; マタイの福音書 17:20; マルコの福音書 11:22–23"> イエスは答えて言われた。「まことに、あなたがたに告げます。もし、あなたがたが、信仰を持ち、疑うことがなければ、いちじくの木になされたようなことができるだけでなく、たとい、この山に向かって、『動いて、海にはいれ。』と言っても、そのとおりになります。</span>
<span className="v" id="v22" data-v="22" data-xref="マタイの福音書 7:7; ヨハネの手紙第一 5:14–15; マルコの福音書 11:24"> あなたがたが信じて祈り求めるものなら、何でも与えられます。」</span>
<span className="v" id="v23" data-v="23" data-xref="使徒の働き 4:7; マルコの福音書 11:27–33; 1 Chronicles 24:1–19"> それから、イエスが宮にはいって、教えておられると、祭司長、民の長老たちが、みもとに来て言った。「何の権威によって、これらのことをしておられるのですか。だれが、あなたにその権威を授けたのですか。」</span>
<span className="v" id="v24" data-v="24" data-xref="ルカの福音書 6:9; コロサイ人への手紙 4:6; マタイの福音書 10:16"> イエスは答えて、こう言われた。「わたしも一言あなたがたに尋ねましょう。もし、あなたがたが答えるなら、わたしも何の権威によって、これらのことをしているかを話しましょう。</span>
<span className="v" id="v25" data-v="25" data-xref="ヨハネの手紙第一 3:20; マルコの福音書 1:1–11; ヨハネの福音書 3:18"> ヨハネのバプテスマは、どこから来たものですか。天からですか。それとも人からですか。」すると、彼らはこう言いながら、互いに論じ合った。「もし、天から、と言えば、それならなぜ、彼を信じなかったか、と言うだろう。</span>
<span className="v" id="v26" data-v="26" data-xref="マルコの福音書 6:20; マタイの福音書 14:5; ヨハネの福音書 5:35"> しかし、もし、人から、と言えば、群衆がこわい。彼らはみな、ヨハネを預言者と認めているのだから。」</span>
<span className="v" id="v27" data-v="27" data-xref="ローマ人への手紙 1:18–22; テサロニケ人への手紙第二 2:9–10; ルカの福音書 20:7–8"> そこで、彼らはイエスに答えて、「わかりません。」と言った。イエスもまた彼らにこう言われた。「わたしも、何の権威によってこれらのことをするのか、あなたがたに話すまい。</span>
<span className="v" id="v28" data-v="28" data-xref="コリント人への手紙第一 15:58; マタイの福音書 20:1; コリント人への手紙第一 10:15"> ところで、あなたがたは、どう思いますか。ある人にふたりの息子がいた。その人は兄のところに来て、『きょう、ぶどう園に行って働いてくれ。』と言った。</span>
<span className="v" id="v29" data-v="29" data-xref="Ezekiel 18:28–32; マタイの福音書 3:2–8; Isaiah 55:6–7"> 兄は答えて『行きます。おとうさん。』と言ったが、行かなかった。</span>
<span className="v" id="v30" data-v="30" data-xref="テトスへの手紙 1:16; Ezekiel 33:31; マタイの福音書 23:3"> それから、弟のところに来て、同じように言った。ところが、弟は答えて『行きたくありません。』と言ったが、あとから悪かったと思って出かけて行った。</span>
<span className="v" id="v31" data-v="31" data-xref="ルカの福音書 7:29; ルカの福音書 7:37–50; マタイの福音書 7:21"> ふたりのうちどちらが、父の願ったとおりにしたのでしょう。」彼らは言った。「あとの者です。」イエスは彼らに言われた。「まことに、あなたがたに告げます。取税人や遊女たちのほうが、あなたがたより先に神の国にはいっているのです。</span>
<span className="v" id="v32" data-v="32" data-xref="ルカの福音書 7:37–50; Zechariah 7:11–12; ルカの福音書 7:29–30"> というのは、あなたがたは、ヨハネが義の道を持って来たのに、彼を信じなかった。しかし、取税人や遊女たちは彼を信じたからです。しかもあなたがたは、それを見ながら、あとになって悔いることもせず、彼を信じなかったのです。</span>
<span className="v" id="v33" data-v="33" data-xref="Isaiah 5:1–4; マルコの福音書 12:1–12; ルカの福音書 20:9–19"> もう一つのたとえを聞きなさい。 ひとりの、家の主人がいた。彼はぶどう園を造って、垣を巡らし、その中に酒ぶねを掘り、やぐらを建て、それを農夫たちに貸して、旅に出かけた。</span>
<span className="v" id="v34" data-v="34" data-xref="ルカの福音書 20:10–19; Isaiah 5:4; Zechariah 1:3–6"> さて、収穫の時が近づいたので、主人は自分の分を受け取ろうとして、農夫たちのところへしもべたちを遣わした。</span>
<span className="v" id="v35" data-v="35" data-xref="2 Chronicles 36:15–16; マタイの福音書 5:12; ヘブル人への手紙 11:36–37"> すると、農夫たちは、そのしもべたちをつかまえて、ひとりは袋だたきにし、もうひとりは殺し、もうひとりは石で打った。</span>
<span className="v" id="v36" data-v="36" data-xref="マタイの福音書 22:4"> そこでもう一度、前よりももっと多くの別のしもべたちを遣わしたが、やはり同じような扱いをした。</span>
<span className="v" id="v37" data-v="37" data-xref="ヨハネの福音書 3:16; ヨハネの福音書 3:35–36; Zephaniah 3:7"> しかし、そのあと、その主人は、『私の息子なら、敬ってくれるだろう。』と言って、息子を遣わした。</span>
<span className="v" id="v38" data-v="38" data-xref="ルカの福音書 20:14; Genesis 37:18–20; マルコの福音書 12:7–8"> すると、農夫たちは、その子を見て、こう話し合った。『あれはあと取りだ。さあ、あれを殺して、あれのものになるはずの財産を手に入れようではないか。』</span>
<span className="v" id="v39" data-v="39" data-xref="使徒の働き 2:23; ヤコブの手紙 5:6; ルカの福音書 22:52–54"> そして、彼をつかまえて、ぶどう園の外に追い出して殺してしまった。</span>
<span className="v" id="v40" data-v="40" data-xref="ヘブル人への手紙 10:29; マルコの福音書 12:9; ルカの福音書 20:15–16"> このばあい、ぶどう園の主人が帰って来たら、その農夫たちをどうするでしょう。」</span>
<span className="v" id="v41" data-v="41" data-xref="使徒の働き 18:6; マタイの福音書 21:43; 使徒の働き 28:28"> 彼らはイエスに言った。「その悪党どもを情け容赦なく殺して、そのぶどう園を、季節にはきちんと収穫を納める別の農夫たちに貸すに違いありません。」</span>
<span className="v" id="v42" data-v="42" data-xref="Psalms 118:22–23; Isaiah 28:16; 使徒の働き 4:11"> イエスは彼らに言われた。「あなたがたは、次の聖書のことばを読んだことがないのですか。 『家を建てる者たちの見捨てた石。 それが礎の石になった。 これは主のなさったことだ。 私たちの目には、 不思議なことである。』</span>
<span className="v" id="v43" data-v="43" data-xref="マタイの福音書 21:41; マタイの福音書 8:11–12; ペテロの手紙第一 2:9"> だから、わたしはあなたがたに言います。神の国はあなたがたから取り去られ、神の国の実を結ぶ国民に与えられます。</span>
<span className="v" id="v44" data-v="44" data-xref="Isaiah 8:14–15; ペテロの手紙第一 2:8; Daniel 2:34–35"> また、この石の上に落ちる者は、粉々に砕かれ、この石が人の上に落ちれば、その人を粉みじんに飛ばしてしまいます。」</span>
<span className="v" id="v45" data-v="45" data-xref="ルカの福音書 20:19; ルカの福音書 11:45; マタイの福音書 12:12"> 祭司長たちとパリサイ人たちは、イエスのこれらのたとえを聞いたとき、自分たちをさして話しておられることに気づいた。</span>
<span className="v" id="v46" data-v="46" data-xref="マタイの福音書 21:11; マタイの福音書 21:26; ルカの福音書 7:16"> それでイエスを捕えようとしたが、群衆を恐れた。群衆はイエスを預言者と認めていたからである。</span>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="Deuteronomy 23:25; マルコの福音書 2:23–28; ルカの福音書 6:1–5"> そのころ、イエスは、安息日に麦畑を通られた。弟子たちはひもじくなったので、穂を摘んで食べ始めた。</span>
<span className="v" id="v2" data-v="2" data-xref="マタイの福音書 12:10; ヨハネの福音書 7:21–24; ルカの福音書 14:3"> すると、パリサイ人たちがそれを見つけて、イエスに言った。「ご覧なさい。あなたの弟子たちが、安息日にしてはならないことをしています。」</span>
<span className="v" id="v3" data-v="3" data-xref="1 Samuel 21:3–6; ルカの福音書 6:3; マルコの福音書 2:25–26"> しかし、イエスは言われた。「ダビデとその連れの者たちが、ひもじかったときに、ダビデが何をしたか、読まなかったのですか。</span>
<span className="v" id="v4" data-v="4" data-xref="Leviticus 24:5–9; Exodus 25:30; Leviticus 8:31"> 神の家にはいって、祭司のほかは自分も供の者たちも食べてはならない供えのパンを食べました。</span>
<span className="v" id="v5" data-v="5" data-xref="Numbers 28:9–10; ヨハネの福音書 7:22–23; Nehemiah 13:17"> また、安息日に宮にいる祭司たちは安息日の神聖を冒しても罪にならないということを、律法で読んだことはないのですか。</span>
<span className="v" id="v6" data-v="6" data-xref="マタイの福音書 12:41–42; 2 Chronicles 6:18; ペテロの手紙第一 2:4–5"> あなたがたに言いますが、ここに宮より大きな者がいるのです。</span>
<span className="v" id="v7" data-v="7" data-xref="Hosea 6:6; マタイの福音書 9:13; Micah 6:6–8"> 『わたしはあわれみは好むが、いけにえは好まない。』ということがどういう意味かを知っていたら、あなたがたは、罪のない者たちを罪に定めはしなかったでしょう。</span>
<span className="v" id="v8" data-v="8" data-xref="マルコの福音書 2:28; ルカの福音書 6:5; ヨハネの福音書 5:17–23"> 人の子は安息日の主です。」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="マルコの福音書 3:1–6; ルカの福音書 6:6–11"> イエスはそこを去って、会堂にはいられた。</span>
<span className="v" id="v10" data-v="10" data-xref="ルカの福音書 13:14; ヨハネの福音書 9:16; ヨハネの福音書 8:6"> そこに片手のなえた人がいた。そこで、彼らはイエスに質問して、「安息日にいやすことは正しいことでしょうか。」と言った。これはイエスを訴えるためであった。</span>
<span className="v" id="v11" data-v="11" data-xref="Deuteronomy 22:4; ルカの福音書 14:5; ルカの福音書 13:15–17"> イエスは彼らに言われた。「あなたがたのうち、だれかが一匹の羊を持っていて、もしその羊が安息日に穴に落ちたら、それを引き上げてやらないでしょうか。</span>
<span className="v" id="v12" data-v="12" data-xref="マタイの福音書 6:26; ルカの福音書 6:9; マルコの福音書 3:4"> 人間は羊より、はるかに値うちのあるものでしょう。それなら、安息日に良いことをすることは、正しいのです。」</span>
<span className="v" id="v13" data-v="13" data-xref="ルカの福音書 13:13; 使徒の働き 3:7–8"> それから、イエスはその人に、「手を伸ばしなさい。」と言われた。彼が手を伸ばすと、手は直って、もう一方の手と同じようになった。</span>
<span className="v" id="v14" data-v="14" data-xref="ヨハネの福音書 11:53; ヨハネの福音書 10:39; マルコの福音書 3:6"> パリサイ人は出て行って、どのようにしてイエスを滅ぼそうかと相談した。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="マルコの福音書 3:7–12; マタイの福音書 10:23; マタイの福音書 19:2"> イエスはそれを知って、そこを立ち去られた。すると多くの人がついて来たので、彼らをみないやし、</span>
<span className="v" id="v16" data-v="16" data-xref="マタイの福音書 8:4; マタイの福音書 9:30; マタイの福音書 17:9"> そして、ご自分のことを人々に知らせないようにと、彼らを戒められた。</span>
<span className="v" id="v17" data-v="17" data-xref="Isaiah 42:1–4; Isaiah 42:9; マタイの福音書 13:35"> これは、預言者イザヤを通して言われた事が成就するためであった。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="Isaiah 42:1; ルカの福音書 4:18; 使徒の働き 10:38"> 「これぞ、わたしの選んだわたしのしもべ、<br />わたしの心の喜ぶわたしの愛する者。<br />わたしは彼の上にわたしの霊を置き、<br />彼は異邦人にさばきを宣べる。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="マタイの福音書 11:29; ヨハネの福音書 18:36–38; テモテへの手紙第二 2:24–25"> 争うこともなく、叫ぶこともせず、<br />大路でその声を聞く者もない。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="Isaiah 42:3–4; Ezekiel 34:16; Isaiah 61:1–3"> 彼はいたんだ葦を折ることもなく、<br />くすぶる燈心を消すこともない、<br />正義を勝利に導くまでは。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="Isaiah 11:10; ローマ人への手紙 15:12–13; Isaiah 42:4"> 異邦人は彼の名に望みをかける。」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="ルカの福音書 11:14–15; マルコの福音書 7:35–37; Isaiah 29:18"> そのとき、悪霊につかれた、目も見えず、口もきけない人が連れて来られた。イエスが彼をいやされたので、そのおしはものを言い、目も見えるようになった。</span>
<span className="v" id="v23" data-v="23" data-xref="マタイの福音書 9:27; ヨハネの福音書 4:29; マタイの福音書 22:42–43"> 群衆はみな驚いて言った。「この人は、ダビデの子なのだろうか。」</span>
<span className="v" id="v24" data-v="24" data-xref="マルコの福音書 3:22; マタイの福音書 9:34; ルカの福音書 11:15"> これを聞いたパリサイ人は言った。「この人は、ただ悪霊どものかしらベルゼブルの力で、悪霊どもを追い出しているだけだ。」</span>
<span className="v" id="v25" data-v="25" data-xref="ガラテヤ人への手紙 5:15; Jeremiah 17:10; マタイの福音書 9:4"> イエスは彼らの思いを知ってこう言われた。「どんな国でも、内輪もめして争えば荒れすたれ、どんな町でも家でも、内輪もめして争えば立ち行きません。</span>
<span className="v" id="v26" data-v="26" data-xref="コロサイ人への手紙 1:13; ヨハネの黙示録 20:2–3; ヨハネの手紙第一 5:19"> もし、サタンがサタンを追い出していて仲間割れしたのだったら、どうしてその国は立ち行くでしょう。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒の働き 19:13–16; マルコの福音書 9:38–39; ルカの福音書 9:49–50"> また、もしわたしがベルゼブルによって悪霊どもを追い出しているのなら、あなたがたの子らはだれによって追い出すのですか。だから、あなたがたの子らが、あなたがたをさばく人となるのです。</span>
<span className="v" id="v28" data-v="28" data-xref="ルカの福音書 11:20; Daniel 7:14; マタイの福音書 6:33"> しかし、わたしが神の御霊によって悪霊どもを追い出しているのなら、もう神の国はあなたがたのところに来ているのです。</span>
<span className="v" id="v29" data-v="29" data-xref="Isaiah 49:24; マルコの福音書 3:27; ルカの福音書 11:21–22"> 強い人の家にはいって家財を奪い取ろうとするなら、まずその人を縛ってしまわないで、どうしてそのようなことができましょうか。そのようにして初めて、その家を略奪することもできるのです。</span>
<span className="v" id="v30" data-v="30" data-xref="マルコの福音書 9:40; ルカの福音書 11:23; Joshua 24:15"> わたしの味方でない者はわたしに逆らう者であり、わたしとともに集めない者は散らす者です。</span>
<span className="v" id="v31" data-v="31" data-xref="ルカの福音書 12:10; マルコの福音書 3:28–30; ヘブル人への手紙 10:29"> だから、わたしはあなたがたに言います。人はどんな罪も冒涜も赦していただけます。しかし、聖霊に逆らう冒涜は赦されません。</span>
<span className="v" id="v32" data-v="32" data-xref="マルコの福音書 3:29; ヘブル人への手紙 10:26–29; ヘブル人への手紙 6:4–6"> また、人の子に逆らうことばを口にする者でも、赦されます。しかし、聖霊に逆らうことを言う者は、だれであっても、この世であろうと次に来る世であろうと、赦されません。</span>
<span className="v" id="v33" data-v="33" data-xref="ルカの福音書 6:43–44; マタイの福音書 7:16–20; ヤコブの手紙 4:8"> 木が良ければ、その実も良いとし、木が悪ければその実も悪いとしなさい。木のよしあしはその実によって知られるからです。</span>
<span className="v" id="v34" data-v="34" data-xref="ルカの福音書 6:45; マタイの福音書 15:18; エペソ人への手紙 4:29"> まむしのすえたち。おまえたち悪い者に、どうして良いことが言えましょう。心に満ちていることを口が話すのです。</span>
<span className="v" id="v35" data-v="35" data-xref="Proverbs 15:4; コロサイ人への手紙 4:6; Proverbs 15:28"> 良い人は、良い倉から良い物を取り出し、悪い人は、悪い倉から悪い物を取り出すものです。</span>
<span className="v" id="v36" data-v="36" data-xref="Ecclesiastes 12:14; ローマ人への手紙 2:16; ヨハネの黙示録 20:12"> わたしはあなたがたに、こう言いましょう。人はその口にするあらゆるむだなことばについて、さばきの日には言い開きをしなければなりません。</span>
<span className="v" id="v37" data-v="37" data-xref="Proverbs 13:3; ヤコブの手紙 2:21–25"> あなたが正しいとされるのは、あなたのことばによるのであり、罪に定められるのも、あなたのことばによるのです。」</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="コリント人への手紙第一 1:22; マルコの福音書 8:11–12; ルカの福音書 11:16"> そのとき、律法学者、パリサイ人たちのうちのある者がイエスに答えて言った。「先生。私たちは、あなたからしるしを見せていただきたいのです。」</span>
<span className="v" id="v39" data-v="39" data-xref="マタイの福音書 16:4; ルカの福音書 11:29–32; マルコの福音書 8:38"> しかし、イエスは答えて言われた。「悪い、姦淫の時代はしるしを求めています。だが預言者ヨナのしるしのほかには、しるしは与えられません。</span>
<span className="v" id="v40" data-v="40" data-xref="Jonah 1:17; マタイの福音書 27:63–64; マタイの福音書 16:21"> ヨナは三日三晩大魚の腹の中にいましたが、同様に、人の子も三日三晩、地の中にいるからです。</span>
<span className="v" id="v41" data-v="41" data-xref="マタイの福音書 12:42; ヘブル人への手紙 11:7; マタイの福音書 12:6"> ニネベの人々が、さばきのときに、今の時代の人々とともに立って、この人々を罪に定めます。なぜなら、ニネベの人々はヨナの説教で悔い改めたからです。しかし、見なさい。ここにヨナよりもまさった者がいるのです。</span>
<span className="v" id="v42" data-v="42" data-xref="1 Kings 10:1–13; 2 Chronicles 9:1–12; ヘブル人への手紙 1:2–4"> 南の女王が、さばきのときに、今の時代の人々とともに立って、この人々を罪に定めます。なぜなら、彼女はソロモンの知恵を聞くために地の果てから来たからです。しかし、見なさい。ここにソロモンよりもまさった者がいるのです。</span>
<span className="v" id="v43" data-v="43" data-xref="ルカの福音書 11:24–26; ルカの福音書 8:28–32; マタイの福音書 8:29"> 汚れた霊が人から出て行って、水のない地をさまよいながら休み場を捜しますが、見つかりません。</span>
<span className="v" id="v44" data-v="44" data-xref="ヨハネの手紙第一 4:4; ヨハネの黙示録 13:8–9; ユダの手紙 1:4–5"> そこで、『出て来た自分の家に帰ろう。』と言って、帰って見ると、家はあいていて、掃除してきちんとかたづいていました。</span>
<span className="v" id="v45" data-v="45" data-xref="ルカの福音書 11:26; マルコの福音書 5:9; ヘブル人への手紙 6:4–8"> そこで、出かけて行って、自分よりも悪いほかの霊を七つ連れて来て、みなはいり込んでそこに住みつくのです。そうなると、その人の後の状態は、初めよりもさらに悪くなります。邪悪なこの時代もまた、そういうことになるのです。」</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="マタイの福音書 13:55; ヨハネの福音書 2:12; ヨハネの福音書 7:3"> イエスがまだ群衆に話しておられるときに、イエスの母と兄弟たちが、イエスに何か話そうとして、外に立っていた。</span>
<span className="v" id="v47" data-v="47"> すると、だれかが言った。「ご覧なさい。あなたのおかあさんと兄弟たちが、あなたに話そうとして外に立っています。」</span>
<span className="v" id="v48" data-v="48" data-xref="マルコの福音書 3:32–33; マタイの福音書 10:37; ルカの福音書 2:52"> しかし、イエスはそう言っている人に答えて言われた。「わたしの母とはだれですか。また、わたしの兄弟たちとはだれですか。」</span>
<span className="v" id="v49" data-v="49" data-xref="マルコの福音書 3:34; ヨハネの福音書 17:8–9; ヨハネの福音書 20:17–20"> それから、イエスは手を弟子たちのほうに差し伸べて言われた。「見なさい。わたしの母、わたしの兄弟たちです。</span>
<span className="v" id="v50" data-v="50" data-xref="ルカの福音書 8:21; マルコの福音書 3:35; ヨハネの福音書 15:14"> 天におられるわたしの父のみこころを行なう者はだれでも、わたしの兄弟、姉妹、また母なのです。」</span>
</div>

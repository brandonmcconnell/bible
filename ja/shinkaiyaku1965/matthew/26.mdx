<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マタイの福音書 7:28; マタイの福音書 19:1"> イエスは、これらの話をすべて終えると、弟子たちに言われた。</span>
<span className="v" id="v2" data-v="2" data-xref="ルカの福音書 22:1–2; マルコの福音書 14:1–2; ヨハネの福音書 13:1–2"> 「あなたがたの知っているとおり、二日たつと過越の祭りになります。人の子は十字架につけられるために引き渡されます。」</span>
<span className="v" id="v3" data-v="3" data-xref="ヨハネの福音書 11:47–53; ヨハネの福音書 18:24; マルコの福音書 14:54"> そのころ、祭司長、民の長老たちは、カヤパという大祭司の家の庭に集まり、</span>
<span className="v" id="v4" data-v="4" data-xref="マタイの福音書 12:14; Psalms 2:2; 使徒の働き 13:10"> イエスをだまして捕え、殺そうと相談した。</span>
<span className="v" id="v5" data-v="5" data-xref="マタイの福音書 27:24; マタイの福音書 21:26; マタイの福音書 14:5"> しかし、彼らは、「祭りの間はいけない。民衆の騒ぎが起こるといけないから。」と話していた。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="マルコの福音書 14:3–9; ルカの福音書 7:37–39; ヨハネの福音書 12:1–8"> さて、イエスがベタニヤで、らい病人シモンの家におられると、</span>
<span className="v" id="v7" data-v="7" data-xref="ヨハネの福音書 12:2–3; ルカの福音書 7:46; ルカの福音書 7:37–38"> ひとりの女がたいへん高価な香油のはいった石膏のつぼを持ってみもとに来て、食卓に着いておられたイエスの頭に香油を注いだ。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨハネの福音書 12:4–6; マルコの福音書 14:4; Exodus 5:17"> 弟子たちはこれを見て、憤慨して言った。「何のために、こんなむだなことをするのか。</span>
<span className="v" id="v9" data-v="9" data-xref="ヨハネの福音書 12:5–6; マルコの福音書 14:5; Joshua 7:20–21"> この香油なら、高く売れて、貧乏な人たちに施しができたのに。」</span>
<span className="v" id="v10" data-v="10" data-xref="テトスへの手紙 3:8; ヘブル人への手紙 13:21; テモテへの手紙第一 5:10"> するとイエスはこれを知って、彼らに言われた。「なぜ、この女を困らせるのです。わたしに対してりっぱなことをしてくれたのです。</span>
<span className="v" id="v11" data-v="11" data-xref="Deuteronomy 15:11; マルコの福音書 14:7; ヨハネの福音書 12:8"> 貧しい人たちは、いつもあなたがたといっしょにいます。しかし、わたしは、いつもあなたがたといっしょにいるわけではありません。</span>
<span className="v" id="v12" data-v="12" data-xref="マルコの福音書 14:8; ヨハネの福音書 12:7; マルコの福音書 16:1"> この女が、この香油をわたしのからだに注いだのは、わたしの埋葬の用意をしてくれたのです。</span>
<span className="v" id="v13" data-v="13" data-xref="マルコの福音書 14:9; マタイの福音書 24:14; Psalms 112:6"> まことに、あなたがたに告げます。世界中のどこででも、この福音が宣べ伝えられる所なら、この人のした事も語られて、この人の記念となるでしょう。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="ルカの福音書 22:3–6; マタイの福音書 10:4; マルコの福音書 14:10–11"> そのとき、十二弟子のひとりで、イスカリオテ・ユダという者が、祭司長たちのところへ行って、</span>
<span className="v" id="v15" data-v="15" data-xref="Zechariah 11:12–13; Genesis 37:26–28; Exodus 21:32"> こう言った。「彼をあなたがたに売るとしたら、いったいいくらくれますか。」すると、彼らは銀貨三十枚を彼に支払った。</span>
<span className="v" id="v16" data-v="16" data-xref="マルコの福音書 14:11; ルカの福音書 22:6"> そのときから、彼はイエスを引き渡す機会をねらっていた。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="ルカの福音書 22:7–13; マルコの福音書 14:12–16; Exodus 12:18–20"> さて、種なしパンの祝いの第一日に、弟子たちがイエスのところに来て言った。「過越の食事をなさるのに、私たちはどこで用意をしましょうか。」</span>
<span className="v" id="v18" data-v="18" data-xref="マルコの福音書 14:13–16; ヨハネの福音書 7:6; ヨハネの福音書 17:1"> イエスは言われた。「都にはいって、これこれの人のところに行って、『先生が「わたしの時が近づいた。わたしの弟子たちといっしょに、あなたのところで過越を守ろう。」と言っておられる。』と言いなさい。」</span>
<span className="v" id="v19" data-v="19" data-xref="ヨハネの福音書 2:5; ヨハネの福音書 15:14; マタイの福音書 21:6"> そこで、弟子たちはイエスに言いつけられたとおりにして、過越の食事の用意をした。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="マルコの福音書 14:17–21; ヨハネの福音書 13:21; ルカの福音書 22:14–16"> さて、夕方になって、イエスは十二弟子といっしょに食卓に着かれた。</span>
<span className="v" id="v21" data-v="21" data-xref="ヨハネの福音書 13:21; ヘブル人への手紙 4:13; ヨハネの福音書 6:70–71"> みなが食事をしているとき、イエスは言われた。「まことに、あなたがたに告げます。あなたがたのうちひとりが、わたしを裏切ります。」</span>
<span className="v" id="v22" data-v="22" data-xref="ヨハネの福音書 13:22–25; ルカの福音書 22:23; マルコの福音書 14:19–20"> すると、弟子たちは非常に悲しんで、「主よ。まさか私のことではないでしょう。」とかわるがわるイエスに言った。</span>
<span className="v" id="v23" data-v="23" data-xref="ヨハネの福音書 13:18; Psalms 41:9; ヨハネの福音書 13:26–28"> イエスは答えて言われた。「わたしといっしょに鉢に手を浸した者が、わたしを裏切るのです。</span>
<span className="v" id="v24" data-v="24" data-xref="使徒の働き 26:22–23; ルカの福音書 24:46; マタイの福音書 18:7"> 確かに、人の子は、自分について書いてあるとおりに、去って行きます。しかし、人の子を裏切るような人間はのろわれます。そういう人は生まれなかったほうがよかったのです。」</span>
<span className="v" id="v25" data-v="25" data-xref="マタイの福音書 26:64; マタイの福音書 27:11; ルカの福音書 22:70"> すると、イエスを裏切ろうとしていたユダが答えて言った。「先生。まさか私のことではないでしょう。」イエスは彼に、「いや、そうだ。」と言われた。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="コリント人への手紙第一 11:23–29; ルカの福音書 22:18–20; コリント人への手紙第一 10:16–17"> また、彼らが食事をしているとき、イエスはパンを取り、祝福して後、これを裂き、弟子たちに与えて言われた。「取って食べなさい。これはわたしのからだです。」</span>
<span className="v" id="v27" data-v="27" data-xref="Isaiah 25:6; コリント人への手紙第一 10:16; Psalms 116:13"> また杯を取り、感謝をささげて後、こう言って彼らにお与えになった。「みな、この杯から飲みなさい。</span>
<span className="v" id="v28" data-v="28" data-xref="ヘブル人への手紙 10:4–14; ヘブル人への手紙 9:14–22; Leviticus 17:11"> これは、わたしの契約の血です。罪を赦すために多くの人のために流されるものです。</span>
<span className="v" id="v29" data-v="29" data-xref="ヘブル人への手紙 12:2; ヨハネの黙示録 7:17; マルコの福音書 14:25"> ただ、言っておきます。わたしの父の御国で、あなたがたと新しく飲むその日までは、わたしはもはや、ぶどうの実で造った物を飲むことはありません。」</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="マタイの福音書 21:1; エペソ人への手紙 5:19–20; ルカの福音書 22:39"> そして、賛美の歌を歌ってから、みなオリーブ山へ出かけて行った。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="Zechariah 13:7; マルコの福音書 14:27–28; ヨハネの福音書 16:32"> そのとき、イエスは弟子たちに言われた。「あなたがたはみな、今夜、わたしのゆえにつまずきます。『わたしが羊飼いを打つ。すると、羊の群れは散り散りになる。』と書いてあるからです。</span>
<span className="v" id="v32" data-v="32" data-xref="マタイの福音書 28:10; ルカの福音書 18:33–34; マタイの福音書 28:16"> しかしわたしは、よみがえってから、あなたがたより先に、ガリラヤへ行きます。」</span>
<span className="v" id="v33" data-v="33" data-xref="ルカの福音書 22:33; ヨハネの福音書 13:36–38; Proverbs 28:25–26"> すると、ペテロがイエスに答えて言った。「たとい全部の者があなたのゆえにつまずいても、私は決してつまずきません。」</span>
<span className="v" id="v34" data-v="34" data-xref="ヨハネの福音書 13:38; ルカの福音書 22:34; マタイの福音書 26:75"> イエスは彼に言われた。「まことに、あなたに告げます。今夜、鶏が鳴く前に、あなたは三度、わたしを知らないと言います。」</span>
<span className="v" id="v35" data-v="35" data-xref="ローマ人への手紙 11:20; ヨハネの福音書 13:37; Proverbs 29:23"> ペテロは言った。「たとい、ごいっしょに死ななければならないとしても、私は、あなたを知らないなどとは決して申しません。」弟子たちはみなそう言った。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="マルコの福音書 14:32–42; マタイの福音書 26:42; ルカの福音書 22:39–46"> それからイエスは弟子たちといっしょにゲツセマネという所に来て、彼らに言われた。「わたしがあそこに行って祈っている間、ここにすわっていなさい。」</span>
<span className="v" id="v37" data-v="37" data-xref="マタイの福音書 4:21; マタイの福音書 17:1; マルコの福音書 5:37"> それから、ペテロとゼベダイの子ふたりとをいっしょに連れて行かれたが、イエスは悲しみもだえ始められた。</span>
<span className="v" id="v38" data-v="38" data-xref="ヨハネの福音書 12:27; ペテロの手紙第一 3:18; ペテロの手紙第一 2:24"> そのとき、イエスは彼らに言われた。「わたしは悲しみのあまり死ぬほどです。ここを離れないで、わたしといっしょに目をさましていなさい。」</span>
<span className="v" id="v39" data-v="39" data-xref="ヨハネの福音書 6:38; ピリピ人への手紙 2:8; ルカの福音書 22:41–42"> それから、イエスは少し進んで行って、ひれ伏して祈って言われた。「わが父よ。できますならば、この杯をわたしから過ぎ去らせてください。しかし、わたしの願うようにではなく、あなたのみこころのように、なさってください。」</span>
<span className="v" id="v40" data-v="40" data-xref="マルコの福音書 14:37; ルカの福音書 22:45; マタイの福音書 26:43"> それから、イエスは弟子たちのところに戻って来て、彼らの眠っているのを見つけ、ペテロに言われた。「あなたがたは、そんなに、一時間でも、わたしといっしょに目をさましていることができなかったのか。</span>
<span className="v" id="v41" data-v="41" data-xref="マルコの福音書 14:38; ルカの福音書 22:46; エペソ人への手紙 6:18"> 誘惑に陥らないように、目をさまして、祈っていなさい。心は燃えていても、肉体は弱いのです。」</span>
<span className="v" id="v42" data-v="42" data-xref="マタイの福音書 26:39; マルコの福音書 14:39–40; ヘブル人への手紙 4:15"> イエスは二度目に離れて行き、祈って言われた。「わが父よ。どうしても飲まずには済まされぬ杯でしたら、どうぞみこころのとおりをなさってください。」</span>
<span className="v" id="v43" data-v="43" data-xref="ルカの福音書 9:32; ローマ人への手紙 13:1; Proverbs 23:34"> イエスが戻って来て、ご覧になると、彼らはまたも眠っていた。目をあけていることができなかったのである。</span>
<span className="v" id="v44" data-v="44" data-xref="コリント人への手紙第二 12:8; ルカの福音書 18:1; マタイの福音書 6:7"> イエスは、またも彼らを置いて行かれ、もう一度同じことをくり返して三度目の祈りをされた。</span>
<span className="v" id="v45" data-v="45" data-xref="ヨハネの福音書 13:1; ヨハネの福音書 12:27; マルコの福音書 14:41–42"> それから、イエスは弟子たちのところに来て言われた。「まだ眠って休んでいるのですか。見なさい。時が来ました。人の子は罪人たちの手に渡されるのです。</span>
<span className="v" id="v46" data-v="46" data-xref="ルカの福音書 9:51; ヨハネの福音書 14:31; 1 Samuel 17:48"> 立ちなさい。さあ、行くのです。見なさい。わたしを裏切る者が近づきました。」</span>
</div>
<div className="bp">
<span className="v" id="v47" data-v="47" data-xref="使徒の働き 1:16; マタイの福音書 26:55; マルコの福音書 14:43–50"> イエスがまだ話しておられるうちに、見よ、十二弟子のひとりであるユダがやって来た。剣や棒を手にした大ぜいの群衆もいっしょであった。群衆はみな、祭司長、民の長老たちから差し向けられたものであった。</span>
<span className="v" id="v48" data-v="48" data-xref="Psalms 55:20–21; Psalms 28:3; 2 Samuel 3:27"> イエスを裏切る者は、彼らと合図を決めて、「私が口づけをするのが、その人だ。その人をつかまえるのだ。」と言っておいた。</span>
<span className="v" id="v49" data-v="49" data-xref="マタイの福音書 26:25; テサロニケ人への手紙第一 5:26; Proverbs 27:6"> それで、彼はすぐにイエスに近づき、「先生。お元気で。」と言って、口づけした。</span>
<span className="v" id="v50" data-v="50" data-xref="マタイの福音書 20:13; マタイの福音書 22:12; Psalms 41:9"> イエスは彼に、「友よ。何のために来たのですか。」と言われた。そのとき、群衆が来て、イエスに手をかけて捕えた。</span>
<span className="v" id="v51" data-v="51" data-xref="ヨハネの福音書 18:36; マルコの福音書 14:47; コリント人への手紙第二 10:4"> すると、イエスといっしょにいた者のひとりが、手を伸ばして剣を抜き、大祭司のしもべに撃ってかかり、その耳を切り落とした。</span>
<span className="v" id="v52" data-v="52" data-xref="ヨハネの黙示録 13:10; Genesis 9:6; ローマ人への手紙 12:19"> そのとき、イエスは彼に言われた。「剣をもとに納めなさい。剣を取る者はみな剣で滅びます。</span>
<span className="v" id="v53" data-v="53" data-xref="2 Kings 6:17; マタイの福音書 4:11; Daniel 7:10"> それとも、わたしが父にお願いして、十二軍団よりも多くの御使いを、今わたしの配下に置いていただくことができないとでも思うのですか。</span>
<span className="v" id="v54" data-v="54" data-xref="Zechariah 13:7; マタイの福音書 26:24; 使徒の働き 1:16"> だが、そのようなことをすれば、こうならなければならないと書いてある聖書が、どうして実現されましょう。」</span>
<span className="v" id="v55" data-v="55" data-xref="マルコの福音書 12:35; ヨハネの福音書 8:2; ルカの福音書 22:52–53"> そのとき、イエスは群衆に言われた。「まるで強盗にでも向かうように、剣や棒を持ってわたしをつかまえに来たのですか。わたしは毎日、宮ですわって教えていたのに、あなたがたは、わたしを捕えなかったのです。</span>
<span className="v" id="v56" data-v="56" data-xref="Zechariah 13:7; ヨハネの福音書 16:32; マルコの福音書 14:50–52"> しかし、すべてこうなったのは、預言者たちの書が実現するためです。」そのとき、弟子たちはみな、イエスを見捨てて、逃げてしまった。</span>
</div>
<div className="bp">
<span className="v" id="v57" data-v="57" data-xref="マタイの福音書 26:3; マルコの福音書 14:53–65; Psalms 56:5–6"> イエスをつかまえた人たちは、イエスを大祭司カヤパのところへ連れて行った。そこには、律法学者、長老たちが集まっていた。</span>
<span className="v" id="v58" data-v="58" data-xref="ヨハネの福音書 7:32; ヨハネの福音書 18:15–16; ヨハネの福音書 18:25"> しかし、ペテロも遠くからイエスのあとをつけながら、大祭司の中庭まではいって行き、成り行きを見ようと役人たちといっしょにすわった。</span>
<span className="v" id="v59" data-v="59" data-xref="使徒の働き 6:11–13; Deuteronomy 19:16–21; マルコの福音書 14:55–56"> さて、祭司長たちと全議会は、イエスを死刑にするために、イエスを訴える偽証を求めていた。</span>
<span className="v" id="v60" data-v="60" data-xref="Deuteronomy 19:15; Psalms 35:11; Psalms 27:12"> 偽証者がたくさん出て来たが、証拠はつかめなかった。しかし、最後にふたりの者が進み出て、</span>
<span className="v" id="v61" data-v="61" data-xref="ヨハネの福音書 2:19–21; マタイの福音書 27:40; マルコの福音書 15:29"> 言った。「この人は、『わたしは神の神殿をこわして、それを三日のうちに建て直せる。』と言いました。」</span>
<span className="v" id="v62" data-v="62" data-xref="ヨハネの福音書 19:9–11; ヨハネの福音書 18:19–24; マルコの福音書 14:60"> そこで、大祭司は立ち上がってイエスに言った。「何も答えないのですか。この人たちが、あなたに不利な証言をしていますが、これはどうなのですか。」</span>
<span className="v" id="v63" data-v="63" data-xref="Leviticus 5:1; マタイの福音書 16:16; Isaiah 53:7"> しかし、イエスは黙っておられた。それで、大祭司はイエスに言った。「私は、生ける神によって、あなたに命じます。あなたは神の子キリストなのか、どうか。その答えを言いなさい。」</span>
<span className="v" id="v64" data-v="64" data-xref="Daniel 7:13; マルコの福音書 14:62; Psalms 110:1"> イエスは彼に言われた。「あなたの言うとおりです。なお、あなたがたに言っておきますが、今からのち、人の子が、力ある方の右の座に着き、天の雲に乗って来るのを、あなたがたは見ることになります。」</span>

<span className="v" id="v67" data-v="67" data-xref="Isaiah 50:6; Isaiah 53:3; マタイの福音書 27:30"> そうして、彼らはイエスの顔につばきをかけ、こぶしでなぐりつけ、また、他の者たちは、イエスを平手で打って、</span>
<span className="v" id="v68" data-v="68" data-xref="ルカの福音書 22:63–65; マルコの福音書 14:65; ペテロの手紙第一 2:4–8"> こう言った。「当ててみろ。キリスト。あなたを打ったのはだれか。」</span>

<span className="v" id="v72" data-v="72" data-xref="マタイの福音書 26:74; Isaiah 48:1; Zechariah 8:17"> それで、ペテロは、またもそれを打ち消し、誓って、「そんな人は知らない。」と言った。</span>

<span className="v" id="v74" data-v="74" data-xref="ヨハネの黙示録 3:19; コリント人への手紙第一 16:22; マルコの福音書 14:71–72"> すると彼は、「そんな人は知らない。」と言って、のろいをかけて誓い始めた。するとすぐに、鶏が鳴いた。</span>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マタイの福音書 8:18; マタイの福音書 4:25–1; ルカの福音書 5:15"> イエスが山から降りて来られると、多くの群衆がイエスに従った。</span>
<span className="v" id="v2" data-v="2" data-xref="マタイの福音書 15:25; ルカの福音書 17:12–19; マタイの福音書 18:26"> すると、ひとりのらい病人がみもとに来て、ひれ伏して言った。「主よ。お心一つで、私をきよめることがおできになります。」</span>
<span className="v" id="v3" data-v="3" data-xref="ルカの福音書 5:13; Psalms 33:9; 2 Kings 5:14"> イエスは手を伸ばして、彼にさわり、「わたしの心だ。きよくなれ。」と言われた。すると、すぐに彼のらい病はきよめられた。</span>
<span className="v" id="v4" data-v="4" data-xref="Leviticus 14:2–32; ルカの福音書 5:14; ルカの福音書 17:14"> イエスは彼に言われた。「気をつけて、だれにも話さないようにしなさい。ただ、人々へのあかしのために、行って、自分を祭司に見せなさい。そして、モーセの命じた供え物をささげなさい。」</span>
<span className="v" id="v5" data-v="5" data-xref="ルカの福音書 7:1–10; 使徒の働き 27:43; 使徒の働き 10:1–33"> イエスがカペナウムにはいられると、ひとりの百人隊長がみもとに来て、懇願して、</span>
<span className="v" id="v6" data-v="6" data-xref="コロサイ人への手紙 4:1; マタイの福音書 4:24; 使徒の働き 9:33"> 言った。「主よ。私のしもべが中風やみで、家に寝ていて、ひどく苦しんでおります。」</span>
<span className="v" id="v7" data-v="7" data-xref="マタイの福音書 9:18–19; ルカの福音書 7:6; マルコの福音書 5:23–24"> イエスは彼に言われた。「行って、直してあげよう。」</span>
<span className="v" id="v8" data-v="8" data-xref="Psalms 107:20; ルカの福音書 7:6–7; Psalms 33:9"> しかし、百人隊長は答えて言った。「主よ。あなたを私の屋根の下にお入れする資格は、私にはありません。ただ、おことばをいただかせてください。そうすれば、私のしもべは直りますから。</span>
<span className="v" id="v9" data-v="9" data-xref="ルカの福音書 4:35–36; テトスへの手紙 2:9; コロサイ人への手紙 3:22"> と申しますのは、私も権威の下にある者ですが、私自身の下にも兵士たちがいまして、そのひとりに『行け。』と言えば行きますし、別の者に『来い。』と言えば来ます。また、しもべに『これをせよ。』と言えば、そのとおりにいたします。」</span>
<span className="v" id="v10" data-v="10" data-xref="マタイの福音書 15:28; ルカの福音書 7:9; マルコの福音書 6:6"> イエスは、これを聞いて驚かれ、ついて来た人たちにこう言われた。「まことに、あなたがたに告げます。わたしはイスラエルのうちのだれにも、このような信仰を見たことがありません。</span>
<span className="v" id="v11" data-v="11" data-xref="ルカの福音書 13:28–29; エペソ人への手紙 3:6; ガラテヤ人への手紙 3:28–29"> あなたがたに言いますが、たくさんの人が東からも西からも来て、天の御国で、アブラハム、イサク、ヤコブといっしょに食卓に着きます。</span>
<span className="v" id="v12" data-v="12" data-xref="マタイの福音書 25:30; ルカの福音書 13:28; マタイの福音書 21:43"> しかし、御国の子らは外の暗やみに放り出され、そこで泣いて歯ぎしりするのです。」</span>
<span className="v" id="v13" data-v="13" data-xref="マタイの福音書 9:29–30; マルコの福音書 9:23; ヨハネの福音書 4:50"> それから、イエスは百人隊長に言われた。「さあ行きなさい。あなたの信じたとおりになるように。」すると、ちょうどその時、そのしもべはいやされた。</span>
<span className="v" id="v14" data-v="14" data-xref="ルカの福音書 4:38–41; マルコの福音書 1:29–34; コリント人への手紙第一 9:5"> それから、イエスは、ペテロの家に来られて、ペテロのしゅうとめが熱病で床に着いているのをご覧になった。</span>
<span className="v" id="v15" data-v="15" data-xref="2 Kings 13:21; ルカの福音書 4:38–39; ルカの福音書 8:54"> イエスが手にさわられると、熱がひき、彼女は起きてイエスをもてなした。</span>
<span className="v" id="v16" data-v="16" data-xref="Exodus 15:26; マタイの福音書 14:14; マルコの福音書 1:32–34"> 夕方になると、人々は悪霊につかれた者を大ぜい、みもとに連れて来た。そこで、イエスはみことばをもって霊どもを追い出し、また病気の人々をみなお直しになった。</span>
<span className="v" id="v17" data-v="17" data-xref="Isaiah 53:4; ペテロの手紙第一 2:24; マタイの福音書 1:22"> これは、預言者イザヤを通して言われた事が成就するためであった。「彼が私たちのわずらいを身に引き受け、私たちの病を背負った。」</span>
<span className="v" id="v18" data-v="18" data-xref="ルカの福音書 4:42–43; ルカの福音書 8:22; マルコの福音書 4:35"> さて、イエスは群衆が自分の回りにいるのをご覧になると、向こう岸に行くための用意をお命じになった。</span>
<span className="v" id="v19" data-v="19" data-xref="ルカの福音書 22:33–34; ヨハネの福音書 13:36–38; ルカの福音書 14:25–27"> そこに、ひとりの律法学者が来てこう言った。「先生。私はあなたのおいでになる所なら、どこにでもついてまいります。」</span>
<span className="v" id="v20" data-v="20" data-xref="Psalms 84:3; ルカの福音書 2:7; Isaiah 53:2–3"> すると、イエスは彼に言われた。「狐には穴があり、空の鳥には巣があるが、人の子には枕する所もありません。」</span>
<span className="v" id="v21" data-v="21" data-xref="ルカの福音書 9:59–62; Leviticus 21:11–12; Numbers 6:6–7"> また、別のひとりの弟子がイエスにこう言った。「主よ。まず行って、私の父を葬ることを許してください。」</span>
<span className="v" id="v22" data-v="22" data-xref="コロサイ人への手紙 2:13; ルカの福音書 15:32; エペソ人への手紙 5:14"> ところが、イエスは彼に言われた。「わたしについて来なさい。死人たちに彼らの中の死人たちを葬らせなさい。」</span>
<span className="v" id="v23" data-v="23" data-xref="ルカの福音書 8:22–25; マルコの福音書 4:36–41; マタイの福音書 9:1"> イエスが舟にお乗りになると、弟子たちも従った。</span>
<span className="v" id="v24" data-v="24" data-xref="ルカの福音書 8:23; Psalms 107:23–27; マルコの福音書 4:37–38"> すると、見よ、湖に大暴風が起こって、舟は大波をかぶった。ところが、イエスは眠っておられた。</span>
<span className="v" id="v25" data-v="25" data-xref="Jonah 1:6; 2 Chronicles 14:11; マルコの福音書 4:38–39"> 弟子たちはイエスのみもとに来て、イエスを起こして言った。「主よ。助けてください。私たちはおぼれそうです。」</span>
<span className="v" id="v26" data-v="26" data-xref="Isaiah 41:10–14; Psalms 65:7; Psalms 107:28–30"> イエスは言われた。「なぜこわがるのか、信仰の薄い者たちだ。」それから、起き上がって、風と湖をしかりつけられると、大なぎになった。</span>
<span className="v" id="v27" data-v="27" data-xref="マルコの福音書 7:37; マルコの福音書 6:51; マタイの福音書 14:33"> 人々は驚いてこう言った。「風や湖までが言うことをきくとは、いったいこの方はどういう方なのだろう。」</span>
<span className="v" id="v28" data-v="28" data-xref="ルカの福音書 8:26–39; マルコの福音書 5:1–20; 使徒の働き 10:38"> それから、向こう岸のガダラ人の地にお着きになると、悪霊につかれた人がふたり墓から出て来て、イエスに出会った。彼らはひどく狂暴で、だれもその道を通れないほどであった。</span>
<span className="v" id="v29" data-v="29" data-xref="マルコの福音書 1:24; ルカの福音書 4:34; ヤコブの手紙 2:19"> すると、見よ、彼らはわめいて言った。「神の子よ。いったい私たちに何をしようというのです。まだその時ではないのに、もう私たちを苦しめに来られたのですか。」</span>
<span className="v" id="v30" data-v="30" data-xref="Deuteronomy 14:8; Leviticus 11:7; マルコの福音書 5:11"> ところで、そこからずっと離れた所に、たくさんの豚の群れが飼ってあった。</span>
<span className="v" id="v31" data-v="31" data-xref="ヨハネの黙示録 20:1–2; ルカの福音書 8:30–33; マルコの福音書 5:12"> それで、悪霊どもはイエスに願ってこう言った。「もし私たちを追い出そうとされるのでしたら、どうか豚の群れの中にやってください。」</span>
<span className="v" id="v32" data-v="32" data-xref="マルコの福音書 5:13; 使徒の働き 2:23; ヨハネの黙示録 20:7"> イエスは彼らに「行け。」と言われた。すると、彼らは出て行って豚にはいった。すると、見よ、その群れ全体がどっとがけから湖へ駆け降りて行って、水におぼれて死んだ。</span>
<span className="v" id="v33" data-v="33" data-xref="ルカの福音書 8:34–36; マルコの福音書 5:14–16; 使徒の働き 19:15–17"> 飼っていた者たちは逃げ出して町に行き、悪霊につかれた人たちのことなどを残らず知らせた。</span>
<span className="v" id="v34" data-v="34" data-xref="使徒の働き 16:39; ルカの福音書 8:37–39; ルカの福音書 5:8"> すると、見よ、町中の者がイエスに会いに出て来た。そして、イエスに会うと、どうかこの地方を立ち去ってくださいと願った。</span>

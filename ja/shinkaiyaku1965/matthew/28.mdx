<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マルコの福音書 16:1–8; ヨハネの福音書 20:1–10; マタイの福音書 27:56"> さて、安息日が終わって、週の初めの日の明け方、マグダラのマリヤと、ほかのマリヤが墓を見に来た。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒の働き 16:26; ヨハネの福音書 20:12–13; マルコの福音書 16:3–5"> すると、大きな地震が起こった。それは、主の使いが天から降りて来て、石をわきへころがして、その上にすわったからである。</span>
<span className="v" id="v3" data-v="3" data-xref="マルコの福音書 9:3; 使徒の働き 1:10; マルコの福音書 16:5"> その顔は、いなずまのように輝き、その衣は雪のように白かった。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネの黙示録 1:17; Daniel 10:7; マタイの福音書 27:65–66"> 番兵たちは、御使いを見て恐ろしさのあまり震え上がり、死人のようになった。</span>
<span className="v" id="v5" data-v="5" data-xref="ヨハネの黙示録 1:17–18; ヘブル人への手紙 1:14; Isaiah 41:10"> すると、御使いは女たちに言った。「恐れてはいけません。あなたがたが十字架につけられたイエスを捜しているのを、私は知っています。</span>
<span className="v" id="v6" data-v="6" data-xref="マルコの福音書 16:6; マタイの福音書 12:40; ルカの福音書 24:6–8"> ここにはおられません。前から言っておられたように、よみがえられたからです。来て、納めてあった場所を見てごらんなさい。</span>
<span className="v" id="v7" data-v="7" data-xref="マタイの福音書 26:32; ルカの福音書 24:22–24; マタイの福音書 28:10"> ですから急いで行って、お弟子たちにこのことを知らせなさい。イエスが死人の中からよみがえられたこと、そして、あなたがたより先にガリラヤに行かれ、あなたがたは、そこで、お会いできるということです。では、これだけはお伝えしました。」</span>
<span className="v" id="v8" data-v="8" data-xref="Psalms 2:11; マルコの福音書 16:8; ルカの福音書 24:36–41"> そこで、彼女たちは、恐ろしくはあったが大喜びで、急いで墓を離れ、弟子たちに知らせに走って行った。</span>
<span className="v" id="v9" data-v="9" data-xref="マタイの福音書 28:17; ヨハネの福音書 20:14–17; マタイの福音書 14:33"> すると、イエスが彼女たちに出会って、「おはよう。」と言われた。彼女たちは近寄って御足を抱いてイエスを拝んだ。</span>
<span className="v" id="v10" data-v="10" data-xref="ローマ人への手紙 8:29; ヨハネの福音書 20:17; マタイの福音書 28:7"> すると、イエスは言われた。「恐れてはいけません。行って、わたしの兄弟たちに、ガリラヤに行くように言いなさい。そこでわたしに会えるのです。」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="マタイの福音書 27:65–66; マタイの福音書 28:4"> 女たちが行き着かないうちに、もう、数人の番兵が都に来て、起こった事を全部、祭司長たちに報告した。</span>
<span className="v" id="v12" data-v="12" data-xref="マタイの福音書 26:3–4; 使徒の働き 4:5–22; マタイの福音書 27:1–2"> そこで、祭司長たちは民の長老たちとともに集まって協議し、兵士たちに多額の金を与えて、</span>
<span className="v" id="v13" data-v="13" data-xref="マタイの福音書 26:64"> こう言った。「『夜、私たちが眠っている間に、弟子たちがやって来て、イエスを盗んで行った。』と言うのだ。</span>
<span className="v" id="v14" data-v="14" data-xref="マタイの福音書 27:2; 使徒の働き 12:19"> もし、このことが総督の耳にはいっても、私たちがうまく説得して、あなたがたには心配をかけないようにするから。」</span>
<span className="v" id="v15" data-v="15" data-xref="テモテへの手紙第一 6:10; マタイの福音書 27:8; マタイの福音書 26:15"> そこで、彼らは金をもらって、指図されたとおりにした。それで、この話が広くユダヤ人の間に広まって今日に及んでいる。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="マタイの福音書 26:32; マタイの福音書 28:10; マタイの福音書 28:7"> しかし、十一人の弟子たちは、ガリラヤに行って、イエスの指示された山に登った。</span>
<span className="v" id="v17" data-v="17" data-xref="Psalms 45:11; Psalms 2:12; ヨハネの福音書 5:23"> そして、イエスにお会いしたとき、彼らは礼拝した。しかし、ある者は疑った。</span>
<span className="v" id="v18" data-v="18" data-xref="ヨハネの福音書 3:35; ペテロの手紙第一 3:22; マタイの福音書 11:27"> イエスは近づいて来て、彼らにこう言われた。「わたしには天においても、地においても、いっさいの権威が与えられています。</span>
<span className="v" id="v19" data-v="19" data-xref="マルコの福音書 16:15–16; 使徒の働き 2:38–39; 使徒の働き 1:8"> それゆえ、あなたがたは行って、あらゆる国の人々を弟子としなさい。そして、父、子、聖霊の御名によってバプテスマを授け、</span>
<span className="v" id="v20" data-v="20" data-xref="Isaiah 41:10; Joshua 1:5; 使徒の働き 18:9–10"> また、わたしがあなたがたに命じておいたすべてのことを守るように、彼らを教えなさい。見よ。わたしは、世の終わりまで、いつも、あなたがたとともにいます。」</span>
</div>

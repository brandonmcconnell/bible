<span className="v" id="v1" data-v="1" data-xref="マルコの福音書 3:13; マタイの福音書 15:29; マルコの福音書 4:1"> この群衆を見て、イエスは山に登り、おすわりになると、弟子たちがみもとに来た。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒の働き 8:35; ルカの福音書 6:20–26; 使徒の働き 10:34"> そこで、イエスは口を開き、彼らに教えて、言われた。</span>
<span className="v" id="v3" data-v="3" data-xref="Isaiah 66:2; Proverbs 29:23; Psalms 34:18"> 「心の貧しい者は幸いです。天の御国はその人のものだからです。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネの黙示録 21:4; コリント人への手紙第二 7:9–10; ヨハネの福音書 16:20–22"> 悲しむ者は幸いです。その人は慰められるからです。</span>
<span className="v" id="v5" data-v="5" data-xref="Psalms 37:11; Isaiah 29:19; ヤコブの手紙 3:13"> 柔和な者は幸いです。その人は地を相続するからです。</span>
<span className="v" id="v6" data-v="6" data-xref="ヨハネの福音書 4:14; Psalms 107:9; ヨハネの福音書 6:27"> 義に飢え渇いている者は幸いです。その人は満ち足りるからです。</span>
<span className="v" id="v7" data-v="7" data-xref="エペソ人への手紙 4:32–1; マタイの福音書 6:14–15; 2 Samuel 22:26"> あわれみ深い者は幸いです。その人はあわれみを受けるからです。</span>
<span className="v" id="v8" data-v="8" data-xref="Psalms 24:4; Psalms 51:10; ヘブル人への手紙 10:22"> 心のきよい者は幸いです。その人は神を見るからです。</span>
<span className="v" id="v9" data-v="9" data-xref="ヘブル人への手紙 12:14; ヤコブの手紙 3:16–18; ローマ人への手紙 12:18"> 平和をつくる者は幸いです。その人は神の子どもと呼ばれるからです。</span>
<span className="v" id="v10" data-v="10" data-xref="ヤコブの手紙 1:12; ペテロの手紙第一 3:13–14; コリント人への手紙第二 4:17"> 義のために迫害されている者は幸いです。天の御国はその人のものだからです。</span>
<span className="v" id="v11" data-v="11" data-xref="ペテロの手紙第一 4:14; ルカの福音書 21:17; マルコの福音書 13:13"> わたしのために、ののしられたり、迫害されたり、また、ありもしないことで悪口雑言を言われたりするとき、あなたがたは幸いです。</span>
<span className="v" id="v12" data-v="12" data-xref="ルカの福音書 6:23; ヤコブの手紙 1:2; コロサイ人への手紙 3:24"> 喜びなさい。喜びおどりなさい。天においてあなたがたの報いは大きいのだから。あなたがたより前に来た預言者たちも、そのように迫害されました。</span>
<span className="v" id="v13" data-v="13" data-xref="コロサイ人への手紙 4:6; ルカの福音書 14:34–35; マルコの福音書 9:49–50"> あなたがたは、地の塩です。もし塩が塩けをなくしたら、何によって塩けをつけるのでしょう。もう何の役にも立たず、外に捨てられて、人々に踏みつけられるだけです。</span>
<span className="v" id="v14" data-v="14" data-xref="ピリピ人への手紙 2:15; ヨハネの福音書 8:12; エペソ人への手紙 5:8–14"> あなたがたは、世界の光です。山の上にある町は隠れる事ができません。</span>
<span className="v" id="v15" data-v="15" data-xref="ルカの福音書 11:33; マルコの福音書 4:21; ルカの福音書 8:16"> また、あかりをつけて、それを枡の下に置く者はありません。燭台の上に置きます。そうすれば、家にいる人々全部を照らします。</span>
<span className="v" id="v16" data-v="16" data-xref="ペテロの手紙第一 2:12; テトスへの手紙 2:7; ヨハネの福音書 15:8"> このように、あなたがたの光を人々の前で輝かせ、人々があなたがたの良い行ないを見て、天におられるあなたがたの父をあがめるようにしなさい。</span>
<span className="v" id="v17" data-v="17" data-xref="ローマ人への手紙 10:4; ルカの福音書 16:17; ガラテヤ人への手紙 4:4–5"> わたしが来たのは律法や預言者を廃棄するためだと思ってはなりません。廃棄するためにではなく、成就するために来たのです。</span>
<span className="v" id="v18" data-v="18" data-xref="ルカの福音書 16:17; Isaiah 40:8; ペテロの手紙第一 1:25"> まことに、あなたがたに告げます。天地が滅びうせない限り、律法の中の一点一画でも決してすたれることはありません。全部が成就されます。</span>
<span className="v" id="v19" data-v="19" data-xref="Deuteronomy 12:32; ヤコブの手紙 2:10–11; マタイの福音書 28:20"> だから、戒めのうち最も小さいものの一つでも、これを破ったり、また破るように人に教えたりする者は、天の御国で、最も小さい者と呼ばれます。しかし、それを守り、また守るように教える者は、天の御国で、偉大な者と呼ばれます。</span>
<span className="v" id="v20" data-v="20" data-xref="ローマ人への手紙 10:2–3; ピリピ人への手紙 3:9; ローマ人への手紙 9:30–32"> まことに、あなたがたに告げます。もしあなたがたの義が、律法学者やパリサイ人の義にまさるものでないなら、あなたがたは決して天の御国に、はいれません。</span>
<span className="v" id="v21" data-v="21" data-xref="Deuteronomy 5:17; Exodus 20:13; Numbers 35:30–34"> 昔の人々に、『人を殺してはならない。人を殺す者はさばきを受けなければならない。』と言われたのを、あなたがたは聞いています。</span>
<span className="v" id="v22" data-v="22" data-xref="ヨハネの手紙第一 3:14–15; ヨハネの手紙第一 4:20–21; ヨハネの手紙第一 2:9"> しかし、わたしはあなたがたに言います。兄弟に向かって腹を立てる者は、だれでもさばきを受けなければなりません。兄弟に向かって『能なし。』と言うような者は、最高議会に引き渡されます。また、『ばか者。』と言うような者は燃えるゲヘナに投げ込まれます。</span>
<span className="v" id="v23" data-v="23" data-xref="マルコの福音書 11:25; Leviticus 6:2–6; マタイの福音書 5:24"> だから、祭壇の上に供え物をささげようとしているとき、もし兄弟に恨まれていることをそこで思い出したなら、</span>
<span className="v" id="v24" data-v="24" data-xref="ヤコブの手紙 5:16; ローマ人への手紙 12:17–18; マタイの福音書 18:15–17"> 供え物はそこに、祭壇の前に置いたままにして、出て行って、まずあなたの兄弟と仲直りをしなさい。それから、来て、その供え物をささげなさい。</span>
<span className="v" id="v25" data-v="25" data-xref="ルカの福音書 12:58–59; Proverbs 25:8; ヘブル人への手紙 3:13"> あなたを告訴する者とは、あなたが彼といっしょに途中にある間に早く仲良くなりなさい。そうでないと、告訴する者は、あなたを裁判官に引き渡し、裁判官は下役に引き渡して、あなたはついに牢に入れられることになります。</span>
<span className="v" id="v26" data-v="26" data-xref="マタイの福音書 18:34; ルカの福音書 12:59; テサロニケ人への手紙第二 1:9"> まことに、あなたに告げます。あなたは最後の一コドラントを支払うまでは、そこから出ては来られません。</span>
<span className="v" id="v27" data-v="27" data-xref="Deuteronomy 5:18; Proverbs 6:32; Exodus 20:14"> 『姦淫してはならない。』と言われたのを、あなたがたは聞いています。</span>
<span className="v" id="v28" data-v="28" data-xref="ヨハネの手紙第一 2:16; ヤコブの手紙 1:14–15; Proverbs 6:25"> しかし、わたしはあなたがたに言います。だれでも情欲をいだいて女を見る者は、すでに心の中で姦淫を犯したのです。</span>
<span className="v" id="v29" data-v="29" data-xref="ローマ人への手紙 8:13; マルコの福音書 9:43–48; コロサイ人への手紙 3:5"> もし、右の目が、あなたをつまずかせるなら、えぐり出して、捨ててしまいなさい。からだの一部を失っても、からだ全体ゲヘナに投げ込まれるよりは、よいからです。</span>
<span className="v" id="v30" data-v="30" data-xref="マルコの福音書 9:43; マタイの福音書 5:29; ペテロの手紙第一 2:8"> もし、右の手があなたをつまずかせるなら、切って、捨ててしまいなさい。からだの一部を失っても、からだ全体ゲヘナに落ちるよりは、よいからです。</span>
<span className="v" id="v31" data-v="31" data-xref="Jeremiah 3:1; Deuteronomy 24:1–4; マタイの福音書 19:7"> また『だれでも、妻を離別する者は、妻に離婚状を与えよ。』と言われています。</span>
<span className="v" id="v32" data-v="32" data-xref="ローマ人への手紙 7:3; コリント人への手紙第一 7:10–11; ルカの福音書 16:18"> しかし、わたしはあなたがたに言います。だれであっても、不貞以外の理由で妻を離別する者は、妻に姦淫を犯させるのです。また、だれでも、離別された女と結婚すれば、姦淫を犯すのです。</span>
<span className="v" id="v33" data-v="33" data-xref="Deuteronomy 23:21; Leviticus 19:12; Ecclesiastes 5:4–6"> さらにまた、昔の人々に、『偽りの誓いを立ててはならない。あなたの誓ったことを主に果たせ。』と言われていたのを、あなたがたは聞いています。</span>
<span className="v" id="v34" data-v="34" data-xref="ヤコブの手紙 5:12; Isaiah 66:1; Deuteronomy 23:21–23"> しかし、わたしはあなたがたに言います。決して誓ってはいけません。すなわち、天をさして誓ってはいけません。そこは神の御座だからです。</span>
<span className="v" id="v35" data-v="35" data-xref="Psalms 48:2; Malachi 1:14; 2 Chronicles 6:6"> 地をさして誓ってもいけません。そこは神の足台だからです。エルサレムをさして誓ってもいけません。そこは偉大な王の都だからです。</span>
<span className="v" id="v36" data-v="36" data-xref="ルカの福音書 12:25; マタイの福音書 6:27; マタイの福音書 23:16–21"> あなたの頭をさして誓ってもいけません。あなたは、一本の髪の毛すら、白くも黒くもできないからです。</span>
<span className="v" id="v37" data-v="37" data-xref="ヤコブの手紙 5:12; コロサイ人への手紙 4:6; コロサイ人への手紙 3:9"> だから、あなたがたは、『はい。』は『はい。』、『いいえ。』は『いいえ。』とだけ言いなさい。それ以上のことは悪いことです。</span>
<span className="v" id="v38" data-v="38" data-xref="Leviticus 24:19–20; Deuteronomy 19:21; Exodus 21:22–27"> 『目には目で、歯には歯で。』と言われたのを、あなたがたは聞いています。</span>
<span className="v" id="v39" data-v="39" data-xref="テサロニケ人への手紙第一 5:15; ペテロの手紙第一 3:9; ローマ人への手紙 12:17–19"> しかし、わたしはあなたがたに言います。悪い者に手向かってはいけません。あなたの右の頬を打つような者には、左の頬も向けなさい。</span>
<span className="v" id="v40" data-v="40" data-xref="ルカの福音書 6:29; コリント人への手紙第一 6:7"> あなたを告訴して下着を取ろうとする者には、上着もやりなさい。</span>
<span className="v" id="v41" data-v="41" data-xref="ルカの福音書 23:26; マタイの福音書 27:32; マルコの福音書 15:21"> あなたに一ミリオン行けと強いるような者とは、いっしょに二ミリオン行きなさい。</span>
<span className="v" id="v42" data-v="42" data-xref="Proverbs 19:17; ヘブル人への手紙 13:16; ルカの福音書 6:30–36"> 求める者には与え、借りようとする者は断わらないようにしなさい。</span>
<span className="v" id="v43" data-v="43" data-xref="Leviticus 19:18; Psalms 139:21–22; ガラテヤ人への手紙 5:13–14"> 『自分の隣人を愛し、自分の敵を憎め。』と言われたのを、あなたがたは聞いています。</span>
<span className="v" id="v44" data-v="44" data-xref="ローマ人への手紙 12:14; ペテロの手紙第一 3:9; ルカの福音書 6:27–28"> しかし、わたしはあなたがたに言います。自分の敵を愛し、迫害する者のために祈りなさい。</span>
<span className="v" id="v45" data-v="45" data-xref="Psalms 145:9; ルカの福音書 6:35; 使徒の働き 14:17"> それでこそ、天におられるあなたがたの父の子どもになれるのです。天の父は、悪い人にも良い人にも太陽を上らせ、正しい人にも正しくない人にも雨を降らせてくださるからです。</span>
<span className="v" id="v46" data-v="46" data-xref="ルカの福音書 6:32–35; ペテロの手紙第一 2:20–23; マタイの福音書 9:10–11"> 自分を愛してくれる者を愛したからといって、何の報いが受けられるでしょう。取税人でも、同じことをしているではありませんか。</span>
<span className="v" id="v47" data-v="47" data-xref="マタイの福音書 5:20; ルカの福音書 6:32; ペテロの手紙第一 2:20"> また、自分の兄弟にだけあいさつしたからといって、どれだけまさったことをしたのでしょう。異邦人でも同じことをするではありませんか。</span>
<span className="v" id="v48" data-v="48" data-xref="ペテロの手紙第一 1:15–16; ヤコブの手紙 1:4; Leviticus 19:2"> だから、あなたがたは、天の父が完全なように、完全でありなさい。</span>

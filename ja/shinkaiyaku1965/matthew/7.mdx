<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ルカの福音書 6:37; ローマ人への手紙 2:1–2; ヤコブの手紙 4:11–12"> さばいてはいけません。さばかれないためです。</span>
<span className="v" id="v2" data-v="2" data-xref="ヤコブの手紙 2:13; マルコの福音書 4:24; ルカの福音書 6:38"> あなたがたがさばくとおりに、あなたがたもさばかれ、あなたがたが量るとおりに、あなたがたも量られるからです。</span>
<span className="v" id="v3" data-v="3" data-xref="ヨハネの福音書 8:7–9; ガラテヤ人への手紙 6:1; ルカの福音書 6:41–42"> また、なぜあなたは、兄弟の目の中のちりに目をつけるが、自分の目の中の梁には気がつかないのですか。</span>
<span className="v" id="v4" data-v="4"> 兄弟に向かって、『あなたの目のちりを取らせてください。』などとどうして言うのですか。見なさい、自分の目には梁があるではありませんか。</span>
<span className="v" id="v5" data-v="5" data-xref="ルカの福音書 6:42; Psalms 51:9–13; マタイの福音書 23:13–28"> 偽善者たち。まず自分の目から梁を取りのけなさい。そうすれば、はっきり見えて、兄弟の目からも、ちりを取り除くことができます。</span>
<span className="v" id="v6" data-v="6" data-xref="Proverbs 9:7–8; Proverbs 23:9; マタイの福音書 10:14–15"> 聖なるものを犬に与えてはいけません。また豚の前に、真珠を投げてはなりません。それを足で踏みにじり、向き直ってあなたがたを引き裂くでしょうから。</span>
<span className="v" id="v7" data-v="7" data-xref="マタイの福音書 21:22; ヨハネの手紙第一 3:22; ヨハネの福音書 15:7"> 求めなさい。そうすれば与えられます。捜しなさい。そうすれば見つかります。たたきなさい。そうすれば開かれます。</span>
<span className="v" id="v8" data-v="8" data-xref="Psalms 81:10; Psalms 81:16; ルカの福音書 23:42–43"> だれであれ、求める者は受け、捜す者は見つけ出し、たたく者には開かれます。</span>
<span className="v" id="v9" data-v="9" data-xref="ルカの福音書 11:11–13"> あなたがたも、自分の子がパンを下さいと言うときに、だれが石を与えるでしょう。</span>
<span className="v" id="v10" data-v="10"> また、子が魚を下さいと言うのに、だれが蛇を与えるでしょう。</span>
<span className="v" id="v11" data-v="11" data-xref="ルカの福音書 11:11–13; ヤコブの手紙 1:17; ローマ人への手紙 8:32"> してみると、あなたがたは、悪い者ではあっても、自分の子どもには良い物を与えることを知っているのです。とすれば、なおのこと、天におられるあなたがたの父が、どうして、求める者たちに良いものを下さらないことがありましょう。</span>
<span className="v" id="v12" data-v="12" data-xref="ルカの福音書 6:31; ローマ人への手紙 13:8–10; ガラテヤ人への手紙 5:13–14"> それで、何事でも、自分にしてもらいたいことは、ほかの人にもそのようにしなさい。これが律法であり預言者です。</span>
<span className="v" id="v13" data-v="13" data-xref="ルカの福音書 13:24–25; Proverbs 16:25; ヨハネの福音書 14:6"> 狭い門からはいりなさい。滅びに至る門は大きく、その道は広いからです。そして、そこからはいって行く者が多いのです。</span>
<span className="v" id="v14" data-v="14" data-xref="ルカの福音書 13:23–30; マタイの福音書 22:14; マタイの福音書 16:24–25"> いのちに至る門は小さく、その道は狭く、それを見いだす者はまれです。</span>
<span className="v" id="v15" data-v="15" data-xref="ヨハネの手紙第一 4:1; ペテロの手紙第二 2:1–3; マタイの福音書 24:11"> にせ預言者たちに気をつけなさい。彼らは羊のなりをしてやって来るが、うちは貪欲な狼です。</span>
<span className="v" id="v16" data-v="16" data-xref="ルカの福音書 6:43–45; マタイの福音書 12:33; ヤコブの手紙 3:12"> あなたがたは、実によって彼らを見分けることができます。ぶどうは、いばらからは取れないし、いちじくは、あざみから取れるわけがないでしょう。</span>
<span className="v" id="v17" data-v="17" data-xref="マタイの福音書 12:33–35; ガラテヤ人への手紙 5:22–24; エペソ人への手紙 5:9"> 同様に、良い木はみな良い実を結ぶが、悪い木は悪い実を結びます。</span>
<span className="v" id="v18" data-v="18" data-xref="ガラテヤ人への手紙 5:17; ヨハネの手紙第一 3:9–10"> 良い木が悪い実をならせることはできないし、また、悪い木が良い実をならせることもできません。</span>
<span className="v" id="v19" data-v="19" data-xref="マタイの福音書 3:10; ヘブル人への手紙 6:8; ヨハネの福音書 15:2–6"> 良い実を結ばない木は、みな切り倒されて、火に投げ込まれます。</span>
<span className="v" id="v20" data-v="20" data-xref="マタイの福音書 7:16; 使徒の働き 5:38"> こういうわけで、あなたがたは、実によって彼らを見分けることができるのです。</span>
<span className="v" id="v21" data-v="21" data-xref="ローマ人への手紙 2:13; ルカの福音書 6:46; ヤコブの手紙 1:22"> わたしに向かって、『主よ、主よ。』と言う者がみな天の御国にはいるのではなく、天におられるわたしの父のみこころを行なう者がはいるのです。</span>
<span className="v" id="v22" data-v="22" data-xref="ルカの福音書 13:25–27; コリント人への手紙第一 13:1–2; Malachi 3:17–18"> その日には、大ぜいの者がわたしに言うでしょう。『主よ、主よ。私たちはあなたの名によって預言をし、あなたの名によって悪霊を追い出し、あなたの名によって奇蹟をたくさん行なったではありませんか。』</span>
<span className="v" id="v23" data-v="23" data-xref="マタイの福音書 25:41; Psalms 6:8; ルカの福音書 13:25"> しかし、その時、わたしは彼らにこう宣告します。『わたしはあなたがたを全然知らない。不法をなす者ども。わたしから離れて行け。』</span>
<span className="v" id="v24" data-v="24" data-xref="ルカの福音書 6:47–49; ヨハネの福音書 13:17; コリント人への手紙第一 3:10–11"> だから、わたしのこれらのことばを聞いてそれを行なう者はみな、岩の上に自分の家を建てた賢い人に比べることができます。</span>
<span className="v" id="v25" data-v="25" data-xref="ヤコブの手紙 1:12; Psalms 125:1–2; ペテロの手紙第一 1:7"> 雨が降って洪水が押し寄せ、風が吹いてその家に打ちつけたが、それでも倒れませんでした。岩の上に建てられていたからです。</span>
<span className="v" id="v26" data-v="26" data-xref="Jeremiah 8:9; ルカの福音書 6:49; ヤコブの手紙 2:20"> また、わたしのこれらのことばを聞いてそれを行なわない者はみな、砂の上に自分の家を建てた愚かな人に比べることができます。</span>
<span className="v" id="v27" data-v="27" data-xref="マタイの福音書 13:19–22; ペテロの手紙第二 2:20–22; コリント人への手紙第一 3:13"> 雨が降って洪水が押し寄せ、風が吹いてその家に打ちつけると、倒れてしまいました。しかもそれはひどい倒れ方でした。」</span>
<span className="v" id="v28" data-v="28" data-xref="ルカの福音書 4:32; マルコの福音書 1:22; ヨハネの福音書 7:46"> イエスがこれらのことばを語り終えられると、群衆はその教えに驚いた。</span>
<span className="v" id="v29" data-v="29" data-xref="ヘブル人への手紙 4:12–13; ルカの福音書 20:8; Deuteronomy 18:18–19"> というのは、イエスが、律法学者たちのようにではなく、権威ある者のように教えられたからである。</span>

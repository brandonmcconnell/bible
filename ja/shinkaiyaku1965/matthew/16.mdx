<span className="v" id="v1" data-v="1" data-xref="ルカの福音書 11:16; マタイの福音書 16:6; 使徒の働き 4:1"> パリサイ人やサドカイ人たちがみそばに寄って来て、イエスをためそうとして、天からのしるしを見せてくださいと頼んだ。</span>
<span className="v" id="v2" data-v="2" data-xref="ルカの福音書 12:54–56"> しかし、イエスは彼らに答えて言われた。「あなたがたは、夕方には、『夕焼けだから晴れる。』と言うし、</span>
<span className="v" id="v3" data-v="3" data-xref="ルカの福音書 12:56; 1 Chronicles 12:32; マタイの福音書 11:5"> 朝には、『朝焼けでどんよりしているから、きょうは荒れ模様だ。』と言う。そんなによく、空模様の見分け方を知っていながら、なぜ時のしるしを見分けることができないのですか。</span>
<span className="v" id="v4" data-v="4" data-xref="ルカの福音書 11:29–30; マタイの福音書 12:39–40; Jonah 1:17"> 悪い、姦淫の時代はしるしを求めています。しかし、ヨナのしるしのほかには、しるしは与えられません。」そう言って、イエスは彼らを残して去って行かれた。</span>
<span className="v" id="v5" data-v="5" data-xref="マルコの福音書 8:13–14; マタイの福音書 15:39"> 弟子たちは向こう岸に行ったが、パンを持って来るのを忘れた。</span>
<span className="v" id="v6" data-v="6" data-xref="ルカの福音書 12:1; ガラテヤ人への手紙 5:9; マタイの福音書 16:12"> イエスは彼らに言われた。「パリサイ人やサドカイ人たちのパン種には注意して気をつけなさい。」</span>
<span className="v" id="v7" data-v="7" data-xref="マルコの福音書 8:16–18; マタイの福音書 15:16–18; 使徒の働き 10:14"> すると、彼らは、「これは私たちがパンを持って来なかったからだ。」と言って、議論を始めた。</span>
<span className="v" id="v8" data-v="8" data-xref="マタイの福音書 6:30; マタイの福音書 14:31; マタイの福音書 8:26"> イエスはそれに気づいて言われた。「あなたがた、信仰の薄い人たち。パンがないからだなどと、なぜ論じ合っているのですか。</span>
<span className="v" id="v9" data-v="9" data-xref="マタイの福音書 14:17–21; ヨハネの福音書 6:9–13; ルカの福音書 9:13–17"> まだわからないのですか、覚えていないのですか。五つのパンを五千人に分けてあげて、なお幾かご集めましたか。</span>
<span className="v" id="v10" data-v="10" data-xref="マタイの福音書 15:34–38; マルコの福音書 8:17–21; マルコの福音書 8:5–9"> また、七つのパンを四千人に分けてあげて、なお幾かご集めましたか。</span>
<span className="v" id="v11" data-v="11" data-xref="マタイの福音書 16:6; ルカの福音書 12:56; マルコの福音書 8:21"> わたしの言ったのは、パンのことなどではないことが、どうしてあなたがたには、わからないのですか。ただ、パリサイ人やサドカイ人たちのパン種に気をつけることです。」</span>
<span className="v" id="v12" data-v="12" data-xref="マタイの福音書 5:20; 使徒の働き 23:8; マタイの福音書 15:4–9"> 彼らはようやく、イエスが気をつけよと言われたのは、パン種のことではなくて、パリサイ人やサドカイ人たちの教えのことであることを悟った。</span>
<span className="v" id="v13" data-v="13" data-xref="ルカの福音書 9:18–20; マルコの福音書 8:27–29; Daniel 7:13"> さて、ピリポ・カイザリヤの地方に行かれたとき、イエスは弟子たちに尋ねて言われた。「人々は人の子をだれだと言っていますか。」</span>
<span className="v" id="v14" data-v="14" data-xref="マルコの福音書 6:15; マタイの福音書 14:2; Malachi 4:5"> 彼らは言った。「バプテスマのヨハネだと言う人もあり、エリヤだと言う人もあります。またほかの人たちはエレミヤだとか、また預言者のひとりだとも言っています。」</span>
<span className="v" id="v15" data-v="15" data-xref="ルカの福音書 9:20; マタイの福音書 13:11; マルコの福音書 8:29"> イエスは彼らに言われた。「あなたがたは、わたしをだれだと言いますか。」</span>
<span className="v" id="v16" data-v="16" data-xref="マタイの福音書 14:33; ヨハネの福音書 11:27; ヨハネの手紙第一 4:15"> シモン・ペテロが答えて言った。「あなたは、生ける神の御子キリストです。」</span>
<span className="v" id="v17" data-v="17" data-xref="ヨハネの福音書 6:45; エペソ人への手紙 1:17–18; マタイの福音書 11:25–27"> するとイエスは、彼に答えて言われた。「バルヨナ・シモン。あなたは幸いです。このことをあなたに明らかに示したのは人間ではなく、天にいますわたしの父です。</span>
<span className="v" id="v18" data-v="18" data-xref="エペソ人への手紙 2:19–22; コリント人への手紙第一 3:9–11; Isaiah 28:16"> ではわたしもあなたに言います。あなたはペテロです。わたしはこの岩の上にわたしの教会を建てます。ハデスの門もそれには打ち勝てません。</span>
<span className="v" id="v19" data-v="19" data-xref="マタイの福音書 18:18; Isaiah 22:22; ヨハネの黙示録 1:18"> わたしは、あなたに天の御国のかぎを上げます。何でもあなたが地上でつなぐなら、それは天においてもつながれており、あなたが地上で解くなら、それは天においても解かれています。」</span>
<span className="v" id="v20" data-v="20" data-xref="マルコの福音書 8:30; ルカの福音書 9:21; ヨハネの福音書 1:41"> そのとき、イエスは、ご自分がキリストであることをだれにも言ってはならない、と弟子たちを戒められた。</span>
<span className="v" id="v21" data-v="21" data-xref="ルカの福音書 24:6–7; マタイの福音書 20:17–19; マタイの福音書 17:22–23"> その時から、イエス・キリストは、ご自分がエルサレムに行って、長老、祭司長、律法学者たちから多くの苦しみを受け、殺され、そして三日目によみがえらなければならないことを弟子たちに示し始められた。</span>
<span className="v" id="v22" data-v="22" data-xref="マルコの福音書 8:32; ヨハネの福音書 13:6–8; マタイの福音書 16:16–17"> するとペテロは、イエスを引き寄せて、いさめ始めた。「主よ。神の御恵みがありますように。そんなことが、あなたに起こるはずはありません。」</span>
<span className="v" id="v23" data-v="23" data-xref="ローマ人への手紙 8:5–8; コロサイ人への手紙 3:2; ピリピ人への手紙 3:19"> しかし、イエスは振り向いて、ペテロに言われた。「下がれ。サタン。あなたはわたしの邪魔をするものだ。あなたは神のことを思わないで、人のことを思っている。」</span>
<span className="v" id="v24" data-v="24" data-xref="マタイの福音書 10:38; ルカの福音書 14:27; ペテロの手紙第一 4:1–2"> それから、イエスは弟子たちに言われた。「だれでもわたしについて来たいと思うなら、自分を捨て、自分の十字架を負い、そしてわたしについて来なさい。</span>
<span className="v" id="v25" data-v="25" data-xref="マタイの福音書 10:39; マルコの福音書 8:35; ヨハネの黙示録 12:11"> いのちを救おうと思う者はそれを失い、わたしのためにいのちを失う者は、それを見いだすのです。</span>
<span className="v" id="v26" data-v="26" data-xref="マルコの福音書 8:36–37; Job 27:8; ルカの福音書 9:25"> 人は、たとい全世界を手に入れても、まことのいのちを損じたら、何の得がありましょう。そのいのちを買い戻すのには、人はいったい何を差し出せばよいでしょう。</span>
<span className="v" id="v27" data-v="27" data-xref="コリント人への手紙第二 5:10; Psalms 62:12; ローマ人への手紙 2:6"> 人の子は父の栄光を帯びて、御使いたちとともに、やがて来ようとしているのです。その時には、おのおのその行ないに応じて報いをします。</span>
<span className="v" id="v28" data-v="28" data-xref="ルカの福音書 9:27; マルコの福音書 9:1; ヨハネの福音書 8:52"> まことに、あなたがたに告げます。ここに立っている人々の中には、人の子が御国とともに来るのを見るまでは、決して死を味わわない人々がいます。」</span>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マタイの福音書 4:13; ルカの福音書 8:37; マタイの福音書 8:18"> イエスは舟に乗って湖を渡り、自分の町に帰られた。</span>
<span className="v" id="v2" data-v="2" data-xref="マルコの福音書 2:1–12; ルカの福音書 5:18–26; Jeremiah 31:33–34"> すると、人々が中風の人を床に寝かせたままで、みもとに運んで来た。イエスは彼らの信仰を見て、中風の人に、「子よ。しっかりしなさい。あなたの罪は赦された。」と言われた。</span>
<span className="v" id="v3" data-v="3" data-xref="マタイの福音書 26:65; ルカの福音書 5:21; Leviticus 24:16"> すると、律法学者たちは、心の中で、「この人は神をけがしている。」と言った。</span>
<span className="v" id="v4" data-v="4" data-xref="ルカの福音書 6:8; マタイの福音書 12:25; ヨハネの黙示録 2:23"> イエスは彼らの心の思いを知って言われた。「なぜ、心の中で悪いことを考えているのか。</span>
<span className="v" id="v5" data-v="5" data-xref="ヨハネの福音書 5:8–14; マルコの福音書 2:9–12; 使徒の働き 3:16"> 『あなたの罪は赦された。』と言うのと、『起きて歩け。』と言うのと、どちらがやさしいか。</span>
<span className="v" id="v6" data-v="6" data-xref="Isaiah 43:25; マタイの福音書 9:5; ヨハネの福音書 20:21–23"> 人の子が地上で罪を赦す権威を持っていることを、あなたがたに知らせるために。」こう言って、それから中風の人に、「起きなさい。寝床をたたんで、家に帰りなさい。」と言われた。</span>
<span className="v" id="v7" data-v="7"> すると、彼は起きて家に帰った。</span>
<span className="v" id="v8" data-v="8" data-xref="ルカの福音書 7:16; マタイの福音書 15:31; 使徒の働き 4:21"> 群衆はそれを見て恐ろしくなり、こんな権威を人にお与えになった神をあがめた。</span>
<span className="v" id="v9" data-v="9" data-xref="ルカの福音書 5:27–38; マルコの福音書 2:14–22; ルカの福音書 19:2–10"> イエスは、そこを去って道を通りながら、収税所にすわっているマタイという人をご覧になって、「わたしについて来なさい。」と言われた。すると彼は立ち上がって、イエスに従った。</span>
<span className="v" id="v10" data-v="10" data-xref="テモテへの手紙第一 1:13–16; ルカの福音書 5:29–32; マルコの福音書 2:15–17"> イエスが家で食事の席に着いておられるとき、見よ、取税人や罪人が大ぜい来て、イエスやその弟子たちといっしょに食卓に着いていた。</span>
<span className="v" id="v11" data-v="11" data-xref="マタイの福音書 11:19; ルカの福音書 5:30; マルコの福音書 2:16"> すると、これを見たパリサイ人たちが、イエスの弟子たちに言った。「なぜ、あなたがたの先生は、取税人や罪人といっしょに食事をするのですか。」</span>
<span className="v" id="v12" data-v="12" data-xref="ルカの福音書 5:31; ヨハネの黙示録 3:17–18; マルコの福音書 2:17"> イエスはこれを聞いて言われた。「医者を必要とするのは丈夫な者ではなく、病人です。</span>
<span className="v" id="v13" data-v="13" data-xref="マルコの福音書 2:17; ルカの福音書 19:10; Hosea 6:6"> 『わたしはあわれみは好むが、いけにえは好まない。』とはどういう意味か、行って学んで来なさい。わたしは正しい人を招くためではなく、罪人を招くために来たのです。」</span>
<span className="v" id="v14" data-v="14" data-xref="ルカの福音書 5:33–39; マルコの福音書 2:18–22; マタイの福音書 6:16"> するとまた、ヨハネの弟子たちが、イエスのところに来てこう言った。「私たちとパリサイ人は断食するのに、なぜ、あなたの弟子たちは断食しないのですか。」</span>
<span className="v" id="v15" data-v="15" data-xref="ヨハネの黙示録 19:9; ヨハネの福音書 3:29; ヨハネの黙示録 21:2"> イエスは彼らに言われた。「花婿につき添う友だちは、花婿がいっしょにいる間は、どうして悲しんだりできましょう。しかし、花婿が取り去られる時が来ます。そのときには断食します。</span>
<span className="v" id="v16" data-v="16" data-xref="コリント人への手紙第一 3:1–2; ヨハネの福音書 16:12; Psalms 125:3"> だれも、真新しい布切れで古い着物の継ぎをするようなことはしません。そんな継ぎ切れは着物を引き破って、破れがもっとひどくなるからです。</span>
<span className="v" id="v17" data-v="17" data-xref="Joshua 9:4; Job 32:19; Psalms 119:83"> また、人は新しいぶどう酒を古い皮袋に入れるようなことはしません。そんなことをすれば、皮袋は裂けて、ぶどう酒が流れ出てしまい、皮袋もだめになってしまいます。新しいぶどう酒を新しい皮袋に入れれば、両方とも保ちます。」</span>
<span className="v" id="v18" data-v="18" data-xref="ルカの福音書 8:41–56; マルコの福音書 5:22–43; マタイの福音書 8:2"> イエスがこれらのことを話しておられると、見よ、ひとりの会堂管理者が来て、ひれ伏して言った。「私の娘がいま死にました。でも、おいでくださって、娘の上に御手を置いてやってください。そうすれば娘は生き返ります。」</span>
<span className="v" id="v19" data-v="19" data-xref="使徒の働き 10:38; ガラテヤ人への手紙 6:9–10; マタイの福音書 8:7"> イエスが立って彼について行かれると、弟子たちもついて行った。</span>
<span className="v" id="v20" data-v="20" data-xref="ルカの福音書 8:43–56; マタイの福音書 14:36; マルコの福音書 6:56"> すると、見よ。十二年の間長血をわずらっている女が、イエスのうしろに来て、その着物のふさにさわった。</span>
<span className="v" id="v21" data-v="21" data-xref="マルコの福音書 5:26–33; ルカの福音書 8:45–47; 使徒の働き 19:12"> 「お着物にさわることでもできれば、きっと直る。」と心のうちで考えていたからである。</span>
<span className="v" id="v22" data-v="22" data-xref="ルカの福音書 7:50; マタイの福音書 15:28; マタイの福音書 9:2"> イエスは、振り向いて彼女を見て言われた。「娘よ。しっかりしなさい。あなたの信仰があなたを直したのです。」すると、女はその時から全く直った。</span>
<span className="v" id="v23" data-v="23" data-xref="2 Chronicles 35:25; マルコの福音書 5:35–40; ルカの福音書 8:49–51"> イエスはその管理者の家に来られて、笛吹く者たちや騒いでいる群衆を見て、</span>
<span className="v" id="v24" data-v="24" data-xref="使徒の働き 20:10; ヨハネの福音書 11:11–13; マタイの福音書 27:39–43"> 言われた。「あちらに行きなさい。その子は死んだのではない。眠っているのです。」すると、彼らはイエスをあざ笑った。</span>
<span className="v" id="v25" data-v="25" data-xref="マルコの福音書 9:27; マルコの福音書 5:41; ルカの福音書 8:54"> イエスは群衆を外に出してから、うちにおはいりになり、少女の手を取られた。すると少女は起き上がった。</span>
<span className="v" id="v26" data-v="26" data-xref="マタイの福音書 4:24; マタイの福音書 14:1–2; マルコの福音書 1:45"> このうわさはその地方全体に広まった。</span>
<span className="v" id="v27" data-v="27" data-xref="マタイの福音書 15:22; マタイの福音書 20:30–31; マルコの福音書 10:46–48"> イエスがそこを出て、道を通って行かれると、ふたりの盲人が大声で、「ダビデの子よ。私たちをあわれんでください。」と叫びながらついて来た。</span>
<span className="v" id="v28" data-v="28" data-xref="マルコの福音書 9:23–24; マタイの福音書 13:58; マタイの福音書 8:2"> 家にはいられると、その盲人たちはみもとにやって来た。イエスが「わたしにそんなことができると信じるのか。」と言われると、彼らは「そうです。主よ。」と言った。</span>
<span className="v" id="v29" data-v="29" data-xref="マタイの福音書 15:28; マルコの福音書 10:52; マタイの福音書 8:13"> そこで、イエスは彼らの目にさわって、「あなたがたの信仰のとおりになれ。」と言われた。</span>
<span className="v" id="v30" data-v="30" data-xref="マタイの福音書 8:4; ルカの福音書 5:14; マタイの福音書 17:9"> すると、彼らの目があいた。イエスは彼らをきびしく戒めて、「決してだれにも知られないように気をつけなさい。」と言われた。</span>
<span className="v" id="v31" data-v="31" data-xref="マルコの福音書 7:36; マタイの福音書 9:26; マルコの福音書 1:44–45"> ところが、彼らは出て行って、イエスのことをその地方全体に言いふらした。</span>
<span className="v" id="v32" data-v="32" data-xref="マタイの福音書 4:24; マタイの福音書 12:22–24; ルカの福音書 11:14"> この人たちが出て行くと、見よ、悪霊につかれたおしが、みもとに連れて来られた。</span>
<span className="v" id="v33" data-v="33" data-xref="Isaiah 35:6; マルコの福音書 7:32–37; Exodus 4:11–12"> 悪霊が追い出されると、そのおしはものを言った。群衆は驚いて、「こんなことは、イスラエルでいまだかつて見たことがない。」と言った。</span>
<span className="v" id="v34" data-v="34" data-xref="ルカの福音書 11:15; マルコの福音書 3:22; マタイの福音書 12:23–24"> しかし、パリサイ人たちは、「彼は悪霊どものかしらを使って、悪霊どもを追い出しているのだ。」と言った。</span>
<span className="v" id="v35" data-v="35" data-xref="マタイの福音書 4:23–24; 使徒の働き 10:38; マルコの福音書 6:56"> それから、イエスは、すべての町や村を巡って、会堂で教え、御国の福音を宣べ伝え、あらゆる病気、あらゆるわずらいを直された。</span>
<span className="v" id="v36" data-v="36" data-xref="マルコの福音書 6:34; Numbers 27:17; Jeremiah 50:6"> また、群衆を見て、羊飼いのない羊のように弱り果てて倒れている彼らをかわいそうに思われた。</span>
<span className="v" id="v37" data-v="37" data-xref="ルカの福音書 10:2; マルコの福音書 16:15; コリント人への手紙第一 3:9"> そのとき、弟子たちに言われた。「収穫は多いが、働き手が少ない。</span>
<span className="v" id="v38" data-v="38" data-xref="ルカの福音書 10:1–2; Jeremiah 3:15; テサロニケ人への手紙第二 3:1"> だから、収穫の主に、収穫のために働き手を送ってくださるように祈りなさい。」</span>

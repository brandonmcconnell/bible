<span className="v" id="v1" data-v="1" data-xref="Zephaniah 3:8; Jeremiah 10:25; ヨハネの黙示録 15:1"> また、私は、大きな声が聖所から出て、七人の御使いに言うのを聞いた。「行って、神の激しい怒りの七つの鉢を、地に向けてぶちまけよ。」</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネの黙示録 8:7; ヨハネの黙示録 16:11; ヨハネの黙示録 13:15–18"> そこで、第一の御使いが出て行き、鉢を地に向けてぶちまけた。すると、獣の刻印を受けている人々と、獣の像を拝む人々に、ひどい悪性のはれものができた。</span>
<span className="v" id="v3" data-v="3" data-xref="Exodus 7:17–21; ヨハネの黙示録 8:8–9; ヨハネの黙示録 11:6"> 第二の御使いが鉢を海にぶちまけた。すると、海は死者の血のような血になった。海の中のいのちのあるものは、みな死んだ。</span>
<span className="v" id="v4" data-v="4" data-xref="Exodus 7:17–20; ヨハネの黙示録 8:10–11; Hosea 13:15"> 第三の御使いが鉢を川と水の源とにぶちまけた。すると、それらは血になった。</span>
<span className="v" id="v5" data-v="5" data-xref="ヨハネの黙示録 1:8; ヨハネの黙示録 11:17; ヨハネの黙示録 1:4"> また私は、水をつかさどる御使いがこう言うのを聞いた。「常にいまし、昔います聖なる方。あなたは正しい方です。なぜならあなたは、このようなさばきをなさったからです。</span>
<span className="v" id="v6" data-v="6" data-xref="Isaiah 49:26; ヨハネの黙示録 11:18; ヨハネの黙示録 6:10–11"> 彼らは聖徒たちや預言者たちの血を流しましたが、あなたは、その血を彼らに飲ませました。彼らは、そうされるにふさわしい者たちです。」</span>
<span className="v" id="v7" data-v="7" data-xref="ヨハネの黙示録 19:2; ヨハネの黙示録 6:9; ヨハネの黙示録 15:3–4"> また私は、祭壇がこう言うのを聞いた。「しかり。主よ。万物の支配者である神よ。あなたのさばきは真実な、正しいさばきです。」</span>
<span className="v" id="v8" data-v="8" data-xref="使徒の働き 2:20; ヨハネの黙示録 14:18; Jonah 4:8"> 第四の御使いが鉢を太陽に向けてぶちまけた。すると、太陽は火で人々を焼くことを許された。</span>
<span className="v" id="v9" data-v="9" data-xref="ヨハネの黙示録 2:21; ヨハネの黙示録 16:21; ヨハネの黙示録 11:13"> こうして、人々は激しい炎熱によって焼かれた。しかも、彼らは、これらの災害を支配する権威を持つ神の御名に対してけがしごとを言い、悔い改めて神をあがめることをしなかった。</span>
<span className="v" id="v10" data-v="10" data-xref="ヨハネの黙示録 9:2; マタイの福音書 8:12; Isaiah 8:21–22"> 第五の御使いが鉢を獣の座にぶちまけた。すると、獣の国は暗くなり、人々は苦しみのあまり舌をかんだ。</span>
<span className="v" id="v11" data-v="11" data-xref="ヨハネの黙示録 16:9; ヨハネの黙示録 16:2; ヨハネの黙示録 16:21"> そして、その苦しみと、はれものとのゆえに、天の神に対してけがしごとを言い、自分の行ないを悔い改めようとしなかった。</span>
<span className="v" id="v12" data-v="12" data-xref="ヨハネの黙示録 9:14; Jeremiah 51:36; Isaiah 44:27"> 第六の御使いが鉢を大ユーフラテス川にぶちまけた。すると、水は、日の出るほうから来る王たちに道を備えるために、かれてしまった。</span>
<span className="v" id="v13" data-v="13" data-xref="ヨハネの黙示録 19:20; テサロニケ人への手紙第二 2:9–11; ヨハネの黙示録 20:10"> また、私は竜の口と、獣の口と、にせ預言者の口とから、かえるのような汚れた霊どもが三つ出て来るのを見た。</span>
<span className="v" id="v14" data-v="14" data-xref="ヨハネの黙示録 17:14; テモテへの手紙第一 4:1; ヨハネの黙示録 20:8"> 彼らはしるしを行なう悪霊どもの霊である。彼らは全世界の王たちのところに出て行く。万物の支配者である神の大いなる日の戦いに備えて、彼らを集めるためである。</span>
<span className="v" id="v15" data-v="15" data-xref="テサロニケ人への手紙第一 5:2–3; マタイの福音書 24:42–43; ペテロの手紙第二 3:10"> ――見よ。わたしは盗人のように来る。目をさまして、身に着物を着け、裸で歩く恥を人に見られないようにする者は幸いである。――</span>
<span className="v" id="v16" data-v="16" data-xref="Zechariah 12:11; Judges 5:19; Joel 3:9–14"> こうして彼らは、ヘブル語でハルマゲドンと呼ばれる所に王たちを集めた。</span>
<span className="v" id="v17" data-v="17" data-xref="ヨハネの福音書 19:30; ヨハネの黙示録 21:6; エペソ人への手紙 6:12"> 第七の御使いが鉢を空中にぶちまけた。すると、大きな声が御座を出て、聖所の中から出て来て、「事は成就した。」と言った。</span>
<span className="v" id="v18" data-v="18" data-xref="Daniel 12:1; ヨハネの黙示録 4:5; ヨハネの黙示録 11:19"> すると、いなずまと声と雷鳴があり、大きな地震があった。この地震は人間が地上に住んで以来、かつてなかったほどのもので、それほどに大きな、強い地震であった。</span>
<span className="v" id="v19" data-v="19" data-xref="ヨハネの黙示録 18:5; ヨハネの黙示録 17:18; ヨハネの黙示録 18:21"> また、あの大きな都は三つに裂かれ、諸国の民の町々は倒れた。そして、大バビロンは、神の前に覚えられて、神の激しい怒りのぶどう酒の杯を与えられた。</span>
<span className="v" id="v20" data-v="20" data-xref="ヨハネの黙示録 6:14; ヨハネの黙示録 20:11; Jeremiah 4:23–25"> 島はすべて逃げ去り、山々は見えなくなった。</span>
<span className="v" id="v21" data-v="21" data-xref="ヨハネの黙示録 11:19; Joshua 10:11; ヨハネの黙示録 16:9"> また、一タラントほどの大きな雹が、人々の上に天から降って来た。人々は、この雹の災害のため、神にけがしごとを言った。その災害が非常に激しかったからである。</span>

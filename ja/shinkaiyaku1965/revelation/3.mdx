<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="テモテへの手紙第一 5:6; ヤコブの手紙 2:26; ヨハネの黙示録 1:4"> また、サルデスにある教会の御使いに書き送れ。『神の七つの御霊、および七つの星を持つ方がこう言われる。「わたしは、あなたの行ないを知っている。あなたは、生きているとされているが、実は死んでいる。</span>
<span className="v" id="v2" data-v="2" data-xref="ペテロの手紙第一 5:8; テモテへの手紙第二 4:1–4; ヨハネの黙示録 16:15"> 目をさましなさい。そして死にかけているほかの人たちを力づけなさい。わたしは、あなたの行ないが、わたしの神の御前に全うされたとは見ていない。</span>
<span className="v" id="v3" data-v="3" data-xref="ヨハネの黙示録 2:5; ペテロの手紙第二 3:10; テサロニケ人への手紙第一 5:2"> だから、あなたがどのように受け、また聞いたのかを思い出しなさい。それを堅く守り、また悔い改めなさい。もし、目をさまさなければ、わたしは盗人のように来る。あなたには、わたしがいつあなたのところに来るか、決してわからない。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネの黙示録 3:5; ヨハネの黙示録 7:9; Ecclesiastes 9:8"> しかし、サルデスには、その衣を汚さなかった者が幾人かいる。彼らは白い衣を着て、わたしとともに歩む。彼らはそれにふさわしい者だからである。</span>
<span className="v" id="v5" data-v="5" data-xref="マタイの福音書 10:32; ルカの福音書 12:8; ヨハネの黙示録 21:27"> 勝利を得る者は、このように白い衣を着せられる。そして、わたしは、彼の名をいのちの書から消すようなことは決してしない。わたしは彼の名をわたしの父の御前と御使いたちの前で言い表わす。</span>
<span className="v" id="v6" data-v="6" data-xref="ヨハネの黙示録 2:7"> 耳のある者は御霊が諸教会に言われることを聞きなさい。」』</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="Isaiah 22:22; マタイの福音書 16:19; ヨハネの黙示録 1:18"> また、フィラデルフィヤにある教会の御使いに書き送れ。<br />『聖なる方、真実な方、ダビデのかぎを持っている方、彼が開くとだれも閉じる者がなく、彼が閉じるとだれも開く者がない、その方がこう言われる。</span>
<span className="v" id="v8" data-v="8" data-xref="コリント人への手紙第一 16:9; コロサイ人への手紙 4:3; ヨハネの黙示録 3:7"> 「わたしは、あなたの行ないを知っている。見よ。わたしは、だれも閉じることのできない門を、あなたの前に開いておいた。なぜなら、あなたには少しばかりの力があって、わたしのことばを守り、わたしの名を否まなかったからである。</span>
<span className="v" id="v9" data-v="9" data-xref="Isaiah 60:14; ヨハネの黙示録 2:9; Isaiah 49:23"> 見よ。サタンの会衆に属する者、すなわち、ユダヤ人だと自称しながら実はそうでなくて、うそを言っている者たちに、わたしはこうする。見よ。彼らをあなたの足もとに来てひれ伏させ、わたしがあなたを愛していることを知らせる。</span>
<span className="v" id="v10" data-v="10" data-xref="ペテロの手紙第二 2:9; ヨハネの黙示録 14:12; Zechariah 13:9"> あなたが、わたしの忍耐について言ったことばを守ったから、わたしも、地上に住む者たちを試みるために、全世界に来ようとしている試練の時には、あなたを守ろう。</span>
<span className="v" id="v11" data-v="11" data-xref="ヤコブの手紙 1:12; ヨハネの黙示録 22:12; ヨハネの黙示録 2:10"> わたしは、すぐに来る。あなたの冠をだれにも奪われないように、あなたの持っているものをしっかりと持っていなさい。</span>
<span className="v" id="v12" data-v="12" data-xref="ヨハネの黙示録 22:4; ヨハネの黙示録 21:2; ヨハネの黙示録 14:1"> 勝利を得る者を、わたしの神の聖所の柱としよう。彼はもはや決して外に出て行くことはない。わたしは彼の上にわたしの神の御名と、わたしの神の都、すなわち、わたしの神のもとを出て天から下って来る新しいエルサレムの名と、わたしの新しい名とを書きしるす。</span>
<span className="v" id="v13" data-v="13" data-xref="ヨハネの黙示録 2:7"> 耳のある者は御霊が諸教会に言われることを聞きなさい。」』</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="コロサイ人への手紙 1:15; ヨハネの黙示録 1:5; コリント人への手紙第二 1:20"> また、ラオデキヤにある教会の御使いに書き送れ。『アーメンである方、忠実で、真実な証人、神に造られたものの根源である方がこう言われる。</span>
<span className="v" id="v15" data-v="15" data-xref="ローマ人への手紙 12:11; マタイの福音書 6:24; 1 Kings 18:21"> 「わたしは、あなたの行ないを知っている。あなたは、冷たくもなく、熱くもない。わたしはむしろ、あなたが冷たいか、熱いかであってほしい。</span>
<span className="v" id="v16" data-v="16" data-xref="ヨハネの黙示録 2:5; Zechariah 11:8–9; Jeremiah 14:19"> このように、あなたはなまぬるく、熱くも冷たくもないので、わたしの口からあなたを吐き出そう。</span>
<span className="v" id="v17" data-v="17" data-xref="Proverbs 13:7; Hosea 12:8; ローマ人への手紙 7:24"> あなたは、自分は富んでいる、豊かになった、乏しいものは何もないと言って、実は自分がみじめで、哀れで、貧しくて、盲目で、裸の者であることを知らない。</span>
<span className="v" id="v18" data-v="18" data-xref="ヨハネの黙示録 16:15; ペテロの手紙第一 1:7; Isaiah 55:1"> わたしはあなたに忠告する。豊かな者となるために、火で精練された金をわたしから買いなさい。また、あなたの裸の恥を現わさないために着る白い衣を買いなさい。また、目が見えるようになるため、目に塗る目薬を買いなさい。</span>
<span className="v" id="v19" data-v="19" data-xref="Proverbs 3:11–12; コリント人への手紙第一 11:32; ヘブル人への手紙 12:5–11"> わたしは、愛する者をしかったり、懲らしめたりする。だから、熱心になって、悔い改めなさい。</span>
<span className="v" id="v20" data-v="20" data-xref="ルカの福音書 12:36–37; ヨハネの黙示録 19:9; ヨハネの福音書 14:21–23"> 見よ。わたしは、戸の外に立ってたたく。だれでも、わたしの声を聞いて戸をあけるなら、わたしは、彼のところにはいって、彼とともに食事をし、彼もわたしとともに食事をする。</span>
<span className="v" id="v21" data-v="21" data-xref="テモテへの手紙第二 2:12; マタイの福音書 19:28; ヨハネの黙示録 2:26–27"> 勝利を得る者を、わたしとともにわたしの座に着かせよう。それは、わたしが勝利を得て、わたしの父とともに父の御座に着いたのと同じである。</span>
<span className="v" id="v22" data-v="22" data-xref="ヨハネの黙示録 2:7; ヨハネの黙示録 2:11; ヨハネの黙示録 2:17"> 耳のある者は御霊が諸教会に言われることを聞きなさい。」』」</span>
</div>

<span className="v" id="v1" data-v="1" data-xref="Isaiah 65:17–19; ペテロの手紙第二 3:13; Isaiah 66:22"> また私は、新しい天と新しい地とを見た。以前の天と、以前の地は過ぎ去り、もはや海もない。</span>
<span className="v" id="v2" data-v="2" data-xref="ヘブル人への手紙 11:10; ヨハネの黙示録 3:12; ヨハネの黙示録 21:10"> 私はまた、聖なる都、新しいエルサレムが、夫のために飾られた花嫁のように整えられて、神のみもとを出て、天から下って来るのを見た。</span>
<span className="v" id="v3" data-v="3" data-xref="Ezekiel 37:27; コリント人への手紙第二 6:16; ヨハネの福音書 14:23"> そのとき私は、御座から出る大きな声がこう言うのを聞いた。「見よ。神の幕屋が人とともにある。神は彼らとともに住み、彼らはその民となる。また、神ご自身が彼らとともにおられて、</span>
<span className="v" id="v4" data-v="4" data-xref="Isaiah 25:8; ヨハネの黙示録 7:17; コリント人への手紙第一 15:26"> 彼らの目の涙をすっかりぬぐい取ってくださる。もはや死もなく、悲しみ、叫び、苦しみもない。なぜなら、以前のものが、もはや過ぎ去ったからである。」</span>
<span className="v" id="v5" data-v="5" data-xref="コリント人への手紙第二 5:17; Isaiah 42:9; Isaiah 43:19"> すると、御座に着いておられる方が言われた。「見よ。わたしは、すべてを新しくする。」また言われた。「書きしるせ。これらのことばは、信ずべきものであり、真実である。」</span>
<span className="v" id="v6" data-v="6" data-xref="ヨハネの福音書 7:37–38; ヨハネの福音書 4:10; ヨハネの黙示録 7:17"> また言われた。「事は成就した。わたしはアルファであり、オメガである。最初であり、最後である。わたしは、渇く者には、いのちの水の泉から、価なしに飲ませる。</span>
<span className="v" id="v7" data-v="7" data-xref="コリント人への手紙第二 6:18; ヘブル人への手紙 8:10; ヨハネの黙示録 2:11"> 勝利を得る者は、これらのものを相続する。わたしは彼の神となり、彼はわたしの子となる。</span>
<span className="v" id="v8" data-v="8" data-xref="コリント人への手紙第一 6:9–10; ヨハネの黙示録 2:11; エペソ人への手紙 5:5–6"> しかし、おくびょう者、不信仰の者、憎むべき者、人を殺す者、不品行の者、魔術を行なう者、偶像を拝む者、すべて偽りを言う者どもの受ける分は、火と硫黄との燃える池の中にある。これが第二の死である。」</span>
<span className="v" id="v9" data-v="9" data-xref="ヨハネの黙示録 21:2; ヨハネの黙示録 19:7; ヨハネの黙示録 16:1–17"> また、最後の七つの災害の満ちているあの七つの鉢を持っていた七人の御使いのひとりが来た。彼は私に話して、こう言った。「ここに来なさい。私はあなたに、小羊の妻である花嫁を見せましょう。」</span>
<span className="v" id="v10" data-v="10" data-xref="ヨハネの黙示録 21:2; Ezekiel 11:24; Ezekiel 40:1–49"> そして、御使いは御霊によって私を大きな高い山に連れて行って、聖なる都エルサレムが神のみもとを出て、天から下って来るのを見せた。</span>
<span className="v" id="v11" data-v="11" data-xref="ヨハネの黙示録 4:6; ヨハネの黙示録 22:5; ヨハネの黙示録 22:1"> 都には神の栄光があった。その輝きは高価な宝石に似ており、透き通った碧玉のようであった。</span>
<span className="v" id="v12" data-v="12" data-xref="Ezekiel 48:31–34; ヨハネの黙示録 7:4–8; ヨハネの黙示録 21:17–21"> 都には大きな高い城壁と十二の門があって、それらの門には十二人の御使いがおり、イスラエルの子らの十二部族の名が書いてあった。</span>
<span className="v" id="v13" data-v="13" data-xref="Ezekiel 48:31–34"> 東に三つの門、北に三つの門、南に三つの門、西に三つの門があった。</span>
<span className="v" id="v14" data-v="14" data-xref="ヘブル人への手紙 11:10; エペソ人への手紙 2:20; Isaiah 54:11"> また、都の城壁には十二の土台石があり、それには、小羊の十二使徒の十二の名が書いてあった。</span>
<span className="v" id="v15" data-v="15" data-xref="Zechariah 2:1; ヨハネの黙示録 11:1–2; Ezekiel 41:1–5"> また、私と話していた者は都とその門とその城壁とを測る金の測りざおを持っていた。</span>
<span className="v" id="v16" data-v="16" data-xref="Ezekiel 48:35; Ezekiel 48:8–20"> 都は四角で、その長さと幅は同じである。彼がそのさおで都を測ると、一万二千スタディオンあった。長さも幅も高さも同じである。</span>
<span className="v" id="v17" data-v="17" data-xref="ヨハネの黙示録 7:4; Deuteronomy 3:11; ヨハネの黙示録 13:18"> また、彼がその城壁を測ると、人間の尺度で百四十四ペーキュスあった。これが御使いの尺度でもあった。</span>
<span className="v" id="v18" data-v="18" data-xref="ヨハネの黙示録 21:11; ヨハネの黙示録 21:21; ヨハネの黙示録 21:19"> その城壁は碧玉で造られ、都は混じりけのないガラスに似た純金でできていた。</span>
<span className="v" id="v19" data-v="19" data-xref="Isaiah 54:11–12; Exodus 28:17–21; Job 28:16–19"> 都の城壁の土台石はあらゆる宝石で飾られていた。第一の土台石は碧玉、第二はサファイヤ、第三は玉髄、第四は緑玉、</span>
<span className="v" id="v20" data-v="20" data-xref="ヨハネの黙示録 4:3"> 第五は赤縞めのう、第六は赤めのう、第七は貴かんらん石、第八は緑柱石、第九は黄玉、第十は緑玉髄、第十一は青玉、第十二は紫水晶であった。</span>
<span className="v" id="v21" data-v="21" data-xref="ヨハネの黙示録 21:18; ヨハネの黙示録 17:4; ヨハネの黙示録 22:2"> また、十二の門は十二の真珠であった。どの門もそれぞれ一つの真珠からできていた。都の大通りは、透き通ったガラスのような純金であった。</span>
<span className="v" id="v22" data-v="22" data-xref="ヨハネの福音書 4:23; 1 Kings 8:27; 2 Chronicles 2:6"> 私は、この都の中に神殿を見なかった。それは、万物の支配者である、神であられる主と、小羊とが都の神殿だからである。</span>
<span className="v" id="v23" data-v="23" data-xref="Isaiah 60:19–20; ヨハネの黙示録 22:5; ヨハネの黙示録 21:11"> 都には、これを照らす太陽も月もいらない。というのは、神の栄光が都を照らし、小羊が都のあかりだからである。</span>
<span className="v" id="v24" data-v="24" data-xref="ヨハネの黙示録 21:26; ヨハネの黙示録 22:2; Zechariah 8:22–23"> 諸国の民が、都の光によって歩み、地の王たちはその栄光を携えて都に来る。</span>
<span className="v" id="v25" data-v="25" data-xref="Isaiah 60:11; Zechariah 14:7; ヨハネの黙示録 22:5"> 都の門は一日中決して閉じることがない。そこには夜がないからである。</span>
<span className="v" id="v26" data-v="26" data-xref="ヨハネの黙示録 21:24"> こうして、人々は諸国の民の栄光と誉れとを、そこに携えて来る。</span>
<span className="v" id="v27" data-v="27" data-xref="ヨハネの黙示録 22:14–15; Isaiah 52:1; ヨハネの黙示録 20:15"> しかし、すべて汚れた者や、憎むべきことと偽りとを行なう者は、決して都にはいれない。小羊のいのちの書に名が書いてある者だけが、はいることができる。</span>

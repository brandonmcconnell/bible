<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ルカの福音書 21:25; エペソ人への手紙 5:32; ルカの福音書 21:11"> また、巨大なしるしが天に現われた。ひとりの女が太陽を着て、月を足の下に踏み、頭には十二の星の冠をかぶっていた。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネの福音書 16:21; ガラテヤ人への手紙 4:19; ヨハネの黙示録 12:4"> この女は、みごもっていたが、産みの苦しみと痛みのために、叫び声をあげた。</span>
<span className="v" id="v3" data-v="3" data-xref="ヨハネの黙示録 17:12; ヨハネの黙示録 12:9; Daniel 7:24"> また、別のしるしが天に現われた。見よ。大きな赤い竜である。七つの頭と十本の角とを持ち、その頭には七つの冠をかぶっていた。</span>
<span className="v" id="v4" data-v="4" data-xref="Daniel 8:9–12; ヨハネの黙示録 12:9; ヨハネの福音書 8:44"> その尾は、天の星の三分の一を引き寄せると、それらを地上に投げた。また、竜は子を産もうとしている女の前に立っていた。彼女が子を産んだとき、その子を食い尽くすためであった。</span>
<span className="v" id="v5" data-v="5" data-xref="ヨハネの黙示録 19:15; ヨハネの黙示録 2:26–27; ヨハネの黙示録 12:2"> 女は男の子を産んだ。この子は、鉄の杖をもって、すべての国々の民を牧するはずである。その子は神のみもと、その御座に引き上げられた。</span>
<span className="v" id="v6" data-v="6" data-xref="ヨハネの黙示録 13:5; ヨハネの黙示録 11:2–3; ヨハネの黙示録 12:14"> 女は荒野に逃げた。そこには、千二百六十日の間彼女を養うために、神によって備えられた場所があった。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="ユダの手紙 1:9; Daniel 12:1; エペソ人への手紙 6:12"> さて、天に戦いが起こって、ミカエルと彼の使いたちは、竜と戦った。それで、竜とその使いたちは応戦したが、</span>
<span className="v" id="v8" data-v="8" data-xref="Psalms 37:10; ヨハネの黙示録 12:11; ユダの手紙 1:6"> 勝つことができず、天にはもはや彼らのいる場所がなくなった。</span>
<span className="v" id="v9" data-v="9" data-xref="ルカの福音書 10:18; ヨハネの福音書 12:31; ヨハネの黙示録 20:10"> こうして、この巨大な竜、すなわち、悪魔とか、サタンとか呼ばれて、全世界を惑わす、あの古い蛇は投げ落とされた。彼は地上に投げ落とされ、彼の使いどもも彼とともに投げ落とされた。</span>
<span className="v" id="v10" data-v="10" data-xref="ルカの福音書 22:31; Zechariah 3:1–2; ヨハネの黙示録 11:15"> そのとき私は、天で大きな声が、こう言うのを聞いた。<br />「今や、私たちの神の救いと力と国と、また、神のキリストの権威が現われた。私たちの兄弟たちの告発者、日夜彼らを私たちの神の御前で訴えている者が投げ落とされたからである。</span>
<span className="v" id="v11" data-v="11" data-xref="コリント人への手紙第二 10:3–5; ヨハネの福音書 16:33; ヨハネの手紙第一 5:5"> 兄弟たちは、小羊の血と、自分たちのあかしのことばのゆえに彼に打ち勝った。彼らは死に至るまでもいのちを惜しまなかった。</span>
<span className="v" id="v12" data-v="12" data-xref="Isaiah 49:13; ヨハネの黙示録 8:13; Psalms 96:11–13"> それゆえ、天とその中に住む者たち。喜びなさい。しかし、地と海とには、わざわいが来る。悪魔が自分の時の短いことを知り、激しく怒って、そこに下ったからである。」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="Genesis 3:15; ヨハネの黙示録 12:3–5; ヨハネの福音書 16:33"> 自分が地上に投げ落とされたのを知った竜は、男の子を産んだ女を追いかけた。</span>
<span className="v" id="v14" data-v="14" data-xref="Exodus 19:4; Isaiah 40:31; ヨハネの黙示録 12:6"> しかし、女は大わしの翼を二つ与えられた。自分の場所である荒野に飛んで行って、そこで一時と二時と半時の間、蛇の前をのがれて養われるためであった。</span>
<span className="v" id="v15" data-v="15" data-xref="Isaiah 8:7; Isaiah 59:19; Psalms 18:4"> ところが、蛇はその口から水を川のように女のうしろへ吐き出し、彼女を大水で押し流そうとした。</span>
<span className="v" id="v16" data-v="16" data-xref="1 Kings 17:6; Exodus 12:35–36; 2 Kings 8:9"> しかし、地は女を助け、その口を開いて、竜が口から吐き出した川を飲み干した。</span>
<span className="v" id="v17" data-v="17" data-xref="ヨハネの黙示録 14:12; Genesis 3:15; ヨハネの黙示録 11:7"> すると、竜は女に対して激しく怒り、女の子孫の残りの者、すなわち、神の戒めを守り、イエスのあかしを保っている者たちと戦おうとして出て行った。</span>
<span className="v" id="v18" data-v="18"> そして、彼は海べの砂の上に立った。</span>
</div>

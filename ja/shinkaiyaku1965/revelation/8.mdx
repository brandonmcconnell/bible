<span className="v" id="v1" data-v="1" data-xref="Zechariah 2:13; Habakkuk 2:20; ヨハネの黙示録 6:1"> 小羊が第七の封印を解いたとき、天に半時間ばかり静けさがあった。</span>
<span className="v" id="v2" data-v="2" data-xref="ルカの福音書 1:19; ヨハネの黙示録 11:15; ヨハネの黙示録 8:6–1"> それから私は、神の御前に立つ七人の御使いを見た。彼らに七つのラッパが与えられた。</span>
<span className="v" id="v3" data-v="3" data-xref="ヨハネの黙示録 5:8; ヨハネの黙示録 8:4; Psalms 141:2"> また、もうひとりの御使いが出て来て、金の香炉を持って祭壇のところに立った。彼にたくさんの香が与えられた。すべての聖徒の祈りとともに、御座の前にある金の祭壇の上にささげるためであった。</span>
<span className="v" id="v4" data-v="4" data-xref="Psalms 141:2; ルカの福音書 1:10; ヨハネの黙示録 8:3"> 香の煙は、聖徒たちの祈りとともに、御使いの手から神の御前に立ち上った。</span>
<span className="v" id="v5" data-v="5" data-xref="ヨハネの黙示録 4:5; ヨハネの黙示録 11:19; Ezekiel 10:2–7"> それから、御使いは、その香炉を取り、祭壇の火でそれを満たしてから、地に投げつけた。すると、雷鳴と声といなずまと地震が起こった。</span>
<span className="v" id="v6" data-v="6" data-xref="ヨハネの黙示録 8:2"> すると、七つのラッパを持っていた七人の御使いはラッパを吹く用意をした。</span>
<span className="v" id="v7" data-v="7" data-xref="Ezekiel 38:22; ヨハネの黙示録 9:4; ヨハネの黙示録 9:18"> 第一の御使いがラッパを吹き鳴らした。すると、血の混じった雹と火とが現われ、地上に投げられた。そして地上の三分の一が焼け、木の三分の一も焼け、青草が全部焼けてしまった。</span>
<span className="v" id="v8" data-v="8" data-xref="Jeremiah 51:25; Exodus 7:17–21; マルコの福音書 11:23"> 第二の御使いがラッパを吹き鳴らした。すると、火の燃えている大きな山のようなものが、海に投げ込まれた。そして海の三分の一が血となった。</span>
<span className="v" id="v9" data-v="9" data-xref="ヨハネの黙示録 16:3; ヨハネの黙示録 8:7; ヨハネの黙示録 8:12"> すると、海の中にいた、いのちのあるものの三分の一が死に、舟の三分の一も打ちこわされた。</span>
<span className="v" id="v10" data-v="10" data-xref="ヨハネの黙示録 16:4; ヨハネの黙示録 9:1; Isaiah 14:12"> 第三の御使いがラッパを吹き鳴らした。すると、たいまつのように燃えている大きな星が天から落ちて来て、川々の三分の一とその水源に落ちた。</span>
<span className="v" id="v11" data-v="11" data-xref="Jeremiah 23:15; Jeremiah 9:15; Deuteronomy 29:18"> この星の名は苦よもぎと呼ばれ、川の水の三分の一は苦よもぎのようになった。水が苦くなったので、その水のために多くの人が死んだ。</span>
<span className="v" id="v12" data-v="12" data-xref="Isaiah 13:10; Joel 2:31; Joel 2:10"> 第四の御使いがラッパを吹き鳴らした。すると、太陽の三分の一と、月の三分の一と、星の三分の一とが打たれたので、三分の一は暗くなり、昼の三分の一は光を失い、また夜も同様であった。</span>
<span className="v" id="v13" data-v="13" data-xref="ヨハネの黙示録 9:12; ヨハネの黙示録 11:14; ヨハネの黙示録 14:6"> また私は見た。一羽のわしが中天を飛びながら、大声で言うのを聞いた。「わざわいが来る。わざわいが、わざわいが来る。地に住む人々に。あと三人の御使いがラッパを吹き鳴らそうとしている。」</span>

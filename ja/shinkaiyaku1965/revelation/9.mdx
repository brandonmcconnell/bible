<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨハネの黙示録 8:10; ローマ人への手紙 10:7; ヨハネの黙示録 9:2"> 第五の御使いがラッパを吹き鳴らした。すると、私は一つの星が天から地上に落ちるのを見た。その星には底知れぬ穴を開くかぎが与えられた。</span>
<span className="v" id="v2" data-v="2" data-xref="Joel 2:10; Genesis 19:28; Joel 2:2"> その星が、底知れぬ穴を開くと、穴から大きな炉の煙のような煙が立ち上り、太陽も空も、この穴の煙によって暗くなった。</span>
<span className="v" id="v3" data-v="3" data-xref="Joel 1:4; ヨハネの黙示録 9:5; Joel 2:25"> その煙の中から、いなごが地上に出て来た。彼らには、地のさそりの持つような力が与えられた。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネの黙示録 7:2–4; Ezekiel 9:4; ヨハネの黙示録 14:1"> そして彼らは、地の草やすべての青草や、すべての木には害を加えないで、ただ、額に神の印を押されていない人間にだけ害を加えるように言い渡された。</span>
<span className="v" id="v5" data-v="5" data-xref="ヨハネの黙示録 9:10; Job 2:6; ヨハネの黙示録 9:3"> しかし、人間を殺すことは許されず、ただ五か月の間苦しめることだけが許された。その与えた苦痛は、さそりが人を刺したときのような苦痛であった。</span>
<span className="v" id="v6" data-v="6" data-xref="ルカの福音書 23:30; Jeremiah 8:3; ヨハネの黙示録 6:16"> その期間には、人々は死を求めるが、どうしても見いだせず、死を願うが、死が彼らから逃げて行くのである。</span>
<span className="v" id="v7" data-v="7" data-xref="Daniel 7:8; Nahum 3:17; Joel 2:4–5"> そのいなごの形は、出陣の用意の整った馬に似ていた。頭に金の冠のようなものを着け、顔は人間の顔のようであった。</span>
<span className="v" id="v8" data-v="8" data-xref="Joel 1:6; コリント人への手紙第一 11:14–15; ペテロの手紙第一 3:3"> また女の髪のような毛があり、歯は、ししの歯のようであった。</span>
<span className="v" id="v9" data-v="9" data-xref="Joel 2:5–8; Nahum 2:4–5; Job 39:25"> また、鉄の胸当てのような胸当てを着け、その翼の音は、多くの馬に引かれた戦車が、戦いに馳せつけるときの響きのようであった。</span>
<span className="v" id="v10" data-v="10" data-xref="ヨハネの黙示録 9:5; ヨハネの黙示録 9:3; ヨハネの黙示録 9:19"> そのうえ彼らは、さそりのような尾と針とを持っており、尾には、五か月間人間に害を加える力があった。</span>
<span className="v" id="v11" data-v="11" data-xref="Job 26:6; ヨハネの黙示録 9:1–2; エペソ人への手紙 2:2"> 彼らは、底知れぬ所の御使いを王にいただいている。彼の名はヘブル語でアバドンといい、ギリシヤ語でアポリュオンという。</span>
<span className="v" id="v12" data-v="12" data-xref="ヨハネの黙示録 11:14; ヨハネの黙示録 8:13–2; ヨハネの黙示録 9:13–21"> 第一のわざわいは過ぎ去った。見よ。この後なお二つのわざわいが来る。</span>
<span className="v" id="v13" data-v="13" data-xref="ヨハネの黙示録 8:3–5; Exodus 30:2–3; ヨハネの黙示録 9:1"> 第六の御使いがラッパを吹き鳴らした。すると、私は神の御前にある金の祭壇の四隅から出る声を聞いた。</span>
<span className="v" id="v14" data-v="14" data-xref="ヨハネの黙示録 16:12; ヨハネの黙示録 9:15; 2 Samuel 8:3"> その声がラッパを持っている第六の御使いに言った。「大川ユーフラテスのほとりにつながれている四人の御使いを解き放せ。」</span>
<span className="v" id="v15" data-v="15" data-xref="ヨハネの黙示録 9:18; ヨハネの黙示録 8:7; ヨハネの黙示録 8:9"> すると、定められた時、日、月、年のために用意されていた四人の御使いが、人類の三分の一を殺すために解き放された。</span>
<span className="v" id="v16" data-v="16" data-xref="ヨハネの黙示録 7:4; Psalms 68:17; Daniel 7:10"> 騎兵の軍勢の数は二億であった。私はその数を聞いた。</span>
<span className="v" id="v17" data-v="17" data-xref="ヨハネの黙示録 9:18; ヨハネの黙示録 14:10; 1 Chronicles 12:8"> 私が幻の中で見た馬とそれに乗る人たちの様子はこうであった。騎兵は、火のような赤、くすぶった青、燃える硫黄の色の胸当てを着けており、馬の頭は、ししの頭のようで、口からは火と煙と硫黄とが出ていた。</span>
<span className="v" id="v18" data-v="18" data-xref="ヨハネの黙示録 9:17; ヨハネの黙示録 9:15"> これらの三つの災害、すなわち、彼らの口から出ている火と煙と硫黄とのために、人類の三分の一は殺された。</span>
<span className="v" id="v19" data-v="19" data-xref="Isaiah 9:15; ヨハネの黙示録 9:10; エペソ人への手紙 4:14"> 馬の力はその口とその尾とにあって、その尾は蛇のようであり、それに頭があって、その頭で害を加えるのである。</span>
<span className="v" id="v20" data-v="20" data-xref="Daniel 5:23; Deuteronomy 31:29; テモテへの手紙第一 4:1"> これらの災害によって殺されずに残った人々は、その手のわざを悔い改めないで、悪霊どもや、金、銀、銅、石、木で造られた、見ることも聞くことも歩くこともできない偶像を拝み続け、</span>
<span className="v" id="v21" data-v="21" data-xref="ヨハネの黙示録 21:8; コリント人への手紙第二 12:21; ヨハネの黙示録 17:5"> その殺人や、魔術や、不品行や、盗みを悔い改めなかった。</span>

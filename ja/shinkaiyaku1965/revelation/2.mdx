<span className="v" id="v1" data-v="1" data-xref="ヨハネの黙示録 1:20; ヨハネの黙示録 1:16; ヨハネの黙示録 1:11–13"> エペソにある教会の御使いに書き送れ。『右手に七つの星を持つ方、七つの金の燭台の間を歩く方が言われる。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネの手紙第一 4:1; ペテロの手紙第二 2:1–3; テサロニケ人への手紙第一 5:21"> 「わたしは、あなたの行ないとあなたの労苦と忍耐を知っている。また、あなたが、悪い者たちをがまんすることができず、使徒と自称しているが実はそうでない者たちをためして、その偽りを見抜いたことも知っている。</span>
<span className="v" id="v3" data-v="3" data-xref="ヘブル人への手紙 10:36; ガラテヤ人への手紙 6:9; ヤコブの手紙 5:7–11"> あなたはよく忍耐して、わたしの名のために耐え忍び、疲れたことがなかった。</span>
<span className="v" id="v4" data-v="4" data-xref="マタイの福音書 24:12–13; Jeremiah 2:2–5; ヘブル人への手紙 6:10–11"> しかし、あなたには非難すべきことがある。あなたは初めの愛から離れてしまった。</span>
<span className="v" id="v5" data-v="5" data-xref="ヨハネの黙示録 3:2–3; ヨハネの黙示録 3:19; ヨハネの黙示録 2:16"> それで、あなたは、どこから落ちたかを思い出し、悔い改めて、初めの行ないをしなさい。もしそうでなく、悔い改めることをしないならば、わたしは、あなたのところに行って、あなたの燭台をその置かれた所から取りはずしてしまおう。</span>
<span className="v" id="v6" data-v="6" data-xref="Psalms 101:3; ヨハネの手紙第二 1:9–10; Psalms 26:5"> しかし、あなたにはこのことがある。あなたはニコライ派の人々の行ないを憎んでいる。わたしもそれを憎んでいる。</span>
<span className="v" id="v7" data-v="7" data-xref="ヨハネの黙示録 2:17; ヨハネの黙示録 2:11; マタイの福音書 11:15"> 耳のある者は御霊が諸教会に言われることを聞きなさい。勝利を得る者に、わたしは神のパラダイスにあるいのちの木の実を食べさせよう。」』</span>
<span className="v" id="v8" data-v="8" data-xref="ヨハネの黙示録 1:17–18; ヨハネの黙示録 1:8; ヨハネの黙示録 1:11"> また、スミルナにある教会の御使いに書き送れ。『初めであり、終わりである方、死んで、また生きた方が言われる。</span>
<span className="v" id="v9" data-v="9" data-xref="ヨハネの黙示録 3:9; コリント人への手紙第二 8:9; ヤコブの手紙 2:5–6"> 「わたしは、あなたの苦しみと貧しさとを知っている。――しかしあなたは実際は富んでいる。――またユダヤ人だと自称しているが、実はそうでなく、かえってサタンの会衆である人たちから、ののしられていることも知っている。</span>
<span className="v" id="v10" data-v="10" data-xref="ヤコブの手紙 1:12; マタイの福音書 10:22; ヨハネの黙示録 3:10–11"> あなたが受けようとしている苦しみを恐れてはいけない。見よ。悪魔はあなたがたをためすために、あなたがたのうちのある人たちを牢に投げ入れようとしている。あなたがたは十日の間苦しみを受ける。死に至るまで忠実でありなさい。そうすれば、わたしはあなたにいのちの冠を与えよう。</span>
<span className="v" id="v11" data-v="11" data-xref="ヨハネの黙示録 20:6; ヨハネの黙示録 20:14; ヨハネの黙示録 21:8"> 耳のある者は御霊が諸教会に言われることを聞きなさい。勝利を得る者は、決して第二の死によってそこなわれることはない。」』</span>
<span className="v" id="v12" data-v="12" data-xref="ヨハネの黙示録 2:16; ヘブル人への手紙 4:12; ヨハネの黙示録 1:16"> また、ペルガモにある教会の御使いに書き送れ。『鋭い、両刃の剣を持つ方がこう言われる。</span>
<span className="v" id="v13" data-v="13" data-xref="ヨハネの黙示録 2:9–10; テモテへの手紙第一 5:8; ヨハネの黙示録 3:8–9"> 「わたしは、あなたの住んでいる所を知っている。そこにはサタンの王座がある。しかしあなたは、わたしの名を堅く保って、わたしの忠実な証人アンテパスがサタンの住むあなたがたのところで殺されたときでも、わたしに対する信仰を捨てなかった。</span>
<span className="v" id="v14" data-v="14" data-xref="Numbers 31:16; ペテロの手紙第二 2:15; ヨハネの黙示録 2:20"> しかし、あなたには少しばかり非難すべきことがある。あなたのうちに、バラムの教えを奉じている人々がいる。バラムはバラクに教えて、イスラエルの人々の前に、つまずきの石を置き、偶像の神にささげた物を食べさせ、また不品行を行なわせた。</span>
<span className="v" id="v15" data-v="15" data-xref="ヨハネの黙示録 2:6"> それと同じように、あなたのところにもニコライ派の教えを奉じている人々がいる。</span>
<span className="v" id="v16" data-v="16" data-xref="テサロニケ人への手紙第二 2:8; ヨハネの黙示録 1:16; ヨハネの黙示録 2:5"> だから、悔い改めなさい。もしそうしないなら、わたしは、すぐにあなたのところに行き、わたしの口の剣をもって彼らと戦おう。</span>
<span className="v" id="v17" data-v="17" data-xref="Isaiah 62:2; Isaiah 65:15; ヨハネの黙示録 19:12–13"> 耳のある者は御霊が諸教会に言われることを聞きなさい。わたしは勝利を得る者に隠れたマナを与える。また、彼に白い石を与える。その石には、それを受ける者のほかはだれも知らない、新しい名が書かれている。」』</span>
<span className="v" id="v18" data-v="18" data-xref="ヨハネの黙示録 1:14–15; ヨハネの黙示録 1:11; ヨハネの福音書 3:35–36"> また、テアテラにある教会の御使いに書き送れ。『燃える炎のような目を持ち、その足は光り輝くしんちゅうのような、神の子が言われる。</span>
<span className="v" id="v19" data-v="19" data-xref="テモテへの手紙第一 1:5; ペテロの手紙第二 1:7; ヨハネの福音書 15:2"> 「わたしは、あなたの行ないとあなたの愛と信仰と奉仕と忍耐を知っており、また、あなたの近ごろの行ないが初めの行ないにまさっていることも知っている。</span>
<span className="v" id="v20" data-v="20" data-xref="ヨハネの黙示録 2:14; 1 Kings 16:31; コリント人への手紙第一 10:18–21"> しかし、あなたには非難すべきことがある。あなたは、イゼベルという女をなすがままにさせている。この女は、預言者だと自称しているが、わたしのしもべたちを教えて誤りに導き、不品行を行なわせ、偶像の神にささげた物を食べさせている。</span>
<span className="v" id="v21" data-v="21" data-xref="ペテロの手紙第二 3:9; ローマ人への手紙 2:4–5; ヨハネの黙示録 9:20–21"> わたしは悔い改める機会を与えたが、この女は不品行を悔い改めようとしない。</span>
<span className="v" id="v22" data-v="22" data-xref="ヨハネの黙示録 17:2; ルカの福音書 13:5; Ezekiel 16:37–41"> 見よ。わたしは、この女を病の床に投げ込もう。また、この女と姦淫を行なう者たちも、この女の行ないを離れて悔い改めなければ、大きな患難の中に投げ込もう。</span>
<span className="v" id="v23" data-v="23" data-xref="マタイの福音書 16:27; ローマ人への手紙 8:27; Psalms 7:9"> また、わたしは、この女の子どもたちをも死病によって殺す。こうして全教会は、わたしが人の思いと心を探る者であることを知るようになる。また、わたしは、あなたがたの行ないに応じてひとりひとりに報いよう。</span>
<span className="v" id="v24" data-v="24" data-xref="コリント人への手紙第二 2:11; ヨハネの黙示録 12:9; コリント人への手紙第二 11:3"> しかし、テアテラにいる人たちの中で、この教えを受け入れておらず、彼らの言うサタンの深いところをまだ知っていないあなたがたに言う。わたしはあなたがたに、ほかの重荷を負わせない。</span>
<span className="v" id="v25" data-v="25" data-xref="ヨハネの黙示録 3:11; ヨハネの黙示録 3:3; ヘブル人への手紙 10:23"> ただ、あなたがたの持っているものを、わたしが行くまで、しっかりと持っていなさい。</span>
<span className="v" id="v26" data-v="26" data-xref="ヨハネの黙示録 3:21; Daniel 7:27; ヨハネの黙示録 2:7"> 勝利を得る者、また最後までわたしのわざを守る者には、諸国の民を支配する権威を与えよう。</span>
<span className="v" id="v27" data-v="27" data-xref="Psalms 2:8–9; ヨハネの黙示録 12:5; ヨハネの黙示録 19:15"> 彼は、鉄の杖をもって土の器を打ち砕くようにして彼らを治める。わたし自身が父から支配の権威を受けているのと同じである。</span>
<span className="v" id="v28" data-v="28" data-xref="ヨハネの黙示録 22:16; ペテロの手紙第二 1:19; ルカの福音書 1:78–79"> また、彼に明けの明星を与えよう。</span>
<span className="v" id="v29" data-v="29" data-xref="ヨハネの黙示録 2:7"> 耳のある者は御霊が諸教会に言われることを聞きなさい。」』</span>

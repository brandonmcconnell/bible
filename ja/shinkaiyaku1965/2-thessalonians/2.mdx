<span className="v" id="v1" data-v="1" data-xref="テサロニケ人への手紙第一 4:14–17; マルコの福音書 13:27; マタイの福音書 24:31"> さて兄弟たちよ。私たちの主イエス・キリストが再び来られることと、私たちが主のみもとに集められることに関して、あなたがたにお願いすることがあります。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネの手紙第一 4:1–2; マルコの福音書 13:7; マタイの福音書 24:4–6"> 霊によってでも、あるいはことばによってでも、あるいは私たちから出たかのような手紙によってでも、主の日がすでに来たかのように言われるのを聞いて、すぐに落ち着きを失ったり、心を騒がせたりしないでください。</span>
<span className="v" id="v3" data-v="3" data-xref="マタイの福音書 24:4–6; ヨハネの手紙第一 2:18; エペソ人への手紙 5:6"> だれにも、どのようにも、だまされないようにしなさい。なぜなら、まず背教が起こり、不法の人、すなわち滅びの子が現われなければ、主の日は来ないからです。</span>
<span className="v" id="v4" data-v="4" data-xref="Ezekiel 28:2; Daniel 7:25; ヨハネの黙示録 13:6–7"> 彼は、すべて神と呼ばれるもの、また礼拝されるものに反抗し、その上に自分を高く上げ、神の宮の中に座を設け、自分こそ神であると宣言します。</span>
<span className="v" id="v5" data-v="5" data-xref="ペテロの手紙第二 1:15; ガラテヤ人への手紙 5:21; マタイの福音書 16:9"> 私がまだあなたがたのところにいたとき、これらのことをよく話しておいたのを思い出しませんか。</span>
<span className="v" id="v6" data-v="6" data-xref="テサロニケ人への手紙第二 2:3; テサロニケ人への手紙第二 2:8"> あなたがたが知っているとおり、彼がその定められた時に現われるようにと、いま引き止めているものがあるのです。</span>
<span className="v" id="v7" data-v="7" data-xref="ヨハネの手紙第一 4:3; ヨハネの黙示録 17:7; テモテへの手紙第二 2:17–18"> 不法の秘密はすでに働いています。しかし今は引き止める者があって、自分が取り除かれる時まで引き止めているのです。</span>
<span className="v" id="v8" data-v="8" data-xref="テサロニケ人への手紙第二 2:3; ヨハネの黙示録 19:20–21; Isaiah 11:4"> その時になると、不法の人が現われますが、主は御口の息をもって彼を殺し、来臨の輝きをもって滅ぼしてしまわれます。</span>
<span className="v" id="v9" data-v="9" data-xref="マタイの福音書 24:24; ヨハネの黙示録 19:20; エペソ人への手紙 2:2"> 不法の人の到来は、サタンの働きによるのであって、あらゆる偽りの力、しるし、不思議がそれに伴い、</span>
<span className="v" id="v10" data-v="10" data-xref="コリント人への手紙第一 1:18; Proverbs 1:7; コリント人への手紙第二 4:2–3"> また、滅びる人たちに対するあらゆる悪の欺きが行なわれます。なぜなら、彼らは救われるために真理への愛を受け入れなかったからです。</span>
<span className="v" id="v11" data-v="11" data-xref="ローマ人への手紙 1:28; ヨハネの福音書 12:39–43; テモテへの手紙第一 4:1"> それゆえ神は、彼らが偽りを信じるように、惑わす力を送り込まれます。</span>
<span className="v" id="v12" data-v="12" data-xref="ローマ人への手紙 1:32; ローマ人への手紙 8:7–8; マルコの福音書 16:16"> それは、真理を信じないで、悪を喜んでいたすべての者が、さばかれるためです。</span>
<span className="v" id="v13" data-v="13" data-xref="テモテへの手紙第二 1:9; エペソ人への手紙 1:4–5; テサロニケ人への手紙第一 1:4"> しかし、あなたがたのことについては、私たちはいつでも神に感謝しなければなりません。主に愛されている兄弟たち。神は、御霊によるきよめと、真理による信仰によって、あなたがたを、初めから救いにお選びになったからです。</span>
<span className="v" id="v14" data-v="14" data-xref="テサロニケ人への手紙第一 2:12; ペテロの手紙第一 5:10; テサロニケ人への手紙第一 1:5"> ですから神は、私たちの福音によってあなたがたを召し、私たちの主イエス・キリストの栄光を得させてくださったのです。</span>
<span className="v" id="v15" data-v="15" data-xref="コリント人への手紙第一 11:2; テサロニケ人への手紙第二 3:6; テサロニケ人への手紙第二 2:2"> そこで、兄弟たち。堅く立って、私たちのことば、または手紙によって教えられた言い伝えを守りなさい。</span>
<span className="v" id="v16" data-v="16" data-xref="ローマ人への手紙 5:2–5; ヨハネの福音書 3:16; ペテロの手紙第一 1:3–8"> どうか、私たちの主イエス・キリストであり、私たちの父なる神である方、すなわち、私たちを愛し、恵みによって永遠の慰めとすばらしい望みとを与えてくださった方ご自身が、</span>
<span className="v" id="v17" data-v="17" data-xref="テサロニケ人への手紙第二 3:3; テサロニケ人への手紙第一 3:13; テサロニケ人への手紙第一 3:2"> あらゆる良いわざとことばとに進むよう、あなたがたの心を慰め、強めてくださいますように。</span>

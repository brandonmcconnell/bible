<span className="v" id="v1" data-v="1" data-xref="テサロニケ人への手紙第一 5:25; コロサイ人への手紙 4:3; コリント人への手紙第一 16:9"> 終わりに、兄弟たちよ。私たちのために祈ってください。主のみことばが、あなたがたのところでと同じように早く広まり、またあがめられますように。</span>
<span className="v" id="v2" data-v="2" data-xref="コリント人への手紙第二 4:3–4; ローマ人への手紙 15:31; Deuteronomy 32:20"> また、私たちが、ひねくれた悪人どもの手から救い出されますように。すべての人が信仰を持っているのではないからです。</span>
<span className="v" id="v3" data-v="3" data-xref="テモテへの手紙第二 4:18; テサロニケ人への手紙第一 5:24; コリント人への手紙第一 10:13"> しかし、主は真実な方ですから、あなたがたを強くし、悪い者から守ってくださいます。</span>
<span className="v" id="v4" data-v="4" data-xref="ピリピ人への手紙 1:6; ピレモンへの手紙 1:21; テサロニケ人への手紙第一 4:10"> 私たちが命じることを、あなたがたが現に実行しており、これからも実行してくれることを私たちは主にあって確信しています。</span>
<span className="v" id="v5" data-v="5" data-xref="Psalms 119:36; 1 Chronicles 29:18; Deuteronomy 30:6"> どうか、主があなたがたの心を導いて、神の愛とキリストの忍耐とを持たせてくださいますように。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="テサロニケ人への手紙第二 3:10–11; テサロニケ人への手紙第二 3:7; ローマ人への手紙 16:17"> 兄弟たちよ。主イエス・キリストの御名によって命じます。締まりのない歩み方をして私たちから受けた言い伝えに従わないでいる、すべての兄弟たちから離れていなさい。</span>
<span className="v" id="v7" data-v="7" data-xref="テサロニケ人への手紙第二 3:6; テサロニケ人への手紙第二 3:9; コリント人への手紙第一 4:16"> どのように私たちを見ならうべきかは、あなたがた自身が知っているのです。あなたがたのところで、私たちは締まりのないことはしなかったし、</span>
<span className="v" id="v8" data-v="8" data-xref="マタイの福音書 6:11; テサロニケ人への手紙第一 2:9; エペソ人への手紙 4:28"> 人のパンをただで食べることもしませんでした。かえって、あなたがたのだれにも負担をかけまいとして、昼も夜も労苦しながら働き続けました。</span>
<span className="v" id="v9" data-v="9" data-xref="テサロニケ人への手紙第二 3:7; テサロニケ人への手紙第一 2:6; コリント人への手紙第一 9:4–14"> それは、私たちに権利がなかったからではなく、ただ私たちを見ならうようにと、身をもってあなたがたに模範を示すためでした。</span>
<span className="v" id="v10" data-v="10" data-xref="Genesis 3:19; Proverbs 13:4; Proverbs 20:4"> 私たちは、あなたがたのところにいたときにも、働きたくない者は食べるなと命じました。</span>
<span className="v" id="v11" data-v="11" data-xref="テモテへの手紙第一 5:13; テサロニケ人への手紙第二 3:6; テサロニケ人への手紙第一 4:11"> ところが、あなたがたの中には、何も仕事をせず、おせっかいばかりして、締まりのない歩み方をしている人たちがあると聞いています。</span>
<span className="v" id="v12" data-v="12" data-xref="エペソ人への手紙 4:28; テサロニケ人への手紙第一 4:11; テサロニケ人への手紙第二 3:8"> こういう人たちには、主イエス・キリストによって、命じ、また勧めます。静かに仕事をし、自分で得たパンを食べなさい。</span>
<span className="v" id="v13" data-v="13" data-xref="ガラテヤ人への手紙 6:9–10; ヘブル人への手紙 12:3; コリント人への手紙第二 4:1"> しかしあなたがたは、たゆむことなく善を行ないなさい。兄弟たちよ。</span>
<span className="v" id="v14" data-v="14" data-xref="テトスへの手紙 3:10; テサロニケ人への手紙第二 3:6; コリント人への手紙第一 5:11"> もし、この手紙に書いた私たちの指示に従わない者があれば、そのような人には、特に注意を払い、交際しないようにしなさい。彼が恥じ入るようになるためです。</span>
<span className="v" id="v15" data-v="15" data-xref="テトスへの手紙 3:10; テサロニケ人への手紙第一 5:14; コリント人への手紙第一 5:5"> しかし、その人を敵とはみなさず、兄弟として戒めなさい。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="Psalms 29:11; ヨハネの福音書 16:33; マタイの福音書 1:23"> どうか、平和の主ご自身が、どんなばあいにも、いつも、あなたがたに平和を与えてくださいますように。どうか、主があなたがたすべてと、ともにおられますように。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="コリント人への手紙第一 16:21; テサロニケ人への手紙第二 1:5; コロサイ人への手紙 4:18"> パウロが自分の手であいさつを書きます。これは私のどの手紙にもあるしるしです。これが私の手紙の書き方です。</span>
<span className="v" id="v18" data-v="18" data-xref="ローマ人への手紙 16:20; ローマ人への手紙 16:23"> どうか、私たちの主イエス・キリストの恵みが、あなたがたすべてとともにありますように。</span>
</div>

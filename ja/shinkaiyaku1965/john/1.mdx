<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="Genesis 1:1; ヨハネの福音書 17:5; ヨハネの黙示録 19:13"> 初めに、ことばがあった。ことばは神とともにあった。ことばは神であった。</span>
<span className="v" id="v2" data-v="2"> この方は、初めに神とともにおられた。</span>
<span className="v" id="v3" data-v="3" data-xref="コロサイ人への手紙 1:16–17; コリント人への手紙第一 8:6; ヨハネの黙示録 4:11"> すべてのものは、この方によって造られた。造られたもので、この方によらずにできたものは一つもない。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネの福音書 8:12; ヨハネの福音書 12:46; ヨハネの福音書 5:26"> この方にいのちがあった。このいのちは人の光であった。</span>
<span className="v" id="v5" data-v="5" data-xref="ヨハネの福音書 3:19–20; ヨハネの福音書 12:36–40; コリント人への手紙第一 2:14"> 光はやみの中に輝いている。やみはこれに打ち勝たなかった。</span>
<span className="v" id="v6" data-v="6" data-xref="Malachi 3:1; ヨハネの福音書 3:28; Isaiah 40:3–5"> 神から遣わされたヨハネという人が現われた。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒の働き 19:4; ヨハネの福音書 1:36; ヨハネの福音書 5:33–35"> この人はあかしのために来た。光についてあかしするためであり、すべての人が彼によって信じるためである。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨハネの福音書 1:20; ヨハネの福音書 3:28; 使徒の働き 19:4"> 彼は光ではなかった。ただ光についてあかしするために来たのである。</span>
<span className="v" id="v9" data-v="9" data-xref="ヨハネの福音書 12:46; ヨハネの福音書 1:4; ヨハネの手紙第一 2:8"> すべての人を照らすそのまことの光が世に来ようとしていた。</span>
<span className="v" id="v10" data-v="10" data-xref="ヨハネの福音書 17:25; ヨハネの手紙第一 3:1; コリント人への手紙第一 2:8"> この方はもとから世におられ、世はこの方によって造られたのに、世はこの方を知らなかった。</span>
<span className="v" id="v11" data-v="11" data-xref="ルカの福音書 19:14; Isaiah 53:2–3; ヨハネの福音書 3:32"> この方はご自分のくにに来られたのに、ご自分の民は受け入れなかった。</span>
<span className="v" id="v12" data-v="12" data-xref="ガラテヤ人への手紙 3:26; ローマ人への手紙 8:14; ヨハネの手紙第一 3:1"> しかし、この方を受け入れた人々、すなわち、その名を信じた人々には、神の子どもとされる特権をお与えになった。</span>
<span className="v" id="v13" data-v="13" data-xref="ヨハネの手紙第一 3:9; ヤコブの手紙 1:18; ペテロの手紙第一 1:23"> この人々は、血によってではなく、肉の欲求や人の意欲によってでもなく、ただ、神によって生まれたのである。</span>
<span className="v" id="v14" data-v="14" data-xref="ヨハネの手紙第一 4:9; テモテへの手紙第一 3:16; Isaiah 40:5"> ことばは人となって、私たちの間に住まわれた。私たちはこの方の栄光を見た。父のみもとから来られたひとり子としての栄光である。この方は恵みとまことに満ちておられた。</span>
<span className="v" id="v15" data-v="15" data-xref="マタイの福音書 3:11; コロサイ人への手紙 1:17; ルカの福音書 3:16"> ヨハネはこの方について証言し、叫んで言った。「『私のあとから来る方は、私にまさる方である。私より先におられたからである。』と私が言ったのは、この方のことです。」</span>
<span className="v" id="v16" data-v="16" data-xref="コロサイ人への手紙 1:19; ローマ人への手紙 5:2; エペソ人への手紙 2:5–10"> 私たちはみな、この方の満ち満ちた豊かさの中から、恵みの上にさらに恵みを受けたのである。</span>
<span className="v" id="v17" data-v="17" data-xref="ローマ人への手紙 6:14; ヨハネの福音書 14:6; ローマ人への手紙 3:19–26"> というのは、律法はモーセによって与えられ、恵みとまことはイエス・キリストによって実現したからである。</span>
<span className="v" id="v18" data-v="18" data-xref="コロサイ人への手紙 1:15; ヨハネの福音書 6:46; マタイの福音書 11:27"> いまだかつて神を見た者はいない。父のふところにおられるひとり子の神が、神を説き明かされたのである。</span>
<span className="v" id="v19" data-v="19" data-xref="ルカの福音書 3:15–18; ヨハネの福音書 10:24; 使徒の働き 19:4"> ヨハネの証言は、こうである。ユダヤ人たちが祭司とレビ人をエルサレムからヨハネのもとに遣わして、「あなたはどなたですか。」と尋ねさせた。</span>
<span className="v" id="v20" data-v="20" data-xref="マルコの福音書 1:7–8; マタイの福音書 3:11–12; ヨハネの福音書 3:28–36"> 彼は告白して否まず、「私はキリストではありません。」と言明した。</span>
<span className="v" id="v21" data-v="21" data-xref="Malachi 4:5; Deuteronomy 18:15–18; マタイの福音書 11:14"> また、彼らは聞いた。「では、いったい何ですか。あなたはエリヤですか。」彼は言った。「そうではありません。」「あなたはあの預言者ですか。」彼は答えた。「違います。」</span>
<span className="v" id="v22" data-v="22" data-xref="2 Samuel 24:13"> そこで、彼らは言った。「あなたはだれですか。私たちを遣わした人々に返事をしたいのですが、あなたは自分を何だと言われるのですか。」</span>
<span className="v" id="v23" data-v="23" data-xref="Isaiah 40:3–5; マルコの福音書 1:3; マタイの福音書 3:3"> 彼は言った。「私は、預言者イザヤが言ったように『主の道をまっすぐにせよ。』と荒野で叫んでいる者の声です。」</span>
<span className="v" id="v24" data-v="24" data-xref="ルカの福音書 11:53; マタイの福音書 23:13–15; ルカの福音書 11:39–44"> 彼らは、パリサイ人の中から遣わされたのであった。</span>
<span className="v" id="v25" data-v="25" data-xref="Deuteronomy 18:18; Deuteronomy 18:15; ヨハネの福音書 1:20–22"> 彼らはまた尋ねて言った。「キリストでもなく、エリヤでもなく、またあの預言者でもないなら、なぜ、あなたはバプテスマを授けているのですか。」</span>
<span className="v" id="v26" data-v="26" data-xref="ヨハネの福音書 1:10–11; ルカの福音書 3:16; 使徒の働き 1:5"> ヨハネは答えて言った。「私は水でバプテスマを授けているが、あなたがたの中に、あなたがたの知らない方が立っておられます。</span>
<span className="v" id="v27" data-v="27" data-xref="ヨハネの福音書 1:30; マルコの福音書 1:7; マタイの福音書 3:11"> その方は私のあとから来られる方で、私はその方のくつのひもを解く値うちもありません。」</span>
<span className="v" id="v28" data-v="28" data-xref="ヨハネの福音書 10:40; ヨハネの福音書 3:23; Judges 7:24"> この事があったのは、ヨルダンの向こう岸のベタニヤであって、ヨハネはそこでバプテスマを授けていた。</span>
<span className="v" id="v29" data-v="29" data-xref="Isaiah 53:7; ヨハネの手紙第一 2:2; ヨハネの手紙第一 3:5"> その翌日、ヨハネは自分のほうにイエスが来られるのを見て言った。「見よ、世の罪を取り除く神の小羊。</span>
<span className="v" id="v30" data-v="30" data-xref="ヨハネの福音書 1:27; ヨハネの福音書 1:15; ルカの福音書 3:16"> 私が『私のあとから来る人がある。その方は私にまさる方である。私より先におられたからだ。』と言ったのは、この方のことです。</span>
<span className="v" id="v31" data-v="31" data-xref="Malachi 3:1; ルカの福音書 1:17; Malachi 4:2–5"> 私もこの方を知りませんでした。しかし、この方がイスラエルに明らかにされるために、私は来て、水でバプテスマを授けているのです。」</span>
<span className="v" id="v32" data-v="32" data-xref="マルコの福音書 1:10; ルカの福音書 3:22; マタイの福音書 3:16"> またヨハネは証言して言った。「御霊が鳩のように天から下って、この方の上にとどまられるのを私は見ました。</span>
<span className="v" id="v33" data-v="33" data-xref="使徒の働き 1:5; マタイの福音書 3:11; ルカの福音書 3:16"> 私もこの方を知りませんでした。しかし、水でバプテスマを授けさせるために私を遣わされた方が、私に言われました。『聖霊がある方の上に下って、その上にとどまられるのがあなたに見えたなら、その方こそ、聖霊によってバプテスマを授ける方である。』</span>
<span className="v" id="v34" data-v="34" data-xref="Psalms 2:7; ヨハネの福音書 1:49; Psalms 89:26–27"> 私はそれを見たのです。それで、この方が神の子であると証言しているのです。」</span>
<span className="v" id="v35" data-v="35" data-xref="ヨハネの福音書 3:25–26; Malachi 3:16"> その翌日、またヨハネは、ふたりの弟子とともに立っていたが、</span>
<span className="v" id="v36" data-v="36" data-xref="ヨハネの福音書 1:29; ペテロの手紙第一 1:19–20; Isaiah 65:1–2"> イエスが歩いて行かれるのを見て、「見よ、神の小羊。」と言った。</span>
<span className="v" id="v37" data-v="37" data-xref="ローマ人への手紙 10:17; ヨハネの福音書 1:43; Zechariah 8:21"> ふたりの弟子は、彼がそう言うのを聞いて、イエスについて行った。</span>
<span className="v" id="v38" data-v="38" data-xref="ヨハネの福音書 18:7; ヨハネの福音書 3:2; ヨハネの福音書 1:49"> イエスは振り向いて、彼らがついて来るのを見て、言われた。「あなたがたは何を求めているのですか。」彼らは言った。「ラビ（訳して言えば、先生）。今どこにお泊まりですか。」</span>
<span className="v" id="v39" data-v="39" data-xref="ルカの福音書 24:29; マタイの福音書 11:28–30; ヨハネの福音書 6:37"> イエスは彼らに言われた。「来なさい。そうすればわかります。」そこで、彼らはついて行って、イエスの泊まっておられる所を知った。そして、その日彼らはイエスといっしょにいた。時は十時ごろであった。</span>
<span className="v" id="v40" data-v="40" data-xref="マルコの福音書 1:16–20; マタイの福音書 4:18–22; ヨハネの福音書 1:40–42"> ヨハネから聞いて、イエスについて行ったふたりのうちのひとりは、シモン・ペテロの兄弟アンデレであった。</span>
<span className="v" id="v41" data-v="41" data-xref="ヨハネの福音書 4:25; ヨハネの福音書 1:45; Psalms 89:20"> 彼はまず自分の兄弟シモンを見つけて、「私たちはメシヤ（訳して言えば、キリスト）に会った。」と言った。</span>
<span className="v" id="v42" data-v="42" data-xref="ヨハネの福音書 21:15–17; コリント人への手紙第一 3:22; コリント人への手紙第一 15:5"> 彼はシモンをイエスのもとに連れて来た。イエスはシモンに目を留めて言われた。「あなたはヨハネの子シモンです。あなたをケパ（訳すとペテロ）と呼ぶことにします。」</span>
<span className="v" id="v43" data-v="43" data-xref="マタイの福音書 9:9; ヨハネの福音書 14:8; Isaiah 65:1"> その翌日、イエスはガリラヤに行こうとされた。そして、ピリポを見つけて「わたしに従って来なさい。」と言われた。</span>
<span className="v" id="v44" data-v="44" data-xref="ヨハネの福音書 12:21; マタイの福音書 11:21; マルコの福音書 8:22"> ピリポは、ベツサイダの人で、アンデレやペテロと同じ町の出身であった。</span>
<span className="v" id="v45" data-v="45" data-xref="Deuteronomy 18:18–22; ルカの福音書 24:27; Micah 5:2"> 彼はナタナエルを見つけて言った。「私たちは、モーセが律法の中に書き、預言者たちも書いている方に会いました。ナザレの人で、ヨセフの子イエスです。」</span>
<span className="v" id="v46" data-v="46" data-xref="ヨハネの福音書 7:52; ヨハネの福音書 7:41–42; ヨハネの福音書 4:29"> ナタナエルは彼に言った。「ナザレから何の良いものが出るだろう。」ピリポは言った。「来て、そして、見なさい。」</span>
<span className="v" id="v47" data-v="47" data-xref="ヨハネの黙示録 14:5; Psalms 32:2; Psalms 73:1"> イエスはナタナエルが自分のほうに来るのを見て、彼について言われた。「これこそ、ほんとうのイスラエル人だ。彼のうちには偽りがない。」</span>
<span className="v" id="v48" data-v="48" data-xref="Isaiah 65:24; ヨハネの福音書 2:25; Psalms 139:1–2"> ナタナエルはイエスに言った。「どうして私をご存じなのですか。」イエスは言われた。「わたしは、ピリポがあなたを呼ぶ前に、あなたがいちじくの木の下にいるのを見たのです。」</span>
<span className="v" id="v49" data-v="49" data-xref="Zephaniah 3:15; Zechariah 9:9; マタイの福音書 27:42"> ナタナエルは答えた。「先生。あなたは神の子です。あなたはイスラエルの王です。」</span>
<span className="v" id="v50" data-v="50" data-xref="ヨハネの福音書 11:40; ヨハネの福音書 20:29; ルカの福音書 1:45"> イエスは答えて言われた。「あなたがいちじくの木の下にいるのを見た、とわたしが言ったので、あなたは信じるのですか。あなたは、それよりもさらに大きなことを見ることになります。」</span>
<span className="v" id="v51" data-v="51" data-xref="Genesis 28:12; 使徒の働き 7:56; ルカの福音書 22:43"> そして言われた。「まことに、まことに、あなたがたに告げます。天が開けて、神の御使いたちが人の子の上を上り下りするのを、あなたがたはいまに見ます。」</span>

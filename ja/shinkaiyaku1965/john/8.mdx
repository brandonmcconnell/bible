<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マタイの福音書 21:1; マルコの福音書 11:1; ルカの福音書 19:37"> イエスはオリーブ山に行かれた。</span>
<span className="v" id="v2" data-v="2" data-xref="マタイの福音書 26:55; ルカの福音書 4:20; ルカの福音書 21:37"> そして、朝早く、イエスはもう一度宮にはいられた。民衆はみな、みもとに寄って来た。イエスはすわって、彼らに教え始められた。</span>
<span className="v" id="v3" data-v="3"> すると、律法学者とパリサイ人が、姦淫の場で捕えられたひとりの女を連れて来て、真中に置いてから、</span>
<span className="v" id="v4" data-v="4"> イエスに言った。「先生。この女は姦淫の現場でつかまえられたのです。</span>
<span className="v" id="v5" data-v="5" data-xref="Leviticus 20:10; Deuteronomy 22:21–24; Ezekiel 16:38–40"> モーセは律法の中で、こういう女を石打ちにするように命じています。ところで、あなたは何と言われますか。」</span>
<span className="v" id="v6" data-v="6" data-xref="Jeremiah 17:13; ルカの福音書 10:25; Ecclesiastes 3:7"> 彼らはイエスをためしてこう言ったのである。それは、イエスを告発する理由を得るためであった。しかし、イエスは身をかがめて、指で地面に書いておられた。</span>
<span className="v" id="v7" data-v="7" data-xref="マタイの福音書 7:1–5; ローマ人への手紙 2:21–25; ローマ人への手紙 2:1–3"> けれども、彼らが問い続けてやめなかったので、イエスは身を起こして言われた。「あなたがたのうちで罪のない者が、最初に彼女に石を投げなさい。」</span>
<span className="v" id="v8" data-v="8"> そしてイエスは、もう一度身をかがめて、地面に書かれた。</span>
<span className="v" id="v9" data-v="9" data-xref="Ecclesiastes 7:22; ローマ人への手紙 2:15; ヨハネの手紙第一 3:20"> 彼らはそれを聞くと、年長者たちから始めて、ひとりひとり出て行き、イエスがひとり残された。女はそのままそこにいた。</span>
<span className="v" id="v10" data-v="10" data-xref="Isaiah 41:11–12"> イエスは身を起こして、その女に言われた。「婦人よ。あの人たちは今どこにいますか。あなたを罪に定める者はなかったのですか。」</span>
<span className="v" id="v11" data-v="11" data-xref="ヨハネの福音書 3:17; ヨハネの福音書 5:14; Isaiah 1:16–18"> 彼女は言った。「だれもいません。」そこで、イエスは言われた。「わたしもあなたを罪に定めない。行きなさい。今からは決して罪を犯してはなりません。」］</span>
<span className="v" id="v12" data-v="12" data-xref="ヨハネの福音書 12:46; ヨハネの福音書 9:5; ヨハネの福音書 12:35"> イエスはまた彼らに語って言われた。「わたしは、世の光です。わたしに従う者は、決してやみの中を歩むことがなく、いのちの光を持つのです。」</span>
<span className="v" id="v13" data-v="13" data-xref="ヨハネの福音書 5:31–47"> そこでパリサイ人はイエスに言った。「あなたは自分のことを自分で証言しています。だから、あなたの証言は真実ではありません。」</span>
<span className="v" id="v14" data-v="14" data-xref="ヨハネの福音書 16:28; ヨハネの福音書 13:3; ヨハネの福音書 8:42"> イエスは答えて、彼らに言われた。「もしこのわたしが自分のことを証言するなら、その証言は真実です。わたしは、わたしがどこから来たか、また、どこへ行くかを知っているからです。しかしあなたがたは、わたしがどこから来たのか、またどこへ行くのか知りません。</span>
<span className="v" id="v15" data-v="15" data-xref="1 Samuel 16:7; ヨハネの福音書 7:24; ヨハネの福音書 12:47"> あなたがたは肉によってさばきます。わたしはだれをもさばきません。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒の働き 17:31; ヨハネの福音書 8:29; ヨハネの福音書 16:32"> しかし、もしわたしがさばくなら、そのさばきは正しいのです。なぜなら、わたしひとりではなく、わたしとわたしを遣わした方とがさばくのだからです。</span>
<span className="v" id="v17" data-v="17" data-xref="Deuteronomy 19:15; Deuteronomy 17:6; ヘブル人への手紙 10:28"> あなたがたの律法にも、ふたりの証言は真実であると書かれています。</span>
<span className="v" id="v18" data-v="18" data-xref="ヨハネの福音書 8:38; ヨハネの福音書 8:58; ヨハネの福音書 8:25"> わたしが自分の証人であり、また、わたしを遣わした父が、わたしについてあかしされます。」</span>
<span className="v" id="v19" data-v="19" data-xref="ヨハネの福音書 16:3; ヨハネの福音書 8:54–55; ヨハネの福音書 14:6–9"> すると、彼らはイエスに言った。「あなたの父はどこにいるのですか。」イエスは答えられた。「あなたがたは、わたしをも、わたしの父をも知りません。もし、あなたがたがわたしを知っていたなら、わたしの父をも知っていたでしょう。」</span>
<span className="v" id="v20" data-v="20" data-xref="ヨハネの福音書 7:30; ヨハネの福音書 7:8; マルコの福音書 12:41"> イエスは宮で教えられたとき、献金箱のある所でこのことを話された。しかし、だれもイエスを捕えなかった。イエスの時がまだ来ていなかったからである。</span>
<span className="v" id="v21" data-v="21" data-xref="ヨハネの福音書 7:34; ヨハネの福音書 8:24; コリント人への手紙第一 15:17–18"> イエスはまた彼らに言われた。「わたしは去って行きます。あなたがたはわたしを捜すけれども、自分の罪の中で死にます。わたしが行く所に、あなたがたは来ることができません。」</span>
<span className="v" id="v22" data-v="22" data-xref="ヨハネの福音書 8:52; Psalms 22:6; ヨハネの福音書 8:48"> そこで、ユダヤ人たちは言った。「あの人は『わたしが行く所に、あなたがたは来ることができない。』と言うが、自殺するつもりなのか。」</span>
<span className="v" id="v23" data-v="23" data-xref="ヨハネの福音書 3:31; ヨハネの福音書 17:14; ヨハネの福音書 17:16"> それでイエスは彼らに言われた。「あなたがたが来たのは下からであり、わたしが来たのは上からです。あなたがたはこの世の者であり、わたしはこの世の者ではありません。</span>
<span className="v" id="v24" data-v="24" data-xref="ヨハネの福音書 3:36; マルコの福音書 16:16; ヨハネの福音書 3:18"> それでわたしは、あなたがたが自分の罪の中で死ぬと、あなたがたに言ったのです。もしあなたがたが、わたしのことを信じなければ、あなたがたは自分の罪の中で死ぬのです。」</span>
<span className="v" id="v25" data-v="25" data-xref="ヨハネの福音書 5:17–29; ルカの福音書 22:67; ヨハネの福音書 1:22"> そこで、彼らはイエスに言った。「あなたはだれですか。」イエスは言われた。「初めからわたしがあなたがたに話して来たことは何でしたか。</span>
<span className="v" id="v26" data-v="26" data-xref="ヨハネの福音書 15:15; ヨハネの福音書 12:47–50; ヨハネの福音書 8:40"> あなたがたについて言うべきこと、さばくべきことがたくさんあります。しかし、わたしを遣わした方は真実であって、わたしはその方から聞いたことをそのまま世に告げるのです。」</span>
<span className="v" id="v27" data-v="27" data-xref="Isaiah 6:9; ヨハネの福音書 8:43; コリント人への手紙第二 4:3–4"> 彼らは、イエスが父のことを語っておられたことを悟らなかった。</span>
<span className="v" id="v28" data-v="28" data-xref="ヨハネの福音書 5:19; ヨハネの福音書 5:30; ヨハネの福音書 6:38"> イエスは言われた。「あなたがたが人の子を上げてしまうと、その時、あなたがたは、わたしが何であるか、また、わたしがわたし自身からは何事もせず、ただ父がわたしに教えられたとおりに、これらのことを話していることを、知るようになります。</span>
<span className="v" id="v29" data-v="29" data-xref="ヨハネの福音書 6:38; ヨハネの福音書 16:32; ヨハネの福音書 4:34"> わたしを遣わした方はわたしとともにおられます。わたしをひとり残されることはありません。わたしがいつも、そのみこころにかなうことを行なうからです。」</span>
<span className="v" id="v30" data-v="30" data-xref="ヨハネの福音書 7:31; ヨハネの福音書 2:23; ヨハネの福音書 11:45"> イエスがこれらのことを話しておられると、多くの者がイエスを信じた。</span>
<span className="v" id="v31" data-v="31" data-xref="ヨハネの手紙第二 1:9; ヨハネの福音書 15:4–9; テモテへの手紙第二 3:14"> そこでイエスは、その信じたユダヤ人たちに言われた。「もしあなたがたが、わたしのことばにとどまるなら、あなたがたはほんとうにわたしの弟子です。</span>
<span className="v" id="v32" data-v="32" data-xref="ローマ人への手紙 8:2; ヨハネの福音書 8:36; ヨハネの福音書 17:17"> そして、あなたがたは真理を知り、真理はあなたがたを自由にします。」</span>
<span className="v" id="v33" data-v="33" data-xref="マタイの福音書 3:9; ヨハネの福音書 8:39; Genesis 15:13"> 彼らはイエスに答えた。「私たちはアブラハムの子孫であって、決してだれの奴隷になったこともありません。あなたはどうして、『あなたがたは自由になる。』と言われるのですか。」</span>
<span className="v" id="v34" data-v="34" data-xref="ローマ人への手紙 6:16; ペテロの手紙第二 2:19; Proverbs 5:22"> イエスは彼らに答えられた。「まことに、まことに、あなたがたに告げます。罪を行なっている者はみな、罪の奴隷です。</span>
<span className="v" id="v35" data-v="35" data-xref="ガラテヤ人への手紙 4:4–7; ルカの福音書 15:31; ローマ人への手紙 8:15–17"> 奴隷はいつまでも家にいるのではありません。しかし、息子はいつまでもいます。</span>
<span className="v" id="v36" data-v="36" data-xref="コリント人への手紙第二 3:17; ガラテヤ人への手紙 5:1; ローマ人への手紙 8:2"> ですから、もし子があなたがたを自由にするなら、あなたがたはほんとうに自由なのです。</span>
<span className="v" id="v37" data-v="37" data-xref="コリント人への手紙第一 2:14; ヨハネの福音書 8:45–47; ヨハネの福音書 7:1"> わたしは、あなたがたがアブラハムの子孫であることを知っています。しかしあなたがたはわたしを殺そうとしています。わたしのことばが、あなたがたのうちにはいっていないからです。</span>
<span className="v" id="v38" data-v="38" data-xref="ヨハネの福音書 5:19; ヨハネの福音書 8:44; ヨハネの福音書 8:41"> わたしは父のもとで見たことを話しています。ところが、あなたがたは、あなたがたの父から示されたことを行なうのです。」</span>
<span className="v" id="v39" data-v="39" data-xref="ガラテヤ人への手紙 3:7; ヨハネの福音書 8:37; ローマ人への手紙 9:7"> 彼らは答えて言った。「私たちの父はアブラハムです。」イエスは彼らに言われた。「あなたがたがアブラハムの子どもなら、アブラハムのわざを行ないなさい。</span>
<span className="v" id="v40" data-v="40" data-xref="ヨハネの福音書 8:26; ガラテヤ人への手紙 4:29; ガラテヤ人への手紙 4:16"> ところが今あなたがたは、神から聞いた真理をあなたがたに話しているこのわたしを、殺そうとしています。アブラハムはそのようなことはしなかったのです。</span>
<span className="v" id="v41" data-v="41" data-xref="Isaiah 64:8; ヨハネの福音書 8:38; Isaiah 63:16"> あなたがたは、あなたがたの父のわざを行なっています。」彼らは言った。「私たちは不品行によって生まれた者ではありません。私たちにはひとりの父、神があります。」</span>
<span className="v" id="v42" data-v="42" data-xref="ヨハネの福音書 12:49; ヨハネの福音書 14:10; ヨハネの福音書 17:8"> イエスは言われた。「神がもしあなたがたの父であるなら、あなたがたはわたしを愛するはずです。なぜなら、わたしは神から出て来てここにいるからです。わたしは自分で来たのではなく、神がわたしを遣わしたのです。</span>
<span className="v" id="v43" data-v="43" data-xref="ヨハネの福音書 12:39–40; ローマ人への手紙 8:7–8; ヨハネの福音書 7:17"> あなたがたは、なぜわたしの話していることがわからないのでしょう。それは、あなたがたがわたしのことばに耳を傾けることができないからです。</span>
<span className="v" id="v44" data-v="44" data-xref="使徒の働き 13:10; ヨハネの手紙第一 3:12; ヨハネの手紙第一 3:8–10"> あなたがたは、あなたがたの父である悪魔から出た者であって、あなたがたの父の欲望を成し遂げたいと願っているのです。悪魔は初めから人殺しであり、真理に立ってはいません。彼のうちには真理がないからです。彼が偽りを言うときは、自分にふさわしい話し方をしているのです。なぜなら彼は偽り者であり、また偽りの父であるからです。</span>
<span className="v" id="v45" data-v="45" data-xref="テモテへの手紙第二 4:3–4; ガラテヤ人への手紙 4:16; ヨハネの福音書 18:37"> しかし、このわたしは真理を話しているために、あなたがたはわたしを信じません。</span>
<span className="v" id="v46" data-v="46" data-xref="ヘブル人への手紙 4:15; ヨハネの福音書 16:8; ペテロの手紙第一 2:22"> あなたがたのうちだれか、わたしに罪があると責める者がいますか。わたしが真理を話しているなら、なぜわたしを信じないのですか。</span>
<span className="v" id="v47" data-v="47" data-xref="ヨハネの福音書 10:26–27; ヨハネの手紙第二 1:9; ヨハネの福音書 18:37"> 神から出た者は、神のことばに聞き従います。ですから、あなたがたが聞き従わないのは、あなたがたが神から出た者でないからです。」</span>
<span className="v" id="v48" data-v="48" data-xref="ヨハネの福音書 7:20; ヨハネの福音書 8:52; マタイの福音書 10:5"> ユダヤ人たちは答えて、イエスに言った。「私たちが、あなたはサマリヤ人で、悪霊につかれていると言うのは当然ではありませんか。」</span>
<span className="v" id="v49" data-v="49" data-xref="ペテロの手紙第一 2:23; Isaiah 49:3; ヨハネの福音書 13:31–32"> イエスは答えられた。「わたしは悪霊につかれてはいません。わたしは父を敬っています。しかしあなたがたは、わたしを卑しめています。</span>
<span className="v" id="v50" data-v="50" data-xref="ヨハネの福音書 5:41; ヨハネの福音書 8:54; ヨハネの福音書 7:18"> しかし、わたしはわたしの栄誉を求めません。それをお求めになり、さばきをなさる方がおられます。</span>
<span className="v" id="v51" data-v="51" data-xref="ヨハネの福音書 11:25–26; ヨハネの福音書 5:24; ヨハネの福音書 3:15–16"> まことに、まことに、あなたがたに告げます。だれでもわたしのことばを守るならば、その人は決して死を見ることがありません。」</span>
<span className="v" id="v52" data-v="52" data-xref="ヨハネの福音書 9:24; ヨハネの福音書 8:48; ヘブル人への手紙 2:9"> ユダヤ人たちはイエスに言った。「あなたが悪霊につかれていることが、今こそわかりました。アブラハムは死に、預言者たちも死にました。しかし、あなたは、『だれでもわたしのことばを守るならば、その人は決して死を味わうことがない。』と言うのです。</span>
<span className="v" id="v53" data-v="53" data-xref="ヨハネの福音書 4:12; ローマ人への手紙 9:5; ヘブル人への手紙 7:1–7"> あなたは、私たちの父アブラハムよりも偉大なのですか。そのアブラハムは死んだのです。預言者たちもまた死にました。あなたは、自分自身をだれだと言うのですか。」</span>
<span className="v" id="v54" data-v="54" data-xref="ヨハネの福音書 8:50; Proverbs 25:27; ペテロの手紙第二 1:17"> イエスは答えられた。「わたしがもし自分自身に栄光を帰するなら、わたしの栄光はむなしいものです。わたしに栄光を与える方は、わたしの父です。この方のことを、あなたがたは『私たちの神である。』と言っています。</span>
<span className="v" id="v55" data-v="55" data-xref="ヨハネの福音書 8:19; ヨハネの福音書 8:44; ヨハネの福音書 7:28–29"> けれどもあなたがたはこの方を知ってはいません。しかし、わたしは知っています。もしわたしがこの方を知らないと言うなら、わたしはあなたがたと同様に偽り者となるでしょう。しかし、わたしはこの方を知っており、そのみことばを守っています。</span>
<span className="v" id="v56" data-v="56" data-xref="ヘブル人への手紙 11:13; Genesis 22:18; ガラテヤ人への手紙 3:7–9"> あなたがたの父アブラハムは、わたしの日を見ることを思って大いに喜びました。彼はそれを見て、喜んだのです。」</span>
<span className="v" id="v57" data-v="57"> そこで、ユダヤ人たちはイエスに向かって言った。「あなたはまだ五十歳になっていないのにアブラハムを見たのですか。」</span>
<span className="v" id="v58" data-v="58" data-xref="Exodus 3:14; コロサイ人への手紙 1:17; ヨハネの福音書 17:5"> イエスは彼らに言われた。「まことに、まことに、あなたがたに告げます。アブラハムが生まれる前から、わたしはいるのです。」</span>
<span className="v" id="v59" data-v="59" data-xref="ヨハネの福音書 11:8; ヨハネの福音書 10:30–33; ヨハネの福音書 10:39–40"> すると彼らは石を取ってイエスに投げつけようとした。しかし、イエスは身を隠して、宮から出て行かれた。</span>

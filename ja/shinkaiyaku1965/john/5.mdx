<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="Deuteronomy 16:16; Exodus 23:14–17; Exodus 34:23"> その後、ユダヤ人の祭りがあって、イエスはエルサレムに上られた。</span>
<span className="v" id="v2" data-v="2" data-xref="Nehemiah 12:39; Nehemiah 3:1; Nehemiah 3:32"> さて、エルサレムには、羊の門の近くに、ヘブル語でベテスダと呼ばれる池があって、五つの回廊がついていた。</span>
<span className="v" id="v3" data-v="3" data-xref="マルコの福音書 3:1–4; ルカの福音書 7:22; マタイの福音書 15:30"> その中に大ぜいの病人、盲人、足なえ、やせ衰えた者が伏せっていた。</span>
<span className="v" id="v4" data-v="4"> そこに、三十八年もの間、病気にかかっている人がいた。</span>
<span className="v" id="v6" data-v="6" data-xref="ルカの福音書 18:41; ヘブル人への手紙 4:15; ヘブル人への手紙 4:13"> イエスは彼が伏せっているのを見、それがもう長い間のことなのを知って、彼に言われた。「よくなりたいか。」</span>
<span className="v" id="v7" data-v="7" data-xref="Psalms 72:12; Deuteronomy 32:36; コリント人への手紙第一 9:24"> 病人は答えた。「主よ。私には、水がかき回されたとき、池の中に私を入れてくれる人がいません。行きかけると、もうほかの人が先に降りて行くのです。」</span>
<span className="v" id="v8" data-v="8" data-xref="ルカの福音書 5:24; マタイの福音書 9:6; マルコの福音書 2:11"> イエスは彼に言われた。「起きて、床を取り上げて歩きなさい。」</span>
<span className="v" id="v9" data-v="9" data-xref="使徒の働き 3:7–8; ヨハネの福音書 9:14; マルコの福音書 3:2–4"> すると、その人はすぐに直って、床を取り上げて歩き出した。<br />ところが、その日は安息日であった。</span>
<span className="v" id="v10" data-v="10" data-xref="Jeremiah 17:21; ルカの福音書 6:2; ヨハネの福音書 9:16"> そこでユダヤ人たちは、そのいやされた人に言った。「きょうは安息日だ。床を取り上げてはいけない。」</span>
<span className="v" id="v11" data-v="11" data-xref="マルコの福音書 2:9–11; ヨハネの福音書 9:16"> しかし、その人は彼らに答えた。「私を直してくださった方が、『床を取り上げて歩け。』と言われたのです。」</span>
<span className="v" id="v12" data-v="12" data-xref="マタイの福音書 21:23; Judges 6:29; ローマ人への手紙 10:2"> 彼らは尋ねた。「『取り上げて歩け。』と言った人はだれだ。」</span>
<span className="v" id="v13" data-v="13" data-xref="ルカの福音書 4:30; ルカの福音書 24:31; ヨハネの福音書 8:59"> しかし、いやされた人は、それがだれであるか知らなかった。人が大ぜいそこにいる間に、イエスは立ち去られたからである。</span>
<span className="v" id="v14" data-v="14" data-xref="ヨハネの福音書 8:11; Leviticus 26:23–24; Psalms 118:18"> その後、イエスは宮の中で彼を見つけて言われた。「見なさい。あなたはよくなった。もう罪を犯してはなりません。そうでないともっと悪い事があなたの身に起こるから。」</span>
<span className="v" id="v15" data-v="15" data-xref="ヨハネの福音書 9:11–12; ヨハネの福音書 4:29; ヨハネの福音書 9:25"> その人は行って、ユダヤ人たちに、自分を直してくれた方はイエスだと告げた。</span>
<span className="v" id="v16" data-v="16" data-xref="ヨハネの福音書 10:39; ヨハネの福音書 7:19–20; マルコの福音書 3:6"> このためユダヤ人たちは、イエスを迫害した。イエスが安息日にこのようなことをしておられたからである。</span>
<span className="v" id="v17" data-v="17" data-xref="ヨハネの福音書 9:4; ヨハネの福音書 14:10; コロサイ人への手紙 1:16"> イエスは彼らに答えられた。「わたしの父は今に至るまで働いておられます。ですからわたしも働いているのです。」</span>
<span className="v" id="v18" data-v="18" data-xref="ヨハネの福音書 10:30; ヨハネの福音書 10:33; ヨハネの福音書 19:7"> このためユダヤ人たちは、ますますイエスを殺そうとするようになった。イエスが安息日を破っておられただけでなく、ご自身を神と等しくして、神を自分の父と呼んでおられたからである。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="ヨハネの福音書 12:49; ヨハネの福音書 8:28; ヨハネの福音書 14:10"> そこで、イエスは彼らに答えて言われた。「まことに、まことに、あなたがたに告げます。子は、父がしておられることを見て行なう以外には、自分からは何事も行なうことができません。父がなさることは何でも、子も同様に行なうのです。</span>
<span className="v" id="v20" data-v="20" data-xref="ヨハネの福音書 3:35; マタイの福音書 3:17; ヨハネの福音書 17:26"> それは、父が子を愛して、ご自分のなさることをみな、子にお示しになるからです。また、これよりもさらに大きなわざを子に示されます。それは、あなたがたが驚き怪しむためです。</span>
<span className="v" id="v21" data-v="21" data-xref="ローマ人への手紙 8:11; Deuteronomy 32:39; ヨハネの福音書 11:25"> 父が死人を生かし、いのちをお与えになるように、子もまた、与えたいと思う者にいのちを与えます。</span>
<span className="v" id="v22" data-v="22" data-xref="ヨハネの福音書 5:27; 使徒の働き 17:31; コリント人への手紙第二 5:10"> また、父はだれをもさばかず、すべてのさばきを子にゆだねられました。</span>
<span className="v" id="v23" data-v="23" data-xref="ヨハネの手紙第一 2:23; ルカの福音書 10:16; マタイの福音書 11:27"> それは、すべての者が、父を敬うように子を敬うためです。子を敬わない者は、子を遣わした父をも敬いません。</span>
<span className="v" id="v24" data-v="24" data-xref="ヨハネの福音書 3:36; ヨハネの福音書 6:40; ヨハネの手紙第一 5:11–13"> まことに、まことに、あなたがたに告げます。わたしのことばを聞いて、わたしを遣わした方を信じる者は、永遠のいのちを持ち、さばきに会うことがなく、死からいのちに移っているのです。</span>
<span className="v" id="v25" data-v="25" data-xref="ヨハネの福音書 5:28; エペソ人への手紙 5:14; エペソ人への手紙 2:5"> まことに、まことに、あなたがたに告げます。死人が神の子の声を聞く時が来ます。今がその時です。そして、聞く者は生きるのです。</span>
<span className="v" id="v26" data-v="26" data-xref="ヨハネの福音書 11:26; ヨハネの福音書 1:4; Exodus 3:14"> それは、父がご自分のうちにいのちを持っておられるように、子にも、自分のうちにいのちを持つようにしてくださったからです。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒の働き 10:42; ヨハネの福音書 5:22; 使徒の働き 17:31"> また、父はさばきを行なう権を子に与えられました。子は人の子だからです。</span>
<span className="v" id="v28" data-v="28" data-xref="ヨハネの黙示録 20:12; テサロニケ人への手紙第一 4:14–17; Isaiah 26:19"> このことに驚いてはなりません。墓の中にいる者がみな、子の声を聞いて出て来る時が来ます。</span>
<span className="v" id="v29" data-v="29" data-xref="Daniel 12:2–3; ローマ人への手紙 2:6–10; 使徒の働き 24:15"> 善を行なった者は、よみがえっていのちを受け、悪を行なった者は、よみがえってさばきを受けるのです。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="ヨハネの福音書 6:38; ヨハネの福音書 5:19; ヨハネの福音書 4:34"> わたしは、自分からは何事も行なうことができません。ただ聞くとおりにさばくのです。そして、わたしのさばきは正しいのです。わたし自身の望むことを求めず、わたしを遣わした方のみこころを求めるからです。</span>
<span className="v" id="v31" data-v="31" data-xref="Proverbs 27:2; ヨハネの福音書 8:54; ヨハネの黙示録 3:14"> もしわたしだけが自分のことを証言するのなら、わたしの証言は真実ではありません。</span>
<span className="v" id="v32" data-v="32" data-xref="ヨハネの福音書 1:33; ヨハネの福音書 12:28–30; ヨハネの福音書 5:36–37"> わたしについて証言する方がほかにあるのです。その方のわたしについて証言される証言が真実であることは、わたしが知っています。</span>
<span className="v" id="v33" data-v="33" data-xref="ヨハネの福音書 1:29–34; ヨハネの福音書 3:26–36; ヨハネの福音書 1:15–27"> あなたがたは、ヨハネのところに人をやりましたが、彼は真理について証言しました。</span>
<span className="v" id="v34" data-v="34" data-xref="ルカの福音書 19:41–42; ヨハネの福音書 20:31; ヨハネの手紙第一 5:9"> といっても、わたしは人の証言を受けるのではありません。わたしは、あなたがたが救われるために、そのことを言うのです。</span>
<span className="v" id="v35" data-v="35" data-xref="ペテロの手紙第二 1:19; ヨハネの福音書 1:7–8; マタイの福音書 11:11"> 彼は燃えて輝くともしびであり、あなたがたはしばらくの間、その光の中で楽しむことを願ったのです。</span>
<span className="v" id="v36" data-v="36" data-xref="ヨハネの福音書 10:25; ヨハネの福音書 10:37–38; ヨハネの福音書 15:24"> しかし、わたしにはヨハネの証言よりもすぐれた証言があります。父がわたしに成し遂げさせようとしてお与えになったわざ、すなわちわたしが行なっているわざそのものが、わたしについて、父がわたしを遣わしたことを証言しているのです。</span>
<span className="v" id="v37" data-v="37" data-xref="ヨハネの福音書 8:18; ヨハネの福音書 1:18; マタイの福音書 3:17"> また、わたしを遣わした父ご自身がわたしについて証言しておられます。あなたがたは、まだ一度もその御声を聞いたこともなく、御姿を見たこともありません。</span>
<span className="v" id="v38" data-v="38" data-xref="ヨハネの手紙第一 2:14; Deuteronomy 6:6–9; ヨハネの福音書 12:44–48"> また、そのみことばをあなたがたのうちにとどめてもいません。父が遣わした者をあなたがたが信じないからです。</span>
<span className="v" id="v39" data-v="39" data-xref="ルカの福音書 24:27; ルカの福音書 24:44; ペテロの手紙第二 1:19–21"> あなたがたは、聖書の中に永遠のいのちがあると思うので、聖書を調べています。その聖書が、わたしについて証言しているのです。</span>
<span className="v" id="v40" data-v="40" data-xref="ヨハネの福音書 3:19; ヨハネの福音書 1:11; Psalms 81:11"> それなのに、あなたがたは、いのちを得るためにわたしのもとに来ようとはしません。</span>
<span className="v" id="v41" data-v="41" data-xref="ヨハネの福音書 7:18; ヨハネの福音書 5:34; テサロニケ人への手紙第一 2:6"> わたしは人からの栄誉は受けません。</span>
<span className="v" id="v42" data-v="42" data-xref="ヨハネの手紙第一 4:20; ヨハネの手紙第一 3:17; ヨハネの福音書 2:25"> ただ、わたしはあなたがたを知っています。あなたがたのうちには、神の愛がありません。</span>
<span className="v" id="v43" data-v="43" data-xref="ヨハネの福音書 10:25; マタイの福音書 24:5; ヨハネの福音書 17:4–6"> わたしはわたしの父の名によって来ましたが、あなたがたはわたしを受け入れません。ほかの人がその人自身の名において来れば、あなたがたはその人を受け入れるのです。</span>
<span className="v" id="v44" data-v="44" data-xref="ヨハネの福音書 12:43; ローマ人への手紙 2:29; ピリピ人への手紙 2:3"> 互いの栄誉は受けても、唯一の神からの栄誉を求めないあなたがたは、どうして信じることができますか。</span>
<span className="v" id="v45" data-v="45" data-xref="ローマ人への手紙 3:19–20; ガラテヤ人への手紙 3:10; コリント人への手紙第二 3:7–11"> わたしが、父の前にあなたがたを訴えようとしていると思ってはなりません。あなたがたを訴える者は、あなたがたが望みをおいているモーセです。</span>
<span className="v" id="v46" data-v="46" data-xref="Deuteronomy 18:15; Deuteronomy 18:18–19; ヨハネの福音書 1:45"> もしあなたがたがモーセを信じているのなら、わたしを信じたはずです。モーセが書いたのはわたしのことだからです。</span>
<span className="v" id="v47" data-v="47" data-xref="ルカの福音書 16:31; ルカの福音書 16:29"> しかし、あなたがたがモーセの書を信じないのであれば、どうしてわたしのことばを信じるでしょう。」</span>
</div>

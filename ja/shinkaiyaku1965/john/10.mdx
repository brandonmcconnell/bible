<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マタイの福音書 7:15; ヨハネの福音書 10:8–10; ローマ人への手紙 16:18"> 「まことに、まことに、あなたがたに告げます。羊の囲いに門からはいらないで、ほかの所を乗り越えて来る者は、盗人で強盗です。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネの福音書 10:14; 使徒の働き 20:28; ペテロの手紙第一 5:4"> しかし、門からはいる者は、その羊の牧者です。</span>
<span className="v" id="v3" data-v="3" data-xref="Ezekiel 34:11–16; テモテへの手紙第二 2:19; ヨハネの福音書 10:4"> 門番は彼のために開き、羊はその声を聞き分けます。彼は自分の羊をその名で呼んで連れ出します。</span>
<span className="v" id="v4" data-v="4" data-xref="Deuteronomy 1:30; ヨハネの福音書 10:16; ヨハネの福音書 12:26"> 彼は、自分の羊をみな引き出すと、その先頭に立って行きます。すると羊は、彼の声を知っているので、彼について行きます。</span>
<span className="v" id="v5" data-v="5" data-xref="ヨハネの手紙第一 4:5–6; コロサイ人への手紙 2:6–10; マルコの福音書 4:24"> しかし、ほかの人には決してついて行きません。かえって、その人から逃げ出します。その人たちの声を知らないからです。」</span>
<span className="v" id="v6" data-v="6" data-xref="Isaiah 56:11; Psalms 82:5; Proverbs 28:5"> イエスはこのたとえを彼らにお話しになったが、彼らは、イエスの話されたことが何のことかよくわからなかった。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="ヨハネの福音書 14:6; エペソ人への手紙 2:18; ヨハネの福音書 10:1"> そこで、イエスはまた言われた。「まことに、まことに、あなたがたに告げます。わたしは羊の門です。</span>
<span className="v" id="v8" data-v="8" data-xref="Ezekiel 34:2; Jeremiah 23:1; ヨハネの福音書 10:1"> わたしの前に来た者はみな、盗人で強盗です。羊は彼らの言うことを聞かなかったのです。</span>
<span className="v" id="v9" data-v="9" data-xref="ヨハネの福音書 14:6; エペソ人への手紙 2:18; ヨハネの福音書 10:7"> わたしは門です。だれでも、わたしを通ってはいるなら、救われます。また安らかに出入りし、牧草を見つけます。</span>
<span className="v" id="v10" data-v="10" data-xref="ルカの福音書 19:10; ヨハネの福音書 6:51; ヨハネの福音書 12:47"> 盗人が来るのは、ただ盗んだり、殺したり、滅ぼしたりするだけのためです。わたしが来たのは、羊がいのちを得、またそれを豊かに持つためです。</span>
<span className="v" id="v11" data-v="11" data-xref="ヨハネの福音書 10:14–15; Psalms 23:1; ヨハネの福音書 15:13"> わたしは、良い牧者です。良い牧者は羊のためにいのちを捨てます。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒の働き 20:29; Zechariah 11:16–17; Ezekiel 34:2–6"> 牧者でなく、また、羊の所有者でない雇い人は、狼が来るのを見ると、羊を置き去りにして、逃げて行きます。それで、狼は羊を奪い、また散らすのです。</span>
<span className="v" id="v13" data-v="13" data-xref="ピリピ人への手紙 2:20; ヨハネの福音書 12:6; 使徒の働き 18:17"> それは、彼が雇い人であって、羊のことを心にかけていないからです。</span>
<span className="v" id="v14" data-v="14" data-xref="ヨハネの福音書 10:27; ヨハネの福音書 10:11; テモテへの手紙第二 2:19"> わたしは良い牧者です。わたしはわたしのものを知っています。また、わたしのものは、わたしを知っています。</span>
<span className="v" id="v15" data-v="15" data-xref="ガラテヤ人への手紙 1:4; ヨハネの福音書 10:11; Isaiah 53:10"> それは、父がわたしを知っておられ、わたしが父を知っているのと同様です。また、わたしは羊のためにわたしのいのちを捨てます。</span>
<span className="v" id="v16" data-v="16" data-xref="Isaiah 56:8; ヨハネの福音書 11:52; ペテロの手紙第一 2:25"> わたしにはまた、この囲いに属さないほかの羊があります。わたしはそれをも導かなければなりません。彼らはわたしの声に聞き従い、一つの群れ、ひとりの牧者となるのです。</span>
<span className="v" id="v17" data-v="17" data-xref="ヨハネの福音書 10:18; ヨハネの福音書 10:11; ヘブル人への手紙 2:9"> わたしが自分のいのちを再び得るために自分のいのちを捨てるからこそ、父はわたしを愛してくださいます。</span>
<span className="v" id="v18" data-v="18" data-xref="ヘブル人への手紙 2:9; テトスへの手紙 2:14; ヨハネの福音書 2:19–21"> だれも、わたしからいのちを取った者はいません。わたしが自分からいのちを捨てるのです。わたしには、それを捨てる権威があり、それをもう一度得る権威があります。わたしはこの命令をわたしの父から受けたのです。」</span>
<span className="v" id="v19" data-v="19" data-xref="ヨハネの福音書 9:16; コリント人への手紙第一 3:3; ヨハネの福音書 7:40–43"> このみことばを聞いて、ユダヤ人たちの間にまた分裂が起こった。</span>
<span className="v" id="v20" data-v="20" data-xref="ヨハネの福音書 7:20; マルコの福音書 3:21; ヨハネの福音書 8:47–48"> 彼らのうちの多くの者が言った。「あれは悪霊につかれて気が狂っている。どうしてあなたがたは、あの人の言うことに耳を貸すのか。」</span>
<span className="v" id="v21" data-v="21" data-xref="Exodus 4:11; Isaiah 35:5–6; Psalms 94:9"> ほかの者は言った。「これは悪霊につかれた者のことばではない。悪霊がどうして盲人の目をあけることができようか。」</span>
<span className="v" id="v22" data-v="22"> そのころ、エルサレムで、宮きよめの祭りがあった。</span>
<span className="v" id="v23" data-v="23" data-xref="使徒の働き 5:12; 使徒の働き 3:11"> 時は冬であった。イエスは、宮の中で、ソロモンの廊を歩いておられた。</span>
<span className="v" id="v24" data-v="24" data-xref="ルカの福音書 22:67–70; ヨハネの福音書 1:19; ヨハネの福音書 8:25"> それでユダヤ人たちは、イエスを取り囲んで言った。「あなたは、いつまで私たちに気をもませるのですか。もしあなたがキリストなら、はっきりとそう言ってください。」</span>
<span className="v" id="v25" data-v="25" data-xref="ヨハネの福音書 10:38; ヨハネの福音書 8:58; ヨハネの福音書 14:11"> イエスは彼らに答えられた。「わたしは話しました。しかし、あなたがたは信じないのです。わたしが父の御名によって行なうわざが、わたしについて証言しています。</span>
<span className="v" id="v26" data-v="26" data-xref="ヨハネの福音書 8:47; コリント人への手紙第二 4:3–4; ヨハネの福音書 12:37–40"> しかし、あなたがたは信じません。それは、あなたがたがわたしの羊に属していないからです。</span>
<span className="v" id="v27" data-v="27" data-xref="ヨハネの福音書 10:16; ヨハネの福音書 10:14; ヨハネの黙示録 3:20"> わたしの羊はわたしの声を聞き分けます。またわたしは彼らを知っています。そして彼らはわたしについて来ます。</span>
<span className="v" id="v28" data-v="28" data-xref="ヨハネの福音書 6:39–40; ヨハネの福音書 6:37; ヨハネの福音書 3:15–16"> わたしは彼らに永遠のいのちを与えます。彼らは決して滅びることがなく、また、だれもわたしの手から彼らを奪い去るようなことはありません。</span>
<span className="v" id="v29" data-v="29" data-xref="ヨハネの福音書 6:37; ヨハネの福音書 17:2; ヨハネの福音書 17:9"> わたしに彼らをお与えになった父は、すべてにまさって偉大です。だれもわたしの父の御手から彼らを奪い去ることはできません。</span>
<span className="v" id="v30" data-v="30" data-xref="ヨハネの福音書 1:1–2; ヨハネの福音書 14:9; ヨハネの福音書 17:21–23"> わたしと父とは一つです。」</span>
<span className="v" id="v31" data-v="31" data-xref="ヨハネの福音書 5:18; ヨハネの福音書 8:59; 1 Samuel 30:6"> ユダヤ人たちは、イエスを石打ちにしようとして、また石を取り上げた。</span>
<span className="v" id="v32" data-v="32" data-xref="ヨハネの手紙第一 3:12; ヨハネの福音書 5:36; Psalms 35:12"> イエスは彼らに答えられた。「わたしは、父から出た多くの良いわざを、あなたがたに示しました。そのうちのどのわざのために、わたしを石打ちにしようとするのですか。」</span>
<span className="v" id="v33" data-v="33" data-xref="ヨハネの福音書 5:18; Leviticus 24:16; ヨハネの福音書 10:30"> ユダヤ人たちはイエスに答えた。「良いわざのためにあなたを石打ちにするのではありません。冒涜のためです。あなたは人間でありながら、自分を神とするからです。」</span>
<span className="v" id="v34" data-v="34" data-xref="Psalms 82:6–7; Exodus 7:1; Psalms 82:1"> イエスは彼らに答えられた。「あなたがたの律法に、『わたしは言った、あなたがたは神である。』と書いてはありませんか。</span>
<span className="v" id="v35" data-v="35" data-xref="マタイの福音書 24:35; ローマ人への手紙 13:1; ルカの福音書 16:17"> もし、神のことばを受けた人々を、神と呼んだとすれば、聖書は廃棄されるものではないから、</span>
<span className="v" id="v36" data-v="36" data-xref="ヨハネの福音書 5:17–18; ヨハネの福音書 3:17; Jeremiah 1:5"> 『わたしは神の子である。』とわたしが言ったからといって、どうしてあなたがたは、父が、聖別して世に遣わした者について、『神を冒涜している。』と言うのですか。</span>
<span className="v" id="v37" data-v="37" data-xref="ヨハネの福音書 15:24; ヨハネの福音書 10:25; ヨハネの福音書 12:37–40"> もしわたしが、わたしの父のみわざを行なっていないのなら、わたしを信じないでいなさい。</span>
<span className="v" id="v38" data-v="38" data-xref="ヨハネの福音書 14:20; ヨハネの福音書 10:25; ヨハネの福音書 10:30"> しかし、もし行なっているなら、たといわたしの言うことが信じられなくても、わざを信用しなさい。それは、父がわたしにおられ、わたしが父にいることを、あなたがたが悟り、また知るためです。」</span>
<span className="v" id="v39" data-v="39" data-xref="ヨハネの福音書 7:30; ヨハネの福音書 8:59; ヨハネの福音書 7:44"> そこで、彼らはまたイエスを捕えようとした。しかし、イエスは彼らの手からのがれられた。</span>
<span className="v" id="v40" data-v="40" data-xref="ヨハネの福音書 1:28; ヨハネの福音書 11:54; ヨハネの福音書 7:1"> そして、イエスはまたヨルダンを渡って、ヨハネが初めにバプテスマを授けていた所に行かれ、そこに滞在された。</span>
<span className="v" id="v41" data-v="41" data-xref="ヨハネの福音書 1:33–34; ヨハネの福音書 1:29–30; マルコの福音書 1:37"> 多くの人々がイエスのところに来た。彼らは、「ヨハネは何一つしるしを行なわなかったけれども、彼がこの方について話したことはみな真実であった。」と言った。</span>
<span className="v" id="v42" data-v="42" data-xref="ヨハネの福音書 4:41; ヨハネの福音書 2:23; ヨハネの福音書 7:31"> そして、その地方で多くの人々がイエスを信じた。</span>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨハネの福音書 3:26; ヨハネの福音書 3:22; コリント人への手紙第二 4:5"> イエスがヨハネよりも弟子を多くつくって、バプテスマを授けていることがパリサイ人の耳にはいった。それを主が知られたとき、</span>
<span className="v" id="v2" data-v="2" data-xref="使徒の働き 10:48; コリント人への手紙第一 1:13–17"> ――イエスご自身はバプテスマを授けておられたのではなく、弟子たちであったが、――</span>
<span className="v" id="v3" data-v="3" data-xref="マタイの福音書 10:23; ヨハネの福音書 10:40; ヨハネの福音書 2:11"> 主はユダヤを去って、またガリラヤへ行かれた。</span>
<span className="v" id="v4" data-v="4" data-xref="ルカの福音書 17:11; ルカの福音書 2:49; ルカの福音書 9:51–52"> しかし、サマリヤを通って行かなければならなかった。</span>
<span className="v" id="v5" data-v="5" data-xref="Joshua 24:32; Genesis 33:19; Genesis 48:22"> それで主は、ヤコブがその子ヨセフに与えた地所に近いスカルというサマリヤの町に来られた。</span>
<span className="v" id="v6" data-v="6" data-xref="ヘブル人への手紙 4:15; ヘブル人への手紙 2:17; マタイの福音書 8:24"> そこにはヤコブの井戸があった。イエスは旅の疲れで、井戸のかたわらに腰をおろしておられた。時は六時ごろであった。</span>
<span className="v" id="v7" data-v="7" data-xref="マタイの福音書 10:42; 1 Kings 17:10; Genesis 24:43"> ひとりのサマリヤの女が水をくみに来た。イエスは「わたしに水を飲ませてください。」と言われた。</span>
<span className="v" id="v8" data-v="8" data-xref="ルカの福音書 9:13; ヨハネの福音書 4:39; ヨハネの福音書 4:5"> 弟子たちは食物を買いに、町へ出かけていた。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒の働き 10:28; マタイの福音書 10:5; 2 Kings 17:24–41"> そこで、そのサマリヤの女は言った。「あなたはユダヤ人なのに、どうしてサマリヤの女の私に、飲み水をお求めになるのですか。」――ユダヤ人はサマリヤ人とつきあいをしなかったからである。――</span>
<span className="v" id="v10" data-v="10" data-xref="ヨハネの福音書 4:14; ヨハネの黙示録 7:17; ヨハネの福音書 7:37–39"> イエスは答えて言われた。「もしあなたが神の賜物を知り、また、あなたに水を飲ませてくれと言う者がだれであるかを知っていたなら、あなたのほうでその人に求めたことでしょう。そしてその人はあなたに生ける水を与えたことでしょう。」</span>
<span className="v" id="v11" data-v="11" data-xref="コリント人への手紙第一 2:14; ヨハネの福音書 3:4"> 彼女は言った。「先生。あなたはくむ物を持っておいでにならず、この井戸は深いのです。その生ける水をどこから手にお入れになるのですか。</span>
<span className="v" id="v12" data-v="12" data-xref="ヨハネの福音書 4:6; ヨハネの福音書 8:53; マタイの福音書 12:42"> あなたは、私たちの先祖ヤコブよりも偉いのでしょうか。ヤコブは私たちにこの井戸を与え、彼自身も、彼の子たちも家畜も、この井戸から飲んだのです。」</span>
<span className="v" id="v13" data-v="13" data-xref="ヨハネの福音書 6:27; Isaiah 65:13–14; ルカの福音書 16:24"> イエスは答えて言われた。「この水を飲む者はだれでも、また渇きます。</span>
<span className="v" id="v14" data-v="14" data-xref="ヨハネの福音書 7:38–39; ヨハネの福音書 6:35; Isaiah 49:10"> しかし、わたしが与える水を飲む者はだれでも、決して渇くことがありません。わたしが与える水は、その人のうちで泉となり、永遠のいのちへの水がわき出ます。」</span>
<span className="v" id="v15" data-v="15" data-xref="ヨハネの福音書 6:34; ローマ人への手紙 8:5; Psalms 4:6"> 女はイエスに言った。「先生。私が渇くことがなく、もうここまでくみに来なくてもよいように、その水を私に下さい。」</span>
<span className="v" id="v16" data-v="16" data-xref="ヘブル人への手紙 4:13; ヨハネの黙示録 2:23; ヨハネの福音書 4:18"> イエスは彼女に言われた。「行って、あなたの夫をここに呼んで来なさい。」</span>
<span className="v" id="v17" data-v="17"> 女は答えて言った。「私には夫はありません。」イエスは言われた。「私には夫がないというのは、もっともです。</span>
<span className="v" id="v18" data-v="18" data-xref="Jeremiah 3:20; コリント人への手紙第一 7:10–11; ローマ人への手紙 7:3"> あなたには夫が五人あったが、今あなたといっしょにいるのは、あなたの夫ではないからです。あなたが言ったことはほんとうです。」</span>
<span className="v" id="v19" data-v="19" data-xref="ルカの福音書 7:39; ヨハネの福音書 6:14; ヨハネの福音書 9:17"> 女は言った。「先生。あなたは預言者だと思います。</span>
<span className="v" id="v20" data-v="20" data-xref="Genesis 12:6–7; Deuteronomy 27:12; Deuteronomy 11:29"> 私たちの先祖は、この山で礼拝しましたが、あなたがたは、礼拝すべき場所はエルサレムだと言われます。」</span>
<span className="v" id="v21" data-v="21" data-xref="テモテへの手紙第一 2:8; Malachi 1:11; ヨハネの福音書 4:23"> イエスは彼女に言われた。「わたしの言うことを信じなさい。あなたがたが父を礼拝するのは、この山でもなく、エルサレムでもない、そういう時が来ます。</span>
<span className="v" id="v22" data-v="22" data-xref="使徒の働き 17:23; Isaiah 2:3; ローマ人への手紙 9:4–5"> 救いはユダヤ人から出るのですから、わたしたちは知って礼拝していますが、あなたがたは知らないで礼拝しています。</span>
<span className="v" id="v23" data-v="23" data-xref="ピリピ人への手紙 3:3; ヨハネの福音書 5:25; マタイの福音書 15:7–9"> しかし、真の礼拝者たちが霊とまことによって父を礼拝する時が来ます。今がその時です。父はこのような人々を礼拝者として求めておられるからです。</span>
<span className="v" id="v24" data-v="24" data-xref="コリント人への手紙第二 3:17; マタイの福音書 15:8–9; ピリピ人への手紙 3:3"> 神は霊ですから、神を礼拝する者は、霊とまことによって礼拝しなければなりません。」</span>
<span className="v" id="v25" data-v="25" data-xref="ヨハネの福音書 1:49; Daniel 9:24–26; ヨハネの福音書 1:41–42"> 女はイエスに言った。「私は、キリストと呼ばれるメシヤの来られることを知っています。その方が来られるときには、いっさいのことを私たちに知らせてくださるでしょう。」</span>
<span className="v" id="v26" data-v="26" data-xref="ヨハネの福音書 8:24; マルコの福音書 14:61–62; ローマ人への手紙 10:20–21"> イエスは言われた。「あなたと話しているこのわたしがそれです。」</span>
<span className="v" id="v27" data-v="27" data-xref="ルカの福音書 7:39; ヨハネの福音書 4:8–9"> このとき、弟子たちが帰って来て、イエスが女の人と話しておられるのを不思議に思った。しかし、だれも、「何を求めておられるのですか。」とも、「なぜ彼女と話しておられるのですか。」とも言わなかった。</span>
<span className="v" id="v28" data-v="28" data-xref="ヨハネの福音書 4:7; ルカの福音書 24:33; マルコの福音書 16:8–10"> 女は、自分の水がめを置いて町へ行き、人々に言った。</span>
<span className="v" id="v29" data-v="29" data-xref="ヨハネの黙示録 22:17; コリント人への手紙第一 14:24–25; ヨハネの福音書 4:25"> 「来て、見てください。私のしたこと全部を私に言った人がいるのです。この方がキリストなのでしょうか。」</span>
<span className="v" id="v30" data-v="30" data-xref="ローマ人への手紙 5:20; 使徒の働き 8:5–8; ルカの福音書 17:16–18"> そこで、彼らは町を出て、イエスのほうへやって来た。</span>
<span className="v" id="v31" data-v="31" data-xref="ヨハネの福音書 1:38; Genesis 24:33; 使徒の働き 16:30–34"> そのころ、弟子たちはイエスに、「先生。召し上がってください。」とお願いした。</span>
<span className="v" id="v32" data-v="32" data-xref="Job 23:12; Psalms 119:103; ヨハネの福音書 4:34"> しかし、イエスは彼らに言われた。「わたしには、あなたがたの知らない食物があります。」</span>
<span className="v" id="v33" data-v="33" data-xref="マタイの福音書 16:6–11; ルカの福音書 9:45"> そこで、弟子たちは互いに言った。「だれか食べる物を持って来たのだろうか。」</span>
<span className="v" id="v34" data-v="34" data-xref="ヨハネの福音書 6:38; ヨハネの福音書 5:30; Job 23:12"> イエスは彼らに言われた。「わたしを遣わした方のみこころを行ない、そのみわざを成し遂げることが、わたしの食物です。</span>
<span className="v" id="v35" data-v="35" data-xref="ルカの福音書 10:2–3; マタイの福音書 9:37–38; ヨハネの福音書 4:30"> あなたがたは、『刈り入れ時が来るまでに、まだ四か月ある。』と言ってはいませんか。さあ、わたしの言うことを聞きなさい。目を上げて畑を見なさい。色づいて、刈り入れるばかりになっています。</span>
<span className="v" id="v36" data-v="36" data-xref="ヤコブの手紙 5:19–20; ローマ人への手紙 1:13; コリント人への手紙第一 3:5–9"> すでに、刈る者は報酬を受け、永遠のいのちに入れられる実を集めています。それは蒔く者と刈る者がともに喜ぶためです。</span>
<span className="v" id="v37" data-v="37" data-xref="Micah 6:15; Job 31:8; ルカの福音書 19:21"> こういうわけで、『ひとりが種を蒔き、ほかの者が刈り取る。』ということわざは、ほんとうなのです。</span>
<span className="v" id="v38" data-v="38" data-xref="ヨハネの福音書 1:7; 2 Chronicles 36:15; 使徒の働き 10:42–43"> わたしは、あなたがたに自分で労苦しなかったものを刈り取らせるために、あなたがたを遣わしました。ほかの人々が労苦して、あなたがたはその労苦の実を得ているのです。」</span>
<span className="v" id="v39" data-v="39" data-xref="ヨハネの福音書 4:29; ヨハネの福音書 4:5; ヨハネの福音書 10:41–42"> さて、その町のサマリヤ人のうち多くの者が、「あの方は、私がしたこと全部を私に言った。」と証言したその女のことばによってイエスを信じた。</span>
<span className="v" id="v40" data-v="40" data-xref="ヨハネの黙示録 3:20; 使徒の働き 16:15; ルカの福音書 24:29"> そこで、サマリヤ人たちはイエスのところに来たとき、自分たちのところに滞在してくださるように願った。そこでイエスは二日間そこに滞在された。</span>
<span className="v" id="v41" data-v="41" data-xref="コリント人への手紙第一 2:4–5; 使徒の働き 1:8; 使徒の働き 8:12"> そして、さらに多くの人々が、イエスのことばによって信じた。</span>
<span className="v" id="v42" data-v="42" data-xref="ヨハネの手紙第一 4:14; ヨハネの福音書 1:29; ヨハネの手紙第一 5:20"> そして彼らはその女に言った。「もう私たちは、あなたが話したことによって信じているのではありません。自分で聞いて、この方がほんとうに世の救い主だと知っているのです。」</span>
<span className="v" id="v43" data-v="43" data-xref="マタイの福音書 4:13; ローマ人への手紙 15:8; マルコの福音書 7:27–28"> さて、二日の後、イエスはここを去って、ガリラヤへ行かれた。</span>
<span className="v" id="v44" data-v="44" data-xref="マタイの福音書 13:57; ルカの福音書 4:24; マルコの福音書 6:4"> イエスご自身が、「預言者は自分の故郷では尊ばれない。」と証言しておられたからである。</span>
<span className="v" id="v45" data-v="45" data-xref="ヨハネの福音書 2:23; ヨハネの福音書 2:13–16; Deuteronomy 16:16"> そういうわけで、イエスがガリラヤに行かれたとき、ガリラヤ人はイエスを歓迎した。彼らも祭りに行っていたので、イエスが祭りの間にエルサレムでなさったすべてのことを見ていたからである。</span>
<span className="v" id="v46" data-v="46" data-xref="ヨハネの福音書 2:1–11; ルカの福音書 7:2; Hosea 5:15"> イエスは再びガリラヤのカナに行かれた。そこは、かつて水をぶどう酒にされた所である。さて、カペナウムに病気の息子がいる王室の役人がいた。</span>
<span className="v" id="v47" data-v="47" data-xref="ヨハネの福音書 4:3; ヨハネの福音書 11:21; ヨハネの福音書 11:32"> この人は、イエスがユダヤからガリラヤに来られたと聞いて、イエスのところへ行き、下って来て息子をいやしてくださるように願った。息子が死にかかっていたからである。</span>
<span className="v" id="v48" data-v="48" data-xref="ヨハネの福音書 20:29; ヘブル人への手紙 2:4; コリント人への手紙第一 1:22"> そこで、イエスは彼に言われた。「あなたがたは、しるしと不思議を見ないかぎり、決して信じない。」</span>
<span className="v" id="v49" data-v="49" data-xref="マルコの福音書 5:23; Psalms 88:10–12; Psalms 40:17"> その王室の役人はイエスに言った。「主よ。どうか私の子どもが死なないうちに下って来てください。」</span>
<span className="v" id="v50" data-v="50" data-xref="マタイの福音書 8:13; マルコの福音書 7:29–30; ローマ人への手紙 4:20–21"> イエスは彼に言われた。「帰って行きなさい。あなたの息子は直っています。」その人はイエスが言われたことばを信じて、帰途についた。</span>
<span className="v" id="v51" data-v="51" data-xref="1 Kings 17:23; ヨハネの福音書 4:50; ヨハネの福音書 4:53"> 彼が下って行く途中、そのしもべたちが彼に出会って、彼の息子が直ったことを告げた。</span>
<span className="v" id="v52" data-v="52"> そこで子どもがよくなった時刻を彼らに尋ねると、「きのう、七時に熱がひきました。」と言った。</span>
<span className="v" id="v53" data-v="53" data-xref="Psalms 107:20; ルカの福音書 19:9; 使徒の働き 16:34"> それで父親は、イエスが「あなたの息子は直っている。」と言われた時刻と同じであることを知った。そして彼自身と彼の家の者がみな信じた。</span>
<span className="v" id="v54" data-v="54" data-xref="ヨハネの福音書 4:45; ヨハネの福音書 2:1–11"> イエスはユダヤを去ってガリラヤにはいられてから、またこのことを第二のしるしとして行なわれたのである。</span>

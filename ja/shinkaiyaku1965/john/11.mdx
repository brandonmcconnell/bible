<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ルカの福音書 10:38–42; ヨハネの福音書 12:17; 2 Kings 20:1–12"> さて、ある人が病気にかかっていた。ラザロといって、マリヤとその姉妹マルタとの村の出で、ベタニヤの人であった。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネの福音書 12:3; マルコの福音書 14:3; マタイの福音書 26:6–7"> このマリヤは、主に香油を塗り、髪の毛でその足をぬぐったマリヤであって、彼女の兄弟ラザロが病んでいたのである。</span>
<span className="v" id="v3" data-v="3" data-xref="ヨハネの福音書 11:5; ヨハネの黙示録 3:19; テモテへの手紙第二 4:20"> そこで姉妹たちは、イエスのところに使いを送って、言った。「主よ。ご覧ください。あなたが愛しておられる者が病気です。」</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネの福音書 11:40; ヨハネの福音書 9:3; ペテロの手紙第一 4:14"> イエスはこれを聞いて、言われた。「この病気は死で終わるだけのものではなく、神の栄光のためのものです。神の子がそれによって栄光を受けるためです。」</span>
<span className="v" id="v5" data-v="5" data-xref="ヨハネの福音書 15:9–13; ヨハネの福音書 16:27; ヨハネの福音書 17:26"> イエスはマルタとその姉妹とラザロとを愛しておられた。</span>
<span className="v" id="v6" data-v="6" data-xref="Isaiah 30:18; Isaiah 55:8–9; Genesis 45:1–5"> そのようなわけで、イエスは、ラザロが病んでいることを聞かれたときも、そのおられた所になお二日とどまられた。</span>
<span className="v" id="v7" data-v="7" data-xref="ヨハネの福音書 10:40–42; ルカの福音書 9:51; 使徒の働き 20:22–24"> その後、イエスは、「もう一度ユダヤに行こう。」と弟子たちに言われた。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨハネの福音書 10:31; ヨハネの福音書 8:59; 使徒の働き 21:12–13"> 弟子たちはイエスに言った。「先生。たった今ユダヤ人たちが、あなたを石打ちにしようとしていたのに、またそこにおいでになるのですか。」</span>
<span className="v" id="v9" data-v="9" data-xref="ヨハネの福音書 9:4; ヨハネの福音書 12:35; Jeremiah 31:9"> イエスは答えられた。「昼間は十二時間あるでしょう。だれでも、昼間歩けば、つまずくことはありません。この世の光を見ているからです。</span>
<span className="v" id="v10" data-v="10" data-xref="ヨハネの手紙第一 2:10–11; Proverbs 4:18–19; Jeremiah 13:16"> しかし、夜歩けばつまずきます。光がその人のうちにないからです。」</span>
<span className="v" id="v11" data-v="11" data-xref="Daniel 12:2; ヨハネの福音書 11:13; ヨハネの福音書 11:43–44"> イエスは、このように話され、それから、弟子たちに言われた。「わたしたちの友ラザロは眠っています。しかし、わたしは彼を眠りからさましに行くのです。」</span>
<span className="v" id="v12" data-v="12"> そこで弟子たちはイエスに言った。「主よ。眠っているのなら、彼は助かるでしょう。」</span>
<span className="v" id="v13" data-v="13" data-xref="マタイの福音書 9:24"> しかし、イエスは、ラザロの死のことを言われたのである。だが、彼らは眠った状態のことを言われたものと思った。</span>
<span className="v" id="v14" data-v="14" data-xref="ヨハネの福音書 16:25; ヨハネの福音書 16:29; ヨハネの福音書 10:24"> そこで、イエスはそのとき、はっきりと彼らに言われた。「ラザロは死んだのです。</span>
<span className="v" id="v15" data-v="15" data-xref="テモテへの手紙第二 2:10; ヨハネの福音書 14:10–11; Isaiah 54:15"> わたしは、あなたがたのため、すなわちあなたがたが信じるためには、わたしがその場に居合わせなかったことを喜んでいます。さあ、彼のところへ行きましょう。」</span>
<span className="v" id="v16" data-v="16" data-xref="ヨハネの福音書 13:37; マタイの福音書 10:3; ヨハネの福音書 21:2"> そこで、デドモと呼ばれるトマスが、弟子の仲間に言った。「私たちも行って、主といっしょに死のうではないか。」</span>
<span className="v" id="v17" data-v="17" data-xref="ヨハネの福音書 11:39; Hosea 6:2; 使徒の働き 2:27–31"> それで、イエスがおいでになってみると、ラザロは墓の中に入れられて四日もたっていた。</span>
<span className="v" id="v18" data-v="18" data-xref="ヨハネの黙示録 14:20; ヨハネの黙示録 21:16; ヨハネの福音書 6:19"> ベタニヤはエルサレムに近く、三千メートルほど離れた所にあった。</span>
<span className="v" id="v19" data-v="19" data-xref="Job 2:11; ヨハネの福音書 11:31; テサロニケ人への手紙第一 5:11"> 大ぜいのユダヤ人がマルタとマリヤのところに来ていた。その兄弟のことについて慰めるためであった。</span>
<span className="v" id="v20" data-v="20" data-xref="ルカの福音書 10:38–42; テサロニケ人への手紙第一 4:17; マタイの福音書 25:1"> マルタは、イエスが来られたと聞いて迎えに行った。マリヤは家ですわっていた。</span>
<span className="v" id="v21" data-v="21" data-xref="ヨハネの福音書 11:32; 1 Kings 17:18; マタイの福音書 9:18"> マルタはイエスに向かって言った。「主よ。もしここにいてくださったなら、私の兄弟は死ななかったでしょうに。</span>
<span className="v" id="v22" data-v="22" data-xref="ヨハネの福音書 9:31; ヨハネの福音書 11:41–42; マタイの福音書 28:18"> 今でも私は知っております。あなたが神にお求めになることは何でも、神はあなたにお与えになります。」</span>
<span className="v" id="v23" data-v="23" data-xref="ヨハネの福音書 11:43–44"> イエスは彼女に言われた。「あなたの兄弟はよみがえります。」</span>
<span className="v" id="v24" data-v="24" data-xref="Daniel 12:2–3; 使徒の働き 24:15; ヨハネの福音書 5:28–29"> マルタはイエスに言った。「私は、終わりの日のよみがえりの時に、彼がよみがえることを知っております。」</span>
<span className="v" id="v25" data-v="25" data-xref="テサロニケ人への手紙第一 4:14; ヨハネの福音書 3:36; ヨハネの手紙第一 5:11–12"> イエスは言われた。「わたしは、よみがえりです。いのちです。わたしを信じる者は、死んでも生きるのです。</span>
<span className="v" id="v26" data-v="26" data-xref="ヨハネの福音書 10:28; ヨハネの福音書 5:24; ローマ人への手紙 8:13"> また、生きていてわたしを信じる者は、決して死ぬことがありません。このことを信じますか。」</span>
<span className="v" id="v27" data-v="27" data-xref="マタイの福音書 16:16; ヨハネの福音書 6:69; ヨハネの福音書 6:14"> 彼女はイエスに言った。「はい。主よ。私は、あなたが世に来られる神の子キリストである、と信じております。」</span>
<span className="v" id="v28" data-v="28" data-xref="ヨハネの福音書 11:20; ヨハネの福音書 13:13; マルコの福音書 10:49"> こう言ってから、帰って行って、姉妹マリヤを呼び、「先生が見えています。あなたを呼んでおられます。」とそっと言った。</span>
<span className="v" id="v29" data-v="29" data-xref="Proverbs 15:23; Psalms 27:8; Song of Solomon 3:1–4"> マリヤはそれを聞くと、すぐ立ち上がって、イエスのところに行った。</span>
<span className="v" id="v30" data-v="30" data-xref="ヨハネの福音書 11:20"> さてイエスは、まだ村にはいらないで、マルタが出迎えた場所におられた。</span>
<span className="v" id="v31" data-v="31" data-xref="ヨハネの福音書 11:19; Genesis 37:35; 2 Samuel 12:16–18"> マリヤとともに家にいて、彼女を慰めていたユダヤ人たちは、マリヤが急いで立ち上がって出て行くのを見て、マリヤが墓に泣きに行くのだろうと思い、彼女について行った。</span>
<span className="v" id="v32" data-v="32" data-xref="ヨハネの福音書 11:21; ルカの福音書 17:16; ルカの福音書 5:8"> マリヤは、イエスのおられた所に来て、お目にかかると、その足もとにひれ伏して言った。「主よ。もしここにいてくださったなら、私の兄弟は死ななかったでしょうに。」</span>
<span className="v" id="v33" data-v="33" data-xref="ヨハネの福音書 11:38; ヨハネの福音書 12:27; マルコの福音書 3:5"> そこでイエスは、彼女が泣き、彼女といっしょに来たユダヤ人たちも泣いているのをご覧になると、霊の憤りを覚え、心の動揺を感じて、</span>
<span className="v" id="v34" data-v="34" data-xref="マルコの福音書 15:47; マタイの福音書 28:6; ヨハネの福音書 1:39"> 言われた。「彼をどこに置きましたか。」彼らはイエスに言った。「主よ。来てご覧ください。」</span>
<span className="v" id="v35" data-v="35" data-xref="ルカの福音書 19:41; ヘブル人への手紙 4:15; ヨハネの福音書 11:33"> イエスは涙を流された。</span>
<span className="v" id="v36" data-v="36" data-xref="ヨハネの福音書 11:3; ヨハネの手紙第一 3:1; ヨハネの手紙第一 4:9–10"> そこで、ユダヤ人たちは言った。「ご覧なさい。主はどんなに彼を愛しておられたことか。」</span>
<span className="v" id="v37" data-v="37" data-xref="ヨハネの福音書 9:6–7; ヨハネの福音書 11:32; ルカの福音書 23:39"> しかし、「盲人の目をあけたこの方が、あの人を死なせないでおくことはできなかったのか。」と言う者もいた。</span>
<span className="v" id="v38" data-v="38" data-xref="ヨハネの福音書 11:33; ルカの福音書 24:2; マタイの福音書 27:60"> そこでイエスは、またも心のうちに憤りを覚えながら、墓に来られた。墓はほら穴であって、石がそこに立てかけてあった。</span>
<span className="v" id="v39" data-v="39" data-xref="ヨハネの福音書 11:17; マルコの福音書 16:3; Psalms 49:7"> イエスは言われた。「その石を取りのけなさい。」死んだ人の姉妹マルタは言った。「主よ。もう臭くなっておりましょう。四日になりますから。」</span>
<span className="v" id="v40" data-v="40" data-xref="ヨハネの福音書 11:4; ヨハネの福音書 11:23–26; ローマ人への手紙 4:17–25"> イエスは彼女に言われた。「もしあなたが信じるなら、あなたは神の栄光を見る、とわたしは言ったではありませんか。」</span>
<span className="v" id="v41" data-v="41" data-xref="マタイの福音書 11:25; ヨハネの福音書 17:1; Psalms 123:1"> そこで、彼らは石を取りのけた。イエスは目を上げて、言われた。「父よ。わたしの願いを聞いてくださったことを感謝いたします。</span>
<span className="v" id="v42" data-v="42" data-xref="ヨハネの福音書 3:17; ヨハネの福音書 17:21; ヨハネの手紙第一 4:14"> わたしは、あなたがいつもわたしの願いを聞いてくださることを知っておりました。しかしわたしは、回りにいる群衆のために、この人々が、あなたがわたしをお遣わしになったことを信じるようになるために、こう申したのです。」</span>
<span className="v" id="v43" data-v="43" data-xref="2 Kings 4:33–36; 使徒の働き 9:40; 使徒の働き 9:34"> そして、イエスはそう言われると、大声で叫ばれた。「ラザロよ。出て来なさい。」</span>
<span className="v" id="v44" data-v="44" data-xref="ヨハネの福音書 5:25; ヨハネの福音書 20:7; ヨハネの福音書 11:25–26"> すると、死んでいた人が、手と足を長い布で巻かれたままで出て来た。彼の顔は布切れで包まれていた。イエスは彼らに言われた。「ほどいてやって、帰らせなさい。」</span>
<span className="v" id="v45" data-v="45" data-xref="ヨハネの福音書 2:23; ヨハネの福音書 11:19; ヨハネの福音書 10:41"> そこで、マリヤのところに来ていて、イエスがなさったことを見た多くのユダヤ人が、イエスを信じた。</span>
<span className="v" id="v46" data-v="46" data-xref="ヨハネの福音書 9:13; 使徒の働き 5:25; ヨハネの福音書 12:37"> しかし、そのうちの幾人かは、パリサイ人たちのところへ行って、イエスのなさったことを告げた。</span>
<span className="v" id="v47" data-v="47" data-xref="マタイの福音書 26:3; ヨハネの福音書 12:19; 使徒の働き 4:5–6"> そこで、祭司長とパリサイ人たちは議会を召集して言った。「われわれは何をしているのか。あの人が多くのしるしを行なっているというのに。</span>
<span className="v" id="v48" data-v="48" data-xref="テサロニケ人への手紙第一 2:15–16; マタイの福音書 23:35–38; マタイの福音書 27:25"> もしあの人をこのまま放っておくなら、すべての人があの人を信じるようになる。そうなると、ローマ人がやって来て、われわれの土地も国民も奪い取ることになる。」</span>
<span className="v" id="v49" data-v="49" data-xref="マタイの福音書 26:3; ヨハネの福音書 11:51; ヨハネの福音書 18:13–14"> しかし、彼らのうちのひとりで、その年の大祭司であったカヤパが、彼らに言った。「あなたがたは全然何もわかっていない。</span>
<span className="v" id="v50" data-v="50" data-xref="ヨハネの福音書 18:14; ルカの福音書 24:46; ローマ人への手紙 3:8"> ひとりの人が民の代わりに死んで、国民全体が滅びないほうが、あなたがたにとって得策だということも、考えに入れていない。」</span>
<span className="v" id="v51" data-v="51" data-xref="Daniel 9:26; コリント人への手紙第二 5:21; Exodus 28:30"> ところで、このことは彼が自分から言ったのではなくて、その年の大祭司であったので、イエスが国民のために死のうとしておられること、</span>
<span className="v" id="v52" data-v="52" data-xref="ヨハネの福音書 10:16; Isaiah 49:6; ヨハネの手紙第一 2:2"> また、ただ国民のためだけでなく、散らされている神の子たちを一つに集めるためにも死のうとしておられることを、預言したのである。</span>
<span className="v" id="v53" data-v="53" data-xref="使徒の働き 5:33; 使徒の働き 9:23; マルコの福音書 14:1"> そこで彼らは、その日から、イエスを殺すための計画を立てた。</span>
<span className="v" id="v54" data-v="54" data-xref="ヨハネの福音書 7:1; ヨハネの福音書 7:4; 2 Chronicles 13:19"> そのために、イエスはもはやユダヤ人たちの間を公然と歩くことをしないで、そこから荒野に近い地方に去り、エフライムという町にはいり、弟子たちとともにそこに滞在された。</span>
<span className="v" id="v55" data-v="55" data-xref="2 Chronicles 30:17–20; ヘブル人への手紙 9:13–14; ヨハネの福音書 6:4"> さて、ユダヤ人の過越の祭りが間近であった。多くの人々が、身を清めるために、過越の祭りの前にいなかからエルサレムに上って来た。</span>
<span className="v" id="v56" data-v="56" data-xref="ヨハネの福音書 7:11; ヨハネの福音書 11:7–8"> 彼らはイエスを捜し、宮の中に立って、互いに言った。「あなたがたはどう思いますか。あの方は祭りに来られることはないでしょうか。」</span>
<span className="v" id="v57" data-v="57" data-xref="ヨハネの福音書 9:22; ヨハネの福音書 8:59; ヨハネの福音書 5:16–18"> さて、祭司長、パリサイ人たちはイエスを捕えるために、イエスがどこにいるかを知っている者は届け出なければならないという命令を出していた。</span>

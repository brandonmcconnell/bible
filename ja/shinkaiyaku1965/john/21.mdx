<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨハネの福音書 6:1; ヨハネの福音書 6:23; マタイの福音書 28:16"> この後、イエスはテベリヤの湖畔で、もう一度ご自分を弟子たちに現わされた。その現わされた次第はこうであった。</span>
<span className="v" id="v2" data-v="2" data-xref="マタイの福音書 4:21–22; ヨハネの福音書 1:45–1; ヨハネの福音書 4:46"> シモン・ペテロ、デドモと呼ばれるトマス、ガリラヤのカナのナタナエル、ゼベダイの子たち、ほかにふたりの弟子がいっしょにいた。</span>
<span className="v" id="v3" data-v="3" data-xref="ルカの福音書 5:5; マタイの福音書 4:18–20; テサロニケ人への手紙第二 3:7–9"> シモン・ペテロが彼らに言った。「私は漁に行く。」彼らは言った。「私たちもいっしょに行きましょう。」彼らは出かけて、小舟に乗り込んだ。しかし、その夜は何もとれなかった。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネの福音書 20:14; ルカの福音書 24:15–16; ルカの福音書 24:31"> 夜が明けそめたとき、イエスは岸べに立たれた。けれども弟子たちには、それがイエスであることがわからなかった。</span>
<span className="v" id="v5" data-v="5" data-xref="ピリピ人への手紙 4:19; ピリピ人への手紙 4:11–13; ヨハネの手紙第一 2:13"> イエスは彼らに言われた。「子どもたちよ。食べる物がありませんね。」彼らは答えた。「はい。ありません。」</span>
<span className="v" id="v6" data-v="6" data-xref="ルカの福音書 5:4–7; 使徒の働き 2:41; ヨハネの福音書 2:5"> イエスは彼らに言われた。「舟の右側に網をおろしなさい。そうすれば、とれます。」そこで、彼らは網をおろした。すると、おびただしい魚のために、網を引き上げることができなかった。</span>
<span className="v" id="v7" data-v="7" data-xref="ヨハネの福音書 13:23; ヨハネの福音書 20:2; マタイの福音書 14:28–29"> そこで、イエスの愛されたあの弟子がペテロに言った。「主です。」すると、シモン・ペテロは、主であると聞いて、裸だったので、上着をまとって、湖に飛び込んだ。</span>
<span className="v" id="v8" data-v="8" data-xref="Deuteronomy 3:11"> しかし、ほかの弟子たちは、魚の満ちたその網を引いて、小舟でやって来た。陸地から遠くなく、百メートル足らずの距離だったからである。</span>
<span className="v" id="v9" data-v="9" data-xref="ヨハネの福音書 21:13; 1 Kings 19:5–6; ヨハネの福音書 21:10"> こうして彼らが陸地に上がったとき、そこに炭火とその上に載せた魚と、パンがあるのを見た。</span>
<span className="v" id="v10" data-v="10"> イエスは彼らに言われた。「あなたがたの今とった魚を幾匹か持って来なさい。」</span>
<span className="v" id="v11" data-v="11" data-xref="ルカの福音書 5:6–8; 使徒の働き 2:41"> シモン・ペテロは舟に上がって、網を陸地に引き上げた。それは百五十三匹の大きな魚でいっぱいであった。それほど多かったけれども、網は破れなかった。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒の働き 10:41; ルカの福音書 9:45; ヨハネの福音書 16:19"> イエスは彼らに言われた。「さあ来て、朝の食事をしなさい。」弟子たちは主であることを知っていたので、だれも「あなたはどなたですか。」とあえて尋ねる者はいなかった。</span>
<span className="v" id="v13" data-v="13" data-xref="ヨハネの福音書 21:9; 使徒の働き 10:41; ルカの福音書 24:42–43"> イエスは来て、パンを取り、彼らにお与えになった。また、魚も同じようにされた。</span>
<span className="v" id="v14" data-v="14" data-xref="ヨハネの福音書 20:26; ヨハネの福音書 20:19"> イエスが、死人の中からよみがえってから、弟子たちにご自分を現わされたのは、すでにこれで三度目である。</span>
<span className="v" id="v15" data-v="15" data-xref="Isaiah 40:11; ヨハネの手紙第一 4:19; ローマ人への手紙 15:1"> 彼らが食事を済ませたとき、イエスはシモン・ペテロに言われた。「ヨハネの子シモン。あなたは、この人たち以上に、わたしを愛しますか。」ペテロはイエスに言った。「はい。主よ。私があなたを愛することは、あなたがご存じです。」イエスは彼に言われた。「わたしの小羊を飼いなさい。」</span>
<span className="v" id="v16" data-v="16" data-xref="使徒の働き 20:28; ペテロの手紙第一 5:2; ペテロの手紙第一 2:25"> イエスは再び彼に言われた。「ヨハネの子シモン。あなたはわたしを愛しますか。」ペテロはイエスに言った。「はい。主よ。私があなたを愛することは、あなたがご存じです。」イエスは彼に言われた。「わたしの羊を牧しなさい。」</span>
<span className="v" id="v17" data-v="17" data-xref="ヨハネの福音書 13:38; ヨハネの福音書 16:30; マルコの福音書 14:72"> イエスは三度ペテロに言われた。「ヨハネの子シモン。あなたはわたしを愛しますか。」ペテロは、イエスが三度「あなたはわたしを愛しますか。」と言われたので、心を痛めてイエスに言った。「主よ。あなたはいっさいのことをご存じです。あなたは、私があなたを愛することを知っておいでになります。」イエスは彼に言われた。「わたしの羊を飼いなさい。</span>
<span className="v" id="v18" data-v="18" data-xref="ヨハネの福音書 13:36; 使徒の働き 12:3–4; 使徒の働き 21:11"> まことに、まことに、あなたに告げます。あなたは若かった時には、自分で帯を締めて、自分の歩きたい所を歩きました。しかし年をとると、あなたは自分の手を伸ばし、ほかの人があなたに帯をさせて、あなたの行きたくない所に連れて行きます。」</span>
<span className="v" id="v19" data-v="19" data-xref="ペテロの手紙第二 1:14; ヨハネの福音書 21:22; マタイの福音書 10:38"> これは、ペテロがどのような死に方をして、神の栄光を現わすかを示して、言われたことであった。こうお話しになってから、ペテロに言われた。「わたしに従いなさい。」</span>
<span className="v" id="v20" data-v="20" data-xref="ヨハネの福音書 21:7; ヨハネの福音書 20:2; ヨハネの福音書 21:24"> ペテロは振り向いて、イエスが愛された弟子があとについて来るのを見た。この弟子はあの晩餐のとき、イエスの右側にいて、「主よ。あなたを裏切る者はだれですか。」と言った者である。</span>
<span className="v" id="v21" data-v="21" data-xref="ルカの福音書 13:23–24; 使徒の働き 1:6–7; マタイの福音書 24:3–4"> ペテロは彼を見て、イエスに言った。「主よ。この人はどうですか。」</span>
<span className="v" id="v22" data-v="22" data-xref="ヨハネの黙示録 2:25; ヨハネの黙示録 3:11; マルコの福音書 9:1"> イエスはペテロに言われた。「わたしの来るまで彼が生きながらえるのをわたしが望むとしても、それがあなたに何のかかわりがありますか。あなたは、わたしに従いなさい。」</span>
<span className="v" id="v23" data-v="23" data-xref="Deuteronomy 29:29; Job 33:13; Daniel 4:35"> そこで、その弟子は死なないという話が兄弟たちの間に行き渡った。しかし、イエスはペテロに、その弟子が死なないと言われたのでなく、「わたしの来るまで彼が生きながらえるのをわたしが望むとしても、それがあなたに何のかかわりがありますか。」と言われたのである。</span>
<span className="v" id="v24" data-v="24" data-xref="ヨハネの福音書 19:35; ヨハネの福音書 15:27; ヨハネの手紙第一 5:6"> これらのことについてあかしした者、またこれらのことを書いた者は、その弟子である。そして、私たちは、彼のあかしが真実であることを、知っている。</span>
<span className="v" id="v25" data-v="25" data-xref="Psalms 40:5; ヨハネの福音書 20:30–31; Psalms 71:15"> イエスが行なわれたことは、ほかにもたくさんあるが、もしそれらをいちいち書きしるすなら、世界も、書かれた書物を入れることができまい、と私は思う。</span>

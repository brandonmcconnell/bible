<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨハネの福音書 5:16–18; ヨハネの福音書 4:3; マタイの福音書 21:38"> その後、イエスはガリラヤを巡っておられた。それは、ユダヤ人たちがイエスを殺そうとしていたので、ユダヤを巡りたいとは思われなかったからである。</span>
<span className="v" id="v2" data-v="2" data-xref="Zechariah 14:16–19; Deuteronomy 16:13–16; Exodus 23:16–17"> さて、仮庵の祭りというユダヤ人の祝いが近づいていた。</span>
<span className="v" id="v3" data-v="3" data-xref="マタイの福音書 12:46; ヨハネの福音書 7:5; ルカの福音書 8:19"> そこで、イエスの兄弟たちはイエスに向かって言った。「あなたの弟子たちもあなたがしているわざを見ることができるように、ここを去ってユダヤに行きなさい。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネの福音書 18:20; Proverbs 18:1–2; マタイの福音書 23:5"> 自分から公の場に出たいと思いながら、隠れた所で事を行なう者はありません。あなたがこれらの事を行なうのなら、自分を世に現わしなさい。」</span>
<span className="v" id="v5" data-v="5" data-xref="マルコの福音書 3:21; ヨハネの福音書 1:11–13; Micah 7:5–6"> 兄弟たちもイエスを信じていなかったのである。</span>
<span className="v" id="v6" data-v="6" data-xref="ヨハネの福音書 7:8; ヨハネの福音書 2:4; ヨハネの福音書 7:30"> そこでイエスは彼らに言われた。「わたしの時はまだ来ていません。しかし、あなたがたの時はいつでも来ているのです。</span>
<span className="v" id="v7" data-v="7" data-xref="ヨハネの福音書 15:18–19; ヨハネの福音書 3:19; ガラテヤ人への手紙 4:16"> 世はあなたがたを憎むことはできません。しかしわたしを憎んでいます。わたしが、世について、その行ないが悪いことをあかしするからです。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨハネの福音書 7:6; ヨハネの福音書 8:20; ヨハネの福音書 7:30"> あなたがたは祭りに上って行きなさい。わたしはこの祭りには行きません。わたしの時がまだ満ちていないからです。」</span>
<span className="v" id="v9" data-v="9"> こう言って、イエスはガリラヤにとどまられた。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="Amos 5:13; マタイの福音書 10:16; Isaiah 42:2–3"> しかし、兄弟たちが祭りに上ったとき、イエスご自身も、公にではなく、いわば内密に上って行かれた。</span>
<span className="v" id="v11" data-v="11" data-xref="ヨハネの福音書 11:56"> ユダヤ人たちは、祭りのとき、「あの方はどこにおられるのか。」と言って、イエスを捜していた。</span>
<span className="v" id="v12" data-v="12" data-xref="ヨハネの福音書 7:40–43; ヨハネの福音書 9:16; ヨハネの福音書 7:32"> そして群衆の間には、イエスについて、いろいろとひそひそ話がされていた。「良い人だ。」と言う者もあり、「違う。群衆を惑わしているのだ。」と言う者もいた。</span>
<span className="v" id="v13" data-v="13" data-xref="ヨハネの福音書 9:22; ヨハネの福音書 19:38; ヨハネの福音書 20:19"> しかし、ユダヤ人たちを恐れたため、イエスについて公然と語る者はひとりもいなかった。</span>
<span className="v" id="v14" data-v="14" data-xref="ヨハネの福音書 7:28; ルカの福音書 19:47; ヨハネの福音書 7:37"> しかし、祭りもすでに中ごろになったとき、イエスは宮に上って教え始められた。</span>
<span className="v" id="v15" data-v="15" data-xref="ルカの福音書 4:22; マタイの福音書 7:28–29; マタイの福音書 13:54"> ユダヤ人たちは驚いて言った。「この人は正規に学んだことがないのに、どうして学問があるのか。」</span>
<span className="v" id="v16" data-v="16" data-xref="ヨハネの福音書 14:10; ヨハネの福音書 14:24; ヨハネの福音書 17:8"> そこでイエスは彼らに答えて言われた。「わたしの教えは、わたしのものではなく、わたしを遣わした方のものです。</span>
<span className="v" id="v17" data-v="17" data-xref="ヨハネの福音書 8:31–32; ヨハネの福音書 8:43; Jeremiah 31:33–34"> だれでも神のみこころを行なおうと願うなら、その人には、この教えが神から出たものか、わたしが自分から語っているのかがわかります。</span>
<span className="v" id="v18" data-v="18" data-xref="ヨハネの福音書 5:41; コリント人への手紙第一 10:31–33; ヨハネの福音書 13:31–32"> 自分から語る者は、自分の栄光を求めます。しかし自分を遣わした方の栄光を求める者は真実であり、その人には不正がありません。</span>
<span className="v" id="v19" data-v="19" data-xref="ヨハネの福音書 1:17; ヨハネの福音書 11:53; マタイの福音書 12:14"> モーセがあなたがたに律法を与えたではありませんか。それなのに、あなたがたはだれも、律法を守っていません。あなたがたは、なぜわたしを殺そうとするのですか。」</span>
<span className="v" id="v20" data-v="20" data-xref="ヨハネの福音書 10:20; ヨハネの福音書 8:48; ヨハネの福音書 8:52"> 群衆は答えた。「あなたは悪霊につかれています。だれがあなたを殺そうとしているのですか。」</span>
<span className="v" id="v21" data-v="21" data-xref="ヨハネの福音書 7:23; ヨハネの福音書 5:2–11"> イエスは彼らに答えて言われた。「わたしは一つのわざをしました。それであなたがたはみな驚いています。</span>
<span className="v" id="v22" data-v="22" data-xref="Leviticus 12:3; Genesis 17:10–14; ローマ人への手紙 4:9–11"> モーセはこのためにあなたがたに割礼を与えました。――ただし、それはモーセから始まったのではなく、先祖たちからです。――それで、あなたがたは安息日にも人に割礼を施しています。</span>
<span className="v" id="v23" data-v="23" data-xref="マタイの福音書 12:5; ヨハネの福音書 5:14–16; マタイの福音書 12:2"> もし、人がモーセの律法が破られないようにと、安息日にも割礼を受けるのなら、わたしが安息日に人の全身をすこやかにしたからといって、何でわたしに腹を立てるのですか。</span>
<span className="v" id="v24" data-v="24" data-xref="Isaiah 11:3–4; ヤコブの手紙 2:9; ヨハネの福音書 8:15"> うわべによって人をさばかないで、正しいさばきをしなさい。」</span>
<span className="v" id="v25" data-v="25" data-xref="ヨハネの福音書 7:10–11"> そこで、エルサレムのある人たちが言った。「この人は、彼らが殺そうとしている人ではないか。</span>
<span className="v" id="v26" data-v="26" data-xref="テモテへの手紙第二 1:7–8; ヨハネの福音書 7:48; ヨハネの福音書 12:42"> 見なさい。この人は公然と語っているのに、彼らはこの人に何も言わない。議員たちは、この人がキリストであることを、ほんとうに知ったのだろうか。</span>
<span className="v" id="v27" data-v="27" data-xref="Micah 5:2; ヨハネの福音書 7:41–42; ヨハネの福音書 6:42"> けれども、私たちはこの人がどこから来たのか知っている。しかし、キリストが来られるとき、それが、どこからか知っている者はだれもいないのだ。」</span>
<span className="v" id="v28" data-v="28" data-xref="ヨハネの福音書 8:42; ヨハネの福音書 8:19; ヨハネの福音書 8:26"> イエスは、宮で教えておられるとき、大声をあげて言われた。「あなたがたはわたしを知っており、また、わたしがどこから来たかも知っています。しかし、わたしは自分で来たのではありません。わたしを遣わした方は真実です。あなたがたは、その方を知らないのです。</span>
<span className="v" id="v29" data-v="29" data-xref="ヨハネの福音書 8:55; マタイの福音書 11:27; ヨハネの福音書 17:18"> わたしはその方を知っています。なぜなら、わたしはその方から出たのであり、その方がわたしを遣わしたからです。」</span>
<span className="v" id="v30" data-v="30" data-xref="ヨハネの福音書 8:20; ヨハネの福音書 10:39; ヨハネの福音書 7:6"> そこで人々はイエスを捕えようとしたが、しかし、だれもイエスに手をかけた者はなかった。イエスの時が、まだ来ていなかったからである。</span>
<span className="v" id="v31" data-v="31" data-xref="ヨハネの福音書 12:42; マタイの福音書 12:23; ヨハネの福音書 10:41–42"> 群衆のうちの多くの者がイエスを信じて言った。「キリストが来られても、この方がしているよりも多くのしるしを行なわれるだろうか。」</span>
<span className="v" id="v32" data-v="32" data-xref="ヨハネの福音書 18:3; ルカの福音書 22:52–53; ヨハネの福音書 11:47–48"> パリサイ人は、群衆がイエスについてこのようなことをひそひそと話しているのを耳にした。それで祭司長、パリサイ人たちは、イエスを捕えようとして、役人たちを遣わした。</span>
<span className="v" id="v33" data-v="33" data-xref="ヨハネの福音書 16:5; ヨハネの福音書 13:33; マルコの福音書 16:19"> そこでイエスは言われた。「まだしばらくの間、わたしはあなたがたといっしょにいて、それから、わたしを遣わした方のもとに行きます。</span>
<span className="v" id="v34" data-v="34" data-xref="Proverbs 1:24–31; ヨハネの福音書 13:33–36; ヨハネの福音書 14:6"> あなたがたはわたしを捜しますが、見いだすことはありません。また、わたしがいる所に、あなたがたは来ることができません。」</span>
<span className="v" id="v35" data-v="35" data-xref="ヤコブの手紙 1:1; Isaiah 11:12; Zephaniah 3:10"> そこで、ユダヤ人たちは互いに言った。「私たちには、見つからないという。それならあの人はどこへ行こうとしているのか。まさかギリシヤ人の中に離散している人々のところへ行って、ギリシヤ人を教えるつもりではあるまい。</span>
<span className="v" id="v36" data-v="36" data-xref="ヨハネの福音書 3:9; ヨハネの福音書 7:34; ヨハネの福音書 12:34"> 『あなたがたはわたしを捜すが、見いだすことはない。』また『わたしのいる所にあなたがたは来ることができない。』とあの人が言ったこのことばは、どういう意味だろうか。」</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="Isaiah 55:1; ヨハネの福音書 4:14; ヨハネの福音書 6:35"> さて、祭りの終わりの大いなる日に、イエスは立って、大声で言われた。「だれでも渇いているなら、わたしのもとに来て飲みなさい。</span>
<span className="v" id="v38" data-v="38" data-xref="ヨハネの福音書 4:14; Isaiah 44:3; Isaiah 58:11"> わたしを信じる者は、聖書が言っているとおりに、その人の心の奥底から、生ける水の川が流れ出るようになる。」</span>
<span className="v" id="v39" data-v="39" data-xref="使徒の働き 2:17; Joel 2:28; ヨハネの福音書 14:16–17"> これは、イエスを信じる者が後になってから受ける御霊のことを言われたのである。イエスはまだ栄光を受けておられなかったので、御霊はまだ注がれていなかったからである。</span>
<span className="v" id="v40" data-v="40" data-xref="マタイの福音書 21:11; ヨハネの福音書 1:21; ヨハネの福音書 6:14"> このことばを聞いて、群衆のうちのある者は、「あの方は、確かにあの預言者なのだ。」と言い、</span>
<span className="v" id="v41" data-v="41" data-xref="ヨハネの福音書 7:52; ヨハネの福音書 1:46; ヨハネの福音書 1:49"> またある者は、「この方はキリストだ。」と言った。またある者は言った。「まさか、キリストはガリラヤからは出ないだろう。</span>
<span className="v" id="v42" data-v="42" data-xref="Micah 5:2; マタイの福音書 2:5; ルカの福音書 2:4"> キリストはダビデの子孫から、またダビデがいたベツレヘムの村から出る、と聖書が言っているではないか。」</span>
<span className="v" id="v43" data-v="43" data-xref="ヨハネの福音書 9:16; ヨハネの福音書 10:19; ヨハネの福音書 7:12"> そこで、群衆の間にイエスのことで分裂が起こった。</span>
<span className="v" id="v44" data-v="44" data-xref="ヨハネの福音書 7:30; 使徒の働き 23:11; ヨハネの福音書 8:20"> その中にはイエスを捕えたいと思った者もいたが、イエスに手をかけた者はなかった。</span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="ヨハネの福音書 7:32; 使徒の働き 5:21–27"> それから役人たちは祭司長、パリサイ人たちのもとに帰って来た。彼らは役人たちに言った。「なぜあの人を連れて来なかったのか。」</span>
<span className="v" id="v46" data-v="46" data-xref="マタイの福音書 7:28–29; ルカの福音書 4:22; ヨハネの福音書 7:26"> 役人たちは答えた。「あの人が話すように話した人は、いまだかつてありません。」</span>
<span className="v" id="v47" data-v="47" data-xref="ヨハネの福音書 7:12; コリント人への手紙第二 6:8; 2 Kings 18:32"> すると、パリサイ人が答えた。「おまえたちも惑わされているのか。</span>
<span className="v" id="v48" data-v="48" data-xref="ヨハネの福音書 12:42; コリント人への手紙第一 1:20; コリント人への手紙第一 2:8"> 議員とかパリサイ人のうちで、だれかイエスを信じた者があったか。</span>
<span className="v" id="v49" data-v="49" data-xref="コリント人への手紙第一 1:20–21; ヨハネの福音書 9:40; ヨハネの福音書 9:34"> だが、律法を知らないこの群衆は、のろわれている。」</span>
<span className="v" id="v50" data-v="50" data-xref="ヨハネの福音書 19:39; ヨハネの福音書 3:1–2"> 彼らのうちのひとりで、イエスのもとに来たことのあるニコデモが彼らに言った。</span>
<span className="v" id="v51" data-v="51" data-xref="Proverbs 18:13; Deuteronomy 1:17; Deuteronomy 19:15–19"> 「私たちの律法では、まずその人から直接聞き、その人が何をしているのか知ったうえでなければ、判決を下さないのではないか。」</span>
<span className="v" id="v52" data-v="52" data-xref="ヨハネの福音書 7:41; ヨハネの福音書 1:46; Isaiah 9:1–2"> 彼らは答えて言った。「あなたもガリラヤの出身なのか。調べてみなさい。ガリラヤから預言者は起こらない。」</span>
<span className="v" id="v53" data-v="53" data-xref="Psalms 33:10; Job 5:12–13; Psalms 76:10"> ［そして人々はそれぞれ家に帰った。</span>
</div>

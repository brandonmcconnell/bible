<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨハネの福音書 12:23; ヨハネの手紙第一 4:19; ヨハネの福音書 13:34"> さて、過越の祭りの前に、この世を去って父のみもとに行くべき自分の時が来たことを知られたので、世にいる自分のものを愛されたイエスは、その愛を残るところなく示された。</span>
<span className="v" id="v2" data-v="2" data-xref="ヤコブの手紙 1:13–17; 使徒の働き 5:3; ヨハネの福音書 13:26–27"> 夕食の間のことであった。悪魔はすでにシモンの子イスカリオテ・ユダの心に、イエスを売ろうとする思いを入れていたが、</span>
<span className="v" id="v3" data-v="3" data-xref="ヨハネの福音書 3:35; マタイの福音書 11:27; ヘブル人への手紙 1:2"> イエスは、父が万物を自分の手に渡されたことと、ご自分が父から来て父に行くことを知られ、</span>
<span className="v" id="v4" data-v="4" data-xref="ルカの福音書 22:27; コリント人への手紙第二 8:9; ルカの福音書 12:37"> 夕食の席から立ち上がって、上着を脱ぎ、手ぬぐいを取って腰にまとわれた。</span>
<span className="v" id="v5" data-v="5" data-xref="ルカの福音書 7:44; Psalms 51:2; Genesis 18:4"> それから、たらいに水を入れ、弟子たちの足を洗って、腰にまとっておられる手ぬぐいで、ふき始められた。</span>
<span className="v" id="v6" data-v="6" data-xref="マタイの福音書 3:11–14; ヨハネの福音書 1:27; ルカの福音書 5:8"> こうして、イエスはシモン・ペテロのところに来られた。ペテロはイエスに言った。「主よ。あなたが、私の足を洗ってくださるのですか。」</span>
<span className="v" id="v7" data-v="7" data-xref="Daniel 12:8; ヨハネの福音書 12:16; ヨハネの福音書 14:26"> イエスは答えて言われた。「わたしがしていることは、今はあなたにはわからないが、あとでわかるようになります。」</span>
<span className="v" id="v8" data-v="8" data-xref="Ezekiel 36:25; 使徒の働き 22:16; テトスへの手紙 3:5"> ペテロはイエスに言った。「決して私の足をお洗いにならないでください。」イエスは答えられた。「もしわたしが洗わなければ、あなたはわたしと何の関係もありません。」</span>
<span className="v" id="v9" data-v="9" data-xref="Psalms 51:7; Psalms 51:2; ペテロの手紙第一 3:21"> シモン・ペテロは言った。「主よ。私の足だけでなく、手も頭も洗ってください。」</span>
<span className="v" id="v10" data-v="10" data-xref="ヨハネの福音書 15:3; コリント人への手紙第二 7:1; コリント人への手紙第二 5:17"> イエスは彼に言われた。「水浴した者は、足以外は洗う必要がありません。全身きよいのです。あなたがたはきよいのですが、みながそうではありません。」</span>
<span className="v" id="v11" data-v="11" data-xref="ヨハネの福音書 13:26; ヨハネの福音書 13:2; ヨハネの福音書 13:21"> イエスはご自分を裏切る者を知っておられた。それで、「みながきよいのではない。」と言われたのである。</span>
<span className="v" id="v12" data-v="12" data-xref="ヨハネの福音書 13:7; ヨハネの福音書 13:4; Ezekiel 24:24"> イエスは、彼らの足を洗い終わり、上着を着けて、再び席に着いて、彼らに言われた。「わたしがあなたがたに何をしたか、わかりますか。</span>
<span className="v" id="v13" data-v="13" data-xref="ルカの福音書 6:46; コリント人への手紙第一 12:3; ヨハネの福音書 11:28"> あなたがたはわたしを先生とも主とも呼んでいます。あなたがたがそう言うのはよい。わたしはそのような者だからです。</span>
<span className="v" id="v14" data-v="14" data-xref="ペテロの手紙第一 5:5; 使徒の働き 20:35; ローマ人への手紙 12:16"> それで、主であり師であるこのわたしが、あなたがたの足を洗ったのですから、あなたがたもまた互いに足を洗い合うべきです。</span>
<span className="v" id="v15" data-v="15" data-xref="ヨハネの手紙第一 2:6; マタイの福音書 11:29; ペテロの手紙第一 3:17–18"> わたしがあなたがたにしたとおりに、あなたがたもするように、わたしはあなたがたに模範を示したのです。</span>
<span className="v" id="v16" data-v="16" data-xref="ルカの福音書 6:40; ヨハネの福音書 15:20; マタイの福音書 10:24–25"> まことに、まことに、あなたがたに告げます。しもべはその主人にまさらず、遣わされた者は遣わした者にまさるものではありません。</span>
<span className="v" id="v17" data-v="17" data-xref="ルカの福音書 11:28; ヤコブの手紙 4:17; ヤコブの手紙 1:25"> あなたがたがこれらのことを知っているのなら、それを行なうときに、あなたがたは祝福されるのです。</span>
<span className="v" id="v18" data-v="18" data-xref="Psalms 41:9; マタイの福音書 26:23; ヨハネの福音書 17:12"> わたしは、あなたがた全部の者について言っているのではありません。わたしは、わたしが選んだ者を知っています。しかし聖書に『わたしのパンを食べている者が、わたしに向かってかかとを上げた。』と書いてあることは成就するのです。</span>
<span className="v" id="v19" data-v="19" data-xref="Isaiah 43:10; ヨハネの福音書 14:29; ヨハネの福音書 16:4"> わたしは、そのことが起こる前に、今あなたがたに話しておきます。そのことが起こったときに、わたしがその人であることをあなたがたが信じるためです。</span>
<span className="v" id="v20" data-v="20" data-xref="ルカの福音書 10:16; ルカの福音書 9:48; マタイの福音書 25:40"> まことに、まことに、あなたがたに告げます。わたしの遣わす者を受け入れる者は、わたしを受け入れるのです。わたしを受け入れる者は、わたしを遣わした方を受け入れるのです。」</span>
<span className="v" id="v21" data-v="21" data-xref="ヨハネの福音書 13:18; マタイの福音書 26:21; マルコの福音書 14:18"> イエスは、これらのことを話されたとき、霊の激動を感じ、あかしして言われた。「まことに、まことに、あなたがたに告げます。あなたがたのうちのひとりが、わたしを裏切ります。」</span>
<span className="v" id="v22" data-v="22" data-xref="ルカの福音書 22:23; マタイの福音書 26:22; マルコの福音書 14:19"> 弟子たちは、だれのことを言われたのか、わからずに当惑して、互いに顔を見合わせていた。</span>
<span className="v" id="v23" data-v="23" data-xref="ヨハネの福音書 19:26; ヨハネの福音書 21:7; ヨハネの福音書 21:20"> 弟子のひとりで、イエスが愛しておられた者が、イエスの右側で席に着いていた。</span>
<span className="v" id="v24" data-v="24" data-xref="使徒の働き 12:17; ルカの福音書 1:22; 使徒の働き 13:16"> そこで、シモン・ペテロが彼に合図をして言った。「だれのことを言っておられるのか、知らせなさい。」</span>
<span className="v" id="v25" data-v="25" data-xref="ヨハネの福音書 21:20; Genesis 44:4–12; Esther 7:5"> その弟子は、イエスの右側で席に着いたまま、イエスに言った。「主よ。それはだれですか。」</span>
<span className="v" id="v26" data-v="26" data-xref="マタイの福音書 26:23; ヨハネの福音書 13:30; マルコの福音書 14:19–20"> イエスは答えられた。「それはわたしがパン切れを浸して与える者です。」それからイエスは、パン切れを浸し、取って、イスカリオテ・シモンの子ユダにお与えになった。</span>
<span className="v" id="v27" data-v="27" data-xref="ルカの福音書 22:3; ヨハネの福音書 13:2; Ecclesiastes 9:3"> 彼がパン切れを受けると、そのとき、サタンが彼にはいった。そこで、イエスは彼に言われた。「あなたがしようとしていることを、今すぐしなさい。」</span>
<span className="v" id="v28" data-v="28"> 席に着いている者で、イエスが何のためにユダにそう言われたのか知っている者は、だれもなかった。</span>
<span className="v" id="v29" data-v="29" data-xref="ヨハネの福音書 12:5–6; ヨハネの福音書 13:1; エペソ人への手紙 4:28"> ユダが金入れを持っていたので、イエスが彼に、「祭りのために入用の物を買え。」と言われたのだとか、または、貧しい人々に何か施しをするように言われたのだとか思った者も中にはいた。</span>
<span className="v" id="v30" data-v="30" data-xref="Isaiah 59:7; Job 24:13–15; Proverbs 4:16"> ユダは、パン切れを受けるとすぐ、外に出て行った。すでに夜であった。</span>
<span className="v" id="v31" data-v="31" data-xref="ヨハネの福音書 14:13; ペテロの手紙第一 4:11; ヨハネの福音書 7:39"> ユダが出て行ったとき、イエスは言われた。「今こそ人の子は栄光を受けました。また、神は人の子によって栄光をお受けになりました。</span>
<span className="v" id="v32" data-v="32" data-xref="ヨハネの黙示録 22:1; Isaiah 53:10–12; ヨハネの福音書 17:4–6"> 神が、人の子によって栄光をお受けになったのであれば、神も、ご自身によって人の子に栄光をお与えになります。しかも、ただちにお与えになります。</span>
<span className="v" id="v33" data-v="33" data-xref="ヨハネの福音書 7:33–34; ヨハネの福音書 8:21–24; ヨハネの福音書 16:16–22"> 子どもたちよ。わたしはいましばらくの間、あなたがたといっしょにいます。あなたがたはわたしを捜すでしょう。そして、『わたしが行く所へは、あなたがたは来ることができない。』とわたしがユダヤ人たちに言ったように、今はあなたがたにも言うのです。</span>
<span className="v" id="v34" data-v="34" data-xref="エペソ人への手紙 5:2; Leviticus 19:18; ヨハネの福音書 15:17"> あなたがたに新しい戒めを与えましょう。あなたがたは互いに愛し合いなさい。わたしがあなたがたを愛したように、そのように、あなたがたも互いに愛し合いなさい。</span>
<span className="v" id="v35" data-v="35" data-xref="ヨハネの手紙第一 4:20–21; ヨハネの手紙第一 3:10–14; ヨハネの手紙第一 2:10"> もしあなたがたの互いの間に愛があるなら、それによって、あなたがたがわたしの弟子であることを、すべての人が認めるのです。」</span>
<span className="v" id="v36" data-v="36" data-xref="ペテロの手紙第二 1:14; ヨハネの福音書 13:33; ヨハネの福音書 21:21–22"> シモン・ペテロがイエスに言った。「主よ。どこにおいでになるのですか。」イエスは答えられた。「わたしが行く所に、あなたは今はついて来ることができません。しかし後にはついて来ます。」</span>
<span className="v" id="v37" data-v="37" data-xref="使徒の働き 21:13; 使徒の働き 20:24; マルコの福音書 14:27–31"> ペテロはイエスに言った。「主よ。なぜ今はあなたについて行くことができないのですか。あなたのためにはいのちも捨てます。」</span>
<span className="v" id="v38" data-v="38" data-xref="ルカの福音書 22:34; マタイの福音書 26:34; マルコの福音書 14:30"> イエスは答えられた。「わたしのためにはいのちも捨てる、と言うのですか。まことに、まことに、あなたに告げます。鶏が鳴くまでに、あなたは三度わたしを知らないと言います。」</span>

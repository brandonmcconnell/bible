<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ペテロの手紙第一 2:8; マタイの福音書 13:21; マタイの福音書 26:31–33"> これらのことをあなたがたに話したのは、あなたがたがつまずくことのないためです。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネの福音書 9:22; 使徒の働き 26:9–11; ローマ人への手紙 10:2–3"> 人々はあなたがたを会堂から追放するでしょう。事実、あなたがたを殺す者がみな、そうすることで自分は神に奉仕しているのだと思う時が来ます。</span>
<span className="v" id="v3" data-v="3" data-xref="ヨハネの福音書 15:21; ヨハネの福音書 17:25; ヨハネの福音書 8:55"> 彼らがこういうことを行なうのは、父をもわたしをも知らないからです。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネの福音書 14:29; マルコの福音書 13:23; ヨハネの福音書 17:12–13"> しかし、わたしがこれらのことをあなたがたに話したのは、その時が来れば、わたしがそれについて話したことを、あなたがたが思い出すためです。わたしが初めからこれらのことをあなたがたに話さなかったのは、わたしがあなたがたといっしょにいたからです。</span>
<span className="v" id="v5" data-v="5" data-xref="ヨハネの福音書 13:36; ヨハネの福音書 7:33; ヨハネの福音書 16:28"> しかし今わたしは、わたしを遣わした方のもとに行こうとしています。しかし、あなたがたのうちには、ひとりとして、どこに行くのですかと尋ねる者がありません。</span>
<span className="v" id="v6" data-v="6" data-xref="ヨハネの福音書 14:1; ヨハネの福音書 16:20–22; ルカの福音書 24:17"> かえって、わたしがこれらのことをあなたがたに話したために、あなたがたの心は悲しみでいっぱいになっています。</span>
<span className="v" id="v7" data-v="7" data-xref="ヨハネの福音書 14:26; ヨハネの福音書 14:16–17; ヨハネの福音書 15:26"> しかし、わたしは真実を言います。わたしが去って行くことは、あなたがたにとって益なのです。それは、もしわたしが去って行かなければ、助け主があなたがたのところに来ないからです。しかし、もし行けば、わたしは助け主をあなたがたのところに遣わします。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒の働き 2:37; ユダの手紙 1:15; Zechariah 12:10"> その方が来ると、罪について、義について、さばきについて、世にその誤りを認めさせます。</span>
<span className="v" id="v9" data-v="9" data-xref="ヨハネの福音書 15:22–25; ヨハネの福音書 8:23–24; ヨハネの福音書 12:47–48"> 罪についてというのは、彼らがわたしを信じないからです。</span>
<span className="v" id="v10" data-v="10" data-xref="コリント人への手紙第二 5:21; ペテロの手紙第一 3:18; ローマ人への手紙 10:3–4"> また、義についてとは、わたしが父のもとに行き、あなたがたがもはやわたしを見なくなるからです。</span>
<span className="v" id="v11" data-v="11" data-xref="ヨハネの福音書 12:31; ヨハネの手紙第一 3:8; ヘブル人への手紙 2:14"> さばきについてとは、この世を支配する者がさばかれたからです。</span>
<span className="v" id="v12" data-v="12" data-xref="マルコの福音書 4:33; ヨハネの福音書 15:15; コリント人への手紙第一 3:1–2"> わたしには、あなたがたに話すことがまだたくさんありますが、今あなたがたはそれに耐える力がありません。</span>
<span className="v" id="v13" data-v="13" data-xref="ヨハネの福音書 14:26; コリント人への手紙第一 2:10–13; ヨハネの福音書 14:17"> しかし、その方、すなわち真理の御霊が来ると、あなたがたをすべての真理に導き入れます。御霊は自分から語るのではなく、聞くままを話し、また、やがて起ころうとしていることをあなたがたに示すからです。</span>
<span className="v" id="v14" data-v="14" data-xref="ヨハネの手紙第一 4:13–14; コリント人への手紙第二 3:14–18; ヨハネの福音書 15:26"> 御霊はわたしの栄光を現わします。わたしのものを受けて、あなたがたに知らせるからです。</span>
<span className="v" id="v15" data-v="15" data-xref="ヨハネの福音書 17:10; マタイの福音書 11:27; ヨハネの福音書 3:35"> 父が持っておられるものはみな、わたしのものです。ですからわたしは、御霊がわたしのものを受けて、あなたがたに知らせると言ったのです。</span>
<span className="v" id="v16" data-v="16" data-xref="ヨハネの福音書 7:33; 使徒の働き 1:3; ヨハネの福音書 14:18–24"> しばらくするとあなたがたは、もはやわたしを見なくなります。しかし、またしばらくするとわたしを見ます。」</span>
<span className="v" id="v17" data-v="17" data-xref="ヨハネの福音書 16:16; マルコの福音書 9:32; ヨハネの福音書 16:5"> そこで、弟子たちのうちのある者は互いに言った。「『しばらくするとあなたがたは、わたしを見なくなる。しかし、またしばらくするとわたしを見る。』また『わたしは父のもとに行くからだ。』と主が言われるのは、どういうことなのだろう。」</span>
<span className="v" id="v18" data-v="18" data-xref="ルカの福音書 24:25; マタイの福音書 16:9–11; ヘブル人への手紙 5:12"> そこで、彼らは「しばらくすると、と主が言われるのは何のことだろうか。私たちには主の言われることがわからない。」と言った。</span>
<span className="v" id="v19" data-v="19" data-xref="ヨハネの福音書 16:30; ヨハネの福音書 16:16; ヨハネの福音書 14:19"> イエスは、彼らが質問したがっていることを知って、彼らに言われた。「『しばらくするとあなたがたは、わたしを見なくなる。しかし、またしばらくするとわたしを見る。』とわたしが言ったことについて、互いに論じ合っているのですか。</span>
<span className="v" id="v20" data-v="20" data-xref="ヤコブの手紙 1:2; マタイの福音書 5:4; Psalms 126:5–6"> まことに、まことに、あなたがたに告げます。あなたがたは泣き、嘆き悲しむが、世は喜ぶのです。あなたがたは悲しむが、しかし、あなたがたの悲しみは喜びに変わります。</span>
<span className="v" id="v21" data-v="21" data-xref="Psalms 113:9; Isaiah 13:8; テサロニケ人への手紙第一 5:3"> 女が子を産むときには、その時が来たので苦しみます。しかし、子を産んでしまうと、ひとりの人が世に生まれた喜びのために、もはやその激しい苦痛を忘れてしまいます。</span>
<span className="v" id="v22" data-v="22" data-xref="ペテロの手紙第一 1:8; 使徒の働き 13:52; ヨハネの福音書 16:6"> あなたがたにも、今は悲しみがあるが、わたしはもう一度あなたがたに会います。そうすれば、あなたがたの心は喜びに満たされます。そして、その喜びをあなたがたから奪い去る者はありません。</span>
<span className="v" id="v23" data-v="23" data-xref="ヨハネの福音書 15:7; ヨハネの福音書 14:13–14; マタイの福音書 21:22"> その日には、あなたがたはもはや、わたしに何も尋ねません。まことに、まことに、あなたがたに告げます。あなたがたが父に求めることは何でも、父は、わたしの名によってそれをあなたがたにお与えになります。</span>
<span className="v" id="v24" data-v="24" data-xref="マタイの福音書 7:7–8; ヤコブの手紙 4:2–3; ヨハネの福音書 15:11"> あなたがたは今まで、何もわたしの名によって求めたことはありません。求めなさい。そうすれば受けるのです。それはあなたがたの喜びが満ち満ちたものとなるためです。</span>
<span className="v" id="v25" data-v="25" data-xref="ヨハネの福音書 16:12; マルコの福音書 4:13; マタイの福音書 13:34–35"> これらのことを、わたしはあなたがたにたとえで話しました。もはやたとえでは話さないで、父についてはっきりと告げる時が来ます。</span>
<span className="v" id="v26" data-v="26" data-xref="ローマ人への手紙 8:34; ヨハネの福音書 17:24; ヨハネの福音書 17:19"> その日には、あなたがたはわたしの名によって求めるのです。わたしはあなたがたに代わって父に願ってあげようとは言いません。</span>
<span className="v" id="v27" data-v="27" data-xref="ヨハネの福音書 14:21; ヨハネの福音書 14:23; ヨハネの福音書 17:23"> それはあなたがたがわたしを愛し、また、わたしを神から出て来た者と信じたので、父ご自身があなたがたを愛しておられるからです。</span>
<span className="v" id="v28" data-v="28" data-xref="ヨハネの福音書 13:1; ヨハネの福音書 13:3; ヨハネの福音書 8:14"> わたしは父から出て、世に来ました。もう一度、わたしは世を去って父のみもとに行きます。」</span>
<span className="v" id="v29" data-v="29" data-xref="ヨハネの福音書 16:25"> 弟子たちは言った。「ああ、今あなたははっきりとお話しになって、何一つたとえ話はなさいません。</span>
<span className="v" id="v30" data-v="30" data-xref="ヨハネの福音書 21:17; ヨハネの福音書 17:8; ヨハネの福音書 16:17"> いま私たちは、あなたがいっさいのことをご存じで、だれもあなたにお尋ねする必要がないことがわかりました。これで、私たちはあなたが神から来られたことを信じます。」</span>
<span className="v" id="v31" data-v="31" data-xref="ルカの福音書 9:44–45; ヨハネの福音書 13:38"> イエスは彼らに答えられた。「あなたがたは今、信じているのですか。</span>
<span className="v" id="v32" data-v="32" data-xref="Zechariah 13:7; マタイの福音書 26:31; ヨハネの福音書 8:29"> 見なさい。あなたがたが散らされて、それぞれ自分の家に帰り、わたしをひとり残す時が来ます。いや、すでに来ています。しかし、わたしはひとりではありません。父がわたしといっしょにおられるからです。</span>
<span className="v" id="v33" data-v="33" data-xref="ヨハネの福音書 14:27; ヨハネの手紙第一 5:4; テサロニケ人への手紙第二 3:16"> わたしがこれらのことをあなたがたに話したのは、あなたがたがわたしにあって平安を持つためです。あなたがたは、世にあっては患難があります。しかし、勇敢でありなさい。わたしはすでに世に勝ったのです。」</span>

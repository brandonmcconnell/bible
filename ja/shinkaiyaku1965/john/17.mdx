<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨハネの福音書 13:31–32; ヨハネの福音書 17:4–5; ピリピ人への手紙 2:9–11"> イエスはこれらのことを話してから、目を天に向けて、言われた。「父よ。時が来ました。あなたの子があなたの栄光を現わすために、子の栄光を現わしてください。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネの福音書 10:28–29; ヨハネの福音書 6:39; Daniel 7:14"> それは子が、あなたからいただいたすべての者に、永遠のいのちを与えるため、あなたは、すべての人を支配する権威を子にお与えになったからです。</span>
<span className="v" id="v3" data-v="3" data-xref="ヨハネの手紙第一 5:20; ヨハネの手紙第一 5:11–12; Jeremiah 9:23–24"> その永遠のいのちとは、彼らが唯一のまことの神であるあなたと、あなたの遣わされたイエス・キリストとを知ることです。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネの福音書 4:34; 使徒の働き 20:24; テモテへの手紙第二 4:7"> あなたがわたしに行なわせるためにお与えになったわざを、わたしは成し遂げて、地上であなたの栄光を現わしました。</span>
<span className="v" id="v5" data-v="5" data-xref="ヨハネの福音書 1:1–3; コロサイ人への手紙 1:15–17; ヨハネの福音書 10:30"> 今は、父よ、みそばで、わたしを栄光で輝かせてください。世界が存在する前に、ごいっしょにいて持っていましたあの栄光で輝かせてください。</span>
<span className="v" id="v6" data-v="6" data-xref="ヨハネの福音書 17:26; ヨハネの福音書 14:21–24; ヨハネの手紙第一 5:20"> わたしは、あなたが世から取り出してわたしに下さった人々に、あなたの御名を明らかにしました。彼らはあなたのものであって、あなたは彼らをわたしに下さいました。彼らはあなたのみことばを守りました。</span>
<span className="v" id="v7" data-v="7" data-xref="ヨハネの福音書 7:16–17; ヨハネの福音書 16:15; ヨハネの福音書 14:7–10"> いま彼らは、あなたがわたしに下さったものはみな、あなたから出ていることを知っています。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨハネの福音書 17:14; ヨハネの福音書 15:15; ヨハネの福音書 16:30"> それは、あなたがわたしに下さったみことばを、わたしが彼らに与えたからです。彼らはそれを受け入れ、わたしがあなたから出て来たことを確かに知り、また、あなたがわたしを遣わされたことを信じました。</span>
<span className="v" id="v9" data-v="9" data-xref="ヘブル人への手紙 9:24; ヨハネの福音書 17:2; ヨハネの福音書 17:6"> わたしは彼らのためにお願いします。世のためにではなく、あなたがわたしに下さった者たちのためにです。なぜなら彼らはあなたのものだからです。</span>
<span className="v" id="v10" data-v="10" data-xref="ヨハネの福音書 10:30; ペテロの手紙第一 2:9; ヨハネの黙示録 5:8–14"> わたしのものはみなあなたのもの、あなたのものはわたしのものです。そして、わたしは彼らによって栄光を受けました。</span>
<span className="v" id="v11" data-v="11" data-xref="マタイの福音書 6:9; Proverbs 18:10; ヨハネの福音書 17:12–18"> わたしはもう世にいなくなります。彼らは世におりますが、わたしはあなたのみもとにまいります。聖なる父。あなたがわたしに下さっているあなたの御名の中に、彼らを保ってください。それはわたしたちと同様に、彼らが一つとなるためです。</span>
<span className="v" id="v12" data-v="12" data-xref="Psalms 109:6–19; ヨハネの福音書 10:27–28; ヨハネの福音書 18:9"> わたしは彼らといっしょにいたとき、あなたがわたしに下さっている御名の中に彼らを保ち、また守りました。彼らのうちだれも滅びた者はなく、ただ滅びの子が滅びました。それは、聖書が成就するためです。</span>
<span className="v" id="v13" data-v="13" data-xref="ヘブル人への手紙 12:2; ガラテヤ人への手紙 5:22; ヨハネの福音書 15:11"> わたしは今みもとにまいります。わたしは彼らの中でわたしの喜びが全うされるために、世にあってこれらのことを話しているのです。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="ヨハネの福音書 17:16; ヨハネの福音書 15:18–21; ヨハネの手紙第一 5:19–20"> わたしは彼らにあなたのみことばを与えました。しかし、世は彼らを憎みました。わたしがこの世のものでないように、彼らもこの世のものでないからです。</span>
<span className="v" id="v15" data-v="15" data-xref="Psalms 121:7; ヨハネの手紙第一 5:18; マタイの福音書 6:13"> 彼らをこの世から取り去ってくださるようにというのではなく、悪い者から守ってくださるようにお願いします。</span>
<span className="v" id="v16" data-v="16" data-xref="ヨハネの福音書 17:14"> わたしがこの世のものでないように、彼らもこの世のものではありません。</span>
<span className="v" id="v17" data-v="17" data-xref="ヨハネの福音書 15:3; Psalms 119:160; エペソ人への手紙 5:26"> 真理によって彼らを聖別してください。あなたのみことばは真理です。</span>
<span className="v" id="v18" data-v="18" data-xref="コリント人への手紙第二 5:20; ヨハネの福音書 20:21; ヨハネの福音書 17:3"> あなたがわたしを世に遣わされたように、わたしも彼らを世に遣わしました。</span>
<span className="v" id="v19" data-v="19" data-xref="テトスへの手紙 2:14; ヘブル人への手紙 2:11; ヨハネの福音書 17:17"> わたしは、彼らのため、わたし自身を聖別します。彼ら自身も真理によって聖別されるためです。</span>
<span className="v" id="v20" data-v="20" data-xref="ヨハネの福音書 17:6–11; 使徒の働き 2:41; 使徒の働き 4:4"> わたしは、ただこの人々のためだけでなく、彼らのことばによってわたしを信じる人々のためにもお願いします。</span>
<span className="v" id="v21" data-v="21" data-xref="コリント人への手紙第一 12:12; コロサイ人への手紙 3:11–14; ヨハネの福音書 17:11"> それは、父よ、あなたがわたしにおられ、わたしがあなたにいるように、彼らがみな一つとなるためです。また、彼らもわたしたちにおるようになるためです。そのことによって、あなたがわたしを遣わされたことを、世が信じるためなのです。</span>
<span className="v" id="v22" data-v="22" data-xref="コリント人への手紙第二 3:18; ヨハネの福音書 14:20; マルコの福音書 16:17–20"> またわたしは、あなたがわたしに下さった栄光を、彼らに与えました。それは、わたしたちが一つであるように、彼らも一つであるためです。</span>
<span className="v" id="v23" data-v="23" data-xref="ヨハネの福音書 17:21; ヨハネの福音書 16:27; ヨハネの手紙第一 3:1"> わたしは彼らにおり、あなたはわたしにおられます。それは、彼らが全うされて一つとなるためです。それは、あなたがわたしを遣わされたことと、あなたがわたしを愛されたように彼らをも愛されたこととを、この世が知るためです。</span>
<span className="v" id="v24" data-v="24" data-xref="ヨハネの福音書 17:5; ヨハネの福音書 12:26; ヨハネの福音書 14:3"> 父よ。お願いします。あなたがわたしに下さったものをわたしのいる所にわたしといっしょにおらせてください。あなたがわたしを世の始まる前から愛しておられたためにわたしに下さったわたしの栄光を、彼らが見るようになるためです。</span>
<span className="v" id="v25" data-v="25" data-xref="ヨハネの福音書 17:11; ヨハネの福音書 7:29; ヨハネの福音書 17:8"> 正しい父よ。この世はあなたを知りません。しかし、わたしはあなたを知っています。また、この人々は、あなたがわたしを遣わされたことを知りました。</span>
<span className="v" id="v26" data-v="26" data-xref="ヨハネの福音書 17:23; ヨハネの福音書 17:6; ヨハネの福音書 15:9"> そして、わたしは彼らにあなたの御名を知らせました。また、これからも知らせます。それは、あなたがわたしを愛してくださったその愛が彼らの中にあり、またわたしが彼らの中にいるためです。」</span>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マルコの福音書 14:32; マタイの福音書 26:36; 2 Samuel 15:23"> イエスはこれらのことを話し終えられると、弟子たちとともに、ケデロンの川筋の向こう側に出て行かれた。そこに園があって、イエスは弟子たちといっしょに、そこにはいられた。</span>
<span className="v" id="v2" data-v="2" data-xref="ルカの福音書 21:37; ルカの福音書 22:39; マルコの福音書 11:11–12"> ところで、イエスを裏切ろうとしていたユダもその場所を知っていた。イエスがたびたび弟子たちとそこで会合されたからである。</span>
<span className="v" id="v3" data-v="3" data-xref="ヨハネの福音書 18:12; ルカの福音書 22:47–53; Psalms 22:12"> そこで、ユダは一隊の兵士と、祭司長、パリサイ人たちから送られた役人たちを引き連れて、ともしびとたいまつと武器を持って、そこに来た。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネの福音書 13:1; ヨハネの福音書 18:7; Psalms 27:3"> イエスは自分の身に起ころうとするすべてのことを知っておられたので、出て来て、「だれを捜すのか。」と彼らに言われた。</span>
<span className="v" id="v5" data-v="5" data-xref="マタイの福音書 21:11; ヨハネの福音書 19:19; マタイの福音書 2:23"> 彼らは、「ナザレ人イエスを。」と答えた。イエスは彼らに「それはわたしです。」と言われた。イエスを裏切ろうとしていたユダも彼らといっしょに立っていた。</span>
<span className="v" id="v6" data-v="6" data-xref="Psalms 27:2; Psalms 70:2–3; 2 Kings 1:9–15"> イエスが彼らに、「それはわたしです。」と言われたとき、彼らはあとずさりし、そして地に倒れた。</span>
<span className="v" id="v7" data-v="7" data-xref="ヨハネの福音書 18:4"> そこで、イエスがもう一度、「だれを捜すのか。」と問われると、彼らは「ナザレ人イエスを。」と言った。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨハネの福音書 10:28; マタイの福音書 26:56; コリント人への手紙第二 12:9"> イエスは答えられた。「それはわたしだと、あなたがたに言ったでしょう。もしわたしを捜しているのなら、この人たちはこのままで去らせなさい。」</span>
<span className="v" id="v9" data-v="9" data-xref="ヨハネの福音書 17:12"> それは、「あなたがわたしに下さった者のうち、ただのひとりをも失いませんでした。」とイエスが言われたことばが実現するためであった。</span>
<span className="v" id="v10" data-v="10" data-xref="マルコの福音書 14:47; マタイの福音書 26:51–54; ルカの福音書 22:49–51"> シモン・ペテロは、剣を持っていたが、それを抜き、大祭司のしもべを撃ち、右の耳を切り落とした。そのしもべの名はマルコスであった。</span>
<span className="v" id="v11" data-v="11" data-xref="マタイの福音書 20:22; マタイの福音書 26:39; ヨハネの福音書 20:17"> そこで、イエスはペテロに言われた。「剣をさやに収めなさい。父がわたしに下さった杯を、どうして飲まずにいられよう。」</span>
<span className="v" id="v12" data-v="12" data-xref="マタイの福音書 26:57; ヨハネの福音書 18:3; 使徒の働き 21:37"> そこで、一隊の兵士と千人隊長、それにユダヤ人から送られた役人たちは、イエスを捕えて縛り、</span>
<span className="v" id="v13" data-v="13" data-xref="ヨハネの福音書 18:24; ヨハネの福音書 11:51; マタイの福音書 26:3"> まずアンナスのところに連れて行った。彼がその年の大祭司カヤパのしゅうとだったからである。</span>
<span className="v" id="v14" data-v="14" data-xref="ヨハネの福音書 11:49–52"> カヤパは、ひとりの人が民に代わって死ぬことが得策である、とユダヤ人に助言した人である。</span>
<span className="v" id="v15" data-v="15" data-xref="ルカの福音書 22:54; マルコの福音書 14:54; マタイの福音書 26:58–68"> シモン・ペテロともうひとりの弟子は、イエスについて行った。この弟子は大祭司の知り合いで、イエスといっしょに大祭司の中庭にはいった。</span>
<span className="v" id="v16" data-v="16" data-xref="マタイの福音書 26:69; マルコの福音書 14:66–68; ルカの福音書 22:55–57"> しかし、ペテロは外で門のところに立っていた。それで、大祭司の知り合いである、もうひとりの弟子が出て来て、門番の女に話して、ペテロを連れてはいった。</span>
<span className="v" id="v17" data-v="17" data-xref="マタイの福音書 26:69–70; ヨハネの福音書 21:15; ルカの福音書 22:56–57"> すると、門番のはしためがペテロに、「あなたもあの人の弟子ではないでしょうね。」と言った。ペテロは、「そんな者ではない。」と言った。</span>
<span className="v" id="v18" data-v="18" data-xref="マルコの福音書 14:54; ヨハネの福音書 18:25; マルコの福音書 14:67"> 寒かったので、しもべたちや役人たちは、炭火をおこし、そこに立って暖まっていた。ペテロも彼らといっしょに、立って暖まっていた。</span>
<span className="v" id="v19" data-v="19" data-xref="マルコの福音書 14:55–65; ルカの福音書 20:20; ルカの福音書 22:63–71"> そこで、大祭司はイエスに、弟子たちのこと、また、教えのことについて尋問した。</span>
<span className="v" id="v20" data-v="20" data-xref="ヨハネの福音書 7:26; Isaiah 48:16; マタイの福音書 4:23"> イエスは彼に答えられた。「わたしは世に向かって公然と話しました。わたしはユダヤ人がみな集まって来る会堂や宮で、いつも教えたのです。隠れて話したことは何もありません。</span>
<span className="v" id="v21" data-v="21" data-xref="マタイの福音書 26:59–60; 使徒の働き 24:12–13; ルカの福音書 22:67"> なぜ、あなたはわたしに尋ねるのですか。わたしが人々に何を話したかは、わたしから聞いた人たちに尋ねなさい。彼らならわたしが話した事がらを知っています。」</span>
<span className="v" id="v22" data-v="22" data-xref="ヨハネの福音書 19:3; マルコの福音書 14:65; ルカの福音書 22:63–64"> イエスがこう言われたとき、そばに立っていた役人のひとりが、「大祭司にそのような答え方をするのか。」と言って、平手でイエスを打った。</span>
<span className="v" id="v23" data-v="23" data-xref="ペテロの手紙第一 2:20–23; コリント人への手紙第二 10:1; マタイの福音書 5:39"> イエスは彼に答えられた。「もしわたしの言ったことが悪いなら、その悪い証拠を示しなさい。しかし、もし正しいなら、なぜ、わたしを打つのか。」</span>
<span className="v" id="v24" data-v="24" data-xref="ヨハネの福音書 18:13; マタイの福音書 26:57"> アンナスはイエスを、縛ったままで大祭司カヤパのところに送った。</span>
<span className="v" id="v25" data-v="25" data-xref="マルコの福音書 14:67–72; ヨハネの福音書 18:17–18; Genesis 18:15"> 一方、シモン・ペテロは立って、暖まっていた。すると、人々は彼に言った。「あなたもあの人の弟子ではないでしょうね。」ペテロは否定して、「そんな者ではない。」と言った。</span>
<span className="v" id="v26" data-v="26" data-xref="ヨハネの福音書 18:1; ヨハネの福音書 18:10; マタイの福音書 26:73"> 大祭司のしもべのひとりで、ペテロに耳を切り落とされた人の親類に当たる者が言った。「私が見なかったとでもいうのですか。あなたは園であの人といっしょにいました。」</span>
<span className="v" id="v27" data-v="27" data-xref="ヨハネの福音書 13:38; マルコの福音書 14:71–72; ルカの福音書 22:60–62"> それで、ペテロはもう一度否定した。するとすぐ鶏が鳴いた。</span>
<span className="v" id="v28" data-v="28" data-xref="ヨハネの福音書 18:33; ヨハネの福音書 19:9; マタイの福音書 27:27"> さて、彼らはイエスを、カヤパのところから総督官邸に連れて行った。時は明け方であった。彼らは、過越の食事が食べられなくなることのないように、汚れを受けまいとして、官邸にはいらなかった。</span>
<span className="v" id="v29" data-v="29" data-xref="マタイの福音書 27:23; マルコの福音書 15:2–5; マタイの福音書 27:11–14"> そこで、ピラトは彼らのところに出て来て言った。「あなたがたは、この人に対して何を告発するのですか。」</span>
<span className="v" id="v30" data-v="30" data-xref="使徒の働き 3:13; ルカの福音書 20:19–26; マルコの福音書 10:33"> 彼らはピラトに答えた。「もしこの人が悪いことをしていなかったら、私たちはこの人をあなたに引き渡しはしなかったでしょう。」</span>
<span className="v" id="v31" data-v="31" data-xref="ヨハネの福音書 19:6–7; ヨハネの福音書 19:15; 使徒の働き 25:18–20"> そこでピラトは彼らに言った。「あなたがたがこの人を引き取り、自分たちの律法に従ってさばきなさい。」ユダヤ人たちは彼に言った。「私たちには、だれを死刑にすることも許されてはいません。」</span>
<span className="v" id="v32" data-v="32" data-xref="ヨハネの福音書 3:14; マタイの福音書 20:19; マタイの福音書 26:2"> これは、ご自分がどのような死に方をされるのかを示して話されたイエスのことばが成就するためであった。</span>
<span className="v" id="v33" data-v="33" data-xref="ルカの福音書 23:3–4; ヨハネの福音書 18:37; ヨハネの福音書 19:3"> そこで、ピラトはもう一度官邸にはいって、イエスを呼んで言った。「あなたは、ユダヤ人の王ですか。」</span>
<span className="v" id="v34" data-v="34"> イエスは答えられた。「あなたは、自分でそのことを言っているのですか。それともほかの人が、あなたにわたしのことを話したのですか。」</span>
<span className="v" id="v35" data-v="35" data-xref="使徒の働き 18:14–16; Nehemiah 4:2; ローマ人への手紙 3:1–2"> ピラトは答えた。「私はユダヤ人ではないでしょう。あなたの同国人と祭司長たちが、あなたを私に引き渡したのです。あなたは何をしたのですか。」</span>
<span className="v" id="v36" data-v="36" data-xref="ルカの福音書 17:20–21; コロサイ人への手紙 1:12–14; ローマ人への手紙 14:17"> イエスは答えられた。「わたしの国はこの世のものではありません。もしこの世のものであったなら、わたしのしもべたちが、わたしをユダヤ人に渡さないように、戦ったことでしょう。しかし、事実、わたしの国はこの世のものではありません。」</span>
<span className="v" id="v37" data-v="37" data-xref="ヨハネの手紙第一 4:6; ヨハネの福音書 8:47; ヨハネの福音書 8:14"> そこでピラトはイエスに言った。「それでは、あなたは王なのですか。」イエスは答えられた。「わたしが王であることは、あなたが言うとおりです。わたしは、真理のあかしをするために生まれ、このことのために世に来たのです。真理に属する者はみな、わたしの声に聞き従います。」</span>
<span className="v" id="v38" data-v="38" data-xref="ヨハネの福音書 19:4; ルカの福音書 23:4; ヨハネの福音書 19:6"> ピラトはイエスに言った。「真理とは何ですか。」 彼はこう言ってから、またユダヤ人たちのところに出て行って、彼らに言った。「私は、あの人には罪を認めません。</span>
<span className="v" id="v39" data-v="39" data-xref="マタイの福音書 27:15–18; ルカの福音書 23:16–23; マルコの福音書 15:6–14"> しかし、過越の祭りに、私があなたがたのためにひとりの者を釈放するのがならわしになっています。それで、あなたがたのために、ユダヤ人の王を釈放することにしましょうか。」</span>
<span className="v" id="v40" data-v="40" data-xref="ルカの福音書 23:25; マルコの福音書 15:15; マタイの福音書 27:16"> すると彼らはみな、また大声をあげて、「この人ではない。バラバだ。」と言った。このバラバは強盗であった。</span>

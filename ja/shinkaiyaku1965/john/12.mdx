<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マルコの福音書 14:3–8; ヨハネの福音書 11:1; ルカの福音書 24:50"> イエスは過越の祭りの六日前にベタニヤに来られた。そこには、イエスが死人の中からよみがえらせたラザロがいた。</span>
<span className="v" id="v2" data-v="2" data-xref="ルカの福音書 22:27; ルカの福音書 10:38–42; ヨハネの黙示録 3:20"> 人々はイエスのために、そこに晩餐を用意した。そしてマルタは給仕していた。ラザロは、イエスとともに食卓に着いている人々の中に混じっていた。</span>
<span className="v" id="v3" data-v="3" data-xref="マルコの福音書 14:3–9; ヨハネの福音書 11:2; ルカの福音書 10:38–39"> マリヤは、非常に高価な、純粋なナルドの香油三百グラムを取って、イエスの足に塗り、彼女の髪の毛でイエスの足をぬぐった。家は香油のかおりでいっぱいになった。</span>
<span className="v" id="v4" data-v="4" data-xref="マタイの福音書 10:4; 1 Samuel 17:28–29; ヨハネの福音書 13:2"> ところが、弟子のひとりで、イエスを裏切ろうとしているイスカリオテ・ユダが言った。</span>
<span className="v" id="v5" data-v="5" data-xref="ルカの福音書 18:22; ルカの福音書 12:33; マルコの福音書 14:4–5"> 「なぜ、この香油を三百デナリに売って、貧しい人々に施さなかったのか。」</span>
<span className="v" id="v6" data-v="6" data-xref="ヨハネの福音書 13:29; Psalms 50:16–20; ヤコブの手紙 2:6"> しかしこう言ったのは、彼が貧しい人々のことを心にかけていたからではなく、彼は盗人であって、金入れを預かっていたが、その中に収められたものを、いつも盗んでいたからである。</span>
<span className="v" id="v7" data-v="7" data-xref="マタイの福音書 26:12; マルコの福音書 14:6; マタイの福音書 27:57–60"> イエスは言われた。「そのままにしておきなさい。マリヤはわたしの葬りの日のために、それを取っておこうとしていたのです。</span>
<span className="v" id="v8" data-v="8" data-xref="Deuteronomy 15:11; マルコの福音書 14:7; マタイの福音書 26:11"> あなたがたは、貧しい人々とはいつもいっしょにいるが、わたしとはいつもいっしょにいるわけではないからです。」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="使徒の働き 4:14; ヨハネの福音書 11:43–45; 使徒の働き 3:10–11"> 大ぜいのユダヤ人の群れが、イエスがそこにおられることを聞いて、やって来た。それはただイエスのためだけではなく、イエスによって死人の中からよみがえったラザロを見るためでもあった。</span>
<span className="v" id="v10" data-v="10" data-xref="ルカの福音書 16:31; マタイの福音書 2:16; ヨハネの福音書 11:47–53"> 祭司長たちはラザロも殺そうと相談した。</span>
<span className="v" id="v11" data-v="11" data-xref="ヨハネの福音書 11:45; ヨハネの福音書 12:18; 使徒の働き 13:45"> それは、彼のために多くのユダヤ人が去って行き、イエスを信じるようになったからである。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="マルコの福音書 11:7–10; マタイの福音書 21:4–9; ルカの福音書 19:35–38"> その翌日、祭りに来ていた大ぜいの人の群れは、イエスがエルサレムに来ようとしておられると聞いて、</span>
<span className="v" id="v13" data-v="13" data-xref="Psalms 118:25–26; ヨハネの黙示録 15:3; マタイの福音書 21:9–11"> しゅろの木の枝を取って、出迎えのために出て行った。そして大声で叫んだ。<br />「ホサナ。<br />祝福あれ。<br />主の御名によって来られる方に。<br />イスラエルの王に。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="Zechariah 9:9; マルコの福音書 11:1–7; マタイの福音書 21:1–7"> イエスは、ろばの子を見つけて、それに乗られた。それは次のように書かれているとおりであった。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="Zechariah 9:9; Isaiah 62:11; Zephaniah 3:16–17"> 「恐れるな。シオンの娘。<br />見よ。あなたの王が来られる。<br />ろばの子に乗って。」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="ヨハネの福音書 2:22; ヨハネの福音書 14:26; ヨハネの福音書 7:39"> 初め、弟子たちにはこれらのことがわからなかった。しかし、イエスが栄光を受けられてから、これらのことがイエスについて書かれたことであって、人々がそのとおりにイエスに対して行なったことを、彼らは思い出した。</span>
<span className="v" id="v17" data-v="17" data-xref="ヨハネの黙示録 1:2; ヨハネの手紙第一 5:9–12; ヨハネの福音書 19:35"> イエスがラザロを墓から呼び出し、死人の中からよみがえらせたときにイエスといっしょにいた大ぜいの人々は、そのことのあかしをした。</span>
<span className="v" id="v18" data-v="18" data-xref="ヨハネの福音書 12:11"> そのために群衆もイエスを出迎えた。イエスがこれらのしるしを行なわれたことを聞いたからである。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒の働き 17:6; Psalms 22:27; ヨハネの手紙第一 2:2"> そこで、パリサイ人たちは互いに言った。「どうしたのだ。何一つうまくいっていない。見なさい。世はあげてあの人のあとについて行ってしまった。」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="ヨハネの福音書 7:35; Isaiah 11:10; 使徒の働き 17:4"> さて、祭りのとき礼拝のために上って来た人々の中に、ギリシヤ人が幾人かいた。</span>
<span className="v" id="v21" data-v="21" data-xref="マタイの福音書 2:2; ルカの福音書 19:2–4; ヨハネの福音書 6:40"> この人たちがガリラヤのベツサイダの人であるピリポのところに来て、「先生。イエスにお目にかかりたいのですが。」と言って頼んだ。</span>
<span className="v" id="v22" data-v="22" data-xref="マルコの福音書 10:13–14; ルカの福音書 9:49–50; ヨハネの福音書 1:40–41"> ピリポは行ってアンデレに話し、アンデレとピリポとは行って、イエスに話した。</span>
<span className="v" id="v23" data-v="23" data-xref="ヨハネの福音書 13:31–32; ヨハネの福音書 17:1–5; Isaiah 60:9"> すると、イエスは彼らに答えて言われた。「人の子が栄光を受けるその時が来ました。</span>
<span className="v" id="v24" data-v="24" data-xref="コリント人への手紙第一 15:36–38; Isaiah 53:10–12; ヘブル人への手紙 2:9–10"> まことに、まことに、あなたがたに告げます。一粒の麦がもし地に落ちて死ななければ、それは一つのままです。しかし、もし死ねば、豊かな実を結びます。</span>
<span className="v" id="v25" data-v="25" data-xref="マタイの福音書 10:39; ルカの福音書 9:23–24; マルコの福音書 8:35"> 自分のいのちを愛する者はそれを失い、この世でそのいのちを憎む者はそれを保って永遠のいのちに至るのです。</span>
<span className="v" id="v26" data-v="26" data-xref="コロサイ人への手紙 3:24; ガラテヤ人への手紙 1:10; 1 Samuel 2:30"> わたしに仕えるというのなら、その人はわたしについて来なさい。わたしがいる所に、わたしに仕える者もいるべきです。もしわたしに仕えるなら、父はその人に報いてくださいます。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="ヨハネの福音書 12:23; ヘブル人への手紙 5:7; マタイの福音書 26:42"> 今わたしの心は騒いでいる。何と言おうか。『父よ。この時からわたしをお救いください。』と言おうか。いや。このためにこそ、わたしはこの時に至ったのです。</span>
<span className="v" id="v28" data-v="28" data-xref="ヨハネの福音書 13:31–32; マタイの福音書 26:42; ヨハネの黙示録 5:9–14"> 父よ。御名の栄光を現わしてください。」そのとき、天から声が聞こえた。「わたしは栄光をすでに現わしたし、またもう一度栄光を現わそう。」</span>
<span className="v" id="v29" data-v="29" data-xref="Job 37:2–5; ヨハネの黙示録 6:1; ヨハネの黙示録 14:2"> そばに立っていてそれを聞いた群衆は、雷が鳴ったのだと言った。ほかの人々は、「御使いがあの方に話したのだ。」と言った。</span>
<span className="v" id="v30" data-v="30" data-xref="ヨハネの福音書 11:42; ヨハネの福音書 11:15; ヨハネの福音書 5:34"> イエスは答えて言われた。「この声が聞こえたのは、わたしのためにではなくて、あなたがたのためにです。</span>
<span className="v" id="v31" data-v="31" data-xref="コリント人への手紙第二 4:4; ヨハネの手紙第一 5:19; ヨハネの手紙第一 3:8"> 今がこの世のさばきです。今、この世を支配する者は追い出されるのです。</span>
<span className="v" id="v32" data-v="32" data-xref="ヨハネの福音書 3:14; ヨハネの福音書 8:28; ペテロの手紙第一 2:24"> わたしが地上から上げられるなら、わたしはすべての人を自分のところに引き寄せます。」</span>
<span className="v" id="v33" data-v="33" data-xref="ヨハネの福音書 18:32; ヨハネの福音書 21:19"> イエスは自分がどのような死に方で死ぬかを示して、このことを言われたのである。</span>
<span className="v" id="v34" data-v="34" data-xref="Ezekiel 37:24–25; Isaiah 9:7; Daniel 7:14"> そこで、群衆はイエスに答えた。「私たちは、律法で、キリストはいつまでも生きておられると聞きましたが、どうしてあなたは、人の子は上げられなければならない、と言われるのですか。その人の子とはだれですか。」</span>
<span className="v" id="v35" data-v="35" data-xref="ヨハネの福音書 12:46; ヨハネの福音書 16:16; エペソ人への手紙 5:8"> イエスは彼らに言われた。「まだしばらくの間、光はあなたがたの間にあります。やみがあなたがたを襲うことのないように、あなたがたは、光がある間に歩きなさい。やみの中を歩く者は、自分がどこに行くのかわかりません。</span>
<span className="v" id="v36" data-v="36" data-xref="エペソ人への手紙 5:8; ヨハネの福音書 8:59; 使徒の働き 13:47–48"> あなたがたに光がある間に、光の子どもとなるために、光を信じなさい。」<br />イエスは、これらのことをお話しになると、立ち去って、彼らから身を隠された。</span>
<span className="v" id="v37" data-v="37" data-xref="ルカの福音書 16:31; ヨハネの福音書 1:11; ヨハネの福音書 15:24"> イエスが彼らの目の前でこのように多くのしるしを行なわれたのに、彼らはイエスを信じなかった。</span>
<span className="v" id="v38" data-v="38" data-xref="Isaiah 53:1; ローマ人への手紙 10:16; ローマ人への手紙 10:20"> それは、「主よ。だれが私たちの知らせを信じましたか。また主の御腕はだれに現わされましたか。」と言った預言者イザヤのことばが成就するためであった。</span>
<span className="v" id="v39" data-v="39" data-xref="ヨハネの福音書 10:38; ヨハネの福音書 5:44; ペテロの手紙第二 2:14"> 彼らが信じることができなかったのは、イザヤがまた次のように言ったからである。</span>
<span className="v" id="v40" data-v="40" data-xref="Isaiah 6:10; マタイの福音書 13:13–15; ルカの福音書 8:10"> 「主は彼らの目を盲目にされた。また、彼らの心をかたくなにされた。それは、彼らが目で見、心で理解し、回心し、そしてわたしが彼らをいやす、ということがないためである。」</span>
<span className="v" id="v41" data-v="41" data-xref="Isaiah 6:1–5; Isaiah 6:9–10; ヨハネの福音書 1:14"> イザヤがこう言ったのは、イザヤがイエスの栄光を見たからで、イエスをさして言ったのである。</span>
<span className="v" id="v42" data-v="42" data-xref="ヨハネの福音書 9:22; ヨハネの福音書 7:13; Isaiah 51:7"> しかし、それにもかかわらず、指導者たちの中にもイエスを信じる者がたくさんいた。ただ、パリサイ人たちをはばかって、告白はしなかった。会堂から追放されないためであった。</span>
<span className="v" id="v43" data-v="43" data-xref="ヨハネの福音書 5:44; マタイの福音書 23:5–7; ヨハネの福音書 5:41"> 彼らは、神からの栄誉よりも、人の栄誉を愛したからである。</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="マタイの福音書 10:40; ヨハネの福音書 13:20; ヨハネの福音書 5:24"> また、イエスは大声で言われた。「わたしを信じる者は、わたしではなく、わたしを遣わした方を信じるのです。</span>
<span className="v" id="v45" data-v="45" data-xref="ヨハネの福音書 14:9–10; コリント人への手紙第二 4:6; コロサイ人への手紙 1:15"> また、わたしを見る者は、わたしを遣わした方を見るのです。</span>
<span className="v" id="v46" data-v="46" data-xref="ヨハネの福音書 8:12; Psalms 36:9; ヨハネの福音書 9:5"> わたしは光として世に来ました。わたしを信じる者が、だれもやみの中にとどまることのないためです。</span>
<span className="v" id="v47" data-v="47" data-xref="ヨハネの福音書 3:17; ヨハネの福音書 8:15–16; ヨハネの福音書 12:48"> だれかが、わたしの言うことを聞いてそれを守らなくても、わたしはその人をさばきません。わたしは世をさばくために来たのではなく、世を救うために来たからです。</span>
<span className="v" id="v48" data-v="48" data-xref="ルカの福音書 10:16; ヘブル人への手紙 9:27–28; ローマ人への手紙 2:16"> わたしを拒み、わたしの言うことを受け入れない者には、その人をさばくものがあります。わたしが話したことばが、終わりの日にその人をさばくのです。</span>
<span className="v" id="v49" data-v="49" data-xref="ヨハネの福音書 14:10; ヨハネの福音書 8:26; ヨハネの福音書 5:30"> わたしは、自分から話したのではありません。わたしを遣わした父ご自身が、わたしが何を言い、何を話すべきかをお命じになりました。</span>
<span className="v" id="v50" data-v="50" data-xref="ヨハネの福音書 17:3; ヨハネの福音書 6:68; ヨハネの手紙第一 5:20"> わたしは、父の命令が永遠のいのちであることを知っています。それゆえ、わたしが話していることは、父がわたしに言われたとおりを、そのままに話しているのです。」</span>
</div>

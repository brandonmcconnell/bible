<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="Isaiah 53:5; Isaiah 50:6; マタイの福音書 20:19"> そこで、ピラトはイエスを捕えて、むち打ちにした。</span>
<span className="v" id="v2" data-v="2" data-xref="マルコの福音書 15:16–20; ルカの福音書 23:11; マタイの福音書 27:27–31"> また、兵士たちは、いばらで冠を編んで、イエスの頭にかぶらせ、紫色の着物を着せた。</span>
<span className="v" id="v3" data-v="3" data-xref="マタイの福音書 27:29; マタイの福音書 26:49; ルカの福音書 1:28"> 彼らは、イエスに近寄っては、「ユダヤ人の王さま。ばんざい。」と言い、またイエスの顔を平手で打った。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネの福音書 18:38; ヨハネの福音書 19:6; ルカの福音書 23:4"> ピラトは、もう一度外に出て来て、彼らに言った。「よく聞きなさい。あなたがたのところにあの人を連れ出して来ます。あの人に何の罪も見られないということを、あなたがたに知らせるためです。」</span>
<span className="v" id="v5" data-v="5" data-xref="ヨハネの福音書 19:2; ヘブル人への手紙 12:2; Isaiah 7:14"> それでイエスは、いばらの冠と紫色の着物を着けて、出て来られた。するとピラトは彼らに「さあ、この人です。」と言った。</span>
<span className="v" id="v6" data-v="6" data-xref="ヨハネの福音書 18:31; ヨハネの福音書 19:4; 使徒の働き 2:23"> 祭司長たちや役人たちはイエスを見ると、激しく叫んで、「十字架につけろ。十字架につけろ。」と言った。ピラトは彼らに言った。「あなたがたがこの人を引き取り、十字架につけなさい。私はこの人には罪を認めません。」</span>
<span className="v" id="v7" data-v="7" data-xref="Leviticus 24:16; ヨハネの福音書 5:18; マタイの福音書 26:63–66"> ユダヤ人たちは彼に答えた。「私たちには律法があります。この人は自分を神の子としたのですから、律法によれば、死に当たります。」</span>
<span className="v" id="v8" data-v="8" data-xref="ヨハネの福音書 19:13; 使徒の働き 14:11–19"> ピラトは、このことばを聞くと、ますます恐れた。</span>
<span className="v" id="v9" data-v="9" data-xref="ヨハネの福音書 18:33; Psalms 38:13–15; ピリピ人への手紙 1:28"> そして、また官邸にはいって、イエスに言った。「あなたはどこの人ですか。」しかし、イエスは彼に何の答えもされなかった。</span>
<span className="v" id="v10" data-v="10" data-xref="Daniel 5:19; ヨハネの福音書 18:39; Daniel 3:14–15"> そこで、ピラトはイエスに言った。「あなたは私に話さないのですか。私にはあなたを釈放する権威があり、また十字架につける権威があることを、知らないのですか。」</span>
<span className="v" id="v11" data-v="11" data-xref="ローマ人への手紙 13:1; ヨハネの福音書 3:27; 使徒の働き 2:23"> イエスは答えられた。「もしそれが上から与えられているのでなかったら、あなたにはわたしに対して何の権威もありません。ですから、わたしをあなたに渡した者に、もっと大きい罪があるのです。」</span>
<span className="v" id="v12" data-v="12" data-xref="使徒の働き 17:6–7; ヨハネの福音書 18:33–36; マルコの福音書 6:16–26"> こういうわけで、ピラトはイエスを釈放しようと努力した。しかし、ユダヤ人たちは激しく叫んで言った。「もしこの人を釈放するなら、あなたはカイザルの味方ではありません。自分を王だとする者はすべて、カイザルにそむくのです。」</span>
<span className="v" id="v13" data-v="13" data-xref="Psalms 82:5–7; マタイの福音書 27:19; Amos 4:7"> そこでピラトは、これらのことばを聞いたとき、イエスを外に引き出し、敷石（ヘブル語ではガバタ）と呼ばれる場所で、裁判の席に着いた。</span>
<span className="v" id="v14" data-v="14" data-xref="マタイの福音書 27:62; ヨハネの福音書 19:5; マルコの福音書 15:25"> その日は過越の備え日で、時は六時ごろであった。ピラトはユダヤ人たちに言った。「さあ、あなたがたの王です。」</span>
<span className="v" id="v15" data-v="15" data-xref="ルカの福音書 23:18; 使徒の働き 21:36; ヨハネの福音書 19:6"> 彼らは激しく叫んだ。「除け。除け。十字架につけろ。」ピラトは彼らに言った。「あなたがたの王を私が十字架につけるのですか。」祭司長たちは答えた。「カイザルのほかには、私たちに王はありません。」</span>
<span className="v" id="v16" data-v="16" data-xref="ルカの福音書 23:24–25; マタイの福音書 27:26–31; マルコの福音書 15:15–20"> そこでピラトは、そのとき、イエスを、十字架につけるため彼らに引き渡した。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="ルカの福音書 23:33; ルカの福音書 14:27; ルカの福音書 23:26"> 彼らはイエスを受け取った。そして、イエスはご自分で十字架を負って、「どくろの地」という場所（ヘブル語でゴルゴタと言われる）に出て行かれた。</span>
<span className="v" id="v18" data-v="18" data-xref="Isaiah 53:12; マルコの福音書 15:24–27; ガラテヤ人への手紙 3:13"> 彼らはそこでイエスを十字架につけた。イエスといっしょに、ほかのふたりの者をそれぞれ両側に、イエスを真中にしてであった。</span>
<span className="v" id="v19" data-v="19" data-xref="マタイの福音書 27:37; ルカの福音書 23:38; マルコの福音書 15:26"> ピラトは罪状書きも書いて、十字架の上に掲げた。それには「ユダヤ人の王ナザレ人イエス。」と書いてあった。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒の働き 26:14; ヨハネの黙示録 16:16; 使徒の働き 22:2"> それで、大ぜいのユダヤ人がこの罪状書きを読んだ。イエスが十字架につけられた場所は都に近かったからである。またそれはヘブル語、ラテン語、ギリシヤ語で書いてあった。</span>
<span className="v" id="v21" data-v="21" data-xref="ヨハネの福音書 19:14; ヨハネの福音書 19:19"> そこで、ユダヤ人の祭司長たちがピラトに、「ユダヤ人の王、と書かないで、彼はユダヤ人の王と自称した、と書いてください。」と言った。</span>
<span className="v" id="v22" data-v="22" data-xref="Psalms 76:10; Psalms 65:7; Proverbs 8:29"> ピラトは答えた。「私の書いたことは私が書いたのです。」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="ルカの福音書 23:34; マルコの福音書 15:24; マタイの福音書 27:35"> さて、兵士たちは、イエスを十字架につけると、イエスの着物を取り、ひとりの兵士に一つずつあたるよう四分した。また下着をも取ったが、それは上から全部一つに織った、縫い目なしのものであった。</span>
<span className="v" id="v24" data-v="24" data-xref="Psalms 22:18; ヨハネの福音書 19:28; ヨハネの福音書 19:36–37"> そこで彼らは互いに言った。「それは裂かないで、だれの物になるか、くじを引こう。」それは、「彼らはわたしの着物を分け合い、わたしの下着のためにくじを引いた。」という聖書が成就するためであった。</span>
<span className="v" id="v25" data-v="25" data-xref="ルカの福音書 23:49; マタイの福音書 27:55–56; ヨハネの福音書 20:1"> 兵士たちはこのようなことをしたが、イエスの十字架のそばには、イエスの母と母の姉妹と、クロパの妻のマリヤとマグダラのマリヤが立っていた。</span>
<span className="v" id="v26" data-v="26" data-xref="ヨハネの福音書 21:24; ヨハネの福音書 20:2; ヨハネの福音書 2:4"> イエスは、母と、そばに立っている愛する弟子とを見て、母に「女の方。そこに、あなたの息子がいます。」と言われた。</span>
<span className="v" id="v27" data-v="27" data-xref="マタイの福音書 12:48–50; ヨハネの福音書 16:32; テモテへの手紙第一 5:2–4"> それからその弟子に「そこに、あなたの母がいます。」と言われた。その時から、この弟子は彼女を自分の家に引き取った。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="Psalms 69:21; Psalms 22:15; ヨハネの福音書 19:30"> この後、イエスは、すべてのことが完了したのを知って、聖書が成就するために、「わたしは渇く。」と言われた。</span>
<span className="v" id="v29" data-v="29" data-xref="Numbers 19:18; ルカの福音書 23:36; マルコの福音書 15:36"> そこには酸いぶどう酒のいっぱいはいった入れ物が置いてあった。そこで彼らは、酸いぶどう酒を含んだ海綿をヒソプの枝につけて、それをイエスの口もとに差し出した。</span>
<span className="v" id="v30" data-v="30" data-xref="ヨハネの福音書 17:4; ピリピ人への手紙 2:8; コロサイ人への手紙 2:14–17"> イエスは、酸いぶどう酒を受けられると、「完了した。」と言われた。そして、頭をたれて、霊をお渡しになった。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="ヨハネの福音書 19:14; ヨハネの福音書 19:42; マルコの福音書 15:42"> その日は備え日であったため、ユダヤ人たちは安息日に（その安息日は大いなる日であったので）、死体を十字架の上に残しておかないように、すねを折ってそれを取りのける処置をピラトに願った。</span>
<span className="v" id="v32" data-v="32" data-xref="ヨハネの福音書 19:18; ルカの福音書 23:39–43"> それで、兵士たちが来て、イエスといっしょに十字架につけられた第一の者と、もうひとりの者とのすねを折った。</span>
<span className="v" id="v33" data-v="33"> しかし、イエスのところに来ると、イエスがすでに死んでおられるのを認めたので、そのすねを折らなかった。</span>
<span className="v" id="v34" data-v="34" data-xref="ヨハネの手紙第一 5:6; Zechariah 12:10; Zechariah 13:1"> しかし、兵士のうちのひとりがイエスのわき腹を槍で突き刺した。すると、ただちに血と水が出て来た。</span>
<span className="v" id="v35" data-v="35" data-xref="ヨハネの福音書 21:24; ヘブル人への手紙 2:3–4; ヨハネの手紙第一 1:1–3"> それを目撃した者があかしをしているのである。そのあかしは真実である。その人が、あなたがたにも信じさせるために、真実を話すということをよく知っているのである。</span>
<span className="v" id="v36" data-v="36" data-xref="Psalms 34:20; Numbers 9:12; Exodus 12:46"> この事が起こったのは、「彼の骨は一つも砕かれない。」という聖書のことばが成就するためであった。</span>
<span className="v" id="v37" data-v="37" data-xref="Zechariah 12:10; ヨハネの黙示録 1:7; Psalms 22:16–17"> また聖書の別のところには、「彼らは自分たちが突き刺した方を見る。」と言われているからである。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="マルコの福音書 15:42–47; マタイの福音書 27:57–61; Proverbs 29:25"> そのあとで、イエスの弟子ではあったがユダヤ人を恐れてそのことを隠していたアリマタヤのヨセフが、イエスのからだを取りかたづけたいとピラトに願った。それで、ピラトは許可を与えた。そこで彼は来て、イエスのからだを取り降ろした。</span>
<span className="v" id="v39" data-v="39" data-xref="ヨハネの福音書 7:50–52; Song of Solomon 4:14; ヨハネの福音書 3:1–21"> 前に、夜イエスのところに来たニコデモも、没薬とアロエを混ぜ合わせたものをおよそ三十キログラムばかり持って、やって来た。</span>
<span className="v" id="v40" data-v="40" data-xref="ヨハネの福音書 11:44; ヨハネの福音書 20:5–7; 使徒の働き 5:6"> そこで、彼らはイエスのからだを取り、ユダヤ人の埋葬の習慣に従って、それを香料といっしょに亜麻布で巻いた。</span>
<span className="v" id="v41" data-v="41" data-xref="ルカの福音書 23:53; マタイの福音書 27:60; ヨハネの福音書 20:15"> イエスが十字架につけられた場所に園があって、そこには、まだだれも葬られたことのない新しい墓があった。</span>
<span className="v" id="v42" data-v="42" data-xref="ヨハネの福音書 19:31; ヨハネの福音書 19:14; Isaiah 53:9"> その日がユダヤ人の備え日であったため、墓が近かったので、彼らはイエスをそこに納めた。</span>
</div>

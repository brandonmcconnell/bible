<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マルコの福音書 6:31–44; ヨハネの福音書 6:23; ルカの福音書 5:1"> その後、イエスはガリラヤの湖、すなわち、テベリヤの湖の向こう岸へ行かれた。</span>
<span className="v" id="v2" data-v="2" data-xref="マタイの福音書 4:24–25; マタイの福音書 12:15; マタイの福音書 15:30–31"> 大ぜいの人の群れがイエスにつき従っていた。それはイエスが病人たちになさっていたしるしを見たからである。</span>
<span className="v" id="v3" data-v="3" data-xref="ヨハネの福音書 6:15; ルカの福音書 9:28; ルカの福音書 6:12–13"> イエスは山に登り、弟子たちとともにそこにすわられた。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネの福音書 2:13; ヨハネの福音書 11:55; ヨハネの福音書 5:1"> さて、ユダヤ人の祭りである過越が間近になっていた。</span>
<span className="v" id="v5" data-v="5" data-xref="マタイの福音書 15:33; ルカの福音書 9:12–13; マタイの福音書 14:14–15"> イエスは目を上げて、大ぜいの人の群れがご自分のほうに来るのを見て、ピリポに言われた。「どこからパンを買って来て、この人々に食べさせようか。」</span>
<span className="v" id="v6" data-v="6" data-xref="Genesis 22:1; Deuteronomy 13:3; 2 Chronicles 32:31"> もっとも、イエスは、ピリポをためしてこう言われたのであった。イエスは、ご自分では、しようとしていることを知っておられたからである。</span>
<span className="v" id="v7" data-v="7" data-xref="Numbers 11:21–22; マルコの福音書 6:37; ヨハネの福音書 12:5"> ピリポはイエスに答えた。「めいめいが少しずつ取るにしても、二百デナリのパンでは足りません。」</span>
<span className="v" id="v8" data-v="8" data-xref="ヨハネの福音書 1:40–44; マタイの福音書 4:18"> 弟子のひとりシモン・ペテロの兄弟アンデレがイエスに言った。</span>
<span className="v" id="v9" data-v="9" data-xref="2 Kings 4:42–44; マタイの福音書 14:17; マルコの福音書 6:38"> 「ここに少年が大麦のパンを五つと小さい魚を二匹持っています。しかし、こんなに大ぜいの人々では、それが何になりましょう。」</span>
<span className="v" id="v10" data-v="10" data-xref="ルカの福音書 9:14–16; マタイの福音書 15:35–36; マルコの福音書 6:39–41"> イエスは言われた。「人々をすわらせなさい。」その場所には草が多かった。そこで男たちはすわった。その数はおよそ五千人であった。</span>
<span className="v" id="v11" data-v="11" data-xref="ヨハネの福音書 6:23; テサロニケ人への手紙第一 5:18; マタイの福音書 15:36"> そこで、イエスはパンを取り、感謝をささげてから、すわっている人々に分けてやられた。また、小さい魚も同じようにして、彼らにほしいだけ分けられた。</span>
<span className="v" id="v12" data-v="12" data-xref="ルカの福音書 1:53; Nehemiah 9:25; Nehemiah 8:10"> そして、彼らが十分食べたとき、弟子たちに言われた。「余ったパン切れを、一つもむだに捨てないように集めなさい。」</span>
<span className="v" id="v13" data-v="13" data-xref="Proverbs 11:24–25; 2 Kings 4:2–7; コリント人への手紙第二 9:8–9"> 彼らは集めてみた。すると、大麦のパン五つから出て来たパン切れを、人々が食べたうえ、なお余ったもので十二のかごがいっぱいになった。</span>
<span className="v" id="v14" data-v="14" data-xref="Deuteronomy 18:15–18; マタイの福音書 21:11; 使徒の働き 7:37"> 人々は、イエスのなさったしるしを見て、「まことに、この方こそ、世に来られるはずの預言者だ。」と言った。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="ヨハネの福音書 18:36; ヨハネの福音書 6:15–21; ヨハネの福音書 7:3–4"> そこで、イエスは、人々が自分を王とするために、むりやりに連れて行こうとしているのを知って、ただひとり、また山に退かれた。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16"> 夕方になって、弟子たちは湖畔に降りて行った。</span>
<span className="v" id="v17" data-v="17" data-xref="マルコの福音書 6:45; ヨハネの福音書 6:24–25; ヨハネの福音書 2:12"> そして、舟に乗り込み、カペナウムのほうへ湖を渡っていた。すでに暗くなっていたが、イエスはまだ彼らのところに来ておられなかった。</span>
<span className="v" id="v18" data-v="18" data-xref="Psalms 107:25; Psalms 135:7; マタイの福音書 14:24"> 湖は吹きまくる強風に荒れ始めた。</span>
<span className="v" id="v19" data-v="19" data-xref="マルコの福音書 6:47–49; マタイの福音書 14:25–26; Job 9:8"> こうして、四、五千メートルほどこぎ出したころ、彼らは、イエスが湖の上を歩いて舟に近づいて来られるのを見て、恐れた。</span>
<span className="v" id="v20" data-v="20" data-xref="マタイの福音書 14:27–31; Isaiah 43:1–2; Isaiah 44:8"> しかし、イエスは彼らに言われた。「わたしだ。恐れることはない。」</span>
<span className="v" id="v21" data-v="21" data-xref="マルコの福音書 6:51; マタイの福音書 14:32–33; ヨハネの黙示録 3:20"> それで彼らは、イエスを喜んで舟に迎えた。舟はほどなく目的の地に着いた。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="マルコの福音書 6:45; マタイの福音書 14:22; ヨハネの福音書 6:2"> その翌日、湖の向こう岸にいた群衆は、そこには小舟が一隻あっただけで、ほかにはなかったこと、また、その舟にイエスは弟子たちといっしょに乗られないで、弟子たちだけが行ったということに気づいた。</span>
<span className="v" id="v23" data-v="23" data-xref="ヨハネの福音書 6:1; ヨハネの福音書 6:11–12"> しかし、主が感謝をささげられてから、人々がパンを食べた場所の近くに、テベリヤから数隻の小舟が来た。</span>
<span className="v" id="v24" data-v="24" data-xref="ヨハネの福音書 6:17; ルカの福音書 8:40; マルコの福音書 6:53"> 群衆は、イエスがそこにおられず、弟子たちもいないことを知ると、自分たちもその小舟に乗り込んで、イエスを捜してカペナウムに来た。</span>
<span className="v" id="v25" data-v="25" data-xref="ヨハネの福音書 1:38–39; マタイの福音書 23:7"> そして湖の向こう側でイエスを見つけたとき、彼らはイエスに言った。「先生。いつここにおいでになりましたか。」</span>
<span className="v" id="v26" data-v="26" data-xref="ヤコブの手紙 4:3–4; ピリピ人への手紙 3:19; ピリピ人への手紙 2:21"> イエスは答えて言われた。「まことに、まことに、あなたがたに告げます。あなたがたがわたしを捜しているのは、しるしを見たからではなく、パンを食べて満腹したからです。</span>
<span className="v" id="v27" data-v="27" data-xref="コロサイ人への手紙 3:2; Isaiah 55:2; ヨハネの福音書 6:54"> なくなる食物のためではなく、いつまでも保ち、永遠のいのちに至る食物のために働きなさい。それこそ、人の子があなたがたに与えるものです。この人の子を父すなわち神が認証されたからです。」</span>
<span className="v" id="v28" data-v="28" data-xref="使徒の働き 16:30; 使徒の働き 9:6; マタイの福音書 19:16"> すると彼らはイエスに言った。「私たちは、神のわざを行なうために、何をすべきでしょうか。」</span>
<span className="v" id="v29" data-v="29" data-xref="ヨハネの手紙第一 3:23; 使徒の働き 16:31; ヨハネの福音書 3:36"> イエスは答えて言われた。「あなたがたが、神が遣わした者を信じること、それが神のわざです。」</span>
<span className="v" id="v30" data-v="30" data-xref="ヨハネの福音書 12:37; ヨハネの福音書 10:38; コリント人への手紙第一 1:22"> そこで彼らはイエスに言った。「それでは、私たちが見てあなたを信じるために、しるしとして何をしてくださいますか。どのようなことをなさいますか。</span>
<span className="v" id="v31" data-v="31" data-xref="Nehemiah 9:15; Psalms 105:40; Psalms 78:24–25"> 私たちの先祖は、荒野でマナを食べました。『彼は彼らに天からパンを与えて食べさせた。』と書いてあるとおりです。」</span>
<span className="v" id="v32" data-v="32" data-xref="ヨハネの福音書 15:1; ヨハネの福音書 6:58; Exodus 16:4"> イエスは彼らに言われた。「まことに、まことに、あなたがたに告げます。モーセはあなたがたに天からのパンを与えたのではありません。しかし、わたしの父は、あなたがたに天からまことのパンをお与えになります。</span>
<span className="v" id="v33" data-v="33" data-xref="ヨハネの福音書 8:42; ヨハネの福音書 17:8; ヨハネの福音書 3:13"> というのは、神のパンは、天から下って来て、世にいのちを与えるものだからです。」</span>
<span className="v" id="v34" data-v="34" data-xref="ヨハネの福音書 4:15; ヨハネの福音書 6:26; Psalms 4:6"> そこで彼らはイエスに言った。「主よ。いつもそのパンを私たちにお与えください。」</span>
<span className="v" id="v35" data-v="35" data-xref="ヨハネの福音書 6:48–58; ヨハネの黙示録 22:17; ヨハネの福音書 6:41"> イエスは言われた。「わたしがいのちのパンです。わたしに来る者は決して飢えることがなく、わたしを信じる者はどんなときにも、決して渇くことがありません。</span>
<span className="v" id="v36" data-v="36" data-xref="ペテロの手紙第一 1:8–9; ルカの福音書 16:31; ヨハネの福音書 12:37"> しかし、あなたがたはわたしを見ながら信じようとしないと、わたしはあなたがたに言いました。</span>
<span className="v" id="v37" data-v="37" data-xref="マタイの福音書 11:28; ヨハネの福音書 6:39; ヨハネの福音書 17:24"> 父がわたしにお与えになる者はみな、わたしのところに来ます。そしてわたしのところに来る者を、わたしは決して捨てません。</span>
<span className="v" id="v38" data-v="38" data-xref="ヨハネの福音書 5:30; ヨハネの福音書 4:34; ヨハネの福音書 3:31"> わたしが天から下って来たのは、自分のこころを行なうためではなく、わたしを遣わした方のみこころを行なうためです。</span>
<span className="v" id="v39" data-v="39" data-xref="ヨハネの福音書 17:12; ヨハネの福音書 6:40; ヨハネの福音書 18:9"> わたしを遣わした方のみこころは、わたしに与えてくださったすべての者を、わたしがひとりも失うことなく、ひとりひとりを終わりの日によみがえらせることです。</span>
<span className="v" id="v40" data-v="40" data-xref="ヨハネの福音書 6:54; ヨハネの福音書 5:24; ローマ人への手紙 6:23"> 事実、わたしの父のみこころは、子を見て信じる者がみな永遠のいのちを持つことです。わたしはその人たちをひとりひとり終わりの日によみがえらせます。」</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="ヨハネの福音書 6:51–52; ヨハネの福音書 6:48; ヨハネの福音書 6:33"> ユダヤ人たちは、イエスが「わたしは天から下って来たパンである。」と言われたので、イエスについてつぶやいた。</span>
<span className="v" id="v42" data-v="42" data-xref="ルカの福音書 4:22; マルコの福音書 6:3; マタイの福音書 13:55–56"> 彼らは言った。「あれはヨセフの子で、われわれはその父も母も知っている、そのイエスではないか。どうしていま彼は『わたしは天から下って来た。』と言うのか。」</span>
<span className="v" id="v43" data-v="43" data-xref="ヘブル人への手紙 4:13; ヨハネの福音書 6:64; マルコの福音書 9:33"> イエスは彼らに答えて言われた。「互いにつぶやくのはやめなさい。</span>
<span className="v" id="v44" data-v="44" data-xref="ヨハネの福音書 6:65; ヨハネの福音書 6:39–40; マタイの福音書 11:25–27"> わたしを遣わした父が引き寄せられないかぎり、だれもわたしのところに来ることはできません。わたしは終わりの日にその人をよみがえらせます。</span>
<span className="v" id="v45" data-v="45" data-xref="Isaiah 54:13; Jeremiah 31:33–34; ヘブル人への手紙 10:16"> 預言者の書に、『そして、彼らはみな神によって教えられる。』と書かれていますが、父から聞いて学んだ者はみな、わたしのところに来ます。</span>
<span className="v" id="v46" data-v="46" data-xref="ヨハネの福音書 1:18; ヨハネの福音書 7:29; マタイの福音書 11:27"> だれも神を見た者はありません。ただ神から出た者、すなわち、この者だけが、父を見たのです。</span>
<span className="v" id="v47" data-v="47" data-xref="ヨハネの福音書 3:36; コロサイ人への手紙 3:3–4; ローマ人への手紙 5:9–10"> まことに、まことに、あなたがたに告げます。信じる者は永遠のいのちを持ちます。</span>
<span className="v" id="v48" data-v="48" data-xref="ヨハネの福音書 6:51; コリント人への手紙第一 11:24–25; コリント人への手紙第一 10:16–17"> わたしはいのちのパンです。</span>
<span className="v" id="v49" data-v="49" data-xref="コリント人への手紙第一 10:3–5; ユダの手紙 1:5; Zechariah 1:5"> あなたがたの先祖は荒野でマナを食べたが、死にました。</span>
<span className="v" id="v50" data-v="50" data-xref="ヨハネの福音書 6:33; ヨハネの福音書 6:51; ローマ人への手紙 8:10"> しかし、これは天から下って来たパンで、それを食べると死ぬことがないのです。</span>
<span className="v" id="v51" data-v="51" data-xref="ルカの福音書 22:19; ヨハネの福音書 6:33; ヘブル人への手紙 10:5–12"> わたしは、天から下って来た生けるパンです。だれでもこのパンを食べるなら、永遠に生きます。またわたしが与えようとするパンは、世のいのちのための、わたしの肉です。」</span>
</div>
<div className="bp">
<span className="v" id="v52" data-v="52" data-xref="ヨハネの福音書 9:16; ヨハネの福音書 10:19; ヨハネの福音書 6:41"> すると、ユダヤ人たちは、「この人は、どのようにしてその肉を私たちに与えて食べさせることができるのか。」と言って互いに議論し合った。</span>
<span className="v" id="v53" data-v="53" data-xref="ヨハネの手紙第一 5:12; マタイの福音書 26:26–28; ヨハネの福音書 6:55"> イエスは彼らに言われた。「まことに、まことに、あなたがたに告げます。人の子の肉を食べ、またその血を飲まなければ、あなたがたのうちに、いのちはありません。</span>
<span className="v" id="v54" data-v="54" data-xref="ヨハネの福音書 6:39–40; ヨハネの福音書 6:27; ピリピ人への手紙 3:7–10"> わたしの肉を食べ、わたしの血を飲む者は、永遠のいのちを持っています。わたしは終わりの日にその人をよみがえらせます。</span>
<span className="v" id="v55" data-v="55" data-xref="ヨハネの福音書 15:1; ヨハネの福音書 8:31; ヨハネの福音書 6:32"> わたしの肉はまことの食物、わたしの血はまことの飲み物だからです。</span>
<span className="v" id="v56" data-v="56" data-xref="ヨハネの手紙第一 3:24; ヨハネの福音書 15:4–5; ヨハネの福音書 14:20"> わたしの肉を食べ、わたしの血を飲む者は、わたしのうちにとどまり、わたしも彼のうちにとどまります。</span>
<span className="v" id="v57" data-v="57" data-xref="ガラテヤ人への手紙 2:20; ヨハネの福音書 5:26; ヨハネの福音書 17:21"> 生ける父がわたしを遣わし、わたしが父によって生きているように、わたしを食べる者も、わたしによって生きるのです。</span>
<span className="v" id="v58" data-v="58" data-xref="ヨハネの福音書 3:36; ヨハネの福音書 6:47–51; ヨハネの福音書 6:41"> これは、天から下って来たパンです。あなたがたの先祖が食べて死んだようなものではありません。このパンを食べる者は永遠に生きます。」</span>
<span className="v" id="v59" data-v="59" data-xref="ヨハネの福音書 6:24; Proverbs 8:1–3; ルカの福音書 4:31"> これは、イエスがカペナウムで教えられたとき、会堂で話されたことである。</span>
</div>
<div className="bp">
<span className="v" id="v60" data-v="60" data-xref="ヨハネの福音書 6:66; ヨハネの福音書 8:43; ヨハネの福音書 8:31"> そこで、弟子たちのうちの多くの者が、これを聞いて言った。「これはひどいことばだ。そんなことをだれが聞いておられようか。」</span>
<span className="v" id="v61" data-v="61" data-xref="ヨハネの福音書 2:24–25; ヨハネの福音書 6:64; ヨハネの福音書 21:17"> しかし、イエスは、弟子たちがこうつぶやいているのを、知っておられ、彼らに言われた。「このことであなたがたはつまずくのか。</span>
<span className="v" id="v62" data-v="62" data-xref="マルコの福音書 16:19; ヨハネの福音書 3:13; ヨハネの福音書 17:4–5"> それでは、もし人の子がもといた所に上るのを見たら、どうなるのか。</span>
<span className="v" id="v63" data-v="63" data-xref="ガラテヤ人への手紙 5:25; ヘブル人への手紙 4:12; Psalms 119:93"> いのちを与えるのは御霊です。肉は何の益ももたらしません。わたしがあなたがたに話したことばは、霊であり、またいのちです。</span>
<span className="v" id="v64" data-v="64" data-xref="ヨハネの福音書 10:26; テモテへの手紙第二 2:19; ヘブル人への手紙 4:13"> しかし、あなたがたのうちには信じない者がいます。」――イエスは初めから、信じない者がだれであるか、裏切る者がだれであるかを、知っておられたのである。――</span>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マルコの福音書 16:9; マタイの福音書 27:60; ヨハネの福音書 19:25"> さて、週の初めの日に、マグダラのマリヤは、朝早くまだ暗いうちに墓に来た。そして、墓から石が取りのけてあるのを見た。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネの福音書 13:23; ヨハネの福音書 20:13; ヨハネの福音書 21:24"> それで、走って、シモン・ペテロと、イエスが愛された、もうひとりの弟子とのところに来て、言った。「だれかが墓から主を取って行きました。主をどこに置いたのか、私たちにはわかりません。」</span>
<span className="v" id="v3" data-v="3" data-xref="ルカの福音書 24:12"> そこでペテロともうひとりの弟子は外に出て来て、墓のほうへ行った。</span>
<span className="v" id="v4" data-v="4" data-xref="2 Samuel 18:23; コリント人への手紙第二 8:12; コリント人への手紙第一 9:24"> ふたりはいっしょに走ったが、もうひとりの弟子がペテロよりも速かったので、先に墓に着いた。</span>
<span className="v" id="v5" data-v="5" data-xref="ヨハネの福音書 19:40; ヨハネの福音書 20:11; ヨハネの福音書 11:44"> そして、からだをかがめてのぞき込み、亜麻布が置いてあるのを見たが、中にはいらなかった。</span>
<span className="v" id="v6" data-v="6" data-xref="ヨハネの福音書 18:17; ヨハネの福音書 21:7; マタイの福音書 16:15–16"> シモン・ペテロも彼に続いて来て、墓にはいり、亜麻布が置いてあって、</span>
<span className="v" id="v7" data-v="7" data-xref="ヨハネの福音書 11:44"> イエスの頭に巻かれていた布切れは、亜麻布といっしょにはなく、離れた所に巻かれたままになっているのを見た。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨハネの福音書 20:25; ヨハネの福音書 20:4; ヨハネの福音書 1:50"> そのとき、先に墓に着いたもうひとりの弟子もはいって来た。そして、見て、信じた。</span>
<span className="v" id="v9" data-v="9" data-xref="Psalms 16:10; Isaiah 25:8; Isaiah 53:10–12"> 彼らは、イエスが死人の中からよみがえらなければならないという聖書を、まだ理解していなかったのである。</span>
<span className="v" id="v10" data-v="10" data-xref="ヨハネの福音書 7:53; ヨハネの福音書 16:32"> それで、弟子たちはまた自分のところに帰って行った。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="ヨハネの福音書 20:5"> しかし、マリヤは外で墓のところにたたずんで泣いていた。そして、泣きながら、からだをかがめて墓の中をのぞき込んだ。</span>
<span className="v" id="v12" data-v="12" data-xref="ルカの福音書 24:3–7; ヨハネの黙示録 3:4; マルコの福音書 16:5–6"> すると、ふたりの御使いが、イエスのからだが置かれていた場所に、ひとりは頭のところに、ひとりは足のところに、白い衣をまとってすわっているのが見えた。</span>
<span className="v" id="v13" data-v="13" data-xref="ヨハネの福音書 20:15; ヨハネの福音書 2:4; 1 Samuel 1:8"> 彼らは彼女に言った。「なぜ泣いているのですか。」彼女は言った。「だれかが私の主を取って行きました。どこに置いたのか、私にはわからないのです。」</span>
<span className="v" id="v14" data-v="14" data-xref="ルカの福音書 24:16; ヨハネの福音書 21:4; マタイの福音書 28:9"> 彼女はこう言ってから、うしろを振り向いた。すると、イエスが立っておられるのを見た。しかし、彼女にはイエスであることがわからなかった。</span>
<span className="v" id="v15" data-v="15" data-xref="ヨハネの福音書 20:13; ヨハネの福音書 18:7; ヨハネの福音書 1:38"> イエスは彼女に言われた。「なぜ泣いているのですか。だれを捜しているのですか。」彼女は、それを園の管理人だと思って言った。「あなたが、あの方を運んだのでしたら、どこに置いたのか言ってください。そうすれば私が引き取ります。」</span>
<span className="v" id="v16" data-v="16" data-xref="ヨハネの福音書 10:3; ヨハネの福音書 1:38; 使徒の働き 10:3"> イエスは彼女に言われた。「マリヤ。」彼女は振り向いて、ヘブル語で、「ラボニ（すなわち、先生）。」とイエスに言った。</span>
<span className="v" id="v17" data-v="17" data-xref="ヨハネの福音書 16:28; エペソ人への手紙 4:8–10; ガラテヤ人への手紙 4:6–7"> イエスは彼女に言われた。「わたしにすがりついていてはいけません。わたしはまだ父のもとに上っていないからです。わたしの兄弟たちのところに行って、彼らに『わたしは、わたしの父またあなたがたの父、わたしの神またあなたがたの神のもとに上る。』と告げなさい。」</span>
<span className="v" id="v18" data-v="18" data-xref="ルカの福音書 24:10; マタイの福音書 28:10; ヨハネの福音書 20:1"> マグダラのマリヤは、行って、「私は主にお目にかかりました。」と言い、また、主が彼女にこれらのことを話されたと弟子たちに告げた。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="ヨハネの福音書 20:26; ヨハネの福音書 14:27; ヨハネの福音書 20:21"> その日、すなわち週の初めの日の夕方のことであった。弟子たちがいた所では、ユダヤ人を恐れて戸がしめてあったが、イエスが来られ、彼らの中に立って言われた。「平安があなたがたにあるように。」</span>
<span className="v" id="v20" data-v="20" data-xref="ヨハネの福音書 16:22; ヨハネの福音書 16:20; ヨハネの福音書 20:27"> こう言ってイエスは、その手とわき腹を彼らに示された。弟子たちは、主を見て喜んだ。</span>
<span className="v" id="v21" data-v="21" data-xref="ヨハネの福音書 17:18–19; ヨハネの福音書 13:20; ヨハネの福音書 3:17"> イエスはもう一度、彼らに言われた。「平安があなたがたにあるように。父がわたしを遣わしたように、わたしもあなたがたを遣わします。」</span>
<span className="v" id="v22" data-v="22" data-xref="Job 33:4; Genesis 2:7; 使徒の働き 8:15"> そして、こう言われると、彼らに息を吹きかけて言われた。「聖霊を受けなさい。</span>
<span className="v" id="v23" data-v="23" data-xref="マタイの福音書 18:18; マタイの福音書 16:19; マルコの福音書 2:5–10"> あなたがたがだれかの罪を赦すなら、その人の罪は赦され、あなたがたがだれかの罪をそのまま残すなら、それはそのまま残ります。」</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="ヨハネの福音書 11:16; ヨハネの福音書 6:66–67; ヘブル人への手紙 10:25"> 十二弟子のひとりで、デドモと呼ばれるトマスは、イエスが来られたときに、彼らといっしょにいなかった。</span>
<span className="v" id="v25" data-v="25" data-xref="ヨハネの福音書 6:30; マルコの福音書 16:11; ヘブル人への手紙 3:12"> それで、ほかの弟子たちが彼に「私たちは主を見た。」と言った。しかし、トマスは彼らに「私は、その手に釘の跡を見、私の指を釘のところに差し入れ、また私の手をそのわきに差し入れてみなければ、決して信じません。」と言った。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="ヨハネの福音書 20:19; Isaiah 54:10; ヨハネの福音書 20:21"> 八日後に、弟子たちはまた室内におり、トマスも彼らといっしょにいた。戸が閉じられていたが、イエスが来て、彼らの中に立って「平安があなたがたにあるように。」と言われた。</span>
<span className="v" id="v27" data-v="27" data-xref="ヨハネの福音書 20:25; ヨハネの手紙第一 1:1–2; ヨハネの福音書 20:20"> それからトマスに言われた。「あなたの指をここにつけて、わたしの手を見なさい。手を伸ばして、わたしのわきに差し入れなさい。信じない者にならないで、信じる者になりなさい。」</span>
<span className="v" id="v28" data-v="28" data-xref="ヨハネの福音書 1:1; Isaiah 9:6; Isaiah 7:14"> トマスは答えてイエスに言った。「私の主。私の神。」</span>
<span className="v" id="v29" data-v="29" data-xref="ペテロの手紙第一 1:8; コリント人への手紙第二 5:7; ヘブル人への手紙 11:1"> イエスは彼に言われた。「あなたはわたしを見たから信じたのですか。見ずに信じる者は幸いです。」</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="ヨハネの福音書 21:25; テモテへの手紙第二 3:15–17; ローマ人への手紙 15:4"> この書には書かれていないが、まだほかの多くのしるしをも、イエスは弟子たちの前で行なわれた。</span>
<span className="v" id="v31" data-v="31" data-xref="使徒の働き 10:43; ヨハネの福音書 3:15–16; ヨハネの手紙第一 5:1"> しかし、これらのことが書かれたのは、イエスが神の子キリストであることを、あなたがたが信じるため、また、あなたがたが信じて、イエスの御名によっていのちを得るためである。</span>
</div>

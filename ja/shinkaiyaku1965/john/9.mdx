<div className="bible-chapter" lang="ja" dir="ltr" data-lang="ja" data-translation="shinkaiyaku1965" data-translation-id="jpn_loc" data-translation-label="新改訳 1965" data-book="JHN" data-book-slug="john" data-book-name="ヨハネの福音書" data-chapter="9" data-verses="41">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> またイエスは道の途中で、生まれつきの盲人を見られた。</span>
<span className="v" id="v2" data-v="2" data-xref="ルカの福音書 13:2; ヨハネの福音書 9:34; 使徒の働き 28:4"> 弟子たちは彼についてイエスに質問して言った。「先生。彼が盲目に生まれついたのは、だれが罪を犯したからですか。この人ですか。その両親ですか。」</span>
<span className="v" id="v3" data-v="3" data-xref="ヨハネの福音書 11:4; ヨハネの福音書 11:40; Ecclesiastes 9:1–2"> イエスは答えられた。「この人が罪を犯したのでもなく、両親でもありません。神のわざがこの人に現われるためです。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネの福音書 12:35; エペソ人への手紙 5:16; ヨハネの福音書 4:34"> わたしたちは、わたしを遣わした方のわざを、昼の間に行なわなければなりません。だれも働くことのできない夜が来ます。</span>
<span className="v" id="v5" data-v="5" data-xref="ヨハネの福音書 8:12; ヨハネの福音書 12:46; 使徒の働き 13:47"> わたしが世にいる間、わたしは世の光です。」</span>
<span className="v" id="v6" data-v="6" data-xref="マルコの福音書 8:23; マルコの福音書 7:33; ヨハネの黙示録 3:18"> イエスは、こう言ってから、地面につばきをして、そのつばきで泥を作られた。そしてその泥を盲人の目に塗って言われた。</span>
<span className="v" id="v7" data-v="7" data-xref="Isaiah 35:5; ヨハネの福音書 9:11; ヨハネの福音書 11:37"> 「行って、シロアム（訳して言えば、遣わされた者）の池で洗いなさい。」そこで、彼は行って、洗った。すると、見えるようになって、帰って行った。</span>
<span className="v" id="v8" data-v="8" data-xref="1 Samuel 2:8; 1 Samuel 21:11; ルカの福音書 18:35"> 近所の人たちや、前に彼がこじきをしていたのを見ていた人たちが言った。「これはすわって物ごいをしていた人ではないか。」</span>
<span className="v" id="v9" data-v="9"> ほかの人は、「これはその人だ。」と言い、またほかの人は、「そうではない。ただその人に似ているだけだ。」と言った。当人は、「私がその人です。」と言った。</span>
<span className="v" id="v10" data-v="10" data-xref="ヨハネの福音書 9:26; ヨハネの福音書 9:21; Ecclesiastes 11:5"> そこで、彼らは言った。「それでは、あなたの目はどのようにしてあいたのですか。」</span>
<span className="v" id="v11" data-v="11" data-xref="ヨハネの福音書 9:6–7; ヨハネの福音書 9:27; Jeremiah 36:17"> 彼は答えた。「イエスという方が、泥を作って、私の目に塗り、『シロアムの池に行って洗いなさい。』と私に言われました。それで、行って洗うと、見えるようになりました。」</span>
<span className="v" id="v12" data-v="12" data-xref="ヨハネの福音書 5:11–13; Exodus 2:18–20; ヨハネの福音書 7:11"> また彼らは彼に言った。「その人はどこにいるのですか。」彼は「私は知りません。」と言った。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="ヨハネの福音書 11:57; ヨハネの福音書 11:46–47; ヨハネの福音書 12:42"> 彼らは、前に盲目であったその人を、パリサイ人たちのところに連れて行った。</span>
<span className="v" id="v14" data-v="14" data-xref="ヨハネの福音書 5:9; ルカの福音書 13:10–17; マタイの福音書 12:1–14"> ところで、イエスが泥を作って彼の目をあけられたのは、安息日であった。</span>
<span className="v" id="v15" data-v="15" data-xref="ヨハネの福音書 9:26–27; ヨハネの福音書 9:10–11"> こういうわけでもう一度、パリサイ人も彼に、どのようにして見えるようになったかを尋ねた。彼は言った。「あの方が私の目に泥を塗ってくださって、私が洗いました。私はいま見えるのです。」</span>
<span className="v" id="v16" data-v="16" data-xref="ヨハネの福音書 7:43; ヨハネの福音書 10:19; マタイの福音書 12:2"> すると、パリサイ人の中のある人々が、「その人は神から出たのではない。安息日を守らないからだ。」と言った。しかし、ほかの者は言った。「罪人である者に、どうしてこのようなしるしを行なうことができよう。」そして、彼らの間に、分裂が起こった。</span>
<span className="v" id="v17" data-v="17" data-xref="ヨハネの福音書 4:19; ヨハネの福音書 6:14; 使徒の働き 3:22–26"> そこで彼らはもう一度、盲人に言った。「あの人が目をあけてくれたことで、あの人を何だと思っているのか。」彼は言った。「あの方は預言者です。」</span>
<span className="v" id="v18" data-v="18" data-xref="ヘブル人への手紙 3:15–19; ヨハネの福音書 5:44; Isaiah 26:11"> しかしユダヤ人たちは、目が見えるようになったこの人について、彼が盲目であったが見えるようになったということを信ぜず、ついにその両親を呼び出して、</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="ヨハネの福音書 9:8–9; 使徒の働き 4:14; 使徒の働き 3:10"> 尋ねて言った。「この人はあなたがたの息子で、生まれつき盲目だったとあなたがたが言っている人ですか。それでは、どうしていま見えるのですか。」</span>
<span className="v" id="v20" data-v="20"> そこで両親は答えた。「私たちは、これが私たちの息子で、生まれつき盲目だったことを知っています。</span>
<span className="v" id="v21" data-v="21"> しかし、どのようにしていま見えるのかは知りません。また、だれがあれの目をあけたのか知りません。あれに聞いてください。あれはもうおとなです。自分のことは自分で話すでしょう。」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="ヨハネの福音書 7:13; ヨハネの福音書 16:2; ルカの福音書 6:22"> 彼の両親がこう言ったのは、ユダヤ人たちを恐れたからであった。すでにユダヤ人たちは、イエスをキリストであると告白する者があれば、その者を会堂から追放すると決めていたからである。</span>
<span className="v" id="v23" data-v="23" data-xref="ヨハネの福音書 9:21"> そのために彼の両親は、「あれはもうおとなです。あれに聞いてください。」と言ったのである。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="Joshua 7:19; ヨハネの福音書 9:16; ヨハネの福音書 8:49"> そこで彼らは、盲目であった人をもう一度呼び出して言った。「神に栄光を帰しなさい。私たちはあの人が罪人であることを知っているのだ。」</span>
<span className="v" id="v25" data-v="25" data-xref="ヨハネの手紙第一 5:10; ヨハネの福音書 9:30; ヨハネの福音書 5:11"> 彼は答えた。「あの方が罪人かどうか、私は知りません。ただ一つのことだけ知っています。私は盲目であったのに、今は見えるということです。」</span>
<span className="v" id="v26" data-v="26"> そこで彼らは言った。「あの人はおまえに何をしたのか。どのようにしてその目をあけたのか。」</span>
<span className="v" id="v27" data-v="27" data-xref="ルカの福音書 22:67; ヨハネの福音書 9:10–15"> 彼は答えた。「もうお話ししたのですが、あなたがたは聞いてくれませんでした。なぜもう一度聞こうとするのです。あなたがたも、あの方の弟子になりたいのですか。」</span>
<span className="v" id="v28" data-v="28" data-xref="ローマ人への手紙 2:17; ヨハネの福音書 7:19; マタイの福音書 27:39"> 彼らは彼をののしって言った。「おまえもあの者の弟子だ。しかし私たちはモーセの弟子だ。</span>
<span className="v" id="v29" data-v="29" data-xref="ヨハネの福音書 8:14; Numbers 12:2–7; 使徒の働き 7:35"> 私たちは、神がモーセにお話しになったことは知っている。しかし、あの者については、どこから来たのか知らないのだ。」</span>
<span className="v" id="v30" data-v="30" data-xref="ヨハネの福音書 12:37; Psalms 119:18; Isaiah 29:18"> 彼は答えて言った。「これは、驚きました。あなたがたは、あの方がどこから来られたのか、ご存じないと言う。しかし、あの方は私の目をおあけになったのです。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="Proverbs 15:29; Isaiah 1:15; Proverbs 28:9"> 神は、罪人の言うことはお聞きになりません。しかし、だれでも神を敬い、そのみこころを行なうなら、神はその人の言うことを聞いてくださると、私たちは知っています。</span>
<span className="v" id="v32" data-v="32" data-xref="Isaiah 64:4; ヨハネの黙示録 16:18; Job 20:4"> 盲目に生まれついた者の目をあけた者があるなどとは、昔から聞いたこともありません。</span>
<span className="v" id="v33" data-v="33" data-xref="ヨハネの福音書 9:16; ヨハネの福音書 3:2; 使徒の働き 5:38–39"> もしあの方が神から出ておられるのでなかったら、何もできないはずです。」</span>
<span className="v" id="v34" data-v="34" data-xref="ヨハネの福音書 9:22; ヨハネの福音書 9:2; Isaiah 66:5"> 彼らは答えて言った。「おまえは全く罪の中に生まれていながら、私たちを教えるのか。」そして、彼を外に追い出した。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="ヨハネの福音書 20:31; ヨハネの手紙第一 5:13; ヨハネの福音書 10:36"> イエスは、彼らが彼を追放したことを聞き、彼を見つけ出して言われた。「あなたは人の子を信じますか。」</span>
<span className="v" id="v36" data-v="36" data-xref="ローマ人への手紙 10:14; Song of Solomon 5:9; ヨハネの福音書 1:38"> その人は答えた。「主よ。その方はどなたでしょうか。私がその方を信じることができますように。」</span>
<span className="v" id="v37" data-v="37" data-xref="ヨハネの福音書 4:26; Psalms 25:8–9; ヨハネの福音書 14:21–23"> イエスは彼に言われた。「あなたはその方を見たのです。あなたと話しているのがそれです。」</span>
<span className="v" id="v38" data-v="38" data-xref="マタイの福音書 14:33; マタイの福音書 28:9; ルカの福音書 24:52"> 彼は言った。「主よ。私は信じます。」そして彼はイエスを拝した。</span>
<span className="v" id="v39" data-v="39" data-xref="ヨハネの福音書 3:19; ヨハネの福音書 12:46; 使徒の働き 26:18"> そこで、イエスは言われた。「わたしはさばきのためにこの世に来ました。それは、目の見えない者が見えるようになり、見える者が盲目となるためです。」</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="ヨハネの黙示録 3:17; マタイの福音書 15:12–14; ヨハネの福音書 7:47–52"> パリサイ人の中でイエスとともにいた人々が、このことを聞いて、イエスに言った。「私たちも盲目なのですか。」</span>
<span className="v" id="v41" data-v="41" data-xref="Isaiah 5:21; ヨハネの福音書 15:22–24; ヨハネの手紙第一 1:8–10"> イエスは彼らに言われた。「もしあなたがたが盲目であったなら、あなたがたに罪はなかったでしょう。しかし、あなたがたは今、『私たちは目が見える。』と言っています。あなたがたの罪は残るのです。」</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨハネの福音書 4:46; Proverbs 31:10–12; ヨハネの福音書 21:2"> それから三日目に、ガリラヤのカナで婚礼があって、そこにイエスの母がいた。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネの福音書 1:40–49; マタイの福音書 10:40–42; コリント人への手紙第一 7:39"> イエスも、また弟子たちも、その婚礼に招かれた。</span>
<span className="v" id="v3" data-v="3" data-xref="Psalms 104:15; ピリピ人への手紙 4:6; Isaiah 24:11"> ぶどう酒がなくなったとき、母がイエスに向かって「ぶどう酒がありません。」と言った。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネの福音書 7:6; ヨハネの福音書 13:1; ヨハネの福音書 7:30"> すると、イエスは母に言われた。「あなたはわたしと何の関係があるのでしょう。女の方。わたしの時はまだ来ていません。」</span>
<span className="v" id="v5" data-v="5" data-xref="ヨハネの福音書 15:14; Genesis 6:22; ヘブル人への手紙 11:8"> 母は手伝いの人たちに言った。「あの方が言われることを、何でもしてあげてください。」</span>
<span className="v" id="v6" data-v="6" data-xref="ヨハネの福音書 3:25; ヘブル人への手紙 9:10; エペソ人への手紙 5:26"> さて、そこには、ユダヤ人のきよめのしきたりによって、それぞれ八十リットルから百二十リットル入りの石の水がめが六つ置いてあった。</span>
<span className="v" id="v7" data-v="7" data-xref="2 Kings 4:2–6; ヨハネの福音書 2:5; ヨハネの福音書 2:3"> イエスは彼らに言われた。「水がめに水を満たしなさい。」彼らは水がめを縁までいっぱいにした。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨハネの福音書 2:9; Proverbs 3:5–6; ローマ人への手紙 13:7"> イエスは彼らに言われた。「さあ、今くみなさい。そして宴会の世話役のところに持って行きなさい。」彼らは持って行った。</span>
<span className="v" id="v9" data-v="9" data-xref="ヨハネの福音書 4:46; ヨハネの福音書 7:17; Psalms 119:100"> 宴会の世話役はぶどう酒になったその水を味わってみた。それがどこから来たのか、知らなかったので、――しかし、水をくんだ手伝いの者たちは知っていた。――彼は、花婿を呼んで、</span>
<span className="v" id="v10" data-v="10" data-xref="ヨハネの黙示録 7:16–17; Proverbs 9:1–6; ルカの福音書 16:25"> 言った。「だれでも初めに良いぶどう酒を出し、人々が十分飲んだころになると、悪いのを出すものだが、あなたは良いぶどう酒をよくも今まで取っておきました。」</span>
<span className="v" id="v11" data-v="11" data-xref="ヨハネの福音書 20:30–31; ヨハネの福音書 1:14; ヨハネの福音書 3:2"> イエスはこのことを最初のしるしとしてガリラヤのカナで行ない、ご自分の栄光を現わされた。それで、弟子たちはイエスを信じた。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="マタイの福音書 12:46; マタイの福音書 13:55–56; マルコの福音書 6:3"> その後、イエスは母や兄弟たちや弟子たちといっしょに、カペナウムに下って行き、長い日数ではなかったが、そこに滞在された。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="ルカの福音書 2:41; ヨハネの福音書 11:55; ヨハネの福音書 2:23"> ユダヤ人の過越の祭りが近づき、イエスはエルサレムに上られた。</span>
<span className="v" id="v14" data-v="14" data-xref="ルカの福音書 19:45–46; マルコの福音書 11:15; マルコの福音書 11:17"> そして、宮の中に、牛や羊や鳩を売る者たちと両替人たちがすわっているのをご覧になり、</span>
<span className="v" id="v15" data-v="15" data-xref="ヨハネの福音書 18:6; Zechariah 4:6; コリント人への手紙第二 10:4"> 細なわでむちを作って、羊も牛もみな、宮から追い出し、両替人の金を散らし、その台を倒し、</span>
<span className="v" id="v16" data-v="16" data-xref="マタイの福音書 21:13; Jeremiah 7:11; マルコの福音書 11:17"> また、鳩を売る者に言われた。「それをここから持って行け。わたしの父の家を商売の家としてはならない。」</span>
<span className="v" id="v17" data-v="17" data-xref="Psalms 69:9; Psalms 119:139"> 弟子たちは、「あなたの家を思う熱心がわたしを食い尽くす。」と書いてあるのを思い起こした。</span>
<span className="v" id="v18" data-v="18" data-xref="マタイの福音書 21:23; マルコの福音書 8:11; マルコの福音書 11:27–28"> そこで、ユダヤ人たちが答えて言った。「あなたがこのようなことをするからには、どんなしるしを私たちに見せてくれるのですか。」</span>
<span className="v" id="v19" data-v="19" data-xref="マルコの福音書 14:58; マルコの福音書 15:29; マタイの福音書 27:40"> イエスは彼らに答えて言われた。「この神殿をこわしてみなさい。わたしは、三日でそれを建てよう。」</span>
<span className="v" id="v20" data-v="20"> そこで、ユダヤ人たちは言った。「この神殿は建てるのに四十六年かかりました。あなたはそれを、三日で建てるのですか。」</span>
<span className="v" id="v21" data-v="21" data-xref="コリント人への手紙第一 6:19; コリント人への手紙第一 3:16; エペソ人への手紙 2:20–22"> しかし、イエスはご自分のからだの神殿のことを言われたのである。</span>
<span className="v" id="v22" data-v="22" data-xref="ヨハネの福音書 12:16; ヨハネの福音書 16:4; ルカの福音書 24:7–8"> それで、イエスが死人の中からよみがえられたとき、弟子たちは、イエスがこのように言われたことを思い起こして、聖書とイエスが言われたことばとを信じた。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="ヨハネの福音書 7:31; ルカの福音書 8:13; ヨハネの福音書 6:14"> イエスが、過越の祭りの祝いの間、エルサレムにおられたとき、多くの人々が、イエスの行なわれたしるしを見て、御名を信じた。</span>
<span className="v" id="v24" data-v="24" data-xref="ヨハネの福音書 6:64; ヘブル人への手紙 4:13; 使徒の働き 1:24"> しかし、イエスは、ご自身を彼らにお任せにならなかった。なぜなら、イエスはすべての人を知っておられたからであり、</span>
<span className="v" id="v25" data-v="25" data-xref="ヨハネの福音書 13:11; マタイの福音書 9:4; ヨハネの福音書 6:64"> また、イエスはご自身で、人のうちにあるものを知っておられたので、人についてだれの証言も必要とされなかったからである。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨハネの福音書 19:39; ヨハネの福音書 7:47–50; ヨハネの福音書 3:10"> さて、パリサイ人の中にニコデモという人がいた。ユダヤ人の指導者であった。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネの福音書 5:36; 使徒の働き 10:38; 使徒の働き 2:22"> この人が、夜、イエスのもとに来て言った。「先生。私たちは、あなたが神のもとから来られた教師であることを知っています。神がともにおられるのでなければ、あなたがなさるこのようなしるしは、だれも行なうことができません。」</span>
<span className="v" id="v3" data-v="3" data-xref="コリント人への手紙第二 5:17; ヨハネの福音書 3:5–6; ペテロの手紙第一 1:23–25"> イエスは答えて言われた。「まことに、まことに、あなたに告げます。人は、新しく生まれなければ、神の国を見ることはできません。」</span>
<span className="v" id="v4" data-v="4" data-xref="コリント人への手紙第一 2:14; コリント人への手紙第一 1:18; ヨハネの福音書 3:3"> ニコデモは言った。「人は、老年になっていて、どのようにして生まれることができるのですか。もう一度、母の胎にはいって生まれることができましょうか。」</span>
<span className="v" id="v5" data-v="5" data-xref="Ezekiel 36:25–27; エペソ人への手紙 5:26; 使徒の働き 2:38"> イエスは答えられた。「まことに、まことに、あなたに告げます。人は、水と御霊によって生まれなければ、神の国にはいることができません。</span>
<span className="v" id="v6" data-v="6" data-xref="ガラテヤ人への手紙 5:16–21; Ezekiel 36:26–27; ローマ人への手紙 8:4–9"> 肉によって生まれた者は肉です。御霊によって生まれた者は霊です。</span>
<span className="v" id="v7" data-v="7" data-xref="ヨハネの福音書 3:3; エペソ人への手紙 4:22–24; ローマ人への手紙 12:1–2"> あなたがたは新しく生まれなければならない、とわたしが言ったことを不思議に思ってはなりません。</span>
<span className="v" id="v8" data-v="8" data-xref="Ecclesiastes 11:4–5; コリント人への手紙第一 2:11; 使徒の働き 2:2"> 風はその思いのままに吹き、あなたはその音を聞くが、それがどこから来てどこへ行くかを知らない。御霊によって生まれる者もみな、そのとおりです。」</span>
<span className="v" id="v9" data-v="9" data-xref="ヨハネの福音書 6:60; ルカの福音書 1:34; Isaiah 42:16"> ニコデモは答えて言った。「どうして、そのようなことがありうるのでしょう。」</span>
<span className="v" id="v10" data-v="10" data-xref="マタイの福音書 22:29; Jeremiah 8:8–9; Ezekiel 11:19"> イエスは答えて言われた。「あなたはイスラエルの教師でありながら、こういうことがわからないのですか。</span>
<span className="v" id="v11" data-v="11" data-xref="ヨハネの福音書 8:38; ヨハネの手紙第一 5:6–12; ヨハネの福音書 12:49"> まことに、まことに、あなたに告げます。わたしたちは、知っていることを話し、見たことをあかししているのに、あなたがたは、わたしたちのあかしを受け入れません。</span>
<span className="v" id="v12" data-v="12" data-xref="コリント人への手紙第一 3:1–2; コリント人への手紙第一 2:7–9; ヘブル人への手紙 5:11"> あなたがたは、わたしが地上のことを話したとき、信じないくらいなら、天上のことを話したとて、どうして信じるでしょう。</span>
<span className="v" id="v13" data-v="13" data-xref="Proverbs 30:4; ヨハネの福音書 6:38; 使徒の働き 2:34"> だれも天に上った者はいません。しかし天から下った者はいます。すなわち人の子です。</span>
<span className="v" id="v14" data-v="14" data-xref="Numbers 21:7–9; ヨハネの福音書 8:28; ヨハネの福音書 12:32–34"> モーセが荒野で蛇を上げたように、人の子もまた上げられなければなりません。</span>
<span className="v" id="v15" data-v="15" data-xref="ヨハネの福音書 3:16; ヨハネの福音書 6:40; ヨハネの福音書 12:44–46"> それは、信じる者がみな、人の子にあって永遠のいのちを持つためです。」</span>
<span className="v" id="v16" data-v="16" data-xref="ローマ人への手紙 5:8; ヨハネの手紙第一 4:9–10; ヨハネの福音書 3:15"> 神は、実に、そのひとり子をお与えになったほどに、世を愛された。それは御子を信じる者が、ひとりとして滅びることなく、永遠のいのちを持つためである。</span>
<span className="v" id="v17" data-v="17" data-xref="ヨハネの手紙第一 4:14; ルカの福音書 19:10; ヨハネの福音書 12:47–48"> 神が御子を世に遣わされたのは、世をさばくためではなく、御子によって世が救われるためである。</span>
<span className="v" id="v18" data-v="18" data-xref="マルコの福音書 16:16; ヨハネの手紙第一 5:10; ローマ人への手紙 8:1"> 御子を信じる者はさばかれない。信じない者は神のひとり子の御名を信じなかったので、すでにさばかれている。</span>
<span className="v" id="v19" data-v="19" data-xref="ヨハネの福音書 8:12; テサロニケ人への手紙第二 2:12; ヨハネの福音書 9:39–41"> そのさばきというのは、こうである。光が世に来ているのに、人々は光よりもやみを愛した。その行ないが悪かったからである。</span>
<span className="v" id="v20" data-v="20" data-xref="エペソ人への手紙 5:11–13; ヨハネの福音書 7:7; Job 24:13–17"> 悪いことをする者は光を憎み、その行ないが明るみに出されることを恐れて、光のほうに来ない。</span>
<span className="v" id="v21" data-v="21" data-xref="ヨハネの手紙第一 1:6; Psalms 139:23–24; ヨハネの手紙第三 1:11"> しかし、真理を行なう者は、光のほうに来る。その行ないが神にあってなされたことが明らかにされるためである。</span>
<span className="v" id="v22" data-v="22" data-xref="ヨハネの福音書 4:1–3; ヨハネの福音書 3:26; ヨハネの福音書 2:13"> その後、イエスは弟子たちと、ユダヤの地に行き、彼らとともにそこに滞在して、バプテスマを授けておられた。</span>
<span className="v" id="v23" data-v="23" data-xref="マルコの福音書 1:4–5; Ezekiel 43:2; マタイの福音書 3:5–6"> 一方ヨハネもサリムに近いアイノンでバプテスマを授けていた。そこには水が多かったからである。人々は次々にやって来て、バプテスマを受けていた。</span>
<span className="v" id="v24" data-v="24" data-xref="マタイの福音書 4:12; マタイの福音書 14:3; マルコの福音書 6:17"> ――ヨハネは、まだ投獄されていなかったからである。――</span>
<span className="v" id="v25" data-v="25" data-xref="ヨハネの福音書 2:6; マタイの福音書 3:11; ヘブル人への手紙 6:2"> それで、ヨハネの弟子たちが、あるユダヤ人ときよめについて論議した。</span>
<span className="v" id="v26" data-v="26" data-xref="ヨハネの福音書 1:7; ヨハネの福音書 1:15; ヨハネの福音書 12:19"> 彼らはヨハネのところに来て言った。「先生。見てください。ヨルダンの向こう岸であなたといっしょにいて、あなたが証言なさったあの方が、バプテスマを授けておられます。そして、みなあの方のほうへ行きます。」</span>
<span className="v" id="v27" data-v="27" data-xref="ヤコブの手紙 1:17; コリント人への手紙第一 4:7; コリント人への手紙第一 15:10"> ヨハネは答えて言った。「人は、天から与えられるのでなければ、何も受けることはできません。</span>
<span className="v" id="v28" data-v="28" data-xref="ヨハネの福音書 1:20; ヨハネの福音書 1:23; マタイの福音書 3:11–12"> あなたがたこそ、『私はキリストではなく、その前に遣わされた者である。』と私が言ったことの証人です。</span>
<span className="v" id="v29" data-v="29" data-xref="マタイの福音書 9:15; Hosea 2:19; Isaiah 54:5"> 花嫁を迎える者は花婿です。そこにいて、花婿のことばに耳を傾けているその友人は、花婿の声を聞いて大いに喜びます。それで、私もその喜びで満たされているのです。</span>
<span className="v" id="v30" data-v="30" data-xref="コロサイ人への手紙 1:18; Psalms 72:17–19; ヘブル人への手紙 3:2–6"> あの方は盛んになり私は衰えなければなりません。」</span>
<span className="v" id="v31" data-v="31" data-xref="ヨハネの福音書 8:23; マタイの福音書 28:18; ローマ人への手紙 9:5"> 上から来る方は、すべてのものの上におられ、地から出る者は地に属し、地のことばを話す。天から来る方は、すべてのものの上におられる。</span>
<span className="v" id="v32" data-v="32" data-xref="ヨハネの福音書 3:11; ヨハネの福音書 15:15; ヨハネの福音書 1:11"> この方は見たこと、また聞いたことをあかしされるが、だれもそのあかしを受け入れない。</span>
<span className="v" id="v33" data-v="33" data-xref="ヘブル人への手紙 6:17; エペソ人への手紙 1:13; テトスへの手紙 1:1–2"> そのあかしを受け入れた者は、神は真実であるということに確認の印を押したのである。</span>
<span className="v" id="v34" data-v="34" data-xref="使徒の働き 10:38; マタイの福音書 12:18; ヨハネの福音書 15:26"> 神がお遣わしになった方は、神のことばを話される。神が御霊を無限に与えられるからである。</span>
<span className="v" id="v35" data-v="35" data-xref="マタイの福音書 28:18; ヨハネの福音書 5:22; ヨハネの福音書 5:20"> 父は御子を愛しておられ、万物を御子の手にお渡しになった。</span>
<span className="v" id="v36" data-v="36" data-xref="ヨハネの福音書 5:24; ヨハネの福音書 1:12; テサロニケ人への手紙第一 5:9"> 御子を信じる者は永遠のいのちを持つが、御子に聞き従わない者は、いのちを見ることがなく、神の怒りがその上にとどまる。</span>

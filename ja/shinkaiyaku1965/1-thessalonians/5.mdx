<span className="v" id="v1" data-v="1" data-xref="使徒の働き 1:7; テサロニケ人への手紙第一 4:9; マタイの福音書 24:36"> 兄弟たち。それらがいつなのか、またどういう時かについては、あなたがたは私たちに書いてもらう必要がありません。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネの黙示録 16:15; ペテロの手紙第二 3:10; マタイの福音書 24:42–44"> 主の日が夜中の盗人のように来るということは、あなたがた自身がよく承知しているからです。</span>
<span className="v" id="v3" data-v="3" data-xref="ルカの福音書 21:34–35; マタイの福音書 24:37–39; ルカの福音書 17:26–30"> 人々が「平和だ。安全だ。」と言っているそのようなときに、突如として滅びが彼らに襲いかかります。ちょうど妊婦に産みの苦しみが臨むようなもので、それをのがれることは決してできません。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネの手紙第一 2:8; ペテロの手紙第二 3:10; Deuteronomy 19:6"> しかし、兄弟たち。あなたがたは暗やみの中にはいないのですから、その日が、盗人のようにあなたがたを襲うことはありません。</span>
<span className="v" id="v5" data-v="5" data-xref="エペソ人への手紙 5:8; 使徒の働き 26:18; ヨハネの福音書 12:36"> あなたがたはみな、光の子ども、昼の子どもだからです。私たちは、夜や暗やみの者ではありません。</span>
<span className="v" id="v6" data-v="6" data-xref="ペテロの手紙第一 1:13; マタイの福音書 24:42; ルカの福音書 22:46"> ですから、ほかの人々のように眠っていないで、目をさまして、慎み深くしていましょう。</span>
<span className="v" id="v7" data-v="7" data-xref="ローマ人への手紙 13:13; コリント人への手紙第一 15:34; ペテロの手紙第二 2:13"> 眠る者は夜眠り、酔う者は夜酔うからです。</span>
<span className="v" id="v8" data-v="8" data-xref="ローマ人への手紙 13:12–13; エペソ人への手紙 6:11; ペテロの手紙第一 1:13"> しかし、私たちは昼の者なので、信仰と愛を胸当てとして着け、救いの望みをかぶととしてかぶって、慎み深くしていましょう。</span>
<span className="v" id="v9" data-v="9" data-xref="テサロニケ人への手紙第一 1:10; ペテロの手紙第一 2:10; テモテへの手紙第二 2:10"> 神は、私たちが御怒りに会うようにお定めになったのではなく、主イエス・キリストにあって救いを得るようにお定めになったからです。</span>
<span className="v" id="v10" data-v="10" data-xref="ローマ人への手紙 14:8–9; ペテロの手紙第一 3:18; ローマ人への手紙 8:34"> 主が私たちのために死んでくださったのは、私たちが、目ざめていても、眠っていても、主とともに生きるためです。</span>
<span className="v" id="v11" data-v="11" data-xref="エペソ人への手紙 4:29; ヘブル人への手紙 10:25; ローマ人への手紙 15:2"> ですから、あなたがたは、今しているとおり、互いに励まし合い、互いに徳を高め合いなさい。</span>
<span className="v" id="v12" data-v="12" data-xref="ヘブル人への手紙 13:17; ヘブル人への手紙 13:7; テモテへの手紙第一 5:17–18"> 兄弟たちよ。あなたがたにお願いします。あなたがたの間で労苦し、主にあってあなたがたを指導し、訓戒している人々を認めなさい。</span>
<span className="v" id="v13" data-v="13" data-xref="マルコの福音書 9:50; ヘブル人への手紙 12:14; ガラテヤ人への手紙 6:6"> その務めのゆえに、愛をもって深い尊敬を払いなさい。お互いの間に平和を保ちなさい。</span>
<span className="v" id="v14" data-v="14" data-xref="テモテへの手紙第二 4:2; ローマ人への手紙 14:1; 使徒の働き 20:35"> 兄弟たち。あなたがたに勧告します。気ままな者を戒め、小心な者を励まし、弱い者を助け、すべての人に対して寛容でありなさい。</span>
<span className="v" id="v15" data-v="15" data-xref="ペテロの手紙第一 3:9; ガラテヤ人への手紙 6:10; Leviticus 19:18"> だれも悪をもって悪に報いないように気をつけ、お互いの間で、またすべての人に対して、いつも善を行なうよう務めなさい。</span>
<span className="v" id="v16" data-v="16" data-xref="ローマ人への手紙 12:12; ピリピ人への手紙 4:4; マタイの福音書 5:12"> いつも喜んでいなさい。</span>
<span className="v" id="v17" data-v="17" data-xref="ローマ人への手紙 12:12; コロサイ人への手紙 4:2; エペソ人への手紙 6:18"> 絶えず祈りなさい。</span>
<span className="v" id="v18" data-v="18" data-xref="エペソ人への手紙 5:20; ピリピ人への手紙 4:6; コロサイ人への手紙 3:17"> すべての事について、感謝しなさい。これが、キリスト・イエスにあって神があなたがたに望んでおられることです。</span>
<span className="v" id="v19" data-v="19" data-xref="エペソ人への手紙 4:30; 使徒の働き 7:51; テモテへの手紙第二 1:6"> 御霊を消してはなりません。</span>
<span className="v" id="v20" data-v="20" data-xref="コリント人への手紙第一 14:3–6; コリント人への手紙第一 14:1; Numbers 11:25–29"> 預言をないがしろにしてはいけません。</span>
<span className="v" id="v21" data-v="21" data-xref="ヨハネの手紙第一 4:1; ローマ人への手紙 12:2; エペソ人への手紙 5:10"> すべてのことを見分けて、ほんとうに良いものを堅く守りなさい。</span>
<span className="v" id="v22" data-v="22" data-xref="コリント人への手紙第二 6:3; ピリピ人への手紙 4:8; コリント人への手紙第一 10:31–33"> 悪はどんな悪でも避けなさい。</span>
<span className="v" id="v23" data-v="23" data-xref="ユダの手紙 1:24; ヘブル人への手紙 4:12; コリント人への手紙第一 1:8–9"> 平和の神ご自身が、あなたがたを全くきよめてくださいますように。主イエス・キリストの来臨のとき、責められるところのないように、あなたがたの霊、たましい、からだが完全に守られますように。</span>
<span className="v" id="v24" data-v="24" data-xref="テサロニケ人への手紙第二 3:3; Numbers 23:19; コリント人への手紙第一 1:9"> あなたがたを召された方は真実ですから、きっとそのことをしてくださいます。</span>
<span className="v" id="v25" data-v="25" data-xref="ヘブル人への手紙 13:18–19; ピリピ人への手紙 1:19; ピレモンへの手紙 1:22"> 兄弟たち。私たちのためにも祈ってください。</span>
<span className="v" id="v26" data-v="26" data-xref="ローマ人への手紙 16:16; コリント人への手紙第一 16:20"> すべての兄弟たちに、きよい口づけをもってあいさつをなさい。</span>
<span className="v" id="v27" data-v="27" data-xref="コロサイ人への手紙 4:16; 使徒の働き 19:13; テモテへの手紙第一 1:3"> この手紙がすべての兄弟たちに読まれるように、主によって命じます。</span>
<span className="v" id="v28" data-v="28" data-xref="ローマ人への手紙 16:20; テサロニケ人への手紙第二 3:18; ローマ人への手紙 16:23"> 私たちの主イエス・キリストの恵みが、あなたがたとともにありますように。</span>

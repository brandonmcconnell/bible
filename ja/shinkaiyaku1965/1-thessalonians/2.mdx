<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="テサロニケ人への手紙第二 3:1; コリント人への手紙第一 15:2; コリント人への手紙第一 15:58"> 兄弟たち。あなたがたが知っているとおり、私たちがあなたがたのところに行ったことは、むだではありませんでした。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒の働き 16:22–24; 使徒の働き 4:13; 使徒の働き 17:2–9"> ご承知のように、私たちはまずピリピで苦しみに会い、はずかしめを受けたのですが、私たちの神によって、激しい苦闘の中でも大胆に神の福音をあなたがたに語りました。</span>
<span className="v" id="v3" data-v="3" data-xref="コリント人への手紙第二 2:17; コリント人への手紙第二 4:2; テサロニケ人への手紙第一 4:7"> 私たちの勧めは、迷いや不純な心から出ているものではなく、だましごとでもありません。</span>
<span className="v" id="v4" data-v="4" data-xref="ガラテヤ人への手紙 1:10; ローマ人への手紙 8:27; ガラテヤ人への手紙 2:7"> 私たちは神に認められて福音をゆだねられた者ですから、それにふさわしく、人を喜ばせようとしてではなく、私たちの心をお調べになる神を喜ばせようとして語るのです。</span>
<span className="v" id="v5" data-v="5" data-xref="ローマ人への手紙 1:9; コリント人への手紙第二 12:17; 使徒の働き 20:33"> ご存じのとおり、私たちは今まで、へつらいのことばを用いたり、むさぼりの口実を設けたりしたことはありません。神がそのことの証人です。</span>
<span className="v" id="v6" data-v="6" data-xref="ガラテヤ人への手紙 1:10; テサロニケ人への手紙第一 2:9; ヨハネの福音書 5:41"> また、キリストの使徒たちとして権威を主張することもできたのですが、私たちは、あなたがたからも、ほかの人々からも、人からの名誉を受けようとはしませんでした。</span>
<span className="v" id="v7" data-v="7" data-xref="Isaiah 66:13; テサロニケ人への手紙第一 2:11; テモテへの手紙第二 2:24–25"> それどころか、あなたがたの間で、母がその子どもたちを養い育てるように、優しくふるまいました。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨハネの手紙第一 3:16; コリント人への手紙第二 12:15; ピリピ人への手紙 2:17"> このようにあなたがたを思う心から、ただ神の福音だけではなく、私たち自身のいのちまでも、喜んであなたがたに与えたいと思ったのです。なぜなら、あなたがたは私たちの愛する者となったからです。</span>
<span className="v" id="v9" data-v="9" data-xref="テサロニケ人への手紙第二 3:7–9; コリント人への手紙第二 11:9; 使徒の働き 18:3"> 兄弟たち。あなたがたは、私たちの労苦と苦闘を覚えているでしょう。私たちはあなたがたのだれにも負担をかけまいとして、昼も夜も働きながら、神の福音をあなたがたに宣べ伝えました。</span>
<span className="v" id="v10" data-v="10" data-xref="ペテロの手紙第一 5:3; テサロニケ人への手紙第一 1:5; コリント人への手紙第二 1:12"> また、信者であるあなたがたに対して、私たちが敬虔に、正しく、また責められるところがないようにふるまったことは、あなたがたがあかしし、神もあかししてくださることです。</span>
<span className="v" id="v11" data-v="11" data-xref="コリント人への手紙第一 4:14–15; ヘブル人への手紙 13:22; テモテへの手紙第一 5:21"> また、ご承知のとおり、私たちは父がその子どもに対してするように、あなたがたひとりひとりに、</span>
<span className="v" id="v12" data-v="12" data-xref="エペソ人への手紙 4:1; ヨハネの手紙第一 2:6; ヨハネの手紙第一 1:6–7"> ご自身の御国と栄光とに召してくださる神にふさわしく歩むように勧めをし、慰めを与え、おごそかに命じました。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="ヘブル人への手紙 4:12; ローマ人への手紙 10:17; ペテロの手紙第一 1:23"> こういうわけで、私たちとしてもまた、絶えず神に感謝しています。あなたがたは、私たちから神の使信のことばを受けたとき、それを人間のことばとしてではなく、事実どおりに神のことばとして受け入れてくれたからです。この神のことばは、信じているあなたがたのうちに働いているのです。</span>
<span className="v" id="v14" data-v="14" data-xref="テサロニケ人への手紙第一 3:4; ヘブル人への手紙 10:33–34; ヘブル人への手紙 5:7–8"> 兄弟たち。あなたがたはユダヤの、キリスト・イエスにある神の諸教会にならう者となったのです。彼らがユダヤ人に苦しめられたのと同じように、あなたがたも自分の国の人に苦しめられたのです。</span>
<span className="v" id="v15" data-v="15" data-xref="マタイの福音書 5:12; ルカの福音書 11:48–53; 使徒の働き 7:52"> ユダヤ人は、主であられるイエスをも、預言者たちをも殺し、また私たちをも追い出し、神に喜ばれず、すべての人の敵となっています。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒の働き 17:13; 使徒の働き 14:19; マルコの福音書 16:16"> 彼らは、私たちが異邦人の救いのために語るのを妨げ、このようにして、いつも自分の罪を満たしています。しかし、御怒りは彼らの上に臨んで窮みに達しました。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="コロサイ人への手紙 2:5; コリント人への手紙第一 5:3; テサロニケ人への手紙第一 3:6"> 兄弟たちよ。私たちは、しばらくの間あなたがたから引き離されたので、――といっても、顔を見ないだけで、心においてではありませんが、――なおさらのこと、あなたがたの顔を見たいと切に願っていました。</span>
<span className="v" id="v18" data-v="18" data-xref="ローマ人への手紙 15:22; ローマ人への手紙 1:13; ヨハネの黙示録 2:10"> それで私たちは、あなたがたのところに行こうとしました。このパウロは一度ならず二度までも心を決めたのです。しかし、サタンが私たちを妨げました。</span>
<span className="v" id="v19" data-v="19" data-xref="ピリピ人への手紙 4:1; テサロニケ人への手紙第一 3:13; ピリピ人への手紙 2:16"> 私たちの主イエスが再び来られるとき、御前で私たちの望み、喜び、誇りの冠となるのはだれでしょう。あなたがたではありませんか。</span>
<span className="v" id="v20" data-v="20" data-xref="コリント人への手紙第二 1:14; コリント人への手紙第一 11:7; Proverbs 17:6"> あなたがたこそ私たちの誉れであり、また喜びなのです。</span>
</div>

<span className="v" id="v1" data-v="1" data-xref="コロサイ人への手紙 1:10; テサロニケ人への手紙第二 1:3; ペテロの手紙第二 3:18"> 終わりに、兄弟たちよ。主イエスにあって、お願いし、また勧告します。あなたがたはどのように歩んで神を喜ばすべきかを私たちから学んだように、また、事実いまあなたがたが歩んでいるように、ますますそのように歩んでください。</span>
<span className="v" id="v2" data-v="2" data-xref="マタイの福音書 28:20; Ezekiel 3:17; テサロニケ人への手紙第二 3:10"> 私たちが、主イエスによって、どんな命令をあなたがたに授けたかを、あなたがたは知っています。</span>
<span className="v" id="v3" data-v="3" data-xref="ペテロの手紙第一 4:2; ローマ人への手紙 12:2; テサロニケ人への手紙第一 5:23"> 神のみこころは、あなたがたがきよくなることです。あなたがたが不品行を避け、</span>
<span className="v" id="v4" data-v="4" data-xref="コリント人への手紙第一 7:9; ローマ人への手紙 12:1; ヘブル人への手紙 13:4"> 各自わきまえて、自分のからだを、きよく、また尊く保ち、</span>
<span className="v" id="v5" data-v="5" data-xref="ガラテヤ人への手紙 4:8; 使徒の働き 17:30–31; エペソ人への手紙 4:17–19"> 神を知らない異邦人のように情欲におぼれず、</span>
<span className="v" id="v6" data-v="6" data-xref="ヘブル人への手紙 13:4; Exodus 20:17; ローマ人への手紙 12:19"> また、このようなことで、兄弟を踏みつけたり、欺いたりしないことです。なぜなら、主はこれらすべてのことについて正しくさばかれるからです。これは、私たちが前もってあなたがたに話し、きびしく警告しておいたところです。</span>
<span className="v" id="v7" data-v="7" data-xref="Leviticus 11:44; エペソ人への手紙 1:4; ペテロの手紙第一 2:9–12"> 神が私たちを召されたのは、汚れを行なわせるためではなく、聖潔を得させるためです。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨハネの手紙第一 3:24; ルカの福音書 10:16; ヨハネの福音書 12:48"> ですから、このことを拒む者は、人を拒むのではなく、あなたがたに聖霊をお与えになる神を拒むのです。</span>
<span className="v" id="v9" data-v="9" data-xref="ヨハネの手紙第一 3:11; ローマ人への手紙 12:10; ヨハネの手紙第一 3:23"> 兄弟愛については、何も書き送る必要がありません。あなたがたこそ、互いに愛し合うことを神から教えられた人たちだからです。</span>
<span className="v" id="v10" data-v="10" data-xref="ピリピ人への手紙 1:9; テサロニケ人への手紙第一 3:12; テサロニケ人への手紙第二 1:3"> 実にマケドニヤ全土のすべての兄弟たちに対して、あなたがたはそれを実行しています。しかし、兄弟たち。あなたがたにお勧めします。どうか、さらにますますそうであってください。</span>
<span className="v" id="v11" data-v="11" data-xref="Ecclesiastes 4:6; エペソ人への手紙 4:28; ペテロの手紙第一 3:4"> また、私たちが命じたように、落ち着いた生活をすることを志し、自分の仕事に身を入れ、自分の手で働きなさい。</span>
<span className="v" id="v12" data-v="12" data-xref="コロサイ人への手紙 4:5; ペテロの手紙第一 2:12; ローマ人への手紙 12:17"> 外の人々に対してもりっぱにふるまうことができ、また乏しいことがないようにするためです。</span>
<span className="v" id="v13" data-v="13" data-xref="Daniel 12:2; テサロニケ人への手紙第一 4:15; テサロニケ人への手紙第一 5:10"> 眠った人々のことについては、兄弟たち、あなたがたに知らないでいてもらいたくありません。あなたがたが他の望みのない人々のように悲しみに沈むことのないためです。</span>
<span className="v" id="v14" data-v="14" data-xref="ローマ人への手紙 8:11; ピリピ人への手紙 3:20–21; Isaiah 26:19"> 私たちはイエスが死んで復活されたことを信じています。それならば、神はまたそのように、イエスにあって眠った人々をイエスといっしょに連れて来られるはずです。</span>
<span className="v" id="v15" data-v="15" data-xref="コリント人への手紙第一 15:51–53; コリント人への手紙第二 4:14; テサロニケ人への手紙第一 2:19"> 私たちは主のみことばのとおりに言いますが、主が再び来られるときまで生き残っている私たちが、死んでいる人々に優先するようなことは決してありません。</span>
<span className="v" id="v16" data-v="16" data-xref="コリント人への手紙第一 15:51–52; ヨハネの黙示録 1:7; マタイの福音書 24:30–31"> 主は、号令と、御使いのかしらの声と、神のラッパの響きのうちに、ご自身天から下って来られます。それからキリストにある死者が、まず初めによみがえり、</span>
<span className="v" id="v17" data-v="17" data-xref="コリント人への手紙第一 15:52; ヨハネの黙示録 11:12; ヨハネの福音書 14:3"> 次に、生き残っている私たちが、たちまち彼らといっしょに雲の中に一挙に引き上げられ、空中で主と会うのです。このようにして、私たちは、いつまでも主とともにいることになります。</span>
<span className="v" id="v18" data-v="18" data-xref="テサロニケ人への手紙第一 5:11; ルカの福音書 21:28; テサロニケ人への手紙第一 5:14"> こういうわけですから、このことばをもって互いに慰め合いなさい。</span>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="コロサイ人への手紙 1:29; ピリピ人への手紙 1:30; ヨハネの黙示録 3:14–22"> あなたがたとラオデキヤの人たちと、そのほか直接私の顔を見たことのない人たちのためにも、私がどんなに苦闘しているか、知ってほしいと思います。</span>
<span className="v" id="v2" data-v="2" data-xref="コロサイ人への手紙 1:27; コロサイ人への手紙 4:8; エペソ人への手紙 6:22"> それは、この人たちが心に励ましを受け、愛によって結び合わされ、理解をもって豊かな全き確信に達し、神の奥義であるキリストを真に知るようになるためです。</span>
<span className="v" id="v3" data-v="3" data-xref="コリント人への手紙第一 1:24; コリント人への手紙第一 1:30; ローマ人への手紙 11:33"> このキリストのうちに、知恵と知識との宝がすべて隠されているのです。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネの手紙第一 4:1; エペソ人への手紙 4:14; ローマ人への手紙 16:18–19"> 私がこう言うのは、だれもまことしやかな議論によって、あなたがたをあやまちに導くことのないためです。</span>
<span className="v" id="v5" data-v="5" data-xref="コリント人への手紙第一 5:3–4; テサロニケ人への手紙第一 2:17; コリント人への手紙第一 16:13"> 私は、肉体においては離れていても、霊においてはあなたがたといっしょにいて、あなたがたの秩序とキリストに対する堅い信仰とを見て喜んでいます。</span>
<span className="v" id="v6" data-v="6" data-xref="コロサイ人への手紙 1:10; ヨハネの手紙第一 2:6; テサロニケ人への手紙第一 4:1"> あなたがたは、このように主キリスト・イエスを受け入れたのですから、彼にあって歩みなさい。</span>
<span className="v" id="v7" data-v="7" data-xref="エペソ人への手紙 3:17; Jeremiah 17:8; エペソ人への手紙 2:20–22"> キリストの中に根ざし、また建てられ、また、教えられたとおり信仰を堅くし、あふれるばかり感謝しなさい。</span>
<span className="v" id="v8" data-v="8" data-xref="テモテへの手紙第一 6:20; エペソ人への手紙 5:6; マタイの福音書 7:15"> あのむなしい、だましごとの哲学によってだれのとりこにもならぬよう、注意しなさい。そのようなものは、人の言い伝えによるものであり、この世に属する幼稚な教えによるものであって、キリストに基づくものではありません。</span>
<span className="v" id="v9" data-v="9" data-xref="コロサイ人への手紙 1:19; ヨハネの福音書 10:30; ヨハネの福音書 1:14"> キリストのうちにこそ、神の満ち満ちたご性質が形をとって宿っています。</span>
<span className="v" id="v10" data-v="10" data-xref="エペソ人への手紙 3:19; コロサイ人への手紙 1:16–18; エペソ人への手紙 1:20–23"> そしてあなたがたは、キリストにあって、満ち満ちているのです。キリストはすべての支配と権威のかしらです。</span>
<span className="v" id="v11" data-v="11" data-xref="ローマ人への手紙 2:29; ピリピ人への手紙 3:3; ローマ人への手紙 6:6"> キリストにあって、あなたがたは人の手によらない割礼を受けました。肉のからだを脱ぎ捨て、キリストの割礼を受けたのです。</span>
<span className="v" id="v12" data-v="12" data-xref="ローマ人への手紙 6:3–5; ペテロの手紙第一 3:21; ガラテヤ人への手紙 3:27"> あなたがたは、バプテスマによってキリストとともに葬られ、また、キリストを死者の中からよみがえらせた神の力を信じる信仰によって、キリストとともによみがえらされたのです。</span>
<span className="v" id="v13" data-v="13" data-xref="エペソ人への手紙 2:5–6; ローマ人への手紙 8:11; エペソ人への手紙 2:1"> あなたがたは罪によって、また肉の割礼がなくて死んだ者であったのに、神は、そのようなあなたがたを、キリストとともに生かしてくださいました。それは、私たちのすべての罪を赦し、</span>
<span className="v" id="v14" data-v="14" data-xref="Isaiah 44:22; エペソ人への手紙 2:14–16; Isaiah 43:25"> いろいろな定めのために私たちに不利な、いや、私たちを責め立てている債務証書を無効にされたからです。神はこの証書を取りのけ、十字架に釘づけにされました。</span>
<span className="v" id="v15" data-v="15" data-xref="ヘブル人への手紙 2:14; エペソ人への手紙 4:8; マタイの福音書 12:29"> 神は、キリストにおいて、すべての支配と権威の武装を解除してさらしものとし、彼らを捕虜として凱旋の行列に加えられました。</span>
<span className="v" id="v16" data-v="16" data-xref="ローマ人への手紙 14:5–6; ローマ人への手紙 14:10; ガラテヤ人への手紙 4:10"> こういうわけですから、食べ物と飲み物について、あるいは、祭りや新月や安息日のことについて、だれにもあなたがたを批評させてはなりません。</span>
<span className="v" id="v17" data-v="17" data-xref="ヘブル人への手紙 10:1; ヘブル人への手紙 8:5; ヨハネの福音書 1:17"> これらは、次に来るものの影であって、本体はキリストにあるのです。</span>
<span className="v" id="v18" data-v="18" data-xref="コロサイ人への手紙 2:8; ヨハネの手紙第一 4:1–2; コロサイ人への手紙 2:23"> あなたがたは、ことさらに自己卑下をしようとしたり、御使い礼拝をしようとする者に、ほうびをだまし取られてはなりません。彼らは幻を見たことに安住して、肉の思いによっていたずらに誇り、</span>
<span className="v" id="v19" data-v="19" data-xref="エペソ人への手紙 4:15–16; ヨハネの福音書 15:4–6; ペテロの手紙第二 3:18"> かしらに堅く結びつくことをしません。このかしらがもとになり、からだ全体は、関節と筋によって養われ、結び合わされて、神によって成長させられるのです。</span>
<span className="v" id="v20" data-v="20" data-xref="コロサイ人への手紙 2:8; コロサイ人への手紙 2:16; ガラテヤ人への手紙 4:3"> もしあなたがたが、キリストとともに死んで、この世の幼稚な教えから離れたのなら、どうして、まだこの世の生き方をしているかのように、</span>
<span className="v" id="v21" data-v="21" data-xref="テモテへの手紙第一 4:3; Genesis 3:3; Isaiah 52:11"> 「すがるな。味わうな。さわるな。」というような定めに縛られるのですか。</span>
<span className="v" id="v22" data-v="22" data-xref="Isaiah 29:13; テトスへの手紙 1:14; コリント人への手紙第一 6:13"> そのようなものはすべて、用いれば滅びるものについてであって、人間の戒めと教えによるものです。</span>
<span className="v" id="v23" data-v="23" data-xref="テモテへの手紙第一 4:8; コロサイ人への手紙 2:18; コロサイ人への手紙 2:8"> そのようなものは、人間の好き勝手な礼拝とか、謙遜とか、または、肉体の苦行などのゆえに賢いもののように見えますが、肉のほしいままな欲望に対しては、何のききめもないのです。</span>

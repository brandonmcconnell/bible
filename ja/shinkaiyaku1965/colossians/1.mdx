<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="コリント人への手紙第二 1:1; コリント人への手紙第一 1:1; ピレモンへの手紙 1:1"> 神のみこころによる、キリスト・イエスの使徒パウロ、および兄弟テモテから、</span>
<span className="v" id="v2" data-v="2" data-xref="ペテロの手紙第二 1:2; エペソ人への手紙 1:1; ローマ人への手紙 1:7"> コロサイにいる聖徒たちで、キリストにある忠実な兄弟たちへ。どうか、私たちの父なる神から、恵みと平安があなたがたの上にありますように。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="テサロニケ人への手紙第一 1:2; コロサイ人への手紙 1:9; テモテへの手紙第二 1:3"> 私たちは、いつもあなたがたのために祈り、私たちの主イエス・キリストの父なる神に感謝しています。</span>
<span className="v" id="v4" data-v="4" data-xref="エペソ人への手紙 1:15; テサロニケ人への手紙第二 1:3; テサロニケ人への手紙第一 1:3"> それは、キリスト・イエスに対するあなたがたの信仰と、すべての聖徒に対してあなたがたが抱いている愛のことを聞いたからです。</span>
<span className="v" id="v5" data-v="5" data-xref="ペテロの手紙第一 1:3–4; エペソ人への手紙 1:13; テモテへの手紙第二 4:8"> それらは、あなたがたのために天にたくわえられてある望みに基づくものです。あなたがたは、すでにこの望みのことを、福音の真理のことばの中で聞きました。</span>
<span className="v" id="v6" data-v="6" data-xref="ヨハネの福音書 15:16; ピリピ人への手紙 1:11; コロサイ人への手紙 1:23"> この福音は、あなたがたが神の恵みを聞き、それをほんとうに理解したとき以来、あなたがたの間でも見られるとおりの勢いをもって、世界中で、実を結び広がり続けています。福音はそのようにしてあなたがたに届いたのです。</span>
<span className="v" id="v7" data-v="7" data-xref="コロサイ人への手紙 4:12; ピレモンへの手紙 1:23; コロサイ人への手紙 4:7"> これはあなたがたが私たちと同じしもべである愛するエパフラスから学んだとおりのものです。彼は私たちに代わって仕えている忠実な、キリストの仕え人であって、</span>
<span className="v" id="v8" data-v="8" data-xref="ローマ人への手紙 15:30; テモテへの手紙第二 1:7; ガラテヤ人への手紙 5:22"> 私たちに、御霊によるあなたがたの愛を知らせてくれました。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="ヤコブの手紙 3:17; ピリピ人への手紙 1:9–11; ヤコブの手紙 1:5"> こういうわけで、私たちはそのことを聞いた日から、絶えずあなたがたのために祈り求めています。どうか、あなたがたがあらゆる霊的な知恵と理解力によって、神のみこころに関する真の知識に満たされますように。</span>
<span className="v" id="v10" data-v="10" data-xref="エペソ人への手紙 4:1; ヘブル人への手紙 13:21; ペテロの手紙第二 1:2–3"> また、主にかなった歩みをして、あらゆる点で主に喜ばれ、あらゆる善行のうちに実を結び、神を知る知識を増し加えられますように。</span>
<span className="v" id="v11" data-v="11" data-xref="エペソ人への手紙 3:16; ピリピ人への手紙 4:13; エペソ人への手紙 4:2"> また、神の栄光ある権能に従い、あらゆる力をもって強くされて、忍耐と寛容を尽くし、</span>
<span className="v" id="v12" data-v="12" data-xref="使徒の働き 20:32; エペソ人への手紙 1:11; エペソ人への手紙 1:18"> また、光の中にある、聖徒の相続分にあずかる資格を私たちに与えてくださった父なる神に、喜びをもって感謝をささげることができますように。</span>
<span className="v" id="v13" data-v="13" data-xref="エペソ人への手紙 5:8; 使徒の働き 26:18; ペテロの手紙第一 2:9"> 神は、私たちを暗やみの圧制から救い出して、愛する御子のご支配の中に移してくださいました。</span>
<span className="v" id="v14" data-v="14" data-xref="エペソ人への手紙 1:7; ローマ人への手紙 3:24–25; ペテロの手紙第一 1:19–20"> この御子のうちにあって、私たちは、贖い、すなわち罪の赦しを得ています。</span>
<span className="v" id="v15" data-v="15" data-xref="ヘブル人への手紙 1:3; ヨハネの福音書 14:9; ヨハネの福音書 1:1"> 御子は、見えない神のかたちであり、造られたすべてのものより先に生まれた方です。</span>
<span className="v" id="v16" data-v="16" data-xref="ローマ人への手紙 11:36; ヨハネの福音書 1:3; コリント人への手紙第一 8:6"> なぜなら、万物は御子にあって造られたからです。天にあるもの、地にあるもの、見えるもの、また見えないもの、王座も主権も支配も権威も、すべて御子によって造られたのです。万物は、御子によって造られ、御子のために造られたのです。</span>
<span className="v" id="v17" data-v="17" data-xref="ヘブル人への手紙 1:3; コリント人への手紙第一 8:6; 使徒の働き 17:28"> 御子は、万物よりも先に存在し、万物は御子にあって成り立っています。</span>
<span className="v" id="v18" data-v="18" data-xref="エペソ人への手紙 1:22–23; ヨハネの黙示録 1:5; エペソ人への手紙 4:15–16"> また、御子はそのからだである教会のかしらです。御子は初めであり、死者の中から最初に生まれた方です。こうして、ご自身がすべてのことにおいて、第一のものとなられたのです。</span>
<span className="v" id="v19" data-v="19" data-xref="コロサイ人への手紙 2:9; ヨハネの福音書 1:16; エペソ人への手紙 1:23"> なぜなら、神はみこころによって、満ち満ちた神の本質を御子のうちに宿らせ、</span>
<span className="v" id="v20" data-v="20" data-xref="コリント人への手紙第二 5:18–21; エペソ人への手紙 1:10; ヨハネの手紙第一 4:9–10"> その十字架の血によって平和をつくり、御子によって万物を、ご自分と和解させてくださったからです。地にあるものも天にあるものも、ただ御子によって和解させてくださったのです。</span>
<span className="v" id="v21" data-v="21" data-xref="エペソ人への手紙 2:12; テトスへの手紙 3:3–7; エペソ人への手紙 2:1–3"> あなたがたも、かつては神を離れ、心において敵となって、悪い行ないの中にあったのですが、</span>
<span className="v" id="v22" data-v="22" data-xref="エペソ人への手紙 5:27; ユダの手紙 1:24; エペソ人への手紙 1:4"> 今は神は、御子の肉のからだにおいて、しかもその死によって、あなたがたをご自分と和解させてくださいました。それはあなたがたを、きよく、傷なく、非難されるところのない者として御前に立たせてくださるためでした。</span>
<span className="v" id="v23" data-v="23" data-xref="ヘブル人への手紙 3:14; ヘブル人への手紙 3:6; マタイの福音書 24:13–14"> ただし、あなたがたは、しっかりとした土台の上に堅く立って、すでに聞いた福音の望みからはずれることなく、信仰に踏みとどまらなければなりません。この福音は、天の下のすべての造られたものに宣べ伝えられているのであって、このパウロはそれに仕える者となったのです。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="ローマ人への手紙 5:3; テモテへの手紙第二 1:8; コリント人への手紙第二 1:5–8"> ですから、私は、あなたがたのために受ける苦しみを喜びとしています。そして、キリストのからだのために、私の身をもって、キリストの苦しみの欠けたところを満たしているのです。キリストのからだとは、教会のことです。</span>
<span className="v" id="v25" data-v="25" data-xref="エペソ人への手紙 3:2; コロサイ人への手紙 1:23; ガラテヤ人への手紙 2:7–8"> 私は、あなたがたのために神からゆだねられた務めに従って、教会に仕える者となりました。神のことばを余すところなく伝えるためです。</span>
<span className="v" id="v26" data-v="26" data-xref="ルカの福音書 8:10; ローマ人への手紙 16:25–26; エペソ人への手紙 3:3–10"> これは、多くの世代にわたって隠されていて、いま神の聖徒たちに現わされた奥義なのです。</span>
<span className="v" id="v27" data-v="27" data-xref="ヨハネの福音書 14:20; ローマ人への手紙 8:10; エペソ人への手紙 3:16–17"> 神は聖徒たちに、この奥義が異邦人の間にあってどのように栄光に富んだものであるかを、知らせたいと思われたのです。この奥義とは、あなたがたの中におられるキリスト、栄光の望みのことです。</span>
<span className="v" id="v28" data-v="28" data-xref="エペソ人への手紙 5:27; Jeremiah 3:15; エペソ人への手紙 4:11–13"> 私たちは、このキリストを宣べ伝え、知恵を尽くして、あらゆる人を戒め、あらゆる人を教えています。それは、すべての人を、キリストにある成人として立たせるためです。</span>
<span className="v" id="v29" data-v="29" data-xref="コリント人への手紙第一 15:10; エペソ人への手紙 1:19; コリント人への手紙第一 9:25–27"> このために、私もまた、自分のうちに力強く働くキリストの力によって、労苦しながら奮闘しています。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ローマ人への手紙 8:6; マタイの福音書 6:33; コリント人への手紙第二 4:18"> こういうわけで、もしあなたがたが、キリストとともによみがえらされたのなら、上にあるものを求めなさい。そこにはキリストが、神の右に座を占めておられます。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネの手紙第一 2:15–17; 1 Chronicles 22:19; コロサイ人への手紙 3:1"> あなたがたは、地上のものを思わず、天にあるものを思いなさい。</span>
<span className="v" id="v3" data-v="3" data-xref="ガラテヤ人への手紙 2:20; ローマ人への手紙 6:2; コロサイ人への手紙 2:20"> あなたがたはすでに死んでおり、あなたがたのいのちは、キリストとともに、神のうちに隠されてあるからです。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネの福音書 11:25; ヨハネの手紙第一 3:2; ガラテヤ人への手紙 2:20"> 私たちのいのちであるキリストが現われると、そのときあなたがたも、キリストとともに、栄光のうちに現われます。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="ローマ人への手紙 8:13; ガラテヤ人への手紙 5:19–21; ガラテヤ人への手紙 5:24"> ですから、地上のからだの諸部分、すなわち、不品行、汚れ、情欲、悪い欲、そしてむさぼりを殺してしまいなさい。このむさぼりが、そのまま偶像礼拝なのです。</span>
<span className="v" id="v6" data-v="6" data-xref="エペソ人への手紙 5:6; ローマ人への手紙 1:18; ペテロの手紙第一 1:14"> このようなことのために、神の怒りが下るのです。</span>
<span className="v" id="v7" data-v="7" data-xref="エペソ人への手紙 2:2; ペテロの手紙第一 4:3–4; ローマ人への手紙 6:19–20"> あなたがたも、以前、そのようなものの中に生きていたときは、そのような歩み方をしていました。</span>
<span className="v" id="v8" data-v="8" data-xref="エペソ人への手紙 4:29; エペソ人への手紙 4:22; ヤコブの手紙 1:20–21"> しかし今は、あなたがたも、すべてこれらのこと、すなわち、怒り、憤り、悪意、そしり、あなたがたの口から出る恥ずべきことばを、捨ててしまいなさい。</span>
<span className="v" id="v9" data-v="9" data-xref="エペソ人への手紙 4:22; エペソ人への手紙 4:25; Leviticus 19:11"> 互いに偽りを言ってはいけません。あなたがたは、古い人をその行ないといっしょに脱ぎ捨てて、</span>
<span className="v" id="v10" data-v="10" data-xref="エペソ人への手紙 4:23–24; ローマ人への手紙 12:2; エペソ人への手紙 2:10"> 新しい人を着たのです。新しい人は、造り主のかたちに似せられてますます新しくされ、真の知識に至るのです。</span>
<span className="v" id="v11" data-v="11" data-xref="ガラテヤ人への手紙 3:28–29; コリント人への手紙第一 12:13; ローマ人への手紙 10:12"> そこには、ギリシヤ人とユダヤ人、割礼の有無、未開人、スクテヤ人、奴隷と自由人というような区別はありません。キリストがすべてであり、すべてのうちにおられるのです。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="エペソ人への手紙 4:32; エペソ人への手紙 4:2; ヨハネの手紙第一 4:19"> それゆえ、神に選ばれた者、きよい、愛されている者として、あなたがたは深い同情心、慈愛、謙遜、柔和、寛容を身に着けなさい。</span>
<span className="v" id="v13" data-v="13" data-xref="エペソ人への手紙 4:32; マルコの福音書 11:25; ヤコブの手紙 2:13"> 互いに忍び合い、だれかがほかの人に不満を抱くことがあっても、互いに赦し合いなさい。主があなたがたを赦してくださったように、あなたがたもそうしなさい。</span>
<span className="v" id="v14" data-v="14" data-xref="ペテロの手紙第一 4:8; エペソ人への手紙 5:2; コリント人への手紙第一 13:1–13"> そして、これらすべての上に、愛を着けなさい。愛は結びの帯として完全なものです。</span>
<span className="v" id="v15" data-v="15" data-xref="ピリピ人への手紙 4:6–7; ヨハネの福音書 14:27; Isaiah 26:3"> キリストの平和が、あなたがたの心を支配するようにしなさい。そのためにこそあなたがたも召されて一体となったのです。また、感謝の心を持つ人になりなさい。</span>
<span className="v" id="v16" data-v="16" data-xref="Psalms 119:11; エペソ人への手紙 5:19; ヨハネの福音書 15:7"> キリストのことばを、あなたがたのうちに豊かに住まわせ、知恵を尽くして互いに教え、互いに戒め、詩と賛美と霊の歌とにより、感謝にあふれて心から神に向かって歌いなさい。</span>
<span className="v" id="v17" data-v="17" data-xref="コリント人への手紙第一 10:31; コロサイ人への手紙 3:23; Proverbs 3:6"> あなたがたのすることは、ことばによると行ないによるとを問わず、すべて主イエスの名によってなし、主によって父なる神に感謝しなさい。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="エペソ人への手紙 5:22–9; テトスへの手紙 2:4–5; コリント人への手紙第一 11:3"> 妻たちよ。主にある者にふさわしく、夫に従いなさい。</span>
<span className="v" id="v19" data-v="19" data-xref="ペテロの手紙第一 3:7; Genesis 2:23–24; コロサイ人への手紙 3:21"> 夫たちよ。妻を愛しなさい。つらく当たってはいけません。</span>
<span className="v" id="v20" data-v="20" data-xref="Exodus 20:12; エペソ人への手紙 6:1–3; Proverbs 6:20"> 子どもたちよ。すべてのことについて、両親に従いなさい。それは主に喜ばれることだからです。</span>
<span className="v" id="v21" data-v="21" data-xref="Proverbs 4:1–4; エペソ人への手紙 6:4; Psalms 103:13"> 父たちよ。子どもをおこらせてはいけません。彼らを気落ちさせないためです。</span>
<span className="v" id="v22" data-v="22" data-xref="エペソ人への手紙 6:5–7; テモテへの手紙第一 6:1–2; ガラテヤ人への手紙 1:10"> 奴隷たちよ。すべてのことについて、地上の主人に従いなさい。人のごきげんとりのような、うわべだけの仕え方ではなく、主を恐れかしこみつつ、真心から従いなさい。</span>
<span className="v" id="v23" data-v="23" data-xref="コロサイ人への手紙 3:17; エペソ人への手紙 6:6–7; ローマ人への手紙 14:8"> 何をするにも、人に対してではなく、主に対してするように、心からしなさい。</span>
<span className="v" id="v24" data-v="24" data-xref="エペソ人への手紙 6:8; ガラテヤ人への手紙 1:10; 使徒の働き 20:32"> あなたがたは、主から報いとして、御国を相続させていただくことを知っています。あなたがたは主キリストに仕えているのです。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒の働き 10:34; ローマ人への手紙 2:11; コリント人への手紙第二 5:10"> 不正を行なう者は、自分が行なった不正の報いを受けます。それには不公平な扱いはありません。</span>
</div>

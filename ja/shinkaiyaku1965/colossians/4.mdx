<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="エペソ人への手紙 6:8–20; ヤコブの手紙 2:13; Deuteronomy 24:14–15"> 主人たちよ。あなたがたは、自分たちの主も天におられることを知っているのですから、奴隷に対して正義と公平を示しなさい。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="テサロニケ人への手紙第一 5:17–18; ピリピ人への手紙 4:6; エペソ人への手紙 6:18"> 目をさまして、感謝をもって、たゆみなく祈りなさい。</span>
<span className="v" id="v3" data-v="3" data-xref="エペソ人への手紙 6:19–20; 使徒の働き 14:27; テサロニケ人への手紙第二 3:1–2"> 同時に、私たちのためにも、神がみことばのために門を開いてくださって、私たちがキリストの奥義を語れるように、祈ってください。この奥義のために、私は牢に入れられています。</span>
<span className="v" id="v4" data-v="4" data-xref="コリント人への手紙第二 4:1–4; エペソ人への手紙 6:20; コロサイ人への手紙 4:6"> また、私がこの奥義を、当然語るべき語り方で、はっきり語れるように、祈ってください。</span>
<span className="v" id="v5" data-v="5" data-xref="エペソ人への手紙 5:15–17; テサロニケ人への手紙第一 4:12; ヤコブの手紙 3:13"> 外部の人に対して賢明にふるまい、機会を十分に生かして用いなさい。</span>
<span className="v" id="v6" data-v="6" data-xref="エペソ人への手紙 4:29; ペテロの手紙第一 3:15; Ecclesiastes 10:12"> あなたがたのことばが、いつも親切で、塩味のきいたものであるようにしなさい。そうすれば、ひとりひとりに対する答え方がわかります。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="エペソ人への手紙 6:21–23; 使徒の働き 20:4; テモテへの手紙第二 4:12"> 私の様子については、主にあって愛する兄弟、忠実な奉仕者、同労のしもべであるテキコが、あなたがたに一部始終を知らせるでしょう。</span>
<span className="v" id="v8" data-v="8" data-xref="エペソ人への手紙 6:22; コロサイ人への手紙 2:2; ピリピ人への手紙 2:28"> 私がテキコをあなたがたのもとに送るのは、あなたがたが私たちの様子を知り、彼によって心に励ましを受けるためにほかなりません。</span>
<span className="v" id="v9" data-v="9" data-xref="ピレモンへの手紙 1:10–19; コロサイ人への手紙 4:7"> また彼は、あなたがたの仲間のひとりで、忠実な愛する兄弟オネシモといっしょに行きます。このふたりが、こちらの様子をみな知らせてくれるでしょう。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="ピレモンへの手紙 1:24; テモテへの手紙第二 4:11; 使徒の働き 19:29"> 私といっしょに囚人となっているアリスタルコが、あなたがたによろしくと言っています。バルナバのいとこであるマルコも同じです。――この人については、もし彼があなたがたのところに行ったなら、歓迎するようにという指示をあなたがたは受けています。――</span>
<span className="v" id="v11" data-v="11" data-xref="使徒の働き 11:2; コリント人への手紙第二 6:1; 使徒の働き 10:45"> ユストと呼ばれるイエスもよろしくと言っています。割礼を受けた人では、この人たちだけが、神の国のために働く私の同労者です。また、彼らは私を激励する者となってくれました。</span>
<span className="v" id="v12" data-v="12" data-xref="ローマ人への手紙 15:30; コロサイ人への手紙 1:9; コロサイ人への手紙 1:7"> あなたがたの仲間のひとり、キリスト・イエスのしもべエパフラスが、あなたがたによろしくと言っています。彼はいつも、あなたがたが完全な人となり、また神のすべてのみこころを十分に確信して立つことができるよう、あなたがたのために祈りに励んでいます。</span>
<span className="v" id="v13" data-v="13" data-xref="コロサイ人への手紙 2:1; ローマ人への手紙 10:2; ヨハネの黙示録 1:11"> 私はあかしします。彼はあなたがたのために、またラオデキヤとヒエラポリスにいる人々のために、非常に苦労しています。</span>
<span className="v" id="v14" data-v="14" data-xref="ピレモンへの手紙 1:24; テモテへの手紙第二 4:10–11"> 愛する医者ルカ、それにデマスが、あなたがたによろしくと言っています。</span>
<span className="v" id="v15" data-v="15" data-xref="ローマ人への手紙 16:5; ピレモンへの手紙 1:2; コリント人への手紙第一 16:9"> どうか、ラオデキヤの兄弟たちに、またヌンパとその家にある教会に、よろしく言ってください。</span>
<span className="v" id="v16" data-v="16" data-xref="テサロニケ人への手紙第一 5:27; テサロニケ人への手紙第二 3:14"> この手紙があなたがたのところで読まれたなら、ラオデキヤ人の教会でも読まれるようにしてください。あなたがたのほうも、ラオデキヤから回って来る手紙を読んでください。</span>
<span className="v" id="v17" data-v="17" data-xref="ピレモンへの手紙 1:2; 使徒の働き 1:17; Ezekiel 44:23–24"> アルキポに、「主にあって受けた務めを、注意してよく果たすように。」と言ってください。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="ヘブル人への手紙 13:3; テモテへの手紙第二 4:22; テモテへの手紙第一 6:21"> パウロが自筆であいさつを送ります。私が牢につながれていることを覚えていてください。どうか、恵みがあなたがたとともにありますように。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="コロサイ人への手紙 1:1; エペソ人への手紙 3:1; ピレモンへの手紙 1:9"> キリスト・イエスの囚人であるパウロ、および兄弟テモテから、私たちの愛する同労者ピレモンへ。また、</span>
<span className="v" id="v2" data-v="2" data-xref="ピリピ人への手紙 2:25; コロサイ人への手紙 4:17; ローマ人への手紙 16:5"> 姉妹アピヤ、私たちの戦友アルキポ、ならびにあなたの家にある教会へ。</span>
<span className="v" id="v3" data-v="3" data-xref="ローマ人への手紙 1:7; エペソ人への手紙 1:2; コリント人への手紙第二 13:14"> 私たちの父なる神と主イエス・キリストから、恵みと平安があなたがたの上にありますように。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="ローマ人への手紙 1:8; エペソ人への手紙 1:16; テサロニケ人への手紙第二 1:3"> 私は、祈りのうちにあなたのことを覚え、いつも私の神に感謝しています。</span>
<span className="v" id="v5" data-v="5" data-xref="コロサイ人への手紙 1:4; エペソ人への手紙 1:15; コリント人への手紙第一 16:1"> それは、主イエスに対してあなたが抱いている信仰と、すべての聖徒に対するあなたの愛とについて聞いているからです。</span>
<span className="v" id="v6" data-v="6" data-xref="ピリピ人への手紙 1:9–11; ペテロの手紙第二 1:8; コロサイ人への手紙 1:9"> 私たちの間でキリストのためになされているすべての良い行ないをよく知ることによって、あなたの信仰の交わりが生きて働くものとなりますように。</span>
<span className="v" id="v7" data-v="7" data-xref="コリント人への手紙第二 7:13; テサロニケ人への手紙第一 3:9; コリント人への手紙第二 7:4"> 私はあなたの愛から多くの喜びと慰めとを受けました。それは、聖徒たちの心が、兄弟よ、あなたによって力づけられたからです。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="テサロニケ人への手紙第一 2:6; コリント人への手紙第二 10:8; コリント人への手紙第二 3:12"> 私は、あなたのなすべきことを、キリストにあって少しもはばからず命じることができるのですが、こういうわけですから、</span>
<span className="v" id="v9" data-v="9" data-xref="コリント人への手紙第二 5:20; エペソ人への手紙 4:1; ローマ人への手紙 12:1"> むしろ愛によって、あなたにお願いしたいと思います。年老いて、今はまたキリスト・イエスの囚人となっている私パウロが、</span>
<span className="v" id="v10" data-v="10" data-xref="コロサイ人への手紙 4:9; コリント人への手紙第一 4:15; テモテへの手紙第一 1:2"> 獄中で生んだわが子オネシモのことを、あなたにお願いしたいのです。</span>
<span className="v" id="v11" data-v="11" data-xref="テモテへの手紙第二 4:11; Job 30:1–2; ペテロの手紙第一 2:10"> 彼は、前にはあなたにとって役に立たない者でしたが、今は、あなたにとっても私にとっても、役に立つ者となっています。</span>
<span className="v" id="v12" data-v="12" data-xref="マタイの福音書 6:14–15; Jeremiah 31:20; マルコの福音書 11:25"> そのオネシモを、あなたのもとに送り返します。彼は私の心そのものです。</span>
<span className="v" id="v13" data-v="13" data-xref="ピリピ人への手紙 1:7; エペソ人への手紙 3:1; コリント人への手紙第一 16:17"> 私は、彼を私のところにとどめておき、福音のために獄中にいる間、あなたに代わって私のために仕えてもらいたいとも考えましたが、</span>
<span className="v" id="v14" data-v="14" data-xref="コリント人への手紙第二 9:7; 1 Chronicles 29:17; ペテロの手紙第一 5:2–3"> あなたの同意なしには何一つすまいと思いました。それは、あなたがしてくれる親切は強制されてではなく、自発的でなければいけないからです。</span>
<span className="v" id="v15" data-v="15" data-xref="Genesis 50:20; Genesis 45:5–8; Isaiah 20:6"> 彼がしばらくの間あなたから離されたのは、たぶん、あなたが彼を永久に取り戻すためであったのでしょう。</span>
<span className="v" id="v16" data-v="16" data-xref="コロサイ人への手紙 3:22; マタイの福音書 23:8; コリント人への手紙第一 7:22"> もはや奴隷としてではなく、奴隷以上の者、すなわち、愛する兄弟としてです。特に私にとってそうですが、あなたにとってはなおさらのこと、肉においても主にあっても、そうではありませんか。</span>
<span className="v" id="v17" data-v="17" data-xref="コリント人への手紙第二 8:23; マタイの福音書 10:40; ピレモンへの手紙 1:12"> ですから、もしあなたが私を親しい友と思うなら、私を迎えるように彼を迎えてやってください。</span>
<span className="v" id="v18" data-v="18" data-xref="Isaiah 53:4–7"> もし彼があなたに対して損害をかけたか、負債を負っているのでしたら、その請求は私にしてください。</span>
<span className="v" id="v19" data-v="19" data-xref="ガラテヤ人への手紙 6:11; ガラテヤ人への手紙 5:2; コリント人への手紙第一 4:15"> この手紙は私の自筆です。私がそれを支払います。――あなたが今のようになれたのもまた、私によるのですが、そのことについては何も言いません。――</span>
<span className="v" id="v20" data-v="20" data-xref="ヨハネの手紙第三 1:4; ピレモンへの手紙 1:7; ピレモンへの手紙 1:12"> そうです。兄弟よ。私は、主にあって、あなたから益を受けたいのです。私の心をキリストにあって、元気づけてください。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="テサロニケ人への手紙第二 3:4; コリント人への手紙第二 2:3; コリント人への手紙第二 7:16"> 私はあなたの従順を確信して、あなたにこの手紙を書きました。私の言う以上のことをしてくださるあなたであると、知っているからです。</span>
<span className="v" id="v22" data-v="22" data-xref="コリント人への手紙第二 1:11; ピリピ人への手紙 2:24; ヨハネの手紙第二 1:12"> それにまた、私の宿の用意もしておいてください。あなたがたの祈りによって、私もあなたがたのところに行けることと思っています。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="コロサイ人への手紙 1:7; ローマ人への手紙 16:7; コロサイ人への手紙 4:12"> キリスト・イエスにあって私とともに囚人となっているエパフラスが、あなたによろしくと言っています。</span>
<span className="v" id="v24" data-v="24" data-xref="テモテへの手紙第二 4:10–11; コロサイ人への手紙 4:14; コロサイ人への手紙 4:10"> 私の同労者たちであるマルコ、アリスタルコ、デマス、ルカからもよろしくと言っています。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="テモテへの手紙第二 4:22; ローマ人への手紙 16:23; ローマ人への手紙 16:20"> 主イエス・キリストの恵みが、あなたがたの霊とともにありますように。</span>
</div>

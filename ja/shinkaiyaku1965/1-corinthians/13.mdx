<span className="v" id="v1" data-v="1" data-xref="テモテへの手紙第一 1:5; ペテロの手紙第一 4:8; ガラテヤ人への手紙 5:22"> たとい、私が人の異言や、御使いの異言で話しても、愛がないなら、やかましいどらや、うるさいシンバルと同じです。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネの手紙第一 4:8; コリント人への手紙第一 13:3; ヨハネの手紙第一 4:20–21"> また、たとい私が預言の賜物を持っており、またあらゆる奥義とあらゆる知識とに通じ、また、山を動かすほどの完全な信仰を持っていても、愛がないなら、何の値うちもありません。</span>
<span className="v" id="v3" data-v="3" data-xref="ヤコブの手紙 2:14–17; ヨハネの福音書 15:13; マタイの福音書 23:5"> また、たとい私が持っている物の全部を貧しい人たちに分け与え、また私のからだを焼かれるために渡しても、愛がなければ、何の役にも立ちません。</span>
<span className="v" id="v4" data-v="4" data-xref="ペテロの手紙第一 4:8; エペソ人への手紙 4:32; ガラテヤ人への手紙 5:21–22"> 愛は寛容であり、愛は親切です。また人をねたみません。愛は自慢せず、高慢になりません。</span>
<span className="v" id="v5" data-v="5" data-xref="コリント人への手紙第一 10:24; ピリピ人への手紙 2:3–5; ヨハネの手紙第一 3:16–17"> 礼儀に反することをせず、自分の利益を求めず、怒らず、人のした悪を思わず、</span>
<span className="v" id="v6" data-v="6" data-xref="ローマ人への手紙 12:9; ヨハネの手紙第三 1:3–4; ヨハネの手紙第二 1:4"> 不正を喜ばずに真理を喜びます。</span>
<span className="v" id="v7" data-v="7" data-xref="ペテロの手紙第一 4:8; コリント人への手紙第一 13:4; テモテへの手紙第二 2:24"> すべてをがまんし、すべてを信じ、すべてを期待し、すべてを耐え忍びます。</span>
<span className="v" id="v8" data-v="8" data-xref="コリント人への手紙第一 13:13; コリント人への手紙第一 13:1–2; ガラテヤ人への手紙 5:6"> 愛は決して絶えることがありません。預言の賜物ならばすたれます。異言ならばやみます。知識ならばすたれます。</span>
<span className="v" id="v9" data-v="9" data-xref="コロサイ人への手紙 2:2–3; エペソ人への手紙 3:18–19; コリント人への手紙第一 2:9"> というのは、私たちの知っているところは一部分であり、預言することも一部分だからです。</span>
<span className="v" id="v10" data-v="10" data-xref="コリント人への手紙第一 13:12; Isaiah 60:19–20; コリント人への手紙第二 5:7–8"> 完全なものが現われたら、不完全なものはすたれます。</span>
<span className="v" id="v11" data-v="11" data-xref="コリント人への手紙第一 14:20; コリント人への手紙第一 3:1–2; ガラテヤ人への手紙 4:1"> 私が子どもであったときには、子どもとして話し、子どもとして考え、子どもとして論じましたが、おとなになったときには、子どものことをやめました。</span>
<span className="v" id="v12" data-v="12" data-xref="ヨハネの手紙第一 3:2; コリント人への手紙第二 3:18; コリント人への手紙第一 13:9–10"> 今、私たちは鏡にぼんやり映るものを見ていますが、その時には顔と顔とを合わせて見ることになります。今、私は一部分しか知りませんが、その時には、私が完全に知られているのと同じように、私も完全に知ることになります。</span>
<span className="v" id="v13" data-v="13" data-xref="コリント人への手紙第一 16:14; コロサイ人への手紙 3:14; ヨハネの手紙第一 4:7–18"> こういうわけで、いつまでも残るものは信仰と希望と愛です。その中で一番すぐれているのは愛です。</span>

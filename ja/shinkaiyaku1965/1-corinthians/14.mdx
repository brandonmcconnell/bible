<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="コリント人への手紙第一 14:39; テモテへの手紙第一 4:14; コリント人への手紙第一 12:1"> 愛を追い求めなさい。また、御霊の賜物、特に預言することを熱心に求めなさい。</span>
<span className="v" id="v2" data-v="2" data-xref="マルコの福音書 16:17; 使徒の働き 19:6; 使徒の働き 10:46"> 異言を話す者は、人に話すのではなく、神に話すのです。というのは、だれも聞いていないのに、自分の霊で奥義を話すからです。</span>
<span className="v" id="v3" data-v="3" data-xref="コリント人への手紙第一 14:12; テモテへの手紙第一 4:13; ユダの手紙 1:20"> ところが預言する者は、徳を高め、勧めをなし、慰めを与えるために、人に向かって話します。</span>
<span className="v" id="v4" data-v="4" data-xref="コリント人への手紙第一 14:22; コリント人への手紙第一 14:26; マルコの福音書 16:17"> 異言を話す者は自分の徳を高めますが、預言する者は教会の徳を高めます。</span>
<span className="v" id="v5" data-v="5" data-xref="コリント人への手紙第一 12:28–30; コリント人への手紙第一 12:10; マルコの福音書 16:17"> 私はあなたがたがみな異言を話すことを望んでいますが、それよりも、あなたがたが預言することを望みます。もし異言を話す者がその解き明かしをして教会の徳を高めるのでないなら、異言を語る者よりも、預言する者のほうがまさっています。</span>
<span className="v" id="v6" data-v="6" data-xref="エペソ人への手紙 1:17; ローマ人への手紙 6:17; テモテへの手紙第二 3:16"> ですから、兄弟たち。私があなたがたのところへ行って異言を話すとしても、黙示や知識や預言や教えなどによって話さないなら、あなたがたに何の益となるでしょう。</span>
<span className="v" id="v7" data-v="7" data-xref="コリント人への手紙第一 14:8; ルカの福音書 7:32; コリント人への手紙第一 13:1"> 笛や琴などいのちのない楽器でも、はっきりした音を出さなければ、何を吹いているのか、何をひいているのか、どうしてわかりましょう。</span>
<span className="v" id="v8" data-v="8" data-xref="Numbers 10:9; Ezekiel 33:3–6; Jeremiah 4:19"> また、ラッパがもし、はっきりしない音を出したら、だれが戦闘の準備をするでしょう。</span>
<span className="v" id="v9" data-v="9" data-xref="コリント人への手紙第一 9:26"> それと同じように、あなたがたも、舌で明瞭なことばを語るのでなければ、言っている事をどうして知ってもらえるでしょう。それは空気に向かって話しているのです。</span>
<span className="v" id="v10" data-v="10"> 世界にはおそらく非常に多くの種類のことばがあるでしょうが、意味のないことばなど一つもありません。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒の働き 28:2; ローマ人への手紙 1:14; コロサイ人への手紙 3:11"> それで、もし私がそのことばの意味を知らないなら、私はそれを話す人にとって異国人であり、それを話す人も私にとって異国人です。</span>
<span className="v" id="v12" data-v="12" data-xref="コリント人への手紙第一 14:26; コリント人への手紙第一 14:3–4; コリント人への手紙第一 14:1"> あなたがたのばあいも同様です。あなたがたは御霊の賜物を熱心に求めているのですから、教会の徳を高めるために、それが豊かに与えられるよう、熱心に求めなさい。</span>
<span className="v" id="v13" data-v="13" data-xref="マルコの福音書 11:24; コリント人への手紙第一 12:30; ヨハネの福音書 14:13–14"> こういうわけですから、異言を語る者は、それを解き明かすことができるように祈りなさい。</span>
<span className="v" id="v14" data-v="14" data-xref="コリント人への手紙第一 14:2; コリント人への手紙第一 14:15–16; コリント人への手紙第一 14:19"> もし私が異言で祈るなら、私の霊は祈るが、私の知性は実を結ばないのです。</span>
<span className="v" id="v15" data-v="15" data-xref="コロサイ人への手紙 3:16; ヨハネの福音書 4:23–24; エペソ人への手紙 6:18"> ではどうすればよいのでしょう。私は霊において祈り、また知性においても祈りましょう。霊において賛美し、また知性においても賛美しましょう。</span>
<span className="v" id="v16" data-v="16" data-xref="1 Chronicles 16:36; Psalms 106:48; ヨハネの黙示録 5:14"> そうでないと、あなたが霊において祝福しても、異言を知らない人々の座席に着いている人は、あなたの言っていることがわからないのですから、あなたの感謝について、どうしてアーメンと言えるでしょう。</span>
<span className="v" id="v17" data-v="17" data-xref="コリント人への手紙第一 14:4; コリント人への手紙第一 14:6"> あなたの感謝は結構ですが、他の人の徳を高めることはできません。</span>
<span className="v" id="v18" data-v="18" data-xref="コリント人への手紙第一 1:4–6; コリント人への手紙第一 4:7"> 私は、あなたがたのだれよりも多くの異言を話すことを神に感謝していますが、</span>
<span className="v" id="v19" data-v="19" data-xref="コリント人への手紙第一 14:21–22; コリント人への手紙第一 14:4"> 教会では、異言で一万語話すよりは、ほかの人を教えるために、私の知性を用いて五つのことばを話したいのです。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="ペテロの手紙第一 2:2; コリント人への手紙第一 13:11; ローマ人への手紙 16:19"> 兄弟たち。物の考え方において子どもであってはなりません。悪事においては幼子でありなさい。しかし考え方においてはおとなになりなさい。</span>
<span className="v" id="v21" data-v="21" data-xref="Isaiah 28:11–12; Jeremiah 5:15; Deuteronomy 28:49"> 律法にこう書いてあります。「『わたしは、異なった舌により、異国の人のくちびるによってこの民に語るが、彼らはなおわたしの言うことを聞き入れない。』と主は言われる。」</span>
<span className="v" id="v22" data-v="22" data-xref="使徒の働き 2:6–12; マルコの福音書 16:17; コリント人への手紙第一 14:1"> それで、異言は信者のためのしるしではなく、不信者のためのしるしです。けれども、預言は不信者でなく、信者のためのしるしです。</span>
<span className="v" id="v23" data-v="23" data-xref="使徒の働き 2:13; 使徒の働き 26:24; コリント人への手紙第一 11:18"> ですから、もし教会全体が一か所に集まって、みなが異言を話すとしたら、初心の者とか信者でない者とかがはいって来たとき、彼らは、あなたがたを気違いだと言わないでしょうか。</span>
<span className="v" id="v24" data-v="24" data-xref="使徒の働き 2:37; コリント人への手紙第一 2:15; ヘブル人への手紙 4:12–13"> しかし、もしみなが預言をするなら、信者でない者や初心の者がはいって来たとき、その人はみなの者によって罪を示されます。みなにさばかれ、</span>
<span className="v" id="v25" data-v="25" data-xref="Isaiah 45:14; Zechariah 8:23; Psalms 72:11"> 心の秘密があらわにされます。そうして、神が確かにあなたがたの中におられると言って、ひれ伏して神を拝むでしょう。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="エペソ人への手紙 5:19; ローマ人への手紙 14:19; コリント人への手紙第一 12:7–10"> 兄弟たち。では、どうすればよいのでしょう。あなたがたが集まるときには、それぞれの人が賛美したり、教えたり、黙示を話したり、異言を話したり、解き明かしたりします。そのすべてのことを、徳を高めるためにしなさい。</span>
<span className="v" id="v27" data-v="27" data-xref="コリント人への手紙第一 14:26"> もし異言を話すのならば、ふたりか、多くても三人で順番に話すべきで、ひとりは解き明かしをしなさい。</span>
<span className="v" id="v28" data-v="28"> もし解き明かす者がだれもいなければ、教会では黙っていなさい。自分だけで、神に向かって話しなさい。</span>
<span className="v" id="v29" data-v="29" data-xref="コリント人への手紙第一 12:10; テサロニケ人への手紙第一 5:19–21; ヨハネの手紙第一 4:1–3"> 預言する者も、ふたりか三人が話し、ほかの者はそれを吟味しなさい。</span>
<span className="v" id="v30" data-v="30" data-xref="テサロニケ人への手紙第一 5:19–20; Job 33:31–33; Job 32:11"> もしも座席に着いている別の人に黙示が与えられたら、先の人は黙りなさい。</span>
<span className="v" id="v31" data-v="31" data-xref="テサロニケ人への手紙第一 5:14; コリント人への手紙第一 14:3; テサロニケ人への手紙第一 5:11"> あなたがたは、みながかわるがわる預言できるのであって、すべての人が学ぶことができ、すべての人が勧めを受けることができるのです。</span>
<span className="v" id="v32" data-v="32" data-xref="使徒の働き 4:19–20; ヨハネの手紙第一 4:1; 1 Samuel 10:10–13"> 預言者たちの霊は預言者たちに服従するものなのです。</span>
<span className="v" id="v33" data-v="33" data-xref="ヤコブの手紙 3:17–18; コリント人への手紙第一 14:40; テサロニケ人への手紙第二 3:16"> それは、神が混乱の神ではなく、平和の神だからです。聖徒たちのすべての教会で行なわれているように、</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="テモテへの手紙第一 2:11–12; Genesis 3:16; Numbers 30:3–13"> 教会では、妻たちは黙っていなさい。彼らは語ることを許されていません。律法も言うように、服従しなさい。</span>
<span className="v" id="v35" data-v="35" data-xref="エペソ人への手紙 5:12; ペテロの手紙第一 3:7; エペソ人への手紙 5:25–27"> もし何かを学びたければ、家で自分の夫に尋ねなさい。教会で語ることは、妻にとってはふさわしくないことです。</span>
<span className="v" id="v36" data-v="36" data-xref="使徒の働き 18:1–17; Zechariah 14:8; 使徒の働き 17:15"> 神のことばは、あなたがたのところから出たのでしょうか。あるいはまた、あなたがたにだけ伝わったのでしょうか。</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="ヨハネの手紙第一 4:6; コリント人への手紙第二 10:7; ペテロの手紙第二 3:2"> 自分を預言者、あるいは、御霊の人と思う者は、私があなたがたに書くことが主の命令であることを認めなさい。</span>
<span className="v" id="v38" data-v="38" data-xref="テモテへの手紙第二 4:3–4; Hosea 4:17; ヨハネの黙示録 22:11–12"> もしそれを認めないなら、その人は認められません。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="コリント人への手紙第一 12:31; コリント人への手紙第一 14:1; テサロニケ人への手紙第一 5:20"> それゆえ、私の兄弟たち。預言することを熱心に求めなさい。異言を話すことも禁じてはいけません。</span>
<span className="v" id="v40" data-v="40" data-xref="コロサイ人への手紙 2:5; テトスへの手紙 1:5; コリント人への手紙第一 14:26–33"> ただ、すべてのことを適切に、秩序をもって行ないなさい。</span>
</div>

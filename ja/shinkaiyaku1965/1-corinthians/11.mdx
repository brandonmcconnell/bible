<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ピリピ人への手紙 3:17; テサロニケ人への手紙第一 1:6; コリント人への手紙第一 4:16"> 私がキリストを見ならっているように、あなたがたも私を見ならってください。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="テサロニケ人への手紙第二 2:15; コリント人への手紙第一 4:17; Proverbs 31:28–31"> さて、あなたがたは、何かにつけて私を覚え、また、私があなたがたに伝えたものを、伝えられたとおりに堅く守っているので、私はあなたがたをほめたいと思います。</span>
<span className="v" id="v3" data-v="3" data-xref="Genesis 3:16; コロサイ人への手紙 1:18; コロサイ人への手紙 3:18"> しかし、あなたがたに次のことを知っていただきたいのです。すべての男のかしらはキリストであり、女のかしらは男であり、キリストのかしらは神です。</span>
<span className="v" id="v4" data-v="4" data-xref="2 Samuel 15:30; コリント人への手紙第一 12:28; コリント人への手紙第一 12:10"> 男が、祈りや預言をするとき、頭にかぶり物を着けていたら、自分の頭をはずかしめることになります。</span>
<span className="v" id="v5" data-v="5" data-xref="Deuteronomy 21:12; ルカの福音書 2:36; 使徒の働き 2:17"> しかし、女が、祈りや預言をするとき、頭にかぶり物を着けていなかったら、自分の頭をはずかしめることになります。それは髪をそっているのと全く同じことだからです。</span>
<span className="v" id="v6" data-v="6" data-xref="Deuteronomy 22:5; Numbers 5:18"> 女がかぶり物を着けないのなら、髪も切ってしまいなさい。髪を切り、頭をそることが女として恥ずかしいことなら、かぶり物を着けなさい。</span>
<span className="v" id="v7" data-v="7" data-xref="コリント人への手紙第一 11:3; Genesis 5:1; Psalms 8:6"> 男はかぶり物を着けるべきではありません。男は神の似姿であり、神の栄光の現われだからです。女は男の栄光の現われです。</span>
<span className="v" id="v8" data-v="8" data-xref="テモテへの手紙第一 2:13; Genesis 2:21–23"> なぜなら、男は女をもとにして造られたのではなくて、女が男をもとにして造られたのであり、</span>
<span className="v" id="v9" data-v="9" data-xref="Genesis 2:18; Genesis 2:23–24; Genesis 2:20"> また、男は女のために造られたのではなく、女が男のために造られたのだからです。</span>
<span className="v" id="v10" data-v="10" data-xref="Genesis 24:64–65; ヘブル人への手紙 1:14; マタイの福音書 18:10"> ですから、女は頭に権威のしるしをかぶるべきです。それも御使いたちのためにです。</span>
<span className="v" id="v11" data-v="11" data-xref="ガラテヤ人への手紙 3:28; コリント人への手紙第一 7:10–14; コリント人への手紙第一 12:12–22"> とはいえ、主にあっては、女は男を離れてあるものではなく、男も女を離れてあるものではありません。</span>
<span className="v" id="v12" data-v="12" data-xref="ローマ人への手紙 11:36; コリント人への手紙第一 8:6; ヘブル人への手紙 1:2–3"> 女が男をもとにして造られたように、同様に、男も女によって生まれるのだからです。しかし、すべては神から発しています。</span>
<span className="v" id="v13" data-v="13" data-xref="ルカの福音書 12:57; ヨハネの福音書 7:24; コリント人への手紙第一 10:15"> あなたがたは自分自身で判断しなさい。女が頭に何もかぶらないで神に祈るのは、ふさわしいことでしょうか。</span>
<span className="v" id="v14" data-v="14" data-xref="2 Samuel 14:26; コリント人への手紙第一 14:35"> 自然自体が、あなたがたにこう教えていないでしょうか。男が長い髪をしていたら、それは男として恥ずかしいことであり、</span>
<span className="v" id="v15" data-v="15"> 女が長い髪をしていたら、それは女の光栄であるということです。なぜなら、髪はかぶり物として女に与えられているからです。</span>
<span className="v" id="v16" data-v="16" data-xref="コリント人への手紙第一 7:17; テモテへの手紙第一 6:3–4; テサロニケ人への手紙第一 2:14"> たとい、このことに異議を唱えたがる人がいても、私たちにはそのような習慣はないし、神の諸教会にもありません。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="ヘブル人への手紙 10:25; コリント人への手紙第一 14:23; コリント人への手紙第一 11:22"> ところで、聞いていただくことがあります。私はあなたがたをほめません。あなたがたの集まりが益にならないで、かえって害になっているからです。</span>
<span className="v" id="v18" data-v="18" data-xref="コリント人への手紙第一 3:3; コリント人への手紙第一 1:10–12; コリント人への手紙第一 5:1"> まず第一に、あなたがたが教会の集まりをするとき、あなたがたの間には分裂があると聞いています。ある程度は、それを信じます。</span>
<span className="v" id="v19" data-v="19" data-xref="ヨハネの手紙第一 2:19; テトスへの手紙 3:10; 使徒の働き 20:30"> というのは、あなたがたの中でほんとうの信者が明らかにされるためには、分派が起こるのもやむをえないからです。</span>
<span className="v" id="v20" data-v="20"> しかし、そういうわけで、あなたがたはいっしょに集まっても、それは主の晩餐を食べるためではありません。</span>
<span className="v" id="v21" data-v="21" data-xref="ペテロの手紙第二 2:13; ユダの手紙 1:12; コリント人への手紙第一 11:23–25"> 食事のとき、めいめい我先にと自分の食事を済ませるので、空腹な者もおれば、酔っている者もいるというしまつです。</span>
<span className="v" id="v22" data-v="22" data-xref="使徒の働き 20:28; Proverbs 17:5; ヤコブの手紙 2:5–6"> 飲食のためなら、自分の家があるでしょう。それとも、あなたがたは、神の教会を軽んじ、貧しい人たちをはずかしめたいのですか。私はあなたがたに何と言ったらよいでしょう。ほめるべきでしょうか。このことに関しては、ほめるわけにはいきません。</span>
<span className="v" id="v23" data-v="23" data-xref="ルカの福音書 22:19–20; マタイの福音書 26:26–28; コリント人への手紙第一 11:23–25"> 私は主から受けたことを、あなたがたに伝えたのです。すなわち、主イエスは、渡される夜、パンを取り、</span>
<span className="v" id="v24" data-v="24" data-xref="ヨハネの福音書 6:53–58; コリント人への手紙第一 11:27–28; コリント人への手紙第一 10:3–4"> 感謝をささげて後、それを裂き、こう言われました。「これはあなたがたのための、わたしのからだです。わたしを覚えるために、このようにしなさい。」</span>
<span className="v" id="v25" data-v="25" data-xref="ルカの福音書 22:20; ヘブル人への手紙 9:15–20; ヘブル人への手紙 13:20"> 夕食の後、杯をも同じようにして言われました。「この杯は、わたしの血による新しい契約です。これを飲むたびに、わたしを覚えるために、このようにしなさい。」</span>
<span className="v" id="v26" data-v="26" data-xref="ヘブル人への手紙 9:28; ヨハネの黙示録 1:7; ヨハネの福音書 14:3"> ですから、あなたがたは、このパンを食べ、この杯を飲むたびに、主が来られるまで、主の死を告げ知らせるのです。</span>
<span className="v" id="v27" data-v="27" data-xref="ヨハネの福音書 6:51; コリント人への手紙第一 10:21; ヘブル人への手紙 10:29"> したがって、もし、ふさわしくないままでパンを食べ、主の杯を飲む者があれば、主のからだと血に対して罪を犯すことになります。</span>
<span className="v" id="v28" data-v="28" data-xref="ガラテヤ人への手紙 6:4; コリント人への手紙第二 13:5; Lamentations 3:40"> ですから、ひとりひとりが自分を吟味して、そのうえでパンを食べ、杯を飲みなさい。</span>
<span className="v" id="v29" data-v="29" data-xref="コリント人への手紙第一 11:27; コリント人への手紙第一 11:30; コリント人への手紙第一 11:32–34"> みからだをわきまえないで、飲み食いするならば、その飲み食いが自分をさばくことになります。</span>
<span className="v" id="v30" data-v="30" data-xref="ヨハネの黙示録 3:19; Numbers 20:12; Amos 3:2"> そのために、あなたがたの中に、弱い者や病人が多くなり、死んだ者が大ぜいいます。</span>
<span className="v" id="v31" data-v="31" data-xref="ヨハネの手紙第一 1:9; Psalms 32:3–5; ヨハネの黙示録 2:5"> しかし、もし私たちが自分をさばくなら、さばかれることはありません。</span>
<span className="v" id="v32" data-v="32" data-xref="ヘブル人への手紙 12:5–11; Psalms 118:18; Proverbs 3:11–12"> しかし、私たちがさばかれるのは、主によって懲らしめられるのであって、それは、私たちが、この世とともに罪に定められることのないためです。</span>
<span className="v" id="v33" data-v="33"> ですから、兄弟たち。食事に集まるときは、互いに待ち合わせなさい。</span>
<span className="v" id="v34" data-v="34" data-xref="コリント人への手紙第一 11:21–22; コリント人への手紙第一 7:17; コリント人への手紙第一 4:19"> 空腹な人は家で食べなさい。それは、あなたがたが集まることによって、さばきを受けることにならないためです。その他のことについては、私が行ったときに決めましょう。</span>
</div>

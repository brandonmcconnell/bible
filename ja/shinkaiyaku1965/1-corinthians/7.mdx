<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="コリント人への手紙第一 7:8; コリント人への手紙第一 7:26–27; コリント人への手紙第一 7:37–38"> さて、あなたがたの手紙に書いてあったことについてですが、男が女に触れないのは良いことです。</span>
<span className="v" id="v2" data-v="2" data-xref="エペソ人への手紙 5:28; エペソ人への手紙 5:33; コリント人への手紙第一 7:9"> しかし、不品行を避けるため、男はそれぞれ自分の妻を持ち、女もそれぞれ自分の夫を持ちなさい。</span>
<span className="v" id="v3" data-v="3" data-xref="ペテロの手紙第一 3:7; Exodus 21:10"> 夫は自分の妻に対して義務を果たし、同様に妻も自分の夫に対して義務を果たしなさい。</span>
<span className="v" id="v4" data-v="4" data-xref="Hosea 3:3; マタイの福音書 19:9; マルコの福音書 10:11–12"> 妻は自分のからだに関する権利を持ってはおらず、それは夫のものです。同様に夫も自分のからだについての権利を持ってはおらず、それは妻のものです。</span>
<span className="v" id="v5" data-v="5" data-xref="Exodus 19:15; Joel 2:16; Zechariah 12:12–14"> 互いの権利を奪い取ってはいけません。ただし、祈りに専心するために、合意の上でしばらく離れていて、また再びいっしょになるというのならかまいません。あなたがたが自制力を欠くとき、サタンの誘惑にかからないためです。</span>
<span className="v" id="v6" data-v="6" data-xref="コリント人への手紙第二 8:8; コリント人への手紙第一 7:25; コリント人への手紙第一 7:12"> 以上、私の言うところは、容認であって、命令ではありません。</span>
<span className="v" id="v7" data-v="7" data-xref="マタイの福音書 19:11–12; ローマ人への手紙 12:6; コリント人への手紙第一 9:5"> 私の願うところは、すべての人が私のようであることです。しかし、ひとりひとり神から与えられたそれぞれの賜物を持っているので、人それぞれに行き方があります。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="コリント人への手紙第一 7:32; コリント人への手紙第一 7:34–35; コリント人への手紙第一 7:26–27"> 次に、結婚していない男とやもめの女に言いますが、私のようにしていられるなら、それがよいのです。</span>
<span className="v" id="v9" data-v="9" data-xref="コリント人への手紙第一 7:2; テモテへの手紙第一 5:14; テモテへの手紙第一 5:11"> しかし、もし自制することができなければ、結婚しなさい。情の燃えるよりは、結婚するほうがよいからです。</span>
<span className="v" id="v10" data-v="10" data-xref="マタイの福音書 5:32; ルカの福音書 16:18; マタイの福音書 19:3–9"> 次に、すでに結婚した人々に命じます。命じるのは、私ではなく主です。妻は夫と別れてはいけません。</span>
<span className="v" id="v11" data-v="11" data-xref="Jeremiah 3:1; コリント人への手紙第一 7:10; Isaiah 50:1"> ――もし別れたのだったら、結婚せずにいるか、それとも夫と和解するか、どちらかにしなさい。――また夫は妻を離別してはいけません。</span>
<span className="v" id="v12" data-v="12" data-xref="コリント人への手紙第二 11:17; コリント人への手紙第一 7:6; コリント人への手紙第一 7:25"> 次に、そのほかの人々に言いますが、これを言うのは主ではなく、私です。信者の男子に信者でない妻があり、その妻がいっしょにいることを承知しているばあいは、離婚してはいけません。</span>
<span className="v" id="v13" data-v="13"> また、信者でない夫を持つ女は、夫がいっしょにいることを承知しているばあいは、離婚してはいけません。</span>
<span className="v" id="v14" data-v="14" data-xref="Malachi 2:15–16; テモテへの手紙第一 4:5; テトスへの手紙 1:15"> なぜなら、信者でない夫は妻によってきよめられており、また、信者でない妻も信者の夫によってきよめられているからです。そうでなかったら、あなたがたの子どもは汚れているわけです。ところが、現にきよいのです。</span>
<span className="v" id="v15" data-v="15" data-xref="ローマ人への手紙 14:19; コリント人への手紙第二 13:11; ヤコブの手紙 3:17–18"> しかし、もし信者でないほうの者が離れて行くのであれば、離れて行かせなさい。そのようなばあいには、信者である夫あるいは妻は、縛られることはありません。神は、平和を得させようとしてあなたがたを召されたのです。</span>
<span className="v" id="v16" data-v="16" data-xref="ペテロの手紙第一 3:1–2; コリント人への手紙第一 9:22; ローマ人への手紙 11:14"> なぜなら、妻よ。あなたが夫を救えるかどうかが、どうしてわかりますか。また、夫よ。あなたが妻を救えるかどうかが、どうしてわかりますか。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="コリント人への手紙第一 4:17; ローマ人への手紙 12:3–8; コリント人への手紙第一 7:24"> ただ、おのおのが、主からいただいた分に応じ、また神がおのおのをお召しになったときのままの状態で歩むべきです。私は、すべての教会で、このように指導しています。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒の働き 15:5; 使徒の働き 15:28; 使徒の働き 15:24"> 召されたとき割礼を受けていたのなら、その跡をなくしてはいけません。また、召されたとき割礼を受けていなかったのなら、割礼を受けてはいけません。</span>
<span className="v" id="v19" data-v="19" data-xref="ガラテヤ人への手紙 6:15; ガラテヤ人への手紙 5:6; ヨハネの手紙第一 2:3–4"> 割礼は取るに足らぬこと、無割礼も取るに足らぬことです。重要なのは神の命令を守ることです。</span>
<span className="v" id="v20" data-v="20" data-xref="コリント人への手紙第一 7:17; テサロニケ人への手紙第一 4:11; テサロニケ人への手紙第二 3:12"> おのおの自分が召されたときの状態にとどまっていなさい。</span>
<span className="v" id="v21" data-v="21" data-xref="ペテロの手紙第一 2:18–24; コロサイ人への手紙 3:11; ルカの福音書 10:40–41"> 奴隷の状態で召されたのなら、それを気にしてはいけません。しかし、もし自由の身になれるなら、むしろ自由になりなさい。</span>
<span className="v" id="v22" data-v="22" data-xref="ペテロの手紙第一 2:16; ピレモンへの手紙 1:16; コロサイ人への手紙 3:22–24"> 奴隷も、主にあって召された者は、主に属する自由人であり、同じように、自由人も、召された者はキリストに属する奴隷だからです。</span>
<span className="v" id="v23" data-v="23" data-xref="コリント人への手紙第一 6:20; ペテロの手紙第一 1:18–19; テトスへの手紙 2:14"> あなたがたは、代価をもって買われたのです。人間の奴隷となってはいけません。</span>
<span className="v" id="v24" data-v="24" data-xref="コリント人への手紙第一 7:20; コロサイ人への手紙 3:23–24; コリント人への手紙第一 7:17"> 兄弟たち。おのおの召されたときのままの状態で、神の御前にいなさい。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="コリント人への手紙第一 7:6; コリント人への手紙第一 4:2; コリント人への手紙第一 7:40"> 処女のことについて、私は主の命令を受けてはいませんが、主のあわれみによって信頼できる者として、意見を述べます。</span>
<span className="v" id="v26" data-v="26" data-xref="コリント人への手紙第一 7:1; コリント人への手紙第一 7:8; ペテロの手紙第一 4:17"> 現在の危急のときには、男はそのままの状態にとどまるのがよいと思います。</span>
<span className="v" id="v27" data-v="27" data-xref="コリント人への手紙第一 7:20; コリント人への手紙第一 7:12–14"> あなたが妻に結ばれているなら、解かれたいと考えてはいけません。妻に結ばれていないのなら、妻を得たいと思ってはいけません。</span>
<span className="v" id="v28" data-v="28" data-xref="ヘブル人への手紙 13:4; コリント人への手紙第一 7:32–36; コリント人への手紙第一 7:26"> しかし、たといあなたが結婚したからといって、罪を犯すのではありません。たとい処女が結婚したからといって、罪を犯すのではありません。ただ、それらの人々は、その身に苦難を招くでしょう。私はあなたがたを、そのようなめに会わせたくないのです。</span>
<span className="v" id="v29" data-v="29" data-xref="ヨハネの手紙第一 2:17; コリント人への手紙第一 7:31; ローマ人への手紙 13:11–12"> 兄弟たちよ。私は次のことを言いたいのです。時は縮まっています。今からは、妻のある者は、妻のない者のようにしていなさい。</span>
<span className="v" id="v30" data-v="30" data-xref="Psalms 30:5; ルカの福音書 6:25; ルカの福音書 6:21"> 泣く者は泣かない者のように、喜ぶ者は喜ばない者のように、買う者は所有しない者のようにしていなさい。</span>
<span className="v" id="v31" data-v="31" data-xref="ヨハネの手紙第一 2:17; ペテロの手紙第一 4:7; ヤコブの手紙 4:14"> 世の富を用いる者は用いすぎないようにしなさい。この世の有様は過ぎ去るからです。</span>
<span className="v" id="v32" data-v="32" data-xref="マタイの福音書 6:25–34; テモテへの手紙第一 5:5; ピリピ人への手紙 4:6"> あなたがたが思い煩わないことを私は望んでいます。独身の男は、どうしたら主に喜ばれるかと、主のことに心を配ります。</span>
<span className="v" id="v33" data-v="33" data-xref="ペテロの手紙第一 3:7; コロサイ人への手紙 3:19; エペソ人への手紙 5:25–33"> しかし、結婚した男は、どうしたら妻に喜ばれるかと世のことに心を配り、</span>
<span className="v" id="v34" data-v="34" data-xref="ルカの福音書 10:40–42; コリント人への手紙第一 6:20; ルカの福音書 2:36–37"> 心が分かれるのです。独身の女や処女は、身もたましいもきよくなるため、主のことに心を配りますが、結婚した女は、どうしたら夫に喜ばれるかと、世のことに心を配ります。</span>
<span className="v" id="v35" data-v="35" data-xref="コリント人への手紙第一 7:33–34; コリント人への手紙第一 7:36; ルカの福音書 8:14"> ですが、私がこう言っているのは、あなたがた自身の益のためであって、あなたがたを束縛しようとしているのではありません。むしろあなたがたが秩序ある生活を送って、ひたすら主に奉仕できるためなのです。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="コリント人への手紙第一 7:37; コリント人への手紙第一 7:9; 1 Samuel 2:33"> もし、処女である自分の娘の婚期も過ぎようとしていて、そのままでは、娘に対しての扱い方が正しくないと思い、またやむをえないことがあるならば、その人は、その心のままにしなさい。罪を犯すわけではありません。彼らに結婚させなさい。</span>
<span className="v" id="v37" data-v="37"> しかし、もし心のうちに堅く決意しており、ほかに強いられる事情もなく、また自分の思うとおりに行なうことのできる人が、処女である自分の娘をそのままにしておくのなら、そのことはりっぱです。</span>
<span className="v" id="v38" data-v="38" data-xref="ヘブル人への手紙 13:4; コリント人への手紙第一 7:1–2; コリント人への手紙第一 7:8"> ですから、処女である自分の娘を結婚させる人は良いことをしているのであり、また結婚させない人は、もっと良いことをしているのです。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="ローマ人への手紙 7:2–3; コリント人への手紙第二 6:14–16; コリント人への手紙第一 7:10"> 妻は夫が生きている間は夫に縛られています。しかし、もし夫が死んだなら、自分の願う人と結婚する自由があります。ただ主にあってのみ、そうなのです。</span>
<span className="v" id="v40" data-v="40" data-xref="コリント人への手紙第一 7:35; ペテロの手紙第二 3:15–16; コリント人への手紙第一 7:8"> 私の意見では、もしそのままにしていられたら、そのほうがもっと幸いです。私も、神の御霊をいただいていると思います。</span>
</div>

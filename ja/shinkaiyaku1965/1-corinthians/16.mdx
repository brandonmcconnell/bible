<span className="v" id="v1" data-v="1" data-xref="ローマ人への手紙 12:13; コリント人への手紙第二 8:1–9; コリント人への手紙第二 9:12–15"> さて、聖徒たちのための献金については、ガラテヤの諸教会に命じたように、あなたがたにもこう命じます。</span>
<span className="v" id="v2" data-v="2" data-xref="Malachi 3:9–10; Deuteronomy 15:11–14; Deuteronomy 8:18"> 私がそちらに行ってから献金を集めるようなことがないように、あなたがたはおのおの、いつも週の初めの日に、収入に応じて、手もとにそれをたくわえておきなさい。</span>
<span className="v" id="v3" data-v="3" data-xref="コリント人への手紙第二 8:6; コリント人への手紙第一 11:34; コリント人への手紙第一 4:19–21"> 私がそちらに行ったとき、あなたがたの承認を得た人々に手紙を持たせて派遣し、あなたがたの献金をエルサレムに届けさせましょう。</span>
<span className="v" id="v4" data-v="4" data-xref="コリント人への手紙第二 8:4; コリント人への手紙第二 8:19; ローマ人への手紙 15:25"> しかし、もし私も行くほうがよければ、彼らは、私といっしょに行くことになるでしょう。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒の働き 19:21; コリント人への手紙第一 4:19; コリント人への手紙第二 1:15–17"> 私は、マケドニヤを通って後、あなたがたのところへ行きます。マケドニヤを通るつもりでいますから。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒の働き 15:3; ローマ人への手紙 15:24; 使徒の働き 20:38"> そして、たぶんあなたがたのところに滞在するでしょう。冬を越すことになるかもしれません。それは、どこに行くとしても、あなたがたに送っていただこうと思うからです。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒の働き 18:21; コリント人への手紙第一 4:19; ヤコブの手紙 4:15"> 私は、いま旅の途中に、あなたがたの顔を見たいと思っているのではありません。主がお許しになるなら、あなたがたのところにしばらく滞在したいと願っています。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒の働き 2:1; Exodus 23:16; 使徒の働き 18:19"> しかし、五旬節まではエペソに滞在するつもりです。</span>
<span className="v" id="v9" data-v="9" data-xref="コリント人への手紙第二 2:12; 使徒の働き 14:27; コロサイ人への手紙 4:3"> というのは、働きのための広い門が私のために開かれており、反対者も大ぜいいるからです。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="コリント人への手紙第一 15:58; テサロニケ人への手紙第一 3:2; ローマ人への手紙 16:21"> テモテがそちらへ行ったら、あなたがたのところで心配なく過ごせるよう心を配ってください。彼も、私と同じように、主のみわざに励んでいるからです。</span>
<span className="v" id="v11" data-v="11" data-xref="テモテへの手紙第一 4:12; 使徒の働き 15:33; テトスへの手紙 2:15"> だれも彼を軽んじてはいけません。彼を平安のうちに送り出して、私のところに来させてください。私は、彼が兄弟たちとともに来るのを待ち望んでいます。</span>
<span className="v" id="v12" data-v="12" data-xref="コリント人への手紙第一 1:12; コリント人への手紙第一 3:5; テトスへの手紙 3:4"> 兄弟アポロのことですが、兄弟たちといっしょにあなたがたのところへ行くように、私は強く彼に勧めました。しかし、彼は今、そちらへ行こうとは全然思っていません。しかし、機会があれば行くでしょう。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="Joshua 1:9; エペソ人への手紙 6:13–18; エペソ人への手紙 6:10"> 目を覚ましていなさい。堅く信仰に立ちなさい。男らしく、強くありなさい。</span>
<span className="v" id="v14" data-v="14" data-xref="ヨハネの福音書 13:34–35; ペテロの手紙第一 4:8; テモテへの手紙第一 1:5"> いっさいのことを愛をもって行ないなさい。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="コリント人への手紙第一 1:16; ローマ人への手紙 16:5; ローマ人への手紙 16:2"> 兄弟たちよ。あなたがたに勧めます。ご承知のように、ステパナの家族は、アカヤの初穂であって、聖徒たちのために熱心に奉仕してくれました。</span>
<span className="v" id="v16" data-v="16" data-xref="ヘブル人への手紙 13:17; テサロニケ人への手紙第一 5:12; ヨハネの手紙第三 1:8"> あなたがたは、このような人たちに、また、ともに働き、労しているすべての人たちに服従しなさい。</span>
<span className="v" id="v17" data-v="17" data-xref="コリント人への手紙第二 11:9; ピリピ人への手紙 2:30; ピレモンへの手紙 1:13"> ステパナとポルトナトとアカイコが来たので、私は喜んでいます。なぜなら、彼らは、あなたがたの足りない分を補ってくれたからです。</span>
<span className="v" id="v18" data-v="18" data-xref="ピレモンへの手紙 1:7; コリント人への手紙第二 7:13; テサロニケ人への手紙第一 5:12"> 彼らは、私の心をも、あなたがたの心をも安心させてくれました。このような人々の労をねぎらいなさい。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="使徒の働き 18:2; ピレモンへの手紙 1:2; ローマ人への手紙 16:3–5"> アジヤの諸教会がよろしくと言っています。アクラとプリスカ、また彼らの家の教会が主にあって心から、あなたがたによろしくと言っています。</span>
<span className="v" id="v20" data-v="20" data-xref="ローマ人への手紙 16:16; テサロニケ人への手紙第一 5:26; ペテロの手紙第一 5:14"> すべての兄弟たちが、あなたがたによろしくと言っています。きよい口づけをもって、互いにあいさつをかわしなさい。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="コロサイ人への手紙 4:18; ガラテヤ人への手紙 6:11; テサロニケ人への手紙第二 3:17"> パウロが、自分の手であいさつを書きます。</span>
<span className="v" id="v22" data-v="22" data-xref="エペソ人への手紙 6:24; ヨハネの福音書 14:21; コリント人への手紙第二 5:14–15"> 主を愛さない者はだれでも、のろわれよ。主よ、来てください。</span>
<span className="v" id="v23" data-v="23" data-xref="ローマ人への手紙 16:20; ローマ人への手紙 16:23"> 主イエスの恵みが、あなたがたとともにありますように。</span>
<span className="v" id="v24" data-v="24" data-xref="コリント人への手紙第一 14:16; ヨハネの黙示録 3:19; コリント人への手紙第二 12:15"> 私の愛は、キリスト・イエスにあって、あなたがたすべての者とともにあります。アーメン。</span>

<span className="v" id="v1" data-v="1" data-xref="ヨハネの黙示録 21:8; ヨハネの黙示録 2:21; コロサイ人への手紙 3:5"> あなたがたの間に不品行があるということが言われています。しかもそれは、異邦人の中にもないほどの不品行で、父の妻を妻にしている者がいるとのことです。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネの黙示録 2:20–22; コリント人への手紙第二 7:7–11; コリント人への手紙第一 5:13"> それなのに、あなたがたは誇り高ぶっています。そればかりか、そのような行ないをしている者をあなたがたの中から取り除こうとして悲しむこともなかったのです。</span>
<span className="v" id="v3" data-v="3" data-xref="コロサイ人への手紙 2:5; テサロニケ人への手紙第一 2:17; コリント人への手紙第二 13:2"> 私のほうでは、からだはそこにいなくても心はそこにおり、現にそこにいるのと同じように、そのような行ないをした者を主イエスの御名によってすでにさばきました。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネの福音書 20:23; コロサイ人への手紙 3:17; マタイの福音書 16:19"> あなたがたが集まったときに、私も、霊においてともにおり、私たちの主イエスの権能をもって、</span>
<span className="v" id="v5" data-v="5" data-xref="テモテへの手紙第一 1:20; テサロニケ人への手紙第二 3:14–15; ガラテヤ人への手紙 6:1–2"> このような者をサタンに引き渡したのです。それは彼の肉が滅ぼされるためですが、それによって彼の霊が主の日に救われるためです。</span>
<span className="v" id="v6" data-v="6" data-xref="ガラテヤ人への手紙 5:9; コリント人への手紙第一 15:33; ヤコブの手紙 4:16"> あなたがたの高慢は、よくないことです。あなたがたは、ほんのわずかのパン種が、粉のかたまり全体をふくらませることを知らないのですか。</span>
<span className="v" id="v7" data-v="7" data-xref="ペテロの手紙第一 1:19–20; エペソ人への手紙 4:22; コロサイ人への手紙 3:5–9"> 新しい粉のかたまりのままでいるために、古いパン種を取り除きなさい。あなたがたはパン種のないものだからです。私たちの過越の小羊キリストが、すでにほふられたからです。</span>
<span className="v" id="v8" data-v="8" data-xref="ペテロの手紙第一 2:1–2; Deuteronomy 16:3; Exodus 12:15"> ですから、私たちは、古いパン種を用いたり、悪意と不正のパン種を用いたりしないで、パン種のはいらない、純粋で真実なパンで、祭りをしようではありませんか。</span>
<span className="v" id="v9" data-v="9" data-xref="エペソ人への手紙 5:11; テサロニケ人への手紙第二 3:14; コリント人への手紙第二 6:14"> 私は前にあなたがたに送った手紙で、不品行な者たちと交際しないようにと書きました。</span>
<span className="v" id="v10" data-v="10" data-xref="コリント人への手紙第一 10:27; ヨハネの福音書 17:15–16; マタイの福音書 5:14–16"> それは、世の中の不品行な者、貪欲な者、略奪する者、偶像を礼拝する者と全然交際しないようにという意味ではありません。もしそうだとしたら、この世界から出て行かなければならないでしょう。</span>
<span className="v" id="v11" data-v="11" data-xref="ローマ人への手紙 16:17; テサロニケ人への手紙第二 3:14; テサロニケ人への手紙第二 3:6"> 私が書いたことのほんとうの意味は、もし、兄弟と呼ばれる者で、しかも不品行な者、貪欲な者、偶像を礼拝する者、人をそしる者、酒に酔う者、略奪する者がいたなら、そのような者とはつきあってはいけない、いっしょに食事をしてもいけない、ということです。</span>
<span className="v" id="v12" data-v="12" data-xref="マルコの福音書 4:11; テモテへの手紙第一 3:7; ルカの福音書 12:14"> 外部の人たちをさばくことは、私のすべきことでしょうか。あなたがたがさばくべき者は、内部の人たちではありませんか。</span>
<span className="v" id="v13" data-v="13" data-xref="Deuteronomy 17:7; Deuteronomy 13:5; Deuteronomy 21:21"> 外部の人たちは、神がおさばきになります。その悪い人をあなたがたの中から除きなさい。</span>

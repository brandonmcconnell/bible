<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヘブル人への手紙 5:13; コリント人への手紙第一 2:14–15; エペソ人への手紙 4:13–14"> さて、兄弟たちよ。私は、あなたがたに向かって、御霊に属する人に対するようには話すことができないで、肉に属する人、キリストにある幼子に対するように話しました。</span>
<span className="v" id="v2" data-v="2" data-xref="ヘブル人への手紙 5:11–14; ヨハネの福音書 16:12; ペテロの手紙第一 2:2"> 私はあなたがたには乳を与えて、堅い食物を与えませんでした。あなたがたには、まだ無理だったからです。実は、今でもまだ無理なのです。</span>
<span className="v" id="v3" data-v="3" data-xref="ヤコブの手紙 3:16; ガラテヤ人への手紙 5:15; テトスへの手紙 3:3"> あなたがたは、まだ肉に属しているからです。あなたがたの間にねたみや争いがあることからすれば、あなたがたは肉に属しているのではありませんか。そして、ただの人のように歩んでいるのではありませんか。</span>
<span className="v" id="v4" data-v="4" data-xref="コリント人への手紙第一 1:12; コリント人への手紙第一 3:3; コリント人への手紙第一 4:6"> ある人が、「私はパウロにつく。」と言えば、別の人は、「私はアポロに。」と言う。そういうことでは、あなたがたは、ただの人たちではありませんか。</span>
<span className="v" id="v5" data-v="5" data-xref="コリント人への手紙第二 6:4; コリント人への手紙第二 6:1; ペテロの手紙第一 4:10"> アポロとは何でしょう。パウロとは何でしょう。あなたがたが信仰にはいるために用いられたしもべであって、主がおのおのに授けられたとおりのことをしたのです。</span>
<span className="v" id="v6" data-v="6" data-xref="コリント人への手紙第一 3:9–10; Proverbs 11:25; コリント人への手紙第二 10:14–15"> 私が植えて、アポロが水を注ぎました。しかし、成長させたのは神です。</span>
<span className="v" id="v7" data-v="7" data-xref="ヨハネの福音書 15:5; ガラテヤ人への手紙 6:3; Psalms 115:1"> それで、たいせつなのは、植える者でも水を注ぐ者でもありません。成長させてくださる神なのです。</span>
<span className="v" id="v8" data-v="8" data-xref="ローマ人への手紙 2:6; マタイの福音書 16:27; ヨハネの手紙第二 1:8"> 植える者と水を注ぐ者は、一つですが、それぞれ自分自身の働きに従って自分自身の報酬を受けるのです。</span>
<span className="v" id="v9" data-v="9" data-xref="ペテロの手紙第一 2:5; エペソ人への手紙 2:20–22; コリント人への手紙第二 6:1"> 私たちは神の協力者であり、あなたがたは神の畑、神の建物です。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="コリント人への手紙第一 3:11; エペソ人への手紙 2:20; ローマ人への手紙 15:20"> 与えられた神の恵みによって、私は賢い建築家のように、土台を据えました。そして、ほかの人がその上に家を建てています。しかし、どのように建てるかについてはそれぞれが注意しなければなりません。</span>
<span className="v" id="v11" data-v="11" data-xref="エペソ人への手紙 2:20; Isaiah 28:16; テモテへの手紙第二 2:19"> というのは、だれも、すでに据えられている土台のほかに、ほかの物を据えることはできないからです。その土台とはイエス・キリストです。</span>
<span className="v" id="v12" data-v="12" data-xref="テモテへの手紙第二 4:3; テモテへの手紙第二 3:7; テモテへの手紙第二 2:20"> もし、だれかがこの土台の上に、金、銀、宝石、木、草、わらなどで建てるなら、</span>
<span className="v" id="v13" data-v="13" data-xref="ペテロの手紙第一 1:7; コリント人への手紙第一 3:14–15; ヨハネの黙示録 20:12"> 各人の働きは明瞭になります。その日がそれを明らかにするのです。というのは、その日は火とともに現われ、この火がその力で各人の働きの真価をためすからです。</span>
<span className="v" id="v14" data-v="14" data-xref="コリント人への手紙第一 3:8; マタイの福音書 25:21–23; コリント人への手紙第一 4:5"> もしだれかの建てた建物が残れば、その人は報いを受けます。</span>
<span className="v" id="v15" data-v="15" data-xref="ヨハネの手紙第二 1:8; コリント人への手紙第一 3:12–13; ユダの手紙 1:23"> もしだれかの建てた建物が焼ければ、その人は損害を受けますが、自分自身は、火の中をくぐるようにして助かります。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="コリント人への手紙第一 6:19; Ezekiel 36:27; コリント人への手紙第二 6:16"> あなたがたは神の神殿であり、神の御霊があなたがたに宿っておられることを知らないのですか。</span>
<span className="v" id="v17" data-v="17" data-xref="コリント人への手紙第一 6:18–20; Ezekiel 43:12; Numbers 19:20"> もし、だれかが神の神殿をこわすなら、神がその人を滅ぼされます。神の神殿は聖なるものだからです。あなたがたがその神殿です。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="Proverbs 3:5; Isaiah 5:21; ガラテヤ人への手紙 6:3"> だれも自分を欺いてはいけません。もしあなたがたの中で、自分は今の世の知者だと思う者がいたら、知者になるためには愚かになりなさい。</span>
<span className="v" id="v19" data-v="19" data-xref="Job 5:13; Psalms 141:10; コリント人への手紙第一 1:19–20"> なぜなら、この世の知恵は、神の御前では愚かだからです。こう書いてあります。「神は、知者どもを彼らの悪賢さの中で捕える。」</span>
<span className="v" id="v20" data-v="20" data-xref="Psalms 94:11; コロサイ人への手紙 2:8; ローマ人への手紙 1:21"> また、次のようにも書いてあります。「主は、知者の論議を無益だと知っておられる。」</span>
<span className="v" id="v21" data-v="21" data-xref="ローマ人への手紙 8:32; ローマ人への手紙 8:28; Jeremiah 9:23–24"> ですから、だれも人間を誇ってはいけません。すべては、あなたがたのものです。</span>
<span className="v" id="v22" data-v="22" data-xref="エペソ人への手紙 4:11–12; ピリピ人への手紙 1:21; コリント人への手紙第一 9:19–22"> パウロであれ、アポロであれ、ケパであれ、また世界であれ、いのちであれ、死であれ、また現在のものであれ、未来のものであれ、すべてあなたがたのものです。</span>
<span className="v" id="v23" data-v="23" data-xref="ガラテヤ人への手紙 3:29; コリント人への手紙第一 11:3; ヨハネの福音書 17:9–10"> そして、あなたがたはキリストのものであり、キリストは神のものです。</span>
</div>

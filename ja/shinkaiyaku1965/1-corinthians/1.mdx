<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ローマ人への手紙 1:1; エペソ人への手紙 1:1; コリント人への手紙第二 1:1"> 神のみこころによってキリスト・イエスの使徒として召されたパウロと、兄弟ソステネから、</span>
<span className="v" id="v2" data-v="2" data-xref="ローマ人への手紙 1:7; コリント人への手紙第一 6:9–11; コリント人への手紙第一 1:30"> コリントにある神の教会へ。すなわち、私たちの主イエス・キリストの御名を、至る所で呼び求めているすべての人々とともに、聖徒として召され、キリスト・イエスにあってきよめられた方々へ。主は私たちの主であるとともに、そのすべての人々の主です。</span>
<span className="v" id="v3" data-v="3" data-xref="ローマ人への手紙 1:7; コリント人への手紙第二 1:2; ペテロの手紙第一 1:2"> 私たちの父なる神と主イエス・キリストから、恵みと平安があなたがたの上にありますように。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="ローマ人への手紙 1:8; ヨハネの福音書 14:26; テモテへの手紙第一 1:14"> 私は、キリスト・イエスによってあなたがたに与えられた神の恵みのゆえに、あなたがたのことをいつも神に感謝しています。</span>
<span className="v" id="v5" data-v="5" data-xref="コリント人への手紙第二 9:11; コリント人への手紙第二 8:7; コロサイ人への手紙 2:3"> というのは、あなたがたは、ことばといい、知識といい、すべてにおいて、キリストにあって豊かな者とされたからです。</span>
<span className="v" id="v6" data-v="6" data-xref="ヨハネの黙示録 1:2; テモテへの手紙第二 1:8; テモテへの手紙第一 2:6"> それは、キリストについてのあかしが、あなたがたの中で確かになったからで、</span>
<span className="v" id="v7" data-v="7" data-xref="ピリピ人への手紙 3:20; ペテロの手紙第二 3:12; ヘブル人への手紙 9:28"> その結果、あなたがたはどんな賜物にも欠けるところがなく、また、熱心に私たちの主イエス・キリストの現われを待っています。</span>
<span className="v" id="v8" data-v="8" data-xref="テサロニケ人への手紙第一 5:23–24; テサロニケ人への手紙第一 3:13; コロサイ人への手紙 1:22"> 主も、あなたがたを、私たちの主イエス・キリストの日に責められるところのない者として、最後まで堅く保ってくださいます。</span>
<span className="v" id="v9" data-v="9" data-xref="テサロニケ人への手紙第二 3:3; ヘブル人への手紙 10:23; Deuteronomy 7:9"> 神は真実であり、その方のお召しによって、あなたがたは神の御子、私たちの主イエス・キリストとの交わりに入れられました。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="ピリピ人への手紙 2:1–4; エペソ人への手紙 4:1–7; コリント人への手紙第一 12:25"> さて、兄弟たち。私は、私たちの主イエス・キリストの御名によって、あなたがたにお願いします。どうか、みなが一致して、仲間割れすることなく、同じ心、同じ判断を完全に保ってください。</span>
<span className="v" id="v11" data-v="11" data-xref="Proverbs 18:6; テモテへの手紙第一 6:4; テモテへの手紙第二 2:23–25"> 実はあなたがたのことをクロエの家の者から知らされました。兄弟たち。あなたがたの間には争いがあるそうで、</span>
<span className="v" id="v12" data-v="12" data-xref="コリント人への手紙第一 3:21–23; ヨハネの福音書 1:42; マタイの福音書 23:9–10"> あなたがたはめいめいに、「私はパウロにつく。」「私はアポロに。」「私はケパに。」「私はキリストにつく。」と言っているということです。</span>
<span className="v" id="v13" data-v="13" data-xref="エペソ人への手紙 4:5; コリント人への手紙第二 11:4; 使徒の働き 2:38"> キリストが分割されたのですか。あなたがたのために十字架につけられたのはパウロでしょうか。あなたがたがバプテスマを受けたのはパウロの名によるのでしょうか。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒の働き 18:8; ローマ人への手紙 16:23; コリント人への手紙第一 1:4"> 私は、クリスポとガイオのほか、あなたがたのだれにもバプテスマを授けたことがないことを感謝しています。</span>
<span className="v" id="v15" data-v="15" data-xref="コリント人への手紙第二 11:2; ヨハネの福音書 3:28–29; ヨハネの福音書 7:18"> それは、あなたがたが私の名によってバプテスマを受けたと言われないようにするためでした。</span>
<span className="v" id="v16" data-v="16" data-xref="コリント人への手紙第一 16:15; コリント人への手紙第一 16:17; 使徒の働き 16:33"> 私はステパナの家族にもバプテスマを授けましたが、そのほかはだれにも授けた覚えはありません。</span>
<span className="v" id="v17" data-v="17" data-xref="コリント人への手紙第一 2:1; コリント人への手紙第一 2:13; ペテロの手紙第二 1:16"> キリストが私をお遣わしになったのは、バプテスマを授けさせるためではなく、福音を宣べ伝えさせるためです。それも、キリストの十字架がむなしくならないために、ことばの知恵によってはならないのです。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="コリント人への手紙第一 2:14; ローマ人への手紙 1:16; テサロニケ人への手紙第二 2:10"> 十字架のことばは、滅びに至る人々には愚かであっても、救いを受ける私たちには、神の力です。</span>
<span className="v" id="v19" data-v="19" data-xref="Isaiah 29:14; Jeremiah 8:9; コリント人への手紙第一 3:19"> それは、こう書いてあるからです。<br />「わたしは知恵ある者の知恵を滅ぼし、<br />賢い者の賢さをむなしくする。」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="ローマ人への手紙 1:22; Job 12:17; コリント人への手紙第一 3:19"> 知者はどこにいるのですか。学者はどこにいるのですか。この世の議論家はどこにいるのですか。神は、この世の知恵を愚かなものにされたではありませんか。</span>
<span className="v" id="v21" data-v="21" data-xref="ルカの福音書 10:21; ローマ人への手紙 1:20–22; マタイの福音書 11:25"> 事実、この世が自分の知恵によって神を知ることがないのは、神の知恵によるのです。それゆえ、神はみこころによって、宣教のことばの愚かさを通して、信じる者を救おうと定められたのです。</span>
<span className="v" id="v22" data-v="22" data-xref="マタイの福音書 16:1–4; マタイの福音書 12:38–39; マルコの福音書 8:11"> ユダヤ人はしるしを要求し、ギリシヤ人は知恵を追求します。</span>
<span className="v" id="v23" data-v="23" data-xref="コリント人への手紙第一 2:14; コリント人への手紙第一 2:2; ペテロの手紙第一 2:8"> しかし、私たちは十字架につけられたキリストを宣べ伝えるのです。ユダヤ人にとってはつまずき、異邦人にとっては愚かでしょうが、</span>
<span className="v" id="v24" data-v="24" data-xref="コリント人への手紙第一 1:30; コロサイ人への手紙 2:3; コリント人への手紙第一 1:18"> しかし、ユダヤ人であってもギリシヤ人であっても、召された者にとっては、キリストは神の力、神の知恵なのです。</span>
<span className="v" id="v25" data-v="25" data-xref="ローマ人への手紙 11:33–36; コリント人への手紙第一 1:18; Zechariah 4:6–7"> なぜなら、神の愚かさは人よりも賢く、神の弱さは人よりも強いからです。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="ヤコブの手紙 2:5; コリント人への手紙第一 3:18–20; ヤコブの手紙 1:9–11"> 兄弟たち、あなたがたの召しのことを考えてごらんなさい。この世の知者は多くはなく、権力者も多くはなく、身分の高い者も多くはありません。</span>
<span className="v" id="v27" data-v="27" data-xref="ヤコブの手紙 2:5; マタイの福音書 11:25; コリント人への手紙第一 1:20"> しかし神は、知恵ある者をはずかしめるために、この世の愚かな者を選び、強い者をはずかしめるために、この世の弱い者を選ばれたのです。</span>
<span className="v" id="v28" data-v="28" data-xref="Job 34:24; ローマ人への手紙 4:17; Isaiah 2:11"> また、この世の取るに足りない者や見下されている者を、神は選ばれました。すなわち、有るものをない者のようにするため、無に等しいものを選ばれたのです。</span>
<span className="v" id="v29" data-v="29" data-xref="ローマ人への手紙 3:27; Jeremiah 9:23; エペソ人への手紙 2:9"> これは、神の御前でだれをも誇らせないためです。</span>
<span className="v" id="v30" data-v="30" data-xref="エペソ人への手紙 1:7; ピリピ人への手紙 3:9; ローマ人への手紙 8:1"> しかしあなたがたは、神によってキリスト・イエスのうちにあるのです。キリストは、私たちにとって、神の知恵となり、また、義ときよめと、贖いとになられました。</span>
<span className="v" id="v31" data-v="31" data-xref="Jeremiah 9:23–24; コリント人への手紙第二 10:17; ピリピ人への手紙 3:3"> まさしく、「誇る者は主にあって誇れ。」と書かれているとおりになるためです。</span>
</div>

<span className="v" id="v1" data-v="1" data-xref="使徒の働き 9:17; テモテへの手紙第一 2:7; コリント人への手紙第一 9:19"> 私には自由がないでしょうか。私は使徒ではないのでしょうか。私は私たちの主イエスを見たのではないでしょうか。あなたがたは、主にあって私の働きの実ではありませんか。</span>
<span className="v" id="v2" data-v="2" data-xref="コリント人への手紙第二 12:12; ヨハネの福音書 6:27; コリント人への手紙第二 3:1–3"> たとい私がほかの人々に対しては使徒でなくても、少なくともあなたがたに対しては使徒です。あなたがたは、主にあって、私が使徒であることの証印です。</span>
<span className="v" id="v3" data-v="3" data-xref="コリント人への手紙第二 12:16–19; コリント人への手紙第二 13:3; コリント人への手紙第二 13:10"> 私をさばく人たちに対して、私は次のように弁明します。</span>
<span className="v" id="v4" data-v="4" data-xref="テサロニケ人への手紙第一 2:6; テサロニケ人への手紙第二 3:8–9; ルカの福音書 10:7"> いったい私たちには飲み食いする権利がないのでしょうか。</span>
<span className="v" id="v5" data-v="5" data-xref="ヨハネの福音書 1:42; ヘブル人への手紙 13:4; マタイの福音書 8:14"> 私たちには、ほかの使徒、主の兄弟たち、ケパなどと違って、信者である妻を連れて歩く権利がないのでしょうか。</span>
<span className="v" id="v6" data-v="6" data-xref="テサロニケ人への手紙第二 3:7–9; 使徒の働き 13:1–2; 使徒の働き 4:36"> それともまた、私とバルナバだけには、生活のための働きをやめる権利がないのでしょうか。</span>
<span className="v" id="v7" data-v="7" data-xref="Proverbs 27:18; Deuteronomy 20:6; テモテへの手紙第二 2:3–4"> いったい自分の費用で兵士になる者がいるでしょうか。自分でぶどう園を造りながら、その実を食べない者がいるでしょうか。羊の群れを飼いながら、その乳を飲まない者がいるでしょうか。</span>
<span className="v" id="v8" data-v="8" data-xref="Isaiah 8:20; テサロニケ人への手紙第一 4:8; ローマ人への手紙 3:31"> 私がこんなことを言うのは、人間の考えによって言っているのでしょうか。律法も同じことを言っているではありませんか。</span>
<span className="v" id="v9" data-v="9" data-xref="Deuteronomy 25:4; テモテへの手紙第一 5:18; Psalms 104:27"> モーセの律法には、「穀物をこなしている牛に、くつこを掛けてはいけない。」と書いてあります。いったい神は、牛のことを気にかけておられるのでしょうか。</span>
<span className="v" id="v10" data-v="10" data-xref="テモテへの手紙第二 2:6; ローマ人への手紙 15:4; ローマ人への手紙 4:23–24"> それとも、もっぱら私たちのために、こう言っておられるのでしょうか。むろん、私たちのためにこう書いてあるのです。なぜなら、耕す者が望みを持って耕し、脱穀する者が分配を受ける望みを持って仕事をするのは当然だからです。</span>
<span className="v" id="v11" data-v="11" data-xref="ローマ人への手紙 15:27; ガラテヤ人への手紙 6:6; コリント人への手紙第二 11:15"> もし私たちが、あなたがたに御霊のものを蒔いたのであれば、あなたがたから物質的なものを刈り取ることは行き過ぎでしょうか。</span>
<span className="v" id="v12" data-v="12" data-xref="コリント人への手紙第一 9:15; コリント人への手紙第一 9:18; コリント人への手紙第二 11:12"> もし、ほかの人々が、あなたがたに対する権利にあずかっているのなら、私たちはなおさらその権利を用いてよいはずではありませんか。それなのに、私たちはこの権利を用いませんでした。かえって、すべてのことについて耐え忍んでいます。それは、キリストの福音に少しの妨げも与えまいとしてなのです。</span>
<span className="v" id="v13" data-v="13" data-xref="Numbers 18:8–20; Numbers 5:9–10; Leviticus 6:26"> あなたがたは、宮に奉仕している者が宮の物を食べ、祭壇に仕える者が祭壇の物にあずかることを知らないのですか。</span>
<span className="v" id="v14" data-v="14" data-xref="マタイの福音書 10:10; テモテへの手紙第一 5:17–18; コリント人への手紙第一 9:4"> 同じように、主も、福音を宣べ伝える者が、福音の働きから生活のささえを得るように定めておられます。</span>
<span className="v" id="v15" data-v="15" data-xref="テサロニケ人への手紙第一 2:9; テサロニケ人への手紙第二 3:8; コリント人への手紙第一 9:12"> しかし、私はこれらの権利を一つも用いませんでした。また、私は自分がそうされたくてこのように書いているのでもありません。私は自分の誇りをだれかに奪われるよりは、死んだほうがましだからです。</span>
<span className="v" id="v16" data-v="16" data-xref="ローマ人への手紙 1:14; Jeremiah 20:9; コロサイ人への手紙 4:17"> というのは、私が福音を宣べ伝えても、それは私の誇りにはなりません。そのことは、私がどうしても、しなければならないことだからです。もし福音を宣べ伝えなかったら、私はわざわいに会います。</span>
<span className="v" id="v17" data-v="17" data-xref="ガラテヤ人への手紙 2:7; コリント人への手紙第一 3:8; 1 Chronicles 28:9"> もし私がこれを自発的にしているのなら、報いがありましょう。しかし、強いられたにしても、私には務めがゆだねられているのです。</span>
<span className="v" id="v18" data-v="18" data-xref="コリント人への手紙第二 11:7–9; コリント人への手紙第一 8:9; テサロニケ人への手紙第一 2:6"> では、私にどんな報いがあるのでしょう。それは、福音を宣べ伝えるときに報酬を求めないで与え、福音の働きによって持つ自分の権利を十分に用いないことなのです。</span>
<span className="v" id="v19" data-v="19" data-xref="ガラテヤ人への手紙 5:13; マタイの福音書 18:15; ヤコブの手紙 5:19–20"> 私はだれに対しても自由ですが、より多くの人を獲得するために、すべての人の奴隷となりました。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒の働き 16:3; ガラテヤ人への手紙 5:18; 使徒の働き 21:20–26"> ユダヤ人にはユダヤ人のようになりました。それはユダヤ人を獲得するためです。律法の下にある人々には、私自身は律法の下にはいませんが、律法の下にある者のようになりました。それは律法の下にある人々を獲得するためです。</span>
<span className="v" id="v21" data-v="21" data-xref="ローマ人への手紙 2:12; ローマ人への手紙 2:14; ガラテヤ人への手紙 3:2"> 律法を持たない人々に対しては、――私は神の律法の外にある者ではなく、キリストの律法を守る者ですが、――律法を持たない者のようになりました。それは律法を持たない人々を獲得するためです。</span>
<span className="v" id="v22" data-v="22" data-xref="コリント人への手紙第一 10:33; ローマ人への手紙 15:1; コリント人への手紙第一 9:19"> 弱い人々には、弱い者になりました。弱い人々を獲得するためです。すべての人に、すべてのものとなりました。それは、何とかして、幾人かでも救うためです。</span>
<span className="v" id="v23" data-v="23" data-xref="テモテへの手紙第二 2:10; マルコの福音書 8:35; コリント人への手紙第一 9:25–27"> 私はすべてのことを、福音のためにしています。それは、私も福音の恵みをともに受ける者となるためなのです。</span>
<span className="v" id="v24" data-v="24" data-xref="ピリピ人への手紙 3:14; ヘブル人への手紙 12:1; テモテへの手紙第二 4:7–8"> 競技場で走る人たちは、みな走っても、賞を受けるのはただひとりだ、ということを知っているでしょう。ですから、あなたがたも、賞を受けられるように走りなさい。</span>
<span className="v" id="v25" data-v="25" data-xref="テモテへの手紙第二 2:5; ヨハネの黙示録 2:10; テモテへの手紙第二 4:7–8"> また闘技をする者は、あらゆることについて自制します。彼らは朽ちる冠を受けるためにそうするのですが、私たちは朽ちない冠を受けるためにそうするのです。</span>
<span className="v" id="v26" data-v="26" data-xref="ペテロの手紙第二 1:10; ピリピ人への手紙 1:21; テモテへの手紙第二 2:5"> ですから、私は決勝点がどこかわからないような走り方はしていません。空を打つような拳闘もしてはいません。</span>
<span className="v" id="v27" data-v="27" data-xref="ローマ人への手紙 8:13; コリント人への手紙第一 9:25; コロサイ人への手紙 3:5"> 私は自分のからだを打ちたたいて従わせます。それは、私がほかの人に宣べ伝えておきながら、自分自身が失格者になるようなことのないためです。</span>

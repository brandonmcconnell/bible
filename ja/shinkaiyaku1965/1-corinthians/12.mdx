<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="コリント人への手紙第一 12:4–11; コリント人への手紙第一 14:37; コリント人への手紙第一 14:1–18"> さて、兄弟たち。御霊の賜物についてですが、私はあなたがたに、ぜひ次のことを知っていていただきたいのです。</span>
<span className="v" id="v2" data-v="2" data-xref="ペテロの手紙第一 4:3; テサロニケ人への手紙第一 1:9; Psalms 115:5"> ご承知のように、あなたがたが異教徒であったときには、どう導かれたとしても、引かれて行った所は、ものを言わない偶像の所でした。</span>
<span className="v" id="v3" data-v="3" data-xref="ヨハネの手紙第一 4:2–3; マタイの福音書 16:16–17; ローマ人への手紙 10:9"> ですから、私は、あなたがたに次のことを教えておきます。神の御霊によって語る者はだれも、「イエスはのろわれよ。」と言わず、また、聖霊によるのでなければ、だれも、「イエスは主です。」と言うことはできません。</span>
<span className="v" id="v4" data-v="4" data-xref="ペテロの手紙第一 4:10; コリント人への手紙第一 12:28; ローマ人への手紙 12:4–6"> さて、御霊の賜物にはいろいろの種類がありますが、御霊は同じ御霊です。</span>
<span className="v" id="v5" data-v="5" data-xref="エペソ人への手紙 4:11–12; ローマ人への手紙 12:6–8; ローマ人への手紙 14:8–9"> 奉仕にはいろいろの種類がありますが、主は同じ主です。</span>
<span className="v" id="v6" data-v="6" data-xref="コリント人への手紙第一 3:7; コリント人への手紙第一 12:11; ヨハネの福音書 5:17"> 働きにはいろいろの種類がありますが、神はすべての人の中ですべての働きをなさる同じ神です。</span>
<span className="v" id="v7" data-v="7" data-xref="ペテロの手紙第一 4:10–11; ローマ人への手紙 12:6–8; コリント人への手紙第一 14:19"> しかし、みなの益となるために、おのおのに御霊の現われが与えられているのです。</span>
<span className="v" id="v8" data-v="8" data-xref="Proverbs 2:6; コリント人への手紙第一 2:6–10; Psalms 143:10"> ある人には御霊によって知恵のことばが与えられ、ほかの人には同じ御霊にかなう知識のことばが与えられ、</span>
<span className="v" id="v9" data-v="9" data-xref="ヤコブの手紙 5:14–15; コリント人への手紙第二 4:13; エペソ人への手紙 2:8"> またある人には同じ御霊による信仰が与えられ、ある人には同一の御霊によって、いやしの賜物が与えられ、</span>
<span className="v" id="v10" data-v="10" data-xref="コリント人への手紙第一 14:39; ヨハネの手紙第一 4:1; マルコの福音書 16:17"> ある人には奇蹟を行なう力、ある人には預言、ある人には霊を見分ける力、ある人には異言、ある人には異言を解き明かす力が与えられています。</span>
<span className="v" id="v11" data-v="11" data-xref="コリント人への手紙第一 12:4; ヘブル人への手紙 2:4; コリント人への手紙第二 10:13"> しかし、同一の御霊がこれらすべてのことをなさるのであって、みこころのままに、おのおのにそれぞれの賜物を分け与えてくださるのです。</span>
<span className="v" id="v12" data-v="12" data-xref="ローマ人への手紙 12:4–5; コロサイ人への手紙 3:15; コリント人への手紙第一 12:27"> ですから、ちょうど、からだが一つでも、それに多くの部分があり、からだの部分はたとい多くあっても、その全部が一つのからだであるように、キリストもそれと同様です。</span>
<span className="v" id="v13" data-v="13" data-xref="エペソ人への手紙 4:5; コロサイ人への手紙 3:11; ガラテヤ人への手紙 3:28"> なぜなら、私たちはみな、ユダヤ人もギリシヤ人も、奴隷も自由人も、一つのからだとなるように、一つの御霊によってバプテスマを受け、そしてすべての者が一つの御霊を飲む者とされたからです。</span>
<span className="v" id="v14" data-v="14" data-xref="コリント人への手紙第一 12:27–28; コリント人への手紙第一 12:12; エペソ人への手紙 4:25"> 確かに、からだはただ一つの器官ではなく、多くの器官から成っています。</span>
<span className="v" id="v15" data-v="15" data-xref="Judges 9:8–15; 2 Kings 14:9"> たとい、足が、「私は手ではないから、からだに属さない。」と言ったところで、そんなことでからだに属さなくなるわけではありません。</span>
<span className="v" id="v16" data-v="16" data-xref="ローマ人への手紙 12:3; コリント人への手紙第一 12:22; ピリピ人への手紙 2:3"> たとい、耳が、「私は目ではないから、からだに属さない。」と言ったところで、そんなことでからだに属さなくなるわけではありません。</span>
<span className="v" id="v17" data-v="17" data-xref="コリント人への手紙第一 12:21; Psalms 139:13–16; Proverbs 20:12"> もし、からだ全体が目であったら、どこで聞くのでしょう。もし、からだ全体が聞くところであったら、どこでかぐのでしょう。</span>
<span className="v" id="v18" data-v="18" data-xref="コリント人への手紙第一 12:28; ローマ人への手紙 12:3; コリント人への手紙第一 12:11"> しかしこのとおり、神はみこころに従って、からだの中にそれぞれの器官を備えてくださったのです。</span>
<span className="v" id="v19" data-v="19"> もし、全部がただ一つの器官であったら、からだはいったいどこにあるのでしょう。</span>
<span className="v" id="v20" data-v="20" data-xref="コリント人への手紙第一 12:14; コリント人への手紙第一 12:12"> しかしこういうわけで、器官は多くありますが、からだは一つなのです。</span>
<span className="v" id="v21" data-v="21" data-xref="Ezra 10:1–5; Nehemiah 4:16–21; Job 29:11"> そこで、目が手に向かって、「私はあなたを必要としない。」と言うことはできないし、頭が足に向かって、「私はあなたを必要としない。」と言うこともできません。</span>
<span className="v" id="v22" data-v="22" data-xref="Proverbs 14:28; Ecclesiastes 9:14–15; Ecclesiastes 4:9–12"> それどころか、からだの中で比較的に弱いと見られる器官が、かえってなくてはならないものなのです。</span>
<span className="v" id="v23" data-v="23" data-xref="Genesis 3:21; Genesis 3:7"> また、私たちは、からだの中で比較的に尊くないとみなす器官を、ことさらに尊びます。こうして、私たちの見ばえのしない器官は、ことさらに良いかっこうになりますが、</span>
<span className="v" id="v24" data-v="24" data-xref="Genesis 3:11; Genesis 2:25"> かっこうの良い器官にはその必要がありません。しかし神は、劣ったところをことさらに尊んで、からだをこのように調和させてくださったのです。</span>
<span className="v" id="v25" data-v="25" data-xref="コリント人への手紙第二 13:11; コリント人への手紙第一 1:10–12; ヨハネの福音書 17:21–26"> それは、からだの中に分裂がなく、各部分が互いにいたわり合うためです。</span>
<span className="v" id="v26" data-v="26" data-xref="ローマ人への手紙 12:15; ガラテヤ人への手紙 6:2; ヘブル人への手紙 13:3"> もし一つの部分が苦しめば、すべての部分がともに苦しみ、もし一つの部分が尊ばれれば、すべての部分がともに喜ぶのです。</span>
<span className="v" id="v27" data-v="27" data-xref="エペソ人への手紙 4:12; コロサイ人への手紙 1:24; エペソ人への手紙 5:30"> あなたがたはキリストのからだであって、ひとりひとりは各器官なのです。</span>
<span className="v" id="v28" data-v="28" data-xref="エペソ人への手紙 4:11–13; ローマ人への手紙 12:6–8; コリント人への手紙第一 12:18"> そして、神は教会の中で人々を次のように任命されました。すなわち、第一に使徒、次に預言者、次に教師、それから奇蹟を行なう者、それからいやしの賜物を持つ者、助ける者、治める者、異言を語る者などです。</span>
<span className="v" id="v29" data-v="29" data-xref="コリント人への手紙第一 12:4–11; コリント人への手紙第一 12:14–20"> みなが使徒でしょうか。みなが預言者でしょうか。みなが教師でしょうか。みなが奇蹟を行なう者でしょうか。</span>
<span className="v" id="v30" data-v="30" data-xref="コリント人への手紙第一 12:10"> みながいやしの賜物を持っているでしょうか。みなが異言を語るでしょうか。みなが解き明かしをするでしょうか。</span>
<span className="v" id="v31" data-v="31" data-xref="コリント人への手紙第一 13:1; コリント人への手紙第一 14:39; マタイの福音書 5:6"> あなたがたは、よりすぐれた賜物を熱心に求めなさい。 また私は、さらにまさる道を示してあげましょう。</span>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ガラテヤ人への手紙 1:6–12; ペテロの手紙第一 5:12; コリント人への手紙第一 15:3–11"> 兄弟たち。私は今、あなたがたに福音を知らせましょう。これは、私があなたがたに宣べ伝えたもので、あなたがたが受け入れ、また、それによって立っている福音です。</span>
<span className="v" id="v2" data-v="2" data-xref="ヘブル人への手紙 3:6; ヘブル人への手紙 2:1; ヘブル人への手紙 3:14"> また、もしあなたがたがよく考えもしないで信じたのでないなら、私の宣べ伝えたこの福音のことばをしっかりと保っていれば、この福音によって救われるのです。</span>
<span className="v" id="v3" data-v="3" data-xref="ペテロの手紙第一 2:24; ガラテヤ人への手紙 1:4; Isaiah 53:1–12"> 私があなたがたに最もたいせつなこととして伝えたのは、私も受けたことであって、次のことです。キリストは、聖書の示すとおりに、私たちの罪のために死なれたこと、</span>
<span className="v" id="v4" data-v="4" data-xref="Hosea 6:2; マタイの福音書 12:40; Psalms 16:10–11"> また、葬られたこと、また、聖書に従って三日目によみがえられたこと、</span>
<span className="v" id="v5" data-v="5" data-xref="マルコの福音書 16:14; コリント人への手紙第一 1:12; ヨハネの福音書 1:42"> また、ケパに現われ、それから十二弟子に現われたことです。</span>
<span className="v" id="v6" data-v="6" data-xref="マタイの福音書 28:10; マルコの福音書 16:7; 使徒の働き 13:36"> その後、キリストは五百人以上の兄弟たちに同時に現われました。その中の大多数の者は今なお生き残っていますが、すでに眠った者もいくらかいます。</span>
<span className="v" id="v7" data-v="7" data-xref="ルカの福音書 24:50; 使徒の働き 1:2–12; ルカの福音書 24:33"> その後、キリストはヤコブに現われ、それから使徒たち全部に現われました。</span>
<span className="v" id="v8" data-v="8" data-xref="コリント人への手紙第一 9:1; 使徒の働き 26:16; 使徒の働き 22:18"> そして、最後に、月足らずで生まれた者と同様な私にも、現われてくださいました。</span>
<span className="v" id="v9" data-v="9" data-xref="エペソ人への手紙 3:7–8; テモテへの手紙第一 1:13–15; 使徒の働き 8:3"> 私は使徒の中では最も小さい者であって、使徒と呼ばれる価値のない者です。なぜなら、私は神の教会を迫害したからです。</span>
<span className="v" id="v10" data-v="10" data-xref="ピリピ人への手紙 4:13; コリント人への手紙第二 3:5; ピリピ人への手紙 2:13"> ところが、神の恵みによって、私は今の私になりました。そして、私に対するこの神の恵みは、むだにはならず、私はほかのすべての使徒たちよりも多く働きました。しかし、それは私ではなく、私にある神の恵みです。</span>
<span className="v" id="v11" data-v="11" data-xref="コリント人への手紙第一 15:3–4; コリント人への手紙第一 2:2"> そういうわけですから、私にせよ、ほかの人たちにせよ、私たちはこのように宣べ伝えているのであり、あなたがたはこのように信じたのです。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒の働き 26:8; 使徒の働き 17:32; テモテへの手紙第二 2:18"> ところで、キリストは死者の中から復活された、と宣べ伝えられているのなら、どうして、あなたがたの中に、死者の復活はない、と言っている人がいるのですか。</span>
<span className="v" id="v13" data-v="13" data-xref="ヨハネの福音書 11:25–26; ローマ人への手紙 8:11; テサロニケ人への手紙第一 4:14"> もし、死者の復活がないのなら、キリストも復活されなかったでしょう。</span>
<span className="v" id="v14" data-v="14" data-xref="コリント人への手紙第一 15:17; テサロニケ人への手紙第一 4:14; ガラテヤ人への手紙 2:2"> そして、キリストが復活されなかったのなら、私たちの宣教は実質のないものになり、あなたがたの信仰も実質のないものになるのです。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒の働き 2:24; Job 13:7–10; 使徒の働き 2:32"> それどころか、私たちは神について偽証をした者ということになります。なぜなら、もしもかりに、死者の復活はないとしたら、神はキリストをよみがえらせなかったはずですが、私たちは神がキリストをよみがえらせた、と言って神に逆らう証言をしたからです。</span>
<span className="v" id="v16" data-v="16"> もし、死者がよみがえらないのなら、キリストもよみがえらなかったでしょう。</span>
<span className="v" id="v17" data-v="17" data-xref="ローマ人への手紙 4:25; ペテロの手紙第一 1:3; コリント人への手紙第一 15:14"> そして、もしキリストがよみがえらなかったのなら、あなたがたの信仰はむなしく、あなたがたは今もなお、自分の罪の中にいるのです。</span>
<span className="v" id="v18" data-v="18" data-xref="テサロニケ人への手紙第一 4:13–14; ヨハネの黙示録 14:13; テサロニケ人への手紙第一 4:16"> そうだったら、キリストにあって眠った者たちは、滅んでしまったのです。</span>
<span className="v" id="v19" data-v="19" data-xref="ペテロの手紙第一 1:21; ヨハネの黙示録 14:13; テモテへの手紙第二 1:12"> もし、私たちがこの世にあってキリストに単なる希望を置いているだけなら、私たちは、すべての人の中で一番哀れな者です。</span>
<span className="v" id="v20" data-v="20" data-xref="コリント人への手紙第一 15:23; 使徒の働き 26:23; ヨハネの黙示録 1:5"> しかし、今やキリストは、眠った者の初穂として死者の中からよみがえられました。</span>
<span className="v" id="v21" data-v="21" data-xref="ヨハネの福音書 11:25; ローマ人への手紙 5:12–17; コリント人への手紙第一 15:22"> というのは、死がひとりの人を通して来たように、死者の復活もひとりの人を通して来たからです。</span>
<span className="v" id="v22" data-v="22" data-xref="ローマ人への手紙 5:12–21; コリント人への手紙第一 15:45–49; ヨハネの福音書 5:21–29"> すなわち、アダムにあってすべての人が死んでいるように、キリストによってすべての人が生かされるからです。</span>
<span className="v" id="v23" data-v="23" data-xref="Isaiah 26:19; ガラテヤ人への手紙 3:29; コリント人への手紙第一 15:52"> しかし、おのおのにその順番があります。まず初穂であるキリスト、次にキリストの再臨のときキリストに属している者です。</span>
<span className="v" id="v24" data-v="24" data-xref="Daniel 7:27; Daniel 7:14; マタイの福音書 28:18"> それから終わりが来ます。そのとき、キリストはあらゆる支配と、あらゆる権威、権力を滅ぼし、国を父なる神にお渡しになります。</span>
<span className="v" id="v25" data-v="25" data-xref="ヘブル人への手紙 10:12–13; Psalms 110:1; マタイの福音書 22:44"> キリストの支配は、すべての敵をその足の下に置くまで、と定められているからです。</span>
<span className="v" id="v26" data-v="26" data-xref="テモテへの手紙第二 1:10; コリント人への手紙第一 15:55; ヨハネの黙示録 21:4"> 最後の敵である死も滅ぼされます。</span>
<span className="v" id="v27" data-v="27" data-xref="Psalms 8:6; ヘブル人への手紙 2:8; マタイの福音書 28:18"> 「彼は万物をその足の下に従わせた。」からです。ところで、万物が従わせられた、と言うとき、万物を従わせたその方がそれに含められていないことは明らかです。</span>
<span className="v" id="v28" data-v="28" data-xref="コロサイ人への手紙 3:11; コリント人への手紙第一 3:23; エペソ人への手紙 1:23"> しかし、万物が御子に従うとき、御子自身も、ご自分に万物を従わせた方に従われます。これは、神が、すべてにおいてすべてとなられるためです。</span>
<span className="v" id="v29" data-v="29" data-xref="ローマ人への手紙 6:3–4; コリント人への手紙第一 15:16; マタイの福音書 20:22"> もしこうでなかったら、死者のゆえにバプテスマを受ける人たちは、何のためにそうするのですか。もし、死者は決してよみがえらないのなら、なぜその人たちは、死者のゆえにバプテスマを受けるのですか。</span>
<span className="v" id="v30" data-v="30" data-xref="コリント人への手紙第二 6:9; ガラテヤ人への手紙 5:11; コリント人への手紙第二 4:7–12"> また、なぜ私たちもいつも危険にさらされているのでしょうか。</span>
<span className="v" id="v31" data-v="31" data-xref="コリント人への手紙第二 4:10–11; ローマ人への手紙 8:36; コリント人への手紙第一 4:9–13"> 兄弟たち。私にとって、毎日が死の連続です。これは、私たちの主キリスト・イエスにあってあなたがたを誇る私の誇りにかけて、誓って言えることです。</span>
<span className="v" id="v32" data-v="32" data-xref="Isaiah 22:13; Isaiah 56:12; ルカの福音書 12:19"> もし、私が人間的な動機から、エペソで獣と戦ったのなら、何の益があるでしょう。もし、死者の復活がないのなら、「あすは死ぬのだ。さあ、飲み食いしようではないか。」ということになるのです。</span>
<span className="v" id="v33" data-v="33" data-xref="Proverbs 13:20; マタイの福音書 24:4; コリント人への手紙第一 5:6"> 思い違いをしてはいけません。友だちが悪ければ、良い習慣がそこなわれます。</span>
<span className="v" id="v34" data-v="34" data-xref="コリント人への手紙第一 6:5; ローマ人への手紙 13:11; ヘブル人への手紙 5:11–12"> 目をさまして、正しい生活を送り、罪をやめなさい。神についての正しい知識を持っていない人たちがいます。私はあなたがたをはずかしめるために、こう言っているのです。</span>
<span className="v" id="v35" data-v="35" data-xref="Ezekiel 37:3; コリント人への手紙第一 15:38–53; ローマ人への手紙 9:19"> ところが、ある人はこう言うでしょう。「死者は、どのようにしてよみがえるのか。どのようなからだで来るのか。」</span>
<span className="v" id="v36" data-v="36" data-xref="ヨハネの福音書 12:24; ルカの福音書 11:40; エペソ人への手紙 5:15"> 愚かな人だ。あなたの蒔く物は、死ななければ、生かされません。</span>
<span className="v" id="v37" data-v="37"> あなたが蒔く物は、後にできるからだではなく、麦やそのほかの穀物の種粒です。</span>
<span className="v" id="v38" data-v="38" data-xref="コリント人への手紙第一 3:7; Isaiah 61:11; マルコの福音書 4:26–29"> しかし神は、みこころに従って、それにからだを与え、おのおのの種にそれぞれのからだをお与えになります。</span>
<span className="v" id="v39" data-v="39" data-xref="Genesis 1:20–26"> すべての肉が同じではなく、人間の肉もあり、獣の肉もあり、鳥の肉もあり、魚の肉もあります。</span>
<span className="v" id="v40" data-v="40"> また、天上のからだもあり、地上のからだもあり、天上のからだの栄光と地上のからだの栄光とは異なっており、</span>
<span className="v" id="v41" data-v="41" data-xref="Isaiah 24:23; Psalms 148:3–5; Deuteronomy 4:19"> 太陽の栄光もあり、月の栄光もあり、星の栄光もあります。個々の星によって栄光が違います。</span>
<span className="v" id="v42" data-v="42" data-xref="マタイの福音書 13:43; Daniel 12:3; ローマ人への手紙 8:21"> 死者の復活もこれと同じです。朽ちるもので蒔かれ、朽ちないものによみがえらされ、</span>
<span className="v" id="v43" data-v="43" data-xref="コリント人への手紙第一 6:14; コロサイ人への手紙 3:4; ピリピ人への手紙 3:20–21"> 卑しいもので蒔かれ、栄光あるものによみがえらされ、弱いもので蒔かれ、強いものによみがえらされ、</span>
<span className="v" id="v44" data-v="44" data-xref="コリント人への手紙第一 15:50; ルカの福音書 24:31; ヨハネの福音書 20:19"> 血肉のからだで蒔かれ、御霊に属するからだによみがえらされるのです。血肉のからだがあるのですから、御霊のからだもあるのです。</span>
<span className="v" id="v45" data-v="45" data-xref="ヨハネの福音書 5:21; Genesis 2:7; ローマ人への手紙 8:2"> 聖書に「最初の人アダムは生きた者となった。」と書いてありますが、最後のアダムは、生かす御霊となりました。</span>
<span className="v" id="v46" data-v="46" data-xref="コロサイ人への手紙 3:9–10; ローマ人への手紙 6:6; エペソ人への手紙 4:22–24"> 最初にあったのは血肉のものであり、御霊のものではありません。御霊のものはあとに来るのです。</span>
<span className="v" id="v47" data-v="47" data-xref="ヨハネの福音書 3:31; Genesis 2:7; Genesis 3:19"> 第一の人は地から出て、土で造られた者ですが、第二の人は天から出た者です。</span>
<span className="v" id="v48" data-v="48" data-xref="Genesis 5:3; ローマ人への手紙 5:12–21; ヨハネの福音書 3:6"> 土で造られた者はみな、この土で造られた者に似ており、天からの者はみな、この天から出た者に似ているのです。</span>
<span className="v" id="v49" data-v="49" data-xref="ローマ人への手紙 8:29; コリント人への手紙第二 3:18; Genesis 5:3"> 私たちは土で造られた者のかたちを持っていたように、天上のかたちをも持つのです。</span>
<span className="v" id="v50" data-v="50" data-xref="ヨハネの福音書 3:3–6; マタイの福音書 16:17; エペソ人への手紙 4:17"> 兄弟たちよ。私はこのことを言っておきます。血肉のからだは神の国を相続できません。朽ちるものは、朽ちないものを相続できません。</span>
<span className="v" id="v51" data-v="51" data-xref="テサロニケ人への手紙第一 4:14–17; ピリピ人への手紙 3:21; コリント人への手紙第一 15:20"> 聞きなさい。私はあなたがたに奥義を告げましょう。私たちはみなが眠ってしまうのではなく、みな変えられるのです。</span>
<span className="v" id="v52" data-v="52" data-xref="テサロニケ人への手紙第一 4:16–17; マタイの福音書 24:31; ヨハネの福音書 5:28"> 終わりのラッパとともに、たちまち、一瞬のうちにです。ラッパが鳴ると、死者は朽ちないものによみがえり、私たちは変えられるのです。</span>
<span className="v" id="v53" data-v="53" data-xref="コリント人への手紙第二 5:2–4; ヨハネの手紙第一 3:2; ローマ人への手紙 2:7"> 朽ちるものは、必ず朽ちないものを着なければならず、死ぬものは、必ず不死を着なければならないからです。</span>
<span className="v" id="v54" data-v="54" data-xref="Isaiah 25:8; ヨハネの黙示録 20:14; ヘブル人への手紙 2:14–15"> しかし、朽ちるものが朽ちないものを着、死ぬものが不死を着るとき、「死は勝利にのまれた。」としるされている、みことばが実現します。</span>
<span className="v" id="v55" data-v="55" data-xref="Hosea 13:14; Psalms 89:48; 使徒の働き 2:27"> 「死よ。おまえの勝利はどこにあるのか。死よ。おまえのとげはどこにあるのか。」</span>
<span className="v" id="v56" data-v="56" data-xref="ローマ人への手紙 4:15; ガラテヤ人への手紙 3:10–13; ローマ人への手紙 7:5–13"> 死のとげは罪であり、罪の力は律法です。</span>
<span className="v" id="v57" data-v="57" data-xref="コリント人への手紙第二 2:14; ローマ人への手紙 8:37; ヨハネの手紙第一 5:4–5"> しかし、神に感謝すべきです。神は、私たちの主イエス・キリストによって、私たちに勝利を与えてくださいました。</span>
<span className="v" id="v58" data-v="58" data-xref="ガラテヤ人への手紙 6:9; 2 Chronicles 15:7; ヘブル人への手紙 6:10"> ですから、私の愛する兄弟たちよ。堅く立って、動かされることなく、いつも主のわざに励みなさい。あなたがたは自分たちの労苦が、主にあってむだでないことを知っているのですから。</span>

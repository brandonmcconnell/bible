<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="コリント人への手紙第一 1:17; コリント人への手紙第一 2:13; コリント人への手紙第一 2:4"> さて兄弟たち。私があなたがたのところへ行ったとき、私は、すぐれたことば、すぐれた知恵を用いて、神のあかしを宣べ伝えることはしませんでした。</span>
<span className="v" id="v2" data-v="2" data-xref="ガラテヤ人への手紙 6:14; ヨハネの福音書 17:3; コリント人への手紙第一 1:22–25"> なぜなら私は、あなたがたの間で、イエス・キリスト、すなわち十字架につけられた方のほかは、何も知らないことに決心したからです。</span>
<span className="v" id="v3" data-v="3" data-xref="コリント人への手紙第二 13:4; コリント人への手紙第一 4:10–13; コリント人への手紙第二 12:5–10"> あなたがたといっしょにいたときの私は、弱く、恐れおののいていました。</span>
<span className="v" id="v4" data-v="4" data-xref="コリント人への手紙第一 4:20; テサロニケ人への手紙第一 1:5; コリント人への手紙第一 1:17"> そして、私のことばと私の宣教とは、説得力のある知恵のことばによって行なわれたものではなく、御霊と御力の現われでした。</span>
<span className="v" id="v5" data-v="5" data-xref="コリント人への手紙第二 4:7; コリント人への手紙第二 12:9; コリント人への手紙第二 6:7"> それは、あなたがたの持つ信仰が、人間の知恵にささえられず、神の力にささえられるためでした。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="ヘブル人への手紙 5:14; ヤコブの手紙 3:15; コリント人への手紙第二 4:4"> しかし私たちは、成人の間で、知恵を語ります。この知恵は、この世の知恵でもなく、この世の過ぎ去って行く支配者たちの知恵でもありません。</span>
<span className="v" id="v7" data-v="7" data-xref="コロサイ人への手紙 1:26–27; ペテロの手紙第二 1:3; マタイの福音書 11:25"> 私たちの語るのは、隠された奥義としての神の知恵であって、それは、神が、私たちの栄光のために、世界の始まる前から、あらかじめ定められたものです。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒の働き 13:27; ヤコブの手紙 2:1; 使徒の働き 7:2"> この知恵を、この世の支配者たちは、だれひとりとして悟りませんでした。もし悟っていたら、栄光の主を十字架につけはしなかったでしょう。</span>
<span className="v" id="v9" data-v="9" data-xref="Isaiah 64:4; Psalms 31:19; ヤコブの手紙 1:12"> まさしく、聖書に書いてあるとおりです。<br />「目が見たことのないもの、<br />耳が聞いたことのないもの、<br />そして、人の心に思い浮かんだことのないもの。<br />神を愛する者のために、<br />神の備えてくださったものは、みなそうである。」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="ヨハネの福音書 14:26; エペソ人への手紙 3:5; ルカの福音書 10:21"> 神はこれを、御霊によって私たちに啓示されたのです。御霊はすべてのことを探り、神の深みにまで及ばれるからです。</span>
<span className="v" id="v11" data-v="11" data-xref="Proverbs 20:27; コリント人への手紙第一 2:10; ローマ人への手紙 11:33–34"> いったい、人の心のことは、その人のうちにある霊のほかに、だれが知っているでしょう。同じように、神のみこころのことは、神の御霊のほかにはだれも知りません。</span>
<span className="v" id="v12" data-v="12" data-xref="ヨハネの手紙第一 2:27; ローマ人への手紙 8:5–6; ヨハネの手紙第一 2:20"> ところで、私たちは、この世の霊を受けたのではなく、神の御霊を受けました。それは、恵みによって神から私たちに賜わったものを、私たちが知るためです。</span>
<span className="v" id="v13" data-v="13" data-xref="コリント人への手紙第一 2:4; コリント人への手紙第一 2:14; コリント人への手紙第一 1:17"> この賜物について話すには、人の知恵に教えられたことばを用いず、御霊に教えられたことばを用います。その御霊のことばをもって御霊のことを解くのです。</span>
<span className="v" id="v14" data-v="14" data-xref="コリント人への手紙第一 1:18; ローマ人への手紙 8:5–8; マタイの福音書 13:11–17"> 生まれながらの人間は、神の御霊に属することを受け入れません。それらは彼には愚かなことだからです。また、それを悟ることができません。なぜなら、御霊のことは御霊によってわきまえるものだからです。</span>
<span className="v" id="v15" data-v="15" data-xref="テサロニケ人への手紙第一 5:21; Proverbs 28:5; ヘブル人への手紙 5:14"> 御霊を受けている人は、すべてのことをわきまえますが、自分はだれによってもわきまえられません。</span>
<span className="v" id="v16" data-v="16" data-xref="Isaiah 40:13–14; ローマ人への手紙 11:34; ヨハネの福音書 16:13–16"> いったい、「だれが主のみこころを知り、主を導くことができたか。」ところが、私たちには、キリストの心があるのです。</span>
</div>

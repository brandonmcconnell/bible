<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨシュア記 23:2; サムエル記第一 10:19; 創世記 33:18–19"> ヨシュアはイスラエルの全部族をシェケムに集め、イスラエルの長老、かしら、裁き人、役人を呼び寄せた。彼らは神の前に進み出た。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨシュア記 24:15; エゼキエル書 16:3; 創世記 31:30"> ヨシュアは民すべてに言った。「イスラエルの神、主はこう言われる。『昔、あなたがたの父祖たち、すなわちアブラハムとナホルの父テラは、大河の向こうに住み、他の神々に仕えていた。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 12:1–4; 創世記 21:2–3; 使徒の働き 7:2–3"> わたしはあなたがたの父アブラハムを大河の向こうから連れ出し、カナンの全土を巡らせ、その子孫<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="または「種」。">a</a></sup>を増やし、イサクを与えた。</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 36:8; 申命記 2:5; 創世記 25:24–26"> わたしはイサクにヤコブとエサウを与えた。わたしはエサウにセイル山を与えてそれを所有させた。ヤコブとその子らはエジプトへ下って行った。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="出エジプト記 3:10; 出エジプト記 7:1–12; 詩篇 105:26–36"> わたしはモーセとアロンを遣わし、また彼らの間で行ったことによってエジプトに災いを下した。その後、わたしはあなたがたを導き出した。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒の働き 7:36; ヘブル人への手紙 11:29; イザヤ書 63:12–13"> わたしがあなたがたの父祖たちをエジプトから導き出すと、あなたがたは海に来た。エジプト人は戦車と騎兵をもって、あなたがたの父祖たちを紅海まで追跡した。</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 4:34; 出エジプト記 14:10; 出エジプト記 14:20"> 彼らが主に向かって叫び求めると、主はあなたがたとエジプト人との間に暗闇を置き、海を彼らの上に引き寄せて彼らを覆われた。あなたがたの目は、わたしがエジプトで行ったことを見た。あなたがたは長い間、荒野に住んだ。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="民数記 21:21–35; 詩篇 135:10–11; ネヘミヤ記 9:22"> わたしは、ヨルダン川の向こうに住んでいたアモリ人の地にあなたがたを導き入れた。彼らはあなたがたと戦ったが、わたしは彼らをあなたがたの手に渡した。あなたがたは彼らの地を所有し、わたしは彼らをあなたがたの前から滅ぼした。</span>
<span className="v" id="v9" data-v="9" data-xref="士師記 11:25; ミカ書 6:5; 民数記 22:2"> それから、モアブの王、ツィポルの子バラクが立ち上がり、イスラエルと戦った。彼は人を遣わしてベオルの子バラムを呼び、あなたがたをのろわせようとした。</span>
<span className="v" id="v10" data-v="10" data-xref="申命記 23:5; 民数記 24:5–10; イザヤ書 54:17"> しかし、わたしはバラムに聞き従わなかった。それで彼は、かえってあなたがたを祝福した。こうしてわたしは、あなたがたを彼の手から救い出した。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="ヨシュア記 4:10–12; ヨシュア記 3:14–17; 詩篇 114:5"> あなたがたはヨルダン川を渡り、エリコに来た。エリコの人々、すなわちアモリ人、ペリジ人、カナン人、ヘト人、ギルガシ人、ヒビ人、およびエブス人はあなたがたと戦ったが、わたしは彼らをあなたがたの手に渡した。</span>
<span className="v" id="v12" data-v="12" data-xref="申命記 7:20; 出エジプト記 23:28; 詩篇 44:3–6"> わたしはあなたがたの前にスズメバチを送り、それが彼らを、すなわちアモリ人の二人の王をあなたがたの前から追い出したのであり、あなたがたの剣や弓によるのではなかった。</span>
<span className="v" id="v13" data-v="13" data-xref="申命記 6:10–12; 申命記 8:7; ヨシュア記 21:45"> わたしは、あなたがたが労しなかった地、建てなかった町々を与えた。あなたがたはそこに住み、自分で植えなかったぶどう畑とオリーブ畑の実を食べている。』</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="サムエル記第一 12:24; 申命記 10:12; 創世記 35:2"> それゆえ今、主を恐れ、誠実と真実をもって主に仕えなさい。父祖たちが大河の向こうやエジプトで仕えていた神々を取り除き、主に仕えなさい。</span>
<span className="v" id="v15" data-v="15" data-xref="列王記第一 18:21; ヨハネ 6:67–68; ルツ記 1:15–16"> 主に仕えることがあなたがたの目に悪いなら、父祖たちが大河の向こうで仕えていた神々であれ、今住んでいる地のアモリ人の神々であれ、だれに仕えるかを今日選びなさい。しかし、私と私の家は主に仕える。」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="ヘブル人への手紙 10:38–39; サムエル記第一 12:23; ローマ人への手紙 6:2"> 民は答えた。「私たちが主を捨て、他の神々に仕えることなど、決してありません。</span>
<span className="v" id="v17" data-v="17" data-xref="出エジプト記 19:4; イザヤ書 63:7–14; イザヤ書 46:4"> 私たちの神、主ご自身が、私たちと父祖たちをエジプトの地、奴隷の家から導き上げ、目の前で大きなしるしを行い、歩んだすべての道と、通り抜けたすべての民の中で守ってくださったからです。</span>
<span className="v" id="v18" data-v="18" data-xref="ミカ書 4:2; 出エジプト記 10:2; 詩篇 116:16"> 主は、すべての国々の民、すなわちこの地に住んでいたアモリ人を私たちの前から追い出されました。それゆえ、私たちもまた主に仕えます。主が私たちの神だからです。」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="イザヤ書 5:16; 出エジプト記 23:21; 詩篇 99:9"> ヨシュアは民に言った。「あなたがたは主に仕えることができない。主は聖なる神、ねたむ神であり、あなたがたの背きと罪を赦されない。</span>
<span className="v" id="v20" data-v="20" data-xref="ヘブル人への手紙 10:26–27; エゼキエル書 18:24; 歴代誌上 28:9"> もしあなたがたが主を捨てて外国の神々に仕えるなら、主があなたがたに良いことをしてくださった後であっても、主は身を翻してあなたがたに災いを下し、あなたがたを滅ぼし尽くされるであろう。」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="出エジプト記 20:19; イザヤ書 44:5; 申命記 5:27–28"> 民はヨシュアに言った。「いいえ、私たちは主に仕えます。」</span>
<span className="v" id="v22" data-v="22" data-xref="詩篇 119:173; 詩篇 119:11; ヨブ記 15:6"> ヨシュアは民に言った。「あなたがたは、自ら主を選んで仕えることの証人である。」<br />彼らは答えた。「私たちは証人です。」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="コリント人への第二の手紙 6:16–18; ヨシュア記 24:14; ヘブル人への手紙 12:28–29"> 「それゆえ今、あなたがたの中にある外国の神々を除き去り、イスラエルの神、主にあなたがたの心を向けなさい。」</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="出エジプト記 24:7; 出エジプト記 24:3; 申命記 5:27–29"> 民はヨシュアに言った。「私たちは私たちの神、主に仕え、その御声に聞き従います。」</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="ネヘミヤ記 9:38; 歴代誌 第二 23:16; 出エジプト記 15:25"> その日、ヨシュアは民と契約を結び、シェケムで彼らのために掟と定めを設けた。</span>
<span className="v" id="v26" data-v="26" data-xref="士師記 9:6; 創世記 35:4; ヨシュア記 4:20–24"> ヨシュアはこれらの言葉を神の律法の書に書き記した。そして大きな石を取り、主の聖所のかたわらにある樫の木の下にそれを立てた。</span>
<span className="v" id="v27" data-v="27" data-xref="ルカ 19:40; ヨシュア記 22:34; ヨシュア記 22:27–28"> ヨシュアは民すべてに言った。「見よ、この石は私たちに対する証しとなる。主が私たちに語られたすべての言葉を聞いたからである。あなたがたが自分の神を否むことのないよう、この石が証しとなる。」</span>
<span className="v" id="v28" data-v="28" data-xref="士師記 2:6"> こうしてヨシュアは民を、それぞれ自分の相続地へと去らせた。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="士師記 2:8; テモテへの第二の手紙 4:7–8; 申命記 34:5"> これらのことの後、主のしもべ、ヌンの子ヨシュアは死んだ。百十歳であった。</span>
<span className="v" id="v30" data-v="30" data-xref="ヨシュア記 19:50; 士師記 2:9; サムエル記第二 23:30"> 人々は、エフライムの山地、ガアシュ山の北にあるティムナト・セラにある彼の相続地の境に彼を葬った。</span>
<span className="v" id="v31" data-v="31" data-xref="士師記 2:7; 申命記 31:13; 申命記 11:2"> イスラエルは、ヨシュアの生涯と、ヨシュアより長く生き、主がイスラエルのために行われたすべての御業を知っていた長老たちの生涯の間、主に仕えた。</span>
<span className="v" id="v32" data-v="32" data-xref="創世記 50:25; 創世記 33:19; 出エジプト記 13:19"> イスラエルの人々がエジプトから携え上ったヨセフの骨は、シェケムに葬られた。そこは、ヤコブがシェケムの父ハモルの子らから銀百ケシタ<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="ヘブル語は「ケシタ」。古代の銀の貨幣単位の一つ。">b</a></sup>で買い取った野の一部であり、ヨセフの子らの相続地となった。</span>
<span className="v" id="v33" data-v="33" data-xref="ヨシュア記 22:13; 出エジプト記 6:25; イザヤ書 57:1–2"> アロンの子エルアザルも死んだ。人々は、エフライムの山地で彼の子ピネハスに与えられていた、ピネハスの丘に彼を葬った。</span>
</div>
</div>

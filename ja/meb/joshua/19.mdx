<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨシュア記 19:9; 創世記 49:5–7; ヨシュア記 18:6–11"> 第二のくじはシメオン、すなわちシメオンの子らの部族のために、その氏族に従って引かれた。彼らの相続地はユダの子らの相続地の中にあった。</span>
<span className="v" id="v2" data-v="2" data-xref="歴代誌上 4:28–30; ネヘミヤ記 11:26–30; 創世記 21:31"> 彼らは相続地として、ベエル・シェバ、すなわちシェバ、モラダ、</span>
<span className="v" id="v3" data-v="3" data-xref="ヨシュア記 15:28–29"> ハツァル・シュアル、バラ、エツェム、</span>
<span className="v" id="v4" data-v="4" data-xref="ヨシュア記 15:30; 士師記 1:17"> エルトラド、ベトゥル、ホルマ、</span>
<span className="v" id="v5" data-v="5" data-xref="サムエル記第一 30:1; 歴代誌上 4:31; ヨシュア記 15:31"> ツィクラグ、ベテ・マルカボト、ハツァル・スサ、</span>
<span className="v" id="v6" data-v="6" data-xref="ヨシュア記 15:32"> ベテ・レバオト、シャルヘン。十三の町と、その村々を持った。</span>
<span className="v" id="v7" data-v="7" data-xref="ヨシュア記 15:42; ヨシュア記 15:32; 民数記 33:19–20"> アイン、リモン、エテル、アシャン。四つの町と、その村々。</span>
<span className="v" id="v8" data-v="8" data-xref="歴代誌上 4:33; サムエル記第一 30:27"> また、南のラマであるバアラト・ベエルに至るまで、これらの町の周囲にあるすべての村々。これがその氏族に従ったシメオンの子らの部族の相続地である。</span>
<span className="v" id="v9" data-v="9" data-xref="コリント人への第二の手紙 8:14–15; 出エジプト記 16:18"> シメオンの子らの相続地は、ユダの子らの分け前から取られた。ユダの子らの分け前は彼らにとって多すぎたからである。それゆえ、シメオンの子らはユダの相続地の中に相続地を持った。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="ヨシュア記 18:11; ヨシュア記 18:6; 創世記 49:13"> 第三のくじはゼブルンの子らのために、その氏族に従って引かれた。彼らの相続地の境界はサリドに至る。</span>
<span className="v" id="v11" data-v="11" data-xref="ヨシュア記 12:22; 歴代誌上 6:68; 列王記第一 4:12"> 彼らの境界は西へ、すなわちマララへ上り、ダベシェトに達する。さらにヨクネアムの前にある川に達する。</span>
<span className="v" id="v12" data-v="12" data-xref="士師記 4:6; 歴代誌上 6:72; ヨシュア記 19:22"> サリドから東のほう、東へ曲がり、キスロト・タボルの境界に向かう。そしてダベラトへ出て、ヤフィアへ上る。</span>
<span className="v" id="v13" data-v="13" data-xref="列王記第二 14:25"> そこから東のほうへ進んでガテ・ヘフェル、エト・カツィンに至り、ネアへと延びるリモンへ出る。</span>
<span className="v" id="v14" data-v="14"> 境界は北のほうハナトンへ回り込み、イフタ・エルの谷で終わる。</span>
<span className="v" id="v15" data-v="15" data-xref="ヨシュア記 11:1; ルツ記 1:19; サムエル記第二 23:15"> また、カタト、ナハラル、シムロン、イダラ、ベツレヘム。十二の町と、その村々。</span>
<span className="v" id="v16" data-v="16"> これがその氏族に従ったゼブルンの子らの相続地であり、これらの町とその村々である。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17"> 第四のくじはイッサカル、すなわちイッサカルの子らのために、その氏族に従って引かれた。</span>
<span className="v" id="v18" data-v="18" data-xref="サムエル記第一 28:4; 列王記第二 4:8; ホセア書 1:4–5"> 彼らの境界はイズレエル、ケスロト、シュネム、</span>
<span className="v" id="v19" data-v="19"> ハファライム、シオン、アナハラト、</span>
<span className="v" id="v20" data-v="20"> ラビト、キシュヨン、エベツ、</span>
<span className="v" id="v21" data-v="21" data-xref="ヨシュア記 21:29"> レメト、エン・ガニム、エン・ハダ、ベテ・パツェツに至る。</span>
<span className="v" id="v22" data-v="22" data-xref="士師記 4:6; 歴代誌上 6:77; ヨシュア記 19:38"> 境界はタボル、シャハツマ、ベテ・シェメシュに達する。彼らの境界はヨルダン川で終わる。十六の町と、その村々。</span>
<span className="v" id="v23" data-v="23"> これがその氏族に従ったイッサカルの子らの部族の相続地であり、町々とその村々である。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="ルカ 2:26–38"> 第五のくじはアシェルの子らの部族のために、その氏族に従って引かれた。</span>
<span className="v" id="v25" data-v="25" data-xref="ヨシュア記 12:20; ヨシュア記 11:1; サムエル記第二 2:16"> 彼らの境界はヘルカト、ハリ、ベテン、アクシャフ、</span>
<span className="v" id="v26" data-v="26" data-xref="雅歌 7:5; 列王記第一 18:42; イザヤ書 33:9"> アラメレク、アマド、ミシャルであった。それは西のほうではカルメルに達し、シホル・リブナトに達する。</span>
<span className="v" id="v27" data-v="27" data-xref="列王記第一 9:13; サムエル記第一 5:2"> 境界は東へ曲がってベテ・ダゴンに向かい、ゼブルンと、北のほうのイフタ・エルの谷に達し、ベテ・エメクとネイエルに至る。そして左手のほうのカブルへ出る。</span>
<span className="v" id="v28" data-v="28" data-xref="士師記 1:31; ヨシュア記 11:8; イザヤ書 23:12"> さらにエブロン、レホブ、ハモン、カナを経て、大シドンに至る。</span>
<span className="v" id="v29" data-v="29" data-xref="士師記 1:31; サムエル記第二 5:11; ミカ書 1:14"> 境界はラマへ曲がり、要塞の町ツロに向かう。さらに境界はホサへ曲がり、アクジブの地方を通って海で終わる。</span>
<span className="v" id="v30" data-v="30" data-xref="ヨシュア記 21:31; 列王記第一 20:30; サムエル記第一 4:1"> またウンマ、アフェク、レホブ。二十二の町と、その村々。</span>
<span className="v" id="v31" data-v="31" data-xref="申命記 33:24–25; 創世記 49:20"> これがその氏族に従ったアシェルの子らの部族の相続地であり、これらの町とその村々である。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32"> 第六のくじはナフタリの子らのために、その氏族に従って引かれた。</span>
<span className="v" id="v33" data-v="33" data-xref="士師記 4:11"> 彼らの境界はヘレフ、ツァアナニムの樫の木、アダミ・ネケブ、ヤブネエルから始まり、ラクムに至る。そしてヨルダン川で終わる。</span>
<span className="v" id="v34" data-v="34" data-xref="申命記 33:23; ヨシュア記 19:12; ヨシュア記 19:22"> 境界は西へ曲がってアズノト・タボルに向かい、そこからフコクへ出る。南はゼブルンに達し、西はアシェルに達し、東側のヨルダン川ではユダに達する。</span>
<span className="v" id="v35" data-v="35" data-xref="ヨシュア記 11:2; 列王記第一 8:65; 創世記 10:18"> その要塞の町々は、ツィディム、ツェル、ハマト、ラカト、キネレト、</span>
<span className="v" id="v36" data-v="36" data-xref="ヨシュア記 11:1; ヨシュア記 11:20; ヨシュア記 12:19"> アダマ、ラマ、ハツォル、</span>
<span className="v" id="v37" data-v="37" data-xref="ヨシュア記 20:7; ヨシュア記 12:22"> ケデシュ、エドレイ、エン・ハツォル、</span>
<span className="v" id="v38" data-v="38"> イロン、ミグダル・エル、ホレム、ベテ・アナト、ベテ・シェメシュ。十九の町と、その村々。</span>
<span className="v" id="v39" data-v="39"> これがその氏族に従ったナフタリの子らの部族の相続地であり、町々とその村々である。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40"> 第七のくじはダンの子らの部族のために、その氏族に従って引かれた。</span>
<span className="v" id="v41" data-v="41" data-xref="歴代誌上 2:53; ヨシュア記 15:33; 士師記 13:25"> 彼らの相続地の境界はツォルア、エシュタオル、イル・シェメシュ、</span>
<span className="v" id="v42" data-v="42" data-xref="士師記 1:35; ヨシュア記 10:12; ヨシュア記 21:24"> シャアラビン、アヤロン、イトラ、</span>
<span className="v" id="v43" data-v="43" data-xref="創世記 38:12; サムエル記第一 5:10; 士師記 14:1–2"> エロン、ティムナ、エクロン、</span>
<span className="v" id="v44" data-v="44" data-xref="列王記第一 15:27; 列王記第一 16:15; 列王記第一 9:18"> エルテケ、ギベトン、バアラト、</span>
<span className="v" id="v45" data-v="45" data-xref="ヨシュア記 21:24"> エフド、ベネ・ベラク、ガテ・リモン、</span>
<span className="v" id="v46" data-v="46" data-xref="ヨナ書 1:3; 使徒の働き 9:36; 歴代誌 第二 2:16"> メ・ヤルコン、ラコンであり、ヨッパの向かいの境界も含んでいた。</span>
<span className="v" id="v47" data-v="47" data-xref="士師記 1:34–35; 士師記 18:1–29"> ダンの子らの境界は彼らのところからさらに延びた。ダンの子らは上って行ってレシェムと戦い、それを占領し、剣の刃で打ち、それを所有してそこに住んだからである。彼らはレシェムを、自分たちの父祖ダンの名にちなんでダンと呼んだ。</span>
<span className="v" id="v48" data-v="48"> これがその氏族に従ったダンの子らの部族の相続地であり、これらの町とその村々である。</span>
</div>
<div className="bp">
<span className="v" id="v49" data-v="49" data-xref="エゼキエル書 45:7–8"> こうして彼らは、境界に従って地を相続地として分け終えた。イスラエルの人々は、自分たちの中にヌンの子ヨシュアの相続地を与えた。</span>
<span className="v" id="v50" data-v="50" data-xref="ヨシュア記 24:30; 士師記 2:9; 歴代誌上 7:24"> 主の命令に従って、彼らは彼が求めた町、すなわちエフライムの山地にあるティムナト・セラを彼に与えた。彼はその町を建て、そこに住んだ。</span>
<span className="v" id="v51" data-v="51" data-xref="ヨシュア記 18:10; ヨシュア記 14:1; ヨシュア記 18:1"> これらは、祭司エルアザル、ヌンの子ヨシュア、イスラエルの人々の部族の父祖の家のかしらたちが、シロの会見の天幕の入口で、主の御前にくじを引いて分けた相続地である。こうして地の分配を終えた。</span>
</div>

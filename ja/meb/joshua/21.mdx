<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨシュア記 14:1; ヨシュア記 19:51; ヨシュア記 17:4"> その時、レビ人の父祖の家のかしらたちは、祭司エルアザル、ヌンの子ヨシュア、およびイスラエルの人々の部族の父祖の家のかしらたちのところに近づき、</span>
<span className="v" id="v2" data-v="2" data-xref="ヨシュア記 18:1; 民数記 35:2–8; マタイ 10:10"> 彼らはカナンの地のシロで言った。「主はモーセを通して、私たちに住む町々と、家畜のための放牧地を与えるよう命じられました。」</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="創世記 49:7; 申命記 33:8–10; 歴代誌上 6:54–81"> そこでイスラエルの人々は、主の命令に従い、自分たちの相続地の中から、これらの町とその放牧地をレビ人に与えた。</span>
<span className="v" id="v4" data-v="4" data-xref="歴代誌上 6:54–60; ヨシュア記 24:33; ヨシュア記 21:8–19"> くじはケハテ人の氏族のために出た。レビ人のうち祭司アロンの子らには、ユダの部族、シメオン人の部族、ベニヤミンの部族の中から、くじによって十三の町が与えられた。</span>
<span className="v" id="v5" data-v="5" data-xref="ヨシュア記 21:20–26; 出エジプト記 6:16–25; 歴代誌上 6:66–70"> ケハテの残りの子らには、エフライムの部族の氏族、ダンの部族、マナセの半部族の中から、くじによって十の町が与えられた。</span>
<span className="v" id="v6" data-v="6" data-xref="ヨシュア記 21:27–33; 歴代誌上 6:71–76; 出エジプト記 6:16–17"> ゲルションの子らには、イッサカルの部族の氏族、アシェルの部族、ナフタリの部族、バシャンにあるマナセの半部族の中から、くじによって十三の町が与えられた。</span>
<span className="v" id="v7" data-v="7" data-xref="ヨシュア記 21:34–40; 歴代誌上 6:77–81; 出エジプト記 6:19"> メラリの子らには、その氏族に従って、ルベンの部族、ガドの部族、ゼブルンの部族の中から十二の町が与えられた。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨシュア記 21:3; ヨシュア記 18:6; 民数記 33:54"> イスラエルの人々は、モーセを通して主が命じられたように、これらの町とその放牧地をくじによってレビ人に与えた。</span>
<span className="v" id="v9" data-v="9" data-xref="歴代誌上 6:65; ヨシュア記 21:13–18"> 彼らはユダの子らの部族とシメオンの子らの部族の中から、名を挙げて記されるこれらの町を与えた。</span>
<span className="v" id="v10" data-v="10" data-xref="ヨシュア記 21:4; 民数記 3:27; 出エジプト記 6:20–26"> それらはレビの子らのうちケハテ人の氏族に属するアロンの子らのものとなった。最初のくじは彼らのものだったからである。</span>
<span className="v" id="v11" data-v="11" data-xref="歴代誌上 6:55; ルカ 1:39; サムエル記第二 5:1–5"> 彼らはユダの山地にある、アナクの父アルバにちなんで名付けられたキルヤテ・アルバ、すなわちヘブロンと、その周囲の放牧地を彼らに与えた。</span>
<span className="v" id="v12" data-v="12" data-xref="ヨシュア記 14:13–15; 歴代誌上 6:55–57"> しかし、その町の畑とその村々は、エフネの子カレブに彼の相続地として与えられた。</span>
<span className="v" id="v13" data-v="13" data-xref="ヨシュア記 15:42; ヨシュア記 10:29; ヨシュア記 15:54"> 彼らは祭司アロンの子らに、人を殺した者のための逃れの町であるヘブロンとその放牧地を与え、またリブナとその放牧地、</span>
<span className="v" id="v14" data-v="14" data-xref="ヨシュア記 15:48; ヨシュア記 15:50; サムエル記第一 30:27–28"> ヤティルとその放牧地、エシュテモアとその放牧地、</span>
<span className="v" id="v15" data-v="15" data-xref="ヨシュア記 15:49; ヨシュア記 15:51; ヨシュア記 12:13"> ホロンとその放牧地、デビルとその放牧地、</span>
<span className="v" id="v16" data-v="16" data-xref="ヨシュア記 15:10; 歴代誌上 6:59; ヨシュア記 15:55"> アインとその放牧地、ユタとその放牧地、ベテ・シェメシュとその放牧地を与えた。これら二つの部族から九つの町である。</span>
<span className="v" id="v17" data-v="17" data-xref="ヨシュア記 18:24–25; ヨシュア記 9:3; 歴代誌上 6:60"> ベニヤミンの部族からは、ギベオンとその放牧地、ゲバとその放牧地、</span>
<span className="v" id="v18" data-v="18" data-xref="イザヤ書 10:30; 歴代誌上 6:60; エレミヤ書 1:1"> アナトテとその放牧地、アルモンとその放牧地。四つの町である。</span>
<span className="v" id="v19" data-v="19"> 祭司であるアロンの子らの町は、すべてで十三の町とその放牧地であった。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="歴代誌上 6:66; ヨシュア記 21:5"> レビ人であるケハテの子らの諸氏族、すなわち残りのケハテの子らは、くじによってエフライムの部族から町々を得た。</span>
<span className="v" id="v21" data-v="21" data-xref="ヨシュア記 20:7; 士師記 9:1; 列王記第一 12:1"> 彼らはエフライムの山地にある、人を殺した者のための逃れの町であるシェケムとその放牧地を彼らに与え、またゲゼルとその放牧地、</span>
<span className="v" id="v22" data-v="22" data-xref="歴代誌上 6:68; ヨシュア記 16:3; ヨシュア記 18:13–14"> キブツァイムとその放牧地、ベテ・ホロンとその放牧地。四つの町である。</span>
<span className="v" id="v23" data-v="23" data-xref="ヨシュア記 19:44–45"> ダンの部族からは、エルテケとその放牧地、ギベトンとその放牧地、</span>
<span className="v" id="v24" data-v="24" data-xref="ヨシュア記 19:42; ヨシュア記 10:12; 歴代誌上 6:69"> アヤロンとその放牧地、ガテ・リモンとその放牧地。四つの町である。</span>
<span className="v" id="v25" data-v="25" data-xref="ヨシュア記 17:11; 士師記 5:19"> マナセの半部族からは、タアナクとその放牧地、ガテ・リモンとその放牧地。二つの町である。</span>
<span className="v" id="v26" data-v="26"> 残りのケハテの子らの諸氏族の町は、すべてで十の町とその放牧地であった。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="歴代誌上 6:71; 申命記 1:4; ヨシュア記 20:8"> 彼らはレビ人の諸氏族のうちゲルションの子らに、マナセの半部族から、人を殺した者のための逃れの町であるバシャンのゴランとその放牧地を与え、またベエシュテラとその放牧地を与えた。二つの町である。</span>
<span className="v" id="v28" data-v="28" data-xref="ヨシュア記 19:12; 歴代誌上 6:72–73"> イッサカルの部族からは、キシュヨンとその放牧地、ダベラテとその放牧地、</span>
<span className="v" id="v29" data-v="29" data-xref="ヨシュア記 10:23; ヨシュア記 12:11; ヨシュア記 10:3"> ヤルムテとその放牧地、エン・ガニムとその放牧地。四つの町である。</span>
<span className="v" id="v30" data-v="30" data-xref="歴代誌上 6:74–75; ヨシュア記 19:25–28"> アシェルの部族からは、ミシャルとその放牧地、アブドンとその放牧地、</span>
<span className="v" id="v31" data-v="31" data-xref="士師記 18:21; 歴代誌上 6:75; 士師記 1:31"> ヘルカテとその放牧地、レホブとその放牧地。四つの町である。</span>
<span className="v" id="v32" data-v="32" data-xref="歴代誌上 6:76; ヨシュア記 20:7; ヨシュア記 19:37"> ナフタリの部族からは、人を殺した者のための逃れの町であるガリラヤのケデシュとその放牧地、ハモテ・ドルとその放牧地、カルタンとその放牧地。三つの町である。</span>
<span className="v" id="v33" data-v="33"> ゲルション人のすべての町は、その氏族に従って十三の町とその放牧地であった。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="歴代誌上 6:77; ヨシュア記 19:11; ヨシュア記 21:7"> レビ人の残りであるメラリの子らの氏族には、ゼブルンの部族から、ヨクネアムとその放牧地、カルタとその放牧地、</span>
<span className="v" id="v35" data-v="35"> ディムナとその放牧地、ナハラルとその放牧地。四つの町である。</span>
<span className="v" id="v36" data-v="36" data-xref="ヨシュア記 20:8; 申命記 4:43; 民数記 21:23"> ルベンの部族からは、ベツェルとその放牧地、ヤハツとその放牧地、</span>
<span className="v" id="v37" data-v="37"> ケデモトとその放牧地、メファアトとその放牧地。四つの町である。</span>
<span className="v" id="v38" data-v="38" data-xref="創世記 32:2; 列王記第一 22:3; 歴代誌上 6:80"> ガドの部族からは、人を殺した者のための逃れの町であるギルアデのラモトとその放牧地、マハナイムとその放牧地、</span>
<span className="v" id="v39" data-v="39" data-xref="イザヤ書 16:8–9; 民数記 32:35; 民数記 32:1"> ヘシュボンとその放牧地、ヤゼルとその放牧地。全部で四つの町である。</span>
<span className="v" id="v40" data-v="40"> メラリの子ら、すなわちレビ人の氏族の残りの者たちの町は、その氏族に従って、くじにより十二の町であった。</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="民数記 35:1–8; 申命記 33:10; 創世記 49:7"> イスラエルの人々の相続地の中にあるレビ人の町は、全部で四十八の町とその放牧地であった。</span>
<span className="v" id="v42" data-v="42"> これらの町には、それぞれの周囲に放牧地があった。これらすべての町がそうであった。</span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="創世記 13:15; 詩篇 106:42–45; 出エジプト記 23:27–31"> こうして主は、父祖たちに与えると誓われた地をことごとくイスラエルに与えられた。彼らはそれを自分たちのものとし、そこに住んだ。</span>
<span className="v" id="v44" data-v="44" data-xref="ヨシュア記 11:23; ヘブル人への手紙 4:9; 申命記 31:3–5"> 主は、父祖たちに誓われたとおり、彼らの周囲に安息を与えられた。敵のうち、彼らの前に立ちはだかる者は一人もいなかった。主はすべての敵を彼らの手に渡された。</span>
<span className="v" id="v45" data-v="45" data-xref="列王記第一 8:56; ヨシュア記 23:14–15; 民数記 23:19"> 主がイスラエルの家に語られた良い約束は、一つとして果たされないものがなく、すべて実現した。</span>
</div>

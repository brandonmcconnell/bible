<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨシュア記 6:21; ヘブル人への手紙 7:1; ヨシュア記 8:2"> エルサレムの王アドニ・ツェデクは、ヨシュアがアイを占領し、それを完全に滅ぼしたこと、すなわち彼がエリコとその王にしたように、アイとその王にもしたこと、またギベオンの住民がイスラエルと平和を結び、彼らの間にいることを聞いた。</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 11:25; ヨシュア記 2:24; 出エジプト記 15:14–16"> 彼らは非常に恐れた。ギベオンは王の町の一つのように大きな町であり、アイよりも大きく、その男たちは皆勇士だったからである。</span>
<span className="v" id="v3" data-v="3" data-xref="歴代誌 第二 11:9; ミカ書 1:13; ヨシュア記 10:1"> そこでエルサレムの王アドニ・ツェデクは、ヘブロンの王ホハム、ヤルムトの王ピラム、ラキシュの王ヤフィア、エグロンの王デビルに使いを遣わして、言った。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨシュア記 9:15; ヨシュア記 10:1; イザヤ書 8:9–10"> 「私のところに上って来て、私を助けてください。ギベオンを打ちましょう。彼らがヨシュアおよびイスラエルの人々と平和を結んだからです。」</span>
<span className="v" id="v5" data-v="5" data-xref="イザヤ書 8:9–10; 創世記 15:16; ヨシュア記 10:6"> そこでアモリ人の五人の王、すなわちエルサレムの王、ヘブロンの王、ヤルムトの王、ラキシュの王、エグロンの王は集まり、彼らとその全軍隊は上って行って、ギベオンに対して宿営し、その町と戦った。</span>
<span className="v" id="v6" data-v="6" data-xref="ヨシュア記 9:6; ヨシュア記 5:10; 申命記 1:15"> ギベオンの男たちは、ギルガルの宿営にいるヨシュアへ使いを遣わして言った。「どうか、しもべたちを見捨てないでください。急いで上って来て、私たちを救い、助けてください。山地に住むアモリ人の王たちが皆、私たちに向かって集まっています。」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="ヨシュア記 8:1; イザヤ書 8:12; イザヤ書 8:14"> そこでヨシュアは、彼と一緒にいるすべての戦士たち、すべての勇士たちとともにギルガルから上って行った。</span>
<span className="v" id="v8" data-v="8" data-xref="ローマ人への手紙 8:31; 申命記 3:2; 詩篇 27:1–2"> 主はヨシュアに言われた。「彼らを恐れてはならない。わたしは彼らをあなたの手に引き渡したからである。彼らのうち、だれ一人としてあなたの前に立つ者はいない。」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="伝道者の書 9:10; テモテへの第二の手紙 2:3; 箴言 24:11–12"> それゆえ、ヨシュアは夜通しギルガルから上って行き、突然彼らを襲った。</span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 18:14; ヨシュア記 16:3; ヨシュア記 16:5"> 主はイスラエルの前で彼らを混乱に陥れ、ギベオンで大いに打ち破られた。イスラエルはベテ・ホロンの上り坂を通って彼らを追い、アゼカとマケダに至るまで打った。</span>
<span className="v" id="v11" data-v="11" data-xref="イザヤ書 28:2; 士師記 5:20; 詩篇 18:12–14"> 彼らがイスラエルの前から逃げ、ベテ・ホロンの下り坂にいたとき、主は天からアゼカに至るまで、彼らの上に大きな石を降らせ、彼らは死んだ。イスラエルの人々が剣で殺した者よりも、雹の石で死んだ者の方が多かった。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="ハバクク書 3:11; イザヤ書 38:8; イザヤ書 60:20"> 主がアモリ人をイスラエルの人々に渡された日、ヨシュアは主に語り、イスラエルの見ている前で言った。「太陽よ、ギベオンの上で止まれ。月よ、アヤロンの谷でとどまれ。」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="ハバクク書 3:11; イザヤ書 38:8; ヨシュア記 10:14"> 民が敵への報復を遂げるまで、太陽は止まり、月はとどまった。これはヤシャルの書に記されているではないか。太陽は天の真ん中にとどまり、ほぼ丸一日、沈むことを急がなかった。</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 1:30; 出エジプト記 14:14; ヨシュア記 10:42"> 主が人の声に聞き入れられたこのような日は、後にも先にもなかった。主がイスラエルのために戦われたからである。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="ヨシュア記 10:43; ヨシュア記 10:6"> ヨシュアは全イスラエルとともに、ギルガルの宿営に帰った。</span>
<span className="v" id="v16" data-v="16" data-xref="サムエル記第一 24:8; アモス書 9:2; 詩篇 139:7–10"> これら五人の王たちは逃げ、マケダの洞穴に隠れた。</span>
<span className="v" id="v17" data-v="17"> ヨシュアは、「五人の王たちがマケダの洞穴に隠れているのが見つかった」と告げられた。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="マタイ 27:66; ヨブ記 21:30; アモス書 9:1"> ヨシュアは言った。「大きな石を洞穴の口に転がし、そのそばに男たちを配置して彼らを見張らせなさい。</span>
<span className="v" id="v19" data-v="19" data-xref="詩篇 18:37–41; エレミヤ書 8:14; イザヤ書 9:14–15"> しかしあなたがたはとどまってはならない。あなたがたの敵を追いかけ、その後方を打ちなさい。彼らが自分たちの町々に入るのを許してはならない。あなたがたの神、主が彼らをあなたがたの手に引き渡されたからである。」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="ヨシュア記 8:24; サムエル記第二 20:6; ヨシュア記 10:10"> ヨシュアとイスラエルの人々が彼らを激しく打ち、ほとんど滅ぼし尽くしたとき、生き残った者たちは要塞化された町々に入った。</span>
<span className="v" id="v21" data-v="21" data-xref="出エジプト記 11:7; イザヤ書 54:17; イザヤ書 57:4"> その後、民は皆、マケダの宿営にいるヨシュアのもとへ無事に帰った。イスラエルの人々に一言でも逆らう者はいなかった。</span>
<span className="v" id="v22" data-v="22" data-xref="サムエル記第一 15:32"> その時ヨシュアは言った。「洞穴の口を開け、あの五人の王たちを洞穴から私のところに引き出しなさい。」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="ヨシュア記 10:1; ヨシュア記 10:5; ヨシュア記 10:3"> 彼らはそのように行い、エルサレムの王、ヘブロンの王、ヤルムトの王、ラキシュの王、エグロンの王というあの五人の王たちを、洞穴から彼のところに引き出した。</span>
<span className="v" id="v24" data-v="24" data-xref="マラキ書 4:3; ローマ人への手紙 16:20; ヨハネの黙示録 2:26–27"> 彼らがこれらの王たちをヨシュアのところに引き出したとき、ヨシュアはイスラエルのすべての男たちを呼び寄せ、彼と一緒に行った戦士たちの指揮官たちに言った。「近づいて、この王たちの首の上に足を置きなさい。」<br />彼らは近づき、その首の上に足を置いた。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="コリント人への第二の手紙 1:10; ヨシュア記 1:9; エペソ人への手紙 6:10"> ヨシュアは彼らに言った。「恐れてはならない。おののいてはならない。強く、また雄々しくありなさい。主はあなたがたが戦うすべての敵に、このようになされるからである。」</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="ヨシュア記 8:29; サムエル記第二 21:9; マタイ 27:25"> その後、ヨシュアは彼らを打って殺し、五本の木に掛けた。彼らは夕方まで木に掛けられていた。</span>
<span className="v" id="v27" data-v="27" data-xref="ヨシュア記 8:29; 申命記 21:22–23; ヨシュア記 7:26"> 日が沈むころ、ヨシュアの命令によって、五人の王は木から下ろされ、隠れていた洞穴に投げ込まれた。その入口には大きな石が置かれ、今日まで残っている。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="ヨシュア記 6:21; 申命記 7:16; 申命記 20:16–17"> その日、ヨシュアはマケダを占領し、剣の刃で町とその王を打ち、その中のすべての人を聖絶した。一人も残さず、エリコの王にしたように、マケダの王にも行った。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="ヨシュア記 21:13; ヨシュア記 15:42; エレミヤ書 52:1"> ヨシュアは全イスラエルとともにマケダからリブナへ進み、リブナと戦った。</span>
<span className="v" id="v30" data-v="30"> 主はリブナとその王をもイスラエルの手に渡された。ヨシュアは剣の刃で町とその中のすべての人を打ち、一人も残さなかった。エリコの王にしたように、その王にも行った。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="ヨシュア記 10:3; ヨシュア記 12:11; ヨシュア記 10:5"> ヨシュアは全イスラエルとともにリブナからラキシュへ進み、それに対して宿営し、それと戦った。</span>
<span className="v" id="v32" data-v="32"> 主はラキシュをイスラエルの手に渡された。ヨシュアは二日目に町を占領し、リブナにしたのと同じように、町とその中のすべての人を剣の刃で打った。</span>
<span className="v" id="v33" data-v="33" data-xref="ヨシュア記 16:10; 士師記 1:29; ヨシュア記 16:3"> その時、ゲゼルの王ホラムがラキシュを助けるために上って来たが、ヨシュアは彼とその民を打ち、一人も生き残らせなかった。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="ヨシュア記 10:3; ヨシュア記 12:12; ヨシュア記 15:39"> ヨシュアは全イスラエルとともにラキシュからエグロンへ進んだ。彼らはそれに対して宿営し、それと戦った。</span>
<span className="v" id="v35" data-v="35" data-xref="レビ記 26:44; ヨシュア記 10:37; ヨブ記 19:10"> 彼らはその日のうちに町を占領し、剣の刃で打った。ヨシュアはラキシュにしたのと同じように、その中のすべての人を聖絶した。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="士師記 1:10; ヨシュア記 15:13; ヨシュア記 14:13–14"> ヨシュアは全イスラエルとともにエグロンからヘブロンへ上って行き、それと戦った。</span>
<span className="v" id="v37" data-v="37"> 彼らは町を占領し、町とその王、周囲のすべての町、その中のすべての人を剣の刃で打った。エグロンにしたのと同じように、一人も残さず、町とその中のすべての人を聖絶した。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="ヨシュア記 15:15; ヨシュア記 12:13; ヨシュア記 15:49"> ヨシュアは全イスラエルとともにデビルへ引き返し、それと戦った。</span>
<span className="v" id="v39" data-v="39" data-xref="オバデヤ書 1:18; ヨシュア記 11:8; 申命記 3:3"> ヨシュアは町とその王、周囲のすべての町を占領した。彼らは剣の刃で打ち、その中のすべての人を聖絶して、一人も残さなかった。ヘブロン、リブナとその王にしたように、デビルとその王にも行った。</span>
<span className="v" id="v40" data-v="40" data-xref="申命記 7:2–16; 出エジプト記 23:31–33; ヨシュア記 8:27"> こうしてヨシュアは、山地、ネゲブ、低地、山腹の全土と、その王たちを打った。一人も残さず、イスラエルの神、主が命じられたとおり、息のあるものをすべて聖絶した。</span>
<span className="v" id="v41" data-v="41" data-xref="ヨシュア記 11:16; ヨシュア記 15:51; 申命記 9:23"> ヨシュアはカデシュ・バルネアからガザに至るまで、またゴシェンの全地方をギベオンに至るまで打った。</span>
<span className="v" id="v42" data-v="42" data-xref="ヨシュア記 10:14; 詩篇 46:7; 詩篇 80:3"> イスラエルの神、主がイスラエルのために戦われたので、ヨシュアはこれらすべての王たちとその地を一度に占領した。</span>
<span className="v" id="v43" data-v="43" data-xref="ヨシュア記 10:15; ヨシュア記 4:19; サムエル記第一 11:14"> ヨシュアは全イスラエルとともに、ギルガルの宿営に帰った。</span>
</div>
</div>

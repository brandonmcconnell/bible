<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨシュア記 14:10; 申命記 31:3; ヨシュア記 24:29"> ヨシュアは年を重ねて老いていた。主は彼に言われた。「あなたは年を重ねて老いたが、まだ相続すべき地が非常に多く残っている。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="ヨシュア記 13:11; サムエル記第一 27:8; ヨエル書 3:4"> 残っている地は次のとおりである。ペリシテ人のすべての地方、およびゲシュル人のすべての地方。</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 2:23; 士師記 3:3; エレミヤ書 2:18"> エジプトの手前にあるシホルから、北はカナン人のものとみなされているエクロンの境界まで。またペリシテ人の五人の領主、すなわちガザ人、アシュドデ人、アシュケロン人、ガト人、エクロン人、そしてアビム人。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨシュア記 19:30; サムエル記第一 4:1; 士師記 1:34–36"> 南のほうでは、カナン人の全土、およびシドン人に属するメアラから、アフェクを経てアモリ人の境界まで。</span>
<span className="v" id="v5" data-v="5" data-xref="列王記第一 5:18; ヨシュア記 12:7; 詩篇 83:7"> またゲバル人の地と、東側のレバノン全土、すなわちヘルモン山のふもとのバアル・ガドからハマトの入り口まで。</span>
<span className="v" id="v6" data-v="6" data-xref="ヨシュア記 11:8; ヨシュア記 23:13; 士師記 2:21–23"> レバノンからミスレフォト・マイムまでの山地の住民、すなわちシドン人を皆、わたしがイスラエルの人々の前から追い払う。あなたは、わたしが命じたとおり、その地をイスラエルに相続地として割り当てなさい。</span>
<span className="v" id="v7" data-v="7" data-xref="民数記 26:53–56; 民数記 33:54; エゼキエル書 48:23–29"> それゆえ今、この地を九つの部族とマナセの半部族に相続地として分けなさい。」</span>
<span className="v" id="v8" data-v="8" data-xref="ヨシュア記 12:6; 申命記 3:12–17; ヨシュア記 22:4"> マナセのもう半分の部族とともに、ルベン人とガド人は、主のしもべモーセがヨルダン川の東で与えた相続地をすでに受け取っていた。</span>
<span className="v" id="v9" data-v="9" data-xref="ヨシュア記 13:16; 民数記 21:30; ヨシュア記 12:2"> すなわち、アルノン川の谷の端にあるアロエルと、谷の真ん中にある町、およびメデバからディボンに至るすべての平原、</span>
<span className="v" id="v10" data-v="10" data-xref="民数記 21:24–26"> ヘシュボンで治めていたアモリ人の王シホンのすべての町で、アンモン人の境界に至るまで。</span>
<span className="v" id="v11" data-v="11" data-xref="歴代誌上 2:23; ヨシュア記 12:2–5; 申命記 4:47–48"> またギルアデ、ゲシュル人およびマアカ人の境界、ヘルモン山全域、サルカに至るバシャン全域、</span>
<span className="v" id="v12" data-v="12" data-xref="ヨシュア記 12:4; ヨシュア記 14:3–4; 民数記 21:23–35"> バシャンでアシュタロトとエドレイにおいて治めていたオグの王国全域であった。彼はレファイムの生き残りであった。モーセはこれらの者を打ち、彼らを追い払った。</span>
<span className="v" id="v13" data-v="13" data-xref="ヨシュア記 23:12–13; ヨシュア記 13:11; 民数記 33:55"> しかしイスラエルの人々は、ゲシュル人やマアカ人を追い払わなかった。ゲシュルとマアカは今日に至るまでイスラエルのただ中に住んでいる。</span>
<span className="v" id="v14" data-v="14" data-xref="民数記 18:20–24; ヨシュア記 14:3–4; 申命記 18:1–2"> ただしレビの部族には相続地を与えなかった。イスラエルの神、主への火のささげ物が、主の言葉どおり、レビの相続分だからである。</span>
<span className="v" id="v15" data-v="15"> モーセはルベンの子らの部族に、その氏族に従って与えた。</span>
<span className="v" id="v16" data-v="16" data-xref="ヨシュア記 13:9; ヨシュア記 12:2; イザヤ書 16:7–9"> 彼らの境界は、アルノン川の谷の端にあるアロエルと、谷の真ん中にある町、およびメデバのそばのすべての平原、</span>
<span className="v" id="v17" data-v="17" data-xref="民数記 22:41; 民数記 32:38; 民数記 21:19"> ヘシュボンと平原にあるそのすべての町、すなわちディボン、バモテ・バアル、ベテ・バアル・メオン、</span>
<span className="v" id="v18" data-v="18" data-xref="民数記 21:23; ヨシュア記 21:36–37; 歴代誌上 6:78–79"> ヤハツ、ケデモト、メファアト、</span>
<span className="v" id="v19" data-v="19" data-xref="民数記 32:37–38"> キルヤタイム、シブマ、谷の山にあるツェレト・シャハル、</span>
<span className="v" id="v20" data-v="20" data-xref="ヨシュア記 12:3; 申命記 4:46; エゼキエル書 25:9"> ベテ・ペオル、ピスガの斜面、ベテ・エシモト、</span>
<span className="v" id="v21" data-v="21" data-xref="民数記 31:8; 申命記 3:10; 申命記 2:30–36"> および平原のすべての町、ヘシュボンで治めていたアモリ人の王シホンの王国全域であった。モーセはシホンと、その地に住んでいたミディアンの指導者エヴィ、レケム、ツル、フル、レバを打った。彼らはシホンに属する君主たちであった。</span>
<span className="v" id="v22" data-v="22" data-xref="民数記 31:8; ユダ 1:11; ペテロの第二の手紙 2:15"> イスラエルの人々は、殺された他の者たちとともに、占い師であるベオルの子バラムを剣で殺した。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23"> ルベンの子らの境界はヨルダン川とその岸であった。これが氏族ごとのルベンの子らの相続地、その町々と村々である。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="民数記 32:34–36"> モーセはガドの部族、すなわちガドの子らに、その氏族に従って与えた。</span>
<span className="v" id="v25" data-v="25" data-xref="サムエル記第二 12:26; サムエル記第二 11:1; 民数記 32:35"> 彼らの境界はヤゼルとギルアデのすべての町、およびラバの東にあるアロエルに至るアンモン人の地の半分、</span>
<span className="v" id="v26" data-v="26" data-xref="サムエル記第二 17:27; サムエル記第二 2:8; 士師記 10:17"> またヘシュボンからラマト・ミツペおよびベトニムまで、そしてマハナイムからデビルの境界までであった。</span>
<span className="v" id="v27" data-v="27" data-xref="民数記 32:36; 民数記 34:11; 創世記 33:17"> 谷間では、ヘシュボンの王シホンの王国の残りの地、すなわちベテ・ハラム、ベテ・ニムラ、スコテ、ツァフォン。境界はヨルダン川の岸に沿い、川の東側にあるキネレテの海の端まで及んだ。</span>
<span className="v" id="v28" data-v="28"> これがその氏族に従ったガドの子らの相続地であり、その町々と村々であった。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29"> モーセはマナセの半部族に相続地を与えた。それはマナセの子らの半部族のためのもので、その氏族に従って与えられた。</span>
<span className="v" id="v30" data-v="30" data-xref="ヨシュア記 13:26; 申命記 3:13–15; 民数記 32:39–41"> 彼らの境界はマハナイムから始まり、バシャン全域、バシャンの王オグの王国全域、バシャンにあるヤイルのすべての町である六十の町、</span>
<span className="v" id="v31" data-v="31" data-xref="ヨシュア記 12:4; 民数記 32:39–40"> またギルアデの半分、およびバシャンにおけるオグの王国の町であるアシュタロトとエドレイであった。これらはマナセの子マキルの子らのためのもので、すなわちマキルの子らの半分のためのもので、その氏族に従って与えられた。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32"> これらはモーセが、エリコの東にあるヨルダン川の向こう側のモアブの平原で割り当てた相続地である。</span>
<span className="v" id="v33" data-v="33" data-xref="ヨシュア記 18:7; ヨシュア記 13:14; 申命記 18:1–2"> しかしレビの部族には、モーセは相続地を与えなかった。イスラエルの神、主ご自身が、御言葉どおり彼らの相続分だからである。</span>
</div>

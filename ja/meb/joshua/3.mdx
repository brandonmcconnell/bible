<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨシュア記 2:1; マルコ 1:35; 民数記 25:1"> ヨシュアは朝早く起き、彼とイスラエルのすべての人々はシティムを出発してヨルダン川に来た。彼らは川を渡る前にそこに宿営した。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨシュア記 1:10–11"> 三日後、役人たちが宿営の中を行き巡り、</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 31:9; サムエル記第二 6:13; 申命記 31:25"> 民に命じた。「あなたがたの神、主の契約の箱をレビ人の祭司たちが担ぐのを見たなら、自分の場所を離れ、その後に従いなさい。</span>
<span className="v" id="v4" data-v="4" data-xref="詩篇 89:7; ヘブル人への手紙 12:28–29; 出エジプト記 3:5"> ただし、箱との間には約二千キュビト<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一キュビトは男性の中指の先から肘までの長さで、約46センチメートル、または約18インチである。二千キュビトは約920メートルに当たる。">a</a></sup>の間隔を保ち、近づいてはならない。そうすれば、進むべき道が分かる。あなたがたはこれまで、この道を通ったことがないからである。」</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="ヨシュア記 7:13; レビ記 20:7; ヨエル書 2:16"> ヨシュアは民に言った。「身を聖別しなさい。明日、主があなたがたのただ中で驚くべきことを行われる。」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="ヨハネ 14:2–3; 民数記 14:15; ミカ書 2:13"> ヨシュアは祭司たちに言った。「契約の箱を担ぎ、民の先頭に立って渡りなさい。」彼らは契約の箱を担ぎ、民の先頭に立って進んだ。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="ヨシュア記 4:14; ヨシュア記 1:5; 歴代誌上 29:25"> 主はヨシュアに言われた。「今日から、わたしは全イスラエルの目の前であなたを大いなる者とする。わたしがモーセとともにいたように、あなたとともにいることを彼らが知るためである。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨシュア記 3:3; ヨシュア記 3:17; 歴代誌 第二 29:15"> 契約の箱を担ぐ祭司たちには、こう命じなさい。『ヨルダン川の水際まで来たら、川の中に立ち止まれ。』」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="申命記 4:1; 申命記 12:8"> ヨシュアはイスラエルの人々に言った。「ここに来て、あなたがたの神、主の言葉を聞きなさい。」</span>
<span className="v" id="v10" data-v="10" data-xref="申命記 7:1; 出エジプト記 33:2; 詩篇 44:2–3"> ヨシュアは言った。「生ける神があなたがたのただ中におられ、カナン人、ヘト人、ヒビ人、ペリジ人、ギルガシ人、アモリ人、エブス人を、あなたがたの前から必ず追い払われることを、これによって知る。</span>
<span className="v" id="v11" data-v="11" data-xref="ゼカリヤ書 6:5; ゼカリヤ書 4:14; 詩篇 24:1"> 見よ、全地の主<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="ここで「主」と訳された語は、ヘブル語のאֲדֹנָי（アドナイ）である。">b</a></sup>の契約の箱が、あなたがたの先頭に立ってヨルダン川へ入って行く。</span>
<span className="v" id="v12" data-v="12" data-xref="ヨシュア記 4:2; ヨシュア記 4:9; ヨシュア記 4:4"> それゆえ今、イスラエルの部族から、各部族につき一人ずつ、十二人の男たちを取りなさい。</span>
<span className="v" id="v13" data-v="13" data-xref="出エジプト記 15:8; 詩篇 78:13; ヨシュア記 3:15–16"> 全地の主である主<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="ここで「主」と訳された語は、ヘブル語の神の固有名יהוה（ヤハウェ）である。">c</a></sup>の箱を担ぐ祭司たちの足の裏がヨルダン川の水に触れると、川上から流れ下る水はせき止められ、一つの水の塊となって立つ。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="使徒の働き 7:44–45; ヨシュア記 6:6; コリント人への第一の手紙 1:24–25"> 民がヨルダン川を渡ろうと天幕をたたんで出発したとき、契約の箱を担ぐ祭司たちは民の先頭に立った。</span>
<span className="v" id="v15" data-v="15" data-xref="歴代誌上 12:15; ヨシュア記 4:18; ヨシュア記 3:13"> 箱を担ぐ者たちがヨルダン川に達し、箱を担ぐ祭司たちの足が水際に浸ったとき、ヨルダン川は収穫の全期間を通してその両岸に溢れていたが、</span>
<span className="v" id="v16" data-v="16" data-xref="ヨシュア記 3:13; 列王記第一 4:12; 列王記第一 7:46"> 川上から流れ下る水は止まり、ツァレタンのそばの町アダムから、はるか遠くに一つの水の塊となって立った。アラバの海、すなわち塩の海へ流れ下る水は完全に断たれ、民はエリコの向かいを渡った。</span>
<span className="v" id="v17" data-v="17" data-xref="出エジプト記 14:22; 出エジプト記 14:29; 詩篇 66:6"> 主の契約の箱を担ぐ祭司たちがヨルダン川の真ん中の乾いた地面にしっかりと立っている間に、全イスラエルは乾いた地面を渡り、ついに全国民がヨルダン川を完全に渡り終えた。</span>
</div>

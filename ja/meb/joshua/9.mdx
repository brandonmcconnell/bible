<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数記 34:6; 出エジプト記 3:17; 出エジプト記 23:23"> ヨルダン川の向こう側、山地、低地、そしてレバノンの前にある大海の全沿岸にいたすべての王たち、すなわちヘト人、アモリ人、カナン人、ペリジ人、ヒビ人、エブス人がこれを聞いたとき、</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネの黙示録 16:14; ヨエル書 3:9–13; 詩篇 2:1–2"> 彼らはヨシュアおよびイスラエルと戦うために、一つになって集まった。</span>
<span className="v" id="v3" data-v="3" data-xref="ヨシュア記 10:2; ヨシュア記 9:17; サムエル記第二 21:1–2"> しかし、ギベオンの住民は、ヨシュアがエリコとアイにしたことを聞いたとき、</span>
<span className="v" id="v4" data-v="4" data-xref="ルカ 16:8; マタイ 10:16; マルコ 2:22"> 彼らも策略を巡らし、遠国から来た使者のように装った。ろばには古い袋と、破れて繕った古いぶどう酒の革袋を載せ、</span>
<span className="v" id="v5" data-v="5" data-xref="ルカ 15:22; 申命記 33:25; 申命記 29:5"> 足には古くて継ぎ当てをした履き物を履き、古い衣服を着ていた。彼らの食糧のパンはすべて乾いて、カビが生えていた。</span>
<span className="v" id="v6" data-v="6" data-xref="ヨシュア記 5:10; 列王記第二 20:14; ヨシュア記 9:9"> 彼らはギルガルの宿営にいるヨシュアのところに行き、彼とイスラエルの人々に言った。「私たちは遠い国から来ました。ですから今、私たちと契約を結んでください。」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="ヨシュア記 11:19; 士師記 2:2; 出エジプト記 34:12"> イスラエルの人々はヒビ人に言った。「もしかすると、あなたがたは私たちの間に住んでいるのかもしれません。どうして私たちがあなたがたと契約を結べるでしょうか。」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="申命記 20:11; 列王記第二 10:5; ヨシュア記 9:11"> 彼らはヨシュアに言った。「私たちはあなたのしもべです。」<br />ヨシュアは彼らに言った。「あなたがたはだれですか。どこから来たのですか。」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="申命記 20:15; ヨシュア記 9:24; イザヤ書 55:5"> 彼らは答えた。「あなたのしもべたちは、あなたの神、主<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="ここで「主」と訳された語は、ヘブル語の神の固有名יהוה（ヤハウェ）である。">a</a></sup>の御名のゆえに、はるか遠い国から参りました。主の名声と、主がエジプトで行われたすべてのことを聞いたからです。</span>
<span className="v" id="v10" data-v="10" data-xref="民数記 21:24–35; 申命記 1:4; ヨシュア記 12:4"> また、ヨルダン川の向こう側にいたアモリ人の二人の王、すなわちヘシュボンの王シホンと、アシュタロトにいたバシャンの王オグに行われたすべてのことを聞いたからです。</span>
<span className="v" id="v11" data-v="11" data-xref="ヨシュア記 9:8; エステル記 8:17; ヨシュア記 1:11"> 私たちの長老たちと私たちの国のすべての住民は、私たちにこう言いました。『旅の食糧を手に取り、彼らを迎えに行き、彼らに言いなさい。「私たちはあなたがたのしもべです。ですから今、私たちと契約を結んでください。」』</span>
<span className="v" id="v12" data-v="12" data-xref="ヨシュア記 9:4–5"> このパンは、あなたがたのところへ来るため家を出た日に、まだ温かいものを旅の食糧として持って来たものです。それが今では、こんなに乾いてカビが生えています。</span>
<span className="v" id="v13" data-v="13"> このぶどう酒の革袋も、満たした時には新しかったのに、今では破れています。衣服も履き物も、あまりに長い旅のため古びてしまいました。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="箴言 3:5–6; 民数記 27:21; 歴代誌上 10:13–14"> イスラエルの人々は彼らの食糧を受け取って調べたが、主の御心を尋ねなかった。</span>
<span className="v" id="v15" data-v="15" data-xref="サムエル記第二 21:2; 申命記 20:10–11; ヨシュア記 11:19"> ヨシュアは彼らと平和を結び、彼らを生かしておくという契約を彼らと結んだ。会衆の指導者たちは彼らに誓った。</span>
<span className="v" id="v16" data-v="16" data-xref="箴言 12:19"> 彼らと契約を結んでから三日後、彼らが自分たちの隣人であり、自分たちの間に住んでいることを彼らは聞いた。</span>
<span className="v" id="v17" data-v="17" data-xref="エズラ記 2:25; ヨシュア記 18:25–28; ヨシュア記 18:14"> イスラエルの人々は旅立ち、三日目に彼らの町々に着いた。彼らの町々はギベオン、ケフィラ、ベエロト、およびキルヤテ・ヤアリムであった。</span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 15:4; サムエル記第二 21:7; 伝道者の書 5:6"> 会衆の指導者たちがイスラエルの神、主にかけて誓っていたため、イスラエルの人々は彼らを打たなかった。全会衆は指導者たちに不平を言った。</span>
<span className="v" id="v19" data-v="19" data-xref="伝道者の書 8:2; ヨシュア記 9:20; 伝道者の書 9:2"> しかし、すべての指導者たちは全会衆に言った。「私たちはイスラエルの神、主にかけて彼らに誓った。だから今、私たちは彼らに手出しすることはできない。</span>
<span className="v" id="v20" data-v="20" data-xref="マラキ書 3:5; 箴言 20:25; テモテへの手紙第一 1:10"> 私たちは彼らにこのように行い、彼らを生かしておこう。私たちが彼らに誓った誓いのゆえに、怒りが私たちに下らないためである。」</span>
<span className="v" id="v21" data-v="21" data-xref="申命記 29:11; ヨシュア記 9:27; ヨシュア記 9:23"> 指導者たちは彼らに言った。「彼らを生かしておきなさい。」こうして、指導者たちが彼らに語ったように、彼らは全会衆のために木を伐る者、水を汲む者となった。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="ヨシュア記 9:6; ヨシュア記 9:16; 創世記 3:13–14"> ヨシュアは彼らを呼び寄せて言った。「この地に住んでいながら、なぜ『私たちはあなたがたから非常に遠い所にいる』と言って、私たちを欺いたのか。</span>
<span className="v" id="v23" data-v="23" data-xref="ヨシュア記 9:21; 創世記 9:25–26; ヨシュア記 9:27"> それゆえ、あなたがたは呪われる。あなたがたの中から、私の神の家のために木を伐り、水を汲む奴隷が絶えることはない。」</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="申命記 20:15–17; 申命記 7:1–2; 出エジプト記 23:31–33"> 彼らはヨシュアに答えた。「あなたの神、主がそのしもべモーセに、この全土をあなたがたに与え、この地のすべての住民をあなたがたの前から滅ぼすように命じられたことが、あなたのしもべたちに確かに告げられていたからです。それゆえ、私たちはあなたがたのゆえに自分たちの命を非常に恐れ、このことを行いました。</span>
<span className="v" id="v25" data-v="25" data-xref="創世記 16:6; 士師記 10:15; エレミヤ書 26:14"> 今、見よ、私たちはあなたの手の中にあります。あなたの目に良いこと、正しいことと思われることを、私たちにしてください。」</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26"> ヨシュアは彼らにそのように行い、イスラエルの人々の手から彼らを救い出し、彼らが殺されないようにした。</span>
<span className="v" id="v27" data-v="27" data-xref="申命記 12:5"> その日、ヨシュアは彼らを、会衆のため、また主が選ばれる場所で主の祭壇のために、木を伐る者、水を汲む者とした。それは今日に至るまでそうである。</span>
</div>
</div>

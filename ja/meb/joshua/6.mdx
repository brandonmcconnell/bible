<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨシュア記 2:24; ヨシュア記 2:9–14; 詩篇 127:1"> イスラエルの人々を前にして、エリコは固く閉ざされていた。出入りする者は一人もいなかった。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="申命記 7:24; ヨシュア記 8:1; ヨシュア記 2:24"> 主はヨシュアに言われた。「見よ、わたしはエリコとその王、そして勇士たちをあなたの手に引き渡した。</span>
<span className="v" id="v3" data-v="3" data-xref="コリント人への第二の手紙 4:7; 民数記 14:9; ヨシュア記 6:7"> 戦士たち全員に町の周囲を一周させなさい。これを六日間行う。</span>
<span className="v" id="v4" data-v="4" data-xref="歴代誌 第二 20:17; ヨハネの黙示録 16:1; 列王記第一 18:43"> 七人の祭司に七つの雄羊の角笛を持たせ、箱の前を進ませなさい。七日目には町を七周し、祭司たちは角笛を吹き鳴らす。</span>
<span className="v" id="v5" data-v="5" data-xref="コリント人への第二の手紙 10:4–5; ヘブル人への手紙 11:30; 出エジプト記 19:19"> 雄羊の角笛を長く吹き鳴らす音を聞いたら、民は皆、大声で叫びなさい。そうすれば町の城壁はその場に崩れ落ち、民はそれぞれ自分の前をまっすぐ上って行く。」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="使徒の働き 9:1; 申命記 20:2–4; ヨシュア記 3:3"> ヌンの子ヨシュアは祭司たちを呼び、彼らに言った。「契約の箱を担ぎなさい。そして七人の祭司たちに、主の箱の前で七つの雄羊の角笛を持たせなさい。」</span>
<span className="v" id="v7" data-v="7" data-xref="ヨシュア記 4:13; ヨシュア記 6:3; ヨシュア記 1:14"> 彼は民に言った。「進め。町を回りなさい。武装した者たちに主の箱の前を進ませなさい。」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="民数記 32:20; ヨシュア記 6:3–4"> ヨシュアが民に語り終えたとき、主の前で七つの雄羊の角笛を持つ七人の祭司たちは進み出て、角笛を吹き鳴らした。そして主の契約の箱が彼らに続いた。</span>
<span className="v" id="v9" data-v="9" data-xref="ヨシュア記 6:13; 民数記 10:25; イザヤ書 58:8"> 武装した者たちは、角笛を吹き鳴らす祭司たちの前を進んだ。しんがりは箱の後に従った。彼らは進みながら角笛を吹き鳴らした。</span>
<span className="v" id="v10" data-v="10" data-xref="ルカ 24:49; マタイ 12:19; イザヤ書 42:2"> ヨシュアは民に命じた。「私が『叫べ』と言う日まで、叫んではならない。声を上げず、口から一言も出してはならない。その時になったら叫べ。」</span>
<span className="v" id="v11" data-v="11"> こうして彼は主の箱を町の周りに進ませ、町を一周させた。彼らは宿営に帰り、宿営に泊まった。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="ヨシュア記 3:1; ヘブル人への手紙 11:7–8; 創世記 22:3"> ヨシュアは朝早く起き、祭司たちは主の箱を担いだ。</span>
<span className="v" id="v13" data-v="13" data-xref="ガラテヤ人への手紙 6:9; マタイ 24:13; 歴代誌上 15:26"> 主の箱の前で七つの雄羊の角笛を持つ七人の祭司たちは進み続け、角笛を吹き鳴らした。武装した者たちは彼らの前を進んだ。しんがりは主の箱の後に続いた。彼らは進みながら角笛を吹き鳴らした。</span>
<span className="v" id="v14" data-v="14" data-xref="ヨシュア記 6:15; ヨシュア記 6:11; ヨシュア記 6:3"> 二日目にも彼らは町を一周し、宿営に帰った。彼らはこれを六日間行った。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="詩篇 119:147; ペテロの第二の手紙 1:19; マタイ 28:1"> 七日目になると、彼らは夜明けとともに早く起き、同じように町を七周した。この日だけ、彼らは町を七周したのである。</span>
<span className="v" id="v16" data-v="16" data-xref="歴代誌 第二 13:15; ヨシュア記 6:5; 歴代誌 第二 20:22–23"> 七周目に祭司たちが角笛を吹き鳴らすと、ヨシュアは民に言った。「叫べ。主がこの町をあなたがたに与えられた。</span>
<span className="v" id="v17" data-v="17" data-xref="申命記 20:17; ヤコブの手紙 2:25; ミカ書 4:13"> 町とその中にあるすべてのものは、主のために聖絶される。ただし、遊女ラハブと、家の中で彼女とともにいる者は皆、生かしておきなさい。彼女が私たちの遣わした使者を隠したからである。</span>
<span className="v" id="v18" data-v="18" data-xref="ヨハネの手紙第一 5:21; エペソ人への手紙 5:11; ヨシュア記 7:1"> あなたがたは聖絶されたものに決して手を出してはならない。それを取るなら、イスラエルの宿営そのものを聖絶の下に置き、災いを招くことになる。</span>
<span className="v" id="v19" data-v="19" data-xref="歴代誌上 26:20; マタイ 27:6; マルコ 12:41"> ただし、銀、金、青銅と鉄の器はすべて主に聖別されたものであり、主の宝物倉に納めなさい。」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="ヘブル人への手紙 11:30; コリント人への第二の手紙 10:4–5; ヨシュア記 6:5"> そこで民は叫び、祭司たちは角笛を吹き鳴らした。民が角笛の音を聞いて大声で叫んだとき、城壁はその場に崩れ落ちた。こうして民は町に上って行き、皆それぞれまっすぐに進んで町を占領した。</span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 137:8–9; エレミヤ書 48:18; ヨシュア記 11:14"> 彼らは町にあるすべてのものを、男も女も、若者も老人も、牛も羊もろばも、剣の刃で聖絶した。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="ヘブル人への手紙 11:31; ヨシュア記 6:17; エゼキエル書 17:18–19"> ヨシュアはその地を偵察した二人の男に言った。「あの遊女の家に入り、あなたがたが彼女に誓ったとおり、そこから彼女と彼女のすべてのものを連れ出しなさい。」</span>
<span className="v" id="v23" data-v="23" data-xref="ヘブル人への手紙 11:7; 創世記 18:24; 使徒の働き 27:24"> 偵察していたその若者たちは入り、ラハブ、その父、母、兄弟、および彼女のすべてのものを連れ出した。彼らはまた、彼女のすべての親族を連れ出し、イスラエルの宿営の外に置いた。</span>
<span className="v" id="v24" data-v="24" data-xref="ヨシュア記 8:28; ヨハネの黙示録 17:16; 列王記第二 25:9"> 彼らは町と、その中にあるすべてのものを火で燃やした。ただ、銀、金、青銅の器、鉄の器だけは主の家の宝物倉に納めた。</span>
<span className="v" id="v25" data-v="25" data-xref="ヘブル人への手紙 11:31; マタイ 1:5; 士師記 1:24–25"> しかしヨシュアは、遊女ラハブとその父の家族、彼女に属するすべての者を生かしておいた。彼女は今日までイスラエルのただ中に住んでいる。ヨシュアがエリコを探るために遣わした使者を隠したからである。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="列王記第一 16:34; 使徒の働き 19:13; 民数記 5:19–21"> その時、ヨシュアは誓いをもって彼らに命じて言った。「立ち上がってこのエリコの町を建てる者は、主の御前で呪われる。その基礎を据えるときには長子を失い、その門を建てるときには末の子を失うであろう。」</span>
<span className="v" id="v27" data-v="27" data-xref="ヨシュア記 9:3; ヨシュア記 1:5; マタイ 28:20"> こうして主はヨシュアとともにおられ、彼の名声は全土に広まった。</span>
</div>
</div>

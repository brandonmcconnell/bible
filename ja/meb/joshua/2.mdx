<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヘブル人への手紙 11:31; ヤコブの手紙 2:25; マタイ 1:5"> ヌンの子ヨシュアは、シティムから二人の男をひそかに偵察に遣わし、「行って、特にエリコとその地を探れ」と言った。二人は行き、ラハブという遊女の家に入って、そこに泊まった。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="イザヤ書 43:13; ダニエル書 4:35; 箴言 21:30"> エリコの王に、「見よ、<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「見よ」と訳されたヘブル語הִנֵּה（ヒンネ）は、「目を留めよ」「よく見よ」という注意を促す間投詞である。">a</a></sup>今夜、イスラエルの人々の中から、この地を探るために男たちが入って来ました」と知らされた。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="サムエル記第二 10:3; 創世記 42:9–12; 使徒の働き 12:6"> エリコの王はラハブに使いを遣わして言った。「あなたのもとに来て、あなたの家に入った男たちを連れ出しなさい。彼らは全土を探るために来たからだ。」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="列王記第二 6:19; サムエル記第二 17:19–20; サムエル記第二 16:18–19"> しかし女は二人をかくまい、こう答えた。「確かに男たちは私のところに来ましたが、どこから来たのかは知りませんでした。</span>
<span className="v" id="v5" data-v="5" data-xref="エレミヤ書 50:20; エゼキエル書 47:12; ヨハネの黙示録 21:25"> 暗くなり、門が閉まるころ、男たちは出て行きました。どこへ行ったのかは知りません。急いで追えば、追いつけるでしょう。」</span>
<span className="v" id="v6" data-v="6" data-xref="ヘブル人への手紙 11:23; ヤコブの手紙 2:25; コロサイ人への手紙 3:3"> 実は彼女は二人を屋上へ上らせ、そこに並べてあった亜麻の茎の下に隠していた。</span>
<span className="v" id="v7" data-v="7" data-xref="士師記 3:28; ヨシュア記 2:5; 士師記 12:5"> 追っ手はヨルダン川の浅瀬へ向かう道を彼らの後を追って行った。追っ手が出て行くとすぐに、門は閉ざされた。</span>
<span className="v" id="v8" data-v="8"> 二人が寝る前に、彼女は屋上の彼らのところに上がって来て、</span>
<span className="v" id="v9" data-v="9" data-xref="出エジプト記 23:27; 申命記 2:25; ヨシュア記 2:11"> 彼女は男たちに言った。「主がこの地をあなたがたに与えられたことを、私は知っています。あなたがたへの恐れが私たちを襲い、この地の住民は皆、あなたがたの前で震え上がっています。</span>
<span className="v" id="v10" data-v="10" data-xref="民数記 21:21–35; 出エジプト記 15:14–16; 出エジプト記 14:21–31"> あなたがたがエジプトから出て来たとき、主があなたがたの前で紅海の水を枯らされたこと、また、あなたがたがヨルダン川の向こう側にいたアモリ人の二人の王、シホンとオグを完全に滅ぼしたことを、私たちは聞いているからです。</span>
<span className="v" id="v11" data-v="11" data-xref="申命記 4:39; ヨシュア記 5:1; ヨシュア記 7:5"> それを聞いたとき、私たちの心はくじけ、あなたがたのために、だれにも勇気が残りませんでした。あなたがたの神、主こそ、上は天においても、下は地においても神であられるからです。</span>
<span className="v" id="v12" data-v="12" data-xref="ヨシュア記 2:18; ヨシュア記 9:18–20; テモテへの第二の手紙 1:16–18"> どうか今、主にかけて私に誓ってください。私はあなたがたに真実を尽くしました。あなたがたも私の父の家に真実を尽くし、その確かなしるしを与えてください。</span>
<span className="v" id="v13" data-v="13"> そして、私の父、母、兄弟、姉妹、および彼らに属するすべての者を生かし、私たちの命を死から救い出してください。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="マタイ 5:7; 士師記 1:24–25; 創世記 24:49"> 男たちは彼女に言った。「私たちのことを漏らさないなら、あなたがたの命の代わりに私たちの命を差し出そう。主がこの地を私たちに与えられるとき、あなたに真実と慈しみを尽くす。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="使徒の働き 9:25; コリント人への第二の手紙 11:33; ヨシュア記 6:20"> そこで彼女は窓から綱で彼らを降ろした。彼女の家は城壁の側面にあり、彼女は城壁の中に住んでいたからである。</span>
<span className="v" id="v16" data-v="16" data-xref="ヤコブの手紙 2:25; サムエル記第一 23:14; 詩篇 11:1"> 彼女は彼らに言った。「追っ手に見つからないように、山へ行きなさい。追っ手が戻って来るまで三日間そこに隠れていなさい。その後、自分たちの道を行きなさい。」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="民数記 30:2; サムエル記第二 21:7; 創世記 24:3–8"> 男たちは彼女に言った。「あなたが私たちに誓わせたこの誓いについて、次の条件が守られなければ、私たちに責任はない。</span>
<span className="v" id="v18" data-v="18" data-xref="ヨシュア記 6:23; ヨシュア記 2:21; ヨシュア記 2:12–13"> 私たちがこの地に入るとき、私たちを降ろした窓に、この緋色のひもを結びつけておきなさい。父、母、兄弟、父の家の者を皆、あなたの家に集めておきなさい。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒の働き 27:31; 列王記第一 2:36–42; 出エジプト記 12:13"> あなたの家の戸口から通りへ出る者はだれでも、その血は彼自身の頭に帰し、私たちは責任を免れる。しかし、あなたと一緒に家の中にいる者にだれかが手を下すなら、その血は私たちの頭に帰する。</span>
<span className="v" id="v20" data-v="20" data-xref="箴言 11:13"> だが、もしあなたが私たちのこの事について話すなら、あなたが私たちに誓わせたこの誓いについて、私たちは責任を免れる。」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="ヨハネ 2:5; ヨシュア記 2:18; マタイ 7:24"> 彼女は「お言葉どおりにします」と答え、二人を送り出した。二人が去ると、彼女は窓に緋色のひもを結んだ。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="サムエル記第一 19:10–12; サムエル記第二 17:20; 詩篇 32:6–7"> 彼らは行き、山に着き、追っ手が戻るまで三日間そこにとどまった。追っ手はその道中くまなく捜したが、彼らを見つけられなかった。</span>
<span className="v" id="v23" data-v="23"> それから二人の男は戻り、山を下って川を渡り、ヌンの子ヨシュアのところに来た。そして彼らに起こったすべてのことを彼に告げた。</span>
<span className="v" id="v24" data-v="24" data-xref="出エジプト記 23:31; ヨシュア記 1:8; ヨシュア記 2:9–11"> 彼らはヨシュアに言った。「本当に、主はその全土を私たちの手に引き渡されました。その地のすべての住民は、私たちの前に震え上がっています。」</span>
</div>

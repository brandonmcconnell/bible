<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨシュア記 19:51; サムエル記第一 1:3; ヨシュア記 21:2"> イスラエルの人々の全会衆はシロに集まり、そこに会見の天幕を設けた。その地は彼らの前に征服されていた。</span>
<span className="v" id="v2" data-v="2"> イスラエルの人々の中には、自分たちの相続地をまだ分けられていない七つの部族が残っていた。</span>
<span className="v" id="v3" data-v="3" data-xref="士師記 18:9; 箴言 13:4; 箴言 10:4"> ヨシュアはイスラエルの人々に言った。「父祖の神、主が与えられた地に入って自分たちのものとするのを、いつまでためらっているのか。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨシュア記 18:6; ヨシュア記 4:2; ヨシュア記 18:3"> 各部族から三人ずつ選び出しなさい。彼らを遣わそう。彼らは立ち上がってその地を巡り、相続地として分けるために調査して記録し、私のところへ帰って来なければならない。</span>
<span className="v" id="v5" data-v="5" data-xref="ヨシュア記 16:1–10; ヨシュア記 19:1–9; ヨシュア記 15:1–12"> 彼らはそれを七つの分け前に分ける。ユダは南の自分の境界内にとどまり、ヨセフの家は北の自分の境界内にとどまる。</span>
<span className="v" id="v6" data-v="6" data-xref="ヨシュア記 14:2; ヨシュア記 18:10; 使徒の働き 13:19"> その地を七つの区分に分けて記録し、ここにいる私のところへ持って来なさい。私はここで、私たちの神、主の御前で、あなたがたのためにくじを引く。</span>
<span className="v" id="v7" data-v="7" data-xref="ヨシュア記 13:33; ヨシュア記 13:8–31; 民数記 18:20"> ただし、レビ人にはあなたがたの間に分け前がない。主に仕える祭司職が彼らの相続分だからである。ガド、ルベン、マナセの半部族は、主のしもべモーセからヨルダン川の東ですでに相続地を受け取っている。」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="ヨシュア記 18:10; ローマ人への手紙 14:19; サムエル記第一 14:41"> 男たちは立ち上がって出て行った。ヨシュアは、地を調査しに行く者たちに命じた。「行って地を巡り、調査して記録し、私のところへ戻って来なさい。私はここシロで、主の御前であなたがたのためにくじを引く。」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="使徒の働き 13:19"> 男たちは行って地を巡り、町ごとに七つの区分に分けて書物に記録した。それからシロの宿営にいるヨシュアのところへ帰って来た。</span>
<span className="v" id="v10" data-v="10" data-xref="コロサイ人への手紙 1:12; 使徒の働き 13:19; ヨシュア記 18:6"> ヨシュアはシロで、主の御前で彼らのためにくじを引いた。そこでヨシュアはその地をイスラエルの人々に、それぞれの分け前に従って分けた。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="ヨシュア記 16:1–10; ヨシュア記 15:1–8; 申命記 10:1–22"> ベニヤミンの子らの部族のくじが、その氏族に従って引かれた。彼らのくじの境界は、ユダの子らとヨセフの子らの間に出た。</span>
<span className="v" id="v12" data-v="12" data-xref="ヨシュア記 16:1; ヨシュア記 7:2; ヨシュア記 2:1"> 北側の彼らの境界はヨルダン川から始まる。境界は北側のエリコの側面に上り、西のほうの山地を通って上り、ベテ・アベンの荒野で終わる。</span>
<span className="v" id="v13" data-v="13" data-xref="創世記 28:19; ヨシュア記 16:2–3; ヨシュア記 10:11"> 境界はそこからルズへ、南側にあるルズの側面、すなわちベテルへ進む。さらに境界は、下ベテ・ホロンの南にある山を通って、アタロト・アダルに下る。</span>
<span className="v" id="v14" data-v="14" data-xref="ヨシュア記 15:9; 歴代誌上 13:5–6; サムエル記第一 7:1–2"> 境界はそこから延びて、ベテ・ホロンの前にある山の南側から西のほうへ曲がり、ユダの子らの町であるキルヤテ・バアル、すなわちキルヤテ・ヤアリムで終わる。これが西側である。</span>
<span className="v" id="v15" data-v="15" data-xref="ヨシュア記 15:9"> 南側はキルヤテ・ヤアリムの果てから始まる。境界は西へ向かい、ネフトアの水の泉へ出る。</span>
<span className="v" id="v16" data-v="16" data-xref="列王記第二 23:10; ヨシュア記 15:7–8; イザヤ書 30:33"> 境界は、レファイムの谷の北にあり、ベン・ヒノムの谷の前にある山の果てに下る。さらに南側にあるエブス人の側面に沿ってヒノムの谷に下り、エン・ロゲルに下る。</span>
<span className="v" id="v17" data-v="17" data-xref="ヨシュア記 15:6"> それは北へ延びてエン・シェメシュへ出て、アドミムの坂の向かいにあるゲリロトへ出て、ルベンの子ボハンの石に下る。</span>
<span className="v" id="v18" data-v="18" data-xref="ヨシュア記 15:6; ヨシュア記 15:61"> さらに北側のアラバの向かい側へ進み、アラバに下る。</span>
<span className="v" id="v19" data-v="19" data-xref="創世記 14:3; ヨシュア記 15:2; 民数記 34:3"> 境界は北側のベテ・ホグラの側面に進み、境界の終わりはヨルダン川の南端にある塩の海の北の入り江となる。これが南の境界である。</span>
<span className="v" id="v20" data-v="20"> 東側の境界はヨルダン川であった。これがその周囲の境界に従った、ベニヤミンの子らの氏族による相続地である。</span>
<span className="v" id="v21" data-v="21" data-xref="ヨシュア記 18:12; ヨシュア記 6:1; ヨシュア記 18:19"> その氏族に従ったベニヤミンの子らの部族の町々は、エリコ、ベテ・ホグラ、エメク・ケツィツ、</span>
<span className="v" id="v22" data-v="22" data-xref="ヨシュア記 15:6; 列王記第一 12:29–32; ヨシュア記 18:18"> ベテ・アラバ、ツェマライム、ベテル、</span>
<span className="v" id="v23" data-v="23" data-xref="サムエル記第一 13:17"> アビム、パラ、オフラ、</span>
<span className="v" id="v24" data-v="24" data-xref="エズラ記 2:26; ヨシュア記 21:17; イザヤ書 10:29"> ケファル・アモニ、オフニ、ゲバ。十二の町と、その村々。</span>
<span className="v" id="v25" data-v="25" data-xref="ヨシュア記 9:17; 列王記第一 3:4–5; ヨシュア記 10:2"> ギベオン、ラマ、ベエロト、</span>
<span className="v" id="v26" data-v="26" data-xref="士師記 10:17; エズラ記 2:25; ヨシュア記 9:17"> ミツペ、ケフィラ、モツァ、</span>
<span className="v" id="v27" data-v="27"> レケム、イルペエル、タララ、</span>
<span className="v" id="v28" data-v="28" data-xref="サムエル記第二 21:14; ヨシュア記 15:8; 士師記 20:4–5"> ツェラ、エレフ、エブス人の町、すなわちエルサレム、ギベア、キルヤテ。十四の町と、その村々。これがその氏族に従ったベニヤミンの子らの相続地である。</span>

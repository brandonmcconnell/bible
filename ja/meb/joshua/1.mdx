<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命記 34:9; 申命記 1:38; 申命記 31:23"> 主のしもべモーセが死んだ後、主<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="すべて大文字の「主」または「神」は、ヘブル語の神の固有名יהוה（ヤハウェ）を訳したものである。ただし、יה（ヤハ）という短い形に由来すると明記されている場合を除く。">a</a></sup>は、モーセに仕えていたヌンの子ヨシュアに告げられた。</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 3:28; 申命記 31:7; 民数記 27:16–21"> 「わたしのしもべモーセは死んだ。今、立ち上がり、この民すべてとともにヨルダン川を渡り、わたしがイスラエルの人々に与える地へ行きなさい。</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 11:24; ヨシュア記 14:9; テトス 1:2"> わたしがモーセに告げたとおり、あなたがたの足の裏が踏む場所は、ことごとくあなたがたに与えた。</span>
<span className="v" id="v4" data-v="4" data-xref="出エジプト記 23:31; 創世記 15:18–21; 申命記 3:25"> 荒野とこのレバノンから、大河ユーフラテス川、ヘト人の全土、そして日の沈む方の大海に至るまでが、あなたがたの境界となる。</span>
<span className="v" id="v5" data-v="5" data-xref="ローマ人への手紙 8:31; 申命記 31:6–8; マタイ 28:20"> あなたの生涯の間、だれ一人あなたの前に立ちはだかることはできない。わたしはモーセとともにいたように、あなたとともにいる。あなたを見放すことも、見捨てることもしない。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="ダニエル書 10:19; エペソ人への手紙 6:10; ヨシュア記 1:9"> 強く、雄々しくあれ。わたしが父祖たちに与えると誓った地を、この民に受け継がせるのはあなただからである。</span>
<span className="v" id="v7" data-v="7" data-xref="歴代誌上 22:13; 申命記 5:32; ヨシュア記 1:8"> ただ強く、きわめて雄々しくあれ。わたしのしもべモーセがあなたに命じた律法をことごとく守り行い、右にも左にもそれてはならない。そうすれば、どこへ行っても栄える。</span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 119:15; 詩篇 19:14; コロサイ人への手紙 3:16"> この律法の書を口から離さず、昼も夜もそれを思い巡らし、そこに記されているすべてを守り行いなさい。そうすれば、あなたの道は栄え、あなたは成功する。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 28:15; エレミヤ書 1:7–8; ヨシュア記 1:6–7"> わたしはあなたに命じたではないか。強く、雄々しくあれ。恐れてはならない。おののいてはならない。あなたがどこへ行っても、あなたの神<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="ここで「神」と訳されたヘブル語はאֱלֹהִים（エロヒム）である。">b</a></sup>、主があなたとともにいる。」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10"> そこでヨシュアは民の役人たちに命じた。</span>
<span className="v" id="v11" data-v="11" data-xref="申命記 9:1; ホセア書 6:2; 列王記第二 20:5"> 「宿営の中を巡り、民にこう命じなさい。『食糧を整えよ。三日のうちにこのヨルダン川を渡り、あなたがたの神、主が相続地として与えられる地に入って、それを自分たちのものとするからだ。』」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="民数記 32:20–22"> ヨシュアはルベン人、ガド人、およびマナセの半部族に言った。</span>
<span className="v" id="v13" data-v="13" data-xref="民数記 32:20–28; 申命記 3:18–20; ヨシュア記 22:1–4"> 「主のしもべモーセがあなたがたに命じた言葉を思い起こしなさい。『あなたがたの神、主はあなたがたに安息を与え、この地を与えられる。』</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 20:8; 出エジプト記 13:18; ヨハネの黙示録 17:4"> あなたがたの妻、幼子、家畜は、モーセがヨルダン川の東で与えた地にとどまる。しかし勇士たちは皆、武装して兄弟たちの先頭に立って渡り、彼らを助けなさい。</span>
<span className="v" id="v15" data-v="15" data-xref="ピリピ人への手紙 2:4; 民数記 32:17–22; コリント人への第一の手紙 12:26"> 主があなたがたに安息を与えられたように、兄弟たちにも安息を与え、彼らも、あなたがたの神、主が与えられる地を自分たちのものとするまで助けなさい。その後、主のしもべモーセがヨルダン川の東で与えた自分たちの相続地へ帰り、それを受け継ぎなさい。」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="テトス 3:1; 申命記 5:27; ペテロの手紙第一 2:13–15"> 彼らはヨシュアに答えた。「あなたが命じられたことはすべて行い、遣わされる所にはどこへでも行きます。</span>
<span className="v" id="v17" data-v="17" data-xref="ヨシュア記 1:5; 列王記第一 1:37; ヨシュア記 1:9"> 私たちがすべてのことにおいてモーセに聞き従ったように、あなたにも聞き従います。ただ、あなたの神、主がモーセとともにおられたように、あなたとともにおられますように。</span>
<span className="v" id="v18" data-v="18" data-xref="エペソ人への手紙 6:10; ヨシュア記 1:9; エズラ記 10:4"> あなたの命令に逆らい、命じられた言葉に聞き従わない者は、だれであれ死ななければなりません。ただ強く、雄々しくあってください。」</span>
</div>

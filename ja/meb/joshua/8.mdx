<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨシュア記 1:9; 申命記 7:18; 申命記 1:21"> 主はヨシュアに言われた。「恐れてはならない。おののいてはならない。すべての戦士たちを連れ、立ち上がってアイへ上りなさい。見よ、わたしはアイの王を、その民、その町、その地とともにあなたの手に引き渡した。</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 20:14; ヨシュア記 6:21; 歴代誌 第二 20:22"> エリコとその王にしたように、アイとその王にも行いなさい。ただし、その戦利品と家畜は自分たちのものとしてよい。町の背後に伏兵を置きなさい。」</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="マタイ 24:39; マタイ 25:6; テサロニケ人への手紙第一 5:2"> そこでヨシュアはすべての戦士たちとともに立ち上がり、アイへ上った。ヨシュアは三万人の勇士たちを選び出し、夜の間に彼らを送り出した。</span>
<span className="v" id="v4" data-v="4" data-xref="士師記 20:29; ヨシュア記 8:16; 士師記 20:36"> 彼は彼らに命じて言った。「見よ、あなたがたは町の後ろに隠れて、町に対して伏兵となりなさい。町からあまり遠く離れず、全員が備えていなさい。</span>
<span className="v" id="v5" data-v="5" data-xref="ヨシュア記 7:5; マタイ 10:16; 士師記 20:31–33"> 私と、私と一緒にいるすべての民は町に近づく。彼らが最初のように私たちに向かって出て来たら、私たちは彼らの前から逃げる。</span>
<span className="v" id="v6" data-v="6" data-xref="士師記 20:32; 出エジプト記 15:9; 伝道者の書 8:11"> 彼らは私たちの後を追って出て来るので、私たちは彼らを町から誘い出す。『彼らは最初のように私たちの前から逃げている』と彼らは言うからである。こうして私たちは彼らの前から逃げる。</span>
<span className="v" id="v7" data-v="7" data-xref="箴言 21:30–31; 列王記第二 5:1; ヨシュア記 8:1"> そのとき、あなたがたは伏せている場所から立ち上がり、町を占領しなさい。あなたがたの神、主がそれをあなたがたの手に引き渡されるからである。</span>
<span className="v" id="v8" data-v="8" data-xref="サムエル記第二 13:28; ヨシュア記 1:16; ヨシュア記 1:9"> 町を奪ったら火を放ちなさい。主の言葉どおりに行え。これが私の命令である。」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="ヨシュア記 7:2; 創世記 12:8; エズラ記 2:28"> ヨシュアが彼らを送り出すと、彼らは伏兵の場所へ行き、ベテルとアイの間、アイの西側にとどまった。しかしヨシュアはその夜、民の中にとどまった。</span>
<span className="v" id="v10" data-v="10" data-xref="ヨシュア記 6:12; 詩篇 119:60; 創世記 22:3"> ヨシュアは朝早く起き、民を召集し、イスラエルの長老たちとともに民の先頭に立ってアイへ上った。</span>
<span className="v" id="v11" data-v="11"> すべての民、すなわち彼と一緒にいた戦士たちは上って近づき、町の前まで来て、アイの北側に宿営した。彼とアイの間には谷があった。</span>
<span className="v" id="v12" data-v="12" data-xref="ヨシュア記 8:2–3"> 彼は約五千人の男たちを取り、彼らをベテルとアイの間、町の西側に伏兵として配置した。</span>
<span className="v" id="v13" data-v="13" data-xref="ヨシュア記 8:12; ヨシュア記 8:8"> こうして彼らは民を配置した。すなわち、町の北に全軍を、町の西に伏兵を置いた。ヨシュアはその夜、谷の真ん中へ行った。</span>
<span className="v" id="v14" data-v="14" data-xref="マタイ 24:39; 士師記 20:34–36; 申命記 1:1"> アイの王はこれを見ると、町の男たちと全軍を率い、急いで朝早く出て、定められた場所でイスラエルと戦おうとアラバの前へ進んだ。しかし、町の背後に伏兵がいることを知らなかった。</span>
<span className="v" id="v15" data-v="15" data-xref="ヨシュア記 18:12; ヨシュア記 16:1; 士師記 20:36"> ヨシュアと全イスラエルは彼らの前で打ち負かされたふりをして、荒野の道へ逃げた。</span>
<span className="v" id="v16" data-v="16" data-xref="士師記 20:31; 士師記 20:36–39; ヨシュア記 8:5–6"> 町にいたすべての民は、彼らを追撃するために呼び集められた。彼らはヨシュアを追いかけ、町から誘い出された。</span>
<span className="v" id="v17" data-v="17" data-xref="ヨブ記 5:13; ヨシュア記 8:3; イザヤ書 19:11–13"> アイとベテルには、イスラエルの後を追って出て行かない男は一人も残っていなかった。彼らは町を開け放したまま、イスラエルを追いかけた。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="ヨシュア記 8:26; ヨブ記 15:25; サムエル記第一 17:41"> 主はヨシュアに言われた。「あなたの手にある投げ槍をアイに向けて伸ばしなさい。わたしがそれをあなたの手に引き渡すからである。」<br />ヨシュアは手にある投げ槍を町に向けて伸ばした。</span>
<span className="v" id="v19" data-v="19"> 伏兵は自分たちの場所から素早く立ち上がり、彼が手を伸ばしたとたんに走り出し、町に入ってそれを占領した。彼らは急いで町に火を放った。</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 76:5; ヨブ記 11:20; 創世記 19:28"> アイの男たちが振り返ると、町の煙が天へ上っていた。彼らには、どちらへも逃げる道がなかった。荒野へ逃げていた民も、追撃して来た者たちに向き直った。</span>
<span className="v" id="v21" data-v="21"> 伏兵が町を占領し、町の煙が上ったのを見たとき、ヨシュアと全イスラエルは向き直ってアイの男たちを打った。</span>
<span className="v" id="v22" data-v="22" data-xref="申命記 7:2; ヨシュア記 10:28; ヨシュア記 6:21"> 伏兵たちも町から彼らに向かって出て来たので、彼らはイスラエルの真ん中に挟まれた。一部はこちら側に、一部はあちら側にいた。イスラエルは彼らを打ち、生き残る者も逃れる者も一人もいないようにした。</span>
<span className="v" id="v23" data-v="23" data-xref="サムエル記第一 15:8; ヨシュア記 10:17; ヨハネの黙示録 19:20"> 彼らはアイの王を生け捕りにし、ヨシュアのところに連れて来た。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="ヨシュア記 11:10–14; ヨシュア記 10:30–41; 民数記 21:24"> イスラエルが野原で、すなわち彼らを追いかけた荒野で、アイのすべての住民を殺し尽くし、彼らが皆剣の刃に倒れて滅び去ったとき、全イスラエルはアイに戻り、剣の刃で町を打った。</span>
<span className="v" id="v25" data-v="25" data-xref="申命記 20:16–18"> その日に倒れた者は、男も女も合わせて一万二千人、すなわちアイのすべての民であった。</span>
<span className="v" id="v26" data-v="26" data-xref="出エジプト記 17:11–12; ヨシュア記 8:18"> ヨシュアはアイの住民をすべて聖絶するまで、投げ槍を伸ばした手を引かなかった。</span>
<span className="v" id="v27" data-v="27" data-xref="ヨシュア記 8:2; 民数記 31:26; 詩篇 50:10"> ただし、その町の家畜と戦利品は、主がヨシュアに命じられた言葉どおり、イスラエルが自分たちのものとした。</span>
<span className="v" id="v28" data-v="28" data-xref="申命記 13:16; エレミヤ書 49:2; 列王記第二 19:25"> そこでヨシュアはアイを焼き、それを永遠の廃墟、今日に至るまでの荒れ地とした。</span>
<span className="v" id="v29" data-v="29" data-xref="ヨシュア記 7:26; サムエル記第二 18:17; 申命記 21:22–23"> 彼はアイの王を夕方まで木に掛けた。日の沈むころ、ヨシュアが命じると、彼らはその死体を木から下ろし、町の門の入り口に投げ捨て、その上に大きな石塚を積み上げた。それは今日に至るまで残っている。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="申命記 27:4–6; 出エジプト記 20:24; 創世記 12:7–8"> その後、ヨシュアはエバル山にイスラエルの神、主のための祭壇を築いた。</span>
<span className="v" id="v31" data-v="31" data-xref="申命記 27:5–7; 出エジプト記 20:24–25; ヨシュア記 8:34–35"> それは主のしもべモーセがイスラエルの人々に命じ、モーセの律法の書に記されているとおり、鉄の道具を当てたことのない自然石の祭壇であった。彼らはその上で主に全焼のささげ物を献げ、和解のいけにえを献げた。</span>
<span className="v" id="v32" data-v="32" data-xref="申命記 27:2–3; 申命記 27:8"> 彼はそこで、イスラエルの人々の前で、モーセが書き記した律法の写しを石の上に書き記した。</span>
<span className="v" id="v33" data-v="33" data-xref="申命記 11:29; 申命記 31:12; 申命記 31:9"> 全イスラエルと、その長老たち、役人たち、および裁き人たちは、寄留者も、生まれながらのイスラエル人も、主の契約の箱を担ぐレビ人の祭司たちの前で、箱の両側に立った。半分はゲリジム山の前に、半分はエバル山の前に立った。それは、主のしもべモーセがかつて、イスラエルの民を祝福するように命じたとおりであった。</span>
<span className="v" id="v34" data-v="34" data-xref="ネヘミヤ記 8:2–3; ネヘミヤ記 13:1; 申命記 31:10–12"> その後、彼は律法の書に書き記されているすべてのことに従って、律法のすべての言葉、すなわち祝福と呪いを読み上げた。</span>
<span className="v" id="v35" data-v="35" data-xref="申命記 31:12; ネヘミヤ記 8:2; エレミヤ書 26:2"> モーセが命じたすべてのことの中で、ヨシュアがイスラエルの全集会、および女たち、幼子たち、彼らの間にいる寄留者の前で読み上げなかった言葉は一つもなかった。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数記 32:18–33; 申命記 29:7–8"> その時、ヨシュアはルベン人、ガド人、およびマナセの半部族を呼び寄せて、</span>
<span className="v" id="v2" data-v="2" data-xref="ヨシュア記 1:12–18; 申命記 3:16–20; 民数記 32:20–29"> 彼らに言った。「あなたがたは、主のしもべモーセがあなたがたに命じたことをすべて守り、また私があなたがたに命じたすべてのことにおいて、私の声に聞き従った。</span>
<span className="v" id="v3" data-v="3" data-xref="ピリピ人への手紙 1:23–27"> あなたがたは今日まで、この長い間、兄弟たちを見捨てず、あなたがたの神、主の命令を忠実に守ってきた。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨシュア記 13:8; 民数記 32:18; 申命記 3:20"> 今、あなたがたの神、主は、約束どおり兄弟たちに安息を与えられた。だから今、自分たちの天幕へ、すなわち主のしもべモーセがヨルダン川の東であなたがたに与えた相続地へ帰りなさい。</span>
<span className="v" id="v5" data-v="5" data-xref="マタイ 22:37; 出エジプト記 20:6; ローマ人への手紙 8:28"> ただし、主のしもべモーセが命じた戒めと律法を守り行うよう、十分に心を配りなさい。あなたがたの神、主を愛し、そのすべての道を歩み、戒めを守り、主に堅く結びつき、心を尽くし、いのちを尽くして主に仕えなさい。」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="ヨシュア記 14:13; ルカ 24:50; 創世記 47:7"> こうしてヨシュアは彼らを祝福して送り出し、彼らは自分たちの天幕へ帰って行った。</span>
<span className="v" id="v7" data-v="7" data-xref="ヨシュア記 17:1–12; 民数記 32:33; ヨシュア記 13:29–31"> さて、マナセの一方の半部族には、モーセがバシャンに相続地を与えていた。しかしもう一方の半部族には、ヨシュアがヨルダン川の西側で彼らの兄弟たちの間に相続地を与えた。さらにヨシュアは彼らをその天幕へ送り出す際にも彼らを祝福し、</span>
<span className="v" id="v8" data-v="8" data-xref="民数記 31:27; 申命記 8:9–14; 箴言 3:16"> こう言った。「多くの富、多くの家畜、銀、金、青銅、鉄、多くの衣服を携えて、自分たちの天幕へ帰りなさい。敵から得た戦利品を兄弟たちと分け合いなさい。」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="民数記 32:29; 民数記 32:26; 民数記 32:1"> ルベン人、ガド人、およびマナセの半部族は帰って行った。彼らはカナンの地にあるシロでイスラエルの人々を離れ、ギルアデの地、すなわちモーセを通して主が命じられたとおりに彼らが所有していた地へ行った。</span>
<span className="v" id="v10" data-v="10" data-xref="ヨシュア記 24:26–27; 創世記 31:46–52; ヨシュア記 4:5–9"> 彼らがカナンの地のヨルダン川沿いの地方に来ると、ルベン人、ガド人、マナセの半部族は、ヨルダン川のそばに、ひときわ大きく目立つ祭壇を築いた。</span>
<span className="v" id="v11" data-v="11" data-xref="申命記 13:12–14; レビ記 17:8–9; ヨシュア記 2:7"> イスラエルの人々はこう聞いた。「見よ、ルベン人、ガド人、およびマナセの半部族が、カナンの地の境、ヨルダン川沿いの地方で、イスラエルの人々に属する側に祭壇を築いた。」</span>
<span className="v" id="v12" data-v="12" data-xref="士師記 20:1–11; 申命記 13:15; ガラテヤ人への手紙 4:17–18"> イスラエルの人々がこれを聞いた時、イスラエルの人々の全会衆は、彼らに対して戦いに上るため、シロに集まった。</span>
<span className="v" id="v13" data-v="13" data-xref="民数記 25:7; 詩篇 106:30–31; 出エジプト記 6:25"> イスラエルの人々は、ギルアデの地にいるルベン人、ガド人、およびマナセの半部族のところへ、祭司エルアザルの子ピネハスを遣わした。</span>
<span className="v" id="v14" data-v="14" data-xref="民数記 1:4; 出エジプト記 18:25"> 彼とともに十人の族長がいた。イスラエルの各部族から父祖の家を代表する族長が一人ずつ選ばれ、それぞれがイスラエルの諸氏族のかしらであった。</span>
<span className="v" id="v15" data-v="15" data-xref="歴代誌上 21:3; サムエル記第一 15:23; 申命記 30:17"> 彼らはギルアデの地にあるルベン人、ガド人、およびマナセの半部族のところに来て、彼らに言った。</span>
<span className="v" id="v16" data-v="16" data-xref="申命記 12:13–14"> 「主の全会衆はこう言う。『イスラエルの神に対して犯したこの背信は何か。今日、主に従うことから離れ、自分たちのために祭壇を築いて、主に反逆するとは。</span>
<span className="v" id="v17" data-v="17" data-xref="民数記 25:1–18; 詩篇 106:28–29; 申命記 4:3–4"> ペオルで犯した咎では足りないというのか。主の会衆に災いが下り、私たちは今日に至るまで、あの咎から清められきっていない。</span>
<span className="v" id="v18" data-v="18" data-xref="民数記 16:22; ヨシュア記 22:16; ヨシュア記 7:11"> それなのにあなたがたは今日、主に従うことから背き去ろうとするのか。あなたがたが今日、主に逆らうなら、明日には主がイスラエルの全会衆に対して怒られることになる。</span>
<span className="v" id="v19" data-v="19" data-xref="ヨシュア記 18:1; 歴代誌 第二 11:16–17; 使徒の働き 10:14–15"> もし、あなたがたの相続地が汚れているというのであれば、主の幕屋がある主の相続地に渡って来て、私たちの間で相続地を得なさい。しかし、私たちの神、主の祭壇のほかに別の祭壇を築いて、主に逆らってはならない。また私たちにも逆らってはならない。</span>
<span className="v" id="v20" data-v="20" data-xref="ヨシュア記 7:1; ヨシュア記 7:5; ヨシュア記 7:18"> ゼラの子アカンが聖絶されたものについて背信の罪を犯した時、イスラエルの全会衆に御怒りが下ったではないか。その咎によって滅びたのは、彼一人ではなかった。』」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="ヤコブの手紙 1:19; 箴言 16:1; ペテロの手紙第一 3:15"> するとルベン人、ガド人、およびマナセの半部族は答えて、イスラエルの千人隊のかしらたちに言った。</span>
<span className="v" id="v22" data-v="22" data-xref="列王記第一 8:39; 詩篇 44:21; 申命記 10:17"> 「力ある神、主。力ある神、主。その方はご存じです。イスラエルも知りますように。これが主への反逆や背信であったなら、今日、私たちを救わないでください。</span>
<span className="v" id="v23" data-v="23" data-xref="サムエル記第一 20:16; 申命記 18:19; エゼキエル書 3:18"> 私たちが主に従うことから離れるために祭壇を築いたのなら、また、その上で全焼のささげ物や穀物のささげ物、和解のいけにえを献げるためであったのなら、主ご自身が裁かれますように。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="ヨシュア記 4:6; 申命記 6:20; 創世記 30:33"> そうではありません。私たちは、ある心配があってこれを行ったのです。後の日に、あなたがたの子らが私たちの子らにこう言うかもしれないと思いました。『あなたがたはイスラエルの神、主と何のかかわりがあるのか。</span>
<span className="v" id="v25" data-v="25" data-xref="列王記第一 12:16; エズラ記 4:2–3; サムエル記第一 26:19"> 主は、私たちとあなたがた、すなわちルベン人とガド人との間の境界として、ヨルダン川を定められた。あなたがたには主にあずかる分はない』と言うかもしれない、ということです。こうしてあなたがたの子らは、私たちの子らが主を恐れることをやめさせるかもしれないのです。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26"> そこで私たちは言いました。『さあ、自分たちのために祭壇を築こう。ただし、全焼のささげ物や、いけにえを献げるためではない。</span>
<span className="v" id="v27" data-v="27" data-xref="ヨシュア記 24:27; 創世記 31:48; 申命記 12:17–18"> これは、私たちとあなたがたとの間、また後の世代との間で証しとなるためである。私たちは主の御前で、全焼のささげ物、いけにえ、和解のいけにえを献げて主に仕える。』こうして後の日に、あなたがたの子らが私たちの子らに、『あなたがたには主にあずかる分がない』と言わないためです。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="出エジプト記 25:40; エゼキエル書 43:10–11; ヘブル人への手紙 8:5"> 私たちはこう考えました。『後の日に、彼らが私たちや後の世代にそう言うなら、こう答えよう。私たちの父たちが造った主の祭壇の形を見よ。これは全焼のささげ物や、いけにえのためではなく、私たちとあなたがたとの間の証しである。』</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="ヨシュア記 24:16; 申命記 12:13–14; ヨシュア記 22:23"> 私たちが主に逆らい、今日、主に従うことから背き去って、主の幕屋の前にある私たちの神、主の祭壇のほかに、全焼のささげ物、穀物のささげ物、いけにえのための祭壇を築くことは、決してありません。」</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="ヨシュア記 22:33; エステル記 1:21; 箴言 15:1"> 祭司ピネハスと会衆の族長たち、すなわち彼とともにいたイスラエルの千人隊のかしらたちは、ルベン人、ガド人、マナセの子らが語った言葉を聞き、それを良いことと思った。</span>
<span className="v" id="v31" data-v="31" data-xref="歴代誌 第二 15:2; レビ記 26:11–12; イザヤ書 12:6"> 祭司エルアザルの子ピネハスは、ルベン人、ガド人、マナセの子らに言った。「あなたがたが主に対してこの背信の罪を犯していなかったので、今日、主が私たちの間におられることが分かった。あなたがたは今、イスラエルの人々を主の御手から救い出した。」</span>
<span className="v" id="v32" data-v="32" data-xref="ヨシュア記 22:12–14; 箴言 25:13"> 祭司エルアザルの子ピネハスと族長たちは、ギルアデの地を出て、ルベン人とガド人のところからカナンの地のイスラエルの人々のもとへ帰り、彼らに報告した。</span>
<span className="v" id="v33" data-v="33" data-xref="歴代誌上 29:20; ルカ 2:28; ダニエル書 2:19"> その事はイスラエルの人々を喜ばせた。イスラエルの人々は神をほめたたえ、ルベン人とガド人が住んでいる地を滅ぼすために、彼らに対して戦いに上ることをもはや語らなかった。</span>
<span className="v" id="v34" data-v="34" data-xref="ヨシュア記 22:27; マタイ 4:10; イザヤ書 43:10"> ルベン人とガド人は、その祭壇を「主が神であることの、私たちの間の証し」と名づけた。</span>
</div>

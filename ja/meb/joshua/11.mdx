<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨシュア記 11:10; 詩篇 2:1–4; 士師記 4:2"> ハツォルの王ヤビンはこれを聞いたとき、マドンの王ヨバブ、シムロンの王、アクシャフの王、</span>
<span className="v" id="v2" data-v="2" data-xref="ヨシュア記 12:3; 士師記 1:27; ヨシュア記 17:11"> 北の山地、キネレテの南のアラバ、低地、西のドルの高地にいた王たち、</span>
<span className="v" id="v3" data-v="3" data-xref="士師記 3:3; ヨシュア記 18:26; 創世記 31:49"> 東と西のカナン人、山地のアモリ人、ヘト人、ペリジ人、エブス人、そしてミツパの地のヘルモン山のふもとにいたヒビ人に使いを遣わした。</span>
<span className="v" id="v4" data-v="4" data-xref="士師記 7:12; サムエル記第一 13:5; 創世記 32:12"> 彼らは全軍を率いて出て来た。その民は海辺の砂のように多く、馬と戦車も非常に多かった。</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 118:10–12; ヨハネの黙示録 16:14; イザヤ書 8:9"> これらのすべての王たちは集まって会い、イスラエルと戦うために進んで来て、メロムの水のほとりに一緒に宿営した。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="ヨシュア記 10:8; サムエル記第二 8:4; 士師記 20:28"> 主はヨシュアに言われた。「彼らを恐れてはならない。明日の今ごろ、わたしは彼らを皆、イスラエルの前で打ち倒された者として渡す。彼らの馬の足の筋を切り、戦車を火で焼きなさい。」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="ヨシュア記 10:9; テサロニケ人への手紙第一 5:2–3"> そこでヨシュアとすべての戦士たちは、メロムの水のほとりで突然彼らに襲いかかった。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨシュア記 13:6; ヨシュア記 19:28; ゼカリヤ書 9:2"> 主は彼らをイスラエルの手に引き渡された。イスラエルは彼らを打ち、大シドン、ミスレフォト・マイム、東のミツパの谷に至るまで彼らを追いかけた。イスラエルは彼らを打ち、一人も残さなかった。</span>
<span className="v" id="v9" data-v="9" data-xref="ヨシュア記 11:6; エゼキエル書 39:9–10"> ヨシュアは主が彼に命じられたとおりに彼らに対して行った。彼は彼らの馬の足の筋を切り、その戦車を火で燃やした。</span>
<span className="v" id="v10" data-v="10" data-xref="ヨシュア記 11:1; 士師記 4:2"> その時ヨシュアは引き返してハツォルを占領し、その王を剣で打った。ハツォルは以前、それらすべての王国の首都であったからである。</span>
<span className="v" id="v11" data-v="11" data-xref="ヨシュア記 10:40; 申命記 20:16"> 彼らはその中のすべての人を剣の刃で打って聖絶し、息のあるものを一つも残さなかった。ヨシュアはハツォルを火で焼いた。</span>
<span className="v" id="v12" data-v="12" data-xref="申命記 20:16–17; 申命記 7:2; 民数記 33:50–53"> ヨシュアはこれらの王たちの町とその王をことごとく捕らえ、主のしもべモーセが命じたとおり、剣の刃で打って聖絶した。</span>
<span className="v" id="v13" data-v="13" data-xref="エレミヤ書 30:18"> ただし、丘の上に立っていた町々のうち、イスラエルはハツォルを除いて一つも燃やさなかった。ハツォルだけはヨシュアが燃やした。</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 20:14; 民数記 31:9; ヨシュア記 8:27"> これらの町の戦利品と家畜は、イスラエルの人々が自分たちのものとした。しかし人々は剣の刃で打って滅ぼし、息のあるものを一つも残さなかった。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="ヨシュア記 1:7; 出エジプト記 34:11–13; 使徒の働き 20:20"> 主がそのしもべモーセに命じられたように、モーセはヨシュアに命じ、ヨシュアはそのように行った。主がモーセに命じられたことのうち、彼が行わなかったことは何一つなかった。</span>
<span className="v" id="v16" data-v="16" data-xref="ヨシュア記 10:41; ヨシュア記 11:21; ヨシュア記 12:8"> こうしてヨシュアはこの全土、すなわち山地、ネゲブ全土、ゴシェンの全土、低地、アラバ、イスラエルの山地とその低地を占領した。</span>
<span className="v" id="v17" data-v="17" data-xref="申命記 7:24; ヨシュア記 11:3; ヨシュア記 13:5"> セイルへ上って行くハラク山から、ヘルモン山のふもとのレバノンの谷にあるバアル・ガドに至るまでである。彼は彼らのすべての王を捕らえ、打って殺した。</span>
<span className="v" id="v18" data-v="18" data-xref="ヨシュア記 14:7–10; ヨシュア記 11:23"> ヨシュアはこれらすべての王たちと長い間戦った。</span>
<span className="v" id="v19" data-v="19" data-xref="ヨシュア記 9:3–27"> ギベオンの住民であるヒビ人を除いて、イスラエルの人々と平和を結んだ町は一つもなかった。彼らは他をすべて戦いによって占領した。</span>
<span className="v" id="v20" data-v="20" data-xref="ローマ人への手紙 9:18; 申命記 20:16–17; 出エジプト記 4:21"> 彼らの心を頑なにし、イスラエルに戦いを挑ませたのは主であった。それは、彼らが聖絶され、あわれみを受けることなく、主がモーセに命じられたとおり滅ぼされるためであった。</span>
<span className="v" id="v21" data-v="21" data-xref="申命記 9:2; 民数記 13:22–23; ヨシュア記 15:13–14"> その時ヨシュアは、ヘブロン、デビル、アナブ、ユダの全山地、イスラエルの全山地からアナク人を断ち滅ぼし、その町々とともに聖絶した。</span>
<span className="v" id="v22" data-v="22" data-xref="サムエル記第一 17:4; 歴代誌上 18:1; ヨシュア記 15:46"> イスラエルの人々の地にアナク人は一人も残っていなかった。ただガザ、ガト、アシュドデにだけ残っていた。</span>
<span className="v" id="v23" data-v="23" data-xref="ヨシュア記 21:44–45; 民数記 26:52–55; ヨシュア記 14:1–15"> こうしてヨシュアは、主がモーセに告げられたとおり全土を占領し、部族ごとの割り当てに従って相続地としてイスラエルに与えた。その地には戦いがやみ、安息があった。</span>

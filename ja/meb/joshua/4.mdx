<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命記 27:2; ヨシュア記 3:17"> 全国民がヨルダン川を完全に渡り終えたとき、主はヨシュアに告げられた。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨシュア記 3:12; 民数記 1:4–15; 列王記第一 18:31"> 「民の中から、各部族から一人ずつ、十二人の男たちを取り、</span>
<span className="v" id="v3" data-v="3" data-xref="ヨシュア記 4:19–20; ヨシュア記 3:13; ヨシュア記 4:8"> 彼らに命じて言いなさい。『ヨルダン川の真ん中から、すなわち祭司たちの足がしっかりと立った場所から、十二個の石を取りなさい。それらをあなたがたと一緒に運び、今夜あなたがたが宿営する宿営地に置きなさい。』」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="ヨシュア記 4:2; マルコ 3:14–19"> そこでヨシュアは、イスラエルの人々の中から用意していた十二人の男たちを、各部族から一人ずつ呼び寄せた。</span>
<span className="v" id="v5" data-v="5"> ヨシュアは彼らに言った。「あなたがたの神、主の箱の前に進み出てヨルダン川の真ん中に行き、イスラエルの人々の部族の数に従って、それぞれ石を一つずつ肩に担ぎ上げなさい。</span>
<span className="v" id="v6" data-v="6" data-xref="出エジプト記 13:14; ヨシュア記 4:21; 詩篇 44:1"> それはあなたがたの間でしるしとなる。後の日に子らが『これらの石は何を意味するのですか』と尋ねるなら、</span>
<span className="v" id="v7" data-v="7" data-xref="出エジプト記 12:14; 民数記 16:40; 出エジプト記 28:12"> こう答えなさい。『主の契約の箱の前で、ヨルダン川の水が断たれた。箱がヨルダン川を渡ったとき、水が断たれたのである。』これらの石は、イスラエルの人々にとって永遠の記念となる。」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="ヨシュア記 4:2–5; ヨシュア記 1:16–18; ヨシュア記 4:20"> イスラエルの人々はヨシュアが命じたとおりに行った。主がヨシュアに語られたように、イスラエルの人々の部族の数に従って、ヨルダン川の真ん中から十二個の石を取り上げた。彼らはそれを自分たちと一緒に宿営地に運び、そこに置いた。</span>
<span className="v" id="v9" data-v="9" data-xref="サムエル記第一 7:12; 士師記 1:26; 歴代誌 第二 5:9"> ヨシュアはヨルダン川の真ん中、すなわち契約の箱を担いだ祭司たちの足が立った場所に十二個の石を立てた。それらは今日に至るまでそこにある。</span>
<span className="v" id="v10" data-v="10" data-xref="ヨシュア記 3:13; 詩篇 119:60; 箴言 27:1"> モーセがヨシュアに命じたすべてのことに従って、主が民に告げるようにヨシュアに命じられたすべてのことが終わるまで、箱を担ぐ祭司たちはヨルダン川の真ん中に立っていた。そして民は急いで渡った。</span>
<span className="v" id="v11" data-v="11" data-xref="ヨシュア記 3:8; ヨシュア記 4:18; ヨシュア記 3:17"> すべての民が完全に渡り終えたとき、主の箱は祭司たちとともに民の目の前で渡った。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="民数記 32:20–32; ヨシュア記 1:14"> モーセが彼らに語ったように、ルベン人、ガド人、マナセの半部族は武装してイスラエルの人々の先頭に立って渡った。</span>
<span className="v" id="v13" data-v="13" data-xref="エペソ人への手紙 6:11; エレミヤ書 39:5; エレミヤ書 52:8"> 戦いの備えをした約四万人が、主の御前を通り、戦うためにエリコの平野へ渡って行った。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="ヨシュア記 3:7; 歴代誌 第二 30:12; 列王記第一 3:28"> その日、主は全イスラエルの目の前でヨシュアを大いなる者とされた。彼らはモーセの生涯のすべての日の間彼を恐れたように、ヨシュアを恐れた。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15"> 主はヨシュアに告げられた。</span>
<span className="v" id="v16" data-v="16" data-xref="ヨハネの黙示録 11:19; 出エジプト記 25:16–22; ヨシュア記 3:3–6"> 「契約の箱を担ぐ祭司たちに、ヨルダン川から上がって来るように命じなさい。」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="創世記 8:16–18; 使徒の働き 16:35–39; 使徒の働き 16:23"> そこでヨシュアは祭司たちに命じて言った。「ヨルダン川から上がって来なさい。」</span>
<span className="v" id="v18" data-v="18" data-xref="ヨシュア記 3:15; 歴代誌上 12:15; ヨシュア記 3:13"> 主の契約の箱を担ぐ祭司たちがヨルダン川の中から上がり、その足の裏が乾いた地面に触れたとき、ヨルダン川の水は元の場所へ戻り、以前のように両岸にあふれた。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="ヨシュア記 5:9; ミカ書 6:5; 出エジプト記 12:2–3"> 民は第一の月の十日にヨルダン川から上がり、エリコの東の境界にあるギルガルに宿営した。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="ヨシュア記 4:3; ヨシュア記 4:8"> ヨシュアは、彼らがヨルダン川から取ったそれら十二個の石をギルガルに立てた。</span>
<span className="v" id="v21" data-v="21" data-xref="ヨシュア記 4:6; 詩篇 145:4–7; 詩篇 105:2–5"> ヨシュアはイスラエルの人々に言った。「後の日に、子らが父親に『これらの石は何を意味するのですか』と尋ねるなら、</span>
<span className="v" id="v22" data-v="22" data-xref="ヨシュア記 3:17; イザヤ書 51:10; イザヤ書 44:27"> あなたがたは子らに知らせて言いなさい。『イスラエルは乾いた地面を歩いてこのヨルダン川を渡った。</span>
<span className="v" id="v23" data-v="23" data-xref="出エジプト記 14:21; イザヤ書 43:16; イザヤ書 63:12–14"> あなたがたの神、主が、わたしたちが渡り終えるまで紅海をわたしたちの前で枯らされたように、あなたがたの神、主は、あなたがたが渡り終えるまでヨルダン川の水をあなたがたの前で枯らされたからである。</span>
<span className="v" id="v24" data-v="24" data-xref="詩篇 106:8; 詩篇 89:13; 列王記第一 8:42–43"> それは、地上のすべての民が主の御手の力強さを知り、あなたがたがいつまでも、あなたがたの神、主を恐れるためである。』」</span>
</div>

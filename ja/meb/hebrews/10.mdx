<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="ヘブル人への手紙 8:5; ヘブル人への手紙 9:11; コロサイ人への手紙 2:17"> 律法は来たるべき良いものの影であって、そのものの実体ではありません。そのため、毎年絶えずささげられる同じいけにえによって、神に近づく人々を完全にすることは決してできません。</span>
<span className="v" id="v2" data-v="2" data-xref="イザヤ書 43:25; ミカ書 7:19; 詩篇 103:12"> もし完全にすることができたなら、礼拝する人々は一度清められた後、もはや罪を意識することがなくなり、いけにえをささげることもやんだのではないでしょうか。</span>
<span className="v" id="v3" data-v="3" data-xref="ヘブル人への手紙 9:7; 出エジプト記 30:10; レビ記 23:27–28"> しかし、それらのいけにえによって毎年、罪が思い起こされます。</span>
<span className="v" id="v4" data-v="4" data-xref="ヘブル人への手紙 10:11; イザヤ書 1:11–15; ミカ書 6:6–8"> 雄牛ややぎの血が罪を取り除くことは不可能だからです。</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 40:6–8; イザヤ書 1:11; イザヤ書 7:14"> それで、キリストは世に来られた時、こう言われました。<br /><span className="pl pl-1">「あなたは、いけにえと供え物を望まず、</span><br /><span className="pl pl-2">わたしのために体を備えてくださった。</span></span>
<span className="v" id="v6" data-v="6" data-xref="マラキ書 1:10; マタイ 3:17; 詩篇 147:11"> <span className="pl pl-1">全焼のいけにえと罪のためのいけにえを、あなたは喜ばれなかった。</span></span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 40:7–8; ヨハネ 4:34; ヨハネ 6:38"> <span className="pl pl-2">そこで、わたしは言った。『見よ、わたしは来た。巻物にわたしについて記されているとおり、</span><br /><span className="pl pl-2">神よ、あなたの御心を行うために。』」</span></span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="ヘブル人への手紙 10:5; マルコ 12:33"> 先に、「いけにえ、供え物、全焼のいけにえ、罪のためのいけにえを、あなたは望まず、喜ばれなかった」と言われました。これらは律法に従ってささげられるものです。</span>
<span className="v" id="v9" data-v="9" data-xref="ヘブル人への手紙 7:18–19; ヘブル人への手紙 12:27–28; ヘブル人への手紙 10:7"> 次に、「見よ、わたしはあなたの御心を行うために来た」と言われました。第二のものを確立するために、第一のものを取り除かれるのです。</span>
<span className="v" id="v10" data-v="10" data-xref="ヘブル人への手紙 10:14; ヘブル人への手紙 10:12; コリント人への第一の手紙 6:11"> この御心により、イエス・キリストがその体をただ一度ささげられたことによって、私たちは聖なる者とされています。</span>
</div>
<div className="bp poetry">
<span className="v" id="v11" data-v="11" data-xref="ヘブル人への手紙 5:1; 民数記 28:3; ヘブル人への手紙 10:4"> 祭司は皆、毎日立って務めを果たし、決して罪を取り除くことのできない同じいけにえを、繰り返しささげます。</span>
<span className="v" id="v12" data-v="12" data-xref="ヘブル人への手紙 1:3; コロサイ人への手紙 3:1; ローマ人への手紙 8:34"> しかしキリストは、罪のためにただ一つのいけにえをささげた後、永遠に神の右に座り、</span>
<span className="v" id="v13" data-v="13" data-xref="ヘブル人への手紙 1:13; 詩篇 110:1; ルカ 20:43"> それ以来、敵がご自分の足台とされる時を待っておられます。</span>
<span className="v" id="v14" data-v="14" data-xref="ヘブル人への手紙 7:25; ヘブル人への手紙 10:1; ヘブル人への手紙 9:14"> 一つのささげ物によって、聖なる者とされている人々を永遠に完全な者とされたからです。</span>
<span className="v" id="v15" data-v="15" data-xref="ヘブル人への手紙 3:7; ヨハネの黙示録 2:11; ヨハネの黙示録 3:6"> 聖霊も私たちにあかししておられます。まず、こう言われます。</span>
<span className="v" id="v16" data-v="16" data-xref="エレミヤ書 31:33–34; ヘブル人への手紙 8:8–12; ローマ人への手紙 11:27"> <span className="pl pl-1">「その日々の後、わたしが彼らと結ぶ契約はこれである」と、</span><br /><span className="pl pl-2">主は言われる。</span><br /><span className="pl pl-1">「わたしの律法を彼らの心に置き、</span><br /><span className="pl pl-2">彼らの思いに書き記す。」</span><br />続いて、こう言われます。</span>
<span className="v" id="v17" data-v="17" data-xref="エレミヤ書 31:34; ヘブル人への手紙 8:12"> <span className="pl pl-1">「彼らの罪と不法を、わたしはもはや思い出さない。」</span></span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="ヘブル人への手紙 10:2; ヘブル人への手紙 10:14"> これらが赦されるところには、もはや罪のためのささげ物はありません。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="エペソ人への手紙 2:18; ヘブル人への手紙 9:12; ヘブル人への手紙 4:16"> ですから兄弟たち、私たちはイエスの血によって、大胆に聖所に入ることができます。</span>
<span className="v" id="v20" data-v="20" data-xref="ヨハネ 14:6; ヨハネ 10:9; ヘブル人への手紙 9:3"> イエスは、垂れ幕、すなわちご自分の肉体を通る、新しい生きた道を私たちのために開いてくださいました。</span>
<span className="v" id="v21" data-v="21" data-xref="ヘブル人への手紙 2:17; ヘブル人への手紙 4:14–16; ヘブル人への手紙 8:1"> また、神の家を治める偉大な祭司がおられるのですから、</span>
<span className="v" id="v22" data-v="22" data-xref="エゼキエル書 36:25; ヨハネ 3:5; エペソ人への手紙 5:26"> 悪い良心から清められるよう心に血を振りかけられ、体を清い水で洗われた者として、真実な心と信仰の確信に満たされて神に近づこうではありませんか。</span>
<span className="v" id="v23" data-v="23" data-xref="テサロニケ人への手紙第一 5:24; コリント人への第一の手紙 1:9; テサロニケ人への第二の手紙 3:3"> 約束された方は忠実ですから、希望の告白を揺るがず堅く保とうではありませんか。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="テサロニケ人への手紙第一 5:11; ヨハネの手紙第一 3:18; ヘブル人への手紙 13:1"> また、互いに愛と良い行いへ奮い立たせるにはどうすればよいか、心を配ろうではありませんか。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒の働き 2:42; テサロニケ人への手紙第一 5:11; マタイ 18:20"> ある人たちの習慣になっているように、共に集まることをやめず、互いに励まし合いましょう。その日が近づいているのを見ているのですから、なおさらそうしましょう。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="ペテロの第二の手紙 2:20–22; ヘブル人への手紙 6:4–6; ヨハネ 9:41"> 真理を知るようになった後、故意に罪を犯すなら、罪のためのいけにえはもはや残されていません。</span>
<span className="v" id="v27" data-v="27" data-xref="イザヤ書 26:11; ヘブル人への手紙 2:3; ゼパニヤ書 1:18"> 残るのは、恐ろしい裁きを待つことと、敵対する者たちを焼き尽くす激しい火だけです。</span>
<span className="v" id="v28" data-v="28" data-xref="ヘブル人への手紙 2:2; 申命記 19:15; 申命記 17:2–13"> モーセの律法を退ける者は、二人または三人の証言に基づき、あわれみを受けることなく死にます。</span>
<span className="v" id="v29" data-v="29" data-xref="ヘブル人への手紙 6:6; エペソ人への手紙 4:30; イザヤ書 63:10"> まして、神の御子を踏みつけ、自分を聖なる者とした契約の血を聖なるものではないとみなし、恵みの霊を侮辱した者は、どれほど重い刑罰に値すると判断されるでしょうか。</span>
<span className="v" id="v30" data-v="30" data-xref="申命記 32:35–36; ローマ人への手紙 12:19; ナホム書 1:2"> 私たちは、「復讐はわたしのもの。わたしが報復する」と主が言われたことを知っています。また、「主はご自分の民を裁かれる」とも言われています。</span>
<span className="v" id="v31" data-v="31" data-xref="マタイ 10:28; ルカ 12:5; ヘブル人への手紙 12:29"> 生ける神の手に陥ることは恐ろしいことです。</span>
</div>
<div className="bp poetry">
<span className="v" id="v32" data-v="32" data-xref="ヘブル人への手紙 6:4; ヘブル人への手紙 12:4; テモテへの第二の手紙 2:3–13"> しかし、以前のことを思い出しなさい。あなたがたは光に照らされた後、苦しみの中で激しい戦いに耐え抜きました。</span>
<span className="v" id="v33" data-v="33" data-xref="コリント人への第一の手紙 4:9; ピリピ人への手紙 4:14; ヘブル人への手紙 11:36"> ある時には、そしりと苦難にさらされて見せ物にされ、またある時には、そのような扱いを受けた人々の仲間となりました。</span>
<span className="v" id="v34" data-v="34" data-xref="ペテロの手紙第一 1:4; テモテへの第二の手紙 1:16; マタイ 5:11–12"> あなたがたは、鎖につながれた私に同情し、自分には天にもっと優れた、いつまでも残る財産があることを知っていたので、所有物を奪われても喜んで受け入れました。</span>
<span className="v" id="v35" data-v="35" data-xref="コリント人への第一の手紙 15:58; ガラテヤ人への手紙 6:8–10; ヘブル人への手紙 3:6"> ですから、あなたがたの確信を捨ててはいけません。それには大きな報いがあります。</span>
<span className="v" id="v36" data-v="36" data-xref="ヘブル人への手紙 12:1; 詩篇 37:7; ヤコブの手紙 5:7–11"> 神の御心を行った後、約束されたものを受けるためには、忍耐が必要です。</span>
<span className="v" id="v37" data-v="37" data-xref="ヤコブの手紙 5:7–9; ハバクク書 2:3–4; ルカ 18:8"> <span className="pl pl-1">「ほんのしばらくすれば、</span><br /><span className="pl pl-2">来られる方が来られる。遅れることはない。</span></span>
<span className="v" id="v38" data-v="38" data-xref="ガラテヤ人への手紙 3:11; ハバクク書 2:4; ローマ人への手紙 1:17"> <span className="pl pl-1">しかし、義人は信仰によって生きる。</span><br /><span className="pl pl-2">もし後ずさりするなら、わたしの魂はその者を喜ばない。」</span></span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="ヨハネの手紙第一 5:5; ペテロの手紙第一 1:5; マルコ 16:16"> しかし私たちは、後ずさりして滅びに至る者ではなく、信仰によって命を保つ者です。</span>
</div>

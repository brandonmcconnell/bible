<div className="bible-chapter" lang="ja" dir="ltr" data-lang="ja" data-translation="meb" data-translation-id="jpn_meb" data-translation-label="MEB" data-book="HEB" data-book-slug="hebrews" data-book-name="ヘブル人への手紙" data-chapter="11" data-verses="40">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="コリント人への第二の手紙 5:7; コリント人への第二の手紙 4:18; ローマ人への手紙 8:24–25"> 信仰とは、望んでいる事柄への確信であり、目に見えない事柄の確証です。</span>
<span className="v" id="v2" data-v="2" data-xref="ヘブル人への手紙 11:39; ヘブル人への手紙 11:4"> 昔の人々は、この信仰によって神に認められました。</span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 33:6; ペテロの第二の手紙 3:5; ヨハネ 1:3"> 信仰によって、宇宙が神の言葉によって形造られたことを理解します。したがって、見えるものは目に見えるものから造られたのではありません。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="ヘブル人への手紙 12:24; 創世記 4:3–5; ヨハネの手紙第一 3:11–12"> 信仰によって、アベルはカインより優れたいけにえを神にささげました。これによって彼は義人であるとあかしされ、神も彼の供え物についてあかしされました。また、彼は死んだ今もなお、これによって語っています。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="創世記 5:21–24; ユダ 1:14; ヘブル人への手紙 11:6"> 信仰によって、エノクは死を見ることのないよう移され、見つからなくなりました。神が彼を移されたからです。移される前、彼は神に喜ばれていたとあかしされていました。</span>
<span className="v" id="v6" data-v="6" data-xref="箴言 8:17; エレミヤ書 29:13–14; マタイ 6:33"> 信仰がなければ、神に喜ばれることはできません。神に近づく者は、神がおられることと、神を求める人々に報いてくださる方であることを信じなければならないからです。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="創世記 6:13–1; ペテロの手紙第一 3:20; エゼキエル書 14:14"> 信仰によって、ノアはまだ見ていない事柄について警告を受け、神への畏れを抱き、<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="または「畏敬」。">a</a></sup>自分の家族を救うために箱舟を造りました。その信仰によって世を罪に定め、信仰による義の相続者となりました。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="創世記 12:1–4; 使徒の働き 7:2–4; マタイ 7:24–25"> 信仰によって、アブラハムは召しに従い、相続財産として受けることになる場所へ出て行きました。行き先を知らないまま出て行ったのです。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 12:8; 創世記 13:18; 創世記 13:3"> 信仰によって、彼は約束の地にいながら、異国にいるように寄留し、同じ約束を共に受け継ぐイサク、ヤコブとともに、天幕に住みました。</span>
<span className="v" id="v10" data-v="10" data-xref="ヘブル人への手紙 13:14; ピリピ人への手紙 3:20; ヘブル人への手紙 12:22"> 神が設計し、建設された、確かな基のある都を待ち望んでいたからです。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="ローマ人への手紙 4:20–21; ヘブル人への手紙 10:23; 創世記 18:11–14"> 信仰によって、サラ自身も、子を産む年齢を過ぎていたのに、子を宿す力を受け、子を産みました。約束された方を忠実な方と認めたからです。</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 22:17; 創世記 32:12; 創世記 15:5"> それゆえ、死んだも同然の一人の人から、空の星のように数多く、海辺の砂のように数えきれないほどの子孫が生まれました。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="創世記 23:4; 詩篇 39:12; ヘブル人への手紙 11:27"> これらの人々は皆、約束されたものを受けないまま、信仰のうちに死にました。ただ、それをはるか遠くから見て、<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="TRは「確信し」を加えている。">b</a></sup>喜んで迎え、自分たちは地上では異国人であり、旅人であると告白しました。</span>
<span className="v" id="v14" data-v="14" data-xref="コリント人への第二の手紙 4:18–7; ヘブル人への手紙 11:16; ヘブル人への手紙 13:14"> このように言う人々は、自分たちの故郷を探し求めていることを明らかにしています。</span>
<span className="v" id="v15" data-v="15" data-xref="創世記 24:6–8; 創世記 12:10; 創世記 32:9–11"> もし、出て来た故郷を思っていたのなら、帰る機会は十分にあったでしょう。</span>
<span className="v" id="v16" data-v="16" data-xref="ヘブル人への手紙 13:14; ヘブル人への手紙 11:10; ピリピ人への手紙 3:20"> しかし実際には、もっと優れた故郷、すなわち天にある故郷を慕っています。それゆえ、神は彼らの神と呼ばれることを恥となさいません。彼らのために都を用意されたからです。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="創世記 22:16; 創世記 22:1–12; ヤコブの手紙 2:21–24"> 信仰によって、アブラハムは試みを受けた時、イサクをささげました。約束を喜んで受け入れた者が、自分のひとり子を<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="「ひとり子」という句はギリシャ語の「μονογενη」に由来し、「独り子」または「ただ一人の子」と訳されることもある。">c</a></sup>ささげようとしたのです。</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 21:12; ローマ人への手紙 9:7; 創世記 17:19"> この子について、「イサクから出る者が、あなたの子孫と呼ばれる」と言われていました。</span>
<span className="v" id="v19" data-v="19" data-xref="ローマ人への手紙 4:17–21; マタイ 9:28; エペソ人への手紙 3:20"> アブラハムは、神には死者の中からでもイサクをよみがえらせることができると考えました。そして、比喩的に言えば、死者の中から彼を取り戻したのです。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="創世記 27:27–40; 創世記 28:2–3"> 信仰によって、イサクは来たるべき事柄についても、ヤコブとエサウを祝福しました。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="創世記 47:31–1; 創世記 48:5–22"> 信仰によって、ヤコブは死を迎える時、ヨセフの息子たちを一人ずつ祝福し、杖の先に寄りかかって礼拝しました。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="出エジプト記 13:19; 創世記 50:24–25; ヨシュア記 24:32"> 信仰によって、ヨセフは最期が近づいた時、イスラエルの子らの出エジプトについて語り、自分の骨について指示しました。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="出エジプト記 1:22; 出エジプト記 1:16; ヘブル人への手紙 13:6"> 信仰によって、モーセは生まれた時、その両親によって三か月の間隠されました。両親はその子が美しいのを見て、王の命令を恐れなかったからです。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="出エジプト記 2:10–11; 使徒の働き 7:21–24"> 信仰によって、モーセは成長した時、ファラオの娘の子と呼ばれることを拒みました。</span>
<span className="v" id="v25" data-v="25" data-xref="詩篇 84:10; テモテへの第二の手紙 2:3–10; ヨブ記 36:21"> 一時の罪の楽しみを味わうよりも、神の民とともに虐げられることを選び、</span>
<span className="v" id="v26" data-v="26" data-xref="ヘブル人への手紙 10:35; ヘブル人への手紙 11:6; ペテロの手紙第一 4:14"> キリストのそしりを、エジプトの宝よりも大きな富と考えました。報いを見つめていたからです。</span>
<span className="v" id="v27" data-v="27" data-xref="コリント人への第二の手紙 4:18; ヘブル人への手紙 11:13; ヘブル人への手紙 11:1"> 信仰によって、彼は王の怒りを恐れずにエジプトを去りました。目に見えない方を見ているように、耐え抜いたからです。</span>
<span className="v" id="v28" data-v="28" data-xref="出エジプト記 12:21–30; ヘブル人への手紙 9:19; ヘブル人への手紙 12:24"> 信仰によって、彼は過越の祭りと血を振りかける儀式を守りました。初子を滅ぼす者が、彼らに触れないためでした。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="出エジプト記 14:13–21; 詩篇 106:9–11; 詩篇 78:13"> 信仰によって、彼らは乾いた地を行くように紅海を渡りました。エジプト人も同じことをしようとしましたが、海に飲み込まれました。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="ヨシュア記 6:3–20; コリント人への第二の手紙 10:4–5"> 信仰によって、エリコの城壁は七日間取り囲まれた後、崩れ落ちました。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="ヤコブの手紙 2:25; ヨシュア記 6:22–25; マタイ 1:5"> 信仰によって、娼婦ラハブは不従順な人々とともに滅びませんでした。偵察に来た人々を好意をもって迎え入れたからです。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="サムエル記第一 16:1; サムエル記第一 1:20; サムエル記第一 16:13"> これ以上、何を語りましょうか。ギデオン、バラク、サムソン、エフタ、ダビデ、サムエル、また預言者たちについて語っていては、時間が足りません。</span>
<span className="v" id="v33" data-v="33" data-xref="詩篇 144:1–2; ヘブル人への手紙 6:12–15; ヘブル人への手紙 10:36"> 彼らは信仰によって国々を征服し、義を行い、約束されたものを得、獅子の口をふさぎ、</span>
<span className="v" id="v34" data-v="34" data-xref="列王記第二 6:16–18; コリント人への第二の手紙 12:9–10; サムエル記第一 17:51–52"> 火の勢いを消し、剣の刃を逃れ、弱さから強くされ、戦いで勇者となり、異国の軍勢を敗走させました。</span>
<span className="v" id="v35" data-v="35" data-xref="列王記第二 4:27–37; 列王記第一 17:22–24; ピリピ人への手紙 3:11"> 女たちは、死んだ家族を復活によって取り戻しました。ほかの人々は、もっと優れた復活を得るため、釈放を受け入れず、拷問に耐えました。</span>
<span className="v" id="v36" data-v="36" data-xref="エレミヤ書 20:2; 創世記 39:20; エレミヤ書 37:15–21"> また、あざけり、むち打ち、さらには鎖や投獄によって試みられた人々もいました。</span>
<span className="v" id="v37" data-v="37" data-xref="歴代誌 第二 24:21; エレミヤ書 26:23; 列王記第一 19:10"> 彼らは石で打たれ、のこぎりで引かれ、試練を受け、剣で殺されました。羊の皮ややぎの皮をまとって歩き回り、乏しく、苦しめられ、虐待されました。</span>
<span className="v" id="v38" data-v="38" data-xref="列王記第一 18:4; サムエル記第一 22:1; 列王記第一 19:9"> この世は、彼らにふさわしくありませんでした。彼らは荒野、山々、洞窟、地の穴をさまよいました。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="ルカ 10:23–24; ヘブル人への手紙 11:13; ヘブル人への手紙 11:2"> これらの人々は皆、その信仰によって神に認められましたが、約束されたものを受けませんでした。</span>
<span className="v" id="v40" data-v="40" data-xref="ヨハネの黙示録 6:11; ヘブル人への手紙 8:6; ヘブル人への手紙 10:11–14"> 神が私たちのために、さらに優れたものを用意してくださり、私たちを別にして彼らだけが完全な者とされることのないようにされたからです。</span>
</div>
</div>

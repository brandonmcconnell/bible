<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="テモテへの第二の手紙 4:7; コリント人への第一の手紙 9:24–27; ピリピ人への手紙 2:16"> ですから私たちも、これほど大勢の証人に雲のように取り囲まれているのですから、あらゆる重荷と、すぐに絡みつく罪とを捨て、前に置かれた競走を忍耐して走ろうではありませんか。</span>
<span className="v" id="v2" data-v="2" data-xref="ミカ書 7:7; ペテロの手紙第一 3:18; ペテロの手紙第一 2:23–24"> 信仰の創始者であり完成者であるイエスを見つめましょう。イエスは待ち受ける喜びのゆえに、恥をものともせず十字架に耐え、神の王座の右に座られました。</span>
</div>
<div className="bp poetry">
<span className="v" id="v3" data-v="3" data-xref="ガラテヤ人への手紙 6:9; コリント人への第二の手紙 4:16; ヨハネの黙示録 2:3"> あなたがたの心が疲れ果て、気力を失うことのないように、罪人たちからご自分に向けられたこれほどの反抗を耐え抜かれた方のことを考えなさい。</span>
<span className="v" id="v4" data-v="4" data-xref="コリント人への第一の手紙 10:13; ヨハネの黙示録 2:13; ヘブル人への手紙 10:32–34"> あなたがたは罪と戦いながら、まだ血を流すまで抵抗したことはありません。</span>
<span className="v" id="v5" data-v="5" data-xref="箴言 3:11–12; ヨブ記 5:17–18; ヨハネの黙示録 3:19"> また、子に語るようにあなたがたを諭す、次の勧めを忘れてしまっています。<br /><span className="pl pl-1">「わが子よ、主の訓練を軽く考えてはならない。</span><br /><span className="pl pl-2">主に戒められる時、気力を失ってはならない。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="ヨハネの黙示録 3:19; 箴言 3:12; 詩篇 119:75"> <span className="pl pl-2">主は愛する者を訓練し、</span><br /><span className="pl pl-2">受け入れる子を皆、懲らしめられるからである。」</span></span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="箴言 19:18; 申命記 8:5; 箴言 13:24"> あなたがたが耐えているのは訓練のためです。神はあなたがたを子として扱っておられます。父から訓練を受けない子がいるでしょうか。</span>
<span className="v" id="v8" data-v="8" data-xref="ヘブル人への手紙 12:6; ペテロの手紙第一 5:9–10; 詩篇 73:1"> 皆が受けている訓練を受けていないのなら、あなたがたは私生児であって、子ではありません。</span>
<span className="v" id="v9" data-v="9" data-xref="民数記 16:22; 民数記 27:16; イザヤ書 42:5"> さらに私たちには、自分を訓練する肉親の父がいて、彼らを敬いました。それなら、なおさら霊の父に従って生きるべきではないでしょうか。</span>
<span className="v" id="v10" data-v="10" data-xref="ペテロの第二の手紙 1:4; レビ記 11:44–45; テトス 2:14"> 肉親の父たちは、自分たちが良いと思う方法で、わずかな日の間、私たちを訓練しました。しかし神は、私たちがご自分の聖さにあずかるよう、私たちの益のために訓練されます。</span>
<span className="v" id="v11" data-v="11" data-xref="ローマ人への手紙 5:3–5; コリント人への第二の手紙 4:17; ヘブル人への手紙 12:5–6"> どんな訓練も、その時には喜ばしいものではなく、つらいものに思われます。しかし後には、それによって鍛えられた人々に、平安に満ちた義の実を結ばせます。</span>
<span className="v" id="v12" data-v="12" data-xref="イザヤ書 35:3; ヘブル人への手紙 12:3; テサロニケ人への手紙第一 5:14"> ですから、力なく垂れた手を上げ、弱った膝をまっすぐにし、</span>
<span className="v" id="v13" data-v="13" data-xref="箴言 4:26–27; イザヤ書 35:3; ガラテヤ人への手紙 6:1"> 自分の足のためにまっすぐな道を造りなさい。それは、足の不自由な者が道を外れることなく、むしろ癒やされるためです。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="コリント人への第二の手紙 7:1; ペテロの手紙第一 1:15–16; テサロニケ人への手紙第一 4:7"> すべての人との平和と、聖さを追い求めなさい。聖さがなければ、だれも主を見ることはできません。</span>
<span className="v" id="v15" data-v="15" data-xref="ヘブル人への手紙 3:12; 申命記 29:18; ガラテヤ人への手紙 5:4"> だれも神の恵みを受け損なうことのないように、また、苦い根が生え出てあなたがたを悩ませ、それによって多くの人が汚されることのないように、よく注意しなさい。</span>
<span className="v" id="v16" data-v="16" data-xref="創世記 25:31–34; コリント人への第一の手紙 6:15–20; ヨハネの黙示録 22:15"> また、だれも性的な不道徳に陥る者や、エサウのように神聖なものを軽んじる者にならないようにしなさい。エサウは一度の食事と引き換えに、長子の権利を売りました。</span>
<span className="v" id="v17" data-v="17" data-xref="箴言 1:24–31; マタイ 25:11–12; マタイ 7:23"> あなたがたが知っているとおり、その後、祝福を受け継ぎたいと願った時には退けられました。涙を流して熱心に求めましたが、心を変える機会を見いだせなかったからです。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="申命記 4:11; 出エジプト記 24:17; 出エジプト記 20:18"> あなたがたが近づいたのは、手で触れることができ、火で燃えている山、暗闇、暗黒、嵐、</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 18:16; コリント人への第一の手紙 15:52; 申命記 4:12"> ラッパの響き、また言葉を告げる声ではありません。その声を聞いた人々は、これ以上何も語られないようにと願いました。</span>
<span className="v" id="v20" data-v="20" data-xref="出エジプト記 19:12–13; 出エジプト記 19:16; ガラテヤ人への手紙 3:10"> 「獣であっても山に触れるなら、石で打ち殺されなければならない」という命令に耐えられなかったからです。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="TRは「または矢で射られなければならない」を加えている。">a</a></sup></span>
<span className="v" id="v21" data-v="21" data-xref="出エジプト記 19:16; 申命記 9:19; イザヤ書 6:3–5"> その光景はあまりにも恐ろしく、モーセさえ「私は恐れおののき、震えている」と言いました。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="ガラテヤ人への手紙 4:26; ピリピ人への手紙 3:20; ヨハネの黙示録 14:1"> しかし、あなたがたが近づいたのは、シオンの山、生ける神の都である天のエルサレム、無数の御使いたち、</span>
<span className="v" id="v23" data-v="23" data-xref="ヤコブの手紙 1:18; ヘブル人への手紙 11:40; ルカ 10:20"> 喜び祝う集い、天に登録されている初子たちの集会、すべての者を裁く神、完全な者とされた義人たちの霊、</span>
<span className="v" id="v24" data-v="24" data-xref="ヘブル人への手紙 9:15; ヘブル人への手紙 11:28; ヘブル人への手紙 11:4"> 新しい契約の仲介者イエス、そしてアベルの血よりもさらに優れたことを語る、振りかけられた血です。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="ヘブル人への手紙 8:5; 申命記 30:17; ヘブル人への手紙 2:1–3"> 語っておられる方を拒まないように注意しなさい。地上で警告した方を拒んだ人々が逃れられなかったのなら、まして天から警告しておられる方に背を向ける私たちは、決して逃れられません。</span>
<span className="v" id="v26" data-v="26" data-xref="ハガイ書 2:6–7; イザヤ書 13:13; 出エジプト記 19:18"> その時、御声は地を揺り動かしました。しかし今は、「もう一度、わたしは地だけでなく、天をも揺り動かす」と約束しておられます。</span>
<span className="v" id="v27" data-v="27" data-xref="コリント人への第一の手紙 7:31; マタイ 24:35; ペテロの第二の手紙 3:10–11"> この「もう一度」という言葉は、造られたものとして揺り動かされるものが取り除かれ、揺り動かされないものが残ることを示しています。</span>
<span className="v" id="v28" data-v="28" data-xref="ローマ人への手紙 12:1–2; ヘブル人への手紙 13:15; ダニエル書 2:44"> ですから、揺り動かされない王国を受けている私たちは、恵みを受けようではありませんか。その恵みによって、畏敬と恐れをもって、神に喜ばれる仕方で仕えましょう。</span>
<span className="v" id="v29" data-v="29" data-xref="申命記 4:24; 申命記 9:3; ヘブル人への手紙 10:27"> 私たちの神は、焼き尽くす火だからです。</span>
</div>

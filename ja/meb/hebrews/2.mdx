<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ルカ 8:15; ペテロの第二の手紙 1:12–13; 箴言 7:1–2"> ですから、私たちは押し流されることのないよう、聞いたことをいっそう心に留めなければなりません。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒の働き 7:53; ガラテヤ人への手紙 3:19; ヘブル人への手紙 10:28"> 御使いたちを通して語られた言葉が確かなものとなり、あらゆる違反と不従順が正当な報いを受けたのなら、</span>
<span className="v" id="v3" data-v="3" data-xref="ヘブル人への手紙 10:28–29; ヘブル人への手紙 12:25; ヘブル人への手紙 5:9"> これほど偉大な救いをないがしろにして、どうして私たちは逃れられるでしょうか。この救いは初めに主によって語られ、聞いた人々によって私たちにも確かなものとして伝えられました。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒の働き 14:3; エペソ人への手紙 1:5; マルコ 16:20"> さらに神も、しるしと不思議、さまざまな力ある業、また御心のままに分け与えられた聖霊の賜物によって、その証言を裏づけられました。</span>
</div>
<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="ヨハネの黙示録 11:15; ペテロの第二の手紙 3:13; ヘブル人への手紙 6:5"> 神は、私たちが語っている来たるべき世界を、御使いたちに従わせたのではありません。</span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 8:4–8; 詩篇 144:3; ヨブ記 7:17–18"> ある人が、ある箇所でこうあかししています。<br /><span className="pl pl-1">「人とは何者なのか。あなたが心に留められるとは。</span><br /><span className="pl pl-2">人の子とは何者なのか。あなたが顧みられるとは。</span></span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 8:5; ピリピ人への手紙 2:6–7"> <span className="pl pl-1">あなたは彼を、しばらくの間、御使いたちより低い者とし、</span><br /><span className="pl pl-2">栄光と誉れの冠を授けられた。</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="TRは「そして、あなたの御手の業を治めさせられた」を加えている。">a</a></sup><br /></span>
<span className="v" id="v8" data-v="8" data-xref="ヨハネ 13:3; コリント人への第一の手紙 15:27; 詩篇 8:6"> <span className="pl pl-2">すべてのものを彼の足の下に従わせられた。」</span><br />神はすべてのものを彼に従わせたのですから、彼に従わないものを何一つ残されませんでした。しかし今、私たちはまだ、すべてのものが彼に従っているのを見てはいません。</span>
<span className="v" id="v9" data-v="9" data-xref="ピリピ人への手紙 2:7–9; ヨハネの黙示録 5:9; ヨハネの手紙第一 4:9–10"> しかし私たちは、御使いたちよりしばらくの間低い者とされたイエスを見ています。イエスは、神の恵みによってすべての人のために死を味わうため、死の苦しみを受け、栄光と誉れの冠を授けられました。</span>
</div>
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="ローマ人への手紙 11:36; 使徒の働き 5:31; ルカ 24:46"> 万物は神のために存在し、神を通して存在しています。多くの子らを栄光へ導くにあたり、彼らの救いの創始者を苦しみによって完全な者とすることは、神にふさわしいことでした。</span>
<span className="v" id="v11" data-v="11" data-xref="ヘブル人への手紙 10:10; ヘブル人への手紙 13:12; ヘブル人への手紙 10:14"> 人を聖なる者とする方も、聖なる者とされる人々も、皆、同じ方から出ています。それゆえ、イエスは彼らを兄弟と呼ぶことを恥となさいません。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="ここで「兄弟」と訳された言葉は、文脈が許す場合、「兄弟姉妹」または「きょうだい」と訳すこともできる。">b</a></sup></span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 22:22; 詩篇 40:10; ヨハネ 18:20"> こう言われます。<br /><span className="pl pl-1">「わたしはあなたの名を兄弟たちに告げ知らせる。</span><br /><span className="pl pl-2">会衆の中で、あなたを賛美して歌う。」</span></span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="イザヤ書 8:17–18; イザヤ書 12:2; 詩篇 91:2"> また、「わたしはこの方に信頼を置く」と言い、さらに、「見よ、ここにわたしと、神がわたしに与えてくださった子らがいる」と言われます。</span>
<span className="v" id="v14" data-v="14" data-xref="テモテへの第二の手紙 1:10; ローマ人への手紙 8:3; コロサイ人への手紙 2:15"> そこで、子らは血と肉を備えているので、イエスご自身も同じように血と肉を身に受けられました。それは、死によって、死の力を持つ者、すなわち悪魔を無力にし、</span>
<span className="v" id="v15" data-v="15" data-xref="ローマ人への手紙 8:15; テモテへの第二の手紙 1:7; ルカ 1:74–75"> 死を恐れるために一生涯、奴隷の状態にあった人々を、ことごとく解放するためでした。</span>
<span className="v" id="v16" data-v="16" data-xref="ガラテヤ人への手紙 3:29; ガラテヤ人への手紙 3:16; ローマ人への手紙 4:16–25"> 確かに、イエスが助けの手を差し伸べられるのは御使いたちではなく、アブラハムの子孫<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="または「種」。">c</a></sup>です。</span>
<span className="v" id="v17" data-v="17" data-xref="ヘブル人への手紙 4:14–2; ピリピ人への手紙 2:7–8; ヘブル人への手紙 2:14"> そのため、イエスはあらゆる点で兄弟たちと同じようにならなければなりませんでした。それは、神への務めにおいて、あわれみ深く忠実な大祭司となり、民の罪を贖うためでした。</span>
<span className="v" id="v18" data-v="18" data-xref="コリント人への第一の手紙 10:13; ヘブル人への手紙 4:15–16; ユダ 1:24"> イエスご自身が試みを受けて苦しまれたからこそ、試みを受けている人々を助けることがおできになるのです。</span>
</div>

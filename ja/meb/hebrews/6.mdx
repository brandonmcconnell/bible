<span className="v" id="v2" data-v="2" data-xref="コリント人への第一の手紙 15:13–57; 使徒の働き 17:31–32; ローマ人への手紙 6:3–5"> 洗礼についての教え、手を置くこと、死者の復活、永遠の裁きという土台を、再び据えることはやめましょう。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒の働き 18:21; コリント人への第一の手紙 16:7; コリント人への第一の手紙 4:19"> 神が許されるなら、私たちはそうします。</span>
<span className="v" id="v4" data-v="4" data-xref="ヘブル人への手紙 10:26–29; ペテロの第二の手紙 2:20–22; マタイ 5:13"> 一度光に照らされ、天からの賜物を味わい、聖霊にあずかる者となり、</span>
<span className="v" id="v5" data-v="5" data-xref="ペテロの手紙第一 2:3; ルカ 8:13; マタイ 13:20–21"> 神の良い言葉と来たるべき時代の力とを味わった人々が、</span>
<span className="v" id="v6" data-v="6" data-xref="ペテロの第二の手紙 2:21; ヘブル人への手紙 10:29; ヘブル人への手紙 6:4"> その後に離れ去った人々を、もう一度悔い改めへと立ち返らせることは不可能です。彼らは自ら神の御子を再び十字架につけ、公然と辱めているからです。</span>
<span className="v" id="v7" data-v="7" data-xref="ホセア書 10:12; イザヤ書 44:3; 詩篇 65:9–13"> たびたび降る雨を吸い込み、耕す人々に役立つ作物を生じる土地は、神から祝福を受けます。</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 3:17–18; ヨハネ 15:6; ルカ 13:7–9"> しかし、いばらやあざみを生じる土地は退けられ、呪われる寸前にあり、最後には焼かれます。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="ヘブル人への手紙 10:39; コリント人への第二の手紙 7:10; ヘブル人への手紙 6:4–6"> 愛する人たち、このように語ってはいますが、あなたがたについては、もっと良いこと、すなわち救いに伴うことを確信しています。</span>
<span className="v" id="v10" data-v="10" data-xref="マタイ 10:42; ヘブル人への手紙 13:16; ガラテヤ人への手紙 6:10"> 神は不義な方ではありません。あなたがたの働きと、御名に対して示した愛の労苦を忘れたりはなさいません。あなたがたは聖徒たちに仕え、今も仕え続けています。</span>
<span className="v" id="v11" data-v="11" data-xref="ペテロの第二の手紙 1:5–8; ヘブル人への手紙 3:6; ローマ人への手紙 5:2–5"> 私たちが願うのは、あなたがた一人一人が最後まで同じ熱意を示し、希望について十分な確信を持つことです。</span>
<span className="v" id="v12" data-v="12" data-xref="ヘブル人への手紙 13:7; ヘブル人への手紙 10:36; ヨハネの手紙第一 2:25"> 怠けることなく、信仰と忍耐によって約束を受け継ぐ人々に倣いなさい。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="創世記 22:15–18; ルカ 1:73; エレミヤ書 22:5"> 神はアブラハムに約束を与えた時、ご自分より偉大な者を指して誓うことができなかったので、ご自分を指して誓い、</span>
<span className="v" id="v14" data-v="14" data-xref="創世記 22:17; 申命記 1:10; ネヘミヤ記 9:23"> 「わたしは必ずあなたを豊かに祝福し、あなたの子孫を大いに増やす」と言われました。</span>
<span className="v" id="v15" data-v="15" data-xref="創世記 12:2–3; ローマ人への手紙 4:17–25; 出エジプト記 1:7"> こうしてアブラハムは、忍耐強く待った末に、約束されたものを得ました。</span>
<span className="v" id="v16" data-v="16" data-xref="出エジプト記 22:11; ヘブル人への手紙 6:13; 創世記 31:53"> 人は自分より偉大な者を指して誓い、その誓いは確証となって、あらゆる論争に決着をつけます。</span>
<span className="v" id="v17" data-v="17" data-xref="ヘブル人への手紙 6:18; 箴言 19:21; イザヤ書 55:11"> それで神も、ご自分の計画が変わらないことを約束の相続者たちにいっそう明確に示そうとして、誓いを加えて保証されました。</span>
<span className="v" id="v18" data-v="18" data-xref="民数記 23:19; テトス 1:2; サムエル記第一 15:29"> それは、神が偽ることのできない二つの不変の事柄によって、避け所を求めて逃れ、前に置かれた希望をつかもうとしている私たちが、力強い励ましを受けるためです。</span>
<span className="v" id="v19" data-v="19" data-xref="詩篇 43:5; ローマ人への手紙 5:5–10; ヘブル人への手紙 9:7"> 私たちはこの希望を、確かで揺るがない魂の錨として持っています。この錨は垂れ幕の内側にまで入って行きます。</span>
<span className="v" id="v20" data-v="20" data-xref="ヘブル人への手紙 4:14; ヘブル人への手紙 3:1; ヘブル人への手紙 5:6"> そこには、先駆けとしてイエスが私たちのために入り、メルキゼデクの位に従う永遠の大祭司となられました。</span>

<span className="v" id="v2" data-v="2" data-xref="民数記 12:7; テモテへの手紙第一 3:15; エペソ人への手紙 2:22"> イエスは、ご自分を任命された方に忠実でした。モーセも神の家全体において忠実であったのと同じです。</span>
<span className="v" id="v3" data-v="3" data-xref="コリント人への第一の手紙 3:9; ペテロの手紙第一 2:5–7; ゼカリヤ書 6:12–13"> 家を建てた者が家そのものより大きな誉れを受けるように、イエスはモーセ以上の栄光にふさわしいとされました。</span>
<span className="v" id="v4" data-v="4" data-xref="ヘブル人への手紙 3:3; ヘブル人への手紙 1:2; エステル記 2:10"> どんな家もだれかによって建てられますが、すべてのものを建てた方は神です。</span>
<span className="v" id="v5" data-v="5" data-xref="民数記 12:7; ヘブル人への手紙 3:2; 出エジプト記 14:31"> モーセは、後に語られることをあかしする僕として、神の家全体に忠実でした。</span>
<span className="v" id="v6" data-v="6" data-xref="コリント人への第二の手紙 6:16; コリント人への第一の手紙 3:16; ヘブル人への手紙 10:35"> しかし、キリスト<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「キリスト」は「油を注がれた者」という意味である。">a</a></sup>は御子として神の家を治める忠実な方です。私たちが確信と、希望を誇りとする心とを終わりまで堅く保つなら、私たちこそ神の家です。</span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 95:7–11; ヘブル人への手紙 3:15; イザヤ書 55:3"> ですから、聖霊がこう言われるとおりです。<br /><span className="pl pl-1">「今日、あなたがたがその声を聞くなら、</span></span>
<span className="v" id="v8" data-v="8" data-xref="箴言 28:14; 出エジプト記 17:7; ゼカリヤ書 7:11–12"> <span className="pl pl-2">荒野で試みた日、反逆した時のように、</span><br /><span className="pl pl-2">心をかたくなにしてはならない。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="使徒の働き 7:36; 申命記 4:9; 出エジプト記 19:4"> <span className="pl pl-2">その場所で、あなたがたの父祖たちはわたしを試し、わたしを試み、</span><br /><span className="pl pl-2">四十年にわたって、わたしの業を見た。</span></span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 95:10; テサロニケ人への第二の手紙 2:10–12; 詩篇 67:2"> <span className="pl pl-1">それゆえ、わたしはその世代に憤り、</span><br /><span className="pl pl-2">『彼らはいつも心が迷い、</span><br /><span className="pl pl-2">わたしの道を知らなかった』と言った。</span></span>
<span className="v" id="v11" data-v="11" data-xref="申命記 1:34–35; ヘブル人への手紙 4:3; 民数記 32:10–13"> <span className="pl pl-1">それで、わたしは怒りのうちに誓った。</span><br /><span className="pl pl-2">『彼らは決して、わたしの安息に入ることはない。』」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="エレミヤ書 17:5; エレミヤ書 7:24; エレミヤ書 17:9"> 兄弟たち、あなたがたのうちのだれにも、生ける神から離れ去るような、不信仰の悪い心がないように気をつけなさい。</span>
<span className="v" id="v13" data-v="13" data-xref="テサロニケ人への手紙第一 5:11; ヘブル人への手紙 10:24–25; テモテへの第二の手紙 4:2"> 「今日」と呼ばれている間、毎日互いに励まし合いなさい。あなたがたのだれも、罪の欺きによって心をかたくなにされないためです。</span>
<span className="v" id="v14" data-v="14" data-xref="ヘブル人への手紙 3:6; ヘブル人への手紙 6:11; ヘブル人への手紙 12:10"> 私たちは、初めに抱いた確信を終わりまでしっかり保つなら、キリストにあずかる者となっているのです。</span>
<span className="v" id="v15" data-v="15" data-xref="ヘブル人への手紙 3:7–8; 詩篇 95:7; ヘブル人への手紙 10:38"> こう言われているとおりです。<br /><span className="pl pl-1">「今日、あなたがたがその声を聞くなら、</span><br /><span className="pl pl-2">反逆した時のように、心をかたくなにしてはならない。」</span></span>
</div>
<div className="bp">

<span className="v" id="v17" data-v="17" data-xref="民数記 14:29; 民数記 26:64–65; 民数記 14:32–33"> 神が四十年の間、憤られたのはだれに対してでしたか。罪を犯し、その死体が荒野に倒れた人々に対してではありませんか。</span>
<span className="v" id="v18" data-v="18" data-xref="民数記 14:30; ヘブル人への手紙 4:6; 申命記 1:34–35"> ご自分の安息に決して入らせないと神が誓われたのは、従わなかった人々に対してではありませんか。</span>

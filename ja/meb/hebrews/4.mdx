<span className="v" id="v1" data-v="1" data-xref="ヘブル人への手紙 12:15; ヘブル人への手紙 4:9; 箴言 28:14"> ですから、神の安息に入るという約束がなお残されている以上、あなたがたのうちに、その約束に届かなかったと思われる者が一人もないよう、恐れ慎もうではありませんか。</span>
<span className="v" id="v2" data-v="2" data-xref="テサロニケ人への手紙第一 2:13; ローマ人への手紙 10:16–17; ヘブル人への手紙 11:6"> 私たちにも、彼らと同じように福音が告げ知らされました。しかし、彼らが聞いた言葉は役に立ちませんでした。聞いた人々のうちで、その言葉が信仰と結びつかなかったからです。</span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 95:11; マタイ 11:28–29; ペテロの手紙第一 1:20"> 信じた私たちは、その安息に入るのです。神が「わたしは怒りのうちに誓った。『彼らは決して、わたしの安息に入ることはない』」と言われたとおりです。もっとも、神の業は世界の基が据えられた時からすでに完成していました。</span>
<span className="v" id="v4" data-v="4" data-xref="出エジプト記 20:11; 出エジプト記 31:17; 創世記 2:1–2"> 七日目について、ある箇所でこう言われています。「神は七日目に、すべての業を終えて休まれた。」</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 95:11; ヘブル人への手紙 4:3; ヘブル人への手紙 3:11"> そして、この箇所では再び、「彼らは決して、わたしの安息に入ることはない」と言われています。</span>
</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="マタイ 21:43; ヘブル人への手紙 3:18–19; 使徒の働き 13:46–47"> ですから、そこに入るべき人々がなお残っており、以前に福音を告げ知らされた人々は不従順のために入れなかったのです。</span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 95:7; ヘブル人への手紙 3:7–8; ヘブル人への手紙 3:15"> そこで神は、長い時を経た後、ダビデを通して再び「今日」という日を定め、先に引用したとおり、こう語られました。<br /><span className="pl pl-1">「今日、あなたがたがその声を聞くなら、</span><br /><span className="pl pl-2">心をかたくなにしてはならない。」</span></span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="ヨシュア記 1:15; ヨシュア記 22:4; 申命記 12:9"> もしヨシュアが彼らに安息を与えていたなら、神はその後に別の日について語られることはなかったでしょう。</span>
<span className="v" id="v9" data-v="9" data-xref="ペテロの手紙第一 2:10; ヨハネの黙示録 21:4; ヨハネの黙示録 7:14–17"> したがって、神の民には安息日の休みがなお残されています。</span>
<span className="v" id="v10" data-v="10" data-xref="ヨハネの黙示録 14:13; ヘブル人への手紙 4:3–4; ペテロの手紙第一 4:1–2"> 神の安息に入った者は、神がご自分の業を終えて休まれたように、自分の業を終えて休んでいるからです。</span>
<span className="v" id="v11" data-v="11" data-xref="マタイ 11:28–30; ルカ 13:24; ヘブル人への手紙 3:18–1"> ですから、その安息に入るために力を尽くそうではありませんか。だれも同じ不従順に陥って倒れることのないためです。</span>
<span className="v" id="v12" data-v="12" data-xref="エレミヤ書 23:29; イザヤ書 55:11; エペソ人への手紙 6:17"> 神の言葉は生きていて力があり、どんな両刃の剣よりも鋭く、魂と霊、関節と骨髄を切り分けるまでに刺し通し、心の思いと意図を見分けます。</span>
<span className="v" id="v13" data-v="13" data-xref="コリント人への第一の手紙 4:5; 詩篇 33:13–15; 箴言 15:3"> 神の目から隠れている被造物は一つもありません。すべてのものが、私たちが申し開きをしなければならない方の目の前に、裸であらわにされています。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="ヘブル人への手紙 9:24; ヘブル人への手紙 12:2; ヘブル人への手紙 9:12"> ですから、もろもろの天を通って行かれた偉大な大祭司、神の御子イエスがおられるのですから、私たちの信仰告白を堅く保とうではありませんか。</span>
<span className="v" id="v15" data-v="15" data-xref="ヘブル人への手紙 2:17–18; コリント人への第二の手紙 5:21; イザヤ書 53:4–5"> 私たちの大祭司は、私たちの弱さに同情できない方ではありません。罪は犯されませんでしたが、あらゆる点で私たちと同じように試みを受けられた方です。</span>
<span className="v" id="v16" data-v="16" data-xref="エペソ人への手紙 3:12; ヘブル人への手紙 7:25; ヘブル人への手紙 10:19–23"> ですから、あわれみを受け、必要な時に助けとなる恵みを見いだすために、大胆に恵みの王座に近づこうではありませんか。</span>
</div>

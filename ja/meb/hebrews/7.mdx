<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 14:18–20; 詩篇 57:2; ヘブル人への手紙 6:20"> このメルキゼデクはサレムの王、いと高き神の祭司であり、王たちを討ち破って帰るアブラハムを迎え、祝福した人です。</span>
<span className="v" id="v2" data-v="2" data-xref="民数記 18:21; 詩篇 85:10–11; サムエル記第一 8:17"> アブラハムは彼に、すべてのものの十分の一を分け与えました。その名は、訳せば、まず「義の王」、次に「サレムの王」、すなわち「平和の王」です。</span>
<span className="v" id="v3" data-v="3" data-xref="ヘブル人への手紙 7:17; ヘブル人への手紙 7:23–28; 出エジプト記 6:20–27"> 彼には父もなく、母もなく、系図もなく、生涯の始まりも命の終わりもありません。神の御子に似た者とされ、いつまでも祭司であり続けます。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="創世記 14:20; 使徒の働き 2:29; 使徒の働き 7:8–9"> この人がどれほど偉大であったか、考えてみなさい。族長アブラハムでさえ、最上の戦利品の十分の一を彼に与えました。</span>
<span className="v" id="v5" data-v="5" data-xref="レビ記 27:30–33; 歴代誌 第二 31:4–6; 民数記 18:21–32"> レビの子孫のうち祭司職を受ける者たちは、律法に従って民から、すなわち、同じアブラハムの子孫である自分たちの兄弟から、十分の一を受け取るよう命じられています。</span>
<span className="v" id="v6" data-v="6" data-xref="ローマ人への手紙 4:13; ヘブル人への手紙 7:3–4; 創世記 13:14–17"> しかし、彼らの系図に属さないメルキゼデクは、アブラハムから十分の一を受け取り、約束を与えられていたアブラハムを祝福しました。</span>
<span className="v" id="v7" data-v="7" data-xref="歴代誌 第二 30:27; 創世記 48:15–20; テモテへの手紙第一 3:16"> 言うまでもなく、より小さい者が、より大きい者から祝福を受けます。</span>
<span className="v" id="v8" data-v="8" data-xref="ヘブル人への手紙 6:20; ヘブル人への手紙 5:6; ヨハネの黙示録 1:18"> こちらでは、死ぬべき人々が十分の一を受け取りますが、あちらでは、生きているとあかしされている者が受け取ります。</span>
<span className="v" id="v9" data-v="9" data-xref="ローマ人への手紙 5:12; 創世記 14:20; ヘブル人への手紙 7:4"> さらに言えば、十分の一を受け取るレビでさえ、アブラハムを通して十分の一を納めたことになります。</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 35:11; ヘブル人への手紙 7:5; 創世記 46:26"> メルキゼデクがアブラハムを迎えた時、レビはまだ祖先アブラハムのうちにいたからです。</span>
</div>
<div className="bp poetry">
<span className="v" id="v11" data-v="11" data-xref="ヘブル人への手紙 8:7; ガラテヤ人への手紙 2:21; ガラテヤ人への手紙 4:9"> さて、レビ系の祭司職によって完全に達することができたのなら――民はその祭司職のもとで律法を受けたのですが――なぜ、アロンの位に従うとは呼ばれず、メルキゼデクの位に従う別の祭司が立てられる必要があったのでしょうか。</span>
<span className="v" id="v12" data-v="12" data-xref="エレミヤ書 31:31–34; イザヤ書 66:21; エゼキエル書 16:61"> 祭司職が変わるなら、律法も必然的に変えられます。</span>
<span className="v" id="v13" data-v="13" data-xref="ヘブル人への手紙 7:11; ヘブル人への手紙 7:14; 民数記 17:5"> これらのことを言われている方は別の部族に属し、その部族からはだれも祭壇で務めたことがありません。</span>
<span className="v" id="v14" data-v="14" data-xref="ミカ書 5:2; イザヤ書 11:1; ルカ 3:33"> 私たちの主がユダから出られたことは明らかです。モーセはこの部族について、祭司職に関することを何も語りませんでした。</span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 110:4; ヘブル人への手紙 7:17–21; ヘブル人への手紙 7:3"> そして、メルキゼデクに似た別の祭司が立てられるなら、このことはいっそう明らかです。</span>
<span className="v" id="v16" data-v="16" data-xref="ヨハネの黙示録 1:18; コロサイ人への手紙 2:20; ヘブル人への手紙 7:28"> その方は、肉体に属する戒めの規定によってではなく、尽きることのない命の力によって祭司となられました。</span>
<span className="v" id="v17" data-v="17" data-xref="詩篇 110:4; ヘブル人への手紙 5:6; ヘブル人への手紙 7:21"> こうあかしされているからです。<br /><span className="pl pl-1">「あなたは永遠に祭司である。</span><br /><span className="pl pl-2">メルキゼデクの位に従う祭司である。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v18" data-v="18" data-xref="ローマ人への手紙 8:3; 使徒の働き 13:39; ガラテヤ人への手紙 4:9"> 以前の戒めは、弱く役に立たないために廃止されます。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒の働き 13:39; ヘブル人への手紙 4:16; ヘブル人への手紙 9:9"> 律法は何一つ完全にしなかったからです。その一方で、もっと優れた希望がもたらされ、その希望によって私たちは神に近づきます。</span>
<span className="v" id="v20" data-v="20" data-xref="民数記 18:7; ヘブル人への手紙 5:6; 詩篇 110:4"> しかも、イエスが祭司とされたのは誓いなしではありませんでした。</span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 110:4; ヘブル人への手紙 7:17; ヘブル人への手紙 6:16–18"> ほかの人々は誓いなしに祭司となりましたが、イエスはご自分についてこう言われた方の誓いによって祭司とされました。<br /><span className="pl pl-1">「主は誓い、御心を変えられない。</span><br /><span className="pl pl-2">『あなたは永遠に祭司である。</span><br /><span className="pl pl-2">メルキゼデクの位に従う祭司である。』」</span></span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="コリント人への第一の手紙 11:25; 創世記 44:32; ヘブル人への手紙 8:6–12"> この誓いのゆえに、イエスはそれだけ優れた契約の保証となられました。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="ネヘミヤ記 12:10–11; 歴代誌上 6:3–14; ヘブル人への手紙 7:8"> また、以前の祭司たちは、死によって務めを続けられないため、大勢いました。</span>
<span className="v" id="v24" data-v="24" data-xref="ヨハネ 12:34; ヘブル人への手紙 7:28; イザヤ書 9:6–7"> しかしイエスは永遠に生きておられるので、その祭司職は変わることがありません。</span>
<span className="v" id="v25" data-v="25" data-xref="ローマ人への手紙 8:34; ヨハネの手紙第一 2:1–2; テモテへの手紙第一 2:5"> それゆえ、ご自分を通して神に近づく人々を完全に救い抜くことがおできになります。彼らのために執り成すため、永遠に生きておられるからです。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="コリント人への第二の手紙 5:21; ヘブル人への手紙 4:14–15; ペテロの手紙第一 2:22"> このような大祭司こそ、私たちにふさわしい方です。聖なる方、罪のない方、汚れのない方、罪人から離され、もろもろの天よりも高くされた方です。</span>
<span className="v" id="v27" data-v="27" data-xref="ヘブル人への手紙 9:28; ヘブル人への手紙 9:12; ヘブル人への手紙 9:14"> この方は、ほかの大祭司たちのように、まず自分の罪のため、次に民の罪のため、毎日いけにえをささげる必要がありません。ご自分をささげた時、ただ一度でこれを成し遂げたからです。</span>
<span className="v" id="v28" data-v="28" data-xref="ヘブル人への手紙 2:10; ヘブル人への手紙 7:21; ヘブル人への手紙 1:2"> 律法は弱さを持つ人々を大祭司に任命します。しかし、律法の後に与えられた誓いの言葉は、永遠に完全な者とされた御子を大祭司に任命します。</span>
</div>

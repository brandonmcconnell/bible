<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出エジプト記 25:8; ヘブル人への手紙 9:10–11; ヘブル人への手紙 8:2"> さて、最初の<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="TRは「幕屋」を加えている。">a</a></sup>契約にも、礼拝に関する規定と地上の聖所がありました。</span>
<span className="v" id="v2" data-v="2" data-xref="出エジプト記 40:4; レビ記 24:5–8; 出エジプト記 26:35"> 幕屋が設けられ、その第一の部分には燭台、机、供えのパンがあり、そこは聖所と呼ばれました。</span>
<span className="v" id="v3" data-v="3" data-xref="出エジプト記 26:31–33; 出エジプト記 40:3; マタイ 27:51"> 第二の垂れ幕の奥には、至聖所と呼ばれる幕屋があり、</span>
<span className="v" id="v4" data-v="4" data-xref="民数記 17:10; 歴代誌 第二 5:10; 出エジプト記 40:3"> そこには金の香壇と、全面を金で覆われた契約の箱がありました。その箱の中には、マナを入れた金の壺、芽を出したアロンの杖、契約の板がありました。</span>
<span className="v" id="v5" data-v="5" data-xref="レビ記 16:2; 民数記 7:89; 出エジプト記 25:17–22"> 箱の上には、贖罪の蓋を覆う栄光のケルビムがありました。しかし今は、これらについて詳しく語ることはできません。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="民数記 28:3; 出エジプト記 27:21; ルカ 1:8–11"> これらのものがこのように整えられると、祭司たちは第一の幕屋に絶えず入り、礼拝の務めを果たします。</span>
<span className="v" id="v7" data-v="7" data-xref="レビ記 16:34; レビ記 5:18; ヘブル人への手紙 10:19–20"> しかし第二の幕屋には、大祭司だけが年に一度入ります。しかも、自分自身と民の過ちのためにささげる血を携えずに入ることはありません。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨハネ 14:6; ヘブル人への手紙 3:7; ヘブル人への手紙 10:19–22"> 聖霊はこれによって、第一の幕屋が立っている間は、聖所への道がまだ明らかにされていなかったことを示しておられます。</span>
<span className="v" id="v9" data-v="9" data-xref="ペテロの手紙第一 3:21; ヘブル人への手紙 5:1; ローマ人への手紙 5:14"> この幕屋は、今の時代を示す象徴です。そこでは供え物といけにえがささげられますが、それらは礼拝する人の良心を完全にすることができません。</span>
<span className="v" id="v10" data-v="10" data-xref="エペソ人への手紙 2:15; コロサイ人への手紙 2:16; レビ記 11:2–47"> それらは、食物、飲み物、さまざまな洗いに関する肉体上の規定にすぎず、物事が改められる時まで課されているものです。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="ヘブル人への手紙 9:23–24; コリント人への第二の手紙 5:1; ヘブル人への手紙 8:1–2"> しかしキリストは、来たるべき良いものの大祭司として来られ、人の手で造られたのではない、すなわちこの被造世界に属さない、より偉大で完全な幕屋を通り、</span>
<span className="v" id="v12" data-v="12" data-xref="ヘブル人への手紙 10:4; ペテロの手紙第一 1:18–19; ヘブル人への手紙 9:15"> やぎや子牛の血によってではなく、ご自分の血によって、ただ一度聖所に入り、永遠の贖いを成し遂げられました。</span>
<span className="v" id="v13" data-v="13" data-xref="民数記 19:2–21; レビ記 16:14–16; 使徒の働き 15:9"> やぎと雄牛の血、また若い雌牛の灰を汚れた人々に振りかけることで、肉体が清められ、聖なる者とされるのなら、</span>
<span className="v" id="v14" data-v="14" data-xref="ヘブル人への手紙 10:22; ペテロの手紙第一 1:19; ヨハネの手紙第一 1:7"> まして、永遠の霊によって、傷のないご自分を神にささげたキリストの血は、生ける神に仕えるために、あなたがたの良心を死んだ行いからどれほど清めてくださることでしょう。</span>
<span className="v" id="v15" data-v="15" data-xref="ローマ人への手紙 3:24–26; ローマ人への手紙 8:30; ローマ人への手紙 8:28"> それゆえ、キリストは新しい契約の仲介者です。最初の契約のもとで犯された違反を贖うためにキリストが死なれたので、召された人々は約束された永遠の相続財産を受けられるのです。</span>
<span className="v" id="v16" data-v="16" data-xref="ヤコブの手紙 2:10; コリント人への第一の手紙 15:22; ローマ人への手紙 5:12"> 遺言がある場合には、遺言を作った者が死ななければなりません。</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 48:21; ヨハネ 14:27; ガラテヤ人への手紙 3:15"> 遺言は死によって効力を生じるものであり、作った者が生きている間は決して効力を持たないからです。</span>
<span className="v" id="v18" data-v="18" data-xref="出エジプト記 24:3–8; ヘブル人への手紙 9:14; ヘブル人への手紙 9:22"> そのため、最初の契約も血なしに成立したのではありません。</span>
<span className="v" id="v19" data-v="19" data-xref="出エジプト記 24:5–11; 民数記 19:6; ヘブル人への手紙 10:4"> モーセは律法に従って、すべての戒めを民全体に語った後、水、緋色の羊毛、ヒソプとともに、子牛とやぎの血を取り、巻物そのものと民全体に振りかけ、</span>
<span className="v" id="v20" data-v="20" data-xref="出エジプト記 24:8; マタイ 26:28; ヘブル人への手紙 13:20"> 「これは、神があなたがたに命じられた契約の血である」と言いました。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="レビ記 8:15; レビ記 8:19; 出エジプト記 29:36"> また同じように、幕屋と務めに用いるすべての器にも血を振りかけました。</span>
<span className="v" id="v22" data-v="22" data-xref="レビ記 17:11; レビ記 6:7; レビ記 4:35"> 律法によれば、ほとんどすべてのものが血によって清められます。血が流されなければ、赦しはありません。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="ペテロの手紙第一 1:19–21; ヘブル人への手紙 10:4; ヘブル人への手紙 9:14"> ですから、天にあるものの写しはこれらによって清められる必要がありました。しかし、天にあるもの自体は、これらよりも優れたいけにえによって清められる必要がありました。</span>
<span className="v" id="v24" data-v="24" data-xref="ヘブル人への手紙 12:2; ヘブル人への手紙 9:11–12; ヘブル人への手紙 9:23"> キリストが入られたのは、真の聖所をかたどった人の手による聖所ではなく、天そのものです。今、私たちのために神の御前に現れておられます。</span>
<span className="v" id="v25" data-v="25" data-xref="ヘブル人への手紙 9:12; ヘブル人への手紙 9:7; ヘブル人への手紙 9:14"> また、大祭司が毎年、自分のものではない血を携えて聖所に入るように、キリストがご自分を何度もささげる必要もありません。</span>
<span className="v" id="v26" data-v="26" data-xref="ヘブル人への手紙 9:12; ペテロの手紙第一 1:20; ヘブル人への手紙 1:2"> もしそうなら、世界の基が据えられて以来、何度も苦しみを受けなければならなかったでしょう。しかし今、キリストは、ご自分をいけにえとして罪を取り除くため、時代の終わりにただ一度、現れました。</span>
<span className="v" id="v27" data-v="27" data-xref="コリント人への第二の手紙 5:10; 伝道者の書 12:7; 伝道者の書 12:14"> 人には一度死ぬこと、その後に裁きを受けることが定められているように、</span>
<span className="v" id="v28" data-v="28" data-xref="テトス 2:13; ペテロの手紙第一 2:24; ローマ人への手紙 6:10"> キリストも、多くの人の罪を負うために一度ささげられ、二度目には罪とは関わりなく、ご自分を待ち望む人々を救うために現れます。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命記 33:3; ヨハネ 10:27–30; ペテロの手紙第一 1:5"> 私はこれらすべてを心に留め、そのすべてを探った。義人も知恵ある者も、その行いも、神の手の中にある。愛されるのか憎まれるのか、人には分からない。すべては彼らの行く手にある。</span>
<span className="v" id="v2" data-v="2" data-xref="マラキ書 3:18; 伝道者の書 2:14–16; マラキ書 3:5"> すべての者に同じことが起こる。義人にも悪人にも、善人にも、清い者にも汚れた者にも、いけにえをささげる者にも、ささげない者にも、同じ運命が臨む。善人も罪人も同じであり、誓う者も、誓いを恐れる者も同じである。</span>
<span className="v" id="v3" data-v="3" data-xref="エレミヤ書 17:9; 伝道者の書 8:11; 伝道者の書 1:17"> 日の下で行われるすべてのことの中に、この悪がある。すべての者に同じ運命が臨む。人間の心は悪に満ち、生きている間、その心には狂気がある。その後、彼らは死者のもとへ行く。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨブ記 14:7–12; イザヤ書 38:18; ルカ 16:26–29"> 生きている者の列に加わっている限り、希望がある。生きている犬は、死んだ獅子にまさる。</span>
<span className="v" id="v5" data-v="5" data-xref="イザヤ書 26:14; 伝道者の書 1:11; 詩篇 6:5"> 生きている者は、自分が死ぬことを知っている。しかし、死者は何も知らず、もはや報いを受けることもない。彼らは記憶からも消える。</span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 146:3–4; 伝道者の書 6:12; ヨブ記 3:17–18"> 彼らの愛も憎しみもねたみも、すでに滅び去った。日の下で行われるどのようなことにも、彼らは二度と永遠に関わることがない。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="伝道者の書 3:12–13; 申命記 12:7; 伝道者の書 10:19"> さあ、喜びをもってパンを食べ、楽しい心でぶどう酒を飲みなさい。神はすでにあなたの行いを受け入れておられる。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨハネの黙示録 19:14; ヨハネの黙示録 3:4–5; ヨハネの黙示録 19:8"> あなたの衣をいつも白くし、頭に油を欠かしてはならない。</span>
<span className="v" id="v9" data-v="9" data-xref="箴言 5:18–19; 伝道者の書 2:10; マラキ書 2:15"> 日の下で神があなたに与えた空しい生涯のすべての日々を、愛する妻とともに喜んで暮らしなさい。あなたの空しい生涯のすべての日々において、これが、あなたの人生と日の下での労苦から受ける取り分である。</span>
<span className="v" id="v10" data-v="10" data-xref="コロサイ人への手紙 3:23; エペソ人への手紙 5:16; ローマ人への手紙 12:11"> あなたの手にできることは何でも、力を尽くして行いなさい。あなたが向かっているよみ<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="よみ（シェオル）は死者の場所である。">a</a></sup>には、働きも、計画も、知識も、知恵もないからである。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="エレミヤ書 9:23; 箴言 21:30–31; 哀歌 3:37–38"> 私は再び日の下で見た。競走は速い者のものではなく、戦いは強い者のものでもない。パンは知恵ある者のものではなく、富は悟りある者のものでもなく、好意は熟練した者のものでもない。時と偶然がすべての者に臨むからである。</span>
<span className="v" id="v12" data-v="12" data-xref="テサロニケ人への手紙第一 5:3; ルカ 21:34–36; 伝道者の書 8:5–7"> 人は自分の時を知らない。魚が災いの網に捕らえられ、鳥がわなにかかるように、人間も災いの時が突然襲うと、そのわなに捕らえられる。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="伝道者の書 8:16; 伝道者の書 7:15; 伝道者の書 6:1"> 私はまた、日の下でこのような知恵を見た。それは私には偉大なものと思われた。</span>
<span className="v" id="v14" data-v="14" data-xref="サムエル記第二 20:15–22; 列王記第二 6:24–20"> 小さな町があり、その中にはわずかな人しかいなかった。そこへ大王が攻めて来て、町を包囲し、それに対して大きな攻城塁を築いた。</span>
<span className="v" id="v15" data-v="15" data-xref="伝道者の書 4:13; 創世記 40:23; エステル記 6:2–3"> その町に、貧しいが知恵のある人がいた。彼はその知恵によって町を救った。しかし、その貧しい人を覚えている者は誰もいなかった。</span>
<span className="v" id="v16" data-v="16" data-xref="伝道者の書 7:19; 箴言 24:5; 箴言 21:22"> そこで私は言った。「知恵は力にまさる。」それでも、貧しい人の知恵は軽んじられ、その言葉は聞かれない。</span>
<span className="v" id="v17" data-v="17" data-xref="ヤコブの手紙 3:17–18; 箴言 28:23; ヤコブの手紙 1:20"> 静かに聞かれる知恵ある者の言葉は、愚かな者たちの中で支配する者の叫び声にまさる。</span>
<span className="v" id="v18" data-v="18" data-xref="ヨシュア記 7:11–12; 伝道者の書 9:16; ヨシュア記 7:5"> 知恵は戦いの武器にまさる。しかし、一人の罪人が多くの善を滅ぼす。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨハネの黙示録 14:13; 箴言 22:1; 伝道者の書 4:2"> 良い名は上質な香油にまさり、死ぬ日は生まれる日にまさる。</span>
<span className="v" id="v2" data-v="2" data-xref="詩篇 90:12; 申命記 32:29; ヘブル人への手紙 9:27"> 宴会の家へ行くより、喪の家へ行くほうが良い。死はすべての人の終わりであり、生きている者はそれを心に留めるべきだ。</span>
<span className="v" id="v3" data-v="3" data-xref="コリント人への第二の手紙 7:9–11; ローマ人への手紙 5:3–4; ヤコブの手紙 4:8–10"> 悲しみは笑いにまさる。顔の悲しみが心を整える。</span>
<span className="v" id="v4" data-v="4" data-xref="マタイ 8:14–16; サムエル記第一 25:36; ルカ 7:12–13"> 知恵ある者の心は喪の家にあり、愚かな者の心は喜びの家にある。</span>
<span className="v" id="v5" data-v="5" data-xref="箴言 15:31–32; 詩篇 141:5; ヨハネの黙示録 3:19"> 愚かな者の歌を聞くより、知恵ある者の叱責を聞くほうが良い。</span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 58:9; 詩篇 118:12; 伝道者の書 2:2"> 鍋の下でいばらがはぜる音のように、愚かな者の笑いも空しい。これも空しい。</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 16:19; 出エジプト記 23:8; 箴言 17:23"> 虐げは知恵ある者を愚かにし、賄賂は理解力を滅ぼす。</span>
<span className="v" id="v8" data-v="8" data-xref="ヘブル人への手紙 10:36; 箴言 14:29; 詩篇 126:5–6"> 物事の終わりは、その始まりにまさる。<br />忍耐強い心は、高ぶる心にまさる。</span>
<span className="v" id="v9" data-v="9" data-xref="ヤコブの手紙 1:19; 箴言 14:17; エペソ人への手紙 4:26–27"> 心のうちで性急に怒ってはならない。怒りは愚かな者の胸に宿る。</span>
<span className="v" id="v10" data-v="10" data-xref="士師記 6:13; 詩篇 14:2–3; 創世記 6:11–12"> 「なぜ昔の日々は今より良かったのか」と言ってはならない。それは知恵から出た問いではない。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="伝道者の書 11:7; テモテへの手紙第一 6:17–19; 伝道者の書 2:13"> 知恵は相続財産と同じように良い。実に、太陽を見る者たちにとって、知恵はさらに優れている。</span>
<span className="v" id="v12" data-v="12" data-xref="箴言 8:35; 箴言 2:7; 箴言 3:18"> 知恵は盾となり、金も盾となる。しかし、知識の優れたところは、知恵がそれを持つ者の命を保つことにある。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="伝道者の書 1:15; ヨブ記 12:14; 詩篇 107:43"> 神のみわざをよく考えよ。神が曲げたものを、誰がまっすぐにできるだろう。</span>
<span className="v" id="v14" data-v="14" data-xref="伝道者の書 3:4; 伝道者の書 3:22; 伝道者の書 12:13"> 順境の日には喜び、逆境の日にはよく考えよ。神は一方を他方と並べて造られた。人が自分の後に起こることを何一つ見いだせないように。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="伝道者の書 8:12–14; 伝道者の書 6:12; 詩篇 73:3–13"> 私は空しい生涯の日々に、これらすべてを見た。義を行いながら滅びる義人がおり、悪を行いながら長生きする悪人がいる。</span>
<span className="v" id="v16" data-v="16" data-xref="ローマ人への手紙 12:3; 箴言 25:16; コロサイ人への手紙 2:18"> 自分を正しい者としすぎるな。また、自分を知恵ある者としすぎるな。なぜ自らを滅ぼすのか。</span>
<span className="v" id="v17" data-v="17" data-xref="箴言 10:27; 詩篇 55:23; ヨブ記 22:16"> 悪にふけるな。また、愚かであってはならない。なぜ自分の時が来る前に死ぬのか。</span>
<span className="v" id="v18" data-v="18" data-xref="伝道者の書 12:13; マラキ書 4:2; 伝道者の書 11:6"> 一方をしっかりつかみ、他方からも手を放さないのが良い。神を恐れる者は、そのどちらにも捕らわれない。</span>
<span className="v" id="v19" data-v="19" data-xref="箴言 21:22; コロサイ人への手紙 1:9–11; 箴言 24:5"> 知恵は、町にいる十人の支配者よりも、知恵ある者を強くする。</span>
<span className="v" id="v20" data-v="20" data-xref="ローマ人への手紙 3:23; イザヤ書 53:6; ヨハネの手紙第一 1:8–10"> 地上には、善を行い、罪を犯さない義人は一人もいない。</span>
<span className="v" id="v21" data-v="21" data-xref="箴言 30:10; イザヤ書 29:21; サムエル記第二 16:10"> 人々の語ることに、いちいち心を留めてはならない。自分のしもべがあなたを呪うのを聞くこともある。</span>
<span className="v" id="v22" data-v="22" data-xref="ヤコブの手紙 3:9; マタイ 18:32–35; ヨハネ 8:7–9"> あなた自身も同じように他の人々を呪ったことを、あなたの心は何度も知っているからである。</span>
<span className="v" id="v23" data-v="23" data-xref="ローマ人への手紙 1:22; 創世記 3:5; コリント人への第一の手紙 1:20"> 私はこれらすべてを知恵によって確かめた。私は「知恵ある者になろう」と言ったが、知恵は私から遠く離れていた。</span>
<span className="v" id="v24" data-v="24" data-xref="ローマ人への手紙 11:33; テモテへの手紙第一 6:16; イザヤ書 55:8–9"> 今あるものは遠く、極めて深い。誰がそれを見いだせるだろう。</span>
<span className="v" id="v25" data-v="25" data-xref="伝道者の書 10:13; ヨシュア記 7:13; 伝道者の書 2:20"> 私は向きを変え、心を傾けて、知り、探り、知恵と物事の道理を求め、悪は愚かさであり、愚かさは狂気であることを知ろうとした。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="箴言 22:14; 箴言 5:3–5; 箴言 2:18–19"> 私は、死よりも苦い女を見いだした。その心はわなと網であり、その手は鎖である。神に喜ばれる者は彼女から逃れるが、罪人は彼女に捕らえられる。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="伝道者の書 12:8–10; 伝道者の書 1:1–2"> 伝道者は言う。「見よ、私は一つ一つを照らし合わせ、結論を見いだそうとして、これを見いだした。</span>
<span className="v" id="v28" data-v="28" data-xref="ヨブ記 33:23; 列王記第一 11:1–3; 詩篇 12:1"> 私はなおも求めているが、まだ見いだしていない。私は千人のうちに一人の男を見いだしたが、そのすべてのうちに一人の女も見いださなかった。</span>
<span className="v" id="v29" data-v="29" data-xref="エレミヤ書 4:22; マルコ 7:8–9; テトス 3:3"> 見よ、私が見いだしたのは、ただこれだけである。神は人間をまっすぐな者に造ったが、彼らは多くの策略を考え出した。」</span>
</div>

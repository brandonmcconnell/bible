<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="伝道者の書 3:16; 伝道者の書 5:8; イザヤ書 5:7"> 私は再び、日の下で行われているすべての虐げを見た。見よ、虐げられている者たちの涙があったが、彼らには慰める者がいなかった。彼らを虐げる者たちの側には力があったが、彼らには慰める者がいなかった。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨブ記 3:11–26; 伝道者の書 2:17; 伝道者の書 9:4–6"> そこで私は、まだ生きている者よりも、すでに死んでいる者を幸いだとした。</span>
<span className="v" id="v3" data-v="3" data-xref="ルカ 23:29; 伝道者の書 6:3–5; マタイ 24:19"> しかし、その両者よりも幸いなのは、まだ生まれておらず、日の下で行われる悪い働きを見ていない者である。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネの手紙第一 3:12; 伝道者の書 1:14; 伝道者の書 2:26"> また私は、あらゆる労苦と巧みな仕事が、隣人へのねたみから生じるのを見た。これも空しく、風を追うようなものである。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="イザヤ書 9:20; 箴言 13:4; 箴言 6:10–11"> 愚かな者は腕を組み、自滅する。</span>
<span className="v" id="v6" data-v="6" data-xref="箴言 16:8; 箴言 15:16–17; 詩篇 37:16"> 静けさとともにある片手いっぱいは、労苦して風を追う両手いっぱいにまさる。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="伝道者の書 4:1; 詩篇 78:33; ゼカリヤ書 1:6"> 私は再び、日の下にある空しさを見た。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨハネの手紙第一 2:16; 箴言 27:20; ルカ 12:20"> 一人きりで、息子も兄弟もいない者がいる。その人のすべての労苦には終わりがなく、その目は富を見ても満足しない。「私はいったい誰のために労苦し、自分から楽しみを奪っているのか。」これも空しい。実に、痛ましい務めだ。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="箴言 27:17; 創世記 2:18; コリント人への第一の手紙 12:18–21"> 二人は一人にまさる。二人には、その労苦に対する良い報いがある。</span>
<span className="v" id="v10" data-v="10" data-xref="テサロニケ人への手紙第一 5:11; テサロニケ人への手紙第一 4:18; イザヤ書 35:3–4"> もし倒れても、一人が仲間を起こすことができる。しかし、倒れた時に起こしてくれる者のいない独りの人は災いだ。</span>
<span className="v" id="v11" data-v="11" data-xref="列王記第一 1:1–4"> また、二人が一緒に横になれば暖かくなる。しかし、一人でどうして暖かくなれるだろう。</span>
<span className="v" id="v12" data-v="12" data-xref="ダニエル書 3:16–17; エペソ人への手紙 4:3; サムエル記第二 23:9"> 一人を打ち負かす者がいても、二人ならその者に立ち向かうことができる。三つ撚りの綱は、簡単には切れない。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="歴代誌 第二 25:16; 歴代誌 第二 16:9–10; 箴言 19:1"> もはや忠告を受け入れることも知らない、年老いた愚かな王よりも、貧しくても知恵のある若者のほうが良い。</span>
<span className="v" id="v14" data-v="14" data-xref="詩篇 113:7–8; 創世記 41:14; ヨブ記 5:11"> その若者は牢獄から出て王となった。実に、彼は自分の王国で貧しく生まれた者だった。</span>
<span className="v" id="v15" data-v="15" data-xref="サムエル記第二 15:6"> 私は、日の下を歩むすべての生きている者が、王の後継者となったもう一人の若者に従うのを見た。</span>
<span className="v" id="v16" data-v="16" data-xref="伝道者の書 1:14; 列王記第一 1:40; 伝道者の書 2:17"> 彼に従う民は数え切れなかった。それでも、後の世代は彼を喜ばない。確かに、これも空しく、風を追うようなものである。</span>
</div>

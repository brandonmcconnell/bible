<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ルカ 12:19; 伝道者の書 8:15; ヤコブの手紙 5:5"> 私は心の中で言った。「さあ、楽しみで自分を試し、快楽を味わってみよう。」しかし、見よ、これも空しかった。</span>
<span className="v" id="v2" data-v="2" data-xref="箴言 14:13; 伝道者の書 7:2–6; ペテロの手紙第一 4:2–4"> 私は笑いについて、「これは愚かだ」と言い、楽しみについて、「これは何を成し遂げるのか」と言った。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="箴言 20:1; 伝道者の書 1:17; 箴言 31:4–5"> 私は心の中で、知恵に導かれながら、ぶどう酒で身を楽しませ、愚かさをつかんでみようと探った。人が生きる日の間、天の下で何をするのが良いのかを見極めるためだった。</span>
<span className="v" id="v4" data-v="4" data-xref="列王記第一 7:1–12; 歴代誌 第二 8:11; 歴代誌 第二 26:10"> 私は大きな事業を行った。自分のために家々を建て、ぶどう畑を植えた。</span>
<span className="v" id="v5" data-v="5" data-xref="ルカ 17:27–29; 雅歌 4:12–1; エレミヤ書 39:4"> 自分のために庭園や公園を造り、その中にあらゆる種類の果樹を植えた。</span>
<span className="v" id="v6" data-v="6" data-xref="ネヘミヤ記 2:14; 詩篇 1:3; エレミヤ書 17:8"> 木々が育つ森を潤すために、貯水池を造った。</span>
<span className="v" id="v7" data-v="7" data-xref="列王記第二 3:4; 創世記 15:3; 列王記第一 4:23"> 男の奴隷と女の奴隷を買い、家で生まれた奴隷もいた。また、エルサレムで私より前にいたすべての者にまさるほど、多くの牛や羊の群れを所有した。</span>
<span className="v" id="v8" data-v="8" data-xref="列王記第一 10:10; 列王記第一 9:28; サムエル記第二 19:35"> 自分のために銀と金、王たちや諸州の財宝を集めた。男の歌い手と女の歌い手を得、人間の喜びである、あらゆる種類の楽器も手に入れた。</span>
<span className="v" id="v9" data-v="9" data-xref="歴代誌上 29:25; 伝道者の書 1:16; 列王記第一 10:23"> こうして私は偉大になり、エルサレムで私より前にいたすべての者にまさった。それでも、私の知恵は私のもとにとどまっていた。</span>
<span className="v" id="v10" data-v="10" data-xref="伝道者の書 9:9; 伝道者の書 5:18; 伝道者の書 3:22"> 私は、自分の目が欲するものを何一つ拒まず、自分の心からどんな喜びも遠ざけなかった。すべての労苦が私の心を喜ばせた。それが、すべての労苦から得た私の取り分だった。</span>
<span className="v" id="v11" data-v="11" data-xref="伝道者の書 1:14; ヨハネの手紙第一 2:16–17; 伝道者の書 1:3"> しかし、私は自分の手が行ったすべてのわざと、それを成し遂げるために費やした労苦を振り返った。見よ、すべては空しく、風を追うようなもので、日の下には何の益もなかった。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="伝道者の書 1:17; 伝道者の書 7:25; 伝道者の書 1:9–10"> 私は向きを変え、知恵と狂気と愚かさについて考えた。王の後に来る者に何ができるだろう。昔から行われてきたことを繰り返すだけではないか。</span>
<span className="v" id="v13" data-v="13" data-xref="エペソ人への手紙 5:8; 伝道者の書 7:11–12; マタイ 6:23"> 私は、光が闇にまさるように、知恵が愚かさにまさることを見た。</span>
<span className="v" id="v14" data-v="14" data-xref="詩篇 49:10; 箴言 17:24; 伝道者の書 9:11"> 知恵ある者の目はその頭にあるが、愚かな者は闇の中を歩く。しかし、どちらにも同じ出来事が起こるのを、私は悟った。</span>
<span className="v" id="v15" data-v="15" data-xref="伝道者の書 6:8; 伝道者の書 1:14; 伝道者の書 1:2"> そこで私は心の中で言った。「愚かな者に起こることは、私にも起こる。それなら、なぜ私はこれほど知恵を求めたのか。」私は心の中で、これも空しいと言った。</span>
<span className="v" id="v16" data-v="16" data-xref="伝道者の書 1:11; 伝道者の書 9:5; 詩篇 88:12"> 知恵ある者も愚かな者と同じく、いつまでも記憶されることはない。来るべき日々には、すべてが久しく忘れ去られる。実に、知恵ある者も愚かな者と同じように死ななければならない。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="伝道者の書 2:11; ヨナ書 4:8; 伝道者の書 4:2"> そこで私は生きることを憎んだ。日の下で行われる働きは、私には苦痛だった。すべては空しく、風を追うようなものだった。</span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 39:6; 詩篇 49:10; ルカ 16:27–28"> 私は、日の下で費やしたすべての労苦を憎んだ。それを、私の後に来る者に残さなければならない。</span>
<span className="v" id="v19" data-v="19" data-xref="ヤコブの手紙 3:17; 伝道者の書 3:22; 伝道者の書 9:13"> その者が知恵ある者になるのか、愚かな者になるのか、誰が知っているだろう。それでも、その者は、私が日の下で労苦し、知恵を用いて成し遂げたすべてのものを支配することになる。これも空しい。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="創世記 43:14; ヨブ記 17:11–15; コリント人への第二の手紙 1:8–10"> そこで私は、日の下で費やしたすべての労苦を思い、心は絶望に沈んだ。</span>
<span className="v" id="v21" data-v="21" data-xref="伝道者の書 2:17–18; 歴代誌 第二 31:20–21; 歴代誌 第二 34:2"> 知恵と知識と技能をもって労苦する人がいても、その人は、そのために何も労苦しなかった者に、それを取り分として残さなければならない。これも空しく、大きな悪である。</span>
<span className="v" id="v22" data-v="22" data-xref="詩篇 127:2; 伝道者の書 1:3; ピリピ人への手紙 4:6"> 人は、日の下で費やすすべての労苦と、心を悩ませることから、何を得るのか。</span>
<span className="v" id="v23" data-v="23" data-xref="ヨブ記 14:1; ヨブ記 5:7; 詩篇 6:6–7"> その人のすべての日々は悲しみで、その労苦は苦悩である。夜になっても、その心は休まらない。これも空しい。</span>
<span className="v" id="v24" data-v="24" data-xref="伝道者の書 3:22; 伝道者の書 8:15; テモテへの手紙第一 6:17"> 人にとって、食べて飲み、自分の労苦のうちに良いものを味わうこと以上に良いことはない。これもまた神の手から来ることを、私は見た。</span>
<span className="v" id="v25" data-v="25" data-xref="伝道者の書 2:1–12; 列王記第一 4:21–24"> 私以上に、誰が食べ、誰が楽しむことができるだろう。</span>
<span className="v" id="v26" data-v="26" data-xref="箴言 13:22; ヨブ記 27:16–17; 箴言 28:8"> 神は、ご自分に喜ばれる人には知恵と知識と喜びを与える。しかし罪人には、集めて蓄えさせ、それを神に喜ばれる人に与えさせるという苦労を与える。これも空しく、風を追うようなものである。</span>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヤコブの手紙 1:19; ヘブル人への手紙 12:28–29; 箴言 15:8"> 神の家へ行くときは、自分の足に気をつけよ。愚かな者のようにいけにえをささげるより、近づいて聞くほうが良い。彼らは、自分たちが悪を行っていることさえ知らない。</span>
<span className="v" id="v2" data-v="2" data-xref="マタイ 6:7; 箴言 10:19; イザヤ書 55:9"> 口を軽々しく開いてはならない。神の前で何かを口にしようと、心を急がせてはならない。神は天におられ、あなたは地にいる。それゆえ、言葉を少なくせよ。</span>
<span className="v" id="v3" data-v="3" data-xref="箴言 15:2; 箴言 10:19; 伝道者の書 10:12–14"> 多くの心配から夢が生じるように、多くの言葉から愚かな者の話が生じる。</span>
<span className="v" id="v4" data-v="4" data-xref="民数記 30:2; 申命記 23:21–23; 詩篇 76:11"> 神に誓願を立てるときは、それを果たすのを遅らせてはならない。神は愚かな者を喜ばれない。誓ったことを果たせ。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒の働き 5:4; 申命記 23:22; 箴言 20:25"> 誓願を立てて果たさないよりは、誓願を立てないほうが良い。</span>
<span className="v" id="v6" data-v="6" data-xref="ヤコブの手紙 1:26; ヨハネの手紙第二 1:8; ヤコブの手紙 3:2"> 自分の口によって罪に陥ってはならない。使者の前で、「これは間違いでした」と言ってはならない。なぜあなたの言葉で神を怒らせ、あなたの手の働きを滅ぼされるのか。</span>
<span className="v" id="v7" data-v="7" data-xref="伝道者の書 12:13; マタイ 12:36; 伝道者の書 8:12"> 多くの夢と多くの言葉には空しさがある。だが、あなたは神を恐れよ。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="詩篇 12:5; 伝道者の書 4:1; 伝道者の書 3:16"> ある地方で、貧しい者が虐げられ、裁きと義が踏みにじられているのを見ても、そのことに驚いてはならない。高官はさらに上の者に見張られており、その上にも高官たちがいるからである。</span>
<span className="v" id="v9" data-v="9" data-xref="列王記第一 4:7–23; 詩篇 115:16; 創世記 1:29–30"> 地の産物はすべての者の益となり、王さえ畑に養われる。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="テモテへの手紙第一 6:10; マタイ 6:24; ルカ 12:15"> 銀を愛する者は銀で満足せず、富を愛する者は収入が増えても満足しない。これも空しい。</span>
<span className="v" id="v11" data-v="11" data-xref="ヨハネの手紙第一 2:16; ハバクク書 2:13; 詩篇 119:36–37"> 財産が増えれば、それを食べる者も増える。その所有者にとって、それを目で眺めて楽しむこと以外に何の益があるのか。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="箴言 3:24; 詩篇 4:8; エレミヤ書 31:26"> 働く者の眠りは、食べるものが少なくても多くても心地よい。しかし、富む者はその豊かさのために眠ることができない。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="伝道者の書 6:1–2; ルカ 18:22–23; 創世記 19:14"> 私は日の下で、痛ましい悪を見た。所有者が自分の害となるまで富を蓄えていることである。</span>
<span className="v" id="v14" data-v="14" data-xref="マタイ 6:19–20; ハガイ書 2:16–17; 箴言 23:5"> その富は不幸な出来事によって失われる。彼に息子が生まれても、その手には何も残っていない。</span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 49:17; ヨブ記 1:21; テモテへの手紙第一 6:7"> 人は母の胎から裸で出て来たように、再び裸で去って行く。その労苦によって得たものを、手に携えて行くことはできない。</span>
<span className="v" id="v16" data-v="16" data-xref="箴言 11:29; 伝道者の書 1:3; ヨハネ 6:27"> これも痛ましい悪である。人は来たときと全く同じように去って行く。風を追って労苦する者に、何の益があるのか。</span>
<span className="v" id="v17" data-v="17" data-xref="詩篇 127:2; エゼキエル書 4:16–17; 詩篇 90:7–11"> その人は一生、闇の中で食べ、大いにいらだち、病み、怒る。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="伝道者の書 2:24; 伝道者の書 3:12–13; 伝道者の書 3:22"> 見よ、私が良い、またふさわしいと見たのは、神から与えられた命の日々の間、人が日の下で重ねるすべての労苦のうちに、食べ、飲み、良いものを味わうことである。これがその人の取り分である。</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 8:18; 伝道者の書 3:13; 伝道者の書 6:2"> また、神が富と財産を与え、それを味わい、自分の取り分を受け取り、自分の労苦を喜ぶ力を与えたすべての人にとって、これは神からの賜物である。</span>
<span className="v" id="v20" data-v="20" data-xref="イザヤ書 65:21–24; イザヤ書 65:13–14; 詩篇 37:16"> その人は自分の生涯の日々をあまり思い返すことがない。神がその心を喜びで満たすからである。</span>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="伝道者の書 12:8–10; 伝道者の書 1:12; 伝道者の書 7:27"> ダビデの子で、エルサレムの王であった伝道者の言葉。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="詩篇 144:4; ローマ人への手紙 8:20; 伝道者の書 5:10"> 「空しさの極みだ」と伝道者は言う。「空しさの極みだ。すべては空しい。」</span>
<span className="v" id="v3" data-v="3" data-xref="伝道者の書 3:9; 伝道者の書 5:16; 伝道者の書 2:22"> 人は日の下で重ねるすべての労苦から、何の益を得るのか。</span>
<span className="v" id="v4" data-v="4" data-xref="詩篇 104:5; ゼカリヤ書 1:5; 伝道者の書 6:12"> 世代は去り、世代は来る。しかし、地はいつまでも残る。</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 19:4–6; ハバクク書 3:11; 詩篇 42:1"> 太陽は昇り、太陽は沈み、再び昇る場所へ急いで戻る。</span>
<span className="v" id="v6" data-v="6" data-xref="ヨハネ 3:8; 伝道者の書 11:5; 詩篇 107:25"> 風は南へ吹き、北へ巡り、巡り巡って、またその巡路に戻る。</span>
<span className="v" id="v7" data-v="7" data-xref="ヨブ記 38:10–11; 詩篇 104:6–9"> すべての川は海へ流れ込むが、海は満ちることがない。川は流れ込むその場所へ、絶えず流れ続ける。</span>
<span className="v" id="v8" data-v="8" data-xref="箴言 27:20; マタイ 11:28; 伝道者の書 4:8"> すべては疲れに満ち、言葉では言い尽くせない。目は見ても満足せず、耳は聞いても満たされない。</span>
<span className="v" id="v9" data-v="9" data-xref="伝道者の書 3:15; 伝道者の書 6:10; 伝道者の書 2:12"> かつてあったものは、これからもあり、かつて行われたことは、これからも行われる。日の下に新しいものは何もない。</span>
<span className="v" id="v10" data-v="10" data-xref="使徒の働き 7:51; ルカ 17:26–30; マタイ 23:30–32"> 「見よ、<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「見よ」は、注意を促して「見なさい」「よく見よ」の意味を表す間投詞として用いられる。">a</a></sup>これは新しい」と言えるものがあるだろうか。それは、われわれより前の時代に、すでに存在していた。</span>
<span className="v" id="v11" data-v="11" data-xref="伝道者の書 2:16; 詩篇 9:6; 伝道者の書 9:5"> 先にあったものは覚えられず、後に起こることも、その後に来る者たちには覚えられない。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="伝道者の書 1:1; 列王記第一 4:1–19"> 私、伝道者は、エルサレムでイスラエルの王であった。</span>
<span className="v" id="v13" data-v="13" data-xref="伝道者の書 3:10; 創世記 3:19; テモテへの手紙第一 4:15"> 私は心を傾け、天の下で行われるすべてのことを、知恵によって探り、調べた。これは、神が人に与えて苦労させる重い務めである。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="「神」と訳されたヘブル語は「אֱלֹהִים」（エロヒム）である。">b</a></sup></span>
<span className="v" id="v14" data-v="14" data-xref="伝道者の書 2:11; 伝道者の書 2:17; 伝道者の書 2:26"> 私は日の下で行われるすべてのわざを見た。見よ、すべては空しく、風を追うようなものだった。</span>
<span className="v" id="v15" data-v="15" data-xref="伝道者の書 7:12–13; イザヤ書 40:4; 伝道者の書 3:14"> 曲がったものをまっすぐにすることはできず、欠けているものを数えることもできない。</span>
<span className="v" id="v16" data-v="16" data-xref="伝道者の書 2:9; 列王記第一 4:30; 列王記第一 10:7"> 私は心の中で言った。「見よ、私は、私より前にエルサレムにいたすべての者にまさる、大いなる知恵を得た。私の心は、豊かな知恵と知識を身につけた。」</span>
<span className="v" id="v17" data-v="17" data-xref="伝道者の書 2:3; テサロニケ人への手紙第一 5:21; 伝道者の書 1:13–14"> 私は心を傾け、知恵を究め、狂気と愚かさをも知ろうとした。しかし、これも風を追うようなものだと悟った。</span>
<span className="v" id="v18" data-v="18" data-xref="ヨブ記 28:28; 伝道者の書 12:12–13; コリント人への第一の手紙 3:18–20"> 知恵が増せば悩みも増し、知識を増す者は悲しみを増す。</span>
</div>

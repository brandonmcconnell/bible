<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ペテロの手紙第一 1:5; テサロニケ人への手紙第一 5:23; ペテロの手紙第一 2:9"> ユダ<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="この名は旧約の「ユダ」と同じ名であり、英語では “Jude” と “Judah” を書き分ける。">a</a></sup>、イエス・キリスト<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="「キリスト」は「油を注がれた者」という意味である。">b</a></sup>のしもべであり、ヤコブの兄弟である私から、召された人々、すなわち父なる神によって聖別され、イエス・キリストのために守られている人々へ。</span>
<span className="v" id="v2" data-v="2" data-xref="ペテロの第二の手紙 1:2; ペテロの手紙第一 1:2; ヨハネの黙示録 1:4–6"> あわれみ、平和、愛が、あなたがたにますます豊かに与えられますように。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="テモテへの手紙第一 6:12; ピリピ人への手紙 1:27; ユダ 1:20"> 愛する人たち。私は、私たちが共にあずかる救いについて、ぜひとも書き送りたいと願っていました。しかし、聖徒たちにただ一度伝えられた信仰のために力を尽くして戦うよう、あなたがたを励ます必要を覚え、手紙を書きました。</span>
<span className="v" id="v4" data-v="4" data-xref="ペテロの第二の手紙 2:1–3; ガラテヤ人への手紙 2:4; ペテロの第二の手紙 2:10"> というのも、ある者たちがひそかに入り込んだからです。彼らは、この裁きを受ける者として昔から書き記されていた不敬虔な者たちで、私たちの神の恵みをみだらな行いの口実に変え、私たちの唯一の主人であり、神であり、主であるイエス・キリストを否定しています。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="民数記 26:64–65; ヘブル人への手紙 3:16–2; コリント人への第一の手紙 10:1–12"> あなたがたはすでにこのことを知っていますが、思い起こしてもらいたいのです。主は民をエジプトの地から救い出した後、信じなかった者たちを滅ぼされました。</span>
<span className="v" id="v6" data-v="6" data-xref="ペテロの第二の手紙 2:4; マタイ 25:41; エペソ人への手紙 6:12"> また、自分たちの本来の地位を守らず、自分たちの住まいを捨てた天使たちを、主は大いなる日の裁きのため、暗闇の中に永遠の鎖でつないでおられます。</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 29:23; ペテロの第二の手紙 2:6; ローマ人への手紙 1:26–27"> 同じように、ソドムとゴモラとその周辺の町々も、彼らと同じく性的不道徳に身を任せ、異なる肉体を追い求めたため、永遠の火の刑罰を受け、警告の例として示されています。</span>
<span className="v" id="v8" data-v="8" data-xref="ヘブル人への手紙 13:17; ペテロの手紙第一 2:17; ペテロの第二の手紙 2:10–12"> それにもかかわらず、この者たちも同じように夢想にふけり、肉体を汚し、権威を侮り、天上の者たちをののしっています。</span>
<span className="v" id="v9" data-v="9" data-xref="ゼカリヤ書 3:2; ペテロの第二の手紙 2:11; 申命記 34:6"> しかし、大天使ミカエルは、悪魔と争い、モーセの遺体について論じ合ったときでさえ、侮辱的な断罪の言葉をあえて口にせず、「主がおまえを戒めてくださるように」と言いました。</span>
<span className="v" id="v10" data-v="10" data-xref="ペテロの第二の手紙 2:12; ローマ人への手紙 1:21–22"> ところが、この者たちは自分たちの知らないことをののしります。そして、理性のない生き物のように本能で知る事柄によって、かえって滅びています。</span>
<span className="v" id="v11" data-v="11" data-xref="ペテロの第二の手紙 2:15; ヨハネの手紙第一 3:12; ヨハネの黙示録 2:14"> 彼らに災いあれ。カインの道を進み、報酬を求めてバラムの迷いへと暴走し、コラの反逆に陥って滅びたからです。</span>
<span className="v" id="v12" data-v="12" data-xref="ペテロの第二の手紙 2:17–20; マタイ 15:13; エゼキエル書 34:8"> この者たちは、あなたがたの愛餐に潜む暗礁です。恐れもなくあなたがたと宴を共にし、自分だけを養う羊飼いです。また、風に吹き流される水のない雲、実を結ばない晩秋の木、二度死に、根こそぎにされた木です。</span>
<span className="v" id="v13" data-v="13" data-xref="ペテロの第二の手紙 2:17; ピリピ人への手紙 3:19; イザヤ書 57:20"> 自らの恥を泡のように吹き出す荒れ狂う海の波、彼らのために永遠の暗黒が残されている、さまよう星々です。</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 33:2; 詩篇 50:3–5; ヘブル人への手紙 11:5–6"> アダムから七代目のエノクも、この者たちについて預言して言いました。「見よ、<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="「見よ」はギリシャ語の「ἰδοὺ」に由来し、「見なさい、注意しなさい、観察しなさい、目を向けなさい、じっと見なさい」という意味で、しばしば間投詞として使われる。">c</a></sup>主は幾万もの聖なる者たちを伴って来られた。</span>
<span className="v" id="v15" data-v="15" data-xref="ローマ人への手紙 2:16; 伝道者の書 11:9; コリント人への第一の手紙 4:5"> すべての者を裁き、すべての不敬虔な者を罪に定めるためである。彼らが不敬虔に行ったすべての不敬虔な行いと、不敬虔な罪人たちが主に逆らって語ったすべての不遜な言葉のゆえに。」</span>
<span className="v" id="v16" data-v="16" data-xref="ペテロの第二の手紙 2:18; ペテロの第二の手紙 2:10; ピリピ人への手紙 2:14"> この者たちは不平をつぶやき、境遇に不満を言い、自分の欲望のままに歩みます。口では大言壮語し、利益を得ようと人にこびへつらいます。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="ペテロの第二の手紙 3:2; ヨハネの手紙第一 4:6; エペソ人への手紙 4:11"> しかし、愛する人たち。私たちの主イエス・キリストの使徒たちが以前に語った言葉を思い出しなさい。</span>
<span className="v" id="v18" data-v="18" data-xref="ペテロの第二の手紙 3:3; テモテへの第二の手紙 4:3; テモテへの第二の手紙 3:1–5"> 彼らはあなたがたにこう言いました。「終わりの時には、あざける者たちが現れ、自分自身の不敬虔な欲望のままに歩む。」</span>
<span className="v" id="v19" data-v="19" data-xref="コリント人への第一の手紙 2:14; 箴言 18:1; ローマ人への手紙 8:9"> この者たちは分裂を引き起こし、本能のままに生き、聖霊を持たない者たちです。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="エペソ人への手紙 6:18; ローマ人への手紙 8:26–27; コリント人への第一の手紙 14:15"> しかし、愛する人たち。あなたがたは、最も聖なる信仰の上に自分自身を築き上げ、聖霊によって祈りなさい。</span>
<span className="v" id="v21" data-v="21" data-xref="ヨハネの手紙第一 4:16; 哀歌 3:25–26; ヘブル人への手紙 9:28"> 神の愛のうちに自分自身を保ち、永遠の命に至るまで、私たちの主イエス・キリストのあわれみを待ち望みなさい。</span>
<span className="v" id="v22" data-v="22" data-xref="ヤコブの手紙 5:19–20; ガラテヤ人への手紙 6:1; ヨハネの手紙第一 5:16–18"> ある者たちには、よく見分けてあわれみをかけなさい。</span>
<span className="v" id="v23" data-v="23" data-xref="テモテへの手紙第一 4:16; コリント人への第一の手紙 15:33; ヨハネの黙示録 3:4"> ほかの者たちを、恐れを抱きながら火の中から引き出して救いなさい。肉に汚された衣服さえも忌み嫌いなさい。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="テモテへの第二の手紙 4:18; エペソ人への手紙 3:20; コロサイ人への手紙 1:22"> さて、彼ら<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="TRとNUでは「あなたがた」となっている。">d</a></sup>をつまずかないように守り、あなたがたを傷のない者として、大きな喜びをもってその栄光の御前に立たせることのできる方、</span>
<span className="v" id="v25" data-v="25" data-xref="テモテへの手紙第一 1:17; ヨハネの黙示録 5:13–14; ペテロの手紙第一 5:10–11"> ただひとり知恵ある方、私たちの救い主である神に、栄光と威厳、支配と権威が、今も、そして永遠にありますように。アーメン。</span>
</div>
</div>

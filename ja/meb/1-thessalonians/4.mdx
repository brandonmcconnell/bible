<span className="v" id="v1" data-v="1" data-xref="コロサイ人への手紙 1:10; テサロニケ人への第二の手紙 1:3; ペテロの第二の手紙 3:18"> 最後に、兄弟姉妹、私たちは主イエスにあって、あなたがたにお願いします。また、強く勧めます。どのように歩んで神を喜ばせるべきかを私たちから教えられたとおりに歩み、さらにいっそう励んでください。</span>
<span className="v" id="v2" data-v="2" data-xref="マタイ 28:20; エゼキエル書 3:17; テサロニケ人への第二の手紙 3:10"> 私たちが主イエスによってどのような命令を与えたか、あなたがたは知っています。</span>
<span className="v" id="v3" data-v="3" data-xref="ペテロの手紙第一 4:2; ローマ人への手紙 12:2; テサロニケ人への手紙第一 5:23"> 神のみこころは、あなたがたが聖なる者とされることです。すなわち、性的な不品行を避け、</span>
<span className="v" id="v4" data-v="4" data-xref="コリント人への第一の手紙 7:9; ローマ人への手紙 12:1; ヘブル人への手紙 13:4"> あなたがた一人ひとりが、聖さと尊厳をもって自分の体を治めるすべを知り、<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="直訳では「自分の器を所有する」。">a</a></sup></span>
<span className="v" id="v5" data-v="5" data-xref="ガラテヤ人への手紙 4:8; 使徒の働き 17:30–31; エペソ人への手紙 4:17–19"> 神を知らない異邦人のように、欲情のままに身を任せないことです。</span>
<span className="v" id="v6" data-v="6" data-xref="ヘブル人への手紙 13:4; 出エジプト記 20:17; ローマ人への手紙 12:19"> また、このことで兄弟姉妹を欺き、その権利を侵してはなりません。以前にも警告し、厳かに証言したように、主はこのようなことすべてに対して正しく報いられる方だからです。</span>
<span className="v" id="v7" data-v="7" data-xref="レビ記 11:44; エペソ人への手紙 1:4; ペテロの手紙第一 2:9–12"> 神が私たちを召されたのは、汚れた生き方のためではなく、聖なる生き方のためです。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨハネの手紙第一 3:24; ルカ 10:16; ヨハネ 12:48"> ですから、このことを退ける者は、人を退けるのではなく、ご自分の聖霊をあなたがたに与えてくださった神を退けるのです。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="ヨハネの手紙第一 3:11; ローマ人への手紙 12:10; ヨハネの手紙第一 3:23"> 兄弟愛については、あなたがたに書き送る必要はありません。互いに愛し合うことを、あなたがた自身が神から教えられているからです。</span>
<span className="v" id="v10" data-v="10" data-xref="ピリピ人への手紙 1:9; テサロニケ人への手紙第一 3:12; テサロニケ人への第二の手紙 1:3"> 実際、あなたがたはマケドニア全土のすべての兄弟姉妹に対して、その愛を実践しています。しかし兄弟姉妹、私たちは、その愛をさらに豊かにするよう、あなたがたに勧めます。</span>
<span className="v" id="v11" data-v="11" data-xref="伝道者の書 4:6; エペソ人への手紙 4:28; ペテロの手紙第一 3:4"> また、静かに暮らすことを志し、自分のことに専念し、私たちが指示したとおり、自分の手で働いてください。</span>
<span className="v" id="v12" data-v="12" data-xref="コロサイ人への手紙 4:5; ペテロの手紙第一 2:12; ローマ人への手紙 12:17"> それは、教会の外の人々に対して品位をもって歩み、何にも事欠かないためです。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="ダニエル書 12:2; テサロニケ人への手紙第一 4:15; テサロニケ人への手紙第一 5:10"> 兄弟姉妹、眠りについた人々について、あなたがたに知らないままでいてほしくありません。希望を持たないほかの人々のように悲しまないためです。</span>
<span className="v" id="v14" data-v="14" data-xref="ローマ人への手紙 8:11; ピリピ人への手紙 3:20–21; イザヤ書 26:19"> 私たちは、イエスが死んでよみがえられたと信じています。それと同じように、神は、イエスにあって眠りについた人々を、イエスとともに連れて来てくださいます。</span>
<span className="v" id="v15" data-v="15" data-xref="コリント人への第一の手紙 15:51–53; コリント人への第二の手紙 4:14; テサロニケ人への手紙第一 2:19"> 私たちは主のことばによって、あなたがたにこのことを告げます。主が来られる時まで生き残っている私たちが、眠りについた人々に先立つことは決してありません。</span>
<span className="v" id="v16" data-v="16" data-xref="コリント人への第一の手紙 15:51–52; ヨハネの黙示録 1:7; マタイ 24:30–31"> 主ご自身が、号令と、大天使の声と、神のラッパの響きとともに、天から下って来られるからです。キリストにある死者がまずよみがえり、</span>
<span className="v" id="v17" data-v="17" data-xref="コリント人への第一の手紙 15:52; ヨハネの黙示録 11:12; ヨハネ 14:3"> それから、生き残っている私たちが彼らとともに雲の中へ引き上げられ、空中で主を迎えます。こうして、私たちはいつまでも主とともにいるのです。</span>
<span className="v" id="v18" data-v="18" data-xref="テサロニケ人への手紙第一 5:11; ルカ 21:28; テサロニケ人への手紙第一 5:14"> ですから、これらの言葉をもって互いに慰め合いなさい。</span>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒の働き 1:7; テサロニケ人への手紙第一 4:9; マタイ 24:36"> 兄弟姉妹、その時と時期については、あなたがたに書き送る必要はありません。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネの黙示録 16:15; ペテロの第二の手紙 3:10; マタイ 24:42–44"> 主の日が夜の盗人のように来ることを、あなたがた自身がよく知っているからです。</span>
<span className="v" id="v3" data-v="3" data-xref="ルカ 21:34–35; マタイ 24:37–39; ルカ 17:26–30"> 人々が「平和だ。安全だ」と言っているその時、妊婦に産みの苦しみが臨むように、突然の滅びが彼らに襲いかかり、決して逃れることはできません。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネの手紙第一 2:8; ペテロの第二の手紙 3:10; 申命記 19:6"> しかし兄弟姉妹、あなたがたは闇の中にはいません。ですから、その日が盗人のように不意にあなたがたを襲うことはありません。</span>
<span className="v" id="v5" data-v="5" data-xref="エペソ人への手紙 5:8; 使徒の働き 26:18; ヨハネ 12:36"> あなたがたは皆、光の子、昼の子だからです。私たちは夜にも闇にも属していません。</span>
<span className="v" id="v6" data-v="6" data-xref="ペテロの手紙第一 1:13; マタイ 24:42; ルカ 22:46"> ですから、ほかの人々のように眠っていないで、目を覚まし、身を慎んでいましょう。</span>
<span className="v" id="v7" data-v="7" data-xref="ローマ人への手紙 13:13; コリント人への第一の手紙 15:34; ペテロの第二の手紙 2:13"> 眠る者は夜眠り、酒に酔う者は夜酔うものです。</span>
<span className="v" id="v8" data-v="8" data-xref="ローマ人への手紙 13:12–13; エペソ人への手紙 6:11; ペテロの手紙第一 1:13"> しかし、私たちは昼に属しているのですから、信仰と愛を胸当てに、救いの希望をかぶとにして、身を慎んでいましょう。</span>
<span className="v" id="v9" data-v="9" data-xref="テサロニケ人への手紙第一 1:10; ペテロの手紙第一 2:10; テモテへの第二の手紙 2:10"> 神が私たちを定められたのは、怒りを受けるためではなく、私たちの主イエス・キリストによって救いを得るためです。</span>
<span className="v" id="v10" data-v="10" data-xref="ローマ人への手紙 14:8–9; ペテロの手紙第一 3:18; ローマ人への手紙 8:34"> キリストが私たちのために死なれたのは、私たちが目覚めていても眠っていても、キリストとともに生きるためです。</span>
<span className="v" id="v11" data-v="11" data-xref="エペソ人への手紙 4:29; ヘブル人への手紙 10:25; ローマ人への手紙 15:2"> ですから、今もしているように、互いに励まし合い、互いを建て上げなさい。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="ヘブル人への手紙 13:17; ヘブル人への手紙 13:7; テモテへの手紙第一 5:17–18"> 兄弟姉妹、あなたがたの間で労苦し、主にあってあなたがたを導き、戒めている人々を認めてください。</span>
<span className="v" id="v13" data-v="13" data-xref="マルコ 9:50; ヘブル人への手紙 12:14; ガラテヤ人への手紙 6:6"> また、その働きのゆえに、愛をもって彼らをこの上なく尊敬してください。<br />互いに平和に過ごしなさい。</span>
<span className="v" id="v14" data-v="14" data-xref="テモテへの第二の手紙 4:2; ローマ人への手紙 14:1; 使徒の働き 20:35"> 兄弟姉妹、私たちはあなたがたに勧めます。秩序を乱す者を戒め、気落ちしている者を励まし、弱い者を支え、すべての人に忍耐強く接しなさい。</span>
<span className="v" id="v15" data-v="15" data-xref="ペテロの手紙第一 3:9; ガラテヤ人への手紙 6:10; レビ記 19:18"> だれも、だれに対しても、悪に悪を返すことがないように気をつけなさい。いつも互いのため、またすべての人のために、良いことを追い求めなさい。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="ローマ人への手紙 12:12; ピリピ人への手紙 4:4; マタイ 5:12"> いつも喜んでいなさい。</span>
<span className="v" id="v17" data-v="17" data-xref="ローマ人への手紙 12:12; コロサイ人への手紙 4:2; エペソ人への手紙 6:18"> 絶えず祈りなさい。</span>
<span className="v" id="v18" data-v="18" data-xref="エペソ人への手紙 5:20; ピリピ人への手紙 4:6; コロサイ人への手紙 3:17"> すべてのことにおいて感謝しなさい。これが、キリスト・イエスにあってあなたがたに対する神のみこころです。</span>
<span className="v" id="v19" data-v="19" data-xref="エペソ人への手紙 4:30; 使徒の働き 7:51; テモテへの第二の手紙 1:6"> 聖霊を消してはならない。</span>
<span className="v" id="v20" data-v="20" data-xref="コリント人への第一の手紙 14:3–6; コリント人への第一の手紙 14:1; 民数記 11:25–29"> 預言を軽んじてはならない。</span>
<span className="v" id="v21" data-v="21" data-xref="ヨハネの手紙第一 4:1; ローマ人への手紙 12:2; エペソ人への手紙 5:10"> すべてのことを吟味し、良いものをしっかり保ちなさい。</span>
<span className="v" id="v22" data-v="22" data-xref="コリント人への第二の手紙 6:3; ピリピ人への手紙 4:8; コリント人への第一の手紙 10:31–33"> あらゆる種類の悪から遠ざかりなさい。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="ユダ 1:24; ヘブル人への手紙 4:12; コリント人への第一の手紙 1:8–9"> どうか、平和の神ご自身が、あなたがたを完全に聖なる者としてくださいますように。あなたがたの霊も魂も体も、そのすべてが、私たちの主イエス・キリストが来られるとき、非難されるところなく守られていますように。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="テサロニケ人への第二の手紙 3:3; 民数記 23:19; コリント人への第一の手紙 1:9"> あなたがたを召してくださる方は真実な方であり、必ずそれを成し遂げてくださいます。</span>
</div>

<span className="v" id="v25" data-v="25" data-xref="ヘブル人への手紙 13:18–19; ピリピ人への手紙 1:19; フィレモンへの手紙 1:22"> 兄弟姉妹、私たちのために祈ってください。</span>
</div>

<span className="v" id="v27" data-v="27" data-xref="コロサイ人への手紙 4:16; 使徒の働き 19:13; テモテへの手紙第一 1:3"> この手紙をすべての聖なる兄弟姉妹に読んで聞かせるよう、私は主によってあなたがたに厳かに命じます。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="ローマ人への手紙 16:20; テサロニケ人への第二の手紙 3:18; ローマ人への手紙 16:23"> 私たちの主イエス・キリストの恵みが、あなたがたとともにありますように。アーメン。</span>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="テサロニケ人への第二の手紙 3:1; コリント人への第一の手紙 15:2; コリント人への第一の手紙 15:58"> 兄弟姉妹、私たちがあなたがたのもとを訪れたことは無駄ではなかったと、あなたがた自身が知っています。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒の働き 16:22–24; 使徒の働き 4:13; 使徒の働き 17:2–9"> あなたがたも知っているように、私たちはその前にフィリピで苦しみに遭い、辱められました。それでも、激しい闘いの中で、私たちの神にあって大胆になり、神の福音をあなたがたに語りました。</span>
<span className="v" id="v3" data-v="3" data-xref="コリント人への第二の手紙 2:17; コリント人への第二の手紙 4:2; テサロニケ人への手紙第一 4:7"> 私たちの勧めは、誤りから出たものでも、汚れた動機によるものでも、欺こうとするものでもありません。</span>
<span className="v" id="v4" data-v="4" data-xref="ガラテヤ人への手紙 1:10; ローマ人への手紙 8:27; ガラテヤ人への手紙 2:7"> むしろ私たちは、福音を委ねるにふさわしい者と神に認められたので、そのように語っています。人を喜ばせるためではなく、私たちの心をお調べになる神に喜ばれるためです。</span>
<span className="v" id="v5" data-v="5" data-xref="ローマ人への手紙 1:9; コリント人への第二の手紙 12:17; 使徒の働き 20:33"> あなたがたが知っているとおり、私たちはへつらいの言葉を用いたことも、貪欲を覆い隠す口実を設けたこともありません。神がその証人です。</span>
<span className="v" id="v6" data-v="6" data-xref="ガラテヤ人への手紙 1:10; テサロニケ人への手紙第一 2:9; ヨハネ 5:41"> また、あなたがたからも、ほかの人々からも、人からの栄誉を求めませんでした。キリストの使徒として権威を主張することもできましたが、そうはしませんでした。</span>
<span className="v" id="v7" data-v="7" data-xref="イザヤ書 66:13; テサロニケ人への手紙第一 2:11; テモテへの第二の手紙 2:24–25"> かえって、あなたがたの間で穏やかに振る舞いました。乳を与える母が自分の子どもを慈しむように、あなたがたを慈しんだのです。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="ヨハネの手紙第一 3:16; コリント人への第二の手紙 12:15; ピリピ人への手紙 2:17"> そのようにあなたがたを深く慕い、神の福音だけでなく、私たち自身をも喜んで差し出したいと思いました。あなたがたが、私たちにとってかけがえのない者となったからです。</span>
<span className="v" id="v9" data-v="9" data-xref="テサロニケ人への第二の手紙 3:7–9; コリント人への第二の手紙 11:9; 使徒の働き 18:3"> 兄弟姉妹、あなたがたは私たちの労苦と骨折りを覚えているでしょう。私たちはだれにも負担をかけないよう、夜も昼も働きながら、神の福音をあなたがたに宣べ伝えました。</span>
<span className="v" id="v10" data-v="10" data-xref="ペテロの手紙第一 5:3; テサロニケ人への手紙第一 1:5; コリント人への第二の手紙 1:12"> 信じているあなたがたに対して、私たちがどれほど聖く、正しく、非難されるところなく振る舞ったかは、あなたがたと神が証人です。</span>
<span className="v" id="v11" data-v="11" data-xref="コリント人への第一の手紙 4:14–15; ヘブル人への手紙 13:22; テモテへの手紙第一 5:21"> あなたがたが知っているように、父が自分の子どもにするように、私たちはあなたがた一人ひとりを励まし、慰め、強く勧めました。</span>
<span className="v" id="v12" data-v="12" data-xref="エペソ人への手紙 4:1; ヨハネの手紙第一 2:6; ヨハネの手紙第一 1:6–7"> それは、ご自分の王国と栄光へ召してくださる神にふさわしく歩むよう、あなたがたに勧めるためでした。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="ヘブル人への手紙 4:12; ローマ人への手紙 10:17; ペテロの手紙第一 1:23"> こういうわけで、私たちも絶えず神に感謝しています。あなたがたは、私たちから聞いた神のことばを受けたとき、それを人の言葉としてではなく、まさしく神のことばとして受け入れました。事実、そのことばは、信じているあなたがたのうちに働いています。</span>
<span className="v" id="v14" data-v="14" data-xref="テサロニケ人への手紙第一 3:4; ヘブル人への手紙 10:33–34; ヘブル人への手紙 5:7–8"> 兄弟姉妹、あなたがたは、キリスト・イエスにあってユダヤにある神の諸教会にならう者となりました。彼らがユダヤ人から受けたのと同じ苦しみを、あなたがたも自分たちの同胞から受けたからです。</span>
<span className="v" id="v15" data-v="15" data-xref="マタイ 5:12; ルカ 11:48–53; 使徒の働き 7:52"> ユダヤ人は、主イエスと自分たちの預言者たちを殺し、私たちを追い出しました。彼らは神を喜ばせず、すべての人に敵対しています。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒の働き 17:13; 使徒の働き 14:19; マルコ 16:16"> 異邦人が救われるように私たちが語ることを妨げ、こうしていつも罪を積み重ねています。しかし、神の怒りはついに彼らに臨みました。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="コロサイ人への手紙 2:5; コリント人への第一の手紙 5:3; テサロニケ人への手紙第一 3:6"> 兄弟姉妹、私たちはほんのしばらくの間、あなたがたから引き離され、孤児のようになりました。しかし、顔を合わせられなくても、心まで離れたのではありません。切なる思いで、なおいっそうあなたがたの顔を見ようと努めました。</span>
<span className="v" id="v18" data-v="18" data-xref="ローマ人への手紙 15:22; ローマ人への手紙 1:13; ヨハネの黙示録 2:10"> それで、あなたがたのもとへ行きたいと願いました。実際、私パウロは一度ならず行こうとしましたが、サタンが私たちを妨げました。</span>
<span className="v" id="v19" data-v="19" data-xref="ピリピ人への手紙 4:1; テサロニケ人への手紙第一 3:13; ピリピ人への手紙 2:16"> 私たちの希望、喜び、誇りとする冠とは何でしょうか。私たちの主イエスが<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="公認本文には「キリスト」が加えられている。">a</a></sup>来られるとき、その御前に立つあなたがたではありませんか。</span>
<span className="v" id="v20" data-v="20" data-xref="コリント人への第二の手紙 1:14; コリント人への第一の手紙 11:7; 箴言 17:6"> まことに、あなたがたこそ私たちの栄光であり、喜びです。</span>
</div>

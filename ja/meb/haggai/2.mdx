<span className="v" id="v1" data-v="1" data-xref="ハガイ書 1:1; ハガイ書 2:20; ハガイ書 2:10"> 第七の月の二十一日に、主の言葉が預言者ハガイを通して臨んだ。</span>
<span className="v" id="v2" data-v="2" data-xref="ハガイ書 1:1; ネヘミヤ記 8:9; エズラ記 2:63"> 「今、シェアルティエルの子でユダの総督であるゼルバベルと、エホツァダクの子で大祭司であるヨシュアと、民の残りの者に告げよ。</span>
<span className="v" id="v3" data-v="3" data-xref="エズラ記 3:12; ハガイ書 2:9; エゼキエル書 7:20"> 『あなたがたのうち、かつてこの家の栄光を見た者で、今も残っているのはだれか。今、この家はどう見えるか。あなたがたの目には、無に等しいではないか。</span>
<span className="v" id="v4" data-v="4" data-xref="歴代誌上 28:20; ヨシュア記 1:9; ゼカリヤ書 8:9"> しかし今、ゼルバベルよ、強くあれ』と主は言われる。『エホツァダクの子で大祭司であるヨシュアよ、強くあれ。この地のすべての民よ、強くあれ』と主は言われる。『働け。私はあなたがたとともにいるからだ』と万軍の主は言われる。</span>
<span className="v" id="v5" data-v="5" data-xref="出エジプト記 34:10; 出エジプト記 29:45–46; イザヤ書 41:13"> 『あなたがたがエジプトから出た時、私はこの言葉をもってあなたがたと契約を結んだ。私の霊はあなたがたの間にとどまっている。恐れるな。』</span>
<span className="v" id="v6" data-v="6" data-xref="ヘブル人への手紙 12:26–28; イザヤ書 10:25; マルコ 13:24–26"> 万軍の主はこう言われる。『あとしばらくすれば、もう一度、私は天と地、海と乾いた地を揺り動かす。</span>
<span className="v" id="v7" data-v="7" data-xref="マラキ書 3:1; 列王記第一 8:11; ヨハネ 7:37–39"> 私はすべての国々を揺り動かす。すると、諸国の宝が来る。私はこの家を栄光で満たす』と万軍の主は言われる。</span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 50:10–12; 詩篇 24:1; イザヤ書 60:17"> 『銀は私のもの、金も私のものだ』と万軍の主は言われる。</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 85:8–9; コリント人への第二の手紙 3:9–10; コロサイ人への手紙 1:19–21"> 『後に現れるこの家の栄光は、以前の栄光よりも大きくなる』と万軍の主は言われる。『この場所に私は平和を与える』と万軍の主は言われる。」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="ハガイ書 2:20; ハガイ書 1:1; ハガイ書 1:15–1"> ダレイオスの第二年、第九の月の二十四日に、主の言葉が預言者ハガイに臨んだ。</span>
<span className="v" id="v11" data-v="11" data-xref="レビ記 10:10–11; マラキ書 2:7; 申命記 33:10"> 「万軍の主はこう言われる。『祭司たちに律法について尋ねよ。</span>
<span className="v" id="v12" data-v="12" data-xref="レビ記 6:27; マタイ 23:19; レビ記 7:6"> だれかが衣の裾に聖なる肉を包んで運び、その裾がパン、煮物、ぶどう酒、油、または何かの食物に触れたなら、それは聖なるものになるか。』」<br />祭司たちは「なりません」と答えた。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="民数記 5:2–3; 民数記 19:11–22; レビ記 22:4–6"> そこでハガイは言った。「死体によって汚れた者が、これらのいずれかに触れたなら、それは汚れるか。」<br />祭司たちは「汚れます」と答えた。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="箴言 28:9; テトス 1:15; イザヤ書 1:11–15"> そこでハガイは答えた。「『この民も、この国も、私の前ではそのようなものだ』と主は言われる。『彼らの手のすべての働きもそのようなものであり、彼らがそこでささげるものも汚れている。</span>
<span className="v" id="v15" data-v="15" data-xref="ハガイ書 1:5; エズラ記 3:10; エズラ記 4:24"> さあ、今日より前、主の神殿で石が石の上に据えられる以前のことを、よく考えよ。</span>
<span className="v" id="v16" data-v="16" data-xref="ハガイ書 1:6; マラキ書 2:2; 箴言 3:9–10"> その間、二十の量を期待して穀物の山に来ても、十しかなかった。五十くみ出そうと酒ぶねに来ても、二十しかなかった。</span>
<span className="v" id="v17" data-v="17" data-xref="申命記 28:22; ハガイ書 1:11; ハガイ書 1:9"> 私はあなたがたの手のすべての働きを、立ち枯れと黴と雹で打った。それでも、あなたがたは私に立ち返らなかった』と主は言われる。</span>
<span className="v" id="v18" data-v="18" data-xref="ゼカリヤ書 8:9; ハガイ書 2:15; エズラ記 5:1–2"> 『今日までのことを、よく考えよ。第九の月の二十四日、主の神殿の基礎が据えられたこの日を、よく心に留めよ。</span>
<span className="v" id="v19" data-v="19" data-xref="マラキ書 3:10; ハバクク書 3:17–18; 箴言 3:9–10"> 種はまだ納屋にあるか。ぶどうの木も、いちじくの木も、ざくろの木も、オリーブの木も、まだ実を結んでいない。しかし今日から、私はあなたがたを祝福する。』」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20"> その月の二十四日に、主の言葉が二度目にハガイに臨んだ。</span>
<span className="v" id="v21" data-v="21" data-xref="ゼカリヤ書 4:6–10; ハガイ書 2:6–7; ハガイ書 1:1"> 「ユダの総督ゼルバベルに告げよ。『私は天と地を揺り動かす。</span>
<span className="v" id="v22" data-v="22" data-xref="ミカ書 5:10; 士師記 7:22; ゼパニヤ書 3:8"> 私は諸王国の王座を覆し、諸国の力を滅ぼす。戦車とそれに乗る者たちを覆す。馬とその乗り手たちは倒れ、それぞれ同胞の剣によって倒れる。</span>
<span className="v" id="v23" data-v="23" data-xref="イザヤ書 43:10; イザヤ書 42:1; 雅歌 8:6"> その日』と万軍の主は言われる。『シェアルティエルの子、私のしもべゼルバベルよ、私はあなたを私のものとして取り、印章の指輪のようにする。私があなたを選んだからだ』と万軍の主は言われる。」</span>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ガラテヤ人への手紙 2:3; 使徒の働き 14:12; コリント人への第二の手紙 8:23"> それから十四年後、私はバルナバと共に再びエルサレムへ上り、テトスも連れて行きました。</span>
<span className="v" id="v2" data-v="2" data-xref="ガラテヤ人への手紙 2:6; ピリピ人への手紙 2:16; テサロニケ人への手紙第一 3:5"> 私が上ったのは啓示によるものでした。私は異邦人の間で宣べ伝えている福音を人々に示し、重んじられている人たちには個別に説明しました。自分が今走っていることも、これまで走ってきたことも、無駄にならないようにするためでした。</span>
<span className="v" id="v3" data-v="3" data-xref="ガラテヤ人への手紙 5:2–6; 使徒の働き 16:3; コリント人への第一の手紙 9:20–21"> しかし、私と共にいたテトスはギリシャ人でしたが、割礼を受けることを強いられませんでした。</span>
<span className="v" id="v4" data-v="4" data-xref="ユダ 1:4; ガラテヤ人への手紙 5:1; ガラテヤ人への手紙 4:3"> 割礼の問題が持ち上がったのは、ひそかに入り込んだ偽の兄弟たちのためでした。彼らは、私たちを奴隷にしようとして、キリスト・イエスにあって私たちが持つ自由をうかがうために忍び込んできたのです。</span>
<span className="v" id="v5" data-v="5" data-xref="ガラテヤ人への手紙 2:14; ガラテヤ人への手紙 4:16; コロサイ人への手紙 1:5"> 私たちは一時たりとも彼らに屈服しませんでした。それは、福音の真理があなたがたのもとに保たれるためです。</span>
<span className="v" id="v6" data-v="6" data-xref="ガラテヤ人への手紙 2:2; 使徒の働き 10:34; コリント人への第二の手紙 12:11"> 重んじられている人たちは、私に何一つ付け加えませんでした。彼らがどのような人であったとしても、私には関係ありません。神は人を分け隔てなさらないからです。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒の働き 9:15; テモテへの手紙第一 2:7; ガラテヤ人への手紙 1:16"> それどころか、ペテロが割礼を受けた者たちへの福音を任されたように、私が割礼を受けていない者たちへの福音を任されたことを、彼らは認めました。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒の働き 9:15; 使徒の働き 22:21; 使徒の働き 2:14–41"> ペテロを通して働き、彼を割礼を受けた者たちへの使徒とされた方は、私を通しても働き、私を異邦人への使徒とされたからです。</span>
<span className="v" id="v9" data-v="9" data-xref="ローマ人への手紙 12:3; ヨハネの黙示録 3:12; ガラテヤ人への手紙 2:2"> 柱と見なされていたヤコブ、ケファ、ヨハネは、私に与えられた恵みを認め、バルナバと私に交わりのしるしとして右手を差し出しました。こうして、私たちは異邦人のもとへ、彼らは割礼を受けた者たちのもとへ行くことになりました。</span>
<span className="v" id="v10" data-v="10" data-xref="使徒の働き 24:17; ヨハネの手紙第一 3:17; ヘブル人への手紙 13:16"> ただ、貧しい人々を忘れないようにとのことでした。それは、私自身も熱心に努めていたことです。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="テモテへの手紙第一 5:20; コリント人への第二の手紙 5:16; 使徒の働き 15:1"> ところが、ペテロがアンティオキアに来た時、彼には明らかに非難されるべきところがあったので、私は面と向かって反対しました。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒の働き 10:28; ルカ 15:2; 使徒の働き 11:2–3"> ヤコブのもとからある人々が来るまでは、ペテロは異邦人と一緒に食事をしていました。しかし彼らが来ると、割礼派の人々を恐れ、身を引いて異邦人から離れていきました。</span>
<span className="v" id="v13" data-v="13" data-xref="コリント人への第一の手紙 15:33; エペソ人への手紙 4:14; ヘブル人への手紙 13:9"> ほかのユダヤ人たちも彼と共に偽善に陥り、ついにはバルナバまで彼らの偽善に引き込まれてしまいました。</span>
<span className="v" id="v14" data-v="14" data-xref="ガラテヤ人への手紙 2:5; 使徒の働き 10:28; 使徒の働き 15:10–11"> しかし、彼らが福音の真理に従ってまっすぐ歩んでいないのを見て、私は皆の前でペテロに言いました。「あなたはユダヤ人でありながら、ユダヤ人のようにではなく異邦人のように生活しているのに、どうして異邦人にユダヤ人のように生活することを強いるのですか。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="テトス 3:3; エペソ人への手紙 2:3; エペソ人への手紙 2:11–12"> 「私たちは生まれながらのユダヤ人であって、『異邦人の罪人』ではありません。</span>
<span className="v" id="v16" data-v="16" data-xref="ピリピ人への手紙 3:9; 詩篇 143:2; ローマ人への手紙 9:30"> しかし、人は律法の行いによってではなく、イエス・キリストへの信仰によって義とされることを知っています。それで私たちも、キリスト・イエスを信じました。律法の行いによってではなく、キリストへの信仰によって義とされるためです。律法の行いによって義とされる者は、だれ一人いないからです。</span>
<span className="v" id="v17" data-v="17" data-xref="ローマ人への手紙 6:1–2; ヨハネの手紙第一 3:8–10; ヨハネの手紙第一 3:5"> ところで、キリストにあって義とされることを求める私たち自身も罪人であることが明らかになったとすれば、キリストは罪に仕える者なのでしょうか。決してそうではありません。</span>
<span className="v" id="v18" data-v="18" data-xref="ガラテヤ人への手紙 4:9–12; ガラテヤ人への手紙 2:4–5; ガラテヤ人への手紙 2:12–16"> 自分が壊したものを再び建てるなら、私は自分自身が律法に背く者であることを示すことになります。</span>
<span className="v" id="v19" data-v="19" data-xref="ローマ人への手紙 7:4; ローマ人への手紙 6:2; テサロニケ人への手紙第一 5:10"> 私は神に生きるために、律法によって律法に死にました。</span>
<span className="v" id="v20" data-v="20" data-xref="ガラテヤ人への手紙 5:24; コリント人への第二の手紙 5:15; ローマ人への手紙 6:4–6"> 私はキリストと共に十字架につけられました。もはや生きているのは私ではなく、キリストが私のうちに生きておられます。今この肉体で生きている命を、私を愛し、私のためにご自身をささげてくださった神の御子への信仰によって生きています。</span>
<span className="v" id="v21" data-v="21" data-xref="ローマ人への手紙 11:6; ガラテヤ人への手紙 3:21; ヘブル人への手紙 7:11"> 私は神の恵みを退けません。もし義が律法によって得られるのなら、キリストの死は無意味だったことになるからです。」</span>
</div>

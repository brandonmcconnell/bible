<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ガラテヤ人への手紙 4:23; ガラテヤ人への手紙 4:29; 創世記 24:2–3"> ここで私が言いたいのは、相続人は、すべてのものの主人であっても、子どもである間は奴隷と何も変わらず、</span>
<span className="v" id="v2" data-v="2"> 父が定めた日までは、後見人や管理人の下にいるということです。</span>
<span className="v" id="v3" data-v="3" data-xref="コロサイ人への手紙 2:20; コロサイ人への手紙 2:8; ガラテヤ人への手紙 4:9"> 同じように私たちも、子どもであった時には、この世の諸原理の下で奴隷となっていました。</span>
<span className="v" id="v4" data-v="4" data-xref="イザヤ書 7:14; ヨハネ 1:14; ローマ人への手紙 1:3"> しかし、時が満ちると、神は御子を遣わされました。御子は女から生まれ、律法の下に生まれました。</span>
<span className="v" id="v5" data-v="5" data-xref="ヘブル人への手紙 9:15; エペソ人への手紙 1:5; ペテロの手紙第一 1:18–20"> それは、律法の下にいる者たちを贖い、私たちが神の子として迎えられるためでした。</span>
<span className="v" id="v6" data-v="6" data-xref="ローマ人への手紙 8:15–17; ローマ人への手紙 5:5; ローマ人への手紙 8:9"> あなたがたが子であるので、神は御子の霊をあなたがたの心に遣わされました。その霊は、「アバ、<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「アバ」は、親しみと敬意と愛を込めて用いられるアラム語の「父」または「お父さん」をギリシャ語で表記したものである。">a</a></sup>父よ」と叫んでいます。</span>
<span className="v" id="v7" data-v="7" data-xref="ローマ人への手紙 8:16–17; ガラテヤ人への手紙 3:29–2; ガラテヤ人への手紙 3:26"> ですから、あなたはもはや奴隷ではなく、子です。子であるなら、キリストを通して神の相続人でもあります。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="コリント人への第一の手紙 8:4; エペソ人への手紙 2:11–12; テサロニケ人への第二の手紙 1:8"> しかし以前、神を知らなかった時、あなたがたは本来神ではないものの奴隷となっていました。</span>
<span className="v" id="v9" data-v="9" data-xref="コリント人への第一の手紙 8:3; ガラテヤ人への手紙 3:3; ローマ人への手紙 8:3"> ところが今は、神を知るようになりました。いや、むしろ神に知られるようになりました。それなのに、なぜ再び、無力で貧弱な諸原理に戻り、もう一度その奴隷になろうとするのですか。</span>
<span className="v" id="v10" data-v="10" data-xref="コロサイ人への手紙 2:16–17; ローマ人への手紙 14:5; レビ記 23:1–44"> あなたがたは、日と月と季節と年を守っています。</span>
<span className="v" id="v11" data-v="11" data-xref="テサロニケ人への手紙第一 3:5; ピリピ人への手紙 2:16; ガラテヤ人への手紙 2:2"> あなたがたのことが心配です。あなたがたのために労したことが、無駄になったのではないかと思うからです。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="コリント人への第二の手紙 2:5; 列王記第一 22:4; 創世記 34:15"> 兄弟たち、お願いします。私のようになってください。私もあなたがたのようになったのですから。あなたがたは私に何も悪いことをしませんでした。</span>
<span className="v" id="v13" data-v="13" data-xref="コリント人への第一の手紙 2:3; コリント人への第二の手紙 12:7–10; コリント人への第二の手紙 11:30"> あなたがたが知っているとおり、私が初めて福音を宣べ伝えたのは、肉体の弱さのためでした。</span>
<span className="v" id="v14" data-v="14" data-xref="マタイ 10:40; テサロニケ人への手紙第一 2:13; ヘブル人への手紙 13:2"> 私の肉体の状態は、あなたがたを試すものでした。それでも、あなたがたは私を軽蔑したり、忌み嫌ったりせず、神の御使いのように、いや、キリスト・イエスのように迎えてくれました。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="ローマ人への手紙 5:2; ヨハネの手紙第一 3:16–18; コロサイ人への手紙 4:13"> あなたがたが味わっていたあの幸いは、どうなったのですか。私は証言しますが、できることなら、あなたがたは自分の目をえぐり出して私に与えたことでしょう。</span>
<span className="v" id="v16" data-v="16" data-xref="アモス書 5:10; 箴言 9:8; ヨハネ 8:45"> それでは、真理を告げたために、私はあなたがたの敵になったのでしょうか。</span>
<span className="v" id="v17" data-v="17" data-xref="ローマ人への手紙 16:18; コリント人への第二の手紙 11:13–15; ペテロの第二の手紙 2:3"> あの者たちは、善意からではなく、あなたがたに熱心に取り入ろうとしています。あなたがたを孤立させ、自分たちに熱心にならせたいのです。</span>
<span className="v" id="v18" data-v="18" data-xref="ピリピ人への手紙 2:12; ヨハネの黙示録 3:19; ピリピ人への手紙 1:27"> 良いことに熱心であるのは、いつでも良いことです。私があなたがたと共にいる時だけではありません。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="エペソ人への手紙 4:13; ローマ人への手紙 8:29; ローマ人への手紙 13:14"> 私の幼い子どもたち。キリストがあなたがたのうちに形づくられるまで、私は再びあなたがたを産む苦しみを味わっています。</span>
<span className="v" id="v20" data-v="20" data-xref="テサロニケ人への手紙第一 2:17–18; コリント人への第一の手紙 4:19–21; テサロニケ人への手紙第一 3:9"> 今すぐあなたがたのもとへ行き、話し方を変えられたらと思います。あなたがたのことで途方に暮れているからです。</span>
</div>
<div className="bp poetry">
<span className="v" id="v21" data-v="21" data-xref="ガラテヤ人への手紙 3:10; ガラテヤ人への手紙 3:23–24; ローマ人への手紙 7:5–6"> 律法の下にいたいと願う人たちよ、答えてください。あなたがたは律法の語ることを聞いていないのですか。</span>
<span className="v" id="v22" data-v="22" data-xref="創世記 16:15; 創世記 21:10; 創世記 21:1–2"> アブラハムには二人の息子があり、一人は女奴隷から、もう一人は自由な女から生まれた、と書かれています。</span>
<span className="v" id="v23" data-v="23" data-xref="ヘブル人への手紙 11:11; ローマ人への手紙 9:7–8; ガラテヤ人への手紙 4:28–29"> 女奴隷の子は肉によって生まれましたが、自由な女の子は約束によって生まれました。</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 21:9–13; ヘブル人への手紙 10:15–18; 創世記 16:8"> これらのことには比喩的な意味があります。この二人の女は二つの契約を表しています。一つはシナイ山から出た契約で、奴隷となる子どもを産みます。これはハガルです。</span>
<span className="v" id="v25" data-v="25" data-xref="ルカ 19:44; 使徒の働き 1:11; ガラテヤ人への手紙 1:17"> このハガルは、アラビアにあるシナイ山であり、今のエルサレムに対応します。今のエルサレムは、その子どもたちと共に奴隷となっているからです。</span>
<span className="v" id="v26" data-v="26" data-xref="ヘブル人への手紙 12:22; ピリピ人への手紙 3:20; ミカ書 4:1–2"> しかし、上にあるエルサレムは自由であり、私たち皆の母です。</span>
<span className="v" id="v27" data-v="27" data-xref="イザヤ書 54:1–5; 詩篇 113:9; ルツ記 4:14–16"> こう書かれています。<br /><span className="pl pl-1">「喜べ、子を産まない不妊の女よ。</span><br /><span className="pl pl-2">産みの苦しみを知らない女よ、声を上げて叫べ。</span><br /><span className="pl pl-2">夫のある女の子どもより、見捨てられた女の子どものほうが多いからだ。」</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="ガラテヤ人への手紙 4:23; ローマ人への手紙 9:8–9; ローマ人への手紙 4:13–18"> 兄弟たち、私たちはイサクと同じように約束の子どもです。</span>
<span className="v" id="v29" data-v="29" data-xref="創世記 21:9; ローマ人への手紙 8:13; ガラテヤ人への手紙 5:11"> しかし、当時、肉によって生まれた者が聖霊によって生まれた者を迫害したように、今も同じです。</span>
<span className="v" id="v30" data-v="30" data-xref="創世記 21:10–12; ヨハネ 8:35; ローマ人への手紙 8:15–17"> しかし、聖書は何と言っていますか。「女奴隷とその息子を追い出しなさい。女奴隷の息子は、自由な女の息子と共に相続することはないからです。」</span>
<span className="v" id="v31" data-v="31" data-xref="ヨハネ 8:36; ヨハネ 1:12–13; ガラテヤ人への手紙 5:1"> ですから兄弟たち、私たちは女奴隷の子どもではなく、自由な女の子どもです。</span>
</div>

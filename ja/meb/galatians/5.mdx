<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="コリント人への第二の手紙 3:17; ガラテヤ人への手紙 5:13; ペテロの手紙第一 2:16"> キリストが与えてくださった自由のうちに、堅く立ちなさい。再び奴隷のくびきにつながれてはなりません。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="ガラテヤ人への手紙 5:6; 使徒の働き 15:1; ローマ人への手紙 9:31–32"> よく聞いてください。私パウロがあなたがたに言います。もし割礼を受けるなら、キリストはあなたがたにとって何の益にもなりません。</span>
<span className="v" id="v3" data-v="3" data-xref="ガラテヤ人への手紙 3:10; ローマ人への手紙 2:25; ヤコブの手紙 2:10–11"> 割礼を受けるすべての人に、もう一度はっきり言います。その人には、律法のすべてを行う義務があります。</span>
<span className="v" id="v4" data-v="4" data-xref="ローマ人への手紙 9:31–32; ペテロの第二の手紙 2:20–22; ローマ人への手紙 11:6"> 律法によって義とされようとするあなたがたは、キリストから切り離され、恵みから落ちてしまいました。</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 130:5; テサロニケ人への手紙第一 1:10; 詩篇 62:5"> 私たちは聖霊により、信仰によって、義とされる望みの実現を待ち望んでいます。</span>
<span className="v" id="v6" data-v="6" data-xref="ガラテヤ人への手紙 6:15; コリント人への第一の手紙 7:19; ヤコブの手紙 2:14–26"> キリスト・イエスにあっては、割礼を受けているかいないかは何の意味もありません。大切なのは、愛を通して働く信仰です。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="コリント人への第一の手紙 9:24; ガラテヤ人への手紙 3:1; ヘブル人への手紙 12:1"> あなたがたは順調に走っていました。それなのに、だれが行く手を阻み、真理に従わないようにしたのですか。</span>
<span className="v" id="v8" data-v="8" data-xref="ガラテヤ人への手紙 1:6; ローマ人への手紙 8:28"> そのような説得は、あなたがたを召してくださる方から出たものではありません。</span>
<span className="v" id="v9" data-v="9" data-xref="コリント人への第一の手紙 15:33; コリント人への第一の手紙 5:6–7; マルコ 8:15"> わずかなパン種が、練り粉全体を膨らませます。</span>
<span className="v" id="v10" data-v="10" data-xref="ガラテヤ人への手紙 5:12; コリント人への第二の手紙 2:3; ガラテヤ人への手紙 1:7"> あなたがたが別の考えを持つことはないと、私は主にあって確信しています。しかし、あなたがたをかき乱す者は、だれであろうと裁きを受けます。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="コリント人への第一の手紙 1:23; ガラテヤ人への手紙 6:12; ガラテヤ人への手紙 4:29"> 兄弟たち、もし私が今も割礼を宣べ伝えているのなら、なぜ今も迫害されているのでしょうか。もしそうなら、十字架のつまずきは取り除かれているはずです。</span>
<span className="v" id="v12" data-v="12" data-xref="ガラテヤ人への手紙 5:10; コリント人への第一の手紙 5:13; テトス 3:10"> あなたがたをかき乱す者たちは、いっそ自らを去勢してしまえばよいのです。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="ペテロの手紙第一 2:16; コリント人への第一の手紙 9:19; コリント人への第一の手紙 8:9"> 兄弟たち、あなたがたは自由を得るために召されました。ただし、その自由を、肉の欲望に従う口実としてはなりません。かえって、愛によって互いに仕えなさい。</span>
<span className="v" id="v14" data-v="14" data-xref="マタイ 7:12; レビ記 19:18; ガラテヤ人への手紙 6:2"> 律法全体は、「あなたの隣人を自分自身のように愛しなさい」という一つのことばに尽きています。</span>
<span className="v" id="v15" data-v="15" data-xref="コリント人への第一の手紙 3:3; ヤコブの手紙 3:14–3; ガラテヤ人への手紙 5:26"> しかし、互いにかみつき、食い尽くし合っているなら、互いを滅ぼしてしまわないように気をつけなさい。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="ガラテヤ人への手紙 5:24–25; ローマ人への手紙 8:12–14; ガラテヤ人への手紙 6:8"> そこで私は言います。聖霊に従って歩みなさい。そうすれば、肉の欲望を決して満たすことはありません。</span>
<span className="v" id="v17" data-v="17" data-xref="ローマ人への手紙 8:13; ヨハネ 3:6; ローマ人への手紙 8:5–8"> 肉の望みは聖霊に逆らい、聖霊の望みは肉に逆らいます。この二つは互いに対立しているため、あなたがたは望むことを思いどおりに行えません。</span>
<span className="v" id="v18" data-v="18" data-xref="ローマ人への手紙 8:14; ローマ人への手紙 6:14–15; ガラテヤ人への手紙 5:25"> しかし、聖霊に導かれているなら、あなたがたは律法の下にはいません。</span>
<span className="v" id="v19" data-v="19" data-xref="コリント人への第一の手紙 6:9–10; コロサイ人への手紙 3:5–8; マタイ 15:18–19"> 肉の行いは明らかです。すなわち、姦淫、淫らな行い、汚れ、好色、</span>
<span className="v" id="v20" data-v="20" data-xref="テトス 3:10; コリント人への第一の手紙 11:19; ヨハネの黙示録 21:8"> 偶像礼拝、魔術、敵意、争い、ねたみ、怒りの爆発、対抗意識、分裂、異端、</span>
<span className="v" id="v21" data-v="21" data-xref="コリント人への第一の手紙 6:9–10; ローマ人への手紙 8:13; ローマ人への手紙 13:13"> そねみ、殺人、泥酔、酒宴、これらに類することです。以前にも警告したように、今も警告しておきます。このようなことを行い続ける者は、神の王国を受け継ぐことがありません。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="コロサイ人への手紙 3:12–17; コリント人への第一の手紙 13:4–7; ヨハネ 15:5"> しかし、聖霊の実は、愛、喜び、平安、忍耐、親切、善良、信仰、<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="または「忠実」。">a</a></sup></span>
<span className="v" id="v23" data-v="23" data-xref="テモテへの手紙第一 1:9; 使徒の働き 24:25; テトス 2:2"> 柔和、自制です。このようなものを禁じる律法はありません。</span>
<span className="v" id="v24" data-v="24" data-xref="ローマ人への手紙 6:6; ローマ人への手紙 13:14; ローマ人への手紙 8:13"> キリストに属する人々は、情欲と欲望と共に、肉を十字架につけたのです。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="ガラテヤ人への手紙 5:16; ローマ人への手紙 8:4–5; ローマ人への手紙 8:2"> 私たちが聖霊によって生きているのなら、聖霊に従って歩みましょう。</span>
<span className="v" id="v26" data-v="26" data-xref="ヤコブの手紙 3:14–16; ピリピ人への手紙 2:1–3; ヤコブの手紙 4:16"> うぬぼれて、互いに挑発し合ったり、ねたみ合ったりしないようにしましょう。</span>
</div>

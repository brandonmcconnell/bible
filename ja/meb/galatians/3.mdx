<div className="bible-chapter" lang="ja" dir="ltr" data-lang="ja" data-translation="meb" data-translation-id="jpn_meb" data-translation-label="MEB" data-book="GAL" data-book-slug="galatians" data-book-name="ガラテヤ人への手紙" data-chapter="3" data-verses="29">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ガラテヤ人への手紙 5:7–8; コリント人への第二の手紙 11:3; ガラテヤ人への手紙 1:6"> 愚かなガラテヤ人たちよ。だれがあなたがたを惑わし、真理に従わないようにしたのですか。あなたがたの目の前には、十字架につけられたイエス・キリストの姿が、ありありと描き出されたではありませんか。</span>
<span className="v" id="v2" data-v="2" data-xref="ローマ人への手紙 10:16–17; ガラテヤ人への手紙 3:14; 使徒の働き 15:8"> あなたがたに一つだけ尋ねたいことがあります。あなたがたが聖霊を受けたのは、律法の行いによったのですか。それとも、信仰をもって聞いたことによったのですか。</span>
<span className="v" id="v3" data-v="3" data-xref="ガラテヤ人への手紙 5:4–8; ガラテヤ人への手紙 4:7–10; ヘブル人への手紙 7:16–19"> あなたがたは、それほど愚かなのですか。聖霊によって始めたのに、今になって肉によって完成されようというのですか。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネの手紙第二 1:8; コリント人への第一の手紙 15:2; ヘブル人への手紙 10:32–39"> あれほど多くの苦しみを受けたことは無駄だったのですか。もし本当に無駄だったのなら、ということですが。</span>
<span className="v" id="v5" data-v="5" data-xref="ガラテヤ人への手紙 3:2; 使徒の働き 14:9–10; 使徒の働き 19:11–12"> それでは、あなたがたに聖霊を与え、あなたがたの間で奇跡を行われる方は、律法の行いによってそうなさるのでしょうか。それとも、信仰をもって聞いたことによってでしょうか。</span>
<span className="v" id="v6" data-v="6" data-xref="創世記 15:6; ローマ人への手紙 4:21–22; ヤコブの手紙 2:23"> 同じように、「アブラハムは神を信じ、それが彼の義と認められた」のです。</span>
<span className="v" id="v7" data-v="7" data-xref="ローマ人への手紙 9:7–8; ガラテヤ人への手紙 3:9; ガラテヤ人への手紙 3:26–29"> ですから、信仰に立つ人々こそアブラハムの子であることを知りなさい。</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 12:3; 創世記 22:18; 創世記 28:14"> 聖書は、神が異邦人を信仰によって義とされることをあらかじめ見通し、「あなたによって、すべての国民が祝福される」とアブラハムに前もって福音を告げました。</span>
<span className="v" id="v9" data-v="9" data-xref="ローマ人への手紙 4:16; ガラテヤ人への手紙 3:29; ローマ人への手紙 4:24"> したがって、信仰に立つ人々は、信仰の人アブラハムと共に祝福されます。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="申命記 27:26; ローマ人への手紙 8:7; ローマ人への手紙 3:19–20"> 律法の行いに頼る者は皆、のろいの下にあります。「律法の書に記されたすべてのことを守り行わない者は、皆のろわれる」と書かれているからです。</span>
<span className="v" id="v11" data-v="11" data-xref="ハバクク書 2:4; ローマ人への手紙 1:17; ヘブル人への手紙 10:38"> 律法によって神の御前で義とされる人が一人もいないことは明らかです。「義人は信仰によって生きる」とあるからです。</span>
<span className="v" id="v12" data-v="12" data-xref="レビ記 18:5; ローマ人への手紙 10:5–6; ネヘミヤ記 9:29"> 律法は信仰によるものではありません。むしろ、「これらを行う者は、これらによって生きる」とあります。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="ペテロの手紙第一 2:24; 申命記 21:23; ヘブル人への手紙 9:12"> キリストは私たちのためにのろいとなり、律法ののろいから私たちを贖ってくださいました。「木に掛けられる者は皆、のろわれる」と書かれているからです。</span>
<span className="v" id="v14" data-v="14" data-xref="ガラテヤ人への手紙 3:28–29; コリント人への第一の手紙 12:13; エゼキエル書 36:26–27"> それは、アブラハムの祝福がキリスト・イエスを通して異邦人に及び、私たちが信仰によって約束された聖霊を受けるためでした。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="ヘブル人への手紙 9:17; ローマ人への手紙 6:19; ローマ人への手紙 3:5"> 兄弟たち、人間の例を挙げて話します。人間の契約でさえ、いったん確定されれば、だれもそれを無効にしたり、何かを付け加えたりはしません。</span>
<span className="v" id="v16" data-v="16" data-xref="創世記 17:7–8; ローマ人への手紙 4:13; ルカ 1:55"> さて、約束はアブラハムとその子孫<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="または「種」。">a</a></sup>に告げられました。神は、多くの者を指して「子孫たちに<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="または「複数の種に」。">b</a></sup>」とは言わず、一人を指して「あなたの子孫に」と言っておられます。その子孫とはキリストです。</span>
<span className="v" id="v17" data-v="17" data-xref="ヘブル人への手紙 11:39–40; 創世記 15:13; ローマ人への手紙 4:13–14"> 私が言いたいのはこうです。神がキリストにあってあらかじめ確定された契約を、四百三十年後に与えられた律法が無効にし、約束を失効させることはありません。</span>
<span className="v" id="v18" data-v="18" data-xref="ヘブル人への手紙 6:12–15; ガラテヤ人への手紙 2:21; ローマ人への手紙 4:13–16"> もし相続が律法に基づくのなら、もはや約束には基づきません。しかし神は、約束によってアブラハムに相続を恵みとして与えられました。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="使徒の働き 7:53; ローマ人への手紙 7:7–13; ヘブル人への手紙 2:2"> それでは、律法は何のためにあるのでしょうか。律法は、約束を受けた子孫が来る時まで、違反のために付け加えられたものです。そして、御使いたちを通し、仲介者の手によって定められました。</span>
<span className="v" id="v20" data-v="20" data-xref="テモテへの手紙第一 2:5; 申命記 6:4; ヨブ記 9:33"> 仲介者は、一人だけのために立つものではありません。しかし、神はお一人です。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="ガラテヤ人への手紙 2:21; ローマ人への手紙 9:31; ローマ人への手紙 3:20–22"> それでは、律法は神の約束に反するのでしょうか。決してそうではありません。もし人を生かすことのできる律法が与えられていたなら、義は確かに律法によって得られたでしょう。</span>
<span className="v" id="v22" data-v="22" data-xref="ローマ人への手紙 11:32; ヘブル人への手紙 9:15; ガラテヤ人への手紙 3:23"> しかし聖書は、すべてのものを罪の下に閉じ込めました。それは、イエス・キリストへの信仰による約束が、信じる人々に与えられるためです。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="ガラテヤ人への手紙 5:18; ガラテヤ人への手紙 3:24–25; ガラテヤ人への手紙 3:19"> 信仰が来る前、私たちは律法の下で監視され、後に明らかにされる信仰の時まで閉じ込められていました。</span>
<span className="v" id="v24" data-v="24" data-xref="ローマ人への手紙 10:4; 使徒の働き 13:38–39; ローマ人への手紙 7:24–25"> こうして律法は、私たちをキリストへ導く養育係となりました。それは、私たちが信仰によって義とされるためです。</span>
<span className="v" id="v25" data-v="25" data-xref="ローマ人への手紙 6:14; ローマ人への手紙 7:4; ヘブル人への手紙 10:15–18"> しかし今や信仰が来たので、私たちはもはや養育係の下にはいません。</span>
<span className="v" id="v26" data-v="26" data-xref="エペソ人への手紙 1:5; コリント人への第二の手紙 6:18; ヨハネ 1:12–13"> あなたがたは皆、キリスト・イエスへの信仰によって神の子どもだからです。</span>
<span className="v" id="v27" data-v="27" data-xref="ローマ人への手紙 13:14; コリント人への第一の手紙 12:13; ローマ人への手紙 6:3–4"> キリストに結ばれるバプテスマを受けたあなたがたは皆、キリストを身にまとったのです。</span>
<span className="v" id="v28" data-v="28" data-xref="コリント人への第一の手紙 12:12–13; コロサイ人への手紙 3:11; ローマ人への手紙 3:29–30"> ユダヤ人もギリシャ人もなく、奴隷も自由人もなく、男も女もありません。あなたがたは皆、キリスト・イエスにあって一つだからです。</span>
<span className="v" id="v29" data-v="29" data-xref="エペソ人への手紙 3:6; ローマ人への手紙 9:7–8; ガラテヤ人への手紙 3:7"> あなたがたがキリストのものであるなら、アブラハムの子孫であり、約束に基づく相続人です。</span>
</div>

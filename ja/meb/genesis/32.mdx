<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="詩篇 91:11; 詩篇 34:7; ヘブル人への手紙 1:4"> ヤコブは旅を続けた。すると、神の使いたちが彼に出会った。</span>
<span className="v" id="v2" data-v="2" data-xref="サムエル記第二 2:8; ヨシュア記 5:14; ヨシュア記 21:38"> ヤコブは彼らを見ると、「これは神の陣営だ」と言った。彼はその場所の名をマハナイム<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="マハナイムは「二つの陣営」を意味する。">a</a></sup>と呼んだ。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 25:30; ヨシュア記 24:4; 申命記 2:5"> ヤコブは自分に先立って、セイルの地、エドムの野にいる兄エサウのもとへ使者たちを遣わした。</span>
<span className="v" id="v4" data-v="4" data-xref="ペテロの手紙第一 3:6; ルカ 14:11; 創世記 33:8"> 彼は彼らに命じた。「私の主人エサウにこう言いなさい。『あなたのしもべヤコブはこう申しております。私はラバンのもとに寄留し、今まで滞在していました。</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 33:8; 創世記 33:15; 創世記 33:11"> 私には牛、ろば、羊の群れ、男のしもべ、女のしもべがあります。ご主人様のご好意を得たいと願い、お知らせするために使いを遣わしました。』」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="創世記 33:1; 創世記 32:8; 創世記 32:11"> 使者たちはヤコブのもとに戻って来て言った。「私たちはあなたの兄エサウのところへ行きました。見よ、彼もあなたを迎えに来ます。しかも四百人の男たちが彼と一緒です。」</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 35:3; コリント人への第二の手紙 1:8–10; 出エジプト記 14:10"> そこでヤコブは非常に恐れ、苦悩した。彼は自分と一緒にいる人々、羊の群れ、牛の群れ、らくだを二つの陣営に分けた。</span>
<span className="v" id="v8" data-v="8" data-xref="マタイ 10:16; 創世記 33:1–3"> 彼は言った。「もしエサウが一つの陣営のところに来て、それを打っても、残った陣営は逃げることができるだろう。」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="創世記 31:42; 詩篇 34:4–6; 創世記 31:3"> ヤコブは言った。「私の父アブラハムの神、私の父イサクの神、主よ。あなたは私に、『あなたの地、あなたの親族のところへ帰りなさい。わたしはあなたに良くする』と言われました。</span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 18:35; 創世記 24:27; サムエル記第二 7:18"> 私は、あなたがしもべに示してくださったすべての慈しみと真実に、少しも値しない者です。一本の杖だけでこのヨルダン川を渡った私が、今では二つの陣営となりました。</span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 59:1–2; 箴言 18:19; マタイ 6:13"> どうか、私の兄の手から、エサウの手から私を救い出してください。彼が来て、母も子も打つのではないかと、私は彼を恐れているのです。</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 28:13–15; ヘブル人への手紙 6:17; テトス 1:2"> あなたは、『わたしは必ずあなたに良くし、あなたの子孫を、多すぎて数えきれない海の砂のようにする』と言われました。」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="箴言 18:16; 創世記 43:11; 箴言 19:6"> 彼はその夜そこに泊まり、自分の持ち物の中から、兄エサウへの贈り物を選んだ。</span>
<span className="v" id="v14" data-v="14" data-xref="ヨブ記 1:3; 申命記 8:18; ヨブ記 42:12"> 雌山羊二百匹、雄山羊二十匹、雌羊二百匹、雄羊二十匹、</span>
<span className="v" id="v15" data-v="15"> 乳を飲ませているらくだ三十頭とその子、雌牛四十頭、雄牛十頭、雌ろば二十頭、ろばの子十頭である。</span>
<span className="v" id="v16" data-v="16" data-xref="創世記 33:8–9; 創世記 32:20; 箴言 2:11"> 彼はそれらを群れごとに分け、しもべたちの手に渡し、しもべたちに言った。「私より先に進み、群れと群れの間に間隔を置きなさい。」</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 33:3"> 彼は先頭の者に命じた。「私の兄エサウがあなたに出会い、『あなたは誰の者か。どこへ行くのか。あなたの前にいるこれらは誰のものか』と尋ねたなら、</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 32:4–5"> あなたはこう言いなさい。『あなたのしもべヤコブのものです。これは私の主人エサウに送る贈り物です。見よ、ヤコブ自身も私たちの後ろにいます。』」</span>
<span className="v" id="v19" data-v="19"> 彼は二番目、三番目の者、そして群れの後について行くすべての者にも命じた。「エサウに出会ったとき、あなたがたは彼にこのように話しなさい。</span>
<span className="v" id="v20" data-v="20" data-xref="ヨブ記 42:8–9; 箴言 21:14; 創世記 43:11"> また、『見よ、あなたのしもべヤコブも私たちの後ろにいます』と言いなさい。」ヤコブは、「先に送る贈り物で兄をなだめ、その後で会おう。もしかすると受け入れてくれるかもしれない」と考えたのである。</span>
<span className="v" id="v21" data-v="21"> こうして、贈り物は彼より先に進み、彼自身はその夜、陣営に泊まった。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="申命記 3:16; 申命記 2:37; テモテへの手紙第一 5:8"> 彼はその夜起き上がり、二人の妻、二人の女のしもべ、十一人の息子を連れて、ヤボクの渡しを渡った。</span>
<span className="v" id="v23" data-v="23"> 彼は彼らを連れて川を渡らせ、自分の持ち物も渡らせた。</span>
<span className="v" id="v24" data-v="24" data-xref="ホセア書 12:3–5; エペソ人への手紙 6:12; ルカ 13:24"> ヤコブは一人残った。すると、ある人が夜明けまで彼と格闘した。</span>
<span className="v" id="v25" data-v="25" data-xref="コリント人への第二の手紙 12:7–9; ホセア書 12:3–4; マタイ 26:41"> その人はヤコブに勝てないのを見ると、ヤコブのももの関節に触れた。そのため、ヤコブが彼と格闘している間に、ヤコブのももの関節が外れた。</span>
<span className="v" id="v26" data-v="26" data-xref="ホセア書 12:4; 詩篇 115:12–13; コリント人への第二の手紙 12:8–9"> その人は言った。「夜が明けるから、私を行かせてくれ。」<br />ヤコブは言った。「私を祝福してくださるまでは、あなたを行かせません。」</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27"> その人は言った。「あなたの名は何というのか。」<br />彼は言った。「ヤコブです。」</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="ヨハネの黙示録 2:17; 創世記 35:10; イザヤ書 62:2–4"> その人は言った。「あなたの名は、もはやヤコブではなく、イスラエル<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="イスラエルは「神と争う」または「神が争われる」と関連する。">b</a></sup>と呼ばれる。あなたは神と人と争い、勝ったからだ。」</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="イザヤ書 9:6; 士師記 13:16–18; ヨブ記 11:7"> ヤコブは尋ねた。「どうか、あなたの名を教えてください。」<br />その人は言った。「なぜあなたは私の名を尋ねるのか。」そして、その場でヤコブを祝福した。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="出エジプト記 24:10–11; 民数記 12:8; イザヤ書 6:5"> ヤコブはその場所の名をペニエル<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="ペニエルは「神の顔」を意味する。">c</a></sup>と呼んだ。「私は顔と顔を合わせて神を見た。それでも、私の命は救われた」と言ったのである。</span>
<span className="v" id="v31" data-v="31" data-xref="コリント人への第二の手紙 12:7; 創世記 19:15; 士師記 8:8"> 彼がペニエルを通り過ぎたとき、太陽は彼の上に昇った。彼はもものために足を引きずっていた。</span>
<span className="v" id="v32" data-v="32" data-xref="サムエル記第一 5:5"> それゆえ、イスラエルの子らは今日に至るまで、ももの関節にある筋を食べない。あの人がヤコブのももの関節、その筋に触れたからである。</span>
</div>
</div>

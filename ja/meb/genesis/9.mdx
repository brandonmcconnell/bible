<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 9:7; 創世記 1:28; 創世記 8:17"> 神はノアとその息子たちを祝福して、彼らに言われた。「生めよ。増えよ。地に満ちよ。</span>
<span className="v" id="v2" data-v="2" data-xref="詩篇 8:4–8; 創世記 1:28; ヤコブの手紙 3:7"> 地のすべての動物、空のすべての鳥、地面を動くすべてのもの、海のすべての魚は、あなたがたを恐れ、おののく。これらはあなたがたの手に委ねられている。</span>
<span className="v" id="v3" data-v="3" data-xref="ローマ人への手紙 14:14; コロサイ人への手紙 2:21–22; コリント人への第一の手紙 10:31"> 生きて動くものはすべて、あなたがたの食物となる。青草を与えたように、わたしはこれらすべてをあなたがたに与える。</span>
<span className="v" id="v4" data-v="4" data-xref="申命記 12:23; 申命記 15:23; 申命記 12:16"> ただし、その命である血を含んだまま、肉を食べてはならない。</span>
<span className="v" id="v5" data-v="5" data-xref="出エジプト記 21:28–29; 出エジプト記 21:12; 創世記 4:9–10"> わたしは必ず、あなたがたの命の血の責任を問う。すべての動物にもその責任を問う。また人にも、すなわちその兄弟である人にも、人の命の責任を問う。</span>
<span className="v" id="v6" data-v="6" data-xref="レビ記 24:17; マタイ 26:52; ヨハネの黙示録 13:10"> 人の血を流す者は、人によって自分の血を流される。神はご自身のかたちに人を造られたからである。</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 1:28; 創世記 9:1; 創世記 9:19"> あなたがたは、生めよ。増えよ。地に満ち広がり、地の上で増えよ。」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8"> 神はノアと、彼と共にいた息子たちに告げられた。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 6:18; イザヤ書 54:9–10; ローマ人への手紙 1:3"> 「見よ、わたしはあなたがたと、あなたがたの後に続く子孫と、わたしの契約を結ぶ。</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 8:1; 創世記 9:15–16; 詩篇 36:5–6"> また、あなたがたと一緒にいるすべての生き物、すなわち鳥、家畜、あなたがたと一緒にいる地のすべての動物、箱舟から出たすべてのもの、地のすべての動物と契約を結ぶ。</span>
<span className="v" id="v11" data-v="11" data-xref="イザヤ書 54:9; 創世記 8:21–22; 創世記 7:21–23"> わたしはあなたがたと契約を結ぶ。すべての肉なるものが、再び洪水によって断ち切られることはなく、地を滅ぼす洪水は二度と起こらない。」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="創世記 17:11; マタイ 26:26–28; 出エジプト記 12:13"> 神は言われた。「これは、わたしとあなたがた、またあなたがたと一緒にいるすべての生き物との間に、代々永遠に結ぶ契約のしるしである。</span>
<span className="v" id="v13" data-v="13" data-xref="エゼキエル書 1:28; ヨハネの黙示録 4:3; ヨハネの黙示録 10:1"> わたしは雲の中にわたしの虹を置く。それが、わたしと地との間の契約のしるしとなる。</span>
<span className="v" id="v14" data-v="14"> わたしが地の上に雲を起こし、雲の中に虹が現れるとき、</span>
<span className="v" id="v15" data-v="15" data-xref="申命記 7:9; エゼキエル書 16:60; イザヤ書 54:8–10"> わたしは、わたしとあなたがた、またすべての肉なるあらゆる生き物との間にあるわたしの契約を思い起こす。水が再び洪水となって、すべての肉なるものを滅ぼすことはない。</span>
<span className="v" id="v16" data-v="16" data-xref="イザヤ書 54:8–10; エレミヤ書 32:40; サムエル記第二 23:5"> 雲の中に虹があるとき、わたしはそれを見て、神と、地の上にあるすべての肉なるあらゆる生き物との間の永遠の契約を思い起こす。」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17"> 神はノアに言われた。「これが、わたしと、地の上にあるすべての肉なるものとの間に、わたしが立てた契約のしるしである。」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="創世記 10:1; 創世記 10:6; 創世記 9:25–27"> 箱舟から出たノアの息子たちは、セム、ハム、ヤペテであった。ハムはカナンの父である。</span>
<span className="v" id="v19" data-v="19" data-xref="歴代誌上 1:4–28; 創世記 8:17; 創世記 5:32"> この三人がノアの息子たちであり、彼らから全地の人々が広がった。</span>
</div>
<div className="bp poetry">
<span className="v" id="v20" data-v="20" data-xref="申命記 20:6; 箴言 10:11; イザヤ書 28:24–26"> ノアは農夫となり、ぶどう園を作った。</span>
<span className="v" id="v21" data-v="21" data-xref="箴言 20:1; ハバクク書 2:15–16; 箴言 23:31–32"> 彼はぶどう酒を飲んで酔い、天幕の中で裸になっていた。</span>
<span className="v" id="v22" data-v="22" data-xref="箴言 30:17; ガラテヤ人への手紙 6:1; マタイ 18:15"> カナンの父であるハムは、父の裸を見て、外にいる二人の兄弟に告げた。</span>
<span className="v" id="v23" data-v="23" data-xref="ガラテヤ人への手紙 6:1; 出エジプト記 20:12; テモテへの手紙第一 5:17"> セムとヤペテは衣を取り、それを二人の肩に掛け、後ろ向きに歩いて行き、父の裸を覆った。彼らは顔を背けていたので、父の裸を見なかった。</span>
<span className="v" id="v24" data-v="24"> ノアはぶどう酒から覚め、末の息子が自分にしたことを知った。</span>
<span className="v" id="v25" data-v="25" data-xref="ヨシュア記 9:23; 申命記 27:16; 士師記 1:28–30"> 彼は言った。<br /><span className="pl pl-1">「カナンは呪われよ。</span><br /><span className="pl pl-2">彼は兄弟たちのしもべのしもべとなる。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v26" data-v="26" data-xref="詩篇 144:15; 創世記 12:1–3; ルカ 3:23–36"> 彼は言った。<br /><span className="pl pl-1">「セムの神である主は祝福されよ。</span><br /><span className="pl pl-2">カナンはセムのしもべとなれ。</span></span>
<span className="v" id="v27" data-v="27" data-xref="ローマ人への手紙 11:12; ローマ人への手紙 15:12; ヘブル人への手紙 11:9–10"> <span className="pl pl-1">神がヤペテを広げてくださるように。</span><br /><span className="pl pl-2">ヤペテがセムの天幕に住むように。</span><br /><span className="pl pl-2">カナンは彼のしもべとなれ。」</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28"> 洪水のあと、ノアは三百五十年生きた。</span>
<span className="v" id="v29" data-v="29" data-xref="創世記 5:27; 詩篇 90:10; 創世記 5:32"> こうして、ノアの全生涯は九百五十年であった。そして彼は死んだ。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 42:25; 創世記 43:16; 創世記 24:2"> ヨセフは自分の家の管理人に命じた。「あの人々の袋に、彼らが運べるだけの食料を満たしなさい。そして、それぞれの銀をその袋の口に入れなさい。</span>
<span className="v" id="v2" data-v="2" data-xref="コリント人への第二の手紙 8:8; 創世記 42:20; 申命記 8:16"> また、私の杯、あの銀の杯を、一番下の者の袋の口に、彼の穀物の代金の銀と一緒に入れなさい。」管理人はヨセフが言った言葉のとおりに行った。</span>
<span className="v" id="v3" data-v="3"> 朝が明るくなるとすぐに、彼らはろばと共に送り出された。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネ 10:32; 詩篇 35:12; 箴言 17:13"> 彼らが町を出て、まだ遠くへ行かないうちに、ヨセフは管理人に言った。「立って、あの人々を追いかけなさい。彼らに追いついたら、こう言いなさい。『なぜあなたがたは、善に悪を返したのか。</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 30:27; レビ記 19:26; 列王記第二 21:6"> これは私の主人が飲む杯であり、また占いに用いるものではないか。あなたがたのしたことは悪である。』」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6"> 管理人は彼らに追いつき、これらの言葉を彼らに語った。</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 38:16–18; 創世記 37:18–32; 列王記第二 8:13"> 彼らは彼に言った。「ご主人様、なぜそのようなことを言われるのですか。あなたのしもべたちがそのようなことをするなど、決してあり得ません。</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 43:12; 創世記 42:35; ローマ人への手紙 13:9"> 見よ、私たちは自分たちの袋の口に見つけた銀を、カナンの地からあなたに持ち帰りました。どうして私たちが、あなたの主人の家から銀や金を盗むでしょうか。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 31:32; 詩篇 7:3–5; ヨブ記 31:38–40"> あなたのしもべたちのうち、それが誰のところで見つかったとしても、その者は死なせてください。私たちもご主人様の奴隷になります。」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="出エジプト記 22:3; 創世記 44:17; 創世記 44:33"> 彼は言った。「それでは、あなたがたの言葉のとおりにしよう。それが見つかった者は私の奴隷となり、あなたがたは無罪となる。」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11"> そこで彼らは急いで、それぞれ自分の袋を地面に下ろし、それぞれ自分の袋を開けた。</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 44:26–32; 創世記 42:36–38; 創世記 43:14"> 管理人は一番上の者から始め、一番下の者で終わるように探した。すると杯はベニヤミンの袋で見つかった。</span>
<span className="v" id="v13" data-v="13" data-xref="サムエル記第二 1:11; 創世記 37:29–34; サムエル記第二 1:2"> 彼らは衣を引き裂き、それぞれろばに荷を積み直して町へ戻った。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="創世記 50:18; 創世記 43:25; 創世記 43:16"> ユダとその兄弟たちはヨセフの家に来た。ヨセフはまだそこにいた。彼らは彼の前で地にひれ伏した。</span>
<span className="v" id="v15" data-v="15" data-xref="創世記 4:10; 創世記 21:26; 創世記 3:13"> ヨセフは彼らに言った。「あなたがたがしたこの仕業は何だ。私のような者が、確かに占いをすることを知らなかったのか。」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="創世記 44:9; ダニエル書 9:7; 民数記 32:23"> ユダは言った。「ご主人様に何と申し上げましょうか。何を語りましょうか。どのようにして潔白を示せるでしょうか。神があなたのしもべたちの咎を見つけ出されたのです。見よ、私たちはご主人様の奴隷です。私たちも、手から杯が見つかった者もです。」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="箴言 17:15; サムエル記第二 23:3; 創世記 18:25"> ヨセフは言った。「私がそのようなことをするなど、決してあり得ない。手から杯が見つかった者だけが私の奴隷となる。あなたがたは、安らかに父のところへ上って行きなさい。」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="出エジプト記 32:22; 創世記 41:40; 創世記 18:30"> そのとき、ユダは彼に近づいて言った。「ご主人様、どうか、しもべに一言申し上げさせてください。しもべに怒りを燃やさないでください。あなたはファラオにも等しい方です。</span>
<span className="v" id="v19" data-v="19" data-xref="創世記 43:7; 創世記 43:29; 創世記 42:7–10"> ご主人様はしもべたちに尋ねて、『あなたがたには父、あるいは兄弟がいるか』と言われました。</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 37:3; 創世記 42:38; ルカ 7:12"> 私たちはご主人様に言いました。『私たちには年老いた父と、父が年老いてから生まれた幼い子がいます。その子の兄は死に、母の子として彼だけが残されているので、父は彼を愛しています。』</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 42:15; 創世記 42:20; アモス書 9:4"> あなたはしもべたちに、『その子を私のところへ連れて下れ。私がこの目で見よう』と言われました。</span>
<span className="v" id="v22" data-v="22" data-xref="創世記 44:30; 創世記 42:38"> 私たちはご主人様に言いました。『あの少年は父から離れることができません。もし父から離れれば、父は死んでしまうでしょう。』</span>
<span className="v" id="v23" data-v="23" data-xref="創世記 43:5; 創世記 43:3; 創世記 42:15–20"> しかしあなたはしもべたちに言われました。『あなたがたの一番下の弟が一緒に下って来ない限り、あなたがたは二度と私の顔を見てはならない。』</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 42:29–34"> 私たちはあなたのしもべである私の父のところへ上って行き、ご主人様の言葉を父に告げました。</span>
<span className="v" id="v25" data-v="25" data-xref="創世記 43:2; 創世記 43:5"> 私たちの父は言いました。『また行って、私たちのために少し食物を買って来なさい。』</span>
<span className="v" id="v26" data-v="26" data-xref="ルカ 11:7; 創世記 43:4–5"> 私たちは言いました。『私たちは下って行くことはできません。もし一番下の弟が私たちと一緒なら、下って行きます。一番下の弟が私たちと一緒でなければ、あの方の顔を見ることができないからです。』</span>
<span className="v" id="v27" data-v="27" data-xref="創世記 46:19; 創世記 35:16–18; 創世記 30:22–25"> あなたのしもべである私の父は私たちに言いました。『私の妻が私に二人の息子を産んだことを、あなたがたは知っている。</span>
<span className="v" id="v28" data-v="28" data-xref="創世記 37:33; 創世記 37:13–14; 創世記 42:36"> 一人は私のもとから出て行ったので、私は「きっと彼は引き裂かれたのだ」と言った。そして、それ以来彼を見ていない。</span>
<span className="v" id="v29" data-v="29" data-xref="創世記 42:38; 創世記 43:14; 申命記 31:17"> もしあなたがたがこの子までも私から奪い去り、彼に災いが降りかかれば、あなたがたは白髪の私を悲しみと共にシェオル<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="シェオルは死者の場所である。">a</a></sup>へ下らせることになる。』</span>
<span className="v" id="v30" data-v="30" data-xref="サムエル記第一 18:1; サムエル記第二 18:33; 創世記 44:31"> ですから今、私がしもべである父のところへ帰ったとき、あの少年が一緒でなければ――父の命はあの少年の命と固く結ばれています――</span>
<span className="v" id="v31" data-v="31" data-xref="創世記 44:29; 創世記 37:35; コリント人への第二の手紙 7:10"> 父はあの少年がいないのを見て、死んでしまうでしょう。しもべどもは、年老いた父を、悲しみのうちにシェオル<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="シェオルは死者の場所である。">b</a></sup>へ下らせることになります。</span>
<span className="v" id="v32" data-v="32" data-xref="創世記 43:8–9; 創世記 43:16"> あなたのしもべは父に対し、あの少年の保証人となって、『もし私が彼をあなたのもとに連れ帰らなかったなら、私は一生、父に対してその罪を負います』と言ったのです。</span>
<span className="v" id="v33" data-v="33" data-xref="ヨハネの手紙第一 3:16; 出エジプト記 32:32; ヘブル人への手紙 7:22"> ですから今、どうかあなたのしもべをあの少年の代わりに、ご主人様の奴隷としてとどまらせてください。あの少年は兄弟たちと一緒に上って行かせてください。</span>
<span className="v" id="v34" data-v="34" data-xref="エステル記 8:6; 詩篇 116:3; 詩篇 119:143"> あの少年を伴わずに、どうして父のところへ上れるでしょう。父に降りかかる災いを、私は見ることができません。」</span>
</div>

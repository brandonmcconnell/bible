<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="詩篇 12:6; 創世記 18:10; 創世記 18:14"> 主は言われたとおりにサラを顧みられ、主は語られたとおりにサラになされた。</span>
<span className="v" id="v2" data-v="2" data-xref="ガラテヤ人への手紙 4:22; ヘブル人への手紙 11:11; 創世記 18:10"> サラは身ごもり、神がアブラハムに告げられた定めの時に、年老いたアブラハムに男の子を産んだ。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 17:19; ローマ人への手紙 9:7; 創世記 21:6"> アブラハムは、自分に生まれた息子、サラが彼に産んだ息子をイサク<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="イサクは「彼は笑う」を意味する。">a</a></sup>と名付けた。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒の働き 7:8; 申命記 12:32; ヨハネ 7:22–23"> アブラハムは、神が彼に命じられたとおり、息子イサクが生まれて八日目に割礼を施した。</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 17:17; ローマ人への手紙 4:19; 創世記 17:1"> 息子イサクが生まれたとき、アブラハムは百歳であった。</span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 126:2; イザヤ書 54:1; 創世記 17:17"> サラは言った。「神は私を笑わせてくださいました。これを聞く者は皆、私と一緒に笑うでしょう。」</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 18:11–12; イザヤ書 66:8; テサロニケ人への第二の手紙 1:10"> 彼女はまた言った。「サラが子に乳を飲ませると、誰がアブラハムに言えただろう。だが私は、年老いた彼に男の子を産んだ。」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="サムエル記第一 1:22; ホセア書 1:8; 創世記 40:20"> その子は育ち、乳離れした。イサクが乳離れした日に、アブラハムは盛大な宴会を催した。</span>
<span className="v" id="v9" data-v="9" data-xref="ガラテヤ人への手紙 4:29; 創世記 16:15; ガラテヤ人への手紙 4:22"> サラは、エジプト人ハガルがアブラハムに産んだ息子が、イサクをからかっているのを見た。</span>
<span className="v" id="v10" data-v="10" data-xref="ヨハネ 8:35; ヨハネの手紙第一 2:19; ガラテヤ人への手紙 4:22–31"> それで彼女はアブラハムに言った。「この女のしもべとその息子を追い出してください。この女のしもべの息子は、私の息子イサクと一緒に跡継ぎになるべきではありません。」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="ヘブル人への手紙 12:11; 創世記 17:18; マタイ 10:37"> 自分の息子のことだったので、このことはアブラハムにとって非常につらかった。</span>
<span className="v" id="v12" data-v="12" data-xref="ヘブル人への手紙 11:18; ローマ人への手紙 9:7–8; 創世記 17:19"> 神はアブラハムに言われた。「この少年とあなたの女のしもべのことで、つらく思ってはならない。サラがあなたに言うことはすべて、彼女の声に聞き従いなさい。イサクから出る者が、あなたの子孫と呼ばれるからである。</span>
<span className="v" id="v13" data-v="13" data-xref="創世記 16:10; 創世記 17:20; 創世記 21:18"> 女のしもべの息子もまた、わたしは一つの民族とする。彼もあなたの子だからである。」</span>
<span className="v" id="v14" data-v="14" data-xref="伝道者の書 9:10; 詩篇 119:60; 創世記 16:7"> アブラハムは朝早く起き、パンと水の皮袋を取り、ハガルに与えて彼女の肩に載せ、少年も託して、彼女を送り出した。彼女は立ち去り、ベエル・シェバの荒野をさまよった。</span>
<span className="v" id="v15" data-v="15" data-xref="列王記第二 3:9; 詩篇 63:1; エレミヤ書 14:3"> 皮袋の水が尽きると、彼女は少年を一本の灌木の下に置いた。</span>
<span className="v" id="v16" data-v="16" data-xref="イザヤ書 49:15; 創世記 29:11; サムエル記第一 24:16"> 彼女は離れて行き、弓の届くほど遠くに座った。「少年が死ぬのを見たくない」と思ったからである。彼女はその向こうに座り、声を上げて泣いた。</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 16:11; 詩篇 50:15; 出エジプト記 3:7"> 神は少年の声を聞かれた。<br />神の使いは天からハガルを呼んで言った。「ハガルよ、どうしたのか。恐れてはならない。神は、あそこにいる少年の声を聞かれたからである。</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 21:13; 創世記 16:10; 創世記 17:20"> 立ち上がり、少年を起こして、あなたの手で彼をしっかり支えなさい。わたしは彼を大いなる民族とするからである。」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="民数記 22:31; 列王記第二 6:17–20; イザヤ書 35:5–6"> 神が彼女の目を開かれたので、彼女は水の井戸を見た。彼女は行って皮袋に水を満たし、少年に飲ませた。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="創世記 28:15; 創世記 39:21; 創世記 16:12"> 神は少年と共におられ、彼は成長した。彼は荒野に住み、弓を射る者となった。</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 26:34–35; 創世記 24:3–4; 民数記 12:16"> 彼はパランの荒野に住んだ。彼の母はエジプトの地から彼のために妻を迎えた。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="ヨシュア記 3:7; 創世記 26:26; 創世記 26:28"> そのころ、アビメレクとその軍の長フィコルはアブラハムに言った。「あなたがすることすべてに、神はあなたと共におられる。</span>
<span className="v" id="v23" data-v="23" data-xref="ヨシュア記 2:12; 創世記 20:14; ヘブル人への手紙 6:16"> だから今、ここで神にかけて私に誓ってほしい。私にも、私の子にも、私の子孫にも、決して偽りを行わないと。私があなたに示した慈しみに応じて、私と、あなたが寄留しているこの地に対して、あなたも行ってほしい。」</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="ヘブル人への手紙 6:16; 創世記 14:13; ローマ人への手紙 12:18"> アブラハムは言った。「私は誓います。」</span>
<span className="v" id="v25" data-v="25" data-xref="創世記 26:15–22; 創世記 29:8; 箴言 25:9"> アブラハムは、アビメレクのしもべたちが力ずくで奪い取った水の井戸のことで、アビメレクに苦情を言った。</span>
<span className="v" id="v26" data-v="26" data-xref="創世記 13:7; 列王記第二 5:20–24"> アビメレクは言った。「誰がそんなことをしたのか、私は知らない。あなたも私に告げず、私も今日まで聞いていなかった。」</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="創世記 14:22–23; イザヤ書 32:8; ローマ人への手紙 1:31"> アブラハムは羊と牛を取ってアビメレクに与え、二人は契約を結んだ。</span>
<span className="v" id="v28" data-v="28"> アブラハムは羊の群れから、七匹の雌の小羊を別にして置いた。</span>
<span className="v" id="v29" data-v="29" data-xref="サムエル記第一 15:14; 創世記 33:8; 出エジプト記 12:26"> アビメレクはアブラハムに言った。「あなたが別にして置いたこの七匹の雌の小羊は、どういう意味なのか。」</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="創世記 31:52; ヨシュア記 24:27; ヨシュア記 22:27–28"> 彼は言った。「この七匹の雌の小羊を私の手から受け取ってください。私がこの井戸を掘ったことの証しとなります。」</span>
<span className="v" id="v31" data-v="31" data-xref="創世記 26:33; 創世記 21:14; 列王記第一 4:25"> それゆえ、彼はその場所をベエル・シェバ<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="ベエル・シェバは「誓いの井戸」または「七の井戸」を意味し得る。">b</a></sup>と呼んだ。そこで二人が誓いを立てたからである。</span>
<span className="v" id="v32" data-v="32" data-xref="出エジプト記 13:17; 創世記 21:27; 士師記 13:1"> こうして彼らはベエル・シェバで契約を結んだ。アビメレクと軍の長フィコルは立ち上がり、ペリシテ人の地へ帰って行った。</span>
<span className="v" id="v33" data-v="33" data-xref="テモテへの手紙第一 1:17; イザヤ書 40:28; 詩篇 90:2"> アブラハムはベエル・シェバに一本のぎょりゅうの木を植え、そこで永遠の神である主の御名を呼び求めた。</span>
<span className="v" id="v34" data-v="34" data-xref="歴代誌上 29:15; ペテロの手紙第一 2:11; ヘブル人への手紙 11:9"> アブラハムは長い間、ペリシテ人の地に寄留した。</span>
</div>
</div>

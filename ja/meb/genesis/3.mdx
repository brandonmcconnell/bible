<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="コリント人への第二の手紙 11:3; コリント人への第二の手紙 11:14; ヨハネの黙示録 12:9"> 主なる神が造られた野のすべての動物の中で、蛇は最も狡猾であった。蛇は女に言った。「神は本当に、『園のどの木からも食べてはならない』と言われたのか。」</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="詩篇 58:4"> 女は蛇に言った。「私たちは園の木の実を食べてもよい。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 2:16–17; コリント人への第二の手紙 6:17; 出エジプト記 19:12–13"> しかし、園の中央にある木の実については、神は『それを食べてはならない。それに触れてもならない。あなたがたが死なないためだ』と言われた。」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="ヨハネ 8:44; コリント人への第二の手紙 11:3; テモテへの手紙第一 2:14"> 蛇は女に言った。「あなたがたは決して死なない。</span>
<span className="v" id="v5" data-v="5" data-xref="エゼキエル書 28:2; テサロニケ人への第二の手紙 2:4; コリント人への第二の手紙 11:13–15"> それを食べたその日に、あなたがたの目が開かれ、神のようになって善と悪を知るようになることを、神は知っているのだ。」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="ヨハネの手紙第一 2:16; ヤコブの手紙 1:14–15; テモテへの手紙第一 2:14"> 女がその木を見ると、それは食物として良く、目に好ましく、賢くなるために望ましいものであった。そこで女はその実を取って食べ、一緒にいた夫にも与えた。彼もそれを食べた。</span>
<span className="v" id="v7" data-v="7" data-xref="イザヤ書 59:6; 創世記 2:25; 創世記 3:5"> すると、二人の目は開かれ、自分たちが裸であることを知った。彼らはイチジクの葉をつなぎ合わせ、自分たちのために腰を覆うものを作った。</span>
<span className="v" id="v8" data-v="8" data-xref="エレミヤ書 23:24; 箴言 15:3; ヘブル人への手紙 4:13"> 彼らは、日の涼しい頃に、主なる神が園を歩かれる音を聞いた。人とその妻は、主なる神の御前を避けて、園の木々の間に身を隠した。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="創世記 4:9; 創世記 16:8; 創世記 18:20–21"> 主なる神は人に呼びかけ、彼に言われた。「あなたはどこにいるのか。」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="創世記 2:25; 詩篇 119:120; イザヤ書 47:3"> 人は言った。「園であなたの声を聞きました。私は裸だったので恐れ、身を隠しました。」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="ローマ人への手紙 3:20; 創世記 4:10; 詩篇 50:21"> 神は言われた。「あなたが裸であることを、誰があなたに告げたのか。食べてはならないとわたしが命じたあの木から、あなたは食べたのか。」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="箴言 28:13; ヤコブの手紙 1:13–15; ヨブ記 31:33"> 人は言った。「あなたが私のそばに置かれたこの女が、あの木から実をくれたので、私は食べました。」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="コリント人への第二の手紙 11:3; テモテへの手紙第一 2:14; 創世記 4:10–12"> 主なる神は女に言われた。「あなたは何ということをしたのか。」<br />女は言った。「蛇が私を欺いたので、私は食べました。」</span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="ミカ書 7:17; イザヤ書 65:25; 詩篇 72:9"> 主なる神は蛇に言われた。<br /><span className="pl pl-1">「このことをしたゆえに、</span><br /><span className="pl pl-2">あなたはすべての家畜、</span><br /><span className="pl pl-2">すべての野の動物の中で呪われる。</span><br /><span className="pl pl-1">あなたは腹ばいで進み、</span><br /><span className="pl pl-2">一生の日々、ちりを食べる。</span></span>
<span className="v" id="v15" data-v="15" data-xref="ローマ人への手紙 16:20; ヨハネの手紙第一 3:8; ヨハネの黙示録 12:17"> <span className="pl pl-1">わたしは、あなたと女との間に、</span><br /><span className="pl pl-2">あなたの子孫と女の子孫との間に敵意を置く。</span><br /><span className="pl pl-1">彼はあなたの頭を打ち砕き、</span><br /><span className="pl pl-2">あなたは彼のかかとを傷つける。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v16" data-v="16" data-xref="テトス 2:5; コロサイ人への手紙 3:18; コリント人への第一の手紙 11:3"> 女に神は言われた。<br /><span className="pl pl-1">「わたしは、あなたの身ごもりの苦しみを大いに増す。</span><br /><span className="pl pl-2">あなたは苦しんで子を産む。</span><br /><span className="pl pl-1">あなたは夫を慕い求め、</span><br /><span className="pl pl-2">彼はあなたを支配する。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v17" data-v="17" data-xref="ローマ人への手紙 8:20–22; 創世記 5:29; イザヤ書 24:5–6"> アダムに神は言われた。<br /><span className="pl pl-1">「あなたは妻の声に聞き従い、</span><br /><span className="pl pl-2">『それから食べてはならない』と</span><br /><span className="pl pl-2">わたしが命じた木から食べた。</span><br /><span className="pl pl-1">地はあなたのゆえに呪われる。</span><br /><span className="pl pl-2">あなたは一生の日々、苦労して地から食物を得る。</span></span>
<span className="v" id="v18" data-v="18" data-xref="マタイ 13:7; ヨブ記 5:5; イザヤ書 7:23"> <span className="pl pl-1">地はあなたのために、いばらとあざみを生えさせる。</span><br /><span className="pl pl-2">あなたは野の草を食べる。</span></span>
<span className="v" id="v19" data-v="19" data-xref="伝道者の書 12:7; ヨブ記 34:15; 詩篇 104:29"> <span className="pl pl-1">あなたは顔に汗を流してパンを食べ、</span><br /><span className="pl pl-2">ついに土に帰る。</span><br /><span className="pl pl-1">あなたはそこから取られた。</span><br /><span className="pl pl-1">あなたはちり。</span><br /><span className="pl pl-2">ちりに帰る。」</span></span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="創世記 2:23; マタイ 1:23; 創世記 5:29"> 人は妻をエバと名付けた。彼女がすべての生きる者の母となるからである。</span>
<span className="v" id="v21" data-v="21" data-xref="イザヤ書 61:10; コリント人への第二の手紙 5:21; コリント人への第二の手紙 5:2–3"> 主なる神は、アダムと彼の妻のために皮の衣を作り、彼らに着せられた。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="ヨハネの黙示録 2:7; ヨハネの黙示録 22:14; 箴言 3:18"> 主なる神は言われた。「見よ、人はわれわれの一人のようになり、善と悪を知るようになった。今、彼が手を伸ばし、命の木からも取って食べ、永遠に生きることがないようにしよう。」</span>
<span className="v" id="v23" data-v="23" data-xref="創世記 4:2; 創世記 3:19; 創世記 4:12"> そこで主なる神は彼をエデンの園から送り出し、彼が取られた土を耕させた。</span>
<span className="v" id="v24" data-v="24" data-xref="ヘブル人への手紙 1:7; 詩篇 104:4; 出エジプト記 25:18–22"> こうして神は人を追放し、命の木への道を守るために、エデンの園の東にケルビム<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="ケルビムは、神に仕える力ある天的な存在である。エゼキエル書10章を参照。">a</a></sup>と、四方に向かって回転する炎の剣を置かれた。</span>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マタイ 24:37–39; ペテロの第二の手紙 2:5–9; 創世記 6:9"> 主はノアに言われた。「あなたとあなたの家族は皆、箱舟に入りなさい。この世代の中で、あなたがわたしの前に正しい者であることを見たからである。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 8:20; レビ記 10:10; レビ記 11:1–47"> あなたは、清いすべての動物の中から、雄と雌を七つがいずつ連れて行きなさい。清くない動物の中からは、雄と雌を一つがいずつ連れて行きなさい。</span>
<span className="v" id="v3" data-v="3"> 空の鳥の中からも、雄と雌を七つがいずつ連れて行きなさい。全地の表に、その種を生かしておくためである。</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 6:13; 創世記 7:12; 創世記 7:17"> あと七日で、わたしは四十日四十夜、地の上に雨を降らせる。わたしが造ったすべての生き物を、地の表から消し去る。」</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 6:22; ルカ 8:21; 出エジプト記 39:32"> ノアは、主が命じられたすべてのとおりに行った。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="創世記 5:32; 創世記 8:13"> 地に大水による洪水が起こったとき、ノアは六百歳であった。</span>
<span className="v" id="v7" data-v="7" data-xref="ルカ 17:27; 創世記 6:18; マタイ 24:38"> ノアは洪水から逃れるため、息子たち、妻、息子たちの妻たちと一緒に箱舟に入った。</span>
<span className="v" id="v8" data-v="8"> 清い動物、清くない動物、鳥、地面を這うすべてのものは、</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 7:16; 創世記 2:19; エレミヤ書 8:7"> 神がノアに命じられたとおりに、雄と雌のつがいになって、ノアのところに来て箱舟に入った。</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 6:17; 創世記 7:4; ルカ 17:27"> 七日後、大水による洪水が地に起こった。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 8:2; マラキ書 3:10; 箴言 8:28–29"> ノアの生涯の六百年目、第二の月、その月の十七日、その日に、大いなる淵の源がすべて裂け、天の窓が開かれた。</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 7:4; マタイ 4:2; 創世記 7:17"> そして、四十日四十夜、地の上に雨が降った。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="創世記 6:18; 創世記 7:1; 創世記 6:10"> まさにその日、ノアは箱舟に入った。ノアの息子たちセム、ハム、ヤペテ、ノアの妻、息子たちの三人の妻たちも一緒であった。</span>
<span className="v" id="v14" data-v="14" data-xref="創世記 7:8–9; 創世記 7:2–3"> 彼らと、それぞれの種類にしたがったすべての野の動物、それぞれの種類にしたがったすべての家畜、それぞれの種類にしたがって地を這うすべてのもの、それぞれの種類にしたがったすべての鳥、翼のあるすべてのものが入った。</span>
<span className="v" id="v15" data-v="15" data-xref="創世記 6:19–20; イザヤ書 11:6"> 命の息を持つすべての肉なるものが、つがいになってノアのところに来て箱舟に入った。</span>
<span className="v" id="v16" data-v="16" data-xref="マタイ 25:10; ルカ 13:25; 詩篇 91:1–10"> 神がノアに命じられたとおりに、すべての肉なるものの雄と雌が入った。その後、主はノアの後ろで戸を閉ざされた。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="創世記 7:4; 創世記 7:12"> 洪水は四十日間、地の上に続いた。水は増して箱舟を押し上げ、箱舟は地から浮かび上がった。</span>
<span className="v" id="v18" data-v="18" data-xref="出エジプト記 14:28; 詩篇 69:15; ヨブ記 22:16"> 水は勢いを増し、地の上で大いに増し加わった。箱舟は水面を漂った。</span>
<span className="v" id="v19" data-v="19" data-xref="詩篇 104:6–9; 詩篇 46:2–3; ペテロの第二の手紙 3:6"> 水は地の上でますます激しく勢いを増し、全天の下にある高い山々はすべて覆われた。</span>
<span className="v" id="v20" data-v="20" data-xref="エレミヤ書 3:23; 詩篇 104:6"> 水はさらに十五キュビト高くなり、山々は覆われた。</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 6:13; 創世記 7:4; 創世記 6:17"> 地の上を動くすべての肉なるものは死んだ。鳥、家畜、野の動物、地に群がるすべての這うもの、そしてすべての人が死んだ。</span>
<span className="v" id="v22" data-v="22" data-xref="創世記 2:7; 創世記 6:17"> 乾いた地にいて、その鼻に命の霊の息を持つすべてのものが死んだ。</span>
<span className="v" id="v23" data-v="23" data-xref="ペテロの第二の手紙 2:5; ペテロの手紙第一 3:20; ヘブル人への手紙 11:7"> 人、家畜、這うもの、空の鳥を含む、地の表にいたすべての生き物が消し去られた。それらは地から消し去られた。ノアと、彼と一緒に箱舟にいた者たちだけが残った。</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 8:3–4"> 水は百五十日の間、地を覆い続けた。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 14:13; 創世記 48:3; 創世記 13:18"> 日の暑いころ、アブラハムが天幕の入り口に座っていると、マムレの樫の木々のそばで、主が彼に現れた。</span>
<span className="v" id="v2" data-v="2" data-xref="ヘブル人への手紙 13:2; 創世記 18:22; 創世記 19:1"> 彼が目を上げて見ると、三人の人が彼の近くに立っていた。彼らを見ると、アブラハムは天幕の入り口から走って行って彼らを出迎え、地にひれ伏して、</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 32:5"> 言った。「ご主人様。私があなたのお目にかなっているなら、どうか、しもべのもとを通り過ぎないでください。</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 24:32; 創世記 19:2; 創世記 43:24"> 少しの水を持って来させますから、あなたがたは足を洗い、木の下で休んでください。</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 104:15; 士師記 13:15; 士師記 6:18"> 少しのパンを持って来ます。元気を取り戻してから、旅を続けてください。せっかく、しもべのもとにお立ち寄りくださったのですから。」<br />彼らは言った。「そうしてください。あなたの言うとおりにしてください。」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="マタイ 13:33; ヘブル人への手紙 13:2; 使徒の働き 16:15"> アブラハムは急いで天幕のサラのところへ行き、「早く、上等の小麦粉を三セア<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="1セアは約7リットル、または1.9ガロン、あるいは0.8ペックである。">a</a></sup>用意してこね、パン菓子を作ってくれ」と言った。</span>
<span className="v" id="v7" data-v="7" data-xref="マラキ書 1:14; ルカ 15:27; ルカ 15:30"> アブラハムは牛の群れへ走って行き、柔らかくて良い子牛を取り、しもべに渡した。しもべは急いでそれを調理した。</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 19:3; 士師記 13:15; ヨハネの黙示録 3:20"> アブラハムは凝乳と乳と、調理した子牛を持って来て、彼らの前に置いた。彼が木の下で彼らのそばに立っている間に、彼らは食べた。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="テトス 2:5; 創世記 24:67; 創世記 4:9"> 彼らはアブラハムに尋ねた。「あなたの妻サラはどこにいますか。」<br />彼は言った。「あそこ、天幕の中です。」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="創世記 21:2; 創世記 17:21; ローマ人への手紙 9:8–9"> その一人が言った。「来年の今ごろ、わたしは必ずあなたのところに戻って来る。見よ、あなたの妻サラには男の子が生まれているだろう。」<br />サラは彼の後ろにある天幕の入り口で聞いていた。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 17:17; ヘブル人への手紙 11:11–12; ルカ 1:36"> アブラハムとサラは年を取り、非常に高齢であった。サラはすでに子を産む年齢を過ぎていた。</span>
<span className="v" id="v12" data-v="12" data-xref="ペテロの手紙第一 3:6; 創世記 17:17; ルカ 1:18–20"> サラは心の中で笑って言った。「年老いた私に、このような喜びがあるだろうか。私の主人も年老いているのに。」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="ヨハネ 2:25"> 主はアブラハムに言われた。「なぜサラは笑って、『年老いた私が、本当に子を産めるだろうか』と言ったのか。</span>
<span className="v" id="v14" data-v="14" data-xref="ルカ 1:37; マタイ 19:26; マルコ 10:27"> 主にとって不可能なことがあるだろうか。定められた時に、来年の今ごろ、わたしはあなたのところに戻って来る。そのとき、サラには男の子が生まれている。」</span>
<span className="v" id="v15" data-v="15" data-xref="ヨハネの手紙第一 1:8; 箴言 28:13; エペソ人への手紙 4:23"> サラは恐ろしくなり、「私は笑っていません」と否定した。<br />彼は言った。「いや、あなたは笑った。」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="使徒の働き 15:3; 使徒の働き 21:5; 使徒の働き 20:38"> その人たちはそこから立ち上がり、ソドムの方を見下ろした。アブラハムは彼らを見送るために、一緒に行った。</span>
<span className="v" id="v17" data-v="17" data-xref="アモス書 3:7; 詩篇 25:14; ヨハネ 15:15"> 主は言われた。「わたしがしようとしていることを、アブラハムに隠しておくべきだろうか。</span>
<span className="v" id="v18" data-v="18" data-xref="ガラテヤ人への手紙 3:8; 創世記 26:4; ガラテヤ人への手紙 3:14"> アブラハムは必ず大いなる強い民族となり、地上のすべての国々は彼によって祝福されるというのに。</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 6:6–7; 申命記 4:9–10; テモテへの手紙第一 3:4–5"> わたしが彼を選んだのは、彼が後の子どもたちと家族に命じて、主の道を守らせ、義と公義を行わせるためである。それは、主がアブラハムについて語ったことを、彼の上に実現するためである。」</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 19:13; エゼキエル書 16:49–50; イザヤ書 3:9"> 主は言われた。「ソドムとゴモラへの叫びは大きく、彼らの罪は非常に重い。</span>
<span className="v" id="v21" data-v="21" data-xref="出エジプト記 3:8; 創世記 11:5; ゼパニヤ書 1:12"> わたしは今から下って行き、わたしに届いた叫びのとおりに彼らが悪を行っているかどうかを見る。もしそうでないなら、わたしはそれを知るだろう。」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="創世記 19:1; 使徒の働き 7:55; エゼキエル書 22:30"> その人たちはそこから向きを変えてソドムへ向かったが、アブラハムはなお主の前に立っていた。</span>
<span className="v" id="v23" data-v="23" data-xref="民数記 16:22; サムエル記第二 24:17; 創世記 20:4"> アブラハムは近づいて言った。「あなたは本当に、義人を悪人と一緒に滅ぼされるのですか。</span>
<span className="v" id="v24" data-v="24" data-xref="エレミヤ書 5:1; イザヤ書 1:9; マタイ 7:13–14"> もしその町に五十人の義人がいたらどうでしょうか。その中にいる五十人の義人のために、その場所を赦さず、滅ぼされるのですか。</span>
<span className="v" id="v25" data-v="25" data-xref="ヨブ記 8:3; イザヤ書 3:10–11; ヨブ記 8:20"> 義人を悪人と共に殺し、義人を悪人と同じように扱うなど、あなたがなさるはずがありません。決してあり得ません。全地を裁く方は、公義を行われるのではありませんか。」</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="エレミヤ書 5:1; マタイ 24:22; イザヤ書 65:8"> 主は言われた。「もしソドムの町の中に五十人の義人が見つかったら、彼らのためにその場所のすべてを赦そう。」</span>
<span className="v" id="v27" data-v="27" data-xref="創世記 3:19; イザヤ書 6:5; コリント人への第一の手紙 15:47–48"> アブラハムは答えた。「私はちりや灰にすぎませんが、あえて主に申し上げます。</span>
<span className="v" id="v28" data-v="28" data-xref="創世記 18:29; 列王記第一 20:32–33; 創世記 18:26"> もし五十人の義人に五人足りなかったらどうでしょうか。その五人足りないために、町のすべてを滅ぼされるのですか。」<br />彼は言われた。「もしそこに四十五人見つかったら、わたしは滅ぼさない。」</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="エペソ人への手紙 6:18; ヘブル人への手紙 4:16"> アブラハムは再び神に語りかけて言った。「もしそこに四十人見つかったらどうでしょうか。」<br />彼は言われた。「その四十人のために、わたしはそれをしない。」</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="詩篇 89:7; 詩篇 9:12; エステル記 4:11–16"> 彼は言った。「主よ、どうかお怒りにならないでください。私は申し上げます。もしそこに三十人見つかったらどうでしょうか。」<br />彼は言われた。「もしそこに三十人見つかったら、わたしはそれをしない。」</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="ルカ 11:8; 創世記 18:27; ルカ 18:1"> 彼は言った。「見よ、私はあえて主に申し上げます。もしそこに二十人見つかったらどうでしょうか。」<br />彼は言われた。「その二十人のために、わたしは滅ぼさない。」</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="ヤコブの手紙 5:15–17; 士師記 6:39; マタイ 7:7"> 彼は言った。「主よ、どうかお怒りにならないでください。私はあと一度だけ申し上げます。もしそこに十人見つかったらどうでしょうか。」<br />彼は言われた。「その十人のために、わたしは滅ぼさない。」</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="創世記 18:22; 創世記 32:26; 創世記 31:55"> 主はアブラハムと語り終えると、去って行かれた。アブラハムも自分の場所へ帰った。</span>
</div>
</div>

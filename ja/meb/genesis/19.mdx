<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 18:22; 創世記 18:1–5; ヘブル人への手紙 13:2"> 夕暮れに二人の御使いがソドムに着いた。ロトはソドムの門に座っていた。ロトは彼らを見ると、立ち上がって出迎え、地に顔を伏せて拝し、</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 18:4; ルカ 24:28–29; ヘブル人への手紙 13:2"> 言った。「見よ、ご主人様。どうか、しもべの家に立ち寄って、一晩泊まり、足を洗ってください。そして、朝早く起きて旅を続けてください。」<br />彼らは言った。「いや、私たちは広場で夜を過ごします。」</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="創世記 18:6–8; 士師記 6:19; サムエル記第一 28:24"> ロトが強く勧めたので、彼らは彼と共に家に入り、彼の家に来た。彼は彼らのために宴会を催し、種なしパンを焼いた。彼らはそれを食べた。</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 13:13; 箴言 4:16; 出エジプト記 23:2"> 彼らがまだ寝ないうちに、その町の男たち、ソドムの男たちが、若者から老人まで、町の隅々からやって来て、家を囲んだ。</span>
<span className="v" id="v5" data-v="5" data-xref="士師記 19:22; イザヤ書 3:9; ユダ 1:7"> 彼らはロトを呼んで言った。「今夜、お前のところに来た男たちはどこにいるのか。彼らを私たちのところに引き出せ。彼らと関係を持つためだ。」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="士師記 19:23"> ロトは戸口にいる彼らのところに出て行き、後ろの戸を閉めて、</span>
<span className="v" id="v7" data-v="7" data-xref="コリント人への第一の手紙 6:9–11; 士師記 19:23; レビ記 20:13"> 言った。「兄弟たち、どうかそんな悪事はしないでくれ。</span>
<span className="v" id="v8" data-v="8" data-xref="士師記 19:24; 創世記 19:31–38; 士師記 9:15"> 見よ、私にはまだ男を知らない二人の娘がいる。どうか彼女たちをあなたがたのところに引き出させてくれ。好きなようにしてくれてよい。ただ、あの男たちには何もしないでくれ。彼らは私の屋根の陰に入って来たのだから。」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="出エジプト記 2:14; ペテロの第二の手紙 2:7–8; 創世記 13:12"> 彼らは言った。「退け！」さらに言った。「この男は寄留者として来たのに、裁判官になろうとしている。今度は彼らよりもお前をひどい目に遭わせてやる。」彼らはロトというこの男に激しく詰め寄り、戸を壊そうと近づいた。</span>
<span className="v" id="v10" data-v="10"> しかし、あの男たちが手を伸ばしてロトを家の中に引き入れ、戸を閉めた。</span>
<span className="v" id="v11" data-v="11" data-xref="列王記第二 6:18; 使徒の働き 13:11; 申命記 28:28–29"> 彼らは家の戸口にいる男たちの目を、小さい者から大きい者までくらませたので、彼らは戸口を見つけようとして疲れ果てた。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="創世記 7:1; ペテロの第二の手紙 2:7; ヨハネの黙示録 18:4"> 男たちはロトに言った。「ほかにあなたの身内の者がここにいるか。あなたの婿たち、あなたの息子たち、娘たち、またこの町にいるあなたの身内の者をみな、ここから連れ出しなさい。</span>
<span className="v" id="v13" data-v="13" data-xref="創世記 18:20; マタイ 13:49–50; ユダ 1:7"> 私たちはこの場所を滅ぼそうとしている。彼らに対する叫びが主の御前で大きくなったので、主はここを滅ぼすために私たちを遣わされたからだ。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="民数記 16:21; エレミヤ書 51:6; 民数記 16:45"> ロトは出て行き、娘たちをめとることになっていた婿たちに言った。「立て。この場所から出よ。主がこの町を滅ぼされる。」<br />しかし、婿たちには彼が冗談を言っているように見えた。</span>
<span className="v" id="v15" data-v="15" data-xref="民数記 16:24–27; ヨハネの黙示録 18:4; 創世記 19:22"> 朝になったとき、御使いたちはロトを急がせて言った。「立って、ここにいるあなたの妻と二人の娘を連れて行きなさい。さもないと、あなたはこの町の罪のために滅ぼされてしまう。」</span>
<span className="v" id="v16" data-v="16" data-xref="ローマ人への手紙 9:15–16; テトス 3:5; ヨハネ 6:44"> しかし彼はためらっていた。主が彼にあわれみをかけられたので、男たちは彼の手と、その妻の手と、二人の娘の手をつかみ、彼らを連れ出して町の外に置いた。</span>
<span className="v" id="v17" data-v="17" data-xref="マタイ 24:16–18; ルカ 9:62; ピリピ人への手紙 3:13–14"> 彼らを外に連れ出したとき、そのうちの一人が言った。「命がけで逃げなさい。後ろを振り返ってはならない。この低地のどこにもとどまってはならない。山へ逃げなさい。さもないと滅ぼされてしまう。」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="ヨハネ 13:6–8; 使徒の働き 10:14; 創世記 32:26"> ロトは彼らに言った。「ご主人様、どうかそんなことがありませんように。</span>
<span className="v" id="v19" data-v="19" data-xref="サムエル記第一 27:1; 詩篇 103:1–22; テモテへの手紙第一 1:14–16"> 見よ、しもべはあなたのお目にかない、あなたは私の命を救って、大いなる慈しみを示してくださいました。しかし私は山まで逃げきれません。災いに追いつかれ、死んでしまいます。</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 119:175; 箴言 3:5–7; 創世記 19:30"> 見よ、あの町なら近く、逃げ込めます。ほんの小さな町です。どうか、そこへ逃げさせてください。小さい町ではありませんか。そうすれば、私は生き延びられます。」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="詩篇 145:19; 詩篇 34:15; 詩篇 102:17"> 彼はロトに言った。「見よ、わたしはこのことでもあなたの願いを聞き入れよう。あなたが語ったその町は滅ぼさない。</span>
<span className="v" id="v22" data-v="22" data-xref="創世記 13:10; 創世記 14:2; 創世記 32:25–28"> 急いでそこへ逃げなさい。あなたがそこに着くまでは、わたしは何もできないからだ。」それゆえ、その町の名はツォアル<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="ツォアルは「小さい」を意味する。">a</a></sup>と呼ばれた。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23"> ロトがツォアルに着いたとき、太陽は地の上に昇っていた。</span>
<span className="v" id="v24" data-v="24" data-xref="申命記 29:23; イザヤ書 13:19; アモス書 4:11"> そのとき、主は、主のもとから、天からソドムとゴモラの上に硫黄と火を降らせた。</span>
<span className="v" id="v25" data-v="25" data-xref="詩篇 107:34; 創世記 14:3; 創世記 13:10"> 主はこれらの町々、低地のすべて、町々のすべての住民、また地の草木を滅ぼされた。</span>
<span className="v" id="v26" data-v="26" data-xref="ルカ 17:31–32; 創世記 19:17; 箴言 14:14"> しかし、ロトの妻は彼の後ろで振り返ったため、塩の柱になった。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="ハバクク書 2:1; 詩篇 5:3; ヘブル人への手紙 2:1"> アブラハムは朝早く起き、主の前に立っていた場所へ行った。</span>
<span className="v" id="v28" data-v="28" data-xref="ヨハネの黙示録 18:9; ヨハネの黙示録 9:2; ヨハネの黙示録 21:8"> 彼がソドムとゴモラ、および低地の全土を見下ろすと、見よ、かまどの煙のように、その地の煙が立ち上っていた。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="創世記 8:1; 申命記 9:5; 創世記 18:23–33"> 神がその低地の町々を滅ぼされたとき、神はアブラハムを心に留められた。そして、ロトが住んでいた町々を滅ぼされたとき、神はその滅びの中からロトを救い出された。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="創世記 19:19; イザヤ書 15:5; ヤコブの手紙 1:8"> ロトはツォアルを出て上って行き、二人の娘と一緒に山に住んだ。彼はツォアルに住むのを恐れたからである。彼は二人の娘と一緒に洞穴に住んだ。</span>
<span className="v" id="v31" data-v="31" data-xref="申命記 25:5; イザヤ書 4:1; 創世記 16:2"> 姉は妹に言った。「私たちの父は年をとり、この地には、世の習いに従って私たちのところに来てくれる男の人はいません。</span>
<span className="v" id="v32" data-v="32" data-xref="レビ記 18:6–7; 創世記 11:3; 創世記 9:21"> さあ、父にぶどう酒を飲ませて、父と一緒に寝ましょう。そうして父によって子孫を残しましょう。」</span>
<span className="v" id="v33" data-v="33" data-xref="ハバクク書 2:15–16; 箴言 23:29–35; 箴言 20:1"> 彼女たちはその夜、父にぶどう酒を飲ませた。そして姉が入り、父と一緒に寝た。父は娘が横になったのも、起き上がったのも知らなかった。</span>
<span className="v" id="v34" data-v="34" data-xref="エレミヤ書 8:12; エレミヤ書 6:15; イザヤ書 3:9"> 翌日、姉は妹に言った。「見よ、私は昨夜、父と寝ました。今夜も父にぶどう酒を飲ませましょう。そしてあなたが入って父と寝て、父によって子孫を残しましょう。」</span>
<span className="v" id="v35" data-v="35" data-xref="箴言 24:16; 詩篇 8:4; ペテロの手紙第一 4:7"> 彼女たちはその夜も父にぶどう酒を飲ませた。妹が起きて父と一緒に寝た。父は娘が横になったのも、起き上がったのも知らなかった。</span>
<span className="v" id="v36" data-v="36" data-xref="ハバクク書 2:15; 士師記 1:7; マタイ 7:2"> こうしてロトの二人の娘は、父によって身ごもった。</span>
<span className="v" id="v37" data-v="37" data-xref="申命記 2:9; 列王記第二 3:1–27; 民数記 21:29"> 姉は男の子を産み、その名をモアブと名付けた。彼は今日のモアブ人の父である。</span>
<span className="v" id="v38" data-v="38" data-xref="申命記 2:19; 士師記 10:6–40; 詩篇 83:4–8"> 妹も男の子を産み、その名をベン・アミと呼んだ。彼は今日のアンモン人の父である。</span>
</div>
</div>

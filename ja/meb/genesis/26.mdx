<div className="bible-chapter" lang="ja" dir="ltr" data-lang="ja" data-translation="meb" data-translation-id="jpn_meb" data-translation-label="MEB" data-book="GEN" data-book-slug="genesis" data-book-name="創世記" data-chapter="26" data-verses="35">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 12:10; 創世記 25:11; 創世記 21:22–32"> アブラハムの時代にあった最初の飢饉とは別に、その地に再び飢饉があった。イサクはゲラルにいるペリシテ人の王アビメレクのもとへ行った。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 12:7; 詩篇 37:3; 創世記 17:1"> 主は彼に現れて言われた。「エジプトへ下って行ってはならない。わたしがあなたに告げる地に住みなさい。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 28:15; 詩篇 105:9; 創世記 17:8"> この地に寄留しなさい。そうすれば、わたしはあなたと共にいて、あなたを祝福する。わたしはあなたとあなたの子孫に、これらのすべての地を与え、あなたの父アブラハムに誓った誓いを果たすからである。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒の働き 3:25; 創世記 15:5; 創世記 22:17–18"> わたしはあなたの子孫を空の星のように増やし、これらすべての地をあなたの子孫に与える。地上のすべての国々は、あなたの子孫によって祝福される。</span>
<span className="v" id="v5" data-v="5" data-xref="マタイ 7:24; 創世記 22:18; 創世記 22:16"> それは、アブラハムがわたしの声に聞き従い、わたしの言いつけ、命令、掟、教えを守ったからである。」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="創世記 20:1"> イサクはゲラルに住んだ。</span>
<span className="v" id="v7" data-v="7" data-xref="箴言 29:25; 創世記 12:13; 創世記 20:2"> その場所の人々が彼の妻について尋ねると、彼は「彼女は私の妹です」と言った。彼は「私の妻です」と言うのを恐れたのである。リベカは美しかったので、「この場所の人々がリベカのゆえに私を殺すかもしれない」と考えたからである。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="イザヤ書 62:5; 箴言 5:18–19; 箴言 7:6"> 彼がそこに長く滞在していたころ、ペリシテ人の王アビメレクが窓から外を見ると、見よ、イサクが妻リベカと戯れていた。</span>
<span className="v" id="v9" data-v="9"> アビメレクはイサクを呼んで言った。「見よ、彼女は確かにあなたの妻ではないか。なぜあなたは『彼女は私の妹です』と言ったのか。」<br />イサクは答えた。「彼女のゆえに殺されるかもしれないと思ったのです。」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="創世記 20:9–10; 創世記 12:18–19"> アビメレクは言った。「あなたは何ということをしてくれたのか。民の一人があなたの妻と寝ていたら、あなたは私たちに罪をもたらすところだったではないか。」</span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 105:15; 創世記 20:6; 箴言 6:29"> アビメレクはすべての民に命じた。「この男、またはその妻に触れる者は、必ず殺される。」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="マルコ 4:8; 創世記 24:1; 創世記 26:3"> イサクはその地に種を蒔き、その年に百倍の収穫を得た。主が彼を祝福されたのである。</span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 112:3; 箴言 10:22; 創世記 24:35"> 彼は豊かになり、ますます栄え、ついに非常に豊かな者となった。</span>
<span className="v" id="v14" data-v="14" data-xref="創世記 37:11; 創世記 13:2; 箴言 27:4"> 彼は羊の群れ、牛の群れ、そして多くのしもべを持つようになった。ペリシテ人は彼をねたんだ。</span>
<span className="v" id="v15" data-v="15" data-xref="創世記 21:30; 創世記 21:25"> 彼の父アブラハムの時代に、父のしもべたちが掘ったすべての井戸を、ペリシテ人は土で埋めて塞いでしまっていた。</span>
<span className="v" id="v16" data-v="16" data-xref="出エジプト記 1:9"> アビメレクはイサクに言った。「私たちのところから去ってくれ。あなたは私たちよりもはるかに強くなったからだ。」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17"> イサクはそこを去り、ゲラルの谷に天幕を張って、そこに住んだ。</span>
<span className="v" id="v18" data-v="18" data-xref="ゼカリヤ書 13:2; ホセア書 2:17; 民数記 32:38"> イサクは、父アブラハムの時代に掘られた水の井戸を再び掘った。アブラハムの死後、ペリシテ人がそれらを塞いでいたからである。彼は、父がつけた名前のとおりに、それらの井戸に名前をつけた。</span>
<span className="v" id="v19" data-v="19" data-xref="ヨハネ 4:10–11; ヨハネ 7:38; 雅歌 4:15"> イサクのしもべたちが谷を掘ると、そこに湧き出る水の井戸を見つけた。</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 21:25"> ゲラルの牧者たちはイサクの牧者たちと争い、「その水は私たちのものだ」と言った。彼らがイサクと争ったので、イサクはその井戸の名をエセク<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="エセクは「争い」を意味する。">a</a></sup>と呼んだ。</span>
<span className="v" id="v21" data-v="21" data-xref="エズラ記 4:6"> 彼らは別の井戸を掘ったが、それについても彼らは争った。それで彼はその名をシテナ<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="シテナは「敵意」または「対立」を意味する。">b</a></sup>と呼んだ。</span>
<span className="v" id="v22" data-v="22" data-xref="創世記 17:6; 出エジプト記 1:7; 詩篇 118:5"> 彼はそこから移り、さらに別の井戸を掘った。それについては彼らは争わなかった。それで彼はその名をレホボト<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="レホボトは「広い場所」を意味する。">c</a></sup>と呼んで言った。「今や主が私たちのために場所を広げてくださった。私たちはこの地で増えるだろう。」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="士師記 20:1; 創世記 21:31; 創世記 46:1"> 彼はそこからベエル・シェバへ上って行った。</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 15:1; 出エジプト記 3:6; イザヤ書 43:1–2"> その夜、主は彼に現れて言われた。「わたしはあなたの父アブラハムの神である。恐れてはならない。わたしはあなたと共にいる。わたしのしもべアブラハムのゆえに、わたしはあなたを祝福し、あなたの子孫を増やす。」</span>
<span className="v" id="v25" data-v="25" data-xref="創世記 13:18; 詩篇 116:17; 創世記 12:7–8"> 彼はそこに祭壇を築き、主の御名を呼び求め、そこに天幕を張った。そこでイサクのしもべたちは井戸を掘った。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="創世記 21:22–32; 創世記 20:3"> その時、アビメレクがゲラルから、彼の友人アフザテと軍の長フィコルと共に、イサクのところへやって来た。</span>
<span className="v" id="v27" data-v="27" data-xref="創世記 26:16; 士師記 11:7; 使徒の働き 7:14"> イサクは彼らに言った。「あなたがたは私を憎み、あなたがたのところから私を追い出したのに、なぜ私のところへ来たのですか。」</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="創世記 21:22–23; イザヤ書 45:14; イザヤ書 61:9"> 彼らは言った。「私たちは、主があなたと共におられるのをはっきりと見ました。それで私たちは言いました。『どうか、私たちの間、すなわち私たちとあなたの間に誓いを立てさせてほしい。私たちと契約を結んでほしい。</span>
<span className="v" id="v29" data-v="29" data-xref="創世記 24:31; 創世記 21:22; 創世記 22:17"> 私たちがあなたに触れず、あなたに良いことだけを行い、あなたを安らかに送り出したように、あなたも私たちに害を加えないでほしい』と。あなたは今、主に祝福された人です。」</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="創世記 19:3; ローマ人への手紙 12:18; ヘブル人への手紙 12:14"> イサクは彼らのために宴会を催し、彼らは飲み食いした。</span>
<span className="v" id="v31" data-v="31" data-xref="サムエル記第一 20:16–17; ヘブル人への手紙 6:16; 創世記 25:33"> 彼らは朝早く起き、互いに誓いを立てた。イサクが彼らを送り出すと、彼らは安らかに去って行った。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="箴言 10:4; 箴言 13:4; 箴言 2:4–5"> その日、イサクのしもべたちが来て、自分たちが掘った井戸について、「水が出ました」と告げた。</span>
<span className="v" id="v33" data-v="33" data-xref="創世記 21:31; 創世記 26:28"> 彼はそれをシバ<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="シバは「誓い」または「七」を意味する。">d</a></sup>と呼んだ。それゆえ、その町の名は今日に至るまでベエル・シェバである。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="創世記 36:2; 創世記 36:13; 出エジプト記 34:16"> エサウは四十歳のとき、ヘト人ベエリの娘ユディテと、ヘト人エロンの娘バセマテを妻にめとった。</span>
<span className="v" id="v35" data-v="35" data-xref="創世記 27:46–2; 創世記 28:8; 創世記 6:2"> 彼女たちはイサクとリベカにとって、心の痛みとなった。</span>
</div>
</div>

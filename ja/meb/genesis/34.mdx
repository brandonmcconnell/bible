<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 30:21; エレミヤ書 2:36; 創世記 30:13"> レアがヤコブに産んだ娘ディナは、その地の娘たちを見るために出かけて行った。</span>
<span className="v" id="v2" data-v="2" data-xref="マタイ 5:28; ヨブ記 31:1; ヨブ記 31:9"> その地の君主であるヒビ人ハモルの子シェケムが彼女を見た。彼は彼女を連れて行き、彼女と寝て、彼女を辱めた。</span>
<span className="v" id="v3" data-v="3" data-xref="ホセア書 2:14; イザヤ書 40:2; 歴代誌 第二 30:22"> 彼の心はヤコブの娘ディナに強く結びつき、彼はその若い女を愛し、彼女に優しく語りかけた。</span>
<span className="v" id="v4" data-v="4" data-xref="士師記 14:2; サムエル記第二 13:13; 創世記 21:21"> シェケムは父ハモルに言った。「この若い女を、私の妻としてもらってください。」</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="サムエル記第二 13:22; レビ記 10:3; サムエル記第一 10:27"> ヤコブは、シェケムが娘ディナを汚したことを聞いた。彼の息子たちは野で家畜と一緒にいたので、ヤコブは彼らが帰って来るまで黙っていた。</span>
<span className="v" id="v6" data-v="6"> シェケムの父ハモルは、ヤコブと話し合うために彼のところへ出て行った。</span>
<span className="v" id="v7" data-v="7" data-xref="ヨシュア記 7:15; 士師記 20:6; 申命記 22:21"> ヤコブの息子たちはそれを聞くと、野から帰って来た。その男たちは心を痛め、非常に怒った。シェケムがヤコブの娘と寝て、イスラエルの中で愚かなこと、してはならないことをしたからである。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="列王記第一 11:2; 詩篇 119:20; 詩篇 84:2"> ハモルは彼らと話し合って言った。「私の息子シェケムの心は、あなたがたの娘を慕い求めています。どうか彼女を彼の妻として与えてください。</span>
<span className="v" id="v9" data-v="9" data-xref="申命記 7:3; 創世記 26:34–35; 創世記 19:14"> 私たちと縁組みをしてください。あなたがたの娘たちを私たちに与え、私たちの娘たちをあなたがたのためにめとってください。</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 20:15; 創世記 47:27; 創世記 42:34"> あなたがたは私たちと一緒に住んでください。この地はあなたがたの前にあります。ここに住み、ここで商いをし、ここに所有地を得てください。」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="創世記 33:15; 創世記 18:3"> シェケムは彼女の父と兄弟たちに言った。「どうか、私を受け入れてください。あなたがたの求めるものは何でも与えます。</span>
<span className="v" id="v12" data-v="12" data-xref="出エジプト記 22:16–17; 申命記 22:28–29; サムエル記第一 18:25–27"> 花嫁の代価と贈り物を、いくらでも私に求めてください。あなたがたが私に求めるものは何でも与えましょう。ただ、その若い女を妻として私に与えてください。」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="創世記 25:27–34; イザヤ書 59:13; ヨブ記 13:4"> ヤコブの息子たちは、シェケムとその父ハモルに欺きをもって答えた。彼が妹ディナを汚したからである。</span>
<span className="v" id="v14" data-v="14" data-xref="マタイ 23:1–39; サムエル記第二 15:7; 創世記 17:11"> 彼らは言った。「私たちはこのことを行うことはできない。無割礼の者に私たちの妹を与えることは、私たちにとって恥となるからだ。</span>
<span className="v" id="v15" data-v="15" data-xref="ガラテヤ人への手紙 4:12"> ただこの条件でのみ、私たちはあなたがたに同意する。もしあなたがたのすべての男子が割礼を受け、あなたがたが私たちのようになるなら、</span>
<span className="v" id="v16" data-v="16"> 私たちは私たちの娘たちをあなたがたに与え、あなたがたの娘たちを私たちのためにめとる。そして私たちはあなたがたと一緒に住み、一つの民となる。</span>
<span className="v" id="v17" data-v="17"> しかし、もしあなたがたが私たちの言うことを聞かず、割礼を受けないなら、私たちは娘を連れて去って行く。」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18"> 彼らの言葉は、ハモルとその子シェケムの気に入った。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒の働き 17:12; 使徒の働き 13:50; サムエル記第一 22:14"> その若者はこのことを行うのをためらわなかった。彼がヤコブの娘を喜んでいたからである。彼は父の家の誰よりも尊ばれていた。</span>
<span className="v" id="v20" data-v="20" data-xref="ルツ記 4:1; 箴言 31:23; アモス書 5:12"> ハモルとその息子シェケムは自分たちの町の門に行き、その町の人々と話し合って言った。</span>
<span className="v" id="v21" data-v="21"> 「この人たちは私たちと平和に過ごしている。それゆえ、彼らにこの地に住ませ、ここで商いをさせよう。見よ、この地は彼らにとって十分に広い。彼らの娘たちを私たちの妻としてめとり、私たちの娘たちを彼らに与えよう。</span>
<span className="v" id="v22" data-v="22"> ただこの条件でのみ、この人たちは私たちと一緒に住み、一つの民となることに同意してくれる。それは、彼らが割礼を受けているように、私たちの中のすべての男子が割礼を受けることである。</span>
<span className="v" id="v23" data-v="23" data-xref="箴言 1:12–13; ヨハネ 6:26–27; ヨハネ 2:16"> 彼らの家畜も、彼らの持ち物も、彼らのすべての獣も、私たちのものになるではないか。ただ私たちが彼らに同意しさえすれば、彼らは私たちと一緒に住むのだ。」</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="創世記 23:10; コリント人への第一の手紙 7:19; イザヤ書 1:10–16"> 彼の町の門を出入りするすべての者は、ハモルとその息子シェケムの言うことを聞いた。そしてすべての男子、すなわち彼の町の門を出入りするすべての者は割礼を受けた。</span>
<span className="v" id="v25" data-v="25" data-xref="創世記 49:5–7; 創世記 29:33–34; 民数記 31:7"> 三日目になり、彼らがまだ痛みを感じていたとき、ヤコブの二人の息子、ディナの兄弟であるシメオンとレビは、それぞれ自分の剣を取り、無防備な町を襲い、すべての男子を殺した。</span>
<span className="v" id="v26" data-v="26" data-xref="サムエル記第二 2:26; 申命記 32:42; イザヤ書 31:8"> 彼らはハモルとその息子シェケムを剣の刃で殺し、シェケムの家からディナを連れ出し、去って行った。</span>
<span className="v" id="v27" data-v="27" data-xref="ヨシュア記 7:13; ヨシュア記 7:21; 出エジプト記 2:14"> ヤコブの息子たちは殺された者たちのところへ来て、町を略奪した。彼らが彼らの妹を汚したからである。</span>
<span className="v" id="v28" data-v="28" data-xref="ヨブ記 1:15–16; 申命記 8:17–18; ヨブ記 20:5"> 彼らは羊の群れ、牛の群れ、ろば、町にあるもの、野にあるものを取り、</span>
<span className="v" id="v29" data-v="29"> さらに彼らのすべての富を奪った。彼らはすべての小さな子どもたちと妻たちを捕虜にし、家の中にあるすべてのものを略奪した。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="詩篇 105:12; ヨシュア記 7:25; 出エジプト記 5:21"> ヤコブはシメオンとレビに言った。「あなたがたは私を悩ませ、この地に住むカナン人やペリジ人の間で私を忌み嫌われる者にした。私は数が少ない。彼らが私に立ち向かって集まり、私を打てば、私も私の家も滅ぼされてしまうだろう。」</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="箴言 6:34; 創世記 34:13; 創世記 49:7"> 彼らは言った。「私たちの妹を遊女のように扱わせてよいのですか。」</span>
</div>
</div>

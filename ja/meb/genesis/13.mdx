<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 12:9–20; ヨシュア記 10:40; サムエル記第二 24:7"> アブラムは、妻と、すべての持ち物、そしてロトと一緒に、エジプトを出てネゲブ地方へ上って行った。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 24:35; 詩篇 112:1–3; 創世記 26:12–13"> アブラムは家畜、銀、金を非常に多く持ち、たいへん豊かであった。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 12:8–9; 創世記 12:6"> 彼は旅を続けて、ネゲブからベテルへ向かい、初めに天幕を張っていたベテルとアイの間の場所へ行った。</span>
<span className="v" id="v4" data-v="4" data-xref="エレミヤ書 29:12; 創世記 12:7–8; イザヤ書 58:9"> そこは、彼が以前に築いた祭壇の場所であった。そこでアブラムは主の御名を呼び求めた。</span>
<span className="v" id="v5" data-v="5" data-xref="エレミヤ書 49:29; 創世記 25:27; 創世記 4:20"> アブラムと一緒に行ったロトもまた、羊の群れ、牛の群れ、天幕を持っていた。</span>
<span className="v" id="v6" data-v="6" data-xref="創世記 36:6–7; 伝道者の書 5:10–11; テモテへの手紙第一 6:9"> その地は、彼らが一緒に住むには十分ではなかった。彼らの持ち物が多すぎて、一緒に住むことができなかったからである。</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 26:20; 創世記 12:6; ヤコブの手紙 3:16"> アブラムの家畜の牧者たちと、ロトの家畜の牧者たちの間に争いが起こった。その当時、カナン人とペリジ人がその地に住んでいた。</span>
<span className="v" id="v8" data-v="8" data-xref="コリント人への第一の手紙 6:6–7; 使徒の働き 7:26; 詩篇 133:1"> アブラムはロトに言った。「どうか、私とあなたの間、また私の牧者たちとあなたの牧者たちの間に、争いがないようにしよう。私たちは親族なのだから。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 20:15; 創世記 34:10; ペテロの手紙第一 3:8–12"> 全地があなたの前にあるではないか。どうか、私から別れてほしい。あなたが左へ行くなら、私は右へ行こう。あなたが右へ行くなら、私は左へ行こう。」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="申命記 34:3; イザヤ書 51:3; 創世記 14:8"> ロトが目を上げてヨルダンの低地一帯を見渡すと、ツォアルに至るまで、どこもよく潤っていた。それは主がソドムとゴモラを滅ぼされる前のことで、主の園のように、またエジプトの地のようであった。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 13:9; ペテロの手紙第一 2:17; ヘブル人への手紙 10:25"> そこでロトは、ヨルダンの低地一帯を自分のために選び取った。ロトは東へ旅立ち、彼らは互いに別れた。</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 19:29; 創世記 14:12; 創世記 19:1"> アブラムはカナンの地に住み、ロトは低地の町々に住んで、ソドムの近くまで天幕を張った。</span>
<span className="v" id="v13" data-v="13" data-xref="ペテロの第二の手紙 2:10; ペテロの第二の手紙 2:6–8; ユダ 1:7"> さて、ソドムの人々は主に対して極めて邪悪な罪人であった。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="イザヤ書 49:18; 申命記 3:27; 創世記 28:14"> ロトが別れて行った後、主はアブラムに言われた。「さあ、目を上げて、あなたのいる場所から北、南、東、西を見渡しなさい。</span>
<span className="v" id="v15" data-v="15" data-xref="歴代誌 第二 20:7; 創世記 35:12; 創世記 15:18"> あなたが見渡しているこのすべての地を、わたしはあなたとあなたの子孫に永遠に与える。</span>
<span className="v" id="v16" data-v="16" data-xref="創世記 28:14; 民数記 23:10; 創世記 32:12"> わたしはあなたの子孫を地のちりのようにする。もし人が地のちりを数えることができるなら、あなたの子孫も数えることができるだろう。</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 13:15; 民数記 13:17–24"> さあ、立って、その地を縦と横に歩き回りなさい。わたしはそれをあなたに与えるからだ。」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="創世記 18:1; 創世記 8:20; 創世記 35:27"> アブラムは天幕を移し、ヘブロンにあるマムレの樫の木々のところに来て住んだ。そしてそこに、主のための祭壇を築いた。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 31:13; ホセア書 12:4; 詩篇 91:15"> 神はヤコブに言われた。「立ち上がってベテルへ上り、そこに住め。兄エサウから逃げたとき、あなたに現れた神のために、そこで祭壇を造れ。」</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="出エジプト記 19:14; 出エジプト記 19:10; エゼキエル書 18:31"> そこでヤコブは自分の家族と、彼と一緒にいるすべての者に言った。「あなたがたの中にある外国の神々を捨て去り、身をきよめ、衣を着替えなさい。</span>
<span className="v" id="v3" data-v="3" data-xref="イザヤ書 43:2; 創世記 32:7; 創世記 31:3"> さあ立ち上がり、ベテルへ上って行こう。私の苦難の日に私に答え、私の行く道で私と共におられた神に、私はそこで祭壇を造る。」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="士師記 9:6; 申命記 7:25; 出エジプト記 32:20"> 彼らは、自分たちの手にあるすべての外国の神々と、耳にある輪をヤコブに渡した。ヤコブはそれらを、シェケムのそばにある樫の木の下に隠した。</span>
<span className="v" id="v5" data-v="5" data-xref="出エジプト記 23:27; 歴代誌 第二 17:10; ヨシュア記 5:1"> 彼らが旅立つと、神への恐怖が周囲の町々を襲い、人々はヤコブの息子たちを追わなかった。</span>
<span className="v" id="v6" data-v="6" data-xref="創世記 28:19; 創世記 28:22; 創世記 12:8"> こうして、ヤコブと彼と一緒にいたすべての民は、カナンの地にあるルズ、すなわちベテルに着いた。</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 35:3; 創世記 35:1; 創世記 28:13"> 彼はそこに祭壇を築き、その場所をエル・ベテル<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="エル・ベテルは「ベテルの神」を意味する。">a</a></sup>と呼んだ。兄から逃げたとき、そこで神が彼に現れたからである。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="創世記 24:59; サムエル記第一 31:13; 士師記 2:5"> リベカの乳母デボラが死に、ベテルの下の方にある樫の木の下に葬られた。その名はアロン・バクテ<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="アロン・バクテは「泣きの樫の木」を意味する。">b</a></sup>と呼ばれた。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="創世記 35:1; 創世記 18:1; 創世記 26:2"> ヤコブがパダン・アラムから来たとき、神は再び彼に現れ、彼を祝福された。</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 17:5; 創世記 32:27–28; 創世記 17:15"> 神は彼に言われた。「あなたの名はヤコブである。あなたの名はもはやヤコブとは呼ばれず、あなたの名はイスラエルとなる。」神は彼をイスラエルと名付けられた。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 17:1; 創世記 9:1; 創世記 22:17"> 神は彼に言われた。「わたしは全能の神である。生めよ、増えよ。一つの民族と、多くの民族の集まりがあなたから出て、王たちがあなたの体から出る。</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 12:7; 創世記 28:13; 創世記 26:3–4"> わたしがアブラハムとイサクに与えた地を、わたしはあなたに与え、あなたの後に続くあなたの子孫にその地を与える。」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="創世記 17:22; 創世記 18:33; 士師記 6:21"> 神は、彼と語られた場所から、彼を離れて上って行かれた。</span>
<span className="v" id="v14" data-v="14" data-xref="創世記 28:18–19; サムエル記第一 7:12; 出エジプト記 17:15"> ヤコブは、神が彼と語られた場所に一本の柱、石の柱を立てた。彼はその上に飲み物のささげ物を注ぎ、その上に油を注いだ。</span>
<span className="v" id="v15" data-v="15" data-xref="創世記 28:19"> ヤコブは、神が彼と語られた場所の名をベテルと呼んだ。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="ミカ書 5:2; 創世記 48:7; 列王記第二 5:19"> 彼らはベテルから旅立った。エフラテに着くまでにはまだ少し距離があったが、ラケルは産気づいた。彼女は難産であった。</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 30:24; サムエル記第一 4:19–21"> 難産で苦しんでいる彼女に、助産婦は言った。「恐れないでください。この子も男の子です。」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="ルカ 12:20; 使徒の働き 7:59; ルカ 23:46"> 彼女は息を引き取ろうとする中で、その子をベン・オニ<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="ベン・オニは「私の悲しみの息子」を意味する。">c</a></sup>と名付けた。しかし父は、ベニヤミン<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="ベニヤミンは「右手の息子」を意味する。">d</a></sup>と名付けた。</span>
<span className="v" id="v19" data-v="19" data-xref="ミカ書 5:2; 創世記 48:7; ルツ記 4:11"> ラケルは死に、エフラテ、すなわちベツレヘムへの道に葬られた。</span>
<span className="v" id="v20" data-v="20" data-xref="サムエル記第一 10:2; 創世記 35:14; サムエル記第二 18:17–18"> ヤコブは彼女の墓の上に柱を立てた。これは今日に至るまで、ラケルの墓の柱である。</span>
<span className="v" id="v21" data-v="21" data-xref="ミカ書 4:8; ルカ 2:8"> イスラエルは旅立ち、エデルの塔の向こうに天幕を張った。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="歴代誌上 5:1; レビ記 18:8; サムエル記第二 20:3"> イスラエルがその地に住んでいたとき、ルベンは行って、父のそばめであるビルハと寝た。イスラエルはそれを聞いた。<br />さて、ヤコブの息子は十二人であった。</span>
<span className="v" id="v23" data-v="23" data-xref="創世記 30:18–20; 創世記 46:8–15; 創世記 29:32–35"> レアの息子たちは、ヤコブの長男ルベン、シメオン、レビ、ユダ、イッサカル、ゼブルン。</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 30:22–24; 創世記 46:19–22; 創世記 35:16–18"> ラケルの息子たちは、ヨセフ、ベニヤミン。</span>
<span className="v" id="v25" data-v="25" data-xref="創世記 46:23–25; 創世記 37:2; 創世記 30:4–8"> ラケルの女のしもべビルハの息子たちは、ダン、ナフタリ。</span>
<span className="v" id="v26" data-v="26" data-xref="創世記 30:9–13; 創世記 46:16–18; 創世記 25:20"> レアの女のしもべジルパの息子たちは、ガド、アシェル。これらは、パダン・アラムでヤコブに生まれた息子たちである。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="創世記 13:18; 創世記 23:19; 創世記 18:1"> ヤコブは、アブラハムとイサクが寄留していたマムレ、キルヤト・アルバ、すなわちヘブロンにいる父イサクのところへ行った。</span>
<span className="v" id="v28" data-v="28" data-xref="創世記 25:7; 創世記 50:26; 創世記 47:28"> イサクの生涯は百八十年であった。</span>
<span className="v" id="v29" data-v="29" data-xref="創世記 15:15; 創世記 49:33; 創世記 49:31"> イサクは息を引き取って死に、老いて長寿を全うし、自分の民に加えられた。息子のエサウとヤコブが彼を葬った。</span>
</div>
</div>

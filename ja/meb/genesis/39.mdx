<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 37:28; 詩篇 105:17; 創世記 37:36"> ヨセフはエジプトへ連れて下られた。ファラオの役人で護衛の長であるエジプト人ポティファルが、彼を連れて来たイシュマエル人から買い取った。</span>
<span className="v" id="v2" data-v="2" data-xref="サムエル記第一 18:14; 詩篇 91:15; エレミヤ書 15:20"> 主はヨセフと共におられ、彼は何をしても栄えた。彼はエジプト人の主人の家にいた。</span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 1:3; 創世記 30:27; マタイ 5:16"> 主が彼と共におられ、彼の手がすることすべてを主が成功させてくださるのを、彼の主人は見た。</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 39:21–22; 箴言 27:18; 創世記 19:19"> ヨセフは主人の信頼を得て、彼に仕えた。主人は彼を家の管理人にし、すべての持ち物をその手に委ねた。</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 30:27; サムエル記第二 6:11–12; 使徒の働き 27:24"> 彼がヨセフを家の管理人とし、またそのすべての持ち物を任せた時から、主はヨセフのゆえに、このエジプト人の家を祝福された。主の祝福は、家にあるものにも、野にあるものにも、彼のすべての持ち物の上にあった。</span>
<span className="v" id="v6" data-v="6" data-xref="サムエル記第一 16:12; ルカ 19:17; 箴言 31:11"> 彼は自分のすべての持ち物をヨセフの手に任せ、自分が食べる食物のほかは、何一つ自分では気にしなかった。ヨセフは体つきも良く、顔立ちも美しかった。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="サムエル記第二 13:11; エゼキエル書 16:34; ペテロの第二の手紙 2:14"> これらのことの後、主人の妻がヨセフに目を向け、「私と寝なさい」と言った。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="箴言 23:26–28; 箴言 22:14; 箴言 9:13–18"> しかし彼は拒み、主人の妻に言った。「ご覧ください。主人は家のことを何も気にかけず、すべての持ち物を私の手に委ねています。</span>
<span className="v" id="v9" data-v="9" data-xref="サムエル記第二 12:13; 創世記 20:6; 創世記 42:18"> この家で私より大きな者はいません。主人は、妻であるあなたのほか、何一つ私に禁じていません。どうして私は、このような大きな悪を行い、神に対して罪を犯せるでしょうか。」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="ペテロの手紙第一 2:11; 創世記 39:8; テサロニケ人への手紙第一 5:22"> 彼女は毎日ヨセフに言い寄ったが、彼は彼女と寝ることにも、そばにいることにも応じなかった。</span>
<span className="v" id="v11" data-v="11" data-xref="エペソ人への手紙 5:12; エペソ人への手紙 5:3; マラキ書 3:5"> ある日のこと、彼が仕事をするために家に入ると、家の中には家の者が一人もいなかった。</span>
<span className="v" id="v12" data-v="12" data-xref="テモテへの第二の手紙 2:22; 箴言 7:13–27; 伝道者の書 7:26"> 彼女は彼の服をつかんで、「私と寝なさい」と言った。<br />しかし、彼は自分の服を彼女の手に残したまま、逃げて外へ出た。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13"> 彼が自分の服を彼女の手に残して外へ逃げたのを見ると、</span>
<span className="v" id="v14" data-v="14" data-xref="創世記 10:21; ペテロの手紙第一 2:20; 詩篇 35:11"> 彼女は家の者たちを呼んで言った。「見なさい。主人は、私たちを辱めるためにヘブライ人を連れて来たのです。彼が私と寝ようとして入って来たので、私は大声で叫びました。</span>
<span className="v" id="v15" data-v="15"> 私が声を上げて叫ぶのを聞くと、彼は服を私のそばに残し、逃げて外へ出たのです。」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="詩篇 37:32; エレミヤ書 4:22; エレミヤ書 9:3–5"> 彼女は主人が家に帰って来るまで、その服を自分のそばに置いておいた。</span>
<span className="v" id="v17" data-v="17" data-xref="出エジプト記 23:1; 列王記第一 18:17; 詩篇 37:14"> 彼女は主人に同じ言葉で言った。「あなたが私たちのところに連れて来たあのヘブライ人のしもべが、私を侮辱しようとして入って来ました。</span>
<span className="v" id="v18" data-v="18"> 私が声を上げて叫んだので、彼は服を私のそばに残し、外へ逃げました。」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="創世記 4:5–6; 箴言 18:17; 箴言 6:34–35"> 主人は、「あなたのしもべは私にこのようなことをしました」と彼女が語った妻の言葉を聞くと、激しく怒った。</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 40:15; テモテへの第二の手紙 2:9; 詩篇 105:18–19"> ヨセフの主人は彼を捕らえ、王の囚人たちがつながれている場所である監獄に入れた。こうして彼はその監獄にいた。</span>
<span className="v" id="v21" data-v="21" data-xref="出エジプト記 3:21; イザヤ書 41:10; ペテロの手紙第一 3:17"> しかし主はヨセフと共におられ、彼に慈しみを示し、監獄の長の信頼を得させられた。</span>
<span className="v" id="v22" data-v="22" data-xref="創世記 40:3–4; 創世記 39:4; サムエル記第一 2:30"> 監獄の長は、監獄にいるすべての囚人をヨセフの手に委ねた。彼らがそこで行うすべてのことは、ヨセフが取り仕切った。</span>
<span className="v" id="v23" data-v="23" data-xref="イザヤ書 43:2; 創世記 39:2–3; 詩篇 1:3"> 監獄の長は、ヨセフの手に任せたことについては何一つ気にかけなかった。主が彼と共におられ、彼が行うことを主が成功させてくださったからである。</span>
</div>

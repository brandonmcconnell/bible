<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨブ記 5:2; 創世記 29:31; 創世記 37:11"> ラケルは自分がヤコブに子どもを産まないのを見ると、姉をねたんだ。彼女はヤコブに言った。「私に子どもをください。そうでなければ、私は死んでしまいます。」</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 16:2; 詩篇 127:3; 列王記第二 5:7"> ヤコブはラケルに向かって怒りを燃やして言った。「私が神に代わることなどできるだろうか。あなたの胎の実を拒んでおられるのは神なのだ。」</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="創世記 50:23; ヨブ記 3:12; ルツ記 4:11"> 彼女は言った。「見よ、私の女のしもべビルハがいます。彼女のところに入ってください。彼女が私の膝の上に子を産むことで、私も彼女によって子を得ることができるでしょう。」</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 35:22; 創世記 21:10; サムエル記第二 12:11"> 彼女は自分の女のしもべビルハを妻としてヤコブに与えたので、ヤコブは彼女のところに入った。</span>
<span className="v" id="v5" data-v="5"> ビルハは身ごもり、ヤコブに男の子を産んだ。</span>
<span className="v" id="v6" data-v="6" data-xref="哀歌 3:59; 詩篇 35:24; 詩篇 43:1"> ラケルは言った。「神は私の訴えを聞き、私の声に耳を傾け、男の子をくださった。」それゆえ、その名をダン<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="ダンは「裁く」を意味する。">a</a></sup>と呼んだ。</span>
<span className="v" id="v7" data-v="7"> ラケルの女のしもべビルハは再び身ごもり、ヤコブに二番目の男の子を産んだ。</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 32:24–25; 創世記 23:6; 創世記 49:21"> ラケルは言った。「私は姉と激しい格闘をして、ついに勝ちました。」彼女はその名をナフタリ<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="ナフタリは「私の格闘」を意味する。">b</a></sup>と名付けた。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="創世記 30:4; 創世記 30:17; 創世記 29:35"> レアは自分が出産をやめたのを見ると、女のしもべジルパを取り、彼女を妻としてヤコブに与えた。</span>
<span className="v" id="v10" data-v="10"> レアの女のしもべジルパはヤコブに男の子を産んだ。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 49:19; イザヤ書 65:11; 創世記 35:26"> レアは「幸運が来た」と言い、その名をガド<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="ガドは「幸運」を意味する。">c</a></sup>と名付けた。</span>
<span className="v" id="v12" data-v="12"> レアの女のしもべジルパはヤコブに二番目の男の子を産んだ。</span>
<span className="v" id="v13" data-v="13" data-xref="ルカ 1:48; 箴言 31:28; 雅歌 6:9"> レアは言った。「私は幸いだ。女たちは私を幸いな者と呼ぶだろう。」彼女はその名をアシェル<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="アシェルは「幸せ」を意味する。">d</a></sup>と名付けた。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="雅歌 7:13; 創世記 25:30"> 麦刈りの季節にルベンが野へ行き、恋なすび<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="恋なすびはマンドラゴラのこと。古代では妊娠を助けるものと考えられていた。">e</a></sup>を見つけて、母レアのところに持って来た。するとラケルがレアに言った。「どうか、あなたの息子の恋なすびを私に分けてください。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="民数記 16:13; コリント人への第一の手紙 4:3; 民数記 16:9–10"> レアは彼女に言った。「あなたが私の夫を奪ったのは小さなことですか。そのうえ、私の息子の恋なすびまでも奪おうとするのですか。」<br />ラケルは言った。「それなら、あなたの息子の恋なすびと引き換えに、今夜は彼があなたと寝るようにしましょう。」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16"> 夕方、ヤコブが野から帰って来ると、レアは彼を迎えに出て言った。「今夜は私のところに来てください。息子の恋なすびで、あなたを雇ったのです。」その夜、彼は彼女と寝た。</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 30:6; 創世記 30:22; 出エジプト記 3:7"> 神はレアの願いを聞き入れられた。彼女は身ごもり、ヤコブに五番目の男の子を産んだ。</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 49:14–15; 申命記 33:18; 創世記 46:13"> レアは言った。「私が女のしもべを夫に与えたので、神は私に報酬をくださった。」彼女はその名をイッサカル<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="イッサカルは「報酬」を意味する。">f</a></sup>と名付けた。</span>
<span className="v" id="v19" data-v="19"> レアは再び身ごもり、ヤコブに六番目の男の子を産んだ。</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 35:23; マタイ 4:13; 創世記 49:13"> レアは言った。「神は私に良い贈り物を与えてくださいました。私が夫に六人の男の子を産んだので、今度こそ夫は私と共に住んでくれるでしょう。」彼女はその名をゼブルン<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="ゼブルンは「住む」または「住まい」と関連する。">g</a></sup>と名付けた。</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 34:1–3; 創世記 34:26; 創世記 46:15"> その後、彼女は女の子を産み、その名をディナと名付けた。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="創世記 29:31; 詩篇 113:9; 詩篇 127:3"> 神はラケルを心に留められた。神は彼女の願いを聞き入れ、彼女の胎を開かれた。</span>
<span className="v" id="v23" data-v="23" data-xref="ルカ 1:25; 創世記 29:31; ルカ 1:27"> 彼女は身ごもって男の子を産み、言った。「神が私の恥を取り除いてくださいました。」</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 49:22–26; 創世記 35:24; 創世記 37:2"> 彼女はその子をヨセフ<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="ヨセフは「加える」と関連する。">h</a></sup>と名付けて、「主が私にもう一人の息子を加えてくださいますように」と言った。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="創世記 24:54; 創世記 24:56; 創世記 28:15"> ラケルがヨセフを産んだ時、ヤコブはラバンに言った。「私を送り出してください。自分の場所、自分の国へ帰りたいのです。</span>
<span className="v" id="v26" data-v="26" data-xref="創世記 29:30; ホセア書 12:12; 創世記 31:26"> 私があなたに仕えて得た妻たちと子どもたちを私に与え、行かせてください。私があなたに仕えた働きは、あなたが知っているはずです。」</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="ルツ記 2:13; 使徒の働き 7:10; イザヤ書 61:9"> ラバンは彼に言った。「私があなたのお目にかなっているなら、どうか留まってください。主があなたのゆえに私を祝福されたことを、占いによって知りました。」</span>
<span className="v" id="v28" data-v="28" data-xref="創世記 29:15; 創世記 29:19"> 彼は言った。「あなたの報酬を指定してください。私はそれを払いましょう。」</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="創世記 31:6; 創世記 31:38–40; ペテロの手紙第一 2:18"> ヤコブは彼に言った。「私がどのようにあなたに仕え、あなたの家畜が私のもとでどのようになったか、あなたは知っています。</span>
<span className="v" id="v30" data-v="30" data-xref="テモテへの手紙第一 5:8; コリント人への第二の手紙 12:14; 申命記 11:10"> 私が来る前、あなたのものはわずかでしたが、今ではおびただしく増えました。主は私の行く所どこでも、あなたを祝福されました。私も今、自分の家のために備えるべきではないでしょうか。」</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="サムエル記第二 21:4–6; ヘブル人への手紙 13:5; 詩篇 118:8"> ラバンは言った。「何をあなたに与えようか。」<br />ヤコブは言った。「何も私に与える必要はありません。もしあなたが私のためにこのことをしてくださるなら、私は再びあなたの群れを飼い、それを守りましょう。</span>
<span className="v" id="v32" data-v="32" data-xref="創世記 31:8; 創世記 31:10; 創世記 30:35"> 今日、私はあなたのすべての群れの間を通り、そこから、ぶちとまだらのものすべて、また羊の中の黒いものすべて、そして山羊の中のまだらとぶちのものをより分けます。これが私の報酬となります。</span>
<span className="v" id="v33" data-v="33" data-xref="出エジプト記 13:14; サムエル記第二 22:21; サムエル記第一 26:23"> 後日、あなたが私の報酬を確認に来るとき、私の正しさが私のために証言します。私のもとにいる山羊の中にぶちやまだらでないもの、あるいは羊の中に黒くないものがあれば、それは盗まれたものとみなされてよいでしょう。」</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="コリント人への第一の手紙 7:7; 民数記 22:29; コリント人への第一の手紙 14:5"> ラバンは言った。「見よ、あなたの言うとおりにしよう。」</span>
<span className="v" id="v35" data-v="35" data-xref="創世記 31:9"> その日、ラバンはしま模様とまだらの雄山羊、ぶちとまだらのすべての雌山羊、すなわち白い部分があるすべてのものと、羊の中のすべての黒いものをより分け、自分の息子たちの手に渡した。</span>
<span className="v" id="v36" data-v="36"> 彼は自分とヤコブとの間に三日の道のりを置き、ヤコブはラバンの残りの群れを飼った。</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="創世記 31:9–13; エゼキエル書 31:8"> ヤコブはポプラ、アーモンド、すずかけの木の若枝を取り、それに白い筋を作るように皮をむき、その枝の白い部分をむき出しにした。</span>
<span className="v" id="v38" data-v="38"> 彼は皮をむいた枝を、群れが水を飲みに来る水桶、すなわち水飲み場の中に、群れに向けて置いた。群れは水を飲みに来たときに発情した。</span>
<span className="v" id="v39" data-v="39" data-xref="出エジプト記 12:35–36; 創世記 31:9–12; 創世記 31:40"> 群れはその枝の前で発情し、しま模様、ぶち、まだらのものを産んだ。</span>
<span className="v" id="v40" data-v="40"> ヤコブは小羊を分け、群れをラバンの群れの中のしま模様のものとすべての黒いものに向かわせた。彼は自分の群れを別に分け、それらをラバンの群れの中には入れなかった。</span>
<span className="v" id="v41" data-v="41"> 群れの中の強いものが発情するたびに、ヤコブはその枝の間で発情するように、水飲み場の群れの目の前に枝を置いた。</span>
<span className="v" id="v42" data-v="42"> しかし、群れが弱いときは、それを置かなかった。こうして弱いものはラバンのものとなり、強いものはヤコブのものとなった。</span>
<span className="v" id="v43" data-v="43" data-xref="創世記 24:35; 創世記 30:30; 創世記 26:13–14"> こうしてヤコブは極めて豊かになり、大きな群れ、女のしもべと男のしもべ、らくだとろばを持つようになった。</span>
</div>
</div>

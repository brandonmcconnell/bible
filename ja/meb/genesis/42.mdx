<div className="bible-chapter" lang="ja" dir="ltr" data-lang="ja" data-translation="meb" data-translation-id="jpn_meb" data-translation-label="MEB" data-book="GEN" data-book-slug="genesis" data-book-name="創世記" data-chapter="42" data-verses="38">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒の働き 7:12; ヨシュア記 7:10; 列王記第二 8:3–4"> さて、ヤコブはエジプトに穀物があるのを見て、息子たちに言った。「なぜあなたがたは顔を見合わせているのか。」</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 43:8; 創世記 45:9; 創世記 43:2"> 彼は言った。「見よ、エジプトに穀物があると聞いた。そこへ下り、私たちのために買って来なさい。そうすれば、私たちは死なずに生き延びられる。」</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="創世記 42:5; 創世記 42:13"> ヨセフの十人の兄弟たちは、エジプトから穀物を買うために下って行った。</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 42:38; 創世記 43:29; 創世記 11:4"> しかしヤコブは、ヨセフの弟ベニヤミンを兄弟たちと一緒には行かせなかった。彼が「彼に災いが降りかかるといけない」と考えたからである。</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 41:57; 使徒の働き 7:11; 創世記 12:10"> カナンの地にも飢饉があったので、イスラエルの子らは、やって来る人々に混じって買いに行った。</span>
<span className="v" id="v6" data-v="6" data-xref="ヨハネの黙示録 3:9; 創世記 37:7–10; 創世記 41:40–41"> ヨセフはその地の統治者であり、すべての民に穀物を売っていた。兄弟たちはやって来て、顔を地に伏せ、彼の前にひれ伏した。</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 42:30; 創世記 42:14–17; マタイ 15:23–26"> ヨセフは兄弟たちを見て彼らだとわかったが、彼らに対して見知らぬ者のように振る舞い、厳しく語りかけた。彼は彼らに言った。「あなたがたはどこから来たのか。」<br />彼らは言った。「食物を買うために、カナンの地から来ました。」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="創世記 37:2; ヨハネ 20:14; ルカ 24:16"> ヨセフは兄弟たちだとわかったが、彼らには彼だとわからなかった。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 37:5–9; 出エジプト記 32:35; ヨシュア記 2:1"> ヨセフは彼らについて見た夢を思い出し、言った。「あなたがたはスパイだ。この国の隙を探るために来たのだ。」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="創世記 37:8; サムエル記第一 26:17; 創世記 27:37"> 彼らは彼に言った。「いいえ、ご主人様。あなたのしもべたちは食物を買うために来たのです。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 42:19; コリント人への第二の手紙 6:4; ヨハネ 7:18"> 私たちは皆、一人の人の息子です。私たちは正直な者であり、あなたのしもべたちはスパイではありません。」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12"> 彼は彼らに言った。「いや、あなたがたはこの国の隙をうかがうために来たのだ。」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="創世記 37:30; 創世記 42:32; 創世記 44:20"> 彼らは言った。「しもべどもは、カナンの地にいる一人の父の息子で、十二人兄弟です。末の弟は今、父と一緒におり、もう一人は、いなくなりました。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="マタイ 15:21–28; ヨブ記 13:24; 創世記 42:9–11"> ヨセフは彼らに言った。「私があなたがたに『あなたがたはスパイだ』と言ったのは、そのことだ。</span>
<span className="v" id="v15" data-v="15" data-xref="サムエル記第一 17:55; エレミヤ書 5:7; 創世記 42:16"> このことであなたがたを試す。ファラオの命にかけて言う。末の弟がここに来ない限り、あなたがたをここから出すことはない。</span>
<span className="v" id="v16" data-v="16" data-xref="創世記 42:11"> あなたがたのうち一人を遣わし、弟を連れて来させよ。その間、ほかの者は監獄に入るのだ。こうして言葉を試し、あなたがたに真実があるか確かめよう。さもなければ、ファラオの命にかけて、あなたがたは確かにスパイだ。」</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 40:4; ヘブル人への手紙 12:10; 創世記 40:7"> 彼は彼らを一緒に三日間、監獄に入れた。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="レビ記 25:43; ネヘミヤ記 5:15; ルカ 18:2"> 三日目にヨセフは彼らに言った。「このことを行って、生き延びなさい。私は神を恐れている。</span>
<span className="v" id="v19" data-v="19" data-xref="創世記 45:23; イザヤ書 42:7; 創世記 40:3"> もしあなたがたが正直な者なら、あなたがた兄弟のうち一人だけが監獄に残りなさい。あなたがたは行って、飢えている家族のために穀物を持ち帰りなさい。</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 44:23; 創世記 43:5; 創世記 42:34"> そして、あなたがたの一番下の弟を私のところに連れて来なさい。そうすれば、あなたがたの言葉は証明され、あなたがたは死なないだろう。」彼らはそのようにした。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="ホセア書 5:15; マルコ 9:43–45; 創世記 37:23–28"> 彼らは互いに言った。「私たちは弟のことで、まことに罪を負っている。彼が哀願したとき、その苦悩を目の当たりにしながら、聞き入れなかった。だから、この苦しみが私たちに降りかかったのだ。」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="歴代誌 第二 24:22; 詩篇 9:12; 列王記第一 2:32"> ルベンは彼らに答えた。「私はあなたがたに『あの少年に罪を犯してはならない』と言ったではないか。しかしあなたがたは聞き入れなかった。だから見よ、彼の血の責任が問われているのだ。」</span>
<span className="v" id="v23" data-v="23" data-xref="コリント人への第二の手紙 5:20; ヨハネ 16:13–14"> 彼らはヨセフがそれを理解しているとは知らなかった。彼らの間には通訳がいたからである。</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 43:30; ユダ 1:22–23; ヘブル人への手紙 4:15"> ヨセフは彼らから離れて行き、泣いた。そして彼らのところに戻り、彼らと話し、彼らの中からシメオンを取り、彼らの目の前で縛った。</span>
<span className="v" id="v25" data-v="25" data-xref="ペテロの手紙第一 3:9; ローマ人への手紙 12:17–21; 創世記 45:21"> それからヨセフは、彼らの袋に穀物を満たし、各々の銀をそれぞれの袋に戻し、道中のための食料を彼らに与えるように命じた。そのように彼らに行われた。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26"> 彼らは穀物をろばに積んで、そこを出発した。</span>
<span className="v" id="v27" data-v="27" data-xref="出エジプト記 4:24; ルカ 2:7; ルカ 10:34"> 宿泊所で、彼らの一人がろばに餌をやるために袋を開けると、自分の銀が見えた。見よ、それは袋の口にあった。</span>
<span className="v" id="v28" data-v="28" data-xref="イザヤ書 45:7; 哀歌 3:37; 創世記 42:36"> 彼は兄弟たちに言った。「私の銀が戻されている。見よ、袋の中にある。」彼らは心を失うほど驚き、震えながら互いに言った。「神は私たちに、何ということをなさったのか。」</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29"> 彼らはカナンの地にいる父ヤコブのところに帰り、自分たちに起こったすべてのことを彼に告げた。</span>
<span className="v" id="v30" data-v="30" data-xref="創世記 42:7"> 「その国の主である人が私たちに厳しく語りかけ、私たちをその国のスパイとみなしました。</span>
<span className="v" id="v31" data-v="31" data-xref="創世記 42:11"> 私たちは彼に言いました。『私たちは正直な者です。スパイではありません。</span>
<span className="v" id="v32" data-v="32"> 私たちは一人の父の息子たちで、十二人の兄弟です。一人はもうおらず、一番下の者は今日、カナンの地で父と一緒にいます。』</span>
<span className="v" id="v33" data-v="33" data-xref="創世記 42:19–20; 創世記 42:15"> その国の主である人は私たちに言いました。『あなたがたが正直な者であることを、このことによって私は知るだろう。あなたがたの兄弟の一人を私のもとに残し、飢えている家族のために穀物を持って行きなさい。</span>
<span className="v" id="v34" data-v="34" data-xref="創世記 34:10; 創世記 34:21; 列王記第一 10:15"> そして、あなたがたの一番下の弟を私のところに連れて来なさい。そうすれば、私はあなたがたがスパイではなく、正直な者であることがわかる。そして、あなたがたの兄弟をあなたがたに渡し、あなたがたはこの国で自由に行き来できるだろう。』」</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="創世記 43:21; 創世記 43:12; 創世記 43:15"> 彼らが袋を空にすると、見よ、各々の銀包みがその袋の中にあった。彼らと彼らの父がその銀包みを見たとき、彼らは恐れた。</span>
<span className="v" id="v36" data-v="36" data-xref="創世記 43:14; ローマ人への手紙 8:31; イザヤ書 27:9"> 父ヤコブは彼らに言った。「あなたがたは私から子を奪った。ヨセフはもういない。シメオンもいない。今度はベニヤミンまで連れ去ろうというのか。すべてが私に降りかかる。」</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="創世記 46:9; ミカ書 6:7; 創世記 43:9"> ルベンは父に言った。「もし私が彼をあなたのもとに連れ帰らなかったなら、私の二人の息子を殺してもかまいません。彼を私の手に委ねてください。私が彼をあなたのもとに連れ帰ります。」</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="創世記 37:35; 創世記 42:4; 創世記 37:33"> 彼は言った。「私の息子はあなたがたと一緒に下って行くことはない。彼の兄は死に、彼だけが残されているからだ。もしあなたがたが行く道中で彼に災いが降りかかれば、あなたがたは白髪の私を悲しみと共にシェオル<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="シェオルは死者の場所である。">a</a></sup>へ下らせることになる。」</span>
</div>
</div>

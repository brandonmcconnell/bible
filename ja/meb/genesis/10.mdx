<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 2:4; 創世記 9:7; 創世記 5:1"> これはノアの息子たち、セム、ハム、ヤペテの系図である。洪水のあと、彼らに息子たちが生まれた。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="エゼキエル書 38:2; エゼキエル書 38:6; ヨハネの黙示録 20:8"> ヤペテの息子たちは、ゴメル、マゴグ、マダイ、ヤワン、トバル、メシェク、ティラスである。</span>
<span className="v" id="v3" data-v="3" data-xref="エゼキエル書 27:14; エレミヤ書 51:27"> ゴメルの息子たちは、アシュケナズ、リファト、トガルマである。</span>
<span className="v" id="v4" data-v="4" data-xref="ダニエル書 11:30; イザヤ書 23:12; 民数記 24:24"> ヤワンの息子たちは、エリシャ、タルシシュ、キティム、ドダニムである。</span>
<span className="v" id="v5" data-v="5" data-xref="ゼパニヤ書 2:11; イザヤ書 42:4; エレミヤ書 2:10"> これらから、海沿いの国々の民が、それぞれ自分たちの土地に分かれていった。彼らは、それぞれの言語、それぞれの氏族、それぞれの国にしたがっていた。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="歴代誌上 1:8–16; エゼキエル書 27:10; 詩篇 105:23"> ハムの息子たちは、クシュ、ミツライム、プト、カナンである。</span>
<span className="v" id="v7" data-v="7" data-xref="エゼキエル書 27:22; エゼキエル書 27:15; イザヤ書 21:13"> クシュの息子たちは、セバ、ハビラ、サブタ、ラアマ、サブテカである。ラアマの息子たちは、シェバとデダンである。</span>
<span className="v" id="v8" data-v="8" data-xref="ミカ書 5:6"> クシュはニムロドの父となった。ニムロドは地上で力ある者となり始めた。</span>
<span className="v" id="v9" data-v="9" data-xref="歴代誌 第二 28:22; 創世記 6:11; 創世記 25:27"> 彼は主の前に力ある狩人であった。それゆえ、「主の前に力ある狩人ニムロドのように」と言われるようになった。</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 11:9; 創世記 11:2; 創世記 14:1"> 彼の王国の始まりは、シンアルの地にあるバベル、エレク、アッカド、カルネであった。</span>
<span className="v" id="v11" data-v="11" data-xref="ミカ書 5:6; 詩篇 83:8; ナホム書 1:1"> 彼はその地からアッシリアに出て行き、ニネベ、レホボト・イル、カラ、</span>
<span className="v" id="v12" data-v="12"> そしてニネベとカラの間にあるレセンを建てた。これが大きな町である。</span>
<span className="v" id="v13" data-v="13" data-xref="歴代誌上 1:11–12; エレミヤ書 46:9; エゼキエル書 30:5"> ミツライムは、ルディム、アナミム、レハビム、ナフトヒム、</span>
<span className="v" id="v14" data-v="14" data-xref="エレミヤ書 47:4; 歴代誌上 1:12; 申命記 2:23"> パトルシム、カスルヒム、カフトリムの父となった。ペリシテ人はカスルヒムから出た。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="民数記 34:2–15; 出エジプト記 34:11; 創世記 23:3"> カナンは、長子シドン、ヘト、</span>
<span className="v" id="v16" data-v="16" data-xref="サムエル記第二 24:18; 士師記 1:21; ゼカリヤ書 9:7"> エブス人、アモリ人、ギルガシ人、</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 34:2"> ヒビ人、アルキ人、シニ人、</span>
<span className="v" id="v18" data-v="18" data-xref="ヨシュア記 18:22; サムエル記第二 8:9; エゼキエル書 27:8"> アルワド人、ツェマリ人、ハマテ人の父となった。その後、カナン人の氏族は散らばっていった。</span>
<span className="v" id="v19" data-v="19" data-xref="創世記 14:2; 創世記 19:24–25; ヨシュア記 12:7–8"> カナン人の境界は、シドンからゲラルに向かってガザに至り、さらにソドム、ゴモラ、アデマ、ツェボイムに向かってラシャに至るものであった。</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 10:6; 創世記 11:1–9"> これらがハムの息子たちであり、それぞれの氏族、それぞれの言語、その土地、その国々にしたがっていた。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="民数記 24:24; 創世記 11:10–26"> エベルのすべての子孫の父であり、ヤペテの兄であるセムにも、子どもたちが生まれた。</span>
<span className="v" id="v22" data-v="22" data-xref="イザヤ書 66:19; エレミヤ書 25:25; 創世記 14:1–9"> セムの息子たちは、エラム、アシュル、アルパクシャド、ルデ、アラムである。</span>
<span className="v" id="v23" data-v="23" data-xref="ヨブ記 1:1; エレミヤ書 25:20"> アラムの息子たちは、ウツ、フル、ゲテル、マシュである。</span>
<span className="v" id="v24" data-v="24" data-xref="ルカ 3:35; 創世記 11:12–15"> アルパクシャドはシェラの父となり、シェラはエベルの父となった。</span>
<span className="v" id="v25" data-v="25" data-xref="歴代誌上 1:19; 創世記 10:32; 申命記 32:8"> エベルには二人の息子が生まれた。一人の名はペレグであった。彼の時代に地が分けられたからである。彼の弟の名はヨクタンであった。</span>
<span className="v" id="v26" data-v="26" data-xref="歴代誌上 1:20–28"> ヨクタンは、アルモダド、シェレフ、ハツァルマベト、エラ、</span>
<span className="v" id="v27" data-v="27" data-xref="歴代誌上 1:20–28"> ハドラム、ウザル、ディクラ、</span>
<span className="v" id="v28" data-v="28" data-xref="歴代誌上 1:20–28; 列王記第一 10:1; 創世記 25:3"> オバル、アビマエル、シェバ、</span>
<span className="v" id="v29" data-v="29" data-xref="列王記第一 9:28; 歴代誌上 9:13; 創世記 2:11"> オフィル、ハビラ、ヨバブの父となった。これらは皆、ヨクタンの息子たちであった。</span>
<span className="v" id="v30" data-v="30" data-xref="民数記 23:7"> 彼らの住まいは、メシャから、東の山地であるセファルへ向かう地域であった。</span>
<span className="v" id="v31" data-v="31" data-xref="創世記 10:5; 創世記 10:20; 使徒の働き 17:26"> これらがセムの息子たちであり、それぞれの氏族、それぞれの言語、その土地、その国々にしたがっていた。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="創世記 9:19; 使徒の働き 17:26; 創世記 10:1"> これらがノアの息子たちの氏族であり、それぞれの系図にしたがい、その国々にいた。洪水のあと、これらから国々が地上に分かれていった。</span>
</div>

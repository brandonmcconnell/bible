<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歴代誌上 1:32–33; 創世記 23:1–2; 創世記 28:1"> アブラハムはもう一人の妻をめとった。彼女の名はケトラであった。</span>
<span className="v" id="v2" data-v="2" data-xref="歴代誌上 1:32–33; 民数記 25:17–18; ヨブ記 2:11"> 彼女は彼に、ジムラン、ヨクシャン、メダン、ミディアン、イシュバク、シュアを産んだ。</span>
<span className="v" id="v3" data-v="3" data-xref="エゼキエル書 25:13; エレミヤ書 49:8; エゼキエル書 27:20"> ヨクシャンはシバとデダンの父となった。デダンの息子たちは、アシュリ人、レトシ人、レウミ人であった。</span>
<span className="v" id="v4" data-v="4" data-xref="イザヤ書 60:6"> ミディアンの息子たちは、エファ、エフェル、ハノク、アビダ、エルダアであった。これらは皆、ケトラの子どもたちであった。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="創世記 24:36; ヘブル人への手紙 1:2; ガラテヤ人への手紙 3:29"> アブラハムは自分のすべての持ち物をイサクに与えた。</span>
<span className="v" id="v6" data-v="6" data-xref="創世記 21:14; 士師記 6:3; 使徒の働き 14:17"> しかし、アブラハムのそばめたちの息子たちには、アブラハムは贈り物を与えた。彼はまだ生きている間に、彼らを息子イサクから離して、東の方、東の国へ送り出した。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="創世記 12:4"> アブラハムが生きた年数は百七十五年であった。</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 35:28–29; 創世記 15:15; 歴代誌上 29:28"> アブラハムは息を引き取って死んだ。長寿を全うし、老いて満ち足り、自分の民に加えられた。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 50:13; 創世記 35:29; 創世記 49:29–30"> 息子たちであるイサクとイシュマエルは、彼をマクペラの洞穴に葬った。そこはマムレの前にある、ヘト人ツォハルの子エフロンの畑であった。</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 23:16; 創世記 49:31"> その畑は、アブラハムがヘトの人々から買い取ったものである。そこにアブラハムと妻サラが葬られた。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 22:17; 創世記 16:14; 創世記 24:62"> アブラハムの死後、神はその息子イサクを祝福された。イサクはベエル・ラハイ・ロイの近くに住んだ。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="詩篇 83:6; 創世記 17:20; 創世記 21:13"> これは、サラのしもべであるエジプト人ハガルがアブラハムに産んだ、アブラハムの息子イシュマエルの系図である。</span>
<span className="v" id="v13" data-v="13" data-xref="歴代誌上 1:29–31; イザヤ書 60:7; 雅歌 1:5"> これらは、それぞれの名によるイシュマエルの息子たちの名である。イシュマエルの長子ネバヨト、次にケダル、アドベエル、ミブサム、</span>
<span className="v" id="v14" data-v="14" data-xref="イザヤ書 21:11; イザヤ書 21:16"> ミシュマ、ドマ、マサ、</span>
<span className="v" id="v15" data-v="15" data-xref="歴代誌上 5:19; ヨブ記 2:11"> ハダド、テマ、エツル、ナフィシュ、ケデマである。</span>
<span className="v" id="v16" data-v="16" data-xref="創世記 17:20; 創世記 17:23"> これらがイシュマエルの息子たちであり、その村々、その宿営地に付けられた名である。彼らは部族ごとの十二人の族長であった。</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 15:15; 創世記 25:7–8"> イシュマエルの生涯は百三十七年であった。彼は息を引き取って死に、自分の民に加えられた。</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 16:12; 創世記 20:1; 列王記第二 23:29"> 彼らは、エジプトの前にあるハビラから、アッシリアへ行く道にあるシュルに至るまで住んだ。彼はすべての兄弟たちと対立して住んだ。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="マタイ 1:2; ルカ 3:34; 使徒の働き 7:8"> これはアブラハムの息子イサクの系図である。アブラハムはイサクの父となった。</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 24:29; 創世記 24:67; 創世記 22:23"> イサクは四十歳のとき、パダン・アラムのアラム人ベトエルの娘であり、アラム人ラバンの妹であるリベカを妻にめとった。</span>
</div>
<div className="bp poetry">
<span className="v" id="v21" data-v="21" data-xref="ルカ 1:13; イザヤ書 58:9; エズラ記 8:23"> イサクは妻のために主に願い求めた。彼女が不妊であったからである。主は彼の願いを聞き入れ、妻リベカは身ごもった。</span>
<span className="v" id="v22" data-v="22" data-xref="サムエル記第一 9:9; サムエル記第一 28:6; サムエル記第一 30:8"> 子どもたちが彼女の胎内で激しくぶつかり合ったので、彼女は言った。「こんなことなら、私はどうなるのだろう。」そして主に尋ねに行った。</span>
<span className="v" id="v23" data-v="23" data-xref="ローマ人への手紙 9:10–13; 創世記 27:40; 創世記 27:29"> 主は彼女に言われた。<br /><span className="pl pl-1">「二つの民族があなたの胎内にあり、</span><br /><span className="pl pl-2">二つの民があなたの体から分かれ出る。</span><br /><span className="pl pl-1">一つの民はもう一つの民より強くなり、</span><br /><span className="pl pl-2">兄が弟に仕える。」</span></span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24"> 彼女の出産の日が満ちたとき、見よ、彼女の胎内には双子がいた。</span>
<span className="v" id="v25" data-v="25" data-xref="創世記 27:11; 創世記 27:16; 創世記 27:23"> 最初の男の子が出て来た。彼は赤く、全身が毛衣のようであった。彼らはその名をエサウ<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="エサウは「毛深い」を意味する。">a</a></sup>と名付けた。</span>
<span className="v" id="v26" data-v="26" data-xref="創世記 27:36; ホセア書 12:3; 創世記 38:28–30"> その後、弟が出て来た。彼の手はエサウのかかとをつかんでいた。彼らはその名をヤコブ<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="ヤコブは「かかとをつかむ者」または「押しのける者」を意味する。">b</a></sup>と名付けた。彼らが生まれたとき、イサクは六十歳であった。</span>
<span className="v" id="v27" data-v="27" data-xref="ヘブル人への手紙 11:9; 創世記 21:20; 創世記 10:9"> 少年たちは成長した。エサウは熟練した狩人となり、野の人となった。ヤコブは物静かな人で、天幕に住んでいた。</span>
<span className="v" id="v28" data-v="28" data-xref="創世記 27:19; 創世記 27:31; 創世記 27:4"> イサクはエサウを愛した。エサウの獲物が好みだったからである。しかし、リベカはヤコブを愛した。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="箴言 13:25; イザヤ書 40:30–31; サムエル記第一 14:28"> ヤコブが煮物を煮ているとき、エサウが野から帰って来た。彼は疲れ果てていた。</span>
<span className="v" id="v30" data-v="30" data-xref="創世記 36:1; 出エジプト記 15:15; 創世記 36:9"> エサウはヤコブに言った。「どうか、その赤いものを、あの赤いものを私に食べさせてくれ。私は疲れ果てているからだ。」それゆえ、彼の名はエドム<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="エドムは「赤い」を意味する。">c</a></sup>と呼ばれた。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31"> ヤコブは言った。「まず、あなたの長子の権利を私に売ってください。」</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="マラキ書 3:14; ヨブ記 21:15; ヨブ記 22:17"> エサウは言った。「見よ、私は死にそうだ。この長子の権利が私にとって何になるというのか。」</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="ヘブル人への手紙 12:16; 創世記 27:36; ヘブル人への手紙 6:16"> ヤコブは言った。「まず、私に誓ってください。」<br />エサウは彼に誓い、自分の長子の権利をヤコブに売った。</span>
<span className="v" id="v34" data-v="34" data-xref="ピリピ人への手紙 3:18–19; ヘブル人への手紙 12:16–17; コリント人への第一の手紙 15:32"> ヤコブはエサウにパンとレンズ豆の煮物を与えた。エサウは食べて飲み、立ち上がって去って行った。このようにして、エサウは自分の長子の権利を軽んじた。</span>
</div>
</div>

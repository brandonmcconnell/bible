<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出エジプト記 31:17; 出エジプト記 20:11; 詩篇 33:6"> こうして、天と地と、そのすべての万象は完成した。</span>
<span className="v" id="v2" data-v="2" data-xref="ヘブル人への手紙 4:4; 出エジプト記 31:17; 申命記 5:14"> 神は第七日に、ご自分がなさっていた仕事を完成された。そして、ご自分がなさっていたすべての仕事を終えて、第七日に休まれた。</span>
<span className="v" id="v3" data-v="3" data-xref="エゼキエル書 20:12; マルコ 2:27; レビ記 23:3"> 神は第七日を祝福し、これを聖別された。神が創造のすべてのわざを終え、この日に休まれたからである。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="創世記 5:1; ヨハネの黙示録 1:8; 創世記 1:4"> これは、天と地が創造されたときの記録<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「記録」と訳されているヘブライ語「תּוֹלְדוֹת」（トレドット）は、「系譜」「由来」「歴史」を意味する。">a</a></sup>である。主なる神<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="ここで「主」と訳されているヘブライ語は、神の固有名「יהוה」（ヤハウェ）である。">b</a></sup>が地と天を造られた日、</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 3:23; ヘブル人への手紙 6:7; ヨブ記 5:10"> 地にはまだ野の低木がなく、野の草もまだ生えていなかった。主なる神が地の上に雨を降らせておらず、土を耕す人もいなかったからである。</span>
<span className="v" id="v6" data-v="6"> しかし、地から霧が立ち上り、地面の全面を潤していた。</span>
<span className="v" id="v7" data-v="7" data-xref="伝道者の書 12:7; ヨブ記 33:4; コリント人への第一の手紙 15:45"> 主なる神は、地面のちりで人を形造り、その鼻に命の息を吹き込まれた。こうして人は生きる者となった。</span>
<span className="v" id="v8" data-v="8" data-xref="エゼキエル書 28:13; 創世記 3:24; 創世記 13:10"> 主なる神は東の方のエデンに園を植え、ご自分が形造った人をそこに置かれた。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 3:22; ヨハネの黙示録 2:7; ヨハネの黙示録 22:14"> 主なる神は、見るからに好ましく、食物として良いすべての木を地面から生えさせた。また、園の中央には命の木と、善悪の知識の木を生えさせた。</span>
<span className="v" id="v10" data-v="10" data-xref="ヨハネの黙示録 22:1; 詩篇 46:4"> 一つの川が、園を潤すためにエデンから流れ出ていた。それはそこから分かれ、四つの川の源となった。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 25:18; 創世記 10:29; サムエル記第一 15:7"> 第一の川の名はピションである。それは金のあるハビラの全土を巡って流れる。</span>
<span className="v" id="v12" data-v="12" data-xref="出エジプト記 28:20; 民数記 11:7; エゼキエル書 28:13"> その地の金は良い。そこにはブデリウム<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="または「芳香樹脂」。">c</a></sup>とシマメノウもある。</span>
<span className="v" id="v13" data-v="13" data-xref="創世記 10:6; イザヤ書 11:11"> 第二の川の名はギホンである。それはクシュの全土を巡って流れる川である。</span>
<span className="v" id="v14" data-v="14" data-xref="ダニエル書 10:4; 創世記 15:18; 申命記 1:7"> 第三の川の名はヒデケルである。これはアッシリアの前を流れる川である。第四の川はユーフラテスである。</span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 128:2; 創世記 2:8; エペソ人への手紙 4:28"> 主なる神は人を取り、エデンの園に置いて、そこを耕し、守らせた。</span>
<span className="v" id="v16" data-v="16" data-xref="サムエル記第一 15:22; テモテへの手紙第一 4:4; テモテへの手紙第一 6:17"> 主なる神は人に命じて言われた。「あなたは園のどの木からでも、思いのままに食べてもよい。</span>
<span className="v" id="v17" data-v="17" data-xref="ローマ人への手紙 6:23; ヤコブの手紙 1:15; 創世記 3:19"> しかし、善悪の知識の木からは食べてはならない。それを食べる日に、あなたは必ず死ぬ。」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="伝道者の書 4:9–12; コリント人への第一の手紙 11:7–12; 箴言 18:22"> 主なる神は言われた。「人が一人でいるのは良くない。わたしは彼のために、彼にふさわしい<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="または「彼に適した」「彼に対応する」。">d</a></sup>助け手を造ろう。」</span>
<span className="v" id="v19" data-v="19" data-xref="詩篇 8:4–8; 創世記 1:28; 創世記 9:2"> 主なる神は、野のすべての獣と空のすべての鳥を地面から形造り、人がそれらを何と呼ぶかを見るために、人のところに連れて来られた。人がそれぞれの生き物を呼んだ名前、それがその名前となった。</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 2:18"> 人はすべての家畜、空の鳥、野のすべての獣に名前をつけた。しかし人には、彼にふさわしい助け手が見つからなかった。</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 15:12; ヨブ記 4:13; サムエル記第一 26:12"> 主なる神は人を深い眠りに落とされた。人が眠っている間に、神はそのあばら骨の一つを取り、その場所を肉で塞がれた。</span>
<span className="v" id="v22" data-v="22" data-xref="コリント人への第一の手紙 11:8–9; テモテへの手紙第一 2:13; ヘブル人への手紙 13:4"> 主なる神は、人から取ったあばら骨で女を造り、彼女を人のところに連れて来られた。</span>
<span className="v" id="v23" data-v="23" data-xref="エペソ人への手紙 5:28–30; コリント人への第一の手紙 11:8–9; サムエル記第二 5:1"> 人は言った。「これこそ、私の骨の骨、私の肉の肉。これを『女』と呼ぼう。男から取られたのだから。」</span>
<span className="v" id="v24" data-v="24" data-xref="マタイ 19:3–9; エペソ人への手紙 5:28–31; マルコ 10:6–12"> それゆえ、男は父と母を離れ、妻と結ばれ、二人は一つの肉となる。</span>
<span className="v" id="v25" data-v="25" data-xref="創世記 3:7; 創世記 3:10–11; ローマ人への手紙 10:11"> 人とその妻は二人とも裸であったが、恥じていなかった。</span>
</div>

<div className="bible-chapter" lang="ja" dir="ltr" data-lang="ja" data-translation="meb" data-translation-id="jpn_meb" data-translation-label="MEB" data-book="GEN" data-book-slug="genesis" data-book-name="創世記" data-chapter="31" data-verses="55">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="伝道者の書 4:4; 詩篇 49:16–17; ヨブ記 31:31"> ヤコブは、「ヤコブは私たちの父のものをすべて奪い取った。父のものから、彼はこのすべての富を得たのだ」と言うラバンの息子たちの言葉を耳にした。</span>
<span className="v" id="v2" data-v="2" data-xref="ダニエル書 3:19; サムエル記第一 18:9–11; 創世記 4:5"> ヤコブがラバンの態度を見ると、見よ、以前のようには自分に向けられていなかった。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 28:15; 創世記 32:9; ヘブル人への手紙 13:5"> 主はヤコブに言われた。「あなたの先祖の地、あなたの親族のところへ帰りなさい。わたしはあなたと共にいる。」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4"> ヤコブは人を遣わして、ラケルとレアを群れのいる野に呼び出し、</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 31:2–3; 創世記 31:53; 創世記 48:15"> 彼女たちに言った。「あなたがたの父の態度を見ると、以前とは違っている。しかし、私の父の神は私と共におられた。</span>
<span className="v" id="v6" data-v="6" data-xref="創世記 30:29; エペソ人への手紙 6:5–8; テトス 2:9–10"> 私が全力であなたがたの父に仕えてきたことは、あなたがたも知っている。</span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 37:28; 創世記 31:29; 民数記 14:22"> あなたがたの父は私を欺き、十回も報酬を変えた。しかし神は、彼が私に害を加えることをお許しにならなかった。</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 30:32"> もし彼が『ぶちのものがあなたの報酬となる』と言えば、群れはみなぶちのものを産んだ。もし彼が『しま模様のものがあなたの報酬となる』と言えば、群れはみなしま模様のものを産んだ。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 31:1; 創世記 31:16; 箴言 13:22"> こうして神は、あなたがたの父の家畜を取り上げて、私に与えられた。</span>
<span className="v" id="v10" data-v="10" data-xref="申命記 13:1; 創世記 30:39; 創世記 20:6"> 群れが交尾する季節に、私が目を上げて夢の中で見ると、見よ、群れと交尾している雄山羊は、しま模様、ぶち、まだらであった。</span>
<span className="v" id="v11" data-v="11" data-xref="イザヤ書 58:9; 創世記 31:13; サムエル記第一 3:6"> 神の使いが夢の中で私に『ヤコブよ』と言われたので、私は『はい、ここにおります』と言った。</span>
<span className="v" id="v12" data-v="12" data-xref="出エジプト記 3:7; 申命記 24:15; 創世記 31:42"> 彼は言われた。『さあ、目を上げて見なさい。群れと交尾している雄山羊はみな、しま模様、ぶち、まだらである。ラバンがあなたにしていることを、わたしはすべて見たからである。</span>
<span className="v" id="v13" data-v="13" data-xref="創世記 31:3; 創世記 32:9; 創世記 28:12–22"> わたしはベテルの神である。あなたはそこで柱に油を注ぎ、そこでわたしに誓いを立てた。さあ、立ち上がり、この地を出て、あなたの生まれた地へ帰りなさい。』」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="ルツ記 4:11; 創世記 2:24; 創世記 29:24"> ラケルとレアは彼に答えた。「私たちの父の家には、まだ私たちへの分け前や相続地があるでしょうか。</span>
<span className="v" id="v15" data-v="15" data-xref="創世記 29:15–20; 創世記 31:41; 創世記 29:27–30"> 父は私たちを他人のように扱っているではありませんか。私たちを売り、その代価まで使い果たしてしまいました。</span>
<span className="v" id="v16" data-v="16" data-xref="創世記 30:35–1; 創世記 31:9; 詩篇 45:10"> 神が父から取り上げられたすべての富は、私たちと子どもたちのものです。さあ、神があなたに言われたとおりにしてください。」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="サムエル記第一 30:17; 創世記 24:61; 創世記 24:10"> そこでヤコブは立ち上がり、息子たちと妻たちをらくだに乗せ、</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 27:1–2; 創世記 27:41; 創世記 35:27–29"> 自分が手に入れたすべての家畜とすべての持ち物、すなわちパダン・アラムで手に入れた家畜をすべて引き連れ、カナンの地にいる父イサクのところへ向かった。</span>
<span className="v" id="v19" data-v="19" data-xref="サムエル記第一 19:13; 創世記 31:30; ホセア書 3:4"> その時、ラバンは自分の羊の毛を刈るために出かけていた。そしてラケルは、父のテラフィム<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="または「家の偶像」。">a</a></sup>を盗んだ。</span>
<span className="v" id="v20" data-v="20"> ヤコブは、自分が逃げることを告げず、アラム人ラバンを欺いた。</span>
<span className="v" id="v21" data-v="21" data-xref="列王記第二 12:17; 創世記 37:25; 創世記 46:28"> こうして彼は、自分のすべての持ち物と共に逃げた。彼は立ち上がって川を渡り、ギレアデの山地へ向かった。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="ヨブ記 5:12–13; 創世記 30:36; 出エジプト記 14:5–31"> 三日目になって、ヤコブが逃げたことがラバンに知らされた。</span>
<span className="v" id="v23" data-v="23" data-xref="創世記 13:8; 創世記 24:27; 出エジプト記 2:11"> ラバンは親族を連れて行き、七日の道のりを追跡して、ギレアデの山地で彼に追いついた。</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 24:50; 創世記 31:29; 創世記 20:3"> 夜の夢の中で、神がアラム人ラバンに現れて言われた。「ヤコブに何も言わないよう、よく気をつけよ。」</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="創世記 12:8; 創世記 33:18; ヘブル人への手紙 11:9"> ラバンはヤコブに追いついた。ヤコブは山に天幕を張っており、ラバンも親族と共にギレアデの山地に天幕を張った。</span>
<span className="v" id="v26" data-v="26" data-xref="サムエル記第一 30:2; 創世記 12:18; 創世記 20:9–10"> ラバンはヤコブに言った。「私を欺き、私の娘たちを剣で捕らえた捕虜のように連れ去るとは、あなたは何ということをしたのか。</span>
<span className="v" id="v27" data-v="27" data-xref="出エジプト記 15:20; 箴言 26:23–26; 創世記 31:3–5"> なぜあなたはひそかに逃げ、私を欺き、私に告げなかったのか。私は喜びと歌、タンバリンと竪琴であなたを送り出しただろうに。</span>
<span className="v" id="v28" data-v="28" data-xref="創世記 31:55; ルツ記 1:14; 使徒の働き 20:37"> そして、なぜ私に息子たちや娘たちに口づけさせてくれなかったのか。今、あなたは愚かなことをした。</span>
<span className="v" id="v29" data-v="29" data-xref="創世記 31:53; 創世記 31:42; 創世記 31:24"> 私の手には、あなたがたに害を加える力がある。しかし、昨夜、あなたがたの父の神が私に語って、『ヤコブに対して、良いことも悪いことも言わないように気をつけなさい』と言われた。</span>
<span className="v" id="v30" data-v="30" data-xref="エレミヤ書 10:11; 創世記 31:19; 士師記 18:24"> 今、あなたは父の家をひどく慕い求めて去ろうとしているが、なぜ私の神々を盗んだのか。」</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="箴言 29:25; 創世記 31:26–27; 創世記 20:11"> ヤコブはラバンに答えた。「あなたが娘たちを私から力ずくで奪うのではないかと恐れたのです。</span>
<span className="v" id="v32" data-v="32" data-xref="サムエル記第一 12:3–5; 創世記 31:30; 創世記 31:19"> しかし、あなたの神々を誰のところで見つけたとしても、その者を生かしてはおきません。私たちの親族の前で、私のところにあるあなたのものを調べ、それを持って行ってください。」ヤコブは、ラケルがそれらを盗んだことを知らなかったからである。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="創世記 24:67; 創世記 24:28"> ラバンはヤコブの天幕、レアの天幕、二人の女のしもべの天幕に入ったが、見つけることはできなかった。彼はレアの天幕を出て、ラケルの天幕に入った。</span>
<span className="v" id="v34" data-v="34" data-xref="創世記 31:19; 創世記 31:17"> その時、ラケルはテラフィムを取り、それをらくだの鞍の中に入れ、その上に座っていた。ラバンは天幕の中をすべて探ったが、それらを見つけることはできなかった。</span>
<span className="v" id="v35" data-v="35" data-xref="レビ記 19:32; 出エジプト記 20:12; ペテロの手紙第一 2:18"> 彼女は父に言った。「父上、御前に立ち上がれないことをお許しください。月のものがあるのです。」彼は探し回ったが、テラフィムを見つけられなかった。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="エペソ人への手紙 4:26; 創世記 49:7; 民数記 16:15"> ヤコブは怒り、ラバンを責めた。ヤコブはラバンに答えた。「私の罪とは何ですか。私の咎とは何だというので、あなたは私を激しく追って来たのですか。</span>
<span className="v" id="v37" data-v="37" data-xref="ペテロの手紙第一 2:12; コリント人への第一の手紙 6:4–5; サムエル記第一 12:3–4"> あなたは私の持ち物をすべて探ったが、あなたの家の持ち物が何か見つかりましたか。私の親族とあなたの親族の前にそれを置いて、彼らに私たち二人の間を裁かせなさい。</span>
<span className="v" id="v38" data-v="38" data-xref="創世記 30:27; 申命記 28:4; エゼキエル書 34:2–4"> この二十年間、私はあなたと共にいました。あなたの雌羊と雌山羊は流産したことがなく、私はあなたの群れの雄羊を食べたこともありません。</span>
<span className="v" id="v39" data-v="39" data-xref="出エジプト記 22:31; 出エジプト記 22:10–13; レビ記 22:8"> 獣に引き裂かれたものを、私はあなたのところに持って行きませんでした。私がその損失を補いました。昼に盗まれたものも、夜に盗まれたものも、あなたは私の手からそれを償わせました。</span>
<span className="v" id="v40" data-v="40" data-xref="ルカ 2:8; 出エジプト記 2:19–22; ペテロの手紙第一 5:2–4"> 昼は暑さに焼かれ、夜は寒さに凍え、眠りは私の目から逃げ去りました。</span>
<span className="v" id="v41" data-v="41" data-xref="創世記 31:7; コリント人への第一の手紙 15:10; コリント人への第二の手紙 11:26"> この二十年間、私はあなたの家で過ごしました。私はあなたの二人の娘のために十四年、あなたの群れのために六年あなたに仕えました。そして、あなたは私の報酬を十回も変えました。</span>
<span className="v" id="v42" data-v="42" data-xref="詩篇 31:7; 創世記 31:53; イザヤ書 8:13"> もし私の父の神、アブラハムの神、イサクの畏れる方が私と共におられなかったなら、あなたは私を何も持たせずに送り出したでしょう。神は私の苦しみと手の労苦をご覧になり、昨夜あなたを戒められたのです。」</span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43"> ラバンはヤコブに答えた。「娘たちは私の娘、子どもたちは私の子ども、群れは私の群れ。あなたが見ているものはすべて私のものだ。だが今日、この娘たちと、その産んだ子どもたちに、私が何をできよう。</span>
<span className="v" id="v44" data-v="44" data-xref="創世記 31:52; ヨシュア記 24:25–27; ヨシュア記 22:27"> さあ、私とあなたで契約を結ぼう。それが私とあなたの間の証拠となるように。」</span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="創世記 28:18–22"> ヤコブは一つの石を取り、それを柱として立てた。</span>
<span className="v" id="v46" data-v="46" data-xref="伝道者の書 3:5; 創世記 31:23; 創世記 31:54"> ヤコブは親族たちに「石を集めなさい」と言った。彼らは石を取り、一つの石塚を作った。彼らはその石塚のそばで食事をした。</span>
<span className="v" id="v47" data-v="47" data-xref="ヘブル人への手紙 12:1"> ラバンはそれをエガル・サハドゥタ<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="エガル・サハドゥタはアラム語で「証拠の石塚」を意味する。">b</a></sup>と呼んだが、ヤコブはそれをガルエド<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="ガルエドはヘブライ語で「証拠の石塚」を意味する。">c</a></sup>と呼んだ。</span>
<span className="v" id="v48" data-v="48" data-xref="ヨシュア記 24:27; ヨシュア記 13:8–9; 創世記 31:23"> ラバンは言った。「この石塚は今日、私とあなたの間の証拠である。」それゆえ、その名はガルエドと呼ばれ、</span>
<span className="v" id="v49" data-v="49" data-xref="士師記 11:29; 士師記 10:17; サムエル記第一 7:5–6"> またミツパ<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="ミツパは「見張りの塔」を意味する。">d</a></sup>と呼ばれた。彼がこう言ったからである。「私たちが互いに離れている間、主が私とあなたの間を見張ってくださるように。</span>
<span className="v" id="v50" data-v="50" data-xref="エレミヤ書 42:5; エレミヤ書 29:23; ミカ書 1:2"> もしあなたが私の娘たちを苦しめるなら、あるいは私の娘たちのほかに妻をめとるなら、私たちのところに誰もいなくても、見よ、神が私とあなたの間の証人である。」</span>
</div>
<div className="bp">
<span className="v" id="v51" data-v="51"> ラバンはヤコブに言った。「見よ、この石塚を。そして見よ、私が私とあなたの間に立てた柱を。</span>
<span className="v" id="v52" data-v="52" data-xref="創世記 31:48; 創世記 31:44–45"> 私がこの石塚を越えてあなたに害を加えず、あなたもこの石塚と柱を越えて私に害を加えない。そのことを、この石塚と柱が証しする。</span>
<span className="v" id="v53" data-v="53" data-xref="創世記 31:42; 創世記 16:5; ヨシュア記 24:2"> アブラハムの神、ナホルの神、彼らの父の神が、私たちの間を裁いてくださるように。」<br />そこでヤコブは、父イサクの畏れる方にかけて誓った。</span>
<span className="v" id="v54" data-v="54" data-xref="出エジプト記 18:12; 創世記 37:25; 創世記 26:30"> ヤコブは山でいけにえをささげ、親族を呼んで食事をした。彼らは食事をし、山で一晩を過ごした。</span>
<span className="v" id="v55" data-v="55" data-xref="創世記 31:28; 申命記 23:5; 創世記 18:33"> 朝早く、ラバンは起き上がり、息子たちや娘たちに口づけして彼らを祝福した。ラバンは去り、自分の場所に帰って行った。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 40:13; 創世記 39:20–23; エステル記 6:1"> これらのことの後、エジプトの王の献酌官とパン職人が、彼らの主君であるエジプトの王に対して罪を犯した。</span>
<span className="v" id="v2" data-v="2" data-xref="箴言 16:14; 箴言 19:12; 詩篇 76:10"> ファラオは二人の高官、すなわち献酌官の長とパン職人の長に向かって怒った。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 39:20; 創世記 39:23"> 彼は彼らを、護衛の長の家にある監獄、すなわちヨセフがつながれていた場所に入れた。</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 39:1; 詩篇 37:5; 創世記 37:36"> 護衛の長は彼らをヨセフに任せ、ヨセフは彼らに仕えた。彼らはしばらくの間、監獄にいた。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="創世記 41:11; 創世記 40:8; 創世記 37:5–10"> 監獄につながれていたエジプトの王の献酌官とパン職人の二人は、同じ夜にそれぞれ夢を見た。それぞれの夢には意味があった。</span>
<span className="v" id="v6" data-v="6" data-xref="創世記 41:8; ダニエル書 2:1–3; 創世記 40:8"> 朝、ヨセフが彼らのところへ行って見ると、二人は沈んだ様子であった。</span>
<span className="v" id="v7" data-v="7" data-xref="ネヘミヤ記 2:2; サムエル記第一 1:8; ルカ 24:17"> 彼は主人の家の監獄で自分と共にいたファラオの高官たちに尋ねた。「今日はなぜ、そんなに沈んだ顔をしているのですか。」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="ダニエル書 2:47; 創世記 41:15–16; ダニエル書 2:28"> 彼らは彼に言った。「私たちは夢を見たが、それを解き明かしてくれる人がいないのだ。」<br />ヨセフは彼らに言った。「解き明かしは神に属することではありませんか。どうか、私に話してください。」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="士師記 7:13–15; 創世記 37:5–10; ダニエル書 4:8"> 献酌官の長は自分の夢をヨセフに言った。「私の夢の中で、見よ、私の前に一本のぶどうの木があった。</span>
<span className="v" id="v10" data-v="10"> そのぶどうの木には三本の枝があった。それは芽を出し、花を咲かせ、房が熟してぶどうになったかのようだった。</span>
<span className="v" id="v11" data-v="11" data-xref="ネヘミヤ記 1:11–1; 列王記第一 10:5; 歴代誌 第二 9:4"> ファラオの杯が私の手にあったので、私はそのぶどうを取り、ファラオの杯の中に搾り、その杯をファラオの手に渡した。」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="創世記 41:12; 士師記 7:14; 創世記 41:25–26"> ヨセフは彼に言った。「その解き明かしはこうです。三本の枝は三日です。</span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 3:3; エレミヤ書 52:31; 列王記第二 25:27"> 今から三日以内に、ファラオはあなたの頭を上げ、あなたを元の地位に戻すでしょう。あなたは、以前に献酌官であったときのように、ファラオの手に杯を渡すようになります。</span>
<span className="v" id="v14" data-v="14" data-xref="ヨシュア記 2:12; ルカ 23:42; サムエル記第一 20:14–15"> しかし、あなたが幸いを得たときには、私のことを思い出し、どうか私に慈しみを示してください。私のことをファラオに話し、私をこの家から出してください。</span>
<span className="v" id="v15" data-v="15" data-xref="ペテロの手紙第一 3:17–18; 創世記 39:20; テモテへの手紙第一 1:10"> 実は、私はヘブライ人の地からさらわれて来ました。そしてここでも、私はこの穴に入れられるようなことは何もしていないのです。」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="創世記 40:1–2"> パン職人の長は、その解き明かしが良いのを見て、ヨセフに言った。「私も夢を見た。見よ、私の頭の上に白いパンの入った三つの籠があった。</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 49:20; 歴代誌上 12:20"> 一番上の籠には、ファラオのためのあらゆる種類の焼き菓子が入っていたが、鳥が私の頭の上の籠からそれらを食べていた。」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="創世記 40:12; 創世記 41:26; コリント人への第一の手紙 11:24"> ヨセフは答えた。「その解き明かしはこうです。三つの籠は三日です。</span>
<span className="v" id="v19" data-v="19" data-xref="創世記 40:22; 使徒の働き 20:27; サムエル記第二 21:6"> 今から三日以内に、ファラオはあなたの頭をあなたから取り去り、あなたを木に吊るすでしょう。そして鳥があなたの肉を食べるでしょう。」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="創世記 40:19; 創世記 40:13; マタイ 14:6"> 三日目はファラオの誕生日であり、彼はすべての家来たちのために宴会を催した。彼は家来たちの中で、献酌官の長の頭と、パン職人の長の頭を上げた。</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 40:13; ネヘミヤ記 2:1"> 彼は献酌官の長をその献酌の役職に戻し、献酌官はファラオの手に杯を渡した。</span>
<span className="v" id="v22" data-v="22" data-xref="創世記 40:19; 創世記 41:16; ダニエル書 2:30"> しかし、彼はパン職人の長を吊るした。ヨセフが彼らに解き明かしたとおりであった。</span>
<span className="v" id="v23" data-v="23" data-xref="詩篇 31:12; ヨブ記 19:14; 詩篇 105:19"> それでも、献酌官の長はヨセフのことを思い出さず、彼を忘れてしまった。</span>
</div>

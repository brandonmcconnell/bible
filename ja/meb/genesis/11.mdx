<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒の働き 2:6; ゼパニヤ書 3:9; イザヤ書 19:18"> 全地は一つの言葉、同じ言語を用いていた。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 10:10; ダニエル書 1:2; 創世記 14:1"> 人々が東へ移動したとき、<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="七十人訳は「東から」と読んでいる。">a</a></sup>彼らはシンアルの地に平野を見つけ、そこに住んだ。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 14:10; 出エジプト記 1:14; 出エジプト記 2:3"> 彼らは互いに言った。「さあ、れんがを作り、よく焼こう。」彼らは石の代わりにれんがを使い、漆喰の代わりに瀝青を使った。</span>
<span className="v" id="v4" data-v="4" data-xref="申命記 1:28; ヨハネ 5:44; ルカ 1:51"> 彼らは言った。「さあ、町と、頂が天に届く塔を自分たちのために建て、名を上げよう。全地の表に散らされないためだ。」</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="創世記 18:21; 詩篇 33:13–14; ヨハネ 3:13"> 主は、人の子らが建てた町と塔を見るために下って来られた。</span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 2:1–4; 創世記 3:22; 創世記 11:1"> 主は言われた。「見よ、彼らは一つの民であり、皆が一つの言語を持っている。そして、これが彼らのし始めたことである。今や、彼らが企てることで、彼らに不可能なことは何もないだろう。</span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 33:10; 詩篇 55:9; ヨブ記 5:12–13"> さあ、われわれは下って行き、そこで彼らの言語を混乱させ、互いの言葉を理解できないようにしよう。」</span>
<span className="v" id="v8" data-v="8" data-xref="ルカ 1:51; 申命記 32:8; 創世記 10:25"> こうして主は、彼らをそこから全地の表に散らされた。彼らは町を建てるのをやめた。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 10:10; 創世記 10:5; 創世記 10:20"> それゆえ、その名はバベルと呼ばれた。そこで主が全地の言語を混乱させたからである。そこから、主は彼らを全地の表に散らされた。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="歴代誌上 1:17–27; 創世記 10:21–22; ルカ 3:34–36"> これはセムの系図である。セムは百歳のとき、洪水の二年後にアルパクシャドの父となった。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 9:7; 詩篇 144:12; 創世記 1:28"> アルパクシャドの父となって後、セムは五百年生き、ほかにも息子や娘たちをもうけた。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="ルカ 3:36"> アルパクシャドは三十五年生きて、シェラの父となった。</span>
<span className="v" id="v13" data-v="13"> シェラの父となって後、アルパクシャドは四百三年生き、ほかにも息子や娘たちをもうけた。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14"> シェラは三十年生きて、エベルの父となった。</span>
<span className="v" id="v15" data-v="15"> エベルの父となって後、シェラは四百三年生き、ほかにも息子や娘たちをもうけた。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="創世記 10:21; 歴代誌上 1:19; 民数記 24:24"> エベルは三十四年生きて、ペレグの父となった。</span>
<span className="v" id="v17" data-v="17"> ペレグの父となって後、エベルは四百三十年生き、ほかにも息子や娘たちをもうけた。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="ルカ 3:35"> ペレグは三十年生きて、レウの父となった。</span>
<span className="v" id="v19" data-v="19"> レウの父となって後、ペレグは二百九年生き、ほかにも息子や娘たちをもうけた。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="ルカ 3:35"> レウは三十二年生きて、セルグの父となった。</span>
<span className="v" id="v21" data-v="21"> セルグの父となって後、レウは二百七年生き、ほかにも息子や娘たちをもうけた。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="ヨシュア記 24:2"> セルグは三十年生きて、ナホルの父となった。</span>
<span className="v" id="v23" data-v="23"> ナホルの父となって後、セルグは二百年生き、ほかにも息子や娘たちをもうけた。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="ルカ 3:34; ヨシュア記 24:2"> ナホルは二十九年生きて、テラの父となった。</span>
<span className="v" id="v25" data-v="25"> テラの父となって後、ナホルは百十九年生き、ほかにも息子や娘たちをもうけた。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="ヨシュア記 24:2; 歴代誌上 1:26–27; 創世記 22:20–24"> テラは七十年生きて、アブラム、ナホル、ハランの父となった。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="創世記 12:4; 創世記 14:12; 創世記 11:31"> これはテラの系図である。テラはアブラム、ナホル、ハランの父となった。ハランはロトの父となった。</span>
<span className="v" id="v28" data-v="28" data-xref="創世記 15:7; ネヘミヤ記 9:7; 使徒の働き 7:2–4"> ハランは父テラがまだ生きている間に、自分の生まれた地、カルデアのウルで死んだ。</span>
<span className="v" id="v29" data-v="29" data-xref="創世記 17:15; 創世記 22:20; 創世記 24:15"> アブラムとナホルは妻をめとった。アブラムの妻の名はサライ、ナホルの妻の名はミルカであった。ミルカはハランの娘であり、ハランはイスカの父でもあった。</span>
<span className="v" id="v30" data-v="30" data-xref="創世記 29:31; 創世記 21:1–2; ルカ 1:7"> サライは不妊で、子どもがいなかった。</span>
<span className="v" id="v31" data-v="31" data-xref="ネヘミヤ記 9:7; 使徒の働き 7:2–4; 創世記 24:10"> テラは、息子アブラムと、ハランの息子で自分の孫であるロトと、息子アブラムの妻で自分の嫁であるサライを連れて行った。彼らはカナンの地へ行くために、カルデアのウルを出発した。彼らはハランに着き、そこに住んだ。</span>
<span className="v" id="v32" data-v="32"> テラの生涯は二百五年であった。テラはハランで死んだ。</span>
</div>

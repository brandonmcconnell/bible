<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 46:4; 申命記 6:7–8; 使徒の働き 8:2"> ヨセフは父の顔の上に伏し、彼の上で泣いて、彼に口づけした。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 50:26; 歴代誌 第二 16:14; ヨハネ 19:39–40"> ヨセフは自分のしもべである医者たちに、父に防腐処理を施すように命じた。医者たちはイスラエルに防腐処理を施した。</span>
<span className="v" id="v3" data-v="3" data-xref="民数記 20:29; 申命記 34:8; 創世記 50:10"> 防腐処理にはそれだけの日数がかかるため、四十日が満ちた。エジプト人たちは彼のために七十日間泣いた。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="創世記 18:3; エステル記 4:2"> 喪の日々が過ぎると、ヨセフはファラオの家の者たちに言った。「もし私があなたがたのご好意を得ているなら、どうかファラオにこう取り次いでください。</span>
<span className="v" id="v5" data-v="5" data-xref="歴代誌 第二 16:14; イザヤ書 22:16; マタイ 27:60"> 『私の父は私に誓わせて言いました。「見よ、私は死のうとしている。私がカナンの地に自分のために掘った墓に、私を葬ってくれ。」ですから今、どうか私に上って行かせて、父を葬らせてください。そうすれば、私は戻って来ます。』」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="創世記 48:21"> ファラオは言った。「彼があなたに誓わせたとおりに上って行き、あなたの父を葬りなさい。」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="創世記 14:16"> ヨセフは父を葬るために上って行った。ファラオのすべての家来たち、ファラオの家の長老たち、エジプトの地のすべての長老たち、</span>
<span className="v" id="v8" data-v="8" data-xref="民数記 32:24–27; 出エジプト記 10:26; 出エジプト記 10:8–9"> そしてヨセフのすべての家、彼の兄弟たち、彼の父の家が彼と一緒に上って行った。ただ、彼らの幼い子どもたちと、羊の群れと牛の群れだけがゴシェンの地に残された。</span>
<span className="v" id="v9" data-v="9" data-xref="出エジプト記 14:28; 列王記第二 18:24; 雅歌 1:9"> 戦車と騎兵も彼と一緒に上って行った。それは非常に大きな一行であった。</span>
<span className="v" id="v10" data-v="10" data-xref="ヨブ記 2:13; 使徒の働き 8:2; サムエル記第二 1:17"> 彼らはヨルダン川の向こうにあるアタドの打ち場に来て、そこで非常に大きく激しい嘆きをもって悼んだ。ヨセフは父のために七日間、喪に服した。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 10:15–19; 創世記 24:6; 申命記 11:30"> その地の住民であるカナン人たちは、アタドの打ち場でのその喪を見て、「これはエジプト人による激しい喪だ」と言った。それゆえ、その名はアベル・ミツライム<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="アベル・ミツライムは「エジプトの嘆き」を意味する。">a</a></sup>と呼ばれた。それはヨルダン川の向こうにある。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="使徒の働き 7:16; 創世記 49:29–32; エペソ人への手紙 6:1"> 息子たちは、父から命じられたとおりに行った。</span>
<span className="v" id="v13" data-v="13" data-xref="創世記 49:29–31; 創世記 23:16–18; 使徒の働き 7:16"> すなわち、彼の息子たちは彼をカナンの地に運び、マクペラの畑の洞穴に彼を葬った。それは墓地の所有地として、アブラハムがマムレの前にある畑と一緒に、ヘト人エフロンから買い取ったものであった。</span>
<span className="v" id="v14" data-v="14"> ヨセフは父を葬った後、彼自身と彼の兄弟たち、そして父を葬るために彼と一緒に上って行ったすべての者たちと共に、エジプトへ戻った。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="箴言 28:1; 創世記 42:21–22; 詩篇 53:5"> ヨセフの兄弟たちは、父が死んだのを見て言った。「ヨセフは私たちを憎み、私たちが行ったすべての悪に、必ず仕返しするかもしれない。」</span>
<span className="v" id="v16" data-v="16" data-xref="箴言 29:25"> 彼らはヨセフに伝言を送った。「父は死ぬ前に、こう命じました。</span>
<span className="v" id="v17" data-v="17" data-xref="エペソ人への手紙 4:32; マタイ 6:14–15; 創世記 45:8"> 『ヨセフにこう言いなさい。「兄弟たちの背きと罪を、どうか赦してやってくれ。彼らはあなたに悪を行った。」』今、どうか、父の神に仕えるしもべたちの背きを赦してください。」この言葉を聞いて、ヨセフは泣いた。</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 37:7–11; 創世記 42:6; 創世記 45:3"> 彼の兄弟たちも行って、彼の前にひれ伏し、言った。「見よ、私たちはあなたのしもべです。」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="ローマ人への手紙 12:19; 創世記 45:5; 創世記 30:2"> ヨセフは彼らに言った。「恐れるな。私が神に代われるだろうか。</span>
<span className="v" id="v20" data-v="20" data-xref="ローマ人への手紙 8:28; 詩篇 119:71; 創世記 45:5–8"> あなたがたは私に悪を企んだ。だが神は、それを善のために計らわれた。今日のように、多くの民の命を救うためであった。</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 47:12; ペテロの手紙第一 3:9; 創世記 45:10–11"> だから今、恐れるな。私はあなたがたと幼い子どもたちを養おう。」彼は彼らを慰め、優しく語りかけた。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22"> ヨセフはエジプトに住んだ。彼と、彼の父の家もである。ヨセフは百十年生きた。</span>
<span className="v" id="v23" data-v="23" data-xref="民数記 32:39; 創世記 30:3; ヨブ記 42:16"> ヨセフはエフライムの子どもたちを三代まで見た。また、マナセの息子マキルの子どもたちも、ヨセフの膝の上で生まれた。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="出エジプト記 3:16–17; 創世記 35:12; 創世記 26:3"> ヨセフは兄弟たちに言った。「私は死のうとしている。しかし、神は必ずあなたがたを顧み、この地から、アブラハム、イサク、ヤコブに誓われた地へ、あなたがたを導き上ってくださる。」</span>
<span className="v" id="v25" data-v="25" data-xref="出エジプト記 13:19; ヨシュア記 24:32; 創世記 47:29–31"> ヨセフはイスラエルの子らに誓わせて、言った。「神は必ずあなたがたを顧みてくださる。あなたがたは私の骨をここから運び上らなければならない。」</span>
<span className="v" id="v26" data-v="26" data-xref="創世記 50:2–3; 創世記 47:9; ヨシュア記 24:29"> こうしてヨセフは百十歳で死んだ。彼らは彼に防腐処理を施し、彼はエジプトで棺に納められた。</span>
</div>
</div>

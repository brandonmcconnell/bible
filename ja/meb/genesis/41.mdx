<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 20:3; 創世記 29:14; 出エジプト記 4:9"> 丸二年が過ぎたころ、ファラオは夢を見た。見よ、彼はナイル川のほとりに立っていた。</span>
<span className="v" id="v2" data-v="2" data-xref="イザヤ書 19:6"> 見よ、ナイル川から見栄えが良く肉付きの良い七頭の雌牛が上がって来て、葦の中で草を食べていた。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 41:20–21; 創世記 41:4"> 見よ、その後から、見栄えが悪く痩せこけた別の七頭の雌牛がナイル川から上がって来て、川岸にいる他の雌牛たちのそばに立った。</span>
<span className="v" id="v4" data-v="4" data-xref="列王記第一 3:15"> 見栄えが悪く痩せこけた雌牛が、見栄えが良く肉付きの良い七頭の雌牛を食べてしまった。そこでファラオは目を覚ました。</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 32:14"> 彼は再び眠りにつき、二度目の夢を見た。見よ、一本の茎から、よく実って丸々とした七つの良い穂が出て来た。</span>
<span className="v" id="v6" data-v="6" data-xref="エゼキエル書 17:10; ホセア書 13:15; エゼキエル書 19:12"> 見よ、その後から、細くて東風に焼け焦げた七つの穂が出て来た。</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 37:5; 創世記 20:3"> 細い穂が、丸々と実った七つの穂を飲み込んだ。ファラオは目を覚ました。見よ、それは夢であった。</span>
<span className="v" id="v8" data-v="8" data-xref="ダニエル書 4:7; 出エジプト記 7:22; マタイ 2:1"> 朝になると、彼の心は騒いだ。彼は人を遣わして、エジプトのすべての魔術師とすべての知者たちを呼び寄せた。ファラオは彼らに自分の夢を話したが、ファラオのためにそれを解き明かせる者はいなかった。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="創世記 40:14; 創世記 40:23; 創世記 40:1–3"> その時、献酌官の長がファラオに言った。「今日、私は自分の過ちを思い出しました。</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 39:20; 創世記 40:2–3; 創世記 37:36"> かつてファラオは家来たちに怒り、私とパン職人の長を、護衛の長の家にある監獄へ入れられました。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 40:5–8"> 私と彼は同じ夜に夢を見ました。私たちは、それぞれ意味を持つ夢を見たのです。</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 40:12–19; 創世記 37:36; 創世記 39:1"> そこに、護衛の長のしもべであるヘブライ人の若者が、私たちと一緒にいました。私たちが彼に話すと、彼は私たちの夢を解き明かしてくれました。彼は、それぞれの夢にしたがって解き明かしてくれたのです。</span>
<span className="v" id="v13" data-v="13" data-xref="エゼキエル書 43:3; 創世記 40:20–22; 創世記 40:12"> そして、彼が解き明かしたとおりになりました。私は元の役職に戻され、パン職人の長は吊るされました。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="ダニエル書 2:25; 詩篇 113:7–8; 詩篇 105:19–22"> そこでファラオは人を遣わしてヨセフを呼んだ。人々は急いで彼を地下牢から連れ出した。ヨセフはひげをそり、衣を着替えて、ファラオの前に出た。</span>
<span className="v" id="v15" data-v="15" data-xref="ダニエル書 5:16; ダニエル書 5:12; 詩篇 25:14"> ファラオはヨセフに言った。「私は夢を見たが、それを解き明かせる者がいない。あなたについては、夢を聞いてそれを解き明かすことができると聞いた。」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="コリント人への第二の手紙 3:5; 創世記 40:8; ダニエル書 2:47"> ヨセフはファラオに答えた。「私の力ではありません。神がファラオに幸いな答えをお与えになります。」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17"> ファラオはヨセフに言った。「夢の中で、見よ、私はナイル川の岸に立っていた。</span>
<span className="v" id="v18" data-v="18" data-xref="エレミヤ書 24:8; エレミヤ書 24:1–3; エレミヤ書 24:5"> 見よ、ナイル川から肉付きが良く見栄えの良い七頭の雌牛が上がって来て、葦の中で草を食べていた。</span>
<span className="v" id="v19" data-v="19"> 見よ、その後から、弱々しく、非常に見栄えが悪く痩せこけた別の七頭の雌牛が上がって来た。私はエジプトの全土で、これほど見栄えの悪いものを見たことがない。</span>
<span className="v" id="v20" data-v="20"> 痩せて見栄えの悪い雌牛は、最初の丸々と太った七頭の雌牛を食べてしまった。</span>
<span className="v" id="v21" data-v="21" data-xref="エゼキエル書 3:3; 詩篇 37:19; ヨハネの黙示録 10:9–10"> それらを食べてしまっても、食べたことがわからないほど、初めと同じように見栄えが悪かった。そこで私は目を覚ました。</span>
<span className="v" id="v22" data-v="22"> 私はまた夢の中で見た。見よ、一本の茎から、丸々と実った七つの良い穂が出て来た。</span>
<span className="v" id="v23" data-v="23" data-xref="詩篇 129:6–7; ホセア書 13:15; 列王記第二 19:26"> 見よ、その後から、しなびて細く、東風に焼け焦げた七つの穂が出て来た。</span>
<span className="v" id="v24" data-v="24" data-xref="ダニエル書 4:7; 創世記 41:8; 出エジプト記 8:19"> 細い穂が、良い七つの穂を飲み込んでしまった。私はこれを魔術師たちに話したが、私に説明できる者はいなかった。」</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="ダニエル書 2:45; ヨハネの黙示録 4:1; エペソ人への手紙 1:17"> ヨセフはファラオに言った。「ファラオの夢は一つです。神がこれからなさることを、ファラオに告げられたのです。</span>
<span className="v" id="v26" data-v="26" data-xref="創世記 41:47; 創世記 41:2; 創世記 41:53"> 良い七頭の雌牛は七年であり、良い七つの穂も七年です。夢は一つです。</span>
<span className="v" id="v27" data-v="27" data-xref="列王記第二 8:1; サムエル記第二 24:19"> その後から上がって来た、痩せて見栄えの悪い七頭の雌牛も七年であり、東風に焼け焦げた、中身のない七つの穂もそうです。それは飢饉の七年となります。</span>
<span className="v" id="v28" data-v="28" data-xref="創世記 41:25; 創世記 41:16"> 私がファラオに申し上げたのは、このことです。神は、これからなさることをファラオにお示しになりました。</span>
<span className="v" id="v29" data-v="29" data-xref="創世記 41:26; 創世記 41:46–47; 創世記 41:49"> 見よ、エジプトの全土に、大豊作の七年が来ます。</span>
<span className="v" id="v30" data-v="30" data-xref="創世記 47:13; 創世記 41:54; ヤコブの手紙 5:17"> その後、飢饉の七年が続きます。エジプトの地では豊作がすべて忘れ去られ、飢饉がその地を食い尽くすでしょう。</span>
<span className="v" id="v31" data-v="31" data-xref="イザヤ書 24:20; サムエル記第一 5:6"> 後に続く飢饉があまりにも激しく、この地に豊作があったことさえわからなくなります。</span>
<span className="v" id="v32" data-v="32" data-xref="民数記 23:19; イザヤ書 46:10–11; イザヤ書 14:24–27"> 同じ夢がファラオに二度示されたのは、このことが神によって確定しており、神が速やかに実行されるしるしです。</span>
<span className="v" id="v33" data-v="33" data-xref="創世記 41:39; 使徒の働き 6:3; 申命記 1:13"> ですから今、ファラオは聡明で知恵のある人を選び、その人をエジプトの地の上にお立てください。</span>
<span className="v" id="v34" data-v="34" data-xref="箴言 22:3; ルカ 16:5; 箴言 6:6–8"> ファラオはこのように行い、国の上に監督官たちを任命し、豊作の七年の間にエジプトの地の収穫の五分の一を徴収させてください。</span>
<span className="v" id="v35" data-v="35" data-xref="創世記 45:6–7; 創世記 41:56; 出エジプト記 4:13"> これから来る豊作の年々に、すべての食料を集めさせ、ファラオの権威の下、町々に穀物を蓄えて保管させてください。</span>
<span className="v" id="v36" data-v="36" data-xref="創世記 47:13–25"> その食料は、エジプトの地に起こる飢饉の七年に備える、この国の蓄えとなります。そうすれば、この国が飢饉によって滅びることはありません。」</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="使徒の働き 7:10; 列王記第一 21:2; サムエル記第二 3:36"> この提案はファラオと、そのすべての家来たちの気に入った。</span>
<span className="v" id="v38" data-v="38" data-xref="ヨブ記 32:8; ダニエル書 5:14; 民数記 27:18"> ファラオは家来たちに言った。「神の霊の宿る、このような人をほかに見つけられるだろうか。」</span>
<span className="v" id="v39" data-v="39" data-xref="創世記 41:33; 創世記 41:28; 創世記 41:25"> ファラオはヨセフに言った。「神がこれらすべてをあなたに示されたのだから、あなたのように聡明で知恵のある者はいない。</span>
<span className="v" id="v40" data-v="40" data-xref="箴言 22:29; 使徒の働き 7:10; 詩篇 105:21–22"> あなたは私の家を治め、私のすべての民はあなたの言葉に従う。王座においてのみ、私はあなたより上に立つ。」</span>
<span className="v" id="v41" data-v="41" data-xref="マタイ 28:18; ピリピ人への手紙 2:9–11; 創世記 42:6"> ファラオはヨセフに言った。「見よ、私はあなたをエジプトの全土の上に置く。」</span>
<span className="v" id="v42" data-v="42" data-xref="ダニエル書 5:29; ダニエル書 5:7; エステル記 3:10"> ファラオは自分の手から指輪を外し、それをヨセフの手にはめ、上等の亜麻布の衣を着せ、彼の首に金の鎖をかけた。</span>
<span className="v" id="v43" data-v="43" data-xref="使徒の働き 7:10; 創世記 45:8; 創世記 45:26"> ファラオはヨセフを第二の戦車に乗せ、人々にその前で「ひざまずけ」と叫ばせた。こうして彼をエジプト全土の上に立てた。</span>
<span className="v" id="v44" data-v="44" data-xref="詩篇 105:22; 出エジプト記 11:7"> ファラオはヨセフに言った。「私はファラオである。だが、あなたの許しなしには、エジプト全土で誰も手も足も動かしてはならない。」</span>
<span className="v" id="v45" data-v="45" data-xref="創世記 46:20; エゼキエル書 30:17; 出エジプト記 2:16"> ファラオはヨセフの名をツァフェナテ・パネア<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="ツァフェナテ・パネアの意味は不確かである。">a</a></sup>と呼び、オンの祭司ポティ・フェラの娘アセナテを彼の妻として与えた。ヨセフはエジプトの地を巡回した。</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="ダニエル書 1:19; 列王記第一 12:6; サムエル記第一 16:21"> ヨセフがエジプトの王ファラオの前に立ったとき、彼は三十歳であった。ヨセフはファラオの前から出て行き、エジプトの全土を巡回した。</span>
<span className="v" id="v47" data-v="47" data-xref="創世記 26:12; 詩篇 72:16"> 豊作の七年の間、地は豊かに実った。</span>
<span className="v" id="v48" data-v="48" data-xref="創世記 41:34–36; 創世記 47:21"> 彼はエジプトの地にあった七年間のすべての食料を集め、その食料を町々に蓄えた。彼は各々の町の周囲の畑の食料を、その町の中に蓄えた。</span>
<span className="v" id="v49" data-v="49" data-xref="詩篇 78:27; 士師記 6:5; 創世記 22:17"> ヨセフは穀物を海の砂のように、非常に多く蓄えた。ついには数えきれなくなったので、数えるのをやめたほどであった。</span>
</div>
<div className="bp">
<span className="v" id="v50" data-v="50" data-xref="創世記 46:20; 創世記 48:5; サムエル記第二 8:18"> 飢饉の年が来る前に、ヨセフに二人の息子が生まれた。オンの祭司ポティ・フェラの娘アセナテが彼に産んだのである。</span>
<span className="v" id="v51" data-v="51" data-xref="詩篇 30:5; 箴言 31:7; 申命記 33:17"> ヨセフは長男をマナセ<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="マナセはヘブライ語の「忘れる」という言葉に似ている。">b</a></sup>と名付けた。「神が、私のすべての労苦と父の家を忘れさせてくださった」と言ったのである。</span>
<span className="v" id="v52" data-v="52" data-xref="創世記 49:22; 創世記 50:23; 創世記 17:6"> 次男をエフライム<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="エフライムはヘブライ語の「実を結ぶ」という言葉に似ている。">c</a></sup>と名付けた。「神が、私の苦しみの地で私を実り多い者としてくださった」と言ったのである。</span>
</div>
<div className="bp">
<span className="v" id="v53" data-v="53" data-xref="創世記 41:29–31; 詩篇 73:20; ルカ 16:25"> エジプトの地にあった豊作の七年が終わった。</span>
<span className="v" id="v54" data-v="54" data-xref="創世記 45:11; 使徒の働き 7:11; 詩篇 105:16"> ヨセフが言ったとおり、飢饉の七年が始まった。すべての国に飢饉があったが、エジプト全土には食物があった。</span>
<span className="v" id="v55" data-v="55" data-xref="マタイ 17:5; マタイ 3:17; エレミヤ書 14:1–6"> エジプト全土が飢えたとき、民はファラオに食物を求めて叫んだ。ファラオはすべてのエジプト人に言った。「ヨセフのところへ行け。彼が言うとおりにせよ。」</span>
<span className="v" id="v56" data-v="56" data-xref="創世記 42:6; ゼカリヤ書 5:3; ルカ 21:35"> 飢饉は全地を覆った。ヨセフはすべての穀物倉を開き、エジプト人に穀物を売った。飢饉はエジプトの地で激しかった。</span>
<span className="v" id="v57" data-v="57" data-xref="創世記 41:54; 創世記 42:5; 創世記 41:56"> 全世界の人々が、穀物を買うため、エジプトのヨセフのもとへ来た。全地で飢饉が激しかったからである。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 22:17; 歴代誌上 1:35; 申命記 23:7"> これはエサウ、すなわちエドムの系図である。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 36:25; 創世記 28:9; 創世記 9:25"> エサウはカナンの娘たちの中から妻をめとった。ヘト人エロンの娘アダ、ヒビ人ツィベオンの子アナの娘オホリバマ、</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 28:9; 創世記 25:13"> そしてイシュマエルの娘で、ネバヨトの妹であるバセマテである。</span>
<span className="v" id="v4" data-v="4" data-xref="歴代誌上 1:35; 出エジプト記 2:18; ヨブ記 2:11"> アダはエサウにエリファズを産み、バセマテはレウエルを産んだ。</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 35:29"> オホリバマはエウシュ、ヤラム、コラを産んだ。これらはカナンの地でエサウに生まれた息子たちである。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="創世記 32:3; 創世記 12:5; 創世記 17:8"> エサウは、妻たち、息子たち、娘たち、家のすべての人々、家畜、すべての獣、カナンの地で手に入れたすべての持ち物を携えて、弟ヤコブから離れた地へ行った。</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 13:6; 創世記 17:8; 創世記 28:4"> 彼らの財産が多すぎて一緒に住むことができず、彼らの家畜のゆえに、彼らが寄留していた地は彼らを支えきれなかったからである。</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 32:3; マラキ書 1:3; エゼキエル書 35:2–7"> エサウはセイルの山地に住んだ。エサウはエドムである。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="創世記 19:37"> セイルの山地に住むエドム人の父エサウの系図は次のとおりである。</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 36:3–4; 歴代誌上 1:35–54"> これらはエサウの息子たちの名である。エサウの妻アダの息子エリファズ、エサウの妻バセマテの息子レウエル。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 36:15–16; 歴代誌上 1:35–36"> エリファズの息子たちは、テマン、オマル、ツェフォ、ガタム、ケナズであった。</span>
<span className="v" id="v12" data-v="12" data-xref="出エジプト記 17:8–16; 申命記 25:17–19; サムエル記第一 15:2–9"> ティムナはエサウの息子エリファズのそばめであり、彼女はエリファズにアマレクを産んだ。これらはエサウの妻アダの子どもたちである。</span>
<span className="v" id="v13" data-v="13" data-xref="歴代誌上 1:37; 創世記 36:17"> これらはレウエルの息子たちである。ナハテ、ゼラ、シャンマ、ミザ。これらはエサウの妻バセマテの子どもたちであった。</span>
<span className="v" id="v14" data-v="14" data-xref="創世記 36:2; 創世記 36:18; 歴代誌上 1:35"> ツィベオンの子アナの娘である、エサウの妻オホリバマの息子たちは次のとおりである。彼女はエサウにエウシュ、ヤラム、コラを産んだ。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="オバデヤ書 1:9; ヨブ記 2:11; 創世記 36:11–12"> エサウの息子たちから出た首長たちは次のとおりである。エサウの長男エリファズの息子たちは、首長テマン、首長オマル、首長ツェフォ、首長ケナズ、</span>
<span className="v" id="v16" data-v="16" data-xref="出エジプト記 15:15"> 首長コラ、首長ガタム、首長アマレク。これらはエドムの地でエリファズから出た首長たちである。これらはアダの子どもたちである。</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 36:13; 歴代誌上 1:37; 創世記 36:4"> エサウの息子レウエルの息子たちは次のとおりである。首長ナハテ、首長ゼラ、首長シャンマ、首長ミザ。これらはエドムの地でレウエルから出た首長たちである。これらはエサウの妻バセマテの子どもたちである。</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 36:14; 歴代誌上 1:35; 創世記 36:5"> エサウの妻オホリバマの息子たちは次のとおりである。首長エウシュ、首長ヤラム、首長コラ。これらはエサウの妻であるアナの娘オホリバマから出た首長たちである。</span>
<span className="v" id="v19" data-v="19"> これらがエサウ、すなわちエドムの息子たちであり、これらが彼らの首長たちである。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="申命記 2:12; 申命記 2:22; 創世記 14:6"> その地に住んでいたホリ人セイルの息子たちは次のとおりである。ロタン、ショバル、ツィベオン、アナ、</span>
<span className="v" id="v21" data-v="21"> ディション、エツェル、ディシャン。これらはエドムの地でセイルの子どもたちであるホリ人から出た首長たちである。</span>
<span className="v" id="v22" data-v="22" data-xref="歴代誌上 1:39"> ロタンの子どもたちはホリとヘマムであった。ロタンの妹はティムナであった。</span>
<span className="v" id="v23" data-v="23" data-xref="歴代誌上 1:40"> これらはショバルの子どもたちである。アルワン、マナハテ、エバル、シェフォ、オナム。</span>
<span className="v" id="v24" data-v="24" data-xref="申命記 2:10; サムエル記第二 18:9; 列王記第一 4:28"> これらはツィベオンの子どもたちである。アヤとアナ。父ツィベオンのろばを飼っているときに、荒野で温泉<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="または「らば」。ヘブライ語の意味は不確かである。">a</a></sup>を見つけたのはこのアナである。</span>
<span className="v" id="v25" data-v="25" data-xref="創世記 36:2; 創世記 36:18; 歴代誌上 1:41"> これらはアナの子どもたちである。ディションと、アナの娘オホリバマ。</span>
<span className="v" id="v26" data-v="26" data-xref="歴代誌上 1:41"> これらはディションの子どもたちである。ヘムダン、エシュバン、イトラン、ケラン。</span>
<span className="v" id="v27" data-v="27" data-xref="歴代誌上 1:42; 創世記 36:21; 歴代誌上 1:38"> これらはエツェルの子どもたちである。ビルハン、ザアワン、アカン。</span>
<span className="v" id="v28" data-v="28" data-xref="哀歌 4:21; ヨブ記 1:1; エレミヤ書 25:20"> これらはディシャンの子どもたちである。ウツとアラン。</span>
<span className="v" id="v29" data-v="29" data-xref="創世記 36:20; 創世記 36:28; 歴代誌上 1:41–42"> これらはホリ人から出た首長たちである。首長ロタン、首長ショバル、首長ツィベオン、首長アナ、</span>
<span className="v" id="v30" data-v="30" data-xref="ダニエル書 7:23; イザヤ書 23:15; 列王記第二 11:19"> 首長ディション、首長エツェル、首長ディシャン。これらはセイルの地で、それぞれの首長にしたがう、ホリ人から出た首長たちである。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="創世記 17:6; 歴代誌上 1:43–50; 創世記 17:16"> イスラエルの子らを王が治める前に、エドムの地を治めていた王たちは次のとおりである。</span>
<span className="v" id="v32" data-v="32"> ベオルの息子ベラがエドムで王として治めた。彼の町の名はディンハバであった。</span>
<span className="v" id="v33" data-v="33" data-xref="エレミヤ書 49:13; エレミヤ書 49:22; アモス書 1:12"> ベラが死に、ボツラのゼラの息子ヨバブが彼に代わって王となった。</span>
<span className="v" id="v34" data-v="34" data-xref="創世記 36:11; ヨブ記 2:11; 創世記 36:15"> ヨバブが死に、テマン人の地のフシャムが彼に代わって王となった。</span>
<span className="v" id="v35" data-v="35"> フシャムが死に、モアブの野でミディアンを打ったベダデの息子ハダドが彼に代わって王となった。彼の町の名はアビテであった。</span>
<span className="v" id="v36" data-v="36" data-xref="歴代誌上 1:47"> ハダドが死に、マスレカのサムラが彼に代わって王となった。</span>
<span className="v" id="v37" data-v="37" data-xref="歴代誌上 1:48; 創世記 10:11"> サムラが死に、川のほとりのレホボトのシャウルが彼に代わって王となった。</span>
<span className="v" id="v38" data-v="38"> シャウルが死に、アクボルの息子バアル・ハナンが彼に代わって王となった。</span>
<span className="v" id="v39" data-v="39" data-xref="出エジプト記 15:15; 歴代誌上 1:50"> アクボルの息子バアル・ハナンが死に、ハダルが彼に代わって王となった。彼の町の名はパウであった。彼の妻の名はメヘタベルといい、メザハブの娘であるマトレドの娘であった。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="歴代誌上 1:51–54; 出エジプト記 15:15; 創世記 36:31"> エサウから出た首長たちの名は、それぞれの氏族、それぞれの場所、その名にしたがって次のとおりである。首長ティムナ、首長アルワ、首長エテテ、</span>
<span className="v" id="v41" data-v="41"> 首長オホリバマ、首長エラ、首長ピノン、</span>
<span className="v" id="v42" data-v="42"> 首長ケナズ、首長テマン、首長ミブツァル、</span>
<span className="v" id="v43" data-v="43" data-xref="創世記 45:8; 歴代誌上 4:14; 創世記 25:30"> 首長マグディエル、首長イラム。これらが、彼らの所有地にある住まいにしたがうエドムの首長たちである。これがエドム人の父エサウである。</span>
</div>

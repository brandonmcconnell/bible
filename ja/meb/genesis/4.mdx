<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨハネの手紙第一 3:12; 創世記 3:15; 創世記 4:25"> 人はその妻エバを知った<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="または「性的関係を持った」。">a</a></sup>。彼女は身ごもり<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="または「妊娠し」。">b</a></sup>、カインを産んで言った。「私は主によって一人の男を得た。」</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネの手紙第一 3:15; ヨハネの手紙第一 3:12; ルカ 11:51"> 彼女はまた、カインの弟アベルを産んだ。アベルは羊を飼う者となり、カインは土を耕す者となった。</span>
<span className="v" id="v3" data-v="3" data-xref="民数記 18:12; レビ記 2:1–11; 列王記第一 17:7"> 時が経って、カインは地の産物から主へのささげ物を持って来た。</span>
<span className="v" id="v4" data-v="4" data-xref="ヘブル人への手紙 11:4; 箴言 3:9; 出エジプト記 13:12"> アベルもまた、自分の羊の初子の中から、その肥えたものを持って来た。主はアベルとそのささげ物に目を留められたが、</span>
<span className="v" id="v5" data-v="5" data-xref="ヘブル人への手紙 11:4; ヨブ記 5:2; ルカ 15:28–30"> カインとそのささげ物には目を留められなかった。カインは非常に怒り、顔を伏せた。</span>
<span className="v" id="v6" data-v="6" data-xref="イザヤ書 1:18; ヨブ記 5:2; ルカ 15:31–32"> 主はカインに言われた。「なぜあなたは怒っているのか。なぜ顔を伏せているのか。</span>
<span className="v" id="v7" data-v="7" data-xref="ヤコブの手紙 1:15; ローマ人への手紙 2:6–10; イザヤ書 3:10–11"> もし正しいことをするなら、顔を上げられるではないか。正しいことをしないなら、罪が戸口で待ち伏せている。罪はあなたを慕い求める。だが、あなたはそれを治めなければならない。」</span>
<span className="v" id="v8" data-v="8" data-xref="マタイ 23:35; ヨハネの手紙第一 3:12–15; ユダ 1:11"> カインは弟アベルに言った。「野に行こう。」彼らが野にいたとき、カインは弟アベルに立ち向かい、彼を殺した。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="箴言 28:13; ヨハネ 8:44; 詩篇 9:12"> 主はカインに言われた。「あなたの弟アベルはどこにいるのか。」<br />彼は言った。「知りません。私は弟の番人でしょうか。」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="ヘブル人への手紙 12:24; 詩篇 72:14; ヘブル人への手紙 11:4"> 主は言われた。「あなたは何をしたのか。聞け。あなたの弟の血が、地からわたしに叫んでいる。</span>
<span className="v" id="v11" data-v="11" data-xref="ガラテヤ人への手紙 3:10; ヨブ記 16:18; 創世記 3:14"> 今、あなたは地から呪われる。地はその口を開けて、あなたの手から弟の血を受けた。</span>
<span className="v" id="v12" data-v="12" data-xref="ホセア書 9:17; レビ記 26:36; レビ記 26:20"> 今後、あなたが地を耕しても、地はもはやその力をあなたに与えない。あなたは地上をさまよい歩く逃亡者となる。」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="ヨブ記 15:22; ヨハネの黙示録 16:9; ヨハネの黙示録 16:11"> カインは主に言った。「私の罰は重すぎて、担いきれません。</span>
<span className="v" id="v14" data-v="14" data-xref="民数記 35:19; 詩篇 143:7; ヨブ記 15:20–24"> 見よ、あなたは今日、私をこの地の表から追い出されました。私はあなたの御前から隠され、地上をさまよい歩く逃亡者となります。私を見つける者は誰でも私を殺すでしょう。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="エゼキエル書 9:4; 詩篇 79:12; 創世記 4:24"> 主は彼に言われた。「それゆえ、カインを殺す者は誰でも、七倍の復讐を受ける。」主はカインに一つのしるしを付けられ、彼を見つける者が誰も彼を打ち殺すことのないようにされた。</span>
</div>
<div className="bp poetry">
<span className="v" id="v16" data-v="16" data-xref="エレミヤ書 23:39; ヨブ記 2:7; 創世記 4:14"> カインは主の前から去り、エデンの東、ノドの地に住んだ。</span>
<span className="v" id="v17" data-v="17" data-xref="詩篇 49:11; 伝道者の書 2:4–11; ダニエル書 4:30"> カインはその妻を知った。彼女は身ごもり、エノクを産んだ。カインは町を建て、その町を息子の名にちなんでエノクと名付けた。</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 36:2; 創世記 5:21"> エノクにはイラドが生まれた。イラドはメフヤエルの父となり、メフヤエルはメトシャエルの父となり、メトシャエルはレメクの父となった。</span>
<span className="v" id="v19" data-v="19" data-xref="創世記 2:24; マタイ 19:8; 創世記 2:18"> レメクは二人の妻をめとった。一人の名はアダ、もう一人の名はチラであった。</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 4:2; エレミヤ書 35:9–10; ヨハネ 8:44"> アダはヤバルを産んだ。彼は天幕に住む者たち、また家畜を飼う者たちの父となった。</span>
<span className="v" id="v21" data-v="21" data-xref="ヨブ記 21:12; イザヤ書 5:12; 創世記 31:27"> 彼の弟の名はユバルであった。彼は竪琴と笛を奏でるすべての者の父となった。</span>
<span className="v" id="v22" data-v="22" data-xref="申命記 33:25; 申命記 8:9; 歴代誌 第二 2:7"> チラもまた、トバル・カインを産んだ。彼は青銅と鉄のあらゆる刃物を鍛える者であった。トバル・カインの妹はナアマであった。</span>
<span className="v" id="v23" data-v="23" data-xref="民数記 23:18; 出エジプト記 20:13; レビ記 19:18"> レメクは妻たちに言った。<br /><span className="pl pl-1">「アダとチラよ、私の声を聞け。</span><br /><span className="pl pl-2">レメクの妻たちよ、私の言葉に耳を傾けよ。</span><br /><span className="pl pl-1">私は、私に傷を負わせた男を殺した。</span><br /><span className="pl pl-2">私を打った若者を殺した。</span></span>
<span className="v" id="v24" data-v="24" data-xref="マタイ 18:22; 創世記 4:15"> <span className="pl pl-1">カインのための復讐が七倍なら、</span><br /><span className="pl pl-2">レメクのためには七十七倍だ。」</span></span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="創世記 4:8; 創世記 4:10–11; 歴代誌上 1:1"> アダムは再びその妻を知った。彼女は男の子を産み、その子をセツと名付けて言った。「カインがアベルを殺したので、神がアベルに代わる別の子を授けてくださった。」</span>
<span className="v" id="v26" data-v="26" data-xref="詩篇 116:17; 列王記第一 18:24; ヨエル書 2:32"> セツにもまた男の子が生まれ、彼はその子をエノスと名付けた。その頃、人々は主の御名を呼び求め始めた。</span>
</div>

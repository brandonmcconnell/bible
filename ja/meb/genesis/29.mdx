<div className="bible-chapter" lang="ja" dir="ltr" data-lang="ja" data-translation="meb" data-translation-id="jpn_meb" data-translation-label="MEB" data-book="GEN" data-book-slug="genesis" data-book-name="創世記" data-chapter="29" data-verses="35">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士師記 6:3; 士師記 6:33; ホセア書 12:12"> ヤコブは旅を続け、東方の人々の地へ来た。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネ 4:14; イザヤ書 49:10; ヨハネ 4:6"> 彼が見ると、野に一つの井戸があり、見よ、そのそばに三つの羊の群れが伏していた。人々はその井戸から群れに水を飲ませていたからである。井戸の口にある石は大きかった。</span>
<span className="v" id="v3" data-v="3"> 群れがすべてそこに集められると、人々は井戸の口から石を転がし、羊に水を飲ませ、再び石を井戸の口の元の場所に戻すのであった。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="創世記 28:10; 創世記 27:43; 使徒の働き 7:2"> ヤコブは彼らに言った。「皆さん、どこから来たのですか。」<br />彼らは言った。「私たちはハランから来ました。」</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="創世記 24:24; 創世記 24:29; 創世記 31:53"> 彼は彼らに言った。「あなたがたはナホルの子ラバンを知っていますか。」<br />彼らは言った。「知っています。」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="サムエル記第二 20:9; 創世記 37:14; 出エジプト記 18:7"> 彼は彼らに言った。「彼は無事ですか。」<br />彼らは言った。「無事です。見なさい、彼の娘ラケルが羊と一緒に来ます。」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="エペソ人への手紙 5:16; ガラテヤ人への手紙 6:9–10"> 彼は言った。「見なさい、まだ日が高い。家畜を集める時間ではありません。羊に水を飲ませてから、行って草を食べさせなさい。」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="マルコ 16:3; ルカ 24:2; 創世記 34:14"> 彼らは言った。「すべての群れが集められ、人々が井戸の口から石を転がすまでは、そうすることができません。それから羊に水を飲ませるのです。」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="出エジプト記 2:21; 雅歌 1:7–8; 出エジプト記 2:15–16"> ヤコブがまだ彼らと話している間に、ラケルが父の羊と一緒にやって来た。彼女は羊を飼っていたからである。</span>
<span className="v" id="v10" data-v="10" data-xref="出エジプト記 2:17"> ヤコブは、母の兄ラバンの娘ラケルと、母の兄ラバンの羊を見ると、近づいて行って井戸の口から石を転がし、母の兄ラバンの群れに水を飲ませた。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 33:4; 創世記 45:14–15; 創世記 45:2"> ヤコブはラケルに口づけし、声を上げて泣いた。</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 24:28; 創世記 13:8; 創世記 14:14–16"> ヤコブはラケルに、自分が彼女の父の親族であり、リベカの息子であることを告げた。彼女は走って行き、父に告げた。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="創世記 24:29; 使徒の働き 20:37; ローマ人への手紙 16:16"> ラバンは妹の息子ヤコブの知らせを聞くと、ヤコブを迎えに走って行き、彼を抱きしめ、口づけして自分の家に連れて来た。ヤコブはこれらのすべてのことをラバンに話した。</span>
<span className="v" id="v14" data-v="14" data-xref="サムエル記第二 19:12–13; 創世記 2:23; 士師記 9:2"> ラバンは彼に言った。「まことに、あなたは私の骨、私の肉です。」ヤコブは一か月の間、彼のもとに滞在した。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="創世記 30:28; 創世記 31:7"> ラバンはヤコブに言った。「親族だからといって、ただで私に仕えるべきではない。どんな報酬を望むか、言ってください。」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="ルツ記 4:11; 創世記 49:31; 創世記 31:4"> ラバンには二人の娘がいた。姉の名はレア、妹の名はラケルであった。</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 12:11; 創世記 46:19–22; 創世記 24:16"> レアの目は弱かった<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="または「柔らかかった」。意味はやや不明である。">a</a></sup>が、ラケルは姿も顔立ちも美しかった。</span>
<span className="v" id="v18" data-v="18" data-xref="ホセア書 12:12; 出エジプト記 22:16–17; 創世記 34:12"> ヤコブはラケルを愛していた。彼は言った。「あなたの妹ラケルのために、私は七年間あなたに仕えましょう。」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="イザヤ書 6:11; イザヤ書 6:5; 詩篇 12:2"> ラバンは言った。「彼女をほかの男に与えるより、あなたに与えるほうが良い。私のところに留まりなさい。」</span>
<span className="v" id="v20" data-v="20" data-xref="コリント人への第一の手紙 13:7; エペソ人への手紙 5:2; ホセア書 12:12"> ヤコブはラケルのために七年間仕えた。彼女を愛していたため、彼にはそれがほんの数日のように思えた。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="士師記 15:1; 創世記 29:20; 創世記 4:1"> ヤコブはラバンに言った。「妻を与えてください。約束の期間が満ちました。彼女と結婚させてください。」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="ヨハネの黙示録 19:9; ルツ記 4:10–13; 士師記 14:10–18"> ラバンはその場所のすべての人々を集め、宴会を催した。</span>
<span className="v" id="v23" data-v="23" data-xref="ミカ書 7:5; 創世記 38:14–15; 創世記 24:65"> 夕方になると、ラバンは娘レアをヤコブのところに連れて来た。ヤコブは彼女のところに入った。</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 16:1; 創世記 30:9–12; 創世記 46:18"> ラバンは自分の女のしもべジルパを、娘レアの女のしもべとして与えた。</span>
<span className="v" id="v25" data-v="25" data-xref="マタイ 7:2; 箴言 11:31; コリント人への第一の手紙 3:13"> 朝になると、見よ、それはレアであった。ヤコブはラバンに言った。「あなたは私に何ということをしたのですか。私はラケルのためにあなたに仕えたのではありませんか。なぜ私を欺いたのですか。」</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26"> ラバンは言った。「私たちのところでは、長女より先に妹を嫁がせることはしません。</span>
<span className="v" id="v27" data-v="27" data-xref="レビ記 18:18; 士師記 14:12; 創世記 2:2–3"> この娘との婚礼の週を満たしなさい。そうすれば、あなたがさらに七年間私に仕えることと引き換えに、もう一人の娘もあなたに与えましょう。」</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28"> ヤコブはそのようにして、レアとの週を満たした。ラバンは自分の娘ラケルを彼の妻として与えた。</span>
<span className="v" id="v29" data-v="29" data-xref="創世記 35:22; 創世記 29:24; 創世記 30:3–8"> ラバンは娘ラケルに、自分の女のしもべビルハを、彼女の女のしもべとして与えた。</span>
<span className="v" id="v30" data-v="30" data-xref="創世記 31:41; 創世記 29:20; 創世記 31:15"> ヤコブはラケルのところにも入った。彼はレアよりもラケルを愛した。そしてさらに七年間、ラバンに仕えた。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="サムエル記第一 2:21; マタイ 10:37; 申命記 21:15"> 主はレアが疎まれているのを見られ、彼女の胎を開かれた。しかしラケルは不妊であった。</span>
<span className="v" id="v32" data-v="32" data-xref="申命記 26:7; 出エジプト記 4:31; 出エジプト記 3:7"> レアは身ごもって男の子を産み、その名をルベン<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="ルベンは「見よ、息子だ」を意味する。">b</a></sup>と名付けた。彼女は言った。「主が私の苦しみをご覧になった。今こそ夫は私を愛してくれるだろう。」</span>
<span className="v" id="v33" data-v="33" data-xref="創世記 34:25; 創世記 49:5–6; 創世記 34:30"> 彼女は再び身ごもって男の子を産み、言った。「私が疎まれているのを主が聞き、この子も授けてくださった。」彼女はその名をシメオン<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="シメオンは「聞くこと」を意味する。">c</a></sup>と名付けた。</span>
<span className="v" id="v34" data-v="34" data-xref="出エジプト記 32:26–29; 創世記 49:5–7; 創世記 46:11"> 彼女は再び身ごもって男の子を産んだ。そして言った。「今度こそ夫は私に結びついてくれるだろう。私は彼に三人の男の子を産んだのだから。」それゆえ、その名はレビ<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="レビは「結びつく」を意味する。">d</a></sup>と呼ばれた。</span>
<span className="v" id="v35" data-v="35" data-xref="マタイ 1:2; 歴代誌上 5:2; 創世記 49:8–12"> 彼女は再び身ごもって男の子を産み、言った。「今度こそ、私は主をほめたたえよう。」それゆえ、その名をユダ<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="ユダは「ほめたたえる」を意味する。">e</a></sup>と名付けた。それから彼女は出産をやめた。</span>
</div>
</div>

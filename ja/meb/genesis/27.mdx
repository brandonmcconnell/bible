<div className="bible-chapter" lang="ja" dir="ltr" data-lang="ja" data-translation="meb" data-translation-id="jpn_meb" data-translation-label="MEB" data-book="GEN" data-book-slug="genesis" data-book-name="創世記" data-chapter="27" data-verses="46">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="サムエル記第一 3:2; 創世記 48:10; 創世記 25:23–25"> イサクが年をとり、目がかすんで見えなくなったとき、彼は長男エサウを呼んで、「私の子よ」と言った。<br />エサウは答えた。「はい、ここにいます。」</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="ヤコブの手紙 4:14; 伝道者の書 9:10; 箴言 27:1"> 彼は言った。「見よ、私は年をとった。自分が死ぬ日を知らない。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 25:27–28; 創世記 10:9; コリント人への第一の手紙 6:12"> だから今、どうかあなたの武器である矢筒と弓を取り、野に出て行き、私のために獲物をしとめて来てくれ。</span>
<span className="v" id="v4" data-v="4" data-xref="ヘブル人への手紙 11:20; 創世記 48:9; 創世記 49:28"> 私の好きなおいしい料理を作り、私のところに持って来なさい。私がそれを食べ、死ぬ前にあなたを祝福するためだ。」</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5"> リベカは、イサクが息子エサウに話しているのを聞いていた。エサウは獲物をしとめて持って来るために、野へ出て行った。</span>
<span className="v" id="v6" data-v="6" data-xref="創世記 25:28"> リベカは息子ヤコブに言った。「私はあなたの父上が、あなたの兄エサウにこう話しているのを聞きました。</span>
<span className="v" id="v7" data-v="7" data-xref="ヨシュア記 6:26; サムエル記第一 24:19; 申命記 33:1"> 『私のために獲物を持って来て、おいしい料理を作り、食べさせてくれ。私は死ぬ前に、主の前でおまえを祝福したい』と。</span>
<span className="v" id="v8" data-v="8" data-xref="エペソ人への手紙 6:1; 創世記 27:13; 使徒の働き 5:29"> だから今、私の子よ、私があなたに命じるとおりに、私の声に聞き従いなさい。</span>
<span className="v" id="v9" data-v="9" data-xref="士師記 13:15; サムエル記第一 16:20"> 今すぐ羊の群れのところへ行き、良い子山羊を二匹取って来なさい。それで、父上の好むおいしい料理を作りましょう。</span>
<span className="v" id="v10" data-v="10"> それを父上に持って行き、食べていただきなさい。父上が死ぬ前に、あなたを祝福してくださるように。」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="創世記 25:25"> ヤコブは母リベカに言った。「兄エサウは毛深い人ですが、私は肌が滑らかな人です。</span>
<span className="v" id="v12" data-v="12" data-xref="申命記 27:18; 創世記 25:27; マラキ書 1:14"> もし父上が私に触れたら、私は欺く者と思われ、祝福ではなく呪いを招くことになります。」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="マタイ 27:25; サムエル記第一 25:24; サムエル記第二 14:9"> 母は彼に言った。「私の子よ、あなたの呪いは私が引き受けます。ただ私の声に聞き従い、行って、それらを取って来なさい。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="創世記 27:9; 箴言 23:2–3; 創世記 25:28"> 彼は行って、それらを取り、母のところに持って来た。母は彼の父が好きなおいしい料理を作った。</span>
<span className="v" id="v15" data-v="15" data-xref="創世記 27:27; ルカ 20:46; ルカ 15:22"> リベカは、家の中で自分の手元にあった長男エサウの上等の服を取り、それを次男ヤコブに着せた。</span>
<span className="v" id="v16" data-v="16"> 彼女は子山羊の毛皮を、彼の手と首の滑らかな部分に巻きつけた。</span>
<span className="v" id="v17" data-v="17"> そして彼女は、自分が作ったおいしい料理とパンを、息子ヤコブの手に渡した。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18"> 彼は父のところへ行き、「父上」と呼びかけた。<br />父は答えた。「ここにいる、わが子よ。おまえは誰だ。」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="イザヤ書 28:15; マタイ 26:70–74; ゼカリヤ書 13:3–4"> ヤコブは父に言った。「私は長男エサウです。お言いつけのとおりにしました。どうか起き上がって座り、私の獲物を召し上がって、私を祝福してください。」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="出エジプト記 20:7; ヨブ記 13:7; 創世記 24:12"> イサクは息子に言った。「私の子よ、どうしてこんなに早く見つけられたのか。」<br />彼は答えた。「あなたの神、主が、すぐに見つけさせてくださったのです。」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="ヤコブの手紙 4:8; イザヤ書 57:19; 創世記 27:12"> イサクはヤコブに言った。「私の子よ、どうか近くに来なさい。私があなたに触れて、あなたが本当に私の息子エサウかどうかを確かめよう。」</span>
<span className="v" id="v22" data-v="22"> ヤコブは父イサクに近づいた。イサクは彼に触れて言った。「声はヤコブの声だが、手はエサウの手だ。」</span>
<span className="v" id="v23" data-v="23" data-xref="創世記 27:16; ヘブル人への手紙 11:20; ローマ人への手紙 9:11–12"> ヤコブの手が兄エサウの手のように毛深かったので、イサクは彼を見分けられなかった。こうしてイサクは彼を祝福した。</span>
<span className="v" id="v24" data-v="24" data-xref="コロサイ人への手紙 3:9; エペソ人への手紙 4:25; 箴言 12:22"> 彼は言った。「あなたは本当に、私の息子エサウなのか。」<br />彼は言った。「そうです。」</span>
</div>
<div className="bp poetry">
<span className="v" id="v25" data-v="25" data-xref="創世記 27:4"> イサクは言った。「それを私の近くに持って来なさい。息子の獲物を食べて、あなたを祝福しよう。」ヤコブがそれを近くに持って行くと、彼は食べた。またヤコブがぶどう酒を持って行くと、彼は飲んだ。</span>
<span className="v" id="v26" data-v="26"> 父イサクは彼に言った。「私の子よ、さあ近くに来て、私に口づけしなさい。」</span>
<span className="v" id="v27" data-v="27" data-xref="ヘブル人への手紙 6:7; 詩篇 65:10; ヘブル人への手紙 11:20"> ヤコブは近づいて、彼に口づけした。イサクは彼の服の香りをかぎ、彼を祝福して言った。<br /><span className="pl pl-1">「見よ、私の息子の香りは、</span><br /><span className="pl pl-2">主が祝福された野の香りのようだ。</span></span>
<span className="v" id="v28" data-v="28" data-xref="申命記 33:28; 申命記 33:13; 詩篇 133:3"> <span className="pl pl-1">神があなたに、天の露と、</span><br /><span className="pl pl-2">地の豊かな産物を、</span><br /><span className="pl pl-2">豊かな穀物と新しいぶどう酒を与えてくださるように。</span></span>
<span className="v" id="v29" data-v="29" data-xref="創世記 12:3; 民数記 24:9; イザヤ書 49:23"> <span className="pl pl-1">民はあなたに仕え、</span><br /><span className="pl pl-2">国々はあなたにひれ伏せ。</span><br /><span className="pl pl-1">あなたの兄弟たちの主となれ。</span><br /><span className="pl pl-2">あなたの母の息子たちは、あなたにひれ伏せ。</span><br /><span className="pl pl-1">あなたを呪う者は呪われ、</span><br /><span className="pl pl-2">あなたを祝福する者は祝福されよ。」</span></span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30"> イサクがヤコブを祝福し終え、ヤコブが父イサクの前から出て行くとすぐに、兄エサウが狩りから帰って来た。</span>
<span className="v" id="v31" data-v="31" data-xref="創世記 27:4"> 彼もおいしい料理を作り、父のところに持って行った。そして言った。「父上、起き上がって、息子の獲物を召し上がり、私を祝福してください。」</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="創世記 27:18"> 父イサクは彼に言った。「お前は誰だ。」<br />彼は言った。「私はあなたの息子、あなたの長男エサウです。」</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="創世記 28:3–4; ローマ人への手紙 11:29; エペソ人への手紙 1:3"> イサクは激しく身震いして言った。「それでは、獲物をしとめて私のところに持って来たのは誰だったのか。お前が来る前に、私はそのすべてを食べ、彼を祝福してしまった。そうだ、彼は祝福されるだろう。」</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="ヘブル人への手紙 12:17; 箴言 1:31; サムエル記第一 30:4"> エサウは父の言葉を聞くと、激しく、苦々しい叫びを上げて言った。「父上、私も、この私も祝福してください。」</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="テサロニケ人への手紙第一 4:6; ヨブ記 13:7; マラキ書 2:10"> イサクは言った。「お前の弟が欺いてやって来て、お前の祝福を奪い取ってしまった。」</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="創世記 25:26; ヨハネ 1:47; 創世記 32:28"> エサウは言った。「ヤコブという名が彼にふさわしいのではありませんか。彼は二度も私を押しのけました。私の長子の権利を奪い、そして今度は私の祝福を奪い取りました。」彼はさらに言った。「私のために祝福を残しておかれなかったのですか。」</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="サムエル記第二 8:14; 創世記 27:28–29; 創世記 25:23"> イサクはエサウに答えた。「見よ、私は彼をお前の主とし、彼のすべての兄弟をしもべとして彼に与えた。穀物と新しいぶどう酒で彼を支えた。私の子よ、それでは、お前のために私に何ができようか。」</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="ヘブル人への手紙 12:17; 創世記 27:34; イザヤ書 65:14"> エサウは父に言った。「父上、祝福は一つしかないのですか。父上、私も、この私も祝福してください。」エサウは声を上げて泣いた。</span>
</div>
<div className="bp poetry">
<span className="v" id="v39" data-v="39" data-xref="創世記 27:28; ヘブル人への手紙 11:20; ヨシュア記 24:4"> 父イサクは彼に答えた。<br /><span className="pl pl-1">「見よ、あなたの住まいは、</span><br /><span className="pl pl-2">地の豊かな産物と、上なる天の露に恵まれるだろう。</span></span>
<span className="v" id="v40" data-v="40" data-xref="列王記第二 8:20–22; 創世記 25:23; 歴代誌 第二 25:11–12"> <span className="pl pl-1">あなたは自分の剣によって生き、</span><br /><span className="pl pl-2">あなたの弟に仕える。</span><br /><span className="pl pl-1">しかし、おまえがもがいて抜け出すとき、</span><br /><span className="pl pl-2">あなたは自分の首から彼のくびきを振り落とすだろう。」</span></span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="ヨハネの手紙第一 3:12–15; 創世記 37:4; 創世記 50:3–4"> 父がヤコブを祝福したその祝福のゆえに、エサウはヤコブを憎んだ。エサウは心の中で言った。「父のための喪の日が近づいている。そのとき、私は弟ヤコブを殺してやる。」</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="創世記 37:18–20; サムエル記第一 30:5; 創世記 42:21–22"> 長男エサウの言葉がリベカに伝えられた。彼女は人を遣わして次男ヤコブを呼び、彼に言った。「見なさい。あなたの兄エサウは、あなたを殺して恨みを晴らそうとしています。</span>
<span className="v" id="v43" data-v="43" data-xref="創世記 27:8; 創世記 11:31; 創世記 27:13"> だから今、私の子よ、私の声に聞き従いなさい。立ち上がり、ハランにいる私の兄ラバンのところへ逃げなさい。</span>
<span className="v" id="v44" data-v="44" data-xref="創世記 31:38; 創世記 31:41"> あなたの兄の激しい怒りが収まるまで、しばらくの間、彼と共に滞在しなさい。</span>
<span className="v" id="v45" data-v="45" data-xref="箴言 19:21; 創世記 4:8–16; 創世記 9:5–6"> 兄の怒りがあなたから離れ、あなたのしたことを忘れるまでです。そのとき、人を遣わして、あなたをそこから連れ戻します。どうして一日のうちに、あなたがた二人を失えましょう。」</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="創世記 24:3; 創世記 26:34–35; 創世記 28:8"> リベカはイサクに言った。「私はヘト人の娘たちのせいで、生きているのが嫌になりました。もしヤコブがこの地の娘たち、あのヘト人の娘たちのような者を妻にめとるなら、私の命に何の意味があるでしょうか。」</span>
</div>
</div>

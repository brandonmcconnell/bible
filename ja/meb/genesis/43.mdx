<div className="bible-chapter" lang="ja" dir="ltr" data-lang="ja" data-translation="meb" data-translation-id="jpn_meb" data-translation-label="MEB" data-book="GEN" data-book-slug="genesis" data-book-name="創世記" data-chapter="43" data-verses="34">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 12:10; 使徒の働き 7:11–13; 哀歌 5:10"> その地では飢饉が激しかった。</span>
<span className="v" id="v2" data-v="2" data-xref="テモテへの手紙第一 6:6–8; 箴言 16:18; 箴言 15:16"> 彼らがエジプトから持ち帰った穀物を食べ尽くしたとき、父は彼らに言った。「また行って、私たちのために少し食物を買って来なさい。」</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="創世記 44:23; 創世記 43:5; サムエル記第二 3:13"> ユダは彼に言った。「あの人は私たちに厳しく警告し、『弟が一緒でなければ、私の顔を見てはならない』と言いました。</span>
<span className="v" id="v4" data-v="4"> もしあなたが弟を私たちと一緒に遣わしてくださるなら、私たちは下って行って、あなたのために食物を買って来ます。</span>
<span className="v" id="v5" data-v="5" data-xref="出エジプト記 20:12; 創世記 44:26; 創世記 42:38"> しかし、もしあなたが彼を遣わさないなら、私たちは下って行きません。あの人が私たちに、『あなたがたの弟が一緒にいない限り、私の顔を見てはならない』と言ったからです。」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6"> イスラエルは言った。「なぜあなたがたは、もう一人弟がいるなどと言って、私にそんな悪いことをしたのか。」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="創世記 43:3; 創世記 42:13; 創世記 43:27"> 彼らは言った。「あの人が、私たちのことや私たちの親族について詳しく尋ね、『あなたがたの父はまだ生きているか。あなたがたにはもう一人兄弟がいるか』と言ったのです。私たちはただ、その質問に答えただけです。彼が『弟を連れて下って来い』と言うと、どうして知ることができたでしょうか。」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="創世記 42:2; 申命記 33:6; 創世記 45:19"> ユダは父イスラエルに言った。「あの子を私と一緒に遣わしてください。私たちは直ちに出発します。私たちも、あなたも、幼い子どもたちも、死なずに生き延びるためです。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 42:37; フィレモンへの手紙 1:18–19; ヘブル人への手紙 7:22"> 私が彼の保証人になります。私の手から彼を求めてください。もし私が彼をあなたのもとに連れ帰り、あなたの前に立たせなかったなら、私に一生その罪を負わせてください。</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 19:16"> これほどためらっていなければ、今頃は二度も往復できていたでしょう。」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="創世記 37:25; エレミヤ書 8:22; エゼキエル書 27:17"> 彼らの父イスラエルは彼らに言った。「どうしてもそうしなければならないのなら、こうしなさい。この地の最も良い産物を器に入れ、あの人への贈り物として持って下りなさい。少しの香油、少しの蜂蜜、香料、没薬、ピスタチオ、アーモンドだ。</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 42:25; 創世記 42:35; テサロニケ人への手紙第一 4:6"> 手には二倍の銀を持って行きなさい。袋の口に戻されていた銀も、手に持って帰りなさい。それは何かの間違いだったのかもしれない。</span>
<span className="v" id="v13" data-v="13" data-xref="創世記 42:38"> あなたがたの弟も連れて、立ち上がり、再びあの人のところへ行きなさい。</span>
<span className="v" id="v14" data-v="14" data-xref="エステル記 4:16; 創世記 17:1; 使徒の働き 21:14"> 全能の神が、あの人の前であなたがたにあわれみを与え、もう一人の兄弟とベニヤミンを返してくださるように。私が子を失うのなら、失うしかない。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15"> 彼らはその贈り物を取り、手に二倍の銀を持ち、ベニヤミンも連れた。彼らは立ち上がってエジプトへ下り、ヨセフの前に立った。</span>
<span className="v" id="v16" data-v="16" data-xref="創世記 44:1; 創世記 43:19; 創世記 24:2–10"> ヨセフは彼らと一緒にベニヤミンを見ると、自分の家の管理人に言った。「この人たちを家の中に連れて行き、動物を屠って準備しなさい。この人たちは昼に私と一緒に食事をするからだ。」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17"> その人はヨセフが命じたとおりに行い、人々をヨセフの家へ連れて行った。</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 42:35; ローマ人への手紙 7:8; 創世記 42:21"> 彼らはヨセフの家に連れて行かれたので恐れて、言った。「私たちが連れて来られたのは、最初に袋に戻されていた銀のためだ。私たちに言いがかりをつけて襲いかかり、私たちを奴隷にし、私たちのろばも奪うつもりなのだ。」</span>
<span className="v" id="v19" data-v="19"> 彼らはヨセフの家の管理人に近づき、家の戸口で彼に話しかけて、</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 42:3; 創世記 42:10; 創世記 42:27"> 言った。「ご主人様、私たちは確かに、最初は食物を買うために下って来たのです。</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 43:12; 創世記 42:27–35; ローマ人への手紙 13:8"> 私たちが宿泊所に着いて袋を開けると、見よ、各々の銀が袋の口にありました。私たちの銀が全額そのままありました。私たちはそれを手に持って再び来ました。</span>
<span className="v" id="v22" data-v="22"> また、食物を買うための別の銀も手に持って下って来ました。誰が私たちの銀を袋に入れたのか、私たちにはわかりません。」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="ヨハネ 20:26; 創世記 42:24; ヨハネ 14:27"> 彼は言った。「安心してください。恐れることはありません。あなたがたの神、父祖の神が、袋の中に宝を与えてくださったのです。銀は確かに私が受け取りました。」そして彼はシメオンを連れ出して来た。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="創世記 18:4; 創世記 24:32; ルカ 7:44"> その人は彼らをヨセフの家に入れ、水を与えたので、彼らは足を洗った。彼は彼らのろばに餌を与えた。</span>
<span className="v" id="v25" data-v="25" data-xref="創世記 43:11; 創世記 43:16"> 彼らは昼にヨセフが来るまでに、贈り物を準備した。彼らがそこで食事をすると聞いていたからである。</span>
<span className="v" id="v26" data-v="26" data-xref="ピリピ人への手紙 2:10–11; 創世記 27:29; 創世記 42:6"> ヨセフが家に帰って来ると、彼らは手にしていた贈り物を家の中にいる彼のもとに持って行き、地に向かって彼にお辞儀をした。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="創世記 42:13; サムエル記第一 25:5; サムエル記第一 17:22"> ヨセフは彼らの安否を尋ねた。「あなたがたが話していた年老いた父親は無事か。まだ生きているか。」</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="創世記 37:7; 創世記 43:26; サムエル記第二 14:4"> 彼らは言った。「あなたのしもべである私たちの父は無事です。まだ生きています。」彼らは頭を下げてお辞儀をした。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="創世記 42:13; 民数記 6:25; 創世記 30:22–24"> ヨセフは目を上げ、同じ母から生まれた弟ベニヤミンを見ると、言った。「これが、あなたがたの話していた末の弟か。」さらに言った。「わが子よ、神があなたを恵まれるように。」</span>
<span className="v" id="v30" data-v="30" data-xref="創世記 42:24; エレミヤ書 31:20; 列王記第一 3:26"> 弟への愛情が込み上げて来たため、ヨセフは急いで泣く場所を探した。彼は自分の部屋に入り、そこで泣いた。</span>
<span className="v" id="v31" data-v="31" data-xref="創世記 45:1; ペテロの手紙第一 3:10; イザヤ書 42:14"> 彼は顔を洗い、外に出て来た。そして自分を抑えて、「食事を出しなさい」と言った。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="創世記 46:34; 出エジプト記 8:26; 創世記 43:16"> 人々はヨセフに一席、兄弟たちに一席、また共に食べるエジプト人たちにも別の席を設けた。エジプト人はヘブライ人と食卓を共にしなかった。それは彼らにとって忌まわしいことだったからである。</span>
<span className="v" id="v33" data-v="33"> 兄弟たちはヨセフの前で、長男から末の弟まで年齢順に座らされたので、互いに驚いて顔を見合わせた。</span>
<span className="v" id="v34" data-v="34" data-xref="創世記 45:22; サムエル記第二 11:8; サムエル記第一 1:5"> ヨセフは自分の前から彼らに分け前を送ったが、ベニヤミンの分け前は彼らの誰の分け前よりも五倍も多かった。彼らは飲み、ヨセフと共に楽しんだ。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 28:13; 創世記 26:22–25; 創世記 28:10"> イスラエルは自分のすべての持ち物と共に旅立ち、ベエル・シェバに来て、父イサクの神にいけにえをささげた。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 15:1; ヨブ記 33:14–15; ヨブ記 4:13"> 神は夜の幻の中でイスラエルに語り、「ヤコブ、ヤコブ」と言われた。<br />彼は答えた。「ここにおります。」</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="創世記 12:2; 申命記 26:5; イザヤ書 43:1–2"> 神は言われた。「わたしは神、あなたの父の神である。エジプトへ下ることを恐れるな。そこで、わたしはあなたを大いなる民族とする。</span>
<span className="v" id="v4" data-v="4" data-xref="出エジプト記 3:8; 創世記 28:15; 創世記 48:21"> わたし自身があなたと共にエジプトへ下り、必ずあなたを再び連れ上る。ヨセフの手があなたの目を閉じる。」</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="創世記 45:21; 創世記 45:19; 創世記 45:27"> ヤコブはベエル・シェバから旅立った。イスラエルの子らは、自分たちの父ヤコブと、その幼い子どもたち、その妻たちを、彼を運ぶためにファラオが送った荷車に乗せた。</span>
<span className="v" id="v6" data-v="6" data-xref="ヨシュア記 24:4; イザヤ書 52:4; 使徒の働き 7:15"> 彼らは家畜と、カナンの地で得た財産を取り、エジプトへ来た。ヤコブと、彼と一緒にいたすべての子孫である。</span>
<span className="v" id="v7" data-v="7"> 息子たちと孫たち、娘たちと息子たちの娘たち、すなわちすべての子孫を、彼は共にエジプトへ連れて来た。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="出エジプト記 1:1–5; 申命記 33:6; 歴代誌上 2:1–55"> エジプトに来たイスラエルの子ら、ヤコブとその息子たちの名は次のとおりである。ヤコブの長男ルベン。</span>
<span className="v" id="v9" data-v="9"> ルベンの息子たちは、ハノク、パル、ヘツロン、カルミ。</span>
<span className="v" id="v10" data-v="10" data-xref="出エジプト記 6:15; 創世記 29:33; 創世記 28:1"> シメオンの息子たちは、エムエル、ヤミン、オハデ、ヤキン、ツォハル、そしてカナン人の女の息子シャウル。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 29:34; 歴代誌上 6:16; 民数記 8:1–26"> レビの息子たちは、ゲルション、ケハテ、メラリ。</span>
<span className="v" id="v12" data-v="12" data-xref="歴代誌上 4:21; 創世記 38:10; 創世記 29:35"> ユダの息子たちは、エル、オナン、シェラ、ペレツ、ゼラ。しかし、エルとオナンはカナンの地で死んだ。ペレツの息子たちはヘツロンとハムルであった。</span>
<span className="v" id="v13" data-v="13" data-xref="歴代誌上 12:32; 創世記 35:23; 創世記 30:14–18"> イッサカルの息子たちは、トラ、プワ、ヨブ、シムロン。</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 33:18–19; 民数記 26:26–27; 民数記 1:30–31"> ゼブルンの息子たちは、セレデ、エロン、ヤフレエル。</span>
<span className="v" id="v15" data-v="15" data-xref="創世記 29:32–35; 創世記 30:17–21; 創世記 34:1–31"> これらは、レアがパダン・アラムでヤコブに産んだ息子たちと、その娘ディナである。息子と娘は合わせて三十三人であった。</span>
<span className="v" id="v16" data-v="16" data-xref="民数記 26:15–17; 創世記 30:11; 民数記 1:24–25"> ガドの息子たちは、ツィフィオン、ハギ、シュニ、エツボン、エリ、アロディ、アレリ。</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 49:20; 創世記 30:13; 民数記 1:13"> アシェルの息子たちは、イムナ、イシュワ、イシュビ、ベリア、そして彼らの妹セラ。ベリアの息子たちは、ヘベルとマルキエル。</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 29:24; 創世記 35:26; 創世記 30:9–13"> これらはラバンが娘レアに与えたジルパの息子たちである。彼女はこれらをヤコブに産んだ。十六人であった。</span>
<span className="v" id="v19" data-v="19" data-xref="創世記 44:27; 創世記 29:18; 創世記 35:24"> ヤコブの妻ラケルの息子たちは、ヨセフとベニヤミン。</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 41:50–52; 創世記 41:45; 申命記 33:13–17"> エジプトの地で、ヨセフにはマナセとエフライムが生まれた。オンの祭司ポティ・フェラの娘アセナテが彼に産んだのである。</span>
<span className="v" id="v21" data-v="21" data-xref="歴代誌上 7:6–12; 歴代誌上 8:1–7; 民数記 26:38–40"> ベニヤミンの息子たちは、ベラ、ベケル、アシュベル、ゲラ、ナアマン、エヒ、ロシュ、ムピム、フピム、アルデ。</span>
<span className="v" id="v22" data-v="22"> これらはヤコブに生まれたラケルの息子たちである。合わせて十四人であった。</span>
<span className="v" id="v23" data-v="23" data-xref="民数記 1:38–39; 創世記 49:16–17; 民数記 1:12"> ダンの息子はフシム。</span>
<span className="v" id="v24" data-v="24" data-xref="歴代誌上 7:13; 民数記 1:42–43; 創世記 35:25"> ナフタリの息子たちは、ヤフツェエル、グニ、エツェル、シレム。</span>
<span className="v" id="v25" data-v="25" data-xref="創世記 29:29; 創世記 35:25; 創世記 30:3–8"> これらはラバンが娘ラケルに与えたビルハの息子たちであり、彼女はこれらをヤコブに産んだ。合わせて七人であった。</span>
<span className="v" id="v26" data-v="26" data-xref="出エジプト記 1:5; 創世記 35:11; 士師記 8:30"> ヤコブと一緒にエジプトに来た者、すなわち彼から直接出た子孫は、ヤコブの息子たちの妻を除いて、合わせて六十六人であった。</span>
<span className="v" id="v27" data-v="27" data-xref="申命記 10:22; 使徒の働き 7:14; 出エジプト記 1:5"> エジプトでヨセフに生まれた息子たちは二人であった。エジプトに来たヤコブの家の者は、合わせて七十人であった。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="創世記 45:10; 創世記 44:16–34; 創世記 49:8"> ヤコブは、ゴシェンへの道を整えさせるため、ユダを先にヨセフのもとへ遣わした。こうして彼らはゴシェンの地に着いた。</span>
<span className="v" id="v29" data-v="29" data-xref="ルカ 15:20; 創世記 45:14–15; 創世記 33:4"> ヨセフは戦車を整え、父イスラエルを迎えにゴシェンへ上った。父の前に姿を現すと、その首を抱き、長い間泣き続けた。</span>
<span className="v" id="v30" data-v="30" data-xref="ルカ 2:29–30; 創世記 45:28"> イスラエルはヨセフに言った。「おまえがまだ生きており、その顔を見ることができた。今はもう、死んでもよい。」</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="創世記 47:1–3; ヘブル人への手紙 2:11; 使徒の働き 18:3"> ヨセフは兄弟たちと、その父の家に言った。「私は上って行って、ファラオに話し、こう告げましょう。『カナンの地にいた私の兄弟たちと、私の父の家が私のところに来ました。</span>
<span className="v" id="v32" data-v="32" data-xref="創世記 47:3; 列王記第一 9:27; 列王記第一 18:5–6"> その人たちは羊飼いであり、家畜を飼う者たちです。彼らは羊の群れと牛の群れ、そしてすべての持ち物を持って来ました。』</span>
<span className="v" id="v33" data-v="33" data-xref="創世記 46:32; 創世記 47:2–4; ヨナ書 1:8"> ファラオがあなたがたを呼び、『あなたがたの職業は何か』と言われたときには、</span>
<span className="v" id="v34" data-v="34" data-xref="出エジプト記 8:26; 創世記 43:32; 創世記 46:32"> あなたがたは、『あなたのしもべたちは、若いころから今まで、私たちも私たちの先祖も家畜を飼う者です』と言いなさい。そうすれば、あなたがたはゴシェンの地に住むことができます。すべての羊飼いはエジプト人にとって忌み嫌われるものだからです。」</span>
</div>
</div>

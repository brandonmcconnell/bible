<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヘブル人への手紙 11:17; ヤコブの手紙 2:21; 申命記 8:2"> これらのことの後、神はアブラハムを試して、彼に言われた。「アブラハムよ。」<br />彼は言った。「ここにいる。」</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="ヨハネ 3:16; ローマ人への手紙 8:32; ヘブル人への手紙 11:17"> 神は言われた。「あなたの息子、あなたの愛するひとり子イサクを連れて、モリヤの地へ行きなさい。わたしがあなたに告げる山の一つで、彼を全焼のささげ物としてささげなさい。」</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="詩篇 119:60; マタイ 10:37; ルカ 14:26"> アブラハムは朝早く起き、ろばに鞍を置き、二人の若者と息子イサクを連れて行った。彼は全焼のささげ物のための薪を割り、立ち上がって、神が彼に告げられた場所へ向かった。</span>
<span className="v" id="v4" data-v="4" data-xref="ルカ 13:32; マタイ 17:23; ホセア書 6:2"> 三日目に、アブラハムは目を上げ、遠くにその場所を見た。</span>
<span className="v" id="v5" data-v="5" data-xref="ヘブル人への手紙 11:19; ヘブル人への手紙 12:1"> アブラハムは若者たちに言った。「ろばと一緒にここに留まっていなさい。私と少年はあそこへ行き、礼拝をしてから、あなたがたのところへ戻って来る。」</span>
<span className="v" id="v6" data-v="6" data-xref="ヨハネ 19:17; ペテロの手紙第一 2:24; イザヤ書 53:6"> アブラハムは全焼のささげ物のための薪を取り、息子イサクに負わせた。彼は自分の手に火と刃物を持った。二人は一緒に歩いて行った。</span>
<span className="v" id="v7" data-v="7" data-xref="ローマ人への手紙 8:15; マタイ 26:39; 創世記 8:20"> イサクは父アブラハムに呼びかけた。「父上。」<br />彼は答えた。「ここにいる、わが子よ。」<br />イサクは言った。「火と薪はありますが、全焼のささげ物のための小羊はどこにあるのですか。」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="ヨハネ 1:36; ヨハネ 1:29; ヨハネの黙示録 5:12"> アブラハムは言った。「わが子よ、神ご自身が全焼のささげ物のための小羊を備えてくださる。」こうして、二人は一緒に歩いて行った。</span>
<span className="v" id="v9" data-v="9" data-xref="ヤコブの手紙 2:21; ヘブル人への手紙 11:17–19; ピリピ人への手紙 2:7–8"> 彼らは神が彼に告げられた場所に着いた。アブラハムはそこに祭壇を築き、薪を並べ、息子イサクを縛り、祭壇の上の薪の上に彼を置いた。</span>
<span className="v" id="v10" data-v="10" data-xref="ヤコブの手紙 2:21–23; ヘブル人への手紙 11:17–19; イザヤ書 53:6–12"> アブラハムは手を伸ばし、息子を屠るために刃物を取った。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="創世記 21:17; 出エジプト記 3:4; 創世記 16:9–10"> 主の使いは天から彼を呼んで言った。「アブラハム、アブラハム。」<br />彼は言った。「ここにいる。」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="ヤコブの手紙 2:21–22; ヤコブの手紙 2:18; サムエル記第一 15:22"> 御使いは言った。「少年に手を下してはならない。彼に何もしてはならない。あなたが神を恐れる者であることが、今わかったからだ。あなたは自分の息子、自分のひとり子を、わたしに惜しまなかった。」</span>
<span className="v" id="v13" data-v="13" data-xref="コリント人への第一の手紙 10:13; 詩篇 40:6–8; コリント人への第二の手紙 1:9–10"> アブラハムが目を上げて見ると、後ろに一匹の雄羊がいて、角を茂みに引っ掛けていた。アブラハムは行ってその雄羊を取り、息子の代わりに全焼のささげ物としてささげた。</span>
<span className="v" id="v14" data-v="14" data-xref="創世記 22:13; 出エジプト記 17:15; 創世記 22:8"> アブラハムはその場所の名を「主は備えられる」<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="または「主は見ておられる」。">a</a></sup>と呼んだ。今日に至るまで、「主の山に備えがある」と言われている。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15"> 主の使いは再び天からアブラハムを呼んで、</span>
<span className="v" id="v16" data-v="16" data-xref="ヘブル人への手紙 6:13–14; ルカ 1:73; 詩篇 105:9"> 言った。「主はこう言われる。『わたしは自分自身にかけて誓った。あなたがこのことを行い、自分の息子、自分のひとり子を惜しまなかったので、</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 15:5; 創世記 24:60; エレミヤ書 33:22"> わたしは必ずあなたを祝福し、あなたの子孫を、天の星のように、海辺の砂のように大いに増し加える。あなたの子孫は敵の城門を勝ち取る。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒の働き 3:25; 創世記 12:3; ガラテヤ人への手紙 3:16"> 地上のすべての国々は、あなたの子孫によって祝福される。あなたがわたしの声に聞き従ったからである。』」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="創世記 21:31; 士師記 20:1; ヨシュア記 15:28"> こうしてアブラハムは若者たちのところに戻り、彼らは立ち上がって一緒にベエル・シェバへ行った。アブラハムはベエル・シェバに住んだ。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="創世記 11:29; 創世記 24:24; 箴言 25:25"> これらのことの後、アブラハムに知らせがあった。「見よ、ミルカもまた、あなたの兄弟ナホルに子どもたちを産みました。</span>
<span className="v" id="v21" data-v="21" data-xref="ヨブ記 1:1; ヨブ記 32:2; 詩篇 60:1–12"> 長子ウツ、その弟ブズ、アラムの父であるケムエル、</span>
<span className="v" id="v22" data-v="22"> ケセド、ハゾ、ピルダシュ、イデラフ、ベトエルです。」</span>
<span className="v" id="v23" data-v="23" data-xref="創世記 24:15; 創世記 28:5; 創世記 24:51"> ベトエルはリベカの父となった。これら八人を、ミルカはアブラハムの兄弟ナホルに産んだ。</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 16:3; 創世記 25:6; 箴言 15:25"> レウマという名の彼のそばめもまた、テバ、ガハム、タハシュ、マアカを産んだ。</span>
</div>

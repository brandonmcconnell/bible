<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 10:10; 創世記 10:22; イザヤ書 37:12"> シンアルの王アムラフェル、エルラサルの王アリオク、エラムの王ケドルラオメル、ゴイムの王ティダルの時代に、</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 13:10; 申命記 29:23; 創世記 10:19"> これらの王たちは、ソドムの王ベラ、ゴモラの王ビルシャ、アデマの王シナブ、ツェボイムの王シェメベル、そしてベラ、すなわちツォアルの王と戦った。</span>
<span className="v" id="v3" data-v="3" data-xref="ヨシュア記 3:16; 申命記 3:17; 民数記 34:12"> これらの王たちは皆、シディムの谷、すなわち塩の海に集まった。</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 9:25–26; エゼキエル書 17:15"> 彼らは十二年の間ケドルラオメルに仕えていたが、十三年目に反逆した。</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 3:11; 創世記 15:20; 申命記 1:4"> 十四年目に、ケドルラオメルと彼に味方した王たちが来て、アシュテロテ・カルナイムでレファイム人を、ハムでズジ人を、シャベ・キルヤタイムでエミム人を、</span>
<span className="v" id="v6" data-v="6" data-xref="申命記 2:22; 申命記 2:12; 創世記 21:21"> セイルの山地でホリ人を打ち、荒野の近くにあるエル・パランまで進んだ。</span>
<span className="v" id="v7" data-v="7" data-xref="歴代誌 第二 20:2; 創世記 16:14; 創世記 20:1"> 彼らは引き返してエン・ミシュパト、すなわちカデシュに来て、アマレク人の全土と、ハツァツォン・タマルに住むアモリ人を打った。</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 19:22; 創世記 13:10; 創世記 19:20"> そこでソドムの王、ゴモラの王、アデマの王、ツェボイムの王、ベラ、すなわちツォアルの王は出て行き、シディムの谷で陣を敷き、彼らに立ち向かった。</span>
<span className="v" id="v9" data-v="9"> すなわち、エラムの王ケドルラオメル、ゴイムの王ティダル、シンアルの王アムラフェル、エルラサルの王アリオクという四人の王が、五人の王と戦った。</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 19:17; 創世記 19:30; イザヤ書 24:18"> さて、シディムの谷には瀝青の穴がたくさんあった。ソドムとゴモラの王たちは逃げてそこに落ち、残りの者たちは山へ逃げた。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 14:21; 創世記 14:16; 申命記 28:31"> 敵はソドムとゴモラのすべての財産と、すべての食料を奪って去った。</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 12:5; 創世記 11:27; ヨハネの黙示録 3:19"> 彼らはまた、ソドムに住んでいたアブラムの親族ロトとその財産を奪って去った。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="創世記 13:18; 創世記 14:24; 創世記 40:15"> 逃れて来た一人の人が、ヘブライ人アブラムにこのことを告げた。その時、アブラムはアモリ人マムレの樫の木々のそばに住んでいた。マムレはエシュコルとアネルの兄弟であり、彼らはアブラムの同盟者であった。</span>
<span className="v" id="v14" data-v="14" data-xref="士師記 18:29; 創世記 15:3; 創世記 17:27"> アブラムは自分の親族が捕らえられたことを聞くと、自分の家で生まれた三百十八人の訓練された者たちを率いて、ダンまで追跡した。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒の働き 9:2; 詩篇 112:5; 列王記第一 15:18"> 夜になると、彼はしもべたちを分けて敵を襲い、彼らを打ち、ダマスコの北にあるホバまで追撃した。</span>
<span className="v" id="v16" data-v="16" data-xref="サムエル記第一 30:18–19; サムエル記第一 30:8; 創世記 12:2"> 彼はすべての財産を取り戻し、親族のロトとその財産、また女たちや人々も取り戻した。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="サムエル記第二 18:18; 箴言 19:4; ヘブル人への手紙 7:1"> アブラムがケドルラオメルと、彼に味方した王たちを打ち負かして帰って来たとき、ソドムの王はシャベの谷、すなわち王の谷まで彼を出迎えた。</span>
<span className="v" id="v18" data-v="18" data-xref="ヘブル人への手紙 6:20–3; 詩篇 110:4; ヘブル人への手紙 5:6"> サレムの王メルキゼデクはパンとぶどう酒を持って来た。彼はいと高き神の祭司であった。</span>
<span className="v" id="v19" data-v="19" data-xref="ヘブル人への手紙 7:6–7; 創世記 14:22; 詩篇 24:1"> 彼はアブラムを祝福して言った。「アブラムは、天と地を造られたいと高き神に祝福されよ。</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 28:22; ヘブル人への手紙 7:4–9; マラキ書 3:10"> あなたの敵をあなたの手に渡されたいと高き神は、ほめたたえられよ。」<br />アブラムはすべての物の十分の一を彼に与えた。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21"> ソドムの王はアブラムに言った。「人々は私に返し、財産はあなたのものとして取ってください。」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="ダニエル書 12:7; ダニエル書 4:34; 申命記 32:40"> アブラムはソドムの王に言った。「私は、いと高き神、天と地の所有者である主に、手を上げて誓いました。</span>
<span className="v" id="v23" data-v="23" data-xref="列王記第二 5:16; コリント人への第二の手紙 11:9–12; エステル記 9:15–16"> あなたのものは、糸一本、サンダルのひも一本さえ取りません。『私がアブラムを富ませた』と、あなたに言わせないためです。</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 14:13; 箴言 3:27; マタイ 7:12"> ただ、若者たちが食べたものと、私と一緒に行った人々、すなわちアネル、エシュコル、マムレの分け前は別です。彼らにはその分け前を取らせてください。」</span>
</div>

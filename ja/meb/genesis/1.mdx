<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨハネ 1:1–3; ヘブル人への手紙 11:3; イザヤ書 45:18"> 初めに、神<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「神」と訳されているヘブライ語は「אֱלֹהִים」（エロヒム）である。">a</a></sup>は天と地を創造された。</span>
<span className="v" id="v2" data-v="2" data-xref="エレミヤ書 4:23; 詩篇 104:30; イザヤ書 45:18"> 地は形なく、むなしく、闇が深淵の面を覆っていた。神の霊が水の面を舞っていた。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="コリント人への第二の手紙 4:6; ヨハネ 1:5; イザヤ書 45:7"> 神は言われた。「光があれ。」すると、光があった。</span>
<span className="v" id="v4" data-v="4" data-xref="伝道者の書 2:13; 創世記 1:18; 伝道者の書 11:7"> 神は光を見て、良しとされた。神は光と闇を分けられた。</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 74:16; イザヤ書 45:7; テサロニケ人への手紙第一 5:5"> 神は光を「昼」、闇を「夜」と呼ばれた。夕があり、朝があった。第一日。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="エレミヤ書 51:15; 詩篇 33:6; ヨブ記 37:18"> 神は言われた。「水の間に大空があれ。水と水を分けよ。」</span>
<span className="v" id="v7" data-v="7" data-xref="箴言 8:28–29; 詩篇 148:4; マタイ 8:27"> 神は大空を造り、大空の下の水と、大空の上の水とを分けられた。そのようになった。</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 1:5; 創世記 1:19; 創世記 1:10"> 神は大空を「天」と呼ばれた。夕があり、朝があった。第二日。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="ペテロの第二の手紙 3:5; ヨナ書 1:9; エレミヤ書 5:22"> 神は言われた。「天の下の水は一つの場所に集まれ。乾いた地が現れよ。」すると、そのようになった。</span>
<span className="v" id="v10" data-v="10" data-xref="申命記 32:4; 詩篇 104:31; 創世記 1:4"> 神は乾いた所を「地」、水の集まった所を「海」と呼ばれた。神はそれを見て、良しとされた。</span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 104:14–17; ヘブル人への手紙 6:7; 詩篇 147:8"> 神は言われた。「地は青草を生えさせよ。種を結ぶ草と、それぞれの種類にしたがって種のある実を結ぶ果樹を、地の上に生えさせよ。」すると、そのようになった。</span>
<span className="v" id="v12" data-v="12" data-xref="マルコ 4:28; イザヤ書 55:10–11; マタイ 13:24–26"> 地は青草、それぞれの種類にしたがって種を結ぶ草、またそれぞれの種類にしたがって種のある実を結ぶ木を生えさせた。神はそれを見て、良しとされた。</span>
<span className="v" id="v13" data-v="13"> 夕があり、朝があった。第三日。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="詩篇 104:19–20; 申命記 4:19; エレミヤ書 31:35"> 神は言われた。「天の大空に光るものがあれ。昼と夜を分け、それらは、しるし、季節、日、年のためのものとなれ。</span>
<span className="v" id="v15" data-v="15"> また、それらは天の大空で光るものとなり、地の上を照らせ。」すると、そのようになった。</span>
<span className="v" id="v16" data-v="16" data-xref="詩篇 136:7–9; 申命記 4:19; 詩篇 8:3"> 神は二つの大きな光るものを造られた。大きい方の光るものに昼を治めさせ、小さい方の光るものに夜を治めさせた。また、星々も造られた。</span>
<span className="v" id="v17" data-v="17" data-xref="詩篇 8:3; 詩篇 8:1; ヨブ記 38:12"> 神はそれらを天の大空に配置し、地の上を照らさせ、</span>
<span className="v" id="v18" data-v="18" data-xref="エレミヤ書 31:35; 詩篇 19:6"> 昼と夜を治めさせ、光と闇を分けさせた。神はそれを見て、良しとされた。</span>
<span className="v" id="v19" data-v="19"> 夕があり、朝があった。第四日。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="創世記 2:19; 詩篇 104:24–25; 列王記第一 4:33"> 神は言われた。「水は生き物の群れで満ちあふれよ。また、鳥は地の上、天の大空を飛べ。」</span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 104:24–26; 創世記 1:25; 創世記 8:19"> 神は大きな海の生き物と、水の中に群がり動くすべての生き物を、それぞれの種類にしたがって創造し、また翼のあるすべての鳥を、それぞれの種類にしたがって創造された。神はそれを見て、良しとされた。</span>
<span className="v" id="v22" data-v="22" data-xref="ヨブ記 40:15; 創世記 8:17; 詩篇 107:38"> 神はそれらを祝福して言われた。「生めよ。増えよ。海の水に満ちよ。また、鳥は地の上に増えよ。」</span>
<span className="v" id="v23" data-v="23"> 夕があり、朝があった。第五日。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="詩篇 50:9–10; 創世記 6:20; 創世記 8:19"> 神は言われた。「地は生き物を、それぞれの種類にしたがって生み出せ。家畜、這うもの、地の獣を、それぞれの種類にしたがって。」すると、そのようになった。</span>
<span className="v" id="v25" data-v="25" data-xref="エレミヤ書 27:5; ヨブ記 12:8–10; 創世記 2:19–20"> 神は地の獣をそれぞれの種類にしたがって、家畜をそれぞれの種類にしたがって、また地を這うすべてのものを、それぞれの種類にしたがって造られた。神はそれを見て、良しとされた。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="コロサイ人への手紙 3:10; エペソ人への手紙 4:24; 詩篇 8:4–8"> 神は言われた。「われわれのかたちに、われわれに似せて人を造ろう。海の魚、空の鳥、家畜、全地、地を這うすべてのものを、彼らに治めさせよう。」</span>
<span className="v" id="v27" data-v="27" data-xref="マタイ 19:4; エペソ人への手紙 2:10; 創世記 5:1–2"> 神はご自身のかたちに人を創造された。神のかたちにこれを創造し、男と女に彼らを創造された。</span>
<span className="v" id="v28" data-v="28" data-xref="創世記 9:1; 創世記 9:7; レビ記 26:9"> 神は彼らを祝福された。神は彼らに言われた。「生めよ。増えよ。地に満ちて、それを従えよ。海の魚、空の鳥、地の上を動くすべての生き物を治めよ。」</span>
<span className="v" id="v29" data-v="29" data-xref="創世記 9:3; 詩篇 104:14–15; 詩篇 145:15–16"> 神は言われた。「見よ、<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="「見よ」はヘブライ語「הִנֵּה」（ヒンネー）で、注意を促す表現である。">b</a></sup>わたしは、全地の表にある種を結ぶすべての草と、種のある実を結ぶすべての木をあなたがたに与えた。それがあなたがたの食物となる。</span>
<span className="v" id="v30" data-v="30" data-xref="詩篇 104:14; 詩篇 145:15–16; 詩篇 147:9"> また、地のすべての獣、空のすべての鳥、地を這うすべてのもの、すなわち命のあるすべてのものには、食物としてすべての青草を与えた。」すると、そのようになった。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="テモテへの手紙第一 4:4; 詩篇 104:24; 詩篇 19:1–2"> 神はご自分が造られたすべてのものを見られた。見よ、それは非常に良かった。夕があり、朝があった。第六日。</span>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="イザヤ書 41:10; 詩篇 119:114; 詩篇 84:11"> これらのことの後、幻の中で主の言葉がアブラムに臨んだ。「恐れるな、アブラム。わたしはあなたの盾。あなたの受ける報いは非常に大きい。」</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="創世記 25:21; 使徒の働き 7:5; 創世記 12:1–3"> アブラムは言った。「主なる神<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「主」と訳されている語は、ヘブライ語「אֲדֹנָי」（アドナイ）で、「主人、主」を意味する。">a</a></sup>よ、私に何をくださるというのですか。私には子どもがなく、私の家を継ぐ者はダマスコのエリエゼルです。」</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 14:14; 箴言 29:21; 伝道者の書 2:7"> アブラムは言った。「見よ、あなたは私に子どもを与えてくださいませんでした。見よ、私の家で生まれた者が私の跡継ぎとなるのです。」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="創世記 17:16; ガラテヤ人への手紙 4:28; サムエル記第二 7:12"> 見よ、主の言葉が彼に臨んだ。「その男はあなたの跡継ぎとはならない。あなた自身から生まれ出る者が、あなたの跡継ぎとなる。」</span>
<span className="v" id="v5" data-v="5" data-xref="ヘブル人への手紙 11:12; ローマ人への手紙 4:18; 申命記 1:10"> 主は彼を外に連れ出して言われた。「さあ、天を仰いで、星を数えなさい。もし数えることができるなら。」そして彼に言われた。「あなたの子孫もそのようになる。」</span>
<span className="v" id="v6" data-v="6" data-xref="ヤコブの手紙 2:23; ガラテヤ人への手紙 3:6–14; ローマ人への手紙 4:9"> アブラムは主を信じた。主はそれを彼に義と認められた。</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 12:1; 使徒の働き 7:2–4; ローマ人への手紙 4:13"> また彼に言われた。「わたしは、この地をあなたに与えて受け継がせるため、あなたをカルデアのウルから導き出した主である。」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="ルカ 1:18; ルカ 1:34; イザヤ書 7:11"> アブラムは言った。「主なる神よ、私がそれを受け継ぐことを、どのようにして知ることができるでしょうか。」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="ルカ 2:24; レビ記 14:30; レビ記 14:22"> 主は彼に言われた。「三歳の雌牛、三歳の雌山羊、三歳の雄羊、山鳩、そして家鳩のひなを、わたしのところに持って来なさい。」</span>
<span className="v" id="v10" data-v="10" data-xref="エレミヤ書 34:18–19; レビ記 1:17; 創世記 15:17"> 彼はこれらすべてを持って来て、真ん中から二つに切り裂き、それぞれの半分を互いに向かい合わせて置いた。しかし、鳥は切り裂かなかった。</span>
<span className="v" id="v11" data-v="11" data-xref="マタイ 13:4; 詩篇 119:13; エゼキエル書 17:3"> 猛禽が死肉の上に降りて来たが、アブラムはそれらを追い払った。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="創世記 2:21; ヨブ記 33:15; ダニエル書 10:8–9"> 日が沈みかけたころ、深い眠りがアブラムに下った。すると見よ、恐怖と大きな闇が彼を襲った。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒の働き 7:6–7; 出エジプト記 1:11; 出エジプト記 12:40–41"> 主はアブラムに言われた。「あなたは、このことを確かに知っておきなさい。あなたの子孫は、自分たちのものではない国で寄留者となり、その国の人々に仕える。彼らは四百年の間、あなたの子孫を苦しめる。</span>
<span className="v" id="v14" data-v="14" data-xref="ネヘミヤ記 9:9–11; 出エジプト記 6:5–6; 出エジプト記 12:32–38"> しかし、彼らが仕えるその民族を、わたしは裁く。その後、彼らは大きな財産を持って出て来る。</span>
<span className="v" id="v15" data-v="15" data-xref="ヨブ記 5:26; 創世記 25:7–9; 歴代誌 第二 34:28"> あなた自身は、平安のうちにあなたの先祖のところへ行き、長寿を全うして葬られる。</span>
<span className="v" id="v16" data-v="16" data-xref="列王記第一 21:26; ダニエル書 8:23; 出エジプト記 12:40"> そして四代目に、彼らはここに戻って来る。アモリ人の罪がまだ満ちていないからである。」</span>
<span className="v" id="v17" data-v="17" data-xref="エレミヤ書 34:18–19; 士師記 6:21; エレミヤ書 11:4"> 日が沈んで暗くなったとき、見よ、煙を吐く炉と燃えるたいまつが、これらの切り裂かれた動物の間を通り過ぎた。</span>
<span className="v" id="v18" data-v="18" data-xref="ヨシュア記 1:3–4; 創世記 12:7; 創世記 24:7"> その日、主はアブラムと契約を結んで言われた。「わたしはあなたの子孫に、エジプトの川からあの大河、ユーフラテス川までのこの地を与えた。</span>
<span className="v" id="v19" data-v="19" data-xref="民数記 24:21–22"> すなわち、ケニ人、ケナズ人、カデモニ人、</span>
<span className="v" id="v20" data-v="20" data-xref="イザヤ書 17:5; 創世記 14:5"> ヘト人、ペリジ人、レファイム人、</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 10:15–19; 出エジプト記 23:23–28; 申命記 7:1"> アモリ人、カナン人、ギルガシ人、そしてエブス人の地である。」</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 17:17"> サラの生涯は百二十七年であった。これがサラの生きた年数である。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 23:19; 創世記 13:18; 歴代誌上 6:57"> サラはカナンの地にあるキルヤト・アルバ、すなわちヘブロンで死んだ。アブラハムはサラのために悼み、泣くためにやって来た。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="創世記 10:15; 創世記 23:7; サムエル記第一 26:6"> アブラハムは亡き妻の前から立ち上がり、ヘトの人々に言った。</span>
<span className="v" id="v4" data-v="4" data-xref="歴代誌上 29:15; ヘブル人への手紙 11:9; 創世記 17:8"> 「私はあなたがたの間に住む寄留者です。亡き妻を葬るため、あなたがたの土地の中に墓地を所有させてください。」</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5"> ヘトの人々はアブラハムに答えた。</span>
<span className="v" id="v6" data-v="6" data-xref="創世記 24:35; 創世記 14:14; 出エジプト記 32:22"> 「ご主人様、私たちの言うことをお聞きください。あなたは私たちの間で、神に立てられた尊い方です。私たちの最も良い墓に、亡き方をお葬りください。自分の墓をあなたにお断りする者は、私たちの中には一人もいません。」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="ヘブル人への手紙 12:14; 創世記 19:1; 箴言 18:24"> アブラハムは立ち上がり、その地の人々、すなわちヘトの人々に向かってお辞儀をした。</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 25:9; ヨハネの手紙第一 2:1–2; 列王記第一 2:17"> 彼は彼らに言った。「私が亡き妻を葬ることを認めてくださるなら、どうか私の願いを聞き、ツォハルの子エフロンに頼んでください。</span>
<span className="v" id="v9" data-v="9" data-xref="ローマ人への手紙 13:8; ローマ人への手紙 12:17"> 彼が所有している、彼の畑の端にあるマクペラの洞穴を私に譲ってくれるように。十分な代価で、あなたがたの間で、墓地の所有地として私に譲ってくれるように。」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="創世記 34:20; 創世記 34:24; 創世記 23:18"> その時、エフロンはヘトの人々の中に座っていた。ヘト人エフロンは、ヘトの人々、すなわち彼の町の門を出入りするすべての人々が聞いているところで、アブラハムに答えた。</span>
<span className="v" id="v11" data-v="11" data-xref="ルカ 19:24; イザヤ書 32:8; 申命記 19:15"> 「いいえ、ご主人様。私の言うことを聞いてください。その畑はあなたに差し上げます。その中にある洞穴もあなたに差し上げます。私の民の人々の前で、それをあなたに差し上げます。あなたの死者を葬ってください。」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="創世記 23:7; 創世記 18:2; 創世記 19:1"> アブラハムはその地の人々の前でお辞儀をした。</span>
<span className="v" id="v13" data-v="13" data-xref="ローマ人への手紙 13:8; サムエル記第二 24:24; 創世記 14:22–23"> 彼はその地の人々が聞いているところで、エフロンに言った。「どうか私の願いを聞いてください。畑の代価をお支払いします。受け取ってください。そうすれば、私はそこに亡き妻を葬れます。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14"> エフロンはアブラハムに答えた。</span>
<span className="v" id="v15" data-v="15" data-xref="エゼキエル書 45:12; 出エジプト記 30:13; 出エジプト記 30:15"> 「ご主人様、私の言うことをお聞きください。銀四百シェケル<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一シェケルは約10グラムで、四百シェケルは約4キログラム、すなわち約8.8ポンドである。">a</a></sup>の土地が、私とあなたの間で何ほどのことでしょう。亡き方をお葬りください。」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="ゼカリヤ書 11:12; エレミヤ書 32:9; 出エジプト記 30:13"> アブラハムはエフロンの言うことを聞いた。アブラハムは、ヘトの人々が聞いているところでエフロンが口にした銀、すなわち商人の間で通用する重さにしたがって、四百シェケルの銀を量り、エフロンに渡した。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="創世記 25:9; 創世記 50:13; 創世記 23:20"> こうして、マムレの前にあるマクペラにあったエフロンの畑、すなわちその畑とその中にあった洞穴、そしてその畑のすべての境界内にあるすべての木々は、</span>
<span className="v" id="v18" data-v="18" data-xref="ルツ記 4:1; エレミヤ書 32:12; 創世記 34:20"> ヘトの人々の前で、彼の町の門を出入りするすべての人々の前で、アブラハムの所有地として確定された。</span>
<span className="v" id="v19" data-v="19" data-xref="創世記 50:13; 伝道者の書 12:7; 伝道者の書 12:5"> その後、アブラハムはカナンの地にあるマムレ、すなわちヘブロンの前にあるマクペラの畑の洞穴に、妻サラを葬った。</span>
<span className="v" id="v20" data-v="20" data-xref="エレミヤ書 32:10–14; ルツ記 4:7–10; 創世記 49:31–32"> その畑とそこにある洞穴は、ヘトの人々によって、墓地の所有地としてアブラハムのものとされた。</span>
</div>
</div>

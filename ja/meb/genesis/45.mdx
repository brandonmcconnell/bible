<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マタイ 18:15; 使徒の働き 10:41; 創世記 43:30–31"> そのとき、ヨセフは自分の前に立っているすべての人の前で、自分を抑えることができなくなり、「すべての人を私の前から出しなさい」と叫んだ。ヨセフが兄弟たちに自分を明かしたとき、ほかの誰も彼と一緒に立っていなかった。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 46:29; 使徒の働き 20:37; 民数記 14:1"> 彼は声を上げて泣いた。エジプト人たちはそれを聞き、ファラオの家もそれを聞いた。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒の働き 7:13; 使徒の働き 9:5; ゼカリヤ書 12:10"> ヨセフは兄弟たちに言った。「私はヨセフだ。父はまだ生きているか。」<br />兄弟たちは彼に答えることができなかった。彼の前でおびえていたからである。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="創世記 37:28; マタイ 14:27; 創世記 50:18"> ヨセフは兄弟たちに言った。「どうか、私に近づいてください。」<br />彼らが近づくと、彼は言った。「私は、あなたがたがエジプトに売った、弟のヨセフだ。</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 50:20; 使徒の働き 7:9–15; 創世記 45:7–8"> だが今、私をここへ売ったことで心を痛めたり、自分を責めたりしないでください。命を救うため、神があなたがたより先に私を遣わされたのです。</span>
<span className="v" id="v6" data-v="6" data-xref="創世記 47:23; 創世記 41:54; 創世記 41:56"> この二年間、この地に飢饉がありました。そしてまだ五年、耕すことも刈り入れることもない年があります。</span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 44:4; 使徒の働き 7:35; 詩篇 18:50"> 神は、あなたがたのために地上に残りの者を保ち、大いなる救いによってあなたがたの命を残すため、私を先に遣わされたのです。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨハネ 15:16; ローマ人への手紙 9:16; ヨハネ 19:11"> だから、私をここへ遣わしたのはあなたがたではなく、神なのです。神は私をファラオの父、その全家の主、エジプト全土の統治者とされました。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 45:19–20; 創世記 45:13"> 急いで父のところへ上り、告げてください。『あなたの息子ヨセフがこう申します。「神は私をエジプト全土の主とされました。ためらわず、私のところへ下って来てください。</span>
<span className="v" id="v10" data-v="10" data-xref="出エジプト記 9:26; 出エジプト記 8:22; 創世記 46:34–6"> あなたはゴシェンの地に住むことになります。あなたも、子どもたちも、孫たちも、羊の群れも、牛の群れも、あなたのすべての持ち物も、私の近くにいることになります。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 47:12; 創世記 47:6; マタイ 15:5–6"> そこで私があなたを養いましょう。飢饉はなお五年続きます。あなたも家族も、持ち物も、窮乏することのないように。」』</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 42:23; ルカ 24:39; ヨハネ 20:27"> 見よ、あなたがたも弟ベニヤミンも、語っているのがほかならぬ私であると、その目で見ています。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒の働き 7:14; ヨハネの黙示録 21:23; ペテロの手紙第一 1:10–12"> エジプトでの私の栄誉と、ここで見たすべてのことを父に告げ、急いで父をここへ連れて下って来てください。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="創世記 33:4; 創世記 29:11; 創世記 46:29"> ヨセフは弟ベニヤミンの首を抱いて泣き、ベニヤミンも彼の首を抱いて泣いた。</span>
<span className="v" id="v15" data-v="15" data-xref="ルカ 15:20; サムエル記第一 10:1; 詩篇 77:4"> 彼はすべての兄弟たちに口づけし、彼らを抱いて泣いた。その後、兄弟たちは彼と語り合った。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="創世記 41:33; エステル記 1:21; 創世記 20:15"> 「ヨセフの兄弟たちが来た」との知らせがファラオの家に届いた。ファラオも家来たちも喜んだ。</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 42:25–26; 創世記 44:1–2"> ファラオはヨセフに言った。「あなたの兄弟たちに言いなさい。『このようにしなさい。あなたがたの家畜に荷を積み、カナンの地へ行きなさい。</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 27:28; 民数記 18:12; 創世記 47:6"> あなたがたの父と家族を連れて、私のところへ来なさい。私はあなたがたにエジプトの地の良いものを与え、あなたがたはその地の最良のものを食べるだろう。』</span>
<span className="v" id="v19" data-v="19" data-xref="創世記 46:5; 創世記 45:27; 創世記 31:17–18"> また、あなたはこのように命じなさい。『あなたがたの幼い子どもたちと妻たちのために、エジプトの地から荷車を取り、あなたがたの父を乗せて来なさい。</span>
<span className="v" id="v20" data-v="20" data-xref="イザヤ書 1:19; ルカ 17:31; 申命記 7:16"> 持ち物を惜しむ必要はない。エジプト全土の最良のものが、あなたがたのものとなる。』」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="創世記 45:19; エゼキエル書 23:24; 哀歌 1:18"> イスラエルの子らはそのようにした。ヨセフはファラオの命令にしたがって彼らに荷車を与え、道中のための食料を与えた。</span>
<span className="v" id="v22" data-v="22" data-xref="創世記 43:34; 列王記第二 5:5; 士師記 14:12"> 彼ら全員に、それぞれ着替えの衣を一着ずつ与えた。ベニヤミンには銀三百枚と着替えの衣五着を与えた。</span>
<span className="v" id="v23" data-v="23" data-xref="創世記 24:10; 出エジプト記 16:3; 創世記 43:11"> 彼は父のために次のものを送った。エジプトの良いものを積んだ十頭のろば、父の道中のために穀物とパンと食料を積んだ十頭の雌ろばである。</span>
<span className="v" id="v24" data-v="24" data-xref="テサロニケ人への手紙第一 5:13; 詩篇 133:1–3; 創世記 42:21–22"> こうしてヨセフは兄弟たちを送り出し、彼らは旅立った。ヨセフは彼らに「途中で言い争わないように」と言った。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25"> 彼らはエジプトから上って行き、カナンの地にある彼らの父ヤコブのところへ来た。</span>
<span className="v" id="v26" data-v="26" data-xref="創世記 44:28; 創世記 37:35; ルカ 24:34"> 彼らは父に、「ヨセフはまだ生きています。しかも、エジプト全土を治めています」と告げた。だがヤコブの心は凍りついた。彼らを信じられなかったのである。</span>
<span className="v" id="v27" data-v="27" data-xref="詩篇 85:6; イザヤ書 57:15; 創世記 45:19"> 彼らはヨセフが語ったすべての言葉を父に伝えた。ヨセフが父を迎えるために送った荷車を見ると、父ヤコブの霊はよみがえった。</span>
<span className="v" id="v28" data-v="28" data-xref="ルカ 2:28–30; ヨハネ 16:21–22; 創世記 46:30"> イスラエルは言った。「もう十分だ。息子ヨセフはまだ生きている。死ぬ前に、行って会おう。」</span>
</div>
</div>

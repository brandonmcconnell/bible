<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 26:1; 創世記 26:6; 創世記 18:1"> アブラハムはそこからネゲブ地方へ向かって旅をし、カデシュとシュルの間に住んだ。彼はゲラルに寄留した。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 12:15; 創世記 26:7; 創世記 12:11–13"> アブラハムは妻サラのことを、「彼女は私の妹です」と言った。ゲラルの王アビメレクは人を遣わし、サラを召し入れた。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 20:7; マタイ 27:19; 詩篇 105:14"> しかし夜の夢の中で、神はアビメレクのところに来て言われた。「見よ、あなたが召し入れた女のゆえに、あなたは死ぬ。彼女は夫のある女だからである。」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="創世記 18:23–25; 歴代誌上 21:17; サムエル記第二 4:11"> アビメレクはまだ彼女に近づいていなかった。彼は言った。「主よ、あなたは正しい民までも殺されるのですか。</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 7:8; 列王記第一 9:4; ダニエル書 6:22"> 彼自身が私に『彼女は私の妹です』と言ったではありませんか。彼女もまた『彼は私の兄です』と言いました。私は全き心と潔白な手でこのことをしました。」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="サムエル記第一 25:34; 箴言 21:1; サムエル記第一 25:26"> 神は夢の中で彼に言われた。「そうだ。あなたが全き心でこのことをしたのを、わたしも知っている。わたしもまた、あなたがわたしに対して罪を犯さないように、あなたを引き止めていた。それゆえ、わたしはあなたが彼女に触れるのを許さなかった。</span>
<span className="v" id="v7" data-v="7" data-xref="ヨブ記 42:8; サムエル記第一 7:5; サムエル記第二 24:17"> だから今、あの男の妻を返しなさい。彼は預言者であり、あなたのために祈るだろう。そうすればあなたは生きる。もし返さないなら、あなたも、あなたに属するすべての者も必ず死ぬことを、確かに知っておきなさい。」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8"> アビメレクは朝早く起き、すべてのしもべたちを呼び寄せ、これらのことをすべて彼らに聞かせた。男たちは非常に恐れた。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 12:18; 創世記 26:10; 創世記 39:9"> それからアビメレクはアブラハムを呼んで言った。「あなたは私たちに何ということをしたのか。私があなたに対してどんな罪を犯したというので、私と私の王国にこのような大きな罪をもたらそうとしたのか。あなたは、してはならないことを私にしたのだ。」</span>
<span className="v" id="v10" data-v="10"> アビメレクはさらにアブラハムに言った。「あなたは何を考えて、このようなことをしたのか。」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="創世記 26:7; 創世記 12:12; ヨブ記 28:28"> アブラハムは言った。「この場所には神への恐れがなく、妻のゆえに私は殺されるに違いないと思ったのです。</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 11:29; 創世記 12:13; テサロニケ人への手紙第一 5:22"> それに、彼女は本当に私の妹なのです。私の父の娘ですが、母の娘ではありません。そして、彼女は私の妻になりました。</span>
<span className="v" id="v13" data-v="13" data-xref="創世記 12:1; 創世記 12:9; 使徒の働き 7:3–5"> 神が私を父の家からさすらいの旅に出させたとき、私は彼女に言いました。『これが、あなたが私に示すべき慈しみです。私たちがどこへ行っても、私について「彼は私の兄です」と言ってください。』」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="創世記 12:16; 創世記 20:2; 創世記 20:7"> アビメレクは羊、牛、男のしもべ、女のしもべを取ってアブラハムに与え、彼の妻サラを彼に返した。</span>
<span className="v" id="v15" data-v="15" data-xref="創世記 34:10; 創世記 13:9; 創世記 47:6"> アビメレクは言った。「見よ、私の地はあなたの前にある。あなたの好きな所に住みなさい。」</span>
<span className="v" id="v16" data-v="16" data-xref="箴言 27:5; 創世記 20:5; 創世記 24:65"> 彼はサラに言った。「見よ、私はあなたの兄に銀千枚を与えた。これは、あなたと一緒にいるすべての人の前で、あなたへの償いとなる。こうして、あなたはすべての人の前で潔白とされた。」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="ヤコブの手紙 5:16; マタイ 21:22; ヨブ記 42:9–10"> アブラハムは神に祈った。そこで神はアビメレクと、その妻と、女のしもべたちを癒やされたので、彼女たちは子どもを産むようになった。</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 12:17; 創世記 30:2; 創世記 16:2"> 主が、アブラハムの妻サラのゆえに、アビメレクの家のすべての胎を固く閉ざしておられたからである。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 30:22; 創世記 19:29; 詩篇 136:23"> 神はノアと、彼と一緒に箱舟にいたすべての野の動物、すべての家畜を心に留められた。神が地の上に風を吹かせると、水は引いていった。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 7:11; マタイ 8:26–27; 箴言 8:28"> 淵の源と天の窓は閉じられ、天からの雨は止められた。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 7:24; 創世記 7:11"> 水は地からしだいに引いていき、百五十日の終わりに水は減った。</span>
<span className="v" id="v4" data-v="4" data-xref="列王記第二 19:37; エレミヤ書 51:27; イザヤ書 37:38"> 第七の月の十七日に、箱舟はアララトの山々の上にとどまった。</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 7:11"> 水は第十の月まで、しだいに減り続けた。第十の月の一日に、山々の頂が現れた。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="創世記 6:16; ダニエル書 6:10"> 四十日の終わりに、ノアは自分が造った箱舟の窓を開け、</span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 147:9; 列王記第一 17:6; 列王記第一 17:4"> 烏を放った。烏は、地から水が乾ききるまで、行ったり来たりした。</span>
<span className="v" id="v8" data-v="8" data-xref="雅歌 2:14; 雅歌 1:15; マタイ 10:16"> ノアはまた、地の表から水が引いたかどうかを見るために、鳩を放った。</span>
<span className="v" id="v9" data-v="9" data-xref="マタイ 11:28; 詩篇 116:7; 申命記 28:65"> しかし、全地の表に水があったため、鳩は足を休める場所を見つけられず、箱舟のノアのもとへ戻って来た。ノアは手を伸ばして鳩を捕らえ、箱舟の中の自分のところへ引き入れた。</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 7:4; 創世記 7:10; 創世記 8:12"> ノアはさらに七日待ち、再び箱舟から鳩を放った。</span>
<span className="v" id="v11" data-v="11" data-xref="ネヘミヤ記 8:15; ゼカリヤ書 4:12–14; ローマ人への手紙 10:15"> 夕方になって、鳩はノアのもとへ戻って来た。見よ、そのくちばしには、摘み取られたばかりのオリーブの葉があった。こうしてノアは、地から水が引いたことを知った。</span>
<span className="v" id="v12" data-v="12" data-xref="イザヤ書 25:9; イザヤ書 30:18; 創世記 8:10"> ノアはさらに七日待ち、鳩を放った。鳩は二度と彼のもとへ戻って来なかった。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="創世記 7:11"> 第六百一年の第一の月、その月の一日に、地の水は乾いた。ノアは箱舟の覆いを取り外して見た。見よ、地の表は乾いていた。</span>
<span className="v" id="v14" data-v="14" data-xref="創世記 7:13–14; 創世記 7:11"> 第二の月の二十七日に、地は完全に乾いた。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15"> 神はノアに告げられた。</span>
<span className="v" id="v16" data-v="16" data-xref="創世記 7:13; 詩篇 121:8; 詩篇 91:11"> 「あなた、あなたの妻、あなたの息子たち、あなたの息子たちの妻たちは、一緒に箱舟から出なさい。</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 1:22; 創世記 9:1; エレミヤ書 31:27–28"> あなたと一緒にいるすべての肉なるあらゆる生き物、鳥、家畜、地を這うすべてのものを一緒に連れ出しなさい。彼らが地に満ち広がり、地の上で子を生み、増えるためである。」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="詩篇 121:8"> ノアは、息子たち、妻、息子たちの妻たちと一緒に外に出た。</span>
<span className="v" id="v19" data-v="19"> すべての野の動物、すべての這うもの、すべての鳥、地の上を動くすべてのものは、それぞれの家族ごとに箱舟から出た。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="ヘブル人への手紙 13:15–16; ローマ人への手紙 12:1; 創世記 22:9"> ノアは主のために祭壇を築き、すべての清い動物と清い鳥の中から取り、祭壇の上に全焼のささげ物をささげた。</span>
<span className="v" id="v21" data-v="21" data-xref="コリント人への第二の手紙 2:15; エペソ人への手紙 5:2; イザヤ書 54:9–10"> 主はその芳ばしい香りをかがれた。主は心の中で言われた。「わたしは、人のゆえに二度と地を呪うことはしない。人の心に思い計ることは、幼い時から悪いからである。わたしは、わたしが行ったように、すべての生き物を二度と打ち滅ぼすことはしない。</span>
<span className="v" id="v22" data-v="22" data-xref="ヤコブの手紙 5:7; 詩篇 74:16–17; エレミヤ書 5:24"> 地が続く限り、種蒔きと刈り入れ、寒さと暑さ、夏と冬、昼と夜がやむことはない。」</span>
</div>

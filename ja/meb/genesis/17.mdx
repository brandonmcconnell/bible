<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ピリピ人への手紙 4:13; エペソ人への手紙 3:20; ルカ 1:6"> アブラムが九十九歳になったとき、主がアブラムに現れて言われた。「わたしは全能の神である。わたしの前を歩み、非の打ち所のない者でありなさい。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 17:4–6; 創世記 12:2; 詩篇 105:8–11"> わたしは、わたしとあなたとの間に契約を立て、あなたを大いに増し加える。」</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="士師記 13:20; 創世記 17:17; 民数記 16:45"> アブラムはひれ伏した。神は彼に告げられた。</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 35:11; ガラテヤ人への手紙 3:28–29; 創世記 12:2"> 「見よ、わたしの契約はあなたと共にある。あなたは多くの民族の父となる。</span>
<span className="v" id="v5" data-v="5" data-xref="マタイ 1:21–23; ネヘミヤ記 9:7; 創世記 17:15"> あなたの名は、もはやアブラムとは呼ばれない。あなたの名はアブラハムとなる。わたしがあなたを多くの民族の父としたからである。</span>
<span className="v" id="v6" data-v="6" data-xref="創世記 17:4; マタイ 1:6–17; 創世記 35:11"> わたしはあなたを大いに実り豊かにする。あなたから民族を起こし、あなたから王たちが出る。</span>
<span className="v" id="v7" data-v="7" data-xref="ローマ人への手紙 9:7–9; 使徒の働き 2:39; 創世記 26:24"> わたしは、わたしとあなた、またあなたの後に続くあなたの子孫との間に、代々にわたる永遠の契約として、わたしの契約を立てる。それは、わたしがあなたと、あなたの後に続くあなたの子孫の神となるためである。</span>
<span className="v" id="v8" data-v="8" data-xref="レビ記 26:12; 詩篇 105:11; 出エジプト記 6:7"> わたしは、あなたが寄留している地、すなわちカナンの全地を、永遠の所有地としてあなたとあなたの後に続くあなたの子孫に与える。わたしは彼らの神となる。」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="イザヤ書 56:4–5; 詩篇 25:10; 詩篇 103:18"> 神はアブラハムに言われた。「あなたについては、あなたとあなたの後に続くあなたの子孫は、代々にわたってわたしの契約を守らなければならない。</span>
<span className="v" id="v10" data-v="10" data-xref="コロサイ人への手紙 2:11–12; ローマ人への手紙 4:9–11; 使徒の働き 7:8"> これは、わたしとあなたがた、またあなたの後に続く子孫との間で、あなたがたが守るべきわたしの契約である。あなたがたの中のすべての男子は割礼を受けなければならない。</span>
<span className="v" id="v11" data-v="11" data-xref="ローマ人への手紙 4:11; 使徒の働き 7:8; 申命記 10:16"> あなたがたは包皮の肉に割礼を受けなさい。それが、わたしとあなたがたとの間の契約のしるしとなる。</span>
<span className="v" id="v12" data-v="12" data-xref="レビ記 12:3; ルカ 2:21; 出エジプト記 12:48–49"> 代々にわたって、あなたがたの中のすべての男子は、生まれて八日目に割礼を受けなければならない。家で生まれた者も、あなたの子孫ではない外国人から金で買われた者も皆、割礼を受けなければならない。</span>
<span className="v" id="v13" data-v="13" data-xref="出エジプト記 12:44; 創世記 37:36; ネヘミヤ記 5:8"> あなたの家で生まれた者も、あなたの金で買われた者も、必ず割礼を受けなければならない。わたしの契約は、永遠の契約として、あなたがたの肉にある。</span>
<span className="v" id="v14" data-v="14" data-xref="出エジプト記 4:24–26; 民数記 15:30–31; 出エジプト記 12:19"> 包皮の肉に割礼を受けていない無割礼の男子は、その民から断ち切られる。彼はわたしの契約を破ったからである。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="サムエル記第二 12:25; 創世記 32:28; 創世記 17:5"> 神はアブラハムに言われた。「あなたの妻サライについては、その名をサライと呼んではならない。彼女の名はサラとなる。</span>
<span className="v" id="v16" data-v="16" data-xref="創世記 35:11; 創世記 17:6; イザヤ書 49:23"> わたしは彼女を祝福し、彼女によってあなたに男の子を与える。そうだ、わたしは彼女を祝福し、彼女は民族の母となる。彼女から諸民の王たちが出る。」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="ヨハネの黙示録 11:16; 創世記 21:6; 創世記 18:12"> そこでアブラハムはひれ伏して笑い、心の中で言った。「百歳の者に子どもが生まれるだろうか。九十歳のサラが子を産むだろうか。」</span>
<span className="v" id="v18" data-v="18" data-xref="使徒の働き 2:39; 詩篇 41:12; 詩篇 4:6"> アブラハムは神に言った。「どうか、イシュマエルがあなたの御前で生きられますように。」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="ルカ 1:13–20; 創世記 21:2–3; 列王記第二 4:16–17"> 神は言われた。「いや、あなたの妻サラがあなたに男の子を産む。あなたはその名をイサク<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="イサクは「彼は笑う」を意味する。">a</a></sup>と名付けなさい。わたしは彼と、彼の後に続く彼の子孫のために、永遠の契約としてわたしの契約を立てる。</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 21:18; 創世記 21:13; 創世記 25:12–18"> イシュマエルについても、わたしはあなたの願いを聞き入れた。見よ、わたしは彼を祝福し、彼に子を多く与え、彼を大いに増し加える。彼は十二人の君主の父となり、わたしは彼を大いなる民族とする。</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 21:2–3; 創世記 26:2–5; ガラテヤ人への手紙 3:29"> しかし、わたしは来年のこの定めの時に、サラがあなたに産むイサクと、わたしの契約を立てる。」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="創世記 18:33; 創世記 35:9–15; 士師記 6:21"> 神はアブラハムと語り終えられると、彼を離れて上って行かれた。</span>
<span className="v" id="v23" data-v="23" data-xref="詩篇 119:60; 創世記 18:19; 創世記 17:10–14"> アブラハムは息子イシュマエルと、家で生まれたすべての者、金で買われたすべての者、すなわちアブラハムの家のすべての男子を連れて行き、神が彼に言われたとおり、その同じ日に彼らの包皮の肉に割礼を施した。</span>
<span className="v" id="v24" data-v="24" data-xref="ローマ人への手紙 4:11; 創世記 17:17; ローマ人への手紙 4:19–20"> アブラハムが包皮の肉に割礼を受けたとき、彼は九十九歳であった。</span>
<span className="v" id="v25" data-v="25"> 息子イシュマエルが包皮の肉に割礼を受けたとき、彼は十三歳であった。</span>
<span className="v" id="v26" data-v="26" data-xref="詩篇 119:60; 創世記 22:3–4; 創世記 12:4"> その同じ日に、アブラハムと息子イシュマエルは割礼を受けた。</span>
<span className="v" id="v27" data-v="27" data-xref="創世記 18:19"> 彼の家のすべての男子、家で生まれた者、外国人から金で買われた者も、彼と共に割礼を受けた。</span>
</div>

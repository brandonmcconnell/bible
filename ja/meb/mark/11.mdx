<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マタイ 21:1–11; ヨハネ 12:14–19; ルカ 19:29–40"> 一行がエルサレムに近づき、オリーブ山にあるベテスファゲ<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="TR本文とNU本文では「ベテスファゲ」の代わりに「ベテファゲ」となっている。">a</a></sup>とベタニアの近くまで来ると、イエスは二人の弟子を遣わして、</span>
<span className="v" id="v2" data-v="2" data-xref="マタイ 21:2–3; ルカ 19:30–31"> 彼らに言われた。<span className="woj">「向こうの村へ行きなさい。村に入るとすぐ、まだだれも乗ったことのない子ろばがつながれているのが見つかる。それを解いて、連れて来なさい。</span></span>
<span className="v" id="v3" data-v="3" data-xref="使徒の働き 10:36; マルコ 14:15; 詩篇 110:3"> <span className="woj">もしだれかが、『なぜそんなことをするのか』と尋ねたら、『主がお入り用なのです。すぐにまたここへ返されます』と言いなさい。」</span></span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="マタイ 26:19; ルカ 19:32–34; マタイ 21:6–7"> 弟子たちが出かけて行くと、表通りに面した戸口の外に子ろばがつながれているのを見つけ、それを解いた。</span>
<span className="v" id="v5" data-v="5"> そこに立っていた人々の何人かが、「子ろばを解いて、何をしているのか」と尋ねた。</span>
<span className="v" id="v6" data-v="6"> 弟子たちがイエスに言われたとおりに答えると、人々は彼らを行かせた。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="ゼカリヤ書 9:9; ルカ 19:35–36; マタイ 21:7–8"> 弟子たちは子ろばをイエスのもとに連れて来て、その上に自分たちの上着を掛けた。イエスはそれに乗られた。</span>
<span className="v" id="v8" data-v="8" data-xref="レビ記 23:40"> 多くの人々は道に自分たちの上着を敷き、ほかの人々は木の枝を切って道に敷いた。</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 118:25–26; マタイ 21:9; マタイ 23:39"> 前を行く者たちも後に従う者たちも叫んだ。「ホサナ。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="「ホサナ」は「私たちを救ってください」または「どうか私たちを助けてください」という意味である。">b</a></sup>主の名によって来られる方は、幸いである。</span>
<span className="v" id="v10" data-v="10" data-xref="エゼキエル書 37:24–25; ルカ 2:14; ルカ 19:38–40"> 主の名によって来る、われらの父ダビデの国は、幸いである。いと高き所にホサナ。」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="ヨハネ 8:1–2; ルカ 19:41–45; ルカ 21:37–38"> イエスはエルサレムに入り、神殿に入られた。そして、すべてを見回された後、すでに夕方になっていたので、十二人と共にベタニアへ出て行かれた。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="マタイ 21:18–22; マタイ 4:2; ヨハネ 19:28"> 翌日、一行がベタニアを出たとき、イエスは空腹を覚えられた。</span>
<span className="v" id="v13" data-v="13" data-xref="マタイ 21:19; ルカ 13:6–9; イザヤ書 5:7"> 遠くに葉の茂ったいちじくの木をご覧になり、何か実が見つかるかと思って、そこへ行かれた。しかし、木のところに来ても、葉のほかには何も見つからなかった。いちじくの季節ではなかったからである。</span>
<span className="v" id="v14" data-v="14" data-xref="マタイ 21:19; マタイ 7:19; マタイ 3:10"> イエスはその木に、<span className="woj">「これから後、いつまでも、だれもおまえの実を食べない」</span>と言われた。弟子たちはそれを聞いていた。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="ヨハネ 2:13–17; マタイ 21:12–16; ルカ 19:45–47"> 一行はエルサレムに来た。イエスは神殿に入り、神殿の中で売り買いしている者たちを追い出し始め、両替人の台や鳩を売る者たちの腰掛けを倒された。</span>
<span className="v" id="v16" data-v="16"> また、だれにも神殿を通って器を運ぶことをお許しにならなかった。</span>
<span className="v" id="v17" data-v="17" data-xref="イザヤ書 56:7; エレミヤ書 7:11; ルカ 19:46"> そして彼らに教えて言われた。<span className="woj">「『私の家は、すべての国民のための祈りの家と呼ばれる』と書かれているではないか。</span><span className="woj">それなのに、あなたがたはそれを強盗の巣にしてしまった。」</span></span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="マタイ 7:28; マルコ 12:12; マルコ 14:1–2"> 祭司長たちと律法学者たちはこれを聞き、どうすればイエスを滅ぼせるかと策を練った。群衆がみなイエスの教えに驚いていたので、彼らはイエスを恐れていた。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="ルカ 21:37; マルコ 11:11; ヨハネ 12:36"> 夕方になると、イエスは都の外へ出て行かれた。</span>
<span className="v" id="v20" data-v="20" data-xref="マタイ 15:13; マルコ 11:14; ヨハネ 15:6"> 朝早く、彼らが通りかかると、いちじくの木が根元から枯れているのを見た。</span>
<span className="v" id="v21" data-v="21" data-xref="箴言 3:33; マタイ 23:7; マタイ 25:41"> ペテロは思い出してイエスに言った。「先生、ご覧ください。呪われたいちじくの木が枯れています。」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="詩篇 62:8; ヨハネ 14:1; マルコ 9:23"> イエスは彼らに答えられた。<span className="woj">「神を信じなさい。</span></span>
<span className="v" id="v23" data-v="23" data-xref="マタイ 17:20; ヨハネ 15:7; マタイ 21:21"> <span className="woj">まことに、あなたがたに言う。だれでもこの山に向かって、『動いて、海に入れ』と言い、心の中で疑わず、自分の言うことが実現すると信じるなら、そのとおりになる。</span></span>
<span className="v" id="v24" data-v="24" data-xref="マタイ 21:22; ヨハネの手紙第一 5:14–15; ヨハネの手紙第一 3:22"> <span className="woj">だから、あなたがたに言う。祈り求めるものは何でも、すでに受けたと信じなさい。そうすれば、そのとおりになる。</span></span>
<span className="v" id="v25" data-v="25" data-xref="マタイ 6:14–15; コロサイ人への手紙 3:13; エペソ人への手紙 4:32"> <span className="woj">立って祈るとき、だれかに恨みを抱いているなら、赦しなさい。そうすれば、天におられるあなたがたの父も、あなたがたの背きを赦してくださる。</span></span>
<span className="v" id="v26" data-v="26"> <span className="woj">しかし、あなたがたが赦さないなら、天におられるあなたがたの父も、あなたがたの背きを赦してくださらない。」</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="NU本文では26節が省かれている。">c</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="ルカ 20:1–8; マタイ 21:23–27; 詩篇 2:1–5"> 一行は再びエルサレムに来た。イエスが神殿の中を歩いておられると、祭司長たち、律法学者たち、長老たちが近寄って来て、</span>
<span className="v" id="v28" data-v="28" data-xref="出エジプト記 2:14; 使徒の働き 7:38–39; 民数記 16:3"> 言い始めた。「何の権威によって、これらのことをしているのか。これらのことをする権威を、だれがあなたに与えたのか。」</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="ルカ 20:3–8; マタイ 21:24; イザヤ書 52:13"> イエスは彼らに言われた。<span className="woj">「私もあなたがたに一つ尋ねよう。答えなさい。そうすれば、何の権威によってこれらのことをしているのか、あなたがたに話そう。</span></span>
<span className="v" id="v30" data-v="30" data-xref="ルカ 3:1–20; ヨハネ 3:25–36; マルコ 1:1–11"> <span className="woj">ヨハネのバプテスマは天からのものだったのか、それとも人からのものだったのか。答えなさい。」</span></span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="ヨハネ 1:29; ヨハネ 1:34; マタイ 21:31–32"> 彼らは互いに相談した。「もし『天から』と言えば、『では、なぜ彼を信じなかったのか』と言うだろう。</span>
<span className="v" id="v32" data-v="32" data-xref="マタイ 21:46; マルコ 12:12; マタイ 14:5"> かといって、『人から』と言えば――。」彼らは群衆を恐れていた。皆がヨハネを本当に預言者だと認めていたからである。</span>
<span className="v" id="v33" data-v="33" data-xref="イザヤ書 6:9–10; コリント人への第二の手紙 4:3–4; テサロニケ人への第二の手紙 2:10–12"> そこで彼らはイエスに、「分かりません」と答えた。<br />イエスは彼らに言われた。<span className="woj">「それなら私も、何の権威によってこれらのことをしているのか、あなたがたに話さない。」</span></span>
</div>

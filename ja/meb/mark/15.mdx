<div className="bible-chapter" lang="ja" dir="ltr" data-lang="ja" data-translation="meb" data-translation-id="jpn_meb" data-translation-label="MEB" data-book="MRK" data-book-slug="mark" data-book-name="マルコ" data-chapter="15" data-verses="47">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マタイ 27:1–2; ルカ 23:1–5; ルカ 22:66"> 朝早く、祭司長たちは長老たち、律法学者たち、最高法院全体と相談し、イエスを縛って連れ出し、ピラトに引き渡した。</span>
<span className="v" id="v2" data-v="2" data-xref="マタイ 2:2; マタイ 27:11–14; テモテへの手紙第一 6:13"> ピラトはイエスに尋ねた。「あなたはユダヤ人の王なのか。」<br />イエスは答えられた。<span className="woj">「あなたがそう言っている。」</span></span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="イザヤ書 53:7; マルコ 15:5; ヨハネ 18:29–31"> 祭司長たちは多くのことでイエスを訴えた。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネ 19:10; マタイ 27:13; マタイ 26:62"> ピラトは再びイエスに尋ねた。「何も答えないのか。見よ、彼らがどれほど多くのことであなたを訴えていることか。」</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="イザヤ書 53:7; ゼカリヤ書 3:8; 詩篇 71:7"> しかし、イエスはそれ以上何もお答えにならなかったので、ピラトは驚いた。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="ヨハネ 18:39–40; 使徒の働き 25:9; 使徒の働き 24:27"> さて、祭りのたびに、ピラトは人々が願い出る囚人を一人、釈放する習慣があった。</span>
<span className="v" id="v7" data-v="7" data-xref="ルカ 23:18–19; マタイ 27:16; ルカ 23:25"> バラバという者が、暴動の際に人を殺した暴徒たちと共に捕らえられていた。</span>
<span className="v" id="v8" data-v="8"> 群衆は大声を上げながら近づき、いつものようにしてほしいとピラトに願い始めた。</span>
<span className="v" id="v9" data-v="9" data-xref="ヨハネ 19:14–16; ヨハネ 19:4–5; ヨハネ 18:39"> ピラトは彼らに答えて言った。「ユダヤ人の王を釈放してほしいのか。」</span>
<span className="v" id="v10" data-v="10" data-xref="箴言 27:4; テトス 3:3; 創世記 4:4–6"> 祭司長たちが妬みのためにイエスを引き渡したことを、ピラトは見抜いていたからである。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒の働き 3:14; ヨハネ 18:40; ホセア書 5:1"> しかし祭司長たちは、代わりにバラバを釈放するよう、群衆を扇動した。</span>
<span className="v" id="v12" data-v="12" data-xref="エレミヤ書 23:5–6; イザヤ書 9:6–7; ゼカリヤ書 9:9"> ピラトは再び彼らに尋ねた。「では、あなたがたがユダヤ人の王と呼んでいる者を、私はどうすればよいのか。」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13"> 彼らは再び叫んだ。「十字架につけろ。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="ルカ 23:41; ルカ 23:23–24; イザヤ書 53:3"> ピラトは彼らに言った。「なぜだ。この人がどんな悪いことをしたというのか。」<br />しかし彼らは、ますます激しく、「十字架につけろ」と叫んだ。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="ヨハネ 19:1; マタイ 27:26; イザヤ書 50:6"> ピラトは群衆を満足させようとして、バラバを彼らに釈放した。一方、イエスをむち打ち、十字架につけるために引き渡した。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="ヨハネ 19:9; マタイ 27:27–31; ヨハネ 18:28"> 兵士たちはイエスを総督官邸の中庭へ連れて行き、部隊全員を呼び集めた。</span>
<span className="v" id="v17" data-v="17" data-xref="マタイ 27:28–30; ヨハネ 19:2–5; ルカ 23:11"> そしてイエスに紫の衣を着せ、いばらで冠を編んでかぶらせた。</span>
<span className="v" id="v18" data-v="18" data-xref="マタイ 27:42–43; マルコ 15:2; 創世記 37:10"> それから、「ユダヤ人の王、万歳」と挨拶し始めた。</span>
<span className="v" id="v19" data-v="19" data-xref="マルコ 14:65; イザヤ書 53:3–5; ルカ 23:11"> また、葦の棒でイエスの頭をたたき、つばを吐きかけ、ひざまずいて拝んだ。</span>
<span className="v" id="v20" data-v="20" data-xref="ヨハネ 19:16; マタイ 27:31"> こうしてイエスをあざけった後、紫の衣を脱がせ、元の衣を着せた。そして十字架につけるために連れ出した。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="マタイ 27:32; ルカ 23:26; ローマ人への手紙 16:13"> そこへ、田舎から来て通りかかったキレネ人シモンを、兵士たちは無理やり同行させ、イエスの十字架を運ばせた。シモンはアレクサンデルとルフォスの父であった。</span>
<span className="v" id="v22" data-v="22" data-xref="マタイ 27:33–44; ヨハネ 19:17–27; ルカ 23:27–38"> 彼らはイエスをゴルゴタ、訳すと「どくろの場所」と呼ばれる所へ連れて行った。</span>
<span className="v" id="v23" data-v="23" data-xref="マタイ 27:34; ヨハネ 19:28–30; ルカ 23:36"> そして、没薬を混ぜたぶどう酒を飲ませようとしたが、イエスはお受けにならなかった。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="ルカ 23:34; ヨハネ 19:23–24; マタイ 27:35–36"> 彼らはイエスを十字架につけ、その衣を分け合い、だれが何を取るか、くじを引いた。</span>
<span className="v" id="v25" data-v="25" data-xref="ヨハネ 19:14; マルコ 15:33; マタイ 27:45"> イエスを十字架につけたのは第三時<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="午前九時。">a</a></sup>であった。</span>
<span className="v" id="v26" data-v="26" data-xref="マタイ 27:37; マタイ 2:2; ヨハネ 19:18–22"> イエスの頭上に掲げられた罪状書きには、「ユダヤ人の王」と書かれていた。</span>
<span className="v" id="v27" data-v="27" data-xref="ルカ 23:32–33; マタイ 27:38; ヨハネ 19:18"> 彼らはイエスと共に二人の強盗を、一人を右に、一人を左に十字架につけた。</span>
<span className="v" id="v28" data-v="28"> こうして、「彼は不法を行う者たちの一人に数えられた」と言う聖書の言葉が成就した。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="NU本文では28節が省かれている。">b</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="マルコ 14:58; 詩篇 109:25; 哀歌 1:12"> 通りかかった人々は、頭を振りながらイエスを冒涜して言った。「ああ、神殿を壊して三日で建てる者よ、</span>
<span className="v" id="v30" data-v="30"> 自分を救って、十字架から降りて来い。」</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="ヨハネ 12:23–24; マタイ 27:41–43; ルカ 23:35–37"> 同じように、祭司長たちも律法学者たちと一緒になって互いにあざけり、言った。「ほかの人は救ったが、自分自身を救うことはできない。</span>
<span className="v" id="v32" data-v="32" data-xref="マタイ 27:44; ルカ 23:39–43; ゼカリヤ書 9:9"> キリスト、イスラエルの王よ、今、十字架から降りて来い。そうすれば、われわれは見て信じよう。」<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="TR本文では「彼を」が省かれている。">c</a></sup>一緒に十字架につけられた者たちも、イエスを侮辱した。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="マタイ 27:45; ルカ 23:44–45; アモス書 8:9–10"> 第六時<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="または「正午」。">d</a></sup>になると、全地が暗くなり、第九時<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="午後三時。">e</a></sup>まで続いた。</span>
<span className="v" id="v34" data-v="34" data-xref="詩篇 22:1; マタイ 27:46; ヘブル人への手紙 5:7"> 第九時に、イエスは大声で叫ばれた。<span className="woj">「エロイ、エロイ、ラマ、サバクタニ。」</span>これは訳すと、<span className="woj">「わが神、わが神、なぜ私をお見捨てになったのですか」</span>という意味である。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="マタイ 27:47–49; マルコ 9:11–13; マタイ 17:11–13"> そばに立っていた人々の何人かは、これを聞いて言った。「見よ、エリヤを呼んでいる。」</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="詩篇 69:21; マルコ 15:23; ヨハネ 19:28–30"> すると一人が走り寄り、海綿に酸いぶどう酒をたっぷり含ませて葦の棒につけ、イエスに飲ませながら言った。「待て。エリヤが降ろしに来るかどうか見てみよう。」</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="ヨハネ 19:30; ルカ 23:46; マタイ 27:50"> イエスは大声で叫び、息を引き取られた。</span>
<span className="v" id="v38" data-v="38" data-xref="ヘブル人への手紙 10:19–23; ルカ 23:45; ヘブル人への手紙 9:3–12"> 神殿の幕は上から下まで真っ二つに裂けた。</span>
<span className="v" id="v39" data-v="39" data-xref="マタイ 27:54; ルカ 23:47–48; マタイ 27:43"> イエスの正面に立っていた百人隊長は、イエスがこのように叫んで息を引き取られたのを見て言った。「まことに、この人は神の子だった。」</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="ルカ 23:49; ルカ 8:2–3; マタイ 27:55–56"> 女たちも遠くから見ていた。その中には、マグダラのマリア、小ヤコブとヨセの母マリア、サロメがいた。</span>
<span className="v" id="v41" data-v="41" data-xref="ルカ 8:2–3; マタイ 27:55–56"> 彼女たちは、イエスがガリラヤにおられたとき、イエスに従って仕えていた。このほかにも、イエスと共にエルサレムに上って来た女たちが大勢いた。</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="ルカ 23:50–56; ヨハネ 19:38–42; ヨハネ 19:31"> すでに夕方になっていた。その日は備えの日、すなわち安息日の前日だったので、</span>
<span className="v" id="v43" data-v="43" data-xref="ルカ 2:38; ルカ 2:25; ルカ 23:51"> アリマタヤのヨセフが来た。彼は有力な最高法院の議員で、自らも神の御国を待ち望んでいた。彼は勇気を出してピラトのもとに入り、イエスの体を渡してほしいと願った。</span>
<span className="v" id="v44" data-v="44" data-xref="ヨハネ 19:31–37"> ピラトは、イエスがもう死んだのかと驚き、百人隊長を呼び寄せ、すでに死んでから長いのかと尋ねた。</span>
<span className="v" id="v45" data-v="45" data-xref="マタイ 27:58; ヨハネ 19:38; マルコ 15:39"> そして百人隊長に確かめると、遺体をヨセフに渡した。</span>
<span className="v" id="v46" data-v="46" data-xref="イザヤ書 53:9; マタイ 27:59–60; イザヤ書 22:16"> ヨセフは亜麻布を買い、イエスを十字架から降ろして亜麻布で包み、岩を掘って造った墓に納めた。そして墓の入り口に石を転がしておいた。</span>
<span className="v" id="v47" data-v="47" data-xref="マルコ 15:40; マルコ 16:1; ルカ 23:55–2"> マグダラのマリアとヨセの母マリアは、イエスが納められた場所を見ていた。</span>
</div>
</div>

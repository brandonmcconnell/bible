<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マタイ 12:9–14; ルカ 6:6–11; マルコ 1:21"> イエスは再び会堂に入られた。そこに片手の萎えた人がいた。</span>
<span className="v" id="v2" data-v="2" data-xref="詩篇 37:32; ルカ 14:1; ルカ 6:7"> 人々はイエスを訴える口実を得ようとして、安息日にその人を癒すかどうか、じっと見ていた。</span>
<span className="v" id="v3" data-v="3" data-xref="ピリピ人への手紙 1:28–30; イザヤ書 42:4; ルカ 6:8"> イエスは片手の萎えた人に、<span className="woj">「立って、真ん中に出なさい」</span>と言われた。</span>
<span className="v" id="v4" data-v="4" data-xref="ルカ 6:9; マタイ 12:10–12; ホセア書 6:6"> それから人々に言われた。<span className="woj">「安息日に許されているのは、善を行うことか、悪を行うことか。いのちを救うことか、殺すことか。」</span>しかし、彼らは黙っていた。</span>
<span className="v" id="v5" data-v="5" data-xref="ルカ 6:10; エペソ人への手紙 4:18; ローマ人への手紙 11:25"> イエスは怒りをもって彼らを見回し、そのかたくなな心を悲しみながら、男に言われた。<span className="woj">「手を伸ばしなさい。」</span>彼が手を伸ばすと、その手はもう一方の手と同じように元どおりになった。</span>
<span className="v" id="v6" data-v="6" data-xref="マタイ 22:16; マルコ 12:13; マタイ 12:14"> パリサイ人たちは外へ出ると、すぐにヘロデ党の者たちと、どうすればイエスを滅ぼせるか相談し始めた。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="マタイ 4:25; ルカ 6:17; マタイ 12:15"> イエスは弟子たちと共に湖のほとりへ退かれた。ガリラヤから来た大勢の群衆が従った。また、ユダヤ、</span>
<span className="v" id="v8" data-v="8" data-xref="エゼキエル書 35:15; イザヤ書 34:5; マタイ 11:21"> エルサレム、イドマヤ、ヨルダンの向こう側、ツロやシドンの周辺からも、大勢の群衆が来た。イエスが行っておられる偉大なわざを聞き、そのもとにやって来たのである。</span>
<span className="v" id="v9" data-v="9" data-xref="マルコ 5:30; ヨハネ 6:15"> イエスは群衆に押しつぶされないよう、ご自分のために小舟を用意しておくよう弟子たちに言われた。</span>
<span className="v" id="v10" data-v="10" data-xref="マタイ 14:36; マルコ 6:56; マタイ 4:23"> イエスが多くの人を癒されたので、病気に苦しむ者たちが皆、イエスに触れようとして押し寄せて来たからである。</span>
<span className="v" id="v11" data-v="11" data-xref="ルカ 4:41; マルコ 1:23–24; ルカ 8:28"> 汚れた霊たちはイエスを見るたびに、その前にひれ伏し、「あなたは神の子です」と叫んだ。</span>
<span className="v" id="v12" data-v="12" data-xref="マタイ 12:16; マルコ 1:25; マルコ 1:34"> イエスは、ご自分のことを知らせないよう彼らを厳しく戒められた。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="ルカ 9:1; ルカ 6:12–16; マタイ 10:1–4"> イエスは山に登り、ご自分が望む者たちを呼び寄せられた。彼らはイエスのもとに来た。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒の働き 1:8; ルカ 9:1–6; ヨハネ 15:16"> イエスは十二人を任命された。それは、彼らをご自分のそばに置き、また宣べ伝えるために遣わし、</span>
<span className="v" id="v15" data-v="15"> 病気を癒し、悪霊を追い出す権威を持たせるためであった。</span>
<span className="v" id="v16" data-v="16" data-xref="ヨハネ 1:42; 使徒の働き 1:13; マタイ 16:16–18"> こうして十二人を任命された。シモンにはペテロという名をつけられた。</span>
<span className="v" id="v17" data-v="17" data-xref="ヘブル人への手紙 4:12; マルコ 14:33; エレミヤ書 23:29"> ゼベダイの子ヤコブと、ヤコブの兄弟ヨハネには、ボアネルゲ、すなわち「雷の子ら」という名をつけられた。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒の働き 1:13; マルコ 2:14; マタイ 9:9"> そしてアンデレ、フィリポ、バルトロマイ、マタイ、トマス、アルパヨの子ヤコブ、タダイ、熱心党員シモン、</span>
<span className="v" id="v19" data-v="19" data-xref="ヨハネ 6:71; ヨハネ 13:2; 使徒の働き 1:16–25"> それに、後にイエスを裏切ったイスカリオテのユダである。<br />それからイエスは家に入られた。</span>
<span className="v" id="v20" data-v="20" data-xref="マルコ 6:31; ヨハネ 4:31–34; マルコ 9:28"> 群衆が再び集まって来たので、イエスと弟子たちは食事をすることさえできなかった。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒の働き 26:24; ヨハネ 10:20; マルコ 3:31"> イエスの身内の者たちはこのことを聞くと、イエスを取り押さえようと出かけた。人々が「彼は正気を失っている」と言っていたからである。</span>
<span className="v" id="v22" data-v="22" data-xref="マタイ 15:1; マタイ 10:25; マタイ 9:34"> エルサレムから下って来た律法学者たちは、「彼はベルゼブルに取りつかれている」「悪霊どもの支配者によって、悪霊を追い出しているのだ」と言った。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="ルカ 11:17–23; マタイ 12:25–30; マタイ 13:34"> イエスは彼らを呼び寄せ、たとえで言われた。<span className="woj">「どうしてサタンがサタンを追い出せるだろうか。</span></span>
<span className="v" id="v24" data-v="24" data-xref="ゼカリヤ書 11:14; イザヤ書 19:2–3; サムエル記第二 20:6"> <span className="woj">もし王国が内部で分裂すれば、その王国は立ちゆかない。</span></span>
<span className="v" id="v25" data-v="25" data-xref="ヤコブの手紙 3:16; 詩篇 133:1; ガラテヤ人への手紙 5:15"> <span className="woj">もし家が内部で分裂すれば、その家は立ちゆかない。</span></span>
<span className="v" id="v26" data-v="26"> <span className="woj">もしサタンが自分自身に逆らって立ち上がり、分裂すれば、立ちゆくことができず、滅びてしまう。</span></span>
<span className="v" id="v27" data-v="27" data-xref="イザヤ書 49:24–26; マタイ 12:29; ルカ 11:21–23"> <span className="woj">まず強い者を縛らなければ、だれもその家に入って家財を奪い取ることはできない。縛って初めて、その家を略奪できる。</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="ルカ 12:10; マタイ 12:31–32; ヨハネの手紙第一 5:16"> <span className="woj">まことに、あなたがたに言う。人の子らのどのような罪も、どのような冒涜の言葉も、すべて赦される。</span></span>
<span className="v" id="v29" data-v="29" data-xref="マタイ 12:31–32; ルカ 12:10; テサロニケ人への第二の手紙 1:9"> <span className="woj">しかし、聖霊を冒涜する者は永遠に赦されず、永遠の刑罰を受ける。」</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="NU本文では「永遠の罪を負う」となっている。">a</a></sup></span>
<span className="v" id="v30" data-v="30" data-xref="ヨハネ 10:20; マルコ 3:22"> これは、彼らが「イエスは汚れた霊に取りつかれている」と言っていたからである。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="ルカ 8:19–21; マタイ 12:46–50"> その時、イエスの母と兄弟たちが来た。そして外に立ち、人を遣わしてイエスを呼ばせた。</span>
<span className="v" id="v32" data-v="32"> 群衆がイエスの周りに座っていた。人々がイエスに言った。「見よ、あなたのお母様と兄弟たち、それに姉妹たち<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="TR本文では「それに姉妹たち」が省かれている。">b</a></sup>が外であなたを捜しています。」</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="マルコ 3:21; 申命記 33:9; マルコ 6:3"> イエスは彼らに答えられた。<span className="woj">「私の母、私の兄弟とはだれか。」</span></span>
<span className="v" id="v34" data-v="34" data-xref="マタイ 12:49–50; ルカ 11:27–28; ローマ人への手紙 8:29"> そして、ご自分を囲んで座っている人々を見回して言われた。<span className="woj">「見よ、私の母、私の兄弟たちだ。</span></span>
<span className="v" id="v35" data-v="35" data-xref="ヨハネの手紙第一 2:17; マタイ 7:21; ヨハネの手紙第一 3:22–23"> <span className="woj">神の御心を行う人はだれでも、私の兄弟、姉妹、また母である。」</span></span>
</div>
</div>

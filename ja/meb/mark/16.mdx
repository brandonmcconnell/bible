<span className="v" id="v2" data-v="2" data-xref="ヨハネ 20:1; ルカ 24:1; マタイ 28:1"> 週の初めの日の朝早く、日が昇ったころ、彼女たちは墓へ行った。</span>
<span className="v" id="v3" data-v="3" data-xref="マルコ 15:46–47; マタイ 27:60–66"> そして互いに言っていた。「だれが墓の入り口から石を転がしてくれるでしょうか。」</span>
<span className="v" id="v4" data-v="4" data-xref="マタイ 28:2–4; ルカ 24:2; ヨハネ 20:1"> ところが目を上げると、非常に大きな石がすでに転がしてあるのが見えた。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="ヨハネ 20:11–12; ルカ 24:3–5; ヨハネ 20:8"> 墓の中に入ると、右側に白い長衣を着た若者が座っているのを見て、彼女たちは驚いた。</span>
<span className="v" id="v6" data-v="6" data-xref="ヨハネの黙示録 1:17–18; コリント人への第一の手紙 15:3–7; ルカ 24:46"> 若者は彼女たちに言った。「驚かなくてよい。あなたがたは、十字架につけられたナザレ人イエスを捜しているのでしょう。あの方はよみがえられました。ここにはおられません。ご覧なさい。ここが、あの方が納められていた場所です。</span>
<span className="v" id="v7" data-v="7" data-xref="マルコ 14:28; マタイ 26:32; マタイ 28:10"> さあ行って、弟子たちとペテロに、『イエスはあなたがたより先にガリラヤへ行かれます。前に言われたとおり、そこでお会いできます』と伝えなさい。」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="ルカ 24:22–24; ルカ 24:9–11; マルコ 16:5–6"> 彼女たちは外へ出て、<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="TR本文は「急いで」を加えている。">a</a></sup>墓から逃げ去った。震えと驚きに襲われていたからである。そして恐ろしかったので、だれにも何も言わなかった。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="一つの孤立した写本は9-20節を省くが、8節の末尾に次の「マルコによる福音書の短い結び」を加えている。彼女たちは命じられたことをすべて、ペテロの周りにいた人々に手短に伝えた。その後、イエスご自身が彼らを遣わし、東から西まで、永遠の救いについての神聖で朽ちることのない宣言を伝えさせられた。">b</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="ヨハネ 20:14–19; ルカ 8:2; ヨハネ 20:12"> <sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="NU本文には9-20節の本文が含まれているが、少数の写本ではこれが省かれていると脚注に記している。世界英語聖書の翻訳者たちは、権威あるギリシャ語多数本文新約聖書だけでなく、TR本文やNU本文が引用する多くの写本を含む圧倒的多数の本文証拠に基づき、マルコによる福音書16:9-20を信頼できるものとみなしている。">c</a></sup>さて、週の初めの日の朝早く、イエスはよみがえり、まずマグダラのマリアに現れた。イエスは以前、彼女から七つの悪霊を追い出されたのである。</span>
<span className="v" id="v10" data-v="10" data-xref="ヨハネ 20:18; ルカ 24:17; ヨハネ 16:6"> 彼女は、イエスと共にいた人々が嘆き悲しんで泣いているところへ行き、そのことを知らせた。</span>
<span className="v" id="v11" data-v="11" data-xref="ルカ 24:11; マルコ 16:13–14; マルコ 9:19"> しかし彼らは、イエスが生きておられ、彼女に姿を現されたと聞いても、信じなかった。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="ルカ 24:13–32; ヨハネ 21:14; ヨハネ 21:1"> その後、彼らのうちの二人が田舎へ向かって歩いていると、イエスは別の姿で現れた。</span>
<span className="v" id="v13" data-v="13" data-xref="ヨハネ 20:25; ルカ 24:33–35; ヨハネ 20:8"> 二人は戻って、ほかの人々に知らせた。しかし、人々は二人の言うことも信じなかった。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="コリント人への第一の手紙 15:5; ルカ 24:36–43; ヘブル人への手紙 3:7–8"> その後、十一人が食卓に着いているところに、イエスご自身が現れた。そして、ご自分がよみがえった後に姿を見た人々の言うことを信じなかった彼らの不信仰と心の頑なさを責められた。</span>
<span className="v" id="v15" data-v="15" data-xref="マタイ 28:19; マルコ 13:10; 使徒の働き 1:8"> イエスは彼らに言われた。<span className="woj">「全世界へ出て行き、すべての被造物に福音を宣べ伝えなさい。</span></span>
<span className="v" id="v16" data-v="16" data-xref="ヨハネ 11:25–26; ヨハネ 3:36; ローマ人への手紙 10:9–14"> <span className="woj">信じてバプテスマを受ける者は救われる。しかし、信じない者は罪に定められる。</span></span>
<span className="v" id="v17" data-v="17" data-xref="使徒の働き 5:16; コリント人への第一の手紙 12:28; 使徒の働き 8:7"> <span className="woj">信じる者たちには、次のようなしるしが伴う。彼らは私の名によって悪霊を追い出し、新しい言語で語る。</span></span>
<span className="v" id="v18" data-v="18" data-xref="ルカ 10:19; ヤコブの手紙 5:14–15; 使徒の働き 28:3–6"> <span className="woj">蛇をつかみ、たとえ死をもたらすものを飲んでも、決して害を受けない。病人に手を置けば、病人は回復する。」</span></span>
</div>

<span className="v" id="v20" data-v="20" data-xref="コリント人への第一の手紙 2:4–5; 使徒の働き 14:3; ローマ人への手紙 15:19"> 弟子たちは出て行って、至る所で福音を宣べ伝えた。主も彼らと共に働き、伴うしるしによって御言葉を確かなものとされた。アーメン。</span>

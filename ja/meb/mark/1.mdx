<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨハネの手紙第一 5:11–12; マタイ 4:3; マタイ 3:17"> 神の子イエス・キリストの福音の始まり。</span>
</div>
<div className="bp poetry">
<span className="v" id="v2" data-v="2" data-xref="マラキ書 3:1; マタイ 11:10; ルカ 1:76"> 預言者たちの書に、こう書かれている。<br /><span className="pl pl-1">「見よ、</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「見よ」はギリシャ語の「ἰδοὺ」に由来し、「見る、注意を向ける、観察する、目を留める」という意味で、しばしば間投詞として用いられる。">a</a></sup><br /><span className="pl pl-1">わたしはあなたの前に使者を遣わす。</span><br /><span className="pl pl-2">彼はあなたの道を整える。</span></span>
<span className="v" id="v3" data-v="3" data-xref="イザヤ書 40:3–5; マタイ 3:3; ルカ 3:4–6"> <span className="pl pl-1">荒野で叫ぶ者の声がする。</span><br /><span className="pl pl-2">『主の道を整えよ。</span><br /><span className="pl pl-2">その道筋をまっすぐにせよ。』」</span></span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="使徒の働き 19:3–4; マタイ 3:6; 使徒の働き 13:24–25"> ヨハネが荒野に現れ、バプテスマを授け、<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="または「浸し」。">b</a></sup>罪の赦しのための悔い改めのバプテスマを宣べ伝えた。</span>
<span className="v" id="v5" data-v="5" data-xref="レビ記 26:40–42; 使徒の働き 19:18; マタイ 3:5–6"> ユダヤ地方全土とエルサレムの人々がみな、ヨハネのもとに出て来た。そして自分たちの罪を告白し、ヨルダン川でヨハネからバプテスマを受けた。</span>
<span className="v" id="v6" data-v="6" data-xref="列王記第二 1:8; レビ記 11:22; マタイ 3:4"> ヨハネはらくだの毛でできた衣をまとい、腰に革の帯を締めていた。食べ物はいなごと野生の蜂蜜だった。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒の働き 13:25; ルカ 3:16; ヨハネ 1:27"> 彼は宣べ伝えて言った。「私より力のある方が、私の後から来られる。私はかがんで、その方の履物のひもを解く資格さえない。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒の働き 1:5; コリント人への第一の手紙 12:13; 使徒の働き 19:4–6"> 私はあなたがたに水で<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="ここで「で」と訳されたギリシャ語（en）は、文脈によっては「～の中で」または「～を用いて」とも訳せる。">c</a></sup>バプテスマを授けたが、その方は聖霊によって、あなたがたにバプテスマを授ける。」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="マタイ 3:13–17; マタイ 2:23; ルカ 3:21–22"> そのころ、イエスはガリラヤのナザレから来られ、ヨルダン川でヨハネからバプテスマを受けられた。</span>
<span className="v" id="v10" data-v="10" data-xref="ヨハネ 1:31–34; ルカ 3:22; イザヤ書 42:1"> イエスが水から上がると、すぐに天が裂け、霊が鳩のようにご自分の上に下って来るのをご覧になった。</span>
<span className="v" id="v11" data-v="11" data-xref="イザヤ書 42:1; マルコ 9:7; マタイ 3:17"> すると天から声がした。「あなたはわたしの愛する子。わたしはあなたを喜びとする。」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="マタイ 4:1–11; ルカ 4:1–13"> するとすぐに、霊はイエスを荒野へ追いやった。</span>
<span className="v" id="v13" data-v="13" data-xref="ヘブル人への手紙 2:17–18; ヘブル人への手紙 4:15; 出エジプト記 34:28"> イエスは四十日間荒野にいて、サタンの誘惑を受けられた。野の獣と共におられ、御使いたちが仕えていた。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="マタイ 4:23; マタイ 4:12; ルカ 8:1"> ヨハネが捕らえられた後、イエスはガリラヤに来て、神の御国の福音を宣べ伝え、</span>
<span className="v" id="v15" data-v="15" data-xref="マタイ 3:2; 使徒の働き 2:36–38; マタイ 4:17"> こう言われた。<span className="woj">「時は満ち、神の御国は近づいた。悔い改めて、福音を信じなさい。」</span></span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="マタイ 4:18–22; ヨハネ 1:40–42; ヨハネ 6:8"> イエスがガリラヤ湖のほとりを歩いておられたとき、シモンとその兄弟アンデレが湖に網を投げているのをご覧になった。彼らは漁師だった。</span>
<span className="v" id="v17" data-v="17" data-xref="ルカ 5:10; マタイ 4:19–20; 使徒の働き 2:38–41"> イエスは彼らに言われた。<span className="woj">「私について来なさい。あなたがたを、人をとる漁師にしよう。」</span></span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="ルカ 18:28–30; ルカ 5:11; マルコ 10:28–31"> 彼らはすぐに網を置いて、イエスに従った。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="マルコ 5:37; 使徒の働き 1:13; マルコ 10:35"> そこから少し進んで行くと、ゼベダイの子ヤコブと、その兄弟ヨハネをご覧になった。彼らも舟の中で網を繕っていた。</span>
<span className="v" id="v20" data-v="20" data-xref="マタイ 10:37; ルカ 14:26; マルコ 10:29"> イエスはすぐに彼らを呼ばれた。彼らは父ゼベダイを雇い人たちと共に舟に残し、イエスについて行った。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="マルコ 6:2; マルコ 1:39; マタイ 4:23"> 一行はカペナウムに入った。安息日になると、イエスはすぐに会堂に入って教えられた。</span>
<span className="v" id="v22" data-v="22" data-xref="マタイ 7:28–29; マタイ 13:54; ルカ 4:32"> 人々はその教えに驚いた。イエスが律法学者たちのようにではなく、権威ある者として教えられたからである。</span>
<span className="v" id="v23" data-v="23" data-xref="マルコ 9:25; マルコ 7:25; マルコ 1:34"> ちょうどその時、会堂に汚れた霊につかれた男がいて、叫んだ。</span>
<span className="v" id="v24" data-v="24" data-xref="マタイ 8:29; ヤコブの手紙 2:19; 使徒の働き 3:14"> 「ああ、ナザレのイエスよ、私たちと何の関係があるのですか。私たちを滅ぼしに来られたのですか。私はあなたがどなたか知っています。神の聖者です。」</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="マルコ 1:34; ルカ 4:41; 使徒の働き 16:17"> イエスは彼を叱りつけ、<span className="woj">「黙れ。この人から出て行け！」</span>と言われた。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="マルコ 9:26; マルコ 9:20; ルカ 11:22"> 汚れた霊は男をけいれんさせ、大声で叫んでから、彼の中から出て行った。</span>
<span className="v" id="v27" data-v="27" data-xref="マタイ 15:31; マルコ 7:37; ルカ 9:1"> 人々はみな驚き、互いに問い合った。「これは何だ。権威を伴う新しい教えではないか。この方が命じると、汚れた霊たちさえ従う。」</span>
<span className="v" id="v28" data-v="28" data-xref="マタイ 9:31; ルカ 4:37; マルコ 1:45"> イエスの評判はすぐに、ガリラヤ地方とその周辺一帯に広まった。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="ルカ 4:38–39; マタイ 8:14–15; マルコ 1:21"> 一行は会堂を出ると、すぐにヤコブとヨハネを伴い、シモンとアンデレの家に入った。</span>
<span className="v" id="v30" data-v="30" data-xref="コリント人への第一の手紙 9:5; マルコ 5:23; ヨハネ 11:3"> シモンのしゅうとめが熱を出して寝込んでいたので、人々はすぐに彼女のことをイエスに話した。</span>
<span className="v" id="v31" data-v="31" data-xref="使徒の働き 9:41; 詩篇 116:12; マルコ 5:41"> イエスはそばに行き、彼女の手を取って起こされた。すると熱はすぐに引き、<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="NU本文では「すぐに」が省かれている。">d</a></sup>彼女は一同に仕えた。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="マタイ 8:16; マルコ 3:2; ルカ 4:40"> 夕方になり、日が沈むと、人々は病人や悪霊につかれた者をみな、イエスのもとに連れて来た。</span>
<span className="v" id="v33" data-v="33" data-xref="マルコ 1:5; 使徒の働き 13:44"> 町中の人々が戸口に集まった。</span>
<span className="v" id="v34" data-v="34" data-xref="ルカ 4:41; マルコ 3:12; マタイ 4:23"> イエスはさまざまな病気を患う多くの人を癒し、多くの悪霊を追い出された。悪霊たちがイエスを知っていたので、彼らがものを言うことをお許しにならなかった。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="ルカ 6:12; ルカ 5:16; ルカ 22:39–46"> 朝早く、まだ暗いうちに、イエスは起きて外へ出て行き、人里離れた所で祈っておられた。</span>
<span className="v" id="v36" data-v="36"> シモンとその仲間たちはイエスを捜しに行った。</span>
<span className="v" id="v37" data-v="37" data-xref="ヨハネ 12:19; マルコ 1:5; ゼカリヤ書 11:11"> そして見つけると、「みんながあなたを捜しています」と言った。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="ルカ 4:43; ヨハネ 17:8; イザヤ書 61:1–3"> イエスは彼らに言われた。<span className="woj">「ほかの近くの町々へ行こう。そこでも宣べ伝えるためだ。そのために私は出て来た。」</span></span>
<span className="v" id="v39" data-v="39" data-xref="マタイ 4:23; マルコ 1:21; ルカ 4:43–44"> こうしてイエスはガリラヤ全土を巡り、諸会堂で宣べ伝え、悪霊を追い出された。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="ルカ 5:12–14; マタイ 8:2–4; レビ記 13:1–14"> 重い皮膚病を患う人がイエスのもとに来て、ひざまずき、懇願して言った。「お望みになれば、私を清くすることがおできになります。」</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="マタイ 9:36; ヘブル人への手紙 2:17; ヘブル人への手紙 4:15"> イエスは深くあわれみ、手を伸ばして彼に触れ、<span className="woj">「そうしよう。清くなりなさい。」</span>と言われた。</span>
<span className="v" id="v42" data-v="42" data-xref="ヨハネ 15:3; マルコ 5:29; ヨハネ 4:50–53"> そう言われると、重い皮膚病はすぐに彼から消え、彼は清くなった。</span>
<span className="v" id="v43" data-v="43" data-xref="マタイ 9:30; マルコ 7:36; ルカ 8:56"> イエスは彼を厳しく戒め、すぐに立ち去らせて、</span>
<span className="v" id="v44" data-v="44" data-xref="レビ記 14:1–32; ルカ 17:14; マタイ 8:4"> こう言われた。<span className="woj">「だれにも何も話さないように気をつけなさい。ただ行って、自分の体を祭司に見せ、清めのためにモーセが命じた物をささげ、彼らへのあかしとしなさい。」</span></span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="マルコ 2:13; マタイ 9:31; ヨハネ 6:2"> しかし彼は出て行くと、そのことを盛んに言い広め始めた。そのためイエスは、もはや公然と町に入れず、町の外の人里離れた所におられた。それでも人々は、あらゆる所からイエスのもとにやって来た。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ルカ 5:1–3; マルコ 2:13; ルカ 8:4–10"> イエスは再び湖のほとりで教え始められた。非常に大勢の群衆が集まって来たので、イエスは湖に浮かべた舟に乗り、腰を下ろされた。群衆は皆、湖のほとりの陸地にいた。</span>
<span className="v" id="v2" data-v="2" data-xref="マタイ 13:34–35; マルコ 3:23; マルコ 4:11"> イエスはたとえを用いて多くのことを教え、その教えの中でこう言われた。</span>
<span className="v" id="v3" data-v="3" data-xref="ヤコブの手紙 2:5; マタイ 13:26; マルコ 4:26–29"> <span className="woj">「よく聞きなさい。見よ、種をまく人が種をまきに出かけた。</span></span>
<span className="v" id="v4" data-v="4" data-xref="マタイ 13:19; マルコ 4:15; マタイ 13:4"> <span className="woj">種をまいていると、ある種は道端に落ち、鳥たち</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="TR本文は「空の」を加えている。">a</a></sup><span className="woj">が来て食べ尽くした。</span></span>
<span className="v" id="v5" data-v="5" data-xref="エゼキエル書 36:26; ルカ 8:6; ルカ 8:13"> <span className="woj">また、ある種は土の少ない岩地に落ちた。土が深くなかったので、すぐに芽を出した。</span></span>
<span className="v" id="v6" data-v="6" data-xref="ヤコブの手紙 1:11; エレミヤ書 17:5–8; ヨナ書 4:8"> <span className="woj">しかし日が昇ると焼かれ、根がなかったので枯れてしまった。</span></span>
<span className="v" id="v7" data-v="7" data-xref="エレミヤ書 4:3; ルカ 8:14; 創世記 3:17–18"> <span className="woj">また、ある種は茨の中に落ちた。茨が伸びてそれをふさぎ、実を結ばなかった。</span></span>
<span className="v" id="v8" data-v="8" data-xref="ヨハネ 15:5; コロサイ人への手紙 1:6; マルコ 4:20"> <span className="woj">また、ある種は良い地に落ち、芽生え、成長して実を結んだ。三十倍、六十倍、百倍もの実を結んだ。」</span></span>
<span className="v" id="v9" data-v="9" data-xref="マタイ 11:15; マルコ 4:23–24; ヨハネの黙示録 3:22"> そして言われた。<span className="woj">「聞く耳のある者は聞きなさい。」</span></span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="マタイ 13:10–17; マルコ 4:34; 箴言 13:20"> イエスが一人になられると、そばにいた人々が十二人と共に、たとえについて尋ねた。</span>
<span className="v" id="v11" data-v="11" data-xref="マタイ 11:25; ルカ 8:10; ヨハネの手紙第一 5:20"> イエスは彼らに言われた。<span className="woj">「あなたがたには神の御国の奥義が与えられている。しかし、外の人々には、すべてがたとえで語られる。</span></span>
<span className="v" id="v12" data-v="12" data-xref="イザヤ書 6:9–10; イザヤ書 44:18; マタイ 13:14–15"> <span className="woj">それは、『彼らは見ても見分けず、聞いても悟らない。そうでなければ、立ち返って罪を赦されるかもしれない。』」</span></span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="ヨハネの黙示録 3:19; マタイ 13:51–52; マルコ 7:17–18"> また彼らに言われた。<span className="woj">「このたとえが分からないのか。それなら、どうしてほかのすべてのたとえを理解できるだろうか。</span></span>
<span className="v" id="v14" data-v="14" data-xref="使徒の働き 8:4; マタイ 13:19; マタイ 13:37"> <span className="woj">種をまく人は、御言葉をまく。</span></span>
<span className="v" id="v15" data-v="15" data-xref="ペテロの手紙第一 5:8; マタイ 13:19; コリント人への第二の手紙 2:11"> <span className="woj">道端にまかれたものとは、御言葉を聞く人々のことである。彼らが聞くと、すぐにサタンが来て、その人たちの内にまかれた御言葉を奪い去る。</span></span>
<span className="v" id="v16" data-v="16" data-xref="マルコ 6:20; ルカ 8:13; マタイ 13:20–21"> <span className="woj">同じように、岩地にまかれたものとは、御言葉を聞くと、すぐに喜んで受け入れる人々のことである。</span></span>
<span className="v" id="v17" data-v="17" data-xref="マタイ 11:6; テサロニケ人への手紙第一 3:3–5; マタイ 12:31"> <span className="woj">しかし自分の内に根がなく、長続きしない。御言葉のために苦難や迫害が起こると、すぐにつまずいてしまう。</span></span>
<span className="v" id="v18" data-v="18" data-xref="ルカ 8:14; エレミヤ書 4:3; マタイ 13:22"> <span className="woj">また、茨の中にまかれたものとは、御言葉を聞く人々のことである。</span></span>
<span className="v" id="v19" data-v="19" data-xref="ヨハネの手紙第一 2:15–17; テモテへの手紙第一 6:9–10; テモテへの手紙第一 6:17"> <span className="woj">しかし、この世の思い煩いや富の惑わし、そのほかの欲望が入り込んで御言葉をふさぐため、実を結ばなくなる。</span></span>
<span className="v" id="v20" data-v="20" data-xref="コロサイ人への手紙 1:10; ルカ 8:15; ヨハネ 15:4–5"> <span className="woj">良い地にまかれたものとは、御言葉を聞いて受け入れ、実を結ぶ人々のことである。三十倍、六十倍、百倍もの実を結ぶ。」</span></span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="マタイ 5:15; ルカ 11:33; ルカ 8:16"> また彼らに言われた。<span className="woj">「明かりを持って来るのは、升</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="直訳すると「モディオン」。約九リットルの乾物を量るかご。">b</a></sup><span className="woj">の下や寝床の下に置くためだろうか。燭台の上に置くためではないか。</span></span>
<span className="v" id="v22" data-v="22" data-xref="ルカ 8:17; 伝道者の書 12:14; マタイ 10:26–27"> <span className="woj">隠されているものは、現されるためにあり、秘密にされているものは、明るみに出されるためにある。</span></span>
<span className="v" id="v23" data-v="23" data-xref="マルコ 4:9; マタイ 11:15; ヨハネの黙示録 2:29"> <span className="woj">聞く耳のある者は聞きなさい。」</span></span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="ヘブル人への手紙 2:1; ルカ 8:18; マタイ 7:2"> また彼らに言われた。<span className="woj">「何を聞くか、よく注意しなさい。あなたがたが量るその尺度で、あなたがたも量られ、聞く者にはさらに加えて与えられる。</span></span>
<span className="v" id="v25" data-v="25" data-xref="マタイ 13:12; ルカ 8:18; マタイ 25:28–29"> <span className="woj">持っている者はさらに与えられ、持っていない者は、持っているものまで取り上げられるからである。」</span></span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="マタイ 13:24; コリント人への第一の手紙 3:6–9; ルカ 8:11"> また言われた。<span className="woj">「神の御国は、人が地に種をまくようなものである。</span></span>
<span className="v" id="v27" data-v="27" data-xref="伝道者の書 11:5; テサロニケ人への第二の手紙 1:3; コリント人への第一の手紙 15:37–38"> <span className="woj">夜も昼も、眠り起きしているうちに、種は芽を出して成長する。しかし、どのようにして育つのか、その人は知らない。</span></span>
<span className="v" id="v28" data-v="28" data-xref="マルコ 4:31–32; ホセア書 6:3; ピリピ人への手紙 1:9–11"> <span className="woj">地はひとりでに実を結ぶ。初めに苗、次に穂、そして穂の中に実った穀粒ができる。</span></span>
<span className="v" id="v29" data-v="29" data-xref="ヨエル書 3:13; マタイ 13:30; マタイ 13:40–43"> <span className="woj">実が熟すと、すぐに鎌を入れる。収穫の時が来たからである。」</span></span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="マタイ 13:31–32; ルカ 13:18–21; 哀歌 2:13"> また言われた。<span className="woj">「神の御国を何にたとえようか。どのようなたとえで表そうか。</span></span>
<span className="v" id="v31" data-v="31" data-xref="使徒の働き 19:20; ルカ 13:18–19; ダニエル書 2:44–45"> <span className="woj">それは一粒のからし種のようなものである。地にまかれるときには、地上のどの種よりも小さい。</span></span>
<span className="v" id="v32" data-v="32" data-xref="ダニエル書 4:20–22; ダニエル書 4:10–14; エゼキエル書 31:3–10"> <span className="woj">しかし、まかれると成長して、どの野菜よりも大きくなり、大きな枝を伸ばす。空の鳥がその陰に巣を作れるほどになる。」</span></span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="マタイ 13:34–35; ヨハネ 16:12; ヘブル人への手紙 5:11–14"> イエスは、人々が受け止められる程度に応じて、このような多くのたとえで御言葉を語られた。</span>
<span className="v" id="v34" data-v="34" data-xref="ヨハネ 16:25; マルコ 4:10; マタイ 15:15–20"> たとえを用いずに語ることはなかった。しかし、ご自分の弟子たちには、ひそかにすべてを説明された。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="マタイ 8:18; ルカ 8:22; ルカ 8:25"> その日の夕方、イエスは弟子たちに、<span className="woj">「向こう岸へ渡ろう」</span>と言われた。</span>
<span className="v" id="v36" data-v="36" data-xref="マルコ 3:9; マルコ 4:1; マルコ 5:2"> 弟子たちは群衆を後にして、舟に乗っておられたイエスをそのままお連れした。ほかの小舟も一緒だった。</span>
<span className="v" id="v37" data-v="37" data-xref="マタイ 8:23–24; ヨブ記 1:19; ルカ 8:22–23"> すると激しい突風が起こり、波が舟の中に打ち込んできて、舟は水でいっぱいになった。</span>
<span className="v" id="v38" data-v="38" data-xref="ペテロの手紙第一 5:7; ヘブル人への手紙 4:15; イザヤ書 54:6–8"> しかしイエスは船尾で枕をして眠っておられた。弟子たちはイエスを起こして言った。「先生、私たちが死にそうなのに、何とも思われないのですか。」</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="詩篇 107:29; 詩篇 89:9; 詩篇 65:7"> イエスは起き上がると風を叱りつけ、湖に、<span className="woj">「静まれ。黙れ！」</span>と言われた。すると風はやみ、すっかり凪になった。</span>
<span className="v" id="v40" data-v="40" data-xref="ルカ 8:25; マタイ 8:26; マタイ 14:31"> そして弟子たちに言われた。<span className="woj">「なぜそんなに怖がるのか。どうして信仰がないのか。」</span></span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="ルカ 8:25; ヨブ記 38:11; 詩篇 89:7"> 彼らは非常に恐れ、互いに言った。「この方は、いったいどういう方なのだろう。風も湖も従うとは。」</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨハネ 4:47; ルカ 5:18; ルカ 18:35–38"> 数日後、イエスが再びカペナウムに入られると、家におられるということが知れ渡った。</span>
<span className="v" id="v2" data-v="2" data-xref="マルコ 2:13; マルコ 1:45; 詩篇 40:9"> すぐに大勢の人が集まり、戸口の辺りにさえ場所がないほどになった。イエスは彼らに御言葉を語られた。</span>
<span className="v" id="v3" data-v="3" data-xref="ルカ 5:18–26; マタイ 9:1–8; マタイ 4:24"> そこへ四人の男が、体の麻痺した人を運んで来た。</span>
<span className="v" id="v4" data-v="4" data-xref="ルカ 5:19; 申命記 22:8"> しかし、群衆のためにイエスのそばへ近づけなかったので、イエスのおられる所の屋根をはがして穴を開け、体の麻痺した人が横たわっている寝床をつり下ろした。</span>
<span className="v" id="v5" data-v="5" data-xref="マタイ 9:2; ヤコブの手紙 5:15; マルコ 2:9–10"> イエスは彼らの信仰を見て、体の麻痺した人に言われた。<span className="woj">「子よ、あなたの罪は赦されている。」</span></span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="ルカ 5:21–22; マルコ 8:17; コリント人への第二の手紙 10:5"> ところが、そこに何人かの律法学者が座っていて、心の中で考えていた。</span>
<span className="v" id="v7" data-v="7" data-xref="イザヤ書 43:25; ルカ 5:21; ミカ書 7:18"> 「なぜこの男は、こんな冒涜の言葉を口にするのか。神おひとりのほかに、だれが罪を赦せるだろうか。」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="詩篇 139:2; 使徒の働き 8:22; ルカ 5:22"> イエスは、彼らが心の中でそのように考えていることを、ご自分の霊ですぐに見抜き、言われた。<span className="woj">「なぜ心の中でそのようなことを考えているのか。</span></span>
<span className="v" id="v9" data-v="9" data-xref="ルカ 5:22–25; マタイ 9:5"> <span className="woj">体の麻痺した人に、『あなたの罪は赦されている』と言うのと、『起きて、寝床を取り上げて歩きなさい』と言うのと、どちらが易しいか。</span></span>
<span className="v" id="v10" data-v="10" data-xref="ダニエル書 7:13–14; マタイ 9:6–8; ヨハネ 5:20–27"> <span className="woj">しかし、人の子が地上で罪を赦す権威を持っていることを、あなたがたが知るために――」</span>そして、体の麻痺した人に言われた。</span>
<span className="v" id="v11" data-v="11" data-xref="マルコ 1:41; ヨハネ 5:8–10; ヨハネ 6:63"> <span className="woj">「あなたに言う。起きて寝床を取り上げ、自分の家に帰りなさい。」</span></span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="マタイ 9:33; マタイ 9:8; ルカ 7:16"> するとその人は立ち上がり、すぐに寝床を取り上げ、皆の前を通って出て行った。人々はみな驚き、「このようなことは、今まで見たことがない」と言って、神をあがめた。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="マルコ 4:1; 箴言 1:20–22; ルカ 19:48"> イエスは再び湖のほとりへ出て行かれた。群衆がみなイエスのもとに来たので、彼らを教えられた。</span>
<span className="v" id="v14" data-v="14" data-xref="ルカ 5:27–32; ルカ 6:15; マタイ 9:9–13"> 通りがかりに、アルパヨの子レビが収税所に座っているのをご覧になり、<span className="woj">「私について来なさい」</span>と言われた。レビは立ち上がり、イエスに従った。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="ルカ 15:1; ルカ 5:29–30; マタイ 9:10–11"> イエスがレビの家で食卓に着いておられると、大勢の徴税人や罪人も、イエスや弟子たちと共に食卓に着いた。このような人々が大勢いて、イエスに従っていたからである。</span>
<span className="v" id="v16" data-v="16" data-xref="ルカ 19:10; ルカ 19:7; ルカ 18:11"> 律法学者たちとパリサイ人たちは、イエスが罪人や徴税人と一緒に食事をしているのを見て、弟子たちに言った。「なぜ彼は徴税人や罪人と一緒に食べたり飲んだりするのか。」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="マタイ 9:12–13; ルカ 15:7; ルカ 5:31–32"> イエスはこれを聞いて、彼らに言われた。<span className="woj">「健康な人に医者は必要ない。必要なのは病人である。私が来たのは、義人を招くためではなく、罪人を悔い改めに招くためである。」</span></span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="ルカ 18:12; マタイ 6:18; マタイ 9:14–17"> ヨハネの弟子たちとパリサイ人たちは断食をしていた。人々がイエスのもとに来て尋ねた。「ヨハネの弟子たちとパリサイ人の弟子たちは断食するのに、なぜあなたの弟子たちは断食しないのですか。」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="マタイ 25:1–10; 創世記 29:22; 士師記 14:10–11"> イエスは彼らに言われた。<span className="woj">「花婿が一緒にいる間、花婿の友人たちは断食できるだろうか。花婿が一緒にいる限り、断食することはできない。</span></span>
<span className="v" id="v20" data-v="20" data-xref="ルカ 17:22; ヨハネの黙示録 21:9; イザヤ書 54:5"> <span className="woj">しかし、花婿が彼らから取り去られる日が来る。その日には、彼らも断食する。</span></span>
<span className="v" id="v21" data-v="21" data-xref="マタイ 9:16; コリント人への第一の手紙 10:13; イザヤ書 57:16"> <span className="woj">だれも、まだ縮んでいない布を古い衣服に縫いつけたりはしない。そんなことをすれば、新しい継ぎ切れが古い衣服を引き裂き、破れがもっとひどくなる。</span></span>
<span className="v" id="v22" data-v="22" data-xref="マタイ 9:17; 詩篇 119:83; ルカ 5:37–38"> <span className="woj">また、新しいぶどう酒を古い革袋に入れる人はいない。そんなことをすれば、ぶどう酒は革袋を破って流れ出し、革袋も失われる。新しいぶどう酒は新しい革袋に入れる。」</span></span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="マタイ 12:1–8; 申命記 23:24–25; ルカ 6:1–5"> ある安息日に、イエスは麦畑の中を通っておられた。弟子たちは歩きながら、麦の穂を摘み始めた。</span>
<span className="v" id="v24" data-v="24" data-xref="出エジプト記 20:10; ヘブル人への手紙 12:3; マタイ 12:2"> パリサイ人たちはイエスに言った。「見よ、なぜ彼らは安息日にしてはならないことをしているのですか。」</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="サムエル記第一 21:3–6; ルカ 10:26; マタイ 22:31"> イエスは彼らに言われた。<span className="woj">「ダビデが、自分も供の者たちも食べ物がなくて空腹だったとき、何をしたか、あなたがたは一度も読んだことがないのか。</span></span>
<span className="v" id="v26" data-v="26" data-xref="サムエル記第二 8:17; レビ記 24:5–9; サムエル記第一 21:1"> <span className="woj">アビヤタルが大祭司だった時代に、ダビデは神の家に入り、祭司のほかは食べてはならない供えのパンを食べ、供の者たちにも与えたではないか。」</span></span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="コロサイ人への手紙 2:16; ルカ 6:9; 申命記 5:14"> また彼らに言われた。<span className="woj">「安息日は人のために設けられたのであって、人が安息日のために造られたのではない。</span></span>
<span className="v" id="v28" data-v="28" data-xref="マタイ 12:8; ヨハネの黙示録 1:10; ヨハネ 5:17"> <span className="woj">だから、人の子は安息日の主でもある。」</span></span>
</div>
</div>

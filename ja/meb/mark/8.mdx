<div className="bible-chapter" lang="ja" dir="ltr" data-lang="ja" data-translation="meb" data-translation-id="jpn_meb" data-translation-label="MEB" data-book="MRK" data-book-slug="mark" data-book-name="マルコ" data-chapter="8" data-verses="38">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マタイ 15:32–39; マルコ 6:34–44"> そのころ、非常に大勢の群衆が集まっていたが、食べる物が何もなかった。イエスは弟子たちを呼び寄せて言われた。</span>
<span className="v" id="v2" data-v="2" data-xref="マタイ 9:36; ミカ書 7:19; 詩篇 103:13"> <span className="woj">「群衆をあわれに思う。もう三日も私と一緒にいるのに、食べる物がない。</span></span>
<span className="v" id="v3" data-v="3" data-xref="イザヤ書 40:31; 士師記 8:4–6; サムエル記第一 30:10–12"> <span className="woj">空腹のまま家に帰らせれば、途中で力尽きてしまうだろう。遠くから来ている人もいるからである。」</span></span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="列王記第二 4:42–44; 列王記第二 7:2; マルコ 6:52"> 弟子たちは答えた。「この人里離れた所で、どこからパンを手に入れて、この人たちを満腹させられるでしょうか。」</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="マタイ 14:15–17; マタイ 15:34; ルカ 9:13"> イエスは彼らに尋ねられた。<span className="woj">「パンはいくつあるか。」</span><br />彼らは言った。「七つです。」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="コロサイ人への手紙 3:17; マタイ 15:35–36; ヨハネ 6:10–11"> そこでイエスは、群衆に地面に座るよう命じられた。そして七つのパンを取り、感謝をささげてから裂き、配るよう弟子たちに渡された。弟子たちは群衆に配った。</span>
<span className="v" id="v7" data-v="7" data-xref="マタイ 14:19; ヨハネ 21:5; ルカ 24:41–42"> また、小さな魚が少しあった。イエスはそれらを祝福し、これも配るように言われた。</span>
<span className="v" id="v8" data-v="8" data-xref="列王記第二 4:42–44; 詩篇 145:16; マタイ 16:10"> 人々は食べて満腹した。そして、残ったパン切れを集めると、七つのかごになった。</span>
<span className="v" id="v9" data-v="9"> 食べた人はおよそ四千人であった。それからイエスは彼らを解散させられた。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="マタイ 15:39"> そしてすぐ弟子たちと共に舟に乗り、ダルマヌタ地方へ来られた。</span>
<span className="v" id="v11" data-v="11" data-xref="コリント人への第一の手紙 10:9; マタイ 12:38; 申命記 6:16"> パリサイ人たちが出て来て、イエスと議論を始めた。イエスを試そうとして、天からのしるしを求めたのである。</span>
<span className="v" id="v12" data-v="12" data-xref="マタイ 12:39–40; マルコ 7:34; マタイ 16:4"> イエスは心の中で深くため息をつき、言われた。<span className="woj">「なぜ、この世代は</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="ここで「世代」と訳された言葉（ゲネア）は、「民」「民族」「一族」とも訳せる。">a</a></sup><span className="woj">しるしを求めるのか。まことに、あなたがたに言う。この世代には、決してしるしは与えられない。」</span></span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="ヨハネ 12:36; 使徒の働き 13:45–46; 詩篇 81:12"> イエスは彼らを残し、再び舟に乗って向こう岸へ行かれた。</span>
<span className="v" id="v14" data-v="14" data-xref="マタイ 16:5"> 弟子たちはパンを持って来るのを忘れ、舟の中にはパンが一つしかなかった。</span>
<span className="v" id="v15" data-v="15" data-xref="コリント人への第一の手紙 5:6–8; マタイ 16:6; マタイ 16:11–12"> イエスは彼らを厳しく戒めて言われた。<span className="woj">「よく注意して、パリサイ人のパン種とヘロデのパン種に用心しなさい。」</span></span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="ルカ 9:46; ルカ 20:5; マタイ 16:7–8"> 弟子たちは、「これは自分たちにパンがないからだ」と互いに論じ合った。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="マルコ 6:52; イザヤ書 63:17; マルコ 2:8"> イエスはそれに気づいて言われた。<span className="woj">「なぜ、パンがないことを論じ合っているのか。まだ気づかず、悟らないのか。心がまだ頑なになっているのか。</span></span>
<span className="v" id="v18" data-v="18" data-xref="使徒の働き 28:26–27; マタイ 13:14–15; エレミヤ書 5:21"> <span className="woj">目がありながら見えないのか。耳がありながら聞こえないのか。覚えていないのか。</span></span>
<span className="v" id="v19" data-v="19" data-xref="ルカ 9:12–17; マタイ 14:17–21; ヨハネ 6:5–13"> <span className="woj">私が五つのパンを五千人に裂いて与えたとき、パン切れをかごいっぱいに幾つ集めたか。」</span><br />彼らは答えた。「十二です。」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="マタイ 15:34–38; マルコ 8:1–9"> <span className="woj">「七つのパンを四千人に裂いて与えたときは、パン切れをかごいっぱいに幾つ集めたか。」</span><br />彼らは答えた。「七つです。」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="マルコ 6:52; マタイ 16:11–12; マルコ 8:12"> イエスは彼らに言われた。<span className="woj">「まだ悟らないのか。」</span></span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="マタイ 11:21; マルコ 6:45; ルカ 10:13"> 彼らはベツサイダに来た。人々は目の見えない人をイエスのもとに連れて来て、触れてくださるよう願った。</span>
<span className="v" id="v23" data-v="23" data-xref="マルコ 7:33; ヨハネ 9:6–7; マルコ 5:23"> イエスはその人の手を取って村の外へ連れ出された。そして、その目に唾をつけ、両手を彼の上に置いて、何か見えるかと尋ねられた。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="イザヤ書 32:3; イザヤ書 29:18; コリント人への第一の手紙 13:9–12"> その人は目を上げて言った。「人が見えます。木のようなものが歩いています。」</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="ペテロの手紙第一 2:9; ペテロの第二の手紙 3:18; 箴言 4:18"> そこでイエスはもう一度、両手を彼の目の上に置かれた。彼がじっと見ると、視力が戻り、すべてのものがはっきり見えるようになった。</span>
<span className="v" id="v26" data-v="26" data-xref="マタイ 8:4; マルコ 8:23; マルコ 5:43"> イエスは彼を家に帰し、<span className="woj">「村に入ってはならない。村のだれにも話してはならない」</span>と言われた。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="マタイ 16:13–20; ルカ 9:18–20"> イエスは弟子たちと共に、カイサリア・フィリピ地方の村々へ出かけられた。その途中で弟子たちに尋ねられた。<span className="woj">「人々は、私をだれだと言っているか。」</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="ヨハネ 1:21; マタイ 14:2; マラキ書 4:5"> 彼らは答えた。「バプテスマのヨハネだと言う人もいれば、エリヤだと言う人もいます。また、預言者の一人だと言う人もいます。」</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="ヨハネの手紙第一 4:15; マタイ 16:15–16; ヨハネの手紙第一 5:1"> イエスは彼らに言われた。<span className="woj">「では、あなたがたは私をだれだと言うのか。」</span><br />ペテロが答えた。「あなたはキリストです。」</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="ルカ 9:21; マタイ 16:20; マルコ 9:9"> するとイエスは、ご自分のことをだれにも話さないよう彼らに命じられた。</span>
<span className="v" id="v31" data-v="31" data-xref="マルコ 10:33–34; ヨハネ 2:19; ルカ 24:26"> それから、人の子は多くの苦しみを受け、長老、祭司長、律法学者たちから拒まれ、殺され、三日後によみがえらなければならないと、彼らに教え始められた。</span>
<span className="v" id="v32" data-v="32" data-xref="マタイ 16:22; ヨハネ 16:25; ヨハネ 16:29"> イエスはこのことをはっきりと話された。するとペテロはイエスをわきへお連れし、いさめ始めた。</span>
<span className="v" id="v33" data-v="33" data-xref="マタイ 4:10; ピリピ人への手紙 3:19; ヨハネの手紙第一 2:15"> しかしイエスは振り向き、弟子たちを見て、ペテロを叱って言われた。<span className="woj">「サタンよ、私の後ろに下がれ。あなたは神のことではなく、人のことを思っている。」</span></span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="マタイ 10:38; ルカ 14:26–27; ヨハネ 10:27"> それからイエスは、弟子たちと共に群衆を呼び寄せて言われた。<span className="woj">「だれでも私の後について来たいと思うなら、自分を捨て、自分の十字架を負って、私について来なさい。</span></span>
<span className="v" id="v35" data-v="35" data-xref="テモテへの第二の手紙 2:11–13; コリント人への第一の手紙 9:23; ルカ 17:33"> <span className="woj">自分のいのちを救おうとする者はそれを失い、私と福音のために自分のいのちを失う者はそれを救うからである。</span></span>
<span className="v" id="v36" data-v="36" data-xref="マタイ 16:26; ルカ 9:25; 詩篇 49:17"> <span className="woj">人が全世界を手に入れても、自分のいのちを失うなら、何の益があるだろうか。</span></span>
<span className="v" id="v37" data-v="37" data-xref="詩篇 49:7–8; ペテロの手紙第一 1:18–19"> <span className="woj">人は自分のいのちと引き換えに、何を与えることができるだろうか。</span></span>
<span className="v" id="v38" data-v="38" data-xref="ルカ 12:8–9; ローマ人への手紙 1:16; ヨハネの手紙第一 2:23"> <span className="woj">姦淫に満ちた罪深いこの時代にあって、私と私の言葉を恥じる者を、人の子も、聖なる御使いたちと共に父の栄光のうちに来るとき、恥じる。」</span></span>
</div>
</div>

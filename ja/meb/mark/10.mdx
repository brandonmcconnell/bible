<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨハネ 10:40; マルコ 4:2; ヨハネ 11:7"> イエスはそこを発ち、ユダヤ地方とヨルダン川の向こう側へ来られた。群衆が再びイエスのもとに集まって来たので、いつものように彼らを教えられた。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="コリント人への第一の手紙 7:10–11; ルカ 11:53–54; ヨハネ 8:6"> パリサイ人たちがイエスを試そうとして近づき、「夫が妻を離縁することは、律法で許されていますか」と尋ねた。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="イザヤ書 8:20; ガラテヤ人への手紙 4:21; ルカ 10:25"> イエスは答えられた。<span className="woj">「モーセはあなたがたに何と命じたか。」</span></span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="申命記 24:1–4; マタイ 5:31–32; イザヤ書 50:1"> 彼らは言った。「モーセは離縁状を書いて妻を離縁することを許しました。」</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="マタイ 19:8; ネヘミヤ記 9:26; 使徒の働き 7:51"> しかしイエスは彼らに言われた。<span className="woj">「あなたがたの心が頑ななので、モーセはこの戒めを書いたのである。</span></span>
<span className="v" id="v6" data-v="6" data-xref="創世記 1:27; 創世記 5:2; 創世記 1:1"> <span className="woj">しかし、創造の初めから、神は人を男と女に造られた。</span></span>
<span className="v" id="v7" data-v="7" data-xref="創世記 2:24; マタイ 19:5–6; エペソ人への手紙 5:31"> <span className="woj">それゆえ、男は父と母を離れ、妻と結ばれ、</span></span>
<span className="v" id="v8" data-v="8" data-xref="エペソ人への手紙 5:28; 創世記 2:24; コリント人への第一の手紙 6:16"> <span className="woj">二人は一つの肉体となる。</span><span className="woj">こうして、彼らはもはや二人ではなく、一つの肉体である。</span></span>
<span className="v" id="v9" data-v="9" data-xref="ローマ人への手紙 7:1–3; 歴代誌上 7:10–13"> <span className="woj">だから、神が結び合わせたものを、人が引き離してはならない。」</span></span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="マルコ 9:33; マルコ 9:28; マルコ 4:10"> 家に入ってから、弟子たちはこのことについて再びイエスに尋ねた。</span>
<span className="v" id="v11" data-v="11" data-xref="マタイ 5:31–32; マタイ 19:9; コリント人への第一の手紙 7:10–11"> イエスは彼らに言われた。<span className="woj">「妻を離縁して別の女と結婚する者は、妻に対して姦淫を犯す。</span></span>
<span className="v" id="v12" data-v="12" data-xref="コリント人への第一の手紙 7:11; コリント人への第一の手紙 7:13"> <span className="woj">また、女が夫を離縁して別の男と結婚するなら、姦淫を犯す。」</span></span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="マタイ 19:13–15; ルカ 18:15–17; 出エジプト記 10:9–11"> 人々は、イエスに触れていただこうとして、幼い子どもたちを連れて来た。しかし弟子たちは、連れて来た人々を叱った。</span>
<span className="v" id="v14" data-v="14" data-xref="マタイ 19:14; マタイ 18:10; マタイ 18:4"> イエスはそれをご覧になると憤り、弟子たちに言われた。<span className="woj">「幼い子どもたちを私のところに来させなさい。止めてはならない。神の御国は、このような者たちのものだ。</span></span>
<span className="v" id="v15" data-v="15" data-xref="マタイ 18:3; ルカ 18:17; ヨハネ 3:3–6"> <span className="woj">まことに、あなたがたに言う。幼い子どものように神の御国を受け入れない者は、決してそこに入ることはない。」</span></span>
<span className="v" id="v16" data-v="16" data-xref="マルコ 9:36; イザヤ書 40:11; ヨハネ 21:15–17"> そして子どもたちを腕に抱き、彼らの上に手を置いて祝福された。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="マタイ 19:16–30; ルカ 18:18–30; ローマ人への手紙 2:7"> イエスが道に出ようとされると、一人の人が走り寄り、御前にひざまずいて尋ねた。「良い先生、永遠のいのちを受け継ぐためには、何をすればよいでしょうか。」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="ルカ 18:19; マタイ 19:17; ローマ人への手紙 3:12"> イエスは彼に言われた。<span className="woj">「なぜ私を良いと言うのか。神お一人のほかに、良い者はいない。</span></span>
<span className="v" id="v19" data-v="19" data-xref="出エジプト記 20:12–17; ローマ人への手紙 13:9; ヤコブの手紙 2:11"> <span className="woj">あなたは戒めを知っている。『殺してはならない』『姦淫してはならない』『盗んではならない』『偽りのあかしをしてはならない』『だまし取ってはならない』『父と母を敬いなさい。』」</span></span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="エゼキエル書 33:31–32; テモテへの第二の手紙 3:5; ピリピ人への手紙 3:6"> 彼はイエスに言った。「先生、私はこれらをみな、幼いころから守ってきました。」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="マタイ 6:19–21; ヨハネの黙示録 2:4; ルカ 18:22"> イエスは彼を見つめ、慈しんで言われた。<span className="woj">「あなたには一つ欠けていることがある。行って、持っている物をすべて売り、貧しい人々に与えなさい。そうすれば、天に宝を持つことになる。それから来て、十字架を負い、私について来なさい。」</span></span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="ヨハネの手紙第一 2:15–16; テモテへの手紙第一 6:9–10; ルカ 12:15"> しかし彼はこの言葉に顔を曇らせ、悲しみながら立ち去った。多くの財産を持っていたからである。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="コリント人への第一の手紙 1:26; ルカ 18:24; マルコ 3:5"> イエスは辺りを見回し、弟子たちに言われた。<span className="woj">「富を持つ者が神の御国に入るのは、なんと難しいことか。」</span></span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="ヤコブの手紙 5:1–3; 箴言 11:28; 詩篇 52:7"> 弟子たちはその言葉に驚いた。しかしイエスは再び彼らに言われた。<span className="woj">「子たちよ、富に頼る者が神の御国に入るのは、なんと難しいことか。</span></span>
<span className="v" id="v25" data-v="25" data-xref="マタイ 19:24–25; ルカ 18:25; マタイ 23:24"> <span className="woj">金持ちが神の御国に入るより、らくだが針の穴を通るほうが易しい。」</span></span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="使徒の働き 16:31; コリント人への第二の手紙 11:23; ローマ人への手紙 10:9–13"> 弟子たちはますます驚き、イエスに言った。「それでは、だれが救われるのでしょうか。」</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="マタイ 19:26; エレミヤ書 32:27; ヨブ記 42:2"> イエスは彼らを見つめて言われた。<span className="woj">「人には不可能だが、神にはそうではない。神にはすべてのことが可能だからである。」</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="マタイ 19:27–30; ルカ 18:28–30; ルカ 14:33"> ペテロがイエスに言い始めた。「見よ、私たちはすべてを捨てて、あなたに従って来ました。」</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="コリント人への第一の手紙 9:23; マタイ 5:10–11; マルコ 8:35"> イエスは言われた。<span className="woj">「まことに、あなたがたに言う。私と福音のために、家、兄弟、姉妹、父、母、妻、子ども、土地を後にした者で、</span></span>
<span className="v" id="v30" data-v="30" data-xref="ルカ 18:30; ピリピ人への手紙 3:8; コリント人への第二の手紙 6:10"> <span className="woj">今この世で、迫害と共に、家、兄弟、姉妹、母、子ども、土地を百倍受け、来たるべき世で永遠のいのちを受けない者はいない。</span></span>
<span className="v" id="v31" data-v="31" data-xref="マタイ 19:30; ルカ 13:30; マタイ 20:16"> <span className="woj">しかし、先の者の多くが後になり、後の者が先になる。」</span></span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="マタイ 20:17–19; ルカ 18:31–34; ルカ 9:51"> 一行はエルサレムへ上る道を進んでいた。イエスが先頭に立って行かれるので、弟子たちは驚き、ついて行く者たちは恐れていた。イエスは再び十二人をそばに呼び、これからご自分に起ころうとしていることを話し始められた。</span>
<span className="v" id="v33" data-v="33" data-xref="マタイ 27:2; マタイ 20:17–19; マルコ 8:31"> <span className="woj">「見よ、私たちはエルサレムへ上って行く。人の子は祭司長たちと律法学者たちに引き渡される。彼らは人の子を死刑に定め、異邦人に引き渡す。</span></span>
<span className="v" id="v34" data-v="34" data-xref="マタイ 26:67; マタイ 16:21; マルコ 14:65"> <span className="woj">そして人の子をあざけり、唾をかけ、むち打ち、殺す。しかし三日目に、彼はよみがえる。」</span></span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="マタイ 20:20–28; サムエル記第二 14:4–11; 列王記第一 2:20"> ゼベダイの子ヤコブとヨハネがイエスに近づいて言った。「先生、私たちがお願いすることをかなえていただきたいのです。」</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="ヨハネ 15:7; 列王記第一 3:5–15; マルコ 10:51"> イエスは彼らに言われた。<span className="woj">「何をしてほしいのか。」</span></span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="マタイ 19:28; マルコ 16:19; ルカ 24:26"> 彼らは言った。「あなたの栄光のうちで、私たちの一人をあなたの右に、もう一人を左に座らせてください。」</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="ルカ 12:50; マタイ 20:21–22; 詩篇 75:8"> しかしイエスは彼らに言われた。<span className="woj">「あなたがたは、自分が何を求めているのか分かっていない。私が飲む杯を飲み、私が受けるバプテスマを受けられるか。」</span></span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="使徒の働き 12:2; ヨハネの黙示録 1:9; ヨハネ 17:14"> 彼らは言った。「できます。」<br />イエスは彼らに言われた。<span className="woj">「確かにあなたがたは、私が飲む杯を飲み、私が受けるバプテスマを受ける。</span></span>
<span className="v" id="v40" data-v="40" data-xref="マタイ 20:23; マタイ 25:34; ヨハネ 17:24"> <span className="woj">しかし、私の右と左に座らせることは、私が与えることではなく、それが備えられている人々に与えられる。」</span></span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="マタイ 20:24; 箴言 13:10; ローマ人への手紙 12:10"> ほかの十人はこれを聞くと、ヤコブとヨハネに腹を立て始めた。</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="ペテロの手紙第一 5:3; ルカ 22:25; マタイ 20:25"> イエスは彼らを呼び寄せて言われた。<span className="woj">「あなたがたも知っているように、異邦人の支配者と認められている者たちは、人々の上に君臨し、偉い者たちは権力を振るっている。</span></span>
<span className="v" id="v43" data-v="43" data-xref="マタイ 23:8–12; ルカ 14:11; マルコ 9:35"> <span className="woj">しかし、あなたがたの間では、そうであってはならない。あなたがたの間で偉くなりたい者は、あなたがたに仕える者となりなさい。</span></span>
<span className="v" id="v44" data-v="44"> <span className="woj">あなたがたの間で一番になりたい者は、すべての人の僕となりなさい。</span></span>
<span className="v" id="v45" data-v="45" data-xref="マタイ 20:28; ピリピ人への手紙 2:5–8; コリント人への第二の手紙 8:9"> <span className="woj">人の子も、仕えられるためではなく仕えるために、また多くの人のための贖いの代価として、自分のいのちを与えるために来たのである。」</span></span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="ルカ 18:35–1; マタイ 20:29–34; ヨハネ 9:8"> 一行はエリコに来た。イエスが弟子たちや大勢の群衆と共にエリコを出て行かれるとき、ティマイの子で、目の見えない物乞いバルティマイが道端に座っていた。</span>
<span className="v" id="v47" data-v="47" data-xref="マルコ 1:24; マタイ 9:27; ヨハネの黙示録 22:16"> 彼はナザレのイエスだと聞くと、「ダビデの子イエスよ、私をあわれんでください」と叫び始めた。</span>
<span className="v" id="v48" data-v="48" data-xref="エレミヤ書 29:13; マルコ 7:26–29; ヘブル人への手紙 5:7"> 多くの人が彼を黙らせようと叱ったが、彼はますます、「ダビデの子よ、私をあわれんでください」と叫んだ。</span>
</div>
<div className="bp">
<span className="v" id="v49" data-v="49" data-xref="ルカ 18:40; マタイ 20:32–34; ヨハネ 11:28"> イエスは立ち止まり、<span className="woj">「あの人を呼びなさい」</span>と言われた。<br />人々は目の見えない人を呼んで言った。「元気を出しなさい。立ちなさい。あなたを呼んでおられる。」</span>
</div>
<div className="bp">
<span className="v" id="v50" data-v="50" data-xref="ピリピ人への手紙 3:7–9; ヘブル人への手紙 12:1"> 彼は上着を脱ぎ捨て、跳び上がってイエスのもとに来た。</span>
</div>
<div className="bp">
<span className="v" id="v51" data-v="51" data-xref="ルカ 18:41–43; マルコ 10:36; マタイ 7:7"> イエスは彼に尋ねられた。<span className="woj">「私に何をしてほしいのか。」</span><br />目の見えない人は言った。「ラボニ、<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「ラボニ」は、「偉大な教師」を意味するアラム語の音訳です。">a</a></sup>もう一度見えるようになりたいのです。」</span>
</div>
<div className="bp">
<span className="v" id="v52" data-v="52" data-xref="マタイ 9:22; 使徒の働き 26:18; マルコ 8:25"> イエスは彼に言われた。<span className="woj">「行きなさい。あなたの信仰があなたを癒した。」</span>彼はすぐに見えるようになり、道を進むイエスについて行った。</span>
</div>
</div>

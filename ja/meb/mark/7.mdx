<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マタイ 15:1–20; マルコ 3:22; ルカ 5:17"> さて、パリサイ人たちと、エルサレムから来た律法学者たちの何人かが、イエスのもとに集まった。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒の働き 10:28; マタイ 7:3–5; ローマ人への手紙 14:14"> 彼らは、弟子たちのうちの何人かが汚れた手、すなわち洗っていない手でパンを食べているのを見て、とがめた。</span>
<span className="v" id="v3" data-v="3" data-xref="ガラテヤ人への手紙 1:14; マルコ 7:13; コロサイ人への手紙 2:8"> （パリサイ人をはじめユダヤ人はみな、長老たちの言い伝えを守り、手と腕を念入りに洗わなければ食事をしない。</span>
<span className="v" id="v4" data-v="4" data-xref="ヘブル人への手紙 9:10; マタイ 23:25; ルカ 11:38–39"> また、市場から帰ったときは、身を洗わなければ食事をしない。このほかにも受け継いで守っていることが多くあり、杯、水差し、青銅の器、寝台を洗うこともそうである。）</span>
<span className="v" id="v5" data-v="5" data-xref="テサロニケ人への第二の手紙 3:6; 使徒の働き 21:21; マタイ 15:2"> そこで、パリサイ人たちと律法学者たちはイエスに尋ねた。「なぜ、あなたの弟子たちは長老たちの言い伝えに従わず、洗っていない手でパンを食べるのですか。」</span>
</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="イザヤ書 29:13; テトス 1:16; マタイ 15:7–9"> イエスは彼らに答えられた。<span className="woj">「イザヤは、あなたがた偽善者について、まさにそのとおり預言した。こう書かれている。</span><br /><span className="pl pl-1 woj">『この民は唇で私を敬うが、</span><br /><span className="pl pl-2 woj">その心は私から遠く離れている。</span></span>
<span className="v" id="v7" data-v="7" data-xref="イザヤ書 29:13; マタイ 15:9; ヤコブの手紙 1:26"> <span className="pl pl-1 woj">彼らは人間の戒めを教えとして教え、</span><br /><span className="pl pl-2 woj">むなしく私を礼拝している。』」</span></span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="マルコ 7:3–4; イザヤ書 1:12"> <span className="woj">「あなたがたは神の戒めを捨て、人間の言い伝えを固く守っている。水差しや杯を洗い、そのほかにも同じようなことを数多く行っている。」</span></span>
<span className="v" id="v9" data-v="9" data-xref="エレミヤ書 44:16–17; ガラテヤ人への手紙 2:21; イザヤ書 29:13"> また彼らに言われた。<span className="woj">「あなたがたは自分たちの言い伝えを守るために、実に巧みに神の戒めを退けている。</span></span>
<span className="v" id="v10" data-v="10" data-xref="出エジプト記 21:17; 出エジプト記 20:12; 申命記 5:16"> <span className="woj">モーセは、『父と母を敬いなさい』</span><span className="woj">また、『父や母を悪く言う者は、必ず死に定められる』と言った。</span></span>
<span className="v" id="v11" data-v="11" data-xref="マタイ 23:18; テモテへの手紙第一 5:4–8; マタイ 15:5"> <span className="woj">ところが、あなたがたは言う。『もし人が父や母に、「私から受けるはずのものはコルバンです」と言うなら』」</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="コルバンとは、神にささげられた供え物を意味するヘブル語である。">a</a></sup>すなわち「神にささげたものです」と言うなら、</span>
<span className="v" id="v12" data-v="12"> <span className="woj">「その人が父や母のために何かすることを、もはや許さない。</span></span>
<span className="v" id="v13" data-v="13" data-xref="マルコ 7:9; テトス 1:14; マタイ 5:17–20"> <span className="woj">こうして、あなたがたは自分たちが伝えてきた言い伝えによって、神の御言葉を無効にしている。このようなことを数多く行っている。」</span></span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="マタイ 15:10; イザヤ書 6:9; 箴言 8:5"> イエスは再び群衆をみな呼び寄せ、言われた。<span className="woj">「あなたがたはみな、私の言うことを聞いて悟りなさい。</span></span>
<span className="v" id="v15" data-v="15" data-xref="箴言 4:23; レビ記 11:42–47; テトス 1:15"> <span className="woj">人の外から入って来るもので、その人を汚すことのできるものは何もない。人から出て来るものこそ、人を汚すのである。</span></span>
<span className="v" id="v16" data-v="16"> <span className="woj">聞く耳のある者は聞きなさい。」</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="NU本文では第十六節が省かれている。">b</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="マタイ 15:15; マタイ 13:36; マルコ 9:28"> イエスが群衆を離れて家に入られると、弟子たちはこのたとえについて尋ねた。</span>
<span className="v" id="v18" data-v="18" data-xref="マタイ 15:16–17; ヘブル人への手紙 5:11; イザヤ書 28:9–10"> イエスは彼らに言われた。<span className="woj">「あなたがたも、まだ悟らないのか。外から人の中に入るものは何であれ、その人を汚すことができないと分からないのか。</span></span>
<span className="v" id="v19" data-v="19" data-xref="マタイ 15:17; コリント人への第一の手紙 6:13; コロサイ人への手紙 2:21–22"> <span className="woj">それは心に入るのではなく、腹に入り、やがて便所へ出される。こうして、すべての食物は清いものとなる。」</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="NU本文では、イエスの直接話法と疑問文は「便所」で終わり、節の末尾は「こうしてイエスは、すべての食物を清いと宣言された」となっている。">c</a></sup></span>
<span className="v" id="v20" data-v="20" data-xref="ヤコブの手紙 3:6; ヤコブの手紙 1:14–15; ヤコブの手紙 4:1"> また言われた。<span className="woj">「人から出て来るもの、それが人を汚す。</span></span>
<span className="v" id="v21" data-v="21" data-xref="エレミヤ書 17:9; ローマ人への手紙 8:7–8; ヤコブの手紙 4:1–3"> <span className="woj">内側から、すなわち人の心から、悪い思い、姦淫、淫行、殺人、盗み、</span></span>
<span className="v" id="v22" data-v="22" data-xref="マタイ 20:15; マタイ 6:23; ペテロの手紙第一 2:15"> <span className="woj">貪欲、悪意、欺き、好色、ねたみ、冒涜、高慢、愚かさが出て来る。</span></span>
<span className="v" id="v23" data-v="23" data-xref="マルコ 7:15; テトス 1:15; コリント人への第一の手紙 3:17"> <span className="woj">これらの悪はみな内側から出て来て、人を汚すのである。」</span></span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="マタイ 15:21–28; マタイ 11:21; エゼキエル書 28:2"> イエスはそこを立ち、ティルスとシドンの地方へ行かれた。そして、ある家に入り、だれにも知られたくないと思っておられたが、隠れていることはできなかった。</span>
<span className="v" id="v25" data-v="25" data-xref="マタイ 15:22; マルコ 9:17–23; 使徒の働き 10:25–26"> 汚れた霊につかれた幼い娘を持つ女が、イエスのことを聞き、すぐに来てその足元にひれ伏したからである。</span>
<span className="v" id="v26" data-v="26" data-xref="マタイ 15:22; イザヤ書 49:12; ガラテヤ人への手紙 3:28"> この女はギリシャ人で、シリア・フェニキアの生まれであった。彼女は、娘から悪霊を追い出してくださるようイエスに願った。</span>
<span className="v" id="v27" data-v="27" data-xref="マタイ 15:23–28; マタイ 7:6; 使徒の働き 22:21"> しかしイエスは彼女に言われた。<span className="woj">「まず子どもたちを十分に食べさせなければならない。子どもたちのパンを取って、小犬に投げてやるのはよくない。」</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="ローマ人への手紙 10:12; ローマ人への手紙 3:29; 使徒の働き 11:17–18"> 彼女は答えた。「主よ、そのとおりです。それでも、食卓の下の小犬も、子どもたちのパンくずを食べます。」</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="イザヤ書 66:2; マタイ 5:3; ヨハネの手紙第一 3:8"> イエスは彼女に言われた。<span className="woj">「その言葉のゆえに、帰りなさい。悪霊はあなたの娘から出て行った。」</span></span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="ヨハネの手紙第一 3:8; ヨハネ 4:50–52"> 女が家に帰ると、子どもは寝床に横たわっており、悪霊は出て行っていた。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="マルコ 5:20; マタイ 15:29–31; マタイ 4:25"> イエスは再びティルスとシドンの地方を去り、デカポリス地方を通って、ガリラヤ湖へ来られた。</span>
<span className="v" id="v32" data-v="32" data-xref="ルカ 11:14; マルコ 5:23; マタイ 9:32–33"> 人々は、耳が聞こえず、話すことにも障害のある人をイエスのもとに連れて来て、その人に手を置いてくださるよう願った。</span>
<span className="v" id="v33" data-v="33" data-xref="マルコ 8:23; ヨハネ 9:6–7; マルコ 5:40"> イエスはその人だけを群衆から離れた所に連れ出し、ご自分の指を彼の両耳に入れ、唾をつけてその舌に触れられた。</span>
<span className="v" id="v34" data-v="34" data-xref="ヨハネ 11:41; マルコ 5:41; マルコ 6:41"> そして天を見上げ、深く息をついて、<span className="woj">「エパタ」</span>、すなわち、<span className="woj">「開け」</span>と言われた。</span>
<span className="v" id="v35" data-v="35" data-xref="イザヤ書 35:5–6; 詩篇 33:9; マルコ 2:12"> するとすぐに彼の耳は開き、舌のもつれも解けて、はっきり話せるようになった。</span>
<span className="v" id="v36" data-v="36" data-xref="マタイ 8:4; マルコ 8:26; マルコ 3:12"> イエスは、このことをだれにも話さないよう人々に命じられた。しかし、命じれば命じるほど、彼らはますます広く言い広めた。</span>
<span className="v" id="v37" data-v="37" data-xref="マルコ 6:51; マルコ 5:42; 出エジプト記 4:10–11"> 人々はこの上なく驚いて言った。「この方がなさったことは、何もかもすばらしい。耳の聞こえない人を聞こえるようにし、口の利けない人を話せるようにされる。」</span>
</div>

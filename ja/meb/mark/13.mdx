<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マタイ 24:1–51; エゼキエル書 11:22–23; エゼキエル書 10:19"> イエスが神殿から出て行かれると、弟子の一人が言った。「先生、ご覧ください。なんと見事な石、なんと見事な建物でしょう。」</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="ルカ 21:6; マタイ 24:2; 列王記第一 9:7–8"> イエスは彼に言われた。<span className="woj">「この大きな建物を見ているのか。ここでは、石が一つもほかの石の上に残らず、すべて崩される。」</span></span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="マタイ 21:1; マルコ 4:34; マルコ 14:33"> イエスが神殿の向かい側にあるオリーブ山に座っておられると、ペテロ、ヤコブ、ヨハネ、アンデレがひそかに尋ねた。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒の働き 1:6–7; マタイ 24:3; ダニエル書 12:6"> 「お話しください。そのことはいつ起こるのでしょうか。それらがすべて成就しようとするときには、どんなしるしがあるのでしょうか。」</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="コロサイ人への手紙 2:8; エペソ人への手紙 5:6; エレミヤ書 29:8"> イエスは彼らに答え始められた。<span className="woj">「だれにも惑わされないように気をつけなさい。</span></span>
<span className="v" id="v6" data-v="6" data-xref="マルコ 13:22; エレミヤ書 23:21–25; ヨハネ 8:24"> <span className="woj">多くの者が私の名によって来て、『私がそれだ』</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="または「私はある」。">a</a></sup><span className="woj">と言い、多くの人を惑わすからである。</span></span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="ルカ 21:9–11; ヨハネ 14:27; マタイ 24:6–7"> <span className="woj">戦争や戦争のうわさを聞いても、動揺してはならない。これらは起こらなければならないが、まだ終わりではない。</span></span>
<span className="v" id="v8" data-v="8" data-xref="マタイ 24:8; イザヤ書 37:3; 詩篇 48:6"> <span className="woj">民族は民族に、国は国に敵対して立ち上がる。各地に地震があり、飢饉や騒乱が起こる。これらは産みの苦しみの始まりである。</span></span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="マタイ 10:17–18; ヨハネ 16:2; ピリピ人への手紙 1:29"> <span className="woj">しかし、あなたがたは自分自身に気をつけなさい。人々はあなたがたを議会に引き渡し、あなたがたは会堂で打たれる。また、私のために総督や王たちの前に立たされる。それは彼らへのあかしとなるためである。</span></span>
<span className="v" id="v10" data-v="10" data-xref="マタイ 24:14; コロサイ人への手紙 1:23; ローマ人への手紙 10:18"> <span className="woj">まず、すべての国民に福音が宣べ伝えられなければならない。</span></span>
<span className="v" id="v11" data-v="11" data-xref="ルカ 21:14–15; ルカ 12:11–12; マタイ 10:19–21"> <span className="woj">人々があなたがたを連れて行って引き渡すとき、何を話そうかと前もって心配したり、考えておいたりしてはならない。その時に与えられることを話しなさい。話すのはあなたがたではなく、聖霊だからである。</span></span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="マタイ 10:21; ルカ 12:52–53; ルカ 21:16"> <span className="woj">兄弟は兄弟を、父は子を死に引き渡す。子どもたちは両親に逆らって立ち上がり、彼らを死なせる。</span></span>
<span className="v" id="v13" data-v="13" data-xref="ヨハネ 15:18–19; マタイ 10:22; マタイ 24:13"> <span className="woj">あなたがたは私の名のために、すべての人から憎まれる。しかし、最後まで耐え忍ぶ者は救われる。</span></span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="ダニエル書 9:27; ダニエル書 12:11; ダニエル書 11:31"> <span className="woj">預言者ダニエルが語った『荒廃をもたらす忌まわしいもの』が、</span><span className="woj">立ってはならない所に立っているのを見たなら」</span>――読者は悟りなさい――<span className="woj">「ユダヤにいる者たちは山へ逃げなさい。</span></span>
<span className="v" id="v15" data-v="15" data-xref="ルカ 17:31–33; ヘブル人への手紙 11:7; ピリピ人への手紙 3:7–8"> <span className="woj">屋上にいる者は、家から何かを取り出そうとして下りたり、中に入ったりしてはならない。</span></span>
<span className="v" id="v16" data-v="16"> <span className="woj">畑にいる者は、上着を取りに戻ってはならない。</span></span>
<span className="v" id="v17" data-v="17" data-xref="哀歌 4:10; ルカ 23:29; ホセア書 9:14"> <span className="woj">その日には、身重の女たちと乳飲み子に乳を飲ませている女たちは災いである。</span></span>
<span className="v" id="v18" data-v="18"> <span className="woj">逃げるのが冬にならないように祈りなさい。</span></span>
<span className="v" id="v19" data-v="19" data-xref="ダニエル書 12:1; ヨエル書 2:2; マタイ 24:21"> <span className="woj">その日には、神が世界を創造された初めから今に至るまでなかった、また今後もないほどの苦難がある。</span></span>
<span className="v" id="v20" data-v="20" data-xref="マタイ 24:22; ゼカリヤ書 13:8–9; イザヤ書 65:8–9"> <span className="woj">もし主がその日々を短くされなかったなら、だれも救われない。しかし主は、ご自分が選ばれた者たちのために、その日々を短くされた。</span></span>
<span className="v" id="v21" data-v="21" data-xref="ルカ 21:8; マタイ 24:23–25; マタイ 24:5"> <span className="woj">そのとき、だれかがあなたがたに、『見よ、キリストはここにいる』とか、『見よ、あそこにいる』と言っても、信じてはならない。</span></span>
<span className="v" id="v22" data-v="22" data-xref="マタイ 24:24; テサロニケ人への第二の手紙 2:8–14; マルコ 13:6"> <span className="woj">偽キリストや偽預言者たちが現れ、できることなら選ばれた者たちさえ惑わそうとして、しるしや不思議なわざを行うからである。</span></span>
<span className="v" id="v23" data-v="23" data-xref="ペテロの第二の手紙 3:17; マルコ 13:5; ヨハネ 14:29"> <span className="woj">だから、あなたがたは気をつけなさい。</span><br /><span className="woj">見よ、私はすべてのことを前もってあなたがたに話した。</span></span>
<span className="v" id="v24" data-v="24" data-xref="イザヤ書 13:10; 使徒の働き 2:19–20; ヨハネの黙示録 6:12–14"> <span className="woj">しかし、その日には、その苦難の後、太陽は暗くなり、月は光を放たず、</span></span>
<span className="v" id="v25" data-v="25" data-xref="イザヤ書 34:4; ヨハネの黙示録 6:13"> <span className="woj">星は空から落ち、天にある諸力は揺り動かされる。</span></span>
<span className="v" id="v26" data-v="26" data-xref="ヨハネの黙示録 1:7; マタイ 16:27; マタイ 24:30"> <span className="woj">そのとき人々は、人の子が大いなる力と栄光を帯び、雲に乗って来るのを見る。</span></span>
<span className="v" id="v27" data-v="27" data-xref="ゼカリヤ書 2:6; マタイ 24:31; 申命記 30:4"> <span className="woj">そのとき、人の子は御使いたちを遣わし、地の果てから天の果てまで、四方から選ばれた者たちを集める。</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="ルカ 21:29–31; マタイ 24:32–33"> <span className="woj">いちじくの木から、このたとえを学びなさい。枝が柔らかくなって葉が出ると、夏が近いことが分かる。</span></span>
<span className="v" id="v29" data-v="29" data-xref="ペテロの手紙第一 4:17–18; ヤコブの手紙 5:9; エゼキエル書 12:25–28"> <span className="woj">同じように、あなたがたも、これらのことが起こるのを見たなら、その時が近く、戸口まで来ていることを知りなさい。</span></span>
<span className="v" id="v30" data-v="30" data-xref="マタイ 24:34; ルカ 21:32; マタイ 16:28"> <span className="woj">まことに、あなたがたに言う。これらのことがすべて起こるまでは、この世代</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="「世代」と訳された言葉（ゲネア）は、「民族」「一族」「民」とも訳すことができる。">b</a></sup><span className="woj">は決して過ぎ去らない。</span></span>
<span className="v" id="v31" data-v="31" data-xref="イザヤ書 40:8; イザヤ書 51:6; マタイ 24:35"> <span className="woj">天と地は過ぎ去るが、私の言葉は決して過ぎ去らない。</span></span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="使徒の働き 1:7; マタイ 24:36–42; マタイ 25:13"> <span className="woj">しかし、その日、その時はだれも知らない。天にいる御使いたちも、子も知らず、父だけが知っておられる。</span></span>
<span className="v" id="v33" data-v="33" data-xref="エペソ人への手紙 6:18; ルカ 12:40; ローマ人への手紙 13:11–12"> <span className="woj">気をつけ、目を覚まし、祈っていなさい。その時がいつなのか、あなたがたは知らないからである。</span></span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="マタイ 25:14–30; ヨハネ 10:3; ルカ 12:36–40"> <span className="woj">それは、外国へ旅立つ人のようなものである。彼は家を後にし、僕たちに権限を与え、それぞれに仕事を割り当て、門番には目を覚ましているよう命じた。</span></span>
<span className="v" id="v35" data-v="35" data-xref="マルコ 13:33; マタイ 24:42; マタイ 24:44"> <span className="woj">だから、目を覚ましていなさい。家の主人がいつ帰って来るか、夕方か、真夜中か、鶏が鳴くころか、明け方か、あなたがたは知らないからである。</span></span>
<span className="v" id="v36" data-v="36" data-xref="テサロニケ人への手紙第一 5:6–7; ローマ人への手紙 13:11–14; マタイ 24:48–51"> <span className="woj">主人が突然帰って来て、あなたがたが眠っているのを見つけることがないようにしなさい。</span></span>
<span className="v" id="v37" data-v="37" data-xref="マルコ 13:33; ルカ 12:41–46; マルコ 13:35"> <span className="woj">私があなたがたに言うことを、すべての人に言う。目を覚ましていなさい。」</span></span>
</div>

<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="イザヤ書 5:1–4; マルコ 13:34; 雅歌 8:11–12"> イエスはたとえで彼らに話し始められた。<span className="woj">「ある人がぶどう園を造り、周りに垣根を巡らし、ぶどう搾り場の穴を掘り、見張りの塔を建てた。そして農夫たちに貸して、外国へ旅立った。</span></span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネ 15:1–8; ヘブル人への手紙 1:1; エレミヤ書 44:4"> <span className="woj">収穫の時になると、ぶどう園の収穫の分け前を農夫たちから受け取るために、一人の僕を彼らのところへ遣わした。</span></span>
<span className="v" id="v3" data-v="3" data-xref="テサロニケ人への手紙第一 2:15; ネヘミヤ記 9:26; エレミヤ書 29:26"> <span className="woj">ところが、彼らはその僕を捕らえて打ちたたき、何も持たせずに帰した。</span></span>
<span className="v" id="v4" data-v="4"> <span className="woj">そこで主人は再び別の僕を遣わした。農夫たちは彼に石を投げつけて頭に傷を負わせ、辱めて帰した。</span></span>
<span className="v" id="v5" data-v="5" data-xref="マタイ 22:6; マタイ 23:37; ネヘミヤ記 9:30"> <span className="woj">さらに別の僕を遣わすと、彼らはその僕を殺した。ほかにも多くの僕を遣わしたが、ある者を打ちたたき、ある者を殺した。</span></span>
<span className="v" id="v6" data-v="6" data-xref="ヘブル人への手紙 1:1–2; マタイ 3:17; ヨハネ 1:34"> <span className="woj">主人にはなお一人、愛する息子がいた。『私の息子なら敬うだろう』と言って、最後にその息子を彼らのところへ遣わした。</span></span>
<span className="v" id="v7" data-v="7" data-xref="創世記 37:20; マタイ 2:16; 使徒の働き 2:23"> <span className="woj">しかし農夫たちは互いに言った。『これは跡取りだ。さあ、殺そう。そうすれば、相続財産はわれわれのものになる。』</span></span>
<span className="v" id="v8" data-v="8" data-xref="マタイ 21:39; ルカ 20:15; マタイ 21:33"> <span className="woj">彼らは息子を捕らえて殺し、ぶどう園の外に投げ捨てた。</span></span>
<span className="v" id="v9" data-v="9" data-xref="ローマ人への手紙 10:20–12; マタイ 21:43; ルカ 19:27"> <span className="woj">さて、ぶどう園の主人はどうするだろうか。やって来て農夫たちを滅ぼし、ぶどう園をほかの人々に与えるだろう。</span></span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 118:22–23; ペテロの手紙第一 2:7–8; イザヤ書 28:16"> <span className="woj">あなたがたは、この聖書の言葉さえ読んだことがないのか。</span><br /><span className="pl pl-1 woj">『家を建てる者たちが退けた石が、</span><br /><span className="pl pl-2 woj">隅のかしら石となった。</span></span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 118:23; 使徒の働き 3:12–16; ハバクク書 1:5"> <span className="pl pl-1 woj">これは主によってなされたことで、</span><br /><span className="pl pl-2 woj">われわれの目には驚くべきことである。』」</span></span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="マルコ 11:18; マタイ 22:22; ヨハネ 7:44"> 彼らはイエスを捕らえようとしたが、群衆を恐れた。このたとえが自分たちに対して語られたことに気づいたからである。彼らはイエスを残して立ち去った。</span>
<span className="v" id="v13" data-v="13" data-xref="ルカ 20:20–26; ルカ 11:54; マルコ 3:6"> それから彼らは、イエスの言葉じりをとらえるために、パリサイ人とヘロデ党の者たちの何人かを遣わした。</span>
<span className="v" id="v14" data-v="14" data-xref="テサロニケ人への手紙第一 2:4; ルカ 20:22; ヨハネ 7:18"> 彼らは来て、イエスに尋ねた。「先生、私たちは、あなたが真実な方で、だれにも気兼ねなさらないことを知っています。人を分け隔てせず、真実に神の道を教えておられるからです。カエサルに税金を納めることは律法にかなっていますか、かなっていませんか。</span>
<span className="v" id="v15" data-v="15" data-xref="エゼキエル書 17:2; ヨハネの黙示録 2:23; マルコ 10:2"> 納めるべきでしょうか、納めるべきではないでしょうか。」<br />しかしイエスは彼らの偽善を見抜いて言われた。<span className="woj">「なぜ私を試すのか。デナリ銀貨を持って来て、見せなさい。」</span></span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="ルカ 20:24–26; ヨハネの黙示録 3:12; マタイ 22:19–22"> 彼らは持って来た。<br />イエスは彼らに言われた。<span className="woj">「これはだれの肖像と銘か。」</span><br />彼らは、「カエサルのです」と答えた。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="ローマ人への手紙 13:7; ペテロの手紙第一 2:17; コリント人への第二の手紙 5:14–15"> イエスは彼らに答えられた。<span className="woj">「カエサルのものはカエサルに、神のものは神に返しなさい。」</span><br />彼らはイエスに非常に驚いた。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="マタイ 22:23–33; 使徒の働き 4:1–2; 使徒の働き 23:6–9"> 復活はないと言っているサドカイ人たちがイエスのもとに来て、尋ねた。</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 25:5–10; ルツ記 4:5; ルツ記 1:11–13"> 「先生、モーセは私たちのためにこう書いています。『ある人の兄弟が死に、妻を残して子どもを残さなかったなら、その人は兄弟の妻をめとり、兄弟のために子孫をもうけなければならない。』</span>
<span className="v" id="v20" data-v="20" data-xref="マタイ 22:25–28; ルカ 20:29–33"> さて、七人の兄弟がいました。長男が妻をめとりましたが、死んで子孫を残しませんでした。</span>
<span className="v" id="v21" data-v="21"> 次男が彼女をめとりましたが、やはり子どもを残さずに死にました。三男も同じでした。</span>
<span className="v" id="v22" data-v="22"> 七人とも彼女をめとりましたが、子どもを残しませんでした。最後に、その女も死にました。</span>
<span className="v" id="v23" data-v="23"> 復活の時、彼らがよみがえると、その女はだれの妻になるのでしょうか。七人とも彼女を妻にしたのです。」</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="ヨハネ 20:9; テモテへの第二の手紙 3:15–17; マタイ 22:29"> イエスは彼らに答えられた。<span className="woj">「あなたがたが思い違いをしているのは、聖書も神の力も知らないからではないか。</span></span>
<span className="v" id="v25" data-v="25" data-xref="ルカ 20:35–36; マタイ 22:30; ヨハネの手紙第一 3:2"> <span className="woj">死者の中からよみがえるとき、人々はめとることも嫁ぐこともなく、天にいる御使いたちのようになるからである。</span></span>
<span className="v" id="v26" data-v="26" data-xref="出エジプト記 3:2–6; ルカ 20:37; 創世記 17:7–8"> <span className="woj">死者がよみがえることについては、モーセの書の柴の箇所で、神がモーセに、『私はアブラハムの神、イサクの神、ヤコブの神である』と語られたのを読んだことがないのか。</span></span>
<span className="v" id="v27" data-v="27" data-xref="ローマ人への手紙 14:9; ローマ人への手紙 4:17; マルコ 12:24"> <span className="woj">神は死者の神ではなく、生きている者の神である。あなたがたは大きな思い違いをしている。」</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="マタイ 22:34–40; ルカ 10:25–28; ルカ 20:39"> 律法学者の一人が来て、彼らが互いに議論しているのを聞いていた。そしてイエスが見事に答えられたのを知り、尋ねた。「すべての戒めの中で、最も重要なものはどれですか。」</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="申命記 6:4; ルカ 10:27; ガラテヤ人への手紙 3:20"> イエスは答えられた。<span className="woj">「最も重要な戒めはこれである。『イスラエルよ、聞け。主は私たちの神、主はただひとりである。</span></span>
<span className="v" id="v30" data-v="30" data-xref="申命記 6:5"> <span className="woj">あなたは心を尽くし、魂を尽くし、思いを尽くし、力を尽くして、あなたの神、主を愛しなさい。』</span><span className="woj">これが第一の戒めである。</span></span>
<span className="v" id="v31" data-v="31" data-xref="ローマ人への手紙 13:8–9; マタイ 22:39; レビ記 19:18"> <span className="woj">第二の戒めはこれである。『隣人を自分自身のように愛しなさい。』</span><span className="woj">これらより大きな戒めはほかにない。」</span></span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="申命記 4:39; 申命記 4:35; イザヤ書 46:9"> 律法学者はイエスに言った。「先生、そのとおりです。神はただひとりで、そのほかに神はいないと、正しく言われました。</span>
<span className="v" id="v33" data-v="33" data-xref="ホセア書 6:6; ミカ書 6:6–8; サムエル記第一 15:22"> また、心を尽くし、知性を尽くし、魂を尽くし、力を尽くして神を愛し、隣人を自分自身のように愛することは、どの全焼のささげ物やいけにえよりも重要です。」</span>
</div>
<div className="bp poetry">
<span className="v" id="v34" data-v="34" data-xref="コロサイ人への手紙 4:6; ルカ 20:40; マタイ 22:46"> イエスは彼が賢く答えたのを見て、言われた。<span className="woj">「あなたは神の御国から遠くない。」</span><br />それからは、だれもあえてイエスに質問しようとしなかった。</span>
<span className="v" id="v35" data-v="35" data-xref="ルカ 20:41–44; マタイ 22:41–45; マタイ 26:55"> イエスは神殿で教えながら言われた。<span className="woj">「なぜ律法学者たちは、キリストはダビデの子だと言うのか。</span></span>
<span className="v" id="v36" data-v="36" data-xref="詩篇 110:1; ヘブル人への手紙 1:13; マタイ 22:43–45"> <span className="woj">ダビデ自身が聖霊によってこう言っている。</span><br /><span className="pl pl-1 woj">『主は私の主に言われた。</span><br /><span className="pl pl-2 woj">「私の右に座っていなさい。</span><br /><span className="pl pl-2 woj">私があなたの敵をあなたの足台とするまで。」』</span></span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="ローマ人への手紙 1:3–4; マタイ 11:25; マタイ 1:23"> <span className="woj">ダビデ自身がキリストを主と呼んでいる。それなら、どうしてキリストはダビデの子なのか。」</span><br />大勢の人々は、イエスの話を喜んで聞いていた。</span>
<span className="v" id="v38" data-v="38" data-xref="マタイ 23:1–7; ルカ 20:45–47; ルカ 11:43"> イエスは教えの中で彼らに言われた。<span className="woj">「律法学者たちに用心しなさい。彼らは長い衣を着て歩き回ることや、広場で挨拶されること、</span></span>
<span className="v" id="v39" data-v="39" data-xref="ヤコブの手紙 2:2–3"> <span className="woj">会堂の上席や宴会の上座を好んでいる。</span></span>
<span className="v" id="v40" data-v="40" data-xref="マタイ 23:13; ルカ 20:47; マタイ 23:33"> <span className="woj">また、やもめたちの家を食い尽くし、見せかけのために長い祈りをする。彼らはさらに厳しい裁きを受ける。」</span></span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="ルカ 21:1–4; 列王記第二 12:9; ヨハネ 8:20"> イエスは献金箱の向かい側に座り、群衆が献金箱に金を入れる様子を見ておられた。多くの金持ちがたくさん入れていた。</span>
<span className="v" id="v42" data-v="42"> そこへ一人の貧しいやもめが来て、レプタ銅貨二枚を入れた。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="文字どおりには「レプタ」（または「やもめの小銭」）。レプタは非常に小さな青銅貨で、一枚は一クァドランスの半分、すなわち銅貨一アサリオンの四分の一に相当する。レプタの価値は、農業労働者の日当の1パーセント未満である。">a</a></sup>これは一クァドランスに相当する。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="一クァドランスは一デナリの約64分の1に相当する硬貨である。一デナリは農業労働者の約一日分の賃金に相当する。">b</a></sup></span>
<span className="v" id="v43" data-v="43" data-xref="コリント人への第二の手紙 9:6–8; コリント人への第二の手紙 8:2; 使徒の働き 11:29"> イエスは弟子たちを呼び寄せて言われた。<span className="woj">「まことに、あなたがたに言う。この貧しいやもめは、献金箱に入れている人々のだれよりも多く入れた。</span></span>
<span className="v" id="v44" data-v="44" data-xref="コリント人への第二の手紙 8:2–3; ヨハネの手紙第一 3:17; エズラ記 2:68–69"> <span className="woj">皆はあり余る中から入れたが、彼女は乏しい中から、持っていたすべて、生活費のすべてを入れたからである。」</span></span>
</div>

## 脚注

<ol className="fnl">
<li id="fn-a"><a href="#fnref-a" className="fnb">a</a> <span className="fnr">12:42</span> 文字どおりには「レプタ」（または「やもめの小銭」）。レプタは非常に小さな青銅貨で、一枚は一クァドランスの半分、すなわち銅貨一アサリオンの四分の一に相当する。レプタの価値は、農業労働者の日当の1パーセント未満である。</li>
<li id="fn-b"><a href="#fnref-b" className="fnb">b</a> <span className="fnr">12:42</span> 一クァドランスは一デナリの約64分の1に相当する硬貨である。一デナリは農業労働者の約一日分の賃金に相当する。</li>
</ol>

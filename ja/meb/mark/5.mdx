<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ルカ 8:26–39; マタイ 8:28–34; マルコ 4:35"> 一行は湖の向こう岸、ガダラ人の地方に着いた。</span>
<span className="v" id="v2" data-v="2" data-xref="マルコ 1:23; イザヤ書 65:4; マルコ 5:8"> イエスが舟から降りられると、すぐに汚れた霊につかれた男が墓場から出て来て、イエスに出会った。</span>
<span className="v" id="v3" data-v="3" data-xref="イザヤ書 65:4; ルカ 8:29; ダニエル書 4:32–33"> この男は墓場を住みかとしていた。もはや鎖を使っても、だれも彼を縛っておくことができなかった。</span>
<span className="v" id="v4" data-v="4" data-xref="ヤコブの手紙 3:7–8"> 彼は何度も足かせと鎖で縛られたが、鎖を引きちぎり、足かせも砕いてしまった。だれにも彼を押さえる力がなかった。</span>
<span className="v" id="v5" data-v="5" data-xref="ヨブ記 2:7–8; 列王記第一 18:28; ヨハネ 8:44"> 彼は夜も昼も絶えず墓場や山の中で叫び、石で自分の体を傷つけていた。</span>
<span className="v" id="v6" data-v="6" data-xref="ヤコブの手紙 2:19; 詩篇 66:3; ルカ 4:41"> 彼は遠くからイエスを見ると、走って来て、その前にひれ伏した。</span>
<span className="v" id="v7" data-v="7" data-xref="マタイ 8:29; 使徒の働き 16:17; マタイ 26:63"> そして大声で叫んだ。「いと高き神の子イエスよ、私と何の関係があるのですか。神にかけてお願いします。私を苦しめないでください。」</span>
<span className="v" id="v8" data-v="8" data-xref="マルコ 1:25; マルコ 9:25–26; 使徒の働き 16:18"> イエスが彼に、<span className="woj">「汚れた霊よ、この人から出て行け！」</span>と言われたからである。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="ルカ 8:30; マルコ 5:15; マタイ 26:53"> イエスは彼に、<span className="woj">「あなたの名は何か」</span>と尋ねられた。<br />彼は答えた。「私の名はレギオンです。私たちは大勢だからです。」</span>
<span className="v" id="v10" data-v="10" data-xref="マルコ 3:22; マルコ 5:13"> そして、自分たちをこの地方から追い出さないでほしいと、イエスにしきりに願った。</span>
<span className="v" id="v11" data-v="11" data-xref="レビ記 11:7–8; イザヤ書 65:4; イザヤ書 66:3"> ところで、山腹では豚の大群が飼われていた。</span>
<span className="v" id="v12" data-v="12" data-xref="コリント人への第二の手紙 2:11; ヨブ記 1:10–12; ルカ 22:31–32"> 悪霊たちはみなイエスに願って言った。「あの豚の中に送って、入らせてください。」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="列王記第一 22:22; ペテロの手紙第一 3:22; ヨブ記 2:6"> イエスはすぐに彼らにお許しになった。汚れた霊たちは男から出て豚の中に入った。すると、およそ二千匹の豚の群れが崖を駆け下りて湖に飛び込み、溺れ死んだ。</span>
<span className="v" id="v14" data-v="14" data-xref="ルカ 8:34; マタイ 8:33"> 豚を飼っていた者たちは逃げ、町や田舎でこのことを知らせた。<br />人々は、何が起こったのか見に来た。</span>
<span className="v" id="v15" data-v="15" data-xref="コロサイ人への手紙 1:13; テモテへの第二の手紙 1:7; サムエル記第一 6:20–21"> 彼らがイエスのもとに来ると、悪霊につかれていた人、すなわちレギオンに取りつかれていた人が、服を着て正気になり、座っているのを見て恐れた。</span>
<span className="v" id="v16" data-v="16"> 一部始終を見ていた人々は、悪霊につかれていた人に起こったことや、豚のことを彼らに話した。</span>
<span className="v" id="v17" data-v="17" data-xref="マタイ 8:34; マルコ 1:24; ルカ 8:37"> そこで人々は、自分たちの地域から立ち去ってくださるよう、イエスに願い始めた。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="ルカ 8:38–39; ピリピ人への手紙 1:23–24; マルコ 5:17"> イエスが舟に乗ろうとされると、悪霊につかれていた人が、お供をさせてほしいと願った。</span>
<span className="v" id="v19" data-v="19" data-xref="詩篇 66:16; ヨハネ 4:29; イザヤ書 38:9–20"> しかしイエスはお許しにならず、彼に言われた。<span className="woj">「自分の家に帰り、家族や仲間に、主があなたのためにどれほど大きなことをしてくださったか、どれほどあわれんでくださったかを知らせなさい。」</span></span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="マルコ 7:31; マタイ 4:25"> そこで彼は立ち去り、イエスが自分のためにどれほど大きなことをしてくださったかを、デカポリスで宣べ伝え始めた。人々はみな驚いた。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="マタイ 9:1; マルコ 4:1; ルカ 8:40"> イエスが舟で再び向こう岸へ渡られると、大勢の群衆がそのもとに集まった。イエスは湖のほとりにおられた。</span>
<span className="v" id="v22" data-v="22" data-xref="ルカ 13:14; 使徒の働き 18:8; マルコ 5:35–36"> すると、会堂司の一人で、ヤイロという人が来た。イエスを見ると、その足元にひれ伏し、</span>
<span className="v" id="v23" data-v="23" data-xref="ルカ 13:13; ルカ 4:40; マルコ 16:18"> しきりに願って言った。「私の幼い娘が死にかけています。どうか来て、娘の上に手を置いてください。そうすれば娘は癒され、生きるでしょう。」</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="マルコ 5:31; マルコ 3:20; ルカ 7:6"> イエスは彼と共に行かれた。大勢の群衆がイエスに従い、その周りに押し寄せた。</span>
<span className="v" id="v25" data-v="25" data-xref="レビ記 15:25–27; ルカ 8:43–44; マタイ 9:20–22"> そこに、十二年間も出血が続いている女がいた。</span>
<span className="v" id="v26" data-v="26" data-xref="エレミヤ書 30:12–13; エレミヤ書 8:22; 詩篇 108:12"> 彼女は多くの医者からひどい目に遭わされ、持っているものをすべて使い果たしたが、少しも良くならず、かえって悪くなっていた。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒の働き 19:12; マタイ 14:36; 使徒の働き 5:15"> 彼女はイエスのことを聞き、群衆の中で後ろから近づいて、その衣に触れた。</span>
<span className="v" id="v28" data-v="28"> 「あの方の衣に触れるだけで、私は癒される」と思っていたからである。</span>
<span className="v" id="v29" data-v="29" data-xref="マルコ 5:34; 詩篇 30:2; マルコ 3:10"> するとすぐに出血が止まり、病が癒されたことを体で感じた。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="ルカ 6:19; ルカ 8:46; ルカ 5:17"> イエスはすぐに、ご自分から力が出て行ったことに気づき、群衆の中で振り向いて、<span className="woj">「私の衣に触れたのはだれか」</span>と尋ねられた。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="ルカ 8:45; ルカ 9:12"> 弟子たちは言った。「群衆があなたに押し迫っているのをご覧になっていながら、『私に触れたのはだれか』と言われるのですか。」</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32"> しかしイエスは、ご自分に触れた者を見つけようと見回された。</span>
<span className="v" id="v33" data-v="33" data-xref="ルカ 8:47; ルカ 1:29; ルカ 1:12"> 女は自分に起こったことを知り、恐れおののきながら進み出て、イエスの前にひれ伏し、すべてをありのままに話した。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="ルカ 8:48; マタイ 9:22; ルカ 7:50"> イエスは彼女に言われた。<span className="woj">「娘よ、あなたの信仰があなたを癒した。安心して行きなさい。その病から解放され、健やかに過ごしなさい。」</span></span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="ルカ 8:49; ヨハネ 11:39; マルコ 5:22"> イエスがまだ話しておられるうちに、会堂司の家から人々が来て言った。「お嬢さんは亡くなりました。これ以上、先生を煩わせることはありません。」</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="ルカ 8:50; マタイ 9:28–29; ヨハネ 11:40"> しかしイエスは、その言葉を聞くとすぐに、会堂司に言われた。<span className="woj">「恐れてはならない。ただ信じなさい。」</span></span>
<span className="v" id="v37" data-v="37" data-xref="使徒の働き 9:40; マルコ 14:33; コリント人への第二の手紙 13:1"> そして、ペテロ、ヤコブ、ヤコブの兄弟ヨハネのほかは、だれもついて来ることをお許しにならなかった。</span>
<span className="v" id="v38" data-v="38" data-xref="マタイ 9:23–24; ルカ 8:52–53; マルコ 5:22"> 一行が会堂司の家に着くと、イエスは人々が騒ぎ、泣き叫び、激しく嘆いているのをご覧になった。</span>
<span className="v" id="v39" data-v="39" data-xref="使徒の働き 20:10; テサロニケ人への手紙第一 5:10; テサロニケ人への手紙第一 4:13–14"> 中に入ると、人々に言われた。<span className="woj">「なぜ騒いで泣いているのか。この子は死んだのではなく、眠っているのだ。」</span></span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="ネヘミヤ記 2:19; 列王記第二 4:33; マタイ 9:24–25"> 人々はイエスをあざ笑った。しかしイエスは彼らを皆外に出すと、子どもの父と母、それにご自分と共にいた者たちを連れ、子どものいる所に入られた。</span>
<span className="v" id="v41" data-v="41" data-xref="マルコ 1:31; ルカ 7:14–15; ルカ 8:54–55"> そして子どもの手を取り、<span className="woj">「タリタ、クミ！」</span>と言われた。これは訳すと、<span className="woj">「少女よ、あなたに言う。起きなさい！」</span>という意味である。</span>
<span className="v" id="v42" data-v="42" data-xref="マルコ 4:41; 使徒の働き 3:10–13; マルコ 7:37"> 少女はすぐに起き上がって歩き始めた。彼女は十二歳だった。人々は非常に驚いた。</span>
<span className="v" id="v43" data-v="43" data-xref="マタイ 8:4; マタイ 9:30; マルコ 1:43"> イエスは、このことをだれにも知らせないよう彼らに厳しく命じ、少女に食べ物を与えるよう言われた。</span>
</div>
</div>

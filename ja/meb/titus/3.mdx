<span className="v" id="v1" data-v="1" data-xref="ローマ人への手紙 13:1–7; ペテロの手紙第一 2:13–17; 伝道者の書 10:4"> 支配者と権威ある者たちに服し、従順であり、あらゆる良い働きをする用意を整えておくよう、人々に思い起こさせなさい。</span>
<span className="v" id="v2" data-v="2" data-xref="エペソ人への手紙 4:31; テモテへの第二の手紙 2:24–25; エペソ人への手紙 4:2"> また、だれをも中傷せず、争いを好まず、穏やかで、すべての人に対して、どこまでもへりくだった態度を示すよう教えなさい。</span>
<span className="v" id="v3" data-v="3" data-xref="エペソ人への手紙 2:1–3; ローマ人への手紙 6:17; コロサイ人への手紙 1:21"> 私たちもかつては愚かで、不従順で、迷わされ、さまざまな欲望と快楽の奴隷となり、悪意とねたみのうちに暮らし、人に憎まれ、互いに憎み合っていました。</span>
<span className="v" id="v4" data-v="4" data-xref="エペソ人への手紙 2:4–10; テトス 2:10–11; テモテへの手紙第一 4:10"> しかし、私たちの救い主である神の慈愛と、人への愛が現れたとき、</span>
<span className="v" id="v5" data-v="5" data-xref="エペソ人への手紙 2:8–9; テモテへの第二の手紙 1:9; コリント人への第一の手紙 6:11"> 神は、私たち自身が行った義の行いによってではなく、ご自身のあわれみによって、再生の洗いと、聖霊によって新しくされることを通して、私たちを救ってくださいました。</span>
<span className="v" id="v6" data-v="6" data-xref="ヨエル書 2:28; ローマ人への手紙 5:5; 使徒の働き 10:45"> 神は、私たちの救い主イエス・キリストを通して、この聖霊を私たちの上に豊かに注いでくださいました。</span>
<span className="v" id="v7" data-v="7" data-xref="ローマ人への手紙 8:17; テトス 2:11; コリント人への第一の手紙 6:11"> それは、私たちが神の恵みによって義とされ、永遠の命を望み、その相続人となるためでした。</span>
<span className="v" id="v8" data-v="8" data-xref="テトス 3:14; テトス 1:9; 詩篇 16:2–3"> このことばは信頼できます。あなたには、これらのことを確信をもって強調してほしいのです。それは、神を信じた人々が良い働きに励むよう心を配るためです。これらは良いことであり、人々の益になります。</span>
<span className="v" id="v9" data-v="9" data-xref="テモテへの第二の手紙 2:14; テモテへの第二の手紙 2:23; テモテへの手紙第一 4:7"> しかし、愚かな詮索、系図、争い、律法をめぐる論争は避けなさい。それらは無益で、むなしいものです。</span>
<span className="v" id="v10" data-v="10" data-xref="ローマ人への手紙 16:17; ヨハネの手紙第二 1:10; マタイ 18:15–17"> 分派を作る人は、一度、二度と戒めた後は避けなさい。</span>
<span className="v" id="v11" data-v="11" data-xref="ヘブル人への手紙 10:26; ルカ 19:22; マタイ 25:26–28"> そのような人は道を踏み外し、罪を犯して、自らを罪に定めているのだと分かっているからです。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="テモテへの第二の手紙 4:9; テモテへの第二の手紙 4:12; コリント人への第一の手紙 16:8–9"> 私がアルテマスかテキコをあなたのもとに遣わしたら、ぜひニコポリスにいる私のところへ来てください。私はそこで冬を過ごすことに決めています。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒の働き 18:24; マタイ 22:35; ヨハネの手紙第三 1:6–8"> 法律家ゼナスとアポロが何一つ不自由しないよう十分に備え、速やかに旅へ送り出してください。</span>
<span className="v" id="v14" data-v="14" data-xref="コロサイ人への手紙 1:10; テトス 3:8; マタイ 7:19"> 私たちの仲間も、必要に応えるために良い働きに励むことを学び、実を結ばない者とならないようにしなければなりません。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ガラテヤ人への手紙 1:6–12; ペテロの手紙第一 5:12; コリント人への第一の手紙 15:3–11"> さて兄弟たち、私があなたがたに宣べ伝えた福音を、改めて知らせます。あなたがたはそれを受け入れ、今もその福音に立っています。</span>
<span className="v" id="v2" data-v="2" data-xref="ヘブル人への手紙 3:6; ヘブル人への手紙 2:1; ヘブル人への手紙 3:14"> また、私が宣べ伝えた言葉を堅く保っているなら、その福音によって救われます。そうでなければ、あなたがたは空しく信じたことになります。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="ペテロの手紙第一 2:24; ガラテヤ人への手紙 1:4; イザヤ書 53:1–12"> 私が受けたことを、何よりも大切なこととして、あなたがたに伝えました。すなわち、聖書に書かれているとおり、キリストはわれわれの罪のために死なれ、</span>
<span className="v" id="v4" data-v="4" data-xref="ホセア書 6:2; マタイ 12:40; 詩篇 16:10–11"> 葬られ、聖書に書かれているとおり、三日目によみがえられました。</span>
<span className="v" id="v5" data-v="5" data-xref="マルコ 16:14; コリント人への第一の手紙 1:12; ヨハネ 1:42"> そしてケファに現れ、それから十二人に現れました。</span>
<span className="v" id="v6" data-v="6" data-xref="マタイ 28:10; マルコ 16:7; 使徒の働き 13:36"> その後、五百人を超える兄弟たちに一度に現れました。その大部分は今も生きていますが、眠りについた人もいます。</span>
<span className="v" id="v7" data-v="7" data-xref="ルカ 24:50; 使徒の働き 1:2–12; ルカ 24:33"> その後ヤコブに現れ、それからすべての使徒たちに現れました。</span>
<span className="v" id="v8" data-v="8" data-xref="コリント人への第一の手紙 9:1; 使徒の働き 26:16; 使徒の働き 22:18"> そして最後に、時ならず生まれた者のような私にも現れてくださいました。</span>
<span className="v" id="v9" data-v="9" data-xref="エペソ人への手紙 3:7–8; テモテへの手紙第一 1:13–15; 使徒の働き 8:3"> 私は使徒の中で最も小さい者であり、使徒と呼ばれる資格もありません。神の教会を迫害したからです。</span>
<span className="v" id="v10" data-v="10" data-xref="ピリピ人への手紙 4:13; コリント人への第二の手紙 3:5; ピリピ人への手紙 2:13"> しかし、神の恵みによって、今の私があります。私に与えられた神の恵みは空しくならず、私は彼らのだれよりも多く働きました。もっとも、働いたのは私ではなく、私と共にあった神の恵みです。</span>
<span className="v" id="v11" data-v="11" data-xref="コリント人への第一の手紙 15:3–4; コリント人への第一の手紙 2:2"> ですから、私であれ彼らであれ、このように宣べ伝え、あなたがたはこのように信じたのです。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="使徒の働き 26:8; 使徒の働き 17:32; テモテへの第二の手紙 2:18"> ところで、キリストは死者の中からよみがえられたと宣べ伝えられているのに、あなたがたの中のある人々は、死者の復活はないと、どうして言うのですか。</span>
<span className="v" id="v13" data-v="13" data-xref="ヨハネ 11:25–26; ローマ人への手紙 8:11; テサロニケ人への手紙第一 4:14"> もし死者の復活がないなら、キリストもよみがえられなかったことになります。</span>
<span className="v" id="v14" data-v="14" data-xref="コリント人への第一の手紙 15:17; テサロニケ人への手紙第一 4:14; ガラテヤ人への手紙 2:2"> もしキリストがよみがえられなかったなら、われわれの宣教はむなしく、あなたがたの信仰もむなしいものです。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒の働き 2:24; ヨブ記 13:7–10; 使徒の働き 2:32"> そればかりか、われわれは神について偽りの証人と認められます。死者がよみがえらないのなら、神がよみがえらせなかったキリストを、神がよみがえらせたと証言したからです。</span>
<span className="v" id="v16" data-v="16"> 死者がよみがえらないのなら、キリストもよみがえらなかったことになります。</span>
<span className="v" id="v17" data-v="17" data-xref="ローマ人への手紙 4:25; ペテロの手紙第一 1:3; コリント人への第一の手紙 15:14"> もしキリストがよみがえられなかったなら、あなたがたの信仰はむなしく、今も罪の中にいることになります。</span>
<span className="v" id="v18" data-v="18" data-xref="テサロニケ人への手紙第一 4:13–14; ヨハネの黙示録 14:13; テサロニケ人への手紙第一 4:16"> そうであれば、キリストにあって眠りについた人々も滅びてしまったことになります。</span>
<span className="v" id="v19" data-v="19" data-xref="ペテロの手紙第一 1:21; ヨハネの黙示録 14:13; テモテへの第二の手紙 1:12"> もしわれわれが、この世の生涯においてだけキリストに望みを置いているのなら、すべての人の中で最も哀れな者です。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="コリント人への第一の手紙 15:23; 使徒の働き 26:23; ヨハネの黙示録 1:5"> しかし今、キリストは死者の中からよみがえられ、眠りについた人々の初穂となられました。</span>
<span className="v" id="v21" data-v="21" data-xref="ヨハネ 11:25; ローマ人への手紙 5:12–17; コリント人への第一の手紙 15:22"> 死が一人の人を通して来たので、死者の復活も一人の人を通して来ました。</span>
<span className="v" id="v22" data-v="22" data-xref="ローマ人への手紙 5:12–21; コリント人への第一の手紙 15:45–49; ヨハネ 5:21–29"> アダムにあってすべての人が死ぬように、キリストにあってすべての人が生かされます。</span>
<span className="v" id="v23" data-v="23" data-xref="イザヤ書 26:19; ガラテヤ人への手紙 3:29; コリント人への第一の手紙 15:52"> ただし、それぞれに順序があります。初穂であるキリスト、次に、キリストが来られる時に、キリストに属する人々です。</span>
<span className="v" id="v24" data-v="24" data-xref="ダニエル書 7:27; ダニエル書 7:14; マタイ 28:18"> それから終わりが来ます。その時、キリストは、すべての支配、すべての権威と力を滅ぼし、王国を父なる神に引き渡されます。</span>
<span className="v" id="v25" data-v="25" data-xref="ヘブル人への手紙 10:12–13; 詩篇 110:1; マタイ 22:44"> キリストは、すべての敵をその足の下に置くまで、王として治めなければならないからです。</span>
<span className="v" id="v26" data-v="26" data-xref="テモテへの第二の手紙 1:10; コリント人への第一の手紙 15:55; ヨハネの黙示録 21:4"> 最後の敵として滅ぼされるのは、死です。</span>
<span className="v" id="v27" data-v="27" data-xref="詩篇 8:6; ヘブル人への手紙 2:8; マタイ 28:18"> 「神はすべてをその足の下に従わせた」からです。しかし、「すべてが従わせられた」と言う時、すべてをキリストに従わせた方が含まれていないことは明らかです。</span>
<span className="v" id="v28" data-v="28" data-xref="コロサイ人への手紙 3:11; コリント人への第一の手紙 3:23; エペソ人への手紙 1:23"> すべてが御子に従わせられた時、御子自身も、すべてを御子に従わせた方に従われます。それは、神がすべてにおいてすべてとなられるためです。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="ローマ人への手紙 6:3–4; コリント人への第一の手紙 15:16; マタイ 20:22"> そうでなければ、死者のためにバプテスマを受ける人々は、どうなるのでしょうか。死者が決してよみがえらないのなら、なぜ彼らは死者のためにバプテスマを受けるのですか。</span>
<span className="v" id="v30" data-v="30" data-xref="コリント人への第二の手紙 6:9; ガラテヤ人への手紙 5:11; コリント人への第二の手紙 4:7–12"> また、なぜわれわれは、いつも危険にさらされているのでしょうか。</span>
<span className="v" id="v31" data-v="31" data-xref="コリント人への第二の手紙 4:10–11; ローマ人への手紙 8:36; コリント人への第一の手紙 4:9–13"> われわれの主キリスト・イエスにあって、私があなたがたを誇りとしていることにかけて断言します。私は日々死んでいます。</span>
<span className="v" id="v32" data-v="32" data-xref="イザヤ書 22:13; イザヤ書 56:12; ルカ 12:19"> もし私が人間的な望みだけで、エフェソで野獣と戦ったのなら、何の益があるでしょうか。死者がよみがえらないのなら、「食べて飲もう。明日は死ぬのだから。」</span>
<span className="v" id="v33" data-v="33" data-xref="箴言 13:20; マタイ 24:4; コリント人への第一の手紙 5:6"> 思い違いをしてはいけません。「悪い交わりは良い品性を損なう」のです。</span>
<span className="v" id="v34" data-v="34" data-xref="コリント人への第一の手紙 6:5; ローマ人への手紙 13:11; ヘブル人への手紙 5:11–12"> 正気に立ち返り、罪を犯してはいけません。神について何の知識もない人たちがいるからです。あなたがたを恥じさせるために、こう言っています。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="エゼキエル書 37:3; コリント人への第一の手紙 15:38–53; ローマ人への手紙 9:19"> しかし、ある人は言うでしょう。「死者はどのようにしてよみがえるのか。どのような体で現れるのか。」</span>
<span className="v" id="v36" data-v="36" data-xref="ヨハネ 12:24; ルカ 11:40; エペソ人への手紙 5:15"> 愚かな人よ。あなた自身が蒔くものも、死ななければ生かされません。</span>
<span className="v" id="v37" data-v="37"> あなたが蒔くのは、後にできる体そのものではなく、麦であれ、ほかの穀物であれ、ただの種です。</span>
<span className="v" id="v38" data-v="38" data-xref="コリント人への第一の手紙 3:7; イザヤ書 61:11; マルコ 4:26–29"> しかし神は、みこころのままにそれに体を与え、一つひとつの種にそれぞれの体を与えられます。</span>
<span className="v" id="v39" data-v="39" data-xref="創世記 1:20–26"> すべての肉が同じ肉なのではありません。人の肉、動物の肉、魚の肉、鳥の肉は、それぞれ異なります。</span>
<span className="v" id="v40" data-v="40"> また、天上の体も地上の体もあります。しかし、天上の体の栄光と地上の体の栄光は異なります。</span>
<span className="v" id="v41" data-v="41" data-xref="イザヤ書 24:23; 詩篇 148:3–5; 申命記 4:19"> 太陽の栄光、月の栄光、星々の栄光はそれぞれ異なり、一つの星と別の星も、栄光において異なります。</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="マタイ 13:43; ダニエル書 12:3; ローマ人への手紙 8:21"> 死者の復活も同じです。朽ちるものとして蒔かれ、朽ちないものとしてよみがえらされます。</span>
<span className="v" id="v43" data-v="43" data-xref="コリント人への第一の手紙 6:14; コロサイ人への手紙 3:4; ピリピ人への手紙 3:20–21"> 卑しいものとして蒔かれ、栄光あるものとしてよみがえらされます。弱いものとして蒔かれ、力あるものとしてよみがえらされます。</span>
<span className="v" id="v44" data-v="44" data-xref="コリント人への第一の手紙 15:50; ルカ 24:31; ヨハネ 20:19"> 自然の体として蒔かれ、霊の体としてよみがえらされます。自然の体があるなら、霊の体もあります。</span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="ヨハネ 5:21; 創世記 2:7; ローマ人への手紙 8:2"> このように、「最初の人アダムは、生きる者となった」と書かれています。最後のアダムは、命を与える霊となりました。</span>
<span className="v" id="v46" data-v="46" data-xref="コロサイ人への手紙 3:9–10; ローマ人への手紙 6:6; エペソ人への手紙 4:22–24"> しかし、霊のものが先なのではなく、生まれながらのものが先で、その後に霊のものが来ます。</span>
<span className="v" id="v47" data-v="47" data-xref="ヨハネ 3:31; 創世記 2:7; 創世記 3:19"> 最初の人は地から出た、ちりで造られた者です。第二の人は天から来られた主です。</span>
<span className="v" id="v48" data-v="48" data-xref="創世記 5:3; ローマ人への手紙 5:12–21; ヨハネ 3:6"> ちりで造られた者がそうであるように、ちりで造られた人々も同じです。天に属する方がそうであるように、天に属する人々も同じです。</span>
<span className="v" id="v49" data-v="49" data-xref="ローマ人への手紙 8:29; コリント人への第二の手紙 3:18; 創世記 5:3"> われわれは、ちりで造られた者のかたちを身につけてきたように、天に属する方のかたちをも身につけましょう。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="NUとTRでは、「身につけましょう」の代わりに「身につけることになります」となっている。">a</a></sup></span>
<span className="v" id="v50" data-v="50" data-xref="ヨハネ 3:3–6; マタイ 16:17; エペソ人への手紙 4:17"> 兄弟たち、<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="ここや、文脈上可能な箇所で「兄弟たち」と訳されている言葉は、「兄弟姉妹」あるいは「きょうだいたち」と訳すこともできる。">b</a></sup>私が言いたいのはこうです。肉と血は神の王国を受け継ぐことができず、朽ちるものが朽ちないものを受け継ぐこともありません。</span>
</div>
<div className="bp poetry">
<span className="v" id="v51" data-v="51" data-xref="テサロニケ人への手紙第一 4:14–17; ピリピ人への手紙 3:21; コリント人への第一の手紙 15:20"> 見よ、<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="「見よ」はギリシャ語の「ἰδοὺ」から来ており、「目を向ける」「注意を払う」「よく見る」「見つめる」という意味がある。しばしば間投詞として使われる。">c</a></sup>私はあなたがたに奥義を告げます。われわれが皆、眠りにつくわけではありません。しかし、皆が変えられます。</span>
<span className="v" id="v52" data-v="52" data-xref="テサロニケ人への手紙第一 4:16–17; マタイ 24:31; ヨハネ 5:28"> 最後のラッパが鳴る時、一瞬のうちに、まばたきする間にです。ラッパが鳴り響くと、死者は朽ちないものによみがえらされ、われわれは変えられます。</span>
<span className="v" id="v53" data-v="53" data-xref="コリント人への第二の手紙 5:2–4; ヨハネの手紙第一 3:2; ローマ人への手紙 2:7"> この朽ちるものは朽ちないものを身につけ、この死すべきものは不死を身につけなければならないからです。</span>
<span className="v" id="v54" data-v="54" data-xref="イザヤ書 25:8; ヨハネの黙示録 20:14; ヘブル人への手紙 2:14–15"> この朽ちるものが朽ちないものを身につけ、この死すべきものが不死を身につける時、書かれている言葉が実現します。「死は勝利にのみ込まれた。」</span>
<span className="v" id="v55" data-v="55" data-xref="ホセア書 13:14; 詩篇 89:48; 使徒の働き 2:27"> <span className="pl pl-1">「死よ、おまえのとげはどこにあるのか。</span><br /><span className="pl pl-2">ハデスよ、</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="または「地獄」。">d</a></sup><br /><span className="pl pl-2">おまえの勝利はどこにあるのか。」</span></span>
</div>
<div className="bp">
<span className="v" id="v56" data-v="56" data-xref="ローマ人への手紙 4:15; ガラテヤ人への手紙 3:10–13; ローマ人への手紙 7:5–13"> 死のとげは罪であり、罪の力は律法です。</span>
<span className="v" id="v57" data-v="57" data-xref="コリント人への第二の手紙 2:14; ローマ人への手紙 8:37; ヨハネの手紙第一 5:4–5"> しかし、われわれの主イエス・キリストを通して勝利を与えてくださる神に感謝します。</span>
<span className="v" id="v58" data-v="58" data-xref="ガラテヤ人への手紙 6:9; 歴代誌 第二 15:7; ヘブル人への手紙 6:10"> ですから、私の愛する兄弟たち、堅く立ち、動かされることなく、いつも主の働きに励みなさい。主にあって、あなたがたの労苦が無駄でないことを知っているからです。</span>
</div>

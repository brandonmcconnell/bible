<span className="v" id="v1" data-v="1" data-xref="コリント人への第一の手紙 1:17; コリント人への第一の手紙 2:13; コリント人への第一の手紙 2:4"> 兄弟たち、私があなたがたのもとに行った時、神のあかしを告げ知らせるのに、優れた話術や知恵を用いませんでした。</span>
<span className="v" id="v2" data-v="2" data-xref="ガラテヤ人への手紙 6:14; ヨハネ 17:3; コリント人への第一の手紙 1:22–25"> あなたがたの間では、イエス・キリスト、それも十字架につけられた方以外、何も知るまいと決めていたからです。</span>
<span className="v" id="v3" data-v="3" data-xref="コリント人への第二の手紙 13:4; コリント人への第一の手紙 4:10–13; コリント人への第二の手紙 12:5–10"> 私は弱さと恐れの中にあり、激しくおののきながら、あなたがたと共にいました。</span>
<span className="v" id="v4" data-v="4" data-xref="コリント人への第一の手紙 4:20; テサロニケ人への手紙第一 1:5; コリント人への第一の手紙 1:17"> 私の言葉と宣教は、人間の知恵による説得力ある言葉ではなく、霊と力が明らかに現れるものでした。</span>
<span className="v" id="v5" data-v="5" data-xref="コリント人への第二の手紙 4:7; コリント人への第二の手紙 12:9; コリント人への第二の手紙 6:7"> それは、あなたがたの信仰が人の知恵ではなく、神の力に基づくものとなるためでした。</span>
</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="ヘブル人への手紙 5:14; ヤコブの手紙 3:15; コリント人への第二の手紙 4:4"> しかし、成熟した人々の間では、われわれも知恵を語ります。ただし、それはこの世の知恵でも、滅びゆくこの世の支配者たちの知恵でもありません。</span>
<span className="v" id="v7" data-v="7" data-xref="コロサイ人への手紙 1:26–27; ペテロの第二の手紙 1:3; マタイ 11:25"> われわれが語るのは、奥義として隠されていた神の知恵です。それは、神がわれわれに栄光を与えるため、世界の始まる前から定めておられた知恵です。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒の働き 13:27; ヤコブの手紙 2:1; 使徒の働き 7:2"> この世の支配者たちは、だれ一人、この知恵を知りませんでした。もし知っていたなら、栄光の主を十字架につけはしなかったでしょう。</span>
<span className="v" id="v9" data-v="9" data-xref="イザヤ書 64:4; 詩篇 31:19; ヤコブの手紙 1:12"> しかし、こう書かれています。<br /><span className="pl pl-1">「目が見たことのないもの、耳が聞いたことのないもの、</span><br /><span className="pl pl-2">人の心に思い浮かびもしなかったもの、</span><br /><span className="pl pl-2">それを神は、ご自分を愛する人々のために備えてくださった。」</span></span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="ヨハネ 14:26; エペソ人への手紙 3:5; ルカ 10:21"> しかし神は、それらを霊によってわれわれに明らかにしてくださいました。霊はすべてを、神の深みさえも探るからです。</span>
<span className="v" id="v11" data-v="11" data-xref="箴言 20:27; コリント人への第一の手紙 2:10; ローマ人への手紙 11:33–34"> 人の内にあるその人の霊のほかに、いったいだれがその人のことを知っているでしょうか。それと同じように、神の霊のほかには、だれも神のことを知りません。</span>
<span className="v" id="v12" data-v="12" data-xref="ヨハネの手紙第一 2:27; ローマ人への手紙 8:5–6; ヨハネの手紙第一 2:20"> われわれが受けたのは、この世の霊ではなく、神から来る霊です。それによって、神が恵みによりわれわれに与えてくださったものを知るためです。</span>
<span className="v" id="v13" data-v="13" data-xref="コリント人への第一の手紙 2:4; コリント人への第一の手紙 2:14; コリント人への第一の手紙 1:17"> われわれはこれらのことを語るのにも、人間の知恵に教えられた言葉ではなく、聖霊に教えられた言葉を用い、霊的なことを霊的な言葉によって解き明かします。</span>
<span className="v" id="v14" data-v="14" data-xref="コリント人への第一の手紙 1:18; ローマ人への手紙 8:5–8; マタイ 13:11–17"> 生まれながらの人は、神の霊に属することを受け入れません。その人には愚かに思われ、知ることもできないからです。それらは霊によって見分けるものだからです。</span>
<span className="v" id="v15" data-v="15" data-xref="テサロニケ人への手紙第一 5:21; 箴言 28:5; ヘブル人への手紙 5:14"> しかし、霊に属する人はすべてを見分けますが、その人自身はだれからも判断されません。</span>
<span className="v" id="v16" data-v="16" data-xref="イザヤ書 40:13–14; ローマ人への手紙 11:34; ヨハネ 16:13–16"> 「だれが主の心を知り、主を教えることができようか。」しかし、われわれにはキリストの心があります。</span>

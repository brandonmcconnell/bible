<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出エジプト記 14:29; ネヘミヤ記 9:11–12; 詩篇 78:13–14"> 兄弟たち、あなたがたに知っておいてほしいことがあります。われわれの先祖は皆、雲の下にいて、皆、海を通り抜けました。</span>
<span className="v" id="v2" data-v="2" data-xref="ヘブル人への手紙 3:2–3; コリント人への第一の手紙 1:13–16; 出エジプト記 14:31"> そして皆、雲の中と海の中で、モーセに結ばれるバプテスマを受けました。</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 8:3; ネヘミヤ記 9:15; 出エジプト記 16:35"> 皆、同じ霊的な食物を食べ、</span>
<span className="v" id="v4" data-v="4" data-xref="出エジプト記 17:6; ヨハネ 7:37; イザヤ書 48:21"> 皆、同じ霊的な飲み物を飲みました。彼らについて来た霊的な岩から飲んだのです。その岩とはキリストでした。</span>
<span className="v" id="v5" data-v="5" data-xref="ヘブル人への手紙 3:17; ユダ 1:5; 民数記 14:37"> しかし、彼らの大部分は神の御心にかなわず、荒野で打ち倒されました。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="ユダ 1:7; コリント人への第一の手紙 10:11; ヘブル人への手紙 4:11"> これらのことは、彼らが悪をむさぼったように、われわれも悪をむさぼることのないよう、われわれのための実例となりました。</span>
<span className="v" id="v7" data-v="7" data-xref="出エジプト記 32:6–8; 詩篇 106:19–20; コリント人への第一の手紙 6:9"> 彼らのうちのある人々のように、偶像礼拝者となってはいけません。「民は座って飲み食いし、立って戯れた」と書かれています。</span>
<span className="v" id="v8" data-v="8" data-xref="民数記 25:1–9; コリント人への第一の手紙 6:18; 詩篇 106:29"> 彼らのうちのある人々がしたように、淫らな行いをしてはいけません。そのため、一日のうちに二万三千人が倒れました。</span>
<span className="v" id="v9" data-v="9" data-xref="民数記 21:5–6; 詩篇 78:18; ヘブル人への手紙 3:8–11"> 彼らのうちのある者たちがキリストを試み、蛇によって滅ぼされたように、われわれもキリストを試みてはいけません。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="NUでは、「キリスト」の代わりに「主」となっている。">a</a></sup></span>
<span className="v" id="v10" data-v="10" data-xref="民数記 14:2; 民数記 16:41; 民数記 14:37"> また、彼らのうちのある人々が不平を言い、滅ぼす者によって滅ぼされたように、あなたがたも不平を言ってはいけません。</span>
<span className="v" id="v11" data-v="11" data-xref="ローマ人への手紙 15:4; ローマ人への手紙 13:11; コリント人への第一の手紙 9:10"> これらのことはすべて、彼らの身に実例として起こり、時代の終わりに生きるわれわれを諭すために書かれました。</span>
<span className="v" id="v12" data-v="12" data-xref="ローマ人への手紙 11:20; ペテロの第二の手紙 3:17; 箴言 16:18"> ですから、自分は立っていると思う人は、倒れないように気をつけなさい。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="ペテロの第二の手紙 2:9; テモテへの第二の手紙 4:18; テサロニケ人への第二の手紙 3:3"> あなたがたが受けた試みで、人に共通しないものはありません。神は真実な方です。あなたがたが耐えられる以上の試みに遭うことを許さず、試みと共に逃れる道も備えて、それに耐えられるようにしてくださいます。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="ヨハネの黙示録 21:8; ヨハネの手紙第一 5:21; ペテロの手紙第一 2:11"> ですから、私の愛する人たち、偶像礼拝から逃げなさい。</span>
<span className="v" id="v15" data-v="15" data-xref="コリント人への第一の手紙 8:1; テサロニケ人への手紙第一 5:21; コリント人への第一の手紙 11:13"> 私は分別ある人々に語るように言います。私の言うことを自分で判断してください。</span>
<span className="v" id="v16" data-v="16" data-xref="マタイ 26:26–28; コリント人への第一の手紙 11:23–29; 使徒の働き 2:42"> われわれが祝福をささげる杯は、キリストの血にあずかることではありませんか。われわれが裂くパンは、キリストの体にあずかることではありませんか。</span>
<span className="v" id="v17" data-v="17" data-xref="ローマ人への手紙 12:5; コロサイ人への手紙 3:15; コリント人への第一の手紙 12:27"> パンは一つですから、大勢いるわれわれも一つの体です。われわれは皆、その一つのパンにあずかるからです。</span>
<span className="v" id="v18" data-v="18" data-xref="ピリピ人への手紙 3:3–5; ガラテヤ人への手紙 6:16; レビ記 7:6"> 肉によるイスラエルを見てください。いけにえを食べる人々は、祭壇にあずかる者ではありませんか。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="コリント人への第一の手紙 8:4; コリント人への第一の手紙 3:7; コリント人への第一の手紙 13:2"> では、私は何を言おうとしているのでしょうか。偶像に供えられた物に何か実体がある、あるいは、偶像に何か実体があるということでしょうか。</span>
<span className="v" id="v20" data-v="20" data-xref="ヨハネの黙示録 9:20; 詩篇 106:37–39; 申命記 32:16–17"> そうではありません。異邦人が供える物は、神ではなく悪霊たちに供えられている、と言っているのです。私は、あなたがたが悪霊たちと交わる者になってほしくありません。</span>
<span className="v" id="v21" data-v="21" data-xref="マタイ 6:24; 列王記第一 18:21; コリント人への第二の手紙 6:15–17"> 主の杯と悪霊たちの杯の両方を飲むことはできません。主の食卓と悪霊たちの食卓の両方にあずかることはできません。</span>
<span className="v" id="v22" data-v="22" data-xref="申命記 32:21; 申命記 32:16; ヘブル人への手紙 10:31"> それとも、われわれは主をねたませようというのですか。われわれは主より強いのですか。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="コリント人への第一の手紙 6:12; コリント人への第一の手紙 8:9; エペソ人への手紙 4:29"> 「すべてのことが私には許されている」と言っても、すべてが有益なわけではありません。「すべてのことが私には許されている」と言っても、すべてが人を築き上げるわけではありません。</span>
<span className="v" id="v24" data-v="24" data-xref="ローマ人への手紙 15:1–2; コリント人への第一の手紙 10:33; ピリピ人への手紙 2:4–5"> だれも自分の益だけを求めず、ほかの人の益を求めなさい。</span>
<span className="v" id="v25" data-v="25" data-xref="テモテへの手紙第一 4:4; コリント人への第一の手紙 8:7; テトス 1:15"> 肉市場で売られている物は何でも、良心のために詮索せずに食べなさい。</span>
<span className="v" id="v26" data-v="26" data-xref="詩篇 24:1; 出エジプト記 19:5; 詩篇 50:12"> 「地と、そこに満ちているものは、主のもの」だからです。</span>
<span className="v" id="v27" data-v="27" data-xref="コリント人への第一の手紙 10:25; ルカ 10:7–8; コリント人への第一の手紙 5:9–11"> 信じていない人に食事へ招かれ、行きたいと思うなら、出された物は何でも、良心のために詮索せずに食べなさい。</span>
<span className="v" id="v28" data-v="28" data-xref="コリント人への第一の手紙 8:10–13; コリント人への第一の手紙 8:7; コリント人への第一の手紙 10:26"> しかし、だれかが「これは偶像に供えられた物です」と言ったなら、そう教えてくれた人と良心のために、食べてはいけません。「地と、そこに満ちているものは、主のもの」だからです。</span>
<span className="v" id="v29" data-v="29" data-xref="コリント人への第一の手紙 9:19; ローマ人への手紙 14:15–21; コリント人への第一の手紙 8:9–13"> 良心と言っても、あなた自身の良心ではなく、ほかの人の良心です。なぜ私の自由が、ほかの人の良心によって裁かれるのでしょうか。</span>
<span className="v" id="v30" data-v="30" data-xref="ローマ人への手紙 14:6; テモテへの手紙第一 4:3–4"> 私が感謝して食べるなら、感謝をささげた物のために、なぜ非難されるのでしょうか。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="コロサイ人への手紙 3:17; コロサイ人への手紙 3:23; ペテロの手紙第一 4:11"> ですから、食べるにも飲むにも、何をするにも、すべて神の栄光のためにしなさい。</span>
<span className="v" id="v32" data-v="32" data-xref="使徒の働き 20:28; コリント人への第一の手紙 10:33; ローマ人への手紙 14:13"> ユダヤ人にも、ギリシャ人にも、神の教会にも、つまずきを与えてはいけません。</span>
<span className="v" id="v33" data-v="33" data-xref="コリント人への第一の手紙 10:24; ガラテヤ人への手紙 1:10; コリント人への第一の手紙 9:19–23"> 私も、自分の益ではなく、多くの人々が救われるために彼らの益を求め、あらゆることにおいてすべての人の益にかなうよう努めています。</span>
</div>

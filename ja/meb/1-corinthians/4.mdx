<span className="v" id="v1" data-v="1" data-xref="ペテロの手紙第一 4:10; テトス 1:7; テモテへの手紙第一 3:9"> ですから、人はわれわれを、キリストに仕える者、神の奥義を任された管理者と考えるべきです。</span>
<span className="v" id="v2" data-v="2" data-xref="マタイ 25:21; ルカ 12:42; ルカ 16:10–12"> さて、管理者に求められるのは、忠実であると認められることです。</span>
<span className="v" id="v3" data-v="3" data-xref="ヨハネ 7:24; コリント人への第一の手紙 2:15; サムエル記第一 16:7"> 私にとって、あなたがたから裁かれることも、人間の法廷で裁かれることも、取るに足りないことです。それどころか、私は自分で自分を裁くことさえしません。</span>
<span className="v" id="v4" data-v="4" data-xref="詩篇 143:2; ヨハネの手紙第一 3:20–21; 詩篇 130:3"> 私には、自分に責められるところは何もありません。しかし、それで義と認められるわけではありません。私を裁く方は主です。</span>
<span className="v" id="v5" data-v="5" data-xref="ヤコブの手紙 5:7; コリント人への第二の手紙 5:10; コリント人への第一の手紙 3:13"> ですから、主が来られる時まで、時に先立って何も裁いてはなりません。主は闇に隠されたものを明るみに出し、人々の心の思いを明らかにされます。その時、一人ひとりは神から称賛を受けます。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="コリント人への第二の手紙 12:6; コリント人への第二の手紙 11:4; コリント人への第二の手紙 12:19"> 兄弟たち、私はあなたがたのために、これらのことを自分とアポロに当てはめて語りました。それは、われわれを例として、「書かれていることを越えてはならない」と学び、だれも一人を持ち上げて、もう一人を見下すことがないためです。</span>
<span className="v" id="v7" data-v="7" data-xref="ヨハネ 3:27; ペテロの手紙第一 4:10; ヤコブの手紙 1:17"> いったい、だれがあなたをほかの人より優れた者とするのですか。受けなかったもので、あなたが持っているものがありますか。もし受けたのなら、なぜ受けなかったかのように誇るのですか。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="ルカ 6:25; 箴言 13:7; コリント人への第一の手紙 5:6"> あなたがたは、もう満ち足り、もう豊かになり、われわれ抜きで王になったのですね。いや、ほんとうに王となっていてくれたらよかった。そうすれば、われわれもあなたがたと共に王となれたのに。</span>
<span className="v" id="v9" data-v="9" data-xref="ヘブル人への手紙 10:33; ローマ人への手紙 8:36; コリント人への第二の手紙 4:8–12"> 私には、神がわれわれ使徒を、死刑を宣告された者のように、最後の者として引き出されたように思えます。われわれは世界に、御使いたちにも人々にも、見せ物とされたからです。</span>
<span className="v" id="v10" data-v="10" data-xref="コリント人への第一の手紙 2:3; 使徒の働き 26:24; コリント人への第一の手紙 3:18"> われわれはキリストのために愚かな者ですが、あなたがたはキリストにあって賢い者です。われわれは弱いのに、あなたがたは強い。あなたがたは尊ばれていますが、われわれは侮られています。</span>
<span className="v" id="v11" data-v="11" data-xref="ローマ人への手紙 8:35; コリント人への第二の手紙 11:23–27; ピリピ人への手紙 4:12"> 今この時に至るまで、われわれは飢え、渇き、衣にも事欠き、打たれ、住む所も定まりません。</span>
<span className="v" id="v12" data-v="12" data-xref="ペテロの手紙第一 3:9; マタイ 5:11; ペテロの手紙第一 4:12–14"> 自分の手で働き、労苦しています。ののしられても祝福し、迫害されても耐え忍びます。</span>
<span className="v" id="v13" data-v="13" data-xref="哀歌 3:45; 使徒の働き 22:22"> 悪口を言われても、言葉を尽くして応じます。今に至るまで、われわれは世のくず、すべての人から払い捨てられる汚れのようにされています。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="テサロニケ人への手紙第一 2:11; コリント人への第一の手紙 4:15; ヨハネの手紙第三 1:4"> 私がこれらのことを書くのは、あなたがたを辱めるためではなく、私の愛する子どもとして諭すためです。</span>
<span className="v" id="v15" data-v="15" data-xref="ガラテヤ人への手紙 4:19; コリント人への第一の手紙 3:10; コリント人への第一の手紙 9:14"> たとえキリストにあって一万人の養育係がいても、あなたがたに多くの父がいるわけではありません。キリスト・イエスにあって、福音を通して、私があなたがたを生んだからです。</span>
<span className="v" id="v16" data-v="16" data-xref="コリント人への第一の手紙 11:1; テサロニケ人への第二の手紙 3:9; ピリピ人への手紙 3:17"> ですから、私にならう者となってください。</span>
<span className="v" id="v17" data-v="17" data-xref="テモテへの手紙第一 1:2; コリント人への第一の手紙 16:10; コリント人への第一の手紙 7:17"> そのために、私はテモテをあなたがたのもとに遣わしました。彼は主にあって私の愛する忠実な子です。彼は、私がどこの教会でも教えているとおり、キリストにある私の歩みを、あなたがたに思い起こさせてくれます。</span>
<span className="v" id="v18" data-v="18" data-xref="コリント人への第一の手紙 4:6–8; コリント人への第一の手紙 5:2; コリント人への第一の手紙 4:21"> 私があなたがたのもとに行くことはないと思い上がっている人たちがいます。</span>
<span className="v" id="v19" data-v="19" data-xref="コリント人への第二の手紙 13:1–4; 使徒の働き 18:21; 使徒の働き 19:21"> しかし、主のみこころであれば、私はすぐにあなたがたのもとに行きます。そして、思い上がっている人たちの言葉ではなく、その力を見極めます。</span>
<span className="v" id="v20" data-v="20" data-xref="コリント人への第一の手紙 2:4; テサロニケ人への手紙第一 1:5; コリント人への第二の手紙 10:4–5"> 神の王国は言葉にではなく、力にあるからです。</span>
<span className="v" id="v21" data-v="21" data-xref="コリント人への第二の手紙 13:2; コリント人への第二の手紙 13:10; テサロニケ人への手紙第一 2:7"> あなたがたは、どちらを望みますか。私がむちを携えて行くことですか。それとも、愛と柔和な心をもって行くことですか。</span>

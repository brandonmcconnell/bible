<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="コリント人への第一の手紙 12:4–11; コリント人への第一の手紙 14:37; コリント人への第一の手紙 14:1–18"> 兄弟たち、霊的な事柄について、あなたがたに知っておいてほしいことがあります。</span>
<span className="v" id="v2" data-v="2" data-xref="ペテロの手紙第一 4:3; テサロニケ人への手紙第一 1:9; 詩篇 115:5"> あなたがたが異教徒<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="または「異邦人」。">a</a></sup>だった時には、誘われるままに、物を言わない偶像のもとへ引かれて行ったことを知っています。</span>
<span className="v" id="v3" data-v="3" data-xref="ヨハネの手紙第一 4:2–3; マタイ 16:16–17; ローマ人への手紙 10:9"> そこで、あなたがたに知らせます。神の霊によって語る人は、だれも「イエスはのろわれよ」とは言いません。また、聖霊によらなければ、だれも「イエスは主である」と言うことはできません。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="ペテロの手紙第一 4:10; コリント人への第一の手紙 12:28; ローマ人への手紙 12:4–6"> さて、賜物にはさまざまな種類がありますが、霊は同じです。</span>
<span className="v" id="v5" data-v="5" data-xref="エペソ人への手紙 4:11–12; ローマ人への手紙 12:6–8; ローマ人への手紙 14:8–9"> 奉仕にはさまざまな種類がありますが、主は同じです。</span>
<span className="v" id="v6" data-v="6" data-xref="コリント人への第一の手紙 3:7; コリント人への第一の手紙 12:11; ヨハネ 5:17"> 働きにはさまざまな種類がありますが、すべての働きをすべての人のうちに生じさせる神は同じです。</span>
<span className="v" id="v7" data-v="7" data-xref="ペテロの手紙第一 4:10–11; ローマ人への手紙 12:6–8; コリント人への第一の手紙 14:19"> 一人ひとりに霊の現れが与えられているのは、皆の益となるためです。</span>
<span className="v" id="v8" data-v="8" data-xref="箴言 2:6; コリント人への第一の手紙 2:6–10; 詩篇 143:10"> ある人には霊を通して知恵の言葉が与えられ、別の人には同じ霊によって知識の言葉が与えられます。</span>
<span className="v" id="v9" data-v="9" data-xref="ヤコブの手紙 5:14–15; コリント人への第二の手紙 4:13; エペソ人への手紙 2:8"> ある人には同じ霊によって信仰が与えられ、別の人には同じ霊によって癒やしの賜物が与えられます。</span>
<span className="v" id="v10" data-v="10" data-xref="コリント人への第一の手紙 14:39; ヨハネの手紙第一 4:1; マルコ 16:17"> ある人には奇跡を行う力、別の人には預言する力、また別の人には霊を見分ける力が与えられます。ある人にはさまざまな言語を語る力、別の人にはそれらの言語を解き明かす力が与えられます。</span>
<span className="v" id="v11" data-v="11" data-xref="コリント人への第一の手紙 12:4; ヘブル人への手紙 2:4; コリント人への第二の手紙 10:13"> これらすべてを行うのは、一つの同じ霊です。霊は、ご自分の望むままに、一人ひとりにそれぞれの賜物を分け与えます。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="ローマ人への手紙 12:4–5; コロサイ人への手紙 3:15; コリント人への第一の手紙 12:27"> 体は一つでも多くの部分があり、その多くの部分が一つの体を形づくっているように、キリストも同じです。</span>
<span className="v" id="v13" data-v="13" data-xref="エペソ人への手紙 4:5; コロサイ人への手紙 3:11; ガラテヤ人への手紙 3:28"> われわれは、ユダヤ人であれギリシャ人であれ、奴隷であれ自由人であれ、皆、一つの霊によって一つの体となるようバプテスマを受け、皆、一つの霊を飲む者とされました。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="コリント人への第一の手紙 12:27–28; コリント人への第一の手紙 12:12; エペソ人への手紙 4:25"> 体は一つの部分ではなく、多くの部分から成っています。</span>
<span className="v" id="v15" data-v="15" data-xref="士師記 9:8–15; 列王記第二 14:9"> 足が「私は手ではないから、体の一部ではない」と言ったとしても、それで体の一部でなくなるわけではありません。</span>
<span className="v" id="v16" data-v="16" data-xref="ローマ人への手紙 12:3; コリント人への第一の手紙 12:22; ピリピ人への手紙 2:3"> 耳が「私は目ではないから、体の一部ではない」と言ったとしても、それで体の一部でなくなるわけではありません。</span>
<span className="v" id="v17" data-v="17" data-xref="コリント人への第一の手紙 12:21; 詩篇 139:13–16; 箴言 20:12"> もし体全体が目なら、どこで聞くのでしょうか。体全体が耳なら、どこでにおいを嗅ぐのでしょうか。</span>
<span className="v" id="v18" data-v="18" data-xref="コリント人への第一の手紙 12:28; ローマ人への手紙 12:3; コリント人への第一の手紙 12:11"> しかし今、神はみこころのままに、一つひとつの部分を体の中に置かれました。</span>
<span className="v" id="v19" data-v="19"> もしすべてが一つの部分なら、体はどこにあるのでしょうか。</span>
<span className="v" id="v20" data-v="20" data-xref="コリント人への第一の手紙 12:14; コリント人への第一の手紙 12:12"> しかし今、多くの部分があっても、体は一つです。</span>
<span className="v" id="v21" data-v="21" data-xref="エズラ記 10:1–5; ネヘミヤ記 4:16–21; ヨブ記 29:11"> 目が手に向かって、「あなたはいらない」と言うことはできません。また、頭が足に向かって、「あなたがたはいらない」と言うこともできません。</span>
<span className="v" id="v22" data-v="22" data-xref="箴言 14:28; 伝道者の書 9:14–15; 伝道者の書 4:9–12"> それどころか、体の中でほかより弱く見える部分こそ、なくてはならないのです。</span>
<span className="v" id="v23" data-v="23" data-xref="創世記 3:21; 創世記 3:7"> また、体の中でほかより尊くないと思える部分を、われわれは一層大切に扱います。人前に出せない部分は、より念入りに覆います。</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 3:11; 創世記 2:25"> 人前に出せる部分には、その必要がありません。しかし神は、劣っている部分に一層大きな誉れを与えて、体を組み合わせられました。</span>
<span className="v" id="v25" data-v="25" data-xref="コリント人への第二の手紙 13:11; コリント人への第一の手紙 1:10–12; ヨハネ 17:21–26"> それは、体の中に分裂がなく、一つひとつの部分が互いを同じようにいたわるためです。</span>
<span className="v" id="v26" data-v="26" data-xref="ローマ人への手紙 12:15; ガラテヤ人への手紙 6:2; ヘブル人への手紙 13:3"> 一つの部分が苦しめば、すべての部分が共に苦しみます。一つの部分が尊ばれれば、すべての部分が共に喜びます。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="エペソ人への手紙 4:12; コロサイ人への手紙 1:24; エペソ人への手紙 5:30"> あなたがたはキリストの体であり、一人ひとりはその部分です。</span>
<span className="v" id="v28" data-v="28" data-xref="エペソ人への手紙 4:11–13; ローマ人への手紙 12:6–8; コリント人への第一の手紙 12:18"> 神は教会の中に、ある人々を置かれました。第一に使徒、第二に預言者、第三に教師、次に奇跡を行う者、次に癒やしの賜物を持つ者、助ける者、治める者、さまざまな言語を語る者です。</span>
<span className="v" id="v29" data-v="29" data-xref="コリント人への第一の手紙 12:4–11; コリント人への第一の手紙 12:14–20"> 皆が使徒でしょうか。皆が預言者でしょうか。皆が教師でしょうか。皆が奇跡を行う者でしょうか。</span>
<span className="v" id="v30" data-v="30" data-xref="コリント人への第一の手紙 12:10"> 皆が癒やしの賜物を持っているでしょうか。皆がさまざまな言語を語るでしょうか。皆がそれを解き明かすでしょうか。</span>
<span className="v" id="v31" data-v="31" data-xref="コリント人への第一の手紙 13:1; コリント人への第一の手紙 14:39; マタイ 5:6"> しかし、より優れた賜物を熱心に求めなさい。さらに私は、最も優れた道をあなたがたに示します。</span>
</div>

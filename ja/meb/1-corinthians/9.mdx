<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒の働き 9:17; テモテへの手紙第一 2:7; コリント人への第一の手紙 9:19"> 私は自由な者ではありませんか。使徒ではありませんか。われわれの主イエス・キリストを見たではありませんか。あなたがたは、主にあって成し遂げた私の働きではありませんか。</span>
<span className="v" id="v2" data-v="2" data-xref="コリント人への第二の手紙 12:12; ヨハネ 6:27; コリント人への第二の手紙 3:1–3"> ほかの人々にとって私が使徒でないとしても、少なくともあなたがたにとっては使徒です。あなたがたこそ、主にある私の使徒職を証明する印だからです。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="コリント人への第二の手紙 12:16–19; コリント人への第二の手紙 13:3; コリント人への第二の手紙 13:10"> 私を取り調べようとする人々に対する弁明は、こうです。</span>
<span className="v" id="v4" data-v="4" data-xref="テサロニケ人への手紙第一 2:6; テサロニケ人への第二の手紙 3:8–9; ルカ 10:7"> われわれには、食べたり飲んだりする権利がないのですか。</span>
<span className="v" id="v5" data-v="5" data-xref="ヨハネ 1:42; ヘブル人への手紙 13:4; マタイ 8:14"> ほかの使徒たちや、主の兄弟たちや、ケファのように、信者である妻を伴って旅する権利がないのですか。</span>
<span className="v" id="v6" data-v="6" data-xref="テサロニケ人への第二の手紙 3:7–9; 使徒の働き 13:1–2; 使徒の働き 4:36"> それとも、生活のために働かない権利がないのは、私とバルナバだけなのですか。</span>
<span className="v" id="v7" data-v="7" data-xref="箴言 27:18; 申命記 20:6; テモテへの第二の手紙 2:3–4"> 自分の費用で軍務につく兵士がいるでしょうか。ぶどう畑を作って、その実を食べない人がいるでしょうか。羊の群れを飼いながら、その乳を飲まない人がいるでしょうか。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="イザヤ書 8:20; テサロニケ人への手紙第一 4:8; ローマ人への手紙 3:31"> 私は人間の考えだけで、こう言っているのでしょうか。律法も同じことを言っているではありませんか。</span>
<span className="v" id="v9" data-v="9" data-xref="申命記 25:4; テモテへの手紙第一 5:18; 詩篇 104:27"> モーセの律法に、「脱穀している牛に口籠をはめてはならない」と書かれています。神が心にかけておられるのは、牛のことだけでしょうか。</span>
<span className="v" id="v10" data-v="10" data-xref="テモテへの第二の手紙 2:6; ローマ人への手紙 15:4; ローマ人への手紙 4:23–24"> それとも、確かにわれわれのために言われたのではありませんか。これはわれわれのために書かれたのです。耕す者は望みをもって耕し、脱穀する者も収穫にあずかる望みをもって働くべきだからです。</span>
<span className="v" id="v11" data-v="11" data-xref="ローマ人への手紙 15:27; ガラテヤ人への手紙 6:6; コリント人への第二の手紙 11:15"> われわれがあなたがたに霊的なものを蒔いたのなら、あなたがたから生活に必要なものを刈り取ることは、行き過ぎでしょうか。</span>
<span className="v" id="v12" data-v="12" data-xref="コリント人への第一の手紙 9:15; コリント人への第一の手紙 9:18; コリント人への第二の手紙 11:12"> ほかの人々が、あなたがたから支えを受けるこの権利にあずかっているなら、われわれにはなおさらその権利があるのではありませんか。<br />それでも、われわれはこの権利を用いませんでした。キリストの福音を少しも妨げないため、すべてを耐え忍んでいます。</span>
<span className="v" id="v13" data-v="13" data-xref="民数記 18:8–20; 民数記 5:9–10; レビ記 6:26"> 聖なる務めをする人々が神殿から出る物を食べ、祭壇に仕える人々が祭壇に供えられた物の分け前を受けることを知らないのですか。</span>
<span className="v" id="v14" data-v="14" data-xref="マタイ 10:10; テモテへの手紙第一 5:17–18; コリント人への第一の手紙 9:4"> 同じように主も、福音を宣べ伝える人々が福音によって生活するように定められました。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="テサロニケ人への手紙第一 2:9; テサロニケ人への第二の手紙 3:8; コリント人への第一の手紙 9:12"> しかし、私はこれらの権利を一つも用いませんでした。また、自分にもそのようにしてもらうために、これを書いているのではありません。だれかに私の誇りを無にされるくらいなら、死んだほうがましです。</span>
<span className="v" id="v16" data-v="16" data-xref="ローマ人への手紙 1:14; エレミヤ書 20:9; コロサイ人への手紙 4:17"> 私が福音を宣べ伝えても、それは誇る理由にはなりません。そうせずにはいられない務めを負っているからです。福音を宣べ伝えないなら、私は何と災いでしょう。</span>
<span className="v" id="v17" data-v="17" data-xref="ガラテヤ人への手紙 2:7; コリント人への第一の手紙 3:8; 歴代誌上 28:9"> 自分から進んでこれをするなら、私には報いがあります。しかし、自分から進んでするのでなくても、私には管理の務めが委ねられています。</span>
<span className="v" id="v18" data-v="18" data-xref="コリント人への第二の手紙 11:7–9; コリント人への第一の手紙 8:9; テサロニケ人への手紙第一 2:6"> では、私の報いは何でしょうか。それは、福音を宣べ伝える時、キリストの福音を無償で提供し、福音において与えられた権利をあえて用いないことです。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="ガラテヤ人への手紙 5:13; マタイ 18:15; ヤコブの手紙 5:19–20"> 私はすべての人から自由ですが、より多くの人を得るため、自ら進んですべての人の奴隷となりました。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒の働き 16:3; ガラテヤ人への手紙 5:18; 使徒の働き 21:20–26"> ユダヤ人を得るために、ユダヤ人にはユダヤ人のようになりました。律法の下にいる人々を得るために、律法の下にいる人には、私も律法の下にいる者のようになりました。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="NUでは、「私自身は律法の下にはいないが」が加えられている。">a</a></sup></span>
<span className="v" id="v21" data-v="21" data-xref="ローマ人への手紙 2:12; ローマ人への手紙 2:14; ガラテヤ人への手紙 3:2"> 律法を持たない人々を得るために、律法を持たない人には、律法を持たない者のようになりました。とはいえ、私は神に対して律法のない者ではなく、キリストの律法に服する者です。</span>
<span className="v" id="v22" data-v="22" data-xref="コリント人への第一の手紙 10:33; ローマ人への手紙 15:1; コリント人への第一の手紙 9:19"> 弱い人々を得るために、弱い人には弱い者のようになりました。何とかして幾人かでも救うために、どのような人に対しても、その人に応じた者となりました。</span>
<span className="v" id="v23" data-v="23" data-xref="テモテへの第二の手紙 2:10; マルコ 8:35; コリント人への第一の手紙 9:25–27"> 私がこのすべてを行うのは、福音のためであり、私も共に福音にあずかるためです。</span>
<span className="v" id="v24" data-v="24" data-xref="ピリピ人への手紙 3:14; ヘブル人への手紙 12:1; テモテへの第二の手紙 4:7–8"> 競走で走る人は皆走りますが、賞を受けるのは一人だと知らないのですか。あなたがたも、賞を得られるように走りなさい。</span>
<span className="v" id="v25" data-v="25" data-xref="テモテへの第二の手紙 2:5; ヨハネの黙示録 2:10; テモテへの第二の手紙 4:7–8"> 競技に出る人は皆、あらゆることについて自制します。彼らは朽ちる冠を受けるためにそうしますが、われわれは朽ちない冠を受けるためにそうするのです。</span>
<span className="v" id="v26" data-v="26" data-xref="ペテロの第二の手紙 1:10; ピリピ人への手紙 1:21; テモテへの第二の手紙 2:5"> ですから私は、目標もなく走るような走り方はしません。空を打つような拳闘もしません。</span>
<span className="v" id="v27" data-v="27" data-xref="ローマ人への手紙 8:13; コリント人への第一の手紙 9:25; コロサイ人への手紙 3:5"> むしろ、自分の体を打ちたたいて服従させます。ほかの人々に宣べ伝えておきながら、自分自身が失格者とならないためです。</span>
</div>

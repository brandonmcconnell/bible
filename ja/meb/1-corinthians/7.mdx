<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="コリント人への第一の手紙 7:8; コリント人への第一の手紙 7:26–27; コリント人への第一の手紙 7:37–38"> さて、あなたがたが書いてよこしたことについて答えます。男は女に触れないほうが良いのです。</span>
<span className="v" id="v2" data-v="2" data-xref="エペソ人への手紙 5:28; エペソ人への手紙 5:33; コリント人への第一の手紙 7:9"> しかし、淫らな行いを避けるため、男はそれぞれ自分の妻を持ち、女もそれぞれ自分の夫を持ちなさい。</span>
<span className="v" id="v3" data-v="3" data-xref="ペテロの手紙第一 3:7; 出エジプト記 21:10"> 夫は妻に対して、妻に負う愛情を示しなさい。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="NUとTRでは、「妻に負う愛情」の代わりに「妻に負うもの」となっている。">a</a></sup>妻も同じように、夫に対してそうしなさい。</span>
<span className="v" id="v4" data-v="4" data-xref="ホセア書 3:3; マタイ 19:9; マルコ 10:11–12"> 妻は自分の体を意のままにする権利を持たず、夫がその権利を持っています。同じように、夫も自分の体を意のままにする権利を持たず、妻がその権利を持っています。</span>
<span className="v" id="v5" data-v="5" data-xref="出エジプト記 19:15; ヨエル書 2:16; ゼカリヤ書 12:12–14"> 互いに拒み合ってはなりません。ただし、断食と祈りに専念するため、互いに同意の上で、しばらく離れるのはかまいません。その後は再び一緒になりなさい。自制できないために、サタンがあなたがたを誘惑することのないようにするためです。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="コリント人への第二の手紙 8:8; コリント人への第一の手紙 7:25; コリント人への第一の手紙 7:12"> ただし、私がこう言うのは譲歩であって、命令ではありません。</span>
<span className="v" id="v7" data-v="7" data-xref="マタイ 19:11–12; ローマ人への手紙 12:6; コリント人への第一の手紙 9:5"> 私としては、すべての人が私のようであればよいと思います。しかし、一人ひとりが神から自分の賜物を受けており、ある人にはこの賜物、別の人には別の賜物があります。</span>
<span className="v" id="v8" data-v="8" data-xref="コリント人への第一の手紙 7:32; コリント人への第一の手紙 7:34–35; コリント人への第一の手紙 7:26–27"> 結婚していない人とやもめには、私のようにそのままでいるのが良い、と言います。</span>
<span className="v" id="v9" data-v="9" data-xref="コリント人への第一の手紙 7:2; テモテへの手紙第一 5:14; テモテへの手紙第一 5:11"> しかし、自制できないなら、結婚しなさい。情欲に燃えるより、結婚するほうが良いからです。</span>
<span className="v" id="v10" data-v="10" data-xref="マタイ 5:32; ルカ 16:18; マタイ 19:3–9"> 結婚している人々に命じておられるのは、私ではなく主です。妻は夫と別れてはなりません。</span>
<span className="v" id="v11" data-v="11" data-xref="エレミヤ書 3:1; コリント人への第一の手紙 7:10; イザヤ書 50:1"> もし別れたなら、結婚しないままでいるか、夫と和解しなさい。また、夫は妻と別れてはなりません。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="コリント人への第二の手紙 11:17; コリント人への第一の手紙 7:6; コリント人への第一の手紙 7:25"> そのほかの人々には、主ではなく私が言います。ある兄弟に信者でない妻がいて、彼と共に暮らすことを妻が望んでいるなら、妻と別れてはなりません。</span>
<span className="v" id="v13" data-v="13"> また、ある女に信者でない夫がいて、彼女と共に暮らすことを夫が望んでいるなら、夫と別れてはなりません。</span>
<span className="v" id="v14" data-v="14" data-xref="マラキ書 2:15–16; テモテへの手紙第一 4:5; テトス 1:15"> 信者でない夫は妻によって聖なる者とされ、信者でない妻も夫によって聖なる者とされているからです。そうでなければ、あなたがたの子どもは汚れた者となりますが、今は聖なる者です。</span>
<span className="v" id="v15" data-v="15" data-xref="ローマ人への手紙 14:19; コリント人への第二の手紙 13:11; ヤコブの手紙 3:17–18"> しかし、信者でない者が去るなら、去らせなさい。そのような場合、兄弟も姉妹も縛られてはいません。神はわれわれを平和に生きるよう召されたのです。</span>
<span className="v" id="v16" data-v="16" data-xref="ペテロの手紙第一 3:1–2; コリント人への第一の手紙 9:22; ローマ人への手紙 11:14"> 妻よ、あなたが夫を救えるかどうか、どうして分かるのですか。夫よ、あなたが妻を救えるかどうか、どうして分かるのですか。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="コリント人への第一の手紙 4:17; ローマ人への手紙 12:3–8; コリント人への第一の手紙 7:24"> ただ、それぞれが主から分け与えられたとおり、神に召された時の境遇に従って歩みなさい。私はすべての教会で、このように命じています。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="使徒の働き 15:5; 使徒の働き 15:28; 使徒の働き 15:24"> 割礼を受けた状態で召された人は、その跡を消そうとしてはなりません。割礼を受けていない状態で召された人は、割礼を受けてはなりません。</span>
<span className="v" id="v19" data-v="19" data-xref="ガラテヤ人への手紙 6:15; ガラテヤ人への手紙 5:6; ヨハネの手紙第一 2:3–4"> 割礼を受けていることも、受けていないことも、問題ではありません。大切なのは、神の戒めを守ることです。</span>
<span className="v" id="v20" data-v="20" data-xref="コリント人への第一の手紙 7:17; テサロニケ人への手紙第一 4:11; テサロニケ人への第二の手紙 3:12"> 一人ひとり、召された時の境遇にとどまりなさい。</span>
<span className="v" id="v21" data-v="21" data-xref="ペテロの手紙第一 2:18–24; コロサイ人への手紙 3:11; ルカ 10:40–41"> 奴隷の身で召されましたか。それを気にしてはいけません。ただし、自由になれる機会があるなら、その機会を生かしなさい。</span>
<span className="v" id="v22" data-v="22" data-xref="ペテロの手紙第一 2:16; フィレモンへの手紙 1:16; コロサイ人への手紙 3:22–24"> 奴隷の身で主に召された者は、主によって自由にされた者です。同じように、自由の身で召された者は、キリストの奴隷です。</span>
<span className="v" id="v23" data-v="23" data-xref="コリント人への第一の手紙 6:20; ペテロの手紙第一 1:18–19; テトス 2:14"> あなたがたは代価を払って買い取られました。人の奴隷となってはいけません。</span>
<span className="v" id="v24" data-v="24" data-xref="コリント人への第一の手紙 7:20; コロサイ人への手紙 3:23–24; コリント人への第一の手紙 7:17"> 兄弟たち、一人ひとり、召された時の境遇のまま、神の前にとどまりなさい。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="コリント人への第一の手紙 7:6; コリント人への第一の手紙 4:2; コリント人への第一の手紙 7:40"> 処女については、私は主から命令を受けていません。しかし、主のあわれみを受けて信頼できる者とされた者として、私の判断を述べます。</span>
<span className="v" id="v26" data-v="26" data-xref="コリント人への第一の手紙 7:1; コリント人への第一の手紙 7:8; ペテロの手紙第一 4:17"> 今われわれに迫っている苦難のため、人は今のままでいるのが良いと、私は思います。</span>
<span className="v" id="v27" data-v="27" data-xref="コリント人への第一の手紙 7:20; コリント人への第一の手紙 7:12–14"> 妻と結ばれていますか。別れようとしてはいけません。妻から解かれていますか。妻を求めてはいけません。</span>
<span className="v" id="v28" data-v="28" data-xref="ヘブル人への手紙 13:4; コリント人への第一の手紙 7:32–36; コリント人への第一の手紙 7:26"> しかし、結婚しても罪を犯したことにはなりません。処女が結婚しても罪を犯したことにはなりません。ただ、そのような人々は身に苦難を受けるでしょう。私はあなたがたをその苦難から免れさせたいのです。</span>
<span className="v" id="v29" data-v="29" data-xref="ヨハネの手紙第一 2:17; コリント人への第一の手紙 7:31; ローマ人への手紙 13:11–12"> 兄弟たち、私が言いたいのはこうです。残された時は短いのです。今からは、妻のある人は、妻がないかのようにしなさい。</span>
<span className="v" id="v30" data-v="30" data-xref="詩篇 30:5; ルカ 6:25; ルカ 6:21"> 泣く人は泣いていないかのように、喜ぶ人は喜んでいないかのように、買う人は所有していないかのようにしなさい。</span>
<span className="v" id="v31" data-v="31" data-xref="ヨハネの手紙第一 2:17; ペテロの手紙第一 4:7; ヤコブの手紙 4:14"> この世を用いる人は、それを使い尽くさないようにしなさい。この世の有様は過ぎ去るからです。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="マタイ 6:25–34; テモテへの手紙第一 5:5; ピリピ人への手紙 4:6"> 私は、あなたがたに思い煩いがないようにと願っています。結婚していない男は、どうすれば主に喜ばれるかと、主のことに心を配ります。</span>
<span className="v" id="v33" data-v="33" data-xref="ペテロの手紙第一 3:7; コロサイ人への手紙 3:19; エペソ人への手紙 5:25–33"> しかし、結婚している男は、どうすれば妻に喜ばれるかと、この世のことに心を配ります。</span>
<span className="v" id="v34" data-v="34" data-xref="ルカ 10:40–42; コリント人への第一の手紙 6:20; ルカ 2:36–37"> 妻と処女にも違いがあります。結婚していない女は、体においても霊においても聖なる者となるため、主のことに心を配ります。しかし、結婚している女は、どうすれば夫に喜ばれるかと、この世のことに心を配ります。</span>
<span className="v" id="v35" data-v="35" data-xref="コリント人への第一の手紙 7:33–34; コリント人への第一の手紙 7:36; ルカ 8:14"> 私がこう言うのは、あなたがた自身の益のためです。あなたがたを束縛するためではなく、ふさわしく振る舞い、心を乱されずに主に仕えるためです。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="コリント人への第一の手紙 7:37; コリント人への第一の手紙 7:9; サムエル記第一 2:33"> もし、ある男が、自分に委ねられている処女に対してふさわしく振る舞っていないと思い、彼女がすでに若い盛りを過ぎていて、結婚させる必要があるなら、望むとおりにしなさい。罪を犯すことにはなりません。二人を結婚させなさい。</span>
<span className="v" id="v37" data-v="37"> しかし、心を堅く定め、必要に迫られず、自分の意志を制することができ、自分に委ねられている処女をそのままにしておこうと心に決めた人は、良いことをしています。</span>
<span className="v" id="v38" data-v="38" data-xref="ヘブル人への手紙 13:4; コリント人への第一の手紙 7:1–2; コリント人への第一の手紙 7:8"> ですから、自分に委ねられている処女を結婚させる人は良いことをし、結婚させない人はさらに良いことをするのです。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="ローマ人への手紙 7:2–3; コリント人への第二の手紙 6:14–16; コリント人への第一の手紙 7:10"> 妻は、夫が生きている間は律法によって夫に結ばれています。しかし、夫が死ねば、望む人と結婚する自由があります。ただし、主にある人とだけです。</span>
<span className="v" id="v40" data-v="40" data-xref="コリント人への第一の手紙 7:35; ペテロの第二の手紙 3:15–16; コリント人への第一の手紙 7:8"> しかし私の判断では、そのままでいるほうが幸いです。そして私も、神の霊を持っていると思います。</span>
</div>

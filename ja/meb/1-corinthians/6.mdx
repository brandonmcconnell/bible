<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マタイ 18:15–17; 使徒の働き 19:38; コリント人への第一の手紙 14:33"> あなたがたのうち、仲間に対して訴えがある時、聖徒たちの前ではなく、あえて義でない人々の前に訴え出る者がいるのですか。</span>
<span className="v" id="v2" data-v="2" data-xref="マタイ 19:28; ダニエル書 7:22; ヨハネの黙示録 20:4"> 聖徒たちが世界を裁くことを知らないのですか。世界があなたがたによって裁かれるのなら、ごく小さな問題を裁く資格もないのですか。</span>
<span className="v" id="v3" data-v="3" data-xref="ユダ 1:6; マタイ 25:41; コリント人への第一の手紙 6:4"> われわれが御使いたちを裁くことを知らないのですか。まして、この世の生活に関する事柄は言うまでもありません。</span>
<span className="v" id="v4" data-v="4" data-xref="コリント人への第一の手紙 5:12; 使徒の働き 6:2–4"> それなのに、この世の生活に関する問題を裁く時、教会で重んじられていない人々を裁判官に立てるのですか。</span>
<span className="v" id="v5" data-v="5" data-xref="コリント人への第一の手紙 15:34; コリント人への第一の手紙 4:14; ヤコブの手紙 3:13–18"> 私がこう言うのは、あなたがたに恥を覚えさせるためです。兄弟の間を裁定できる知恵ある者が、あなたがたの中には一人もいないのですか。</span>
<span className="v" id="v6" data-v="6" data-xref="ピリピ人への手紙 2:14–15; ヨハネの手紙第一 2:9–11; ヨハネの手紙第一 3:11–15"> それどころか、兄弟が兄弟を訴え、しかも信じていない人々の前に訴え出ています。</span>
<span className="v" id="v7" data-v="7" data-xref="ローマ人への手紙 12:17–19; 箴言 20:22; ペテロの手紙第一 2:19–23"> そもそも互いに訴え合うこと自体が、すでにあなたがたの敗北です。なぜ、むしろ不正を受けないのですか。なぜ、むしろだまし取られるままにしないのですか。</span>
<span className="v" id="v8" data-v="8" data-xref="テサロニケ人への手紙第一 4:6; コロサイ人への手紙 3:25; マルコ 10:19"> ところが、あなたがた自身が不正を行い、だまし取っています。それも兄弟たちに対してです。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="テモテへの手紙第一 1:9–10; ガラテヤ人への手紙 5:19–21; エペソ人への手紙 5:4–5"> それとも、義でない者は神の王国を受け継げないことを知らないのですか。思い違いをしてはいけません。淫らな行いをする者、偶像を礼拝する者、姦淫する者、男娼、男色を行う者、</span>
<span className="v" id="v10" data-v="10" data-xref="コリント人への第一の手紙 5:11; ガラテヤ人への手紙 5:21; エゼキエル書 22:29"> 盗む者、貪欲な者、酒に酔う者、人をののしる者、人から奪い取る者は、神の王国を受け継ぐことができません。</span>
<span className="v" id="v11" data-v="11" data-xref="コリント人への第一の手紙 1:30; コロサイ人への手紙 3:5–7; コリント人への第一の手紙 1:2"> あなたがたの中にも、以前はそのような者がいました。しかし、あなたがたは洗われ、聖なる者とされ、主イエスの名とわれわれの神の霊によって義とされました。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="コリント人への第一の手紙 10:23–33; コリント人への第一の手紙 9:27; ヘブル人への手紙 12:15–16"> 「私にはすべてのことが許されている」と言っても、すべてが有益なわけではありません。「私にはすべてのことが許されている」と言っても、私は何ものにも支配されはしません。</span>
<span className="v" id="v13" data-v="13" data-xref="コリント人への第一の手紙 6:19; コリント人への第一の手紙 3:16; ローマ人への手紙 6:12"> 「食物は腹のため、腹は食物のため」と言っても、神はそのどちらも滅ぼされます。体は淫らな行いのためではなく、主のためにあり、主も体のためにおられます。</span>
<span className="v" id="v14" data-v="14" data-xref="コリント人への第二の手紙 4:14; ローマ人への手紙 8:11; エペソ人への手紙 1:19–20"> 神は主をよみがえらせ、ご自分の力によってわれわれをもよみがえらせてくださいます。</span>
<span className="v" id="v15" data-v="15" data-xref="エペソ人への手紙 5:30; ローマ人への手紙 12:5; エペソ人への手紙 4:15–16"> あなたがたの体がキリストの体の一部であることを知らないのですか。それなら、キリストの体の一部を取って、娼婦の体の一部としてよいでしょうか。決してそのようなことがあってはなりません。</span>
<span className="v" id="v16" data-v="16" data-xref="創世記 2:24; エペソ人への手紙 5:31; マルコ 10:8"> それとも、娼婦と結ばれる者は、その女と一つの体になることを知らないのですか。「二人は一つの肉となる」と神は言われます。</span>
<span className="v" id="v17" data-v="17" data-xref="ヨハネ 17:21–23; ガラテヤ人への手紙 2:20; コリント人への第一の手紙 12:13"> しかし、主と結ばれる者は、主と一つの霊になります。</span>
<span className="v" id="v18" data-v="18" data-xref="ペテロの手紙第一 2:11; テサロニケ人への手紙第一 4:3; コロサイ人への手紙 3:5"> 淫らな行いから逃げなさい。「人が犯す罪はすべて体の外にある」と言われますが、淫らな行いをする者は、自分の体そのものに対して罪を犯すのです。</span>
<span className="v" id="v19" data-v="19" data-xref="コリント人への第一の手紙 3:16; コリント人への第二の手紙 6:16; ペテロの手紙第一 2:5"> それとも、あなたがたの体は、あなたがたのうちにおられる聖霊の神殿であることを知らないのですか。この聖霊を、あなたがたは神から受けました。あなたがたは自分自身のものではありません。</span>
<span className="v" id="v20" data-v="20" data-xref="コリント人への第一の手紙 7:23; ローマ人への手紙 12:1; ペテロの手紙第一 2:9"> あなたがたは代価を払って買い取られたからです。ですから、自分の体と霊をもって神の栄光を現しなさい。あなたがたの体も霊も神のものです。</span>

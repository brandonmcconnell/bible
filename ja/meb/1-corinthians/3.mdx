<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヘブル人への手紙 5:13; コリント人への第一の手紙 2:14–15; エペソ人への手紙 4:13–14"> 兄弟たち、私はあなたがたに、霊に属する人に対するようには語れず、肉に属する人、キリストにある幼子に対するように語りました。</span>
<span className="v" id="v2" data-v="2" data-xref="ヘブル人への手紙 5:11–14; ヨハネ 16:12; ペテロの手紙第一 2:2"> 私はあなたがたに乳を飲ませ、固い食物は与えませんでした。あなたがたにはまだ受け入れることができなかったからです。実際、今でもまだ受け入れることができません。</span>
<span className="v" id="v3" data-v="3" data-xref="ヤコブの手紙 3:16; ガラテヤ人への手紙 5:15; テトス 3:3"> あなたがたは依然として肉に属しているからです。あなたがたの間にねたみや争いや分派がある以上、肉に属し、ただの人のように歩んでいるのではありませんか。</span>
<span className="v" id="v4" data-v="4" data-xref="コリント人への第一の手紙 1:12; コリント人への第一の手紙 3:3; コリント人への第一の手紙 4:6"> ある人が「私はパウロにつく」と言い、別の人が「私はアポロにつく」と言うなら、あなたがたは肉に属する者ではありませんか。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="コリント人への第二の手紙 6:4; コリント人への第二の手紙 6:1; ペテロの手紙第一 4:10"> では、アポロとは何者ですか。パウロとは何者ですか。あなたがたが信じるに至るために仕えた者にすぎず、それぞれが主から与えられた務めを果たしたのです。</span>
<span className="v" id="v6" data-v="6" data-xref="コリント人への第一の手紙 3:9–10; 箴言 11:25; コリント人への第二の手紙 10:14–15"> 私が植え、アポロが水を注ぎました。しかし、成長させてくださったのは神です。</span>
<span className="v" id="v7" data-v="7" data-xref="ヨハネ 15:5; ガラテヤ人への手紙 6:3; 詩篇 115:1"> ですから、植える者も水を注ぐ者も取るに足りず、成長させてくださる神こそがすべてです。</span>
<span className="v" id="v8" data-v="8" data-xref="ローマ人への手紙 2:6; マタイ 16:27; ヨハネの手紙第二 1:8"> 植える者と水を注ぐ者は一つですが、それぞれが自分の働きに応じて報いを受けます。</span>
<span className="v" id="v9" data-v="9" data-xref="ペテロの手紙第一 2:5; エペソ人への手紙 2:20–22; コリント人への第二の手紙 6:1"> われわれは神に仕える同労者です。あなたがたは神の畑、神の建物です。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="コリント人への第一の手紙 3:11; エペソ人への手紙 2:20; ローマ人への手紙 15:20"> 私は、与えられた神の恵みに従い、熟練した建築家のように土台を据え、ほかの人がその上に建てています。しかし、一人ひとり、どのようにその上に建てるか注意しなければなりません。</span>
<span className="v" id="v11" data-v="11" data-xref="エペソ人への手紙 2:20; イザヤ書 28:16; テモテへの第二の手紙 2:19"> すでに据えられている土台、すなわちイエス・キリスト以外に、だれも別の土台を据えることはできないからです。</span>
<span className="v" id="v12" data-v="12" data-xref="テモテへの第二の手紙 4:3; テモテへの第二の手紙 3:7; テモテへの第二の手紙 2:20"> もしだれかが、その土台の上に、金、銀、宝石、木、草、わらで建てるなら、</span>
<span className="v" id="v13" data-v="13" data-xref="ペテロの手紙第一 1:7; コリント人への第一の手紙 3:14–15; ヨハネの黙示録 20:12"> 一人ひとりの働きは明らかになります。「その日」がそれを明らかにするからです。その日は火の中に現れ、その火が、一人ひとりの働きがどのようなものかを試します。</span>
<span className="v" id="v14" data-v="14" data-xref="コリント人への第一の手紙 3:8; マタイ 25:21–23; コリント人への第一の手紙 4:5"> その土台の上に建てたものが残れば、その人は報いを受けます。</span>
<span className="v" id="v15" data-v="15" data-xref="ヨハネの手紙第二 1:8; コリント人への第一の手紙 3:12–13; ユダ 1:23"> もしその人の働きが焼ければ、損失を受けますが、その人自身は救われます。ただし、火をくぐり抜けるようにしてです。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="コリント人への第一の手紙 6:19; エゼキエル書 36:27; コリント人への第二の手紙 6:16"> あなたがたは神の神殿であり、神の霊があなたがたのうちに住んでいることを知らないのですか。</span>
<span className="v" id="v17" data-v="17" data-xref="コリント人への第一の手紙 6:18–20; エゼキエル書 43:12; 民数記 19:20"> もしだれかが神の神殿を滅ぼすなら、神がその人を滅ぼされます。神の神殿は聖なるものであり、その神殿とはあなたがたのことだからです。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="箴言 3:5; イザヤ書 5:21; ガラテヤ人への手紙 6:3"> だれも自分を欺いてはなりません。あなたがたのうちに、自分はこの世で知恵ある者だと思う人がいるなら、知恵ある者となるために愚かな者となりなさい。</span>
<span className="v" id="v19" data-v="19" data-xref="ヨブ記 5:13; 詩篇 141:10; コリント人への第一の手紙 1:19–20"> この世の知恵は、神の前では愚かだからです。「神は知恵ある者を、その悪賢さによって捕らえる」と書かれています。</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 94:11; コロサイ人への手紙 2:8; ローマ人への手紙 1:21"> また、「主は知恵ある者の考えがむなしいことを知っておられる」とも書かれています。</span>
<span className="v" id="v21" data-v="21" data-xref="ローマ人への手紙 8:32; ローマ人への手紙 8:28; エレミヤ書 9:23–24"> ですから、だれも人を誇ってはなりません。すべてはあなたがたのものです。</span>
<span className="v" id="v22" data-v="22" data-xref="エペソ人への手紙 4:11–12; ピリピ人への手紙 1:21; コリント人への第一の手紙 9:19–22"> パウロも、アポロも、ケファも、世界も、生も、死も、今あるものも、後に来るものも、すべてあなたがたのものです。</span>
<span className="v" id="v23" data-v="23" data-xref="ガラテヤ人への手紙 3:29; コリント人への第一の手紙 11:3; ヨハネ 17:9–10"> あなたがたはキリストのもの、キリストは神のものです。</span>
</div>

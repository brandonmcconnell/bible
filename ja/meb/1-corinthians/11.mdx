<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ピリピ人への手紙 3:17; テサロニケ人への手紙第一 1:6; コリント人への第一の手紙 4:16"> 私がキリストにならっているように、あなたがたも私にならう者となってください。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="テサロニケ人への第二の手紙 2:15; コリント人への第一の手紙 4:17; 箴言 31:28–31"> 兄弟たち、あなたがたがあらゆることにおいて私を覚え、私が伝えたとおりに教えを堅く守っているので、あなたがたを称賛します。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 3:16; コロサイ人への手紙 1:18; コロサイ人への手紙 3:18"> しかし、あなたがたに知ってほしいことがあります。すべての男の頭<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="または「源」。">a</a></sup>はキリスト、女の頭<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="または「源」。">b</a></sup>は男、キリストの頭<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="または「源」。">c</a></sup>は神です。</span>
<span className="v" id="v4" data-v="4" data-xref="サムエル記第二 15:30; コリント人への第一の手紙 12:28; コリント人への第一の手紙 12:10"> 男が祈ったり預言したりする時、頭を覆っているなら、自分の頭を辱めます。</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 21:12; ルカ 2:36; 使徒の働き 2:17"> しかし、女が祈ったり預言したりする時、頭を覆っていないなら、自分の頭を辱めます。それは髪をそり落としたのと同じことだからです。</span>
<span className="v" id="v6" data-v="6" data-xref="申命記 22:5; 民数記 5:18"> 女が頭を覆わないのなら、髪も切ってしまいなさい。しかし、女が髪を切ったり、そり落としたりすることが恥ずかしいなら、頭を覆いなさい。</span>
<span className="v" id="v7" data-v="7" data-xref="コリント人への第一の手紙 11:3; 創世記 5:1; 詩篇 8:6"> 男は神のかたちであり、神の栄光なので、頭を覆うべきではありません。しかし、女は男の栄光です。</span>
<span className="v" id="v8" data-v="8" data-xref="テモテへの手紙第一 2:13; 創世記 2:21–23"> 男が女から出たのではなく、女が男から出たからです。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 2:18; 創世記 2:23–24; 創世記 2:20"> また、男が女のために造られたのではなく、女が男のために造られました。</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 24:64–65; ヘブル人への手紙 1:14; マタイ 18:10"> そのため、御使いたちのゆえに、女は自分の頭を治める権威を持つべきです。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="ガラテヤ人への手紙 3:28; コリント人への第一の手紙 7:10–14; コリント人への第一の手紙 12:12–22"> とはいえ、主にあっては、女は男から独立しておらず、男も女から独立していません。</span>
<span className="v" id="v12" data-v="12" data-xref="ローマ人への手紙 11:36; コリント人への第一の手紙 8:6; ヘブル人への手紙 1:2–3"> 女が男から出たように、男も女を通して生まれます。しかし、すべては神から出ています。</span>
<span className="v" id="v13" data-v="13" data-xref="ルカ 12:57; ヨハネ 7:24; コリント人への第一の手紙 10:15"> 自分で判断してください。女が頭を覆わずに神に祈ることは、ふさわしいでしょうか。</span>
<span className="v" id="v14" data-v="14" data-xref="サムエル記第二 14:26; コリント人への第一の手紙 14:35"> 男が長い髪をしていれば、その人の恥となることを、自然そのものもあなたがたに教えているではありませんか。</span>
<span className="v" id="v15" data-v="15"> しかし、女が長い髪をしていれば、それはその人の栄光です。髪は覆いとして与えられているからです。</span>
<span className="v" id="v16" data-v="16" data-xref="コリント人への第一の手紙 7:17; テモテへの手紙第一 6:3–4; テサロニケ人への手紙第一 2:14"> それでも言い争おうとする人がいるなら、われわれにはそのような習慣はなく、神の諸教会にもありません。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="ヘブル人への手紙 10:25; コリント人への第一の手紙 14:23; コリント人への第一の手紙 11:22"> 次のことを命じるにあたっては、あなたがたを称賛できません。あなたがたが集まっても、良くなるどころか、かえって悪くなっているからです。</span>
<span className="v" id="v18" data-v="18" data-xref="コリント人への第一の手紙 3:3; コリント人への第一の手紙 1:10–12; コリント人への第一の手紙 5:1"> まず、あなたがたが教会に集まる時、あなたがたの間に分裂があると聞いています。ある程度はそうだろうと思います。</span>
<span className="v" id="v19" data-v="19" data-xref="ヨハネの手紙第一 2:19; テトス 3:10; 使徒の働き 20:30"> あなたがたの中で真に認められた人々が明らかになるためには、あなたがたの間に分派も生じるはずだからです。</span>
<span className="v" id="v20" data-v="20"> ですから、あなたがたが一つの所に集まっても、主の晩餐を食べていることにはなりません。</span>
<span className="v" id="v21" data-v="21" data-xref="ペテロの第二の手紙 2:13; ユダ 1:12; コリント人への第一の手紙 11:23–25"> 食べる時、それぞれが自分の食事を先に食べてしまい、空腹の人がいる一方で、酔っている人もいるからです。</span>
<span className="v" id="v22" data-v="22" data-xref="使徒の働き 20:28; 箴言 17:5; ヤコブの手紙 2:5–6"> あなたがたには、飲み食いする家がないのですか。それとも、神の教会を軽んじ、何も持たない人々に恥をかかせるのですか。あなたがたに何と言えばよいでしょう。称賛すべきでしょうか。このことでは称賛できません。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="ルカ 22:19–20; マタイ 26:26–28; コリント人への第一の手紙 11:23–25"> 私は主から受けたことを、あなたがたにも伝えました。すなわち、主イエスは裏切られた夜、パンを取り、</span>
<span className="v" id="v24" data-v="24" data-xref="ヨハネ 6:53–58; コリント人への第一の手紙 11:27–28; コリント人への第一の手紙 10:3–4"> 感謝をささげてから、それを裂いて言われました。<span className="woj">「取って食べなさい。これは、あなたがたのために裂かれる、わたしの体です。わたしを覚えて、これを行いなさい。」</span></span>
<span className="v" id="v25" data-v="25" data-xref="ルカ 22:20; ヘブル人への手紙 9:15–20; ヘブル人への手紙 13:20"> 食事の後、同じように杯を取り、こう言われました。<span className="woj">「この杯は、わたしの血による新しい契約です。飲むたびに、わたしを覚えて、これを行いなさい。」</span></span>
<span className="v" id="v26" data-v="26" data-xref="ヘブル人への手紙 9:28; ヨハネの黙示録 1:7; ヨハネ 14:3"> あなたがたは、このパンを食べ、この杯を飲むたびに、主が来られる時まで、主の死を告げ知らせるのです。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="ヨハネ 6:51; コリント人への第一の手紙 10:21; ヘブル人への手紙 10:29"> ですから、主にふさわしくない仕方でこのパンを食べたり、主の杯を飲んだりする者は、主の体と血に対して罪を犯すことになります。</span>
<span className="v" id="v28" data-v="28" data-xref="ガラテヤ人への手紙 6:4; コリント人への第二の手紙 13:5; 哀歌 3:40"> 一人ひとり、自分を吟味してから、そのパンを食べ、その杯から飲みなさい。</span>
<span className="v" id="v29" data-v="29" data-xref="コリント人への第一の手紙 11:27; コリント人への第一の手紙 11:30; コリント人への第一の手紙 11:32–34"> 主の体をわきまえず、ふさわしくない仕方で食べたり飲んだりする者は、自分に対する裁きを食べ、また飲むことになるからです。</span>
<span className="v" id="v30" data-v="30" data-xref="ヨハネの黙示録 3:19; 民数記 20:12; アモス書 3:2"> そのため、あなたがたの中には、弱い人や病気の人が多く、眠りについた人も少なくありません。</span>
<span className="v" id="v31" data-v="31" data-xref="ヨハネの手紙第一 1:9; 詩篇 32:3–5; ヨハネの黙示録 2:5"> もしわれわれが自分自身を正しくわきまえるなら、裁かれることはありません。</span>
<span className="v" id="v32" data-v="32" data-xref="ヘブル人への手紙 12:5–11; 詩篇 118:18; 箴言 3:11–12"> しかし、われわれが裁かれる時は、この世と共に罪に定められないために、主から懲らしめを受けているのです。</span>
<span className="v" id="v33" data-v="33"> ですから、私の兄弟たち、食べるために集まる時は、互いに待ちなさい。</span>
<span className="v" id="v34" data-v="34" data-xref="コリント人への第一の手紙 11:21–22; コリント人への第一の手紙 7:17; コリント人への第一の手紙 4:19"> 空腹なら、家で食べなさい。あなたがたが集まることによって、裁きを受けないためです。そのほかのことは、私がそちらへ行った時に整えます。</span>
</div>

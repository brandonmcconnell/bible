<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="コリント人への第一の手紙 14:39; テモテへの手紙第一 4:14; コリント人への第一の手紙 12:1"> 愛を追い求め、霊の賜物を熱心に求めなさい。特に、預言できるように求めなさい。</span>
<span className="v" id="v2" data-v="2" data-xref="マルコ 16:17; 使徒の働き 19:6; 使徒の働き 10:46"> ほかの言語で語る人は、人にではなく神に語っています。だれも理解せず、霊によって奥義を語っているからです。</span>
<span className="v" id="v3" data-v="3" data-xref="コリント人への第一の手紙 14:12; テモテへの手紙第一 4:13; ユダ 1:20"> しかし、預言する人は、人を築き上げ、励まし、慰めるために語ります。</span>
<span className="v" id="v4" data-v="4" data-xref="コリント人への第一の手紙 14:22; コリント人への第一の手紙 14:26; マルコ 16:17"> ほかの言語で語る人は自分を築き上げますが、預言する人は教会を築き上げます。</span>
<span className="v" id="v5" data-v="5" data-xref="コリント人への第一の手紙 12:28–30; コリント人への第一の手紙 12:10; マルコ 16:17"> 私は、あなたがた全員がほかの言語で語ることを望みますが、それ以上に、預言することを望みます。ほかの言語で語る人がそれを解き明かして教会を築き上げるのでなければ、預言する人のほうが優れているからです。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="エペソ人への手紙 1:17; ローマ人への手紙 6:17; テモテへの第二の手紙 3:16"> 兄弟たち、<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="ここや、文脈上可能な箇所で「兄弟たち」と訳されている言葉は、「兄弟姉妹」あるいは「きょうだいたち」と訳すこともできる。">a</a></sup>もし私があなたがたのもとに行って、ほかの言語で語るとしても、啓示、知識、預言、教えのいずれかによって語らなければ、あなたがたに何の益があるでしょうか。</span>
<span className="v" id="v7" data-v="7" data-xref="コリント人への第一の手紙 14:8; ルカ 7:32; コリント人への第一の手紙 13:1"> 笛や竪琴のように、音を出す命のない物でさえ、一つひとつの音に違いがなければ、何を吹き、何を弾いているのか、どうして分かるでしょうか。</span>
<span className="v" id="v8" data-v="8" data-xref="民数記 10:9; エゼキエル書 33:3–6; エレミヤ書 4:19"> ラッパがはっきりしない音を出すなら、だれが戦いの準備をするでしょうか。</span>
<span className="v" id="v9" data-v="9" data-xref="コリント人への第一の手紙 9:26"> 同じように、あなたがたも、舌ではっきり理解できる言葉を発しなければ、語られていることがどうして分かるでしょうか。空に向かって語ることになるでしょう。</span>
<span className="v" id="v10" data-v="10"> 世界には実に多くの種類の言語がありますが、意味を持たない言語は一つもありません。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒の働き 28:2; ローマ人への手紙 1:14; コロサイ人への手紙 3:11"> ですから、もし私がその言語の意味を知らなければ、話す人にとって私は外国人となり、話す人も私にとって外国人となります。</span>
<span className="v" id="v12" data-v="12" data-xref="コリント人への第一の手紙 14:26; コリント人への第一の手紙 14:3–4; コリント人への第一の手紙 14:1"> あなたがたも同じです。霊の賜物を熱心に求めているのですから、教会を築き上げる賜物に豊かであるよう求めなさい。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="マルコ 11:24; コリント人への第一の手紙 12:30; ヨハネ 14:13–14"> ですから、ほかの言語で語る人は、それを解き明かせるように祈りなさい。</span>
<span className="v" id="v14" data-v="14" data-xref="コリント人への第一の手紙 14:2; コリント人への第一の手紙 14:15–16; コリント人への第一の手紙 14:19"> 私がほかの言語で祈るなら、私の霊は祈っていますが、私の知性は実を結ばないからです。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="コロサイ人への手紙 3:16; ヨハネ 4:23–24; エペソ人への手紙 6:18"> では、どうすればよいでしょう。私は霊によって祈り、知性をもっても祈ります。霊によって歌い、知性をもっても歌います。</span>
<span className="v" id="v16" data-v="16" data-xref="歴代誌上 16:36; 詩篇 106:48; ヨハネの黙示録 5:14"> そうでなければ、あなたが霊によって祝福をささげても、事情を知らない人がそこにいるなら、あなたの感謝にどうして「アーメン」と言えるでしょうか。あなたが何を言っているのか分からないからです。</span>
<span className="v" id="v17" data-v="17" data-xref="コリント人への第一の手紙 14:4; コリント人への第一の手紙 14:6"> あなたが感謝をささげること自体は良くても、ほかの人は築き上げられません。</span>
<span className="v" id="v18" data-v="18" data-xref="コリント人への第一の手紙 1:4–6; コリント人への第一の手紙 4:7"> 私は、あなたがたのだれよりも多く、ほかの言語で語っていることを、私の神に感謝します。</span>
<span className="v" id="v19" data-v="19" data-xref="コリント人への第一の手紙 14:21–22; コリント人への第一の手紙 14:4"> しかし教会では、ほかの言語で一万の言葉を語るよりも、ほかの人々を教えるために、知性をもって五つの言葉を語りたいと思います。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="ペテロの手紙第一 2:2; コリント人への第一の手紙 13:11; ローマ人への手紙 16:19"> 兄弟たち、考え方において子どもとなってはいけません。悪意については幼子となり、考え方においては成熟した者となりなさい。</span>
<span className="v" id="v21" data-v="21" data-xref="イザヤ書 28:11–12; エレミヤ書 5:15; 申命記 28:49"> 律法にこう書かれています。「異なる言語を話す人々と、外国人の唇によって、わたしはこの民に語る。それでも彼らはわたしに聞き従わない、と主は言われる。」</span>
<span className="v" id="v22" data-v="22" data-xref="使徒の働き 2:6–12; マルコ 16:17; コリント人への第一の手紙 14:1"> ですから、ほかの言語は、信じる人々のためではなく、信じていない人々のためのしるしです。しかし預言は、信じていない人々のためではなく、信じる人々のためのしるしです。</span>
<span className="v" id="v23" data-v="23" data-xref="使徒の働き 2:13; 使徒の働き 26:24; コリント人への第一の手紙 11:18"> それで、教会全体が一つの所に集まり、皆がほかの言語で語っている時、事情を知らない人や信じていない人が入って来たら、「あなたがたは気が狂っている」と言わないでしょうか。</span>
<span className="v" id="v24" data-v="24" data-xref="使徒の働き 2:37; コリント人への第一の手紙 2:15; ヘブル人への手紙 4:12–13"> しかし、皆が預言している時、信じていない人や事情を知らない人が入って来れば、その人は皆から罪を示され、皆から吟味されます。</span>
<span className="v" id="v25" data-v="25" data-xref="イザヤ書 45:14; ゼカリヤ書 8:23; 詩篇 72:11"> こうして心の秘密が明らかにされ、その人はひれ伏して神を礼拝し、「本当に、神はあなたがたの間におられる」と告白するでしょう。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="エペソ人への手紙 5:19; ローマ人への手紙 14:19; コリント人への第一の手紙 12:7–10"> それでは兄弟たち、どうすればよいでしょうか。あなたがたが集まる時、それぞれが賛美の歌を持ち、教えを持ち、啓示を持ち、ほかの言語を持ち、その解き明かしを持っています。すべてのことを、互いを築き上げるために行いなさい。</span>
<span className="v" id="v27" data-v="27" data-xref="コリント人への第一の手紙 14:26"> ほかの言語で語る人がいるなら、二人、多くても三人までが、順番に語り、一人が解き明かしなさい。</span>
<span className="v" id="v28" data-v="28"> 解き明かす人がいなければ、教会では黙っていて、自分自身と神に語りなさい。</span>
<span className="v" id="v29" data-v="29" data-xref="コリント人への第一の手紙 12:10; テサロニケ人への手紙第一 5:19–21; ヨハネの手紙第一 4:1–3"> 預言者は二人か三人が語り、ほかの人々はそれを見分けなさい。</span>
<span className="v" id="v30" data-v="30" data-xref="テサロニケ人への手紙第一 5:19–20; ヨブ記 33:31–33; ヨブ記 32:11"> しかし、座っている別の人に啓示が与えられたなら、先に語っていた人は黙りなさい。</span>
<span className="v" id="v31" data-v="31" data-xref="テサロニケ人への手紙第一 5:14; コリント人への第一の手紙 14:3; テサロニケ人への手紙第一 5:11"> 皆が学び、皆が励まされるために、あなたがたは一人ずつ順に預言することができるからです。</span>
<span className="v" id="v32" data-v="32" data-xref="使徒の働き 4:19–20; ヨハネの手紙第一 4:1; サムエル記第一 10:10–13"> 預言者たちの霊は、預言者たちに従います。</span>
<span className="v" id="v33" data-v="33" data-xref="ヤコブの手紙 3:17–18; コリント人への第一の手紙 14:40; テサロニケ人への第二の手紙 3:16"> 神は混乱の神ではなく、平和の神だからです。聖徒たちのすべての教会でも同じです。</span>
<span className="v" id="v34" data-v="34" data-xref="テモテへの手紙第一 2:11–12; 創世記 3:16; 民数記 30:3–13"> 妻たちは教会では静かにしていなさい。彼女たちが話すことは許されていません。律法も言っているように、むしろ従う立場にありなさい。</span>
<span className="v" id="v35" data-v="35" data-xref="エペソ人への手紙 5:12; ペテロの手紙第一 3:7; エペソ人への手紙 5:25–27"> 何かを学びたいなら、家で自分の夫に尋ねなさい。妻が教会で話すことは恥ずべきことだからです。</span>
<span className="v" id="v36" data-v="36" data-xref="使徒の働き 18:1–17; ゼカリヤ書 14:8; 使徒の働き 17:15"> いったい、神の言葉はあなたがたから出たのですか。それとも、あなたがたにだけ届いたのですか。</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="ヨハネの手紙第一 4:6; コリント人への第二の手紙 10:7; ペテロの第二の手紙 3:2"> 自分を預言者、あるいは霊に属する者だと思う人は、私があなたがたに書いていることが主の命令だと認めなさい。</span>
<span className="v" id="v38" data-v="38" data-xref="テモテへの第二の手紙 4:3–4; ホセア書 4:17; ヨハネの黙示録 22:11–12"> しかし、知らない人は、知らないままでいなさい。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="コリント人への第一の手紙 12:31; コリント人への第一の手紙 14:1; テサロニケ人への手紙第一 5:20"> ですから兄弟たち、預言することを熱心に求め、ほかの言語で語ることを禁じてはいけません。</span>
<span className="v" id="v40" data-v="40" data-xref="コロサイ人への手紙 2:5; テトス 1:5; コリント人への第一の手紙 14:26–33"> すべてのことを、ふさわしく、秩序をもって行いなさい。</span>
</div>

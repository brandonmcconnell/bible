<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ローマ人への手紙 1:1; エペソ人への手紙 1:1; コリント人への第二の手紙 1:1"> 神のみこころによってキリスト・イエス<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「キリスト」は「油を注がれた者」という意味である。">a</a></sup>の使徒として召されたパウロと、兄弟ソステネから、</span>
<span className="v" id="v2" data-v="2" data-xref="ローマ人への手紙 1:7; コリント人への第一の手紙 6:9–11; コリント人への第一の手紙 1:30"> コリントにある神の教会、すなわち、キリスト・イエスにあって聖なる者とされ、聖徒として召された人々、また、どこにおいても、彼らの主であり、われわれの主でもあるイエス・キリストの名を呼び求めるすべての人々へ。</span>
<span className="v" id="v3" data-v="3" data-xref="ローマ人への手紙 1:7; コリント人への第二の手紙 1:2; ペテロの手紙第一 1:2"> われわれの父なる神と主イエス・キリストから、恵みと平安があなたがたにあるように。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="ローマ人への手紙 1:8; ヨハネ 14:26; テモテへの手紙第一 1:14"> 私は、キリスト・イエスにあってあなたがたに与えられた神の恵みのゆえに、いつもあなたがたのことを私の神に感謝しています。</span>
<span className="v" id="v5" data-v="5" data-xref="コリント人への第二の手紙 9:11; コリント人への第二の手紙 8:7; コロサイ人への手紙 2:3"> あなたがたはキリストにあって、あらゆる点で、あらゆる言葉と知識において豊かにされたからです。</span>
<span className="v" id="v6" data-v="6" data-xref="ヨハネの黙示録 1:2; テモテへの第二の手紙 1:8; テモテへの手紙第一 2:6"> こうして、キリストについてのあかしは、あなたがたのうちに確かなものとなりました。</span>
<span className="v" id="v7" data-v="7" data-xref="ピリピ人への手紙 3:20; ペテロの第二の手紙 3:12; ヘブル人への手紙 9:28"> そのため、あなたがたはどの賜物にも欠けることなく、われわれの主イエス・キリストが現れるのを待ち望んでいます。</span>
<span className="v" id="v8" data-v="8" data-xref="テサロニケ人への手紙第一 5:23–24; テサロニケ人への手紙第一 3:13; コロサイ人への手紙 1:22"> 主もまた、われわれの主イエス・キリストの日に責められるところのない者となるよう、最後まであなたがたを堅く支えてくださいます。</span>
<span className="v" id="v9" data-v="9" data-xref="テサロニケ人への第二の手紙 3:3; ヘブル人への手紙 10:23; 申命記 7:9"> 神は真実な方です。この神によって、あなたがたは御子、われわれの主イエス・キリストとの交わりに召されたのです。</span>
</div>
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="ピリピ人への手紙 2:1–4; エペソ人への手紙 4:1–7; コリント人への第一の手紙 12:25"> 兄弟たち、<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="ここや、文脈上可能な箇所で「兄弟たち」と訳されている言葉は、「兄弟姉妹」あるいは「きょうだいたち」と訳すこともできる。">b</a></sup>われわれの主イエス・キリストの名によって、あなたがたにお願いします。皆が同じことを語り、あなたがたの間に分裂がなく、同じ思いと同じ判断によって堅く一つに結ばれてください。</span>
<span className="v" id="v11" data-v="11" data-xref="箴言 18:6; テモテへの手紙第一 6:4; テモテへの第二の手紙 2:23–25"> 私の兄弟たち、実は、あなたがたの間に争いがあると、クロエの家の者たちから知らされました。</span>
<span className="v" id="v12" data-v="12" data-xref="コリント人への第一の手紙 3:21–23; ヨハネ 1:42; マタイ 23:9–10"> 私が言っているのは、あなたがたがそれぞれ、「私はパウロにつく」「私はアポロにつく」「私はケファにつく」「私はキリストにつく」と言っていることです。</span>
<span className="v" id="v13" data-v="13" data-xref="エペソ人への手紙 4:5; コリント人への第二の手紙 11:4; 使徒の働き 2:38"> キリストが幾つにも分かれたのですか。パウロがあなたがたのために十字架につけられたのですか。それとも、あなたがたはパウロの名によってバプテスマを受けたのですか。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒の働き 18:8; ローマ人への手紙 16:23; コリント人への第一の手紙 1:4"> 私がバプテスマを授けたのは、クリスポとガイオだけで、あなたがたのほかのだれにも授けなかったことを、神に感謝します。</span>
<span className="v" id="v15" data-v="15" data-xref="コリント人への第二の手紙 11:2; ヨハネ 3:28–29; ヨハネ 7:18"> ですから、だれも、私が自分の名によってあなたがたにバプテスマを授けたとは言えません。</span>
<span className="v" id="v16" data-v="16" data-xref="コリント人への第一の手紙 16:15; コリント人への第一の手紙 16:17; 使徒の働き 16:33"> （もっとも、ステファナの家の者たちにもバプテスマを授けました。それ以外には、だれかに授けたかどうか覚えていません。）</span>
<span className="v" id="v17" data-v="17" data-xref="コリント人への第一の手紙 2:1; コリント人への第一の手紙 2:13; ペテロの第二の手紙 1:16"> キリストが私を遣わされたのは、バプテスマを授けるためではなく、福音を宣べ伝えるためだからです。それも、言葉の巧みな知恵によらず、キリストの十字架が空しくならないようにするためです。</span>
<span className="v" id="v18" data-v="18" data-xref="コリント人への第一の手紙 2:14; ローマ人への手紙 1:16; テサロニケ人への第二の手紙 2:10"> 十字架の言葉は、滅びに向かう人々には愚かですが、救われつつあるわれわれには神の力です。</span>
<span className="v" id="v19" data-v="19" data-xref="イザヤ書 29:14; エレミヤ書 8:9; コリント人への第一の手紙 3:19"> こう書かれています。<br /><span className="pl pl-1">「わたしは知恵ある者の知恵を滅ぼし、</span><br /><span className="pl pl-2">悟りある者の悟りを退ける。」</span></span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="ローマ人への手紙 1:22; ヨブ記 12:17; コリント人への第一の手紙 3:19"> 知恵ある者はどこにいますか。律法学者はどこにいますか。この時代の論客はどこにいますか。神はこの世の知恵を愚かなものにされたのではありませんか。</span>
<span className="v" id="v21" data-v="21" data-xref="ルカ 10:21; ローマ人への手紙 1:20–22; マタイ 11:25"> 神の知恵のうちにあって、この世は自分の知恵によって神を知ることができませんでした。そこで神は、宣教の愚かさを通して、信じる人々を救うことを良しとされたのです。</span>
<span className="v" id="v22" data-v="22" data-xref="マタイ 16:1–4; マタイ 12:38–39; マルコ 8:11"> ユダヤ人はしるしを求め、ギリシャ人は知恵を追い求めます。</span>
<span className="v" id="v23" data-v="23" data-xref="コリント人への第一の手紙 2:14; コリント人への第一の手紙 2:2; ペテロの手紙第一 2:8"> しかし、われわれは十字架につけられたキリストを宣べ伝えます。それはユダヤ人にはつまずき、ギリシャ人には愚かさです。</span>
<span className="v" id="v24" data-v="24" data-xref="コリント人への第一の手紙 1:30; コロサイ人への手紙 2:3; コリント人への第一の手紙 1:18"> しかし、ユダヤ人にもギリシャ人にも、召された人々にとっては、キリストは神の力、神の知恵です。</span>
<span className="v" id="v25" data-v="25" data-xref="ローマ人への手紙 11:33–36; コリント人への第一の手紙 1:18; ゼカリヤ書 4:6–7"> 神の愚かさは人よりも賢く、神の弱さは人よりも強いからです。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="ヤコブの手紙 2:5; コリント人への第一の手紙 3:18–20; ヤコブの手紙 1:9–11"> 兄弟たち、自分たちがどのように召されたかを考えてみなさい。人間的な基準で知恵ある者は多くなく、力ある者も多くなく、身分の高い者も多くありませんでした。</span>
<span className="v" id="v27" data-v="27" data-xref="ヤコブの手紙 2:5; マタイ 11:25; コリント人への第一の手紙 1:20"> しかし神は、知恵ある者を辱めるために、この世の愚かなものを選ばれました。また、強いものを辱めるために、この世の弱いものを選ばれました。</span>
<span className="v" id="v28" data-v="28" data-xref="ヨブ記 34:24; ローマ人への手紙 4:17; イザヤ書 2:11"> 神は、存在するものを無力にするために、この世の卑しいもの、軽蔑されているもの、無に等しいものを選ばれました。</span>
<span className="v" id="v29" data-v="29" data-xref="ローマ人への手紙 3:27; エレミヤ書 9:23; エペソ人への手紙 2:9"> それは、だれも神の前で誇ることがないためです。</span>
<span className="v" id="v30" data-v="30" data-xref="エペソ人への手紙 1:7; ピリピ人への手紙 3:9; ローマ人への手紙 8:1"> 神によって、あなたがたはキリスト・イエスのうちにあります。キリストはわれわれにとって、神からの知恵、義、聖め、そして贖いとなられました。</span>
<span className="v" id="v31" data-v="31" data-xref="エレミヤ書 9:23–24; コリント人への第二の手紙 10:17; ピリピ人への手紙 3:3"> それは、「誇る者は、主を誇れ」と書かれているとおりです。</span>
</div>

<span className="v" id="v1" data-v="1"> 主の言葉が私に臨んだ。</span>
<span className="v" id="v2" data-v="2" data-xref="エゼキエル書 20:46; エゼキエル書 4:7; エゼキエル書 25:2"> 「人の子よ、エルサレムに顔を向け、聖所に向かって語り、イスラエルの地に対して預言せよ。</span>
<span className="v" id="v3" data-v="3" data-xref="ヨブ記 9:22; エレミヤ書 21:13; エゼキエル書 5:8"> イスラエルの地に言え。『主はこう言われる。「見よ、わたしはあなたに立ち向かう。わたしは剣をさやから抜き、あなたの中から義人も悪人も断ち切る。</span>
<span className="v" id="v4" data-v="4" data-xref="エゼキエル書 20:47; エゼキエル書 7:2; エゼキエル書 6:11–14"> わたしがあなたの中から義人も悪人も断ち切るので、わたしの剣はさやから抜かれ、南から北まで、すべての肉なる者に向けられる。</span>
<span className="v" id="v5" data-v="5" data-xref="エゼキエル書 21:30; ナホム書 1:9; サムエル記第一 3:12"> すべての肉なる者は、主であるわたしが剣をさやから抜いたことを知る。それは二度とさやに戻らない。」』</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="イザヤ書 22:4; エゼキエル書 6:11; エレミヤ書 19:10"> それゆえ、人の子よ、嘆息せよ。心を砕かれ、<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="直訳すると、「あなたの両ももが砕けること」。">a</a></sup>苦しみのうちに、彼らの目の前で嘆息せよ。</span>
<span className="v" id="v7" data-v="7" data-xref="エゼキエル書 7:17; エゼキエル書 7:26; イザヤ書 13:7"> 彼らがあなたに、『なぜ嘆息しているのか』と尋ねたなら、こう言え。『知らせのためだ。それが来るからだ。すべての心は溶け、すべての手は力を失い、すべての霊は衰え、すべての膝は水のように弱くなる。見よ、それは来て、必ず実現する』と主なる神は言われる。」</span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8"> 主の言葉が私に臨んだ。</span>
<span className="v" id="v9" data-v="9" data-xref="イザヤ書 34:5–6; エゼキエル書 21:28; エゼキエル書 21:3"> 「人の子よ、預言して言え。『主はこう言われる。<br /><span className="pl pl-1">「剣だ。剣だ。</span><br /><span className="pl pl-2">研がれ、</span><br /><span className="pl pl-2">磨かれた。</span></span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 110:5–6; エゼキエル書 20:47; エゼキエル書 21:25–27"> <span className="pl pl-1">殺戮のために研がれ、</span><br /><span className="pl pl-2">稲妻となるために磨かれた。</span><br /><span className="pl pl-1">それなのに、喜べるのか。</span><br /><span className="pl pl-2">わが子の王笏は、ほかのすべての木を退ける。</span></span>
<span className="v" id="v11" data-v="11" data-xref="エゼキエル書 21:19; エレミヤ書 25:33; エレミヤ書 51:20–23"> <span className="pl pl-1">剣は磨くために渡された。</span><br /><span className="pl pl-2">人の手に握られるため。</span><br /><span className="pl pl-1">剣は研がれた。</span><br /><span className="pl pl-2">そうだ、それは磨かれ、</span><br /><span className="pl pl-2">殺す者の手に渡される。」』</span></span>
<span className="v" id="v12" data-v="12" data-xref="エゼキエル書 21:6; ヨエル書 1:13; エゼキエル書 21:14"> <span className="pl pl-1">人の子よ、叫び、泣きわめけ。</span><br /><span className="pl pl-2">剣はわたしの民に臨み、</span><br /><span className="pl pl-2">イスラエルのすべての君主に臨む。</span><br /><span className="pl pl-1">彼らはわたしの民と共に剣に渡される。</span><br /><span className="pl pl-2">それゆえ、自分のももを打て。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v13" data-v="13" data-xref="エゼキエル書 21:10; コリント人への第二の手紙 8:2; エゼキエル書 21:25"> 試しの時だ。すべてを退ける王笏さえ消え去るなら、どうなるのか」と主なる神は言われる。</span>
<span className="v" id="v14" data-v="14" data-xref="列王記第二 24:1; 民数記 24:10; レビ記 26:24"> <span className="pl pl-1">「それゆえ、人の子よ、預言し、</span><br /><span className="pl pl-2">両手を打ち合わせよ。</span><br /><span className="pl pl-1">剣を二度、いや三度と打ち重ねよ。</span><br /><span className="pl pl-2">それは致命の剣、</span><br /><span className="pl pl-1">大いなる者を刺し貫く剣、</span><br /><span className="pl pl-2">彼らの部屋にまで入り込む。</span></span>
<span className="v" id="v15" data-v="15" data-xref="エゼキエル書 21:10; エレミヤ書 17:27; エゼキエル書 21:22"> <span className="pl pl-1">わたしはすべての門に脅威となる剣を置いた。</span><br /><span className="pl pl-2">彼らの心が溶け、</span><br /><span className="pl pl-2">つまずく者は増える。</span><br /><span className="pl pl-1">ああ、剣は稲妻とされ、</span><br /><span className="pl pl-2">殺戮へ切っ先を向ける。</span></span>
<span className="v" id="v16" data-v="16" data-xref="エゼキエル書 21:20; エゼキエル書 21:4; エゼキエル書 14:17"> <span className="pl pl-1">集まれ。</span><br /><span className="pl pl-2">右へ向かえ。</span><br /><span className="pl pl-1">整列せよ。</span><br /><span className="pl pl-2">左へ向かえ。</span><br /><span className="pl pl-2">顔の向く所へ進め。</span></span>
<span className="v" id="v17" data-v="17" data-xref="エゼキエル書 5:13; エゼキエル書 21:14; ゼカリヤ書 6:8"> <span className="pl pl-1">わたしも両手を打ち合わせ、</span><br /><span className="pl pl-2">わたしの憤りを静める。</span><br /><span className="pl pl-2">主であるわたしが語った。」</span></span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18"> 再び、主の言葉が私に臨んだ。</span>
<span className="v" id="v19" data-v="19" data-xref="エゼキエル書 4:1–3; エレミヤ書 1:10; エゼキエル書 5:1–17"> 「人の子よ、バビロンの王の剣が来るために、二つの道を定めよ。どちらも一つの国から出るようにし、道しるべを設けよ。町へ向かう道の分岐点に設けよ。</span>
<span className="v" id="v20" data-v="20" data-xref="アモス書 1:14; エレミヤ書 49:2; エゼキエル書 25:5"> 剣がアンモンの子らのラバへ行く道と、城壁に囲まれたエルサレムのユダへ行く道を定めよ。</span>
<span className="v" id="v21" data-v="21" data-xref="士師記 18:20; 箴言 16:33; 士師記 17:5"> バビロンの王は道の分かれ目、二つの道の起点に立ち、占いを行った。彼は矢を振り、テラフィム<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="テラフィムは家の偶像であり、家の財産の相続権と関係していた可能性がある。">b</a></sup>に尋ね、肝臓を調べた。</span>
<span className="v" id="v22" data-v="22" data-xref="エゼキエル書 4:2; エゼキエル書 26:9; エレミヤ書 51:14"> 彼の右手にはエルサレムを示す占いの結果が出た。破城槌を据え、殺戮のために口を開き、叫び声を上げ、門に破城槌を据え、土塁を築き、砦を建てるためである。</span>
<span className="v" id="v23" data-v="23" data-xref="民数記 5:15; エゼキエル書 21:24; エゼキエル書 29:16"> 彼らに誓いを立てた者たちの目には、それは偽りの占いのように見える。しかし、彼は彼らの不義を思い起こさせ、彼らを捕らえる。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="ホセア書 4:2; ミカ書 3:10–12; エレミヤ書 3:2"> それゆえ、主なる神はこう言われる。『あなたがたは自分たちの不義を思い起こさせた。あなたがたの背きがあらわにされ、すべての行いの中に罪が現れたからである。あなたがたが思い起こされたので、手で捕らえられる。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="エゼキエル書 35:5; エゼキエル書 21:29; エゼキエル書 17:19"> 致命傷を負った悪しき者、イスラエルの君主よ。あなたの日が来た。終わりの不義の時が来た。</span>
<span className="v" id="v26" data-v="26" data-xref="エゼキエル書 17:24; 詩篇 75:7; エレミヤ書 13:18"> 主なる神はこう言われる。「ターバンを取り去り、冠を脱がせよ。これは今までのようではない。低い者を高くし、高い者を低くせよ。</span>
<span className="v" id="v27" data-v="27" data-xref="ミカ書 5:2; エレミヤ書 23:5–6; ゼカリヤ書 9:9"> わたしはそれを覆し、覆し、覆す。それは、権利を持つ者が来るまで、もはや存在しない。わたしはその者にそれを与える。」』</span>
</div>
<div className="bp poetry">
<span className="v" id="v28" data-v="28" data-xref="エゼキエル書 21:20; エゼキエル書 21:9–10; ゼパニヤ書 2:8–10"> 人の子よ、預言して言え。『主なる神はアンモンの子らと、彼らの受けたそしりについてこう言われる。<br /><span className="pl pl-1">「剣だ。剣が抜かれた。</span><br /><span className="pl pl-2">それは殺戮のために磨かれ、</span><br /><span className="pl pl-1">食い尽くすため、</span><br /><span className="pl pl-2">稲妻のようになるために磨かれた。</span></span>
<span className="v" id="v29" data-v="29" data-xref="エゼキエル書 21:25; エゼキエル書 22:28; 詩篇 37:13"> <span className="pl pl-1">人々はあなたのために偽りの幻を見、</span><br /><span className="pl pl-2">あなたのために偽りを占う。</span><br /><span className="pl pl-1">それは、致命傷を負った悪人たち、</span><br /><span className="pl pl-2">終わりの不義の時にその日が来た者たちの首の上に、あなたを置くためである。</span></span>
<span className="v" id="v30" data-v="30" data-xref="エゼキエル書 16:38; 創世記 15:14; エレミヤ書 47:6–7"> <span className="pl pl-1">剣をさやに戻せ。</span><br /><span className="pl pl-2">あなたが造られた場所、</span><br /><span className="pl pl-2">あなたの生まれた国で、わたしはあなたを裁く。</span></span>
<span className="v" id="v31" data-v="31" data-xref="ナホム書 1:6; エレミヤ書 6:22–23; エゼキエル書 14:19"> <span className="pl pl-1">わたしはあなたの上に憤りを注ぎ、</span><br /><span className="pl pl-2">怒りの火をあなたに吹きつける。</span><br /><span className="pl pl-1">わたしはあなたを残忍な者たち、</span><br /><span className="pl pl-2">滅ぼすことに熟練した者たちの手に渡す。</span></span>
<span className="v" id="v32" data-v="32" data-xref="エゼキエル書 25:10; マラキ書 4:1; エゼキエル書 20:47–48"> <span className="pl pl-1">あなたは火の燃料となり、</span><br /><span className="pl pl-2">あなたの血は国のただ中に流される。</span><br /><span className="pl pl-1">あなたは二度と思い起こされない。</span><br /><span className="pl pl-2">主であるわたしが語った。」』」</span></span>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="エゼキエル書 40:2–3; エゼキエル書 40:17; エゼキエル書 41:23"> 彼は私を本堂へ連れて行き、脇柱を測った。こちら側の幅は六キュビト、あちら側の幅も六キュビトで、それが幕屋の幅であった。</span>
<span className="v" id="v2" data-v="2" data-xref="列王記第一 6:17; 歴代誌 第二 3:3; 列王記第一 6:2"> 入口の幅は十キュビト、<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一キュビトは、人の腕の中指の先からひじまでの長さで、約18インチ、または46センチメートルである。">a</a></sup>入口の両側の壁は、それぞれ五キュビトであった。彼が本堂を測ると、長さは四十キュビト、幅は二十キュビトであった。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="エゼキエル書 40:16"> それから彼は内側へ入り、入口の脇柱を測ると、それぞれ二キュビトであった。入口部分の長さは六キュビト、その幅は七キュビトであった。</span>
<span className="v" id="v4" data-v="4" data-xref="列王記第一 6:20; ヘブル人への手紙 9:3–8; 出エジプト記 26:33–34"> 彼が本堂の奥にある部屋を測ると、長さは二十キュビト、幅も二十キュビトであった。彼は私に、「ここが至聖所である」と言った。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="列王記第一 6:5–6; エゼキエル書 42:3–14; エゼキエル書 41:6–9"> それから彼は宮の壁を測ると六キュビト、宮を四方から囲む各脇部屋の幅は四キュビトであった。</span>
<span className="v" id="v6" data-v="6" data-xref="列王記第一 6:10; 列王記第一 6:5–6; エゼキエル書 40:17"> 脇部屋は三階建てで、各階に三十室あり、上へ上へと重なっていた。宮の壁の周囲には脇部屋を支える段が設けられていたので、部屋の梁を宮の壁に差し込む必要はなかった。</span>
<span className="v" id="v7" data-v="7" data-xref="列王記第一 6:8; ヘブル人への手紙 6:1; マタイ 13:32"> 脇部屋は上の階ほど広くなっていた。宮を囲む壁が上の階ほど狭くなっていたからである。そのため、宮は上に行くほど幅が広くなり、下の階から中の階を通って上の階へ上るようになっていた。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="エゼキエル書 40:5; ヨハネの黙示録 21:16"> また、宮の周囲には高くなった基壇があるのが見えた。脇部屋の基礎は、長キュビト六キュビト、すなわち一竿分であった。</span>
<span className="v" id="v9" data-v="9" data-xref="エゼキエル書 41:11; エゼキエル書 42:4; エゼキエル書 42:1"> 脇部屋の外壁の厚さは五キュビトであった。宮に属する脇部屋の外側には空き地が残されていた。</span>
<span className="v" id="v10" data-v="10" data-xref="エゼキエル書 40:17"> 部屋と部屋との間には、宮を四方から囲む幅二十キュビトの空間があった。</span>
<span className="v" id="v11" data-v="11" data-xref="エゼキエル書 41:9; エゼキエル書 42:4"> 脇部屋の戸口は残された空き地に面しており、一つは北向き、もう一つは南向きであった。周囲の空き地の幅は五キュビトであった。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="エゼキエル書 42:1; エゼキエル書 42:13; エゼキエル書 41:13–15"> 西側の別区画に面する建物は、幅七十キュビトであった。その建物を囲む壁の厚さは五キュビト、建物の長さは九十キュビトであった。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="エゼキエル書 40:47"> 彼が宮を測ると、長さは百キュビトであった。別区画と、その建物と壁を合わせた長さも百キュビトであった。</span>
<span className="v" id="v14" data-v="14"> 宮の東側の正面と別区画を合わせた幅も百キュビトであった。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="エゼキエル書 42:3; エゼキエル書 42:1; エゼキエル書 41:12"> 彼が宮の背後にある別区画に面した建物と、その両側の回廊の長さを測ると、百キュビトであった。内側の宮と庭の前廊、</span>
<span className="v" id="v16" data-v="16" data-xref="列王記第一 6:4; エゼキエル書 40:25; エゼキエル書 40:16"> 敷居、格子窓、三階にわたって周囲にある回廊は、敷居に面する所も含め、周囲を木で覆われていた。木の覆いは地面から窓まで達し、窓にも覆いがあった。</span>
<span className="v" id="v17" data-v="17" data-xref="エゼキエル書 42:15"> 戸口の上から内側の宮まで、また外側も、内外の壁の周囲全体が、定められた寸法に従って造られていた。</span>
<span className="v" id="v18" data-v="18" data-xref="列王記第一 7:36; エゼキエル書 40:16; エゼキエル書 40:22"> そこにはケルビムとなつめやしの木が彫られていた。ケルブとケルブの間には、なつめやしの木が一本ずつあり、各ケルブには二つの顔があった。</span>
<span className="v" id="v19" data-v="19" data-xref="エゼキエル書 10:14; エゼキエル書 1:10"> 一方には、なつめやしの木に向いた人の顔があり、もう一方には、なつめやしの木に向いた若い獅子の顔があった。宮の周囲全体がこのように造られていた。</span>
<span className="v" id="v20" data-v="20" data-xref="エゼキエル書 41:18"> 地面から戸口の上まで、ケルビムとなつめやしの木が彫られていた。宮の壁はこのようになっていた。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="エゼキエル書 41:1; 列王記第一 6:33; エゼキエル書 40:14"> 本堂の脇柱は四角形であった。本堂の正面は、宮の正面と同じ外観であった。</span>
<span className="v" id="v22" data-v="22" data-xref="マラキ書 1:12; エゼキエル書 23:41; マラキ書 1:7"> 祭壇は木で造られ、高さ三キュビト、長さ二キュビトであった。その四隅、土台、側面も木で造られていた。彼は私に、「これは主の前にある食卓である」と言った。</span>
<span className="v" id="v23" data-v="23" data-xref="列王記第一 6:31–35; 歴代誌 第二 4:22; エゼキエル書 41:1"> 本堂と至聖所には、それぞれ二枚戸があった。</span>
<span className="v" id="v24" data-v="24" data-xref="列王記第一 6:34; エゼキエル書 40:48"> それぞれの戸には、回転する戸板が二枚ずつあった。一方の戸に二枚、もう一方の戸にも二枚であった。</span>
<span className="v" id="v25" data-v="25" data-xref="エゼキエル書 41:18"> 本堂の戸には、壁に彫られたものと同じケルビムとなつめやしの木が彫られていた。外側の前廊の正面には木の敷居があった。</span>
<span className="v" id="v26" data-v="26" data-xref="エゼキエル書 41:16; エゼキエル書 40:16; エゼキエル書 41:5"> 前廊の両側には格子窓となつめやしの木があった。宮の脇部屋と敷居も、このように造られていた。</span>
</div>

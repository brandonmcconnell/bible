<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="エゼキエル書 3:14; エゼキエル書 11:24; エゼキエル書 11:13"> さらに、霊は私を持ち上げ、東向きの主の宮の東門へ連れて行った。見よ、門の入口に二十五人の男がいた。その中に、アズルの子ヤアザヌヤとベナヤの子ペラテヤがいるのを見た。彼らは民の首長たちであった。</span>
<span className="v" id="v2" data-v="2" data-xref="イザヤ書 30:1; エレミヤ書 5:5; 詩篇 2:1–2"> その方は私に言われた。「人の子よ、この者たちは、この町で不義を企み、邪悪な助言を与えている者たちである。</span>
<span className="v" id="v3" data-v="3" data-xref="エゼキエル書 12:27; エゼキエル書 12:22; エゼキエル書 11:7–11"> 彼らは言っている。『家を建てる時はまだ近くない。この町は大釜で、われわれはその肉だ。』</span>
<span className="v" id="v4" data-v="4" data-xref="エゼキエル書 20:46–47; エゼキエル書 21:2; エゼキエル書 3:2–15"> それゆえ、彼らに向かって預言せよ。人の子よ、預言せよ。」</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="エレミヤ書 17:10; エレミヤ書 16:17; ヨハネの黙示録 2:23"> そのとき、主の霊が私の上に降り、私に言った。「語れ。『主はこう言われる。「イスラエルの家よ、あなたがたはそのように言った。わたしはあなたがたの心に浮かぶことを知っている。</span>
<span className="v" id="v6" data-v="6" data-xref="エゼキエル書 7:23; エゼキエル書 22:27; エゼキエル書 22:12"> あなたがたはこの町で殺された者を増やし、その通りを死体で満たした。」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="エゼキエル書 24:3–13; ミカ書 3:2–3; 列王記第二 25:18–22"> それゆえ、主なる神はこう言われる。「あなたがたが町の中に横たえた死者こそ肉であり、この町は大釜である。しかし、あなたがたはその中から連れ出される。</span>
<span className="v" id="v8" data-v="8" data-xref="箴言 10:24; イザヤ書 24:17–18; ヨブ記 3:25"> あなたがたは剣を恐れた。わたしはあなたがたの上に剣をもたらす」と主なる神は言われる。</span>
<span className="v" id="v9" data-v="9" data-xref="エゼキエル書 5:8; 詩篇 106:41; 申命記 28:36"> 「わたしはあなたがたを町の中から連れ出し、異国人の手に渡し、あなたがたの間で裁きを執行する。</span>
<span className="v" id="v10" data-v="10" data-xref="列王記第二 14:25; エレミヤ書 52:9–10; 列王記第二 25:19–21"> あなたがたは剣に倒れる。わたしはイスラエルの国境であなたがたを裁く。そのとき、あなたがたは、わたしが主であることを知る。</span>
<span className="v" id="v11" data-v="11" data-xref="エゼキエル書 11:3; エゼキエル書 11:7–10"> この町はあなたがたの大釜とはならず、あなたがたもその中の肉とはならない。わたしはイスラエルの国境であなたがたを裁く。</span>
<span className="v" id="v12" data-v="12" data-xref="エゼキエル書 8:10; エゼキエル書 8:16; エゼキエル書 8:14"> そのとき、あなたがたは、わたしが主であることを知る。あなたがたはわたしの掟に従って歩まず、わたしの定めを行わず、周囲の諸国の定めに従って行ったからである。」』」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="エゼキエル書 11:1; エゼキエル書 9:8; 使徒の働き 5:5"> 私が預言していると、ベナヤの子ペラテヤが死んだ。そこで私はひれ伏し、大声で叫んだ。「ああ、主なる神よ。イスラエルの残りの者を完全に滅ぼされるのですか。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14"> 主の言葉が私に臨んだ。</span>
<span className="v" id="v15" data-v="15" data-xref="エゼキエル書 33:24; イザヤ書 65:5; ヨハネ 16:2"> 「人の子よ、あなたの兄弟たち、まさにあなたの親族である兄弟たちと、イスラエルの全家は、エルサレムの住民から、『主から遠く離れていろ。この地はわれわれの所有として与えられた』と言われた者たちである。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="イザヤ書 8:14; 申命記 30:3–4; 詩篇 90:1"> それゆえ、こう言え。『主なる神はこう言われる。「わたしは彼らを諸国の間に遠く移し、国々の中に散らしたが、彼らが移された国々で、しばらくの間、彼らの聖所となる。」』</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="エゼキエル書 28:25; エレミヤ書 3:18; エゼキエル書 34:13"> それゆえ、こう言え。『主なる神はこう言われる。「わたしはあなたがたを諸民族の中から集め、散らされた国々から呼び集め、イスラエルの地をあなたがたに与える。」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="エゼキエル書 37:23; エゼキエル書 5:11; エゼキエル書 42:7–8"> 「彼らはそこへ行き、その地からすべての忌まわしいものと、すべての忌むべきものを取り除く。</span>
<span className="v" id="v19" data-v="19" data-xref="エゼキエル書 36:26–27; エレミヤ書 31:33; 詩篇 51:10"> わたしは彼らに一つの心を与え、彼らのうちに新しい霊を置く。彼らの肉体から石の心を取り除き、肉の心を与える。</span>
<span className="v" id="v20" data-v="20" data-xref="エゼキエル書 14:11; 詩篇 105:45; エレミヤ書 30:22"> こうして彼らはわたしの掟に従って歩み、わたしの定めを守り、それを行う。彼らはわたしの民となり、わたしは彼らの神となる。</span>
<span className="v" id="v21" data-v="21" data-xref="エゼキエル書 9:10; 伝道者の書 11:9; エレミヤ書 1:16"> しかし、忌まわしいものと忌むべきものを心から慕って歩む者たちには、その行いを彼ら自身の頭に報いる」と主なる神は言われる。』」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="エゼキエル書 10:19; エゼキエル書 1:19–20"> そのとき、ケルビムは翼を上げ、輪もそのそばにあった。イスラエルの神の栄光は、彼らの上にあった。</span>
<span className="v" id="v23" data-v="23" data-xref="ゼカリヤ書 14:4; エゼキエル書 8:4; エゼキエル書 10:4"> 主の栄光は町の中から上って行き、町の東側にある山の上に立った。</span>
<span className="v" id="v24" data-v="24" data-xref="エゼキエル書 3:12; エゼキエル書 8:3; エゼキエル書 11:1"> 霊は私を持ち上げ、神の霊による幻のうちに、カルデアへ、捕囚の民のもとへ連れて行った。<br />こうして、私が見た幻は私から上って行った。</span>
<span className="v" id="v25" data-v="25" data-xref="エゼキエル書 3:4; エゼキエル書 3:27; エゼキエル書 3:17"> そこで私は、主が私に示されたすべてのことを捕囚の民に語った。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="イザヤ書 66:23; エゼキエル書 44:1–2; 出エジプト記 20:9"> 主なる神はこう言われる。「東を向く内庭の門は、六日の労働日には閉じておかなければならない。しかし、安息日には開き、新月の日にも開かなければならない。</span>
<span className="v" id="v2" data-v="2" data-xref="エゼキエル書 44:3; エゼキエル書 46:8; 歴代誌上 29:10–12"> 君主は外から門の前廊を通って入り、門の柱のそばに立つ。祭司たちは彼の焼き尽くすささげ物と平和のささげ物を用意し、彼は門の敷居の所で礼拝する。それから外へ出るが、門は夕方まで閉じてはならない。</span>
<span className="v" id="v3" data-v="3" data-xref="ルカ 1:10; ヨハネ 10:9; ヘブル人への手紙 10:19–22"> この地の民も、安息日と新月の日に、その門の入口で主の前に礼拝しなければならない。</span>
<span className="v" id="v4" data-v="4" data-xref="エゼキエル書 45:17; 民数記 28:9–10"> 君主が安息日に主にささげる焼き尽くすささげ物は、傷のない子羊六頭と、傷のない雄羊一頭である。</span>
<span className="v" id="v5" data-v="5" data-xref="エゼキエル書 45:24; エゼキエル書 46:7; 申命記 16:17"> 穀物のささげ物は、雄羊一頭につき一エパ、子羊については彼がささげることのできる量とし、一エパにつき一ヒン<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一ヒンは約6.5リットル、または1.7ガロンである。">a</a></sup>の油を添える。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="一エパは約22リットル、または約3分の2ブッシェルである。">b</a></sup></span>
<span className="v" id="v6" data-v="6" data-xref="エゼキエル書 46:1"> 新月の日には、傷のない若い雄牛一頭、子羊六頭、雄羊一頭をささげる。それらは傷のないものでなければならない。</span>
<span className="v" id="v7" data-v="7" data-xref="エゼキエル書 46:5"> 彼は穀物のささげ物として、雄牛一頭につき一エパ、雄羊一頭につき一エパ、子羊については彼がささげることのできる量を用意し、一エパにつき一ヒンの油を添えなければならない。</span>
<span className="v" id="v8" data-v="8" data-xref="エゼキエル書 46:2; エゼキエル書 44:1–3; コロサイ人への手紙 1:18"> 君主が入るときは、門の前廊を通って入り、同じ道を通って出なければならない。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="申命記 16:16; 出エジプト記 23:14–17; ペテロの第二の手紙 2:20–21"> しかし、この地の民が定められた祭りに主の前へ来るとき、礼拝するために北の門から入る者は南の門から出なければならず、南の門から入る者は北の門から出なければならない。入って来た門から引き返してはならず、まっすぐ向かい側の門から出なければならない。</span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 42:4; 歴代誌上 29:20; 歴代誌上 29:22"> 君主は、民が入るときに彼らと共に入り、彼らが出るときに共に出なければならない。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="エゼキエル書 46:5; エゼキエル書 46:7; 民数記 15:1–41"> 祭りと定められた祝日には、穀物のささげ物は雄牛一頭につき一エパ<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="一エパは約22リットル、または約3分の2ブッシェルである。">c</a></sup>、雄羊一頭につき一エパ、子羊については彼がささげることのできる量とし、一エパにつき一ヒンの油を添える。</span>
<span className="v" id="v12" data-v="12" data-xref="エゼキエル書 46:1–2; エゼキエル書 45:17; エゼキエル書 44:3"> 君主が主への自発のささげ物として、焼き尽くすささげ物または平和のささげ物を用意するときには、東を向く門を彼のために開かなければならない。彼は安息日に行うのと同じように、焼き尽くすささげ物と平和のささげ物を用意する。それから彼が出た後、門を閉じなければならない。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="イザヤ書 50:4; ヨハネ 1:29; 出エジプト記 12:5"> あなたは毎日、傷のない一歳の子羊一頭を、主への焼き尽くすささげ物として用意しなければならない。朝ごとにこれを用意せよ。</span>
<span className="v" id="v14" data-v="14" data-xref="民数記 28:5"> また、朝ごとに、それと共に穀物のささげ物として一エパの六分の一<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="一エパは約22リットル、または約3分の2ブッシェルである。">d</a></sup>と、上質の小麦粉を湿らせるための油一ヒンの三分の一を用意せよ。これは永遠の定めにより、絶えず主にささげる穀物のささげ物である。</span>
<span className="v" id="v15" data-v="15" data-xref="ヘブル人への手紙 10:1–10; 民数記 28:6; 出エジプト記 29:42"> このようにして、朝ごとに子羊と穀物のささげ物と油を、絶えずささげる焼き尽くすささげ物として用意しなければならない。」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="歴代誌 第二 21:3; ガラテヤ人への手紙 4:7; 創世記 25:5–6"> 主なる神はこう言われる。「君主が自分の息子の一人に贈り物を与えるなら、それはその息子の相続地となる。それは世襲の所有地として息子たちのものとなる。</span>
<span className="v" id="v17" data-v="17" data-xref="レビ記 25:10; ルカ 19:25–26; ガラテヤ人への手紙 4:30–31"> しかし、自分の相続地から、しもべの一人に贈り物を与えるなら、それは解放の年までそのしもべのものとなり、その後は君主に戻る。君主の相続地は、ただその息子たちのものとなる。</span>
<span className="v" id="v18" data-v="18" data-xref="エゼキエル書 45:8; 列王記第一 21:19; エゼキエル書 22:27"> 君主は、民をその所有地から追い出すために、民の相続地を取り上げてはならない。自分の所有地から息子たちに相続地を与えなければならない。わたしの民が、それぞれ自分の所有地から散らされないためである。」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="エゼキエル書 42:9; エゼキエル書 44:4–5; エゼキエル書 40:44–46"> それから彼は、門の脇にある入口を通って、北を向く祭司たちのための聖なる部屋へ私を連れて行った。見よ、その奥の西側に一つの場所があった。</span>
<span className="v" id="v20" data-v="20" data-xref="歴代誌 第二 35:13; エゼキエル書 44:29; エゼキエル書 44:19"> 彼は私に言った。「ここは、祭司たちが罪過のささげ物と罪のきよめのささげ物を煮、穀物のささげ物を焼く場所である。それらを外庭へ持ち出して、民を聖別してしまうことがないようにするためである。」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21"> それから彼は私を外庭へ連れ出し、庭の四隅を通らせた。見よ、庭の各隅に小庭があった。</span>
<span className="v" id="v22" data-v="22"> 庭の四隅には囲まれた小庭があり、それぞれ長さ四十キュビト、<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="一キュビトは、人の腕の中指の先からひじまでの長さで、約18インチ、または46センチメートルである。">e</a></sup>幅三十キュビトであった。四隅にあるこの四つは、すべて同じ寸法であった。</span>
<span className="v" id="v23" data-v="23"> 四つの小庭には、それぞれ周囲に壁があり、その壁の下には周囲を巡る煮炊き場が設けられていた。</span>
<span className="v" id="v24" data-v="24" data-xref="エゼキエル書 46:20; ヨハネ 21:15–17; ペテロの手紙第一 5:2"> 彼は私に言った。「これらは、宮に仕える者たちが民のいけにえを煮る場所である。」</span>
</div>

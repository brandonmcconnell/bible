<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="エゼキエル書 40:20; エゼキエル書 40:17; エゼキエル書 42:13"> それから彼は私を北の方へ、外庭に連れ出した。そして、別区画に面し、北側の建物にも面している部屋へ連れて行った。</span>
<span className="v" id="v2" data-v="2" data-xref="エゼキエル書 41:13"> 北側の入口に面した部分は長さ百キュビト、<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一キュビトは、人の腕の中指の先からひじまでの長さで、約18インチ、または46センチメートルである。">a</a></sup>幅五十キュビトであった。</span>
<span className="v" id="v3" data-v="3" data-xref="エゼキエル書 41:15–16; エゼキエル書 41:10; 雅歌 7:5"> 内庭に属する二十キュビトの空間と、外庭に属する石畳に面して、三階には回廊と回廊が向かい合っていた。</span>
<span className="v" id="v4" data-v="4" data-xref="エゼキエル書 46:19; ルカ 13:24; マタイ 7:14"> 部屋の前には、内側に向かって幅十キュビトの通路があり、そこへ通じる道は幅一キュビトであった。部屋の戸口は北を向いていた。</span>
<span className="v" id="v5" data-v="5" data-xref="エゼキエル書 41:7"> 上の部屋は狭かった。建物の回廊が、下の階や中の階よりも上の階の場所を多く占めていたからである。</span>
<span className="v" id="v6" data-v="6" data-xref="エゼキエル書 41:6; 列王記第一 6:8"> 部屋は三階建てであったが、庭の柱のような柱がなかった。そのため、上の階は地面から見て、下の階や中の階よりも奥に引っ込んでいた。</span>
<span className="v" id="v7" data-v="7" data-xref="エゼキエル書 42:12; エゼキエル書 42:10"> 部屋の外側、外庭に面して部屋の前にある壁は、長さ五十キュビトであった。</span>
<span className="v" id="v8" data-v="8" data-xref="エゼキエル書 41:13–14"> 外庭にある部屋の長さは五十キュビトであった。見よ、宮に面する部屋の長さは百キュビトであった。</span>
<span className="v" id="v9" data-v="9" data-xref="エゼキエル書 46:19; エゼキエル書 44:5"> これらの部屋の下には、外庭から部屋に入るための東側の入口があった。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="エゼキエル書 42:1; エゼキエル書 42:13; エゼキエル書 41:12–15"> 庭の壁の厚みの中、東側の別区画と建物に面する所にも部屋があった。</span>
<span className="v" id="v11" data-v="11" data-xref="エゼキエル書 42:4"> その前の通路は、北側の部屋の通路と同じ外観であった。部屋の長さと幅は同じで、すべての出口、造り、戸口も同じであった。</span>
<span className="v" id="v12" data-v="12"> 南側の部屋の戸口と同じように、通路の先にも戸口があった。その通路は東側の壁の正面にあり、そこから部屋に入るようになっていた。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="レビ記 10:17; レビ記 7:6; エゼキエル書 40:46"> 彼は私に言った。「別区画に面する北側の部屋と南側の部屋は聖なる部屋である。主に近づく祭司たちは、そこで最も聖なるものを食べる。そこに、最も聖なるもの、すなわち穀物のささげ物、罪のきよめのささげ物、罪過のささげ物を置く。この場所は聖なるものだからである。</span>
<span className="v" id="v14" data-v="14" data-xref="エゼキエル書 44:19; レビ記 8:7; 出エジプト記 29:4–9"> 祭司たちは聖所に入った後、務めのために着た衣服をそこで脱いで置くまでは、聖所から外庭へ出てはならない。それらの衣服は聖なるものだからである。それから別の衣服を着て、民のための場所に近づかなければならない。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="エゼキエル書 43:1; エゼキエル書 41:15; エゼキエル書 40:6–16"> 彼は内側の宮を測り終えると、東を向く門から私を連れ出し、その周囲全体を測った。</span>
<span className="v" id="v16" data-v="16" data-xref="エゼキエル書 40:3; ヨハネの黙示録 11:1–2; ゼカリヤ書 2:1"> 測り竿で東側を測ると、五百竿であった。</span>
<span className="v" id="v17" data-v="17"> 測り竿で北側を測ると、五百竿であった。</span>
<span className="v" id="v18" data-v="18"> 測り竿で南側を測ると、五百竿であった。</span>
<span className="v" id="v19" data-v="19"> 彼は西側に回り、測り竿で五百竿を測った。</span>
<span className="v" id="v20" data-v="20" data-xref="エゼキエル書 45:2; エゼキエル書 22:26; エゼキエル書 40:5"> 彼は四方を測った。その周囲には壁があり、長さ五百キュビト、幅五百キュビトで、聖なるものと俗なるものとを分けていた。</span>
</div>

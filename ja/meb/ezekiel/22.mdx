<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> さらに、主の言葉が私に臨んだ。</span>
<span className="v" id="v2" data-v="2" data-xref="イザヤ書 58:1; エゼキエル書 24:6; エゼキエル書 24:9"> 「人の子よ、あなたは裁くのか、流血の町を裁くのか。それなら、その町にすべての忌むべき行いを知らせよ。</span>
<span className="v" id="v3" data-v="3" data-xref="エゼキエル書 22:27; ローマ人への手紙 2:5; ペテロの第二の手紙 2:3"> あなたはこう言え。『主なる神はこう言われる。「自らの時を招くために、その中で血を流し、自らを汚すために偶像を造る町よ。</span>
<span className="v" id="v4" data-v="4" data-xref="列王記第二 21:16; 詩篇 44:13–14; エゼキエル書 22:2"> あなたは自分が流した血によって罪ある者となり、自分が造った偶像によって汚れた。あなたは自分の日々を近づけ、自分の年月の終わりに達した。それゆえ、わたしはあなたを諸国のそしりとし、すべての国々のあざけりとした。</span>
<span className="v" id="v5" data-v="5" data-xref="イザヤ書 22:2; エレミヤ書 15:2–3"> 近くにいる者も、あなたから遠く離れている者も、悪名高く、騒乱に満ちたあなたをあざける。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="エゼキエル書 22:27; イザヤ書 1:23; ゼカリヤ書 3:3"> 見よ、イスラエルの君主たちは、それぞれ自分の力に任せて、あなたの中で血を流した。</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 27:16; 出エジプト記 22:21–22; レビ記 20:9"> あなたの中で、人々は父と母を軽蔑した。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="直訳すると、父と母を軽く扱った。">a</a></sup>あなたの中で寄留者を虐げ、あなたの中で父のない子とやもめを苦しめた。</span>
<span className="v" id="v8" data-v="8" data-xref="エゼキエル書 23:38–39; エゼキエル書 22:26; エゼキエル書 20:13"> あなたはわたしの聖なるものを軽蔑し、わたしの安息日を汚した。</span>
<span className="v" id="v9" data-v="9" data-xref="ホセア書 4:14; レビ記 19:16; ホセア書 4:10"> あなたの中には、人を中傷し、血を流す者たちがいた。あなたの中で、人々は山の聖所で食べ、淫らな行いをした。</span>
<span className="v" id="v10" data-v="10" data-xref="レビ記 18:19; レビ記 18:7–8; エゼキエル書 18:6"> あなたの中で、人々は父の裸をあらわにし、月のものによって汚れている女を辱めた。</span>
<span className="v" id="v11" data-v="11" data-xref="レビ記 18:15; サムエル記第二 13:14; レビ記 20:17"> ある者は隣人の妻と忌むべきことを行い、ある者は嫁を淫らに汚し、またある者は父の娘である自分の姉妹を辱めた。</span>
<span className="v" id="v12" data-v="12" data-xref="申命記 27:25; エゼキエル書 23:35; 詩篇 106:21"> あなたの中で、人々は血を流すために賄賂を受け取った。あなたは利息と高利を取り、虐げによって隣人から不当な利益をむさぼり、わたしを忘れた」と主なる神は言われる。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="エゼキエル書 21:17; イザヤ書 33:15; アモス書 2:6–8"> 「見よ、それゆえ、わたしはあなたが得た不正な利益と、あなたの中で流された血のために手を打った。</span>
<span className="v" id="v14" data-v="14" data-xref="エゼキエル書 21:7; エゼキエル書 17:24; エゼキエル書 24:14"> わたしがあなたを扱う日に、あなたの心は耐えられるだろうか。あなたの手はなお強くあり続けられるだろうか。主であるわたしが語った。わたしはそれを行う。</span>
<span className="v" id="v15" data-v="15" data-xref="ネヘミヤ記 1:8; エゼキエル書 22:22; 申命記 4:27"> わたしはあなたを諸国の間に散らし、国々の中に追い散らす。わたしはあなたの汚れをあなたの中から取り除く。</span>
<span className="v" id="v16" data-v="16" data-xref="エゼキエル書 6:7; 詩篇 83:18; エゼキエル書 7:24"> あなた自身が諸国の目の前で汚される。そのとき、あなたは、わたしが主であることを知る。」』」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17"> 主の言葉が私に臨んだ。</span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 119:119; イザヤ書 1:22; エレミヤ書 6:28–30"> 「人の子よ、イスラエルの家はわたしにとって金かすとなった。彼らは皆、炉の中の青銅、すず、鉄、鉛であり、銀の金かすである。</span>
<span className="v" id="v19" data-v="19" data-xref="マタイ 13:30; エゼキエル書 24:3–6; ミカ書 4:12"> それゆえ、主なる神はこう言われる。『あなたがたは皆、金かすとなったので、見よ、わたしはあなたがたをエルサレムのただ中に集める。</span>
<span className="v" id="v20" data-v="20" data-xref="エレミヤ書 4:11–12; イザヤ書 54:16; エゼキエル書 24:13"> 人々が銀、青銅、鉄、鉛、すずを炉の中に集め、その上に火を吹きつけて溶かすように、わたしは怒りと憤りをもってあなたがたを集め、そこに置いて溶かす。</span>
<span className="v" id="v21" data-v="21" data-xref="イザヤ書 64:7; ナホム書 1:6; 詩篇 50:3"> わたしはあなたがたを集め、怒りの火を吹きつける。あなたがたはその中で溶かされる。</span>
<span className="v" id="v22" data-v="22" data-xref="エゼキエル書 20:8; エゼキエル書 20:33; ホセア書 5:10"> 銀が炉の中で溶かされるように、あなたがたもその中で溶かされる。そのとき、あなたがたは、主であるわたしが憤りをあなたがたの上に注いだことを知る。』」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23"> 主の言葉が私に臨んだ。</span>
<span className="v" id="v24" data-v="24" data-xref="歴代誌 第二 36:14–16; エレミヤ書 2:30; 歴代誌 第二 28:22"> 「人の子よ、この地に言え。『あなたは清められず、憤りの日に雨も降らない地である。』</span>
<span className="v" id="v25" data-v="25" data-xref="ホセア書 6:9; エレミヤ書 2:34; エゼキエル書 13:19"> その中には預言者たちの陰謀がある。彼らは獲物を引き裂く、ほえる獅子のようである。彼らは人の命を食い尽くし、宝物や貴重品を奪い、その中で多くの女をやもめにした。</span>
<span className="v" id="v26" data-v="26" data-xref="レビ記 10:10; エゼキエル書 44:23; エゼキエル書 22:8"> その祭司たちはわたしの律法を侵し、わたしの聖なるものを汚した。彼らは聖なるものと俗なるものとを区別せず、汚れたものと清いものとの違いを人々に教えず、わたしの安息日から目を背けた。そのため、わたしは彼らの中で汚されている。</span>
<span className="v" id="v27" data-v="27" data-xref="エゼキエル書 22:13; イザヤ書 1:23; エゼキエル書 22:6"> その中の君主たちは、獲物を引き裂く狼のようである。不正な利益を得るために血を流し、人の命を奪っている。</span>
<span className="v" id="v28" data-v="28" data-xref="エゼキエル書 13:6–7; エゼキエル書 13:10–16; エレミヤ書 23:25–32"> その預言者たちは彼らのためにしっくいを塗り、偽りの幻を見、偽りを占って、『主なる神はこう言われる』と言う。しかし、主は語っていない。</span>
<span className="v" id="v29" data-v="29" data-xref="エゼキエル書 22:7; 出エジプト記 23:9; 出エジプト記 22:21"> この地の民は人を虐げ、略奪を行ってきた。彼らは貧しい者や乏しい者を苦しめ、寄留者を不当に圧迫した。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="イザヤ書 59:16; エレミヤ書 5:1; 詩篇 106:23"> わたしはその中で、城壁を築き、この地を滅ぼさなくてよいように、わたしの前で破れ口に立つ者を捜した。しかし、だれも見つからなかった。</span>
<span className="v" id="v31" data-v="31" data-xref="エゼキエル書 16:43; エゼキエル書 7:8–9; エゼキエル書 9:10"> それゆえ、わたしは彼らの上に憤りを注ぎ、怒りの火で彼らを焼き尽くした。彼らの歩みを彼ら自身の頭に報いた」と主なる神は言われる。</span>
</div>

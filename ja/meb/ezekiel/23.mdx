<div className="bp">
<span className="v" id="v1" data-v="1"> 再び、主の言葉が私に臨んだ。</span>
<span className="v" id="v2" data-v="2" data-xref="エゼキエル書 16:44–46; エレミヤ書 3:7–10"> 「人の子よ、一人の母から生まれた二人の女がいた。</span>
<span className="v" id="v3" data-v="3" data-xref="レビ記 17:7; エゼキエル書 16:22; ヨシュア記 24:14"> 彼女たちはエジプトで淫行を行い、若い時から淫行を行った。そこで彼女たちの乳房はもてあそばれ、若い乳首は愛撫された。</span>
<span className="v" id="v4" data-v="4" data-xref="エゼキエル書 16:8; 詩篇 76:2; エレミヤ書 2:2–3"> 姉の名はオホラ、妹の名はオホリバであった。彼女たちはわたしのものとなり、息子や娘を産んだ。その名について言えば、オホラはサマリア、オホリバはエルサレムである。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="ホセア書 5:13; 列王記第二 17:3; 列王記第二 16:7"> オホラはわたしのものでありながら淫行を行った。彼女は愛人たち、近隣のアッシリア人を慕った。</span>
<span className="v" id="v6" data-v="6" data-xref="エゼキエル書 23:23"> 彼らは青い衣をまとった総督や支配者であり、皆、魅力的な若者で、馬に乗る騎兵であった。</span>
<span className="v" id="v7" data-v="7" data-xref="ホセア書 5:3; ホセア書 6:10; エゼキエル書 22:3–4"> 彼女は彼ら、すなわちアッシリアの選り抜きの男たちすべてを相手に淫行を行った。慕った者が持つすべての偶像によって自分を汚した。</span>
<span className="v" id="v8" data-v="8" data-xref="エゼキエル書 23:19; エゼキエル書 23:3; 出エジプト記 32:4"> 彼女はエジプトを出てからも、そこでの淫行をやめなかった。若い時、彼らは彼女と寝て、若い乳首を愛撫し、彼女に淫行を注ぎかけたからである。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="ホセア書 11:5; 列王記第二 15:29; 列王記第二 17:23"> それゆえ、わたしは彼女を愛人たちの手、彼女が慕ったアッシリア人の手に渡した。</span>
<span className="v" id="v10" data-v="10" data-xref="エゼキエル書 23:29; ホセア書 2:10; エレミヤ書 22:8–9"> 彼らは彼女の裸をあらわにし、息子や娘を奪い、彼女を剣で殺した。彼女は女たちの間で語り草となった。彼らが彼女に裁きを行ったからである。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="エレミヤ書 3:8–11; エゼキエル書 16:47–51; エゼキエル書 23:4"> 妹のオホリバはこれを見た。それでも、彼女は情欲の面で姉以上に堕落し、その淫行は姉の淫行よりもさらにひどかった。</span>
<span className="v" id="v12" data-v="12" data-xref="列王記第二 16:7–15; エゼキエル書 23:23; 歴代誌 第二 28:16–23"> 彼女はアッシリア人を慕った。彼らは近隣の総督や支配者で、華麗な衣をまとい、馬に乗る騎兵であり、皆、魅力的な若者であった。</span>
<span className="v" id="v13" data-v="13" data-xref="ホセア書 12:1–2; 列王記第二 17:18–19; エゼキエル書 23:31"> わたしは彼女が汚れたのを見た。二人とも同じ道を歩んだ。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="エゼキエル書 8:10; エレミヤ書 22:14; エレミヤ書 50:2"> 彼女はさらに淫行を増し加えた。壁に描かれた男たち、朱色で描かれたカルデア人の像を見たからである。</span>
<span className="v" id="v15" data-v="15" data-xref="士師記 8:18; サムエル記第一 18:4; イザヤ書 22:21"> 彼らは腰に帯を締め、頭にはゆったりと垂れたターバンを着け、皆、君主たちのように見えた。彼らの生まれた地、カルデアのバビロン人の姿であった。</span>
<span className="v" id="v16" data-v="16" data-xref="エゼキエル書 16:29; マタイ 5:28; ヨブ記 31:1"> 彼女は彼らを見るとすぐに慕い、カルデアへ使者を送った。</span>
<span className="v" id="v17" data-v="17" data-xref="エゼキエル書 23:28; エゼキエル書 23:22; 創世記 10:10"> バビロン人は彼女の愛の床に入って来て、淫行によって彼女を汚した。彼女は彼らによって汚されたが、やがて彼女の心は彼らを嫌うようになった。</span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 78:59; 詩篇 106:40; エレミヤ書 12:8"> 彼女は淫行をあらわにし、裸をさらした。それで、わたしの心も、姉を嫌ったのと同じように彼女を嫌うようになった。</span>
<span className="v" id="v19" data-v="19" data-xref="エゼキエル書 23:3; エゼキエル書 20:7; エゼキエル書 16:51"> それでも彼女は、エジプトの地で淫行を行った若い日々を思い出し、淫行を増し加えた。</span>
<span className="v" id="v20" data-v="20" data-xref="エゼキエル書 17:15; エゼキエル書 16:26; エレミヤ書 5:8"> 彼女は、肉体がろばの肉体のようで、精液が馬の精液のような愛人たちを慕った。</span>
<span className="v" id="v21" data-v="21"> こうしてあなたは、エジプト人が若い乳房のためにあなたの乳首を愛撫した、若い日の淫らな行いを思い起こした。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="エゼキエル書 16:37; ヨハネの黙示録 17:16; エレミヤ書 6:22–23"> それゆえ、オホリバよ、主なる神はこう言われる。『見よ、わたしは、あなたが嫌うようになった愛人たちをあなたに敵対させ、四方から彼らをあなたに攻め来させる。</span>
<span className="v" id="v23" data-v="23" data-xref="エレミヤ書 50:21; 列王記第二 24:2; 列王記第二 20:14–17"> バビロン人とすべてのカルデア人、ペコデ、ショア、コア、そして彼らと共にいるすべてのアッシリア人である。彼らは皆、魅力的な若者、総督、支配者、君主、名高い者であり、皆、馬に乗っている。</span>
<span className="v" id="v24" data-v="24" data-xref="サムエル記第二 24:14; エゼキエル書 26:10; エゼキエル書 23:45"> 彼らは武器と戦車と荷車を携え、多くの民と共にあなたに攻めて来る。彼らは小盾、大盾、兜を持って、四方からあなたに立ち向かう。わたしは裁きを彼らに委ね、彼らは自分たちの裁きに従ってあなたを裁く。</span>
<span className="v" id="v25" data-v="25" data-xref="エゼキエル書 23:47; エゼキエル書 8:1–18; エゼキエル書 15:6–7"> わたしはあなたに対してねたみを燃やす。彼らは憤りをもってあなたを扱い、あなたの鼻と耳を切り取る。あなたの残りの者は剣に倒れる。彼らはあなたの息子や娘を奪い、あなたの残りの者は火に食い尽くされる。</span>
<span className="v" id="v26" data-v="26" data-xref="エゼキエル書 16:39; エレミヤ書 13:22; エゼキエル書 23:29"> 彼らはあなたの衣服をはぎ取り、美しい飾り物を奪う。</span>
<span className="v" id="v27" data-v="27" data-xref="エゼキエル書 16:41; エゼキエル書 23:3; エゼキエル書 23:19"> こうして、わたしはあなたの淫らな行いと、エジプトの地以来の淫行をやめさせる。あなたはもはや彼らを仰ぎ見ることも、エジプトを思い出すこともない。』</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="エゼキエル書 23:22; エゼキエル書 23:17; エレミヤ書 34:20"> 主なる神はこう言われる。『見よ、わたしはあなたを、あなたが憎む者たち、あなたが嫌うようになった者たちの手に渡す。</span>
<span className="v" id="v29" data-v="29" data-xref="エゼキエル書 16:39; エゼキエル書 23:25–26; エゼキエル書 23:45–47"> 彼らは憎しみをもってあなたを扱い、あなたが働いて得たものをすべて奪い、あなたを裸のまま残す。あなたの淫行による裸、淫らな行いと淫行はあらわにされる。</span>
<span className="v" id="v30" data-v="30" data-xref="エゼキエル書 6:9; 詩篇 106:35–38; エレミヤ書 2:18–20"> これらのことがあなたに行われるのは、あなたが諸国を追って淫行を行い、彼らの偶像によって汚されたからである。</span>
<span className="v" id="v31" data-v="31" data-xref="列王記第二 21:13; エレミヤ書 7:14–15; エゼキエル書 16:47–51"> あなたは姉の道を歩んだ。それゆえ、わたしは姉の杯をあなたの手に渡す。』</span>
</div>
<div className="bp poetry">
<span className="v" id="v32" data-v="32" data-xref="イザヤ書 51:17; 詩篇 60:3; エゼキエル書 22:4–5"> 主なる神はこう言われる。<br /><span className="pl pl-1">『あなたは姉の杯を飲む。</span><br /><span className="pl pl-2">それは深く、大きい。</span><br /><span className="pl pl-1">あなたはあざけられ、物笑いにされる。</span><br /><span className="pl pl-2">その杯には多くのものが入っている。</span></span>
<span className="v" id="v33" data-v="33" data-xref="イザヤ書 51:17; エレミヤ書 25:27; エレミヤ書 25:15–16"> <span className="pl pl-1">あなたは酔いと悲しみに満たされる。</span><br /><span className="pl pl-2">驚きと荒廃の杯、</span><br /><span className="pl pl-2">あなたの姉サマリアの杯によって。</span></span>
<span className="v" id="v34" data-v="34" data-xref="詩篇 75:8; イザヤ書 51:17; ヨハネの黙示録 18:7"> <span className="pl pl-1">あなたはそれを飲み干し、</span><br /><span className="pl pl-2">その割れた破片をかじり、</span><br /><span className="pl pl-2">自分の乳房を引き裂く。</span><br />わたしが語った』と主なる神は言われる。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="列王記第一 14:9; イザヤ書 17:10; エレミヤ書 32:33"> それゆえ、主なる神はこう言われる。『あなたはわたしを忘れ、わたしを自分の背後に投げ捨てた。それゆえ、あなたも自分の淫らな行いと淫行を負え。』」</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="エゼキエル書 22:2; イザヤ書 58:1; エゼキエル書 16:2"> さらに、主は私に言われた。「人の子よ、あなたはオホラとオホリバを裁くのか。それなら、彼女たちにその忌むべき行いを告げよ。</span>
<span className="v" id="v37" data-v="37" data-xref="エゼキエル書 16:36; エレミヤ書 32:35; エレミヤ書 7:31"> 彼女たちは姦淫を行い、その手には血がある。彼女たちは偶像と姦淫を行った。また、わたしのために産んだ息子たちを、偶像に食い尽くさせるために火の中を通らせた。</span>
<span className="v" id="v38" data-v="38" data-xref="エゼキエル書 20:13; 列王記第二 21:7; エゼキエル書 7:20"> さらに、彼女たちはわたしに対してこのことを行った。同じ日にわたしの聖所を汚し、わたしの安息日を汚した。</span>
<span className="v" id="v39" data-v="39" data-xref="列王記第二 21:4; エゼキエル書 44:7; エレミヤ書 23:11"> 彼女たちは自分の子どもたちを偶像のために殺した後、同じ日にわたしの聖所へ入り、それを汚した。見よ、彼女たちはわたしの家のただ中でこのことを行った。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="列王記第二 9:30; エレミヤ書 4:30; エゼキエル書 16:13–16"> さらに、あなたがたは遠くから来る男たちを呼び寄せ、そのもとへ使者を送った。見よ、彼らはやって来た。あなたは彼らのために体を洗い、目に化粧を施し、飾り物で身を飾った。</span>
<span className="v" id="v41" data-v="41" data-xref="エステル記 1:6; エレミヤ書 44:17; イザヤ書 65:11"> そして、豪華な寝台に座り、その前に食卓を整え、その上にわたしの香と油を置いた。</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="エゼキエル書 16:11–12; ヨハネの黙示録 12:3; 出エジプト記 32:18–19"> 彼女のそばには、安逸にふける群衆の声があった。一般の人々と共に、荒野から酔いどれたちが連れて来られた。彼らは彼女たちの手に腕輪をはめ、頭に美しい冠を載せた。</span>
<span className="v" id="v43" data-v="43" data-xref="エゼキエル書 23:3; エレミヤ書 13:23; エズラ記 9:7"> そこで私は、姦淫によって老い衰えた女について言った。『今になって、彼らは彼女と淫行を行い、彼女も彼らと淫行を行うのか。』</span>
<span className="v" id="v44" data-v="44" data-xref="エゼキエル書 23:9–13; エゼキエル書 23:3"> 彼らは娼婦のもとへ入るように彼女のもとへ入った。このようにして、淫らな女オホラとオホリバのもとへ入った。</span>
<span className="v" id="v45" data-v="45" data-xref="ホセア書 6:5; レビ記 20:10; エゼキエル書 23:36–39"> しかし、義人たちは、姦淫を行う女への裁きと、血を流す女への裁きによって、彼女たちを裁く。彼女たちは姦淫を行う女であり、その手には血があるからである。</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="エゼキエル書 16:40; エレミヤ書 15:4; エレミヤ書 24:9"> 主なる神はこう言われる。『わたしは彼女たちに対して群衆を攻め上らせ、彼女たちを翻弄され、略奪される者とする。</span>
<span className="v" id="v47" data-v="47" data-xref="エゼキエル書 16:40–41; エレミヤ書 39:8; エゼキエル書 24:21"> その群衆は彼女たちを石で打ち、剣で切り倒す。彼女たちの息子や娘を殺し、家々を火で焼く。</span>
</div>
<div className="bp">
<span className="v" id="v48" data-v="48" data-xref="エゼキエル書 6:6; エゼキエル書 23:27; エゼキエル書 16:41"> こうして、わたしはこの地から淫らな行いをやめさせる。すべての女は教訓を受け、あなたがたのような淫らな行いをしなくなる。</span>
<span className="v" id="v49" data-v="49" data-xref="エゼキエル書 9:10; エゼキエル書 7:4; エゼキエル書 6:7"> 彼らはあなたがたの淫らな行いをあなたがたに報いる。あなたがたは自分の偶像の罪を負う。そのとき、あなたがたは、わたしが主なる神であることを知る。』」</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨハネの黙示録 10:9–10; エゼキエル書 3:17–21; エゼキエル書 2:8–9"> その方は私に言われた。「人の子よ、目の前にあるものを食べよ。この巻物を食べてから、行ってイスラエルの家に語れ。」</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="エレミヤ書 25:17; 使徒の働き 26:19"> そこで私は口を開き、その方は私にその巻物を食べさせた。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="エレミヤ書 15:16; ヨハネの黙示録 10:9–10; 詩篇 119:103"> その方は私に言われた。「人の子よ、わたしが与えるこの巻物を腹に入れ、内臓を満たせ。」<br />そこで私はそれを食べた。それは私の口に蜜のように甘かった。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="マタイ 10:5–6; 使徒の働き 1:8; エゼキエル書 2:3"> その方は私に言われた。「人の子よ、イスラエルの家へ行き、わたしの言葉を彼らに語れ。</span>
<span className="v" id="v5" data-v="5" data-xref="ヨナ書 1:2; イザヤ書 33:19; ヨナ書 3:2–4"> あなたが遣わされるのは、言葉が異なり、理解しにくい言語の民ではなく、イスラエルの家である。</span>
<span className="v" id="v6" data-v="6" data-xref="マタイ 11:20–24; ローマ人への手紙 9:30–33; ヨナ書 3:5–10"> あなたがその言葉を理解できない、多くの、言葉が異なり、理解しにくい言語の民に遣わされるのでもない。もしわたしがあなたを彼らに遣わしたなら、彼らは必ずあなたに聞き従っただろう。</span>
<span className="v" id="v7" data-v="7" data-xref="ルカ 10:16; エゼキエル書 2:4; サムエル記第一 8:7"> しかし、イスラエルの家はあなたに聞き従おうとしない。彼らはわたしにも聞き従おうとしないからだ。イスラエルの家は皆、額が硬く<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="直訳すると「額が硬い」">a</a></sup>、心もかたくなである。</span>
<span className="v" id="v8" data-v="8" data-xref="エレミヤ書 1:18; 使徒の働き 7:51–56; ミカ書 3:8"> 見よ、わたしはあなたの顔を彼らの顔に対して硬くし、あなたの額を彼らの額に対して硬くした。</span>
<span className="v" id="v9" data-v="9" data-xref="エゼキエル書 2:6; エレミヤ書 1:8; イザヤ書 50:7"> わたしはあなたの額を金剛石のように、火打石よりも硬くした。彼らを恐れてはならない。その顔におびえてはならない。彼らは反逆の家だからだ。」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="詩篇 119:11; ヨブ記 22:22; エゼキエル書 3:1–3"> また、その方は私に言われた。「人の子よ、わたしがあなたに語るすべての言葉を心に受け止め、耳で聞け。</span>
<span className="v" id="v11" data-v="11" data-xref="エゼキエル書 2:7; エゼキエル書 3:27; エゼキエル書 33:30"> 捕囚となっているあなたの民の子らのところへ行き、彼らに語れ。彼らが聞いても、聞くことを拒んでも、『主なる神はこう言われる』と告げよ。」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="エゼキエル書 8:3; 使徒の働き 8:39; エゼキエル書 11:1"> その時、霊が私を引き上げた。すると、私の後ろから大きなとどろきの声が聞こえた。「主の栄光が、そのおられる所からほめたたえられるように。」</span>
<span className="v" id="v13" data-v="13" data-xref="エゼキエル書 1:24; エゼキエル書 10:16–17; エゼキエル書 10:5"> また、生き物の翼が互いに触れ合う音と、そのそばの車輪の音が聞こえた。それは大きなとどろきであった。</span>
<span className="v" id="v14" data-v="14" data-xref="エゼキエル書 37:1; エレミヤ書 20:7–9; 列王記第二 3:15"> 霊は私を引き上げ、連れ去った。私は苦々しい思いと、霊の燃える思いを抱いて進んだ。主の御手が強く私の上に臨んでいた。</span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 137:1; ヨブ記 2:13; 創世記 50:10"> こうして私は、ケバル川のほとりのテル・アビブに住む捕囚の民のところへ行った。私は彼らが住む所で、呆然として七日間、彼らの中に座っていた。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="エレミヤ書 42:7"> 七日が過ぎた時、主の言葉が私に臨んで言われた。</span>
<span className="v" id="v17" data-v="17" data-xref="イザヤ書 52:8; ヘブル人への手紙 13:17; 歴代誌 第二 19:10"> 「人の子よ、わたしはあなたをイスラエルの家の見張り人とした。わたしの口から言葉を聞き、わたしに代わって彼らに警告せよ。</span>
<span className="v" id="v18" data-v="18" data-xref="エゼキエル書 33:6; ヤコブの手紙 5:19–20; エゼキエル書 3:20"> わたしが悪しき者に、『あなたは必ず死ぬ』と言う時、あなたが彼に警告せず、悪しき者をその悪い道から離れさせて命を救うために語らないなら、その悪しき者は自分の咎のうちに死ぬ。しかし、わたしはその血の責任をあなたの手に求める。</span>
<span className="v" id="v19" data-v="19" data-xref="エゼキエル書 33:9; エゼキエル書 14:20; テモテへの手紙第一 4:16"> しかし、あなたが悪しき者に警告しても、彼がその悪と悪い道から立ち返らないなら、彼は自分の咎のうちに死ぬ。しかし、あなたは自分の命を救ったことになる。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="エゼキエル書 18:24; エゼキエル書 18:26; エゼキエル書 33:12–13"> また、義人が自分の義から離れて不正を行い、わたしが彼の前につまずきの石を置くなら、彼は死ぬ。あなたが彼に警告しなかったので、彼は自分の罪のうちに死に、彼が行った義の行いは覚えられない。しかし、わたしはその血の責任をあなたの手に求める。</span>
<span className="v" id="v21" data-v="21" data-xref="テモテへの手紙第一 4:16; 箴言 9:9; テトス 2:15"> しかし、あなたが義人に、義人が罪を犯さないよう警告し、彼が罪を犯さないなら、彼は警告を受け入れたので必ず生きる。そして、あなたは自分の命を救ったことになる。」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="使徒の働き 9:6; エゼキエル書 37:1; エゼキエル書 8:4"> そこで主の御手が私の上に臨み、主は私に言われた。「立って平地へ出て行け。そこで、わたしはあなたに語る。」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="エゼキエル書 1:28; 使徒の働き 7:55; ヨハネの黙示録 1:17"> そこで私は立って平地へ出て行った。すると見よ、ケバル川のほとりで見た栄光と同じ主の栄光が、そこに立っていた。私はひれ伏した。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="エゼキエル書 2:2; ダニエル書 10:19; ダニエル書 10:8–10"> その時、霊が私の中に入り、私を立たせた。主は私に語って言われた。「行って、自分の家に閉じこもれ。</span>
<span className="v" id="v25" data-v="25" data-xref="エゼキエル書 4:8; 使徒の働き 9:16; マルコ 3:21"> 人の子よ、見よ、彼らはあなたに縄をかけ、それであなたを縛る。あなたは彼らの中へ出て行けなくなる。</span>
<span className="v" id="v26" data-v="26" data-xref="エゼキエル書 24:27; ミカ書 3:6–7; アモス書 8:11–12"> わたしはあなたの舌を上あごにつかせる。あなたは口がきけなくなり、彼らを戒める者になれない。彼らは反逆の家だからだ。</span>
<span className="v" id="v27" data-v="27" data-xref="エゼキエル書 12:2–3; エゼキエル書 24:27; エゼキエル書 3:11"> しかし、わたしがあなたに語る時、わたしはあなたの口を開く。あなたは彼らに、『主なる神はこう言われる』と告げよ。聞く者は聞け。拒む者は拒め。彼らは反逆の家だからだ。」</span>
</div>

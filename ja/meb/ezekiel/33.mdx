<div className="bp">
<span className="v" id="v1" data-v="1"> 主の言葉が私に臨んだ。</span>
<span className="v" id="v2" data-v="2" data-xref="エゼキエル書 33:30; エゼキエル書 33:17; エゼキエル書 3:11"> 「人の子よ、あなたの民の子らに語り、彼らに言え。『わたしがある地に剣をもたらすとき、その地の民が自分たちの中から一人を選び、自分たちの見張り人としたとする。</span>
<span className="v" id="v3" data-v="3" data-xref="ホセア書 8:1; ネヘミヤ記 4:20; ネヘミヤ記 4:18"> その者が剣の来るのを見て角笛を吹き、民に警告したとき、</span>
<span className="v" id="v4" data-v="4" data-xref="エゼキエル書 18:13; 使徒の働き 18:6; エレミヤ書 6:17"> 角笛の音を聞いても警告に注意せず、剣が来てその者を取り去ったなら、その血の責任はその人自身の頭にある。</span>
<span className="v" id="v5" data-v="5" data-xref="出エジプト記 9:19–21; ヘブル人への手紙 11:7; ヨハネ 8:39"> 彼は角笛の音を聞いたのに、警告を受け入れなかった。その血の責任は彼自身にある。しかし、警告を受け入れていたなら、自分の命を救えただろう。</span>
<span className="v" id="v6" data-v="6" data-xref="エゼキエル書 3:18–20; エゼキエル書 33:8–9; 創世記 42:22"> しかし、見張り人が剣の来るのを見ても角笛を吹かず、民が警告を受けないまま、剣が来て彼らの中からだれかを取り去ったなら、その人は自分の不義のために取り去られる。しかし、わたしはその血の責任を見張り人の手に問う。』</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="エゼキエル書 3:17–21; エレミヤ書 26:2; エゼキエル書 2:7–8"> 人の子よ、わたしはあなたをイスラエルの家の見張り人とした。それゆえ、わたしの口から言葉を聞き、わたしに代わって彼らに警告せよ。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒の働き 20:26–27; エゼキエル書 33:6; エゼキエル書 33:14"> わたしが悪人に、『悪人よ、あなたは必ず死ぬ』と言うとき、あなたが悪人にその道から離れるよう警告するために語らないなら、その悪人は自分の不義のうちに死ぬ。しかし、わたしはその血の責任をあなたの手に問う。</span>
<span className="v" id="v9" data-v="9" data-xref="エゼキエル書 3:19; 使徒の働き 20:26; 箴言 15:10"> しかし、あなたが悪人に、その道から離れるよう警告しても、彼がその道から離れないなら、彼は自分の不義のうちに死ぬ。しかし、あなたは自分の命を救った。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="イザヤ書 49:14; エゼキエル書 37:11; エゼキエル書 24:23"> 人の子よ、イスラエルの家に言え。『あなたがたは、「われわれの背きと罪がわれわれの上にあり、そのためにわれわれは衰え果てている。それなのに、どうして生きられるだろうか」と言っている。』</span>
<span className="v" id="v11" data-v="11" data-xref="テモテへの手紙第一 2:4; エゼキエル書 18:23; ペテロの第二の手紙 3:9"> 彼らに言え。『「わたしは生きている」と主なる神は言われる。「わたしは悪人の死を喜ばない。むしろ、悪人が自分の道から立ち返って生きることを喜ぶ。立ち返れ。あなたがたの悪い道から立ち返れ。イスラエルの家よ、なぜ死のうとするのか。」』</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="歴代誌 第二 7:14; エゼキエル書 33:18–19; ローマ人への手紙 3:25"> 人の子よ、あなたの民の子らに言え。『義人の義も、彼が背いた日には彼を救わない。悪人の悪も、彼がその悪から立ち返った日には、そのために倒れることはない。また、義人も罪を犯した日には、自分の義によって生きることはできない。</span>
<span className="v" id="v13" data-v="13" data-xref="エゼキエル書 18:24; ヘブル人への手紙 10:38; エゼキエル書 18:4"> わたしが義人に、「あなたは必ず生きる」と言っても、彼が自分の義に頼って不義を行うなら、彼の正しい行いは一つも覚えられない。彼は自分が行った不義のために死ぬ。</span>
<span className="v" id="v14" data-v="14" data-xref="エゼキエル書 18:27; エレミヤ書 18:7–8; ホセア書 14:1"> また、わたしが悪人に、「あなたは必ず死ぬ」と言っても、彼が自分の罪から立ち返り、公正で正しいことを行い、</span>
<span className="v" id="v15" data-v="15" data-xref="エゼキエル書 20:11; ルカ 19:8; 出エジプト記 22:1–4"> 担保を返し、奪ったものを償い、不義を行わず、命の掟に従って歩むなら、彼は必ず生き、死ぬことはない。</span>
<span className="v" id="v16" data-v="16" data-xref="イザヤ書 43:25; エゼキエル書 18:22; ミカ書 7:18–19"> 彼が犯した罪は一つも、彼に対して覚えられることはない。彼は公正で正しいことを行ったので、必ず生きる。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="マタイ 25:24–26; エゼキエル書 18:25; エゼキエル書 18:29"> それでも、あなたの民の子らは、「主の道は公平ではない」と言う。しかし、公平でないのは彼らの道である。</span>
<span className="v" id="v18" data-v="18" data-xref="エゼキエル書 33:12–13; ペテロの第二の手紙 2:20–22; ヘブル人への手紙 10:38"> 義人が自分の義から離れて不義を行うなら、彼はそのために死ぬ。</span>
<span className="v" id="v19" data-v="19" data-xref="エゼキエル書 18:27–28; エゼキエル書 33:14"> 悪人が自分の悪から離れ、公正で正しいことを行うなら、彼はそれによって生きる。</span>
<span className="v" id="v20" data-v="20" data-xref="マタイ 16:27; エゼキエル書 18:25; エゼキエル書 33:17"> それでも、あなたがたは、「主の道は公平ではない」と言う。イスラエルの家よ、わたしはあなたがたを、それぞれの歩みに従って裁く。』」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="エゼキエル書 1:2; エレミヤ書 39:1–8; 列王記第二 25:4"> 私たちが捕囚となって第十二年の第十の月、その月の五日、エルサレムから逃れて来た者が私のもとに来て、「町は陥落しました」と言った。</span>
<span className="v" id="v22" data-v="22" data-xref="エゼキエル書 1:3; エゼキエル書 3:26–27; エゼキエル書 24:26–27"> 逃れて来た者が到着する前の夕方、主の手が私の上にあった。主は、その者が朝、私のもとに来るまでに、私の口を開かれた。こうして私の口は開かれ、私はもはや口のきけない者ではなくなった。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23"> 主の言葉が私に臨んだ。</span>
<span className="v" id="v24" data-v="24" data-xref="エゼキエル書 33:27; イザヤ書 51:2; 使徒の働き 7:5"> 「人の子よ、イスラエルの地の廃墟に住む者たちは言っている。『アブラハムは一人だったが、この地を所有した。われわれは大勢いる。この地はわれわれの所有として与えられている。』</span>
<span className="v" id="v25" data-v="25" data-xref="申命記 12:16; エレミヤ書 7:9–10; 創世記 9:4"> それゆえ、彼らに言え。『主なる神はこう言われる。「あなたがたは血のついたまま肉を食べ、偶像を仰ぎ見て、血を流している。それでも、この地を所有できるのか。</span>
<span className="v" id="v26" data-v="26" data-xref="創世記 27:40; ミカ書 2:1–2; ゼパニヤ書 3:3"> あなたがたは自分の剣を頼みとし、忌むべきことを行い、それぞれ隣人の妻を汚している。それでも、この地を所有できるのか。」』</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="サムエル記第一 13:6; エレミヤ書 42:22; エゼキエル書 39:4"> あなたは彼らに言え。『主なる神はこう言われる。「わたしは生きている。廃墟にいる者たちは必ず剣に倒れる。野原にいる者は、野の動物に与えて食い尽くさせる。とりでや洞穴にいる者は、疫病で死ぬ。</span>
<span className="v" id="v28" data-v="28" data-xref="エゼキエル書 7:24; エレミヤ書 44:2; エレミヤ書 44:6"> わたしはこの地を荒れ果てた所、驚きの的とする。その力の誇りは終わり、イスラエルの山々は荒れ果て、通り過ぎる者もいなくなる。</span>
<span className="v" id="v29" data-v="29" data-xref="エゼキエル書 6:7; エゼキエル書 36:17–18; エゼキエル書 22:2–15"> 彼らが行ったすべての忌むべき行いのために、わたしがこの地を荒れ果てた所、驚きの的とするとき、彼らは、わたしが主であることを知る。」』</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="マタイ 22:16–17; エレミヤ書 23:35; イザヤ書 29:13"> 人の子よ、あなたの民の子らは、城壁のそばや家々の戸口であなたについて語り、互いに、自分の兄弟に言っている。『さあ、主から出る言葉が何であるか、聞きに行こう。』</span>
<span className="v" id="v31" data-v="31" data-xref="マタイ 13:22; 詩篇 78:36–37; ヤコブの手紙 1:22–24"> 彼らは民が集まって来るようにあなたのもとへ来て、わたしの民のようにあなたの前に座り、あなたの言葉を聞く。しかし、それを行わない。彼らは口では愛を語るが、その心は不正な利益を追い求めている。</span>
<span className="v" id="v32" data-v="32" data-xref="マルコ 6:20; マルコ 4:16–17; ヨハネ 5:35"> 見よ、あなたは彼らにとって、美しい声を持ち、楽器を巧みに奏でる者が歌う、愛らしい歌のようである。彼らはあなたの言葉を聞くが、それを行わない。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="エレミヤ書 28:9; サムエル記第一 3:19–20; エゼキエル書 2:5"> これが実現するとき、見よ、それは来る。そのとき、彼らは、自分たちの中に預言者がいたことを知る。」</span>
</div>

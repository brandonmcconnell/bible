<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出エジプト記 24:10; ヨハネの黙示録 4:2–3; ヨハネの黙示録 1:13"> 私が見ると、見よ、ケルビムの頭上にある大空に、サファイア<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="または「ラピスラズリ」">a</a></sup>のようなものが現れた。それは王座の形に似て、ケルビムの上にあった。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネの黙示録 8:5; エゼキエル書 10:16; エゼキエル書 1:13"> その方は亜麻布の衣を着た者に語って言われた。「回転する車輪の間、ケルブの下へ入り、ケルビムの間から燃える炭火を両手いっぱいに取り、町の上にまき散らせ。」<br />その人は、私が見ている前で入って行った。</span>
<span className="v" id="v3" data-v="3" data-xref="エゼキエル書 43:4; エゼキエル書 9:3; エゼキエル書 8:16"> その人が入って行った時、ケルビムは神殿の右側に立っており、雲が内庭を満たしていた。</span>
<span className="v" id="v4" data-v="4" data-xref="エゼキエル書 1:28; エゼキエル書 9:3; 出エジプト記 40:35"> 主の栄光はケルブの上から上り、神殿の敷居の上にとどまった。神殿は雲で満たされ、庭は主の栄光の輝きで満たされた。</span>
<span className="v" id="v5" data-v="5" data-xref="エゼキエル書 1:24; ヨブ記 40:9; 出エジプト記 19:16"> ケルビムの翼の音は外庭にまで聞こえ、全能の神が語られる声のようであった。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="エゼキエル書 10:2; 詩篇 99:1; 詩篇 80:1"> その方が亜麻布の衣を着た者に、「回転する車輪の間、ケルビムの間から火を取れ」と命じられると、その人は入って行き、一つの車輪のそばに立った。</span>
<span className="v" id="v7" data-v="7" data-xref="マタイ 13:41–42; エゼキエル書 1:13; エゼキエル書 41:23–26"> すると、一人のケルブが、ケルビムの間から手を伸ばして、その間にある火を取り、亜麻布の衣を着た者の手に置いた。その人はそれを受け取り、出て行った。</span>
<span className="v" id="v8" data-v="8" data-xref="エゼキエル書 1:8; エゼキエル書 10:21; イザヤ書 6:6"> ケルビムには、その翼の下に人の手のようなものが見えた。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="エゼキエル書 1:15–17; ダニエル書 10:6; ヨハネの黙示録 21:20"> 私が見ると、見よ、ケルビムのそばに四つの車輪があり、一人のケルブのそばに一つの車輪、もう一人のケルブのそばにもう一つの車輪があった。車輪の外観は緑柱石のようであった。</span>
<span className="v" id="v10" data-v="10" data-xref="エゼキエル書 1:16; 詩篇 36:6; 詩篇 104:24"> その外観は四つとも同じ形で、一つの車輪の中に別の車輪があるようであった。</span>
<span className="v" id="v11" data-v="11" data-xref="エゼキエル書 1:17; エゼキエル書 10:22; エゼキエル書 1:20"> 進む時には四方のどの方向にも進み、進む時に向きを変えなかった。頭が向く所へ、その後について進み、進む時に向きを変えなかった。</span>
<span className="v" id="v12" data-v="12" data-xref="エゼキエル書 1:18; ヨハネの黙示録 4:8; ヨハネの黙示録 4:6"> ケルビムの全身、背中、手、翼、また車輪には、四つの車輪を含め、周囲一面に目があった。</span>
<span className="v" id="v13" data-v="13"> その車輪は、私が聞いているところで、「回転する車輪」と呼ばれた。</span>
<span className="v" id="v14" data-v="14" data-xref="ヨハネの黙示録 4:7; エゼキエル書 10:21; 列王記第一 7:36"> それぞれに四つの顔があった。第一の顔はケルブの顔、第二の顔は人の顔、第三の顔は獅子の顔、第四の顔は鷲の顔であった。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="エゼキエル書 1:5; ホセア書 9:12; エゼキエル書 11:22"> ケルビムは上って行った。これは、私がケバル川のほとりで見た生き物である。</span>
<span className="v" id="v16" data-v="16" data-xref="エゼキエル書 1:19–21"> ケルビムが進むと、車輪もそのそばを進んだ。ケルビムが翼を上げて地から上る時、車輪もそのそばを離れなかった。</span>
<span className="v" id="v17" data-v="17" data-xref="エゼキエル書 1:20–21; ローマ人への手紙 8:2; エゼキエル書 1:12"> ケルビムが止まると、車輪も止まり、ケルビムが上ると、車輪もともに上った。生き物の霊が車輪の中にあったからである。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="詩篇 18:10; マタイ 23:37–39; 詩篇 78:60–61"> 主の栄光は神殿の敷居の上から出て、ケルビムの上にとどまった。</span>
<span className="v" id="v19" data-v="19" data-xref="エゼキエル書 8:16; エゼキエル書 1:17–21; エゼキエル書 1:26–28"> ケルビムは翼を上げ、私の目の前で地から上った。彼らが出て行くと、車輪もそのそばにあった。彼らは主の家の東の門の入口に立ち、イスラエルの神の栄光がその上にあった。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="エゼキエル書 1:1; エゼキエル書 10:15; 列王記第一 7:36"> これは、私がケバル川のほとりで、イスラエルの神の下に見た生き物である。私は、それらがケルビムであることを知った。</span>
<span className="v" id="v21" data-v="21" data-xref="エゼキエル書 1:6; エゼキエル書 41:18–19; エゼキエル書 10:14"> それぞれに四つの顔と四つの翼があり、その翼の下には人の手のようなものがあった。</span>
<span className="v" id="v22" data-v="22" data-xref="エゼキエル書 10:11; エゼキエル書 1:10; エゼキエル書 1:12"> その顔の形は、私がケバル川のほとりで見た顔と同じであり、その姿も彼ら自身も同じであった。それぞれまっすぐ前へ進んだ。</span>
</div>

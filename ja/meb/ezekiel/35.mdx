<span className="v" id="v1" data-v="1" data-xref="エゼキエル書 22:1; エゼキエル書 21:1; エゼキエル書 34:1"> さらに、主の言葉が私に臨んだ。</span>
<span className="v" id="v2" data-v="2" data-xref="エゼキエル書 6:2; 創世記 32:3; エゼキエル書 25:8"> 「人の子よ、セイル山に顔を向け、これに対して預言せよ。</span>
<span className="v" id="v3" data-v="3" data-xref="エレミヤ書 6:12; エゼキエル書 35:7; エゼキエル書 6:14"> これに言え。『主なる神はこう言われる。「セイル山よ、見よ、わたしはあなたに立ち向かう。わたしはあなたに向かって手を伸ばし、あなたを荒れ果てた所とし、驚きの的とする。</span>
<span className="v" id="v4" data-v="4" data-xref="エゼキエル書 35:9; マラキ書 1:3–4; ヨエル書 3:19"> わたしはあなたの町々を廃墟とし、あなたは荒れ果てる。そのとき、あなたは、わたしが主であることを知る。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="詩篇 137:7; オバデヤ書 1:10–16; アモス書 1:11"> あなたは永遠の敵意を抱き、イスラエルの子らが災難に遭った時、終わりの不義の時に、彼らを剣の力に渡した。</span>
<span className="v" id="v6" data-v="6" data-xref="イザヤ書 63:2–6; ヨハネの黙示録 18:24; オバデヤ書 1:15"> それゆえ、わたしは生きている」と主なる神は言われる。「わたしはあなたを血に定め、血があなたを追う。あなたは血を憎まなかったので、血があなたを追う。</span>
<span className="v" id="v7" data-v="7" data-xref="エゼキエル書 29:11; エゼキエル書 35:3; 士師記 5:6–7"> わたしはセイル山を荒れ果てた所、驚きの的とし、そこを行き来する者を断ち切る。</span>
<span className="v" id="v8" data-v="8" data-xref="エゼキエル書 31:12; エゼキエル書 32:4–5; エゼキエル書 39:4–5"> わたしはその山々を殺された者で満たす。剣で殺された者たちは、あなたの丘、谷、すべての水路に倒れる。</span>
<span className="v" id="v9" data-v="9" data-xref="エゼキエル書 25:13; マラキ書 1:3–4; エゼキエル書 6:7"> わたしはあなたを永遠に荒れ果てた所とする。あなたの町々には人が住まなくなる。そのとき、あなたがたは、わたしが主であることを知る。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="エゼキエル書 36:5; 詩篇 83:4–12; エゼキエル書 48:35"> あなたは、『この二つの国民と二つの国は私のものとなる。われわれがそれを所有する』と言った。しかし、そこには主がおられた。</span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 9:16; マタイ 7:2; 詩篇 73:17–18"> それゆえ、わたしは生きている」と主なる神は言われる。「あなたが彼らを憎み、怒りとねたみを示したように、わたしもあなたを扱う。わたしがあなたを裁くとき、彼らの中で自分を知らせる。</span>
<span className="v" id="v12" data-v="12" data-xref="エゼキエル書 36:2; 詩篇 83:12; エゼキエル書 6:7"> あなたは、主であるわたしが、イスラエルの山々に向かって語ったあなたのすべての侮辱を聞いたことを知る。あなたは、『それらは荒れ果てた。食い尽くすためにわれわれに与えられた』と言った。</span>
<span className="v" id="v13" data-v="13" data-xref="ダニエル書 11:36; イザヤ書 36:20; エレミヤ書 29:23"> あなたがたは口をもってわたしに向かって高ぶり、わたしに逆らう言葉を増し加えた。わたしはそれを聞いた。」</span>
<span className="v" id="v14" data-v="14" data-xref="エレミヤ書 51:48; イザヤ書 14:7–8; イザヤ書 65:13–15"> 主なる神はこう言われる。「全地が喜ぶとき、わたしはあなたを荒れ果てさせる。</span>
<span className="v" id="v15" data-v="15" data-xref="エゼキエル書 35:3–4; 哀歌 4:21; イザヤ書 34:5–6"> イスラエルの家の相続地が荒れ果てたとき、あなたが喜んだように、わたしもあなたを同じように扱う。セイル山とエドム全土は、ことごとく荒れ果てる。そのとき、彼らは、わたしが主であることを知る。」』」</span>

</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="ヨシュア記 19:24–31; 創世記 30:12–13"> ダンの境界に接し、東側から西側までが、アシェルの一つの割り当て地となる。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="ヨシュア記 19:32–39; 創世記 30:7–8"> アシェルの境界に接し、東側から西側までが、ナフタリの一つの割り当て地となる。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="ヨシュア記 17:1–11; ヨシュア記 13:29–31; 創世記 48:14–20"> ナフタリの境界に接し、東側から西側までが、マナセの一つの割り当て地となる。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="ヨシュア記 17:8–10; ヨシュア記 17:14–18; ヨシュア記 16:1–10"> マナセの境界に接し、東側から西側までが、エフライムの一つの割り当て地となる。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="ヨシュア記 13:15–21; 創世記 29:32; 創世記 49:3–4"> エフライムの境界に接し、東側から西側までが、ルベンの一つの割り当て地となる。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="ヨシュア記 15:1–63; ヨシュア記 19:9; 創世記 29:35"> ルベンの境界に接し、東側から西側までが、ユダの一つの割り当て地となる。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="エゼキエル書 45:1–6; イザヤ書 12:6; イザヤ書 33:20–22"> ユダの境界に接して、東側から西側まで、あなたがたがささげる奉納地を置く。その幅は二万五千竿、長さは東側から西側まで、ほかの割り当て地の一つと同じとする。聖所はその中央に置く。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9"> あなたがたが主にささげる奉納地は、長さ二万五千竿、幅一万竿とする。</span>
<span className="v" id="v10" data-v="10" data-xref="エゼキエル書 45:4; エゼキエル書 44:28; マタイ 10:10"> この聖なる奉納地は祭司たちのためのもので、北側の長さは二万五千竿、西側の幅は一万竿、東側の幅は一万竿、南側の長さは二万五千竿とする。主の聖所はその中央に置く。</span>
<span className="v" id="v11" data-v="11" data-xref="エゼキエル書 40:46; エゼキエル書 44:10; マタイ 24:45–46"> これは、ツァドクの子らのうち、聖別された祭司たちのためのものである。彼らはわたしの指示を守り、イスラエルの子らが迷い出たときにも、レビ人たちのように迷い出なかった。</span>
<span className="v" id="v12" data-v="12" data-xref="レビ記 27:21; エゼキエル書 45:4"> 土地の奉納地のうち、レビ人の境界に接する区画が、彼らのための最も聖なる奉納地となる。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="エゼキエル書 45:3; 申命記 12:19; エゼキエル書 45:5"> 祭司たちの境界に沿って、レビ人の土地は長さ二万五千キュビト、幅一万キュビトとする。全体の長さは二万五千キュビト、幅は一万キュビトである。</span>
<span className="v" id="v14" data-v="14" data-xref="レビ記 27:28; レビ記 27:9–10; 出エジプト記 22:29"> 彼らはその一部も売ってはならず、交換してもならない。この土地の初物を他人に譲り渡してはならない。それは主にとって聖なるものだからである。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="エゼキエル書 42:20; エゼキエル書 45:6; エゼキエル書 44:23"> 二万五千キュビトの幅のうち、残る五千キュビトは、町と住居と放牧地のための一般の土地とする。町はその中央に置く。</span>
<span className="v" id="v16" data-v="16" data-xref="ヨハネの黙示録 21:16"> 町の寸法は次のとおりである。北側は四千五百キュビト、南側は四千五百キュビト、東側は四千五百キュビト、西側は四千五百キュビトとする。</span>
<span className="v" id="v17" data-v="17"> 町の放牧地は、北へ二百五十キュビト、南へ二百五十キュビト、東へ二百五十キュビト、西へ二百五十キュビトとする。</span>
<span className="v" id="v18" data-v="18" data-xref="ヨシュア記 9:27; エズラ記 2:43–58; エゼキエル書 45:6"> 聖なる奉納地に沿って残る土地は、東へ一万キュビト、西へ一万キュビトとする。それは聖なる奉納地に沿って置かれ、その産物は町で働く者たちの食物となる。</span>
<span className="v" id="v19" data-v="19" data-xref="エゼキエル書 45:6; 列王記第一 4:7–23; ネヘミヤ記 11:1–36"> イスラエルのすべての部族から出た、町で働く者たちがこれを耕す。</span>
<span className="v" id="v20" data-v="20" data-xref="ヨハネの黙示録 21:16; ヘブル人への手紙 12:17"> 奉納地全体は、縦二万五千キュビト、横二万五千キュビトの正方形とする。聖なる奉納地と町の所有地を一つにして、ささげなければならない。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="エゼキエル書 48:22; エゼキエル書 37:24; エゼキエル書 48:8"> 残りの土地は君主のものとなる。聖なる奉納地と町の所有地の両側、すなわち、奉納地の二万五千キュビトに面して東の境界まで延びる土地と、西側の二万五千キュビトに面して西の境界まで延びる土地である。それは各部族の割り当て地に沿って君主のものとなり、聖なる奉納地と宮の聖所はその中央に置かれる。</span>
<span className="v" id="v22" data-v="22"> レビ人の所有地と町の所有地は、君主の土地の中央にある。ユダの境界とベニヤミンの境界との間にある土地が、君主のものとなる。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="ヨシュア記 18:21–28; エゼキエル書 48:1–7; 創世記 35:16–19"> 残りの部族については、東側から西側までが、ベニヤミンの一つの割り当て地となる。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="ヨシュア記 19:1–9; 創世記 29:33; 創世記 49:5–7"> ベニヤミンの境界に接し、東側から西側までが、シメオンの一つの割り当て地となる。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="ヨシュア記 19:17–23; 創世記 30:14–18"> シメオンの境界に接し、東側から西側までが、イッサカルの一つの割り当て地となる。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="ヨシュア記 19:10–16; 創世記 30:19–20"> イッサカルの境界に接し、東側から西側までが、ゼブルンの一つの割り当て地となる。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="ヨシュア記 13:24–28; 創世記 30:10–11"> ゼブルンの境界に接し、東側から西側までが、ガドの一つの割り当て地となる。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="エゼキエル書 47:15; 歴代誌 第二 20:2; エゼキエル書 47:19–20"> ガドの境界に接する南側の境界は、タマルからメリボテ・カデシュの水まで、さらに川に沿って大海までとする。</span>

<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="ヨシュア記 13:1–21; 民数記 34:2; 民数記 34:13"> これが、あなたがたがイスラエルの諸部族に相続地としてくじで分ける土地であり、これらが彼らの割り当て地である」と主なる神は言われる。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="エゼキエル書 48:16; ヨハネの黙示録 21:16; エゼキエル書 48:32–35"> 「町の出口は次のとおりである。北側は、測って四千五百竿とする。</span>
<span className="v" id="v31" data-v="31" data-xref="ヨハネの黙示録 21:12–13; イザヤ書 26:1–2; ヨハネの黙示録 21:21"> 町の門にはイスラエルの諸部族の名を付ける。北側には三つの門がある。ルベンの門が一つ、ユダの門が一つ、レビの門が一つである。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32"> 東側は四千五百竿で、三つの門がある。ヨセフの門が一つ、ベニヤミンの門が一つ、ダンの門が一つである。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33"> 南側は、測って四千五百竿で、三つの門がある。シメオンの門が一つ、イッサカルの門が一つ、ゼブルンの門が一つである。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34"> 西側は四千五百竿で、三つの門がある。ガドの門が一つ、アシェルの門が一つ、ナフタリの門が一つである。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="ヨハネの黙示録 21:3; ゼカリヤ書 2:10; ヨハネの黙示録 22:3"> 町の周囲は一万八千竿となる。その日から、この町は『主はそこにおられる』と呼ばれる。」</span>

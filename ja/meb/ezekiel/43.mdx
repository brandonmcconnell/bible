<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="エゼキエル書 44:1; エゼキエル書 42:15; エゼキエル書 46:1"> その後、彼は私を東を向く門へ連れて行った。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネの黙示録 18:1; エゼキエル書 11:23; イザヤ書 6:3"> 見よ、イスラエルの神の栄光が東の方から来た。その声は大水のとどろきのようであり、地はその栄光に照らされた。</span>
<span className="v" id="v3" data-v="3" data-xref="エゼキエル書 9:5; エゼキエル書 9:1; エレミヤ書 1:10"> その幻の姿は、私が以前に見た幻の姿と同じであった。私が町を滅ぼすために来たときに見た幻のようであり、ケバル川のほとりで見た幻のようであった。私はひれ伏した。</span>
<span className="v" id="v4" data-v="4" data-xref="エゼキエル書 10:18–19; エゼキエル書 44:2; エゼキエル書 43:2"> 主の栄光は、東を向く門を通って宮に入った。</span>
<span className="v" id="v5" data-v="5" data-xref="コリント人への第二の手紙 12:2–4; 列王記第一 8:10–11; エゼキエル書 8:3"> 霊が私を引き上げ、内庭へ連れて行った。見よ、主の栄光が宮に満ちていた。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="エゼキエル書 40:3; イザヤ書 66:6; ヨハネの黙示録 16:1"> 私は宮の中から、だれかが私に語りかける声を聞いた。一人の人が私のそばに立っていた。</span>
<span className="v" id="v7" data-v="7" data-xref="エゼキエル書 43:9; 詩篇 47:8; レビ記 26:30"> その方は私に言われた。「人の子よ、ここはわたしの王座の場所、わたしの足の裏を置く場所であり、わたしがイスラエルの子らの中に永遠に住む所である。イスラエルの家は、彼らもその王たちも、淫行や、彼らの高き所に置いた王たちの死体によって、わたしの聖なる名を二度と汚さない。</span>
<span className="v" id="v8" data-v="8" data-xref="エゼキエル書 5:11; エゼキエル書 8:3–16; 歴代誌 第二 33:7"> 彼らは自分たちの敷居をわたしの敷居のそばに置き、自分たちの戸口の柱をわたしの戸口の柱のそばに置いた。わたしと彼らとの間には壁一枚しかなかった。彼らは行った忌むべきことによって、わたしの聖なる名を汚した。それゆえ、わたしは怒りのうちに彼らを滅ぼし尽くした。</span>
<span className="v" id="v9" data-v="9" data-xref="エゼキエル書 43:7; エゼキエル書 37:26–28; エゼキエル書 18:30–31"> 今、彼らに淫行と王たちの死体をわたしから遠ざけさせよ。そうすれば、わたしは彼らの中に永遠に住む。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="エゼキエル書 40:4; エゼキエル書 16:61; エゼキエル書 16:63"> 人の子よ、イスラエルの家にこの宮を示し、彼らに自分たちの不義を恥じさせ、その設計を測らせよ。</span>
<span className="v" id="v11" data-v="11" data-xref="エゼキエル書 36:27; エゼキエル書 11:20; マタイ 28:20"> 彼らが自分たちの行ったすべてのことを恥じるなら、宮の形、造り、出口、入口、全体の構造、すべての定め、すべての形、すべての律法を彼らに知らせよ。それを彼らの目の前に書き記し、彼らにそのすべての形とすべての定めを守り行わせよ。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="エゼキエル書 40:2; ヨハネの黙示録 21:27; 詩篇 93:5"> これが宮の律法である。山の頂にあるその境界全体は、最も聖なる所となる。見よ、これが宮の律法である。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="エゼキエル書 40:5; 出エジプト記 27:1–8; エゼキエル書 41:8"> 祭壇の寸法はキュビトによる。ここでの一キュビト<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="通常の一キュビトは、人の腕の中指の先からひじまでの長さで、約18インチ、または46センチメートルである。一手幅は約4.3インチ、または11センチメートルである。">a</a></sup>は、通常の一キュビトに一手幅を加えた長さである。祭壇の土台は高さ一キュビト、幅一キュビトで、その縁の周囲には一スパン<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="一スパンは、手を広げたときの親指の先から小指の先までの長さで、約半キュビト、9インチ、または22.8センチメートルである。">b</a></sup>の縁取りがある。これが祭壇の台座である。</span>
<span className="v" id="v14" data-v="14"> 地面の土台から下の縁までは二キュビト、幅は一キュビトである。小さい縁から大きい縁までは四キュビト、幅は一キュビトである。</span>
<span className="v" id="v15" data-v="15" data-xref="出エジプト記 27:2; 詩篇 118:27; レビ記 9:9"> 祭壇の上部は高さ四キュビトで、炉床から上に四本の角が伸びている。</span>
<span className="v" id="v16" data-v="16" data-xref="出エジプト記 27:1; 歴代誌 第二 4:1; 出エジプト記 38:1–2"> 炉床は長さ十二キュビト、幅十二キュビトで、四辺が正方形である。</span>
<span className="v" id="v17" data-v="17" data-xref="出エジプト記 20:26; エゼキエル書 40:6; 出エジプト記 25:25"> 大きい縁は長さ十四キュビト、幅十四キュビトで、四辺が正方形である。その周囲の縁取りは半キュビト、土台は周囲一キュビトである。階段は東を向く。」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="出エジプト記 40:29; ヘブル人への手紙 10:4–12; エゼキエル書 2:1"> 彼は私に言った。「人の子よ、主なる神はこう言われる。『祭壇を造り、その上に焼き尽くすささげ物をささげ、血を振りかける日の、祭壇についての定めは次のとおりである。</span>
<span className="v" id="v19" data-v="19" data-xref="エゼキエル書 40:46; エゼキエル書 44:15; 民数記 16:40"> わたしに近づいて仕える、ツァドクの子孫であるレビ人の祭司たちに、罪のきよめのささげ物として若い雄牛を与えよ』と主なる神は言われる。『</span>
<span className="v" id="v20" data-v="20" data-xref="レビ記 16:19; レビ記 8:15; 出エジプト記 29:12"> あなたはその血を取り、祭壇の四本の角、大きい縁の四隅、周囲の縁取りに塗れ。こうして祭壇を清め、そのために贖罪を行え。</span>
<span className="v" id="v21" data-v="21" data-xref="出エジプト記 29:14; レビ記 4:12; レビ記 8:17"> また、罪のきよめのささげ物の雄牛を取り、聖所の外にある、宮の定められた場所で焼け。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="エゼキエル書 43:25–26; エゼキエル書 43:20; ペテロの手紙第一 1:19"> 二日目には、傷のない雄やぎを罪のきよめのささげ物としてささげよ。雄牛で清めたように、祭壇を清めなければならない。</span>
<span className="v" id="v23" data-v="23" data-xref="出エジプト記 29:1"> 清め終えたなら、傷のない若い雄牛と、群れの中から傷のない雄羊をささげよ。</span>
<span className="v" id="v24" data-v="24" data-xref="レビ記 2:13; マルコ 9:49–50; 民数記 18:19"> それらを主の前に近づけよ。祭司たちはそれらに塩を振りかけ、主への焼き尽くすささげ物としてささげなければならない。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="レビ記 8:33; 出エジプト記 29:35–37; レビ記 8:35"> 七日間、毎日、罪のきよめのささげ物として雄やぎを用意せよ。また、傷のない若い雄牛と、群れの中から傷のない雄羊も用意しなければならない。</span>
<span className="v" id="v26" data-v="26" data-xref="出エジプト記 29:24; レビ記 8:34; 出エジプト記 32:29"> 七日間、彼らは祭壇のために贖罪を行い、それを清めなければならない。こうして祭壇を聖別する。</span>
<span className="v" id="v27" data-v="27" data-xref="レビ記 9:1; エゼキエル書 20:40–41; ペテロの手紙第一 2:5"> その日数を終えたなら、八日目以後、祭司たちはあなたがたの焼き尽くすささげ物と平和のささげ物を祭壇の上にささげる。そうすれば、わたしはあなたがたを受け入れる』と主なる神は言われる。」</span>
</div>
</div>

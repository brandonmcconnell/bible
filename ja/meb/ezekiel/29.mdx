<span className="v" id="v1" data-v="1" data-xref="エゼキエル書 29:17; エゼキエル書 26:1; エゼキエル書 20:1"> 第十年の第十の月、その月の十二日、主の言葉が私に臨んだ。</span>
<span className="v" id="v2" data-v="2" data-xref="エゼキエル書 6:2; エレミヤ書 44:30; エレミヤ書 46:2–16"> 「人の子よ、エジプトの王ファラオに顔を向け、彼とエジプト全土に対して預言せよ。</span>
<span className="v" id="v3" data-v="3" data-xref="エゼキエル書 32:2; イザヤ書 27:1; エレミヤ書 44:30"> こう語れ。『主なる神はこう言われる。<br /><span className="pl pl-1">「エジプトの王ファラオよ、見よ、わたしはあなたに立ち向かう。</span><br /><span className="pl pl-2">自分の川々の中に横たわる大きな怪物よ。</span><br /><span className="pl pl-1">あなたは、『私の川は私のものだ。</span><br /><span className="pl pl-2">私が自分のために造った』と言った。</span></span>
<span className="v" id="v4" data-v="4" data-xref="列王記第二 19:28; エゼキエル書 38:4; アモス書 4:2"> <span className="pl pl-1">わたしはあなたのあごに鉤を掛け、</span><br /><span className="pl pl-2">あなたの川々の魚を、うろこに付着させる。</span><br /><span className="pl pl-1">あなたと、うろこに付着した川々のすべての魚を、</span><br /><span className="pl pl-2">川々の中から引き上げる。</span></span>
<span className="v" id="v5" data-v="5" data-xref="エレミヤ書 34:20; エゼキエル書 32:4–6; エレミヤ書 8:2"> <span className="pl pl-1">わたしはあなたと、あなたの川々のすべての魚を、</span><br /><span className="pl pl-2">荒野に投げ出す。</span><br /><span className="pl pl-1">あなたは野原に倒れ、</span><br /><span className="pl pl-2">集められることも、拾い集められることもない。</span><br /><span className="pl pl-1">わたしはあなたを地の獣と、</span><br /><span className="pl pl-2">空の鳥の餌とする。</span></span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="列王記第二 18:21; イザヤ書 36:6; 出エジプト記 9:14"> エジプトのすべての住民は、わたしが主であることを知る。彼らがイスラエルの家にとって、葦の杖であったからである。</span>
<span className="v" id="v7" data-v="7" data-xref="イザヤ書 36:6; エゼキエル書 17:15–17; エレミヤ書 17:5–6"> 彼らがあなたを手でつかむと、あなたは折れて、彼らの肩をことごとく裂いた。彼らがあなたに寄りかかると、あなたは折れて、彼らの腰をことごとくふらつかせた。」』</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="エゼキエル書 14:17; エゼキエル書 30:10; エゼキエル書 29:19–20"> それゆえ、主なる神はこう言われる。『見よ、わたしはあなたに剣をもたらし、あなたから人と動物を断ち切る。</span>
<span className="v" id="v9" data-v="9" data-xref="エゼキエル書 29:3; 箴言 16:18; エゼキエル書 29:10–12"> エジプトの地は荒れ果てた廃墟となる。そのとき、彼らは、わたしが主であることを知る。<br />彼が、『川は私のものだ。私がそれを造った』と言ったからである。</span>
<span className="v" id="v10" data-v="10" data-xref="エゼキエル書 30:12; エゼキエル書 30:6–9; 出エジプト記 14:2"> それゆえ、見よ、わたしはあなたと、あなたの川々に立ち向かう。セベネの塔からエチオピアの国境に至るまで、エジプトの地を全く荒れ果てた廃墟とする。</span>
<span className="v" id="v11" data-v="11" data-xref="エゼキエル書 32:13; エレミヤ書 43:11–12; エゼキエル書 30:10–13"> 人の足もそこを通らず、動物の足もそこを通らない。そこは四十年間、人の住まない所となる。</span>
<span className="v" id="v12" data-v="12" data-xref="エレミヤ書 46:19; エゼキエル書 30:7; エゼキエル書 30:23"> わたしは、荒れ果てた国々のただ中で、エジプトの地を荒れ果てさせる。その町々は、廃墟となった町々のただ中で、四十年間荒れ果てる。わたしはエジプト人を諸国の間に散らし、国々の中に追い散らす。』</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="エレミヤ書 46:26; イザヤ書 19:22"> 主なる神はこう言われる。『四十年の終わりに、わたしはエジプト人を、散らされた諸民族の中から集める。</span>
<span className="v" id="v14" data-v="14" data-xref="エゼキエル書 30:14; イザヤ書 11:11; エレミヤ書 44:1"> わたしはエジプトの捕囚の民を帰らせ、彼らをその生まれ故郷であるパテロスの地に戻らせる。そこで彼らは弱小の王国となる。</span>
<span className="v" id="v15" data-v="15" data-xref="ゼカリヤ書 10:11; エゼキエル書 30:13; エゼキエル書 17:14"> それは諸王国の中で最も低いものとなり、二度と諸国の上に自らを高く上げることはない。わたしは彼らを小さくし、二度と諸国を支配できないようにする。</span>
<span className="v" id="v16" data-v="16" data-xref="ホセア書 8:13; イザヤ書 20:5; エゼキエル書 29:6–7"> イスラエルの家が彼らを頼ろうとして振り向くとき、彼らは不義を思い起こさせる存在ではなくなり、イスラエルの家の頼みともならない。そのとき、彼らは、わたしが主なる神であることを知る。』」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="エゼキエル書 29:1; エゼキエル書 1:2; エゼキエル書 24:1"> 第二十七年の第一の月、その月の一日、主の言葉が私に臨んだ。</span>
<span className="v" id="v18" data-v="18" data-xref="エレミヤ書 27:6; エレミヤ書 25:9; エゼキエル書 26:7–12"> 「人の子よ、バビロンの王ネブカドネザルは、その軍勢にツロに対する厳しい労役をさせた。すべての頭ははげ、すべての肩はすりむけた。しかし、彼もその軍勢も、ツロに対して行った労役に見合う報酬を、ツロから得られなかった。</span>
<span className="v" id="v19" data-v="19" data-xref="エゼキエル書 30:24–25; エレミヤ書 43:10–13; エゼキエル書 32:11"> それゆえ、主なる神はこう言われる。『見よ、わたしはエジプトの地をバビロンの王ネブカドネザルに与える。彼はその大勢の民を運び去り、その略奪物を奪い、その獲物を取る。それが彼の軍勢への報酬となる。</span>
<span className="v" id="v20" data-v="20" data-xref="エレミヤ書 25:9; イザヤ書 10:6–7; イザヤ書 45:1–3"> 彼らがわたしのために働いたので、わたしは彼の労役への報酬としてエジプトの地を与えた』と主なる神は言われる。」</span>
</div>

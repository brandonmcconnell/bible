<span className="v" id="v2" data-v="2" data-xref="エゼキエル書 29:3; ナホム書 2:11–13; エゼキエル書 27:2"> 「人の子よ、エジプトの王ファラオのために哀歌を唱え、彼に言え。<br /><span className="pl pl-1">『あなたは諸国の若い獅子にたとえられた。</span><br /><span className="pl pl-2">しかし、あなたは海の怪物のようである。</span><br /><span className="pl pl-1">あなたは川々の中で暴れ回り、</span><br /><span className="pl pl-2">足で水をかき乱し、</span><br /><span className="pl pl-2">その川々を濁らせた。</span></span>
<span className="v" id="v3" data-v="3" data-xref="エゼキエル書 12:13; エレミヤ書 16:16; 伝道者の書 9:12"> <span className="pl pl-1">主なる神はこう言われる。</span><br /><span className="pl pl-2">「わたしは多くの民の集まりをもって、</span><br /><span className="pl pl-2">あなたの上に網を広げる。</span><br /><span className="pl pl-2">彼らはわたしの網であなたを引き上げる。</span></span>
<span className="v" id="v4" data-v="4" data-xref="イザヤ書 18:6; エゼキエル書 29:5; エゼキエル書 31:12–13"> <span className="pl pl-1">わたしはあなたを陸に残し、</span><br /><span className="pl pl-2">野原に投げ出す。</span><br /><span className="pl pl-1">空のすべての鳥をあなたの上に住まわせ、</span><br /><span className="pl pl-2">全地の動物をあなたで満腹にさせる。</span></span>
<span className="v" id="v5" data-v="5" data-xref="エゼキエル書 31:12"> <span className="pl pl-1">わたしはあなたの肉を山々の上に置き、</span><br /><span className="pl pl-2">あなたの巨大な体で谷々を満たす。</span></span>
<span className="v" id="v6" data-v="6" data-xref="イザヤ書 34:3; イザヤ書 34:7; ヨハネの黙示録 14:20"> <span className="pl pl-1">あなたが泳ぎ回った地を、あなたの血で潤し、</span><br /><span className="pl pl-2">山々にまで及ばせる。</span><br /><span className="pl pl-2">水路はあなたで満ちる。</span></span>
<span className="v" id="v7" data-v="7" data-xref="マタイ 24:29; ヨエル書 2:31; イザヤ書 13:10"> <span className="pl pl-1">わたしがあなたを消すとき、天を覆い、</span><br /><span className="pl pl-2">その星々を暗くする。</span><br /><span className="pl pl-1">太陽を雲で覆い、</span><br /><span className="pl pl-2">月はその光を放たない。</span></span>
<span className="v" id="v8" data-v="8" data-xref="創世記 1:14; 箴言 20:20"> <span className="pl pl-1">天の光るものをすべて、</span><br /><span className="pl pl-2">あなたの上で暗くし、</span><br /><span className="pl pl-2">あなたの地に闇を置く」と主なる神は言われる。</span></span>
<span className="v" id="v9" data-v="9" data-xref="ヨハネの黙示録 18:10–15; エゼキエル書 30:26; エレミヤ書 25:15–25"> <span className="pl pl-1">「わたしがあなたの滅びを諸国の間、</span><br /><span className="pl pl-2">あなたの知らなかった国々にもたらすとき、</span><br /><span className="pl pl-2">多くの民の心を悩ませる。</span></span>
<span className="v" id="v10" data-v="10" data-xref="エゼキエル書 26:16; エゼキエル書 27:35; 列王記第一 9:8"> <span className="pl pl-1">わたしは多くの民をあなたのことで驚かせる。</span><br /><span className="pl pl-2">わたしが彼らの前で剣を振りかざすとき、</span><br /><span className="pl pl-2">その王たちはあなたのことで非常に恐れる。</span><br /><span className="pl pl-1">あなたが倒れる日、</span><br /><span className="pl pl-2">彼らは絶えず震え、</span><br /><span className="pl pl-1">それぞれ自分の命のために、</span><br /><span className="pl pl-2">おののく。」</span></span>
<span className="v" id="v11" data-v="11" data-xref="エレミヤ書 43:10; エゼキエル書 26:7; エゼキエル書 30:22–25"> <span className="pl pl-1">主なる神はこう言われる。</span><br /><span className="pl pl-2">「バビロンの王の剣が、あなたに臨む。</span></span>
<span className="v" id="v12" data-v="12" data-xref="エゼキエル書 28:7; エゼキエル書 29:19; エゼキエル書 31:11"> <span className="pl pl-1">わたしは勇士たちの剣によって、</span><br /><span className="pl pl-2">あなたの大勢の民を倒す。</span><br /><span className="pl pl-2">彼らは皆、諸国の中で最も残忍な者たちである。</span><br /><span className="pl pl-1">彼らはエジプトの誇りを無にし、</span><br /><span className="pl pl-2">その大勢の民はすべて滅ぼされる。</span></span>
<span className="v" id="v13" data-v="13" data-xref="エゼキエル書 29:11; エゼキエル書 29:8; エゼキエル書 30:12"> <span className="pl pl-1">わたしは豊かな水のほとりから、</span><br /><span className="pl pl-2">そのすべての動物も滅ぼす。</span><br /><span className="pl pl-1">人の足がもはや水をかき乱すことはなく、</span><br /><span className="pl pl-2">動物のひづめも水をかき乱さない。</span></span>
<span className="v" id="v14" data-v="14"> <span className="pl pl-1">そのとき、わたしはその水を澄ませ、</span><br /><span className="pl pl-2">その川々を油のように流れさせる」と、</span><br /><span className="pl pl-2">主なる神は言われる。</span></span>
<span className="v" id="v15" data-v="15" data-xref="エゼキエル書 6:7; 出エジプト記 7:5; 出エジプト記 14:4"> <span className="pl pl-1">「わたしがエジプトの地を荒れ果てた廃墟とし、</span><br /><span className="pl pl-2">かつて満ちていたものをすべて失った地とし、</span><br /><span className="pl pl-1">そこに住むすべての者を打つとき、</span><br /><span className="pl pl-2">彼らは、わたしが主であることを知る。</span></span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="サムエル記第二 1:17; 歴代誌 第二 35:25; エゼキエル書 26:17"> これが人々の唱える哀歌である。諸国の娘たちはこれを唱え、エジプトとその大勢の民のために哀歌を唱える」と主なる神は言われる。』」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="エゼキエル書 32:1; エゼキエル書 33:21; エゼキエル書 1:2"> また、第十二年、その月の十五日、主の言葉が私に臨んだ。</span>
<span className="v" id="v18" data-v="18" data-xref="エゼキエル書 31:14; エゼキエル書 32:2; エレミヤ書 1:10"> 「人の子よ、エジプトの大勢の民のために泣き叫べ。彼女と名高い諸国の娘たちを、穴に下る者たちと共に、地の低い所へ投げ落とせ。</span>
<span className="v" id="v19" data-v="19" data-xref="エゼキエル書 31:18; エゼキエル書 32:29–30; エレミヤ書 9:25–26"> あなたは美しさにおいて、だれより優れているのか。下って行き、割礼を受けていない者たちと共に横たわれ。</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 28:3; エゼキエル書 32:23–26; エゼキエル書 32:29–30"> 彼らは剣で殺された者たちの間に倒れる。エジプトは剣に渡された。その大勢の民すべてと共に、彼女を引き去れ。</span>
<span className="v" id="v21" data-v="21" data-xref="イザヤ書 14:9–10; エゼキエル書 32:27; エゼキエル書 32:19"> 勇士の中の強者たちは、彼とその助け手たちに、よみ<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="よみ（シェオル）は死者の場所である。">a</a></sup>のただ中から語りかける。彼らは下って来た。割礼を受けていない者たちは、剣で殺されて横たわっている。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="エゼキエル書 32:26; エゼキエル書 32:29–30; エゼキエル書 32:24"> アッシリアとその全軍はそこにいる。その墓は彼女の周囲にある。彼らは皆、剣で殺されて倒れた者たちである。</span>
<span className="v" id="v23" data-v="23" data-xref="エゼキエル書 26:20; エゼキエル書 32:24–27; 詩篇 27:13"> その墓は穴の最も深い所に設けられ、その全軍は墓の周囲にいる。彼らは皆、剣で殺されて倒れた者たちで、生ける者の地に恐怖をもたらした。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="エゼキエル書 32:18; エゼキエル書 26:20; エレミヤ書 49:34–39"> エラムと、その大勢の民すべても、その墓の周囲にいる。彼らは皆、剣で殺されて倒れた者たちである。彼らは割礼を受けないまま地の低い所へ下り、生ける者の地に恐怖をもたらした。そして、穴に下る者たちと共に自分たちの恥を負っている。</span>
<span className="v" id="v25" data-v="25" data-xref="詩篇 139:8; 歴代誌上 10:4; サムエル記第二 1:20"> 殺された者たちの間に、エラムとその大勢の民のための寝床が設けられている。その墓は周囲にある。彼らは皆、割礼を受けておらず、剣で殺された者たちである。彼らは生ける者の地に恐怖をもたらしたが、今は穴に下る者たちと共に自分たちの恥を負っている。エラムは殺された者たちの間に置かれている。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="エゼキエル書 27:13; 創世記 10:2; エゼキエル書 38:2–3"> メシェク、トバルと、その大勢の民すべてもそこにいる。その墓は彼らの周囲にある。彼らは皆、割礼を受けておらず、剣で殺された者たちである。彼らは生ける者の地に恐怖をもたらした。</span>
<span className="v" id="v27" data-v="27" data-xref="イザヤ書 14:18–19; ヨブ記 3:13–15; エゼキエル書 32:21"> 彼らは、武器を携えたままよみへ下り、剣を頭の下に置かれた、割礼を受けていない倒れた勇士たちと共に横たわることはない。彼らの不義はその骨の上にある。彼らは生ける者の地で、勇士たちの恐怖であったからである。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="ダニエル書 2:34–35"> しかし、あなたは割礼を受けていない者たちの間で打ち砕かれ、剣で殺された者たちと共に横たわる。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="エレミヤ書 49:7–22; マラキ書 1:3–4; オバデヤ書 1:1–9"> エドム、その王たちとすべての君主もそこにいる。彼らは力を持っていたが、剣で殺された者たちと共に置かれている。彼らは割礼を受けていない者たち、穴に下る者たちと共に横たわる。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="エゼキエル書 38:6; エゼキエル書 39:2; エゼキエル書 28:21"> 北のすべての君主と、シドン人すべてもそこにいる。彼らは殺された者たちと共に下った。彼らはその力によって恐怖をもたらしたが、恥を受けた。彼らは剣で殺された者たちと共に、割礼を受けないまま横たわり、穴に下る者たちと共に自分たちの恥を負っている。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="エゼキエル書 31:16; エゼキエル書 14:22; 哀歌 2:13"> ファラオは彼らを見て、自分の大勢の民すべてについて慰めを得る。ファラオとその全軍は剣で殺された」と主なる神は言われる。</span>
<span className="v" id="v32" data-v="32" data-xref="エゼキエル書 32:27; 創世記 35:5; コリント人への第二の手紙 5:11"> 「わたしは彼の恐怖を生ける者の地に置いた。ファラオとその大勢の民すべては、割礼を受けていない者たちの間で、剣で殺された者たちと共に横たわる」と主なる神は言われる。</span>
</div>

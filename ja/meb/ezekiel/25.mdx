<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 主の言葉が私に臨んだ。</span>
<span className="v" id="v2" data-v="2" data-xref="エレミヤ書 49:1–6; アモス書 1:13–15; エゼキエル書 6:2"> 「人の子よ、アンモンの子らに顔を向け、彼らに対して預言せよ。</span>
<span className="v" id="v3" data-v="3" data-xref="エゼキエル書 36:2; 詩篇 70:2–3; 箴言 17:5"> アンモンの子らに言え。『主なる神の言葉を聞け。主なる神はこう言われる。「わたしの聖所が汚されたとき、イスラエルの地が荒れ果てたとき、ユダの家が捕囚となったとき、あなたはそれらに向かって、『ああ、よい気味だ』と言った。</span>
<span className="v" id="v4" data-v="4" data-xref="申命記 28:33; 士師記 6:33; 列王記第一 4:30"> それゆえ、見よ、わたしはあなたを東方の民に渡して、その所有とする。彼らはあなたの中に陣営を置き、住まいを設ける。彼らはあなたの果実を食べ、あなたの乳を飲む。</span>
<span className="v" id="v5" data-v="5" data-xref="エゼキエル書 21:20; サムエル記第二 12:26; イザヤ書 17:2"> わたしはラバをらくだの放牧場とし、アンモンの子らの地を羊の群れの休み場とする。そのとき、あなたがたは、わたしが主であることを知る。」</span>
<span className="v" id="v6" data-v="6" data-xref="ゼパニヤ書 2:8; オバデヤ書 1:12; ゼパニヤ書 2:10"> 主なる神はこう言われる。「あなたはイスラエルの地に向かって手を打ち、足を踏み鳴らし、心の底から侮って喜んだ。</span>
<span className="v" id="v7" data-v="7" data-xref="ゼパニヤ書 1:4; エゼキエル書 25:16; エゼキエル書 6:14"> それゆえ、見よ、わたしはあなたに向かって手を伸ばし、あなたを諸国の略奪物として渡す。わたしはあなたを諸民族の中から断ち切り、国々の中から消し去り、あなたを滅ぼす。そのとき、あなたは、わたしが主であることを知る。」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="イザヤ書 15:1–9; エレミヤ書 25:21; エレミヤ書 48:1–47"> 主なる神はこう言われる。「モアブとセイルは、『見よ、ユダの家もすべての諸国と同じだ』と言った。</span>
<span className="v" id="v9" data-v="9" data-xref="エレミヤ書 48:23; ヨシュア記 13:17; ヨシュア記 13:19–20"> それゆえ、見よ、わたしはモアブの側面を、その国境にある町々、その地の誉れであるベテ・エシモテ、バアル・メオン、キルヤタイムから開く。</span>
<span className="v" id="v10" data-v="10" data-xref="エゼキエル書 21:32; 詩篇 83:3–6; エゼキエル書 25:4"> わたしはそれを東方の民に開き、彼らをアンモンの子らに攻めかからせる。そして、アンモンの子らを彼らの所有とする。こうして、アンモンの子らは諸国の間で思い起こされなくなる。</span>
<span className="v" id="v11" data-v="11" data-xref="エゼキエル書 35:15; エゼキエル書 30:19; 詩篇 149:7"> わたしはモアブに裁きを行う。そのとき、彼らは、わたしが主であることを知る。」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="エレミヤ書 49:7–22; エゼキエル書 25:8; 詩篇 137:7"> 主なる神はこう言われる。「エドムはユダの家に復讐し、彼らに復讐することによって大きな罪を犯した。」</span>
<span className="v" id="v13" data-v="13" data-xref="エゼキエル書 29:8; マラキ書 1:3–4; エレミヤ書 25:23"> それゆえ、主なる神はこう言われる。「わたしはエドムに向かって手を伸ばし、そこから人と動物を断ち切る。テマンからデダンに至るまで、その地を荒れ果てさせる。彼らは剣に倒れる。</span>
<span className="v" id="v14" data-v="14" data-xref="イザヤ書 11:14; 創世記 27:29; ヘブル人への手紙 10:30–31"> わたしは、わたしの民イスラエルの手によってエドムに復讐する。彼らはわたしの怒りと憤りに従ってエドムを扱う。そのとき、彼らはわたしの復讐を知る」と主なる神は言われる。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="エゼキエル書 25:6; イザヤ書 14:29–31; エゼキエル書 25:12"> 主なる神はこう言われる。「ペリシテ人は復讐を行い、心の底から侮り、絶え間ない敵意をもって復讐し、滅ぼそうとした。」</span>
<span className="v" id="v16" data-v="16" data-xref="サムエル記第一 30:14; ゼパニヤ書 2:4–15; エゼキエル書 25:13"> それゆえ、主なる神はこう言われる。「見よ、わたしはペリシテ人に向かって手を伸ばし、ケレテ人を断ち切り、海辺に残る者を滅ぼす。</span>
<span className="v" id="v17" data-v="17" data-xref="エゼキエル書 25:11; エゼキエル書 25:14; エゼキエル書 5:15"> わたしは怒りに満ちた懲らしめをもって、彼らに大いなる復讐を行う。わたしが彼らに復讐するとき、彼らは、わたしが主であることを知る。」』」</span>
</div>
</div>

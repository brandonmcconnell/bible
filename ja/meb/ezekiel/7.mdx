<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> さらに、主の言葉が私に臨んで言われた。</span>
<span className="v" id="v2" data-v="2" data-xref="アモス書 8:2; ペテロの手紙第一 4:7; エゼキエル書 7:3"> 「人の子よ、主なる神はイスラエルの地にこう言われる。『終わりだ。地の四隅に終わりが来た。</span>
<span className="v" id="v3" data-v="3" data-xref="エゼキエル書 18:30; エゼキエル書 5:13; エゼキエル書 33:20"> 今、終わりがあなたの上に来た。わたしは怒りをあなたに送り、あなたの道に従ってあなたを裁き、あなたのすべての忌むべき行いをあなたの上に報いる。</span>
<span className="v" id="v4" data-v="4" data-xref="エゼキエル書 6:7; エゼキエル書 11:21; エゼキエル書 5:11"> わたしの目はあなたを惜しまず、あわれみをかけない。わたしはあなたの道をあなたの上に報い、あなたの忌むべき行いはあなたの中に現れる。その時、あなたがたは、わたしが主であることを知る。』</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="ナホム書 1:9; 列王記第二 21:12–13; エゼキエル書 5:9"> 主なる神はこう言われる。『災いだ。比類のない災いだ。見よ、それが来る。</span>
<span className="v" id="v6" data-v="6" data-xref="ゼカリヤ書 13:7; エゼキエル書 7:3; ペテロの第二の手紙 2:5"> 終わりが来た。終わりが来た。あなたに向かって目覚めた。見よ、来る。</span>
<span className="v" id="v7" data-v="7" data-xref="エゼキエル書 12:28; エゼキエル書 7:12; イザヤ書 22:5"> 地に住む者よ、あなたの破滅が来た。時が来た。日が近い。それは混乱の日であり、山々で喜び叫ぶ日ではない。</span>
<span className="v" id="v8" data-v="8" data-xref="エゼキエル書 9:8; エゼキエル書 14:19; エゼキエル書 20:8"> 今、わたしは間もなく憤りをあなたの上に注ぎ、怒りをあなたに対して全うする。あなたの道に従ってあなたを裁き、あなたのすべての忌むべき行いをあなたの上に報いる。</span>
<span className="v" id="v9" data-v="9" data-xref="ヨハネの黙示録 20:13; ミカ書 6:9; イザヤ書 9:13"> わたしの目は惜しまず、あわれみをかけない。わたしはあなたの道に従ってあなたに報い、あなたの忌むべき行いはあなたの中に現れる。その時、あなたがたは、主であるわたしが打つことを知る。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="イザヤ書 10:5; ヤコブの手紙 4:6; テサロニケ人への手紙第一 5:3"> 見よ、その日だ。見よ、それが来る。あなたの破滅が現れた。杖は花を咲かせ、高ぶりは芽を出した。</span>
<span className="v" id="v11" data-v="11" data-xref="ゼパニヤ書 1:18; エゼキエル書 7:23; イザヤ書 59:6–8"> 暴虐は、悪の杖へと伸びた。彼らも、その群衆も、その富も、何一つ残らない。その中に尊いものは何もない。</span>
<span className="v" id="v12" data-v="12" data-xref="イザヤ書 5:13–14; コリント人への第一の手紙 7:29–31; エゼキエル書 7:5–7"> 時が来た。日が近づいた。買う者は喜ぶな。売る者は嘆くな。憤りがその全群衆の上に臨むからだ。</span>
<span className="v" id="v13" data-v="13" data-xref="レビ記 25:24–28; レビ記 25:31; ヨブ記 15:25"> 売る者は、たとえ生き長らえても、売ったものに戻ることはない。この幻はその全群衆に及び、覆ることはない。だれも、咎に満ちた自分の生き方によって身を保つことはできない。</span>
<span className="v" id="v14" data-v="14" data-xref="エレミヤ書 4:5; エレミヤ書 7:20; エレミヤ書 51:27"> 人々は角笛を吹き、すべてを整えた。しかし、戦いに出る者は一人もいない。わたしの憤りがその全群衆の上に臨むからだ。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="エレミヤ書 14:18; エゼキエル書 5:12; 哀歌 1:20"> 外には剣があり、内には疫病と飢饉がある。野にいる者は剣で死に、町にいる者は飢饉と疫病に食い尽くされる。</span>
<span className="v" id="v16" data-v="16" data-xref="イザヤ書 59:11; イザヤ書 38:14; エズラ記 9:15"> その中で逃れた者は山々へ逃れ、谷の鳩のようになる。彼らは皆、自分の咎のためにうめく。</span>
<span className="v" id="v17" data-v="17" data-xref="エゼキエル書 21:7; ヘブル人への手紙 12:12; エレミヤ書 6:24"> すべての手は力を失い、すべての膝は水のように力を失う。</span>
<span className="v" id="v18" data-v="18" data-xref="アモス書 8:10; イザヤ書 15:2–3; イザヤ書 3:24"> 彼らは粗布を身にまとい、恐怖が彼らを覆う。すべての顔には恥があり、すべての頭はそり落とされる。</span>
<span className="v" id="v19" data-v="19" data-xref="箴言 11:4; ゼパニヤ書 1:18; ルカ 12:19–20"> 彼らは銀を通りに投げ捨て、金を汚れたものとする。主の憤りの日には、銀も金も彼らを救うことができない。それらは彼らの心を満たすことも、腹を満たすこともできない。それが彼らの咎のつまずきとなったからだ。</span>
<span className="v" id="v20" data-v="20" data-xref="エゼキエル書 24:21; エレミヤ書 7:30; エゼキエル書 8:15–16"> 彼らは美しい飾りを誇りとし、それを用いて忌むべき像と忌まわしいものを造った。それゆえ、わたしはそれを彼らにとって汚れたものとする。</span>
<span className="v" id="v21" data-v="21" data-xref="列王記第二 24:13; 詩篇 74:2–8; 歴代誌 第二 36:18–19"> わたしはそれを異国人の手に獲物として渡し、地の悪しき者たちに略奪物として渡す。彼らはそれを汚す。</span>
<span className="v" id="v22" data-v="22" data-xref="エレミヤ書 18:17; 詩篇 74:18–23; 詩篇 74:10–11"> わたしは彼らから顔を背ける。彼らはわたしの隠れた所を汚す。強盗たちがそこに入り込み、これを汚す。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="エゼキエル書 9:9; エレミヤ書 27:2; エゼキエル書 11:6"> 鎖を作れ。この地は流血の罪に満ち、町は暴虐に満ちているからだ。</span>
<span className="v" id="v24" data-v="24" data-xref="エゼキエル書 28:7; 詩篇 106:41; エゼキエル書 21:31"> それゆえ、わたしは最も悪い国々を連れて来る。彼らはその家々を所有する。わたしは強い者たちの誇りを絶やし、彼らの聖なる場所は汚される。</span>
<span className="v" id="v25" data-v="25" data-xref="エレミヤ書 8:15–16; イザヤ書 57:21; 哀歌 4:17–18"> 滅びが来る。彼らは平和を求めても、それはない。</span>
<span className="v" id="v26" data-v="26" data-xref="エレミヤ書 4:20; エゼキエル書 14:1; ミカ書 3:6"> 災いに災いが重なり、うわさにうわさが続く。彼らは預言者に幻を求める。しかし、律法は祭司から失われ、助言は長老たちから失われる。</span>
<span className="v" id="v27" data-v="27" data-xref="エゼキエル書 18:30; エゼキエル書 7:4–8; エゼキエル書 26:16"> 王は嘆き、君主は荒廃を身にまとい、この地の民の手は震える。わたしは彼らの道に従って彼らを扱い、彼らの裁きに従って彼らを裁く。その時、彼らは、わたしが主であることを知る。』」</span>
</div>

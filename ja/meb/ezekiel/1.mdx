<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マタイ 3:16; エゼキエル書 11:24; 使徒の働き 7:56"> 第三十年、第四の月の五日、私がケバル川のほとりで捕囚の民の中にいた時、天が開かれ、私は神<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「神」と訳されたヘブル語は「אֱלֹהִים」（エロヒム）である。">a</a></sup>の幻を見た。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="列王記第二 24:12–15; エゼキエル書 8:1; エゼキエル書 20:1"> その月の五日、エホヤキン王が捕囚となって第五年に、</span>
<span className="v" id="v3" data-v="3" data-xref="エゼキエル書 3:14; エゼキエル書 3:22; 列王記第二 3:15"> カルデア人の地、ケバル川のほとりで、主<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="すべて大文字の「主」または「神」はヘブル語のיהוה（ヤハウェ）から来ている。ただし、短い形のיה（ヤハ）から来ていると記されている場合を除く。">b</a></sup>の言葉がブジの子である祭司エゼキエルに臨み、そこで主の御手が彼の上にあった。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="エゼキエル書 1:27; エゼキエル書 8:2; エレミヤ書 23:19"> 私が見ると、見よ<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="「見よ」はヘブル語「הִנֵּה」またはギリシア語「ἰδοὺ」に由来し、「見なさい」「注意せよ」「よく見よ」という意味の間投詞である。">c</a></sup>、北から激しい風が吹いて来た。大きな雲があり、火がひらめき、その周囲には輝きがあった。火の中心からは、輝く金属のようなものが見えた。</span>
<span className="v" id="v5" data-v="5" data-xref="ヨハネの黙示録 4:6–8; エゼキエル書 1:26; ヨハネの黙示録 6:6"> その中心から、四つの生き物に似たものが現れた。その姿は人に似ていた。</span>
<span className="v" id="v6" data-v="6" data-xref="エゼキエル書 10:14; ヨハネの黙示録 4:7–8; エゼキエル書 1:15"> それぞれに四つの顔があり、それぞれに四つの翼があった。</span>
<span className="v" id="v7" data-v="7" data-xref="ヨハネの黙示録 1:15; ダニエル書 10:6; 詩篇 104:4"> 足はまっすぐで、足の裏は子牛のひづめの裏のようであり、磨かれた青銅のように輝いていた。</span>
<span className="v" id="v8" data-v="8" data-xref="エゼキエル書 10:21; エゼキエル書 10:11; イザヤ書 6:6"> 四方の翼の下には、人の手があった。四つの生き物の顔と翼は、次のようであった。</span>
<span className="v" id="v9" data-v="9" data-xref="エゼキエル書 10:22; エゼキエル書 10:11; エゼキエル書 1:11–12"> 翼は互いに触れ合っていた。進む時には向きを変えず、それぞれまっすぐ前へ進んだ。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="エゼキエル書 10:14; ヨハネの黙示録 4:7; コリント人への第一の手紙 9:9–10"> 顔の形は、四つとも人の顔を持ち、右側には獅子の顔、左側には牛の顔があり、また四つとも鷲の顔を持っていた。</span>
<span className="v" id="v11" data-v="11" data-xref="イザヤ書 6:2; エゼキエル書 1:23; エゼキエル書 10:19"> その顔はこのようであった。翼は上方に広げられ、それぞれ二つの翼が隣の生き物の翼に触れ、残りの二つで体を覆っていた。</span>
<span className="v" id="v12" data-v="12" data-xref="エゼキエル書 1:9; エゼキエル書 10:22; ヘブル人への手紙 1:14"> それぞれまっすぐ前へ進んだ。霊が行こうとする所へ彼らも行き、進む時に向きを変えなかった。</span>
<span className="v" id="v13" data-v="13" data-xref="ヨハネの黙示録 4:5; 詩篇 104:4; マタイ 28:3"> 生き物の姿は、燃える炭火のようであり、たいまつのように見えた。火が生き物の間を行き巡り、火は明るく、その火から稲妻が出ていた。</span>
<span className="v" id="v14" data-v="14" data-xref="マタイ 24:27; ゼカリヤ書 4:10; マルコ 13:27"> 生き物は、稲妻がひらめくように行き来した。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="ダニエル書 7:9; エゼキエル書 10:9; エゼキエル書 1:19–21"> 私が生き物を見ていると、見よ、四つの生き物のそれぞれのそばに、地の上に一つずつ車輪があった。</span>
<span className="v" id="v16" data-v="16" data-xref="ダニエル書 10:6; エゼキエル書 10:9–11; 出エジプト記 39:13"> 車輪の外観と作りは緑柱石のように輝き、四つとも同じ形をしていた。その外観と作りは、一つの車輪の中に別の車輪があるようであった。</span>
<span className="v" id="v17" data-v="17" data-xref="エゼキエル書 1:9; エゼキエル書 1:12; イザヤ書 55:11"> 進む時には四方のどの方向にも進み、進む時に向きを変えなかった。</span>
<span className="v" id="v18" data-v="18" data-xref="エゼキエル書 10:12; ヨハネの黙示録 4:6; ヨハネの黙示録 4:8"> 車輪の縁は高く、恐ろしいほどであり、四つの車輪の縁には周囲一面に目があった。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="エゼキエル書 10:16; エゼキエル書 10:19; 詩篇 103:20"> 生き物が進むと、車輪もそのそばを進んだ。生き物が地から上がると、車輪も上 霊ががった。</span>
<span className="v" id="v20" data-v="20" data-xref="エゼキエル書 1:12; エゼキエル書 10:17; コリント人への第一の手紙 14:32"> 行こうとする所へ、生き物も進んだ。霊がそこへ行こうとしたからである。車輪も彼らとともに上がった。生き物の霊が車輪の中にあったからである。</span>
<span className="v" id="v21" data-v="21" data-xref="エゼキエル書 10:17; エゼキエル書 1:19–20; ローマ人への手紙 8:2"> 生き物が進むと車輪も進み、生き物が止まると車輪も止まった。生き物が地から上がると、車輪も彼らとともに上がった。生き物の霊が車輪の中にあったからである。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="エゼキエル書 10:1; エゼキエル書 1:26; ヨハネの黙示録 4:6"> 生き物の頭上には、恐ろしいほどに輝く水晶のような大空があり、その頭上高く広がっていた。</span>
<span className="v" id="v23" data-v="23" data-xref="ヨブ記 4:18; エゼキエル書 1:11–12; 詩篇 89:7"> 大空の下で、彼らは翼を互いに向けてまっすぐ伸ばしていた。それぞれ二つの翼で体の一方を覆い、二つの翼で体の他方を覆っていた。</span>
<span className="v" id="v24" data-v="24" data-xref="エゼキエル書 43:2; ダニエル書 10:6; ヨハネの黙示録 1:15"> 彼らが進む時、私はその翼の音を聞いた。それは大水のとどろきのようであり、全能者の声のようであり、軍勢の音のような激しい響きであった。彼らは止まる時、翼を垂れた。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="エゼキエル書 1:22"> 彼らの頭上の大空のさらに上から声がした。彼らは止まる時、翼を垂れた。</span>
<span className="v" id="v26" data-v="26" data-xref="エゼキエル書 10:1; 出エジプト記 24:10; ヨハネの黙示録 1:13"> その頭上の大空の上には、サファイア<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="または「ラピスラズリ」">d</a></sup>のように見える王座に似たものがあった。その王座に似たものの上には、人の姿に似た方が座しておられた。</span>
<span className="v" id="v27" data-v="27" data-xref="エゼキエル書 1:4; エゼキエル書 8:2; ヘブル人への手紙 12:29"> 私が見ると、その腰のように見える所から上は、火に包まれた輝く金属のようであり、腰のように見える所から下は火のようであった。また、その方の周囲には輝きがあった。</span>
<span className="v" id="v28" data-v="28" data-xref="ヨハネの黙示録 10:1; ヨハネの黙示録 4:3; 創世記 17:3"> その周囲の輝きは、雨の日に雲の中に現れる虹のようであった。<br />これが主の栄光に似たものの姿であった。私はそれを見ると、ひれ伏した。そして、語る方の声を聞いた。</span>
</div>

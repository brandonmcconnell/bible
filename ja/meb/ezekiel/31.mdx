<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="エゼキエル書 30:20; エレミヤ書 52:5–6; エゼキエル書 1:2"> 第十一年の第三の月、その月の一日、主の言葉が私に臨んだ。</span>
<span className="v" id="v2" data-v="2" data-xref="エゼキエル書 29:19; エゼキエル書 30:10; エゼキエル書 31:18"> 「人の子よ、エジプトの王ファラオと、その大勢の民に言え。<br /><span className="pl pl-1">『あなたはその偉大さにおいて、</span><br /><span className="pl pl-2">だれに似ているのか。</span></span>
<span className="v" id="v3" data-v="3" data-xref="イザヤ書 10:33–34; ダニエル書 4:10; ダニエル書 4:20–23"> <span className="pl pl-1">見よ、アッシリアはレバノンの杉であった。</span><br /><span className="pl pl-2">美しい枝を持ち、</span><br /><span className="pl pl-1">森のような陰を作り、</span><br /><span className="pl pl-2">丈は高く、</span><br /><span className="pl pl-2">その梢は茂った大枝の間にあった。</span></span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネの黙示録 17:15; 箴言 14:28; エゼキエル書 17:5"> <span className="pl pl-1">水がそれを養い、</span><br /><span className="pl pl-2">深淵がそれを成長させた。</span><br /><span className="pl pl-1">深淵の川々は植えられた場所の周囲を流れ、</span><br /><span className="pl pl-2">その水路を野のすべての木に送った。</span></span>
<span className="v" id="v5" data-v="5" data-xref="ダニエル書 4:11; エゼキエル書 17:5; 詩篇 1:3"> <span className="pl pl-1">それゆえ、その丈は、</span><br /><span className="pl pl-2">野のすべての木よりも高くなった。</span><br /><span className="pl pl-1">その大枝は増え、</span><br /><span className="pl pl-2">豊かな水によって枝は長く伸び広がった。</span></span>
<span className="v" id="v6" data-v="6" data-xref="エゼキエル書 17:23; マタイ 13:32; ダニエル書 4:12"> <span className="pl pl-1">空のすべての鳥が、その大枝に巣を作った。</span><br /><span className="pl pl-2">野のすべての動物が、その枝の下で子を産んだ。</span><br /><span className="pl pl-2">すべての大国が、その陰に住んだ。</span></span>
<span className="v" id="v7" data-v="7"> <span className="pl pl-1">こうして、それはその偉大さと、</span><br /><span className="pl pl-2">枝の長さによって美しかった。</span><br /><span className="pl pl-2">その根は豊かな水のほとりにあった。</span></span>
<span className="v" id="v8" data-v="8" data-xref="エゼキエル書 28:13; 創世記 13:10; イザヤ書 51:3"> <span className="pl pl-1">神の園の杉も、その美しさをかすませることはできなかった。</span><br /><span className="pl pl-2">糸杉もその大枝には及ばず、</span><br /><span className="pl pl-1">松の木もその枝には及ばなかった。</span><br /><span className="pl pl-2">神の園のどの木も、</span><br /><span className="pl pl-2">その美しさには及ばなかった。</span></span>
<span className="v" id="v9" data-v="9" data-xref="エゼキエル書 28:13; ダニエル書 2:37–38; 創世記 13:10"> <span className="pl pl-1">わたしは多くの枝によって、それを美しくした。</span><br /><span className="pl pl-2">そのため、神の園にある、</span><br /><span className="pl pl-2">エデンのすべての木がそれをねたんだ。』</span></span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="エゼキエル書 28:17; ダニエル書 5:20; 歴代誌 第二 32:25"> それゆえ、主なる神はこう言われる。『その丈が高くなり、梢を茂った大枝の間に置き、その高さのために心が高ぶったので、</span>
<span className="v" id="v11" data-v="11" data-xref="エゼキエル書 32:11–12; ナホム書 3:18; ダニエル書 5:18–19"> わたしはそれを諸国の有力者の手に渡す。その者は必ずこれを思いのままに扱う。わたしはその悪のために、これを追い出した。</span>
<span className="v" id="v12" data-v="12" data-xref="エゼキエル書 28:7; エゼキエル書 35:8; エゼキエル書 30:11"> 異国人、諸国の中で最も残忍な者たちがこれを切り倒し、捨て去った。その枝は山々とすべての谷に落ち、その大枝はこの地のすべての水路のそばで折れた。地のすべての民はその陰から出て行き、これを見捨てた。</span>
<span className="v" id="v13" data-v="13" data-xref="エゼキエル書 32:4; エゼキエル書 29:5; イザヤ書 18:6"> 空のすべての鳥は、その倒れた幹の上に住み、野のすべての動物はその枝の上にいる。</span>
<span className="v" id="v14" data-v="14" data-xref="詩篇 63:9–10; ネヘミヤ記 13:18; ペテロの第二の手紙 2:6"> これは、水のほとりにあるどの木も、自分の丈の高さを誇らず、その梢を茂った大枝の間に置かないためである。水を飲むすべての木のうち、力あるものも、その高さに立ち続けることはない。彼らは皆、死に渡され、人の子らの間で、穴に下る者たちと共に地の低い所へ行くからである。』</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="マラキ書 3:4; ナホム書 2:8–10; ヨハネの黙示録 18:9–11"> 主なる神はこう言われる。『それがよみ<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="よみ（シェオル）は死者の場所である。">a</a></sup>に下った日、わたしは喪をもたらした。わたしはそのために深淵を覆い、その川々をせき止めた。大水はとどめられた。わたしはそのためにレバノンを嘆かせ、野のすべての木はそのためにしおれた。</span>
<span className="v" id="v16" data-v="16" data-xref="イザヤ書 14:15; イザヤ書 14:8; エゼキエル書 26:15"> わたしがそれを穴に下る者たちと共によみ<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="よみ（シェオル）は死者の場所である。">b</a></sup>へ投げ落としたとき、その倒れる音によって諸国を震えさせた。エデンのすべての木、レバノンの選り抜きの最良の木、水を飲むすべての木は、地の低い所で慰めを得た。</span>
<span className="v" id="v17" data-v="17" data-xref="詩篇 9:17; エゼキエル書 31:6; エゼキエル書 31:3"> 彼らもまた、それと共によみへ、剣で殺された者たちのもとへ下った。諸国のただ中でその陰に住み、その腕となっていた者たちも同じである。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="エゼキエル書 32:19; エゼキエル書 32:21; エゼキエル書 28:10"> エデンの木々の中で、栄光と偉大さにおいて、あなたはこのようにだれに似ているのか。しかし、あなたはエデンの木々と共に地の低い所へ引き下ろされる。あなたは剣で殺された者たちと共に、割礼を受けていない者たちの間に横たわる。<br />これがファラオと、その大勢の民である』と主なる神は言われる。」</span>
</div>

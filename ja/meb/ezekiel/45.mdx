<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="エゼキエル書 48:29; ゼカリヤ書 14:20–21; 民数記 34:13"> 「あなたがたが相続地として土地をくじで分けるとき、土地の聖なる区画を奉納地として主にささげなければならない。その長さは二万五千竿、幅は一万竿とする。その境界の内側は、周囲すべてが聖なるものとなる。</span>
<span className="v" id="v2" data-v="2" data-xref="エゼキエル書 42:16–20; エゼキエル書 27:28"> このうち、縦五百キュビト、横五百キュビトの正方形を聖所のために取り、その周囲に幅五十キュビト<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一キュビトは、人の腕の中指の先からひじまでの長さで、約18インチ、または46センチメートルである。">a</a></sup>の放牧地を設けなければならない。</span>
<span className="v" id="v3" data-v="3" data-xref="エゼキエル書 48:10"> この区画から、長さ二万五千、幅一万を測らなければならない。その中に最も聖なる聖所を置く。</span>
<span className="v" id="v4" data-v="4" data-xref="エゼキエル書 43:19; 民数記 16:5; エゼキエル書 40:45"> それは土地の聖なる区画であり、聖所で仕え、主に近づいて務めを行う祭司たちのためのものとなる。そこは彼らが家を建てる場所となり、聖所のための聖なる区域となる。</span>
<span className="v" id="v5" data-v="5" data-xref="エゼキエル書 48:13; ネヘミヤ記 10:38–39; エゼキエル書 48:20"> 長さ二万五千キュビト、幅一万キュビトの区画は、宮で仕えるレビ人の所有地となり、二十の部屋を設けるためのものとなる。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="エゼキエル書 48:15–18; エゼキエル書 48:30–35"> 聖なる奉納地に沿って、幅五千キュビト、長さ二万五千キュビトの土地を、町の所有地として定めなければならない。それはイスラエルの家全体のものとなる。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="エゼキエル書 48:21; エゼキエル書 34:24; エゼキエル書 46:16–18"> 君主の所有地は、聖なる奉納地と町の所有地の両側に置く。聖なる奉納地と町の所有地に面して、西側は西へ、東側は東へ延びる。その長さは、西の境界から東の境界まで、部族の割り当て地の一つと同じ長さとする。</span>
<span className="v" id="v8" data-v="8" data-xref="イザヤ書 11:3–5; エゼキエル書 46:18; エゼキエル書 22:27"> それがイスラエルの中で君主の所有地となる。わたしの君主たちは、もはやわたしの民を虐げず、イスラエルの家にその部族ごとの土地を与えなければならない。」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="ゼカリヤ書 8:16; エレミヤ書 22:3; エゼキエル書 44:6"> 主なる神はこう言われる。「イスラエルの君主たちよ、もう十分だ。暴虐と略奪を取り除き、公正と義を行え。わたしの民をその所有地から追い立てるのをやめよ」と主なる神は言われる。</span>
<span className="v" id="v10" data-v="10" data-xref="ミカ書 6:10–11; アモス書 8:4–6; 箴言 16:11"> 「あなたがたは正しいはかり、正しいエパ、<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="一エパは約22リットル、または約3分の2ブッシェルである。">b</a></sup>正しいバテを用いなければならない。</span>
<span className="v" id="v11" data-v="11" data-xref="イザヤ書 5:10"> エパとバテは同じ基準に基づくものとする。一バテは一ホメルの十分の一、一エパも一ホメル<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="一ホメルは約220リットル、または6ブッシェルである。">c</a></sup>の十分の一とし、どちらもホメルを基準とする。</span>
<span className="v" id="v12" data-v="12" data-xref="出エジプト記 30:13; 民数記 3:47; レビ記 27:25"> 一シェケル<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="一シェケルは約10グラム、あるいは約0.35オンスである。">d</a></sup>は二十ゲラとする。<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="一ゲラは約0.5グラム、または約7.7グレーンである。">e</a></sup>二十シェケルと二十五シェケルと十五シェケルを合わせたものを、一ミナとする。<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="一ミナは約600グラム、または約1.3ポンドである。">f</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13"> あなたがたがささげる奉納物は次のとおりである。小麦一ホメルから一エパの六分の一を、また大麦一ホメルから一エパの六分の一をささげる。</span>
<span className="v" id="v14" data-v="14"> 油について定められた分は、一コルから一バテの十分の一である。一コルは十バテ、すなわち一ホメルである。十バテが一ホメルだからである。<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="一コルは容量で一ホメルに等しく、約211リットル、55.9ガロン、または6ブッシェルである。一バテは約21.1リットル、5.59ガロン、または2.4ペックである。">g</a></sup></span>
<span className="v" id="v15" data-v="15" data-xref="レビ記 1:4; レビ記 6:30; コロサイ人への手紙 1:21"> また、イスラエルの水に恵まれた牧草地にいる羊の群れから、二百頭につき子羊一頭をささげる。これは穀物のささげ物、焼き尽くすささげ物、平和のささげ物のためであり、民のために贖罪を行うためである」と主なる神は言われる。</span>
<span className="v" id="v16" data-v="16" data-xref="出エジプト記 30:14–15; イザヤ書 16:1"> 「この地の民は皆、イスラエルの君主のために、この奉納物を納めなければならない。</span>
<span className="v" id="v17" data-v="17" data-xref="エゼキエル書 46:4–12; 歴代誌 第二 31:3; イザヤ書 66:23"> 祭り、新月、安息日、イスラエルの家のすべての定められた祭りに、焼き尽くすささげ物、穀物のささげ物、注ぎのささげ物を用意するのは君主の務めである。彼はイスラエルの家のために贖罪を行うため、罪のきよめのささげ物、穀物のささげ物、焼き尽くすささげ物、平和のささげ物を用意しなければならない。」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="レビ記 16:16; 出エジプト記 12:2; エゼキエル書 43:22"> 主なる神はこう言われる。「第一の月、その月の一日に、傷のない若い雄牛を取り、聖所を清めなければならない。</span>
<span className="v" id="v19" data-v="19" data-xref="エゼキエル書 43:20; エゼキエル書 43:14; レビ記 16:18–20"> 祭司は罪のきよめのささげ物の血を取り、宮の戸口の柱、祭壇の大きい縁の四隅、内庭の門の柱に塗らなければならない。</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 19:12; レビ記 4:27–35; エゼキエル書 45:15"> その月の七日にも、誤って罪を犯した者と、思慮のない者のために、同じように行わなければならない。こうして宮のために贖罪を行う。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="レビ記 23:5–8; コリント人への第一の手紙 5:7–8; 民数記 9:2–14"> 第一の月、その月の十四日に、あなたがたは過越を守る。それは七日間の祭りであり、種なしパンを食べなければならない。</span>
<span className="v" id="v22" data-v="22" data-xref="レビ記 4:14; コリント人への第二の手紙 5:21; マタイ 20:28"> その日、君主は自分自身とこの地のすべての民のために、罪のきよめのささげ物として雄牛一頭を用意しなければならない。</span>
<span className="v" id="v23" data-v="23" data-xref="ヨブ記 42:8; レビ記 23:8; 民数記 23:1–2"> 祭りの七日間、彼は毎日、傷のない雄牛七頭と雄羊七頭を主への焼き尽くすささげ物として用意しなければならない。また、罪のきよめのささげ物として、毎日、雄やぎ一頭を用意しなければならない。</span>
<span className="v" id="v24" data-v="24" data-xref="エゼキエル書 46:5–7; 民数記 28:12–15"> 彼は穀物のささげ物として、雄牛一頭につき一エパ<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="一エパは約22リットル、または約3分の2ブッシェルである。">h</a></sup>、雄羊一頭につき一エパ、また、一エパにつき一ヒン<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="一ヒンは約6.5リットル、または1.7ガロンである。">i</a></sup>の油を用意しなければならない。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="レビ記 23:33–43; 民数記 29:12–38; 歴代誌 第二 5:3"> 第七の月の十五日から始まる祭りの七日間にも、彼は同じように行わなければならない。罪のきよめのささげ物、焼き尽くすささげ物、穀物のささげ物、油を同じように用意しなければならない。」</span>
</div>
</div>

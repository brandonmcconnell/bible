<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 主の言葉が私に臨んだ。</span>
<span className="v" id="v2" data-v="2" data-xref="エレミヤ書 23:1; エレミヤ書 3:15; イザヤ書 40:11"> 「人の子よ、イスラエルの羊飼いたちに対して預言せよ。預言して、その羊飼いたちに言え。『主なる神はこう言われる。「自分自身を養うイスラエルの羊飼いたちに災いあれ。羊飼いは羊を養うべきではないか。</span>
<span className="v" id="v3" data-v="3" data-xref="ゼカリヤ書 11:16; エレミヤ書 2:30; エゼキエル書 33:25–26"> あなたがたは脂肪を食べ、羊毛を身にまとい、肥えたものを殺す。しかし、羊を養わない。</span>
<span className="v" id="v4" data-v="4" data-xref="マタイ 18:12–13; マタイ 9:36; エゼキエル書 34:16"> 弱ったものを強めず、病んだものを癒やさず、傷ついたものを包まず、追いやられたものを連れ戻さず、失われたものを捜さなかった。かえって、力と厳しさをもって彼らを支配した。</span>
<span className="v" id="v5" data-v="5" data-xref="マタイ 9:36; 歴代誌 第二 18:16; エレミヤ書 23:2"> 羊飼いがいなかったので、羊は散らされた。彼らは野のすべての動物の餌となり、散らされた。</span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 142:4; ペテロの手紙第一 2:25; ヨハネ 10:16"> わたしの羊は、すべての山と、すべての高い丘をさまよった。わたしの羊は全地の表に散らされたが、捜す者も、探し求める者もいなかった。」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="エレミヤ書 22:2–3; ミカ書 3:8–9; 詩篇 82:1–7"> それゆえ、羊飼いたちよ、主の言葉を聞け。</span>
<span className="v" id="v8" data-v="8" data-xref="ペテロの第二の手紙 2:13; 使徒の働き 20:33; エゼキエル書 34:5–6"> 「わたしは生きている」と主なる神は言われる。「羊飼いがいなかったために、わたしの羊は獲物となり、野のすべての動物の餌となった。わたしの羊飼いたちは、わたしの羊を捜さず、自分自身を養い、わたしの羊を養わなかった。」</span>
<span className="v" id="v9" data-v="9"> それゆえ、羊飼いたちよ、主の言葉を聞け。</span>
<span className="v" id="v10" data-v="10" data-xref="エゼキエル書 34:2; ゼカリヤ書 10:3; エゼキエル書 13:8"> 主なる神はこう言われる。「見よ、わたしは羊飼いたちに立ち向かう。わたしは彼らの手にわたしの羊の責任を問い、彼らに羊を養うことをやめさせる。羊飼いたちは、もはや自分自身を養うことはない。わたしは羊を彼らの口から救い出し、彼らの餌とならないようにする。」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="ヨハネ 10:16; ルカ 19:10; エレミヤ書 23:3"> 主なる神はこう言われる。「見よ、わたし自身が、わたしの羊を捜し、探し求める。</span>
<span className="v" id="v12" data-v="12" data-xref="イザヤ書 40:11; ヨハネ 10:11–12; ルカ 19:10"> 羊飼いが、散らされた羊の中にいる日に自分の群れを捜し出すように、わたしも自分の羊を捜し出す。雲と深い闇の日に散らされたすべての場所から、彼らを救い出す。</span>
<span className="v" id="v13" data-v="13" data-xref="エゼキエル書 28:25–26; エゼキエル書 11:17; イザヤ書 11:11–16"> わたしは彼らを諸民族の中から連れ出し、国々から集め、自分たちの地へ導き入れる。イスラエルの山々、水路のそば、この地の人の住むすべての所で彼らを養う。</span>
<span className="v" id="v14" data-v="14" data-xref="ヨハネ 10:9; エレミヤ書 31:25; 詩篇 31:8–10"> 良い牧草地で彼らを養い、イスラエルの高い山々に彼らの囲いを置く。彼らはそこで良い囲いの中に伏し、イスラエルの山々の豊かな牧草地で養われる。</span>
<span className="v" id="v15" data-v="15" data-xref="エレミヤ書 3:15; 詩篇 23:1–2; ヨハネ 21:15"> わたし自身が、わたしの羊の羊飼いとなり、彼らを伏させる」と主なる神は言われる。</span>
<span className="v" id="v16" data-v="16" data-xref="ルカ 19:10; エゼキエル書 34:4; エゼキエル書 34:11"> 「わたしは失われたものを捜し、追いやられたものを連れ戻し、傷ついたものを包み、病んだものを強める。しかし、肥えたものと強いものを滅ぼす。わたしは公正をもって彼らを養う。」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="エゼキエル書 34:20–22; マタイ 25:32–33; ゼカリヤ書 10:3"> わたしの群れよ、あなたがたについて主なる神はこう言われる。「見よ、わたしは羊と羊の間、雄羊と雄やぎの間を裁く。</span>
<span className="v" id="v18" data-v="18" data-xref="マタイ 23:13; ルカ 11:52; 民数記 16:13"> 良い牧草地で草を食べたうえに、残った牧草を足で踏みつけるのは、あなたがたにとって小さなことなのか。澄んだ水を飲んだうえに、残った水を足で濁らせなければならないのか。</span>
<span className="v" id="v19" data-v="19"> わたしの羊は、あなたがたが足で踏みつけたものを食べ、あなたがたが足で濁らせたものを飲んでいる。」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="マタイ 25:31–46; エゼキエル書 34:10; 詩篇 22:12–16"> それゆえ、主なる神は彼らにこう言われる。「見よ、わたし自身が、肥えた羊と痩せた羊との間を裁く。</span>
<span className="v" id="v21" data-v="21" data-xref="ゼカリヤ書 11:5; 申命記 33:17; ルカ 13:14–16"> あなたがたは脇腹と肩で押し、角で弱ったものを突いて、ついには彼らを外へ散らした。</span>
<span className="v" id="v22" data-v="22" data-xref="エレミヤ書 23:2–3; 詩篇 72:12–14; エゼキエル書 34:10"> それゆえ、わたしは自分の群れを救う。彼らはもはや獲物とはならない。わたしは羊と羊との間を裁く。</span>
<span className="v" id="v23" data-v="23" data-xref="エゼキエル書 37:24–25; エレミヤ書 30:9; イザヤ書 40:11"> わたしは彼らの上に一人の羊飼い、わたしのしもべダビデを立てる。彼は彼らを養う。彼が彼らを養い、彼らの羊飼いとなる。</span>
<span className="v" id="v24" data-v="24" data-xref="エレミヤ書 31:33; エゼキエル書 36:28; エレミヤ書 23:5–6"> 主であるわたしが彼らの神となり、わたしのしもべダビデが彼らの中で君主となる。主であるわたしが語った。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="イザヤ書 11:6–9; エゼキエル書 37:26; レビ記 26:6"> わたしは彼らと平和の契約を結び、凶暴な獣をこの地から絶やす。彼らは荒野に安心して住み、森の中で眠る。</span>
<span className="v" id="v26" data-v="26" data-xref="申命記 28:12; イザヤ書 44:3; レビ記 26:4"> わたしは彼らと、わたしの丘の周囲の地を祝福とする。季節に応じて雨を降らせる。それは祝福の雨となる。</span>
<span className="v" id="v27" data-v="27" data-xref="エレミヤ書 30:8; レビ記 26:4; レビ記 26:13"> 野の木は実を結び、地は産物を生じる。彼らは自分たちの地に安心して住む。わたしが彼らのくびきの横木を折り、彼らを奴隷にした者たちの手から救い出すとき、彼らは、わたしが主であることを知る。</span>
<span className="v" id="v28" data-v="28" data-xref="エレミヤ書 46:27; エレミヤ書 30:10; エゼキエル書 39:26"> 彼らはもはや諸国の獲物とならず、地の動物に食い尽くされることもない。彼らは安心して住み、だれも彼らを恐れさせない。</span>
<span className="v" id="v29" data-v="29" data-xref="エゼキエル書 36:29; イザヤ書 4:2; エゼキエル書 34:26–27"> わたしは彼らのために名高い植え場を設ける。彼らはもはやこの地で飢饉に食い尽くされず、諸国からの辱めを受けることもない。</span>
<span className="v" id="v30" data-v="30" data-xref="エゼキエル書 37:27; エゼキエル書 34:24; 詩篇 46:11"> 彼らは、主であるわたし、彼らの神が彼らと共におり、彼ら、イスラエルの家がわたしの民であることを知る」と主なる神は言われる。</span>
<span className="v" id="v31" data-v="31" data-xref="詩篇 100:3; ヨハネ 10:16; 詩篇 78:52"> 「あなたがたはわたしの羊、わたしの牧草地の羊である。あなたがたは人であり、わたしはあなたがたの神である」と主なる神は言われる。』」</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="エゼキエル書 8:1; エゼキエル書 30:20; エゼキエル書 24:1"> 第七年の第五の月、その月の十日、イスラエルの長老たちの何人かが主に尋ねるために来て、私の前に座った。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2"> 主の言葉が私に臨んだ。</span>
<span className="v" id="v3" data-v="3" data-xref="箴言 28:9; マタイ 15:8–9; 詩篇 50:15–21"> 「人の子よ、イスラエルの長老たちに語り、彼らに言え。『主なる神はこう言われる。「あなたがたは、わたしに尋ねるために来たのか。わたしは生きている」と主なる神は言われる。「わたしはあなたがたの問いに答えない。」』</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="エゼキエル書 22:2; エゼキエル書 23:36; エゼキエル書 14:20"> 人の子よ、あなたは彼らを裁くのか。彼らを裁くのか。彼らの先祖たちの忌むべき行いを思い知らせよ。</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 7:6; エゼキエル書 20:15; 出エジプト記 3:8"> 彼らに言え。『主なる神はこう言われる。「わたしがイスラエルを選び、ヤコブの家の子孫に誓い、エジプトの地で彼らに自分を知らせた日、わたしは彼らに誓って、『わたしは主、あなたがたの神である』と言った。</span>
<span className="v" id="v6" data-v="6" data-xref="出エジプト記 3:8; エレミヤ書 32:22; エゼキエル書 20:15"> その日、わたしは彼らをエジプトの地から導き出し、彼らのために探し出しておいた地、すなわち、乳と蜜の流れる、あらゆる地の誉れである地へ導き入れると誓った。</span>
<span className="v" id="v7" data-v="7" data-xref="レビ記 18:3; エゼキエル書 20:8; レビ記 11:44"> わたしは彼らに言った。『それぞれ、自分の目が慕う忌むべきものを投げ捨てよ。エジプトの偶像で自分を汚してはならない。わたしは主、あなたがたの神である。』</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="エゼキエル書 20:7; イザヤ書 63:10; エゼキエル書 20:21"> しかし、彼らはわたしに反逆し、わたしの言うことを聞こうとしなかった。だれも、自分の目が慕う忌むべきものを投げ捨てず、エジプトの偶像を捨てなかった。そこでわたしは、エジプトの地のただ中で彼らの上に憤りを注ぎ、彼らに対する怒りを全うすると言った。</span>
<span className="v" id="v9" data-v="9" data-xref="エゼキエル書 39:7; エゼキエル書 20:22; 出エジプト記 32:12"> しかし、わたしは自分の名のために行動し、その名が、彼らの住んでいた諸国の民の目の前で汚されないようにした。わたしはその民の目の前で、彼らをエジプトの地から導き出すことによって、自分を彼らに知らせたからである。</span>
<span className="v" id="v10" data-v="10" data-xref="出エジプト記 15:22; 出エジプト記 13:17–18; 出エジプト記 14:17–22"> こうして、わたしは彼らをエジプトの地から出し、荒野へ導いた。</span>
<span className="v" id="v11" data-v="11" data-xref="ローマ人への手紙 10:5; レビ記 18:5; 申命記 4:8"> わたしは彼らにわたしの掟を与え、わたしの定めを示した。人はそれらを行うなら、それによって生きる。</span>
<span className="v" id="v12" data-v="12" data-xref="エゼキエル書 20:20; エゼキエル書 37:28; レビ記 21:23"> また、わたしと彼らとの間のしるしとして、わたしの安息日をも彼らに与えた。それは、彼らを聖別する者が主であるわたしだと、彼らが知るためであった。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="エゼキエル書 20:21; エゼキエル書 20:8; イザヤ書 56:6"> しかし、イスラエルの家は荒野でわたしに反逆した。彼らはわたしの掟に従って歩まず、わたしの定めを退けた。人はそれらを守るなら、それによって生きる。それなのに、彼らはわたしの安息日を甚だしく汚した。そこでわたしは、荒野で彼らの上に憤りを注ぎ、彼らを滅ぼすと言った。</span>
<span className="v" id="v14" data-v="14" data-xref="エゼキエル書 20:9; エゼキエル書 36:22–23; エゼキエル書 20:22"> しかし、わたしは自分の名のために行動し、その名が、わたしが彼らを導き出したのを見ていた諸国の民の目の前で汚されないようにした。</span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 95:11; 詩篇 106:26; ヘブル人への手紙 3:18"> また、わたしは荒野で彼らに誓い、わたしが彼らに与えた地、すなわち、乳と蜜の流れる、あらゆる地の誉れである地へ彼らを導き入れないと言った。</span>
<span className="v" id="v16" data-v="16" data-xref="民数記 15:39; エゼキエル書 20:8; エゼキエル書 14:3–4"> それは、彼らがわたしの定めを退け、わたしの掟に従って歩まず、わたしの安息日を汚したからである。彼らの心は偶像を追い求めた。</span>
<span className="v" id="v17" data-v="17" data-xref="エゼキエル書 11:13; エレミヤ書 4:27; エレミヤ書 5:18"> それでも、わたしの目は彼らを惜しみ、彼らを滅ぼさなかった。荒野で彼らを全滅させることはしなかった。</span>
<span className="v" id="v18" data-v="18" data-xref="ゼカリヤ書 1:2–4; 詩篇 78:6–8; ペテロの手紙第一 1:18"> わたしは荒野で彼らの子どもたちに言った。『先祖たちの掟に従って歩んではならない。彼らの定めを守ってはならず、彼らの偶像によって自分を汚してはならない。</span>
<span className="v" id="v19" data-v="19" data-xref="エゼキエル書 36:27; 申命記 5:32–8; エゼキエル書 37:24"> わたしは主、あなたがたの神である。わたしの掟に従って歩み、わたしの定めを守り、それを行え。</span>
<span className="v" id="v20" data-v="20" data-xref="イザヤ書 58:13; エレミヤ書 17:22; 出エジプト記 31:13–17"> わたしの安息日を聖なるものとせよ。それは、わたしとあなたがたとの間のしるしとなり、わたしが主、あなたがたの神であることを、あなたがたが知るためである。』</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="エゼキエル書 20:13; 民数記 21:5; エゼキエル書 20:8"> しかし、その子どもたちもわたしに反逆した。彼らはわたしの掟に従って歩まず、わたしの定めを守り行わなかった。人はそれらを行うなら、それによって生きる。それなのに、彼らはわたしの安息日を汚した。そこでわたしは、荒野で彼らの上に憤りを注ぎ、彼らに対する怒りを全うすると言った。</span>
<span className="v" id="v22" data-v="22" data-xref="エゼキエル書 20:14; エゼキエル書 20:9; エレミヤ書 14:21"> それでも、わたしは手を引き、自分の名のために行動した。その名が、わたしが彼らを導き出したのを見ていた諸国の民の目の前で汚されないようにするためであった。</span>
<span className="v" id="v23" data-v="23" data-xref="レビ記 26:33; 申命記 28:64–68; 申命記 32:26–27"> また、わたしは荒野で彼らに誓い、彼らを諸国の間に散らし、国々の中に追い散らすと言った。</span>
<span className="v" id="v24" data-v="24" data-xref="エゼキエル書 20:16; エゼキエル書 6:9; アモス書 2:4"> それは、彼らがわたしの定めを行わず、わたしの掟を退け、わたしの安息日を汚し、その目が先祖たちの偶像を追い求めたからである。</span>
<span className="v" id="v25" data-v="25" data-xref="詩篇 81:12; イザヤ書 66:4; エゼキエル書 20:39"> また、わたしは彼らに良くない掟と、それによって生きることのできない定めを与えた。</span>
<span className="v" id="v26" data-v="26" data-xref="エゼキエル書 6:7; レビ記 18:21; エゼキエル書 20:31"> 彼らが初めに胎を開く子をすべて火の中に通らせたので、わたしは彼らの供え物によって彼らを汚れた者とした。それは彼らを荒れ果てさせ、わたしが主であることを彼らに知らせるためであった。」』</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="ローマ人への手紙 2:24; エゼキエル書 2:7; エゼキエル書 3:11"> それゆえ、人の子よ、イスラエルの家に語り、彼らに言え。『主なる神はこう言われる。「さらに、あなたがたの先祖はこのことにおいても、わたしに背いて冒瀆した。</span>
<span className="v" id="v28" data-v="28" data-xref="エゼキエル書 6:13; ネヘミヤ記 9:22–26; エレミヤ書 3:6"> わたしが与えると誓った地へ彼らを導き入れたとき、彼らはすべての高い丘と、葉の茂ったすべての木を見て、そこでいけにえをささげ、わたしを怒らせる供え物をささげた。そこで芳しい香りをたき、注ぎのささげ物を注いだ。</span>
<span className="v" id="v29" data-v="29" data-xref="エゼキエル書 16:24–25; エゼキエル書 16:31"> そこで、わたしは彼らに、『あなたがたが行くその高き所は何なのか』と言った。それゆえ、その名は今日までバマ<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「バマ」は「高き所」を意味する。">a</a></sup>と呼ばれている。」』</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="エレミヤ書 16:12; エレミヤ書 7:26; 士師記 2:19"> それゆえ、イスラエルの家に言え。『主なる神はこう言われる。「あなたがたは先祖たちの道にならって自分を汚すのか。彼らの忌むべきものを慕って淫行を行うのか。</span>
<span className="v" id="v31" data-v="31" data-xref="エゼキエル書 20:26; 詩篇 106:37–39; エレミヤ書 7:31"> あなたがたは供え物をささげ、息子たちを火の中に通らせるとき、今日に至るまで、すべての偶像によって自分を汚している。イスラエルの家よ、わたしがあなたがたの問いに答えるべきだろうか。わたしは生きている」と主なる神は言われる。「わたしはあなたがたの問いに答えない。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="エゼキエル書 11:5; エレミヤ書 44:17; 詩篇 139:2"> あなたがたが、『われわれは諸国の民や国々の諸部族のようになり、木や石に仕えよう』と言っているが、あなたがたの心に浮かんでいる考えは、決して実現しない。</span>
<span className="v" id="v33" data-v="33" data-xref="エレミヤ書 21:5; エゼキエル書 8:18; エレミヤ書 44:6"> わたしは生きている」と主なる神は言われる。「わたしは必ず、力強い手と伸ばした腕と、注ぎ出される憤りをもって、あなたがたの王となる。</span>
<span className="v" id="v34" data-v="34" data-xref="エゼキエル書 20:38; アモス書 9:9–10; エゼキエル書 34:16"> わたしは力強い手と伸ばした腕と、注ぎ出される憤りをもって、あなたがたを諸民族の中から連れ出し、散らされた国々から集める。</span>
<span className="v" id="v35" data-v="35" data-xref="ホセア書 2:14; エレミヤ書 2:35; エゼキエル書 17:20"> あなたがたを諸民族の荒野へ連れて行き、そこで顔と顔を合わせて、あなたがたを裁く。</span>
<span className="v" id="v36" data-v="36" data-xref="コリント人への第一の手紙 10:5–10; 民数記 11:1–35; エゼキエル書 20:13"> エジプトの地の荒野で、わたしがあなたがたの先祖を裁いたように、あなたがたを裁く」と主なる神は言われる。</span>
<span className="v" id="v37" data-v="37" data-xref="エレミヤ書 33:13; レビ記 27:32; マタイ 25:32–33"> 「わたしはあなたがたを杖の下に通らせ、契約の絆に入れる。</span>
<span className="v" id="v38" data-v="38" data-xref="エゼキエル書 13:9; アモス書 9:9–10; 詩篇 95:11"> あなたがたの中から、反逆する者とわたしに背く者を除き去る。彼らを住んでいる地から連れ出すが、彼らはイスラエルの地に入ることができない。そのとき、あなたがたは、わたしが主であることを知る。」』</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="ホセア書 4:17; イザヤ書 1:13–15; エゼキエル書 43:7"> 「イスラエルの家よ、あなたがたについて主なる神はこう言われる。『行け。それぞれ自分の偶像に仕えよ。今後もわたしの言うことを聞こうとしないなら、そうするがよい。しかし、あなたがたの供え物と偶像によって、わたしの聖なる名を二度と汚してはならない。</span>
<span className="v" id="v40" data-v="40" data-xref="イザヤ書 56:7; マラキ書 3:4; イザヤ書 60:7"> わたしの聖なる山、イスラエルの高い山で」と主なる神は言われる。「そこでは、その地にいるイスラエルの全家、そのすべての者がわたしに仕える。そこでわたしは彼らを受け入れ、あなたがたの奉納物と、供え物の初物と、すべての聖なるものを求める。</span>
<span className="v" id="v41" data-v="41" data-xref="エゼキエル書 28:25; エゼキエル書 11:17; エゼキエル書 38:23"> わたしがあなたがたを諸民族の中から連れ出し、散らされていた国々から集めるとき、芳しい香りとしてあなたがたを受け入れる。あなたがたを通して、諸国の民の目の前で、わたしが聖なる者であることを示す。</span>
<span className="v" id="v42" data-v="42" data-xref="エゼキエル書 34:13; エゼキエル書 38:23; エゼキエル書 36:23–24"> わたしがあなたがたをイスラエルの地、すなわち、あなたがたの先祖に与えると誓った地へ導き入れるとき、あなたがたは、わたしが主であることを知る。</span>
<span className="v" id="v43" data-v="43" data-xref="エゼキエル書 6:9; ホセア書 5:15; エレミヤ書 31:18"> そこで、あなたがたは自分の歩みと、自分を汚したすべての行いを思い出す。そして、自分が行ったすべての悪のために、自分自身を忌み嫌う。</span>
<span className="v" id="v44" data-v="44" data-xref="エゼキエル書 24:24; 詩篇 115:1; エゼキエル書 20:9"> イスラエルの家よ、わたしがあなたがたの悪い道にも、腐敗した行いにも従わず、わたしの名のためにあなたがたを扱うとき、あなたがたは、わたしが主であることを知る」と主なる神は言われる。』」</span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45"> 主の言葉が私に臨んだ。</span>
<span className="v" id="v46" data-v="46" data-xref="アモス書 7:16; エゼキエル書 21:2; エレミヤ書 13:19"> 「人の子よ、南に顔を向け、南に向かって語り、南の野の森に向かって預言せよ。</span>
<span className="v" id="v47" data-v="47" data-xref="エレミヤ書 21:14; イザヤ書 24:1–6; エゼキエル書 17:24"> 南の森に言え。『主の言葉を聞け。主なる神はこう言われる。「見よ、わたしはあなたの中に火をつける。その火は、あなたの中のすべての青々とした木と、すべての枯れた木を焼き尽くす。燃え上がる炎は消されず、南から北まで、すべての顔がそれによって焼かれる。</span>
<span className="v" id="v48" data-v="48" data-xref="エレミヤ書 40:2–3; エレミヤ書 7:20; 申命記 29:24–28"> すべての肉なる者は、主であるわたしが火をつけたことを見る。その火は消されない。」』」</span>
</div>
<div className="bp">
<span className="v" id="v49" data-v="49" data-xref="ヨハネ 16:25; 使徒の働き 17:18; エゼキエル書 17:2"> そこで私は言った。「ああ、主なる神よ。人々は私について、『彼はたとえばかり語る者ではないか』と言っています。」</span>
</div>

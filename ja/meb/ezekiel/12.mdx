<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 主の言葉がまた私に臨んだ。</span>
<span className="v" id="v2" data-v="2" data-xref="マルコ 4:12; エレミヤ書 5:21; 詩篇 78:40"> 「人の子よ、あなたは反逆の家のただ中に住んでいる。彼らには見る目があるのに見ず、聞く耳があるのに聞かない。彼らは反逆の家だからである。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="エレミヤ書 36:3; テモテへの第二の手紙 2:25; エレミヤ書 26:3"> それゆえ、人の子よ、捕囚に赴く者の荷物を用意し、彼らの目の前で、昼のうちに移れ。彼らの目の前で、自分の場所から別の場所へ移れ。彼らは反逆の家だが、もしかすると気づくかもしれない。</span>
<span className="v" id="v4" data-v="4" data-xref="エレミヤ書 39:4; エゼキエル書 12:12; 列王記第二 25:4"> 昼のうちに、彼らの目の前で、捕囚に赴く者の荷物として自分の荷物を運び出せ。そして夕方、捕囚へ出て行く者のように、彼らの目の前で自ら出て行け。</span>
<span className="v" id="v5" data-v="5" data-xref="列王記第二 25:4; エレミヤ書 39:2–4"> 彼らの目の前で壁を掘って穴を開け、そこから荷物を運び出せ。</span>
<span className="v" id="v6" data-v="6" data-xref="エゼキエル書 4:3; イザヤ書 8:18; エゼキエル書 24:24"> 彼らの目の前で荷物を肩に担ぎ、暗闇の中で運び出せ。地が見えないように顔を覆え。わたしはあなたをイスラエルの家へのしるしとしたからである。」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="エゼキエル書 24:18; エゼキエル書 37:10; エゼキエル書 37:7"> 私は命じられたとおりに行った。昼のうちに、捕囚に赴く者の荷物として自分の荷物を運び出し、夕方には手で壁を掘って穴を開けた。暗闇の中で荷物を運び出し、彼らの目の前で肩に担いだ。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8"> 朝になって、主の言葉が私に臨んだ。</span>
<span className="v" id="v9" data-v="9" data-xref="エゼキエル書 24:19; エゼキエル書 17:12; エゼキエル書 20:49"> 「人の子よ、反逆の家であるイスラエルの家は、あなたに『何をしているのか』と尋ねなかったか。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="列王記第二 9:25; イザヤ書 13:1; エレミヤ書 24:8"> 彼らに言え。『主なる神はこう言われる。「この宣告は、エルサレムにいる君主と、その中にいるイスラエルの全家に関するものである。」』</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="エレミヤ書 52:15; エレミヤ書 15:2; エレミヤ書 52:28–30"> また言え。『私はあなたがたへのしるしである。私が行ったとおりのことが彼らに行われる。彼らは捕囚となって連れ去られる。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="列王記第二 25:4; エレミヤ書 39:4; エゼキエル書 12:6"> 彼らの中にいる君主は、暗闇の中で荷物を肩に担いで出て行く。人々は壁に穴を掘り、そこから荷物を運び出す。彼は自分の目で地を見ることがないように、顔を覆う。</span>
<span className="v" id="v13" data-v="13" data-xref="エレミヤ書 39:7; ホセア書 7:12; エゼキエル書 17:20"> わたしは彼の上に網を広げ、彼はわたしのわなに捕らえられる。わたしは彼をカルデア人の地、バビロンへ連れて行く。しかし、彼はそこを見ないまま、そこで死ぬ。</span>
<span className="v" id="v14" data-v="14" data-xref="エゼキエル書 5:2; 列王記第二 25:4–5; エゼキエル書 17:21"> わたしは、彼の周りにいるすべての助け手と、そのすべての部隊を四方の風に散らし、その後から剣を抜く。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="エゼキエル書 6:7; エゼキエル書 12:16; エゼキエル書 12:20"> わたしが彼らを諸国の中に追い散らし、国々の中に散らすとき、彼らは、わたしが主であることを知る。</span>
<span className="v" id="v16" data-v="16" data-xref="エレミヤ書 22:8–9; エゼキエル書 14:22–23; エゼキエル書 6:8–10"> しかし、わたしは彼らのうち少数の者を、剣と飢饉と疫病から生き残らせる。それは、彼らが行く諸国で、自分たちのすべての忌むべき行いを語り明かすためである。そのとき、彼らは、わたしが主であることを知る。』」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17"> さらに、主の言葉が私に臨んだ。</span>
<span className="v" id="v18" data-v="18" data-xref="哀歌 5:9; 詩篇 80:5; ヨブ記 3:24"> 「人の子よ、震えながらパンを食べ、おののきと不安のうちに水を飲め。</span>
<span className="v" id="v19" data-v="19" data-xref="ゼカリヤ書 7:14; エゼキエル書 6:6–7; エゼキエル書 6:14"> この地の民に言え。『主なる神は、エルサレムの住民とイスラエルの地についてこう言われる。「彼らは恐れながらパンを食べ、おびえながら水を飲む。その地は、その中にあるすべてのものを失い、そこに住むすべての者の暴虐のために荒れ果てる。</span>
<span className="v" id="v20" data-v="20" data-xref="エレミヤ書 4:7; イザヤ書 7:23–24; エレミヤ書 25:9"> 人の住む町々は荒れ果て、その地は荒廃する。そのとき、あなたがたは、わたしが主であることを知る。」』」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21"> 主の言葉が私に臨んだ。</span>
<span className="v" id="v22" data-v="22" data-xref="エゼキエル書 18:2–3; エゼキエル書 11:3; エゼキエル書 12:27"> 「人の子よ、イスラエルの地であなたがたが用いている、『日々は延び、どの幻も実現しない』ということわざは何か。</span>
<span className="v" id="v23" data-v="23" data-xref="ヨエル書 2:1; エゼキエル書 7:5–7; ゼパニヤ書 1:14"> それゆえ、彼らに言え。『主なる神はこう言われる。「わたしはこのことわざを終わらせる。彼らがイスラエルで再びこれをことわざとして用いることはない。」』また彼らに、こう言え。『主なる神はこう言われる。「日々は近づき、すべての幻が実現する時も近い。</span>
<span className="v" id="v24" data-v="24" data-xref="エレミヤ書 14:13–16; エゼキエル書 13:23; ゼカリヤ書 13:2–4"> イスラエルの家の中には、もはや偽りの幻も、へつらいの占いもなくなる。</span>
<span className="v" id="v25" data-v="25" data-xref="ハバクク書 1:5; エゼキエル書 12:28; イザヤ書 55:11"> 主であるわたしが語る。わたしが語る言葉は必ず実現する。それはもはや先延ばしにされない。反逆の家よ、あなたがたの生きている間に、わたしは言葉を語り、それを実現する」と主なる神は言われる。』」</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26"> 再び、主の言葉が私に臨んだ。</span>
<span className="v" id="v27" data-v="27" data-xref="ダニエル書 10:14; エゼキエル書 12:22; ペテロの第二の手紙 3:4"> 「人の子よ、見よ、イスラエルの家の者たちは、『彼が見る幻は、はるか先の日のことであり、彼は遠い時代について預言している』と言っている。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="エゼキエル書 12:23–25; マルコ 13:32–37; テサロニケ人への手紙第一 5:2–3"> それゆえ、彼らに言え。『主なる神はこう言われる。「わたしの言葉は一つも、これ以上先延ばしにされない。わたしが語る言葉は実現する」と主なる神は言われる。』」</span>
</div>

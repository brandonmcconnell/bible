<div className="bp">
<span className="v" id="v1" data-v="1"> 再び、主の言葉が私に臨んだ。</span>
<span className="v" id="v2" data-v="2" data-xref="エゼキエル書 22:2; エゼキエル書 20:4; イザヤ書 58:1"> 「人の子よ、エルサレムに、その忌むべき行いを思い知らせよ。</span>
<span className="v" id="v3" data-v="3" data-xref="エゼキエル書 16:45; イザヤ書 51:1–2; 申命記 20:17"> こう言え。『主なる神はエルサレムにこう言われる。「あなたの出自と誕生はカナン人の地にある。あなたの父はアモリ人、あなたの母はヘテ人であった。</span>
<span className="v" id="v4" data-v="4" data-xref="ホセア書 2:3; 創世記 15:13; 出エジプト記 5:16–21"> あなたの誕生について言えば、あなたが生まれた日、へその緒は切られず、清めるために水で洗われず、塩でこすられることも、布で包まれることもなかった。</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 32:10; 創世記 21:10; 出エジプト記 1:22"> だれの目もあなたを惜しまず、あなたをあわれんで、これらのことを一つでもしてくれる者はいなかった。あなたは生まれた日に忌み嫌われ、野原に投げ捨てられた。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="エペソ人への手紙 2:4–5; ヨハネ 5:25; テトス 3:3–7"> わたしがあなたのそばを通り、あなたが血の中でもがいているのを見たとき、血まみれのあなたに、『生きよ』と言った。そうだ、血まみれのあなたに、『生きよ』と言った。</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 1:10; 出エジプト記 1:7; イザヤ書 62:3"> わたしはあなたを野に生える草のように増えさせた。あなたは育ち、大きくなり、見事な美しさに達した。乳房は形づくられ、髪も伸びた。しかし、あなたは裸で何も身に着けていなかった。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="ルツ記 3:9; エレミヤ書 2:2–3; ローマ人への手紙 5:8"> わたしが再びあなたのそばを通り、あなたを見ると、見よ、あなたは愛の時を迎えていた。そこでわたしは衣の裾をあなたの上に広げ、あなたの裸を覆った。わたしはあなたに誓いを立て、あなたと契約を結んだ」と主なる神は言われる。「こうして、あなたはわたしのものとなった。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="詩篇 23:5; ルツ記 3:3; ヨハネの手紙第一 2:27"> それから、わたしはあなたを水で洗った。あなたの血をすっかり洗い流し、油を塗った。</span>
<span className="v" id="v10" data-v="10" data-xref="エゼキエル書 16:18; エゼキエル書 16:13; イザヤ書 61:10"> 刺繍を施した衣を着せ、革の履物を履かせた。上質の亜麻布をまとわせ、絹で覆った。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 24:22; イザヤ書 3:19; 創世記 41:42"> 飾り物であなたを飾り、両手に腕輪をはめ、首に首飾りを掛けた。</span>
<span className="v" id="v12" data-v="12" data-xref="イザヤ書 3:21; イザヤ書 28:5; エレミヤ書 13:18"> 鼻に輪を付け、耳には耳飾りを付け、頭には美しい冠を載せた。</span>
<span className="v" id="v13" data-v="13" data-xref="申命記 32:13–14; 詩篇 50:2; 列王記第一 4:21"> こうして、あなたは金と銀で飾られた。あなたの衣服は上質の亜麻布と絹と刺繍を施した布であった。あなたは上等の小麦粉と蜜と油を食べた。あなたは非常に美しくなり、王族の身分にまで栄えた。</span>
<span className="v" id="v14" data-v="14" data-xref="列王記第一 10:24; 哀歌 2:15; コリント人への第一の手紙 4:7"> あなたの美しさの評判は諸国に広まった。わたしがあなたにまとわせた威光によって、その美しさは完全なものとなった」と主なる神は言われる。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="イザヤ書 57:8; エレミヤ書 2:20; エゼキエル書 16:25"> 「しかし、あなたは自分の美しさに頼り、自分の名声のために娼婦のように振る舞った。通りかかる者すべてに淫行を注ぎ出し、その者のものとなった。</span>
<span className="v" id="v16" data-v="16" data-xref="列王記第二 23:7; エゼキエル書 7:20; 歴代誌 第二 28:24"> あなたは自分の衣服の一部を取り、色とりどりに飾った高き所を造り、その上で淫行を行った。このようなことは起こるべきではなく、今後も起こってはならない。</span>
<span className="v" id="v17" data-v="17" data-xref="エゼキエル書 23:14–21; エレミヤ書 3:9; エゼキエル書 16:11"> また、わたしがあなたに与えた、わたしの金と銀の美しい飾り物を取り、男の姿をした像を造り、それらと淫行を行った。</span>
<span className="v" id="v18" data-v="18"> 刺繍を施した衣を取ってそれらの像を覆い、わたしの油と香をその前に供えた。</span>
<span className="v" id="v19" data-v="19" data-xref="エゼキエル書 16:13; ホセア書 2:8–13; 創世記 8:21"> わたしがあなたに与えたパン、すなわち、あなたを養うために与えた上等の小麦粉と油と蜜さえも、芳しい香りとしてそれらの前に供えた。実際、そのようになった」と主なる神は言われる。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="エゼキエル書 23:37; エゼキエル書 20:31; エレミヤ書 7:31"> 「その上、あなたはわたしのために産んだ息子や娘を取り、それらの像に、食い尽くされるいけにえとしてささげた。あなたの淫行は小さなことだったのか。</span>
<span className="v" id="v21" data-v="21" data-xref="列王記第二 17:17; レビ記 18:21; 申命記 18:10"> あなたはわたしの子どもたちを殺し、火の中を通らせて彼らにささげた。</span>
<span className="v" id="v22" data-v="22" data-xref="エレミヤ書 2:2; ホセア書 11:1; エゼキエル書 16:43"> あなたはすべての忌むべき行いと淫行の中で、自分の若かった日々を思い出さなかった。そのころ、あなたは裸で何も身に着けず、血の中でもがいていた。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="ヨハネの黙示録 12:12; エゼキエル書 2:10; エゼキエル書 24:6"> あなたがこれらすべての悪を行った後で――災いだ。災いだ。あなたには災いがある」と主なる神は言われる。</span>
<span className="v" id="v24" data-v="24" data-xref="詩篇 78:58; エゼキエル書 16:39; エゼキエル書 16:31"> 「あなたは自分のために丸天井の建物を築き、すべての通りに高い場所を造った。</span>
<span className="v" id="v25" data-v="25" data-xref="エゼキエル書 16:31; エレミヤ書 3:2; 創世記 38:21"> あらゆる道の分かれ目に高い場所を築き、自分の美しさを忌むべきものとした。通りかかる者すべてに足を開き、淫行を重ねた。</span>
<span className="v" id="v26" data-v="26" data-xref="エゼキエル書 23:19–21; エゼキエル書 20:7–8; エゼキエル書 8:10"> また、肉体のたくましい隣人であるエジプト人と淫行を行い、淫行を重ねて、わたしを怒らせた。</span>
<span className="v" id="v27" data-v="27" data-xref="イザヤ書 9:12; エゼキエル書 16:57; エゼキエル書 16:37"> それゆえ、見よ、わたしはあなたに向かって手を伸ばし、あなたの取り分を減らし、あなたを憎む者たち、すなわち、あなたの淫らな歩みを恥じているペリシテ人の娘たちの思いのままにさせた。</span>
<span className="v" id="v28" data-v="28" data-xref="列王記第二 16:7; ホセア書 10:6; 列王記第二 16:10–18"> あなたは満足することができず、アッシリア人とも淫行を行った。彼らと淫行を行っても、なお満足しなかった。</span>
<span className="v" id="v29" data-v="29" data-xref="列王記第二 21:9; 士師記 2:12–19; エゼキエル書 13:14–23"> さらに、商人の地カルデアにまで淫行を増し加えた。それでも満足しなかった。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="エレミヤ書 3:3; イザヤ書 1:3; イザヤ書 3:9"> あなたの心は、なんと弱いのか」と主なる神は言われる。「厚かましい娼婦のするこれらすべてのことを行うとは。</span>
<span className="v" id="v31" data-v="31" data-xref="エゼキエル書 16:33–34; イザヤ書 52:3; エゼキエル書 16:39"> あらゆる道の分かれ目に丸天井の建物を築き、すべての通りに高い場所を造った。しかし、報酬をさげすむあなたは、普通の娼婦のようでさえなかった。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="エレミヤ書 2:28; エゼキエル書 23:37; エレミヤ書 2:25"> 夫の代わりに見知らぬ男たちを受け入れる、姦淫の妻よ。</span>
<span className="v" id="v33" data-v="33" data-xref="イザヤ書 57:9; ホセア書 8:9–10; エゼキエル書 16:41"> 人々はすべての娼婦に贈り物をする。しかし、あなたは自分のすべての愛人に贈り物をし、彼らが四方からあなたのもとへ来て淫行を行うよう、彼らを買収した。</span>
<span className="v" id="v34" data-v="34"> あなたの淫行は、ほかの女たちとは反対である。だれも淫行をするためにあなたを追い求めない。あなたは報酬を受けるのではなく、自分から報酬を与える。まさに、あなたはほかの女たちとは正反対である。」</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="ヨハネ 4:18; 列王記第一 22:19; ヨハネ 4:10"> それゆえ、娼婦よ、主の言葉を聞け。</span>
<span className="v" id="v36" data-v="36" data-xref="エゼキエル書 23:10; エゼキエル書 24:13; ゼパニヤ書 3:1"> 主なる神はこう言われる。「あなたが愛人たちと淫行を行い、あなたの汚れが注ぎ出され、裸がさらされたため、また、すべての忌むべき偶像のため、さらに、それらに与えた子どもたちの血のため、</span>
<span className="v" id="v37" data-v="37" data-xref="ホセア書 2:10; エレミヤ書 13:22; ホセア書 2:3"> 見よ、わたしはあなたが喜んだすべての愛人、あなたが愛したすべての者、さらに、あなたが憎んだすべての者を集める。彼らを四方からあなたに敵対して集め、あなたの裸を彼らの前にさらす。彼らはあなたの裸をすべて見る。</span>
<span className="v" id="v38" data-v="38" data-xref="レビ記 20:10; 創世記 9:6; ゼパニヤ書 1:17"> わたしは、姦淫を行い、血を流す女たちが裁かれるように、あなたを裁く。怒りとねたみによる血の報いをあなたにもたらす。</span>
<span className="v" id="v39" data-v="39" data-xref="エゼキエル書 23:26; ホセア書 2:3; エゼキエル書 16:24–25"> わたしはあなたを彼らの手に渡す。彼らはあなたの丸天井の建物を取り壊し、高い場所を打ち壊す。あなたの衣服をはぎ取り、美しい飾り物を奪い、あなたを裸のまま残す。</span>
<span className="v" id="v40" data-v="40" data-xref="エゼキエル書 23:47; ハバクク書 1:6–10; ヨハネ 8:5–7"> 彼らは一団をあなたに差し向け、あなたを石で打ち、剣で刺し貫く。</span>
<span className="v" id="v41" data-v="41" data-xref="エゼキエル書 23:48; エレミヤ書 52:13; エレミヤ書 39:8"> 彼らはあなたの家々を火で焼き、多くの女たちの目の前であなたに裁きを執行する。わたしはあなたに淫行をやめさせる。あなたはもはや報酬を与えることもない。</span>
<span className="v" id="v42" data-v="42" data-xref="エゼキエル書 5:13; エゼキエル書 21:17; イザヤ書 40:1–2"> こうして、あなたに対するわたしの憤りを静め、わたしのねたみをあなたから去らせる。わたしは静まり、もはや怒らない。</span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="エゼキエル書 16:22; エゼキエル書 11:21; 詩篇 78:42"> あなたは自分の若かった日々を思い出さず、これらすべてのことによってわたしに向かって荒れ狂った。それゆえ、見よ、わたしもあなたの歩みをあなた自身の頭に報いる」と主なる神は言われる。「あなたは自分のすべての忌むべき行いに加えて、この淫らな行いを重ねることはない。</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="エゼキエル書 18:2–3; 詩篇 106:35–38; サムエル記第一 24:13"> 見よ、ことわざを使う者は皆、あなたについて、『母のように、その娘も同じだ』ということわざを使う。</span>
<span className="v" id="v45" data-v="45" data-xref="ゼカリヤ書 11:8; イザヤ書 1:4; エゼキエル書 23:37–39"> あなたは、自分の夫と子どもたちを忌み嫌った母の娘であり、自分の夫と子どもたちを忌み嫌った姉妹たちの姉妹である。あなたの母はヘテ人、父はアモリ人であった。</span>
<span className="v" id="v46" data-v="46" data-xref="エゼキエル書 23:4; エゼキエル書 16:48–49; エゼキエル書 16:53–56"> あなたの姉はサマリアであり、その娘たちと共にあなたの左に住んでいる。あなたの妹はソドムであり、その娘たちと共にあなたの右に住んでいる。</span>
<span className="v" id="v47" data-v="47" data-xref="列王記第二 21:9; エゼキエル書 16:51; エゼキエル書 5:6–7"> あなたは彼女たちの道を歩み、その忌むべき行いを行うだけでは済まず、ほどなくして、あらゆる道で彼女たち以上に堕落した。</span>
<span className="v" id="v48" data-v="48" data-xref="マタイ 10:15; ルカ 10:12; 使徒の働き 7:52"> わたしは生きている」と主なる神は言われる。「あなたの姉妹ソドムとその娘たちも、あなたとあなたの娘たちが行ったほどのことは行わなかった。</span>
</div>
<div className="bp">
<span className="v" id="v49" data-v="49" data-xref="詩篇 138:6; エゼキエル書 28:2; 創世記 13:10"> 見よ、あなたの姉妹ソドムの不義はこれであった。彼女とその娘たちには、高ぶりと十分な食べ物と安らかな繁栄があった。しかし、貧しい者や乏しい者を助けなかった。</span>
<span className="v" id="v50" data-v="50" data-xref="創世記 19:24; 創世記 18:20; 創世記 19:5"> 彼女たちは高慢になり、わたしの前で忌むべきことを行った。それゆえ、わたしはそれを見たとき、彼女たちを取り除いた。</span>
<span className="v" id="v51" data-v="51" data-xref="エレミヤ書 3:8–11; ルカ 12:47–48; ローマ人への手紙 3:9–20"> サマリアは、あなたの罪の半分も犯さなかった。しかし、あなたは彼女たちよりも多くの忌むべき行いを重ね、自分が行ったすべての忌むべき行いによって、姉妹たちを義と認められる者にした。</span>
<span className="v" id="v52" data-v="52" data-xref="マタイ 7:1–5; エゼキエル書 36:15; エゼキエル書 16:56"> あなたは姉妹たちに有利な判決を下したのだから、自分の恥を負え。あなたが彼女たちよりも忌むべき罪を犯したため、彼女たちはあなたよりも義である。あなたも辱められ、自分の恥を負え。あなたは姉妹たちを義と認められる者にした。</span>
</div>
<div className="bp">
<span className="v" id="v53" data-v="53" data-xref="エゼキエル書 29:14; エレミヤ書 12:16; エゼキエル書 39:25"> わたしは彼女たちの捕囚を回復させる。ソドムとその娘たちの捕囚、サマリアとその娘たちの捕囚、そして彼女たちと共にいる、あなたの捕囚の民も回復させる。</span>
<span className="v" id="v54" data-v="54" data-xref="エゼキエル書 14:22–23; エレミヤ書 2:26; エゼキエル書 36:31–32"> それは、あなたが自分の恥を負い、自分の行ったすべてのことを恥じるためである。あなたが彼女たちを慰める者となったからである。</span>
<span className="v" id="v55" data-v="55" data-xref="エゼキエル書 36:11; マラキ書 3:4; エゼキエル書 16:53"> あなたの姉妹ソドムとその娘たちは以前の状態に戻り、サマリアとその娘たちも以前の状態に戻る。あなたとあなたの娘たちも以前の状態に戻る。</span>
<span className="v" id="v56" data-v="56" data-xref="イザヤ書 65:5; ルカ 15:28–30; ゼパニヤ書 3:11"> あなたが高ぶっていた日々には、あなたの姉妹ソドムの名があなたの口に上ることさえなかった。</span>
<span className="v" id="v57" data-v="57" data-xref="列王記第二 16:5–7; エゼキエル書 16:36–37; 歴代誌 第二 28:5–6"> それは、あなたの悪があらわにされる前、シリアの娘たちとその周囲のすべての者からそしられ、四方からあなたを侮るペリシテ人の娘たちからそしられた時のことである。</span>
<span className="v" id="v58" data-v="58" data-xref="エゼキエル書 23:49; 哀歌 5:7; 創世記 4:13"> あなたは自分の淫らな行いと忌むべき行いの報いを負っている」と主は言われる。</span>
</div>
<div className="bp">
<span className="v" id="v59" data-v="59" data-xref="イザヤ書 24:5; エゼキエル書 17:19; 申命記 29:25"> 主なる神はこう言われる。「誓いを軽蔑して契約を破ったあなたに、わたしもあなたが行ったとおりに行う。</span>

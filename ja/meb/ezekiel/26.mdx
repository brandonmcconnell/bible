<span className="v" id="v1" data-v="1" data-xref="エゼキエル書 20:1; エゼキエル書 1:2; エレミヤ書 39:2"> 第十一年、その月の一日、主の言葉が私に臨んだ。</span>
<span className="v" id="v2" data-v="2" data-xref="イザヤ書 23:1–18; エゼキエル書 36:2; ヨエル書 3:4"> 「人の子よ、ツロはエルサレムに向かって、『ああ、よい気味だ。諸民族の門であった町は打ち破られ、その役割は私に移った。あの町が荒れ果てた今、私は豊かになる』と言った。</span>
<span className="v" id="v3" data-v="3" data-xref="エレミヤ書 51:42; イザヤ書 5:30; ミカ書 4:11"> それゆえ、主なる神はこう言われる。『ツロよ、見よ、わたしはあなたに立ち向かう。海が波を押し寄せさせるように、多くの国々をあなたに攻め上らせる。</span>
<span className="v" id="v4" data-v="4" data-xref="イザヤ書 23:11; アモス書 1:10; エゼキエル書 26:9"> 彼らはツロの城壁を破壊し、その塔を打ち壊す。わたしはその土を削り取り、そこを裸の岩にする。</span>
<span className="v" id="v5" data-v="5" data-xref="エゼキエル書 29:19; エゼキエル書 27:32; エゼキエル書 25:7"> そこは海の中で網を広げる場所となる。わたしが語った』と主なる神は言われる。『そこは諸国の略奪物となる。</span>
<span className="v" id="v6" data-v="6" data-xref="エゼキエル書 16:46; エゼキエル書 26:8; エレミヤ書 49:2"> 野にいるその娘たちは剣で殺される。そのとき、彼らは、わたしが主であることを知る。』</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="エズラ記 7:12; ダニエル書 2:37; エゼキエル書 23:24"> 主なる神はこう言われる。『見よ、わたしは王の王、バビロンの王ネブカドネザルを、馬、戦車、騎兵、多くの民からなる軍勢と共に、北からツロに攻め来させる。</span>
<span className="v" id="v8" data-v="8" data-xref="エゼキエル書 21:22; エレミヤ書 52:4; エレミヤ書 32:24"> 彼は野にいるあなたの娘たちを剣で殺す。あなたに対して砦を築き、土塁を盛り上げ、盾を構える。</span>
<span className="v" id="v9" data-v="9" data-xref="歴代誌 第二 26:15"> 破城槌をあなたの城壁に打ち当て、斧であなたの塔を打ち壊す。</span>
<span className="v" id="v10" data-v="10" data-xref="エゼキエル書 26:15; エゼキエル書 27:28; エレミヤ書 47:3"> 彼の馬があまりにも多いため、その土煙があなたを覆う。城壁を破られた町に人々が入るように、彼があなたの門から入るとき、騎兵、荷車、戦車の音によって、あなたの城壁は揺れ動く。</span>
<span className="v" id="v11" data-v="11" data-xref="イザヤ書 5:28; イザヤ書 26:5; ハバクク書 1:8"> 彼は馬のひづめであなたのすべての通りを踏みにじり、あなたの民を剣で殺す。あなたの力を支える柱は地に倒れる。</span>
<span className="v" id="v12" data-v="12" data-xref="イザヤ書 23:8; 歴代誌 第二 32:27; ゼカリヤ書 9:3–4"> 彼らはあなたの富を略奪し、商品を奪う。城壁を打ち壊し、美しい家々を破壊する。あなたの石材、木材、土を水の中に投げ込む。</span>
<span className="v" id="v13" data-v="13" data-xref="エレミヤ書 7:34; イザヤ書 23:16; イザヤ書 14:11"> わたしはあなたの歌の響きをやめさせる。あなたの琴の音は、もはや聞かれない。</span>
<span className="v" id="v14" data-v="14" data-xref="マラキ書 1:4; ヨブ記 12:14; 民数記 23:19"> わたしはあなたを裸の岩にする。あなたは網を広げる場所となり、二度と建て直されない。主であるわたしが語った』と主なる神は言われる。</span>
</div>
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="エゼキエル書 27:35; エレミヤ書 49:21; エゼキエル書 26:18"> 主なる神はツロにこう言われる。『あなたが倒れる音、傷ついた者たちのうめき、あなたの中で行われる殺戮の音によって、島々は震えるのではないか。</span>
<span className="v" id="v16" data-v="16" data-xref="エゼキエル書 32:10; ヨナ書 3:6; ヨブ記 8:22"> そのとき、海のすべての君主は王座から降り、上着を脱ぎ、刺繍を施した衣を脱ぎ捨てる。彼らは震えを身にまとって地に座り、絶えず震え、あなたのことで驚き恐れる。</span>
<span className="v" id="v17" data-v="17" data-xref="イザヤ書 14:12; エゼキエル書 19:1; サムエル記第二 1:25–27"> 彼らはあなたのために哀歌を唱え、あなたに言う。<br /><span className="pl pl-1">「ああ、あなたは滅ぼされた。</span><br /><span className="pl pl-2">海を行く者たちが住んでいた町よ。</span><br /><span className="pl pl-1">海の上で強かった、</span><br /><span className="pl pl-2">名高い町よ。</span><br /><span className="pl pl-1">あなたとその住民は、</span><br /><span className="pl pl-2">そこに住むすべての者に恐怖を与えていたのに。</span></span>
<span className="v" id="v18" data-v="18" data-xref="エゼキエル書 26:15; イザヤ書 23:5–7; エゼキエル書 27:35"> <span className="pl pl-1">今、あなたが倒れる日に島々は震える。</span><br /><span className="pl pl-2">そうだ、海の島々は、あなたが消え去ることにおびえる。」』</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="イザヤ書 8:7–8; エゼキエル書 26:3; ダニエル書 11:40"> 主なる神はこう言われる。『わたしがあなたを、人の住まない町々のような荒れ果てた町とし、深淵をあなたの上に湧き上がらせ、大水があなたを覆うとき、</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 27:13; ルカ 10:15; ゼカリヤ書 2:8"> わたしはあなたを、穴に下る者たちと共に、昔の民のもとへ下らせる。あなたを、穴に下る者たちと共に、地の低い所、昔から荒れ果てている場所に住ませる。あなたは人の住む所とはならない。そして、わたしは生ける者の地に栄光を現す。</span>
<span className="v" id="v21" data-v="21" data-xref="エゼキエル書 27:36; エゼキエル書 28:19; ヨハネの黙示録 18:21"> わたしはあなたを恐るべきものとし、あなたは存在しなくなる。人々があなたを捜しても、二度と見つけることはない』と主なる神は言われる。」</span>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1"> 主の言葉が私に臨んだ。</span>
<span className="v" id="v2" data-v="2" data-xref="エゼキエル書 39:1; エゼキエル書 27:13; エゼキエル書 38:3"> 「人の子よ、マゴグの地のゴグ、ロシュ、メシェク、トバルの君主に顔を向け、彼に対して預言せよ。</span>
<span className="v" id="v3" data-v="3" data-xref="エゼキエル書 13:8; エゼキエル書 39:1–10; エゼキエル書 29:3"> こう言え。『主なる神はこう言われる。「ロシュ、メシェク、トバルの君主ゴグよ、見よ、わたしはあなたに立ち向かう。</span>
<span className="v" id="v4" data-v="4" data-xref="エゼキエル書 29:4; ダニエル書 11:40; エゼキエル書 38:15"> わたしはあなたの向きを変えさせ、あなたのあごに鉤を掛け、あなたとその全軍を連れ出す。馬と騎兵、完全に武装したすべての者、小盾と大盾を持つ大軍、剣を取るすべての者を連れ出す。</span>
<span className="v" id="v5" data-v="5" data-xref="エゼキエル書 27:10; 創世記 10:6; エゼキエル書 30:5"> 彼らと共に、ペルシア、エチオピア、プテがいる。彼らは皆、盾と兜を身に着けている。</span>
<span className="v" id="v6" data-v="6" data-xref="エゼキエル書 27:14; 創世記 10:2–3; 歴代誌上 1:5–6"> ゴメルとその全軍、北の果てにいるトガルマの家とその全軍、さらに多くの民があなたと共にいる。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="歴代誌 第二 25:8; ヨエル書 3:9–12; イザヤ書 37:22"> 備えよ。あなたと、あなたのもとに集まったすべての軍勢は備えを整え、彼らの守り手となれ。</span>
<span className="v" id="v8" data-v="8" data-xref="エゼキエル書 38:16; イザヤ書 24:22; エゼキエル書 38:11–12"> 多くの日の後、あなたは召集される。後の年月に、あなたは剣から回復した地へ行く。そこは、多くの民の中から集められた者たちが住むイスラエルの山々であり、長い間、絶えず荒れ果てていた。しかし、その民は諸民族の中から連れ出され、皆、安心して住んでいる。</span>
<span className="v" id="v9" data-v="9" data-xref="イザヤ書 28:2; エレミヤ書 4:13; ヨエル書 2:2"> あなたは攻め上り、暴風のように来る。あなたとその全軍、あなたと共にいる多くの民は、地を覆う雲のようになる。」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="詩篇 36:4; ミカ書 2:1; 詩篇 83:3–4"> 主なる神はこう言われる。「その日、あなたの心にさまざまな考えが浮かび、あなたは悪い計画を企てる。</span>
<span className="v" id="v11" data-v="11" data-xref="ゼカリヤ書 2:4–5; 箴言 3:29–30; エレミヤ書 49:31–32"> あなたは言う。『私は城壁のない村々の地へ攻め上ろう。平穏に、安心して住んでいる者たちの所へ行こう。彼らは皆、城壁もかんぬきも門もない所に住んでいる。</span>
<span className="v" id="v12" data-v="12" data-xref="イザヤ書 10:6; エゼキエル書 38:8; エゼキエル書 29:19"> 略奪物を奪い、獲物を取るために行こう。人が住むようになった廃墟に手を向け、諸国の中から集められ、家畜と財産を得て、地の中心に住む民を襲おう。』</span>
<span className="v" id="v13" data-v="13" data-xref="エゼキエル書 27:15; エゼキエル書 27:22–23; エゼキエル書 32:2"> シェバ、デダン、タルシシュの商人たちと、そのすべての若い獅子は、あなたに尋ねる。『あなたは略奪物を奪うために来たのか。獲物を取るために軍勢を集めたのか。銀と金を運び去り、家畜と財産を奪い、大いなる略奪を行うためか。』」』</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="エゼキエル書 38:8; ゼカリヤ書 2:5; エレミヤ書 23:6"> それゆえ、人の子よ、預言してゴグに言え。『主なる神はこう言われる。「わたしの民イスラエルが安心して住むその日、あなたはそのことを知るのではないか。</span>
<span className="v" id="v15" data-v="15" data-xref="エゼキエル書 39:2; エゼキエル書 38:6; ヨハネの黙示録 20:8"> あなたは自分の場所、北の果てから、多くの民と共に来る。彼らは皆、馬に乗る者で、大きな集団、強大な軍勢である。</span>
<span className="v" id="v16" data-v="16" data-xref="エゼキエル書 39:21; エゼキエル書 38:23; ホセア書 3:5"> あなたは地を覆う雲のように、わたしの民イスラエルに攻め上る。終わりの日々に、わたしはあなたをわたしの地に攻め来させる。ゴグよ、わたしは諸国の目の前で、あなたを通して自らが聖なる者であることを示す。そのとき、諸国はわたしを知る。」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="ダニエル書 11:40–45; イザヤ書 63:1–6; ヨエル書 3:9–14"> 主なる神はこう言われる。「あなたは、わたしが昔、わたしのしもべであるイスラエルの預言者たちを通して語った者ではないか。彼らは当時、長年にわたって、わたしがあなたを彼らに攻め来させると預言した。</span>
<span className="v" id="v18" data-v="18" data-xref="エゼキエル書 36:5–6; ヘブル人への手紙 12:29; 詩篇 89:46"> ゴグがイスラエルの地に攻め来るその日、わたしの鼻には憤りが燃え上がる」と主なる神は言われる。</span>
<span className="v" id="v19" data-v="19" data-xref="ハガイ書 2:6–7; ヨハネの黙示録 11:13; ヨハネの黙示録 16:20"> 「わたしは、ねたみと燃える憤りのうちに語った。その日、イスラエルの地に大きな揺れが必ず起こる。</span>
<span className="v" id="v20" data-v="20" data-xref="ホセア書 4:3; ナホム書 1:4–6; ヨハネの黙示録 6:12–13"> 海の魚、空の鳥、野の動物、地を這うすべてのもの、地の表にいるすべての人は、わたしの前で震える。山々は崩れ、急斜面は崩れ落ち、すべての城壁は地に倒れる。</span>
<span className="v" id="v21" data-v="21" data-xref="ハガイ書 2:22; 士師記 7:22; エゼキエル書 14:17"> わたしは、わたしのすべての山々で、ゴグに向かって剣を呼び寄せる」と主なる神は言われる。「人は皆、兄弟に向かって剣を振るう。</span>
<span className="v" id="v22" data-v="22" data-xref="イザヤ書 66:16; 詩篇 11:6; ヨハネの黙示録 16:21"> わたしは疫病と流血をもって彼を裁く。彼とその全軍、彼と共にいる多くの民の上に、豪雨、大粒の雹、火、硫黄を降らせる。</span>
<span className="v" id="v23" data-v="23" data-xref="詩篇 9:16; ヨハネの黙示録 19:1–6; エゼキエル書 38:16"> わたしは自分を大いなる者として示し、自らが聖なる者であることを示し、多くの国々の目の前で自分を知らせる。そのとき、彼らは、わたしが主であることを知る。」』」</span>
</div>

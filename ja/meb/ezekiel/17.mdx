<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 主の言葉が私に臨んだ。</span>
<span className="v" id="v2" data-v="2" data-xref="エゼキエル書 20:49; マタイ 13:35; コリント人への第一の手紙 13:12"> 「人の子よ、イスラエルの家に謎を出し、たとえを語れ。</span>
<span className="v" id="v3" data-v="3" data-xref="ホセア書 8:1; エレミヤ書 48:40; エゼキエル書 17:7"> こう言え。『主なる神はこう言われる。「大きな翼と長い羽を持ち、豊かな羽毛に覆われ、その羽が色とりどりの一羽の大鷲が、レバノンに来て、杉の木の頂を取った。</span>
<span className="v" id="v4" data-v="4" data-xref="イザヤ書 43:14; イザヤ書 47:15; ヨハネの黙示録 18:11–19"> その若枝の先端を摘み取り、交易の地へ運び、商人の町に植えた。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="イザヤ書 44:4; 申命記 8:7–9; エレミヤ書 37:1"> また、その地の種の一部を取り、肥沃な土地に植えた。それを豊かな水のほとりに置き、柳の木のように植えた。</span>
<span className="v" id="v6" data-v="6" data-xref="エゼキエル書 17:14; 箴言 16:18–19"> それは成長し、丈が低く、横に枝を広げるぶどうの木となった。その枝は鷲の方に向き、根は鷲の下にあった。こうして、それはぶどうの木となり、枝を出し、若枝を伸ばした。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="エゼキエル書 31:4; エゼキエル書 17:15; 列王記第二 24:20"> また、大きな翼と多くの羽を持つ、もう一羽の大鷲がいた。見よ、このぶどうの木は、植えられた地から、その鷲に水を注いでもらおうとして、根を鷲の方へ伸ばし、枝を鷲の方へ向けた。</span>
<span className="v" id="v8" data-v="8" data-xref="エゼキエル書 17:5–6"> それは枝を出し、実を結び、立派なぶどうの木となるよう、豊かな水のそばの良い土地に植えられていた。」』</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="エゼキエル書 17:10; エレミヤ書 32:5; イザヤ書 30:1–7"> こう言え。『主なる神はこう言われる。「それは栄えるだろうか。最初の鷲はその根を引き抜き、実を切り落とし、芽生えた新鮮な葉をすべて枯れさせるのではないか。それを根から引き抜くのに、強い腕も多くの民も必要ない。</span>
<span className="v" id="v10" data-v="10" data-xref="ホセア書 13:15; ヨハネ 15:6; マタイ 21:19"> 見よ、それは植えられてはいるが、栄えるだろうか。東風が触れれば、完全に枯れるのではないか。それは育った地で枯れる。」』」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11"> さらに、主の言葉が私に臨んだ。</span>
<span className="v" id="v12" data-v="12" data-xref="エゼキエル書 24:19; エゼキエル書 17:3; エゼキエル書 1:2"> 「今、反逆の家に言え。『これらが何を意味するのか、あなたがたには分からないのか。』彼らに告げよ。『見よ、バビロンの王がエルサレムに来て、その王と首長たちを捕らえ、バビロンの自分のもとへ連れて行った。</span>
<span className="v" id="v13" data-v="13" data-xref="歴代誌 第二 36:13; 列王記第二 24:15–17; エゼキエル書 17:5"> 彼は王族の一人<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="または「種」。">a</a></sup>を取り、その者と契約を結び、誓いを立てさせた。また、その地の有力者たちを連れ去った。</span>
<span className="v" id="v14" data-v="14" data-xref="エゼキエル書 29:14; 申命記 28:43; サムエル記第一 2:30"> それは王国を低くして、自ら高ぶることができないようにし、契約を守ることによって存続させるためであった。</span>
<span className="v" id="v15" data-v="15" data-xref="エレミヤ書 52:3; エレミヤ書 38:18; エゼキエル書 17:7"> しかし、その王はバビロンの王に反逆し、馬と多くの兵士を与えてもらおうとして、使者をエジプトに送った。このようなことをする者が栄えるだろうか。逃れることができるだろうか。契約を破って、なお逃れられるだろうか。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="エゼキエル書 12:13; エレミヤ書 52:11; エゼキエル書 17:18–19"> わたしは生きている」と主なる神は言われる。「彼を王とした王が住む所、すなわち、彼がその誓いを軽蔑し、その契約を破った相手のいるバビロンのただ中で、彼は必ず死ぬ。</span>
<span className="v" id="v17" data-v="17" data-xref="エレミヤ書 37:7; エゼキエル書 4:2; エゼキエル書 29:6–7"> 多くの人を断ち滅ぼすために敵が土塁を築き、砦を建てる戦いで、ファラオは強大な軍勢と大軍をもってしても、彼を助けることはできない。</span>
<span className="v" id="v18" data-v="18" data-xref="歴代誌上 29:24; 歴代誌 第二 30:8; 哀歌 5:6"> 彼は誓いを軽蔑して契約を破った。見よ、彼は手を差し出して契約したにもかかわらず、これらすべてのことを行った。彼は逃れられない。』</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="申命記 5:11; エレミヤ書 5:9; エレミヤ書 5:2"> それゆえ、主なる神はこう言われる。『わたしは生きている。彼が軽蔑したわたしの誓いと、彼が破ったわたしの契約を、必ず彼自身の頭に報いる。</span>
<span className="v" id="v20" data-v="20" data-xref="エゼキエル書 12:13; エゼキエル書 32:3; エレミヤ書 2:35"> わたしは彼の上に網を広げ、彼はわたしのわなに捕らえられる。わたしは彼をバビロンへ連れて行き、彼がわたしに対して犯した背きのために、そこで彼を裁く。</span>
<span className="v" id="v21" data-v="21" data-xref="列王記第二 25:5; 列王記第二 25:11; エゼキエル書 12:14"> 彼の全軍の逃亡者は皆、剣に倒れ、残った者たちは四方の風に散らされる。そのとき、あなたがたは、主であるわたしが語ったことを知る。』</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="イザヤ書 53:2; ゼカリヤ書 6:12–13; イザヤ書 11:1–5"> 主なる神はこう言われる。『わたしも高くそびえる杉の頂から一枝を取り、それを植える。その一番上の若枝から柔らかな枝を摘み取り、高くそびえる山に植える。</span>
<span className="v" id="v23" data-v="23" data-xref="マタイ 13:32; エゼキエル書 31:6; イザヤ書 2:2"> イスラエルの高い山にそれを植える。それは大枝を出し、実を結び、立派な杉の木となる。あらゆる種類の鳥がその枝の陰に住み、そこに宿る。</span>
<span className="v" id="v24" data-v="24" data-xref="アモス書 9:11; コリント人への第一の手紙 1:27–28; エゼキエル書 24:14"> 野のすべての木は、主であるわたしが、高い木を低くし、低い木を高くし、青々とした木を枯らし、枯れた木に芽を出させたことを知る。<br />主であるわたしが語り、それを行った。』」</span>
</div>
</div>

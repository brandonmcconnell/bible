<div className="bp poetry">
<span className="v" id="v1" data-v="1"> 再び、主の言葉が私に臨んだ。</span>
<span className="v" id="v2" data-v="2" data-xref="エレミヤ書 31:29–30; 哀歌 5:7; エゼキエル書 37:11"> 「あなたがたがイスラエルの地について、<br /><span className="pl pl-1">『父たちが酸っぱいぶどうを食べ、</span><br /><span className="pl pl-2">子どもたちの歯が浮く』</span><br />ということわざを使うのは、どういうことか。</span>
<span className="v" id="v3" data-v="3" data-xref="エゼキエル書 18:19–20; エゼキエル書 33:11–20; エゼキエル書 18:30"> わたしは生きている」と主なる神は言われる。「あなたがたがイスラエルで、二度とこのことわざを使うことはない。</span>
<span className="v" id="v4" data-v="4" data-xref="エゼキエル書 18:20; ローマ人への手紙 6:23; 民数記 16:22"> 見よ、すべての人はわたしのもの。父も子も、共にわたしのものである。罪を犯す者、その者が死ぬ。</span>
</div>
<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="エゼキエル書 33:14; ヨハネの手紙第一 3:7; 箴言 21:3"> <span className="pl pl-1">ある人が義人で、</span><br /><span className="pl pl-2">公正で正しいことを行い、</span></span>
<span className="v" id="v6" data-v="6" data-xref="エゼキエル書 18:15; 申命記 4:19; エゼキエル書 6:13"> <span className="pl pl-1">山の聖所で食べず、</span><br /><span className="pl pl-2">イスラエルの家の偶像を仰ぎ見ず、</span><br /><span className="pl pl-1">隣人の妻を汚さず、</span><br /><span className="pl pl-2">月経中の女に近づかず、</span></span>
<span className="v" id="v7" data-v="7" data-xref="エゼキエル書 18:16; 出エジプト記 22:26; エゼキエル書 18:12"> <span className="pl pl-1">だれをも虐げず、</span><br /><span className="pl pl-2">借りた者に担保を返し、</span><br /><span className="pl pl-1">力ずくで何も奪わず、</span><br /><span className="pl pl-2">飢えた者に自分のパンを与え、</span><br /><span className="pl pl-2">裸の者を衣服で覆い、</span></span>
<span className="v" id="v8" data-v="8" data-xref="出エジプト記 22:25; ゼカリヤ書 8:16; 申命記 23:19–20"> <span className="pl pl-1">利息を取って貸さず、</span><br /><span className="pl pl-2">高利を取らず、</span><br /><span className="pl pl-1">不正から手を引き、</span><br /><span className="pl pl-2">人と人との間を正しく裁き、</span></span>
<span className="v" id="v9" data-v="9" data-xref="エゼキエル書 20:11; ハバクク書 2:4; アモス書 5:4"> <span className="pl pl-1">わたしの掟に従って歩み、</span><br /><span className="pl pl-2">わたしの定めを守り、</span><br /><span className="pl pl-2">真実に行うなら、</span><br /><span className="pl pl-1">その人は義人である。</span><br /><span className="pl pl-2">彼は必ず生きる」と主なる神は言われる。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="出エジプト記 21:12; ヨハネの手紙第一 3:12; ヨハネ 18:40"> 「しかし、その人に、強盗であり、人の血を流し、これらのことの一つでも行う息子が生まれ、</span>
<span className="v" id="v11" data-v="11" data-xref="ヨハネの黙示録 22:14; マタイ 7:21–27; 列王記第一 13:8"> その息子がこれらの良い行いを一つもせず、<br /><span className="pl pl-1">山の聖所で食べ、</span><br /><span className="pl pl-2">隣人の妻を汚し、</span></span>
<span className="v" id="v12" data-v="12" data-xref="エゼキエル書 8:17; エゼキエル書 8:6; 列王記第二 21:11"> <span className="pl pl-1">貧しい者や乏しい者を虐げ、</span><br /><span className="pl pl-2">力ずくで奪い、</span><br /><span className="pl pl-1">担保を返さず、</span><br /><span className="pl pl-2">偶像を仰ぎ見て、</span><br /><span className="pl pl-2">忌むべきことを行い、</span></span>
<span className="v" id="v13" data-v="13" data-xref="出エジプト記 22:25; レビ記 20:9; エゼキエル書 3:18"> <span className="pl pl-1">利息を取って貸し、</span><br /><span className="pl pl-2">高利を取るなら、</span><br />彼は生きるだろうか。生きることはない。彼はこれらすべての忌むべき行いを行った。彼は必ず死ぬ。その血の責任は彼自身にある。</span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="歴代誌 第二 34:21; 箴言 23:24; エレミヤ書 8:6"> しかし、見よ、その息子にさらに息子が生まれ、その子が父の犯したすべての罪を見て恐れ、同じことを行わず、</span>
<span className="v" id="v15" data-v="15" data-xref="エゼキエル書 18:6–7; エゼキエル書 18:11–13"> <span className="pl pl-1">山の聖所で食べず、</span><br /><span className="pl pl-2">イスラエルの家の偶像を仰ぎ見ず、</span><br /><span className="pl pl-2">隣人の妻を汚さず、</span></span>
<span className="v" id="v16" data-v="16" data-xref="エゼキエル書 18:7; イザヤ書 58:7–10; ヨブ記 22:7"> <span className="pl pl-1">だれをも虐げず、</span><br /><span className="pl pl-2">担保を取らず、</span><br /><span className="pl pl-1">力ずくで何も奪わず、</span><br /><span className="pl pl-2">飢えた者に自分のパンを与え、</span><br /><span className="pl pl-2">裸の者を衣服で覆い、</span></span>
<span className="v" id="v17" data-v="17" data-xref="エゼキエル書 18:8–9; マタイ 18:27–35; エゼキエル書 18:13"> <span className="pl pl-1">貧しい者を虐げることから手を引き、</span><br /><span className="pl pl-2">利息も高利も受け取らず、</span><br /><span className="pl pl-1">わたしの定めを行い、</span><br /><span className="pl pl-2">わたしの掟に従って歩むなら、</span><br />彼は父の不義のために死ぬことはない。彼は必ず生きる。</span>
<span className="v" id="v18" data-v="18" data-xref="エゼキエル書 3:18; エゼキエル書 18:26; エゼキエル書 18:24"> 彼の父は、残酷に人を虐げ、兄弟から物を奪い、自分の民の間で良くないことを行ったので、見よ、自分の不義のうちに死ぬ。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="出エジプト記 20:5; ゼカリヤ書 1:3–6; 申命記 5:9"> しかし、あなたがたは、『なぜ子は父の不義を負わないのか』と言う。子が公正で正しいことを行い、わたしのすべての掟を守って実行したのだから、彼は必ず生きる。</span>
<span className="v" id="v20" data-v="20" data-xref="申命記 24:16; 列王記第二 14:6; エゼキエル書 18:4"> 罪を犯す者、その者が死ぬ。子が父の不義を負うことはなく、父が子の不義を負うこともない。義人の義はその人に帰し、悪人の悪もその人に帰する。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="エゼキエル書 18:27–28; テトス 2:11–14; エゼキエル書 33:19"> しかし、悪人が自分の犯したすべての罪から立ち返り、わたしのすべての掟を守り、公正で正しいことを行うなら、彼は必ず生き、死ぬことはない。</span>
<span className="v" id="v22" data-v="22" data-xref="ミカ書 7:19; エゼキエル書 33:16; イザヤ書 43:25"> 彼が犯した背きは一つも、彼に対して覚えられることはない。彼は自分が行った義のゆえに生きる。</span>
<span className="v" id="v23" data-v="23" data-xref="エゼキエル書 33:11; テモテへの手紙第一 2:4; ペテロの第二の手紙 3:9"> わたしは悪人の死を少しでも喜ぶだろうか」と主なる神は言われる。「むしろ、悪人が自分の道から立ち返って生きることを喜ぶのではないか。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="エゼキエル書 33:18; 箴言 21:16; ヨハネの手紙第二 1:8"> しかし、義人が自分の義から離れ、不義を行い、悪人が行うすべての忌むべき行いと同じことをするなら、彼は生きるだろうか。彼が行った正しい行いは一つも覚えられない。彼が犯した背きと、彼が犯した罪のために、彼は死ぬ。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="エゼキエル書 33:17; マラキ書 3:13–15; マラキ書 2:17"> それでも、あなたがたは、『主の道は公平ではない』と言う。イスラエルの家よ、今、聞け。わたしの道が公平でないのか。公平でないのは、あなたがたの道ではないか。</span>
<span className="v" id="v26" data-v="26"> 義人が自分の義から離れて不義を行い、そのために死ぬなら、彼は自分が行った不義のために死ぬ。</span>
<span className="v" id="v27" data-v="27" data-xref="エゼキエル書 18:21; イザヤ書 1:18; イザヤ書 55:7"> また、悪人が自分の行ってきた悪から離れ、公正で正しいことを行うなら、彼は自分の命を救う。</span>
<span className="v" id="v28" data-v="28" data-xref="申命記 32:29; ルカ 15:17–18; ヤコブの手紙 2:10–12"> 彼はよく考え、自分が犯したすべての背きから離れたので、必ず生き、死ぬことはない。</span>
<span className="v" id="v29" data-v="29" data-xref="エゼキエル書 18:25; 箴言 19:3; エゼキエル書 18:2"> それでも、イスラエルの家は、『主の道は公平ではない』と言う。イスラエルの家よ、わたしの道が公平でないのか。公平でないのは、あなたがたの道ではないか。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="エゼキエル書 18:21; マタイ 16:27; マタイ 3:2"> それゆえ、イスラエルの家よ、わたしはあなたがたを、それぞれの歩みに従って裁く」と主なる神は言われる。「立ち返れ。すべての背きから離れよ。そうすれば、不義があなたがたを滅びに陥れることはない。</span>
<span className="v" id="v31" data-v="31" data-xref="詩篇 51:10; エゼキエル書 36:26; エゼキエル書 11:19"> あなたがたが犯したすべての背きを、自分たちから投げ捨てよ。自分たちのために新しい心と新しい霊を造れ。イスラエルの家よ、なぜあなたがたは死のうとするのか。</span>
<span className="v" id="v32" data-v="32" data-xref="ペテロの第二の手紙 3:9; エゼキエル書 18:23; エゼキエル書 33:11"> わたしは死ぬ者の死を喜ばない」と主なる神は言われる。「それゆえ、立ち返って生きよ。」</span>
</div>

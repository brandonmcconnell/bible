<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨハネの黙示録 22:1; ゼカリヤ書 14:8; ヨエル書 3:18"> 彼は私を宮の入口へ連れ戻した。見よ、水が宮の敷居の下から東へ流れ出ていた。宮の正面が東を向いていたからである。その水は宮の右側、祭壇の南側の下から流れ下っていた。</span>
<span className="v" id="v2" data-v="2" data-xref="エゼキエル書 44:4; エゼキエル書 44:2"> それから彼は私を北の門から外へ連れ出し、外側の道を回って、東を向く外門へ導いた。見よ、水が門の右側から流れ出ていた。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="エゼキエル書 40:3; 使徒の働き 10:45–46; 使徒の働き 11:16–18"> その人は手に測り縄を持ち、東へ進んで一千キュビト<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一キュビトは、人の腕の中指の先からひじまでの長さで、約18インチ、または46センチメートルである。">a</a></sup>を測り、私に水の中を渡らせた。水はくるぶしまであった。</span>
<span className="v" id="v4" data-v="4" data-xref="コロサイ人への手紙 1:6; ローマ人への手紙 15:19; 使徒の働き 19:10–20"> 彼はさらに一千キュビトを測り、私に水の中を渡らせた。水は膝まであった。さらに一千キュビトを測り、私に水の中を渡らせると、水は腰まであった。</span>
<span className="v" id="v5" data-v="5" data-xref="イザヤ書 11:9; ハバクク書 2:14; マタイ 13:31–32"> さらに一千キュビトを測ると、私には渡ることのできない川になった。水が深くなり、泳げるほどの水、歩いて渡ることのできない川になっていたからである。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="エゼキエル書 44:5; エゼキエル書 40:4; ゼカリヤ書 4:2"> 彼は私に言った。「人の子よ、これを見たか。」<br />それから彼は私を連れて行き、川岸へ戻らせた。</span>
<span className="v" id="v7" data-v="7" data-xref="エゼキエル書 47:12; ヨハネの黙示録 22:2; 列王記第二 2:13"> 私が戻ると、見よ、川の両岸に非常に多くの木があった。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨシュア記 3:16; 申命記 3:17; 列王記第二 2:19–22"> 彼は私に言った。「この水は東の地域へ流れ出て、アラバへ下り、海へ向かって進む。海へ流れ込むと、海の水は癒やされる。</span>
<span className="v" id="v9" data-v="9" data-xref="ヨハネ 7:37–38; ヨハネ 6:63; ヨハネ 4:14"> この川が流れて行く所では、群がるすべての生き物が生きる。魚は非常に多くなる。この水がそこへ流れ込み、海の水が癒やされるので、川が流れて行く所では、すべてが生きる。</span>
<span className="v" id="v10" data-v="10" data-xref="マタイ 4:19; 詩篇 104:25; 民数記 34:6"> 漁師たちはその岸に立つ。エン・ゲディからエン・エグライムまで、網を広げる場所となる。魚は大海の魚のように種類豊かで、非常に多くなる。</span>
<span className="v" id="v11" data-v="11" data-xref="申命記 29:23; ヨハネの黙示録 22:11; エレミヤ書 17:6"> しかし、その沼と湿地は癒やされず、塩を取る場所として残される。</span>
<span className="v" id="v12" data-v="12" data-xref="ヨハネの黙示録 22:2; 詩篇 1:3; エレミヤ書 17:8"> 川の両岸には、食用となるあらゆる木が生える。その葉は枯れず、その実は絶えることがない。聖所から流れ出る水によって、毎月、新しい実を結ぶ。その実は食物となり、その葉は癒やしのために用いられる。」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="エゼキエル書 48:4–6; エレミヤ書 3:18; 民数記 34:2–12"> 主なる神はこう言われる。「あなたがたがイスラエルの十二部族に相続地として分ける土地の境界は、次のとおりである。ヨセフには二つの割り当てを与える。</span>
<span className="v" id="v14" data-v="14" data-xref="エゼキエル書 20:5–6; 創世記 12:7; エゼキエル書 48:29"> あなたがたは互いに等しくこれを相続する。わたしはこの地をあなたがたの先祖に与えると誓った。この地は相続地としてあなたがたのものとなる。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="民数記 34:8; エゼキエル書 48:1"> 土地の境界は次のとおりである。<br />北側は、大海からヘテロンへの道を通り、ツェダデの入口までとする。</span>
<span className="v" id="v16" data-v="16" data-xref="エゼキエル書 48:1; 民数記 13:21; サムエル記第二 8:8"> さらに、ハマテ、ベロタ、ダマスコの境界とハマテの境界との間にあるシブライムを経て、ハウランの境界にあるハツェル・ハティコンまでとする。</span>
<span className="v" id="v17" data-v="17" data-xref="エゼキエル書 48:1; 民数記 34:9"> 海からの境界は、ダマスコの境界にあるハツァル・エナンまでとし、北はハマテの境界までとする。これが北側である。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="創世記 13:10; 創世記 31:23; 創世記 31:47"> 東側は、ハウランとダマスコ、ギレアデとイスラエルの地との間を通り、ヨルダン川に沿って、北の境界から東の海まで測る。これが東側である。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="エゼキエル書 48:28; 申命記 32:51; 民数記 34:5"> 南側は、タマルからメリボテ・カデシュの水まで、さらに川に沿って大海までとする。これが南側である。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="民数記 34:6; エゼキエル書 48:1"> 西側は大海とし、南の境界からハマテの入口の向かいまでとする。これが西側である。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21"> あなたがたは、この土地をイスラエルの部族に従って自分たちの間で分けなければならない。</span>
<span className="v" id="v22" data-v="22" data-xref="コロサイ人への手紙 3:11; エペソ人への手紙 3:6; 使徒の働き 11:18"> あなたがたと、あなたがたの間に住み、あなたがたの間で子どもをもうけた寄留者との間で、これをくじによって相続地として分けなければならない。彼らをイスラエルの子らの中に生まれた者と同じように扱わなければならない。彼らもあなたがたと共に、イスラエルの諸部族の間で相続地を受ける。</span>
<span className="v" id="v23" data-v="23"> 寄留者が住んでいる部族の中で、その者に相続地を与えなければならない」と主なる神は言われる。</span>
</div>

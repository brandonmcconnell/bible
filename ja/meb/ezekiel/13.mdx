<div className="bp">
<span className="v" id="v1" data-v="1"> 主の言葉が私に臨んだ。</span>
<span className="v" id="v2" data-v="2" data-xref="エゼキエル書 13:17; エレミヤ書 37:19; エゼキエル書 22:28"> 「人の子よ、預言しているイスラエルの預言者たちに向かって預言し、自分の心のままに預言している者たちに言え。『主の言葉を聞け。</span>
<span className="v" id="v3" data-v="3" data-xref="哀歌 2:14; エレミヤ書 23:28–32; ホセア書 9:7"> 主なる神はこう言われる。「何も見ていないのに、自分の霊に従って歩む愚かな預言者たちには災いがある。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネの黙示録 19:20; ミカ書 2:11; テサロニケ人への第二の手紙 2:9–10"> イスラエルよ、あなたの預言者たちは荒れ跡に住む狐のようであった。</span>
<span className="v" id="v5" data-v="5" data-xref="エゼキエル書 22:30; 詩篇 106:23; イザヤ書 58:12"> あなたがたは破れ口に上らず、イスラエルの家のために城壁を築き直さなかった。そのため、主の日の戦いに立つことができない。</span>
<span className="v" id="v6" data-v="6" data-xref="エレミヤ書 29:8; エゼキエル書 22:28; エレミヤ書 28:15"> 彼らは偽りの幻を見、うその占いを語った。彼らは『主はこう言われる』と言うが、主は彼らを遣わしていない。それでも彼らは、その言葉が実現するのを人々に待ち望ませた。</span>
<span className="v" id="v7" data-v="7" data-xref="エゼキエル書 13:6; マタイ 24:23–24; エゼキエル書 13:2–3"> あなたがたは偽りの幻を見、偽りの占いを語ったではないか。『主はこう言われる』と言っているが、わたしは語っていない。」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="エゼキエル書 5:8; エゼキエル書 21:3; エゼキエル書 28:22"> それゆえ、主なる神はこう言われる。「あなたがたが偽りを語り、偽りの幻を見たので、見よ、わたしはあなたがたに立ち向かう」と主なる神は言われる。</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 87:6; 詩篇 69:28; エゼキエル書 20:38"> 「わたしの手は、偽りの幻を見る預言者と、偽りの占いを語る者に向けられる。彼らはわたしの民の集会に加わらず、イスラエルの家の名簿にも記されず、イスラエルの地に入ることもない。そのとき、あなたがたは、わたしが主なる神であることを知る。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="エゼキエル書 22:28; エゼキエル書 13:16; エレミヤ書 6:14"> 彼らは、『平和だ』と言ってわたしの民を惑わしたが、平和はない。だれかが壁を築くと、見よ、彼らはそれにしっくいを塗る。</span>
<span className="v" id="v11" data-v="11" data-xref="エゼキエル書 38:22; イザヤ書 28:2; ナホム書 1:7–8"> しっくいを塗る者たちに、それは倒れると言え。激しい大雨が降り、大粒の雹も降る。暴風がそれを引き裂く。</span>
<span className="v" id="v12" data-v="12" data-xref="列王記第二 3:13; 哀歌 2:14–15; 士師記 9:38"> 見よ、壁が倒れたとき、『あなたがたが塗ったしっくいはどこに行ったのか』と問われるではないか。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="イザヤ書 30:30; ヨハネの黙示録 16:21; 詩篇 148:8"> それゆえ、主なる神はこう言われる。「わたしは憤りのうちに暴風でそれを引き裂く。怒りのうちに激しい大雨を降らせ、憤りのうちに大粒の雹を降らせて、その壁を滅ぼす。</span>
<span className="v" id="v14" data-v="14" data-xref="ミカ書 1:6; エレミヤ書 14:15; エレミヤ書 6:15"> わたしは、あなたがたがしっくいを塗った壁を壊し、地面に倒して、その土台をむき出しにする。壁は倒れ、あなたがたはその中で滅びる。そのとき、あなたがたは、わたしが主であることを知る。</span>
<span className="v" id="v15" data-v="15" data-xref="イザヤ書 30:13; 詩篇 62:3; ネヘミヤ記 4:3"> こうして、わたしは壁と、それにしっくいを塗った者たちに対する憤りを全うする。そしてあなたがたに、『壁はなくなり、それにしっくいを塗った者たちもいなくなった』と言う。</span>
<span className="v" id="v16" data-v="16" data-xref="エゼキエル書 13:10; エレミヤ書 6:14; エレミヤ書 8:11"> 彼らは、エルサレムについて預言し、平和がないのに、エルサレムのために平和の幻を見るイスラエルの預言者たちである」と主なる神は言われる。』」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="エゼキエル書 13:2; 列王記第二 22:14; 士師記 4:4"> 人の子よ、あなたの民の娘たち、すなわち自分の心から預言する女たちに顔を向け、彼女たちに向かって預言せよ。</span>
<span className="v" id="v18" data-v="18" data-xref="ペテロの第二の手紙 2:14; エゼキエル書 13:20; テモテへの第二の手紙 4:3"> こう言え。『主なる神はこう言われる。「すべてのひじに魔法の帯を縫い付け、あらゆる背丈の人の頭に合わせてベールを作り、人の命を狩る女たちには災いだ。あなたがたはわたしの民の命を狩りながら、自分たちの命は守ろうとするのか。</span>
<span className="v" id="v19" data-v="19" data-xref="ミカ書 3:5; 箴言 28:21; エレミヤ書 23:17"> あなたがたは、一握りの大麦とパンのひとかけらのために、わたしの民の中でわたしを汚した。偽りに耳を傾けるわたしの民に偽りを語り、死ぬべきでない者を殺し、生きるべきでない者を生かしておいた。」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="エゼキエル書 13:18; テモテへの第二の手紙 3:8–9; エゼキエル書 13:8–9"> それゆえ、主なる神はこう言われる。「見よ、わたしは、あなたがたが人の命を鳥のように狩るために用いる魔法の帯に立ち向かう。それをあなたがたの腕から引き裂き、わなにかけられた者たちを鳥のように解き放つ。</span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 91:3"> わたしはまた、あなたがたのベールを引き裂き、わたしの民をあなたがたの手から救い出す。彼らはもはやあなたがたの手の中で獲物とはならない。そのとき、あなたがたは、わたしが主であることを知る。</span>
<span className="v" id="v22" data-v="22" data-xref="エレミヤ書 23:14; エレミヤ書 14:13–17; ペテロの第二の手紙 2:18–19"> あなたがたは偽りによって、わたしが悲しませなかった義人の心を悲しませた。また、悪人が悪い道から立ち返って命を得ることがないよう、その手を強めた。</span>
<span className="v" id="v23" data-v="23" data-xref="エゼキエル書 13:21; エゼキエル書 12:24; ミカ書 3:6"> それゆえ、あなたがたはもはや偽りの幻を見ることも、占いを行うこともない。わたしはわたしの民をあなたがたの手から救い出す。そのとき、あなたがたは、わたしが主であることを知る。」』」</span>
</div>

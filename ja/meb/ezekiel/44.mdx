<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="エゼキエル書 43:1; エゼキエル書 40:17; エゼキエル書 42:14"> それから彼は私を、東を向く聖所の外門へ戻した。その門は閉じられていた。</span>
<span className="v" id="v2" data-v="2" data-xref="エゼキエル書 43:2–4; 出エジプト記 24:10; イザヤ書 6:1–5"> 主は私に言われた。「この門は閉じたままにしておかなければならない。開いてはならず、だれもそこから入ってはならない。イスラエルの神、主がそこから入られたからである。それゆえ、門は閉じておかなければならない。</span>
<span className="v" id="v3" data-v="3" data-xref="エゼキエル書 46:2; エゼキエル書 34:24; エゼキエル書 37:25"> 君主だけは、君主としてそこに座り、主の前でパンを食べることができる。彼は門の前廊を通って入り、同じ道を通って出なければならない。」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="エゼキエル書 1:28; ヨハネの黙示録 1:17; エゼキエル書 3:23"> それから彼は北の門を通って、私を宮の前へ連れて行った。私が見ると、見よ、主の栄光が主の宮に満ちていた。そこで私はひれ伏した。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="エゼキエル書 40:4; エゼキエル書 43:10–11; 申命記 12:32"> 主は私に言われた。「人の子よ、主の宮のすべての定めとすべての律法について、わたしがあなたに告げるすべてのことを心に留め、目で見、耳で聞け。宮の入口と聖所のすべての出口をよく心に留めよ。</span>
<span className="v" id="v6" data-v="6" data-xref="エゼキエル書 3:9; エゼキエル書 45:9; ペテロの手紙第一 4:3"> 反逆する者たち、イスラエルの家に言え。『主なる神はこう言われる。「イスラエルの家よ、あなたがたのすべての忌むべき行いは、もう十分だ。</span>
<span className="v" id="v7" data-v="7" data-xref="レビ記 22:25; エレミヤ書 9:26; エゼキエル書 44:9"> あなたがたは、心にも肉体にも割礼を受けていない異国人をわたしの聖所に入れ、わたしの家を汚した。あなたがたがわたしのパン、脂肪と血をささげたとき、彼らはわたしの聖所の中にいた。そのうえ彼らはわたしの契約を破り、あなたがたの忌むべき行いをさらに重ねた。</span>
<span className="v" id="v8" data-v="8" data-xref="エゼキエル書 44:14; 民数記 18:3–5; エゼキエル書 40:45–46"> あなたがたは、わたしの聖なるものに関する務めを守らず、自分たちのために、わたしの聖所で務めを守る者たちを置いた。」</span>
<span className="v" id="v9" data-v="9" data-xref="ヨエル書 3:17; エゼキエル書 44:7; ゼカリヤ書 14:21"> 主なる神はこう言われる。「イスラエルの子らの中にいるどの異国人も、心にも肉体にも割礼を受けていない者は、わたしの聖所に入ってはならない。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="エゼキエル書 22:26; エゼキエル書 48:11; 列王記第二 23:8–9"> しかし、イスラエルが迷い出たときにわたしから遠く離れ、偶像を追ってわたしから迷い出たレビ人たちは、自分たちの不義を負う。</span>
<span className="v" id="v11" data-v="11" data-xref="民数記 16:9; 歴代誌 第二 29:34; 歴代誌 第二 30:17"> それでも彼らは、わたしの聖所で仕える者となり、宮の門を監督し、宮で務めを行う。彼らは民のために焼き尽くすささげ物といけにえを屠り、民の前に立って仕える。</span>
<span className="v" id="v12" data-v="12" data-xref="列王記第二 16:10–16; 詩篇 106:26; エゼキエル書 14:3–4"> 彼らは民の偶像の前で仕え、イスラエルの家を不義につまずかせるものとなった。それゆえ、わたしは彼らに向かって手を上げて誓った」と主なる神は言われる。「彼らは自分たちの不義を負う。</span>
<span className="v" id="v13" data-v="13" data-xref="民数記 18:3; 列王記第二 23:9; エゼキエル書 16:61"> 彼らはわたしに近づいて祭司の務めを行うことも、わたしの聖なるもの、最も聖なるもののどれにも近づくこともできない。彼らは自分たちの恥と、自ら行った忌むべきことの責めを負わなければならない。</span>
<span className="v" id="v14" data-v="14" data-xref="歴代誌上 23:28–32; 民数記 18:4"> それでも、わたしは彼らに宮の務めを守らせ、宮のすべての奉仕と、その中で行われるすべてのことを担当させる。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="申命記 10:8; エゼキエル書 48:11; エゼキエル書 44:7"> しかし、イスラエルの子らがわたしから迷い出たときにも、わたしの聖所の務めを守ったレビ人の祭司、ツァドクの子らは、わたしに近づいて仕える。彼らはわたしの前に立ち、脂肪と血をわたしにささげる」と主なる神は言われる。</span>
<span className="v" id="v16" data-v="16" data-xref="エゼキエル書 41:22; マラキ書 1:12; 民数記 18:7–8"> 「彼らはわたしの聖所に入り、わたしの食卓に近づいて仕え、わたしの指示を守る。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="ヨハネの黙示録 19:8; 出エジプト記 28:43; 出エジプト記 39:27–29"> 彼らが内庭の門に入るときには、亜麻布の衣服を着なければならない。内庭の門や、その内側で仕えるとき、羊毛の衣服を身に着けてはならない。</span>
<span className="v" id="v18" data-v="18" data-xref="出エジプト記 39:28; コリント人への第一の手紙 11:4–10; イザヤ書 3:20"> 頭には亜麻布のターバンを巻き、腰には亜麻布の下着を着けなければならない。汗をかくようなものを身に着けてはならない。</span>
<span className="v" id="v19" data-v="19" data-xref="エゼキエル書 46:20; レビ記 6:27; レビ記 6:10–11"> 民のいる外庭へ出るときには、務めを行うために着た衣服を脱ぎ、聖なる部屋に置かなければならない。それから別の衣服を着なければならない。その衣服によって民を聖別することがないようにするためである。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="コリント人への第一の手紙 11:14; 民数記 6:5; レビ記 21:5–24"> 彼らは頭を剃ってはならず、髪を長く伸ばしてもならない。髪をきちんと切りそろえなければならない。</span>
<span className="v" id="v21" data-v="21" data-xref="レビ記 10:9; テトス 1:7–8; テモテへの手紙第一 5:23"> 祭司はだれも、内庭に入るときにぶどう酒を飲んではならない。</span>
<span className="v" id="v22" data-v="22" data-xref="レビ記 21:7; レビ記 21:13–14; テモテへの手紙第一 3:2"> 彼らは、やもめや離縁された女を妻としてはならない。イスラエルの家の子孫である処女、または祭司のやもめだけを妻としなければならない。</span>
<span className="v" id="v23" data-v="23" data-xref="エゼキエル書 22:26; レビ記 10:10–11; テモテへの第二の手紙 2:24–25"> 彼らは、聖なるものと俗なるものとの違いをわたしの民に教え、汚れたものと清いものとを見分けさせなければならない。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="歴代誌上 23:4; エゼキエル書 22:26; 歴代誌 第二 19:8–10"> 争いが起こったとき、彼らは立って裁き、わたしの定めに従って判決を下さなければならない。彼らは、すべての定められた祭りにおいて、わたしの律法と掟を守り、わたしの安息日を聖なるものとしなければならない。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="コリント人への第二の手紙 5:16; レビ記 22:4; マタイ 8:21–22"> 彼らは死者に近づいて自分を汚してはならない。ただし、父、母、息子、娘、兄弟、または夫のいない姉妹のためには、自分を汚してもよい。</span>
<span className="v" id="v26" data-v="26" data-xref="ヘブル人への手紙 9:13–14; 民数記 19:11–14; 民数記 6:10–21"> 祭司が清められた後、さらに七日を数えなければならない。</span>
<span className="v" id="v27" data-v="27" data-xref="民数記 6:9–11; エゼキエル書 44:17; レビ記 4:3–35"> 聖所で務めを行うために聖所の内庭へ入る日、彼は自分の罪のきよめのささげ物をささげなければならない」と主なる神は言われる。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="ヨシュア記 13:33; 民数記 18:20; 申命記 18:1–2"> 「彼らには相続地がある。わたしが彼らの相続地である。あなたがたはイスラエルの中で、彼らに所有地を与えてはならない。わたしが彼らの所有である。</span>
<span className="v" id="v29" data-v="29" data-xref="民数記 18:14; レビ記 27:21; レビ記 27:28"> 彼らは穀物のささげ物、罪のきよめのささげ物、罪過のささげ物を食べる。イスラエルのうちで聖絶されたものはすべて、彼らのものとなる。</span>
<span className="v" id="v30" data-v="30" data-xref="ネヘミヤ記 10:35–37; 歴代誌 第二 31:10; 申命記 18:4"> あらゆるものの初物のうち最上のものと、あなたがたがささげるあらゆる奉納物は、祭司のものとなる。あなたがたは練り粉の初物も祭司に与えなければならない。祝福をあなたの家にとどまらせるためである。</span>
<span className="v" id="v31" data-v="31" data-xref="レビ記 22:8; 出エジプト記 22:31; 申命記 14:21"> 祭司たちは、鳥であれ動物であれ、自然に死んだものや、引き裂かれたものを食べてはならない。」』」</span>
</div>

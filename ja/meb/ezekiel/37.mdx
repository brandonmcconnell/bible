<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="エゼキエル書 3:22; エゼキエル書 1:3; 使徒の働き 8:39"> 主の手が私の上にあり、主の霊によって私を連れ出し、谷のただ中に降ろされた。そこは骨で満ちていた。</span>
<span className="v" id="v2" data-v="2" data-xref="詩篇 141:7; エゼキエル書 37:11; 申命記 11:30"> 主は私をそれらの骨の周りに歩き回らせた。見よ、谷の平地には非常に多くの骨があり、見よ、それらはすっかり乾いていた。</span>
<span className="v" id="v3" data-v="3" data-xref="ヨハネ 11:25–26; ヨハネ 5:21; 申命記 32:39"> 主は私に言われた。「人の子よ、これらの骨は生き返ることができるか。」<br />私は答えた。「主なる神よ、あなたがご存じです。」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="ヨハネ 5:25; ヨハネ 5:28–29; マタイ 21:21"> すると、主は私に言われた。「これらの骨に向かって預言し、言え。『乾いた骨よ、主の言葉を聞け。</span>
<span className="v" id="v5" data-v="5" data-xref="エゼキエル書 37:14; 詩篇 104:29–30; 創世記 2:7"> 主なる神はこれらの骨にこう言われる。「見よ、わたしはあなたがたの中に息を入れる。あなたがたは生きる。</span>
<span className="v" id="v6" data-v="6" data-xref="ヨエル書 2:27; イザヤ書 49:23; ヨエル書 3:17"> わたしはあなたがたに筋を付け、肉を生じさせ、皮膚で覆い、あなたがたの中に息を入れる。あなたがたは生きる。そのとき、あなたがたは、わたしが主であることを知る。」』」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="使徒の働き 2:2; 列王記第一 19:11–13; エレミヤ書 13:5–7"> そこで私は、命じられたとおりに預言した。私が預言していると、音がした。見よ、地響きが起こり、骨と骨が互いにつながった。</span>
<span className="v" id="v8" data-v="8"> 私が見ると、見よ、それらに筋が付き、肉が生じ、その上を皮膚が覆った。しかし、その中には息がなかった。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="ヨハネ 3:8; 雅歌 4:16; 詩篇 104:30"> そのとき、主は私に言われた。「風に預言せよ。人の子よ、預言して風に言え。『主なる神はこう言われる。「息よ、四方の風から来い。この殺された者たちに吹きつけ、彼らを生かせ。」』」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="ヨハネの黙示録 11:11; 詩篇 104:30; ヨハネの黙示録 20:4–5"> そこで私は、命じられたとおりに預言した。すると、息が彼らの中に入り、彼らは生きて、自分の足で立った。非常に大きな軍勢であった。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="エペソ人への手紙 2:1; 詩篇 77:7–9; エゼキエル書 39:25"> そのとき、主は私に言われた。「人の子よ、これらの骨はイスラエルの全家である。見よ、彼らは言っている。『われわれの骨は乾き、望みは失われた。われわれは完全に断ち切られた。』</span>
<span className="v" id="v12" data-v="12" data-xref="イザヤ書 26:19; ホセア書 13:14; テサロニケ人への手紙第一 4:16"> それゆえ、預言して彼らに言え。『主なる神はこう言われる。「見よ、わたしの民よ、わたしはあなたがたの墓を開き、墓からあなたがたを上らせ、イスラエルの地へ連れて行く。</span>
<span className="v" id="v13" data-v="13" data-xref="エゼキエル書 37:6; エゼキエル書 16:62; 詩篇 126:2–3"> わたしの民よ、わたしがあなたがたの墓を開き、墓からあなたがたを上らせるとき、あなたがたは、わたしが主であることを知る。</span>
<span className="v" id="v14" data-v="14" data-xref="エゼキエル書 36:27; ヨエル書 2:28–29; エゼキエル書 36:36"> わたしはあなたがたのうちにわたしの霊を置く。あなたがたは生きる。わたしはあなたがたを自分たちの地に置く。そのとき、あなたがたは、主であるわたしが語り、それを行ったことを知る」と主は言われる。』」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15"> 再び、主の言葉が私に臨んだ。</span>
<span className="v" id="v16" data-v="16" data-xref="歴代誌 第二 15:9; 歴代誌 第二 10:19; 歴代誌 第二 10:17"> 「人の子よ、一本の木を取り、その上に、『ユダと、その仲間であるイスラエルの子らのために』と書け。次にもう一本の木を取り、その上に、『ヨセフ、すなわちエフライムの木と、その仲間であるイスラエルの全家のために』と書け。</span>
<span className="v" id="v17" data-v="17" data-xref="ホセア書 1:11; エレミヤ書 50:4; イザヤ書 11:13"> それらを互いにつなぎ合わせて、一本の木とせよ。それらがあなたの手の中で一つになるようにせよ。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="エゼキエル書 24:19; エゼキエル書 12:9; エゼキエル書 17:12"> あなたの民の子らがあなたに、『これらが何を意味するのか、われわれに教えてくれないか』と言うとき、</span>
<span className="v" id="v19" data-v="19" data-xref="ゼカリヤ書 10:6; エゼキエル書 37:16–17; エペソ人への手紙 2:13–14"> 彼らに言え。『主なる神はこう言われる。「見よ、わたしはエフライムの手にあるヨセフの木と、その仲間であるイスラエルの諸部族を取り、ユダの木と合わせて一本の木とする。それらはわたしの手の中で一つになる。</span>
<span className="v" id="v20" data-v="20" data-xref="エゼキエル書 12:3; 民数記 17:6–9; ホセア書 12:10"> あなたが文字を書いた木は、彼らの目の前であなたの手にある。」』</span>
<span className="v" id="v21" data-v="21" data-xref="エゼキエル書 36:24; エレミヤ書 29:14; エレミヤ書 23:8"> 彼らに言え。『主なる神はこう言われる。「見よ、わたしはイスラエルの子らを、彼らが行った諸国の中から取り出し、四方から集め、自分たちの地へ連れて行く。</span>
<span className="v" id="v22" data-v="22" data-xref="エゼキエル書 37:24; エゼキエル書 34:23–24; エレミヤ書 3:18"> わたしはその地、イスラエルの山々で、彼らを一つの国民とする。一人の王が彼らすべての王となる。彼らは二度と二つの国民とはならず、二度と二つの王国に分かれることもない。</span>
<span className="v" id="v23" data-v="23" data-xref="ヨハネの黙示録 21:3–4; エゼキエル書 36:28–29; ヨハネの手紙第一 1:9"> 彼らは二度と、偶像、忌まわしいもの、どのような背きによっても自分を汚さない。わたしは、彼らが罪を犯したすべての住まいから彼らを救い出し、清める。彼らはわたしの民となり、わたしは彼らの神となる。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="エゼキエル書 34:23–24; ホセア書 3:5; エゼキエル書 37:25"> わたしのしもべダビデが彼らの王となる。彼らすべてに一人の羊飼いがいる。彼らはわたしの定めに従って歩み、わたしの掟を守り、それを行う。</span>
<span className="v" id="v25" data-v="25" data-xref="アモス書 9:15; エゼキエル書 37:24; エゼキエル書 28:25"> 彼らは、わたしがしもべヤコブに与えた地、あなたがたの先祖が住んでいた地に住む。彼らとその子どもたち、その子どもたちの子どもも、そこに永遠に住む。わたしのしもべダビデが永遠に彼らの君主となる。</span>
<span className="v" id="v26" data-v="26" data-xref="イザヤ書 55:3; エレミヤ書 30:19; エゼキエル書 34:25"> わたしは彼らと平和の契約を結ぶ。それは彼らとの永遠の契約となる。わたしは彼らをそこに置いて増やし、わたしの聖所を永遠に彼らの中に置く。</span>
<span className="v" id="v27" data-v="27" data-xref="ヨハネの黙示録 21:3; ヨハネ 1:14; エゼキエル書 37:23"> わたしの幕屋も彼らと共にある。わたしは彼らの神となり、彼らはわたしの民となる。</span>
<span className="v" id="v28" data-v="28" data-xref="ヨハネ 17:17–19; エゼキエル書 20:12; 出エジプト記 31:13"> わたしの聖所が永遠に彼らの中にあるとき、諸国は、主であるわたしがイスラエルを聖別する者であることを知る。」』」</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="エゼキエル書 33:21; エゼキエル書 1:2–3; エゼキエル書 3:14"> 私たちが捕囚となって第二十五年、年の初め、その月の十日、町が打たれてから第十四年の、まさにその日、主の手が私の上にあり、主は私をそこへ連れて行かれた。</span>
<span className="v" id="v2" data-v="2" data-xref="エゼキエル書 1:1; ダニエル書 7:1; ダニエル書 7:7"> 神の幻のうちに、主は私をイスラエルの地へ連れて行き、非常に高い山の上に降ろされた。その南側には、町の建物のようなものがあった。</span>
<span className="v" id="v3" data-v="3" data-xref="エゼキエル書 47:3; ヨハネの黙示録 11:1; ダニエル書 10:5–6"> 主が私をそこへ連れて行かれると、見よ、青銅のような姿をした一人の人がいた。その手には亜麻のひもと測り竿があり、門の所に立っていた。</span>
<span className="v" id="v4" data-v="4" data-xref="エゼキエル書 44:5; マタイ 10:27; エゼキエル書 2:7–8"> その人は私に言った。「人の子よ、目で見、耳で聞き、わたしがあなたに示すことをすべて心に留めよ。あなたはそれらを示されるために、ここへ連れて来られた。あなたが見るすべてのことをイスラエルの家に告げよ。」</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="エゼキエル書 42:20; イザヤ書 26:1; ヨハネの黙示録 21:12"> 見よ、宮の外側を壁が取り囲んでいた。その人の手には、通常の一キュビトに一手幅を加えた長さを一キュビトとする、六キュビト<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="通常の一キュビトは、人の腕の中指の先からひじまでの長さで、約18インチ、または46センチメートルである。一手幅は約4.3インチ、または11センチメートルなので、ここで述べられている長キュビトは約22.3インチ、または57センチメートルとなる。したがって、長キュビト六キュビトの測り竿は、約3ヤード26.6インチ、または約3.42メートルであった。">a</a></sup>の測り竿があった。彼が壁を測ると、厚さは一竿、高さも一竿であった。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="エゼキエル書 43:1; エゼキエル書 8:16; エゼキエル書 11:1"> それから彼は東を向いている門へ行き、その階段を上った。門の敷居を測ると、幅は一竿であり、もう一方の敷居も幅一竿であった。</span>
<span className="v" id="v7" data-v="7" data-xref="エゼキエル書 40:36; エゼキエル書 40:33; 歴代誌上 23:28"> それぞれの詰め所は長さ一竿、幅一竿で、詰め所と詰め所の間は五キュビトであった。宮に面する門の前廊のそばにある敷居は一竿であった。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8"> 彼はまた、宮に面する門の前廊を測ると、一竿であった。</span>
<span className="v" id="v9" data-v="9" data-xref="エゼキエル書 45:19"> それから門の前廊を測ると八キュビト、その脇柱は二キュビトであった。門の前廊は宮に面していた。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10"> 東の門の詰め所は、こちら側に三つ、あちら側に三つあった。三つとも同じ寸法であり、脇柱もこちら側とあちら側で同じ寸法であった。</span>
<span className="v" id="v11" data-v="11"> 彼が門口の幅を測ると十キュビト、門の長さは十三キュビトであった。</span>
<span className="v" id="v12" data-v="12"> 詰め所の前には、こちら側に一キュビトの仕切りがあり、あちら側にも一キュビトの仕切りがあった。詰め所は、こちら側もあちら側も六キュビトであった。</span>
<span className="v" id="v13" data-v="13"> 彼が一方の詰め所の屋根から、向かい側の詰め所の屋根まで門を測ると、幅は二十五キュビトで、入口と入口が向かい合っていた。</span>
<span className="v" id="v14" data-v="14" data-xref="出エジプト記 27:9; イザヤ書 62:9; エゼキエル書 42:1"> また、彼は脇柱を六十キュビトとした。門の周囲の庭は脇柱まで達していた。</span>
<span className="v" id="v15" data-v="15"> 入口にある門の前面から、門の内側の前廊の前面までは五十キュビトであった。</span>
<span className="v" id="v16" data-v="16" data-xref="歴代誌 第二 3:5; 列王記第一 6:4; エゼキエル書 41:26"> 詰め所と、門の内側にあるその脇柱の周囲には格子窓があり、アーチにも同じように窓があった。窓は周囲で内側を向き、それぞれの脇柱には、なつめやしの木が彫られていた。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="ヨハネの黙示録 11:2; エゼキエル書 42:1; 歴代誌上 23:28"> それから彼は私を外庭へ連れて行った。見よ、庭の周囲には部屋があり、石畳が造られていた。石畳の上には三十の部屋があった。</span>
<span className="v" id="v18" data-v="18"> 石畳は門の両側にあり、門の長さに対応していた。これが下の石畳であった。</span>
<span className="v" id="v19" data-v="19" data-xref="エゼキエル書 40:23; エゼキエル書 40:27; エゼキエル書 46:1–2"> それから彼は、下の門の前面から内庭の外側の前面までの幅を測ると、東側も北側も百キュビトであった。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="エゼキエル書 40:6"> 彼は、北を向いている外庭の門の長さと幅を測った。</span>
<span className="v" id="v21" data-v="21" data-xref="エゼキエル書 40:29–30; エゼキエル書 40:25–26; エゼキエル書 40:10–16"> その詰め所は、こちら側に三つ、あちら側に三つあった。その脇柱とアーチは最初の門と同じ寸法で、長さは五十キュビト、幅は二十五キュビトであった。</span>
<span className="v" id="v22" data-v="22" data-xref="エゼキエル書 40:31; エゼキエル書 40:37; エゼキエル書 40:6"> その窓、アーチ、なつめやしの木は、東を向いている門と同じ寸法であった。七段の階段を上ってその門へ行き、そのアーチは階段の前にあった。</span>
<span className="v" id="v23" data-v="23" data-xref="エゼキエル書 40:19; エゼキエル書 40:27–28; 出エジプト記 38:9–12"> 内庭には、北側と東側で、それぞれ外庭の門と向かい合う門があった。彼が門から門まで測ると、百キュビトであった。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="エゼキエル書 46:9; エゼキエル書 40:6; エゼキエル書 40:20–21"> 彼は私を南へ導いた。見よ、南を向く門があった。彼がその脇柱とアーチを測ると、これまでと同じ寸法であった。</span>
<span className="v" id="v25" data-v="25" data-xref="エゼキエル書 40:33; エゼキエル書 40:16; エゼキエル書 40:21–22"> その門とアーチの周囲には、ほかの窓と同じような窓があった。長さは五十キュビト、幅は二十五キュビトであった。</span>
<span className="v" id="v26" data-v="26" data-xref="エゼキエル書 40:22; エゼキエル書 40:16; エゼキエル書 40:6"> そこへ上るには七段の階段があり、そのアーチは階段の前にあった。脇柱には、こちら側に一本、あちら側に一本、なつめやしの木が彫られていた。</span>
<span className="v" id="v27" data-v="27" data-xref="エゼキエル書 40:23; エゼキエル書 40:32; エゼキエル書 40:19"> 内庭にも南を向く門があった。彼が南に向かって門から門まで測ると、百キュビトであった。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="エゼキエル書 40:35; エゼキエル書 40:32"> それから彼は南の門を通って、私を内庭へ連れて行った。彼が南の門を測ると、これまでと同じ寸法であった。</span>
<span className="v" id="v29" data-v="29" data-xref="エゼキエル書 40:25; エゼキエル書 40:16; エゼキエル書 40:7"> その詰め所、脇柱、アーチも同じ寸法であった。その門とアーチの周囲には窓があった。門の長さは五十キュビト、幅は二十五キュビトであった。</span>
<span className="v" id="v30" data-v="30" data-xref="エゼキエル書 40:21; エゼキエル書 40:36; エゼキエル書 40:25"> 周囲にはアーチがあり、長さ二十五キュビト、幅五キュビトであった。</span>
<span className="v" id="v31" data-v="31" data-xref="エゼキエル書 40:26; エゼキエル書 40:34; エゼキエル書 40:22"> そのアーチは外庭に面していた。脇柱には、なつめやしの木が彫られていた。そこへ上る階段は八段であった。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="エゼキエル書 40:35; エゼキエル書 40:28–31"> それから彼は私を、東側の内庭へ連れて行った。彼が門を測ると、これまでと同じ寸法であった。</span>
<span className="v" id="v33" data-v="33" data-xref="エゼキエル書 40:21; エゼキエル書 40:36; エゼキエル書 40:25"> その詰め所、脇柱、アーチも同じ寸法であった。その門とアーチの周囲には窓があった。門の長さは五十キュビト、幅は二十五キュビトであった。</span>
<span className="v" id="v34" data-v="34" data-xref="エゼキエル書 40:22; エゼキエル書 40:31; エゼキエル書 40:37"> そのアーチは外庭に面していた。こちら側とあちら側の脇柱には、なつめやしの木が彫られていた。そこへ上る階段は八段であった。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="エゼキエル書 47:2; エゼキエル書 40:32; エゼキエル書 44:4"> それから彼は私を北の門へ連れて行き、これまでと同じ寸法で測った。</span>
<span className="v" id="v36" data-v="36" data-xref="エゼキエル書 40:29; エゼキエル書 40:21; エゼキエル書 40:16"> その詰め所、脇柱、アーチがあり、その周囲には窓があった。門の長さは五十キュビト、幅は二十五キュビトであった。</span>
<span className="v" id="v37" data-v="37" data-xref="エゼキエル書 40:34; エゼキエル書 40:31"> その脇柱は外庭に面していた。こちら側とあちら側の脇柱には、なつめやしの木が彫られていた。そこへ上る階段は八段であった。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="歴代誌 第二 4:6; エゼキエル書 40:17; レビ記 8:21"> 門の脇柱のそばには、入口のある部屋があった。そこで焼き尽くすささげ物を洗った。</span>
<span className="v" id="v39" data-v="39" data-xref="エゼキエル書 46:2; レビ記 1:3–17; レビ記 4:2–3"> 門の前廊には、こちら側に二つ、あちら側に二つの台があった。その上で焼き尽くすささげ物、罪のきよめのささげ物、罪過のささげ物を屠った。</span>
<span className="v" id="v40" data-v="40"> 北の門の入口へ上って行く外側の一方には二つの台があり、門の前廊に属するもう一方にも二つの台があった。</span>
<span className="v" id="v41" data-v="41" data-xref="エゼキエル書 40:39–40"> 門のそばには、こちら側に四つ、あちら側に四つ、合わせて八つの台があり、その上でいけにえを屠った。</span>
<span className="v" id="v42" data-v="42" data-xref="エゼキエル書 40:39; 出エジプト記 20:25"> 焼き尽くすささげ物のために、切り石で造った台が四つあった。それぞれ長さ一キュビト半、幅一キュビト半、高さ一キュビトであった。その上に、焼き尽くすささげ物といけにえを屠るための道具を置いた。</span>
<span className="v" id="v43" data-v="43" data-xref="レビ記 1:8; レビ記 1:6; レビ記 8:20"> 手幅ほどの鉤が、内側の周囲に取り付けられていた。ささげ物の肉は台の上に置かれた。</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="歴代誌上 6:31–32; 歴代誌上 16:41–43; エゼキエル書 40:27"> 内門の外側、内庭には、歌う者たちのための部屋があった。それは北の門のそばにあり、南を向いていた。東の門のそばにある一つの部屋は北を向いていた。</span>
<span className="v" id="v45" data-v="45" data-xref="歴代誌上 9:23; 詩篇 134:1; レビ記 8:35"> 彼は私に言った。「南を向くこの部屋は、宮の務めを守る祭司たちのためである。</span>
<span className="v" id="v46" data-v="46" data-xref="エゼキエル書 44:15; エゼキエル書 43:19; 列王記第一 2:35"> 北を向く部屋は、祭壇の務めを守る祭司たちのためである。彼らはツァドクの子らであり、レビの子らの中から主に近づいて仕える者たちである。」</span>
<span className="v" id="v47" data-v="47" data-xref="エゼキエル書 40:19; エゼキエル書 40:23; エゼキエル書 40:27"> 彼が庭を測ると、長さ百キュビト、幅百キュビトの正方形であった。祭壇は宮の前にあった。</span>
</div>
<div className="bp">
<span className="v" id="v48" data-v="48" data-xref="歴代誌 第二 3:4; 列王記第一 6:3"> それから彼は私を宮の前廊へ連れて行き、前廊の脇柱を測った。こちら側は五キュビト、あちら側も五キュビトであった。門の幅は、こちら側が三キュビト、あちら側も三キュビトであった。</span>
<span className="v" id="v49" data-v="49" data-xref="列王記第一 7:15–21; エゼキエル書 40:34; 歴代誌 第二 3:17"> 前廊の長さは二十キュビト、幅は十一キュビトであった。人々は階段を上ってそこへ行った。脇柱のそばには、こちら側に一本、あちら側に一本の柱があった。</span>
</div>

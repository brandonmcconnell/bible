<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="エゼキエル書 37:4; エゼキエル書 34:14; エゼキエル書 37:22"> 「人の子よ、イスラエルの山々に向かって預言し、こう言え。『イスラエルの山々よ、主の言葉を聞け。</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 32:13; エゼキエル書 25:3; エゼキエル書 35:10"> 主なる神はこう言われる。「敵があなたがたに向かって、『ああ、思いどおりだ。昔からの高き所は、われわれの所有となった』と言った。」』</span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 44:13–14; 哀歌 2:15–16; エレミヤ書 18:16"> それゆえ、預言して言え。『主なる神はこう言われる。「彼らはあなたがたを荒れ果てさせ、四方からのみ尽くし、残された諸国の所有物にしようとした。あなたがたは人々の口に上り、民の悪評の的となった。」</span>
<span className="v" id="v4" data-v="4" data-xref="エゼキエル書 34:28; 申命記 11:11; エゼキエル書 36:6"> それゆえ、イスラエルの山々よ、主なる神の言葉を聞け。主なる神は、山々と丘、水の流れる谷と低地、荒れ果てた廃墟と見捨てられた町々、すなわち周囲に残された諸国の略奪物となり、あざけりとなった所にこう言われる。</span>
<span className="v" id="v5" data-v="5" data-xref="ミカ書 7:8; エゼキエル書 36:3; 詩篇 137:7"> それゆえ、主なる神はこう言われる。「わたしは、ねたみの火のうちに、残された諸国とエドム全土に向かって語った。彼らは心から喜び、心の底からの侮りをもって、わたしの地を自分たちの所有とし、略奪物にしようとした。」』</span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 123:3–4; エゼキエル書 34:29; 詩篇 74:23"> それゆえ、イスラエルの地について預言し、山々と丘、水の流れる谷と低地に言え。『主なる神はこう言われる。「見よ、あなたがたが諸国の辱めを負ったので、わたしはねたみと憤りのうちに語った。」</span>
<span className="v" id="v7" data-v="7" data-xref="エゼキエル書 20:5; アモス書 1:1–15; エゼキエル書 20:15"> それゆえ、主なる神はこう言われる。「わたしは誓った。あなたがたの周囲にいる諸国は、必ず自分たちの辱めを負う。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="イザヤ書 27:6; ヘブル人への手紙 10:37; エゼキエル書 34:26–29"> しかし、イスラエルの山々よ、あなたがたは枝を伸ばし、わたしの民イスラエルのために実を結ぶ。彼らが帰って来る時が近いからである。</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 46:11; ホセア書 2:21–23; エゼキエル書 36:34"> 見よ、わたしはあなたがたの味方である。わたしはあなたがたに心を向ける。あなたがたは耕され、種をまかれる。</span>
<span className="v" id="v10" data-v="10" data-xref="エゼキエル書 36:33; エレミヤ書 33:12; エゼキエル書 36:37"> わたしはあなたがたの上に人を増やす。イスラエルの全家、そのすべてを増やす。町々には人が住み、廃墟は建て直される。</span>
<span className="v" id="v11" data-v="11" data-xref="エレミヤ書 33:12; エレミヤ書 23:5–8; エレミヤ書 31:27"> わたしはあなたがたの上に人と動物を増やす。彼らは増え、実り豊かになる。わたしは、以前のようにあなたがたに人を住まわせ、初めのころよりも良くする。そのとき、あなたがたは、わたしが主であることを知る。</span>
<span className="v" id="v12" data-v="12" data-xref="エレミヤ書 15:7; エゼキエル書 36:13; エレミヤ書 32:44"> わたしは人々、すなわち、わたしの民イスラエルをあなたがたの上に歩ませる。彼らはあなたがたを所有し、あなたがたは彼らの相続地となる。あなたがたは二度と彼らから子を奪わない。」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="民数記 13:32"> 主なる神はこう言われる。「人々はあなたがたに、『あなたは人を食い尽くし、自分の国民から子を奪ってきた』と言っている。</span>
<span className="v" id="v14" data-v="14" data-xref="エゼキエル書 37:25–28; アモス書 9:15; イザヤ書 60:21"> それゆえ、あなたはもはや人を食い尽くさず、自分の国民から子を奪うこともない」と主なる神は言われる。</span>
<span className="v" id="v15" data-v="15" data-xref="エゼキエル書 34:29; 詩篇 89:50; エゼキエル書 36:6"> 「わたしは、あなたに諸国からの辱めを二度と聞かせない。あなたは諸民族からのそしりを二度と負わず、自分の国民を二度とつまずかせない」と主なる神は言われる。』」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16"> さらに、主の言葉が私に臨んだ。</span>
<span className="v" id="v17" data-v="17" data-xref="エレミヤ書 2:7; 民数記 35:33–34; ミカ書 2:10"> 「人の子よ、イスラエルの家が自分たちの地に住んでいたとき、彼らはその歩みと行いによって地を汚した。わたしの前では、彼らの歩みは月経による女の汚れのようであった。</span>
<span className="v" id="v18" data-v="18" data-xref="歴代誌 第二 34:21; エゼキエル書 7:8; 哀歌 2:4"> それゆえ、彼らがその地で流した血と、その偶像によって地を汚したことのために、わたしは彼らの上に憤りを注いだ。</span>
<span className="v" id="v19" data-v="19" data-xref="エゼキエル書 39:24; 申命記 28:64; エゼキエル書 5:12"> わたしは彼らを諸国の間に散らし、国々の中に追い散らした。彼らの歩みと行いに従って彼らを裁いた。</span>
<span className="v" id="v20" data-v="20" data-xref="ローマ人への手紙 2:24; イザヤ書 52:5; エレミヤ書 33:24"> 彼らが行った諸国で、彼らはわたしの聖なる名を汚した。人々が彼らについて、『この者たちは主の民でありながら、主の地を離れた』と言ったからである。</span>
<span className="v" id="v21" data-v="21" data-xref="イザヤ書 48:9; 詩篇 74:18; エゼキエル書 20:9"> しかし、わたしは、イスラエルの家が行った諸国の中で汚した、わたしの聖なる名を惜しんだ。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="詩篇 106:8; エゼキエル書 36:32; 詩篇 115:1–2"> それゆえ、イスラエルの家に言え。『主なる神はこう言われる。「イスラエルの家よ、わたしがこれを行うのは、あなたがたのためではない。あなたがたが行った諸国の中で汚した、わたしの聖なる名のためである。</span>
<span className="v" id="v23" data-v="23" data-xref="エゼキエル書 20:41; イザヤ書 5:16; エゼキエル書 39:7"> わたしは、諸国の中で汚されたわたしの大いなる名、あなたがたが彼らの中で汚した名を聖なるものとする。わたしが諸国の目の前で、あなたがたのうちに自らが聖なる者であることを示すとき、彼らは、わたしが主であることを知る」と主なる神は言われる。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="エゼキエル書 37:21; エゼキエル書 34:13; アモス書 9:14–15"> わたしはあなたがたを諸国の中から取り、すべての国々から集め、あなたがた自身の地へ連れて行く。</span>
<span className="v" id="v25" data-v="25" data-xref="ヘブル人への手紙 10:22; ヨハネ 3:5; エレミヤ書 33:8"> わたしは清い水をあなたがたの上に振りかける。あなたがたは清くなる。わたしは、あなたがたのすべての汚れと、すべての偶像からあなたがたを清める。</span>
<span className="v" id="v26" data-v="26" data-xref="エゼキエル書 11:19–20; 詩篇 51:10; コリント人への第二の手紙 5:17"> わたしはあなたがたに新しい心を与え、あなたがたのうちに新しい霊を置く。あなたがたの肉体から石の心を取り除き、肉の心を与える。</span>
<span className="v" id="v27" data-v="27" data-xref="テトス 3:3–6; ヘブル人への手紙 13:21; コリント人への第一の手紙 3:16"> わたしはあなたがたのうちにわたしの霊を置き、わたしの掟に従って歩ませる。あなたがたはわたしの定めを守り、それを行う。</span>
<span className="v" id="v28" data-v="28" data-xref="エレミヤ書 31:33; エレミヤ書 32:38; エゼキエル書 37:27"> あなたがたは、わたしがあなたがたの先祖に与えた地に住む。あなたがたはわたしの民となり、わたしはあなたがたの神となる。</span>
<span className="v" id="v29" data-v="29" data-xref="ヨハネ 1:7–9; マタイ 1:21; ホセア書 2:21–23"> わたしはあなたがたを、すべての汚れから救う。わたしは穀物を呼び寄せて増やし、あなたがたの上に飢饉をもたらさない。</span>
<span className="v" id="v30" data-v="30" data-xref="エゼキエル書 34:27; ヨエル書 2:26; 申命記 29:23–28"> わたしは木の実と畑の産物を増やす。あなたがたが諸国の間で、飢饉による辱めを二度と受けないためである。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="エゼキエル書 6:9; エゼキエル書 20:43; ネヘミヤ記 9:26–35"> そのとき、あなたがたは自分たちの悪い歩みと、良くない行いを思い出し、自分たちの不義と忌むべき行いのために、自分自身を忌み嫌う。</span>
<span className="v" id="v32" data-v="32" data-xref="申命記 9:5; エゼキエル書 36:22; テモテへの第二の手紙 1:9"> わたしがこれを行うのは、あなたがたのためではない」と主なる神は言われる。「そのことを知れ。イスラエルの家よ、自分たちの歩みを恥じ、辱められよ。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="イザヤ書 58:12; エゼキエル書 36:10; エレミヤ書 33:10"> 主なる神はこう言われる。わたしがあなたがたをすべての不義から清める日に、町々に人を住まわせ、廃墟を建て直す。</span>
<span className="v" id="v34" data-v="34" data-xref="エゼキエル書 6:14; エレミヤ書 25:9–11; 歴代誌 第二 36:21"> 荒れ果てていた地は、通り過ぎるすべての者の目に荒れ地と見えていたが、耕されるようになる。</span>
<span className="v" id="v35" data-v="35" data-xref="イザヤ書 51:3; ヨエル書 2:3; エレミヤ書 33:9"> 人々は、『荒れ果てていたこの地は、エデンの園のようになった。廃墟となり、荒れ果て、破壊されていた町々は、城壁で囲まれ、人が住んでいる』と言う。</span>
<span className="v" id="v36" data-v="36" data-xref="マタイ 24:35; 民数記 23:19; エゼキエル書 17:24"> そのとき、あなたがたの周囲に残された諸国は、主であるわたしが、破壊された所を建て直し、荒れ果てていた所に植えたことを知る。主であるわたしが語り、それを行う。</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="ヨハネの手紙第一 5:14; ヘブル人への手紙 10:21–22; エゼキエル書 14:3"> 主なる神はこう言われる。このことについても、わたしはイスラエルの家の願いを聞き入れ、彼らのために行う。わたしは彼らを、羊の群れのように増やす。</span>
<span className="v" id="v38" data-v="38" data-xref="列王記第一 8:63; 使徒の働き 2:5–11; ヨハネ 10:16"> いけにえの羊の群れのように、定められた祭りの時のエルサレムの羊の群れのように、廃墟となった町々は人の群れで満ちる。そのとき、彼らは、わたしが主であることを知る。』」</span>
</div>

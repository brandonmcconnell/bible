<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="サムエル記第一 16:13; 詩篇 78:71; サムエル記第一 9:16"> その時、サムエルは油の壺を取り、それを彼の頭に注ぎ、彼に口づけして言った。「主が、ご自身の所有の民を治める君主としてあなたに油を注がれたのだ。</span>
<span className="v" id="v2" data-v="2" data-xref="サムエル記第一 9:3–5; 創世記 35:19–20; ヨシュア記 18:28"> 今日、あなたがわたしから去って行く時、あなたはゼルツァのベニヤミンの領域にあるラケルの墓のそばで二人の男に出会う。彼らはあなたに言うであろう。『あなたが探しに行ったろばは見つかった。そして見よ、あなたの父はろばのことを気にかけるのをやめ、「わたしの息子のためにどうしようか」と言って、あなたのために思い煩っている。』</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 35:3; 創世記 35:1; 創世記 28:22"> それからあなたはそこからさらに先へ進み、タボルの樫の木に来る。そこで、神のもとへ行くためにベテルへ上って行く三人の男があなたに出会う。一人は三匹の子やぎを運び、一人は三つのパンを運び、もう一人はぶどう酒の皮袋を一つ運んでいる。</span>
<span className="v" id="v4" data-v="4" data-xref="士師記 18:15"> 彼らはあなたに挨拶し、二つのパンをあなたに与える。あなたはそれを彼らの手から受け取りなさい。</span>
<span className="v" id="v5" data-v="5" data-xref="列王記第二 3:15; サムエル記第一 13:3; サムエル記第一 19:20"> その後、あなたはペリシテ人の守備隊がある神の丘に来る。あなたがそこ、すなわちその町に来た時、琴、タンバリン、笛、竪琴を先頭にして、高き所から下って来る預言者たちの一団に出会う。彼らは預言している。</span>
<span className="v" id="v6" data-v="6" data-xref="サムエル記第一 10:10; サムエル記第一 19:23–24; 民数記 11:25"> その時、主の霊があなたの上に激しく臨み、あなたも彼らと一緒に預言し、変えられて別の人のようになる。</span>
<span className="v" id="v7" data-v="7" data-xref="士師記 6:12; ヨシュア記 1:5; イザヤ書 7:14"> これらのしるしがあなたに臨んだなら、その時できることを行いなさい。神があなたとともにおられるからである。</span>
<span className="v" id="v8" data-v="8" data-xref="サムエル記第一 11:14–15; サムエル記第一 13:4; サムエル記第一 13:8–15"> あなたはわたしより先にギルガルへ下って行きなさい。そして見よ、わたしは全焼のささげ物を献げ、和解のいけにえを献げるために、あなたのところに下って行く。わたしがあなたのところに行き、あなたが何をすべきかをあなたに示すまで、あなたは七日の間待たなければならない。」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="イザヤ書 38:7–8; サムエル記第一 10:2–6; 士師記 7:11"> 彼がサムエルのもとから去ろうとして背を向けた時、神は彼に別の心を与えられた。そしてこれらすべてのしるしがその日のうちに起こった。</span>
<span className="v" id="v10" data-v="10" data-xref="サムエル記第一 10:5–6; サムエル記第一 19:20–24"> 彼らがそこの丘に来た時、見よ、預言者たちの一団が彼に出会った。そして神の霊が彼の上に激しく臨み、彼は彼らの中で預言した。</span>
<span className="v" id="v11" data-v="11" data-xref="サムエル記第一 19:24; ヨハネ 7:15; マタイ 13:54–55"> 以前から彼を知っていたすべての者が、見よ、彼が預言者たちと一緒に預言しているのを見た時、民は互いに言った。「キシュの息子に何が起こったのか。サウルもまた預言者たちの仲間なのか。」</span>
<span className="v" id="v12" data-v="12" data-xref="イザヤ書 54:13; ヨハネ 6:45; ヤコブの手紙 1:17"> その同じ場所の一人が答えた。「では、あの預言者たちの父はだれなのか。」それゆえ、「サウルもまた預言者たちの仲間なのか」ということが、ことわざとなった。</span>
<span className="v" id="v13" data-v="13"> 彼が預言し終えた時、彼は高き所へ来た。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="サムエル記第一 14:50; 列王記第二 5:25; サムエル記第一 9:3–10"> サウルのおじは彼とその若者に言った。「あなたがたはどこへ行っていたのか。」<br />彼は言った。「ろばを探しにです。見つからないのを見て、私たちはサムエルのところへ行きました。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15"> サウルのおじは言った。「どうか、サムエルがあなたがたに何と言ったか、わたしに教えてくれ。」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="箴言 29:11; 士師記 14:6; サムエル記第一 9:20"> サウルはおじに言った。「ろばが見つかったと、彼は私たちにはっきりと教えてくれました。」しかし、サムエルが語った王位のことについては、彼は彼に告げなかった。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="士師記 20:1; サムエル記第一 7:5–6"> サムエルはミツパで、主の御前に民を呼び集めた。</span>
<span className="v" id="v18" data-v="18" data-xref="士師記 6:8–9; ネヘミヤ記 9:27–28; 士師記 2:1"> そして彼はイスラエルの人々に言った。「イスラエルの神、主はこう言われる。『わたしがイスラエルをエジプトから導き上げ、エジプト人の手と、あなたがたを虐げたすべての王国の手から、あなたがたを救い出した。』</span>
<span className="v" id="v19" data-v="19" data-xref="サムエル記第一 12:12; サムエル記第一 8:19; ヨシュア記 24:1"> しかしあなたがたは今日、すべての災難と苦難からご自身であなたがたを救い出されるあなたがたの神を退け、彼に向かって『いいえ。私たちの上に王を立てよ』と言った。それゆえ今、あなたがたの部族ごとに、また千人隊ごとに、主の御前に進み出なさい。」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="ヨシュア記 7:16–18; 使徒の働き 1:24–26; サムエル記第一 14:41"> こうしてサムエルがイスラエルのすべての部族を近づけると、ベニヤミン部族が選ばれた。</span>
<span className="v" id="v21" data-v="21"> 彼がベニヤミン部族をその氏族ごとに近づけると、マトリの氏族が選ばれた。そしてキシュの息子サウルが選ばれたが、人々が彼を探した時、彼は見つからなかった。</span>
<span className="v" id="v22" data-v="22" data-xref="民数記 27:21; 士師記 20:18; サムエル記第一 23:2–4"> それゆえ、彼らはさらに主に尋ねた。「まだここに人が来るのでしょうか。」<br />主は答えられた。「見よ、彼は荷物の間に身を隠している。」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="サムエル記第一 9:2; サムエル記第一 16:7; サムエル記第一 17:4"> 彼らは走って行き、そこから彼を連れて来た。彼が民の間に立った時、彼は肩から上はどの民よりも背が高かった。</span>
<span className="v" id="v24" data-v="24" data-xref="列王記第一 1:25; 列王記第一 1:39; サムエル記第二 21:6"> サムエルはすべての民に言った。「主が選ばれた者を見ているか。すべての民の中に彼のような者はいない。」<br />すべての民は叫んで、「王よ、万歳」と言った。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="サムエル記第一 8:11–18; 申命記 17:14–20; ローマ人への手紙 13:1–7"> その時サムエルは民に王権の規定を語り、それを書に書き記し、主の御前にそれを置いた。サムエルはすべての民を、それぞれ自分の家に去らせた。</span>
<span className="v" id="v26" data-v="26" data-xref="サムエル記第一 11:4; ヨシュア記 18:28; サムエル記第一 15:34"> サウルもまた、ギベアにある自分の家へ行った。そして神に心を動かされた勇士たちが、彼と一緒に行った。</span>
<span className="v" id="v27" data-v="27" data-xref="申命記 13:13; 歴代誌 第二 17:5; 列王記第一 10:25"> しかし、何人かのならず者たちが、「どうしてこの男が私たちを救うことができようか」と言った。彼らは彼を軽蔑し、彼に贈り物を持って来なかった。しかし彼は黙っていた。</span>
</div>
